<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:4–10; 马太福音 13:1–15; 马可福音 4:1–12"> 那一天，耶稣从屋里出来，坐在海边。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 5:3; 马太福音 4:25; 马可福音 4:1"> 有一大群人聚集到祂那里，祂只好上船坐下，众人都站在岸上。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 4:2–9; 马可福音 4:13; 诗篇 78:2"> 祂用比喻对他们讲许多事，说：<span className="woj">“看哪，有一个撒种的人出去撒种。</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:18–19"> <span className="woj">撒的时候，有些种子落在路旁，飞鸟来把它们吃尽了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结 11:19; 以西结 36:26; 撒迦利亚书 7:12"> <span className="woj">有些落在石头地上，土不深，就立刻发苗，因为土浅；</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:21; 雅各书 1:11–12; 歌罗西书 1:23"> <span className="woj">太阳一出来，就被晒焦，又因没有根，就枯干了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 4:18–19; 耶利米书 4:3–4; 创世记 3:18"> <span className="woj">有些落在荆棘里，荆棘长起来，把它们挤住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 13:23; 路加福音 8:15; 创世记 26:12"> <span className="woj">还有些落在好土里，就结出果实，有一百倍的，有六十倍的，有三十倍的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:11; 马太福音 11:15; 启示录 2:7"> <span className="woj">有耳可听的，就应当听。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 4:33–34; 马可福音 4:10"> 门徒进前来，对祂说：“你为什么用比喻对他们说话？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:9–10; 哥林多前书 2:14; 马太福音 19:11"> 祂回答他们说：<span className="woj">“天国的奥秘，只给你们知道，却不给他们知道。</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:29; 马可福音 4:24–25; 路加福音 8:18"> <span className="woj">因为凡有的，还要给他，使他有余；凡没有的，连他所有的也要夺去。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西结 12:2; 耶利米书 5:21; 以赛亚书 42:18–20"> <span className="woj">所以我用比喻对他们说话，是因为他们看也看不见，听也听不见，也不明白。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 6:9–10; 以西结 12:2; 哥林多后书 3:14"> <span className="woj">在他们身上，正应验了以赛亚的预言，说：</span><br /><span className="pl pl-1 woj">‘你们听是要听见，</span><br /><span className="pl pl-2 woj">却绝不明白；</span><br /><span className="pl pl-1 woj">看是要看见，</span><br /><span className="pl pl-2 woj">却绝不领悟；</span></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 6:10; 马可福音 4:12; 撒迦利亚书 7:11"> <span className="pl pl-1 woj">因为这百姓的心已经迟钝，</span><br /><span className="pl pl-2 woj">耳朵发沉，</span><br /><span className="pl pl-2 woj">眼睛闭上；</span><br /><span className="pl pl-1 woj">恐怕他们眼睛看见，</span><br /><span className="pl pl-2 woj">耳朵听见，</span><br /><span className="pl pl-2 woj">心里明白，</span><br /><span className="pl pl-1 woj">就回转过来，</span><br /><span className="pl pl-2 woj">我便医治他们。’</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:23–24; 以弗所书 1:17–18; 马太福音 16:17"> <span className="woj">“但你们的眼睛是有福的，因为看见了；你们的耳朵也是有福的，因为听见了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:56; 希伯来书 11:13; 彼得前书 1:10–12"> <span className="woj">我实在告诉你们，许多先知和义人想要看你们所看见的，却没有看见；想要听你们所听见的，却没有听见。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:11–12; 路加福音 8:11–15; 马可福音 4:13–20"> <span className="woj">“所以，你们要听这撒种之人的比喻。</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 8:11–15; 马太福音 13:38; 希伯来书 2:1"> <span className="woj">凡听见天国的道却不明白的，那恶者就来，把撒在他心里的夺去；这就是撒在路旁的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以西结 33:31–32; 诗篇 106:12–13; 约翰福音 5:35"> <span className="woj">撒在石头地上的，就是人听了道，立刻欢喜领受；</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 11:6; 彼得后书 1:8–9; 以弗所书 3:17"> <span className="woj">只是他心里没有根，不过暂时忍耐；一遇见因这道而来的患难或迫害，立刻就跌倒。</span></span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 6:17; 路加福音 8:14; 提摩太前书 6:9–10"> <span className="woj">撒在荆棘里的，就是人听了道，后来今世的忧虑和财富的迷惑把道挤住了，他就结不出果实。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 1:11; 马太福音 12:33; 约翰福音 15:16"> <span className="woj">撒在好土里的，就是人听了道，又明白了，必然结果实，有一百倍的，有六十倍的，有三十倍的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 25:1; 马太福音 13:47; 马太福音 20:1"> 耶稣又设另一个比喻给他们，说：<span className="woj">“天国好像一个人在自己的田里撒了好种。</span></span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 5:8; 彼得后书 2:1; 使徒行传 20:30–31"> <span className="woj">人睡觉的时候，他的仇敌来，把毒麦</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="毒麦是一种类似麦子的杂草，成熟前很像小麦，成熟后差别才明显。">a</a></sup><span className="woj">撒在麦子中间，就走了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 4:26–29"> <span className="woj">到发苗吐穗的时候，毒麦也显出来了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 16:17; 哥林多后书 6:1; 哥林多后书 5:18–20"> <span className="woj">家主的仆人来对他说：‘主啊，你不是在田里撒了好种吗？这些毒麦是从哪里来的呢？’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 5:3–7; 帖撒罗尼迦前书 5:14; 路加福音 9:49–54"> <span className="woj">“他说：‘这是仇敌做的。’</span><br /><span className="woj">“仆人问他说：‘你要我们去把它们拔出来吗？’</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> <span className="woj">“他说：‘不必，恐怕你们拔毒麦的时候，连麦子也一起连根拔出来。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 3:12; 提摩太前书 5:24; 哥林多前书 4:5"> <span className="woj">让两样一同长，直到收割。收割的时候，我要对收割的人说：先把毒麦拔出来，捆成捆，好烧掉；但要把麦子收进我的仓里。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 13:18–19; 马太福音 17:20; 马可福音 4:30–32"> 耶稣又设另一个比喻给他们，说：<span className="woj">“天国好像一粒芥菜种，有人拿去撒在自己的田里。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以西结 31:6; 但以理 4:12; 以西结 17:23–24"> <span className="woj">它本是百种中最小的；长起来以后，却比各样蔬菜都大，成了一棵树，甚至天上的飞鸟来宿在它的枝上。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="加拉太书 5:9; 哥林多前书 5:6–7; 路加福音 13:21"> 祂又对他们讲另一个比喻：<span className="woj">“天国好像面酵，有妇人拿来藏在三斗</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="直译为“三撒特”。三撒特约为三十九升，略多于一蒲式耳。">b</a></sup><span className="woj">面里，直到全团都发起来。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:33–34; 约翰福音 16:25; 马太福音 13:13"> 耶稣用比喻把这一切话对众人说；若不用比喻，祂就不对他们说话，</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 78:2; 以弗所书 3:9; 彼得前书 1:20–21"> 这是要应验先知所说的话：<br /><span className="pl pl-1">“我要开口用比喻；</span><br /><span className="pl pl-2">我要说出创世以来隐藏的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约翰福音 16:17–20; 马太福音 13:11; 马太福音 9:28"> 于是耶稣离开众人，进了屋子。祂的门徒来到祂面前，说：“请把田间毒麦的比喻给我们讲明白。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 3:5–7; 马太福音 13:41; 路加福音 10:16"> 祂回答说：<span className="woj">“撒好种的就是人子；</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:44; 腓立比书 3:18–19; 使徒行传 13:10"> <span className="woj">田地就是世界；好种就是天国之子；毒麦就是那恶者之子；</span></span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 13:49; 启示录 14:15–19; 马太福音 25:31"> <span className="woj">撒毒麦的仇敌就是魔鬼；收割的时候就是这世代的末了；收割的人就是天使。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 13:39"> <span className="woj">所以，毒麦怎样被拔出来，用火焚烧，这世代末了的时候也要这样。</span></span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 24:31; 马太福音 18:7; 彼得后书 2:1–2"> <span className="woj">人子要差遣祂的天使，从祂的国里把一切使人跌倒的事和作恶的人都挑出来，</span></span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:50; 路加福音 16:23–24; 马太福音 8:12"> <span className="woj">丢进火炉里；在那里必要哀哭切齿。</span></span>
<span className="v" id="v43" data-v="43" data-xref="但以理 12:3; 马太福音 11:15; 路加福音 12:32"> <span className="woj">那时，义人在他们父的国里，要像太阳一样发光。有耳可听的，就应当听。</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; 歌罗西书 2:3; 腓立比书 3:7–9"> <span className="woj">“天国又好像藏在田里的宝贝，有人发现了，就把它藏起来，欢欢喜喜地去变卖他一切所有的，买了那块田。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; 马太福音 16:26; 马太福音 13:24"> <span className="woj">“天国又好像一个商人寻找贵重的珍珠；</span></span>
<span className="v" id="v46" data-v="46" data-xref="以弗所书 3:8; 路加福音 18:28–30; 箴言 2:4"> <span className="woj">找到一颗价值极高的珍珠，就去变卖他一切所有的，买了它。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="约翰福音 15:6; 提摩太后书 3:2–5; 马太福音 22:9–10"> <span className="woj">“天国又好像网撒在海里，聚拢各样的鱼。</span></span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 13:30; 马太福音 13:40–43; 马太福音 3:12"> <span className="woj">网满了，人就拉上岸来，坐下，把好的收在器具里，不好的丢掉。</span></span>
<span className="v" id="v49" data-v="49" data-xref="启示录 20:12–15; 马太福音 24:31; 马太福音 13:39"> <span className="woj">世界的末了</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“世代的末了”。">c</a></sup><span className="woj">也要这样：天使要出来，把恶人从义人中分别出来，</span></span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 13:42; 马太福音 8:12; 启示录 14:10–11"> <span className="woj">丢进火炉里；在那里必要哀哭切齿。”</span></span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 13:19; 马太福音 13:11; 马可福音 4:34"> 耶稣对他们说：<span className="woj">“这一切你们都明白了吗？”</span><br />他们回答祂说：“主啊，明白了。”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="约翰一书 2:7–8; 提摩太后书 3:16–17; 提多书 1:9"> 祂对他们说：<span className="woj">“所以，每一个受教作天国门徒的文士，好像一个家主，从他的库里拿出新旧的东西来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="马太福音 7:28; 马可福音 4:33–35"> 耶稣讲完这些比喻，就离开那里。</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 7:28; 约翰福音 7:15–16; 马可福音 6:1–6"> 祂来到自己的家乡，在他们的会堂里教导他们，以致他们惊奇，说：“这个人从哪里得来这样的智慧和这些异能呢？</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 6:42; 马可福音 6:3; 路加福音 3:23"> 这不是木匠的儿子吗？祂母亲不是叫马利亚吗？祂的兄弟不是雅各、约西、西门和犹大<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作“犹达”。">d</a></sup>吗？</span>
<span className="v" id="v56" data-v="56"> 祂的姐妹们不也都在我们这里吗？这个人从哪里得来这一切呢？”</span>
<span className="v" id="v57" data-v="57" data-xref="约翰福音 4:44; 马太福音 11:6; 路加福音 4:24"> 他们就因祂跌倒。<br />但耶稣对他们说：<span className="woj">“先知除了在自己的家乡和本家之外，没有不受尊敬的。”</span></span>
<span className="v" id="v58" data-v="58" data-xref="马可福音 6:5–6; 罗马书 11:20; 希伯来书 3:12–19"> 祂因为他们不信，就不在那里多行异能。</span>
</div>

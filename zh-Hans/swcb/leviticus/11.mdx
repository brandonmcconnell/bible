<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="11" data-verses="47">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:11; 利未记 11:11; 希伯来书 9:10"> “你们要对以色列人说：‘地上一切走兽中，你们可以吃的活物如下：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多后书 6:17; 申命记 6:6–7"> 凡走兽中分蹄，蹄完全裂开，并且反刍的，你们都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> “‘但在反刍的或分蹄的走兽中，以下这些你们不可吃：骆驼，因为它反刍，却不分蹄，对你们是不洁净的。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:18; 箴言 30:26; 马太福音 7:26"> 蹄兔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作岩獾，或作岩兔">a</a></sup>，因为它反刍，却不分蹄，对你们是不洁净的。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:7"> 野兔，因为它反刍，却不分蹄，对你们是不洁净的。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 66:17; 以赛亚书 65:4; 以赛亚书 66:3"> 猪，因为它分蹄，蹄完全裂开，却不反刍，对你们是不洁净的。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 52:11; 歌罗西书 2:16; 希伯来书 9:10"> 它们的肉，你们不可吃；它们的尸体，你们不可触摸。它们对你们是不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 5:6; 雅各书 2:18; 使徒行传 20:21"> “‘水中之物，你们可以吃的如下：凡在水里、海里、河里，有鳍有鳞的，你们都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未记 7:18; 诗篇 139:21–22"> 凡在海里、河里，没有鳍和鳞的，无论是在水中群游的，还是水中一切有生命的活物，对你们都是可憎之物；</span>
<span className="v" id="v11" data-v="11"> 你们要把它们视为可憎。它们的肉，你们不可吃；它们的尸体，你们要视为可憎。</span>
<span className="v" id="v12" data-v="12"> 凡水中没有鳍和鳞的，对你们都是可憎之物。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约伯记 39:27–30; 耶利米书 4:22; 提多书 3:3"> “‘飞鸟中，你们要把以下这些视为可憎；它们不可吃，因为是可憎之物：鹰、秃鹫、黑兀鹫、</span>
<span className="v" id="v14" data-v="14"> 鸢、各类黑鸢、</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王纪上 17:6; 箴言 30:17"> 各类乌鸦、</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 34:11–15; 以弗所书 5:7–11; 以弗所书 2:2–3"> 角鸮、鸣鸮、海鸥、各类鹰隼、</span>
<span className="v" id="v17" data-v="17"> 小鸮、鸬鹚、大鸮、</span>
<span className="v" id="v18" data-v="18"> 白鸮、沙漠鸮、鱼鹰、</span>
<span className="v" id="v19" data-v="19"> 鹳、各类鹭鸶、戴胜和蝙蝠。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:10; 腓立比书 3:18–19; 利未记 11:23"> “‘凡有翅膀、用四足爬行的昆虫，对你们都是可憎之物。</span>
<span className="v" id="v21" data-v="21"> 只是有翅膀、用四足行走的爬物中，那些有长而带关节的腿、能在地上跳跃的，你们可以吃。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 3:4; 马可福音 1:6; 出埃及记 10:4–5"> 其中你们可以吃的有：各类蝗虫、各类螽斯、各类蟋蟀和各类蚱蜢。</span>
<span className="v" id="v23" data-v="23"> 但凡有翅膀、有四只脚的爬物，对你们都是可憎之物。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:33; 以弗所书 2:1–3; 哥林多后书 6:17"> “‘因这些，你们会成为不洁净：凡触摸它们尸体的，必不洁净到晚上。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:5; 利未记 14:8; 民数记 31:24"> 凡搬运它们尸体任何部分的，必须洗自己的衣服，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> “‘凡走兽分蹄却没有完全裂开，或不反刍的，对你们是不洁净的；凡触摸它们的，必不洁净。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 11:23; 利未记 11:20"> 四足行走的动物中，凡用爪行走的，对你们是不洁净的；凡触摸它们尸体的，必不洁净到晚上。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:24–25"> 搬运它们尸体的人，必须洗自己的衣服，并且不洁净到晚上。它们对你们是不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="利未记 11:41–42; 提摩太后书 3:2–5; 诗篇 10:3"> “‘在地上爬行的爬物中，以下这些对你们是不洁净的：鼬鼠、老鼠、各类大蜥蜴、</span>
<span className="v" id="v30" data-v="30"> 壁虎、巨蜥、壁蜥、石龙子和变色龙。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 11:24–25; 利未记 11:8"> 在一切爬物中，这些对你们是不洁净的；它们死后，凡触摸它们的，必不洁净到晚上。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 15:12; 提多书 3:5; 提多书 2:14"> 它们死后落在什么东西上，那东西就不洁净；无论是木器、衣服、皮革、麻袋，或任何作工用的器具，都必须放进水里，并且不洁净到晚上；然后才洁净。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 6:28; 利未记 15:12; 利未记 14:45"> 若有任何一种掉进瓦器里，器里所有的东西都不洁净；你们要把那器皿打碎。</span>
<span className="v" id="v34" data-v="34" data-xref="提多书 1:15; 箴言 21:4; 箴言 21:27"> 凡可吃的食物，若被水浸过，就不洁净；凡可喝的饮料，若在这样的器皿里，也不洁净。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 15:12; 利未记 6:28; 利未记 11:33"> 它们尸体的一部分落在什么东西上，那东西就不洁净；无论是烤炉，或锅灶，都要打碎。它们是不洁净的，对你们也必是不洁净的。</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 13:1; 约翰福音 4:14"> 然而泉源或聚水的池子仍是洁净的；只是触碰到它们尸体的，就不洁净。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:37; 彼得前书 1:23; 约翰一书 5:18"> 它们尸体的一部分若落在要播种的种子上，种子仍是洁净的。</span>
<span className="v" id="v38" data-v="38"> 但若水已经浇在种子上，而它们尸体的一部分落在上面，对你们就是不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="利未记 11:40; 利未记 11:24; 利未记 15:7"> “‘你们可以吃的动物若死了，触摸它尸体的人必不洁净到晚上。</span>
<span className="v" id="v40" data-v="40" data-xref="利未记 22:8; 以西结 44:31; 申命记 14:21"> 吃了它尸体的人，必须洗自己的衣服，并且不洁净到晚上；搬运它尸体的人，也必须洗自己的衣服，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="利未记 11:29; 利未记 11:20; 利未记 11:23"> “‘凡在地上爬行的爬物都是可憎之物，不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多书 1:12; 以赛亚书 65:25; 哥林多后书 11:3"> 凡用肚腹爬行的、凡用四足行走的，或凡有许多脚的，就是一切在地上爬行的爬物，你们都不可吃，因为它们是可憎之物。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 20:25; 利未记 11:41–42"> 你们不可因任何爬行的爬物使自己成为可憎；你们不可因它们使自己不洁净，以致被它们玷污。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 20:2; 彼得前书 1:15–16; 利未记 19:2"> 因为我是耶和华你们的上帝。所以你们要使自己分别为圣，并且要圣洁，因为我是圣洁的。你们不可因任何在地上活动的爬物玷污自己。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 11:44; 出埃及记 20:2; 出埃及记 6:7"> 因为我是耶和华，是把你们从埃及地领上来、要作你们上帝的。所以你们要圣洁，因为我是圣洁的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未记 14:54; 利未记 15:32; 以西结 43:12"> “‘这是关于走兽、飞鸟、水中一切活动的活物，以及地上一切爬行之物的律法，</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 10:10; 以西结 44:23; 罗马书 14:13–23"> 为要分别不洁净的和洁净的，也分别可吃的活物和不可吃的活物。’”</span>
</div>
</div>

</div>

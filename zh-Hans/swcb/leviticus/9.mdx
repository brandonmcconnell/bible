<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 28:1; 以西结 43:26–27; 利未记 15:14"> 到了第八天，摩西召了亚伦和他的儿子们，以及以色列的长老；</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 4:3; 希伯来书 10:10–14; 利未记 8:14"> 他对亚伦说：“你要从牛群中取一只公牛犊作赎罪祭，一只公绵羊作燔祭，都要没有残疾，献在耶和华面前。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 6:17; 启示录 5:9; 提多书 2:14"> 你要告诉以色列人说：‘你们要取一只公山羊作赎罪祭；又取一只牛犊和一只绵羊羔，都要一岁、没有残疾，作燔祭；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:43; 以西结 43:2; 利未记 9:23"> 又取一头公牛和一只公绵羊作平安祭，献在耶和华面前；并取调了油的素祭；因为今天耶和华要向你们显现。’”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2–3; 出埃及记 19:17; 尼希米记 8:1"> 他们把摩西所吩咐的带到会幕前。全会众都近前来，站在耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 9:23; 以西结 43:2; 出埃及记 24:16"> 摩西说：“这就是耶和华吩咐你们要做的事；耶和华的荣耀必向你们显现。”</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 5:3; 希伯来书 5:1; 利未记 4:3"> 摩西对亚伦说：“你要近前到祭坛那里，献上你的赎罪祭和燔祭，为自己和百姓赎罪；又要献上百姓的供物，为他们赎罪，照耶和华所吩咐的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 4:1–12; 利未记 1:4–5; 利未记 4:29"> 于是亚伦近前到祭坛那里，宰了为自己作赎罪祭的牛犊。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 4:6–7; 利未记 8:15; 利未记 4:25"> 亚伦的儿子们把血递给他；他把指头蘸在血中，抹在祭坛的角上，又把血倒在祭坛的底部。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 8:16–17; 箴言 23:26; 利未记 3:9–11"> 只是赎罪祭的脂肪、两个肾和肝上的网膜，他都烧在祭坛上，照耶和华吩咐摩西的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 8:17; 利未记 4:11–12; 利未记 16:27–28"> 肉和皮，他用火烧在营外。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:2; 以弗所书 5:25–27; 利未记 1:1–17"> 他宰了燔祭；亚伦的儿子们把血递给他，他就把血洒在祭坛四周。</span>
<span className="v" id="v13" data-v="13"> 他们把燔祭一块一块地连同头递给他，他就把这些烧在祭坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 8:21"> 他洗了内脏和腿，把它们烧在祭坛上的燔祭上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 4:27–31; 希伯来书 5:3; 利未记 9:3"> 他献上百姓的供物，取了那为百姓作赎罪祭的山羊，宰了它，献为赎罪祭，像先前一样。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 9:12–14; 利未记 8:18–21; 希伯来书 10:1–22"> 他献上燔祭，照条例献了。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:1–2; 约翰福音 6:53; 利未记 9:1"> 他献上素祭，从其中取满一把，烧在祭坛上；这是在早晨的燔祭以外献的。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20; 罗马书 5:1; 以弗所书 2:14–17"> 他又宰了为百姓作平安祭牲的公牛和公绵羊。亚伦的儿子们把血递给他，他就把血洒在祭坛四周；</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 3:16; 利未记 9:10; 利未记 3:9"> 又把公牛和公绵羊的脂肪、肥尾巴、遮盖内脏的脂肪、两个肾和肝上的网膜递给他；</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 3:14–17; 利未记 7:29–34"> 他们把脂肪放在胸上，他就把脂肪烧在祭坛上。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 7:30–34; 利未记 7:24; 出埃及记 29:24"> 亚伦把胸和右腿在耶和华面前摇一摇，作摇祭，照摩西所吩咐的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 21:5; 路加福音 24:50; 民数记 6:23–27"> 亚伦向百姓举手，为他们祝福；他献完赎罪祭、燔祭和平安祭，就下来了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="利未记 9:6; 民数记 16:19; 路加福音 1:21–22"> 摩西和亚伦进入会幕，又出来，为百姓祝福；耶和华的荣耀向全体百姓显现。</span>
<span className="v" id="v24" data-v="24" data-xref="士师记 6:21; 列王纪上 18:38–39; 历代志上 21:26"> 有火从耶和华面前出来，吞灭了祭坛上的燔祭和脂肪。全体百姓看见了，就欢呼，俯伏在地。</span>
</div>

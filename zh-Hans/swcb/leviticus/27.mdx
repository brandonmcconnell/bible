<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="27" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:2; 撒母耳记上 1:28; 士师记 11:30–31"> “你要吩咐以色列子孙，对他们说：‘人许特别的愿，把人按你所估的价值献给耶和华时，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:13; 利未记 27:25; 民数记 18:16"> 你对二十岁到六十岁的男子所估的价值，要按圣所的舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司。">a</a></sup>，为五十舍客勒银子。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 27:9–10; 撒迦利亚书 11:12–13; 马太福音 26:15"> 如果是女子，你所估的价值要为三十舍客勒。</span>
<span className="v" id="v5" data-v="5"> 如果那人是五岁到二十岁，你所估的价值，男子要为二十舍客勒，女子为十舍客勒。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:40–43; 民数记 18:14–16"> 如果那人是一个月到五岁，你所估的价值，男子要为五舍客勒银子，女子要为三舍客勒银子。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 90:10"> 如果那人是六十岁以上；若是男子，你所估的价值要为十五舍客勒；女子为十舍客勒。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:7; 利未记 14:21–22; 路加福音 21:1–4"> 但如果他贫穷，付不起你所估的价值，就要把他带到祭司面前，祭司要为他估价。祭司要按他所能支付的为他估价。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “‘如果是人献给耶和华作供物的牲畜，凡人把这样的牲畜献给耶和华的，都成为圣。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 27:15–33; 雅各书 1:8"> 他不可更换，也不可交换，或拿好的换坏的，或拿坏的换好的。如果他竟以牲畜换牲畜，那么原牲畜和所换来的都要成为圣。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 23:18; 玛拉基书 1:14"> 如果是任何不洁净的牲畜，是不可献给耶和华作供物的，他就要把那牲畜安置在祭司面前；</span>
<span className="v" id="v12" data-v="12"> 祭司要估定它的价值，无论是好是坏。祭司怎样估定，就怎样成立。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:19; 利未记 27:15; 利未记 22:14"> 但如果他一定要赎回它，就要在你所估的价值上加五分之一。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 18:14; 利未记 25:29–31; 利未记 27:21"> “‘人把自己的房屋分别为圣献给耶和华时，祭司要估定它的价值，无论是好是坏。祭司怎样估定，就照样成立。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:13"> 如果献房屋的人要赎回自己的房屋，就要在你所估价的钱上加五分之一，房屋就归他。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结 45:11–14; 何西阿 3:2; 使徒行传 4:34–37"> “‘如果人把自己承受为业的田地的一部分分别为圣献给耶和华，你所估的价值要按所需种子来定。一贺梅珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一贺梅珥约为220升，或6蒲式耳。">b</a></sup>大麦种子所播种的田地，要估价为五十舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约为10克，或约0.35盎司。">c</a></sup>银子。</span>
<span className="v" id="v17" data-v="17"> 如果他从禧年起把田地分别为圣献上，就要按你所估的价值成立。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 25:15–16; 利未记 25:51–52; 利未记 25:27"> 但如果他在禧年以后把田地分别为圣献上，祭司就要按距离禧年所剩的年数给他计算价钱，并且要从你所估的价值中扣减。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 27:13"> 如果把田地分别为圣献上的人一定要赎回田地，就要在你所估价的钱上加五分之一，田地仍归他。</span>
<span className="v" id="v20" data-v="20"> 如果他不赎回那田地，或是已经把那田地卖给别人，就不可再赎回；</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 44:29; 民数记 18:14; 利未记 25:31"> 但那田地到禧年得释放时，要成为圣归耶和华，像永献的田地一样；它要归祭司为业。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 25:10; 利未记 25:25"> “‘如果他把买来的田地，就是不属于他承受为业之田地的，分别为圣献给耶和华，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 27:18; 利未记 27:12"> 祭司就要为他计算到禧年为止你所估价值的数额；他要在那一天交出你所估的价值，作为归耶和华的圣物。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 25:28; 利未记 27:20"> 到了禧年，田地要归还给卖主，就是归还给那承受此地为业的人。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:13; 民数记 18:16; 民数记 3:47"> 你们一切估价都要按圣所的舍客勒：二十季拉<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一季拉约为0.5克，或约7.7格令。">d</a></sup>为一舍客勒。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一舍客勒约为10克，或约0.35盎司。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:2; 出埃及记 13:12–13; 民数记 18:17"> “‘但是牲畜中头生的，既然作为头生的归耶和华，谁也不可再把它分别为圣；无论是牛是羊，都是耶和华的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 27:11"> 如果是不洁净的牲畜，他就要按你所估的价值把它赎回，并加上五分之一；若不赎回，就要按你所估的价值卖掉。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:17–19; 利未记 27:21; 出埃及记 22:20"> “‘然而，人从自己一切所有中永献给耶和华的任何永献之物，无论是人，是牲畜，或是他承受为业的田地，都不可出售，也不可赎回。凡永献的，都归耶和华为至圣。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:18–23; 民数记 21:2–3"> “‘凡从人中被定为当灭的人，都不可赎；他必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 23:23; 尼希米记 13:12; 创世记 28:22"> “‘地上一切的十分之一，无论是地的种子，还是树上的果子，都是耶和华的；是归耶和华为圣的。</span>
<span className="v" id="v31" data-v="31"> 如果有人要赎回他十分之一中的任何一部分，就要加上五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 33:13; 以西结 20:37; 弥迦书 7:14"> 凡牛群或羊群中的十分之一，就是从杖下经过的，每第十只都要归耶和华为圣。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 27:10"> 他不可查看是好是坏，也不可更换。如果他竟更换，那么原来的和所换来的都要成为圣，不可赎回。’”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="利未记 26:46; 民数记 1:1; 希伯来书 12:18–25"> 这些就是耶和华在西奈山为以色列子孙吩咐摩西的诫命。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:14–18; 利未记 9:17; 以赛亚书 66:20"> “‘若有人向耶和华献素祭为供物，他的供物要用细面。他要把油浇在上面，并把乳香放在上面。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 5:12; 利未记 6:15; 使徒行传 10:4"> 他要把供物带到亚伦的子孙作祭司的那里。祭司要从细面和油中取满一把，连同全部乳香，把这作为记念的部分烧在坛上；这是火祭，是献给耶和华的馨香。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 10:12–13; 民数记 18:9; 利未记 21:22"> 素祭所剩下的要归给亚伦和他的子孙；这是献给耶和华的火祭中至圣的部分。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:2; 哥林多前书 5:7–8; 诗篇 22:14"> “‘你若献在炉中烤的素祭为供物，就要用调油的细面无酵饼，或抹油的无酵薄饼。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:21; 利未记 7:9"> 你的供物若是在铁盘上做的素祭，就要用调油的无酵细面。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:1–19; 诗篇 22:1–21; 马可福音 14:1–15"> 你要把它切成块子，把油浇在上面；这是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:1–2; 利未记 7:9"> 你的供物若是在锅里做的素祭，就要用细面加油做成。</span>
<span className="v" id="v8" data-v="8"> 你要把用这些东西做成的素祭带到耶和华面前，交给祭司；祭司要把它带到坛前。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:2; 腓立比书 4:18; 利未记 6:15"> 祭司要从素祭中取出作为记念的部分，烧在坛上；这是火祭，是献给耶和华的馨香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 2:3"> 素祭所剩下的要归给亚伦和他的子孙；这是献给耶和华的火祭中至圣的部分。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 5:9; 路加福音 12:1; 出埃及记 23:18"> “‘你们献给耶和华的任何素祭都不可用酵做成；因为你们不可把任何酵或任何蜜当作火祭献给耶和华焚烧。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:19; 创世记 23:10–11; 出埃及记 22:29"> 作为初熟之物的供物，你们可以把它们献给耶和华，但它们不可在坛上升为馨香。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 43:24; 马太福音 5:13; 歌罗西书 4:6"> 你献的每一份素祭供物都要用盐调和。不可让你上帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译为“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">a</a></sup>之约的盐从你的素祭中缺少。你献的一切供物都要献上盐。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 23:10; 玛拉基书 1:11; 民数记 28:2"> “‘你若向耶和华献初熟之物的素祭，就要为你初熟之物的素祭献上用火烘过并轧碎的新鲜谷穗。</span>
<span className="v" id="v15" data-v="15"> 你要把油放在上面，又把乳香放在上面；这是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 5:7; 罗马书 8:26–27; 以赛亚书 61:1"> 祭司要把其中轧碎的谷物一部分和油一部分，连同全部乳香，焚烧作为记念的部分；这是献给耶和华的火祭。</span>
</div>

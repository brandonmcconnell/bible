<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="24" data-verses="23">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 4:6; 以弗所书 5:8–14; 出埃及记 27:20–21"> “你要吩咐以色列人，把捣成的清橄榄油拿来给你，用来点灯，使灯常常燃着。</span>
<span className="v" id="v3" data-v="3"> 在会幕中法柜幔子外，亚伦要从晚上到早晨，在耶和华面前常常照管这灯。这要作你们世世代代永远的律例。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 31:8; 出埃及记 37:17–24; 出埃及记 39:37"> 他要在耶和华面前常常照管纯金灯台上的灯盏。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:30; 列王纪上 18:31; 出埃及记 40:23"> “你要取细面，烤成十二个饼；每个饼要用十分之二伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一伊法约为22升，或约为三分之二蒲式耳">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:48; 出埃及记 25:23–24; 历代志下 4:19"> 你要把这些饼摆成两行，每行六个，放在耶和华面前的纯金桌子上。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:2; 启示录 8:3–4; 创世记 9:16"> 你要把纯乳香放在每一行上，使乳香作为饼的记念，就是献给耶和华的火祭。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 2:4; 民数记 4:7; 历代志上 9:32"> 每逢安息日，他要常常把这些饼摆在耶和华面前；这是为以色列人所立的永约。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 8:31; 路加福音 6:4; 马可福音 2:26"> 这些饼要归给亚伦和他的儿子。他们要在圣处吃，因为这是耶和华的火祭中归给他的至圣之物，作为永久的律例。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 11:4; 出埃及记 12:38"> 有一个以色列妇人的儿子，他的父亲是埃及人；他出去到以色列人中间，在营里与一个以色列人争斗。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 24:15–16; 出埃及记 3:15"> 这以色列妇人的儿子亵渎了圣名，并且咒诅；他们就把他带到摩西那里。他母亲名叫示罗密，是但支派底伯利的女儿。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 18:15–16; 民数记 15:34; 民数记 27:5"> 他们把他关押起来，直到耶和华的旨意向他们说明。</span>
<span className="v" id="v13" data-v="13"> 耶和华对摩西说：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:7; 利未记 20:27; 申命记 21:21"> “把那咒诅的人带到营外；凡听见的人都要按手在他头上，全会众要用石头打死他。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:13; 出埃及记 22:28; 利未记 5:1"> 你要告诉以色列人说：‘凡咒诅自己上帝的，必担当自己的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 12:31; 雅各书 2:7; 约翰福音 10:33–36"> 亵渎耶和华之名的，必须被处死；全会众必用石头打死他。无论是寄居者还是本地人，亵渎圣名的时候，都必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 9:5–6; 申命记 19:11–12; 申命记 27:24"> “‘凡击打任何人以致死亡的，必须被处死。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 24:21; 出埃及记 21:34–36"> 凡击打牲畜以致死亡的，必须赔偿，命偿命。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:38; 马太福音 7:2; 申命记 19:21"> 如果有人伤害他的邻舍，他怎样做，也要怎样待他：</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 19:21; 马太福音 5:38; 出埃及记 21:23–25"> 骨折还骨折，眼还眼，牙还牙。他怎样伤害人，也要怎样加在他身上。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 24:17–18; 出埃及记 21:33"> 杀死牲畜的，必须赔偿；杀人的，必须被处死。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:49; 民数记 15:15–16; 民数记 9:14"> 你们对寄居者和本地人，要有同一种律法；因为我是耶和华你们的上帝。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 10:28–29; 希伯来书 2:2–3; 民数记 15:35–36"> 摩西告诉以色列人；他们就把那咒诅的人带到营外，用石头打死他。以色列人照耶和华吩咐摩西的做了。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 19:4; 申命记 27:15; 民数记 33:52"> “『你们不可为自己制造偶像，不可立雕刻的像或柱像，也不可在你们的地上安置刻有图像的石头，向它跪拜；因为我是耶和华你们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="利未记 19:30"> 『你们要守我的安息日，敬畏我的圣所。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:19; 申命记 11:13–15; 申命记 28:1–14"> 『你们若遵行我的律例，谨守我的诫命，并且实行，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 8:12; 诗篇 67:6; 利未记 25:21"> 我就按时赐雨给你们，土地必出产土产，田野的树木必结果子。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司 9:13; 约珥 2:26; 约珥 2:19"> 你们打粮要延续到收葡萄的时候，收葡萄要延续到撒种的时候。你们要吃饱自己的粮食，在你们的地上安然居住。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 35:9; 西番雅书 3:13; 诗篇 147:14"> 『我要赐平安在这地上；你们躺卧，无人使你们惧怕。我要从这地除去恶兽，刀剑也必不经过你们的地。</span>
<span className="v" id="v7" data-v="7"> 你们要追赶仇敌，他们必在你们面前倒在刀下。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 23:10; 申命记 28:7; 申命记 32:30"> 你们五个人要追赶一百人，一百人要追赶一万人；你们的仇敌必在你们面前倒在刀下。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 17:6–7; 尼希米记 9:23; 以西结 16:62"> 『我要眷顾你们，使你们多结果子，使你们增多，也要坚立我与你们所立的约。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:22; 列王纪下 19:29; 路加福音 12:17"> 你们要吃久存的陈粮，又要因有新粮而搬出陈粮。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:8; 启示录 21:3; 出埃及记 29:45"> 我要把我的帐幕设在你们中间；我的心必不厌恶你们。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 6:16; 耶利米书 30:22; 耶利米书 7:23"> 我要行走在你们中间，作你们的上帝；你们也要作我的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 34:27; 利未记 25:38; 诗篇 116:16"> 我是耶和华你们的上帝，曾把你们从埃及地领出来，使你们不再作他们的奴隶。我折断了你们轭上的横木，使你们挺身行走。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 28:15–68; 利未记 26:18; 耶利米书 17:27"> 『但你们若不听从我，不遵行这一切诫命，</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 17:15; 申命记 31:16; 撒迦利亚书 7:11–13"> 若拒绝我的律例，心里厌恶我的典章，不遵行我一切的诫命，反而背弃我的约，</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:8; 耶利米书 5:17; 弥迦书 6:15"> 我也要这样待你们：我要指定惊恐临到你们，就是肺痨和热病，使眼目衰残，使生命消耗。你们要白白撒种，因为你们的仇敌要吃掉。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 箴言 28:1; 诗篇 53:5"> 我要向你们变脸，你们就要在仇敌面前被击败。恨你们的人要辖制你们；无人追赶，你们也要逃跑。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 26:21; 利未记 26:28; 利未记 26:24"> 『你们若在这些事以后仍不听从我，我就要为你们的罪加七倍惩罚你们。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:23; 列王纪上 17:1; 但以理 4:37"> 我要打碎你们因力量而有的骄傲；我要使你们的天像铁，使你们的地像铜。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 127:1; 申命记 11:17; 以赛亚书 49:4"> 你们的力气要白白耗费，因为你们的地不出产土产，地上的树木也不结果子。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 26:18; 利未记 26:27"> 『你们若与我作对，不肯听从我，我就要照你们的罪加七倍降灾给你们。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 14:15; 申命记 32:24; 士师记 5:6"> 我要使野兽到你们中间；它们要夺去你们的儿女，毁灭你们的牲畜，使你们人数减少。你们的道路要变为荒凉。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 5:3; 耶利米书 2:30; 阿摩司 4:6–12"> 『你们若因这些事仍不归向我，反而与我作对，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 18:26; 撒母耳记下 22:27; 约伯记 9:4"> 我也要与你们作对；我亲自要为你们的罪击打你们七倍。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 14:12; 以西结 5:17; 耶利米书 29:17–18"> 我要使刀剑临到你们，执行约的报复。你们聚集在城内时，我要把瘟疫送到你们中间；你们要被交在仇敌手中。</span>
<span className="v" id="v26" data-v="26" data-xref="弥迦书 6:14; 以赛亚书 3:1; 诗篇 105:16"> 我折断你们粮食的杖时，十个女人要在一个炉子里烤你们的饼，又要按重量把饼交给你们。你们要吃，却不得饱足。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 26:24; 利未记 26:21"> 『你们若虽经这些事仍不听从我，反而与我作对，</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:18; 耶利米书 21:5; 以赛亚书 66:15"> 我就要在烈怒中与你们作对；我也要为你们的罪惩罚你们七倍。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 5:10; 耶利米哀歌 4:10; 马太福音 24:19"> 你们要吃自己儿子的肉，也要吃自己女儿的肉。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 23:20; 以赛亚书 27:9; 以西结 6:13"> 我要毁坏你们的邱坛，砍下你们的香坛，把你们的尸体抛在你们偶像的尸体上；我的心必厌恶你们。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:3; 耶利米哀歌 1:10; 希伯来书 10:26"> 我要使你们的城邑荒废，使你们的圣所荒凉；你们供物的馨香之气，我也不喜悦。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 9:11; 耶利米书 19:8; 耶利米书 18:16"> 我要使这地荒凉，住在其中的仇敌必因此惊骇。</span>
<span className="v" id="v33" data-v="33" data-xref="撒迦利亚书 7:14; 以西结 20:23; 申命记 28:64–66"> 我要把你们分散在列国中，并拔刀追赶你们。你们的地要成为荒凉，你们的城邑要成为废墟。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 36:21; 利未记 26:43; 利未记 25:2–4"> 那时，只要这地荒凉、你们在仇敌之地，这地就要享受它的安息。那时，这地要歇息，享受它的安息。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 24:5–6; 罗马书 8:22"> 只要这地荒凉，就要得享安息，就是你们住在其上时，在你们的安息日中它没有得着的安息。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结 21:7; 以赛亚书 30:17; 利未记 26:17"> 『至于你们中剩下的人，我要在他们仇敌之地使胆怯进入他们心中；被风吹动的叶子响声也要使他们逃跑。他们要逃，如同人躲避刀剑；无人追赶，他们也要跌倒。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 7:12–13; 士师记 2:14; 耶利米书 37:10"> 无人追赶时，他们要彼此绊跌，如同在刀剑面前。你们在仇敌面前必无力站立。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 28:48; 以赛亚书 27:13; 耶利米书 42:17–18"> 你们要在列国中灭亡；你们仇敌的地要吞吃你们。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结 4:17; 以西结 24:23; 以西结 33:10"> 你们中剩下的人要在仇敌之地因自己的罪孽衰残；也要因他们祖先的罪孽，和他们一同衰残。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; 尼希米记 9:2–5; 约翰一书 1:8–10"> 『如果他们承认自己的罪孽和祖先的罪孽，就是他们干犯我所犯的罪，又承认他们与我作对，</span>
<span className="v" id="v41" data-v="41" data-xref="以西结 44:7; 历代志下 32:26; 历代志下 12:6–7"> 我也与他们作对，把他们带到仇敌之地；那时，如果他们未受割礼的心谦卑下来，他们也甘愿领受自己罪孽的刑罚，</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 106:45; 出埃及记 6:5; 以西结 16:60"> 我就要记念我与雅各所立的约，也要记念我与以撒所立的约，又要记念我与亚伯拉罕所立的约；我也要记念这地。</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 8:7; 利未记 26:15; 约翰福音 7:7"> 这地也要被他们离弃；当它离开他们而荒凉的时候，就要享受它的安息。他们也要甘愿领受自己罪孽的刑罚，因为他们拒绝我的典章，心里厌恶我的律例。</span>
<span className="v" id="v44" data-v="44" data-xref="罗马书 11:2; 尼希米记 9:31; 申命记 4:29–31"> 然而，虽是这样，他们在仇敌之地的时候，我必不拒绝他们，也不厌恶他们，以致将他们灭绝、背弃我与他们所立的约；因为我是耶和华他们的上帝。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 25:38; 以西结 20:22; 以西结 20:9"> 但我为了他们的缘故，要记念他们祖先的约；这些祖先是我在列国眼前从埃及地领出来的，为要作他们的上帝。我是耶和华。』”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未记 27:34; 申命记 12:1; 申命记 6:1"> 这些就是耶和华在西奈山借着摩西，在祂自己和以色列子孙之间所立的律例、典章和律法。</span>
</div>

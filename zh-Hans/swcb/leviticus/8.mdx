<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="8" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:2–4; 出埃及记 39:41; 希伯来书 7:27"> “你要带亚伦和他的儿子们同来，又带圣衣、膏油、赎罪祭的公牛、两只公绵羊和一篮无酵饼；</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 30:13; 使徒行传 2:1; 尼希米记 8:1"> 并要召集全会众到会幕门口。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 39:26; 出埃及记 39:7; 出埃及记 39:5"> 摩西照耶和华所吩咐他的行了；会众就聚集在会幕门口。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:4–37"> 摩西对会众说：“这是耶和华吩咐要做的事。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 6:11; 以弗所书 5:26; 出埃及记 29:4"> 摩西带亚伦和他的儿子们来，用水洗他们。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 以赛亚书 61:10; 加拉太书 3:27"> 他给亚伦穿上内袍，给他束上腰带，给他穿上外袍，又给他穿上以弗得，并把以弗得上精工织成的带子系在他身上，用这带子把以弗得系紧。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:63; 帖撒罗尼迦前书 5:8; 以赛亚书 59:17"> 他给亚伦戴上胸牌，又把乌陵和土明放在胸牌里。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 2:9–11; 撒迦利亚书 6:11–14; 出埃及记 28:36–38"> 他把礼冠戴在亚伦头上，又把金牌，就是圣冠，安在礼冠前面，正如耶和华吩咐摩西的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:9–11; 利未记 8:2; 出埃及记 30:23–29"> 摩西拿膏油来，膏抹帐幕和其中所有的一切，使它们分别为圣。</span>
<span className="v" id="v11" data-v="11" data-xref="提多书 3:6; 出埃及记 30:29; 出埃及记 16:19"> 他把膏油在祭坛上弹了七次，又膏抹祭坛和坛的一切器具，以及盆和盆座，使它们分别为圣。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:30; 诗篇 133:2; 出埃及记 29:7"> 他把一些膏油倒在亚伦头上，膏抹他，使他分别为圣。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:8–9; 启示录 5:10; 启示录 1:6"> 摩西带亚伦的儿子们来，给他们穿上内袍，束上腰带，戴上头巾，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结 43:19; 诗篇 66:15; 彼得前书 3:18"> 他牵来赎罪祭的公牛，亚伦和他的儿子们按手在赎罪祭公牛的头上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 4:7; 希伯来书 9:18–23; 以西结 43:19–27"> 他宰了公牛；摩西取血，用手指抹在祭坛四周的角上，净化祭坛，又把血倒在祭坛脚那里，使坛分别为圣，为坛赎罪。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:13; 利未记 3:3–5; 利未记 4:8–9"> 他取了内脏上所有的脂肪、肝上的网子、两个肾和肾上的脂肪；摩西把这些烧在祭坛上。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:11–12; 出埃及记 29:14; 利未记 6:30"> 但是公牛和牛皮、牛肉、牛粪，他都用火烧在营外，正如耶和华吩咐摩西的。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 8:2; 利未记 1:4–13; 出埃及记 29:15–18"> 他献上燔祭的公绵羊；亚伦和他的儿子们按手在公绵羊的头上。</span>
<span className="v" id="v19" data-v="19"> 他宰了公绵羊；摩西把血洒在祭坛四周。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 1:8"> 他把公绵羊切成块；摩西把头、肉块和脂肪都烧了。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 5:2; 出埃及记 29:18; 利未记 1:17"> 他用水洗了内脏和腿；摩西把整只公绵羊烧在祭坛上。这是燔祭，作为悦纳的馨香，是献给耶和华的火祭，正如耶和华吩咐摩西的。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 8:2; 利未记 8:29; 出埃及记 29:19–31"> 他献上另一只公绵羊，就是承接圣职的公绵羊；亚伦和他的儿子们按手在公绵羊的头上。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:20; 利未记 14:14; 罗马书 12:1"> 他宰了公绵羊；摩西取些血，抹在亚伦的右耳垂上、右手的大拇指上、右脚的大脚趾上。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:18–22"> 他带亚伦的儿子们来；摩西把些血抹在他们的右耳垂上、右手的大拇指上、右脚的大脚趾上；摩西又把血洒在祭坛四周。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 3:9; 利未记 3:3–5; 以赛亚书 53:10"> 他取了脂肪、肥尾巴、内脏上所有的脂肪、肝上的网子、两个肾和肾上的脂肪，以及右腿；</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:23; 提摩太前书 2:5; 使徒行传 5:12"> 又从耶和华面前那篮无酵饼中，取一个无酵饼、一个调油的饼和一个薄饼，放在脂肪和右腿上。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:21; 希伯来书 9:14; 出埃及记 29:24–37"> 他把这一切放在亚伦手中和他儿子们手中，在耶和华面前摇一摇，作为摇祭。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 29:25; 诗篇 22:13–14; 希伯来书 10:14–22"> 摩西从他们手中接过来，烧在祭坛的燔祭上。这些是承接圣职的祭，作为悦纳的馨香，是献给耶和华的火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:31; 彼得前书 4:11; 利未记 7:30–34"> 摩西取胸，在耶和华面前摇一摇，作为摇祭。这是承接圣职之公绵羊中归给摩西的份，正如耶和华吩咐摩西的。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 29:21; 民数记 3:3; 出埃及记 30:30"> 摩西取些膏油和祭坛上的血，洒在亚伦和他的衣服上，也洒在他的儿子们和他儿子们的衣服上，使亚伦和他的衣服，以及他的儿子们和他儿子们的衣服，都一同分别为圣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 29:31–32; 加拉太书 2:20; 撒母耳记上 2:13–17"> 摩西对亚伦和他的儿子们说：“你们要在会幕门口煮这肉，并在那里吃这肉和承接圣职篮子里的饼，照我所吩咐的说：‘亚伦和他的儿子们要吃这些。’</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 29:34; 出埃及记 12:10; 希伯来书 3:13–14"> 剩下的肉和饼，你们要用火烧掉。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 29:35; 民数记 19:12; 以西结 43:25–27"> 七天之内，你们不可从会幕门口出去，直到你们承接圣职的日子满了；因为他要使你们承接圣职七天。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:27; 希伯来书 7:16; 希伯来书 10:11–12"> 今天所做的，耶和华也吩咐要照样做，为你们赎罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 3:7; 申命记 11:1; 列王纪上 2:3"> 你们要昼夜七天留在会幕门口，遵守耶和华的吩咐，免得你们死亡；因为我所受的吩咐就是这样。”</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 12:32; 申命记 4:2; 出埃及记 40:16"> 亚伦和他的儿子们行了耶和华借摩西所吩咐的一切事。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="6" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:9; 使徒行传 5:4; 利未记 5:15"> “如果有人犯罪，干犯耶和华，在寄存物、交易、抢夺的事上欺骗邻舍，或欺压邻舍，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:4; 利未记 19:12; 出埃及记 22:9–11"> 或是捡到失物却说谎，并且起假誓——人在这些事中的任何一件上犯罪——</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 18:18; 阿摩司 3:10; 利未记 5:3–4"> 那么，他既犯了罪，又有了罪责，就要归还他所抢夺的，或他欺压所得的，或交托给他的寄存物，或他所捡到的失物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 5:16; 路加福音 19:8; 民数记 5:7–8"> 或任何他起假誓所涉及的东西；他都要如数归还，并且另外加上五分之一。在他被判有罪的日子，要把这些还给物主。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:15; 利未记 5:18; 以赛亚书 53:10–11"> 他要把赎愆祭带到耶和华面前：就是从羊群中取一只没有残疾的公绵羊，按你所估定的价值，作为赎愆祭交给祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 4:26; 约翰一书 1:9; 约翰一书 2:1–2"> 祭司要在耶和华面前为他赎罪；他无论因什么事成了有罪，都必蒙赦免。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华对摩西说：</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 6:12–13; 民数记 28:3; 出埃及记 29:38–42"> “你要吩咐亚伦和他的儿子们说：‘燔祭的律法是这样：燔祭要整夜留在祭坛的炉膛上，直到早晨；坛上的火要在坛上持续燃烧。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:39–43; 利未记 16:4; 利未记 1:13"> 祭司要穿上细麻衣，又要把细麻裤穿在身上；他要把坛上燔祭被火烧尽后留下的灰取出，放在祭坛旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 4:12; 以西结 44:19; 希伯来书 13:11–13"> 然后他要脱下这些衣服，穿上别的衣服，把灰带到营外洁净的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 9:24; 出埃及记 29:38–42; 尼希米记 13:31"> 祭坛上的火要在坛上持续燃烧，不可熄灭；祭司每天早晨要在坛上烧柴，把燔祭摆在火上，又要把平安祭的脂肪烧在其上。</span>
<span className="v" id="v13" data-v="13"> 火要在祭坛上不断燃烧，不可熄灭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 15:4; 利未记 2:1–2; 约翰福音 6:32"> “‘素祭的律法是这样：亚伦的儿子们要在耶和华面前、在祭坛前献上这祭。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:2; 利未记 2:9"> 祭司要从素祭的细面和油中取出一把，并取素祭上所有的乳香，作为这祭的纪念部分，烧在祭坛上，作为献给耶和华的馨香之气。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 44:29; 利未记 2:3; 利未记 10:12–13"> 剩下的，亚伦和他的儿子们要吃；要在圣处不带酵地吃。他们要在会幕的院子里吃。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:3; 利未记 2:11; 民数记 18:9–10"> 不可加酵烤。我已把它赐给他们，作为我火祭中的一份；这是至圣的，正如赎罪祭和赎愆祭一样。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 6:29; 民数记 18:10; 哈该书 2:12–14"> 亚伦子孙中的每一个男子都可以吃这祭；这是你们世世代代从耶和华的火祭中永远得的分。凡触着这些祭物的，都必成为圣。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华对摩西说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:2; 出埃及记 16:36; 利未记 2:1–16"> “亚伦和他的儿子们在受膏的日子，要献给耶和华的供物是这样：细面伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1伊法约等于22升，或约等于2/3蒲式耳。">a</a></sup>十分之一，作为常献的素祭，早晨一半，晚上一半。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 2:5; 利未记 7:9; 历代志上 9:31"> 这祭要用油在煎盘上做成；调和好以后，你要把它带来；要把烤成块的素祭献上，作为献给耶和华的馨香之气。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:22–25; 以赛亚书 53:10; 利未记 8:21"> 在他儿子中接替他受膏的祭司要献上这祭。这是永远的条例；这祭要完全焚烧，献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 2:10; 利未记 6:16–17"> 祭司所献的每一份素祭都要完全焚烧，不可吃。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 耶和华对摩西说：</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:24; 利未记 1:11; 利未记 1:3"> “你要告诉亚伦和他的儿子们说：‘赎罪祭的律法是这样：赎罪祭要在宰杀燔祭的地方，在耶和华面前宰杀；这是至圣的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:17–18; 以西结 44:28–29; 何西阿 4:8"> 为赎罪而献这祭的祭司要吃这祭；要在圣处，就是会幕的院子里吃。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 29:37; 哈该书 2:12; 哥林多后书 7:1"> 凡触着这祭肉的，都必成为圣。若有这祭的血弹在衣服上，你要在圣处洗净那被血弹到的衣服。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:33; 利未记 15:12; 希伯来书 9:9–10"> 煮这祭肉的陶器要打碎；若是在铜器里煮的，就要擦净，并用水冲洗。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 6:25; 利未记 6:17–18; 民数记 18:10"> 祭司中的每一个男子都可以吃这祭；这是至圣的。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 10:18; 利未记 16:27–28; 希伯来书 13:11"> 但是，任何赎罪祭，若有它的血被带进会幕、在圣所里赎罪，就不可吃；必须用火焚烧。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 19:12; 希伯来书 9:7; 利未记 4:27"> “你要告诉以色列子民说：『如果有人无意中犯罪，违犯了耶和华所吩咐不可做的任何事，并做了其中一件，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:27–28; 利未记 4:14; 利未记 9:2"> 如果受膏的祭司犯罪，以致使百姓陷入罪责，他就要为自己所犯的罪，把一头无残疾的公牛献给耶和华作赎罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 1:3–4; 但以理 9:26; 以赛亚书 53:6"> 他要把公牛牵到会幕门口，在耶和华面前；他要按手在公牛的头上，并在耶和华面前宰杀公牛。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:14; 民数记 19:4; 利未记 4:16–17"> 受膏的祭司要取一些公牛的血，带进会幕。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 16:14; 利未记 14:18; 利未记 26:28"> 祭司要用指头蘸血，在耶和华面前，对着圣所的幔子，把一些血弹七次。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 8:15; 利未记 9:9; 利未记 16:18"> 祭司要把一些血抹在会幕内、耶和华面前香坛的角上；又要把公牛其余的血倒在会幕门口燔祭坛的底部。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:3–5; 利未记 4:26; 利未记 4:31"> 他要从赎罪祭的公牛身上取下所有脂肪：覆盖内脏的脂肪，以及内脏上的所有脂肪，</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 3:4"> 两个肾和肾上靠近腰部的脂肪，以及肝叶，都要连同肾一并取下，</span>
<span className="v" id="v10" data-v="10"> 正如从平安祭牲的公牛身上取下一样。祭司要把这些烧在燔祭坛上。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:5; 出埃及记 29:14; 利未记 9:8–11"> 公牛的皮、所有的肉，连同它的头和腿、内脏和粪，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:11; 出埃及记 29:14; 利未记 16:27"> 就是公牛其余的一切，他都要搬到营外倒灰的洁净地方，放在柴上用火焚烧；要在倒灰的地方焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 5:17; 利未记 5:2–5; 何西阿 5:15"> “『如果以色列全会众犯罪，这事在会众眼前是隐藏的，而他们做了耶和华所吩咐不可做的任何事，因而有了罪责；</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:28"> 他们所犯的罪一被知道，会众就要献一头公牛作赎罪祭，把它牵到会幕前。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 16:21; 利未记 8:14"> 会众的长老要在耶和华面前按手在公牛的头上；这公牛要在耶和华面前被宰杀。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:5–12; 希伯来书 9:12–14"> 受膏的祭司要把公牛的一些血带进会幕。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:6–7"> 祭司要用指头蘸血，在耶和华面前，对着幔子弹七次。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7"> 他要把一些血抹在会幕内、耶和华面前祭坛的角上；其余的血要倒在会幕门口燔祭坛的底部。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 5:6; 利未记 4:26; 民数记 15:25"> 他要从公牛身上取下所有脂肪，烧在坛上。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 15:25; 希伯来书 10:10–12; 利未记 12:8"> 他要照样处理这公牛；他怎样处理赎罪祭的公牛，也要怎样处理这公牛；祭司要为他们赎罪，他们就必蒙赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 16:15; 马太福音 20:28; 哥林多后书 5:21"> 他要把公牛搬到营外，像焚烧第一头公牛那样焚烧它。这是为会众献的赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:13; 民数记 31:13"> “『首领若犯罪，无意中做了耶和华他的上帝所吩咐不可做的任何事，因而有了罪责，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:14; 罗马书 8:3; 民数记 7:22"> 他所犯的罪若使他知道了，他就要带一只无残疾的公山羊来作供物。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 3:13; 利未记 7:2; 利未记 4:3–35"> 他要按手在山羊的头上，在耶和华面前、宰杀燔祭牲的地方宰杀它。这是赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:7; 利未记 4:18; 利未记 4:30"> 祭司要用指头取一些赎罪祭牲的血，抹在燔祭坛的角上；其余的血要倒在燔祭坛的底部。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 4:20; 利未记 4:31; 利未记 4:35"> 所有脂肪，祭司都要烧在坛上，像烧平安祭牲的脂肪一样；祭司要为他所犯的罪替他赎罪，他就必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 4:2; 民数记 15:27; 利未记 4:13"> “『平民百姓中若有一个人无意中犯罪，做了耶和华所吩咐不可做的任何事，因而有了罪责，</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:32"> 他所犯的罪若使他知道了，他就要为自己所犯的罪，带一只无残疾的母山羊来作供物。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 4:4; 利未记 4:24; 利未记 1:4"> 他要按手在赎罪祭牲的头上，在献燔祭的地方宰杀赎罪祭牲。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 4:7; 利未记 4:25; 利未记 4:34"> 祭司要用指头取一些血，抹在燔祭坛的角上；其余的血都要倒在坛的底部。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 4:26; 利未记 4:35; 利未记 1:9"> 所有脂肪，祭司都要取下，像从平安祭牲取下脂肪一样；祭司要把它烧在坛上，作为献给耶和华的馨香；祭司要为他赎罪，他就必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 4:28; 彼得前书 3:18; 彼得前书 2:22"> “『他若带一只羊羔作赎罪祭的供物，就要带一只无残疾的母羊。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 4:29–31; 利未记 4:4"> 他要按手在赎罪祭牲的头上，在宰杀燔祭牲的地方宰杀它作赎罪祭。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 4:30; 利未记 4:25; 利未记 4:7"> 祭司要用指头取一些赎罪祭牲的血，抹在燔祭坛的角上；其余所有的血都要倒在坛的底部。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 4:26; 利未记 4:20; 利未记 14:18"> 所有脂肪，祭司都要取下，像从平安祭牲的羊羔取下脂肪一样。祭司要把这些烧在坛上，烧在献给耶和华的火祭上。祭司要为他所犯的罪替他赎罪，他就必蒙赦免。</span>
</div>

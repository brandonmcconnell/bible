<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="15" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司 3:7; 利未记 13:1; 利未记 11:1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 5:2; 撒母耳记下 3:29; 利未记 22:4"> “你们要对以色列人说，告诉他们：‘人若身体有漏症，他因这漏症就是不洁净的。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 23:20; 以西结 16:26; 利未记 12:3"> 关于他漏症中的不洁，是这样：无论他的身体因漏症而流出，还是他的身体因漏症而阻塞，这都是他的不洁。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="提多书 1:15; 以弗所书 5:11; 哥林多前书 15:33"> “‘凡有漏症的人所躺的床都不洁净；凡他所坐的物也都不洁净。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:25; 利未记 16:26; 利未记 17:15"> 凡摸他床的，要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 4:8; 以赛亚书 1:16"> 坐了有漏症的人所坐过之物的，要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> “‘摸有漏症者身体的人，要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:4; 彼得后书 2:1–3; 以赛亚书 1:16"> “‘有漏症的人若向洁净的人吐唾沫，那人就要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 31:34"> “‘有漏症的人骑过的任何鞍子都不洁净。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 4:8; 诗篇 26:6; 利未记 15:8"> 凡摸了他身下任何东西的人，都不洁净到晚上；拿这些东西的人，要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> “‘有漏症的人若没有用水冲洗手就摸了谁，谁就要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 6:28; 利未记 11:32–33; 哥林多后书 5:1"> “‘有漏症的人摸过的陶器要打碎；一切木器都要用水冲洗。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 14:8; 利未记 8:33; 利未记 15:28"> “‘有漏症的人从漏症得洁净的时候，要为自己的洁净计算七天，洗自己的衣服，用流动的水洗身体，就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 12:8; 利未记 12:6; 希伯来书 10:10"> “‘第八天，他要取两只斑鸠，或两只雏鸽，来到耶和华面前，到会幕门口，把它们交给祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 14:30–31; 利未记 4:26; 马太福音 3:17"> 祭司要献上它们，一只作赎罪祭，另一只作燔祭。祭司要因他的漏症，在耶和华面前为他赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 23:10–11; 利未记 22:4; 利未记 15:5"> “‘人若有精液流出，就要用水洗全身，并且不洁净到晚上。</span>
<span className="v" id="v17" data-v="17"> 凡沾了精液的衣服和皮物，都要用水洗，并且不洁净到晚上。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 15:5; 帖撒罗尼迦前书 4:3–5; 哥林多前书 6:12"> 男人若与女人同寝，有精液流出，两人都要用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 12:2; 马太福音 15:19; 马可福音 5:25"> “‘女人若有血流出，就是身体的月经，她就要处在经期的不洁中七天。凡摸她的，都不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 15:4–9; 箴言 2:16–19; 箴言 6:35"> “‘她在经期不洁中所躺的一切东西都不洁净；她所坐的一切东西也不洁净。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 7:14; 哥林多后书 7:1; 以赛亚书 22:14"> 凡摸她床的，要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
<span className="v" id="v22" data-v="22"> 凡摸她所坐任何东西的，要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
<span className="v" id="v23" data-v="23"> 那东西若在床上，或在她所坐的任何物上，他摸了，就不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 20:18; 彼得前书 2:11; 利未记 18:19"> “‘若有男人与她同寝，她的月经沾在他身上，他就不洁净七天；凡他所躺的床也都不洁净。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 5:25; 马太福音 9:20; 路加福音 8:43"> “‘女人若在经期以外多日血漏，或经期过后仍有血漏，在她不洁血漏的一切日子，她都要像在经期的日子一样。她是不洁净的。</span>
<span className="v" id="v26" data-v="26"> 在她血漏的一切日子，她所躺的每一张床，对她来说都像经期的床一样；她所坐的一切东西都不洁净，像她经期的不洁一样。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 15:21; 希伯来书 10:22; 利未记 17:15–16"> 凡摸这些东西的，都不洁净；他要洗自己的衣服，用水洗澡，并且不洁净到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="利未记 15:13–15; 加拉太书 3:13; 以弗所书 1:6–7"> “‘但她若从血漏得洁净，就要为自己计算七天，之后就洁净了。</span>
<span className="v" id="v29" data-v="29"> 第八天，她要取两只斑鸠，或两只雏鸽，带到会幕门口交给祭司。</span>
<span className="v" id="v30" data-v="30"> 祭司要献上一只作赎罪祭，另一只作燔祭；祭司要因她血漏的不洁，在耶和华面前为她赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数记 19:20; 民数记 19:13; 以西结 5:11"> “‘你们要这样使以色列人与他们的不洁分别开来，免得他们玷污我在他们中间的帐幕，因自己的不洁而死。’”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 11:46; 利未记 13:59; 民数记 6:13"> 这是关于有漏症的人，以及有精液流出、因此不洁净的人的律法；</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 15:19; 利未记 20:18; 利未记 15:24–25"> 也是关于处在经期不洁中的女人，关于男人或女人有漏症，以及关于与不洁净的女人同寝之人的律法。</span>
</div>
</div>

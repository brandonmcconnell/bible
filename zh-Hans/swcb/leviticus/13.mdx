<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="13" data-verses="59">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 24:8; 利未记 14:56; 利未记 14:3"> “人身上的皮肤若有肿块、痂，或亮斑，成了他身上皮肤的麻风病灾，就要把他带到祭司亚伦那里，或亚伦一个作祭司的儿子那里。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 3:19–20; 使徒行传 20:28; 玛拉基书 2:7"> 祭司要察看他身上皮肤的病灶；若病灶上的毛已经变白，病灶的现象深于身上的皮肤，这就是麻风病灾；祭司察看他以后，要宣告他为不洁净。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 12:15; 哥林多前书 4:5; 提摩太前书 5:24"> 若他身上皮肤的亮斑是白色的，现象不深于皮肤，上面的毛也没有变白，祭司就要把患病的人隔离七天。</span>
<span className="v" id="v5" data-v="5"> 第七天，祭司要察看他。看哪，若在他看来，病灶止住了，没有在皮肤上扩散，祭司就要再把他隔离七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 11:25; 利未记 14:8; 申命记 32:5"> 第七天，祭司要再次察看他。看哪，若病灶已经变淡，也没有在皮肤上扩散，祭司就要宣告他为洁净。这只是痂；他要洗衣服，就洁净了。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 38:3; 利未记 13:35–36; 提摩太后书 2:16–17"> 但他为了得洁净给祭司察看以后，若痂在皮肤上扩散，他就要再次给祭司察看。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 15:7–8; 腓立比书 3:18–19; 使徒行传 8:21"> 祭司要察看他；看哪，若痂在皮肤上扩散，祭司就要宣告他为不洁净。这是麻风病。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “人若有麻风病灾，就要把他带到祭司那里；</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 5:27; 历代志下 26:19–20; 利未记 13:14–15"> 祭司要察看他。看哪，若皮肤上有白色肿块，使毛变白，并且肿块中有生肉，</span>
<span className="v" id="v11" data-v="11"> 这就是他身上皮肤的慢性麻风病；祭司要宣告他为不洁净，不必把他隔离，因为他已经不洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰一书 1:8–10; 约伯记 42:6; 罗马书 7:14"> “若麻风病在皮肤上四处发作，按祭司所能看见的，麻风病覆盖了患病的人全身的皮肤，从头到脚，</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:41; 以赛亚书 64:6"> 祭司就要察看他。看哪，若麻风病覆盖了他全身，祭司就要宣告这病灶为洁净；全都变白了，他是洁净的。</span>
<span className="v" id="v14" data-v="14"> 但什么时候他身上出现生肉，他就不洁净。</span>
<span className="v" id="v15" data-v="15"> 祭司要察看那生肉，宣告他为不洁净；生肉是不洁净的。这是麻风病。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 1:14–16; 罗马书 7:14–24; 腓立比书 3:6–8"> 或者，若生肉又变回白色，他就要到祭司那里。</span>
<span className="v" id="v17" data-v="17"> 祭司要察看他。看哪，若病灶已经变白，祭司就要宣告这病灶为洁净；他是洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:9; 以赛亚书 38:21; 诗篇 38:3–7"> “人身上的皮肤若长过疮，已经好了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 13:24"> 在疮原来的地方有白色肿块，或红白色的亮斑，就要给祭司察看。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 5:14; 利未记 13:3; 彼得后书 2:20"> 祭司要察看。看哪，若其现象深于皮肤，上面的毛已经变白，祭司就要宣告他为不洁净。这是麻风病灾，在疮中发作了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 5:5"> 但若祭司察看，见其中没有白毛，也不深于皮肤，而是变淡了，祭司就要把他隔离七天。</span>
<span className="v" id="v22" data-v="22"> 若它在皮肤上扩散，祭司就要宣告他为不洁净。这是病灶。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 约伯记 34:31–32; 马太福音 26:75"> 但若亮斑停在原处，没有扩散，这就是疮的疤痕；祭司要宣告他为洁净。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 3:24"> “或者，人身上的皮肤若被火烧伤，烧伤处的生肉成了红白色或白色的亮斑，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 13:18–20; 利未记 13:4"> 祭司就要察看；看哪，若亮斑上的毛已经变白，现象深于皮肤，这就是麻风病，在烧伤处发作了；祭司要宣告他为不洁净。这是麻风病灾。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 13:23; 利未记 13:4–5"> 但若祭司察看，见亮斑中没有白毛，也不深于皮肤，而是变淡了，祭司就要把他隔离七天。</span>
<span className="v" id="v27" data-v="27"> 第七天，祭司要察看他。若它在皮肤上扩散，祭司就要宣告他为不洁净。这是麻风病灾。</span>
<span className="v" id="v28" data-v="28"> 若亮斑停在原处，没有在皮肤上扩散，而是变淡了，这就是烧伤造成的肿块；祭司要宣告他为洁净，因为这是烧伤的疤痕。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:15; 马太福音 13:14–15; 哥林多后书 4:3–4"> “男人或女人若在头上或胡须上有病灶，</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 13:34–37; 利未记 14:54"> 祭司就要察看那病灶；看哪，若其现象深于皮肤，其中的毛黄而细，祭司就要宣告他为不洁净。这是癣疥，是头上或胡须上的麻风病。</span>
<span className="v" id="v31" data-v="31"> 若祭司察看癣疥的病灶，见其现象不深于皮肤，其中也没有黑毛，祭司就要把患癣疥的人隔离七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 13:30; 马太福音 23:5; 路加福音 18:9–12"> 第七天，祭司要察看那病灶；看哪，若癣疥没有扩散，其中也没有黄毛，癣疥的现象不深于皮肤，</span>
<span className="v" id="v33" data-v="33"> 那人就要剃毛，但不可剃癣疥之处。然后祭司要把患癣疥的人再隔离七天。</span>
<span className="v" id="v34" data-v="34" data-xref="犹大书 1:22; 约翰一书 4:1; 启示录 2:2"> 第七天，祭司要察看癣疥；看哪，若癣疥没有在皮肤上扩散，其现象也不深于皮肤，祭司就要宣告他为洁净。他要洗衣服，就洁净了。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 13:27; 提摩太后书 2:16–17; 利未记 13:7"> 但他得洁净以后，若癣疥在皮肤上扩散，</span>
<span className="v" id="v36" data-v="36"> 祭司就要察看他；看哪，若癣疥在皮肤上扩散，祭司就不必寻找黄毛；他是不洁净的。</span>
<span className="v" id="v37" data-v="37"> 但若在他看来，癣疥止住了，其中长出黑毛，癣疥已经痊愈；他是洁净的。祭司要宣告他为洁净。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> “男人或女人身上的皮肤若有亮斑，就是白色亮斑，</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:22–25; 雅各书 3:2; 传道书 7:20"> 祭司就要察看。看哪，若他们身上皮肤的亮斑是暗白色的，这就是无害的疹子，在皮肤上发作；他是洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="加拉太书 4:13; 罗马书 8:10; 雅歌 5:11"> “若男人头上的头发脱落，他是秃头；他是洁净的。</span>
<span className="v" id="v41" data-v="41"> 若他前额的头发脱落，他是前额秃；他是洁净的。</span>
<span className="v" id="v42" data-v="42"> 但若秃头处或前额秃处有红白色的病灶，这就是麻风病在他的秃头处或前额秃处发作。</span>
<span className="v" id="v43" data-v="43"> 祭司就要察看他。看哪，若他秃头处或前额秃处病灶的肿块是红白色的，像身上皮肤的麻风病现象，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得后书 2:1–2; 马太福音 6:23; 以赛亚书 1:5"> 他就是患麻风病的人。他是不洁净的。祭司必须宣告他为不洁净；他的病灶在头上。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="弥迦书 3:7; 利未记 10:6; 以西结 24:17"> “身上有这病灶的麻风病人要穿撕裂的衣服，头发要披散。他要遮住上唇，并且呼喊：『不洁净！不洁净！』</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪下 7:3; 列王纪下 15:5; 历代志下 26:21"> 只要病灶还在他身上，他就不洁净。他是不洁净的；他要独自居住，他的住处要在营外。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="犹大书 1:23; 罗马书 13:12; 以西结 16:16"> “衣物若有麻风的灾病，无论是羊毛衣物，还是细麻衣物；</span>
<span className="v" id="v48" data-v="48" data-xref="利未记 13:51; 启示录 3:4; 申命记 8:11"> 无论是在细麻或羊毛的经线或纬线中；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="经线和纬线是织布中纵向和横向的线">a</a></sup>无论是在皮革上，还是在任何皮革制品上；</span>
<span className="v" id="v49" data-v="49"> 若这灾斑在衣物上，或皮革上，或经线中，或纬线中，或任何皮革制品上，呈绿色或红色，这就是麻风的灾病，必须给祭司察看。</span>
<span className="v" id="v50" data-v="50" data-xref="以西结 44:23"> 祭司要察看那灾斑，把有灾斑的物件隔离七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未记 14:44"> 第七天，他要察看那灾斑。若灾斑在衣物上扩散，或在经线中，或在纬线中，或在皮革上，不论那皮革作什么用途，这灾斑就是侵蚀性的霉斑；它是不洁净的。</span>
<span className="v" id="v52" data-v="52" data-xref="利未记 11:35; 利未记 11:33; 利未记 14:44–45"> 那有灾斑的衣物，无论是羊毛或细麻中的经线或纬线，或任何皮革制品，他都要焚烧，因为这是侵蚀性的霉斑，必须用火焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53"> “若祭司察看，见灾斑没有在衣物上扩散，或在经线中，或在纬线中，或在任何皮革制品上扩散，</span>
<span className="v" id="v54" data-v="54"> 祭司就要吩咐人洗那有灾斑的物件，并把它再隔离七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结 24:13; 希伯来书 6:4–8; 彼得后书 2:20–22"> 洗过以后，祭司要察看那灾斑；看哪，若灾斑的颜色没有改变，灾斑也没有扩散，它就是不洁净的；你要用火焚烧它。这是霉蚀的斑，无论蚀处在里面还是外面。</span>
<span className="v" id="v56" data-v="56"> 若祭司察看，见灾斑洗过以后变淡了，他就要把那一块从衣物、皮革、经线或纬线中撕下来；</span>
<span className="v" id="v57" data-v="57" data-xref="马太福音 22:7; 启示录 21:8; 马太福音 3:12"> 若它又出现在衣物上，或经线中，或纬线中，或任何皮革制品上，这就是在扩散；你要用火焚烧那有灾斑的物件。</span>
<span className="v" id="v58" data-v="58" data-xref="列王纪下 5:14; 启示录 1:5; 诗篇 51:2"> 至于那衣物，或经线，或纬线，或任何皮革制品，你洗过以后，若灾斑离开了，就要再洗一次，它就洁净了。”</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> 这是关于羊毛或细麻衣物上的霉灾，无论是在经线中，或纬线中，或任何皮革制品上，宣告它洁净或宣告它不洁净的律法。</span>
</div>
</div>

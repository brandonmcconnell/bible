<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:4; 利未记 23:37; 民数记 29:39"> “你要吩咐以色列子孙，对他们说：‘耶和华所定的节期，就是你们要宣告为圣会的，这些就是我所定的节期。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 19:3; 出埃及记 23:12; 出埃及记 35:2–3"> “‘六日要做工，但第七日是完全安息的安息日，是圣会；你们不可做任何工。在你们一切住处，这都是向耶和华守的安息日。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未记 23:2; 出埃及记 23:14; 利未记 23:37"> “‘这些是耶和华所定的节期，就是你们要按所定日期宣告的圣会。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 申命记 16:1–8; 民数记 28:16–17"> 正月十四日黄昏，是耶和华的逾越节。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 34:18; 申命记 16:8; 出埃及记 12:15–16"> 这月十五日，是向耶和华守的无酵节。七日之内你们要吃无酵饼。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 28:18–25; 利未记 23:8; 利未记 23:21"> 第一日你们要有圣会，不可做任何日常工作。</span>
<span className="v" id="v8" data-v="8"> 七日之内，你们要向耶和华献火祭。第七日要有圣会，不可做任何日常工作。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 34:26; 出埃及记 23:19; 申命记 16:9"> “你要吩咐以色列子孙，对他们说：‘你们进了我赐给你们的地，收割庄稼的时候，要把你们初熟庄稼的一捆带给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 29:24; 利未记 10:14; 利未记 9:21"> 他要在耶和华面前摇这一捆，使你们蒙悦纳。祭司要在安息日的次日摇这一捆。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:10–12; 彼得前书 1:19; 利未记 1:10"> 你们摇这一捆的那日，要把一只一岁的、没有残疾的公羊羔献给耶和华作燔祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:14–16; 约珥 1:9; 民数记 28:10"> 与它同献的素祭，要用调油的细面伊法十分之二<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1伊法约为22升，或约为2/3蒲式耳。">a</a></sup>，作为献给耶和华、馨香的火祭；与它同献的奠祭，要用酒一欣的四分之一。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1欣约为6.5升，或1.7加仑。">b</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 34:26; 创世记 4:4–5; 利未记 3:17"> 你们不可吃饼、烘过的谷或新谷，直到这一天，直到你们把你们上帝的供物带来。这在你们一切住处，要作你们世世代代永远的条例。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 23:10–11; 利未记 25:8; 申命记 16:9–10"> “‘你们要从安息日的次日，就是从你们带来摇祭之捆的那日起计算，数满七个安息日。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:1; 民数记 28:26"> 要数到第七个安息日的次日，共五十天；你们要向耶和华献新的素祭。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:10; 出埃及记 34:26; 出埃及记 34:22"> 你们要从住处带出两个饼，作摇祭；要用细面伊法十分之二<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="1伊法约为22升，或约为2/3蒲式耳。">c</a></sup>，加酵烤成，作为初熟之物献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 28:27–31; 利未记 23:12–13; 玛拉基书 1:13–14"> 你们要把七只一岁的、没有残疾的羊羔、一头公牛犊、两只公绵羊，连同这些饼一起献上。它们要作献给耶和华的燔祭，并同献素祭和奠祭，就是献给耶和华、馨香的火祭。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 28:30; 利未记 4:23–28; 利未记 7:11–18"> 你们要献一只公山羊作赎罪祭，又献两只一岁的公羊羔作平安祭的祭物。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 18:4; 以弗所书 2:14; 民数记 18:8–12"> 祭司要把它们连同初熟之物的饼和两只羊羔，在耶和华面前摇一摇，作为摇祭。它们要归耶和华为圣，给祭司。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 23:2; 利未记 23:4; 民数记 18:23"> 你们要在这同一天宣告有圣会；不可做任何日常工作。这在你们一切住处，要作你们世世代代永远的条例。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 24:19–21; 利未记 19:9–10; 以赛亚书 58:10"> “‘你们收割地上的庄稼时，不可把田角割尽，也不可拾取收割时遗落的；要留给穷人和寄居的人。我是耶和华你们的上帝。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华对摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:52; 帖撒罗尼迦前书 4:16; 利未记 25:9"> “你要吩咐以色列子孙说：‘七月初一日，你们要有严肃安息，以吹号作纪念，是圣会。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:21"> 不可做任何日常工作；要向耶和华献火祭。’”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华对摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 16:29–31; 出埃及记 30:10; 利未记 16:24"> “然而，这七月初十日是赎罪日。你们要有圣会，要刻苦己心，并要向耶和华献火祭。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 3:9; 利未记 16:34; 希伯来书 10:10"> 在这同一天，你们不可做任何工，因为这是赎罪日，要在耶和华你们的上帝面前为你们赎罪。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:14; 民数记 5:2; 利未记 23:27"> 凡在这同一天不刻苦己心的人，必从他民中被剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:3; 西番雅书 2:5; 耶利米书 15:7"> 凡在这同一天做任何工的人，我必把那人从他民中除灭。</span>
<span className="v" id="v31" data-v="31"> 你们不可做任何工；这在你们一切住处，要作你们世世代代永远的条例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:31; 马太福音 11:28–30; 诗篇 69:10–11"> 这要作你们完全安息的安息日，你们要刻苦己心。从这月初九日晚上，从晚上到晚上，你们要守你们的安息日。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华对摩西说：</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 7:2; 尼希米记 8:14; 以斯拉记 3:4"> “你要吩咐以色列子孙说：‘这七月十五日，是向耶和华守的住棚节<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“帐棚节”，或“苏科特”。">d</a></sup>，为期七日。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 23:24–25; 利未记 23:7–8"> 第一日要有圣会；不可做任何日常工作。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 8:18; 约翰福音 7:37; 历代志下 7:8–11"> 七日之内，你们要向耶和华献火祭。第八日你们要有圣会，也要向耶和华献火祭。这是严肃会；不可做任何日常工作。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="利未记 23:2; 利未记 23:4; 传道书 3:1"> “‘这些是耶和华所定的节期，你们要宣告为圣会，好向耶和华献火祭、燔祭、素祭、祭物和奠祭，各按其日——</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 29:39; 利未记 19:3; 以斯拉记 2:68–69"> 这是在耶和华的安息日以外，也在你们献给耶和华的礼物、所许的一切愿、甘心献的一切供物以外。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 23:16; 申命记 16:13; 利未记 23:34"> “‘所以，七月十五日，你们收藏了地的出产以后，要守耶和华的节七日。第一日要严肃安息，第八日也要严肃安息。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 4:4; 启示录 7:9; 申命记 16:14–15"> 第一日，你们要取华美树上的果子、棕树枝、茂密树的枝条和溪边的柳枝，在耶和华你们的上帝面前欢乐七日。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 29:12; 尼希米记 8:18"> 你们每年要守这节，向耶和华守七日；这要作你们世世代代永远的条例。你们要在七月守这节。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 8:14–17; 创世记 33:17; 民数记 24:5"> 你们要住在临时棚子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或“棚”。">e</a></sup>里七日；凡以色列本地出生的人，都要住在临时棚子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或“棚”。">f</a></sup>里，</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 31:10–13; 诗篇 78:5–6; 出埃及记 13:14"> 好使你们世世代代知道，我领以色列子孙出埃及地的时候，曾使他们住在临时棚子<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或“棚”。">g</a></sup>里。我是耶和华你们的上帝。’”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="利未记 23:1–2; 马太福音 18:20; 利未记 21:24"> 于是摩西向以色列子孙宣告耶和华所定的节期。</span>
</div>
</div>

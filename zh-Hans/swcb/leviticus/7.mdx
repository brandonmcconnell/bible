<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:17; 利未记 5:14–7; 利未记 6:25"> “‘这是赎愆祭的条例：这是至圣的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 1:5; 利未记 6:25; 利未记 1:11"> 人在哪里宰燔祭牲，也要在哪里宰赎愆祭牲；祭司要把它的血洒在祭坛的四周。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 3:15–16; 诗篇 51:6"> 他要献上它所有的脂肪：肥尾巴和盖在内脏上的脂肪，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:4"> 又要取下两个肾和肾上靠近腰部的脂肪，以及肝上的网子，连同肾一起取下；</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 1:13; 加拉太书 5:24; 彼得前书 4:1–2"> 祭司要把这些烧在祭坛上，作为献给耶和华的火祭；这是赎愆祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 6:29; 民数记 18:9–10; 利未记 2:3"> 祭司中的每一个男子都可以吃这祭物；要在圣洁的地方吃。这是至圣的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未记 6:25–26; 利未记 14:13; 哥林多前书 9:13"> “‘赎罪祭怎样，赎愆祭也怎样；两者同归一个条例。用它们献祭赎罪的祭司要得这祭物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 4:11; 出埃及记 29:14; 罗马书 13:14"> 为人献燔祭的祭司，要自己得他所献那燔祭牲的皮。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:9; 以西结 44:29; 利未记 2:10"> 凡在炉中烤的素祭，以及凡在锅里和铁盘上预备的，都要归献这祭的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 8:14; 出埃及记 16:18"> 凡素祭，无论是调油的或干的，都要归亚伦所有的子孙，彼此同得。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 22:18–21; 以西结 45:15; 利未记 3:1–17"> “‘这是人献给耶和华的平安祭祭物的条例：</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 2:4; 民数记 6:15; 彼得前书 2:5"> 如果他为感恩而献，就要与感恩祭一同献上调油的无酵饼、抹油的无酵薄饼，以及用油调和的细面饼。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司 4:5; 利未记 23:17; 马太福音 13:33"> 他要把有酵饼与他为感恩所献的平安祭祭物一同献上，作为他的供物。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:19; 出埃及记 29:27–28; 民数记 18:24–32"> 他要从每一样供物中取一个，献给耶和华作举祭；这要归给洒平安祭牲之血的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 22:29–30"> 他为感恩所献平安祭祭物的肉，要在献祭当天吃，不可留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 19:5–8; 申命记 12:6; 诗篇 116:14"> “‘但如果他所献的祭物是还愿祭，或是甘心祭，就要在他献祭的当天吃；剩下的，第二天也可以吃，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:10; 何西阿 6:2; 哥林多前书 15:4"> 但祭肉若有剩到第三天的，就要用火焚烧。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 19:7–8; 利未记 11:41; 民数记 18:27"> 如果他平安祭祭物的肉在第三天被吃了，这祭就不蒙悦纳，也不算在献祭的人身上；这要成为可憎之物，吃这肉的人必担当他的罪孽。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多书 1:15; 使徒行传 10:15–16"> “‘沾了任何不洁之物的肉不可吃，要用火焚烧。至于这肉，凡洁净的人都可以吃；</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 15:2–33; 创世记 17:14; 利未记 22:3–7"> 但人若身上有污秽，却吃了属于耶和华的平安祭祭物的肉，那人必从他的民中被剪除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 12:1–59; 利未记 11:20; 以西结 4:14"> 若有人摸了任何不洁之物，无论是人的污秽，或是不洁净的牲畜，或是任何不洁的可憎之物，又吃了属于耶和华的平安祭祭物的肉，那人必从他的民中被剪除。’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 3:16–17; 利未记 17:6; 撒母耳记上 2:15–17"> “你要告诉以色列人说：‘牛的脂肪，或绵羊、山羊的脂肪，你们都不可吃。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 22:31; 利未记 17:15; 利未记 22:8"> 自死之物的脂肪，以及被野兽撕裂之物的脂肪，可以作别的用途，但你们绝不可吃。</span>
<span className="v" id="v25" data-v="25"> 凡吃人献给耶和华作火祭的牲畜脂肪的，吃的人必从他的民中被剪除。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 9:4; 利未记 3:17; 使徒行传 15:20"> 在你们一切住处，无论是鸟的血或牲畜的血，你们都不可吃。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 10:29; 利未记 7:20–21; 利未记 7:25"> 无论是谁吃了任何血，那人必从他的民中被剪除。’”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和华对摩西说：</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 1:20; 约翰一书 1:7; 利未记 3:1–17"> “你要告诉以色列人说：‘向耶和华献平安祭祭物的人，要从他的平安祭祭物中，把他的供物带来献给耶和华。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 6:20; 利未记 3:9; 利未记 3:14"> 他要亲手把献给耶和华的火祭带来；他要把脂肪连同胸带来，好把胸在耶和华面前摇一摇，作为摇祭。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 3:5; 利未记 3:11; 利未记 3:16"> 祭司要把脂肪烧在祭坛上，但胸要归亚伦和他的子孙。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 6:20; 利未记 7:34; 利未记 9:21"> 你们要从平安祭祭物中，把右腿给祭司作举祭。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 26:1–46; 利未记 6:1–30; 利未记 7:3"> 亚伦子孙中献平安祭牲之血和脂肪的，要得右腿作为他的份。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 18:18–19; 利未记 10:14–15; 出埃及记 29:9"> 因为我从以色列人的平安祭祭物中，取了摇过的胸和举起的腿，赐给祭司亚伦和他的子孙，作为他们从以色列人所得永远的份。’”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:20; 约翰一书 2:27; 民数记 18:7–19"> 这是亚伦受圣职所得的份，也是他子孙受圣职所得的份，是从献给耶和华的火祭中取出的，是在他使他们前来担任祭司职分、事奉耶和华的日子赐下的；</span>
<span className="v" id="v36" data-v="36" data-xref="利未记 8:12; 利未记 8:30; 出埃及记 40:13–15"> 就是在膏立他们的日子，耶和华吩咐以色列人给他们的。这是他们世世代代永远的份。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:1; 利未记 1:1–6; 利未记 6:9–18"> 这是燔祭、素祭、赎罪祭、赎愆祭、承接圣职礼和平安祭祭物的条例，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 1:1–2"> 是耶和华在西奈山吩咐摩西的，就是祂在西奈旷野吩咐以色列人把他们的供物献给耶和华的那一天。</span>
</div>
</div>

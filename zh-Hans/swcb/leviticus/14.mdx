<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 马可福音 1:40–44"> “患麻风病的人得洁净的日子，其条例是这样：人要把他带到祭司那里；</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要出到营外。祭司要察看他。看哪，如果那患麻风病的人身上的麻风灾病已经痊愈，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 19:6; 利未记 14:6; 希伯来书 9:19"> 祭司就要吩咐人为那将要得洁净的人取两只洁净的活鸟、香柏木、朱红色线和牛膝草。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 14:50; 希伯来书 2:14; 哥林多后书 5:1"> 祭司要吩咐人把其中一只鸟，在盛有活水的陶器上宰杀。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:5; 撒迦利亚书 13:1; 腓立比书 2:9–11"> 至于那只活鸟，祭司要把它和香柏木、朱红色线、牛膝草一同取来，把这些和那只活鸟蘸在那只宰于活水上的鸟的血中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 以西结 36:25; 以赛亚书 52:15"> 他要把血洒在那要从麻风病中得洁净的人身上七次，宣布他为洁净，又要把那只活鸟放到田野里去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 11:25; 民数记 8:7; 彼得前书 3:21"> “那将要得洁净的人要洗自己的衣服，剃去全身的毛发，用水洗澡；他就洁净了。以后他可以进营，但要在自己的帐棚外住七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 6:9; 利未记 14:8; 民数记 8:7"> 到第七天，他要剃去头上所有的头发、胡须和眉毛；他要剃去全身的毛发。他要洗自己的衣服，又要用水洗身体；这样，他就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 2:1; 马太福音 8:4; 路加福音 5:14"> “第八天，他要取两只没有残疾的公羔羊、一只没有残疾的一岁母羔羊、十分之三伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一伊法约为22升，或约为三分之二蒲式耳。">a</a></sup>调油的细面作素祭，以及一罗革<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一罗革是一种液量单位，约为300毫升或10盎司。">b</a></sup>油。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:26–27; 出埃及记 29:1–4; 民数记 8:21"> 那洁净他的祭司要把那将要得洁净的人和这些东西，安置在会幕门口、耶和华面前。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 29:24; 利未记 6:6–7; 利未记 8:27–29"> “祭司要取一只公羔羊，连同那一罗革油献为赎愆祭，并把它们在耶和华面前摇一摇，作摇祭。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:11; 利未记 1:11; 利未记 4:24"> 他要在圣所中宰赎罪祭牲和燔祭牲的地方宰那只公羔羊；因为赎愆祭怎样归祭司，赎罪祭也怎样归祭司。这是至圣的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:20; 利未记 8:23–24; 哥林多后书 7:1"> 祭司要取些赎愆祭牲的血，抹在那将要得洁净之人的右耳垂上、右手大拇指上和右脚大脚趾上。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 45:7; 约翰福音 3:34; 约翰一书 2:20"> 祭司要取些那一罗革油，倒在自己左手掌里。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:17; 哥林多前书 10:31; 利未记 4:6"> 祭司要用右手指蘸左手里的油，用手指在耶和华面前弹油七次。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 1:2; 以西结 36:27; 利未记 14:14"> 祭司要把手里剩下的一些油，抹在那将要得洁净之人的右耳垂上、右手大拇指上和右脚大脚趾上，就是抹在赎愆祭牲的血上。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:26; 哥林多后书 1:21–22; 以弗所书 1:17–18"> 祭司手里剩下的油，要抹在那将要得洁净之人的头上；祭司要在耶和华面前为他赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 14:12; 利未记 5:1; 利未记 12:6–8"> “祭司要献赎罪祭，为那将要得洁净的人因他的污秽而赎罪。之后，他要宰燔祭牲；</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 14:10; 以弗所书 5:2; 利未记 14:8"> 然后祭司要把燔祭和素祭献在祭坛上。祭司要为他赎罪，他就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 5:7; 利未记 12:8; 箴言 17:5"> “如果他贫穷，负担不起这么多，就要取一只公羔羊作赎愆祭，摇一摇，为他赎罪；又取十分之一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一伊法约为22升，或约为三分之二蒲式耳。">c</a></sup>调油的细面作素祭，以及一罗革<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一罗革是一种液量单位，约为300毫升或10盎司。">d</a></sup>油；</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 7:16; 以赛亚书 59:11; 耶利米书 48:28"> 还要取两只斑鸠或两只雏鸽，按他的能力所及；其中一只作赎罪祭，另一只作燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="利未记 14:10–11"> “第八天，他要为自己的洁净，把这些带到会幕门口、耶和华面前，交给祭司。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:12; 利未记 14:10"> 祭司要取那赎愆祭的羔羊和那一罗革油；祭司要把它们在耶和华面前摇一摇，作摇祭。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 5:1; 诗篇 40:6; 利未记 14:14–20"> 他要宰那赎愆祭的羔羊。祭司要取些赎愆祭牲的血，抹在那将要得洁净之人的右耳垂上、右手大拇指上和右脚大脚趾上。</span>
<span className="v" id="v26" data-v="26"> 祭司要把些油倒在自己左手掌里；</span>
<span className="v" id="v27" data-v="27"> 祭司要用右手指把左手里的油在耶和华面前弹七次。</span>
<span className="v" id="v28" data-v="28"> 然后祭司要把手里的一些油，抹在那将要得洁净之人的右耳垂上、右手大拇指上和右脚大脚趾上，就是抹在赎愆祭牲血的地方。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 14:18; 约翰一书 2:1–2; 出埃及记 30:15–16"> 祭司手里剩下的油，要抹在那将要得洁净之人的头上，在耶和华面前为他赎罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 14:22; 罗马书 8:3; 利未记 12:8"> 他要献上一只斑鸠，或一只雏鸽，按他的能力所及，</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 14:18; 利未记 5:7"> 就是按他能力所及的，一只作赎罪祭，另一只作燔祭，连同素祭一起献上。祭司要在耶和华面前为那将要得洁净的人赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 14:10; 利未记 14:21; 马太福音 11:5"> 这是为患麻风灾病而无力预备洁净祭物的人所定的条例。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 32:49; 创世记 17:8; 民数记 32:22"> “你们进入迦南地，就是我赐给你们作产业的地以后，如果我使你们所得为业之地的一所房屋里出现蔓延性霉斑，</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 91:10; 申命记 7:26; 撒迦利亚书 5:4"> 房主就要来告诉祭司说：‘据我看来，房屋里似乎有某种灾斑。’</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 18:4; 希伯来书 12:15; 提摩太后书 2:17–18"> 祭司还没有进去察看灾斑以前，要吩咐人把房屋腾空，免得房屋里所有的东西都成为不洁净。之后，祭司要进去察看那房屋。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 13:42; 利未记 13:3; 利未记 13:19–20"> 他要察看那灾斑；看哪，如果灾斑在房屋的墙上有凹陷的纹路，呈绿色或红色，而且看起来比墙面低陷，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 13:50"> 祭司就要从房屋出来，到房门口，把房屋封闭七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未记 13:36; 利未记 13:27; 利未记 13:22"> 第七天，祭司要再来察看。如果灾斑在房屋的墙上蔓延了，</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 2:20; 提多书 3:10; 哥林多前书 5:5–6"> 祭司就要吩咐人把有灾斑的石头挖出来，丢到城外不洁净的地方。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 65:4; 启示录 22:15; 马太福音 24:51"> 他要叫人把房屋里面四周刮净；他们要把刮下来的灰泥倒在城外不洁净的地方。</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太后书 2:2; 提摩太前书 5:21–22; 历代志下 17:7–9"> 他们要另取石头，放在那些石头的位置上；他也要另取灰泥，把房屋重新粉刷。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 6:28–30; 犹大书 1:12; 彼得后书 2:20"> “如果在他挖出石头、刮净房屋并重新粉刷以后，灾斑又在房屋里复发出来，</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 13:51–52; 撒迦利亚书 5:4"> 祭司就要进去察看；看哪，如果灾斑在房屋里蔓延了，这就是房屋里侵蚀性的霉斑，是不洁净的。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 10:27; 马太福音 24:2; 列王纪上 9:6–9"> 他要拆毁那房屋，包括房屋的石头、木料和所有灰泥；要把这些都搬到城外不洁净的地方。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="民数记 19:21–22; 利未记 22:6; 利未记 11:28"> “此外，在房屋封闭期间进去的人，必不洁净直到晚上。</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 14:8–9; 利未记 11:25"> 在那房屋里躺卧的人要洗自己的衣服；在那房屋里吃饭的人也要洗自己的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 6:11; 约伯记 5:18; 马可福音 5:29"> “如果祭司进去察看，看哪，房屋粉刷以后，灾斑没有在房屋里蔓延，祭司就要宣布这房屋为洁净，因为灾斑已经痊愈。</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 14:4"> 为洁净房屋，他要取两只鸟、香柏木、朱红色线和牛膝草。</span>
<span className="v" id="v50" data-v="50"> 他要把其中一只鸟，在盛有活水的陶器上宰杀。</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 51:7"> 他要取香柏木、牛膝草、朱红色线和那只活鸟，蘸在被宰之鸟的血中和活水中，在房屋上洒七次。</span>
<span className="v" id="v52" data-v="52"> 他要用鸟血、活水、活鸟、香柏木、牛膝草和朱红色线来洁净那房屋；</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 14:20; 利未记 14:7"> 但他要把那只活鸟放到城外田野里去。这样，他要为房屋赎罪，房屋就洁净了。”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未记 15:32; 利未记 14:32; 利未记 6:9"> 这是为各样麻风灾病、疥癣、</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 13:47–59"> 衣服和房屋上侵蚀性的霉斑、</span>
<span className="v" id="v56" data-v="56" data-xref="利未记 13:2"> 肿块、痂和亮斑所定的条例；</span>
<span className="v" id="v57" data-v="57" data-xref="利未记 10:10; 以西结 44:23; 耶利米书 15:19"> 为要指明什么时候为不洁净，什么时候为洁净。<br />这是麻风病的条例。</span>
</div>

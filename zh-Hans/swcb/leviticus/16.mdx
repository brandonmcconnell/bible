<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–2"> 亚伦的两个儿子来到耶和华面前而死；他们死后，耶和华对摩西说话。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:10; 列王纪上 8:10–12; 希伯来书 10:19–20"> 耶和华对摩西说：“要告诉你的哥哥亚伦，不可随时进入幔子内的至圣所，到柜上的施恩座前，免得他死亡；因为我要在施恩座上的云中显现。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 4:3; 希伯来书 9:24–25; 希伯来书 9:7"> “亚伦要带一头公牛犊作赎罪祭，一只公绵羊作燔祭，才可以进入圣所。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:39–43; 以西结 44:17–18; 出埃及记 30:20"> 他要穿上圣的细麻内袍，把细麻裤子穿在身上，束上细麻腰带，戴上细麻礼冠；这些都是圣衣。他要用水洗身，然后穿上。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:21; 利未记 8:2; 以斯拉记 6:17"> 他要从以色列人的会众取两只公山羊作赎罪祭，一只公绵羊作燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 9:7; 希伯来书 9:7; 希伯来书 7:27"> “亚伦要献上那头为自己作赎罪祭的公牛，为自己和自己的家赎罪。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:1; 利未记 4:4; 马太福音 16:21"> 他要把两只公山羊带来，安置在会幕门口、耶和华面前。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:23–26; 约拿 1:7; 箴言 16:33"> 亚伦要为这两只公山羊掣签：一个签归耶和华，另一个签归替罪羊。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:27–28; 使徒行传 2:23"> 亚伦要献上那只抽中归耶和华之签的公山羊，把它献为赎罪祭。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:2; 利未记 16:21–22; 希伯来书 9:23–24"> 但那只抽中归替罪羊之签的公山羊，要活着安置在耶和华面前，在它上面行赎罪礼，好把它作为替罪羊送到旷野去。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 16:6; 希伯来书 7:27; 希伯来书 9:7"> “亚伦要献上那头为自己作赎罪祭的公牛，为自己和自己的家赎罪；他要宰杀那头为自己作赎罪祭的公牛。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:1; 出埃及记 30:34–38; 启示录 8:3–4"> 他要拿一个香炉，盛满耶和华面前坛上的火炭，又拿两捧捣细的馨香之香，带进幔子内。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:21; 出埃及记 30:1; 出埃及记 30:7–8"> 他要在耶和华面前把香放在火上，使香的云遮盖约柜上的施恩座，免得他死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 9:25; 利未记 4:5–6; 希伯来书 9:13"> 他要取一些公牛的血，用指头洒在施恩座朝东的一面；又要用指头把一些血在施恩座前洒七次。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:7; 希伯来书 2:17; 希伯来书 9:3"> “然后他要宰杀那只为百姓作赎罪祭的公山羊，把它的血带进幔子内，用这血照他处理公牛的血那样，洒在施恩座上和施恩座前。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 9:22–23; 利未记 16:18; 以西结 45:18–19"> 他要为圣所赎罪，因为以色列人的污秽和他们的过犯，就是他们一切的罪；对于住在他们中间、处在他们污秽之中的会幕，他也要照样行。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:6; 路加福音 1:10; 出埃及记 34:3"> 他进入圣所行赎罪礼的时候，任何人不可在会幕里，直到他出来，并为自己、自己的家人和以色列全体会众赎了罪。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7; 希伯来书 5:7–8; 利未记 16:16"> “他要出来，到耶和华面前的坛那里，为坛赎罪；他要取一些公牛的血和一些公山羊的血，抹在坛四围的角上。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:1; 以西结 43:18–22"> 他要用指头把一些血在坛上洒七次，洁净坛，使它脱离以色列人的污秽而成为圣。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 16:16; 以西结 45:20; 歌罗西书 1:20"> “他为圣所、会幕和坛赎罪完毕以后，要献上那只活的公山羊。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 53:6; 哥林多后书 5:21; 以斯拉记 10:1"> 亚伦要把双手按在那只活公山羊的头上，在它上面承认以色列人一切的罪孽和他们一切的过犯，就是他们一切的罪；他要把这些都归在公山羊的头上，借着一个预备好的人把它送到旷野去。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:28; 以赛亚书 53:11–12; 约翰福音 1:29"> 那只公山羊要担当他们一切的罪孽，把它们带到荒无人烟之地；那人要在旷野放走那只公山羊。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结 44:19; 以西结 42:14; 利未记 16:4"> “亚伦要进入会幕，脱下他进圣所时所穿的细麻衣，放在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 16:3–5; 希伯来书 10:19–22; 出埃及记 28:4–14"> 然后他要在圣处用水洗身，穿上自己的衣服，出来献上自己的燔祭和百姓的燔祭，为自己和百姓赎罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:13; 利未记 4:8–10; 利未记 16:6"> 赎罪祭牲的脂肪，他要烧在坛上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未记 16:10; 希伯来书 7:19; 民数记 19:21"> “那放替罪羊的人要洗衣服，用水洗身，然后才可以进营。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 4:21; 利未记 6:30; 利未记 4:11–12"> 那作赎罪祭的公牛和作赎罪祭的公山羊，它们的血被带入圣所行赎罪礼；它们要被搬到营外，人要用火焚烧它们的皮、肉和粪。</span>
<span className="v" id="v28" data-v="28"> 焚烧它们的人要洗衣服，用水洗身，然后才可以进营。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 58:3; 民数记 29:7; 出埃及记 20:10"> “这要作你们永远的条例：七月初十日，你们要刻苦己心，不可做任何工作；无论是本地人，还是寄居在你们中间的外人，都要这样。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 33:8; 诗篇 51:2; 以弗所书 5:26"> 因为在这一天，要为你们赎罪，使你们洁净；你们在耶和华面前要从一切罪中得洁净。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 23:32; 以赛亚书 58:5; 利未记 25:4"> 这日是你们完全安息的安息日，你们要刻苦己心。这是永远的条例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:4; 出埃及记 29:29–30; 利未记 4:5"> 那受膏、承接圣职接替他父亲作祭司的祭司，要行赎罪礼；他要穿上细麻衣，就是圣衣。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 16:16; 利未记 16:24; 利未记 16:6"> 他要为圣所赎罪；也要为会幕和坛赎罪；又要为众祭司和会众的全体百姓赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="希伯来书 9:7; 希伯来书 9:25; 出埃及记 30:10"> “这要作你们永远的条例：因以色列人一切的罪，要一年一次为他们赎罪。”<br />这事照耶和华所吩咐摩西的做了。</span>
</div>
</div>

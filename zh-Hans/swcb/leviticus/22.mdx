<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 18:21; 申命记 15:19; 利未记 22:32"> “你要告诉亚伦和他的儿子们，要他们远离以色列人分别为圣归给我的圣物，免得亵渎我的圣名。我是耶和华。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="LORD 或 GOD 用全大写时，源自希伯来文 יהוה Yahweh；除非另有注明，是来自短式 יה Yah。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 7:20–21; 民数记 19:13; 诗篇 16:11"> “你要告诉他们：‘你们世世代代所有后裔中，若有人在自己污秽未除的时候，亲近以色列人分别为圣献给耶和华的圣物，那人必从我面前被剪除。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未记 11:39; 利未记 15:2–3; 利未记 15:13–16"> “‘亚伦的后裔中，凡患麻风病或有漏症的，不可吃圣物，直到他洁净。凡触碰因死人而不洁之物的，或触碰遗精之人的，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:43–44; 利未记 15:7; 利未记 15:19"> 或触碰任何会使他不洁的爬物，或触碰使他成为不洁的人，无论那人有什么不洁——</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 15:5; 希伯来书 10:22; 哈该书 2:13"> 触碰这些的人必不洁净到晚上；除非他用水洗身，否则不可吃圣物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:22; 申命记 18:3–4; 哥林多前书 9:13–14"> 日落以后，他就洁净了；然后他可以吃圣物，因为这是他的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 17:15; 出埃及记 22:31; 以西结 44:31"> 自死的或被野兽撕裂的，他不可吃，免得因它玷污自己。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 28:43; 民数记 18:22; 民数记 18:32"> “‘所以，他们要谨守我的吩咐，免得他们因亵渎圣物而担当罪，在罪中死亡。我是使他们成圣的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 12:4; 撒母耳记上 21:6; 出埃及记 29:33"> “‘外人不可吃圣物；寄居在祭司家中的外人，或雇工，都不可吃圣物。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:13; 出埃及记 12:44; 民数记 18:11–13"> 但祭司若用银钱买了奴仆，那人可以吃圣物；在他家中出生的人也可以吃他的食物。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:13; 利未记 21:3"> 祭司的女儿若嫁给外人，就不可吃圣物中的举祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 10:14; 创世记 38:11; 民数记 18:11–19"> 但祭司的女儿若成了寡妇，或被休，又没有孩子，回到父家，像她年轻时一样，就可以吃她父亲的食物；只是外人不可吃其中任何一点。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 27:15; 利未记 27:13; 利未记 5:15–19"> “‘若有人无意中吃了圣物，就要按圣物原值加上五分之一，交给祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 18:32; 利未记 19:8; 以西结 22:26"> 祭司不可亵渎以色列人献给耶和华的圣物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 22:9; 彼得前书 2:24; 以赛亚书 53:11–12"> 免得他们在吃自己圣物的时候，担当招致罪责的罪孽；因为我是使他们成圣的耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 1:2; 申命记 12:6; 民数记 15:3"> “你要告诉亚伦和他的儿子们，以及以色列众人，对他们说：‘凡以色列家中的人，或在以色列中的寄居者，献上供物，不论是为任何许愿，或为任何甘心祭，就是他们献给耶和华作燔祭的，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 1:10; 利未记 1:3; 以弗所书 5:27"> 为使你们蒙悦纳，你们要从牛、绵羊或山羊中献上一只无残疾的公牲畜。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 17:1; 玛拉基书 1:8; 申命记 15:21"> 凡有残疾的，你们不可献，因为它不能使你们蒙悦纳。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 15:8; 民数记 15:3; 利未记 3:6"> 凡向耶和华献平安祭，不论是为还愿，或是从牛群、羊群中献甘心祭，都必须是完全的，才可蒙悦纳；它不可有残疾。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:20; 玛拉基书 1:8; 利未记 1:9"> 瞎眼的、受伤的、残废的、长疣的、溃烂的、流脓疮的，你们不可献给耶和华，也不可把这些作为火祭献在坛上给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:18"> 牛或羊若有畸形或肢体缺少，你可以献作甘心祭；但为还愿献的，它不可蒙悦纳。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 22:20; 申命记 23:1; 利未记 21:20"> 睾丸碰伤、压碎、破裂或割掉的，你们不可献给耶和华；在你们的地上不可这样做。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 21:8; 以斯拉记 6:8–10; 民数记 15:14–16"> 这些你们也不可从外人的手中献为你们上帝的食物，因为它们里面有败坏，有残疾；它们不能使你们蒙悦纳。’”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华对摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:30; 利未记 19:23–24; 利未记 22:25"> “牛、绵羊或山羊出生以后，要同母七天；从第八天起，它就可蒙悦纳，作为献给耶和华的火祭供物。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 22:6–7; 申命记 14:21; 出埃及记 34:26"> 无论是母牛或母羊，你们不可在同一天宰杀它和它的幼崽。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="诗篇 116:17; 诗篇 107:22; 阿摩司 4:5"> “你们向耶和华献感谢祭的时候，要献得使你们蒙悦纳。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 7:15–18; 出埃及记 16:19–20; 利未记 19:7"> 祭物要在当天吃完；不可留到早晨。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 4:40; 利未记 19:37; 民数记 15:40"> “所以你们要遵守我的诫命，并且实行。我是耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:21; 路加福音 11:2; 马太福音 6:9"> 你们不可亵渎我的圣名；我必在以色列人中被尊为圣。我是使你们成圣的耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="LORD 或 GOD 用全大写时，源自希伯来文 יהוה Yahweh；除非另有注明，是来自短式 יה Yah。">b</a></sup>，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 11:45; 出埃及记 6:7; 利未记 25:38"> 是把你们从埃及地领出来、要作你们上帝的。我是耶和华。”</span>
</div>
</div>

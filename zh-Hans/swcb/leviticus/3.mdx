<span className="v" id="v1" data-v="1" data-xref="民数记 6:14; 利未记 1:3; 罗马书 5:1–2"> “『如果他的供物是平安祭的祭牲，若是从牛群中献的，无论公的母的，他都要把没有残疾的献在耶和华面前。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 29:10; 利未记 1:4–5; 使徒行传 2:36–38"> 他要按手在供物的头上，在会幕门口宰杀。亚伦的儿子们，就是祭司，要把血洒在祭坛的四周。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 4:8–9; 出埃及记 29:22"> 他要从平安祭的祭牲中，把火祭献给耶和华：就是遮盖内脏的脂肪和内脏上所有的脂肪，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:10; 利未记 8:25; 出埃及记 29:22"> 两个肾和肾上靠近腰部的脂肪，以及肝上的网子，连同肾一起取下。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:12; 出埃及记 29:13; 彼得前书 2:5"> 亚伦的儿子们要把这些烧在祭坛上的燔祭上，就是在火上的柴上；这是献给耶和华为馨香的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 2:11–12; 加拉太书 3:28; 利未记 1:2"> 『如果他献给耶和华作平安祭的供物是从羊群中取的，无论公的母的，他都要献上没有残疾的。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 8:62; 以弗所书 5:12; 利未记 17:8–9"> 如果他献一只羊羔作为供物，就要把它献在耶和华面前；</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 1:5; 以弗所书 3:12; 利未记 3:13"> 他要按手在供物的头上，在会幕前宰杀。亚伦的儿子们要把它的血洒在祭坛的四周。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 29:22; 利未记 9:19; 利未记 8:25"> 他要从平安祭的祭牲中，把火祭献给耶和华：它的脂肪，就是整条肥尾巴，要靠近脊骨取下；还有遮盖内脏的脂肪和内脏上所有的脂肪，</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 3:4"> 两个肾和肾上靠近腰部的脂肪，以及肝上的网子，连同肾一起取下。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 21:17; 利未记 21:6; 利未记 3:16"> 祭司要把这些烧在祭坛上；这是献给耶和华的火祭的食物。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 9:15; 以赛亚书 53:2; 哥林多后书 5:21"> 『如果他的供物是山羊，就要把它献在耶和华面前。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:8; 罗马书 5:15–21; 哥林多后书 5:21"> 他要按手在它的头上，在会幕前宰杀；亚伦的儿子们要把它的血洒在祭坛的四周。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:38; 马太福音 22:37; 利未记 3:9–11"> 他要从其中献上他的供物，作为献给耶和华的火祭：就是遮盖内脏的脂肪和内脏上所有的脂肪，</span>
<span className="v" id="v15" data-v="15"> 两个肾和肾上靠近腰部的脂肪，以及肝上的网子，连同肾一起取下。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 马太福音 22:37; 以赛亚书 53:10"> 祭司要把这些烧在祭坛上；这是火祭的食物，作为馨香的祭；所有的脂肪都是耶和华的。</span>
</div>

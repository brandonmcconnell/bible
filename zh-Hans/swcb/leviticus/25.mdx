<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="25" data-verses="55">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 加拉太书 4:24–25; 出埃及记 19:1"> 耶和华在西奈山对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:21; 利未记 26:34–35; 出埃及记 23:10"> “你要对以色列人说，告诉他们：你们到了我赐给你们的地，那地就要向耶和华守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:10"> 六年你要耕种田地，六年你要修剪葡萄园，收取地的果实；</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 36:21; 利未记 25:20–23; 出埃及记 23:10–11"> 但第七年，地要有完全安息的安息年，是向耶和华守的安息。你不可耕种田地，也不可修剪葡萄园。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:29; 以赛亚书 37:30"> 你收割后自生的庄稼，不可收割；未经修剪的葡萄树所结的葡萄，不可摘取。这一年，地要完全安息。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 2:44; 出埃及记 23:11; 使徒行传 4:34–35"> 地在安息年所出的，要给你们作食物；给你、你的仆人、婢女、雇工，以及在你那里寄居的外人。</span>
<span className="v" id="v7" data-v="7"> 也要给你的牲畜和你地上的野兽；地的一切出产都可作食物。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 23:15; 创世记 2:2"> “你要数算七个安息年，就是七个七年；这七个安息年的日子，共是四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:24; 利未记 23:27; 帖撒罗尼迦前书 1:8"> 到七月初十日，你要吹响宏亮的号角。在赎罪日，你们要在全地吹响号角。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:8; 以赛亚书 63:4; 彼得前书 2:16"> 你们要使第五十年分别为圣，在全地向所有居民宣告自由。这一年要作为你们的禧年；你们各人都要回到自己的产业，各人都要回到自己的家族。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 27:17; 利未记 25:4–5"> 第五十年要作为你们的禧年。在这一年，你们不可耕种；自生的庄稼不可收割；未经修剪的葡萄树所结的葡萄，也不可摘取。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 25:6–7"> 因为这是禧年，对你们是圣的；你们要吃田地自然的出产。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 25:10; 利未记 27:17–24; 民数记 36:4"> “在这禧年，你们各人都要回到自己的产业。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 19:13; 利未记 25:17; 撒母耳记上 12:3–4"> “如果你卖什么给邻舍，或从邻舍买什么，你们彼此不可亏负。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:18–23; 腓立比书 4:5"> 你要按禧年以后的年数从邻舍那里买；他要按收成的年数卖给你。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 25:27; 利未记 25:51"> 年数多，你就要提高价钱；年数少，你就要降低价钱；因为他卖给你的是收成的次数。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 19:14; 利未记 19:32; 利未记 25:43"> 你们彼此不可亏负，却要敬畏你的上帝；因为我是耶和华你们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 23:6; 申命记 12:10; 箴言 1:33"> “所以你们要遵行我的律例，谨守我的典章，并且实行；你们就可以在那地安然居住。</span>
<span className="v" id="v19" data-v="19" data-xref="约珥 2:26; 诗篇 85:12; 利未记 26:5"> 地必出产果实，你们要吃得饱足，在那里安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 25:4; 路加福音 12:29; 民数记 11:4"> 如果你们说：‘第七年我们吃什么呢？看哪，我们既不耕种，也不收取我们的出产；’</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 28:8; 箴言 10:22; 哥林多后书 9:10"> 那么，我必在第六年命令我的福临到你们，使地结出够三年用的果实。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 19:29; 利未记 26:10; 以赛亚书 37:30"> 第八年你们要耕种，却仍吃陈粮，直到第九年；等到第九年的出产收进来，你们仍要吃陈粮。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:11; 诗篇 39:12; 以西结 48:14"> “地不可永远出售，因为地是我的；你们在我这里是客旅，是寄居的。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 1:7; 利未记 25:51–53; 利未记 25:27"> 在你们所得为业的全地，要准许土地可以赎回。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路得记 2:20; 耶利米书 32:7–8; 路得记 3:12"> “如果你的弟兄贫穷，卖了自己的一部分产业，他至近的亲属就要来，赎回他弟兄所卖的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 5:7"> 如果一个人没有人替他赎回，后来自己富足，有足够的能力赎回，</span>
<span className="v" id="v27" data-v="27"> 他就要计算卖出以后的年数，把余款还给买主；他就可以回到自己的产业。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 35:9–10; 利未记 25:10; 彼得前书 1:4–5"> 但如果他没有能力为自己取回，所卖的就要留在买主手中，直到禧年。到了禧年，它就要归还，他就可以回到自己的产业。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> “如果有人卖了有城墙的城内的住宅，他卖了以后，可以在一整年内赎回；在整整一年内，他有赎回权。</span>
<span className="v" id="v30" data-v="30"> 如果满了一整年还没有赎回，那么有城墙城内的房屋就永远定归买主，世世代代归他；禧年也不得归还。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 49:7–8"> 但没有城墙环绕的村庄里的房屋，要算作乡间的田地：可以赎回，到了禧年也要归还。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:1–45; 民数记 35:1–8"> “然而，在利未人的城里，利未人所得为业城中的房屋，利未人随时可以赎回。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:20–24; 申命记 18:1–2"> 利未人可以赎回所卖的房屋，以及他所得为业城中的房屋；到了禧年，这房屋要归还；因为利未人城中的房屋，是他们在以色列人中所得的产业。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 25:23; 使徒行传 4:36–37; 民数记 35:2–5"> 只是他们城郊牧场的田地不可出售，因为那是他们永远的产业。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命记 15:7–8; 使徒行传 11:29; 利未记 25:25"> “如果你的弟兄贫穷，在你们中间无力维持自己，你就要扶持他；他要像寄居者和暂住者一样与你同住。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 22:25; 申命记 23:19–20; 以西结 18:8"> 不可向他收取利息或利润；只要敬畏你的上帝，使你的弟兄可以在你那里生活。</span>
<span className="v" id="v37" data-v="37"> 你借钱给他，不可收利息；把食物给他，也不可取利润。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 11:45; 民数记 15:41; 出埃及记 20:2"> 我是耶和华你们的上帝，曾把你们从埃及地领出来，为要把迦南地赐给你们，并作你们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 21:2; 列王纪上 9:22; 列王纪下 4:1"> “如果你的弟兄在你那里贫穷，卖身给你，你不可叫他像奴隶一样服侍。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 21:2–3"> 他要像雇工和暂住者一样在你那里；他要服侍你直到禧年。</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 25:28; 出埃及记 21:3; 约翰福音 8:32"> 到那时，他和他的儿女要一起离开你，回到自己的家族，回到他祖先的产业。</span>
<span className="v" id="v42" data-v="42" data-xref="利未记 25:55; 罗马书 6:22; 哥林多前书 7:21–23"> 因为他们是我的仆人，是我从埃及地领出来的；不可把他们当奴隶出售。</span>
<span className="v" id="v43" data-v="43" data-xref="歌罗西书 4:1; 利未记 25:46; 出埃及记 1:13–14"> 你不可苛刻地辖管他，却要敬畏你的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="出埃及记 12:44; 诗篇 2:8–9; 以赛亚书 14:1–2"> “至于你们可以拥有的男奴和女奴，要从你们四围的列国中买男奴和女奴。</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 56:3–6"> 此外，也可以从寄居在你们中间的外人的子女中买，并从他们在你们中间的家族，就是他们在你们地上所生的那些人中买；他们就可以作你们的产业。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 14:2; 利未记 25:43"> 你们可以把他们遗留给你们以后的子孙作产业，使他们成为产业；你们可以使他们永远作奴隶。但对你们的弟兄以色列人，你们彼此不可苛暴辖管。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="雅各书 2:5; 利未记 25:26; 撒母耳记上 2:7–8"> “如果在你那里寄居的外人或暂住者变得富足，而你在他身边的弟兄贫穷了，卖身给住在你们中间的外人或旅居者，或卖给外人家族中的人，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 5:5; 希伯来书 2:11–13; 利未记 25:35"> 他卖了以后，仍可以被赎回。他的弟兄中有一人可以赎回他；</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 25:26"> 或者他的叔伯，或叔伯的儿子，可以赎回他；他家族中任何至近的亲属都可以赎回他；如果他自己富足了，也可以赎回自己。</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 16:14; 以赛亚书 21:16; 利未记 25:53"> 他要和买主计算，从卖身给他的那一年起，直到禧年为止；卖身的价钱要按年数计算；他在买主那里要按雇工的年限计算。</span>
<span className="v" id="v51" data-v="51"> 如果还剩许多年，就要按这些年数，从买他的价银中归还他的赎价。</span>
<span className="v" id="v52" data-v="52"> 如果到禧年只剩不多年，就要和买主计算；按他服侍的年数归还他的赎价。</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 25:46; 利未记 25:43"> 他在那人那里要像逐年雇来的雇工；那人不可在你眼前苛刻地辖管他。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 21:2–3; 利未记 25:40–41; 以赛亚书 49:9"> 如果他没有这样被赎回，到了禧年，他和他的儿女就要一起得释放。</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 25:42; 以赛亚书 43:3; 出埃及记 13:3"> 因为以色列人对我来说是仆人；他们是我的仆人，是我从埃及地领出来的。我是耶和华你们的上帝。”</span>
</div>
</div>

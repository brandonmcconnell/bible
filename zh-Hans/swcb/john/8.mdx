<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1; 马可福音 11:1; 路加福音 19:37"> 耶稣却往橄榄山去。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 26:55; 路加福音 4:20; 路加福音 21:37"> 清晨，祂又来到圣殿，众人都来到祂那里。祂就坐下教导他们。</span>
<span className="v" id="v3" data-v="3"> 文士和法利赛人带来一个行淫时被抓的妇人。他们叫她站在中间，</span>
<span className="v" id="v4" data-v="4"> 就对耶稣说：“老师，这妇人是正在行淫时被当场抓到的。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 20:10; 申命记 22:21–24; 以西结 16:38–40"> 摩西在律法上吩咐我们，要把这样的妇人用石头打死。 祢怎么说呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 17:13; 路加福音 10:25; 传道书 3:7"> 他们说这话是为了试探祂，好找把柄来控告祂。<br />但耶稣弯下身，用指头在地上画字。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:1–5; 罗马书 2:21–25; 罗马书 2:1–3"> 他们不住地问祂，耶稣就直起腰来，对他们说：<span className="woj">“你们中间谁是没有罪的，谁就可以先拿石头打她。”</span></span>
<span className="v" id="v8" data-v="8"> 于是祂又弯下身，在地上画字。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="传道书 7:22; 罗马书 2:15; 约翰一书 3:20"> 他们听见这话，良心受到责备，就从老到少，一个一个地出去了。只剩下耶稣一人，还有那妇人依然站在中间。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 41:11–12"> 耶稣直起腰来，看见她，就说：<span className="woj">“妇人，那些控告你的人在哪里呢？没有人定你的罪吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 3:17; 约翰福音 5:14; 以赛亚书 1:16–18"> 她说：“主啊，没有。”<br />耶稣说：<span className="woj">“我也不定你的罪。去吧，从今以后不要再犯罪了。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU（联合圣经公会版）包含约翰福音 7:53–8:11，但加上了方括号，表明文本批评家对这段经文是否为原稿缺乏信心。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 12:46; 约翰福音 9:5; 约翰福音 12:35"> 后来，耶稣又对众人说：<span className="woj">“我就是世界的光。</span><span className="woj">跟从我的，绝不在黑暗里走，反而要得着生命的光。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 5:31–47"> 法利赛人就对祂说：“祢是为自己作见证，祢的见证不真。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 16:28; 约翰福音 13:3; 约翰福音 8:42"> 耶稣回答他们说：<span className="woj">“我即使为自己作见证，我的见证也是真的，因为我知道我从哪里来，往哪里去；你们却不知道我从哪里来，往哪里去。</span></span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:7; 约翰福音 7:24; 约翰福音 12:47"> <span className="woj">你们是按着肉体判断；我却不判断任何人。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:31; 约翰福音 8:29; 约翰福音 16:32"> <span className="woj">即使我判断，我的判断也是真的，因为我不是单独一人，还有差我来的父与我同在。</span></span>
<span className="v" id="v17" data-v="17" data-xref="申命记 19:15; 申命记 17:6; 希伯来书 10:28"> <span className="woj">你们的律法上也记着，两个人的见证是真的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:38; 约翰福音 8:58; 约翰福音 8:25"> <span className="woj">我是为自己作见证的，差我来的父也为我作见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:3; 约翰福音 8:54–55; 约翰福音 14:6–9"> 于是他们问祂：“祢的父在哪里？”<br />耶稣回答：<span className="woj">“你们既不认识我，也不认识我的父；你们若认识我，也就认识我的父。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:30; 约翰福音 7:8; 马可福音 12:41"> 这些话是耶稣在圣殿里教导人时，在库房旁边说的。没有人捉拿祂，因为祂的时候还没有到。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:34; 约翰福音 8:24; 哥林多前书 15:17–18"> 耶稣又对他们说：<span className="woj">“我要走了，你们会寻找我，并且你们会死在你们的罪中。我所去的地方，你们不能去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 8:52; 诗篇 22:6; 约翰福音 8:48"> 犹太人就说：“祂说<span className="woj">‘我所去的地方，你们不能去’</span>，难道祂要自杀吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:31; 约翰福音 17:14; 约翰福音 17:16"> 耶稣对他们说：<span className="woj">“你们是从下头来的，我是从上头来的；你们是属这世界的，我不是属这世界的。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 马可福音 16:16; 约翰福音 3:18"> <span className="woj">所以我对你们说，你们会死在你们的罪中；你们若不信我就是那一位</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“我是”。">b</a></sup><span className="woj">，就必死在你们的罪中。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:17–29; 路加福音 22:67; 约翰福音 1:22"> 他们就问祂：“祢到底是谁？”<br />耶稣对他们说：<span className="woj">“就是我从起初对你们所说的。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:15; 约翰福音 12:47–50; 约翰福音 8:40"> <span className="woj">关于你们，我有许多事要说，要判断。但差我来的是真实的，我从祂那里听见的，我就传给世人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 6:9; 约翰福音 8:43; 哥林多后书 4:3–4"> 他们不明白祂是在对他们说关于父的事。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 5:19; 约翰福音 5:30; 约翰福音 6:38"> 于是耶稣对他们说：<span className="woj">“当你们举起人子以后，必知道我就是那一位，并且知道我没有一件事是凭着自己做的。我说这些话，正是照着父所教导我的。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:38; 约翰福音 16:32; 约翰福音 4:34"> <span className="woj">差我来的与我同在。父没有撇下我独自一人，因为我常做祂所喜悦的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 7:31; 约翰福音 2:23; 约翰福音 11:45"> 耶稣说这些话的时候，就有许多人信了祂。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰二书 1:9; 约翰福音 15:4–9; 提摩太后书 3:14"> 于是耶稣对信祂的犹太人说：<span className="woj">“你们若恒常遵守我的道，就真是我的门徒了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 8:2; 约翰福音 8:36; 约翰福音 17:17"> <span className="woj">你们必认识真理，真理必叫你们得以自由。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:9; 约翰福音 8:39; 创世记 15:13"> 他们回答祂：“我们是亚伯拉罕的后裔，从来没有作过任何人的奴仆。祢怎么说<span className="woj">‘你们必得以自由’</span>呢？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="罗马书 6:16; 彼得后书 2:19; 箴言 5:22"> 耶稣回答他们：<span className="woj">“我确实地告诉你们，凡犯罪的，就是罪的奴仆。</span></span>
<span className="v" id="v35" data-v="35" data-xref="加拉太书 4:4–7; 路加福音 15:31; 罗马书 8:15–17"> <span className="woj">奴仆不能永远住在家里，儿子却永远住在家里。</span></span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 3:17; 加拉太书 5:1; 罗马书 8:2"> <span className="woj">所以，上帝的儿子若叫你们自由，你们就真自由了。</span></span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 2:14; 约翰福音 8:45–47; 约翰福音 7:1"> <span className="woj">我知道你们是亚伯拉罕的后裔，你们却想要杀我，因为你们心里容不下我的道。</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 5:19; 约翰福音 8:44; 约翰福音 8:41"> <span className="woj">我所说的，是我在我父那里看见的；你们所做的，是你们在你们父那里看见的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="加拉太书 3:7; 约翰福音 8:37; 罗马书 9:7"> 他们回答祂：“我们的父是亚伯拉罕。”<br />耶稣对他们说：<span className="woj">“你们若是亚伯拉罕的儿女，就会做亚伯拉罕所做的事。</span></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 8:26; 加拉太书 4:29; 加拉太书 4:16"> <span className="woj">我把从上帝那里听见的真理告诉了你们，现在你们却想要杀我。亚伯拉罕没有做过这样的事。</span></span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 64:8; 约翰福音 8:38; 以赛亚书 63:16"> <span className="woj">你们是在做你们父所做的事。”</span><br />他们就对祂说：“我们不是从淫乱生的。我们只有一位父，就是上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:49; 约翰福音 14:10; 约翰福音 17:8"> 耶稣对他们说：<span className="woj">“倘若上帝是你们的父，你们就会爱我，因为我是从上帝出来的，也是从上帝降临的。我不是凭着自己来的，而是祂差我来的。</span></span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 12:39–40; 罗马书 8:7–8; 约翰福音 7:17"> <span className="woj">你们为什么不明白我的话呢？无非是因为你们听不进去我的道。</span></span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 13:10; 约翰一书 3:12; 约翰一书 3:8–10"> <span className="woj">你们是出于你们的父魔鬼，你们就乐意去做你们父的私欲。他从起初就是杀人的，不守真理，因为他心里没有真理。他说谎是出于自己的本性，因为他本来就是说谎的，也是说谎之人的父。</span></span>
<span className="v" id="v45" data-v="45" data-xref="提摩太后书 4:3–4; 加拉太书 4:16; 约翰福音 18:37"> <span className="woj">至于我，因为我讲真理，你们就不信我。</span></span>
<span className="v" id="v46" data-v="46" data-xref="希伯来书 4:15; 约翰福音 16:8; 彼得前书 2:22"> <span className="woj">你们中间谁能指证我有罪呢？我既然讲真理，你们为什么不信我呢？</span></span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 10:26–27; 约翰二书 1:9; 约翰福音 18:37"> <span className="woj">出于上帝的，就听上帝的话；你们不听，因为你们不是出于上帝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="约翰福音 7:20; 约翰福音 8:52; 马太福音 10:5"> 犹太人回答祂说：“我们说祢是撒马利亚人，并且被鬼附了，难道说得不对吗？”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="彼得前书 2:23; 以赛亚书 49:3; 约翰福音 13:31–32"> 耶稣回答：<span className="woj">“我不是被鬼附的。我尊敬我的父，你们却侮辱我。</span></span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 5:41; 约翰福音 8:54; 约翰福音 7:18"> <span className="woj">我不寻求自己的荣耀；有一位为我寻求，并且施行判断。</span></span>
<span className="v" id="v51" data-v="51" data-xref="约翰福音 11:25–26; 约翰福音 5:24; 约翰福音 3:15–16"> <span className="woj">我确实地告诉你们，人若遵守我的道，就永远不见死。”</span></span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="约翰福音 9:24; 约翰福音 8:48; 希伯来书 2:9"> 犹太人对祂说：“现在我们知道祢是被鬼附的了。亚伯拉罕死了，众先知也死了，祢却说，<span className="woj">‘人若遵守我的道，就永远尝不到死味。’</span></span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 4:12; 罗马书 9:5; 希伯来书 7:1–7"> 难道祢比我们的父亚伯拉罕还大吗？他死了，众先知也死了。祢把自己当作什么人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="约翰福音 8:50; 箴言 25:27; 彼得后书 1:17"> 耶稣回答：<span className="woj">“我若荣耀自己，我的荣耀就算不得什么。荣耀我的是我的父，就是你们所说是你们上帝的那位。</span></span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 8:19; 约翰福音 8:44; 约翰福音 7:28–29"> <span className="woj">你们不认识祂，我却认识祂。我若说不认识祂，我就会像你们一样是个说谎的。但我认识祂，也遵守祂的道。</span></span>
<span className="v" id="v56" data-v="56" data-xref="希伯来书 11:13; 创世记 22:18; 加拉太书 3:7–9"> <span className="woj">你们的父亚伯拉罕欢欢喜喜地仰望我的日子，他看见了，就极其快乐。”</span></span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57"> 犹太人就对祂说：“祢还没有五十岁，岂见过亚伯拉罕呢？”</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="出埃及记 3:14; 歌罗西书 1:17; 约翰福音 17:5"> 耶稣对他们说：<span className="woj">“我确实地告诉你们，在亚伯拉罕出生以前，我就存在（我是）。”</span></span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="约翰福音 11:8; 约翰福音 10:30–33; 约翰福音 10:39–40"> 于是他们拿起石头要打祂；耶稣却躲藏起来，从他们中间穿过，走出了圣殿。</span>
</div>

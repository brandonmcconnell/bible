<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="7" data-verses="53">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 5:16–18; 约翰福音 4:3; 马太福音 21:38"> 这些事以后，耶稣在加利利游行，不愿在犹太游行，因为犹太人想要杀祂。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 14:16–19; 申命记 16:13–16; 出埃及记 23:16–17"> 那时犹太人的节期，就是住棚节，快到了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 约翰福音 7:5; 路加福音 8:19"> 于是祂的兄弟们对祂说：“离开这里上犹太去吧，叫祢的门徒也看见祢所做的事。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:20; 箴言 18:1–2; 马太福音 23:5"> 人要显扬名声，就没有在暗处做事的。祢既然做这些事，就当将自己显明给世人看。”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 3:21; 约翰福音 1:11–13; 弥迦书 7:5–6"> 因为连祂的兄弟们也不信祂。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:8; 约翰福音 2:4; 约翰福音 7:30"> 耶稣就对他们说：<span className="woj">“我的时候还没有到，你们的时候却常是方便的。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:18–19; 约翰福音 3:19; 加拉太书 4:16"> <span className="woj">世人不能恨你们，却是恨我，因为我指证他们的行为是恶的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 7:6; 约翰福音 8:20; 约翰福音 7:30"> <span className="woj">你们上去过节吧。我现在还不上去过这节，因为我的时候还没有满。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶稣说了这话，仍旧留在加利利。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司 5:13; 马太福音 10:16; 以赛亚书 42:2–3"> 但祂的兄弟们上去过节以后，祂也上去了，不是公开的，而是暗暗地去。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:56"> 犹太人在节期中寻找祂，说：“祂在哪里？”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 7:40–43; 约翰福音 9:16; 约翰福音 7:32"> 群众中有很多关于祂的私下议论。有人说：“祂是个好人。”另有人说：“不是，祂是迷惑群众的。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:22; 约翰福音 19:38; 约翰福音 20:19"> 只是因怕犹太人，没有人敢公开谈论祂。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:28; 路加福音 19:47; 约翰福音 7:37"> 到了节期过半，耶稣上圣殿去教导人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 马太福音 7:28–29; 马太福音 13:54"> 犹太人就很惊讶，说：“这个人没有学过，怎么会明白书卷呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:10; 约翰福音 14:24; 约翰福音 17:8"> 耶稣回答他们说：<span className="woj">“我的教导不是我自己的，乃是差我来者的。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:31–32; 约翰福音 8:43; 耶利米书 31:33–34"> <span className="woj">人若立志遵行祂的旨意，就必晓得这教导是出于上帝，还是我凭着自己说的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 5:41; 哥林多前书 10:31–33; 约翰福音 13:31–32"> <span className="woj">凭着自己说的人，是寻求自己的荣耀；但那寻求差祂来者之荣耀的，这人才是真实的，在祂心里没有不义。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 1:17; 约翰福音 11:53; 马太福音 12:14"> <span className="woj">摩西岂不是传了律法给你们吗？你们却没有一个人守律法。你们为什么想要杀我呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:20; 约翰福音 8:48; 约翰福音 8:52"> 众人回答说：“祢是被鬼附了！谁想要杀祢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:23; 约翰福音 5:2–11"> 耶稣回答他们说：<span className="woj">“我做了一件事，你们就都惊讶。</span></span>
<span className="v" id="v22" data-v="22" data-xref="利未记 12:3; 创世记 17:10–14; 罗马书 4:9–11"> <span className="woj">摩西传了割礼给你们（其实不是从摩西起的，而是从祖先起的），你们也在安息日给人行割礼。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:5; 约翰福音 5:14–16; 马太福音 12:2"> <span className="woj">既然人在安息日受割礼，是为了不违背摩西的律法，那么我在安息日叫一个人全身都痊愈了，你们就向我发怒吗？</span></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 11:3–4; 雅各书 2:9; 约翰福音 8:15"> <span className="woj">不可按外貌断定是非，总要按公义断定是非。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 7:10–11"> 于是，耶路撒冷人中有的说：“这不是他们想要杀的那个人吗？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:7–8; 约翰福音 7:48; 约翰福音 12:42"> 你看，祂公开发言，他们却不对祂说什么。难道官长们真的认出祂是基督了吗？</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 5:2; 约翰福音 7:41–42; 约翰福音 6:42"> 然而，我们知道这个人从哪里来；但基督来的时候，没有人知道祂从哪里来。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 8:42; 约翰福音 8:19; 约翰福音 8:26"> 耶稣在圣殿里教导人，大声喊着说：<span className="woj">“你们认识我，也知道我从哪里来。我不是凭着自己来的，但差我来的是真实的，你们不认识祂。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:55; 马太福音 11:27; 约翰福音 17:18"> <span className="woj">我认识祂，因为我是从祂来的，是祂差了我来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 8:20; 约翰福音 10:39; 约翰福音 7:6"> 他们就想要捉拿祂，只是没有人下手，因为祂的时候还没有到。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:42; 马太福音 12:23; 约翰福音 10:41–42"> 但群众中有许多人信了祂。他们说：“基督来的时候，所行的神迹难道会比这个人行的更多吗？”</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 18:3; 路加福音 22:52–53; 约翰福音 11:47–48"> 法利赛人听见群众这样私下议论祂，祭司长和法利赛人就差遣圣殿警卫去捉拿祂。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 16:5; 约翰福音 13:33; 马可福音 16:19"> 于是耶稣说：<span className="woj">“我还有一点点时间与你们同在，然后我就要回到差我来的那位那里去。</span></span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; 约翰福音 13:33–36; 约翰福音 14:6"> <span className="woj">你们要寻找我，却找不到；我所在的地方，你们不能去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="雅各书 1:1; 以赛亚书 11:12; 西番雅书 3:10"> 犹太人就彼此对问：“这个人要到哪里去，叫我们找不到祂呢？难道祂要到散居在希腊人中的犹太人那里去，教导希腊人吗？</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 3:9; 约翰福音 7:34; 约翰福音 12:34"> 祂说<span className="woj">‘你们要寻找我，却找不到’</span>以及<span className="woj">‘我所在的地方，你们不能去’</span>，这话是什么意思呢？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 55:1; 约翰福音 4:14; 约翰福音 6:35"> 节期的最后一天，也是最隆重的一天，耶稣站着高声说：<span className="woj">“人若渴了，可以到我这里来喝！</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:14; 以赛亚书 44:3; 以赛亚书 58:11"> <span className="woj">信我的人，就如经上所说，从他腹中将流出活水的江河来。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:17; 约珥 2:28; 约翰福音 14:16–17"> 耶稣这话是指着信祂之人要领受圣灵说的。那时圣灵还没有赐下来，因为耶稣还没有得着荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:11; 约翰福音 1:21; 约翰福音 6:14"> 群众中许多人听见这些话，就说：“这真是那先知。”</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:52; 约翰福音 1:46; 约翰福音 1:49"> 另有人说：“这是基督。”但也有人说：“基督怎么会从加利利出来呢？</span>
<span className="v" id="v42" data-v="42" data-xref="弥迦书 5:2; 马太福音 2:5; 路加福音 2:4"> 经上不是说，基督是出自大卫的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“种子”。">a</a></sup>，并且出自大卫本乡的伯利恒村吗？”</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 7:12"> 于是群众因着祂起了纷争。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 7:30; 使徒行传 23:11; 约翰福音 8:20"> 他们中间有人想捉拿祂，只是没有人下手。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 7:32; 使徒行传 5:21–27"> 那些警卫回到祭司长和法利赛人那里；他们问警卫：“你们为什么没有把祂带来？”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="马太福音 7:28–29; 路加福音 4:22; 约翰福音 7:26"> 警卫回答：“从来没有人像这个人那样说话的！”</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="约翰福音 7:12; 哥林多后书 6:8; 列王纪下 18:32"> 法利赛人回答他们：“你们也被迷惑了吗？</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 12:42; 哥林多前书 1:20; 哥林多前书 2:8"> 官长或法利赛人中，有谁信了祂呢？</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:20–21; 约翰福音 9:40; 约翰福音 9:34"> 但这群不明白律法的群众是该受咒诅的。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:39; 约翰福音 3:1–2"> 尼哥底母（就是从前夜里去见耶稣的那位，也是他们当中的一员）对他们说：</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命记 1:17; 申命记 19:15–19"> “不先听本人的申诉，不了解他所做的事，我们的律法难道就定他的罪吗？”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="约翰福音 7:41; 约翰福音 1:46; 以赛亚书 9:1–2"> 他们回答他说：“难道你也是出乎加利利吗？你去查考就能知道，加利利没有出过先知。”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="诗篇 33:10; 约伯记 5:12–13; 诗篇 76:10"> 于是各人都回自己的家去了，</span>
</div>
</div>

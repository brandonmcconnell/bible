<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 14:32; 马太福音 26:36; 撒母耳记下 15:23"> 耶稣说了这些话，就同门徒出去，渡过汲沦溪；在那里有一个园子，祂和门徒就进去了。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:37; 路加福音 22:39; 马可福音 11:11–12"> 出卖耶稣的犹大也知道那个地方，因为耶稣和门徒常常在那里聚集。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 18:12; 路加福音 22:47–53; 诗篇 22:12"> 于是犹大领了一队士兵，以及祭司长和法利赛人的警卫，拿着灯笼、火把和兵器，来到那里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 13:1; 约翰福音 18:7; 诗篇 27:3"> 耶稣知道将要临到自己的一切事，就走出来，对他们说：<span className="woj">“你们要找谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:11; 约翰福音 19:19; 马太福音 2:23"> 他们回答说：“找拿撒勒人耶稣。”<br />耶稣对他们说：<span className="woj">“我就是。”</span><br />出卖祂的犹大也和他们站在一起。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 27:2; 诗篇 70:2–3; 列王纪下 1:9–15"> 当耶稣对他们说<span className="woj">“我就是”</span>的时候，他们就往后退，倒在地上。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰福音 18:4"> 祂又问他们：<span className="woj">“你们要找谁？”</span><br />他们说：“找拿撒勒人耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:28; 马太福音 26:56; 哥林多后书 12:9"> 耶稣回答：<span className="woj">“我已经告诉你们，我就是。你们若找我，就让这些人走吧。”</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:12"> 这就应验了祂曾说过的话：<span className="woj">“祢所赐给我的人，我一个也没有失落。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 14:47; 马太福音 26:51–54; 路加福音 22:49–51"> 带着剑的西门·彼得就拔出剑来，将大祭司的仆人砍了一剑，削掉了他的右耳。那仆人名叫马勒古。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 20:22; 马太福音 26:39; 约翰福音 20:17"> 耶稣就对彼得说：<span className="woj">“把剑收回鞘里去！父所赐给我的杯，我岂能不喝呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:57; 约翰福音 18:3; 使徒行传 21:37"> 于是那队士兵、千夫长和犹太人的警卫拿住耶稣，把祂绑起来，</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 18:24; 约翰福音 11:51; 马太福音 26:3"> 先押到亚那那里；因为亚那是那年作大祭司的该亚法的岳父。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:49–52"> 这该亚法就是从前向犹太人提议“一个人替百姓死是有益的”那个人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:54; 马可福音 14:54; 马太福音 26:58–68"> 西门·彼得和另一个门徒跟着耶稣。那门徒是大祭司认识的，所以同耶稣一起进了大祭司的院子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:69; 马可福音 14:66–68; 路加福音 22:55–57"> 彼得却站在门外。大祭司认识的那门徒出来，对看门的婢女说了一声，就把彼得领了进去。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 26:69–70; 约翰福音 21:15; 路加福音 22:56–57"> 看门的婢女就对彼得说：“你不也是这个人的门徒吗？”<br />他说：“我不是。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 14:54; 约翰福音 18:25; 马可福音 14:67"> 因为天冷，仆人和警卫生了炭火，站在那里烤火。彼得也同他们站在一起烤火。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:55–65; 路加福音 20:20; 路加福音 22:63–71"> 大祭司就盘问耶稣关于祂的门徒和祂的教导。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:26; 以赛亚书 48:16; 马太福音 4:23"> 耶稣回答他说：<span className="woj">“我从来都是公开对世人讲话的。我常在会堂和圣殿里，就是犹太人聚集的地方教导人，我在暗地里并没有说什么。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:59–60; 使徒行传 24:12–13; 路加福音 22:67"> <span className="woj">你为什么问我呢？去问那些听过我讲话的人吧；看哪，我所说的，他们都知道。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 19:3; 马可福音 14:65; 路加福音 22:63–64"> 耶稣说了这话，旁边站着的一个警卫就打了耶稣一巴掌，说：“祢这样回答大祭司吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:20–23; 哥林多后书 10:1; 马太福音 5:39"> 耶稣回答他：<span className="woj">“我若说错了，你可以指证错在哪里；我若说得对，你为什么打我呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:13; 马太福音 26:57"> 亚那就把耶稣绑着押解到大祭司该亚法那里去。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 14:67–72; 约翰福音 18:17–18; 创世记 18:15"> 西门·彼得正站着烤火。有人对他说：“你不也是祂的门徒吗？”<br />彼得否认说：“我不是。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 18:1; 约翰福音 18:10; 马太福音 26:73"> 有大祭司的一个仆人，是彼得削掉耳朵那人的亲戚，说：“我不是看见你同祂在园子里吗？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 13:38; 马可福音 14:71–72; 路加福音 22:60–62"> 彼得再次否认；立刻，鸡就叫了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 18:33; 约翰福音 19:9; 马太福音 27:27"> 清晨，众人将耶稣从该亚法那里押往总督府。他们自己却没有进总督府，免得染了污秽，不能吃逾越节的筵席。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 27:23; 马可福音 15:2–5; 马太福音 27:11–14"> 于是彼拉多出来见他们，说：“你们拿什么罪名控告这个人？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 3:13; 路加福音 20:19–26; 马可福音 10:33"> 他们回答他说：“这个人若不是作恶的，我们就不会把祂交给你了。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 19:6–7; 约翰福音 19:15; 使徒行传 25:18–20"> 彼拉多就对他们说：“你们自己把祂带去，按着你们的律法审判祂吧。”<br />犹太人对他说：“我们没有杀人的权力。”</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:14; 马太福音 20:19; 马太福音 26:2"> 这就应验了耶稣指着自己将要怎样死所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 23:3–4; 约翰福音 18:37; 约翰福音 19:3"> 于是彼拉多又进了总督府，叫耶稣来，对祂说：“祢是犹太人的王吗？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 耶稣回答他：<span className="woj">“这话是你自己说的，还是别人论到我时对你说的？”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行传 18:14–16; 尼希米记 4:2; 罗马书 3:1–2"> 彼拉多回答：“难道我是犹太人吗？祢本国的人和祭司长把祢交给我。祢做了什么事？”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="路加福音 17:20–21; 歌罗西书 1:12–14; 罗马书 14:17"> 耶稣回答：<span className="woj">“我的国不属这世界。我的国若属这世界，我的部下就会争战，使我不至于被交给犹太人。只是我的国不属这世界。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 约翰福音 8:47; 约翰福音 8:14"> 彼拉多就对祂说：“那么，祢是一个王吗？”<br />耶稣回答：<span className="woj">“你说我是王。我为此而生，也为此来到世上，特要为真理作见证。凡属真理的人，必听我的声音。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 19:4; 路加福音 23:4; 约翰福音 19:6"> 彼拉多对祂说：“真理是什么？”<br />他说了这话，又出来到犹太人那里，对他们说：“我查不出祂有什么罪。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:15–18; 路加福音 23:16–23; 马可福音 15:6–14"> 但你们有个规矩，要我在逾越节给你们释放一个囚犯。你们要我给你们释放这犹太人的王吗？”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:25; 马可福音 15:15; 马太福音 27:16"> 他们就又喊叫说：“不要这个人，要巴拉巴！”这巴拉巴是个强盗。</span>
</div>
</div>

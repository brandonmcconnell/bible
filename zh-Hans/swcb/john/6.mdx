<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 6:31–44; 约翰福音 6:23; 路加福音 5:1"> 这些事以后，耶稣渡过加利利海，也就是提比哩亚海。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:24–25; 马太福音 12:15; 马太福音 15:30–31"> 有一大群人跟着祂，因为看见祂在病人身上所行的神迹。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 6:15; 路加福音 9:28; 路加福音 6:12–13"> 耶稣上了山，和门徒一同坐在那里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 2:13; 约翰福音 11:55; 约翰福音 5:1"> 那时犹太人的逾越节近了。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 15:33; 路加福音 9:12–13; 马太福音 14:14–15"> 耶稣举目看见一大群人向祂走来，就对腓力说：<span className="woj">“我们去哪里买饼叫这些人吃呢？”</span></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 22:1; 申命记 13:3; 历代志下 32:31"> 祂说这话是为了试验他，因为祂自己知道要怎么做。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数记 11:21–22; 马可福音 6:37; 约翰福音 12:5"> 腓力回答祂：“就是两百个银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="银币即得拿利（denarius），约为一个农业工人一天的工资，所以两百个银币大约是六到七个月的工资。">a</a></sup>的饼，叫他们各人吃一点，也是不够的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:40–44; 马太福音 4:18"> 祂的一个门徒，就是西门·彼得的兄弟安得烈，对祂说：</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 4:42–44; 马太福音 14:17; 马可福音 6:38"> “这里有一个男孩，带着五个大麦饼和两条鱼，只是分给这么多人，还算得什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:14–16; 马太福音 15:35–36; 马可福音 6:39–41"> 耶稣说：<span className="woj">“叫众人坐下。”</span>那地方草多。男人们就坐下，数目约有五千。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:23; 帖撒罗尼迦前书 5:18; 马太福音 15:36"> 耶稣拿起饼，祝谢了，就分给门徒，门徒又分给坐着的人；鱼也照样分了，都随着他们所要的。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:53; 尼希米记 9:25; 尼希米记 8:10"> 他们吃饱了，耶稣对门徒说：<span className="woj">“把剩下的零碎收拾起来，免得有任何糟蹋。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 列王纪下 4:2–7; 哥林多后书 9:8–9"> 他们就把那五个大麦饼的零碎，就是众人吃剩的，收拾起来，装满了十二个篮子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 18:15–18; 马太福音 21:11; 使徒行传 7:37"> 众人看见耶稣所行的神迹，就说：“这真是那要来到世上的先知。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:36; 约翰福音 6:15–21; 约翰福音 7:3–4"> 耶稣察觉到他们要来强逼祂作王，就独自又退到山上去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了傍晚，祂的门徒下到海边，</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:45; 约翰福音 6:24–25; 约翰福音 2:12"> 上了船，要渡海往迦百农去。天已经黑了，耶稣还没有来到他们那里。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 107:25; 诗篇 135:7; 马太福音 14:24"> 狂风大作，海面翻腾起来。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 6:47–49; 马太福音 14:25–26; 约伯记 9:8"> 他们摇橹约行了二十五或三十斯他迪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十五到三十斯他迪（stadia）大约是五到六公里，或三到四英里。">b</a></sup>，看见耶稣在海面上走 ，渐渐靠近船，他们就害怕起来。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 14:27–31; 以赛亚书 43:1–2; 以赛亚书 44:8"> 但祂对他们说：<span className="woj">“是我。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“我是”。">c</a></sup><span className="woj">不要怕。”</span></span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:51; 马太福音 14:32–33; 启示录 3:20"> 于是他们欣然接祂上船，船立刻就到了他们要去的地方。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45; 马太福音 14:22; 约翰福音 6:2"> 第二天，站在海对岸的群众发现那里除了门徒上的那一艘之外，没有别的船，而且耶稣没有同门徒上船，而是门徒自己去的。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:1; 约翰福音 6:11–12"> 然而，有几艘从提比哩亚来的船，停在靠近主祝谢后众人吃饼的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:17; 路加福音 8:40; 马可福音 6:53"> 众人见耶稣和门徒都不在那里，就自己上了船，往迦百农去寻找耶稣。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:38–39; 马太福音 23:7"> 他们在海对岸找到祂，就问祂：“拉比，祢什么时候到这里来的？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各书 4:3–4; 腓立比书 3:19; 腓立比书 2:21"> 耶稣回答他们：<span className="woj">“我确实地告诉你们，你们找我，并不是因为看见了神迹，而是因为吃饼得饱。</span></span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 3:2; 以赛亚书 55:2; 约翰福音 6:54"> <span className="woj">不要为那必朽坏的食物劳力，而要为那存到永生的食物劳力，就是人子要赐给你们的。因为父上帝已经印证了祂。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 16:30; 使徒行传 9:6; 马太福音 19:16"> 于是他们问祂：“我们该做什么，才算做上帝的工作呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰一书 3:23; 使徒行传 16:31; 约翰福音 3:36"> 耶稣回答他们：<span className="woj">“信上帝所差来的那位，这就是上帝的工作。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:37; 约翰福音 10:38; 哥林多前书 1:22"> 他们又问祂：“那么，祢行什么神迹叫我们看了就信祢呢？祢做什么工作呢？</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 9:15; 诗篇 105:40; 诗篇 78:24–25"> 我们的祖先在旷野吃过吗哪，正如经上所记：‘祂赐给他们从天上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希腊语和希伯来语对“天”、“诸天”、“天空”和“空气”使用同一个词。">d</a></sup>来的饼吃。’”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:1; 约翰福音 6:58; 出埃及记 16:4"> 耶稣对他们说：<span className="woj">“我确实地告诉你们，那从天上来的饼不是摩西赐给你们的，乃是我父将天上真正的饼赐给你们。</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:42; 约翰福音 17:8; 约翰福音 3:13"> <span className="woj">因为上帝的饼就是那从天上降下来，赐生命给世界的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 4:15; 约翰福音 6:26; 诗篇 4:6"> 他们就对祂说：“主啊，求祢常把这饼赐给我们。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:48–58; 启示录 22:17; 约翰福音 6:41"> 耶稣对他们说：<span className="woj">“我就是生命的饼。到我这里来的，必永远不饿；信我的，必永远不渴。</span></span>
<span className="v" id="v36" data-v="36" data-xref="彼得前书 1:8–9; 路加福音 16:31; 约翰福音 12:37"> <span className="woj">只是我告诉过你们，你们已经看见我了，却还是不信。</span></span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 11:28; 约翰福音 6:39; 约翰福音 17:24"> <span className="woj">凡父所赐给我的人，必到我这里来；到我这里来的，我绝不丢弃他。</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 5:30; 约翰福音 4:34; 约翰福音 3:31"> <span className="woj">因为我从天上降下来，不是要按自己的意愿行，而是要按差我来者的意愿行。</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 17:12; 约翰福音 6:40; 约翰福音 18:9"> <span className="woj">差我来者之父的意愿就是：凡祂所赐给我的，叫我一个也不失落，在末日却叫他复活。</span></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:54; 约翰福音 5:24; 罗马书 6:23"> <span className="woj">差我来者的意愿就是：叫一切看见子而信祂的人得永生；并且在末日我要叫他复活。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰福音 6:51–52; 约翰福音 6:48; 约翰福音 6:33"> 犹太人因为祂说<span className="woj">“我是从天上降下来的饼”</span>，就私下议论祂。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 4:22; 马可福音 6:3; 马太福音 13:55–56"> 他们说：“这不就是约瑟的儿子耶稣吗？祂的父母我们都认识。祂怎么现在说<span className="woj">‘我是从天上降下来的’</span>呢？”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="希伯来书 4:13; 约翰福音 6:64; 马可福音 9:33"> 耶稣回答他们说：<span className="woj">“你们不要私下议论。</span></span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 6:65; 约翰福音 6:39–40; 马太福音 11:25–27"> <span className="woj">若不是差我来的父吸引人，就没有人能到我这里来；到我这里来的，在末日我要叫他复活。</span></span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 54:13; 耶利米书 31:33–34; 希伯来书 10:16"> <span className="woj">先知书上记着说：‘他们都要受上帝的教导。’</span><span className="woj">凡听见父的教导并学习的，就到我这里来。</span></span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 1:18; 约翰福音 7:29; 马太福音 11:27"> <span className="woj">这不是说有人看见过父，唯独从上帝来的那位，祂才看见过父。</span></span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:36; 歌罗西书 3:3–4; 罗马书 5:9–10"> <span className="woj">我确实地告诉你们，信我的人有永生。</span></span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 6:51; 哥林多前书 11:24–25; 哥林多前书 10:16–17"> <span className="woj">我就是生命的饼。</span></span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 10:3–5; 犹大书 1:5; 撒迦利亚书 1:5"> <span className="woj">你们的祖先在旷野吃过吗哪，还是死了。</span></span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 6:33; 约翰福音 6:51; 罗马书 8:10"> <span className="woj">这是从天上降下来的饼，叫人吃了就不死。</span></span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 22:19; 约翰福音 6:33; 希伯来书 10:5–12"> <span className="woj">我就是从天上降下来的生命之饼。人若吃这饼，就必永远活着。是的，我为世人的生命所赐的饼，就是我的肉。”</span></span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 6:41"> 因此，犹太人彼此争论说：“这个人怎么能把祂的肉给我们吃呢？”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="约翰一书 5:12; 马太福音 26:26–28; 约翰福音 6:55"> 耶稣对他们说：<span className="woj">“我确实地告诉你们，你们若不吃人子的肉，不喝祂的血，你们里面就没有生命。</span></span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 6:39–40; 约翰福音 6:27; 腓立比书 3:7–10"> <span className="woj">吃我肉、喝我血的人就有永生，在末日我要叫他复活。</span></span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 15:1; 约翰福音 8:31; 约翰福音 6:32"> <span className="woj">因为我的肉是真正的食物，我的血是真正的饮料。</span></span>
<span className="v" id="v56" data-v="56" data-xref="约翰一书 3:24; 约翰福音 15:4–5; 约翰福音 14:20"> <span className="woj">吃我肉、喝我血的人常在我里面，我也常在他里面。</span></span>
<span className="v" id="v57" data-v="57" data-xref="加拉太书 2:20; 约翰福音 5:26; 约翰福音 17:21"> <span className="woj">永活的父怎样差我来，我又因父活着；照样，吃我肉的人也要因我活着。</span></span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 3:36; 约翰福音 6:47–51; 约翰福音 6:41"> <span className="woj">这就是从天上降下来的饼，不像你们的祖先吃过吗哪还是死了。吃这饼的人必永远活着。”</span></span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 6:24; 箴言 8:1–3; 路加福音 4:31"> 这些话是耶稣在迦百农会堂里教导人时说的。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="约翰福音 6:66; 约翰福音 8:43; 约翰福音 8:31"> 祂的门徒中有许多人听见，就说：“这话甚难！谁能听得进去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="约翰福音 2:24–25; 约翰福音 6:64; 约翰福音 21:17"> 耶稣心里知道门徒为这事私下议论，就对他们说：<span className="woj">“这话使你们跌倒吗？</span></span>
<span className="v" id="v62" data-v="62" data-xref="马可福音 16:19; 约翰福音 3:13; 约翰福音 17:4–5"> <span className="woj">倘若你们看见人子升到祂本来所在的地方，那会怎样呢？</span></span>
<span className="v" id="v63" data-v="63" data-xref="加拉太书 5:25; 希伯来书 4:12; 诗篇 119:93"> <span className="woj">赐人生命的是圣灵，肉体是无益的。我对你们所说的话就是灵，就是生命。</span></span>
<span className="v" id="v64" data-v="64" data-xref="约翰福音 10:26; 提摩太后书 2:19; 希伯来书 4:13"> <span className="woj">只是你们中间有些人不信。”</span>因为耶稣从起头就知道谁是不信的，谁是要出卖祂的。</span>
<span className="v" id="v65" data-v="65" data-xref="约翰福音 6:44–45; 约翰福音 6:37; 约翰福音 3:27"> 祂又说：<span className="woj">“所以我对你们说过，若不是蒙我父的恩赐，没有人能到我这里来。”</span></span>
</div>

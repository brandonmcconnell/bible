<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="2" data-verses="25">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:46; 箴言 31:10–12; 约翰福音 21:2"> 第三天，在加利利的迦拿有一个婚宴。耶稣的母亲在那里。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:40–49; 马太福音 10:40–42; 哥林多前书 7:39"> 耶稣和祂的门徒也受邀参加了婚宴。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 104:15; 腓立比书 4:6; 以赛亚书 24:11"> 酒用尽了，耶稣的母亲对祂说：“他们没有酒了。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:6; 约翰福音 13:1; 约翰福音 7:30"> 耶稣对她说：<span className="woj">“妇人，这与你我有什么相干？我的时候还没有到。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:14; 创世记 6:22; 希伯来书 11:8"> 祂的母亲对仆人们说：“祂吩咐你们什么，你们就做什么。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:25; 希伯来书 9:10; 以弗所书 5:26"> 照犹太人洁净礼的规矩，那里放着六口石水缸，每口可容纳两三米特里<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="两三米特里（metretes）大约是20到30美制加仑，或75到115升。">a</a></sup>。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 4:2–6; 约翰福音 2:5; 约翰福音 2:3"> 耶稣对仆人们说：<span className="woj">“把缸倒满水。”</span>他们就倒满了，直到缸口。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 2:9; 箴言 3:5–6; 罗马书 13:7"> 祂又对他们说：<span className="woj">“现在舀出来，端给宴席的总管。”</span>他们就端去了。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 4:46; 约翰福音 7:17; 诗篇 119:100"> 宴席的总管尝了那水变的酒，并不知道是从哪里来的（只有舀水的仆人知道），总管就叫来新郎，</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 7:16–17; 箴言 9:1–6; 路加福音 16:25"> 对他说：“大家都是先上好酒，等客人喝足了，才上差的。你却把好酒留到现在！”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:30–31; 约翰福音 1:14; 约翰福音 3:2"> 耶稣在加利利的迦拿行了这头一件神迹，显明了祂的荣光，祂的门徒就信祂了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:46; 马太福音 13:55–56; 马可福音 6:3"> 这事以后，耶稣同祂的母亲、兄弟和门徒下到迦百农去；他们在那里住了几天。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:41; 约翰福音 11:55; 约翰福音 2:23"> 犹太人的逾越节近了，耶稣就上耶路撒冷去。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 19:45–46; 马可福音 11:15; 马可福音 11:17"> 祂发现圣殿里有人在卖牛、羊、鸽子，还有兑换银钱的人坐在那里。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:6; 撒迦利亚书 4:6; 哥林多后书 10:4"> 祂就用绳子做成一条鞭子，把所有的牛羊都从殿里赶出去；倒出兑换银钱之人的钱币，推翻他们的桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:13; 耶利米书 7:11; 马可福音 11:17"> 又对卖鸽子的人说：<span className="woj">“把这些东西拿走！不要把我父的殿当作集市！”</span></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:9; 诗篇 119:139"> 祂的门徒想起经上记着说：“我为祢的殿心里焦急，如同火烧。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 21:23; 马可福音 8:11; 马可福音 11:27–28"> 因此犹太人质问祂说：“祢既然做这些事，能显什么神迹给我们看呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:58; 马可福音 15:29; 马太福音 27:40"> 耶稣回答他们说：<span className="woj">“拆毁这座圣殿，三天内我必将它重建起来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 犹太人就说：“这座圣殿建了四十六年！祢要在三天内重建它吗？”</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 以弗所书 2:20–22"> 但耶稣所说的圣殿，是指祂的身体。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 12:16; 约翰福音 16:4; 路加福音 24:7–8"> 所以当祂从死里复活之后，祂的门徒想起祂说过这话，就信了圣经和耶稣所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 7:31; 路加福音 8:13; 约翰福音 6:14"> 逾越节期间，耶稣在耶路撒冷过节的时候，许多人看见祂所行的神迹，就信了祂的名。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:64; 希伯来书 4:13; 使徒行传 1:24"> 但耶稣却不将自己交托给他们，因为祂了解每一个人，</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 13:11; 马太福音 9:4; 约翰福音 6:64"> 也不需要谁来见证人是怎样的；因为祂自己知道人的心里存的是什么。</span>
</div>
</div>

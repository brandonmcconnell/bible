<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="19" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 53:5; 以赛亚书 50:6; 马太福音 20:19"> 于是彼拉多把耶稣带去鞭打。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 15:16–20; 路加福音 23:11; 马太福音 27:27–31"> 士兵们用荆棘编作冠冕，戴在祂头上，又给祂穿上紫袍。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 27:29; 马太福音 26:49; 路加福音 1:28"> 他们上前对祂说：“万岁，犹太人的王！”并用手打祂。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:38; 约翰福音 19:6; 路加福音 23:4"> 彼拉多又出来对众人说：“看哪，我把祂领出来交给你们，好叫你们知道我查不出祂有什么罪。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:2; 希伯来书 12:2; 以赛亚书 7:14"> 耶稣出来了，戴着荆棘冠冕，穿着紫袍。彼拉多对他们说：“你们看这个人！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:31; 约翰福音 19:4; 使徒行传 2:23"> 祭司长和警卫看见祂，就喊叫说：“钉十字架！钉十字架！”<br />彼拉多对他们说：“你们自己把祂带去钉十字架吧，因为我查不出祂有什么罪。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未记 24:16; 约翰福音 5:18; 马太福音 26:63–66"> 犹太人回答他：“我们有律法，按着我们的律法，祂是该死的，因为祂自称是上帝的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 19:13; 使徒行传 14:11–19"> 彼拉多听见这话，就越发害怕。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 18:33; 诗篇 38:13–15; 腓立比书 1:28"> 他又进了总督府，对耶稣说：“祢是从哪里来的？”耶稣却不回答他。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理 5:19; 约翰福音 18:39; 但以理 3:14–15"> 彼拉多就对祂说：“祢不对我说话吗？祢不知道我有权力释放祢，也有权力把祢钉十字架吗？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:1; 约翰福音 3:27; 使徒行传 2:23"> 耶稣回答：<span className="woj">“若不是从上头赐给你的，你就毫无权力办我。所以，把我交给你的那人，罪更重了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 17:6–7; 约翰福音 18:33–36; 马可福音 6:16–26"> 从此彼拉多想要释放祂，犹太人却喊叫说：“你若释放这个人，就不是凯撒的朋友！凡自称为王的，就是背叛凯撒！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 82:5–7; 马太福音 27:19; 阿摩司 4:7"> 彼拉多听见这些话，就带耶稣出来，在一个名叫“铺华石处”（希伯来语叫“厄巴大”）的地方，坐在审判席上。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:62; 约翰福音 19:5; 马可福音 15:25"> 那天是逾越节的预备日，大约是第六个时辰。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“第六个时辰”按罗马计时法是早上6:00，或按当时使用的犹太计时法是正午。">a</a></sup>彼拉多对犹太人说：“看哪，你们的王！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 23:18; 使徒行传 21:36; 约翰福音 19:6"> 他们喊叫说：“除掉祂！除掉祂！把祂钉十字架！”<br />彼拉多对他们说：“我可以把你们的王钉十字架吗？”<br />祭司长回答：“除了凯撒，我们没有王！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:24–25; 马太福音 27:26–31; 马可福音 15:15–20"> 于是彼拉多把耶稣交给他们去钉十字架。他们就接管了耶稣，把祂带走。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:33; 路加福音 14:27; 路加福音 23:26"> 耶稣自己背着十字架出来，到了一个名叫“髑髅地”的地方，希伯来语叫“各各他”；</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:12; 马可福音 15:24–27; 加拉太书 3:13"> 他们就在那里把祂钉在十字架上，还有两个人同祂一起被钉，一边一个，耶稣在中间。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 27:37; 路加福音 23:38; 马可福音 15:26"> 彼拉多又写了一个牌子，钉在十字架上。上面写着：“拿撒勒人耶稣，犹太人的王。”</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 26:14; 启示录 16:16; 使徒行传 22:2"> 许多犹太人读了这牌子，因为耶稣被钉十字架的地方靠近城，并且牌子是用希伯来文、拉丁文和希腊文写的。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 19:14; 约翰福音 19:19"> 犹太人的祭司长就对彼拉多说：“不要写‘犹太人的王’，要写‘祂自己说：我是犹太人的王’。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 76:10; 诗篇 65:7; 箴言 8:29"> 彼拉多回答：“我写了什么，就写了什么。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="路加福音 23:34; 马可福音 15:24; 马太福音 27:35"> 士兵把耶稣钉在十字架上之后，拿祂的衣服分为四份，每个士兵一份；又拿了祂的内衣。这件内衣没有缝线，是上下整件织成的。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 22:18; 约翰福音 19:28; 约翰福音 19:36–37"> 于是他们彼此说：“我们不要撕破它，我们来抽签，看谁能得着。”这要应验经上的话说：<br /><span className="pl pl-1">“他们分了我的外衣，</span><br /><span className="pl pl-2">又为我的内衣抽签。”</span><br />士兵果然做了这些事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 23:49; 马太福音 27:55–56; 约翰福音 20:1"> 站在耶稣十字架旁边的，有祂的母亲、祂母亲的姐妹、革罗罢的妻子马利亚，还有抹大拉的马利亚。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 21:24; 约翰福音 20:2; 约翰福音 2:4"> 耶稣看见母亲和祂所爱的那门徒站在旁边，就对母亲说：<span className="woj">“妇人，看哪，你的儿子！”</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:48–50; 约翰福音 16:32; 提摩太前书 5:2–4"> 然后又对那门徒说：<span className="woj">“看哪，你的母亲！”</span>从那个时辰起，那门徒就把她接到了自己家里。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="诗篇 69:21; 诗篇 22:15; 约翰福音 19:30"> 这事以后，耶稣知道<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU（联合圣经公会版）和TR（公认文本）作“知道”，而不是“看见”。">b</a></sup>一切的事都已经成就了，为要应验经上的话，就说：<span className="woj">“我渴了！”</span></span>
<span className="v" id="v29" data-v="29" data-xref="民数记 19:18; 路加福音 23:36; 马可福音 15:36"> 那里放着一个盛满酸酒的器皿；他们就拿海绵蘸满了酸酒，绑在牛膝草上，送到祂嘴边。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 17:4; 腓立比书 2:8; 歌罗西书 2:14–17"> 耶稣尝了那酸酒，就说：<span className="woj">“成了！”</span>随后低下头，交出了祂的灵。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 19:14; 约翰福音 19:42; 马可福音 15:42"> 因为那天是预备日，为了不让尸体在安息日留在十字架上（因为那安息日是个大日子），犹太人就求彼拉多打断他们的腿，把尸体拿下来。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 19:18; 路加福音 23:39–43"> 于是士兵上前，把同耶稣一起钉十字架的第一和第二人的腿都打断了；</span>
<span className="v" id="v33" data-v="33"> 只是来到耶稣那里，见祂已经死了，就没有打断祂的腿。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰一书 5:6; 撒迦利亚书 12:10; 撒迦利亚书 13:1"> 然而，有一个士兵拿枪扎了祂的肋旁，立刻有血和水流出来。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 21:24; 希伯来书 2:3–4; 约翰一书 1:1–3"> 那看见这事的人作了见证，他的见证是真的。他知道自己说的是真的，好叫你们也信。</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 34:20; 民数记 9:12; 出埃及记 12:46"> 这些事发生，为要应验经上的话：“祂的骨头一根也不可折断。”</span>
<span className="v" id="v37" data-v="37" data-xref="撒迦利亚书 12:10; 启示录 1:7; 诗篇 22:16–17"> 经上又有一处说：“他们要仰望自己所扎的人。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马可福音 15:42–47; 马太福音 27:57–61; 箴言 29:25"> 这些事以后，亚利马太的约瑟求彼拉多，允许他把耶稣的遗体取下来。他本是耶稣的门徒，只因怕犹太人，所以是暗暗地作门徒。彼拉多准许了。他就去把耶稣的遗体取下来。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:50–52; 雅歌 4:14; 约翰福音 3:1–21"> 起初夜里去见耶稣的尼哥底母也来了，带着没药和沉香的混合物，大约有一百罗马斤。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="100罗马斤，每斤12盎司，大约是72磅，或33公斤。">c</a></sup></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 11:44; 约翰福音 20:5–7; 使徒行传 5:6"> 他们就照犹太人殡葬的规矩，把耶稣的遗体用细麻布加上香料裹好。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:53; 马太福音 27:60; 约翰福音 20:15"> 在耶稣钉十字架的地方有一个园子，园子里有一座新坟墓，是从未安葬过人的。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 19:31; 约翰福音 19:14; 以赛亚书 53:9"> 因为那天是犹太人的预备日，而那座坟墓又近，他们就把耶稣安放在那里。</span>
</div>
</div>

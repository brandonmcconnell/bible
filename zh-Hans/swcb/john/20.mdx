<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="20" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:9; 马太福音 27:60; 约翰福音 19:25"> 一周的第一天清晨，天还黑着的时候，抹大拉的马利亚来到坟墓那里，看见石头已经从坟墓挪开了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:23; 约翰福音 20:13; 约翰福音 21:24"> 于是她跑去见西门·彼得和耶稣所爱的那另一个门徒，对他们说：“有人把主从坟墓里移走了，我们不知道他们把祂放在哪里了！”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 彼得和那另一个门徒就出来，往坟墓那里去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:23; 哥林多后书 8:12; 哥林多前书 9:24"> 两人同跑，但那另一个门徒跑得比彼得快，先到了坟墓。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:40; 约翰福音 20:11; 约翰福音 11:44"> 他弯下身往里看，看见细麻布放在那里，却没有进去。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:17; 约翰福音 21:7; 马太福音 16:15–16"> 西门·彼得跟着他来到，就进了坟墓。他看见细麻布放在那里，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 11:44"> 又看见包在耶稣头上的头巾，没有和细麻布放在一起，而是单独卷在另一处。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:25; 约翰福音 20:4; 约翰福音 1:50"> 那时，先到坟墓的那另一个门徒也进去了，他看见就信了。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 16:10; 以赛亚书 25:8; 以赛亚书 53:10–12"> 因为他们还不明白经上所说，祂必须从死里复活的意思。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 7:53; 约翰福音 16:32"> 于是这两个门徒就回自己的住处去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:5"> 马利亚却站在坟墓外面哭泣。她哭着弯下身往坟墓里看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 启示录 3:4; 马可福音 16:5–6"> 看见两个身穿白衣的天使，坐在安放耶稣遗体的地方，一个在头那端，一个在脚那端。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:15; 约翰福音 2:4; 撒母耳记上 1:8"> 天使问她：“妇人，你为什么哭？”<br />她对他们说：“因为有人把我的主移走了，我不知道他们把祂放在哪里。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 约翰福音 21:4; 马太福音 28:9"> 她说了这话，转过身来，看见耶稣站在那里，却不知道那就是耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 20:13; 约翰福音 18:7; 约翰福音 1:38"> 耶稣问她：<span className="woj">“妇人，你为什么哭？你在找谁？”</span><br />马利亚以为祂是看园的，就对祂说：“先生，如果是你把祂挪走的，请告诉我你把祂放在哪里，我好去把祂带走。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:3; 约翰福音 1:38; 使徒行传 10:3"> 耶稣对她说：<span className="woj">“马利亚。”</span><br />她转过身来，用希伯来语对祂说：“拉波尼！”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拉波尼”是希伯来语“伟大的老师”的音译。">a</a></sup>（意思就是老师！）<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“主人”。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:28; 以弗所书 4:8–10; 加拉太书 4:6–7"> 耶稣对她说：<span className="woj">“不要拉着我，因为我还没有升上去见我的父。你往我的弟兄那里去，告诉他们：‘我要升上去见我的父，也是你们的父；见我的上帝，也是你们的上帝。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 马太福音 28:10; 约翰福音 20:1"> 抹大拉的马利亚就去告诉门徒，说她已经看见了主，又将主对她说的这些话告诉了他们。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 20:26; 约翰福音 14:27; 约翰福音 20:21"> 那一天，就是一周的第一天傍晚，门徒们聚集的地方，因为怕犹太人，门都关着。耶稣来站在他们中间，对他们说：<span className="woj">“愿你们平安。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 16:22; 约翰福音 16:20; 约翰福音 20:27"> 说了这话，祂就把手和肋旁指给他们看。门徒看见了主，就欢喜了。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 17:18–19; 约翰福音 13:20; 约翰福音 3:17"> 耶稣又对他们说：<span className="woj">“愿你们平安。父怎样差遣了我，我也照样差遣你们。”</span></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 33:4; 创世记 2:7; 使徒行传 8:15"> 说了这话，祂就向他们吹了一口气，对他们说：<span className="woj">“领受圣灵吧！</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 18:18; 马太福音 16:19; 马可福音 2:5–10"> <span className="woj">你们赦免谁的罪，谁的罪就赦免了；你们留下谁的罪，谁的罪就留下了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 11:16; 约翰福音 6:66–67; 希伯来书 10:25"> 十二使徒中有一个称为底土马<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“双胞胎”。">c</a></sup>的多马；耶稣来的时候，他没有和他们在一起。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:30; 马可福音 16:11; 希伯来书 3:12"> 其他门徒就对他说：“我们已经看见主了！”<br />多马却对他们说：“除非我看见祂手上的钉痕，用指头探入那钉痕，又用手探入祂的肋旁，否则我绝不相信。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 20:19; 以赛亚书 54:10; 约翰福音 20:21"> 过了八天，门徒又在屋里，多马也和他们在一起。门都关着，耶稣来站在他们中间，说：<span className="woj">“愿你们平安。”</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 20:25; 约翰一书 1:1–2; 约翰福音 20:20"> 然后祂对多马说：<span className="woj">“把你的指头伸到这里来，看看我的手；伸出你的手，探入我的肋旁。不要疑惑，总要信。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:1; 以赛亚书 9:6; 以赛亚书 7:14"> 多马回答祂说：“我的主，我的上帝！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="彼得前书 1:8; 哥林多后书 5:7; 希伯来书 11:1"> 耶稣对他说：<span className="woj">“你因为看见了我才信；</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="TR（公认文本）加上了“多马，”。">d</a></sup><span className="woj">那些没有看见就信的有福了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:25; 提摩太后书 3:15–17; 罗马书 15:4"> 耶稣在门徒面前还行了许多别的神迹，没有记在这书上。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:43; 约翰福音 3:15–16; 约翰一书 5:1"> 但记下这些事，是要叫你们信耶稣是基督，是上帝的儿子，并且叫你们信了祂，就可以因祂的名得生命。</span>
</div>
</div>

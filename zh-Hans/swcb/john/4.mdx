<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="4" data-verses="54">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:26; 约翰福音 3:22; 哥林多后书 4:5"> 主知道法利赛人听见耶稣收门徒和施洗比约翰还多</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:48; 哥林多前书 1:13–17"> （其实耶稣自己并没有施洗，而是祂的门徒施洗），</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:23; 约翰福音 10:40; 约翰福音 2:11"> 祂就离开犹太，又往加利利去了。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 祂必须经过撒马利亚。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 24:32; 创世记 33:19; 创世记 48:22"> 于是祂到了撒马利亚的一座城，名叫叙加，靠近雅各给他儿子约瑟的那块地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 4:15; 希伯来书 2:17; 马太福音 8:24"> 雅各井就在那里。耶稣因走路疲乏，就坐在井旁。那时大约是第六个时辰。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即正午。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:42; 列王纪上 17:10; 创世记 24:43"> 有一个撒马利亚妇人来打水。耶稣对她说：<span className="woj">“请给我一点水喝。”</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:13; 约翰福音 4:39; 约翰福音 4:5"> 那时祂的门徒进城买食物去了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 10:28; 马太福音 10:5; 列王纪下 17:24–41"> 撒马利亚妇人对祂说：“祢既是犹太人，怎么向我一个撒马利亚妇人要水喝呢？”（因为犹太人和撒马利亚人没有来往。）</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:14; 启示录 7:17; 约翰福音 7:37–39"> 耶稣回答说：<span className="woj">“你若知道上帝的恩赐，又知道对你说‘请给我一点水喝’的是谁，你早就会求祂，祂也早就会把活水赐给你了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:14; 约翰福音 3:4"> 妇人说：“先生，祢没有打水的器具，井又深，祢从哪里得那活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 4:6; 约翰福音 8:53; 马太福音 12:42"> 我们的祖先雅各将这口井留给我们，他自己和他的子孙及牲畜也都喝这井里的水，难道祢比他还大吗？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 6:27; 以赛亚书 65:13–14; 路加福音 16:24"> 耶稣回答说：<span className="woj">“凡喝这水的，还会再渴；</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:38–39; 约翰福音 6:35; 以赛亚书 49:10"> <span className="woj">但谁喝了我赐的水，就永远不再渴。我赐的水要在他里面成为泉源，直涌到永生。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:34; 罗马书 8:5; 诗篇 4:6"> 妇人对祂说：“先生，请把这水赐给我，叫我不渴，也不用再老远来这里打水。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 4:13; 启示录 2:23; 约翰福音 4:18"> 耶稣对她说：<span className="woj">“去叫你的丈夫，然后回到这里来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 妇人回答：“我没有丈夫。”<br />耶稣对她说：<span className="woj">“你说‘我没有丈夫’，说得很对，</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:20; 哥林多前书 7:10–11; 罗马书 7:3"> <span className="woj">因为你曾经有过五个丈夫；现在你有的这个，并不是你的丈夫。你这话是真的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 约翰福音 6:14; 约翰福音 9:17"> 妇人对祂说：“先生，我看出祢是一位先知。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 12:6–7; 申命记 27:12; 申命记 11:29"> 我们的祖先在这山上敬拜，你们犹太人却说，人们应当敬拜的地方是在耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 2:8; 玛拉基书 1:11; 约翰福音 4:23"> 耶稣对她说：<span className="woj">“妇人，你当信我。时候将到，你们敬拜父，既不在这个山上，也不在耶路撒冷。</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 17:23; 以赛亚书 2:3; 罗马书 9:4–5"> <span className="woj">你们敬拜你们所不知道的，我们敬拜我们所知道的，因为救恩是从犹太人出来的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:3; 约翰福音 5:25; 马太福音 15:7–9"> <span className="woj">时候将到，现在就是了，真正敬拜父的，要用心灵和真理敬拜祂，因为父寻找这样敬拜祂的人。</span></span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 3:17; 马太福音 15:8–9; 腓立比书 3:3"> <span className="woj">上帝是灵，所以敬拜祂的，必须用心灵和真理敬拜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:49; 但以理 9:24–26; 约翰福音 1:41–42"> 妇人对祂说：“我知道被称为基督的弥赛亚要来。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“弥赛亚”（希伯来语）和“基督”（希腊语）的意思都是“受膏者”。">b</a></sup>祂来的时候，会将一切的事告诉我们。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:24; 马可福音 14:61–62; 罗马书 10:20–21"> 耶稣对她说：<span className="woj">“正在和你说话的我就是。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 约翰福音 4:8–9"> 就在这时，祂的门徒回来了。他们对祂正和一个妇人说话感到惊讶，只是没有人说：“祢在找什么？”或“祢为什么和她说话？”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:7; 路加福音 24:33; 马可福音 16:8–10"> 于是那妇人留下水罐，跑进城里去，对众人说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 22:17; 哥林多前书 14:24–25; 约翰福音 4:25"> “你们来看！有一个人将我所做过的一切事都说出来了，莫非这就是基督吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 5:20; 使徒行传 8:5–8; 路加福音 17:16–18"> 众人就出城，往耶稣那里去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:38; 创世记 24:33; 使徒行传 16:30–34"> 这期间，门徒催促祂说：“拉比，请吃。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约伯记 23:12; 诗篇 119:103; 约翰福音 4:34"> 祂却对他们说：<span className="woj">“我有食物吃，是你们不知道的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 16:6–11; 路加福音 9:45"> 门徒就彼此对问：“难道有人拿东西给祂吃了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 6:38; 约翰福音 5:30; 约伯记 23:12"> 耶稣对他们说：<span className="woj">“我的食物就是遵行差我来者的旨意，完成祂的工作。</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 马太福音 9:37–38; 约翰福音 4:30"> <span className="woj">你们岂不说‘到收割的时候还有四个月’吗？看哪，我告诉你们，举目向田观看，庄稼已经熟了，可以收割了。</span></span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 5:19–20; 罗马书 1:13; 哥林多前书 3:5–9"> <span className="woj">收割的人得工钱，积蓄果子到永生，叫撒种的和收割的一同喜乐。</span></span>
<span className="v" id="v37" data-v="37" data-xref="弥迦书 6:15; 约伯记 31:8; 路加福音 19:21"> <span className="woj">俗语说，‘那人撒种，这人收割’，这话是真的。</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 1:7; 历代志下 36:15; 使徒行传 10:42–43"> <span className="woj">我差你们去收割你们所没有劳苦的。别人劳苦，你们却享受他们劳苦的成果。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 4:29; 约翰福音 4:5; 约翰福音 10:41–42"> 那城里有许多撒马利亚人信了耶稣，因为那妇人作见证说：“祂将我所做过的一切事都说出来了。”</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 3:20; 使徒行传 16:15; 路加福音 24:29"> 于是撒马利亚人来到耶稣那里，恳求祂留在他们那里，祂就在那里住了两天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前书 2:4–5; 使徒行传 1:8; 使徒行传 8:12"> 因着耶稣的话，信的人就更多了。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:14; 约翰福音 1:29; 约翰一书 5:20"> 他们对妇人说：“现在我们信，不再是因为你的话；因为我们亲自听见了，知道祂确实是基督，是世界的救主。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:13; 罗马书 15:8; 马可福音 7:27–28"> 两天后，祂离开那里，前往加利利。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 13:57; 路加福音 4:24; 马可福音 6:4"> 因为耶稣自己作过见证：先知在自己的家乡是不受尊敬的。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 2:23; 约翰福音 2:13–16; 申命记 16:16"> 到了加利利，加利利人就接待祂，因为他们也去过节，看见了祂在耶路撒冷过节时所行的一切事。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 2:1–11; 路加福音 7:2; 何西阿 5:15"> 耶稣又来到加利利的迦拿，就是祂把水变成酒的地方。有一个大臣，他的儿子在迦百农患了病。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 4:3; 约翰福音 11:21; 约翰福音 11:32"> 他听见耶稣从犹太回到了加利利，就去见祂，求祂下去医治他的儿子，因为他的儿子快要死了。</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 20:29; 希伯来书 2:4; 哥林多前书 1:22"> 耶稣就对他说：<span className="woj">“除非你们看见神迹奇事，否则你们绝不相信。”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:23; 诗篇 88:10–12; 诗篇 40:17"> 那大臣对祂说：“先生，求祢趁着我的孩子还没有死，就下去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马太福音 8:13; 马可福音 7:29–30; 罗马书 4:20–21"> 耶稣对他说：<span className="woj">“回去吧，你的儿子活了。”</span>那人信了耶稣对他说的话，就回去了。</span>
<span className="v" id="v51" data-v="51" data-xref="列王纪上 17:23; 约翰福音 4:50; 约翰福音 4:53"> 正下去的时候，他的仆人迎面走来，报告说：“你的孩子活了！”</span>
<span className="v" id="v52" data-v="52"> 他就向他们打听孩子好转的时间。他们对他说：“昨天第七个时辰，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="即下午一点。">c</a></sup>烧就退了。”</span>
<span className="v" id="v53" data-v="53" data-xref="诗篇 107:20; 路加福音 19:9; 使徒行传 16:34"> 父亲就知道，那正是耶稣对他说<span className="woj">“你的儿子活了”</span>的那个时辰。他自己和全家就都信了。</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 4:45; 约翰福音 2:1–11"> 这是耶稣从犹太回到加利利后，所行的第二件神迹。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 13:31–32; 约翰福音 17:4–5; 腓立比书 2:9–11"> 耶稣说了这些话，就举目望天，说：<span className="woj">“父啊，时候到了。愿祢荣耀祢的儿子，使祢的儿子也荣耀祢；</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:28–29; 约翰福音 6:39; 但以理 7:14"> <span className="woj">正如祢给了祂管理全人类的权柄，使祂将永生赐给凡祢所赐给祂的人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:20; 约翰一书 5:11–12; 耶利米书 9:23–24"> <span className="woj">认识祢——独一的真神，并且认识祢所差来的耶稣基督，这就是永生。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:34; 使徒行传 20:24; 提摩太后书 4:7"> <span className="woj">我在地上已经荣耀了祢。祢交给我做的工作，我已经完成了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:1–3; 歌罗西书 1:15–17; 约翰福音 10:30"> <span className="woj">现在，父啊，求祢使我在祢面前得荣耀，就是创世以前我与祢同享的荣耀。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 17:26; 约翰福音 14:21–24; 约翰一书 5:20"> <span className="woj">“祢从世上赐给我的人，我已经将祢的名显明给他们。他们本是祢的，祢将他们赐给了我，他们也遵守了祢的道。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:16–17; 约翰福音 16:15; 约翰福音 14:7–10"> <span className="woj">现在他们知道，凡祢所赐给我的，都是从祢那里来的；</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 17:14; 约翰福音 15:15; 约翰福音 16:30"> <span className="woj">因为祢赐给我的话，我已经传给了他们；他们也领受了，又确实知道我是从祢那里来的，并且信是祢差了我来。</span></span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:24; 约翰福音 17:2; 约翰福音 17:6"> <span className="woj">我为他们祈求。我不为世界祈求，而是为祢赐给我的人祈求，因为他们是祢的。</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 10:30; 彼得前书 2:9; 启示录 5:8–14"> <span className="woj">凡是我的都是祢的，祢的也是我的，并且我因他们得了荣耀。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:9; 箴言 18:10; 约翰福音 17:12–18"> <span className="woj">我不再留在这世上，他们却在这世上，我要到祢那里去。圣天父啊，求祢因祢赐给我的名保守他们，叫他们合而为一，像我们一样。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 109:6–19; 约翰福音 10:27–28; 约翰福音 18:9"> <span className="woj">我与他们同在世上的时候，我奉祢的名保守了他们。我也护卫了祢所赐给我的人。除了那灭亡之子，他们中间没有一个失落的，好叫经上的话得以应验。</span></span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 12:2; 加拉太书 5:22; 约翰福音 15:11"> <span className="woj">现在我要到祢那里去；我还在世上的时候说这些话，是要叫他们心里充满我的喜乐。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:16; 约翰福音 15:18–21; 约翰一书 5:19–20"> <span className="woj">我已将祢的道赐给他们。世界恨他们，因为他们不属世界，正如我不属世界一样。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 121:7; 约翰一书 5:18; 马太福音 6:13"> <span className="woj">我不求祢带他们离开世界，只求祢保守他们脱离那恶者。</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 17:14"> <span className="woj">他们不属世界，正如我不属世界一样。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:3; 诗篇 119:160; 以弗所书 5:26"> <span className="woj">求祢用真理使他们成圣；祢的道就是真理。</span></span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 5:20; 约翰福音 20:21; 约翰福音 17:3"> <span className="woj">祢怎样差我到世上，我也照样差他们到世上。</span></span>
<span className="v" id="v19" data-v="19" data-xref="提多书 2:14; 希伯来书 2:11; 约翰福音 17:17"> <span className="woj">我为他们的缘故，自己分别为圣，叫他们也因真理成圣。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 17:6–11; 使徒行传 2:41; 使徒行传 4:4"> <span className="woj">“我不但为这些人祈求，也为那些因他们的话而信我的人祈求，</span></span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 12:12; 歌罗西书 3:11–14; 约翰福音 17:11"> <span className="woj">叫他们都合而为一；正如父祢在我里面，我在祢里面，使他们也在我们里面，叫世人可以信是祢差了我来。</span></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 3:18; 约翰福音 14:20; 马可福音 16:17–20"> <span className="woj">祢所赐给我的荣耀，我已赐给他们，使他们合而为一，像我们合而为一；</span></span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 17:21; 约翰福音 16:27; 约翰一书 3:1"> <span className="woj">我在他们里面，祢在我里面，使他们完完全全地合而为一，叫世人知道是祢差了我来，也知道祢爱他们，正如祢爱我一样。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 17:5; 约翰福音 12:26; 约翰福音 14:3"> <span className="woj">父啊，我愿祢赐给我的人，我在哪里，他们也和我同在哪里，叫他们看见祢赐给我的荣耀，因为创世以前，祢就已经爱我了。</span></span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:11; 约翰福音 7:29; 约翰福音 17:8"> <span className="woj">公义的父啊，世人未曾认识祢，我却认识祢；这些人也知道是祢差了我来。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 17:23; 约翰福音 17:6; 约翰福音 15:9"> <span className="woj">我已经将祢的名指示他们，还要再指示，叫祢爱我的那爱在他们里面，我也在他们里面。”</span></span>

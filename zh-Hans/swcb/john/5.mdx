<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="5" data-verses="47">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 16:16; 出埃及记 23:14–17; 出埃及记 34:23"> 这事以后，到了犹太人的一个节期，耶稣就上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 12:39; 尼希米记 3:1; 尼希米记 3:32"> 在耶路撒冷靠近羊门有一个水池，希伯来语叫“毕士大”，旁边有五个柱廊。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:1–4; 路加福音 7:22; 马太福音 15:30"> 里面躺着一大群病人，有瞎眼的、瘸腿的和瘫痪的，等候水动；</span>
<span className="v" id="v4" data-v="4"> 因为有天使会按时下到池子里搅动池水。水动之后，谁先下池子，无论患什么病都会痊愈。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU（联合圣经公会版）省略了第3节中“等候水动”至第4节末尾的经文。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 3:2; 路加福音 8:43; 马可福音 9:21"> 那里有一个人，病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯来书 4:15; 希伯来书 4:13"> 耶稣看见他躺在那里，知道他病了很久，就问他：<span className="woj">“你想要痊愈吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 72:12; 申命记 32:36; 哥林多前书 9:24"> 病人回答祂：“先生，水动的时候，没有人把我放进池子里；我正要去的时候，别人已经先下去了。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 马太福音 9:6; 马可福音 2:11"> 耶稣对他说：<span className="woj">“起来，拿起你的垫子走吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:7–8; 约翰福音 9:14; 马可福音 3:2–4"> 那人立刻痊愈了，拿起垫子就走。<br />那天正是安息日。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 17:21; 路加福音 6:2; 约翰福音 9:16"> 所以犹太人对那被治好的人说：“今天是安息日，你拿垫子是不合法的。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 2:9–11; 约翰福音 9:16"> 他回答他们：“那使我痊愈的对我说：<span className="woj">‘拿起你的垫子走吧。’</span>”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:23; 士师记 6:29; 罗马书 10:2"> 他们就问他：“对你说<span className="woj">‘拿起垫子走吧’</span>的那个人是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 约翰福音 8:59"> 但那被治好的人不知道是谁，因为那里人多，耶稣已经避开了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:11; 利未记 26:23–24; 诗篇 118:18"> 后来，耶稣在圣殿里找到他，对他说：<span className="woj">“看哪，你已经痊愈了。不要再犯罪，免得你遭遇更坏的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:11–12; 约翰福音 4:29; 约翰福音 9:25"> 那人就去告诉犹太人，使他痊愈的是耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:39; 约翰福音 7:19–20; 马可福音 3:6"> 因此犹太人迫害耶稣，想要杀祂，因为祂在安息日做这些事。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:4; 约翰福音 14:10; 歌罗西书 1:16"> 但耶稣回答他们：<span className="woj">“我父做事直到如今，我也在做事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 10:30; 约翰福音 10:33; 约翰福音 19:7"> 为此，犹太人越发想要杀祂，因为祂不仅破坏了安息日，还称上帝为祂自己的父，将自己与上帝当作平等。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:49; 约翰福音 8:28; 约翰福音 14:10"> 耶稣就回答他们说：<span className="woj">“我确实地告诉你们，子凭着自己不能做什么，唯有看见父所做的，子才能做；因为父所做的事，子也照样做。</span></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:35; 马太福音 3:17; 约翰福音 17:26"> <span className="woj">因为父爱子，将自己所做的一切事指示祂，还要将比这些更大的事指示祂，叫你们惊讶。</span></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:11; 申命记 32:39; 约翰福音 11:25"> <span className="woj">因为父怎样叫死人复活，赐他们生命，子也照样随自己的意愿赐人生命。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:27; 使徒行传 17:31; 哥林多后书 5:10"> <span className="woj">父不审判任何人，而是把一切审判的事全交给了子，</span></span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:23; 路加福音 10:16; 马太福音 11:27"> <span className="woj">叫所有人都尊敬子，如同尊敬父一样。不尊敬子的，就是不尊敬差祂来的父。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 约翰福音 6:40; 约翰一书 5:11–13"> <span className="woj">“我确实地告诉你们，那听我话又信差我来者的，就有永生，不至于被定罪，而是已经出死入生了。</span></span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:28; 以弗所书 5:14; 以弗所书 2:5"> <span className="woj">我确实地告诉你们，时候将到，现在就是了，死人将听见上帝儿子的声音，听见的人就要活了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 11:26; 约翰福音 1:4; 出埃及记 3:14"> <span className="woj">因为父怎样在自己里面有生命，也照样赐给子在自己里面有生命，</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 10:42; 约翰福音 5:22; 使徒行传 17:31"> <span className="woj">并且因为祂是人子，就赐给祂执行审判的权柄。</span></span>
<span className="v" id="v28" data-v="28" data-xref="启示录 20:12; 帖撒罗尼迦前书 4:14–17; 以赛亚书 26:19"> <span className="woj">你们不要把这事看作希奇，因为时候将到，凡在坟墓里的，都要听见祂的声音，</span></span>
<span className="v" id="v29" data-v="29" data-xref="但以理 12:2–3; 罗马书 2:6–10; 使徒行传 24:15"> <span className="woj">就出来：行善的复活得生，作恶的复活被定罪。</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 6:38; 约翰福音 5:19; 约翰福音 4:34"> <span className="woj">我凭着自己不能做什么。我怎么听见，就怎么审判。我的审判是公义的，因为我不寻求自己的意愿，只寻求差我来之父的意愿。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 约翰福音 8:54; 启示录 3:14"> <span className="woj">“我若为自己作见证，我的见证就不真。</span></span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 1:33; 约翰福音 12:28–30; 约翰福音 5:36–37"> <span className="woj">另有一位为我作见证的，我也知道祂为我作的见证是真的。</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:29–34; 约翰福音 3:26–36; 约翰福音 1:15–27"> <span className="woj">你们曾差人到约翰那里，他为真理作了见证。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 约翰福音 20:31; 约翰一书 5:9"> <span className="woj">其实我领受的见证不是从人来的，但我说这些事，为要叫你们得救。</span></span>
<span className="v" id="v35" data-v="35" data-xref="彼得后书 1:19; 约翰福音 1:7–8; 马太福音 11:11"> <span className="woj">约翰是一盏点着发光的灯，你们也情愿暂时在他的光中欢喜。</span></span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 10:25; 约翰福音 10:37–38; 约翰福音 15:24"> <span className="woj">但我有比约翰更大的见证；因为父交给我要完成的工作，就是我所做的这些事，为我作见证，证明是父差我来的。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 8:18; 约翰福音 1:18; 马太福音 3:17"> <span className="woj">差我来的父自己也为我作了见证。你们从来没有听过祂的声音，也没有见过祂的形像。</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰一书 2:14; 申命记 6:6–9; 约翰福音 12:44–48"> <span className="woj">你们也没有让祂的道住在你们里面，因为你们不信祂所差来的那位。</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得后书 1:19–21"> <span className="woj">“你们查考圣经，因你们以为内中有永生；正是这圣经为我作见证。</span></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 3:19; 约翰福音 1:11; 诗篇 81:11"> <span className="woj">然而你们不肯到我这里来得生命。</span></span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:18; 约翰福音 5:34; 帖撒罗尼迦前书 2:6"> <span className="woj">我不领受从人来的荣耀。</span></span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:20; 约翰一书 3:17; 约翰福音 2:25"> <span className="woj">但我知道你们，你们心里没有上帝的爱。</span></span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 10:25; 马太福音 24:5; 约翰福音 17:4–6"> <span className="woj">我奉我父的名来，你们不接纳我；若有别人奉自己的名来，你们倒会接纳他。</span></span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:43; 罗马书 2:29; 腓立比书 2:3"> <span className="woj">你们互相接受荣耀，却不寻求从独一上帝来的荣耀，怎能信我呢？</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="罗马书 3:19–20; 加拉太书 3:10; 哥林多后书 3:7–11"> <span className="woj">“不要以为我会在父面前控告你们。有一位控告你们的，就是你们所仰望的摩西。</span></span>
<span className="v" id="v46" data-v="46" data-xref="申命记 18:15; 申命记 18:18–19; 约翰福音 1:45"> <span className="woj">你们若信摩西，就会信我，因为他写了关于我的事。</span></span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> <span className="woj">你们若不信他所写的，怎么能信我的话呢？”</span></span>
</div>
</div>

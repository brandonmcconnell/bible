<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 约翰福音 10:8–10; 罗马书 16:18"> <span className="woj">“我确实地告诉你们，进羊圈不从门进去，却从别处爬进去的，那人就是贼，是强盗。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:14; 使徒行传 20:28; 彼得前书 5:4"> <span className="woj">从门进去的，才是羊的牧人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以西结 34:11–16; 提摩太后书 2:19; 约翰福音 10:4"> <span className="woj">看门的人给他开门，羊也听他的声音。他按着名字呼叫自己的羊，领它们出来。</span></span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:30; 约翰福音 10:16; 约翰福音 12:26"> <span className="woj">他把自己的羊都放出来以后，就走在它们前面，羊也跟着他，因为它们认得他的声音。</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:5–6; 歌罗西书 2:6–10; 马可福音 4:24"> <span className="woj">羊绝不跟着陌生人，反而会逃跑，因为它们不认得陌生人的声音。”</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 56:11; 诗篇 82:5; 箴言 28:5"> 耶稣将这个比喻告诉他们，但他们不明白祂说的是什么意思。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:1"> 所以耶稣又对他们说：<span className="woj">“我确实地告诉你们，我就是羊的门。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西结 34:2; 耶利米书 23:1; 约翰福音 10:1"> <span className="woj">凡在我以先来的，都是贼，是强盗；羊却没有听从他们。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:7"> <span className="woj">我就是门；凡从我进来的，必得拯救，并且进出都能找到草场。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 约翰福音 6:51; 约翰福音 12:47"> <span className="woj">盗贼来，无非是要偷窃、杀害、毁坏；我来了，是要叫羊得生命，并且得的更丰盛。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:14–15; 诗篇 23:1; 约翰福音 15:13"> <span className="woj">“我是好牧人。</span><span className="woj">好牧人为羊舍命。</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:29; 撒迦利亚书 11:16–17; 以西结 34:2–6"> <span className="woj">雇工不是牧人，羊也不是他自己的；他看见狼来，就撇下羊逃跑了。狼就抓住羊，把羊群赶散。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:20; 约翰福音 12:6; 使徒行传 18:17"> <span className="woj">雇工逃跑，因为他是雇来的，并不顾念羊。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:27; 约翰福音 10:11; 提摩太后书 2:19"> <span className="woj">我是好牧人；我认识我的羊，我的羊也认识我，</span></span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:4; 约翰福音 10:11; 以赛亚书 53:10"> <span className="woj">正如父认识我，我也认识父一样；并且我为羊舍命。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 56:8; 约翰福音 11:52; 彼得前书 2:25"> <span className="woj">我另外有羊，不属这圈里的；</span><span className="woj">我必须把它们也领来，它们也要听我的声音，并且要合成一群，归一个牧人了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:18; 约翰福音 10:11; 希伯来书 2:9"> <span className="woj">我父爱我，因为我将命舍去，</span><span className="woj">好再取回来。</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:9; 提多书 2:14; 约翰福音 2:19–21"> <span className="woj">没有人能夺去我的命，是我自己舍的。我有权柄舍去，也有权柄再取回来。这是我从我父所领受的命令。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:16; 哥林多前书 3:3; 约翰福音 7:40–43"> 犹太人为这些话又起了纷争。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:20; 马可福音 3:21; 约翰福音 8:47–48"> 他们中有许多人说：“祂是被鬼附了，而且疯了！你们为什么听祂的呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 4:11; 以赛亚书 35:5–6; 诗篇 94:9"> 另有人说：“这不是被鬼附的人能说出的话。鬼岂能开瞎子的眼睛呢？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 在耶路撒冷有修殿节<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“修殿节”是“光明节（Hanukkah）”的希腊语名称，是庆祝重新奉献圣殿的节日。">a</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:12; 使徒行传 3:11"> 那时是冬天，耶稣在圣殿里的所罗门柱廊下行走。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 约翰福音 1:19; 约翰福音 8:25"> 犹太人围着祂说：“祢让我们心里悬念要到几时呢？祢若是基督，就明明地告诉我们。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:38; 约翰福音 8:58; 约翰福音 14:11"> 耶稣回答他们说：<span className="woj">“我已经告诉你们了，你们却不信。我奉我父之名所做的事，可以为我作见证。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:47; 哥林多后书 4:3–4; 约翰福音 12:37–40"> <span className="woj">只是你们不信，因为正如我对你们说过的，你们不是我的羊。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 10:16; 约翰福音 10:14; 启示录 3:20"> <span className="woj">我的羊听我的声音，我认识它们，它们也跟从我。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:39–40; 约翰福音 6:37; 约翰福音 3:15–16"> <span className="woj">我又赐给它们永生，它们必永远不致灭亡，也没有人能从我手里把它们夺走。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:37; 约翰福音 17:2; 约翰福音 17:9"> <span className="woj">赐给我这些羊的父比万有都大，没有人能从我父手里把它们夺走。</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:1–2; 约翰福音 14:9; 约翰福音 17:21–23"> <span className="woj">我与父原为一。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 5:18; 约翰福音 8:59; 撒母耳记上 30:6"> 犹太人又拿起石头来要打祂。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰一书 3:12; 约翰福音 5:36; 诗篇 35:12"> 耶稣回答他们说：<span className="woj">“我将许多从父那里来的善事显给你们看，你们是为哪一件拿石头打我呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 5:18; 利未记 24:16; 约翰福音 10:30"> 犹太人回答说：“我们拿石头打祢，不是为着善事，而是为了祢说僭妄的话；因为祢是一个人，竟将自己当作上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 82:6–7; 出埃及记 7:1; 诗篇 82:1"> 耶稣回答他们说：<span className="woj">“你们的律法上岂不是写着‘我曾说你们是神’吗？</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:35; 罗马书 13:1; 路加福音 16:17"> <span className="woj">既然那些承受上帝之道的人，上帝尚且称他们为神（而且圣经是不能废除的），</span></span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:17–18; 约翰福音 3:17; 耶利米书 1:5"> <span className="woj">那么父所分别为圣、又差到世上来的那位，仅仅因为说‘我是上帝的儿子’，你们就说‘祢说僭妄的话’吗？</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 15:24; 约翰福音 10:25; 约翰福音 12:37–40"> <span className="woj">我若不行我父的事，你们就不必信我；</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 14:20; 约翰福音 10:25; 约翰福音 10:30"> <span className="woj">我若行了，你们纵然不信我，也当信这些事，好叫你们知道并且相信，父在我里面，我也在父里面。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:30; 约翰福音 8:59; 约翰福音 7:44"> 他们又想要捉拿祂，祂却逃出了他们的掌控。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 1:28; 约翰福音 11:54; 约翰福音 7:1"> 耶稣又往约旦河对岸去，到了约翰起初施洗的地方，就住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 1:33–34; 约翰福音 1:29–30; 马可福音 1:37"> 许多人来到祂那里，说：“约翰虽然没有行过一件神迹，但他指着这人所说的一切话都是真的。”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 4:41; 约翰福音 2:23; 约翰福音 7:31"> 在那里，有许多人信了耶稣。</span>
</div>
</div>

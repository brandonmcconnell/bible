<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:8; 马太福音 13:21; 马太福音 26:31–33"> <span className="woj">“我将这些事告诉了你们，免得你们跌倒。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:22; 使徒行传 26:9–11; 罗马书 10:2–3"> <span className="woj">他们要把你们赶出会堂。是的，时候将到，凡杀你们的，还以为自己是在事奉上帝。</span></span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:21; 约翰福音 17:25; 约翰福音 8:55"> <span className="woj">他们会做这些事，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR（公认文本）加上了“向你们”。">a</a></sup><span className="woj">是因为他们既不认识父，也不认识我。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 14:29; 马可福音 13:23; 约翰福音 17:12–13"> <span className="woj">但我将这些事告诉你们，好叫事情发生的时候，你们能想起我对你们说的话。我起初没有把这些事告诉你们，因为我与你们同在。</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:36; 约翰福音 7:33; 约翰福音 16:28"> <span className="woj">但现在我要到差我来的那位那里去，你们中间却没有一个人问我：‘祢往哪里去？’</span></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:1; 约翰福音 16:20–22; 路加福音 24:17"> <span className="woj">只因我将这些事告诉了你们，你们心里就充满了忧愁。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 15:26"> <span className="woj">然而我将真理告诉你们：我离开对你们是有益的。因为我若不离开，保惠师就不会到你们这里来；我若去，就会差祂到你们这里来。</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:37; 犹大书 1:15; 撒迦利亚书 12:10"> <span className="woj">祂来了，就要在罪、在义、在审判上，指证世人的错；</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:22–25; 约翰福音 8:23–24; 约翰福音 12:47–48"> <span className="woj">在罪上，是因为他们不信我；</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 3:18; 罗马书 10:3–4"> <span className="woj">在义上，是因为我往父那里去，你们就再也看不见我了；</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:31; 约翰一书 3:8; 希伯来书 2:14"> <span className="woj">在审判上，是因为这世界的统治者已经受了审判。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:33; 约翰福音 15:15; 哥林多前书 3:1–2"> <span className="woj">“我还有许多事要告诉你们，但你们现在担当不了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:26; 哥林多前书 2:10–13; 约翰福音 14:17"> <span className="woj">然而，当真理的圣灵来的时候，祂要引导你们明白一切的真理；因为祂不是凭着自己说的，而是把祂所听见的都说出来，并且要把将来的事告诉你们。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:13–14; 哥林多后书 3:14–18; 约翰福音 15:26"> <span className="woj">祂要荣耀我，因为祂要将受于我的，告诉你们。</span></span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 17:10; 马太福音 11:27; 约翰福音 3:35"> <span className="woj">凡父所有的，都是我的；所以我说，祂将受于</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR（公认文本）作“必将受于”，而不是“将受于”。">b</a></sup><span className="woj">我的，告诉你们。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:33; 使徒行传 1:3; 约翰福音 14:18–24"> <span className="woj">“再过一点点时间，你们就看不见我了；再过一点点时间，你们还要看见我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:16; 马可福音 9:32; 约翰福音 16:5"> 于是祂的几个门徒彼此对问说：“祂对我们说：<span className="woj">‘再过一点点时间，你们就看不见我了；再过一点点时间，你们还要看见我’</span>；又说：<span className="woj">‘因为我往父那里去’</span>；这是什么意思呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 马太福音 16:9–11; 希伯来书 5:12"> 他们又说：“祂说<span className="woj">‘一点点时间’</span>，到底是什么意思？我们不明白祂在说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:30; 约翰福音 16:16; 约翰福音 14:19"> 耶稣察觉到他们想问祂，就对他们说：<span className="woj">“因为我说‘再过一点点时间，你们就看不见我了；再过一点点时间，你们还要看见我’，你们就为这话彼此询问吗？</span></span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 1:2; 马太福音 5:4; 诗篇 126:5–6"> <span className="woj">我确实地告诉你们，你们将要痛哭哀号，世人却要喜乐。你们将要忧愁，但你们的忧愁将要变为喜乐。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 113:9; 以赛亚书 13:8; 帖撒罗尼迦前书 5:3"> <span className="woj">妇人生产的时候会有痛苦，因为她的时候到了；但孩子生下来之后，她就不再记住那苦楚了，因为欢喜有一个人生到了世上。</span></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 1:8; 使徒行传 13:52; 约翰福音 16:6"> <span className="woj">所以你们现在有忧愁，但我还要再见你们，你们的心就会喜乐，并且没有人能夺去你们的喜乐。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 15:7; 约翰福音 14:13–14; 马太福音 21:22"> <span className="woj">“到那日，你们什么也不会问我了。我确实地告诉你们，你们奉我的名无论向父求什么，祂必赐给你们。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:7–8; 雅各书 4:2–3; 约翰福音 15:11"> <span className="woj">直到现在，你们没有奉我的名求过什么。你们求，就必得着，叫你们的喜乐得以满足。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:12; 马可福音 4:13; 马太福音 13:34–35"> <span className="woj">“我一直在用比喻对你们说这些事；但时候将到，我不再用比喻对你们说，而是要把关于父的事明明地告诉你们。</span></span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 8:34; 约翰福音 17:24; 约翰福音 17:19"> <span className="woj">到那日，你们要奉我的名祈求；我并不是说，我还要为你们求父；</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:21; 约翰福音 14:23; 约翰福音 17:23"> <span className="woj">因为父自己爱你们，因为你们已经爱我，并且信我是从上帝那里来的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:1; 约翰福音 13:3; 约翰福音 8:14"> <span className="woj">我从父那里出来，到了世界；我又离开世界，往父那里去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰福音 16:25"> 门徒对祂说：“看哪，现在祢是明明地说话，不用比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:17; 约翰福音 17:8; 约翰福音 16:17"> 现在我们知道祢无所不知，也不需要任何人来问祢。因此我们信祢是从上帝那里来的。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 约翰福音 13:38"> 耶稣回答他们说：<span className="woj">“现在你们信了吗？</span></span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 13:7; 马太福音 26:31; 约翰福音 8:29"> <span className="woj">看哪，时候将到，而且现在已经到了，你们要被分散，各归自己的地方去，留下我独自一人。其实我不是独自一人，因为有父与我同在。</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 14:27; 约翰一书 5:4; 帖撒罗尼迦后书 3:16"> <span className="woj">我将这些事告诉你们，是要叫你们在我里面有平安。在世上你们有苦难；但你们要振作！我已经胜了世界。”</span></span>
</div>

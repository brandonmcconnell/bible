<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="3" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 19:39; 约翰福音 7:47–50; 约翰福音 3:10"> 有一个法利赛人，名叫尼哥底母，是犹太人的官。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 5:36; 使徒行传 10:38; 使徒行传 2:22"> 他夜里来见耶稣，对祂说：“拉比，我们知道祢是由上帝那里来作老师的；因为祢所行的这些神迹，若没有上帝同在，无人能行。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 5:17; 约翰福音 3:5–6; 彼得前书 1:23–25"> 耶稣回答说：<span className="woj">“我确实地告诉你，人若不重生，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此处及约翰福音3:7译作“重生”的词（ἄνωθεν），也有“再次”和“从上面”的意思。">a</a></sup><span className="woj">就不能看见上帝的国。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 2:14; 哥林多前书 1:18; 约翰福音 3:3"> 尼哥底母对祂说：“人老了，怎么能重生呢？难道能再进母腹生出来吗？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结 36:25–27; 以弗所书 5:26; 使徒行传 2:38"> 耶稣回答：<span className="woj">“我确实地告诉你，人若不是从水和圣灵生的，就不能进上帝的国。</span></span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:16–21; 以西结 36:26–27; 罗马书 8:4–9"> <span className="woj">从肉体生的就是肉体，从圣灵生的就是灵。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:3; 以弗所书 4:22–24; 罗马书 12:1–2"> <span className="woj">不要因为我对你说‘你们必须重生’而感到惊讶。</span></span>
<span className="v" id="v8" data-v="8" data-xref="传道书 11:4–5; 哥林多前书 2:11; 使徒行传 2:2"> <span className="woj">风随意吹，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="相同的希腊词（πνεῦμα）也有“风”、“气息”和“灵”的意思。">b</a></sup><span className="woj">你听见风的声音，却不知道它从哪里来，往哪里去。凡从圣灵生的，也是如此。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 6:60; 路加福音 1:34; 以赛亚书 42:16"> 尼哥底母问祂：“怎么会有这些事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:29; 耶利米书 8:8–9; 以西结 11:19"> 耶稣回答他说：<span className="woj">“你是以色列人的老师，还不明白这些事吗？</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:38; 约翰一书 5:6–12; 约翰福音 12:49"> <span className="woj">我确实地告诉你，我们说的是我们知道的，见证的是我们见过的，你们却不领受我们的见证。</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:1–2; 哥林多前书 2:7–9; 希伯来书 5:11"> <span className="woj">我对你们说地上的事，你们尚且不信，若对你们说天上的事，你们怎么能信呢？</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 约翰福音 6:38; 使徒行传 2:34"> <span className="woj">除了从天降下、仍旧在天的人子，没有人升过天。</span></span>
<span className="v" id="v14" data-v="14" data-xref="民数记 21:7–9; 约翰福音 8:28; 约翰福音 12:32–34"> <span className="woj">摩西在旷野怎样举蛇，人子也必照样被举起来，</span></span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 3:16; 约翰福音 6:40; 约翰福音 12:44–46"> <span className="woj">叫一切信祂的，不致灭亡，反得永生。</span></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:8; 约翰一书 4:9–10; 约翰福音 3:15"> <span className="woj">上帝爱世人，甚至将祂的独生</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“独生”源于希腊文“μονογενη”，有时也译作“唯一的”或“独生子”。">c</a></sup><span className="woj">子赐给他们，叫一切信祂的，不致灭亡，反得永生。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:14; 路加福音 19:10; 约翰福音 12:47–48"> <span className="woj">因为上帝差祂的儿子降世，不是要审判世人，而是要叫世人藉着祂得救。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:16; 约翰一书 5:10; 罗马书 8:1"> <span className="woj">信祂的人不被审判；不信的人罪已经定了，因为他不信上帝独生子的名。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:12; 帖撒罗尼迦后书 2:12; 约翰福音 9:39–41"> <span className="woj">光来到世上，世人因自己的行为是恶的，不爱光倒爱黑暗，这就是审判的缘由。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 5:11–13; 约翰福音 7:7; 约伯记 24:13–17"> <span className="woj">凡作恶的都恨光，不来就光，恐怕他的行为被暴露。</span></span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 1:6; 诗篇 139:23–24; 约翰三书 1:11"> <span className="woj">但遵行真理的就来就光，为要显明他的行为是靠着上帝而行的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:1–3; 约翰福音 3:26; 约翰福音 2:13"> 这些事以后，耶稣和门徒到了犹太地，祂在那里与他们同住，并且施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 1:4–5; 以西结 43:2; 马太福音 3:5–6"> 约翰也在靠近撒冷的哀嫩施洗，因为那里水多，众人也去受洗；</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 4:12; 马太福音 14:3; 马可福音 6:17"> 那时约翰还没有被下在监里。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 2:6; 马太福音 3:11; 希伯来书 6:2"> 当时，约翰的门徒和几个犹太人为了洁净礼的事发生了争论。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:7; 约翰福音 1:15; 约翰福音 12:19"> 他们来到约翰那里，对他说：“拉比，从前同你在约旦河对岸、你为祂作见证的那位，看哪，祂现在正在施洗，众人都往祂那里去了。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="雅各书 1:17; 哥林多前书 4:7; 哥林多前书 15:10"> 约翰回答说：“若不是从天上赐的，人就不能得到什么。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:20; 约翰福音 1:23; 马太福音 3:11–12"> 你们自己可以为我作见证，我曾说过：‘我不是基督’，而是‘我是奉差遣在祂前面的’。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 9:15; 何西阿 2:19; 以赛亚书 54:5"> 娶新娘的是新郎；新郎的朋友站着听他说话，听见新郎的声音就非常喜乐。因此，我这喜乐满足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 1:18; 诗篇 72:17–19; 希伯来书 3:2–6"> 祂必兴旺，我必衰微。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:23; 马太福音 28:18; 罗马书 9:5"> “从上面来的是超越万有之上；从地上来的是属于地，所说的也是地上的事。从天上来的是超越万有之上。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:11; 约翰福音 15:15; 约翰福音 1:11"> 祂将所见所闻的作见证，却没有人领受祂的见证。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 6:17; 以弗所书 1:13; 提多书 1:1–2"> 那领受祂见证的，就印证了上帝是真实的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 10:38; 马太福音 12:18; 约翰福音 15:26"> 上帝所差来的，就说上帝的话，因为上帝将圣灵赐给祂是没有限量的。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 28:18; 约翰福音 5:22; 约翰福音 5:20"> 父爱子，已将万有交在祂手里。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:24; 约翰福音 1:12; 帖撒罗尼迦前书 5:9"> 信子的人有永生；不顺从<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="在此语境中，同一个词也可译为“不顺从”或“不信”。">d</a></sup>子的人得不着生命，上帝的震怒常在他身上。”</span>
</div>
</div>

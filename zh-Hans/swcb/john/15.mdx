<span className="v" id="v2" data-v="2" data-xref="马太福音 3:10; 希伯来书 12:10–11; 马太福音 15:13"> <span className="woj">凡属我不结果子的枝子，祂就剪去；凡结果子的枝子，祂就修剪干净，叫它结更多的果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 17:17; 以弗所书 5:26; 彼得前书 1:22"> <span className="woj">现在你们因着我对你们所讲的道，已经干净了。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:6; 加拉太书 2:20; 约翰福音 8:31"> <span className="woj">你们要常在我里面，我也常在你们里面。枝子若不连在葡萄树上，自己就不能结果子；你们若不常在我里面，也是这样。</span></span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:13; 歌罗西书 1:10; 约翰福音 15:16"> <span className="woj">我是葡萄树，你们是枝子。常在我里面的，我也常在他里面，这人就多结果子；因为离了我，你们就不能做什么。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:19; 希伯来书 6:7–8; 马太福音 13:41"> <span className="woj">人若不常在我里面，就像枝子被丢在外面枯干了；人把它们捡起来，扔在火里烧了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:4; 约翰一书 5:14; 约翰福音 14:13"> <span className="woj">你们若常在我里面，我的话也常在你们里面，凡你们所愿意的，祈求就必为你们成就。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:31; 马太福音 5:16; 腓立比书 1:11"> <span className="woj">“你们多结果子，我父就因此得荣耀，你们也就是我的门徒了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:23–24; 约翰福音 17:26; 约翰一书 2:28"> <span className="woj">父怎样爱我，我也怎样爱你们；你们要常在我的爱里。</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 3:21–24"> <span className="woj">你们若遵守我的命令，就常在我的爱里，正如我遵守了我父的命令，常在祂的爱里。</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 17:13; 罗马书 15:13; 约翰福音 16:24"> <span className="woj">我已经把这些事告诉了你们，是要叫我的喜乐存在你们心里，并叫你们的喜乐得以满足。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:21; 彼得前书 4:8; 约翰福音 13:34"> <span className="woj">“你们要彼此相爱，像我爱你们一样，这就是我的命令。</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 10:11; 以弗所书 5:2; 罗马书 5:6–8"> <span className="woj">人为朋友舍命，人的爱心没有比这个更大的了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 12:50; 约翰一书 5:3; 雅各书 2:23"> <span className="woj">你们若遵行我所吩咐的，就是我的朋友了。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 25:14; 哥林多前书 2:9–12; 马太福音 13:11"> <span className="woj">以后我不再称你们为仆人，因为仆人不知道主人所做的事。我乃称你们为朋友，因为我从我父那里听见的一切，都已经让你们知道了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 15:19; 耶利米书 1:5–7; 以弗所书 2:10"> <span className="woj">不是你们拣选了我，而是我拣选了你们，并且派你们去结果子，叫你们的果子长存；使你们奉我的名，无论向父求什么，祂就赐给你们。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:12; 约翰一书 3:14–17; 彼得前书 2:17"> <span className="woj">“我将这些事吩咐你们，是要叫你们彼此相爱。</span></span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 3:13; 约翰福音 7:7; 马可福音 13:13"> <span className="woj">“世人若恨你们，你们该知道，在恨你们以先，世人已经恨我了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:4–5; 约翰福音 17:14–16; 以弗所书 1:4–11"> <span className="woj">你们若属世界，世界必爱属自己的人。只因你们不属世界，而是我从世界中拣选了你们，所以世界就恨你们。</span></span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:12; 约翰福音 13:16; 马太福音 10:24"> <span className="woj">你们要记住我对你们说过的话：‘奴仆不能大于主人。’</span><span className="woj">他们若迫害了我，也必迫害你们；若遵守了我的道，也必遵守你们的道。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:22; 约翰福音 16:3; 马太福音 10:18"> <span className="woj">但他们为了我的名，要向你们做这一切的事，因为他们不认识差我来的那位。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 9:41; 雅各书 4:17; 使徒行传 17:30"> <span className="woj">我若没有来对他们说话，他们就没有罪；但现在他们的罪无可推诿了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 8:40–42; 约翰二书 1:9; 约翰一书 2:23"> <span className="woj">恨我的，也恨我的父。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:36; 约翰福音 14:9; 约翰福音 7:31"> <span className="woj">我若没有在他们中间做过别人未曾做过的事，他们就没有罪；但现在他们虽然看见了，却把我和我的父都恨恶了。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 109:3; 诗篇 69:4; 诗篇 35:19"> <span className="woj">这无非是要应验他们律法上所写的话：‘他们无故地恨我。’</span></span>
</div>

<span className="v" id="v27" data-v="27" data-xref="约翰一书 4:14; 约翰福音 21:24; 使徒行传 10:39–42"> <span className="woj">你们也要作见证，因为你们从起初就与我同在。</span></span>

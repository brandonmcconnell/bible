<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="申命记 17:12; 何西阿 4:17; 阿摩司 5:13"> <span className="pl pl-1">“然而，不要让人争讼，也不要让人指控；</span><br /><span className="pl pl-2">因为你的民像那些与祭司争讼的人。</span></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 15:8; 何西阿 2:2; 加拉太书 4:26"> <span className="pl pl-1">你白天必绊跌，</span><br /><span className="pl pl-2">先知夜间也必和你一同绊跌；</span><br /><span className="pl pl-2">我必毁灭你的母亲。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 5:13; 箴言 19:2; 何西阿 6:6"> <span className="pl pl-1">我的子民因缺乏知识而灭亡。</span><br /><span className="pl pl-2">因为你拒绝知识，我也必拒绝你，</span><br /><span className="pl pl-2">使你不能作我的祭司。</span><br /><span className="pl pl-1">因为你忘记了你上帝的律法，</span><br /><span className="pl pl-2">我也必忘记你的儿女。</span></span>

<span className="v" id="v8" data-v="8" data-xref="弥迦书 3:11; 以赛亚书 56:11; 提多书 1:11"> <span className="pl pl-1">他们以我子民的罪为食，</span><br /><span className="pl pl-2">心里贪恋他们的罪孽。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 24:2; 耶利米书 5:31; 马太福音 15:14"> <span className="pl pl-1">民如何，祭司也必如何；</span><br /><span className="pl pl-2">我必因他们所行的道路惩罚他们，</span><br /><span className="pl pl-2">照他们所做的报应他们。</span></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:14; 利未记 26:26; 哈该书 1:6"> <span className="pl pl-1">他们必吃，却不得饱足；</span><br /><span className="pl pl-2">他们必行淫，却不得增多；</span><br /><span className="pl pl-2">因为他们已经离弃，不听从耶和华。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 20:1; 路加福音 21:34; 以赛亚书 28:7"> <span className="pl pl-1">淫乱、酒和新酒夺去人的悟性。</span></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:27; 何西阿 5:4; 哈巴谷 2:19"> <span className="pl pl-2">我的子民向自己的木偶求问，</span><br /><span className="pl pl-2">一根木杖给他们答复。</span><br /><span className="pl pl-1">淫乱的灵实在使他们走迷了路，</span><br /><span className="pl pl-2">他们对自己的上帝不忠。</span></span>

</div>

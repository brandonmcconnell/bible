<span className="v" id="v1" data-v="1" data-xref="路得记 1:9; 提摩太前书 5:8; 提摩太前书 5:14"> 她婆婆拿俄米对她说：“我女儿，我岂不该为你寻求安身之处，使你得以安好吗？</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:5–10; 路得记 2:20–23; 路得记 2:8"> 现在，波阿斯不是我们的亲属吗？你曾和他的使女们在一起。看哪，今晚他要在打谷场簸大麦。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:2; 提摩太前书 2:9–10; 以斯帖记 5:1"> 所以你要沐浴，抹膏，穿上衣服，下到打谷场去；但不要让那人知道你在那里，直到他吃喝完了。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:22"> 等他躺下的时候，你要看准他躺卧的地方，然后进去，掀开他的脚，躺下；他会告诉你该做什么。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 3:20; 以弗所书 6:1"> 路得对她说：“凡你所说的，我都要去做。”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; 约翰福音 2:5; 出埃及记 20:12"> 她就下到打谷场，照她婆婆所吩咐的一切去做。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:6; 以斯帖记 1:10; 撒母耳记下 13:28"> 波阿斯吃喝完了，心中畅快，就到谷堆尽头躺下。路得悄悄地来，掀开他的脚，躺下。</span>
<span className="v" id="v8" data-v="8"> 到了半夜，那人惊醒，翻过身来；看哪，有个女子躺在他的脚边。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 16:8; 路得记 2:20; 路得记 3:12"> 他说：“你是谁？”<br />她回答：“我是你的婢女路得。请把你的衣襟展开遮盖你的婢女，因为你是至近的亲属。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路得记 2:20; 哥林多前书 13:4–5; 路得记 1:8"> 他说：“我女儿，愿你蒙耶和华赐福。你后来显出的慈爱比起初更大，因为你没有跟随年轻人，无论贫富。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> 现在，我女儿，不要害怕。凡你所说的，我都会为你做；因为我民所在的全城都知道你是贤德的女子。</span>
<span className="v" id="v12" data-v="12" data-xref="路得记 4:1; 帖撒罗尼迦前书 4:6; 马太福音 7:12"> 现在，我的确是至近的亲属；然而，还有一位亲属比我更近。</span>
<span className="v" id="v13" data-v="13" data-xref="路得记 4:5; 耶利米书 4:2; 路得记 2:20"> 今夜你在这里住下。到了早晨，若他愿意为你尽至亲的本分，很好，就让他尽这本分；但若他不愿意为你尽至亲的本分，我指着永活的耶和华起誓，我必为你尽这本分。你躺到早晨吧。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 8:21; 罗马书 14:16; 哥林多前书 10:32"> 她就在他脚边躺到早晨，在人还不能彼此辨认的时候就起来；因为他说：“不可让人知道这女子来到打谷场。”</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 32:8; 加拉太书 6:10"> 他又说：“把你身上的披肩拿来，托住。”她就托住；他量了六份大麦，放在她身上，然后他进城去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 路得来到婆婆那里，婆婆说：“我女儿，怎么样了？”<br />她就把那人为她所做的一切都告诉了婆婆。</span>
<span className="v" id="v17" data-v="17"> 她说：“他给了我这六份大麦，因为他说：‘你不要空手回到你婆婆那里去。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 37:3–5; 以赛亚书 28:16; 以赛亚书 30:7"> 于是拿俄米说：“我女儿，你等着，直到知道事情会怎样成就；因为那人今日若不把这事办妥，就不会歇息。”</span>
</div>

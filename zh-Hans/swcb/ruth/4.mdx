<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 25:7; 路得记 3:12; 申命记 16:18"> 波阿斯上到城门口，坐在那里。看哪，波阿斯所说的那位至近亲属正好经过。波阿斯对他说：“朋友，请过来坐下！”他就过来坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 31:23; 列王纪上 21:8; 使徒行传 6:12"> 波阿斯又从城里的长老中选了十个人，说：“请坐在这里。”他们就坐下。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:10; 诗篇 112:5"> 波阿斯对那位至近亲属说：“拿俄米从摩押地回来，如今要卖我们兄弟以利米勒的那块田地。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 25:25–29; 耶利米书 32:7–12; 罗马书 12:17"> 我想我应当告诉你，说：‘请你在坐在这里的人面前，并在我民中的长老面前买下它。’如果你愿意赎回，就赎回；如果你不愿意赎回，就告诉我，好让我知道。因为除了你以外，没有人可以赎回；其次就是我。”<br />他说：“我愿意赎回。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 38:8; 申命记 25:5–6; 马太福音 22:24"> 波阿斯说：“你从拿俄米手中买那块田的日子，也必须从死人的妻子摩押女子路得那里买下，为要在他的产业上兴起死人的名。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 25:25; 路得记 3:13"> 那位至近亲属说：“我不能为自己赎回，免得损害我自己的产业。你自己行使我的赎业权吧；因为我不能赎回。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 25:7–10"> 从前在以色列，关于赎回和交换，为了确认一切事，有这样的惯例：一个人脱下自己的鞋，交给他的邻舍；这就是在以色列确认交易的方式。</span>
<span className="v" id="v8" data-v="8"> 所以那位至近亲属对波阿斯说：“你自己买下吧。”然后他脱下自己的鞋。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 32:10–12; 创世记 23:16–18"> 波阿斯对长老和众民说：“今天你们作见证：凡属以利米勒的，以及凡属基连和玛伦的，我都从拿俄米手中买下了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 25:6; 以弗所书 5:25; 创世记 29:27"> 此外，玛伦的妻子摩押女子路得，我也买得为妻，为要在他的产业上兴起死人的名，使死人的名不从他的弟兄中，也不从他本地的城门口被剪除。今天你们作见证。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 29:32–24; 弥迦书 5:2; 马太福音 2:6"> 在城门口的众民和长老都说：“我们作见证。愿耶和华使这进你家的女子像拉结和利亚一样；她们二人建立了以色列家。愿你在以法他行事尊荣，在伯利恒得名声。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 38:29; 撒母耳记上 2:20; 历代志上 2:4"> 愿耶和华借着这年轻女子赐给你的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“种子”">a</a></sup>，使你的家像他玛给犹大所生法勒斯的家一样。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 33:5; 创世记 29:31; 路得记 3:11"> 于是波阿斯娶了路得，她就作了他的妻子；他与她同房，耶和华使她怀孕，她就生了一个儿子。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:5–20; 路加福音 1:58; 创世记 12:2"> 妇女们对拿俄米说：“耶和华是应当称颂的，因为祂今日没有使你缺少至近亲属。愿他的名在以色列得名声。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 55:22; 以赛亚书 46:4; 创世记 45:11"> 他必使你的生命复苏，并在你年老时供养你；因为爱你的儿媳妇生了他，她待你胜过七个儿子。”</span>
<span className="v" id="v16" data-v="16"> 拿俄米把孩子抱来，放在怀里，作他的养母。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:58–63"> 邻近的妇女给他起名，说：“拿俄米生了一个儿子。”她们给他起名叫俄备得。他是耶西的父亲，耶西是大卫的父亲。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 1:3–6; 历代志上 2:4–8; 路加福音 3:33"> 以下是法勒斯的后代史：法勒斯生希斯仑，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:33; 历代志上 2:9–10; 马太福音 1:4"> 希斯仑生兰，兰生亚米拿达，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:7; 路加福音 3:32; 马太福音 1:4"> 亚米拿达生拿顺，拿顺生撒门，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:32; 马太福音 1:5; 历代志上 2:11–12"> 撒门生波阿斯，波阿斯生俄备得，</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 2:15; 以赛亚书 11:1; 马太福音 1:6"> 俄备得生耶西，耶西生大卫。</span>
</div>
</div>

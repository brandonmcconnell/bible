<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 26:1; 以西结 14:13"> 在士师治理的日子，地上发生了饥荒。有一个犹大伯利恒的人，带着妻子和两个儿子，往摩押地去寄居。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:19; 弥迦书 5:2; 撒母耳记上 17:21"> 那人名叫以利米勒，妻子名叫拿俄米；他的两个儿子名叫玛伦和基连，都是犹大伯利恒的以法他人。他们来到摩押地，就住在那里。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:10–11; 诗篇 34:19; 希伯来书 12:6"> 拿俄米的丈夫以利米勒死了，留下她和两个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:5; 列王纪上 11:1–2; 申命记 23:3"> 这两个儿子娶了摩押女子为妻，一个名叫俄珥巴，另一个名叫路得。他们在那里住了大约十年。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:39; 诗篇 89:30–32; 以赛亚书 49:21"> 玛伦和基连两个人也都死了，这妇人就失去了两个孩子和丈夫。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 132:15; 出埃及记 3:16; 诗篇 111:5"> 后来，她和两个儿媳妇起身，要从摩押地回来，因为她在摩押地听见耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当译作全大写的“LORD”或“GOD”时，是上帝专有名的译法（希伯来文“יהוה”，通常读作雅威）。">a</a></sup>眷顾了祂的子民，赐粮食给他们。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 8:3; 路得记 1:14; 出埃及记 18:27"> 她离开所在的地方，两个儿媳妇也与她同行。她们走在路上，要回犹大地去。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 2:20; 路得记 1:5; 歌罗西书 3:18"> 拿俄米对两个儿媳妇说：“你们各自回母亲家去吧。愿耶和华以慈爱待你们，像你们待已死的人和我一样。</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 3:1; 使徒行传 20:37; 创世记 29:11"> 愿耶和华使你们各自在丈夫家里得安歇。”<br />于是她亲吻她们；她们放声大哭。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 8:23; 诗篇 16:3; 诗篇 119:63"> 她们对她说：“不，我们要同你回到你的百姓那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 25:5; 创世记 38:11"> 拿俄米说：“我的女儿们，回去吧。你们为什么要跟我去呢？难道我腹中还有儿子，可以作你们的丈夫吗？</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:17; 提摩太前书 5:9"> 我的女儿们，回去吧，走你们的路；因为我年纪太大，不能再有丈夫。即使我说：‘我还有指望，’即使我今夜有丈夫，并且生下儿子，</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 19:21; 士师记 2:15; 诗篇 32:4"> 你们难道要等他们长大吗？难道要为他们守着不嫁吗？不，我的女儿们，我为你们的缘故极其忧伤，因为耶和华的手已经伸出来攻击我。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 18:24; 马太福音 16:24; 马太福音 10:37"> 她们又放声大哭；俄珥巴亲吻了婆婆，路得却紧紧跟随她。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 11:24; 约书亚记 24:15; 西番雅书 1:6"> 拿俄米说：“看哪，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“看哪”，来自“הִנֵּה”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">b</a></sup>你的嫂子已经回到她的百姓和她的神明那里去了。你也跟着你的嫂子回去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 15:21; 路得记 2:11–12; 列王纪下 2:2–6"> 路得说：“不要催我离开你，转身不跟随你。因为你往哪里去，我也往哪里去；你在哪里住宿，我也在哪里住宿。你的百姓就是我的百姓，你的上帝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">c</a></sup>就是我的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 3:17; 列王纪上 2:23; 列王纪下 6:31"> 你在哪里死，我也在哪里死，也要葬在那里。除非死亡使你我分离，不然，愿耶和华重重地惩罚我。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:14; 以弗所书 6:10; 使徒行传 2:42"> 拿俄米见路得决意要跟她去，就不再劝她。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:10; 以赛亚书 23:7; 耶利米哀歌 2:15"> 于是二人同行，直到来到伯利恒。她们到了伯利恒，全城都因她们而骚动；妇女们说：“这是拿俄米吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约伯记 6:4; 希伯来书 12:11; 诗篇 73:14"> 她对她们说：“不要叫我拿俄米。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“拿俄米”的意思是“甜美”。">d</a></sup>要叫我玛拉，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“玛拉”的意思是“苦”。">e</a></sup>因为全能者使我受了极大的苦。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 2:7–8; 约伯记 1:21; 约伯记 16:8"> 我满满地出去，耶和华却使我空空地回来。耶和华既然作证攻击我，全能者又使我受苦，你们为什么还叫我拿俄米呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="路得记 2:23; 撒母耳记下 21:9; 出埃及记 9:31–32"> 这样，拿俄米就回来了；她的儿媳妇、摩押女子路得也同她一起，从摩押地回来。她们来到伯利恒，正是大麦收割开始的时候。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 3:17; 帖撒罗尼迦前书 1:6; 哥林多前书 4:16"> 你们要效法我，就像我也效法基督一样。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:15; 哥林多前书 4:17; 箴言 31:28–31"> 弟兄们，我称赞你们，因为你们凡事都记念我，并且坚守我传给你们的传统。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:16; 歌罗西书 1:18; 歌罗西书 3:18"> 但我愿意你们知道：各人的头<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：源头">a</a></sup>是基督，女人的头<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：源头">b</a></sup>是男人，基督的头<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：源头">c</a></sup>是上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 15:30; 哥林多前书 12:28; 哥林多前书 12:10"> 凡男人祷告或说预言，若蒙着头，就是羞辱自己的头。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 21:12; 路加福音 2:36; 使徒行传 2:17"> 但凡女人祷告或说预言，若不蒙头，就是羞辱自己的头，因为这就和剃了头发一样。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 22:5; 民数记 5:18"> 女人若不蒙头，就也该把头发剪掉；但女人若剪发或剃发是羞耻的，就该蒙头。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 11:3; 创世记 5:1; 诗篇 8:6"> 男人本不该蒙头，因为他是上帝的形象和荣耀；但女人是男人的荣耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 2:13; 创世记 2:21–23"> 因为男人不是出于女人，女人却是出于男人；</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 2:18; 创世记 2:23–24; 创世记 2:20"> 而且男人不是为女人而造的，女人却是为男人而造的。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 24:64–65; 希伯来书 1:14; 马太福音 18:10"> 因此，女人应当在自己的头上有权柄，为了天使的缘故。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28; 哥林多前书 7:10–14; 哥林多前书 12:12–22"> 然而，在主里面，女人并不独立于男人，男人也不独立于女人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:36; 哥林多前书 8:6; 希伯来书 1:2–3"> 因为女人怎样出于男人，男人也照样借着女人而生；但万有都是出于上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 约翰福音 7:24; 哥林多前书 10:15"> 你们自己判断：女人不蒙头向上帝祷告合宜吗？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:26; 哥林多前书 14:35"> 难道连本性也不教导你们：男人若留长头发，就是他的羞辱吗？</span>
<span className="v" id="v15" data-v="15"> 但女人若留长头发，就是她的荣耀，因为头发赐给她，是作遮盖的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 7:17; 提摩太前书 6:3–4; 帖撒罗尼迦前书 2:14"> 但若有人似乎要争辩，我们没有这样的习俗，上帝的众教会也没有。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:25; 哥林多前书 14:23; 哥林多前书 11:22"> 我吩咐这事，并不称赞你们，因为你们聚集不是使人更好，而是使人更坏。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 3:3; 哥林多前书 1:10–12; 哥林多前书 5:1"> 首先，我听说你们在教会中聚集的时候，你们中间有分裂；这事我也有几分相信。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:19; 提多书 3:10; 使徒行传 20:30"> 因为你们中间也必须有派别，好使那些蒙认可的人在你们中间显明出来。</span>
<span className="v" id="v20" data-v="20"> 所以，你们聚集在一起的时候，所吃的并不是主的晚餐。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:13; 犹大书 1:12; 哥林多前书 11:23–25"> 因为你们吃的时候，各人先吃自己的晚餐；有人饥饿，有人却醉了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 20:28; 箴言 17:5; 雅各书 2:5–6"> 怎么，你们没有房子可以吃喝吗？还是你们藐视上帝的教会，使那些不足的人羞愧呢？我该对你们说什么呢？要称赞你们吗？在这事上我不称赞你们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 马太福音 26:26–28; 哥林多前书 11:23–25"> 因为我从主所领受的，也传给了你们：主耶稣在祂被出卖的那一夜，拿起饼来；</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:53–58; 哥林多前书 11:27–28; 哥林多前书 10:3–4"> 祝谢了，就擘开，说：<span className="woj">“拿着吃。这是我的身体，是为你们擘开的。你们要这样做，为的是记念我。”</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯来书 9:15–20; 希伯来书 13:20"> 饭后，祂也照样拿起杯来，说：<span className="woj">“这杯是用我的血所立的新约。你们每逢喝的时候，要这样做，为的是记念我。”</span></span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:28; 启示录 1:7; 约翰福音 14:3"> 因为你们每逢吃这饼、喝这杯，就是宣告主的死，直到祂来。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 6:51; 哥林多前书 10:21; 希伯来书 10:29"> 所以，凡以不配主的方式吃这饼或喝主的杯的，就是干犯主的身体和主的血了。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:4; 哥林多后书 13:5; 耶利米哀歌 3:40"> 人应当省察自己，然后才吃这饼、喝这杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 11:27; 哥林多前书 11:30; 哥林多前书 11:32–34"> 因为人若不分辨主的身体，就以不配的方式吃喝，是给自己吃喝审判。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 3:19; 民数记 20:12; 阿摩司 3:2"> 因此，你们中间有许多软弱的、患病的，睡了的也不少。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 1:9; 诗篇 32:3–5; 启示录 2:5"> 我们若分辨自己，就不至于受审判。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:5–11; 诗篇 118:18; 箴言 3:11–12"> 但我们受审判的时候，是被主管教，免得我们和世人一同被定罪。</span>
<span className="v" id="v33" data-v="33"> 所以，我的弟兄们，你们聚集吃的时候，要彼此等候。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 11:21–22; 哥林多前书 7:17; 哥林多前书 4:19"> 若有人饿了，就该在家里吃，免得你们聚集是为了受审判。其余的事，我来的时候会安排妥当。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 12:4–11; 哥林多前书 14:37; 哥林多前书 14:1–18"> 弟兄们，关于属灵的事，我不愿意你们不明白。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 4:3; 帖撒罗尼迦前书 1:9; 诗篇 115:5"> 你们知道，你们作异教徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“外邦人”">a</a></sup>的时候，怎样被牵引，就怎样被带到那些不能说话的偶像那里。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 4:2–3; 马太福音 16:16–17; 罗马书 10:9"> 因此我让你们知道，凡靠着上帝的灵说话的，没有人会说：“耶稣是可咒诅的。”若不是靠着圣灵，也没有人能说：“耶稣是主。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彼得前书 4:10; 哥林多前书 12:28; 罗马书 12:4–6"> 恩赐有各种不同，却是同一位圣灵。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 4:11–12; 罗马书 12:6–8; 罗马书 14:8–9"> 服事有各种不同，却是同一位主。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:7; 哥林多前书 12:11; 约翰福音 5:17"> 运行有各种不同，却是同一位上帝在所有人里面运行万事。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10–11; 罗马书 12:6–8; 哥林多前书 14:19"> 圣灵的显现赐给各人，是要使众人得益处。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; 哥林多前书 2:6–10; 诗篇 143:10"> 有人借着圣灵得了智慧的言语，另有人照着同一位圣灵得了知识的言语，</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 5:14–15; 哥林多后书 4:13; 以弗所书 2:8"> 又有人靠着同一位圣灵得了信心，另有人靠着同一位圣灵得了医治的各种恩赐，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 14:39; 约翰一书 4:1; 马可福音 16:17"> 又有人能行异能，另有人能说预言，另有人能辨别诸灵，另有人能说各种方言，另有人能翻译方言。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:4; 希伯来书 2:4; 哥林多后书 10:13"> 这一切都是同一位圣灵所运行的，祂照自己的意愿分别分给各人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:4–5; 歌罗西书 3:15; 哥林多前书 12:27"> 就如身体是一个，却有许多肢体；身体的肢体虽多，仍是一个身体；基督也是这样。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 歌罗西书 3:11; 加拉太书 3:28"> 因为我们无论是犹太人或希腊人，是为奴的或自由的，都在一位圣灵里受洗，归入一个身体，并且都得以饮于同一位圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 12:27–28; 哥林多前书 12:12; 以弗所书 4:25"> 身体原不是一个肢体，而是许多肢体。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 9:8–15; 列王纪下 14:9"> 如果脚说：“因为我不是手，所以我不属于身体”，它并不能因此就不属于身体。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 哥林多前书 12:22; 腓立比书 2:3"> 如果耳朵说：“因为我不是眼睛，所以我不属于身体”，它并不能因此就不属于身体。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 12:21; 诗篇 139:13–16; 箴言 20:12"> 如果全身都是眼睛，听觉在哪里呢？如果全身都是听觉，嗅觉在哪里呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:28; 罗马书 12:3; 哥林多前书 12:11"> 但如今，上帝照着祂的意愿，把肢体一一安置在身体里。</span>
<span className="v" id="v19" data-v="19"> 如果全都是一个肢体，身体在哪里呢？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 12:14; 哥林多前书 12:12"> 但如今，肢体虽多，身体却是一个。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 10:1–5; 尼希米记 4:16–21; 约伯记 29:11"> 眼睛不能对手说：“我不需要你”；头也不能对脚说：“我不需要你们。”</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 传道书 9:14–15; 传道书 4:9–12"> 不，倒不如说，身体上那些看来比较软弱的肢体，是不可缺少的。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 3:21; 创世记 3:7"> 身体上那些我们认为比较不体面的部分，我们就给它们加上更多体面；我们不雅观的部分，就得到更多遮护，</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 3:11; 创世记 2:25"> 至于我们雅观的部分，并不需要这样。但上帝把身体配搭在一起，把更多尊荣给那较低微的部分，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 13:11; 哥林多前书 1:10–12; 约翰福音 17:21–26"> 使身体里不至于分裂，而是各肢体彼此同样关怀。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 加拉太书 6:2; 希伯来书 13:3"> 若一个肢体受苦，所有肢体就一同受苦；若一个肢体得尊荣，所有肢体就一同喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:12; 歌罗西书 1:24; 以弗所书 5:30"> 你们就是基督的身体，并且各自作肢体。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 4:11–13; 罗马书 12:6–8; 哥林多前书 12:18"> 上帝在教会中设立了一些人：第一是使徒，第二是先知，第三是教师，其次是行异能的，再其次是医治的各种恩赐、帮助、治理、各种方言。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:4–11; 哥林多前书 12:14–20"> 难道都是使徒吗？难道都是先知吗？难道都是教师吗？难道都是行异能的吗？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 12:10"> 难道都有医治的恩赐吗？难道都说各种方言吗？难道都翻译方言吗？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 13:1; 哥林多前书 14:39; 马太福音 5:6"> 你们要热切渴慕那更好的恩赐。而且，我把一条最卓越的道路指示给你们。</span>
</div>
</div>

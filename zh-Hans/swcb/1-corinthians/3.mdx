<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:13; 哥林多前书 2:14–15; 以弗所书 4:13–14"> 弟兄们，我从前不能把你们当作属灵的人说话，只能当作属肉体的人，当作在基督里的婴孩。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:11–14; 约翰福音 16:12; 彼得前书 2:2"> 我喂你们喝奶，没有给你们吃固体食物，因为你们那时还不能承受。其实，就是现在你们也还不能，</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:16; 加拉太书 5:15; 提多书 3:3"> 因为你们仍然是属肉体的。你们中间既然有嫉妒、纷争和结党，你们岂不是属肉体，照着人的方式行事吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:12; 哥林多前书 3:3; 哥林多前书 4:6"> 因为有人说：“我是跟随保罗的，”另有人说：“我是跟随亚波罗的，”你们岂不是属肉体的吗？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:4; 哥林多后书 6:1; 彼得前书 4:10"> 那么，亚波罗算什么？保罗算什么？不过是仆人；你们借着他们信了，并且各人照主所赐给他的服事。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:9–10; 箴言 11:25; 哥林多后书 10:14–15"> 我栽种了，亚波罗浇灌了，惟有上帝使它生长。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:5; 加拉太书 6:3; 诗篇 115:1"> 可见，栽种的算不得什么，浇灌的也算不得什么；惟有使它生长的上帝才算得什么。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 2:6; 马太福音 16:27; 约翰二书 1:8"> 栽种的和浇灌的都是一样的，但各人要照自己的劳苦领受自己的赏赐。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:5; 以弗所书 2:20–22; 哥林多后书 6:1"> 因为我们是上帝的同工；你们是上帝的田地，上帝的建筑。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 3:11; 以弗所书 2:20; 罗马书 15:20"> 我照着上帝赐给我的恩典，像一位明智的总建筑师，立好了根基，另有人在上面建造。但是各人要谨慎，怎样在上面建造。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20; 以赛亚书 28:16; 提摩太后书 2:19"> 因为除了已经立好的根基，就是耶稣基督以外，没有人能立别的根基。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:3; 提摩太后书 3:7; 提摩太后书 2:20"> 如果有人用金、银、宝石、木、草、禾秸在这根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 1:7; 哥林多前书 3:14–15; 启示录 20:12"> 各人的工程都要显露出来。因为那日要把它显明出来，因为它是在火中显现；这火本身要试验各人的工程是怎样的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 3:8; 马太福音 25:21–23; 哥林多前书 4:5"> 如果有人在这根基上建造的工程存留下来，他就要得赏赐。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰二书 1:8; 哥林多前书 3:12–13; 犹大书 1:23"> 如果有人的工程被烧毁，他就要受损失；但他自己要得救，不过像经过火一样。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 6:19; 以西结 36:27; 哥林多后书 6:16"> 难道你们不知道，你们是上帝的殿，上帝的灵住在你们里面吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 6:18–20; 以西结 43:12; 民数记 19:20"> 如果有人毁坏上帝的殿，上帝就要毁坏他；因为上帝的殿是圣洁的，这殿就是你们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以赛亚书 5:21; 加拉太书 6:3"> 谁都不可欺骗自己。如果你们中间有人在这个世代自以为有智慧，就让他成为愚拙的，好使他成为有智慧的。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 5:13; 诗篇 141:10; 哥林多前书 1:19–20"> 因为这个世界的智慧，在上帝看来是愚拙。因为经上记着说：“祂在智慧人的诡计中捉住他们。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 94:11; 歌罗西书 2:8; 罗马书 1:21"> 又说：“主知道智慧人的意念，都是虚妄的。”</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:32; 罗马书 8:28; 耶利米书 9:23–24"> 所以，谁都不可拿人夸口。因为万有都是你们的，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:11–12; 腓立比书 1:21; 哥林多前书 9:19–22"> 无论是保罗，或是亚波罗，或是矶法，或是世界，或是生命，或是死亡，或是现在的事，或是将来的事，全都是你们的；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:29; 哥林多前书 11:3; 约翰福音 17:9–10"> 而你们是基督的，基督是上帝的。</span>
</div>
</div>

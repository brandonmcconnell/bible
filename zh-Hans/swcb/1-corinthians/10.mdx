<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 14:29; 尼希米记 9:11–12; 诗篇 78:13–14"> 弟兄们，我不愿你们不知道：我们的祖先都在云下，都经过了海；</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:2–3; 哥林多前书 1:13–16; 出埃及记 14:31"> 都在云里、海里受洗归入摩西；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:3; 尼希米记 9:15; 出埃及记 16:35"> 都吃了一样的属灵食物；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:6; 约翰福音 7:37; 以赛亚书 48:21"> 也都喝了一样的属灵饮料。因为他们所喝的，是出于那随着他们的属灵磐石；那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 3:17; 犹大书 1:5; 民数记 14:37"> 然而，他们中间多数人，上帝并不喜悦，所以他们倒毙在旷野。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 哥林多前书 10:11; 希伯来书 4:11"> 这些事成了我们的鉴戒，为要使我们不贪恋恶事，像他们贪恋一样。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:6–8; 诗篇 106:19–20; 哥林多前书 6:9"> 你们不要拜偶像，像他们中间有些人那样。如经上所记：“百姓坐下吃喝，起来玩乐。”</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 25:1–9; 哥林多前书 6:18; 诗篇 106:29"> 我们也不要犯淫乱，像他们中间有些人犯了淫乱，一天就倒毙了二万三千人。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 21:5–6; 诗篇 78:18; 希伯来书 3:8–11"> 我们也不要试探基督，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU作“主”，不是“基督”。">a</a></sup>像他们中间有些人试探，结果被蛇毁灭。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:2; 民数记 16:41; 民数记 14:37"> 你们也不要发怨言，像他们中间有些人发怨言，结果被灭命者毁灭。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:4; 罗马书 13:11; 哥林多前书 9:10"> 这些事发生在他们身上，都是作为鉴戒，并且写下来为要警戒我们；众世代的终局已经临到我们了。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:20; 彼得后书 3:17; 箴言 16:18"> 所以，自以为站得稳的人要谨慎，免得跌倒。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:9; 提摩太后书 4:18; 帖撒罗尼迦后书 3:3"> 临到你们的试探，无非是人所共有的。上帝是信实的，祂必不让你们受试探过于你们所能承受的；并且在受试探的时候，也必开一条出路，使你们能忍受得住。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 21:8; 约翰一书 5:21; 彼得前书 2:11"> 所以，我亲爱的弟兄们，你们要逃避拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:1; 帖撒罗尼迦前书 5:21; 哥林多前书 11:13"> 我是对明智人说话；你们要判断我所说的。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:26–28; 哥林多前书 11:23–29; 使徒行传 2:42"> 我们所祝福的祝福之杯，岂不是同享基督的血吗？我们所擘开的饼，岂不是同享基督的身体吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:5; 歌罗西书 3:15; 哥林多前书 12:27"> 因为只有一个饼，我们虽多，仍是一个身体；因为我们都分受这一个饼。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 3:3–5; 加拉太书 6:16; 利未记 7:6"> 你们看看按肉身说的以色列人：那些吃祭物的人，岂不是在祭坛上有份吗？</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 8:4; 哥林多前书 3:7; 哥林多前书 13:2"> 那么，我是在说什么呢？难道祭偶像之物算什么吗？或者偶像算什么吗？</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 9:20; 诗篇 106:37–39; 申命记 32:16–17"> 不是；我是说，外邦人所献的，是献给鬼魔，不是献给上帝；我不愿你们与鬼魔相交。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 列王纪上 18:21; 哥林多后书 6:15–17"> 你们不能既喝主的杯，又喝鬼魔的杯；不能既在主的桌上有份，又在鬼魔的桌上有份。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:21; 申命记 32:16; 希伯来书 10:31"> 或者，我们要惹主嫉妒吗？难道我们比祂强吗？</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:12; 哥林多前书 8:9; 以弗所书 4:29"> “凡事我都可行”，但不都有益处；“凡事我都可行”，但不都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:1–2; 哥林多前书 10:33; 腓立比书 2:4–5"> 谁都不要只求自己的益处，而要各人求邻舍的益处。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前书 4:4; 哥林多前书 8:7; 提多书 1:15"> 凡肉市上卖的，你们只管吃，不要为良心的缘故追问，</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 24:1; 出埃及记 19:5; 诗篇 50:12"> 因为“地和其中所充满的都属于主。”</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 10:25; 路加福音 10:7–8; 哥林多前书 5:9–11"> 如果有不信的人请你们赴席，你们也愿意去，摆在你们面前的，尽管吃，不要为良心的缘故追问。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 8:10–13; 哥林多前书 8:7; 哥林多前书 10:26"> 但如果有人对你们说：“这是献过偶像的”，就不要吃，为了那告诉你们的人，也为了良心的缘故。因为“地和其中所充满的都属于主。”</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:19; 罗马书 14:15–21; 哥林多前书 8:9–13"> 我说的良心，不是你自己的，而是别人的良心。我的自由为什么被别人的良心审判呢？</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 14:6; 提摩太前书 4:3–4"> 我若带着感谢领受，为什么因我所感谢的东西被人毁谤呢？</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:17; 歌罗西书 3:23; 彼得前书 4:11"> 所以，你们或吃或喝，无论做什么，都要为上帝的荣耀而做。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 20:28; 哥林多前书 10:33; 罗马书 14:13"> 不要使犹太人、希腊人，或上帝的教会绊跌；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 10:24; 加拉太书 1:10; 哥林多前书 9:19–23"> 就像我也在凡事上使众人满意，不求自己的益处，只求许多人的益处，使他们可以得救。</span>
</div>
</div>

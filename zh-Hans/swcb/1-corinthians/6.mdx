<span className="v" id="v1" data-v="1" data-xref="马太福音 18:15–17; 使徒行传 19:38; 哥林多前书 14:33"> 你们中间若有人与邻舍有纠纷，竟敢在不义的人面前告状，而不在圣徒面前吗？</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:28; 但以理 7:22; 启示录 20:4"> 难道你们不知道圣徒将要审判世界吗？如果世界要由你们来审判，难道你们不配审理最小的事吗？</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:6; 马太福音 25:41; 哥林多前书 6:4"> 难道你们不知道我们将要审判天使吗？更何况今生的事呢？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 5:12; 使徒行传 6:2–4"> 既然这样，你们若要审理今生的事，难道要设立那些在教会中无足轻重的人来审判吗？</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 15:34; 哥林多前书 4:14; 雅各书 3:13–18"> 我说这话，是要使你们羞愧。难道你们中间连一个智慧人都没有，能够在弟兄之间作判断吗？</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:14–15; 约翰一书 2:9–11; 约翰一书 3:11–15"> 竟然是弟兄与弟兄打官司，而且是在不信的人面前！</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:17–19; 箴言 20:22; 彼得前书 2:19–23"> 所以，你们彼此诉讼，这已经完全是你们的失败了。为什么不宁愿受亏负呢？为什么不宁愿被欺诈呢？</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 4:6; 歌罗西书 3:25; 马可福音 10:19"> 不，你们自己倒行亏负、欺诈的事，而且是对弟兄这样做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:9–10; 加拉太书 5:19–21; 以弗所书 5:4–5"> 难道你们不知道不义的人不能承受上帝的国吗？不要被欺骗。无论是淫乱的人，拜偶像的人，奸淫的人，作男妓的人，行同性性行为的人，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:11; 加拉太书 5:21; 以西结 22:29"> 偷窃的人，贪婪的人，醉酒的人，毁谤的人，勒索的人，都不能承受上帝的国。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:30; 歌罗西书 3:5–7; 哥林多前书 1:2"> 你们中间也有人从前是这样；但你们已经被洗净，已经被分别为圣，已经奉主耶稣的名，并借着我们上帝的圣灵称义了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 10:23–33; 哥林多前书 9:27; 希伯来书 12:15–16"> “凡事我都可行”，但不都有益处。“凡事我都可行”，但我不愿受任何事辖制。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 罗马书 6:12"> “食物是为肚腹，肚腹是为食物”，但上帝要使肚腹和食物都归于无有。身体不是为淫乱，而是为主；主也是为身体。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:14; 罗马书 8:11; 以弗所书 1:19–20"> 上帝已经使主复活，也必借着祂的能力使我们复活。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:30; 罗马书 12:5; 以弗所书 4:15–16"> 难道你们不知道你们的身体是基督的肢体吗？我岂可把基督的肢体拿来作妓女的肢体吗？绝不可！</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 2:24; 以弗所书 5:31; 马可福音 10:8"> 难道你们不知道，与妓女联合的，就是与她成为一体吗？因为祂说：“二人要成为一体。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 17:21–23; 加拉太书 2:20; 哥林多前书 12:13"> 但与主联合的，就是与祂成为一灵。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:11; 帖撒罗尼迦前书 4:3; 歌罗西书 3:5"> 你们要逃避淫乱！“人所犯的一切罪都在身体以外”，但犯淫乱的人，是得罪自己的身体。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 3:16; 哥林多后书 6:16; 彼得前书 2:5"> 难道你们不知道你们的身体是在你们里面的圣灵的殿吗？这圣灵是你们从上帝那里领受的。你们不是属于自己的，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:23; 罗马书 12:1; 彼得前书 2:9"> 因为你们是用重价买来的。所以，要在你们的身体和你们的灵里荣耀上帝，因为它们是属于上帝的。</span>

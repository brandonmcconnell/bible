<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:17; 提摩太前书 2:7; 哥林多前书 9:19"> 我不是自由的吗？我不是使徒吗？我没有见过我们的主耶稣基督吗？你们不是我在主里的工作吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 12:12; 约翰福音 6:27; 哥林多后书 3:1–3"> 即使对别人来说我不是使徒，对你们来说我至少是；因为你们是在主里我作使徒职分的印证。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 12:16–19; 哥林多后书 13:3; 哥林多后书 13:10"> 我对那些审查我的人的申辩就是这样：</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:6; 帖撒罗尼迦后书 3:8–9; 路加福音 10:7"> 难道我们没有权利吃喝吗？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:42; 希伯来书 13:4; 马太福音 8:14"> 难道我们没有权利带着一位信主的妻子同行，像其余的使徒、主的弟兄们和矶法一样吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:7–9; 使徒行传 13:1–2; 使徒行传 4:36"> 难道只有我和巴拿巴没有权利不做工吗？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命记 20:6; 提摩太后书 2:3–4"> 有谁当兵是自备粮饷呢？有谁栽葡萄园，却不吃园中的果子呢？又有谁牧养羊群，却不喝羊群的奶呢？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:20; 帖撒罗尼迦前书 4:8; 罗马书 3:31"> 我说这些话，难道只是照人的方式说的吗？律法不也这样说吗？</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 25:4; 提摩太前书 5:18; 诗篇 104:27"> 因为摩西的律法上写着：“牛踹谷的时候，不可笼住它的嘴。” 上帝所关心的是牛吗？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太后书 2:6; 罗马书 15:4; 罗马书 4:23–24"> 祂这样说，岂不确实是为我们的缘故吗？是的，这是为我们的缘故写的，因为耕种的人理当存着盼望去耕种，打谷的人也该存着盼望，分享他所盼望的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:27; 加拉太书 6:6; 哥林多后书 11:15"> 如果我们在你们中间撒下了属灵的事物，若从你们收割属肉身的事物，算是大事吗？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:15; 哥林多前书 9:18; 哥林多后书 11:12"> 如果别人分享对你们享有的这权利，我们岂不更该吗？<br />然而，我们没有使用这权利，反倒凡事忍受，免得给基督的福音造成任何阻碍。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 18:8–20; 民数记 5:9–10; 利未记 6:26"> 你们不知道办理圣事的人吃殿中的物，伺候祭坛的人从祭坛分得一份吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:10; 提摩太前书 5:17–18; 哥林多前书 9:4"> 主也是这样命定，传福音的人要靠福音生活。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:9; 帖撒罗尼迦后书 3:8; 哥林多前书 9:12"> 但这些权利，我一样也没有用过。我写这些话，并不是要人在我身上这样做；因为我宁可死，也不愿有人使我的夸口落空。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:14; 耶利米书 20:9; 歌罗西书 4:17"> 我若传福音，并没有什么可夸的，因为必要的责任已经加在我身上；我若不传福音，就有祸了。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:7; 哥林多前书 3:8; 历代志上 28:9"> 我若出于自愿做这事，就有赏赐；若不是出于自愿，就是有管家的职分托付给我。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 11:7–9; 哥林多前书 8:9; 帖撒罗尼迦前书 2:6"> 那么，我的赏赐是什么呢？就是我传福音的时候，可以把基督的福音无偿地传给人，免得滥用我在福音上的权利。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 5:13; 马太福音 18:15; 雅各书 5:19–20"> 我虽然不受任何人辖制，却使自己作了众人的奴仆，为的是赢得更多的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:3; 加拉太书 5:18; 使徒行传 21:20–26"> 对犹太人，我就成了像犹太人，为要赢得犹太人；对律法以下的人，我就成了像律法以下的人，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 添加：虽然我自己不在律法之下">a</a></sup>为要赢得律法以下的人；</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:12; 罗马书 2:14; 加拉太书 3:2"> 对没有律法的人，我就成了像没有律法的人（其实我在上帝面前并不是没有律法，而是在基督面前受律法约束），为要赢得没有律法的人。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 10:33; 罗马书 15:1; 哥林多前书 9:19"> 对软弱的人，我就成了软弱的，为要赢得软弱的人。对所有人，我成了各种样子，为要无论如何救一些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:10; 马可福音 8:35; 哥林多前书 9:25–27"> 我做这一切，都是为了福音的缘故，好使我在福音上也一同有份。</span>
<span className="v" id="v24" data-v="24" data-xref="腓立比书 3:14; 希伯来书 12:1; 提摩太后书 4:7–8"> 你们不知道，在赛跑场上奔跑的人都跑，但得奖赏的只有一人吗？你们也要这样跑，好使你们得着奖赏。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 2:5; 启示录 2:10; 提摩太后书 4:7–8"> 凡参加竞技的人，在各方面都有节制。他们这样做，是要得会朽坏的冠冕；我们却是要得不会朽坏的冠冕。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 1:10; 腓立比书 1:21; 提摩太后书 2:5"> 所以我这样跑，不是没有目标；我这样斗拳，不是打空气；</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 8:13; 哥林多前书 9:25; 歌罗西书 3:5"> 我严厉克制自己的身体，使它顺服，免得我传给别人以后，自己反倒被取消资格。</span>
</div>

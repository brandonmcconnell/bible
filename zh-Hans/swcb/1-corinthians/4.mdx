<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 提多书 1:7; 提摩太前书 3:9"> 所以，人应当把我们看作基督的仆役，以及上帝奥秘的管家。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 此外，对管家所要求的，是要显明为忠心。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 7:24; 哥林多前书 2:15; 撒母耳记上 16:7"> 至于我，被你们审判，或被人的审判庭审判，我都看为极小的事；是的，我连自己也不审判。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 143:2; 约翰一书 3:20–21; 诗篇 130:3"> 因为我自觉没有什么亏欠；然而我并不因此称义，审判我的乃是主。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:7; 哥林多后书 5:10; 哥林多前书 3:13"> 所以，时候未到以前，什么都不要审判，只等到主来；祂要把黑暗中隐藏的事照明出来，也要显明人心里的意念。那时，各人都要从上帝那里得到称赞。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:6; 哥林多后书 11:4; 哥林多后书 12:19"> 弟兄们，我为你们的缘故，把这些事用比喻转用在我自己和亚波罗身上，好叫你们在我们身上学习不要越过所写的，免得你们有人为这个人反对另一个人而自高自大。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:27; 彼得前书 4:10; 雅各书 1:17"> 因为谁使你与别人不同呢？你有什么不是领受的呢？既然是领受的，为什么夸口，好像不是领受的呢？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; 箴言 13:7; 哥林多前书 5:6"> 你们已经饱足了，已经富足了；你们离开我们，已经作王了。是的，我倒愿意你们真的作王，好使我们也可以与你们一同作王！</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:33; 罗马书 8:36; 哥林多后书 4:8–12"> 我想，上帝把我们这些使徒列在末后，好像定了死罪的人；因为我们成了给世界观看的场面，包括天使和世人。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 2:3; 使徒行传 26:24; 哥林多前书 3:18"> 我们为基督的缘故是愚拙的，你们在基督里却是有智慧的；我们软弱，你们却刚强；你们有尊荣，我们却受羞辱。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:35; 哥林多后书 11:23–27; 腓立比书 4:12"> 直到现在这一刻，我们还是又饥又渴，衣不蔽体，挨打，居无定所。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:9; 马太福音 5:11; 彼得前书 4:12–14"> 我们劳苦，亲手做工；人咒骂我们，我们就祝福；被迫害，我们就忍受；</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:45; 使徒行传 22:22"> 被毁谤，我们就温和劝导。直到如今，我们成了世界的污秽，成了众人擦掉的污垢。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:11; 哥林多前书 4:15; 约翰三书 1:4"> 我写这些事，不是要使你们羞愧，而是要劝戒你们，好像劝戒我亲爱的儿女。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:19; 哥林多前书 3:10; 哥林多前书 9:14"> 你们在基督里虽然有一万位导师，却没有许多父亲；因为在基督耶稣里，我借着福音成了你们的父亲。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 11:1; 帖撒罗尼迦后书 3:9; 腓立比书 3:17"> 所以，我恳求你们效法我。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:2; 哥林多前书 16:10; 哥林多前书 7:17"> 因此，我已经差提摩太到你们那里去；他是在主里我亲爱而忠心的儿子。他必提醒你们，我在基督里的行事之道，正如我在各处、各教会中所教导的。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:6–8; 哥林多前书 5:2; 哥林多前书 4:21"> 有些人自高自大，以为我不到你们那里去。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 13:1–4; 使徒行传 18:21; 使徒行传 19:21"> 但主若愿意，我不久就要到你们那里去；并且我要知道那些自高自大的人的，不是言语，而是能力。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4; 帖撒罗尼迦前书 1:5; 哥林多后书 10:4–5"> 因为上帝的国不在于言语，而在于能力。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 哥林多后书 13:10; 帖撒罗尼迦前书 2:7"> 你们愿意怎么样呢？要我带着杖到你们那里去，还是带着爱和温柔的灵呢？</span>
</div>

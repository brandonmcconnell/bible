<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:9–10; 申命记 15:11–14; 申命记 8:18"> 每周第一日，你们各人要按自己的收入预先留出一些存起来，免得我来的时候才现凑捐款。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:6; 哥林多前书 11:34; 哥林多前书 4:19–21"> 我到了以后，你们认可谁，我就写信差他们把你们恩惠的礼物送到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 8:4; 哥林多后书 8:19; 罗马书 15:25"> 如果我也该去，他们就和我同去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 19:21; 哥林多前书 4:19; 哥林多后书 1:15–17"> 我经过马其顿以后，要到你们那里去，因为我正要经过马其顿。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 15:3; 罗马书 15:24; 使徒行传 20:38"> 或许我会和你们同住一段时间，甚至在你们那里过冬，好让你们为我送行，无论我往哪里去。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 18:21; 哥林多前书 4:19; 雅各书 4:15"> 我现在不愿只是路过时见你们；如果主许可，我盼望和你们同住一些时候。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:1; 出埃及记 23:16; 使徒行传 18:19"> 但我要留在以弗所，直到五旬节，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 2:12; 使徒行传 14:27; 歌罗西书 4:3"> 因为有一扇又大又有功效的门向我开了，而且反对的人也多。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 15:58; 帖撒罗尼迦前书 3:2; 罗马书 16:21"> 如果提摩太来了，你们要留心使他在你们那里无所惧怕，因为他和我一样，做主的工作。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 4:12; 使徒行传 15:33; 提多书 2:15"> 所以，不要让任何人轻看他。你们要平安地送他上路，使他到我这里来；因为我正等着他和弟兄们一同来。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:12; 哥林多前书 3:5; 提多书 3:4"> 关于弟兄亚波罗，我极力劝他和弟兄们一同到你们那里去；但他现在完全不愿意去，等有机会的时候他会去。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:9; 以弗所书 6:13–18; 以弗所书 6:10"> 要警醒！要在信心上站立得稳！要勇敢！要刚强！</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:34–35; 彼得前书 4:8; 提摩太前书 1:5"> 你们所做的一切，都要凭着爱心而做。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 1:16; 罗马书 16:5; 罗马书 16:2"> 弟兄们，我劝你们——你们知道司提反一家，他们是亚该亚初熟的果子，并且他们专心服侍圣徒——</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:17; 帖撒罗尼迦前书 5:12; 约翰三书 1:8"> 你们也要顺服这样的人，并顺服所有同工劳苦的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 11:9; 腓立比书 2:30; 腓利门书 1:13"> 司提反、福徒拿都和亚该古来了，我很欢喜；因为你们所缺少的，他们补足了。</span>
<span className="v" id="v18" data-v="18" data-xref="腓利门书 1:7; 哥林多后书 7:13; 帖撒罗尼迦前书 5:12"> 他们使我和你们的灵都畅快。所以，你们要认可这样的人。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 腓利门书 1:2; 罗马书 16:3–5"> 亚细亚的各教会问候你们。亚居拉和百基拉，以及在他们家里的教会，在主里热切问候你们。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 16:16; 帖撒罗尼迦前书 5:26; 彼得前书 5:14"> 众弟兄都问候你们。你们要用圣洁的亲吻彼此问候。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歌罗西书 4:18; 加拉太书 6:11; 帖撒罗尼迦后书 3:17"> 这问候是我保罗亲手写的。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:24; 约翰福音 14:21; 哥林多后书 5:14–15"> 如果有人不爱主耶稣基督，愿他受咒诅。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希腊语：anathema。">a</a></sup>主啊，来吧！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亚兰语：Maranatha！">b</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 16:20; 罗马书 16:23"> 愿主耶稣基督的恩典与你们同在。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 14:16; 启示录 3:19; 哥林多后书 12:15"> 我在基督耶稣里的爱与你们众人同在。阿们。</span>

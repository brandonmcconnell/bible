<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 1:1; 以弗所书 1:1; 哥林多后书 1:1"> 保罗，借着上帝的旨意蒙召作耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>的使徒，和我们的弟兄所提尼，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多前书 6:9–11; 哥林多前书 1:30"> 写信给在哥林多的上帝的教会，就是在基督耶稣里被圣别、蒙召作圣徒的人，以及所有在各处呼求我们主耶稣基督之名的人；祂是他们的主，也是我们的主：</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 1:7; 哥林多后书 1:2; 彼得前书 1:2"> 愿恩典与平安从我们的父上帝和主耶稣基督归给你们。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:8; 约翰福音 14:26; 提摩太前书 1:14"> 我常常为你们感谢我的上帝，因为上帝在基督耶稣里赐给你们的恩典，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 9:11; 哥林多后书 8:7; 歌罗西书 2:3"> 使你们在祂里面凡事富足，在一切言语和一切知识上都富足——</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:2; 提摩太后书 1:8; 提摩太前书 2:6"> 正如基督的见证在你们中间得以坚固——</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 3:20; 彼得后书 3:12; 希伯来书 9:28"> 以致你们在任何恩赐上都不缺少，等候我们主耶稣基督的显现；</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:23–24; 帖撒罗尼迦前书 3:13; 歌罗西书 1:22"> 祂也必坚固你们到底，使你们在我们主耶稣基督的日子无可指责。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:3; 希伯来书 10:23; 申命记 7:9"> 上帝是信实的；你们是借着祂蒙召，进入祂儿子我们主耶稣基督的团契。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:1–4; 以弗所书 4:1–7; 哥林多前书 12:25"> 弟兄们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里译作“弟兄们”的词，在上下文允许的地方，也可正确译作“弟兄姊妹们”或“手足们”。">b</a></sup>我借着我们主耶稣基督的名劝你们：你们都要说一样的话，你们中间不可有分裂，而要在同一心思、同一判断上完全联合。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:6; 提摩太前书 6:4; 提摩太后书 2:23–25"> 我的弟兄们，因为革来氏家里的人向我报告了关于你们的事，说你们中间有纷争。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:21–23; 约翰福音 1:42; 马太福音 23:9–10"> 我的意思是，你们各人说：“我跟随保罗”，“我跟随亚波罗”，“我跟随矶法”，还有：“我跟随基督”。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 哥林多后书 11:4; 使徒行传 2:38"> 基督是分开的吗？保罗为你们钉了十字架吗？或者你们是奉保罗的名受洗的吗？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 18:8; 罗马书 16:23; 哥林多前书 1:4"> 我感谢上帝，除了基利司布和该犹以外，我没有给你们任何人施洗，</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 11:2; 约翰福音 3:28–29; 约翰福音 7:18"> 免得有人说，我曾奉自己的名给你们施洗。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:15; 哥林多前书 16:17; 使徒行传 16:33"> （我也给司提反一家施过洗；此外，我不知道还给别的什么人施过洗没有。）</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 2:1; 哥林多前书 2:13; 彼得后书 1:16"> 因为基督差遣我，不是为施洗，而是为传福音——不是用言辞的智慧，免得基督的十字架落了空。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 2:14; 罗马书 1:16; 帖撒罗尼迦后书 2:10"> 因为十字架的道，对正在灭亡的人是愚拙；但对我们正在得救的人，却是上帝的大能。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 29:14; 耶利米书 8:9; 哥林多前书 3:19"> 因为经上记着：<br /><span className="pl pl-1">“我要毁灭智慧人的智慧，</span><br /><span className="pl pl-2">我要废弃明达人的明达。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:22; 约伯记 12:17; 哥林多前书 3:19"> 智慧人在哪里？文士在哪里？这时代的辩士在哪里？上帝岂不是使这世界的智慧成为愚拙了吗？</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 10:21; 罗马书 1:20–22; 马太福音 11:25"> 因为在上帝的智慧中，世人凭自己的智慧不认识上帝，上帝就乐意借着所传信息的愚拙，拯救那些信的人。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:1–4; 马太福音 12:38–39; 马可福音 8:11"> 犹太人求神迹，希腊人寻求智慧，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 2:14; 哥林多前书 2:2; 彼得前书 2:8"> 我们却传被钉十字架的基督；这对犹太人是绊脚石，对希腊人是愚拙，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 1:30; 歌罗西书 2:3; 哥林多前书 1:18"> 但对那些蒙召的人，无论是犹太人还是希腊人，基督是上帝的大能，上帝的智慧；</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 11:33–36; 哥林多前书 1:18; 撒迦利亚书 4:6–7"> 因为上帝的愚拙比人更有智慧，上帝的软弱比人更刚强。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:5; 哥林多前书 3:18–20; 雅各书 1:9–11"> 弟兄们，你们看自己蒙召的情形：按肉体来说，有智慧的不多，有能力的不多，出身尊贵的也不多；</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 2:5; 马太福音 11:25; 哥林多前书 1:20"> 但上帝拣选了世上愚拙的，为要使有智慧的羞愧；上帝拣选了世上软弱的，为要使刚强的羞愧；</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 34:24; 罗马书 4:17; 以赛亚书 2:11"> 上帝拣选了世上卑微的、被人藐视的，以及那不存在的，为要使那存在的归于无有，</span>
<span className="v" id="v29" data-v="29" data-xref="罗马书 3:27; 耶利米书 9:23; 以弗所书 2:9"> 使凡有血肉的，在上帝面前都不能夸口。</span>
<span className="v" id="v30" data-v="30" data-xref="以弗所书 1:7; 腓立比书 3:9; 罗马书 8:1"> 但你们因着祂而在基督耶稣里；基督成了我们从上帝而来的智慧，又成了我们的义、圣别和救赎，</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 9:23–24; 哥林多后书 10:17; 腓立比书 3:3"> 正如经上记着：“夸口的，应当在主里夸口。”</span>
</div>
</div>

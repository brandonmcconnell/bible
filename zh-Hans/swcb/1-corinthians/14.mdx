<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1CO" data-book-slug="1-corinthians" data-book-name="哥林多前书" data-chapter="14" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 14:39; 提摩太前书 4:14; 哥林多前书 12:1"> 要追求爱，也要切慕属灵的恩赐，但尤其要切慕作先知讲道。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:17; 使徒行传 19:6; 使徒行传 10:46"> 因为说别的语言的人，不是对人说，而是对上帝说，因为没有人听得懂；但他在圣灵里讲说奥秘。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 14:12; 提摩太前书 4:13; 犹大书 1:20"> 但作先知讲道的人，是对人说话，为要造就、劝勉、安慰人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 14:22; 哥林多前书 14:26; 马可福音 16:17"> 说别的语言的人造就自己；作先知讲道的人造就教会。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:28–30; 哥林多前书 12:10; 马可福音 16:17"> 我愿意你们都说别的语言，但更愿意你们作先知讲道。因为作先知讲道的人，比说别的语言的人更重要，除非那人能翻译出来，使教会得到造就。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所书 1:17; 罗马书 6:17; 提摩太后书 3:16"> 弟兄们，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“弟兄”一词在这里以及上下文允许的地方，也可正确译为“弟兄姊妹”或“手足”。">a</a></sup>现在，如果我到你们那里，只说别的语言，却不用启示，或知识，或预言，或教导对你们说话，我对你们有什么益处呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 14:8; 路加福音 7:32; 哥林多前书 13:1"> 即使是无生命而发声的东西，无论是笛子或琴，如果发出的音调没有区别，怎能知道所吹或所弹的是什么呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 10:9; 以西结 33:3–6; 耶利米书 4:19"> 如果号角发出不明确的声音，谁会预备自己去打仗呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 9:26"> 你们也是这样，如果不用舌头说出容易明白的话，怎能知道所说的是什么呢？因为你们就是对着空气说话。</span>
<span className="v" id="v10" data-v="10"> 世上的语言种类或许很多，没有一种是没有意义的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:2; 罗马书 1:14; 歌罗西书 3:11"> 所以，如果我不明白那语言的意思，对说话的人来说，我就是外族人；说话的人对我来说，也是外族人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 14:26; 哥林多前书 14:3–4; 哥林多前书 14:1"> 你们也是这样，既然热切追求属灵的恩赐，就要寻求在造就教会的事上更加丰盛。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:24; 哥林多前书 12:30; 约翰福音 14:13–14"> 因此，说别的语言的人应当祈求自己能翻译出来。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 14:2; 哥林多前书 14:15–16; 哥林多前书 14:19"> 因为如果我用别的语言祷告，我的灵在祷告，但我的悟性没有果效。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 3:16; 约翰福音 4:23–24; 以弗所书 6:18"> 那么怎么办呢？我要用灵祷告，也要用悟性祷告；我要用灵歌唱，也要用悟性歌唱。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 16:36; 诗篇 106:48; 启示录 5:14"> 否则，如果你用灵祝谢，那站在不通晓者位置上的人，既然不知道你在说什么，怎能在你感谢的时候说“阿们”呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 14:4; 哥林多前书 14:6"> 你固然感谢得好，但别人没有得到造就。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:4–6; 哥林多前书 4:7"> 我感谢我的上帝，我说别的语言比你们众人都多。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:21–22; 哥林多前书 14:4"> 然而，在教会中，我宁愿用悟性说五句话，使我也可以教导别人，胜过用别的语言说一万句话。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:2; 哥林多前书 13:11; 罗马书 16:19"> 弟兄们，在心思上不要作小孩子；然而在恶事上要作婴孩，在心思上却要成熟。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 28:11–12; 耶利米书 5:15; 申命记 28:49"> 律法上记着：“我要藉着说陌生语言的人，藉着外族人的嘴唇，对这百姓说话；即使这样，他们也不听我，主说。”</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:6–12; 马可福音 16:17; 哥林多前书 14:1"> 所以，别的语言是一个记号，不是给信的人，而是给不信的人；作先知讲道也是一个记号，不是给不信的人，而是给信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 2:13; 使徒行传 26:24; 哥林多前书 11:18"> 所以，如果全教会聚集在一起，众人都说别的语言，又有不通晓的人或不信的人进来，他们岂不说你们发疯了吗？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:37; 哥林多前书 2:15; 希伯来书 4:12–13"> 但如果众人都作先知讲道，有不信的人或不通晓的人进来，他就被众人责备，被众人审断。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:14; 撒迦利亚书 8:23; 诗篇 72:11"> 这样，他心里的秘密就显露出来。于是他会俯伏在地敬拜上帝，宣告上帝确实在你们中间。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 5:19; 罗马书 14:19; 哥林多前书 12:7–10"> 那么，弟兄们，该怎么做呢？你们聚在一起的时候，各人或有一首诗歌，或有一个教导，或有一个启示，或有一种别的语言，或有一个翻译。凡事都要为造就彼此而做。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 14:26"> 如果有人说别的语言，只可有两个人，至多三个人，并且要轮流说；还要有一个人翻译。</span>
<span className="v" id="v28" data-v="28"> 如果没有翻译的人，他就当在教会中静默，只对自己和上帝说。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:10; 帖撒罗尼迦前书 5:19–21; 约翰一书 4:1–3"> 至于先知，可以让两三个人说话，其他人要分辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19–20; 约伯记 33:31–33; 约伯记 32:11"> 如果有启示临到旁边坐着的人，先说的人就当静默。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 5:14; 哥林多前书 14:3; 帖撒罗尼迦前书 5:11"> 因为你们都可以一个一个地作先知讲道，使众人都可以学习，众人都可以受到劝勉。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:19–20; 约翰一书 4:1; 撒母耳记上 10:10–13"> 先知的灵是顺服先知的，</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 3:17–18; 哥林多前书 14:40; 帖撒罗尼迦后书 3:16"> 因为上帝不是混乱的上帝，而是平安的上帝，正如在众圣徒的各教会中一样。</span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前书 2:11–12; 创世记 3:16; 民数记 30:3–13"> 妻子们在各教会中要安静，因为不允许她们说话，倒要顺服，正如律法也说的，</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所书 5:12; 彼得前书 3:7; 以弗所书 5:25–27"> 如果她们想学什么，“就让她们在家里问自己的丈夫，因为妻子在教会中说话是可耻的。”</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 18:1–17; 撒迦利亚书 14:8; 使徒行传 17:15"> 什么！？上帝的道是从你们传出去的吗？难道单单临到你们吗？</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 哥林多后书 10:7; 彼得后书 3:2"> 如果有人自以为是先知或属灵的人，就该承认我写给你们的这些事是主的命令。</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太后书 4:3–4; 何西阿 4:17; 启示录 22:11–12"> 但如果有人无知，就让他无知吧。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:31; 哥林多前书 14:1; 帖撒罗尼迦前书 5:20"> 所以，弟兄们，要切慕作先知讲道，也不要禁止说别的语言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌罗西书 2:5; 提多书 1:5; 哥林多前书 14:26–33"> 凡事都要规规矩矩地，按着次序行。</span>
</div>
</div>

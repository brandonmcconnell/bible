<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1CO" data-book-slug="1-corinthians" data-book-name="哥林多前书" data-chapter="15" data-verses="58">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:6–12; 彼得前书 5:12; 哥林多前书 15:3–11"> 弟兄们，现在我要使你们知道我所传给你们的福音；这福音你们也领受了，并且也站立在其中。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:6; 希伯来书 2:1; 希伯来书 3:14"> 你们若持守我传给你们的道，就也借着这福音得救；否则，你们就是徒然信了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 2:24; 加拉太书 1:4; 以赛亚书 53:1–12"> 因为我首先传给你们的，也是我所领受的：基督照着圣经所说，为我们的罪死了，</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿 6:2; 马太福音 12:40; 诗篇 16:10–11"> 并且埋葬了，又照着圣经所说，第三天复活了；</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:14; 哥林多前书 1:12; 约翰福音 1:42"> 又向矶法显现，然后向十二使徒显现。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 28:10; 马可福音 16:7; 使徒行传 13:36"> 后来祂一次向五百多位弟兄显现，其中大多数到如今还在，但也有些已经睡了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行传 1:2–12; 路加福音 24:33"> 后来祂向雅各显现，然后向众使徒显现；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 9:1; 使徒行传 26:16; 使徒行传 22:18"> 最后，也向我这个像未到产期而生的人显现。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:7–8; 提摩太前书 1:13–15; 使徒行传 8:3"> 我原是使徒中最小的，不配称为使徒，因为我曾迫害上帝的教会。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 哥林多后书 3:5; 腓立比书 2:13"> 然而，靠着上帝的恩典，我成了现在的我。祂赐给我的恩典并不是徒然的；我比他们众人更多劳苦；其实不是我，而是与我同在的上帝的恩典。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:3–4; 哥林多前书 2:2"> 所以，无论是我，还是他们，我们都是这样传，你们也这样信了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:8; 使徒行传 17:32; 提摩太后书 2:18"> 既然所传的是基督已经从死人中复活，怎么你们中间有人说没有死人复活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:25–26; 罗马书 8:11; 帖撒罗尼迦前书 4:14"> 如果没有死人复活的事，基督也就没有复活。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:17; 帖撒罗尼迦前书 4:14; 加拉太书 2:2"> 如果基督没有复活，那么我们的传讲就是徒然，你们的信心也是徒然。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 约伯记 13:7–10; 使徒行传 2:32"> 而且我们也被发现是为上帝作假见证的人，因为我们为上帝作见证说祂使基督复活了；如果死人真的不复活，祂就没有使基督复活。</span>
<span className="v" id="v16" data-v="16"> 因为如果死人不复活，基督也就没有复活。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 4:25; 彼得前书 1:3; 哥林多前书 15:14"> 如果基督没有复活，你们的信心就是徒然；你们仍在自己的罪中。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 4:13–14; 启示录 14:13; 帖撒罗尼迦前书 4:16"> 那么，那些在基督里睡了的人也灭亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 1:21; 启示录 14:13; 提摩太后书 1:12"> 如果我们只在今生对基督有盼望，我们就是所有人中最可怜的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 15:23; 使徒行传 26:23; 启示录 1:5"> 但如今基督已经从死人中复活，成了睡了之人初熟的果子。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:25; 罗马书 5:12–17; 哥林多前书 15:22"> 死既然是借着人来的，死人复活也照样是借着人来的。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 5:12–21; 哥林多前书 15:45–49; 约翰福音 5:21–29"> 因为在亚当里众人都死了，照样，在基督里众人也都要得生命。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 26:19; 加拉太书 3:29; 哥林多前书 15:52"> 但各人按自己的次序：基督是初熟的果子；然后，在祂来的时候，属于基督的人也要复活。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 7:27; 但以理 7:14; 马太福音 28:18"> 随后，末期就到了；那时祂要把国交给父上帝，那时祂已经废除一切统治、一切权柄和能力。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:12–13; 诗篇 110:1; 马太福音 22:44"> 因为祂必须作王，直到祂把一切仇敌都放在祂的脚下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:10; 哥林多前书 15:55; 启示录 21:4"> 最后要被废除的仇敌就是死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 8:6; 希伯来书 2:8; 马太福音 28:18"> 因为：“祂使万物都服在祂的脚下。” 但既然说“万物都服了”，显然那使万物服祂的，不在其内。</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:11; 哥林多前书 3:23; 以弗所书 1:23"> 万物既都服了祂，那时子自己也要服于那使万物服祂的，好使上帝在万有之中成为万有。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="罗马书 6:3–4; 哥林多前书 15:16; 马太福音 20:22"> 不然，那些为死人受洗的人将要做什么呢？如果死人完全不复活，他们为什么还为死人受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 6:9; 加拉太书 5:11; 哥林多后书 4:7–12"> 我们又为什么时刻处在危险中呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:10–11; 罗马书 8:36; 哥林多前书 4:9–13"> 我在我们的主基督耶稣里因你们而夸耀；我指着这夸耀断言：我天天面对死亡。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 22:13; 以赛亚书 56:12; 路加福音 12:19"> 如果我是出于人的目的，在以弗所同野兽搏斗，那对我有什么益处呢？如果死人不复活，那么“让我们吃喝吧，因为明天我们就死了。”</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 马太福音 24:4; 哥林多前书 5:6"> 不要被迷惑！“恶劣的交往败坏良好的品行。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 6:5; 罗马书 13:11; 希伯来书 5:11–12"> 要合乎公义地醒悟过来，不要犯罪；因为有人不认识上帝。我说这话，是要叫你们羞愧。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西结 37:3; 哥林多前书 15:38–53; 罗马书 9:19"> 但有人会说：“死人怎样复活呢？”又说：“他们带着怎样的身体来呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 12:24; 路加福音 11:40; 以弗所书 5:15"> 愚昧的人哪！你自己所种的，若不死，就不能得生命。</span>
<span className="v" id="v37" data-v="37"> 你所种的，并不是将来要成的身体，而只是一粒光秃的种子，也许是麦子，也许是别的种子。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 3:7; 以赛亚书 61:11; 马可福音 4:26–29"> 但上帝随自己的意思给它一个身体，并且给每一种子各自的身体。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 1:20–26"> 并非所有血肉之体都是同样的血肉之体；人的血肉是一种，兽的血肉又是一种，鱼的又是一种，鸟的又是一种。</span>
<span className="v" id="v40" data-v="40"> 也有天上的形体和地上的形体；但天上形体的荣光与地上形体的荣光不同。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 24:23; 诗篇 148:3–5; 申命记 4:19"> 太阳有一种荣光，月亮有另一种荣光，众星又有另一种荣光；这颗星与那颗星在荣光上也有不同。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:43; 但以理 12:3; 罗马书 8:21"> 死人复活也是这样。所种的是会朽坏的身体，复活的是不朽坏的身体；</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前书 6:14; 歌罗西书 3:4; 腓立比书 3:20–21"> 所种的是羞辱的，复活的是荣耀的；所种的是软弱的，复活的是有能力的；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 15:50; 路加福音 24:31; 约翰福音 20:19"> 所种的是属自然生命的身体，复活的是属灵的身体。既有属自然生命的身体，也有属灵的身体。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 5:21; 创世记 2:7; 罗马书 8:2"> 经上也是这样记着：“第一个人亚当成了有生命的活人。” 末后的亚当成了赐生命的灵。</span>
<span className="v" id="v46" data-v="46" data-xref="歌罗西书 3:9–10; 罗马书 6:6; 以弗所书 4:22–24"> 但属灵的不是在先，属自然生命的才是在先，然后才是属灵的。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:31; 创世记 2:7; 创世记 3:19"> 第一个人出于地，是属尘土的；第二个人是从天上来的主。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 5:3; 罗马书 5:12–21; 约翰福音 3:6"> 那属尘土的怎样，凡属尘土的也怎样；那属天的怎样，凡属天的也怎样。</span>
<span className="v" id="v49" data-v="49" data-xref="罗马书 8:29; 哥林多后书 3:18; 创世记 5:3"> 我们既然带着属尘土者的形像，就让我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU、TR作“我们也将要”而非“让我们也”。">a</a></sup>也带着属天者的形像。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 3:3–6; 马太福音 16:17; 以弗所书 4:17"> 弟兄们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里“弟兄们”一词，以及上下文允许之处，也可以正确译为“弟兄姐妹们”或“手足们”。">b</a></sup>我现在说，血肉之体不能承受上帝的国；会朽坏的也不能承受不朽坏的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v51" data-v="51" data-xref="帖撒罗尼迦前书 4:14–17; 腓立比书 3:21; 哥林多前书 15:20"> 看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”源自“ἰδοὺ”，意思是看、留意、观察、看见或凝视，常用作感叹词。">c</a></sup>我告诉你们一个奥秘：我们不会都睡去，但我们都要改变，</span>
<span className="v" id="v52" data-v="52" data-xref="帖撒罗尼迦前书 4:16–17; 马太福音 24:31; 约翰福音 5:28"> 就在一刹那，眨眼之间，最后的号角吹响的时候。因为号角要吹响，死人要复活成为不朽坏的，我们也要改变。</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多后书 5:2–4; 约翰一书 3:2; 罗马书 2:7"> 因为这会朽坏的身体必须穿上不朽坏，这必死的身体也必须穿上不死。</span>
<span className="v" id="v54" data-v="54" data-xref="以赛亚书 25:8; 启示录 20:14; 希伯来书 2:14–15"> 这会朽坏的身体既穿上了不朽坏，这必死的身体既穿上了不死，那时经上所记的事就要应验：“死亡被胜利吞灭了。”</span>
<span className="v" id="v55" data-v="55" data-xref="何西阿 13:14; 诗篇 89:48; 使徒行传 2:27"> <span className="pl pl-1">“死亡啊，你的毒刺在哪里？</span><br /><span className="pl pl-2">阴间啊，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：地狱">d</a></sup><br /><span className="pl pl-2">你的胜利在哪里？”</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="罗马书 4:15; 加拉太书 3:10–13; 罗马书 7:5–13"> 死亡的毒刺就是罪，罪的权势就是律法。</span>
<span className="v" id="v57" data-v="57" data-xref="哥林多后书 2:14; 罗马书 8:37; 约翰一书 5:4–5"> 但感谢上帝，祂借着我们的主耶稣基督把胜利赐给我们。</span>
<span className="v" id="v58" data-v="58" data-xref="加拉太书 6:9; 历代志下 15:7; 希伯来书 6:10"> 所以，我亲爱的弟兄们，你们务要坚定，不可动摇，常常多做主的工作，因为你们知道，你们在主里的劳苦不是徒然的。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 7:8; 哥林多前书 7:26–27; 哥林多前书 7:37–38"> 关于你们写信问我的事：男人不亲近女人是好的。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 5:28; 以弗所书 5:33; 哥林多前书 7:9"> 但因有淫乱的事，各男人应当有自己的妻子，各女人也应当有自己的丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 3:7; 出埃及记 21:10"> 丈夫要把妻子应得的夫妻情分给她，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU和TR作“她所应得的”，而不是“她应得的夫妻情分”。">a</a></sup>妻子待丈夫也要照样。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿 3:3; 马太福音 19:9; 马可福音 10:11–12"> 妻子对自己的身体没有主权，丈夫才有；同样，丈夫对自己的身体也没有主权，妻子才有。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:15; 约珥 2:16; 撒迦利亚书 12:12–14"> 不可彼此剥夺，除非双方同意，暂时如此，好使你们专心禁食和祷告；之后还要再在一起，免得撒但因你们不能自制而试探你们。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 8:8; 哥林多前书 7:25; 哥林多前书 7:12"> 我说这话是出于准许，不是出于命令。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 19:11–12; 罗马书 12:6; 哥林多前书 9:5"> 然而我愿意所有人都像我一样。不过，各人都有自己从上帝所得的恩赐：这个人是这样，那个人是那样。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:32; 哥林多前书 7:34–35; 哥林多前书 7:26–27"> 我对未婚的人和寡妇说，他们若保持像我这样，是好的。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 7:2; 提摩太前书 5:14; 提摩太前书 5:11"> 但如果他们不能自制，就应当结婚；因为结婚总比欲火焚身好。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 5:32; 路加福音 16:18; 马太福音 19:3–9"> 至于已经结婚的人，我吩咐——不是我，而是主吩咐——妻子不可离开丈夫</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:1; 哥林多前书 7:10; 以赛亚书 50:1"> （但如果她离开了，就应当保持不嫁，或者与丈夫和好），丈夫也不可离弃妻子。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 11:17; 哥林多前书 7:6; 哥林多前书 7:25"> 至于其余的人，是我说，不是主说：若有弟兄有不信的妻子，而她愿意和他同住，他就不可离弃她。</span>
<span className="v" id="v13" data-v="13"> 女人有不信的丈夫，而他愿意和她同住，她就不可离弃丈夫。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 2:15–16; 提摩太前书 4:5; 提多书 1:15"> 因为不信的丈夫因着妻子被分别为圣；不信的妻子也因着丈夫被分别为圣。否则，你们的儿女就是不洁净的；但如今他们是圣洁的。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:19; 哥林多后书 13:11; 雅各书 3:17–18"> 然而，若不信的一方要离开，就让他离开吧。在这样的事上，弟兄或姊妹不受束缚；但上帝召我们是为了平安。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:1–2; 哥林多前书 9:22; 罗马书 11:14"> 妻子啊，你怎么知道你是否会使丈夫得救呢？丈夫啊，你又怎么知道你是否会使妻子得救呢？</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 4:17; 罗马书 12:3–8; 哥林多前书 7:24"> 只要照着主分给各人的，照着上帝召各人的，各人就这样行事为人。我在众教会中都是这样吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:5; 使徒行传 15:28; 使徒行传 15:24"> 有人蒙召时已经受了割礼吗？他就不要变成未受割礼的样子。有人蒙召时未受割礼吗？他就不要受割礼。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:15; 加拉太书 5:6; 约翰一书 2:3–4"> 受割礼算不得什么，未受割礼也算不得什么；重要的是遵守上帝的诫命。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:17; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:12"> 各人蒙召时处在什么身份，就应当留在那身份中。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:18–24; 歌罗西书 3:11; 路加福音 10:40–41"> 你蒙召时是奴仆吗？不要因此忧虑；但如果你有机会得自由，就利用这个机会。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 腓利门书 1:16; 歌罗西书 3:22–24"> 因为蒙召时作奴仆的人，在主里是主所释放的人；同样，蒙召时自由的人，是基督的奴仆。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:20; 彼得前书 1:18–19; 提多书 2:14"> 你们是重价买来的；不要作人的奴仆。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 7:20; 歌罗西书 3:23–24; 哥林多前书 7:17"> 弟兄们，各人蒙召时处在什么处境，就应当在上帝面前留在那处境中。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 7:6; 哥林多前书 4:2; 哥林多前书 7:40"> 关于童女，我没有从主来的命令，但我作为蒙主怜悯、成为可信的人，提出我的判断。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 7:1; 哥林多前书 7:8; 彼得前书 4:17"> 因此，我认为由于当前的艰难，人保持现状是好的。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:20; 哥林多前书 7:12–14"> 你已经有妻子的约束吗？不要寻求解脱。你没有妻子的约束吗？不要寻求妻子。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 13:4; 哥林多前书 7:32–36; 哥林多前书 7:26"> 但你若结婚，并没有犯罪；童女若结婚，也没有犯罪。然而这样的人在肉身上会有苦难，而我想使你们免受这苦。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 2:17; 哥林多前书 7:31; 罗马书 13:11–12"> 弟兄们，我是说：时候缩短了。从今以后，有妻子的，要像没有妻子一样；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哭泣的，要像不哭泣一样；喜乐的，要像不喜乐一样；买东西的，要像没有拥有一样；</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 2:17; 彼得前书 4:7; 雅各书 4:14"> 使用这世界的，要像没有尽情使用一样；因为这世界的样式正在过去。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:25–34; 提摩太前书 5:5; 腓立比书 4:6"> 我愿意你们无所挂虑。未婚的人挂念主的事，想着怎样使主喜悦；</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:25–33"> 已婚的人却挂念世上的事，想着怎样使妻子喜悦。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前书 6:20; 路加福音 2:36–37"> 妻子和童女之间也有分别。未婚的女子挂念主的事，好使她身体和灵都圣洁；已婚的女子却挂念世上的事，想着怎样使丈夫喜悦。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 7:33–34; 哥林多前书 7:36; 路加福音 8:14"> 我说这话是为你们自己的益处，不是要套住你们，而是要你们行合宜的事，并且能不分心地专注于主。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 7:37; 哥林多前书 7:9; 撒母耳记上 2:33"> 但如果有人认为自己对待自己的童女不合宜，若她已经过了青春盛期，而事情又确有需要，他就可以随自己的意思去做；他没有犯罪。让他们结婚吧。</span>
<span className="v" id="v37" data-v="37"> 但那心里坚定、没有迫不得已的需要，又能掌控自己意愿的人，若心里决定守住自己的童女，他做得好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 13:4; 哥林多前书 7:1–2; 哥林多前书 7:8"> 这样看来，把自己的童女嫁出去的人做得好；不把她嫁出去的人做得更好。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:2–3; 哥林多后书 6:14–16; 哥林多前书 7:10"> 丈夫活着多久，妻子就在律法上受约束多久；但丈夫若死了，她就自由了，可以随自己的意思嫁给谁，只是要在主里。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 7:35; 彼得后书 3:15–16; 哥林多前书 7:8"> 然而，照我的判断，她若保持现状，就更有福；我想我也有上帝的圣灵。</span>
</div>
</div>

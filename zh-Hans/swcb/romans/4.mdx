<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 51:2; 罗马书 4:16; 哥林多后书 11:22"> 那么，按着肉体来说，我们的祖先亚伯拉罕得了什么呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 1:31; 哥林多后书 11:30; 腓立比书 3:9"> 如果亚伯拉罕是因行为称义，他就有可夸口的，但在上帝面前却不能。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 15:6; 雅各书 2:23; 加拉太书 3:6–8"> 经上是怎么说的呢？“亚伯拉罕信上帝，这就算为他的义。”</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 11:6; 罗马书 9:32; 罗马书 11:35"> 对于做工的人，得报酬不算是恩典，而是应得的。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:9; 罗马书 3:22; 提多书 3:3–7"> 但对于不靠行为，只信靠那称不敬虔之人为义之上帝的人，他的信心就算为义。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 1:9; 腓立比书 3:9; 哥林多前书 1:30"> 正如大卫也论到那在行为之外蒙上帝算为义的人是有福的：</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 32:1–2; 诗篇 130:3–4; 路加福音 7:47–50"> <span className="pl pl-1">“过犯得蒙赦免、</span><br /><span className="pl pl-2">罪恶被遮盖的人，是有福的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 32:2; 彼得前书 2:24; 哥林多后书 5:19–20"> <span className="pl pl-1">主绝不将罪算在他身上的那人，是有福的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:14; 歌罗西书 3:11; 加拉太书 3:26–28"> 那么，这种福分是只赐给受割礼的人，还是也赐给未受割礼的人呢？因为我们说，亚伯拉罕的信心被算为他的义。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 6:15; 加拉太书 5:6; 创世记 17:10"> 那是怎么算的呢？是在他受割礼的时候，还是在未受割礼的时候？不是在受割礼的时候，而是在未受割礼的时候。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:22; 路加福音 19:9; 哥林多后书 1:22"> 他领受了割礼的记号，作为他未受割礼时因信心而得之义的印记，使他成为一切未受割礼而信之人的父，使义也算给他们。</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 约翰福音 8:39–40; 箴言 2:20"> 他也作受割礼之人的父，就是那些不仅受了割礼，而且效法我们祖先亚伯拉罕在未受割礼时所存信心之踪迹去行的人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 3:29; 创世记 22:17–18; 创世记 28:14"> 因为上帝应许亚伯拉罕和他的后裔必承受世界，并不是借着律法，而是借着因信心而得的义。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:18–24; 腓立比书 3:9; 罗马书 4:16"> 如果属于律法的人才是后嗣，信心就成了虚空，应许也就失效了。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:13; 加拉太书 3:10; 罗马书 3:19–20"> 因为律法带来的是愤怒；哪里没有律法，哪里就没有违背律法的事。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 3:24–26; 以弗所书 2:8; 加拉太书 3:22"> 因此，承受应许是出于信心，好叫它也出于恩典，以确保这应许归给所有的后裔，不仅归给那属于律法的人，也归给那效法亚伯拉罕信心的人。亚伯拉罕是我们所有人的父，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:28; 创世记 17:4–5; 约翰福音 5:21"> 正如经上所记：“我已经立你作多国之父。” 亚伯拉罕在他所信的上帝面前作了我们的父；这位上帝是赐生命给死人、称无为有的上帝。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:24; 创世记 15:5–6; 使徒行传 27:25"> 在毫无指望的时候，亚伯拉罕仍然满怀盼望地相信了，使他得以成为多国之父，正如先前对他说过的话：“你的后裔将要如此。”</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:11–19; 罗马书 4:20–21; 创世记 17:17"> 他的信心并没有软弱，他没有考虑自己那已经衰败的身体（当时他大约一百岁），也没有考虑撒拉子宫的衰死。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前书 16:13; 但以理 10:19"> 他也没有因着不信而对上帝的应许产生动摇，反而在信心上得着刚强，将荣耀归给上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> 并且满心相信，上帝所应许的，祂也必能成就。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 4:6; 罗马书 4:3"> 所以，这也就“算为他的义”了。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 10:11; 罗马书 15:4; 哥林多前书 10:6"> “算为他的义”这句话，不仅是为了他一个人写的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:24; 彼得前书 1:21; 使徒行传 13:30"> 也是为了我们这些将被算为义的人写的，就是我们这些信靠那使我们的主耶稣从死里复活之上帝的人。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 4:9–10; 以赛亚书 53:5–6; 哥林多后书 5:21"> 耶稣被交给人，是为了我们的过犯；祂复活，是为了使我们称义。</span>
</div>

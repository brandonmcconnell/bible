<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="罗马书 2:25–29; 创世记 25:32; 传道书 6:11"> 那么，犹太人有什么长处呢？割礼又有什么益处呢？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 9:4; 使徒行传 7:38; 哥林多前书 9:17"> 各方面都很多！首先，上帝的圣言交托给了他们。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 2:13; 希伯来书 4:2; 罗马书 9:6"> 即使有些人不信，那又怎样呢？难道他们的不信能废弃上帝的信实吗？</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 51:4; 诗篇 116:11; 加拉太书 2:17"> 绝对不能！哪怕人人都撒谎，上帝依然是真实的。正如经上所记：<br /><span className="pl pl-1">“好让你在言语上显为公义，</span><br /><span className="pl pl-2">在你受人评判时，必然得胜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 6:19; 加拉太书 3:15; 罗马书 9:18–20"> 但是，如果我们的不义反倒彰显了上帝的公义，我们该怎么说呢？难道降怒的上帝是不公义的吗？（我是按着人的常理来说的。）</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:25; 使徒行传 17:31; 约伯记 8:3"> 绝对不能！若是这样，上帝怎能审判世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:4; 罗马书 9:19–20; 使徒行传 13:27–29"> 如果上帝的真实因我的虚谎越发显明，使祂得着荣耀，为什么我还要像罪人一样受审判呢？</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 6:1; 罗马书 6:15; 罗马书 5:20"> 为什么不说“我们可以作恶以成全善事”呢？（这正是我们被人毁谤的话，也有人硬说我们是这样教导的。）定这些人的罪是理所当然的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:22; 罗马书 6:15; 以赛亚书 65:5"> 这又怎么说呢？我们比他们强吗？绝不是的。因为我们已经指出，无论是犹太人还是希腊人，全都在罪恶的权势之下。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 53:1–3; 诗篇 14:1–3; 罗马书 3:23"> 正如经上所记：<br /><span className="pl pl-1">“没有义人，</span><br /><span className="pl pl-2">连一个也没有。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 14:2–4; 诗篇 53:2; 提多书 3:3"> <span className="pl pl-1">没有明白的，</span><br /><span className="pl pl-2">没有寻求上帝的。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 14:3; 传道书 7:20; 以赛亚书 64:6"> <span className="pl pl-1">人人都偏离了正道，</span><br /><span className="pl pl-2">一同沦为无用；</span><br /><span className="pl pl-1">没有行善的，</span><br /><span className="pl pl-2">连一个也没有。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 5:9; 诗篇 140:3; 马太福音 23:27–28"> <span className="pl pl-1">“他们的喉咙是敞开的坟墓，</span><br /><span className="pl pl-2">他们的舌头弄诡诈。”</span><br /><span className="pl pl-1">“他们嘴唇底下藏着毒蛇的恶毒。”</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 10:7; 诗篇 109:17–18; 诗篇 59:12"> <span className="pl pl-2">“他们满口是咒骂与苦毒。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">“他们杀人流血，脚步飞快；</span></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-2">在他们所经过的路上，留下毁灭与悲惨；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 59:8; 罗马书 5:1; 路加福音 1:79"> <span className="pl pl-2">平安的路，他们未曾知道。”</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">“他们眼中毫无对上帝的敬畏。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 3:10; 加拉太书 3:22–23; 罗马书 2:12–18"> 我们知道，律法上的话都是对律法之下的人说的，好塞住每一个人的口，使全世界都伏在上帝的审判之下。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:16; 使徒行传 13:39; 罗马书 3:28"> 因为没有一个肉体能借着遵行律法在祂面前称义；律法本是叫人知罪。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 10:43; 耶利米书 33:16; 腓立比书 3:9"> 但如今，上帝的公义在律法之外已经显明出来，有律法和先知为证；</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 10:12; 加拉太书 3:28; 罗马书 8:1"> 就是上帝的公义，借着信耶稣基督，加给一切相信的人。因为这并没有分别，</span>
<span className="v" id="v23" data-v="23" data-xref="传道书 7:20; 约翰一书 1:8–10; 罗马书 3:9"> 因为世人都犯了罪，亏缺了上帝的荣耀；</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 1:18–19; 提多书 3:5–7; 歌罗西书 1:14"> 如今却蒙祂的恩典，借着在基督耶稣里的救赎，就白白地称义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:23–24; 彼得前书 1:18–20; 约翰一书 4:10"> 上帝设立耶稣作赎罪祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“挽回祭”">a</a></sup>，是凭着人的信心，借着祂的血，为要显明上帝的公义；因为祂用忍耐的心，宽容了人过去所犯的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:4; 罗马书 4:5; 罗马书 3:30"> 好在现今这个时候显明祂的公义，使人知道祂自己为公义，也称对耶稣有信心的人为义。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 4:2; 罗马书 2:23; 哥林多前书 1:29–31"> 既是这样，哪里还能夸口呢？没有可夸的了。是借着什么律呢？是借着行为的律吗？不是，而是借着信心的律。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 2:16; 加拉太书 3:8; 提多书 3:7"> 所以我们认定，人称义是因着信心，不在于遵行律法。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 3:11; 以弗所书 3:6; 撒迦利亚书 2:11"> 难道上帝仅仅是犹太人的上帝吗？祂不也是外邦人的上帝吗？是的，祂也是外邦人的上帝。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:8; 加拉太书 3:20; 腓立比书 3:3"> 因为上帝只有一位，祂要借着信心称受割礼的人为义，也要借着信心称未受割礼的人为义。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:21; 马太福音 5:17; 罗马书 13:8–10"> 那么，我们借着信心废弃了律法吗？绝对不能！相反，我们更是坚固了律法。</span>
</div>
</div>

</div>

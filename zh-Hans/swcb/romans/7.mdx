<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 6:14; 罗马书 7:6; 罗马书 6:3"> 弟兄们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里的“弟兄们”在上下文允许的情况下，也可以正确地翻译为“弟兄姐妹”。">a</a></sup>，我现在是对懂律法的人说话。难道你们不知道，律法管辖人，是在人活着的时候吗？</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 2:23–24; 哥林多前书 7:39; 哥林多前书 7:4"> 就如已婚的妇人，丈夫活着的时候，她受律法约束归属于丈夫；但如果丈夫死了，她就脱离了丈夫的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 20:14; 马太福音 5:32; 马可福音 10:6–12"> 因此，如果丈夫活着的时候，她归了别的男人，就会被称为淫妇。但如果丈夫死了，她就脱离了那律法，即使她归了别的男人，也不是淫妇。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:24; 加拉太书 5:22–23; 以赛亚书 54:5"> 所以，我的弟兄们，借着基督的身体，你们对律法也已经死了，使你们可以归于另一位，就是从死里复活的祂，好让我们能为上帝结果子。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:3; 加拉太书 5:16–17; 加拉太书 5:24"> 因为当我们属乎肉体的时候，那因律法而起的罪恶情欲，就在我们的肢体中发动，以致结出死亡的果子。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:23–25; 哥林多后书 3:6; 罗马书 7:4"> 但现在，我们既然已经从那捆绑我们的律法中得释放，就脱离了律法；使我们按着灵的新样服侍，不再按着字句的旧样。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:20; 罗马书 4:15; 哥林多前书 15:56"> 那么，我们该怎么说呢？律法是罪吗？绝对不是！然而，如果不是借着律法，我就不知道什么是罪。如果律法没有说“不可贪心”，我就不知道什么是贪心。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 7:11; 哥林多前书 15:56; 罗马书 4:15"> 然而，罪借着诫命找到了机会，就在我里面激起各样的贪心。因为没有律法，罪就是死的。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:10; 罗马书 8:7; 雅各书 2:10–11"> 我以前没有律法的时候是活着的，但诫命一来到，罪就活了，我就死了。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 3:7; 罗马书 10:5; 利未记 18:5"> 那本来叫人得生命的诫命，我却发现它反而叫我死；</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 3:13; 罗马书 7:8; 希伯来书 3:13"> 因为罪借着诫命找到了机会，欺骗了我，并且借着诫命杀了我。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 1:8; 诗篇 119:137; 诗篇 19:7–12"> 所以，律法本是圣洁的，诫命也是圣洁、公义、良善的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:13–15; 加拉太书 3:21; 罗马书 8:3"> 那么，是那良善的叫我死吗？绝对不是！而是罪，为了显出它是罪，就借着那良善的叫我死，使罪借着诫命变得极度邪恶。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 21:25; 列王纪下 17:17; 罗马书 7:18"> 我们知道律法是属灵的，但我却是属乎肉体的，已经卖给罪了。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 5:17; 罗马书 7:19–20; 传道书 7:20"> 因为我不明白我所做的。我所愿意的，我没有去做；我所恨恶的，我倒去做。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 7:12; 罗马书 7:14; 提摩太前书 1:8"> 如果我所做的是我所不愿意的，我就赞同律法是良善的。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 7:20; 腓立比书 3:8–9; 罗马书 7:18"> 既然如此，这就不是我做的，而是住在我里面的罪做的。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:6; 诗篇 51:5; 加拉太书 5:17"> 我也知道，在我里面，就是在我肉体之中，没有良善。因为我有行善的意愿，却没有能力行出来。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:15"> 因为我所愿意的善，我没有去做；我所不愿意的恶，我反而去行。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 7:17"> 如果我去做我所不愿意的，这就不是我做的，而是住在我里面的罪做的。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:14; 罗马书 7:23; 诗篇 119:133"> 因此，我发现了一个律：当我愿意行善的时候，就有恶与我同在。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 1:2; 诗篇 40:8; 诗篇 119:35"> 因为按着我里面的人，我喜爱上帝的律法；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:17; 雅各书 4:1; 罗马书 8:2"> 但我看出肢体中另有一个律，与我心思的律交战，把我掳去，使我服从那在我肢体中罪的律。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 提摩太后书 4:18; 提多书 2:14"> 我真是个苦恼的人哪！谁能救我脱离这必死的身体呢？</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:17–24; 歌罗西书 3:17; 哥林多后书 12:9–10"> 感谢上帝，借着我们的主耶稣基督！这样看来，我一方面用心思服侍上帝的律法，另一方面却用肉体服侍罪的律。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:22; 撒母耳记上 12:22; 腓立比书 3:5"> 那么我要问，上帝弃绝了祂的子民吗？绝对没有！因为我也是以色列人，是亚伯拉罕的后裔，属于便雅悯支派。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 94:14; 罗马书 8:29–30; 出埃及记 32:1"> 上帝并没有弃绝祂预先所知道的子民。你们难道不知道圣经上关于以利亚是怎么说的吗？他是如何向上帝控告以色列的：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:10–18; 列王纪上 18:13; 尼希米记 9:26"> “主啊，他们杀了你的先知，拆毁了你的祭坛。只剩下我一个人，他们还要寻索我的性命。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 19:18; 民数记 25:3; 西番雅书 1:4"> 但上帝是怎么回答他的？“我为自己留下了七千人，他们都没有向巴力屈膝。”</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 9:27; 以弗所书 1:5–6; 罗马书 9:11"> 同样，在现今这个时候，照着恩典的拣选，也还有余民。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:21; 罗马书 4:4–5; 提摩太后书 1:9"> 既然是出于恩典，就不再是本乎行为；不然，恩典就不再是恩典了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有些抄本加上：“但如果是本乎行为，就不再是恩典；不然，行为就不再是行为了。”">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:18; 罗马书 11:5; 哥林多后书 4:4"> 那么结果怎样呢？以色列人所切求的，他们没有得着。但蒙拣选的人得着了，其余的人却变得刚硬。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 29:4; 以赛亚书 29:10; 以西结 12:2"> 正如经上所记：“上帝给了他们昏沉的灵，使他们的眼睛看不见，耳朵听不到，直到今日。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 69:22–23; 路加福音 12:20; 诗篇 28:4"> 大卫也说：<br /><span className="pl pl-1">“愿他们的筵席成为网罗、陷阱、</span><br /><span className="pl pl-2">绊脚石和对他们的报应。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 69:23; 申命记 28:64–68; 彼得后书 2:4"> <span className="pl pl-1">愿他们的眼睛昏暗，无法看见；</span><br /><span className="pl pl-2">愿他们的脊背永远弯曲。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 13:46–48; 罗马书 11:31; 罗马书 10:19"> 那么我要问，他们绊跌，是要彻底跌倒吗？绝对没有！反而是因着他们的过犯，救恩临到了外邦人，为了要激起他们发愤。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:25; 歌罗西书 1:27; 罗马书 11:15"> 如果他们的过犯成了世界的富足，他们的损失成了外邦人的富足，何况他们的丰满呢！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:15; 提摩太后书 1:11–12; 以弗所书 3:8"> 我现在是对你们外邦人说话。既然我是外邦人的使徒，我就敬重我的职分，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 7:16; 提摩太前书 4:16; 罗马书 9:3"> 希望借此能激起我骨肉之亲发愤，好拯救他们当中的一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 罗马书 5:10–11; 歌罗西书 1:20–21"> 如果他们被弃绝，促成了世界与上帝和好，那么他们被接纳，岂不意味着死而复生吗？</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结 44:30; 雅各书 1:18; 箴言 3:9"> 如果初熟的面团是圣洁的，全团也是圣洁的；如果树根是圣洁的，树枝也是圣洁的。</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所书 2:11–13; 以弗所书 3:6; 马太福音 21:43"> 如果有些树枝被折断了，而你这野橄榄枝被接在其中，与它们一同分享橄榄树根的丰盛汁水，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:12; 罗马书 11:20; 以弗所书 2:19–20"> 你就不要向那些树枝夸口。如果你要夸口，当记住：不是你托着树根，而是树根托着你。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 11:17; 罗马书 11:11–12; 罗马书 11:23–24"> 那么你会说：“树枝被折断，是为了让我接上。”</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:16; 哥林多后书 1:24; 哥林多前书 10:12"> 不错，他们因为不信而被折断，而你是因着信心才站立得住。不要自高，反要敬畏；</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4–9; 耶利米书 25:29; 耶利米书 49:12"> 因为上帝既然不顾惜原本的树枝，也必不顾惜你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:14; 希伯来书 3:6; 哥林多前书 15:2"> 可见，上帝既有恩慈，也有严厉。对跌倒的人，祂是严厉的；但对你，上帝是有恩慈的，只要你常在祂的恩慈中；不然，你也会被砍下来。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 3:16; 撒迦利亚书 12:10; 马太福音 23:39"> 至于他们，如果他们不再固执于不信，就会被重新接上，因为上帝有能力把他们重新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:17–18; 罗马书 11:30"> 如果你是从天生的野橄榄树上砍下来的，且逆着本性被接在好橄榄树上，何况这些原本的树枝，岂不更要被接在自己的橄榄树上吗？</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多后书 3:14–16; 罗马书 16:25"> 弟兄们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里的“弟兄们”在上下文中也可以正确地翻译为“弟兄姐妹们”。">b</a></sup>，我不愿意你们对这奥秘一无所知，免得你们自以为聪明：以色列人中有一部分是硬心的，直到外邦人的数目添满，</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 59:20; 耶利米书 31:31–37; 诗篇 14:7"> 这样，全以色列都必得救。正如经上所记：<br /><span className="pl pl-1">“必有一位拯救者从锡安出来，</span><br /><span className="pl pl-2">祂必消除雅各家一切不敬虔的事。</span></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:31–34; 以赛亚书 59:21; 以西结 36:25–29"> <span className="pl pl-1">这就是我与他们所立的约，</span><br /><span className="pl pl-2">当我除去他们罪恶的时候。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 10:15; 申命记 7:7–8; 马太福音 21:43"> 就福音而言，他们为你们的缘故成了仇敌；但就拣选而言，他们为列祖的缘故仍是蒙爱的。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 7:21; 民数记 23:19; 玛拉基书 3:6"> 因为上帝的恩赐和呼召是不可撤回的。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 3:7; 以弗所书 2:1–2; 哥林多前书 7:25"> 正如你们从前不顺服上帝，现在却因他们的不顺服而蒙了怜悯；</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:15; 罗马书 10:16; 罗马书 11:25"> 照样，他们现在也是不顺服的，好叫他们因着你们所蒙的怜悯，现在也能蒙怜悯。</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太书 3:22; 罗马书 3:9; 提摩太前书 2:4–6"> 因为上帝将众人都圈在不顺服之中，为了要怜悯众人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="约伯记 5:9; 约伯记 11:7–9; 诗篇 92:5"> 深哉，上帝丰富的智慧和知识！祂的判语何其难测，祂的道路何其难寻！</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 40:13; 哥林多前书 2:16; 约伯记 15:8"> <span className="pl pl-1">“谁曾知道主的心意？</span><br /><span className="pl pl-2">谁曾作过祂的谋士？”</span></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 41:11; 约伯记 35:7; 哥林多前书 4:7"> <span className="pl pl-1">“谁曾先给了祂，</span><br /><span className="pl pl-2">使祂后来要偿还呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="歌罗西书 1:15–17; 哥林多前书 8:6; 希伯来书 2:10"> 因为万有都是本于祂，倚靠祂，归于祂。愿荣耀归给祂，直到永远！阿们。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ROM" data-book-slug="romans" data-book-name="罗马书" data-chapter="1" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 罗马书 15:16; 哥林多前书 1:1"> 耶稣基督的仆人保罗，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”意为“受膏者”。">a</a></sup>蒙召作使徒，被分别出来传上帝的福音。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:2; 路加福音 1:70; 罗马书 3:21"> 这福音是祂从前藉着祂的众先知，在圣经上所应许的，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 1:1; 加拉太书 4:4; 耶利米书 23:5–6"> 论到祂的儿子——按肉体说，祂是从大卫的后裔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：种子。">b</a></sup>生的；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:14; 希伯来书 5:5–6; 以弗所书 1:19–23"> 按着圣洁的灵说，因从死里复活，以大能显明是上帝的儿子，就是我们的主耶稣基督。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:15; 罗马书 16:26; 使徒行传 6:7"> 藉着祂，我们领受了恩典和使徒的职分，为祂的名的缘故，在万国中使人因信心而顺服；</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:9; 启示录 17:14; 彼得后书 1:10"> 其中也有你们这蒙召属耶稣基督的人。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 1:2; 犹大书 1:1–2; 以弗所书 1:2"> 写信给一切在罗马、为上帝所爱、蒙召作圣徒的人：愿恩典与平安，从我们的父上帝和主耶稣基督归于你们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 16:19; 哥林多前书 1:4; 帖撒罗尼迦前书 1:8–9"> 首先，我藉着耶稣基督，为你们众人感谢我的上帝，因为你们的信心传遍了全世界。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 6:18; 提摩太后书 1:3; 以弗所书 1:16–19"> 上帝可以为我作见证——就是我在祂儿子的福音上，用我的灵所事奉的上帝——我怎样在祷告中常常不住地提到你们，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 15:30–32; 使徒行传 18:21; 腓利门书 1:22"> 恳求照上帝的旨意，现在我终于能顺利地到你们那里去。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:12; 罗马书 16:25; 罗马书 15:29"> 因为我切切地想见你们，要把一些属灵的恩赐分给你们，使你们得以坚固；</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 3:7–10; 约翰三书 1:3–4; 哥林多后书 7:13"> 也就是说，我在你们中间，藉着你我彼此的信心，大家同得鼓励。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 19:21; 腓立比书 4:17; 提摩太后书 4:17"> 弟兄们，我不愿意你们不知道，我屡次计划到你们那里去（只是到如今仍有阻碍），为了在你们中间也得些果子，如同在其余的外族人中一样。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:16–23; 使徒行传 9:15; 歌罗西书 3:11"> 无论是希腊人还是外族人，无论是聪明人还是愚笨人，我都欠他们的债。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:20; 以赛亚书 6:8; 哥林多前书 9:17"> 所以，就我而言，我切望把福音也传给你们在罗马的人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马可福音 8:38; 提摩太后书 1:8; 彼得前书 4:16"> 我不以基督的福音为耻；因为这福音是上帝的大能，要使一切相信的人得着救恩，先是犹太人，后是希腊人。</span>
<span className="v" id="v17" data-v="17" data-xref="哈巴谷 2:4; 加拉太书 3:11; 希伯来书 10:38"> 因为上帝的公义在这福音上显明出来，是本于信心，以至于信心。正如经上所记：“义人必因信心得生。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:6; 提摩太前书 4:1–2; 罗马书 1:32"> 上帝的愤怒从天上显明，降在那些不虔不义、以不义压制真理的人身上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:16–17; 诗篇 19:1–6; 罗马书 1:20"> 因为关于上帝的已知之事，在他们心里是显而易见的，因为上帝已经向他们显明了。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:19; 以赛亚书 40:26; 诗篇 19:1–6"> 自从造天地以来，上帝那不可见之事，就是祂永恒的大能和神性，都是清楚可见的，藉着所造之物就能被察觉，叫他们无可推诿。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:17–18; 列王纪下 17:15; 耶利米书 2:5"> 因为他们虽然认识上帝，却不把祂当作上帝来荣耀祂，也不感谢祂。他们的思想反而变得虚妄，愚昧的心也就昏暗了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 1:19–21; 罗马书 11:25; 箴言 26:12"> 他们自称为聪明，反成了愚拙，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 106:20; 耶利米书 2:11; 使徒行传 17:29"> 将不朽坏之上帝的荣耀，换成了必朽坏的人、飞禽、走兽和爬行动物的形象。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 使徒行传 7:42; 使徒行传 14:16"> 所以，上帝任凭他们顺着心中的私欲去行污秽的事，以致彼此羞辱自己的身体。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷 2:18; 耶利米书 13:25; 约翰一书 2:15–16"> 他们将上帝的真实换为虚谎，去敬拜事奉受造之物，却不敬拜那造物的主——主乃是永远有福的。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="犹大书 1:7; 提摩太前书 1:10; 罗马书 1:24"> 因此，上帝任凭他们放纵可耻的情欲。他们的女人把顺应本性的事，变成了违背本性的事；</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 20:13; 利未记 18:22; 罗马书 1:23–24"> 男人也是如此，放弃了与女人顺应本性的事，彼此欲火中烧，男人和男人行不合宜的事，就在自己身上受了这妄为应得的报应。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:10–12; 罗马书 1:21; 提多书 1:16"> 既然他们拒绝在认知中保留上帝，上帝就任凭他们存败坏的心智，去行那些不当行的事；</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 12:20; 箴言 16:28; 诗篇 41:7"> 他们装满了各样不义、淫乱、邪恶、贪婪、恶毒；满心是嫉妒、凶杀、争竞、诡诈、恶习；又是暗中毁谤人的、</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 3:2; 犹大书 1:16; 彼得后书 2:18"> 背后说人的、怨恨上帝的、狂妄的、傲慢的、自夸的、捏造恶事的、违背父母的、</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 3:3; 箴言 18:2; 罗马书 3:11"> 愚顽的、背约的、无亲情的、不肯宽恕的、毫无怜悯的；</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 2:1–5; 罗马书 1:21; 罗马书 6:21"> 他们虽然知道上帝的法则，就是行这些事的人是该死的，却不仅自己去行，还赞同那些行这些事的人。</span>
</div>
</div>

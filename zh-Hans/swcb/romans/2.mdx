<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:3; 约翰福音 8:7–9"> 因此，人哪，无论你是谁，只要你论断人，就无可推诿。因为你在什么事上论断人，就在什么事上定自己的罪；因为你这论断人的，自己也做同样的事。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 9:7–8; 西番雅书 3:5; 诗篇 145:17"> 我们知道，上帝必按着真理，审判做这类事的人。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 罗马书 1:32–1"> 人哪，你论断做这类事的人，自己却做同样的事，你以为能逃脱上帝的审判吗？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 3:9; 以赛亚书 30:18; 出埃及记 34:6"> 还是你藐视祂丰盛的恩慈、宽容和忍耐，不晓得上帝的恩慈是领你悔改的呢？</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 12:14; 罗马书 1:18; 罗马书 2:2–3"> 你竟任着你刚硬不悔改的心，为自己积蓄忿怒，以致在上帝发怒、彰显祂公义审判的日子，忿怒临到你。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 62:12; 耶利米书 32:19; 马太福音 16:27"> 祂“必照各人的行为报应各人”：</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:7–8; 路加福音 8:15; 提摩太后书 1:10"> 凡恒心行善，寻求荣耀、尊贵和不朽坏之福的，祂就以永生报应他们；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:18–21; 帖撒罗尼迦后书 1:8; 提摩太前书 6:3–4"> 至于那些自私自利、不顺从真理、反顺从不义的人，必有震怒和愤恨报应他们。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 4:17; 以西结 18:4; 罗马书 1:16"> 将有患难和困苦临到一切作恶的人的灵魂，先是犹太人，后是希腊人；</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 32:17; 以赛亚书 26:12; 民数记 6:26"> 却将荣耀、尊贵和平安赐给一切行善的人，先是犹太人，后是希腊人。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:17; 使徒行传 10:34; 历代志下 19:7"> 因为上帝不偏待人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:21; 加拉太书 3:10; 加拉太书 2:16–19"> 凡在律法之外犯罪的，也必在律法之外灭亡；凡在律法之下犯罪的，必按律法受审判。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:22–25; 约翰一书 3:7; 雅各书 2:21–25"> 因为在上帝面前，不是听律法的人算为义，而是行律法的人才得称义</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:12; 罗马书 1:19–20; 罗马书 2:27"> （没有律法的外邦人，若出于本性行律法的事，他们虽然没有律法，自己就是自己的律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:11; 哥林多后书 1:12; 罗马书 1:18–19"> 这就显明律法的要求写在他们心里，他们的良心同作见证，并且他们的思想或控告、或辩护。）</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 12:14; 哥林多前书 4:5; 使徒行传 17:31"> 这就在上帝借着耶稣基督，照着我所传的福音，审判人隐秘事的日子显露出来。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 2:23; 弥迦书 3:11; 以赛亚书 48:1–2"> 你既然自称为犹太人，倚靠律法，以上帝夸口，</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:21; 申命记 4:8; 雅各书 4:17"> 明白祂的旨意，并且受了律法的教导，能分辨是非；</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 3:17–18; 马太福音 15:14; 以赛亚书 49:6"> 又深信自己是盲人的向导，在黑暗中之人的光，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:5; 提多书 1:16; 提摩太后书 1:13"> 愚昧人的管教者，婴孩的师傅，在律法上有知识和真理的模范；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 9:27; 马太福音 23:3–28; 路加福音 12:47"> 那么，你教导别人，难道不教导自己吗？你宣讲人不可偷窃，自己却偷窃吗？</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 3:8; 马太福音 12:39; 马可福音 11:17"> 你说人不可通奸，自己却通奸吗？你厌恶偶像，自己却抢劫庙宇吗？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 4:16–17; 罗马书 2:17; 罗马书 3:2"> 你指着律法夸口，自己却违犯律法，羞辱上帝吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 36:20–23; 以赛亚书 52:5; 彼得后书 2:2"> 正如经上所记的：“上帝的名在外邦人中，因你们受了亵渎。”</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 4:4; 加拉太书 5:3–6; 使徒行传 7:51"> 你若是遵行律法的，割礼固然有益处；但你若是违犯律法的，你的割礼就算不得割礼。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:11; 哥林多前书 7:18–19; 罗马书 8:4"> 因此，未受割礼的人若遵守律法的条例，他虽然未受割礼，岂不算是受了割礼吗？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:41–42; 罗马书 2:29; 哥林多后书 3:6"> 并且那肉体上未受割礼、却成全律法的人，岂不是要审判你这拥有仪文和割礼却违犯律法的人吗？</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:15; 马太福音 3:9; 罗马书 9:6–8"> 因为外表上作犹太人的，并不是真犹太人；外表上肉体的割礼，也不是真割礼。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 30:6; 腓立比书 3:3; 申命记 10:16"> 惟有内心作犹太人的，才是真犹太人；真割礼也是心里的，是在乎灵，不在乎字句。这样的人所受的称赞不是从人来的，而是从上帝来的。</span>

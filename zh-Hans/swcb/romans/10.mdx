<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 9:20–22; 罗马书 9:1–3; 约翰福音 5:34"> 弟兄们，我心里所渴望的，并且向上帝所祈求的，是为以色列人，愿他们能得救。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 21:20; 罗马书 9:31–32; 箴言 19:2"> 我可以为他们作证，他们对上帝有热心，但这热心并不是出于真知识。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 3:9; 路加福音 16:15; 哥林多后书 5:21"> 因为他们不知道上帝的公义，想要建立自己的义，就不归服于上帝的公义了。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 3:24; 罗马书 8:3–4; 马太福音 5:17–18"> 因为基督是律法的总结<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“成全”或“终结”">a</a></sup>，使所有相信的人都得着义。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未记 18:5; 以西结 20:11; 尼希米记 9:29"> 摩西论到出于律法的义，写道：“遵行这些律例的人，必因这些律例而活。”</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 30:11–14; 箴言 30:4; 以弗所书 4:8–10"> 但那出于信心的义如此说：“你心里不要说：‘谁要升到天上去呢？’（这就是说，要领基督降下来）；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:20; 启示录 1:18; 罗马书 4:25"> 或说：‘谁要下到深渊里去呢？’（这就是说，要领基督从死人中升上来。）”</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 30:14; 罗马书 1:16–17; 提摩太前书 4:6"> 然而它到底怎么说呢？“这话语离你很近，就在你口中，在你心里；” 这就是我们所传扬那信心的道：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 12:8; 使徒行传 16:31; 腓立比书 2:11"> 你若口里宣认耶稣为主，心里相信上帝叫祂从死人中复活，就必得救。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:15; 罗马书 10:9; 加拉太书 2:16"> 因为人心里相信，就可以称义；口里宣认，就可以得救。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:16; 罗马书 9:33; 彼得前书 2:6"> 因为经上说：“凡相信祂的人，必不至于羞愧。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="腓立比书 4:19; 启示录 17:14; 加拉太书 3:28"> 因为犹太人和希腊人并没有分别；同一位主是万有之主，祂厚赐给一切求告祂的人。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:21; 约珥 2:32"> 因为，“凡求告主名的人，都必得救。”</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 16:15–16; 使徒行传 26:17–18; 提多书 1:3"> 然而，人未曾相信祂，怎能求告祂呢？未曾听见祂，怎能相信祂呢？没有传道的，怎能听见呢？</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 那鸿书 1:15; 以弗所书 2:17"> 若没有奉差遣，怎能传道呢？正如经上所记：<br /><span className="pl pl-1">“那些传扬和平福音、</span><br /><span className="pl pl-2">报美好佳音之人的脚踪，是何等佳美！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 53:1; 罗马书 3:3; 约翰福音 12:38–40"> 只是他们并没有都顺从这福音。因为以赛亚说：“主啊，我们所传的，有谁相信呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 3:2; 加拉太书 3:5; 帖撒罗尼迦前书 2:13"> 可见，信心是从听道来的，而听道是从上帝的话来的。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="某些抄本作“基督的话”（ῥήματος Χριστοῦ），而非“上帝的话”（ῥήματος Θεοῦ）。两种读法都有古抄本支持。">b</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 19:4; 罗马书 1:8; 马太福音 24:14"> 但我问，他们没有听见吗？确实听见了，<br /><span className="pl pl-1">“他们的声音传遍全地，</span><br /><span className="pl pl-2">他们的言语传到地极。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="申命记 32:21; 罗马书 11:11; 罗马书 11:14"> 但我再问，以色列人不知道吗？首先，摩西说：<br /><span className="pl pl-1">“我要用那不成国的，激起你们的嫉妒；</span><br /><span className="pl pl-2">我要用那无知的国，惹动你们的怒气。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:1–2; 罗马书 9:30; 以赛亚书 55:4–5"> 以赛亚也非常放胆地说：<br /><span className="pl pl-1">“没有寻找我的，我被他们寻见；</span><br /><span className="pl pl-2">没有求问我的，我向他们显现。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 65:2–5; 彼得前书 2:8; 耶利米书 35:15"> 至于以色列人，他却说：“我整天向那悖逆顶嘴的百姓伸出我的手。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:14; 罗马书 14:1; 加拉太书 6:1–2"> 我们坚强的人，理当担代软弱之人的软弱，不求自己的喜悦。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 14:19; 哥林多前书 10:24; 腓立比书 2:4–5"> 我们各人务要让邻舍喜悦，使他得益处，被建立起来。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 69:9; 腓立比书 2:8; 约翰福音 4:34"> 因为连基督也没有求自己的喜悦。正如经上所记：“辱骂祢之人的辱骂，都落在我身上。”</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:11; 提摩太后书 3:16–17; 罗马书 4:23–24"> 从前所写的圣经，都是为了教导我们而写的，使我们借着忍耐和圣经所赐的安慰，可以得着盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 2:4–5; 彼得前书 3:8; 罗马书 12:16"> 愿赐忍耐和安慰的上帝，使你们效法基督耶稣，彼此同心，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:29–30; 启示录 1:6; 以弗所书 1:3"> 好使你们同心合意，齐声荣耀我们主耶稣基督的父上帝。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40; 约翰福音 13:34; 罗马书 5:2"> 所以，你们要彼此接纳，如同基督接纳了你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认文本（TR）作“我们”而不是“你们”。">a</a></sup>一样，使荣耀归于上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 4:4–5; 马太福音 15:24; 约翰福音 1:11"> 我说，基督为了上帝的真理，成了受割礼之人的仆役，为要证实应许给列祖的话，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 22:50; 诗篇 18:49; 罗马书 3:29"> 并使外邦人因着祂的怜悯荣耀上帝。正如经上所记：<br /><span className="pl pl-1">“因此，我要在外邦中赞美祢，</span><br /><span className="pl pl-2">歌颂祢的名。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="诗篇 67:3–4; 申命记 32:43; 以赛亚书 42:10–12"> 经上又说：<br /><span className="pl pl-1">“外邦人哪，你们当与祂的子民一同欢呼。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="诗篇 117:1"> 又说：<br /><span className="pl pl-1">“万邦啊，你们都当赞美主！</span><br /><span className="pl pl-2">万民哪，你们都当颂赞祂！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 11:10; 以赛亚书 11:1; 马太福音 12:21"> 以赛亚又说：<br /><span className="pl pl-1">“将来必有耶西的根，</span><br /><span className="pl pl-2">就是那兴起来治理外邦的；</span><br /><span className="pl pl-2">外邦人都要仰望祂。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦后书 2:16–17; 罗马书 12:12; 哥林多后书 9:8"> 愿赐盼望的上帝，因着你们的信心，将一切喜乐和平安充满你们，使你们借着圣灵的能力，大有盼望。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 3:16; 彼得后书 1:12; 约翰一书 2:21"> 我的弟兄们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此处的“弟兄们”，在上下文允许的情况下，也可以准确地翻译为“弟兄姐妹”。">b</a></sup>，我自己也深信你们满有良善，充足了各样的知识，也能彼此劝诫。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:3; 哥林多前书 15:10; 罗马书 1:5"> 然而，我写信给你们，有些地方稍微大胆了一些，是为了提醒你们。我这样写，是因着上帝赐给我的恩典，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:13; 罗马书 1:1; 使徒行传 9:15"> 使我为外邦人作基督耶稣的仆役，作上帝福音的祭司，叫所献上的外邦人，因着圣灵成为圣洁，可蒙悦纳。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 2:14–16; 哥林多后书 12:11–21; 希伯来书 5:1"> 所以，在上帝的事上，我在基督耶稣里有可夸的。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:12; 罗马书 1:5; 使徒行传 21:19"> 除了基督借着我的言语和行为，使外邦人顺服所做成的事之外，我不敢提别的。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 12:12; 希伯来书 2:4; 使徒行传 19:11–12"> 这些事是借着神迹奇事的能力，并借着上帝的灵的能力做成的。甚至我从耶路撒冷一直绕行到以利哩古，到处传满了基督的福音。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 10:13–16; 哥林多前书 3:9–15; 以弗所书 2:20–22"> 我立定志向，不在基督的名已经被传开的地方传福音，免得建造在别人的根基上。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 52:15; 以赛亚书 65:1"> 正如经上所记：<br /><span className="pl pl-1">“未曾得到祂消息的人，将要看见；</span><br /><span className="pl pl-2">未曾听见的人，将要明白。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 1:13; 帖撒罗尼迦前书 2:17–18"> 因此，我多次被拦阻，不能到你们那里去。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 15:32; 罗马书 1:10–12; 罗马书 15:29"> 但现在，我在这些地区再没有可传道的地方，而且这许多年来，我一直切望到你们那里去。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:28; 罗马书 1:12; 使徒行传 15:3"> 无论我什么时候去西班牙，我都会到你们那里去。因为我盼望在旅途中见到你们，并在与你们短暂相聚之后，能得到你们的帮助，为我送行前往那里。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 24:17; 使徒行传 19:21; 使徒行传 20:22"> 但现在，我要往耶路撒冷去，服侍那里的圣徒。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 8:1–9; 使徒行传 11:27–30; 哥林多后书 9:2"> 因为马其顿和亚该亚人乐意凑出了一笔款项，捐给耶路撒冷圣徒中的穷人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 9:11; 加拉太书 6:6; 腓利门书 1:19"> 这固然是他们乐意的，其实他们也是欠了债的。因为外邦人既然分享了他们属灵的好处，就理当在物质上服侍他们。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 15:24; 腓立比书 4:17; 歌罗西书 1:6"> 所以，等我办妥了这事，把这善果妥善地交托给他们之后，我就会路过你们那里，前往西班牙。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 4:13; 罗马书 1:10–12; 诗篇 16:11"> 我知道，我到你们那里去的时候，必定带着基督福音丰盛的祝福而去。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:12; 哥林多后书 1:11; 哥林多后书 4:11"> 弟兄们，我借着我们的主耶稣基督，又借着圣灵的爱，恳求你们与我一同竭力，为我向上帝祈求，</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 3:2; 哥林多后书 8:4; 哥林多后书 9:1"> 使我能脱离犹太地那些不顺从的人，也使我为耶路撒冷所办的服侍，能蒙圣徒悦纳；</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 16:18; 腓利门书 1:20; 腓利门书 1:7"> 好让我顺着上帝的旨意，欢欢喜喜地到你们那里去，与你们一同得安歇。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 13:11; 腓立比书 4:9; 帖撒罗尼迦前书 5:23"> 愿赐平安的上帝与你们众人同在。阿们。</span>
</div>
</div>

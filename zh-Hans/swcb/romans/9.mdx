<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:7; 罗马书 1:9; 加拉太书 1:20"> 我在基督里说真话，绝不撒谎，我的良心在圣灵里与我一同作证：</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:18; 诗篇 119:136; 耶利米书 13:17"> 我的心里有极大的忧愁和不息的伤痛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:32; 以斯帖记 8:6; 罗马书 11:14"> 为我弟兄，就是我肉体的骨肉之亲，我宁愿自己被咒诅，与基督分离。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:12; 诗篇 147:19; 罗马书 9:6"> 他们是以色列人；那儿子的名分、荣耀、诸约、律法的颁赐、敬拜的礼仪和应许，都是他们的。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:30; 约翰福音 1:1–3; 歌罗西书 1:16–19"> 列祖是他们的先祖；按肉体说，基督也是从他们出来的。祂是超越万有之上、永远受称颂的上帝。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="罗马书 2:28–29; 加拉太书 6:16; 罗马书 11:1–2"> 但这并不是说上帝的话落空了。因为从以色列生的，不都是以色列人；</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 21:12; 希伯来书 11:18; 约翰福音 8:37–39"> 也不因为是亚伯拉罕的后裔，就都是他的儿女。相反，“从以撒生的，才要称为你的后裔。”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:13; 罗马书 4:11–16; 加拉太书 3:26–29"> 也就是说，肉体所生的儿女并不是上帝的儿女，只有凭应许所生的儿女才被算为后裔。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 18:10; 创世记 18:14; 创世记 17:21"> 因为这应许的话是这样说的：“到所定的日期我会再来，那时撒拉必生一个儿子。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 25:21–23; 路加福音 16:26; 罗马书 5:11"> 不仅如此，利百加也是从一个人，就是从我们的先祖以撒怀了孕。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 彼得后书 1:10"> 双子还没有生下来，善恶也没有做出来，为要使上帝按拣选而定的旨意得以成立，不是出于人的行为，而是出于呼召人的那一位，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU文本将“不是出于人的行为，而是出于呼召人的那一位”放在第12节的开头，而不是第11节的末尾。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:22–23; 撒母耳记下 8:14; 列王纪上 22:47"> 上帝就对她说：“将来大的要服侍小的。”</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 1:2–3; 申命记 21:15; 创世记 29:33"> 正如经上所记：“我爱雅各，却恶以扫。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 19:7; 诗篇 145:17; 申命记 32:4"> 那么，我们该怎么说呢？难道上帝有不公义吗？绝对没有！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 33:19; 罗马书 9:16; 弥迦书 7:18"> 因为祂对摩西说：“我要怜悯谁，就怜悯谁；我要体恤谁，就体恤谁。”</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所书 2:8; 马太福音 11:25–26; 彼得前书 2:9–10"> 由此可见，这不在于人的意愿，也不在于人的奔跑，只在于施怜悯的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 9:16; 箴言 16:4; 出埃及记 14:17–18"> 因为经上对法老说：“我将你兴起来，正是为了这个目的：要在你身上彰显我的大能，并使我的名传遍全地。”</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:20; 出埃及记 4:21; 罗马书 9:15–16"> 由此可见，祂愿意怜悯谁，就怜悯谁；愿意使谁刚硬，就使谁刚硬。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="但以理 4:35; 历代志下 20:6; 哥林多前书 15:12"> 这样，你必然会问我：“那么祂为什么还要指责人呢？有谁能抗拒祂的旨意呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 29:16; 以赛亚书 45:9–11; 以赛亚书 64:8"> 人哪，你到底是谁，竟敢跟上帝顶嘴呢？被造之物岂能对造物主说：“你为什么把我造成这样？”</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:8; 箴言 16:4; 提摩太后书 2:20–21"> 陶匠难道没有权利从同一团泥里，拿一部分做成贵重的器皿，又拿另一部分做成卑贱的器皿吗？</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 犹大书 1:4; 罗马书 9:21"> 倘若上帝为了彰显祂的愤怒，显明祂的大能，就极其忍耐地宽容那些预备遭毁灭的愤怒的器皿，</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 2:4; 彼得前书 1:2–5; 歌罗西书 1:27"> 又要将祂丰盛的荣耀彰显在那些蒙怜悯、早先预备得荣耀的器皿上，这又有什么不可呢？</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:11; 使徒行传 13:47–48; 以弗所书 3:6–8"> 这器皿就是我们这些被祂所呼召的人，不仅来自犹太人，也来自外邦人。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿 2:23; 彼得前书 2:10; 约翰福音 16:27"> 正如祂在何西阿书上所说：<br /><span className="pl pl-1">“那本来不是我子民的，我要称他们为‘我的子民’；</span><br /><span className="pl pl-2">那本来不蒙爱的，我要称她为‘蒙爱的’。”</span></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿 1:9–10; 约翰一书 3:1–3; 加拉太书 3:26"> <span className="pl pl-1">“从前在什么地方对他们说：‘你们不是我的子民’，</span><br /><span className="pl pl-2">将来就在那里，他们要被称为‘永生上帝的儿女’。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 10:20–23; 罗马书 11:4–6; 以赛亚书 1:9"> 以赛亚指着以色列人大声呼喊说：<br /><span className="pl pl-1">“以色列人的数目虽然多如海沙，</span><br /><span className="pl pl-2">但得救的不过是剩下的余数；</span></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 10:23; 启示录 19:11; 使徒行传 17:31"> <span className="pl pl-1">因为祂必在公义中完成这工作，并迅速结束，</span><br /><span className="pl pl-2">因为主必在地上迅速地成就这事。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 1:9; 以赛亚书 13:19; 阿摩司 4:11"> 正如以赛亚先前所说：<br /><span className="pl pl-1">“若不是万军之耶和华</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希腊文为Sabaoth（或希伯来文Tze’va’ot）。">b</a></sup><br /><span className="pl pl-1">给我们存留后裔，</span><br /><span className="pl pl-2">我们早已像所多玛一样，</span><br /><span className="pl pl-2">也早已与蛾摩拉毫无分别了。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比书 3:9; 希伯来书 11:7; 加拉太书 2:16"> 那么，我们该怎么说呢？那不追求义的外邦人，反而得着了义，就是因信心而得的义；</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:7; 罗马书 3:20; 雅各书 2:10–11"> 但以色列人追求律法的义，却没能达到律法的义。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:23; 彼得前书 2:8; 路加福音 7:23"> 为什么呢？因为他们不是凭着信心去求，而是似乎凭着律法的行为去求。他们绊跌在那绊脚石上，</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 28:16; 以赛亚书 8:14–15; 罗马书 10:11"> 正如经上所记：<br /><span className="pl pl-1">“看哪，</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”源自希腊文“ἰδοὺ”，意为注视、注意、观察、看见或凝视。常作感叹词使用。">c</a></sup><br /><span className="pl pl-1">我在锡安放了一块绊脚石和使人跌倒的磐石；</span><br /><span className="pl pl-2">信靠祂的人必不至于失望。”</span></span>
</div>
</div>

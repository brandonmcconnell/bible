<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:5; 罗马书 6:13; 希伯来书 13:15–16"> 所以弟兄们，我以上帝的怜悯劝你们，将身体献上当作活祭，是圣洁的，是上帝所喜悦的；这是你们理所当然的理性事奉。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:14; 以弗所书 4:22–24; 哥林多后书 5:17"> 不要被这个世界同化，而是要借着心意的更新而蜕变，好让你们能察验什么是上帝那善良、可喜悦、完美的旨意。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:3; 腓立比书 2:3–8; 箴言 26:12"> 我借着所赐给我的恩典对你们众人说：不要把自己看得太高，而要照着上帝分给各人信心的大小，客观理性地看待自己。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 12:27; 哥林多前书 12:12–14; 以弗所书 4:15–16"> 因为正如我们一个身体上有许多肢体，而且所有肢体都有不同的功用，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:20; 哥林多前书 10:17; 哥林多前书 12:27–28"> 我们这许多人在基督里也是一个身体，并且互相作肢体。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 4:10–11; 哥林多前书 7:7; 哥林多前书 12:28–31"> 照着所赐给我们的恩典，我们各有不同的恩赐：如果是说预言，就当照着信心的程度去说；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:11; 提摩太后书 4:2; 使徒行传 13:1"> 如果是服事，就当专心服事；如果是教导，就当专心教导；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 9:7; 提摩太前书 5:17; 哥林多前书 12:28"> 如果是劝勉，就当专心劝勉；施舍的，应当慷慨；治理的，应当殷勤；展现怜悯的，应当甘心乐意。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 34:14; 彼得前书 4:8; 提摩太前书 1:5"> 爱人不可虚伪。恶要厌恶，善要持守。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:3; 约翰福音 13:34–35; 希伯来书 13:1"> 要以弟兄之爱互相亲爱；在尊重人方面，要彼此推让。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:10–11; 使徒行传 18:25; 启示录 3:15–16"> 殷勤不可懒惰，要灵里火热，常常服事主。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:13; 希伯来书 10:36; 诗篇 62:8"> 在盼望中要喜乐，在患难中要忍耐，祷告要恒切。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:16; 哥林多后书 9:12; 约翰一书 3:17"> 圣徒有需要，就要帮补；要乐于款待客旅。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:9; 马太福音 5:44; 帖撒罗尼迦前书 5:15"> 要祝福逼迫你们的人；只要祝福，不可咒诅。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 12:26; 希伯来书 13:3; 诗篇 35:13–14"> 与喜乐的人要同乐，与哀哭的人要同哭。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:8; 箴言 3:7; 雅各书 3:13–17"> 要彼此同心。不要心高气傲，而要俯就卑微的人。不要自以为聪明。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; 帖撒罗尼迦前书 5:15; 马太福音 5:39"> 不要以恶报恶。众人眼中看为美好的事，要留心去做。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:14; 马太福音 5:9; 罗马书 14:19"> 若是可能，总要尽你们所能地与众人和睦。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 32:35; 希伯来书 10:30; 箴言 24:29"> 亲爱的弟兄啊，不要自己复仇，宁可让步，听凭上帝的震怒。因为经上记着说：“复仇在我，我必报应，这是主说的。”</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; 马太福音 5:44; 路加福音 6:27"> 所以，<br /><span className="pl pl-1">“你的仇敌若饿了，就给他吃；</span><br /><span className="pl pl-2">若渴了，就给他喝；</span><br /><span className="pl pl-2">因为你这样行，就是把炭火堆在他的头上。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="彼得前书 3:9; 路加福音 6:27–30; 箴言 16:32"> 不可被恶所胜，反要以善胜恶。</span>
</div>

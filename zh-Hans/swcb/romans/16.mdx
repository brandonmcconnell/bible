<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:18; 彼得前书 1:22–23; 提摩太前书 5:9–10"> 我向你们推荐我们的姊妹非比，她是坚革哩教会的仆人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“执事”">a</a></sup>，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:29; 腓立比书 1:27; 马太福音 10:40–42"> 请你们在主里以与圣徒相称的方式接待她。无论她需要在什么事上得到你们的帮助，你们都要协助她，因为她曾帮助过许多人，也帮助了我。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 16:19; 提摩太后书 4:19; 使徒行传 18:26"> 问候在基督耶稣里与我同工的百基拉和亚居拉，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 2:30; 约翰一书 3:16; 哥林多前书 16:1"> 他们为救我的命，将自己的生死置之度外。不仅我感谢他们，外邦的众教会也感谢他们。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 4:15; 腓利门书 1:2; 哥林多前书 16:19"> 也问候在他们家中的教会。问候我所亲爱的以拜尼土，他是亚该亚归向基督的初熟果子。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:12; 马太福音 27:55; 提摩太前书 5:10"> 问候马利亚，她为我们辛勤劳苦。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 16:11; 罗马书 16:21; 腓利门书 1:23"> 问候我的亲属和与我一同坐监的安多尼古和犹尼亚，他们在使徒中是出名的，而且比我先在基督里。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 约翰一书 3:14; 罗马书 16:5"> 问候我在主里所亲爱的暗伯利。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:2–3; 罗马书 16:21"> 问候在基督里与我们同工的耳巴奴，和我所亲爱的士大古。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:18; 彼得前书 1:7; 申命记 8:2"> 问候在基督里经过考验的亚比利。问候亚利多布家里的人。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 16:21; 罗马书 16:7"> 问候我的亲属希罗天。问候拿其数家中在主里的人。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 6:10–11; 哥林多前书 15:58"> 问候在主里劳苦的土非拿和土富撒。问候所亲爱的彼息，她曾在主里多多劳苦。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:21; 提摩太前书 5:2; 约翰二书 1:1"> 问候在主里蒙拣选的鲁孚，也问候他的母亲，她也就是我的母亲。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:2; 罗马书 8:29; 希伯来书 3:1"> 问候亚逊其土、弗勒干、黑米、八罗巴、黑马，以及与他们在一起的弟兄们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在这里以及在上下文允许的地方，“弟兄们”也可以准确地翻译为“弟兄姊妹”。">b</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:2; 罗马书 1:7; 罗马书 16:14"> 问候非罗罗古和犹利亚，尼利亚和他的姊妹，以及阿林巴，并与他们在一起的众圣徒。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:26; 哥林多前书 16:20; 哥林多后书 13:12"> 你们要用圣洁的亲嘴之礼彼此问候。基督的众教会都问候你们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:19; 帖撒罗尼迦后书 3:6; 提摩太前书 6:3–5"> 弟兄们，我恳求你们，要留意那些制造分裂和绊跌人之事、违背你们所学之道的人，要避开他们。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:4; 马太福音 7:15; 提摩太前书 6:5"> 因为这样的人不服事我们的主耶稣基督，只服事自己的肚腹；他们用花言巧语欺骗单纯之人的心。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 10:16; 哥林多前书 14:20; 腓立比书 2:15"> 你们的顺服已经传于众人，因此我为你们欢喜。但我愿你们在善事上有智慧，在恶事上却单纯。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:19; 约翰一书 3:8; 创世记 3:15"> 赐平安的上帝快要将撒但践踏在你们的脚下。<br />愿我们主耶稣基督的恩典与你们同在。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 使徒行传 17:5; 使徒行传 13:1"> 与我同工的提摩太，以及我的亲属路求、耶孙和所西巴德，都问候你们。</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 6:11; 哥林多前书 16:21; 罗马书 16:8"> 我这代笔写信的德丢，在主里问候你们。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:14; 使徒行传 19:22; 提摩太后书 4:20"> 接待我、也接待全教会的该犹问候你们。本城的司库以拉都和括土弟兄问候你们。</span>
<span className="v" id="v24" data-v="24"> 愿我们主耶稣基督的恩典与你们众人同在！阿们。</span>

</div>

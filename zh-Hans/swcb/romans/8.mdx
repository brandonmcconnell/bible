<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ROM" data-book-slug="romans" data-book-name="罗马书" data-chapter="8" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:18–19; 哥林多后书 5:17; 加拉太书 3:13"> 如今，那些在基督耶稣里、不随从肉体、只随从圣灵的人，就不被定罪了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU文本省略了“不随从肉体，只随从圣灵”这句话。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 6:14; 哥林多后书 3:17; 罗马书 6:18"> 因为生命之灵的律，在基督耶稣里释放了我，使我脱离了罪和死的律。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 13:39; 加拉太书 4:4–5; 希伯来书 7:18–19"> 律法因肉体的软弱而无法做到的事，上帝却做到了：祂差遣自己的儿子，取了有罪肉体的样式，为了对付罪，就在肉体中定了罪，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 5:16; 加拉太书 5:22–25; 歌罗西书 1:22"> 使律法公义的要求，成就在我们这些不随从肉体、只随从圣灵的人身上。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 2:14; 加拉太书 5:19–25; 约翰福音 3:6"> 因为随从肉体的人，体贴肉体的事；随从圣灵的人，体贴圣灵的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:8; 罗马书 8:7; 罗马书 8:13"> 体贴肉体的就是死，体贴圣灵的乃是生命与平安；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:14; 约翰一书 2:15–16; 雅各书 4:4"> 因为体贴肉体就是与上帝为敌，它不服从上帝的律法，事实上也无法服从。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:5–6; 希伯来书 11:5–6; 罗马书 8:9"> 属肉体的人不能得上帝的喜悦。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:6; 哥林多前书 3:16; 提摩太后书 1:14"> 然而，如果上帝的灵住在你们里面，你们就不属肉体，而是属圣灵了。人若没有基督的灵，就不属于基督。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:17; 加拉太书 2:20; 哥林多后书 5:21"> 基督若在你们里面，身体固然因罪而死，灵却因义而活。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 4:14; 罗马书 6:4–5; 哥林多后书 4:11"> 然而，如果使耶稣从死里复活者的灵住在你们里面，那使基督耶稣从死里复活的，也必借着住在你们里面的祂的灵，使你们必死的身体又活过来。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:2–15; 哥林多前书 6:19–20; 彼得前书 4:2–3"> 弟兄们，这样看来，我们并不是欠肉体的债，去顺从肉体活着。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:8; 彼得前书 2:11; 哥林多前书 9:27"> 因为你们若顺从肉体活着，必定会死；但若靠着圣灵治死身体的恶行，就必存活。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 约翰福音 1:12; 加拉太书 3:26"> 因为凡被上帝的灵引导的，都是上帝的儿女。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:5–7; 提摩太后书 1:7; 哥林多前书 2:12"> 因为你们所受的，不是奴仆的灵，使你们仍旧害怕；你们所受的，乃是得儿女名分的圣灵，借着祂我们呼叫：“阿爸！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“阿爸”是亚兰语的“父亲”或“爸爸”，在向我们在天上的父祷告时，表达亲切与敬意。">b</a></sup>父啊！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:13; 哥林多后书 1:22; 哥林多后书 5:5"> 圣灵亲自与我们的灵一同印证我们是上帝的儿女；</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 4:7; 加拉太书 3:29; 以弗所书 3:6"> 既是儿女，便是后嗣——是上帝的后嗣，和基督同作后嗣。如果我们确实与祂一同受苦，也必与祂一同得荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:17–18; 彼得前书 4:13; 彼得前书 1:5–7"> 我认为，现在的苦楚比起将来要显明在我们身上的荣耀，根本无法相比。</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:17–18; 罗马书 8:23; 约翰一书 3:2"> 受造之物正热切期盼着上帝的儿女显现出来。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:17–19; 创世记 5:29; 罗马书 8:22"> 因为受造之物服在虚妄之下，并不是出于自愿，而是出于那使它服从的，不过仍有盼望：</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 22:3–5; 使徒行传 3:21; 彼得后书 3:13"> 就是受造之物自己也将从败坏的辖制中得释放，进入上帝儿女荣耀的自由中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 12:4; 耶利米书 12:11; 约翰福音 16:21"> 因为我们知道，一切受造之物一同叹息、劳苦，直到如今。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:20–21; 哥林多后书 5:2–5; 希伯来书 9:28"> 不但如此，就是我们这拥有圣灵初熟果子的人，自己心里也在叹息，等候得着儿女的名分，就是我们的身体得蒙救赎。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 5:7; 希伯来书 11:1; 哥林多后书 4:18"> 因为我们是在盼望中得救的。只是看得见的盼望就不算盼望了；谁会盼望自己已经看见的呢？</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 12:12; 希伯来书 10:36; 诗篇 27:14"> 但如果我们盼望那看不见的，就会忍耐等候。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:20; 以弗所书 6:18; 加拉太书 4:6"> 同样，圣灵也在我们的软弱上帮助我们。我们本不知道当怎样祷告，但圣灵亲自用说不出来的叹息替我们代求。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 17:10; 约翰一书 5:14–15; 以弗所书 2:18"> 那鉴察人心的，知道圣灵的心意，因为圣灵是照着上帝的旨意替圣徒代求。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:10; 雅各书 1:12; 创世记 50:20"> 我们知道，万事都互相效力，叫爱上帝的人得益处，就是那些按祂旨意被召的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 1:4–5; 耶利米书 1:5; 以弗所书 1:11"> 因为祂预先所认识的人，祂也预定他们效法祂儿子的模样，使祂儿子在许多弟兄<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里的“弟兄”在上下文允许的情况下，也可以准确地翻译为“弟兄姐妹”或“手足”。">c</a></sup>中作长子。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 17:14; 罗马书 8:28; 以弗所书 1:11"> 祂所预定的人，祂又呼召他们；所呼召的人，祂又称他们为义；所称为义的人，祂又使他们得荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 118:6; 耶利米书 1:19; 诗篇 56:11"> 既是这样，对这些事我们该怎么说呢？上帝若帮助我们，谁能敌对我们呢？</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:16; 罗马书 8:28; 诗篇 84:11"> 祂连自己的儿子都没有顾惜，为我们众人舍了，岂不也把万物和祂一同白白地赐给我们吗？</span>
<span className="v" id="v33" data-v="33" data-xref="启示录 12:10–11; 以赛亚书 50:8–9; 以赛亚书 54:17"> 谁能控告上帝拣选的人呢？有上帝称他们为义了。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:25; 罗马书 8:27; 希伯来书 9:24"> 谁能定他们的罪呢？有死过的基督，而且祂已经复活了，如今在上帝的右边，也替我们代求。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 10:28; 诗篇 103:17; 约翰福音 16:33"> 谁能使我们与基督的爱隔绝呢？难道是患难吗？是困苦吗？是迫害吗？是饥饿吗？是赤身露体吗？是危险吗？是刀剑吗？</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 44:22; 以赛亚书 53:7; 哥林多前书 15:30"> 正如经上所记：<br /><span className="pl pl-1">“为祢的缘故，我们终日被杀；</span><br /><span className="pl pl-2">我们被看作将宰的羊。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:57; 约翰一书 4:4; 哥林多后书 2:14"> 然而，靠着爱我们的那一位，我们在这一切事上已经得胜有余了。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 10:28; 罗马书 14:8; 提摩太后书 1:12"> 因为我深信，无论是死，是生，是天使，是掌权的，是现在的事，是将来的事，是有能力的，</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:28–30; 罗马书 8:35; 罗马书 5:8"> 是高处的，是深处的，或是任何别的受造之物，都不能使我们与上帝的爱隔绝；这爱是在我们的主基督耶稣里的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:16; 加拉太书 5:13; 罗马书 6:15"> 那么，我们该怎么说呢？难道我们要继续留在罪中，好让恩典显得格外丰盛吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:9; 歌罗西书 3:3; 罗马书 7:4"> 绝对不可！我们这向罪死了的人，怎能继续活在罪中呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:27; 加拉太书 2:20–21; 罗马书 6:8"> 难道你们不知道，我们所有受洗归入基督耶稣的人，就是受洗归入祂的死吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:17; 歌罗西书 3:10; 以弗所书 4:22–24"> 因此，我们借着洗礼与祂一同埋葬，归入了死，好叫我们也能活出新生命的样式，正如基督借着父的荣耀从死里复活一样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:10–11; 哥林多后书 4:10; 歌罗西书 2:12"> 因为，我们若在祂死的样式上与祂联合，也必有份于祂的复活；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:20; 以弗所书 4:22; 加拉太书 5:24"> 因为我们知道，我们的旧人已经与祂同钉十字架，使罪身失效，叫我们不再受罪的奴役。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:1; 歌罗西书 3:1–3; 罗马书 7:4"> 因为已死的人就脱离了罪。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 2:11–12; 歌罗西书 3:3–4; 哥林多后书 4:10–14"> 我们若与基督同死，就信我们也必与祂同活。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:14; 启示录 1:18; 使徒行传 2:24–28"> 因为知道基督既然从死里复活，就不再死，死亡也不再辖制祂了！</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 4:6; 彼得前书 3:18"> 祂死，是向罪死了，只有这一次；祂活，是向上帝活着。</span>
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 3:3–5; 哥林多前书 6:20; 罗马书 6:2"> 这样，你们在基督耶稣我们的主里，也要将自己看作是向罪死了，向上帝却是活着的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:16; 罗马书 6:16; 罗马书 8:13"> 所以，不要让罪在你们必死的肉身上掌权，使你们顺从肉身的私欲。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:1; 罗马书 6:16; 歌罗西书 3:5"> 也不要把你们的肢体献给罪，作不义的器具；倒要像从死里复活的人，将自己献给上帝，并把你们的肢体献给上帝作义的器具。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 罗马书 8:2; 罗马书 7:4–11"> 罪必不能辖制你们，因为你们不在律法之下，而是在恩典之下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 2:11–14; 以弗所书 2:8–10; 罗马书 6:1–2"> 那又怎样呢？我们在恩典之下，不在律法之下，就可以犯罪吗？绝对不可！</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 8:34; 马太福音 6:24; 约书亚记 24:15"> 难道你们不知道，你们将自己献上作奴仆去顺从谁，就作谁的奴仆吗？或作罪的奴仆，以致于死；或作顺从的奴仆，以致于义。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:9; 提摩太后书 1:13; 罗马书 1:8"> 感谢上帝！你们虽然从前是罪的奴仆，现在却从心里顺从了传授给你们的教导模范。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 6:22; 罗马书 8:2; 加拉太书 5:1"> 你们既然从罪里得了释放，就作了义的奴仆。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 6:13; 彼得前书 4:2–4; 歌罗西书 3:5–7"> 因为你们肉体的软弱，我就用人的方式来说：你们从前怎样将肢体献给不洁和不法作奴仆，以致于不法；现在也要照样将肢体献给义作奴仆，以致于成圣。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:16–17; 约翰福音 8:34"> 因为你们作罪的奴仆时，就不受义的约束了。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 1:32; 罗马书 7:5; 罗马书 6:23"> 那么，你们当时结了什么果子呢？就是你们现在所以为耻的事，因为那些事的结局就是死。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 罗马书 6:18; 罗马书 8:2"> 但现在，你们既然从罪里得了释放，作了上帝的奴仆，就结出成圣的果子，那结局就是永生。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:36; 罗马书 5:12; 雅各书 1:15"> 因为罪的工价乃是死；但上帝的恩赐，在我们的主基督耶稣里，却是永生。</span>
</div>

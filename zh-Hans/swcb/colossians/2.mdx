<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:29; 腓立比书 1:30; 启示录 3:14–22"> 我愿意你们知道，我为你们、为老底嘉的人，以及所有没有亲眼见过我肉身面貌的人，是何等竭力奋斗；</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:27; 歌罗西书 4:8; 以弗所书 6:22"> 为要使他们的心得着安慰，在爱中联结，并且得到悟性所带来充足确信的一切丰富，好认识上帝的奥秘，就是父和基督；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:24; 哥林多前书 1:30; 罗马书 11:33"> 在祂里面，智慧和知识的一切宝藏都隐藏着。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 以弗所书 4:14; 罗马书 16:18–19"> 我说这话，是免得有人用花言巧语迷惑你们。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:3–4; 帖撒罗尼迦前书 2:17; 哥林多前书 16:13"> 因为我虽然肉身不在你们那里，灵里却与你们同在；我欢喜看见你们的秩序，以及你们对基督信心的坚定。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 1:10; 约翰一书 2:6; 帖撒罗尼迦前书 4:1"> 所以，你们既然接受了主基督耶稣，就当在祂里面行事为人；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 3:17; 耶利米书 17:8; 以弗所书 2:20–22"> 在祂里面扎根、建造，并且照着你们所受的教导，在信心上得以坚固，满有感谢。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 6:20; 以弗所书 5:6; 马太福音 7:15"> 你们要谨慎，免得有人用哲学和虚空的欺骗，照着人的传统，照着世上的基本灵力，而不是照着基督，把你们掳去。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:19; 约翰福音 10:30; 约翰福音 1:14"> 因为上帝本性一切的丰盛，都有形有体地住在祂里面；</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:19; 歌罗西书 1:16–18; 以弗所书 1:20–23"> 你们在祂里面也得了丰盛。祂是一切执政的和掌权者的元首。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 2:29; 腓立比书 3:3; 罗马书 6:6"> 你们在祂里面也受了不是人手所行的割礼，就是脱去肉体罪恶之身体的割礼，乃是基督的割礼；</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:3–5; 彼得前书 3:21; 加拉太书 3:27"> 你们在洗礼中已经与祂一同埋葬，也在其中借着信上帝的作为，与祂一同复活；这上帝使祂从死人中复活。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:5–6; 罗马书 8:11; 以弗所书 2:1"> 你们从前因自己的过犯和肉体未受割礼而死，上帝却使你们与祂一同活过来，赦免了我们一切的过犯；</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 44:22; 以弗所书 2:14–16; 以赛亚书 43:25"> 又涂抹了那用规条写成、抵挡我们的字据，把它撤去，钉在十字架上。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 2:14; 以弗所书 4:8; 马太福音 12:29"> 祂既解除了执政的和掌权者的武装，就公开展示他们，借着十字架胜过了他们。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 14:5–6; 罗马书 14:10; 加拉太书 4:10"> 所以，不要让任何人在饮食上，或在节期、月朔、安息日方面论断你们；</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:1; 希伯来书 8:5; 约翰福音 1:17"> 这些原是将来之事的影子，实体却属于基督。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:8; 约翰一书 4:1–2; 歌罗西书 2:23"> 不要让任何人凭着自我贬抑和敬拜天使夺去你们的奖赏；这样的人拘泥于自己没有见过的事，凭着属肉体的心思徒然自高自大，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:15–16; 约翰福音 15:4–6; 彼得后书 3:18"> 不紧紧持定元首；全身本是靠着祂，借着关节和筋络得供应并联结在一起，就以上帝所赐的增长而增长。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 歌罗西书 2:16; 加拉太书 4:3"> 你们若是与基督一同死了，脱离了世上的基本灵力，为什么还像活在世上一样，受规条约束，</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:3; 创世记 3:3; 以赛亚书 52:11"> “不可拿，不可尝，不可摸”</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 29:13; 提多书 1:14; 哥林多前书 6:13"> （这一切一经使用就都败坏），照着人的命令和教训呢？</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 4:8; 歌罗西书 2:18; 歌罗西书 2:8"> 这些事在自立的敬拜、谦卑和苦待身体上，确实有智慧的名声，却对于克制肉体的放纵毫无价值。</span>
</div>
</div>

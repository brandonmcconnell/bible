<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 6:8–20; 雅各书 2:13; 申命记 24:14–15"> 作主人的，要把公正公平的待遇给你们的仆人，因为知道你们也有一位主在天上。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:17–18; 腓立比书 4:6; 以弗所书 6:18"> 你们要恒切祷告，在祷告中警醒感恩；</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 6:19–20; 使徒行传 14:27; 帖撒罗尼迦后书 3:1–2"> 也要同时为我们祷告，求上帝给我们开传道的门，使我们能讲说基督的奥秘；我也正是为此被捆锁，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 4:1–4; 以弗所书 6:20; 歌罗西书 4:6"> 好使我按着所应当说的，把这奥秘显明出来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:15–17; 帖撒罗尼迦前书 4:12; 雅各书 3:13"> 你们对外人要以智慧行事，把握时机。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 4:29; 彼得前书 3:15; 传道书 10:12"> 你们的话语要常常带着恩典，用盐调和，好叫你们知道该怎样回答各人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:21–23; 使徒行传 20:4; 提摩太后书 4:12"> 关于我的一切事，有亲爱的弟兄、忠心的仆人、在主里的同作奴仆推基古，会告诉你们。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:22; 歌罗西书 2:2; 腓立比书 2:28"> 我差他到你们那里，正是为这事，好让他知道你们的情况，并安慰你们的心；</span>
<span className="v" id="v9" data-v="9" data-xref="腓利门书 1:10–19; 歌罗西书 4:7"> 同去的还有阿尼西母，他是忠心、亲爱的弟兄，是你们中的一位。他们会把这里所发生的一切事都告诉你们。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓利门书 1:24; 提摩太后书 4:11; 使徒行传 19:29"> 与我一同被囚的亚里达古问候你们；巴拿巴的表弟马可也问候你们——关于他，你们已经领受了指示：“如果他到你们那里，要接待他”——</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 11:2; 哥林多后书 6:1; 使徒行传 10:45"> 还有称为犹士都的耶数也问候你们。在受割礼的人中，只有这些人是我为上帝的国度同工的；他们成了我的安慰。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:30; 歌罗西书 1:9; 歌罗西书 1:7"> 以巴弗问候你们；他是你们中的一位，是基督的仆人，常常在祷告中为你们竭力，使你们在上帝一切旨意中站立得稳，成熟而完全。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 2:1; 罗马书 10:2; 启示录 1:11"> 我可以为他作证：他为你们，为老底嘉的人，也为希拉波立的人，有极大的热心。</span>
<span className="v" id="v14" data-v="14" data-xref="腓利门书 1:24; 提摩太后书 4:10–11"> 亲爱的医生路加和底马问候你们。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:5; 腓利门书 1:2; 哥林多前书 16:9"> 请问候在老底嘉的弟兄们，以及宁法和在他家里的教会。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:27; 帖撒罗尼迦后书 3:14"> 这封信在你们中间宣读以后，也要使它在老底嘉人的教会中宣读；你们也要读那封从老底嘉来的信。</span>
<span className="v" id="v17" data-v="17" data-xref="腓利门书 1:2; 使徒行传 1:17; 以西结 44:23–24"> 要告诉亚基布：“你要留心你在主里所领受的职事，务要完成它。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:3; 提摩太后书 4:22; 提摩太前书 6:21"> 我保罗亲手写这问安的话。要记念我的锁链。愿恩典与你们同在。阿们。</span>
</div>

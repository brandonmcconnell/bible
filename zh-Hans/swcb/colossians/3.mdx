<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="COL" data-book-slug="colossians" data-book-name="歌罗西书" data-chapter="3" data-verses="25">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 8:6; 马太福音 6:33; 哥林多后书 4:18"> 所以，你们若与基督一同复活了，就要寻求上面的事；在那里，基督坐在上帝的右边。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 2:15–17; 历代志上 22:19; 歌罗西书 3:1"> 你们要思念上面的事，不要思念地上的事。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:20; 罗马书 6:2; 歌罗西书 2:20"> 因为你们已经死了，你们的生命与基督一同藏在上帝里面。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:25; 约翰一书 3:2; 加拉太书 2:20"> 当基督——我们的生命——显现的时候，你们也要与祂一同在荣耀中显现。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:13; 加拉太书 5:19–21; 加拉太书 5:24"> 所以，要治死你们在地上的肢体：淫乱、污秽、邪情、恶欲，以及贪婪；贪婪就是拜偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 5:6; 罗马书 1:18; 彼得前书 1:14"> 因这些事，上帝的愤怒临到悖逆之子。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:2; 彼得前书 4:3–4; 罗马书 6:19–20"> 你们从前活在这些事中的时候，也曾在其中行事。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 4:29; 以弗所书 4:22; 雅各书 1:20–21"> 但现在，你们必须把这一切都除掉：恼怒、愤怒、恶意、毁谤，以及你们口中的羞耻言语。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:22; 以弗所书 4:25; 利未记 19:11"> 不要彼此说谎，因为你们已经脱去了旧人和旧人的行为，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:23–24; 罗马书 12:2; 以弗所书 2:10"> 并且穿上了新人；这新人照着创造他的那位的形象，在知识上不断更新。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 罗马书 10:12"> 在这新人里，并没有希腊人和犹太人、受割礼的和未受割礼的、蛮族人、西古提人、奴仆或自由人；基督却是一切，又在一切之中。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 以弗所书 4:2; 约翰一书 4:19"> 所以，你们既是上帝所拣选、圣洁蒙爱的人，就要穿上怜悯的心、仁慈、谦卑、温柔和忍耐；</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:32; 马可福音 11:25; 雅各书 2:13"> 要彼此包容，互相饶恕；若有人对别人有怨言，正如基督饶恕了你们，你们也要这样做。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:8; 以弗所书 5:2; 哥林多前书 13:1–13"> 最重要的是，要行在爱中；这爱是完全的纽带。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 4:6–7; 约翰福音 14:27; 以赛亚书 26:3"> 又要让上帝的平安在你们心里作主；你们也是为此在一个身体里蒙召。你们要存感谢的心。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:11; 以弗所书 5:19; 约翰福音 15:7"> 要让基督的话丰丰富富地住在你们里面；用各样智慧，以诗篇、赞美诗和属灵的歌彼此教导、劝戒，心中带着恩典向主歌唱。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 10:31; 歌罗西书 3:23; 箴言 3:6"> 无论你们做什么，或说话，或行事，都要奉主耶稣的名而做，借着祂感谢父上帝。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:22–9; 提多书 2:4–5; 哥林多前书 11:3"> 作妻子的，要顺服自己的丈夫，这在主里是合宜的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:7; 创世记 2:23–24; 歌罗西书 3:21"> 作丈夫的，要爱你们的妻子，不可苦待她们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 箴言 6:20"> 作儿女的，凡事要听从父母，因为这是主所喜悦的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所书 6:4; 诗篇 103:13"> 作父亲的，不要激怒你们的儿女，免得他们灰心。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:5–7; 提摩太前书 6:1–2; 加拉太书 1:10"> 作奴仆的，凡事要听从你们肉身上的主人；不要只在他们眼前服事，像讨人喜欢的人，而要存单纯的心，敬畏上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 3:17; 以弗所书 6:6–7; 罗马书 14:8"> 无论你们做什么，都要从心里做，像是为主做，不是为人做；</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 6:8; 加拉太书 1:10; 使徒行传 20:32"> 因为你们知道，你们必从主那里得到产业作为赏赐；因为你们服事的是主基督。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:34; 罗马书 2:11; 哥林多后书 5:10"> 但行不义的人必按他所行的不义受报应，并没有偏待人的事。</span>
</div>
</div>

</div>

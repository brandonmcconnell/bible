<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:1; 哥林多前书 1:1; 腓利门书 1:1"> 奉上帝旨意作基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>耶稣使徒的保罗，和我们的弟兄提摩太，</span>
<span className="v" id="v2" data-v="2" data-xref="彼得后书 1:2; 以弗所书 1:1; 罗马书 1:7"> 写信给在歌罗西、在基督里的圣徒和忠信的弟兄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里译作“弟兄”的词，在上下文允许的地方，也可正确译为“弟兄姊妹”或“手足”。">b</a></sup>：愿恩典、平安从我们的父上帝和主耶稣基督临到你们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 1:2; 歌罗西书 1:9; 提摩太后书 1:3"> 我们常常为你们祷告，感谢上帝，就是我们主耶稣基督的父，</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 1:15; 帖撒罗尼迦后书 1:3; 帖撒罗尼迦前书 1:3"> 因为听说你们在基督耶稣里的信心，以及你们对众圣徒所有的爱，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:3–4; 以弗所书 1:13; 提摩太后书 4:8"> 这是因那为你们存留在天上的盼望；这盼望是你们从前在福音真理的话语中所听见的。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 腓立比书 1:11; 歌罗西书 1:23"> 这福音已经传到你们那里，正如在全世界一样，不断结果、增长；自从你们听见，并真实认识上帝恩典的那一天起，它在你们中间也是这样。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 4:12; 腓利门书 1:23; 歌罗西书 4:7"> 这正如你们从我们亲爱的同作仆人的以巴弗那里所学的；他是替你们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU作“我们”">c</a></sup>忠心服侍基督的人，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 15:30; 提摩太后书 1:7; 加拉太书 5:22"> 也把你们在圣灵里的爱告诉了我们。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 3:17; 腓立比书 1:9–11; 雅各书 1:5"> 因此，我们自从听见这事的那一天起，也就不住地为你们祷告、祈求，愿你们在一切属灵的智慧和悟性上，充满对祂旨意的认识，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:1; 希伯来书 13:21; 彼得后书 1:2–3"> 好使你们行事为人配得上主，凡事蒙祂喜悦，在一切善工上结果子，并且在认识上帝上不断增长；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:16; 腓立比书 4:13; 以弗所书 4:2"> 照着祂荣耀的大能，得着一切能力的加力量，使你们凡事忍耐、恒忍，并且喜乐；</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:32; 以弗所书 1:11; 以弗所书 1:18"> 又感谢父，祂使我们有资格在光明中与圣徒同得基业。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 使徒行传 26:18; 彼得前书 2:9"> 祂救我们脱离黑暗的权势，把我们迁入祂爱子的国里；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:7; 罗马书 3:24–25; 彼得前书 1:19–20"> 我们在祂里面有救赎，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="TR加上“借着祂的血，”">d</a></sup>就是罪得赦免。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 1:3; 约翰福音 14:9; 约翰福音 1:1"> 祂是那不能看见之上帝的形像，是一切受造之物的首生者。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:36; 约翰福音 1:3; 哥林多前书 8:6"> 因为万有都是借着祂造的，无论是在天上的、在地上的，能看见的、不能看见的，或是宝座，或是统治，或是执政的，或是掌权的；万有都是借着祂并为祂造的。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 1:3; 哥林多前书 8:6; 使徒行传 17:28"> 祂在万有之先；万有也在祂里面维系。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:22–23; 启示录 1:5; 以弗所书 4:15–16"> 祂是身体，就是教会的头；祂是元始，是从死人中复活的首生者，好使祂在凡事上居首位。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 2:9; 约翰福音 1:16; 以弗所书 1:23"> 因为一切的丰盛都乐意住在祂里面，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:18–21; 以弗所书 1:10; 约翰一书 4:9–10"> 并且借着祂，既借着祂十字架上的血成就了和平，就借着祂使万有与自己和好；无论是地上的，还是天上的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所书 2:12; 提多书 3:3–7; 以弗所书 2:1–3"> 你们从前与上帝隔绝，在心思上因恶行成为仇敌，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:27; 犹大书 1:24; 以弗所书 1:4"> 如今祂却借着祂肉身的身体，经过死亡，使你们和好，好把你们圣洁、没有瑕疵、无可责备地呈献在祂面前；</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 3:14; 希伯来书 3:6; 马太福音 24:13–14"> 只要你们继续持守信心，根基稳固，坚定不移，不离开你们所听见的福音的盼望。这福音已经传给天下一切受造之物；我保罗也作了这福音的仆人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="罗马书 5:3; 提摩太后书 1:8; 哥林多后书 1:5–8"> 现在我为你们受苦，倒觉得喜乐；并且为了祂的身体，就是教会，在我的肉身上补满基督患难中尚缺少的部分。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所书 3:2; 歌罗西书 1:23; 加拉太书 2:7–8"> 我照着上帝为你们赐给我的管家职分，作了教会的仆人，为要成全上帝的话语，</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 罗马书 16:25–26; 以弗所书 3:3–10"> 就是历世历代以来隐藏的奥秘；但如今已经向祂的圣徒显明了。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:20; 罗马书 8:10; 以弗所书 3:16–17"> 上帝乐意让他们知道，这奥秘在外邦人中有何等荣耀的丰富；这奥秘就是基督在你们里面，成了荣耀的盼望。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:27; 耶利米书 3:15; 以弗所书 4:11–13"> 我们传扬祂，用一切智慧劝诫各人、教导各人，为要把各人在基督耶稣里成熟完全地呈献出来；</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 15:10; 以弗所书 1:19; 哥林多前书 9:25–27"> 我也为此劳苦，照着祂在我里面大有能力运行的功用竭力奋斗。</span>
</div>
</div>

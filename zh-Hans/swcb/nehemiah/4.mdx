<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:10; 希伯来书 11:36; 诗篇 35:15–16"> 参巴拉听见我们正在建造城墙，就发怒，极其恼恨，嘲笑犹太人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:9–10; 哥林多前书 1:27; 以西结 37:3–13"> 他在他的弟兄和撒玛利亚军队面前说：“这些软弱的犹太人在做什么？他们要自行加固城墙吗？他们要献祭吗？他们要一天完成吗？他们要从灰堆中使那些烧焦的石头复活吗？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:19; 列王纪上 20:10; 尼希米记 2:10"> 亚扪人多比雅站在他旁边，说：“他们所建造的，就是一只狐狸爬上去，也会把他们的石墙撞倒。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 79:12; 诗篇 123:3–4; 箴言 3:34"> “我们的上帝啊，求祢垂听，因为我们被人藐视。求祢使他们的羞辱归到他们自己头上，使他们在被掳之地成为被掠夺之物。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 109:14; 耶利米书 18:23; 诗篇 69:27–28"> 不要遮盖他们的罪孽，也不要让他们的罪从祢面前被涂抹；因为他们在建造的人面前出言侮辱。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:13; 尼希米记 6:15; 希伯来书 13:21"> 于是我们建造城墙；整道城墙都连接起来，高到一半，因为百姓一心做工。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:10; 尼希米记 4:1; 使徒行传 5:33"> 参巴拉、多比雅、阿拉伯人、亚扪人和亚实突人听见耶路撒冷城墙修复的工程继续进展，破口开始堵住，就非常恼怒。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 83:3–11; 以赛亚书 8:9–10; 耶利米书 20:10"> 他们一同密谋，要来攻打耶路撒冷，使我们陷入混乱。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:8; 使徒行传 4:24–30; 诗篇 50:15"> 但我们向我们的上帝祷告，又因他们的缘故，昼夜设立守望的人防备他们。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 11:1–2; 哈该书 1:2; 历代志下 2:18"> 犹大人说：“扛抬重物的人力气衰弱，瓦砾又多，我们无法建造城墙。”</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 5:2; 使徒行传 23:12; 诗篇 56:6"> 我们的敌人说：“他们还不知道，也看不见，我们就来到他们中间，杀死他们，使工程停止。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 31:7; 创世记 31:41; 民数记 14:22"> 住在他们附近的犹太人从各处来，十次对我们说：“你们无论转向哪里，他们都会攻击我们。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:17–18; 以弗所书 6:11–20; 雅歌 3:7–8"> 因此，我在城墙后面低洼的空旷处设立守卫，按宗族安排百姓，拿着刀、枪和弓。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 10:12; 民数记 14:9; 以赛亚书 41:10–14"> 我察看之后，就起来对贵族、官长和其余百姓说：“不要怕他们！要记念主，祂伟大可畏；要为你们的弟兄、儿女、妻子和家园争战。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 17:14; 罗马书 12:11; 约伯记 5:12–13"> 我们的敌人听见我们已经知道他们的计谋，并且上帝使他们的计谋归于无有，我们就都回到城墙那里，各做各的工。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 4:23; 诗篇 101:6; 尼希米记 5:15–16"> 从那时起，我的仆人一半做工，一半拿着枪、盾牌、弓和铠甲；官长都站在犹大全家后面。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 6:7; 提摩太后书 4:7; 提摩太后书 2:3"> 建造城墙的人和扛抬重物的人都一边负重，一手做工，一手拿兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:9; 历代志下 13:12–17"> 建造的人各自腰间佩刀建造；吹号的人在我身旁。</span>
<span className="v" id="v19" data-v="19"> 我对贵族、官长和其余百姓说：“工程浩大，分布很广；我们在城墙上彼此相隔很远。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 14:14; 申命记 1:30; 申命记 20:4"> 你们在哪里听见号角声，就聚集到我们那里；我们的上帝必为我们争战。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:9; 歌罗西书 1:29; 哥林多前书 15:58"> 于是我们做工，半数的人拿着枪，从天亮直到星宿出现。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 11:1–2"> 那时我又对百姓说：“各人和他的仆人都要住在耶路撒冷城内，好在夜间为我们守卫，白天做工。”</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 9:48; 尼希米记 7:2; 哥林多前书 15:10"> 这样，我和我的弟兄、我的仆人，以及跟随我的卫兵，都不脱衣服；各人取水时也带着兵器。</span>
</div>
</div>

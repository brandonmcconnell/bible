<span className="v" id="v2" data-v="2" data-xref="诗篇 101:6; 尼希米记 1:2; 马太福音 25:21"> 我就派我的弟兄哈拿尼，和堡垒长官哈拿尼雅，管理耶路撒冷；因为他是忠信的人，敬畏上帝胜过许多人。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 3:28–30; 诗篇 127:1; 尼希米记 3:23"> 我对他们说：“等到太阳热了，才可打开耶路撒冷的城门；人还站岗的时候，就要关门上闩。也要派耶路撒冷的居民守望，各按自己的班次，各守在自己房屋附近。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:12; 马太福音 6:33; 哈该书 1:4–6"> 那城广大宽阔，但城内百姓稀少，房屋还没有建造。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 3:5; 歌罗西书 1:29; 以斯拉记 7:27"> 我的上帝使我心里有意召集贵族、官长和百姓，好按家谱登记。我找到最初上来之人的家谱册，在其中看见这样写着：</span>
</div>
<div className="bp">

<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:2; 哈该书 1:1; 撒迦利亚书 3:1–3"> 他们是同所罗巴伯、耶书亚、尼希米、亚撒利雅、拉米雅、拿哈玛尼、末底改、必珊、米斯毗列、比革瓦伊、尼宏和巴拿一同回来的。<br />以色列百姓的人数如下：</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:3; 以斯拉记 8:3; 尼希米记 10:14"> 巴录的子孙二千一百七十二名。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 2:4; 以斯拉记 8:8"> 示法提雅的子孙三百七十二名。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 2:5; 尼希米记 6:18"> 亚拉的子孙六百五十二名。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 2:6; 尼希米记 10:14; 尼希米记 8:4"> 巴哈摩押的子孙，就是耶书亚和约押的子孙，二千八百一十八名。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 10:26; 以斯拉记 2:7; 以斯拉记 8:7"> 以拦的子孙一千二百五十四名。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 2:8"> 萨土的子孙八百四十五名。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯拉记 2:9"> 萨改的子孙七百六十名。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 2:10"> 宾内的子孙六百四十八名。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 2:11"> 比拜的子孙六百二十八名。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:12"> 押甲的子孙二千三百二十二名。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 2:13"> 亚多尼干的子孙六百六十七名。</span>

<span className="v" id="v21" data-v="21" data-xref="以斯拉记 2:16"> 亚特的子孙，就是希西家的后裔，九十八名。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 2:19"> 哈顺的子孙三百二十八名。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 2:17"> 比赛的子孙三百二十四名。</span>

<span className="v" id="v26" data-v="26" data-xref="以斯拉记 2:21–22"> 伯利恒和尼陀法的人一百八十八名。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 11:21; 以赛亚书 10:30; 以斯拉记 2:23"> 亚拿突人一百二十八名。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯拉记 2:24"> 伯·亚斯玛弗人四十二名。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 18:25; 以斯拉记 2:25; 士师记 18:12"> 基列·耶琳、基非拉和比录的人七百四十三名。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 18:24–25; 以斯拉记 2:26"> 拉玛和迦巴的人六百二十一名。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 13:23; 以斯拉记 2:27; 撒母耳记上 13:5"> 默玛人一百二十二名。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉记 2:28; 约书亚记 8:9; 约书亚记 8:17"> 伯特利和艾的人一百二十三名。</span>
<span className="v" id="v33" data-v="33" data-xref="以斯拉记 2:29"> 另一个尼波的人五十二名。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 7:12; 以斯拉记 2:31"> 另一个以拦的子孙一千二百五十四名。</span>
<span className="v" id="v35" data-v="35" data-xref="以斯拉记 2:32; 以斯拉记 10:31"> 哈琳的子孙三百二十名。</span>

<span className="v" id="v37" data-v="37" data-xref="历代志上 8:12; 尼希米记 6:2; 尼希米记 11:34–35"> 罗德、哈第和阿挪的子孙七百二十一名。</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉记 2:35"> 西拿的子孙三千九百三十名。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="历代志上 24:7–19; 以斯拉记 2:36"> 祭司：耶大雅的子孙，就是耶书亚家的人，九百七十三名。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志上 24:14; 以斯拉记 2:37"> 音麦的子孙一千零五十二名。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 9:12; 历代志上 24:9; 以斯拉记 2:38"> 巴施户珥的子孙一千二百四十七名。</span>
<span className="v" id="v42" data-v="42" data-xref="历代志上 24:8; 以斯拉记 10:31; 以斯拉记 2:39"> 哈琳的子孙一千零十七名。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 2:40; 尼希米记 3:9"> 利未人：耶书亚的子孙、甲篾的子孙，就是何第瓦的子孙，七十四名。</span>
<span className="v" id="v44" data-v="44" data-xref="以斯拉记 2:41; 历代志上 25:2"> 歌唱的人：亚萨的子孙一百四十八名。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 26:1–32; 以斯拉记 2:42"> 守门的人：沙龙的子孙、亚特的子孙、达们的子孙、亚谷的子孙、哈底大的子孙、朔拜的子孙，共一百三十八名。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以斯拉记 2:43; 利未记 27:2–8; 约书亚记 9:23–27"> 殿役：西哈的子孙、哈苏巴的子孙、答巴俄的子孙、</span>
<span className="v" id="v47" data-v="47" data-xref="以斯拉记 2:44"> 基绿的子孙、西亚的子孙、巴顿的子孙、</span>
<span className="v" id="v48" data-v="48" data-xref="以斯拉记 2:45–46"> 利巴拿的子孙、哈迦巴的子孙、萨买的子孙、</span>
<span className="v" id="v49" data-v="49"> 哈难的子孙、吉德的子孙、迦哈的子孙、</span>
<span className="v" id="v50" data-v="50"> 利亚雅的子孙、利汛的子孙、尼哥大的子孙、</span>
<span className="v" id="v51" data-v="51" data-xref="以斯拉记 2:49"> 迦散的子孙、乌撒的子孙、巴西亚的子孙、</span>
<span className="v" id="v52" data-v="52" data-xref="以斯拉记 2:50"> 比赛的子孙、米乌宁的子孙、尼普心的子孙、</span>
<span className="v" id="v53" data-v="53"> 巴卜的子孙、哈古巴的子孙、哈忽的子孙、</span>
<span className="v" id="v54" data-v="54" data-xref="以斯拉记 2:52"> 巴洗律的子孙、米希大的子孙、哈沙的子孙、</span>
<span className="v" id="v55" data-v="55" data-xref="以斯拉记 2:53"> 巴柯的子孙、西西拉的子孙、答玛的子孙、</span>
<span className="v" id="v56" data-v="56"> 尼细亚的子孙和哈提法的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="以斯拉记 2:55; 尼希米记 11:3"> 所罗门仆人的子孙：琐太的子孙、琐斐列的子孙、比利大的子孙、</span>
<span className="v" id="v58" data-v="58" data-xref="以斯拉记 2:56"> 雅拉的子孙、达昆的子孙、吉德的子孙、</span>
<span className="v" id="v59" data-v="59" data-xref="以斯拉记 2:57"> 示法提雅的子孙、哈替的子孙、玻黑列·哈斯巴音的子孙和亚们的子孙。</span>
<span className="v" id="v60" data-v="60" data-xref="以斯拉记 2:58"> 殿役和所罗门仆人的子孙共三百九十二名。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="以斯拉记 2:59"> 以下这些人是从特·米拉、特·哈萨、基绿、亚顿和音麦上来的；但他们不能证明自己的宗族和血统<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“后裔”。">a</a></sup>是否属以色列：</span>
<span className="v" id="v62" data-v="62" data-xref="以斯拉记 2:60"> 第莱雅的子孙、多比雅的子孙、尼哥大的子孙，共六百四十二名。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉记 2:61–63; 列王纪上 2:7; 撒母耳记下 17:27"> 祭司中，有哈巴雅的子孙、哈哥斯的子孙，以及巴西莱的子孙；这巴西莱娶了基列人巴西莱的一个女儿为妻，所以按他们的名被称呼。</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="历代志上 9:1; 尼希米记 7:5; 尼希米记 13:29"> 这些人在家谱记录中寻找自己的谱系，却找不到，因此被视为不洁，不得担任祭司职分。</span>
<span className="v" id="v65" data-v="65" data-xref="出埃及记 28:30; 尼希米记 8:9; 尼希米记 10:1"> 省长告诉他们，不可吃至圣之物，直到有一位祭司带着乌陵和土明起来供职。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="以斯拉记 2:64"> 全会众合计四万二千三百六十名，</span>
<span className="v" id="v67" data-v="67" data-xref="以斯拉记 2:65; 以赛亚书 45:1–2; 耶利米书 27:7"> 此外还有他们的仆婢七千三百三十七名；又有男女歌唱的人二百四十五名。</span>
<span className="v" id="v68" data-v="68" data-xref="以斯拉记 2:66–67"> 他们有马七百三十六匹，骡子二百四十五匹，</span>
<span className="v" id="v69" data-v="69"> 骆驼四百三十五匹，驴六千七百二十匹。</span>
</div>
<div className="bp">
<span className="v" id="v70" data-v="70" data-xref="尼希米记 8:9; 民数记 7:2–86; 出埃及记 12:22"> 有些族长为工程奉献。省长捐入库房的有金子一千达利克<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="达利克是波斯王发行的金币，约重8.4克。">b</a></sup>，盆五十个，祭司礼服五百三十件。</span>

</div>

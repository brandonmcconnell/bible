<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 13:2–3; 以斯拉记 8:23; 尼希米记 8:2"> 这月二十四日，以色列子孙聚集禁食，身穿麻衣，头蒙尘土。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理 9:3–10; 尼希米记 13:3; 以斯拉记 10:11"> 以色列的后裔与一切外族人分别出来，站着承认自己的罪和列祖的罪孽。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 8:7–8; 尼希米记 8:3–4"> 他们站在自己的地方，用一天的四分之一时间诵读耶和华他们上帝的律法书；又用一天的四分之一时间认罪，敬拜耶和华他们的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 8:7; 尼希米记 12:8; 尼希米记 9:5"> 利未人耶书亚、巴尼、甲篾、示巴尼、布尼、示利比、巴尼和基拿尼站在台阶上，大声呼求耶和华他们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 103:1–2; 彼得前书 1:3; 哥林多后书 4:6"> 利未人耶书亚、甲篾、巴尼、哈沙尼、示利比、荷第雅、示巴尼和毗他希雅说：“你们要站起来，称颂耶和华你们的上帝，从亘古直到永远！愿祢荣耀的名受称颂，超越一切称颂和赞美！</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:16; 创世记 1:1; 启示录 4:11"> 祢，惟有祢是耶和华。祢创造了天和天上的天，以及天上的万象；祢创造了地和地上的万物，海和海中的一切；祢保全这一切，天上的万象也敬拜祢。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 11:31; 创世记 17:5; 以赛亚书 51:2"> 祢是耶和华上帝，祢拣选了亚伯兰，领他出迦勒底的吾珥，给他起名叫亚伯拉罕。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:6; 创世记 15:18–21; 希伯来书 6:18"> 祢看见他的心在祢面前忠信，就与他立约，要把迦南人、赫人、亚摩利人、比利洗人、耶布斯人和革迦撒人的地赐给他，赐给他的后裔；祢成就了祢的话，因为祢是公义的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:7–9; 使徒行传 7:34; 出埃及记 3:16"> “祢看见我们列祖在埃及所受的苦难，也在红海边听见他们的呼求，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:20; 但以理 9:15; 出埃及记 18:11"> 就向法老和他所有臣仆，以及他国中所有百姓，施行神迹奇事；因为祢知道他们狂傲地对待我们的列祖。祢为自己赢得了名声，直到今日。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:13; 出埃及记 14:21–22; 出埃及记 14:27–28"> 祢在他们面前分开海，使他们从海中干地走过去；却把追赶他们的人抛入深处，如石头投入汹涌的大水。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 13:21–22; 尼希米记 9:19; 诗篇 107:7"> 白天，祢用云柱引导他们；夜间，祢用火柱照亮他们当走的路。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:160; 出埃及记 20:1; 诗篇 119:127–128"> “祢也降临在西奈山，从天上与他们说话，赐给他们正直的典章、真实的律法、美好的律例和诫命。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 20:8–11; 创世记 2:3; 以西结 20:12"> 祢使他们知道祢的圣安息日，又借祢仆人摩西吩咐他们诫命、律例和律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 10:3–4; 申命记 1:8; 出埃及记 17:6"> 祢从天上赐下粮食，止住他们的饥饿；又从磐石中使水流出，止住他们的干渴；祢吩咐他们进去得那地为业，就是祢举手起誓要赐给他们的地。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="尼希米记 9:29; 诗篇 81:11–14; 希伯来书 3:15"> “但他们和我们的列祖行事狂傲，硬着颈项，不听从祢的诫命，</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 86:5; 约珥 2:13; 诗篇 145:8–9"> 拒绝顺服，也不记念祢在他们中间所行的奇事，反而硬着颈项，在悖逆中立首领，要回到他们受奴役之地。然而祢是乐意赦免人的上帝，有恩典，有怜悯，不轻易发怒，满有慈爱，祢没有离弃他们。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 106:19–23; 出埃及记 32:4–8; 以西结 20:7–44"> 甚至他们为自己铸造牛犊，说：‘这是领你出埃及的上帝’，犯了极大的亵渎，</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 106:45; 尼希米记 9:27; 玛拉基书 3:6"> 祢仍因祢丰盛的怜悯，没有在旷野离弃他们。白天云柱没有离开他们，仍引导他们走路；夜间火柱也没有离开他们，仍照亮他们当走的路。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 143:10; 民数记 11:17; 以赛亚书 63:11–14"> 祢又赐下祢良善的圣灵教导他们，没有使吗哪离开他们的口，又赐水止住他们的干渴。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 2:7; 申命记 8:4; 诗篇 34:10"> “祢在旷野供养他们四十年，他们一无所缺；他们的衣服没有穿破，脚也没有肿。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 21:21–35; 申命记 3:1–17; 申命记 2:26–36"> 祢又把列国和万民赐给他们，按疆界分给他们；于是他们得了西宏之地，就是希实本王的地，也得了巴珊王噩的地。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 22:17; 创世记 15:5; 历代志上 27:23"> 祢使他们的子孙多如天上的星，又把他们带进那地，就是祢曾对他们列祖说，要他们进去得为业的地。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 21:43; 约书亚记 11:23; 诗篇 44:2–3"> “于是他们的子孙进去，得了那地为业；祢在他们面前制伏那地的居民，就是迦南人，把他们和他们的君王，以及那地的万民，都交在他们手中，使他们任意对待。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 32:15; 尼希米记 9:35; 申命记 3:5"> 他们夺取坚固的城和肥美的地，得了装满各样美物的房屋、凿成的水池、葡萄园、橄榄园和许多果树。他们吃得饱足，身体肥壮，因祢的大恩乐享美福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:9; 士师记 2:11–12; 尼希米记 9:18"> “然而他们不顺服，悖逆祢，把祢的律法抛在背后；他们杀害祢的先知，就是那些警戒他们、要使他们归向祢的先知，并且犯了极大的亵渎。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 106:41–45; 列王纪下 14:27; 列王纪下 13:5"> 所以祢把他们交在敌人手中，使他们受苦。他们在患难的时候向祢呼求，祢就从天上垂听；又照祢丰盛的怜悯，赐给他们拯救者，把他们从敌人手中救出来。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 5:31–1; 士师记 4:1; 列王纪上 8:39"> 但他们得了安宁以后，又在祢面前行恶；所以祢任凭他们落在仇敌手中，受仇敌辖制。然而他们回转向祢呼求的时候，祢仍从天上垂听；祢照祢的怜悯，多次拯救他们。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 9:16; 利未记 18:5; 尼希米记 9:26"> 祢警戒他们，要使他们归回祢的律法；他们却狂傲，不听从祢的诫命，违背祢的典章——人若遵行这些典章，就必因此得生命——他们转过肩背，硬着颈项，不肯听从。</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 2:4; 历代志下 36:15–16; 以赛亚书 42:24"> 祢多年容忍他们，又借祢的圣灵，藉着众先知警戒他们；他们仍不肯听从。因此祢把他们交在各地民族手中。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="耶利米哀歌 3:22; 耶利米书 4:27; 尼希米记 9:17"> “然而，因祢丰盛的怜悯，祢没有把他们灭尽，也没有离弃他们；因为祢是有恩典、有怜悯的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命记 7:9; 尼希米记 1:5; 但以理 9:4"> 现在，我们的上帝啊，祢是伟大、大能、可畏的上帝，守约施慈爱。自亚述诸王的时候直到今日，临到我们、我们的君王、首领、祭司、先知、列祖和祢众百姓的一切苦难，求祢不要看为小事。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 18:25; 诗篇 106:6; 约伯记 34:23"> 在临到我们的一切事上，祢都是公义的；因为祢行事信实，我们却行了恶。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 29:19; 列王纪下 17:13; 申命记 31:21"> 我们的君王、首领、祭司和列祖都没有遵守祢的律法，也没有听从祢的诫命和祢警戒他们的法度。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 28:47; 申命记 32:12–15; 耶利米书 5:19"> 他们在自己的国中，在祢赐给他们的大恩中，在祢摆在他们面前宽阔肥美的地上，没有事奉祢，也没有离开他们的恶行。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以斯拉记 9:9; 申命记 28:48; 历代志下 12:8"> “看哪，今日我们作了仆人；至于祢赐给我们列祖、使他们享用其果实和美物的地，看哪，我们竟在这地上作了仆人。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 28:33; 申命记 28:48; 以斯拉记 7:24"> 因我们的罪，这地把丰盛的出产交给祢所立来辖制我们的诸王；他们照自己的意思管辖我们的身体和牲畜，我们正处在极大的困苦中。</span>
<span className="v" id="v38" data-v="38" data-xref="尼希米记 10:1; 历代志下 34:31; 以斯拉记 10:3"> 因这一切，我们立下确实的约，并写成文书；我们的首领、利未人和祭司都在上面盖印。”</span>
</div>
</div>

</div>

<span className="v" id="v1" data-v="1" data-xref="尼希米记 10:2–8; 尼希米记 12:12–21; 以斯拉记 2:1–2"> 同撒拉铁的儿子所罗巴伯和耶书亚一同上来的祭司和利未人如下：西莱雅、耶利米、以斯拉，</span>
<span className="v" id="v2" data-v="2"> 亚玛利雅、玛鹿、哈突，</span>
<span className="v" id="v3" data-v="3"> 示迦尼、利宏、米利末，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:5"> 易多、近顿、亚比雅，</span>
<span className="v" id="v5" data-v="5"> 米雅民、玛底雅、璧迦，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 9:10; 尼希米记 11:10"> 示玛雅、约雅立、耶大雅，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 24:18; 撒迦利亚书 3:1; 以斯拉记 3:2"> 撒路、亚木、希勒家和耶大雅。这些人在耶书亚的日子，是祭司和他们弟兄的首领。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 11:17; 尼希米记 12:24; 尼希米记 11:22"> 利未人有耶书亚、宾内、甲篾、示利比、犹大和玛他尼；玛他尼和他的弟兄负责称谢的诗歌。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 12:24; 诗篇 134:1–3"> 他们的弟兄巴布迦和乌尼，按班次站在他们对面。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 6:3–15; 尼希米记 13:28; 尼希米记 13:4"> 耶书亚生约雅金，约雅金生以利亚实，以利亚实生耶何耶大，</span>
<span className="v" id="v11" data-v="11"> 耶何耶大生约拿单，约拿单生押杜亚。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米记 12:22; 历代志上 9:33–34; 历代志上 24:6–31"> 在约雅金的日子，祭司各宗族的首领如下：西莱雅族有米拉雅；耶利米族有哈拿尼雅；</span>
<span className="v" id="v13" data-v="13"> 以斯拉族有米书兰；亚玛利雅族有约哈难；</span>
<span className="v" id="v14" data-v="14"> 米利古族有约拿单；示巴尼族有约瑟；</span>
<span className="v" id="v15" data-v="15"> 哈琳族有押拿；米拉约族有希勒恺；</span>
<span className="v" id="v16" data-v="16"> 易多族有撒迦利亚；近顿族有米书兰；</span>
<span className="v" id="v17" data-v="17"> 亚比雅族有细基利；米拿民族、摩亚底族有毗勒太；</span>
<span className="v" id="v18" data-v="18"> 璧迦族有沙母亚；示玛雅族有约拿单；</span>
<span className="v" id="v19" data-v="19"> 约雅立族有玛特乃；耶大雅族有乌西；</span>
<span className="v" id="v20" data-v="20"> 撒来族有加莱；亚木族有希伯；</span>
<span className="v" id="v21" data-v="21"> 希勒家族有哈沙比雅；耶大雅族有拿坦业。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:10–13"> 至于利未人，在以利亚实、耶何耶大、约哈难和押杜亚的日子，他们各宗族的首领都被记录下来；祭司的首领也在波斯人大流士执政时被记录。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 9:14–44"> 利未的子孙，各宗族的首领，都写在历代志书上，直到以利亚实的儿子约哈难的日子。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 25:1–26; 尼希米记 11:17; 以斯拉记 3:10–11"> 利未人的首领有哈沙比雅、示利比和甲篾的儿子耶书亚；他们的弟兄站在他们对面，照上帝之人大卫的命令，分班赞美称谢。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 26:15; 尼希米记 12:8–9; 历代志上 26:12"> 玛他尼、巴布迦、俄巴底亚、米书兰、达们和亚谷，是守门的人，在各门的库房守卫。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 8:9; 以斯拉记 7:6; 以斯拉记 7:11"> 这些人都在约萨达的孙子、耶书亚的儿子约雅金的日子，以及省长尼希米和祭司兼文士以斯拉的日子供职。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 15:16; 历代志上 15:28; 历代志下 29:30"> 为耶路撒冷城墙行奉献礼的时候，众人从利未人所住的各处寻找他们，带他们到耶路撒冷，要欢欢喜喜地举行奉献礼，用称谢、歌唱、钹、瑟和琴来庆祝。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 9:16; 历代志上 2:54; 尼希米记 6:2"> 歌唱的人从耶路撒冷周围的平原和尼陀法人的村庄聚集而来，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:43; 历代志上 6:60; 以斯拉记 2:24"> 又从伯·吉甲，以及迦巴和亚斯玛弗的田野而来；因为歌唱的人在耶路撒冷周围为自己建立了村庄。</span>
<span className="v" id="v30" data-v="30" data-xref="约伯记 1:5; 出埃及记 19:10; 历代志下 29:5"> 祭司和利未人洁净自己，也洁净百姓、城门和城墙。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:13; 尼希米记 12:38; 历代志上 13:1"> 我带犹大的首领上城墙，又派定两大队称谢的人列队而行。一队在城墙上向右边往粪厂门行进；</span>
<span className="v" id="v32" data-v="32"> 何沙雅和犹大首领的一半跟在他们后面，</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 10:2–7"> 还有亚撒利雅、以斯拉、米书兰，</span>
<span className="v" id="v34" data-v="34"> 犹大、便雅悯、示玛雅、耶利米，</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 6:4; 民数记 10:2–10; 历代志下 5:12"> 以及一些祭司的子孙拿着号筒：撒迦利亚，他是约拿单的儿子，约拿单是示玛雅的儿子，示玛雅是玛他尼的儿子，玛他尼是米该亚的儿子，米该亚是撒刻的儿子，撒刻是亚萨的儿子；</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 12:24; 历代志下 8:14; 历代志上 23:5"> 还有他的弟兄示玛雅、亚萨利、米拉莱、基拉莱、玛艾、拿坦业、犹大和哈拿尼，拿着上帝之人大卫的乐器；文士以斯拉在他们前面引领。</span>
<span className="v" id="v37" data-v="37" data-xref="尼希米记 3:26; 尼希米记 2:14; 尼希米记 8:3"> 他们从泉门往前直行，沿大卫城的台阶上去，在城墙的坡道上，经过大卫家以上，直到东边的水门。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="尼希米记 3:8; 尼希米记 3:11; 尼希米记 12:31"> 另一队称谢的人迎着他们而行，我跟在他们后面，另有一半百姓在城墙上，从炉楼以上直到宽墙，</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米记 3:1; 尼希米记 3:3; 尼希米记 8:16"> 又经过以法莲门、古门、鱼门、哈楠业楼、哈米亚楼，直到羊门；他们停在护卫门。</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 42:4; 诗篇 134:1–3; 尼希米记 12:31–32"> 于是两队称谢的人站在上帝的殿中；我和与我同在的一半官长也站在那里，</span>
<span className="v" id="v41" data-v="41"> 还有祭司以利亚金、玛西雅、米拿民、米该雅、以利约乃、撒迦利亚和哈拿尼雅，拿着号筒；</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 81:1; 尼希米记 11:14; 诗篇 100:1–2"> 又有玛西雅、示玛雅、以利亚撒、乌西、约哈难、玛基雅、以拦和以谢。歌唱的人高声歌唱，由伊斯拉希雅指挥。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 3:13; 诗篇 92:4; 耶利米书 31:13"> 那日众人献上大祭，欢喜快乐，因为上帝使他们大大喜乐；妇女和儿童也都欢乐，耶路撒冷的欢声远处都能听见。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="尼希米记 13:12–13; 尼希米记 10:37–39; 历代志下 31:11–13"> 那日，众人派人管理库房，就是收藏举祭、初熟之物和十分之一的房间，要按各城田地的出产，把律法规定给祭司和利未人的份收集进去；因为犹大人为供职的祭司和利未人欢喜。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 25:1–26; 历代志下 23:6; 历代志上 23:28"> 祭司和利未人履行他们上帝所吩咐的职责，也履行洁净的职责；歌唱的人和守门的人也照大卫和他儿子所罗门的命令履行职责。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 29:30; 诗篇 73:1; 历代志上 25:1–31"> 因为古时在大卫和亚萨的日子，有歌唱者的首领，也有赞美称谢上帝的诗歌。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 18:21–29; 尼希米记 12:26; 尼希米记 13:10–12"> 在所罗巴伯的日子和尼希米的日子，以色列众人按每日所需，把歌唱的人和守门的人当得的份给他们；又把分别为圣归给利未人的份给利未人，利未人也把分别为圣归给亚伦子孙的份给他们。</span>
</div>

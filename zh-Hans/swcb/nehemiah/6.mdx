<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:19; 尼希米记 2:10; 尼希米记 4:1"> 参巴拉、多比雅、阿拉伯人基善和我们其余的敌人听说我已经建好城墙，墙上没有留下破口（不过到那时我还没有把门扇安在各门上），</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 37:12; 历代志上 8:12; 尼希米记 11:35"> 参巴拉和基善就派人来见我，说：“来吧，我们在阿挪平原的村庄相会。”但他们想要害我。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 9:4; 马太福音 10:16; 提摩太前书 4:15–16"> 我派使者去见他们，说：“我正在做一件大工程，不能下去。我若离开工程下去见你们，为什么要使工程停下来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 16:15–20; 路加福音 18:5; 加拉太书 2:5"> 他们这样四次派人来见我，我都照同样的话回答他们。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 6:11; 哥林多后书 2:11; 哥林多后书 11:13–15"> 第五次，参巴拉照样派他的仆人来见我，手里拿着一封未封口的信，</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 2:19; 以斯拉记 4:12; 罗马书 3:8"> 信上写着：“列国中有传闻，迦施慕也说，你和犹太人打算背叛；因此你建造城墙。照这些传闻，你要作他们的王。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:24–26; 列王纪上 1:7; 列王纪上 1:18"> 你又设立先知在耶路撒冷宣告你，说：‘犹大有王了！’现在这些话必传到王那里。所以现在来吧，让我们一同商议。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 52:2; 约伯记 13:4; 马太福音 12:34"> 我就派人去见他说：“你所说的这些事并不存在，都是你自己心里捏造出来的。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 138:3; 彼得前书 5:10; 以弗所书 3:16"> 他们都想使我们惧怕，说：“他们的手必因这工程发软，工程就不能完成。”但现在，求祢坚固我的手。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:5; 马太福音 7:15; 诗篇 37:12"> 我去见米希大别的孙子、第莱雅的儿子示玛雅；他闭门不出。他说：“我们在上帝的殿里，在圣殿中相会，把殿门关上吧；因为他们要来杀你，夜里必来杀你。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 11:1–2; 使徒行传 21:13; 箴言 28:1"> 我说：“像我这样的人岂可逃跑？像我这样的人岂能进圣殿保全性命呢？我不进去。”</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 13:22; 提摩太前书 3:3; 以西结 13:7"> 我看明了，看哪，上帝并没有差遣他；他对我说这预言，是因为多比雅和参巴拉雇用了他。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 20:10; 哥林多后书 11:12; 提摩太后书 1:7"> 他被雇用，是要使我惧怕，照他的话去做而犯罪，好让他们有把柄造恶名来羞辱我。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 13:29; 提摩太后书 4:14–15; 以赛亚书 9:14–15"> “我的上帝啊，求祢照多比雅和参巴拉所行的这些事记念他们，也记念女先知挪亚底和其余那些想要使我惧怕的先知。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="诗篇 1:3; 但以理 9:25; 尼希米记 4:1–2"> 以禄月二十五日，城墙完成了，共用了五十二天。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 126:2; 约书亚记 5:1; 尼希米记 4:7"> 我们一切敌人听见，周围的列国都惧怕，心中自觉羞愧；因为他们看出这工程是靠我们的上帝完成的。</span>
<span className="v" id="v17" data-v="17" data-xref="弥迦书 7:1–6; 马太福音 24:10–12; 尼希米记 3:5"> 在那些日子，犹大的贵族多次寄信给多比雅，多比雅的信也送到他们那里。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 2:5; 尼希米记 7:10; 尼希米记 3:4"> 原来在犹大有许多人向他起过誓，因为他是亚拉的儿子示迦尼的女婿；他的儿子约哈难也娶了比利迦的儿子米书兰的女儿为妻。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 4:18–21; 尼希米记 6:9; 约翰福音 7:7"> 他们还在我面前称赞他的善行，又把我的话传给他。多比雅也寄信来，使我惧怕。</span>
</div>
</div>

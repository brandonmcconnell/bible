<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 12:39; 耶利米书 31:38; 约翰福音 5:2"> 于是大祭司以利亚实和他的弟兄众祭司起来，建造羊门。他们将门分别为圣，安上门扇；又将城墙分别为圣，直到哈米亚楼，直到哈楠业楼。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:36; 以斯拉记 2:34; 尼希米记 10:12"> 在他旁边建造的是耶利哥人；在他们旁边建造的是音利的儿子撒刻。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:14; 尼希米记 12:39; 西番雅书 1:10"> 哈西拿的子孙建造鱼门。他们架设梁木，安上门扇、门闩和门栓。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 8:33; 尼希米记 3:21; 尼希米记 10:7"> 在他们旁边修造的是哈哥斯的孙子、乌利亚的儿子米利末；在他们旁边修造的是米示萨别的孙子、比利迦的儿子米书兰；在他们旁边修造的是巴拿的儿子撒督。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 3:27; 撒母耳记下 14:2; 耶利米书 27:2"> 在他们旁边修造的是提哥亚人；但他们的贵族不肯肩负他们主的工作。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 12:39"> 巴西亚的儿子耶何耶大和比所玳的儿子米书兰修造古门。他们架设梁木，安上门扇、门闩和门栓。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:2; 约书亚记 9:3–27; 尼希米记 3:19"> 在他们旁边修造的是基遍人米拉提，和米仑人雅顿，也就是基遍和米斯巴的人，他们修造到大河西省长的驻地。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 12:38; 尼希米记 3:31–32; 创世记 50:2"> 在他旁边修造的是哈海雅的儿子乌薛，他是金匠中的一人；在他旁边修造的是做香料的哈拿尼雅。他们修复耶路撒冷，直到宽墙。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:12; 尼希米记 3:17"> 在他们旁边修造的是户珥的儿子利法雅，他管理耶路撒冷一半的区。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 3:28–30; 尼希米记 10:4; 尼希米记 3:23"> 在他们旁边修造的是哈路抹的儿子耶大雅，在自己房屋对面修造；在他旁边修造的是哈沙尼的儿子哈突。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 12:38; 以斯拉记 2:6; 尼希米记 10:14"> 哈琳的儿子玛基雅和巴哈摩押的儿子哈述，修造另一段和炉楼。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 3:9; 使徒行传 21:8–9; 出埃及记 35:25"> 在他旁边修造的是哈罗黑的儿子沙龙，他管理耶路撒冷另一半的区；他和他的女儿们一起修造。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米记 2:13; 约书亚记 15:34; 历代志下 26:9"> 哈嫩和撒挪亚的居民修造谷门。他们建造这门，安上门扇、门闩和门栓，又修造城墙一千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘约为男子从肘部到中指尖的长度，约46厘米。">a</a></sup>，直到粪厂门。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 6:1; 尼希米记 2:13; 尼希米记 3:12–13"> 利甲的儿子玛基雅修造粪厂门；他管理伯·哈基琳区。他建造这门，安上门扇、门闩和门栓。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:7; 以赛亚书 8:6; 尼希米记 12:37"> 各荷西的儿子沙仑修造泉门；他管理米斯巴区。他建造这门，给它加盖，安上门扇、门闩和门栓；又修造靠近王园西罗亚池的城墙，直到从大卫城下来的台阶。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:29; 尼希米记 3:9; 列王纪下 20:20"> 在他以后修造的是押卜的儿子尼希米，他管理伯·夙一半的区；他修造到大卫坟墓对面的地方，又到人工池和勇士的房屋。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:44; 尼希米记 3:16; 撒母耳记上 23:1–13"> 在他以后修造的是利未人，巴尼的儿子利宏；在他旁边修造的是哈沙比雅，他管理基伊拉一半的区，为自己的区修造。</span>
<span className="v" id="v18" data-v="18"> 在他以后修造的是他们的弟兄，希拿达的儿子巴瓦伊；他管理基伊拉另一半的区。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:9; 尼希米记 10:9; 尼希米记 12:8"> 在他旁边修造的是耶书亚的儿子以谢，他管理米斯巴；他修造另一段，在城墙转弯处，正对着上军械库的坡道。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 3:1; 传道书 9:10; 罗马书 12:11"> 在他以后，萨拜的儿子巴录热心修造另一段，从城墙转弯处直到大祭司以利亚实家的门口。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 7:63; 以斯拉记 2:61"> 在他以后，哈哥斯的孙子、乌利亚的儿子米利末修造另一段，从以利亚实家的门口直到以利亚实家的尽头。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:28; 尼希米记 6:2"> 在他以后修造的是祭司，就是周围地区的人。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:2; 尼希米记 8:4; 尼希米记 3:29–30"> 在他们以后，便雅悯和哈述在自己房屋对面修造；在他们以后，亚难尼的孙子、玛西雅的儿子亚撒利雅在自己房屋旁边修造。</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 3:19; 尼希米记 3:27; 尼希米记 10:9"> 在他以后，希拿达的儿子宾内修造另一段，从亚撒利雅的房屋直到城墙转弯处，又到城角。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:2; 耶利米书 37:21; 尼希米记 12:39"> 乌赛的儿子巴拉修造城墙转弯处对面的部分，以及从王上宫突出、靠近护卫院的楼。在他以后修造的是巴录的儿子毗大雅。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 8:1; 尼希米记 11:21; 尼希米记 12:37"> （殿役住在俄斐勒，直到水门东面突出的楼对面。）</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 3:5"> 在他以后，提哥亚人修造另一段，对着那突出的高楼，直到俄斐勒的墙。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="历代志下 23:15; 耶利米书 31:40; 列王纪下 11:16"> 从马门以上，祭司们各自在自己房屋对面修造。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 19:2; 以斯拉记 2:37; 尼希米记 7:40"> 在他们以后，音麦的儿子撒督在自己房屋对面修造；在他以后，守东门的示迦尼的儿子示玛雅修造。</span>
<span className="v" id="v30" data-v="30"> 在他以后，示利米雅的儿子哈拿尼雅和萨拉的第六个儿子哈嫩修造另一段；在他以后，比利迦的儿子米书兰在自己房间对面修造。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:8; 尼希米记 3:32"> 在他以后，金匠中的一人玛基雅修造到殿役和商人的房屋，对着哈米弗甲门，直到城角的楼房。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 3:1; 约翰福音 5:2; 尼希米记 12:39"> 从城角楼房到羊门之间，是金匠和商人修造的。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 48:2; 以赛亚书 52:1; 尼希米记 11:18"> 百姓的首领住在耶路撒冷。其余的百姓也抽签，每十人中选一人来住在圣城耶路撒冷，其余九人住在别的城。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 5:9; 哥林多后书 8:16–17; 约伯记 29:13"> 凡甘心自愿住在耶路撒冷的人，百姓都为他们祝福。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:1; 以斯拉记 2:43; 历代志上 9:1–34"> 以下是住在耶路撒冷的本省首领；至于犹大的各城，以色列人、祭司、利未人、殿役和所罗门仆人的子孙，都各自住在本城自己的产业中。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 38:29; 马太福音 1:3; 路加福音 3:33"> 犹大子孙和便雅悯子孙中，有些人住在耶路撒冷。犹大子孙中，有法勒斯子孙亚他雅；他是乌西雅的儿子，乌西雅是撒迦利亚的儿子，撒迦利亚是亚玛利雅的儿子，亚玛利雅是示法提雅的儿子，示法提雅是玛勒列的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:5; 尼希米记 3:15; 民数记 26:20"> 又有玛西雅；他是巴录的儿子，巴录是各荷西的儿子，各荷西是哈赛雅的儿子，哈赛雅是亚大雅的儿子，亚大雅是约雅立的儿子，约雅立是撒迦利亚的儿子，撒迦利亚是示罗尼人的儿子。</span>
<span className="v" id="v6" data-v="6"> 住在耶路撒冷的法勒斯子孙共有四百六十八名，都是勇士。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 9:7–9"> 便雅悯的子孙如下：撒路；他是米书兰的儿子，米书兰是约叶的儿子，约叶是毗大雅的儿子，毗大雅是哥赖雅的儿子，哥赖雅是玛西雅的儿子，玛西雅是以铁的儿子，以铁是耶筛亚的儿子。</span>
<span className="v" id="v8" data-v="8"> 在他以后有迦拜和撒来，共九百二十八名。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 9:7"> 细基利的儿子约珥是他们的监督；哈西努亚的儿子犹大是管理城的副官。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 9:10; 尼希米记 12:6; 尼希米记 12:19"> 祭司中，有约雅立的儿子耶大雅、雅斤，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 9:11; 历代志上 6:7–14; 民数记 3:32"> 还有管理上帝殿的西莱雅；他是希勒家的儿子，希勒家是米书兰的儿子，米书兰是撒督的儿子，撒督是米拉约的儿子，米拉约是亚希突的儿子。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:12–13"> 还有他们的弟兄，在殿中做工的，共八百二十二名；又有亚大雅，他是耶罗罕的儿子，耶罗罕是毗拉利的儿子，毗拉利是暗洗的儿子，暗洗是撒迦利亚的儿子，撒迦利亚是巴施户珥的儿子，巴施户珥是玛基雅的儿子；</span>
<span className="v" id="v13" data-v="13"> 还有他的弟兄，各宗族的首领，共二百四十二名；又有亚玛帅，他是亚萨列的儿子，亚萨列是亚哈赛的儿子，亚哈赛是米实利末的儿子，米实利末是音麦的儿子；</span>
<span className="v" id="v14" data-v="14"> 还有他们的弟兄，英勇有力的人，共一百二十八名；管理他们的是哈基多琳的儿子撒巴第业。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 9:14; 历代志上 9:19"> 利未人中，有示玛雅；他是哈述的儿子，哈述是押利甘的儿子，押利甘是哈沙比雅的儿子，哈沙比雅是布尼的儿子。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 6:2–3; 尼希米记 8:7; 以斯拉记 8:33"> 又有利未人首领中的沙比太和约撒拔，管理上帝殿外面的事务。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 9:15; 历代志上 25:1–6; 尼希米记 12:8–9"> 又有玛他尼；他是米迦的儿子，米迦是撒底的儿子，撒底是亚萨的儿子；他是祷告时带领称谢的首领。还有他弟兄中的副手巴布迦，以及沙母亚的儿子押大；沙母亚是加拉的儿子，加拉是耶杜顿的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米记 11:1; 启示录 21:2; 但以理 9:24"> 在圣城的利未人共有二百八十四名。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="尼希米记 7:45; 历代志上 9:17–22; 诗篇 84:10"> 守门的人有亚谷、达们和他们的弟兄，在城门守卫的，共一百七十二名。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 11:3"> 其余的以色列人、祭司和利未人，都住在犹大各城，各在自己的产业中。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 3:26; 历代志下 27:3; 尼希米记 3:31"> 殿役住在俄斐勒；西哈和基斯帕管理殿役。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:42; 历代志上 25:1–6; 以斯拉记 8:19"> 在耶路撒冷管理利未人的是乌西；他是巴尼的儿子，巴尼是哈沙比雅的儿子，哈沙比雅是玛他尼的儿子，玛他尼是米迦的儿子；他属亚萨的子孙，是负责上帝殿事务的歌唱者。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 7:20–24; 尼希米记 12:47; 以斯拉记 6:8–9"> 因为王有命令论到他们，也为歌唱的人定下每日所需的供应。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 38:30; 历代志上 18:17; 历代志上 23:28"> 犹大儿子谢拉的子孙中，米示萨别的儿子毗他希雅，在百姓一切事务上代表王处理。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 14:15; 约书亚记 15:21–22"> 至于村庄和田地，犹大子孙中有人住在基列·亚巴和所属的乡镇，底本和所属的乡镇，叶甲薛和所属的村庄，</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 15:26–27; 约书亚记 19:2"> 又住在耶书亚、摩拉大、伯·帕列，</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:33; 约书亚记 15:28; 士师记 20:1"> 哈萨·书亚、别是巴和所属的乡镇，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 27:6; 约书亚记 15:31"> 洗革拉、米哥拿和所属的乡镇，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:41; 约书亚记 15:32–33; 约书亚记 15:35"> 音·临门、琐拉、耶末，</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 10:3; 约书亚记 15:8; 约书亚记 18:16"> 撒挪亚、亚杜兰和所属的村庄，拉吉和它的田地，亚西加和所属的乡镇。他们从别是巴直到欣嫩谷安营居住。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 12:8; 约书亚记 8:9; 约书亚记 18:13"> 便雅悯子孙也从迦巴往前，住在密抹、亚雅、伯特利和所属的乡镇，</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:18; 以赛亚书 10:30; 撒母耳记上 21:1"> 亚拿突、挪伯、亚难雅，</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 4:3; 撒母耳记上 7:17; 约书亚记 18:25"> 夏琐、拉玛、基他音，</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 13:18"> 哈第、洗编、尼八拉，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 8:12; 尼希米记 7:37; 历代志上 4:14"> 罗德、阿挪和匠人谷。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 21:1–45; 创世记 49:7; 历代志上 6:54–81"> 利未人中，有些犹大的班次定居在便雅悯境内。</span>
</div>
</div>

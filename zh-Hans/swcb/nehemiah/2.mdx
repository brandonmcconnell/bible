<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:1; 尼希米记 1:11; 尼希米记 1:1"> 亚达薛西王二十年尼散月，有酒摆在王面前，我拿起酒来递给王。我从前在王面前从未显出愁容。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 15:13; 创世记 40:7"> 王对我说：“你既没有生病，为什么面带愁容呢？这不是别的，必是心中忧伤。”<br />我就非常惧怕。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 1:3; 但以理 2:4; 列王纪上 1:31"> 我对王说：“愿王万岁！我列祖坟墓所在的城荒废，城门被火吞灭，我怎能不面带愁容呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 箴言 3:6; 尼希米记 1:4"> 王问我说：“你要求什么？”<br />于是我向天上的上帝祷告。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:22; 路得记 2:13; 以斯帖记 7:3"> 我对王说：“王若看为好，若你的仆人在你眼前蒙恩，求王差我往犹大，到我列祖坟墓所在的城去，好让我重建它。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 13:6; 以赛亚书 65:24; 尼希米记 5:14"> 那时王后也坐在王旁边。王问我说：“你的旅程要多久？什么时候回来？”<br />王乐意差遣我，我就向王定了日期。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:21; 以斯拉记 8:36; 尼希米记 2:9"> 我又对王说：“王若看为好，请赐我诏书给大河西的各省长，使他们准我经过，直到我抵达犹大；</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:6; 以赛亚书 66:14; 尼希米记 7:2"> 又赐一封信给管理王园林的亚萨，叫他给我木料，好为殿旁堡垒的城门、城墙，以及我所要居住的房屋作梁木。”<br />因我的上帝施恩的手帮助我，王就允准了我所求的。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 8:22"> 我到了大河西的各省长那里，把王的诏书交给他们。王还派了军官和骑兵护送我。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 2:19; 尼希米记 4:7; 尼希米记 13:4"> 和伦人参巴拉和亚扪人臣仆多比雅听见这事，就极其恼怒，因为有人来为以色列子孙谋求福祉。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 8:32"> 我到了耶路撒冷，在那里停留三天。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:17; 以斯拉记 7:27; 耶利米书 31:33"> 夜间，我和少数几个人起来；我的上帝使我心里要为耶路撒冷做的事，我没有告诉任何人。除了我所骑的牲口以外，没有别的牲口跟着我。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 1:3; 尼希米记 2:3; 尼希米记 3:13–14"> 当夜我从谷门出去，往野狗泉方向，又到粪厂门；我查看耶路撒冷的城墙，见城墙被拆毁，城门被火吞灭。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 3:15; 列王纪下 20:20; 历代志下 32:30"> 我又往泉门和王池去，但我所骑的牲口没有地方可以通过。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:23; 约翰福音 18:1; 耶利米书 31:38–40"> 于是我夜间沿溪而上，查看城墙；然后转身，从谷门进去，就回来了。</span>
<span className="v" id="v16" data-v="16"> 官长们不知道我去了哪里，做了什么。我还没有把这事告诉犹太人、祭司、贵族、官长，以及其余做工的人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 5:14; 尼希米记 1:3; 以赛亚书 35:3–4"> 后来我对他们说：“你们看见我们所处的困境：耶路撒冷荒废，城门被火焚烧。来吧，让我们重建耶路撒冷的城墙，免得我们再受羞辱。”</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:13; 历代志下 32:5; 历代志上 19:13"> 我告诉他们我的上帝施恩的手如何帮助我，也告诉他们王对我所说的话。<br />他们说：“我们起来建造吧！”于是他们振作起来，着手这美好的工程。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:6; 尼希米记 6:1–2; 诗篇 44:13–14"> 但和伦人参巴拉、亚扪人臣仆多比雅和阿拉伯人基善听见了，就讥笑我们，藐视我们，说：“你们在做什么？要背叛王吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 8:21; 以斯拉记 4:3; 诗篇 35:27"> 我回答他们说：“天上的上帝必使我们亨通；所以我们这些祂的仆人要起来建造。但你们在耶路撒冷无分、无权，也无可纪念之处。”</span>
</div>
</div>

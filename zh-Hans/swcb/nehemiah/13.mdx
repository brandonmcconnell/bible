<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:3–5; 尼希米记 9:3; 尼希米记 13:23"> 那日，众人在百姓耳中诵读摩西书，发现书上写着：亚扪人和摩押人永不可进入上帝的会众，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:5; 约书亚记 24:9–10; 民数记 23:8–11"> 因为他们没有拿食物和水迎接以色列子孙，反而雇了巴兰来咒诅他们；然而我们的上帝使咒诅变为祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 9:2; 出埃及记 12:38; 民数记 11:4"> 他们听见这律法，就使一切混杂的人离开以色列。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="尼希米记 12:44; 尼希米记 6:17–18; 尼希米记 13:28"> 在这以前，负责管理我们上帝殿中房间的祭司以利亚实，与多比雅有亲属关系，</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 12:44; 历代志下 34:11; 民数记 18:21–24"> 就为他预备了一间大房间；从前人们把素祭、乳香、器皿，以及照命令给利未人、歌唱的人和守门的人之五谷、新酒和油的十分之一，和给祭司的举祭，都存放在那里。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 5:14; 尼希米记 2:5–6; 马太福音 13:25"> 这一切发生的时候，我不在耶路撒冷；因为巴比伦王亚达薛西三十二年，我回到王那里。过了一段日子，我向王请假，</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 13:5; 马太福音 21:12–13; 耶利米哀歌 1:10"> 来到耶路撒冷，才知道以利亚实为多比雅所做的恶事，就是在上帝殿的院内为他预备房间。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 11:15–17; 以斯拉记 10:1; 诗篇 69:9"> 我非常忧愤，就把多比雅家中的一切物件都从那房间里扔出去。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:5; 历代志下 29:15–19; 尼希米记 12:45"> 我又下令，他们就洁净那些房间；我把上帝殿的器皿、素祭和乳香重新带回那里。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="尼希米记 10:37; 玛拉基书 3:8; 玛拉基书 1:6–14"> 我发现利未人当得的份没有给他们，以致供职的利未人和歌唱的人各自逃回自己的田地。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 10:39; 尼希米记 13:17; 尼希米记 13:25"> 我就责备官长，说：“为什么离弃上帝的殿呢？”我招聚利未人和歌唱的人，使他们重新站在自己的岗位上。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 10:37–39; 玛拉基书 3:10; 尼希米记 12:44"> 于是犹大众人把五谷、新酒和油的十分之一带进库房。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 22:7; 尼希米记 7:2; 尼希米记 12:44"> 我派祭司示利米雅、文士撒督和利未人毗大雅作库房管理员；在他们旁边的是撒刻的孙子、玛他尼的儿子哈难，因为他们被认为忠信；他们的职责是把份分给他们的弟兄。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 122:6–9; 尼希米记 13:22; 尼希米记 13:31"> 我的上帝啊，求祢因这事记念我，不要涂抹我为我上帝的殿和其中职守所行的善事。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 10:31; 尼希米记 13:21; 出埃及记 34:21"> 那些日子，我在犹大看见有人在安息日踩酒榨，搬运禾捆，把酒、葡萄、无花果和各样重担驮在驴上，在安息日带进耶路撒冷；他们卖食物的那日，我就警戒他们。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:12; 申命记 5:14"> 也有推罗人住在那里，把鱼和各样货物运来，在安息日卖给犹大子孙，并且在耶路撒冷售卖。</span>
<span className="v" id="v17" data-v="17" data-xref="尼希米记 13:11; 尼希米记 13:25; 以赛亚书 1:10"> 我就责备犹大的贵族，对他们说：“你们怎么行这恶事，亵渎安息日呢？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 17:21–23; 耶利米书 44:9; 民数记 32:14"> 你们列祖岂不是这样行，以致我们的上帝把这一切灾祸降在我们和这城身上吗？如今你们又亵渎安息日，使更多愤怒临到以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 23:32; 出埃及记 31:14–17; 耶利米书 17:19–22"> 安息日前，耶路撒冷城门开始昏暗的时候，我就下令关门，又吩咐直到安息日以后才可开门。我派我的几个仆人守在城门口，不准人在安息日把重担带进来。</span>
<span className="v" id="v20" data-v="20"> 于是商人和贩卖各样货物的人，有一两次在耶路撒冷城外过夜。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:3–4; 彼得前书 2:14; 以斯拉记 7:26"> 我就警戒他们，对他们说：“你们为什么在城墙外过夜呢？如果再这样，我就要下手对付你们。”从那以后，他们在安息日就不再来了。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:30; 尼希米记 13:14; 尼希米记 13:31"> 我又吩咐利未人洁净自己，来守城门，使安息日分别为圣。我的上帝啊，也求祢因这事记念我，照祢丰盛的慈爱怜惜我。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:1–2; 以斯拉记 10:10; 尼希米记 10:30"> 那些日子，我又看见犹太人娶了亚实突、亚扪和摩押的女子为妻；</span>
<span className="v" id="v24" data-v="24" data-xref="西番雅书 3:9"> 他们的儿女有一半说亚实突话，不会说犹大的语言，只会照各族的语言说话。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:3; 尼希米记 13:17; 尼希米记 10:29–30"> 我就责备他们，咒诅他们，打了其中一些人，拔下他们的头发，并叫他们指着上帝起誓，说：“你们不可把自己的女儿嫁给他们的儿子，也不可为你们的儿子，或为自己，娶他们的女儿。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 11:1–8; 列王纪上 3:13; 传道书 7:26"> 以色列王所罗门岂不是因这些事犯罪吗？在多国中没有一位王像他，他蒙他的上帝所爱，上帝立他作全以色列的王；然而连他也被外邦女子引诱犯罪。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 10:2; 撒母耳记上 30:24"> 难道我们要听任你们行这一切大恶，娶外邦女子为妻，得罪我们的上帝吗？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米记 2:19; 尼希米记 3:1; 尼希米记 12:22"> 大祭司以利亚实的儿子耶何耶大的一个儿子，是和伦人参巴拉的女婿；我就把他从我这里赶出去。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 6:14; 民数记 25:12–13; 玛拉基书 2:4–8"> 我的上帝啊，求祢记念他们，因为他们玷污了祭司职分，以及祭司和利未人的约。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="尼希米记 10:30; 尼希米记 12:1–26; 历代志上 23:1–26"> 这样，我洁净他们，使他们脱离一切外族人，又派定祭司和利未人的职责，各人各尽其职；</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 13:14; 尼希米记 13:22; 诗篇 106:4"> 也派定按时献柴和初熟之物的事。我的上帝啊，求祢记念我，施恩于我。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:7; 出埃及记 22:25–27; 哥林多前书 6:6–8"> 百姓和他们的妻子大声呼号，控诉他们的犹太弟兄。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 2:2; 诗篇 128:2–4; 诗篇 127:3–5"> 有人说：“我们和我们的儿女人口众多；请让我们得到粮食，好吃了活命。”</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 25:35–39; 玛拉基书 3:8–11; 创世记 47:15–25"> 也有人说：“因为饥荒，我们正抵押田地、葡萄园和房屋，为要得到粮食。”</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 4:13; 以斯拉记 4:20; 申命记 28:47–48"> 还有人说：“我们已经借钱缴纳王税，用田地和葡萄园作抵押。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 4:1; 利未记 25:39–43; 以赛亚书 58:7"> 如今我们的身体和我们弟兄的身体一样，我们的儿女也和他们的儿女一样。看哪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”译自希伯来文“הִנֵּה”，意思是“看、留意、注意”，常用作感叹词。">a</a></sup>，我们却要使自己的儿女作奴仆；我们有些女儿已经被迫作奴仆。我们也无力赎回，因为我们的田地和葡萄园已经归了别人。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 11:8; 尼希米记 13:25; 以弗所书 4:26"> 我听见他们的呼号和这些话，就非常愤怒。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 23:19–20; 利未记 25:36; 出埃及记 22:25"> 我心里筹划以后，就责备贵族和官长，对他们说：“你们各人都向自己的弟兄收取利息。”我召集大会来对付他们。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 25:47–49; 哥林多前书 8:11; 马太福音 25:29"> 我对他们说：“我们已经尽力赎回被卖给列国的犹太弟兄；你们竟还要卖自己的弟兄，使他们又被卖给我们吗？”他们就沉默无言，无话可答。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 25:36; 撒母耳记下 12:14; 罗马书 2:24"> 我又说：“你们所做的事不好。你们岂不该因列国我们仇敌的羞辱，而行事敬畏我们的上帝吗？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 6:1; 出埃及记 22:25–27; 以西结 18:13"> 我和我的弟兄、仆人也借钱借粮给他们。请我们大家停止收取这种利息吧。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:6; 利未记 6:4–5; 路加福音 3:8"> 请你们今日就把他们的田地、葡萄园、橄榄园和房屋归还给他们，也把你们向他们所收的银钱、粮食、新酒和油的百分之一还给他们。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 10:5; 耶利米书 34:8–10; 马太福音 19:21–22"> 他们说：“我们必归还他们，不再向他们索取什么。你怎样说，我们就怎样做。”<br />于是我召来祭司，使众人起誓，要照这承诺去行。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:6; 历代志上 16:36; 马太福音 10:14"> 我又抖着怀里的衣襟说：“凡不履行这承诺的，愿上帝也这样把他从他的家和产业中抖出去；愿他这样被抖空，一无所有。”<br />全会众都说：“阿们！”又赞美耶和华。百姓就照这承诺去行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米记 13:6; 帖撒罗尼迦后书 3:8–9; 哥林多前书 9:4–15"> 此外，自从我被任命为犹大地的省长，从亚达薛西王二十年直到三十二年，共十二年，我和我的弟兄都没有吃省长的俸禄。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 5:9; 以赛亚书 50:10; 箴言 16:6"> 在我以前的前任省长加重百姓的负担，从他们那里取粮和酒，此外还取银子四十舍客勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一舍客勒约10克。">b</a></sup>；甚至他们的仆人也辖制百姓。但我因敬畏上帝，没有这样行。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:9; 帖撒罗尼迦前书 2:5–6; 哥林多前书 15:58"> 我也持续参与这城墙的工程。我们没有购置田地，我的仆人都聚集在那里做工。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:19; 彼得前书 4:9–10; 撒母耳记下 9:7"> 在我席上吃饭的，有犹太人和官长一百五十人，此外还有从周围列国来到我们这里的人。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:22–23; 诗篇 37:21; 诗篇 37:26"> 每天预备的，有一头牛和六只肥美的羊，也为我预备飞禽；每十天还预备各样酒很多。尽管如此，我没有索取省长的俸禄，因为这百姓所受的劳役沉重。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 13:31; 诗篇 106:4; 尼希米记 13:14"> 我的上帝啊，求祢记念我为这百姓所做的一切善事，恩待我。</span>
</div>
</div>

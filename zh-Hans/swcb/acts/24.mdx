<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="24" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:11; 使徒行传 23:2; 使徒行传 25:2"> 过了五天，大祭司亚拿尼亚同几位长老和一个辩士，就是帖土罗，下来了。他们向总督控告保罗。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行传 24:26–27"> 保罗被传来后，帖土罗开始控告他，说：“尊贵的腓力斯大人，因着你，我们享有极大的太平；又因着你的远见，这个民族得以兴旺，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 23:26; 使徒行传 26:25; 路加福音 1:3"> 我们在各方面、各地方都满怀感谢地领受这一切。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:32"> 但为了不多耽误你，我恳求你宽容我们，听我们说几句话。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 28:22; 使徒行传 24:14; 使徒行传 26:5"> 我们发现这个人如同瘟疫，在普天下所有犹太人中煽动叛乱，又是拿撒勒派的一个头目。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:12; 使徒行传 21:27–32; 约翰福音 18:31"> 他甚至企图亵渎圣殿，我们就逮捕了他。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加上：“我们想要按照我们的律法审判他，”">a</a></sup></span>
<span className="v" id="v7" data-v="7"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 加上：“可是千夫长吕西亚前来，用强暴的手段把他从我们手中夺走，”">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 23:35; 使徒行传 25:15–16; 使徒行传 25:5"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR 加上：“命令控告他的人到你这里来。”">c</a></sup>你亲自审问他，就可以查明我们控告他的这一切事。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 2:16; 弥迦书 7:2–3; 诗篇 4:2"> 犹太人也一同攻击，断言这些事确是如此。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前书 3:15; 撒母耳记上 2:25; 路加福音 18:2"> 总督示意保罗说话，保罗就回答说：“我知道你多年来作这个民族的审判官，所以我乐意为自己申辩。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:1; 使徒行传 21:18; 使徒行传 23:11"> 你可以查明，我上耶路撒冷敬拜，到现在不过十二天。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 25:8; 使徒行传 28:17; 使徒行传 24:18"> 他们并没有看见我在圣殿里同任何人争论，也没有看见我在会堂里或城里煽动群众。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:7; 彼得前书 3:16"> 他们现在控告我的事，也不能向你证明。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:2; 罗马书 3:21; 使徒行传 3:13"> 但有一件事我向你承认：我正是照着他们称为教派的这道，事奉我们祖先的上帝；凡合乎律法、写在先知书上的一切，我都信。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理 12:2; 约翰福音 5:28–29; 帖撒罗尼迦前书 4:14–16"> 我对上帝存着盼望，就是他们自己也期待的：义人和不义的人都要复活。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:1; 提摩太前书 1:5; 哥林多后书 4:2"> 因此，我也常常操练自己，对上帝、对人都存无亏的良心。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:10; 罗马书 15:25–28; 哥林多前书 16:1–4"> 过了几年，我来是要把周济款和供物带给我的民族；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:21; 使徒行传 21:26–30; 使徒行传 24:12"> 正是在这些事上，有几个从亚细亚来的犹太人看见我在圣殿里已经行了洁净礼，并没有聚众，也没有骚乱。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:30; 使徒行传 25:16"> 如果他们有什么事反对我，他们本该到你面前来控告。</span>
<span className="v" id="v20" data-v="20"> 不然，就让这些人自己说，我站在公会面前时，他们在我身上发现了什么不义；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:6; 使徒行传 4:2; 使徒行传 26:6–8"> 除非是因为我站在他们当中喊出的这一句话：‘我今天在你们面前受审，是为死人复活的事！’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:6; 使徒行传 24:24; 使徒行传 25:26"> 腓力斯对这道有更确切的了解，就把他们延期，说：“等千夫长吕西亚下来，我要判决你们的案件。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 28:16; 使徒行传 27:3; 箴言 16:7"> 他吩咐百夫长看守保罗，给他一些宽待，也不要禁止他的朋友来服事他或探望他。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:21; 加拉太书 2:16; 马可福音 6:20"> 过了几天，腓力斯和他的妻子土西拉一同来到；土西拉是犹太女子。腓力斯派人叫保罗来，听他讲论在基督耶稣里的信。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:8; 彼得前书 3:15; 使徒行传 10:42"> 保罗讲论公义、节制和将来的审判，腓力斯就害怕了，回答说：“你暂且去吧；等我方便的时候，我会再叫你来。”</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 6:9–10; 箴言 17:23; 以赛亚书 56:11"> 同时，他也指望保罗会给他钱，好释放他。因此他也更常叫保罗来，和他谈话。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 25:9; 使徒行传 25:14; 使徒行传 12:3"> 过了两年，波求·非斯都接替了腓力斯；腓力斯想要讨犹太人的欢心，就把保罗留在监禁中。</span>
</div>
</div>

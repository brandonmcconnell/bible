<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 23:34; 使徒行传 25:5; 使徒行传 8:40"> 非斯都到了行省以后，过了三天，就从凯撒利亚上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:15; 箴言 4:16; 使徒行传 24:1"> 祭司长和犹太人的首要人物向他控告保罗，并且恳求他，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 9:24; 使徒行传 23:12–15; 撒母耳记上 23:19–21"> 求他给他们一个针对保罗的恩惠，传召保罗到耶路撒冷来；他们却在路上设下埋伏，要杀害保罗。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:23"> 然而非斯都回答说，保罗应当拘押在凯撒利亚，而他自己不久就要动身离开。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 25:25; 约翰福音 18:29–30; 使徒行传 25:18–19"> 他说：“所以，你们中间有权势的人可以和我一同下去；如果那人有什么过错，就让他们控告他。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 25:17; 使徒行传 25:10; 马太福音 27:19"> 非斯都在他们那里停留了十多天，就下凯撒利亚去；第二天，他坐在审判台上，命令把保罗带来。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 24:13; 路加福音 23:10; 使徒行传 25:24"> 保罗来了以后，那些从耶路撒冷下来的犹太人站在他周围，提出许多严重的控告来反对他，却不能证明。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 24:12; 使徒行传 28:17; 哥林多后书 1:12"> 保罗申辩说：“无论对犹太人的律法，对圣殿，还是对凯撒，我都没有犯什么罪。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 24:27; 使徒行传 12:3; 使徒行传 25:20"> 但非斯都想要讨犹太人的喜欢，就回答保罗说：“你愿意上耶路撒冷去，在那里就这些事在我面前受审吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:18; 哥林多后书 4:2; 使徒行传 28:18"> 保罗说：“我正站在凯撒的审判台前，我应当在这里受审。我并没有亏负犹太人什么，这也是你很清楚知道的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:19; 使徒行传 26:32; 使徒行传 25:25"> 如果我有罪，犯了什么该死的事，我并不拒绝受死；但如果他们控告我的那些事都不是真的，就没有人可以把我交给他们。我向凯撒上诉！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:21; 腓立比书 1:12–14; 腓立比书 1:20"> 于是非斯都和顾问团商议以后，回答说：“你既然向凯撒上诉，就要到凯撒那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:40; 使徒行传 26:1; 使徒行传 26:27–28"> 过了些日子，亚基帕王和百妮基来到凯撒利亚，问候非斯都。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 24:27"> 他们在那里停留了许多天，非斯都就把保罗的案件陈述给王，说：“这里有一个人，是腓力斯留下的囚犯；</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1–3; 以斯帖记 3:9; 路加福音 18:3–5"> 我在耶路撒冷的时候，祭司长们和犹太人的长老们向我控告他，要求判他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:51; 申命记 19:17–18; 使徒行传 23:30"> 我回答他们说，罗马人的规矩不是在被告还没有与原告当面对质，并有机会为被控告的事申辩以前，就把任何人交出去处死。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:6; 使徒行传 25:10"> 所以他们来到这里聚集以后，我没有拖延，第二天就坐在审判台上，命令把那人带来。</span>
<span className="v" id="v18" data-v="18"> 原告们站起来时，并没有提出我所预想的那些罪名来控告他；</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:29; 使徒行传 18:15; 哥林多前书 15:3–4"> 只是有些关于他们自己宗教的问题，以及关于一个已经死了的耶稣，保罗却坚称祂还活着。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 25:9"> 我不知该怎样查问这些事，就问他愿不愿意到耶路撒冷去，在那里就这些事受审。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:16; 路加福音 2:1; 使徒行传 25:10–11"> 但保罗上诉，要求留押等候皇帝裁决，我就命令把他拘留，直到我可以把他送到凯撒那里。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:15; 马太福音 10:18; 以赛亚书 52:15"> 亚基帕对非斯都说：“我自己也想听听这个人。”<br />非斯都说：“明天你会听到他。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 26:30; 使徒行传 25:13; 约翰一书 2:16"> 第二天，亚基帕和百妮基带着盛大的排场来到，与千夫长们和城里的显要人物一同进入听审厅；非斯都一声令下，保罗就被带进来。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 22:22; 使徒行传 25:7; 使徒行传 25:2–3"> 非斯都说：“亚基帕王，以及所有在这里与我们同在的诸位，你们看这个人，在耶路撒冷和这里，犹太全体民众都向我请求，呼喊说他不该再活着。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:29; 使徒行传 25:11–12; 路加福音 23:4"> 但我发现他没有犯什么该死的罪；既然他本人向皇帝上诉，我就决定把他送去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3"> 关于这个人，我没有什么确切的事可写给我的主上。因此我把他带出来到你们面前，尤其是带到你面前，亚基帕王，好让我在审问之后，有事可以写。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 7:51; 箴言 18:13"> 因为我看来，押送一个囚犯，却不说明对他的控告，是不合理的。”</span>
</div>
</div>

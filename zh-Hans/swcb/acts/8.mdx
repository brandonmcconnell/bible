<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="8" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 22:20; 但以理 3:16–18; 使徒行传 5:40"> 扫罗赞同处死司提反。那一天，耶路撒冷的教会遭遇大逼迫；除了使徒以外，众人都分散到犹太和撒马利亚各地。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:10–11; 创世记 23:2; 耶利米书 22:18"> 有敬虔的人埋葬了司提反，为他大大哀哭。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:13; 加拉太书 1:13; 哥林多前书 15:9"> 但扫罗残害教会，挨家进去，把男女都拉出来，送进监牢。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:23; 使徒行传 11:19; 使徒行传 8:1"> 因此，那些分散的人到各处传讲这道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:5; 使徒行传 21:8; 使徒行传 8:35–36"> 腓利下到撒马利亚城，向他们宣讲基督。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 4:41–42; 历代志下 30:12; 马太福音 20:15–16"> 群众听见腓利所说的话，又看见他所行的神迹，就同心合意地留心听他。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:1; 使徒行传 14:8–10; 马可福音 16:17–18"> 因为污灵从许多被附的人身上出来，大声喊叫着出来；许多瘫痪的和瘸腿的也得了医治。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:52; 使徒行传 13:48; 使徒行传 8:39"> 那城里就大有喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:6; 使徒行传 5:36; 约翰福音 7:18"> 有一个人名叫西门，素来在城里行邪术，使撒马利亚的百姓惊奇，又自称是个伟大人物；</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:34; 彼得后书 2:2; 启示录 13:3"> 从小到大，众人都留心听他，说：“这个人就是上帝那称为伟大的能力。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 8:9; 加拉太书 3:1; 以赛亚书 44:25"> 他们留心听他，是因为他长期用邪术使他们惊奇。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 2:38; 使徒行传 1:3; 马太福音 28:19"> 但他们信了腓利所传关于上帝国和耶稣基督之名的福音，男女都受了洗。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:6–7; 约翰福音 5:20; 使徒行传 19:11"> 西门自己也信了；受洗以后，他常常跟随腓利。他看见神迹和大异能发生，就惊奇不已。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 帖撒罗尼迦前书 3:2; 加拉太书 2:9"> 在耶路撒冷的使徒听见撒马利亚领受了上帝的道，就派彼得和约翰到他们那里去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:38; 约翰福音 16:23–24; 约翰福音 14:13–14"> 他们下去以后，为他们祷告，使他们可以领受圣灵；</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 19:2; 马太福音 28:19"> 因为圣灵还没有降在他们任何人身上，他们只是奉基督耶稣的名受了洗。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 19:6; 使徒行传 6:6; 提摩太后书 1:6"> 于是使徒给他们按手，他们就领受了圣灵。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:5; 马太福音 10:8; 列王纪下 8:9"> 西门看见圣灵是借着使徒按手而赐下的，就拿钱给他们，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 约翰三书 1:9; 约翰福音 5:44"> 说：“也把这权柄给我，使我给谁按手，谁就可以领受圣灵。”</span>
<span className="v" id="v20" data-v="20" data-xref="但以理 5:17; 马太福音 10:8; 使徒行传 2:38"> 彼得却对他说：“愿你的银子和你一同灭亡！因为你以为可以用钱取得上帝的恩赐。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 4:13; 诗篇 36:1; 马太福音 6:22–24"> 你在这事上没有分，也没有份，因为你的心在上帝面前不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 2:25–26; 但以理 4:27; 希伯来书 4:12"> 所以，你要为自己的这恶悔改，祈求上帝，或许你心里的意念可以得赦免。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 58:6; 箴言 5:22; 约翰福音 8:34"> 因为我看出你正在苦胆之毒中，在不义的捆绑里。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 8:8; 民数记 21:7; 约伯记 42:8"> 西门回答说：“请你们为我向主祷告，使你们所说的事没有一样临到我。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 20:21; 使徒行传 26:22–23; 使徒行传 1:8"> 于是，使徒作了见证，讲了主的道，就回耶路撒冷去，并在撒马利亚人的许多村庄传福音。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:19; 希伯来书 1:14; 列王纪下 1:3"> 有主的一位天使对腓利说：“起来，往南走，到那条从耶路撒冷下迦萨去的路上；那路是旷野。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="西番雅书 3:10; 诗篇 68:31; 以赛亚书 56:3–8"> 他就起来去了。看哪，有一个埃塞俄比亚人，是埃塞俄比亚女王甘大基手下有大权的太监，掌管她所有的府库；他曾上耶路撒冷去敬拜，</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:16; 以赛亚书 1:1; 使徒行传 28:25"> 现在正回来，坐在车上，诵读先知以赛亚的书。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:19; 使徒行传 11:12; 使徒行传 20:22–23"> 圣灵对腓利说：“你走近这车，贴近它。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 约翰福音 5:39; 以弗所书 5:17"> 腓利跑过去，听见他诵读先知以赛亚的书，就说：“你所读的，你明白吗？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="罗马书 10:14; 诗篇 73:16–17; 以赛亚书 29:18–19"> 他说：“没有人指教我，我怎能明白呢？”于是他请腓利上车，和他同坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 53:7–8; 彼得前书 2:21–24; 耶利米书 51:40"> 他所读的那段经文是这样：<br /><span className="pl pl-1">“祂像羊被牵去宰杀；</span><br /><span className="pl pl-2">又像羊羔在剪毛的人面前无声，</span><br /><span className="pl pl-2">祂也是这样不开口。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 53:12; 以赛亚书 53:8; 撒迦利亚书 13:7"> <span className="pl pl-1">祂受屈辱的时候，祂的审判被夺去。</span><br /><span className="pl pl-2">谁能述说祂的世代呢？</span><br /><span className="pl pl-2">因为祂的生命从地上被夺去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 15:15; 马太福音 13:36; 马太福音 2:2–4"> 太监问腓利说：“请问，先知说这话是指谁？是指他自己，还是指别人？”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行传 18:28; 使徒行传 28:23"> 腓利就开口，从这段经文开始，向他传讲耶稣。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 10:47; 约翰福音 3:5; 提多书 3:5–6"> 他们沿路前行，来到有水的地方；太监说：“看哪，这里有水。我受洗有什么妨碍呢？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认文本增添：腓利说：“你若全心相信，就可以。”他回答说：“我信耶稣基督是上帝的儿子。”">a</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:1; 约翰福音 3:22–23"> 他吩咐停车；腓利和太监二人都下到水里，腓利就给他施洗。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:12; 列王纪下 2:16; 以西结 8:3"> 他们从水里上来，主的灵把腓利提走了；太监再也看不见他，就欢欢喜喜地继续上路。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 21:8; 使徒行传 23:23; 使徒行传 23:33"> 后来有人发现腓利在亚锁都。他经过各城，一路传福音，直到凯撒利亚。</span>
</div>
</div>

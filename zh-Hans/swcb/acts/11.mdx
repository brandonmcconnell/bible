<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 22:27; 玛拉基书 1:11; 以赛亚书 32:15"> 使徒和在犹太的弟兄们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里以及上下文允许之处，“弟兄”一词也可正确译为“弟兄姊妹”或“同胞”。">a</a></sup>听说外邦人也领受了上帝的道。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:45; 使徒行传 10:9; 使徒行传 15:1"> 彼得上到耶路撒冷的时候，那些奉割礼的人和他争辩，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:28; 加拉太书 2:12; 路加福音 15:2"> 说：“你竟到未受割礼的人那里，和他们一起吃饭！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行传 14:27; 约书亚记 22:21–31"> 彼得就开口，按次序向他们解释说：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 10:9–32; 使徒行传 9:10; 使徒行传 22:17"> “我在约帕城里祷告，出神的时候看见一个异象：有一样器皿降下来，好像一块大布，四角从天上缒下，一直来到我跟前。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行传 3:4"> 我定睛观看，仔细察看，就看见地上的四足牲畜、野兽、爬行动物和天空的飞鸟。</span>
<span className="v" id="v7" data-v="7"> 我又听见有声音对我说：<span className="woj">『起来，彼得，宰了吃！』</span></span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 14:14; 何西阿 9:3; 哥林多前书 7:14"> 但我说：『绝不可，主啊！因为凡俗或不洁净的东西从来没有进过我的口。』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 15:9; 希伯来书 9:13–14; 使徒行传 10:34–35"> 第二次，有声音从天上回答我说：<span className="woj">『上帝所洁净的，你不可称为不洁净。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 21:17; 民数记 24:10; 哥林多后书 12:8"> 这样一连三次，然后一切又都被收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 4:27; 使徒行传 9:10–12; 出埃及记 4:14"> 看哪，就在那时，有三个人站在我所在的房子前，是从凯撒利亚被差来见我的。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:29; 罗马书 3:22; 帖撒罗尼迦后书 2:2"> 圣灵吩咐我和他们同去，不要区别对待。这六位弟兄也同我一起去，我们就进了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:30–32; 使徒行传 10:3–6; 使徒行传 9:43"> 他告诉我们，他怎样看见天使站在他家里，对他说：『你要差人去约帕，请那称为彼得的西门来；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:15; 使徒行传 10:22; 使徒行传 16:31–34"> 他要对你说一些话，你和你全家都将借着这些话得救。』</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 19:6; 使徒行传 10:34–46; 使徒行传 2:2–12"> 我一开始说话，圣灵就降在他们身上，正像起初降在我们身上一样。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 1:5; 马可福音 1:8; 箴言 1:23"> 我就想起主的话，祂怎样说：<span className="woj">『约翰确实是用水施洗，但你们要受圣灵的洗。』</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:47; 罗马书 9:20–26; 但以理 4:35"> 既然上帝把同样的恩赐赐给他们，正如在我们信主耶稣基督时赐给我们一样，我是谁，竟能拦阻上帝呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:12–13; 哥林多后书 7:10; 以西结 36:26"> 他们听见这些话，就不作声了，并归荣耀给上帝，说：“这样看来，上帝也把通向生命的悔改赐给外邦人了！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 4:36; 使徒行传 21:2; 使徒行传 15:3"> 那些因司提反的事而兴起的逼迫四散的人，走到腓尼基、居比路和安提阿；他们不向别人讲这道，只向犹太人讲。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 27:32; 使徒行传 13:1; 哥林多前书 1:23–24"> 但其中有些居比路人和古利奈人来到安提阿，也向希腊化的人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希腊化的人是持守希腊习俗和文化的人。">b</a></sup>传讲主耶稣。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行传 2:47; 使徒行传 5:14"> 主的手与他们同在，许多人信了，并归向主。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:27; 使徒行传 8:14; 使徒行传 13:1–3"> 关于他们的消息传到耶路撒冷教会的耳中；他们就派巴拿巴出去，往安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:58; 使徒行传 14:22; 使徒行传 13:43"> 他到了那里，看见上帝的恩典，就很欢喜；他劝勉众人都要立定心志，恒久倚靠主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 11:21; 使徒行传 5:14; 使徒行传 9:31"> 因为他是一个善良的人，充满圣灵和信心；于是有许多人被加添归主。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 9:11; 使徒行传 9:27; 使徒行传 9:30"> 巴拿巴出去到大数寻找扫罗。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 4:16; 使徒行传 26:28; 彼得前书 4:14"> 找到了，就带他到安提阿。他们足有一年和教会聚集在一起，教导了许多人。门徒被称为基督徒，是从安提阿开始的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 13:1; 哥林多前书 12:28; 以弗所书 4:11"> 在那些日子，有几位先知从耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 21:10; 使徒行传 18:2; 路加福音 3:1"> 其中有一位名叫亚迦布的站起来，借着圣灵指明将有大饥荒遍及全世界；这事在革老丢年间果然发生了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 8:12–14; 加拉太书 2:10; 哥林多后书 8:2–4"> 于是门徒们各人按自己的力量，定意捐款救济住在犹太的弟兄们；</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:23; 使徒行传 12:25; 使徒行传 15:4"> 他们也这样做了，经巴拿巴和扫罗的手，把捐款送到长老们那里。</span>
</div>
</div>

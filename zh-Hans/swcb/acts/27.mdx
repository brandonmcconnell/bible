<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="27" data-verses="44">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 25:25; 使徒行传 25:12; 使徒行传 10:1"> 既然决定要我们坐船往意大利去，他们就把保罗和其他几个囚犯交给奥古斯都营的一位百夫长，名叫犹流。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:29; 腓利门书 1:24; 歌罗西书 4:10"> 我们登上一艘亚大米田的船，这船将要开往亚细亚沿岸各地；于是我们出海，有马其顿的帖撒罗尼迦人亚里达古和我们同去。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 24:23; 使徒行传 28:16; 使徒行传 27:43"> 第二天，我们停靠西顿。犹流善待保罗，准许他到朋友那里去，得到照顾。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 15:39; 使徒行传 13:4"> 从那里出海以后，因为风不顺，我们就贴着塞浦路斯背风的一面航行。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:9; 使徒行传 13:13; 使徒行传 15:41"> 我们横渡基利迦和旁非利亚一带的海面，来到吕基亚的每拉。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 28:11; 使徒行传 27:1; 使徒行传 6:9"> 百夫长在那里找到一艘亚历山大的船，要开往意大利，就让我们上了船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 27:21; 提多书 1:5; 提多书 1:12"> 我们缓慢航行了许多天，好不容易来到革尼土对面；因为风不容许我们继续前行，我们就贴着克里特背风的一面，在撒摩尼对面航行。</span>
<span className="v" id="v8" data-v="8"> 我们艰难地沿岸航行，来到一个叫佳澳的地方，靠近拉西亚城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 29:7; 利未记 23:27–29; 利未记 16:29–31"> 过了很久，航行已经危险，因为禁食节已经过去了，保罗就劝告他们，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理 2:30; 使徒行传 27:20–26; 使徒行传 27:41–44"> 对他们说：“诸位，我看这次航行不但货物和船要受损失、大遭亏损，连我们的性命也会如此。”</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 33:4; 希伯来书 11:7; 以西结 3:17–18"> 但百夫长更听从船长和船主，不听保罗所说的话。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:30; 使徒行传 27:8"> 因为那港口不适合过冬，多数人就建议从那里出海，或者能设法到达腓尼基，在那里过冬；腓尼基是克里特的一个港口，朝向西南和西北。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 约伯记 37:17"> 这时南风轻轻吹起，他们以为目的已经达到，就起锚，贴近克里特沿岸航行。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 4:37; 诗篇 107:25–27; 出埃及记 14:21–27"> 但不久，有一股暴风从岸上猛扑下来，名叫友拉革罗。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：“东北风”。">a</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:4; 使徒行传 27:27"> 船被风抓住，不能迎风前进，我们只好任风刮去，随风漂流。</span>
<span className="v" id="v16" data-v="16"> 我们贴着一个名叫高大的小岛背风处疾驶，才勉强保住小艇。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 27:29; 使徒行传 27:26; 使徒行传 27:41"> 水手把小艇拉上来以后，就用缆索捆绑船身，加以加固；又怕在赛耳底沙洲搁浅，就放下海锚，这样随风漂流。</span>
<span className="v" id="v18" data-v="18" data-xref="约拿 1:5; 使徒行传 27:38; 马太福音 16:26"> 我们被风暴猛烈折腾，第二天他们开始把东西抛到海里。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:4; 路加福音 9:24–25; 马可福音 8:35–37"> 第三天，他们亲手把船上的用具抛掉。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:29; 马太福音 8:24–25; 耶利米书 2:25"> 许多天太阳和星辰都没有显现，又有猛烈的风暴压迫着我们，我们获救的一切希望就都消失了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 诗篇 107:5–6; 使徒行传 27:7"> 众人很久没有进食，保罗就站在他们中间，说：“诸位，你们本该听我的话，不从克里特出航，免得遭受这损伤和亏损。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 27:25; 使徒行传 27:36; 哥林多后书 4:8–9"> 现在我劝你们振作起来，因为你们当中没有一个人会丧命，只是这船要失去。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:11; 罗马书 1:9; 提摩太后书 4:17"> 因为就在今天夜里，我所属、我所事奉的上帝，祂的一位天使站在我旁边，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:11; 提摩太后书 4:16–17; 马太福音 10:28"> 说：‘保罗，不要怕。你必须站在凯撒面前。看哪，上帝已经把所有与你同船航行的人都赐给你了。’</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 4:20–21; 路加福音 1:45; 民数记 23:19"> 所以，诸位，要振作起来！因为我信上帝，事情必定照着对我所说的成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 28:1; 使徒行传 27:17; 使徒行传 27:29"> 只是我们必须在某一个岛上搁浅。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约拿 1:6; 使徒行传 27:30; 启示录 18:17"> 到了第十四夜，我们在亚得里亚海漂来漂去。约在半夜，水手们估计快要靠近某处陆地。</span>
<span className="v" id="v28" data-v="28"> 他们探测水深，发现有二十噚。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十噚＝120英尺＝36.6米">b</a></sup>过了一会儿，他们又探测，发现有十五噚。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十五噚＝90英尺＝27.4米">c</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 27:17; 希伯来书 6:19; 申命记 28:67"> 他们怕我们会在礁石上搁浅，就从船尾抛下四个锚，盼望天亮。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 27:16; 使徒行传 27:32"> 水手们想要逃离船，假装要从船头抛锚，把小艇放下海里。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 2:13–14; 诗篇 91:11–12; 耶利米书 29:11–13"> 保罗对百夫长和士兵说：“这些人若不留在船上，你们就不能获救。”</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比书 3:7–9; 路加福音 16:8"> 于是士兵砍断小艇的绳索，让它漂走。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 天快亮的时候，保罗劝大家都吃点东西，说：“今天是你们等待的第十四天了，你们一直禁食，什么也没有吃。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:30; 列王纪上 1:52; 路加福音 21:18"> 所以我劝你们吃点东西，因为这关系到你们的安全；你们各人头上的一根头发也不会损失。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 15:36; 哥林多前书 10:30–31; 提摩太前书 4:3–4"> 他说完这些话，就拿起饼，在众人面前感谢上帝；然后擘开，开始吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 1:4–6; 使徒行传 27:22; 诗篇 27:14"> 于是众人都振作起来，也吃了东西。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 2:41; 罗马书 13:1; 彼得前书 3:20"> 我们在船上的共有二百七十六人。</span>
<span className="v" id="v38" data-v="38" data-xref="约拿 1:5; 马太福音 6:25; 使徒行传 27:18–19"> 他们吃饱以后，就把麦子抛到海里，使船减轻。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 28:1"> 到了天亮，他们不认得那地方，却看见一个有沙滩的海湾，就决定尽力把船冲到岸上去。</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 33:23; 使徒行传 27:29–30"> 他们砍断锚索，把锚留在海里，同时解开舵绳；又升起前帆，顺着风向沙滩驶去。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多后书 11:25–26; 以西结 27:26; 使徒行传 27:26–29"> 但他们遇到两股海流交汇的地方，就使船搁浅了。船头嵌住，不能动弹，船尾却被浪的猛烈冲击打碎。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马可福音 15:15–20; 传道书 9:3; 诗篇 74:20"> 士兵们的主意是要杀掉囚犯，免得有人游水逃走。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 27:3; 箴言 16:7; 使徒行传 27:11"> 但百夫长想要救保罗，就阻止他们实行这个意图，并吩咐会游泳的人先跳下水，往陆地去；</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 27:22; 诗篇 107:28–30; 约翰福音 6:39–40"> 其余的人，有的靠木板，有的靠船上的其他东西跟着去。这样，众人都平安逃上了陆地。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:6; 腓立比书 2:2; 使徒行传 1:13–15"> 五旬节那一天到了，他们都同心合意聚在一处。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:31; 列王纪上 19:11; 诗篇 18:10"> 忽然，从天上来了一阵响声，好像猛烈的风吹过，充满了他们所坐的整座房子。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 3:11; 约翰福音 1:32–33; 耶利米书 23:29"> 又有像火焰的舌头向他们显现，分散开来，分别停在他们每个人身上。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:17; 使徒行传 13:52; 使徒行传 4:31"> 他们都被圣灵充满，就按着圣灵赐给他们开口说话的能力，开始说起别的语言来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行传 8:2; 歌罗西书 1:23"> 那时，有虔诚的犹太人从天下各国来，住在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 2:3; 哥林多前书 16:9; 使徒行传 2:2"> 这声音一响，众人就聚集过来，感到困惑，因为每个人都听见他们用自己的语言说话。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:12; 使徒行传 1:11; 约翰福音 7:52"> 众人都惊讶诧异，彼此说：“看哪，这些说话的人不都是加利利人吗？</span>
<span className="v" id="v8" data-v="8"> 我们怎么听见他们各人用我们出生地的本地话说话呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:1; 使徒行传 18:2; 启示录 1:4"> 我们有帕提亚人、玛代人、以拦人，以及住在美索不达米亚、犹太、加帕多家、本都、亚细亚、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:6; 撒迦利亚书 8:23; 撒迦利亚书 8:20"> 弗吕家、旁非利亚、埃及的人，并靠近古利奈一带利比亚地方的人，还有从罗马来的访客，包括犹太人和归信犹太教的人，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:10; 出埃及记 15:11; 诗篇 78:4"> 克里特人和阿拉伯人——我们都听见他们用我们的语言讲说上帝的大作为！”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行传 17:20; 路加福音 18:36"> 众人都惊讶困惑，彼此说：“这是什么意思呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:23; 使徒行传 2:15; 撒母耳记上 1:14"> 另有些人讥笑说：“他们是喝足了新酒。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 51:7; 以赛亚书 51:1; 申命记 27:9"> 彼得和那十一个使徒站起来，高声对众人说：“犹太人和所有住在耶路撒冷的人哪，这件事你们当知道，也要留心听我的话。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:5–8; 撒母耳记上 1:15; 马太福音 20:3"> 这些人并不像你们所想的是醉了，因为现在不过是一天的第三小时。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约上午九点。">a</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="约珥 2:28–32"> 这正是借着先知约珥所说的：</span>
<span className="v" id="v17" data-v="17" data-xref="约珥 2:28–32; 以赛亚书 44:3; 提多书 3:4–6"> <span className="pl pl-1">『上帝说：在末后的日子，</span><br /><span className="pl pl-2">我要把我的灵浇灌在所有血肉之人身上。</span><br /><span className="pl pl-1">你们的儿子和女儿要说预言；</span><br /><span className="pl pl-2">你们的年轻人要见异象；</span><br /><span className="pl pl-2">你们的老人要做异梦。</span></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:28; 歌罗西书 3:11; 哥林多前书 7:21–22"> <span className="pl pl-1">是的，在那些日子，</span><br /><span className="pl pl-2">我要把我的灵浇灌在我的男仆和女仆身上，他们就要说预言。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约珥 2:30–31; 西番雅书 1:14–18; 玛拉基书 4:1–6"> <span className="pl pl-1">我要在上面的天上显出奇事，</span><br /><span className="pl pl-2">在下面的地上显出神迹：</span><br /><span className="pl pl-2">有血，有火，有烟雾。</span></span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:10; 阿摩司 8:9; 马太福音 24:29"> <span className="pl pl-1">太阳要变为黑暗，</span><br /><span className="pl pl-2">月亮要变为血，</span><br /><span className="pl pl-2">这都在主伟大而荣耀的日子来到以前。</span></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 10:12–13; 约珥 2:32; 诗篇 86:5"> <span className="pl pl-1">到那时，凡求告主名的，都必得救。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 3:2; 约翰福音 14:10–11; 马太福音 12:28"> “以色列人哪，请听这些话！拿撒勒人耶稣，就是上帝借着祂在你们中间所行的异能、奇事和神迹，向你们证明的人，正如你们自己所知道的，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行传 4:28; 使徒行传 3:18"> 祂既按着上帝既定的旨意和预知被交出，你们就借着不法之人的手，把祂钉在十字架上杀了；</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 6:14; 彼得前书 1:21; 使徒行传 2:32"> 上帝却使祂复活，解除了死亡的痛苦，因为祂不可能被死亡拘禁。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 16:8–11; 以赛亚书 41:13; 诗篇 62:6"> 大卫论到祂说：<br /><span className="pl pl-1">『我常看见主在我面前，</span><br /><span className="pl pl-2">因为祂在我右边，使我不至动摇。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 16:9; 诗篇 63:5; 诗篇 71:23"> <span className="pl pl-1">因此，我的心欢喜，我的舌头快乐；</span><br /><span className="pl pl-2">并且我的肉身也要安居在盼望中，</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:10; 使徒行传 2:31; 启示录 1:18"> <span className="pl pl-1">因为你必不把我的灵魂撇在阴间，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：地狱。">b</a></sup><br /><span className="pl pl-2">也不容你的圣者见朽坏。</span></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 16:11; 诗篇 25:4; 诗篇 21:6"> <span className="pl pl-1">你已经把生命的道路指示我；</span><br /><span className="pl pl-2">你必以你的同在使我满有喜乐。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 13:36; 列王纪上 2:10; 使徒行传 7:8–9"> “弟兄们，论到先祖大卫，我可以坦率地对你们说：他死了，也埋葬了，他的坟墓直到今日还在我们这里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 132:11–18; 诗篇 89:3–4; 耶利米书 33:14–15"> 所以，他既是先知，又知道上帝曾向他起誓，要从他的后裔中，按肉身兴起基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“基督”的意思是“受膏者”。">c</a></sup>坐在他的宝座上，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 2:27; 诗篇 16:10; 使徒行传 13:35"> 他预先看见这事，就论到基督的复活说：祂的灵魂没有被撇在阴间，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：地狱。">d</a></sup>祂的肉身也没有见朽坏。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 3:15; 使徒行传 1:8; 使徒行传 1:22"> 这位耶稣，上帝已经使祂复活，我们都是这事的见证人。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:4; 使徒行传 5:31; 使徒行传 2:17"> 祂既被高举到上帝的右边，又从父领受了所应许的圣灵，就把你们现在所看见、所听见的这事浇灌下来。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 110:1; 马太福音 22:42–45; 希伯来书 1:13"> 大卫并没有升到诸天之上，但他自己说：<br /><span className="pl pl-1">『主对我主说：“坐在我的右边，</span></span>
<span className="v" id="v35" data-v="35" data-xref="启示录 19:19–3; 罗马书 16:20; 以赛亚书 60:14"> <span className="pl pl-2">等我使你的仇敌作你的脚凳。”』</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 5:30–31; 罗马书 14:8–12; 哥林多后书 5:10"> “所以，以色列全家都应当确实知道：上帝已经立祂为主、为基督了；这祂，就是你们所钉十字架的耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行传 22:10; 希伯来书 4:12–13"> 众人听见这话，觉得扎心，就对彼得和其余的使徒说：“弟兄们，我们该做什么？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:16; 马可福音 16:16; 使徒行传 8:12"> 彼得对他们说：“你们每个人都要悔改，奉耶稣基督的名受洗，使罪得赦；你们就必领受圣灵的恩赐。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 44:3; 创世记 17:7–8; 罗马书 8:30"> 因为这应许是给你们和你们的儿女，也给所有在远方的人，就是凡主我们的上帝所召归自己的人。”</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:15; 申命记 32:5; 马太福音 17:17"> 彼得还用许多别的话作见证，劝勉他们说：“你们要救自己脱离这弯曲的世代！”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 4:4; 使徒行传 2:47; 使徒行传 16:31–34"> 于是，欣然领受他话的人都受了洗。那一天，约有三千人被加添。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 10:25; 使徒行传 1:14; 约翰一书 1:3"> 他们恒心持守使徒的教导和团契，擘饼和祷告。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 约翰福音 14:12; 路加福音 8:37"> 众人都心生敬畏，又有许多奇事和神迹借着使徒行出来。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 4:32; 约翰一书 3:16–18; 哥林多后书 8:14–15"> 所有信的人都在一起，凡物公用。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰一书 3:17; 提摩太前书 6:18–19; 雅各书 2:14–16"> 他们卖了自己的产业和财物，照各人所需要的分给众人。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 5:42; 使徒行传 20:7; 使徒行传 2:42"> 他们天天同心合意地恒切聚集在圣殿里，又在家中擘饼，存着欢喜和单纯的心用饭，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 16:5; 使徒行传 5:13–14; 使徒行传 2:41"> 赞美上帝，得众民的喜爱。主将得救的人天天加给教会。</span>
</div>
</div>

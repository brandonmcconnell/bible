<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 8:3; 提摩太前书 1:13; 加拉太书 1:13"> 扫罗仍然向主的门徒喷吐威吓和杀害的话，就去见大祭司，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:9; 使徒行传 19:23; 使徒行传 24:14"> 向他求文书，带到大马士革的各会堂，好让他若发现任何属于这道的人，无论男女，都可以捆绑起来带到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:12–13; 哥林多前书 15:8; 使徒行传 22:6"> 他行路将近大马士革的时候，忽然有光从天上四面照着他。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 2:8; 创世记 22:11; 罗马书 11:22"> 他就倒在地上，听见有声音对他说：<span className="woj">“扫罗！扫罗！你为什么逼迫我？”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 1:13; 撒母耳记上 3:4–10; 约伯记 9:4"> 他说：“主啊，你是谁？”<br />主说：<span className="woj">“我就是你所逼迫的耶稣。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加上：“你用脚踢刺棒是难的。”">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 22:10; 使徒行传 26:16; 提摩太前书 1:14–16"> <span className="woj">但</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 省略“但”。">b</a></sup><span className="woj">起来，进城去，你必须做的事，必有人告诉你。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 22:9; 但以理 10:7; 使徒行传 26:13–14"> 与他同行的人站在那里，说不出话来；他们听见声音，却看不见任何人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 22:11; 使徒行传 9:18; 列王纪下 6:17–20"> 扫罗从地上起来，眼睛虽然睁开，却什么也看不见。众人牵着他的手，把他带进大马士革。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿 3:6–8; 以斯帖记 4:16; 历代志下 33:12–13"> 他三天不能看见，也不吃也不喝。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 22:1; 使徒行传 10:3; 使徒行传 22:12"> 在大马士革有一个门徒，名叫亚拿尼亚。主在异象中对他说：<span className="woj">“亚拿尼亚！”</span><br />他说：“看哪，是我，主啊。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:39; 使徒行传 22:3; 使徒行传 9:30"> 主对他说：<span className="woj">“起来，到那条叫直街的街上去，在犹大</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：犹达。">c</a></sup><span className="woj">家里询问一个名叫扫罗的大数人。看哪，他正在祷告，</span></span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 5:23; 使徒行传 9:10; 使徒行传 9:17–18"> <span className="woj">并且在异象中看见一个名叫亚拿尼亚的人进来，按手在他身上，使他能恢复视力。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 1:13–15; 使徒行传 8:3; 使徒行传 22:19–20"> 亚拿尼亚却回答说：“主啊，我听许多人说过这个人，说他在耶路撒冷怎样多多加害于你的圣徒。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:21; 使徒行传 7:59; 提摩太后书 2:22"> 他在这里也有祭司长们给他的权柄，要捆绑所有求告你名的人。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:15–16; 以弗所书 3:7–8; 提摩太后书 4:16–17"> 但主对他说：<span className="woj">“你去吧，因为他是我所拣选的器皿，要在列国、君王和以色列子孙面前承载我的名。</span></span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 3:3; 使徒行传 21:11; 哥林多后书 6:4"> <span className="woj">我要指示他，为我的名必须受多少苦。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 8:17; 使徒行传 6:6; 使徒行传 2:4"> 亚拿尼亚就去了，进入那家。他按手在扫罗身上，说：“扫罗弟兄，在你来的路上向你显现的主，就是耶稣，差我来，使你可以恢复视力，并且被圣灵充满。”</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 3:14; 使徒行传 22:16; 使徒行传 2:38"> 立刻，有像鳞片一样的东西从他眼睛上掉下来，他就恢复了视力。他起来受了洗，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:20; 撒母耳记上 30:12; 加拉太书 1:17"> 吃过饭，就有了力量。<br />扫罗和在大马士革的门徒同住了几天。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 20:28; 加拉太书 2:20; 约翰一书 4:14–15"> 他立刻在各会堂里宣讲基督，说他是上帝的儿子。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:13–14; 使徒行传 8:3; 帖撒罗尼迦后书 1:10"> 所有听见的人都惊奇，说：“这不就是在耶路撒冷残害那些求告这名的人吗？他到这里来，不正是为了把他们捆绑起来，带到祭司长们面前吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 18:5; 以赛亚书 40:29; 路加福音 21:15"> 但扫罗越发有力量，使住在大马士革的犹太人困惑不解，证明这位就是基督。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:17–18; 帖撒罗尼迦前书 2:15–16; 使徒行传 14:19"> 过了许多日子，犹太人一同密谋要杀他，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 11:32; 使徒行传 25:3; 使徒行传 20:3"> 但他们的阴谋被扫罗知道了。他们昼夜守着城门，要杀他；</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 2:15; 哥林多后书 11:33; 撒母耳记上 19:11–12"> 但他的门徒夜间带着他，把他装在筐子里，从城墙上缒下去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:20; 加拉太书 1:17–19; 使徒行传 9:19"> 扫罗到了耶路撒冷，想要与门徒结交；但他们都怕他，不相信他是门徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:36; 使徒行传 4:29; 使徒行传 4:13"> 只有巴拿巴接待他，带他去见使徒，向他们述说扫罗怎样在路上看见了主，主怎样对他说话，以及他在大马士革怎样奉耶稣的名放胆传讲。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 1:21; 民数记 27:16–17; 诗篇 121:8"> 他就和他们一同进入<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="TR 和 NU 加上“又出去”。">d</a></sup>耶路撒冷，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 6:1; 犹大书 1:9; 使徒行传 11:20"> 奉主耶稣的名放胆传讲。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="TR 和 NU 省略“耶稣”，并将第28节和第29节的顺序颠倒。">e</a></sup>他与希腊化犹太人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="希腊化犹太人是使用希腊语言和文化的希伯来人。">f</a></sup>说话辩论，他们却想要杀他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 11:25; 使徒行传 8:40; 使徒行传 9:11"> 弟兄们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这里译为“弟兄们”的词，在上下文允许的地方，也可以正确译为“弟兄姊妹们”或“手足”。">g</a></sup>知道了，就带他下到凯撒利亚，送他往大数去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 111:10; 约翰福音 14:16–18; 以赛亚书 33:6"> 于是，犹太全地、加利利和撒马利亚的各教会得平安，并且被建立；她们敬畏主，蒙圣灵安慰，人数不断增多。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:13; 使徒行传 8:25; 箴言 2:8"> 彼得走遍各处的时候，也下到住在吕大的圣徒那里。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 约翰福音 5:5; 马可福音 2:3–11"> 在那里，他遇见一个人，名叫以尼雅，已经瘫痪，在床上躺了八年。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:6; 使徒行传 3:12; 使徒行传 3:6"> 彼得对他说：“以尼雅，耶稣基督医治你。起来，整理你的床！”他立刻起来了。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 11:21; 使徒行传 9:42; 历代志上 5:16"> 所有住在吕大和沙仑的人都看见了他，就归向主。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多书 3:8; 提多书 2:7; 历代志下 2:16"> 在约帕有一个女门徒，名叫大比大，翻译出来就是多加。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="“多加”是希腊语，意思是“羚羊”。">h</a></sup>这个妇人满有善行，并且常行怜悯的事。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 1:13; 使徒行传 20:8; 约翰福音 11:36–37"> 那些日子，她病了，死了。众人给她洗过身体，就把她安放在楼上的房间里。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:36; 使徒行传 11:26; 使徒行传 9:32"> 吕大靠近约帕，门徒听说彼得在那里，就差两个男人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="依照 NU、TR；MT 省略“两个男人”。">i</a></sup>去见他，恳求他不要耽延，快到他们那里去。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒罗尼迦前书 1:3"> 彼得就起来，和他们同去。他到了以后，众人领他上楼上的房间。所有寡妇都站在彼得旁边哭泣，给他看多加和她们在一起时所做的内衣和其他衣服。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:25; 马可福音 5:40–42; 路加福音 8:54"> 彼得叫她们都出去，就跪下祷告。他转向那身体，说：“大比大，起来！”她睁开眼睛，看见彼得，就坐了起来。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 使徒行传 6:1; 创世记 45:26"> 彼得伸手扶她起来，又叫圣徒和寡妇进来，把她活活地呈现在他们面前。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:44; 约翰福音 12:11; 约翰福音 11:45"> 这事传遍了约帕，许多人就信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:6; 使徒行传 10:32"> 彼得在约帕住了许多日子，与一个名叫西门的制革匠同住。</span>
</div>
</div>

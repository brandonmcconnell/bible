<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 1:2; 提摩太后书 4:20; 哥林多后书 1:1"> 这些事以后，保罗离开雅典，来到哥林多。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 16:3–4; 哥林多前书 16:19; 提摩太后书 4:19"> 他遇见一个犹太人，名叫亚居拉，本都人，最近和妻子百基拉从意大利来，因为革老丢曾命令所有犹太人离开罗马。保罗就去找他们；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 4:12; 帖撒罗尼迦前书 2:9; 哥林多后书 11:9"> 因为他和他们同业，就和他们住在一起做工；他们的行业是制造帐棚。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:11; 使徒行传 17:17; 使徒行传 28:23"> 每逢安息日，他在会堂里辩论，劝导犹太人和希腊人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14; 使徒行传 18:28; 使徒行传 20:21"> 西拉和提摩太从马其顿下来以后，保罗被圣灵催促，向犹太人作见证，证明耶稣就是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 33:4; 撒母耳记下 1:16; 以西结 33:8–9"> 他们抵挡他，并说亵渎的话，保罗就抖了抖衣服，对他们说：“你们的血归到你们自己的头上！我清白无辜。从今以后，我要到外邦人那里去！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:14; 歌罗西书 4:11; 使徒行传 10:2"> 他离开那里，进了一个人的家；那人名叫犹士都，是敬拜上帝的人，他的家紧挨着会堂。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 1:13–17; 罗马书 10:14–17; 马可福音 16:15–16"> 管会堂的基利司布和全家都信了主。许多哥林多人听了，就信而受洗。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 23:11; 以弗所书 6:19–20; 使徒行传 27:23–25"> 夜间，主在异象中对保罗说：<span className="woj">“不要害怕，只管讲，不要闭口；</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 出埃及记 4:12; 以赛亚书 41:10"> <span className="woj">因为我与你同在，没有人会攻击你、伤害你，因为在这城里我有许多子民。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 14:3; 使徒行传 19:10; 使徒行传 20:31"> 保罗在那里住了一年零六个月，在他们中间教导上帝的道。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 13:50; 使徒行传 18:27; 使徒行传 13:7"> 迦流作亚该亚总督的时候，犹太人同心起来攻击保罗，把他带到审判台前，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:8; 使徒行传 24:5–6; 使徒行传 6:13"> 说：“这个人劝人违背律法去敬拜上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:14–15; 使徒行传 25:11; 马可福音 9:19"> 保罗正要开口，迦流就对犹太人说：“你们犹太人哪，如果真是关于不法之事或邪恶罪行，我受理你们才算合理；</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:29; 使徒行传 25:19; 提摩太前书 6:4"> 但如果是关于言词、名目和你们自己律法的问题，你们自己处理吧；因为我不愿作这些事的审判官。”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 12:16; 诗篇 76:10; 罗马书 13:3–4"> 于是他把他们从审判台前赶出去。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:1; 阿摩司 6:6; 使徒行传 17:32"> 众希腊人就抓住管会堂的所提尼，在审判台前打他。迦流对这些事毫不在意。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:18; 民数记 6:5–9"> 此后，保罗又住了许多日，就辞别弟兄们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里以及上下文允许之处，译作“弟兄”的词也可正确译为“弟兄姊妹”或“手足”。">a</a></sup>，从那里坐船往叙利亚去；百基拉和亚居拉也同他一起去。他在坚革哩剃了头，因为他许过愿。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:1; 提摩太前书 1:3; 提摩太后书 1:18"> 他来到以弗所，把他们留在那里；他自己却进了会堂，和犹太人辩论。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:37–38; 哥林多前书 16:12; 使徒行传 20:16"> 他们请他多住些时候，他没有同意；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 4:19; 雅各书 4:15; 罗马书 15:32"> 他辞别他们，说：“无论如何，我必须在耶路撒冷守这将到的节期；但如果上帝愿意，我还要回到你们这里来。”于是他从以弗所开船离去。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 8:40; 使徒行传 15:4; 使徒行传 23:23"> 他在凯撒利亚上岸后，就上去问候了教会，又下到安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 14:22; 使徒行传 16:6; 使徒行传 15:41"> 在那里住了一些时候以后，他就离开，按次序走遍加拉太和弗吕家地区，坚固众门徒。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 4:6; 提多书 3:13; 哥林多前书 3:5–6"> 有一个犹太人，名叫亚波罗，按出身是亚历山大人，很有口才，来到以弗所。他在圣经上很有能力。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 19:3; 罗马书 12:11; 何西阿 14:9"> 这人受过主的道路的教导；他灵里火热，准确地讲论并教导关于耶稣的事，不过他只知道约翰的洗礼。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:25; 使徒行传 14:3; 哥林多前书 12:21"> 他开始在会堂里放胆讲论。百基拉和亚居拉听见，就把他带到一旁，把上帝的道路更准确地向他讲解。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:13–14; 雅各书 1:16–18; 彼得前书 1:2–3"> 他想要渡海到亚该亚去，弟兄们就鼓励他，并写信给门徒，请他们接待他。他到了以后，对那些因恩典而信的人帮助很大；</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 18:5; 哥林多前书 15:3–4; 使徒行传 9:22"> 因为他有力地驳倒犹太人，当众用圣经证明耶稣就是基督。</span>
</div>
</div>

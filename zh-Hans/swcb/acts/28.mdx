<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:26; 使徒行传 27:44; 使徒行传 27:39"> 我们脱险以后，他们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU作“我们”">a</a></sup>才知道那岛名叫马耳他。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:14; 希伯来书 13:2; 歌罗西书 3:11"> 当地人向我们显出非同寻常的善意；因为当时下着雨，天气又冷，他们就生火接待我们众人。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 23:33; 马太福音 12:34; 使徒行传 28:4"> 保罗拾起一捆柴，放在火上，有一条毒蛇因热出来，咬住他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 约翰福音 7:24"> 当地人看见那蛇悬在他手上，就彼此说：“这个人无疑是个杀人犯，虽然从海里逃脱了，正义仍不容他活着。”</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 马可福音 16:18; 诗篇 91:13"> 然而保罗把那蛇甩进火里，并没有受伤。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:22; 使徒行传 14:11–13; 马太福音 21:9"> 他们本来预料他会肿起来，或是忽然倒下死去；可是他们等了很久，看见他没有遭遇什么坏事，就改变了看法，说他是一位神明。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40–41; 路加福音 19:6–9; 使徒行传 28:2"> 那地方附近有田产，属于岛上的首领，名叫部百流；他接待我们，殷勤款待我们三天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:40; 马可福音 6:5; 雅各书 5:14–16"> 部百流的父亲患热病和痢疾，卧床不起。保罗进去到他那里，祷告，按手在他身上，医好了他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 5:12; 马可福音 6:54–56; 使徒行传 5:15"> 这事以后，岛上其余有病的人也都来，并且得了医治。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:6; 腓立比书 4:11–12; 马太福音 6:31–34"> 他们也多方尊敬我们；等我们开船的时候，他们把我们所需要的东西装上船。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 27:6; 哥林多前书 8:4; 以赛亚书 45:20"> 三个月以后，我们乘一艘在岛上过冬的亚历山大船起航，船首像是“双子兄弟”。</span>
<span className="v" id="v12" data-v="12"> 我们停靠叙拉古，在那里住了三天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 27:13"> 从那里绕行，来到利基翁。过了一天，南风吹起，第二天我们到了部丢利；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:4; 使徒行传 20:6; 使徒行传 19:1"> 在那里我们遇见弟兄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里以及上下文允许之处，“弟兄”一词也可正确译为“弟兄姊妹”或“手足”。">b</a></sup>，他们恳请我们同他们住七天。这样，我们来到了罗马。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:3; 罗马书 15:24; 出埃及记 4:14"> 那里的弟兄们听见我们的消息，就出来迎接我们，远至亚比乌市场和三馆。保罗看见他们，就感谢上帝，壮起胆来。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 27:3; 使徒行传 24:23; 使徒行传 28:30–31"> 我们进了罗马，百夫长把囚犯交给护卫长；但保罗蒙准独自居住，只有一个士兵看守他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:8; 使徒行传 6:14; 使徒行传 25:10"> 过了三天，保罗召集犹太人的首领。他们聚集以后，保罗对他们说：“弟兄们，我虽然没有做过什么事违背本国的百姓或我们祖宗的习俗，却仍然从耶路撒冷被当作囚犯交在罗马人手里。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:31–32; 使徒行传 23:29; 使徒行传 22:24–25"> 他们审问了我，本想释放我，因为我身上没有该死的罪。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:32; 使徒行传 25:21; 使徒行传 25:10–12"> 但犹太人反对，我不得不上诉于凯撒；并不是我有什么事要控告我的本族。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 提摩太后书 2:9; 使徒行传 26:6–7"> 因此，我请你们来见面并与你们说话；因为我是为以色列的盼望被这条锁链捆绑。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 54:17; 以赛亚书 41:11; 以赛亚书 50:8"> 他们对他说：“我们并没有收到从犹太来论到你的信，也没有弟兄到这里来报告或说你什么坏话。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:12; 使徒行传 24:14; 彼得前书 3:16"> 但我们愿意听听你的想法；因为关于这个派别，我们知道它到处都受人反对。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 17:2–3; 使徒行传 19:8; 使徒行传 18:28"> 他们同保罗约定了日子，就有更多人到他的住处来。他从早到晚向他们讲解，为上帝的国作见证，并从摩西的律法和先知书劝说他们关于耶稣的事。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 14:4; 使徒行传 17:4–5; 使徒行传 19:8–9"> 有些人信了所说的话，有些人却不信。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:7; 彼得后书 1:21; 马可福音 7:6"> 他们彼此意见不合，就离去了；临走以前，保罗说了一句话：“圣灵借着以赛亚先知对我们的祖先说得对，</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 6:9–10; 以西结 12:2; 以赛亚书 42:19–20"> 说：<br /><span className="pl pl-1">『你去对这百姓说：</span><br /><span className="pl pl-1">你们听是要听见，</span><br /><span className="pl pl-2">却决不能明白；</span><br /><span className="pl pl-1">看是要看见，</span><br /><span className="pl pl-2">却决不能领悟。</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 6:10"> <span className="pl pl-1">因为这百姓的心已经变得麻木，</span><br /><span className="pl pl-2">他们的耳朵听觉迟钝，</span><br /><span className="pl pl-2">他们闭上了眼睛；</span><br /><span className="pl pl-1">免得他们眼睛看见，</span><br /><span className="pl pl-2">耳朵听见，</span><br /><span className="pl pl-2">心里明白，</span><br /><span className="pl pl-2">回转过来，</span><br /><span className="pl pl-2">我就医治他们。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行传 26:17–18; 罗马书 3:29–30"> 所以你们当知道，上帝的救恩已经传给外邦人，他们也必听从。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 他说了这些话以后，犹太人就离去了，彼此大大争论。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU省略第29节。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 保罗在自己租的房子里住了整整两年，接待所有来见他的人，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 4:29; 以弗所书 6:19–20; 马太福音 4:23"> 放胆传讲上帝的国，教导有关主耶稣基督的事，没有人禁止。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:16; 提摩太后书 1:3; 哥林多后书 1:12"> 保罗定睛看着公议会，说：“弟兄们，我在上帝面前行事为人，凭着完全无亏的良心，直到今天。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 18:22; 使徒行传 24:1; 弥迦书 5:1"> 大祭司亚拿尼亚吩咐站在保罗旁边的人打他的嘴。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 25:1–2; 约翰福音 7:51; 马太福音 23:27–28"> 保罗就对他说：“你这粉饰的墙，上帝要打你！你坐着按律法审判我，却违背律法吩咐人打我吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 站在旁边的人说：“你竟辱骂上帝的大祭司吗？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:28; 传道书 10:20; 犹大书 1:8–9"> 保罗说：“弟兄们，我不知道他是大祭司；因为经上记着：‘不可毁谤你百姓的官长。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:15; 使徒行传 24:21; 使徒行传 26:5–8"> 保罗看出其中一部分是撒都该人，另一部分是法利赛人，就在公议会中喊着说：“诸位弟兄，我是法利赛人，是法利赛人的儿子。我是为了死人复活的盼望而受审判！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 55:9; 约翰福音 7:40–43; 马太福音 10:34"> 他说了这话，法利赛人和撒都该人之间就起了争论，会众也分裂了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 马太福音 22:23; 马可福音 12:18"> 因为撒都该人说没有复活，也没有天使或灵；法利赛人却都承认这些。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 22:7; 使徒行传 22:17–18; 约翰福音 12:29"> 于是大大喧嚷起来，有几个法利赛派的文士站起来争辩说：“我们看不出这个人有什么恶。如果有灵或天使对他说过话，我们就不要与上帝争战！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:19; 雅各书 3:14–2; 使徒行传 22:24"> 争论越发激烈，千夫长恐怕保罗被他们撕碎，就命令士兵下去，把他从他们中间强行带走，带进营楼。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 18:9; 使徒行传 19:21; 提摩太后书 4:17"> 当夜，主站在保罗旁边，说：<span className="woj">“要壮胆，保罗；你怎样在耶路撒冷为我作见证，也必须照样在罗马作见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 23:30; 以赛亚书 8:9–10; 使徒行传 23:21"> 到了天亮，有些犹太人结成同盟，起誓咒诅自己，说若不先杀了保罗，就不吃不喝。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 16:2; 撒母耳记下 15:31; 撒母耳记下 15:12"> 参与这阴谋的，有四十多人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 23:12; 耶利米书 8:12; 以赛亚书 3:9"> 他们来到祭司长和长老那里，说：“我们已经起了重誓，咒诅自己，若不先杀了保罗，就什么也不尝。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7; 诗篇 37:32–33; 箴言 1:16"> 现在，请你们和公议会通知千夫长，要他明天把保罗带下来到你们这里，好像你们要更详细审问他的案情；我们已经预备好了，在他还未走近以前就杀他。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:10; 哥林多前书 3:19; 使徒行传 23:32"> 但保罗姐妹的儿子听见他们设下埋伏，就来进了营楼，告诉保罗。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 马太福音 8:8–9; 马太福音 10:16"> 保罗叫来一个百夫长，说：“把这个青年带到千夫长那里去，因为他有事要告诉他。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 3:1; 以弗所书 4:1; 使徒行传 28:17"> 于是百夫长带着他到千夫长那里，说：“囚犯保罗叫我来，请我把这个青年带到你这里；他有事要告诉你。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 31:32; 以斯帖记 9:12; 以斯帖记 7:2"> 千夫长拉着他的手，走到一旁，私下问他说：“你有什么事要告诉我？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 23:14–15; 使徒行传 23:1; 诗篇 12:2"> 他说：“犹太人已经约定，要请你明天把保罗带下去到公议会，好像要更准确地查问他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:12–14; 使徒行传 14:5–6; 哥林多后书 11:26"> 所以你不要答应他们；因为他们中间有四十多人埋伏等着他，已经起誓咒诅自己，若不先杀了他，就不吃不喝。现在他们已经预备好了，只等你答应。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 1:44; 约书亚记 2:14"> 于是千夫长让那青年走，嘱咐他说：“不要告诉任何人你已经把这些事向我透露了。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:25; 使徒行传 23:33; 路加福音 12:38"> 千夫长叫了两个百夫长来，说：“预备二百名士兵、七十名骑兵和二百名持矛兵，在夜间第三时出发，前往凯撒利亚。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约晚上九点。">a</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 25:14; 使徒行传 23:26; 使徒行传 24:10"> 又要他们预备坐骑，让保罗骑上，安全送到总督腓力斯那里。</span>
<span className="v" id="v25" data-v="25"> 他写了一封信，内容如下：</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:23; 使徒行传 26:25; 路加福音 1:3"> “革老丢·吕西亚，致最尊贵的总督腓力斯阁下：问安。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 22:25–29; 使徒行传 21:31–33; 使徒行传 24:6"> “这个人被犹太人抓住，快要被他们杀害；我得知他是罗马人，就带着士兵赶到，救了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 22:30"> 我想知道他们控告他的原因，就把他带下去到他们的公议会。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 26:31; 使徒行传 25:25; 使徒行传 18:15"> 我发现他受控告，是关于他们律法的问题，却没有任何该死或该囚禁的罪名。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:35; 使徒行传 25:16; 使徒行传 25:5–6"> 后来有人告诉我，犹太人要埋伏害这个人，我就立刻把他送到你这里，同时也吩咐控告他的人到你面前告他。愿你平安。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 2:3–4; 路加福音 7:8; 使徒行传 23:23–24"> 于是士兵照着所受的命令，夜里带着保罗，把他送到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:23; 使徒行传 23:10"> 第二天，他们让骑兵护送保罗，自己回营楼去了。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 23:26; 使徒行传 23:23–24; 使徒行传 28:16"> 骑兵来到凯撒利亚，把信交给总督，也把保罗呈到他面前。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 21:39; 使徒行传 25:1; 但以理 2:49"> 总督读了信，就问保罗是哪一省的人；知道他是基利家人后，就说：</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 23:30; 使徒行传 25:16; 马太福音 27:27"> “等控告你的人也到了，我要详细听你的案。”他命令把保罗看守在希律的宫殿里。</span>
</div>
</div>

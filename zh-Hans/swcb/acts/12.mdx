<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:9; 约翰福音 15:20; 马太福音 10:17–18"> 那时，希律王下手苦害教会中的一些人。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:37; 马太福音 20:23; 马太福音 4:21–22"> 他用刀杀了约翰的兄弟雅各。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:15; 约翰福音 12:43; 使徒行传 24:27"> 他见这事使犹太人高兴，就又去捉拿彼得。那时正是除酵节的日子。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 19:21; 路加福音 22:33; 路加福音 21:12"> 希律逮捕了彼得，把他关进监狱，交给四班兵丁看守，每班四人，打算在逾越节后把他提出来交给百姓。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 帖撒罗尼迦前书 5:17; 雅各书 5:16"> 于是彼得被关在监狱里；教会却为他向上帝切切祷告。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 21:33; 希伯来书 13:6; 腓立比书 4:6–7"> 希律将要把彼得提出来的前一夜，彼得睡在两个士兵中间，被两条锁链捆着，门前也有守卫看守监牢。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:19; 使徒行传 16:26; 诗篇 146:7"> 看哪，主的一位天使站在他旁边，牢房里有光照耀。天使拍彼得的肋旁，叫醒他，说：“快起来！”他的锁链就从手上脱落。</span>
<span className="v" id="v8" data-v="8"> 天使对他说：“穿好衣服，穿上鞋。”彼得就照做了。天使又对他说：“披上外衣，跟我来。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:1; 希伯来书 11:8; 创世记 45:26"> 彼得就出来跟着他。他不知道天使所做的是真实的，还以为自己看见了异象。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:19; 使徒行传 16:26; 以赛亚书 45:1–2"> 他们经过第一道和第二道守卫，来到通往城里的铁门；门自动为他们打开。他们出去，走过一条街，天使立刻离开了他。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理 6:22; 但以理 3:28; 彼得后书 2:9"> 彼得清醒过来，说：“现在我确实知道，主差遣了祂的天使，救我脱离希律的手，也脱离犹太百姓所期待的一切。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 使徒行传 12:5; 马太福音 18:19–20"> 他想明白这事，就来到马利亚的家；她是那称为马可的约翰的母亲。那里有许多人聚集在一起祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:16; 路加福音 13:25; 约翰福音 18:16–17"> 彼得敲院门的时候，一个名叫罗大的使女前来应门。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:41; 马太福音 28:8"> 她认出是彼得的声音，因为欢喜，没有开门，反而跑进去报告说彼得站在门前。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:10; 路加福音 24:11; 马可福音 16:14"> 他们对她说：“你疯了！”她却坚持说确是这样。他们说：“那是他的天使。”</span>
<span className="v" id="v16" data-v="16"> 彼得继续敲门。他们开了门，看见他，就很惊奇。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 21:40; 使徒行传 13:16; 使徒行传 19:33"> 彼得摆手示意他们安静，然后向他们说明主怎样把他从监狱里带出来。他说：“把这些事告诉雅各和弟兄们。”随后他离开，往别处去了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:22–25; 使徒行传 16:27; 使徒行传 19:23"> 天一亮，士兵中间起了不小的骚动，不知道彼得到底出了什么事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:27; 诗篇 37:32–33; 约翰福音 12:10–11"> 希律搜寻他，却找不到，就审问守卫，吩咐把他们处死。后来希律从犹太下到凯撒利亚，住在那里。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 3:7; 马太福音 11:21–22; 以西结 27:17"> 希律对推罗和西顿的人十分恼怒。他们同心来到他那里，先拉拢了王的侍从布拉斯都，请求和好，因为他们的地区靠王的地区供给粮食。</span>
<span className="v" id="v21" data-v="21"> 到了指定的日子，希律穿上王服，坐在宝座上，向他们发表讲话。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 14:10–13; 启示录 13:4; 犹大书 1:16"> 民众喊着说：“这是神明的声音，不是人的声音！”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 115:1; 使徒行传 10:25–26; 帖撒罗尼迦后书 2:4"> 主的一位天使立刻击打他，因为他没有把荣耀归给上帝。随后他被虫子咬噬，就死了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 6:7; 使徒行传 19:20; 帖撒罗尼迦后书 3:1"> 上帝的道却兴旺起来，越发广传。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 12:12; 彼得前书 5:13; 使徒行传 15:37"> 巴拿巴和扫罗完成了他们的服侍，就到<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 作“从”，而非“到”">a</a></sup>耶路撒冷去，也带着那称为马可的约翰同行。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 箴言 1:24; 使徒行传 26:2"> 亚基帕对保罗说：“准许你为自己申辩。”<br />于是保罗伸出手来，开始申辩：</span>
<span className="v" id="v2" data-v="2"> “亚基帕王啊，关于犹太人控告我的一切事，我今天能在你面前申辩，自己觉得很幸运，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:14; 使徒行传 26:26; 使徒行传 26:7"> 尤其因为你熟悉犹太人中所有的规矩和争议。因此，我恳求你耐心听我。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:13; 提摩太后书 3:10; 腓立比书 3:5"> “其实，我从年轻时起的生活方式，从起初在本民族中和在耶路撒冷的情形，所有犹太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 23:6; 使徒行传 22:3; 使徒行传 24:5"> 他们从起初就认识我；如果他们愿意作证，就知道我曾按我们宗教中最严谨的教派作法利赛人而生活。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:13; 使徒行传 24:15; 使徒行传 28:20"> 如今我站在这里受审，是因为上帝向我们祖先所应许的盼望；</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:1; 腓立比书 3:11; 提摩太前书 5:5"> 我们十二个支派昼夜热切事奉上帝，都盼望达到这应许。亚基帕王啊，正是为了这盼望，我被犹太人控告！</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 15:12–20; 使徒行传 4:2; 使徒行传 17:31–32"> 如果上帝使死人复活，为什么你们会认为这是难以置信的呢？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:13; 使徒行传 22:8; 腓立比书 3:6"> “从前我自己确实以为，应该多方反对拿撒勒人耶稣的名。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 8:3; 使徒行传 9:13–14; 使徒行传 9:21"> 我在耶路撒冷也是这样做的。我从祭司长那里得了权柄，把许多圣徒关在监里；他们被处死的时候，我也投票赞成。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 22:19; 马太福音 10:17; 使徒行传 13:45"> 我常常在各会堂惩罚他们，逼他们亵渎。因我极其恼怒他们，甚至追逼他们直到外邦的城市。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:10; 使徒行传 22:5–11; 使徒行传 9:1–8"> “因此，我带着祭司长的权柄和委任，前往大马士革。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 17:2; 启示录 21:23; 启示录 1:16"> 王啊，正午的时候，我在路上看见有光从天上来，比太阳还亮，四面照着我和与我同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:40; 使徒行传 22:2; 使徒行传 9:7"> 我们都倒在地上，我听见有声音用希伯来语对我说：<span className="woj">‘扫罗，扫罗，你为什么迫害我？你用脚踢刺棒是难的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 15:20–21; 马太福音 25:45; 出埃及记 16:8"> “我说：‘主啊，你是谁？’<br />“祂说：<span className="woj">‘我就是你所迫害的耶稣。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 22:14–15; 以西结 2:1; 但以理 10:11"> <span className="woj">但你起来，站在脚上；我向你显现，是为了这个目的：要任命你作仆人和见证人，见证你已经看见的事，也见证我将要向你显明的事；</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:15; 提摩太前书 2:7; 耶利米书 1:19"> <span className="woj">我必救你脱离这百姓和外邦人；我差你到他们那里去，</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:9; 以弗所书 1:18; 以弗所书 5:8"> <span className="woj">要开他们的眼睛，使他们从黑暗转向光明，从撒但的权势转向上帝，好使他们因信我而得蒙赦罪，并在成圣的人中得着产业。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 50:5; 加拉太书 1:16; 以西结 2:7–8"> “因此，亚基帕王啊，我没有违背那从天上来的异象，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 3:8; 使徒行传 3:19; 使徒行传 2:38"> 而是先向大马士革的人、耶路撒冷的人，以及犹太全地的人宣讲，也向外邦人宣讲，叫他们悔改，转向上帝，行出与悔改相称的行为。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 21:30–31; 使徒行传 21:27; 使徒行传 25:3"> 因这个缘故，犹太人在圣殿里抓住我，想要杀我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:14; 约翰福音 5:46; 罗马书 3:21"> 然而我得了从上帝而来的帮助，就站立直到今天，向尊贵的和卑微的作见证，所说的无非是众先知和摩西说将要发生的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:1–12; 路加福音 24:26; 歌罗西书 1:18"> 就是基督必须受苦，并且祂要借着从死人中复活，首先向这百姓和外邦人宣告光。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 2:13–14; 哥林多前书 1:23; 哥林多前书 4:10"> 保罗这样申辩的时候，非斯都大声说：“保罗，你疯了！你学问太大，使你发狂了！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:26; 提多书 1:9; 提多书 2:7–8"> 但保罗说：“非斯都大人，我没有疯；我坦然说的是真实而合乎理性的话。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3; 使徒行传 2:1–12; 以赛亚书 30:20"> 王知道这些事，所以我也向他坦率地说话。我深信这些事没有一件向他隐藏，因为这事并不是在角落里做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:22–23"> 亚基帕王啊，你信众先知吗？我知道你是信的。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 马太福音 10:18; 使徒行传 26:29"> 亚基帕对保罗说：“你想稍微劝一劝，就使我成为基督徒吗？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:20; 歌罗西书 1:28; 罗马书 10:1"> 保罗说：“我向上帝祈求，无论是略微劝说，还是多方劝说，不但你，连今天所有听我的人，都能像我一样，只是不要有这些锁链。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 18:15; 使徒行传 28:22; 使徒行传 25:23"> 于是王和总督，以及百妮基，并同坐的人都起来。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 23:29; 使徒行传 23:9; 使徒行传 28:18"> 他们退到一边后，彼此谈论说：“这个人没有做什么该死或该被捆锁的事。”</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 28:18; 使徒行传 25:11–12; 使徒行传 25:25"> 亚基帕对非斯都说：“这个人若没有向凯撒上诉，本来可以释放。”</span>
</div>
</div>

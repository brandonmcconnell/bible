<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:5; 提摩太后书 1:2; 哥林多前书 4:17"> 保罗来到特庇和路司得；看哪，那里有一个门徒，名叫提摩太，是一个信主的犹太妇人的儿子，父亲却是希腊人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 5:10; 提摩太后书 3:15; 使徒行传 14:21"> 在路司得和以哥念的弟兄们都为他作好见证。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:3; 哥林多前书 9:20; 加拉太书 5:6"> 保罗想要他和自己一同出去，就因那些地方的犹太人，把他带去给他行了割礼，因为众人都知道他的父亲是希腊人。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 15:28–29; 使徒行传 15:2; 使徒行传 11:30"> 他们经过各城，把耶路撒冷的使徒和长老所定的规条交给他们遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:31; 使徒行传 2:47; 使徒行传 6:7"> 于是众教会在信心上得坚固，人数天天增加。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 18:23; 使徒行传 16:7; 使徒行传 13:2–4"> 他们经过弗吕家和加拉太地区的时候，被圣灵禁止在亚细亚讲道。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:9; 腓立比书 1:19; 加拉太书 4:6"> 到了每西亚附近，他们想要进庇推尼去，但圣灵不许他们。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 2:12; 提摩太后书 4:13; 使徒行传 16:11"> 他们经过每西亚，下到特罗亚。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:10–12; 使徒行传 19:21; 使徒行传 18:5"> 夜间，有异象向保罗显现：有一个马其顿人站着，恳求他说：“请过到马其顿来帮助我们。”</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 2:12–13; 使徒行传 14:7; 使徒行传 16:10–17"> 保罗既看见这异象，我们立刻想要往马其顿去，断定主已经呼召我们向他们传福音。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:1; 使徒行传 16:8"> 于是我们从特罗亚开船，直行到撒摩特喇，第二天到尼亚波利；</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 2:2; 腓立比书 1:1; 使徒行传 20:6"> 从那里到腓立比，这是马其顿这一地区的首要城市，是罗马殖民地。我们在这城里住了几天。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 13:14; 歌罗西书 1:23; 使徒行传 17:2"> 安息日，我们出城门，到了河边，料想那里有一个祷告的地方，就坐下，对聚集的妇女们讲话。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:17–18; 路加福音 24:45; 以赛亚书 50:5"> 有一个妇人，名叫吕底亚，是推雅推喇城的人，卖紫色布匹，敬拜上帝；她听见我们的话。主打开她的心，使她留心听保罗所讲的事。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 11:14; 希伯来书 13:2; 使徒行传 16:33"> 她和她一家既受了洗，就恳求我们说：“你们若认定我是忠于主的，就请到我家里来住。”于是她劝服了我们。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 19:31; 申命记 18:9–11; 以赛亚书 8:19"> 我们去祷告的时候，有一个使女迎面而来，她有占卜的灵，靠占卜给她的主人们赚了许多钱。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 14:6; 彼得前书 2:16; 马可福音 5:7"> 她跟着保罗和我们，喊着说：“这些人是至高上帝的仆人，向我们传讲一条救恩的道路！”</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:17; 路加福音 10:17–19; 使徒行传 3:6"> 她这样做了许多天。<br />但保罗非常厌烦，就转身对那灵说：“我奉耶稣基督的名命令你从她身上出来！”那灵就在那时刻出来了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 使徒行传 21:30; 使徒行传 8:3"> 她的主人们见自己得利的指望没有了，就抓住保罗和西拉，拉他们到市场上，去见官长。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 4:4; 约翰福音 15:18–20; 使徒行传 28:22"> 他们把二人带到行政官面前，说：“这些人是犹太人，扰乱我们的城，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 3:8; 使徒行传 26:3; 耶利米书 10:3"> 传讲我们罗马人不可接受、也不可遵行的规矩。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:2; 哥林多后书 6:5; 哥林多后书 11:23–25"> 群众一同起来攻击他们；行政官剥去他们的衣服，命令人用棍打他们。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 2:10; 提摩太后书 2:9; 撒母耳记上 23:22–23"> 打了他们许多棍以后，就把他们丢进监牢，吩咐狱卒严加看守。</span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 13:27; 约伯记 33:11; 耶利米书 29:26"> 狱卒领了这样的命令，就把他们丢进内监，两脚上了木枷。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 5:16–18; 诗篇 119:62; 雅各书 1:2"> 约在半夜，保罗和西拉正在祷告，唱诗赞美上帝，囚犯们也侧耳听他们。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:31; 使徒行传 5:19; 使徒行传 12:10"> 忽然发生大地震，甚至监牢的地基都震动了；立刻，所有的门都开了，众人的锁链也都松开了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 12:19; 马太福音 27:5; 士师记 9:54"> 狱卒从睡梦中惊醒，看见监门开着，以为囚犯已经逃走，就拔刀要自杀。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦前书 5:15; 路加福音 23:34; 路加福音 6:27–28"> 但保罗大声喊着说：“不要伤害自己！我们都在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="启示录 3:9; 使徒行传 24:25; 以赛亚书 60:14"> 狱卒叫人拿灯来，冲进去，战战兢兢地俯伏在保罗和西拉面前，</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:37; 约翰福音 6:27–29; 以赛亚书 58:9"> 然后领他们出来，说：“先生们，我必须做什么才可以得救？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:12; 使徒行传 2:38–39; 约翰福音 3:36"> 他们说：“信主耶稣基督，你和你一家都必得救。”</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 1:16; 歌罗西书 1:27–28; 提摩太前书 1:13–16"> 他们就把主的道讲给他和他家里所有的人听。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 1:16; 使徒行传 16:15; 使徒行传 16:25"> 当夜，就在那时刻，狱卒带他们去洗他们的伤痕；他和他全家立刻都受了洗。</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 15:13; 使徒行传 2:46; 罗马书 5:11"> 他领他们上自己家里，摆上饭食；他和全家因信了上帝，就大大喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="耶利米书 5:22; 诗篇 76:10; 使徒行传 5:40"> 到了天亮，行政官派差役来说：“释放那两个人。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 15:33; 约翰福音 14:27; 撒母耳记上 1:17"> 狱卒把这些话报告给保罗，说：“行政官已经派人来释放你们；现在请出来，平平安安地走吧。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 22:25–29; 诗篇 58:1–2; 马太福音 10:16"> 但保罗对他们说：“我们是罗马人，他们没有审讯，就在众人面前打了我们，又把我们关进监牢！现在他们要暗中释放我们吗？绝对不行！叫他们自己来领我们出去！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:29; 马太福音 21:46; 马太福音 14:5"> 差役把这些话报告给行政官；他们听见保罗和西拉是罗马人，就害怕了，</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 8:34; 马可福音 5:17; 但以理 6:23"> 于是前来恳求他们。领他们出来以后，请他们离开那城。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 3:2–3; 使徒行传 16:14; 使徒行传 14:22"> 二人出了监牢，进了吕底亚的家；见了弟兄们，就勉励他们，然后离开了。</span>
</div>
</div>

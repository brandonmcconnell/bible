<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–3; 提摩太后书 2:20; 马太福音 13:47–48"> 有一个人，名叫亚拿尼亚，同他的妻子撒非喇卖了一份产业，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:37; 彼得后书 2:14–15; 马太福音 23:5"> 私自留下价银的一部分，他的妻子也知道；然后他拿来一部分，放在使徒脚前。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 23:24; 以赛亚书 29:15; 约翰福音 13:2"> 彼得说：“亚拿尼亚，为什么撒但充满了你的心，使你欺哄圣灵，私自留下卖地价银的一部分呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:3; 约书亚记 7:25–26; 列王纪下 5:25–27"> 地还留着的时候，不是你自己的吗？卖了以后，价银不是由你支配吗？你心里怎么会起这样的念头呢？你不是欺哄人，而是欺哄上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:10–11; 使徒行传 2:43; 使徒行传 5:13"> 亚拿尼亚听见这些话，就倒下，断了气。凡听见这些事的人都大大惧怕。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:40; 撒母耳记下 18:17; 申命记 21:23"> 年轻人起来，把他裹好，抬出去埋葬了。</span>
<span className="v" id="v7" data-v="7"> 大约过了三个小时，他的妻子进来，还不知道所发生的事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 5:2"> 彼得问她：“告诉我，你们卖那块地，就是这个价钱吗？”<br />她说：“是的，就是这个价钱。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:9; 使徒行传 5:3–4; 诗篇 95:8–11"> 彼得对她说：“你们为什么同心试探主的灵呢？看哪，埋葬你丈夫之人的脚已经到门口了，他们也要把你抬出去。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:5"> 她立刻倒在彼得脚前，断了气。年轻人进来，见她已经死了，就把她抬出去，埋在她丈夫旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:5; 哥林多前书 10:11–12; 使徒行传 19:17"> 全教会和所有听见这些事的人都大大惧怕。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:11; 哥林多后书 12:12; 希伯来书 2:4"> 借着使徒的手，许多神迹奇事在民间行出来。他们都同心合意地在所罗门廊下。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:47; 使徒行传 4:21; 约翰福音 12:42"> 其余的人没有一个敢加入他们；然而百姓尊重他们。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 2:47; 使徒行传 4:4; 以赛亚书 55:11–13"> 信而归主的人越发增添，男男女女成群。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 14:36; 使徒行传 19:11–12; 约翰福音 14:12"> 甚至有人把病人抬到街上，放在小床和褥子上，好让彼得经过的时候，至少他的影子可以遮到他们中的一些人。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 16:17–18; 马可福音 2:3–4; 马太福音 15:30–31"> 也有许多人从耶路撒冷周围的城镇聚集而来，带着病人和被污灵折磨的人；他们全都得了医治。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:45; 使徒行传 7:9; 使徒行传 17:5"> 但大祭司和一切与他在一起的人，就是撒都该派的人，都起来，满心嫉妒，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 4:3; 路加福音 21:12; 哥林多后书 11:23"> 就下手拿住使徒，把他们关在公共拘留所里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:26; 诗篇 34:7; 使徒行传 12:7–11"> 可是夜间有主的一位天使打开监门，领他们出来，说：</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 6:63; 约翰福音 6:68; 约翰一书 5:11–12"> “你们去，站在圣殿里，把这生命的一切话都讲给百姓听。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:2; 使徒行传 22:15; 使徒行传 12:18–19"> 他们听了这话，天快亮的时候就进圣殿去教导人。大祭司和与他在一起的人来了，召集公会和以色列子孙的全体长老，差人到监狱去，要把使徒带来。</span>
<span className="v" id="v22" data-v="22"> 但是差役到了，不见他们在监狱里，就回来报告说：</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 2:4; 诗篇 33:10; 但以理 6:22–24"> “我们发现监狱关得严严的，守卫也站在门前；可是打开门，里面一个人也没有！”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 4:1; 使徒行传 5:26; 约翰福音 12:19"> 大祭司、守殿官和祭司长们听见这些话，就为这些事十分困惑，不知道这会变成什么局面。</span>
<span className="v" id="v25" data-v="25"> 有一个人来告诉他们：“看哪，你们关在监狱里的那些人，正站在圣殿里教导百姓。”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:13; 使徒行传 4:21; 马太福音 26:5"> 于是守殿官同差役去，把他们带来，但没有用强暴，因为他们害怕百姓用石头打他们。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 5:22; 使徒行传 4:7; 路加福音 22:66"> 他们把使徒带来，叫他们站在公会面前。大祭司问他们，</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 27:25; 使徒行传 7:52; 使徒行传 4:10–11"> 说：“我们不是严严地命令过你们，不可奉这名教导人吗？看哪，你们倒把你们的教导充满了耶路撒冷，还想把这人的血归到我们身上。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:19; 撒母耳记上 15:24; 马可福音 7:7–9"> 彼得和众使徒回答说：“我们必须顺服上帝，过于顺服人。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:13; 彼得前书 2:24; 使徒行传 10:39"> 我们祖先的上帝使耶稣复活了；你们却把祂挂在木头上杀了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行传 2:33; 希伯来书 2:10"> 上帝用祂的右手将祂高举，立祂为君王和救主，好把悔改和罪得赦免赐给以色列。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:26–27; 希伯来书 2:3–4; 使徒行传 1:8"> 我们是这些事的见证人；上帝赐给顺服祂之人的圣灵，也是见证人。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行传 7:54; 使徒行传 2:37; 路加福音 4:28–29"> 他们听见这话，心里极其恼怒，定意要杀他们。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 22:3; 路加福音 2:46; 路加福音 5:17"> 但公会中有一个法利赛人站起来，名叫迦玛列，是一位律法教师，受众百姓尊敬；他吩咐人把使徒暂时带到外面去。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 22:26; 耶利米书 26:19; 马太福音 27:19"> 他对众人说：“以色列人哪，关于这些人，你们要谨慎自己将要做的事。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 8:9; 彼得后书 2:2; 加拉太书 6:3"> 因为从前，丢大起来，自称是个人物；跟随他的约有四百人。他被杀了；所有听从他的人都分散了，归于无有。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 诗篇 7:14–15; 马太福音 26:52"> 此人以后，在登记户口的日子，加利利人犹大起来，拉拢了一些百姓跟从他。他也灭亡了；所有听从他的人也都四散了。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:13; 耶利米哀歌 3:37; 以赛亚书 8:9–10"> 现在我告诉你们，离开这些人，任凭他们吧。因为这计谋或这工作若是出于人，必要败坏；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以赛亚书 46:10; 马太福音 16:18"> 但若是出于上帝，你们就不能败坏它，甚至会被发现是在与上帝争战！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 10:17; 使徒行传 5:28; 使徒行传 4:17–21"> 他们同意了他的话。于是叫使徒来，打了他们，又命令他们不可奉耶稣的名讲话，然后释放了他们。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各书 1:2; 彼得前书 4:13–16; 路加福音 6:22"> 他们就离开公会，因被算为配为耶稣的名受辱而欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒行传 2:46; 使徒行传 20:20; 路加福音 21:37"> 他们天天在圣殿里，并且在家中，不住地教导人，传讲耶稣就是基督。</span>
</div>
</div>

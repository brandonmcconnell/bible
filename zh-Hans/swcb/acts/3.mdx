<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 55:17; 使徒行传 10:3; 使徒行传 4:13"> 彼得和约翰在祷告的时辰，就是第九小时，正上圣殿去。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="下午3点。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 14:8; 约翰福音 9:8; 路加福音 16:20"> 有一个人，从母腹里就是瘸腿的，被人抬来；他们天天把他放在圣殿一个叫美门的门口，要向进圣殿的人求周济。</span>
<span className="v" id="v3" data-v="3"> 他看见彼得和约翰将要进圣殿，就求他们给他周济。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:9–10; 约翰福音 11:40; 路加福音 4:20"> 彼得同约翰定睛看他，说：“看我们。”</span>
<span className="v" id="v5" data-v="5"> 那人就留意看他们，指望从他们得着什么。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 3:16; 使徒行传 10:38; 使徒行传 4:10"> 彼得却说：“金银我都没有；但我所有的，我给你。奉拿撒勒人耶稣基督的名，起来行走！”</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 1:31; 马可福音 9:27; 使徒行传 9:41"> 彼得拉着他的右手，扶他起来；他的脚和踝骨立刻有了力量。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 14:10; 以赛亚书 35:6; 诗篇 107:20–22"> 他一跳起来，就站住，开始行走；他同他们进了圣殿，一边走，一边跳，一边赞美上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:21; 使徒行传 4:16; 路加福音 13:17"> 众人都看见他行走，赞美上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:2; 约翰福音 5:20; 约翰福音 9:3"> 他们认出他就是那常坐在圣殿美门口求周济的人；因他所遭遇的事，他们满心惊奇诧异。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:12; 约翰福音 10:23; 路加福音 8:38"> 那蒙医治的瘸子紧紧拉着彼得和约翰，众人都大为惊奇，一同跑到他们那里，就是到那称为所罗门的廊下。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 约翰福音 3:27–28; 但以理 2:28–30"> 彼得看见，就回应众人说：“以色列人啊，你们为什么因这人惊奇？为什么定睛看我们，好像我们凭自己的能力或敬虔使他行走呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 22:32; 使徒行传 7:32; 马太福音 27:17–25"> 亚伯拉罕、以撒、雅各的上帝，就是我们祖宗的上帝，已经荣耀了祂的仆人耶稣；你们却把祂交了出去，并且在彼拉多面前弃绝祂，那时彼拉多已经决定要释放祂。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 1:24; 使徒行传 7:52; 彼得前书 3:18"> 你们却弃绝了那圣洁公义者，反求释放一个凶手给你们，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 启示录 21:6; 使徒行传 2:32"> 杀了生命的君王；上帝却使祂从死人中复活，我们都是这事的见证人。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:21–22; 使徒行传 4:10; 使徒行传 14:9"> 因信祂的名，祂的名使这个你们所看见、所认识的人强健了。是的，那借着祂而有的信心，使这人在你们众人面前完全康健。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行传 13:27; 约翰福音 16:3"> “现在，弟兄们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里译为“弟兄们”的词，也可以正确译为“弟兄姊妹们”或“手足们”。">b</a></sup>我知道你们做这事是出于无知，你们的官长也是如此。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:1–12; 使徒行传 26:22–23; 使徒行传 2:23"> 但上帝借众先知的口所预先宣告的，就是基督必受苦的事，祂就这样成就了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:38; 以赛亚书 44:22; 以赛亚书 43:25"> “所以，你们要悔改，归向上帝，使你们的罪可以被涂抹，好叫安舒的时期从主面前来到，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:30–36; 启示录 19:11–16; 帖撒罗尼迦后书 2:2"> 并且使祂差遣那预先为你们指定的基督耶稣来；</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:21; 以赛亚书 1:26; 使徒行传 1:11"> 天上必须接纳祂，直到万物复兴的时候，就是上帝从古以来借祂圣先知的口所说的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 18:15–19; 使徒行传 7:37; 加拉太书 4:4"> 摩西确实曾对祖宗说：‘主上帝要从你们弟兄中间为你们兴起一位先知，像我一样。凡祂对你们所说的一切，你们都要听从祂。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 18:19; 约翰福音 12:48; 希伯来书 10:28–30"> 将来，凡不听从那位先知的灵魂，必从民中被彻底灭绝。’</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 3:21; 路加福音 24:27; 撒母耳记上 3:20"> 是的，从撒母耳以来，以及后来所有说话的先知，也都宣告了这些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 22:18; 加拉太书 3:8; 使徒行传 2:39"> 你们是先知的子孙，也是上帝与我们祖宗所立之约的子孙；祂曾对亚伯拉罕说：‘地上万族都要借着你的后裔得福。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：种子">c</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 1:21; 使徒行传 3:22; 犹大书 1:24"> 上帝既兴起祂的仆人耶稣，就先差祂到你们这里来，赐福给你们，使你们各人离开自己的邪恶。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:3; 路加福音 24:19; 马太福音 4:23–24"> 提阿非罗啊，我所写的第一卷书，是关于耶稣开始所做和所教导的一切，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 1:9; 约翰福音 20:21; 以赛亚书 59:20–21"> 直到祂被接上升的日子；在此以前，祂借着圣灵吩咐了祂所拣选的使徒。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 15:5–7; 使徒行传 13:31; 约翰福音 20:26"> 祂受害以后，用许多证据向这些人显明自己是活着的，四十天之久向他们显现，讲论上帝的国。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 24:49; 约翰福音 14:16; 约翰福音 15:26"> 祂与他们聚集的时候，吩咐他们说：<span className="woj">“不要离开耶路撒冷，要等候父的应许，就是你们从我这里听见的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:11; 使徒行传 11:15–16; 路加福音 3:16"> <span className="woj">因为约翰确实是用水施洗，但过不了多少日子，你们要受圣灵的洗。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 19:11; 路加福音 17:20; 但以理 7:27"> 于是，他们聚集的时候，就问祂：“主啊，你就在这时候为以色列恢复国度吗？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:36; 帖撒罗尼迦前书 5:1–2; 马可福音 13:32"> 祂对他们说：<span className="woj">“父凭自己的权柄所定的时候和日期，不是你们可以知道的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 28:19; 马可福音 16:15; 罗马书 15:19"> <span className="woj">但圣灵临到你们身上，你们就必得着能力；你们要在耶路撒冷、犹太全地和撒玛利亚，直到地极，作我的见证人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="但以理 7:13; 路加福音 24:50–51; 马可福音 16:19"> 祂说了这些话，他们正看的时候，祂就被接上升，有一朵云彩把祂接去，离开他们的视线。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:4; 约翰福音 20:12; 启示录 7:14"> 祂离去的时候，他们定睛望着天空；看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，源自“ἰδοὺ”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">a</a></sup>有两个人穿着白衣，站在他们旁边，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 1:7; 帖撒罗尼迦前书 4:16; 马可福音 13:26"> 也说：“加利利人哪，你们为什么站着望向天空呢？这位离开你们被接上天空的耶稣，你们怎样看见祂往天空去，祂还要照样回来。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:52; 马太福音 21:1; 路加福音 24:50"> 那时，他们从那座名叫橄榄山的山回耶路撒冷去；这山靠近耶路撒冷，约有安息日可走的路程。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:8; 路加福音 22:12; 马可福音 14:15"> 他们进城以后，就上了所住的楼房；在那里有彼得、约翰、雅各、安得烈、腓力、多马、巴多罗买、马太、亚勒腓的儿子雅各、奋锐党的西门，以及雅各的儿子犹大。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 6:4; 以弗所书 6:18; 歌罗西书 4:2"> 这些人都同心合意，恒切地祷告和祈求，还有几个妇人、耶稣的母亲马利亚，以及祂的弟兄们。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 15:6; 使徒行传 21:20; 启示录 3:4"> 那些日子，彼得在门徒中间站起来——人数约有一百二十——说：</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 41:9; 约翰福音 13:18; 诗篇 55:12–15"> “弟兄们，圣灵从前借着大卫的口，论到那带领人捉拿耶稣的犹大所说的这段经文，必须应验。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 1:25; 马可福音 3:19; 约翰福音 17:12"> 他本来列在我们中间，并且在这职事上得了一份。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:3–10; 马太福音 26:14–15; 诗篇 55:23"> 这人用他作恶所得的报酬买了一块田；后来他头朝下坠落，身体裂开，肠子都流了出来。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:22; 马太福音 28:15; 使徒行传 21:40"> 住在耶路撒冷的众人都知道了这事，所以那块田用他们的语言称为‘亚革大马’，意思就是‘血田’。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 69:25; 诗篇 109:8–15; 使徒行传 1:25"> 因为诗篇上写着：<br /><span className="pl pl-1">‘愿他的住处变为荒场，</span><br /><span className="pl pl-2">无人居住在其中；’</span><br />又说：<br /><span className="pl pl-1">‘愿别人取得他的职分。’</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 15:27; 路加福音 10:1–2; 民数记 27:17"> “所以，主耶稣在我们中间出入的整个时期，常与我们同行的人中，</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 1:2; 使徒行传 4:33; 使徒行传 1:8–9"> 从约翰施洗开始，直到祂离开我们被接上升的日子为止，必须有一个人与我们一同成为祂复活的见证人。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 15:22; 使徒行传 1:26"> 他们就提出两个人：一个是称为巴撒巴、又名犹士都的约瑟，另一个是马提亚。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 16:7; 使徒行传 15:8; 希伯来书 4:13"> 他们祷告说：“主啊，你知道所有人的心，求你指明这两个人中，你拣选了哪一个，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 9:2; 约翰福音 6:70–71; 约翰福音 17:12"> 好取得这职事和使徒职分的一份；犹大已经离弃这职分，往自己的地方去了。”</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 16:8; 约书亚记 18:10; 撒母耳记上 14:41–42"> 他们为这两个人抽签，签落在马提亚身上；他就和十一个使徒同列。</span>
</div>
</div>

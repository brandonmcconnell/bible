<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:4; 使徒行传 13:51; 使徒行传 13:46"> 在以哥念，他们一同进了犹太人的会堂，讲道讲得使许多犹太人和希腊人都信了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 13:50; 使徒行传 21:27–30; 使徒行传 14:19"> 但那些不信的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“不顺从的”">a</a></sup>犹太人挑动外邦人的心，使他们怨恨弟兄们。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 2:4; 以弗所书 6:18–20; 使徒行传 20:32"> 因此，他们在那里住了很久，靠着主放胆传讲；主为祂恩典的道作见证，准许神迹奇事借着他们的手施行出来。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:24; 使徒行传 14:14; 路加福音 11:21–23"> 城里的众人却分裂了：有的站在犹太人一边，有的站在使徒一边。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:19; 提摩太后书 3:11; 使徒行传 17:5"> 外邦人和犹太人连同他们的官长企图施暴，羞辱他们，并用石头打他们；</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 14:20–21; 马太福音 10:23; 提摩太后书 3:11"> 他们察觉了，就逃往吕高尼的各城：路司得、特庇，以及周围地区。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 14:21; 使徒行传 16:10; 帖撒罗尼迦前书 2:2"> 他们在那里传福音。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:2; 约翰福音 9:1–2; 约翰福音 5:3–5"> 在路司得，有一个人坐着，两脚无力，生来就是瘸腿的，从来没有走过路。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:4; 马太福音 15:28; 马太福音 9:28–29"> 他听保罗讲道；保罗定睛看他，见他有信心可以得痊愈，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 35:6; 约翰福音 5:8–9; 约翰福音 14:12"> 就大声说：“你双脚站直起来！”他就跳起来，开始行走。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:6; 使徒行传 8:10; 使徒行传 12:22"> 众人看见保罗所做的事，就用吕高尼话高声说：“众神以人的样子降到我们这里来了！”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:35"> 他们称巴拿巴为“宙斯”，称保罗为“赫尔墨斯”，因为保罗是主要发言的人。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理 2:46; 使徒行传 10:25"> 城外宙斯庙的祭司牵着牛，拿着花环来到城门口，想要和众人一同献祭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:65; 哥林多前书 9:5–6; 列王纪下 5:7"> 使徒巴拿巴和保罗听见了，就撕裂衣服，冲进众人中间，喊着说：</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:26; 哥林多前书 8:4; 雅各书 5:17"> “各位，为什么做这些事呢？我们也是人，和你们有同样的性情；我们传福音给你们，是要你们离弃这些虚妄之事，归向那位永活的上帝，就是创造天、地、海和其中万物的上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:30; 诗篇 81:12; 罗马书 1:28"> 在过去的世代，祂任凭万国各行其道。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:19–20; 约珥 2:23; 约伯记 5:10"> 然而，祂并没有不给自己留下见证；因为祂施行善事，从天赐雨给你们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR读作“我们”，而不是“你们”">b</a></sup>，赏赐丰收的季节，使我们的心充满食物和喜乐。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 44:16–17; 创世记 19:9; 创世记 11:6"> 即使说了这些话，他们也几乎拦不住众人向他们献祭。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 11:25; 提摩太后书 3:11; 使徒行传 13:50–51"> 但有些犹太人从安提阿和以哥念来到那里，劝服了众人；他们用石头打保罗，把他拖到城外，以为他已经死了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:9–10; 哥林多后书 6:9; 使徒行传 14:6"> 门徒围着他站着的时候，他却起来，进了城。第二天，他和巴拿巴一同往特庇去。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 14:19; 使徒行传 14:1; 使徒行传 13:51"> 他们向那城传了福音，使许多人作了门徒，就回到路司得、以哥念和安提阿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 5:10; 提摩太后书 3:12; 约翰福音 16:33"> 坚固门徒的心，劝勉他们要持守信仰，又说：“我们必须经历许多患难，才能进入上帝的国。”</span>
<span className="v" id="v23" data-v="23" data-xref="提多书 1:5; 使徒行传 11:30; 雅各书 5:14"> 他们在各教会为他们任命了长老，又禁食祷告，就把他们交托给他们所信靠的主。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 13:13–14; 使徒行传 15:38"> 他们经过彼西底，来到旁非利亚。</span>
<span className="v" id="v25" data-v="25"> 他们在别加讲了道，就下到亚大利。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:40; 使徒行传 11:19; 哥林多后书 1:12"> 从那里坐船往安提阿去；当初他们就是从那里被交托在上帝的恩典中，去做他们如今已经完成的工作。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 16:9; 使徒行传 15:12; 歌罗西书 4:3"> 他们到了以后，就聚集教会，报告上帝借着他们所做的一切事，以及祂怎样为外邦人开了信心的门。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 使徒行传 15:35"> 他们在那里和门徒住了很久。</span>
</div>
</div>

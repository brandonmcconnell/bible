<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:36; 使徒行传 15:35; 使徒行传 11:22–27"> 在安提阿的教会中，有几位先知和教师：巴拿巴、称为尼结的西面、古利奈人路求、与分封王希律同养的马念，以及扫罗。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 1:15; 使徒行传 9:15; 哥林多前书 12:11"> 他们事奉主、禁食的时候，圣灵说：“要为我分别出巴拿巴和扫罗，去做我呼召他们所做的工作。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:6; 提摩太后书 2:2; 使徒行传 13:2"> 于是他们禁食祷告，给他们按手，就差遣他们去了。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 13:2; 使徒行传 11:19"> 他们既受圣灵差遣，就下到西流基；从那里坐船往塞浦路斯去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 13:14; 使徒行传 13:46; 使徒行传 14:1"> 他们到了撒拉米，就在犹太人的各会堂里传讲上帝的道。他们也有约翰作助手。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:15; 约翰一书 4:1; 哥林多后书 11:13"> 他们走遍全岛，直到帕弗，遇见一个行巫术的人，是假先知，是犹太人，名叫巴耶稣；</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:38; 使徒行传 13:12; 使徒行传 18:12"> 他与行省总督士求·保罗在一起。士求·保罗是个有见识的人，他召来巴拿巴和扫罗，想要听上帝的道。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 3:8; 使徒行传 13:6–7; 提摩太后书 4:14–15"> 只是那行巫术的以吕马——他的名字翻译出来就是这个意思——抵挡他们，想要使行省总督偏离这信仰。</span>
<span className="v" id="v9" data-v="9" data-xref="弥迦书 3:8; 使徒行传 4:8; 使徒行传 2:4"> 但扫罗，又名保罗，被圣灵充满，定睛看着他，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:44; 哥林多后书 11:3; 马太福音 13:38"> 说：“你这魔鬼的儿子，充满各样诡诈和各样奸恶，一切公义的仇敌，你还不停止扭曲主正直的道路吗？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 9:3; 诗篇 32:4; 希伯来书 10:31"> 现在，看哪，主的手临到你身上，你要瞎眼，暂时看不见太阳！”<br />立刻，有雾气和黑暗落在他身上；他四处摸索，寻找有人牵着他的手领他。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 10:4–5; 使徒行传 13:7; 路加福音 4:22"> 那时，行省总督看见所发生的事，就信了，并对主的教导感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 15:38; 使徒行传 2:10; 使徒行传 14:24–25"> 保罗和他的同伴从帕弗开船，来到旁非利亚的别迦。约翰离开他们，回耶路撒冷去了。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:13; 使徒行传 14:19; 使徒行传 13:5"> 他们却从别迦继续前行，来到彼西底的安提阿；在安息日进了会堂，坐下来。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:22; 使徒行传 15:21; 马可福音 5:22"> 诵读律法和先知书以后，会堂的主管派人到他们那里，说：“弟兄们，你们若有什么劝勉百姓的话，请说。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 12:17; 使徒行传 13:26; 使徒行传 10:2"> 保罗站起来，举手示意，说：“以色列人和敬畏上帝的人，请听。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 7:6–8; 以赛亚书 63:9–14; 诗篇 105:23–24"> 这百姓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR、NU 加上“以色列”">a</a></sup>的上帝拣选了我们的祖宗；当他们在埃及地作寄居者的时候，祂抬举了这百姓，又用高举的膀臂领他们从那里出来。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 7:36; 诗篇 95:8–11; 诗篇 106:13–29"> 约有四十年的时间，祂在旷野容忍他们。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 7:1; 诗篇 78:55; 使徒行传 7:45"> 祂灭了迦南地七个民族以后，把他们的土地赐给他们作产业，约有四百五十年。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 2:16; 撒母耳记上 3:20; 列王纪下 23:22"> 这些事以后，祂赐给他们士师，直到先知撒母耳的时候。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 10:1; 撒母耳记上 15:1; 撒母耳记上 12:12–19"> 后来他们求一个王，上帝就把便雅悯支派的人，基士的儿子扫罗，赐给他们四十年。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 13:13–14; 列王纪上 15:5; 诗篇 78:70–72"> 祂废了扫罗以后，就兴起大卫作他们的王；祂也为大卫作见证说：‘我找到了耶西的儿子大卫，他是合我心意的人，必实行我一切的旨意。’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:1; 诗篇 132:11; 启示录 22:16"> 从这人的后裔中，上帝照着祂的应许，给以色列带来了救恩<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR、NU 读作“一位救主，就是耶稣”，而不是“救恩”">b</a></sup>；</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 1:22; 约翰福音 1:6–8; 路加福音 3:2–20"> 在祂到来以前，约翰已经先向以色列<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR、NU 读作“向以色列全体百姓”，而不是“向以色列”">c</a></sup>宣讲悔改的洗礼。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 3:11; 马可福音 1:7; 约翰福音 1:26–27"> 约翰将要完成他的路程时，说：‘你们以为我是谁？我不是那一位。但看哪，有一位在我以后来的，祂脚上的鞋带，我都不配解开。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:77; 罗马书 1:16; 路加福音 1:69"> “弟兄们，亚伯拉罕血脉的子孙，以及你们中间敬畏上帝的人，这救恩的道已经传给你们。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 3:17; 路加福音 24:24–27; 路加福音 24:20"> 住在耶路撒冷的人和他们的官长，因为不认识祂，也不明白每个安息日所诵读的众先知的话，就定了祂的罪，正应验了这些话。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 23:21–25; 路加福音 23:14–16; 约翰福音 19:4"> 他们虽然找不到该判祂死刑的理由，仍然请求彼拉多杀祂。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 23:53; 约翰福音 19:28; 约翰福音 19:30"> 他们成就了经上指着祂所写的一切以后，就把祂从木头上取下来，安放在坟墓里。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:24; 使徒行传 17:31; 马太福音 28:6"> 但上帝使祂从死人中复活；</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:48; 使徒行传 1:3; 使徒行传 1:11"> 许多天中，那些曾与祂从加利利上耶路撒冷的人都看见了祂；这些人如今是祂在百姓面前的见证人。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 4:13; 使徒行传 26:6; 以西结 34:23"> 我们也把应许给祖宗的福音传给你们，</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 2:7; 希伯来书 5:5; 希伯来书 1:5–6"> 就是上帝叫耶稣复活，把这应许成就给我们这些他们的儿女了。正如第二篇诗上也写着：<br /><span className="pl pl-1">‘你是我的儿子；</span><br /><span className="pl pl-2">我今日作了你的父亲。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 55:3; 诗篇 89:2–4; 罗马书 6:9"> “至于上帝叫祂从死人中复活，使祂不再归于朽坏这事，祂曾这样说：‘我必将大卫那圣洁、可靠的福分赐给你们。’</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 16:10; 使徒行传 2:27–31; 诗篇 49:9"> 所以祂也在另一篇诗上说：‘你必不让你的圣者见朽坏。’</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:29; 撒母耳记下 7:12; 列王纪上 2:10"> 大卫在他自己的世代遵行了上帝的旨意以后，就睡了，与他的祖宗同葬，也见了朽坏；</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 13:30; 使徒行传 2:24"> 但上帝所复活的那一位并没有见朽坏。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 24:47; 约翰一书 2:12; 哥林多后书 5:18–21"> 所以，弟兄们，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="此处“弟兄们”一词，以及上下文允许之处，也可正确译为“弟兄姊妹们”或“手足们”。">d</a></sup>你们应当知道：借着这一位，赦罪的事传给你们；</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 10:4; 加拉太书 2:16; 罗马书 8:3"> 凡信的人，都借着祂在一切事上得称义；这些事是你们靠摩西的律法不能称义的。</span>
<span className="v" id="v40" data-v="40" data-xref="玛拉基书 4:1; 希伯来书 3:12; 玛拉基书 3:2"> 所以你们要谨慎，免得先知书上所说的临到你们：</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷 1:5; 彼得前书 4:17; 罗马书 11:7–14"> <span className="pl pl-1">‘看哪，你们这些轻慢的人！</span><br /><span className="pl pl-2">要惊奇，要灭亡，</span><br /><span className="pl pl-2">因为在你们的日子，我要做一件事，</span><br /><span className="pl pl-2">这事即使有人向你们宣告，你们也绝不会信。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒行传 28:28; 使徒行传 10:33; 马太福音 19:30"> 犹太人出会堂的时候，外邦人恳求他们到下一个安息日再把这些话讲给他们听。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 11:23; 使徒行传 14:22; 以弗所书 2:8"> 会众散去以后，有许多犹太人和虔诚的归信者跟随保罗和巴拿巴。二人同他们谈话，劝他们继续留在上帝的恩典中。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="诗篇 110:3; 创世记 49:10; 以赛亚书 11:10"> 下一个安息日，几乎全城的人都聚集，要听上帝的道。</span>
<span className="v" id="v45" data-v="45" data-xref="犹大书 1:10; 使徒行传 18:6; 使徒行传 5:17"> 但犹太人看见群众，就满心嫉妒，反驳保罗所说的话，并且亵渎。</span>
</div>
<div className="bp poetry">
<span className="v" id="v46" data-v="46" data-xref="使徒行传 28:28; 马太福音 21:43; 使徒行传 18:5–6"> 保罗和巴拿巴放胆说：“上帝的道本来必须先讲给你们听。既然你们把它从自己身边推开，判定自己不配得永生，看哪，我们就转向外邦人。</span>
<span className="v" id="v47" data-v="47" data-xref="以赛亚书 49:6; 以赛亚书 42:6; 路加福音 2:32"> 因为主曾这样吩咐我们说：<br /><span className="pl pl-1">‘我已经立你作外邦人的光，</span><br /><span className="pl pl-2">使你把救恩带到地极。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="罗马书 8:29–30; 以弗所书 1:4; 罗马书 11:7"> 外邦人听见这话，就欢喜，并且荣耀上帝的道。凡被指定得永生的人都信了。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 12:24; 使徒行传 19:10; 使徒行传 19:26"> 主的道传遍了那一带全境。</span>
<span className="v" id="v50" data-v="50" data-xref="使徒行传 14:19; 使徒行传 13:45; 使徒行传 14:2"> 但犹太人煽动虔诚而有名望的妇女和城里的首要人物，掀起对保罗和巴拿巴的逼迫，把他们赶出自己的境界。</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 10:14; 使徒行传 18:6; 路加福音 9:5"> 二人就对着他们跺下脚上的尘土，来到以哥念。</span>
<span className="v" id="v52" data-v="52" data-xref="罗马书 15:13; 帖撒罗尼迦前书 1:6; 使徒行传 4:31"> 门徒满有喜乐，又被圣灵充满。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:1; 马太福音 8:5–13; 马太福音 27:27"> 在凯撒利亚有一个人，名叫哥尼流，是所谓意大利营的一名百夫长。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 7:7–8; 使徒行传 10:4; 使徒行传 10:22"> 他是虔诚人，和全家都敬畏上帝，常常慷慨周济百姓，并且时常向上帝祷告。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理 9:20–21; 使徒行传 3:1; 使徒行传 5:19"> 白天约第九时，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="下午三点。">a</a></sup>他在异象中清楚看见上帝的一位天使进来，到他那里，对他说：“哥尼流！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 希伯来书 6:10; 使徒行传 10:31"> 他定睛看着天使，惊惧地说：“主啊，什么事？”<br />天使对他说：“你的祷告和你给穷人的周济已经升到上帝面前，作为纪念。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:9; 使徒行传 9:38; 使徒行传 15:7"> 现在你要派人去约帕，请那又称为彼得的西门来。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:43; 使徒行传 11:13–14; 罗马书 10:14–17"> 他住在一个名叫西门的硝皮匠家里；那人的房子在海边。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 加上：“这个人会告诉你必须做什么。”">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓利门书 1:16; 撒母耳记上 14:6–7; 马太福音 8:9–10"> 对他说话的天使离开以后，哥尼流叫来两个家仆，又从常侍候他的人中叫来一个虔诚的士兵。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:36; 诗篇 119:59–60; 使徒行传 10:33"> 他把一切事都向他们说明，就派他们去约帕。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="西番雅书 1:5; 诗篇 55:17; 撒母耳记上 9:25"> 第二天，他们在路上，快到那城的时候，约在中午，彼得上房顶去祷告。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 22:17; 启示录 4:2–3; 哥林多后书 12:2–4"> 他饿了，想要吃东西；人在预备的时候，他进入恍惚状态。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:6; 约翰福音 1:51; 罗马书 16:25–26"> 他看见天开了，有一个器物降下来到他那里，好像一块大布，四角垂下，落在地上。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:8–9; 约翰福音 7:37; 哥林多前书 6:9–11"> 里面有地上各种四足走兽、野兽、爬行动物和天空的飞鸟。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:31–34; 耶利米书 35:2–5; 使徒行传 10:10"> 有声音对他说：<span className="woj">“彼得，起来，宰了吃！”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 20:25; 以西结 4:14; 但以理 1:8"> 彼得却说：“主啊，绝不可！因为凡俗或不洁净的东西，我从来没有吃过。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 10:25; 马太福音 15:11; 提多书 1:15"> 第二次又有声音对他说：<span className="woj">“上帝已经洁净的，你不可当作不洁净。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 41:32; 约翰福音 21:17; 哥林多后书 13:1"> 这事一连发生了三次，那物随即被收回天上。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 13:12; 使徒行传 10:7–19; 使徒行传 5:24"> 彼得心里十分困惑，不知道自己所见的异象是什么意思。看哪，哥尼流所派来的人已经打听到西门的房子，站在门口，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 10:5–6; 使徒行传 11:11"> 呼叫询问那又称为彼得的西门是不是住在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 8:29; 使徒行传 11:12; 使徒行传 21:4"> 彼得还在思索那异象的时候，圣灵对他说：“看哪，有三<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="根据 TR 和 NU 的读法；MT 省略“三”。">c</a></sup>个人在找你。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:7–9; 撒迦利亚书 2:9–11; 以赛亚书 48:16"> 起来，下去，和他们同去，不要有任何疑虑，因为是我差他们来的。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:38–39; 马可福音 10:51; 使徒行传 10:29"> 彼得下去见那些人，说：“看哪，我就是你们所找的人。你们为什么来？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 11:14; 使徒行传 10:2; 使徒行传 22:12"> 他们说：“百夫长哥尼流是个义人，敬畏上帝，并且受犹太全民族称赞。他蒙一位圣天使指示，请你到他家里，好听你所说的话。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 10:45; 使徒行传 11:12; 彼得前书 4:9"> 于是彼得请他们进来，接待他们住宿。<br />第二天，彼得起来，和他们同去；约帕的几个弟兄也陪他一起去。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 8:40; 撒迦利亚书 8:20–23; 撒迦利亚书 3:10"> 又过了一天，他们进了凯撒利亚。哥尼流已经召集了他的亲族和亲近的朋友，正在等候他们。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 19:10; 启示录 22:8–9; 但以理 2:46"> 彼得进去的时候，哥尼流迎接他，俯伏在他脚前拜他。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 19:10; 启示录 22:8–9; 使徒行传 14:14–15"> 彼得却扶他起来，说：“起来！我自己也是人。”</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 2:12; 约翰福音 4:35; 使徒行传 10:24"> 彼得和他说着话进去，发现有许多人聚集在那里。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:9; 以弗所书 3:6–7; 加拉太书 2:12–14"> 他对他们说：“你们自己知道，犹太人和外族人交往或来往，是不合律法的；但上帝已经指示我，不可把任何人称为凡俗或不洁净。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:60; 彼得前书 3:15; 使徒行传 10:19–20"> 所以我被请来的时候，也没有推辞就来了。现在我问，你们为什么请我来？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 10:3; 但以理 9:20–21; 尼希米记 9:1–3"> 哥尼流说：“四天前，我禁食直到这时；在第九时，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="下午三点。">d</a></sup>我正在家里祷告。看哪，有一个人穿着明亮的衣服，站在我面前，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:4; 但以理 9:23; 路加福音 1:13"> 说：‘哥尼流，你的祷告已经蒙垂听，你给穷人的周济在上帝面前蒙记念了。</span>
<span className="v" id="v32" data-v="32"> 所以你要派人去约帕，请那又称为彼得的西门来。他住在海边一个名叫西门的硝皮匠家里。他来的时候，会对你说话。’</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 1:19; 加拉太书 4:14; 历代志下 30:12"> 所以我立刻派人到你那里，你肯来，真好。现在我们都在上帝面前聚集在这里，要听上帝吩咐你的一切事。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="罗马书 2:11; 历代志下 19:7; 申命记 10:17"> 彼得开口说：“我确实看出，上帝不偏待人；</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:29; 使徒行传 10:2; 罗马书 10:12–13"> 但在各国中，那敬畏祂、行义的人都蒙祂悦纳。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 28:18; 使徒行传 2:36; 启示录 17:14"> 上帝把这道传给以色列儿女，借着耶稣基督宣讲和平的福音——祂是万有的主——</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 4:14; 使徒行传 2:22; 使徒行传 28:22"> 这事你们自己知道，就是约翰所传的洗礼以后，从加利利开始，传遍全犹太的事；</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:18; 使徒行传 2:22; 以赛亚书 61:1–3"> 就是上帝怎样以圣灵和能力膏拿撒勒的耶稣；祂到处行善，医治所有被魔鬼压制的人，因为上帝与祂同在。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:48; 使徒行传 1:8; 使徒行传 10:41"> 祂在犹太人的地区和耶路撒冷所做的一切事，我们都是见证人；他们也<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="TR 省略“也”。">e</a></sup>把祂挂在木头上杀了。</span>
<span className="v" id="v40" data-v="40" data-xref="彼得前书 1:21; 使徒行传 13:30–31; 哥林多前书 15:3–4"> 第三天，上帝使祂复活，并使祂显现出来，</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 14:22; 使徒行传 10:39; 约翰福音 21:13"> 不是显现给所有百姓，而是显现给上帝预先拣选的见证人，就是我们这些在祂从死人中复活以后与祂同吃同喝的人。</span>
<span className="v" id="v42" data-v="42" data-xref="哥林多后书 5:10; 提摩太后书 4:1; 彼得前书 4:5"> 祂吩咐我们向百姓宣讲，并作见证：祂就是上帝所指定、要审判活人和死人的那一位。</span>
<span className="v" id="v43" data-v="43" data-xref="撒迦利亚书 13:1; 使徒行传 2:38; 以赛亚书 53:11"> 众先知都为祂作见证，说凡信祂的人，都必因祂的名领受罪的赦免。”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行传 11:15; 使徒行传 19:6; 使徒行传 15:8"> 彼得还在说这些话的时候，圣灵降在所有听道的人身上。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 10:23; 使徒行传 2:38; 加拉太书 3:13–14"> 那些和彼得同来的受割礼的信徒都惊奇，因为圣灵的恩赐也浇灌在外邦人身上。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 19:6; 使徒行传 2:4; 马可福音 16:17"> 因为他们听见这些人说各种语言，颂扬上帝为大。<br />于是彼得回答说：</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 8:36; 罗马书 10:12; 使徒行传 11:15–17"> “这些人既然和我们一样领受了圣灵，谁能禁止用水给他们施洗呢？”</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 2:38; 使徒行传 8:16; 加拉太书 3:27"> 他就吩咐他们奉耶稣基督的名受洗。然后他们请求彼得住几天。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 1:1; 腓立比书 4:16; 使徒行传 20:4"> 他们经过暗妃波里和亚波罗尼亚，来到帖撒罗尼迦；那里有一个犹太人的会堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 9:20; 使徒行传 17:17; 使徒行传 18:4"> 保罗照他的惯例进去到他们那里，一连三个安息日，根据圣经和他们辩论，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:28; 使徒行传 9:22; 路加福音 24:32"> 讲解并证明基督必须受苦，并且从死人中复活；他说：“我向你们传讲的这位耶稣，就是基督。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 17:12; 使徒行传 13:43; 使徒行传 14:4"> 他们中间有些人被说服了，就归附保罗和西拉；还有一大群敬虔的希腊人，以及不少尊贵的妇女。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:26; 使徒行传 17:13; 罗马书 16:21"> 但那些不信服的犹太人带着<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认经文作“那些不信服的犹太人心里嫉妒，带着”，而不是“但那些不信服的犹太人带着”。">a</a></sup>市井上的几个恶人，聚集成群，使全城骚动起来。他们袭击耶孙的家，想把保罗和西拉带出来交给民众。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:5; 使徒行传 16:19–21; 使徒行传 28:22"> 他们找不到二人，就把耶孙和几位弟兄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此处译为“弟兄”的词，在上下文允许时，也可以正确地译为“弟兄姊妹”或“手足”。">b</a></sup>拉到城里的官长面前，喊叫说：“那些搅乱天下的人也到这里来了，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行传 16:21; 约翰福音 19:12"> 耶孙接待了他们。这些人都违背凯撒的命令，说另有一个王，就是耶稣！”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 2:3; 约翰福音 11:48"> 群众和城里的官长听见这些话，就都不安。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 17:5"> 他们从耶孙和其余的人收了保证金，就释放了他们。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:2; 帖撒罗尼迦前书 2:2; 使徒行传 17:13–14"> 弟兄们随即在夜间送保罗和西拉离开，往庇哩亚去。他们到了那里，就进了犹太人的会堂。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 34:16; 箴言 2:1–5; 约翰福音 5:39"> 这里的人比帖撒罗尼迦的人更高尚，因为他们以十分热切的心领受这道，天天查考圣经，要看看这些事是否如此。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:14; 使徒行传 14:1; 使徒行传 13:50"> 所以他们中间有许多人信了；又有不少显贵的希腊妇女和男子也信了。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 2:14–16; 箴言 28:25; 使徒行传 6:12"> 但帖撒罗尼迦的犹太人知道保罗也在庇哩亚传讲上帝的道，就也来到那里，煽动群众。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 17:10; 马太福音 10:23; 使徒行传 9:25"> 于是弟兄们立刻送保罗出去，直到海边；西拉和提摩太仍留在那里。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 18:5; 帖撒罗尼迦前书 3:1; 使徒行传 18:1"> 护送保罗的人把他带到雅典；他们领受了给西拉和提摩太的命令，要他们尽快到保罗那里去，就离开了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:158; 彼得后书 2:7; 诗篇 119:136"> 保罗在雅典等候他们的时候，看见满城都是偶像，心里就激愤。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:16; 使徒行传 14:1–4; 使徒行传 17:2–4"> 所以他在会堂里同犹太人和敬虔的人辩论，也天天在市集上同遇见的人辩论。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:20–21; 歌罗西书 2:8; 路加福音 11:53"> 还有<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="公认经文省略“还有”。">c</a></sup>一些伊壁鸠鲁派和斯多亚派的哲学家同他谈论。有的说：“这个拾人牙慧的想说什么？”<br />另有的说：“他似乎是在宣传外来的神明。”这是因为他传讲耶稣和复活。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:27; 使徒行传 17:22; 使徒行传 24:24"> 他们拉住他，把他带到亚略巴古，说：“你所讲的这新教导，我们可以知道是什么吗？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 1:23; 何西阿 8:12; 哥林多前书 2:14"> 因为你把一些奇怪的事传到我们耳中，所以我们想知道这些事是什么意思。”</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:16–17; 歌罗西书 4:5; 以弗所书 5:16"> 原来所有雅典人和住在那里的外乡人，除了谈论或听闻一些新鲜事以外，不把时间花在别的事上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:19; 使徒行传 19:35; 使徒行传 17:16"> 保罗站在亚略巴古当中，说：“各位雅典人，我看出你们在各方面都非常虔诚敬神。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:22; 加拉太书 4:8–9; 约翰福音 17:3"> 因为我走过的时候，仔细观看你们所敬拜的对象，也发现一座坛，上面刻着：‘献给未识之神。’所以，你们所不认识而敬拜的，我现在传给你们。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 8:27; 申命记 10:14; 使徒行传 7:48"> 创造世界和其中万物的上帝，既是天地的主，就不住在人手所造的殿宇里。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 50:8–13; 创世记 2:7; 以赛亚书 42:5"> 祂也不受人手的服侍，好像缺少什么；因为祂自己赐给万人生命、气息和万物。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:7–8; 创世记 3:20; 罗马书 5:12–19"> 祂从一血脉造出万族的人，使他们住在全地面上，并且预先定准他们的时期和居住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 23:23–24; 申命记 4:7; 使徒行传 14:17"> 为要使他们寻求主，或者可以摸索而找到祂；其实祂离我们各人不远。</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 12:10; 歌罗西书 1:17; 希伯来书 1:3"> ‘因为我们在祂里面生活、行动、存有。’正如你们自己的诗人中有人说：‘因为我们也是祂的后裔。’</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 40:25; 出埃及记 20:4; 诗篇 115:4–8"> 既然我们是上帝的后裔，就不该以为神性像金、银、石头，是由人的技艺和构想雕刻出来的。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:16; 提多书 2:11–12; 路加福音 24:47"> 所以，上帝过去宽容了人无知的时代；但如今祂命令各处所有的人都要悔改，</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:31–46; 彼得后书 3:7; 罗马书 2:16"> 因为祂已经定了日子，要借着祂所指定的人，按公义审判世界；祂已经使这人从死人中复活，给万人作了可信的凭据。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 17:18; 使徒行传 26:8; 使徒行传 25:19"> 他们听见死人复活的事，有人讥笑；另有人说：“关于这事，我们还想再听你讲。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 于是保罗从他们中间出去了。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 17:19; 罗马书 11:5–6; 使徒行传 13:48"> 但有几个人贴近他，并且信了，其中有亚略巴古的官丢尼修，还有一个名叫大马哩的妇人，以及其他与他们在一起的人。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:23–28; 哥林多前书 16:12; 哥林多前书 1:12"> 亚波罗在哥林多的时候，保罗经过内陆地区，来到以弗所，遇见几个门徒。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:39; 使徒行传 11:15–17; 加拉太书 3:5"> 他对他们说：“你们信的时候领受了圣灵吗？”<br />他们对他说：“没有，我们甚至没有听说有圣灵。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:25; 哥林多前书 12:13; 使徒行传 8:16"> 他说：“那么你们受的是什么洗呢？”<br />他们说：“是约翰的洗。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:29–34; 使徒行传 11:16; 使徒行传 1:5"> 保罗说：“约翰所施的确实是悔改的洗，他告诉百姓要信那在他以后来的那一位，就是基督耶稣。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 抄本省略“基督”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:12; 使徒行传 8:16; 罗马书 6:3–4"> 他们听见这话，就奉主耶稣的名受洗。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 6:6; 使徒行传 2:4; 马可福音 16:17"> 保罗按手在他们身上，圣灵就临到他们；他们说起别的语言，并且说预言。</span>
<span className="v" id="v7" data-v="7"> 他们总共约有十二个男人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 28:23; 使徒行传 1:3; 使徒行传 9:20–22"> 保罗进了会堂，放胆讲论，持续了三个月，辩论并劝服众人有关上帝国的事。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 19:23; 使徒行传 9:2; 使徒行传 18:6–8"> 但有些人心里刚硬，不顺从，在众人面前毁谤这道，保罗就离开他们，把门徒分别出来，天天在推喇奴的学堂里辩论。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 20:31; 提摩太后书 1:15; 使徒行传 16:6"> 这事持续了两年，以致住在亚细亚的人，无论是犹太人还是希腊人，都听见了主耶稣的道。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 16:17–20; 使徒行传 5:12; 罗马书 15:18–19"> 上帝借着保罗的手行了非同寻常的神迹，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:15; 列王纪下 13:20–21; 马可福音 16:17"> 甚至有人从保罗身上拿手巾或围裙带到病人那里，疾病就离开他们，邪灵也出去了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 12:27; 马可福音 9:38; 路加福音 11:19"> 也有几个游行各处、赶鬼的犹太人，擅自对那些有邪灵的人呼唤主耶稣的名，说：“我们奉保罗所传的耶稣严令你们。”</span>
<span className="v" id="v14" data-v="14"> 有一个犹太祭司长士基瓦的七个儿子这样做。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 16:17–18; 路加福音 4:33–35; 马可福音 1:34"> 邪灵回答说：“耶稣我认识，保罗我也知道；可是你们是谁？”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 马可福音 5:3–4; 马可福音 5:15"> 那有邪灵的人就扑在他们身上，制伏他们，胜过他们，以致他们赤着身子、带着伤，从那房子里逃出去了。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 1:12; 使徒行传 5:5; 腓立比书 2:9–11"> 这事给所有住在以弗所的人知道了，无论是犹太人还是希腊人。众人都惧怕，主耶稣的名也被尊为大。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:10; 诗篇 32:5; 马太福音 3:6"> 许多已经信的人也来，承认并公开述说自己所行的事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:8; 出埃及记 32:20; 创世记 35:4"> 许多行邪术的人把他们的书卷带来，在众人面前焚烧。他们计算书价，发现共有五万银币。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里的五万银币很可能指五万德拉克马。若是如此，被焚书卷的价值相当于农业工人约一百六十人年的工资。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 12:24; 使徒行传 6:7; 以赛亚书 55:11"> 这样，主的道不断增长，越发有能力。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:22; 使徒行传 20:16; 使徒行传 23:11"> 这些事结束以后，保罗在圣灵里定意，经过马其顿和亚该亚以后，就往耶路撒冷去，说：“我到过那里以后，也必须看看罗马。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 16:23; 提摩太后书 4:20; 使徒行传 16:3"> 于是他派服事他的两个人提摩太和以拉都往马其顿去，自己却暂时留在亚细亚。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 19:9; 使徒行传 24:22; 哥林多后书 1:8–10"> 那时，因这道起了不小的骚动。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 6:9–10; 使徒行传 16:16; 使徒行传 16:19"> 有一个名叫底米丢的人，是银匠，制造亚底米的银龛，给工匠们带来不少生意。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:19; 何西阿 12:7–8; 启示录 18:11–19"> 他把他们和同业的工人聚集起来，说：“诸位，你们知道，我们靠这行当发财。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 17:29; 哥林多前书 8:4; 以赛亚书 44:10–20"> 你们也看见、听见，这个保罗不仅在以弗所，也几乎在全亚细亚，劝服并引诱许多人离开，说人手所造的并不是神明。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 2:11; 提摩太前书 6:5; 马太福音 23:13"> 这样，不但我们这行业有被人轻视的危险，而且大女神亚底米的庙也会被看为无有，连全亚细亚和天下所敬拜的她的威荣也要被毁掉。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 13:4; 启示录 17:13; 使徒行传 16:19–24"> 他们听见这话，就怒气填胸，喊着说：“以弗所人的亚底米是伟大的！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 歌罗西书 4:10; 使徒行传 27:2"> 全城都陷入混乱。他们抓住保罗旅行的同伴、马其顿人该犹和亚里达古，齐心冲进剧场。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 21:39; 撒母耳记下 18:2–3; 使徒行传 17:22–31"> 保罗想要进去到民众那里，门徒却不许他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:10; 使徒行传 21:12; 使徒行传 16:6"> 还有几位亚细亚的官长，是他的朋友，也派人来劝他不要冒险进剧场。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 21:34; 使徒行传 19:40; 马太福音 11:7–9"> 因为集会一片混乱，有人喊这个，有人喊那个；大多数人并不知道为什么聚集。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 12:17; 提摩太后书 4:14; 提摩太前书 1:20"> 有人从人群中把亚历山大带出来，是犹太人推他上前。亚历山大摆手，想要向民众申辩。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:28; 马太福音 6:7; 启示录 13:4"> 但他们认出他是犹太人，就异口同声地喊了约两个小时：“以弗所人的亚底米是伟大的！”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:10–11; 提摩太前书 4:2; 以弗所书 2:12"> 城里的书记官使群众安静下来，说：“以弗所人哪，有谁不知道以弗所人的城是大女神亚底米，以及那从宙斯那里降下来的神像的守护者呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行传 5:35–39; 箴言 25:8"> 既然这些事不能否认，你们就应当安静，不可鲁莽行事。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多后书 6:3; 罗马书 2:22; 使徒行传 25:8"> 你们把这些人带来，他们既没有抢劫庙宇，也没有亵渎你们的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:7; 哥林多前书 6:1; 使徒行传 18:14"> 所以，如果底米丢和同他一起的工匠有事要控告谁，法庭是开放的，也有总督；让他们彼此起诉吧。</span>
<span className="v" id="v39" data-v="39"> 但如果你们还寻求别的事，就应当在合法的集会中解决。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 17:5–8; 马太福音 26:5; 使徒行传 20:1"> 至于今天的骚乱，我们确实有被控告的危险，因为没有理由；对于这场骚动，我们无法交代。”</span>
<span className="v" id="v41" data-v="41" data-xref="传道书 9:17; 诗篇 65:7; 哥林多后书 1:8–10"> 他说完这些话，就解散了集会。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 18:19–21; 马太福音 26:61–62; 使徒行传 6:13–14"> 大祭司说：“这些事是真的吗？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:1; 创世记 11:31; 诗篇 29:3"> 司提反说：“弟兄们、父老们，请听。我们的祖先亚伯拉罕在美索不达米亚，还没有住在哈兰以前，荣耀的上帝向他显现，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1; 希伯来书 11:8; 约书亚记 24:3"> 对他说：『你要离开你的土地，离开你的亲族，往我将要指示你的地去。』</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 12:4–5; 创世记 11:31–32; 以赛亚书 41:9"> 于是他离开迦勒底人的地方，住在哈兰。他父亲死后，上帝使他迁到你们现在所住的这地。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:8; 创世记 12:7; 创世记 13:15"> 在这地，上帝没有给他产业，连立足之地也没有，却应许要把这地赐给他和他以后的后裔为产业；那时他还没有孩子。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 15:13; 出埃及记 12:40–41; 加拉太书 3:17"> 上帝这样说：他的后裔必在异地作寄居的，并且他们要被奴役、受虐待四百年。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 3:12; 诗篇 105:27–36; 尼希米记 9:9–11"> 上帝说：『他们所服侍为奴的那国，我要审判；以后他们要出来，在这地方事奉我。』</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:23–26; 创世记 17:9–14; 创世记 21:1–4"> 上帝又赐给他割礼之约。因此亚伯拉罕生了以撒，第八天给他行了割礼；以撒生了雅各；雅各生了十二位族长。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 39:2; 诗篇 105:17; 以赛亚书 43:2"> “族长们嫉妒约瑟，把他卖到埃及；但上帝与他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; 提摩太后书 4:18; 箴言 2:6"> 救他脱离一切患难，又使他在埃及王法老面前得恩宠和智慧。法老立他作埃及和自己全家的总管。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 41:54–57; 创世记 45:11; 创世记 42:5"> 后来，埃及和迦南全地遭遇饥荒和大患难，我们的祖先找不到粮食。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:1–24; 创世记 43:2"> 雅各听说埃及有粮，就第一次打发我们的祖先去。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 45:1–18; 创世记 46:31–10"> 第二次，约瑟向他的弟兄们表明身份，约瑟的家族也被法老知道了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 46:26–27; 申命记 10:22; 出埃及记 1:5"> 约瑟就派人召他的父亲雅各和他全体亲族来，共七十五人。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 49:33; 出埃及记 1:6; 创世记 46:3–7"> 于是雅各下到埃及；他和我们的祖先都死在那里；</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 24:32; 创世记 23:16; 出埃及记 13:19"> 他们被带回示剑，安放在亚伯拉罕用银子出价从示剑的哈抹子孙那里买来的坟墓里。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 1:7–12; 使徒行传 7:6; 使徒行传 13:17"> “上帝向亚伯拉罕起誓应许的时期临近时，百姓在埃及增多起来，人数繁盛，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 1:8"> 直到另有一位不认识约瑟的王兴起。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 105:25; 出埃及记 1:9–22; 启示录 12:4–5"> 这王用诡计对待我们的民族，虐待我们的祖先，强迫他们丢弃婴孩，使婴孩不能存活。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:23; 出埃及记 2:2–10; 撒母耳记上 16:12"> 那时，摩西出生了；他在上帝眼中极其俊美。他在父亲家里被抚养了三个月。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:24; 出埃及记 2:2–10; 申命记 32:26"> 他被丢弃的时候，法老的女儿把他抱起来，抚养他作自己的儿子。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:11; 但以理 1:17–20; 历代志下 9:22"> 摩西受了埃及人一切智慧的教导，在言语和作为上都有能力。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 2:11–12; 箴言 21:1; 希伯来书 11:24–26"> 他到了四十岁的时候，心里起意要去看望他的弟兄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里译为“弟兄”的词，在上下文允许时，也可正确译为“弟兄姊妹”或“手足”。">a</a></sup>，就是以色列的子孙。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:10–11; 使徒行传 7:28; 约翰福音 18:25–27"> 他看见其中一个人受冤屈，就保护他，为那受欺压的人报仇，打死了那个埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:7; 马可福音 9:32; 列王纪下 5:1"> 他以为自己的弟兄们会明白，上帝正藉着他的手赐给他们拯救；可是他们不明白。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 2:13–15; 箴言 18:19; 约翰一书 3:11–15"> “第二天，他遇见他们争斗，就劝他们重新和好，说：『先生们，你们是弟兄，为什么彼此冤屈呢？』</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 7:35; 路加福音 12:14; 使徒行传 7:54"> 但那欺负邻舍的人把他推开，说：『谁立你作我们的官长和审判者？</span>
<span className="v" id="v28" data-v="28"> 难道你想杀我，像昨天杀那埃及人一样吗？』</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 18:2–4; 出埃及记 2:14–22; 出埃及记 4:19–20"> 摩西因这话就逃走，在米甸地作了寄居的人，在那里生了两个儿子。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 3:1–2; 使徒行传 7:35; 以赛亚书 43:2"> “满了四十年，有一位主的使者在西奈山旷野的荆棘火焰中向他显现。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:3–4"> 摩西看见那景象，就感到惊奇。他走近要观看的时候，主的声音临到他：</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马太福音 22:32; 约伯记 4:14"> 『我是你祖先的上帝，就是亚伯拉罕的上帝、以撒的上帝、雅各的上帝。』 摩西战战兢兢，不敢观看。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 3:5; 约书亚记 5:15; 传道书 5:1"> 主对他说：『把你脚上的鞋脱下来，因为你所站的地方是圣地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 3:7–10; 出埃及记 4:31; 诗篇 106:44"> 我确实看见我在埃及的百姓所受的苦难，也听见了他们的叹息。我下来要拯救他们。现在你来，我要差你往埃及去。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:22–23; 路加福音 19:14; 诗篇 113:7–8"> “这位摩西，就是他们曾拒绝说『谁立你作官长和审判者？』的那一位，上帝藉着在荆棘中向他显现的那位使者的手，差他作官长和拯救者。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 12:41; 出埃及记 14:21; 出埃及记 33:1"> 这人领他们出来，在埃及、红海和旷野四十年间行了奇事神迹。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 18:15–19; 使徒行传 3:22–23; 约翰福音 18:37"> 这就是那位对以色列子孙说『主我们的上帝要从你们弟兄中为你们兴起一位先知，像我一样』的摩西。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认文本加上：“你们要听从他。”">b</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 3:2; 希伯来书 5:12; 彼得前书 4:11"> 这就是那位在旷野会众中，与在西奈山向他说话的使者同在，又与我们的祖先同在的人；他领受了活的启示，要传给我们。</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 14:3–4; 民数记 11:5; 尼希米记 9:16–17"> 我们的祖先不肯顺服他，反而拒绝他，心里转回埃及，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 32:1; 出埃及记 32:23"> 对亚伦说：『为我们造一些神明，在我们前面引路；因为这个领我们出埃及地的摩西，我们不知道他遭遇了什么事。』</span>
<span className="v" id="v41" data-v="41" data-xref="诗篇 106:19–21; 尼希米记 9:18; 启示录 9:20"> 那些日子，他们造了一只牛犊，把祭物献给那偶像，并因自己手所造的而欢喜。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司 5:25–26; 以西结 20:39; 耶利米书 19:13"> 于是上帝转脸离开他们，任凭他们事奉天上的军队，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这个习语也可译为“天上的万象”、“天使性存在”或“天体”。">c</a></sup>正如先知书上所写的：<br /><span className="pl pl-1">『以色列家啊，你们在旷野四十年，</span><br /><span className="pl pl-2">难道曾把被宰的牲畜和祭物献给我吗？</span></span>
<span className="v" id="v43" data-v="43" data-xref="阿摩司 5:26–27; 出埃及记 20:4–5; 申命记 5:8–9"> <span className="pl pl-1">你们抬着摩洛的帐幕，</span><br /><span className="pl pl-2">和你们神利番的星，</span><br /><span className="pl pl-1">就是你们所造、为要敬拜的形像；</span><br /><span className="pl pl-2">所以我要把你们迁到巴比伦之外。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="出埃及记 25:40; 出埃及记 38:21; 希伯来书 8:5"> “我们的祖先在旷野有见证的帐幕，是照那向摩西说话的那一位所吩咐的，按着摩西所看见的样式造的；</span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 44:2; 约书亚记 18:1; 约书亚记 23:9"> 后来，我们的祖先随同约书亚把这帐幕带进来，当他们承受那些列国的土地时，上帝把那些列国从我们祖先面前赶出去，直到大卫的日子。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 132:1–5; 使徒行传 13:22; 撒母耳记下 7:1–5"> 大卫在上帝面前蒙恩，祈求为雅各的上帝寻找居所。</span>
<span className="v" id="v47" data-v="47" data-xref="列王纪上 8:20; 列王纪上 6:37–38; 撒母耳记下 7:13"> 但所罗门为祂建造了殿。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 17:24–25; 以赛亚书 66:1–2; 列王纪上 8:27"> 然而，至高者并不住在人手所造的殿宇里，正如先知所说：</span>
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 66:1; 诗篇 11:4; 约翰福音 4:21"> <span className="pl pl-1">『天是我的宝座，</span><br /><span className="pl pl-2">地是我脚的踏凳。</span><br /><span className="pl pl-1">主说：你们要为我建造什么样的殿呢？</span><br /><span className="pl pl-2">或者，哪里是我安息的地方呢？</span></span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 32:17; 诗篇 33:6–9; 使徒行传 14:15"> <span className="pl pl-1">这一切不都是我的手所造的吗？』</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="申命记 10:16; 以弗所书 4:30; 以赛亚书 63:10"> “你们这些硬着颈项、心和耳未受割礼的人，总是抗拒圣灵！你们的祖先怎样，你们也怎样。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 5:12; 历代志下 36:16; 列王纪上 19:10"> 哪一位先知不是你们的祖先所迫害的呢？他们杀了那些预告那义者来临的人；如今你们竟成了出卖祂、杀害祂的人。</span>
<span className="v" id="v53" data-v="53" data-xref="希伯来书 2:2; 加拉太书 3:19; 使徒行传 7:38"> 你们领受了按天使所颁布的律法，却没有遵守！”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒行传 5:33; 诗篇 35:16; 马太福音 25:30"> 众人听见这些话，心里被刺痛，就向他咬牙切齿。</span>
<span className="v" id="v55" data-v="55" data-xref="马可福音 16:19; 希伯来书 1:3; 哥林多后书 4:6"> 但司提反满有圣灵，定睛望天，看见上帝的荣耀，又看见耶稣站在上帝的右边，</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 26:64–65; 使徒行传 10:11; 启示录 11:19"> 就说：“看哪，我看见诸天开了，人子站在上帝的右边！”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="撒迦利亚书 7:11; 诗篇 58:4; 使徒行传 23:27"> 众人大声喊叫，捂住耳朵，同心合意地向他冲过去。</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行传 22:20; 使徒行传 8:1; 使徒行传 6:13"> 他们把他推出城外，用石头打他。作见证的人把自己的衣服放在一个名叫扫罗的年轻人脚前。</span>
<span className="v" id="v59" data-v="59" data-xref="路加福音 23:46; 诗篇 31:5; 使徒行传 22:16"> 他们用石头打司提反；他呼求着说：“主耶稣，接纳我的灵！”</span>
<span className="v" id="v60" data-v="60" data-xref="马太福音 5:44; 路加福音 23:34; 哥林多前书 15:20"> 他跪下来，大声喊着说：“主啊，不要把这罪归在他们身上！”说完这话，他就睡了。</span>
</div>
</div>

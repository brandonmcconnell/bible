<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 2:17; 路加福音 5:4; 撒母耳记上 20:41–42"> 我们离别他们，开船启航，就直航到哥士，第二天到罗得，又从那里到帕大喇。</span>
<span className="v" id="v2" data-v="2" data-xref="约拿 1:3; 使徒行传 11:19; 使徒行传 15:3"> 我们找到一艘要渡海去腓尼基的船，就上船启航。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 21:16; 使徒行传 4:36; 马太福音 4:24"> 我们望见塞浦路斯，就把它留在左边，向叙利亚航行，在推罗登陆，因为船要在那里卸货。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 20:22–23; 使徒行传 21:10–12; 使徒行传 20:6–7"> 我们找到一些门徒，就在那里住了七天。他们借着圣灵对保罗说，不要上耶路撒冷去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 20:36; 使徒行传 9:40; 诗篇 95:6"> 那几天过了，我们就离开，继续行程。他们众人连妻子儿女都送我们，直到城外。我们在海滩上跪下祷告。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:27; 约翰福音 1:11; 哥林多后书 2:13"> 彼此辞别以后，我们上了船，他们也回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:24; 撒母耳记上 10:4; 使徒行传 28:12"> 我们从推罗完成了航程，来到多利买。我们问候了弟兄们，和他们同住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 6:5; 使徒行传 8:26–40; 以弗所书 4:11"> 第二天，我们这些与保罗同行的人离开，来到凯撒利亚。<br />我们进了传福音者腓利的家，住在他那里；他是那七人之一。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 2:17; 启示录 2:20; 约珥 2:28"> 这人有四个女儿，都是童女，会说预言。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 11:28; 使徒行传 21:4; 使徒行传 20:16"> 我们在那里住了好些天，有一位先知，名叫亚迦布，从犹太下来。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:33; 耶利米书 13:1–11; 撒母耳记上 15:27–28"> 他来到我们这里，拿起保罗的腰带，捆住自己的脚和手，说：“圣灵这样说：『在耶路撒冷，犹太人也要这样捆绑这腰带的主人，把他交在外邦人手中。』”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:21–23; 使徒行传 20:22; 使徒行传 21:4"> 我们听见这些话，就和当地的人一起恳求保罗不要上耶路撒冷去。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:24; 腓立比书 2:17; 腓立比书 1:20–21"> 于是保罗回答说：“你们为什么哭泣，使我心碎呢？我为主耶稣的名，不但准备好被捆绑，也准备好在耶路撒冷死。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 马太福音 26:42; 马太福音 26:39"> 既然他不肯被劝服，我们就不再说了，只说：“愿主的旨意成就。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1; 使徒行传 25:6; 使徒行传 25:9"> 过了这些日子，我们收拾行装，上耶路撒冷去。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行传 21:8; 诗篇 92:14"> 也有几个凯撒利亚的门徒和我们一同去，带着一位塞浦路斯人拿孙；他是早期的门徒，我们要住在他那里。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 15:4; 罗马书 15:7; 希伯来书 13:1–2"> 我们到了耶路撒冷，弟兄们欢喜地接待我们。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 1:19; 加拉太书 2:9; 使徒行传 15:13"> 第二天，保罗同我们去见雅各；所有长老也都在场。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:27; 使徒行传 1:17; 罗马书 15:18–19"> 保罗问候了他们，就一一述说上帝借着他的事奉在外邦人中所做的事。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2; 加拉太书 1:14; 使徒行传 22:3"> 他们听了，就荣耀上帝。他们对保罗说：“弟兄，你看，犹太人中信的人有好几千，他们都为律法热心。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:12–15; 哥林多前书 9:19–21; 加拉太书 5:1–6"> 他们听人说，你教导所有在外邦人中的犹太人背弃摩西，告诉他们不要给孩子行割礼，也不要遵行那些习俗。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:12; 使徒行传 15:22; 使徒行传 19:32"> 那么怎么办呢？会众必定会聚集，因为他们会听说你来了。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 18:18; 民数记 6:2–7"> 所以，你要照我们告诉你的去做。我们这里有四个人已经许了愿。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:26; 使徒行传 24:18; 使徒行传 18:18"> 你带他们去，和他们一同洁净自己，并替他们出费用，好让他们剃头。这样，众人就会知道，他们所听说关于你的事都不是真的，反而知道你自己也是遵行律法的人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:29; 使徒行传 15:19–20"> 至于信的外邦人，我们已经写信决定：他们不必遵守这样的事，只要禁戒祭偶像之物、血、勒死的牲畜和淫乱。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 24:18; 使徒行传 21:24; 民数记 6:13–20"> 于是保罗带着那几个人，第二天和他们一同洁净自己，进了圣殿，宣告洁净日期的满期，直到为他们每一个人献上供物。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:21; 使徒行传 24:18; 使徒行传 13:50"> 那七天快满的时候，从亚细亚来的犹太人看见保罗在圣殿里，就煽动所有群众，下手抓住他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 24:5–6; 使徒行传 21:21; 使徒行传 26:20–21"> 喊叫说：“以色列人哪，快来帮忙！这就是那个到处教导众人攻击本民族、律法和这地方的人。不但如此，他还带希腊人进了圣殿，玷污了这圣地！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 提摩太后书 4:20; 使徒行传 18:19"> 原来他们曾看见以弗所人特罗非摩和保罗在城里，就以为保罗带了他进圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:21; 哥林多后书 11:26; 使徒行传 16:19–22"> 全城都震动起来，百姓一同跑来。他们抓住保罗，把他拖出圣殿，门立刻关了。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 11:23–33; 使徒行传 17:5; 使徒行传 26:9–10"> 他们正想杀他，有消息传到营里的千夫长那里，说全耶路撒冷都乱了。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:27; 以赛亚书 3:15; 使徒行传 5:40"> 千夫长立刻带着士兵和百夫长，跑下去到他们那里。他们看见千夫长和士兵，就停止殴打保罗。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:20; 使徒行传 21:11; 使徒行传 20:23"> 于是千夫长走近，逮捕了保罗，命令用两条铁链捆绑他，又查问他是什么人，做了什么事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:32; 使徒行传 23:10; 使徒行传 22:24"> 人群中有的喊这个，有的喊那个。千夫长因为喧嚷无法查明实情，就命令把保罗带进营楼。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="哈巴谷 1:2–3; 诗篇 55:9; 诗篇 58:2"> 保罗到了台阶那里，因为群众十分凶猛，就被士兵抬着走；</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 19:15; 使徒行传 22:22; 路加福音 23:18"> 因为一大群百姓跟在后面，喊着：“除掉他！”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:34; 路加福音 21:15; 使徒行传 19:30"> 保罗快要被带进营楼的时候，对千夫长说：“我可以对你说句话吗？”<br />他说：“你会希腊话吗？</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 24:26; 使徒行传 5:36–37; 马太福音 5:11"> 你不就是前些日子煽动叛乱，带领四千名刺客党人到旷野去的那个埃及人吗？”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 22:3; 使徒行传 9:11; 使徒行传 23:27"> 保罗说：“我是犹太人，来自基利家的大数，是一个并非无名小城的公民。求你准我对百姓说话。”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:2; 使徒行传 28:17; 使徒行传 13:26"> “弟兄们、父老们，请听我现在向你们所作的申辩。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 21:40"> 他们听见他用希伯来语对他们说话，就更加安静了。<br />他说：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:5; 腓立比书 3:5–6; 使徒行传 9:11"> “我确实是犹太人，生在基利家的大数，却在这城长大，在迦玛列脚前，按着我们祖宗律法的严格传统受教，热心侍奉上帝，就像你们今天众人一样。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 22:19–20; 提摩太前书 1:13–15; 使徒行传 26:9–11"> 我曾逼迫这道，直到置人于死地，把男人和女人都捆绑起来，交进监牢。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:1–2; 路加福音 22:66; 使徒行传 5:21"> 大祭司和众长老全体也可以为我作证。我又从他们那里领了给弟兄们的书信，前往大马士革，要把在那里的人也捆绑起来，带到耶路撒冷受刑罚。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:3–8; 使徒行传 26:12–18; 启示录 1:16"> “我在途中将近大马士革的时候，约在正午，忽然有大光从天上四面照着我。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:9; 马太福音 25:45; 创世记 22:11"> 我就仆倒在地，听见有声音对我说：<span className="woj">‘扫罗，扫罗，你为什么逼迫我？’</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:9; 撒母耳记上 8:7; 出埃及记 16:7–8"> 我回答说：‘主啊，你是谁？’祂对我说：<span className="woj">‘我就是你所逼迫的拿撒勒人耶稣。’</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:7; 但以理 10:7; 使徒行传 26:13"> “和我同行的人确实看见了那光，也害怕，却没有听明白那对我说话者的声音。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:30; 使徒行传 22:12–16; 使徒行传 2:37"> 我说：‘主啊，我该做什么？’主对我说：<span className="woj">‘起来，进大马士革去；在那里，凡指定你要做的一切事，都会有人告诉你。’</span></span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 9:8–9; 使徒行传 13:11; 以赛亚书 42:16"> 因那光的荣耀，我不能看见，就被同行的人牵着手，进了大马士革。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:22; 使徒行传 6:3; 约翰三书 1:12"> “有一个人名叫亚拿尼亚，按着律法是虔诚的人，受所有住在大马士革的犹太人称赞。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:17–18; 腓利门书 1:16"> 他到我这里来，站在旁边对我说：‘扫罗弟兄，重见光明吧！’就在那一刻，我抬头看见了他。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:12; 哥林多前书 15:8; 哥林多前书 9:1"> 他说：‘我们祖宗的上帝已经拣选了你，使你知道祂的旨意，又看见那位义者，并听见从祂口中发出的声音。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:11; 使徒行传 4:20; 约翰福音 15:27"> 因为你要把所看见、所听见的，向众人为祂作见证。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 2:21; 提多书 3:5"> 现在你为什么耽延呢？起来，受洗，呼求主的名，洗去你的罪。’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 12:1–4; 使徒行传 10:9–10; 使徒行传 9:26–28"> “后来我回到耶路撒冷，在圣殿里祷告的时候，进入异象之中，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:29; 路加福音 21:21; 以西结 3:6–7"> 看见祂对我说：<span className="woj">‘赶快，速速离开耶路撒冷，因为他们不会接受你为我作的见证。’</span></span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 22:4; 马太福音 10:17; 使徒行传 8:3"> 我说：‘主啊，他们自己知道，我曾把信你的人关进监牢，又在各会堂里鞭打他们。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:58; 使徒行传 8:1; 罗马书 1:32"> 你的见证人司提反流血的时候，我也站在旁边，赞同他被处死，并看守那些杀他之人的外衣。’</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:15; 提摩太前书 2:7; 以弗所书 3:6–8"> “祂对我说：<span className="woj">‘你去吧，因为我要差你远远地到外邦人那里去。’</span>”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:24; 使徒行传 21:36; 约翰福音 19:15"> 众人听他说到这句话，就扬声说：“这样的人要从地上除掉！他是不配活着的！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:13; 使徒行传 26:11; 传道书 10:3"> 他们喊叫，甩掉外衣，又把尘土扬在空中。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:31–32; 使徒行传 21:34; 约翰福音 19:1"> 千夫长命令把保罗带进营楼，吩咐用鞭打拷问他，好知道他们为什么这样喊叫控告他。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:37; 使徒行传 25:16; 使徒行传 27:43"> 他们用皮带捆绑他的时候，保罗问站在旁边的百夫长：“一个罗马人，还没有定罪，你们鞭打他是合法的吗？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 23:27; 使徒行传 22:29"> 百夫长听见这话，就去告诉千夫长说：“你要做的事可要小心，因为这个人是罗马人！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 千夫长来问他说：“告诉我，你是罗马人吗？”<br />他说：“是。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 千夫长回答说：“我花了大价钱才买到这个公民身份。”<br />保罗说：“我生来就是罗马人。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 21:33; 使徒行传 22:24–26; 使徒行传 16:38–39"> 于是那些要拷问他的人立刻离开了他。千夫长知道他是罗马人，又因为曾经捆绑了他，也害怕起来。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:28; 使徒行传 21:33; 使徒行传 21:11"> 第二天，千夫长想要确实知道保罗为什么被犹太人控告，就解开他的捆绑，命令祭司长们和全公会聚集，然后把保罗带下去，叫他站在他们面前。</span>
</div>

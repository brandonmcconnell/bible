<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:6; 使徒行传 15:5; 利未记 12:3"> 有几个人从犹太下来，教导弟兄们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里译为“弟兄们”的词，在上下文允许的地方，也可以正确译为“弟兄姊妹”或“手足”。">a</a></sup>说：“你们若不照摩西的规矩受割礼，就不能得救。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 15:22–23; 使徒行传 15:6–7; 加拉太书 2:1–2"> 保罗和巴拿巴与他们发生了不小的纷争和辩论，于是众人就指派保罗、巴拿巴和他们中间的另外几个人，为这问题上耶路撒冷去见使徒和长老。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 14:27; 使徒行传 21:5; 哥林多前书 16:11"> 他们蒙教会送行，经过腓尼基和撒玛利亚，述说外邦人的归主，使众弟兄都大大欢喜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:27; 使徒行传 15:12; 使徒行传 15:3"> 到了耶路撒冷，他们受到教会、使徒和长老的接待，就报告上帝借着他们所做的一切事。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:1–3; 腓立比书 3:5–8; 使徒行传 15:1"> 但有几个信了主的法利赛派的人起来说：“必须给他们行割礼，并吩咐他们遵守摩西的律法。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯来书 13:7; 希伯来书 13:17"> 使徒和长老聚集在一起，要察看这件事。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 10:17–18; 加拉太书 2:7–9; 历代志上 28:4–5"> 经过许多辩论后，彼得站起来，对他们说：“弟兄们，你们知道，早在从前，上帝就在你们中间作了拣选，要借我的口使外邦人听见福音的话语而相信。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:24; 使徒行传 10:47; 使徒行传 14:3"> 知道人心的上帝为他们作了见证，把圣灵赐给他们，正如赐给我们一样。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:6; 加拉太书 5:6; 使徒行传 10:28"> 祂在我们和他们之间没有作任何分别，借着信洁净了他们的心。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:1; 马太福音 23:4; 加拉太书 4:9"> 现在，你们为什么试探上帝，要把我们祖先和我们都不能负的轭放在门徒的颈项上呢？</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:24; 提多书 3:4–7; 提多书 2:11"> 不，我们相信，我们得救是借着主耶稣的恩典，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认文本加“基督”。">b</a></sup>正如他们一样。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 14:27; 使徒行传 15:4; 使徒行传 21:19"> 全会众都静默下来，听巴拿巴和保罗述说上帝借着他们在外邦人中所行的神迹奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:17; 加拉太书 2:12; 雅各书 1:1"> 他们静默以后，雅各回答说：“弟兄们，请听我说。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:1; 使徒行传 15:7–9; 路加福音 2:31–32"> 西缅已经述说，上帝起初怎样眷顾外邦人，从他们中间取出一群百姓归于自己的名。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:8–12; 使徒行传 13:47"> 这与众先知的话相合。正如经上所记：</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司 9:11–12; 诗篇 89:35–49; 路加福音 1:31–33"> <span className="pl pl-1">‘这些事以后，我要回来。</span><br /><span className="pl pl-1">我要重新建造大卫倒塌的帐幕；</span><br /><span className="pl pl-1">我要重新建造它的废墟，</span><br /><span className="pl pl-1">我要把它立起来，</span></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 2:11; 撒迦利亚书 8:20–23; 以赛亚书 65:1"> <br /><span className="pl pl-1">好使其余的人寻求主，</span><br /><span className="pl pl-1">就是所有称为我名下的外邦人。</span><br /><span className="pl pl-1">这是行这一切事的主说的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:4; 以弗所书 3:9; 以赛亚书 46:9–10"> “上帝一切的作为，祂从亘古以来都知道。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 15:28; 加拉太书 1:7–10; 使徒行传 15:24"> 所以我的判断是：不要难为那些从外邦人中归向上帝的人，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:29; 启示录 2:20; 利未记 3:17"> 只要写信给他们，叫他们禁戒偶像的污秽、淫乱、勒死的牲畜和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:15; 使徒行传 13:27; 哥林多后书 3:14–15"> 因为从古以来，摩西在各城都有传讲他的人，每个安息日在会堂里诵读。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:27; 使徒行传 15:40; 帖撒罗尼迦前书 1:1"> 那时，使徒、长老和全教会都认为好，就从他们中间拣选人，和保罗、巴拿巴一同差往安提阿去；他们就是称为巴撒巴的犹大和西拉，都是弟兄中的领袖。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里译为“弟兄”的词，在上下文允许的地方，也可以正确译为“弟兄姊妹”或“手足”。">c</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:26; 雅各书 1:1; 加拉太书 1:21"> 他们借这些人的手写道：<br />“使徒、长老和弟兄们，问候在安提阿、叙利亚和基利家属外邦人的弟兄们。</span>
<span className="v" id="v24" data-v="24" data-xref="加拉太书 5:12; 加拉太书 5:10; 使徒行传 15:1"> 我们听说有几个人从我们这里出去，用话语搅扰你们，扰乱你们的心灵，说：‘你们必须受割礼并遵守律法。’其实我们并没有吩咐他们。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得后书 3:15; 使徒行传 1:14; 使徒行传 15:2"> 所以我们同心合意，认为好，就拣选几个人，差他们同我们所爱的巴拿巴和保罗到你们那里去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:19; 使徒行传 9:23–25; 腓立比书 2:29–30"> 这两个人曾为我们主耶稣基督的名冒生命危险。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 15:22; 使徒行传 15:32; 约翰三书 1:13"> 因此，我们差了犹大和西拉去，他们也要亲口把同样的事告诉你们。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:13; 启示录 2:24; 马太福音 11:30"> 因为圣灵和我们都认为好，不把别的重担加在你们身上，只把这些必要的事加给你们：</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:20; 使徒行传 21:25; 启示录 2:14"> 就是禁戒祭偶像之物、血、勒死的牲畜和淫乱。你们若能谨守不犯这些事，就好了。愿你们平安。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 16:4; 使徒行传 6:2; 使徒行传 23:33"> 于是，他们被差遣，就下到安提阿；他们聚集了会众，把信交给他们。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:4–5; 腓立比书 3:3; 加拉太书 5:1"> 众人读了，就因这劝勉而欢喜。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 11:23; 使徒行传 14:22; 使徒行传 13:1"> 犹大和西拉自己也是先知，就用许多话劝勉弟兄们，坚固他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 16:11; 使徒行传 16:36; 希伯来书 11:31"> 他们在那里住了一些时候，弟兄们就平平安安地送他们回到使徒那里。</span>
<span className="v" id="v34" data-v="34"> <sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有些抄本添加：但西拉认为留在那里是好的。">d</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 4:2; 歌罗西书 1:28; 使徒行传 13:1"> 但保罗和巴拿巴仍住在安提阿，和许多别人一同教导并传讲主的话语。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 14:6; 使徒行传 13:4; 使徒行传 13:51"> 过了些日子，保罗对巴拿巴说：“我们现在回去，探望我们在各城中曾传讲主话语的弟兄们，看看他们怎样。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 13:5"> 巴拿巴打算把称为马可的约翰也带上。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:13; 箴言 25:19; 路加福音 14:27–34"> 但保罗认为，带上这个曾在旁非利亚离开他们、不和他们同去做工的人，并不合适。</span>
<span className="v" id="v39" data-v="39" data-xref="歌罗西书 4:10; 传道书 7:20; 使徒行传 4:36"> 于是争执变得十分激烈，以致他们彼此分开。巴拿巴带着马可，坐船往塞浦路斯去；</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 15:22; 使徒行传 14:26; 使徒行传 11:23"> 保罗却拣选了西拉，也出发了；弟兄们把他交托在上帝的恩典中。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 15:23; 加拉太书 1:21; 使徒行传 15:32"> 他走遍叙利亚和基利家，坚固众教会。</span>
</div>
</div>

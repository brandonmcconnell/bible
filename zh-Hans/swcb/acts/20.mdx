<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="20" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 7:5; 使徒行传 19:21; 提摩太前书 1:3"> 骚乱平息以后，保罗请门徒来，向他们告别，就离开往马其顿去。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 2:3; 帖撒罗尼迦前书 4:1; 歌罗西书 1:28"> 他走遍了那些地区，用许多话勉励他们，然后来到希腊。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:19; 哥林多后书 11:26; 使徒行传 9:23–24"> 他在那里住了三个月，正要坐船去叙利亚的时候，犹太人设计要害他，他就决定从马其顿回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:29; 以弗所书 6:21; 提摩太后书 4:20"> 与他同行到亚细亚的，有庇哩亚人所巴特，帖撒罗尼迦人亚里达古和西公都，特庇人该犹，提摩太，以及亚细亚人推基古和特罗非摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:8; 使徒行传 16:10–11; 提摩太后书 4:13"> 这些人先走，在特罗亚等候我们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:3; 使徒行传 16:12; 出埃及记 23:15"> 除酵节以后，我们从腓立比开船，五天后来到特罗亚他们那里，在那里住了七天。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 16:2; 使徒行传 2:42; 约翰福音 20:19"> 七日的第一日，门徒聚集擘饼的时候，保罗与他们谈论，因为打算第二天离开，就一直讲到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:13; 路加福音 22:12"> 我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认经文读作“他们”，而不是“我们”">a</a></sup>聚集的楼上，有许多灯。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 13:36; 马太福音 26:40–41; 约拿 1:5–6"> 有一个名叫犹推古的少年人坐在窗台上，沉沉地睡着。保罗讲得更久，他因睡熟了，就从三楼掉下去，被扶起来时已经死了。</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 5:39; 马太福音 9:23–24; 列王纪上 17:21–22"> 保罗下去，伏在他身上，抱着他说：“不要惊慌，因为他的生命还在他里面。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 20:7; 使徒行传 20:9"> 保罗上楼，擘饼吃了，又同他们谈论了很久，直到天亮，然后离开。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:16; 帖撒罗尼迦前书 5:14; 哥林多后书 1:4"> 他们把那孩子活活地带来，众人就大得安慰。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 6:46; 马可福音 1:35; 马可福音 6:31–33"> 我们先上船，开往亚朔，打算在那里接保罗上船；因为他是这样安排的，自己打算走陆路。</span>
<span className="v" id="v14" data-v="14"> 他在亚朔与我们会合，我们就接他上船，来到米推利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 4:20; 使徒行传 20:17"> 从那里开船，第二天来到基阿对面；再过一天，我们停靠在撒摩，并在特罗基利停留；又过一天，来到米利都。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:8; 使徒行传 2:1; 使徒行传 19:21"> 因为保罗已经决定越过以弗所航行，免得在亚细亚耽搁时间；他正赶路，如果可能，要在五旬节那天到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多书 1:5; 使徒行传 11:30; 提摩太前书 5:17"> 保罗从米利都派人到以弗所，请教会的长老来见他。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 1:5–6; 使徒行传 18:19; 使徒行传 19:1"> 他们来到他那里，他就对他们说：“你们自己知道，从我踏进亚细亚的第一天起，我在你们中间一直怎样为人，</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:24; 哥林多后书 2:4; 罗马书 12:11"> 怎样以完全谦卑的心，带着许多眼泪，又因犹太人的计谋而遭遇试炼，服侍主；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:27; 提摩太后书 4:2; 使徒行传 5:42"> 你们也知道，凡对你们有益的事，我没有一样避讳不传给你们，并且在公众面前和各家各户教导你们，</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:38; 使徒行传 11:18; 约翰一书 5:11–13"> 向犹太人和希腊人见证向上帝悔改，并且信靠我们的主耶稣。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认经文加有“基督”">b</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 4:14; 哥林多后书 5:14; 彼得后书 1:14"> 现在，看哪，我受圣灵约束，往耶路撒冷去，不知道在那里会遭遇什么事；</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 9:16; 帖撒罗尼迦前书 3:3; 使徒行传 21:4"> 只知道圣灵在各城向我作见证，说捆锁和患难等着我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:6–8; 哥林多后书 4:1; 哥林多后书 12:10"> 但是这些事我都不看为重要；我也不以自己的性命为宝贵，只要我可以欢欢喜喜跑完我的路程，完成我从主耶稣所领受的职分，充分见证上帝恩典的福音。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 28:31; 使徒行传 20:38; 马太福音 4:23"> “现在，看哪，我知道你们所有人，就是我在你们中间来往传讲上帝国的人，都不会再见我的面了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:6; 以西结 3:18–21; 以西结 33:2–9"> 因此我今日向你们作见证：众人的血与我无关，</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 20:20; 帖撒罗尼迦前书 2:4; 加拉太书 1:7–10"> 因为上帝全部的旨意，我没有避讳不传给你们。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:2–3; 提摩太前书 4:16; 以赛亚书 40:11"> 所以，你们要谨慎自己，也要谨慎全群；圣灵立你们在其中作监督，要牧养主和<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="公认经文、联合圣经公会文本省略“主和”">c</a></sup>上帝的教会，就是祂用自己的血买来的。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 7:15; 彼得后书 2:1; 约翰福音 10:12"> 我知道，我离开以后，凶暴的狼必进入你们中间，不顾惜羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 1:19–20; 提摩太后书 4:3–4; 箴言 23:33"> 就是你们自己中间，也会有人起来说歪曲的话，要引诱门徒跟从他们。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:8; 使徒行传 20:19; 使徒行传 19:10"> 所以你们要警醒，记得三年之久，我昼夜不住地流泪劝戒各人。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 1:12; 以弗所书 1:14; 歌罗西书 3:24"> 现在，弟兄们，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这里译为“弟兄们”的词，在上下文允许时，也可正确译为“弟兄姊妹们”或“手足们”。">d</a></sup>我把你们交托给上帝和祂恩典的话；这话能够建造你们，并且在一切成圣的人中间赐给你们基业。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 11:9; 哥林多前书 9:12; 哥林多前书 9:18"> 我没有贪图任何人的银子、金子或衣服。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 18:3; 哥林多前书 4:12; 帖撒罗尼迦后书 3:8–9"> 你们自己知道，这两只手供给了我和与我同在之人的需要。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 13:16; 箴言 19:17; 哥林多后书 9:6–12"> 我在一切事上给你们作榜样，叫你们这样劳苦，应当帮助软弱的人，并且记念主耶稣的话，祂自己说过：<span className="woj">‘施比受更有福。’</span>”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 21:5; 路加福音 22:41; 腓立比书 4:6"> 他说完这些话，就跪下同众人祷告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 1:4; 哥林多前书 16:20; 帖撒罗尼迦前书 5:26"> 众人都痛哭，抱着保罗的颈项亲吻他，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 15:3; 哥林多前书 16:11; 使徒行传 20:25"> 最叫他们忧伤的，是他说他们不会再见他的面那句话。于是他们送他上船。</span>
</div>
</div>

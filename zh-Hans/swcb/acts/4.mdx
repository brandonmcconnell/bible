<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行传 6:12; 使徒行传 23:6–9"> 他们对百姓说话的时候，祭司们、圣殿守卫长和撒都该人来到他们那里，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:18; 帖撒罗尼迦前书 4:13–14; 使徒行传 24:14–15"> 因为他们教导百姓，并且在耶稣里宣告死人复活，就很烦恼。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 5:18; 马太福音 10:16–17; 使徒行传 16:19–24"> 他们下手拿住他们，把他们拘押到第二天，因为那时已经是晚上了。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:41; 哥林多后书 2:14–17; 提摩太后书 2:9–10"> 但听见这道的人有许多信了，男子的人数约有五千。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 4:8; 马太福音 27:1–2; 路加福音 20:1"> 第二天早晨，他们的官长、长老和文士聚集在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 约翰福音 18:24; 马太福音 26:3"> 大祭司亚那在那里，还有该亚法、约翰、亚历山大，以及大祭司的亲族。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:23; 马可福音 11:28; 使徒行传 5:40"> 他们叫彼得和约翰站在中间，就查问说：“你们凭什么能力，或奉什么名做这事？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 马太福音 10:19–20; 使徒行传 2:4"> 于是彼得被圣灵充满，对他们说：“百姓的官长和以色列的长老们，</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:15–17; 使徒行传 3:7; 约翰福音 10:32"> 如果今天我们因一个瘸腿的人所得的善事受审问，要问他是怎样得了痊愈，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29–32; 使徒行传 3:6; 使徒行传 2:36"> 那么，你们众人和以色列全体百姓都当知道：是奉拿撒勒人耶稣基督的名，就是你们所钉十字架、上帝使祂从死人中复活的那一位，靠着祂，这个人健全地站在你们面前。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 马可福音 12:10–12"> 这位就是‘你们这些建造者所看为无用的石头，已经成了房角的头块石头。’</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 14:6; 哥林多前书 3:11; 约翰福音 3:36"> 除祂以外，别无救恩；因为在天下人间，没有赐下别的名，使我们必须靠着得救！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 约翰福音 7:15; 马太福音 11:25"> 他们看见彼得和约翰的胆量，又察觉他们是没有受过学问的普通人，就很惊奇；他们认出他们曾跟过耶稣。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 19:36; 使徒行传 3:8–12; 使徒行传 4:21"> 又看见那得了医治的人和他们一同站着，就无话可驳。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 26:30–32; 使徒行传 5:34–42; 马太福音 5:22"> 于是他们吩咐彼得和约翰离开议会，退到外面，然后彼此商议，</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行传 6:10; 约翰福音 12:18"> 说：“我们该怎样处置这两个人呢？因为确实有一个明显的神迹藉着他们行出来，凡住在耶路撒冷的人都清楚看见，我们也不能否认。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:28; 罗马书 15:18–22; 使徒行传 5:24"> 但为免这事在百姓中进一步传开，我们要警告他们，从今以后不可再奉这名对任何人讲话。”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:40; 路加福音 24:46–48; 使徒行传 5:20"> 他们就叫了彼得和约翰来，命令他们一概不可奉耶稣的名说话，也不可教导。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:29; 出埃及记 1:17; 哥林多前书 10:15"> 但彼得和约翰回答他们说：“在上帝面前，听从你们而不听从上帝是否正确，你们自己判断吧；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 22:15; 耶利米书 20:9; 哥林多前书 9:16–17"> 因为我们所看见、所听见的，不能不说。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:26; 马太福音 21:46; 路加福音 22:2"> 官长们又威胁他们，然后释放了他们；因为百姓的缘故，他们找不到办法惩罚他们，因为众人都为所发生的事荣耀上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:5; 使徒行传 9:33; 路加福音 13:11"> 原来那蒙这医治神迹的人已经四十多岁了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:14–17; 使徒行传 12:11–12; 诗篇 119:63"> 他们被释放以后，就来到自己的同伴那里，把祭司长们和长老们对他们所说的一切都报告了。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:11; 耶利米书 32:17; 尼希米记 9:6"> 他们听见了，就同心合意地向上帝扬声说：“主啊，你是上帝，就是创造天、地、海和其中万物的那一位；</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–6; 使徒行传 1:16; 使徒行传 2:30"> 你曾藉着你仆人大卫的口说：<br /><span className="pl pl-1">‘列国为什么喧嚷，</span><br /><span className="pl pl-2">万民为什么谋算虚妄的事？</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:2; 启示录 17:12–14; 但以理 9:24"> <span className="pl pl-1">地上的君王一同起来，</span><br /><span className="pl pl-2">官长们聚集商议，</span><br /><span className="pl pl-2">要敌挡主，并敌挡祂的基督。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基督（希腊语）和弥赛亚（希伯来语）的意思都是“受膏者”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 27:2; 使徒行传 4:30; 路加福音 9:22"> “因为真的，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU文本加上“在这城里，”">b</a></sup>希律和本丢·彼拉多，连同外邦人和以色列民，都聚集起来敌挡你所膏立的圣仆耶稣，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:23; 以赛亚书 46:10; 创世记 50:20"> 要成就你手和你的旨意所预定要发生的一切事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:13; 使徒行传 14:3; 腓立比书 1:14"> 现在，主啊，求你察看他们的威胁，并赐给你的仆人们大有胆量讲你的道；</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 4:27; 使徒行传 3:6; 使徒行传 5:12"> 同时伸出你的手来医治，并使神迹奇事藉着你圣仆耶稣的名行出来。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 21:22; 使徒行传 2:2; 使徒行传 2:4"> 他们祷告完了，聚集的地方震动起来；他们都被圣灵充满，就放胆讲论上帝的道。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:10; 以弗所书 4:2–6; 彼得前书 3:8"> 信的人群都同有一颗心、一个灵魂。没有一个人说自己所拥有的有一样是自己的，而是凡物公用。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:16; 使徒行传 1:22; 使徒行传 1:8"> 使徒们以大能为主耶稣的复活作见证；大恩典临到他们众人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 2:45; 路加福音 12:33; 路加福音 16:9"> 因为他们中间没有一个缺乏的；凡拥有田地或房屋的人都卖了，把所卖的价银拿来，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 5:2; 使徒行传 2:45; 哥林多后书 8:20–21"> 放在使徒脚前；然后照各人的需要分给各人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="加拉太书 2:9; 加拉太书 2:13; 加拉太书 2:1"> 有一个利未人约西，按出身是塞浦路斯人，使徒们称他为巴拿巴（翻译出来就是“劝慰之子”），</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 5:1–2; 使徒行传 4:34–35; 马太福音 19:29"> 他有一块田地，卖了，把钱拿来，放在使徒脚前。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各书 2:9; 利未记 19:15"> 我的弟兄们，不要带着偏待人的心，持守对我们荣耀的主耶稣基督的信心。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖记 3:10; 以斯帖记 8:2"> 因为若有一个戴金戒指、穿华美衣服的人进了你们的会堂，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：聚会">a</a></sup>又有一个穿肮脏衣服的穷人也进来，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:9; 雅各书 2:6; 路加福音 7:44–46"> 你们就特别看重那穿华美衣服的人，说：“请坐在这里的好位子上；”却对那穷人说：“你站在那里，”或说：“坐在我的脚凳旁边，”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:24; 约伯记 34:19; 马太福音 7:1–5"> 这岂不是你们在自己中间偏待人，成了怀着恶念的审判者吗？</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 5:3; 路加福音 6:20; 启示录 2:9"> 我亲爱的弟兄们，请听。上帝岂不是拣选了这世上的穷人，使他们在信心上富足，并承受祂应许给爱祂之人的国度吗？</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前书 11:22; 箴言 14:31"> 可是你们却羞辱了穷人。欺压你们、亲自把你们拉到法庭去的，不正是富人吗？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:9–11; 启示录 13:5–6; 提摩太前书 1:13"> 他们不是亵渎那称在你们身上的尊名吗？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 19:18; 加拉太书 5:14; 马太福音 22:39"> 然而，你们若照着经上的话：“你要爱你的邻舍如同自己，” 成全那至尊的律法，你们就做得好。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 19:15; 雅各书 2:1–4; 约翰一书 3:4"> 但你们若偏待人，就是犯罪，被律法定为违犯律法的人。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 3:10; 马太福音 5:18–19; 申命记 27:26"> 因为凡遵守全律法，却在一点上跌倒的，他就对全部律法都有罪责。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:13–14; 马太福音 5:21–28; 申命记 5:17–18"> 因为那说“不可奸淫” 的，也说“不可杀人”。 现在，你若不奸淫，却杀人，就成了违犯律法的人。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:25; 雅各书 2:8; 彼得后书 1:4–8"> 你们既然要受自由的律法审判，就该照这样说话，照这样行事。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:7; 马太福音 6:15; 箴言 21:13"> 因为对不施怜悯的人，审判也不施怜悯。怜悯胜过审判。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:26–27; 马太福音 7:21–23; 雅各书 1:22–25"> 我的弟兄们，如果有人说自己有信心，却没有行为，这有什么益处呢？信心能拯救他吗？</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 马太福音 25:35–40; 以赛亚书 58:7"> 若有弟兄或姐妹没有衣服穿，又缺少日用的饮食，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 约翰一书 3:16–18; 马太福音 25:42–45"> 你们中间有人对他们说：“平平安安地去吧。愿你们得暖、得饱；”却不给他们身体所需要的东西，这有什么益处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 2:26; 彼得后书 1:5–9; 雅各书 2:19–20"> 照样，信心若没有行为，本身就是死的。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:13; 雅各书 2:14; 加拉太书 5:6"> 可是有人会说：“你有信心，我有行为。”你把你没有行为的信心给我看，我就借着我的行为把我的信心给你看。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 马可福音 1:24; 马太福音 8:29"> 你信上帝只有一位，你做得好。鬼魔也信，却战抖。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:17; 雅各书 2:26; 箴言 12:11"> 你这虚浮的人哪，你愿意知道没有行为的信心是死的吗？</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 22:16–18; 创世记 22:9–12; 约翰福音 8:39"> 我们的父亚伯拉罕把他儿子以撒献在祭坛上的时候，岂不是因行为称义了吗？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 1:3; 希伯来书 11:17–19; 加拉太书 5:6"> 你看，信心与他的行为一同起作用，并且信心因行为得以完全。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:6; 以赛亚书 41:8; 历代志下 20:7"> 这就应验了经上所说的：“亚伯拉罕信上帝，这就算为他的义，” 他也被称为上帝的朋友。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 2:21–22; 雅各书 2:15–18; 诗篇 60:12"> 这样看来，人称义是因着行为，不是单因着信心。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 约书亚记 6:22–25; 约书亚记 2:19–21"> 同样，妓女喇合接待使者，又从别的路把他们送出去的时候，不也是因行为称义了吗？</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:20; 雅各书 2:17; 雅各书 2:14"> 身体没有灵是死的，照样，信心没有行为也是死的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 11:28; 提摩太前书 6:9–10; 箴言 11:4"> 来吧，你们这些富足的人，要为那将要临到你们的苦难哭泣哀号！</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:19–20; 约伯记 13:28; 路加福音 12:33"> 你们的财富已经腐烂，你们的衣服已经被虫蛀了。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 2:5; 雅各书 5:7–8; 启示录 21:8"> 你们的金银已经锈蚀；那锈蚀要作证控告你们，又要像火一样吞吃你们的肉体。你们在末后的日子积蓄了财宝。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 19:13; 耶利米书 22:13; 申命记 24:14–15"> 看哪，给那些收割你们田地的工人的工钱，被你们用欺诈扣留，这工钱正在呼喊；收割之人的呼声已经进入万军之主的耳中。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希腊文：Sabaoth（或希伯来文：Tze’va’ot）">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 5:6; 路加福音 16:25; 路加福音 16:19"> 你们在地上奢华享乐，放纵私欲；你们滋养自己的心，如同在宰杀的日子。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:22–23; 约翰福音 19:9–11; 以赛亚书 53:7"> 你们定了义人的罪，并且杀害了他。他没有抵抗你们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:1–3; 雅各书 5:8–9; 约珥 2:23"> 所以，弟兄们，你们要忍耐，直到主的来临。看哪，农夫等候地里宝贵的出产，为它耐心等待，直到得了早雨和晚雨。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 5:9; 加拉太书 5:22; 诗篇 37:7"> 你们也要忍耐，坚固你们的心，因为主的来临近了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 19:18; 哥林多前书 4:5; 雅各书 4:11"> 弟兄们，不要彼此埋怨，免得你们受审判。看哪，审判者正站在门前。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 11:32–38; 马太福音 5:11–12; 希伯来书 13:7"> 弟兄们，要把那些奉主名说话的先知，作为受苦和忍耐的榜样。</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 1:12; 出埃及记 34:6; 约伯记 1:21–22"> 看哪，我们称那些忍耐的人为有福。你们听见过约伯的忍耐，也看见了主所成就的结局，知道主满有慈悲和怜悯。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:33–37; 马太福音 23:16–22; 哥林多后书 1:17–20"> 我的弟兄们，最要紧的是不可起誓——不可指着天起誓，也不可指着地起誓，或起任何别的誓；你们说“是”，就该是“是”；说“不是”，就该是“不是”，免得你们落入虚伪。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR读作“受审判”，而不是“落入虚伪”。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 50:15; 约拿 2:2; 使徒行传 16:24–25"> 你们中间有受苦的吗？他就该祷告。有喜乐的吗？他就该歌颂。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:13; 使徒行传 28:8; 马可福音 16:18"> 你们中间有病了吗？他就该请教会的长老来；他们要奉主的名为他抹油，在他身上祷告。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 5:14–16; 雅各书 5:13; 雅各书 5:16"> 出于信心的祷告必医治那病人，主必使他起来；他若犯了罪，也必蒙赦免。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 29:12–13; 箴言 15:29; 马太福音 21:22"> 所以，你们要彼此认罪，彼此代祷，好使你们得医治。义人恳切的祷告大有功效。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 17:1; 路加福音 4:25; 启示录 11:6"> 以利亚是与我们性情相同的人；他恳切祷告，求不要下雨，地上就三年零六个月没有下雨。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 18:42–45; 耶利米书 14:22; 列王纪上 18:18"> 他又祷告，天就降下雨来，地也生出出产。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:1; 马太福音 18:15; 雅各书 5:20"> 弟兄们，你们中间若有人偏离真理，又有人使他回转，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:8; 箴言 10:12; 提摩太前书 4:16"> 这人该知道：使一个罪人从错误的道路上回转的，必救一个灵魂脱离死亡，并且遮盖许多的罪。</span>
</div>
</div>

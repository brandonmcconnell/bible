<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:11; 加拉太书 5:17; 罗马书 7:23"> 你们中间的战争和争斗是从哪里来的呢？不正是从你们肢体里交战的享乐私欲来的吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 16:24; 马太福音 7:7–8; 雅各书 1:5"> 你们贪恋，却得不着；你们杀害、贪图，却不能得到；你们争斗、发动战争。你们得不着，是因为你们不求。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:14; 约翰一书 3:22; 雅各书 1:6–7"> 你们求，却得不着，因为你们妄求，为要把所得的花费在自己的享乐上。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:15–16; 罗马书 8:7; 约翰福音 15:19"> 你们这些奸夫淫妇啊，难道你们不知道与世界为友就是与上帝为敌吗？所以，凡想要作世界朋友的，就是使自己成为上帝的仇敌。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:16; 哥林多前书 6:19; 民数记 11:29"> 或者你们以为经上说“住在我们里面的圣灵切切恋慕，以至于嫉妒”是徒然的吗？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 23:12; 箴言 3:34; 彼得前书 5:5"> 但祂赐下更多恩典。因此经上说：“上帝抵挡骄傲的人，却赐恩典给谦卑的人。”</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 5:8–9; 以弗所书 4:27; 以弗所书 6:11–12"> 所以，你们要顺服上帝。要抵挡魔鬼，魔鬼就必逃避你们。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:18; 希伯来书 10:22; 玛拉基书 3:7"> 你们要亲近上帝，祂就必亲近你们。罪人哪，要洗净你们的手；心怀二意的人哪，要洁净你们的心。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 7:10–11; 马太福音 5:4; 路加福音 6:25"> 你们要悲哀、哀恸、哭泣；要使你们的笑声变为哀恸，你们的喜乐变为愁苦。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 147:6; 马太福音 23:12; 彼得前书 5:6"> 你们要在主面前谦卑自己，祂就必高举你们。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="彼得前书 2:1; 罗马书 2:1; 雅各书 5:9"> 弟兄们，不要彼此毁谤。毁谤弟兄、论断弟兄的，就是毁谤律法、论断律法。但如果你论断律法，你就不是遵行律法的人，而是审判者。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:4; 罗马书 2:1; 马太福音 10:28"> 设立律法者只有一位，祂能拯救，也能毁灭。可是你是谁，竟论断别人呢？</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 27:1; 路加福音 12:17–20; 创世记 11:3–4"> 现在，听着，你们这些说“今天或明天我们要到这座城去，在那里住一年，做买卖，赚取利润”的人哪，</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 1:24; 诗篇 39:5; 约翰一书 2:17"> 其实明天你们的生命会怎样，你们并不知道。你们的生命是什么呢？你们不过是一阵雾气，出现片刻，随后就消散了。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:21; 希伯来书 6:3; 耶利米哀歌 3:37"> 你们倒应该说：“如果主愿意，我们就会活着，并且做这事或那事。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:1; 哥林多前书 5:6; 诗篇 52:7"> 但如今你们竟在自夸中夸耀；这一切夸耀都是恶的。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:41; 约翰福音 13:17; 约翰福音 15:22"> 所以，人若知道该行善却不去行，这对他就是罪。</span>
</div>

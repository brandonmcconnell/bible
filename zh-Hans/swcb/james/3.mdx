<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前书 1:7; 彼得前书 5:3"> 我的弟兄们，不要有许多人作教师，因为知道我们要受更重的审判。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:26; 箴言 13:3; 彼得前书 3:10"> 原来我们在许多事上都会跌倒；若有人在言语上不跌倒，他就是完全的人，也能勒住全身。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 32:9; 诗篇 39:1; 雅各书 1:26"> 事实上，我们把嚼环放在马的口里，使它们顺服我们，就能驾驭它们的全身。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 107:25–27; 马太福音 8:24; 使徒行传 27:14–38"> 看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，源自“ἰδοὺ”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">a</a></sup>船也是这样，虽然那么大，又被狂风驱动，却仍由很小的舵引导，随掌舵的人所愿而行。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米书 9:3–8; 箴言 12:18"> 舌头也是这样，是小小的肢体，却夸口说大话。看，多小的火能点燃多大的森林！</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 120:2–3; 箴言 16:27; 马可福音 7:15"> 舌头就是火。在我们的肢体中，舌头是个不义的世界，能玷污全身，点燃生命的轮子，并且是被革赫拿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或：地狱">b</a></sup>点燃的。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 5:4"> 各类走兽、飞鸟、爬行动物和海中的生物，都可以被驯服，并且已经被人类驯服；</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:13; 诗篇 140:3; 诗篇 55:21"> 惟独舌头没有人能驯服。它是不止息的恶物，充满致命的毒。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 10:7; 创世记 1:26–27; 诗篇 62:4"> 我们用舌头称颂我们的上帝和父，又用舌头咒诅那些照上帝形像被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:14; 彼得前书 3:9; 哥林多前书 3:3"> 称颂和咒诅从同一个口里出来。我的弟兄们，这些事本不该这样。</span>
<span className="v" id="v11" data-v="11"> 泉源能从同一个出口涌出甜水和苦水吗？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 马太福音 12:33; 马太福音 7:16–20"> 我的弟兄们，无花果树能结橄榄吗？葡萄树能结无花果吗？照样，一个泉源也不能流出咸水和甜水。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 5:23; 雅各书 3:17; 马太福音 5:5"> 你们中间谁是有智慧、有见识的呢？他就当以好品行显明自己的行为是在智慧的温柔中做成的。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 3:16; 哥林多前书 13:4; 腓立比书 2:3"> 但如果你们心里怀着苦毒的嫉妒和自私的野心，就不要夸口，也不要说谎抵挡真理。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 雅各书 1:17; 哥林多前书 3:19"> 这样的智慧不是从上头降下来的，而是属地的、属血气的、属鬼魔的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 3:14; 哥林多前书 3:3; 哥林多前书 14:33"> 因为哪里有嫉妒和自私的野心，哪里就有混乱和各样邪恶的行为。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 5:22–23; 箴言 2:6; 哥林多前书 13:4–7"> 但从上头来的智慧，首先是纯洁的，然后是和平的、温柔的、通达情理的，充满怜悯和好果子，没有偏私，没有虚伪。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 5:9; 何西阿 10:12; 腓立比书 1:11"> 公义的果子，是由缔造和平的人在和平中撒下的。</span>
</div>

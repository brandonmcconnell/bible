<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 12:15; 彼得前书 1:1; 约翰福音 7:35"> 上帝和主耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>的仆人雅各，写信给散居各地的十二支派：问候你们。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:6–8; 雅各书 1:12; 哥林多后书 12:9–10"> 我的弟兄们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里以及上下文允许之处，“弟兄们”也可以正确地译为“弟兄姊妹”或“手足”。">b</a></sup>你们落在各种试炼中时，都要看作极大的喜乐，</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 5:3–4; 希伯来书 10:36; 歌罗西书 1:11"> 因为知道你们的信心经过考验，就生出忍耐。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前书 5:10; 马太福音 5:48"> 但要让忍耐成就完全的工作，好使你们完全、完整，毫无缺欠。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 约翰福音 15:7; 箴言 3:5–7"> 你们中间若有人缺少智慧，就该向上帝求；祂厚赐给众人，也不责备人，智慧就必赐给他。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:21–22; 希伯来书 11:6; 马可福音 11:22–24"> 但他要凭信心求，一点也不疑惑；因为疑惑的人就像海中的波浪，被风吹动翻腾。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 4:3; 以赛亚书 58:3–4; 箴言 21:27"> 这样的人不要以为自己会从主那里得到什么。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 18:21; 马太福音 6:24; 雅各书 4:8"> 他心怀二意，在一切所行的事上都摇摆不定。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:23–24; 雅各书 2:5–6; 箴言 19:1"> 卑微的弟兄应当因自己升高而夸耀；</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:24; 约翰一书 2:17; 约伯记 14:2"> 富足的人也应当因自己降卑而夸耀，因为他要像草上的花一样消逝。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 40:7–8; 诗篇 37:35–36; 诗篇 49:6–14"> 太阳随着灼热的风升起，使草枯干；草上的花凋落，它外貌的美丽也消逝。富足的人在自己的追求中也要这样衰残。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 彼得前书 1:6–8; 启示录 2:10"> 忍受试炼的人有福了，因为他经过考验合格以后，必得主应许给爱祂之人的生命冠冕。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷 2:12–13; 雅各书 1:12; 罗马书 9:19–20"> 人被试探时，不可说：“我是被上帝试探的。”因为上帝不能被恶试探，祂自己也不试探任何人。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 7:21–22; 以弗所书 4:22; 马太福音 15:18"> 但各人被试探，是被自己的私欲牵引、诱惑。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14; 约伯记 15:35; 罗马书 5:12–21"> 私欲怀了胎，就生出罪；罪长成后，就生出死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:7; 雅各书 1:19; 腓立比书 2:12"> 我亲爱的弟兄们，不要被迷惑。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 3:27; 马太福音 7:11; 希伯来书 13:8"> 各样美善的恩赐和各样全备的赏赐都是从上头来的，是从众光之父降下来的；在祂并没有变化，也没有转动的影儿。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:29–31; 彼得前书 1:23; 约翰福音 3:3–5"> 祂按自己的旨意，用真理的道生了我们，使我们成为祂所造之物中的一种初熟果子。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 所以，我亲爱的弟兄们，人人都要快快地听，慢慢地说，慢慢地动怒；</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 2:24–25; 以弗所书 4:26; 雅各书 3:17–18"> 因为人的怒气并不成就上帝的义。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:22; 以弗所书 1:13; 彼得前书 2:11"> 因此，你们要除去一切污秽和泛滥的邪恶，以谦卑领受那栽种在你们里面的道，就是能拯救你们灵魂的道。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：保全你们的生命。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 2:13; 路加福音 6:46–48; 约翰福音 13:17"> 只是你们要作行道的人，不要只作听道的人，自己欺骗自己。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:26–27; 以西结 33:31–32; 雅各书 2:14–26"> 因为若有人听道而不行道，他就像一个人在镜子里察看自己本来的面貌；</span>
<span className="v" id="v24" data-v="24" data-xref="彼得后书 3:11; 路加福音 1:66; 路加福音 7:39"> 他看见自己，走开以后，立刻忘了自己是什么样子。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 约翰福音 13:17; 哥林多后书 3:17–18"> 但那仔细察看完全、使人自由的律法，并且持守下去的人，不是听了就忘的人，而是实行这工作的人；这人在自己所做的事上必蒙福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; 诗篇 141:3; 彼得前书 3:10"> 如果你们中间有人自以为敬虔，却不勒住自己的舌头，反而欺骗自己的心，这人的敬虔就是徒然的。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:16–17; 约翰一书 3:17–19; 加拉太书 6:9–10"> 在我们的上帝和父面前，纯洁没有玷污的敬虔是这样：看顾在患难中的孤儿寡妇，并且保守自己不被世界玷污。</span>
</div>
</div>

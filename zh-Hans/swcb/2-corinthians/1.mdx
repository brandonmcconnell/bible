<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="2CO" data-book-slug="2-corinthians" data-book-name="哥林多后书" data-chapter="1" data-verses="24">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:1; 腓立比书 1:1; 以弗所书 1:1"> 奉上帝旨意作基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>耶稣使徒的保罗，和我们的弟兄提摩太，写信给在哥林多的上帝的教会，以及遍布亚该亚全境的众圣徒：</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 以弗所书 6:23; 腓立比书 1:2"> 愿恩典与平安从我们的父上帝和主耶稣基督临到你们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 15:5–6"> 愿颂赞归于我们主耶稣基督的上帝和父，祂是怜悯之父，是赐一切安慰的上帝；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:11; 以赛亚书 51:12; 帖撒罗尼迦后书 2:16–17"> 祂在我们一切患难中安慰我们，使我们能用自己从上帝所受的安慰，去安慰那些在各样患难中的人。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:24; 腓立比书 3:10; 哥林多后书 4:10–11"> 因为基督的苦难怎样在我们身上增多，照样，我们的安慰也借着基督增多。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 2:10; 哥林多后书 1:4; 哥林多后书 4:15–18"> 如果我们受患难，是为了你们的安慰和救恩；如果我们得安慰，也是为了你们的安慰，这安慰使你们能忍耐承受我们也正在承受的同样苦难。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17–18; 帖撒罗尼迦后书 1:4–7; 雅各书 1:12"> 我们对你们的盼望是坚定的，因为知道你们既然一同受苦，也必一同得安慰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 4:7–12; 哥林多前书 15:32; 哥林多前书 4:8"> 弟兄们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里以及上下文允许的地方，“弟兄们”一词也可正确译为“弟兄姐妹”或“手足”。">b</a></sup>关于我们在亚细亚所遭遇的患难，我们不愿意你们不知道：我们被压得极重，超过了自己的力量，甚至连活命都绝望了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 3:5; 希伯来书 11:19; 哥林多后书 4:7"> 是的，我们自己里面已经有了死亡的判决，为的是叫我们不倚靠自己，只倚靠那使死人复活的上帝；</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 4:10; 诗篇 34:19; 彼得后书 2:9"> 祂曾救我们脱离这样可怕的死亡，现在仍在拯救我们；我们也把盼望寄托在祂身上，相信祂还要继续拯救我们。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比书 1:19; 哥林多后书 4:15; 使徒行传 12:5"> 你们也要用祈求为我们一同帮助；这样，那借着许多人赐给我们的恩赐，就可以使许多人替你们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="+ MT：你们的；TR和NU：我们的">c</a></sup>献上感谢。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:17; 哥林多前书 2:13; 雅各书 3:13–18"> 我们所夸耀的就是这个：我们的良心见证我们在世上为人处世，尤其是对你们，是本着上帝的圣洁和真诚，不凭属肉体的智慧，而凭上帝的恩典。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 4:2; 腓利门书 1:6; 哥林多后书 13:6"> 因为我们写给你们的，并没有别的，都是你们所读到、也所承认的；我也盼望你们会承认到底——</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 2:16; 哥林多前书 1:8; 帖撒罗尼迦前书 2:19–20"> 正如你们在某种程度上已经承认我们——在我们主耶稣的日子，我们是你们所夸耀的，正如你们也是我们所夸耀的一样。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:19; 罗马书 1:11; 罗马书 15:29"> 我既有这样的信心，就定意先到你们那里去，使你们可以得第二次益处，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:5–7; 使徒行传 21:5; 使徒行传 19:21–22"> 然后经由你们那里前往马其顿，再从马其顿回到你们那里，并由你们送行前往犹太。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:37; 雅各书 5:12; 哥林多后书 10:2–3"> 那么，我这样计划，难道是反复无常吗？或者，我所计划的，难道是按着肉体计划，以致在我这里既有“是，是”，又有“不，不”吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:9; 启示录 3:7; 约翰福音 7:28"> 但上帝是信实的，我们对你们所说的话并不是“是而又不是”。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:8; 启示录 1:17; 约翰二书 1:9"> 因为我们在你们中间所传的上帝的儿子耶稣基督——就是我、西拉和提摩太所传的——并不是“是而又不是”，在祂里面只有“是”。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 2:24–25; 加拉太书 3:22; 启示录 7:12"> 因为上帝的应许无论有多少，在祂里面都是“是”。所以，借着祂也有“阿们”，使上帝借着我们得荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:27; 彼得前书 5:10; 约翰一书 2:20"> 那使我们和你们在基督里坚固、又膏立我们的，就是上帝；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:30; 哥林多后书 5:5; 以弗所书 1:13–14"> 祂也给我们盖了印，并在我们心里赐下圣灵作为定金。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:20; 哥林多前书 4:21; 罗马书 1:9"> 我呼求上帝为我的灵魂作见证：我是为了宽容你们，才没有再到哥林多去。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:3; 哥林多前书 15:1; 腓立比书 1:25–26"> 我们并不是辖制你们的信心，而是为了你们的喜乐与你们同工；因为你们凭信心站立得稳。</span>
</div>
</div>

</div>

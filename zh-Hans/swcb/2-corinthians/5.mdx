<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 19:25–26; 约翰一书 3:2; 彼得后书 1:13–14"> 我们知道，我们这帐篷在地上的房屋若被拆毁，就有从上帝而来的建筑，就是不是人手所造、在天上永恒的房屋。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 8:23; 哥林多前书 15:53–54; 哥林多后书 5:3–4"> 我们在这帐篷里确实叹息，切望穿上从天上来的居所；</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:7–11; 启示录 16:15; 启示录 3:18"> 如果我们确实穿上了，就不至于显为赤裸。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 15:53–54; 哥林多后书 5:2; 以赛亚书 25:8"> 我们在这帐篷里的确叹息，担着重担；不是愿意脱去衣服，而是愿意再穿上衣服，好使这必死的被生命吞灭。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 1:22; 以弗所书 1:13–14; 罗马书 8:23"> 那为这件事预备我们的就是上帝，祂也赐给我们圣灵作为凭据。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 5:1; 腓立比书 3:20–21; 希伯来书 11:13"> 所以，我们常常坦然无惧，并且知道，我们住在身体里，就与主相离；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:1–27; 哥林多后书 4:18; 罗马书 8:24–25"> 因为我们行事为人是凭信心，不是凭眼见。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 1:20–24; 哥林多后书 5:6; 约翰福音 14:3"> 我说，我们坦然无惧，宁愿离开身体，与主同住。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:10; 彼得后书 3:14; 罗马书 14:18"> 所以，无论是住在身体里，还是离开身体，我们也立定志向，要讨祂喜悦。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 16:27; 启示录 22:12; 以弗所书 6:8"> 因为我们众人都必须在基督的审判台前显露出来，好叫各人按着他在身体里所行的，或善或恶，受报。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:23; 希伯来书 10:31; 提摩太后书 2:24–26"> 因此，我们既知道敬畏主，就劝服人；但我们在上帝面前是显明的，我也盼望我们在你们的良心里也是显明的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:1; 哥林多后书 1:14; 加拉太书 6:12–14"> 我们不是再向你们推荐自己，而是给你们机会可以为我们夸口，使你们有话回答那些凭外貌而不凭内心夸口的人。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:16–17; 哥林多后书 11:1; 哥林多后书 12:6"> 如果我们癫狂，那是为上帝；如果我们清醒，那是为你们。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:20; 罗马书 14:7–9; 马太福音 10:37–38"> 原来基督的爱催逼我们；因为我们这样断定：一人为众人死了，众人就都死了。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:7–9; 彼得前书 4:2–4; 彼得前书 1:14–15"> 祂为众人死，是要使那些活着的人不再为自己活，而是为那替他们死而复活的主活。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:11; 腓立比书 3:7–8; 约翰福音 6:63"> 所以，从今以后，我们不再按肉体认识任何人。虽然我们曾按肉体认识基督，如今却不再这样认识祂了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 36:26; 以弗所书 4:22–24; 以赛亚书 43:18–19"> 因此，若有人在基督里，他就是新造的人。旧的事已经过去。看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，源自“ἰδοὺ”，意思是看、留意、观察、观看或凝视。它常用作感叹词。">a</a></sup>一切都变成新的了。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20–21; 哥林多后书 5:19–20; 罗马书 5:10–11"> 但这一切都是出于上帝，祂藉着耶稣基督使我们与祂自己和好，又把和好的职事赐给我们；</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 43:25; 以赛亚书 44:22; 约翰一书 2:1–2"> 这就是：上帝在基督里使世界与祂自己和好，不把他们的过犯算在他们身上，并且把和好的道托付给我们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 路加福音 14:23; 玛拉基书 2:7"> 所以，我们作基督的使者，就好像上帝藉着我们劝勉人一样；我们替基督恳求你们：要与上帝和好。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:22–24; 彼得前书 3:18; 罗马书 5:19"> 上帝使那位不知罪的，替我们成为罪，好叫我们在祂里面成为上帝的义。</span>
</div>
</div>

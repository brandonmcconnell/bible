<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:11; 哥林多后书 10:12; 哥林多后书 5:12"> 我们又开始推荐自己吗？还是像有些人一样，需要给你们的荐信，或从你们来的荐信吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 9:1–2; 帖撒罗尼迦前书 1:8; 罗马书 1:8"> 你们就是我们的信，写在我们心里，被众人知道、阅读；</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 11:19; 耶利米书 31:33; 希伯来书 8:10"> 显明你们是基督的信，由我们服事而成，不是用墨写的，而是用永活上帝的圣灵写的；不是写在石版上，而是写在肉心的版上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 以弗所书 3:12; 哥林多后书 2:14"> 我们借着基督，在上帝面前有这样的信心；</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:9; 腓立比书 4:13; 哥林多前书 15:10"> 并不是我们凭自己足以把任何事看作出于自己；我们的能力乃是出于上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 6:63; 罗马书 7:6; 耶利米书 31:31"> 祂也使我们足以作新约的仆人，不是凭字句，而是凭圣灵；因为字句叫人死，圣灵却赐人生命。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:9–11; 罗马书 10:4; 出埃及记 31:18"> 那用字刻在石头上、属死的职事尚且带着荣耀而来，以致以色列子孙因摩西脸上的荣耀，不能定睛看他的脸，虽然那荣耀正在消逝；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:16; 以弗所书 2:18; 加拉太书 3:14"> 圣灵的职事岂不更有荣耀吗？</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 3:21–22; 希伯来书 12:18–21; 哥林多后书 5:21"> 如果定罪的职事有荣耀，义的职事就更在荣耀上大大超过了。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:17; 哈该书 2:7–9; 使徒行传 26:13"> 其实，那从前得了荣耀的，在这方面，因那超过的荣耀，就算不得有荣耀了。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:20–21; 希伯来书 8:13; 希伯来书 7:21–25"> 如果那正在消逝的是带着荣耀的，那长存的就更在荣耀中了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 7:4; 使徒行传 4:13; 腓立比书 1:20"> 所以，我们既有这样的盼望，就用极大的坦然讲论；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:33–35; 希伯来书 10:1–9; 以弗所书 2:14–15"> 不像摩西将帕子蒙在脸上，使以色列子孙不能定睛看到那正在消逝之物的结局。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:3–4; 使徒行传 26:18; 罗马书 11:25"> 但他们的心思变得刚硬；直到今日，诵读旧约的时候，同样的帕子仍然存在，因为这帕子是在基督里才被除去的。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:27–29"> 然而直到今日，每当诵读摩西的时候，帕子仍蒙在他们心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:34; 以赛亚书 29:18; 以赛亚书 25:7"> 但每当有人转向主，帕子就被除去了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:2; 加拉太书 5:13; 约翰福音 8:32"> 主就是圣灵；主的圣灵在哪里，哪里就有自由。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:6; 以弗所书 4:22–24; 罗马书 12:2"> 我们众人既然脸上没有帕子，像在镜中观看主的荣耀，就被改变成同样的形象，荣上加荣，正如从主，就是圣灵而来。</span>
</div>

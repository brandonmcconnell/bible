<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:4; 哥林多前书 1:21; 哥林多后书 11:19"> 我但愿你们稍微容忍我的一点愚妄；其实你们也确实容忍我了。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿 2:19–20; 以弗所书 5:26–27; 以赛亚书 54:5"> 因为我以属上帝的嫉妒为你们嫉妒；因为我已经把你们许配给一个丈夫，好把你们如同贞洁的童女献给基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:8; 加拉太书 1:6; 以弗所书 4:14"> 但我恐怕，蛇怎样用诡诈欺骗了夏娃，你们的心思也会这样从在基督里的纯一中被败坏。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:6–8; 哥林多前书 3:11; 提摩太前书 2:5"> 因为如果有人来传另一个耶稣，不是我们所传过的；或者你们领受另一个灵，不是你们所领受过的；或者接受另一个“福音”，不是你们所接受过的，你们倒容忍得很好。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:11–12; 哥林多前书 15:10; 加拉太书 2:6–9"> 因为我认为，我一点也不在那些最杰出的使徒以下。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 3:4; 哥林多前书 1:17; 哥林多后书 4:2"> 我虽然在言辞上不熟练，在知识上却不是不熟练。不，在各方面、在一切事上，我们都已经向你们显明了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 12:13; 帖撒罗尼迦前书 2:9; 哥林多后书 10:1"> 难道我白白地把上帝的福音传给你们，为要使你们被高举，自己反倒卑微，这就犯了罪吗？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:18; 哥林多后书 11:9; 腓立比书 4:14–16"> 我夺取了别的教会，接受他们的供给，为要服侍你们。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:8–9; 帖撒罗尼迦前书 2:9; 帖撒罗尼迦前书 2:6"> 我在你们那里、又有缺乏的时候，没有成为任何人的负担；因为从马其顿来的弟兄们补足了我的缺乏。我在一切事上都保守自己不成为你们的负担，将来也要这样做。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 9:1; 罗马书 1:9; 使徒行传 18:12"> 基督的真理既在我里面，在亚该亚一带，就没有人能阻止我这样夸口。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 12:15; 哥林多后书 6:11–12; 哥林多后书 7:3"> 为什么呢？因为我不爱你们吗？上帝知道。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:12; 哥林多前书 5:6; 哥林多后书 5:12"> 但我现在所做的，我还要继续做，为要断绝那些想找机会之人的机会，使他们在所夸口的事上，被认为和我们一样。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 1:7; 启示录 2:2; 约翰一书 4:1"> 因为这样的人是假使徒，是诡诈的工人，装作基督的使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:8; 哥林多后书 2:11; 哥林多后书 11:3"> 这也不足为奇，因为连撒但也装作光明的天使。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 3:19; 启示录 9:11; 以赛亚书 9:14–15"> 所以，如果他的仆役也装作公义的仆役，并不是什么大事；他们的结局必照着他们的行为。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 11:1; 哥林多后书 12:6; 哥林多后书 12:11"> 我再说：不要有人把我看作愚妄人。即使如此，也请把我当作愚妄人接纳，好让我也稍微夸口。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 7:12; 腓立比书 3:3–6; 哥林多后书 9:4"> 我现在所说的，不是照着主说的，而是在这种夸口的自信中，像愚妄人说的。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:10; 哥林多后书 11:21–23; 哥林多后书 10:12–18"> 既然许多人按着肉体夸口，我也要夸口。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:10; 哥林多前书 10:15; 哥林多前书 8:1"> 因为你们既是聪明人，就乐意容忍愚妄人。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:4; 加拉太书 4:3; 加拉太书 5:1"> 如果有人使你们作奴仆，吞吃你们，掳掠你们，高抬自己，或打你们的脸，你们都容忍了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 10:10; 哥林多后书 11:17; 哥林多后书 10:1–2"> 我羞愧地说，我们好像是软弱了。然而，无论谁在哪一方面大胆——我是以愚妄说的——我也大胆。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 3:5; 罗马书 11:1; 罗马书 9:4"> 他们是希伯来人吗？我也是。他们是以色列人吗？我也是。他们是亚伯拉罕的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：种子">a</a></sup>吗？我也是。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:4–5; 哥林多后书 1:9–10; 哥林多后书 6:9"> 他们是基督的仆人吗？——我是像失了理智的人说话——我更是：劳苦更多，坐牢更多，受鞭打过量，屡次面临死亡。</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 13:9; 申命记 25:2–3; 马太福音 10:17"> 我从犹太人受过五次四十下减一下的鞭打。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 14:19; 使徒行传 16:37; 希伯来书 11:37"> 我被棍打过三次；被石头打过一次；遭遇船难三次；在深海里过了一昼一夜。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:5; 使徒行传 17:5; 使徒行传 13:50"> 我常常旅行，遇到江河的危险、强盗的危险、同族人的危险、外邦人的危险、城里的危险、旷野的危险、海上的危险、假弟兄中的危险；</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:12; 哥林多后书 6:5; 帖撒罗尼迦前书 2:9"> 劳碌困苦，常常不眠，饥饿干渴，常常禁食，受寒冷，衣不蔽体。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 7:17; 罗马书 15:16; 使徒行传 20:18–35"> 除了外面的那些事，还有天天压在我身上的事：为众教会挂虑。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 8:13; 哥林多前书 9:22; 加拉太书 4:8–20"> 有谁软弱，我不软弱呢？有谁被绊倒，我不义愤如焚呢？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 12:5–11; 箴言 25:27; 哥林多前书 2:3"> 如果必须夸口，我就要夸自己软弱的事。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 9:5; 以弗所书 1:3; 约翰福音 10:30"> 主耶稣基督的上帝和父，就是那永远当受称颂的，知道我不说谎。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:24–25; 哥林多后书 11:26"> 在大马士革，亚哩达王手下的总督把守大马士革人的城，想要捉拿我。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 9:25; 撒母耳记上 19:12; 约书亚记 2:18"> 我就从城墙上的一个窗户，装在筐子里被人缒下去，逃脱了他的手。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:23; 哥林多后书 12:20–21; 哥林多后书 13:10"> 但我自己定意：不再带着忧愁到你们那里去。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:8; 哥林多后书 1:14; 哥林多前书 12:26"> 因为如果我使你们忧愁，那么除了那因我而忧愁的人以外，谁还能使我喜乐呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:10; 哥林多后书 8:22; 腓利门书 1:21"> 我把这件事写给你们，好叫我来的时候，不至于从那些本该使我喜乐的人那里得到忧愁；我深信你们众人都会以我的喜乐为喜乐。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 7:12; 箴言 27:5–6; 利未记 19:17–18"> 因为我是在极大的患难和心中的痛苦中，流着许多眼泪写信给你们；不是要使你们忧愁，而是要使你们知道我对你们有何等丰盛的爱。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:12–13; 加拉太书 4:12; 箴言 17:25"> 如果有人造成了忧愁，他不是使我忧愁，而是在某种程度上使你们众人忧愁（我不愿说得太重）。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 5:4–5; 提摩太前书 5:20; 哥林多后书 7:11"> 多数人所加给他的这责罚，对这样的人已经够了；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:32; 加拉太书 6:1–2; 歌罗西书 3:13"> 所以相反，你们倒应该赦免他、安慰他，免得这样的人被过度的忧愁吞没。</span>
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:22–23; 加拉太书 6:1–2; 加拉太书 6:10"> 因此，我恳求你们重新确认你们对他的爱。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 10:6; 腓利门书 1:21; 腓立比书 2:22"> 我也正是为此写信，好知道你们经得起验证，是否在一切事上都顺服。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:23; 马太福音 18:18; 哥林多后书 5:20"> 你们赦免谁什么事，我也赦免；因为我若确实赦免了什么，我是为你们的缘故，在基督面前赦免了那人，</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 5:8; 以弗所书 6:11–12; 哥林多后书 11:3"> 免得撒但占我们的便宜，因为我们并非不知道他的诡计。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:8; 使徒行传 14:27; 歌罗西书 4:3"> 我为了基督的福音来到特罗亚，又有门在主里为我开了，</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 7:5–6; 哥林多后书 12:18; 提多书 1:4"> 可是我的灵没有安宁，因为没有找到我的弟兄提多；于是我辞别他们，往马其顿去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以弗所书 5:2; 罗马书 8:37; 哥林多后书 2:15–16"> 感谢上帝！祂常常在基督里带领我们凯旋，并借着我们在各处显扬认识祂的馨香之气。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:2; 哥林多前书 1:18; 以西结 20:41"> 因为对上帝来说，我们在蒙拯救的人中，也在灭亡的人中，都是基督的馨香之气：</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5–6; 约翰福音 9:39; 彼得前书 2:7–8"> 对这一等人，是出于死亡、通向死亡的臭气；对那一等人，是出于生命、通向生命的馨香之气。谁能胜任这些事呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 4:2; 哥林多后书 1:12; 彼得后书 2:1–3"> 因为我们不像那许多人贩卖上帝的话；我们乃是出于真诚，乃是出于上帝，在上帝面前，在基督里说话。</span>
</div>

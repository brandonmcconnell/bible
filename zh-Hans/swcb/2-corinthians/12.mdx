<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:12; 哥林多后书 12:7; 约翰一书 5:20"> 我夸口无疑是无益的，但我要说到主的异象和启示。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:17; 以西结 8:1–3; 帖撒罗尼迦前书 4:17"> 我认识一个在基督里的人，十四年前被提到第三层天上去——或在身体里，我不知道；或在身体外，我也不知道；上帝知道。</span>
<span className="v" id="v3" data-v="3"> 我认识这样一个人——或在身体里，或在身体外，我不知道；上帝知道——</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 23:43; 启示录 2:7; 以西结 31:9"> 他被提到乐园里，听见不可言说的话，是人不可说出的。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:30; 哥林多前书 2:3; 哥林多后书 12:9–10"> 为这样的人，我要夸口；但为我自己，除了我的软弱以外，我不夸口。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:16; 哥林多后书 11:31; 哥林多后书 12:11"> 因为即使我想夸口，也不算愚妄，因为我说的是真话；但我克制不说，免得有人把我看得过于他在我身上所看见的，或从我听见的。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:55; 士师记 2:3; 历代志下 32:25–26"> 又因这些启示极其伟大，为免我过于高抬自己，就有一根刺加在我的肉体上，就是撒但的使者来折磨我，免得我过于高抬自己。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 5:7; 马太福音 26:39–44; 撒母耳记上 15:11"> 为这事，我三次恳求主，使它离开我。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 4:13; 哥林多后书 12:10; 以赛亚书 40:29–31"> 祂对我说：<span className="woj">“我的恩典够你用，因为我的能力是在软弱中显得完全。”</span>所以，我更甘心以我的软弱为夸耀，好使基督的能力覆庇我。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 以弗所书 6:10; 罗马书 5:3"> 因此，为基督的缘故，我以软弱、凌辱、缺乏、迫害、困苦为喜乐；因为我什么时候软弱，什么时候就刚强。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 11:5; 哥林多后书 11:1; 哥林多前书 15:8–10"> 我夸口成了愚妄人。是你们逼我的；其实我本该由你们推荐，因为我虽然算不了什么，却没有一处不及那些最杰出的使徒。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:18–19; 哥林多后书 11:4; 哥林多后书 4:2"> 使徒的凭据确实在你们中间显出来了，就是以完全的忍耐，借着神迹、奇事和大能的作为显出来。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 9:12; 哥林多前书 9:6; 哥林多后书 11:7–9"> 你们有什么地方不如其余的教会呢？除非是我自己没有成为你们的负担。请你们饶恕我这个亏负吧！</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 创世记 24:35–36; 哥林多前书 10:33"> 看哪，这是我第三次预备到你们那里去，我也不会成为你们的负担；因为我所求的不是你们的财物，而是你们。儿女不该为父母积蓄，父母才该为儿女积蓄。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:8; 哥林多后书 1:6; 腓立比书 2:17"> 我极其甘心为你们的灵魂花费，并且自己也被耗尽。难道我越发爱你们，就越少被你们爱吗？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:5; 哥林多后书 10:2–3; 哥林多后书 12:13"> 即便如此，我自己没有加重你们的负担。可是你们也许会说，我狡猾，用诡诈抓住了你们。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 9:5; 哥林多前书 4:17; 列王纪下 5:20–27"> 我差到你们那里去的人，有谁被我利用来占过你们的便宜吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:6; 罗马书 4:12; 使徒行传 20:33–35"> 我劝提多去，又差那位弟兄与他同去。提多占过你们的便宜吗？我们行事不都是本着同一个灵吗？不都是走同样的脚步吗？</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:1; 哥林多前书 14:26; 哥林多后书 10:8"> 你们又以为我们是在向你们辩解吗？我们是在上帝面前，在基督里说话。亲爱的，一切都是为了造就你们。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:19–21; 彼得前书 2:1; 罗马书 1:29"> 因为我怕我来的时候，见你们不是我所希望的样子；你们见我，也不是你们所希望的样子；又怕在你们中间有纷争、嫉妒、怒气爆发、结党、毁谤、背后议论、骄傲的意念、混乱；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 彼得前书 4:2–3; 歌罗西书 3:5"> 又怕我再来的时候，我的上帝使我在你们面前降卑，并且为许多从前犯了罪、却没有为他们所行的污秽、淫乱和邪荡悔改的人哀痛。</span>
</div>

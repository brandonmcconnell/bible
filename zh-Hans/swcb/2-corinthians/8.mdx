<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 16:9; 哥林多后书 9:2; 哥林多后书 9:4"> 弟兄们，我们把上帝赐给马其顿众教会的恩典告诉你们：</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:5; 箴言 11:25; 哥林多后书 6:10"> 在患难的严峻考验中，他们满溢的喜乐和极深的贫穷，反而涌流出丰厚的慷慨。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:5; 出埃及记 35:21–22"> 我可以作证，他们是按着自己的能力，而且超过了自己的能力，自愿捐献；</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:17; 加拉太书 6:10; 哥林多后书 9:1"> 他们再三恳求我们收下这恩典，并准他们参与服侍圣徒的团契。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 12:1; 罗马书 14:7–9; 历代志下 30:12"> 这并不像我们所期望的；他们反而先把自己献给主，又照着上帝的旨意献给我们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多后书 8:4"> 因此我们劝提多，既然他从前已经开始，就也在你们中间完成这恩典的事。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:8; 彼得后书 1:5–8; 帖撒罗尼迦后书 1:3"> 你们既然在一切事上，就是在信心、言语、知识、一切热心，以及你们对我们的爱上，都格外丰盛，就也要在这恩典上格外丰盛。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:6; 约翰一书 3:17–19; 雅各书 2:14–16"> 我说这话不是出于命令，而是借着别人的热心，也验证你们爱心的真诚。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 8:32; 腓立比书 2:6–8; 马太福音 20:28"> 你们知道我们主耶稣基督的恩典：祂本来富足，却为了你们成了贫穷，使你们因祂的贫穷可以成为富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18–19; 希伯来书 13:16; 哥林多后书 9:2"> 我在这事上提出意见：这对你们是有益的；你们一年前就先开始了，不但去做，也有愿意的心。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 9:2"> 如今也要把这事完成；既然有愿意的热诚，也要照你们所有的能力完成。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 12:42–44; 哥林多后书 9:7; 路加福音 21:1–4"> 因为若有愿意的心，就按人所有的蒙悦纳，不是按人所没有的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 4:34; 罗马书 15:26–27"> 这不是要别人轻省，而你们受累，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:12; 使徒行传 4:34"> 而是为了均平。现在你们的富余补足他们的缺乏，好使他们的富余也可以补足你们的缺乏，这样就有均平。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:18; 路加福音 22:35"> 如经上所记：“多收的没有余，少收的也没有缺。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 17:17; 耶利米书 32:40; 哥林多后书 2:13–14"> 感谢上帝，祂把同样为你们殷勤关怀的心放在提多心里。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:6; 希伯来书 13:22; 哥林多后书 8:10"> 他固然接受了我们的劝勉，但他自己更加热心，就自愿往你们那里去了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多前书 7:17"> 我们同他差遣了一位弟兄；这位弟兄因着福音在众教会中受到称赞。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 16:3–4; 哥林多后书 4:15; 哥林多后书 9:8"> 不但如此，他也受众教会委派，在这恩典的事上与我们同行；这事由我们办理，是为了主自己的荣耀，也显明我们的热诚。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 5:22; 罗马书 14:16; 以弗所书 5:15"> 我们这样做，是避免有人在我们经办这丰厚捐助的事上责备我们。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:17; 彼得前书 2:12; 腓立比书 4:8"> 我们顾念光明正大的事，不但在主面前，也在人面前。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:20–22"> 我们又同他们差遣了我们的弟兄；我们在许多事上多次证实他是热心的，如今因他对你们有极大的信任，就更加热心。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 2:25; 腓利门书 1:17; 哥林多后书 8:6"> 至于提多，他是我的伙伴，也是为你们作工的同工。至于我们的弟兄们，他们是众教会的使者，是基督的荣耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 7:14; 哥林多后书 7:4; 哥林多后书 9:2–4"> 所以，你们要在众教会面前向他们显出你们爱心的凭据，以及我们为你们夸耀的凭据。</span>
</div>

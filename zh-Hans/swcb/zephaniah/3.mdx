<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 6:6; 以赛亚书 30:12; 以赛亚书 59:13"> 这悖逆、污秽、欺压人的城有祸了！</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 5:3; 耶利米书 22:21; 耶利米书 7:23–28"> 她不听从声音，不接受管教，不信靠耶和华，不亲近她的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哈巴谷 1:8; 以西结 22:25–27; 耶利米书 5:6"> 她中间的首领是咆哮的狮子；她的审判官是夜晚的豺狼，什么也不留到次日。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 22:26; 何西阿 9:7; 玛拉基书 2:8"> 她的先知是傲慢诡诈的人；她的祭司亵渎圣所，践踏律法。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:4; 诗篇 145:17; 耶利米哀歌 3:23"> 耶和华在她中间是公义的；祂不行不义。每天早晨，祂使自己的公正显明如光；祂从不失败，不义的人却不知羞耻。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:6; 西番雅书 2:5; 哥林多前书 10:11"> 我已经剪除列国；他们的城垛荒凉。我使他们的街道荒废，以致无人经过；他们的城市被毁，以致无人，毫无居民。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿 9:9; 耶利米书 36:3; 弥迦书 2:1–2"> 我说：“你只要敬畏我，接受管教。”这样，她的居所就不致照我对她所命定的一切被剪除。但他们早早起来，败坏自己一切所行的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约珥 3:2; 西番雅书 1:18; 弥迦书 7:7"> 耶和华说：“因此，你们要等候我，直到我起来夺取猎物的日子；因为我已决意聚集列国，召集列邦，好将我的愤怒，就是我一切猛烈的怒气，倾倒在他们身上；因为全地都必被我忌邪的火吞灭。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 11:1; 诗篇 22:27; 以赛亚书 19:18"> 那时，我必洁净万民的嘴唇，使他们都呼求耶和华的名，肩并肩事奉祂。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 11:11; 诗篇 68:31; 以赛亚书 18:1"> 从古实河外，敬拜我的人，就是我分散之民的女子，必带来我的供物。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 54:4; 约珥 2:26–27; 以赛亚书 11:9"> 那日，你必不因你一切悖逆我所行的事而蒙羞；因为那时，我必从你中间除去那些因骄傲而欢腾的人，你也不再在我的圣山上狂傲。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 14:32; 那鸿书 1:7; 撒迦利亚书 13:8–9"> 但我必在你中间留下困苦贫穷的民；他们必投靠耶和华的名。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 14:5; 西番雅书 2:7; 弥迦书 4:7"> 以色列的余民不行罪孽，也不说谎；他们口中也找不到诡诈的舌头；他们必得喂养，并且躺卧，无人使他们惧怕。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 12:6; 撒迦利亚书 2:10–11; 弥迦书 4:8"> 锡安的女子啊，要歌唱！以色列啊，要欢呼！耶路撒冷的女子啊，要全心欢喜快乐。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 51:22; 西番雅书 3:5; 以赛亚书 33:22"> 耶和华已经除去你的判决，赶出你的仇敌。以色列的王耶和华在你中间；你必不再惧怕灾祸。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:12; 以赛亚书 35:3–4; 以赛亚书 41:10"> 那日，必有人对耶路撒冷说：“不要惧怕。锡安哪，不要让你的手软弱。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 149:4; 诗篇 147:11; 耶利米书 32:41"> 耶和华你的上帝在你中间，是施行拯救的大能者。祂必因你欢欣喜乐；祂必以祂的爱使你安静；祂必因你欢呼歌唱。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 42:2–4; 以西结 36:24; 耶利米哀歌 2:6–7"> 我必从你那里除去那些为指定节期悲伤的人；他们是你的重担和羞辱。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 49:25–26; 以赛亚书 60:14; 耶利米书 30:16"> 看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，源自“הִנֵּה”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">a</a></sup>到那时，我必对付一切苦待你的人；我必拯救瘸腿的，聚集被赶散的。我必使那些在全地蒙羞的人得称赞和尊荣。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 29:14; 玛拉基书 3:12; 以赛亚书 56:5"> 那时，我必领你们进入；那时，我必聚集你们；因为当我在你们眼前恢复你们命运的时候，我必使你们在地上万民中得尊荣和称赞。这是耶和华说的。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约珥 1:14; 历代志下 20:4; 以斯帖记 4:16"> 你们要聚集，要聚集，不知羞耻的国民啊，</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 17:13; 何西阿 13:3; 那鸿书 1:6"> 在所定的时候以前，在那日子如糠秕过去以前，在耶和华猛烈的怒气临到你们以前，在耶和华发怒的日子临到你们以前。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司 5:14–15; 以赛亚书 26:20–21; 诗篇 76:9"> 地上所有谦卑的人，就是遵行祂典章的人啊，你们要寻求耶和华；要寻求公义，寻求谦卑。或许你们在耶和华发怒的日子得以隐藏。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 9:5–7; 阿摩司 1:6–8; 耶利米书 47:1–7"> 因为加沙必被撇弃，亚实基伦必成为荒场；亚实突必在正午被赶出，以革伦必被连根拔起。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 25:16; 耶利米书 47:7; 约书亚记 13:3"> 海岸的居民，基利提人的国民啊，你们有祸了！耶和华的话攻击你，迦南啊，非利士人的地。我要毁灭你，以致无人居住。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 17:2; 以西结 25:5; 以赛亚书 5:17"> 海岸必成为草场，有牧人的棚屋和羊群的圈。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 4:31; 以西结 39:25; 西番雅书 3:20"> 这海岸必归犹大家余剩的人。他们要在那里放牧。晚上，他们要躺卧在亚实基伦的房屋中，因为耶和华他们的上帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">a</a></sup>必眷顾他们，使他们恢复。</span>
<span className="v" id="v8" data-v="8" data-xref="阿摩司 1:13; 诗篇 83:4–7; 耶利米书 48:27–29"> 我听见了摩押的羞辱和亚扪子孙的辱骂，就是他们羞辱我的子民，并向他们的疆界自高自大的话。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 15:1–9; 以赛亚书 11:14; 申命记 29:23"> 因此，我指着我的永生起誓，万军之耶和华以色列的上帝说：摩押必定像所多玛，亚扪子孙必像蛾摩拉，成为荨麻之地、盐坑和永远荒废之处。我子民中余剩的人必掠夺他们，我国中幸存的人必承受他们的地。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 16:6; 耶利米书 48:29; 西番雅书 2:8"> 这是他们因骄傲所得的，因为他们辱骂万军之耶和华的子民，并向他们自高自大。</span>
<span className="v" id="v11" data-v="11" data-xref="弥迦书 4:1–3; 撒迦利亚书 13:2; 诗篇 138:4"> 耶和华必向他们显为可畏，因为祂必使地上所有的神明饥瘦。人都要敬拜祂，各人在自己的地方，就是列国所有的海岸。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结 30:4–9; 以赛亚书 43:3; 耶利米书 51:20–23"> 古实人哪，你们也必被我的刀杀死。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="那鸿书 3:7; 那鸿书 1:1; 以赛亚书 10:12"> 祂必伸手攻击北方，毁灭亚述，使尼尼微成为荒场，干旱如旷野。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 13:19–22; 以赛亚书 34:11–17; 阿摩司 9:1"> 畜群和各种走兽必躺卧在城中；鹈鹕和豪猪都要栖宿在它的柱顶上；它们的叫声必在窗户间回响。荒凉必在门槛上，因为祂已经露出香柏木梁。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 28:2; 以赛亚书 22:2; 以赛亚书 47:7–8"> 这就是那欢乐的城，安然居住，心里说：“惟有我，除我以外再没有别人。”她竟成了荒场，成了走兽躺卧之处！凡经过她的人都必嗤笑，并摇动拳头。</span>
</div>

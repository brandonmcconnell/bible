<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:2; 历代志下 34:1–33; 彼得后书 1:19"> 在犹大王亚们的儿子约西亚的日子，耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当原文以全大写字母表示时，“LORD”或“GOD”是上帝专有名（希伯来文“יהוה”，通常发音为雅威）的译法。">a</a></sup>的话临到西番雅；他是古示的儿子，古示是基大利的儿子，基大利是亚玛利雅的儿子，亚玛利雅是希西家的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="弥迦书 7:13; 列王纪下 22:16–17; 以西结 33:27–29"> 耶和华说：我必从地面上彻底扫除一切。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 4:3; 以西结 7:19; 耶利米书 12:4"> 我必扫除人和动物；我必扫除天上的飞鸟、海里的鱼，以及与恶人同在的瓦砾堆。我必把人从地面上剪除，耶和华说。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿 10:5; 弥迦书 5:13; 列王纪下 23:4–5"> 我必伸手攻击犹大和耶路撒冷的一切居民；我必从这地方剪除巴力所剩下的残余，以及偶像祭司和异教祭司的名号；</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 19:13; 列王纪上 11:33; 列王纪下 17:33"> 还有那些在房顶敬拜天上万象的人，那些敬拜耶和华并指着祂起誓、又指着玛勒堪起誓的人；</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 1:4; 耶利米书 2:13; 耶利米书 15:6"> 那些转身不跟随耶和华的人，以及那些不寻求耶和华、也不求问祂的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷 2:20; 撒迦利亚书 2:13; 西番雅书 1:14"> 在主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“主”的词是“Adonai”。">b</a></sup>耶和华面前要肃静，因为耶和华的日子近了。耶和华已经预备了祭牲，已经把祂邀请的人分别为圣。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 24:21; 以赛亚书 3:18–24; 耶利米书 22:24–30"> 到耶和华献祭的日子，我必惩罚首领、王子，以及一切穿外邦衣服的人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 5:5; 阿摩司 3:10; 撒母耳记上 2:15–16"> 那日，我必惩罚一切跳过门槛的人，就是那些用强暴和诡诈充满他们主人之家的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 33:14; 阿摩司 8:3; 列王纪下 22:14"> 耶和华说，那日，必有呼喊的声音从鱼门传来，哀号从新区传来，山丘上传来巨大的崩裂声。</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 5:1; 耶利米书 25:34; 何西阿 12:7–8"> 玛革提施的居民哪，要哀号，因为迦南的民都灭亡了！一切满载银子的人都被剪除了。</span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司 6:1; 耶利米书 48:11; 以西结 8:12"> 那时，我必提灯搜查耶路撒冷；我必惩罚那些沉淀在自己酒渣上的人，他们心里说：“耶和华既不降福，也不降祸。”</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司 5:11; 弥迦书 6:15; 申命记 28:30"> 他们的财富必成为掠物，他们的房屋必成荒场。他们建造房屋，却不得居住；栽种葡萄园，却不得喝其中的酒。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 以西结 30:3; 西番雅书 1:7"> 耶和华的大日近了，近了，而且急速来到；耶和华日子的声音已到，勇士在那里痛苦呼喊。</span>
<span className="v" id="v15" data-v="15" data-xref="约珥 2:2; 以赛亚书 22:5; 启示录 6:17"> 那日是忿怒的日子，是困苦和艰难的日子，是毁坏和荒废的日子，是黑暗和幽冥的日子，是密云和幽暗的日子，</span>
<span className="v" id="v16" data-v="16" data-xref="何西阿 8:1; 阿摩司 3:6; 以赛亚书 32:14"> 是号角和警报的日子，要攻击坚固城和高大的城垛。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 3:17; 诗篇 83:10; 耶利米书 2:17"> 我必使人遭受患难，以致他们像盲人一样行走，因为他们得罪了耶和华。他们的血必像尘土被倒出，他们的肉必像粪土。</span>
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:8; 以西结 7:19; 箴言 11:4"> 在耶和华忿怒的日子，他们的银子和金子都不能救他们；全地必被祂忌邪的火吞灭，因为祂必使住在这地上的一切人终结，实在是可怕的终结。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:11; 彼得前书 1:15–16; 以弗所书 4:32"> 所以，你们要效法上帝，好像蒙爱的儿女一样。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:34; 加拉太书 2:20; 歌罗西书 3:14"> 也要凭爱心行事，正如基督爱了我们，为我们舍了自己，作献给上帝的供物和祭物，成为馨香的气味。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 3:5; 以弗所书 5:5; 加拉太书 5:19–21"> 至于淫乱、一切污秽或贪婪，在你们中间连提都不可，才合乎圣徒的体统；</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:8; 以弗所书 4:29; 帖撒罗尼迦前书 5:18"> 也不可有污言秽语、愚妄的话或粗俗的玩笑，这些都不相宜；倒要说感谢的话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:21; 哥林多前书 6:9–10; 以弗所书 5:3"> 你们要确实知道：凡淫乱的人、污秽的人，或贪婪的人——贪婪就是拜偶像——在基督和上帝的国里都没有产业。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="罗马书 1:18; 歌罗西书 2:8; 马太福音 24:4"> 不要让任何人用空洞的话欺骗你们；因为这些事，上帝的愤怒临到悖逆之子。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 18:4; 以弗所书 5:11; 提摩太前书 5:22"> 所以，不要与他们同伙。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:12; 约翰一书 1:7; 使徒行传 26:18"> 从前你们是黑暗，如今在主里却是光。你们要像光明的儿女一样行事，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:9–10; 加拉太书 5:22–23; 约翰三书 1:11"> 因为圣灵的果子在于一切良善、公义和真理，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:1–2; 希伯来书 12:28; 诗篇 19:14"> 要察验什么是主所喜悦的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:12; 提摩太前书 5:20; 帖撒罗尼迦后书 3:6"> 不要参与黑暗无果子的行为，倒要责备它们。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:3; 耶利米书 23:24; 传道书 12:14"> 因为他们暗中所行的事，就是提起来也是可耻的。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 3:20–21; 哥林多前书 4:5; 何西阿 2:10"> 但一切事被责备的时候，就被光显明出来；因为凡显明一切的就是光。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 60:1; 罗马书 13:11–12; 以赛亚书 26:19"> 所以有话说：“睡着的人哪，醒来！从死人中起来，基督就要光照你。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:5; 雅各书 3:13; 腓立比书 1:27"> 所以，你们要谨慎留意自己怎样行事；不要像不智慧的人，要像有智慧的人，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 阿摩司 5:13; 约翰福音 12:35"> 要赎回光阴，因为现今的日子邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:2; 帖撒罗尼迦前书 5:18; 歌罗西书 1:9"> 因此，不要作愚昧人，却要明白主的旨意是什么。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 罗马书 13:13"> 不要醉酒，酒中有放荡；却要被圣灵充满，</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:16; 哥林多前书 14:26; 诗篇 95:2"> 用诗篇、圣诗和灵歌彼此对说，在你们心中向主歌唱、作乐；</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 3:17; 帖撒罗尼迦前书 5:18; 希伯来书 13:15"> 凡事常常奉我们主耶稣基督的名，感谢上帝，就是父；</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:3; 以弗所书 5:24; 以弗所书 5:22"> 又要存敬畏基督的心，彼此顺服。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:18–1; 彼得前书 3:1–6; 提多书 2:5"> 作妻子的，要顺服自己的丈夫，如同顺服主。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 11:3–10; 歌罗西书 1:18; 以弗所书 1:22–23"> 因为丈夫是妻子的头，正如基督也是教会的头；祂自己是身体的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 5:33; 歌罗西书 3:20; 提多书 2:7"> 教会怎样顺服基督，妻子也要照样在凡事上顺服自己的丈夫。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:28"> 作丈夫的，要爱你们的妻子，正如基督爱教会，为她舍了自己，</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:22; 约翰福音 15:3; 以西结 36:25"> 为要使她成为圣洁，借着话语，用水的洗净洁净她，</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 1:22; 希伯来书 9:14; 彼得前书 1:19"> 好把教会荣耀地献给自己，没有斑点、皱纹或任何这样的瑕疵，而是圣洁、没有缺陷。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:25; 马太福音 19:5; 创世记 2:21–24"> 同样，丈夫也应当爱自己的妻子，如同爱自己的身体。爱自己妻子的，就是爱自己。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 34:14–15; 以弗所书 5:31; 传道书 4:5"> 从来没有人恨恶自己的肉身，总是养育、珍惜它，正如主待教会一样，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 6:15; 哥林多前书 12:12–27; 罗马书 12:5"> 因为我们是祂身体上的肢体，是祂的肉和骨。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 2:24; 马太福音 19:5; 马可福音 10:7–8"> “因此，人要离开父母，与妻子联合，二人成为一体。”</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 21:2; 哥林多后书 11:2; 以赛亚书 54:5"> 这奥秘是伟大的，但我是指着基督和教会说的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:2–7; 以斯帖记 1:20; 以弗所书 5:25"> 然而，你们各人也都要爱自己的妻子，如同爱自己；妻子也要敬重她的丈夫。</span>
</div>
</div>

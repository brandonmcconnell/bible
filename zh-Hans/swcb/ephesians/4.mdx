<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:10; 腓立比书 1:27; 帖撒罗尼迦前书 2:12"> 所以，我这在主里的囚徒恳求你们：行事为人要与所蒙的呼召相称，</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:12–13; 哥林多前书 13:7; 哥林多前书 13:4–5"> 凡事谦卑、温柔、忍耐，在爱中彼此宽容，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:10; 歌罗西书 3:13–15; 哥林多前书 12:12–13"> 竭力在和平的联结中保守圣灵所赐的合一。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:18; 罗马书 12:4–5; 哥林多前书 12:4–13"> 身体只有一个，圣灵只有一位，正如你们蒙召也是在你们呼召的一个盼望中；</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 8:6; 哥林多前书 12:13; 彼得前书 3:21"> 主只有一位，信心只有一个，洗礼只有一个；</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 11:36; 玛拉基书 2:10; 哥林多前书 8:6"> 上帝只有一位，就是众人的父，祂超乎众人之上，贯乎众人之中，也在我们众人里面。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10; 罗马书 12:3; 哥林多前书 12:7–11"> 但我们每一个人都照着基督恩赐的分量蒙了恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 68:18; 歌罗西书 2:15; 撒母耳记上 30:26"> 所以祂说：<br /><span className="pl pl-1">“祂升上高天的时候，</span><br /><span className="pl pl-2">掳掠了俘虏，</span><br /><span className="pl pl-2">又赐下礼物给人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:13; 马太福音 12:40; 箴言 30:4"> 既说“祂升上”，这岂不就是祂也先降到地的低下之处吗？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 7:26; 希伯来书 4:14; 以弗所书 1:20–23"> 那降下的，正是那升到诸天之上、远超一切的，为要充满万有。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:15; 哥林多前书 12:28–29; 以弗所书 2:20"> 祂所赐的，有些是使徒，有些是先知，有些是传福音的，有些是牧者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“牧师”">a</a></sup>和教师，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:11–14; 以弗所书 4:16; 哥林多前书 12:27"> 为要装备圣徒，去做服事的工作，建立基督的身体，</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:28; 约翰福音 17:21; 以弗所书 4:5"> 直到我们众人在信心和对上帝儿子的认识上同归于一，成为成熟的人，达到基督丰满身量的程度，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:9; 罗马书 16:17–18; 哥林多前书 14:20"> 使我们不再作小孩子，被人的诡计和狡猾中错谬的计谋所摇动，随各种教训之风飘来飘去；</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 3:18; 以弗所书 4:25; 撒迦利亚书 8:16"> 而是在爱中说真实的话，在凡事上长进，归向那作元首的，就是基督；</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:19; 约翰福音 15:5; 歌罗西书 2:2"> 本于祂，全身借着各节所供应的，配合联络起来，照着每一部分按其分量所发挥的功用，使身体增长，在爱中建立自己。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 彼得前书 4:3–4; 帖撒罗尼迦前书 4:1–2"> 所以我这样说，并且在主里郑重作证：你们行事为人不要再像其余的外邦人那样，存着虚妄的心思而行；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:15; 以弗所书 2:12; 罗马书 1:21–23"> 他们的悟性昏暗，因他们里面的无知，又因他们心里的刚硬，就与上帝的生命隔绝了。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:5; 罗马书 1:24–26; 提摩太前书 4:2"> 他们既然麻木不仁，就放纵自己去行私欲，贪婪地做各样污秽的事。</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 2:11–14; 约翰福音 6:45; 马太福音 11:29"> 但你们学习基督并不是这样，</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 5:20; 以弗所书 1:13; 希伯来书 3:7–8"> 如果你们确实听见了祂，并且照着在耶稣里的真理，在祂里面受过教导，</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 6:6; 希伯来书 12:1; 雅各书 1:21"> 就要在从前的生活方式上脱去旧人；这旧人因迷惑人的私欲而渐渐败坏；</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 12:2; 罗马书 8:6; 诗篇 51:10"> 又要在你们心思的灵里被更新，</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:10–14; 哥林多后书 5:17; 以弗所书 2:10"> 并且穿上新人；这新人是照着上帝的样式，在真理的公义和圣洁中被造的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 3:9; 撒迦利亚书 8:16; 箴言 12:22"> 所以，你们既然除去虚假，各人就要与邻舍说真话，因为我们是彼此的肢体。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 1:19; 诗篇 4:4; 诗篇 37:8"> “你们发怒，却不要犯罪。” 不要让太阳落下时你们还在愤怒中，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 4:7; 彼得前书 5:8; 以弗所书 6:16"> 也不要给魔鬼留地步<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“机会”">b</a></sup>。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前书 6:18; 帖撒罗尼迦前书 4:11–12; 加拉太书 6:10"> 偷窃的不要再偷，倒要劳力，亲手做正当的事，好有东西分给有需要的人。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 4:6; 帖撒罗尼迦前书 5:11; 传道书 10:12"> 不可让败坏的话从你们口中出来，只要说合乎需要、能建立人的好话，使听见的人得恩典。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19; 以赛亚书 63:10; 以弗所书 1:13–14"> 不要叫上帝的圣灵担忧；你们在祂里面受了印记，直到救赎的日子。</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:8; 传道书 7:9; 提多书 3:2–3"> 一切苦毒、烈怒、愤怒、喧嚷和毁谤，连同一切恶毒，都要从你们中间除去。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:12–13; 马太福音 6:14–15; 马可福音 11:25"> 要彼此恩慈相待，存怜悯的心，彼此饶恕，正如上帝在基督里也饶恕了你们。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:24; 提摩太后书 1:8; 腓立比书 1:13–16"> 因此，我保罗，为你们外邦人的缘故，成了基督耶稣的囚徒；</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:25–27; 提摩太前书 1:11; 提摩太后书 1:11"> 如果你们确实听说过，上帝为你们赐给我这恩典的安排，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:12; 罗马书 16:25; 以弗所书 1:9–11"> 就是这奥秘怎样借着启示让我知道，正如我前面简略写过的；</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 4:3; 哥林多前书 4:1; 哥林多后书 11:6"> 你们读了，就能明白我对基督奥秘的理解。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:10–12; 彼得后书 3:2; 提多书 1:1–3"> 这奥秘在过去的世代没有让世人知道，像如今借着圣灵启示给祂的圣使徒和先知一样；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:26–29; 约翰一书 1:3; 约翰一书 2:25"> 就是外邦人借着福音，在基督耶稣里同为后嗣，同为一个身体的肢体，同享祂的应许。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 1:19; 以弗所书 3:20; 以弗所书 3:2"> 我照着上帝恩典的恩赐，按着祂大能的运行，作了这福音的仆人。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 1:27; 哥林多前书 15:9; 以弗所书 2:7"> 我本是众圣徒中最微小的，却蒙赐这恩典，要把基督那测不透的丰富传给外邦人，</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26; 马太福音 13:35; 提摩太后书 1:9"> 又使众人都看见这奥秘的安排<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 读作“团契”，而不是“安排”">a</a></sup>是什么；这奥秘历代以来隐藏在创造万物的上帝里，祂是借着耶稣基督创造万物的，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:12; 以弗所书 6:12; 哥林多前书 2:7"> 为要使上帝多方面的智慧，如今借着教会，被天上执政的和掌权的知道；</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:11; 以弗所书 1:4"> 这是照着祂在我们的主基督耶稣里所成就的永恒旨意。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 2:18; 罗马书 5:2; 希伯来书 4:14–16"> 我们在祂里面，借着对祂的信心，就有胆量，并且可以坦然无惧地来到上帝面前。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:24; 帖撒罗尼迦后书 3:13; 哥林多后书 1:6"> 因此，我请求你们不要因我为你们所受的患难灰心；这些患难是你们的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 95:6; 以弗所书 1:16–19; 腓立比书 2:10"> 因此，我在我们主耶稣基督的父面前屈膝；</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 启示录 5:8–14; 以弗所书 1:21"> 天上地上的各家，都是从祂得名。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:11; 腓立比书 4:13; 以赛亚书 40:29–31"> 愿祂照着祂荣耀的丰富，借着祂的圣灵，用能力使你们内在的人刚强起来；</span>
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:7; 约翰一书 4:16; 约翰福音 14:23"> 使基督借着信心住在你们心里，使你们在爱中扎根立基，</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 103:11–12; 约伯记 11:7–9; 以弗所书 1:18–23"> 好让你们能与众圣徒一同刚强起来，明白什么是阔、长、高、深，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:23; 歌罗西书 2:9–10; 歌罗西书 1:10"> 并且知道基督那超越知识的爱，使你们被上帝一切的丰盛充满。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 9:8; 罗马书 4:21; 耶利米书 32:27"> 上帝能照着运行在我们里面的大能，成就超过我们所求所想的一切，并且极其丰盛；</span>
<span className="v" id="v21" data-v="21" data-xref="犹大书 1:25; 罗马书 11:36; 彼得后书 3:18"> 愿荣耀在教会中，并在基督耶稣里，归给祂，直到万代，直到永永远远。阿们。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="歌罗西书 2:13; 以弗所书 2:5–6; 歌罗西书 3:1–4"> 你们从前死在过犯和罪中时，祂使你们活了过来，</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:12; 约翰一书 5:19; 以弗所书 2:3"> 那时你们行在其中，随从这世界的潮流，顺服空中掌权者的首领，就是如今在悖逆之子里面运行的灵。</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 3:3; 以弗所书 4:22; 加拉太书 5:16–24"> 我们从前也都在他们中间，随着自己肉体的私欲生活，行肉体和心思所愿意的事，按本性是可怒之子，和其余的人一样。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 1:3; 以弗所书 1:7; 诗篇 86:15"> 然而，上帝有丰富的怜悯，因着祂爱我们的大爱，</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 3:24; 以弗所书 2:8; 罗马书 5:10"> 甚至当我们因过犯而死的时候，祂使我们与基督一同活了过来——你们得救是本乎恩典——</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:1–3; 以弗所书 1:3; 罗马书 6:4–5"> 又使我们与祂一同复活，并且在基督耶稣里使我们与祂一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 1:16–17; 提多书 3:4; 以弗所书 2:4"> 为要在将来的世代中，显明祂恩典极其丰富，就是祂在基督耶稣里向我们所施的恩慈；</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:22–26; 以弗所书 2:5; 罗马书 4:16"> 因为你们得救是本乎恩典，借着信心；这并不是出于你们自己，而是上帝的礼物，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:9; 罗马书 11:6; 提多书 3:3–5"> 不是出于行为，免得有人夸口。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:13; 歌罗西书 1:10; 希伯来书 13:21"> 因为我们是祂的作品，在基督耶稣里被造，为要行善；这些善行是上帝预先预备好的，好让我们行在其中。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 2:11; 歌罗西书 2:13; 歌罗西书 3:11"> 所以，你们要记得：从前你们按肉身来说是外邦人，被那些称为“受割礼”的人（这是在肉身上由人手所行的）称作“未受割礼”的人，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 4:8; 歌罗西书 1:21; 耶利米书 31:31–34"> 那时你们与基督隔绝，与以色列的国民身份无分，在应许的诸约上是外人，在世上没有指望，没有上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:39; 歌罗西书 1:20–22; 歌罗西书 1:13–14"> 但如今，在基督耶稣里，你们这些从前远离的人，借着基督的血已经得以亲近。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28; 歌罗西书 3:11; 歌罗西书 3:15"> 因为祂是我们的和平，祂使双方合而为一，并拆毁了中间隔断的墙，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 2:14; 加拉太书 3:10; 歌罗西书 1:21–22"> 在祂的肉身中废掉了仇恨，就是那包含在规条中的诫命律法，为要在祂自己里面把两者造成一个新人，成就和平，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:20–22; 罗马书 5:10; 哥林多后书 5:18–21"> 并借着十字架，使双方在一个身体里与上帝和好，借着十字架杀灭了仇恨。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 57:19–21; 使徒行传 10:36; 罗马书 5:1"> 祂来向你们这些远离的人传和平，也向那些亲近的人传和平。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:13; 以弗所书 3:12; 罗马书 5:2"> 因为我们双方借着祂，在一位圣灵里得以进到父面前。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:20; 约翰一书 3:1; 加拉太书 6:10"> 这样，你们不再是外人和寄居者，而是与圣徒同为国民，是上帝家里的人，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:4–5; 以赛亚书 28:16; 彼得前书 2:7–8"> 被建造在使徒和先知的根基上，基督耶稣自己就是房角石；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 3:16–17; 哥林多前书 3:9; 哥林多后书 6:16"> 在祂里面，整座建筑连接得整齐，在主里渐渐成长为一座圣殿；</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:4–5; 哥林多前书 3:16; 约翰一书 4:16"> 在祂里面，你们也一同被建造，成为上帝在圣灵里的居所。</span>
</div>

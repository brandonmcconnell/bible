<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:20–25; 箴言 23:22; 箴言 6:20"> 儿女们，你们要在主里顺服父母，因为这是正当的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 20:12; 申命记 27:16; 马太福音 15:4–6"> “要孝敬你的父亲和母亲”，这是第一条带有应许的诫命：</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 5:16; 申命记 4:40; 申命记 12:28"> “使你得福，并在地上长寿。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:21; 箴言 22:6; 箴言 29:15"> 父亲们，不要激怒你们的儿女，却要照着主的管教和训诫养育他们。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:18–21; 提多书 2:9–10; 歌罗西书 3:17–24"> 仆人们，要惧怕战兢，存专一的心，顺服那些按肉身作你们主人的人，如同顺服基督一样；</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:22–23; 帖撒罗尼迦前书 2:4; 加拉太书 1:10"> 不要只在有人看着时才服事，像讨人喜欢的人一样，却要像基督的仆人，从心里遵行上帝的旨意，</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:23; 以弗所书 6:5–6; 哥林多前书 10:31"> 甘心服事，如同服事主，不是服事人；</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:24; 路加福音 14:14; 箴言 11:18"> 因为知道各人无论做了什么善事，无论是奴仆还是自由人，都必从主那里得回同样的善报。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:25–1; 使徒行传 10:34; 罗马书 2:11"> 主人们，你们也要同样待仆人，停止威吓；因为知道他们和你们共同的主在天上，祂并不偏待人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 以赛亚书 40:31; 约书亚记 1:9"> 最后，你们要在主里，并在祂大能的力量中刚强起来。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 10:4; 罗马书 13:12; 以弗所书 6:13"> 要穿戴上帝的全副军装，使你们能站立得住，抵挡魔鬼的诡计。</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 1:13; 哥林多后书 4:4; 以弗所书 2:2"> 因为我们的争战不是抵挡血肉之人，而是抵挡那些执政的、掌权的、这世代黑暗的世界统治者，以及天上领域中属灵的邪恶势力。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 10:4; 路加福音 21:36; 以弗所书 6:11–17"> 所以，要穿戴上帝的全副军装，使你们在邪恶的日子能抵挡得住，并且成就了一切之后仍能站立。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:17; 帖撒罗尼迦前书 5:8; 以赛亚书 11:5"> 所以要站稳，用真理当腰带束腰，穿上公义的胸甲，</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 罗马书 10:15; 哥林多后书 5:18–21"> 又用和平福音的预备装备你们的脚，</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 5:8–9; 约翰一书 5:4–5; 箴言 18:10"> 此外，还要拿起信心的盾牌；借着它，你们就能熄灭那恶者一切燃烧的箭。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 以赛亚书 59:17; 启示录 19:15"> 并且要戴上救恩的头盔，拿起圣灵的宝剑，就是上帝的话语<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="来自希腊语“ῥῆμα”（rhema），意思是“说出来的话”">a</a></sup>；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:17; 歌罗西书 4:2; 腓立比书 4:6"> 借着各样的祷告和祈求，时时在圣灵里祷告；为此要警醒，以完全的恒忍，为众圣徒祈求。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 4:3; 使徒行传 4:29; 帖撒罗尼迦后书 3:1"> 也要为我祷告，使我开口的时候有话语赐给我，好坦然无惧地显明福音的奥秘，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:20; 歌罗西书 4:4; 提摩太后书 2:9"> 我为这福音作了带锁链的使者；愿我能为它坦然无惧地讲论，正如我所当讲的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 提摩太后书 4:12; 提多书 3:12"> 至于我的事，我的景况如何，亲爱的弟兄、在主里忠心的仆人推基古会把一切告诉你们，使你们也可以知道。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:25; 歌罗西书 4:7–8; 帖撒罗尼迦后书 2:17"> 我特意差他到你们那里去，为要使你们知道我们的情况，并使他安慰你们的心。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:16; 加拉太书 5:6; 彼得前书 5:14"> 愿平安归给弟兄们，愿爱与信心从父上帝和主耶稣基督归给他们。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 22:37; 哥林多后书 8:12; 马太福音 6:13"> 愿恩典与所有以不朽的爱爱我们主耶稣基督的人同在。阿们。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:2; 哥林多后书 1:1; 哥林多前书 1:1–2"> 保罗，照着上帝的旨意作基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>耶稣使徒的，写给在以弗所的圣徒，就是在基督耶稣里忠信的人：</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 加拉太书 1:3; 提多书 1:4"> 愿恩典和平安从我们的父上帝和主耶稣基督归给你们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 1:3; 哥林多后书 1:3; 以弗所书 2:6"> 愿颂赞归给我们主耶稣基督的上帝和父；祂在基督里，曾在天上的境界中，把各样属灵的福分赐给我们，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 1:9; 罗马书 8:28–30; 以弗所书 2:10"> 正如祂在创世以前，在基督里拣选了我们，使我们在爱中，在祂面前成为圣洁、没有瑕疵；</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:29–30; 以弗所书 1:11; 加拉太书 4:5–6"> 又照着祂旨意所喜悦的，预定我们借着耶稣基督得儿子的名分，归于祂自己，</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 3:22–26; 以弗所书 1:12; 歌罗西书 1:13"> 使祂荣耀的恩典得着赞美；这恩典是祂在那蒙爱的里面白白赐给我们的。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 2:24; 罗马书 3:24; 约翰一书 1:7–9"> 我们在祂里面，借着祂的血得了救赎，就是过犯得赦免，这是照着祂恩典的丰富。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 5:12; 以弗所书 3:10; 罗马书 5:15"> 这恩典是祂用各样的智慧和明达，丰富地赐给我们的；</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26–28; 罗马书 16:25–27; 以弗所书 3:3–9"> 祂照着自己所喜悦的，使我们知道祂旨意的奥秘，就是祂在基督里所预先定下的，</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 1:20; 腓立比书 2:9–10; 加拉太书 4:4"> 为了在日期满足时的安排，使万有都在基督里归于一，就是天上的和地上的，都在祂里面归于一。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:28; 彼得前书 1:4; 以赛亚书 46:10–11"> 我们也在祂里面得了产业，既按着那位照自己旨意的谋划运行万事者的目的，预先被定下，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 1:6; 耶利米书 17:5–7; 以弗所书 1:13–14"> 为要使我们这些预先把盼望放在基督里的人，成为祂荣耀的赞美。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 1:22; 以弗所书 4:30; 提摩太后书 2:19"> 你们也在祂里面，听见了真理的话，就是你们救恩的福音；你们也在祂里面信了，就受了所应许的圣灵为印记。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 1:22; 哥林多后书 5:5; 以弗所书 4:30"> 这圣灵是我们产业的凭据，直到上帝自己产业得蒙救赎，使祂的荣耀得着赞美。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="腓利门书 1:5; 歌罗西书 1:3–4; 帖撒罗尼迦后书 1:3"> 因此，我既听见你们在主耶稣里的信心，以及你们对众圣徒的爱，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:8–9; 歌罗西书 1:9; 歌罗西书 1:3"> 就不住地为你们感谢，在我的祷告中提到你们，</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 11:2; 雅各书 3:17–18; 歌罗西书 1:9–10"> 求我们主耶稣基督的上帝，荣耀的父，把智慧和启示的灵赐给你们，使你们认识祂；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:18; 哥林多后书 4:6; 路加福音 24:45"> 又使你们心中的眼睛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认经文作“悟性”，而不是“心”。">b</a></sup>被照亮，好叫你们知道祂呼召的盼望是什么，祂在圣徒中所得产业的荣耀是何等丰富，</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 2:13; 以弗所书 3:20; 歌罗西书 2:12"> 并且知道祂向我们这些信的人所显的能力，是何等超越地伟大，照着祂大能的力量所运行的功效。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:12; 马可福音 16:19; 诗篇 110:1"> 祂曾使这能力运行在基督身上，使祂从死人中复活，又使祂在天上的境界中坐在自己的右边，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:9–11; 歌罗西书 2:10; 歌罗西书 1:15–16"> 远超过一切执政、权柄、能力、主权，以及一切有名号的；不但在今世，也在来世。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 1:18; 歌罗西书 2:10; 哥林多前书 15:25–27"> 上帝又使万有都服在祂的脚下，并使祂作万有之上的头，赐给教会；</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:18–19; 约翰福音 1:16; 歌罗西书 2:9–10"> 教会是祂的身体，是那在万有中充满万有者的丰满。</span>
</div>

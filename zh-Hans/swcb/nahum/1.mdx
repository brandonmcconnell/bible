<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 2:13; 约拿 1:2; 撒迦利亚书 9:1"> 关于尼尼微的默示。伊勒歌斯人那鸿所得异象的书。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 8:2; 出埃及记 20:5; 诗篇 94:1"> 耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当译作全大写的“LORD”或“GOD”时，是上帝专有名（希伯来文“יהוה”，通常读作雅威）的译文。">a</a></sup>是忌邪的上帝<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>，并且施行报应。耶和华施行报应，满有烈怒。耶和华向祂的敌人报仇，向祂的仇敌怀怒。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 147:5; 出埃及记 34:6–7; 尼希米记 9:17"> 耶和华不轻易发怒，大有能力，绝不使有罪的免受惩罚。耶和华在旋风和暴风中行走，云彩是祂脚下的尘土。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 33:9; 诗篇 106:9; 诗篇 114:5"> 祂斥责海，使海干涸，使一切江河枯干。巴珊和迦密衰残，黎巴嫩的花也衰残。</span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 1:4; 撒母耳记下 22:8; 耶利米书 4:24"> 群山在祂面前震动，丘陵都消融。大地在祂面前颤抖，世界和其中所有居民也是如此。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 10:10; 玛拉基书 3:2; 申命记 32:22–23"> 谁能在祂的愤恨面前站立？谁能承受祂怒气的猛烈？祂的烈怒如火倾倒，磐石也被祂崩裂。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 10:27; 提摩太后书 2:19; 耶利米哀歌 3:25"> 耶和华本为善，在患难的日子作坚固保障；祂认识那些投靠祂的人。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:17; 以赛亚书 8:22; 以西结 13:13"> 但祂必以涨溢的洪水彻底毁灭那地方，并且追赶祂的仇敌进入黑暗。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 21:11; 箴言 21:30; 诗篇 33:10"> 你们谋算什么来抵挡耶和华呢？祂必彻底毁灭；苦难不会第二次兴起。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 7:4; 以赛亚书 5:24; 以赛亚书 9:18"> 他们像荆棘缠结，又像喝醉了酒的人，必如干枯的碎秸全然被吞灭。</span>
<span className="v" id="v11" data-v="11" data-xref="那鸿书 1:9; 历代志下 13:7; 列王纪下 18:13–14"> 有一个从你那里出来，图谋恶事抵挡耶和华，献邪恶的计谋。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 30:19; 约珥 2:19; 以赛亚书 17:14"> 耶和华如此说：“他们虽然势力充足，人数众多，仍必被剪除，归于无有。我虽然曾使你受苦，却不再使你受苦。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 10:27; 以赛亚书 9:4; 耶利米书 2:20"> 现在我必从你身上折断他的轭，挣开你的捆绑。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 109:13; 以赛亚书 46:1–2; 弥迦书 5:13"> 耶和华已经论到你下令说：“你的名不再有后裔承继。我必从你众神的庙中剪除雕刻的偶像和铸造的偶像。我必为你预备坟墓，因为你卑劣。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 罗马书 10:15; 以赛亚书 40:9–10"> 看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”来自“הִנֵּה”，意思是看、留意、观察、看见或凝视，常用作感叹词。">c</a></sup>在山上有报好消息、传扬平安之人的脚踪！犹大啊，要守你的节期，履行你的誓愿，因为那恶人不再从你中间经过；他已全然被剪除。</span>
</div>
</div>

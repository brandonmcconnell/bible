<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 3:1–3; 哈巴谷 2:12; 何西阿 4:2"> 流人血的城有祸了！它充满谎言和抢夺，掠物无穷。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 47:3; 那鸿书 2:3–4; 约伯记 39:22–25"> 鞭声响起，车轮轰鸣，马匹腾跃，战车奔驰；</span>
<span className="v" id="v3" data-v="3" data-xref="哈巴谷 3:11; 以西结 39:4; 以赛亚书 34:3"> 骑兵冲锋，刀剑闪烁，枪矛发光；被杀的人众多，尸体成堆，尸首无穷。人们在尸体上绊跌，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 47:9; 以赛亚书 47:12–13; 启示录 17:1–5"> 都是因为那迷人的妓女大行淫乱；她是巫术的主母，用淫乱出卖列国，用巫术出卖万族。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 13:26; 以西结 23:29; 耶利米书 13:22"> 万军之耶和华说：“看哪，我与你为敌。我要把你的裙子掀到你脸上；我要使列国看见你的赤身，使列邦看见你的羞耻。</span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 2:9; 耶利米书 51:37; 约伯记 9:31"> 我要把可憎的污秽扔在你身上，使你卑贱，使你成为被人观看的对象。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 15:5; 以赛亚书 51:19; 启示录 18:10"> 凡看见你的，都必逃离你，说：‘尼尼微荒废了！谁会为她哀哭呢？’我到哪里为你寻找安慰你的人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="阿摩司 6:2; 以西结 30:14–16; 耶利米书 46:25–26"> 你比挪亚们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：底比斯">a</a></sup>更好吗？她坐落在众河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：尼罗河">b</a></sup>之间，四围有水；海是她的堡垒，海是她的城墙。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 30:5; 以西结 27:10; 以赛亚书 20:5"> 古实和埃及是她无穷的力量；普特和利比亚是她的帮手。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 20:4; 约珥 3:3; 何西阿 13:16"> 然而她也被掳走，进入被掳之地。她的婴孩也在各街口被摔碎；人为她的尊贵人拈阄，她所有的显贵都被锁链捆绑。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 49:26; 以赛亚书 2:10; 诗篇 75:8"> 你也必醉倒；你必隐藏起来；你也必因敌人寻找坚固的避难所。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 6:13; 以赛亚书 28:4; 哈巴谷 1:10"> 你所有的堡垒都必像结着初熟无花果的无花果树；若被摇动，果子就落入吃的人口中。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 51:30; 以赛亚书 19:16; 耶利米书 50:37"> 看哪，你里面的军队像妇女一样。你国土的城门向你的敌人敞开；火吞灭了你的门闩。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 32:3–4; 那鸿书 2:1; 历代志下 32:11"> 你要为受围困打水；要加固你的堡垒；要进入泥土，踩踏灰浆；要使砖窑坚固。</span>
<span className="v" id="v15" data-v="15" data-xref="约珥 1:4; 那鸿书 2:13; 那鸿书 3:13"> 在那里，火必吞灭你；刀剑必剪除你；它必像蚱蜢吞食一样吞灭你。你尽管像蚱蜢一样增多，像蝗虫一样增多吧。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 22:17; 尼希米记 9:23; 耶利米书 33:22"> 你增添商人，多过天上的星。蚱蜢掠尽就飞走。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 51:27; 启示录 9:7"> 你的卫士像蝗虫，你的官员像成群的蝗虫，在寒冷的日子停在墙上；太阳一出现，它们就飞走，它们所在之处也无人知道。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 22:17; 诗篇 76:5–6; 耶利米书 50:18"> 亚述王啊，你的牧人沉睡；你的贵族躺卧。你的百姓分散在山上，无人聚集他们。</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 1:9; 耶利米哀歌 2:15; 约伯记 27:23"> 你的伤口无法医治，因为你的创伤致命。凡听见关于你的消息的，都为你拍掌；因为谁没有受过你无休止的残暴呢？</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约珥 3:9–11; 历代志下 25:8; 耶利米书 51:20–23"> 那击碎人的已经上来攻击你。要守住堡垒！要看守道路！要束紧腰！要大大增强你的力量！</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="诗篇 80:12–13; 以西结 37:23; 西番雅书 3:11"> 因为耶和华恢复雅各的尊荣，如同以色列的尊荣；因为毁灭者已经毁灭他们，毁坏了他们的葡萄枝。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结 23:14–15; 以赛亚书 63:1–3; 撒迦利亚书 6:2"> 他勇士的盾牌染成红色；英勇的人身穿朱红衣。预备之日，战车闪着钢光，松木枪被挥舞起来。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:13; 以西结 26:10; 那鸿书 3:2–3"> 战车在街道上狂奔，在宽阔处来回疾驰；它们的样子像火把，奔跑如闪电。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 46:12; 耶利米书 51:27–28; 耶利米书 50:29"> 他召集他的精兵；他们在路上跌跌撞撞。他们冲向城墙，防护盾牌已经安置妥当。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 45:1–2; 彼得后书 3:10–11"> 河闸都打开了，宫殿也瓦解了。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 38:14; 以赛亚书 59:11; 路加福音 23:48"> 这是命定的：她被揭露，被掳走；她的婢女哀鸣，声音如鸽子，用手捶胸。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 51:13; 启示录 17:1; 耶利米书 46:5"> 但尼尼微自古以来就像水池；然而他们逃走了。有人喊：“站住！站住！”却没有人回头。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 26:12; 但以理 11:8; 那鸿书 2:12–13"> 抢掠银子吧！抢掠金子吧！因为宝物无穷，各样珍贵之物丰盛无比。</span>
<span className="v" id="v10" data-v="10" data-xref="约珥 2:6; 诗篇 22:14; 但以理 5:6"> 她空虚、荒凉、废弃。人心消化，双膝相碰，他们的身体和脸面都变得苍白。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:29; 耶利米书 2:15; 以赛亚书 31:4"> 狮子的洞穴在哪里？少壮狮子的觅食之处在哪里？在那里，公狮、母狮和幼狮行走，无人使它们惧怕。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 51:34; 诗篇 17:12; 以赛亚书 10:6–14"> 公狮为幼狮撕碎足够的猎物，又为母狮勒死猎物，把所杀的充满自己的洞穴，把掠物充满自己的巢穴。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 21:13; 诗篇 46:9; 那鸿书 3:5"> 万军之耶和华说：“看哪，我与你为敌。我要在烟中焚烧她的战车，刀剑必吞灭你的少壮狮子；我必从地上除掉你的猎物，你使者的声音也不再被听见。”</span>

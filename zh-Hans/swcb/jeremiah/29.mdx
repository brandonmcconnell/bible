<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 9:20; 使徒行传 15:23; 希伯来书 13:22"> 以下是先知耶利米从耶路撒冷寄给被掳者中剩余的长老、祭司、先知，以及所有被尼布甲尼撒从耶路撒冷掳到巴比伦之人的信中的话。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 22:24–28; 耶利米书 27:20; 历代志下 36:9–10"> 这是在耶哥尼雅王、太后、宦官、犹大和耶路撒冷的官长、工匠和铁匠离开耶路撒冷以后，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 8:11; 历代志下 34:20; 耶利米书 39:14"> 借着沙番的儿子以利亚萨和希勒家的儿子基玛利雅的手送去的；他们是犹大王西底家派往巴比伦、去见巴比伦王尼布甲尼撒的人。信上说：</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 24:5; 以赛亚书 10:5–6; 以赛亚书 45:7"> 万军之耶和华——以色列的上帝，对所有我使他们从耶路撒冷被掳到巴比伦的人这样说：</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 29:28; 耶利米书 29:10; 以西结 28:26"> “你们要建造房屋，住在其中；栽种园子，吃其中的果子。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3–4; 创世记 24:51; 创世记 28:1–4"> 你们要娶妻，生儿养女；也要为你们的儿子娶妻，把你们的女儿嫁给丈夫，使他们生儿养女。你们要在那里增多，不要减少。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 2:1–2; 以斯拉记 6:10; 彼得前书 2:13–17"> 你们要为我使你们被掳到的那城寻求平安，并为那城向耶和华祷告；因为那城平安，你们也必平安。”</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:6; 耶利米书 5:31; 帖撒罗尼迦后书 2:9–11"> 万军之耶和华——以色列的上帝这样说：“不要让你们中间的先知和占卜的人欺骗你们；也不要听信你们使人所做的梦。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 27:15; 耶利米书 29:31; 耶利米书 29:23"> 因为他们奉我的名向你们说虚假的预言；我并没有差遣他们。”这是耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理 9:2; 撒迦利亚书 7:5; 耶利米书 24:6–7"> 耶和华这样说：“为巴比伦所定的七十年满了以后，我必眷顾你们，向你们成就我美好的话，使你们回到这地方。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 55:8–12; 诗篇 33:11; 弥迦书 4:12"> 因为我知道我向你们所怀的意念，”这是耶和华说的，“是赐平安的意念，不是降灾祸的意念，要给你们盼望和未来。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 7:7–8; 耶利米书 33:3; 诗篇 50:15"> 你们必呼求我，前来向我祷告，我就垂听你们。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:29–31; 诗篇 119:2; 马太福音 7:7"> 你们寻求我，若全心寻求我，就必寻见。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 36:1–38; 耶利米书 30:3; 历代志上 28:9"> 我必使你们寻见我，”这是耶和华说的，“我必扭转你们被掳的境况；我要从我赶你们到的各国和各处聚集你们，”这是耶和华说的，“我必带你们回到我使你们从那里被掳离开的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 29:8–9; 耶利米书 28:1–17; 以西结 1:3"> 因为你们说：“耶和华在巴比伦为我们兴起了先知，”</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 38:2–3; 耶利米书 38:17–23; 以西结 17:12–21"> 所以，耶和华论坐在大卫宝座上的王，和住在这城里的所有人民，就是你们那些没有和你们一同被掳去的弟兄，这样说：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 24:8–10; 耶利米书 29:18; 耶利米书 24:1–3"> 万军之耶和华这样说：“看哪，我必使刀剑、饥荒、瘟疫临到他们，使他们像坏得不能吃的烂无花果。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 29:8; 耶利米书 15:4; 耶利米书 42:18"> 我必用刀剑、饥荒、瘟疫追赶他们，使他们在地上万国中被抛来抛去；在我赶他们到的各国中，他们必成为令人惊骇、震惊、嗤笑和羞辱的对象。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 6:19; 耶利米书 26:5; 耶利米书 7:24–26"> 因为他们没有听从我的话，”这是耶和华说的，“就是我差遣我的仆人众先知到他们那里所说的话；我殷勤地差遣他们，你们却不听。”这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:5; 弥迦书 4:10; 以西结 3:15"> 所以，你们所有我从耶路撒冷打发到巴比伦去的被掳之人，要听耶和华的话。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 14:14–15; 耶利米哀歌 2:14; 耶利米书 29:8–9"> 万军之耶和华——以色列的上帝，论哥赖雅的儿子亚哈和玛西雅的儿子西底家这样说；他们奉我的名向你们说谎言的预言：“看哪，我必把他们交在巴比伦王尼布甲尼撒手中；他必在你们眼前杀死他们。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 65:15; 但以理 3:6; 但以理 3:21"> 在巴比伦所有被掳的犹大人必以他们作为咒诅的话说：‘愿耶和华使你像被巴比伦王用火烤死的西底家和亚哈一样！’</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:14; 希伯来书 4:13; 玛拉基书 3:5"> 因为他们在以色列中做了愚妄的事，与邻舍的妻子通奸，又奉我的名说虚假的话，是我没有吩咐他们的。我是知道这一切并作见证的。”这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 29:31–32"> 你要论到尼希兰人示玛雅，说：</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 37:3; 耶利米书 29:29; 耶利米书 52:24"> “万军之耶和华——以色列的上帝这样说：‘因为你曾以自己的名义写信给在耶路撒冷的所有人民，给玛西雅的儿子西番雅祭司，以及所有祭司，说：</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 20:1–2; 列王纪下 9:11; 约翰福音 10:20"> “耶和华立你接替耶何耶大祭司作祭司，使耶和华殿中有官员，可以管束每一个癫狂、妄自作先知的人；你要把他关在枷锁和镣铐中。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 25:16; 耶利米书 43:2–3; 耶利米书 29:26"> 现在，亚拿突人耶利米向你们妄自作先知，你为什么没有斥责他呢？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 29:5; 耶利米书 29:1; 耶利米书 29:10"> 因为他送信到巴比伦给我们，说：被掳的时期很长。你们要建造房屋，住在其中；栽种园子，吃其中的果子。”’”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 29:25"> 西番雅祭司就把这封信念给先知耶利米听。</span>
<span className="v" id="v30" data-v="30"> 于是耶和华的话临到耶利米，说：</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 29:9; 耶利米书 29:23–24; 耶利米书 14:14–15"> “你要传话给所有被掳的人，说：‘耶和华论尼希兰人示玛雅这样说：“因为示玛雅向你们说预言，而我并没有差遣他，他又使你们倚靠谎言，”</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 28:16; 列王纪下 7:19–20; 耶利米书 17:6"> 所以耶和华这样说：“看哪，我必惩罚尼希兰人示玛雅和他的后裔。他必没有一人住在这百姓中，也必不得看见我将要赐给我百姓的福，”这是耶和华说的，“因为他说了悖逆耶和华的话。”’”</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 46:14; 以赛亚书 11:11; 出埃及记 14:2"> 论到所有住在埃及地的犹太人，就是住在密夺、答比匿、挪弗和巴忒罗地的人，有话临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 6:11; 耶利米书 9:11; 耶利米书 34:22"> “万军之耶和华、以色列的上帝这样说：‘我降在耶路撒冷和犹大各城的一切灾祸，你们都看见了。看哪，今日它们成了荒凉，无人居住，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:26; 申命记 13:6; 申命记 32:17"> 这是因他们所行的邪恶惹我发怒，就是他们去烧香，事奉他们、你们和你们列祖都不认识的别神。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 26:5; 耶利米书 7:25; 耶利米书 7:13"> 然而，我差遣我所有的仆人众先知到你们那里，早早起来差遣他们，说：“啊，不要行这我所恨恶的可憎之事。”</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 11:10; 耶利米书 19:13; 历代志下 36:16"> 他们却不听，也不侧耳而听；他们没有离开自己的邪恶，停止向别神烧香。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:20; 耶利米书 21:5; 以赛亚书 51:17"> 因此，我的烈怒和愤怒倾倒出来，在犹大的城镇和耶路撒冷的街道上燃烧；它们就成为废墟和荒凉，正如今日一样。’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷 2:10; 耶利米书 51:22; 以西结 33:11"> “所以现在，耶和华、万军之上帝、以色列的上帝这样说：‘你们为什么行这大恶，害自己的性命，使你们中间的男人、女人、婴孩和吃奶的孩子从犹大中被剪除，以致你们无人存留呢？</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:18; 耶利米书 25:6–7; 耶利米书 44:3"> 你们以自己手所做的惹我发怒，在你们去寄居的埃及地向别神烧香，使你们被剪除，并在地上万国中成为咒诅和羞辱吗？</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:17–18; 约书亚记 22:17–20; 耶利米书 44:15–19"> 你们忘了你们列祖的邪恶、犹大列王的邪恶、他们妻子的邪恶、你们自己的邪恶，以及你们妻子在犹大地和耶路撒冷街道上所行的邪恶了吗？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:14; 彼得前书 5:6; 启示录 15:4"> 他们直到今日还没有谦卑下来，也没有惧怕，没有遵行我摆在你们和你们列祖面前的律法和律例。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 利未记 26:17; 利未记 20:5–6"> “所以万军之耶和华、以色列的上帝这样说：‘看哪，我必定意攻击你们，降祸，剪除全犹大。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 42:15–18; 耶利米书 42:22; 以赛亚书 65:15"> 我要取那些定意进入埃及地、在那里寄居的犹大余民，他们都必灭尽。他们必倒在埃及地；他们必被刀剑和饥荒灭尽。他们从最小的到最大的，都必死于刀剑和饥荒；他们必成为令人恐惧、惊骇、咒诅和羞辱的对象。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 11:22; 耶利米书 43:11; 耶利米书 44:27–28"> 我怎样用刀剑、饥荒和瘟疫惩罚耶路撒冷，也必照样惩罚那些住在埃及地的人；</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 9:27; 耶利米书 22:26–27; 耶利米书 42:17"> 以致犹大余民中那些进入埃及地、在那里寄居的人，没有一个能逃脱或存留下来，回到犹大地，就是他们心里渴望回去居住的地方；因为除了逃脱的人以外，没有人能回去。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 11:21; 耶利米书 5:1–5; 创世记 19:4"> 于是，所有知道自己妻子向别神烧香的男人，以及所有站在旁边的女人，聚成一大群，就是所有住在埃及地巴忒罗的百姓，都回答耶利米说：</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 21:14–15; 路加福音 19:27; 耶利米书 16:15–17"> “至于你奉耶和华的名对我们所说的话，我们不听你的。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 7:18; 尼希米记 9:34; 耶利米书 44:21"> 我们口中所出的一切话，我们必定履行，就是向天后烧香，向她浇奠祭，照我们、我们的列祖、我们的君王和我们的首领在犹大的城镇和耶路撒冷的街道上所行的；因为那时我们食物充足，生活安好，没有遭遇灾祸。</span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 3:13–15; 民数记 11:5–6; 约伯记 21:14–15"> 可是自从我们停止向天后烧香、向她浇奠祭以来，我们就缺乏一切，又被刀剑和饥荒灭尽。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:18; 耶利米书 44:15; 列王纪上 21:25"> 那些妇女说：“我们向天后烧香、向她浇奠祭的时候，为她做饼来敬拜她，向她浇奠祭，难道是没有我们的丈夫一起做的吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶利米就对所有回答他的百姓，就是男人和女人，对所有百姓说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 44:17; 耶利米书 44:9; 耶利米书 11:13"> “你们和你们列祖、你们的君王、你们的首领，以及那地的百姓，在犹大的城镇和耶路撒冷的街道上所烧的香，耶和华岂不记得，岂不放在心上吗？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 25:18; 以赛亚书 7:13; 玛拉基书 2:17"> 耶和华因你们所行的恶和你们所犯的可憎之事，就再也不能容忍。因此，你们的土地成了荒凉、惊骇和咒诅，无人居住，正如今日一样。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 9:9; 但以理 9:11–12; 尼希米记 13:18"> 因为你们烧香，得罪耶和华，没有听从耶和华的声音，也没有遵行祂的律法、律例和法度；所以这灾祸临到你们，正如今日一样。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 43:7; 耶利米书 44:15–16; 耶利米书 42:15"> 耶利米又对所有百姓，包括所有妇女说：“所有在埃及地的犹大人哪，要听耶和华的话！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 14:9; 使徒行传 23:12–15; 以赛亚书 28:15"> 万军之耶和华、以色列的上帝这样说：‘你们和你们的妻子都亲口说了，也亲手履行了，说：“我们所许的愿，就是向天后烧香、向她浇奠祭，我们必定履行。”<br />“‘那么，你们就坚守你们的愿，履行你们的愿吧。’</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="诗篇 50:16; 以西结 20:39; 希伯来书 6:13"> “所以，所有住在埃及地的犹大人哪，要听耶和华的话：‘看哪，我指着我的大名起誓，’耶和华说，‘在埃及全地，我的名必不再被任何犹大人口中提起，说：“主耶和华永活。”</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:28; 列王纪下 21:14; 耶利米书 1:10"> 看哪，我要守望他们，为要降祸，不是赐福；所有在埃及地的犹大人必被刀剑和饥荒灭尽，直到他们全都灭亡。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 44:14; 以赛亚书 27:12–13; 以赛亚书 10:19"> 逃脱刀剑的人，必从埃及地回到犹大地，人数稀少。所有进入埃及地、在那里寄居的犹大余民都必知道，是谁的话立得住，是我的话，还是他们的话。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 19:21; 马太福音 24:15–16; 耶利米书 44:30"> “‘这是给你们的记号，’耶和华说，‘就是我要在这地方惩罚你们，使你们知道我的话必定立得住，要降祸给你们。’</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 25:4–7; 耶利米书 43:9–13; 耶利米书 34:21"> 耶和华这样说：‘看哪，我必把埃及王法老合弗拉交在他仇敌的手中，交在寻索他性命的人手中，正如我把犹大王西底家交在他的仇敌、寻索他性命的巴比伦王尼布甲尼撒手中一样。’”</span>
</div>

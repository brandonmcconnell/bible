<div className="bp poetry">

<span className="v" id="v5" data-v="5" data-xref="西番雅书 1:10–11; 阿摩司 8:10; 以赛亚书 5:30"> 耶和华如此说：<br /><span className="pl pl-1">“我们听见颤抖的声音；</span><br /><span className="pl pl-2">是恐惧的声音，不是平安的声音。</span></span>
<span className="v" id="v6" data-v="6" data-xref="那鸿书 2:10; 约珥 2:6; 耶利米书 4:31"> <span className="pl pl-1">你们现在问问看：男人会生产吗？</span><br /><span className="pl pl-2">我为什么看见人人双手按腰，像生产的妇人一样，</span><br /><span className="pl pl-2">脸色全都变得苍白？</span></span>
<span className="v" id="v7" data-v="7" data-xref="但以理 12:1; 撒迦利亚书 14:1–2; 玛拉基书 4:1"> <span className="pl pl-1">哀哉！那日为大，无日可比！</span><br /><span className="pl pl-2">这正是雅各遭难的时候；</span><br /><span className="pl pl-2">但他必从其中得拯救。</span></span>
<span className="v" id="v8" data-v="8" data-xref="那鸿书 1:13; 以西结 34:27; 以赛亚书 9:4"> <span className="pl pl-1">到那日，万军之耶和华说，我必从你颈项上折断他的轭，</span><br /><span className="pl pl-2">并挣开你的绳索。</span><br /><span className="pl pl-2">外族人不再使他们作奴仆；</span></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿 3:5; 以赛亚书 55:3–5; 路加福音 1:69"> <span className="pl pl-1">他们却要事奉耶和华他们的上帝，</span><br /><span className="pl pl-2">以及我为他们兴起的大卫他们的王。</span></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 46:27–28; 以赛亚书 43:5; 耶利米书 29:14"> <span className="pl pl-1">所以，我的仆人雅各啊，不要惧怕，耶和华说。</span><br /><span className="pl pl-2">以色列啊，不要惊惶。</span><br /><span className="pl pl-1">因为看哪，我要从远方拯救你，</span><br /><span className="pl pl-2">从他们被掳之地拯救你的后裔。</span><br /><span className="pl pl-1">雅各必归回，</span><br /><span className="pl pl-2">安静安稳。</span><br /><span className="pl pl-2">没有人使他惧怕。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 10:24; 耶利米书 1:19; 以赛亚书 8:10"> <span className="pl pl-1">因为我与你同在，要拯救你，耶和华说；</span><br /><span className="pl pl-2">我必将我赶散你到的万国彻底灭绝，</span><br /><span className="pl pl-2">却不将你彻底灭绝；</span><br /><span className="pl pl-1">但我要按度纠正你，</span><br /><span className="pl pl-2">绝不任你不受惩罚。”</span></span>

<span className="v" id="v16" data-v="16" data-xref="耶利米书 10:25; 以赛亚书 33:1; 出埃及记 23:22"> <span className="pl pl-1">因此，凡吞吃你的都必被吞吃。</span><br /><span className="pl pl-2">你所有的敌人，每一个都必被掳。</span><br /><span className="pl pl-1">抢夺你的必成为被抢夺的。</span><br /><span className="pl pl-2">凡掠夺你的，我必使他们成为被掠夺的。</span></span>

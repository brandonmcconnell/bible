<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 36:1; 列王纪下 24:1–2; 但以理 1:1"> 约西亚的儿子犹大王约雅敬第四年，就是巴比伦王尼布甲尼撒元年，临到耶利米、论到犹大众民的话，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 18:11; 耶利米书 19:14–15; 马可福音 7:14–15"> 是先知耶利米对犹大众民和耶路撒冷全体居民所说的：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 11:7; 耶利米书 26:5; 耶利米书 1:2"> “从亚们的儿子犹大王约西亚十三年，直到今日，这二十三年来，耶和华的话临到我，我也对你们说，早早起来不断地说；可是你们没有听。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 25:3; 耶利米书 26:5; 耶利米书 13:10–11"> 耶和华差遣祂所有仆人众先知到你们这里，早早地不断差遣他们；可是你们没有听，也没有侧耳去听。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 7:7; 创世记 17:8; 以赛亚书 55:6–7"> 他们说：‘你们各人现在要回转，离开自己的恶道和所行的恶，就可以住在耶和华赐给你们和你们祖先的土地上，从古时直到永远。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:19; 耶利米书 7:6; 耶利米书 35:15"> 不要随从别的神去事奉、敬拜它们，也不要用你们手所做的惹我发怒；这样，我就不加害于你们。’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 21:15; 箴言 8:36; 申命记 32:21"> “然而你们没有听从我，”耶和华说，“反倒用你们手所做的惹我发怒，以致害了自己。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 因此，万军之耶和华这样说：“因为你们没有听从我的话，</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 13:3; 耶利米书 18:16; 耶利米书 1:15"> 看哪，我必差遣人去召来北方的所有族类，”耶和华说，“又召来我的仆人巴比伦王尼布甲尼撒，带他们来攻击这地、这地的居民，以及四围所有这些国家。我要把他们彻底毁灭，使他们令人惊骇、被人嗤笑，成为永远的荒凉。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 7:34; 启示录 18:22–23; 以西结 26:13"> 并且，我要从他们中间除掉欢喜的声音和快乐的声音，新郎的声音和新娘的声音，磨石的声音和灯的亮光。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 9:2; 撒迦利亚书 1:12; 历代志下 36:21–22"> 这全地必成为荒凉，令人惊骇；这些国家必服事巴比伦王七十年。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理 9:2; 以赛亚书 13:19; 耶利米书 29:10"> “七十年满了以后，我必惩罚巴比伦王和那国，”耶和华说，“因他们的罪孽，也必使迦勒底人的地永远荒凉。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 1:10; 耶利米书 1:5; 但以理 5:31"> 我必使我论到那地所宣告的一切话，就是写在这书上、耶利米论到列国所预言的一切话，都临到那地。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 51:6; 耶利米书 27:7; 耶利米书 50:9"> 因为许多国家和大君王必使他们作奴仆，正是使他们作奴仆；我必照他们的行为，照他们手所做的报应他们。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 14:10"> 因为耶和华以色列的上帝对我这样说：“你从我手中接过这盛满烈怒之酒的杯，使我所差你去的列国都喝这杯。</span>
<span className="v" id="v16" data-v="16" data-xref="那鸿书 3:11; 耶利米书 51:7; 耶利米书 51:39"> 他们必喝，摇摇晃晃，神志昏乱，因为我要在他们中间差来刀剑。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 1:10; 耶利米书 25:28; 以西结 43:3"> 于是我从耶和华手中接过那杯，使耶和华所差我去的列国都喝：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:9; 诗篇 60:3; 耶利米书 44:22"> 就是耶路撒冷和犹大的城邑，以及它的君王和首领，使他们成为荒凉，令人惊骇，被人嗤笑，受人咒诅，正如今日一样；</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 46:13–26; 那鸿书 3:8–10; 耶利米书 46:2"> 埃及王法老和他的臣仆、首领，以及他的全体人民；</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:1; 以西结 30:5; 以赛亚书 20:1"> 一切混杂的民族，乌斯地的诸王，非利士人的诸王，亚实基伦、迦萨、以革伦，以及亚实突剩下的人；</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 48:1–22; 诗篇 137:7; 耶利米书 9:26"> 以东、摩押和亚扪人；</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 47:4; 阿摩司 1:9–10; 以西结 28:22–23"> 推罗的诸王，西顿的诸王，以及海那边岛屿的诸王；</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 9:26; 耶利米书 49:32; 耶利米书 49:8"> 底但、提玛、布斯，以及所有剃去鬓角的人；</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 9:14; 耶利米书 25:20; 以西结 30:5"> 阿拉伯的诸王，以及住在旷野中混杂民族的诸王；</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:11; 创世记 10:22; 以赛亚书 13:17"> 心利的诸王，以拦的诸王，玛代人的诸王；</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 51:41; 耶利米书 25:9; 耶利米书 50:1–46"> 北方远近的诸王，彼此相连；还有地面上世上所有的国。示沙克王也必在他们以后喝。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 25:16; 哈巴谷 2:16; 以西结 21:4–5"> “你要对他们说：‘万军之耶和华以色列的上帝这样说：“你们要喝，喝醉，呕吐，跌倒，不再起来，因为我要在你们中间差来刀剑。”’</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 34:33; 耶利米书 51:29; 以赛亚书 14:24–27"> 如果他们不肯从你手中接过那杯来喝，你就要对他们说：‘万军之耶和华这样说：“你们必定要喝。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 38:21; 箴言 11:31; 彼得前书 4:17"> 看哪，我既从称为我名下的城开始降灾，你们岂能完全不受惩罚吗？你们必不能不受惩罚；因为我要召刀剑临到地上所有居民，万军之耶和华说。”’</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="阿摩司 1:2; 约珥 3:16; 以赛亚书 42:13"> “所以你要把这一切话向他们发预言，告诉他们：<br /><span className="pl pl-1">“‘耶和华必从高处吼叫，</span><br /><span className="pl pl-2">从祂圣洁的居所发声。</span><br /><span className="pl pl-2">祂必向自己的羊圈大声吼叫；</span><br /><span className="pl pl-1">祂要像踹葡萄的人一样发出呼喊，</span><br /><span className="pl pl-2">攻击地上所有居民。</span></span>
<span className="v" id="v31" data-v="31" data-xref="何西阿 4:1; 约珥 3:2; 以赛亚书 66:16"> <span className="pl pl-1">响声必传到地极；</span><br /><span className="pl pl-2">因为耶和华与列国有争讼。</span><br /><span className="pl pl-1">祂必审判凡有血肉的。</span><br /><span className="pl pl-2">至于恶人，祂必把他们交给刀剑，”耶和华说。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 23:19; 以赛亚书 34:2; 历代志下 15:6"> 万军之耶和华这样说：<br /><span className="pl pl-1">“看哪，灾祸必从一国传到另一国；</span><br /><span className="pl pl-2">大风暴必从地极兴起。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 66:16; 耶利米书 8:2; 诗篇 79:3"> 到那日，从地这边直到地那边，到处都有被耶和华击杀的人。他们无人哀哭，无人收殓，也无人埋葬；他们必成为地面上的粪土。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 6:26; 耶利米书 50:27; 诗篇 2:9"> <span className="pl pl-1">牧人哪，你们要哀号呼喊；</span><br /><span className="pl pl-2">羊群的领袖啊，你们要在尘土中打滚；</span><br /><span className="pl pl-1">因为你们被宰杀和分散的日子已经满了，</span><br /><span className="pl pl-2">你们必像精美的陶器一样坠落破碎。</span></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 11:20; 阿摩司 2:14; 耶利米书 52:8–11"> <span className="pl pl-1">牧人没有路可逃，</span><br /><span className="pl pl-2">羊群的领袖也无处逃脱。</span></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 4:8; 耶利米书 25:34"> <span className="pl pl-1">听啊，牧人呼喊的声音，</span><br /><span className="pl pl-2">羊群领袖哀号的声音，</span><br /><span className="pl pl-2">因为耶和华毁坏他们的草场。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 27:10–11; 以赛亚书 32:14"> <span className="pl pl-1">平安的羊圈都寂静无声，</span><br /><span className="pl pl-2">因为耶和华的烈怒。</span></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:7; 耶利米书 5:6; 何西阿 13:7–8"> <span className="pl pl-1">祂像狮子离开自己的隐密处；</span><br /><span className="pl pl-2">因压迫的凶猛，</span><br /><span className="pl pl-2">又因祂的烈怒，他们的土地已令人惊骇。</span></span>
</div>

</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米书 2:7; 创世记 38:14; 以西结 8:4–6"> “你举目望向光秃的高处，看看吧！哪里没有人与你同寝呢？你坐在路旁等候他们，像旷野中的阿拉伯人一样。你因你的淫乱和邪恶玷污了这地。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 26:19; 耶利米书 14:4; 申命记 28:23"> 因此甘霖被止住，春雨也没有降下；然而你有妓女的额，一点也不肯羞愧。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 2:2; 耶利米书 3:19; 诗篇 71:17"> 从今以后，你岂不向我呼喊说：‘我的父啊，你是我幼年的引导者！’吗？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:3; 以赛亚书 57:16; 以西结 22:6"> “‘祂会永远怀怒吗？祂会存留怒气到底吗？’看哪，你这样说了，又行了恶事，并且得逞了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:7–17; 以西结 16:31; 耶利米书 7:24"> 约西亚王在位的日子，耶和华又对我说：“背道的以色列所做的，你看见了吗？她上到各高山，在各青翠树下，在那里行淫。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 16:46; 何西阿 6:1–4; 何西阿 14:1"> 她做了这一切以后，我说：‘她会归向我；’但她没有归回；她诡诈的妹妹犹大也看见了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 24:1; 何西阿 4:15–17; 以赛亚书 50:1"> 我看见背道的以色列犯了奸淫，正因这缘故，我休了她，给了她休书；然而她诡诈的妹妹犹大并不惧怕，也去行淫。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 2:27; 以赛亚书 57:6; 耶利米书 3:2"> 因她轻看自己的淫乱，这地就被玷污；她又与石头和木头行奸淫。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿 7:14; 耶利米书 12:2; 历代志下 34:33–18"> 虽然如此，她诡诈的妹妹犹大还没有全心归向我，只是假意归向我，”耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结 23:11; 以西结 16:51–52; 何西阿 11:7"> 耶和华对我说：“背道的以色列比诡诈的犹大还显为义。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 86:15; 以西结 33:11; 申命记 4:29–31"> 你去，向北方宣告这些话，说：‘背道的以色列啊，回来吧，’耶和华说；‘我必不以怒容看你，因为我有怜悯，’耶和华说。‘我必不永远怀怒。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:25; 耶利米书 3:6; 申命记 12:2"> 只要承认你的罪孽，就是你违背了耶和华你的上帝，在各青翠树下把你的道路分散给外人，并且没有听从我的声音，’”耶和华说。</span>
<span className="v" id="v14" data-v="14" data-xref="何西阿 2:19–20; 耶利米书 2:19; 耶利米书 31:32"> “背道的儿女啊，回来吧，”耶和华说，“因为我是你们的丈夫。我要从一座城取你们一人，从一个宗族取你们两人，把你们带到锡安。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:4; 使徒行传 20:28; 以弗所书 4:11–12"> 我也要把合我心意的牧人赐给你们，他们必以知识和明辨牧养你们。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 65:17; 阿摩司 9:14–15; 以西结 37:26"> 到那些日子，你们在地上增多兴旺的时候，”耶和华说，“人必不再说：‘耶和华的约柜！’它也不再进入人心。人不再记念它，不再想念它，也不再另造一个。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 43:7; 弥迦书 4:1–5; 耶利米书 17:12"> 那时，人必称耶路撒冷为‘耶和华的宝座’；万国都必聚集到它那里，归向耶和华的名，归向耶路撒冷。他们不再随从自己邪恶之心的顽梗而行。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:8; 何西阿 1:11; 阿摩司 9:15"> 在那些日子，犹大家必与以色列家同行，他们要一同从北方之地出来，到我赐给你们列祖为业的地去。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:4; 耶利米书 31:9; 以赛亚书 63:16"> “但我说：‘我何等愿意把你列在儿女之中，赐给你可喜悦的地，就是列国万军中美好的产业！’我又说：‘你要称我为“我的父”，也不再转离不跟从我。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 48:8; 耶利米书 5:11; 何西阿 5:7"> “以色列家啊，妻子怎样诡诈地离开丈夫，你们也照样以诡诈待我，”耶和华说。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 7:10; 耶利米书 31:9; 耶利米书 2:32"> 在光秃的高处，有声音被听见，就是以色列儿女的哭泣和恳求；因为他们扭曲了自己的道路，忘记了耶和华他们的上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿 14:1; 何西阿 14:4; 撒迦利亚书 13:9"> 背道的儿女啊，回来吧！我要医治你们的背道。<br />“看哪，我们来到你面前；因为你是耶和华我们的上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 121:1–2; 诗篇 3:8; 以赛亚书 12:2"> 从山冈而来的帮助、山上的喧嚷，实在是枉然的。以色列的救恩实在在于耶和华我们的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿 9:10; 以西结 16:63; 以西结 16:61"> 但那可耻之物从我们幼年以来吞吃了我们列祖劳碌所得，就是他们的羊群、牛群、儿女。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 22:21; 箴言 5:13; 以赛亚书 50:11"> 让我们躺卧在自己的羞耻中，让我们的惭愧遮盖我们；因为从我们幼年以来直到今日，我们和我们的列祖都得罪了耶和华我们的上帝，没有听从耶和华我们上帝的声音。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 26:2; 启示录 3:22; 阿摩司 7:16"> “你要站在耶和华殿的门口，在那里宣告这话，说：‘所有从这些门进去敬拜耶和华的犹大人哪，你们要听耶和华的话。’”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:11; 耶利米书 26:13; 以赛亚书 1:16–19"> 万军之耶和华——以色列的上帝如此说：“你们要改正自己的道路和行为，我就使你们住在这地方。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:11; 马太福音 3:9–10; 西番雅书 3:11"> 不要倚靠虚谎的话，说：‘这是耶和华的殿，耶和华的殿，耶和华的殿。’</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:12–13; 以赛亚书 1:19; 耶利米书 7:3"> 你们若真正改正自己的道路和行为，若真正使人与邻舍之间施行公正；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:21–24; 撒迦利亚书 7:9–12; 耶利米书 13:10"> 若不欺压寄居者、孤儿和寡妇，不在这地方流无辜人的血，也不随从别的神明，以致自害，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:40; 耶利米书 25:5; 耶利米书 3:18"> 我就使你们住在这地方，就是我从古时直到永远赐给你们列祖的土地。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:15; 以西结 13:6–16; 耶利米书 23:14–16"> 看哪，你们倚靠无益的虚谎话。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:6; 出埃及记 20:3; 雅各书 4:1–4"> 难道你们要偷盗、杀人、通奸、起假誓、向巴力烧香、随从你们素不认识的别神，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:34; 以西结 23:37; 以西结 23:39"> 然后来到这称为我名下的殿，站在我面前，说：‘我们得了拯救’，好去行这一切可憎的事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以赛亚书 56:7; 马太福音 21:13"> 这称为我名下的殿，在你们眼中竟成了强盗的巢穴吗？看哪，我自己都看见了，”耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 26:6; 撒母耳记上 4:10–11"> “你们现在去我起初使我名居住的地方，就是在示罗的地方，看看我因我子民以色列的邪恶怎样对待了它。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 65:12; 历代志下 36:15–16; 耶利米书 7:25"> 现在，因为你们行了这一切事，”耶和华说，“我也对你们说话，早早起来不断地说，你们却不听；我呼唤你们，你们却不回答；</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:60; 列王纪下 25:9; 耶利米书 7:4"> 所以，我必照我对示罗所做的，来对待这称为我名下、你们所倚靠的殿，以及我赐给你们和你们列祖的地方。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1; 列王纪下 17:23; 耶利米书 52:3"> 我必把你们从我眼前赶出去，正如我赶出你们所有的弟兄，就是以法莲的全体后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：种子">a</a></sup>一样。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 11:14; 耶利米书 14:11–12; 耶利米书 15:1"> “所以，你不要为这百姓祷告。不要为他们呼求或祈祷，也不要向我代求；因为我不会听你。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 8:6–18; 以西结 14:23; 耶利米书 6:27"> 他们在犹大的城镇和耶路撒冷的街道上所做的事，你没有看见吗？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 19:13; 耶利米书 44:17–19; 哥林多前书 10:22"> 孩子捡柴，父亲生火，妇女揉面，为天后做饼，又向别神浇奠祭，好惹我发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 20:11; 耶利米书 2:19; 但以理 9:7–8"> 他们是在惹我发怒吗？”耶和华说。“他们岂不是惹自己发怒，使自己的脸蒙羞吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 42:18; 耶利米哀歌 2:3–5; 以赛亚书 42:25"> 因此主耶和华如此说：“看哪，我的怒气和烈怒必倾倒在这地方，临到人、牲畜、田野的树木和地里的出产；它必燃烧，不能熄灭。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿 8:13; 耶利米书 6:20; 阿摩司 5:21–23"> 万军之耶和华——以色列的上帝如此说：“把你们的燔祭加在你们的祭物上，吃肉吧。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿 6:6; 撒母耳记上 15:22; 诗篇 51:16–17"> 因为我把你们列祖从埃及地领出来的日子，并没有就燔祭或祭物对他们说话，也没有吩咐他们；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:26; 申命记 5:33; 出埃及记 19:5–6"> 我只吩咐他们这一件事，说：‘你们要听从我的声音，我就作你们的上帝，你们也要作我的子民。你们要行在我所吩咐你们的一切道路上，使你们得福。’</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 耶利米书 8:5; 耶利米书 7:26"> 他们却不听，也不侧耳而听，反而照自己的计谋和邪恶之心的顽梗而行，向后退，不向前进。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 36:15; 耶利米书 25:4; 尼希米记 9:26"> 自从你们列祖出埃及地的日子直到今日，我差遣我所有仆人众先知到你们那里，天天早早起来差遣他们。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 16:12; 历代志下 30:8; 耶利米书 7:24"> 然而他们不听从我，也不侧耳而听，反而硬着颈项。他们行恶比他们列祖更甚。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 26:2; 耶利米书 1:7; 以赛亚书 65:12"> “你要把这一切话告诉他们，但他们不会听你。你也要呼唤他们，但他们不会回答你。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:14–15; 箴言 1:7; 以赛亚书 1:4–5"> 你要对他们说：‘这就是那不听从耶和华他们上帝声音、不接受管教的国民。真理已经灭绝，从他们口中断绝了。’</span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 弥迦书 1:16; 耶利米书 6:30"> 剪掉你的头发，丢弃吧；在光秃的高处举哀吧；因为耶和华已经弃绝并撇弃祂所震怒的世代。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 32:34; 以西结 7:20; 但以理 9:27"> “因为犹大的子孙行了我眼中看为恶的事，”耶和华说。“他们把可憎之物放在称为我名下的殿中，玷污这殿。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:10; 耶利米书 32:35; 利未记 18:21"> 他们在欣嫩子谷建造陀斐特的邱坛，要在火中焚烧自己的儿女；这不是我所吩咐的，也不是我心中所起的意念。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 19:11; 耶利米书 19:6; 列王纪下 23:10"> 因此，看哪，日子将到，”耶和华说，“那里不再称为‘陀斐特’或‘欣嫩子谷’，而要称为‘杀戮谷’；因为他们要在陀斐特埋葬死人，直到没有地方可埋。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 12:9; 申命记 28:26; 启示录 19:17–18"> 这百姓的尸首必成为天空飞鸟和地上走兽的食物，没有人把它们吓走。</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 18:23; 何西阿 2:11; 以西结 26:13"> 那时，我必使犹大城镇和耶路撒冷街道上的欢喜声和快乐声、新郎的声音和新娘的声音都止息；因为这地必成为荒场。”</span>
</div>
</div>

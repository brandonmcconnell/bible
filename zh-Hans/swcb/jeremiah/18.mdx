<span className="v" id="v1" data-v="1"> 有话从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 1:1; 使徒行传 9:6; 耶利米书 19:1–2"> “你起来，下到窑匠的家去；在那里，我要使你听见我的话。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:14; 约拿 1:3; 使徒行传 26:19"> 于是我下到窑匠的家；看哪，他正在轮盘上做器皿。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:20–23; 耶利米书 18:6; 以赛亚书 45:9"> 窑匠用泥做的器皿，在他手中做坏了，他就照自己看为好的样式，另做成别的器皿。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华的话临到我，说：</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 64:8; 罗马书 9:20–21; 耶利米书 18:4"> “以色列家啊，难道我不能像这窑匠一样待你们吗？”耶和华说。“看哪，泥在窑匠手中怎样，你们在我手中也怎样，以色列家啊。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:10; 耶利米书 12:14–17; 耶利米书 45:4"> 我什么时候论到一邦、一国，说要拔出、拆毁、毁灭它；</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 18:21; 耶利米书 26:13; 约拿 3:9–10"> 如果我所论到的那一国转离他们的恶，我就为原想加给他们的灾祸转意。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:28; 阿摩司 9:11–15; 耶利米书 1:10"> 我什么时候论到一邦、一国，说要建立、栽植它；</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 33:18; 撒母耳记上 2:30; 以西结 18:24"> 如果他们行我眼中看为恶的事，不听从我的声音，我就为曾说要赐给他们的好处转意。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 17:13; 以赛亚书 55:6–7; 耶利米书 35:15"> “所以现在你要对犹大人和耶路撒冷的居民说：‘耶和华如此说：“看哪，我正在筹划灾祸攻击你们，设计计谋攻击你们。你们各人现在都要转离自己的恶道，改正你们的道路和行为。”’</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:25; 耶利米书 7:24; 申命记 29:19"> 但他们说：‘这是徒然；因为我们要照自己的计谋行事，我们各人都要随从自己邪恶之心的顽梗。’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 5:30; 何西阿 6:10; 耶利米书 23:14"> 因此，耶和华如此说：<br /><span className="pl pl-1">“你们现在到列国中去询问：</span><br /><span className="pl pl-2">‘谁听见过这样的事？’</span><br /><span className="pl pl-2">以色列处女做了一件极可憎的事。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 6:68"> <span className="pl pl-1">黎巴嫩的雪岂会从田野的磐石上断绝吗？</span><br /><span className="pl pl-2">从远方流下的寒水岂会干涸吗？</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:16; 耶利米书 2:32; 何西阿 11:2"> <span className="pl pl-1">然而我的子民忘记了我；</span><br /><span className="pl pl-2">他们向假神烧香。</span><br /><span className="pl pl-1">他们被绊倒，离开自己的道路，</span><br /><span className="pl pl-2">离开古老的路径，</span><br /><span className="pl pl-2">去走小路，走未修筑的道路，</span></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 22:7; 耶利米书 25:9; 耶利米书 19:8"> <span className="pl pl-1">使他们的土地令人惊骇，</span><br /><span className="pl pl-2">永远被人嗤笑。</span><br /><span className="pl pl-1">凡经过这地的人都必惊骇，</span><br /><span className="pl pl-2">摇头叹息。</span></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 13:24; 耶利米书 2:27; 约伯记 27:21"> <span className="pl pl-1">我必在敌人面前，用东风般把他们驱散。</span><br /><span className="pl pl-2">在他们遭难的日子，</span><br /><span className="pl pl-2">我必以背向他们，不以面向他们。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="诗篇 52:2; 耶利米书 11:19; 玛拉基书 2:7"> 于是他们说：“来吧！让我们设计计谋攻击耶利米；因为律法不会从祭司那里消失，谋略不会从智慧人那里消失，话语也不会从先知那里消失。来吧，让我们用舌头攻击他，不要听他的任何话。”</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:9; 耶利米书 20:12; 诗篇 55:16–17"> <span className="pl pl-1">耶和华啊，求你留心听我，</span><br /><span className="pl pl-2">听那些与我争竞之人的声音。</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 35:7; 诗篇 57:6; 诗篇 106:23"> <span className="pl pl-1">难道可以以恶报善吗？</span><br /><span className="pl pl-2">他们竟为我的性命挖了坑。</span><br /><span className="pl pl-1">求你记得我怎样站在你面前为他们说好话，</span><br /><span className="pl pl-2">要使你的烈怒转离他们。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 109:9–20; 耶利米哀歌 5:3; 阿摩司 4:10"> <span className="pl pl-1">因此，求你把他们的儿女交给饥荒，</span><br /><span className="pl pl-2">把他们交在刀剑的权势之下。</span><br /><span className="pl pl-1">愿他们的妻子丧子又守寡；</span><br /><span className="pl pl-2">愿他们的男人被杀死，</span><br /><span className="pl pl-2">愿他们的青年人在战场上被刀剑击杀。</span></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 6:26; 诗篇 140:5; 西番雅书 1:10–11"> <span className="pl pl-1">当你使军队突然临到他们时，</span><br /><span className="pl pl-2">愿哀声从他们的屋中传出；</span><br /><span className="pl pl-1">因为他们挖坑要捉拿我，</span><br /><span className="pl pl-2">又暗设网罗绊我的脚。</span></span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 35:4; 诗篇 69:22–28; 尼希米记 4:4–5"> <span className="pl pl-1">然而，耶和华啊，你知道他们要杀我的一切计谋。</span><br /><span className="pl pl-2">不要赦免他们的罪孽；</span><br /><span className="pl pl-2">不要从你眼前涂抹他们的罪。</span><br /><span className="pl pl-1">愿他们在你面前倾覆；</span><br /><span className="pl pl-2">愿你在发怒的时候处置他们。</span></span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 11:6; 出埃及记 19:5; 历代志下 29:10"> “你们要听这约的话，并告诉犹大人和耶路撒冷的居民；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 27:26; 申命记 28:15–68; 申命记 29:19–20"> 要对他们说，耶和华——以色列的上帝如此说：‘不听这约之话的人是受咒诅的。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:12; 耶利米书 7:22–23; 申命记 4:20"> 这约是我在把你们列祖从埃及地、从铁炉中领出来的日子吩咐他们的，说：“你们要听从我的声音，并照我所吩咐你们的一切去行；这样，你们就要作我的子民，我也要作你们的上帝；</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:12–13; 诗篇 105:9–11; 耶利米书 28:6"> 好使我坚立我向你们列祖所起的誓，把流奶与蜜之地赐给他们，”正如今日一样。’”<br />于是我回答说：“阿们，耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:22; 罗马书 2:13; 耶利米书 7:2"> 耶和华对我说：“你要在犹大的城邑中和耶路撒冷的街道上宣告这一切话，说：‘你们要听这约的话，并且遵行。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 36:15; 以弗所书 4:17; 撒母耳记上 8:9"> 因为从我把你们列祖从埃及地领上来的日子，直到今日，我都恳切告诫他们，早早起来告诫，说：“你们要听从我的声音。”</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 7:24; 耶利米书 7:26; 耶利米书 35:15"> 然而他们没有听从，也没有侧耳而听，反倒各人随从自己恶心的顽梗而行。因此，我使这约的一切话临到他们；这约是我吩咐他们遵行的，他们却没有遵行。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿 6:9; 马太福音 26:3–4; 弥迦书 3:11"> 耶和华对我说：“在犹大人和耶路撒冷居民中发现了阴谋。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 31:16; 以西结 16:59; 诗篇 78:8–10"> 他们转回去随从他们先祖的罪孽；那些先祖拒绝听我的话。他们去随从别神，事奉它们。以色列家和犹大家都背弃了我与他们列祖所立的约。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 8:18; 箴言 1:28; 以赛亚书 1:15"> 因此耶和华如此说：‘看哪，我必使灾祸临到他们，是他们不能逃脱的；他们要向我呼求，我却不听他们。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:28; 申命记 32:37; 历代志下 28:22"> 那时，犹大的城邑和耶路撒冷的居民要去向他们烧香所拜的神明呼求；但在他们遭难的时候，那些神明绝不能拯救他们。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:28; 列王纪下 23:13; 以赛亚书 2:8"> 犹大啊，你神明的数目与你城邑的数目相等；你们为那可耻之物所设立的祭坛，就是向巴力烧香的祭坛，数目也与耶路撒冷街道的数目相等。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 7:16; 耶利米书 11:11; 约翰一书 5:16"> “所以，你不要为这百姓祷告，不要为他们发出呼求或祈祷；因为他们因遭难向我呼求的时候，我必不听他们。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多书 1:15; 耶利米书 3:1–2"> <span className="pl pl-1">我所爱的在我殿中做什么呢？</span><br /><span className="pl pl-2">她既与许多人行淫乱，</span><br /><span className="pl pl-2">圣肉也已离开你。</span><br /><span className="pl pl-1">你行恶的时候，</span><br /><span className="pl pl-2">竟然欢喜。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:17–24; 以赛亚书 27:11; 诗篇 52:8"> <span className="pl pl-1">耶和华曾给你起名叫“青翠的橄榄树，</span><br /><span className="pl pl-2">果实美好而秀丽”。</span><br /><span className="pl pl-1">祂以大哄嚷的声音点火在其上，</span><br /><span className="pl pl-2">它的枝子就折断了。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 5:2; 耶利米书 2:21; 耶利米书 12:2"> 因为栽种你的万军之耶和华已经宣告灾祸攻击你；这是因以色列家和犹大家所行的恶，他们向巴力烧香，惹我发怒，是自招祸患。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 23:11–12; 列王纪下 6:9–10; 以西结 8:6–18"> 耶和华使我知道这事，我就知道了；那时祢把他们所做的事指示我。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 53:7–8; 耶利米书 20:10; 诗篇 83:4"> 但我像一只温顺的羔羊被牵去宰杀。我不知道他们已经设计谋害我，说：<br /><span className="pl pl-1">“让我们毁坏这树和它的果子；</span><br /><span className="pl pl-2">让我们把他从活人之地剪除，</span><br /><span className="pl pl-2">使他的名不再被记念。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 20:12; 耶利米书 17:10; 撒母耳记上 16:7"> <span className="pl pl-1">然而，按公义审判的万军之耶和华啊，</span><br /><span className="pl pl-2">察验人心和意念的主啊，</span><br /><span className="pl pl-1">我必看见祢在他们身上施行报应；</span><br /><span className="pl pl-2">因为我已将我的案件向祢陈明。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 20:10; 阿摩司 2:12; 路加福音 13:33–34"> “所以，耶和华论到寻索你性命的亚拿突人如此说；他们说：‘你不可奉耶和华的名说预言，免得你死在我们手中’——</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 18:21; 历代志下 36:17; 耶利米书 9:21"> 因此万军之耶和华如此说：‘看哪，我必惩罚他们。年轻人必死于刀剑；他们的儿女必死于饥荒。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:12; 弥迦书 7:4; 何西阿 9:7"> 他们必没有余剩的人，因为我必使灾祸临到亚拿突人，就是他们受惩罚的那一年。’”</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="以西结 24:1–2; 耶利米书 52:4–7; 列王纪下 25:1–12"> 犹大王西底家第九年十月，巴比伦王尼布甲尼撒和他的全军来攻打耶路撒冷，围困这城。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 52:6–7; 弥迦书 2:12–13; 列王纪下 25:3–4"> 到西底家第十一年四月初九日，城被攻破了。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:4; 耶利米书 38:17; 耶利米书 39:13"> 巴比伦王的众首领都进来，坐在中门那里：尼甲沙利薛、三甲尼波、拉伯撒利撒西金、拉伯玛尼甲沙利薛，以及巴比伦王其余的一切首领。</span>
<span className="v" id="v4" data-v="4" data-xref="阿摩司 2:14; 历代志下 32:5; 列王纪下 25:4–7"> 犹大王西底家和所有战士看见他们，就在夜间逃跑，从王的园子，经过两道城墙之间的门，出城往亚拉巴方向去了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:33; 约书亚记 5:10; 耶利米书 52:26–27"> 迦勒底人的军队追赶他们，在耶利哥的平原追上了西底家。他们拿住他，把他带到哈马地的利比拉，带到巴比伦王尼布甲尼撒那里；王就判定他的罪。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 52:10; 耶利米书 34:19–21; 耶利米书 24:8–10"> 巴比伦王在利比拉，在西底家眼前杀了他的众子；巴比伦王又杀了犹大所有的贵族。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 12:13; 列王纪下 25:7; 耶利米书 52:11"> 并且剜了西底家的眼睛，用铜链锁住他，要把他带到巴比伦去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 1:3; 耶利米书 38:18; 耶利米书 21:10"> 迦勒底人用火焚烧王宫和百姓的房屋，并拆毁耶路撒冷的城墙。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 40:1; 创世记 37:36; 耶利米书 10:18"> 护卫长尼布撒拉旦把城里剩下的百姓、投降归向他的逃兵，以及其余剩下的百姓，都掳到巴比伦去。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 25:12; 耶利米书 40:7; 耶利米书 52:16"> 但是护卫长尼布撒拉旦把民中一无所有的穷人留在犹大地，同时把葡萄园和田地赐给他们。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:23; 耶利米书 15:21; 约伯记 5:19"> 巴比伦王尼布甲尼撒吩咐护卫长尼布撒拉旦有关耶利米的事，说：</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; 耶利米书 40:4; 箴言 21:1"> “你去带他来，好好照顾他，不可害他；他告诉你什么，你就照他的话待他。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:3; 耶利米书 39:9"> 于是护卫长尼布撒拉旦、拉伯撒利尼布沙斯班、拉伯玛尼甲沙利薛，以及巴比伦王所有的高级官员，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 38:28; 列王纪下 22:12; 耶利米书 26:24"> 派人把耶利米从护卫兵院中带出来，把他交给沙番的孙子、亚希甘的儿子基大利，要他带耶利米回家。于是耶利米住在民中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 2:9; 耶利米书 32:1–2; 耶利米书 36:1–5"> 耶利米还被关在护卫兵院中的时候，耶和华的话临到他，说：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 9:12; 撒迦利亚书 1:6; 约书亚记 23:14–15"> “你去对古实人以伯·米勒说：‘万军之耶和华、以色列的上帝这样说：“看哪，我要使我所说降祸不降福的话临到这城；到那日，这些话必在你眼前成就。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 41:1–2; 诗篇 91:14–15; 诗篇 50:15"> 但到那日，我必拯救你，”耶和华说；“你必不被交在你所惧怕的人手中。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:2; 诗篇 34:22; 耶利米书 21:9"> 因为我必定救你。你不会倒在刀下，却必保全性命，因为你信靠了我，”耶和华说。’”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:11; 耶利米书 40:13; 耶利米书 6:13"> 众军队的首领、加利亚的儿子约哈难、何沙雅的儿子耶撒尼亚，以及所有百姓，从最小的到最大的，都近前来，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 36:7; 利未记 26:22; 使徒行传 8:24"> 对先知耶利米说：“求你让我们的恳求呈在你面前，并且为我们，向耶和华你的上帝祷告，就是为这所有的余民祷告；因为你亲眼看见，我们从许多人中只剩下寥寥无几，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 86:11; 箴言 3:6; 诗篇 25:4–5"> 愿耶和华你的上帝指示我们当走的路，和当做的事。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 12:23; 撒母耳记上 3:17–18; 出埃及记 8:29"> 先知耶利米对他们说：“我听见了。看哪，我要照你们的话向耶和华你们的上帝祷告；无论耶和华怎样回答你们，我都要告诉你们，决不向你们隐瞒什么。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 31:50; 士师记 11:10; 玛拉基书 3:5"> 他们对耶利米说：“如果我们不照耶和华你的上帝差你来告诉我们的一切话去做，愿耶和华在我们中间作真实可信的见证人。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:23; 申命记 5:29; 罗马书 8:7"> 无论是好是坏，我们都要听从耶和华我们上帝的声音；我们差你到祂那里去，为要使我们听从耶和华我们上帝的声音，好叫我们得福。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:14; 以赛亚书 28:16; 哈巴谷 2:3"> 过了十天，耶和华的话临到耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:1; 耶利米书 41:11–16; 耶利米书 43:2–5"> 于是他召了加利亚的儿子约哈难、和他同在的众军队首领，以及所有百姓，从最小的到最大的，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 19:4; 耶利米书 42:2; 列王纪下 19:6"> 对他们说：“耶和华以色列的上帝，就是你们差我到祂面前呈上你们恳求的那一位，这样说：</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:28; 以西结 36:36; 耶利米书 24:6"> ‘如果你们仍住在这地，我就要建立你们，不拆毁你们；栽植你们，不拔出你们；因为我为我降在你们身上的灾祸而忧伤。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:31; 耶利米书 1:19; 耶利米书 1:8"> 不要惧怕你们所惧怕的巴比伦王。不要惧怕他，’耶和华说，‘因为我与你们同在，要拯救你们，救你们脱离他的手。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 1:11; 诗篇 106:45–46; 箴言 16:7"> 我要赐给你们怜悯，使他怜悯你们，并使你们归回自己的土地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 44:16; 出埃及记 5:2; 耶利米书 42:10"> “‘但如果你们说：“我们不住在这地，”以致不听从耶和华你们上帝的声音，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 41:17; 耶利米书 4:19; 以赛亚书 31:1"> 说：“不，我们要进入埃及地，在那里看不见战争，听不见号角声，也不会缺粮挨饿；我们要住在那里；”’</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 17:16; 耶利米书 44:12–14; 耶利米书 42:17"> 现在，犹大的余民哪，因此你们要听耶和华的话！万军之耶和华以色列的上帝说：‘如果你们果真定意要进入埃及，去那里寄居，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 44:27; 以西结 11:8; 阿摩司 9:1–4"> 那么，你们所惧怕的刀剑必在那里，在埃及地追上你们；你们所害怕的饥荒也必在那里，在埃及紧紧跟随你们；你们必死在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 42:22; 耶利米书 44:28; 耶利米书 44:13–14"> 凡定意要进入埃及、去那里寄居的人，都必如此。他们必死于刀剑、饥荒和瘟疫；他们中没有一人能存留，或逃脱我将降在他们身上的灾祸。’</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 7:20; 耶利米书 18:16; 耶利米书 29:18"> 因为万军之耶和华以色列的上帝这样说：‘我的怒气和烈怒怎样倾倒在耶路撒冷的居民身上，你们进入埃及时，我的烈怒也必照样倾倒在你们身上；你们必成为令人惊骇、惊愕、咒诅和羞辱的对象；你们必不再看见这地方。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 17:16; 以赛亚书 30:1–7; 尼希米记 9:26"> “犹大的余民哪，耶和华论到你们说：‘不要进入埃及！’你们要确实知道，我今日已经向你们作证。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 14:3–4; 以西结 33:31; 马太福音 22:15–18"> 因为你们欺骗了自己的性命；你们差我到耶和华你们的上帝那里，说：‘请为我们向耶和华我们的上帝祷告；耶和华我们的上帝所说的一切，都请告诉我们，我们就必遵行。’</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 2:7; 撒迦利亚书 7:11–12; 使徒行传 20:26–27"> 我今日已经告诉你们了；可是耶和华你们的上帝差我到你们这里所说的一切事，你们却一样也没有听从祂的声音。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 42:17; 以西结 6:11; 何西阿 9:6"> 现在你们要确实知道：你们渴望去寄居的地方，你们必死于刀剑、饥荒和瘟疫。”</span>
</div>

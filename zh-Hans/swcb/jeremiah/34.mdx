<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:15; 但以理 2:37–38; 列王纪下 25:1–9"> 当巴比伦王尼布甲尼撒和他的全军，以及他统治之下地上的列国和万民，正在攻打耶路撒冷和属耶路撒冷的一切城时，有话从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 21:10; 耶利米书 34:22; 耶利米书 37:8–10"> “耶和华——以色列的上帝如此说：‘你去告诉犹大王西底家，对他说，耶和华如此说：“看哪，我必将这城交在巴比伦王手中，他必用火焚烧它。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 32:4; 耶利米书 21:7; 列王纪下 25:4–7"> 你必不能逃脱他的手，必要被捉住，交在他手中。你的眼要看见巴比伦王的眼，他要与你面对面说话；你也必到巴比伦去。”’</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 然而，犹大王西底家啊，你要听耶和华的话。耶和华论到你如此说：‘你必不死于刀剑。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 22:18; 历代志下 16:14; 列王纪下 22:20"> 你必平安而死；人怎样为你以前的列祖，就是在你以前的先王焚烧，也必照样为你焚烧。他们必为你哀哭，说：“唉，我主啊！”因为这话是我说的，’这是耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 15:16–24; 撒母耳记上 3:18; 列王纪上 21:19"> 于是先知耶利米在耶路撒冷把这一切话告诉犹大王西底家；</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:3; 耶利米书 4:5; 列王纪下 18:13–14"> 那时，巴比伦王的军队正在攻打耶路撒冷，以及犹大剩下的一切城，就是攻打拉吉和亚西加；因为犹大的城中，只剩下这些坚固城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 25:10; 列王纪下 23:2–3; 列王纪下 11:17"> 西底家王与在耶路撒冷的众民立约，向他们宣告自由以后，有话从耶和华临到耶利米，</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 15:12; 利未记 25:39–46; 出埃及记 3:18"> 叫各人释放自己的男仆和女仆，凡是希伯来男人或希伯来女人，都让他们自由离去；谁也不可使自己的犹太弟兄作奴仆。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 26:16; 耶利米书 26:10; 耶利米书 38:4"> 凡立约的首领和众民都听从了，各人释放自己的男仆和女仆，让他们自由离去，不再使他们作奴仆。他们听从了，就释放了他们；</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 2:20–22; 箴言 26:11; 马太福音 12:43–45"> 但后来他们又反悔，使那些已经释放、自由离去的仆人和婢女回来，强迫他们重新作仆人和婢女。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 因此，有耶和华的话从耶和华临到耶利米，说：</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 6:8; 约书亚记 24:17; 申命记 5:27"> “耶和华——以色列的上帝如此说：‘我把你们的列祖从埃及地、从为奴之家领出来的日子，曾与他们立约，说：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 15:12; 列王纪上 9:22; 列王纪下 17:13–14"> “满了七年，你们各人都要释放自己的弟兄，就是那卖给你、服侍你六年的希伯来人；你要让他从你那里自由离去。”可是你们的列祖没有听从我，也没有侧耳而听。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 34:8; 列王纪下 23:3; 尼希米记 10:29"> 如今你们回转了，行我眼中看为正的事，各人向自己的邻舍宣告自由；你们也在称为我名下的殿中，在我面前立了约。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 19:12; 出埃及记 20:7; 耶利米书 34:11"> 但你们又反悔，亵渎我的名；各人使自己的仆人和婢女，就是你们已经释放、让他们随意自由离去的人回来，并且强迫他们作你们的仆人和婢女。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 7:2; 申命记 28:25; 加拉太书 6:7"> 所以耶和华如此说：“你们没有听从我，没有各人向自己的弟兄、自己的邻舍宣告自由。看哪，我要向你们宣告自由，”这是耶和华说的，“使你们归于刀剑、瘟疫和饥荒；我必使你们在地上的万国中被抛来抛去。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 15:10; 创世记 15:17–18; 何西阿 6:7"> 那些违背我的约、不履行他们在我面前所立之约的话的人，就是把牛犊劈成两半、从两半中间经过的人，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 34:10; 西番雅书 3:3–4; 但以理 9:6"> 犹大的首领、耶路撒冷的首领、太监、祭司，以及这地的众民，就是从牛犊两半中间经过的人，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 7:33; 耶利米书 16:4; 耶利米书 19:7"> 我必将他们交在仇敌手中，交在寻索他们性命的人手中。他们的尸体必成为天空飞鸟和地上走兽的食物。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 52:24–27; 耶利米书 39:6; 耶利米书 52:10"> “我必将犹大王西底家和他的首领交在他们仇敌手中，交在寻索他们性命的人手中，也交在已经离开你们的巴比伦王军队手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 9:11; 耶利米书 39:8; 耶利米书 39:1–2"> 看哪，我必下令，”这是耶和华说的，“使他们回到这城。他们必攻打这城，攻取它，并用火焚烧它。我必使犹大的城邑荒凉，无人居住。”</span>
</div>
</div>

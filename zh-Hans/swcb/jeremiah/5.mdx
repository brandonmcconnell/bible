<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 18:23–32; 历代志下 16:9; 以西结 22:30"> “你们在耶路撒冷的街上来回奔跑吧；现在查看、知道，并在她的广场上寻找，看看能不能找到一个人，有没有一个行公义、寻求诚实的人；若有，我就赦免这城。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:16; 耶利米书 4:2; 何西阿 4:1–2"> 他们虽然说：『耶和华永活』，其实他们所起的誓是假的。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 2:30; 耶利米书 7:28; 以赛亚书 9:13"> 耶和华啊，你的眼目岂不是看重诚实吗？你击打他们，他们却不忧伤；你毁灭他们，他们却拒绝接受管教。他们使自己的脸比磐石还硬，拒绝回转。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 8:7; 何西阿 4:6; 以赛亚书 28:9–13"> 于是我说：“这些人必定是贫穷的，是愚昧的；因为他们不知道耶和华的道路，也不知道他们上帝的律法。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 2:20; 雅各书 2:5–7; 马太福音 19:23–26"> 我要去见尊大的人，对他们说话，因为他们知道耶和华的道路，也知道他们上帝的律法。”可是这些人却一同折断了轭，挣开了绳索。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 4:7; 哈巴谷 1:8; 西番雅书 3:3"> 因此，林中的狮子必杀害他们；晚间的狼必毁灭他们；豹子必在他们的城外窥伺。凡从那里出去的，必被撕碎，因为他们的过犯众多，他们的背道增多。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:8; 约书亚记 23:7; 耶利米书 2:11"> “我怎能赦免你呢？你的儿女离弃我，指着那些不是神的起誓。我使他们饱足，他们却行淫，成群聚集在娼妓家里。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 13:27; 申命记 5:18; 撒母耳记下 11:2–4"> 他们像喂饱了、到处乱跑的马，各人都向邻舍的妻子嘶鸣。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:9; 耶利米书 5:29; 以赛亚书 1:24"> 我岂不因这些事惩罚他们吗？”耶和华说。“我的心岂不向这样的国施行报复吗？</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 4:27; 马太福音 22:7; 阿摩司 9:8"> “你们登上她的城墙，毁坏吧，但不可彻底毁灭。除掉她的枝条，因为它们不属于耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:20; 以赛亚书 48:8; 何西阿 6:7"> 因为以色列家和犹大家向我行了极大的诡诈。”耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 36:16; 以西结 12:22–28; 耶利米书 23:14–17"> 他们否认耶和华，说：“不是祂。灾祸不会临到我们；我们也不会见到刀剑或饥荒。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 14:15; 约伯记 8:2; 耶利米书 14:13"> 先知必成为风，道并不在他们里面；这样的事必临到他们。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:29; 耶利米书 1:9; 何西阿 6:5"> 因此，耶和华——万军之上帝说：“因为你们说这话，看哪，我要使我在你口中的话成为火，使这百姓成为柴，火必吞灭他们。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:49; 耶利米书 4:16; 以赛亚书 33:19"> 看哪，以色列家啊，我必使一个国家从远方来攻击你们。”耶和华说。“那是强大的国家，是古老的国家，是一个你们不认识其语言、也听不懂他们所说的话的国家。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 5:28; 诗篇 5:9; 罗马书 3:13"> 他们的箭袋是敞开的坟墓；他们全都是勇士。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 26:16; 申命记 28:33; 何西阿 8:14"> 他们必吞吃你的庄稼和粮食，就是你儿女该吃的；他们必吞吃你的羊群和牛群；他们必吞吃你的葡萄树和无花果树；他们必用刀剑击毁你所倚靠的坚固城。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 5:10; 罗马书 11:1–5; 耶利米书 4:27"> “但即使在那些日子，”耶和华说，“我也不把你们灭绝净尽。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 9:8–9; 申命记 28:47–48; 耶利米书 22:8–9"> 当你们说：『耶和华我们的上帝为什么向我们行这一切事呢？』那时，你要对他们说：『正如你们离弃我，在你们的土地上侍奉外邦的神；照样，你们也必在不属于你们的土地上侍奉外邦人。』</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> “你们要在雅各家宣告这事，在犹大传扬，说：</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 28:26; 以西结 12:2; 以赛亚书 6:9–10"> 『愚昧无知的百姓啊，你们有眼却看不见，有耳却听不见；现在要听这话：</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 38:10–11; 诗篇 104:9; 约伯记 26:10"> 你们岂不惧怕我吗？』耶和华说；『你们岂不在我面前战兢吗？我以永久的定例安置沙为海的界限，使海不能越过。波浪虽翻腾，却不能得胜；虽咆哮，仍不能越过。』</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 6:28; 申命记 21:18; 诗篇 95:10"> “但这百姓有悖逆反叛的心；他们背叛，离去了。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 147:8; 约珥 2:23; 创世记 8:22"> 他们心里不说：『我们现在当敬畏耶和华我们的上帝；祂按时赐下雨水，就是早雨和晚雨，又为我们保守收割所定的周数。』</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 59:2; 诗篇 107:17; 诗篇 107:34"> “你们的罪孽使这些事转离，你们的罪阻挡美善的事临到你们。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 1:11; 诗篇 64:5; 以西结 22:2–12"> 因为在我百姓中有恶人；他们窥探，好像捕鸟的人埋伏一样；他们设下圈套，捕捉人。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 1:12; 耶利米书 9:6; 何西阿 12:7–8"> 笼子怎样装满鸟，他们的家也怎样充满诡诈。因此他们成了大人物，也富足起来。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 1:23; 申命记 32:15; 耶利米书 7:6"> 他们肥胖光润；是的，他们在恶事上超过限度。他们不为孤儿的案件伸冤，使孤儿得以顺遂；也不维护穷人的权利。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 5:9; 玛拉基书 3:5; 耶利米书 9:9"> “我岂不因这些事惩罚他们吗？”耶和华说。“我的心岂不向这样的国施行报复吗？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="何西阿 6:10; 耶利米书 23:14; 以赛亚书 1:2"> “这地上发生了令人震惊又可怕的事：</span>
<span className="v" id="v31" data-v="31" data-xref="以西结 13:6; 耶利米书 14:14; 弥迦书 2:11"> 先知说虚假的预言，祭司凭自己的权柄掌权；我的百姓也喜爱这样。到了结局，你们要怎样行呢？”</span>
</div>

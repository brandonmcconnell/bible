<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约珥 2:12; 耶利米书 3:22; 耶利米书 3:12"> 耶和华说：“以色列啊，你若回转，若回转归向我，若从我眼前除掉你可憎之物，你就不再被迁移；</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 65:16; 耶利米书 9:24; 创世记 22:18"> 你要起誓说：‘耶和华永活’，并且要本着真实、公正和公义。列国必因祂为自己祝福，也必因祂夸耀。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿 10:12; 路加福音 8:7; 路加福音 8:14"> 因为耶和华对犹大人和耶路撒冷这样说：“要开垦你们的荒地，不要撒种在荆棘中。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 10:16; 申命记 30:6; 罗马书 2:28–29"> 犹大人和耶路撒冷的居民哪，要为耶和华给自己行割礼，除掉你们心上的包皮；免得我的烈怒如火发出，因你们行为的邪恶而焚烧，无人能扑灭。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 8:14; 耶利米书 6:1; 约书亚记 10:20"> 你们要在犹大宣告，在耶路撒冷传扬，说：‘要在这地吹号！’要大声呼喊说：‘你们要聚集！我们进坚固城吧！’</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:2; 耶利米书 1:13–15; 耶利米书 51:27"> 要向锡安竖立旗号。要逃命！不要停留；因为我必从北方带来灾祸和大毁灭。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:7; 耶利米书 5:6; 以赛亚书 6:11"> 狮子已经从它的密林中上来，毁灭列国的也已经出动。他已经动身，离开自己的地方，要使你的土地荒凉，使你的城邑荒废，无人居住。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 22:12; 耶利米书 6:26; 以赛亚书 10:4"> 因此，你们要披上麻衣，哀号哭喊；因为耶和华的烈怒还没有从我们转回。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 13:9–16; 以赛亚书 29:9–10; 以赛亚书 22:3–5"> 耶和华说：“到那日，王的心和首领的心都要丧胆；祭司必惊骇，先知必诧异。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:12; 帖撒罗尼迦后书 2:9–12; 以赛亚书 37:35"> 于是我说：“啊，主耶和华啊！你实在大大欺哄了这百姓和耶路撒冷，说：‘你们必得平安’，其实刀剑已经刺到心里。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="何西阿 13:15; 以西结 17:10; 耶利米书 23:19"> 那时，必有人对这百姓和耶路撒冷说：“有一阵热风从旷野中光秃的高处，吹向我民的女儿；不是为簸扬，也不是为洁净。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:16; 以西结 5:8; 以西结 6:11–13"> 一阵猛烈的风要从这些地方为我而来。现在我也要向他们宣告判决。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 19:1; 以赛亚书 66:15; 哈巴谷 1:8"> 看哪，他必如云上来，他的战车必如旋风。他的马比鹰更快。我们有祸了！因为我们败亡了。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 4:8; 以赛亚书 55:7; 使徒行传 8:22"> 耶路撒冷啊，要洗净你心中的邪恶，使你可以得救。你的恶念要在你里面存留多久呢？</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 8:16; 约书亚记 17:15; 士师记 18:29"> 因为有声音从但宣告，从以法莲山地传报灾祸：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 5:15; 以西结 21:22; 以赛亚书 39:3"> “要告诉列国；看哪，要向耶路撒冷传扬：‘守望者从远方之地而来，向犹大的城邑发声喊叫。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 5:23; 列王纪下 25:1–4; 尼希米记 9:30"> 他们像看守田地的人，四面围住她，因为她背叛了我，’”这是耶和华说的。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 2:19; 诗篇 107:17; 箴言 1:31"> “你的道路和你的行为把这些事招到你身上。这就是你的邪恶；它是苦的，已经刺入你的心。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哈巴谷 3:16; 以赛亚书 16:11; 以赛亚书 22:4"> 我的痛苦，我的痛苦！我心深处疼痛！我的心在我里面战栗。我不能缄默，因为我的灵魂啊，你已经听见号角声，战争的警报。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 42:7; 马太福音 10:28; 约珥 1:15"> 毁灭接着毁灭已经命定，因为全地都荒废了。我的帐棚忽然被毁，我的帐幕顷刻消失。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 36:10; 历代志下 36:3; 历代志下 36:6–7"> 我要看见旗号、听见号角声到几时呢？</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 14:20; 罗马书 16:19; 耶利米书 5:21"> “因为我的百姓愚昧，不认识我。他们是愚昧的儿女，没有悟性。他们善于行恶，却不知道怎样行善。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 24:29; 马可福音 13:24–25; 以赛亚书 13:10"> 我观看大地，看哪，它空虚混沌；我观看诸天，天也没有光。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 38:20; 以赛亚书 5:25; 那鸿书 1:5–6"> 我观看群山，看哪，山都震动，众丘陵来回摇晃。</span>
<span className="v" id="v25" data-v="25" data-xref="西番雅书 1:2–3; 耶利米书 12:4; 耶利米书 9:10"> 我观看，看哪，无人，空中的飞鸟也都逃去了。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 107:34; 耶利米书 12:4; 耶利米书 14:2–6"> 我观看，看哪，肥田变为旷野，所有城邑在耶和华面前，在祂烈怒面前，都被拆毁。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 46:28; 耶利米书 5:10; 耶利米书 5:18"> 因为耶和华这样说：“全地必荒凉；然而我不彻底毁灭。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 23:19; 以赛亚书 50:3; 何西阿 4:3"> 因此，大地必悲哀，上面的天也必发黑，因为我已经说了，已经定意，并不后悔，也不转回。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 2:19–21; 耶利米书 4:7; 耶利米书 52:7"> 各城都因骑兵和弓箭手的响声而逃跑；他们进入密林，爬上岩石。各城都被撇弃，无人居住在其中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 9:30; 耶利米哀歌 1:2; 耶利米哀歌 1:19"> 你这被毁坏的啊，你要做什么呢？你虽穿上朱红衣服，虽用金饰打扮自己，虽用眼妆描大你的眼睛，却是徒然使自己美丽。你的情人藐视你，寻索你的性命。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米哀歌 1:17; 以赛亚书 1:15; 耶利米书 13:21"> 因为我听见声音，好像临产妇人的声音，又像生头胎者的痛苦呼喊，是锡安女儿的声音；她喘息，伸开双手，说：“我现在有祸了！因为我的灵魂在杀人者面前发昏。”</span>
</div>

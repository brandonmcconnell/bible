<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 24:18; 约书亚记 10:29; 历代志下 36:11"> 西底家登基的时候二十一岁，在耶路撒冷作王十一年。他母亲名叫哈慕他，是立拿人耶利米的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 14:22; 列王纪下 24:19–20; 以西结 17:16–20"> 他行耶和华眼中看为恶的事，照约雅敬所行的一切。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 3:4–5; 历代志下 36:13; 以赛亚书 3:1"> 因耶和华的怒气，这事临到耶路撒冷和犹大，直到祂把他们从自己面前赶出去。<br />西底家背叛了巴比伦王。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:1; 撒迦利亚书 8:19; 以西结 24:1–2"> 西底家作王第九年十月初十，巴比伦王尼布甲尼撒率领他的全军来攻击耶路撒冷，对城安营，并在四围筑垒攻城。</span>
<span className="v" id="v5" data-v="5"> 于是城被围困，直到西底家王第十一年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 39:2; 以赛亚书 3:1; 列王纪下 25:3"> 四月初九，城里的饥荒严重，国中的百姓没有粮食。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 39:4–7; 耶利米书 51:32; 列王纪下 25:4"> 城被攻破，所有战士就在夜间从城中逃出，经过靠近王园、两道城墙之间的门出去。那时迦勒底人正四围围攻这城。战士们往亚拉巴方向去了，</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 34:21; 耶利米书 32:4; 耶利米书 38:23"> 迦勒底人的军队追赶王，在耶利哥的平原追上西底家；他的全军都离开他四散了。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 39:5; 民数记 13:21; 列王纪下 25:6"> 他们拿住王，把他带到哈马地的利比拉，去见巴比伦王；巴比伦王就判他的罪。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 22:30; 列王纪下 25:7; 创世记 21:16"> 巴比伦王在西底家眼前杀了他的众子，又在利比拉杀了犹大所有的首领。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 12:13; 耶利米书 34:3–5"> 他剜了西底家的眼睛；巴比伦王用铜链锁住他，把他带到巴比伦，关在监里，直到他死的日子。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:8; 耶利米书 39:9; 耶利米书 52:29"> 巴比伦王尼布甲尼撒十九年五月初十，侍立在巴比伦王面前的护卫长尼布撒拉旦进入耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 79:1; 弥迦书 3:12; 历代志下 36:19"> 他焚烧了耶和华的殿和王宫；耶路撒冷所有的房屋，连每一座大房屋，他都用火焚烧。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 1:3; 列王纪下 25:10"> 跟随护卫长的迦勒底全军，把耶路撒冷四围所有的城墙都拆毁了。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1–2; 撒迦利亚书 14:2"> 护卫长尼布撒拉旦把民中一些最贫穷的人、城里剩下的其余百姓、投降归附巴比伦王的人，以及其余的群众都掳去了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 25:12; 耶利米书 39:9–10; 耶利米书 40:5–7"> 但护卫长尼布撒拉旦留下当地一些最贫穷的人，使他们作看守葡萄园的人和耕田的人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 27:19–22; 耶利米书 52:21–23; 历代志下 4:12–15"> 迦勒底人把耶和华殿里的铜柱、座和铜海打碎，把所有的铜运到巴比伦。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:3; 民数记 4:14; 列王纪上 7:45"> 他们又拿走锅、铲子、烛剪、盆、匙子，以及所有供职用的铜器。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:49–50; 历代志下 4:6–22; 利未记 26:12"> 护卫长拿走杯、火鼎、盆、锅、灯台、匙子和碗；凡金的按金拿走，凡银的按银拿走。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 7:47; 列王纪下 25:16; 历代志下 4:18"> 两根柱子、一个海，以及所罗门王为耶和华殿所造、在座下的十二只铜牛，这一切器物的铜无法称量。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:17; 列王纪上 7:15–21; 历代志下 3:15–17"> 至于柱子，一根柱子高十八肘；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>用十二肘长的量绳可围绕它一圈；厚四指，是中空的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:25; 列王纪下 25:17; 历代志下 3:15"> 柱上有铜柱顶；一个柱顶高五肘，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">b</a></sup>柱顶四围有网子和石榴，都是铜的。第二根柱子也一样，有石榴。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 7:20"> 四面有九十六个石榴；在周围网子上的石榴共有一百个。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪下 25:18; 耶利米书 29:25; 耶利米书 35:4"> 护卫长拿住大祭司西莱雅、副祭司西番雅，以及三个守门槛的人，</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 25:19; 以斯帖记 1:14; 马太福音 18:10"> 又从城里拿住一个管理战士的官员，以及在城里找到的七个常见王面的人；还拿住军长的书记，就是负责征召国中百姓的，以及在城中找到的国中百姓六十个人。</span>
<span className="v" id="v26" data-v="26"> 护卫长尼布撒拉旦拿住他们，把他们带到利比拉去见巴比伦王。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 33:28; 以赛亚书 32:13–14; 以赛亚书 6:11–12"> 巴比伦王在哈马地的利比拉击杀他们，把他们处死。<br />这样，犹大被掳离开本地。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 24:12–16; 列王纪下 24:2–3; 但以理 1:1–3"> 以下是尼布甲尼撒所掳之民的数目：<br />第七年，犹大人三千零二十三名；</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 52:12; 创世记 12:5; 列王纪下 25:11"> 尼布甲尼撒十八年，他从耶路撒冷掳去八百三十二人；</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 52:15; 耶利米书 6:9"> 尼布甲尼撒二十三年，护卫长尼布撒拉旦掳去犹大人七百四十五名。<br />总人数为四千六百名。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 25:27–30; 诗篇 3:3; 创世记 40:13"> 犹大王约雅斤被掳第三十七年，十二月二十五日，巴比伦王以未米罗达登基元年，抬举了犹大王约雅斤，放他出监。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; 但以理 5:18–19; 但以理 2:37"> 他用好话对他说，又使他的座位高过与他一同在巴比伦众王的座位；</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 9:7; 列王纪上 2:7; 创世记 41:14"> 又给他换下囚衣。约雅斤一生的日子，常常在他面前吃饭。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 9:10; 路加福音 11:3; 马太福音 6:11"> 至于他的供给，巴比伦王每日按份不断供给他，直到他死的日子，就是他一生的年日。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 39:1–2; 列王纪下 25:1–2; 耶利米书 25:1"> 这是犹大王西底家第十年，尼布甲尼撒第十八年，耶和华的话临到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 37:21; 尼希米记 3:25; 耶利米书 33:1"> 那时，巴比伦王的军队正在围攻耶路撒冷。先知耶利米被关在护卫院中，就是在犹大王宫里的护卫院。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 34:2–3; 耶利米书 21:4–7; 耶利米书 26:8–9"> 因为犹大王西底家把他关起来，说：“你为什么预言说：‘耶和华如此说：“看哪，我要把这城交在巴比伦王手中，他必攻取这城；</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4–7; 列王纪下 25:4–7; 耶利米书 37:17"> 犹大王西底家必不能逃脱迦勒底人的手，必定要被交在巴比伦王手中，与他面对面说话，亲眼看见他的眼睛；</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 39:7; 以西结 17:9–10; 以西结 17:15"> 他必把西底家带到巴比伦；西底家必在那里，直到我眷顾他的时候，”耶和华说，“你们虽然与迦勒底人争战，却不能亨通。”’？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶利米说：“耶和华的话临到我，说：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:1; 耶利米书 11:21; 利未记 25:25"> ‘看哪，你叔叔沙龙的儿子哈拿篾要来见你，说：“请你买我在亚拿突的那块田；因为赎买的权利归你，你可以买下它。”’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 32:7; 耶利米书 32:2; 耶利米书 33:1"> “于是，我叔叔的儿子哈拿篾照着耶和华的话，来到护卫院见我，对我说：‘请你买我在便雅悯地亚拿突的那块田；因为承受的权利归你，赎买的权利也归你。请你为自己买下它。’<br />“那时我知道这是耶和华的话。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 11:12–13; 以斯帖记 3:9; 列王纪上 20:39"> 我就从我叔叔的儿子哈拿篾那里，买了在亚拿突的那块田，称了银子给他，共十七舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司。">a</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:44; 耶利米书 32:12; 耶利米书 32:25"> 我签了契约，封好，叫了见证人，并用天平称了银子给他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前书 11:16; 使徒行传 26:3"> 于是我拿了买契，就是封好的、含有条款和规定的那一份，以及敞开的那一份；</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:16; 耶利米书 51:59; 耶利米书 36:4–5"> 我在我叔叔的儿子哈拿篾面前，在签署买契的见证人面前，并在坐在护卫院中的所有犹太人面前，把买契交给尼利亚的儿子、玛西雅的孙子巴录。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> “我在他们面前吩咐巴录说：</span>
<span className="v" id="v14" data-v="14"> 万军之耶和华以色列的上帝如此说：‘要拿这些契约，就是这封好的买契和这敞开的契约，放在瓦器里，使它们可以保存许多日子。’</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 3:10; 阿摩司 9:14–15; 耶利米书 30:18"> 因为万军之耶和华以色列的上帝如此说：‘在这地上，人还要再买房屋、田地和葡萄园。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 12:1; 创世记 32:9–12; 腓立比书 4:6–7"> 我把买契交给尼利亚的儿子巴录以后，就向耶和华祷告说：</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> “啊，主耶和华！看哪，你曾用你的大能和伸出来的膀臂创造天地；在你没有难成的事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 10:16; 申命记 5:9–10; 出埃及记 34:7"> 你向千万人施慈爱，又将父亲的罪孽报应在他们以后儿女的怀中。伟大而有大能的上帝，万军之耶和华是你的名：</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:10; 马太福音 16:27; 诗篇 62:12"> 你的谋略伟大，作为大有能力；你的眼目睁开，鉴察世人的一切道路，要照各人的道路和他行为的结果报应各人；</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:10; 撒母耳记下 7:23; 出埃及记 10:2"> 你在埃及地施行神迹奇事，直到今日，在以色列中，也在其他人中；你为自己立了名，正如今日一样；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:6; 申命记 26:8; 诗篇 105:43"> 你用神迹、奇事、大能的手、伸出来的膀臂和极大的威严，把你的子民以色列从埃及地领出来；</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 3:8; 出埃及记 13:5; 耶利米书 11:5"> 你把这地赐给他们，就是你向他们祖先起誓要赐给他们的，流奶与蜜之地。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:7; 诗篇 78:54–55; 但以理 9:10–14"> 他们进来占有这地，却不听从你的声音，也不遵行你的律法。凡你吩咐他们要做的，他们一件也没有做。因此，你使这一切灾祸临到他们。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:36; 申命记 4:26; 约书亚记 23:15–16"> “看哪，攻城土垒已经筑起来，要攻取这城。因刀剑、饥荒和瘟疫，这城被交在攻打它的迦勒底人手中。你所说的已经成就。看哪，你也看见了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:24; 诗篇 97:2; 诗篇 77:19"> 主耶和华啊，你却对我说：‘你要用银子买那块田，并叫见证人来作证；’然而这城已经被交在迦勒底人手中。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华的话临到耶利米，说：</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:17; 以赛亚书 64:8"> “看哪，我是耶和华，是一切血肉之躯的上帝。岂有我难成的事吗？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 32:3; 耶利米书 32:24; 耶利米书 19:7–12"> 因此耶和华如此说：看哪，我要把这城交在迦勒底人手中，交在巴比伦王尼布甲尼撒手中，他必攻取这城。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 21:10; 耶利米书 19:13; 耶利米书 52:13"> 攻打这城的迦勒底人必进来，放火焚烧这城，也烧毁那些房屋；人曾在这些房屋的屋顶上向巴力烧香，又向别神浇奠祭，惹我发怒。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 7:22–26; 申命记 9:7–12; 耶利米书 25:7"> “因为以色列人和犹大人从年轻时起，只行我眼中看为恶的事；以色列人只用他们手所做的惹我发怒，耶和华说。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:27; 耶利米书 27:10; 列王纪下 21:4–7"> 因为这城自从建造的那日直到今日，一直惹我发怒，激起我的烈怒，以致我要把它从我面前除掉，</span>
<span className="v" id="v32" data-v="32" data-xref="但以理 9:8; 耶利米书 2:26; 以赛亚书 1:4–6"> 这是因为以色列人和犹大人所行的一切恶，惹我发怒——他们、他们的君王、他们的首领、他们的祭司、他们的先知、犹大人和耶路撒冷的居民。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:13; 耶利米书 2:27; 以西结 8:16"> 他们向我转背，不向我转脸。虽然我早早起来教导他们，他们却不听，不领受训诲。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 7:30; 以西结 8:5–16; 列王纪下 21:4–7"> 他们反把可憎之物放在称为我名下的殿中，玷污它。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 7:31; 历代志下 33:6; 利未记 18:21"> 他们在欣嫩子谷建造巴力的丘坛，使他们的儿女经火献给摩洛；这不是我吩咐他们的，甚至我心里也没有想过他们会行这可憎的事，使犹大陷在罪中。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 32:24; 耶利米书 32:3; 耶利米书 32:28"> 现在，耶和华以色列的上帝论到这城如此说，就是你们所说“它因刀剑、饥荒和瘟疫被交在巴比伦王手中”的这城：</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 23:3; 耶利米书 23:6; 以西结 34:12–14"> “看哪，我要把他们从我在怒气、烈怒和大愤恨中驱赶他们去的各国招聚出来；我要再把他们带回这地方，使他们安然居住。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 24:7; 以西结 11:19–20; 希伯来书 8:10"> 他们要作我的子民，我要作他们的上帝。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结 11:19–20; 使徒行传 4:32; 约翰福音 17:21"> 我要赐给他们同一个心和同一条道路，使他们永远敬畏我，好叫他们和他们以后的儿女得福。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米书 31:31–33; 以西结 36:26; 耶利米书 24:7"> 我要与他们立永远的约，必不转离他们，必善待他们。我要把敬畏我的心放在他们心里，使他们不离开我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 24:6; 西番雅书 3:17; 以赛亚书 62:5"> 是的，我必欢喜善待他们；我必全心全意，坚定地把他们栽植在这地。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="耶利米书 31:28; 约书亚记 23:14–15; 耶利米书 33:10–11"> 因为耶和华如此说：“我怎样使这一切大灾祸临到这百姓，也必照样使我所应许他们的一切福乐临到他们。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结 37:11–14; 耶利米书 32:15; 耶利米书 32:36"> 在这地上必有人买田地；关于这地，你们说：‘这是荒凉之地，没有人，也没有牲畜；它被交在迦勒底人手中。’</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米书 17:26; 耶利米书 33:26; 耶利米书 33:11"> 在便雅悯地、耶路撒冷四围、犹大各城、山地各城、低地各城和南地各城，人必用银子买田，签署契约，封好，并叫见证人来作证；因为我必使他们被掳的归回，”耶和华说。</span>
</div>

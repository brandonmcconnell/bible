<span className="v" id="v1" data-v="1" data-xref="耶利米书 26:8; 耶利米书 51:63; 耶利米书 42:22"> 耶利米向全体百姓说完耶和华他们上帝的一切话，就是耶和华他们上帝差他到他们那里所传的这一切话以后，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:13; 以赛亚书 7:9; 耶利米书 40:8"> 何沙雅的儿子亚撒利雅、加利亚的儿子约哈难，以及所有骄傲的人，都对耶利米说：“你说的是假话。耶和华我们的上帝并没有差你来说：‘你们不可进入埃及，在那里居住。’</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 45:1–3; 耶利米书 36:4; 耶利米书 36:26"> 这是尼利亚的儿子巴录煽动你反对我们，要把我们交在迦勒底人手中，使他们杀死我们，或把我们掳到巴比伦去。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 42:5–6; 诗篇 37:3; 历代志下 25:16"> 于是加利亚的儿子约哈难、军队的众首领和全体百姓，都不听从耶和华的声音，不住在犹大地。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 40:11–12; 耶利米书 41:15–16; 撒母耳记上 26:19"> 加利亚的儿子约哈难和军队的众首领，带走了犹大所有的余民，就是从被赶到的各国回来、要住在犹大地的人——</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 39:10; 耶利米书 40:7; 耶利米书 41:10"> 男人、女人、孩童、王的众女儿，以及护卫长尼布撒拉旦留在沙番的孙子、亚希甘的儿子基大利那里的所有人；还有耶利米先知和尼利亚的儿子巴录。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:16; 耶利米书 44:1; 以赛亚书 30:4"> 他们进入埃及地，因为他们不听从耶和华的声音；他们来到答比匿。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 2:16; 诗篇 139:7; 提摩太后书 2:9"> 耶和华的话在答比匿临到耶利米，说：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 18:2–12; 耶利米书 19:1–15; 耶利米书 51:63–64"> “你要手拿几块大石头，在犹大人眼前，把它们藏在答比匿法老宫门口砖砌工程的灰泥里。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 44:28–1; 耶利米书 1:15; 诗篇 31:20"> 你要告诉他们，万军之耶和华、以色列的上帝如此说：‘看哪，我必差人去召我的仆人巴比伦王尼布甲尼撒来；我要把他的宝座安放在我所藏的这些石头上，他必在其上铺设他的王帐。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 15:2; 耶利米书 44:13; 以西结 29:19–20"> 他必来攻击埃及地；该遭死亡的必遭死亡，该被掳的必被掳，该遭刀剑的必遭刀剑。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 30:13; 诗篇 109:18–19; 以赛亚书 19:1"> 我要在埃及众神的庙中点火；他必焚烧这些庙宇，把他们掳走。他必披上埃及地，像牧人披上自己的衣服；他必平安地从那里出去。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 19:18"> 他还必打碎埃及地伯示麦的石柱；埃及众神的庙宇，他必用火焚烧。’”</span>
</div>

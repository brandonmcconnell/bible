<span className="v" id="v2" data-v="2" data-xref="耶利米书 4:31; 以赛亚书 1:8; 以赛亚书 3:16–17"> 那美丽娇嫩的锡安女子，我必剪除。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 19:43; 耶利米书 39:1–3; 列王纪下 24:10–12"> 牧人必带着他们的羊群来到她那里；他们必在她四围支搭帐棚，各人在自己的地方牧放。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 15:8; 西番雅书 2:4; 约珥 3:9"> “要预备战争攻击她！起来吧！我们中午上去吧。我们有祸了！因为日头偏西，黄昏的影子拉长了。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 52:13; 以赛亚书 32:14; 历代志下 36:19"> 起来吧！我们夜间上去吧，毁坏她的宫殿。”</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 20:19–20; 耶利米书 32:24"> 因为万军之耶和华如此说：“要砍伐树木，筑垒攻击耶路撒冷。这就是那该受追讨的城；她里面满了欺压。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 20:8; 以西结 7:23; 以西结 7:11"> 井怎样涌出水来，她也照样涌出自己的邪恶。在她里面听见暴力和毁灭；疾病与创伤常在我面前。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 23:18; 何西阿 9:12; 耶利米书 17:23"> 耶路撒冷啊，要受训诲，免得我的心与你疏离，免得我使你荒凉，成为无人居住之地。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 49:9; 耶利米书 16:16; 俄巴底亚 1:5–6"> 万军之耶和华说：“他们必像摘葡萄一样，把以色列剩余的人摘尽。你要像摘葡萄的人，把手再次伸进筐中。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:51; 耶利米书 7:26; 约翰福音 7:7"> 我该向谁说话，向谁作证，使他们可以听呢？看哪，他们的耳朵未受割礼，不能听。看哪，耶和华的话成了他们讥诮的对象；他们并不喜悦它。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 9:21; 耶利米书 20:9; 弥迦书 3:8"> 因此我充满耶和华的烈怒，忍耐到疲乏。<br /><span className="pl pl-1">“要把它倾倒在街上的孩童身上，</span><br /><span className="pl pl-2">也倾倒在聚集的年轻人身上；</span><br /><span className="pl pl-1">因为丈夫和妻子都必被擒，</span><br /><span className="pl pl-2">老人和年迈日高的人也都被擒。</span></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 8:10; 以赛亚书 5:25; 申命记 28:39–43"> <span className="pl pl-1">他们的房屋必转归别人，</span><br /><span className="pl pl-2">他们的田地和妻子也一同如此；</span><br /><span className="pl pl-1">因为我必伸手攻击这地的居民，这是耶和华说的。”</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 23:11; 耶利米书 8:10; 弥迦书 3:11"> <span className="pl pl-1">“因为从他们中最小的到最大的，人人都贪图不义之财；</span><br /><span className="pl pl-2">从先知到祭司，人人都行事虚谎。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以西结 13:10; 耶利米书 23:17; 耶利米书 4:10"> <span className="pl pl-1">他们也草率地医治我百姓的伤口，</span><br /><span className="pl pl-2">说：‘平安了！平安了！’其实没有平安。</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 8:12; 马太福音 15:14; 耶利米书 3:3"> <span className="pl pl-1">他们行了可憎之事，感到羞愧了吗？</span><br /><span className="pl pl-2">不，他们一点也不羞愧，也不知道脸红。</span><br /><span className="pl pl-1">因此，他们必在跌倒的人中跌倒；</span><br /><span className="pl pl-2">我追讨他们的时候，他们必被推倒，”这是耶和华说的。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 30:21; 申命记 32:7; 耶利米书 18:15"> 耶和华如此说：“你们要站在路上观看，访问古道，问：‘善道在哪里？’并且行在其中，你们的灵魂就必得安息。但他们说：‘我们不行在其中。’</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 25:4; 以赛亚书 58:1; 撒迦利亚书 7:11"> 我设立守望者在你们以上，说：‘要听号角的声音！’但他们说：‘我们不听！’</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 4:10; 耶利米书 31:10; 弥迦书 6:5"> 因此，列国啊，要听；会众啊，要知道他们中间所发生的事。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 1:2; 耶利米书 8:9; 耶利米书 17:10"> 大地啊，要听！看哪，我必使灾祸临到这百姓，就是他们意念的果子，因为他们没有听从我的话；至于我的律法，他们也弃绝了。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 1:11; 阿摩司 5:21–22; 以赛亚书 60:6"> 从示巴来的乳香，和从远方来的香菖蒲，对我有什么用呢？你们的燔祭不蒙悦纳；你们的祭物也不使我喜悦。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 8:14; 以西结 3:20; 耶利米书 13:16"> 因此耶和华如此说：“看哪，我必在这百姓面前放置绊脚石；父亲和儿子必一同被它们绊跌，邻舍和朋友都必灭亡。”</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 50:41–43; 耶利米书 10:22; 耶利米书 6:1"> 耶和华如此说：“看哪，有一个民族从北方之地而来；有一个大国从地极被激动起来。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 13:18; 耶利米书 50:42; 路加福音 21:25–26"> 他们拿着弓和枪；他们残忍，没有怜悯。他们的声音像海涛咆哮；他们骑着马，各人列阵，如同人上战场，要攻击你，锡安的女儿啊。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 4:31; 耶利米书 50:43; 耶利米书 49:24"> 我们听见了关于它的风声；我们的手就发软。痛苦抓住了我们，疼痛如临产的妇人。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 49:29; 耶利米书 20:10; 诗篇 31:13"> 不要出去到田野，也不要行在路上；因为有仇敌的刀剑，四围都有惊恐。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 4:8; 撒迦利亚书 12:10; 以赛亚书 32:11"> 我百姓的女儿啊，要穿上麻衣，在灰中打滚！要哀悼，如丧独子；要极其悲痛地哀哭，因为毁灭者必忽然临到我们。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 1:18; 耶利米书 15:20; 以西结 3:8–10"> “我已立你在我百姓中作试验金属的人和堡垒，使你可以知道并试验他们的道路。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 9:4; 耶利米书 5:23; 耶利米书 18:18"> 他们全都是顽梗的悖逆者，到处毁谤人。他们是铜是铁；他们全都行事败坏。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 24:13; 耶利米书 9:7; 彼得前书 4:12"> 风箱猛烈吹动；铅在火中烧尽。他们继续熬炼也是徒然，因为恶人没有被除去。</span>
<span className="v" id="v30" data-v="30" data-xref="何西阿 9:17; 诗篇 119:119; 以赛亚书 1:22"> 人必称他们为被弃的银子，因为耶和华已经弃绝他们。”</span>
</div>

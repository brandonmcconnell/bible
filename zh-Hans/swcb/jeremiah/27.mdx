<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 27:3; 耶利米书 28:1; 耶利米书 27:12"> 犹大王约西亚的儿子约雅敬执政之初，有这话从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司 7:1; 阿摩司 7:4; 耶利米书 27:12"> 耶和华对我这样说：“你要制作绳索和轭木，放在你的颈项上。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司 1:9–3; 以西结 25:1–17; 以西结 17:15–21"> 然后藉着那些来到耶路撒冷见犹大王西底家的使者，把这些送给以东王、摩押王、亚扪人之王、推罗王和西顿王。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 51:19; 耶利米书 10:10; 耶利米书 25:27"> 你要吩咐他们去告诉他们的主人说：‘万军之耶和华——以色列的上帝这样说：“你们要告诉你们的主人：</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:17; 耶利米书 51:15; 诗篇 115:15–16"> ‘我用我的大能和伸出的膀臂，造了地、地面上的人和牲畜。我看谁为合宜，就把地赐给谁。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 28:14; 耶利米书 25:9; 但以理 2:37–38"> 现在，我已将这一切土地都交在巴比伦王尼布甲尼撒我仆人的手中，也把田野的走兽赐给他，使它们服侍他。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 52:31; 启示录 13:5–10; 但以理 5:25–31"> 列国都必服侍他和他的儿子，并他儿子的儿子，直到他自己土地的时候来到；那时，许多国家和大君王必使他作他们的奴仆。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结 14:21; 以西结 17:19–21; 耶利米书 38:17–19"> “‘“‘哪个国家、哪个国度不服侍这巴比伦王尼布甲尼撒，不把颈项放在巴比伦王的轭下，我必用刀剑、饥荒和瘟疫惩罚那国，直到我藉他的手将他们灭尽，’这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 14:14; 玛拉基书 3:5; 耶利米书 29:8"> 至于你们，不要听从你们的先知、占卜者、你们的梦、观兆者和行邪术的人；他们对你们说：“你们不必服侍巴比伦王。”</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:31; 耶利米书 28:16; 耶利米书 23:25"> 因为他们向你们说假预言，使你们远离自己的土地，以致我把你们赶出去，你们就灭亡。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:8; 耶利米书 27:2; 耶利米书 38:2"> 但哪个国家把颈项放在巴比伦王的轭下，服侍他，我必让那国仍留在自己的土地上，’这是耶和华说的；‘他们必耕种那地，住在其中。’”’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 28:1; 耶利米书 38:17; 历代志下 36:11–13"> 我照这一切话对犹大王西底家说：“你们要把颈项放在巴比伦王的轭下，服侍他和他的百姓，就可以存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 18:31; 耶利米书 27:8; 箴言 8:36"> 你和你的百姓为什么要因刀剑、饥荒和瘟疫而死，正如耶和华论到不服侍巴比伦王的国家所说的话呢？</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 14:14; 哥林多后书 11:13–15; 耶利米书 29:8–9"> 不要听从那些先知对你们所说的话；他们说：‘你们不必服侍巴比伦王。’因为他们向你们说假预言。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 27:10; 历代志下 25:16; 耶利米书 6:13–15"> 耶和华说：“我并没有差遣他们，他们却奉我的名说假预言；以致我把你们赶出去，使你们和向你们说预言的先知都灭亡。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 24:13; 耶利米书 28:3; 但以理 1:2"> 我又对祭司和这全体百姓说，耶和华这样说：“不要听从你们的先知向你们所说的预言；他们说：‘看哪，耶和华殿中的器皿很快就要从巴比伦带回来。’因为他们向你们说假预言。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 38:17; 耶利米书 38:23; 耶利米书 7:34"> 不要听从他们。要服侍巴比伦王，就可以存活。这城为什么要成为荒凉之地呢？</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 7:8; 耶利米书 18:20; 撒母耳记上 12:19"> 但如果他们是先知，如果耶和华的话与他们同在，就让他们现在向万军之耶和华代求，使那些留在耶和华殿中、犹大王宫中和耶路撒冷的器皿，不至于运到巴比伦去。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 25:13; 耶利米书 52:17–23; 列王纪下 25:17"> 因为万军之耶和华论到柱子、铜海、盆座，以及留在这城中其余的器皿这样说，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:1; 历代志下 36:10; 列王纪下 24:14–16"> 就是巴比伦王尼布甲尼撒从耶路撒冷掳走犹大王约雅敬的儿子耶哥尼雅到巴比伦，并掳走犹大和耶路撒冷所有显贵的时候，没有拿走的器皿——</span>
<span className="v" id="v21" data-v="21"> 是的，万军之耶和华——以色列的上帝，论到留在耶和华殿中、犹大王宫中和耶路撒冷的器皿这样说：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 29:10; 以斯拉记 7:19; 耶利米书 32:5"> ‘它们必被带到巴比伦，留在那里，直到我眷顾它们的日子，’这是耶和华说的；‘那时我必把它们带上来，使它们归回这地方。’”</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="以西结 6:5; 列王纪下 23:16; 耶利米书 7:32–34"> 耶和华说：“那时，人必将犹大诸王的骸骨、他们首领的骸骨、祭司的骸骨、先知的骸骨，以及耶路撒冷居民的骸骨，从他们的坟墓中取出来。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 23:5; 耶利米书 9:22; 申命记 4:19"> 他们必把这些骸骨摊开在太阳、月亮和天上万象面前，就是他们所爱的、所事奉的、所随从的、所寻求的、所敬拜的。这些骸骨必不被收殓，也不被埋葬，必像粪土在地面上。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 9:6; 耶利米书 29:14; 耶利米书 23:3"> 在这邪恶家族所有剩下的人中，就是我赶逐到各处还剩下的人，必宁愿选择死亡而不选择生命。”这是万军之耶和华说的。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 24:16; 弥迦书 7:8; 何西阿 6:1"> “你还要对他们说：‘耶和华如此说：<br /><span className="pl pl-1">“‘人跌倒了，岂不再起来吗？</span><br /><span className="pl pl-2">人转离了，岂不回转吗？</span></span>

<span className="v" id="v6" data-v="6" data-xref="诗篇 14:2; 以西结 18:28; 路加福音 15:17–19"> <span className="pl pl-1">我留心听了，却没有听见他们说正直的话。</span><br /><span className="pl pl-2">没有人为自己的恶行悔改，说：“我做了什么呢？”</span><br /><span className="pl pl-1">人人都转向自己的道路，</span><br /><span className="pl pl-2">如马直冲战场。</span></span>

</div>

<span className="v" id="v10" data-v="10" data-xref="耶利米书 6:12–13; 以西结 33:31; 以赛亚书 56:10–12"> <span className="pl pl-1">因此，我必把他们的妻子给别人，</span><br /><span className="pl pl-2">把他们的田地给将要占有的人。</span><br /><span className="pl pl-1">因为从最小的到最大的，人人都贪婪；</span><br /><span className="pl pl-2">从先知到祭司，人人都行诡诈。</span></span>

<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:15; 耶利米书 9:15; 耶利米哀歌 3:19"> <span className="pl pl-1">“我们为什么静坐不动呢？</span><br /><span className="pl pl-2">你们要聚集！</span><br /><span className="pl pl-2">让我们进入坚固城，</span><br /><span className="pl pl-2">在那里静默吧；</span><br /><span className="pl pl-1">因为耶和华我们的上帝使我们静默，</span><br /><span className="pl pl-2">又给我们毒水喝，</span><br /><span className="pl pl-2">因为我们得罪了耶和华。</span></span>

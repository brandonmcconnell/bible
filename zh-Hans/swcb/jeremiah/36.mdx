<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 25:1; 历代志下 36:5; 耶利米书 45:1"> 犹大王约西亚的儿子约雅敬第四年，耶和华的话临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 30:2; 耶利米书 25:3; 耶利米书 1:10"> “你取一卷书卷，把我从约西亚的日子起，直到今日，向你所说攻击以色列、攻击犹大和攻击列国的一切话，都写在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:8; 使徒行传 3:19; 耶利米书 26:3"> 或者犹大家听见我打算降在他们身上的一切灾祸，各人就转离自己的恶道；这样，我就赦免他们的罪孽和他们的罪。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:12; 耶利米书 36:32; 以西结 2:9"> 于是耶利米召了尼利亚的儿子巴录；巴录就按耶利米口述，把耶和华对他说过的一切话都写在一卷书卷上。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:2; 耶利米书 33:1; 哥林多后书 11:23"> 耶利米吩咐巴录说：“我受限制，不能进耶和华的殿。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 36:8–9; 耶利米书 26:2; 耶利米书 22:2"> 所以你要去，在禁食的日子，在耶和华殿中，把你按我口述所写在书卷上耶和华的话读给百姓听；也要读给从犹大各城出来的人听。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 36:3; 耶利米书 21:5; 历代志下 33:12–13"> 或许他们会在耶和华面前恳求，各人转离自己的恶道；因为耶和华已经宣告，要向这百姓大发怒气和烈怒。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 1:17; 哥林多前书 16:10; 路加福音 4:16–30"> 尼利亚的儿子巴录就照先知耶利米所吩咐他的一切去做，在耶和华殿中从书卷上宣读耶和华的话。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 20:3; 约拿 3:5; 以斯帖记 4:16"> 犹大王约西亚的儿子约雅敬第五年九月，耶路撒冷所有的百姓，以及从犹大各城来到耶路撒冷的所有百姓，都在耶和华面前宣告禁食。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:11; 耶利米书 26:10; 耶利米书 52:25"> 巴录就在耶和华殿的上院，在耶和华殿新门入口处，沙番的儿子文士基玛利雅的房间里，从书卷上把耶利米的话读给所有百姓听。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 36:10; 历代志下 34:20; 列王纪下 25:22"> 沙番的孙子、基玛利雅的儿子米该亚，从书卷上听见耶和华的一切话以后，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 26:22; 列王纪下 22:12; 耶利米书 36:25"> 就下到王宫，进了文士的房间；看哪，所有首领都坐在那里：文士以利沙玛、示玛雅的儿子第莱雅、押波的儿子以利拿单、沙番的儿子基玛利雅、哈拿尼雅的儿子西底家，以及所有首领。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 22:10; 历代志下 34:24; 历代志下 34:16–18"> 米该亚就把巴录读书卷给百姓听时他所听见的一切话，都告诉他们。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 36:2; 耶利米书 41:18; 耶利米书 41:1–2"> 于是所有首领派古示的曾孙、示利米雅的孙子、尼探雅的儿子犹底去见巴录，说：“请你把读给百姓听的那书卷拿在手中，到这里来。”<br />于是尼利亚的儿子巴录把书卷拿在手中，到他们那里去。</span>
<span className="v" id="v15" data-v="15"> 他们对他说：“请坐下，读给我们听。”<br />于是巴录读给他们听。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 13:18; 耶利米书 36:24; 阿摩司 7:10–11"> 他们听见这一切话，就惊惧地彼此相视，对巴录说：“我们一定要把这一切话告诉王。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:15; 约翰福音 9:10–11; 约翰福音 9:26–27"> 他们问巴录说：“请告诉我们，你是怎样按他口述写下这一切话的？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 36:4; 耶利米书 36:2; 箴言 26:4–5"> 巴录回答他们说：“他亲口向我口述这一切话，我就用墨写在书卷上。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪上 17:3; 列王纪上 18:10; 耶利米书 26:20–24"> 于是首领们对巴录说：“你和耶利米要去躲藏，不要让任何人知道你们在哪里。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 36:12; 耶利米书 36:21"> 他们进院中去见王，但他们先把书卷存放在文士以利沙玛的房间里。然后他们把这一切话说给王听。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 22:10; 历代志下 34:18; 以西结 2:4–5"> 王就派犹底去取书卷；他便从文士以利沙玛的房间里取来。犹底读给王听，也读给站在王旁边的所有首领听。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司 3:15; 耶利米书 22:14–16; 耶利米书 36:9"> 那时正是九月，王坐在冬宫里，他面前的火盆中有火燃烧。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 22:8; 箴言 21:30; 列王纪上 22:27"> 每当犹底读了三四栏，王就用文士刀把它割下来，扔进火盆里的火中，直到整卷书卷都在火盆里的火中烧尽了。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 36:16; 诗篇 36:1; 约拿 3:6"> 王和听见这一切话的臣仆都不惧怕，也没有撕裂衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:22; 耶利米书 36:12; 使徒行传 5:34–39"> 以利拿单、第莱雅和基玛利雅曾向王恳求，不要烧这书卷；可是他不听他们。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 17:3; 列王纪上 19:1–3; 列王纪上 19:14"> 王又吩咐王的儿子耶拉篾、亚斯列的儿子西莱雅、亚伯叠的儿子示利米雅，去捉拿文士巴录和先知耶利米；但是耶和华把他们隐藏了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 36:4"> 王烧了书卷，就是巴录按耶利米口述所写的话以后，耶和华的话临到耶利米，说：</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 1:5–6; 约伯记 23:13; 耶利米书 44:28"> “你再取另一卷，将犹大王约雅敬所烧第一卷上原有的一切话都写在上面。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 30:10; 耶利米书 26:9; 申命记 29:19"> 论到犹大王约雅敬，你要说：‘耶和华如此说：“你烧了这书卷，说：『你为什么在卷上写说：“巴比伦王必定要来毁灭这地，使这地的人和牲畜都从那里断绝”呢？』”</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:30; 列王纪下 24:12–15; 创世记 31:40"> 所以，耶和华论犹大王约雅敬如此说：“他必没有人坐在大卫的宝座上；他的尸首必被抛弃，白天受炎热，夜间受寒霜。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; 耶利米书 19:15; 耶利米书 35:17"> 我必因他的罪孽惩罚他和他的后裔，以及他的臣仆。我必使我所宣告要降在他们身上的一切灾祸，降在他们、耶路撒冷的居民和犹大人身上；他们却不听。”’”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 36:4; 耶利米书 36:18; 出埃及记 4:15–16"> 于是耶利米又取另一卷，交给尼利亚的儿子文士巴录；他就按耶利米口述，将犹大王约雅敬在火中烧掉的那卷书上的一切话都写在上面；此外又添上许多类似的话。</span>
</div>
</div>

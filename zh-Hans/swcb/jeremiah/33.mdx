<span className="v" id="v1" data-v="1" data-xref="耶利米书 38:28; 耶利米书 37:21; 耶利米书 32:2–3"> 耶和华的话第二次临到耶利米，那时他仍被关在护卫兵的院子里，说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:3; 出埃及记 15:3; 以赛亚书 37:26"> “成就这事、塑造这事为要坚立它的耶和华——耶和华是祂的名——如此说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:12; 以赛亚书 65:24; 以弗所书 3:20"> ‘你呼求我，我就回应你，并要把你不知道的伟大而难明的事指示你。’</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:24; 哈巴谷 1:10; 以西结 4:2"> 因为耶和华以色列的上帝，论到这城的房屋和犹大诸王的宫室，就是那些被拆毁、用来抵挡围城土垒和刀剑的，说：</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:17; 耶利米书 21:10; 耶利米书 21:4–7"> ‘人来与迦勒底人争战，却使这些房屋充满人的尸体；这些人是我在怒气和烈怒中所击杀的。因他们一切的邪恶，我已经向这城掩面。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:10; 以赛亚书 30:26; 提多书 3:5–6"> 看哪，我要使这城得健康和医治；我要医治他们，并向他们显明丰盛的平安与真实。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:26; 耶利米书 30:3; 阿摩司 9:14–15"> 我要恢复犹大和以色列的命运，建造他们，使他们像起初一样。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亚书 13:1; 弥迦书 7:18–19; 诗篇 51:2"> 我要洁净他们一切得罪我的罪孽；他们得罪我、违背我的一切罪孽，我都要赦免。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:2–3; 以赛亚书 60:5; 西番雅书 3:17–20"> 这城在地上万国面前，必使我得喜乐的名声，得赞美和荣耀；万国听见我向他们所施行的一切美善，就必因我赐给这城的一切美善和一切平安而惧怕战兢。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:43; 耶利米书 32:36; 以西结 37:11"> 耶和华如此说：“你们说这地方是荒废的，没有人也没有牲畜；在犹大的城镇和耶路撒冷的街道上，也是荒凉的，没有人、没有居民、没有牲畜。然而在这地方，必再听见</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:22"> 欢喜的声音和快乐的声音，新郎的声音和新娘的声音，以及那些带着感谢祭进入耶和华殿中的人所说的声音：‘你们要称谢万军之耶和华，因为耶和华本为善，祂的慈爱永远长存。’因为我要使这地被掳的处境扭转，像起初一样。”这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 65:10; 以西结 34:12–15; 耶利米书 36:29"> 万军之耶和华如此说：“在这荒废、无人无牲畜的地方，并在它所有的城镇中，必再有牧人的住处，使羊群躺卧。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:32; 路加福音 15:4; 耶利米书 17:26"> 在山地的城镇、低地的城镇、南地的城镇、便雅悯地、耶路撒冷周围的地方，以及犹大的城镇，羊群必再从数点者的手下经过。”这是耶和华说的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="哈该书 2:6–9; 耶利米书 23:5; 历代志上 17:13–14"> 耶和华说：“看哪，日子将到，我要成就我论到以色列家和犹大家所说的那美好的话。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 11:1–5; 耶利米书 23:5–6; 以赛亚书 4:2"> <span className="pl pl-1">“在那些日子、那时候，</span><br /><span className="pl pl-2">我要使公义的苗裔为大卫兴起；</span><br /><span className="pl pl-2">祂必在这地施行公平和公义。</span></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:6; 哥林多前书 1:30; 以赛亚书 45:17"> <span className="pl pl-1">在那些日子，犹大必得拯救，</span><br /><span className="pl pl-2">耶路撒冷必安然居住。</span><br /><span className="pl pl-1">她必被称为这个名：</span><br /><span className="pl pl-2">耶和华我们的义。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 2:4; 诗篇 89:29–37; 路加福音 1:32–33"> 因为耶和华如此说：“大卫必永不缺人坐在以色列家的宝座上。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 56:7; 启示录 1:6; 申命记 18:1"> 利未人的祭司在我面前也必不缺人献燔祭、烧素祭，并常常献祭。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华的话临到耶利米，说：</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 8:22; 诗篇 89:37; 以赛亚书 54:9–10"> “耶和华如此说：‘你们若能废弃我与白昼所立的约、我与黑夜所立的约，使白昼和黑夜不按其定时出现，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 89:34; 历代志下 7:18; 撒母耳记下 23:5"> 那么我与我仆人大卫所立的约也可以废弃，使他没有儿子在他的宝座上作王；我与事奉我的利未人祭司所立的约也可以废弃。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 15:5; 创世记 22:17; 希伯来书 11:12"> 天上的万象不能数算，海边的沙也不能量度；照样，我必使我仆人大卫的后裔和事奉我的利未人增多。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话临到耶利米，说：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 4:2–4; 诗篇 83:4; 诗篇 44:13–14"> “你没有想过这百姓所说的话吗？他们说：‘耶和华所拣选的两个家族，祂已经弃绝了。’他们这样藐视我的百姓，以为他们在自己面前不再成国。”</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 74:16–17; 耶利米书 31:35–36; 诗篇 104:19"> 耶和华如此说：“若我与白昼黑夜所立的约废去，若我没有设立天地的定例，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 31:37; 以赛亚书 14:1; 何西阿 2:23"> 那么我也必弃绝雅各的后裔和我仆人大卫的后裔，不从他的后裔中选取人治理亚伯拉罕、以撒、雅各的后裔；因为我要使他们被掳的处境扭转，并怜悯他们。”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 36:4–5; 耶利米书 27:1; 列王纪下 23:34–36"> 犹大王约西亚的儿子约雅敬执政初期，有这话从耶和华而来：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:2; 使徒行传 20:27; 马太福音 28:20"> “耶和华如此说：‘你要站在耶和华殿的院中，对犹大各城所有前来耶和华殿敬拜的人，说我命令你对他们说的一切话；一个字也不可删减。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 以赛亚书 1:16–19; 耶利米书 18:7–10"> 或许他们会听从，各人转离自己的恶道；这样，我就会后悔，不把我因他们恶行而打算降给他们的灾祸降下。’”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:6; 耶利米书 44:10; 以赛亚书 1:20"> 你要告诉他们：“耶和华如此说：‘如果你们不听从我，不遵行我摆在你们面前的律法，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 11:7; 列王纪下 9:7; 耶利米书 7:13"> 不听从我仆人众先知的话，就是我一再早早起来差遣到你们那里去的人——可是你们没有听从——</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 24:9; 列王纪下 22:19; 耶利米书 25:18"> 那么我就要使这殿像示罗一样，并使这城成为地上万国咒诅的话柄。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 5:31; 弥迦书 3:11; 使徒行传 5:17"> 祭司、先知和众民都听见耶利米在耶和华殿中说这些话。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:13–14; 使徒行传 7:52; 耶利米书 18:18"> 耶利米说完耶和华命令他向众民所说的一切话，祭司、先知和众民就抓住他，说：“你必定要死！</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:17–19; 使徒行传 19:24–32; 弥迦书 2:6"> 你为什么奉耶和华的名说预言，说：‘这殿必像示罗一样，这城必荒凉，无人居住’？”众民都在耶和华殿中聚集，围住耶利米。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:10; 耶利米书 38:4–6; 耶利米书 37:14–16"> 犹大的首领听见这些事，就从王宫上到耶和华的殿，坐在耶和华殿新门的入口处。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 38:4; 马太福音 26:66; 申命记 18:20"> 祭司和先知就对首领和众民说：“这个人该死，因为他向这城说预言攻击它，正如你们亲耳所听见的。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:29; 耶利米书 26:15; 使徒行传 4:19"> 耶利米就对所有首领和众民说：“耶和华差遣我向这殿和这城说预言，说你们所听见的这一切话。</span>
<span className="v" id="v13" data-v="13" data-xref="约拿 3:9; 约拿 4:2; 以赛亚书 1:19"> 现在你们要改正自己的道路和行为，听从耶和华你们上帝的声音；这样，耶和华就会后悔，不把祂向你们所宣告的灾祸降下。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 9:25; 撒母耳记下 15:26; 耶利米书 38:5"> 至于我，看哪，我在你们手中；你们看怎样是好的、正当的，就怎样待我吧。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 35:33; 箴言 6:17; 马太福音 26:25"> 只是你们要确知，如果你们把我处死，就必使无辜人的血归到你们自己、这城和城中居民身上；因为耶和华确实差遣我到你们这里，把这一切话说给你们听。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 5:34–39; 使徒行传 23:29; 使徒行传 25:25"> 于是首领和众民对祭司和先知说：“这个人不该死，因为他是奉耶和华我们上帝的名对我们说话。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:34; 弥迦书 1:1"> 国中的几位长老起来，对民的全会众说：</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 1:1; 尼希米记 4:2; 撒迦利亚书 8:3"> “摩利沙人弥迦在犹大王希西家的日子说预言；他对犹大众人说：‘万军之耶和华如此说：<br /><span className="pl pl-1">“锡安必被耕种，像一块田地；</span><br /><span className="pl pl-2">耶路撒冷必成为废墟，</span><br /><span className="pl pl-2">这殿所在的山必成为森林中的高处。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 32:14; 撒母耳记下 24:16; 以赛亚书 37:15–20"> 犹大王希西家和全犹大把他处死了吗？希西家岂不是敬畏耶和华，恳求耶和华施恩，耶和华就后悔，不把祂向他们所宣告的灾祸降下吗？我们若那样做，就是大大作恶，害自己的性命了！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 7:2; 约书亚记 9:17; 约书亚记 15:60"> 还有一个人奉耶和华的名说预言，就是基列·耶琳人示玛雅的儿子乌利亚；他照耶利米一切的话，向这城和这地说预言攻击它们。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:23; 马太福音 14:5; 耶利米书 36:26"> 约雅敬王和他所有勇士、所有首领听见乌利亚的话，王就想把他处死；乌利亚听见了，就害怕，逃到埃及去了。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 36:12; 列王纪下 22:12; 列王纪下 22:14"> 约雅敬王派亚革波的儿子以利拿单和几个人同他一起去埃及。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 2:30; 启示录 11:7; 以西结 19:6"> 他们把乌利亚从埃及带出来，领到约雅敬王那里；王用刀杀了他，把他的尸体丢在平民的坟地里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 40:5–7; 耶利米书 39:14; 耶利米书 1:18–19"> 然而沙番的儿子亚希甘的手扶助耶利米，使他们没有把他交在百姓手中处死。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="列王纪下 23:35; 耶利米书 1:3; 耶利米书 25:1"> 犹大王约西亚的儿子约雅敬在位的日子，有话从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:55; 历代志上 9:26; 列王纪上 6:5–6"> “你去利甲族的家，对他们说话，带他们进耶和华的殿，进入其中一间房间，给他们酒喝。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 于是我带了哈巴洗尼雅的孙子、耶利米的儿子雅撒尼亚，和他的弟兄、他所有的儿子，以及利甲全族；</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 33:1; 列王纪下 12:9; 历代志下 8:14"> 我把他们带进耶和华的殿，进入上帝之人伊基大利的儿子哈难众子的房间；这房间在官长们的房间旁边，在沙龙的儿子、看守门槛的玛西雅的房间上面。</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 9:7; 阿摩司 2:12; 哥林多后书 2:9"> 我把盛满酒的碗和杯摆在利甲族众子面前，对他们说：“请喝酒！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 1:15; 历代志上 2:55; 列王纪下 10:15"> 但他们说：“我们不喝酒；因为我们的祖先利甲的儿子约拿达曾吩咐我们说：‘你们和你们的子孙永远不可喝酒。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 35:10; 创世记 25:27; 尼希米记 8:14–16"> 你们不可建造房屋，不可撒种，不可栽种葡萄园，也不可拥有葡萄园；你们一生都要住在帐棚里，好使你们在寄居为游牧者的地上可以活许多日子。’</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:20; 箴言 4:10; 箴言 1:8–9"> 凡我们的祖先利甲的儿子约拿达所吩咐我们的，我们都听从了：我们和我们的妻子、儿女，一生都不喝酒；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 6:6; 耶利米书 35:7; 诗篇 37:16"> 也不为自己建造房屋居住。我们没有葡萄园、田地或种子；</span>
<span className="v" id="v10" data-v="10"> 只住在帐棚里，并且听从，照我们祖先约拿达所吩咐我们的一切去行。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:14; 耶利米书 4:5–7; 但以理 1:1–2"> 但是巴比伦王尼布甲尼撒上来攻击这地的时候，我们说：‘来吧！我们去耶路撒冷，为要躲避迦勒底人的军队和亚兰人的军队。’这样，我们就住在耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华的话临到耶利米，说：</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:33; 耶利米书 5:3; 耶利米书 6:8–10"> “万军之耶和华、以色列的上帝如此说：‘你去告诉犹大人和耶路撒冷的居民：“你们还不接受训诲，听从我的话吗？”这是耶和华说的。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:3–4; 耶利米书 7:24–26; 箴言 1:20–33"> “利甲的儿子约拿达吩咐他子孙不可喝酒的话，他们都遵行了；直到今日他们都不喝，因为他们听从自己祖先的命令；但我曾对你们说话，早早起来说话，你们却不听从我。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 18:11; 以西结 18:30–32; 耶利米书 25:5–6"> 我也差遣我所有的仆人众先知到你们那里，早早起来差遣他们，说：‘你们各人现在都要离开自己的恶道，改正你们的行为，不可跟从别神去事奉它们。这样，你们就必住在我赐给你们和你们祖先的土地上。’可是你们没有侧耳，也没有听从我。</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 1:6; 耶利米书 35:14; 路加福音 15:11–13"> 利甲的儿子约拿达的子孙遵行了他们祖先吩咐他们的命令，但这百姓却不听从我。”’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 66:4; 以赛亚书 65:12; 罗马书 10:21"> “因此，耶和华，万军的上帝、以色列的上帝如此说：‘看哪，我必使我所宣告要降在犹大和耶路撒冷所有居民身上的一切灾祸临到他们；因为我对他们说话，他们却不听；我呼唤他们，他们却不回答。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16; 出埃及记 20:12; 以弗所书 6:1–3"> 耶利米对利甲族说：“万军之耶和华、以色列的上帝如此说：‘因为你们听从了你们祖先约拿达的命令，谨守他一切的训令，并照他所吩咐你们的一切去行，’</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 15:19; 路加福音 21:36; 耶利米书 33:17–18"> 所以万军之耶和华、以色列的上帝如此说：‘利甲的儿子约拿达必永远不缺少一个人侍立在我面前。’”</span>
</div>
</div>

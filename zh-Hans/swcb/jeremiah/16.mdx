<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:2; 耶利米书 2:1; 耶利米书 1:4"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:26–27; 路加福音 23:29; 创世记 19:14"> “你不可在这地方娶妻，也不可有儿女。”</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 16:9; 耶利米书 16:5; 耶利米书 6:21"> 因为论到在这地方所生的儿女，论到生他们的母亲，和在这地生养他们的父亲，耶和华如此说：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 25:33; 诗篇 83:10; 耶利米书 9:22"> “他们必惨死；无人为他们哀哭，也无人埋葬他们。他们必像粪土在地面上。他们必被刀剑和饥荒吞灭；他们的尸体必给空中的飞鸟和地上的走兽作食物。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结 24:16–23; 以赛亚书 27:11; 耶利米书 15:1–4"> 耶和华如此说：“不要进入丧家；不要去哀哭，也不要为他们悲伤，因为我已从这百姓收回我的平安，”耶和华说，“就是慈爱和怜悯。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:1; 耶利米书 41:5; 耶利米书 47:5"> 无论尊大还是卑微，都必死在这地；他们不得埋葬。人不会为他们哀哭，不会为他们割伤自己，也不会为他们剃光头。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿 9:4; 以西结 24:17; 申命记 26:14"> 人不会在哀悼中为他们擘饼，因死人安慰他们；也不会因他们的父亲或母亲，给他们喝安慰杯。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 15:17; 传道书 7:2–4; 以赛亚书 22:12–14"> “你不可进入宴乐之家，与他们同坐吃喝。”</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 25:10; 耶利米书 7:34; 以西结 26:13"> 因为万军之耶和华——以色列的上帝如此说：“看哪，在你眼前，在你有生之日，我要使欢笑的声音和喜乐的声音、新郎的声音和新娘的声音，从这地方止息。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:19; 列王纪上 9:8–9; 申命记 29:24–25"> 你将这一切话告诉这百姓的时候，他们若问你：‘耶和华为什么宣告要把这一切大灾祸降在我们身上？’或问：‘我们的罪孽是什么？’或问：‘我们得罪耶和华我们的上帝，所犯的罪是什么？’</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:35–41; 申命记 29:25–26; 耶利米书 22:9"> 你就要告诉他们：‘因为你们的列祖离弃了我，’耶和华说，‘随从别的神明，服侍它们，敬拜它们；他们离弃了我，没有遵守我的律法。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 13:10; 耶利米书 7:26; 传道书 9:3"> 你们行恶比你们列祖更甚；看哪，你们各人都随从自己邪恶顽梗的心而行，以致不听从我。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:36; 申命记 4:26–28; 耶利米书 15:14"> 因此，我必把你们从这地赶出去，进入你们和你们列祖都不认识的地。在那里，你们必昼夜服侍别的神明，因为我必不向你们施恩。’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:7–8; 申命记 15:15; 出埃及记 20:2"> “所以，看哪，日子将到，”耶和华说，“人不再说：‘我指着那领以色列人从埃及地上来的永活的耶和华起誓；’</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:18; 耶利米书 24:6; 耶利米书 32:37"> 却要说：‘我指着那领以色列人从北方之地，并从祂赶逐他们到的各国上来的永活的耶和华起誓。’我必领他们回到我赐给他们列祖的土地。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哈巴谷 1:14–15; 阿摩司 4:2; 弥迦书 7:2"> “看哪，我要召许多渔夫来，”耶和华说，“他们必把他们打捞上来。随后我要召许多猎人来，他们必从各山、各冈、岩石缝中猎取他们。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 15:3; 耶利米书 23:24; 箴言 5:21"> 因为我的眼目察看他们一切所行的路；他们不能从我面前隐藏，他们的罪孽也不能从我眼前遮掩。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 35:33–34; 以赛亚书 40:2; 启示录 18:6"> 我先要加倍报应他们的罪孽和他们的罪，因为他们用自己可憎之物的尸骸玷污了我的地，又用他们可厌之物充满了我的产业。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 25:4; 耶利米书 17:17; 那鸿书 1:7"> <span className="pl pl-1">耶和华啊，我的力量、我的坚垒，</span><br /><span className="pl pl-2">我在患难之日的避难所，</span><br /><span className="pl pl-1">列国必从地极来到你这里，</span><br /><span className="pl pl-2">说：</span><br /><span className="pl pl-1">“我们的列祖所承受的不过是虚假，</span><br /><span className="pl pl-2">是虚空，是毫无益处的东西。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 37:19; 诗篇 115:4–8; 加拉太书 4:8"> <span className="pl pl-1">人岂可为自己制造神明，</span><br /><span className="pl pl-2">而它们其实不是神呢？”</span></span>
</div>

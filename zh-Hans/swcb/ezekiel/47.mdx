<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 22:1; 撒迦利亚书 14:8; 约珥 3:18"> 他带我回到殿的门口；看哪，有水从殿的门槛下向东流出，因为殿面朝东。水从殿的下面，从殿的右侧，就是祭坛的南边，往下流。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 44:4; 以西结 44:2"> 然后他带我从朝北的门出去，又领我绕到外面，来到外门，就是朝东的门。看哪，有水从右边流出。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结 40:3; 使徒行传 10:45–46; 使徒行传 11:16–18"> 那人手里拿着量绳向东出去，量了一千肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>使我涉过水，水到踝子骨。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:6; 罗马书 15:19; 使徒行传 19:10–20"> 他又量了一千肘，使我涉过水，水到膝盖。他又量了一千肘，使我涉过水，水到腰。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 11:9; 哈巴谷 2:14; 马太福音 13:31–32"> 后来他又量了一千肘；水成了河，使我不能涉过，因为水已经涨起，深到可游泳，是不能步行涉过的河。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结 44:5; 以西结 40:4; 撒迦利亚书 4:2"> 他对我说：“人子啊，你看见了吗？”<br />然后他带我回来，回到河岸。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 47:12; 启示录 22:2; 列王纪下 2:13"> 我回来的时候，看哪，河岸这边和那边有极多的树。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 3:16; 申命记 3:17; 列王纪下 2:19–22"> 他对我说：“这些水流向东方地区，下到亚拉巴。然后它们要流向海，流入海里，那海的水将被使之流出；水就会得医治。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 7:37–38; 约翰福音 6:63; 约翰福音 4:14"> 凡滋生群游的活物，在这些河流所到的各处都必存活。鱼必极其繁多；因为这些水流到那里，海水就会得医治，凡河流所到之处，一切都必存活。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 诗篇 104:25; 民数记 34:6"> 必有渔夫站在水边。从隐·基底直到隐·以革莲，都必成为撒网之处。那里的鱼必各从其类，像大海的鱼一样，极其繁多。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 29:23; 启示录 22:11; 耶利米书 17:6"> 只是它的泥沼和沼泽不得医治，必被留作盐地。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 22:2; 诗篇 1:3; 耶利米书 17:8"> 在河两岸，必生长各样可作食物的树；它们的叶子不会枯干，果子也不会断绝。每月必结新果，因为它们的水是从圣所流出来的。它们的果子可作食物，叶子可作医治。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 48:4–6; 耶利米书 3:18; 民数记 34:2–12"> 主耶和华如此说：“你们要按以色列十二支派分地为业，边界如下。约瑟必得两份。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 20:5–6; 创世记 12:7; 以西结 48:29"> 你们要承受这地，彼此一样；因为我曾起誓要把这地赐给你们的列祖。这地必归给你们为业。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 34:8; 以西结 48:1"> “这地的边界如下：<br />“北边，从大海起，经希特伦，直到西达入口；</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 48:1; 民数记 13:21; 撒母耳记下 8:8"> 哈马、比罗他、西伯莲（在大马士革边界和哈马边界之间），直到靠近浩兰边界的哈洗·哈提干。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 48:1; 民数记 34:9"> 从海起的边界，必到大马士革边界上的哈萨·以难；北面向北，是哈马的边界。这是北边。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 13:10; 创世记 31:23; 创世记 31:47"> “东边，在浩兰、大马士革、基列和以色列地之间，要以约旦河为界；你们要从北界量到东海。这是东边。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结 48:28; 申命记 32:51; 民数记 34:5"> “南边向南，要从他玛直到米利博·加低斯的水，又到小河，直到大海。这是南边向南。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 34:6; 以西结 48:1"> “西边要以大海为界，从南界直到哈马入口对面。这是西边。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> “你们要按以色列的支派，把这地分给自己。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:11; 以弗所书 3:6; 使徒行传 11:18"> 你们要拈阄把它分给你们为业，也分给住在你们中间、并在你们中间生儿育女的外人。他们在你们中间要像以色列子孙中本地出生的人一样，和你们一同在以色列支派中得产业。</span>
<span className="v" id="v23" data-v="23"> 外人寄居在哪个支派中，你们就要在那里把他的产业给他，”主耶和华说。</span>
</div>

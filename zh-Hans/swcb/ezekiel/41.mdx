<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 40:2–3; 以西结 40:17; 以西结 41:23"> 他带我到圣所，量了门柱，这边宽六肘，那边宽六肘，这就是帐幕的宽度。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 6:17; 历代志下 3:3; 列王纪上 6:2"> 入口的宽度是十肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>入口的两侧，这边五肘，那边五肘。他量了圣所的长度，四十肘；宽度，二十肘。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结 40:16"> 然后他往里面去，量了入口的门柱，各二肘；入口宽六肘；入口两侧的宽度七肘。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 6:20; 希伯来书 9:3–8; 出埃及记 26:33–34"> 他量了它的长度，二十肘；宽度，二十肘，在圣所前面。他对我说：“这是至圣所。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:5–6; 以西结 42:3–14; 以西结 41:6–9"> 然后他量了殿墙，厚六肘；围绕殿四周的每间旁屋，宽四肘。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:10; 列王纪上 6:5–6; 以西结 40:17"> 旁屋有三层，一层在另一层之上，每层三十间。旁屋四围嵌入属于殿的墙，好得支撑，却不穿透殿墙。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 6:8; 希伯来书 6:1; 马太福音 13:32"> 旁屋越往上越宽，因为墙越往上越窄。因此，殿越往上越宽；人从最低层经过中层，上到最高层。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结 40:5; 启示录 21:16"> 我又看见殿四围有升高的基座。旁屋的根基是一整竿，就是六大肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 41:11; 以西结 42:4; 以西结 42:1"> 旁屋外墙的厚度是五肘。余下的地方是属于殿的旁屋所在之处。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 40:17"> 房间之间的宽度是二十肘，在殿的四围各面。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 41:9; 以西结 42:4"> 旁屋的门朝向留下的空地，一扇门朝北，另一扇门朝南。那空地的宽度四围都是五肘。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结 42:1; 以西结 42:13; 以西结 41:13–15"> 在西边、朝向分隔之地前面的那座建筑，宽七十肘；建筑的墙四围厚五肘，长九十肘。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 40:47"> 于是他量了殿，长一百肘；又量分隔之地、那座建筑连同它的墙，长一百肘；</span>
<span className="v" id="v14" data-v="14"> 殿的正面宽度，以及朝东的分隔之地的宽度，也是一百肘。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 42:3; 以西结 42:1; 以西结 41:12"> 他量了在殿后、分隔之地前面那座建筑的长度，以及这边和那边的楼廊，从内殿起共一百肘；又量院子的廊子，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 6:4; 以西结 40:25; 以西结 40:16"> 门槛、封闭的窗户，以及四围三层的楼廊，在门槛对面，四围都有木板镶覆；从地面到窗户，（这些窗户是遮蔽的，）</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 42:15"> 直到门上方的空间，直到内殿，也到外面，并量了内外四围所有的墙，都是按尺寸。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:36; 以西结 40:16; 以西结 40:22"> 墙上做有基路伯和棕树；每两个基路伯之间有一棵棕树，每个基路伯有两张脸：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 10:14; 以西结 1:10"> 这边有人的脸朝向棕树，那边有少壮狮子的脸朝向棕树。全殿四围都是这样做的。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 41:18"> 从地面到门上方都做有基路伯和棕树。殿墙就是这样。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结 41:1; 列王纪上 6:33; 以西结 40:14"> 圣所的门柱是方的。至于圣所的正面，它的外观如同殿的外观。</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 1:12; 以西结 23:41; 玛拉基书 1:7"> 祭坛是木做的，高三肘，长二肘。它的角、它的座和它的侧面都是木做的。他对我说：“这是在耶和华面前的桌子。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 6:31–35; 历代志下 4:22; 以西结 41:1"> 殿和圣所各有两扇门。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:34; 以西结 40:48"> 每扇门各有两片门扇，是两片可转动的门扇：这一扇门有两片，另一扇门也有两片。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结 41:18"> 在圣所的门上做有基路伯和棕树，像墙上所做的一样。外面廊子的正面有木门槛。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 41:16; 以西结 40:16; 以西结 41:5"> 廊子的两侧，这边和那边，都有封闭的窗户和棕树。殿的旁屋和门槛就是这样安排的。</span>
</div>

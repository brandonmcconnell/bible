<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:1–11; 约书亚记 13:29–31; 创世记 48:14–20"> “挨着拿弗他利的边界，从东边到西边，玛拿西得一份。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 17:8–10; 约书亚记 17:14–18; 约书亚记 16:1–10"> “挨着玛拿西的边界，从东边到西边，以法莲得一份。</span>

<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 13:15–21; 创世记 29:32; 创世记 49:3–4"> “挨着以法莲的边界，从东边直到西边，流便得一份。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:1–63; 约书亚记 19:9; 创世记 29:35"> “挨着流便的边界，从东边到西边，犹大得一份。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结 45:1–6; 以赛亚书 12:6; 以赛亚书 33:20–22"> “挨着犹大的边界，从东边到西边，要有你们所献的供地，宽二万五千苇，长度如同各支派的一份，从东边到西边；圣所要在其中间。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “你们献给耶和华的供地，长二万五千苇，宽一万苇。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 45:4; 以西结 44:28; 马太福音 10:10"> 这圣供地要归祭司：北面长二万五千，西面宽一万，东面宽一万，南面长二万五千；耶和华的圣所要在其中间。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 40:46; 以西结 44:10; 马太福音 24:45–46"> 这地要归撒督子孙中分别为圣的祭司，就是那些谨守我吩咐的；以色列人走迷的时候，他们没有像利未人那样走迷。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 27:21; 以西结 45:4"> 这地要归他们，作为从全地供地中献上的供地，是至圣的，挨着利未人的边界。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 45:3; 申命记 12:19; 以西结 45:5"> “利未人所得的，要沿着祭司的边界，长二万五千肘，宽一万肘；全长二万五千，宽一万。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:28; 利未记 27:9–10; 出埃及记 22:29"> 他们不可卖出其中任何部分，也不可交换；这地初献的部分也不可转让，因为它归耶和华为圣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 42:20; 以西结 45:6; 以西结 44:23"> “那二万五千前面所剩下宽五千肘的地，要作普通用途，归城使用，作为居住地和郊地；城要在其中间。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 21:16"> 这些是城的尺寸：北面四千五百，南面四千五百，东面四千五百，西面四千五百。</span>
<span className="v" id="v17" data-v="17"> 城要有郊地：向北二百五十，向南二百五十，向东二百五十，向西二百五十。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 9:27; 以斯拉记 2:43–58; 以西结 45:6"> 沿着圣供地所剩下的长度，东边一万，西边一万；它要沿着圣供地。它的出产要作城中劳作者的食物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 45:6; 列王纪上 4:7–23; 尼希米记 11:1–36"> 在城中劳作的人，就是从以色列各支派出来的人，要耕种这地。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 21:16; 希伯来书 12:17"> 全部供地要是二万五千乘二万五千的正方形。你们要把它连同城的产业一起献上，作为圣供地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结 48:22; 以西结 37:24; 以西结 48:8"> “所剩下的地要归王，在圣供地和城的产业两边；从供地的二万五千向东到东边界，又向西从二万五千到西边界，沿着各支派的份，都要归王。圣供地和殿的圣所要在其中间。</span>
<span className="v" id="v22" data-v="22"> 此外，除了利未人的产业和城的产业，那位于王的产业中间、在犹大边界和便雅悯边界之间的地，都要归王。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约书亚记 18:21–28; 以西结 48:1–7; 创世记 35:16–19"> “至于其余的支派：从东边到西边，便雅悯得一份。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:1–9; 创世记 29:33; 创世记 49:5–7"> “挨着便雅悯的边界，从东边到西边，西缅得一份。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 19:17–23; 创世记 30:14–18"> “挨着西缅的边界，从东边到西边，以萨迦得一份。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约书亚记 19:10–16; 创世记 30:19–20"> “挨着以萨迦的边界，从东边到西边，西布伦得一份。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 13:24–28; 创世记 30:10–11"> “挨着西布伦的边界，从东边到西边，迦得得一份。</span>

</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 13:1–21; 民数记 34:2; 民数记 34:13"> “这就是你们要抽签分给以色列各支派为产业的地；这些就是他们各自的份。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结 48:16; 启示录 21:16; 以西结 48:32–35"> “这些是城的出口：北面按尺寸四千五百苇；</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 21:12–13; 以赛亚书 26:1–2; 启示录 21:21"> 城门要按以色列支派的名字命名，北面有三门：流便门一座，犹大门一座，利未门一座。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> “东面四千五百苇，有三门：约瑟门一座，便雅悯门一座，但门一座。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> “南面按尺寸四千五百苇，有三门：西缅门一座，以萨迦门一座，西布伦门一座。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> “西面四千五百苇，有三门：迦得门一座，亚设门一座，拿弗他利门一座。</span>

<span className="v" id="v35" data-v="35" data-xref="启示录 21:3; 撒迦利亚书 2:10; 启示录 22:3"> “城的周围共一万八千苇；从那日起，这城的名字要称为『耶和华在那里』。”</span>

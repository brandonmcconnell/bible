<span className="v" id="v2" data-v="2" data-xref="以西结 29:3; 那鸿书 2:11–13; 以西结 27:2"> “人子啊，你要为埃及王法老作哀歌，对他说：<br /><span className="pl pl-1">‘你曾被比作列国中的少壮狮子；</span><br /><span className="pl pl-2">然而你却像海中的怪兽。</span><br /><span className="pl pl-1">你在自己的江河中冲出，</span><br /><span className="pl pl-2">用脚搅动众水，</span><br /><span className="pl pl-2">又弄浑他们的江河。’”</span></span>
<span className="v" id="v3" data-v="3" data-xref="以西结 12:13; 耶利米书 16:16; 传道书 9:12"> <span className="pl pl-1">主耶和华如此说：</span><br /><span className="pl pl-2">“我要用许多民族聚集的众人，</span><br /><span className="pl pl-2">将我的网撒在你身上；他们必把你拉上我的网。</span></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 18:6; 以西结 29:5; 以西结 31:12–13"> <span className="pl pl-1">我要把你丢在陆地上，</span><br /><span className="pl pl-2">把你抛在田野间，</span><br /><span className="pl pl-1">使天空所有的飞鸟落在你身上，</span><br /><span className="pl pl-2">又使全地的走兽因你得饱足。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结 31:12"> <span className="pl pl-1">我要把你的肉放在山岭上，</span><br /><span className="pl pl-2">用你高大的躯体填满山谷。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 34:3; 以赛亚书 34:7; 启示录 14:20"> <span className="pl pl-1">我要用你的血浇灌你游泳之地，</span><br /><span className="pl pl-2">直到山上；</span><br /><span className="pl pl-2">水道都必充满你。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:29; 约珥 2:31; 以赛亚书 13:10"> <span className="pl pl-1">我熄灭你的时候，必遮盖诸天，</span><br /><span className="pl pl-2">使天上的星宿昏暗。</span><br /><span className="pl pl-1">我必用云遮盖太阳，</span><br /><span className="pl pl-2">月亮也不发光。</span></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:14; 箴言 20:20"> <span className="pl pl-1">我必使天上所有明亮的光体在你以上变为昏暗，</span><br /><span className="pl pl-2">又使黑暗临到你的地，”主耶和华说。</span></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 18:10–15; 以西结 30:26; 耶利米书 25:15–25"> <span className="pl pl-1">“我把你的毁灭带到列国中，</span><br /><span className="pl pl-2">带到你素来不认识的各国时，</span><br /><span className="pl pl-2">必使许多民族的心烦乱。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西结 26:16; 以西结 27:35; 列王纪上 9:8"> <span className="pl pl-1">是的，我在他们面前挥动我的刀时，</span><br /><span className="pl pl-2">必使许多民族因你惊骇，</span><br /><span className="pl pl-1">他们的君王也必因你极其恐惧。</span><br /><span className="pl pl-2">在你倾倒的日子，</span><br /><span className="pl pl-1">他们各人必时时刻刻为自己的性命战兢。”</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 43:10; 以西结 26:7; 以西结 30:22–25"> <span className="pl pl-1">因为主耶和华如此说：</span><br /><span className="pl pl-2">“巴比伦王的刀必临到你。</span></span>
<span className="v" id="v12" data-v="12" data-xref="以西结 28:7; 以西结 29:19; 以西结 31:11"> <span className="pl pl-1">我要使你的众民倒在勇士的刀下；</span><br /><span className="pl pl-2">他们都是列国中强暴的人。</span><br /><span className="pl pl-1">他们必使埃及的骄傲归于无有，</span><br /><span className="pl pl-2">它所有的众民都必被灭。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西结 29:11; 以西结 29:8; 以西结 30:12"> <span className="pl pl-1">我要从众水旁毁灭它所有的牲畜。</span><br /><span className="pl pl-2">人的脚不再搅动这些水，</span><br /><span className="pl pl-2">牲畜的蹄也不再搅动。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">那时，我要使他们的水澄清，</span><br /><span className="pl pl-2">使他们的江河像油一样流动，”</span><br /><span className="pl pl-2">主耶和华说。</span></span>
<span className="v" id="v15" data-v="15" data-xref="以西结 6:7; 出埃及记 7:5; 出埃及记 14:4"> <span className="pl pl-1">“我使埃及地荒凉废弃，</span><br /><span className="pl pl-2">使那地失去它所充满的一切，</span><br /><span className="pl pl-1">又击杀其中所有居民的时候，</span><br /><span className="pl pl-2">他们就知道我是耶和华。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 1:17; 历代志下 35:25; 以西结 26:17"> “‘“这就是他们要唱的哀歌。列国的女子要用这哀歌哀悼；她们要用这哀歌为埃及和它所有的众民哀悼，”主耶和华说。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 32:1; 以西结 33:21; 以西结 1:2"> 第十二年本月十五日，耶和华的话又临到我，说：</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 31:14; 以西结 32:2; 耶利米书 1:10"> “人子啊，你要为埃及的众民哀号，把他们，就是她和有名列国的女子，与下坑的人一同抛到地的最低处。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 31:18; 以西结 32:29–30; 耶利米书 9:25–26"> 你比谁更美呢？下去吧，与未受割礼的人同卧。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 28:3; 以西结 32:23–26; 以西结 32:29–30"> 他们必倒在被刀杀的人中。她已经交给刀剑了。要把她和她所有的众民拖去。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 14:9–10; 以西结 32:27; 以西结 32:19"> 勇士中的强者，要从阴间<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>中对他和帮助他的人说话。他们已经下去了。未受割礼、被刀杀的人静卧在那里。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结 32:26; 以西结 32:29–30; 以西结 32:24"> “亚述在那里，她所有的众军也在那里。她的坟墓在她四围；他们全都被杀，倒在刀下。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 26:20; 以西结 32:24–27; 诗篇 27:13"> 他们的坟墓设在坑的最深处，她的众军围绕她的坟墓；他们全都被杀，倒在刀下；他们曾在活人之地使人惊恐。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结 32:18; 以西结 26:20; 耶利米书 49:34–39"> “以拦在那里，她所有的众民在她坟墓四围；他们全都被杀，倒在刀下，未受割礼就下到地的最低处；他们曾在活人之地使人惊恐，如今与下坑的人一同担当自己的羞辱。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 139:8; 历代志上 10:4; 撒母耳记下 1:20"> 有人为以拦和她所有的众民，在被杀的人中安置床榻。她的坟墓在她四围；他们全都未受割礼，被刀杀了；因为他们曾在活人之地使人惊恐，如今与下坑的人一同担当自己的羞辱。以拦被安放在被杀的人中。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西结 27:13; 创世记 10:2; 以西结 38:2–3"> “米设、土巴和他们所有的众民在那里。他们的坟墓在他们四围；他们全都未受割礼，被刀杀了；因为他们曾在活人之地使人惊恐。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:18–19; 约伯记 3:13–15; 以西结 32:21"> 他们不得与未受割礼者中倒下的勇士同卧；那些勇士带着兵器下到阴间，把刀剑枕在头下。他们的罪孽在他们的骨头上；因为他们曾在活人之地成为勇士所惧怕的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理 2:34–35"> “但你也要在未受割礼的人中被打碎，与被刀杀的人同卧。</span>

</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西结 31:16; 以西结 14:22; 耶利米哀歌 2:13"> “法老看见他们，就必为他所有的众民得安慰；法老和他的全军都被刀杀了，”主耶和华说。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结 32:27; 创世记 35:5; 哥林多后书 5:11"> “因为我曾使他在活人之地令人惊恐。他必被安放在未受割礼的人中，与被刀杀的人同在；法老和他所有的众民都必如此，”主耶和华说。</span>

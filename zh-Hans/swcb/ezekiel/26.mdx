<span className="v" id="v1" data-v="1" data-xref="以西结 20:1; 以西结 1:2; 耶利米书 39:2"> 第十一年，某月初一日，耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 23:1–18; 以西结 36:2; 约珥 3:4"> “人子啊，因为推罗论耶路撒冷说：‘啊哈！那作万民门户的已经破碎，转向我了；她既荒废，我必得丰盛。’</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 51:42; 以赛亚书 5:30; 弥迦书 4:11"> 所以主耶和华这样说：‘看哪，推罗啊，我与你为敌；我必使许多国家上来攻击你，如同海使波浪涌起。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 23:11; 阿摩司 1:10; 以西结 26:9"> 他们必毁坏推罗的城墙，拆毁她的塔楼；我也必刮去她的尘土，使她成为光秃的磐石。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 29:19; 以西结 27:32; 以西结 25:7"> 她必在海中成为铺晒渔网的地方；因为我已经说了，’主耶和华说，‘她必成为列国的掠物。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 16:46; 以西结 26:8; 耶利米书 49:2"> 她在田野中的属城必被刀剑杀戮。这样，他们就知道我是耶和华。’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:12; 但以理 2:37; 以西结 23:24"> “因为主耶和华这样说：‘看哪，我必使巴比伦王尼布甲尼撒，就是诸王之王，从北方来攻击推罗；他必带着马匹、战车、骑兵和许多人民的军队。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 21:22; 耶利米书 52:4; 耶利米书 32:24"> 他必用刀剑杀你在田野中的属城；他必建造堡垒攻击你，筑起土垒攻击你，举起盾牌攻击你。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 26:15"> 他必把攻城锤对准你的城墙，用斧头拆毁你的塔楼。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 26:15; 以西结 27:28; 耶利米书 47:3"> 因他的马匹众多，扬起的尘土必遮盖你；当他进入你的城门，如同人进入被攻破的城时，骑兵、车轮和战车的响声必使你的城墙震动。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:28; 以赛亚书 26:5; 哈巴谷 1:8"> 他必用马蹄践踏你所有的街道；他必用刀剑杀你的人民；你坚固的柱子必倒在地上。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 23:8; 历代志下 32:27; 撒迦利亚书 9:3–4"> 他们必掠夺你的财富，抢劫你的货物；他们必拆毁你的城墙，毁坏你华美的房屋；他们必把你的石头、木料和尘土都抛在水中。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:34; 以赛亚书 23:16; 以赛亚书 14:11"> 我必使你歌唱的声音止息；你竖琴的声音必不再被听见。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 1:4; 约伯记 12:14; 民数记 23:19"> 我必使你成为光秃的磐石；你必成为铺晒渔网的地方。你必不再被建造；因为我耶和华已经说了，’主耶和华说。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以西结 27:35; 耶利米书 49:21; 以西结 26:18"> “主耶和华对推罗这样说：‘当你倾倒的响声传出，当受伤的人呻吟，当杀戮在你中间施行时，海岛岂不震动吗？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 32:10; 约拿 3:6; 约伯记 8:22"> 那时，海上的众首领都必从宝座上下来，脱下礼袍，除去刺绣的衣服；他们必披上战兢，坐在地上，时时刻刻发抖，因你而惊骇。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:12; 以西结 19:1; 撒母耳记下 1:25–27"> 他们必为你唱起哀歌，对你说：<br /><span className="pl pl-1">“你这有航海者居住的名城，</span><br /><span className="pl pl-2">何竟被毁灭！</span><br /><span className="pl pl-1">你在海上强盛，</span><br /><span className="pl pl-2">你和你的居民，</span><br /><span className="pl pl-1">曾使所有住在那里的人</span><br /><span className="pl pl-2">都惧怕！”</span></span>
<span className="v" id="v18" data-v="18" data-xref="以西结 26:15; 以赛亚书 23:5–7; 以西结 27:35"> <span className="pl pl-1">现在，在你倾倒的日子，海岛必战兢；</span><br /><span className="pl pl-2">是的，海中的岛屿必因你的离去而惊惶。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:7–8; 以西结 26:3; 但以理 11:40"> “因为主耶和华这样说：‘我使你成为荒凉的城，像无人居住的城一样；我使深渊上来淹没你，使大水覆盖你；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 27:13; 路加福音 10:15; 撒迦利亚书 2:8"> 那时，我必使你与下坑的人一同下去，到古时的人那里；我必使你住在地的低处，在久已荒凉之处，与下坑的人同住，使你无人居住；我必在活人之地设立荣耀。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 27:36; 以西结 28:19; 启示录 18:21"> 我必使你成为可惊骇的事；你将不复存在。人虽寻找你，却永远不再寻见你，’主耶和华说。”</span>
</div>

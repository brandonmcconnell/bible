<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 31:29–30; 耶利米哀歌 5:7; 以西结 37:11"> “你们在以色列地引用这句俗语，说：<br /><span className="pl pl-1">‘父亲吃了酸葡萄，</span><br /><span className="pl pl-2">儿女的牙就酸倒了。’</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结 18:19–20; 以西结 33:11–20; 以西结 18:30"> “主耶和华说：我指着我的永生起誓，你们在以色列必不再引用这句俗语。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 18:20; 罗马书 6:23; 民数记 16:22"> 看哪，所有灵魂都是我的；父亲的灵魂怎样属于我，儿子的灵魂也照样属于我。犯罪的灵魂必死亡。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以西结 33:14; 约翰一书 3:7; 箴言 21:3"> <span className="pl pl-1">“但人若是公义的，</span><br /><span className="pl pl-2">行公正和公义的事，</span></span>
<span className="v" id="v6" data-v="6" data-xref="以西结 18:15; 申命记 4:19; 以西结 6:13"> <span className="pl pl-1">没有在山上吃祭物，</span><br /><span className="pl pl-2">没有举目仰望以色列家的偶像，</span><br /><span className="pl pl-1">没有玷污邻舍的妻子，</span><br /><span className="pl pl-2">没有在妇女经期亲近她；</span></span>
<span className="v" id="v7" data-v="7" data-xref="以西结 18:16; 出埃及记 22:26; 以西结 18:12"> <span className="pl pl-1">没有亏负任何人，</span><br /><span className="pl pl-2">却把债户的抵押物归还给他；</span><br /><span className="pl pl-1">没有抢夺人的东西，</span><br /><span className="pl pl-2">把自己的食物给饥饿的人，</span><br /><span className="pl pl-2">又用衣服遮盖赤身的人；</span></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 22:25; 撒迦利亚书 8:16; 申命记 23:19–20"> <span className="pl pl-1">没有借贷取利，</span><br /><span className="pl pl-2">没有收取增利；</span><br /><span className="pl pl-1">从罪恶中收回自己的手，</span><br /><span className="pl pl-2">在人与人之间施行真实的公正；</span></span>
<span className="v" id="v9" data-v="9" data-xref="以西结 20:11; 哈巴谷 2:4; 阿摩司 5:4"> <span className="pl pl-1">遵行我的律例，</span><br /><span className="pl pl-2">谨守我的典章，</span><br /><span className="pl pl-2">以诚实行事；</span><br /><span className="pl pl-1">这人是公义的，</span><br /><span className="pl pl-2">他必定存活。”主耶和华说。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:12; 约翰一书 3:12; 约翰福音 18:40"> “如果他生了一个儿子，是强盗，流人的血，并且做这些事中的任何一件，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 22:14; 马太福音 7:21–27; 列王纪上 13:8"> 或者不做那些正事中的任何一件，<br /><span className="pl pl-1">反而在山上的丘坛吃祭物，</span><br /><span className="pl pl-2">玷污邻舍的妻子，</span></span>
<span className="v" id="v12" data-v="12" data-xref="以西结 8:17; 以西结 8:6; 列王纪下 21:11"> <span className="pl pl-1">亏负贫穷和贫乏的人，</span><br /><span className="pl pl-2">抢夺人的东西，</span><br /><span className="pl pl-1">不归还抵押物，</span><br /><span className="pl pl-2">举目仰望偶像，</span><br /><span className="pl pl-2">行可憎的事，</span></span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:25; 利未记 20:9; 以西结 3:18"> <span className="pl pl-1">借贷取利，</span><br /><span className="pl pl-2">向穷人收取增利，</span><br />这样的人还会存活吗？他必不能存活。他行了这一切可憎的事，必定死亡；他的血必归到自己身上。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:21; 箴言 23:24; 耶利米书 8:6"> “现在，看哪，如果他生了一个儿子，看见父亲所犯的一切罪，就惧怕，不照样去行，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 18:6–7; 以西结 18:11–13"> <span className="pl pl-1">没有在山上吃祭物，</span><br /><span className="pl pl-2">没有举目仰望以色列家的偶像，</span><br /><span className="pl pl-2">没有玷污邻舍的妻子，</span></span>
<span className="v" id="v16" data-v="16" data-xref="以西结 18:7; 以赛亚书 58:7–10; 约伯记 22:7"> <span className="pl pl-1">没有亏负任何人，</span><br /><span className="pl pl-2">没有拿人的东西作抵押，</span><br /><span className="pl pl-1">没有抢夺人的东西，</span><br /><span className="pl pl-2">却把自己的食物给饥饿的人，</span><br /><span className="pl pl-2">又用衣服遮盖赤身的人；</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结 18:8–9; 马太福音 18:27–35; 以西结 18:13"> <span className="pl pl-1">不向穷人伸手加害，</span><br /><span className="pl pl-2">没有收取利息或增利；</span><br /><span className="pl pl-1">遵行我的典章，</span><br /><span className="pl pl-2">遵行我的律例；</span><br />他必不因父亲的罪孽而死亡；他必定存活。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 3:18; 以西结 18:26; 以西结 18:24"> 至于他的父亲，因为他残酷地欺压人，抢夺弟兄，在本族人中行不善的事，看哪，他必因自己的罪孽而死亡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:5; 撒迦利亚书 1:3–6; 申命记 5:9"> “然而你们说：‘儿子为什么不担当父亲的罪孽呢？’儿子既行公正和公义的事，谨守我一切的律例，并且遵行，他必定存活。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 24:16; 列王纪下 14:6; 以西结 18:4"> 犯罪的灵魂必死亡。儿子不担当父亲的罪孽，父亲也不担当儿子的罪孽。义人的义必归到自己身上，恶人的恶也必归到自己身上。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结 18:27–28; 提多书 2:11–14; 以西结 33:19"> “恶人若转离他所犯的一切罪，谨守我一切的律例，行公正和公义的事，他必定存活，不至死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 7:19; 以西结 33:16; 以赛亚书 43:25"> 他所犯的一切过犯，都不再被记念来控告他；他必因自己所行的义而存活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 33:11; 提摩太前书 2:4; 彼得后书 3:9"> 主耶和华说：我岂喜悦恶人死亡吗？岂不更喜悦他转离自己的道路而存活吗？</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结 33:18; 箴言 21:16; 约翰二书 1:8"> “但义人若转离自己的义，去行罪孽，照恶人所行一切可憎的事而行，他还会存活吗？他所行的一切义，都不被记念。他必因自己所犯的罪过和所犯的罪而死亡。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结 33:17; 玛拉基书 3:13–15; 玛拉基书 2:17"> “然而你们说：‘主的道路不公平。’以色列家啊，现在要听：我的道路不公平吗？岂不是你们的道路不公平吗？</span>
<span className="v" id="v26" data-v="26"> 义人若转离自己的义，去行罪孽，并因此死亡，他就是因自己所行的罪孽而死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 18:21; 以赛亚书 1:18; 以赛亚书 55:7"> 再者，恶人若转离自己所犯的恶，行公正和公义的事，他就必保全自己的生命。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:29; 路加福音 15:17–18; 雅各书 2:10–12"> 因为他省察，并转离自己所犯的一切过犯，他必定存活，不至死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 18:25; 箴言 19:3; 以西结 18:2"> 然而以色列家说：‘主的道路不公正。’以色列家啊，我的道路不公正吗？岂不是你们的道路不公正吗？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结 18:21; 马太福音 16:27; 马太福音 3:2"> “所以，主耶和华说：以色列家啊，我必按各人的道路审判你们。你们要回转，使自己转离一切过犯，这样，罪孽就不致成为你们败亡的祸根。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 51:10; 以西结 36:26; 以西结 11:19"> 你们要把自己所犯的一切过犯从你们身上丢弃，为自己造一个新心和新灵。以色列家啊，你们何必死亡呢？</span>
<span className="v" id="v32" data-v="32" data-xref="彼得后书 3:9; 以西结 18:23; 以西结 33:11"> 主耶和华说：因为我不喜悦那死亡的人死亡。所以你们要回转，就必存活！”</span>
</div>
</div>

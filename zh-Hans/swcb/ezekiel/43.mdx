<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 44:1; 以西结 42:15; 以西结 46:1"> 以后，他带我到门，就是朝东的门。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 18:1; 以西结 11:23; 以赛亚书 6:3"> 看哪，以色列上帝的荣耀从东方而来。祂的声音像众水的声音；大地因祂的荣耀而发光。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 9:5; 以西结 9:1; 耶利米书 1:10"> 这景象像我所见过的异象，就是我来毁灭这城时所见的异象；这些异象又像我在迦巴鲁河边所见的异象；我就脸伏于地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 10:18–19; 以西结 44:2; 以西结 43:2"> 耶和华的荣耀从朝东的门进入殿中。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:2–4; 列王纪上 8:10–11; 以西结 8:3"> 圣灵将我举起，带我进入内院；看哪，耶和华的荣耀充满了殿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结 40:3; 以赛亚书 66:6; 启示录 16:1"> 我听见有一位从殿中对我说话；有一个人站在我旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 43:9; 诗篇 47:8; 利未记 26:30"> 祂对我说：“人子啊，这是我宝座所在之处，是我脚掌所踏之处；我要在这里永远住在以色列人中间。以色列家和他们的君王，必不再因他们的淫乱，和他们在高处的君王尸首，玷污我的圣名；</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 5:11; 以西结 8:3–16; 历代志下 33:7"> 他们把自己的门槛设在我的门槛旁，把自己的门柱设在我的门柱旁，我与他们之间仅有一道墙；他们因所行可憎的事玷污了我的圣名。因此，我在怒中灭绝了他们。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 43:7; 以西结 37:26–28; 以西结 18:30–31"> 现在，让他们把他们的淫乱和他们君王的尸首从我面前除去，远离我；这样，我就要永远住在他们中间。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结 40:4; 以西结 16:61; 以西结 16:63"> “你，人子啊，要把这殿指示以色列家，使他们因自己的罪孽感到羞愧；让他们量度这模型。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 36:27; 以西结 11:20; 马太福音 28:20"> 如果他们因自己所做的一切感到羞愧，就要把殿的形状、样式、出口、入口、全部结构、所有条例、所有形状和所有律法都使他们知道；并且写在他们眼前，使他们遵守殿的全部形状和所有条例，并照着去行。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结 40:2; 启示录 21:27; 诗篇 93:5"> “这是殿的律法：山顶上殿四围的全界限都要至为圣洁。看哪，这就是殿的律法。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 40:5; 出埃及记 27:1–8; 以西结 41:8"> “以下是祭坛按肘量的尺寸（一肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="普通一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。一掌宽约4.3英寸或11厘米。">a</a></sup>是一肘加一掌）：底座高一肘，宽一肘，边缘四围的边框为一拃；<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一拃是人手张开时，从拇指尖到小指尖的长度（约半肘，即9英寸，或22.8厘米）。">b</a></sup>这就是祭坛的基座。</span>
<span className="v" id="v14" data-v="14"> 从地上的底座到下层台阶高二肘，宽一肘；从较小的台阶到较大的台阶高四肘，宽一肘。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 27:2; 诗篇 118:27; 利未记 9:9"> 坛的上部高四肘；从坛面向上有四个角。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1; 历代志下 4:1; 出埃及记 38:1–2"> 坛面长十二肘，宽十二肘，四面成正方形。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:26; 以西结 40:6; 出埃及记 25:25"> 台阶四面长十四肘，宽十四肘；四围的边框为半肘；底座四围为一肘；台阶要朝东。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:29; 希伯来书 10:4–12; 以西结 2:1"> 祂对我说：“人子啊，主耶和华如此说：‘建造祭坛、在其上献燔祭并洒血的那日，祭坛的条例如下：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 40:46; 以西结 44:15; 民数记 16:40"> 你要把一头小公牛作为赎罪祭，交给利未人的祭司，就是撒督的后裔，他们是亲近我、事奉我的人，’主耶和华说。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 16:19; 利未记 8:15; 出埃及记 29:12"> 你要取些公牛的血，抹在坛的四角、台阶的四个角和四围的边框上。你要这样洁净祭坛，为它赎罪。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:14; 利未记 4:12; 利未记 8:17"> 你也要取那赎罪祭的公牛，在殿的指定地点，就是圣所外，把它焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结 43:25–26; 以西结 43:20; 彼得前书 1:19"> “第二日，你要献一只没有残疾的公山羊作赎罪祭；他们要洁净祭坛，像用公牛洁净祭坛一样。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:1"> 你洁净完了以后，要献一头没有残疾的小公牛，和羊群中一只没有残疾的公绵羊。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 2:13; 马可福音 9:49–50; 民数记 18:19"> 你要把它们带到耶和华面前，祭司要把盐撒在它们身上，献给耶和华作燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="利未记 8:33; 出埃及记 29:35–37; 利未记 8:35"> “七日之内，你每天要预备一只公山羊作赎罪祭；也要预备一头小公牛，和羊群中一只没有残疾的公绵羊。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:24; 利未记 8:34; 出埃及记 32:29"> 七日之内，他们要为祭坛赎罪，洁净它；这样，他们就要使它成圣。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 9:1; 以西结 20:40–41; 彼得前书 2:5"> 这些日子满了以后，从第八日起，祭司要在坛上献你们的燔祭和平安祭。那时，我必悦纳你们，’主耶和华说。”</span>
</div>
</div>

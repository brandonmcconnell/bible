<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 37:4; 以西结 34:14; 以西结 37:22"> “人子啊，你要向以色列的众山发预言，说：‘以色列的众山哪，要听耶和华的话。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:13; 以西结 25:3; 以西结 35:10"> 主耶和华如此说：因为仇敌攻击你们说：“啊哈！”又说：“古时的高处归我们为业了！”’</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米书 18:16"> 所以你要发预言，说：‘主耶和华如此说：因为，正因为他们使你们荒凉，从四围吞吃你们，好使你们成为列国余民的产业；你们又被多话之人挂在嘴边，成了众民的恶言；</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 34:28; 申命记 11:11; 以西结 36:6"> 所以，以色列的众山哪，要听主耶和华的话：主耶和华对大山、小山、河沟、山谷、荒凉的废墟，以及被遗弃的城邑，就是那些成为四围列国余民掠物和讥笑的地方，如此说：</span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:8; 以西结 36:3; 诗篇 137:7"> 所以主耶和华如此说：我在我忌邪的烈火中，确实已经发言攻击列国的余民和以东全地；他们满心欢喜，心存轻蔑，把我的地指定归自己为产业，要把它抛出去成为掠物。’</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 123:3–4; 以西结 34:29; 诗篇 74:23"> 所以你要论到以色列地发预言，对大山、小山、河沟、山谷说：‘主耶和华如此说：看哪，我在我的忌邪和烈怒中已经发言，因为你们承受了列国的羞辱。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 20:5; 阿摩司 1:1–15; 以西结 20:15"> 所以主耶和华如此说：我已经起誓：“你们四围的列国必承受自己的羞辱。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 27:6; 希伯来书 10:37; 以西结 34:26–29"> “‘“但你们，以色列的众山啊，你们必发枝条，为我的子民以色列结果子，因为他们快要来了。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 46:11; 何西阿 2:21–23; 以西结 36:34"> 看哪，我是帮助你们的；我必转向你们，你们就要被耕种、被撒种。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 36:33; 耶利米书 33:12; 以西结 36:37"> 我必使你们上面的人增多，就是以色列全家，所有的人都必增多。城邑必有人居住，荒废之处必被重建。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:12; 耶利米书 23:5–8; 耶利米书 31:27"> 我必使你们上面的人和牲畜增多；他们必增多并且繁衍。我必使你们有人居住，像从前一样，并且使你们比起初更好。那时你们就知道我是耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:7; 以西结 36:13; 耶利米书 32:44"> 是的，我必使人在你们上面行走，就是我的子民以色列。他们必拥有你们，你们必作他们的产业；你们必不再使他们丧子。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 13:32"> “‘主耶和华如此说：因为人对你说：“你吞吃人，又使你的国民丧子”；</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 37:25–28; 阿摩司 9:15; 以赛亚书 60:21"> 所以你必不再吞吃人，也不再使你的国民丧子。”这是主耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 34:29; 诗篇 89:50; 以西结 36:6"> “我必不再让你听见列国的羞辱；你也不再承受万民的辱骂，也不再使你的国民绊跌。”这是主耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华的话又临到我说：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 2:7; 民数记 35:33–34; 弥迦书 2:10"> “人子啊，以色列家住在自己的地上时，用他们的道路和行为玷污了那地。他们的道路在我面前，如同妇人在经期中的不洁。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 34:21; 以西结 7:8; 耶利米哀歌 2:4"> 因此，我把我的烈怒倾倒在他们身上，因为他们把血倾倒在那地上，又因他们用偶像玷污了那地。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 39:24; 申命记 28:64; 以西结 5:12"> 我把他们分散在列国中，他们就被驱散到各国。我照他们的道路和行为审判了他们。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 2:24; 以赛亚书 52:5; 耶利米书 33:24"> 他们到了所去的列国那里，就亵渎了我的圣名，因为人论到他们说：‘这些人是耶和华的子民，却离开了祂的地。’</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 48:9; 诗篇 74:18; 以西结 20:9"> 但我顾惜我的圣名，就是以色列家在他们所去的列国中所亵渎的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 106:8; 以西结 36:32; 诗篇 115:1–2"> “所以你要告诉以色列家：‘主耶和华如此说：以色列家啊，我这样做不是为你们的缘故，而是为我的圣名，就是你们在所去的列国中所亵渎的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 20:41; 以赛亚书 5:16; 以西结 39:7"> 我要使我的大名显为圣；这名在列国中被亵渎，就是你们在他们中间所亵渎的。主耶和华说：当我在他们眼前、在你们身上显为圣的时候，列国就知道我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结 37:21; 以西结 34:13; 阿摩司 9:14–15"> “‘“因为我必从列国中取出你们，从各国聚集你们，把你们带回自己的地。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:22; 约翰福音 3:5; 耶利米书 33:8"> 我必用洁净的水洒在你们身上，你们就洁净了；我要洁净你们，使你们脱离一切污秽和一切偶像。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 11:19–20; 诗篇 51:10; 哥林多后书 5:17"> 我也要赐给你们一颗新心，把一个新灵放在你们里面；我要从你们的肉体中除去石心，赐给你们肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多书 3:3–6; 希伯来书 13:21; 哥林多前书 3:16"> 我要把我的圣灵放在你们里面，使你们遵行我的律例；你们必谨守我的典章并实行。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 31:33; 耶利米书 32:38; 以西结 37:27"> 你们必住在我赐给你们列祖的地上。你们要作我的子民，我要作你们的上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 1:7–9; 马太福音 1:21; 何西阿 2:21–23"> 我必拯救你们脱离一切污秽。我必召唤五谷，使它增多，不使饥荒临到你们。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结 34:27; 约珥 2:26; 申命记 29:23–28"> 我必使树上的果子和田里的出产增多，使你们不再在列国中承受饥荒的羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西结 6:9; 以西结 20:43; 尼希米记 9:26–35"> “‘“那时你们必记起自己邪恶的道路和不好的行为；你们必因自己的罪孽和可憎之事，在自己眼中厌恶自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 9:5; 以西结 36:22; 提摩太后书 1:9"> 主耶和华说：我这样做不是为你们的缘故。你们要知道。以色列家啊，要因你们的道路羞愧惭惶。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 58:12; 以西结 36:10; 耶利米书 33:10"> “‘主耶和华如此说：在我洁净你们，使你们脱离一切罪孽的日子，我必使城邑有人居住，荒废之处必被重建。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结 6:14; 耶利米书 25:9–11; 历代志下 36:21"> 那荒凉之地必被耕种，不再在所有过路的人眼前显为荒凉。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 51:3; 约珥 2:3; 耶利米书 33:9"> 他们必说：“这曾经荒凉的地，如今变得像伊甸园；那些荒废、荒凉、毁坏的城邑，现在坚固且有人居住。”</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 24:35; 民数记 23:19; 以西结 17:24"> 那时，你们四围剩下的列国就知道，我耶和华已经重建毁坏之处，栽种荒凉之地。我耶和华已经说了，也必成就。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 5:14; 希伯来书 10:21–22; 以西结 14:3"> “‘主耶和华如此说：此外，我还要让以色列家为这事求问我，好为他们成就：我要使他们的人数增多，多如羊群。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 8:63; 使徒行传 2:5–11; 约翰福音 10:16"> 如同作祭物的羊群，如同耶路撒冷在指定节期的羊群，荒废的城邑也必充满人群如羊群。那时他们就知道我是耶和华。’”</span>
</div>

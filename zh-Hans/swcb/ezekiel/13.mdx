<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 13:17; 耶利米书 37:19; 以西结 22:28"> “人子啊，你要说预言攻击以色列中说预言的先知，对那些凭自己的心说预言的人说：‘你们要听耶和华的话：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 2:14; 耶利米书 23:28–32; 何西阿 9:7"> 主耶和华如此说：“那些愚昧的先知有祸了！他们随从自己的灵，却一无所见。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:20; 弥迦书 2:11; 帖撒罗尼迦后书 2:9–10"> 以色列啊，你的先知好像荒废之处的狐狸。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 22:30; 诗篇 106:23; 以赛亚书 58:12"> 你们没有上去堵住破口，也没有为以色列家筑起城墙，好在耶和华的日子在战场上站立。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 29:8; 以西结 22:28; 耶利米书 28:15"> 他们看见的是虚假，所占卜的是谎言；他们说：‘耶和华说’，其实耶和华并没有差遣他们。他们却使人盼望这话必得应验。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 13:6; 马太福音 24:23–24; 以西结 13:2–3"> 你们说：‘耶和华说’，其实我并没有说；你们所看见的岂不是虚假的异象，所说的岂不是谎言的占卜吗？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结 5:8; 以西结 21:3; 以西结 28:22"> “‘所以主耶和华如此说：“因为你们说虚假的话，看见谎言，所以，看哪，我要与你们为敌，”主耶和华说。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 87:6; 诗篇 69:28; 以西结 20:38"> “我的手必攻击那些看见虚假异象、说谎言占卜的先知。他们不得列在我百姓的议会中，也不得登记在以色列家的册上，更不得进入以色列地。那时你们就知道我是主耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结 22:28; 以西结 13:16; 耶利米书 6:14"> “‘正因为他们诱惑我的百姓，说：“平安”，其实没有平安。有人筑起墙，看哪，他们就用白灰粉饰。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 38:22; 以赛亚书 28:2; 那鸿书 1:7–8"> 你要告诉那些用白灰粉饰的人：这墙必要倒塌。必有暴雨倾盆而下；你们这些大冰雹啊，也必降下；狂风必撕裂它。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 3:13; 耶利米哀歌 2:14–15; 士师记 9:38"> 看哪，墙倒塌的时候，人岂不会对你们说：“你们用来粉饰它的灰在哪里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 30:30; 启示录 16:21; 诗篇 148:8"> “‘所以主耶和华如此说：“我必在烈怒中用狂风撕裂它。我必在怒气中使暴雨倾盆而下，又在烈怒中降下大冰雹，将它毁灭。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 1:6; 耶利米书 14:15; 耶利米书 6:15"> 我必拆毁你们用白灰粉饰的墙，使它倒塌在地，以致根基显露。它必倒塌，你们也必在其中被毁灭。那时你们就知道我是耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:13; 诗篇 62:3; 尼希米记 4:3"> 这样，我必向这墙和那些用白灰粉饰它的人倾尽我的烈怒。我必对你们说：‘墙没有了，粉饰墙的人也没有了——</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 13:10; 耶利米书 6:14; 耶利米书 8:11"> 就是那些论到耶路撒冷说预言、为她看见平安异象的以色列先知；其实没有平安，’”主耶和华说。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 13:2; 列王纪下 22:14; 士师记 4:4"> 你，人子啊，要面向你本国的女子，就是那些凭自己的心说预言的女子，说预言攻击她们，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:14; 以西结 13:20; 提摩太后书 4:3"> 说：“主耶和华如此说：‘那些在众人的肘上缝制魔带，又给各种身量的人作头巾，为要猎取生命的妇女有祸了！你们岂可猎取我百姓的生命，又为自己保全人的生命吗？</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 3:5; 箴言 28:21; 耶利米书 23:17"> 你们为几把大麦、几块饼，在我百姓中亵渎我；你们向我那听信谎言的百姓说谎，杀死不该死的生命，保全不该活的生命。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结 13:18; 提摩太后书 3:8–9; 以西结 13:8–9"> “所以主耶和华如此说：‘看哪，我要攻击你们的魔带，就是你们用来猎取生命、使它们飞起来的魔带；我要把这些魔带从你们的膀臂上撕下，释放那些生命，使它们飞走，就是你们像捕鸟一样诱捕的生命。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 91:3"> 我也要撕裂你们的头巾，救我的百姓脱离你们的手；他们不再在你们手中被诱捕。那时你们就知道我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:14; 耶利米书 14:13–17; 彼得后书 2:18–19"> 因为你们用谎言使义人的心忧伤，而我并没有使他忧伤；又坚固恶人的手，使他不离开自己的恶道，以致不能存活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 13:21; 以西结 12:24; 弥迦书 3:6"> 所以你们必不再看见虚假的异象，也不再行占卜。我必救我的百姓脱离你们的手。那时你们就知道我是耶和华。’”</span>
</div>

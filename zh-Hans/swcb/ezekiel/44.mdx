<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 43:1; 以西结 40:17; 以西结 42:14"> 他又带我回到圣所朝东的外门；那门是关闭的。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 43:2–4; 出埃及记 24:10; 以赛亚书 6:1–5"> 耶和华对我说：“这门必须关闭，不可打开，也不可有人从这里进去；因为耶和华——以色列的上帝已经从这里进去。因此这门必须关闭。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 46:2; 以西结 34:24; 以西结 37:25"> 至于王，他作为王，要坐在这门内，在耶和华面前吃饼。他要从门廊的路进去，也要从同一条路出去。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结 1:28; 启示录 1:17; 以西结 3:23"> 他又带我从北门来到殿前；我观看，看哪，耶和华的荣耀充满了耶和华的殿；我就俯伏在地。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结 40:4; 以西结 43:10–11; 申命记 12:32"> 耶和华对我说：“人子啊，凡我告诉你有关耶和华殿的一切条例和一切律法，你都要用心留意，亲眼观看，亲耳聆听；又要用心留意殿的入口，以及圣所的一切出口。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 3:9; 以西结 45:9; 彼得前书 4:3"> 你要告诉那悖逆的，就是以色列家：‘主耶和华如此说：“以色列家啊，你们这一切可憎之事够了！</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 22:25; 耶利米书 9:26; 以西结 44:9"> 你们把外族人，就是心未受割礼、肉体也未受割礼的人，带进我的圣所，玷污它，就是我的殿；你们献上我的食物，就是脂肪和血的时候，他们违背了我的约，使你们一切可憎之事更加增多。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 44:14; 民数记 18:3–5; 以西结 40:45–46"> 你们没有尽看守我圣物的职责，却为自己在我的圣所中设立人来尽我的职责。”</span>
<span className="v" id="v9" data-v="9" data-xref="约珥 3:17; 以西结 44:7; 撒迦利亚书 14:21"> 主耶和华说：“凡在以色列人中的外族人，心未受割礼、肉体也未受割礼的，都不可进入我的圣所。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结 22:26; 以西结 48:11; 列王纪下 23:8–9"> “‘“至于那些利未人，当以色列走迷的时候，他们远离我，随从自己的偶像，从我面前走迷，他们必担当自己的罪孽。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 16:9; 历代志下 29:34; 历代志下 30:17"> 然而他们要在我的圣所中作服事的人，看守殿门，在殿中服事。他们要为百姓宰杀燔祭牲和祭牲，并站在百姓面前服事他们。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:10–16; 诗篇 106:26; 以西结 14:3–4"> 因为他们在百姓的偶像面前服事他们，成了以色列家陷入罪孽的绊脚石，所以我已经举手起誓要攻击他们，”主耶和华说，“他们必担当自己的罪孽。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 18:3; 列王纪下 23:9; 以西结 16:61"> 他们不可亲近我，担任祭司来事奉我，也不可亲近我的任何圣物，就是至圣之物；他们却要担当自己的羞辱和他们所行的可憎之事。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 23:28–32; 民数记 18:4"> 然而我要使他们看守殿的职责，办理殿中一切服事和其中一切要做的事。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 10:8; 以西结 48:11; 以西结 44:7"> “‘“但那些利未人的祭司，就是撒督的子孙，当以色列人从我面前走迷的时候，仍然尽看守我圣所的职责，他们必亲近我，事奉我。他们要站在我面前，把脂肪和血献给我，”主耶和华说。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 41:22; 玛拉基书 1:12; 民数记 18:7–8"> “他们要进入我的圣所，亲近我的桌前，事奉我，并且遵守我的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 19:8; 出埃及记 28:43; 出埃及记 39:27–29"> “‘“他们进入内院各门的时候，必须穿细麻衣；他们在内院各门和里面服事的时候，不可有羊毛衣服穿在身上。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 39:28; 哥林多前书 11:4–10; 以赛亚书 3:20"> 他们头上要戴细麻布裹头巾，腰间要穿细麻布裤子；不可穿任何使身体出汗的衣物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 46:20; 利未记 6:27; 利未记 6:10–11"> 他们出去到外院，就是到百姓所在的外院时，必须脱下他们服事时所穿的衣服，放在圣屋里；他们要穿上别的衣服，免得用他们的衣服使百姓分别为圣。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 11:14; 民数记 6:5; 利未记 21:5–24"> “‘“他们不可剃头，也不可任由头发长长；只可修剪头发。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 10:9; 提多书 1:7–8; 提摩太前书 5:23"> 祭司进入内院的时候，谁都不可喝酒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 21:7; 利未记 21:13–14; 提摩太前书 3:2"> 他们不可娶寡妇或被休的妇人为妻；只可娶以色列家后裔中的处女，或娶祭司遗下的寡妇。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 22:26; 利未记 10:10–11; 提摩太后书 2:24–25"> 他们要教导我的子民分辨圣与俗，使他们知道不洁与洁净的区别。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="历代志上 23:4; 以西结 22:26; 历代志下 19:8–10"> “‘“在争讼中，他们要站出来审判；要按我的条例审判。他们在我一切所定的节期中，要遵守我的律法和律例；也要使我的安息日为圣。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 5:16; 利未记 22:4; 马太福音 8:21–22"> “‘“他们不可到死人那里，使自己沾染不洁；但为了父亲、母亲、儿子、女儿、兄弟，或未嫁的姐妹，他们可以沾染不洁。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:13–14; 民数记 19:11–14; 民数记 6:10–21"> 他洁净以后，要为他计算七天。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 6:9–11; 以西结 44:17; 利未记 4:3–35"> 到他进入圣所、进入内院，在圣所中服事的那一天，他要献上自己的赎罪祭，”主耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 13:33; 民数记 18:20; 申命记 18:1–2"> “‘他们必有产业：我就是他们的产业；你们不可在以色列中给他们产业。我就是他们的产业。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 18:14; 利未记 27:21; 利未记 27:28"> 他们要吃素祭、赎罪祭和赎愆祭；以色列中一切永献之物都要归他们。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 10:35–37; 历代志下 31:10; 申命记 18:4"> 各样初熟之物中最先的，以及你们一切供物中的各样供物，都要归给祭司。你们也要把初熟的面团给祭司，使祝福临到你们的家。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 22:8; 出埃及记 22:31; 申命记 14:21"> 无论是鸟还是兽，凡自死的或被撕裂的，祭司都不可吃。</span>
</div>

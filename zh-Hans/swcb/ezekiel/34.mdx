<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 23:1; 耶利米书 3:15; 以赛亚书 40:11"> “人子啊，你要发预言攻击以色列的牧人。你要发预言，对他们，就是对那些牧人说：‘主耶和华如此说：“以色列的牧人有祸了，他们只顾喂养自己！牧人岂不应当喂养羊群吗？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 11:16; 耶利米书 2:30; 以西结 33:25–26"> 你们吃脂油，穿羊毛，宰杀肥壮的，却不喂养羊群。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 18:12–13; 马太福音 9:36; 以西结 34:16"> 有病的，你们没有使它强壮；患病的，你们没有医治；受伤的，你们没有包扎；被赶散的，你们没有领回；失丧的，你们没有寻找；反倒用强暴和严酷辖制它们。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:36; 历代志下 18:16; 耶利米书 23:2"> 它们四散，是因为没有牧人；它们成了田野一切走兽的食物，就四散了。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 142:4; 彼得前书 2:25; 约翰福音 10:16"> 我的羊在众山间、各高冈上流荡。是的，我的羊散在全地表面；没有人搜寻，也没有人寻找。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 22:2–3; 弥迦书 3:8–9; 诗篇 82:1–7"> “‘所以，你们这些牧人啊，要听耶和华的话：</span>
<span className="v" id="v8" data-v="8" data-xref="彼得后书 2:13; 使徒行传 20:33; 以西结 34:5–6"> 主耶和华说：“我指着我的永生起誓，因为我的羊成了掠物，我的羊因没有牧人成了田野一切走兽的食物；我的牧人没有寻找我的羊，却只顾喂养自己，不喂养我的羊，</span>
<span className="v" id="v9" data-v="9"> 所以，你们这些牧人啊，要听耶和华的话！”</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 34:2; 撒迦利亚书 10:3; 以西结 13:8"> 主耶和华如此说：“看哪，我必与这些牧人为敌；我必向他们追讨我的羊，使他们不再喂养羊群。牧人也不再喂养自己；我必救我的羊脱离他们的口，使羊不再作他们的食物。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:16; 路加福音 19:10; 耶利米书 23:3"> “‘因为主耶和华如此说：“看哪，我自己，我必亲自搜寻我的羊，寻找它们。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:11; 约翰福音 10:11–12; 路加福音 19:10"> 牧人在他的羊四散的日子，在四散的羊中间怎样寻找他的羊群，我也必照样寻找我的羊。在密云幽暗的日子，它们被分散到各处，我必从那里救出它们。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 28:25–26; 以西结 11:17; 以赛亚书 11:11–16"> 我必把它们从万民中领出来，从列国中聚集它们，带它们进入自己的土地；我要在以色列的山上，在溪水旁，在境内一切有人居住的地方喂养它们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:9; 耶利米书 31:25; 诗篇 31:8–10"> 我要用美好的草场喂养它们；它们的羊圈必在以色列高处的山上。它们要在那里躺卧在美好的羊圈中，在以色列山上肥美的草场吃草。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:15; 诗篇 23:1–2; 约翰福音 21:15"> 我自己必作我羊的牧人，使它们躺卧。”主耶和华说。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西结 34:4; 以西结 34:11"> “失丧的，我必寻找；被赶散的，我必领回；受伤的，我必包扎；患病的，我必使它强壮；但肥壮的和强健的，我必灭绝。我要按公义喂养它们。”’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 34:20–22; 马太福音 25:32–33; 撒迦利亚书 10:3"> “至于你们，我的羊群啊，主耶和华如此说：‘看哪，我要在羊与羊之间，在公绵羊与公山羊之间施行审判。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 23:13; 路加福音 11:52; 民数记 16:13"> 你们在美好的草场上吃草，难道还算小事吗？竟还要用脚践踏所剩的草场？你们喝了清水，难道还算小事吗？竟还要用脚搅浑所剩的水？</span>
<span className="v" id="v19" data-v="19"> 至于我的羊，它们吃的是你们用脚践踏过的，喝的是你们用脚搅浑过的。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:31–46; 以西结 34:10; 诗篇 22:12–16"> “所以主耶和华对它们如此说：‘看哪，我，我必在肥羊和瘦羊之间施行审判。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 11:5; 申命记 33:17; 路加福音 13:14–16"> 因为你们用肋旁和肩膀冲撞，又用角抵触一切有病的，直到把它们驱散到各处，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:2–3; 诗篇 72:12–14; 以西结 34:10"> 所以我必拯救我的羊群，它们不再成为掠物；我也必在羊与羊之间施行审判。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 37:24–25; 耶利米书 30:9; 以赛亚书 40:11"> 我必在它们之上设立一位牧人，他必喂养它们，就是我的仆人大卫。他必喂养它们，作它们的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 31:33; 以西结 36:28; 耶利米书 23:5–6"> 我耶和华必作它们的上帝，我的仆人大卫必在它们中间作首领。我耶和华已经说了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:6–9; 以西结 37:26; 利未记 26:6"> “‘我必与它们立平安的约，使恶兽从地上绝迹。它们必安然住在旷野，睡在树林中。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:12; 以赛亚书 44:3; 利未记 26:4"> 我必使它们和我山四围之地成为祝福。我必使雨水按时降下，必有祝福的雨水。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:8; 利未记 26:4; 利未记 26:13"> 田野的树必结果，土地必出产；它们必在自己的土地上安然居住。我折断它们轭上的杠，救它们脱离那些奴役它们之人的手；那时它们就知道我是耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 46:27; 耶利米书 30:10; 以西结 39:26"> 它们不再作列国的掠物，地上的走兽也不再吞吃它们；它们必安然居住，无人使它们惧怕。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 36:29; 以赛亚书 4:2; 以西结 34:26–27"> 我必为它们兴起一片有名的栽种之地；它们在这地上不再因饥荒被吞灭，也不再承受列国的羞辱。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结 37:27; 以西结 34:24; 诗篇 46:11"> 它们必知道我耶和华它们的上帝与它们同在，并且它们以色列家是我的子民，这是主耶和华说的。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 100:3; 约翰福音 10:16; 诗篇 78:52"> 你们，我的羊，我草场上的羊，是人；我是你们的上帝。’主耶和华说。”</span>
</div>

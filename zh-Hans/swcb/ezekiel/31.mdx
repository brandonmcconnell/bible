<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结 30:20; 耶利米书 52:5–6; 以西结 1:2"> 第十一年三月初一日，耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 29:19; 以西结 30:10; 以西结 31:18"> “人子啊，你要对埃及王法老和他的众民说：<br /><span className="pl pl-1">‘在你的伟大中，你像谁呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 10:33–34; 但以理 4:10; 但以理 4:20–23"> <span className="pl pl-1">看哪，亚述人曾是黎巴嫩的一棵香柏树，</span><br /><span className="pl pl-2">枝子秀美，</span><br /><span className="pl pl-1">荫影如林，</span><br /><span className="pl pl-2">身量高大；</span><br /><span className="pl pl-2">树梢在密枝之间。</span></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 17:15; 箴言 14:28; 以西结 17:5"> <span className="pl pl-1">众水滋养它，</span><br /><span className="pl pl-2">深渊使它生长。</span><br /><span className="pl pl-1">深渊的江河环绕它栽植之处流动，</span><br /><span className="pl pl-2">又发出水道，流向田野所有的树。</span></span>
<span className="v" id="v5" data-v="5" data-xref="但以理 4:11; 以西结 17:5; 诗篇 1:3"> <span className="pl pl-1">因此，它的身量高过田野所有的树；</span><br /><span className="pl pl-2">它的枝条增多，</span><br /><span className="pl pl-1">它因众水充足，展开枝条时，</span><br /><span className="pl pl-2">枝子就长长。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以西结 17:23; 马太福音 13:32; 但以理 4:12"> <span className="pl pl-1">天空所有的飞鸟都在它的枝条中筑巢；</span><br /><span className="pl pl-2">田野所有的走兽都在它的枝子下生产幼崽；</span><br /><span className="pl pl-2">一切大国都住在它的荫下。</span></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">它因伟大而美丽，</span><br /><span className="pl pl-2">因枝子长大而美丽；</span><br /><span className="pl pl-2">因为它的根靠近众水。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西结 28:13; 创世记 13:10; 以赛亚书 51:3"> <span className="pl pl-1">上帝园中的香柏树不能遮掩它；</span><br /><span className="pl pl-2">柏树的枝条不如它；</span><br /><span className="pl pl-1">松树的枝子也不如它；</span><br /><span className="pl pl-2">上帝园中没有一棵树在美丽上能与它相比。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以西结 28:13; 但以理 2:37–38; 创世记 13:10"> <span className="pl pl-1">我使它因枝条繁多而美丽，</span><br /><span className="pl pl-2">以致上帝园中</span><br /><span className="pl pl-2">伊甸所有的树都嫉妒它。’</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结 28:17; 但以理 5:20; 历代志下 32:25"> “因此，主耶和华如此说：‘因为他身量高大，树梢伸入密枝之间，又因他的高大而心里骄傲，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 32:11–12; 那鸿书 3:18; 但以理 5:18–19"> 我必把他交在列国中大能者的手中；那人必定处置他。我因他的邪恶已经把他赶出去。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 28:7; 以西结 35:8; 以西结 30:11"> 外族人，就是列国中的暴虐者，已经砍下他，丢弃他。他的枝子落在山岭和一切谷中；他的枝条折断，散在全地所有的水道旁。地上万民都离开他的荫，下去丢弃他。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 32:4; 以西结 29:5; 以赛亚书 18:6"> 天空所有的飞鸟都要栖息在他的废墟上，田野所有的走兽都要在他的枝条上，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 63:9–10; 尼希米记 13:18; 彼得后书 2:6"> 为要使水边所有的树都不因自己的身量高大而自高，也不把树梢伸入密枝之间；他们中强壮的，就是一切喝水的，也不凭自己的高大站立；因为他们全都被交给死亡，到地的低处，在世人中间，与那些下坑的人同在。’</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 3:4; 那鸿书 2:8–10; 启示录 18:9–11"> “主耶和华说：‘他下到阴间<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>的日子，我使人哀悼。我为他遮盖深渊，拦阻深渊的江河；众水都被止住。我使黎巴嫩为他哀伤，田野所有的树都因他衰残。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 14:15; 以赛亚书 14:8; 以西结 26:15"> 我把他扔下阴间<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup>，与下坑的人同在；在他倾倒的响声中，我使列国震动。伊甸所有的树，黎巴嫩中精选和最好的树，一切喝水的树，都在地的低处得了安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:17; 以西结 31:6; 以西结 31:3"> 他们也同他下到阴间，到那些被刀杀的人那里；就是那些曾作他膀臂、在列国中住在他荫下的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结 32:19; 以西结 32:21; 以西结 28:10"> “‘在荣耀和伟大上，你在伊甸的树中究竟像谁呢？然而你必与伊甸的树一同被带下去，到地的低处。你必躺在未受割礼的人中间，与那些被刀杀的人同在。<br />“‘这就是法老和他的众民。’主耶和华说。”</span>
</div>

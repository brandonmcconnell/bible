<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 33:21; 以西结 1:2–3; 以西结 3:14"> 我们被掳第二十五年，年初，月之初十日，就是城被攻破以后第十四年，正在那一天，耶和华的手按在我身上，祂把我带到那里。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 1:1; 但以理 7:1; 但以理 7:7"> 在上帝的异象中，祂把我带到以色列地，把我安置在一座极高的山上；山的南边有一座像城一样的建筑。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 47:3; 启示录 11:1; 但以理 10:5–6"> 祂把我带到那里；看哪，有一个人，他的样子好像铜，手里拿着麻绳和量度的竿；他站在门口。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 44:5; 马太福音 10:27; 以西结 2:7–8"> 那人对我说：“人子啊，你要用眼看，用耳听，并把心放在我将要指示你的一切事上；因为你被带到这里来，正是为要让我把这些事指示你。你所看见的一切，都要宣告给以色列家。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结 42:20; 以赛亚书 26:1; 启示录 21:12"> 看哪，殿外四围有一道墙。那人手里有一根量竿，长六肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="普通一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。一掌宽约4.3英寸或11厘米，所以这里所说的长肘约为22.3英寸或57厘米。因此，一根六长肘的量竿约为3码26.6英寸，或约3.42米长。">a</a></sup>，每肘是一肘加一掌宽。他量那建筑的厚度，是一竿；高度也是一竿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结 43:1; 以西结 8:16; 以西结 11:1"> 他来到朝东的门，登上台阶，量门的门槛，宽一竿；又量另一道门槛，宽一竿。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 40:36; 以西结 40:33; 历代志上 23:28"> 每间卫房长一竿，宽一竿；卫房之间相隔五肘。靠近朝向殿的门廊那里，门的门槛是一竿。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 他又量朝向殿的门廊，是一竿。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 45:19"> 然后他量门廊，是八肘；量门柱，是二肘；门廊朝向殿。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 朝东的门有卫房，这边三间，那边三间；三间都是同一尺寸。这边和那边的门柱也是同一尺寸。</span>
<span className="v" id="v11" data-v="11"> 他量门口的宽度，是十肘；门道的长度，是十三肘；</span>
<span className="v" id="v12" data-v="12"> 卫房前的边界，这边一肘，那边的边界一肘；卫房这边六肘，那边六肘。</span>
<span className="v" id="v13" data-v="13"> 他量门，从这边卫房的屋顶到那边卫房的屋顶，宽二十五肘，门与门相对。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:9; 以赛亚书 62:9; 以西结 42:1"> 他又立出门柱，六十肘；院子延伸到门四围的门柱那里。</span>
<span className="v" id="v15" data-v="15"> 从入口处门的前端到门内廊的前端，共五十肘。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 3:5; 列王纪上 6:4; 以西结 41:26"> 门内四围，卫房和它们的门柱都有封闭的窗户，拱廊也同样有窗户；窗户都朝向里面，四围都有。每根门柱上都有棕树。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 11:2; 以西结 42:1; 历代志上 23:28"> 他带我进外院。看哪，院子四围有房间，也有铺石地；铺石地上有三十间房。</span>
<span className="v" id="v18" data-v="18"> 铺石地在各门旁边，与各门的长度相对应，就是下层铺石地。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 40:23; 以西结 40:27; 以西结 46:1–2"> 然后他量从下门前端到内院外前端的宽度，东面和北面都是一百肘。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结 40:6"> 他量外院朝北的门的长度和宽度。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 40:29–30; 以西结 40:25–26; 以西结 40:10–16"> 它的卫房这边三间，那边三间；它的门柱和拱廊与第一座门的尺寸相同：长五十肘，宽二十五肘。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 40:31; 以西结 40:37; 以西结 40:6"> 它的窗户、拱廊和棕树，都与朝东的门的尺寸相同。人上到那里要经过七级台阶；它的拱廊在台阶前面。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 40:19; 以西结 40:27–28; 出埃及记 38:9–12"> 内院有一座门与这门相对，在北面和东面都是如此。他量从这门到那门，是一百肘。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结 46:9; 以西结 40:6; 以西结 40:20–21"> 他领我往南去；看哪，有一座朝南的门。他按这些尺寸量它的门柱和拱廊。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结 40:33; 以西结 40:16; 以西结 40:21–22"> 门内和拱廊四围都有窗户，像那些窗户一样；长五十肘，宽二十五肘。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 40:22; 以西结 40:16; 以西结 40:6"> 上到那里有七级台阶，它的拱廊在台阶前面。它的门柱上有棕树，这边一棵，那边一棵。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 40:23; 以西结 40:32; 以西结 40:19"> 内院有一座朝南的门。他量朝南从这门到那门，是一百肘。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结 40:35; 以西结 40:32"> 然后他带我从南门进内院。他按这些尺寸量南门；</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 40:25; 以西结 40:16; 以西结 40:7"> 它的卫房、门柱和拱廊，都照这些尺寸。门内和拱廊四围都有窗户。它长五十肘，宽二十五肘。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结 40:21; 以西结 40:36; 以西结 40:25"> 四围有拱廊，长二十五肘，宽五肘。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结 40:26; 以西结 40:34; 以西结 40:22"> 它的拱廊朝向外院；门柱上有棕树。上到那里有八级台阶。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结 40:35; 以西结 40:28–31"> 他带我到内院的东面。他按这些尺寸量那门；</span>
<span className="v" id="v33" data-v="33" data-xref="以西结 40:21; 以西结 40:36; 以西结 40:25"> 它的卫房、门柱和拱廊，都照这些尺寸。门内和拱廊四围都有窗户。它长五十肘，宽二十五肘。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结 40:22; 以西结 40:31; 以西结 40:37"> 它的拱廊朝向外院；这边和那边的门柱上都有棕树。上到那里有八级台阶。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西结 47:2; 以西结 40:32; 以西结 44:4"> 他带我到北门，按这些尺寸量它——</span>
<span className="v" id="v36" data-v="36" data-xref="以西结 40:29; 以西结 40:21; 以西结 40:16"> 就是量它的卫房、门柱和拱廊。门内四围都有窗户。长五十肘，宽二十五肘。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结 40:34; 以西结 40:31"> 它的门柱朝向外院；这边和那边的门柱上都有棕树。上到那里有八级台阶。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志下 4:6; 以西结 40:17; 利未记 8:21"> 在各门的门柱旁有一间带门的房间。他们在那里洗燔祭牲。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结 46:2; 利未记 1:3–17; 利未记 4:2–3"> 在门廊里，这边有两张桌子，那边有两张桌子，可在其上宰杀燔祭牲、赎罪祭牲和赎愆祭牲。</span>
<span className="v" id="v40" data-v="40"> 在外面一侧，就是人上到朝北之门入口的地方，有两张桌子；在另一侧，属于门廊的地方，也有两张桌子。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结 40:39–40"> 门旁这边有四张桌子，那边有四张桌子，共八张桌子；他们在其上宰杀祭牲。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结 40:39; 出埃及记 20:25"> 又有四张凿成石头的桌子，是为燔祭用的，长一肘半，宽一肘半，高一肘。人把宰杀燔祭牲和祭牲所用的器具放在其上。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 1:8; 利未记 1:6; 利未记 8:20"> 四围里面固定着钩子，长一掌宽。祭肉放在桌子上。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="历代志上 6:31–32; 历代志上 16:41–43; 以西结 40:27"> 内门外，在内院里有歌唱者的房间，在北门旁边，朝向南。另有一间在东门旁边，朝向北。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 9:23; 诗篇 134:1; 利未记 8:35"> 他对我说：“这间朝南的房间，是给那些执行殿中职守的祭司用的。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结 44:15; 以西结 43:19; 列王纪上 2:35"> 那间朝北的房间，是给那些执行祭坛职守的祭司用的。他们是撒督的子孙，是利未子孙中亲近耶和华、事奉祂的人。”</span>
<span className="v" id="v47" data-v="47" data-xref="以西结 40:19; 以西结 40:23; 以西结 40:27"> 他量院子，长一百肘，宽一百肘，是正方形。祭坛在殿前。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="历代志下 3:4; 列王纪上 6:3"> 然后他带我到殿的门廊，量门廊的两根门柱，这边五肘，那边五肘。门口的宽度，这边三肘，那边三肘。</span>
<span className="v" id="v49" data-v="49" data-xref="列王纪上 7:15–21; 以西结 40:34; 历代志下 3:17"> 门廊长二十肘，宽十一肘；人经过台阶上到那里。门柱旁有柱子，这边一根，那边一根。</span>
</div>

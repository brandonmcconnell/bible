<span className="v" id="v3" data-v="3" data-xref="以西结 11:3; 以西结 17:2; 以西结 20:49"> 你要向这叛逆之家说一个比喻，对他们说：‘主耶和华如此说：<br /><span className="pl pl-1">“把锅放在火上，</span><br /><span className="pl pl-2">放好，</span><br /><span className="pl pl-2">也把水倒进去。</span></span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:2–3; 以西结 22:18–22; 马太福音 7:2"> <span className="pl pl-1">将肉块聚集在其中，</span><br /><span className="pl pl-2">就是一切上好的肉块：</span><br /><span className="pl pl-2">腿和肩。</span><br /><span className="pl pl-2">要把精选的骨头装满其中。</span></span>

</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="利未记 17:13; 申命记 12:16; 约伯记 16:18"> <span className="pl pl-1">“‘“因为她所流的血在她中间；</span><br /><span className="pl pl-2">她把血倒在光秃的磐石上；</span><br /><span className="pl pl-1">她没有把血倒在地上，</span><br /><span className="pl pl-2">用尘土遮盖。</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 32:21–22; 启示录 18:5–10; 以西结 22:30–31"> <span className="pl pl-1">为要激起烈怒，施行报应，</span><br /><span className="pl pl-2">我把她的血放在光秃的磐石上，</span><br /><span className="pl pl-2">使它不得被遮盖。”</span></span>

<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以西结 24:6; 哈巴谷 2:12; 以赛亚书 31:9"> “‘所以主耶和华如此说：<br /><span className="pl pl-1">“这流人血的城有祸了！</span><br /><span className="pl pl-2">我也要把柴堆加大。</span></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米书 17:3; 耶利米哀歌 1:10"> <span className="pl pl-1">添上木柴，</span><br /><span className="pl pl-2">使火烧旺；</span><br /><span className="pl pl-1">把肉煮透，</span><br /><span className="pl pl-2">使汤熬浓，</span><br /><span className="pl pl-2">让骨头烧焦。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 玛拉基书 4:1; 以赛亚书 1:25"> <span className="pl pl-1">然后把空锅放在炭火上，</span><br /><span className="pl pl-2">使它烧热，</span><br /><span className="pl pl-1">使它的铜烧红，</span><br /><span className="pl pl-2">使其中的污秽熔化，</span><br /><span className="pl pl-2">使它的锈被烧尽。</span></span>

<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 22:24; 以西结 5:13; 西番雅书 3:2"> “‘“你的污秽中有淫行。因为我洁净你，你却没有被洁净，所以你不再从你的污秽中被洁净，直到我向你发的烈怒止息。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:27; 以西结 18:30; 以赛亚书 3:11"> “‘“我耶和华已经说了。这事必成就，我也必实行。我必不退回，必不顾惜，也不后悔。人必按你的道路，照你的行为审判你。”这是主耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的话又临到我，说：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:10; 耶利米书 13:17; 雅歌 7:10"> “人子啊，看哪，我要一击取去你眼所喜爱的；然而你不可悲哀，不可哭泣，眼泪也不可流下。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿 9:4; 撒母耳记下 15:30; 利未记 10:6"> 只可默默叹息，不可为死人举哀。要把头巾束在头上，把鞋穿在脚上；不要遮盖嘴唇，也不要吃吊丧的饼。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 7:29–30"> 于是我早晨向百姓说话，晚上我的妻子就死了。次日早晨，我就照所吩咐的去做。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结 12:9; 以西结 37:18; 玛拉基书 3:7–8"> 百姓问我：“你这样做，对我们有什么意义，难道你不告诉我们吗？”</span>
</div>
<div className="bp">

<span className="v" id="v22" data-v="22" data-xref="诗篇 78:64; 耶利米书 16:4–7; 以西结 24:16–17"> 你们必照我所做的去做：不遮盖嘴唇，也不吃吊丧的饼。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 33:10; 以西结 4:17; 利未记 26:39"> 你们的头巾要在头上，鞋要在脚上；你们不可悲哀，也不可哭泣，却要在自己的罪孽中消亡，彼此哀叹。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 4:3; 以赛亚书 20:3; 路加福音 11:29–30"> 以西结就这样成为你们的预兆；凡他所做的，你们也必照样做。这事临到时，你们就知道我是主耶和华。’”’”</span>
</div>

<span className="v" id="v26" data-v="26" data-xref="约伯记 1:15–19; 以西结 33:21–22; 撒母耳记上 4:12–18"> 在那日，逃脱的人必到你这里来，使你亲耳听见这事。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 33:22; 以西结 29:21; 路加福音 21:15"> 在那日，你的口必向那逃脱的人开了，你要说话，不再哑口。这样，你就要成为他们的预兆；他们就知道我是耶和华。”</span>

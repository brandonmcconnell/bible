<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 4:12; 耶利米书 5:21; 诗篇 78:40"> “人子啊，你住在悖逆之家中间；他们有眼可看，却不看；有耳可听，却不听，因为他们是悖逆之家。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 提摩太后书 2:25; 耶利米书 26:3"> “所以，人子啊，你要预备迁移用的行囊，白天在他们眼前迁移。你要在他们眼前从你的地方迁到另一个地方；他们虽然是悖逆之家，也许还会思想。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4; 以西结 12:12; 列王纪下 25:4"> 你要白天在他们眼前拿出你的行囊，像迁移用的行囊；到了晚上，你要在他们眼前亲自出去，像人被掳离去一样。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 25:4; 耶利米书 39:2–4"> 你要在他们眼前挖通墙，从那里把行囊带出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 4:3; 以赛亚书 8:18; 以西结 24:24"> 你要在他们眼前把行囊扛在肩上，在黑暗中带出去。你要蒙住脸，使你看不见这地，因为我已立你作以色列家的预兆。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结 24:18; 以西结 37:10; 以西结 37:7"> 我就照所吩咐我的去做。白天我拿出我的行囊，像迁移用的行囊；到了晚上，我亲手挖通墙。在黑暗中，我把行囊带出去，在他们眼前扛在肩上。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 早晨，耶和华的话临到我，说：</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 24:19; 以西结 17:12; 以西结 20:49"> “人子啊，以色列家，就是那悖逆之家，岂不是问你：‘你在做什么？’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:25; 以赛亚书 13:1; 耶利米书 24:8"> “你要对他们说：‘主耶和华如此说：“这重担关系到耶路撒冷的首领，以及他们所在之处的以色列全家。”’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 52:15; 耶利米书 15:2; 耶利米书 52:28–30"> “你要说：‘我是你们的预兆。我怎样做，他们也必怎样遭遇；他们必被掳去，进入被掳之地。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:4; 耶利米书 39:4; 以西结 12:6"> “‘他们中间的首领必在黑暗中把行囊扛在肩上出去。他们必挖通墙，从那里把东西带出去。他必蒙住脸，因为他不会亲眼看见这地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:7; 何西阿 7:12; 以西结 17:20"> 我也要把我的网撒在他身上，他必被我的罗网捉住。我要把他带到巴比伦，到迦勒底人的地；然而他必看不见那里，虽然他必死在那里。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 5:2; 列王纪下 25:4–5; 以西结 17:21"> 凡在他四围帮助他的人，以及他所有的队伍，我都要分散到四方；我也要拔刀追赶他们。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 6:7; 以西结 12:16; 以西结 12:20"> “‘我把他们驱散在列国中，分散在各地的时候，他们就知道我是耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:8–9; 以西结 14:22–23; 以西结 6:8–10"> 但我要从他们中间留下少数人，使他们脱离刀剑、饥荒和瘟疫，好叫他们在所到的列国中述说自己一切可憎的事。这样，他们就知道我是耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华的话又临到我，说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 诗篇 80:5; 约伯记 3:24"> “人子啊，你吃饼要战兢，喝水要颤抖恐惧。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 7:14; 以西结 6:6–7; 以西结 6:14"> 你要告诉这地的百姓：‘主耶和华论到耶路撒冷的居民和以色列地如此说：“他们吃饼必恐惧，喝水必惊惶；因为住在其中的一切人都行强暴，她的地和其中所有的都必荒凉。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:7; 以赛亚书 7:23–24; 耶利米书 25:9"> 有人居住的城必变为荒废，这地必成为荒凉。这样，你们就知道我是耶和华。”’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和华的话临到我，说：</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 18:2–3; 以西结 11:3; 以西结 12:27"> “人子啊，在以色列地，你们所说的这句俗语是什么意思呢？你们说：‘日子延长，一切异象都落空。’</span>
<span className="v" id="v23" data-v="23" data-xref="约珥 2:1; 以西结 7:5–7; 西番雅书 1:14"> 所以你要告诉他们：‘主耶和华如此说：“我必使这句俗语止息；在以色列，人必不再用它作俗语。”’但你要告诉他们：‘“日子近了，各异象的应验也近了。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 14:13–16; 以西结 13:23; 撒迦利亚书 13:2–4"> 因为在以色列家中，必不再有任何虚假的异象，也不再有谄媚的占卜。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷 1:5; 以西结 12:28; 以赛亚书 55:11"> 因为我是耶和华。我要说话；我所说的话必定成就，不再拖延。悖逆之家啊，在你们的日子，我必说出这话，也必成就它。”这是主耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华的话又临到我，说：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理 10:14; 以西结 12:22; 彼得后书 3:4"> “人子啊，看哪，以色列家的人说：‘他所见的异象是指许多日子以后的事；他所说的预言是关乎遥远的时代。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结 12:23–25; 马可福音 13:32–37; 帖撒罗尼迦前书 5:2–3"> “所以你要告诉他们：‘主耶和华如此说：“我的话没有一句再被拖延；我所说的话必定成就。”这是主耶和华说的。’”</span>
</div>
</div>

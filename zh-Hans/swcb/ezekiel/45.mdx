<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 48:29; 撒迦利亚书 14:20–21; 民数记 34:13"> “‘“此外，当你们拈阄分地为产业时，要把一份供物献给耶和华，作为地中的圣区。长要二万五千苇，宽要一万苇。它四围所有边界以内都要为圣。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 42:16–20; 以西结 27:28"> 其中要有一块五百乘五百的正方形作圣所，四围有五十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>作它的郊地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 48:10"> 你要从这量出的地中量出长二万五千、宽一万的一块；圣所，就是至圣之处，要在其中。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 43:19; 民数记 16:5; 以西结 40:45"> 这是地中的圣区；要归给祭司，就是圣所的服事者，那些亲近耶和华、事奉祂的人。这地要作他们建造房屋的地方，也要作圣所的圣地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 48:13; 尼希米记 10:38–39; 以西结 48:20"> 另有长二万五千肘、宽一万肘的地，要归给利未人，就是殿的服事者，作为他们自己的产业，供二十间房屋之用。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结 48:15–18; 以西结 48:30–35"> “‘“你们要划定城的产业，宽五千肘、长二万五千肘，与圣区的供地相邻。这地要归以色列全家。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结 48:21; 以西结 34:24; 以西结 46:16–18"> “‘“属于首领的地，要在圣供地和城的产业的两侧，紧挨着圣供地和城的产业，西边向西，东边向东；它的长度要与其中一个分地相等，从西界到东界。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 11:3–5; 以西结 46:18; 以西结 22:27"> 这地要归他作以色列中的产业。我的首领不再欺压我的百姓，而要按以色列家的各支派把地分给他们。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 8:16; 耶利米书 22:3; 以西结 44:6"> “‘主耶和华如此说：“以色列的首领啊，够了！要除去强暴和掠夺，实行公平和公义！不要再侵夺我百姓的产业！”这是主耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:10–11; 阿摩司 8:4–6; 箴言 16:11"> “你们要有公道的天平、公道的伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一伊法约为二十二升，或约三分之二蒲式耳。">b</a></sup>和公道的罢特。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:10"> 伊法和罢特要同一标准量；罢特应为一贺梅珥<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一贺梅珥约为二百二十升，或六蒲式耳。">c</a></sup>的十分之一，伊法也为一贺梅珥的十分之一。它们的量要按贺梅珥而定。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:25"> 一舍客勒<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一舍客勒约为十克，或约零点三五盎司。">d</a></sup>要为二十季拉。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一季拉约为零点五克，或约七点七格令。">e</a></sup>二十舍客勒、二十五舍客勒、十五舍客勒，加起来就是你们的一弥那。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一弥那约为六百克，或一点三美磅。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> “‘“这是你们要献的供物：每一贺梅珥小麦取六分之一伊法，每一贺梅珥大麦也要取六分之一伊法；</span>
<span className="v" id="v14" data-v="14"> 油的定份，按油的罢特计算，是从每歌珥取十分之一罢特；一歌珥是十罢特，也就是一贺梅珥（因为十罢特是一贺梅珥）。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一歌珥的容量与一贺梅珥相同，约为二百一十一升、五十五点九加仑，或六蒲式耳。一罢特约为二十一点一升、五点五九加仑，或二点四配克。">g</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 6:30; 歌罗西书 1:21"> 又要从以色列水草丰美的牧场中，每二百只羊取一只羊羔，用作素祭、燔祭和平安祭，为他们赎罪。”这是主耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:14–15; 以赛亚书 16:1"> “这地的全体百姓都要把这供物交给以色列的首领。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 46:4–12; 历代志下 31:3; 以赛亚书 66:23"> 首领的职责是在以色列家一切指定的节期、月朔、安息日，以及各节期中，供献燔祭、素祭和奠祭。他要预备赎罪祭、素祭、燔祭和平安祭，为以色列家赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 16:16; 出埃及记 12:2; 以西结 43:22"> “‘主耶和华如此说：“正月初一日，你要取一头无残疾的公牛犊，洁净圣所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 43:20; 以西结 43:14; 利未记 16:18–20"> 祭司要取些赎罪祭牲的血，抹在殿的门柱上、祭坛台座的四角上，以及内院门的门柱上。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 19:12; 利未记 4:27–35; 以西结 45:15"> 本月初七日，也要为所有误犯的人和愚蒙的人这样做；你们要这样为殿赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 23:5–8; 哥林多前书 5:7–8; 民数记 9:2–14"> “‘“正月十四日，你们要守逾越节，为期七日的节；要吃无酵饼。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:14; 哥林多后书 5:21; 马太福音 20:28"> 那日，首领要为自己和这地的全体百姓预备一头公牛作赎罪祭。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 42:8; 利未记 23:8; 民数记 23:1–2"> 节期的七日中，他要每日预备七头无残疾的公牛和七只无残疾的公绵羊，作为献给耶和华的燔祭，一连七日；又要每日预备一只公山羊作赎罪祭。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 46:5–7; 民数记 28:12–15"> 他要预备素祭：每头公牛配一伊法<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一伊法约为二十二升，或约三分之二蒲式耳。">h</a></sup>，每只公绵羊配一伊法，每一伊法配一欣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一欣约为六点五升，或一点七加仑。">i</a></sup>油。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="利未记 23:33–43; 民数记 29:12–38; 历代志下 5:3"> “‘“七月十五日，在节期中，他要照同样的方式行七日。他要照样预备赎罪祭、燔祭、素祭和油。”</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 20:46; 以西结 4:7; 以西结 25:2"> “人子啊，你要面向耶路撒冷，向圣所宣讲，向以色列地说预言。</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 9:22; 耶利米书 21:13; 以西结 5:8"> 你要对以色列地说：‘耶和华如此说：“看哪，我与你为敌，必拔刀出鞘，从你中间剪除义人和恶人。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 20:47; 以西结 7:2; 以西结 6:11–14"> 既然我要从你中间剪除义人和恶人，所以我的刀必出鞘，攻击从南到北一切有血肉的。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 21:30; 那鸿书 1:9; 撒母耳记上 3:12"> 一切有血肉的都必知道，是我耶和华拔刀出鞘；这刀必不再归鞘。”’</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 22:4; 以西结 6:11; 耶利米书 19:10"> “所以，人子啊，你要叹息。你要在他们眼前心碎<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直译：“你大腿的折断”。">a</a></sup>而痛苦地叹息。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 7:17; 以西结 7:26; 以赛亚书 13:7"> 他们问你：‘你为什么叹息？’你就说：‘因为有消息传来；看哪，它来了！人心都要消化，众手都要发软，各人的灵都要昏厥，所有膝盖都要软弱如水。看哪，它来了，必定成就。这是主耶和华说的。’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 耶和华的话临到我，说：</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 34:5–6; 以西结 21:28; 以西结 21:3"> “人子啊，你要说预言，说：‘耶和华如此说：<br /><span className="pl pl-1">“刀剑啊！刀剑啊！</span><br /><span className="pl pl-2">它已经磨快，</span><br /><span className="pl pl-2">也已经擦亮。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 110:5–6; 以西结 20:47; 以西结 21:25–27"> <span className="pl pl-1">它磨快，为要行屠杀；</span><br /><span className="pl pl-2">它擦亮，为要像闪电。</span><br /><span className="pl pl-1">我们岂可欢乐呢？</span><br /><span className="pl pl-2">我儿子的杖定所有树的罪。</span></span>
<span className="v" id="v11" data-v="11" data-xref="以西结 21:19; 耶利米书 25:33; 耶利米书 51:20–23"> <span className="pl pl-1">这刀交给人擦亮，</span><br /><span className="pl pl-2">好被握在手中。</span><br /><span className="pl pl-1">刀剑已经磨快，</span><br /><span className="pl pl-2">是的，已经擦亮，</span><br /><span className="pl pl-2">要交在杀戮者手中。”’</span></span>
<span className="v" id="v12" data-v="12" data-xref="以西结 21:6; 约珥 1:13; 以西结 21:14"> <span className="pl pl-1">人子啊，你要呼喊哀号；</span><br /><span className="pl pl-2">因为这刀临到我的子民，</span><br /><span className="pl pl-2">临到以色列所有的首领。</span><br /><span className="pl pl-1">他们和我的子民一同被交付刀剑；</span><br /><span className="pl pl-2">所以你要拍打大腿。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="以西结 21:10; 哥林多后书 8:2; 以西结 21:25"> “因为有试验。若连那定罪的杖也不再存在，又将如何呢？”这是主耶和华说的。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 24:1; 民数记 24:10; 利未记 26:24"> <span className="pl pl-1">“所以，人子啊，你要说预言，</span><br /><span className="pl pl-2">又要拍手。</span><br /><span className="pl pl-1">要使刀剑加倍，第三次临到，</span><br /><span className="pl pl-2">这是使人受致命伤的刀剑。</span><br /><span className="pl pl-1">这是使那受致命伤的大人物受害的刀剑，</span><br /><span className="pl pl-2">它进入他们的内室。</span></span>
<span className="v" id="v15" data-v="15" data-xref="以西结 21:10; 耶利米书 17:27; 以西结 21:22"> <span className="pl pl-1">我已经把威吓的刀剑立在他们所有城门前，</span><br /><span className="pl pl-2">使他们的心消化，</span><br /><span className="pl pl-2">使他们跌倒的事增多。</span><br /><span className="pl pl-1">啊！这刀被制成像闪电，</span><br /><span className="pl pl-2">为屠杀而指向目标。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以西结 21:20; 以西结 21:4; 以西结 14:17"> <span className="pl pl-1">聚拢吧。</span><br /><span className="pl pl-2">向右去！</span><br /><span className="pl pl-1">摆好阵势吧。</span><br /><span className="pl pl-2">向左去！</span><br /><span className="pl pl-2">你的面无论转向哪里，都去吧。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结 5:13; 以西结 21:14; 撒迦利亚书 6:8"> <span className="pl pl-1">我也要拍手，</span><br /><span className="pl pl-2">并使我的烈怒止息。</span><br /><span className="pl pl-2">我耶和华已经说了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶和华的话又临到我，说：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 4:1–3; 耶利米书 1:10; 以西结 5:1–17"> “人子啊，你也要划定两条路，使巴比伦王的刀剑可以前来。这两条路都要从同一地出来；你要立一个路标，立在通往城的路头。</span>
<span className="v" id="v20" data-v="20" data-xref="阿摩司 1:14; 耶利米书 49:2; 以西结 25:5"> 你要划定一条路，使刀剑来到亚扪人的拉巴；又划定一条路，使刀剑来到犹大，到设防的耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 18:20; 箴言 16:33; 士师记 17:5"> 因为巴比伦王站在岔路口，在两条路的路头，要用占卜。他摇动箭，求问特拉芬<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="特拉芬是家中的偶像，可能与家产继承权有关。">b</a></sup>，察看肝脏。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 4:2; 以西结 26:9; 耶利米书 51:14"> 他右手中得着耶路撒冷的签，要安设攻城槌，张口施行杀戮，扬声呐喊，把攻城槌安设在城门前，筑起土垒，建造攻城堡垒。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 5:15; 以西结 21:24; 以西结 29:16"> 在他们眼中，这必像虚假的占卜，就是那些曾向他们起誓的人；但他使罪孽被记起，好叫他们被捉拿。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="何西阿 4:2; 弥迦书 3:10–12; 耶利米书 3:2"> “所以主耶和华如此说：‘因为你们使自己的罪孽被记起，你们的过犯显露出来，以致你们所行的一切都显出你们的罪；因为你们被记起，就必被人手捉拿。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结 35:5; 以西结 21:29; 以西结 17:19"> “‘你这受致命伤的恶人，以色列的首领啊，你的日子到了，在终局罪孽的时候到了。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 17:24; 诗篇 75:7; 耶利米书 13:18"> 主耶和华如此说：“要摘下头巾，取下冠冕。这必不再照从前那样。要高举卑微的，降卑高大的。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 5:2; 耶利米书 23:5–6; 撒迦利亚书 9:9"> 我要倾覆，倾覆，再倾覆它。这也必不再存在，直到那有权得着它的人来到；我就把它赐给他。”’</span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="以西结 21:20; 以西结 21:9–10; 西番雅书 2:8–10"> “人子啊，你要说预言，说：‘主耶和华论到亚扪人和他们的羞辱如此说：<br /><span className="pl pl-1">“刀剑啊！刀剑已经拔出！</span><br /><span className="pl pl-2">它为屠杀已经擦亮，</span><br /><span className="pl pl-1">要使它吞灭，</span><br /><span className="pl pl-2">好像闪电；</span></span>
<span className="v" id="v29" data-v="29" data-xref="以西结 21:25; 以西结 22:28; 诗篇 37:13"> <span className="pl pl-1">他们为你见虚假的异象，</span><br /><span className="pl pl-2">为你占卜谎言，</span><br /><span className="pl pl-1">要把你放在受致命伤的恶人颈项上；</span><br /><span className="pl pl-2">他们的日子到了，在终局罪孽的时候到了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="以西结 16:38; 创世记 15:14; 耶利米书 47:6–7"> <span className="pl pl-1">要使刀剑归回鞘中。</span><br /><span className="pl pl-2">在你受造之处，</span><br /><span className="pl pl-2">在你出生之地，我必审判你。</span></span>
<span className="v" id="v31" data-v="31" data-xref="那鸿书 1:6; 耶利米书 6:22–23; 以西结 14:19"> <span className="pl pl-1">我必将我的愤怒倾倒在你身上，</span><br /><span className="pl pl-2">用我烈怒的火吹向你。</span><br /><span className="pl pl-1">我必把你交在野蛮人手中，</span><br /><span className="pl pl-2">交在善于毁灭的人手中。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以西结 25:10; 玛拉基书 4:1; 以西结 20:47–48"> <span className="pl pl-1">你必成为火中的柴。</span><br /><span className="pl pl-2">你的血必流在这地中间。</span><br /><span className="pl pl-1">你必不再被记念；</span><br /><span className="pl pl-2">因为我耶和华已经说了。”’”</span></span>
</div>

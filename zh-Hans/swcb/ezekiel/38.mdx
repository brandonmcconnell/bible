<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 39:1; 以西结 27:13; 以西结 38:3"> “人子啊，你要面向玛各地的歌革，就是罗施、米设、土巴的王子，发预言攻击他，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 13:8; 以西结 39:1–10; 以西结 29:3"> 说：‘主耶和华如此说：“看哪，罗施、米设、土巴的王子歌革啊，我与你为敌。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 29:4; 但以理 11:40; 以西结 38:15"> 我必使你转回，把钩子放在你的腮颊上，把你和你的全军都带出来；你们有马和骑兵，全都全副披挂，是一大队人马，拿着大小盾牌，全都手持刀剑；</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 27:10; 创世记 10:6; 以西结 30:5"> 波斯、古实和弗与他们同在，全都拿着盾牌，戴着头盔；</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 27:14; 创世记 10:2–3; 历代志上 1:5–6"> 歌篾和他的全部军队，北方极处的陀迦玛家和他的全部军队，还有许多民族与你同在。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 25:8; 约珥 3:9–12; 以赛亚书 37:22"> “‘“你要预备，是的，要预备好；你和聚集到你那里的一切队伍都要预备好；你要作他们的护卫。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 38:16; 以赛亚书 24:22; 以西结 38:11–12"> 许多日以后，你必被召集。到了末后的年日，你必来到那从刀剑中被恢复的地；那民从许多民族中被聚集，来到以色列的山上；这些山素来荒废，但这民已从万民中被带出来，他们全都安然居住。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 28:2; 耶利米书 4:13; 约珥 2:2"> 你必上来，如暴风临到；你和你的全部军队，以及与你同来的许多民族，必像遮盖大地的云。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 36:4; 弥迦书 2:1; 诗篇 83:3–4"> “‘主耶和华如此说：“到那日，你心里必起意念，筹划恶谋。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 2:4–5; 箴言 3:29–30; 耶利米书 49:31–32"> 你必说：‘我要上到那无城墙村庄之地；我要到那些安息、安然居住的人那里去，他们全都住在没有城墙、没有门闩和城门的地方，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 10:6; 以西结 38:8; 以西结 29:19"> 为要夺取掠物，抢夺财物；要伸手攻击那些曾荒废而如今有人居住的地方，攻击那从列国中被聚集、得了牲畜和财物、住在大地中央的民。’</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 27:15; 以西结 27:22–23; 以西结 32:2"> 示巴、底但、他施的商人和它所有的少壮狮子都必问你：‘你来是要夺取掠物吗？你聚集你的队伍，是要抢夺财物，带走金银，夺走牲畜和财物，夺取大量掠物吗？’”’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结 38:8; 撒迦利亚书 2:5; 耶利米书 23:6"> “所以，人子啊，你要发预言，对歌革说：‘主耶和华如此说：“到那日，我的子民以色列安然居住的时候，难道你不会知道吗？</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 39:2; 以西结 38:6; 启示录 20:8"> 你必从你的地方，从北方极处而来；你和与你同来的许多民族，全都骑着马，是一大队人马，是强大的军队。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 39:21; 以西结 38:23; 何西阿 3:5"> 你必上来攻击我的子民以色列，像云遮盖大地。到末后的日子，我必带你来攻击我的地，好使列国在他们眼前看见我在你身上显为圣，歌革啊，他们就认识我。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理 11:40–45; 以赛亚书 63:1–6; 约珥 3:9–14"> “‘主耶和华如此说：“你岂不是我从前借我的仆人以色列的众先知所说的那人吗？他们在那些日子多年预言，说我必带你来攻击他们。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 36:5–6; 希伯来书 12:29; 诗篇 89:46"> 到那日，歌革来攻击以色列地的时候，”主耶和华说，“我的怒气必涌上我的鼻孔。</span>
<span className="v" id="v19" data-v="19" data-xref="哈该书 2:6–7; 启示录 11:13; 启示录 16:20"> 我在我的忌邪中，在我烈怒的火中已经说了：那日，在以色列地必有大震动，</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿 4:3; 那鸿书 1:4–6; 启示录 6:12–13"> 以致海里的鱼、天空的鸟、田野的走兽、地上一切爬行的爬物，以及地面上的所有人，都必在我面前震动。山岭必被推倒，陡坡必崩塌，一切城墙都必倒在地上。</span>
<span className="v" id="v21" data-v="21" data-xref="哈该书 2:22; 士师记 7:22; 以西结 14:17"> 我必在我的各山召刀剑来攻击他，”主耶和华说，“各人的刀剑必攻击自己的弟兄。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 66:16; 诗篇 11:6; 启示录 16:21"> 我必用瘟疫和流血审判他。我必将暴雨、大冰雹、火与硫磺降在他和他的军队，以及与他同来的许多民族身上。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 9:16; 启示录 19:1–6; 以西结 38:16"> 我必显为大，显为圣，并要在许多列国眼前使人认识我。这样，他们就知道我是耶和华。”’</span>
</div>

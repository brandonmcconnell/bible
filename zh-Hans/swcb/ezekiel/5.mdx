<span className="v" id="v1" data-v="1" data-xref="以赛亚书 7:20; 以西结 44:20; 利未记 21:5"> “你，人子啊，要拿一把锋利的刀，当作剃头匠的剃刀，用来剃过你的头和你的胡须；然后拿天平把头发称一称，分成几份。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 5:12; 利未记 26:33; 以西结 4:1–8"> 围困的日子满了，你要把三分之一在城中用火焚烧；又取三分之一，在城的四围用刀砍击；再把三分之一散在风中，我必拔刀追赶他们。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 52:16; 耶利米书 40:6; 耶利米书 39:10"> 你要从其中取少数，包在你衣服的边襟里。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:4; 耶利米书 41:1–18; 列王纪下 25:25"> 你还要从这些里面再取一些，扔在火中焚烧。火必从其中出来，烧到以色列全家。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结 4:1; 申命记 4:6; 耶利米书 6:6"> “主耶和华这样说：‘这就是耶路撒冷。我把她安置在列国之中，四围有列邦环绕她。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 11:10; 以西结 16:47–48; 尼希米记 9:16–17"> 她行恶，悖逆我的典章，比列国更甚；悖逆我的律例，比她四围的列邦更甚；因为他们弃绝了我的典章，至于我的律例，他们也没有遵行。’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:10–11; 历代志下 33:9; 列王纪下 21:9–11"> “所以主耶和华这样说：‘因为你们比周围的列国更加悖乱，没有遵行我的律例，也没有谨守我的典章，甚至没有照周围列国的典章去行；</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 15:7; 耶利米书 24:9; 以西结 21:3"> 所以主耶和华这样说：看哪，我，我与你们为敌；我必在列国眼前，在你们中间施行审判。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:21; 但以理 9:12; 阿摩司 3:2"> 因你们一切可憎的事，我必在你们中间行我从未行过、以后也不再行类似的事。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 2:6; 申命记 28:64; 以西结 12:14"> 因此，在你们中间，父亲要吃儿子，儿子也要吃父亲；我必在你们身上施行审判，把你们剩下的全都分散到四方。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 7:20; 以西结 7:9; 以西结 11:18"> 所以，主耶和华说：我指着我的永生起誓，因为你用一切可厌的物和一切可憎的事玷污了我的圣所，所以我也必削减你。我的眼必不顾惜，我也不怜悯。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 5:2; 耶利米书 15:2; 耶利米书 43:10–11"> 你们中间三分之一的人必因瘟疫而死，因饥荒而灭亡；三分之一的人必在你四围倒在刀下；三分之一的人我必分散到四方，并且拔刀追赶他们。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:24; 以西结 36:5–6; 以西结 21:17"> “‘这样，我的怒气就要成就；我向他们发的烈怒也要止息，我就得安慰。我在他们身上成就我的烈怒时，他们就知道，我耶和华是以我的忌邪之心说了话。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结 22:4; 尼希米记 2:17; 诗篇 79:1–4"> “‘并且，我要使你在周围的列国中，在所有经过的人眼前，成为荒凉和羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 25:17; 耶利米书 22:8–9; 列王纪上 9:7"> 当我在怒气、烈怒和烈怒的责备中，在你身上施行审判的时候，你就必成为周围列国的羞辱、讥刺、训诫和惊骇——这是我耶和华说的——</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 4:16; 申命记 32:23–24; 以西结 14:13"> 那时，我要把毁灭人的饥荒恶箭射向他们；这些箭是为毁灭而设，我要发出它们来毁灭你们。我要加增你们的饥荒，折断你们粮食的杖。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 38:22; 以西结 14:21; 利未记 26:22"> 我要使饥荒和恶兽临到你们，它们必使你们丧失儿女；瘟疫和流血的事必经过你中间；我也必使刀剑临到你。这是我耶和华说的。’”</span>
</div>

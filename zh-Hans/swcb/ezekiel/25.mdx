<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 49:1–6; 阿摩司 1:13–15; 以西结 6:2"> “人子啊，你要面向亚扪人，说预言攻击他们。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 36:2; 诗篇 70:2–3; 箴言 17:5"> 你要对亚扪人说：‘你们要听主耶和华的话！主耶和华如此说：“因为我的圣所被亵渎时，你们说：‘啊哈！’以色列地荒凉时，你们也这样说；犹大家被掳时，你们也这样说，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:33; 士师记 6:33; 列王纪上 4:30"> 所以，看哪，我必把你们交给东方人作产业。他们要在你们中间安营，在你们中间建立住处；他们要吃你们的果子，喝你们的奶。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 21:20; 撒母耳记下 12:26; 以赛亚书 17:2"> 我必使拉巴成为骆驼的圈，使亚扪人的地成为羊群歇卧之处。那时你们就知道我是耶和华。”</span>
<span className="v" id="v6" data-v="6" data-xref="西番雅书 2:8; 俄巴底亚 1:12; 西番雅书 2:10"> 因为主耶和华如此说：“因为你们拍手、跺脚，心中满怀轻蔑，向以色列地欢喜，</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅书 1:4; 以西结 25:16; 以西结 6:14"> 所以，看哪，我已经伸手攻击你们，必把你们交给列国掠夺。我必把你们从万民中剪除，使你们从各国灭亡；我必毁灭你们。那时你们就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 15:1–9; 耶利米书 25:21; 耶利米书 48:1–47"> “‘主耶和华如此说：“因为摩押和西珥说：‘看哪，犹大家和列国一样’，</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 48:23; 约书亚记 13:17; 约书亚记 13:19–20"> 所以，看哪，我必打开摩押的边界，从那些城邑，就是从它边境上的城邑，从那地的荣耀之处——伯耶西末、巴力免、基列亭——打开，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 21:32; 诗篇 83:3–6; 以西结 25:4"> 交给东方人，使他们去攻击亚扪人；我也必把他们交给东方人作产业，使亚扪人在列国中不再被记念。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 35:15; 以西结 30:19; 诗篇 149:7"> 我必在摩押施行审判。那时他们就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 49:7–22; 以西结 25:8; 诗篇 137:7"> “‘主耶和华如此说：“因为以东向犹大家报仇，大大有罪，向他们施行报复，”</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 29:8; 玛拉基书 1:3–4; 耶利米书 25:23"> 所以主耶和华如此说：“我必伸手攻击以东，从其中剪除人与牲畜；我必使它荒凉，从提幔直到到底但，他们都必倒在刀下。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 11:14; 创世记 27:29; 希伯来书 10:30–31"> 我必借我子民以色列的手，把我的报复加在以东身上；他们必照我的怒气、照我的烈怒对待以东。那时他们就知道我的报复，”主耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 25:6; 以赛亚书 14:29–31; 以西结 25:12"> “‘主耶和华如此说：“因为非利士人施行报复，心中轻蔑地报仇，要以永久的敌意毁灭人，”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 30:14; 西番雅书 2:4–15; 以西结 25:13"> 所以主耶和华如此说：“看哪，我必伸手攻击非利士人，剪除基利提人，毁灭海岸剩余的人。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 25:11; 以西结 25:14; 以西结 5:15"> 我必以愤怒的责罚，在他们身上施行大报复。当我把我的报复加在他们身上时，他们就知道我是耶和华。”’”</span>
</div>
</div>

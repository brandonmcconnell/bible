<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 3:22; 以西结 1:3; 使徒行传 8:39"> 耶和华的手降在我身上，祂藉着耶和华的灵把我带出去，将我放在谷中；那里满了骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 141:7; 以西结 37:11; 申命记 11:30"> 祂使我从骸骨四围经过；看哪，在谷地上骸骨极多；看哪，都极其枯干。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:25–26; 约翰福音 5:21; 申命记 32:39"> 祂对我说：“人子啊，这些骸骨能活过来吗？”<br />我回答说：“主耶和华啊，祢知道。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 5:25; 约翰福音 5:28–29; 马太福音 21:21"> 祂又对我说：“你要向这些骸骨说预言，对它们说：‘枯干的骸骨啊，要听耶和华的话。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 37:14; 诗篇 104:29–30; 创世记 2:7"> 主耶和华对这些骸骨这样说：“看哪，我必使气息进入你们里面，你们就要活过来。</span>
<span className="v" id="v6" data-v="6" data-xref="约珥 2:27; 以赛亚书 49:23; 约珥 3:17"> 我必给你们加上筋，使肉生在你们身上，用皮遮盖你们，把气息放在你们里面，你们就要活过来。那时你们就知道我是耶和华。”’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:2; 列王纪上 19:11–13; 耶利米书 13:5–7"> 于是我照着所受的命令说预言。我说预言的时候，就有响声；看哪，有震动，骸骨便彼此接合，骨与骨相连。</span>
<span className="v" id="v8" data-v="8"> 我观看，看哪，骸骨上有了筋，长出了肉，又有皮在上面遮盖；只是它们里面还没有气息。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:8; 雅歌 4:16; 诗篇 104:30"> 祂对我说：“你要向风说预言；人子啊，你要说预言，对风说：‘主耶和华这样说：“气息啊，要从四方的风而来，吹在这些被杀的人身上，使他们活过来。”’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="启示录 11:11; 诗篇 104:30; 启示录 20:4–5"> 于是我照着祂吩咐我的说预言，气息就进入他们里面，他们便活过来，站立起来，成为一支极其庞大的军队。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:1; 诗篇 77:7–9; 以西结 39:25"> 祂对我说：“人子啊，这些骸骨就是以色列全家。看哪，他们说：‘我们的骸骨枯干了，我们的盼望失去了；我们完全被剪除了。’</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 26:19; 何西阿 13:14; 帖撒罗尼迦前书 4:16"> 所以你要说预言，对他们说：‘主耶和华这样说：“看哪，我的子民啊，我必打开你们的坟墓，使你们从坟墓中上来；我要带你们进入以色列地。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 37:6; 以西结 16:62; 诗篇 126:2–3"> 我的子民啊，当我打开你们的坟墓，使你们从坟墓中上来时，你们就知道我是耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 36:27; 约珥 2:28–29; 以西结 36:36"> 我必将我的灵放在你们里面，你们就要活过来；然后我必安置你们在自己的土地上。你们就知道我耶和华已经说了，也成就了，”这是耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的话又临到我，说：</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 历代志下 10:19; 历代志下 10:17"> “你，人子啊，要拿一根杖，在上面写：‘归犹大和作他同伴的以色列子孙。’再拿另一根杖，在上面写：‘归约瑟，就是以法莲的杖，并归作他同伴的以色列全家。’</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿 1:11; 耶利米书 50:4; 以赛亚书 11:13"> 然后你要为自己把这两根杖彼此接合成一根杖，使它们在你手中成为一根。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结 24:19; 以西结 12:9; 以西结 17:12"> “你本族的子民对你说：‘你不告诉我们，这些是什么意思吗？’</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 10:6; 以西结 37:16–17; 以弗所书 2:13–14"> 你就对他们说：‘主耶和华这样说：“看哪，我要拿约瑟的杖，就是在以法莲手中的杖，和作他同伴的以色列众支派；我要把它们和犹大的杖并在一起，使它们成为一根杖，它们在我手中必成为一根。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 12:3; 民数记 17:6–9; 何西阿 12:10"> 你所写的那些杖，要在他们眼前拿在你手中。”’</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 36:24; 耶利米书 29:14; 耶利米书 23:8"> 你要对他们说：‘主耶和华这样说：“看哪，我要从以色列子孙所去的列国中取出他们，从四围聚集他们，带他们进入自己的土地。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 37:24; 以西结 34:23–24; 耶利米书 3:18"> 我要使他们在那地，在以色列的山上，成为一个国家；必有一位王作他们众人的王。他们不再是两个国家，也绝不再分为两个王国。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 21:3–4; 以西结 36:28–29; 约翰一书 1:9"> 他们不再因自己的偶像、可憎之物，或任何过犯玷污自己；我却要从他们犯罪的一切居所中拯救他们，并且洁净他们。这样，他们要作我的子民，我要作他们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结 34:23–24; 何西阿 3:5; 以西结 37:25"> “‘“我的仆人大卫必作他们的王；他们众人必有一位牧人。他们也必遵行我的典章，谨守我的律例，并且实行。</span>
<span className="v" id="v25" data-v="25" data-xref="阿摩司 9:15; 以西结 37:24; 以西结 28:25"> 他们必住在我赐给我仆人雅各的地上，就是你们列祖所住过的地。他们和他们的儿女，并他们儿女的儿女，都必永远住在那里；我的仆人大卫必永远作他们的王子。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 55:3; 耶利米书 30:19; 以西结 34:25"> 此外，我要与他们立平安的约；这必是与他们所立的永远之约。我要安置他们，使他们增多，并且把我的圣所设在他们中间，直到永远。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 21:3; 约翰福音 1:14; 以西结 37:23"> 我的帐幕也必在他们那里；我要作他们的上帝，他们要作我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17–19; 以西结 20:12; 出埃及记 31:13"> 当我的圣所永远在他们中间的时候，列国就知道我是使以色列分别为圣的耶和华。”’”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 20:49; 马太福音 13:35; 哥林多前书 13:12"> “人子啊，你要向以色列家出一个谜语，讲一个比喻；</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 8:1; 耶利米书 48:40; 以西结 17:7"> 说：‘主耶和华如此说：“有一只大鹰，翅膀巨大，翎毛长长，羽毛丰满，色彩斑斓，来到黎巴嫩，取了香柏树的树梢。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 43:14; 以赛亚书 47:15; 启示录 18:11–19"> 它掐下嫩枝最顶端的一枝，带到贸易之地，栽在商人的城里。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 44:4; 申命记 8:7–9; 耶利米书 37:1"> “‘“它又取了那地的一些种子，栽在肥沃的土壤里，安置在众水旁，使它像柳树一样。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 17:14; 箴言 16:18–19"> 它生长起来，成了一棵蔓延而低矮的葡萄树；枝子转向那鹰，根也在那鹰下面。于是它成了葡萄树，长出枝条，发出嫩枝。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结 31:4; 以西结 17:15; 列王纪下 24:20"> “‘“又有另一只大鹰，翅膀巨大，羽毛众多。看哪，这葡萄树从栽种它的土地上，把根弯向那鹰，把枝子伸向那鹰，好让那鹰浇灌它。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 17:5–6"> 它本是栽在众水旁的好土里，为要长出枝条，结出果子，成为佳美的葡萄树。”’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结 17:10; 耶利米书 32:5; 以赛亚书 30:1–7"> “你要说：‘主耶和华如此说：“它会兴盛吗？那鹰岂不拔出它的根，剪去它的果子，使它枯干，使它一切新发的嫩叶都枯干吗？不用强壮的膀臂或众多的人，也能把它连根拔起。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿 13:15; 约翰福音 15:6; 马太福音 21:19"> 看哪，它虽已栽种，会兴盛吗？东风一吹到它，岂不完全枯干吗？它必在生长的畦地上枯干。”’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华的话又临到我，说：</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 24:19; 以西结 17:3; 以西结 1:2"> “现在你要对这悖逆之家说：‘你们不知道这些事是什么意思吗？’你要告诉他们：‘看哪，巴比伦王来到耶路撒冷，带走了它的王和首领，把他们带到巴比伦自己那里。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 36:13; 列王纪下 24:15–17; 以西结 17:5"> 他从王室后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“种子”">a</a></sup>中取了一人，与他立约，又使他起誓，并带走那地的强者，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 29:14; 申命记 28:43; 撒母耳记上 2:30"> 好使这国降卑，不能高举自己，却要遵守他的约，得以站立。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:3; 耶利米书 38:18; 以西结 17:7"> 但那人背叛他，派遣使者到埃及去，要他们给他马匹和众多人民。他会兴盛吗？行这些事的人能逃脱吗？他背弃这约，还能逃脱吗？</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结 12:13; 耶利米书 52:11; 以西结 17:18–19"> “‘主耶和华说：我指着我的永生起誓，他必死在立他为王的那王所居住之地，就是在巴比伦中、在那王那里；他藐视了那王的誓言，背弃了那王的约。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 37:7; 以西结 4:2; 以西结 29:6–7"> 当敌人筑起土垒、建造围城台，要剪除许多人时，法老虽有强大的军队和众多群众，也不能在战争中帮助他。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 29:24; 历代志下 30:8; 耶利米哀歌 5:6"> 因为他背弃这约，藐视这誓言；看哪，他已经伸出手来，却仍做了这一切。他必不能逃脱。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 5:11; 耶利米书 5:9; 耶利米书 5:2"> “所以主耶和华如此说：我指着我的永生起誓，我必把他所藐视我的誓言、他所背弃我的约，归到他自己头上。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 12:13; 以西结 32:3; 耶利米书 2:35"> 我必将我的网撒在他身上，他必被我的网罗捉住。我必带他到巴比伦，并要在那里因他对我所犯的罪审判他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:5; 列王纪下 25:11; 以西结 12:14"> 他各队中所有逃跑的人都必倒在刀下，剩下的人必分散到四方之风中。那时你们就知道，是我耶和华说了这话。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:2; 撒迦利亚书 6:12–13; 以赛亚书 11:1–5"> “主耶和华如此说：‘我也要取香柏树高耸树梢的一枝，将它栽上；我要从它嫩枝最顶端掐下一枝嫩枝，栽在高而耸立的山上。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:32; 以西结 31:6; 以赛亚书 2:2"> 我要把它栽在以色列高处的山上；它必长出枝条，结出果子，成为佳美的香柏树。各类飞鸟都要住在它下面，住在它枝子的荫下。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司 9:11; 哥林多前书 1:27–28; 以西结 24:14"> 田野所有的树都必知道，是我耶和华使高树降卑，使矮树升高，使青树枯干，使枯树发旺。<br />“‘我耶和华已经说了，也已经成就了。’”</span>
</div>
</div>

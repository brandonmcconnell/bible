<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 3:14; 以西结 11:24; 以西结 11:13"> 此外，灵将我举起，带我到耶和华殿朝东的东门。看哪，门口有二十五个人；我在他们中间看见押朔的儿子雅撒尼亚和比拿雅的儿子毗拉提，他们都是民中的首领。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:1; 耶利米书 5:5; 诗篇 2:1–2"> 祂对我说：“人子啊，这些人是在这城中图谋罪孽、设恶谋的人；</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 12:27; 以西结 12:22; 以西结 11:7–11"> 他们说：‘建造房屋的时候还没有临近。这城是锅，我们是肉。’</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 20:46–47; 以西结 21:2; 以西结 3:2–15"> 所以你要说预言攻击他们。人子啊，你要说预言。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 17:10; 耶利米书 16:17; 启示录 2:23"> 耶和华的灵降在我身上，祂对我说：“你要说：‘耶和华如此说：“以色列家啊，你们是这样说的；因为你们心里所起的意念，我都知道。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 7:23; 以西结 22:27; 以西结 22:12"> 你们在这城中增多被杀的人，使街道充满被杀的人。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结 24:3–13; 弥迦书 3:2–3; 列王纪下 25:18–22"> “‘所以主耶和华如此说：“你们放在城中的被杀者，他们才是肉，这城才是锅；但你们却要从其中被带出来。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以赛亚书 24:17–18; 约伯记 3:25"> 你们惧怕刀剑；我必使刀剑临到你们。”主耶和华说。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 5:8; 诗篇 106:41; 申命记 28:36"> “我必把你们从城中带出来，交在外族人的手中，并在你们中间施行审判。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 14:25; 耶利米书 52:9–10; 列王纪下 25:19–21"> 你们必倒在刀下。我必在以色列的边境审判你们。那时你们就知道我是耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 11:3; 以西结 11:7–10"> 这城必不作你们的锅，你们也不作其中的肉。我必在以色列的边境审判你们。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 8:10; 以西结 8:16; 以西结 8:14"> 你们就知道我是耶和华，因为你们没有遵行我的律例，也没有实行我的典章，却照着你们周围列国的规例去行。”’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 11:1; 以西结 9:8; 使徒行传 5:5"> 我说预言的时候，比拿雅的儿子毗拉提死了。于是我俯伏在地，大声呼喊说：“哎，主耶和华啊！你要将以色列的余民完全灭绝吗？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华的话临到我，说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 33:24; 以赛亚书 65:5; 约翰福音 16:2"> “人子啊，你的弟兄，就是你的弟兄，你的亲族，以及以色列全家，他们所有人，就是耶路撒冷的居民曾对他们说：‘你们远离耶和华吧；这地已经赐给我们作产业了。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:14; 申命记 30:3–4; 诗篇 90:1"> “所以你要说：‘主耶和华如此说：“虽然我使他们远离，分散在列国中；虽然我把他们分散在各地，我仍要在他们所到的各地暂时作他们的圣所。”’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 28:25; 耶利米书 3:18; 以西结 34:13"> “所以你要说：‘主耶和华如此说：“我必从各民族中聚集你们，从你们被分散到的各地召集你们，并要把以色列地赐给你们。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结 37:23; 以西结 5:11; 以西结 42:7–8"> “‘他们必到那里，除掉其中一切可憎之物和一切可厌恶的事。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 36:26–27; 耶利米书 31:33; 诗篇 51:10"> 我必赐给他们一颗心，也必将新的灵放在他们里面；我必从他们的肉体中除去石心，赐给他们肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 14:11; 诗篇 105:45; 耶利米书 30:22"> 使他们遵行我的律例，谨守我的典章，并且实行。他们要作我的子民，我要作他们的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 9:10; 传道书 11:9; 耶利米书 1:16"> 至于那些心随从自己可憎之物和可厌恶之事的心意而行的人，我必使他们所行的归到他们自己头上。’主耶和华说。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结 10:19; 以西结 1:19–20"> 那时，基路伯展开翅膀，轮子在他们旁边；以色列上帝的荣耀在他们上方。</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 14:4; 以西结 8:4; 以西结 10:4"> 耶和华的荣耀从城中上升，停在城东的那座山上。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 3:12; 以西结 8:3; 以西结 11:1"> 灵将我举起，借着上帝的灵，在异象中带我到迦勒底，到被掳的人那里。<br />于是我所见的异象离我上升去了。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结 3:4; 以西结 3:27; 以西结 3:17"> 我就把耶和华指示我的一切事都告诉被掳的人。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 58:1; 以西结 24:6; 以西结 24:9"> “你，人子啊，你要审判吗？你要审判这流人血的城吗？那就使她知道她一切可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 22:27; 罗马书 2:5; 彼得后书 2:3"> 你要说：‘主耶和华如此说：“这城在自己中间流人血，使自己的时候来到；又为害自己制造偶像，使自己玷污！</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:16; 诗篇 44:13–14; 以西结 22:2"> 你因自己所流的血而有罪，又因自己所造的偶像而被玷污！你使自己的日子临近，到了自己年岁的尽头。因此，我使你成为列国的羞辱，成为各地的讥笑。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 22:2; 耶利米书 15:2–3"> 离你近的和离你远的都要讥笑你；你这恶名昭著、充满骚乱的城啊！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结 22:27; 以赛亚书 1:23; 撒迦利亚书 3:3"> “‘“看哪，以色列的首领各仗自己的权势，在你里面流人血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:16; 出埃及记 22:21–22; 利未记 20:9"> 在你里面，他们轻慢父母。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直译：轻看父亲和母亲。">a</a></sup>在你中间，他们欺压寄居者；在你里面，他们亏负孤儿和寡妇。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 23:38–39; 以西结 22:26; 以西结 20:13"> 你藐视我的圣物，亵渎我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿 4:14; 利未记 19:16; 何西阿 4:10"> 在你里面有搬弄谗言的人，为要流人血；在你里面，他们在山上吃祭物；他们在你中间行淫乱。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 18:19; 利未记 18:7–8; 以西结 18:6"> 在你里面，他们露了父亲的下体；在你里面，他们玷辱在月经污秽中的妇人。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 18:15; 撒母耳记下 13:14; 利未记 20:17"> 有人与邻舍的妻子行可憎之事；又有人以淫乱玷污自己的儿媳；还有人在你里面玷辱自己的姐妹，就是父亲的女儿。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:25; 以西结 23:35; 诗篇 106:21"> 在你里面，他们收受贿赂，为要流人血；你收取利息和重利，又用欺压贪取邻舍的财利，并且忘记了我，”主耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 21:17; 以赛亚书 33:15; 阿摩司 2:6–8"> “‘“看哪，因此我拍手斥责你所得的不义之财，以及你中间所流的血。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 21:7; 以西结 17:24; 以西结 24:14"> 到我对付你的日子，你的心还能忍受吗？你的手还能有力吗？我耶和华已经说了，也必成就。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 1:8; 以西结 22:22; 申命记 4:27"> 我必把你分散在列国中，使你散布在各地；我必除净你里面的污秽。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 6:7; 诗篇 83:18; 以西结 7:24"> 你必在列国眼前因自己而受亵渎；那时你就知道我是耶和华。”’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华的话临到我，说：</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:119; 以赛亚书 1:22; 耶利米书 6:28–30"> “人子啊，以色列家对我成了渣滓；他们全都是炉中的铜、锡、铁、铅；他们是银子的渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:30; 以西结 24:3–6; 弥迦书 4:12"> 因此主耶和华如此说：‘因为你们全都成了渣滓，所以看哪，我必把你们聚集到耶路撒冷中间。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:11–12; 以赛亚书 54:16; 以西结 24:13"> 人怎样把银、铜、铁、铅、锡聚集到炉中，向其中吹火，使它熔化，我也照样在我的怒气和烈怒中聚集你们，把你们放在那里，使你们熔化。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:7; 那鸿书 1:6; 诗篇 50:3"> 是的，我必聚集你们，用我烈怒的火吹在你们身上，你们就必在其中熔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 20:8; 以西结 20:33; 何西阿 5:10"> 银子怎样在炉中熔化，你们也必照样在其中熔化；你们就知道我耶和华已将我的烈怒倾倒在你们身上。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话临到我，说：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–16; 耶利米书 2:30; 历代志下 28:22"> “人子啊，要对她说：‘你是未得洁净、在震怒之日没有雨水降在其上的地。’</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿 6:9; 耶利米书 2:34; 以西结 13:19"> 她的先知在其中结党，像咆哮的狮子撕裂猎物。他们吞吃生命，夺取财宝和贵重之物，使其中寡妇增多。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:10; 以西结 44:23; 以西结 22:8"> 她的祭司蹂躏我的律法，亵渎我的圣物。他们不分别圣的和俗的，也不叫人分辨污秽的和洁净的，又掩眼不顾我的安息日；所以我在他们中间被亵渎。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 22:13; 以赛亚书 1:23; 以西结 22:6"> 她的首领在其中像狼撕裂猎物，流人血，毁灭生命，为要取得不义之财。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结 13:6–7; 以西结 13:10–16; 耶利米书 23:25–32"> 她的先知为他们用白灰粉饰，看见虚假的异象，为他们占卜谎言，说：‘主耶和华如此说’，其实耶和华并没有说话。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 22:7; 出埃及记 23:9; 出埃及记 22:21"> 这地的百姓惯行欺压，施行抢夺；他们确实困扰贫穷和缺乏的人，又无理地欺压寄居者。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:16; 耶利米书 5:1; 诗篇 106:23"> “我在他们中间寻找一个人，他愿意修筑墙垣，并为这地站在我面前的破口中，使我不毁灭它；但我找不到一个。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结 16:43; 以西结 7:8–9; 以西结 9:10"> 因此，我已将我的震怒倾倒在他们身上，用我烈怒的火灭尽他们；我已使他们所行的归到他们头上，”主耶和华说。</span>
</div>

<span className="v" id="v4" data-v="4" data-xref="申命记 8:17–18; 箴言 23:4–5; 箴言 18:11"> <span className="pl pl-1">你凭自己的智慧和聪明为自己得了财富，</span><br /><span className="pl pl-2">又把金银收入你的宝库。</span></span>

<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西结 28:2; 出埃及记 9:17; 雅各书 1:11"> “‘所以主耶和华如此说：<br /><span className="pl pl-1">“因为你把自己的心看作上帝的心，</span></span>

<span className="v" id="v8" data-v="8" data-xref="以西结 27:26–27; 以西结 27:34; 箴言 1:12"> <span className="pl pl-1">他们必使你下到坑中；</span><br /><span className="pl pl-2">你必像被杀的人那样死去，</span><br /><span className="pl pl-2">死在海的中心。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以西结 28:2; 以赛亚书 31:3; 诗篇 82:7"> <span className="pl pl-1">在杀你的人面前，你还会说‘我是上帝’吗？</span><br /><span className="pl pl-2">但在刺伤你的人手中，</span><br /><span className="pl pl-2">你是人，并不是上帝。</span></span>

</div>
<div className="bp poetry">

<span className="v" id="v12" data-v="12" data-xref="以西结 19:1; 以西结 26:17; 哥林多后书 1:22"> “人子啊，你要为推罗王唱起哀歌，对他说：‘主耶和华如此说：<br /><span className="pl pl-1">“你是完美尺度的印记，</span><br /><span className="pl pl-2">满有智慧，</span><br /><span className="pl pl-2">全然美丽。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西结 28:15; 创世记 2:8; 以西结 27:16"> <span className="pl pl-1">你曾在伊甸，</span><br /><span className="pl pl-2">就是上帝的园中。</span><br /><span className="pl pl-1">各样宝石装饰你：</span><br /><span className="pl pl-2">红宝石、黄玉、绿宝石，</span><br /><span className="pl pl-2">橄榄石、红玛瑙、碧玉，</span><br /><span className="pl pl-2">蓝宝石</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“青金石”">a</a></sup><br /><span className="pl pl-2">、绿松石和水苍玉。</span><br /><span className="pl pl-1">金制的铃鼓</span><br /><span className="pl pl-2">和笛子的工艺都在你身上；</span><br /><span className="pl pl-2">在你被造的日子，它们就预备好了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 14:12–15; 出埃及记 30:26; 以西结 28:13"> <span className="pl pl-1">你是受膏、遮护的基路伯；</span><br /><span className="pl pl-2">那时我把你安置在上帝的圣山上。</span><br /><span className="pl pl-2">你曾在火石中间来往行走。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:4; 以西结 28:17–18; 罗马书 7:9"> <span className="pl pl-1">从你被造的日子起，你的道路完全，</span><br /><span className="pl pl-2">直到在你里面发现不义。</span></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 6:9–10; 哈巴谷 2:8; 哈巴谷 2:17"> <span className="pl pl-1">因你贸易繁多，你里面充满了强暴，</span><br /><span className="pl pl-2">你也犯了罪。</span><br /><span className="pl pl-1">因此我把你当作污俗之物，从上帝的山驱逐出去。</span><br /><span className="pl pl-2">遮护的基路伯啊，</span><br /><span className="pl pl-2">我已将你从火石中间毁灭。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结 28:5; 以西结 31:10; 雅各书 4:6"> <span className="pl pl-1">你的心因你的美丽而高傲；</span><br /><span className="pl pl-2">你因自己的光彩败坏了你的智慧。</span><br /><span className="pl pl-1">我已把你摔在地上；</span><br /><span className="pl pl-2">我已把你摆在众王面前，</span><br /><span className="pl pl-2">使他们观看你。</span></span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 4:3; 启示录 18:8; 阿摩司 1:9–10"> <span className="pl pl-1">因你罪孽众多，</span><br /><span className="pl pl-2">因你贸易中的不义，</span><br /><span className="pl pl-2">你亵渎了你的圣所。</span><br /><span className="pl pl-1">因此我使火从你中间发出；</span><br /><span className="pl pl-2">它已经吞灭你。</span><br /><span className="pl pl-1">我使你在地上变为灰烬，</span><br /><span className="pl pl-2">在所有看见你的人眼前。</span></span>

<span className="v" id="v21" data-v="21" data-xref="以西结 6:2; 创世记 10:15; 耶利米书 25:22"> “人子啊，你要面向西顿，发预言攻击它，</span>

</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:37; 以西结 20:41; 以西结 36:28"> “‘主耶和华如此说：“我从以色列家所分散到的万民中把他们聚集起来，并在列国眼前，在他们中间显为圣的时候，他们就要住在自己的土地上，就是我赐给我仆人雅各的地。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 28:24; 以西结 28:22; 耶利米书 32:15"> 他们必安然住在其中；他们必建造房屋，栽种葡萄园，并且安然居住；等我向四围一切轻视他们的人施行审判以后，他们就知道我是耶和华他们的上帝。”’”</span>
</div>

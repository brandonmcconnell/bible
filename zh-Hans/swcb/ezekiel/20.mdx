<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 8:1; 以西结 30:20; 以西结 24:1"> 第七年五月初十，有几个以色列的长老来求问耶和华，坐在我面前。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2"> 耶和华的话临到我，说：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 马太福音 15:8–9; 诗篇 50:15–21"> “人子啊，你要对以色列的长老说话，告诉他们：‘主耶和华如此说：“你们来是要求问我吗？我指着我的永生起誓，”主耶和华说，“我必不被你们求问。”’</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结 22:2; 以西结 23:36; 以西结 14:20"> “人子啊，你要审判他们吗？你要审判他们吗？你要使他们知道他们祖先所行可憎的事。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:6; 以西结 20:15; 出埃及记 3:8"> 你要告诉他们：‘主耶和华如此说：“当我拣选以色列，向雅各家的后裔起誓，在埃及地向他们显明我自己，向他们起誓说：‘我是耶和华你们的上帝’的那日，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:8; 耶利米书 32:22; 以西结 20:15"> 那日我向他们起誓，要把他们从埃及地领出来，进入我为他们察看好的土地，就是流奶与蜜之地，是万地中的荣耀。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 18:3; 以西结 20:8; 利未记 11:44"> 我对他们说：‘你们各人要抛弃自己眼中可憎之物，不可用埃及的偶像玷污自己。我是耶和华你们的上帝。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结 20:7; 以赛亚书 63:10; 以西结 20:21"> “‘“可是他们悖逆我，不肯听从我。他们没有各人抛弃自己眼中可憎之物，也没有离弃埃及的偶像。于是我说，我要将我的烈怒倾倒在他们身上，在埃及地中向他们成就我的怒气。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 39:7; 以西结 20:22; 出埃及记 32:12"> 但我为我名的缘故行事，免得我的名在他们所在的列国眼前被亵渎；我曾在这些列国眼前向他们显明我自己，要把他们从埃及地领出来。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 15:22; 出埃及记 13:17–18; 出埃及记 14:17–22"> 于是我使他们出埃及地，把他们带进旷野。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 10:5; 利未记 18:5; 申命记 4:8"> 我将我的律例赐给他们，把我的典章指示他们；人若遵行，就必因这些而活。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 20:20; 以西结 37:28; 利未记 21:23"> 此外，我也将我的安息日赐给他们，作为我与他们之间的记号，使他们知道我是使他们成圣的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结 20:21; 以西结 20:8; 以赛亚书 56:6"> “‘“可是以色列家在旷野悖逆我。他们不遵行我的律例，厌弃我的典章；人若遵守，就必因这些而活。他们大大亵渎我的安息日。于是我说，我要在旷野将我的烈怒倾倒在他们身上，灭绝他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 20:9; 以西结 36:22–23; 以西结 20:22"> 但我为我名的缘故行事，免得我的名在列国眼前被亵渎；我曾在这些列国眼前把他们领出来。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 95:11; 诗篇 106:26; 希伯来书 3:18"> 此外，我在旷野向他们起誓，不把他们带进我所赐给他们的土地，就是流奶与蜜之地，是万地中的荣耀，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 15:39; 以西结 20:8; 以西结 14:3–4"> 因为他们厌弃我的典章，不遵行我的律例，亵渎我的安息日；他们的心随从自己的偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 11:13; 耶利米书 4:27; 耶利米书 5:18"> 然而我的眼顾惜他们，没有毁灭他们，也没有在旷野把他们灭尽。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 1:2–4; 诗篇 78:6–8; 彼得前书 1:18"> 我在旷野对他们的儿女说：‘不要遵行你们祖先的律例，不要守他们的典章，也不要用他们的偶像玷污自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 36:27; 申命记 5:32–8; 以西结 37:24"> 我是耶和华你们的上帝。你们要遵行我的律例，谨守我的典章，并且实行。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 58:13; 耶利米书 17:22; 出埃及记 31:13–17"> 要以我的安息日为圣；它们要作为我与你们之间的记号，使你们知道我是耶和华你们的上帝。’</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结 20:13; 民数记 21:5; 以西结 20:8"> “‘“可是那些儿女悖逆我。他们不遵行我的律例，也不谨守我的典章去实行；人若遵行，就必因这些而活。他们亵渎我的安息日。于是我说，我要将我的烈怒倾倒在他们身上，在旷野向他们成就我的怒气。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 20:14; 以西结 20:9; 耶利米书 14:21"> 然而我收回我的手，为我名的缘故行事，免得我的名在列国眼前被亵渎；我曾在这些列国眼前把他们领出来。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:33; 申命记 28:64–68; 申命记 32:26–27"> 此外，我在旷野向他们起誓，要把他们分散在列国中，使他们散布在各地，</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 20:16; 以西结 6:9; 阿摩司 2:4"> 因为他们没有实行我的典章，反而厌弃我的律例，亵渎我的安息日，并且他们的眼睛随从他们祖先的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:12; 以赛亚书 66:4; 以西结 20:39"> 此外，我也把不好的律例和不能使他们存活的典章给了他们。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 6:7; 利未记 18:21; 以西结 20:31"> 我借着他们自己的供物玷污他们，就是使一切开母胎的经过火，好使他们荒凉，最终使他们知道我是耶和华。”’</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 2:24; 以西结 2:7; 以西结 3:11"> “所以，人子啊，你要对以色列家说话，告诉他们：‘主耶和华如此说：“此外，你们的祖先在这事上亵渎了我，就是对我行了背信之罪。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结 6:13; 尼希米记 9:22–26; 耶利米书 3:6"> 因为我把他们带进我起誓要赐给他们的土地以后，他们看见每一座高冈和每一棵茂密的树，就在那里献上祭物，在那里呈上他们激怒我的供物；他们也在那里献上馨香之气，在那里浇上奠祭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 16:24–25; 以西结 16:31"> 于是我对他们说：‘你们所去的丘坛是什么意思？’所以那地方名叫巴玛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“巴玛”的意思是“丘坛”。">a</a></sup>，直到今日。”’</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 16:12; 耶利米书 7:26; 士师记 2:19"> “所以你要告诉以色列家：‘主耶和华如此说：“你们要照你们祖先的方式玷污自己吗？你们要随从他们可憎之物行淫吗？</span>
<span className="v" id="v31" data-v="31" data-xref="以西结 20:26; 诗篇 106:37–39; 耶利米书 7:31"> 你们献上供物，使你们的儿子经过火的时候，直到今日还用你们所有的偶像玷污自己吗？以色列家啊，我岂能被你们求问吗？主耶和华说，我指着我的永生起誓，我必不被你们求问！</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结 11:5; 耶利米书 44:17; 诗篇 139:2"> “‘“你们心里所想的，绝不会成就；你们说：‘我们要像列国，像各地的族类一样，去侍奉木头和石头。’</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 21:5; 以西结 8:18; 耶利米书 44:6"> 主耶和华说：“我指着我的永生起誓，我必用大能的手、伸出的膀臂和倾倒出来的烈怒作王治理你们。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结 20:38; 阿摩司 9:9–10; 以西结 34:16"> 我必用大能的手、伸出的膀臂和倾倒出来的烈怒，把你们从万民中领出来，从你们被分散到的各地聚集你们。</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿 2:14; 耶利米书 2:35; 以西结 17:20"> 我必把你们带进万民的旷野，在那里与你们面对面审判。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 10:5–10; 民数记 11:1–35; 以西结 20:13"> 我怎样在埃及地的旷野审判你们的祖先，也必照样审判你们，”主耶和华说。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 33:13; 利未记 27:32; 马太福音 25:32–33"> “我必使你们从杖下经过，带你们进入约的约束。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结 13:9; 阿摩司 9:9–10; 诗篇 95:11"> 我必从你们中间清除悖逆的人和违背我的人；我必把他们从寄居之地领出来，但他们不得进入以色列地。那时你们就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="何西阿 4:17; 以赛亚书 1:13–15; 以西结 43:7"> “‘至于你们，以色列家啊，主耶和华如此说：“你们各人去侍奉自己的偶像吧；以后若仍不听从我，也去吧；但你们不可再用你们的供物和你们的偶像亵渎我的圣名。</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 56:7; 玛拉基书 3:4; 以赛亚书 60:7"> 因为在我的圣山，在以色列高处的山上，”主耶和华说，“在那里，以色列全家，就是他们全体，都要在那地侍奉我。在那里我必悦纳他们；在那里我必要求你们的举祭、你们供物中的初熟之物，以及你们一切圣物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结 28:25; 以西结 11:17; 以西结 38:23"> 当我把你们从万民中领出来，从你们被分散到的各地聚集你们的时候，我必悦纳你们如馨香之气；我必在列国眼前在你们身上显为圣。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结 34:13; 以西结 38:23; 以西结 36:23–24"> 当我把你们带进以色列地，就是我起誓要赐给你们祖先的地方时，你们就知道我是耶和华。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结 6:9; 何西阿 5:15; 耶利米书 31:18"> 在那里，你们必记起自己的行径，以及你们玷污自己的所有作为；你们必因自己所行的一切恶事，在自己眼中厌恶自己。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结 24:24; 诗篇 115:1; 以西结 20:9"> 以色列家啊，当我为我名的缘故待你们，不照你们邪恶的行径，也不照你们败坏的作为待你们的时候，你们就知道我是耶和华，”主耶和华说。’”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45"> 耶和华的话临到我，说：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司 7:16; 以西结 21:2; 耶利米书 13:19"> “人子啊，你要面向南方，向南方宣讲，向南地田野的树林发预言。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米书 21:14; 以赛亚书 24:1–6; 以西结 17:24"> 你要对南方的树林说：‘要听耶和华的话：主耶和华如此说：“看哪，我要在你里面点火，吞灭你里面每一棵青树和每一棵枯树。燃烧的火焰必不熄灭；从南到北，所有的脸面都要被它烧焦。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 40:2–3; 耶利米书 7:20; 申命记 29:24–28"> 凡有血肉的都要看见，是我耶和华点燃了它；它必不熄灭。”’”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="约翰福音 16:25; 使徒行传 17:18; 以西结 17:2"> 于是我说：“啊，主耶和华啊！他们论到我说：‘他岂不是个说比喻的人吗？’”</span>
</div>
</div>

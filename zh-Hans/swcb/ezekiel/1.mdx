<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 3:16; 以西结 11:24; 使徒行传 7:56"> 第三十年四月初五，我在迦巴鲁河边被掳的人中间，天开了，我看见上帝的异象。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译为“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王纪下 24:12–15; 以西结 8:1; 以西结 20:1"> 那月初五，就是约雅斤王被掳第五年，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 3:14; 以西结 3:22; 列王纪下 3:15"> 在迦勒底人之地、迦巴鲁河边，耶和华的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="当英文以全大写字母写作“LORD”或“GOD”时，是上帝专有名的翻译（希伯来文“יהוה”，通常读作 Yahweh）。">b</a></sup>话临到布西的儿子、祭司以西结；耶和华的手在那里按在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结 1:27; 以西结 8:2; 耶利米书 23:19"> 我观看，看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”源自“הִנֵּה”，意思是观看、留意、察看、看见或注视。它常用作感叹词。">c</a></sup>有狂风从北方刮来：一朵大云，带着闪烁的闪电，四围有光辉；从其中，就是从火中，显出仿佛发光金属的样子。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 4:6–8; 以西结 1:26; 启示录 6:6"> 从其中出来四个活物的形状。它们的样貌是这样：它们有人的形状。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 10:14; 启示录 4:7–8; 以西结 1:15"> 各有四张脸，各有四个翅膀。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 1:15; 但以理 10:6; 诗篇 104:4"> 它们的脚是直的；脚掌像牛犊的脚掌；它们闪耀如擦亮的铜。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 10:21; 以西结 10:11; 以赛亚书 6:6"> 在它们四边的翅膀底下，有人的手。它们四个的脸和翅膀是这样：</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 10:22; 以西结 10:11; 以西结 1:11–12"> 它们的翅膀彼此相连。它们行走时并不转身，各自径直向前行。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结 10:14; 启示录 4:7; 哥林多前书 9:9–10"> 至于它们脸的形状，它们有人的脸；四个在右边都有狮子的脸；四个在左边都有牛的脸；四个也都有鹰的脸。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 6:2; 以西结 1:23; 以西结 10:19"> 它们的脸就是这样。它们的翅膀向上展开；每个有两个翅膀彼此相接，两个翅膀遮盖自己的身体。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 1:9; 以西结 10:22; 希伯来书 1:14"> 它们各自径直向前行。灵要往哪里去，它们就往哪里去；它们行走时并不转身。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 4:5; 诗篇 104:4; 马太福音 28:3"> 至于那些活物的形状，它们的样貌像燃烧的火炭，又像火把的样子。火在活物中间来回闪动；那火明亮，又有闪电从火中发出。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:27; 撒迦利亚书 4:10; 马可福音 13:27"> 活物往来奔走，好像闪电一现。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理 7:9; 以西结 10:9; 以西结 1:19–21"> 我观看那些活物的时候，看哪，每个活物旁边，在地上各有一个轮子，对着它们四张脸中的每一张。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 10:6; 以西结 10:9–11; 出埃及记 39:13"> 轮子的样貌和构造好像绿宝石。四个轮子都有同一个形状；它们的样貌和构造仿佛轮中套轮。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 1:9; 以西结 1:12; 以赛亚书 55:11"> 它们行走的时候，向四个方向行走；行走时并不转向。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 10:12; 启示录 4:6; 启示录 4:8"> 至于轮辋，高而可畏；四个轮子的轮辋周围都满了眼睛。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结 10:16; 以西结 10:19; 诗篇 103:20"> 活物行走，轮子也在它们旁边行走；活物从地上升起，轮子也升起。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 1:12; 以西结 10:17; 哥林多前书 14:32"> 灵要往哪里去，它们就往哪里去；灵要往那里去。轮子也在它们旁边升起，因为活物的灵在轮子里。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 10:17; 以西结 1:19–20; 罗马书 8:2"> 那些行走，这些也行走；那些站住，这些也站住；那些从地上升起，轮子也在它们旁边升起，因为活物的灵在轮子里。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结 10:1; 以西结 1:26; 启示录 4:6"> 活物的头以上有穹苍的形状，看起来像令人敬畏的水晶，铺展在它们头的上方。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 4:18; 以西结 1:11–12; 诗篇 89:7"> 穹苍以下，它们的翅膀伸直，彼此相对。每个在这边有两个翅膀遮盖，每个在那边有两个翅膀遮盖自己的身体。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 43:2; 但以理 10:6; 启示录 1:15"> 它们行走的时候，我听见它们翅膀的响声，像众水的响声，像全能者的声音，又像喧嚷的响声，像军队的响声。它们站住的时候，就垂下翅膀。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结 1:22"> 在它们头以上的穹苍之上有声音。它们站住的时候，就垂下翅膀。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 10:1; 出埃及记 24:10; 启示录 1:13"> 在它们头以上的穹苍之上，有宝座的形状，样貌像蓝宝石<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：青金石">d</a></sup>。在宝座的形状上，有一位的形状，样貌像人，坐在其上方。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 1:4; 以西结 8:2; 希伯来书 12:29"> 我看见仿佛发光金属的样子，又像四围其中有火的样子，从他腰部的样貌以上是这样；从他腰部的样貌以下，我看见仿佛火的样子，他四围有光辉。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 10:1; 启示录 4:3; 创世记 17:3"> 那四围光辉的样貌，好像下雨之日云中彩虹的样貌。<br />这就是耶和华荣耀之形状的样貌。我看见时，就面伏于地，又听见一位说话的声音。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 33:30; 以西结 33:17; 以西结 3:11"> “人子啊，你要向你本族的子民说话，告诉他们：‘我使刀剑临到一地的时候，那地的民从他们中间选出一个人，立他作守望者；</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 8:1; 尼希米记 4:20; 尼希米记 4:18"> 如果他看见刀剑临到那地，就吹号警告百姓，</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 18:13; 使徒行传 18:6; 耶利米书 6:17"> 那么，凡听见号声却不理会警告的人，若刀剑临到，把他除灭，他的血就归到自己的头上。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 9:19–21; 希伯来书 11:7; 约翰福音 8:39"> 他听见了号声，却不接受警告；他的血必归到他自己身上。若他理会了警告，就救了自己的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 3:18–20; 以西结 33:8–9; 创世记 42:22"> 但如果守望者看见刀剑临到，却不吹号，百姓没有受到警告，刀剑临到，从他们中间除灭任何一人，那人是在自己的罪孽中被除灭；但他的血，我必向守望者追讨。’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结 3:17–21; 耶利米书 26:2; 以西结 2:7–8"> “所以你，人子啊，我已经立你作以色列家的守望者。你要听我口中的话，替我警告他们。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 20:26–27; 以西结 33:6; 以西结 33:14"> 我对恶人说：‘恶人哪，你必定死亡。’你若不开口警告恶人离开他的道路，那个恶人必死在自己的罪孽中；但他的血，我必向你追讨。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 3:19; 使徒行传 20:26; 箴言 15:10"> 然而，你若警告恶人离开他的道路，叫他回转，他却不离开自己的道路，他必死在自己的罪孽中；但你已经救了自己的性命。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 49:14; 以西结 37:11; 以西结 24:23"> “你，人子啊，要告诉以色列家：‘你们这样说：“我们的过犯和我们的罪压在我们身上，我们因这些罪日渐消亡。我们还怎能活着呢？”’</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:4; 以西结 18:23; 彼得后书 3:9"> 你要告诉他们：‘主耶和华说：“我指着我的永生起誓，我绝不喜悦恶人死亡，倒喜悦恶人离开他的道路而活。回转吧，回转离开你们邪恶的道路！以色列家啊，你们为什么要死亡呢？”’</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 7:14; 以西结 33:18–19; 罗马书 3:25"> “你，人子啊，要告诉你本族的子民：‘义人的义，在他悖逆的日子不能救他。至于恶人的恶，在他离开自己邪恶的日子，他不致因那恶跌倒；义人在犯罪的日子，也不能靠他的义而活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 18:24; 希伯来书 10:38; 以西结 18:4"> 我对义人说他必定存活；如果他倚靠自己的义而行罪孽，他一切的义行都不被记念；他必死在自己所行的罪孽中。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 18:27; 耶利米书 18:7–8; 何西阿 14:1"> 还有，我对恶人说：“你必定死亡。”如果他离开自己的罪，行公正正直的事，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 20:11; 路加福音 19:8; 出埃及记 22:1–4"> 如果恶人归还抵押物，偿还抢夺所得，行在生命的律例中，不行罪孽，他就必定存活，不致死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 43:25; 以西结 18:22; 弥迦书 7:18–19"> 他所犯的一切罪都不被记念而归在他身上。他行了公正正直的事，必定存活。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 25:24–26; 以西结 18:25; 以西结 18:29"> “‘然而，你本族的子民说：“主的道路不公平。”其实，是他们自己的道路不公平。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 33:12–13; 彼得后书 2:20–22; 希伯来书 10:38"> 义人离开自己的义而行罪孽，他必因此死亡。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 18:27–28; 以西结 33:14"> 恶人离开自己的恶，行公正正直的事，他必因此存活。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 16:27; 以西结 18:25; 以西结 33:17"> 然而你们说：“主的道路不公平。”以色列家啊，我必按你们各人的道路审判你们。’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结 1:2; 耶利米书 39:1–8; 列王纪下 25:4"> 我们被掳第十二年，十月初五日，有一个从耶路撒冷逃出来的人来到我这里，说：“城已经被攻破了！”</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 1:3; 以西结 3:26–27; 以西结 24:26–27"> 在那逃出来的人到来以前的晚上，耶和华的手临到我；到那人早晨来到我这里时，祂已经开了我的口；我的口开了，我就不再哑口。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话临到我，说：</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 33:27; 以赛亚书 51:2; 使徒行传 7:5"> “人子啊，住在以色列地废墟中的人说：‘亚伯拉罕只是一个人，却承受了这地；我们人数众多，这地已经赐给我们为业。’</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 12:16; 耶利米书 7:9–10; 创世记 9:4"> 所以你要告诉他们：‘主耶和华如此说：“你们吃带血的食物，仰望你们的偶像，又流人的血。你们岂可拥有这地呢？</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:40; 弥迦书 2:1–2; 西番雅书 3:3"> 你们倚靠自己的刀剑，行可憎的事，各人玷污邻舍的妻子。你们岂可拥有这地呢？”’</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 13:6; 耶利米书 42:22; 以西结 39:4"> “你要告诉他们：‘主耶和华如此说：“我指着我的永生起誓，住在废墟中的人必倒在刀下；在田野中的人，我必交给野兽吞吃；在坚固处和洞穴中的人，必死于瘟疫。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结 7:24; 耶利米书 44:2; 耶利米书 44:6"> 我必使这地荒凉，令人惊骇；它权势的骄傲必止息。以色列的山必荒凉，无人经过。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 6:7; 以西结 36:17–18; 以西结 22:2–15"> 因他们所行的一切可憎之事，我使这地荒凉，令人惊骇；那时他们就知道我是耶和华。”’</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 22:16–17; 耶利米书 23:35; 以赛亚书 29:13"> “至于你，人子啊，你本族的子民在墙边和房门口谈论你；他们彼此相告，各人对自己的弟兄说：‘请来听听有什么话从耶和华而出。’</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 13:22; 诗篇 78:36–37; 雅各书 1:22–24"> 他们来到你这里，像民众聚会一样；他们坐在你面前，像我的子民一样；他们听你的话，却不去实行；他们口中显出许多爱意，心却追随自己的利益。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 6:20; 马可福音 4:16–17; 约翰福音 5:35"> 看哪，在他们看来，你就像一个声音悦耳、善于奏乐的人所唱的一首极其动听的歌；因为他们听你的话，却不去实行。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="耶利米书 28:9; 撒母耳记上 3:19–20; 以西结 2:5"> “这事成就的时候——看哪，必定成就——那时他们就知道有先知在他们中间。”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 22:2; 以西结 20:4; 以赛亚书 58:1"> “人子啊，要使耶路撒冷知道她那些可憎的事；</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 16:45; 以赛亚书 51:1–2; 申命记 20:17"> 你要说：‘主耶和华对耶路撒冷这样说：“你的根源和你的出生，是在迦南人之地；你的父亲是亚摩利人，你的母亲是赫人。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿 2:3; 创世记 15:13; 出埃及记 5:16–21"> 至于你的出生，在你生下来的日子，没有人剪断你的脐带；没有人用水洗你，使你洁净；也没有人用盐擦你，完全没有人用布包裹你。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:10; 创世记 21:10; 出埃及记 1:22"> 没有一只眼怜惜你，为你做这些事中的任何一件来怜悯你；你却被丢在田野里，因为在你出生的日子，你被人厌恶。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所书 2:4–5; 约翰福音 5:25; 提多书 3:3–7"> “‘“我从你旁边经过，看见你在血中挣扎，就对你说：‘你虽在血中，仍要活！’是的，我对你说：‘你虽在血中，仍要活！’</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 1:10; 出埃及记 1:7; 以赛亚书 62:3"> 我使你繁多，如田间生长的植物；你增多长大，达到极美的地步。你的两乳成形，你的头发生长；然而你仍赤身露体。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得记 3:9; 耶利米书 2:2–3; 罗马书 5:8"> “‘“我从你旁边经过，看见你，看哪，你的时候正是相爱的时刻；我就把衣襟展开在你身上，遮盖你的赤裸。是的，我向你起誓，与你立约，”主耶和华说，“你就归于我了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 23:5; 路得记 3:3; 约翰一书 2:27"> “‘“于是我用水洗你；是的，我彻底洗净你身上的血，又用油膏抹你。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 16:18; 以西结 16:13; 以赛亚书 61:10"> 我也给你穿上刺绣的衣服，把皮凉鞋穿在你脚上；我用细麻布给你装束，用丝绸遮盖你。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 24:22; 以赛亚书 3:19; 创世记 41:42"> 我用饰物装扮你，把镯子戴在你手上，把链子戴在你颈上。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 3:21; 以赛亚书 28:5; 耶利米书 13:18"> 我把环子戴在你鼻上，把耳环戴在你耳上，把华美的冠冕戴在你头上。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 32:13–14; 诗篇 50:2; 列王纪上 4:21"> 这样，你就以金银装扮；你的衣服是细麻布、丝绸和刺绣的衣服。你吃的是细面、蜂蜜和油。你极其美丽，兴盛到王后的地位。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 10:24; 耶利米哀歌 2:15; 哥林多前书 4:7"> 你的美名因你的美貌传到列国，因为我加在你身上的威荣使你的美貌完全，”主耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 57:8; 耶利米书 2:20; 以西结 16:25"> “‘“可是你倚仗自己的美貌，因自己的名声而行淫，向每个经过的人倾倒你的淫乱；这就归了他。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:7; 以西结 7:20; 历代志下 28:24"> 你拿自己的一些衣服，为自己做了彩饰的丘坛，并在上面行淫。这样的事本不该发生，也绝不可再有。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 23:14–21; 耶利米书 3:9; 以西结 16:11"> 你又拿我赐给你的金银美饰，为自己制造男人的像，与它们行淫。</span>
<span className="v" id="v18" data-v="18"> 你拿自己的刺绣衣服覆盖它们，又把我的油和我的香摆在它们面前。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 16:13; 何西阿 2:8–13; 创世记 8:21"> 我赐给你的食物，就是我用来喂养你的细面、油和蜂蜜，你竟把这些摆在它们面前，作为馨香之气；事情就是这样，”主耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结 23:37; 以西结 20:31; 耶利米书 7:31"> “‘“此外，你把你为我所生的儿女献给它们，让他们被吞吃。你的淫乱岂是小事，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 17:17; 利未记 18:21; 申命记 18:10"> 以致你杀了我的儿女，把他们交出去，使他们经火归给它们吗？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 2:2; 何西阿 11:1; 以西结 16:43"> 在你一切可憎的事和淫乱中，你没有记念你幼年的日子；那时你赤身露体，在血中挣扎。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="启示录 12:12; 以西结 2:10; 以西结 24:6"> “‘“在你行了这一切恶事之后——你有祸了！你有祸了！”主耶和华说——</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:58; 以西结 16:39; 以西结 16:31"> “你为自己建造了拱顶之处，在各街上为自己筑了高台。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结 16:31; 耶利米书 3:2; 创世记 38:21"> 你在每条道路的路口建造你的高台，使你的美貌成为可憎的；你向每个经过的人张开双脚，增多你的淫乱。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 23:19–21; 以西结 20:7–8; 以西结 8:10"> 你又与你邻邦埃及人，就是肉体强壮的人，行淫乱；你增多你的淫乱，惹我发怒。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 9:12; 以西结 16:57; 以西结 16:37"> 所以看哪，我向你伸手，减少你的份额，把你交给恨你之人的心愿，就是非利士众女；她们都因你淫荡的行径而羞愧。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 16:7; 何西阿 10:6; 列王纪下 16:10–18"> 你又与亚述人行淫，因为你贪得无厌；是的，你与他们行淫，却仍不满足。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 21:9; 士师记 2:12–19; 以西结 13:14–23"> 你还把你的淫乱增多，直到商贾之地，直到迦勒底；即使这样，你仍不满足。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 3:3; 以赛亚书 1:3; 以赛亚书 3:9"> “‘“你的心何等软弱，”主耶和华说，“因为你行这一切事，都是厚颜无耻的妓女所做的；</span>
<span className="v" id="v31" data-v="31" data-xref="以西结 16:33–34; 以赛亚书 52:3; 以西结 16:39"> 你在每条道路的路口建造你的拱顶之处，在各街上筑你的高台；你却不像妓女，因为你轻看嫖资。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 2:28; 以西结 23:37; 耶利米书 2:25"> “‘“你这淫妇啊，宁愿接纳外人，不接纳自己的丈夫！</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 57:9; 何西阿 8:9–10; 以西结 16:41"> 人都给一切妓女礼物；你却把你的礼物给你所有的情人，贿赂他们，使他们从四面八方来到你这里，与你行淫。</span>
<span className="v" id="v34" data-v="34"> 你在淫乱的事上与别的女人不同，因为没有人追求你要与你行淫；你给人嫖资，却没有人给你嫖资，所以你与别人不同。”’</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 4:18; 列王纪上 22:19; 约翰福音 4:10"> “所以，你这妓女啊，要听耶和华的话：</span>
<span className="v" id="v36" data-v="36" data-xref="以西结 23:10; 以西结 24:13; 西番雅书 3:1"> ‘主耶和华这样说：“因为你的污秽倾泄出来，你与你的情人行淫时赤裸显露；又因为你一切可憎的偶像，以及你献给它们的儿女的血；</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿 2:10; 耶利米书 13:22; 何西阿 2:3"> 所以看哪，我要聚集你所有的情人，就是你所欢悦的，并你所爱的一切人，连同你所恨的一切人。我必把他们从四面聚集来攻击你，在他们面前显露你的赤裸，使他们看见你全部的赤裸。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 20:10; 创世记 9:6; 西番雅书 1:17"> 我必照审判犯奸淫和流人血的妇女那样审判你；我必使忿怒和妒恨的血临到你。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结 23:26; 何西阿 2:3; 以西结 16:24–25"> 我也必把你交在他们手中；他们必拆毁你的拱顶之处，毁坏你的高台。他们必剥去你的衣服，夺走你美丽的饰物，留下你赤身露体。</span>
<span className="v" id="v40" data-v="40" data-xref="以西结 23:47; 哈巴谷 1:6–10; 约翰福音 8:5–7"> 他们也必带一群人来攻击你，用石头打你，用刀剑刺透你。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结 23:48; 耶利米书 52:13; 耶利米书 39:8"> 他们必用火焚烧你的房屋，在许多妇人眼前向你施行审判。我必使你停止行淫，你也不再给人嫖资。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结 5:13; 以西结 21:17; 以赛亚书 40:1–2"> 这样，我必使我向你的烈怒止息，我的妒恨也必离开你；我必安静，不再发怒。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="以西结 16:22; 以西结 11:21; 诗篇 78:42"> “‘“因为你没有记念你幼年的日子，反而在这一切事上向我狂怒；所以看哪，我也必使你的行为报应在你头上，”主耶和华说，“你就不再把这淫荡加在你一切可憎的事上。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="以西结 18:2–3; 诗篇 106:35–38; 撒母耳记上 24:13"> “‘“看哪，凡用俗语的人都必用这俗语攻击你，说：‘有其母，必有其女。’</span>
<span className="v" id="v45" data-v="45" data-xref="撒迦利亚书 11:8; 以赛亚书 1:4; 以西结 23:37–39"> 你是你母亲的女儿；你母亲厌弃她的丈夫和她的儿女。你也是你姐妹的姐妹；她们厌弃她们的丈夫和她们的儿女。你的母亲是赫人，你的父亲是亚摩利人。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结 23:4; 以西结 16:48–49; 以西结 16:53–56"> 你的姐姐是撒马利亚，她和她的众女住在你左边；你的妹妹住在你右边，就是所多玛和她的众女。</span>
<span className="v" id="v47" data-v="47" data-xref="列王纪下 21:9; 以西结 16:51; 以西结 5:6–7"> 然而你没有行她们的道路，也没有照她们可憎的事去做；但不久，你在你一切所行的事上比她们更败坏。</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 10:15; 路加福音 10:12; 使徒行传 7:52"> 我指着我的永生起誓，”主耶和华说，“你的妹妹所多玛和她的众女所行的，并不像你和你的众女所行的。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="诗篇 138:6; 以西结 28:2; 创世记 13:10"> “‘“看哪，你妹妹所多玛的罪孽是这样：她和她的众女骄傲，饼食饱足，安逸兴盛；她也不扶助困苦和贫穷人的手。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 19:24; 创世记 18:20; 创世记 19:5"> 她们傲慢，在我面前行可憎的事。因此我看见后，就把她们除掉。</span>
<span className="v" id="v51" data-v="51" data-xref="耶利米书 3:8–11; 路加福音 12:47–48; 罗马书 3:9–20"> 撒马利亚所犯的罪还不到你的一半；你却使你可憎的事比她们更多，因你所行的一切可憎之事，使你的姐妹显为义。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 7:1–5; 以西结 36:15; 以西结 16:56"> 你也要亲自担当自己的羞辱，因为你为你的姐妹作出判决；因你所犯的罪比她们更可憎，她们就比你更显为义。是的，你也要惭愧，担当自己的羞辱，因为你使你的姐妹显为义。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="以西结 29:14; 耶利米书 12:16; 以西结 39:25"> “‘“我必使她们被掳的归回，就是使所多玛和她的众女被掳的归回，使撒马利亚和她的众女被掳的归回，也使你在她们中间被掳的归回；</span>
<span className="v" id="v54" data-v="54" data-xref="以西结 14:22–23; 耶利米书 2:26; 以西结 36:31–32"> 好使你担当自己的羞辱，并因你所行的一切感到羞愧，因为你成了她们的安慰。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结 36:11; 玛拉基书 3:4; 以西结 16:53"> 你的姐妹所多玛和她的众女必恢复原来的景况；撒马利亚和她的众女也必恢复原来的景况；你和你的众女也必恢复原来的景况。</span>
<span className="v" id="v56" data-v="56" data-xref="以赛亚书 65:5; 路加福音 15:28–30; 西番雅书 3:11"> 在你骄傲的日子，你口中没有提起你的妹妹所多玛，</span>
<span className="v" id="v57" data-v="57" data-xref="列王纪下 16:5–7; 以西结 16:36–37; 历代志下 28:5–6"> 那是在你的邪恶显露以前，正如亚兰众女和她四围所有的人、非利士众女羞辱你的时候；她们从四围藐视你。</span>
<span className="v" id="v58" data-v="58" data-xref="以西结 23:49; 耶利米哀歌 5:7; 创世记 4:13"> 你担当了自己的淫荡和可憎的事，”耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="以赛亚书 24:5; 以西结 17:19; 申命记 29:25"> “‘因为主耶和华这样说：“你既藐视誓言、背弃盟约，我也必照你所行的待你。</span>
<span className="v" id="v60" data-v="60" data-xref="何西阿 2:19–20; 希伯来书 12:24; 以西结 16:8"> 然而，我必记念你幼年日子与你所立的约，并且与你立定永远的约。</span>
<span className="v" id="v61" data-v="61" data-xref="希伯来书 8:13; 加拉太书 4:26–31; 以赛亚书 66:7–12"> 那时，你接纳你的姐妹，就是你的姐姐和妹妹时，你必记念自己的道路，并且羞愧；我必把她们赐给你作女儿，但不是按着你的约。</span>
<span className="v" id="v62" data-v="62" data-xref="耶利米书 24:7; 以西结 6:7; 以西结 39:22"> 我必与你立定我的约；那时你就知道我是耶和华；</span>
<span className="v" id="v63" data-v="63" data-xref="诗篇 39:9; 罗马书 3:19; 以西结 36:31–32"> 好使你记念，并且羞愧；当我赦免你所做的一切时，你必因自己的羞辱，再也不开口，”主耶和华说。’”</span>
</div>

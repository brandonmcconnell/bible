<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司 8:2; 彼得前书 4:7; 以西结 7:3"> “你，人子啊，主耶和华对以色列地这样说：‘结局！结局已经临到这地的四境。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 18:30; 以西结 5:13; 以西结 33:20"> 现在结局临到你，我要向你发出我的怒气，照你的行为审判你，使你一切可憎的事临到你。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 6:7; 以西结 11:21; 以西结 5:11"> 我的眼必不顾惜你，我也不怜悯；我要使你的行为临到你，你可憎的事必在你中间。这样，你们就知道我是耶和华。’</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="那鸿书 1:9; 列王纪下 21:12–13; 以西结 5:9"> “主耶和华这样说：‘灾祸！空前的灾祸！看哪，灾祸来了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亚书 13:7; 以西结 7:3; 彼得后书 2:5"> 结局已经来到。结局已经来到！它醒起，攻击你。看哪，它来了。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 12:28; 以西结 7:12; 以赛亚书 22:5"> 这地的居民啊，你的厄运已经临到你！时候到了！日子近了，是山上喧乱的日子，不是欢呼的日子。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 9:8; 以西结 14:19; 以西结 20:8"> 现在我快要将我的烈怒倾倒在你身上，向你成就我的怒气，照你的行为审判你，使你一切可憎的事临到你。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 20:13; 弥迦书 6:9; 以赛亚书 9:13"> 我的眼必不顾惜，我也不怜悯。我要照你的行为惩罚你；你可憎的事必在你中间。这样，你们就知道是我耶和华击打你。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 10:5; 雅各书 4:6; 帖撒罗尼迦前书 5:3"> “‘看哪，那日子！看哪，它来了！你的厄运已经发出。杖已经开花，骄傲已经发芽。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅书 1:18; 以西结 7:23; 以赛亚书 59:6–8"> 暴力兴起，成了邪恶的杖。他们中间没有一人能存留，他们的群众、他们的财富也不能存留；他们中间没有什么有价值的东西。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 5:13–14; 哥林多前书 7:29–31; 以西结 7:5–7"> 时候到了！日子近了。买主不要欢喜，卖主也不要哀哭；因为烈怒临到它所有的群众。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 25:24–28; 利未记 25:31; 约伯记 15:25"> 卖主即使还活着，也不能回到所卖的产业；因为这异象关乎它所有的群众，没有人能返回。没有人能靠自己生命中的罪孽使自己坚立。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 4:5; 耶利米书 7:20; 耶利米书 51:27"> 他们已经吹响号角，预备齐全；却没有人上阵，因为我的烈怒临到它所有的群众。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 14:18; 以西结 5:12; 耶利米哀歌 1:20"> “‘外有刀剑，内有瘟疫和饥荒。在田野的，必死于刀剑；在城中的，必被饥荒和瘟疫吞灭。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:11; 以赛亚书 38:14; 以斯拉记 9:15"> 但他们中间逃脱的，必逃出去，在山上如谷中的鸽子，个个因自己的罪孽哀鸣。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 21:7; 希伯来书 12:12; 耶利米书 6:24"> 众手都必发软，众膝都必软弱如水。</span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司 8:10; 以赛亚书 15:2–3; 以赛亚书 3:24"> 他们也必以麻布束腰，恐怖必遮盖他们；众人脸上必有羞愧，众人头上必都光秃。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 11:4; 西番雅书 1:18; 路加福音 12:19–20"> 他们要把银子抛在街上，他们的金子必如污秽之物。在耶和华烈怒的日子，他们的银子和金子不能救他们，不能使他们的生命满足，也不能填饱他们的肚腹；因为这成了他们罪孽的绊脚石。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 24:21; 耶利米书 7:30; 以西结 8:15–16"> 至于祂装饰的华美，祂把它设在威严中；但他们在其中制造可憎之物和可厌之物的像。因此，我使它对他们成为污秽之物。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 24:13; 诗篇 74:2–8; 历代志下 36:18–19"> 我要把它交在外族人手中作为掠物，交给地上的恶人作为抢夺之物；他们必亵渎它。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 18:17; 诗篇 74:18–23; 诗篇 74:10–11"> 我也要转脸不顾他们，他们就必亵渎我的隐秘处；强盗要进去，亵渎它。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结 9:9; 耶利米书 27:2; 以西结 11:6"> “‘要制造锁链，因为这地充满流血的罪案，这城充满暴力。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 28:7; 诗篇 106:41; 以西结 21:31"> 因此，我要使列国中最恶的人来，他们必占有他们的房屋。我也要使强者的骄傲止息；他们的圣所必被亵渎。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 8:15–16; 以赛亚书 57:21; 耶利米哀歌 4:17–18"> 毁灭来了！他们要寻求平安，却没有平安。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 4:20; 以西结 14:1; 弥迦书 3:6"> 灾祸加上灾祸，传闻接着传闻。他们要向先知寻求异象；但祭司必失去律法，长老必失去谋略。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 18:30; 以西结 7:4–8; 以西结 26:16"> 王必悲哀，首领必披上凄凉；这地百姓的手必惊惶。我要照他们的道路待他们，按他们自己的判断审判他们。这样，他们就知道我是耶和华。’”</span>
</div>
</div>

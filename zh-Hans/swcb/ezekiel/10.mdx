<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 24:10; 启示录 4:2–3; 启示录 1:13"> 我观看，看哪，在基路伯头上方的穹苍中，在他们上方显现出仿佛一块蓝宝石<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：青金石">a</a></sup>，其形状好像宝座的样式。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 8:5; 以西结 10:16; 以西结 1:13"> 祂对那身穿细麻衣的人说：“你进去，到旋转的轮子之间，就是到基路伯下面，从基路伯之间取满两手火炭，撒在城上。”<br />我观看的时候，那人就进去了。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 43:4; 以西结 9:3; 以西结 8:16"> 那人进去的时候，基路伯站在殿的右侧；云充满了内院。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 1:28; 以西结 9:3; 出埃及记 40:35"> 耶和华的荣耀从基路伯那里升起，停在殿的门槛上方；殿中充满了云，院子也充满了耶和华荣耀的光辉。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 1:24; 约伯记 40:9; 出埃及记 19:16"> 基路伯翅膀的声音甚至传到外院，好像全能上帝说话的声音。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结 10:2; 诗篇 99:1; 诗篇 80:1"> 事情是这样发生的：祂吩咐那身穿细麻衣的人说：“要从旋转的轮子之间，从基路伯之间取火。”那人就进去，站在一个轮子旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 13:41–42; 以西结 1:13; 以西结 41:23–26"> 有一个基路伯从基路伯之间伸手到基路伯之间的火那里，取了一些，放在那身穿细麻衣的人手中；那人接过来，就出去了。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 1:8; 以西结 10:21; 以赛亚书 6:6"> 在基路伯翅膀下面，显出有人手的形状。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结 1:15–17; 但以理 10:6; 启示录 21:20"> 我观看，看哪，基路伯旁边有四个轮子，一个轮子在一个基路伯旁边，另一个轮子在另一个基路伯旁边。轮子的外观好像水苍玉。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 1:16; 诗篇 36:6; 诗篇 104:24"> 至于它们的外观，四个都是同一个样式，好像轮中套轮。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 1:17; 以西结 10:22; 以西结 1:20"> 它们行走的时候，向四个方向行走；行走时并不转向，而是头朝哪里，它们就跟着往哪里去；行走时并不转向。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 1:18; 启示录 4:8; 启示录 4:6"> 他们全身，包括背、手、翅膀和轮子，四围都满了眼睛；那四个轮子也是如此。</span>
<span className="v" id="v13" data-v="13"> 至于那些轮子，我亲耳听见它们被称为“旋转的轮子”。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 4:7; 以西结 10:21; 列王纪上 7:36"> 他们各有四张脸：第一张脸是基路伯的脸，第二张脸是人的脸，第三张脸是狮子的脸，第四张是鹰的脸。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 1:5; 何西阿 9:12; 以西结 11:22"> 基路伯升上去了。这就是我在迦巴鲁河边所看见的活物。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 1:19–21"> 基路伯行走的时候，轮子也在他们旁边行走；基路伯举起翅膀，要从地上升起的时候，轮子也不离开他们旁边而转向。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 1:20–21; 罗马书 8:2; 以西结 1:12"> 他们站住的时候，这些轮子也站住；他们升起的时候，这些轮子也和他们一同升起，因为活物的灵在它们里面。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 18:10; 马太福音 23:37–39; 诗篇 78:60–61"> 耶和华的荣耀从殿的门槛上方出去，停在基路伯上方。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 8:16; 以西结 1:17–21; 以西结 1:26–28"> 基路伯举起翅膀，在我眼前从地上升起；他们出去的时候，轮子也在他们旁边。然后他们停在耶和华殿东门的门口；以色列上帝的荣耀在他们上方。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结 1:1; 以西结 10:15; 列王纪上 7:36"> 这就是我在迦巴鲁河边，在以色列上帝下面所看见的活物；我知道他们是基路伯。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 1:6; 以西结 41:18–19; 以西结 10:14"> 他们各有四张脸，各有四个翅膀；他们翅膀下面有人手的样式。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 10:11; 以西结 1:10; 以西结 1:12"> 至于他们脸的样式，正是我在迦巴鲁河边所看见的那些脸；他们的外观和本体都是一样的。他们各自直往前行。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="以西结 29:17; 以西结 26:1; 以西结 20:1"> 第十年十月十二日，耶和华的话临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 6:2; 耶利米书 44:30; 耶利米书 46:2–16"> “人子啊，你要面向埃及王法老，发预言攻击他和全埃及。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 32:2; 以赛亚书 27:1; 耶利米书 44:30"> 你要说：‘主耶和华如此说：<br /><span className="pl pl-1">“看哪，埃及王法老，我与你为敌；</span><br /><span className="pl pl-2">你这卧在自己河流中的大怪兽，</span><br /><span className="pl pl-1">曾说：‘我的河是我自己的，</span><br /><span className="pl pl-2">是我为自己造的。’</span></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:28; 以西结 38:4; 阿摩司 4:2"> <span className="pl pl-1">我要把钩子钩在你的腮颊上，</span><br /><span className="pl pl-2">使你河中的鱼粘在你的鳞甲上。</span><br /><span className="pl pl-1">我要把你从你的河流中拉上来，</span><br /><span className="pl pl-2">连同你河中所有粘在你鳞甲上的鱼。</span></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 34:20; 以西结 32:4–6; 耶利米书 8:2"> <span className="pl pl-1">我要把你丢在旷野，</span><br /><span className="pl pl-2">你和你河中所有的鱼都在那里。</span><br /><span className="pl pl-1">你要倒在田野间，</span><br /><span className="pl pl-2">不会被收殓，也不会被聚集。</span><br /><span className="pl pl-1">我已把你给地上的走兽作食物，</span><br /><span className="pl pl-2">也给天空的飞鸟作食物。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 18:21; 以赛亚书 36:6; 出埃及记 9:14"> “‘“埃及所有的居民必知道我是耶和华，因为他们曾作以色列家的芦苇杖。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 36:6; 以西结 17:15–17; 耶利米书 17:5–6"> 他们用手抓住你时，你就折断，撕裂他们所有的肩膀；他们倚靠你时，你就折断，使他们所有的大腿瘫软。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结 14:17; 以西结 30:10; 以西结 29:19–20"> “‘所以主耶和华如此说：“看哪，我要使刀剑临到你，剪除你中间的人和牲畜。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 29:3; 箴言 16:18; 以西结 29:10–12"> 埃及地必成为荒凉和废墟。那时他们就知道我是耶和华。<br />“‘“因为他说：‘这河是我的，是我造的’，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 30:12; 以西结 30:6–9; 出埃及记 14:2"> 所以，看哪，我与你和你的河流为敌。我要使埃及地全然荒废凄凉，从色弗尼塔直到埃塞俄比亚的边界。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 32:13; 耶利米书 43:11–12; 以西结 30:10–13"> 人的脚必不经过那里，牲畜的脚也不经过那里；那里四十年无人居住。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 46:19; 以西结 30:7; 以西结 30:23"> 我要使埃及地在荒凉的列国中成为荒凉；她的城在被毁的众城中必荒凉四十年。我要把埃及人分散到列国，驱散到各地。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 46:26; 以赛亚书 19:22"> “‘主耶和华如此说：“四十年满了以后，我要从他们被分散到的各族中招聚埃及人。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 30:14; 以赛亚书 11:11; 耶利米书 44:1"> 我要扭转埃及被掳的境况，使他们回到巴忒罗地，就是他们出生之地；在那里，他们必成为卑微的国。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 10:11; 以西结 30:13; 以西结 17:14"> 它必成为列国中最低微的，不再高举自己超过列国。我要使他们衰微，以致不再统治列国。</span>
<span className="v" id="v16" data-v="16" data-xref="何西阿 8:13; 以赛亚书 20:5; 以西结 29:6–7"> 它必不再作以色列家的依靠；以色列人转向仰望他们的时候，就使自己的罪孽被记起。那时他们就知道我是主耶和华。”’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 29:1; 以西结 1:2; 以西结 24:1"> 第二十七年正月初一日，耶和华的话临到我，说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 27:6; 耶利米书 25:9; 以西结 26:7–12"> “人子啊，巴比伦王尼布甲尼撒使他的军队为攻打推罗服了艰苦的劳役；人人的头都磨秃了，人人的肩都磨破了；然而他和他的军队攻打推罗所服的劳役，并没有从推罗得着工价。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 30:24–25; 耶利米书 43:10–13; 以西结 32:11"> 所以主耶和华如此说：‘看哪，我要把埃及地赐给巴比伦王尼布甲尼撒。他必掳走她的民众，夺取她的掠物，抢取她的战利品；这要作他军队的工价。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 25:9; 以赛亚书 10:6–7; 以赛亚书 45:1–3"> 我已把埃及地赐给他，作为他服役的报酬，因为他们是为我工作，’主耶和华说。</span>
</div>

<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 2:10; 路加福音 21:15; 诗篇 132:17"> “到那日，我要使以色列家长出一只角，也要在他们中间开你的口。那时他们就知道我是耶和华。”</span>

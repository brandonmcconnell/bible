<span className="v" id="v1" data-v="1" data-xref="以西结 40:20; 以西结 40:17; 以西结 42:13"> 于是他带我出来到外院，往北边去；又带我进入那些房间，就是对着隔开的地方、也对着北边那建筑的房间。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 41:13"> 朝着长一百肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>之处的是北门，宽五十肘。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 41:15–16; 以西结 41:10; 雅歌 7:5"> 对着内院所属的二十肘之地，又对着外院所属的铺石地，三层都有廊对着廊。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 46:19; 路加福音 13:24; 马太福音 7:14"> 房间前面有一条向内宽十肘的通道，一条一肘的路；它们的门都朝北。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 41:7"> 上层的房间较短，因为廊子占去了这些房间的空间，比占去建筑中下层和中层的更多。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 41:6; 列王纪上 6:8"> 因为这些房间有三层，却没有像院中柱子那样的柱子；所以从地面起，最上层比下层和中层更向后退。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 42:12; 以西结 42:10"> 房间旁边、朝外院、在房间前面的外墙，长五十肘。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 41:13–14"> 因为在外院的那些房间长五十肘。看哪，面向圣殿的那些房间长一百肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 46:19; 以西结 44:5"> 这些房间下面有东边的入口，人从外院进入这些房间。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结 42:1; 以西结 42:13; 以西结 41:12–15"> 在院墙的厚度处，朝东、在隔开的地方前面，又在那建筑前面，有一些房间。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 42:4"> 它们前面的路，样式好像朝北那些房间的样式；长宽都一样。它们所有的出口、布局和门也都一样。</span>
<span className="v" id="v12" data-v="12"> 南边那些房间的门怎样，在通道的起头也有一扇门，就是在朝东的墙前正对着的通道入口，人由此进入那些房间。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 10:17; 利未记 7:6; 以西结 40:46"> 他对我说：“北边的房间和南边的房间，就是对着隔开的地方的，是圣房；亲近耶和华的祭司要在那里吃至圣之物。他们也要在那里放置至圣之物，包括素祭、赎罪祭和赎愆祭；因为那地方是圣的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 44:19; 利未记 8:7; 出埃及记 29:4–9"> 祭司进去以后，不可从圣所出来到外院，直到他们把在那里供职所穿的衣服放下；因为这些衣服是圣的。然后他们要穿上别的衣服，才可以走近给百姓使用的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 43:1; 以西结 41:15; 以西结 40:6–16"> 他量完内殿，就带我从朝东的门出去，四围量那地方。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 40:3; 启示录 11:1–2; 撒迦利亚书 2:1"> 他用量竿量东边，按量竿共五百竿，四围都量。</span>
<span className="v" id="v17" data-v="17"> 他用量竿量北边，四围共五百竿。</span>
<span className="v" id="v18" data-v="18"> 他用量竿量南边，共五百竿。</span>
<span className="v" id="v19" data-v="19"> 他转到西边，用量竿量，共五百竿。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 45:2; 以西结 22:26; 以西结 40:5"> 他量了四面。那地方四围有墙，长五百肘，宽五百肘，为要把圣的和俗的分别开来。</span>
</div>

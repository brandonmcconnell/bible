<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 16:44–46; 耶利米书 3:7–10"> “人子啊，有两个女人，是同一个母亲的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 17:7; 以西结 16:22; 约书亚记 24:14"> 她们在埃及行淫；她们在年少时就行淫。在那里，她们的胸被抚摸，少女的乳头被爱抚。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 16:8; 诗篇 76:2; 耶利米书 2:2–3"> 她们的名字，姐姐叫阿荷拉，妹妹叫阿荷利巴。她们都归于我，并且生了儿女。至于她们的名字，阿荷拉就是撒马利亚，阿荷利巴就是耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="何西阿 5:13; 列王纪下 17:3; 列王纪下 16:7"> “阿荷拉虽属我，却行淫；她恋慕她的情夫，就是她邻近的亚述人，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 23:23"> 他们身穿蓝衣，都是总督和官长，都是可爱的青年，是骑着马的骑士。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿 5:3; 何西阿 6:10; 以西结 22:3–4"> 她把自己交给他们行淫；他们全都是亚述人中精选的人。凡她所恋慕的人，她都因他们的偶像玷污了自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 23:19; 以西结 23:3; 出埃及记 32:4"> 她没有离开从埃及以来的淫行；因为她年少时，他们就与她同寝。他们爱抚她少女的乳头，把他们的淫行倾倒在她身上。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿 11:5; 列王纪下 15:29; 列王纪下 17:23"> “所以我把她交在她情夫手中，就是交在她所恋慕的亚述人手中。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 23:29; 何西阿 2:10; 耶利米书 22:8–9"> 这些人揭露了她的赤身，夺走了她的儿女，又用刀杀了她。她在妇女中成了警戒的俗语，因为他们对她施行了审判。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:8–11; 以西结 16:47–51; 以西结 23:4"> “她妹妹阿荷利巴看见了这一切，却在恋慕上比她更败坏，在淫行上比她姐姐的淫行更邪恶。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:7–15; 以西结 23:23; 历代志下 28:16–23"> 她恋慕亚述人，就是她邻近的总督和官长；他们衣着极其华美，是骑着马的骑士，全都是可爱的青年。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿 12:1–2; 列王纪下 17:18–19; 以西结 23:31"> 我看见她被玷污了；她们二人走的是同一条路。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结 8:10; 耶利米书 22:14; 耶利米书 50:2"> “她又增多她的淫行；因为她看见墙上所描绘的人像，就是用红色描绘的迦勒底人像，</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:18; 撒母耳记上 18:4; 以赛亚书 22:21"> 腰间系着带子，头上垂着头巾，全都像军官的样子，仿照巴比伦人的形像，就是出生在迦勒底地的人。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 16:29; 马太福音 5:28; 约伯记 31:1"> 她一看见他们，就恋慕他们，差遣使者到迦勒底去见他们。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 23:28; 以西结 23:22; 创世记 10:10"> 巴比伦人来到她那里，上了爱的床，用他们的淫行玷污她。她被他们玷污以后，心里就厌弃他们。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 78:59; 诗篇 106:40; 耶利米书 12:8"> 这样，她揭露了自己的淫行，揭露了自己的赤身。于是我的心就厌弃她，正如我的心厌弃她姐姐一样。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 23:3; 以西结 20:7; 以西结 16:51"> 然而她更加增多她的淫行，追想她年少的日子，就是她在埃及地行淫的日子。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 17:15; 以西结 16:26; 耶利米书 5:8"> 她恋慕他们的情夫；那些人的阳物如驴的阳物，精液如马的精液。</span>
<span className="v" id="v21" data-v="21"> 这样，你追想起你年少时的淫荡，就是埃及人因你少女的胸而爱抚你乳头的时候。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结 16:37; 启示录 17:16; 耶利米书 6:22–23"> “所以，阿荷利巴啊，主耶和华如此说：‘看哪，我必激起你的情夫来攻击你，就是你心里所厌弃的人；我必使他们从四围来攻击你：</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 50:21; 列王纪下 24:2; 列王纪下 20:14–17"> 巴比伦人和所有迦勒底人，比割、书亚、哥亚，以及同他们在一起的所有亚述人；他们全都是可爱的青年，是总督和官长，是军官和有名望的人，全都是骑着马的。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 24:14; 以西结 26:10; 以西结 23:45"> 他们必带着兵器、战车、辎重车，并一群众民来攻击你。他们必拿小盾、大盾和头盔，在四围摆阵攻击你。我必把审判权交给他们，他们必照他们的审判来审判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结 23:47; 以西结 8:1–18; 以西结 15:6–7"> 我必把我的妒恨加在你身上，他们必以烈怒对待你。他们必割去你的鼻子和耳朵；你余剩的人必倒在刀下。他们必夺走你的儿女；你剩下的人必被火吞灭。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 16:39; 耶利米书 13:22; 以西结 23:29"> 他们还要剥去你的衣服，夺走你华美的珠宝。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 16:41; 以西结 23:3; 以西结 23:19"> 这样，我必使你的淫荡从你身上止息，除掉你从埃及地以来的淫行，使你不再向他们举目，也不再记念埃及。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结 23:22; 以西结 23:17; 耶利米书 34:20"> “因为主耶和华如此说：‘看哪，我必把你交在你所恨的人手中，交在你心里所厌弃的人手中。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 16:39; 以西结 23:25–26; 以西结 23:45–47"> 他们必以恨恶对待你，夺走你劳碌所得的一切，使你赤身露体。你行淫的赤身必被揭露，你的淫荡和你的淫行都要显露出来。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结 6:9; 诗篇 106:35–38; 耶利米书 2:18–20"> 这些事临到你，是因为你随从列国行淫，又因你被他们的偶像玷污。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 21:13; 耶利米书 7:14–15; 以西结 16:47–51"> 你走了你姐姐的路；所以我必把她的杯交在你手中。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 51:17; 诗篇 60:3; 以西结 22:4–5"> “主耶和华如此说：<br /><span className="pl pl-1">‘你必喝你姐姐的杯，</span><br /><span className="pl pl-2">那杯又深又大。</span><br /><span className="pl pl-1">你必被讥笑、被嘲弄。</span><br /><span className="pl pl-2">杯中盛得很多。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 51:17; 耶利米书 25:27; 耶利米书 25:15–16"> <span className="pl pl-1">你必被醉酒和忧愁充满，</span><br /><span className="pl pl-2">就是惊骇和荒凉的杯，</span><br /><span className="pl pl-2">你姐姐撒马利亚的杯。</span></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 18:7"> <span className="pl pl-1">你甚至要喝那杯，喝到点滴不剩；</span><br /><span className="pl pl-2">你要啃咬它的碎片，</span><br /><span className="pl pl-2">并撕裂自己的胸；</span><br />因为我已经说了，’主耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:9; 以赛亚书 17:10; 耶利米书 32:33"> “所以主耶和华如此说：‘因为你忘记我，把我抛在背后，所以你也要担当你的淫荡和你的淫行。’”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结 22:2; 以赛亚书 58:1; 以西结 16:2"> 耶和华又对我说：“人子啊，你要审判阿荷拉和阿荷利巴吗？那就向她们宣告她们可憎的事。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结 16:36; 耶利米书 32:35; 耶利米书 7:31"> 因为她们犯了奸淫，手上有血。她们与自己的偶像犯奸淫，又使她们为我所生的儿子经火献给偶像吞灭。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结 20:13; 列王纪下 21:7; 以西结 7:20"> 此外，她们还这样对待我：在同一天玷污我的圣所，又亵渎我的安息日。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪下 21:4; 以西结 44:7; 耶利米书 23:11"> 因为她们把自己的儿女杀了献给偶像以后，同一天又进我的圣所来亵渎它；看哪，她们竟在我殿中间做了这事。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王纪下 9:30; 耶利米书 4:30; 以西结 16:13–16"> “此外，你们姐妹还派人去请远方来的男人；使者奉差遣去见他们，看哪，他们就来了。为了他们，你沐浴自己，描画眼睛，用饰物装扮自己，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖记 1:6; 耶利米书 44:17; 以赛亚书 65:11"> 坐在华丽的床上，床前摆设桌子；你把我的香和我的油放在桌上。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="以西结 16:11–12; 启示录 12:3; 出埃及记 32:18–19"> “她那里有安逸群众的喧声；又有酒徒从旷野被带来，与庸俗之人同来；他们把镯子戴在她们手上，把华美的冠冕戴在她们头上。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结 23:3; 耶利米书 13:23; 以斯拉记 9:7"> 那时我论到那在奸淫中衰老的女子说：‘现在他们还要与她行淫，她也与他们行淫。’</span>
<span className="v" id="v44" data-v="44" data-xref="以西结 23:9–13; 以西结 23:3"> 他们到她那里去，像人到妓女那里一样。他们就是这样到阿荷拉和阿荷利巴这两个淫荡的女人那里去。</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿 6:5; 利未记 20:10; 以西结 23:36–39"> 义人必按淫妇所当受的审判，和流人血的妇女所当受的审判来审判她们，因为她们是淫妇，手上有血。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以西结 16:40; 耶利米书 15:4; 耶利米书 24:9"> “因为主耶和华如此说：‘我必使一群人上来攻击她们，把她们交给人折腾并抢掠。</span>
<span className="v" id="v47" data-v="47" data-xref="以西结 16:40–41; 耶利米书 39:8; 以西结 24:21"> 那群人必用石头打死她们，用刀剑处决她们。他们必杀死她们的儿女，又用火焚烧她们的房屋。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="以西结 6:6; 以西结 23:27; 以西结 16:41"> “‘这样，我必使淫荡从这地止息，使所有妇女都受警戒，不再照你们的淫荡去行。</span>
<span className="v" id="v49" data-v="49" data-xref="以西结 9:10; 以西结 7:4; 以西结 6:7"> 他们必把你们的淫荡报应在你们身上，你们也必担当你们偶像的罪。这样，你们就知道我是主耶和华。’”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 66:23; 以西结 44:1–2; 出埃及记 20:9"> “‘主耶和华如此说：“内院朝东的门，在六个工作的日子要关闭；但在安息日要打开，在月朔之日也要打开。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 44:3; 以西结 46:8; 历代志上 29:10–12"> 王要从外面经门廊的路进入，站在门柱旁；祭司要预备他的燔祭和平安祭，他要在门的门槛那里敬拜。然后他要出去，但那门不可关闭，直到晚上。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 约翰福音 10:9; 希伯来书 10:19–22"> 在安息日和月朔，这地的百姓要在那门的入口，在耶和华面前敬拜。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 45:17; 民数记 28:9–10"> 王在安息日献给耶和华的燔祭，要是六只没有残疾的羊羔和一只没有残疾的公绵羊；</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 45:24; 以西结 46:7; 申命记 16:17"> 素祭要为公绵羊献一伊法；为羊羔献的素祭，要照他力所能献的；每一伊法要加一欣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一欣约为6.5升，或1.7加仑。">a</a></sup>油。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一伊法约为22升，或约为三分之二蒲式耳。">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="以西结 46:1"> 在月朔之日，要献一头没有残疾的小公牛、六只羊羔和一只公绵羊，都要没有残疾。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 46:5"> 他要预备素祭：为公牛献一伊法，为公绵羊献一伊法；为羊羔所献的，要照他力所能献的；每一伊法要加一欣油。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 46:2; 以西结 44:1–3; 歌罗西书 1:18"> 王进入的时候，要经门廊的路进去，也要从那条路出去。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 16:16; 出埃及记 23:14–17; 彼得后书 2:20–21"> “‘“但这地的百姓在指定的节期来到耶和华面前时，从北门的路进去敬拜的，要从南门的路出去；从南门的路进去的，要从北门的路出去。他不可从进来的门原路返回，而要直往前行出去。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 42:4; 历代志上 29:20; 历代志上 29:22"> 他们进去的时候，王要与他们一同进去；他们出去的时候，他也要出去。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结 46:5; 以西结 46:7; 民数记 15:1–41"> “‘“在节期和指定的节日，素祭要为一头公牛献一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一伊法约为22升，或约为三分之二蒲式耳。">c</a></sup>，为一只公绵羊献一伊法；为羊羔所献的，要照他力所能献的；每一伊法要加一欣油。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 46:1–2; 以西结 45:17; 以西结 44:3"> 王预备甘心祭，作为献给耶和华的甘心祭，无论是燔祭还是平安祭，都要有人为他打开朝东的门；他要预备他的燔祭和平安祭，像安息日所行的一样。然后他要出去；他出去以后，要有人把门关闭。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 50:4; 约翰福音 1:29; 出埃及记 12:5"> “‘“你每日要预备一只一岁的、没有残疾的羊羔，作为献给耶和华的燔祭；每天早晨都要预备。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 28:5"> 每天早晨，你也要一同预备素祭，就是六分之一伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一伊法约为22升，或约为三分之二蒲式耳。">d</a></sup>，并三分之一欣油，用来调和细面；这是献给耶和华的素祭，是永远的条例，要常常献上。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:1–10; 民数记 28:6; 出埃及记 29:42"> 这样，他们每天早晨都要预备羊羔、素祭和油，作为常献的燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 21:3; 加拉太书 4:7; 创世记 25:5–6"> “‘主耶和华如此说：“如果王把礼物赐给他的一个儿子，那就是他的产业，归他的儿子们所有；这是他们因承受而得的产业。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 25:10; 路加福音 19:25–26; 加拉太书 4:30–31"> 但如果他从自己的产业中拿出礼物赐给他的一个仆人，那礼物归仆人所有，直到自由之年；然后要归还给王。至于他的产业，必归他的儿子们。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 45:8; 列王纪上 21:19; 以西结 22:27"> 此外，王不可夺取百姓的产业，把他们从自己的产业中赶出去。他要从自己的产业中给他的儿子们产业，免得我的子民各人从自己的产业中分散。”’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结 42:9; 以西结 44:4–5; 以西结 40:44–46"> 然后他带我经过门旁边的入口，进入祭司的圣屋，就是朝北的圣屋。看哪，西边后面有一个地方。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 35:13; 以西结 44:29; 以西结 44:19"> 他对我说：“这是祭司煮赎愆祭和赎罪祭、烤素祭的地方，免得他们把这些带到外院，使百姓成圣。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 然后他带我出去到外院，使我经过院子的四角；看哪，院子的每个角落都有一个院子。</span>
<span className="v" id="v22" data-v="22"> 院子四角有围起来的院子，长四十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">e</a></sup>，宽三十肘。四角的这四个院子大小相同。</span>
<span className="v" id="v23" data-v="23"> 这四个院子里面四周有墙，墙下四周设有煮祭物的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结 46:20; 约翰福音 21:15–17; 彼得前书 5:2"> 他对我说：“这些是煮祭物的房子，是圣殿的服事人员煮百姓祭物的地方。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:5; 罗马书 8:34; 约翰福音 14:6"> 孩子们，我写这些给你们，是要你们不犯罪。如果有人犯了罪，我们在父那里有一位辩护者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希腊语 παρακλητον：可译为辅导者、帮助者、代求者、辩护者和安慰者。">a</a></sup>，就是公义的耶稣基督。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:14; 彼得前书 3:18; 约翰一书 4:10"> 祂为我们的罪作了挽回祭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“挽回祭”源自希腊语“ιλασμος”，指平息、挽回，或平息、挽回的方式——就是因我们的罪而转去上帝忿怒的祭。">b</a></sup>；不只是为我们的罪，也是为全世界的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 路加福音 6:46"> 我们若遵守祂的诫命，就可以知道自己确实认识祂。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 1:6; 提多书 1:16; 雅各书 2:14–16"> 有人说：“我认识祂”，却不遵守祂的诫命，这人就是说谎的，真理不在他里面。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 14:23; 约翰福音 14:21; 约翰一书 4:12–13"> 但谁遵守祂的话，上帝的爱在谁里面就真正达到圆满。由此我们知道自己是在祂里面：</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:21; 约翰福音 13:15; 哥林多前书 11:1"> 说自己常在祂里面的，也应当像祂那样生活。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:11; 利未记 19:18; 马可福音 12:29–34"> 弟兄们，我写给你们的不是新诫命，而是你们从起初就有的旧诫命。这旧诫命就是你们从起初所听见的话。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:8; 罗马书 13:12; 约翰福音 13:34"> 我又写给你们一条新诫命。在祂和你们身上，这诫命都是真实的，因为黑暗正在消退，真光已经照耀。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 4:20; 约翰一书 2:11; 约翰一书 3:13–17"> 自称在光中，却恨弟兄的，到现在仍在黑暗中。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 3:14; 罗马书 9:32–33; 罗马书 14:13"> 爱弟兄的，就常在光中；在他里面也没有使人跌倒的缘由。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:35; 提多书 3:3; 约翰一书 1:6"> 恨弟兄的仍在黑暗中，在黑暗中行走，不知道往哪里去，因为黑暗使他的眼睛失明了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:43; 使徒行传 13:38; 以弗所书 1:7"> 孩子们，我写给你们，因为你们的罪因祂的名已经得了赦免。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:7; 约翰一书 2:14; 路加福音 10:22"> 父亲们，我写给你们，因为你们认识那从起初就有的那一位。<br />年轻人，我写给你们，因为你们已经胜过那恶者。<br />孩子们，我写给你们，因为你们认识父。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 119:11; 约翰一书 2:13; 歌罗西书 3:16"> 父亲们，我已经写给你们，因为你们认识那从起初就有的那一位。<br />年轻人，我已经写给你们，因为你们刚强，上帝的话常在你们里面，你们也已经胜过那恶者。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅各书 4:4; 罗马书 12:2; 马太福音 6:24"> 不要爱世界，也不要爱世界上的事。人若爱世界，父的爱就不在他里面。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 13:14; 加拉太书 5:17; 诗篇 119:36–37"> 世上的一切——肉体的欲望、眼目所贪恋的，以及因今生所有而生的骄傲——都不是从父来的，而是从世界来的。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:35; 罗马书 12:2; 哥林多前书 7:31"> 世界和其中的欲望都正在消逝；但遵行上帝旨意的人永远长存。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:3; 约翰二书 1:7; 马太福音 24:24"> 孩子们，如今是末后的时期。你们听说敌基督要来；现在已经有许多敌基督出现了。由此我们知道，现在就是最后的时刻。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 20:30; 哥林多前书 11:19; 路加福音 8:13"> 他们从我们中间出去，却不真正属于我们；要是属于我们，就会留在我们中间。他们离开，正显明他们没有一个属于我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:26; 约翰一书 2:27; 哥林多后书 1:21–22"> 你们从那位圣者领受了膏抹，你们也都有知识。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：“知道什么是真实的”；或作：“知道万事”。">c</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 1:12; 犹大书 1:5; 箴言 1:5"> 我写给你们，不是因为你们不知道真理，而是因为你们知道，而且知道没有谎言是出于真理的。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰二书 1:7; 约翰一书 4:3; 约翰一书 2:18"> 谁是说谎的呢？不就是否认耶稣是基督的人吗？否认父和子的，就是敌基督。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 4:15; 约翰福音 8:19; 约翰福音 5:23"> 凡否认子的，就没有父；承认子的，父也与他同在。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="MT省略：“承认子的，也有父。”">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 14:23; 约翰福音 15:9–10; 约翰一书 4:13"> 至于你们，要让从起初所听见的常在你们里面。你们从起初所听见的若常在你们里面，你们也必常住在子和父里面。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:28; 提多书 3:7; 犹大书 1:21"> 祂所应许我们的，就是永生。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:1–3; 约翰二书 1:7; 使徒行传 20:29–30"> 我写这些给你们，是论到那些想要迷惑你们的人。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:26; 约翰一书 2:20–21; 哥林多前书 2:13"> 至于你们，从祂领受的膏抹常在你们里面，不需要别人来教导你们。祂的膏抹在一切事上教导你们；这膏抹真实无伪。既然它这样教导了你们，你们就要常住在祂里面。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰一书 4:17; 马可福音 8:38; 约翰一书 3:2"> 孩子们，现在要常住在祂里面。这样，祂显现的时候，我们就可以坦然无惧；祂来的时候，也不至于在祂面前羞愧。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 3:3–5; 约翰一书 3:7; 约翰一书 5:1"> 你们若知道祂是公义的，也就知道每一个行义的人都是从祂生的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12–13; 约翰福音 8:42; 约翰一书 2:29"> 凡信耶稣是基督的，都是从上帝生的；凡爱父的，也爱那从父生的人。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:34–35; 约翰一书 2:5; 约翰一书 3:22–24"> 我们爱上帝、遵守祂的诫命，就由此知道自己也爱上帝的儿女。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 约翰福音 14:21–24"> 爱上帝，就是遵守祂的诫命；祂的诫命并不沉重。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 15:57; 约翰一书 4:4; 约翰福音 16:33"> 因为凡从上帝生的，都胜过世界。那胜过世界的，就是你们的信心。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:15; 约翰一书 5:1"> 胜过世界的是谁呢？不就是那信耶稣是上帝儿子的人吗？</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:26; 希伯来书 9:14; 约翰福音 16:13"> 这位就是耶稣基督；祂借着水和血而来，不是只有水，而是水和血。作见证的是圣灵，因为圣灵就是真理。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 28:19; 哥林多后书 13:14; 使徒行传 5:32"> 作见证的有三者：<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="只有少数较晚期的抄本加上：“在天上：父、道和圣灵；这三者是一。并且在地上作见证的有三者：”">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 5:6–7; 约翰福音 15:26; 彼得前书 3:21"> 圣灵、水和血；这三者的见证一致。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:16–17; 马太福音 17:5; 使徒行传 17:31"> 人的见证我们尚且接受，上帝的见证更有分量；这就是上帝为祂儿子所作的见证。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:16; 加拉太书 4:6; 约翰福音 3:33"> 信上帝儿子的，心里就有这见证。不信上帝的，等于说上帝在说谎，因为他不信上帝为祂儿子所作的见证。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:23; 约翰一书 2:25; 约翰福音 3:36"> 这见证就是：上帝把永生赐给我们，而这生命在祂儿子里面。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 3:36; 约翰福音 5:24; 约翰福音 1:12"> 有子的，就有生命；没有上帝儿子的，就没有生命。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:31; 约翰福音 1:12; 彼得后书 1:10–11"> 我把这些事写给你们这些信上帝儿子之名的人，为要让你们知道自己有永生，也继续信上帝儿子的名。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 14:13; 耶利米书 33:3; 耶利米书 29:12–13"> 我们在祂面前可以这样坦然无惧：无论求什么，只要合乎祂的旨意，祂就听我们。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:9–10; 马可福音 11:24; 箴言 15:29"> 我们既知道祂听我们的祈求，也就知道，无论向祂求什么，所求的已经得着了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:4–6; 撒母耳记上 2:25; 耶利米书 11:14"> 若有人看见弟兄犯了不至于死的罪，就应当为他祈求；上帝必把生命赐给那犯了不至于死之罪的人。有一种罪是至于死的；我不是说应当为这种罪祈求。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 3:4; 约翰一书 5:16; 雅各书 4:7–10"> 一切不义都是罪，但也有不至于死的罪。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 3:9; 约翰一书 5:4; 约翰一书 5:1"> 我们知道，凡从上帝生的都不犯罪；那从上帝生的人会保守自己，那恶者也不能加害他。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 4:4; 约翰一书 4:4–6; 以弗所书 2:2"> 我们知道，我们属于上帝；整个世界却都处在那恶者的权势之下。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 17:3; 路加福音 24:45; 约翰福音 14:9"> 我们知道，上帝的儿子已经来了，也赐给我们悟性，使我们认识那位真实者。我们住在那位真实者里面，也就是住在祂儿子耶稣基督里面。这就是真上帝，也是永生。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:14; 哥林多前书 10:7; 出埃及记 20:3–4"> 孩子们，要远离偶像。</span>
</div>

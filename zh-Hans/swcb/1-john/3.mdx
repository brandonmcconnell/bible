<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12; 加拉太书 3:26; 哥林多后书 6:18"> 你们看，父赐给我们多么大的爱，让我们得称为上帝的儿女！世界不认识我们，正因为它不认识祂。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:21; 歌罗西书 3:4; 哥林多前书 13:12"> 亲爱的，我们现在是上帝的儿女，将来会成为怎样，还没有显明。但我们知道，祂显现的时候，我们会像祂，因为我们必看见祂真实的样子。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:1; 约翰一书 2:6; 彼得后书 3:14"> 凡把这盼望寄托在祂身上的，都洁净自己，正如祂纯洁一样。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 5:17; 罗马书 3:20; 罗马书 4:15"> 凡犯罪的，也违背律法；罪就是违背律法。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:21; 希伯来书 9:28; 彼得前书 3:18"> 你们知道，祂曾显现，为的是除去我们的罪；祂里面没有罪。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:11; 约翰一书 2:4; 约翰一书 3:9"> 凡常住在祂里面的，就不犯罪；凡犯罪的，既没有见过祂，也不认识祂。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 2:29; 彼得前书 1:15–16; 罗马书 2:13"> 孩子们，不要让人迷惑你们。行义的人是义人，正如祂是义的。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 2:14; 约翰福音 8:44; 歌罗西书 2:15"> 犯罪的人属于魔鬼，因为魔鬼从起初就一直犯罪。上帝的儿子显现，就是为了毁灭魔鬼的作为。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 彼得前书 1:23; 约翰福音 1:13"> 凡从上帝生的，就不犯罪，因为祂的种子常在他里面；他也不能犯罪，因为他是从上帝生的。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:8; 约翰三书 1:11; 路加福音 6:35"> 谁是上帝的儿女，谁是魔鬼的儿女，就这样显明出来：不行义的，不属于上帝；不爱弟兄的，也不属于上帝。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12; 约翰二书 1:5; 约翰一书 4:7"> 你们从起初所听见的信息就是：我们应当彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:4; 创世记 4:4–15; 箴言 29:27"> 不要像该隐。他属于那恶者，杀害了自己的兄弟。他为什么杀兄弟呢？因为他所做的是恶的，而他兄弟所做的是义的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 约翰福音 17:14; 路加福音 21:17"> 弟兄们，世界若恨你们，不要惊讶。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:35; 约翰一书 5:2; 约翰一书 4:20–21"> 我们知道自己已经出死入生，因为我们爱弟兄。不爱弟兄的，仍留在死中。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:21–22; 箴言 26:24–26; 启示录 21:8"> 凡恨弟兄的，就是杀人的；你们知道，杀人的人没有永生常在他里面。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:9–11; 以弗所书 5:2; 约翰福音 13:34"> 我们从这件事知道何为爱：祂为我们舍了自己的生命。我们也应当为弟兄舍命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:16; 以赛亚书 58:7–10; 申命记 15:7–11"> 若有人有世上的财物，看见弟兄有需要，却硬着心不肯怜悯，上帝的爱怎能住在他里面呢？</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各书 2:15–16; 罗马书 12:9; 彼得前书 1:22"> 孩子们，我们相爱，不要只在言语上、口头上说爱，而要以行动和真诚来爱。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:22; 约翰一书 3:21; 希伯来书 6:10–11"> 这样，我们就知道自己属于真理，也能在祂面前使自己的心安稳下来；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 139:1–4; 耶利米书 17:10; 希伯来书 4:13"> 我们的心若责备我们，上帝仍高过我们的心，祂知道一切。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:28; 希伯来书 4:16; 哥林多后书 1:12"> 亲爱的，我们的心若不责备我们，我们在上帝面前就可以坦然无惧；</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 15:7; 约翰福音 9:31; 约翰一书 5:14"> 无论求什么，都从祂领受，因为我们遵守祂的诫命，也做祂所喜悦的事。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:29; 约翰福音 13:34; 彼得前书 1:22"> 祂的诫命就是：我们要信祂儿子耶稣基督的名，并彼此相爱，正如祂命令我们的。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 3:16; 约翰一书 4:15–16; 约翰一书 4:12–13"> 遵守祂诫命的，就常住在祂里面，祂也住在那人里面。我们知道祂住在我们里面，是因为祂把圣灵赐给了我们。</span>
</div>
</div>

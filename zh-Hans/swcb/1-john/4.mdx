<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:21; 彼得后书 2:1; 提摩太前书 4:1"> 亲爱的，不要每一个灵都信，总要察验这些灵是不是出于上帝，因为已经有许多假先知到世上来了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:14; 哥林多前书 12:3; 提摩太前书 3:16"> 你们可以这样认出上帝的灵：凡有灵承认耶稣基督已经以肉身而来，这灵就是出于上帝的；</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 2:22; 约翰二书 1:7; 约翰一书 2:18"> 凡有灵不承认耶稣基督已经以肉身而来，就不是出于上帝；这是敌基督的灵。你们听说它要来，如今它已经在世上了。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:31; 约翰一书 5:4; 罗马书 8:37"> 孩子们，你们是出于上帝的，并且已经胜过那些假先知，因为在你们里面的那一位，比在世上的那一位更大。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:23; 彼得后书 2:2–3; 约翰福音 17:14"> 他们属于世界，所以所说的也是属世界的话，世界便听他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:17; 约翰福音 10:27; 哥林多前书 2:12–14"> 我们是出于上帝的。认识上帝的就听我们；不出于上帝的就不听我们。这样，我们就能分辨真理的灵和错误的灵。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:20–1; 约翰一书 4:8; 彼得前书 1:22"> 亲爱的，我们要彼此相爱，因为爱出于上帝。凡有爱的人都是从上帝生的，也认识上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:16; 诗篇 86:15; 哥林多后书 13:11"> 没有爱的人不认识上帝，因为上帝就是爱。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:16; 约翰一书 5:11; 罗马书 8:32"> 上帝怎样爱我们，就显明在这件事上：祂差遣自己的独生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“独生”一词来自希腊词“μονογενη”，有时译作“独生的”或“独一无二的”。">a</a></sup>子到世上来，使我们借着祂得生命。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:4–5; 罗马书 5:8–10; 约翰一书 4:19"> 爱就在这里：不是我们爱上帝，而是祂爱我们，并差遣祂的儿子，为我们的罪作挽回祭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“挽回祭”来自希腊词“ιλασμος”，指平息、挽回，或平息、挽回的途径——就是因我们的罪而转离上帝忿怒的祭。">b</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12–13; 歌罗西书 3:13; 约翰福音 13:34"> 亲爱的，上帝既这样爱我们，我们也应当彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:18; 约翰一书 2:5; 约翰一书 4:17–18"> 从来没有人见过上帝。我们若彼此相爱，上帝就住在我们里面，祂的爱也在我们里面达到圆满。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:20–22; 约翰一书 3:24; 哥林多前书 3:16–17"> 祂把自己的灵赐给了我们；由此我们知道，我们住在祂里面，祂也住在我们里面。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:10; 约翰福音 3:16–17; 约翰福音 4:42"> 我们已经看见，也作见证：父差遣子作世界的救主。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 10:9; 约翰一书 5:5; 马太福音 10:32"> 凡承认耶稣是上帝儿子的，上帝就住在他里面，他也住在上帝里面。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 3:24; 诗篇 36:7–9; 约翰一书 3:1"> 我们已经认识，也相信上帝对我们的爱。上帝就是爱；常在爱中的，就常在上帝里面，上帝也住在他里面。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:12; 约翰一书 2:28; 罗马书 8:29"> 爱在我们中间达到圆满，就使我们在审判的日子可以坦然无惧，因为祂是怎样的，我们在这世上也是怎样的。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太后书 1:7; 罗马书 8:15; 约翰一书 4:12"> 爱里没有惧怕；完全的爱能驱除惧怕，因为惧怕与刑罚相连。心里惧怕的人，在爱里还没有达到圆满。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:10; 约翰福音 3:16; 约翰福音 15:16"> 我们爱祂，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU文本省略“祂”。">c</a></sup>因为祂先爱我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 3:17; 约翰一书 2:9; 约翰一书 4:12"> 有人说：“我爱上帝”，却恨弟兄，这人就是说谎的。连看得见的弟兄都不爱，又怎能爱看不见的上帝呢？</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 22:37–39; 利未记 19:18; 约翰一书 3:11"> 我们从祂领受的诫命就是：爱上帝的，也要爱自己的弟兄。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 23:4–5; 以西结 34:16; 以赛亚书 58:7"> 你不可看见你兄弟的牛或羊走失，却避开不管；你总要把它们带回给你的兄弟。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 7:12; 帖撒罗尼迦前书 4:6"> 如果你的兄弟离你不近，或你不认识他，你就要把那牲畜牵回你家，留在你那里，直到你的兄弟来寻找；你要还给他。</span>
<span className="v" id="v3" data-v="3"> 他的驴，你也要这样做；他的衣服，你也要这样做；凡你兄弟失落的东西，是他丢失而被你找到的，你都要这样做。你不可避开不管。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 6:1–2; 希伯来书 12:12–13; 马太福音 5:44"> 你不可看见你兄弟的驴或牛倒在路上，却避开不管；你总要帮助他把它们扶起来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 11:4–15; 申命记 18:12"> 女人不可穿男人的衣物，男人也不可穿女人的衣物；因为凡做这些事的人，都是耶和华你上帝所憎恶的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 22:28; 箴言 12:10; 创世记 8:17"> 如果你在路上遇见鸟窝，或在树上，或在地上，里面有雏鸟或鸟蛋，母鸟伏在雏鸟上或鸟蛋上，你不可连母鸟带雏鸟一起取走。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:40; 箴言 22:4"> 你总要放走母鸟，雏鸟可以归你自己，这样你就可以得福，并且使你的日子长久。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 11:2; 以赛亚书 22:1; 出埃及记 21:28–36"> 你建造新房屋的时候，要在屋顶四围做栏杆，免得有人从那里掉下来，使流血的罪归到你的家。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 19:19; 哥林多后书 11:3; 马太福音 9:16"> 你不可在你的葡萄园里撒两样种子，免得你所撒种子的出产和葡萄园的出产都归为圣，不得归你使用。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 6:14–16"> 你不可用牛和驴一起耕地。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 19:19"> 你不可穿羊毛和麻混织的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 23:5; 民数记 15:37–41"> 你要在自己所披外衣的四角做穗子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“流苏”">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 29:21; 创世记 29:31; 以弗所书 5:28–29"> 如果有人娶妻，与她同房后却厌恶她，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 22:19; 箴言 18:21; 箴言 18:8"> 指控她有羞耻的事，败坏她的名声，说：“我娶了这个女人，亲近她的时候，没有发现她有贞洁的凭证”；</span>
<span className="v" id="v15" data-v="15"> 那么，少女的父母要把这少女贞洁的凭证拿出来，带到城门口给城里的长老。</span>
<span className="v" id="v16" data-v="16"> 少女的父亲要对长老说：“我把女儿给这人为妻，他却厌恶她。</span>
<span className="v" id="v17" data-v="17"> 看哪，他指控她有羞耻的事，说：‘我没有发现你的女儿有贞洁的凭证。’然而这些就是我女儿贞洁的凭证。”他们要把那布铺在城里的长老面前。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 18:21"> 那城的长老要拿住那人，责打他。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 22:29; 马太福音 19:8–9; 申命记 24:1–4"> 他们要罚他一百舍客勒银子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一舍客勒约为10克，或约0.35盎司；所以100舍客勒约为一公斤，或2.2磅。">b</a></sup>，给那少女的父亲，因为他败坏了以色列一个处女的名声。她仍要作他的妻子；他一生不可休弃她。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 但如果这事是真的，在那少女身上没有发现贞洁的凭证，</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 13:5; 创世记 34:7; 士师记 20:6"> 就要把那少女带到她父亲家的门口，本城的人要用石头把她打死，因为她在以色列中做了愚妄的事，在她父家行淫。这样，你就要从你们中间除掉这恶。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 20:10; 以西结 23:45–47; 约翰福音 8:4–5"> 如果有人被发现与有夫之妇同寝，他们二人，就是与那女人同寝的男人和那女人，都要处死。这样，你就要从以色列中除掉这恶。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:18–19; 申命记 20:7"> 如果有一个少女，是处女，已经许配给丈夫，有人在城里遇见她，与她同寝，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 22:21–22; 申命记 21:14; 哥林多前书 5:13"> 你们就要把他们二人带到那城的城门口，用石头把他们打死：那少女，是因为她在城里却没有呼喊；那男人，是因为他玷辱了邻舍的妻子。这样，你就要从你们中间除掉这恶。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 13:14"> 但如果那人在田野遇见已经许配的少女，抓住她并强迫她，与她同寝，那么只有与她同寝的那男人要被处死；</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 21:22"> 对那少女，你不可做什么。那少女没有该死的罪；这事就像人起来攻击邻舍，把他杀了一样；</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 13:7"> 因为那人在田野遇见她，已经许配的少女呼喊，却没有人救她。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 22:16–17"> 如果有人遇见一个少女，是处女，还没有许配，就抓住她，与她同寝，并且他们被发现，</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 22:19; 申命记 22:24; 申命记 21:14"> 那与她同寝的男人就要给少女的父亲五十舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约为10克，或约0.35盎司。">c</a></sup>银子。因为他玷辱了她，她就要作他的妻子；他一生不可休弃她。</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 27:20; 哥林多前书 5:1; 利未记 18:8"> 人不可娶他父亲的妻子，也不可揭开他父亲的衣襟。</span>
</div>
</div>

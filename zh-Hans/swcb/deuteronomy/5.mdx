<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="DEU" data-book-slug="deuteronomy" data-book-name="申命记" data-chapter="5" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 马太福音 23:3; 申命记 29:10"> 摩西召集以色列众人，对他们说：“以色列啊，要听我今日说给你们听的律例和典章，好叫你们学习，并谨守遵行。”</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:23; 出埃及记 19:5–8; 出埃及记 24:8"> 耶和华我们的上帝在何烈山与我们立约。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:10–15; 创世记 17:21; 创世记 17:7"> 耶和华不是与我们的列祖立这约，而是与我们，就是今日在这里还活着的我们众人立的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 19:18–19; 申命记 34:10; 出埃及记 19:9"> 耶和华在山上，从火中与你们面对面说话，</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:19; 出埃及记 19:16; 出埃及记 20:18–21"> （那时我站在耶和华和你们中间，要把耶和华的话指示你们；因为你们惧怕那火，没有上山。）祂说：</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 20:2–17; 诗篇 81:5–10; 利未记 26:1–2"> “我是耶和华你的上帝，曾把你从埃及地，从为奴之家领出来。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:3; 马太福音 4:10; 约翰一书 5:21"> “除我以外，你不可有别的神。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:4; 申命记 4:15–19"> “不可为自己雕刻偶像，也不可制作任何形像，仿造天上、地上，或地底下水中的任何东西。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:4–6; 出埃及记 34:7; 但以理 9:4–9"> 不可向它们跪拜，也不可事奉它们；因为我耶和华你的上帝，是忌邪的上帝。恨我的，我必追讨他们父亲的罪孽，临到儿女，直到第三、第四代；</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:28; 约翰一书 1:7; 耶利米书 32:18"> 爱我、守我诫命的，我必向他们施慈爱，直到千代。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 19:12; 申命记 6:13"> “不可滥用耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="英文中全大写的“LORD”或“GOD”，除非另有注明为短形式“יה Yah”，都是译自希伯来文“יהוה Yahweh”。">a</a></sup>你上帝的名；<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：不可妄称耶和华你上帝的名。">b</a></sup>因为滥用祂名的人，耶和华必不以他为无罪。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:8–11; 以赛亚书 58:13; 以赛亚书 56:6"> “要照耶和华你上帝所吩咐你的，谨守安息日，分别为圣。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 20:12; 路加福音 13:14–16; 出埃及记 23:12"> 六日你要劳碌，做你一切的工；</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:4; 创世记 2:2; 出埃及记 23:12"> 但第七日是向耶和华你上帝守的安息日。这一日你不可做任何工，无论是你、你的儿子、你的女儿、你的男仆、你的女仆、你的牛、你的驴、你的任何牲畜，或住在你城门内的寄居者，都不可做工；这样，你的男仆和女仆可以和你一样休息。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 5:6; 申命记 15:15; 申命记 16:12"> 你要记得，你在埃及地作过奴仆，耶和华你的上帝用大能的手和伸出来的膀臂，把你从那里领出来。因此，耶和华你的上帝吩咐你守安息日。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 歌罗西书 3:20"> “要孝敬你的父亲和母亲，照耶和华你上帝所吩咐你的，使你在耶和华你上帝赐给你的地上日子长久，并且得福。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:13; 罗马书 13:9; 马太福音 5:21–22"> “不可谋杀。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 20:14; 路加福音 18:20; 利未记 20:10"> “不可奸淫。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:15; 罗马书 13:9; 以弗所书 4:28"> “不可偷盗。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:16; 出埃及记 23:1; 箴言 19:9"> “不可作假见证陷害你的邻舍。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:17; 罗马书 13:9; 路加福音 12:15"> “不可贪恋你邻舍的妻子；也不可贪图你邻舍的房屋、田地、男仆、女仆、牛、驴，或任何属于你邻舍的东西。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:12; 出埃及记 31:18; 申命记 4:12–15"> 耶和华在山上，从火中、云中、幽暗中，用大声音把这些话说给你们全会众听；祂没有再加别的话。祂把这些话写在两块石版上，交给了我。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 20:18–19; 希伯来书 12:18–21"> 那时山被火焚烧，你们听见从黑暗中发出的声音，就近前来到我这里；你们各支派的首领和长老都来了。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 4:33; 出埃及记 19:19; 出埃及记 33:20"> 你们说：“看哪，耶和华我们的上帝已经把祂的荣耀和伟大显给我们看，我们也听见祂从火中发出的声音。今日我们看见，上帝确实与人说话，人仍然活着。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:16; 加拉太书 3:10; 哥林多后书 3:7–9"> 现在，我们为什么要死呢？这大火必吞灭我们。如果我们再听见耶和华我们上帝的声音，就必死亡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 4:33; 罗马书 3:20; 马太福音 26:63"> 凡有血肉的人，有谁像我们一样听见永活上帝从火中说话的声音，还能活着呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 20:19; 希伯来书 12:19"> 你要近前去，听耶和华我们上帝所要说的一切；耶和华我们上帝对你所说的一切，你都告诉我们；我们就听从并遵行。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 18:17; 民数记 36:5; 民数记 27:7"> 你们对我说话时，耶和华听见了你们话语的声音；耶和华对我说：“这百姓对你所说的话，我听见了。他们所说的都说得好。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 48:18; 以西结 33:31–32; 申命记 11:1"> 惟愿他们常有这样的心，敬畏我，遵守我一切的诫命，使他们和他们的儿女永远得福！</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> “你去告诉他们：‘你们回到自己的帐篷去。’</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 3:19; 以西结 20:11; 申命记 5:1"> 至于你，要站在我这里；我要把一切诫命、律例和典章告诉你，你要教导他们，使他们在我赐给他们为业的地上遵行。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 23:6; 箴言 4:27; 约书亚记 1:7"> 所以，你们要照耶和华你们上帝所吩咐你们的谨守遵行，不可偏离左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:23; 申命记 4:40; 路加福音 1:6"> 你们要行在耶和华你们上帝所吩咐你们的一切道路上，使你们可以存活，得福，并在你们将要承受为业的地上日子长久。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 25:1; 约书亚记 22:7; 民数记 33:17–18"> 以下是摩西在约旦河东的旷野，在亚拉巴，对着苏弗，在巴兰、陀弗、拉班、哈洗录和底撒哈之间，向以色列全体所说的话。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 32:8; 民数记 13:26; 申命记 9:23"> 从何烈，沿西珥山的路，到加低斯·巴尼亚，有十一天的路程。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 33:38; 申命记 4:1–2; 民数记 20:1"> 第四十年十一月初一日，摩西照着耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="英文以全大写字母呈现的“LORD”或“GOD”，是上帝专有名的译法（希伯来文“יהוה”，通常读作 Yahweh）。">a</a></sup>吩咐他传给以色列人的一切话，对他们说话；</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:21–35; 约书亚记 12:2–6; 约书亚记 13:10–12"> 那是在他击败了住在希实本的亚摩利王西宏，以及住在亚斯他录、在以得来的巴珊王噩以后。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 4:8; 申命记 32:46; 申命记 31:9"> 在约旦河东，摩押地，摩西开始阐明这律法，说：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:1; 民数记 10:11–13; 出埃及记 19:1–2"> “耶和华我们的上帝<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>在何烈对我们说：‘你们在这山住得够久了。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:24; 约书亚记 10:40; 阿摩司 2:9"> 你们要转身起行，去亚摩利人的山区，以及附近所有地方：亚拉巴、山区、低地、南地、海边、迦南人的地和黎巴嫩，直到大河，就是幼发拉底河。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 创世记 12:7; 创世记 26:3–4"> 看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”来自“הִנֵּה”，意思是看、注意、观察、观看或凝视；常用作感叹词。">c</a></sup>我已经把这地摆在你们面前。你们要进去，取得耶和华向你们列祖——亚伯拉罕、以撒、雅各——起誓要赐给他们和他们以后后裔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：种子">d</a></sup>的地。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 18:18; 民数记 11:17; 民数记 11:11–14"> 那时我对你们说：“我独自一人不能承担你们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 10:22; 出埃及记 32:13; 创世记 22:17"> 耶和华你们的上帝使你们增多；看哪，今日你们的人数像天上的星那样众多。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 115:14; 创世记 22:17; 民数记 6:27"> 愿耶和华你们列祖的上帝使你们比现在多一千倍，并照祂应许你们的赐福给你们！</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 列王纪上 3:7–9; 哥林多后书 2:16"> 我独自一人怎能承担你们的麻烦、你们的重担和你们的争讼呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 18:21; 使徒行传 1:21–23; 民数记 11:16–17"> 你们要从各支派中选出有智慧、有见识、受人尊重的人，我要立他们作你们的首领。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 你们回答我说：“你所说的这事很好，可以去做。”</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:18; 出埃及记 18:25–26; 以弗所书 4:11"> 于是我选取你们各支派的首领，就是有智慧、受人尊重的人，立他们作你们的首领，按着你们的支派，作千夫长、百夫长、五十夫长、十夫长和官长。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:24; 出埃及记 22:21; 历代志下 19:6–10"> 那时我吩咐你们的审判官说：“你们要听审你们弟兄之间的案件，在人与他的弟兄，以及与他同住的寄居者之间，都要按公义审判。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:19; 出埃及记 18:26; 雅各书 2:9"> 审判时不可偏袒；无论小事大事，你们都要一样听审。不可惧怕人的脸色，因为审判是属于上帝的。你们难以处理的案件，要带到我这里来，我就听审。”</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:32; 申命记 4:5; 使徒行传 20:20"> 那时我吩咐你们一切当做的事。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 1:2; 申命记 8:15; 耶利米书 2:6"> 我们照耶和华我们的上帝吩咐我们的，从何烈起行，经过你们所看见那又大又可怕的旷野，沿着通往亚摩利人山区的路走，来到加低斯·巴尼亚。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 1:7–8"> 我对你们说：“你们已经来到亚摩利人的山区，就是耶和华我们的上帝赐给我们的地方。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:9; 诗篇 46:1; 民数记 14:8–9"> 看哪，耶和华你的上帝已经把这地摆在你面前。你要上去取得这地，正如耶和华你列祖的上帝对你所说的。不要害怕，也不要惊惶。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 13:1–20"> 你们都来到我面前，说：“请让我们派人先去，为我们侦察那地，把我们应当从哪条路上去、要进哪些城的消息带回来给我们。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民数记 13:3–33"> 这话我看为好，就从你们中间选了十二个人，每个支派一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 13:21–27; 约书亚记 2:1–2"> 他们转身上山区去，来到以实各谷，侦察那地。</span>
<span className="v" id="v25" data-v="25"> 他们手里拿了那地的一些果子，带下来给我们，又把消息带回来给我们，说：“耶和华我们的上帝赐给我们的是美地。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 14:1–4; 使徒行传 7:51; 诗篇 106:24–25"> 然而你们不肯上去，反而悖逆耶和华你们上帝的命令。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 9:28; 诗篇 106:25; 民数记 14:3"> 你们在帐棚里发怨言，说：“因为耶和华恨我们，所以祂把我们从埃及地领出来，要把我们交在亚摩利人手中，毁灭我们。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 13:28–33; 申命记 9:1–2; 约书亚记 15:14"> 我们要上到哪里去呢？我们的弟兄使我们心里丧胆，说：‘那民比我们更强大、更高大；城邑又大又坚固，高达天际。而且我们在那里还看见了亚衲人的子孙！’”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 于是我对你们说：“不要惊恐，也不要怕他们。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 14:14; 尼希米记 4:20; 罗马书 8:31"> 在你们前面行的耶和华你们的上帝，祂必为你们争战，正如祂在埃及，在你们眼前为你们所做的一切；</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 46:3–4; 使徒行传 13:18; 何西阿 11:3–4"> 在旷野，你也看见耶和华你的上帝怎样背负你，像人背负自己的儿子一样，在你们所走的一切路上，直到你们来到这地方。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:24; 犹大书 1:5; 希伯来书 3:18–19"> 然而在这事上，你们不信耶和华你们的上帝；</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 10:33; 诗篇 78:14; 尼希米记 9:12"> 祂在路上走在你们前面，为你们寻找安营的地方：夜间在火中，指示你们当走的路；白天在云中。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 14:22–30; 诗篇 95:11; 以西结 20:15"> 耶和华听见你们这些话的声音，就发怒，起誓说：</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 95:11"> “这个邪恶世代的人，必没有一个能看见我起誓要赐给你们列祖的美地，</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 14:24; 约书亚记 14:6–14; 民数记 32:12"> 惟有耶孚尼的儿子迦勒可以看见；他所踏过的地，我要赐给他和他的子孙，因为他专心跟从耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数记 20:12; 申命记 4:21; 申命记 34:4"> 耶和华也因你们的缘故向我发怒，说：“你也不得进去那里。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 3:28; 民数记 14:30; 申命记 31:7–8"> 站在你面前的嫩的儿子约书亚，他必进去那里。你要鼓励他，因为他要使以色列承受那地为业。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 7:15–16; 民数记 14:3; 民数记 14:31"> 还有你们的小孩子，就是你们说必被掳掠或被杀害的；你们的儿女，今日还不知善恶的，他们必进去那里。我要把那地赐给他们，他们必得为业。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 14:25"> 至于你们，要转身起行，沿红海的路往旷野去。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 14:39–45; 箴言 19:3; 民数记 22:34"> 那时你们回答我说：“我们得罪了耶和华。我们要照耶和华我们的上帝所吩咐我们的一切，上去争战。”你们各人都佩上自己的兵器，擅自上山区去。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="民数记 14:41–43; 约书亚记 7:8–13; 以赛亚书 59:1–2"> 耶和华对我说：“你要告诉他们：‘不要上去，也不要争战；因为我不在你们中间，免得你们在仇敌面前被击败。’”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="民数记 14:44; 以赛亚书 63:10; 使徒行传 7:51"> 于是我告诉了你们，你们却不听；反而悖逆耶和华的命令，狂妄自大，上了山区。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 118:12; 民数记 14:45; 民数记 21:3"> 住在那山区的亚摩利人出来攻击你们，追赶你们如同蜜蜂追赶人，在西珥击败你们，直到何珥玛。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 12:17; 诗篇 78:34"> 你们回来，在耶和华面前哭泣；耶和华却不听你们的声音，也不侧耳听你们。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 20:1; 民数记 20:22; 士师记 11:16–17"> 于是你们在加低斯住了许多日子，照着你们所停留的日子。</span>
</div>
</div>

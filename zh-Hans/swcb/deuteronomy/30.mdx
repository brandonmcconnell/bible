<span className="v" id="v1" data-v="1" data-xref="申命记 30:15; 列王纪上 8:47–48; 申命记 30:19"> 当这一切事，就是我摆在你面前的祝福和咒诅，都临到你身上，而你在耶和华你的上帝赶逐你去的万国中，把这些事记在心里，</span>
<span className="v" id="v2" data-v="2" data-xref="约珥 2:12–13; 尼希米记 1:9; 申命记 4:28–31"> 你和你的儿女就归向耶和华你的上帝，照我今日所吩咐你的一切，尽心尽性听从祂的声音，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:14; 以西结 36:24; 诗篇 147:2"> 那时，耶和华你的上帝必使你从被掳中得释放，怜悯你，并且再从耶和华你的上帝使你分散到的万民中招聚你。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 1:9; 以西结 39:25–29; 申命记 28:64"> 你被赶散的人即使在天的尽头，耶和华你的上帝也必从那里招聚你，从那里带你回来。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 29:14"> 耶和华你的上帝必带你进入你列祖所得为业的土地，你也必得它为业。祂必善待你，使你的人数比你列祖更多。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:16; 以西结 36:26–27; 耶利米书 32:39"> 耶和华你的上帝必给你的心和你后裔的心行割礼，使你尽心尽性爱耶和华你的上帝，好使你存活。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 7:15; 耶利米哀歌 4:21–22; 耶利米书 51:24–26"> 耶和华你的上帝必把这一切咒诅加在你的仇敌和恨恶你、迫害你的人身上。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 2:16; 以西结 36:27; 以西结 11:19–20"> 你必归回，听从耶和华的声音，遵行我今日所吩咐你的一切诫命。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 28:11–14; 耶利米书 32:41; 耶利米书 33:9"> 耶和华你的上帝必使你手所做的一切、你身所生的、你牲畜所产的、你土地所出的，都丰盛兴旺，使你得福；因为耶和华必再次喜悦你，使你得福，像祂喜悦你列祖一样，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:40–41; 申命记 4:29; 尼希米记 1:9"> 只要你听从耶和华你的上帝的声音，谨守写在这律法书上的祂的诫命和律例，并且尽心尽性归向耶和华你的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 45:19; 诗篇 147:19–20; 罗马书 16:25–26"> 我今日所吩咐你的这条诫命，对你并不太难，也不遥远。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 10:6–8; 箴言 30:4; 约翰福音 3:13"> 它不在天上，以致你要说：“谁为我们上到天上，把它取下来给我们，向我们宣讲，好让我们遵行呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:33; 马太福音 12:42; 箴言 2:1–5"> 它也不在海的那边，以致你要说：“谁为我们渡到海的那边，把它取来给我们，向我们宣讲，好让我们遵行呢？”</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 10:8–10; 耶利米书 12:2; 马太福音 7:21"> 这话却离你很近，就在你口中，在你心里，使你可以遵行。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 11:26; 申命记 30:19; 约翰一书 5:11–12"> 看哪，我今日把生命与福乐、死亡与灾祸摆在你面前。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 30:6; 马太福音 22:37–38; 约翰一书 5:2–3"> 因为我今日吩咐你爱耶和华你的上帝，行祂的道路，谨守祂的诫命、律例和典章，使你可以存活并增多，也使耶和华你的上帝在你进去得为业的土地上赐福给你。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 4:4; 希伯来书 3:12; 箴言 1:32"> 但如果你的心转离，不肯听从，反被引诱去敬拜别的神明，事奉它们，</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 8:19–20; 以赛亚书 63:17–18; 申命记 4:26"> 我今日向你们宣告：你们必定灭亡。你们过约旦河进去要得为业的那地，你们在那里的日子必不长久。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 30:15; 申命记 11:26; 诗篇 119:30"> 我今日呼唤天地作证指控你们：我已将生命与死亡、祝福与咒诅摆在你面前。所以你要选择生命，使你和你的后裔都可以存活，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 11:25–26; 申命记 10:20; 约翰福音 17:3"> 爱耶和华你的上帝，听从祂的声音，紧紧依靠祂；因为祂就是你的生命，是你日子的长久，使你可以住在耶和华向你列祖亚伯拉罕、以撒、雅各起誓要赐给他们的土地上。</span>

<span className="v" id="v1" data-v="1" data-xref="申命记 31:10; 出埃及记 23:10–11; 利未记 25:2–4"> 每逢七年结束的时候，你要豁免债务。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各书 2:13; 路加福音 6:34–38"> 豁免的方式是这样：凡债主借给邻舍的，都要免除；不可向他的邻舍和弟兄追讨，因为耶和华的豁免已经宣告了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:20; 马太福音 17:25–26; 哥林多前书 6:6–7"> 向外邦人，你可以追讨；但你借给你弟兄的，无论是什么，你都要免除。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:10–11; 箴言 28:27; 箴言 11:24–25"> 然而，在你们中间必没有穷人（因为在耶和华你的上帝赐给你作产业、让你占有的地上，耶和华必定赐福给你），</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 28:1–15; 以赛亚书 1:19–20; 约书亚记 1:7"> 只要你殷勤听从耶和华你上帝的声音，谨守遵行我今天吩咐你的这一切诫命。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:12–13; 路加福音 6:35; 尼希米记 9:27"> 因为耶和华你的上帝必照祂所应许你的赐福给你。你要借给许多国，却不必向人借贷；你要统治许多国，它们却不能统治你。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:16–17; 申命记 15:9; 箴言 21:13"> 在耶和华你的上帝赐给你的地上，无论哪一座城门内，若有你的弟兄，就是穷人，与你同在，你不可硬着心，也不可向你贫穷的弟兄收紧你的手；</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 马太福音 5:42"> 你总要向他张开你的手，按他所缺乏、所需要的，足足借给他。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 24:15; 马太福音 20:15; 耶利米书 17:10"> 你要谨慎，免得心里起邪恶的念头，说：“第七年，就是豁免年，快到了，”你就以恶眼看待你贫穷的弟兄，什么也不给他；他若向耶和华控告你，这就成了你的罪。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯来书 13:16; 以赛亚书 58:10"> 你总要给他；给他的时候，你心里不可忧愁，因为为这事，耶和华你的上帝必在你一切工作和你手所办的一切事上赐福给你。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 14:7; 马太福音 26:11; 约翰福音 12:8"> 因为这地上的穷人永不会断绝。所以我吩咐你：在你的地上，你总要向你的弟兄、困苦的人和穷人张开你的手。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 34:14; 利未记 25:39–41; 出埃及记 21:2–6"> 若你的弟兄，一个希伯来男人或希伯来女人，被卖给你，服侍你六年，到了第七年，你要让他自由地离开你。</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 3:5; 耶利米书 22:13; 箴言 3:27–28"> 你让他自由地离开你时，不可让他空手而去。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 16:2; 箴言 10:22; 诗篇 68:10"> 你要从你的羊群、禾场和酒榨中丰丰富富地供给他；耶和华你的上帝怎样赐福给你，你也要照样给他。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:12; 马太福音 18:32–33; 申命记 5:14–15"> 你要记得，你在埃及地作过奴隶，耶和华你的上帝救赎了你。因此我今天吩咐你这事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:5–6; 诗篇 40:8; 诗篇 40:6"> 如果他对你说：“我不愿离开你，”因为他爱你和你的家，又因为他与你在一起过得好，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 1:22; 利未记 25:39–42"> 那么你要拿锥子，把他的耳朵穿透到门上，他就永远作你的仆人。对你的婢女也要照样办理。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以赛亚书 16:14; 以赛亚书 21:16"> 当你让他自由地离开你时，不要觉得为难，因为他服侍你六年，价值等于雇工的两倍。耶和华你的上帝必在你所做的一切事上赐福给你。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 13:12; 利未记 27:26"> 你牛群和羊群中所生的一切头生公畜，都要分别为圣，归给耶和华你的上帝。你不可用你牛群中头生的牛作工，也不可剪你羊群中头生的羊的毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 12:17; 申命记 14:23; 申命记 12:5–7"> 你和你的家属，每年要在耶和华你的上帝面前，在耶和华所选择的地方吃它。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 17:1; 玛拉基书 1:7–8; 利未记 22:19–25"> 如果它有什么残疾，瘸腿或瞎眼，或有任何残疾，你就不可把它献给耶和华你的上帝为祭。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:21–22; 申命记 12:15–16"> 你可以在你的城门内吃它；不洁净的人和洁净的人都可以吃，如同吃羚羊和鹿一样。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:16; 利未记 7:26; 申命记 12:23"> 只是不可吃它的血；你要把血倒在地上，像倒水一样。</span>

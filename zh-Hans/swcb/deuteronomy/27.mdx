<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 15:14; 路加福音 11:28; 雅各书 2:10"> 摩西和以色列的长老吩咐百姓说：“你们要遵守我今天吩咐你们的一切诫命。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 8:31; 以西结 36:26; 以西结 11:19"> 当你们过约旦河，进入耶和华你上帝赐给你的土地那一天，你要为自己立起几块大石头，并用石灰涂抹。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 8:32; 申命记 26:9; 哥林多后书 3:2–3"> 你过河以后，要把这律法的一切话写在石头上，好使你可以进入耶和华你上帝赐给你的土地，就是流奶与蜜之地，正如耶和华、你列祖的上帝所应许你的。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 11:29–30; 约书亚记 8:30–33"> 你们过了约旦河以后，要在以巴路山上立起这些石头，就是我今天吩咐你们的，并要用石灰涂抹。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:25; 出埃及记 24:4; 约书亚记 8:30–31"> 你要在那里为耶和华你的上帝筑一座坛，一座石坛。不可在石头上使用任何铁器。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 5:2; 利未记 1:1–17"> 你要用未凿过的石头筑耶和华你上帝的坛；你要在坛上向耶和华你的上帝献燔祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 3:1–17; 以赛亚书 12:3; 诗篇 100:1–2"> 你要献平安祭，并在那里吃；你要在耶和华你的上帝面前欢乐。</span>
<span className="v" id="v8" data-v="8" data-xref="哈巴谷 2:2; 约翰福音 16:25; 哥林多后书 3:12"> 你要把这律法的一切话清清楚楚地写在石头上。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:10–11; 申命记 26:16–18; 以弗所书 5:8–9"> 摩西和利未人的祭司对全以色列说：“以色列啊，要安静聆听！今天你已经成为耶和华你上帝的子民。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 11:1; 彼得前书 1:14–16; 马太福音 5:48"> 所以你要听从耶和华你上帝的声音，遵行祂的诫命和律例，就是我今天吩咐你的。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 当天，摩西吩咐百姓说：</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 9:7; 创世记 30:24; 创世记 35:18"> “你们过了约旦河以后，以下这些支派要站在基利心山上祝福百姓：西缅、利未、犹大、以萨迦、约瑟和便雅悯。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 27:4; 创世记 29:32; 创世记 30:20"> 以下这些支派要站在以巴路山上宣告咒诅：吕便、迦得、亚设、西布伦、但和拿弗他利。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 9:11; 申命记 33:9–10; 约书亚记 8:33"> 利未人要高声对以色列众人说：</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:17; 出埃及记 20:4; 申命记 5:8"> ‘有人制造雕刻的或铸造的偶像，就是耶和华所憎恶的，是工匠手所做的，并在暗中设立，那人必受咒诅。’<br />众百姓都要回答说：‘阿们。’</span>
</div>

</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命记 19:14; 箴言 22:28; 箴言 23:10–11"> ‘挪移邻舍地界的，必受咒诅。’<br />众百姓都要说：‘阿们。’</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 19:14; 马太福音 15:14; 箴言 28:10"> ‘使盲人在路上走迷的，必受咒诅。’<br />众百姓都要说：‘阿们。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 10:18; 申命记 24:17; 箴言 17:23"> ‘向寄居者、孤儿和寡妇屈枉公正的，必受咒诅。’<br />众百姓都要说：‘阿们。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 22:30; 利未记 18:8; 哥林多前书 5:1"> ‘与他父亲的妻子同寝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即与……发生性关系">a</a></sup>的，必受咒诅，因为他辱没了父亲的床榻。’<br />众百姓都要说：‘阿们。’</span>

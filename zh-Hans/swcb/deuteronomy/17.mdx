<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 15:21; 玛拉基书 1:8; 申命记 23:18"> 你不可把有残疾或有任何恶处的牛羊献给耶和华你的上帝，因为那是耶和华你上帝所憎恶的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士师记 2:20; 何西阿 8:1; 约书亚记 7:11"> 在你中间，在耶和华你上帝赐给你的任何城镇里，若发现有男人或女人行耶和华你上帝眼中看为恶的事，违背祂的约，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 7:31; 申命记 4:19; 约伯记 31:26–27"> 去事奉别的神，敬拜它们，或敬拜太阳、月亮，或天上的万象，就是我没有吩咐的，</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:51; 申命记 13:12–14; 申命记 19:18"> 有人告诉你，你也听见了，就要仔细查问。看哪，若这事真实，确凿无疑，以色列中确实行了这样的可憎之事，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 24:14; 约书亚记 7:25; 利未记 24:16"> 你就要把行这恶事的那男人或那女人带到你的城门那里，就是那男人或那女人；你要用石头把他们打死。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 35:30; 希伯来书 10:28; 提摩太前书 5:19"> 凭两个见证人或三个见证人的口，那个该死的人才可被处死；凭一个见证人的口，不可把他处死。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 13:9; 哥林多前书 5:13; 申命记 17:12"> 见证人的手要先下在他身上，把他处死，然后众民的手也要下手。这样，你就要从你中间除掉这恶。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 12:5; 哈该书 2:11; 申命记 1:17"> 若在你的城镇中，有案件难以判断，无论是血案与血案之间、诉讼与诉讼之间，或伤害与伤害之间，是争议的案件，你就要起来，上耶和华你上帝所选择的地方去。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 44:24; 哈该书 2:11; 玛拉基书 2:7"> 你要到利未人的祭司和那时在任的审判官那里；你要询问，他们就会把判决告诉你。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:2–3"> 你要照他们从耶和华所选择的那地方告诉你的判决去行；他们教导你的一切，你都要谨守遵行。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 1:7; 申命记 5:32; 罗马书 13:1–6"> 你要照他们教导你的律法指示，照他们告诉你的判决去行；他们向你宣告的判语，你不可偏离，或向右，或向左。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 15:30; 申命记 13:5; 申命记 18:5"> 若有人擅自行事，不听从那站在那里在耶和华你上帝面前事奉的祭司，或不听从审判官，那人就必须死。你要从以色列中除掉这恶。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 13:11; 申命记 19:20; 民数记 15:30–31"> 众民听见了就会惧怕，不再擅自行事。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 8:19–20; 撒母耳记上 12:19; 约书亚记 1:13"> 当你到了耶和华你上帝赐给你的地，得了那地并住在其中，说：“我要立一位王治理我，像我周围的列国一样，”</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 30:21; 历代志上 22:10; 历代志上 12:23"> 你总要立耶和华你上帝所选择的人作王治理你。你要从你弟兄中立一人作王治理你；不可立不是你弟兄的外族人治理你。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 31:1–3; 以西结 17:15; 申命记 28:68"> 只是王不可为自己加添许多马匹，也不可使百姓回埃及，为要加添许多马匹；因为耶和华曾对你们说：“你们不可再回那条路。”</span>
<span className="v" id="v17" data-v="17" data-xref="尼希米记 13:26; 马太福音 19:5; 箴言 30:8–9"> 他不可为自己加添许多妻子，免得他的心偏离；也不可为自己大量积蓄金银。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 31:9; 列王纪下 22:8; 历代志下 34:15"> 当他坐在自己国度的王位上时，要为自己把这律法抄录在书卷上，照着利未人的祭司面前的原本抄写。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 1:8; 诗篇 119:97–100; 诗篇 1:2"> 这书要在他身边，他一生的日子都要诵读，好使他学习敬畏耶和华他的上帝，谨守这律法的一切话和这些律例，并遵行；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 5:32; 列王纪上 15:5; 诗篇 131:1–2"> 免得他的心高过他的弟兄，也免得他偏离诫命，或向右，或向左；这样，他和他的子孙就可以在以色列中，在他的国度里长久在位。</span>
</div>

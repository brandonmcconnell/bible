<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 1:19; 出埃及记 23:22; 利未记 26:3–13"> 如果你留心听从耶和华你上帝的声音，谨守遵行我今日所吩咐你的一切诫命，耶和华你的上帝就必使你高过地上的万国。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 1:6; 申命记 28:15; 提摩太前书 4:8"> 你若听从耶和华你上帝的声音，以下这一切福分都必临到你，追上你。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 144:12–15; 创世记 39:5; 哈该书 2:19"> 你在城里必蒙福，在田间也必蒙福。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 创世记 49:25; 申命记 7:13"> 你身所生的、你地所产的、你牲畜所生的、牛群所增的、羊群所出的，都必蒙福。</span>
<span className="v" id="v5" data-v="5"> 你的筐子和你的抟面盆都必蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 121:8; 民数记 27:17; 历代志下 1:10"> 你进来必蒙福，出去也必蒙福。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:38–41; 利未记 26:7–8; 诗篇 89:23"> 耶和华必使起来攻击你的仇敌在你面前被击败。他们从一条路出来攻击你，却要从七条路在你面前逃跑。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:10; 利未记 26:10; 箴言 3:9–10"> 耶和华必命令福分临到你的仓房，并临到你手所办的一切事。祂必在耶和华你上帝赐给你的地上赐福给你。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 申命记 26:18–19"> 你若谨守耶和华你上帝的诫命，行祂的道路，耶和华就必照祂向你所起的誓，立你作为归祂自己的圣民。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 7:14; 申命记 11:25; 耶利米书 33:9"> 地上的万民看见你被称为属耶和华名下的人，就必惧怕你。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 30:9; 箴言 10:22; 利未记 26:9"> 在耶和华向你列祖起誓要赐给你的地上，耶和华必使你身所生的、牲畜所生的、土地所产的，都丰富昌盛。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 15:6; 约珥 2:23–24; 申命记 15:10"> 耶和华必为你打开祂天上美好的宝库，按时给你的地降雨，并赐福给你手所做的一切工。你必借给许多国，却不向他们借贷。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:1; 申命记 4:6–9; 腓立比书 1:27"> 你若听从耶和华你上帝的诫命，就是我今日吩咐你要谨守遵行的，耶和华就必使你作首不作尾；你只居上，不居下；</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 30:21; 申命记 5:32; 申命记 11:16"> 并且你不可偏离我今日所吩咐你的任何话，或向右或向左，去随从别的神明，事奉它们。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 2:2; 申命记 28:2; 申命记 29:20"> 但如果你不听从耶和华你上帝的声音，不谨守遵行我今日所吩咐你的一切诫命和律例，以下这一切咒诅都必临到你，追上你。</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 3:9–12; 箴言 3:33; 约珥 1:4"> 你在城里必受咒诅，在田间也必受咒诅。</span>
<span className="v" id="v17" data-v="17" data-xref="哈该书 1:6; 申命记 28:5; 诗篇 69:22"> 你的筐子和你的抟面盆都必受咒诅。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 26:26; 利未记 26:19–20; 约伯记 18:16–19"> 你身所生的、你地所产的、牛群所增的、羊群所出的，都必受咒诅。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:6; 士师记 5:6–7; 历代志下 15:5"> 你进来必受咒诅，出去也必受咒诅。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 66:15; 玛拉基书 2:2; 申命记 4:26"> 耶和华必在你手所办的一切事上，向你发出咒诅、混乱和责罚，直到你被毁灭，直到你迅速灭亡；这是因为你行事邪恶，离弃了我。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 26:25; 耶利米书 24:10; 耶利米书 16:4"> 耶和华必使瘟疫紧紧缠住你，直到祂把你从你进去要占有的地上灭绝。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司 4:9; 利未记 26:16; 哈该书 2:17"> 耶和华必用痨病、热病、炎症、灼热、刀剑、枯萎和霉烂击打你；这些必追赶你，直到你灭亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:19; 耶利米书 14:1–6; 列王纪上 18:2"> 你头上的天必变为铜，你脚下的地必变为铁。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 28:12; 以赛亚书 5:24; 阿摩司 4:11"> 耶和华必使你地上的雨变为粉尘和尘土，从天上降在你身上，直到你被毁灭。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 30:17; 以西结 23:46; 耶利米书 24:9"> 耶和华必使你在仇敌面前被击败。你从一条路出去攻击他们，却要从七条路在他们面前逃跑；你必在地上万国中被抛来抛去。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 34:20; 耶利米书 16:4; 耶利米书 7:33"> 你的尸体必成为天上各样飞鸟和地上走兽的食物，并且无人把它们吓走。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 5:6; 申命记 28:35; 利未记 21:20"> 耶和华必用埃及的疮、肿瘤、坏血病和疥癣击打你，使你无法医治。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:9–11; 以赛亚书 19:11–17; 以赛亚书 6:9–10"> 耶和华必用癫狂、眼瞎和心中惊惶击打你。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 59:10; 约伯记 5:14; 士师记 6:1–6"> 你必在正午摸索，像盲人在黑暗中摸索一样；你在所行的路上必不亨通。你只会常常受欺压、被抢夺，并且无人拯救你。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司 5:11; 耶利米书 8:10; 约伯记 31:10"> 你要聘定妻子，却有别的男人与她同寝。你要建造房屋，却不得住在其中。你要栽种葡萄园，却不得享用它的果子。</span>
<span className="v" id="v31" data-v="31" data-xref="约伯记 1:14–15; 士师记 6:1"> 你的牛在你眼前被宰杀，你却不得吃它的肉。你的驴在你面前被强夺去，却不归还给你。你的羊群必交给你的仇敌，你却无人拯救。</span>
<span className="v" id="v32" data-v="32" data-xref="约珥 3:6; 申命记 28:41; 约伯记 17:5"> 你的儿女必交给别的民族。你的眼目终日切望他们，以致衰残；你手中却无力可施。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 5:17; 申命记 28:29–30; 以赛亚书 1:7"> 你地所产的和你一切劳碌所得，必被你不认识的民族吃尽。你只会常常受欺压、被压碎，</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 16:10–11; 申命记 28:68; 以赛亚书 33:14"> 以致你眼中所见的景象要使你发疯。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 28:27; 以赛亚书 3:24; 以赛亚书 3:17"> 耶和华必在你的膝上和腿上，用无法医治的恶疮击打你，从你的脚掌直到头顶。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 16:13; 申命记 4:28; 列王纪下 25:11"> 耶和华必把你和你为自己所立的王，带到一个你和你列祖都不认识的民族那里；在那里，你必事奉木头和石头所造的别的神明。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 25:9; 列王纪上 9:7–8; 耶利米书 24:9"> 在耶和华领你去的万民中，你必成为令人惊骇的对象、俗语和笑谈。</span>
<span className="v" id="v38" data-v="38" data-xref="哈该书 1:6; 弥迦书 6:15; 约珥 1:4"> 你必把许多种子带到田里，却收进很少，因为蝗虫必吞吃它。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 17:10–11; 约珥 2:2–4; 约拿 4:7"> 你要栽种葡萄园，修理它们，却不得喝酒，也不得收成，因为虫子必吃掉它们。</span>
<span className="v" id="v40" data-v="40" data-xref="弥迦书 6:15; 诗篇 23:5; 诗篇 104:15"> 你全境内必有橄榄树，却不得用油抹身，因为你的橄榄必掉落。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 28:32; 耶利米哀歌 1:5; 列王纪下 24:14"> 你必生儿育女，但他们不属你，因为他们必被掳去。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司 7:1–2; 申命记 28:38–39"> 你所有的树木和你地里的出产，必被蝗虫吞吃。</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 28:13; 撒母耳记上 13:19–23; 列王纪下 17:20"> 在你中间寄居的外族人，必在你以上升得越来越高；你却下降得越来越低。</span>
<span className="v" id="v44" data-v="44" data-xref="申命记 28:12–13; 耶利米哀歌 1:5"> 他必借给你，你却不能借给他；他必作首，你必作尾。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="申命记 28:15; 以赛亚书 1:20; 耶利米书 24:9–10"> 这一切咒诅必临到你，追赶你，追上你，直到你被毁灭；因为你没有听从耶和华你上帝的声音，没有遵守祂所吩咐你的诫命和律例。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 8:18; 申命记 28:37; 以西结 14:8"> 这些咒诅必在你和你的后裔身上成为记号和奇事，直到永远。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 16:11; 申命记 12:7–12; 尼希米记 9:35–37"> 因为你在万物丰足的时候，没有以喜乐和欢心事奉耶和华你的上帝；</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 28:13–14; 耶利米哀歌 5:2–6; 以西结 4:16–17"> 所以你必在饥饿、干渴、赤身露体、缺乏万物之中，事奉耶和华所差来攻击你的仇敌。祂必把铁轭加在你的颈项上，直到祂毁灭你。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米书 49:22; 耶利米书 48:40"> 耶和华必使一个民族从远方、从地极起来攻击你，像鹰飞来一样；那是一个你不懂它语言的民族，</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 47:6; 历代志下 36:17; 路加福音 21:23–24"> 一个面貌凶狠的民族，不尊重年老的，也不恩待年幼的。</span>
<span className="v" id="v51" data-v="51" data-xref="申命记 28:33; 以赛亚书 62:8; 利未记 26:26"> 他们必吃掉你牲畜所生的和你地所产的，直到你被毁灭。他们也不给你留下五谷、新酒、油、牛群所增的或羊群所出的，直到他们使你灭亡。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米书 52:4–7; 以西结 4:1–8; 马太福音 24:15–16"> 他们必在你各城门内围困你，直到你在全地所倚靠的高大坚固城墙都倒塌。他们必在耶和华你上帝赐给你的全地，在你各城门内围困你。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米书 19:9; 利未记 26:29"> 在围困和你的仇敌使你受的困苦中，你必吃自己身所生的，就是耶和华你上帝赐给你的儿女的肉。</span>
<span className="v" id="v54" data-v="54" data-xref="申命记 15:9; 马太福音 20:15; 申命记 13:6"> 你中间柔弱而极其娇嫩的男人，他的眼必恶待自己的兄弟、他所爱的妻子，以及他还存留的儿女，</span>
<span className="v" id="v55" data-v="55" data-xref="耶利米书 34:2; 耶利米书 52:6; 耶利米书 5:10"> 以致他不给他们任何他所要吃的儿女的肉；因为在围困和你的仇敌在你各城门内使你受的困苦中，他已经一无所剩。</span>
<span className="v" id="v56" data-v="56" data-xref="申命记 28:54; 以赛亚书 3:16; 耶利米哀歌 4:3–6"> 你中间柔弱娇嫩的女人，因娇嫩柔弱，连脚掌踏在地上都不敢，她的眼必恶待她所爱的丈夫、她的儿子、她的女儿，</span>
<span className="v" id="v57" data-v="57" data-xref="以赛亚书 49:15; 创世记 49:10"> 以及她两腿之间生下的婴孩和她所生的儿女；因为在围困和你的仇敌在你城门内使你受的困苦中，她因缺乏万物，就要暗中吃他们。</span>
<span className="v" id="v58" data-v="58" data-xref="以赛亚书 42:8; 耶利米书 7:9–10; 玛拉基书 1:14"> 如果你不谨守遵行写在这书上的这律法的一切话，好敬畏这荣耀而可畏的名，就是耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="英文中全大写的 LORD 或 GOD 源自希伯来文 יהוה Yahweh，除非另有说明是源自短式 יה Yah。">a</a></sup>你的上帝，</span>
<span className="v" id="v59" data-v="59" data-xref="马可福音 13:19; 申命记 28:46; 但以理 9:12"> 那么耶和华必使你和你后裔所受的灾祸可畏，就是重大而长久的灾祸，以及严重而长久的疾病。</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 7:15; 出埃及记 15:26; 申命记 28:27"> 祂必使你所惧怕的埃及各样疾病再次临到你；它们必紧紧缠住你。</span>
<span className="v" id="v61" data-v="61" data-xref="申命记 4:25–26"> 还有一切没有写在这律法书上的疾病和灾祸，耶和华也必使它们临到你，直到你被毁灭。</span>
<span className="v" id="v62" data-v="62" data-xref="申命记 10:22; 尼希米记 9:23; 申命记 4:27"> 你们的人数虽然曾像天上的星那样众多，却必剩下很少；因为你没有听从耶和华你上帝的声音。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米书 32:41; 申命记 30:9"> 从前耶和华怎样喜悦你们，要善待你们，使你们增多，耶和华也照样必喜悦你们，使你们灭亡，毁灭你们。你必从你进去要占有的地上被拔除。</span>
<span className="v" id="v64" data-v="64" data-xref="申命记 4:27–28; 利未记 26:33; 耶利米书 16:13"> 耶和华必把你分散在万民中，从地的一端到地的另一端。在那里，你必事奉你和你列祖都不认识的别的神明，就是木头和石头。</span>
<span className="v" id="v65" data-v="65" data-xref="利未记 26:36; 罗马书 11:10; 阿摩司 9:4"> 在这些民族中，你必不得安宁，你的脚掌也不得安歇；耶和华却要在那里赐给你战抖的心、衰残的眼目和憔悴的灵魂。</span>
<span className="v" id="v66" data-v="66" data-xref="耶利米哀歌 1:13; 希伯来书 10:27; 启示录 6:15–17"> 你的性命必在你面前悬而不定。你必昼夜惧怕，对自己的性命没有把握。</span>
<span className="v" id="v67" data-v="67" data-xref="申命记 28:34; 约伯记 7:3–4; 启示录 9:6"> 早晨你要说：“但愿到了晚上！”晚上你要说：“但愿到了早晨！”这是因为你心中所惧怕的恐惧，以及你眼中所看见的景象。</span>
<span className="v" id="v68" data-v="68" data-xref="耶利米书 44:12; 耶利米书 43:7; 何西阿 8:13"> 耶和华必用船把你带回埃及，走我曾告诉你永远不会再见的那条路。在那里，你们要把自己卖给仇敌作男女奴隶，却没有人买你们。</span>

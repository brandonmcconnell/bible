<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 21:5; 罗马书 9:8; 加拉太书 3:26"> 你们是耶和华你们上帝的儿女。不可为死人割伤自己，也不可剃去额上的头发。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:6; 利未记 20:26; 出埃及记 19:5–6"> 因为你是归耶和华你上帝为圣的子民；耶和华已经从地面上万民中拣选你，作祂自己拥有的子民。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结 4:14; 罗马书 14:14; 利未记 20:25"> 凡可憎的东西，你都不可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:2–45; 使徒行传 10:14; 列王纪上 4:23"> 你们可以吃的动物是这些：牛、绵羊、山羊、</span>
<span className="v" id="v5" data-v="5"> 鹿、瞪羚、狍子、野山羊、羱羊、羚羊和岩羚羊。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多后书 6:17; 诗篇 1:1–2"> 凡动物中分蹄、蹄裂成两瓣又反刍的，你们都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:22–23; 提多书 1:16; 提摩太后书 3:5"> 但那些反刍或分蹄的动物中，这些你们不可吃：骆驼、野兔和兔子。因为它们反刍却不分蹄，对你们是不洁净的。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:26–27; 以赛亚书 66:3; 彼得后书 2:22"> 猪，因为它分蹄却不反刍，对你们是不洁净的。你们不可吃它们的肉，也不可摸它们的尸体。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 11:9–12"> 水中所有的生物，你们可以吃这些：凡有鳍有鳞的，你们都可以吃。</span>
<span className="v" id="v10" data-v="10"> 凡没有鳍没有鳞的，你们都不可吃；对你们是不洁净的。</span>
<span className="v" id="v11" data-v="11"> 凡洁净的鸟，你们都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 11:13–19"> 但这些你们不可吃：鹰、秃鹫、鱼鹰、</span>
<span className="v" id="v13" data-v="13"> 红鸢、隼，以及各类的鸢、</span>
<span className="v" id="v14" data-v="14"> 各类的乌鸦、</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 30:29"> 鸵鸟、猫头鹰、海鸥，以及各类的鹰、</span>
<span className="v" id="v16" data-v="16"> 小鸮、大鸮、角鸮、</span>
<span className="v" id="v17" data-v="17"> 鹈鹕、秃鹫、鸬鹚、</span>
<span className="v" id="v18" data-v="18"> 鹳，各类的鹭鸶，戴胜和蝙蝠。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:19; 利未记 11:20–23"> 凡有翅膀的爬行物，对你们都是不洁净的，不可吃。</span>
<span className="v" id="v20" data-v="20"> 凡洁净的鸟，你们都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:19; 出埃及记 34:26; 利未记 22:8"> 凡自死的东西，你们都不可吃。可以给住在你城门内的寄居者吃，或卖给外族人；因为你是归耶和华你上帝为圣的子民。<br />不可用山羊羔母亲的奶煮山羊羔。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 10:37; 申命记 12:17; 申命记 26:12–15"> 你每年田地所出的，就是你种子的一切出产，都要献上十分之一。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:5–7; 申命记 4:10; 申命记 12:17–18"> 你要在耶和华你上帝面前，在祂所选择使祂的名居住的地方，吃你五谷、新酒和油的十分之一，以及你牛群羊群中头生的；这样，你就可以学习常常敬畏耶和华你的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:21; 申命记 12:5; 申命记 11:24"> 如果路程对你太远，以致你不能把它带去，因为耶和华你上帝所选择安置祂名的地方离你太远；当耶和华你的上帝赐福给你的时候，</span>
<span className="v" id="v25" data-v="25"> 你就要把它换成银钱，把银钱包在手里，前往耶和华你上帝所选择的地方。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:7; 申命记 12:7; 马太福音 21:12"> 你可以用那银钱换取凡你心所愿的：牛、羊、酒、浓酒，或凡你心所要求的。你要在那里，在耶和华你上帝面前吃喝，并且欢乐，你和你的家人都要欢乐。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:20; 申命记 14:29; 申命记 12:12"> 住在你城门内的利未人，你不可撇弃，因为他在你中间没有份，也没有产业。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 14:22; 阿摩司 4:4; 申命记 26:12–15"> 每逢三年末了，你要把那一年你一切出产的十分之一都拿出来，存放在你的城门内。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 15:10; 申命记 14:27; 箴言 19:17"> 利未人，因为他在你中间没有份，也没有产业，还有住在你中间的寄居者、孤儿和寡妇，就是在你城门内的人，都要来，吃得饱足；这样，耶和华你的上帝就会在你手所做的一切工作上赐福给你。</span>
</div>

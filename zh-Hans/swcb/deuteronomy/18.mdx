<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="DEU" data-book-slug="deuteronomy" data-book-name="申命记" data-chapter="18" data-verses="22">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 18:8–9; 申命记 10:9; 哥林多前书 9:13–14"> 祭司和利未人，就是利未全支派，在以色列中不可有份，也不可有产业。他们要吃献给耶和华的火祭和祂的份。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 1:5–6; 诗篇 84:11; 彼得前书 2:5"> 他们在弟兄中不可有产业。耶和华是他们的产业，正如祂对他们所说的。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 7:30–34; 申命记 12:27"> 祭司从百姓，就是从献祭的人那里，无论献的是牛是羊，都应得这一份：他们要把前腿、两腮和内脏给祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 12:44–47; 民数记 18:12–24; 历代志下 31:4–10"> 你要把你的五谷、新酒和油初熟的，以及你羊群中初剪的羊毛给他。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:8; 民数记 3:10; 出埃及记 28:1–14"> 因为耶和华你的上帝从你众支派中拣选了他和他的子孙，使他们永远站立，奉耶和华的名事奉。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 35:2–3; 申命记 12:5; 申命记 16:2"> 如果一个利未人，从以色列全地他所寄居的任何一座城门出来，照着他心中一切的愿望，来到耶和华所要选择的地方，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:2–4"> 他就可以奉耶和华他上帝的名事奉，像他所有站在那里、在耶和华面前事奉的利未弟兄一样。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 12:44; 尼希米记 12:47; 历代志下 31:4"> 除了他变卖祖业所得的以外，他们还要有同等的份额可吃。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 12:29–31; 利未记 18:26–27; 利未记 18:30"> 你进入耶和华你的上帝赐给你的地以后，不可学习效法那些列国可憎的事。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 19:31; 出埃及记 22:18; 利未记 19:26"> 你们中间不可有人使自己的儿子或女儿经火，也不可有占卜的、算命的、观兆的、行邪术的，</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 19:31; 撒母耳记上 28:11–14"> 或念咒的，或求问交鬼的，或巫师，或求问死人的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:24; 申命记 9:4; 利未记 18:27"> 因为凡行这些事的人，都是耶和华所憎恶的。因这些可憎的事，耶和华你的上帝正把他们从你面前赶出去。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:48; 创世记 17:1; 创世记 6:9"> 你要在耶和华你的上帝面前纯全。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 14:16; 申命记 18:10; 创世记 20:6"> 因为你将要赶出的这些列国听从行邪术的和占卜的；至于你，耶和华你的上帝不准你这样做。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 3:22–23; 使徒行传 7:37; 约翰福音 1:45"> 耶和华你的上帝要从你中间、从你的弟兄中，为你兴起一位像我一样的先知。你们要听从他。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 20:19; 申命记 5:23–28; 申命记 9:10"> 这正是你在何烈，在会众聚集的日子，向耶和华你的上帝所求的一切；你说：“不要让我再听见耶和华我上帝的声音，也不要让我再看见这大火，免得我死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命记 5:28"> 耶和华对我说：“他们所说的话说得好。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 18:15; 约翰福音 8:28; 约翰福音 12:49–50"> 我要从他们弟兄中，为他们兴起一位像你一样的先知。我要把我的话放在他口中，他要把我吩咐他的一切都告诉他们。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 3:22–23; 希伯来书 2:3; 希伯来书 10:26"> 凡不听从他奉我名所说我话的人，我必向那人追讨。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 13:1–5; 耶利米书 27:15; 耶利米书 23:13–15"> 但若有先知擅自奉我的名说我没有吩咐他说的话，或奉别神的名说话，那先知必须死。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1–3; 帖撒罗尼迦前书 5:24; 启示录 2:2"> 你心里也许会说：“我们怎能知道哪一句话不是耶和华所说的呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 18:20; 列王纪下 20:1; 耶利米书 28:1–17"> 当先知奉耶和华的名说话，如果那事没有随之发生，也没有成就，那就是耶和华没有说过的话；是那先知擅自说的。你不要怕他。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 11:31; 申命记 4:38; 申命记 1:28"> 以色列啊，你要听！你今日要过约旦河，进去赶出比你更大、更强的列国，夺取又大又坚固、高耸入天的城邑，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 13:22; 那鸿书 1:6; 申命记 7:24"> 又要面对高大强壮的人民，就是亚衲族人；你认识他们，也听人说过：“谁能在亚衲的子孙面前站立得住呢？”</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:24; 希伯来书 12:29; 罗马书 8:31"> 所以你今日要知道，耶和华你的上帝是在你前面过去的那一位，如同吞灭的火。祂必毁灭他们，使他们在你面前屈服。这样，你就要把他们赶出去，使他们迅速灭亡，正如耶和华对你所说的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 8:17; 申命记 9:5; 申命记 18:9–14"> 耶和华你的上帝把他们从你面前赶出去以后，你不可心里说：“耶和华使我进来得这地，是因我的义。”其实耶和华把他们从你面前赶出去，是因为这些国家的邪恶。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 3:5; 创世记 17:8; 创世记 26:4"> 你进去得他们的地，并不是因你的义，也不是因你心里的正直；乃是因为这些国家的邪恶，耶和华你的上帝才把他们从你面前赶出去，并且要成就耶和华向你列祖亚伯拉罕、以撒、雅各起誓所说的话。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:16; 使徒行传 7:51; 申命记 31:27"> 所以你要知道，耶和华你的上帝把这美地赐给你为业，并不是因你的义，因为你是硬着颈项的百姓。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:2; 出埃及记 14:11; 民数记 21:5"> 你要记住，不可忘记，你在旷野怎样惹耶和华你的上帝发怒。从你离开埃及地的那一天起，直到你们来到这地方，你们一直悖逆耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:19–22; 出埃及记 32:16; 出埃及记 32:7–10"> 在何烈山，你们也惹耶和华发怒，耶和华就向你们发怒，要毁灭你们。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 34:28; 出埃及记 24:18; 列王纪上 19:8"> 我上山去领受石版，就是耶和华与你们所立之约的版；那时我在山上停留了四十昼夜，没有吃饭，也没有喝水。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:4"> 耶和华把两块石版交给我，是上帝的指头写的；版上写着耶和华在聚会的日子，在山上从火中对你们所说的一切话。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 9:9; 民数记 10:33; 希伯来书 8:6–10"> 过了四十昼夜，耶和华把两块石版，就是约版，交给了我。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:7–8; 申命记 31:29; 士师记 2:17"> 耶和华对我说：“起来，快快从这里下去；因为你从埃及领出来的百姓已经败坏了自己。他们很快偏离了我所吩咐他们的道路，为自己铸造了一个像！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 9:6; 列王纪下 17:14; 申命记 10:16"> 耶和华又对我说：“我看见这百姓；看哪，他们是硬着颈项的百姓。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 29:20; 出埃及记 32:10–13; 诗篇 9:5"> 你且由着我，我要毁灭他们，从天下涂抹他们的名；我要使你成为比他们更强大、更兴盛的国家。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:18; 申命记 5:23; 申命记 4:11"> 于是我转身从山上下去；山正被火焚烧，两块约版在我两手中。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 32:19; 使徒行传 7:40–41"> 我一看，看哪，你们得罪了耶和华你们的上帝，为自己铸造了一只牛犊；你们很快偏离了耶和华所吩咐你们的道路。</span>
<span className="v" id="v17" data-v="17"> 我拿起那两块版，从我两手中扔出去，在你们眼前摔碎了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:28; 申命记 9:9; 诗篇 106:23"> 我又像先前一样俯伏在耶和华面前四十昼夜，没有吃饭，也没有喝水；这是因为你们所犯的一切罪，就是行耶和华眼中看为恶的事，惹祂发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 10:10; 出埃及记 32:14; 雅各书 5:16–17"> 因为我惧怕耶和华向你们发出的怒气和烈怒，祂要毁灭你们。但那一次耶和华也听了我。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 32:35; 出埃及记 32:21; 希伯来书 7:26–28"> 耶和华也向亚伦大大发怒，要毁灭他。那时我也为亚伦祷告。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 32:20; 以赛亚书 31:7; 以赛亚书 2:18–21"> 我把你们所犯的罪，就是你们所造的那只牛犊，拿来用火焚烧，又把它捣碎，磨得极细，细如尘土；我把它的尘土撒在从山上流下来的溪水中。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 11:34; 出埃及记 17:7; 民数记 11:1–5"> 在他备拉、玛撒、基博罗哈他瓦，你们都惹耶和华发怒。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 106:24–25; 希伯来书 4:2; 诗篇 78:22"> 耶和华从加低斯巴尼亚差遣你们，说：“你们上去，得我所赐给你们的地。”那时你们却悖逆耶和华你们上帝的命令，不信祂，也不听从祂的声音。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 31:27; 使徒行传 7:51; 申命记 9:6–7"> 自从我认识你们的日子以来，你们一直悖逆耶和华。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 9:18; 申命记 9:16"> 因此我俯伏在耶和华面前，就是我俯伏的那四十昼夜，因为耶和华曾说要毁灭你们。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 32:11–13; 提多书 2:14; 诗篇 107:2"> 我向耶和华祷告说：“主耶和华啊，求你不要毁灭你的百姓，你的产业，就是你以你的伟大所救赎、用大能的手从埃及领出来的。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 14:21; 弥迦书 7:18–19; 撒母耳记上 25:25"> 求你记念你的仆人亚伯拉罕、以撒、雅各；不要看这百姓的顽梗，也不要看他们的邪恶和罪，</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:16; 出埃及记 32:12"> 免得你领我们出来的那地说：‘耶和华不能把他们领进祂所应许给他们的地，又因为祂恨他们，所以把他们领出来，要在旷野杀死他们。’</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 1:10; 列王纪上 8:51; 申命记 9:26"> 然而他们是你的百姓，你的产业，是你用大能和伸出来的膀臂领出来的。”</span>
</div>
</div>

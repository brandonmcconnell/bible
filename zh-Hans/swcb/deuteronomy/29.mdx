<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 5:2–3; 希伯来书 8:9; 出埃及记 24:2–8"> 这些是耶和华在摩押地吩咐摩西与以色列人所立之约的话，是在祂于何烈山与他们所立的约之外的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:4; 出埃及记 8:12; 约书亚记 24:5–6"> 摩西召集全以色列，对他们说：<br />你们亲眼看见耶和华在埃及地向法老、向他所有臣仆、向他全地所行的一切；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:32–35; 尼希米记 9:9–11; 申命记 7:18–19"> 就是你们亲眼所见的大试炼、神迹和那些大奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:18; 以赛亚书 6:9–10; 箴言 20:12"> 但直到今日，耶和华还没有赐给你们明白的心、能看的眼睛、能听的耳朵。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 8:4; 尼希米记 9:21; 申命记 8:2"> 我在旷野带领你们四十年；你们身上的衣服没有穿旧，脚上的鞋也没有穿旧。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:3; 以弗所书 5:18; 哥林多前书 9:25"> 你们没有吃饼，也没有喝酒和烈酒，为要使你们知道我是耶和华你们的上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:24–17; 民数记 32:33–42; 诗篇 135:10–12"> 你们来到这地方的时候，希实本王西宏和巴珊王噩出来与我们交战，我们击败了他们。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 3:12–13; 民数记 32:33"> 我们夺取了他们的地，把它赐给吕便人、迦得人和玛拿西半个支派为产业。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:3; 申命记 4:6; 路加福音 11:28"> 所以你们要谨守这约的话，并遵行，好使你们在所做的一切事上亨通。</span>
<span className="v" id="v10" data-v="10" data-xref="约珥 2:16–17; 启示录 20:12; 申命记 31:12–13"> 你们今日都站在耶和华你们上帝面前：你们的首领、你们的支派、你们的长老和你们的官长，就是以色列所有的男子，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:38; 约书亚记 9:21–27; 出埃及记 12:48–49"> 你们的孩子、你们的妻子，以及你营中间的寄居者，从为你劈柴的到为你打水的，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:12–15; 列王纪下 11:17; 申命记 5:2–3"> 为要使你进入耶和华你上帝的约，进入祂的誓言，就是耶和华你上帝今日与你所立的，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 6:7; 创世记 17:7; 申命记 28:9"> 好使祂今日确立你作祂的子民，祂作你的上帝，正如祂对你所说的，也如祂向你的列祖亚伯拉罕、以撒、雅各所起的誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:31–34; 希伯来书 8:7–12"> 我立这约和这誓，不只是与你们立，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:39; 哥林多前书 7:14; 耶利米书 50:5"> 也是与今日和我们一同站在耶和华我们上帝面前的人，以及今日不在这里与我们同在的人立</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 2:19; 申命记 2:9; 申命记 2:4"> （因为你们知道我们怎样住在埃及地，也知道我们怎样从你们所经过的列国中间经过；</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:36"> 你们也看见了他们中间那些可憎之物，以及他们用木头、石头、银子、金子所造的偶像）；</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:15; 申命记 11:16–17; 申命记 13:1–15"> 免得你们中间有男人、女人、家族或支派，今日心里偏离耶和华我们的上帝，去事奉那些民族的神；免得你们中间有根结出苦毒的毒物；</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:24; 民数记 15:30; 民数记 15:39"> 免得他听见这咒诅的话，心里却自称有福，说：“我虽然随从自己顽梗的心而行，也必平安，”以致湿的和干的一同毁灭。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 74:1; 诗篇 79:5; 申命记 9:14"> 耶和华必不赦免他；那时，耶和华的怒气和祂的忌恨要向那人发作如烟，这书上所写的一切咒诅都必临到他，耶和华必从天下涂抹他的名。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:41; 约书亚记 7:1–26; 以西结 13:9"> 耶和华必照着这律法书上所写之约的一切咒诅，把他从以色列众支派中分别出来，使他遭受灾祸。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 19:8"> 将来的世代，就是你们以后兴起的子孙，以及从远方来的外国人，看见那地的灾祸和耶和华使那地所患的疾病时，必说：</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅书 2:9; 耶利米书 17:6; 以赛亚书 34:9"> 那全地都是硫磺、盐和焚烧之地，不能播种，不能出产，其中也没有青草生长，好像耶和华在怒气和烈怒中所倾覆的所多玛、蛾摩拉、押玛和洗扁一样。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 22:8–9; 列王纪上 9:8–9; 罗马书 2:5"> 甚至万国都必说：“耶和华为什么这样待这地？这大怒的烈焰是什么意思？”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:9; 以赛亚书 47:6; 耶利米书 50:7"> 那时人必说：“这是因为他们离弃了耶和华他们列祖之上帝的约，就是祂领他们出埃及地时与他们所立的约；</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:64; 士师记 2:12–13; 士师记 5:8"> 他们去事奉别的神，敬拜那些他们不认识、祂也没有分派给他们的神。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理 9:11–14; 申命记 28:15–68; 申命记 27:15–26"> 因此，耶和华的怒气向这地发作，把这书上所写的一切咒诅都降在其上。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 7:20; 列王纪上 14:15; 诗篇 52:5"> 耶和华在怒气、烈怒和大愤恨中，把他们从自己的土地上连根拔出，抛到别的地去，就像今日一样。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理 2:22; 使徒行传 1:7; 罗马书 11:33–34"> 隐秘的事属于耶和华我们的上帝；但显明的事永远属于我们和我们的子孙，好使我们遵行这律法的一切话。</span>
</div>

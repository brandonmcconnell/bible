<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:40; 约伯记 7:1; 申命记 4:19"> 这些是你们在耶和华你们列祖的上帝赐给你们为业之地，一生在地上存活的日子，都要谨守遵行的律例和典章。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:5; 列王纪下 16:4; 民数记 33:51–52"> 你们要彻底毁坏那些你们将要赶出的民族敬奉他们神明的一切地方：在高山上、冈陵上、各青翠树下。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 2:2; 撒迦利亚书 13:2; 民数记 33:52"> 你们要拆毁他们的祭坛，打碎他们的柱像，用火焚烧他们的亚舍拉柱，砍倒他们神明的雕刻像，从那地方除灭它们的名。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:23; 申命记 20:18; 申命记 16:21–22"> 你们不可这样待耶和华你们的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 12:11; 申命记 26:2; 历代志下 7:12"> 但耶和华你们的上帝要从你们各支派中选择一个地方，立祂的名在那里；你们要寻求祂的居所，到那里去。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:19–20; 玛拉基书 3:10; 利未记 27:32–33"> 你们要把你们的燔祭、祭物、十分之一、手中的摇祭、所许的愿、甘心祭，以及牛群羊群中头生的，都带到那里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 12:18; 利未记 23:40; 申命记 14:26"> 你们和你们的家属要在那里，在耶和华你们的上帝面前吃，并且因你们手所办的一切，就是耶和华你们的上帝赐福给你们的，欢喜快乐。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 21:25; 士师记 17:6; 箴言 21:2"> 你们不可照我们今日在这里所做的一切去做，就是各人行自己眼中看为正的事；</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 8:56; 诗篇 95:11; 申命记 25:19"> 因为你们还没有到达耶和华你们的上帝所赐给你们的安息和产业。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 33:11; 以西结 34:28; 申命记 3:27"> 但你们过了约旦河，住在耶和华你们的上帝使你们承受为业的地，祂又使你们脱离四围所有仇敌而得安息，使你们安然居住，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 12:5; 申命记 15:20; 申命记 17:8"> 那时，耶和华你们的上帝所选择、使祂的名居住的地方，你们就要把我所吩咐你们的一切都带到那里：你们的燔祭、祭物、十分之一、手中的摇祭，以及你们向耶和华所许的一切上好的愿祭。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:7; 申命记 10:9; 申命记 26:12"> 你们和你们的儿子、女儿、男仆、女仆，以及你们城门内的利未人，都要在耶和华你们的上帝面前欢喜快乐，因为他在你们中间无份无业。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:28–32; 列王纪上 15:34; 历代志下 15:17"> 你要谨慎，不可在你所看见的任何地方献你的燔祭；</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 12:11; 哥林多后书 5:19; 申命记 12:5"> 只要在耶和华从你一个支派中所选择的地方，在那里献你的燔祭，在那里行我所吩咐你的一切。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 14:5; 申命记 15:22–23; 申命记 14:26"> 然而，在你各城门内，你可以照你心里一切所愿宰牲吃肉，按耶和华你的上帝所赐给你的福分而吃。不洁净的人和洁净的人都可以吃，就像吃羚羊和鹿一样。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:4; 申命记 15:23; 申命记 12:23–24"> 只是不可吃血；你要把血倒在地上，如同倒水一样。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 26:14; 申命记 12:6; 申命记 14:22–29"> 你的五谷、新酒和油的十分之一，牛群羊群中头生的，或你所许的任何愿祭、甘心祭、手中的摇祭，都不可在你城门内吃；</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:7; 申命记 14:23; 申命记 12:5"> 你和你的儿子、女儿、男仆、女仆，以及你城门内的利未人，都要在耶和华你的上帝面前，在耶和华你的上帝所选择的地方吃这些。你要在耶和华你的上帝面前，因你手所办的一切欢喜快乐。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 31:4–21; 尼希米记 10:34–39; 申命记 14:27–29"> 你要谨慎，只要你在自己的地上活着，就不可撇弃利未人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 19:8; 申命记 11:24; 出埃及记 34:24"> 当耶和华你的上帝照祂应许你的扩张你的疆界，而你说：“我想吃肉，”因为你心里想吃肉，你就可以照你心里一切所愿吃肉。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 12:5; 列王纪上 14:21; 申命记 16:11"> 如果耶和华你的上帝所选择立祂名的地方离你太远，你就可以照我所吩咐你的，从耶和华所赐给你的牛群羊群中宰牲；你可以在你城门内，照你心里一切所愿吃。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:15–16"> 正如羚羊和鹿怎样被人吃，你也要照样吃；不洁净的人和洁净的人都可以一样吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 17:11; 创世记 9:4; 利未记 17:13–14"> 只是你务必要不吃血；因为血就是生命。不可把生命和肉一起吃。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:16; 申命记 15:23"> 你不可吃血；要把血倒在地上，如同倒水一样。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:38; 申命记 4:40; 以赛亚书 3:10"> 你不可吃血，好使你和你以后你的子孙都得福，因为你行了耶和华眼中看为正的事。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 18:19; 民数记 5:9–10; 申命记 12:11"> 只是你所有的圣物和你所许的愿祭，你要带到耶和华所选择的地方去。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 1:13; 利未记 17:11; 利未记 1:9"> 你的燔祭，肉和血，都要献在耶和华你上帝的坛上。你祭物的血要倒在耶和华你上帝的坛上，肉你可以吃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 4:40; 约翰福音 15:14; 约翰福音 15:10"> 我吩咐你的这一切话，你都要谨守听从，好使你和你以后你的子孙永远得福，因为你行了耶和华你上帝眼中看为善、看为正的事。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 23:4; 申命记 19:1; 申命记 9:3"> 当耶和华你的上帝从你面前剪除那些民族，就是你进去要赶出的民族；你赶出他们，住在他们的地上，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:2; 以西结 20:32; 申命记 7:16"> 你要谨慎，免得他们从你面前被消灭以后，你陷入网罗去随从他们，又免得你寻问他们的神明，说：“这些民族怎样敬奉他们的神明？我也要照样行。”</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 32:35; 申命记 18:9–10; 列王纪下 17:15–17"> 你不可这样待耶和华你的上帝；因为凡耶和华所憎恶、祂所恨恶的可憎之事，他们都向自己的神明行了；他们甚至把自己的儿子和女儿用火焚烧，献给他们的神明。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 4:2; 启示录 22:18–19; 约书亚记 1:7"> 我吩咐你们的一切事，你们都要谨守遵行；不可加添，也不可删减。</span>
</div>

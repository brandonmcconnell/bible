<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:33–35; 申命记 1:4; 申命记 29:7"> 后来我们转回，沿着通往巴珊的路上去。巴珊王噩和他的众民都出来，在以得来与我们交战。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 2:10; 历代志下 20:17; 民数记 21:23–25"> 耶和华对我说：“不要怕他，因为我已经把他和他的众民，以及他的地，都交在你手中。你要怎样待住在希实本的亚摩利王西宏，也要怎样待他。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数记 21:35; 约书亚记 13:12; 约书亚记 13:30"> 于是耶和华我们的上帝也把巴珊王噩和他的众民都交在我们手中。我们击杀了他，直到没有一人给他留下。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 4:13; 约书亚记 12:4; 约书亚记 13:30–31"> 那时，我们夺取了他所有的城，没有一座城不是我们从他们手中夺来的，共六十座城，就是亚珥歌伯全境，巴珊王噩的国。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 1:28; 民数记 13:28; 希伯来书 11:30"> 这些城都有高墙、城门和门闩，都是坚固城；此外还有许多无城墙的乡村。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:34; 诗篇 135:10–12; 申命记 2:24"> 我们把这些城尽行毁灭，像对待希实本王西宏一样；每一座有人居住的城，连妇女和孩童，都尽行毁灭。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:35; 约书亚记 8:27; 约书亚记 11:11–14"> 但所有牲畜和城中的掠物，我们都夺来作为自己的战利品。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:9–12; 约书亚记 12:2–6; 民数记 32:33–42"> 那时，我们从约旦河外亚摩利人的两个王手中夺取了那地，从亚嫩谷直到黑门山。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 5:23; 诗篇 29:6; 以西结 27:5"> （西顿人称黑门为西连，亚摩利人称它为示尼珥。）</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 13:31; 约书亚记 13:11–12; 申命记 4:49"> 我们夺取了平原的所有城、整个基列和整个巴珊，直到撒迦和以得来，都是巴珊王噩国内的城。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:5; 耶利米书 49:2; 撒母耳记下 12:26"> （因为巴珊王噩是利乏音人余民中仅存的。看哪，他的床架是铁床架，不是在亚扪人的拉巴吗？按人的肘尺计算，长九肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>，宽四肘。）</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:36; 民数记 32:32–38; 约书亚记 13:8–28"> 那时，我们占领了这地：从亚嫩谷旁的亚罗珥，以及基列山地的一半和其中的城，我给了流便人和迦得人；</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:39–42; 约书亚记 13:29–32; 历代志上 5:23–26"> 基列其余的地方，以及整个巴珊，就是噩的国，我给了玛拿西半支派——亚珥歌伯全境，也就是整个巴珊。（这地称为利乏音人的地。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:41; 约书亚记 13:13; 撒母耳记下 3:3"> 玛拿西的儿子睚珥夺取了亚珥歌伯全境，直到基述人和玛迦人的边界，并按自己的名字称这些地方，就是巴珊，叫哈倭特·睚珥，直到今日。）</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:39–40; 约书亚记 17:1–3; 约书亚记 22:7"> 我把基列给了玛吉。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 21:24; 申命记 2:37; 撒母耳记下 24:5"> 我给流便人和迦得人的地，是从基列直到亚嫩谷，以谷中为界，并直到雅博河，就是亚扪人的边界；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 12:3; 创世记 14:3; 约书亚记 3:16"> 还有亚拉巴、约旦河和它的边界，从基尼烈直到亚拉巴海，就是盐海，在毗斯迦山坡东边以下。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 32:20–24; 约书亚记 4:12–13; 约书亚记 1:12–15"> 那时我吩咐你们说：“耶和华你们的上帝已经把这地赐给你们，使你们占有它。你们所有勇士都要带着兵器，在你们的弟兄以色列人前面过去。</span>
<span className="v" id="v19" data-v="19"> 但你们的妻子、孩童和牲畜（我知道你们有许多牲畜），可以住在我赐给你们的城里，</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 22:4; 约书亚记 22:8"> 直到耶和华使你们的弟兄像你们一样得享安息，并且他们也占有耶和华你们的上帝在约旦河外赐给他们的地。然后你们各人可以回到我赐给你们的产业那里。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 27:18–23; 哥林多后书 12:10; 诗篇 9:10"> 那时我吩咐约书亚说：“你的眼睛已经看见耶和华你的上帝向这两个王所做的一切；耶和华也必照样对待你将要渡过去所到之地的一切国。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 14:14; 申命记 20:4; 申命记 1:30"> 你们不要惧怕他们，因为耶和华你们的上帝亲自为你们争战。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 12:8–9"> 那时，我恳求耶和华说：</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 15:11; 申命记 11:2; 诗篇 71:19"> “主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“主”的词是“Adonai”。">b</a></sup>耶和华啊，你已经开始把你的伟大和你强有力的手显给你的仆人看。在天上或地上，有哪一个神能做像你这样的事，行像你这样的大能作为呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 4:21–22; 以西结 20:6; 出埃及记 3:8"> 求你让我过去，看约旦河外那美好的地、那美好的山地和黎巴嫩。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 1:37; 申命记 31:2; 历代志上 22:7–9"> 但耶和华因你们的缘故向我发怒，不听我。耶和华对我说：“够了！不要再向我提这事。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 27:12; 申命记 34:1–4; 创世记 13:14–15"> 你上毗斯迦山顶去，举目向西、向北、向南、向东观看；你要亲眼看见，因为你不能过这约旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 31:3; 申命记 31:7; 申命记 1:38"> 但你要委任约书亚，勉励他，使他刚强；因为他必在这百姓前面过去，并且要使他们承受你将要看见的那地为业。”</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:6; 申命记 4:46; 民数记 25:3"> 于是我们住在伯·毗珥附近的谷中。</span>
</div>
</div>

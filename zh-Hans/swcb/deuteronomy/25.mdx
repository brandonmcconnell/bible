<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 17:15; 申命记 1:16–17; 申命记 17:8–9"> 如果人与人之间有争讼，他们来到审判那里，审判官审判他们，就要判义人为义，定恶人为有罪。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:47–48; 马太福音 10:17; 使徒行传 5:40"> 如果恶人该受鞭打，审判官就要叫他俯伏在自己面前，按他的罪恶照数鞭打他。</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 18:3; 雅各书 2:2–3; 路加福音 15:30"> 可以判他受四十下，不可超过；免得若是超过这数目，多打他许多下，你的弟兄就在你眼中被贬低。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="提摩太前书 5:17–18; 哥林多前书 9:9–10; 箴言 12:10"> 牛踹谷的时候，不可笼住它的嘴。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:24; 路加福音 20:28; 马可福音 12:19"> 如果兄弟同住，其中一个死了，没有儿子，死者的妻子不可嫁给外人；她丈夫的兄弟要到她那里，娶她为妻，向她尽丈夫兄弟的义务。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 21:19; 诗篇 9:5; 诗篇 109:13"> 她所生的长子，要承继他死去兄弟的名，免得他的名从以色列中被涂抹。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路得记 4:5–6; 路得记 4:1–2"> 如果那人不愿娶他兄弟的妻子，他兄弟的妻子就要到城门那里去见长老，说：“我丈夫的兄弟拒绝在以色列中为他兄弟立名，不肯向我尽丈夫兄弟的义务。”</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 4:6"> 他城里的长老要召他来，和他说话。如果他坚持说：“我不愿娶她”，</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 4:7–8; 民数记 12:14; 以赛亚书 50:6"> 他兄弟的妻子就要当着长老的面到他跟前，从他脚上脱下他的鞋，吐唾沫在他脸上。她要回应说：“凡不建立自己兄弟家的人，都要这样待他。”</span>
<span className="v" id="v10" data-v="10"> 在以色列中，他的名要称为“被脱鞋之人的家”。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:9; 罗马书 3:8"> 如果两个人彼此争斗，其中一人的妻子走近，要从打她丈夫的人手中救出丈夫，伸手抓住那人的下体，</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 19:13; 申命记 19:21; 申命记 7:2"> 你就要砍断她的手。你的眼不可顾惜。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 11:1; 箴言 16:11; 利未记 19:35–37"> 你的袋子里不可有不同的法码，一重一轻。</span>
<span className="v" id="v14" data-v="14"> 你的家里不可有不同的量器，一大一小。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 20:12; 申命记 4:40; 以弗所书 6:3"> 你要有足量而公正的法码，要有足量而公正的量器，好使你在耶和华你上帝赐给你的土地上日子长久。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:1; 启示录 21:27; 申命记 22:5"> 因为凡做这些事的，凡行不义的，都是耶和华你上帝所憎恶的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 17:8–16; 民数记 25:17–18; 民数记 24:20"> 你要记得，你们出埃及时，亚玛力在路上怎样待你：</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 3:18; 诗篇 36:1; 箴言 16:6"> 他怎样在路上迎击你，趁你疲乏困倦的时候，攻击你后队中所有软弱的人；他并不敬畏上帝。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 17:14; 撒母耳记上 14:48; 出埃及记 17:16"> 所以，当耶和华你的上帝使你脱离四围所有仇敌、得享安息，在耶和华你的上帝赐给你作产业去拥有的土地上时，你要从天下涂抹亚玛力的记忆。你不可忘记。</span>
</div>

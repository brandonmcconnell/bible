<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 32:7–8; 申命记 31:8; 诗篇 20:7"> 你出去与仇敌争战的时候，看见马匹、战车，和人数比你多的百姓，不要怕他们；因为领你从埃及地上来的耶和华你的上帝与你同在。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 31:6; 历代志下 13:12; 民数记 10:8–9"> 你们临近战场的时候，祭司要上前来，对百姓讲话，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 13:6; 诗篇 3:6; 启示录 2:10"> 告诉他们：“以色列啊，要听！你们今天临近战场，要与仇敌争战。你们心里不要胆怯！不要害怕，不要惊慌，也不要因他们而恐惧；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 14:14; 申命记 3:22; 申命记 1:30"> 因为耶和华你们的上帝与你们同去，要为你们与仇敌争战，拯救你们。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米记 12:27; 民数记 31:14; 申命记 16:18"> 官长要对百姓说：“有谁建造了新房子，还没有奉献落成的？他可以离开，回自己的家去，免得他死在战场上，别人奉献那房子。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 19:23–25; 申命记 28:1–30; 耶利米书 31:5"> 有谁栽种了葡萄园，还没有享用其中果子的？他可以离开，回自己的家去，免得他死在战场上，别人享用那果子。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 24:5; 申命记 28:30; 路加福音 14:18–20"> 有谁已经聘定妻子，还没有迎娶她的？他可以离开，回自己的家去，免得他死在战场上，别人娶她。”</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 7:3; 申命记 1:28; 启示录 21:8"> 官长还要继续对百姓说：“有谁害怕、心里胆怯的？他可以离开，回自己的家去，免得他弟兄的心像他的心一样融化。”</span>
<span className="v" id="v9" data-v="9"> 官长对百姓讲完了话，就要在百姓前面设立军队的首领。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:5–6; 哥林多后书 5:18–1; 以弗所书 2:17"> 你临近一座城，要攻打它的时候，先要向它宣告和平。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 约书亚记 11:19–20; 约书亚记 16:10"> 如果它以和平回应你，向你开门，那么城里所有的人都要成为给你服苦役的人，服侍你。</span>
<span className="v" id="v12" data-v="12"> 如果它不肯与你和好，却要与你开战，你就要围困它。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 2:6–12; 列王纪上 11:15–16; 诗篇 110:1"> 耶和华你的上帝把它交在你手中时，你要用刀刃击杀城中所有的男子；</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 8:2; 约书亚记 22:8; 民数记 31:9"> 但妇女、孩童、牲畜，以及城里所有的一切，就是城里所有的掠物，你可以为自己夺取。耶和华你的上帝赐给你的仇敌的掠物，你可以享用。</span>
<span className="v" id="v15" data-v="15"> 对所有离你很远的城，就是不属于这些民族之城的城，你都要这样做。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 11:14; 民数记 21:2–3; 民数记 33:52"> 但这些民族的城，就是耶和华你的上帝赐给你作产业的城，凡有气息的，一个也不可存留活命；</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 34:5–6; 耶利米书 50:35–40; 申命记 7:1–2"> 却要把他们彻底毁灭：赫人、亚摩利人、迦南人、比利洗人、希未人和耶布斯人，正如耶和华你的上帝所吩咐你的；</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:30–31; 出埃及记 23:33; 以弗所书 5:11"> 免得他们教导你们效法他们为自己的神所行的一切可憎之事，使你们得罪耶和华你们的上帝。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 3:10; 约翰福音 15:2–8; 申命记 26:6"> 你围困一座城很久，与它交战，要攻取它的时候，不可挥斧毁坏那里的树木；因为你可以吃树上的果子。不可砍伐它们；田间的树岂是人，能被你围困吗？</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 26:15; 耶利米书 33:4; 传道书 9:14"> 只有你知道不是结果作食物的树，才可以毁坏、砍伐。你要筑起攻城工事，攻击与你交战的城，直到它陷落。</span>
</div>

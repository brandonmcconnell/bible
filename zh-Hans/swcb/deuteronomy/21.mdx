<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 26:21; 诗篇 5:6; 箴言 28:17"> 在耶和华你的上帝赐给你为业的地上，若发现有人被杀，倒在田野，不知道是谁击杀了他，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 13:3–4; 申命记 16:18–19"> 你的长老和审判官就要出去，量一量被杀的人周围各城的距离。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 19:2; 马太福音 11:28–30; 耶利米书 31:18"> 离被杀的人最近的那城，城中的长老要从牛群中取一头母牛犊，就是未曾使用、未曾负轭拉过的。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:21–24; 彼得前书 3:18"> 那城的长老要把母牛犊牵到有流水的山谷，那里未曾耕种，也未曾撒种；他们要在那里，在山谷中打断母牛犊的颈项。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:13; 玛拉基书 2:7; 申命记 10:8"> 利未子孙祭司要近前来，因为耶和华你的上帝拣选了他们事奉祂，并奉耶和华的名祝福；一切争讼和一切伤害案件，都要凭他们的话判定。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 73:13; 诗篇 26:6; 诗篇 51:7"> 离被杀的人最近的那城，所有长老都要在山谷中那被打断颈项的母牛犊上洗手。</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 21:21–23; 约伯记 21:31–34; 撒母耳记下 16:8"> 他们要回应说：“我们的手没有流这人的血，我们的眼也没有看见这事。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿 1:14; 列王纪下 24:4; 以西结 23:24–25"> 耶和华啊，求你赦免你所救赎的百姓以色列，不要使无辜人的血归在你的百姓以色列中间。”这血债就必为他们得赦免。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 19:12–13; 列王纪下 10:30–31; 申命记 13:18"> 这样，当你行耶和华眼中看为正的事时，就可以从你们中间除去无辜人的血债。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 20:10–16; 约书亚记 21:44"> 你出去与仇敌争战，耶和华你的上帝把他们交在你手中，你就把他们掳去；</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 创世记 34:3; 创世记 12:14–15"> 若你在俘虏中看见一个美貌的女子，恋慕她，想娶她为妻，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 14:9; 民数记 6:9; 以弗所书 4:22"> 你就要把她带回你的家。她要剃头，修剪指甲，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 45:10–11; 路加福音 14:26–27"> 脱去被掳时所穿的衣服，住在你家里，为她的父母哀哭整整一个月。之后，你可以与她同房，作她的丈夫，她也作你的妻子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 22:29; 创世记 34:2; 申命记 22:19"> 后来，若你不喜悦她，就要让她随意离去；但你绝不可为钱卖她。你不可把她当奴婢对待，因为你已经羞辱了她。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 29:33; 创世记 29:20; 创世记 29:18"> 若一个人有两个妻子，一个是他所爱的，另一个是他所不爱的；所爱的和所不爱的都给他生了儿女，而长子是那不受爱的妻子所生的，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:10; 历代志上 5:2; 历代志下 21:3"> 到他使儿子们承受他所有之物的日子，他不可把所爱之妻所生的儿子立为长子，越过那不受爱之妻所生的长子；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:3; 创世记 25:31–34; 诗篇 105:36"> 他必须承认那不受爱之妻所生的儿子为长子，把自己所有的一切给他双份，因为他是他力量的初始；长子的权利是他的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 19:3; 出埃及记 20:12; 阿摩司 4:11–12"> 若一个人有顽梗悖逆的儿子，不听从父亲的话，也不听从母亲的话；他们管教他，他仍不听他们，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:3; 申命记 21:2; 申命记 16:18"> 他的父亲和母亲就要抓住他，把他带到本城的长老那里，到本地的城门口。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> 他们要对本城的长老说：“我们这个儿子顽梗悖逆，不听从我们的话，是贪食好酒的人。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 19:19–20; 申命记 13:10–11; 利未记 24:16"> 本城所有的人都要用石头把他打死。这样，你就要从你们中间除掉这恶。全以色列听见，就必惧怕。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 19:31–38; 使徒行传 26:31; 路加福音 23:33"> 若有人犯了该死的罪，被处死，你把他挂在木头上，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:13; 约翰福音 19:31; 哥林多后书 5:21"> 他的尸体不可整夜留在木头上，必须当天把他埋葬；因为被挂的人是受上帝咒诅的。你不可玷污耶和华你的上帝赐给你为产业的地。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:14; 申命记 13:9; 申命记 6:1–10"> 当你进入耶和华你的上帝赐给你作产业的那地，得了它，并住在其中，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 23:19; 出埃及记 23:16; 以西结 44:30"> 你要从耶和华你的上帝赐给你的地上所收的一切初熟土产中取一些，放在筐子里，往耶和华你的上帝所选择、使祂的名居住的地方去。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 105:9–10; 申命记 19:17; 创世记 26:3"> 你要来到当时供职的祭司那里，对他说：“我今日向耶和华你的上帝声明，我已经来到耶和华向我们祖先起誓要赐给我们的地。”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 23:19; 马太福音 5:23–24; 希伯来书 13:10–12"> 祭司要从你手中接过筐子，放在耶和华你的上帝的祭坛前。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:27; 创世记 31:20"> 你要在耶和华你的上帝面前回应说：“我的父亲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“祖先”">a</a></sup>是一个将要灭亡的亚兰人。他下到埃及，在那里寄居，人数稀少；后来他在那里成了一个又大又强、人口众多的民族。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 1:11; 出埃及记 1:14; 出埃及记 5:23"> 埃及人恶待我们，苦害我们，把艰苦的劳役加在我们身上。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:23–4; 以弗所书 3:20–21; 出埃及记 3:9"> 于是我们向耶和华我们祖先的上帝呼求。耶和华听见我们的声音，看见我们的困苦、劳碌和受压迫。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:34; 申命记 5:15; 诗篇 78:12–13"> 耶和华用大能的手和伸出来的臂膀，用大可畏的事、神迹和奇事，领我们出埃及；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 诗篇 105:44; 诗篇 107:7–8"> 又把我们带到这地方，将这地赐给我们，就是流奶与蜜之地。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 26:2; 申命记 18:4; 启示录 22:9"> 现在，看哪，我把耶和华你赐给我的地上初熟的土产带来了。”你要把它放在耶和华你的上帝面前，并在耶和华你的上帝面前敬拜。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 16:11; 申命记 12:7; 腓立比书 4:4"> 你和利未人，以及在你中间寄居的外族人，都要因耶和华你的上帝赐给你和你家的各样美物而欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 27:30; 民数记 18:24; 腓立比书 4:18–19"> 当你在第三年，就是十分取一之年，把你一切出产的十分之一都取完以后，就要把它给利未人、寄居的外族人、孤儿和寡妇，使他们可以在你的城门内吃得饱足。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:176; 诗篇 119:153; 诗篇 119:141"> 你要在耶和华你的上帝面前说：“我已经把圣物从我家中拿出，也已经照你吩咐我的一切命令，把它们给了利未人、寄居的外族人、孤儿和寡妇。我没有违背你的任何命令，也没有忘记。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 7:20; 利未记 21:11; 何西阿 9:4"> 我在哀悼中没有吃过这圣物，在不洁净的时候也没有取出其中任何一部分，也没有为死人献上其中任何一部分。我听从了耶和华我上帝的声音；我都照你所吩咐我的做了。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:15; 撒迦利亚书 2:13; 耶利米书 31:23"> 求你从你的圣所，从天上垂看，赐福给你的百姓以色列，以及你赐给我们的土地，正如你向我们祖先起誓所应许的，就是流奶与蜜之地。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 12:1; 约翰福音 14:15; 约翰一书 5:2–3"> 今日，耶和华你的上帝吩咐你遵行这些律例和典章。所以你要尽心、尽性谨守遵行。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:7; 以赛亚书 12:2; 哥林多前书 6:19–20"> 你今日已经声明，耶和华是你的上帝，你要行祂的道路，谨守祂的律例、诫命和典章，并听从祂的声音。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 7:6; 申命记 14:2; 申命记 28:9"> 耶和华今日也声明，你是属祂自己产业的子民，正如祂应许你的；你要谨守祂的一切诫命。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 2:9; 申命记 7:6; 申命记 28:1"> 祂要使你在祂所造的万国之上得称赞、名声和尊荣，并且照祂所说的，使你成为归耶和华你的上帝为圣的子民。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 23:25–28; 约翰一书 4:1; 耶利米书 29:8"> 如果你们中间兴起一个先知，或一个做梦的人，给你一个神迹或奇事，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 13:6; 马太福音 7:22–23; 启示录 13:13–14"> 而他对你所说的神迹或奇事果然应验，说：“我们去随从别的神”——就是你素来不认识的——“并且事奉它们吧，”</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:2; 哥林多前书 11:19; 诗篇 66:10"> 你不可听从那先知的话，也不可听从那做梦的人；因为耶和华你们的上帝正在试验你们，要知道你们是否尽心、尽性地爱耶和华你们的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:10; 申命记 10:20; 哥林多前书 6:17"> 你们要跟从耶和华你们的上帝，敬畏祂，遵守祂的诫命，听从祂的声音。你们要事奉祂，紧紧依附祂。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:13; 申命记 18:20; 耶利米书 14:15"> 那先知或那做梦的人必须被处死，因为他讲了叛逆耶和华你们上帝的话；耶和华曾把你们从埃及地领出来，从为奴之家救赎出来，而他却要使你偏离耶和华你的上帝吩咐你走的道路。这样，你就要从你们中间除掉那恶。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 17:2–7; 彼得后书 2:1; 以弗所书 4:14"> 如果你的兄弟，就是你母亲的儿子，或你的儿子、女儿，或你怀中的妻子，或如同你自己生命的朋友，暗中引诱你说：“我们去事奉别的神吧”——就是你和你列祖素来不认识的；</span>
<span className="v" id="v7" data-v="7"> 是你们周围各民的神，或离你近，或离你远，从地这边直到地那边——</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 19:13; 箴言 1:10; 申命记 7:16"> 你不可依从他，也不可听从他；你的眼不可怜惜他，不可宽容他，也不可遮庇他；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:58; 路加福音 14:26; 马太福音 10:37"> 你必须杀死他。要处死他，你的手要先下在他身上，然后众百姓的手也要下在他身上。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 7:25; 利未记 24:14–16; 出埃及记 20:2"> 你要用石头打死他，因为他企图使你离开耶和华你的上帝；耶和华曾把你从埃及地、从为奴之家领出来。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 19:20; 申命记 17:13; 提摩太前书 5:20"> 全以色列听见了，就必惧怕，不再在你们中间行这样的恶事。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–17; 约书亚记 22:11–34"> 如果你听见有关耶和华你的上帝赐给你居住的某一座城的消息，说：</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 2:19; 申命记 13:2; 哥林多后书 6:15"> 有些恶徒从你们中间出来，诱惑他们城里的居民说：“我们去事奉别的神吧，”就是你们素来不认识的，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:4; 以赛亚书 11:3–4; 约翰福音 7:24"> 那么你要查问、探究，并且仔细询问。看哪，如果这事确实，证据确凿，证明这样的可憎之事在你们中间发生了，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 22:20; 利未记 27:28; 申命记 7:2"> 你就必须用刀刃击杀那城的居民，把那城和其中所有的一切，连牲畜，都用刀刃尽行毁灭。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 49:2; 约书亚记 8:28; 以赛亚书 25:2"> 你要把那城一切掠物聚集到街市中央，把那城和它所有的掠物用火焚烧，归给耶和华你的上帝。它要永远成为废墟，不得再被建造。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 26:4; 申命记 7:26; 约书亚记 7:26"> 不可让任何当灭之物留在你手中，好使耶和华转离祂烈怒的怒气，向你施怜悯，怜恤你，使你人数增多，正如祂向你列祖所起誓的，</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:28; 马太福音 7:21; 申命记 12:25"> 只要你听从耶和华你上帝的声音，遵守我今日吩咐你的一切诫命，行耶和华你上帝眼中看为正的事。</span>
</div>

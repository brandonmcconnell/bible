<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 10:5; 以西结 20:11; 利未记 18:5"> 现在，以色列啊，要听我教导你们遵行的律例和典章，好使你们可以存活，并且进去得耶和华——你们列祖的上帝——所赐给你们的地。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:32; 箴言 30:6; 启示录 22:18–19"> 我吩咐你们的话，你们不可加添，也不可删减，好使你们遵守我吩咐你们的、耶和华你们上帝的诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 25:1–9; 诗篇 106:28–29; 约书亚记 22:17"> 你们亲眼看见耶和华因巴力·毗珥所行的事；凡跟随巴力·毗珥的人，耶和华你的上帝都已经从你们中间除灭了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 10:20; 约书亚记 23:8; 约翰福音 6:67–69"> 但你们这些忠于耶和华你们上帝的人，今日都还活着。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 28:20; 帖撒罗尼迦前书 4:1–2; 希伯来书 3:5"> 看哪，我已经照耶和华我的上帝吩咐我的，把律例和典章教导你们，使你们在进去得为业的那地中照着遵行。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 28:28; 诗篇 111:10; 提摩太后书 3:15"> 所以你们要谨守遵行；因为这就是你们在万民眼前的智慧和聪明。他们听见这一切律例，就会说：“这大国的确是有智慧、有聪明的民。”</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:18; 撒母耳记下 7:23; 诗篇 34:18"> 哪一个大国有神与他们如此亲近，像耶和华我们的上帝在我们每逢求告祂时与我们亲近呢？</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 147:19–20; 罗马书 7:12–14; 诗篇 119:127–128"> 又哪一个大国有这样公义的律例和典章，像我今日摆在你们面前的这一切律法呢？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 6:7; 申命记 11:19; 诗篇 78:3–8"> 只是你要谨慎，殷勤保守自己，免得你忘记亲眼所看见的事，也免得它们在你一生的日子离开你的心；总要让你的儿女和你儿女的儿女知道——</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:9; 希伯来书 12:18–19; 出埃及记 19:16"> 就是你在何烈山站在耶和华你的上帝面前的那一天，耶和华对我说：“你要把百姓召集到我这里，我要使他们听见我的话，好使他们在世上活着的一切日子学习敬畏我，也可以教导他们的儿女。”</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 5:23; 出埃及记 19:16–18; 希伯来书 12:18–19"> 你们走近，站在山下。那山有火焰燃烧，直烧到天的深处，并有黑暗、云彩和幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:15; 申命记 5:4; 申命记 5:22"> 耶和华从火中对你们说话；你们听见话语的声音，却没有看见形状；只是有声音。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:28; 出埃及记 31:18; 申命记 9:9–11"> 祂向你们宣告祂的约，就是祂吩咐你们遵行的十条诫命；祂把它们写在两块石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 105:44–45; 以西结 21:1–23"> 那时耶和华吩咐我把律例和典章教导你们，使你们在过去得为业的那地遵行。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:12; 以赛亚书 40:18; 哥林多后书 4:4–6"> 所以你们要格外谨慎，因为耶和华在何烈山从火中对你们说话的那一天，你们没有看见任何形状，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:29; 申命记 5:8; 出埃及记 20:4–5"> 免得你们败坏自己，为自己雕刻偶像，做成任何形象的样式，像男或女的形像，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:23"> 地上任何走兽的形像，空中飞翔的任何有翅膀飞鸟的形像，</span>
<span className="v" id="v18" data-v="18"> 地上任何爬行动物的形像，地底下水中任何鱼的形像；</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:25; 申命记 17:3; 列王纪下 21:3"> 又免得你举目望天，看见太阳、月亮、星辰，就是天上的万象，就受引诱去敬拜它们、事奉它们；这些是耶和华你的上帝分给全天下万民的。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 8:51; 耶利米书 11:4; 出埃及记 19:5–6"> 但耶和华已经取了你们，把你们从铁炉中、从埃及领出来，使你们成为祂产业的子民，像今日一样。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:37; 民数记 20:12; 诗篇 106:32–33"> 此外，耶和华因你们的缘故向我发怒，起誓不准我过约旦河，也不准我进入耶和华你的上帝赐给你作产业的那美地；</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 3:25; 申命记 3:27; 彼得后书 1:13–15"> 我必须死在这地，不能过约旦河；但你们要过去，得那美地为业。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:9; 希伯来书 3:12; 约书亚记 23:16"> 你们要谨慎，免得忘记耶和华你们的上帝与你们所立的约，为自己雕刻偶像，做任何耶和华你的上帝禁止你造的形像。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:29; 那鸿书 1:6; 申命记 9:3"> 因为耶和华你的上帝是吞灭的火，是忌邪的上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 4:16; 何西阿 9:9; 哥林多前书 10:22"> 当你生了儿女和儿女的儿女，在那地住久以后，若败坏自己，雕刻任何形像的偶像，行耶和华你上帝眼中看为恶的事，惹祂发怒，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:1; 弥迦书 6:2; 耶利米书 22:29"> 我今日呼天唤地作证攻击你们：你们必很快从你们过约旦河去得为业的那地上完全灭亡。你们在那地的日子必不能长久，必被彻底毁灭。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 28:62–64; 利未记 26:33; 以西结 12:15"> 耶和华必把你们分散在万民中；在耶和华领你们去的列国中，你们剩下的人数必稀少。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:64; 耶利米书 16:13; 申命记 28:36"> 在那里，你们必事奉人手所造的神，就是木头和石头；它们不能看，不能听，不能吃，也不能闻。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:2; 耶利米书 29:12–14; 历代志下 15:4"> 但你们在那里必寻求耶和华你的上帝；你们若尽心尽性寻求祂，就必寻见祂。</span>
<span className="v" id="v30" data-v="30" data-xref="约珥 2:12–13; 耶利米书 23:20; 何西阿 3:5"> 当你遭遇患难，这一切事临到你，到了日后的日子，你必归向耶和华你的上帝，听从祂的声音。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 31:8; 诗篇 116:5; 尼希米记 9:31"> 因为耶和华你的上帝是怜悯人的上帝。祂必不撇下你，也不毁灭你，更不忘记祂向你列祖起誓与他们所立的约。</span>
<span className="v" id="v32" data-v="32" data-xref="约伯记 8:8; 马太福音 24:31; 诗篇 44:1"> 你且查问在你以前的往日，自从上帝在地上创造人以来，从天这边到天那边，是否曾有过这样的大事，或曾听见过像这样的事？</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 6:22; 申命记 5:24; 出埃及记 33:20"> 是否有民听见上帝从火中说话的声音，像你所听见的，还能存活呢？</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 26:8; 申命记 5:15; 出埃及记 6:6"> 或者，上帝可曾尝试去从一国中为自己取出一国，借着试炼、神迹、奇事、争战、大能的手、伸展的膀臂和大可畏的事，正如耶和华你们的上帝在埃及，在你们眼前为你们所行的一切呢？</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 45:18; 撒母耳记上 2:2; 以赛亚书 45:5"> 这些显给你看，是要使你知道，耶和华就是上帝；除祂以外，再没有别的。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 19:9; 出埃及记 19:19; 申命记 4:33"> 祂从天上使你听见祂的声音，为要教导你；在地上祂使你看见祂的大火，你又从火中听见祂的话。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 10:15; 以赛亚书 63:9; 出埃及记 13:9"> 因为祂爱你的列祖，所以拣选他们以后的后裔，并以祂的同在、以祂的大能，亲自把你从埃及领出来；</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 7:1; 申命记 9:1–5; 出埃及记 23:27–28"> 要从你面前赶出比你更大、更强的列国，领你进去，把他们的地赐给你作产业，像今日一样。</span>
<span className="v" id="v39" data-v="39" data-xref="约书亚记 2:11; 申命记 4:35; 历代志上 29:11"> 所以今日你要知道，也要记在心上：耶和华，祂是在上天下地的上帝；再没有别的。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 6:3; 以弗所书 6:3; 申命记 12:28"> 你要遵守祂的律例和祂的诫命，就是我今日吩咐你的，使你和你以后的子孙都可以蒙福，并使你在耶和华你的上帝赐给你的地上日子长久，直到永远。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:6; 民数记 35:14–15; 约书亚记 20:2–9"> 那时，摩西在约旦河东、向日出之地，分别出三座城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:18; 申命记 19:1–10; 民数记 35:15–28"> 使误杀人的可以逃到那里，就是素来不恨邻舍、无意中杀了他的；他逃到这些城中的一座，就可以存活：</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 20:8; 列王纪上 4:13; 约书亚记 21:27"> 为流便人分别了旷野中平原之地的比悉；为迦得人分别了基列的拉末；为玛拿西人分别了巴珊的哥兰。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命记 27:3; 利未记 27:34; 玛拉基书 4:4"> 这是摩西摆在以色列子孙面前的律法。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 2:3; 申命记 4:1; 诗篇 119:7"> 这些是摩西在以色列子孙出埃及以后对他们讲的法度、律例和典章，</span>
<span className="v" id="v46" data-v="46" data-xref="申命记 3:29; 申命记 4:47; 申命记 1:4–5"> 在约旦河东，伯·毗珥对面的谷中，在住希实本的亚摩利王西宏之地；摩西和以色列子孙出埃及以后击败了他。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 3:1–14; 民数记 21:33–35; 申命记 29:7–8"> 他们取得了他的地和巴珊王噩的地，就是约旦河东、向日出之地的两个亚摩利王的地；</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 3:9; 申命记 2:36; 申命记 3:12"> 从亚嫩谷边的亚罗珥，直到西云山（也称为黑门山），</span>
<span className="v" id="v49" data-v="49" data-xref="申命记 3:17; 约书亚记 13:20; 申命记 34:1"> 以及约旦河东的整个亚拉巴，直到亚拉巴海，毗斯迦山坡以下。</span>
</div>

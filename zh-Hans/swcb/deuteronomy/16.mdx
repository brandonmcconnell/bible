<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:18; 出埃及记 12:2–20; 出埃及记 13:4"> 你要守亚笔月，向耶和华你的上帝守逾越节；因为在亚笔月，耶和华你的上帝夜间把你从埃及领出来。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:5; 申命记 12:26; 路加福音 22:15"> 你要在耶和华所选择、使祂的名居住的地方，从羊群和牛群中，把逾越节的祭牲献给耶和华你的上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 12:39; 出埃及记 34:18; 出埃及记 12:19–20"> 你不可同祭牲吃有酵的饼；要同它吃无酵饼七天，就是困苦饼（因为你急忙从埃及地出来），使你一生的日子都记得你从埃及地出来的那一天。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 34:25; 出埃及记 12:10; 出埃及记 13:7"> 七天之内，在你全境中不可见有酵；你第一天晚上所献祭牲的肉，也不可留到早晨。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 16:2; 申命记 12:5–6"> 在耶和华你的上帝赐给你的任何城门内，你不可献逾越节的祭牲；</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 12:5; 出埃及记 12:6–9; 民数记 9:11"> 只可在耶和华你的上帝所选择、使祂的名居住的地方，在晚上日落的时候，就是你从埃及出来的时节，在那里献逾越节的祭牲。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 35:13; 出埃及记 12:8–9; 约翰福音 2:23"> 你要在耶和华你的上帝所选择的地方烤了吃。早晨你就回到你的帐棚去。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 13:6–8; 利未记 23:6–8; 利未记 23:36"> 六天你要吃无酵饼；第七天要向耶和华你的上帝守严肃会，什么工都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 34:22; 出埃及记 23:16; 使徒行传 2:1"> 你要为自己数算七个星期。从你开始向站着的庄稼下镰刀的时候起，要开始数算七个星期。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 16:2; 利未记 12:8; 玛拉基书 3:10–11"> 你要向耶和华你的上帝守七七节，照耶和华你的上帝赐福给你的程度，献上你手中甘心祭的礼物。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 12:7; 申命记 12:12; 申命记 12:18"> 你和你的儿子、女儿、男仆、女仆，以及你城门内的利未人，还有在你们中间的寄居者、孤儿和寡妇，都要在耶和华你的上帝所选择、使祂的名居住的地方，在耶和华你的上帝面前欢乐。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 15:15; 耶利米哀歌 3:19–20; 罗马书 6:17–18"> 你要记得你在埃及作过奴隶；你要谨守遵行这些律例。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 23:16; 约翰福音 7:2; 历代志下 5:3"> 你从禾场和酒榨收聚之后，要守住棚节七天。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 8:9–12; 申命记 16:11; 以赛亚书 30:29"> 你守节的时候要欢乐；你和你的儿子、女儿、男仆、女仆，以及你城门内的利未人、寄居者、孤儿和寡妇，都要欢乐。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 23:36–42; 申命记 30:16; 申命记 16:10"> 你要在耶和华所选择的地方，向耶和华你的上帝守节七天，因为耶和华你的上帝必在你一切出产和你手所做的一切工作上赐福给你，你就要全然喜乐。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 诗篇 96:8; 哈该书 1:9"> 你所有的男子，每年三次要在耶和华你的上帝所选择的地方朝见祂：在无酵节、七七节和住棚节。他们不可空手朝见耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 9:6–7; 哥林多后书 8:12; 申命记 16:10"> 每个人都要照自己的能力，按耶和华你的上帝赐给你的福分奉献。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 23:4; 出埃及记 18:25–26; 罗马书 13:1–6"> 你要在耶和华你的上帝赐给你的各城门内，按你的各支派，为自己设立审判官和官员；他们要用公义的判决审判百姓。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 19:15; 出埃及记 23:2; 箴言 17:23"> 你不可歪曲公正；不可偏待人；不可收受贿赂，因为贿赂使有智慧的人眼瞎，扭曲义人的话。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 4:8; 以西结 18:9; 以西结 18:5"> 你要追求全然公义的事，使你可以存活，并承受耶和华你的上帝赐给你的地。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 33:3; 列王纪下 17:16; 出埃及记 34:13"> 你为自己筑耶和华你的上帝的祭坛时，不可在坛旁为自己栽种任何树木作亚舍拉。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 26:1; 出埃及记 20:4; 撒迦利亚书 8:17"> 也不可为自己立耶和华你的上帝所憎恶的圣柱。</span>
</div>

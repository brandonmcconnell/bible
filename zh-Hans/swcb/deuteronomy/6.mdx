<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 12:1; 申命记 4:45"> 这些是耶和华你们的上帝吩咐要教导你们的诫命、律例和典章，使你们在要过去占领的地上遵行；</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:40; 申命记 13:4; 出埃及记 20:20"> 使你、你的儿子和你儿子的儿子，一生的日子都敬畏耶和华你的上帝，谨守祂的一切律例和祂的诫命，就是我吩咐你的；也使你的日子得以长久。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 22:17; 出埃及记 3:8; 创世记 26:4"> 以色列啊，所以你要听，并且谨守遵行，好使你得福，并且大大增多，正如耶和华你列祖的上帝向你所应许的，在流奶与蜜之地。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马可福音 12:29–32; 以赛亚书 44:6; 提摩太前书 2:5"> 以色列啊，你要听：耶和华是我们的上帝；耶和华是独一的。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 12:30; 马太福音 22:37; 路加福音 10:27"> 你要尽心、尽性、尽力爱耶和华你的上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:16; 箴言 7:3; 耶利米书 31:33"> 我今日吩咐你的这些话，要放在你心上；</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:19; 以弗所书 6:4; 诗篇 78:4–6"> 你要殷勤教导你的儿女；无论你坐在家里，走在路上，躺下，起来，都要谈论这些话。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命记 11:18"> 你要把它们系在手上作记号，它们也要成为你两眼之间的额饰。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 11:20; 以赛亚书 30:8; 以赛亚书 57:8"> 你要把它们写在你房屋的门框上和你的城门上。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:13; 诗篇 105:44; 尼希米记 9:25"> 将来，耶和华你的上帝领你进入祂向你列祖亚伯拉罕、以撒、雅各起誓要赐给你的地，那里有你没有建造的又大又美的城邑，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 7:12–18; 申命记 8:10–20; 以西结 16:10–20"> 有装满各样美物、不是你装满的房屋，有凿好的、不是你凿的水池，有不是你栽种的葡萄园和橄榄树；你吃了得饱足；</span>
<span className="v" id="v12" data-v="12"> 那时你要谨慎，免得忘记耶和华，祂曾把你从埃及地、从为奴之家领出来。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:8; 申命记 10:20; 马太福音 4:10"> 你要敬畏耶和华你的上帝；你要事奉祂，并且要指着祂的名起誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:6; 约翰一书 5:21; 申命记 13:7"> 你不可随从别神，就是你周围各族人的神；</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:24; 出埃及记 20:5; 申命记 7:4"> 因为在你中间的耶和华你的上帝是忌邪的上帝；免得耶和华你的上帝向你发怒，把你从地面上消灭。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 17:7; 路加福音 4:12; 马太福音 4:7"> 你不可试探耶和华你的上帝，像你在玛撒试探祂那样。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 11:22; 诗篇 119:4; 哥林多前书 15:58"> 你要谨守耶和华你上帝的诫命、祂的法度和祂的律例，就是祂所吩咐你的。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 4:40; 申命记 12:25; 罗马书 12:2"> 你要行耶和华眼中看为正、看为善的事，好使你得福，并且可以进去占领耶和华向你列祖起誓应许的那美地，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 33:52–53; 出埃及记 23:28–30; 士师记 3:1–4"> 从你面前赶出你所有的仇敌，照耶和华所说的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:14; 出埃及记 12:26; 约书亚记 4:6–7"> 日后，你的儿子问你说：“耶和华我们的上帝吩咐你们的这些法度、律例和典章是什么意思？”</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:17–18; 以弗所书 2:11–12; 申命记 15:15"> 你就要对你的儿子说：“我们在埃及作过法老的奴仆。耶和华用大能的手把我们从埃及领出来；</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 4:34; 诗篇 58:10–11; 申命记 7:19"> 耶和华在我们眼前向埃及、法老和法老全家施行又大又可畏的神迹奇事；</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 6:18; 申命记 6:10; 出埃及记 13:5"> 祂把我们从那里领出来，为要领我们进去，把祂向我们列祖起誓应许的地赐给我们。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:39; 诗篇 41:2; 申命记 10:12–13"> 耶和华吩咐我们遵行这一切律例，敬畏耶和华我们的上帝，使我们常得益处，保全我们的生命，像今日一样。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 24:13; 罗马书 10:3; 利未记 18:5"> 我们若照祂所吩咐我们的，在耶和华我们的上帝面前谨守遵行这一切诫命，这对我们就是义。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:4; 申命记 1:40; 民数记 14:25"> 于是我们转回，照耶和华对我所说的，沿着通往红海的路往旷野去；我们绕行西珥山许多日子。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2"> 耶和华吩咐我说：</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:6; 申命记 2:14; 申命记 2:7"> “你们绕行这山已经够久了；要转向北方。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 20:14–21; 出埃及记 15:15; 申命记 23:7"> 要吩咐百姓说：‘你们将要经过你们弟兄以扫子孙的边境；他们住在西珥，必惧怕你们。因此，你们要谨慎。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 36:8; 约书亚记 24:4; 耶利米书 27:5"> 不可与他们相争；因为他们的地，我连脚掌所踏的一点也不给你们，因为我已经把西珥山赐给以扫作产业。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:12; 民数记 20:19; 罗马书 12:17"> 你们要用钱向他们买食物吃，也要用钱向他们买水喝。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米记 9:21; 申命记 8:2–4"> 因为耶和华你的上帝在你手所做的一切事上赐福给你。你走过这大旷野的路，祂都知道。这四十年，耶和华你的上帝与你同在；你一无所缺。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 9:26; 士师记 11:18; 列王纪下 16:6"> 于是我们离开住在西珥的弟兄以扫子孙，经过从以拉他和以旬·迦别来的亚拉巴之路；又转向，经过摩押旷野的路。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 19:36–37; 民数记 21:15; 民数记 21:28"> 耶和华对我说：“不可扰害摩押，也不可与他们争战；因为他们的地，我必不赐给你作产业，因为我已经把亚珥赐给罗得的子孙作产业。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 14:5; 申命记 2:11; 民数记 13:22"> （以米人从前住在那里，是强大、众多的民族，身材高大，像亚衲人一样。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:28; 民数记 13:28; 创世记 14:5"> 他们也被算为利乏音人，像亚衲人一样；但摩押人称他们为以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:22; 创世记 14:6; 申命记 2:32–11"> 何利人从前也住在西珥，但以扫子孙接续了他们；以扫子孙从自己面前毁灭他们，住在他们的地方，正如以色列在耶和华赐给他们作产业之地所行的一样。）</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 21:12; 民数记 13:23"> “现在起来，过撒烈溪。”于是我们过了撒烈溪。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 26:64–65; 民数记 14:28–35; 申命记 1:34–35"> 从我们离开加低斯·巴尼亚，直到过了撒烈溪，期间共有三十八年；到那时，那一代的战士都从营中灭尽了，正如耶和华向他们起誓所说的。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 106:26; 以赛亚书 66:14; 诗篇 32:4"> 而且耶和华的手攻击他们，要把他们从营中毁灭，直到他们灭尽。</span>
<span className="v" id="v16" data-v="16"> 当所有战士都从百姓中灭尽、死亡以后，</span>
<span className="v" id="v17" data-v="17"> 耶和华吩咐我说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 以赛亚书 15:1; 民数记 21:15"> “你今天要经过摩押的边境亚珥。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:9; 士师记 11:13–27; 历代志下 20:10"> 你接近亚扪子孙的边境时，不可扰害他们，也不可与他们相争；因为亚扪子孙的地，我必不赐给你作产业，因为我已经把那地赐给罗得的子孙作产业。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 14:5"> （那地也被算为利乏音人之地。利乏音人从前住在那里，但亚扪人称他们为散送冥人；</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 27:7–8; 申命记 1:28; 申命记 2:22"> 他们是强大、众多的民族，身材高大，像亚衲人一样；但耶和华在以色列面前毁灭了他们；他们就接续他们，住在他们的地方，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 36:8; 创世记 36:20–30; 申命记 2:12"> 正如祂为住在西珥的以扫子孙所行的；那时祂从他们面前毁灭何利人，他们就接续他们，住在他们的地方，直到今日。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 10:14; 约书亚记 13:3; 阿摩司 9:7"> 至于住在村庄直到迦萨的亚卫人，从迦斐托出来的迦斐托人毁灭了他们，住在他们的地方。）</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 27:5; 但以理 4:17; 士师记 11:18–21"> “起来，启程，过亚嫩谷。看哪，我已经把亚摩利人希实本王西宏和他的地交在你手中；你要开始得他的地为业，并与他交战。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 11:25; 出埃及记 15:14–16; 申命记 28:10"> 全天下的各族因你而惊恐惧怕；他们听见你的消息，就必因你战兢痛苦。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 约书亚记 13:18"> 我从基底莫旷野派使者到希实本王西宏那里，用和平的话说：</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 11:19; 申命记 2:6; 民数记 21:21–23"> “求你让我经过你的地。我只走大道，不偏向右，也不偏向左。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 20:19"> 你要用钱卖给我食物吃，也要用钱给我水喝；只要让我步行过去，</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 20:18; 士师记 11:17–18; 申命记 23:3–4"> 就像住在西珥的以扫子孙和住在亚珥的摩押人待我一样，直到我过约旦河，进入耶和华我们的上帝赐给我们的地。”</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 21:23; 出埃及记 4:21; 约书亚记 11:19–20"> 但希实本王西宏不肯让我们从他那里经过，因为耶和华你的上帝使他的灵刚硬，使他的心顽梗，为要把他交在你手中，正如今日一样。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 1:8; 申命记 2:24"> 耶和华对我说：“看哪，我已经开始把西宏和他的地交给你了。你要开始得他的地为业。”</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 21:23–30; 士师记 11:20–23; 诗篇 136:19"> 于是西宏和他的全体百姓出来，在雅杂与我们交战。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 7:2; 约书亚记 21:44; 申命记 3:2–3"> 耶和华我们的上帝把他交在我们面前；我们击败了他、他的儿子和他的全体百姓。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 7:2; 撒母耳记上 15:3; 申命记 3:6"> 那时，我们夺取了他所有的城，把每一座有人居住的城，连同妇女和孩子，都尽行毁灭；我们没有留下一个。</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 8:27; 申命记 20:14; 民数记 31:9–11"> 只有牲畜和所夺取各城中的财物，我们取为自己的战利品。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 13:9; 申命记 4:48; 申命记 3:12"> 从亚嫩谷边的亚罗珥和谷中的城，直到基列，没有一座城高到我们攻不下；耶和华我们的上帝把一切都交在我们面前。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:24; 申命记 3:16; 创世记 32:22"> 只是亚扪子孙的地你没有挨近，就是雅博河沿岸一带、山地的城，以及耶和华我们的上帝禁止我们去的一切地方。</span>
</div>
</div>

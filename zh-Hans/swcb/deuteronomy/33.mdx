<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:6; 诗篇 90:1; 创世记 27:4"> 以下是上帝的人摩西在临死以前为以色列子孙所祝的福。</span>
<span className="v" id="v2" data-v="2" data-xref="犹大书 1:14; 哈巴谷 3:3; 启示录 5:11"> 他说：<br /><span className="pl pl-1">“耶和华从西奈而来，</span><br /><span className="pl pl-2">从西珥向他们升起。</span><br /><span className="pl pl-1">祂从巴兰山发光；</span><br /><span className="pl pl-2">祂从万万圣者中而来。</span><br /><span className="pl pl-2">在祂右手有火焰的律法赐给他们。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="另有抄本作：“祂从南方，从祂的山坡，带着无数圣者而来。”">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 10:39; 玛拉基书 1:2; 申命记 7:6–8"> <span className="pl pl-1">祂确实爱众民。</span><br /><span className="pl pl-2">祂所有的圣民都在你手中。</span><br /><span className="pl pl-2">他们坐在你脚前；</span><br /><span className="pl pl-2">各人领受你的话语。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:17; 诗篇 119:111; 约翰福音 7:19"> <span className="pl pl-1">摩西吩咐我们遵行律法，</span><br /><span className="pl pl-2">作为雅各会众的产业。</span></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:15; 士师记 17:6; 民数记 23:21"> <span className="pl pl-1">百姓的首领聚集，</span><br /><span className="pl pl-2">以色列众支派一同聚集的时候，</span><br /><span className="pl pl-2">祂在耶书仑中作王。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="创世记 49:8; 民数记 32:31–32; 约书亚记 22:1–9"> <span className="pl pl-1">“愿吕便存活，不至死亡；</span><br /><span className="pl pl-2">愿他的人数也不少。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="创世记 49:8–12; 诗篇 20:2; 撒母耳记下 7:9–12"> 以下是为犹大所说的。他说：<br /><span className="pl pl-1">“耶和华啊，求你垂听犹大的声音，</span><br /><span className="pl pl-2">带他归到自己的民那里。</span><br /><span className="pl pl-1">他用双手为自己争战；</span><br /><span className="pl pl-2">求你帮助他抵挡敌人。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 17:7; 出埃及记 28:30; 民数记 20:13"> 论到利未，他说：<br /><span className="pl pl-1">“你的土明和乌陵在你的虔诚人那里；</span><br /><span className="pl pl-2">你曾在玛撒试验他，</span><br /><span className="pl pl-2">在米利巴水与他争论。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:37; 出埃及记 32:25–29; 马太福音 12:48"> <span className="pl pl-1">他论到自己的父母说：‘我没有顾念他们。’</span><br /><span className="pl pl-2">他不承认自己的兄弟，</span><br /><span className="pl pl-2">也不认识自己的儿女；</span><br /><span className="pl pl-1">因为他们遵守你的话语，</span><br /><span className="pl pl-2">持守你的约。</span></span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:11; 诗篇 51:19; 申命记 17:9–11"> <span className="pl pl-1">他们要将你的典章教导雅各，</span><br /><span className="pl pl-2">将你的律法教导以色列。</span><br /><span className="pl pl-1">他们要把香摆在你面前，</span><br /><span className="pl pl-2">把全牲燔祭献在你的祭坛上。</span></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 24:23; 以西结 43:27; 以西结 20:40–41"> <span className="pl pl-1">耶和华啊，求你赐福他的才能，</span><br /><span className="pl pl-2">悦纳他手所做的工。</span><br /><span className="pl pl-1">求你击穿那些起来攻击他的人的腰，</span><br /><span className="pl pl-2">使恨他的人不能再起来。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:2; 诗篇 91:4; 马太福音 23:37"> 论到便雅悯，他说：<br /><span className="pl pl-1">“耶和华所爱的，必在祂旁边安然居住。</span><br /><span className="pl pl-2">祂终日遮护他；</span><br /><span className="pl pl-2">他住在祂的两肩之间。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="创世记 49:22–26; 弥迦书 5:7; 以赛亚书 18:4"> 论到约瑟，他说：<br /><span className="pl pl-1">“愿他的土地蒙耶和华赐福，</span><br /><span className="pl pl-2">得天上的宝物、甘露，</span><br /><span className="pl pl-2">以及伏卧在下面的深渊；</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19; 马太福音 5:45; 诗篇 8:3"> <span className="pl pl-1">得太阳所结的宝物，</span><br /><span className="pl pl-2">月亮所产的宝物；</span></span>
<span className="v" id="v15" data-v="15" data-xref="哈巴谷 3:6; 创世记 49:26; 雅各书 5:7"> <span className="pl pl-1">得太古山岭的上好之物，</span><br /><span className="pl pl-2">永恒山冈的宝物；</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:35; 诗篇 24:1; 出埃及记 3:2–4"> <span className="pl pl-1">得大地和其中所充满的宝物，</span><br /><span className="pl pl-2">以及住在荆棘中的那位的恩惠。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即出埃及记3:3-4中的燃烧荆棘。">b</a></sup><br /><span className="pl pl-1">愿这一切临到约瑟的头上，</span><br /><span className="pl pl-2">临到那从弟兄中被分别出来之人的头顶上。</span></span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 22:11; 民数记 23:22; 诗篇 44:5"> <span className="pl pl-1">他牛群中头生的有威严；</span><br /><span className="pl pl-2">他的角是野牛的角。</span><br /><span className="pl pl-2">他要用这些角抵触万民，直到地极。</span><br /><span className="pl pl-1">这就是以法莲的万万；</span><br /><span className="pl pl-2">这就是玛拿西的千千。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="创世记 49:13–15; 约书亚记 19:11; 士师记 5:14"> 论到西布伦，他说：<br /><span className="pl pl-1">“西布伦哪，愿你在外出时欢喜；</span><br /><span className="pl pl-2">以萨迦啊，愿你在帐棚中快乐。</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 60:5; 以赛亚书 2:3; 诗篇 4:5"> <span className="pl pl-1">他们要召集万民到山上；</span><br /><span className="pl pl-2">在那里他们要献公义的祭，</span><br /><span className="pl pl-1">因为他们要吸取海中的丰盛，</span><br /><span className="pl pl-2">沙中的隐藏珍宝。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="创世记 49:19; 创世记 9:26–27; 历代志上 5:18–21"> 论到迦得，他说：<br /><span className="pl pl-1">“扩张迦得的有福了。</span><br /><span className="pl pl-2">他住在那里如母狮，</span><br /><span className="pl pl-2">撕裂膀臂和头顶。</span></span>
<span className="v" id="v21" data-v="21" data-xref="民数记 32:16–42; 士师记 5:11; 士师记 5:2"> <span className="pl pl-1">他为自己预备了头一份，</span><br /><span className="pl pl-2">因为立法者的份为他保留在那里。</span><br /><span className="pl pl-1">他与百姓的首领同来；</span><br /><span className="pl pl-2">他施行耶和华的公义，</span><br /><span className="pl pl-2">以及祂与以色列有关的典章。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="士师记 18:27; 约书亚记 19:47; 士师记 15:8"> 论到但，他说：<br /><span className="pl pl-1">“但是狮子的幼崽，</span><br /><span className="pl pl-2">从巴珊跳出来。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="创世记 49:21; 诗篇 36:8; 马太福音 4:16"> 论到拿弗他利，他说：<br /><span className="pl pl-1">“拿弗他利啊，你满得恩惠，</span><br /><span className="pl pl-2">充满耶和华的赐福，</span><br /><span className="pl pl-2">要得西方和南方为业。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="创世记 49:20; 约伯记 29:6; 罗马书 14:18"> 论到亚设，他说：<br /><span className="pl pl-1">“亚设在儿女方面蒙福。</span><br /><span className="pl pl-2">愿他蒙自己的弟兄悦纳。</span><br /><span className="pl pl-2">愿他把脚蘸在油中。</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10; 诗篇 138:3; 腓立比书 4:13"> <span className="pl pl-1">你的门闩必是铁和铜；</span><br /><span className="pl pl-2">你的力量必像你的日子一样。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 15:11; 以赛亚书 43:11–13; 耶利米书 10:6"> <span className="pl pl-1">“耶书仑哪，没有谁像上帝；</span><br /><span className="pl pl-2">祂驾行诸天来帮助你，</span><br /><span className="pl pl-2">以祂的威荣驾行穹苍。</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 18:2; 诗篇 90:1–2; 诗篇 46:1"> <span className="pl pl-1">永恒的上帝是你的居所，</span><br /><span className="pl pl-2">在你下面是永久的膀臂。</span><br /><span className="pl pl-1">祂从你面前赶出仇敌，</span><br /><span className="pl pl-2">说：‘毁灭吧！’</span></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 23:9; 创世记 27:28; 出埃及记 33:16"> <span className="pl pl-1">以色列安然居住，</span><br /><span className="pl pl-2">雅各的泉源独居，</span><br /><span className="pl pl-1">在五谷新酒之地。</span><br /><span className="pl pl-2">他的天也滴下甘露。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 45:17; 以赛亚书 12:2; 诗篇 115:9–11"> <span className="pl pl-1">以色列啊，你有福了！</span><br /><span className="pl pl-2">谁像你这蒙耶和华拯救的百姓？</span><br /><span className="pl pl-2">祂是帮助你的盾牌，</span><br /><span className="pl pl-2">是你威荣的刀剑。</span><br /><span className="pl pl-1">你的仇敌必向你屈服；</span><br /><span className="pl pl-2">你必踏在他们的高处。”</span></span>
</div>

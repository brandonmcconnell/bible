<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:1–2; 出埃及记 25:10–15; 申命记 10:3–4"> 那时，耶和华对我说：“你要凿出两块石版，像先前的一样，上山到我这里来，并且做一个木柜。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 8:9; 申命记 10:5; 申命记 4:13"> 我要把你摔碎的先前那两块版上的话，写在这些版上；你要把它们放在柜里。”</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 34:4; 出埃及记 37:1–9; 出埃及记 25:10"> 于是我做了一个皂荚木柜，又凿出两块石版，像先前的一样，手里拿着这两块版上了山。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 9:10; 出埃及记 34:28; 希伯来书 12:18–19"> 耶和华照先前所写的，把十条诫命写在版上，就是集会的日子，耶和华在山上从火中对你们所说的话；然后耶和华把版交给了我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:29; 出埃及记 40:20; 申命记 10:2"> 我转身下山，把版放在我所做的柜里；它们就在那里，照耶和华所吩咐我的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 33:38; 民数记 20:23–28; 民数记 33:30–33"> （以色列人从比罗比尼·雅干起行，到了摩西拉。亚伦死在那里，也葬在那里；他儿子以利亚撒接替他供祭司的职分。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:32–34"> 他们从那里起行，到了古德歌大；又从谷歌大到了约巴他，那地有溪水。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:5; 申命记 18:5; 民数记 6:23–26"> 那时，耶和华分别利未支派，叫他们抬耶和华的约柜，站在耶和华面前事奉祂，并奉祂的名祝福，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 44:28; 民数记 18:20–24; 申命记 18:1–2"> 因此，利未在他弟兄中没有份，也没有产业；耶和华就是他的产业，正如耶和华你的上帝对他说的。）</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 9:18–19; 申命记 9:25; 出埃及记 34:28"> 我像先前一样，在山上停留了四十昼夜；那一次耶和华也垂听了我。耶和华不愿毁灭你们。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:1; 出埃及记 32:34"> 耶和华对我说：“起来，在百姓前面起行；他们要进去占有那地，就是我起誓要赐给他们列祖的地。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 6:8; 申命记 6:5; 路加福音 10:27"> 现在，以色列啊，耶和华你的上帝向你所要的是什么呢？不过是要你敬畏耶和华你的上帝，行祂一切的道路，爱祂，尽心尽性事奉耶和华你的上帝，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:39; 申命记 6:24; 雅各书 1:25"> 遵守耶和华的诫命和律例，就是我今日吩咐你的，为要使你得益处。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:5; 诗篇 24:1; 诗篇 115:16"> 看哪，天和天上的天，地和地上的一切，都属于耶和华你的上帝。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:37; 申命记 7:7–8; 罗马书 9:13–23"> 然而耶和华只喜悦你的列祖，爱他们，并在他们以后拣选他们的后裔，就是你们，超过万民，正如今日一样。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 4:4; 申命记 30:6; 利未记 26:41"> 所以你们要给自己的心行割礼，不可再硬着颈项。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34; 罗马书 2:11; 但以理 2:47"> 因为耶和华你们的上帝，祂是万神之神、万主之主，是伟大的上帝，大有能力，令人敬畏；祂不偏待人，也不受贿赂。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 146:9; 诗篇 68:5; 耶利米书 49:11"> 祂为孤儿寡妇施行公正，也爱寄居者，赐给他食物和衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 22:21; 利未记 19:33–34; 路加福音 17:18"> 所以你们要爱寄居者，因为你们在埃及地也曾作寄居者。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:13; 申命记 13:4; 路加福音 4:8"> 你要敬畏耶和华你的上帝，要事奉祂，紧紧跟随祂，并且奉祂的名起誓。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:14; 诗篇 106:21–22; 出埃及记 15:2"> 祂是你所赞美的，祂是你的上帝；祂为你做了这些伟大而令人敬畏的事，是你亲眼所看见的。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 46:27; 出埃及记 1:5; 创世记 15:5"> 你的列祖下到埃及时，共有七十人；现在耶和华你的上帝使你多如天上的星。</span>
</div>

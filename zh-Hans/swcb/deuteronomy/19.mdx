<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 12:29; 申命记 6:10; 申命记 7:1–2"> 当耶和华你的上帝剪除列国，就是耶和华你的上帝把他们的地赐给你的时候，你接替他们，住在他们的城邑和房屋中，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 21:13; 约书亚记 20:2–7; 申命记 4:41–43"> 就要在耶和华你的上帝赐给你为业的土地中，为自己分别出三座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 57:14; 希伯来书 12:13; 以赛亚书 35:8"> 你要修筑道路，并把耶和华你的上帝使你承受为业之地的境内分成三部分，使所有杀人者都可以逃到那里。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 35:15–24; 申命记 4:42; 以赛亚书 30:33"> 杀人者逃到那里而得以存活的情形是这样：凡不是出于故意杀了邻舍，并且从前也不恨他的——</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 35:25; 箴言 27:12; 列王纪下 6:5–7"> 比如有人与邻舍进森林砍柴，他挥手用斧砍树，斧头脱了柄，击中他的邻舍，以致他死了——这人就可以逃到这些城中的一座，得以存活。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 35:12; 撒母耳记下 14:7; 申命记 21:22"> 否则，报血仇的人心里怒气正盛，可能追赶那杀人者；因为路远，就追上他，把他打死；其实他罪不至死，因为他从前并不恨那人。</span>
<span className="v" id="v7" data-v="7"> 因此我命令你：要为自己分别出三座城。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 12:20; 出埃及记 34:24; 出埃及记 23:31"> 如果耶和华你的上帝照祂向你列祖所起的誓，扩张你的疆界，把祂应许赐给你列祖的全地赐给你；</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 20:7–8; 申命记 11:22–25; 申命记 12:32"> 又如果你谨守遵行我今日所吩咐你的这一切诫命，爱耶和华你的上帝，常行祂的道路，那么你就要在这三座城之外，再为自己加添三座城。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:7; 箴言 6:17; 马太福音 27:4–5"> 这样，在耶和华你的上帝赐给你为产业的土地中，无辜人的血就不至于被流，以致流血的罪归到你身上。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:16–21; 申命记 27:24; 创世记 9:6"> 但如果有人恨他的邻舍，埋伏等候他，起来攻击他，把他打死，以致他死了，然后逃进这些城中的一座；</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 2:28–34; 列王纪上 2:5–6"> 那么他本城的长老就要派人去，从那里把他带来，交在报血仇的人手中，使他处死。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 2:31; 申命记 21:9; 申命记 7:16"> 你的眼不可怜惜他；你要从以色列中除掉流无辜人血的罪，使你可以得福。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 27:17; 箴言 22:28; 箴言 23:10"> 在耶和华你的上帝赐给你去占有的地上，在你将要承受为业的产业中，你不可挪移邻舍的地界，就是古人所立的地界。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 35:30; 申命记 17:6; 哥林多后书 13:1"> 一个人无论犯什么罪孽，犯什么罪，一个证人不可起来指控他；凭两个证人的口，或凭三个证人的口，案件才可成立。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 27:12; 诗篇 35:11; 出埃及记 23:1–7"> 如果有不义的证人起来指控某人，作证说他作恶，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 17:9; 申命记 21:5; 玛拉基书 2:7"> 那么争讼的双方都要站在耶和华面前，站在当时任职的祭司和审判官面前；</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 13:14; 申命记 17:4; 历代志下 19:6–7"> 审判官要仔细查问；看哪，如果那证人是作假见证的，虚假地作证陷害他的弟兄，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 19:9; 但以理 6:24"> 你们就要照他想要怎样待他的弟兄来待他。这样，你就要把那恶从你们中间除掉。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 21:21; 申命记 17:13; 申命记 13:11"> 其余的人听见，就会惧怕，以后再也不在你们中间行这样的恶事。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:38–39; 出埃及记 21:23–25; 申命记 19:13"> 你的眼不可怜惜：要以命偿命，以眼还眼，以牙还牙，以手还手，以脚还脚。</span>
</div>

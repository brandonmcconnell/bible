<span className="v" id="v1" data-v="1" data-xref="申命记 31:3; 使徒行传 13:19; 申命记 4:38"> 当耶和华你的上帝领你进入你要去占领的土地，并且从你面前赶出许多民族——赫人、革迦撒人、亚摩利人、迦南人、比利洗人、希未人和耶布斯人，就是七个比你强大有力的民族——</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 2:2; 出埃及记 23:32–33; 申命记 20:16–17"> 耶和华你的上帝把他们交在你面前，你击败他们的时候，你必须把他们尽行毁灭。不可与他们立约，也不可怜悯他们。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:2; 约书亚记 23:12–13; 出埃及记 34:15–16"> 不可与他们通婚。不可把你的女儿嫁给他的儿子，也不可为你的儿子娶他的女儿。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 6:15; 士师记 2:11; 申命记 4:26"> 因为那会使你的儿子转离，不跟从我，去事奉别的神明。这样，耶和华的怒气就会向你发作，祂会很快毁灭你。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:24; 申命记 12:2–3; 出埃及记 34:13"> 但你们要这样对待他们：拆毁他们的祭坛，打碎他们的柱像，砍下他们的亚舍拉木柱，用火焚烧他们雕刻的偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:2; 出埃及记 19:5–6; 彼得前书 2:9"> 因为你是归耶和华你的上帝为圣的子民。耶和华你的上帝从地面上的万民中拣选了你，作祂自己产业的子民。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 10:22; 罗马书 9:11–15; 罗马书 11:6"> 耶和华专爱你、拣选你，并不是因为你的人数比任何民族更多；因为你在万民中是人数最少的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:2; 出埃及记 32:13; 以弗所书 2:4–5"> 乃是因为耶和华爱你，又因为祂愿意守祂向你列祖所起的誓，耶和华就用大能的手把你领出来，把你从为奴之家、从埃及王法老手中救赎出来。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:23; 提摩太后书 2:13; 帖撒罗尼迦后书 3:3"> 所以你要知道，耶和华你的上帝，祂就是上帝，是信实的上帝；向爱祂、守祂诫命的人，祂守约施慈爱，直到千代；</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:18; 那鸿书 1:2; 罗马书 12:19"> 却当面报应恨祂的人，要灭绝他们。对恨祂的人，祂必不迟延，必当面报应他。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 14:15; 申命记 4:1; 申命记 5:32"> 所以，你要谨守我今天吩咐你的诫命、律例和典章，并且遵行。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 28:1–14; 申命记 7:9; 利未记 26:3–13"> 因为你听从这些典章，谨守遵行，耶和华你的上帝就必向你守祂向你列祖起誓所立的约和慈爱。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:21; 约翰福音 15:10; 申命记 28:3–5"> 祂必爱你，赐福给你，使你人数增多。祂也必在祂向你列祖起誓要赐给你的土地上，赐福给你身所生的、你地所产的，以及你的五谷、新酒和油，并你牲畜所增、羊群所生的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 23:26–33; 申命记 28:4; 诗篇 127:3"> 你必蒙福超过万民。你中间无论男女，或你的牲畜，都没有不能生育的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 15:26; 诗篇 105:36–37; 利未记 26:3–4"> 耶和华必除去你一切的疾病；你所知道埃及那些恶疾，祂必不加在你身上，却要加在所有恨你的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:33; 士师记 8:27; 申命记 13:8"> 耶和华你的上帝所要交给你的一切民族，你都要消灭。你的眼不可顾惜他们。你不可事奉他们的神明；因为那会成为你的网罗。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 13:32; 民数记 33:53; 申命记 18:21"> 你若心里说：“这些民族比我众多；我怎能赶出他们呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 105:5; 申命记 31:6; 申命记 1:29"> 你不可惧怕他们。你务要记得耶和华你的上帝向法老和全埃及所做的事：</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:34; 尼希米记 9:10–11; 耶利米书 32:20–21"> 就是你的眼所看见的大试炼、神迹、奇事、大能的手和伸出来的膀臂；耶和华你的上帝就是用这些把你领出来。耶和华你的上帝也要这样对待你所惧怕的一切民族。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 24:12; 出埃及记 23:28–30"> 此外，耶和华你的上帝必差黄蜂到他们中间，直到那些剩下和躲藏的人都从你面前灭亡。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 1:5; 申命记 10:17; 尼希米记 9:32"> 你不可因他们惊惧；因为耶和华你的上帝在你中间，祂是伟大而可畏的上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:29–30; 约书亚记 15:63"> 耶和华你的上帝必将那些民族从你面前渐渐赶出。你不可一下子消灭他们，免得田野的兽增多，攻击你。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 8:20; 申命记 2:15; 耶利米书 17:18"> 但耶和华你的上帝必把他们交在你面前，并且大大扰乱他们，直到他们灭亡。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 10:8; 约书亚记 23:9; 约书亚记 1:5"> 祂必把他们的君王交在你手中；你要使他们的名从天下消灭。没有人能在你面前站立，直到你把他们毁灭。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 32:20; 历代志上 14:12; 申命记 17:1"> 他们神明雕刻的偶像，你们要用火焚烧。不可贪图偶像上的金银，也不可取为己有，免得你因此陷入网罗；因为这是耶和华你的上帝所憎恶的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 13:17; 何西阿 14:8; 以西结 11:18"> 你不可把可憎之物带进你家，免得自己也像它一样成为当灭之物。你必须极其厌恶它，极其憎嫌它，因为它是当灭之物。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 6:5; 申命记 10:12; 路加福音 1:74–75"> 所以你要爱耶和华你的上帝，常常遵守祂的吩咐、律例、典章和诫命。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 8:2–5; 申命记 29:10; 使徒行传 26:22"> 你们今日要知道——我不是对你们的儿女说的；他们并不知道，也没有见过耶和华你们上帝的管教、祂的伟大、祂大能的手和祂伸出来的膀臂，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:19; 申命记 4:34; 诗篇 105:27–45"> 祂的神迹和作为，就是祂在埃及中间向埃及王法老和他的全地所行的；</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 106:11; 出埃及记 14:23–31; 出埃及记 15:19"> 也没有见过祂向埃及的军队、马匹和战车所行的事：他们追赶你们的时候，祂怎样使红海的水淹没他们，耶和华又怎样毁灭他们，直到今日；</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 77:20; 诗篇 106:12–48; 诗篇 78:14–72"> 也没有见过祂在旷野怎样待你们，直到你们来到这地方；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:9–10; 诗篇 106:17; 民数记 16:1–35"> 也没有见过祂怎样待流便子孙以利押的儿子大坍和亚比兰：地怎样在以色列众人中间开口，吞灭了他们和他们的家眷、帐棚，以及一切跟随他们的活物；</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:4–6; 诗篇 145:12; 诗篇 150:2"> 但你们亲眼看见了耶和华所行的一切伟大作为。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:10; 约书亚记 1:6–7; 以弗所书 3:16"> 所以，你们要遵守我今日吩咐你们的全部诫命，使你们可以刚强，进去得你们将要过去取得的那地为业；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 申命记 4:40; 申命记 6:2"> 并使你们在那地得以长久，就是耶和华向你们列祖起誓，要赐给他们和他们后裔的流奶与蜜之地。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 14:18"> 你将要进去得为业的那地，不像你们出来的埃及地；在那里你撒种，用脚浇灌，像浇灌菜园一样；</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:7; 申命记 8:7–9; 诗篇 65:12–13"> 但你们将要过去得为业的那地，是有山有谷之地，吸饮天上降雨之水，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 24:6; 诗篇 33:18; 列王纪上 9:3"> 是耶和华你的上帝所眷顾的地。从岁首到年终，耶和华你上帝的眼目常常看顾那地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 10:12; 申命记 4:29; 申命记 6:17"> 如果你们殷勤听从我今日吩咐你们的诫命，爱耶和华你们的上帝，尽心尽性事奉祂，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 5:7; 利未记 26:4; 以西结 34:26"> 我就按时降雨在你们的地上，就是秋雨和春雨，使你们可以收取五谷、新酒和油。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 104:14; 申命记 6:11; 约珥 2:19"> 我也必使你的田野为你的牲畜长草；你也要吃得饱足。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:27; 希伯来书 3:12; 希伯来书 2:1"> 你们要谨慎，免得你们的心受迷惑，就偏离正道，去事奉别神，敬拜它们；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 8:35; 申命记 6:15; 历代志下 6:26"> 以致耶和华向你们发怒，封闭天空，使天不下雨，地也不出产；你们就从耶和华所赐给你们的美地上迅速灭亡。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 3:16; 申命记 6:6–9; 箴言 3:1"> 所以，你们要把我这些话存在你们的心里和灵魂里；要把它们绑在手上作记号，戴在两眼之间作额饰。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 以赛亚书 38:19; 申命记 4:9–10"> 你们要教导你们的儿女，无论坐在家里，行在路上，躺下，起来，都要谈论这些话。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:9"> 你要把这些话写在你房屋的门柱上和你的城门上；</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 使你们和你们儿女在那地的日子得以增多，就是耶和华向你们列祖起誓要赐给他们的地，如天覆地的日子那样长久。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 6:17; 申命记 11:13; 申命记 10:20"> 如果你们殷勤遵守我吩咐你们的一切诫命，遵行它们，爱耶和华你们的上帝，行祂一切的道路，紧紧依靠祂，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:38; 申命记 9:1; 申命记 7:1–2"> 耶和华就必从你们面前赶出这些民族；你们也必赶出比你们更大更强的民族，得他们的地为业。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 14:9; 出埃及记 23:31; 创世记 15:18–21"> 凡你们脚掌所踏之地都必归你们：从旷野和黎巴嫩，从那河，就是幼发拉底河，直到西海，都要作你们的疆界。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:24; 出埃及记 23:27; 约书亚记 1:5"> 没有人能在你们面前站立得住。耶和华你们的上帝必照祂对你们所说的，使你们所踏之地的人都惧怕你们、畏惧你们。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 30:1; 申命记 30:15–20; 加拉太书 3:10"> 看哪，今日我将祝福和咒诅摆在你们面前：</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:19; 申命记 28:1–14; 以赛亚书 3:10"> 如果你们听从耶和华你们上帝的诫命，就是我今日吩咐你们的，就必得祝福；</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:15–68; 罗马书 2:8–9; 加拉太书 3:10"> 如果你们不听从耶和华你们上帝的诫命，却偏离我今日吩咐你们的道路，去随从你们不认识的别神，就必受咒诅。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 27:12–26; 约书亚记 8:30–35"> 当耶和华你的上帝领你进入你将要去得为业的那地时，你要把祝福陈明在基利心山上，把咒诅陈明在以巴路山上。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 12:6; 士师记 7:1; 约书亚记 4:19"> 它们岂不是在约旦河那边、日落方向的路后面，在住亚拉巴的迦南人之地，靠近吉甲，在摩利橡树旁吗？</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 1:11; 申命记 9:1; 约书亚记 3:13–17"> 因为你们将要过约旦河，进去取得耶和华你们的上帝所赐给你们的那地为业；你们必得那地为业，并住在其中。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 28:20; 申命记 12:32; 帖撒罗尼迦前书 4:1–2"> 你们要谨守遵行我今日摆在你们面前的一切律例和典章。</span>
</div>

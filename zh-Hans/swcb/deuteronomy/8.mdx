<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 5:32–3; 帖撒罗尼迦前书 4:1–2"> 我今日吩咐你们的一切诫命，你们都要谨守遵行，好使你们存活，人数增多，并进去得耶和华向你们祖先起誓应许的那地为业。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:3; 彼得前书 1:7; 申命记 8:16"> 你们要记念耶和华你们的上帝这四十年在旷野引导你们所走的全程；祂这样做，是要使你们谦卑，试验你们，要知道你们心里如何，肯不肯遵守祂的诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:4; 路加福音 4:4; 希伯来书 13:5–6"> 祂使你们谦卑，让你们饥饿，又用你们和你们祖先都不认识的吗哪喂养你们，为要教导你们：人活着不是单靠食物，而是靠耶和华口中所出的一切话。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:21; 申命记 29:5; 马太福音 26:25–30"> 这四十年，你们身上的衣服没有穿旧，你们的脚也没有肿。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:19; 箴言 3:12; 撒母耳记下 7:14"> 你们心里要思想：人怎样管教自己的儿子，耶和华你们的上帝也怎样管教你们。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 6:31; 申命记 5:33; 撒母耳记上 12:24"> 所以你们要遵守耶和华你们上帝的诫命，行在祂的道路中，敬畏祂。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:9–12; 出埃及记 3:8; 以西结 20:6"> 因为耶和华你们的上帝正领你们进入美地；那地有溪水，有泉源，也有地下水，在谷中和山间涌流；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 6:13; 诗篇 147:14; 申命记 32:14"> 那地有小麦、大麦、葡萄树、无花果树和石榴树；那地有橄榄树和蜜；</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 22:14; 申命记 33:25; 约书亚记 22:8"> 在那地，你们吃粮不会缺乏，在其中一无所缺；那地的石头是铁，从它的山中可以挖出铜。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 103:2; 罗马书 14:6; 箴言 3:9"> 你们吃了而且饱足，就要因耶和华你们的上帝所赐给你们的美地称颂祂。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:21; 何西阿 2:8–9; 箴言 1:32"> 你们要谨慎，免得忘记耶和华你们的上帝，不遵守祂的诫命、典章和律例，就是我今日吩咐你们的；</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命记 28:47; 申命记 32:15"> 免得你们吃得饱足，建造华美的房屋并住在里面；</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 1:3; 创世记 13:1–5; 路加福音 12:13–21"> 你们的牛群羊群增多，金银增多，所有的一切都增多；</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 106:21; 哥林多前书 4:7–8; 申命记 8:11"> 那时你们的心就高傲起来，忘记耶和华你们的上帝，祂曾把你们从埃及地、从为奴之家领出来；</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:6; 民数记 20:11; 耶利米书 2:6"> 祂曾引导你们经过那又大又可怕的旷野，那里有毒蛇、蝎子和干旱无水之地；祂为你们使水从燧石般坚硬的磐石中流出来；</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 8:3; 雅各书 1:12; 出埃及记 16:15"> 祂在旷野用你们祖先不认识的吗哪喂养你们，为要使你们谦卑，试验你们，终久使你们得好处；</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 9:4; 哥林多前书 4:7; 但以理 4:30"> 免得你们心里说：“我的力量和我手的能力为我取得了这财富。”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿 2:8; 申命记 7:8"> 你们却要记念耶和华你们的上帝，因为赐给你们能力取得财富的是祂，为要坚立祂向你们祖先起誓所立的约，像今日一样。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 4:26; 撒母耳记上 12:25; 西番雅书 1:18"> 如果你们忘记耶和华你们的上帝，随从别的神，事奉它们，敬拜它们，事情必定这样：我今日向你们作证，你们必定灭亡。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理 9:11–12; 历代志下 36:16–17"> 像耶和华在你们面前使之灭亡的列国一样，你们也必灭亡，因为你们不肯听从耶和华你们上帝的声音。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="DEU" data-book-slug="deuteronomy" data-book-name="申命记" data-chapter="31" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西去把这些话告诉以色列众人。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 34:7; 民数记 27:17; 列王纪上 3:7"> 他对他们说：“我今天一百二十岁了，不能再出入了。耶和华曾对我说：‘你不可过这约旦河。’</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:3; 申命记 31:23; 申命记 3:28"> 耶和华你的上帝必亲自在你前面过去。祂必从你面前灭绝这些国民，你就要夺取他们的地。约书亚必照耶和华所说的，在你前面过去。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 23:28–31; 申命记 2:33; 申命记 3:3–11"> 耶和华怎样对待亚摩利人的王西宏和噩，以及他们的地，就是祂灭绝他们的时候所做的，也必照样对待这些国民。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:2; 申命记 20:16–17; 出埃及记 23:32–33"> 耶和华必把他们交在你们面前，你们要照我吩咐你们的一切诫命待他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:9; 以弗所书 6:10; 诗篇 27:14"> 你们要刚强壮胆。不要惧怕，也不要因他们惊慌，因为耶和华你的上帝亲自与你同去。祂必不撇下你，也不离弃你。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 3:28; 申命记 31:6; 申命记 1:38"> 摩西召了约书亚来，在以色列众人眼前对他说：“你要刚强壮胆，因为你要和这百姓一同进入耶和华向他们列祖起誓要赐给他们的地；你要使他们承受那地为业。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 33:14; 申命记 31:6; 约书亚记 1:9"> 耶和华亲自在你前面行。祂必与你同在，必不撇下你，也不离弃你。不要惧怕，也不要沮丧。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 4:15; 约书亚记 3:3; 申命记 17:18"> 摩西写下这律法，交给抬耶和华约柜的利未子孙祭司，以及以色列的众长老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 23:34–43; 申命记 15:1–2"> 摩西吩咐他们说：“每逢七年的末了，在豁免年的指定时候，在住棚节，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:2; 约书亚记 8:34–35; 申命记 16:16–17"> 当以色列众人来到耶和华你的上帝所选择的地方，朝见祂的时候，你要在以色列众人面前，把这律法读给他们听。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:10; 诗篇 34:11–14; 申命记 6:6–7"> 要召集百姓，男人、女人、孩子，以及你城门内的寄居者，使他们可以听见、学习、敬畏耶和华你们的上帝，并谨守遵行这律法的一切话；</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 11:2; 申命记 6:7; 箴言 22:6"> 也使他们还不认识这律法的儿女，可以听见并学习敬畏耶和华你们的上帝，好叫你们在过约旦河去得为业的地上居住的日子，都这样行。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 27:13; 申命记 31:23; 约伯记 2:1"> 耶和华对摩西说：“看哪，你死期临近了。你要召约书亚来，你们一同站在会幕里，好让我任命他。”<br />摩西和约书亚就去，站在会幕里。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 40:38; 诗篇 99:7; 出埃及记 33:9–10"> 耶和华在帐幕里、在云柱中显现；云柱停在帐幕门口上方。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 士师记 10:13; 士师记 2:12"> 耶和华对摩西说：“看哪，你必与列祖同睡。这百姓起来以后，要在他们所去寄居之地随从外族的神行淫，离弃我，违背我与他们所立的约。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:42; 以赛亚书 8:17; 诗篇 104:29"> 到那日，我的怒气必向他们发作；我必离弃他们，向他们掩面，他们就要被吞灭，许多灾祸和患难必临到他们。到那日，他们必说：‘这些灾祸临到我们，不是因为我们的上帝不在我们中间吗？’</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 31:16–17"> 到那日，因他们转向别的神所行的一切恶，我必定向他们掩面。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 申命记 31:21–22; 申命记 31:26"> “现在你们要为自己写下这首歌，教导以色列子孙，把它放在他们口中，好使这首歌为我作见证，指证以色列子孙。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿 13:6; 申命记 6:10–12; 尼希米记 9:25–26"> 因为我将他们带进我向他们列祖起誓所应许的流奶与蜜之地，他们吃得饱足，身体肥胖以后，就会转向别的神，事奉它们，藐视我，违背我的约。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿 5:3; 诗篇 139:2; 约翰福音 2:24–25"> 将来许多灾祸和患难临到他们的时候，这首歌要在他们面前作见证；因为这歌必不从他们后裔的口中被忘记。因为在我把他们带进我所应许给他们的地以前，我已经知道他们今天的意念和所行的事。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 31:19; 申命记 31:9"> 于是摩西当天写下这首歌，教导以色列子孙。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 31:7–8; 申命记 31:14; 使徒行传 7:45"> 祂任命嫩的儿子约书亚，说：“你要刚强壮胆；因为你要把以色列子孙带进我向他们起誓所应许的地。我必与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 31:9; 申命记 17:18"> 摩西把这律法的话写在书上，直到写完为止。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 31:9"> 摩西吩咐抬耶和华约柜的利未人说：</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 31:19; 列王纪下 22:8–11; 加拉太书 2:19"> “你们要把这律法书放在耶和华你们上帝的约柜旁边，让它在那里作见证，指证你们。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 32:20; 申命记 9:24; 使徒行传 7:51"> 因为我知道你们的悖逆和你们的硬颈。看哪，我今天还活着与你们同在的时候，你们尚且悖逆耶和华，何况我死以后呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:1; 申命记 4:26; 申命记 30:19"> 你们要把你们各支派的众长老和官长召集到我这里，我好把这些话说给他们听，并呼天唤地作见证指证他们。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 2:19; 申命记 32:5; 路加福音 21:24"> 因为我知道，我死以后，你们必全然败坏，偏离我所吩咐你们的道路；日后灾祸必临到你们，因为你们必行耶和华眼中看为恶的事，用你们手所做的惹祂发怒。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 3:2; 申命记 4:5; 约翰福音 12:49"> 摩西把这首歌的话从头到尾说给以色列全会众听。</span>
</div>
</div>

</div>

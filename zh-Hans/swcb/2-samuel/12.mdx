<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:35–41; 诗篇 51:1–19; 撒母耳记下 11:10–17"> 耶和华差遣拿单到大卫那里。拿单来到他面前，对他说：“在一座城里有两个人：一个富有，另一个贫穷。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 15:16; 约伯记 1:3; 撒母耳记下 5:13–16"> 富人有极多的羊群和牛群；</span>
<span className="v" id="v3" data-v="3" data-xref="弥迦书 7:5; 撒母耳记下 11:3; 箴言 5:18–19"> 穷人除了所买来养活的一只小母羊羔以外，什么也没有。羊羔和他以及他的儿女一同长大，吃他自己的食物，喝他自己的杯，睡在他的怀里，对他来说就像女儿一样。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 1:14; 撒母耳记下 11:3–4; 创世记 18:2–7"> 有一个旅客来到富人那里，富人舍不得从自己的羊群牛群中取一只预备给那到他这里来的过路人，反而取了穷人的羊羔，预备给那到他这里来的人。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 38:24; 罗马书 2:1; 撒母耳记上 26:16"> 大卫向那人怒气大作，对拿单说：“我指着永活的耶和华起誓，做这事的人该死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:1; 路加福音 19:8; 箴言 6:31"> 他必须偿还四倍的羊羔，因为他做了这事，又因为他毫无怜悯！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:14; 撒母耳记上 16:13; 撒母耳记下 22:1"> 拿单对大卫说：“你就是那人！耶和华——以色列的上帝如此说：‘我膏立你作以色列的王，救你脱离扫罗的手。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 84:11; 罗马书 8:32; 撒母耳记下 9:7"> 我把你主人的家和你主人的妻子交在你怀里，又把以色列家和犹大家赐给你；如果这些还太少，我还会把许多这样的事加给你。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:19; 诗篇 139:1–2; 撒母耳记上 15:23"> 你为什么藐视耶和华的话，行祂眼中看为恶的事呢？你用刀击杀赫人乌利亚，娶了他的妻子作你的妻子，又借亚扪人的刀杀了他。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14–15; 马太福音 26:52; 罗马书 2:4"> 现在，刀剑必永不离开你的家，因为你藐视我，娶了赫人乌利亚的妻子作你的妻子。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 16:21–22; 申命记 28:30; 撒母耳记下 15:10"> “耶和华如此说：‘看哪，我必从你自己的家中兴起灾祸攻击你；我必在你眼前取走你的妻子，把她们交给你的邻舍；他必在这日光之下与你的妻子同寝。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 16:22; 撒母耳记下 11:4–15; 传道书 12:14"> 你暗中做了这事，但我必在全以色列面前、在日光之下做这事。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:4; 撒母耳记下 24:10; 箴言 28:13"> 大卫对拿单说：“我得罪了耶和华。”<br />拿单对大卫说：“耶和华也已经除掉你的罪；你不会死。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:24; 以赛亚书 52:5; 诗篇 89:31–33"> 然而，因为你这事使耶和华的仇敌大得亵渎的机会，你所生的孩子也必定要死。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:38; 诗篇 104:29; 历代志下 13:20"> 然后拿单回自己家去了。<br />耶和华击打乌利亚的妻子给大卫所生的孩子，孩子就病得很重。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 13:31; 使徒行传 9:9; 诗篇 69:10"> 因此大卫为这孩子恳求上帝；大卫禁食，进去整夜伏在地上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 撒母耳记上 28:23"> 他家中的长老在他旁边起来，要把他从地上扶起来；但他不肯，也不和他们一起吃饭。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 20:15"> 到第七天，孩子死了。大卫的臣仆害怕告诉他孩子死了，因为他们说：“看哪，孩子还活着的时候，我们对他说话，他都不听我们的声音；如果我们告诉他孩子死了，他岂不伤害自己吗？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 但大卫看见臣仆彼此低声说话，就察觉孩子死了；大卫对臣仆说：“孩子死了吗？”<br />他们说：“死了。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:20; 路得记 3:3; 耶利米哀歌 3:39–41"> 大卫就从地上起来，沐浴，抹膏，换了衣服；他进耶和华的殿敬拜。然后他回到自己家里；他一要求，他们就把食物摆在他面前，他便吃了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 2:15"> 臣仆对他说：“你所做的这事是什么意思呢？孩子活着的时候，你禁食哭泣；孩子死了，你却起来吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 38:1–3; 以赛亚书 38:5; 约拿 3:9–10"> 他说：“孩子还活着的时候，我禁食哭泣；因为我说：‘谁知道耶和华会不会恩待我，使孩子可以活呢？’</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:35; 约伯记 30:23; 路加福音 23:43"> 但现在他死了，我为什么还要禁食呢？我能使他再回来吗？我必到他那里去，他却不能回到我这里来。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:6; 历代志上 28:5–6; 历代志上 22:9–10"> 大卫安慰他的妻子拔示巴，就进去与她同寝。她生了一个儿子，大卫给他起名叫所罗门。耶和华爱他；</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 7:4; 尼希米记 13:26; 列王纪上 1:11"> 耶和华借先知拿单的手传话，给他起名叫耶底底亚，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“耶底底亚”的意思是“蒙耶和华所爱的”。">a</a></sup>是为耶和华的缘故。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 20:1–3; 申命记 3:11; 撒母耳记下 11:25"> 约押攻打亚扪人的拉巴，攻取了王城。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结 21:20; 撒母耳记下 11:1; 申命记 3:11"> 约押派使者到大卫那里，说：“我攻打了拉巴。是的，我已经攻取了水城。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 7:18"> 现在，请你聚集其余的百姓，安营攻城，夺取这城；免得我夺取这城，它就以我的名命名。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 大卫聚集全体百姓，前往拉巴，攻打它，并夺取了它。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 20:2"> 他从他们王的头上取下王冠；这王冠的重量是一他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为30公斤、66磅或965金衡盎司。">b</a></sup>金子，上面镶着宝石；这王冠被戴在大卫头上。他从城中带出大量掠物。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 20:3; 诗篇 21:8–9; 阿摩司 1:3"> 他把城里的人带出来，使他们用锯、铁镐、铁斧劳作，又使他们到砖窑做工；他对亚扪人的各城都这样做。然后大卫和全体百姓回耶路撒冷去了。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 13:1–4; 列王纪上 8:1; 历代志上 13:6–14"> 大卫又聚集以色列所有被拣选的人，共三万人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:4; 撒母耳记上 7:1; 诗篇 80:1"> 大卫起身，和所有跟随他的人从巴拉·犹大出发，要从那里把上帝的约柜运上来；这约柜是以那名，就是坐在基路伯之上的万军之耶和华的名来称呼的。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 6:7; 民数记 7:4–9; 民数记 4:5–12"> 他们把上帝的约柜放在一辆新车上，从山上亚比拿达的家里运出来；亚比拿达的儿子乌撒和亚希约赶着这辆新车。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:7; 撒母耳记上 7:1–2"> 他们把约柜从山上亚比拿达的家里运出来，上帝的约柜在车上；亚希约走在约柜前面。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 13:8; 诗篇 150:3–5; 阿摩司 5:23"> 大卫和以色列全家在耶和华面前，用各样柏木制的乐器，以及琴、弦乐器、手鼓、响板和钹奏乐。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 13:9; 民数记 4:15; 民数记 4:19–20"> 他们到了拿艮的禾场，乌撒伸手扶住上帝的约柜，因为牛失前蹄。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 6:19; 历代志上 15:13; 历代志上 13:10"> 耶和华向乌撒发怒，上帝因他的过失在那里击杀他；他就死在上帝的约柜旁。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿 4:1; 历代志上 13:11–12; 约拿 4:9"> 大卫因耶和华击杀乌撒而不悦；他称那地方为毗列斯·乌撒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“毗列斯·乌撒”的意思是“击杀乌撒”。">a</a></sup>，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 119:120; 历代志上 13:11–12; 民数记 17:12–13"> 那日，大卫惧怕耶和华，说：“耶和华的约柜怎能到我这里来呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 26:4–8; 撒母耳记下 15:19; 历代志上 15:18"> 于是大卫不肯把耶和华的约柜搬到大卫城他那里去，却把它转运到迦特人俄别·以东的家中。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:5; 创世记 30:27; 箴言 3:9–10"> 耶和华的约柜在迦特人俄别·以东的家中停留三个月；耶和华赐福给俄别·以东和他全家。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 15:25–3; 列王纪上 8:1; 马太福音 10:42"> 有人告诉大卫王说：“耶和华因上帝的约柜，赐福给俄别·以东的家和他一切所有的。”<br />于是大卫欢欢喜喜地去，把上帝的约柜从俄别·以东的家中运上大卫城。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:5; 历代志上 15:15; 民数记 4:15"> 抬耶和华约柜的人走了六步，大卫就献上一头牛和一只肥牛犊为祭。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 2:18; 出埃及记 15:20; 诗篇 150:4"> 大卫在耶和华面前尽力跳舞；大卫穿着细麻布的以弗得。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 68:24–27; 历代志上 15:28; 历代志上 15:25"> 这样，大卫和以色列全家欢呼吹角，把耶和华的约柜运上来。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 2:14; 历代志上 15:29; 诗篇 69:7"> 耶和华的约柜进入大卫城的时候，扫罗的女儿米甲从窗户往外观看，看见大卫王在耶和华面前踊跃跳舞，心里就轻视他。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 15:1; 历代志下 1:4; 列王纪上 8:5"> 他们把耶和华的约柜抬进去，安放在它的地方，就是大卫为它搭的帐幕中央；大卫在耶和华面前献上燔祭和平安祭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 8:55; 历代志上 16:2; 创世记 14:19"> 大卫献完燔祭和平安祭，就奉万军之耶和华的名祝福百姓。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 8:10; 历代志下 35:7–8; 历代志上 16:3"> 他分给众人，就是以色列全体会众，无论男女，每人一份饼、枣子和葡萄干。于是众人都离开，各回各家去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 6:16; 撒母耳记下 6:14; 士师记 9:4"> 大卫回去要祝福自己的家。扫罗的女儿米甲出来迎接大卫，说：“以色列王今日多么荣耀啊！他今日在臣仆的婢女眼前露体，像一个轻浮人无耻地露体一样！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:22; 诗篇 89:19–20; 撒母耳记上 13:14"> 大卫对米甲说：“这是在耶和华面前；祂拣选了我，高过你父亲和他全家，立我作耶和华子民以色列的君王。因此，我要在耶和华面前欢庆。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:14; 希伯来书 12:2; 以赛亚书 51:7"> 我还要比这更加卑微，在我自己眼中看为低贱。但你所说的那些婢女，必尊敬我。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:25; 以赛亚书 22:14; 以赛亚书 4:1"> 扫罗的女儿米甲，直到死的日子都没有孩子。</span>
</div>
</div>

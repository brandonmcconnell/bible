<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 1:5; 撒母耳记下 12:11; 撒母耳记上 8:11"> 这事以后，押沙龙为自己预备了战车和马，又派五十人在他前面奔跑。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:14; 路得记 4:1; 约伯记 24:14"> 押沙龙清早起来，站在城门路旁。凡有争讼要到王那里求审判的人，押沙龙就叫住他，说：“你是哪一城的人？”<br />那人说：“仆人是以色列某一个支派的人。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:15; 以西结 22:7; 彼得前书 2:17"> 押沙龙对他说：“看哪，你的案件有理，也正当；可是王没有委派人来听你的案子。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:29; 士师记 9:1–5; 箴言 27:2"> 押沙龙又说：“唉，愿我被立为这地的审判官！凡有争讼或案件的人都可以到我这里来，我必为他主持公道。”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:33; 诗篇 55:21; 箴言 26:25"> 每当有人近前来向他下拜，他就伸手拉住那人，与他亲吻。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:18; 彼得后书 2:3; 箴言 11:9"> 凡以色列人到王那里求审判的，押沙龙都这样待他们。于是押沙龙窃取了以色列人的心。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 58:4; 撒母耳记上 16:13; 撒母耳记上 16:1–2"> 过了四十年，押沙龙对王说：“请准我去希伯仑，偿还我向耶和华所许的愿。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:20–21; 撒母耳记下 13:37–38; 撒母耳记上 1:11"> 因为仆人住在亚兰的基述时曾许愿说：‘如果耶和华真的带我回到耶路撒冷，我就要事奉耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 王对他说：“你平安地去吧。”<br />于是他起身，往希伯仑去了。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 12:38; 撒母耳记下 5:5; 撒母耳记下 3:2–3"> 押沙龙派探子走遍以色列各支派，说：“你们一听见号角的声音，就要说：‘押沙龙在希伯仑作王了！’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:13; 撒母耳记上 22:15; 罗马书 16:18–19"> 有二百人受邀，从耶路撒冷与押沙龙同去；他们单纯地去了，什么也不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 41:9; 撒母耳记下 15:31; 约书亚记 15:51"> 押沙龙献祭的时候，派人从亚希多弗自己的城，就是基罗，把大卫的谋士基罗人亚希多弗请来。叛乱的势力强大，因为跟随押沙龙的人不断增多。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 9:3; 马太福音 27:22; 撒母耳记下 15:6"> 有使者来见大卫，说：“以色列人的心都归向押沙龙了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:9; 以西结 46:18; 诗篇 55:3–11"> 大卫对所有在耶路撒冷与他同在的臣仆说：“起来！我们逃走吧，不然我们没有人能逃脱押沙龙。要赶快离开，免得他迅速追上我们，把灾祸降在我们身上，并用刀杀戮这城。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:66–69; 箴言 18:24; 路加福音 22:28–29"> 王的臣仆对王说：“看哪，我主我王所选择的，无论是什么，仆人都愿意去做。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:21–22; 撒母耳记下 20:3; 诗篇 3:1"> 王出去了，他全家都跟在他后面。王留下十个妃嫔看守宫殿。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 3:1–2; 传道书 10:7; 诗篇 66:12"> 王出去了，所有百姓都跟在他后面；他们停在伯·米哈。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 8:18; 撒母耳记上 30:14; 撒母耳记下 20:7"> 他所有的臣仆都从他身旁经过；所有基利提人、所有比利提人，以及所有迦特人，就是从迦特跟随他来的六百人，都从王面前经过。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 18:2; 路得记 1:11–13"> 王对迦特人以太说：“你为什么也要跟我们去呢？回去，留在王那里吧；因为你是外邦人，也是流亡的人。回你自己的地方去吧。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:13; 撒母耳记下 2:6; 约翰福音 1:17"> 你昨天才来，今天我岂可使你跟我们漂泊呢？因为我不知道自己要往哪里去。你回去，也带你的弟兄们回去吧。愿慈爱和信实与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路得记 1:16–17; 箴言 17:17; 列王纪下 4:30"> 以太回答王说：“我指着永活的耶和华起誓，也指着我主我王的性命起誓：无论我主我王在哪里，或死或生，仆人也必在那里。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 大卫对以太说：“去吧，过去。”于是迦特人以太和他所有的人，以及跟随他的所有小孩子，都过去了。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:2; 列王纪上 2:37; 约翰福音 18:1"> 全地的人都放声哭泣，所有百姓都过去了。王自己也过了汲沦溪，所有百姓都过去，往旷野的路去了。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:15; 撒母耳记下 8:17; 撒母耳记下 20:25"> 看哪，撒督也来了，所有利未人与他同来，抬着上帝的约柜；他们放下上帝的柜；亚比亚他上去，直到所有百姓都从城里出来过去了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 25:30; 诗篇 26:8; 诗篇 43:3–4"> 王对撒督说：“把上帝的柜抬回城里去。如果我在耶和华眼前蒙恩，祂必带我回来，使我再见到它和祂的居所；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 3:18; 撒母耳记下 22:20; 列王纪上 10:9"> 但如果祂说：‘我不喜悦你’，看哪，我在这里。愿祂照祂看为好的待我。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 9:9; 撒母耳记下 17:17; 撒母耳记下 24:11"> 王又对祭司撒督说：“你不是先见吗？你平安地回城去吧，你的两个儿子也与你同去，就是你的儿子亚希玛斯和亚比亚他的儿子约拿单。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 17:16; 撒母耳记下 15:23; 撒母耳记下 17:1"> 看哪，我要停留在旷野的渡口，直到有消息从你们那里来通知我。”</span>
<span className="v" id="v29" data-v="29"> 于是撒督和亚比亚他把上帝的柜抬回耶路撒冷；他们就住在那里。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 6:12; 撒母耳记下 19:4; 路加福音 19:41"> 大卫沿着橄榄山的坡道上去，一边上去一边哭；他蒙着头，赤着脚。所有与他同在的百姓也都各自蒙着头，一边上去一边哭。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 17:14; 撒母耳记下 17:23; 雅各书 3:15"> 有人告诉大卫说：“亚希多弗也在与押沙龙一同叛乱的人中。”<br />大卫说：“耶和华啊，求你使亚希多弗的计谋变为愚拙。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 16:2; 撒母耳记下 1:2; 诗篇 3:3–5"> 大卫到了山顶，就是敬拜上帝的地方，看哪，亚基人户筛前来迎接他，衣服撕裂，头上蒙尘。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:35"> 大卫对他说：“如果你跟我过去，就会成为我的负担；</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:2; 撒母耳记下 16:16–19; 马太福音 10:16"> 但你若回城，对押沙龙说：‘王啊，我愿作你的仆人；过去我怎样作你父亲的仆人，现在也照样作你的仆人。’这样，你就能为我挫败亚希多弗的计谋。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 17:15–16"> 撒督和亚比亚他两位祭司不是在那里与你同在吗？所以你在王宫里所听见的一切，都要告诉撒督和亚比亚他两位祭司。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 17:17; 撒母耳记下 15:27; 撒母耳记下 18:19–33"> 看哪，他们的两个儿子也在那里与他们同在，就是撒督的儿子亚希玛斯和亚比亚他的儿子约拿单。你们要借着他们把你所听见的一切传给我。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 16:15–16; 历代志上 27:33"> 于是大卫的朋友户筛进了城；押沙龙也进了耶路撒冷。</span>
</div>
</div>

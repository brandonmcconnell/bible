<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 18:5; 撒母耳记下 18:14; 箴言 17:25"> 有人告诉约押：“看哪，王为押沙龙哭泣哀悼。”</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 19:12; 箴言 16:15"> 那一天，胜利在全体百姓中变成了哀恸，因为那一天百姓听见有人说：“王为他的儿子悲伤。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 31:27; 撒母耳记下 19:32; 撒母耳记下 17:24"> 那一天，百姓偷偷进城，好像在战场逃跑、蒙羞的人悄悄溜走一样。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:33; 撒母耳记下 15:30"> 王蒙着脸，大声呼喊：“我儿押沙龙啊！押沙龙，我儿，我儿啊！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:47–48; 诗篇 3:8; 尼希米记 9:27"> 约押进屋到王那里，说：“今天，你使你所有仆人的脸蒙羞了；他们今天救了你的性命，也救了你儿女的性命、你妻子们的性命和你妃嫔们的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 23:5; 撒母耳记下 3:24–25; 箴言 19:9–10"> 因为你爱恨你的人，恨爱你的人。今天你表明，众首领和仆人在你眼中算不得什么。我今天看出来，如果押沙龙还活着，而我们今天全都死了，你就会满意。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 14:28; 创世记 34:3; 箴言 19:15"> 现在，起来，出去安慰你的仆人；因为我指着耶和华起誓，如果你不出去，今夜必没有一个人留下来跟随你。那对你来说，必比你从幼年直到如今所遭遇的一切祸患更坏。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 18:24; 撒母耳记下 18:4; 撒母耳记下 19:3"> 于是王起来，坐在城门口。有人告诉全体百姓：“看哪，王坐在城门口。”全体百姓都来到王面前。以色列人却各自逃回自己的帐棚去了。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 15:14; 创世记 3:12–13; 撒母耳记下 8:1–14"> 以色列众支派中，众百姓都在争论，说：“王曾救我们脱离仇敌的手，也救我们脱离非利士人的手；如今他却因押沙龙逃离了本地。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14; 士师记 18:9; 何西阿 8:4"> 我们膏立来治理我们的押沙龙已经战死了。现在，你们为什么不说一句请王回来的话呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 15:29; 列王纪上 2:35; 撒母耳记下 15:35–36"> 大卫王派人去见撒督和亚比亚他两位祭司，说：“你们要对犹大的长老说：‘全以色列的话已经传到王那里，要请王回宫，你们为什么反倒成了最后请王回宫的人呢？</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 5:1; 创世记 2:23; 以弗所书 5:30"> 你们是我的弟兄，是我的骨肉。你们为什么成了最后请王回来的人呢？’</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 17:25; 列王纪上 19:2; 路得记 1:17"> 也要对亚玛撒说：‘你不是我的骨肉吗？如果你不常在我面前作军队的元帅，取代约押，愿上帝重重地惩罚我。’”</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:1; 使徒行传 4:32; 诗篇 110:2–3"> 王就使全体犹大人的心都归向他，如同一人；于是他们派人去见王，说：“请你和你所有的仆人回来吧。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 5:9; 撒母耳记上 11:14–15"> 于是王回来，到了约旦河。犹大人来到吉甲，要去迎接王，送王过约旦河。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:8; 撒母耳记下 16:5–13; 列王纪上 2:36–46"> 来自巴户琳的便雅悯人基拉的儿子示每，急忙同犹大人一起下去迎接大卫王。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 16:1–4; 撒母耳记下 9:2; 撒母耳记下 9:10"> 跟随他的有一千名便雅悯人，还有扫罗家的仆人洗巴，以及他十五个儿子和二十个仆人；他们在王面前渡过约旦河。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 81:15; 启示录 3:9; 诗篇 66:3"> 有渡船过去，要把王的家眷接过来，并照王看为好的去做。<br />基拉的儿子示每在王过约旦河的时候，俯伏在王面前。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 22:15; 撒母耳记下 13:20; 撒母耳记下 13:33"> 他对王说：“求我主不要将罪孽归给我，也不要记念我主我王出耶路撒冷那天，你仆人所行的悖逆之事；愿王不要把这事放在心上。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 12:25; 诗篇 78:34–37; 创世记 48:14"> 因为你仆人知道我犯了罪。所以，看哪，今天我在约瑟全家中首先下来迎接我主我王。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 22:28; 撒母耳记上 26:9; 列王纪上 21:10–11"> 但洗鲁雅的儿子亚比筛回答说：“示每既然咒骂耶和华的受膏者，难道不该为此被处死吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 11:13; 撒母耳记下 16:10; 撒母耳记下 3:39"> 大卫说：“洗鲁雅的儿子们，我与你们有什么相干，使你们今天与我作对呢？今天在以色列中岂可处死人呢？我岂不知道今天我是以色列的王吗？”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:46; 列王纪上 2:8–9; 列王纪上 2:37"> 王对示每说：“你必不死。”王就向他起誓。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 41:5; 马太福音 6:16; 撒母耳记下 15:30"> 扫罗的后裔米非波设下来迎接王；从王离开的那天直到他平安回来的那天，他没有修脚，没有修胡须，也没有洗衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 16:17"> 他来到耶路撒冷迎接王的时候，王对他说：“米非波设，你为什么没有和我同去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 16:2–3; 撒母耳记下 4:4; 撒母耳记下 9:3"> 他回答说：“我主我王啊，我的仆人欺骗了我。因为你仆人曾说：‘我要为自己备上驴，好骑上它与王同去，’因为你仆人是瘸腿的。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 14:17; 撒母耳记下 14:20; 撒母耳记上 29:9"> 他却向我主我王诽谤你仆人；但我主我王如同上帝的天使。所以，照你眼中看为好的去做吧。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 9:13; 撒母耳记下 9:10; 撒母耳记下 21:6–9"> 因为我父全家在我主我王面前都不过是该死的人；可是你却把你仆人列在与你同桌吃饭的人中。我还有什么权利再向王呼求呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 18:15; 诗篇 101:5; 诗篇 82:2"> 王对他说：“你为什么还要多说你的事呢？我说，你和洗巴分这土地。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="腓立比书 1:20; 使徒行传 20:24; 撒母耳记下 1:26"> 米非波设对王说：“是的，让他全都拿去吧；因为我主我王已经平安回到自己的家了。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:7; 尼希米记 7:63; 以斯拉记 2:61"> 基列人巴西莱从罗基琳下来；他同王一起过约旦河，要送王过约旦河。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 25:2; 约伯记 1:3; 箴言 16:31"> 巴西莱年纪很老，已经八十岁了。王住在玛哈念的时候，他曾供给王食物，因为他是极富有的人。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 25:34–40; 路加福音 22:28–30; 撒母耳记下 9:11"> 王对巴西莱说：“你和我一同过去吧，我要在耶路撒冷供养你，使你与我同在。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:14; 哥林多前书 7:29; 创世记 47:8–9"> 巴西莱对王说：“我一生的年日还有多少，竟要与王一同上耶路撒冷呢？</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 15:33; 以斯拉记 2:65; 诗篇 90:10"> 我今天已经八十岁了。好坏我还能分辨吗？你仆人还能尝出所吃所喝的滋味吗？我还能听见歌唱的男女的声音吗？你仆人又何必成为我主我王的负担呢？</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:38"> 你仆人只要同王过约旦河就好了。王为什么要用这样的赏赐来报答我呢？</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪上 2:7; 耶利米书 41:17; 撒母耳记下 19:40"> 求你让你仆人回去，好让我死在自己的城里，葬在我父母的坟墓旁。看哪，你仆人金罕在这里；让他同我主我王过去吧；你看怎样好，就怎样待他。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 王回答说：“金罕可以和我一同过去；你看怎样好，我就怎样待他。凡你向我所求的，我都要为你做。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="创世记 31:55; 路得记 1:14; 创世记 47:7"> 全体百姓都过了约旦河，王也过去了。王亲吻巴西莱，为他祝福；巴西莱就回自己的地方去了。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:9; 创世记 49:10; 撒母耳记下 19:11–15"> 王过去到了吉甲，金罕也和他一同过去。犹大全体百姓送王过去，以色列百姓的一半也送王过去。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 8:1; 士师记 12:1; 约翰福音 7:5–6"> 看哪，以色列众人都来到王那里，对王说：“为什么我们的弟兄犹大人偷偷把你带走，送王和王的家眷过约旦河，又把所有跟随他的大卫的人也带过来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 19:12; 撒母耳记下 5:1; 历代志上 2:3–17"> 犹大众人回答以色列人说：“因为王与我们亲近。你们为什么因这事发怒呢？我们吃过王的什么吗？或者他给过我们什么礼物吗？”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="加拉太书 5:20; 撒母耳记下 5:1; 列王纪上 11:30–31"> 以色列人回答犹大人说：“按支派，我们在王身上有十分，我们对大卫也比你们更有份。你们为什么轻看我们，不先听取我们的意见，把我们的王请回来呢？”但犹大人的话比以色列人的话更强硬。</span>
</div>
</div>

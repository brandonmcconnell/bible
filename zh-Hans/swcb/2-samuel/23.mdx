<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 27:2; 历代志上 11:11–47; 历代志上 27:32"> 以下是大卫所有勇士的名字：塔革扪人约设·巴设，是众军长之首；他名叫以斯尼人亚底挪，曾一次击杀八百人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:4; 历代志上 11:12–14; 撒母耳记上 17:26"> 其次是亚合人朵代的儿子以利亚撒，他是跟随大卫的三个勇士之一。当时非利士人聚集在那里要打仗，他们向非利士人挑战，以色列人却撤退了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:5; 撒母耳记上 11:13; 士师记 15:14"> 他起来击杀非利士人，直到手疲乏，手紧贴住刀；那一天，耶和华施行了大拯救；众人只回来跟在他后面夺取掠物。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 11:13–14; 历代志上 11:27; 撒母耳记下 23:33"> 其次是哈拉人亚基的儿子沙玛。非利士人聚集成一队，在一块长满扁豆的田里；百姓就在非利士人面前逃跑。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳记下 23:10; 诗篇 3:8"> 但他站在那块田中间守卫它，击杀非利士人；耶和华施行了大拯救。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:1; 撒母耳记下 5:18; 约书亚记 12:15"> 三十个首领中的三个人下到亚杜兰洞，在收割的时候来到大卫那里；非利士人的一队军兵在利乏音谷安营。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 22:4–5; 撒母耳记上 13:4; 撒母耳记上 10:5"> 那时大卫在山寨里；非利士人的驻军当时在伯利恒。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:14; 诗篇 42:1–2; 以赛亚书 41:17"> 大卫渴望地说：“但愿有人从伯利恒城门旁的井里打水给我喝！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 35:14; 哥林多后书 5:14; 腓立比书 2:17"> 这三个勇士就闯过非利士人的军营，从伯利恒城门旁的井里打水，带来给大卫；但他不肯喝，却把水倒出来献给耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 马可福音 14:24; 哥林多前书 15:30"> 他说：“耶和华啊，我绝不可做这事！这岂不是那些冒生命危险去的人们的血吗？”因此他不肯喝。这些事是那三个勇士所做的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:10; 撒母耳记下 10:14; 历代志上 11:20–21"> 洗鲁雅的儿子、约押的兄弟亚比筛，是这三个人的首领。他举起枪攻击三百人，杀了他们，因此在这三个人中有名声。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:8; 马太福音 13:23; 哥林多前书 15:41"> 他岂不是这三个人中最尊贵的吗？所以他作了他们的首领。不过他并没有列入那三个人之中。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 8:18; 约书亚记 15:21; 撒母耳记下 20:23"> 耶何耶大的儿子比拿雅，是甲薛一个勇士的儿子，行过大能的事；他杀了摩押人亚利伊勒的两个儿子。他又在下雪的时候，下到坑中杀了一只狮子。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 17:51; 历代志上 11:23; 歌罗西书 2:15"> 他杀了一个身材高大的埃及人；那埃及人手里拿着枪，他却拿着棍子下去迎战，从埃及人手里夺过枪来，用那人的枪杀了他。</span>
<span className="v" id="v22" data-v="22"> 耶何耶大的儿子比拿雅做了这些事，因此在三个勇士中有名声。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 20:23; 历代志上 27:6; 撒母耳记上 22:14"> 他比三十个勇士更尊贵，却没有达到那三个人的地位。大卫派他统管自己的护卫。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 2:18; 历代志上 27:7; 历代志上 11:26"> 约押的兄弟亚撒黑是三十个勇士之一；还有伯利恒人朵多的儿子伊勒哈难，</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 7:1; 历代志上 11:27–28"> 哈律人沙玛，哈律人以利加，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 历代志上 11:27–28; 历代志上 27:9–10"> 帕勒提人希利斯，提哥亚人益吉的儿子以拉，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 21:18; 历代志上 11:19; 历代志上 11:28"> 亚拿突人亚比以谢，户沙人米本乃，</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:13; 列王纪下 25:23; 历代志上 11:30"> 亚合人撒们，尼陀法人玛哈莱，</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 11:30–31; 约书亚记 18:28; 历代志上 27:15"> 尼陀法人巴拿的儿子希立，便雅悯子孙基比亚人利拜的儿子以太，</span>

<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:16; 历代志上 11:32–33"> 亚拉巴人亚比亚本，巴鲁米人押斯玛弗，</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 11:34"> 沙本人以利雅哈，雅善的儿子们，约拿单，</span>

<span className="v" id="v37" data-v="37" data-xref="历代志上 11:37; 历代志上 11:39; 撒母耳记下 4:2"> 亚扪人洗勒，比录人拿哈莱，他们是给洗鲁雅的儿子约押拿兵器的，</span>

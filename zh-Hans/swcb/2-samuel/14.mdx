<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 13:39; 撒母耳记下 2:18; 撒母耳记下 18:33"> 洗鲁雅的儿子约押察觉王的心向着押沙龙。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:6; 阿摩司 1:1; 路得记 3:3"> 约押派人到提哥亚，从那里带来一个聪明的妇人，对她说：“请你装作居丧的人，穿上丧服，不要用油抹身；要像一个为死人哀悼很久的妇人。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:19; 出埃及记 4:15; 以赛亚书 51:16"> 你进去见王，对他这样说。”于是约押把要说的话放在她口中。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 1:2; 列王纪下 6:26–28; 撒母耳记上 25:23"> 提哥亚的妇人对王说话的时候，就伏脸于地，向王下拜，说：“王啊，求你救我！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士师记 9:8–15; 撒母耳记下 12:1–3"> 王对她说：“你有什么事？”<br />她回答说：“我实在是个寡妇，丈夫已经死了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 4:8; 申命记 22:26–27; 出埃及记 2:13"> 你的婢女有两个儿子；他们二人在田间争斗，没有人把他们分开，其中一个打了另一个，把他杀了。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:19; 马太福音 21:38; 撒母耳记下 12:17"> 看哪，全家都起来攻击你的婢女，说：‘把那打死兄弟的人交出来，我们好因他所杀兄弟的性命杀他，并且也除灭那承受产业的。’这样，他们就要熄灭我所剩下的炭火，不给我丈夫在地面上留下名号和余存的人。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; 以赛亚书 11:3–4; 约伯记 29:16"> 王对妇人说：“你回家去吧，我必为你的事下命令。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 25:24; 列王纪上 2:33; 马太福音 27:25"> 提哥亚的妇人对王说：“我主我王啊，愿这罪孽归在我和我父家身上；愿王和王的宝座无罪。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 王说：“无论谁对你说什么，你都带他到我这里来，他就不再骚扰你。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 14:45; 马太福音 10:30; 民数记 35:19"> 她说：“请王记念耶和华你的上帝，使报血仇的人不再毁灭，免得他们毁灭我的儿子。”<br />王说：“我指着永活的耶和华起誓，你儿子连一根头发也不会落在地上。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 18:27; 撒母耳记上 25:24; 使徒行传 26:1"> 妇人说：“请让我这婢女对我主我王说一句话。”<br />王说：“你说吧。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 13:37–38; 撒母耳记下 12:7; 士师记 20:2"> 妇人说：“那么，你为什么筹划这样的事，攻击上帝的民呢？王说出这话，就好像有罪的人一样，因为王不把自己被放逐的人接回家来。</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 30:23; 民数记 35:28; 希伯来书 9:27"> 我们都必死亡，好像泼在地上的水，不能再收回；上帝也不夺取生命，却设法使被放逐的人不至于被祂弃绝。</span>
<span className="v" id="v15" data-v="15"> 现在我来对我主我王说这话，是因为百姓使我惧怕。你的婢女说：‘我要去对王说话，也许王会成全婢女的请求。’</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:19"> 因为王必垂听，要救他的婢女脱离那人的手；那人想把我和我儿子一同从上帝的产业中除灭。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 29:9; 撒母耳记下 19:27; 撒母耳记下 14:20"> 你的婢女又说：‘愿我主我王的话使人安息；因为我主我王像上帝的使者一样，能辨别善恶。愿耶和华你的上帝与你同在。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:25; 撒母耳记上 3:17–18; 耶利米书 38:14"> 王回答妇人说：“我问你的事，请你不要向我隐瞒。”<br />妇人说：“请我主我王说吧。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:3; 撒母耳记上 1:26; 撒母耳记上 20:3"> 王说：“这一切事，是不是约押的手与你同在？”<br />妇人回答说：“我主我王啊，我指着你的性命起誓，凡我主我王所说的，没有人能向右或向左偏离；是你的仆人约押吩咐我，他把这一切话放在你婢女口中。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 14:17; 撒母耳记下 19:27; 约伯记 32:21–22"> 你的仆人约押做这事，是要改变事情的局面。我主有智慧，如同上帝使者的智慧，能知道地上的一切事。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 14:11; 撒母耳记上 14:39; 马可福音 6:26"> 王对约押说：“看哪，现在我准了这事。你去，把那年轻人押沙龙带回来。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路得记 2:2; 约伯记 31:20; 约伯记 29:11"> 约押伏脸于地，向王下拜，并称颂王。约押说：“我主我王啊，今日你的仆人知道我在你眼前蒙恩了，因为王成全了仆人的请求。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:3; 撒母耳记下 13:37–38"> 于是约押起身，往基述去，把押沙龙带到耶路撒冷。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 22:4; 创世记 43:3; 撒母耳记下 3:13"> 王说：“让他回自己的家，但不可见我的面。”于是押沙龙回了自己的家，没有见王的面。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 1:6; 申命记 28:35; 约伯记 2:7"> 在全以色列中，没有人像押沙龙那样因俊美大受称赞。从脚掌到头顶，他身上毫无瑕疵。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 44:20; 哥林多前书 11:14; 撒母耳记下 18:9"> 他剪头发的时候——他每年年底剪一次，因为头发重在他身上，所以他剪掉——按王家的秤，称他头上的头发，重二百舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克或0.35盎司，所以二百舍客勒约为2千克或4.4磅。">a</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 18:18; 撒母耳记下 13:1; 以赛亚书 14:22"> 押沙龙生了三个儿子和一个女儿，女儿名叫她玛。她是一个容貌美丽的女子。</span>
<span className="v" id="v28" data-v="28"> 押沙龙在耶路撒冷住了整整两年，却没有见王的面。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 14:30–31; 以斯帖记 1:12; 马太福音 22:3"> 押沙龙派人去召约押，要差他到王那里去，但约押不肯来见他。他又第二次派人去召，约押仍不肯来。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 15:4–5; 列王纪下 10:6–7; 列王纪下 9:33"> 因此他对仆人说：“看哪，约押的田靠近我的田，他在那里有大麦。你们去放火烧了。”押沙龙的仆人就放火烧了那田。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 于是约押起身，来到押沙龙家里见他，对他说：“你的仆人为什么放火烧了我的田？”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 20:8; 出埃及记 14:12; 箴言 28:13"> 押沙龙回答约押说：“看哪，我曾派人到你那里，说：‘你来这里，我好差你到王那里去，说：“我为什么从基述回来呢？我还在那里倒更好。现在，让我见王的面；如果我有罪孽，就让他杀我吧。”’”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 33:4; 路加福音 15:20; 创世记 27:26"> 于是约押去见王，把这话告诉他；王召了押沙龙来，他就来见王，在王面前伏脸于地叩拜；王就亲吻押沙龙。</span>
</div>
</div>

</div>

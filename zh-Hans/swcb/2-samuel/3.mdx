<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳记下" data-chapter="3" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:30; 箴言 4:18–19; 约伯记 8:7"> 扫罗家和大卫家之间争战了很久。大卫越来越强盛，扫罗家却越来越衰弱。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:1–4; 创世记 49:3–4; 撒母耳记下 13:1–29"> 大卫在希伯仑生了几个儿子。他的长子是暗嫩，是耶斯列女子亚希暖所生的；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 27:8; 历代志上 3:1; 申命记 3:14"> 次子是基利押，是迦密人拿八的妻亚比该所生的；三子是押沙龙，是基述王达买的女儿玛迦所生的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13–25; 列王纪上 1:5–18"> 四子是亚多尼雅，是哈及所生的；五子是示法提雅，是亚比她所生的；</span>
<span className="v" id="v5" data-v="5"> 六子是以特念，是大卫的妻以格拉所生的。这些都是大卫在希伯仑所生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 2:8–9; 历代志下 25:8; 以赛亚书 8:9–10"> 扫罗家和大卫家争战的时候，押尼珥在扫罗家中使自己势力强大。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:8–11; 列王纪上 2:21–22; 撒母耳记下 12:8"> 扫罗有一个妾，名叫利斯巴，是爱亚的女儿；伊施波设对押尼珥说：“你为什么与我父亲的妾同房？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 9:8; 撒母耳记下 16:9; 马可福音 6:18–19"> 押尼珥因伊施波设的话非常恼怒，说：“我岂是属犹大的狗头吗？今日我以慈爱待你父亲扫罗的家、他的弟兄和他的朋友，没有把你交在大卫手中；你今日竟因这女人的事指控我有罪！</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:28; 列王纪上 19:2; 路得记 1:17"> 愿上帝这样惩罚押尼珥，甚至更重；若我不照耶和华向大卫所起的誓为他成就，</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 20:1; 撒母耳记上 3:20; 列王纪上 4:25"> 把国位从扫罗家转移，立大卫的宝座治理以色列和犹大，从但直到别示巴。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 伊施波设因惧怕押尼珥，就一句话也不能回答他。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 12:38–40; 撒母耳记下 3:21; 路加福音 16:5–8"> 押尼珥替自己差派使者去见大卫，说：“这地是谁的？”又说：“你与我结盟吧；看哪，我的手必与你同在，使全以色列都归向你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 43:3; 撒母耳记上 19:11–17; 创世记 44:23"> 大卫说：“好，我要与你立约；但我向你要求一件事：你来见我面的时候，若不先带扫罗的女儿米甲来，就不得见我的面。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 18:27; 撒母耳记上 18:25; 撒母耳记下 2:10"> 大卫差派使者去见扫罗的儿子伊施波设，说：“把我的妻米甲交给我；她是我用一百非利士人的阳皮所聘娶的。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:44"> 伊施波设就派人去，把米甲从她丈夫拉亿的儿子帕铁那里带走。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:5; 撒母耳记下 19:16; 列王纪上 2:8"> 她丈夫跟着她，一路哭着跟到巴户琳。押尼珥对他说：“走吧！回去！”他就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 押尼珥与以色列的长老商议，说：“从前你们一直寻求大卫作王治理你们。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:28; 诗篇 89:19–23; 撒母耳记上 9:16"> 现在就去做吧！因为耶和华论到大卫说：‘我要借我仆人大卫的手，拯救我的民以色列脱离非利士人的手，和他们一切仇敌的手。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志上 12:29; 撒母耳记上 10:20–21; 诗篇 68:27"> 押尼珥也把这些话说给便雅悯人听；又往希伯仑去，把以色列和便雅悯全家看为好的事都说给大卫听。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 26:30; 以斯帖记 1:3"> 押尼珥带着二十个人来到希伯仑见大卫。大卫为押尼珥和同他来的人摆设筵席。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:12; 列王纪上 11:37; 撒母耳记下 3:10"> 押尼珥对大卫说：“我要起身去，把全以色列聚集到我主我王这里，使他们与你立约，好让你照着你心里所愿的一切治理他们。”于是大卫送押尼珥走，他就平平安安地去了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 看哪，大卫的臣仆和约押从袭击中回来，带着许多战利品；那时押尼珥没有与大卫同在希伯仑，因为大卫已经送他走，他也平平安安地去了。</span>
<span className="v" id="v23" data-v="23"> 约押和与他同在的全军来到，有人告诉约押说：“尼珥的儿子押尼珥来见王，王已经送他走，他也平平安安地去了。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 3:8; 撒母耳记下 19:5–7; 约翰福音 18:35"> 约押就来见王，说：“你做了什么？看哪，押尼珥来见你，你为什么送他走，让他已经离去了呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 28:6; 以赛亚书 37:28; 民数记 27:17"> 你知道尼珥的儿子押尼珥。他来是要欺骗你，要知道你的出入，并知道你所做的一切。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 约押从大卫那里出来，就差派使者追赶押尼珥，把他从西拉井带回来；但大卫并不知道。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:5; 撒母耳记下 20:9–10; 列王纪上 2:32"> 押尼珥回到希伯仑的时候，约押把他拉到城门中间，要私下与他说话，就在那里击中他的腹部，使他死了；这是为他兄弟亚撒黑的血。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 35:33; 出埃及记 21:12; 创世记 9:6"> 后来大卫听见了，就说：“我和我的国在耶和华面前，永远与尼珥的儿子押尼珥的血无罪。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 1:16; 诗篇 109:8–19; 利未记 13:44–46"> 愿这血归到约押头上和他父亲全家；愿约押家不断有患漏症的、长大麻风的、扶杖而行的、倒在刀下的、缺乏食物的。”</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行传 28:4; 撒母耳记下 2:19–23"> 约押和他兄弟亚比筛杀了押尼珥，因为押尼珥在基遍的战场上杀了他们的兄弟亚撒黑。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 37:34; 撒母耳记下 1:11; 撒母耳记下 1:2"> 大卫对约押和所有跟随他的百姓说：“你们要撕裂衣服，披上麻布，在押尼珥前面哀哭。”大卫王也跟在灵柩后面。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 约伯记 31:28; 撒母耳记上 30:4"> 他们把押尼珥安葬在希伯仑；王在押尼珥的坟墓旁放声大哭，众民也都哭了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 1:17; 历代志下 35:25; 路加福音 12:19–20"> 王为押尼珥作哀歌，说：“押尼珥岂该像愚昧人死去那样死去吗？</span>
<span className="v" id="v34" data-v="34" data-xref="士师记 16:21; 撒母耳记下 1:12; 约伯记 24:14"> 你的手没有被捆绑，你的脚没有被上脚镣；你倒下，像人在作恶之人面前倒下一样。”<br />众民又为他哀哭。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 12:17; 撒母耳记下 1:12; 路得记 1:17"> 天还未黑的时候，众民都来劝大卫吃饭；但大卫起誓说：“若在日落以前我尝饭或别的什么，愿上帝这样惩罚我，甚至更重。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 7:37; 诗篇 62:9; 马可福音 15:11–13"> 众民都注意到了这事，并且喜悦；正如王所做的一切都使众民喜悦。</span>
<span className="v" id="v37" data-v="37"> 那一天，众民和全以色列都明白，杀尼珥的儿子押尼珥并不是出于王。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:9; 撒母耳记下 2:8; 撒母耳记下 3:12"> 王对臣仆说：“你们岂不知道，今日在以色列有一位领袖、一位伟人倒下了吗？</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 2:33–34; 诗篇 101:8; 诗篇 28:4"> 我虽然受膏为王，今天仍然软弱；洗鲁雅的这些儿子对我来说太难制伏了。愿耶和华照作恶者的恶报应他。”</span>
</div>
</div>

</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 7:11–12; 创世记 26:1; 创世记 12:10"> 大卫在位的日子，连年有饥荒，一连三年；大卫就寻求耶和华的面。耶和华说：“这是因扫罗和他流人血的家，因为他杀死了基遍人。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 9:3–21; 列王纪下 10:31; 撒母耳记上 14:44"> 王召了基遍人来，对他们说（基遍人原不是以色列人，而是亚摩利人所剩下的；以色列人曾向他们起誓，扫罗却为以色列人和犹大人发热心，想要杀灭他们）；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 20:19; 希伯来书 9:22; 撒母耳记上 26:19"> 大卫对基遍人说：“我该为你们做什么？我该用什么来赎罪，使你们可以祝福耶和华的产业？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 49:6–8; 彼得前书 1:18–19"> 基遍人对他说：“我们和扫罗或他家之间，不是金银的问题；我们也无权在以色列中处死任何人。”<br />王说：“你们说什么，我就为你们做什么。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 21:1; 但以理 9:26; 马太福音 7:2"> 他们对王说：“那毁灭我们、谋害我们，要把我们灭尽，使我们不得存留在以色列任何境内的人，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:24; 民数记 25:4–5; 撒母耳记上 11:4"> 请把他子孙中的七个人交给我们，我们要在耶和华面前，把他们悬挂在耶和华所拣选的扫罗的基比亚。”<br />王说：“我必交给你们。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 20:15; 撒母耳记上 18:3; 撒母耳记上 23:18"> 但王因耶和华的誓约，就是大卫和扫罗的儿子约拿单之间的誓约，怜惜扫罗的孙子、约拿单的儿子米非波设。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:19; 撒母耳记下 3:7"> 王却带走亚雅的女儿利斯巴给扫罗所生的两个儿子，亚摩尼和米非波设；又带走扫罗的女儿米拉给米何拉人巴西莱的儿子亚得列所生的五个儿子。</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 1:22; 申命记 21:1–9; 撒母耳记下 6:17"> 他把他们交在基遍人手里；基遍人就在山上、耶和华面前悬挂他们，他们七个人一同倒下。他们被处死是在收割的日子，就是初收大麦的时候。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 21:23; 列王纪上 21:27; 约珥 2:23"> 亚雅的女儿利斯巴取了麻布，为自己铺在磐石上，从收割开始，直到天上下雨浇在他们身上。她白天不让空中的飞鸟停在他们身上，夜间也不让田野的走兽靠近。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 2:4; 路得记 2:11–12"> 有人告诉大卫扫罗的妃嫔、亚雅的女儿利斯巴所做的事。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 17:11; 撒母耳记上 31:10–13; 撒母耳记下 2:5–7"> 于是大卫去，从基列·雅比人那里取了扫罗的骸骨和他儿子约拿单的骸骨；这些骸骨是他们从伯珊的街市上偷来的，就是非利士人在基利波杀死扫罗那日，把他们悬挂的地方。</span>
<span className="v" id="v13" data-v="13"> 大卫从那里把扫罗的骸骨和他儿子约拿单的骸骨带上来；众人也收殓了那些被悬挂之人的骸骨。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 18:28; 撒母耳记下 24:25; 约书亚记 7:26"> 他们把扫罗和他儿子约拿单的骸骨，葬在便雅悯地的洗拉，在扫罗父亲基士的坟墓里；众人照王所吩咐的一切去行。此后，上帝垂听了为那地所献的祷告。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 14:10–11; 撒母耳记下 5:22; 传道书 12:3"> 非利士人又与以色列争战；大卫和他的臣仆一同下去，与非利士人作战。大卫疲乏了；</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 21:18; 撒母耳记下 21:20; 撒母耳记上 17:4–5"> 有巨人后裔以实比诺，他的矛重三百舍客勒铜；他佩着新刀，想要杀死大卫。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 11:36; 撒母耳记下 18:3; 诗篇 132:17"> 但洗鲁雅的儿子亚比筛帮助大卫，击打那非利士人，把他杀了。那时，大卫的人向他起誓说：“你不可再和我们一同出战，免得你熄灭以色列的灯。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志上 11:29; 撒母耳记下 21:20; 撒母耳记下 21:16"> 此后，在歌伯又与非利士人争战。那时，户沙人西比该杀了巨人后裔撒弗。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 20:5; 撒母耳记上 17:4–11; 历代志上 11:26"> 在歌伯又与非利士人争战，伯利恒人雅雷俄珥金的儿子伊勒哈难杀了迦特人歌利亚的兄弟；那人的矛杆粗如织布机的卷轴。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 21:18; 撒母耳记下 21:16; 历代志上 20:6"> 在迦特又有争战；那里有一个身材高大的人，每只手各有六个指头，每只脚各有六个脚趾，共二十四个；他也是巨人所生的。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 17:10; 撒母耳记上 17:36; 撒母耳记上 16:9"> 他向以色列骂阵，大卫的哥哥示每的儿子约拿单就杀了他。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 20:8; 罗马书 8:31; 耶利米书 9:23"> 这四个人都是迦特巨人所生的；他们都倒在大卫和他臣仆的手下。</span>
</div>

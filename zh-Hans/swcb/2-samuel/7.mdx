<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王纪上 5:4"> 王住在自己的宫中，耶和华又使他摆脱四围所有仇敌，得享安息的时候，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 16:1; 撒母耳记下 5:11; 哈该书 1:4"> 王对先知拿单说：“你看，我住在香柏木的宫殿里，上帝的约柜却住在幔子中。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:7; 列王纪上 8:17–18; 列王纪下 4:27"> 拿单对王说：“去吧，照你心里所有的去做，因为耶和华与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 17:3; 民数记 12:6; 阿摩司 3:7"> 当夜，耶和华的话临到拿单，说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:3–32; 列王纪上 5:3–4; 列王纪上 8:16–19"> “你去告诉我的仆人大卫：‘耶和华这样说：“你要为我建造殿宇，使我居住吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:16; 约书亚记 18:1; 出埃及记 40:18–19"> 自从我领以色列子民出埃及的日子，直到今日，我没有住过殿宇，却一直在帐篷和会幕中往来。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:6; 撒母耳记下 5:2; 利未记 26:11–12"> 我与所有以色列子民同行的各处，我何曾向以色列任何一个支派的人说过一句话——就是我吩咐牧养我子民以色列的人——说：‘你们为什么没有为我建造香柏木的殿宇呢？’”’</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 78:70–71; 撒母耳记下 6:21; 撒母耳记下 12:7"> 现在你要这样告诉我的仆人大卫：‘万军之耶和华这样说：“我从羊圈中，从跟随羊群的地方，取了你来作我子民以色列的君王。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 5:10; 历代志上 17:8; 撒母耳记上 18:14"> 你无论往哪里去，我都与你同在，并且从你面前剪除你所有的仇敌。我要使你得大名，像地上伟人的名一样。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司 9:15; 历代志上 17:9; 耶利米书 24:6"> 我要为我的子民以色列指定一个地方，栽培他们，使他们住在自己的地方，不再被迁动。邪恶之子必不再苦害他们，像起初一样，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:27; 撒母耳记下 7:1; 历代志上 17:10"> 也不像自从我命令士师治理我子民以色列的日子以来那样。我要使你摆脱所有仇敌，得享安息。不仅如此，耶和华还告诉你，耶和华必为你建立家室。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 8:20; 使徒行传 2:30; 使徒行传 13:36"> 你的日子满足、你与你列祖同睡的时候，我必在你以后兴起你的后裔，就是从你身体而出的；我必坚立他的国。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王纪上 8:19; 撒母耳记下 7:16"> 他要为我的名建造殿宇，我必坚立他国度的宝座，直到永远。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 1:5; 启示录 3:19; 历代志上 17:13"> 我要作他的父，他要作我的子。他若行不义，我必用人的杖、用世人的鞭责罚他；</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:23; 撒母耳记上 15:28; 诗篇 89:28"> 但我的慈爱必不离开他，像我使慈爱离开扫罗一样；我曾把扫罗从你面前除去。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 诗篇 89:36–37; 撒母耳记下 7:13"> 你的家和你的国必在你面前永远坚立。你的宝座必坚立到永远。”’”</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:15; 使徒行传 20:27; 哥林多前书 15:3"> 拿单就照这一切话，照这整个异象，告诉了大卫。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 8:4; 历代志上 17:16; 撒母耳记上 18:18"> 于是大卫王进去，坐在耶和华面前，说：“主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“主”的词是“Adonai”（阿多奈）。">a</a></sup>耶和华啊，我是谁？我的家又算什么，你竟带领我到这地步？</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 55:8–9; 历代志上 17:17; 诗篇 36:7"> 主耶和华啊，这在你眼中还算为小事；你又论到你仆人的家，说到久远的将来。主耶和华啊，这竟是关乎世人的事！</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 21:17; 撒母耳记上 16:7; 诗篇 139:1"> 大卫还能对你多说什么呢？主耶和华啊，因为你知道你的仆人。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 115:1; 诗篇 138:2; 以弗所书 1:9"> 你为了你的话，并照你自己的心意，行了这一切大事，使你的仆人知道。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 86:10; 出埃及记 15:11; 诗篇 86:8"> 所以，耶和华上帝啊，你本为大；因为照我们亲耳所听见的一切，没有谁像你；除你以外，也没有上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:26; 申命记 10:21; 申命记 15:15"> 地上哪一个国能像你的子民，像以色列呢？上帝曾去救赎他们归自己作子民，为自己成就名声，又为你们行大事，为你的地行可畏的事，在你从埃及、从列国和他们的神明那里救赎归自己的子民面前行这些事。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 26:18; 彼得前书 2:10; 创世记 17:7"> 你为自己坚立你的子民以色列，作你的子民直到永远；耶和华啊，你也作了他们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 119:49; 以西结 36:37; 创世记 32:12"> “现在，耶和华上帝啊，你论到你仆人和他家所说的话，求你永远坚立，并照你所说的去行。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 17:23–24; 诗篇 72:18–19; 马太福音 6:9"> 愿你的名永远被尊为大，说：‘万军之耶和华是治理以色列的上帝；你仆人大卫的家必在你面前坚立。’</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 17:25–26; 诗篇 10:17; 路得记 4:4"> 万军之耶和华、以色列的上帝啊，因为你已经向你的仆人启示说：‘我必为你建立家室。’所以你的仆人才心里找着勇气，向你作这样的祷告。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17; 出埃及记 34:6; 民数记 23:19"> “现在，主耶和华啊，你是上帝，你的话是真实的；你也向你的仆人应许了这美好的事。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 6:24–26; 历代志上 17:27; 诗篇 115:12–15"> 现在，求你乐意赐福给你仆人的家，使它可以在你面前永远存续；因为主耶和华啊，这是你所说的。愿你仆人的家因你的赐福永远蒙福。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:9; 撒母耳记下 3:2–3; 撒母耳记下 13:15"> 此后，大卫的儿子押沙龙有一个美丽的妹妹，名叫她玛；大卫的儿子暗嫩爱上了她。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:10; 列王纪上 21:4; 雅歌 5:8"> 暗嫩因他的妹妹她玛愁烦，甚至病了；因为她还是童女，暗嫩觉得难以对她做什么。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:9; 哥林多前书 3:19; 雅各书 3:15"> 暗嫩有一个朋友，名叫约拿达，是大卫的哥哥示米亚的儿子；约拿达是一个非常狡猾的人。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:17; 利未记 18:9; 以斯帖记 5:13–14"> 他对暗嫩说：“王子啊，你为什么一天比一天消瘦呢？不告诉我吗？”<br />暗嫩对他说：“我爱我兄弟押沙龙的妹妹她玛。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 6:24–25; 箴言 19:27; 使徒行传 23:15"> 约拿达对他说：“你躺在床上装病。你父亲来看你的时候，你就对他说：‘请让我的妹妹她玛来，给我饼吃，在我眼前预备食物，好让我看见，并从她手里接过来吃。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 18:6; 马太福音 13:33"> 于是暗嫩躺下装病。王来看他的时候，暗嫩对王说：“请让我妹妹她玛来，在我眼前给我做两个饼，好让我从她手里接过来吃。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大卫就派人到家里去见她玛，说：“现在到你哥哥暗嫩的屋里去，为他预备食物。”</span>
<span className="v" id="v8" data-v="8"> 她玛就到她哥哥暗嫩的屋里去；暗嫩正躺着。她拿了面，揉好，在他眼前做成饼，又把饼烤熟。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:1; 约翰福音 3:20; 士师记 3:19"> 她拿起锅，把饼倒在他面前，他却不肯吃。暗嫩说：“叫所有人都离开我。”于是所有人都从他那里出去了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩对她玛说：“把食物拿进内室来，好让我从你手里接过来吃。”她玛就把自己做好的饼拿进内室，给她哥哥暗嫩。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:11–12"> 她把饼拿近给他吃的时候，他抓住她，对她说：“我的妹妹，来，与我同寝吧！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 19:23; 利未记 20:17; 士师记 20:6"> 她回答他说：“不要，我哥哥，不要强迫我！因为在以色列不该做这样的事。你不要做这愚妄的事！</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 19:24; 创世记 20:12; 创世记 19:8"> 至于我，我要把我的羞耻带到哪里去呢？至于你，你在以色列中就会像一个愚妄人。现在，请你向王说，他不会不把我给你。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 12:11; 以斯帖记 7:8; 士师记 20:5"> 然而，他不肯听她的话；他比她强，就强迫她，与她同寝。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 23:17"> 随后，暗嫩极其恨她；他恨她的恨，比先前爱她的爱更大。暗嫩对她说：“起来，走吧！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 她对他说：“不可这样，因为你打发我走的这大恶，比你先前对我所做的还要严重！”<br />但他不肯听她。</span>
<span className="v" id="v17" data-v="17"> 他就叫伺候自己的仆人来，说：“现在，把这个女人从我这里赶出去，她出去以后就把门闩上。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 5:30; 创世记 37:3; 诗篇 45:13–14"> 她身上穿着彩衣，因为王的女儿中仍为童女的，都是穿这样的袍子。他的仆人就把她带出去，随后把门闩上。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 耶利米书 2:37; 撒母耳记下 1:11"> 她玛把灰撒在自己头上，撕裂身上所穿的彩衣；她把手放在头上，一边走一边大声哭喊。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:19; 创世记 46:15; 创世记 34:2"> 她哥哥押沙龙对她说：“你哥哥暗嫩与你在一起了吗？但现在，我妹妹，不要作声。他是你的哥哥，不要把这事放在心上。”<br />于是她玛凄凉地住在她哥哥押沙龙的家里。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:7; 撒母耳记下 3:28–29; 撒母耳记上 2:29"> 大卫王听见这一切事，就非常愤怒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 19:17–18; 创世记 31:24; 创世记 24:50"> 押沙龙不对暗嫩说好说歹；因为暗嫩强迫了他的妹妹她玛，所以押沙龙恨暗嫩。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 38:12–13; 撒母耳记上 25:4; 历代志下 26:10"> 过了整整两年，押沙龙在靠近以法莲的巴力·夏琐有剪羊毛的人；押沙龙邀请了王所有的儿子。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 11:8–15; 耶利米书 41:6–7; 诗篇 55:21"> 押沙龙来到王那里，说：“看哪，你仆人有剪羊毛的人。请王和王的臣仆与仆人一同去。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士师记 19:7–10; 撒母耳记下 14:22"> 王对押沙龙说：“不，我儿，我们不要都去，免得成为你的负担。”押沙龙恳切请他，他仍不肯去，只为他祝福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 20:9; 撒母耳记下 3:27; 撒母耳记下 11:13–15"> 押沙龙说：“若不然，请让我哥哥暗嫩和我们一同去。”<br />王对他说：“他为什么要和你去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 但押沙龙恳切请王，王就让暗嫩和王所有的儿子与他一同去了。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 19:6; 士师记 19:22; 士师记 19:9"> 押沙龙吩咐他的仆人说：“你们要留意，等暗嫩因酒心里畅快的时候，我对你们说：‘击杀暗嫩’，你们就杀他。不要惧怕。这不是我吩咐你们的吗？要刚强，要勇敢！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 18:9; 列王纪上 1:33; 列王纪下 1:9–12"> 押沙龙的仆人照押沙龙所吩咐的，对暗嫩行了。于是王所有的儿子都起来，各人骑上自己的骡子逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 他们还在路上的时候，有消息传到大卫那里，说：“押沙龙杀了王所有的儿子，一个也没有剩下！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 1:11; 撒母耳记下 12:16; 约伯记 1:20"> 王就起来，撕裂衣服，躺在地上；他的所有臣仆也都撕裂衣服，站在旁边。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:9; 撒母耳记下 13:3; 创世记 27:41"> 大卫的哥哥示米亚的儿子约拿达回答说：“不要让我的主以为他们杀了所有少年人，就是王的儿子们；死的只有暗嫩。因为自从暗嫩强迫他妹妹她玛那天起，这事就已按押沙龙的命令定下了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:19"> 现在，请不要让我主我王把这事放在心上，以为王所有的儿子都死了；因为死的只有暗嫩。”</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 4:8–14; 箴言 28:17; 阿摩司 5:19"> 押沙龙却逃跑了。守望的少年人举目观看，看哪，有许多人从他后面山坡的路上来。</span>
<span className="v" id="v35" data-v="35"> 约拿达对王说：“看哪，王的儿子们来了！正如你仆人所说的。”</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:33; 撒母耳记下 12:21; 撒母耳记下 13:15"> 他刚说完，看哪，王的儿子们就到了，放声大哭。王和他的所有臣仆也都痛哭。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 3:3; 撒母耳记下 14:32; 撒母耳记下 13:34"> 押沙龙逃跑，去投奔基述王亚米忽的儿子达买。大卫天天为他的儿子悲哀。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 15:8; 撒母耳记下 14:23; 撒母耳记下 14:32"> 押沙龙逃跑，去了基述，在那里住了三年。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:67; 创世记 38:12; 创世记 37:35"> 大卫王渴望出去见押沙龙，因为暗嫩既然死了，他也为暗嫩的事得了安慰。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 11:1–3; 士师记 11:12–28; 士师记 10:7–9"> 这事以后，亚扪人的王死了，他儿子哈嫩接续他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 11:1; 申命记 23:3–6; 尼希米记 13:1–3"> 大卫说：“我要以慈爱待拿辖的儿子哈嫩，正如他父亲以慈爱待我一样。”于是大卫差遣臣仆，为他父亲的事去安慰他。大卫的臣仆到了亚扪人的地。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 42:16; 创世记 42:9; 哥林多前书 13:5"> 但亚扪人的首领对他们的主哈嫩说：“大卫差人来安慰你，你以为他是在尊敬你的父亲吗？大卫差他的臣仆到你这里来，岂不是为了窥探这城、侦察它，好将它倾覆吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 20:4; 耶利米书 41:5; 历代志上 19:3–4"> 于是哈嫩拿住大卫的臣仆，剃去他们一半的胡须，又从中间割断他们的衣服，直到露出臀部，然后把他们放走。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 19:5; 列王纪上 16:34; 约书亚记 6:24–26"> 有人把这事告诉大卫，他就派人去迎接他们，因为这些人非常羞愧。王说：“你们住在耶利哥，等到胡须长起来，然后再回来。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 8:3; 撒母耳记下 8:5; 创世记 34:30"> 亚扪人见自己在大卫面前成了可憎的，亚扪人就派人去雇用伯·利合的亚兰人和琐巴的亚兰人，步兵二万人，又雇用玛迦王带一千人，以及陀伯人一万二千人。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 23:8–39; 历代志上 19:8–19"> 大卫听见了，就派约押和勇士的全军出征。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 10:6; 约书亚记 19:28; 民数记 13:21"> 亚扪人出来，在城门口摆阵；琐巴和利合的亚兰人、陀伯人和玛迦人，则另在田野里。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 20:42–43; 约书亚记 8:21–22"> 约押看见前后都有战阵对着他，就从以色列所有精兵中挑选人，摆阵迎战亚兰人。</span>
<span className="v" id="v10" data-v="10"> 其余的兵交在他兄弟亚比筛手中；亚比筛就摆阵迎战亚扪人。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 6:2; 尼希米记 4:20; 腓立比书 1:27–28"> 约押说：“如果亚兰人强过我，你就来帮助我；如果亚扪人强过你，我就来帮助你。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 16:13; 申命记 31:6; 撒母耳记上 3:18"> 你要刚强！让我们为我们的百姓和我们上帝的城邑刚强；愿耶和华照祂看为好的去行。”</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 20:13–21; 列王纪上 20:28–30; 历代志上 19:14–15"> 于是约押和跟随他的兵向前进攻亚兰人；亚兰人在他面前逃跑。</span>
<span className="v" id="v14" data-v="14"> 亚扪人看见亚兰人逃跑，他们也在亚比筛面前逃跑，进了城。于是约押离开亚扪人，回到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 14:2–3; 弥迦书 4:11–12; 以赛亚书 8:9–10"> 亚兰人见自己被以色列击败，就聚集起来。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 19:16; 撒母耳记下 8:3–8; 历代志上 18:3"> 哈大底谢差人把大河那边的亚兰人调出来；他们来到希兰，有哈大底谢的军长朔巴率领他们。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 19:17"> 有人把这事告诉大卫；他就聚集全以色列，过了约旦河，来到希兰。亚兰人摆阵迎战大卫，与他交战。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 19:18; 撒母耳记下 8:4; 诗篇 46:11"> 亚兰人在以色列面前逃跑；大卫杀了亚兰人七百名战车兵和四万名骑兵，又击杀他们的军长朔巴，他就死在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 8:6; 启示录 18:10; 诗篇 48:4–5"> 所有臣服于哈大底谢的王看见自己在以色列面前被击败，就与以色列讲和，服侍他们。从此亚兰人不敢再帮助亚扪人了。</span>
</div>

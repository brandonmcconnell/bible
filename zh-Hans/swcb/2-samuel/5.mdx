<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 11:1–3; 撒母耳记下 19:13; 创世记 29:14"> 于是，以色列众支派都来到希伯仑见大卫，说：“看哪，我们是你的骨肉。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:4; 以西结 34:23"> 从前扫罗作我们王的时候，率领以色列出入的是你。耶和华也曾对你说：‘你要牧养我的子民以色列，作以色列的君王。’”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:4; 撒母耳记上 16:13; 撒母耳记上 23:18"> 以色列的众长老都来到希伯仑见王，大卫王就在希伯仑，在耶和华面前与他们立约；他们就膏大卫作以色列的王。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:27; 路加福音 3:23; 列王纪上 2:11"> 大卫登基的时候三十岁，作王四十年。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 2:11; 历代志上 3:4; 列王纪上 2:11"> 他在希伯仑作犹大的王七年零六个月，在耶路撒冷作全以色列和犹大的王三十三年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 1:8; 耶利米书 37:10; 历代志上 11:4–9"> 王和他的人往耶路撒冷去攻打住在那地的耶布斯人；他们对大卫说：“瞎眼的和瘸腿的也会把你挡在外面。”他们心想：“大卫进不了这里。”</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 2:10; 撒母耳记下 6:16; 撒母耳记下 6:12"> 然而大卫攻取了锡安的堡垒；这就是大卫城。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:16–17; 历代志上 11:6–9; 撒母耳记上 17:25"> 那一天，大卫说：“谁攻打耶布斯人，就让他从水道上去，击杀那些大卫心里所恨恶的瘸腿和瞎眼的人。”因此人们说：“瞎眼的和瘸腿的不能进这屋子。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:15; 列王纪上 9:24; 历代志下 32:5"> 大卫住在堡垒里，称它为大卫城。大卫又从米罗起，向内四围建造。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 3:1; 罗马书 8:31; 诗篇 46:11"> 大卫日渐强盛，因为耶和华——万军之上帝与他同在。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 14:1; 列王纪上 5:1–2; 列王纪上 5:18"> 推罗王希兰差遣使者到大卫那里，又送来香柏木、木匠和石匠；他们为大卫建造宫殿。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 7:16; 列王纪上 10:9; 历代志上 14:2"> 大卫知道耶和华已经坚立他作以色列的王，又为祂子民以色列的缘故高举他的国。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志上 3:9; 申命记 17:17; 历代志下 13:21"> 大卫离开希伯仑以后，在耶路撒冷又为自己娶了更多的妃嫔和妻子；大卫又生了儿女。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 3:5–9; 路加福音 2:31; 历代志上 14:4"> 以下是在耶路撒冷为他所生之人的名字：沙母亚、朔罢、拿单、所罗门、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 3:6; 历代志上 14:5"> 益辖、以利书亚、尼斐、雅非亚、</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 3:8; 历代志上 14:7"> 以利沙玛、以利雅大、以利法列。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 23:14; 历代志上 14:8–9; 历代志上 11:16"> 非利士人听见有人膏大卫作以色列的王，所有非利士人就上来寻找大卫；大卫听见了，就下到堡垒去。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:8; 撒母耳记下 23:13; 创世记 14:5"> 非利士人已经来到利乏音谷，四散驻扎。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:1; 撒母耳记上 23:2; 撒母耳记下 5:23"> 大卫求问耶和华说：“我可以上去攻打非利士人吗？你会把他们交在我手里吗？”<br />耶和华对大卫说：“你上去吧；因为我必定把非利士人交在你手里。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 28:21"> 大卫来到巴力·毗拉心，在那里击败他们。于是他说：“耶和华在我面前冲破我的仇敌，像水冲破一样。”因此他给那地方起名叫巴力·毗拉心。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“巴力·毗拉心”的意思是“冲破的主”。">a</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 14:11–12; 申命记 7:5; 撒母耳记上 5:2–6"> 非利士人把他们的神像留在那里，大卫和他的人就把它们拿走了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 14:13; 撒母耳记下 5:18; 列王纪上 20:22"> 非利士人又上来，四散驻扎在利乏音谷。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 14:14; 马太福音 9:29–30; 马太福音 8:23–25"> 大卫求问耶和华，祂说：“你不可上去；要绕到他们后面，从桑树前面攻打他们。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 7:6; 士师记 4:14; 士师记 7:15"> 你听见桑树梢上有行军的声音，就要奋起行动；因为那时耶和华已经在你前面出去，要击打非利士人的军队。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志上 14:16; 约书亚记 16:10; 以赛亚书 28:21"> 大卫就照耶和华所吩咐他的去做，击败非利士人，从迦巴直到基色。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 30:31; 撒母耳记上 23:4; 创世记 32:2"> 此后，大卫求问耶和华说：“我可以上犹大的某一座城去吗？”<br />耶和华对他说：“可以上去。”<br />大卫说：“我该上哪里去？”<br />祂说：“到希伯仑去。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 25:42–43; 撒母耳记上 30:5; 路加福音 22:28–29"> 于是大卫带着他的两个妻子，就是耶斯列人亚希暖和迦密人拿八的妻子亚比该，上到那里去。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 30:1; 历代志上 12:1–7; 撒母耳记上 27:2–3"> 大卫也带着跟随他的人上去，各人带着自己的家眷；他们住在希伯仑的各城里。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 5:5; 撒母耳记上 31:11–13; 撒母耳记下 5:3"> 犹大人来了，在那里膏大卫作犹大家的王。有人告诉大卫说：“埋葬扫罗的是基列·雅比人。”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 23:21; 诗篇 115:15; 路得记 2:20"> 大卫派使者到基列·雅比人那里，对他们说：“你们向你们的主扫罗显出这份恩情，埋葬了他，愿你们蒙耶和华赐福。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及记 34:6; 马太福音 5:44"> 现在愿耶和华以慈爱和信实待你们。我也要因你们做了这事，报答你们这份恩情。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:10; 撒母耳记下 10:12; 创世记 15:1"> 现在，你们的手要刚强，你们也要勇敢；因为你们的主扫罗已经死了，犹大家也已经膏我作他们的王。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 14:50; 创世记 32:2; 撒母耳记下 3:7–8"> 扫罗军队的元帅、尼珥的儿子押尼珥，已经带着扫罗的儿子伊施波设渡过去，到玛哈念。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 19:18; 约书亚记 13:8–11; 民数记 1:40"> 他立伊施波设作王，统治基列、亚书利人、耶斯列、以法莲、便雅悯和全以色列。</span>
<span className="v" id="v10" data-v="10"> 扫罗的儿子伊施波设登基作以色列王的时候四十岁，作王两年。但犹大家跟随大卫。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 大卫在希伯仑作犹大家的王，共七年六个月。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:25; 约书亚记 10:2; 约书亚记 9:3"> 尼珥的儿子押尼珥和扫罗儿子伊施波设的臣仆，从玛哈念出来，往基遍去。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 8:16; 历代志上 2:16; 撒母耳记下 20:23"> 洗鲁雅的儿子约押和大卫的臣仆也出来，在基遍池旁遇见他们；双方就坐下，一边在池这边，一边在池那边。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥对约押说：“请让年轻人起来，在我们面前较量吧！”<br />约押说：“让他们起来吧！”</span>
<span className="v" id="v15" data-v="15"> 于是他们起来，按数目过去：便雅悯和扫罗儿子伊施波设那边十二人，大卫的臣仆那边十二人。</span>
<span className="v" id="v16" data-v="16"> 他们各自揪住对手的头，把刀刺入对方的肋旁；于是他们一同倒下。因此，基遍的那地方被称为希勒甲·哈素林。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“希勒甲·哈素林”的意思是“短剑之田”。">a</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:1"> 那一天战斗非常激烈；押尼珥和以色列人在大卫的臣仆面前败了。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 12:8; 哈巴谷 3:19; 雅歌 8:14"> 洗鲁雅的三个儿子都在那里：约押、亚比筛和亚撒黑。亚撒黑脚步轻快，如同野羚羊。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:21; 约书亚记 1:7; 箴言 4:27"> 亚撒黑追赶押尼珥。他追赶押尼珥时，不偏右也不偏左。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 押尼珥回头看，说：“你是亚撒黑吗？”<br />他回答说：“是。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 14:19"> 押尼珥对他说：“你转向右边或左边，抓住一个年轻人，夺取他的装备吧。”可是亚撒黑不肯转身离开，不再追赶他。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:27; 箴言 29:1; 列王纪下 14:10–12"> 押尼珥又对亚撒黑说：“你转身离开吧，不要再追赶我。我何必击倒你在地呢？那样我怎么能面对你哥哥约押呢？”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:27; 撒母耳记下 4:6; 撒母耳记下 5:6"> 然而亚撒黑拒绝转身离开。因此押尼珥用枪的尾端刺入他的腹部，枪从他背后穿出；他就倒在那里，死在原地。凡来到亚撒黑倒下而死的地方的人，都站住了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 但约押和亚比筛继续追赶押尼珥。他们来到亚玛山，就是在基亚前面、通往基遍旷野路旁的那山时，太阳已经落了。</span>
<span className="v" id="v25" data-v="25"> 便雅悯人聚集在押尼珥后面，成为一队，站在一座山顶上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 46:14; 耶利米书 46:10; 使徒行传 7:26"> 押尼珥呼叫约押说：“刀剑岂可永远吞噬吗？你不知道结局必是苦涩吗？你到什么时候才吩咐百姓转回，不再追赶自己的弟兄呢？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳记下 2:14; 箴言 15:1"> 约押说：“我指着永活的上帝<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>起誓，如果你没有说话，百姓必定到早晨才会离去，不再各自追赶自己的弟兄。”</span>
<span className="v" id="v28" data-v="28"> 于是约押吹角；全体百姓都站住，不再追赶以色列人，也不再争战。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8; 雅歌 2:17"> 押尼珥和他的人整夜经过亚拉巴，渡过约旦河，走过整个毕伦，来到玛哈念。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 约押停止追赶押尼珥而回来；他聚集全体百姓时，发现大卫的人少了十九人，另外还有亚撒黑。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:1; 列王纪上 20:11"> 但大卫的臣仆击杀了便雅悯人和押尼珥的人，共有三百六十人死了。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 2:13–16; 撒母耳记上 17:58; 历代志下 21:1"> 他们抬起亚撒黑，把他埋葬在伯利恒他父亲的坟墓里。约押和他的人走了一整夜，天亮的时候到了希伯仑。</span>
</div>
</div>

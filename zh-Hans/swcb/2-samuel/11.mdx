<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 20:1; 列王纪上 20:26; 列王纪上 20:22"> 到了年初，列王出征的时候，大卫派约押和跟随他的臣仆，以及以色列全军出去；他们毁灭亚扪人，围攻拉巴。但大卫仍住在耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 诗篇 119:37; 约伯记 31:1"> 到了傍晚，大卫从床上起来，在王宫的屋顶上散步。他从屋顶上看见一个妇人正在沐浴；那妇人容貌非常美丽。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 23:39; 历代志上 3:5; 雅各书 1:14–15"> 大卫派人去打听那妇人。有人说：“这不是以连的女儿、赫人乌利亚的妻子拔示巴吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未记 18:19; 雅各书 1:14–15; 诗篇 51:1–19"> 大卫派使者去，把她接来；她来到他那里，他就与她同寝（那时她已经从她的不洁中得了洁净）；随后她回到自己的家。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22; 箴言 6:34"> 那妇人怀了孕；她派人告诉大卫，说：“我怀孕了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 创世记 4:7; 撒母耳记上 15:30"> 大卫派人去见约押，说：“请把赫人乌利亚派到我这里来。”约押就把乌利亚派到大卫那里。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:14; 撒母耳记上 17:22; 创世记 29:6"> 乌利亚来到他那里，大卫问候约押是否平安，百姓是否平安，战事进展如何。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 18:4; 创世记 43:34; 以赛亚书 29:15"> 大卫对乌利亚说：“下到你家去，洗洗脚吧。”乌利亚就离开王宫，王的礼物也随后送给他。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; 约伯记 5:12–14"> 但乌利亚和他主人的众臣仆一起睡在王宫门口，没有下到自己家去。</span>
<span className="v" id="v10" data-v="10"> 有人告诉大卫说：“乌利亚没有下到自己家去。”大卫就对乌利亚说：“你不是从旅途回来吗？为什么没有下到你家去？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:2; 撒母耳记下 20:6; 撒母耳记下 7:6"> 乌利亚对大卫说：“约柜、以色列和犹大都住在棚里；我主约押和我主的臣仆都在旷野扎营。我怎能进我家吃喝，并与妻子同寝呢？我指着你的性命和你的灵魂起誓，我绝不做这事！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:37; 耶利米书 2:22–23"> 大卫对乌利亚说：“今天也留在这里，明天我让你回去。”于是乌利亚那一天和第二天都留在耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷 2:15; 创世记 19:32–35; 箴言 20:1"> 大卫召他来，他就在大卫面前吃喝；大卫使他喝醉。到了傍晚，他出去，与他主人的臣仆一起睡在自己的床上，却没有下到自己家去。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 17:9; 列王纪上 21:8–10; 诗篇 19:13"> 到了早晨，大卫写了一封信给约押，交在乌利亚手中送去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:9; 诗篇 51:4; 耶利米书 20:13"> 他在信中写道：“把乌利亚派到战斗最激烈的前线，然后从他身边撤退，使他被击中而死。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; 撒母耳记上 22:17–19; 使徒行传 5:29"> 约押围城侦察的时候，就把乌利亚派在他知道有勇士的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:9; 诗篇 51:14"> 城里的人出来与约押交战。大卫的臣仆中有一些人阵亡；赫人乌利亚也死了。</span>
<span className="v" id="v18" data-v="18"> 于是约押派人去，把有关战事的一切都告诉大卫；</span>
<span className="v" id="v19" data-v="19"> 他吩咐使者说：“你把有关战事的一切都向王说完以后，</span>
<span className="v" id="v20" data-v="20"> 如果王发怒，问你说：‘你们为什么离城那么近去交战？难道你们不知道他们会从城墙上射箭吗？</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 7:1; 士师记 9:50–54; 撒母耳记下 3:27"> 谁击杀了耶路比设的儿子亚比米勒？不是有一个妇人从城墙上把上磨石扔在他身上，使他死在提备斯吗？你们为什么离城墙那么近呢？’那时你就说：‘你的仆人赫人乌利亚也死了。’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 于是使者去了，来到大卫那里，把约押派他来说的一切都告诉大卫。</span>
<span className="v" id="v23" data-v="23"> 使者对大卫说：“那些人胜过我们，出到田野迎战我们；我们追击他们，直到城门口。</span>
<span className="v" id="v24" data-v="24"> 射手从城墙上射你的仆人；王的臣仆中有一些人死了，你的仆人赫人乌利亚也死了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 约书亚记 7:8–9; 传道书 9:1–3"> 大卫对使者说：“你要对约押这样说：‘不要因这事忧愁，因为刀剑吞灭这个，也吞灭那个。你要加强攻城的战斗，把城推翻。’你要鼓励他。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 创世记 27:41; 撒母耳记下 3:31"> 乌利亚的妻子听见她丈夫乌利亚死了，就为丈夫哀哭。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 51:4–5; 撒母耳记下 12:9; 申命记 22:29"> 哀哭的日子过了，大卫派人把她接到自己宫里，她就成了他的妻子，并给他生了一个儿子。但大卫所做的这事使耶和华不喜悦。</span>
</div>
</div>

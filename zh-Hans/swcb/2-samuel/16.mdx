<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 17:29; 士师记 10:4; 士师记 5:10"> 王对洗巴说：“你带这些来是什么意思？”<br />洗巴说：“驴是给王的家眷骑的；饼和夏果是给年轻人吃的；酒是给在旷野疲乏的人喝的。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 9:9–10; 诗篇 15:3; 撒母耳记下 19:24–30"> 王说：“你主人的儿子在哪里？”<br />洗巴对王说：“看哪，他留在耶路撒冷；因为他说：‘今天以色列家要把我父亲的国归还给我。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="箴言 18:13; 箴言 18:17; 箴言 19:2"> 于是王对洗巴说：“看哪，凡属米非波设的都归你了。”<br />洗巴说：“我俯伏下拜。愿我在你眼前蒙恩，我主我王啊。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:16; 撒母耳记上 17:43; 出埃及记 22:28"> 大卫王到了巴户琳，看哪，有一个属扫罗家族的人出来，名叫示每，是基拉的儿子；他一边走出来，一边咒骂。</span>
<span className="v" id="v6" data-v="6"> 他向大卫和大卫王的所有臣仆扔石头；众百姓和所有勇士都在王的左右。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 13:13; 撒母耳记上 25:17; 列王纪上 21:10"> 示每咒骂时说：“滚吧，滚吧！你这流人血的人，恶人哪！</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 1:16; 撒母耳记下 3:28–29; 列王纪上 2:32–33"> 你取代扫罗作王，耶和华把扫罗家的血债都归到你身上了！耶和华已经把国交在你儿子押沙龙手里！看哪，你自作自受，因为你是流人血的人！”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 22:28; 撒母耳记下 9:8; 撒母耳记上 24:14"> 洗鲁雅的儿子亚比筛对王说：“这条死狗为什么咒骂我主我王呢？请让我过去砍下他的头。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 19:22; 罗马书 9:20; 约翰福音 18:11"> 王说：“洗鲁雅的儿子们，我与你们有什么相干呢？既然他咒骂，而且耶和华对他说：‘咒骂大卫’，谁还能说：‘你为什么这样做呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 17:1–4; 创世记 45:5; 撒母耳记下 12:11–12"> 大卫对亚比筛和他所有臣仆说：“看哪，我亲生的儿子尚且寻索我的性命，何况这个便雅悯人呢？由他吧，让他咒骂，因为耶和华吩咐了他。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 希伯来书 12:10; 诗篇 25:18"> 或许耶和华会察看我所受的冤屈，因今日所受的咒骂，耶和华反而以善报我。”</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 23:23; 撒母耳记下 16:5–6"> 于是大卫和跟随他的人继续沿路前行；示每在对面的山坡上一路跟着走，一边走一边咒骂，又向他扔石头、扬尘土。</span>
<span className="v" id="v14" data-v="14"> 王和跟随他的众百姓都疲乏地到了那里；他就在那里恢复了精神。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:37; 撒母耳记下 15:12"> 押沙龙和所有百姓，就是以色列人，来到耶路撒冷，亚希多弗也与他同来。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 11:12; 撒母耳记上 10:24; 列王纪上 1:25"> 大卫的朋友亚基人户筛来见押沙龙时，户筛对押沙龙说：“愿王万岁！愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 19:25; 撒母耳记下 15:32–37; 申命记 32:6"> 押沙龙对户筛说：“这是你对朋友的恩情吗？你为什么没有跟你的朋友同去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:13; 撒母耳记下 5:1–3"> 户筛对押沙龙说：“不；耶和华、这百姓和所有以色列人所拣选的是谁，我就归属谁，并且与他同住。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 15:34; 诗篇 55:21; 撒母耳记上 28:2"> 再者，我该服侍谁呢？我岂不该在他儿子面前服侍吗？我怎样在你父亲面前服侍，也必照样在你面前服侍。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:10; 诗篇 37:12–13; 以赛亚书 29:15"> 于是押沙龙对亚希多弗说：“你们出个主意，我们该怎样行。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 20:3; 撒母耳记下 15:16; 撒迦利亚书 8:13"> 亚希多弗对押沙龙说：“你父亲留下来看守宫殿的妃嫔，你进去与她们同寝。这样，全以色列都会听见你使你父亲憎恶；所有跟随你的人手就会刚强。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 12:11–12; 撒母耳记下 15:16; 撒母耳记下 20:3"> 于是他们在屋顶上为押沙龙支搭帐棚；押沙龙就在全以色列眼前进去与他父亲的妃嫔同寝。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 15:12; 撒母耳记下 17:14; 撒母耳记下 17:23"> 那些日子，亚希多弗所出的计谋，好像人求问上帝内殿所得的话一样；亚希多弗的一切计谋，无论对大卫还是对押沙龙，都是这样。</span>
</div>

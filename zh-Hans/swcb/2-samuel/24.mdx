<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 21:1; 历代志上 27:23–24; 雅各书 1:13–14"> 耶和华的怒气又向以色列发作，祂激动大卫起来对付他们，说：“去，数点以色列和犹大。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 3:10; 士师记 20:1; 撒母耳记下 20:23"> 王对在他身边的元帅约押说：“现在你要走遍以色列各支派，从但直到别是巴，数点百姓，好让我知道百姓的总数。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 1:11; 诗篇 115:14; 箴言 14:28"> 约押对王说：“愿耶和华你的上帝使百姓无论现有多少，再增加百倍，并且愿我主我王亲眼看见。但我主我王为什么喜悦做这事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:29; 传道书 8:4; 历代志上 21:4"> 然而，王的话胜过了约押和军队的众首领。约押和军队的众首领就从王面前出去，数点以色列百姓。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 13:9; 申命记 2:36; 约书亚记 13:16"> 他们过了约旦河，在亚罗珥安营，在迦得谷中那城的右边，又到雅谢；</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 19:28; 创世记 31:47–48; 士师记 18:28–29"> 然后他们来到基列和他停·合示地；又来到但雅安，绕到西顿，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:29; 约书亚记 11:3; 创世记 21:22–33"> 来到推罗的堡垒，以及希未人和迦南人的各城；又出去到犹大南方的别是巴。</span>
<span className="v" id="v8" data-v="8"> 他们走遍全地，过了九个月二十天，就来到耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:23–24; 历代志上 21:5–6; 民数记 1:44–46"> 约押把数点百姓所得的总数呈报给王；以色列中拔刀的勇士有八十万人，犹大人有五十万人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:13; 撒母耳记上 13:13; 箴言 28:13"> 大卫数点百姓以后，心里自责。大卫对耶和华说：“我做了这事，犯了大罪。现在，耶和华啊，求你除去你仆人的罪孽；因为我行了极其愚昧的事。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 22:5; 撒母耳记上 9:9; 历代志上 29:29"> 大卫早晨起来时，耶和华的话临到先知迦得，就是大卫的先见，说：</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:6–10; 启示录 3:19; 箴言 3:12"> “你去告诉大卫：‘耶和华这样说：“我给你提出三样事，你要选择其中一样，好让我照你所选的施行在你身上。”’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志上 21:12; 利未记 26:25; 撒母耳记下 21:1"> 于是迦得来到大卫那里，告诉他说：“是要七年的饥荒临到你的地吗？还是你在敌人追赶你时，在他们面前逃跑三个月？还是你的地要有三天的瘟疫？现在你要回答，并考虑我该怎样回复那差我来的。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 51:1; 诗篇 119:156; 历代志上 21:13"> 大卫对迦得说：“我非常困苦。现在让我们落在耶和华的手中吧，因为祂的怜悯极大。不要让我落在人的手中。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:14; 历代志上 27:24; 民数记 25:9"> 于是耶和华从早晨直到所定的时候，降瘟疫在以色列中；从但直到别是巴，百姓中死了七万人。</span>
<span className="v" id="v16" data-v="16" data-xref="约珥 2:13–14; 创世记 6:6; 出埃及记 12:23"> 天使向耶路撒冷伸手要毁灭它的时候，耶和华为这灾祸转意，对那毁灭百姓的天使说：“够了。现在收回你的手。”那时耶和华的天使在耶布斯人亚劳拿的禾场旁。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 74:1; 历代志上 21:16–17; 撒母耳记下 24:10"> 大卫看见击杀百姓的天使，就对耶和华说：“看哪，是我犯了罪，是我行了悖逆的事；可是这些羊做了什么呢？求你的手攻击我和我父家吧。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志上 21:18–30; 撒母耳记下 24:11"> 那一天，迦得来到大卫那里，对他说：“你上去，在耶布斯人亚劳拿的禾场上为耶和华筑一座祭坛。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:8; 尼希米记 9:26; 历代志下 36:16"> 大卫就照迦得的话，按耶和华所吩咐的上去了。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 18:2; 路得记 2:10; 历代志上 21:20–21"> 亚劳拿观看，看见王和他的臣仆向他走来。亚劳拿就出去，脸伏于地，向王下拜。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 21:22; 民数记 25:8; 撒母耳记下 21:3–14"> 亚劳拿说：“我主我王为什么来到仆人这里？”<br />大卫说：“我要买你的禾场，为耶和华筑一座祭坛，使瘟疫停止，不再折磨百姓。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:21; 撒母耳记上 6:14; 历代志上 21:22"> 亚劳拿对大卫说：“愿我主我王拿去，并照他看为好的献上。看哪，这里有牛可以作燔祭，有打粮的器具和牛轭可以作柴。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 20:40–41; 以赛亚书 32:8; 诗篇 20:3–4"> 王啊，这一切，亚劳拿都献给王。”亚劳拿又对王说：“愿耶和华你的上帝悦纳你。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:24–25; 玛拉基书 1:12–14; 创世记 23:13"> 王对亚劳拿说：“不，我一定要按价向你买。我不把白得的燔祭献给耶和华我的上帝。”于是大卫用五十舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司，所以50舍客勒约为0.5千克，或1.1磅。">a</a></sup>银子买了那禾场和牛。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 21:14; 耶利米哀歌 3:32–33; 创世记 8:20"> 大卫在那里为耶和华筑了一座祭坛，献上燔祭和平安祭。耶和华就为这地垂听祈求，瘟疫也从以色列中止住了。</span>
</div>
</div>

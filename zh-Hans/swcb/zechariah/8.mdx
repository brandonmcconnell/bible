<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 万军之耶和华的话临到我。</span>
<span className="v" id="v2" data-v="2" data-xref="约珥 2:18; 撒迦利亚书 1:14–16; 以赛亚书 42:13–14"> 万军之耶和华如此说：“我为锡安大发热心，并以极大的烈怒为她发热心。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 1:16; 撒迦利亚书 2:10–11; 约翰福音 1:14"> 耶和华如此说：“我已经回到锡安，要住在耶路撒冷中间。耶路撒冷必称为‘真理之城’；万军之耶和华的山必称为‘圣山’。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 65:20–22; 约伯记 5:26; 耶利米哀歌 5:11–15"> 万军之耶和华如此说：“年老的男女必再次住在耶路撒冷的街上；各人因年纪老迈，手中都拿着拐杖。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 31:13; 马太福音 11:16–17; 耶利米书 30:19–20"> 城中的街道必满了男孩女孩，在街上玩耍。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 32:27; 罗马书 4:20–21; 民数记 11:22–23"> 万军之耶和华如此说：“在那些日子，这事若在这百姓余民眼中看为希奇，难道在我眼中也看为希奇吗？”万军之耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 31:8; 罗马书 11:25–27; 玛拉基书 1:11"> 万军之耶和华如此说：“看哪，我要从东方之地和西方之地拯救我的百姓。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 36:28; 以西结 11:20; 耶利米书 31:33"> 我要带他们来，他们必住在耶路撒冷中间。他们要作我的子民，我要作他们的上帝，都在真实和公义中。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 35:4; 历代志上 22:13; 以斯拉记 5:1–2"> 万军之耶和华如此说：“你们这些在这日子听见众先知口中这些话的人，手要刚强；这些先知是在万军之耶和华殿的根基奠定、就是圣殿要建造的日子说话的。</span>
<span className="v" id="v10" data-v="10" data-xref="哈该书 1:6–11; 哈该书 2:16–18; 阿摩司 3:6"> 因为在那些日子以前，人没有工价，牲畜也没有工价；因敌人的缘故，出入的人也不得平安；因为我使众人各自与邻舍相敌。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 12:1; 哈该书 2:19; 撒迦利亚书 8:8–9"> 但如今，我待这百姓的余民，必不像从前的日子那样，”万军之耶和华说。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 26:4–5; 申命记 33:13; 创世记 27:28"> “因为必有平安的种子；葡萄树必结果子，土地必出土产，诸天必降甘露。我必使这百姓的余民承受这一切。</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:20; 撒迦利亚书 8:9; 诗篇 72:17"> 犹大家和以色列家啊，从前你们在列国中怎样成了咒诅，照样，我要拯救你们，你们也必成为祝福。不要惧怕。你们的手要刚强。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:28; 以西结 24:14; 耶利米书 4:28"> 因为万军之耶和华如此说：“你们列祖惹我发怒的时候，我怎样定意降灾给你们，”万军之耶和华说，“并且我没有后悔，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 8:13; 弥迦书 7:18–20; 路加福音 12:32"> 照样，在这些日子，我也再次定意善待耶路撒冷和犹大家。不要惧怕。</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所书 4:25; 撒迦利亚书 7:9; 诗篇 15:2"> 你们所当行的是这些事：各人要对邻舍说真实话；在你们的城门口，要施行真实与和平的审判；</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; 弥迦书 2:1–3; 耶利米书 44:4"> 你们谁都不可在心里图谋恶事陷害邻舍，也不可喜爱虚假的誓言；因为这一切都是我所恨恶的，”耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 万军之耶和华的话临到我。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 8:16; 耶利米书 39:2; 撒迦利亚书 7:5"> 万军之耶和华如此说：“四月、五月、七月、十月的禁食，必成为犹大家的喜乐、欢欣和愉快的节期。因此，你们要爱真实与和平。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 2:2–3; 弥迦书 4:1–2; 撒迦利亚书 2:11"> 万军之耶和华如此说：“还必有许多民族和许多城的居民前来。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 7:2; 何西阿 6:3; 诗篇 146:1–2"> 这城的居民必到那城去，说：‘我们要快去恳求耶和华的恩惠，寻求万军之耶和华。我也要去。’</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亚书 8:21; 以赛亚书 60:3–22; 启示录 21:24"> 是的，许多民族和强大的国家必来到耶路撒冷，寻求万军之耶和华，恳求耶和华的恩惠。”</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 55:5; 哥林多前书 14:25; 以赛亚书 60:3"> 万军之耶和华如此说：“在那些日子，列国各语言中必有十个人抓住一个犹太人的衣襟，说：‘我们要与你们同去，因为我们听说上帝与你们同在。’”</span>
</div>
</div>

<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 11:7; 马太福音 23:37; 罗马书 15:8"> 耶和华我的上帝说：“你要牧养那将被宰杀的羊群。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 50:7; 何西阿 12:8; 提摩太前书 6:5–10"> 买它们的人宰杀它们，却不受惩罚；卖它们的人说：‘耶和华当受称颂，因为我富足了。’它们自己的牧人也不怜惜它们。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 13:14; 马太福音 22:7; 以赛亚书 9:19–21"> 耶和华说：‘我必不再怜惜这地的居民。看哪，我要把各人交在他邻舍手中和他王手中。他们必击打这地，我也不从他们手中解救他们。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 11:14; 撒迦利亚书 11:4; 以赛亚书 11:4"> 于是我牧养那将被宰杀的羊群，尤其是羊群中受压迫的。我为自己拿了两根杖，一根我称为“恩惠”，另一根我称为“联合”；我就牧养羊群。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 49:7; 马太福音 23:34–36; 约翰福音 15:18"> 一个月之内，我除灭了那三个牧人；因为我的心厌烦他们，他们的心也憎恶我。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 43:11; 马太福音 13:10–11; 马太福音 21:19"> 于是我说：“我不牧养你们了。要死的，就让它死；要被剪除的，就让它被剪除；剩下的，就让它们彼此吃对方的肉。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 11:7; 诗篇 89:39; 希伯来书 8:8–13"> 我拿起我的杖“恩惠”，把它折断，为要废弃我与万民所立的约。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅书 3:12; 路加福音 2:38; 申命记 31:21"> 那一天，这约就废弃了；这样，羊群中那些听从我的穷苦人就知道这是耶和华的话。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:15; 出埃及记 21:32; 路加福音 22:3–6"> 我对他们说：“如果你们看为好，就给我工价；若不然，就留着吧。”于是他们称了三十块银子作为我的工价。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 27:3–10; 使徒行传 1:18–19; 以赛亚书 53:2–3"> 耶和华对我说：“把它丢给陶匠吧——这就是他们给我估定的那美好的价钱！”我拿了那三十块银子，把它们丢给耶和华殿中的陶匠。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 9:21; 以赛亚书 11:13; 使徒行传 23:7–10"> 然后我折断另一根杖“联合”，为要废弃犹大和以色列之间的弟兄情谊。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 6:10–12; 路加福音 11:40; 耶利米书 2:26–27"> 耶和华对我说：“你还要再为自己拿愚昧牧人的器具。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 34:2–6; 耶利米书 23:2; 马太福音 23:2–4"> 因为看哪，我要在这地兴起一个牧人；他不看顾那些被剪除的，不寻找那些分散的，不医治受伤的，也不喂养健壮的；却要吃肥羊的肉，撕裂它们的蹄子。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 23:1; 以西结 13:3; 哥林多前书 8:4"> 祸哉，那离弃羊群的无用牧人！刀必击打他的膀臂和右眼。他的膀臂必完全枯干，他的右眼必全然昏暗！”</span>
</div>

<span className="v" id="v7" data-v="7" data-xref="以赛亚书 48:20; 创世记 19:17; 以赛亚书 52:11"> 锡安哪，来吧！与巴比伦女子同住的啊，要逃脱。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 17:8; 申命记 32:10; 约翰福音 15:21–23"> 万军之耶和华这样说：为了荣耀，祂差遣我到掳掠你们的列国那里；因为触碰你们的，就是触碰祂眼中的瞳人。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 19:16; 以赛亚书 14:2; 撒迦利亚书 4:9"> 看哪，我必向他们挥动我的手，他们就必成为服侍他们之人的掠物；你们就知道是万军之耶和华差遣了我。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 28:20; 约翰福音 1:14; 西番雅书 3:14–15"> 锡安的女儿啊，要歌唱欢喜！因为看哪，我来了，必住在你中间。这是耶和华说的。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 11:15; 彼得前书 2:9–10; 使徒行传 28:28"> 到那日，许多国家必归附耶和华，成为我的子民；我必住在你中间，你就知道是万军之耶和华差遣了我到你那里。</span>
<span className="v" id="v12" data-v="12" data-xref="撒迦利亚书 1:17; 申命记 32:9; 耶利米书 10:16"> 耶和华必在圣地承受犹大作祂的产业，又必再次拣选耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷 2:20; 诗篇 68:5; 诗篇 78:65"> 凡有血肉的，都要在耶和华面前静默；因为祂已经从祂的圣所居所起来了！”</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 1:1; 以斯拉记 6:14–15; 撒迦利亚书 1:1"> 大流士王第四年，九月，就是基斯流月的第四日，耶和华的话临到撒迦利亚。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 8:21; 耶利米书 26:19; 撒母耳记上 13:12"> 伯特利的人派沙利色、利坚·米勒和他们的人去恳求耶和华施恩，</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 8:19; 雅各书 4:8–10; 玛拉基书 2:7"> 并去对万军之耶和华殿中的祭司和先知说：“我是否还要在五月哭泣、禁戒自己，像我这些年来所做的一样呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 10:16"> 万军之耶和华的话临到我说：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 1:12; 以赛亚书 58:4–6; 哥林多前书 10:31"> “你要对这地所有的百姓和祭司说：‘这七十年来，你们在五月和七月禁食哀哭，真是为我禁食，真是为我吗？</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 11:20–21; 哥林多前书 11:26–29; 何西阿 8:13"> 你们吃、你们喝的时候，不是为自己吃、为自己喝吗？</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:16–20; 耶利米书 17:26; 耶利米书 7:5"> 当耶路撒冷有人居住并且繁荣，周围的城镇、南地和低地也有人居住的时候，耶和华藉从前的先知所宣告的，不正是这些话吗？’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华的话临到撒迦利亚说：</span>
<span className="v" id="v9" data-v="9" data-xref="弥迦书 6:8; 诗篇 82:2–4; 箴言 21:3"> “万军之耶和华曾这样说：‘你们要施行真实的审判，各人要以恩慈和怜悯待自己的弟兄。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:28; 以赛亚书 1:23; 雅各书 5:4"> 不可欺压寡妇、孤儿、寄居者和穷人；你们谁也不可在心里图谋恶事陷害自己的弟兄。’</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 9:29; 耶利米书 8:5; 何西阿 4:16"> 但他们不肯听从，转过肩背，塞住耳朵，不愿听见。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 11:19; 尼希米记 9:29–30; 历代志下 36:16"> 是的，他们使自己的心硬如火石，免得听见律法，以及万军之耶和华藉祂的灵、藉从前的先知所传的话。因此，万军之耶和华有大忿怒临到。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 1:24–28; 耶利米书 14:12; 以赛亚书 1:15"> 事情就这样发生了：正如祂呼唤，他们不肯听从；照样，他们呼求，我也不听，”万军之耶和华说；</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:33; 申命记 28:64; 耶利米书 23:19"> “我却要用旋风把他们驱散到他们不认识的万国中。这样，他们离去以后，这地就荒凉了，以致无人经过，也无人返回；因为他们使可喜悦之地变为荒凉。”</span>
</div>

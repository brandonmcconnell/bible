<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:4; 约翰一书 3:18; 约翰福音 8:32"> 作长老的，写信给蒙拣选的女士和她的儿女，就是我在真理中所爱的；不但我爱他们，所有认识真理的人也爱他们，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 2:14; 约翰一书 1:8; 约翰一书 2:17"> 这是为那住在我们里面，并且必永远与我们同在的真理。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 4:10; 罗马书 1:7; 提摩太前书 1:14"> 恩典、怜悯、平安必与我们同在，从父上帝和父的儿子主耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>而来，在真理和爱中。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰三书 1:3–4; 以弗所书 5:8; 以弗所书 5:2"> 我非常喜乐，因为我发现你的儿女中有人行在真理中，正如我们从父所领受的命令。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 3:11; 约翰福音 13:34–35; 约翰福音 15:12"> 女士啊，现在我恳求你：我写给你的并不是一条新命令，而是我们从起初就有的命令，就是我们要彼此相爱。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰一书 5:3; 约翰一书 2:24; 约翰福音 15:10"> 爱就是我们照祂的命令行。这就是命令，正如你们从起初所听见的：你们要行在其中。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 2:26; 约翰一书 4:1–3; 约翰一书 2:18–22"> 因为有许多迷惑人的已经进入世上，就是那些不承认耶稣基督成了肉身而来的人。这样的人就是那迷惑人的，也是那敌基督者。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:35; 启示录 3:11; 哥林多前书 3:14"> 你们要小心自己，免得我们失去已经做成的事，而要得着完全的赏赐。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 7:16–17; 歌罗西书 3:16; 约翰一书 2:22–24"> 凡越界而不住在基督教导中的，就没有上帝；住在这教导中的，就有父，也有子。</span>
<span className="v" id="v10" data-v="10" data-xref="提多书 3:10; 罗马书 16:17–18; 帖撒罗尼迦后书 3:6"> 如果有人到你们那里，不带着这教导，不要接他到家里，也不要问候他；</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:22; 以弗所书 5:11; 启示录 18:4"> 因为问候他的，就是参与他的恶行。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰三书 1:13–14; 约翰福音 16:12; 哥林多前书 16:5–7"> 我还有许多事要写给你们，却不愿意用纸和墨来写；但我盼望到你们那里，与你们面对面交谈，好使我们的喜乐得以满足。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 5:13; 约翰二书 1:1–13"> 你那蒙拣选的姊妹的儿女问候你。阿们。</span>
</div>

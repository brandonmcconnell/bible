<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 3:1–9; 彼得后书 2:1; 哥林多后书 11:13–15"> 圣灵明明地说，后来有些人会离弃信仰，去听从迷惑人的邪灵和鬼魔的教训，</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:19; 使徒行传 20:30; 罗马书 16:18"> 这些是借着说谎之人的假冒为善而来；这些人的良心像被热铁烙过一样。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 13:4; 提摩太前书 4:4; 罗马书 14:6"> 他们禁止嫁娶，又吩咐人禁戒食物；这些食物是上帝创造的，要让那些信而明白真理的人怀着感恩领受。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 14:20; 哥林多前书 10:25; 罗马书 14:14"> 因为上帝所创造的一切都是好的；若怀着感恩领受，就没有什么可弃绝的。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 4:3; 哥林多前书 7:14; 路加福音 4:4"> 因为它借着上帝的话语和祷告成为圣洁。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 2:7–10; 歌罗西书 3:16; 马太福音 13:52"> 你若把这些事提醒弟兄们，就是基督耶稣的好仆人，在信仰的话语和你一向遵从的美好教训上得了养育。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 2:16; 提多书 2:12; 提摩太前书 1:4"> 至于世俗和老妇的无稽传说，你要拒绝；要操练自己，以致敬虔。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:33; 提摩太前书 6:6; 诗篇 37:3–4"> 因为身体的操练有一些益处；惟有敬虔在凡事上都有益处，因它有今生和来世生命的应许。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:15"> 这话是可信的，值得完全接受。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 2:4; 约翰一书 2:2; 提摩太前书 2:6"> 为此，我们劳苦又受辱，因为我们信靠永活的上帝；祂是万人的救主，尤其是信徒的救主。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:2; 提摩太后书 4:2; 提多书 2:15"> 你要吩咐并教导这些事。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提多书 2:7; 提摩太后书 2:22; 提摩太后书 2:15"> 不可让人轻看你年轻；倒要在言语、行为、爱心、灵、信心和纯洁上，作信徒的榜样。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 6:4; 提多书 2:15; 提摩太后书 4:2"> 在我来以前，你要专心于宣读、劝勉和教导。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 1:6; 彼得前书 4:9–11; 提摩太前书 1:18"> 不要忽略你里面的恩赐，就是借着预言、在众长老按手时赐给你的。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:16; 腓立比书 2:15–16; 诗篇 143:5"> 这些事你要殷勤去做，并全心投入，使众人都看出你的长进。</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 1:9; 提多书 2:7; 约翰二书 1:8–9"> 你要谨慎自己和自己的教导；要在这些事上持守，因为你这样做，就能救自己，也能救听你的人。</span>
</div>

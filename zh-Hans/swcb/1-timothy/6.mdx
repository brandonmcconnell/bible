<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1TI" data-book-slug="1-timothy" data-book-name="提摩太前书" data-chapter="6" data-verses="21">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多书 2:5; 彼得前书 2:17–20; 提多书 2:8–10"> 凡在轭下作奴仆的，都要看自己的主人配受一切尊敬，好使上帝的名和教义不被亵渎。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 4:1; 提摩太前书 4:11; 创世记 16:4–5"> 那些有信主之主人作主人的，不可因为他们是弟兄就轻看他们，反倒要更好地服侍他们，因为领受这益处的是信主而蒙爱的人。你要教导并劝勉这些事。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:3; 罗马书 16:17; 提摩太前书 1:10"> 如果有人传异教，不赞同纯正的话，就是我们主耶稣基督的话，也不赞同合乎敬虔的教义，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 2:23; 提摩太后书 3:4; 提摩太前书 3:6"> 他就是自高自大，一无所知，却迷恋争辩、争论和言词之争；由此产生嫉妒、纷争、毁谤、恶意猜疑，</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 3:5; 提多书 1:11; 彼得后书 2:3"> 以及那些心思败坏、失去真理之人的不断争执；他们以为敬虔是得利的门路。你要离开这样的人。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 抄本省略“你要离开这样的人”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:5; 提摩太前书 6:8; 箴言 16:8"> 然而，敬虔加上知足就是大利。</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 1:21; 诗篇 49:17; 路加福音 12:20–21"> 因为我们没有带什么到世上来，也确实不能带什么出去。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 13:5–6; 马太福音 6:11; 马太福音 6:25–33"> 只要有食物和衣服，我们就该以此为足。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 2:15–17; 箴言 15:27; 提摩太前书 3:7"> 但那些决意要发财的人，就落入试探、网罗和许多愚昧有害的私欲中；这些私欲使人沉没在败坏和灭亡里。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 1:19; 提摩太前书 6:9; 诗篇 32:10"> 因为贪爱钱财是各种恶事的根。有些人贪恋钱财，就偏离了信心，用许多愁苦把自己刺透了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 2:22; 提摩太后书 3:17; 提摩太前书 4:12"> 但你这属上帝的人，要逃避这些事，追求公义、敬虔、信心、爱、忍耐和温柔。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 提摩太前书 1:18; 哥林多前书 9:25–26"> 要为信心打那美好的仗；要持定永生。你蒙召就是为此，并且在许多见证人面前作了那美好的告白。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 18:36–37; 马太福音 27:11; 提摩太前书 5:21"> 我在赐生命给万物的上帝面前，并在曾在本丢·彼拉多面前为那美好的告白作见证的基督耶稣面前，吩咐你：</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 3:14; 彼得前书 1:7; 帖撒罗尼迦前书 5:23"> 要守住这命令，毫无玷污，无可指责，直到我们的主耶稣基督显现。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 19:16; 启示录 17:14; 提摩太前书 1:17"> 到了适当的时候，祂要显明这显现；祂是那有福、独一的掌权者，万王之王、万主之主。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 1:17; 约翰福音 1:18; 约翰一书 1:5"> 唯有祂是不朽的，住在人不能靠近的光中，是没有人曾看见、也不能看见的。愿尊荣和永远的权能归给祂。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 11:28; 使徒行传 14:17; 箴言 27:24"> 你要嘱咐今世富有的人，不要高傲，也不要把盼望寄托在无定的钱财上，而要寄托在永活的上帝身上；祂丰富地供给我们万物，使我们享用。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 约翰一书 3:17; 诗篇 37:3"> 又要嘱咐他们行善，在善事上富足，乐意施舍，愿意分享；</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 6:19–21; 提摩太前书 6:12; 提摩太后书 2:19"> 为自己积存美好的根基，预备将来，使他们可以持定永生。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 提摩太后书 2:16; 提摩太后书 1:12–14"> 提摩太啊，要守护那托付给你的，避开虚空的闲谈和那被误称为知识的反论；</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:18; 提摩太前书 1:6; 提摩太后书 4:22"> 有些人自称有这种知识，就偏离了信心。<br />愿恩典与你们同在。阿们。</span>
</div>
</div>

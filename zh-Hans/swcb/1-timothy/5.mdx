<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1TI" data-book-slug="1-timothy" data-book-name="提摩太前书" data-chapter="5" data-verses="25">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 19:32; 彼得前书 5:5–6; 提多书 2:2"> 不要严责老年男子，只要劝他如同父亲；劝年轻男子如同弟兄；</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 4:12; 马太福音 12:50; 腓立比书 4:8"> 劝老年妇女如同母亲；劝年轻妇女如同姐妹，总要完全纯洁。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 27:19; 使徒行传 6:1; 申命记 10:18"> 要尊敬那些真正的寡妇。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 6:1–3; 约翰福音 19:26–27; 马太福音 15:4–6"> 但若寡妇有儿女或孙辈，就让他们先学习在自己的家中行敬虔，报答父母，因为这是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加上“美好且”">a</a></sup>上帝面前所悦纳的。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 5:3; 路加福音 2:37; 哥林多前书 7:32"> 那真正作寡妇、无依无靠的，是仰望上帝，昼夜不住地恳求祷告。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 5:5; 启示录 18:7; 路加福音 15:24"> 但那贪图享乐的，虽活着也是死的。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 4:11; 提多书 2:15; 提摩太后书 4:1"> 这些事你也要吩咐她们，使她们无可指责。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 6:10; 哥林多后书 12:14; 路加福音 11:11–13"> 但若有人不供养自己的人，尤其是自己家里的人，他就是背弃了信仰，比不信的人还不如。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 3:2; 提摩太前书 5:11; 路加福音 2:36–37"> 登记在册的寡妇不可少于六十岁，并且只作过一个丈夫的妻子，</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18; 提多书 3:8; 使徒行传 9:36"> 有善工的证明：若她养育过儿女，接待过外人，洗过圣徒的脚，救济过受苦的人，并且竭力行各样善工。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:14; 何西阿 13:6; 雅各书 5:5"> 至于年轻的寡妇，要拒绝登记，因为她们情欲发动、违背基督的时候，就想要嫁人，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:6; 雅各书 3:1; 哥林多前书 11:34"> 因而招致定罪，因为她们废弃了起初的承诺。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 帖撒罗尼迦后书 3:6–11; 使徒行传 20:30"> 此外，她们又学会懒散，挨家挨户闲逛；不但懒散，还说闲话、好管闲事，说不该说的话。</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 2:5; 提摩太前书 6:1; 提多书 2:8"> 所以我愿意年轻的寡妇嫁人，生养儿女，管理家务，不给对头留下辱骂的机会。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:2; 犹大书 1:4–5; 彼得后书 2:20–22"> 因为已经有些人转去跟从撒但了。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 5:3–5; 提摩太前书 5:8"> 若有信的人，无论男女，家中有寡妇，就该救济她们，不要让教会受累，好让教会救济那些真正的寡妇。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:17; 帖撒罗尼迦前书 5:12–13; 加拉太书 6:6"> 善于治理的长老，应当算为配受加倍的尊荣，尤其是在话语和教导上劳苦的人。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 25:4; 哥林多前书 9:14; 哥林多前书 9:7–10"> 因为经上说：“牛踹谷的时候，不可笼住它的嘴。” 又说，<span className="woj">“工人配得他的工钱。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:16; 申命记 19:15; 哥林多后书 13:1"> 对长老的控告，除非有两三个见证人的证言，否则不要受理。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:2; 提多书 1:13; 提摩太前书 1:20"> 犯罪的人，要在众人面前责备他们，使其余的人也心生惧怕。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4; 提摩太后书 4:1; 提摩太前书 6:13"> 我在上帝、主耶稣基督和蒙拣选的天使面前嘱咐你：要遵守这些事，不存偏见，做什么都不可偏心。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:11; 提摩太前书 3:10; 提摩太前书 3:6"> 不要急促给任何人按手。不要在别人的罪上有份。要保守自己纯洁。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 104:15; 箴言 31:4–7; 提摩太前书 4:4"> 不要再只喝水；为了你的胃和你常有的疾病，可以稍微用点酒。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10; 使徒行传 8:18; 加拉太书 5:19–21"> 有些人的罪是明显的，先他们来到审判面前；有些人的罪也随后跟来。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; 路加福音 11:33; 诗篇 37:5–6"> 同样，善工也有明显的；那些不是明显的，也不能隐藏。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="腓立比书 1:27; 哥林多前书 16:13; 诗篇 27:14"> 所以，我所亲爱、所想念的弟兄们，你们是我的喜乐、我的冠冕；我亲爱的，你们要这样在主里站立得稳。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="希伯来书 12:14; 哥林多前书 1:10; 马可福音 9:50"> 我劝友阿蝶，也劝循都基，要在主里同心。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:5; 启示录 13:8; 路加福音 10:20"> 是的，我也求你这位忠诚的同伴，帮助这些妇女；因为她们曾在福音上与我一同劳苦，也与革利免以及我其余的同工一同劳苦；他们的名字都在生命册上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:16–18; 罗马书 12:12; 雅各书 1:2–4"> 你们要常常在主里喜乐！我再说：“你们要喜乐！”</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:8–9; 马太福音 6:25; 提多书 3:2"> 要让众人知道你们的温和。主近了。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 3:5–6; 彼得前书 5:7; 马太福音 6:25–33"> 应当一无挂虑，只要凡事借着祷告、恳求和感谢，把你们所求的告诉上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:27; 以赛亚书 26:3; 帖撒罗尼迦后书 3:16"> 上帝所赐、超越一切理性的平安，必在基督耶稣里守护你们的心和你们的意念。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:17; 提多书 2:7; 罗马书 12:9–21"> 最后，弟兄们，凡是真实的，凡是可敬的，凡是公正的，凡是纯洁的，凡是可爱的，凡是有美名的；若有什么美德，若有什么值得称赞的，这些事你们都要思想。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:22; 腓立比书 3:17; 帖撒罗尼迦前书 4:1–8"> 你们从我所学习、所领受、所听见、所看见的事，都要去行；赐平安的上帝就必与你们同在。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 11:9; 加拉太书 6:6; 哥林多后书 7:6–7"> 我在主里大大喜乐，因为如今你们对我的关心终于重新兴起；其实你们确实一直关心，只是没有机会。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:6–9; 希伯来书 13:5–6; 马太福音 6:31–34"> 我并不是因缺乏才这样说，因为无论在什么境况中，我已经学会知足。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 11:29; 哥林多后书 12:7–10; 哥林多后书 11:27"> 我知道怎样处卑贱，也知道怎样处丰富；在任何事、任何境况中，我都已经学会秘诀：或饱足，或饥饿；或丰富，或缺乏。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 41:10; 哥林多后书 12:9–10; 歌罗西书 1:11"> 我靠着那加给我力量的基督，凡事都能做。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:16; 腓立比书 1:7; 希伯来书 10:34"> 然而，你们分担我的患难，做得好。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:5; 哥林多后书 11:8–12; 使徒行传 16:40–5"> 腓立比人哪，你们自己也知道，在福音开始的时候，我离开马其顿，没有一个教会在供给与接受的事上与我有份，只有你们。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:9; 使徒行传 17:1; 帖撒罗尼迦前书 2:18"> 因为我在帖撒罗尼迦的时候，你们也一次又一次地送来供给我的需要。</span>
<span className="v" id="v17" data-v="17" data-xref="提多书 3:14; 希伯来书 6:10; 哥林多后书 9:9–13"> 这并不是我求礼物，而是我求那归在你们账上不断增多的果子。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 腓立比书 4:12; 哥林多后书 9:12"> 但我样样都有，并且有余；我已经充足，因为我从以巴弗提收到了你们送来的东西，那是馨香的气味，是上帝所悦纳、所喜悦的祭物。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 9:8–11; 诗篇 84:11; 彼得前书 5:10"> 我的上帝必照祂在基督耶稣里荣耀的丰富，供应你们一切所需。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 11:36; 诗篇 115:1; 启示录 14:7"> 愿荣耀归给我们的上帝和父，直到永永远远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 1:2; 腓利门书 1:23–24; 歌罗西书 4:10–14"> 请问候在基督耶稣里的每一位圣徒。与我在一起的弟兄们问候你们。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 1:13; 哥林多后书 13:13; 罗马书 16:16"> 众圣徒都问候你们，特别是凯撒家里的人问候你们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 13:14; 罗马书 16:20; 罗马书 16:23"> 愿主耶稣基督的恩典与你们众人同在。阿们。</span>
</div>

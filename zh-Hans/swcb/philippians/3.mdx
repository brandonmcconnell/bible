<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 5:11; 腓立比书 4:4; 雅各书 1:2"> 最后，我的弟兄们，你们要在主里喜乐！把同样的话写给你们，对我来说并不厌烦，对你们却是稳妥的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 11:13; 提多书 1:16; 启示录 22:15"> 要提防那些狗；要提防那些作恶的人；要提防那假割礼。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:11; 申命记 30:6; 罗马书 7:6"> 因为我们才是受割礼的，就是靠着圣灵敬拜上帝、在基督耶稣里喜乐、不信靠肉体的人；</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 11:18–22"> 虽然我自己也可以信靠肉体。如果别人以为自己可以信靠肉体，我更可以：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:22; 罗马书 11:1; 使徒行传 23:6"> 我第八天受割礼，出于以色列族，属于便雅悯支派，是希伯来人所生的希伯来人；按律法说，是法利赛人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:13–14; 使徒行传 8:3; 使徒行传 26:9–10"> 按热心说，是逼迫教会的；按律法上的义说，是无可指摘的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 马太福音 16:26; 马太福音 13:44–46"> 然而，凡从前对我有益的，我因基督都看作亏损。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 9:23–24; 罗马书 8:18; 腓立比书 3:7"> 不但如此，我也把万事看作亏损，因为认识我主基督耶稣是至宝。为了祂，我已经失去万事，并且看作粪土，为要得着基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:21; 哥林多前书 1:30; 加拉太书 2:16"> 并且被发现在祂里面；我不是有自己那出于律法的义，而是有那借着信基督而来的义，就是从上帝而来、基于信心的义，</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 2:20; 罗马书 8:17; 彼得前书 4:1–2"> 使我认识祂和祂复活的大能，并且与祂一同受苦，效法祂的死，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 启示录 20:5; 使徒行传 23:6"> 或者无论如何可以达到从死人中复活。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 6:11–12; 彼得后书 1:5–8; 诗篇 138:8"> 这不是说我已经得着了，或已经完全了；我乃是竭力追求，好抓住那目标，正如基督耶稣也为此抓住了我。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯来书 12:1–2; 腓立比书 3:12"> 弟兄们，我不认为自己已经抓住了；但我只做一件事：忘记背后，努力面前，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:24; 彼得前书 5:10; 启示录 3:21"> 向着目标竭力追求，为要得着上帝在基督耶稣里从上面呼召我所得的奖赏。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 7:17; 雅各书 1:4–5; 箴言 2:3–6"> 所以，我们中凡是成熟的人，都应当这样想。如果在任何事上你们有不同的想法，上帝也会把这事启示给你们。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:6; 启示录 3:3; 启示录 2:4–5"> 不过，我们已经达到什么地步，就应当照着同一准则行事，也应当有同样的心思。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="腓立比书 4:9; 哥林多前书 4:16; 彼得前书 5:3"> 弟兄们，你们要一同效法我，也要留意那些照我们给你们的榜样而行的人。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 4:17; 以赛亚书 8:11; 加拉太书 6:12"> 因为有许多人行事，我屡次告诉你们，现在甚至流泪地告诉你们：他们是基督十字架的仇敌；</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 16:18; 罗马书 8:5–7; 彼得后书 2:3"> 他们的结局是灭亡；他们的神是自己的肚腹；他们以自己的羞辱为荣耀；他们专念地上的事。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 2:19; 歌罗西书 3:1–3; 哥林多后书 4:18–1"> 但我们的公民身份是在天上；我们也从那里等候救主，就是主耶稣基督。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 3:2; 歌罗西书 3:4; 哥林多前书 15:42–56"> 祂要改变我们卑微的身体，使它和祂荣耀的身体相似，这是照着祂那甚至能使万有都服从自己的大能运行。</span>
</div>

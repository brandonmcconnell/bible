<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:12; 约翰一书 4:12; 约翰一书 4:7–8"> 所以，在基督里若有什么劝勉，爱中若有什么安慰，圣灵里若有什么相交，若有什么慈心和怜悯，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:16; 彼得前书 3:8–9; 哥林多前书 1:10"> 就要意念相同，有同样的爱，同心合意，心思一致，使我的喜乐满足。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 12:10; 加拉太书 5:26; 以弗所书 5:21"> 凡事不可出于争竞或虚荣，只要存谦卑的心，各人看别人比自己强；</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:24; 罗马书 15:1; 雅各书 2:8"> 各人不要只顾自己的事，也要顾别人的事。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 2:21"> 你们要有这样的心志，就是基督耶稣所具有的：</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 5:18; 哥林多后书 4:4; 希伯来书 1:3"> 祂本有上帝的形态，却不把与上帝同等看作要紧抓不放的事，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:9; 马太福音 20:28; 约翰福音 1:14"> 反而倒空自己，取了奴仆的形态，成为人的样式。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:18; 希伯来书 12:2; 罗马书 5:19"> 祂既显为人的形状，就谦卑自己，顺服至死，而且死在十字架上。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:16; 马太福音 28:18; 彼得前书 3:22"> 因此，上帝也将祂升为至高，又赐给祂那超乎万名之上的名，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 45:23–25; 马太福音 28:18; 启示录 5:13–14"> 使天上的、地上的和地底下的一切，因耶稣的名无不屈膝，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 4:15; 罗马书 14:11; 约翰福音 13:13"> 无不口称耶稣基督为主，使荣耀归于父上帝。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得后书 1:5–10; 路加福音 13:23–24; 哥林多前书 15:58"> 这样，我亲爱的，你们既然一向顺服，不但我在你们那里时如此，如今我不在的时候更是如此，就当恐惧战兢，做成你们自己的救恩。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:21; 哥林多后书 3:5; 提摩太后书 1:9"> 因为是上帝在你们里面运行，使你们立志并行事，为要成就祂的美意。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:9; 哥林多前书 10:10; 腓立比书 2:3"> 凡事都不要发怨言、起争论，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:14–16; 彼得前书 2:12; 马太福音 5:45"> 好使你们无可指责，纯洁无害，在这弯曲悖谬的世代中作上帝无瑕疵的儿女；你们在他们中间显明为世上的光，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 9:26; 加拉太书 2:2; 约翰一书 1:1"> 持守生命的道，使我在基督的日子可以夸口，知道我没有空跑，也没有徒劳。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 4:6; 罗马书 15:16; 希伯来书 13:15–16"> 是的，即使我被浇奠在你们信心的祭物和事奉上，我也喜乐，并且与你们众人一同喜乐。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:2–4; 腓立比书 4:4; 腓立比书 3:1"> 你们也要照样喜乐，并且与我一同喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:17; 帖撒罗尼迦前书 3:6–8; 帖撒罗尼迦前书 3:2"> 我靠着主耶稣盼望不久就打发提摩太到你们那里去，使我知道你们的情况后，也可以得着鼓励。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 2:2; 哥林多前书 16:10; 腓立比书 2:22"> 因为我没有别人与我同心，真正关心你们的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:24; 马太福音 16:24; 腓立比书 2:4"> 因为众人都求自己的事，不求耶稣基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 4:17; 哥林多后书 2:9; 提摩太后书 1:2"> 但你们知道他经过考验，像儿子服事父亲一样，他与我一同服事，推进福音。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 22:3; 腓立比书 2:19"> 所以，我一看出我的事将会怎样，就盼望立刻打发他去。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰三书 1:14; 腓利门书 1:22; 腓立比书 1:25–26"> 但我靠着主深信，我自己也快要去。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:18; 腓利门书 1:1–2; 腓立比书 4:3"> 然而，我认为必须把以巴弗提送回你们那里去。他是我的弟兄、同工、同当兵的，也是你们的使者，供给我所需的仆役；</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 箴言 12:25; 以弗所书 3:13"> 因为他切切想念你们众人，并且非常忧愁，因为你们听见他病了。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:19; 腓立比书 2:30; 诗篇 103:3–4"> 他确实病了，几乎要死；可是上帝怜悯了他，不但怜悯他，也怜悯我，免得我忧上加忧。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:22; 提摩太后书 1:4; 腓立比书 2:26–27"> 所以我更加急切地送他回去，使你们再见到他就可以喜乐，我也可以少些忧愁。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒罗尼迦前书 5:12; 哥林多前书 16:18; 提摩太前书 5:17"> 因此，你们要在主里满心喜乐地接待他，并且尊重这样的人，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 16:17; 使徒行传 20:24; 腓立比书 4:10"> 因为他为了基督的工作，几乎至死，冒着生命危险，要补足你们在服事我这事上的不足。</span>
</div>
</div>

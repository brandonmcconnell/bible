<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:1; 使徒行传 16:12–15; 罗马书 1:1"> 保罗和提摩太，耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”意为“受膏者”。">a</a></sup>的仆人，写信给所有在腓立比、在基督耶稣里的圣徒，连同监督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：“监管者”，或“主教”。">b</a></sup>和服侍者：<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：“执事”。">c</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多后书 1:2; 彼得前书 1:2"> 愿恩典与平安从我们的父上帝和主耶稣基督归给你们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:4; 帖撒罗尼迦前书 1:2–3; 腓利门书 1:4–5"> 我每逢想起你们，就感谢我的上帝；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 1:2; 罗马书 1:9; 约翰二书 1:4"> 每次为你们众人祈求时，总是欢欢喜喜地祈求，</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:14–15; 腓立比书 1:7; 希伯来书 3:14"> 因为从第一天直到如今，你们都同心参与<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="译为“参与”的词（κοινωνίᾳ）也有“团契”和“分享”的意思。">d</a></sup>推进福音；</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦前书 5:23–24; 腓立比书 2:13; 以弗所书 4:12"> 我深信这一点：那在你们里面开始了善工的，必成全这工，直到耶稣基督的日子。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:3; 腓立比书 1:5; 歌罗西书 4:18"> 我为你们众人这样想，本是理所当然的，因为我把你们放在心上；无论我是在捆锁中，还是在辩护并证实福音的时候，你们众人都与我一同有份于恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 罗马书 1:9; 提摩太后书 1:4"> 上帝可以为我作见证，我是怎样以基督耶稣的慈怜切切想念你们众人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 3:12; 歌罗西书 1:9; 彼得后书 1:5–6"> 我所祷告的，就是要你们的爱在知识和一切辨别力上越发丰盛，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 5:23"> 使你们能分辨并认可那美好的事，好叫你们纯洁无过，直到基督的日子，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 约翰福音 15:8; 约翰福音 15:4–5"> 并且结满了借着耶稣基督而来的义果，使上帝得荣耀和赞美。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:9; 罗马书 8:28; 使徒行传 11:19–21"> 弟兄们，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这里译为“弟兄们”的词，在本处以及上下文允许之处，也可正确译为“弟兄姐妹”或“手足”。">e</a></sup>我愿意你们知道，我所遭遇的事反而促进了福音，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 2:9; 以弗所书 3:1; 腓立比书 1:7"> 以致全宫廷卫队<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或译：“禁卫军”。">f</a></sup>和其余所有人都清楚知道，我被捆锁是为基督的缘故；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 6:19–20; 帖撒罗尼迦前书 2:2; 路加福音 1:74"> 并且主里的弟兄大多数因我的捆锁而有信心，越发放胆，无所惧怕地传讲上帝的话。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:17–18; 腓立比书 2:3; 哥林多后书 11:13"> 有些人传基督确实是出于嫉妒和纷争，也有些人是出于善意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:17; 哥林多后书 4:1–2; 诗篇 69:26"> 前者出于自私的野心，并非真诚地传基督，以为可以使我的锁链更添苦楚；</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 1:11–12; 腓立比书 2:3; 腓立比书 1:7"> 后者却是出于爱，知道我是奉派为福音辩护的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 马可福音 9:38–40; 哥林多前书 15:11"> 这有什么关系呢？只要无论怎样，或是假意，或是真心，基督总被传开了。为此我欢喜；是的，我还要欢喜。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 8:28; 使徒行传 16:7; 哥林多后书 1:11"> 因为我知道，借着你们的祷告和耶稣基督之灵的供应，这事终必使我得着拯救，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:16; 哥林多前书 6:20; 以赛亚书 54:4"> 正如我热切的期待和盼望：我绝不会有任何失望，反而现在也要像往常一样，凡事放胆，使基督在我的身体上被尊为大，无论是借着生，还是借着死。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:20; 哥林多后书 5:8; 哥林多后书 5:1"> 因为对我来说，活着就是基督，死了就有益处。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:2; 加拉太书 2:20; 腓立比书 1:24"> 但如果我继续在肉身活着，这会使我的工作结果子；然而我不知道该选择什么。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:8; 诗篇 17:15; 启示录 14:13"> 我被这两者夹在中间：我渴望离世与基督同在，这好得多；</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:7; 腓立比书 1:22; 腓立比书 1:25–26"> 然而为你们的缘故，我留在肉身中更有需要。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 2:24; 哥林多后书 1:24; 以弗所书 4:11–13"> 既然这样确信，我知道我会留下来，并且会和你们众人同住，为了你们在信心上的长进和喜乐，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 1:14; 哥林多后书 5:12; 腓立比书 3:3"> 使你们在基督耶稣里，因我而有的夸耀<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或译：“欢喜”。">g</a></sup>，可以因我再次与你们同在而更加丰盛。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:1; 哥林多前书 16:13–14; 哥林多前书 1:10"> 只要你们行事为人与基督的福音相称，好叫我无论来见你们，或是不在你们那里，都可以听见你们的情况：你们凭着同一个灵站立得稳，同心协力为福音的信仰奋斗；</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 1:7–8; 帖撒罗尼迦后书 1:5–6; 马太福音 10:28"> 丝毫不被敌对者吓倒。这对他们是灭亡的证据，对你们却是救恩的证据，而且这是出于上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 1:2; 彼得前书 4:13; 使徒行传 5:41"> 因为为了基督的缘故，已经恩赐给你们：不但信祂，也要为祂受苦，</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 2:2; 使徒行传 16:19–40; 提摩太后书 4:7"> 正经历同样的争战，就是你们曾在我身上看见、如今又听说仍在我身上的。</span>
</div>
</div>

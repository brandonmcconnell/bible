<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 3:3; 提摩太后书 4:3; 提摩太前书 4:1–3"> 但你要知道：在末后的日子，艰难的时期必来到。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:21; 罗马书 1:29–31; 犹大书 1:16"> 因为人会专爱自己，贪爱钱财，自夸，骄傲，亵渎，违背父母，忘恩负义，不圣洁，</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 罗马书 1:31; 马太福音 10:21"> 无亲情，不肯和解，毁谤人，不能自制，凶暴，不爱良善，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 3:18–19; 提摩太前书 3:6; 犹大书 1:4"> 背叛，任性妄为，自高自大，爱享乐过于爱上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 23:27–28"> 有敬虔的外貌，却否认敬虔的能力；这些人你也要躲开。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:4; 彼得后书 3:17; 提多书 3:3"> 因为这些人中，有些人潜入别人家里，俘获那些被罪压垮、被各样私欲牵引的愚昧妇女；</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:3–4; 以弗所书 4:14; 提摩太前书 2:4"> 她们总是在学习，却始终不能认识真理。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:8–11; 启示录 2:20; 提摩太前书 6:5"> 雅尼和佯庇怎样抵挡摩西，这些人也照样抵挡真理；他们心思败坏，在信仰上被弃绝。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 3:8; 出埃及记 7:12; 耶利米书 28:15–17"> 但他们不能再进一步，因为他们的愚昧必在众人面前显露，正如那两个人的愚昧也显露了一样。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:11; 提多书 2:7; 彼得后书 1:5–7"> 但你跟从了我的教导、品行、志向、信心、忍耐、爱心、坚忍，</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 34:19; 使徒行传 14:5–6; 哥林多后书 11:23–28"> 以及我所受的逼迫和苦难，就是我在安提阿、以哥念、路司得所遭遇的那些事。我忍受了那些逼迫；主把我从这一切中救了出来。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14; 彼得前书 4:12–16; 彼得前书 2:20–21"> 不但如此，凡立志在基督耶稣里敬虔度日的人，都要遭受逼迫。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 4:1; 彼得后书 2:20; 提多书 3:3"> 但恶人和骗子必越来越坏，欺骗人，也被人欺骗。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 提摩太后书 2:2; 提摩太后书 1:13"> 至于你，要持守你所学并确信的事，因为你知道自己是从谁学来的；</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:98–99; 路加福音 24:45; 箴言 22:6"> 并且你从婴孩时期就明白圣经；这圣经能使你借着在基督耶稣里的信心，有得救的智慧。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 15:4; 希伯来书 4:12; 彼得后书 1:19–21"> 全部经文都是上帝所默示的，并且<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：凡上帝所默示的经文，也">a</a></sup>有益于教导、责备、纠正和在公义上的训练，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 2:21; 以弗所书 2:10; 哥林多后书 9:8"> 使每一个属于上帝的人可以完备，为各样善工充分装备好。</span>
</div>

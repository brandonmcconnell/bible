<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:9–10; 以弗所书 6:10; 提摩太后书 1:7"> 所以，我的孩子，你要在基督耶稣里的恩典中刚强起来。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太后书 1:13–14; 提摩太前书 4:6; 提摩太前书 6:12"> 你在许多见证人面前从我听见的那些事，也要交托给忠信的人，使他们也能教导别人。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:2–3; 雅各书 1:12; 提摩太后书 4:5"> 所以，你要忍受苦难，作基督耶稣的好士兵。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:4; 路加福音 8:14; 彼得后书 2:20"> 凡服役的士兵，不让自己被生活事务缠住，好叫招他入伍的人喜悦。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 9:24–27; 启示录 3:11; 提摩太后书 4:7–8"> 同样，人若参加竞赛，不按规矩比赛，就不能得冠冕。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 哥林多前书 9:7–11; 哥林多前书 3:6–9"> 劳苦的农夫理当先分享收成。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:5; 约翰一书 5:20; 路加福音 24:45"> 你要思想我所说的话；愿主在一切事上赐给你悟性。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:24; 罗马书 2:16; 哥林多前书 15:11–20"> 你要记念耶稣基督，祂从死人中复活，是大卫的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：种子">a</a></sup>；这是照着我所传的福音。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 1:7; 使徒行传 28:31; 提摩太后书 1:8"> 我为这福音受苦，甚至像罪犯一样被锁链捆绑；然而上帝的话没有被捆绑。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:10; 歌罗西书 1:24; 提摩太后书 2:3"> 因此，我为蒙拣选的人忍受一切，好使他们也可以得着在基督耶稣里的救恩，连同永恒的荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:8; 歌罗西书 3:3–4; 罗马书 6:5"> 这话是可信的：<br /><span className="pl pl-1">“我们若与祂同死，</span><br /><span className="pl pl-2">也必与祂同活。</span></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 8:17; 马太福音 10:33; 启示录 20:4"> <span className="pl pl-1">我们若忍耐，</span><br /><span className="pl pl-2">也必与祂一同作王。</span><br /><span className="pl pl-1">我们若不认祂，</span><br /><span className="pl pl-2">祂也必不认我们。</span></span>
<span className="v" id="v13" data-v="13" data-xref="民数记 23:19; 罗马书 3:3; 帖撒罗尼迦后书 3:3"> <span className="pl pl-1">我们纵然失信，</span><br /><span className="pl pl-2">祂仍是信实的；</span><br /><span className="pl pl-2">因为祂不能否认自己。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提多书 3:9–11; 提摩太后书 2:23; 提摩太后书 4:1"> 你要提醒他们这些事，在主面前郑重嘱咐他们，不可为言语争辩；这没有益处，只会败坏听见的人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:4; 彼得后书 1:10; 提摩太前书 4:6"> 你要竭力把自己呈献在上帝面前，作蒙认可、无须羞愧的工人，正确地讲解真理的道。</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 3:9; 提摩太前书 6:20; 提摩太后书 2:14"> 但要避开空洞的闲谈，因为这会使人在不敬虔上越陷越深，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:20; 那鸿书 3:15; 雅各书 5:3"> 而且那些话会像坏疽一样蔓延；其中有许米乃和腓理徒。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:12; 提摩太前书 1:19; 希伯来书 3:10"> 他们偏离了真理，说复活的事已经过去，就颠覆了一些人的信心。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 10:14; 哥林多前书 8:3; 那鸿书 1:7"> 然而，上帝坚固的根基立住了，上面有这印记：“主认识属祂的人”；又说：“凡称呼主名的人都当离开不义。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 读作“基督”，而不是“主”">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:21–23; 彼得前书 2:5; 提摩太前书 3:15"> 在大户人家里，不但有金器银器，也有木器瓦器；有些作贵重用途，有些作卑贱用途。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:17; 以弗所书 2:10; 哥林多后书 7:1"> 所以，人若洁净自己，脱离这些，就必作贵重用途的器皿，分别为圣，合乎主人使用，预备行各样善事。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:11; 彼得前书 3:11; 哥林多前书 6:18"> 你要逃避年轻人的私欲；却要同那些以清洁的心呼求主的人一起追求公义、信心、爱和和平。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:14; 提多书 3:9; 提摩太前书 4:7"> 至于愚拙无知的争辩，你要拒绝，因为知道这些会产生纷争。</span>
<span className="v" id="v24" data-v="24" data-xref="提多书 3:2; 雅各书 1:19–20; 提摩太前书 3:2–3"> 主的仆人不可争吵，只要温和待众人，善于教导，忍耐，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 11:18; 加拉太书 6:1; 提摩太前书 2:4"> 用温柔劝戒抵挡他的人。也许上帝会赐给他们悔改，使他们充分认识真理，</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 3:7; 以赛亚书 49:25–26; 诗篇 124:7"> 他们就可以醒悟过来，脱离魔鬼的网罗；他们原是被他掳去，遵行他的旨意。</span>
</div>
</div>

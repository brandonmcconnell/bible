<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 10:42; 提摩太后书 4:8; 提摩太前书 5:21"> 因此，我在上帝和主耶稣基督面前，并凭着祂的显现和祂的国度嘱咐你；祂将要审判活人和死人：</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:14; 提摩太前书 4:15–16; 提多书 2:15"> 务要传讲这道；无论得时不得时，都要迫切；要用百般忍耐和教导去责备、斥责、劝勉。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得后书 2:1–3; 提摩太后书 3:1–6; 提摩太前书 4:1–3"> 因为时候将到，人们不再听纯正的教训，反倒耳朵发痒，随从自己的私欲，为自己聚集许多教师，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 7:11; 提摩太前书 1:4; 使徒行传 7:57"> 并且掩耳不听真理，转向荒诞的传说。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 1:8; 彼得前书 1:13; 提摩太后书 2:3"> 但你凡事要保持清醒，忍受苦难，做传福音者的工作，尽你的职事。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:23; 腓立比书 2:17; 彼得后书 1:14–15"> 因为我已经被献上作奠祭，我离世的时候到了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 6:12; 哥林多前书 9:24–27; 希伯来书 12:1–2"> 那美好的仗我已经打过了；当跑的路程我已经跑完了；信仰我已经守住了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:12; 启示录 2:10; 彼得前书 5:4"> 从今以后，有公义的冠冕为我存留，就是主，那公义的审判者，在那日要赐给我的；不但赐给我，也赐给所有爱慕祂显现的人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:4; 提摩太后书 4:21"> 你要尽快到我这里来，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:15–16; 提摩太后书 1:15; 歌罗西书 4:14–15"> 因为底马爱了这现今的世界，离弃了我，往帖撒罗尼迦去了；革勒士往加拉太去了；提多往挞马太去了。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 12:25"> 只有路加和我在一起。你要把马可带来同你一起，因为他在服侍上对我有用。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 6:21; 使徒行传 20:4; 提多书 3:12"> 至于推基古，我已经差他去以弗所。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 4:11; 哥林多后书 11:27; 使徒行传 16:11"> 你来的时候，要把我留在特罗亚加布那里的外衣带来，还有那些书卷，尤其是那些羊皮卷。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前书 1:20; 帖撒罗尼迦后书 1:6; 诗篇 28:4"> 铜匠亚历山大对我做了许多恶事。主必照他的行为报应他。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 3:8; 腓立比书 3:2; 马太福音 10:16–17"> 你也要防备他，因为他极力抵挡我们的话。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:60; 约翰福音 16:32; 马可福音 14:50"> 我初次申辩的时候，没有人前来帮助我，大家都离弃了我。愿这事不归罪于他们。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 5:8; 腓立比书 1:12–14; 撒母耳记上 17:37"> 但主站在我身旁，加给我力量，使信息借着我得以充分传扬，也使所有外邦人都可以听见。我也就从狮子口里被救出来。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:7; 帖撒罗尼迦后书 3:3; 犹大书 1:24–25"> 主必救我脱离一切邪恶的事，也必保全我进入祂天上的国。愿荣耀归给祂，直到永永远远。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 哥林多前书 16:19; 罗马书 16:3–4"> 请问百基拉和亚居拉，以及阿尼色弗一家的人安。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:4; 使徒行传 19:22; 腓立比书 2:26–27"> 以拉都留在哥林多；特罗非摩病了，我就把他留在米利都。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:9; 腓立比书 4:22; 约翰三书 1:14"> 你务要在冬天以前赶来。友布罗问你安，布田、利奴、革老底亚和所有弟兄也问你安。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="腓利门书 1:25; 加拉太书 6:18; 歌罗西书 4:18"> 愿主耶稣基督与你的灵同在。愿恩典与你们同在。阿们。</span>
</div>
</div>

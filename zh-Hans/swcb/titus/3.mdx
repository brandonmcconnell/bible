<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 13:1–7; 彼得前书 2:13–17; 传道书 10:4"> 你要提醒他们顺服执政者和掌权者，服从命令，预备好行各样善事，</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:31; 提摩太后书 2:24–25; 以弗所书 4:2"> 不毁谤任何人，不争吵，要温和，向众人显出完全的谦卑。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 2:1–3; 罗马书 6:17; 歌罗西书 1:21"> 因为我们从前也是愚昧、悖逆、受迷惑，服侍各样的私欲和享乐，活在恶毒和嫉妒中，可恨，又彼此相恨。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:4–10; 提多书 2:10–11; 提摩太前书 4:10"> 但当我们的救主上帝的恩慈和祂对人类的爱显明的时候，</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:8–9; 提摩太后书 1:9; 哥林多前书 6:11"> 祂拯救了我们，不是因我们自己所行的义行，而是照着祂的怜悯，借着重生的洗涤和圣灵的更新；</span>
<span className="v" id="v6" data-v="6" data-xref="约珥 2:28; 罗马书 5:5; 使徒行传 10:45"> 这圣灵是祂借着我们的救主耶稣基督丰富地浇灌在我们身上的；</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17; 提多书 2:11; 哥林多前书 6:11"> 好使我们因祂的恩典称义，可以照着永生的盼望成为后嗣。</span>
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 提多书 1:9; 诗篇 16:2–3"> 这话是可信的。关于这些事，我愿你坚定地强调，使那些已经信上帝的人留心致力于善行。这些事都是好的，并且对人有益；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 2:14; 提摩太后书 2:23; 提摩太前书 4:7"> 但要避开愚昧的争辩、家谱、纷争和关于律法的争执，因为这些都是无益而虚空的。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 16:17; 约翰二书 1:10; 马太福音 18:15–17"> 对于结党分派的人，警戒过一两次之后，就要避开他，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 10:26; 路加福音 19:22; 马太福音 25:26–28"> 因为知道这样的人已经偏离，正在犯罪，是自定己罪。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:9; 提摩太后书 4:12; 哥林多前书 16:8–9"> 我派亚提马或推基古到你那里去的时候，你要尽快到尼哥波立来见我，因为我已经决定在那里过冬。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:24; 马太福音 22:35; 约翰三书 1:6–8"> 你要赶快送精通律法的西纳和亚波罗上路，使他们没有缺乏。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:10; 提多书 3:8; 马太福音 7:19"> 我们的人也要学习致力于善行，以应付必要的需要，免得不结果子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 1:5; 以弗所书 6:23–24; 约翰二书 1:1–2"> 同我在一起的人都问候你。请问候那些在信心里爱我们的人。<br />愿恩典与你们众人同在。阿们。</span>
</div>

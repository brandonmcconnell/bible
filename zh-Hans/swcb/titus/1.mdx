<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 1:1; 提摩太前书 6:3; 提摩太后书 2:25"> 保罗，上帝的仆人、耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>的使徒，照着上帝选民的信心，以及那合乎敬虔的真理知识，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:19; 约翰一书 2:25; 提摩太后书 1:9"> 盼望永恒的生命；这生命是不能说谎的上帝在万古以前所应许的；</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:11; 提多书 3:4–6; 提摩太前书 1:1"> 到了祂自己的时候，就借着所传的信息显明了祂的话；这信息是我照着我们的救主上帝的命令受托付的，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 1:2; 犹大书 1:3; 彼得后书 1:1"> 写信给提多，就是照着共同的信心作我真孩子的：愿恩典、怜悯、平安从父上帝和我们的救主主耶稣基督临到你。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:23; 提摩太前书 1:3; 传道书 12:9"> 我把你留在克里特，是为了这个缘故：要你把那些未办妥的事整顿好，并且照我吩咐你的，在各城任命长老——</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 3:2–7; 提摩太前书 3:12; 提多书 1:6–8"> 若有人无可指责，只作一个妻子的丈夫，儿女有信心，没有被控放荡或不服管束，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:18; 彼得后书 2:10; 彼得前书 4:10"> 因为监督既是上帝的管家，就必须无可指责，不任性，不轻易发怒，不酗酒，不打人，不贪不义之财；</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 3:2; 提多书 2:7; 列王纪上 5:7"> 却要好客，喜爱良善，清醒自守，公正，圣洁，有节制，</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 2:15; 提摩太后书 1:13; 提摩太前书 6:3"> 坚守那合乎教导、可信靠的话语，好使他能用纯正的教义劝勉人，也能责服那些反对的人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 1:6; 约翰一书 4:1; 加拉太书 2:4"> 因为也有许多人不服管束，说虚空的话，欺骗人，尤其是那些奉割礼的人；</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 3:6; 提摩太前书 6:5; 罗马书 3:19"> 这些人的口必须被堵住。他们为了不义之财，教导不该教导的事，败坏整家的人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 16:18; 提摩太前书 4:2; 使徒行传 17:28"> 他们自己的一位先知说：“克里特人常是说谎者，是恶兽，又懒又贪吃。”</span>
<span className="v" id="v13" data-v="13" data-xref="提多书 2:2; 提摩太前书 5:20; 提多书 2:15"> 这个见证是真的。为这缘故，你要严厉地责备他们，使他们在信心上纯正，</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:4; 歌罗西书 2:22; 加拉太书 4:9"> 不去理会犹太人的荒诞传说和那些背离真理之人的诫命。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:14; 罗马书 14:20; 哥林多前书 10:23"> 对洁净的人，凡物都是洁净的；但对污秽而不信的人，什么都不洁净；连他们的心思和良心也都污秽了。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 2:4; 以赛亚书 29:13; 以弗所书 5:6"> 他们宣称自己认识上帝，却用行为否认祂；他们是可憎的、悖逆的，对任何善工都不合用。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 传道书 8:15; 雅各书 5:5"> 我心里说：“来吧，我要用欢笑试验你；所以你要享受快乐。”看哪，这也是虚空。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 传道书 7:2–6; 彼得前书 4:2–4"> 我论笑声说：“这是愚妄”；论欢笑说：“这有什么成就呢？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 传道书 1:17; 箴言 31:4–5"> 我心里寻索，怎样用酒使我的身体畅快，而我的心仍用智慧引导我；又怎样抓住愚昧，直到我看明世人一生在天下该做什么才是好的。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 7:1–12; 历代志下 8:11; 历代志下 26:10"> 我为自己兴建大工程。我为自己建造房屋，栽种葡萄园。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米书 39:4"> 我为自己建造园囿和花园，又在其中栽种各样果树。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 2:14; 诗篇 1:3; 耶利米书 17:8"> 我为自己开凿水池，用来浇灌长满树木的林园。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:4; 创世记 15:3; 列王纪上 4:23"> 我买了仆人和婢女，也有生在我家中的仆人。我又拥有许多牛群羊群，超过所有在我以前住在耶路撒冷的人。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 10:10; 列王纪上 9:28; 撒母耳记下 19:35"> 我又为自己积聚金银，以及列王和各省的财宝。我为自己得了男歌手和女歌手，以及世人所喜爱的：各样乐器。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 29:25; 传道书 1:16; 列王纪上 10:23"> 于是我昌盛起来，超过所有在我以前住在耶路撒冷的人。我的智慧也仍然与我同在。</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 9:9; 传道书 5:18; 传道书 3:22"> 凡我眼睛所想要的，我没有一样不给它们；凡我心所喜乐的，我没有一样不享受；因为我的心因我一切劳碌而喜乐，这就是我从一切劳碌中所得的分。</span>
<span className="v" id="v11" data-v="11" data-xref="传道书 1:14; 约翰一书 2:16–17; 传道书 1:3"> 后来，我察看我双手所做的一切工，以及我劳碌所成就的辛劳；看哪，全是虚空，是捕风，在日光之下毫无益处。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="传道书 1:17; 传道书 7:25; 传道书 1:9–10"> 我转而考察智慧、狂妄和愚昧；因为继承王位的人还能做什么呢？不过是做早已做过的事。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 传道书 7:11–12; 马太福音 6:23"> 于是我看出智慧胜过愚昧，正如光明胜过黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 49:10; 箴言 17:24; 传道书 9:11"> 智慧人的眼睛在他头上，愚昧人却在黑暗中行走——然而我也明白，同一遭遇临到他们众人。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 6:8; 传道书 1:14; 传道书 1:2"> 我心里说：“愚昧人所遭遇的，我也照样会遭遇；那我为什么更有智慧呢？”我心里又说，这也是虚空。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 1:11; 传道书 9:5; 诗篇 88:12"> 因为智慧人和愚昧人一样，都不能永远被记念；在将来的日子，一切早已被遗忘。确实，智慧人也必须像愚昧人一样死去！</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="传道书 2:11; 约拿 4:8; 传道书 4:2"> 所以我恨恶生命，因为在日光之下所做的工使我愁烦；因为一切都是虚空，是捕风。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 39:6; 诗篇 49:10; 路加福音 16:27–28"> 我恨恶我在日光之下所劳碌的一切劳碌，因为我必须把它留给我以后来的人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 3:17; 传道书 3:22; 传道书 9:13"> 谁知道他是智慧人还是愚昧人呢？然而他必掌管我在日光之下劳碌、并显出自己有智慧所得的一切劳碌。这也是虚空。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 43:14; 约伯记 17:11–15; 哥林多后书 1:8–10"> 因此，我开始使我的心对我在日光之下所劳碌的一切劳碌感到绝望。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 2:17–18; 历代志下 31:20–21; 历代志下 34:2"> 因为有人以智慧、知识和技能劳碌；然而他所得的分却要留给一个没有为此劳碌的人。这也是虚空，是大祸患。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 127:2; 传道书 1:3; 腓立比书 4:6"> 人在日光之下劳碌所得的一切劳碌，以及他心中的竭力，究竟有什么呢？</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 14:1; 约伯记 5:7; 诗篇 6:6–7"> 因为他一生的日子都是痛苦，他的劳苦都是忧伤；即使在夜间，他的心也不得安息。这也是虚空。</span>
<span className="v" id="v24" data-v="24" data-xref="传道书 3:22; 传道书 8:15; 提摩太前书 6:17"> 人莫如吃喝，并使自己的灵魂在劳碌中享福。我看出，这也是出于上帝的手。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 2:1–12; 列王纪上 4:21–24"> 因为谁能比我更能吃，谁能比我更能享受呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 约伯记 27:16–17; 箴言 28:8"> 因为上帝赐智慧、知识和喜乐给蒙祂喜悦的人；却赐辛劳给罪人，使他收聚、堆积，好把所得给蒙上帝喜悦的人。这也是虚空，是捕风。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 12:8–10; 传道书 1:12; 传道书 7:27"> 在耶路撒冷作王、大卫的儿子传道者的话：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="诗篇 144:4; 罗马书 8:20; 传道书 5:10"> 传道者说：“虚空的虚空，虚空的虚空，一切都是虚空。”</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 3:9; 传道书 5:16; 传道书 2:22"> 人在日光之下劳碌的一切劳碌，有什么益处呢？</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 104:5; 撒迦利亚书 1:5; 传道书 6:12"> 一代过去，一代又来；地却永远长存。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 19:4–6; 哈巴谷 3:11; 诗篇 42:1"> 太阳升起，太阳落下，又赶往它升起的地方。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:8; 传道书 11:5; 诗篇 107:25"> 风往南吹，又转向北；它不断旋转而行，风又返回它的循环。</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 38:10–11; 诗篇 104:6–9"> 所有江河都流入海，海却不满；江河流向何处，仍然再流向何处。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 27:20; 马太福音 11:28; 传道书 4:8"> 万事都充满疲乏，难以言说。眼看，看不满足；耳听，听不充满。</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 3:15; 传道书 6:10; 传道书 2:12"> 已有的事，还要再有；已做的事，还要再做；日光之下并无新事。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:51; 路加福音 17:26–30; 马太福音 23:30–32"> 岂有一件事可以说：“看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”源自“הִנֵּה”，意思是看、注意、观察、观看或凝视。它常用作感叹词。">a</a></sup>这是新的”吗？它早已存在，在我们以前的世代就有了。</span>
<span className="v" id="v11" data-v="11" data-xref="传道书 2:16; 诗篇 9:6; 传道书 9:5"> 先前的事无人记念；将来要有的事，后来的人也不会记念。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="传道书 1:1; 列王纪上 4:1–19"> 我，传道者，曾在耶路撒冷作以色列的王。</span>
<span className="v" id="v13" data-v="13" data-xref="传道书 3:10; 创世记 3:19; 提摩太前书 4:15"> 我专心用智慧寻求、查究天下所做的一切事。这是上帝<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译为“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>给世人的沉重担子，使他们在其中受苦。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 2:11; 传道书 2:17; 传道书 2:26"> 我看见日光之下所做的一切事；看哪，一切都是虚空，都是捕风。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 7:12–13; 以赛亚书 40:4; 传道书 3:14"> 弯曲的不能变直；缺少的不能计数。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 2:9; 列王纪上 4:30; 列王纪上 10:7"> 我心里说：“看哪，我为自己取得大智慧，胜过所有在我以前在耶路撒冷的人。是的，我的心多多经历了智慧和知识。”</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 2:3; 帖撒罗尼迦前书 5:21; 传道书 1:13–14"> 我专心要认识智慧，也要认识疯狂和愚昧。我察觉这也是捕风。</span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 28:28; 传道书 12:12–13; 哥林多前书 3:18–20"> 因为智慧多，愁烦也多；加增知识的，也加增忧伤。</span>
</div>
</div>

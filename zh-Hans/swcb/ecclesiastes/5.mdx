<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:19; 希伯来书 12:28–29; 箴言 15:8"> 你到上帝的殿去时，要谨慎你的脚步；近前聆听，胜过献愚昧人的祭，因为他们不知道自己是在作恶。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:7; 箴言 10:19; 以赛亚书 55:9"> 不要用口冒失发言，也不要让你的心在上帝面前急于说什么；因为上帝在天上，你在地上。所以，你的话要少。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 传道书 10:12–14"> 事务繁多就生梦；言语众多就显出愚昧人的声音。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 30:2; 申命记 23:21–23; 诗篇 76:11"> 你向上帝许愿，偿还不可迟延；因为祂不喜悦愚昧人。你所许的愿，要偿还。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:4; 申命记 23:22; 箴言 20:25"> 你不许愿，胜过许愿而不偿还。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:26; 约翰二书 1:8; 雅各书 3:2"> 不要让你的口使你陷入罪中。不要在使者面前辩称这是失误。为什么要让上帝因你的声音发怒，毁坏你手所做的工呢？</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:13; 马太福音 12:36; 传道书 8:12"> 因为梦多有虚空，话多也是如此；但你必须敬畏上帝。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 12:5; 传道书 4:1; 传道书 3:16"> 你若在一个地区看见穷人受欺压，公正和公义被强夺，不要因这事惊奇；因为有高过官员的在监察，在他们以上还有更高的官员。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:7–23; 诗篇 115:16; 创世记 1:29–30"> 而且，土地的益处是为众人的；君王也靠田地得益。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:10; 马太福音 6:24; 路加福音 12:15"> 喜爱银子的，不会因银子满足；喜爱丰裕的，也不会因增益满足。这也是虚空。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:16; 哈巴谷 2:13; 诗篇 119:36–37"> 财物增多，吃用的人也增多；物主除了用眼睛饱看以外，还有什么益处呢？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 诗篇 4:8; 耶利米书 31:26"> 劳碌人的睡眠香甜，无论他吃得少或多；富人的丰裕却不容他睡觉。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="传道书 6:1–2; 路加福音 18:22–23; 创世记 19:14"> 我在日光之下看见一件严重的祸患：财富由主人保守，反而害了自己。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 6:19–20; 哈该书 2:16–17; 箴言 23:5"> 那些财富因灾祸灭失；若他生了儿子，他手中也一无所有。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 49:17; 约伯记 1:21; 提摩太前书 6:7"> 他怎样从母腹赤身而出，也必照样赤身而去；他劳碌所得的，手中一样也不能带走。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 传道书 1:3; 约翰福音 6:27"> 这也是一件严重的祸患：他怎样来，也照样去。他为风劳碌，有什么益处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 127:2; 以西结 4:16–17; 诗篇 90:7–11"> 他终日也在黑暗中吃喝，满有烦恼、疾病和愤怒。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="传道书 2:24; 传道书 3:12–13; 传道书 3:22"> 看哪，我所看为美善合宜的是：人在上帝所赐的一生中，在日光之下，在他一切劳碌中吃喝，并享受美好；因为这是他的份。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 8:18; 传道书 3:13; 传道书 6:2"> 凡上帝赐给他资财和财富，并赐他能力可以享用、取得自己的份、在劳碌中喜乐的人——这就是上帝的恩赐。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:21–24; 以赛亚书 65:13–14; 诗篇 37:16"> 因为他不常思念自己一生的日子，因为上帝使他专注于心中的喜乐。</span>
</div>

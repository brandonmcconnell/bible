<span className="v" id="v1" data-v="1" data-xref="传道书 3:17; 马太福音 16:3; 传道书 8:5–6"> 凡事都有时节，天底下每一件事都有定时：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 9:27; 约伯记 14:5; 马太福音 15:13"> <span className="pl pl-1">有出生的时候，</span><br /><span className="pl pl-2">也有死亡的时候；</span><br /><span className="pl pl-1">有栽种的时候，</span><br /><span className="pl pl-2">也有拔出所栽种之物的时候；</span></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 6:1–2; 撒母耳记上 2:6; 耶利米书 45:4"> <span className="pl pl-1">有杀戮的时候，</span><br /><span className="pl pl-2">也有医治的时候；</span><br /><span className="pl pl-1">有拆毁的时候，</span><br /><span className="pl pl-2">也有建造的时候；</span></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 12:15; 诗篇 30:5; 雅各书 4:9"> <span className="pl pl-1">有哭泣的时候，</span><br /><span className="pl pl-2">也有欢笑的时候；</span><br /><span className="pl pl-1">有哀恸的时候，</span><br /><span className="pl pl-2">也有跳舞的时候；</span></span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 3:25; 约书亚记 10:27; 约书亚记 4:3–9"> <span className="pl pl-1">有抛弃石头的时候，</span><br /><span className="pl pl-2">也有聚集石头的时候；</span><br /><span className="pl pl-1">有拥抱的时候，</span><br /><span className="pl pl-2">也有避免拥抱的时候；</span></span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 3:7–8; 路加福音 9:24–25; 马可福音 8:35–37"> <span className="pl pl-1">有寻找的时候，</span><br /><span className="pl pl-2">也有失落的时候；</span><br /><span className="pl pl-1">有保存的时候，</span><br /><span className="pl pl-2">也有丢弃的时候；</span></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司 5:13; 弥迦书 7:5; 耶利米哀歌 3:28"> <span className="pl pl-1">有撕裂的时候，</span><br /><span className="pl pl-2">也有缝补的时候；</span><br /><span className="pl pl-1">有沉默的时候，</span><br /><span className="pl pl-2">也有说话的时候；</span></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:25; 以弗所书 5:28–29; 路加福音 14:26"> <span className="pl pl-1">有爱的时候，</span><br /><span className="pl pl-2">也有恨的时候；</span><br /><span className="pl pl-1">有战争的时候，</span><br /><span className="pl pl-2">也有和平的时候。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="传道书 1:3; 传道书 5:16; 箴言 14:23"> 做工的人在自己劳碌的事上有什么益处呢？</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 1:13–14; 创世记 3:19; 传道书 2:26"> 我见上帝把重担给世人，使他们为此劳苦。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 11:33; 罗马书 1:19–20; 约伯记 11:7"> 祂使万物各按其时成为美好；祂又把永恒放在人的心里。然而，人不能测透上帝从起初到末了所做的工。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 37:3; 传道书 3:22; 提摩太前书 6:18"> 我知道，对他们来说，没有什么比一生喜乐、行善更好。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 128:2; 传道书 9:7; 传道书 2:24"> 并且人人都应当吃喝，在自己一切劳碌中享福；这是上帝的恩赐。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 诗篇 33:11; 罗马书 11:36"> 我知道，上帝所做的一切都必永存；无可增添，也无可减少。上帝这样做，是要人们在祂面前敬畏。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 1:9–10; 传道书 6:10"> 现有的，早已存在；将有的，也早已存在。上帝又寻回那已经过去的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="传道书 4:1; 传道书 5:8; 诗篇 94:21–22"> 此外，我在日光之下又见：在公正之处有邪恶；在公义之处也有邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 5:10; 传道书 12:14; 马太福音 16:27"> 我心里说：“上帝必审判义人和恶人，因为在那里，每一件事、每一项行为都有定时。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 73:22; 诗篇 49:12; 希伯来书 9:27"> 我心里说：“至于世人，上帝试验他们，为要使他们看明自己就像动物一样。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 49:12; 诗篇 49:20; 诗篇 89:47–48"> 因为世人所遭遇的，动物也遭遇；同一件事临到他们。这个怎样死，那个也怎样死。是的，他们都有同一个气息；人并不胜过动物，因为一切都是虚空。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:19; 约伯记 34:15; 传道书 12:7"> 都归于一处；都出于尘土，也都归回尘土。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 12:7; 约翰福音 14:3; 哥林多后书 5:1"> 谁知道人的灵是否上升，动物的灵是否下到地里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="传道书 2:24; 传道书 3:11–12; 传道书 10:14"> 因此我见：人没有什么比在自己的工作中喜乐更好，因为这是他的份；谁能带他去看他以后将发生的事呢？</span>
</div>

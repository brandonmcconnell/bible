<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="传道书 5:13; 传道书 4:7; 传道书 9:3"> 我见日光之下有一件祸患，好像是出于掌权者的错误：</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 28:12; 箴言 29:2; 以斯帖记 3:1"> 愚昧被安置在极尊贵的地位，富人却坐在卑微之处。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 19:10; 以斯帖记 6:8; 箴言 30:22"> 我见过仆人骑马，王子却像仆人一样在地上行走。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:27; 诗篇 7:15–16; 以斯帖记 7:10"> 挖坑的，可能掉在坑里；拆墙的，可能被蛇咬。</span>
<span className="v" id="v9" data-v="9"> 凿石的，可能被石头所伤；劈木的，可能因木头而遇险。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:5; 歌罗西书 4:5; 传道书 10:15"> 斧头若钝了，人不磨利斧刃，就必须多用力气；但技巧能带来成功。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:17; 诗篇 58:4–5; 诗篇 64:3"> 蛇若在被施咒制伏之前咬人，那么施咒者的舌头就毫无益处。</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 4:6; 路加福音 4:22; 箴言 22:11"> 智慧人口中的话带着恩惠，愚昧人却被自己的嘴唇吞灭。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 25:10–11; 箴言 29:9; 使徒行传 6:9–11"> 他口中言语的开端是愚昧；他谈话的结尾是邪恶的狂妄。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 15:2; 传道书 6:12; 传道书 5:3"> 愚昧人还多说话。<br />人不知道将来会怎样；在他以后要发生的事，谁能告诉他呢？</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 50:4–5; 以赛亚书 57:1; 以赛亚书 35:8–10"> 愚昧人的劳碌使他们人人疲乏；因为他连怎样进城都不知道。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 3:12; 以赛亚书 5:11–12; 以赛亚书 3:4–5"> <span className="pl pl-1">土地啊，你的王若是孩童，</span><br /><span className="pl pl-2">你的首领若在早晨宴乐，你就有祸了！</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 31:4–5; 箴言 28:2–3; 以赛亚书 5:11"> <span className="pl pl-1">土地啊，你的王若是贵族之子，</span><br /><span className="pl pl-2">你的首领若按时进食，</span><br /><span className="pl pl-2">是为得力，不是为醉酒，你就有福了！</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:1; 箴言 24:30–34; 箴言 20:4"> <span className="pl pl-1">因懒惰，屋顶塌陷；</span><br /><span className="pl pl-2">因双手闲懒，房屋漏雨。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:15; 传道书 2:1–2; 彼得前书 4:3"> <span className="pl pl-1">筵席是为欢笑而设，</span><br /><span className="pl pl-2">酒能使生命欢畅；</span><br /><span className="pl pl-2">钱能应付万事。</span></span>

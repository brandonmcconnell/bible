<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 33:3; 约翰福音 10:27–30; 彼得前书 1:5"> 我把这一切都放在心上，甚至要查明这一切：义人、智慧人和他们的作为，都在上帝手中；无论是爱是恨，人都不知道；一切都在他们前面。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:18; 传道书 2:14–16; 玛拉基书 3:5"> 万事临到众人都是一样的。义人和恶人遭遇同一个结局；好人、洁净的人、不洁净的人，献祭的人和不献祭的人，也都一样。好人怎样，罪人也怎样；起誓的人怎样，惧怕起誓的人也怎样。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 17:9; 传道书 8:11; 传道书 1:17"> 在日光之下所做的一切事中，有一件祸患，就是众人遭遇同一个结局。并且世人的心充满邪恶；他们活着的时候，心里有狂妄，之后就归到死人那里。</span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 14:7–12; 以赛亚书 38:18; 路加福音 16:26–29"> 凡与一切活人相连的，就有希望；因为活着的狗胜过死了的狮子。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 26:14; 传道书 1:11; 诗篇 6:5"> 活着的人知道自己必死；死人却什么都不知道，也不再有赏报，因为他们的记忆被遗忘了。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 146:3–4; 传道书 6:12; 约伯记 3:17–18"> 他们的爱、他们的恨、他们的嫉妒，早已消灭；在日光之下所做的一切事上，他们永远不再有份。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="传道书 3:12–13; 申命记 12:7; 传道书 10:19"> 你只管去，欢欢喜喜吃你的饼，心中快乐喝你的酒；因为上帝已经悦纳你的作为。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 19:14; 启示录 3:4–5; 启示录 19:8"> 你的衣服要常常洁白，你头上也不要缺少膏油。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 5:18–19; 传道书 2:10; 玛拉基书 2:15"> 在你虚空的一生中，就是祂在日光之下赐给你的虚空岁月中，要与你所爱的妻子快乐度日；因为这是你在生命中，在日光之下劳碌所得的份。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 3:23; 以弗所书 5:16; 罗马书 12:11"> 凡你的手所找到要做的事，都要尽力去做；因为在你将要去的阴间，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>没有工作，没有计划，没有知识，也没有智慧。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 9:23; 箴言 21:30–31; 耶利米哀歌 3:37–38"> 我又转念，看见日光之下：赛跑不一定归给快跑的人，战争不一定归给强壮的人，粮食不一定归给智慧人，财富不一定归给聪明人，恩宠也不一定归给有才能的人；因为时间和际遇临到他们众人。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:3; 路加福音 21:34–36; 传道书 8:5–7"> 人也不知道自己的时候。鱼被恶网捕住，鸟被网罗捉住，世人也照样在祸患的时候陷入网罗；这祸患忽然临到他们身上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="传道书 8:16; 传道书 7:15; 传道书 6:1"> 我也在日光之下看见这样的智慧，我看为重大。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 20:15–22; 列王纪下 6:24–20"> 有一座小城，城里的人很少；有一位大王来攻击它，围困它，又筑起高大的攻城工事来攻击它。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 4:13; 创世记 40:23; 以斯帖记 6:2–3"> 城中有一个贫穷的智慧人，他用自己的智慧拯救了那城；可是没有人记念那个贫穷人。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 7:19; 箴言 24:5; 箴言 21:22"> 于是我说：“智慧胜过力量。”然而贫穷人的智慧被藐视，他的话也无人听从。</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 3:17–18; 箴言 28:23; 雅各书 1:20"> 智慧人的话在安静中被听见，胜过在愚昧人中掌权者的喊叫。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 7:11–12; 传道书 9:16; 约书亚记 7:5"> 智慧胜过打仗的兵器；但一个罪人能败坏许多美善。</span>
</div>
</div>

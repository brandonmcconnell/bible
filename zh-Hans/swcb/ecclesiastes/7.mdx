<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="ECC" data-book-slug="ecclesiastes" data-book-name="传道书" data-chapter="7" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 14:13; 箴言 22:1; 传道书 4:2"> 美名胜过珍贵的香膏；死的日子胜过出生的日子。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 90:12; 申命记 32:29; 希伯来书 9:27"> 往哀悼之家去，胜过往宴乐之家去；因为这是所有人的结局，活着的人应当把这事放在心上。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:9–11; 罗马书 5:3–4; 雅各书 4:8–10"> 忧愁胜过喜笑；因为脸上的愁容能使心变好。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 8:14–16; 撒母耳记上 25:36; 路加福音 7:12–13"> 智慧人的心在哀悼之家；愚昧人的心在欢乐之家。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 诗篇 141:5; 启示录 3:19"> 听智慧人的责备，胜过听愚昧人的歌声。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 58:9; 诗篇 118:12; 传道书 2:2"> 愚昧人的笑声，好像锅底下荆棘的爆响。这也是虚空。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 16:19; 出埃及记 23:8; 箴言 17:23"> 勒索确实使智慧人变为愚妄；贿赂败坏人的悟性。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:36; 箴言 14:29; 诗篇 126:5–6"> 一件事的结局胜过它的开端。<br />存心忍耐的，胜过心里骄傲的。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:19; 箴言 14:17; 以弗所书 4:26–27"> 你心里不要急躁发怒，因为怒气停留在愚昧人的怀中。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 6:13; 诗篇 14:2–3; 创世记 6:11–12"> 不要说：“为什么从前的日子比现在好呢？”因为你这样问并不是出于智慧。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="传道书 11:7; 提摩太前书 6:17–19; 传道书 2:13"> 智慧和产业一样美好；对见日光的人更有益处。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 8:35; 箴言 2:7; 箴言 3:18"> 因为智慧作庇护，金钱也作庇护；但知识的优越之处在于：智慧能保全拥有它之人的生命。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="传道书 1:15; 约伯记 12:14; 诗篇 107:43"> 你要察看上帝的作为，因为祂所弯曲的，谁能弄直呢？</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 3:4; 传道书 3:22; 传道书 12:13"> 亨通的日子要喜乐；遭患难的日子要思想。上帝使这两样并列，为要使人不能查出自己以后会怎样。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="传道书 8:12–14; 传道书 6:12; 诗篇 73:3–13"> 在我虚空的日子里，这一切我都见过：有义人在自己的义中灭亡，也有恶人在自己的恶行中长寿。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 箴言 25:16; 歌罗西书 2:18"> 不要过分公义，也不要使自己过分有智慧。你何必毁灭自己呢？</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:27; 诗篇 55:23; 约伯记 22:16"> 不要过分邪恶，也不要愚昧。你何必未到时候就死呢？</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 12:13; 玛拉基书 4:2; 传道书 11:6"> 你抓住这个是好的；也不要从那个缩回你的手，因为敬畏上帝的人必脱离这一切。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:22; 歌罗西书 1:9–11; 箴言 24:5"> 智慧使智慧人有力量，胜过城中十个掌权者。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 3:23; 以赛亚书 53:6; 约翰一书 1:8–10"> 世上确实没有一个义人只行善而不犯罪。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 30:10; 以赛亚书 29:21; 撒母耳记下 16:10"> 你也不要把人所说的一切话都放在心上，免得听见你的仆人咒骂你；</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 3:9; 马太福音 18:32–35; 约翰福音 8:7–9"> 因为你自己的心知道，你自己也曾多次同样咒骂别人。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 1:22; 创世记 3:5; 哥林多前书 1:20"> 这一切我都用智慧试验过。我说：“我要有智慧”；智慧却离我很远。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:33; 提摩太前书 6:16; 以赛亚书 55:8–9"> 现有的事离人遥远，又极其深奥。谁能查明呢？</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 10:13; 约书亚记 7:13; 传道书 2:20"> 我转而专心要认识、考察、寻求智慧和事物的道理，并要知道邪恶是愚蠢，愚昧是疯狂。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 22:14; 箴言 5:3–5; 箴言 2:18–19"> 我发现有一种女人比死更苦：她的心是网罗和陷阱，她的手是锁链。讨上帝喜悦的人必逃脱她；犯罪的人却要被她缠住。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="传道书 12:8–10; 传道书 1:1–2"> “看哪，我发现了这个，”传道者说，“我一件接着一件考察，为要找到解释，</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 33:23; 列王纪上 11:1–3; 诗篇 12:1"> 这是我心仍在寻求、却没有找到的。我在一千个男子中找到一个，却在所有这些人中没有找到一个女子。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 4:22; 马可福音 7:8–9; 提多书 3:3"> 看哪，我只发现这一件事：上帝造人原是正直的；他们却寻求许多巧计。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 18:8–11; 利未记 16:2; 出埃及记 20:21"> 那时所罗门说：“耶和华曾说，祂要住在幽暗之中。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:4–6; 诗篇 135:21; 历代志上 28:6"> 但我已经为你建造了宏伟的殿宇，作你永远居住的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:14; 历代志下 29:29; 列王纪上 8:55–61"> 王转过脸来，为以色列全会众祝福；以色列全会众都站着。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 72:18–19; 马太福音 24:35; 诗篇 68:32–35"> 他说：“耶和华以色列的上帝是应当称颂的！祂亲口对我父亲大卫说话，也亲手成就，说：</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:24; 列王纪上 8:16; 撒母耳记上 13:13–14"> ‘自从我把我的百姓从埃及地领出来那日以来，我没有从以色列众支派中选择一座城，建造殿宇，使我的名在那里；也没有选择一个人作我百姓以色列的君王。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 28:4; 诗篇 132:13; 历代志下 12:13"> 但现在我选择耶路撒冷，使我的名在那里；我也选择大卫治理我的百姓以色列。’</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:1; 列王纪上 5:3; 历代志上 22:7"> 我父亲大卫心中有意，要为耶和华以色列上帝的名建造殿宇。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 马可福音 14:8; 列王纪上 8:18–21"> 但耶和华对我父亲大卫说：‘你心中有意为我的名建造殿宇；你心中有这意念，是好的。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 7:12–13; 历代志上 17:4; 历代志上 17:11–12"> 然而，你不可建造这殿；惟有你亲生的儿子，他要为我的名建造这殿。’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="传道书 1:4; 历代志上 28:5; 历代志上 17:11"> “如今耶和华成就了祂所说的话；我已经起来接替我父亲大卫，坐在以色列的王位上，正如耶和华所应许的，并且已经为耶和华以色列上帝的名建造了殿宇。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 5:10; 历代志下 5:7; 列王纪上 8:21"> 我把约柜安放在那里；柜中有耶和华的约，就是祂与以色列子孙所立的约。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 63:4; 以赛亚书 50:10; 约伯记 11:13"> 所罗门站在耶和华的坛前，在以色列全会众面前，张开双手。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:54; 尼希米记 8:4; 诗篇 95:6"> 原来所罗门造了一个铜台，长五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘约为四十六厘米。">a</a></sup>，宽五肘，高三肘，放在院子中央；他站在台上，在以色列全会众面前跪下，向天张开双手。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:11; 申命记 7:9; 尼希米记 1:5"> 他说：“耶和华以色列的上帝啊，天上地下没有神像你；你向那些全心行在你面前的仆人守约施慈爱。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 撒母耳记下 7:12; 列王纪上 8:24"> 你向你仆人我父亲大卫所应许的，已经为他持守；你亲口说出，也亲手成就，正如今日一样。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:4; 约翰福音 15:14–15; 历代志下 7:18"> “现在，耶和华以色列的上帝啊，求你向你仆人我父亲大卫守住所应许他的话，说：‘只要你的子孙谨慎自己的道路，照你在我面前所行的那样遵行我的律法，你在我面前就必不断有人坐在以色列的王位上。’</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 11:5; 以赛亚书 41:17; 历代志下 6:4"> 现在，耶和华以色列的上帝啊，求你使你对你仆人大卫所说的话得以证实。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 2:6; 以赛亚书 66:1; 诗篇 139:7–10"> “然而，上帝真的会与人在地上同住吗？看哪，天和天上的天尚且容不下你，何况我所建造的这殿呢？</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 8:28; 路加福音 18:1–7; 约翰福音 17:20"> 但耶和华我的上帝啊，求你垂顾你仆人的祷告和恳求，垂听你仆人在你面前所发的呼求和祷告；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 34:15; 但以理 6:10; 诗篇 121:5"> 愿你的眼昼夜看顾这殿，就是你曾说要立你名的地方；愿你垂听你仆人向这地方所献的祷告。</span>
<span className="v" id="v21" data-v="21" data-xref="弥迦书 7:18; 但以理 9:19; 以赛亚书 43:25"> 你的仆人和你的百姓以色列向这地方祷告的时候，求你垂听他们的恳求。求你从你的居所，就是从天上垂听；你听见的时候，求你赦免。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 22:11; 利未记 5:1; 民数记 5:19–22"> “若有人得罪邻舍，有人叫他起誓，他来到这殿中，在你的坛前起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 3:10–11; 箴言 17:15; 耶利米书 51:56"> 求你从天上垂听并施行审判，判断你的仆人：定恶人有罪，使他的行径归到自己头上；称义人为义，照他的义赏赐他。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 26:17; 列王纪下 17:7–18; 约书亚记 7:8"> “若你的百姓以色列因得罪你而败在仇敌面前，后来又转回，承认你的名，在这殿中向你祷告恳求，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 33:6–13; 以斯拉记 1:1–6; 创世记 13:15"> 求你从天上垂听，赦免你百姓以色列的罪，使他们归回你赐给他们和他们列祖的地。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 28:23; 申命记 11:17; 利未记 26:19"> “若因他们得罪你，天闭塞不下雨；他们若向这地方祷告，承认你的名，并因你使他们受苦而离开自己的罪，</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 8:35–36; 耶利米书 5:24; 撒迦利亚书 10:1"> 求你从天上垂听，赦免你的仆人、你的百姓以色列的罪；你既指教他们当行的善道，也求你降雨在你的地上，就是你赐给你百姓为产业之地。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 9:3–11; 约珥 2:25; 路得记 1:1"> “若地上有饥荒，若有瘟疫，若有枯萎病或霉烂病，若有蝗虫或蚂蚱，若他们的仇敌在他们本地城邑围困他们；无论有什么灾祸，什么疾病，</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 50:15; 诗篇 32:2–6; 历代志下 6:12–13"> 你的百姓以色列，或一人或众人，各人知道自己的灾祸和痛苦，向这殿张开双手，无论献上什么祷告、什么恳求，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 28:9; 撒母耳记上 16:7; 启示录 2:23"> 求你从天上你的居所垂听并赦免，照各人一切所行的报应他；因为你知道他的心，惟有你知道世人的心。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:31; 约伯记 28:28; 诗篇 128:1"> 这样，他们在你赐给我们列祖的地上，一生一世都敬畏你，行你的道路。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 56:3–7; 列王纪上 8:41–43; 马太福音 8:10–11"> “至于不属你百姓以色列的外族人，为了你的大名、大能的手和伸出来的膀臂，从远方而来，来到这里向这殿祷告，</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 7:14; 列王纪上 8:16; 启示录 11:15"> 求你从天上你的居所垂听，照外族人向你所呼求的一切为他成就，使地上万民都认识你的名，敬畏你，像你的百姓以色列一样；又使他们知道我所建造的这殿是称为你名下的。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="历代志下 20:6–13; 历代志下 18:31; 历代志下 20:4"> “你的百姓若奉你的差遣，无论往哪条路出去与仇敌争战，向你所选择的这城，以及我为你名所建造的殿祷告，</span>
<span className="v" id="v35" data-v="35" data-xref="但以理 9:17–19; 诗篇 9:3–4; 耶利米书 5:28"> 求你从天上垂听他们的祷告和恳求，为他们伸冤。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="传道书 7:20; 雅各书 3:2; 约翰一书 1:8–10"> “他们若得罪你——因为世上没有不犯罪的人——你向他们发怒，把他们交给仇敌，使他们被掳到远方或近处的地去；</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 31:18–20; 但以理 9:5–11; 以赛亚书 64:6–12"> 他们若在被掳之地回心转意，在被掳之地转回，向你恳求说：‘我们犯了罪，行了悖逆，作了恶事’；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志下 33:11–13; 但以理 6:10; 但以理 9:3–4"> 他们若在被掳之地，就是他们被掳去的地方，全心全灵归向你，又向你赐给他们列祖的地、你所选择的城，以及我为你名所建造的殿祷告，</span>
<span className="v" id="v39" data-v="39" data-xref="弥迦书 7:18–20; 历代志下 6:35; 诗篇 25:18"> 求你从天上你的居所垂听他们的祷告和恳求，为他们伸冤，赦免得罪你的百姓。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志下 7:15; 诗篇 116:2; 尼希米记 1:6"> “我的上帝啊，现在求你睁眼观看，侧耳垂听在这地方所献的祷告。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 61:10; 历代志上 28:2; 诗篇 132:8–10"> “现在，耶和华上帝啊，求你起来，进入你安息之所，你和你有能力的约柜同入。耶和华上帝啊，愿你的祭司披戴救恩，愿你的圣民因良善欢喜快乐。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="以赛亚书 55:3; 诗篇 132:1; 以赛亚书 61:1"> “耶和华上帝啊，求你不要转脸不顾你的受膏者；求你记念你向你仆人大卫所施的慈爱。”</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 21:16–17; 列王纪下 8:24–29; 历代志下 36:1"> 耶路撒冷的居民立约兰最小的儿子亚哈谢接替他作王，因为同阿拉伯人进营的那队人杀了他所有年长的儿子。这样，犹大王约兰的儿子亚哈谢作了王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 16:28; 列王纪下 8:26; 历代志下 21:6"> 亚哈谢登基的时候四十二岁，在耶路撒冷作王一年。他母亲名叫亚他利雅，是暗利的孙女。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 27:12–13; 创世记 6:4–5; 士师记 17:4–5"> 他也行亚哈家的道路，因为他母亲教导他行恶。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 13:20; 历代志下 24:17–18; 箴言 19:27"> 他行耶和华眼中看为恶的事，像亚哈家一样；他父亲死后，他们作他的谋士，使他走向灭亡。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 8:28–29; 历代志下 19:2; 诗篇 1:1"> 他也听从他们的计谋，与以色列王亚哈的儿子约兰同去，在基列的拉末与亚兰王哈薛争战；亚兰人打伤了约兰。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 9:15; 列王纪下 8:29; 列王纪下 10:13–14"> 约兰回到耶斯列，要医治他在拉玛与亚兰王哈薛争战时所受的伤。犹大王约兰的儿子亚撒利雅下到耶斯列去探望亚哈的儿子约兰，因为他病了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 10:15; 列王纪下 9:21; 玛拉基书 4:3"> 亚哈谢去见约兰，这事出于上帝，使他败亡；因为他到了以后，就同约兰出去迎战宁示的儿子耶户；耶户是耶和华所膏，要剪除亚哈家的。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 10:10–14"> 耶户审判亚哈家的时候，遇见犹大的众首领和亚哈谢兄弟的众子，他们正服事亚哈谢，耶户就杀了他们。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 21:17; 列王纪下 9:27–28; 历代志下 21:20–1"> 耶户又寻找亚哈谢，众人在撒玛利亚抓住他；那时他正躲在那里。他们把他带到耶户那里，就杀了他；又埋葬他，因为他们说：“他是约沙法的孙子，约沙法曾全心寻求耶和华。”亚哈谢家没有能力保住国权。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪下 11:1–3; 历代志下 22:2–4"> 亚哈谢的母亲亚他利雅看见自己的儿子死了，就起来剿灭犹大家所有王室后裔。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 15:4; 列王纪下 11:2; 以赛亚书 65:8"> 但王的女儿约示巴把亚哈谢的儿子约阿施，从那些被杀的王子中偷偷救出来，把他和他的乳母安置在卧房里。约示巴是约兰王的女儿、祭司耶何耶大的妻子，也是亚哈谢的妹妹；她把约阿施藏起来，躲过亚他利雅，使她没有杀他。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 12:8; 诗篇 73:18–19; 耶利米书 12:1"> 亚他利雅治理那地的时候，约阿施与他们一同藏在上帝的殿里六年。</span>
</div>

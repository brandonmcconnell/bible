<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 15:12; 列王纪下 11:4–20; 尼希米记 9:38"> 第七年，耶何耶大奋勇自强，与百夫长立约；他们是耶罗罕的儿子亚撒利雅、约哈难的儿子以实玛利、俄备得的儿子亚撒利雅、亚大雅的儿子玛西雅，以及细基利的儿子以利沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:13–17; 历代志下 21:2; 历代志上 15:12"> 他们走遍犹大，从犹大各城召集利未人和以色列各父族的族长；他们都来到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 21:7; 撒母耳记下 7:12; 历代志下 6:16"> 全会众在上帝的殿里与王立约。耶何耶大<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯来文作“他”。">a</a></sup>对他们说：“看哪，王的儿子必须作王，正如耶和华论到大卫子孙所说的。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:3–6; 历代志上 26:13–16; 路加福音 1:8–9"> 你们要这样行：你们中间安息日进班的祭司和利未人，三分之一要作守门的；</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 46:2–3; 使徒行传 3:2; 列王纪下 11:5–6"> 三分之一要在王宫，三分之一要在基址门；众百姓都要在耶和华殿的院内。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 23:28–32; 列王纪下 11:6–7"> 除了祭司和供职的利未人以外，谁都不可进入耶和华的殿；他们可以进去，因为他们是圣的。众百姓都要遵守耶和华的吩咐。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 3:38; 民数记 3:10; 列王纪下 11:8–9"> 利未人要各人手拿兵器，围绕王；凡进入殿的，必须处死。王出入的时候，你们要与王同在。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 11:9; 历代志上 24:1–26"> 利未人和全犹大都照祭司耶何耶大所吩咐的一切去行。各人带着自己的部下，就是安息日进班的人和安息日出班的人；因为祭司耶何耶大没有解散班次。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 21:9; 撒母耳记下 8:7"> 祭司耶何耶大把上帝殿里大卫王的枪、小盾和盾牌交给百夫长。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:6; 历代志下 6:12; 列王纪下 11:11"> 他安排众百姓各人手拿兵器，从殿的右边到殿的左边，靠近祭坛和殿，四围围绕王。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 10:24; 出埃及记 25:16; 列王纪下 11:12"> 于是他们把王的儿子领出来，给他戴上冠冕，将律法书交给他，立他作王。耶何耶大和他的儿子们膏立他，众人说：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 11:13–16; 列王纪下 9:32–37"> 亚他利雅听见百姓奔跑、赞美王的声音，就来到耶和华的殿，到百姓那里。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:2; 历代志下 34:31; 列王纪下 9:23"> 她观看，看哪，王站在入口处自己的柱旁，百夫长和吹号的人在王旁边；本地众民都欢喜吹号，歌唱的人也奏乐器，带领众人歌唱赞美。亚他利雅就撕裂衣服，说：“反了！反了！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结 9:7; 列王纪下 11:8; 列王纪下 11:15"> 祭司耶何耶大带出统领军队的百夫长，对他们说：“把她从队列中带出去；凡跟随她的，必须用刀杀死。”因为祭司说：“不可在耶和华的殿里杀她。”</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 3:28; 耶利米书 31:40; 历代志下 22:10"> 于是众人为她让开路。她到了王宫马门入口那里，他们就在那里杀了她。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:10; 尼希米记 9:38; 列王纪下 11:17"> 耶何耶大使自己、众百姓和王之间立约，要作耶和华的子民。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:40; 列王纪下 10:25–28; 列王纪下 18:4"> 众百姓都到巴力庙，拆毁了它，打碎巴力的坛和偶像，又在坛前杀了巴力的祭司玛坦。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 5:5; 民数记 28:1–31; 历代志下 29:25"> 耶何耶大派定耶和华殿里的职分，交在利未祭司手下；这些利未祭司是大卫分派在耶和华殿中的，要照摩西律法上所写的，向耶和华献燔祭，并照大卫所定的，欢喜歌唱。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 26:1–32; 历代志上 9:22–24"> 他又在耶和华殿的各门设立守门人，使凡有任何不洁的人都不得进去。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:19; 列王纪下 15:35; 列王纪下 11:9–10"> 他率领百夫长、贵族、民间官长和本地众民，把王从耶和华的殿带下来；他们经由上门来到王宫，使王坐在国位上。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 11:20; 启示录 18:20; 启示录 19:1–4"> 本地众民都欢喜，城中也安静；众人已经用刀杀了亚他利雅。</span>
</div>

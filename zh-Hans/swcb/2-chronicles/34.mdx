<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 1:1; 耶利米书 1:2; 历代志下 33:25"> 约西亚登基的时候八岁，在耶路撒冷作王三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:2; 约书亚记 1:7; 列王纪下 22:2"> 他行耶和华眼中看为正的事，行他祖大卫的道路，不偏左右。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:22; 历代志下 15:2; 箴言 8:17"> 他作王第八年，还年轻的时候，就开始寻求他祖大卫的上帝；第十二年，他开始洁净犹大和耶路撒冷，除去邱坛、亚舍拉木柱、雕刻偶像和铸造偶像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 32:20; 利未记 26:30; 列王纪下 23:4–6"> 众人在他面前拆毁众巴力的祭坛；他砍下祭坛上面的香坛，又把亚舍拉木柱、雕刻偶像和铸造偶像打碎，磨成粉末，撒在那些曾向它们献祭之人的坟上。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:2; 耶利米书 3:10; 民数记 35:33"> 他把祭司的骸骨烧在他们的坛上，洁净了犹大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 13:20–21; 以赛亚书 7:25; 历代志下 30:1"> 他在玛拿西、以法莲、西缅各城，直到拿弗他利，以及周围荒废之处，也都这样行。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:1; 申命记 9:21; 历代志下 34:1"> 他拆毁祭坛，把亚舍拉木柱和雕刻偶像打成粉末，又砍下以色列全地所有香坛，然后回到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:16; 历代志上 18:15; 耶利米书 29:25"> 约西亚作王第十八年，洁净了那地和殿以后，差遣亚萨利雅的儿子沙番、城长玛西雅和约哈斯的儿子史官约亚，去修理耶和华他上帝的殿。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 30:18; 历代志下 30:10; 历代志下 35:8"> 他们来到大祭司希勒家那里，把带进上帝殿的银子交给他；这银子是看守门槛的利未人从玛拿西、以法莲、所有以色列余民、全犹大和便雅悯，以及耶路撒冷居民手中收来的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 12:11–12; 以斯拉记 3:7; 列王纪下 22:5–6"> 他们把银子交在督管耶和华殿工程的人手中；在耶和华殿里做工的人，就用这些银子修补整修殿宇。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 33:4–7; 历代志下 33:22"> 他们把银子给木匠和建筑工人，用来买凿成的石头、接合用的木料，又为犹大诸王所毁坏的房屋作梁木。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 12:15; 历代志上 23:5; 列王纪下 22:7"> 这些人忠心做工；督工的是米拉利子孙中的利未人雅哈和俄巴底亚，以及哥辖子孙中的撒迦利雅和米书兰，负责指导；还有其他利未人，都是精通乐器的人。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:10; 历代志下 2:18; 耶利米书 8:8"> 他们也管理搬运的人，并督导各种工作中做工的人。利未人中还有书记、官员和守门人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 8:36; 诗篇 1:2; 利未记 10:11"> 他们把带进耶和华殿的银子取出来的时候，祭司希勒家发现了耶和华借摩西所赐的律法书。</span>
<span className="v" id="v15" data-v="15"> 希勒家回应书记沙番说：“我在耶和华的殿里发现了律法书。”希勒家就把书交给沙番。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 22:9–10; 耶利米书 36:20–21"> 沙番把书带到王那里，并向王回报说：“凡交托给你仆人们的事，他们都在办理。</span>
<span className="v" id="v17" data-v="17"> 他们已经把耶和华殿中所找到的银子倒出来，交在督工和工匠手中。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:46; 耶利米书 36:20–21; 申命记 17:19"> 书记沙番又告诉王说：“祭司希勒家交给我一本书。”沙番就在王面前朗读。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 申命记 28:3–68; 列王纪下 22:19"> 王听见律法书上的话，就撕裂衣服。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 22:12; 耶利米书 26:24; 耶利米书 40:9"> 王吩咐希勒家、沙番的儿子亚希甘、米迦的儿子押顿、书记沙番和王的臣仆亚撒雅，说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 21:2; 以西结 14:1–11; 历代志下 28:6"> “你们去为我、为以色列和犹大所剩下的人，求问耶和华，询问这所发现书上的话；因为我们列祖没有遵守耶和华的话，没有照这书上所写的一切去行，所以耶和华倾倒在我们身上的烈怒甚大。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及记 15:20; 列王纪下 22:14"> 于是希勒家和王所吩咐的人，去见女先知户勒大。她是掌管礼服的沙龙的妻子；沙龙是特瓦的儿子，特瓦是哈斯拉的儿子。户勒大住在耶路撒冷第二区。他们就照这话对她说。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 37:7–10; 耶利米书 21:3–7; 列王纪下 22:15–20"> 她对他们说：“耶和华以色列的上帝如此说：‘你们要告诉那差你们来见我的人：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–20; 约书亚记 23:16; 申命记 28:15–68"> 耶和华如此说：看哪，我必使灾祸临到这地方和其中的居民，就是他们在犹大王面前所读那书上所写的一切咒诅。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 7:20; 马可福音 9:43–48; 那鸿书 1:6"> 因为他们离弃了我，向别神烧香，用他们手所做的一切惹我发怒，所以我的烈怒要倾倒在这地方，不能熄灭。’</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 34:23; 历代志下 34:21"> 至于那差你们来求问耶和华的犹大王，你们要这样告诉他：‘耶和华以色列的上帝如此说：关于你所听见的话，</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 32:26; 以西结 9:4; 诗篇 34:18"> 因为你听见上帝攻击这地方和其中居民的话时，心里柔软，又在我面前谦卑自己，撕裂衣服，在我面前哭泣；你既在我面前谦卑自己，我也垂听了你。这是耶和华说的。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 39:8; 诗篇 37:37; 列王纪上 21:29"> 看哪，我必使你归到你列祖那里；你必平平安安归入坟墓。我要降在这地方和其中居民身上的一切灾祸，你的眼必不看见。’”<br />他们就把这话回报王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪下 23:1–3; 历代志下 30:2; 马可福音 14:8"> 于是王派人召集犹大和耶路撒冷所有长老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:7; 列王纪下 23:2; 历代志下 34:15"> 王上耶和华的殿，犹大众人、耶路撒冷居民、祭司、利未人和所有百姓，无论大小，都与他同去；王把在耶和华殿中发现的约书上所有的话，读给他们听。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 23:16; 列王纪下 23:3; 列王纪下 11:14"> 王站在自己的位置上，在耶和华面前立约，要跟随耶和华，尽心尽性谨守祂的诫命、法度和律例，履行这书上所写的约言。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 30:12; 耶利米书 3:10; 历代志下 14:4"> 他使所有在耶路撒冷和便雅悯的人都站立。耶路撒冷居民就照上帝，他们列祖之上帝的约而行。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 34:3–7; 约书亚记 24:31; 列王纪下 23:4–20"> 约西亚从以色列子民所属的各地除去一切可憎之物，又使所有在以色列的人都事奉耶和华他们的上帝。约西亚在世的日子，他们没有离开耶和华他们列祖的上帝。</span>
</div>
</div>

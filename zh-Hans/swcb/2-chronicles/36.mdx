<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 22:11; 历代志下 33:25; 历代志下 26:1"> 本地百姓立约西亚的儿子约哈斯，在耶路撒冷接替他父亲作王。</span>
<span className="v" id="v2" data-v="2"> 约哈斯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约哈斯是约哈斯的另一种写法。">a</a></sup>登基的时候二十三岁，在耶路撒冷作王三个月。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 23:33"> 埃及王在耶路撒冷废了他的王位，又罚这地银子一百他连得和金子一他连得。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为三十公斤。">b</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 22:10–12; 列王纪下 23:34–35; 以西结 19:3–4"> 埃及王立他的兄弟以利雅敬作犹大和耶路撒冷的王，给他改名叫约雅敬。尼哥把他的兄弟约哈斯<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="约哈斯是约哈斯的另一种写法。">c</a></sup>带到埃及去了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:36–37; 耶利米书 22:13–19; 耶利米书 26:1"> 约雅敬登基的时候二十五岁，在耶路撒冷作王十一年。他行耶和华他上帝眼中看为恶的事。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 33:11; 列王纪下 24:5–6; 以西结 19:5–9"> 巴比伦王尼布甲尼撒上来攻打他，用铜链锁住他，要把他带到巴比伦。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 24:13; 但以理 5:2–4; 耶利米书 27:16–18"> 尼布甲尼撒也把耶和华殿里的一些器具带到巴比伦，放在巴比伦自己的庙里。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 24:5–6; 马太福音 1:11–12; 历代志上 3:16–17"> 约雅敬其余的事、他所行可憎的事，以及在他身上所发现的，看哪，都写在《以色列和犹大诸王记》上。他儿子约雅斤接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 24:8–17"> 约雅斤登基的时候八岁，在耶路撒冷作王三个月零十天。他行耶和华眼中看为恶的事。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 37:1; 历代志下 36:7; 列王纪下 24:10–17"> 到了年初，尼布甲尼撒王差人把他带到巴比伦，同时也把耶和华殿中贵重的器具带去；又立他的兄弟西底家作犹大和耶路撒冷的王。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 24:18–20; 耶利米书 52:1–3; 耶利米书 27:1"> 西底家登基的时候二十一岁，在耶路撒冷作王十一年。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 33:23; 耶利米书 37:2–21; 耶利米书 38:14–28"> 他行耶和华他上帝眼中看为恶的事；先知耶利米奉耶和华口中所出的话说话，他却不在耶利米面前谦卑自己。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 52:2–3; 历代志下 30:8; 以西结 17:11–20"> 他又背叛曾使他指着上帝起誓的尼布甲尼撒王；他硬着颈项，刚硬己心，不肯归向耶和华以色列的上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 9:8; 以西结 22:6; 弥迦书 3:9–11"> 此外，祭司长和百姓也都大大犯罪，随从列国一切可憎的事，玷污耶和华在耶路撒冷分别为圣的殿。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 35:15; 耶利米书 7:13; 耶利米书 25:3–4"> 耶和华他们列祖的上帝，因怜悯祂的百姓和祂的居所，屡次早早差遣使者到他们那里。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 5:12–13; 历代志下 30:10; 路加福音 22:63–64"> 但他们嘲笑上帝的使者，藐视祂的话，讥诮祂的先知，直到耶和华的烈怒向祂的百姓发作，无法挽回。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 74:20; 以斯拉记 9:7; 以西结 9:5–7"> 因此，耶和华使迦勒底人的王来攻击他们，在他们圣所的殿中用刀杀了他们的年轻人；无论少男、处女、老人、白发者，他都不怜悯。耶和华把他们全都交在他手中。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 36:7; 历代志下 36:10; 以赛亚书 39:6"> 上帝殿里大小器具，耶和华殿里的宝物，王和众首领的宝物，他全都带到巴比伦。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 79:1; 列王纪上 9:8; 耶利米书 52:13–15"> 他们焚烧上帝的殿，拆毁耶路撒冷的城墙，用火烧了城里所有宫殿，毁坏其中一切贵重器具。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 27:7; 以斯拉记 1:1–11; 历代志下 36:22"> 凡逃脱刀剑的人，他都掳到巴比伦；他们作他和他子孙的仆人，直到波斯国兴起掌权。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 29:10; 利未记 26:34–35; 撒迦利亚书 1:12"> 这就应验了耶和华借耶利米口中所说的话，直到这地享受它的安息年。地荒凉的日子都守安息，直到满了七十年。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 25:12; 以斯拉记 1:1–3; 耶利米书 29:10"> 波斯王居鲁士元年，为要应验耶和华借耶利米口中所说的话，耶和华激动波斯王居鲁士的心，使他传令通告全国，又写成文书，说：</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 44:26–28; 以斯拉记 7:13; 罗马书 8:31"> “波斯王居鲁士如此说：‘耶和华，天上的上帝，已经把地上万国赐给我；祂又吩咐我在犹大的耶路撒冷为祂建造殿宇。你们中间凡属祂百姓的人，愿耶和华他的上帝与他同在；让他上去吧。’”</span>
</div>
</div>

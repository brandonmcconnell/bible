<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:21–24; 诗篇 33:10; 诗篇 33:16"> 罗波安来到耶路撒冷，召集犹大家和便雅悯家，共十八万精选的战士，要与以色列争战，把国夺回归罗波安。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:15; 历代志下 12:5–7; 历代志下 8:14"> 但耶和华的话临到上帝人示玛雅，说：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 17:34; 创世记 49:28; 启示录 7:4–8"> “你要对所罗门的儿子、犹大王罗波安，以及在犹大和便雅悯的全以色列说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 50:20; 列王纪上 11:29–38; 历代志下 10:15–16"> ‘耶和华如此说：“你们不可上去，也不可与你们的弟兄争战！各人回自己的家去吧，因为这事出于我。”’”众人就听从耶和华的话，转回去，不再攻打耶罗波安。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 以赛亚书 22:8–11"> 罗波安住在耶路撒冷，在犹大建造防御城。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 3:5; 阿摩司 1:1; 历代志上 4:32"> 他建造伯利恒、以坦、提哥亚、</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:35; 撒母耳记上 22:1; 约书亚记 15:58"> 伯·夙、梭哥、亚杜兰、</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 54:1; 约书亚记 15:24; 撒母耳记上 23:19"> 迦特、玛利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:39; 约书亚记 15:35; 约书亚记 10:5"> 亚多莱音、拉吉、亚西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 15:33; 约书亚记 14:14"> 琐拉、亚雅仑和希伯仑；这些都是犹大和便雅悯境内的坚固城。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:19; 以赛亚书 22:10–11; 历代志下 11:23"> 他加固这些堡垒，在其中设置军官，又储备粮食、油和酒。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 13:22; 历代志下 26:14–15; 历代志下 32:5"> 他在各城中放置盾牌和枪，使城极其坚固。犹大和便雅悯都归属他。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 在全以色列境内的祭司和利未人，都从他们各自的境内站到罗波安这边。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 13:9; 民数记 35:2–5; 列王纪上 12:28–33"> 因为利未人离开他们的牧场和产业，来到犹大和耶路撒冷；这是因为耶罗波安和他的儿子弃绝他们，不让他们向耶和华尽祭司的职分。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:28; 列王纪上 12:31; 列王纪上 13:33"> 耶罗波安却为邱坛、为公山羊偶像和自己所造的牛犊偶像，设立祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 使徒行传 11:23; 诗篇 84:5–7"> 在他们以后，以色列各支派中凡定意寻求耶和华以色列上帝的人，都来到耶路撒冷，向耶和华他们列祖的上帝献祭。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 12:1; 历代志下 1:1–12; 历代志下 7:17–19"> 这样，他们使犹大国强盛，使所罗门的儿子罗波安坚固三年；因为他们三年行大卫和所罗门的道路。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 历代志上 27:18; 撒母耳记上 17:13"> 罗波安娶了玛哈拉为妻；她是大卫的儿子耶利摩的女儿，又是耶西的儿子以利押的女儿亚比亥所生的。</span>
<span className="v" id="v19" data-v="19"> 玛哈拉给他生了儿子：耶乌施、示玛利雅和撒罕。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 13:2; 历代志下 11:21; 历代志下 12:16"> 后来，他又娶了押沙龙的孙女玛迦；玛迦给他生了亚比雅、亚太、细撒和示罗密。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 8:30; 申命记 17:17; 列王纪上 11:3"> 罗波安爱押沙龙的孙女玛迦，超过爱他所有的妻妾；他娶了十八个妻子，六十个妾，生了二十八个儿子，六十个女儿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 21:15–17; 历代志上 29:1; 历代志上 5:1–2"> 罗波安立玛迦的儿子亚比雅作首领，在众兄弟中为王子，因为他想立他作王。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:3; 创世记 25:6; 路加福音 16:8"> 罗波安办事明智，把他的儿子分散到犹大和便雅悯全地各坚固城，又给他们丰富的粮食，并为他们寻求许多妻子。</span>
</div>
</div>

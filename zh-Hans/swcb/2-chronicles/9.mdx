<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="9" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 列王纪上 10:1–13"> 示巴女王听见所罗门的名声，就带着极大的队伍到耶路撒冷，要用难题考问所罗门；随行的骆驼驮着香料、大量金子和宝石。她来到所罗门那里，就把心里所有的话都同他说了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:15; 列王纪上 3:12; 马可福音 4:34"> 所罗门回答了她所有的问题；没有一件事对所罗门隐藏，是他不能给她说明的。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 3:1–4; 列王纪上 10:3; 列王纪上 6:1–7"> 示巴女王看见所罗门的智慧和他所建造的宫殿，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 12:37; 列王纪上 4:22–23; 诗篇 143:7"> 又看见他席上的食物、群臣的座位、仆役的侍立、他们的衣服、酒政和他们的衣服，以及他上耶和华殿的台阶，就惊叹得神不守舍。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译“她屏息无言”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 10:6"> 她对王说：“我在本国所听见关于你的事和你的智慧，果然是真的。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 10:7; 历代志下 9:5; 列王纪上 4:34"> 然而，直到我来亲眼看见，我才相信那些话；看哪，人告诉我的还不到你大智慧的一半。你胜过我所听见的名声！</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:4; 箴言 3:14; 箴言 10:21"> 你的人有福了！你这些仆人有福了！他们常常站在你面前，听你的智慧。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 2:11; 历代志上 29:23; 以赛亚书 32:1–2"> 耶和华你的上帝是应当称颂的！祂喜悦你，使你坐在祂的王位上，为耶和华你的上帝作王。因为你的上帝爱以色列，要永远坚立他们，所以立你作他们的王，施行公平和公义。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 9:1; 诗篇 72:10; 诗篇 72:15"> 她给王一百二十他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为三十公斤；一百二十他连得约为三点六公吨。">b</a></sup>金子，又给大量香料和宝石；示巴女王给所罗门王的香料，以前从未有过这样多的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 8:18; 列王纪上 10:11; 列王纪上 10:22"> 户兰的仆人和所罗门的仆人从俄斐运金子来，也运来檀香木<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="可能指印度檀香木，木纹美丽，带有香气，适合木工制作。">c</a></sup>和宝石。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 10:12; 历代志上 23:5; 诗篇 92:1–3"> 王用檀香木为耶和华的殿和王宫造台阶，又为歌唱的人造琴和瑟；在犹大地从未见过这样的。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 10:13; 以弗所书 3:20; 诗篇 20:4"> 所罗门王照示巴女王一切所愿、所求的都赐给她，此外还多过她带给王的礼物。于是她和她的仆人转回自己的本国去了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 72:15; 诗篇 68:29; 列王纪上 10:14–28"> 所罗门每年所得的金子，重六百六十六他连得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一他连得约为三十公斤；六百六十六他连得约为二十公吨。">d</a></sup>；</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 68:29; 诗篇 72:10"> 此外，还有商人和客商所带来的。亚拉伯众王和当地的省长也把金银带给所罗门。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 10:16–17; 历代志下 12:9–10"> 所罗门王用锤出来的金子造了二百面大盾牌；每面大盾牌用六百舍客勒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一舍客勒约为十克；六百舍客勒约为六公斤。">e</a></sup>锤出来的金子。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:2"> 又用锤出来的金子造了三百面盾牌；每面盾牌用三百舍客勒<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一舍客勒约为十克；三百舍客勒约为三公斤。">f</a></sup>金子。王把这些盾牌放在黎巴嫩林宫里。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 10:18–20; 诗篇 45:8; 启示录 20:11"> 王又造了一个象牙大宝座，用纯金包裹。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 24:9; 启示录 5:5; 民数记 23:24"> 宝座有六级台阶，并有金脚凳与宝座相连；座位两边有扶手，扶手旁边站着两只狮子。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 19:28; 启示录 21:12"> 六级台阶左右两边又站着十二只狮子；在任何国中都没有这样造的。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 10:21; 以斯帖记 1:7; 历代志下 9:27"> 所罗门王一切饮器都是金的，黎巴嫩林宫的一切器皿都是纯金的；在所罗门的日子，银子算不得什么。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 22:48; 约伯记 39:13; 列王纪上 10:22"> 因为王有船只与户兰的仆人一同往他施去。每三年，他施的船只回来一次，带来金子、银子、象牙、猿猴和孔雀。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 1:12; 诗篇 89:27; 列王纪上 4:30–31"> 所罗门王的财富和智慧胜过地上所有的王。</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:5; 雅各书 3:17; 箴言 2:6"> 地上众王都求见所罗门，要听上帝放在他心里的智慧。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 10:25; 约伯记 42:11; 诗篇 72:10"> 他们各人年年带来贡物：银器、金器、衣服、军械、香料、马和骡子。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 4:26; 列王纪上 10:26; 历代志下 1:14"> 所罗门有四千个马棚，可容战马和战车，又有一万二千名骑兵；他把他们安置在战车城，也安置在王身边，在耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 4:21; 创世记 15:18; 列王纪上 4:24"> 他统治从大河直到非利士地、直到埃及边境的众王。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 以赛亚书 9:10; 列王纪上 10:27–29"> 王使耶路撒冷的银子多如石头，又使香柏木多如低地的桑树。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 1:16; 列王纪上 10:28; 以赛亚书 31:1"> 有人从埃及和各地为所罗门带来马匹。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:29; 列王纪上 11:41–43; 列王纪上 11:29"> 所罗门其余的事，从始至终，不都写在先知拿单的史书、示罗人亚希雅的预言书，以及先见易多论尼八儿子耶罗波安的异象书上吗？</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 11:42–43"> 所罗门在耶路撒冷作全以色列的王四十年。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:10; 撒母耳记下 7:12; 列王纪上 1:21"> 所罗门与他列祖同睡，葬在他父亲大卫的城里；他儿子罗波安接替他作王。</span>
</div>
</div>

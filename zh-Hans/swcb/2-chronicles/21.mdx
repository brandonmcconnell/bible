<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 22:50; 列王纪下 8:16–17; 历代志下 12:16"> 约沙法与他列祖同睡，与他列祖一同葬在大卫城里；他儿子约兰接替他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:6; 历代志下 23:2; 历代志下 24:5"> 约兰有几个兄弟，都是约沙法的儿子：亚撒利雅、耶歇、撒迦利亚、亚撒利雅、米迦勒和示法提雅。这些都是以色列王约沙法的儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:23; 申命记 21:15–17; 历代志下 11:5"> 他们的父亲把许多银子、金子和宝物，以及犹大的坚固城赐给他们；但他把国赐给约兰，因为约兰是长子。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:5; 历代志下 21:17; 创世记 4:8"> 约兰起来接管他父亲的国，巩固自己以后，就用刀杀了他所有的兄弟，也杀了以色列的一些首领。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 8:17–22"> 约兰登基的时候三十二岁，在耶路撒冷作王八年。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 18:1; 列王纪上 12:28–30; 列王纪下 8:18"> 他行以色列诸王的道路，像亚哈家一样，因为他娶了亚哈的女儿为妻。他行耶和华眼中看为恶的事。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 11:36; 诗篇 132:17–18; 撒母耳记下 7:12–17"> 然而耶和华不愿毁灭大卫家，因为祂与大卫所立的约，又照祂所应许的，永远赐灯光给大卫和他的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 21:10; 历代志下 20:22–23; 创世记 27:40"> 约兰在位的日子，以东背叛，脱离犹大的权下，为自己立王。</span>
<span className="v" id="v9" data-v="9"> 于是约兰和他的军长，以及所有战车都过去；他夜间起来，击杀围困他的以东人和战车长。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 15:2; 耶利米书 2:13; 历代志下 13:10"> 这样，以东背叛，脱离犹大的权下，直到今日。那时，立拿也同时背叛，脱离他的权下，因为他离弃了耶和华他列祖的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 20:5; 列王纪上 11:7; 利未记 17:7"> 此外，他在犹大诸山建造邱坛，使耶路撒冷的居民行淫乱，又引诱犹大走迷路。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 14:2–5; 历代志下 17:3–4; 列王纪下 2:1"> 有一封信从先知以利亚那里送到他手中，信上说：“耶和华你祖大卫的上帝如此说：‘因为你没有行你父亲约沙法的道路，也没有行犹大王亚撒的道路，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 21:4; 历代志下 21:11; 列王纪上 16:30–33"> 却行以色列诸王的道路，使犹大和耶路撒冷的居民行淫乱，像亚哈家所行的一样，又杀了你父家的兄弟，就是比你好的人，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 26:21; 出埃及记 20:5; 何西阿 5:11"> 看哪，耶和华必以大灾击打你的百姓、你的儿女、你的妻子和你一切所有的；</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 21:18–19; 使徒行传 1:18; 申命记 28:67"> 你自己也必患重病，肠子生病，直到你的肠子因病日复一日地坠出。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 17:11; 历代志下 33:11; 列王纪上 11:14"> 耶和华激动非利士人和靠近古实人的阿拉伯人的心，来攻击约兰；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 22:1; 历代志下 22:6; 历代志下 25:23"> 他们上来攻打犹大，闯入其中，把王宫中所有的财物，以及他的儿子和妻子都掳去；除了他最小的儿子约哈斯以外，没有留下一个儿子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 21:15; 使徒行传 12:23; 列王纪下 9:29"> 这一切事以后，耶和华击打约兰，使他的肠子患上不能医治的病。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 16:14; 耶利米书 34:5"> 过了许久，两年期满，他的肠子因病坠出；他在剧痛的病中死去。他的百姓没有为他焚香，像为他列祖所焚的一样。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 22:18; 历代志下 28:27; 耶利米书 22:28"> 约兰登基的时候三十二岁，在耶路撒冷作王八年。他死的时候无人惋惜。人把他葬在大卫城，却没有葬在诸王的坟墓里。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 14:1–6"> 亚玛谢登基的时候二十五岁，在耶路撒冷作王二十九年。他母亲名叫约耶但，是耶路撒冷人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 25:14; 雅各书 4:8; 使徒行传 8:21"> 他行耶和华眼中看为正的事，只是心不完全。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 24:25–26; 列王纪下 14:5–22; 创世记 9:5–6"> 国在他手中稳固以后，他就杀了那些杀他父王的臣仆。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 24:16; 以西结 18:20; 列王纪下 14:5–6"> 但他没有处死他们的儿女，而是照摩西律法书上所写、耶和华所吩咐的去行，说：“不可因儿女处死父亲，也不可因父亲处死儿女；各人只因自己的罪而死。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 1:3; 历代志下 17:14–18; 历代志下 11:1"> 亚玛谢召集犹大人，按他们的父族，把全犹大和便雅悯编在千夫长、百夫长之下。他数点二十岁以上的人，查得精选之兵三十万，都是能拿枪和盾牌出战的。</span>
<span className="v" id="v6" data-v="6"> 他又用一百他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为三十公斤。">a</a></sup>银子，从以色列雇了一十万大能勇士。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 19:2; 列王纪上 12:28; 何西阿 9:13"> 有一个上帝人来见他，说：“王啊，不要让以色列军队与你同去，因为耶和华不与以色列同在，也不与以法莲众子民同在。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:11; 历代志下 20:6; 腓立比书 4:19"> 你若一定要去，就奋勇作战吧；但上帝必使你败在仇敌面前，因为上帝有能力帮助人，也有能力使人败落。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 10:22; 申命记 8:18"> 亚玛谢对上帝人说：“我已经给了以色列军兵一百他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为三十公斤。">b</a></sup>，那怎么办呢？”<br />上帝人回答：“耶和华能赐给你比这更多的。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 12:24; 撒母耳记下 19:43; 箴言 29:22"> 于是亚玛谢把那支从以法莲来投奔他的军队分别出来，叫他们回本地去。因此他们向犹大发怒，怒气大大燃烧，就怀着烈怒回本地去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:7; 诗篇 60:1; 撒母耳记下 8:13"> 亚玛谢壮起胆来，率领自己的百姓出征，到了盐谷，击杀西珥子民一万人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 20:10; 历代志上 20:3; 撒母耳记下 12:31"> 犹大子民又活捉一万人，把他们带到岩石顶上，从岩石顶上扔下去，使他们全都摔得粉碎。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 8:5; 列王纪上 16:29; 列王纪上 9:17"> 但亚玛谢所遣回、不让同去打仗的那队军兵，从撒玛利亚直到伯·和仑，袭击犹大各城，杀了三千人，又夺取了许多财物。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:23; 申命记 7:25; 申命记 7:5"> 亚玛谢杀败以东人回来以后，把西珥子民的神像带来，立为自己的神明，在它们面前下拜，向它们烧香。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 96:5; 历代志下 25:11–12; 历代志下 25:7"> 因此耶和华向亚玛谢发怒，差一个先知去见他，对他说：“这些百姓的神明不能救自己的百姓脱离你的手，你为什么寻求它们呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 18:20–21; 耶利米书 29:26; 历代志下 18:25"> 先知对王说话的时候，王对他说：“我们立你作王的谋士了吗？住口吧！你为什么要被击杀呢？”<br />先知就住口，说：“我知道上帝已经定意要毁灭你，因为你做了这事，又不听从我的劝告。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:8–14; 历代志下 25:13; 箴言 20:3"> 犹大王亚玛谢与他的谋士商议以后，就差人去见以色列王约阿施，就是耶户的孙子、约哈斯的儿子，说：“来吧，我们面对面较量。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 9:8–15; 列王纪上 4:33; 诗篇 80:13"> 以色列王约阿施差人去见犹大王亚玛谢，说：“黎巴嫩的蒺藜差人去见黎巴嫩的香柏树，说：‘把你的女儿给我儿子为妻。’后来黎巴嫩的一只野兽经过，把那蒺藜践踏了。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:16; 历代志下 32:25; 箴言 18:6"> 你心里说自己打败了以东，心中高傲，以此夸耀。现在还是安居在家吧。你为什么要惹祸，使自己和犹大一同败亡呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志下 22:7; 列王纪上 12:15; 彼得前书 2:8"> 但亚玛谢不肯听从；这是出于上帝，为要把他们交在仇敌手中，因为他们寻求以东的神明。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19–20; 撒母耳记上 6:9; 约书亚记 21:16"> 于是以色列王约阿施上来，在犹大的伯·示麦与犹大王亚玛谢面对面较量。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 4:10; 历代志下 28:5–6; 列王纪上 22:36"> 犹大败在以色列面前，各人都逃回自己的帐棚去了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:17; 尼希米记 8:16; 历代志下 26:9"> 以色列王约阿施在伯·示麦擒住犹大王亚玛谢，就是约哈斯的孙子、约阿施的儿子，把他带到耶路撒冷，又拆毁耶路撒冷的城墙，从以法莲门直到角门，共四百肘。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘约为四十六厘米；四百肘约为一百八十四米。">c</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 26:15; 历代志下 12:9; 列王纪下 14:14"> 他又拿走俄别·以东那里上帝殿里所找到的一切金银和器皿，以及王宫的宝物，又带走人质，然后回撒玛利亚去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪下 14:17–22"> 以色列王约哈斯的儿子约阿施死后，犹大王约阿施的儿子亚玛谢又活了十五年。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 20:34; 列王纪下 14:15"> 亚玛谢其余的事，从始至终，看哪，不都写在《犹大和以色列诸王记》上吗？</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 24:25; 约书亚记 10:31; 列王纪下 14:19"> 自从亚玛谢转离不跟随耶和华以后，有人在耶路撒冷同谋反叛他；他逃到拉吉，他们却派人追到拉吉，在那里杀了他。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 14:20"> 众人用马把他驮回来，葬在犹大城他列祖的坟墓里。</span>
</div>
</div>

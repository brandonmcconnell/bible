<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 5:7–8; 历代志下 11:13; 何西阿 5:4"> 希西家差人到全以色列和犹大，又写信给以法莲和玛拿西，叫他们到耶路撒冷耶和华的殿，向耶和华以色列的上帝守逾越节。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:10–11; 历代志上 13:1–3; 历代志下 30:13"> 王和众首领，以及耶路撒冷全会众已经商议，要在二月守逾越节。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 29:34; 出埃及记 12:6; 出埃及记 12:18"> 因为他们不能按时守节；祭司使自己成圣的人数不够，百姓也还没有聚集到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:4"> 王和全会众都看这事为正。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 20:1; 利未记 23:2; 以斯帖记 8:8–10"> 于是他们定下命令，要传遍全以色列，从别是巴直到但，叫众人到耶路撒冷向耶和华以色列的上帝守逾越节；因为他们没有照所写的，用众多人数守过这节。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:31; 以斯帖记 8:14; 列王纪下 15:19"> 驿使就带着王和众首领的信，照王的命令走遍全以色列和犹大，说：“以色列子民哪，你们要归向耶和华，亚伯拉罕、以撒和以色列的上帝，好让祂转向你们这些脱离亚述诸王之手的余民。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 29:8; 以西结 20:13–18; 撒迦利亚书 1:3–4"> 不要像你们的列祖和弟兄一样，他们干犯耶和华他们列祖的上帝，以致祂使他们成为令人惊骇的对象，正如你们所见。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 32:9; 历代志下 29:10; 申命记 10:16"> 现在不要像你们列祖那样硬着颈项；要归顺耶和华，进入祂永远分别为圣的圣所，事奉耶和华你们的上帝，好使祂的烈怒转离你们。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 55:7; 弥迦书 7:18; 诗篇 86:5"> 你们若归向耶和华，你们的弟兄和儿女必在掳掠他们的人面前蒙怜悯，得以回到这地；因为耶和华你们的上帝有恩典、有怜悯。你们若归向祂，祂必不转脸不顾你们。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:16; 历代志下 30:6; 尼希米记 2:19"> 驿使就从一城到一城，走遍以法莲、玛拿西的地，直到西布伦；但那里的人嗤笑他们，讥诮他们。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:18; 历代志下 30:21; 历代志下 30:25"> 然而，亚设、玛拿西和西布伦中也有人谦卑自己，来到耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:39; 耶利米书 24:7; 腓立比书 2:13"> 上帝的手也临到犹大，使他们同心一致，照耶和华的话，遵行王和众首领的命令。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:2; 诗篇 84:7"> 二月，有许多百姓聚集在耶路撒冷，守除酵节，是一大群会众。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:24; 撒母耳记下 15:23; 历代志下 15:16"> 他们起来，除去耶路撒冷的祭坛，又把一切香坛除去，丢进汲沦溪。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 29:34; 历代志下 5:11; 出埃及记 19:22"> 二月十四日，他们宰了逾越节的羊羔。祭司和利未人觉得惭愧，就使自己成圣，把燔祭带进耶和华的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 33:1; 历代志下 35:15; 列王纪下 11:14"> 他们按着班次，照上帝人摩西的律法站在自己的岗位上；祭司从利未人手中接过血来洒上。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 29:34; 历代志下 35:3–6; 出埃及记 12:6"> 会众中有许多人还没有使自己成圣，所以利未人负责宰逾越节的羊羔，替一切不洁的人，使他们分别为圣归耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 11:28; 雅各书 5:15–16; 但以理 9:19"> 因为百姓中有许多人，特别是以法莲、玛拿西、以萨迦和西布伦来的许多人，还没有洁净自己，却没有照所写的吃逾越节的羊羔。希西家为他们祷告说：“凡立定心意寻求上帝，就是耶和华他列祖之上帝的人，即使没有照圣所洁净的规矩洁净自己，</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 19:3; 箴言 23:26; 约伯记 11:13"> 愿良善的耶和华赦免他。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 15:26; 雅各书 5:15–16; 诗篇 103:3"> 耶和华垂听希西家，医治了百姓。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:15; 出埃及记 13:6; 申命记 12:12"> 在耶路撒冷的以色列子民大大欢喜，守除酵节七日。利未人和祭司天天赞美耶和华，用响亮的乐器向耶和华歌唱。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:6; 尼希米记 9:3; 以赛亚书 40:1–2"> 希西家向所有善于事奉耶和华的利未人说鼓励的话。于是他们在节期七日中吃祭物，献平安祭，又向耶和华他们列祖的上帝认罪。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 8:65; 历代志下 7:9"> 全会众商议要再守七日，于是又欢欢喜喜地守了七日。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:34; 历代志下 35:7–8; 以弗所书 4:8"> 因为犹大王希西家赐给会众一千头公牛、七千只羊作祭物；众首领也赐给会众一千头公牛、一万只羊。又有许多祭司使自己成圣。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 30:11; 历代志下 30:18; 历代志上 16:10–11"> 犹大全会众、祭司和利未人、从以色列来的全会众，以及从以色列地来的外族人和住在犹大的外族人，都欢喜快乐。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 7:8–10"> 于是耶路撒冷大有喜乐；自从以色列王大卫的儿子所罗门的日子以来，耶路撒冷没有这样的事。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 26:15; 诗篇 68:5; 民数记 6:23–26"> 利未祭司起来为百姓祝福；他们的声音蒙垂听，他们的祷告达到祂圣洁的居所，就是天上。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 15:24; 以弗所书 6:10; 马太福音 1:8"> 他儿子约沙法接替他作王，并且巩固自己，抵御以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 15:8; 历代志下 11:5; 历代志下 11:11–12"> 他在犹大所有坚固城中安置军兵，又在犹大地和他父亲亚撒所攻取的以法莲各城中设立防营。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 22:2; 以赛亚书 41:10; 提摩太后书 4:22"> 耶和华与约沙法同在，因为他行他祖大卫起初所行的道路，没有寻求众巴力，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 12:28; 路加福音 1:6; 帖撒罗尼迦前书 2:12"> 只寻求他父亲的上帝，遵行祂的诫命，不随从以色列的行为。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 18:1; 马太福音 6:33; 诗篇 127:1"> 因此耶和华坚定他手中的国；全犹大都给约沙法进贡，他就大有财富和尊荣。</span>
<span className="v" id="v6" data-v="6" data-xref="何西阿 14:9; 历代志下 15:17; 历代志下 20:33"> 他的心在耶和华的道路上越发振奋；并且他从犹大除去邱坛和亚舍拉木柱。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 35:3; 尼希米记 8:7–8; 传道书 12:9–10"> 他作王第三年，差派他的首领便亥伊勒、俄巴底亚、撒迦利亚、拿坦业和米该雅，去犹大各城教导百姓；</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:1–6; 历代志下 19:8; 玛拉基书 2:7"> 与他们同去的还有利未人示玛雅、尼探雅、西巴第雅、亚撒黑、示米拉末、约拿单、亚多尼雅、多比雅、多巴多尼雅；这些都是利未人；又有祭司以利沙玛和约兰与他们同去。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 5:46; 罗马书 3:2; 使徒行传 8:40"> 他们带着耶和华的律法书，在犹大教导百姓；他们走遍犹大各城，在百姓中施教。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 14:14; 出埃及记 15:14–16; 箴言 16:7"> 耶和华使犹大周围各地的诸国都心生惧怕，所以他们不敢与约沙法争战。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 26:8; 历代志下 9:14; 撒母耳记下 8:2"> 有些非利士人给约沙法带来礼物和贡银；阿拉伯人也给他送来羊群：公绵羊七千七百只，公山羊七千七百只。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 历代志下 32:5"> 约沙法日渐强大，在犹大建造堡垒和储货城。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 27:25–31; 历代志下 26:10–15"> 他在犹大各城有许多工程；在耶路撒冷又有战士，就是大能勇士。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 11:1; 创世记 15:5; 民数记 1:18"> 他们按父族登记如下：属犹大的千夫长中，有押拿统领，率领大能勇士三十万；</span>
<span className="v" id="v15" data-v="15"> 其次是约哈难统领，率领二十八万人；</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 5:9; 士师记 5:2; 历代志上 29:9"> 其次是细基利的儿子亚玛斯雅，他甘心把自己献给耶和华，率领大能勇士二十万。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 14:8; 撒母耳记下 1:21–22"> 属便雅悯的有大能勇士以利亚大，率领拿弓和盾牌的二十万人；</span>
<span className="v" id="v18" data-v="18"> 其次是约萨拔，率领十八万预备好出战的人。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 17:2; 历代志下 11:12; 历代志下 11:23"> 这些都是服事王的人，此外还有王安置在犹大全地坚固城中的人。</span>
</div>

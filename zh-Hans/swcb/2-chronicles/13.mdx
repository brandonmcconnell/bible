<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 12:16; 列王纪上 15:1–8"> 耶罗波安王十八年，亚比雅登基作犹大王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:20; 列王纪上 15:6–7; 士师记 19:16"> 他在耶路撒冷作王三年。他母亲名叫米该亚，是基比亚人乌列的女儿。亚比雅和耶罗波安之间有战争。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 26:12–13; 历代志上 21:5; 撒母耳记上 17:1–3"> 亚比雅率领四十万精选的勇士上阵；耶罗波安也率领八十万精选的大能勇士，摆阵迎战他。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:22; 历代志下 15:2; 创世记 10:18"> 亚比雅站在以法莲山地中的洗玛脸山上，说：“耶罗波安和全以色列啊，你们要听我说：</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 18:19; 利未记 2:13; 马可福音 9:49–50"> 耶和华以色列的上帝曾与大卫立盐约，把以色列的国永远赐给大卫和他的子孙，你们难道不知道吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 11:26; 列王纪上 12:20; 历代志下 10:19"> 然而，尼八的儿子耶罗波安，就是大卫儿子所罗门的臣仆，起来背叛他的主人。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 9:4; 历代志下 12:13; 使徒行传 17:5"> 有些无赖之徒、邪恶之辈聚集到他那里，强行抵挡所罗门的儿子罗波安。那时罗波安年轻，心里柔弱，无法抵挡他们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 历代志下 11:15; 路加福音 19:14"> “现在你们有意抵挡耶和华交在大卫子孙手中的国。你们人数众多，又有耶罗波安为你们造来作神明的金牛犊。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 11:14–15; 耶利米书 2:11; 出埃及记 29:35"> 你们不是赶出了耶和华的祭司，就是亚伦的子孙和利未人，又照外邦人的习俗为自己设立祭司吗？凡带着一头公牛犊和七只公绵羊来使自己承接圣职的，就可以作那些不是神明之物的祭司。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:5–6; 历代志下 11:16–17; 撒迦利亚书 13:9"> “至于我们，耶和华是我们的上帝，我们没有离弃祂。我们有事奉耶和华的祭司，就是亚伦的子孙，也有利未人各尽其职。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:4; 利未记 24:2–9; 出埃及记 29:38"> 他们每天早晨、傍晚向耶和华献燔祭，烧馨香的香，又在洁净的桌子上摆列陈设饼，照料金灯台和灯盏，使它们每晚点燃；因为我们谨守耶和华我们上帝的吩咐，但你们却离弃了祂。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:39; 罗马书 8:31; 民数记 10:8–9"> 看哪，上帝与我们同在，作我们的元帅；祂的祭司也拿着警号，要向你们吹响战号。以色列子民啊，不要与耶和华你们列祖的上帝争战；因为你们必不能亨通。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:4; 约书亚记 8:9; 箴言 21:30"> 但耶罗波安使伏兵绕到犹大人后面；这样，耶罗波安的军兵在犹大人前面，伏兵在他们后面。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 14:11; 出埃及记 14:10; 约书亚记 8:20"> 犹大人回头一看，战事前后夹击；他们就向耶和华呼求，祭司也吹号。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 14:12; 约书亚记 11:8; 诗篇 118:4–7"> 于是犹大人呐喊。犹大人呐喊的时候，上帝就在亚比雅和犹大面前击打耶罗波安和全以色列。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 16:8; 士师记 11:21; 约书亚记 10:12"> 以色列子民在犹大人面前逃跑；上帝把他们交在犹大人手中。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 28:6; 历代志下 13:3; 历代志下 13:12"> 亚比雅和他的百姓大大杀戮他们；以色列人被杀倒毙的精选勇士有五十万。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 5:20; 历代志下 14:11; 那鸿书 1:7"> 那时，以色列子民被制伏，犹大子民得胜，因为他们倚靠耶和华他们列祖的上帝。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 15:8; 约书亚记 15:9; 约书亚记 10:39"> 亚比雅追击耶罗波安，从他手中夺取几座城：伯特利和属伯特利的乡镇，耶沙拿和属耶沙拿的乡镇，以法拉音和属以法拉音的乡镇。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 25:38; 列王纪上 14:20; 使徒行传 12:23"> 在亚比雅的日子，耶罗波安再也不能恢复势力。耶和华击打他，他就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 9:5; 撒母耳记下 5:12–13; 士师记 10:4"> 但亚比雅日渐强盛，为自己娶了十四个妻子，生了二十二个儿子和十六个女儿。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 9:29; 历代志下 12:15; 历代志下 24:27"> 亚比雅其余的事、他的行迹和言论，都写在先知易多的评传中。</span>
</div>
</div>

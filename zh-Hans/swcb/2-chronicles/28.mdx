<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:13; 以赛亚书 1:1; 列王纪下 16:1–20"> 亚哈斯登基的时候二十岁，在耶路撒冷作王十六年。他不像他祖大卫那样行耶和华眼中看为正的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:17; 士师记 2:11; 历代志下 22:3–4"> 却行以色列诸王的道路，还为众巴力铸造偶像。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:2; 历代志下 33:6; 利未记 18:21"> 他又在欣嫩子谷烧香，并照耶和华从以色列子民面前赶出的列国可憎的事，使自己的儿女经火焚烧。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 16:4; 申命记 12:2–3; 利未记 26:30"> 他在邱坛上、山冈上、各青翠树下献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:1; 历代志下 24:24; 列王纪下 16:5–6"> 因此耶和华他的上帝把他交在亚兰王手中。亚兰人击败他，从他那里掳走许多人，带到大马士革。他又被交在以色列王手中，以色列王大大击杀了他。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 15:27; 约书亚记 24:20; 耶利米书 15:6"> 利玛利的儿子比加一日之内在犹大杀了十二万人，都是勇士，因为他们离弃了耶和华他们列祖的上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 43:15; 创世记 41:43; 以斯帖记 10:3"> 以法莲的大能勇士细基利杀了王的儿子玛西雅、管理王宫的亚斯利甘，以及仅次于王的以利加拿。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 11:4; 申命记 28:25; 申命记 28:41"> 以色列子民从他们弟兄中掳走妇女、儿子和女儿二十万人，又从他们那里夺取许多财物，把财物带到撒玛利亚。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 47:6; 以斯拉记 9:6; 启示录 18:5"> 但那里有耶和华的一位先知，名叫俄德。他出去迎见来到撒玛利亚的军队，对他们说：“看哪，耶和华你们列祖的上帝因向犹大发怒，把他们交在你们手中；你们却以怒气杀戮他们，怒气冲天。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:39–46; 马太福音 7:2–4; 耶利米书 25:29"> 现在你们又打算把犹大和耶路撒冷的子民降为你们的男女奴仆。你们自己岂不也有得罪耶和华你们上帝的过犯吗？</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 2:13; 以斯拉记 10:14; 马太福音 5:7"> 现在你们要听我说，把你们从弟兄中所掳来的俘虏送回去，因为耶和华的烈怒已经临到你们。”</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 28:1; 耶利米书 26:6"> 于是以法莲子民中的几个首领，就是约哈难的儿子亚撒利雅、米实利末的儿子比利家、沙龙的儿子耶希西家和哈得莱的儿子亚玛撒，起来反对那些从战场回来的人，</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:14; 马太福音 23:32; 约书亚记 22:17–18"> 对他们说：“你们不可把俘虏带到这里来，因为你们打算做的事，会使我们得罪耶和华，使我们的罪和罪责更加增多；因为我们的罪责已经重大，烈怒也已经临到以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 于是带兵器的人把俘虏和掠物留在众首领和全会众面前。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 25:21–22; 申命记 34:3; 士师记 1:16"> 那些按名被指定的人就起来接收俘虏，用掠物给他们中间所有赤身的人穿衣，给他们衣服和鞋，又给他们吃喝，用油抹他们；凡软弱的，就让他们骑在驴上，带他们到棕树城耶利哥，回到他们的弟兄那里。然后他们返回撒玛利亚。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 16:5–7; 以赛亚书 7:17; 以赛亚书 7:1–9"> 那时，亚哈斯王差人去向亚述诸王求助。</span>
<span className="v" id="v17" data-v="17" data-xref="俄巴底亚 1:10; 俄巴底亚 1:13–14; 利未记 26:18"> 因为以东人又来攻打犹大，掳走了人。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 16:57; 以西结 16:27; 撒母耳记上 6:9"> 非利士人也侵占了犹大低地和南地的城邑，夺取了伯·示麦、亚雅仑、基低罗、梭哥和属梭哥的乡镇、亭拿和属亭拿的乡镇，以及瑾锁和属瑾锁的乡镇，并住在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 21:2; 约伯记 40:12; 申命记 28:43"> 因为以色列王亚哈斯在犹大放纵无度，严重干犯耶和华，所以耶和华使犹大卑微。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 历代志上 5:26; 以赛亚书 30:16"> 亚述王提革拉·毗列色来到亚哈斯那里，却使他受困，并没有坚固他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 16:8–9; 列王纪下 18:15–16; 历代志下 12:9"> 因为亚哈斯从耶和华殿、王宫和众首领家中取了一部分财物，送给亚述王；但这并没有帮助他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:5; 以西结 21:13; 耶利米书 5:3"> 这位亚哈斯王在急难的时候，越发干犯耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 25:14; 耶利米书 44:20–28; 哈巴谷 1:11"> 他向那些击败他的大马士革之神献祭，说：“因为亚兰诸王的神帮助他们，我也要向它们献祭，使它们帮助我。”但那些神却使他和全以色列败亡。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:7; 列王纪下 16:17–18; 历代志下 30:14"> 亚哈斯收集上帝殿里的器皿，把上帝殿里的器皿砍碎，又关闭耶和华殿的门；他还在耶路撒冷各处街角为自己筑坛。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:3"> 他在犹大每一座城中建造邱坛，向别神烧香，惹动耶和华他列祖的上帝发怒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 16:19–20; 历代志下 20:34; 历代志下 27:7–9"> 亚哈斯其余的事和他一切行迹，从始至终，看哪，都写在《犹大和以色列诸王记》上。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 21:20; 历代志下 24:25; 箴言 10:7"> 亚哈斯与他列祖同睡，人把他葬在城里，就是耶路撒冷；但没有把他送入以色列诸王的坟墓。他儿子希西家接替他作王。</span>
</div>
</div>

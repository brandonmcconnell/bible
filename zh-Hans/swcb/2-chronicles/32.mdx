<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="32" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:13–37; 列王纪下 17:6; 历代志下 20:1–2"> 这些事和这忠信以后，亚述王西拿基立来进入犹大，围攻坚固城，想要攻取归自己。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王纪下 12:17"> 希西家见西拿基立已经来到，并且定意攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就与他的首领和勇士商议，要堵住城外泉源的水；他们都帮助他。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 32:30; 列王纪下 18:9; 列王纪上 19:21"> 于是许多百姓聚集，堵住一切泉源和流经那地中间的溪流，说：“为什么让亚述诸王来了，找到充足的水呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:23; 列王纪上 9:24; 列王纪下 25:4"> 希西家奋勇自强，修筑所有破裂的城墙，把城墙加高到城楼，又在外面修筑另一道城墙，加固大卫城的米罗，制造许多兵器和盾牌。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 40:2; 历代志下 30:22; 尼希米记 8:16"> 他设立军长管理百姓，把他们召集到城门广场那里，对他们说安慰鼓励的话：</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 6:16; 罗马书 8:31; 以弗所书 6:10"> “你们要刚强壮胆！不要因亚述王和跟随他的全军惧怕，也不要惊惶；因为与我们同在的，比与他同在的更大。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 17:5; 历代志下 20:17; 以赛亚书 41:10"> 与他同在的是血肉的膀臂，与我们同在的是耶和华我们的上帝，祂必帮助我们，为我们争战。”百姓就因犹大王希西家的话安定下来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:17; 约书亚记 10:31; 以赛亚书 36:2"> 此后，亚述王西拿基立派他的仆人到耶路撒冷；那时他正率全军攻打拉吉。他派人去见犹大王希西家和在耶路撒冷的全犹大，说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:19; 以赛亚书 36:4"> 亚述王西拿基立如此说：“你们倚靠什么，竟在耶路撒冷被围困时仍然留在那里呢？</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:43; 诗篇 11:1–3; 以赛亚书 36:18"> 希西家不是在诱骗你们，使你们死于饥渴吗？他说：‘耶和华我们的上帝必救我们脱离亚述王的手。’</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 31:1; 申命记 12:13–14; 申命记 12:26–27"> 这希西家岂不是废去了祂的邱坛和祭坛，又吩咐犹大和耶路撒冷说：‘你们只可在一个坛前敬拜，在这坛上烧香’吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:33–35; 以赛亚书 44:8–10; 但以理 4:30"> 我和我列祖向各地众民所行的，你们难道不知道吗？那些地方列国的神明，哪一个能救自己的地脱离我的手呢？</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 10:11–12; 出埃及记 15:9–11; 以赛亚书 42:8"> 我列祖所彻底毁灭的列国众神中，有哪一个能救自己的百姓脱离我的手，以致你们的上帝竟能救你们脱离我的手呢？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 5:2; 但以理 3:15; 以赛亚书 36:18"> 现在，不要让希西家这样欺骗你们、说服你们；也不要相信他，因为没有任何一国一邦的神能救自己的百姓脱离我的手，也脱离我列祖的手。何况你们的上帝，岂能救你们脱离我的手呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 73:9; 约翰福音 15:21; 约伯记 15:25–26"> 西拿基立的仆人还说了更多攻击耶和华上帝和祂仆人希西家的话。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:14; 列王纪下 19:12; 以赛亚书 37:28–29"> 西拿基立也写信辱骂耶和华以色列的上帝，攻击祂说：“各地列国的神既不能救自己的百姓脱离我的手，希西家的上帝也不能救祂的百姓脱离我的手。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 17:10; 列王纪下 18:26–28; 撒母耳记上 17:26"> 他们用犹大语大声呼喊，对城墙上耶路撒冷的百姓说话，要使他们惧怕惊慌，好攻取这城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 19:18; 以赛亚书 2:8; 耶利米书 32:30"> 他们谈论耶路撒冷的上帝，好像谈论地上各族之神，就是人手所造的一样。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 91:14–15; 以赛亚书 37:14–20; 历代志下 14:11"> 希西家王和亚摩斯的儿子先知以赛亚因此祷告，向天呼求。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 37:36–38; 诗篇 76:5; 诗篇 18:50"> 耶和华差遣一位天使，把亚述王营中所有大能勇士、统帅和军长都剪除。亚述王就满面羞愧地回到自己的地。他进了自己神的庙中，从他亲身所出的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即他的亲生儿子。">a</a></sup>在那里用刀杀了他。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 31:4–5; 诗篇 18:48–50; 帖撒罗尼迦后书 3:5"> 这样，耶和华拯救希西家和耶路撒冷的居民脱离亚述王西拿基立的手，也脱离所有仇敌的手，并在四境引导他们。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 17:5; 马太福音 2:11; 历代志下 1:1"> 有许多人把礼物带到耶路撒冷献给耶和华，又把宝物献给犹大王希西家；从此以后，希西家在万国眼中被高举。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 38:1–8; 列王纪下 20:1–11; 以赛亚书 38:21–22"> 那些日子，希西家病得要死；他向耶和华祷告，耶和华就对他说话，赐给他一个兆头。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 24:18; 历代志下 26:16; 历代志下 32:31"> 但希西家没有照他所蒙的恩惠报答，因为他心高气傲；因此烈怒临到他、犹大和耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 26:18–19; 历代志下 34:27–28; 历代志下 33:12"> 然而希西家和耶路撒冷的居民因心中的骄傲谦卑自己，所以耶和华的烈怒在希西家的日子没有临到他们。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 27:25–31; 历代志下 1:12; 箴言 10:22"> 希西家大有财富和尊荣。他为自己建造府库，收藏银子、金子、宝石、香料、盾牌和各样贵重器具；</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 7:8; 历代志下 26:10; 列王纪上 4:26"> 又建造仓房，收藏五谷、新酒和油的出产；为各类牲畜预备棚圈，为羊群预备羊圈。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:12; 箴言 10:22; 撒母耳记上 2:7"> 他又为自己建造城邑，并拥有许多羊群牛群；因为上帝赐给他极多的产业。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:33; 以赛亚书 22:9–11; 诗篇 1:1–3"> 这希西家也堵住基训上游的水源，把水直引到大卫城的西边。希西家凡事都亨通。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 8:2; 箴言 17:3; 创世记 22:1"> 然而，巴比伦首领派使者来见他，询问这地所发生的奇事；在这件事上，上帝离开他，为要试验他，好知道他心里所有的。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 36:1–22; 列王纪下 18:1–20; 历代志下 31:20–21"> 希西家其余的事和他的善行，看哪，都写在亚摩斯的儿子先知以赛亚的异象书上，并《犹大和以色列诸王记》中。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王纪上 1:21; 历代志下 16:14"> 希西家与他列祖同睡，人把他葬在大卫子孙坟墓的高处。他死的时候，全犹大和耶路撒冷的居民都尊敬他。他儿子玛拿西接替他作王。</span>
</div>
</div>

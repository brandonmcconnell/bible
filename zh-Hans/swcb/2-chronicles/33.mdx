<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 21:1–18; 历代志上 3:13; 以赛亚书 3:12"> 玛拿西登基的时候十二岁，在耶路撒冷作王五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:3; 申命记 18:9; 列王纪下 17:11"> 他行耶和华眼中看为恶的事，随从耶和华从以色列子民面前赶出的列国可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 16:21; 申命记 17:3; 历代志下 31:1"> 他重新建造他父亲希西家所拆毁的邱坛，又为众巴力筑坛，制造亚舍拉木柱，敬拜事奉天上的万象。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 7:16; 列王纪上 8:29; 申命记 12:11"> 他在耶和华的殿中筑坛；耶和华曾论这殿说：“我的名必永远在耶路撒冷。”</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 4:9; 耶利米书 32:34–35; 以西结 8:7–18"> 他又在耶和华殿的两院中，为天上的万象筑坛。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 18:21; 利未记 20:6; 历代志下 28:3"> 他还在欣嫩子谷使自己的儿女经火，又行法术、占卜和巫术，并交鬼问巫。他行了许多耶和华眼中看为恶的事，惹动祂发怒。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 33:4; 历代志下 7:16; 列王纪上 11:13"> 他把自己所造雕刻的偶像安放在上帝的殿中；上帝曾对大卫和他儿子所罗门说：“在这殿中，并在我从以色列众支派中所选择的耶路撒冷，我必永远立我的名。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:31–1; 利未记 8:36"> 只要他们谨守遵行我所吩咐他们的一切，就是借摩西所赐的一切律法、律例和典章，我就不再使以色列的脚离开我为你们列祖所指定的土地。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 24:3–4; 箴言 29:12; 历代志下 33:2"> 玛拿西引诱犹大和耶路撒冷的居民，使他们行恶，比耶和华在以色列子民面前所灭的列国更甚。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 耶利米书 44:4–5; 撒迦利亚书 1:4"> 耶和华向玛拿西和他的百姓说话，他们却不听。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 28:36; 历代志下 36:6; 尼希米记 9:32"> 因此，耶和华使亚述王的军长来攻击他们；他们用钩子拿住玛拿西，用铜链锁住他，把他带到巴比伦。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 10:3; 诗篇 50:15; 历代志下 32:26"> 他在急难中恳求耶和华他的上帝，在他列祖的上帝面前极其谦卑。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 5:20; 但以理 4:25; 马太福音 7:7–8"> 他向祂祷告，祂就听了他的祈求，垂听他的恳求，使他回到耶路撒冷，恢复他的国位。于是玛拿西知道耶和华是上帝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 27:3; 列王纪上 1:33; 尼希米记 3:3"> 此后，玛拿西在大卫城外修筑城墙，从谷中基训的西边，直到鱼门入口，围绕俄斐勒，筑得极高；又在犹大所有坚固城中安置勇敢的军长。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 33:3–7; 何西阿 14:1–3; 列王纪下 21:7"> 他除去外邦神明和耶和华殿中的偶像，又把他在耶和华殿的山上和耶路撒冷所筑的一切祭坛，都从城外丢出去。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 14:4; 列王纪上 18:30; 历代志下 33:9"> 他重修耶和华的坛，在坛上献平安祭和感谢祭，又吩咐犹大事奉耶和华以色列的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 32:12; 列王纪上 22:43; 列王纪下 15:4"> 然而百姓仍在邱坛献祭，只是单单献给耶和华他们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:19; 历代志下 33:12–13; 阿摩司 7:12"> 玛拿西其余的事、他向他的上帝所作的祷告，以及先见奉耶和华以色列上帝的名对他所说的话，看哪，都写在《以色列诸王记》上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:11; 约翰一书 1:9; 但以理 5:22"> 他的祷告，上帝怎样垂听他的祈求，他一切的罪和过犯，以及他谦卑以前建造邱坛、设立亚舍拉木柱和雕刻偶像的地方，看哪，都写在何赛的史书上。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译“先见的史书”。">a</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:10; 历代志下 32:33; 列王纪下 21:18–25"> 玛拿西与他列祖同睡，人把他葬在自己的宫中。他儿子亚们接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:13–15; 路加福音 12:19–20; 历代志下 33:1"> 亚们登基的时候二十二岁，在耶路撒冷作王二年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 21:20; 以西结 20:18; 列王纪下 21:1–11"> 他行耶和华眼中看为恶的事，像他父亲玛拿西所行的一样；亚们向他父亲玛拿西所造的一切雕刻偶像献祭，并事奉它们。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 33:12; 历代志下 33:19; 耶利米书 7:26"> 他没有像他父亲玛拿西那样在耶和华面前谦卑自己；这亚们反而罪上加罪。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:22; 历代志下 25:27–28; 历代志下 24:25–26"> 他的臣仆同谋害他，在他的宫中杀了他。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 35:31; 历代志下 34:1; 历代志下 36:1"> 但本地百姓杀了所有同谋害亚们王的人；本地百姓又立他儿子约西亚接替他作王。</span>
</div>
</div>

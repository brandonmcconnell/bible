<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 9:31; 列王纪上 2:10; 列王纪上 14:31"> 亚比雅与他列祖同睡，人把他葬在大卫城里；他儿子亚撒接替他作王。在亚撒的日子，国中太平十年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:11; 历代志下 31:20; 列王纪上 15:14"> 亚撒行耶和华他上帝眼中看为善、看为正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:5; 出埃及记 34:13; 列王纪下 23:14"> 他除去外邦祭坛和邱坛，打碎柱像，砍下亚舍拉木柱，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 30:19; 诗篇 119:10; 诗篇 101:2–8"> 又吩咐犹大人寻求耶和华他们列祖的上帝，遵行祂的律法和命令。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 34:4; 历代志下 34:7"> 他又从犹大各城除去邱坛和日像；国在他面前得享太平。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 15:15; 历代志上 22:9; 约伯记 34:29"> 他在犹大建造坚固城；因为那地太平，那些年间没有战争，是因耶和华赐他安息。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 3:12; 历代志下 14:6; 耶利米书 29:12–14"> 他对犹大人说：“我们来建造这些城，在四围筑墙，建楼，设门和门闩。这地仍在我们面前，因为我们寻求了耶和华我们的上帝；我们寻求祂，祂就赐我们四境平安。”于是他们建造，并且亨通。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 13:3; 历代志下 17:14–19; 历代志下 11:1"> 亚撒有军兵，出自犹大的有三十万人，拿小盾和枪；出自便雅悯的有二十八万人，拿大盾、拉弓。他们全都是大能勇士。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 16:8; 历代志下 12:2–3; 历代志下 11:8"> 古实人谢拉率领一百万军兵和三百辆战车出来攻打他们，来到玛利沙。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 1:17; 约书亚记 19:4"> 亚撒出去迎战，他们就在玛利沙的洗法谷摆阵。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 1:19; 哥林多后书 12:9–10; 诗篇 22:5"> 亚撒向耶和华他的上帝呼求，说：“耶和华啊，帮助有能力的和没有力量的，在你以外别无别人。耶和华我们的上帝啊，求你帮助我们；因为我们倚靠你，奉你的名来攻击这大军。耶和华啊，你是我们的上帝，不要让人胜过你。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 13:15; 诗篇 136:17–18; 申命记 28:7"> 于是耶和华在亚撒和犹大人面前击打古实人；古实人就逃跑。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:19; 创世记 26:1; 创世记 20:1"> 亚撒和跟随他的百姓追赶他们，直到基拉耳。古实人倒毙甚多，不能复原，因为他们在耶和华和祂军队面前被击溃。犹大军队夺取了许多战利品。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 17:10; 创世记 35:5; 历代志下 20:29"> 他们又攻击基拉耳周围的一切城，因为耶和华使那些城的人都惊惧。他们掠夺所有城邑，因为其中有许多财物。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:30–47; 民数记 31:9; 撒母耳记上 30:20"> 他们又攻击牧畜人的帐棚，夺取许多羊和骆驼，然后回到耶路撒冷。</span>
</div>

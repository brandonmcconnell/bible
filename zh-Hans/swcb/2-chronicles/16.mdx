<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 15:9; 历代志下 15:5; 列王纪上 12:27"> 亚撒作王第三十六年，以色列王巴沙上来攻打犹大，修筑拉玛，不许人出入归向犹大王亚撒。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 12:18; 历代志下 28:21; 列王纪下 18:15"> 于是亚撒从耶和华殿和王宫的府库中取出银子和金子，送给住在大马士革的亚兰王便哈达，说：</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 15:4; 历代志下 18:3; 哥林多后书 6:16"> “你我之间要立约，像我父与你父之间所立的约一样。看哪，我把银子和金子送给你。请你去废除你与以色列王巴沙所立的约，使他离开我。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 20:1; 历代志下 17:12; 列王纪上 15:20"> 便哈达听从亚撒王，派军长去攻打以色列的城邑；他们攻取了以云、但、亚伯·玛音和拿弗他利所有的储货城。</span>
<span className="v" id="v5" data-v="5"> 巴沙听见了，就停工，不再修筑拉玛。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 21:17; 约书亚记 15:38; 以赛亚书 10:29"> 亚撒王率领全犹大，把巴沙修筑拉玛所用的石头和木料都搬走，用来修筑迦巴和米斯巴。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 19:2; 列王纪上 16:1; 诗篇 146:3–6"> 那时，先见哈拿尼来见犹大王亚撒，对他说：“因为你倚靠亚兰王，没有倚靠耶和华你的上帝，所以亚兰王的军队已经逃脱你的手。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 12:3; 历代志下 13:16; 历代志下 16:7"> 古实人和路比人不是庞大的军队吗？他们有极多的战车和骑兵；但因你倚靠耶和华，祂就把他们交在你手中。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:12; 箴言 15:3; 耶利米书 16:17"> 因为耶和华的眼目遍察全地，要为那些向祂心志完全的人显出大能。你这事做得愚昧；从今以后，你必有战争。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 18:26; 使徒行传 16:23–24; 撒母耳记下 12:13"> 亚撒因此向先见发怒，把他关进监牢，因为他为这事向他大发烈怒。那时，亚撒也虐待了一些百姓。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志下 12:15; 历代志下 9:29; 历代志下 35:27"> 看哪，亚撒的事，从始至终，都写在《犹大和以色列诸王记》上。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:5; 历代志下 28:22; 历代志上 10:14"> 亚撒作王第三十九年，脚上患病，病势极重；然而他病的时候没有寻求耶和华，只求医生。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 15:24"> 亚撒与他列祖同睡，死在他作王第四十一年。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 50:2; 历代志下 21:19; 耶利米书 34:5"> 人把他葬在大卫城他为自己凿成的坟墓里，安放在铺满香料和各样按调香术调制香品的床上；又为他举行了极盛大的焚香礼。</span>
</div>

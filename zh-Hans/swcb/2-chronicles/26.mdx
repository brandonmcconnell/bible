<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 22:1; 马太福音 1:8–9; 历代志下 33:25"> 犹大众民立乌西雅接替他父亲亚玛谢作王，那时他十六岁。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 16:6; 历代志下 25:28; 历代志下 25:23"> 乌西雅重建以禄，使它归回犹大。以后王与他列祖同睡。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 15:2–3; 阿摩司 1:1; 何西阿 1:1"> 乌西雅登基的时候十六岁，在耶路撒冷作王五十二年。他母亲名叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 25:2"> 他行耶和华眼中看为正的事，照他父亲亚玛谢一切所行的。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 15:2; 历代志下 24:2; 历代志上 22:13"> 撒迦利亚在世的日子，乌西雅定意寻求上帝；撒迦利亚明白上帝的异象。乌西雅寻求耶和华的时候，上帝就使他亨通。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 14:29; 撒母耳记上 5:6; 撒母耳记上 5:1"> 他出去与非利士人争战，拆毁迦特的城墙、雅比尼的城墙和亚实突的城墙；又在亚实突境内和非利士人中间建造城邑。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 21:16; 历代志上 5:20; 历代志下 14:11"> 上帝帮助他攻击非利士人、住在姑珥·巴力的阿拉伯人和米乌尼人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:2; 历代志下 17:11; 创世记 19:38"> 亚扪人向乌西雅进贡。他的名声传到埃及入口，因为他极其强盛。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:13; 历代志下 25:23; 列王纪下 14:13"> 乌西雅又在耶路撒冷的角门、谷门和城墙转角处建造城楼，并加固这些地方。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 26:18–21; 以赛亚书 29:17; 列王纪下 3:4"> 他在旷野建造城楼，挖了许多水池，因为他在低地和平原有大量牲畜。他又在山地和肥沃田野中有农夫和修理葡萄园的人，因为他喜爱农事。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 5:2"> 乌西雅又有一支能出战的军队，按班次出征；他们的数目是书记耶利和官员玛西雅在王的一位军长哈拿尼雅手下清点的。</span>
<span className="v" id="v12" data-v="12"> 父族首领，就是大能勇士的总数，是二千六百人。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 25:5; 历代志下 14:8; 历代志下 11:1"> 他们手下有军兵三十万七千五百人，能以大能争战，帮助王攻击仇敌。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:16; 撒母耳记上 17:49"> 乌西雅为全军预备盾牌、枪、头盔、铠甲、弓和甩石用的石头。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 31:4; 马太福音 4:24; 历代志下 2:7"> 他在耶路撒冷制造巧匠发明的机械，安在城楼和城垛上，用来射箭和发大石。他的名声远扬，因为他得了奇妙的帮助，直到强盛。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 32:25; 历代志下 25:19; 箴言 16:18"> 但他强盛以后，心高气傲，以致败坏；他干犯耶和华他的上帝，进入耶和华的殿，要在香坛上烧香。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:10; 历代志上 26:6; 历代志上 12:28"> 祭司亚撒利雅跟着他进去，与他同去的还有耶和华的祭司八十人，都是勇敢的人。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 30:7–8; 民数记 18:7; 耶利米书 13:18"> 他们抵挡乌西雅王，对他说：“乌西雅啊，向耶和华烧香不是你的职分，而是亚伦子孙、分别为圣烧香的祭司的职分。你出圣所吧，因为你已经干犯耶和华；你必不能从耶和华上帝那里得荣耀。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 12:10; 历代志下 25:16; 列王纪下 5:25–27"> 乌西雅就发怒；他手里拿着香炉要烧香。他向祭司发怒的时候，在耶和华殿中、香坛旁边、祭司面前，麻风病忽然发在他的额上。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 28:22; 以斯帖记 6:12; 利未记 14:34"> 大祭司亚撒利雅和所有祭司观看他，看哪，他额上长了麻风；他们就急忙催他出去。他自己也急忙出去，因为耶和华击打了他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 13:46; 民数记 12:15; 列王纪下 7:3"> 乌西雅王直到死日都是麻风病人，住在隔离的房子里，因为他与耶和华的殿隔绝。他儿子约坦管理王宫，治理国中的百姓。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:1; 以赛亚书 6:1; 历代志下 9:29"> 乌西雅其余的事，从始至终，都是亚摩斯的儿子先知以赛亚所记的。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 28:27; 历代志下 21:20; 历代志下 26:18"> 乌西雅与他列祖同睡；人把他葬在属诸王的坟地里，与他列祖同葬，因为他们说：“他是麻风病人。”他儿子约坦接替他作王。</span>
</div>

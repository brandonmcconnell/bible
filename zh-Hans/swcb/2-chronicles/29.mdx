<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:1–3; 历代志上 3:13; 历代志下 26:5"> 希西家登基的时候二十五岁，在耶路撒冷作王二十九年。他母亲名叫亚比雅，是撒迦利亚的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 34:2; 历代志下 28:1"> 他行耶和华眼中看为正的事，照他祖大卫一切所行的。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 28:24; 历代志下 29:7; 马太福音 6:33"> 他作王第一年正月，打开耶和华殿的门，并加以修理。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 19:2; 尼希米记 3:29; 历代志下 32:6"> 他召来祭司和利未人，把他们聚集在东边的广场上，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 35:6; 哥林多前书 3:16–17; 历代志下 34:3–8"> 对他们说：“利未人哪，请听我说！现在你们要使自己成圣，也要使耶和华你们列祖上帝的殿成圣，把污秽之物从圣所中清出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 8:16; 耶利米书 2:27; 但以理 9:16"> 因为我们的列祖不忠，行了耶和华我们上帝眼中看为恶的事，离弃了祂；他们转脸不顾耶和华的居所，背向祂。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 28:24; 利未记 24:2–8; 历代志下 29:3"> 他们又关闭廊门，熄灭灯火，不在圣所向以色列的上帝烧香，也不献燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 25:9; 耶利米书 25:18; 耶利米书 29:18"> 因此耶和华的烈怒临到犹大和耶路撒冷，使他们令人惊骇、恐惧、嗤笑，正如你们亲眼所见。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 28:17; 历代志下 28:5–8; 耶利米哀歌 5:7"> 看哪，我们的列祖因此倒在刀下；我们的儿女和妻子也被掳去。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 50:5; 历代志下 23:16; 以斯拉记 10:3"> 现在我心里有意，要与耶和华以色列的上帝立约，使祂的烈怒转离我们。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:8; 加拉太书 6:7–8; 民数记 8:6–14"> 我的众子啊，现在不要懈怠；因为耶和华拣选了你们，要你们站在祂面前事奉祂，作祂的仆役，向祂烧香。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 3:19–20; 历代志上 15:5–7; 民数记 4:2–20"> 于是利未人起来：哥辖子孙中有亚玛赛的儿子玛哈、亚撒利雅的儿子约珥；米拉利子孙中有押底的儿子基士、耶哈利勒的儿子亚撒利雅；革顺人中有洗玛的儿子约亚、约亚的儿子伊甸；</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 6:39; 历代志上 15:8; 历代志上 15:17"> 以利撒反子孙中有申利和耶利；亚萨子孙中有撒迦利雅和玛他尼；</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 6:33; 历代志上 25:1; 历代志上 25:6"> 希幔子孙中有耶利和示每；耶杜顿子孙中有示玛雅和乌薛。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 30:12; 历代志上 23:28; 历代志下 29:5"> 他们召集自己的弟兄，使自己成圣，又照王的命令，按耶和华的话进去洁净耶和华的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:16; 马太福音 21:12–13; 马太福音 23:27"> 祭司进入耶和华殿的里面洁净殿，把在耶和华殿中所发现的一切污秽之物，都搬到耶和华殿的院子里；利未人接过来，运到外面的汲沦溪。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:2–8; 历代志下 3:4; 列王纪上 6:3"> 正月初一日，他们开始成圣；初八日到了耶和华的廊子。他们用八天使耶和华的殿成圣，到正月十六日就完成了。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 4:1; 历代志下 4:7–8; 历代志下 13:11"> 于是他们进去见希西家王，到宫里说：“我们已经洁净了耶和华的全殿，也洁净了燔祭坛和坛的一切器具，陈设饼的桌子和桌子的一切器具。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 28:24"> 亚哈斯王在位不忠的时候所丢弃的一切器具，我们也都预备好，并使它们成圣。看哪，都在耶和华的坛前。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 6:12; 耶利米书 25:4; 出埃及记 24:4"> 希西家王清早起来，召集城里的首领，上耶和华的殿去。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 4:3–14; 约伯记 42:8; 以西结 45:23"> 他们牵来七头公牛、七只公绵羊、七只羊羔和七只公山羊，为国、为圣所、为犹大作赎罪祭。王吩咐亚伦子孙祭司把这些献在耶和华的坛上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:18; 利未记 8:19; 利未记 8:24"> 于是他们宰了公牛，祭司接过血，洒在坛上；他们又宰了公绵羊，把血洒在坛上；也宰了羊羔，把血洒在坛上。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:15; 利未记 4:24; 利未记 1:4"> 他们把作赎罪祭的公山羊牵到王和会众面前；众人按手在其上。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:20; 以西结 45:15; 哥林多后书 5:18–21"> 祭司宰了公山羊，用它们的血在坛上作赎罪祭，为全以色列赎罪；因为王吩咐要为全以色列献燔祭和赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 8:14; 历代志上 23:5; 撒母耳记下 24:11"> 王又照大卫、王的先见迦得和先知拿单的命令，把利未人安置在耶和华的殿中，拿着钹、瑟和琴；因为这命令是耶和华借祂的先知所吩咐的。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:5; 历代志上 15:24; 阿摩司 6:5"> 利未人拿着大卫的乐器站立，祭司也拿着号站立。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 23:18; 诗篇 137:3–4; 历代志下 20:21"> 希西家吩咐人在坛上献燔祭。燔祭一开始，耶和华的歌声也同时响起，还有号声和以色列王大卫的乐器声。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 5:8–14; 诗篇 89:15; 诗篇 68:24–26"> 全会众都敬拜，歌唱的人歌唱，吹号的人吹号；这一切持续到燔祭献完。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:18; 历代志上 29:20; 腓立比书 2:10–11"> 献祭完毕，王和所有在场的人都屈身敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 4:4; 诗篇 95:1–2; 历代志上 16:7–36"> 希西家王和众首领又吩咐利未人，用大卫和先见亚萨的话赞美耶和华。他们欢欢喜喜地赞美，又低头敬拜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 出埃及记 35:22; 利未记 7:12"> 希西家回应说：“现在你们已经将自己奉献给耶和华；请近前来，把祭物和感谢祭带进耶和华的殿。”会众就带来祭物和感谢祭；凡甘心乐意的，也都带来燔祭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉记 6:17; 列王纪上 3:4; 历代志上 29:21"> 会众带来的燔祭数目，是公牛七十头、公绵羊一百只、羊羔二百只；这一切都是献给耶和华的燔祭。</span>
<span className="v" id="v33" data-v="33"> 分别为圣之物有牛六百头、羊三千只。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:11; 历代志下 30:3; 诗篇 94:15"> 但祭司太少，不能剥尽所有燔祭牲的皮；所以他们的弟兄利未人帮助他们，直到工作完成，也直到祭司使自己成圣。因为利未人在使自己成圣的事上，比祭司更心里正直。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 15:5–10; 出埃及记 29:13; 历代志上 16:37–42"> 燔祭很多，还有平安祭牲的脂油，以及每个燔祭同献的奠祭。这样，耶和华殿中的事奉就整顿好了。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:41; 帖撒罗尼迦前书 3:8–9; 历代志上 29:9"> 希西家和众百姓都欢喜，因为上帝为百姓所预备的事成就了；这事成得很快。</span>
</div>

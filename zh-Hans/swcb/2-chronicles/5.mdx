<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 7:51; 历代志上 22:14; 撒母耳记下 8:11"> 这样，所罗门为耶和华殿所做的一切工程都完成了。所罗门把他父亲大卫分别为圣之物，就是银子、金子和一切器具，都带进来，放在上帝殿的府库里。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 6:12; 历代志下 1:4; 民数记 10:33"> 那时，所罗门召集以色列的长老、众支派的首领，以及以色列子孙各父族的族长到耶路撒冷，要把耶和华的约柜从大卫城，就是锡安，运上来。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:2; 历代志下 7:8–10; 利未记 23:34–36"> 于是以色列众人在七月的节期中聚集到王那里。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:3; 约书亚记 3:6; 约书亚记 6:6"> 以色列所有长老都来到，利未人便抬起约柜。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 8:6; 历代志下 1:3; 列王纪上 8:4"> 他们把约柜、会幕和会幕里所有圣器具都运上来；祭司利未人把这些都运上来。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 29:21; 撒母耳记下 6:13; 历代志上 16:1–2"> 所罗门王和聚集到他那里、以色列全会众，都在约柜前献羊和牛，多得不可胜数，无法计算。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 132:8; 列王纪上 6:23–28; 列王纪上 8:6–7"> 祭司把耶和华的约柜抬进它的地方，就是殿的内殿、至圣所，放在基路伯的翅膀下面。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:12–15; 民数记 4:6; 出埃及记 37:3–5"> 因为基路伯展开翅膀在约柜所在之处以上，基路伯从上面遮盖约柜和抬柜的杠。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 8:8–9"> 杠很长，杠头从内殿前可以看见，却在外面看不见；约柜就在那里，直到今日。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 9:4; 历代志下 6:11; 申命记 10:2–5"> 约柜里除了两块石版以外，什么也没有；这石版是摩西在何烈山放进去的，就是以色列子孙出埃及时，耶和华与他们立约之处。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="历代志下 35:4; 历代志下 29:5; 约伯记 1:5"> 祭司从圣所出来的时候，所有在场的祭司都已经使自己成圣，并不按班次供职；</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 15:24; 诗篇 68:25; 历代志上 6:39"> 歌唱的利未人全体，就是亚萨、希幔、耶杜顿和他们的儿子、弟兄，都穿着细麻衣，拿着钹、瑟和琴，站在坛的东边；同他们一起的还有一百二十名吹号的祭司。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 3:11; 耶利米书 33:11; 历代志下 7:3"> 吹号的和歌唱的一同发声，声如一人，赞美感谢耶和华；他们随着号、钹和乐器扬声赞美耶和华，说：<br /><span className="pl pl-1">“祂本为善，</span><br /><span className="pl pl-2">祂的慈爱永远长存！”</span><br />那时，殿中充满了云，就是耶和华的殿；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 40:35; 列王纪上 8:11; 以赛亚书 6:1–4"> 祭司因云的缘故不能站立供职，因为耶和华的荣耀充满了上帝的殿。</span>
</div>

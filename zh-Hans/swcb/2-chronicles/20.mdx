<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 83:5–8; 以赛亚书 16:6; 历代志下 32:1"> 此后，摩押人、亚扪人和一些米乌尼人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十士译本作“米乌尼人”；希伯来文作“亚扪人”。">a</a></sup>来攻打约沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 14:7; 撒母耳记上 23:29; 约书亚记 15:62"> 有人来告诉约沙法说：“有一大群人从海那边、从亚兰来攻击你。看哪，他们已经在哈洗逊·他玛。”哈洗逊·他玛就是隐·基底。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理 9:3; 历代志下 19:3; 撒母耳记上 7:6"> 约沙法惧怕，就定意寻求耶和华，并在全犹大宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 50:15; 诗篇 60:10–12; 诗篇 69:35"> 犹大人聚集，求耶和华帮助；他们从犹大各城出来寻求耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:15–19; 历代志下 6:12–13; 历代志下 34:31"> 约沙法站在犹大和耶路撒冷的会众中，在耶和华殿里，新院前，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 4:39; 历代志上 29:11–12; 但以理 4:17"> 说：“耶和华我们列祖的上帝啊，你不是天上的上帝吗？你不是统治万国万邦的吗？能力和大能都在你手中，无人能抵挡你。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 41:8; 雅各书 2:23; 诗篇 44:2"> 我们的上帝啊，你不是曾在你百姓以色列面前赶出这地的居民，把这地永远赐给你朋友亚伯拉罕的后裔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译“种子”。">b</a></sup>吗？</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 6:10; 历代志下 2:4"> 他们住在这地，并在这里为你的名建造圣所，说：</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 6:28–30; 历代志下 6:20; 列王纪上 8:33"> ‘若有灾祸临到我们，无论是刀剑、审判、瘟疫或饥荒，我们必站在这殿前，也站在你面前，因为你的名在这殿里；我们在患难中向你呼求，你必垂听拯救。’</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 2:19; 申命记 2:4–5; 申命记 2:9"> 现在，看哪，亚扪人、摩押人和西珥山的人，就是以色列出埃及地时你不许以色列侵犯的人；以色列转离他们，没有灭绝他们。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 83:3–12; 士师记 11:23–24; 耶利米书 18:20"> 看哪，他们怎样报答我们，竟来把我们从你赐给我们为业的产业中赶出去。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 121:1–2; 诗篇 25:15; 诗篇 141:8"> 我们的上帝啊，你不审判他们吗？因为我们无力抵挡这来攻击我们的大军，也不知道该怎样行；我们的眼目只仰望你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:1; 使徒行传 21:5; 申命记 29:10"> 犹大众人和他们的婴孩、妻子、儿女，都站在耶和华面前。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 15:1; 历代志下 24:20; 使徒行传 10:31"> 那时，耶和华的灵在会众中临到雅哈悉；他是撒迦利亚的儿子，撒迦利亚是比拿雅的儿子，比拿雅是耶利的儿子，耶利是玛他尼的儿子；他是利未人，属亚萨的子孙。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 32:7–8; 申命记 31:6; 出埃及记 14:13–14"> 他说：“犹大众人、耶路撒冷的居民和约沙法王啊，你们要听！耶和华对你们如此说：‘不要因这大军惧怕，也不要惊惶；因为这场争战不是你们的，乃是上帝的。</span>
<span className="v" id="v16" data-v="16"> 明天你们要下去迎敌。看哪，他们必从洗斯坡上来；你们要在谷尾、耶鲁伊勒旷野前找到他们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:13–14; 历代志下 15:2; 以赛亚书 41:10"> 这场争战你们不必作战；犹大和耶路撒冷啊，你们只管站稳，静立观看耶和华与你们同在所施行的救恩。不要惧怕，也不要惊惶。明天出去迎敌，因为耶和华与你们同在。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 4:31; 历代志下 7:3; 创世记 24:26"> 约沙法就面伏于地；犹大众人和耶路撒冷居民也都俯伏在耶和华面前，敬拜耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 15:16–22; 历代志上 16:42; 历代志上 16:5"> 哥辖子孙和可拉子孙中的利未人站起来，用极大的声音赞美耶和华以色列的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:31; 约翰福音 14:1; 约翰福音 11:40"> 次日清早，他们起来，往提哥亚的旷野去。他们出去的时候，约沙法站着说：“犹大和耶路撒冷的居民哪，要听我说！信靠耶和华你们的上帝，就必坚立；信祂的先知，就必亨通。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:1; 诗篇 106:1; 历代志下 5:13"> 约沙法与百姓商议之后，就派人穿着圣洁的礼服，在军前向耶和华歌唱赞美，说：“你们要感谢耶和华，因为祂的慈爱永远长存。”</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 14:20; 以赛亚书 19:2; 以西结 38:21"> 他们开始歌唱赞美的时候，耶和华就设下伏兵，攻击来攻打犹大的亚扪人、摩押人和西珥山的人，他们就被击败。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 7:22; 撒母耳记上 14:20; 以西结 35:2–3"> 因为亚扪人和摩押人起来攻击西珥山的居民，把他们灭尽杀绝；他们杀尽西珥的居民以后，又彼此帮助，互相毁灭。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 37:36; 诗篇 110:6; 历代志上 5:22"> 犹大人来到望楼，俯瞰旷野，看见那大军；看哪，满地都是倒毙的尸体，没有一人逃脱。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 30:19–20; 列王纪下 7:9–16; 民数记 31:15"> 约沙法和他的百姓来夺取他们的财物，见其中有大量财富、尸首和贵重器物；他们为自己剥取，多得不能携带。因财物甚多，他们收取了三天。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:15; 创世记 32:20; 历代志下 5:9"> 第四天，他们聚集在比拉迦<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“比拉迦”的意思是“祝福”。">c</a></sup>谷，在那里称颂耶和华；因此那地方名叫比拉迦谷，直到今日。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 12:43; 希伯来书 6:20; 诗篇 30:1"> 然后犹大和耶路撒冷众人都回去，约沙法走在他们前头，欢欢喜喜返回耶路撒冷；因为耶和华使他们因仇敌而欢喜。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 14:2–3; 诗篇 57:8; 诗篇 92:3"> 他们带着瑟、琴和号来到耶路撒冷，进耶和华的殿。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 17:10; 列王纪下 7:6; 出埃及记 23:27"> 各地诸国听见耶和华攻击以色列的仇敌，就都惧怕上帝。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 15:15; 历代志下 14:6–7; 撒母耳记下 7:1"> 这样，约沙法的国得享平静，因为他的上帝赐他四境平安。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 22:41–44"> 约沙法作犹大王。他登基的时候三十五岁，在耶路撒冷作王二十五年。他母亲名叫阿苏巴，是示利希的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 14:2–5; 列王纪上 15:11; 历代志下 14:11–13"> 约沙法行他父亲亚撒的道路，不偏离，行耶和华眼中看为正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 17:6; 历代志下 19:3; 历代志下 12:14"> 只是邱坛还没有除去，百姓也还没有立定心意归向他们列祖的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:1; 历代志下 19:2; 列王纪上 16:7"> 约沙法其余的事，从始至终，都写在哈拿尼的儿子耶户的史书上，收录在《以色列诸王记》中。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:48–49; 列王纪下 1:2–16"> 此后，犹大王约沙法与以色列王亚哈谢结盟；亚哈谢行事极其邪恶。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 10:22; 历代志下 9:21; 列王纪上 9:26"> 约沙法与他合伙造船，要往他施去；他们在以旬·迦别造船。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 历代志下 19:2; 历代志下 9:21"> 那时，玛利沙人多大瓦的儿子以利以谢向约沙法预言说：“因为你与亚哈谢结盟，耶和华已经破坏你的工程。”那些船就破裂，不能往他施去了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:64; 以西结 43:13–17; 列王纪上 9:25"> 他又造了一座铜坛，长二十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘约为四十六厘米。">a</a></sup>，宽二十肘，高十肘。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 3:5; 撒迦利亚书 13:1; 出埃及记 30:18–21"> 他又造了一个铸成的海<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译“大盆”或“水池”。">b</a></sup>，从这边缘到那边缘为十肘，形状是圆的，高五肘，周围三十肘。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 1:10; 以西结 10:14; 哥林多前书 9:9–10"> 海的下面有牛的形像，围绕一周，每十肘都有牛像围着海；牛像分两行，是铸海的时候一同铸成的。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:19–20; 启示录 21:14; 马可福音 16:15"> 海安放在十二只牛上：三只朝北，三只朝西，三只朝南，三只朝东；海放在牛背上，牛的后部都朝内。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:26"> 海厚一掌，边缘的样式像杯边，又像百合花；可容纳三千罢特。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一罢特约为二十一点一升；三千罢特约为六万三千三百升。">c</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:38; 出埃及记 30:18–21; 列王纪上 7:40"> 他又造了十个盆，五个放在右边，五个放在左边，用来洗涤；燔祭所用之物就在其中洗涤，但海是给祭司洗涤用的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 25:31–40; 列王纪上 7:49; 约翰福音 8:12"> 他照定例造了十个金灯台，放在殿里，五个在右边，五个在左边。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 7:48; 玛拉基书 1:12; 出埃及记 25:23–30"> 他又造了十张桌子，放在殿里，五张在右边，五张在左边。他又造了一百个金盆。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 6:36; 列王纪下 21:5; 列王纪上 7:12"> 此外，他造了祭司院、大院和院门，又用铜包裹门扇。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 7:39"> 他把海安放在殿的右边，就是东南方。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 7:40–51; 列王纪上 7:14"> 户兰造了锅、铲子和盆。<br />这样，户兰完成了他为所罗门王在上帝殿中所做的工程：</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 7:41; 历代志下 3:15–17"> 两根柱子；柱顶上的球和两个柱冠；遮盖柱顶两个柱冠之球的两片网子；</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 7:20; 列王纪上 7:42; 耶利米书 52:23"> 两片网子的四百个石榴；每片网子有两行石榴，用来遮盖柱子上柱冠的两个球。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 7:27–43"> 他又造了盆座，以及盆座上的盆；</span>
<span className="v" id="v15" data-v="15"> 一个海和海下的十二只牛；</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 2:13; 列王纪上 7:13–14; 历代志下 4:11"> 户兰·亚比<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“亚比”意为“他的父亲”。">d</a></sup>也为所罗门王、为耶和华的殿，用光亮的铜造了锅、铲子、叉子和这一切器具。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:46"> 王在约旦平原，在疏割和洗利达之间的黏土地铸造这些器具。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:47; 耶利米书 52:20; 历代志上 22:14"> 所罗门造了这一切器具，数量极多，铜的重量无法查明。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 9:13; 但以理 5:2–3; 出埃及记 25:23–30"> 所罗门又造了上帝殿里的一切器具：金坛、摆设陈设饼的桌子，</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 4:7; 出埃及记 25:31–37; 列王纪上 6:5"> 纯金的灯台和其上的灯盏，可以照定例在内殿前点燃；</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 6:29; 出埃及记 37:20; 列王纪上 6:35"> 还有花、灯盏和火钳，都是至纯的金子；</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 12:13; 列王纪下 25:14; 耶利米书 52:18"> 又有灯剪、盆、调羹和火鼎，都是纯金的。至于殿的入口，至圣所的内门和殿中正殿的门扇，都是金的。</span>
</div>

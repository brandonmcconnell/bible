<span className="v" id="v1" data-v="1" data-xref="历代志上 3:12; 以赛亚书 1:1; 马太福音 1:9"> 约坦登基的时候二十五岁，在耶路撒冷作王十六年。他母亲名叫耶路沙，是撒督的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 15:34–35; 使徒行传 5:13; 历代志下 26:4"> 他行耶和华眼中看为正的事，照他父亲乌西雅一切所行的；只是他没有进入耶和华的殿。百姓仍然行败坏的事。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:14; 尼希米记 3:26–27; 耶利米书 20:2"> 约坦建造耶和华殿的上门，并在俄斐勒城墙上建造许多工程。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 11:5–10; 历代志下 26:9–10; 约书亚记 14:12–13"> 他又在犹大山地建造城邑，在树林中建造堡垒和城楼。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 11:4–33; 撒母耳记下 10:1–14; 耶利米书 49:1–6"> 他也与亚扪人的王争战，胜过他们。那一年，亚扪人给他一百他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为三十公斤。">a</a></sup>银子、一万歌珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一歌珥约为二百一十一升；一万歌珥小麦约重一千六百四十公吨。">b</a></sup>小麦和一万歌珥大麦。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一万歌珥大麦约重一千三百一十公吨。">c</a></sup>第二年和第三年，亚扪人也照样给他。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 26:5; 历代志下 19:3"> 约坦日渐强大，因为他在耶和华他的上帝面前端正自己的道路。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 26:22–23; 列王纪下 15:36; 历代志下 32:32–33"> 约坦其余的事，以及他一切战争和行迹，看哪，都写在《以色列和犹大诸王记》上。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 27:1"> 他登基的时候二十五岁，在耶路撒冷作王十六年。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 15:38"> 约坦与他列祖同睡，葬在大卫城里；他儿子亚哈斯接替他作王。</span>

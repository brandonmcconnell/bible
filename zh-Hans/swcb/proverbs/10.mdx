<span className="v" id="v5" data-v="5" data-xref="箴言 6:8; 箴言 30:25; 箴言 17:2"> <span className="pl pl-1">夏天收聚的是智慧之子；</span><br /><span className="pl pl-2">收割时沉睡的是贻羞之子。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:2; 箴言 28:20; 约伯记 29:13"> <span className="pl pl-1">福分临到义人的头上；</span><br /><span className="pl pl-2">强暴遮盖恶人的口。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 112:6; 路加福音 1:48; 马可福音 14:9"> <span className="pl pl-1">义人的记念蒙福；</span><br /><span className="pl pl-2">恶人的名字必朽烂。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 7:24–25; 箴言 12:1; 雅各书 3:13"> <span className="pl pl-1">心中有智慧的领受诫命；</span><br /><span className="pl pl-2">喋喋不休的愚昧人必跌倒。</span></span>

<span className="v" id="v10" data-v="10" data-xref="诗篇 35:19; 箴言 6:13; 约翰三书 1:10"> <span className="pl pl-1">以眼传神的人使人忧伤；</span><br /><span className="pl pl-2">喋喋不休的愚昧人必跌倒。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:14; 以弗所书 4:29; 箴言 10:6"> <span className="pl pl-1">义人的口是生命的泉源；</span><br /><span className="pl pl-2">强暴遮盖恶人的口。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:8; 哥林多前书 13:4–7; 箴言 17:9"> <span className="pl pl-1">仇恨挑起纷争；</span><br /><span className="pl pl-2">爱能遮盖一切过错。</span></span>

<span className="v" id="v14" data-v="14" data-xref="箴言 18:7; 箴言 10:8; 箴言 13:3"> <span className="pl pl-1">智慧人积存知识；</span><br /><span className="pl pl-2">愚妄人的口临近毁灭。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 18:11; 箴言 19:7; 诗篇 52:7"> <span className="pl pl-1">富人的财富是他的坚城；</span><br /><span className="pl pl-2">穷人的毁灭是他们的贫乏。</span></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:23; 以赛亚书 3:10–11; 希伯来书 6:10"> <span className="pl pl-1">义人的劳作带来生命；</span><br /><span className="pl pl-2">恶人的收益导致罪。</span></span>
<span className="v" id="v17" data-v="17" data-xref="彼得后书 1:5–11; 路加福音 11:28; 箴言 6:23"> <span className="pl pl-1">谨守管教的，走在生命的道路上；</span><br /><span className="pl pl-2">离弃责备的，使人走迷。</span></span>

<span className="v" id="v19" data-v="19" data-xref="雅各书 1:19; 雅各书 3:2; 箴言 17:27–28"> <span className="pl pl-1">多言之中，悖逆不缺；</span><br /><span className="pl pl-2">约束嘴唇的，是有智慧。</span></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 17:9; 箴言 12:18; 创世记 6:5"> <span className="pl pl-1">义人的舌头如精银；</span><br /><span className="pl pl-2">恶人的心价值微小。</span></span>
<span className="v" id="v21" data-v="21" data-xref="何西阿 4:6; 箴言 17:16; 箴言 1:29"> <span className="pl pl-1">义人的嘴唇滋养多人；</span><br /><span className="pl pl-2">愚妄人因缺乏悟性而死亡。</span></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 107:38; 创世记 26:12; 撒母耳记上 2:7–8"> <span className="pl pl-1">耶和华的赐福使人富足；</span><br /><span className="pl pl-2">祂并不加上忧愁。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:21; 箴言 2:14; 箴言 14:9"> <span className="pl pl-1">行恶是愚昧人的乐趣；</span><br /><span className="pl pl-2">智慧却是有悟性之人的乐趣。</span></span>

<span className="v" id="v32" data-v="32" data-xref="箴言 15:28; 箴言 12:6; 箴言 11:11"> <span className="pl pl-1">义人的嘴唇知道什么是可悦纳的；</span><br /><span className="pl pl-2">恶人的口却乖谬。</span></span>

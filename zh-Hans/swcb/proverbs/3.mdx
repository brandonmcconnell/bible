<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; 约翰福音 14:21–24; 申命记 6:6–9"> <span className="pl pl-1">我儿，不要忘记我的教导，</span><br /><span className="pl pl-2">要让你的心谨守我的诫命；</span></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:1–3; 箴言 4:10; 诗篇 91:16"> <span className="pl pl-1">因为它们必使你日子长久，</span><br /><span className="pl pl-2">增添生命的年岁和平安。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多后书 3:3; 希伯来书 10:16"> <span className="pl pl-1">不可让慈爱和信实离开你。</span><br /><span className="pl pl-2">要把它们系在你的颈项上，</span><br /><span className="pl pl-2">写在你心版上。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 2:52; 撒母耳记上 2:26; 罗马书 14:18"> <span className="pl pl-1">这样，你必在上帝和人眼前蒙恩宠，</span><br /><span className="pl pl-2">得美好的见识。</span></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:5; 耶利米书 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要全心信靠耶和华，</span><br /><span className="pl pl-2">不可倚靠自己的悟性。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 诗篇 32:8; 腓立比书 4:6"> <span className="pl pl-1">在你一切所行的路上都要认定祂，</span><br /><span className="pl pl-2">祂必使你的道路正直。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 罗马书 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以为有智慧。</span><br /><span className="pl pl-2">要敬畏耶和华，远离恶事。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 诗篇 147:3; 箴言 16:24"> <span className="pl pl-1">这必使你的身体健康，</span><br /><span className="pl pl-2">使你的骨头得滋养。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命记 26:2–15; 哥林多前书 16:2; 出埃及记 23:19"> <span className="pl pl-1">你要用你的财物尊荣耶和华，</span><br /><span className="pl pl-2">用你一切出产中初熟的果子尊荣祂；</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命记 28:8; 箴言 22:9"> <span className="pl pl-1">这样，你的仓房必充满丰裕，</span><br /><span className="pl pl-2">你的酒池必有新酒盈溢。</span></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 5:17; 启示录 3:19; 希伯来书 12:5–12"> <span className="pl pl-1">我儿，不要轻看耶和华的管教，</span><br /><span className="pl pl-2">也不要厌烦祂的责备；</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 8:5; 启示录 3:19; 箴言 29:17"> <span className="pl pl-1">因为耶和华所爱的，祂必责备，</span><br /><span className="pl pl-2">正如父亲责备他所喜悦的儿子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 传道书 9:15–18"> <span className="pl pl-1">找到智慧的人有福了，</span><br /><span className="pl pl-2">得着悟性的人有福了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 约伯记 28:13–19"> <span className="pl pl-1">因为得智慧的收益胜过得银子，</span><br /><span className="pl pl-2">它的回报胜过精金。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 约伯记 28:18; 诗篇 73:25–26"> <span className="pl pl-1">智慧比红宝石更宝贵。</span><br /><span className="pl pl-2">凡你所渴慕的，都不能与它相比。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多后书 6:10; 箴言 22:4"> <span className="pl pl-1">长久的日子在它右手中，</span><br /><span className="pl pl-2">财富和尊荣在它左手中。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以赛亚书 26:3; 腓立比书 4:8–9"> <span className="pl pl-1">它的道路是愉悦的道路，</span><br /><span className="pl pl-2">它一切的路径都是平安。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 启示录 2:7; 箴言 15:4"> <span className="pl pl-1">对持定它的人，智慧是生命树。</span><br /><span className="pl pl-2">凡紧握它的，都有福了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:24; 耶利米书 10:12; 约翰福音 1:3"> <span className="pl pl-1">耶和华以智慧奠立大地；</span><br /><span className="pl pl-2">以悟性建立诸天。</span></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 7:11; 诗篇 65:9–12; 约伯记 36:27–28"> <span className="pl pl-1">因祂的知识，深渊裂开，</span><br /><span className="pl pl-2">天空滴下甘露。</span></span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:8; 申命记 6:6–9; 申命记 32:46–47"> <span className="pl pl-1">我儿，不要让它们离开你的眼目。</span><br /><span className="pl pl-2">要持守健全的智慧和明辨；</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以赛亚书 38:16"> <span className="pl pl-1">这样，它们必作你灵魂的生命，</span><br /><span className="pl pl-2">作你颈项上的恩美。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 诗篇 121:3"> <span className="pl pl-1">那时，你必安然行你的路，</span><br /><span className="pl pl-2">你的脚不会绊跌。</span></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 3:5; 诗篇 4:8; 箴言 6:22"> <span className="pl pl-1">你躺卧时，必不惧怕；</span><br /><span className="pl pl-2">是的，你必躺卧，睡得香甜。</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10–14; 诗篇 112:7; 彼得前书 3:14"> <span className="pl pl-1">不要惧怕突来的惊恐，</span><br /><span className="pl pl-2">也不要惧怕恶人遭毁灭的时候临到；</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 91:3; 撒母耳记上 2:9; 箴言 14:26"> <span className="pl pl-1">因为耶和华必作你的倚靠，</span><br /><span className="pl pl-2">祂必保守你的脚不被陷住。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太书 6:10; 雅各书 2:15–16; 罗马书 13:7"> <span className="pl pl-1">行善的对象若理当得善，</span><br /><span className="pl pl-2">而你手中有力量去做，就不可推辞。</span></span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:13; 申命记 24:12–15; 哥林多后书 8:11"> <span className="pl pl-1">你若身边就有，</span><br /><span className="pl pl-2">就不可对邻舍说：“你去吧，改天再来；</span><br /><span className="pl pl-2">明天我会给你。”</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 诗篇 55:20"> <span className="pl pl-1">不可设计恶事陷害你的邻舍，</span><br /><span className="pl pl-2">因他在你身旁安然居住。</span></span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 2:24; 箴言 29:22; 罗马书 12:18–21"> <span className="pl pl-1">若有人没有伤害你，</span><br /><span className="pl pl-2">就不可无故与他争讼。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 诗篇 37:1; 加拉太书 5:21"> <span className="pl pl-1">不可嫉妒强暴的人，</span><br /><span className="pl pl-2">也不可选择他的任何道路。</span></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 25:14; 约翰福音 15:15; 箴言 11:20"> <span className="pl pl-1">因为乖僻的人为耶和华所憎恶，</span><br /><span className="pl pl-2">但祂与正直人亲密相交。</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 37:22; 利未记 26:14–46; 约伯记 8:6–7"> <span className="pl pl-1">耶和华的咒诅在恶人的家中，</span><br /><span className="pl pl-2">祂却赐福给义人的居所。</span></span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:6; 彼得前书 5:5; 诗篇 138:6"> <span className="pl pl-1">祂确实讥笑好讥笑的人，</span><br /><span className="pl pl-2">却赐恩典给谦卑的人。</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 132:18; 以赛亚书 65:13–15; 诗篇 73:24"> <span className="pl pl-1">智慧人必承受荣耀，</span><br /><span className="pl pl-2">愚昧人却以羞辱为高升。</span></span>

<span className="v" id="v4" data-v="4" data-xref="箴言 29:14; 箴言 20:8; 但以理 11:20"> <span className="pl pl-1">王凭公正使国稳固；</span><br /><span className="pl pl-2">收受贿赂的，却使国倾覆。</span></span>
<span className="v" id="v5" data-v="5" data-xref="何西阿 5:1; 约伯记 17:5; 诗篇 5:9"> <span className="pl pl-1">谄媚邻舍的人，</span><br /><span className="pl pl-2">是在他脚前张设网罗。</span></span>

<span className="v" id="v7" data-v="7" data-xref="约伯记 29:16; 诗篇 41:1; 箴言 21:13"> <span className="pl pl-1">义人关心穷人的公义；</span><br /><span className="pl pl-2">恶人却不在意这种认识。</span></span>

<span className="v" id="v11" data-v="11" data-xref="箴言 19:11; 箴言 12:16; 弥迦书 7:5"> <span className="pl pl-1">愚昧人倾吐一切怒气；</span><br /><span className="pl pl-2">智慧人却克制自己。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 20:8; 列王纪下 10:6–7; 诗篇 52:2–4"> <span className="pl pl-1">统治者若听信谎言，</span><br /><span className="pl pl-2">他的臣仆就都成了恶人。</span></span>

<span className="v" id="v14" data-v="14" data-xref="箴言 16:12; 以赛亚书 11:4; 诗篇 72:2–4"> <span className="pl pl-1">王若按公平审判穷人，</span><br /><span className="pl pl-2">他的宝座必永远坚立。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 10:1; 箴言 17:25; 箴言 29:17"> <span className="pl pl-1">管教的杖使人有智慧；</span><br /><span className="pl pl-2">放任自流的孩子使母亲蒙羞。</span></span>

<span className="v" id="v1" data-v="1" data-xref="申命记 28:7; 诗篇 53:5; 以赛亚书 26:3–4"> <span className="pl pl-1">恶人无人追赶也逃跑；</span><br /><span className="pl pl-2">义人却像狮子一样勇敢。</span></span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:28; 列王纪上 16:8–29; 列王纪下 15:8–31"> <span className="pl pl-1">因叛乱，一国有许多统治者；</span><br /><span className="pl pl-2">但借着有聪明和知识的人，秩序得以维持。</span></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 18:28–30"> <span className="pl pl-1">穷乏人欺压贫穷人，</span><br /><span className="pl pl-2">好像暴雨冲刷，使田地不留庄稼。</span></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:32; 以弗所书 5:11; 马太福音 14:4"> <span className="pl pl-1">离弃律法的人称赞恶人；</span><br /><span className="pl pl-2">遵守律法的人却与他们相争。</span></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 92:6; 雅各书 1:5; 约翰一书 2:27"> <span className="pl pl-1">恶人不明白公正；</span><br /><span className="pl pl-2">寻求耶和华的人却完全明白。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; 路加福音 16:19–23"> <span className="pl pl-1">行事纯全的贫穷人，</span><br /><span className="pl pl-2">胜过道路弯曲而富有的人。</span></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:3–4; 箴言 29:3; 箴言 3:1–35"> <span className="pl pl-1">遵守律法的是有智慧的儿子；</span><br /><span className="pl pl-2">与贪食者作伴的，却使父亲蒙羞。</span></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 27:16–17; 箴言 13:22; 传道书 2:26"> <span className="pl pl-1">靠高利增加财富的人，</span><br /><span className="pl pl-2">是为怜悯贫穷人的人积聚。</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 66:18; 提摩太后书 4:3–4; 撒迦利亚书 7:11–13"> <span className="pl pl-1">转耳不听律法的人，</span><br /><span className="pl pl-2">连他的祷告也是可憎的。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 26:27; 诗篇 37:25–26; 加拉太书 2:4"> <span className="pl pl-1">使正直人偏离走恶道的，</span><br /><span className="pl pl-2">必掉进自己的陷阱；</span><br /><span className="pl pl-2">但无可指责的人必承受美福。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 传道书 9:15–17; 箴言 26:16"> <span className="pl pl-1">富人在自己眼中有智慧；</span><br /><span className="pl pl-2">但有聪明的贫穷人能看透他。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">义人得胜时，大有荣耀；</span><br /><span className="pl pl-2">恶人兴起时，人就躲藏。</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 1:8–10; 诗篇 32:3–5; 约伯记 31:33"> <span className="pl pl-1">遮掩自己罪的人不会亨通；</span><br /><span className="pl pl-2">承认并离弃罪的人必蒙怜悯。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 诗篇 2:11; 以赛亚书 66:2"> <span className="pl pl-1">常常敬畏的人有福了；</span><br /><span className="pl pl-2">心里刚硬的人必陷入患难。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 2:16; 箴言 19:12"> <span className="pl pl-1">恶人统治无助的百姓，</span><br /><span className="pl pl-2">如同咆哮的狮子，或猛扑的熊。</span></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:21; 耶利米书 22:15–17; 传道书 4:1"> <span className="pl pl-1">暴虐的统治者缺乏判断力；</span><br /><span className="pl pl-2">恨恶不义之财的人，日子必长久。</span></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 9:6; 列王纪上 21:19; 出埃及记 21:14"> <span className="pl pl-1">背负流血罪咎而受折磨的人，必逃亡直到死亡；</span><br /><span className="pl pl-2">无人扶持他。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; 启示录 3:3"> <span className="pl pl-1">行事无可指责的人必得保守安全；</span><br /><span className="pl pl-2">道路弯曲的人却必突然跌倒。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士师记 9:4; 箴言 27:23–27"> <span className="pl pl-1">耕种自己土地的人必有充足粮食；</span><br /><span className="pl pl-2">追逐虚幻的人必饱尝贫穷。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 16:10–12; 箴言 13:11; 启示录 2:10"> <span className="pl pl-1">忠信的人必多得祝福；</span><br /><span className="pl pl-2">急于发财的人必不免受罚。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 24:23; 箴言 18:5; 以西结 13:19"> <span className="pl pl-1">偏袒人是不好的；</span><br /><span className="pl pl-2">然而人会为一块饼而行恶。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 23:6; 提摩太前书 6:9; 箴言 28:20"> <span className="pl pl-1">吝啬的人急于追求财富，</span><br /><span className="pl pl-2">却不知道贫穷正等着他。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 27:5–6; 马太福音 18:15; 诗篇 141:5"> <span className="pl pl-1">责备人的，后来比用舌头谄媚人的更得喜爱。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 15:4–6; 箴言 18:9; 箴言 19:26"> <span className="pl pl-1">抢夺父母又说“这不是错”的，</span><br /><span className="pl pl-2">是与毁灭者同伙。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 11:25; 提摩太前书 6:6; 箴言 13:10"> <span className="pl pl-1">贪婪的人挑起纷争；</span><br /><span className="pl pl-2">信靠耶和华的人必兴旺。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 3:5; 耶利米书 17:9; 约伯记 28:28"> <span className="pl pl-1">信靠自己的人是愚昧人；</span><br /><span className="pl pl-2">行在智慧中的人必得保守安全。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 19:17; 申命记 15:7; 诗篇 41:1–3"> <span className="pl pl-1">施给贫穷人的，必不缺乏；</span><br /><span className="pl pl-2">掩眼不顾的，必多受咒诅。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 29:2; 约伯记 24:4; 使徒行传 12:23–24"> <span className="pl pl-1">恶人兴起时，人就躲藏；</span><br /><span className="pl pl-2">他们灭亡时，义人就兴盛。</span></span>

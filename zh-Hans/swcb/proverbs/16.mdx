<span className="v" id="v3" data-v="3" data-xref="诗篇 37:4–5; 箴言 3:6; 诗篇 55:22"> <span className="pl pl-1">要把你的行为交托耶和华，</span><br /><span className="pl pl-2">你的计划就必成功。</span></span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 2:9; 罗马书 9:22; 以赛亚书 43:21"> <span className="pl pl-1">耶和华造万物，各有其目的；</span><br /><span className="pl pl-2">就是恶人，也是为灾祸的日子而造。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:16–17; 箴言 11:21; 箴言 8:13"> <span className="pl pl-1">凡心里骄傲的人，都是耶和华所憎恶的；</span><br /><span className="pl pl-2">他们必定不免受罚。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:16; 约伯记 28:28; 哥林多后书 7:1"> <span className="pl pl-1">因慈爱和诚实，罪孽得赎；</span><br /><span className="pl pl-2">因敬畏耶和华，人离开恶事。</span></span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:31; 约翰一书 3:22; 歌罗西书 1:10"> <span className="pl pl-1">人所行的若蒙耶和华喜悦，</span><br /><span className="pl pl-2">祂甚至使他的仇敌与他和好。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 15:16; 诗篇 37:16; 提摩太前书 6:6–9"> <span className="pl pl-1">少有财物而有公义，</span><br /><span className="pl pl-2">胜过多有收入却行不义。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 19:21; 诗篇 37:23; 箴言 16:1"> <span className="pl pl-1">人心筹划自己的道路，</span><br /><span className="pl pl-2">但耶和华指引他的脚步。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 32:1–2; 创世记 44:5; 创世记 44:15"> <span className="pl pl-1">王的嘴唇上有受启示的判语；</span><br /><span className="pl pl-2">审判时，他的口不可失信。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 11:1; 箴言 20:10; 箴言 20:23"> <span className="pl pl-1">公道的天平和秤属于耶和华；</span><br /><span className="pl pl-2">袋中一切法码都是祂所造的。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 25:5; 箴言 29:14; 路加福音 12:48"> <span className="pl pl-1">君王行恶是可憎的，</span><br /><span className="pl pl-2">因为王位靠公义坚立。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 14:35; 诗篇 101:5–7; 箴言 22:11"> <span className="pl pl-1">公义的嘴唇为君王所喜悦；</span><br /><span className="pl pl-2">他们珍重说诚实话的人。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:2; 箴言 19:12; 传道书 10:4"> <span className="pl pl-1">王的烈怒是死亡的使者，</span><br /><span className="pl pl-2">但智慧人能平息它。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 72:6; 约伯记 29:23–24; 何西阿 6:3"> <span className="pl pl-1">王脸上的光中有生命；</span><br /><span className="pl pl-2">他的恩宠好像春雨的云。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 8:10–11; 马太福音 16:26; 箴言 8:19"> <span className="pl pl-1">得智慧胜过黄金，何等美好！</span><br /><span className="pl pl-2">得聪明比白银更当选择。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 35:8; 箴言 19:16; 箴言 10:9"> <span className="pl pl-1">正直人的大道是离开恶事；</span><br /><span className="pl pl-2">谨守自己道路的，保全自己的生命。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:2; 以赛亚书 2:11–12; 箴言 18:12"> <span className="pl pl-1">骄傲在败坏以先，</span><br /><span className="pl pl-2">狂傲的灵在跌倒以前。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:3; 以赛亚书 57:15; 诗篇 138:6"> <span className="pl pl-1">存谦卑的心与贫穷人在一起，</span><br /><span className="pl pl-2">胜过与骄傲人分掠物。</span></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 17:7–8; 诗篇 2:12; 以赛亚书 30:18"> <span className="pl pl-1">留心话语的人，必得亨通；</span><br /><span className="pl pl-2">信靠耶和华的，是有福的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 16:23–24; 以赛亚书 50:4; 箴言 15:7"> <span className="pl pl-1">心中有智慧的，必称为明辨；</span><br /><span className="pl pl-2">嘴唇的甘美增进教导。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 13:14; 约翰福音 6:63; 约翰福音 5:24"> <span className="pl pl-1">聪明是拥有它之人的生命泉源，</span><br /><span className="pl pl-2">但愚昧人的惩罚就是他们的愚昧。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:28; 马太福音 12:34–35; 歌罗西书 3:16"> <span className="pl pl-1">智慧人的心教导他的口，</span><br /><span className="pl pl-2">又给他的嘴唇增添学识。</span></span>

<span className="v" id="v25" data-v="25" data-xref="箴言 14:12; 箴言 12:15; 哥林多后书 13:5"> <span className="pl pl-1">有一条路，人以为正，</span><br /><span className="pl pl-2">至终却通向死亡。</span></span>
<span className="v" id="v26" data-v="26" data-xref="传道书 6:7; 箴言 14:23; 箴言 9:12"> <span className="pl pl-1">劳碌人的胃口为他劳碌，</span><br /><span className="pl pl-2">因为他的口催逼他。</span></span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 3:6; 箴言 6:14; 以赛亚书 5:18"> <span className="pl pl-1">无赖之徒图谋祸害；</span><br /><span className="pl pl-2">他的话如同灼热的火。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 17:9; 箴言 18:8; 箴言 15:18"> <span className="pl pl-1">乖僻人挑起纷争；</span><br /><span className="pl pl-2">传闲话的人离间密友。</span></span>

<span className="v" id="v30" data-v="30" data-xref="马太福音 13:15; 弥迦书 7:3; 马太福音 14:7–8"> <span className="pl pl-1">眨眼图谋乖僻事的人，</span><br /><span className="pl pl-2">紧抿嘴唇的人，定意作恶。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 20:29; 利未记 19:32; 箴言 3:1–2"> <span className="pl pl-1">白发是荣耀的冠冕；</span><br /><span className="pl pl-2">它是在公义的生命中得到的。</span></span>
<span className="v" id="v32" data-v="32" data-xref="雅各书 1:19; 箴言 15:18; 箴言 25:28"> <span className="pl pl-1">不轻易发怒的人胜过勇士；</span><br /><span className="pl pl-2">管束自己心灵的人，胜过攻取城池的人。</span></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 18:18; 约拿 1:7; 使徒行传 1:26"> <span className="pl pl-1">签被掷在怀中，</span><br /><span className="pl pl-2">但它每一个定夺都出于耶和华。</span></span>

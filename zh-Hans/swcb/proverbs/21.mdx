<span className="v" id="v1" data-v="1" data-xref="箴言 16:9; 箴言 20:24; 以斯拉记 6:22"> <span className="pl pl-1">王的心在耶和华手中，好像水道；</span><br /><span className="pl pl-2">祂随自己的心意使它转向。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:2; 箴言 16:25; 路加福音 16:15"> <span className="pl pl-1">人所行的一切，在自己眼中都看为正；</span><br /><span className="pl pl-2">但耶和华衡量人心。</span></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 15:22; 何西阿 6:6; 弥迦书 6:6–8"> <span className="pl pl-1">行公义和公平，</span><br /><span className="pl pl-2">比献祭更蒙耶和华悦纳。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 6:17; 彼得前书 5:5; 以赛亚书 2:17"> <span className="pl pl-1">高傲的眼目和骄傲的心，</span><br /><span className="pl pl-2">恶人的灯，都是罪。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 10:4; 箴言 13:4; 以弗所书 4:28"> <span className="pl pl-1">殷勤人的筹划必带来益处；</span><br /><span className="pl pl-2">凡急躁的人必奔向贫穷。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 13:11; 箴言 10:2; 箴言 20:21"> <span className="pl pl-1">用谎言的舌头得来的财宝，</span><br /><span className="pl pl-2">对寻求死亡的人来说，是转瞬即逝的雾气。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:21; 以弗所书 5:6; 箴言 1:18–19"> <span className="pl pl-1">恶人的强暴必把他们卷走，</span><br /><span className="pl pl-2">因为他们拒绝行正直的事。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:15; 约翰一书 2:29; 诗篇 14:2–3"> <span className="pl pl-1">有罪之人的道路弯曲；</span><br /><span className="pl pl-2">无辜之人的行为正直。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 19:13; 箴言 21:19; 箴言 27:15–16"> <span className="pl pl-1">住在屋顶的角落，</span><br /><span className="pl pl-2">胜过与好争吵的女人同住一屋。</span></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 3:2–3; 箴言 3:29; 诗篇 36:4"> <span className="pl pl-1">恶人的心渴望恶事；</span><br /><span className="pl pl-2">在他眼中，邻舍得不到怜悯。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:25; 箴言 18:15; 箴言 9:9"> <span className="pl pl-1">亵慢人受惩罚，愚蒙人就得智慧；</span><br /><span className="pl pl-2">智慧人受教导，就领受知识。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 14:11; 诗篇 37:35–36; 彼得后书 3:6–7"> <span className="pl pl-1">那位义者察看恶人的家，</span><br /><span className="pl pl-2">使恶人败亡。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 28:27; 马太福音 6:14; 箴言 1:28"> <span className="pl pl-1">谁塞耳不听穷人的呼求，</span><br /><span className="pl pl-2">他自己呼求时，也必不蒙垂听。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:16; 箴言 19:6; 箴言 17:8"> <span className="pl pl-1">暗中的礼物能平息怒气，</span><br /><span className="pl pl-2">怀中的贿赂能止住烈怒。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 10:29; 马太福音 7:23; 马太福音 13:41–42"> <span className="pl pl-1">秉行公平使义人欢喜；</span><br /><span className="pl pl-2">却使作恶的人灭亡。</span></span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 10:38; 诗篇 125:5; 诗篇 49:14"> <span className="pl pl-1">偏离明理之道的人，</span><br /><span className="pl pl-2">必在亡灵的会中安息。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 23:21; 提摩太前书 5:6; 提摩太后书 3:4"> <span className="pl pl-1">喜爱宴乐的，必成为穷人；</span><br /><span className="pl pl-2">喜爱酒和油的，不会富足。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:8; 以赛亚书 43:3–4; 以赛亚书 53:4–5"> <span className="pl pl-1">恶人作义人的赎价，</span><br /><span className="pl pl-2">奸诈人代替正直人。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:9; 诗篇 120:5–6; 诗篇 55:6–7"> <span className="pl pl-1">住在旷野之地，</span><br /><span className="pl pl-2">胜过与好争吵、易恼怒的女人同住。</span></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:3–4; 诗篇 112:3; 传道书 7:11"> <span className="pl pl-1">智慧人的居所中有宝贵的财物和油；</span><br /><span className="pl pl-2">愚昧人却把它吞尽。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:6; 哥林多前书 15:58; 箴言 22:4"> <span className="pl pl-1">追求公义和慈爱的人，</span><br /><span className="pl pl-2">必得生命、公义和尊荣。</span></span>
<span className="v" id="v22" data-v="22" data-xref="传道书 7:19; 箴言 24:5; 传道书 9:13–18"> <span className="pl pl-1">智慧人登上勇士的城，</span><br /><span className="pl pl-2">拆毁他们所倚靠的坚固。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 13:3; 箴言 18:21; 雅各书 1:26"> <span className="pl pl-1">谨守口与舌的人，</span><br /><span className="pl pl-2">保守自己的生命免遭患难。</span></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 1:1; 箴言 18:12; 箴言 1:22"> <span className="pl pl-1">骄傲狂妄的人——他的名字叫“亵慢人”——</span><br /><span className="pl pl-2">行事带着骄傲的狂妄。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 13:4; 箴言 12:24; 马太福音 25:26"> <span className="pl pl-1">懒惰人的欲望害死他，</span><br /><span className="pl pl-2">因为他的手拒绝劳作。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 37:26; 使徒行传 20:33–35; 以弗所书 4:28"> <span className="pl pl-1">有人终日贪婪地贪求；</span><br /><span className="pl pl-2">义人却施舍，并不吝惜。</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 66:3; 箴言 15:8; 耶利米书 6:20"> <span className="pl pl-1">恶人的祭物是可憎的——</span><br /><span className="pl pl-2">何况他存着邪恶的心意献上呢！</span></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多后书 4:13; 箴言 19:5; 箴言 19:9"> <span className="pl pl-1">作假见证的必灭亡；</span><br /><span className="pl pl-2">听从的人说话却存到永远。</span></span>
<span className="v" id="v29" data-v="29" data-xref="帖撒罗尼迦前书 3:11; 箴言 11:5; 哈该书 2:18–19"> <span className="pl pl-1">恶人厚着脸皮；</span><br /><span className="pl pl-2">至于正直人，他坚定自己的道路。</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 19:21; 使徒行传 5:39; 耶利米书 9:23"> <span className="pl pl-1">没有智慧、没有聪明，</span><br /><span className="pl pl-2">也没有谋略能敌挡耶和华。</span></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 20:7; 以赛亚书 31:1; 诗篇 33:17–18"> <span className="pl pl-1">马是为争战的日子预备的；</span><br /><span className="pl pl-2">但得胜在于耶和华。</span></span>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 10:1; 历代志上 22:9; 历代志上 28:5"> 以色列王、大卫的儿子所罗门的箴言：</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 7:4; 申命记 4:5–6; 提摩太后书 3:15–17"> <span className="pl pl-1">为要使人认识智慧和训诲，</span><br /><span className="pl pl-2">分辨有悟性的言语；</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; 约伯记 22:22; 箴言 8:10–11"> <span className="pl pl-1">领受明智处世的训诲，</span><br /><span className="pl pl-2">行公义、公正和公平；</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 诗篇 119:9"> <span className="pl pl-1">使愚蒙人有精明，</span><br /><span className="pl pl-2">使少年人有知识和谨慎——</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; 哥林多前书 10:15"> <span className="pl pl-1">使智慧人听了，就增长学问；</span><br /><span className="pl pl-2">使有悟性的人获得明智的谋略；</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:2; 马可福音 4:11; 诗篇 49:4"> <span className="pl pl-1">使人明白箴言和譬喻，</span><br /><span className="pl pl-2">懂得智慧人的言语和谜语。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 诗篇 111:10–1; 传道书 12:13"> <span className="pl pl-1">敬畏耶和华</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在英文中以全大写字母呈现时，“LORD”或“GOD”是上帝专有名字（希伯来文“יהוה”，通常读作“雅威”）的译法。">a</a></sup><br /><span className="pl pl-1">是知识的开端，</span><br /><span className="pl pl-2">但愚昧人藐视智慧和训诲。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">我儿，要听你父亲的训诲，</span><br /><span className="pl pl-2">不要离弃你母亲的教导；</span></span>
<span className="v" id="v9" data-v="9" data-xref="但以理 5:29; 箴言 4:9; 创世记 41:42"> <span className="pl pl-1">因为它们要作你头上增光的花环，</span><br /><span className="pl pl-2">作你颈项上的项链。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 5:11; 箴言 16:29; 诗篇 1:1"> <span className="pl pl-1">我儿，若罪人引诱你，</span><br /><span className="pl pl-2">不要答应。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">他们若说：“跟我们来吧。</span><br /><span className="pl pl-2">我们埋伏要害人流血。</span><br /><span className="pl pl-2">我们无缘无故暗算无辜的人。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 124:3; 诗篇 28:1; 罗马书 3:13"> <span className="pl pl-1">我们要像阴间</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup><br /><span className="pl pl-1">一样把他们活活吞下，</span><br /><span className="pl pl-2">完整地吞下，像下到坑里的人一样。</span></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 6:9–10; 路加福音 12:15; 约伯记 24:2–3"> <span className="pl pl-1">我们必找到各样贵重的财物。</span><br /><span className="pl pl-2">我们必用掠物装满我们的房屋。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">你要在我们中间投你的签。</span><br /><span className="pl pl-2">我们大家共用一个钱袋”——</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:101; 诗篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">我儿，不要跟他们走同一条路。</span><br /><span className="pl pl-2">要使你的脚远离他们的路径，</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">因为他们的脚奔向邪恶，</span><br /><span className="pl pl-2">急速去流人的血。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 35:11; 箴言 7:23; 耶利米书 8:7"> <span className="pl pl-1">在任何飞鸟眼前张网，都是徒然；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 9:16; 以斯帖记 7:10; 箴言 5:22–23"> <span className="pl pl-1">这些人却埋伏要流自己的血。</span><br /><span className="pl pl-2">他们暗中潜伏，是要害自己的性命。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; 彼得后书 2:3; 雅各书 5:1–4"> <span className="pl pl-1">凡贪图财利之人的道路都是这样；</span><br /><span className="pl pl-2">这样的财利夺去其主人的生命。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; 歌罗西书 2:3; 路加福音 11:49"> <span className="pl pl-1">智慧在街上高声呼喊，</span><br /><span className="pl pl-2">在广场上发声。</span></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:20; 箴言 9:3; 马太福音 13:2"> <span className="pl pl-1">智慧在喧闹处的显要地方呼叫；</span><br /><span className="pl pl-2">在城门口，在城门入口，宣告自己的话：</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 诗篇 1:1; 箴言 5:12"> <span className="pl pl-1">“你们愚蒙人喜爱愚蒙，要到几时呢？</span><br /><span className="pl pl-2">好讥诮的人以讥诮为乐，</span><br /><span className="pl pl-2">愚昧人恨恶知识，要到几时呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 以西结 33:11; 以西结 18:27–30"> <span className="pl pl-1">你们要因我的责备回转。</span><br /><span className="pl pl-2">看哪，</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”译自“הִנֵּה”，意思是看、留意、观察、观看或注视。它常用作感叹语。">c</a></sup><br /><span className="pl pl-2">我要将我的灵浇灌给你们。</span><br /><span className="pl pl-2">我要使你们明白我的话。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:12; 罗马书 10:21; 耶利米书 7:13"> <span className="pl pl-1">因为我呼唤，你们却拒绝；</span><br /><span className="pl pl-2">我伸出我的手，却无人理会；</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:11; 路加福音 7:30; 箴言 1:30"> <span className="pl pl-1">你们反倒轻忽我一切的劝告，</span><br /><span className="pl pl-2">不肯接受我的责备；</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:4; 箴言 10:24; 诗篇 37:13"> <span className="pl pl-1">所以你们遭灾时，我也要发笑。</span><br /><span className="pl pl-2">灾祸临到你们时，我要讥笑，</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; 路加福音 21:34–35; 诗篇 58:9"> <span className="pl pl-1">当灾祸像暴风临到你们，</span><br /><span className="pl pl-2">当你们的灾难如旋风来到，</span><br /><span className="pl pl-2">当患难和痛苦临到你们。</span></span>
<span className="v" id="v28" data-v="28" data-xref="弥迦书 3:4; 雅各书 4:3; 耶利米书 11:11"> <span className="pl pl-1">那时他们要呼求我，我却不回答；</span><br /><span className="pl pl-2">他们要殷勤寻找我，却找不到我，</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; 约伯记 21:14–15; 箴言 6:23"> <span className="pl pl-1">因为他们恨恶知识，</span><br /><span className="pl pl-2">没有选择敬畏耶和华。</span></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 81:11; 箴言 1:25; 路加福音 14:18–20"> <span className="pl pl-1">他们不肯接受我的劝告，</span><br /><span className="pl pl-2">藐视我一切的责备。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 14:14; 耶利米书 6:19; 箴言 22:8"> <span className="pl pl-1">因此，他们要吃自己道路所结的果子，</span><br /><span className="pl pl-2">饱尝自己的计谋。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 8:36; 耶利米书 2:19; 约翰福音 3:36"> <span className="pl pl-1">因为愚蒙人的背离必杀害他们，</span><br /><span className="pl pl-2">愚昧人的安逸自满必毁灭他们。</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 25:12–13; 诗篇 112:7–8; 以赛亚书 26:3"> <span className="pl pl-1">但凡听从我的，必安然居住，</span><br /><span className="pl pl-2">安逸无忧，不怕灾祸。”</span></span>
</div>

<span className="v" id="v1" data-v="1" data-xref="箴言 10:12; 箴言 25:15; 箴言 15:18"> <span className="pl pl-1">柔和的回答使怒气消退，</span><br /><span className="pl pl-2">暴戾的话语激起愤怒。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 12:23; 箴言 15:28; 箴言 13:16"> <span className="pl pl-1">智慧人的舌头善于表达知识，</span><br /><span className="pl pl-2">愚昧人的口却涌出愚妄。</span></span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 4:13; 耶利米书 16:17; 耶利米书 23:24"> <span className="pl pl-1">耶和华的眼目无处不在，</span><br /><span className="pl pl-2">鉴察恶人和善人。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 12:18; 箴言 16:24; 箴言 18:8"> <span className="pl pl-1">温良的舌头是生命树，</span><br /><span className="pl pl-2">舌中的诡诈却压伤人的灵。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 箴言 13:1; 箴言 13:18"> <span className="pl pl-1">愚昧人藐视父亲的管教，</span><br /><span className="pl pl-2">留心责备的人却显出明智。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:21; 箴言 21:20; 箴言 10:22"> <span className="pl pl-1">义人的家中有许多财宝，</span><br /><span className="pl pl-2">恶人的进项却带来患难。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:34; 雅各书 3:6; 以弗所书 4:29"> <span className="pl pl-1">智慧人的嘴唇传播知识；</span><br /><span className="pl pl-2">愚昧人的心却不是这样。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 15:29; 箴言 21:27; 历代志上 29:17"> <span className="pl pl-1">恶人所献的祭是耶和华所憎恶的，</span><br /><span className="pl pl-2">正直人的祷告却是祂所喜悦的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 6:11; 箴言 21:21; 马太福音 7:13"> <span className="pl pl-1">恶人的道路是耶和华所憎恶的，</span><br /><span className="pl pl-2">追求公义的人却为祂所爱。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 12:1; 约翰福音 3:20; 箴言 13:1"> <span className="pl pl-1">离弃正道的人必受严厉的管教；</span><br /><span className="pl pl-2">恨恶责备的人必死亡。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 44:21; 希伯来书 4:13; 诗篇 139:8"> <span className="pl pl-1">阴间</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup><br /><span className="pl pl-1">和亚巴顿都在耶和华面前，</span><br /><span className="pl pl-2">何况世人的心呢！</span></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司 5:10; 约伯记 21:14; 箴言 9:7–8"> <span className="pl pl-1">嘲讽的人不爱受责备；</span><br /><span className="pl pl-2">他也不去找智慧人。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 17:22; 约翰福音 14:1; 箴言 18:14"> <span className="pl pl-1">喜乐的心使面容欢快，</span><br /><span className="pl pl-2">心中忧伤使灵破碎。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 9:9; 以赛亚书 30:10; 箴言 18:15"> <span className="pl pl-1">聪明人的心寻求知识，</span><br /><span className="pl pl-2">愚昧人的口却以愚妄为食。</span></span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 6:10; 罗马书 12:12; 箴言 15:13"> <span className="pl pl-1">困苦人的日子尽都愁苦，</span><br /><span className="pl pl-2">心中欢快的人常享筵席。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 诗篇 37:16; 传道书 5:10–12"> <span className="pl pl-1">少有财物而敬畏耶和华，</span><br /><span className="pl pl-2">胜过多有财宝却伴随烦乱。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:1; 箴言 21:19; 约翰一书 4:16"> <span className="pl pl-1">有爱相伴的蔬菜饭，</span><br /><span className="pl pl-2">胜过带着仇恨的肥牛犊。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:1; 箴言 26:21; 箴言 29:22"> <span className="pl pl-1">暴怒的人挑起纷争，</span><br /><span className="pl pl-2">不轻易发怒的人平息争端。</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 35:8; 箴言 22:5; 以赛亚书 30:21"> <span className="pl pl-1">懒惰人的道路像荆棘丛，</span><br /><span className="pl pl-2">正直人的路径却是平坦大道。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 29:3; 箴言 10:1; 箴言 23:15–16"> <span className="pl pl-1">智慧的儿子使父亲欢喜，</span><br /><span className="pl pl-2">愚昧的人却藐视母亲。</span></span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 5:15; 箴言 10:23; 箴言 14:16"> <span className="pl pl-1">愚妄使无智慧的人喜乐，</span><br /><span className="pl pl-2">聪明人却使自己的道路正直。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 11:14; 箴言 20:18; 传道书 8:6"> <span className="pl pl-1">没有商议，计划就失败；</span><br /><span className="pl pl-2">谋士众多，计划便立定。</span></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 50:4; 箴言 25:11–12; 以弗所书 4:29"> <span className="pl pl-1">人因口中的回应而得喜乐。</span><br /><span className="pl pl-2">合时的话何等美好！</span></span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:1–2; 诗篇 16:11; 马太福音 7:14"> <span className="pl pl-1">生命的路径为智慧人向上引导，</span><br /><span className="pl pl-2">使他免得下到阴间。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 146:9; 诗篇 68:5–6; 箴言 14:11"> <span className="pl pl-1">耶和华必拔除骄傲人的家，</span><br /><span className="pl pl-2">却必保全寡妇的地界。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 6:16–19; 耶利米书 4:14; 箴言 15:23"> <span className="pl pl-1">恶人的意念是耶和华所厌恶的，</span><br /><span className="pl pl-2">纯洁人的意念却令人喜悦。</span></span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 23:8; 箴言 1:19; 耶利米书 17:11"> <span className="pl pl-1">贪图不义之财的人使自己的家受连累，</span><br /><span className="pl pl-2">恨恶贿赂的人必存活。</span></span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 3:15; 箴言 29:11; 传道书 5:2"> <span className="pl pl-1">义人的心衡量怎样回答，</span><br /><span className="pl pl-2">恶人的口却涌出恶言。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 9:31; 诗篇 145:18–19; 箴言 15:8"> <span className="pl pl-1">耶和华远离恶人，</span><br /><span className="pl pl-2">却垂听义人的祷告。</span></span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 58:11; 启示录 22:5; 启示录 21:23"> <span className="pl pl-1">眼中的光使心欢喜；</span><br /><span className="pl pl-2">好消息使骨头健壮。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 15:5; 箴言 25:12; 约翰福音 15:3–4"> <span className="pl pl-1">听从生命责备的耳朵，</span><br /><span className="pl pl-2">必住在智慧人中。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 1:24–33; 启示录 3:19; 箴言 1:7"> <span className="pl pl-1">拒绝管教的人藐视自己的灵魂，</span><br /><span className="pl pl-2">听从责备的人获得聪明。</span></span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 5:5; 箴言 18:12; 箴言 1:7"> <span className="pl pl-1">敬畏耶和华教导人智慧；</span><br /><span className="pl pl-2">尊荣以前，必有谦卑。</span></span>

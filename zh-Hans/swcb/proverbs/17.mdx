<span className="v" id="v1" data-v="1" data-xref="箴言 15:17; 诗篇 37:16; 箴言 21:19"> <span className="pl pl-1">干饼一块而安静，</span><br /><span className="pl pl-2">胜过满屋宴席却相争。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 10:5; 传道书 4:13; 箴言 14:35"> <span className="pl pl-1">行事明智的仆人必管辖贻羞之子，</span><br /><span className="pl pl-2">并在弟兄中同分产业。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 48:10; 耶利米书 17:10; 诗篇 26:2"> <span className="pl pl-1">炼银有坩埚，炼金有炉；</span><br /><span className="pl pl-2">惟有耶和华试炼人心。</span></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 4:3–4; 约翰一书 4:5; 箴言 28:4"> <span className="pl pl-1">作恶的人留心邪恶的嘴唇；</span><br /><span className="pl pl-2">说谎的人侧耳听恶毒的舌头。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 14:31; 约伯记 31:29; 约翰一书 3:17"> <span className="pl pl-1">嘲笑穷人的，是羞辱造他的主；</span><br /><span className="pl pl-2">幸灾乐祸的，必不免受罚。</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 127:3–5; 箴言 13:22; 箴言 16:31"> <span className="pl pl-1">孙辈是老人的冠冕；</span><br /><span className="pl pl-2">父母是儿女的荣耀。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:12; 箴言 12:19; 诗篇 50:16–17"> <span className="pl pl-1">高尚的话不适合愚昧人，</span><br /><span className="pl pl-2">何况说谎的嘴唇更不适合首领。</span></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 23:8; 弥迦书 7:3; 撒母耳记上 25:35"> <span className="pl pl-1">贿赂在馈赠者眼中像宝石；</span><br /><span className="pl pl-2">他无论转向哪里，都亨通。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 10:12; 彼得前书 4:8; 箴言 16:28"> <span className="pl pl-1">遮掩过犯的，是促进爱；</span><br /><span className="pl pl-2">反复提起旧事的，离间密友。</span></span>
<span className="v" id="v10" data-v="10" data-xref="启示录 3:19; 箴言 9:8–9; 箴言 15:5"> <span className="pl pl-1">一句责备深入明达人，</span><br /><span className="pl pl-2">胜过责打愚昧人一百下。</span></span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 2:46; 撒母耳记下 16:5–9; 撒母耳记下 18:15"> <span className="pl pl-1">恶人只寻求悖逆；</span><br /><span className="pl pl-2">所以必有残酷的使者奉派攻击他。</span></span>
<span className="v" id="v12" data-v="12" data-xref="何西阿 13:8; 撒母耳记下 17:8; 箴言 28:15"> <span className="pl pl-1">宁可让人遇见被夺去幼崽的母熊，</span><br /><span className="pl pl-2">也不要遇见正在愚妄中的愚昧人。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 109:4–13; 彼得前书 3:9; 罗马书 12:17"> <span className="pl pl-1">以恶报善的，</span><br /><span className="pl pl-2">灾祸必不离开他的家。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:3; 箴言 25:8; 提摩太后书 2:23–24"> <span className="pl pl-1">纷争的开始如同决堤；</span><br /><span className="pl pl-2">所以争吵爆发以前，要止息争端。</span></span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 23:7; 箴言 18:5; 以赛亚书 5:23"> <span className="pl pl-1">称恶人为义的，和定义人为有罪的，</span><br /><span className="pl pl-2">二者同样为耶和华所憎恶。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 21:25–26; 箴言 23:23; 箴言 18:15"> <span className="pl pl-1">愚昧人既无悟性，</span><br /><span className="pl pl-2">手中为何有钱买智慧呢？</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 约翰福音 15:13–14; 撒母耳记上 20:17"> <span className="pl pl-1">朋友时时相爱；</span><br /><span className="pl pl-2">弟兄为患难而生。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:15; 箴言 6:1–5; 箴言 22:26–27"> <span className="pl pl-1">无知的人击掌作保，</span><br /><span className="pl pl-2">在邻舍面前作担保。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 16:18; 箴言 18:12; 撒母耳记上 25:36–38"> <span className="pl pl-1">喜爱悖逆的，就是喜爱纷争；</span><br /><span className="pl pl-2">把门建高的，是寻求毁灭。</span></span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 3:6–8; 箴言 10:31; 箴言 6:12–15"> <span className="pl pl-1">心里乖僻的，得不着福祉；</span><br /><span className="pl pl-2">舌头诡诈的，陷入祸患。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 10:1; 箴言 19:13; 箴言 17:25"> <span className="pl pl-1">生愚昧儿子的，必忧伤；</span><br /><span className="pl pl-2">愚昧人的父亲毫无喜乐。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 15:13; 箴言 12:25; 箴言 18:14"> <span className="pl pl-1">喜乐的心是良药；</span><br /><span className="pl pl-2">忧伤的灵使骨头枯干。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 17:8; 申命记 16:19; 出埃及记 23:8"> <span className="pl pl-1">恶人在暗中收受贿赂，</span><br /><span className="pl pl-2">为要扭曲公正的道路。</span></span>
<span className="v" id="v24" data-v="24" data-xref="传道书 2:14; 传道书 8:1; 箴言 14:6"> <span className="pl pl-1">智慧在明达人面前；</span><br /><span className="pl pl-2">愚昧人的眼睛却游荡到地极。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:1; 撒母耳记下 13:1–22; 箴言 19:13"> <span className="pl pl-1">愚昧的儿子使父亲忧愁，</span><br /><span className="pl pl-2">使生他的母亲痛苦。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 17:15; 箴言 18:5; 约翰福音 18:22"> <span className="pl pl-1">惩罚义人固然不好，</span><br /><span className="pl pl-2">因官员正直而鞭打他们也不合宜。</span></span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 3:18; 雅各书 1:19; 箴言 10:19"> <span className="pl pl-1">节制言语的有知识；</span><br /><span className="pl pl-2">性情冷静的是明达人。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 13:5; 箴言 15:2; 传道书 10:14"> <span className="pl pl-1">愚昧人若静默不言，也算为有智慧；</span><br /><span className="pl pl-2">他闭口不语，就被看为有明辨。</span></span>

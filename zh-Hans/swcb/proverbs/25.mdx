<span className="v" id="v2" data-v="2" data-xref="申命记 29:29; 罗马书 11:33–34; 约伯记 11:7–8"> <span className="pl pl-1">将事情隐藏是上帝的荣耀，</span><br /><span className="pl pl-2">将事情查明是君王的荣耀。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 55:9; 诗篇 103:11; 列王纪上 4:29"> <span className="pl pl-1">天之高，地之深，</span><br /><span className="pl pl-2">君王的心也照样测不透。</span></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 2:20–21; 以西结 22:18; 箴言 17:3"> <span className="pl pl-1">除去银子的渣滓，</span><br /><span className="pl pl-2">材料就出来，可供银匠使用。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:12; 箴言 20:8; 诗篇 101:7–8"> <span className="pl pl-1">除去王面前的恶人，</span><br /><span className="pl pl-2">他的宝座就必因公义得坚立。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 27:2; 箴言 25:27; 箴言 16:19"> <span className="pl pl-1">不要在王面前自高，</span><br /><span className="pl pl-2">也不要在大人物中间占据位置；</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:7–11; 路加福音 18:14; 彼得前书 5:5"> <span className="pl pl-1">因为有人对你说：“请上到这里来”，</span><br /><span className="pl pl-2">胜过你在尊贵人面前被降到低位，</span><br /><span className="pl pl-2">就是在你亲眼所见的人面前。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:25; 箴言 17:14; 箴言 18:6"> <span className="pl pl-1">不要急忙把争讼带到法庭。</span><br /><span className="pl pl-2">到了最后，你的邻舍羞辱你，你要怎么办呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 18:5–17; 箴言 11:13; 箴言 20:19"> <span className="pl pl-1">要与你的邻舍辩明你的案件，</span><br /><span className="pl pl-2">不可泄露别人的秘密，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 119:39"> <span className="pl pl-2">免得听见的人使你蒙羞，</span><br /><span className="pl pl-2">你的坏名声就永不离开。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 15:23; 以赛亚书 50:4; 传道书 12:10"> <span className="pl pl-1">一句话说得合宜，</span><br /><span className="pl pl-2">就像银器中镶嵌的金苹果。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 141:5; 箴言 15:31–32; 箴言 15:5"> <span className="pl pl-1">智慧人的责备临到听从的耳，</span><br /><span className="pl pl-2">就像金耳环和精金的饰物。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:17; 箴言 25:25; 腓立比书 2:25–30"> <span className="pl pl-1">忠信的使者对差派他的人，</span><br /><span className="pl pl-2">就像收割时节有雪的清凉；</span><br /><span className="pl pl-2">因为他使主人的心舒畅。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:6; 路加福音 14:11; 彼得后书 2:15–19"> <span className="pl pl-1">空夸虚假礼物的人，</span><br /><span className="pl pl-2">就像有云有风却没有雨。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 15:1; 传道书 10:4; 箴言 16:14"> <span className="pl pl-1">借着耐心，掌权者可以被说服。</span><br /><span className="pl pl-2">柔和的舌能折断骨头。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 25:27; 以弗所书 5:18; 箴言 24:13–14"> <span className="pl pl-1">你找到蜂蜜了吗？</span><br /><span className="pl pl-2">只吃够你所需的，</span><br /><span className="pl pl-2">免得吃得过多，就吐出来。</span></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 19:2–3; 士师记 19:18–21; 罗马书 15:24"> <span className="pl pl-1">你的脚要少进邻舍的家，</span><br /><span className="pl pl-2">免得他厌烦你，恨恶你。</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 57:4; 箴言 12:18; 雅各书 3:6"> <span className="pl pl-1">作假见证陷害邻舍的人，</span><br /><span className="pl pl-2">就像棍棒、刀剑，或利箭。</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:6; 以西结 29:6–7; 约伯记 6:14–20"> <span className="pl pl-1">患难之日倚靠不忠信的人，</span><br /><span className="pl pl-2">就像坏牙或瘸脚。</span></span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:15; 传道书 3:4; 以赛亚书 58:7"> <span className="pl pl-1">对忧伤的心唱歌，</span><br /><span className="pl pl-2">就像寒冷天脱去衣服，</span><br /><span className="pl pl-2">又像把醋倒在碱上。</span></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:20–21; 马太福音 5:44; 出埃及记 23:4–5"> <span className="pl pl-1">如果你的仇敌饿了，就给他食物吃；</span><br /><span className="pl pl-2">如果他渴了，就给他水喝；</span></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 16:12; 马太福音 10:13; 哥林多前书 15:18"> <span className="pl pl-1">因为你这样是把炭火堆在他的头上，</span><br /><span className="pl pl-2">耶和华也必报答你。</span></span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 37:22; 诗篇 15:3; 罗马书 1:30"> <span className="pl pl-1">北风带来雨；</span><br /><span className="pl pl-2">暗中毁谤的舌头也带来怒容。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 21:19; 箴言 21:9; 箴言 27:15–16"> <span className="pl pl-1">宁可住在屋顶的角落，</span><br /><span className="pl pl-2">也不与好争吵的妇人同住一屋。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:30; 罗马书 10:15; 诗篇 63:1"> <span className="pl pl-1">从远方来的好消息，</span><br /><span className="pl pl-2">就像凉水给口渴的人。</span></span>
<span className="v" id="v26" data-v="26" data-xref="以西结 34:18–19; 撒母耳记上 22:14–18; 帖撒罗尼迦前书 2:15"> <span className="pl pl-1">义人在恶人面前退让，</span><br /><span className="pl pl-2">就像浑浊的泉源和被污染的井。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 5:44; 箴言 27:2; 腓立比书 2:3"> <span className="pl pl-1">吃蜜过多不好，</span><br /><span className="pl pl-2">寻求自己的荣耀也并非荣耀。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 16:32; 箴言 22:24; 历代志下 32:5"> <span className="pl pl-1">心灵毫无约束的人，</span><br /><span className="pl pl-2">就像被攻破、没有城墙的城。</span></span>

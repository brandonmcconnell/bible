<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="申命记 25:13–16; 箴言 16:11; 箴言 20:23"> <span className="pl pl-1">虚假的天平是耶和华所憎恶的，</span><br /><span className="pl pl-2">准确的法码却是祂所喜悦的。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:23; 箴言 15:33; 箴言 16:18–19"> <span className="pl pl-1">骄傲来到，羞辱也随之而来；</span><br /><span className="pl pl-2">谦卑的人却有智慧。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:6; 箴言 28:18; 诗篇 26:1"> <span className="pl pl-1">正直人的纯全必引导他们；</span><br /><span className="pl pl-2">奸诈人的乖僻必毁灭他们。</span></span>
<span className="v" id="v4" data-v="4" data-xref="西番雅书 1:18; 箴言 10:2; 创世记 7:1"> <span className="pl pl-1">财富在震怒的日子毫无益处，</span><br /><span className="pl pl-2">公义却能救人脱离死亡。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 5:22; 诗篇 9:15–16; 箴言 1:31–32"> <span className="pl pl-1">无可指摘之人的义必修直他的道路；</span><br /><span className="pl pl-2">恶人却必因自己的邪恶跌倒。</span></span>
<span className="v" id="v6" data-v="6" data-xref="传道书 10:8; 列王纪上 2:44; 诗篇 7:15–16"> <span className="pl pl-1">正直人的义必拯救他们；</span><br /><span className="pl pl-2">不忠信的人却必被恶欲困住。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 10:28; 约伯记 8:13–14; 约伯记 11:20"> <span className="pl pl-1">恶人一死，指望就灭没；</span><br /><span className="pl pl-2">权势的期望也归于无有。</span></span>
<span className="v" id="v8" data-v="8" data-xref="但以理 6:23–24; 箴言 21:18; 以斯帖记 7:9–10"> <span className="pl pl-1">义人蒙拯救脱离患难，</span><br /><span className="pl pl-2">恶人却来代替他的位置。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 2:10–16; 箴言 4:5–6; 约翰一书 2:27"> <span className="pl pl-1">不敬虔的人用口毁坏邻舍，</span><br /><span className="pl pl-2">义人却借着知识得拯救。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:12; 以斯帖记 8:15–16; 诗篇 58:10–11"> <span className="pl pl-1">义人亨通，城就欢喜；</span><br /><span className="pl pl-2">恶人灭亡，众人就欢呼。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 14:34; 箴言 29:8; 雅各书 3:6"> <span className="pl pl-1">因正直人的祝福，城得高升；</span><br /><span className="pl pl-2">因恶人的口，城被倾覆。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 10:19; 彼得前书 2:23; 路加福音 18:9"> <span className="pl pl-1">藐视邻舍的人缺乏智慧；</span><br /><span className="pl pl-2">有聪明的人却静默不言。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 箴言 25:9; 利未记 19:16"> <span className="pl pl-1">搬弄是非的人泄露秘密；</span><br /><span className="pl pl-2">心灵可靠的人却保守隐情。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 24:6; 箴言 15:22; 箴言 20:18"> <span className="pl pl-1">没有明智的指导，国家就败落；</span><br /><span className="pl pl-2">谋士众多，就有胜利。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 17:18; 箴言 6:1–5; 箴言 22:26–27"> <span className="pl pl-1">为陌生人作保的，必为此受害；</span><br /><span className="pl pl-2">拒绝担保的人却安稳。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 31:30–31; 路加福音 10:42; 使徒行传 16:14–15"> <span className="pl pl-1">有恩德的女子获得尊荣，</span><br /><span className="pl pl-2">强暴的人获得财富。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:7; 马太福音 25:34–40; 雅各书 2:13"> <span className="pl pl-1">怜悯人的人善待自己的灵魂；</span><br /><span className="pl pl-2">残忍的人却使自己的肉身受害。</span></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 6:8–9; 传道书 10:8; 何西阿 10:12–13"> <span className="pl pl-1">恶人赚得虚假的工价；</span><br /><span className="pl pl-2">撒播公义的人收获可靠的赏赐。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 10:16; 罗马书 2:8–9; 箴言 12:28"> <span className="pl pl-1">真正行义的人得生命；</span><br /><span className="pl pl-2">追求邪恶的人得死亡。</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 119:1; 箴言 21:29; 历代志上 29:17"> <span className="pl pl-1">心中乖僻的人是耶和华所憎恶的；</span><br /><span className="pl pl-2">行事无可指摘的人是祂所喜悦的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 112:1–2; 使徒行传 2:39; 耶利米书 32:39"> <span className="pl pl-1">你要确知，恶人必不免受惩罚；</span><br /><span className="pl pl-2">义人的后裔</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“种子”">a</a></sup><br /><span className="pl pl-2">必蒙拯救。</span></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 3:3–4; 箴言 31:30; 那鸿书 3:4–6"> <span className="pl pl-1">美貌女子缺乏明辨，</span><br /><span className="pl pl-2">如同金环戴在猪鼻上。</span></span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 37:4; 罗马书 2:8–9; 马太福音 5:6"> <span className="pl pl-1">义人的愿望只归于善；</span><br /><span className="pl pl-2">恶人的期望却是震怒。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 19:17; 路加福音 6:38; 申命记 15:10"> <span className="pl pl-1">有人施散，反而更加增多；</span><br /><span className="pl pl-2">有人过分吝惜，反致贫穷。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 5:7; 哥林多后书 9:6–9; 以赛亚书 58:7–11"> <span className="pl pl-1">慷慨的人必得丰裕；</span><br /><span className="pl pl-2">滋润人的，自己也必得滋润。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约伯记 29:13; 创世记 42:6; 阿摩司 8:4–6"> <span className="pl pl-1">囤积粮食的人，众人咒诅他；</span><br /><span className="pl pl-2">出售粮食的人，福必临到他的头上。</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 7:15–16; 箴言 17:11; 诗篇 9:15–16"> <span className="pl pl-1">殷勤寻求良善的，是寻求恩惠；</span><br /><span className="pl pl-2">搜寻邪恶的，邪恶必临到他。</span></span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前书 6:17; 耶利米书 17:8; 诗篇 52:7–8"> <span className="pl pl-1">倚靠自己财富的人必跌倒；</span><br /><span className="pl pl-2">义人却必如青叶茂盛。</span></span>
<span className="v" id="v29" data-v="29" data-xref="传道书 5:16; 箴言 14:19; 箴言 15:27"> <span className="pl pl-1">扰害自己家的人必承受风；</span><br /><span className="pl pl-2">愚昧人必作心中有智慧之人的仆人。</span></span>
<span className="v" id="v30" data-v="30" data-xref="但以理 12:3; 雅各书 5:20; 哥林多前书 9:19–23"> <span className="pl pl-1">义人的果实是生命树；</span><br /><span className="pl pl-2">智慧人赢得灵魂。</span></span>
<span className="v" id="v31" data-v="31" data-xref="彼得前书 4:17–18; 耶利米书 25:29; 哥林多前书 11:30–32"> <span className="pl pl-1">看哪，义人在地上尚且受报，</span><br /><span className="pl pl-2">何况恶人和罪人呢！</span></span>

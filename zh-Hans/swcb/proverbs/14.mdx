<span className="v" id="v7" data-v="7" data-xref="箴言 13:20; 以弗所书 5:11; 哥林多前书 5:11"> <span className="pl pl-1">要远离愚昧人，</span><br /><span className="pl pl-2">因为你在他嘴唇上找不到知识。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:17; 提摩太后书 3:13; 雅各书 3:13"> <span className="pl pl-1">谨慎人的智慧在于思想自己的道路，</span><br /><span className="pl pl-2">愚昧人的愚妄却是欺骗。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 26:18–19; 箴言 10:23; 罗马书 14:17–18"> <span className="pl pl-1">愚妄人嘲笑为罪赎罪，</span><br /><span className="pl pl-2">正直人中间却有善意。</span></span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:7; 箴言 18:14; 箴言 15:13"> <span className="pl pl-1">心知道自己的苦涩与喜乐；</span><br /><span className="pl pl-2">外人不能分享这些。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 3:33; 箴言 12:7; 马太福音 7:26–27"> <span className="pl pl-1">恶人的家必被倾覆，</span><br /><span className="pl pl-2">正直人的帐棚却必兴旺。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:25; 马太福音 7:13–14; 箴言 12:15"> <span className="pl pl-1">有一条路，人以为正，</span><br /><span className="pl pl-2">至终却通向死亡。</span></span>
<span className="v" id="v13" data-v="13" data-xref="传道书 2:2; 雅各书 4:9; 传道书 2:10–11"> <span className="pl pl-1">人在欢笑中，心也可能忧伤；</span><br /><span className="pl pl-2">喜乐的结局也可能是沉重。</span></span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 6:8; 箴言 12:14; 希伯来书 3:12"> <span className="pl pl-1">不忠的人必照自己的道路受报；</span><br /><span className="pl pl-2">善人也同样必照自己的道路得赏。</span></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:17; 箴言 14:8; 约翰一书 4:1"> <span className="pl pl-1">愚蒙人凡事都信，</span><br /><span className="pl pl-2">谨慎人却仔细考量自己的道路。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 22:3; 箴言 3:7; 帖撒罗尼迦前书 5:22"> <span className="pl pl-1">智慧人敬畏，并远离恶事；</span><br /><span className="pl pl-2">愚昧人却急躁鲁莽。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 14:29; 雅各书 1:19; 传道书 7:9"> <span className="pl pl-1">轻易发怒的人必行愚妄，</span><br /><span className="pl pl-2">诡计多端的人被人憎恨。</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 1:18; 彼得前书 5:4; 耶利米书 44:17"> <span className="pl pl-1">愚蒙人承受愚妄，</span><br /><span className="pl pl-2">谨慎人却以知识为冠冕。</span></span>
<span className="v" id="v19" data-v="19" data-xref="创世记 42:6; 玛拉基书 4:3; 出埃及记 8:8"> <span className="pl pl-1">恶人俯伏在善人面前，</span><br /><span className="pl pl-2">邪恶人在义人的门口俯伏。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 19:4; 箴言 10:15; 箴言 19:6–7"> <span className="pl pl-1">贫穷人连自己的邻舍也厌弃他，</span><br /><span className="pl pl-2">富足人却有许多朋友。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 19:17; 箴言 28:27; 箴言 11:12"> <span className="pl pl-1">藐视邻舍的人犯罪，</span><br /><span className="pl pl-2">怜悯贫穷人的有福了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 12:2; 约翰福音 1:17; 诗篇 61:7"> <span className="pl pl-1">谋划恶事的人岂不是走迷了吗？</span><br /><span className="pl pl-2">但慈爱和信实属于谋划善事的人。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 28:19; 箴言 12:24; 帖撒罗尼迦后书 3:10–12"> <span className="pl pl-1">一切辛勤劳作都有益处，</span><br /><span className="pl pl-2">嘴唇空谈只导致贫穷。</span></span>
<span className="v" id="v24" data-v="24" data-xref="传道书 7:11–12; 路加福音 12:19–20; 路加福音 16:19–25"> <span className="pl pl-1">智慧人的冠冕是他们的财富，</span><br /><span className="pl pl-2">愚昧人的愚妄却以愚妄为冠冕。</span></span>

<span className="v" id="v1" data-v="1" data-xref="箴言 15:10; 箴言 9:7–8; 诗篇 119:97–100"> <span className="pl pl-1">喜爱管教的，就是喜爱知识；</span><br /><span className="pl pl-2">恨恶责备的，却是愚蠢。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 8:35; 使徒行传 11:24; 诗篇 112:5"> <span className="pl pl-1">善人必从耶和华得蒙恩惠；</span><br /><span className="pl pl-2">但祂必定罪那图谋邪恶的人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 10:25; 以弗所书 3:17; 箴言 12:12"> <span className="pl pl-1">人不能靠邪恶而立稳；</span><br /><span className="pl pl-2">义人的根却不会动摇。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 14:30; 箴言 31:10–25; 箴言 14:1"> <span className="pl pl-1">贤德的妇人是丈夫的冠冕；</span><br /><span className="pl pl-2">贻羞的妻子如同他骨中的朽烂。</span></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 139:23; 以赛亚书 55:7; 诗篇 140:1–3"> <span className="pl pl-1">义人的意念是公正的；</span><br /><span className="pl pl-2">恶人的计谋却是诡诈的。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:3; 耶利米书 5:26; 箴言 1:11–19"> <span className="pl pl-1">恶人的话是埋伏要流人血；</span><br /><span className="pl pl-2">正直人的口却拯救他们。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:24–27; 箴言 11:21; 箴言 10:25"> <span className="pl pl-1">恶人被推翻，归于无有；</span><br /><span className="pl pl-2">义人的家却必站立。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 10:18; 哥林多前书 4:5; 哥林多前书 3:10–15"> <span className="pl pl-1">人必按自己的智慧受称赞；</span><br /><span className="pl pl-2">心术乖谬的人必被藐视。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:11; 箴言 13:7"> <span className="pl pl-1">不受重视却有仆人的，</span><br /><span className="pl pl-2">胜过自抬身价却缺少食物的。</span></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 25:4; 创世记 33:13–14; 民数记 22:28–32"> <span className="pl pl-1">义人顾惜自己牲畜的生命；</span><br /><span className="pl pl-2">恶人的怜悯却是残忍。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 28:19; 箴言 14:23; 帖撒罗尼迦前书 4:11–12"> <span className="pl pl-1">耕种自己田地的，必有充足的粮食；</span><br /><span className="pl pl-2">追逐虚浮之事的，却缺乏悟性。</span></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:7–8; 约翰福音 15:5; 路加福音 8:13–15"> <span className="pl pl-1">恶人贪求邪恶之人的掠物；</span><br /><span className="pl pl-2">义人的根却茂盛。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 21:23; 箴言 11:8; 诗篇 64:8"> <span className="pl pl-1">恶人因嘴唇的罪过陷入网罗；</span><br /><span className="pl pl-2">义人却必脱离患难。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:20–21; 以赛亚书 3:10–11; 箴言 13:2"> <span className="pl pl-1">人必因口所结的果子饱得美福；</span><br /><span className="pl pl-2">人手所做的，必得回报。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 3:7; 箴言 26:12; 箴言 14:16"> <span className="pl pl-1">愚妄人的道路在自己眼中看为正；</span><br /><span className="pl pl-2">智慧人却听从劝告。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 雅各书 1:19; 箴言 10:12"> <span className="pl pl-1">愚妄人的恼怒当天就显露；</span><br /><span className="pl pl-2">不计较侮辱的，才是谨慎人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 14:5; 箴言 14:25; 箴言 24:28"> <span className="pl pl-1">说真话的人作诚实的见证；</span><br /><span className="pl pl-2">假见证人却说谎。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 16:24; 箴言 15:4; 诗篇 57:4"> <span className="pl pl-1">有人出言冒失，如刀刺人；</span><br /><span className="pl pl-2">智慧人的舌头却医治人。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:9; 诗篇 52:4–5; 约伯记 20:5"> <span className="pl pl-1">真实的嘴唇必永远坚立；</span><br /><span className="pl pl-2">说谎的舌头只存片时。</span></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 5:9; 彼得前书 3:8–13; 箴言 12:12"> <span className="pl pl-1">图谋邪恶的人心里有诡诈；</span><br /><span className="pl pl-2">促进和平的人却有喜乐。</span></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 3:13; 诗篇 91:10; 罗马书 8:28"> <span className="pl pl-1">灾祸不会临到义人；</span><br /><span className="pl pl-2">恶人却必满受祸害。</span></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 5:6; 箴言 11:20; 启示录 22:15"> <span className="pl pl-1">说谎的嘴唇为耶和华所憎恶；</span><br /><span className="pl pl-2">行事诚实的人为祂所喜悦。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 13:16; 箴言 11:13; 箴言 10:19"> <span className="pl pl-1">谨慎人保留自己的知识；</span><br /><span className="pl pl-2">愚昧人的心却宣扬愚妄。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:27; 箴言 10:4; 箴言 21:25–26"> <span className="pl pl-1">殷勤人的手必掌权；</span><br /><span className="pl pl-2">懒惰终必导致服苦役。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 16:24; 箴言 15:13; 箴言 17:22"> <span className="pl pl-1">人心里的忧虑使心沉重；</span><br /><span className="pl pl-2">一句良言使心欢喜。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰一书 2:26; 马太福音 5:46–48; 箴言 17:27"> <span className="pl pl-1">义人在交友上谨慎；</span><br /><span className="pl pl-2">恶人的道路却使他们走迷。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 13:4; 箴言 26:15; 箴言 15:16"> <span className="pl pl-1">懒惰人不烤自己打来的猎物；</span><br /><span className="pl pl-2">殷勤人的财物却是宝贵。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰三书 1:11; 罗马书 5:21; 以西结 18:20–24"> <span className="pl pl-1">在公义的路上有生命；</span><br /><span className="pl pl-2">在它的路径上没有死亡。</span></span>

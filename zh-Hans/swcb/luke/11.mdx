</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:6–15; 传道书 5:2; 诗篇 72:18–19"> 祂对他们说：<span className="woj">“你们祷告的时候，要说：</span><br /><span className="pl pl-1 woj">‘我们在天上的父，</span><br /><span className="pl pl-2 woj">愿你的名被尊为圣。</span><br /><span className="pl pl-1 woj">愿你的国降临。</span><br /><span className="pl pl-2 woj">愿你的旨意行在地上，如同行在天上。</span></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 6:11; 马太福音 6:34; 箴言 30:8"> <span className="pl pl-1 woj">我们日用的食物，求你天天赐给我们。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 6:12–15; 马太福音 26:41; 以赛亚书 43:25–26"> <span className="pl pl-1 woj">赦免我们的罪，</span><br /><span className="pl pl-2 woj">因为凡亏欠我们的人，我们也都赦免。</span><br /><span className="pl pl-1 woj">不叫我们陷入试探，</span><br /><span className="pl pl-2 woj">救我们脱离那恶者。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:1–8"> 祂又对他们说：<span className="woj">“你们中间谁有一个朋友，半夜去找他，说：‘朋友，请借给我三个饼，</span></span>
<span className="v" id="v6" data-v="6"> <span className="woj">因为我有一个朋友旅途中来到我这里，我没有什么可以摆在他面前。’</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 13:25; 加拉太书 6:17; 路加福音 7:6"> <span className="woj">那人在里面回答说：‘不要烦扰我。门已经关了，孩子们也同我在床上了。我不能起来给你。’</span></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:26; 歌罗西书 4:12; 罗马书 15:30"> <span className="woj">我告诉你们，虽不因他是朋友而起来给他，却因他坚持不懈，就必起来，照他所需用的给他。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 11:24; 约翰福音 16:23–24; 马太福音 21:22"> <span className="woj">“我告诉你们，要不断祈求，就给你们；不断寻找，就寻见；不断叩门，就给你们开门。</span></span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 4:3; 耶利米哀歌 3:54–58; 诗篇 31:22"> <span className="woj">因为凡祈求的，就得着；寻找的，就寻见；叩门的，就给他开门。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 7:9; 以赛亚书 49:15"> <span className="woj">“你们中间作父亲的，若儿子求饼，难道会给他石头吗？或求鱼，难道会拿蛇代替鱼给他吗？</span></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 9:10; 路加福音 10:19; 以西结 2:6"> <span className="woj">或求鸡蛋，难道会给他蝎子吗？</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 7:11; 以赛亚书 44:3–4; 罗马书 8:32"> <span className="woj">你们虽然不好，尚且知道把好东西给自己的儿女，何况天父，岂不更要把圣灵赐给求祂的人吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 12:22–24; 马太福音 9:32–34; 马可福音 7:32–37"> 耶稣赶出一个鬼，那鬼使人哑口。鬼出来以后，那哑巴就说出话来；众人都希奇。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 9:34; 马太福音 12:24–30; 约翰福音 8:48"> 但其中有人说：“祂是靠着鬼王别西卜赶鬼。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 6:30; 哥林多前书 1:22; 马可福音 8:11–12"> 另有人试探祂，向祂求从天上来的神迹。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 3:23–27; 马太福音 12:25–29; 以赛亚书 19:2–3"> 耶稣知道他们的意念，就对他们说：<span className="woj">“凡一国自相纷争，就必荒废；一家自相纷争，就必败落。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 12:26; 马太福音 12:31–34; 路加福音 11:15"> <span className="woj">若撒但也自相纷争，他的国怎能站立得住呢？因为你们说我是靠着别西卜赶鬼。</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:49; 约伯记 15:6; 罗马书 3:19"> <span className="woj">我若靠着别西卜赶鬼，你们的子弟又靠谁赶鬼呢？这样，他们就要作你们的审判者。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 8:19; 马太福音 12:28; 路加福音 10:9"> <span className="woj">我若靠着上帝的指头赶鬼，那么上帝的国已经临到你们了。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:27; 马太福音 12:29"> <span className="woj">“壮士全副武装，看守自己的住宅，他的家产就平安无事。</span></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 49:24–25; 以赛亚书 53:12; 约翰一书 3:8"> <span className="woj">但有一个比他更强的来攻击他，胜过他，就夺去他所倚靠的全副盔甲，又分了他的掠物。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:30; 路加福音 9:50; 马可福音 9:40"> <span className="woj">“不与我同在的，就是敌挡我；不同我收聚的，就是分散。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 12:43–45; 彼得前书 5:8; 约伯记 2:2"> <span className="woj">“污灵从人里面出来以后，经过干旱无水之地，寻找安歇之处；既找不着，就说：‘我要回到我出来的那屋里去。’</span></span>
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦后书 2:9–12; 彼得后书 2:10–19; 犹大书 1:8–13"> <span className="woj">到了那里，看见里面已经打扫干净，整理好了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 5:14; 马太福音 12:45; 彼得后书 2:20–22"> <span className="woj">于是它去，另带了七个比自己更恶的灵来，都进去住在那里；那人末后的景况就比先前更坏了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:42; 路加福音 1:48; 路加福音 23:29"> 耶稣说这些话的时候，众人中有一个女人高声对祂说：“怀你胎的腹和哺养你的乳房是有福的！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 6:47–48; 路加福音 8:21; 诗篇 112:1"> 耶稣却说：<span className="woj">“更确切地说，听上帝的话而遵守的人才是有福的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:16; 马可福音 8:11–12; 哥林多前书 1:22"> 众人越聚越多，耶稣开始说：<span className="woj">“这世代是邪恶的世代；它寻求神迹，除了先知约拿的神迹以外，再没有神迹给它。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 12:40–42; 约拿 1:17; 约拿 3:2–10"> <span className="woj">约拿怎样成了尼尼微人的神迹，人子也要照样成为这世代的神迹。</span></span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 9:1; 列王纪上 10:1–13; 罗马书 2:27"> <span className="woj">南方的女王在审判的时候，要同这世代的人一同起来，定他们的罪；因为她从地极而来，要听所罗门的智慧。看哪，在这里有一位比所罗门更大的。</span></span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 7:26; 路加福音 11:31; 约拿 3:5–4"> <span className="woj">尼尼微人在审判的时候，要同这世代一同站起来，定它的罪；因为他们听了约拿所传的就悔改了。看哪，在这里有一位比约拿更大的。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:16–17; 马可福音 4:21–22; 马太福音 5:15–16"> <span className="woj">“没有人点了灯，把它放在地窖里，或放在斗底下，总是放在灯台上，使进来的人看见亮光。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 6:22–23; 使徒行传 26:18; 耶利米书 5:21"> <span className="woj">身体的灯就是眼睛。所以你的眼睛若明亮，全身就满有光；若昏暗，身体也就满了黑暗。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 16:25; 彼得后书 1:9; 雅各书 3:13–17"> <span className="woj">所以要谨慎，免得你里面的光竟成了黑暗。</span></span>
<span className="v" id="v36" data-v="36" data-xref="箴言 20:27; 箴言 6:23; 箴言 4:18–19"> <span className="woj">因此，你全身若满有光，没有一点黑暗，就必全然光明，好像明亮的灯光照耀你一样。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 7:36; 哥林多前书 9:19–23; 路加福音 14:1"> 耶稣说话的时候，有一个法利赛人请祂同他吃饭。耶稣就进去坐席。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:2–3; 马可福音 7:2–5; 约翰福音 3:25"> 那法利赛人看见耶稣饭前没有先洗手，就感到希奇。</span>
<span className="v" id="v39" data-v="39" data-xref="提多书 1:15; 箴言 30:12; 创世记 6:5"> 主对他说：<span className="woj">“如今你们法利赛人洗净杯盘的外面，你们里面却满了贪婪和邪恶。</span></span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:20; 哥林多前书 15:36; 马太福音 23:26"> <span className="woj">无知的人哪！造外面的，岂不也造里面吗？</span></span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 12:33; 雅各书 1:27; 提多书 1:15"> <span className="woj">只要把里面所有的施舍给穷人，看哪，一切对你们就都洁净了。</span></span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 23:23; 路加福音 18:12; 箴言 21:3"> <span className="woj">但你们法利赛人有祸了！因为你们将薄荷、芸香和各样菜蔬献上十分之一，却忽略公义和上帝的爱。这些本该行，那些也不可不行。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 20:46; 马可福音 12:38–39; 路加福音 14:7–11"> <span className="woj">你们法利赛人有祸了！因为你们喜爱会堂里的首位，又喜爱人在市场上向你们问安。</span></span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 23:27–28; 诗篇 5:9; 使徒行传 23:3"> <span className="woj">你们文士和法利赛人，假冒为善的人，有祸了！因为你们像不显露的坟墓，人在上面行走却不知道。”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 9:40; 马太福音 22:35; 耶利米书 6:10"> 有一个律法师回答祂说：“老师，你这样说，也把我们侮辱了。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:52; 以赛亚书 10:1; 马太福音 23:2–4"> 耶稣说：<span className="woj">“你们律法师也有祸了！因为你们把难担的重担放在人身上，自己却连一个指头也不肯动，去帮助他们担。</span></span>
<span className="v" id="v47" data-v="47" data-xref="帖撒罗尼迦前书 2:15; 使徒行传 7:51; 马太福音 23:29–33"> <span className="woj">你们有祸了！因为你们修造先知的坟墓，而你们的祖先却杀害了他们。</span></span>
<span className="v" id="v48" data-v="48" data-xref="雅各书 5:10; 马太福音 23:31; 历代志下 36:16"> <span className="woj">可见你们为自己祖先的行为作见证，又赞同他们；因为他们杀害先知，你们却修造他们的坟墓。</span></span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:30; 歌罗西书 2:3; 以弗所书 4:11"> <span className="woj">所以上帝的智慧也说：‘我要差遣先知和使徒到他们那里去；他们中有些人，他们要杀害，要逼迫，</span></span>
<span className="v" id="v50" data-v="50" data-xref="创世记 9:5–6; 启示录 18:20–24; 列王纪下 24:4"> <span className="woj">使从创世以来众先知所流的血，都要向这世代追讨，</span></span>
<span className="v" id="v51" data-v="51" data-xref="历代志下 24:20–22; 马太福音 23:35; 希伯来书 11:4"> <span className="woj">从亚伯的血起，直到撒迦利亚的血为止；他是在祭坛和圣所之间被杀的。’是的，我告诉你们，这都要向这世代追讨。</span></span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 23:13; 玛拉基书 2:7; 路加福音 11:45–46"> <span className="woj">你们律法师有祸了！因为你们夺去了知识的钥匙；自己不进去，正要进去的人，你们也阻挡了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="哥林多前书 13:5; 耶利米书 20:10; 路加福音 20:20"> 耶稣离开那里以后，文士和法利赛人开始极其恼怒，百般盘问祂，</span>
<span className="v" id="v54" data-v="54" data-xref="马可福音 12:13; 马太福音 22:15; 马太福音 22:35"> 暗中窥探，要从祂的话里抓把柄，好控告祂。</span>
</div>

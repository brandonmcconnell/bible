<div className="bp">

<span className="v" id="v6" data-v="6" data-xref="路加福音 12:24; 诗篇 145:15–16; 诗篇 147:9"> <span className="woj">“五只麻雀不是卖两个小铜钱吗</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一个 assarion 是小铜币，约等于农业工人一小时的工钱。">b</a></sup><span className="woj">？但在上帝面前，一只也不被忘记。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:30–31; 马太福音 6:26; 以赛亚书 43:3–4"> <span className="woj">就是你们的头发，也都数过了。所以不要怕；你们比许多麻雀更贵重。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:32–33; 约翰一书 2:23; 罗马书 10:9–10"> <span className="woj">“我告诉你们，凡在人面前承认我的，人子在上帝的天使面前也必承认他；</span></span>

</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:45; 提摩太前书 6:5; 以西结 33:31"> 众人中有一个人对耶稣说：“老师，请吩咐我的兄弟和我分家业。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:3; 罗马书 2:1; 罗马书 9:20"> 耶稣对他说：<span className="woj">“人哪，谁立我作你们的审判官或分产人呢？”</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:5; 提摩太前书 6:6–10; 诗篇 119:36–37"> 祂又对众人说：<span className="woj">“你们要谨慎，防备一切贪心；因为人的生命不在于家道丰富。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 26:12–14; 何西阿 2:8; 创世记 41:47–49"> 祂就对他们讲一个比喻，说：<span className="woj">“有一个财主的田地出产丰盛。</span></span>

<span className="v" id="v18" data-v="18" data-xref="雅各书 3:15; 雅各书 4:15; 路加福音 12:21"> <span className="woj">又说：‘我要这样做：我要拆掉我的仓房，另建更大的，在那里收藏我所有的粮食和财物。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 27:1; 雅各书 4:13–15; 哥林多前书 15:32"> <span className="woj">然后我要对自己的灵魂说：“灵魂啊，你有许多财物积存，可供多年享用；只管安逸，吃喝快乐吧！”’</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约伯记 27:8; 耶利米书 17:11; 提摩太前书 6:7"> <span className="woj">“但上帝对他说：‘无知的人哪！今夜就要取走你的灵魂；你所预备的，要归谁呢？’</span></span>

</div>
<div className="bp">

<span className="v" id="v24" data-v="24" data-xref="马太福音 10:31; 诗篇 147:9; 路加福音 12:7"> <span className="woj">你们想想乌鸦：它们不种也不收，没有仓库，也没有仓房，上帝尚且养活它们。你们比飞鸟贵重得多！</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:27; 马太福音 5:36; 路加福音 19:3"> <span className="woj">你们哪一个能靠忧虑使自己的身量加上一肘</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘约为人从中指尖到肘部的长度，约十八英寸或四十六厘米。">c</a></sup><span className="woj">呢？</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 5:7; 诗篇 39:6; 传道书 7:13"> <span className="woj">这样，若连这最小的事你们都不能做，为什么还忧虑其余的事呢？</span></span>

<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 6:31; 路加福音 12:22; 路加福音 22:35"> <span className="woj">“你们不要追求吃什么、喝什么，也不要心里不安。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 6:32; 马太福音 6:8; 以弗所书 4:17"> <span className="woj">因为世上的外邦人都寻求这些事；但你们的父知道你们需要这些。</span></span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 6:33; 希伯来书 13:5; 诗篇 34:9"> <span className="woj">你们只要求上帝的国，这些东西就必加给你们。</span></span>

<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:28; 彼得前书 1:3–5; 启示录 1:6"> <span className="woj">“小群啊，不要怕，因为你们的父乐意把国赐给你们。</span></span>

<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="彼得前书 1:13; 以弗所书 6:14; 马太福音 25:4–10"> <span className="woj">“你们的腰要束好，灯也要点着。</span></span>
<span className="v" id="v36" data-v="36" data-xref="犹大书 1:20–21; 雅各书 5:7–8; 启示录 3:20"> <span className="woj">要像仆人等候自己的主人从婚宴回来，好叫主人来到叩门的时候，他们立刻给他开门。</span></span>
<span className="v" id="v37" data-v="37" data-xref="彼得后书 3:14; 马太福音 24:42; 约翰福音 13:4–5"> <span className="woj">主人来到，看见仆人警醒，那些仆人就有福了。我实在告诉你们，主人必自己束上腰，叫他们坐席，进前来服事他们。</span></span>
<span className="v" id="v38" data-v="38" data-xref="帖撒罗尼迦前书 5:4–5; 马太福音 25:6"> <span className="woj">他若二更或三更来到，看见他们这样，那些仆人就有福了。</span></span>
<span className="v" id="v39" data-v="39" data-xref="彼得后书 3:10; 启示录 3:3; 启示录 16:15"> <span className="woj">你们要知道，家主若知道贼什么时候来，就必警醒，不容自己的房屋被挖穿。</span></span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 5:6; 马太福音 25:13; 罗马书 13:11"> <span className="woj">所以你们也要预备好，因为在你们想不到的时候，人子就来了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="马可福音 13:37; 彼得前书 4:7; 彼得前书 5:8"> 彼得对祂说：“主啊，这比喻是对我们说的，还是对众人说的呢？”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 24:45–46; 彼得前书 5:1–4; 希伯来书 13:17"> 主说：<span className="woj">“谁是那忠心有智慧的管家，主人要派他管理家中的人，按时分给他们食物呢？</span></span>
<span className="v" id="v43" data-v="43"> <span className="woj">主人来到，看见那仆人这样做，那仆人就有福了。</span></span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 22:29–30; 马太福音 24:47; 路加福音 19:17–19"> <span className="woj">我实在告诉你们，主人要派他管理自己一切所有的。</span></span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 24:48–50; 启示录 18:7–8; 腓立比书 3:18–19"> <span className="woj">但那仆人若心里说：‘我的主人来得迟’，就动手打男仆女仆，又吃又喝又醉酒，</span></span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 12:40; 马太福音 24:51; 诗篇 11:5"> <span className="woj">那仆人的主人就要在他想不到的日子、不知道的时辰来到，把他重重惩治，使他和不忠信的人同受一份。</span></span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 4:17; 约翰福音 9:41; 约翰福音 12:48"> <span className="woj">那知道主人意思，却不预备，也不照主人意思行的仆人，必多受责打；</span></span>
<span className="v" id="v48" data-v="48" data-xref="雅各书 3:1; 利未记 5:17; 路加福音 16:10–12"> <span className="woj">但那不知道而做了该受责打之事的，必少受责打。多给谁，就向谁多要；多托付谁，就向谁多取。</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="玛拉基书 4:1; 路加福音 12:51–52; 马太福音 3:10–12"> <span className="woj">“我来是要把火投在地上；若是已经燃起来，我何等迫切！</span></span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 12:27–28; 约翰福音 19:30; 约翰福音 7:6–8"> <span className="woj">我有当受的洗还没有受；直到成就以前，我是何等焦急！</span></span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 10:34–36; 路加福音 12:49; 马太福音 24:7–10"> <span className="woj">你们以为我来是要使地上太平吗？我告诉你们，不是，乃是叫人分裂。</span></span>

</div>

<span className="v" id="v56" data-v="56" data-xref="马太福音 16:3; 马太福音 24:32–33; 马太福音 11:25"> <span className="woj">假冒为善的人哪！你们知道分辨天地的气象，怎么不知道分辨这时候呢？</span></span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="申命记 32:29; 约翰福音 7:24; 使徒行传 13:26–38"> <span className="woj">“你们又为什么不自己判断什么是正当的呢？</span></span>

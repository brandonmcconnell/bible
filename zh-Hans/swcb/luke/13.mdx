<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:17–18; 耶利米哀歌 2:20; 以西结 9:5–7"> 正在那时候，有几个人在场，把彼拉多怎样把一些加利利人的血掺在他们祭物中的事告诉耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:2; 使徒行传 28:4; 约伯记 22:5–16"> 耶稣回答他们说：<span className="woj">“你们以为这些加利利人遭受这样的事，就比所有别的加利利人更有罪吗？</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 3:19; 马太福音 3:2; 使徒行传 2:38–40"> <span className="woj">我告诉你们，不是的；你们若不悔改，都要同样灭亡。</span></span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 3:15; 约伯记 1:19; 约翰福音 9:11"> <span className="woj">或者，西罗亚楼倒塌时压死的那十八个人，你们以为他们比一切住在耶路撒冷的人更有罪吗？</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结 18:30; 路加福音 13:3; 以赛亚书 28:10–13"> <span className="woj">我告诉你们，不是的；你们若不悔改，都要同样灭亡。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 以赛亚书 5:1–4; 加拉太书 5:22"> 祂又讲了这个比喻：<span className="woj">“有一个人在自己的葡萄园里栽了一棵无花果树。他来树上找果子，却找不着。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:19; 路加福音 3:9; 约翰福音 15:6"> <span className="woj">他就对管园的人说：‘看哪，这三年来，我到这无花果树上找果子，却找不着。把它砍了吧！何必白占土地呢？’</span></span>
<span className="v" id="v8" data-v="8" data-xref="彼得后书 3:9; 约珥 2:17; 罗马书 10:1"> <span className="woj">管园的回答说：‘主啊，今年且留着它，等我在它周围掘开土，加上肥料。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:2; 帖撒罗尼迦前书 2:15; 希伯来书 6:8"> <span className="woj">以后若结果子便罢；若不结果子，再把它砍了。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 安息日，耶稣在一个会堂里教导人。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 看哪，有一个女人被病弱的灵缠身十八年，腰弯得直不起来。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:20; 马太福音 8:16; 路加福音 6:8–10"> 耶稣看见她，就叫她过来，对她说：<span className="woj">“女人，你脱离这病了。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 107:20–22; 马可福音 16:18; 马可福音 5:23"> 于是祂按手在她身上；她立刻直起腰来，荣耀上帝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 20:9; 马太福音 12:2; 约翰福音 9:14–16"> 会堂主管因为耶稣在安息日治病，就恼怒，对众人说：“有六天应当做工；所以你们可以在那些日子来求医治，不可在安息日来！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 约翰福音 7:21–24; 使徒行传 13:9–10"> 主回答他说：<span className="woj">“假冒为善的人哪！你们各人在安息日，岂不也把牛或驴从槽上解开，牵去饮水吗？</span></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 2:27; 提摩太后书 2:26; 路加福音 19:9"> <span className="woj">何况这个女人，本是亚伯拉罕的女儿，被撒但捆绑了整整十八年，难道不该在安息日从这捆绑中被释放吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:16; 诗篇 132:18; 以赛亚书 45:24"> 耶稣说这些话，所有敌对祂的人都羞愧；众人却因祂所行一切荣耀的事欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:30–34; 路加福音 17:21; 马太福音 13:31–32"> 祂说：<span className="woj">“上帝的国像什么？我拿什么来比它呢？</span></span>
<span className="v" id="v19" data-v="19" data-xref="但以理 4:12; 但以理 4:21; 但以理 2:44–45"> <span className="woj">它像一粒芥菜种，有人拿去种在自己的园子里；它长大成了树，天上的飞鸟栖息在它的枝上。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 祂又说：<span className="woj">“我拿什么来比上帝的国呢？</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 13:33; 哥林多前书 5:6; 帖撒罗尼迦前书 5:23–24"> <span className="woj">它像面酵，有妇人拿来藏在三斗</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直译为“三撒特”。三撒特约为三十九升，略多于一蒲式耳。">a</a></sup><span className="woj">面里，直到全团都发起来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 马太福音 9:35; 马可福音 10:32–34"> 耶稣往耶路撒冷去，一路经过各城各村教导人。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:14; 马太福音 22:14; 约翰福音 21:21–22"> 有一个人问祂：“主啊，得救的人少吗？”<br />耶稣对众人说：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:13–14; 彼得后书 1:10; 哥林多前书 9:24–27"> <span className="woj">“你们要竭力从窄门进去；我告诉你们，将来有许多人想要进去，却不能。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 25:10–12; 路加福音 13:27; 马太福音 7:21–23"> <span className="woj">等到家主起来关了门，你们开始站在外面叩门，说：‘主啊，主啊，给我们开门！’他就要回答你们说：‘我不认识你们，也不知道你们是哪里来的。’</span></span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 58:2; 提多书 1:16; 提摩太后书 3:5"> <span className="woj">那时，你们就要说：‘我们在你面前吃过喝过，你也在我们的街上教导过人。’</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 6:8; 马太福音 25:41; 马太福音 7:22–23"> <span className="woj">他要说：‘我告诉你们，我不知道你们是哪里来的。你们这一切作恶的人，离开我去吧！’</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:11–12; 马太福音 22:13; 马太福音 25:30"> <span className="woj">你们看见亚伯拉罕、以撒、雅各和众先知都在上帝的国里，自己却被赶到外面，在那里必要哀哭切齿。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 43:6; 以赛亚书 66:18–20; 以赛亚书 49:6"> <span className="woj">从东、从西、从北、从南，将有人来，在上帝的国里坐席。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:30; 马可福音 10:31; 马太福音 20:16"> <span className="woj">看哪，有些在后的，将要在前；有些在前的，将要在后。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 6:9–11; 诗篇 11:1–2; 马太福音 14:1"> 就在那一天，有几个法利赛人来对耶稣说：“离开这里走吧，因为希律想要杀你。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 2:10; 希伯来书 5:9; 约翰福音 17:4–5"> 祂对他们说：<span className="woj">“你们去告诉那只狐狸：‘看哪，今天明天我赶鬼治病，第三天我完成我的使命。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 马太福音 21:11; 使徒行传 13:27"> <span className="woj">虽然如此，今天、明天、后天我必须继续前行；因为先知在耶路撒冷之外丧命，是不合宜的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 23:37–39; 申命记 32:11–12; 使徒行传 7:52"> <span className="woj">“耶路撒冷啊，耶路撒冷啊，你杀害先知，又用石头打死奉差遣到你这里来的人！我多少次愿意聚集你的儿女，好像母鸡把自己的小鸡聚集在翅膀底下，只是你们不愿意！</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:26; 马可福音 11:9–10; 马太福音 21:9"> <span className="woj">看哪，你们的家要被撇给你们，成为荒凉。我告诉你们，你们绝不会再看见我，直到你们说：‘奉主名来的，是有福的！’”</span></span>
</div>

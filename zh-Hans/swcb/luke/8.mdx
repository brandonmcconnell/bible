<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:23; 罗马书 10:15; 马太福音 9:35"> 不久以后，耶稣周游各城各村，传讲并宣扬上帝国的福音。十二使徒和祂同去，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:9; 马太福音 27:55–56; 马可福音 15:40–41"> 还有几个曾经得医治脱离邪灵和疾病的妇女：称为抹大拉的马利亚，曾有七个鬼从她身上出来；</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 4:46–53; 哥林多后书 8:9; 使徒行传 9:36–39"> 又有希律家宰苦撒的妻子约亚拿，苏撒拿，以及许多别的妇女；她们都用自己的财物供给他们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 作“供给祂”。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 4:1–9; 马太福音 13:2–9"> 有一大群人聚集，又有人从各城来到祂那里，祂就用比喻说：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:1; 雅各书 1:23–24; 马可福音 4:15"> <span className="woj">“有一个撒种的人出去撒种。撒的时候，有的落在路旁，被人践踏，天上的飞鸟又把它吃尽了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 3:7–8; 路加福音 8:13; 马可福音 4:5–6"> <span className="woj">有的落在磐石上，一长出来就枯干了，因为没有水分。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 路加福音 21:34"> <span className="woj">有的落在荆棘里，荆棘一同生长，把它挤住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 11:15; 启示录 2:11; 启示录 2:7"> <span className="woj">又有的落在好土里，长起来，结出百倍的果实。”</span>祂说了这些话，就高声说：<span className="woj">“有耳可听的，就应当听！”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 4:10; 马太福音 13:10; 马太福音 13:18"> 门徒问祂：“这比喻是什么意思？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 6:9; 马可福音 4:11; 马太福音 11:25"> 祂说：<span className="woj">“上帝国的奥秘，只给你们知道；至于其余的人，就用比喻，使他们‘看也看不见，听也听不明白。’</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:19; 马可福音 4:14–20; 雅各书 1:21"> <span className="woj">“这比喻是这样：种子就是上帝的话。</span></span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:9–14; 启示录 12:9; 雅各书 1:23–24"> <span className="woj">那些在路旁的，是听见的人；随后魔鬼来，从他们心里把道夺去，免得他们相信而得救。</span></span>
<span className="v" id="v13" data-v="13" data-xref="何西阿 6:4; 约翰福音 5:35; 箴言 12:12"> <span className="woj">那些在磐石上的，是人听见道，就欢喜领受；但这些人没有根，不过暂时相信，遇见试探的时候就退去了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> <span className="woj">落在荆棘里的，是那些听见了道，后来在前行中被生活的忧虑、财富和享乐挤住，结不出成熟的果实。</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:36; 加拉太书 5:22–26; 歌罗西书 1:10"> <span className="woj">落在好土里的，是那些以诚实善良的心听了道，就紧紧持守，并且凭着忍耐结出果实的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 马太福音 5:15–16; 马可福音 4:21–22"> <span className="woj">“没有人点了灯，又用器皿盖住，或放在床底下；总是放在灯台上，使进来的人看见亮光。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 马太福音 10:26; 马可福音 4:22"> <span className="woj">因为没有什么隐藏的事不被显明，也没有什么秘密的事不被人知道、显露出来。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:12; 路加福音 19:26; 马可福音 4:23–25"> <span className="woj">所以你们要谨慎自己怎样听。因为凡有的，还要给他；凡没有的，连他自以为有的，也要从他夺去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 12:46–50; 马可福音 3:31–35; 马可福音 3:21"> 耶稣的母亲和兄弟来到祂那里，因为人多，不能近前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 1:14; 马可福音 6:3; 马太福音 13:55–56"> 有人告诉祂：“你的母亲和你的兄弟站在外面，想要见你。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各书 1:22; 约翰福音 13:17"> 耶稣回答他们说：<span className="woj">“听上帝的话而遵行的人，就是我的母亲和我的兄弟。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 8:23–27; 马可福音 4:35–41; 马可福音 6:45"> 有一天，耶稣和门徒上了船，祂对他们说：<span className="woj">“我们渡到湖那边去吧。”</span>他们就开了船。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 93:3–4; 诗篇 124:2–4; 诗篇 148:8"> 船行的时候，耶稣睡着了。湖上忽然起了风暴，船进了许多水，非常危险。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:25–29; 路加福音 4:39; 诗篇 104:6–9"> 门徒来叫醒祂，说：“主啊，主啊，我们要丧命了！”祂醒来，斥责风和汹涌的水；风浪就止住，湖面平静了。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 8:26; 箴言 30:4; 马可福音 4:40–41"> 祂对他们说：<span className="woj">“你们的信心在哪里？”</span>他们又害怕又惊奇，彼此说：“这到底是谁？祂竟吩咐风和水，连风和水也听从祂。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 5:1–20; 马太福音 8:28–34"> 他们到了加大拉人的地方，就是加利利对面。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 5:2–5; 撒母耳记上 19:24; 民数记 19:16"> 耶稣上岸的时候，城里有一个被鬼附了很久的人迎面而来。他不穿衣服，也不住在家里，只住在坟墓中。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:29; 彼得后书 2:4; 马可福音 5:6–8"> 他看见耶稣，就喊叫，俯伏在祂面前，大声说：“至高上帝的儿子耶稣，我与你有什么相干？求你不要折磨我！”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:3–5; 路加福音 9:39; 提摩太后书 2:25–26"> 因为耶稣正吩咐污灵从那人里面出来。原来那污灵屡次抓住他；他虽被人看守，又用铁链和脚镣捆锁，却把锁链挣断，被鬼赶到旷野去。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 26:53; 路加福音 8:2; 马太福音 8:29"> 耶稣问他说：<span className="woj">“你叫什么名字？”</span><br />他说：“群。”因为有许多鬼进了他里面。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:41; 腓立比书 2:10–11; 约伯记 2:5"> 那些鬼央求耶稣，不要命令它们到无底坑去。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 65:4; 以赛亚书 66:3; 启示录 20:7"> 那里有一大群猪在山上吃食；鬼央求祂准许它们进入猪里，祂就准了它们。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 5:8; 约翰福音 8:44; 路加福音 8:22–23"> 鬼从那人里面出来，进入猪里；那群猪就闯下陡坡，投进湖里淹死了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 5:14; 马太福音 8:33; 马太福音 28:11"> 放猪的人看见所发生的事，就逃跑了，到城里和乡间去报告。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行传 22:3; 约翰一书 3:8"> 众人出来要看所发生的事；他们来到耶稣那里，看见鬼已经离开的那个人坐在耶稣脚前，穿着衣服，神志清醒，就害怕起来。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 4:24"> 看见这事的人，把那被鬼附的人怎样得医治告诉了他们。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 16:39; 路加福音 8:28; 路加福音 10:10–11"> 加大拉周围地区的众人都求耶稣离开他们，因为他们十分惧怕。耶稣就上船回去了。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:13–16; 马可福音 5:18–20; 诗篇 145:3–12"> 鬼已经离开的那人求耶稣，想要跟祂同去；耶稣却打发他回去，说：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前书 5:8; 申命记 10:21"> <span className="woj">“你回家去，宣告上帝为你做了何等大的事。”</span>他就走遍全城，传扬耶稣为他做了何等大的事。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:1; 马可福音 5:21; 马可福音 6:20"> 耶稣回来的时候，众人迎接祂，因为他们都在等候祂。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 5:22–43; 路加福音 13:14; 使徒行传 18:8"> 看哪，有一个名叫睚鲁的人来了；他是会堂的主管。他俯伏在耶稣脚前，求祂到他家里去，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; 约伯记 1:18–19"> 因为他有一个独生<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“独生”译自希腊词“μονογενής”，也可译为“唯一的”或“独一的”。">b</a></sup>女儿，约十二岁，快要死了。耶稣去的时候，众人拥挤祂。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 5:25–26; 马太福音 9:20–22; 利未记 15:25–33"> 有一个女人，患了十二年血漏，花尽了所有生活费用在医生身上，却没有一个人能医好她。</span>
<span className="v" id="v44" data-v="44" data-xref="马可福音 5:27–28; 申命记 22:12; 使徒行传 19:12"> 她从后面来，摸了耶稣衣服的穗子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“繸子”。">c</a></sup>；她的血漏立刻止住了。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶稣说：<span className="woj">“摸我的是谁？”</span><br />众人都不承认，彼得和同伴说：“主啊，众人拥拥挤挤挨着你，你还说：<span className="woj">‘摸我的是谁？’</span>”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前书 2:9"> 但耶稣说：<span className="woj">“有人摸了我，因为我知道有能力从我身上出去。”</span></span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 5:33; 路加福音 17:15–16; 哥林多前书 2:3"> 那女人见自己不能隐藏，就战战兢兢地来，俯伏在耶稣面前，当着众百姓说明自己为什么摸祂，又怎样立刻得了医治。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 马太福音 9:22; 希伯来书 4:2"> 耶稣对她说：<span className="woj">“女儿，放心吧。你的信心使你痊愈了；平安地去吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:35–43; 以赛亚书 7:12; 路加福音 7:6"> 祂还在说话的时候，有人从会堂主管家里来，对他说：“你的女儿已经死了，不要再烦扰老师。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 11:25; 马可福音 5:36"> 耶稣听见，就回答他说：<span className="woj">“不要怕，只要信，她就必得医治。”</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="马可福音 14:33; 马太福音 6:5–6; 列王纪上 17:19–23"> 到了那家，除了彼得、约翰、雅各，孩子的父亲和母亲，祂不许任何人进去。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 约翰福音 11:4; 撒迦利亚书 12:10"> 众人都在为她哭泣哀号，耶稣却说：<span className="woj">“不要哭；她不是死了，是睡着了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="路加福音 16:14; 以赛亚书 53:3; 约翰福音 11:39"> 他们知道她已经死了，就讥笑祂。</span>
<span className="v" id="v54" data-v="54" data-xref="耶利米书 31:32; 约翰福音 11:43; 马可福音 1:31"> 耶稣却把众人都赶出去，拉着她的手，呼唤说：<span className="woj">“孩子，起来！”</span></span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 11:44; 列王纪上 17:21–23; 马可福音 5:43"> 她的灵魂就回来了，她立刻起来。耶稣吩咐给她东西吃。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 8:4; 马太福音 9:30; 路加福音 5:14"> 她的父母惊奇不已；耶稣嘱咐他们，不要把所发生的事告诉任何人。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:1–3; 彼得后书 1:16–19; 约翰福音 20:31"> 既然已经有许多人着手，把在我们中间成就的事按次序写成记述，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:27; 使徒行传 26:16; 希伯来书 2:3"> 正如那些从起初亲眼见过、又服事这道的人传给我们的，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 1:1; 使徒行传 26:25; 使徒行传 11:4"> 尊贵的提阿非罗，我也把这一切从头仔细查考了，觉得应该按次序写给你，</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 20:31; 使徒行传 18:25; 哥林多前书 14:19"> 好让你确切知道，你所受教导的事真实可靠。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:10; 马太福音 2:1; 尼希米记 12:4"> 在犹太王希律的日子，有一位祭司名叫撒迦利亚，属于亚比雅班次。他的妻子是亚伦的后裔，名叫伊丽莎白。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 7:1; 创世记 17:1; 腓立比书 2:15"> 他们二人在上帝面前都是义人，遵行主的一切诫命和规例，无可指摘。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:11; 创世记 18:11; 撒母耳记上 1:2"> 可是他们没有孩子，因为伊丽莎白不能生育，而且两人都已经年纪老迈。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:14; 历代志上 24:19; 历代志下 31:2"> 有一天，撒迦利亚按照自己班次的次序，在上帝面前执行祭司职务。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:11; 出埃及记 30:7–8; 历代志上 23:13"> 按祭司职分的惯例，他抽签抽中，要进主的殿烧香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:17; 启示录 8:3; 希伯来书 4:14"> 烧香的时候，众百姓都在外面祷告。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:26–27; 使徒行传 10:3–4; 士师记 13:3"> 有一位主的天使向他显现，站在香坛的右边。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:22; 士师记 6:22; 路加福音 2:9–10"> 撒迦利亚看见他，就惊慌害怕。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 2:21; 使徒行传 10:31; 创世记 25:21"> 天使对他说：“撒迦利亚，不要害怕，因为你的祈求已经蒙垂听了。你的妻子伊丽莎白要给你生一个儿子，你要给他起名叫约翰。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 创世记 21:6"> 你必欢喜快乐，也有许多人要因他的出生而喜乐。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 民数记 6:2–4; 路加福音 7:33"> 因为他在主面前将要成为伟大的人。他清酒烈酒都不可喝；从母腹里，他就要被圣灵充满。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:3–5; 马太福音 21:32; 玛拉基书 3:1"> 他要使许多以色列人回转，归向主他们的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 4:5–6; 马太福音 11:14; 路加福音 1:76"> 他要带着以利亚的灵和能力走在主前面，‘使父亲的心转向儿女，’ 又使悖逆的人回转，领受义人的智慧，好为主预备一群准备好了的百姓。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 38:22; 创世记 17:17; 路加福音 1:7"> 撒迦利亚对天使说：“我怎么能确定这事呢？我已经老了，我妻子也年纪老迈了。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 马太福音 18:10; 但以理 9:21–23"> 天使回答他说：“我是加百列，站在上帝面前。我奉差遣来对你说话，把这好消息告诉你。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 3:26; 以西结 24:27; 路加福音 1:22"> 看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”译自希腊语“ἰδοὺ”，意思是看、留意、注意、观看，常用作感叹词。">a</a></sup>你必沉默，不能说话，直到这些事成就的日子，因为你不信我的话；这些话到了时候必然应验。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 6:23–27"> 百姓等着撒迦利亚，见他在殿里耽搁这么久，就觉得奇怪。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 约翰福音 13:24; 使徒行传 21:40"> 他出来以后，不能对他们说话。他们就明白他在殿里看见了异象。他一直向他们打手势，却仍然说不出话来。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 9:25; 列王纪下 11:5–7"> 他供职的日子满了，就回家去了。</span>
<span className="v" id="v24" data-v="24"> 这些日子以后，他的妻子伊丽莎白怀了孕，隐藏了五个月，说：</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 30:22–23; 以赛亚书 54:1–4; 创世记 21:1–2"> “主眷顾我的日子，竟这样待我，除去了我在人前的羞辱。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 2:23; 路加福音 1:19; 约翰福音 7:41"> 到了第六个月，天使加百列奉上帝差遣，往加利利的一座城去，那城名叫拿撒勒，</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:18; 以赛亚书 7:14; 马太福音 1:16"> 到一个童女那里。她已经许配给一个名叫约瑟的人，他是大卫家的后裔。童女的名字叫马利亚。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 6:12; 但以理 10:19; 路加福音 1:30"> 天使进去，对她说：“蒙大恩的女子，愿你喜乐！主与你同在。你在女子中是蒙福的！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:17; 路加福音 1:12; 使徒行传 10:4"> 马利亚因这话十分不安，反复思想这样的问候是什么意思。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 罗马书 8:31; 路加福音 12:32"> 天使对她说：“马利亚，不要害怕，因为你在上帝面前蒙了恩。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 7:14; 马太福音 1:21; 马太福音 1:25"> 看哪，你要怀孕生一个儿子，要给他起名叫耶稣。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 9:6–7; 以赛亚书 16:5; 撒母耳记下 7:11–13"> 他将要成为伟大的人，要称为至高者的儿子。主上帝要把他祖先大卫的王位赐给他。</span>
<span className="v" id="v33" data-v="33" data-xref="但以理 2:44; 希伯来书 1:8; 但以理 7:13–14"> 他要作王，治理雅各家，直到永远；他的国度永无穷尽。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="士师记 13:8–12; 使徒行传 9:6"> 马利亚对天使说：“这怎么可能呢？我还没有同房。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:18; 约翰福音 1:49; 马太福音 1:20"> 天使回答她：“圣灵要临到你身上，至高者的能力要荫庇你。因此，那将要出生的圣者，要称为上帝的儿子。</span>
<span className="v" id="v36" data-v="36"> 看哪，你的亲戚伊丽莎白，在年老的时候也怀了一个儿子；那素来被称为不能生育的，如今已经有孕六个月了。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:26; 耶利米书 32:27; 马可福音 10:27"> 因为上帝所说的话，没有一句不能成就。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：“因为凡上帝所说的话都能成就。”">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="罗马书 4:20–21; 诗篇 119:38; 诗篇 116:16"> 马利亚说：“看哪，我是主的使女；愿你的话成就在我身上。”<br />于是天使离开了她。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:65; 约书亚记 15:48–59; 约书亚记 10:40"> 那些日子，马利亚起身，急忙往山地去，来到犹大的一座城。</span>
<span className="v" id="v40" data-v="40"> 她进了撒迦利亚的家，向伊丽莎白问安。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 1:67; 使徒行传 4:8; 路加福音 1:44"> 伊丽莎白一听见马利亚问安，腹中的婴孩就跳动起来；伊丽莎白也被圣灵充满。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 1:28; 士师记 5:24; 创世记 22:18"> 她高声喊着说：“你在女子中是蒙福的！你腹中的果子也是蒙福的！</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 20:28; 约翰福音 13:13; 路加福音 2:11"> 我主的母亲竟然到我这里来，我怎么配得这样的恩待？</span>
<span className="v" id="v44" data-v="44"> 看哪，你问安的声音一进我的耳朵，我腹中的婴孩就因喜乐而跳动。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 20:29; 约翰福音 11:40; 路加福音 11:27–28"> 那相信主对她所说的话必会成就的女子，是有福的！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v46" data-v="46" data-xref="撒母耳记上 2:1–10; 诗篇 34:2–3; 诗篇 35:9"> 马利亚说：<br /><span className="pl pl-1">“我的心尊主为大；</span></span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 35:9; 提摩太前书 2:3; 哈巴谷 3:18"> <span className="pl pl-2">我的灵因上帝我的救主欢喜，</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 138:6; 玛拉基书 3:12; 哥林多前书 1:26–28"> <span className="pl pl-2">因为他眷顾了他使女卑微的处境。</span><br /><span className="pl pl-1">看哪，从今以后，万代都要称我为有福。</span></span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 126:2–3; 诗篇 111:9; 以弗所书 3:20"> <span className="pl pl-2">因为那有大能者为我成就了大事；</span><br /><span className="pl pl-2">他的名是圣的。</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 103:17–18; 出埃及记 20:6; 创世记 17:7"> <span className="pl pl-2">他的怜悯临到敬畏他的人，直到世世代代。</span></span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 98:1; 以赛亚书 52:10; 撒母耳记上 2:3–4"> <span className="pl pl-1">他用膀臂施展大能；</span><br /><span className="pl pl-2">他驱散了心里狂傲妄想的人。</span></span>
<span className="v" id="v52" data-v="52" data-xref="以西结 17:24; 雅各书 4:10; 诗篇 107:40–41"> <span className="pl pl-1">他把掌权者从王位上拉下来，</span><br /><span className="pl pl-2">却高举卑微的人。</span></span>
<span className="v" id="v53" data-v="53" data-xref="诗篇 107:8–9; 路加福音 6:21; 诗篇 34:10"> <span className="pl pl-1">他用美物使饥饿的人得饱足，</span><br /><span className="pl pl-2">却叫富足的人空手而去。</span></span>
<span className="v" id="v54" data-v="54" data-xref="诗篇 98:3; 弥迦书 7:20; 以赛亚书 44:21"> <span className="pl pl-1">他扶助他的仆人以色列，</span><br /><span className="pl pl-2">为要记念他的怜悯，</span><br /></span>
<span className="v" id="v55" data-v="55" data-xref="诗篇 105:6–10; 创世记 17:19; 诗篇 132:11–17"> <span className="pl pl-2">正如他对我们祖先所说的，</span><br /><span className="pl pl-2">就是向亚伯拉罕和他的后裔</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：“种子”。">c</a></sup><br /><span className="pl pl-2">所应许的，直到永远。”</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> 马利亚和伊丽莎白同住了约三个月，然后回到自己家里。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="路加福音 1:13; 创世记 21:2–3; 路加福音 2:6–7"> 伊丽莎白生产的日子到了，她生了一个儿子。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:25; 路加福音 1:14; 罗马书 12:15"> 她的邻居和亲戚听见主向她大施怜悯，就和她一同喜乐。</span>
<span className="v" id="v59" data-v="59" data-xref="创世记 17:12; 利未记 12:3; 腓立比书 3:5"> 到了第八天，他们来给孩子行割礼，想照他父亲的名字叫他撒迦利亚。</span>
<span className="v" id="v60" data-v="60" data-xref="路加福音 1:13; 撒母耳记下 12:25; 路加福音 1:63"> 他的母亲回答说：“不行，他要叫约翰。”</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61"> 他们对她说：“你亲族中没有人叫这个名字。”</span>
<span className="v" id="v62" data-v="62" data-xref="路加福音 1:22"> 于是他们向孩子的父亲打手势，问他想给孩子起什么名字。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="路加福音 1:60; 以赛亚书 30:8; 路加福音 1:13"> 他要了一块写字板，写道：“他的名字是约翰。”<br />众人都惊奇。</span>
<span className="v" id="v64" data-v="64" data-xref="路加福音 1:20; 出埃及记 4:15–16; 以西结 33:22"> 他的口立刻开了，舌头也自由了，就开口称颂上帝。</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 1:39; 使徒行传 5:11; 路加福音 7:16"> 周围居住的人都生出敬畏的心；这些事传遍了犹太的整个山地。</span>
<span className="v" id="v66" data-v="66" data-xref="使徒行传 11:21; 路加福音 2:19; 路加福音 2:51"> 所有听见的人都把这些事存在心里，说：“这孩子将来会成为什么样的人呢？”因为主的手与他同在。</span>
</div>
<div className="bp poetry">
<span className="v" id="v67" data-v="67" data-xref="约珥 2:28; 路加福音 1:41; 路加福音 1:15"> 他的父亲撒迦利亚被圣灵充满，就预言说：</span>
<span className="v" id="v68" data-v="68" data-xref="诗篇 106:48; 路加福音 7:16; 诗篇 41:13"> <span className="pl pl-1">“主以色列的上帝是当受称颂的，</span><br /><span className="pl pl-2">因为他眷顾并救赎了自己的百姓；</span></span>
<span className="v" id="v69" data-v="69" data-xref="诗篇 18:2; 以西结 29:21; 撒母耳记下 22:3"> <span className="pl pl-1">他在他仆人大卫家中，</span><br /><span className="pl pl-2">为我们兴起了拯救的角，</span><br /></span>
<span className="v" id="v70" data-v="70" data-xref="使徒行传 3:21–24; 罗马书 1:2; 彼得后书 1:21"> <span className="pl pl-2">正如他从古以来，</span><br /><span className="pl pl-2">借着圣先知的口所说的；</span><br /></span>
<span className="v" id="v71" data-v="71" data-xref="诗篇 106:10; 耶利米书 23:6; 西番雅书 3:15–20"> <span className="pl pl-2">他要救我们脱离仇敌，</span><br /><span className="pl pl-2">脱离一切恨我们之人的手；</span></span>
<span className="v" id="v72" data-v="72" data-xref="希伯来书 6:13–18; 弥迦书 7:20; 诗篇 106:45"> <span className="pl pl-1">要向我们的祖先施怜悯，</span><br /><span className="pl pl-2">记念他的圣约，</span></span>
<span className="v" id="v73" data-v="73" data-xref="创世记 22:16–18; 诗篇 105:9; 申命记 7:8"> <span className="pl pl-1">就是他向我们祖先亚伯拉罕所起的誓。</span></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:7; 罗马书 14:13; 哥林多前书 11:19"> 耶稣对门徒说：<span className="woj">“使人跌倒的事不可能不来，但那使人跌倒的人有祸了！</span></span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 9:42; 马太福音 18:14; 马太福音 18:3–6"> <span className="woj">若把一块磨石拴在他的颈项上，把他丢在海里，还强过他使这些小子中的一个跌倒。</span></span>
<span className="v" id="v3" data-v="3" data-xref="利未记 19:17; 马太福音 18:21; 马太福音 18:15–17"> <span className="woj">你们要谨慎！若你的弟兄得罪你，就责备他；他若悔改，就赦免他。</span></span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12–13; 马太福音 18:21–22; 罗马书 12:20"> <span className="woj">若他一天七次得罪你，又七次回转来对你说：‘我悔改了’，你总要赦免他。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 9:24; 希伯来书 12:2; 腓立比书 4:13"> 使徒对主说：“求你加增我们的信心。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:20; 马太福音 21:21; 马可福音 9:23"> 主说：<span className="woj">“你们若有像一粒芥菜种那样的信心，就可以对这棵桑树说：‘连根拔起，栽在海里！’它也必听从你们。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:11; 路加福音 13:15; 路加福音 14:5"> <span className="woj">你们中间谁有仆人耕地或牧羊，从田里回来，就对他说：‘快来坐下吃饭’呢？</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 创世记 43:16; 撒母耳记下 12:20"> <span className="woj">岂不对他说：‘给我预备晚饭，束上腰服事我，等我吃喝完了，随后你才可以吃喝’吗？</span></span>
<span className="v" id="v9" data-v="9"> <span className="woj">仆人照所吩咐的做了，主人还要谢谢他吗？我想不会。</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 9:16–17; 约伯记 22:2–3; 彼得前书 5:5–6"> <span className="woj">你们也是这样，做完了一切所吩咐你们的，只当说：‘我们是不配受赏的仆人，所做的本是我们应尽的本分。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 约翰福音 4:3–4"> 耶稣往耶路撒冷去，经过撒玛利亚和加利利交界的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 13:45–46; 路加福音 5:12; 列王纪下 7:3"> 祂进一个村庄的时候，有十个麻风病人迎面而来，远远地站着，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:22; 马太福音 20:30–31; 马太福音 9:27"> 高声说：“耶稣，主啊，怜悯我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未记 13:1–46; 列王纪下 5:14"> 耶稣看见他们，就对他们说：<span className="woj">“你们去，把身体给祭司察看。”</span>他们去的时候，就洁净了。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 30:11–12; 诗篇 103:1–4; 诗篇 118:18–19"> 其中有一个见自己已经好了，就回来，大声荣耀上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 8:5–25; 马太福音 10:5; 启示录 19:10"> 又脸伏于地，俯伏在耶稣脚前感谢祂；这人是撒玛利亚人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 诗篇 106:13; 创世记 3:9"> 耶稣回答说：<span className="woj">“得洁净的不是十个人吗？那九个在哪里呢？</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 50:23; 马太福音 15:24–28; 诗篇 106:13"> <span className="woj">除了这外族人，就没有别人回来把荣耀归给上帝吗？”</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 马可福音 10:52"> 于是祂对那人说：<span className="woj">“起来，走吧；你的信心使你痊愈了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 18:36; 路加福音 19:11; 但以理 2:44"> 法利赛人问耶稣，上帝的国什么时候来到。祂回答他们说：<span className="woj">“上帝的国来到，不是凭外在观察可以看见的；</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:28; 罗马书 14:17; 马可福音 13:21"> <span className="woj">人也不能说：‘看哪，在这里！’或说：‘看哪，在那里！’因为看哪，上帝的国就在你们中间。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 5:35; 马太福音 9:15; 约翰福音 8:21–24"> 祂又对门徒说：<span className="woj">“日子将到，你们渴望看见人子的一个日子，却看不见。</span></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 马太福音 24:23–26; 路加福音 17:21"> <span className="woj">人要对你们说：‘看哪，在这里！’或说：‘看哪，在那里！’你们不要出去，也不要跟随他们，</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 24:27; 马太福音 24:30; 玛拉基书 4:1–2"> <span className="woj">因为闪电怎样从天这一边一闪，照到天那一边，人子在祂的日子也要这样。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 16:21; 路加福音 9:22; 马可福音 8:31"> <span className="woj">只是祂必须先受许多苦，又被这世代弃绝。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:37–39; 路加福音 17:24; 创世记 7:7–23"> <span className="woj">挪亚的日子怎样，人子的日子也要怎样。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒罗尼迦前书 5:1–3; 路加福音 16:19–23"> <span className="woj">那时人又吃又喝，又娶又嫁，直到挪亚进方舟的那日，洪水来了，把他们全都灭了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="以西结 16:49–50; 创世记 18:20–21; 雅各书 5:1–5"> <span className="woj">又像罗得的日子，人又吃又喝，又买又卖，又耕种又建造；</span></span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 2:6; 西番雅书 2:9; 犹大书 1:7"> <span className="woj">直到罗得离开所多玛的那日，有火与硫磺从天上降下来，把他们全都灭了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 1:7; 帖撒罗尼迦后书 1:7; 启示录 1:7"> <span className="woj">人子显现的日子，也要这样。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 21:21; 马可福音 13:14–16; 耶利米书 45:5"> <span className="woj">那日，人在屋顶上，财物在屋里，不要下来拿；人在田里的，也不要回去。</span></span>
<span className="v" id="v32" data-v="32" data-xref="创世记 19:26; 希伯来书 10:38–39; 彼得后书 2:18–22"> <span className="woj">你们要记念罗得的妻子！</span></span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:35–37; 马太福音 10:39; 约翰福音 12:25"> <span className="woj">凡想保全自己生命的，必丧失生命；凡丧失生命的，必保全生命。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 24:40–41; 彼得后书 2:9; 玛拉基书 3:16–18"> <span className="woj">我告诉你们，那一夜，两个人在一张床上，一个被取去，一个被留下。</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:41; 出埃及记 11:5; 士师记 16:21"> <span className="woj">两个女人一同推磨，一个被取去，一个被留下。”</span></span>

</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马太福音 24:28; 约伯记 39:29–30; 启示录 19:17–18"> 门徒回答祂说：“主啊，在哪里呢？”<br />祂对他们说：<span className="woj">“尸体在哪里，秃鹰也必聚集在那里。”</span></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 1:15; 马太福音 9:10–13; 路加福音 5:29–32"> 众税吏和罪人都挨近耶稣，要听祂讲道。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 法利赛人和文士就发怨言说：“这个人接待罪人，又和他们一同吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 耶稣就对他们讲这个比喻：</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 34:16; 以西结 34:11–12; 马太福音 18:12–14"> <span className="woj">“你们中间谁有一百只羊，若失去一只，不把九十九只留在旷野，去寻找那失去的，直到找着呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 12:2; 路加福音 19:9; 以赛亚书 46:3–4"> <span className="woj">找着了，就欢欢喜喜地把它扛在肩上。</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前书 2:25"> <span className="woj">到了家里，就请朋友和邻舍来，对他们说：‘请和我一同欢喜吧，因为我那失去的羊已经找着了！’</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> <span className="woj">我告诉你们，照样，一个罪人悔改，在天上也要这样为他欢喜，胜过为九十九个不用悔改的义人欢喜。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西结 34:12; 约翰福音 10:16"> <span className="woj">“或者，一个女人有十个德拉克马</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一个德拉克马银币约等于农业工人一天的工钱。">a</a></sup><span className="woj">银币，若失去一个，岂不点上灯，打扫屋子，仔细寻找，直到找着吗？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> <span className="woj">找着了，就请朋友和邻舍来，说：‘请和我一同欢喜吧，因为我那失去的德拉克马已经找着了！’</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多后书 7:10; 以西结 33:11"> <span className="woj">我告诉你们，照样，一个罪人悔改，在上帝的天使面前也有欢喜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 21:23–31"> 祂又说：<span className="woj">“有一个人有两个儿子。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 21:16–17; 马可福音 12:44; 路加福音 15:30"> <span className="woj">小儿子对父亲说：‘父亲，请把我应得的那份产业给我。’父亲就把产业分给他们。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米书 2:5; 箴言 21:17"> <span className="woj">过了不多几天，小儿子收拾了一切，往远方去了；在那里放荡度日，挥霍了自己的产业。</span></span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 33:11; 阿摩司 8:9–12; 何西阿 2:9–14"> <span className="woj">既耗尽了一切，那地方又发生大饥荒，他就开始穷困起来。</span></span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 提摩太后书 2:25–26; 以赛亚书 1:5"> <span className="woj">于是他去投靠那地方的一个居民；那人打发他到田里去放猪。</span></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:19–21; 耶利米哀歌 4:5; 何西阿 12:1"> <span className="woj">他恨不得拿猪所吃的豆荚填饱肚子，却没有人给他。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结 18:28; 以弗所书 2:4–5; 路加福音 15:18–19"> <span className="woj">他醒悟过来，就说：‘我父亲有多少雇工，粮食有余，我倒在这里快饿死了！</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 约翰一书 1:8–10; 路加福音 15:21"> <span className="woj">我要起来，到我父亲那里去，对他说：“父亲，我得罪了天，也得罪了你。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 42:6; 路加福音 5:8; 诗篇 84:10"> <span className="woj">我不配再称为你的儿子；把我当作一个雇工吧。”’</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 103:10–13; 诗篇 86:5; 诗篇 86:15"> <span className="woj">“他就起来，往父亲那里去。离家还远的时候，父亲看见他，就动了怜悯的心，跑去抱着他的颈项，连连亲吻他。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 51:4; 路加福音 15:18–19; 耶利米书 3:13"> <span className="woj">儿子对他说：‘父亲，我得罪了天，也得罪了你；我不配再称为你的儿子。’</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 41:42; 以斯帖记 8:2; 启示录 6:11"> <span className="woj">“父亲却对仆人说：‘快把那最好的袍子拿出来给他穿上；把戒指戴在他手上，把鞋穿在他脚上；</span></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 25:6; 马太福音 22:2–14; 诗篇 63:5"> <span className="woj">把那肥牛犊牵来宰了，我们可以吃喝庆祝；</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 2:5; 以西结 34:16; 路加福音 19:10"> <span className="woj">因为我这个儿子是死而复活，失而复得了。’他们就开始庆祝。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 150:4; 耶利米书 31:4; 路加福音 15:11–12"> <span className="woj">“那时，大儿子正在田里。他回来，离家不远，听见作乐跳舞的声音，</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">就叫了一个仆人来，问是什么事。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 9:17; 腓利门书 1:16; 使徒行传 22:13"> <span className="woj">仆人对他说：‘你的兄弟回来了；你父亲因为他平安健康地回来，就宰了肥牛犊。’</span></span>
<span className="v" id="v28" data-v="28" data-xref="约拿 4:9; 撒母耳记上 18:8; 约拿 4:1–4"> <span className="woj">大儿子却生气，不肯进去；他父亲就出来劝他。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亚书 7:3; 以赛亚书 65:5"> <span className="woj">他回答父亲说：‘看哪，我服事你这么多年，从来没有违背过你的命令，可是你从来没有给我一只山羊羔，让我和朋友一同庆祝。</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> <span className="woj">但你这个儿子，和娼妓吞尽了你的产业，他一回来，你倒为他宰了肥牛犊。’</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:27–28; 罗马书 9:4; 罗马书 11:1"> <span className="woj">“父亲对他说：‘孩子，你常和我同在，我一切所有的都是你的。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 2:1–10; 路加福音 15:24; 以赛亚书 35:10"> <span className="woj">可是你这个兄弟是死而复活，失而复得了；我们理当庆祝欢喜。’”</span></span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 12:41–44; 约翰福音 8:20; 马太福音 27:6"> 耶稣抬头观看，看见富有的人把捐项投入圣殿库中。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 12:42"> 又看见一个穷寡妇投了两个小铜钱。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直译为“两个 lepta”。两个 lepta 约等于农业工人一天工钱的百分之一。">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:12; 使徒行传 10:34; 哥林多后书 8:2–3"> 祂说：<span className="woj">“我实在告诉你们，这穷寡妇所投的，比众人都多；</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:44–45; 路加福音 15:12; 使徒行传 4:34"> <span className="woj">因为这些人都是从自己富余中拿出捐项给上帝；但她在贫穷中，把自己一切养生的都投上了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:20; 马太福音 24:1–51; 马可福音 13:1–37"> 有些人谈论圣殿怎样用美石和供物装饰，耶稣就说：</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:2; 马可福音 13:2; 耶利米哀歌 5:18"> <span className="woj">“至于你们所看见的这些，将来日子要到，没有一块石头留在另一块石头上，不被拆毁。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 1:6–7; 马可福音 13:14; 马可福音 13:3–4"> 他们问祂说：“老师，那么这些事什么时候发生呢？这些事将要成就的时候，有什么预兆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:1; 马可福音 13:5–6; 以弗所书 5:6"> 耶稣说：<span className="woj">“你们要谨慎，不要受迷惑；因为将有许多人冒我的名来，说：‘我是他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“我是”。">b</a></sup><span className="woj">，’又说：‘时候近了。’你们不要跟随他们。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 马太福音 24:6–8; 马可福音 13:7–8"> <span className="woj">你们听见战争和动乱，不要惊惶；因为这些事必须先发生，只是结局不会立刻来到。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:19–20; 马可福音 13:8; 历代志下 15:5–6"> 祂又对他们说：<span className="woj">“民要攻打民，国要攻打国。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:29–30; 路加福音 21:25–27"> <span className="woj">多处必有大地震、饥荒和瘟疫，又有可怕的事和从天上来的大神迹。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:12–14; 使徒行传 5:40; 使徒行传 22:30"> <span className="woj">但在这一切事以前，人要下手拿住你们，逼迫你们，把你们交给会堂和监狱，又为我的名把你们带到君王和总督面前。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:12; 腓立比书 1:28; 帖撒罗尼迦后书 1:5"> <span className="woj">这事将成为你们作见证的机会。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 马可福音 13:11; 马太福音 10:19–20"> <span className="woj">所以你们要心里定意，不要预先思想怎样申辩，</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:9; 以弗所书 6:19; 路加福音 12:12"> <span className="woj">因为我必赐给你们口才和智慧，是你们一切敌对的人所不能抵挡、不能反驳的。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 启示录 6:9; 弥迦书 7:5–6"> <span className="woj">你们甚至要被父母、弟兄、亲族和朋友出卖；他们也要把你们中间的一些人置于死地。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:19; 路加福音 6:22; 约翰福音 15:21"> <span className="woj">你们要因我的名被众人恨恶。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 10:30; 撒母耳记上 14:45; 路加福音 12:7"> <span className="woj">然而你们连一根头发也必不损坏。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:36; 马太福音 10:22; 雅各书 1:3"> <span className="woj">“你们凭着忍耐，就必得着自己的生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理 9:27; 马可福音 13:14"> <span className="woj">“你们看见耶路撒冷被军队围困，就知道它荒凉的日子近了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 6:1; 创世记 19:17; 路加福音 17:31–33"> <span className="woj">那时，在犹太的，应当逃到山上；在城里的，应当离开；在乡下的，不要进城。</span></span>
<span className="v" id="v22" data-v="22" data-xref="何西阿 9:7; 以赛亚书 65:12–16; 以赛亚书 63:4"> <span className="woj">因为这是报应的日子，要使经上所写的一切都得成就。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 13:17; 马太福音 24:19; 路加福音 23:29"> <span className="woj">当那些日子，怀孕的和奶孩子的有祸了！因为这地要有大灾难，这百姓要遭受忿怒。</span></span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:25; 启示录 11:2; 以赛亚书 63:18"> <span className="woj">他们要倒在刀下，又被掳到各国去；耶路撒冷要被外邦人践踏，直到外邦人的日期满了。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 13:10; 约珥 2:30–31; 启示录 6:12–14"> <span className="woj">“日、月、星辰要显出预兆；地上的万国也要困苦，因海和波涛的轰响而惊惶失措；</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:29; 申命记 28:65–67; 彼得后书 3:10–12"> <span className="woj">人想到将要临到世界的事，就吓得魂不附体，因为天上的万象都要震动。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:30; 启示录 1:7; 马可福音 13:26"> <span className="woj">那时，他们要看见人子带着能力和大荣耀，驾云降临。</span></span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 8:23; 以赛亚书 60:1–2; 以弗所书 4:30"> <span className="woj">这些事一开始发生，你们就当挺身昂首，因为你们的救赎近了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:32–35; 马可福音 13:28–30"> 耶稣又对他们讲一个比喻：<span className="woj">“你们看无花果树和各样树木。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:57"> <span className="woj">它们一发芽，你们自己看见，就知道夏天已经近了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 5:9; 希伯来书 10:37; 彼得前书 4:7"> <span className="woj">同样，你们看见这些事发生，也该知道上帝的国近了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:30; 马太福音 24:34; 马太福音 23:36"> <span className="woj">我实在告诉你们，这世代还没有过去，这一切都要成就。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 40:8; 马可福音 13:31; 马太福音 24:35"> <span className="woj">天地要废去，我的话却绝不会废去。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> <span className="woj">“你们要谨慎，免得你们的心被宴乐、醉酒和今生的忧虑压住，那日子就突然临到你们。</span></span>
<span className="v" id="v35" data-v="35" data-xref="启示录 16:15; 诗篇 11:6; 耶利米书 48:43–44"> <span className="woj">因为那日子要像网罗一样临到全地面上一切居住的人。</span></span>
<span className="v" id="v36" data-v="36" data-xref="约翰一书 2:28; 马太福音 25:13; 彼得前书 5:8"> <span className="woj">所以你们要时时警醒祷告，使你们能配得逃避这一切将要发生的事，并站在人子面前。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 马可福音 11:19; 马太福音 21:17"> 耶稣每日在圣殿里教导人，每夜出去，在名叫橄榄山的山上住宿。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:1–2"> 众百姓清早都到圣殿里来听祂讲道。</span>
</div>

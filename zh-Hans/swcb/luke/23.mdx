<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 马太福音 27:11–14; 路加福音 22:66"> 他们全体都起来，把耶稣带到彼拉多面前。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:6–7; 约翰福音 19:12; 路加福音 23:14"> 他们开始控告祂，说：“我们发现这个人煽惑我们的民族，禁止纳税给凯撒，又说自己是基督，是王。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 1:49; 提摩太前书 6:13; 路加福音 22:70"> 彼拉多问祂说：“你是犹太人的王吗？”<br />耶稣回答他说：<span className="woj">“你说的是。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:38; 路加福音 23:14–15; 路加福音 23:22"> 彼拉多对祭司长和众人说：“我查不出这个人有什么罪状。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:14; 约翰福音 1:43; 约翰福音 2:11"> 但他们越发坚持，说：“祂从加利利开始，直到这里，在犹太全地教导人，煽动百姓。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 5:37; 路加福音 13:1"> 彼拉多听见加利利，就问这人是不是加利利人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:1; 路加福音 13:31; 马太福音 14:1"> 既知道耶稣属于希律管辖，就把祂送到希律那里；那几天希律也在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:7–9; 马太福音 14:1; 马可福音 6:14"> 希律看见耶稣，就十分高兴；因为他听见过许多关于祂的事，早就想见祂，并且希望看祂行一件神迹。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 27:14; 马太福音 7:6; 彼得前书 2:23"> 于是希律问了祂许多话，耶稣却一言不答。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 11:53; 路加福音 23:14–15; 路加福音 23:5"> 祭司长和文士站在那里，极力控告祂。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 15:16–20; 马太福音 27:27–30; 诗篇 69:19–20"> 希律和他的士兵轻看祂，戏弄祂，给祂穿上华丽的衣服，又把祂送回彼拉多那里。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 4:27; 启示录 17:13–14; 诗篇 83:4–6"> 希律和彼拉多就在那一天彼此成了朋友；他们从前本是彼此为敌的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:14; 马太福音 27:21–23; 约翰福音 18:38"> 彼拉多召集祭司长、官长和百姓，</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 6:4; 希伯来书 7:26; 路加福音 23:1–2"> 对他们说：“你们把这个人带到我这里，说祂煽惑百姓。看哪，我在你们面前审问过祂，并没有查出祂在你们所控告的事上有什么罪状。</span>
<span className="v" id="v15" data-v="15"> 就是希律也没有查出；因为我把你们送到他那里去。可见祂没有做什么该死的事。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:26; 路加福音 23:22; 马可福音 15:15"> 所以我要责打祂，然后释放祂。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 每逢这节期，彼拉多必须释放一个囚犯给他们。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 省略第 17 节。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:36; 使徒行传 3:14; 使徒行传 22:22"> 他们却一齐喊叫说：“除掉这个人！给我们释放巴拉巴！”——</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 3:14; 路加福音 23:5; 路加福音 23:2"> 巴拉巴是因城里发生的一次叛乱和杀人，被下在监里的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 15:15; 马太福音 14:8–9; 马太福音 27:19"> 彼拉多愿意释放耶稣，就再次对他们说话，</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:22–25; 马可福音 15:13; 约翰福音 19:15"> 他们却喊着说：“钉十字架！钉祂十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 23:14; 路加福音 23:20; 彼得前书 3:18"> 彼拉多第三次对他们说：“为什么呢？这个人做了什么恶事？我并没有查出祂有该死的罪。所以我要责打祂，然后释放祂。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 11:8; 诗篇 57:4; 诗篇 22:12–13"> 他们却大声催逼，要求把祂钉十字架。他们的声音和祭司长的声音占了上风。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 27:26; 出埃及记 23:2; 箴言 17:15"> 彼拉多就判定照他们所求的办理。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 3:14; 马可福音 15:6–7; 马可福音 15:15"> 他释放了他们所求的那因叛乱和杀人被下在监里的人，却把耶稣交给他们，任凭他们的意思去行。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:32–44; 马可福音 15:21–32; 使徒行传 6:9"> 他们把耶稣带走的时候，抓住一个从乡下来的古利奈人西门，把十字架搁在他身上，叫他背着跟在耶稣后面。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 8:52; 路加福音 8:2; 马可福音 15:40"> 有许多百姓跟随耶稣，其中也有妇女为祂捶胸哀哭。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> 耶稣转身对她们说：<span className="woj">“耶路撒冷的女子啊，不要为我哭，要为你们自己和你们的儿女哭。</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:19; 路加福音 21:23–24; 马可福音 13:17–19"> <span className="woj">看哪，日子将到，那时人要说：‘不生育的、未曾怀胎的、未曾乳养婴孩的，是有福的。’</span></span>
<span className="v" id="v30" data-v="30" data-xref="启示录 6:16; 何西阿 10:8; 以赛亚书 2:19"> <span className="woj">那时，他们要开始对大山说：‘倒在我们身上吧！’对小山说：‘遮盖我们吧！’</span></span>
<span className="v" id="v31" data-v="31" data-xref="彼得前书 4:17–18; 约翰福音 15:6; 箴言 11:31"> <span className="woj">因为人若在树青的时候这样行，树枯的时候又将怎样呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 15:27; 以赛亚书 53:12; 马太福音 27:38"> 又有两个犯人也和祂一同被带去处死。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 15:22–23; 约翰福音 19:17–18; 约翰福音 18:32"> 到了那名叫“髑髅”的地方，他们就在那里把耶稣钉在十字架上，也把两个犯人钉上，一个在右边，一个在左边。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:44; 使徒行传 7:60; 彼得前书 3:9"> 耶稣说：<span className="woj">“父啊，赦免他们，因为他们不知道自己在做什么。”</span><br />他们拈阄分了祂的衣服。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 22:17; 以赛亚书 42:1; 彼得前书 2:4"> 百姓站在那里观看。官长也嗤笑祂，说：“祂救了别人；祂若是上帝的基督，是那蒙拣选者，就让祂救自己吧！”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马太福音 27:48; 马太福音 27:34"> 士兵也戏弄祂，上前拿酸酒送给祂，</span>
<span className="v" id="v37" data-v="37"> 说：“你若是犹太人的王，就救自己吧！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马可福音 15:26; 马太福音 27:37; 约翰福音 19:19–22"> 在祂上方也有牌子，用希腊文、拉丁文和希伯来文写着：“这是犹太人的王。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:44; 马可福音 15:32; 路加福音 23:35"> 悬挂着的犯人中有一个辱骂祂，说：“你不是基督吗？救你自己和我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="以弗所书 5:11; 路加福音 12:5; 启示录 15:4"> 另一个却回答，责备他说：“你既是同受刑罚，还不惧怕上帝吗？</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 26:40–41; 以斯拉记 9:13; 彼得前书 1:19"> 我们受刑是应该的，因为我们所受的，是自己行为该得的报应；但这个人没有做过一件不对的事。”</span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 10:9–14; 使徒行传 16:31; 约翰一书 5:11–13"> 他又对耶稣说：“主啊，你进入你国的时候，求你记念我。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="启示录 2:7; 诗篇 50:15; 提摩太前书 1:15–16"> 耶稣对他说：<span className="woj">“我实在告诉你，今天你要同我在乐园里了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 27:45; 马可福音 15:33–34; 阿摩司 8:9"> 那时约有第六小时<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="时间从日出算起，所以第六小时约为正午。">b</a></sup>，黑暗笼罩全地，直到第九小时<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="下午三点。">c</a></sup>。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 10:19–22; 马太福音 27:51; 希伯来书 9:3–8"> 太阳昏暗了，圣殿的幔子从中间裂为两半。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 31:5; 使徒行传 7:59; 约翰福音 19:30"> 耶稣大声呼喊说：<span className="woj">“父啊，我将我的灵交在你手里！”</span>说了这话，祂就断了气。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马太福音 27:54; 马可福音 15:39; 路加福音 23:41"> 百夫长看见所发生的事，就荣耀上帝，说：“这个人真是义人。”</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 18:13; 使徒行传 2:37; 耶利米书 31:19"> 聚集观看的众人，看见所发生的事，都捶着胸回去了。</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 8:2; 诗篇 38:11; 路加福音 23:55"> 一切认识耶稣的人，以及从加利利跟随祂来的妇女，都远远地站着观看这些事。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:38–42; 使徒行传 11:24; 使徒行传 10:22"> 看哪，有一个人名叫约瑟，是议会成员，为人善良公义；</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:25; 路加福音 2:38; 以赛亚书 8:12"> 他并没有赞同他们的计谋和所行的事。他是犹太人的城亚利马太人，也在等候上帝的国。</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 19:38–42"> 这人去见彼拉多，求取耶稣的身体。</span>
<span className="v" id="v53" data-v="53" data-xref="马太福音 27:59–60; 以赛亚书 53:9; 马可福音 15:46"> 他把身体取下来，用细麻布裹好，安放在石头凿成、从来没有葬过人的坟墓里。</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 27:62; 约翰福音 19:31; 马可福音 15:42"> 那日是预备日，安息日快到了。</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 23:49; 马太福音 27:61; 马可福音 15:47"> 那些从加利利同耶稣来的妇女跟在后面，看见坟墓，也看见祂的身体怎样安放。</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 24:1; 马可福音 16:1; 申命记 5:14"> 她们回去，预备了香料和香膏。安息日，她们便照诫命安息了。</span>
</div>

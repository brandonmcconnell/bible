<span className="v" id="v2" data-v="2"> 看哪，有一个患水肿病的人在祂面前。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:10; 马可福音 3:4; 路加福音 13:14–16"> 耶稣回应律法师和法利赛人，说：<span className="woj">“安息日治病合乎律法吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 22:46; 马太福音 21:25–27"> 他们却沉默不语。<br />耶稣扶着那人，治好了他，就让他走了。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及记 23:4–5; 马太福音 12:11–12"> 祂又对他们说：<span className="woj">“你们中间谁的儿子</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 作“驴”，而非“儿子”。">a</a></sup><span className="woj">或牛在安息日掉进井里，不立刻拉他上来呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行传 6:10"> 他们不能回答这些话。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:3; 路加福音 11:43; 马太福音 23:6"> 耶稣见所请的客人怎样选择首位，就对他们讲了一个比喻，说：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> <span className="woj">“你被人请去赴婚宴的时候，不要坐在首位上；恐怕有比你更尊贵的客人也被他请来，</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> <span className="woj">那请你们两人的就来对你说：‘把座位让给这一位吧。’那时你就羞愧地退到末位去了。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳记上 15:17"> <span className="woj">你被请的时候，要去坐在末位上；这样，请你的人来了，就对你说：‘朋友，请上座。’那时，你在同席的人面前就有光彩了。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 马太福音 23:12; 箴言 29:23"> <span className="woj">因为凡自高的，必降为卑；凡自卑的，必升为高。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:46; 雅各书 2:1–6; 路加福音 6:32–36"> 耶稣也对请祂的人说：<span className="woj">“你摆设午饭或晚饭的时候，不要请你的朋友、兄弟、亲族和富有的邻舍，恐怕他们也回请你，你就得了报答。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以赛亚书 58:10; 箴言 14:31"> <span className="woj">你摆设筵席，倒要请贫穷的、残疾的、瘸腿的、瞎眼的；</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行传 24:15; 约翰福音 5:29"> <span className="woj">你就有福了，因为他们没有能力报答你；到义人复活的时候，你必得报答。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 路加福音 22:30; 路加福音 13:29"> 同席的人中有一个听见这些话，就对耶稣说：“在上帝国里吃饭的人有福了！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 22:2–14; 启示录 22:17; 以赛亚书 55:1–7"> 耶稣对他说：<span className="woj">“有一个人摆设大筵席，请了许多人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:27–29; 马太福音 10:1–4; 马太福音 22:3–4"> <span className="woj">到了筵席的时候，他差仆人去对所请的人说：‘请来吧，因为样样都已经预备好了。’</span></span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> <span className="woj">众人却异口同声地推辞。</span><br /><span className="woj">“第一个对他说：‘我买了一块田，必须去看看。请你准我辞了。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> <span className="woj">“另一个说：‘我买了五对牛，要去试一试。请你准我辞了。’</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 24:5; 哥林多前书 7:33; 路加福音 14:26–28"> <span className="woj">“又一个说：‘我刚娶了妻，所以不能去。’</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 马太福音 11:5; 路加福音 14:24"> <span className="woj">“那仆人回来，把这些事告诉主人。家主就动怒，对仆人说：‘快出去，到城里的大街小巷，把贫穷的、残疾的、瞎眼的、瘸腿的都带进来。’</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 14:2; 以弗所书 3:8; 提摩太前书 2:5–6"> <span className="woj">“仆人说：‘主啊，你所吩咐的已经办了，还有空位。’</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:9–10; 歌罗西书 1:28; 使徒行传 13:47–48"> <span className="woj">“主人对仆人说：‘出去到大路和篱笆那里，勉强人进来，好坐满我的屋子。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:43; 使徒行传 13:46; 约翰福音 8:24"> <span className="woj">我告诉你们，先前所请的那些人，没有一个能尝我的筵席。因为被召的人多，蒙选的人少。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="RP MT 包含最后一句。TR、NU 和 FH MT 省略：“因为被召的人多，蒙选的人少。”">b</a></sup><span className="woj">’”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:24–27; 路加福音 12:1"> 有大群人和耶稣同行。祂转身对他们说：</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:37; 约翰福音 12:25; 腓立比书 3:8"> <span className="woj">“若有人到我这里来，不轻看</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“恨”。">c</a></sup><span className="woj">自己的父母、妻子、儿女、弟兄、姐妹，甚至自己的生命，就不能作我的门徒。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 10:38; 路加福音 9:23–25; 马可福音 8:34–37"> <span className="woj">凡不背着自己的十字架来跟从我的，也不能作我的门徒。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 马太福音 10:22; 约书亚记 24:19–24"> <span className="woj">你们中间谁想要建一座楼，不先坐下来计算费用，看自己能不能完成呢？</span></span>
<span className="v" id="v29" data-v="29"> <span className="woj">恐怕他立了根基，却不能完工，凡看见的人就开始讥笑他，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 6:11; 约翰二书 1:8; 哥林多前书 3:11–14"> <span className="woj">说：‘这个人开了工，却不能完工。’</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王纪下 18:20–22"> <span className="woj">或者，一个王出去和另一个王打仗，岂不先坐下来谋算，自己能不能用一万人去迎战那带着两万人来攻打他的呢？</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 12:20; 雅各书 4:6–10; 路加福音 12:58"> <span className="woj">若不能，就趁对方还远的时候，派使者去求和。</span></span>
<span className="v" id="v33" data-v="33" data-xref="腓立比书 3:7–8; 约翰一书 2:15–16; 路加福音 5:28"> <span className="woj">这样，你们无论谁，若不撇下一切所有的，就不能作我的门徒。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:13; 歌罗西书 4:6; 马可福音 9:49–50"> <span className="woj">“盐本是好的；但盐若失了味，怎能使它再有咸味呢？</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 11:15; 路加福音 9:44; 启示录 2:11"> <span className="woj">它既不适合放在田里，也不适合放在粪堆里，只好丢在外面。有耳可听的，就应当听。”</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:1–11; 使徒行传 10:38; 马可福音 1:12–13"> 耶稣满有圣灵，从约旦河回来，被圣灵引到旷野，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:28; 希伯来书 4:15; 申命记 9:9"> 四十天受魔鬼试探。那些日子，祂什么也没有吃；日子满了以后，祂就饿了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:3; 路加福音 3:22"> 魔鬼对祂说：“你若是上帝的儿子，就吩咐这块石头变成饼吧。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 8:3; 马太福音 4:4; 马太福音 6:31"> 耶稣回答他说：<span className="woj">“经上记着：‘人活着，不是单靠食物，乃是靠上帝口里所出的一切话。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:15–16; 哥林多前书 15:52; 马太福音 4:8"> 魔鬼又领祂上了一座高山，霎时间把天下万国都指给祂看。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 12:31; 约翰一书 5:19; 约翰福音 14:30"> 魔鬼对祂说：“这一切权柄和它们的荣华，我都要给你；因为这些已经交给我，我愿意给谁就给谁。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 8:28; 诗篇 72:11; 以赛亚书 45:14"> 所以，你若在我面前敬拜，这一切就都是你的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 6:13; 申命记 10:20; 马太福音 4:10"> 耶稣回答他说：<span className="woj">“撒但，退到我后面去！因为经上记着：‘你要敬拜主你的上帝，单要事奉祂。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="马太福音 4:5–6; 路加福音 4:3; 马太福音 8:29"> 魔鬼又领祂到耶路撒冷，使祂站在圣殿顶端，对祂说：“你若是上帝的儿子，就从这里跳下去吧；</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:11–12; 希伯来书 1:14; 哥林多后书 11:14"> 因为经上记着：<br /><span className="pl pl-1">‘祂要为你吩咐祂的天使保护你；’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="诗篇 91:12"> 又说：<br /><span className="pl pl-1">‘他们要用手托住你，</span><br /><span className="pl pl-2">免得你的脚碰在石头上。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 6:16; 希伯来书 3:8–9; 哥林多前书 10:9"> 耶稣回答他说：<span className="woj">“经上说：‘不可试探主你的上帝。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="希伯来书 4:15; 雅各书 4:7; 马太福音 4:11"> 魔鬼用尽了各样试探，就暂时离开祂。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23–25; 使徒行传 10:37; 马太福音 4:12"> 耶稣带着圣灵的能力回到加利利；关于祂的消息传遍了周围地区。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 4:23; 马太福音 9:8; 马太福音 9:35"> 祂在他们的会堂里教导人，众人都称赞祂。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:2; 使徒行传 13:14–16; 马太福音 2:23"> 耶稣来到拿撒勒，就是祂长大的地方。照祂平常的规矩，安息日进了会堂，站起来要诵读。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 61:1–3; 使徒行传 13:15; 使徒行传 7:42"> 有人把先知以赛亚的书交给祂。祂展开书卷，找到一处写着：</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 61:1; 马太福音 11:5; 诗篇 146:7–8"> <span className="pl pl-1 woj">“主的灵在我身上，</span><br /><span className="pl pl-2 woj">因为祂膏立我，叫我传福音给贫穷的人。</span><br /><span className="pl pl-1 woj">祂差遣我医治伤心的人，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 省略“医治伤心的人”。">a</a></sup><br /><span className="pl pl-2 woj">宣告被掳的得释放，</span><br /><span className="pl pl-2 woj">瞎眼的得看见，</span><br /><span className="pl pl-2 woj">叫受压制的得自由，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 61:2; 以赛亚书 63:4; 哥林多后书 6:1"> <span className="pl pl-2 woj">并宣告主悦纳人的禧年。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 4:17; 约翰福音 8:2; 路加福音 19:48"> 祂把书卷卷起来，交还给侍役，就坐下。会堂里众人的眼睛都定睛看祂。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 4:25–26; 使徒行传 3:18; 使徒行传 2:16–18"> 祂就对他们说：<span className="woj">“今天这经文在你们耳中已经应验了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 13:54–56; 诗篇 45:2; 使徒行传 6:10"> 众人都为祂作见证，并希奇祂口中所出的恩言；他们说：“这不是约瑟的儿子吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:46–53; 马太福音 11:23–24; 马可福音 2:1–12"> 祂对他们说：<span className="woj">“你们必定要用这句俗语对我说：‘医生，医治你自己吧！我们听说你在迦百农所行的事，也在你自己的家乡这里行吧。’”</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 13:57; 约翰福音 4:44; 马可福音 6:4–5"> 祂又说：<span className="woj">“我实在告诉你们，没有先知在自己家乡是受欢迎的。</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 5:17; 列王纪上 17:1; 马太福音 20:15"> <span className="woj">我确实告诉你们，以利亚的日子，天闭塞了三年六个月，遍地有大饥荒；那时以色列中有许多寡妇。</span></span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 17:9–24; 马太福音 11:21; 俄巴底亚 1:20"> <span className="woj">可是以利亚并没有奉差遣到她们中任何一人那里去，只奉差遣到西顿地的撒勒法，一个寡妇那里去。</span></span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 5:1–27; 约翰福音 17:12; 马太福音 12:4"> <span className="woj">先知以利沙的时候，以色列中有许多麻风病人，却没有一个得洁净，只有叙利亚人乃缦得了洁净。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 5:33; 历代志下 24:20–21; 耶利米书 38:6"> 会堂里的人听见这些话，都怒气填胸。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:59; 使徒行传 21:28–32; 民数记 15:35"> 他们起来，把祂赶出城，带到他们城所建山岭的崖边，要把祂推下去。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:39; 约翰福音 8:59; 约翰福音 18:6–7"> 祂却从他们中间走过去，离开了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 1:21–28; 马太福音 4:13; 使徒行传 13:50–2"> 祂下到加利利的一座城迦百农去，在安息日教导众人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 4:36; 马太福音 7:28–29; 约翰福音 6:63"> 他们对祂的教导感到惊奇，因为祂的话带着权柄。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:23"> 会堂里有一个人，被污鬼的灵附着，就大声喊叫，</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 1:24; 雅各书 2:19; 马太福音 8:29"> 说：“唉！拿撒勒人耶稣，我们与你有什么相干？你来要毁灭我们吗？我知道你是谁，是上帝的圣者！”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 4:41; 路加福音 4:39; 马太福音 8:26"> 耶稣斥责他说：<span className="woj">“住口！从他里面出来！”</span>鬼把那人摔倒在众人中间，就从他里面出来，并没有伤害他。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="路加福音 4:32; 彼得前书 3:22; 马太福音 12:22–23"> 众人都惊讶，彼此谈论说：“这是什么话？祂竟用权柄和能力吩咐污灵，污灵就出来了！”</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 1:45; 路加福音 4:14; 以赛亚书 52:13"> 于是关于祂的消息传遍了周围各地。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 8:14–15; 马可福音 1:29–31; 约翰福音 11:22"> 耶稣离开会堂，进了西门的家。西门的岳母害了重热病，他们为她求耶稣。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 4:41; 路加福音 4:35; 路加福音 8:24"> 耶稣站在她旁边，斥责那热病，热病就退了；她立刻起来服事他们。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:32–34; 马太福音 8:16–17; 马可福音 5:23"> 日落的时候，凡有病人的，不论患什么病，都把他们带到耶稣那里；祂一一按手在他们身上，医治他们。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:34; 雅各书 2:19; 路加福音 4:34–35"> 又有鬼从许多人身上出来，喊着说：“你是基督，上帝的儿子！”耶稣斥责他们，不许他们说话，因为他们知道祂是基督。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 马可福音 1:35–38; 约翰福音 4:34"> 天亮的时候，祂出去，到旷野地方。众人寻找祂，来到祂那里，挽留祂，不让祂离开他们。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 1:38–39; 提摩太后书 4:2; 约翰福音 9:4"> 但祂对他们说：<span className="woj">“我也必须到别的城传上帝国的福音；因为我正是为这事奉差遣的。”</span></span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 4:23; 马可福音 1:39; 路加福音 4:15"> 于是祂在加利利的各会堂传道。</span>
</div>
</div>

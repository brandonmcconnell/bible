<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 马太福音 25:14–30; 雅各书 4:3"> 耶稣又对门徒说：<span className="woj">“有一个财主，有一个管家。有人向他告发这管家浪费他的财物。</span></span>

</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 5:31; 以赛亚书 10:3; 箴言 18:9"> <span className="woj">“那管家心里说：‘主人要夺去我管家的职分，我该怎么办呢？锄地吧，我没有力气；讨饭吧，我又羞愧。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:9; 耶利米书 4:22; 雅各书 3:15"> <span className="woj">我知道该怎么做了，好叫我被撤去管家职分以后，有人接我到他们家里去。’</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:41–42; 马太福音 18:24"> <span className="woj">于是他把主人的债户一个一个叫来，问第一个说：‘你欠我主人多少？’</span></span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:10; 路加福音 16:12; 路加福音 16:9"> <span className="woj">他说：‘一百罢特</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百罢特约为三百九十五升，或一百零四美制加仑。">a</a></sup><span className="woj">油。’管家对他说：‘拿你的账，快坐下，写五十。’</span></span>
<span className="v" id="v7" data-v="7" data-xref="雅歌 8:11–12; 路加福音 20:9; 路加福音 20:12"> <span className="woj">又问另一个说：‘你欠多少？’他说：‘一百歌珥</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一百歌珥约为二千一百一十升，或六百蒲式耳。">b</a></sup><span className="woj">麦子。’管家对他说：‘拿你的账，写八十。’</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:5; 以弗所书 5:8; 箴言 6:6–8"> <span className="woj">“主人就称赞这不义的管家，因为他做事精明；因为今世之子在自己的世代里，比光明之子更精明。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 19:21; 提摩太前书 6:17–19; 但以理 4:27"> <span className="woj">我告诉你们，要借着不义的钱财为自己结交朋友，好叫钱财无用的时候，他们可以接你们到永远的帐幕里。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:11–12; 马太福音 25:21; 路加福音 19:17"> <span className="woj">在最小的事上忠心的，在大事上也忠心；在最小的事上不义的，在大事上也不义。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 12:33; 雅各书 2:5; 箴言 8:18–19"> <span className="woj">所以，你们若在不义的钱财上不忠心，谁还把真实的财富托付给你们呢？</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 19:13–26; 马太福音 25:14–29; 约伯记 1:21"> <span className="woj">你们若在别人的东西上不忠心，谁还把属于你们自己的东西给你们呢？</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 2:15–16; 马太福音 6:24; 雅各书 4:4"> <span className="woj">没有仆人能事奉两个主人；不是恨这个爱那个，就是依附这个轻看那个。你们不能又事奉上帝，又事奉玛门。”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“玛门”指财富，或财富的假神。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:35; 路加福音 20:47; 耶利米书 6:13"> 法利赛人是贪爱钱财的，他们听见这一切话，就嗤笑耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:7; 箴言 21:2; 哥林多前书 4:5"> 耶稣对他们说：<span className="woj">“你们是在人面前自称为义的人，但上帝知道你们的心；因为在人中间被高举的，在上帝面前是可憎的。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 11:9–14; 马太福音 21:32; 使徒行传 3:24–25"> <span className="woj">“律法和先知到约翰为止；从那时起，上帝国的福音被传开，人人都奋力要进去。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:18; 路加福音 21:33; 彼得前书 1:25"> <span className="woj">但天地废去，比律法的一点一画落空还容易。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 19:9; 马可福音 10:11–12; 马太福音 5:31–32"> <span className="woj">“凡休妻另娶的，就是犯奸淫；娶被丈夫休了的女人，也是犯奸淫。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结 16:49; 阿摩司 6:4–6; 路加福音 18:24–25"> <span className="woj">“有一个财主，穿着紫色袍和细麻布衣服，天天奢华宴乐。</span></span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:2; 撒母耳记上 2:8; 雅各书 2:5"> <span className="woj">又有一个讨饭的，名叫拉撒路，浑身生疮，被人放在财主门口，</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 15:27; 马可福音 7:28; 约翰福音 6:12"> <span className="woj">想要拿财主桌上掉下来的碎渣充饥；甚至狗也来舔他的疮。</span></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:24; 诗篇 49:16–19; 雅各书 1:11"> <span className="woj">后来那讨饭的死了，被天使带到亚伯拉罕怀里。财主也死了，并且埋葬了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:4; 路加福音 16:28; 马太福音 18:9"> <span className="woj">他在阴间</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作“地狱”。">d</a></sup><span className="woj">受痛苦，举目远远看见亚伯拉罕，又看见拉撒路在他怀里。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 4:10; 启示录 22:1; 启示录 7:16–17"> <span className="woj">他就喊着说：‘我祖亚伯拉罕哪，可怜我吧！请差拉撒路来，用指尖蘸点水凉凉我的舌头；因为我在这火焰里极其痛苦。’</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:24; 约翰一书 2:15; 诗篇 17:14"> <span className="woj">“亚伯拉罕说：‘孩子，你要想起，你生前享过福，拉撒路也同样受过苦；如今他在这里得安慰，你倒受痛苦。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 3:36; 诗篇 49:14; 诗篇 50:22"> <span className="woj">不但这样，在我们和你们之间，有深渊限定，以致人要从这里过到你们那里不能，从那边过到我们这里也不能。’</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> <span className="woj">“财主说：‘我父啊，那么求你差他到我父家去；</span></span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:40; 诗篇 49:12–13; 帖撒罗尼迦前书 4:6"> <span className="woj">因为我还有五个兄弟；让他警告他们，免得他们也来到这痛苦的地方。’</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:21; 路加福音 24:27; 路加福音 16:16"> <span className="woj">“亚伯拉罕说：‘他们有摩西和先知的话，可以听从。’</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 16:9–11; 路加福音 16:24; 路加福音 13:5"> <span className="woj">“他说：‘不，我祖亚伯拉罕哪！若有一个从死人中到他们那里去，他们必要悔改。’</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:3; 使徒行传 19:8; 约翰福音 11:43–53"> <span className="woj">“亚伯拉罕对他说：‘他们若不听摩西和先知的话，就是有一个从死人中复活，他们也不会信服。’”</span></span>
</div>

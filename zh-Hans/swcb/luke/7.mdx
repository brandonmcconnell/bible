<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LUK" data-book-slug="luke" data-book-name="路加福音" data-chapter="7" data-verses="50">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:5–13; 路加福音 7:1–10; 马太福音 7:28–29"> 耶稣在百姓耳中讲完这一切话，就进了迦百农。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:2–3; 创世记 24:27; 约翰福音 4:46–47"> 有一个百夫长所看重的仆人病得快要死了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 8:5; 约翰福音 4:47; 路加福音 9:38"> 百夫长听见耶稣的事，就差几个犹太人的长老去求祂来救他的仆人。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 马太福音 10:11; 路加福音 7:6–7"> 他们来到耶稣那里，就恳切地求祂，说：“你为他做这事，他是配得的；</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 2:11–12; 历代志上 29:3–9; 列王纪上 5:1"> 因为他爱我们的民族，又为我们建造了会堂。”</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 5:24; 创世记 32:10; 雅各书 4:6"> 耶稣就和他们同去。离那家不远的时候，百夫长又差几个朋友来对祂说：“主啊，不必劳驾了，因为我不配让你到我屋檐下；</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 107:20; 诗篇 33:9; 路加福音 4:36"> 所以我也自认为不配亲自到你那里去。只要你说一句话，我的仆人就必痊愈。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:22; 使徒行传 23:17; 使徒行传 22:25–26"> 因为我也是受权柄管辖的人，手下也有士兵。我对这个说：‘去！’他就去；对那个说：‘来！’他就来；对我的仆人说：‘做这事！’他就做。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 15:28; 罗马书 3:1–3; 马太福音 8:10"> 耶稣听见这些话，就对他感到惊奇，转身对跟随祂的众人说：<span className="woj">“我告诉你们，这样大的信心，就是在以色列中，我也没有见过。”</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:50–53; 马太福音 8:13; 马太福音 15:28"> 那些奉差来的人回到家里，看见那病仆已经好了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 10:38"> 不久以后，耶稣往一座名叫拿因的城去，祂的许多门徒和一大群人同祂一起去。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王纪上 17:9"> 将近城门的时候，看哪，有一个死人被抬出来；他是母亲的独生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“独生”译自希腊词“μονογενής”，也可译为“唯一的”或“独一的”。">a</a></sup>儿子，而他母亲又是寡妇。城里有许多人陪着她。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:13; 以赛亚书 63:9; 诗篇 86:15"> 主看见她，就怜悯她，对她说：<span className="woj">“不要哭。”</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:25; 约翰福音 11:43–44; 使徒行传 9:40–41"> 祂走近，摸了棺架，抬的人就站住了。祂说：<span className="woj">“年轻人，我吩咐你，起来！”</span></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 列王纪下 4:32–37; 列王纪上 17:23–24"> 那死人就坐起来，开始说话。耶稣便把他交给他母亲。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 众人都满心敬畏，荣耀上帝，说：“有一位大先知在我们中间兴起来了！”又说：“上帝眷顾了祂的百姓！”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 4:24; 马可福音 6:14; 马太福音 9:26"> 关于耶稣的这消息传遍了整个犹太和周围各地。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:26; 马太福音 11:2–19"> 约翰的门徒把这一切事告诉了约翰。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:6–7; 约翰福音 4:25; 创世记 22:18"> 约翰叫了两个门徒来，差他们到耶稣那里，说：“你就是那要来的吗？还是我们该等候别人？”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 那两个人来到耶稣那里，说：“施洗者约翰差我们来问你：‘你就是那要来的吗？还是我们该等候别人？’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:10; 诗篇 90:7–9; 希伯来书 12:6"> 正在那时候，耶稣医好了许多患疾病、灾病和被邪灵折磨的人，又使许多瞎眼的人得以看见。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 35:5–6; 以赛亚书 61:1–3; 路加福音 4:18"> 耶稣回答他们说：<span className="woj">“你们去，把所看见、所听见的事告诉约翰：瞎子看见，瘸子行走，麻风病人得洁净，聋子听见，死人复活，贫穷的人有福音传给他们。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 11:6; 彼得前书 2:7–8; 罗马书 9:32–33"> <span className="woj">凡不因我跌倒的，就是有福的。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以弗所书 4:14; 约翰福音 1:23; 路加福音 1:80"> 约翰所差来的人离开以后，耶稣就对众人讲论约翰，说：<span className="woj">“你们从前出去到旷野，是要看什么呢？看风吹动的芦苇吗？</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 59:17; 以斯帖记 8:15; 以斯帖记 1:3"> <span className="woj">你们出去到底是要看什么呢？看穿细软衣服的人吗？看哪，那些衣着华丽、生活奢华的人，是在王宫里。</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 约翰福音 5:35; 路加福音 20:6"> <span className="woj">你们出去到底是要看什么呢？看先知吗？是的，我告诉你们，他比先知大多了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="玛拉基书 3:1; 路加福音 1:76; 马可福音 1:2"> <span className="woj">经上所记的就是他：</span><br /><span className="pl pl-1 woj">‘看哪，我要差遣我的使者在你面前，</span><br /><span className="pl pl-2 woj">他要在你前面预备你的道路。’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 13:16–17; 马太福音 11:11; 歌罗西书 1:25–27"> <span className="woj">“我告诉你们，凡妇人所生的，没有一个先知大过施洗者约翰；然而在上帝国里最小的，也比他大。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行传 18:25"> 众百姓和税吏听见这话，既受过约翰的洗，就承认上帝是公义的。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多后书 6:1; 马太福音 22:35"> 但法利赛人和律法师没有受约翰的洗，就为自己拒绝了上帝的旨意。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 11:16–19; 耶利米哀歌 2:13; 马可福音 4:30"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 加有“主说”。">b</a></sup><span className="woj">“这样，我该用什么来比这世代的人呢？他们像什么呢？</span></span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 11:16–19; 耶利米书 5:3–5; 箴言 17:16"> <span className="woj">他们像孩子坐在市场上，彼此呼喊说：‘我们向你们吹笛，你们不跳舞；我们唱哀歌，你们不哭泣。’</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 马可福音 1:6; 约翰福音 8:52"> <span className="woj">施洗者约翰来了，不吃饼，也不喝酒，你们就说：‘他有鬼。’</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 约翰福音 12:2"> <span className="woj">人子来了，也吃也喝，你们又说：‘看哪，一个贪食好酒的人，是税吏和罪人的朋友！’</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 马太福音 11:19; 何西阿 14:9"> <span className="woj">但智慧总由她所有的儿女证明为义。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:3–9; 马太福音 26:5–6; 路加福音 14:1"> 有一个法利赛人请耶稣和他吃饭；耶稣就进了那法利赛人的家，坐席。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 14:3–9; 马太福音 26:6–13; 马太福音 21:31"> 看哪，那城里有一个女人，是个罪人；她知道耶稣在法利赛人家里坐席，就带着一玉瓶香膏来，</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 126:5–6; 诗篇 51:17; 创世记 18:4"> 站在耶稣背后，挨着祂的脚哭，开始用眼泪湿了祂的脚，又用自己的头发擦干，不住地亲祂的脚，并用香膏抹上。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 马可福音 7:21"> 请耶稣的法利赛人看见这事，就心里说：“这人若是先知，必知道摸祂的是谁，是怎样的女人；她是个罪人。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 16:19; 路加福音 5:31; 以西结 33:31"> 耶稣回答他说：<span className="woj">“西门，我有话要对你说。”</span><br />他说：“老师，请说。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 罗马书 5:20; 马太福音 18:28"> <span className="woj">“有一个债主有两个欠债的人：一个欠五百银币，一个欠五十。</span></span>
<span className="v" id="v42" data-v="42" data-xref="但以理 9:18–19; 歌罗西书 3:13; 罗马书 3:24"> <span className="woj">因为他们无力偿还，债主就免了两个人的债。这样，他们哪一个更爱他呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="诗篇 116:16–18; 提摩太前书 1:13–16; 路加福音 7:47"> 西门回答说：“我想，是那多得赦免的人。”<br />耶稣对他说：<span className="woj">“你判断得对。”</span></span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前书 5:10; 士师记 19:21; 创世记 18:4"> 于是祂转向那女人，对西门说：<span className="woj">“你看见这女人吗？我进了你的家，你没有给我水洗脚；她却用眼泪湿了我的脚，又用头发擦干。</span></span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳记下 15:5; 撒母耳记下 19:39; 罗马书 16:16"> <span className="woj">你没有给我亲吻；但她从我进来以后，就不住地亲我的脚。</span></span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 23:5; 传道书 9:8; 马太福音 6:17"> <span className="woj">你没有用油抹我的头；她却用香膏抹我的脚。</span></span>
<span className="v" id="v47" data-v="47" data-xref="约翰一书 4:19; 约翰一书 3:18; 以赛亚书 1:18"> <span className="woj">所以我告诉你，她许多的罪都赦免了，因为她爱得多；但那少得赦免的，爱也少。”</span></span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 9:2; 马可福音 2:5; 路加福音 5:20"> 祂就对那女人说：<span className="woj">“你的罪赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 马太福音 9:3; 马可福音 2:7"> 同席的人开始心里说：“这是谁，竟然也赦免罪？”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 耶稣对那女人说：<span className="woj">“你的信心救了你；平安地去吧。”</span></span>
</div>
</div>

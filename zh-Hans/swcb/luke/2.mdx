<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马太福音 24:14; 使徒行传 25:21"> 那些日子，凯撒奥古斯都颁布谕旨，要天下人民都登记户籍。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 马太福音 4:24; 使徒行传 26:30"> 这是居里扭任叙利亚总督时第一次办理的登记。</span>
<span className="v" id="v3" data-v="3"> 众人都各归各城，去登记户籍。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 5:2; 约翰福音 7:42; 撒母耳记上 16:1"> 约瑟也从加利利的拿撒勒城，上犹太去，到了大卫的城，名叫伯利恒；因为他本是大卫的家族和后裔，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22–27; 马太福音 1:18–19"> 要和已经许配给他的马利亚一同登记。马利亚那时已经怀孕。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="诗篇 33:11; 启示录 12:1–5; 弥迦书 5:2"> 他们在那里的时候，马利亚生产的日子到了。</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:4; 哥林多后书 8:9; 以赛亚书 53:2–3"> 她生了头胎的儿子，用布包起来，放在马槽里，因为客店里没有地方给他们。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="创世记 31:39–40; 诗篇 78:70–71; 撒母耳记上 17:34–35"> 在同一带地方，有牧羊人夜间住在野外，看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:1; 哥林多后书 3:18; 列王纪上 8:11"> 看哪，主的一位天使站在他们旁边，主的荣光四面照着他们；他们就非常惧怕。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 40:9; 以赛亚书 61:1; 以赛亚书 52:7"> 天使对他们说：“不要怕！看哪，我向你们报一个大喜的福音，是关乎万民的。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 9:6; 马太福音 1:21; 使徒行传 2:36"> 因今天在大卫的城里，为你们生了救主，就是主基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 7:14; 以赛亚书 53:1–2; 以赛亚书 7:11"> 你们要看见一个婴孩，用布包着，躺在马槽里；这就是给你们的记号。”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:20–21; 启示录 5:11; 诗篇 148:2"> 忽然，有一大队天军同那天使一起赞美上帝，说：</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 5:1; 路加福音 19:38; 歌罗西书 1:20"> <span className="pl pl-1">“在至高之处，荣耀归于上帝；</span><br /><span className="pl pl-2">在地上，平安归于祂所喜悦的人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:22; 马太福音 2:1–2; 马太福音 2:9–11"> 众天使离开他们升天以后，牧羊人彼此说：“我们现在往伯利恒去，看看所发生的这事，就是主向我们显明的。”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 他们急忙去了，找到了马利亚和约瑟，又看见那婴孩躺在马槽里。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 66:16; 路加福音 8:39; 诗篇 71:17–18"> 他们看见以后，就把天使论这孩子所说的话传开了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 凡听见的人，都希奇牧羊人对他们所说的话。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 马利亚却把这一切话珍藏在心里，反复思想。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:48; 以赛亚书 29:19; 使徒行传 11:18"> 牧羊人回去了，因他们所听见、所看见的一切，正如天使所告诉他们的，就荣耀、赞美上帝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 创世记 17:12; 加拉太书 4:4–5"> 满了八天，给孩子行割礼的时候，就给祂起名叫耶稣；这名是在祂成胎以前，由天使所起的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 12:1–8"> 按摩西律法，满了他们洁净的日子，他们就带着孩子上耶路撒冷去，把祂献给主，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 13:2; 出埃及记 22:29; 民数记 3:13"> 正如主的律法上所写的：“凡头生的男子，都要称为圣，归给主。”</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 12:6–8; 利未记 12:2; 哥林多后书 8:9"> 又要照主的律法所说的，献上祭物：“一对斑鸠，或两只雏鸽。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 25:9; 路加福音 2:38; 路加福音 1:6"> 看哪，在耶路撒冷有一个人名叫西面；这人公义虔诚，等候以色列的安慰，圣灵在他身上。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:51; 希伯来书 11:5; 路加福音 9:27"> 他得了圣灵的启示，知道自己在看见主的基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“基督”（希腊语）和“弥赛亚”（希伯来语）的意思都是“受膏者”。">b</a></sup>以前，必不见死。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 他受圣灵感动，进入圣殿。孩子耶稣的父母照律法的规矩，把祂带进来，要为祂办理礼仪。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 西面就把祂接在怀里，称颂上帝，说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 14:13; 创世记 15:15; 腓立比书 1:23"> <span className="pl pl-1">“主啊，如今可以照你的话，</span><br /><span className="pl pl-2">让你的仆人平安离世；</span></span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因为我的眼睛已经看见你的救恩，</span></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 62:1–2; 以赛亚书 42:1–4; 诗篇 98:2–3"> <span className="pl pl-2">就是你在万民面前所预备的；</span></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 60:1–3; 以赛亚书 49:6; 使徒行传 26:23"> <span className="pl pl-1">是启示外邦人的光，</span><br /><span className="pl pl-2">又是你民以色列的荣耀。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以赛亚书 8:18; 路加福音 2:48"> 约瑟和孩子的母亲，因这些论到祂的话而希奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 1:23; 彼得前书 2:7–8; 以赛亚书 8:14–15"> 西面给他们祝福，又对孩子的母亲马利亚说：“看哪，这孩子被立，是要叫以色列中许多人跌倒，也叫许多人兴起；祂又要成为受人反对的记号，</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 8:2; 哥林多前书 11:19; 马太福音 12:24–35"> 至于你自己的灵魂，也要被刀刺透；这样，许多人心里的意念就要显露出来。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及记 15:20; 创世记 30:13; 使徒行传 21:9"> 又有一位女先知名叫亚拿，是亚设支派法内力的女儿。她年纪已经很老，从童贞出嫁以后，同丈夫生活了七年，</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太前书 5:5; 诗篇 23:6; 使徒行传 14:23"> 后来守寡，约有八十四年。她不离开圣殿，昼夜禁食祈求，事奉上帝。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多后书 9:15; 马可福音 15:43"> 正在那时候，她也上前来称谢主，并向一切盼望耶路撒冷得救赎的人，讲论这孩子。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太书 4:4–5; 申命记 12:32"> 约瑟和马利亚照主的律法办完了一切，就回到加利利，自己的城拿撒勒去了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以赛亚书 11:1–5"> 孩子渐渐长大，灵里刚强，充满智慧，上帝的恩典在祂身上。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及记 12:14; 民数记 28:16; 申命记 12:18"> 每年逾越节，祂的父母都上耶路撒冷去。</span>
<span className="v" id="v42" data-v="42"> 当祂十二岁的时候，他们按节期的规矩上去。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 30:21–23; 出埃及记 12:15; 历代志下 25:17"> 守满了节日，他们回去的时候，孩童耶稣仍留在耶路撒冷；约瑟和祂的母亲并不知道，</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 122:1–4; 以赛亚书 2:3; 诗篇 42:4"> 以为祂在同行的人群中，就走了一天的路程，才在亲族和熟人中寻找祂。</span>
<span className="v" id="v45" data-v="45"> 找不着，就回耶路撒冷去找祂。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以赛亚书 49:1–2; 以赛亚书 50:4"> 过了三天，他们在圣殿里找到了祂。祂坐在教师中间，一面听他们，一面问他们问题。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 7:28; 路加福音 4:32; 诗篇 119:99"> 凡听见祂的人，都对祂的悟性和应对感到惊奇。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 马太福音 12:46; 路加福音 3:23"> 祂父母看见祂，就很惊讶。祂母亲对祂说：“孩子，你为什么这样待我们？看哪，你父亲和我一直焦急地找你。”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="约翰福音 6:38; 约翰福音 8:29; 玛拉基书 3:1"> 祂对他们说：<span className="woj">“你们为什么找我？岂不知道我必须在我父的家里吗？”</span></span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 马可福音 9:32"> 祂所说的这话，他们不明白。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理 7:28; 创世记 37:11"> 祂就同他们下去，回到拿撒勒，并且顺从他们。祂母亲把这一切话都珍藏在心里。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳记上 2:26"> 耶稣的智慧和身量，并上帝和人喜爱祂的心，都一齐增长。</span>
</div>
</div>

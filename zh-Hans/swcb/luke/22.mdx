<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:6–23; 马太福音 26:2–5; 约翰福音 11:55–57"> 无酵节，又名逾越节，近了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 11:47–53; 马太福音 12:14; 路加福音 20:19"> 祭司长和文士想法子怎样除掉耶稣，因为他们惧怕百姓。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 13:2; 马可福音 14:10–11; 约翰福音 13:26–27"> 撒但进入了犹大，就是称为加略人的犹大；他本是十二使徒中的一个。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:1; 使徒行传 5:24; 路加福音 22:52"> 他就去和祭司长以及圣殿守卫长商议，怎样把耶稣交给他们。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 26:15–16; 使徒行传 1:18; 马太福音 27:3–5"> 他们很欢喜，就约定给他银钱。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 14:2; 马太福音 26:5"> 犹大答应了，就寻找机会，要趁众人不在的时候把耶稣交给他们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:18; 马可福音 14:12–16; 哥林多前书 5:7"> 到了无酵节的日子，就是必须宰逾越节羊羔的那一天。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:13–16; 使徒行传 4:19; 使徒行传 4:13"> 耶稣差遣彼得和约翰，说：<span className="woj">“你们去为我们预备逾越节的筵席，好让我们吃。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 他们问祂：“你要我们在哪里预备？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 16:4; 马太福音 26:18–19; 使徒行传 8:26–29"> 祂对他们说：<span className="woj">“看哪，你们进城的时候，会遇见一个人拿着一瓶水；你们就跟着他进他所进的那家，</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:28; 启示录 3:20; 路加福音 19:34"> <span className="woj">对那家的主人说：‘老师问你：客房在哪里？我好在那里同我的门徒吃逾越节的筵席。’</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:14–15; 使徒行传 1:13; 约翰福音 2:25"> <span className="woj">他会指给你们一间楼上的大房间，陈设齐备；你们就在那里预备。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:33; 路加福音 19:32; 约翰福音 2:5"> 他们去了，所遇见的正如耶稣所告诉他们的，就预备了逾越节的筵席。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:20; 马可福音 14:17; 申命记 16:6–7"> 时候到了，耶稣和十二使徒一同坐席。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:50; 约翰福音 4:34; 约翰福音 17:1"> 祂对他们说：<span className="woj">“我切切地愿意在受苦以前，和你们吃这逾越节的筵席；</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 14:15; 启示录 19:9; 路加福音 22:30"> <span className="woj">因为我告诉你们，我绝不再吃这筵席，直到它在上帝的国里成就。”</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:19; 诗篇 116:13; 申命记 8:10"> 祂接过杯来，祝谢了，说：<span className="woj">“你们拿这个，彼此分着喝；</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 26:29; 路加福音 22:16; 马可福音 14:25"> <span className="woj">因为我告诉你们，从今以后，我绝不再喝这葡萄汁，直到上帝的国来到。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 11:23–29; 哥林多前书 10:16; 马可福音 14:22–24"> 祂又拿起饼来，祝谢了，擘开，递给他们，说：<span className="woj">“这是我的身体，为你们舍的；你们也当这样行，为的是记念我。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 26:28; 哥林多前书 11:25; 撒迦利亚书 9:11"> 饭后，祂也照样拿起杯来，说：<span className="woj">“这杯是用我的血所立的新约，是为你们流出来的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 41:9; 约翰福音 13:26; 约翰福音 13:21–22"> <span className="woj">只是看哪，出卖我之人的手，正同我在桌上。</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:23; 诗篇 109:6–15; 诗篇 55:12–15"> <span className="woj">人子固然要照所定的去，但出卖人子的那人有祸了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:22–25; 马可福音 14:19; 马太福音 26:22"> 他们就彼此追问，他们中间究竟哪一个会做这事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 9:46; 马可福音 9:34; 马可福音 10:37–41"> 他们中间又起了争论，谁算为最大。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 20:25–28; 马可福音 10:41–45"> 耶稣对他们说：<span className="woj">“外邦人的君王辖制他们，掌权治理他们的又被称为‘恩主’。</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 5:5; 路加福音 9:48; 马太福音 18:3–5"> <span className="woj">但你们不可这样；你们中间为大的，倒要像年幼的；作领袖的，倒要像服事人的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 20:28; 路加福音 12:37; 约翰福音 13:5–16"> <span className="woj">是谁为大？是坐席的，还是服事人的？岂不是坐席的吗？然而我在你们中间，如同服事人的。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:18; 希伯来书 4:15; 使徒行传 1:25"> <span className="woj">“我受试炼的时候，常和我同在的就是你们。</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 25:34; 提摩太后书 2:12; 雅各书 2:5"> <span className="woj">我把国赐给你们，正如我父赐给我一样，</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:28; 马太福音 8:11; 启示录 2:26–27"> <span className="woj">使你们在我的国里，在我的席上吃喝，并且坐在宝座上，审判以色列十二个支派。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:8; 撒迦利亚书 3:1; 约伯记 1:6–12"> 主又说：<span className="woj">“西门，西门，看哪，撒但已经求得许可，要筛你们像筛麦子一样；</span></span>
<span className="v" id="v32" data-v="32" data-xref="彼得前书 5:8–10; 约翰福音 21:15–17; 约翰福音 17:9–11"> <span className="woj">但我已经为你祈求，使你的信心不至失落。你回转以后，要坚固你的弟兄。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里“弟兄”一词也可正确译为“弟兄姐妹”或“手足”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 14:31; 马太福音 26:33–35; 马可福音 14:29"> 彼得对祂说：“主啊，我已经预备好，与你同下监，同受死！”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 13:38; 马太福音 26:34; 马可福音 14:30"> 耶稣说：<span className="woj">“彼得，我告诉你，今天鸡还没有叫，你要三次不认得我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 10:9–10; 路加福音 10:4; 诗篇 23:1"> 耶稣又对他们说：<span className="woj">“我差你们出去的时候，没有钱袋、行囊和鞋，你们缺少什么没有？”</span><br />他们说：“没有。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:22–25; 帖撒罗尼迦前书 3:4; 帖撒罗尼迦前书 2:14–15"> 祂对他们说：<span className="woj">“但现在，有钱袋的要带着，有行囊的也一样；没有刀的，要卖掉外衣去买一把。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 53:12; 路加福音 23:32; 哥林多后书 5:21"> <span className="woj">我告诉你们，经上所写的这话必须应验在我身上：‘祂被列在罪犯之中。’</span><span className="woj">因为关于我的事正在成就。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:49; 马太福音 26:52–54; 约翰福音 18:36"> 他们说：“主啊，看哪，这里有两把刀。”<br />祂对他们说：<span className="woj">“够了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 21:37; 约翰福音 18:1–2; 马太福音 21:1"> 耶稣出来，照常往橄榄山去，门徒也跟随祂。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 6:13; 马太福音 26:36–46; 路加福音 22:46"> 到了那地方，祂对他们说：<span className="woj">“你们要祷告，免得陷入试探。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="马太福音 26:39; 马可福音 14:35; 路加福音 18:11"> 祂离开他们，约有扔一块石头那么远，跪下祷告，</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:27–28; 马太福音 26:39; 马太福音 26:42"> 说：<span className="woj">“父啊，你若愿意，就把这杯从我这里撤去；然而不要成就我的意思，只要成就你的意思。”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:11; 马太福音 26:53; 诗篇 91:11–12"> 有一位天使从天上向祂显现，加添祂的力量。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米哀歌 1:12; 希伯来书 5:7; 诗篇 22:12–21"> 耶稣极其痛苦，祷告更加恳切；祂的汗如大血点滴在地上。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马可福音 14:40–41; 马太福音 26:43; 马太福音 26:40"> 祂祷告完了，起来到门徒那里，见他们因忧愁都睡着了，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 22:40; 约拿 1:6; 路加福音 21:34–36"> 就对他们说：<span className="woj">“你们为什么睡觉？起来祷告，免得陷入试探。”</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马可福音 14:41–50; 约翰福音 18:2–11; 路加福音 22:3–6"> 祂还在说话的时候，看哪，有一群人来了；那称为犹大的，是十二使徒中的一个，走在前面。他近前来，要亲吻耶稣。</span>
<span className="v" id="v48" data-v="48" data-xref="马可福音 14:44–46; 撒母耳记下 20:9–10; 箴言 27:6"> 耶稣对他说：<span className="woj">“犹大，你用亲吻来出卖人子吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 22:38"> 左右的人看见将要发生的事，就说：“主啊，我们用刀砍可以不可以？”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 18:10–11; 马可福音 14:47; 罗马书 12:19"> 其中有一个人砍了大祭司的仆人，削掉了他的右耳。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="罗马书 12:21; 哥林多后书 10:1; 彼得前书 2:21–23"> 耶稣回答说：<span className="woj">“到此为止吧。”</span>祂就摸那人的耳朵，把他治好了。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 22:4; 马可福音 14:48–49; 约翰福音 17:12"> 耶稣对那些来抓祂的祭司长、圣殿守卫长和长老说：<span className="woj">“你们带着刀棒出来拿我，如同拿强盗吗？</span></span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 12:27; 以弗所书 6:12; 使徒行传 26:18"> <span className="woj">我天天同你们在圣殿里的时候，你们没有下手拿我。但现在是你们的时候，是黑暗掌权的时候。”</span></span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="马可福音 14:53–54; 马太福音 26:57–58; 约翰福音 18:12–17"> 他们拿住耶稣，把祂带走，领进大祭司的家。彼得远远地跟着。</span>
<span className="v" id="v55" data-v="55" data-xref="诗篇 26:4–5; 哥林多后书 6:15–17; 马可福音 14:66–72"> 他们在院子中间生了火，一同坐下；彼得也坐在他们中间。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 18:17; 马可福音 14:6; 马可福音 14:17"> 有一个使女看见彼得坐在火光里，就定睛看他，说：“这个人也是同祂一起的。”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="约翰一书 1:9; 约翰福音 18:25; 马太福音 26:70"> 彼得却不认耶稣，说：“女人，我不认得祂。”</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="约翰福音 18:25; 马太福音 26:71–72; 马可福音 14:69–70"> 过了不久，又有一个人看见他，说：“你也是他们一伙的！”<br />彼得说：“人哪，我不是！”</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="约翰福音 18:26–27; 马可福音 14:69–70; 马太福音 26:73–74"> 约过了一小时，又有一个人极力地说：“这人确实也同祂一起，因为他也是加利利人！”</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="马太福音 26:74–75; 路加福音 22:34; 马可福音 14:71–72"> 彼得说：“人哪，我不知道你说的是什么！”他还在说话的时候，鸡立刻叫了。</span>
<span className="v" id="v61" data-v="61" data-xref="路加福音 22:34; 以赛亚书 57:15–18; 耶利米书 31:18–20"> 主转过身来看彼得，彼得就想起主对他说过的话：<span className="woj">“鸡叫以前，你要三次不认我。”</span></span>
<span className="v" id="v62" data-v="62" data-xref="马太福音 26:75; 哥林多前书 10:12; 马可福音 14:72"> 他就出去，痛哭起来。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="约翰福音 18:22; 马可福音 14:55–65; 约伯记 16:9–10"> 看守耶稣的人戏弄祂，打祂。</span>
<span className="v" id="v64" data-v="64" data-xref="士师记 16:25; 士师记 16:21"> 他们蒙住祂的眼睛，打祂的脸，问祂说：“说预言吧！打你的是谁？”</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 12:10; 马太福音 12:31–32; 马太福音 27:39"> 他们还用许多别的话辱骂祂。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="马太福音 27:1; 马可福音 15:1; 使徒行传 22:5"> 天一亮，百姓的长老会，就是祭司长和文士，都聚集起来，把耶稣带到他们的议会里，说：</span>
<span className="v" id="v67" data-v="67" data-xref="马太福音 11:3–5; 约翰福音 8:43–45; 马太福音 26:63–68"> “你若是基督，就告诉我们。”<br />耶稣对他们说：<span className="woj">“我若告诉你们，你们绝不相信；</span></span>
<span className="v" id="v68" data-v="68" data-xref="路加福音 20:41–44; 路加福音 20:3–7"> <span className="woj">我若问你们，你们也绝不回答我，也不会释放我。</span></span>
<span className="v" id="v69" data-v="69" data-xref="但以理 7:13–14; 诗篇 110:1; 马可福音 16:19"> <span className="woj">从今以后，人子要坐在上帝权能的右边。”</span></span>

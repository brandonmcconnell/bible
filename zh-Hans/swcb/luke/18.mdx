<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LUK" data-book-slug="luke" data-book-name="路加福音" data-chapter="18" data-verses="43">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 4:2; 罗马书 12:12; 帖撒罗尼迦前书 5:17"> 耶稣又对他们讲一个比喻，说明人必须常常祷告，不可灰心。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 诗篇 8:1–4; 路加福音 18:4"> 祂说：<span className="woj">“某城里有一个审判官，不惧怕上帝，也不尊重人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:17; 耶利米书 5:28; 申命记 27:19"> <span className="woj">那城里有一个寡妇，常到他那里，说：‘求你为我向我的对头伸冤！’</span></span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 4:12–13; 路加福音 16:3; 路加福音 12:17"> <span className="woj">他有一段时间不肯；后来心里说：‘我虽然不惧怕上帝，也不尊重人，</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:8; 路加福音 18:39; 士师记 16:16"> <span className="woj">但因这寡妇烦扰我，我就为她伸冤吧，免得她不断地来，叫我筋疲力尽。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 7:13"> 主说：<span className="woj">“你们听这不义的审判官所说的话。</span></span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 10:35–37; 彼得后书 3:9; 路加福音 11:13"> <span className="woj">上帝的选民昼夜呼求祂，祂岂不为他们伸冤吗？祂难道会迟迟不理他们吗？</span></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:23–26; 彼得后书 3:8–9; 马太福音 24:9–13"> <span className="woj">我告诉你们，祂必快快为他们伸冤。然而人子来的时候，在地上还能找到信心吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 16:15; 箴言 30:12; 以赛亚书 65:5"> 耶稣也向那些自以为义、轻看别人的人讲了这个比喻：</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 21:31–32; 列王纪上 8:30; 列王纪下 20:5"> <span className="woj">“有两个人上圣殿去祷告：一个是法利赛人，另一个是税吏。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:5; 以赛亚书 65:5; 启示录 3:17"> <span className="woj">法利赛人站着，自言自语地祷告说：‘上帝啊，我感谢你，我不像别人，勒索、不义、奸淫，也不像这个税吏。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 11:42; 马太福音 23:23–24; 马太福音 9:14"> <span className="woj">我一个星期禁食两次；凡我所得的，都献上十分之一。’</span></span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 9:6; 约翰一书 1:8–10; 提摩太前书 1:15"> <span className="woj">但那税吏远远地站着，连举目望天也不敢，只捶着胸说：‘上帝啊，开恩可怜我这个罪人！’</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 14:11; 路加福音 16:15; 雅各书 4:10"> <span className="woj">我告诉你们，这人回家去，倒比那人称义了；因为凡自高的，必降为卑；凡自卑的，必升为高。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:13–16; 马太福音 19:13–15; 撒母耳记上 1:24"> 有人也把婴孩带到耶稣那里，要祂摸他们；门徒看见，就责备那些人。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 18:3–4; 哥林多前书 14:20; 哥林多前书 7:14"> 耶稣却叫他们来，说：<span className="woj">“让小孩子到我这里来，不要禁止他们，因为上帝的国正是属于这样的人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 18:3; 马可福音 10:15; 诗篇 131:1–2"> <span className="woj">我实在告诉你们，凡不像小孩子一样领受上帝国的，绝不能进去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 10:17–31; 使徒行传 16:30; 马太福音 19:16–30"> 有一个官问耶稣说：“良善的老师，我该做什么，才能承受永生？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约伯记 15:14–16; 雅各书 1:17; 希伯来书 7:26"> 耶稣对他说：<span className="woj">“你为什么称我是良善的？除了上帝一位以外，再没有良善的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12–17; 申命记 5:16–21; 罗马书 13:9"> <span className="woj">诫命你是知道的：‘不可奸淫；不可杀人；不可偷盗；不可作假见证；当孝敬父母。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="腓立比书 3:6; 罗马书 10:2–3; 马可福音 10:20–21"> 那人说：“这一切我从小都遵守了。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 12:33; 提摩太前书 6:18–19; 马太福音 19:21"> 耶稣听见了，就对他说：<span className="woj">“你还缺少一件：要变卖你一切所有的，分给穷人，你就必有财宝在天上；然后来跟从我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结 33:31; 约翰一书 2:15; 约伯记 31:24–25"> 那人听见这些话，就十分忧愁，因为他非常富有。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; 雅各书 2:5–7; 马可福音 10:23–27"> 耶稣看见他十分忧愁，就说：<span className="woj">“有钱财的人进上帝的国，是何等困难！</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 23:24"> <span className="woj">骆驼穿过针眼，比财主进上帝的国还容易。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 13:23"> 听见的人说：“这样，谁能得救呢？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 32:17; 马太福音 19:26; 路加福音 1:37"> 耶稣说：<span className="woj">“在人不能的事，在上帝却能。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 10:28; 腓立比书 3:7; 马太福音 19:27"> 彼得说：“看哪，我们已经撇下自己所有的跟从你了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:29–31; 马太福音 10:37–39; 路加福音 14:26–28"> 耶稣对他们说：<span className="woj">“我实在告诉你们，没有人为上帝国的缘故，撇下房屋、妻子、弟兄、父母或儿女，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 13:5–6; 约伯记 42:10; 启示录 2:17"> <span className="woj">不在今世得许多倍，并在来世得永生。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 20:17–19; 以赛亚书 53:1–12; 诗篇 22:1–31"> 耶稣带着十二使徒到一边，对他们说：<span className="woj">“看哪，我们上耶路撒冷去，先知所写关于人子的一切都要成就。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 23:11; 以赛亚书 50:6; 以赛亚书 53:3"> <span className="woj">祂要被交给外邦人，被戏弄、凌辱、吐唾沫；</span></span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 15:3–4; 路加福音 24:7; 马太福音 27:63"> <span className="woj">他们要鞭打祂，杀害祂；第三天，祂要复活。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 9:45; 马可福音 9:32; 路加福音 24:25"> 这些事，门徒一样也不明白；这话向他们隐藏了，他们不懂所说的是什么意思。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:29–34; 马可福音 10:46–52; 路加福音 16:20–21"> 耶稣将近耶利哥的时候，有一个瞎子坐在路旁讨饭。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 21:10–11; 路加福音 15:26"> 他听见许多人经过，就问是什么事。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 2:23; 约翰福音 19:19; 约翰福音 12:35–36"> 他们告诉他：“拿撒勒人耶稣经过这里。”</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:27; 路加福音 18:39; 马太福音 15:22"> 他就喊着说：“大卫的子孙耶稣啊，怜悯我吧！”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 32:26–28; 诗篇 141:1; 路加福音 18:15"> 走在前面的人责备他，要他安静；他却越发喊着说：“大卫的子孙啊，怜悯我吧！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:31–34; 马可福音 10:48–52"> 耶稣站住，吩咐人把他带过来。那人近前来，耶稣问他说：</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 3:5–15; 马太福音 20:21–22; 腓立比书 4:6"> <span className="woj">“你要我为你做什么？”</span><br />他说：“主啊，我要能看见。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 8:3; 路加福音 8:48; 路加福音 17:19"> 耶稣对他说：<span className="woj">“你可以看见了；你的信心使你痊愈。”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="诗篇 146:8; 帖撒罗尼迦后书 1:10–12; 以赛亚书 43:21"> 他立刻看见了，就跟随耶稣，荣耀上帝。众人看见，也都赞美上帝。</span>
</div>
</div>

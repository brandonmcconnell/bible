<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:1–27; 路加福音 18:35; 列王纪下 2:18–22"> 耶稣进了耶利哥，正经过那里。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 18:24–27; 历代志下 17:5–6"> 看哪，有一个人名叫撒该，是税吏长，又很富有。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:8; 路加福音 9:7–9; 约翰福音 12:21"> 他想看看耶稣是谁，只因人多，自己身材又矮，就看不见。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 9:10; 路加福音 5:19; 列王纪上 10:27"> 于是他跑到前头，爬上一棵桑树，要看耶稣，因为耶稣将要从那里经过。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:20; 约翰福音 14:23; 希伯来书 13:2"> 耶稣到了那地方，抬头看见他，就对他说：<span className="woj">“撒该，快下来！今天我必须住在你家里。”</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:29; 使徒行传 16:34; 使徒行传 16:15"> 他就急忙下来，欢欢喜喜地接待耶稣。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:2; 路加福音 7:39; 路加福音 7:34"> 众人看见，都发怨言说：“祂竟到一个罪人家里去住宿。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 12:6; 民数记 5:7; 路加福音 18:22–23"> 撒该站着对主说：“主啊，看哪，我把一半财产分给穷人；我若讹诈过谁，就还他四倍。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:7; 路加福音 13:16; 罗马书 4:16"> 耶稣对他说：<span className="woj">“今天救恩临到这家，因为他也是亚伯拉罕的子孙。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西结 34:16; 马太福音 1:21; 提摩太前书 1:13–16"> <span className="woj">人子来，是要寻找并拯救失丧的人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 17:20; 使徒行传 1:6; 帖撒罗尼迦后书 2:1–3"> 众人听这些话的时候，耶稣又讲了一个比喻，因为祂已经接近耶路撒冷，而且他们以为上帝的国立刻就要显现。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:14–30; 路加福音 19:12–27; 路加福音 20:9"> 于是祂说：<span className="woj">“有一个贵族往远方去，要为自己取得王位，然后回来。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 25:14–15; 约翰福音 12:26; 哥林多前书 12:7–11"> <span className="woj">他叫了自己的十个仆人来，给他们十锭银子，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十锭银子超过农业工人三年的工钱。">a</a></sup><span className="woj">对他们说：‘你们去经营，直到我回来。’</span></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 8:7; 使徒行传 7:51–52; 使徒行传 3:14–15"> <span className="woj">但他的国民恨他，打发使者随后去说：‘我们不要这个人作我们的王。’</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:1–5; 罗马书 14:10–12; 诗篇 2:4–6"> <span className="woj">“后来他取得王位回来，就吩咐把那些领过银子的仆人叫来，要知道他们经营赚了多少。</span></span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:18–26; 提摩太后书 4:7–8; 哥林多前书 15:10"> <span className="woj">第一个来到他说：‘主啊，你的一锭银子已经赚了十锭。’</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 16:10; 马太福音 25:21; 启示录 2:26–29"> <span className="woj">“主人对他说：‘好，良善的仆人！你在极小的事上忠心，可以有权管理十座城。’</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:20; 马太福音 13:23; 哥林多后书 8:12"> <span className="woj">“第二个来说：‘主啊，你的一锭银子已经赚了五锭。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 15:58; 哥林多前书 15:41–42; 哥林多前书 3:8"> <span className="woj">“主人也对他说：‘你也可以管理五座城。’</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:24; 箴言 26:13–16; 雅各书 4:17"> <span className="woj">又有一个来说：‘主啊，看哪，这是你的一锭银子，我把它包在手巾里收着；</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:24–25; 罗马书 8:7; 约翰一书 4:18"> <span className="woj">因为我怕你，你是严厉的人；没有存放的，你也要拿走；没有撒种的，你也要收割。’</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 1:16; 马太福音 12:37; 约伯记 15:5–6"> <span className="woj">“主人对他说：‘恶仆啊，我要凭你自己的话审判你！你既知道我是严厉的人，没有存放的也拿走，没有撒种的也收割，</span></span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 22:25–27; 罗马书 2:4–5; 申命记 23:19–20"> <span className="woj">为什么不把我的银子存在银行里？等我来的时候，就可以连本带利收回。’</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 16:2; 路加福音 12:20"> <span className="woj">于是对旁边站着的人说：‘夺过他这一锭来，给那有十锭的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 16:2; 撒母耳记下 7:19; 以赛亚书 55:8–9"> <span className="woj">“他们对他说：‘主啊，他已经有十锭了！’</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰二书 1:8; 路加福音 8:18; 马太福音 21:43"> <span className="woj">‘我告诉你们，凡有的，还要给他；没有的，连他所有的也要夺过来。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:14; 诗篇 21:8–9; 马太福音 22:7"> <span className="woj">至于我那些仇敌，就是不愿意我作他们王的，把他们带到这里来，在我面前杀了。’”</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:51; 希伯来书 12:2; 彼得前书 4:1"> 耶稣说完这些话，就在前面走，上耶路撒冷去。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 1:12; 马太福音 21:17; 马太福音 21:1–11"> 将近伯法其<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR、NU 作“伯法其”，而非“伯法士基”。">b</a></sup>和伯大尼，到了名叫橄榄山的地方，耶稣差遣两个门徒，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 22:8–13; 路加福音 19:32; 撒母耳记上 10:2–9"> 说：<span className="woj">“你们往对面的村子去；进去的时候，会看见一匹驴驹拴在那里，是从来没有人骑过的。把它解开牵来。</span></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 24:1; 诗篇 50:10–12; 马可福音 11:3–6"> <span className="woj">若有人问你们：‘为什么解它？’你们就说：‘主需要它。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 22:13"> 奉差遣的人去了，所遇见的正如耶稣所告诉他们的。</span>
<span className="v" id="v33" data-v="33"> 他们解驴驹的时候，驴主对他们说：“你们为什么解这驴驹？”</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 9:9; 约翰福音 10:35; 哥林多后书 8:9"> 他们说：“主需要它。”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 11:7–8; 马太福音 21:7; 约翰福音 12:14"> 他们就把驴驹牵到耶稣那里，把自己的衣服搭在驴驹上，扶耶稣骑上。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 9:13; 马太福音 21:8"> 耶稣前行的时候，众人把自己的衣服铺在路上。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:12–13; 以斯拉记 3:10–13; 马太福音 21:1"> 将近耶路撒冷，正下橄榄山的时候，整群门徒因所看见的一切异能，就欢喜起来，大声赞美上帝，</span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亚书 9:9; 路加福音 13:35; 诗篇 118:22–26"> 说：“奉主名来的王是有福的！ 在天上有平安，在至高之处有荣耀！”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 4:1–2; 马太福音 23:13; 使徒行传 4:16–18"> 众人中有几个法利赛人对耶稣说：“老师，责备你的门徒吧！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="哈巴谷 2:11; 以赛亚书 55:12; 马太福音 3:9"> 耶稣回答他们说：<span className="woj">“我告诉你们，若是他们闭口不说，这些石头也要呼喊起来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 13:34–35; 约翰福音 11:35; 诗篇 119:136"> 耶稣临近耶路撒冷，看见那城，就为它哀哭，</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 32:29; 希伯来书 10:26–29; 以赛亚书 48:18"> 说：<span className="woj">“但愿你在今日，就是你，也知道关乎你平安的事！只是如今这事在你眼前隐藏了。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 21:20–24; 以赛亚书 29:1–4; 以西结 4:2"> <span className="woj">因为日子将到，你的仇敌要在你四周筑起土垒，围住你，四面困住你，</span></span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 21:6; 路加福音 13:34–35; 约翰福音 3:18–21"> <span className="woj">又要把你和你里面的儿女摔在地上，在你里面不留一块石头在另一块石头上，因为你不知道上帝眷顾你的时候。”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 21:12–13; 马可福音 11:15–17; 约翰福音 2:13–17"> 耶稣进了圣殿，开始赶出在里面买卖的人，</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 56:7; 耶利米书 7:11; 诗篇 93:5"> 对他们说：<span className="woj">“经上记着：‘我的殿必作祷告的殿，’</span><span className="woj">你们倒使它成为‘强盗的巢穴’！”</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马可福音 11:18; 马太福音 26:55; 马可福音 11:27–33"> 耶稣天天在圣殿里教导人；祭司长、文士和百姓中的首领都想除灭祂。</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 8:3; 使徒行传 16:14; 约翰福音 7:46–49"> 只是找不到可行的办法，因为众百姓都专心听祂，紧紧抓住祂所说的每一句话。</span>
</div>
</div>

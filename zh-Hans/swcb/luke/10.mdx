<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 6:7–13; 路加福音 9:52; 民数记 11:24–26"> 这些事以后，主又指定了另外七十个人，差遣他们两个两个地在祂前面<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直译为“在祂面前”。">a</a></sup>，往祂将要去的各城各地去。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36–38; 约翰福音 4:35–38; 哥林多前书 3:6–9"> 祂对他们说：<span className="woj">“要收的庄稼多，工人却少；所以你们要求庄稼的主，打发工人出去收祂的庄稼。</span></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:16; 使徒行传 20:29; 以西结 2:3–6"> <span className="woj">你们去吧！看哪，我差你们出去，如同羊羔进入狼群。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:35; 列王纪下 4:29; 路加福音 10:4–12"> <span className="woj">不要带钱袋，不要带行囊，不要带鞋；在路上也不要向人问安。</span></span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 25:6; 马太福音 10:12–13; 以赛亚书 57:19"> <span className="woj">无论进哪一家，先说：‘愿平安归于这家。’</span></span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:16; 哥林多后书 2:15–16; 以弗所书 5:6"> <span className="woj">若那里有配得平安的人，你们所求的平安就必停留在他身上；若没有，就必归回你们。</span></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 5:17–18; 马太福音 10:10–11; 加拉太书 6:6"> <span className="woj">你们要住在那一家，吃喝他们所供给的，因为工人得工价是应当的。不要从这家搬到那家。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:27; 马太福音 10:40; 路加福音 10:10"> <span className="woj">无论进哪一座城，人若接待你们，给你们摆上什么，你们就吃什么；</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:2; 约翰福音 3:5; 路加福音 10:11"> <span className="woj">要医治那里的病人，并对他们说：‘上帝的国临近你们了。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 18:6; 马太福音 10:14; 使徒行传 13:51"> <span className="woj">但无论进哪一座城，人若不接待你们，就到那城的街上说：</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:9; 使徒行传 13:51; 使徒行传 13:26"> <span className="woj">‘就是你们城里粘在我们脚上的尘土，我们也擦下来归还给你们。不过你们要知道，上帝的国已经临近了。’</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:15; 马太福音 11:24; 耶利米哀歌 4:6"> <span className="woj">我告诉你们，到那日，所多玛所受的还比那城容易受呢。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 23:1–18; 约珥 3:4–8; 以西结 26:1–26"> <span className="woj">“哥拉汛哪，你有祸了！伯赛大啊，你有祸了！因为在你们中间所行的异能，若行在推罗、西顿，他们早已披麻蒙灰坐着悔改了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 15:22–25; 罗马书 2:1; 路加福音 12:47–48"> <span className="woj">但在审判的时候，推罗、西顿所受的还比你们容易受。</span></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 14:13–15; 马太福音 4:13; 路加福音 13:28"> <span className="woj">迦百农啊，你已经被高举到天上吗？你必降到阴间。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间指死人所在的地下境界，也可指地狱。">b</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 13:20; 马太福音 10:40; 帖撒罗尼迦前书 4:8"> <span className="woj">听从你们的，就是听从我；拒绝你们的，就是拒绝我；拒绝我的，就是拒绝那差我来的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:20; 马可福音 16:17; 路加福音 9:1"> 那七十个人欢欢喜喜地回来，说：“主啊，因你的名，连鬼也服了我们！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 12:7–9; 以赛亚书 14:12; 启示录 9:1"> 耶稣对他们说：<span className="woj">“我看见撒但像闪电一样从天上坠落。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 91:13; 马可福音 16:18; 罗马书 16:20"> <span className="woj">看哪，我已经给你们权柄，可以践踏蛇和蝎子，又胜过仇敌一切的能力；绝没有什么能伤害你们。</span></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:15; 启示录 20:12; 希伯来书 12:23"> <span className="woj">然而，不要因灵服了你们而欢喜；要因你们的名记录在天上而欢喜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 4:3; 马太福音 13:11–16; 马太福音 11:25–27"> 就在那时候，耶稣在圣灵里欢喜，说：<span className="woj">“父啊，天地的主，我感谢你！因为你把这些事向智慧聪明的人隐藏起来，却向小孩子显明出来。父啊，是的，因为这在你眼中本是美好的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:27; 约翰福音 1:18; 约翰福音 6:44–46"> 祂转向门徒，说：<span className="woj">“一切都已经由我父交给我。除了父，没有人知道子是谁；除了子和子愿意启示的人，也没有人知道父是谁。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:16–17"> 祂又转向门徒，私下对他们说：<span className="woj">“看见你们所看见之事的眼睛，是有福的。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 8:56; 希伯来书 11:13; 彼得前书 1:10–12"> <span className="woj">我告诉你们，许多先知和君王想要看你们所看见的，却没有看见；想要听你们所听见的，却没有听见。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:34–39; 路加福音 18:18; 马太福音 19:16–19"> 看哪，有一个律法师站起来试探耶稣，说：“老师，我该做什么，才能承受永生？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="罗马书 10:5; 以赛亚书 8:20; 加拉太书 3:21–22"> 耶稣对他说：<span className="woj">“律法上写的是什么？你怎样读呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 12:30–31; 马太福音 22:37–40; 申命记 6:5"> 他回答说：“你要尽心、尽性、尽力、尽意爱主你的上帝； 又要爱邻舍如同自己。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结 20:11; 利未记 18:5; 马太福音 19:17"> 耶稣对他说：<span className="woj">“你回答得对。你这样做，就必得生命。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 16:15; 罗马书 4:2; 利未记 19:34"> 但那人想要证明自己有理，就问耶稣：“谁是我的邻舍呢？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="诗篇 88:4; 路加福音 18:31; 耶利米哀歌 2:12"> 耶稣回答说：<span className="woj">“有一个人从耶路撒冷下耶利哥去，落在强盗手中；他们剥去他的衣服，又打伤他，就离开了，留下他半死不活。</span></span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 3:16–18; 诗篇 69:20; 耶利米书 5:31"> <span className="woj">偶然有一个祭司从那条路下来，看见他，就从另一边过去了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行传 18:17; 诗篇 109:25"> <span className="woj">又有一个利未人也是这样，来到那地方，看见他，也从另一边过去了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:50; 耶利米书 38:7–13; 路加福音 7:13"> <span className="woj">但有一个撒玛利亚人，行路来到他那里；看见他，就动了怜悯的心，</span></span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 12:20; 诗篇 147:3; 帖撒罗尼迦前书 5:15"> <span className="woj">上前包裹他的伤口，倒上油和酒；又扶他骑上自己的牲口，带到客店里，照顾他。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; 路加福音 14:13; 罗马书 16:23"> <span className="woj">第二天，他离开的时候，拿出两个银币交给店主，说：‘请照顾他。你额外花费的，我回来的时候会还给你。’</span></span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 7:42; 马太福音 21:28–31; 马太福音 17:25"> <span className="woj">你想，这三个人哪一个成了那落在强盗手中之人的邻舍呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 3:16–18; 弥迦书 6:8; 彼得前书 2:21"> 他说：“是那怜悯他的。”<br />耶稣对他说：<span className="woj">“你去，也照样做吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:19–20; 约翰福音 11:1–5; 约翰福音 12:1–3"> 他们继续前行的时候，耶稣进了一个村庄。有一个名叫马大的女人接待祂到自己家里。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; 路加福音 8:35; 约翰福音 12:3"> 她有一个妹妹，名叫马利亚，也坐在耶稣脚前，听祂的话。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:27; 路加福音 12:29; 马太福音 14:15"> 马大被许多服事的事搅扰，就上前来，说：“主啊，我妹妹留下我一个人服事，你不在意吗？请吩咐她来帮助我。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="腓立比书 4:6; 路加福音 21:34; 马太福音 6:25–34"> 耶稣回答她说：<span className="woj">“马大，马大，你为许多事忧虑烦扰；</span></span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 27:4; 诗篇 16:5–6; 约翰福音 10:27–28"> <span className="woj">但有一件事是需要的。马利亚已经选择了那美好的份，是不能从她夺去的。”</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 马太福音 12:1–8"> 有一个安息日，耶稣从麦田经过；祂的门徒掐了麦穗，用手搓着吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:2; 约翰福音 5:16; 约翰福音 5:9–11"> 有几个法利赛人说：“你们为什么做安息日不可做的事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 马可福音 2:25–26; 马太福音 12:3–5"> 耶稣回答他们说：<span className="woj">“大卫和跟随他的人饥饿的时候所做的，你们没有读过吗？</span></span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9"> <span className="woj">他怎样进了上帝的殿，拿陈设饼吃，又给跟随他的人吃；这饼除了祭司以外，别人都不可吃。”</span></span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 2:27; 启示录 1:10; 马可福音 9:7"> 祂又对他们说：<span className="woj">“人子是安息日的主。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 3:1–6; 马太福音 12:9–14; 路加福音 4:31"> 又有一个安息日，耶稣进了会堂教导人；那里有一个人，右手枯干了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; 诗篇 38:12; 路加福音 13:14"> 文士和法利赛人窥探耶稣，看祂在安息日治不治病，好找把柄控告祂。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 42:4; 马太福音 9:4; 路加福音 5:22"> 祂却知道他们的意念，就对那手枯干的人说：<span className="woj">“起来，站在中间。”</span>那人就起来站着。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:4; 马太福音 12:12–13; 路加福音 14:3"> 耶稣对他们说：<span className="woj">“我问你们，安息日行善或作恶，救命或害命，哪一样是合乎律法的？”</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:6–7; 马可福音 3:5; 约翰福音 5:8"> 祂环视众人，就对那人说：<span className="woj">“伸出你的手来。”</span>他一伸，手就复原，像另一只一样完好。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 2:1–2; 使徒行传 5:33; 传道书 9:3"> 他们却怒气填胸，彼此商议该怎样对付耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 5:7; 马可福音 6:46; 马可福音 1:35"> 那些日子，耶稣出去上山祷告，整夜向上帝祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 3:13–19; 马太福音 9:36–4; 启示录 21:14"> 到了天亮，祂叫门徒来，从他们中间挑选了十二个人，称他们为使徒：</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:13; 马太福音 4:21; 马太福音 4:18"> 西门，祂又给他起名叫彼得；还有他的兄弟安得烈；雅各；约翰；腓力；巴多罗买；</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 9:9; 马可福音 3:18; 使徒行传 1:13"> 马太；多马；亚勒腓的儿子雅各；称为奋锐党的西门；</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:22; 约翰福音 6:70–71; 马可福音 3:18"> 雅各的儿子犹大；还有加略人犹大，就是后来成了叛徒的那一个。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:21; 马太福音 4:23–25; 诗篇 107:17–20"> 耶稣和他们下了山，站在一块平地上；有一大群祂的门徒，又有许多百姓，从犹太全地、耶路撒冷，以及推罗、西顿的海边来，都是要听祂讲道，并得医治脱离疾病；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:15; 马太福音 15:22; 使徒行传 5:16"> 还有那些被污灵搅扰的人，也都得了医治。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 14:36; 马可福音 3:10; 使徒行传 5:15–16"> 众人都想摸祂，因为有能力从祂身上出来，医好了他们所有人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:5; 路加福音 6:20–24; 哥林多后书 8:9"> 耶稣举目看着门徒，说：<br /><span className="pl pl-1 woj">“贫穷的人有福了，</span><br /><span className="pl pl-2 woj">因为上帝的国是你们的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 6:35; 马太福音 5:6; 雅各书 1:12"> <span className="pl pl-1 woj">现在饥饿的人有福了，</span><br /><span className="pl pl-2 woj">因为你们将要饱足。</span><br /><span className="pl pl-1 woj">现在哭泣的人有福了，</span><br /><span className="pl pl-2 woj">因为你们将要欢笑。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:10–12; 马太福音 10:22; 彼得前书 4:12–16"> <span className="pl pl-1 woj">人为人子的缘故恨恶你们，排斥你们，辱骂你们，弃绝你们的名为恶，你们就有福了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:41; 启示录 21:7; 启示录 3:12"> <span className="pl pl-2 woj">当那日，你们要欢喜跳跃，因为看哪，你们在天上的赏赐是大的；他们的祖先待先知也是这样。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:2; 雅各书 5:1–6; 诗篇 49:6–7"> <span className="pl pl-1 woj">“但你们富足的人有祸了！</span><br /><span className="pl pl-2 woj">因为你们已经得了你们的安慰。</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 65:13; 雅各书 4:9; 箴言 14:13"> <span className="pl pl-1 woj">你们现在饱足的人有祸了，</span><br /><span className="pl pl-2 woj">因为你们将要饥饿。</span><br /><span className="pl pl-1 woj">你们现在欢笑的人有祸了，</span><br /><span className="pl pl-2 woj">因为你们将要哀恸哭泣。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:19; 雅各书 4:4; 马太福音 7:15"> <span className="pl pl-1 woj">有祸了，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加有“你们”。">a</a></sup><br /><span className="pl pl-1 woj">当</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 加有“众”。">b</a></sup><br /><span className="pl pl-1 woj">人都说你们好的时候；</span><br /><span className="pl pl-2 woj">因为他们的祖先待假先知也是这样。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 5:15; 路加福音 6:35; 罗马书 12:17–21"> <span className="woj">“只是我告诉你们这些听的人：要爱你们的仇敌，善待恨你们的人；</span></span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 3:9; 哥林多前书 4:12; 罗马书 12:14"> <span className="woj">要祝福咒诅你们的人，为虐待你们的人祷告。</span></span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 10:34; 马太福音 5:39–42; 哥林多后书 11:20"> <span className="woj">有人打你这边的脸，把另一边也让他打；有人夺去你的外衣，连里衣也不要阻拦他拿去。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 15:7–10; 哥林多后书 9:6–14; 马太福音 6:12"> <span className="woj">凡向你求的，就给他；有人拿走你的东西，不要向他讨回来。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 7:12; 加拉太书 5:14; 马太福音 22:39"> <span className="woj">“你们愿意人怎样待你们，也要照样待人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="马太福音 5:46–47; 彼得前书 2:19–20"> <span className="woj">“你们若只爱那爱你们的人，有什么可称赞的呢？就是罪人也爱那爱他们的人。</span></span>
<span className="v" id="v33" data-v="33"> <span className="woj">你们若善待那善待你们的人，有什么可称赞的呢？就是罪人也这样做。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> <span className="woj">你们若借给人，只指望从他们收回，有什么可称赞的呢？就是罪人也借给罪人，要照数收回。</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 5:44–45; 约翰福音 13:35; 箴言 19:17"> <span className="woj">但你们要爱仇敌，要善待人，要借给人，不指望收回；你们的赏赐就必大，你们也必作至高者的儿女，因为祂恩待忘恩负义和邪恶的人。</span></span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:1–2; 马太福音 5:48; 彼得前书 1:15–16"> <span className="pl pl-1 woj">“所以，你们要有怜悯，</span><br /><span className="pl pl-2 woj">正如你们的父有怜悯一样。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以弗所书 4:32; 雅各书 5:9; 马太福音 7:1–5"> <span className="pl pl-1 woj">不要论断，</span><br /><span className="pl pl-2 woj">你们就不被论断；</span><br /><span className="pl pl-1 woj">不要定人的罪，</span><br /><span className="pl pl-2 woj">你们就不被定罪；</span><br /><span className="pl pl-1 woj">要饶恕人，</span><br /><span className="pl pl-2 woj">你们就必蒙饶恕。</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多后书 9:6–8; 申命记 15:10; 马可福音 4:24"> <span className="woj">“你们要给人，就必有给你们的；而且是十足的量器，压实了，摇匀了，满溢出来，倒在你们怀里。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="直译为“倒在你们怀中”。">c</a></sup><span className="woj">因为你们用什么量器量给人，也必用什么量器量给你们。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 15:14; 提摩太后书 3:13; 提摩太前书 6:3–5"> 祂又对他们讲一个比喻：<span className="woj">“瞎子岂能领瞎子呢？两个人不是都要掉进坑里吗？</span></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:16; 马太福音 10:24–25; 约翰福音 15:20"> <span className="woj">学生不能高过老师；凡学成了的，都会像他的老师。</span></span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 8:7; 雅各书 1:24; 罗马书 2:1"> <span className="woj">为什么看见你弟兄眼中的木屑，却不察觉自己眼中的梁木呢？</span></span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 2:21–29; 帖撒罗尼迦前书 2:10–12; 诗篇 51:9–13"> <span className="woj">你自己眼中的梁木看不见，怎能对弟兄说：‘弟兄，让我去掉你眼中的木屑’呢？假冒为善的人哪！先去掉自己眼中的梁木，然后才能看得清楚，去掉你弟兄眼中的木屑。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 2:21; 马太福音 12:33; 马太福音 7:16–20"> <span className="woj">“好树不会结坏果子，坏树也不会结好果子。</span></span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 12:33; 雅各书 3:12; 加拉太书 5:19–23"> <span className="woj">每一棵树都是凭自己的果子认出来的。人不会从荆棘上摘无花果，也不会从蒺藜里摘葡萄。</span></span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; 马太福音 12:34–37; 以弗所书 4:29"> <span className="woj">善人从心里所存的善发出善；恶人从心里所存的恶发出恶；因为心里所充满的，口里就说出来。</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="加拉太书 6:7; 玛拉基书 1:6; 马太福音 7:21–23"> <span className="woj">“你们为什么称呼我‘主啊，主啊’，却不遵行我所说的呢？</span></span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 1:22–25; 马太福音 7:24–27; 路加福音 11:28"> <span className="woj">凡到我这里来，听见我的话又去行的，我要告诉你们他像什么人。</span></span>
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 3:10–15; 诗篇 62:2; 马太福音 7:25–26"> <span className="woj">他像一个人盖房子，深深地挖地，把根基立在磐石上；洪水来的时候，急流冲击那房子，却不能摇动它，因为它根基立在磐石上。</span></span>
<span className="v" id="v49" data-v="49" data-xref="以西结 33:31; 雅各书 1:22–26; 马太福音 23:3"> <span className="woj">但听见而不去行的，就像一个人在土地上盖房子，没有根基；急流一冲，那房子立刻倒塌，而且倒塌得很大。”</span></span>
</div>

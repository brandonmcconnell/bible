<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="LUK" data-book-slug="luke" data-book-name="路加福音" data-chapter="24" data-verses="53">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 20:1–2; 马可福音 16:1–8; 马太福音 28:1–8"> 七日的第一日，天还很早，她们和另外几个人带着所预备的香料来到坟墓那里。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:3–4; 马太福音 27:60–66; 马可福音 15:46–47"> 她们发现石头已经从坟墓滚开了。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 约翰福音 20:6–7; 马太福音 16:5"> 她们进去，却没有找到主耶稣的身体。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:5; 约翰福音 20:11–12; 使徒行传 1:10"> 正在为这事十分困惑的时候，看哪，有两个人穿着耀眼的衣服，站在她们旁边。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:5–6; 马太福音 28:3–5; 启示录 1:18"> 她们惊惧，把脸伏在地上。<br />那两个人对她们说：“为什么在死人中寻找活着的呢？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:22–23; 路加福音 9:22; 马可福音 8:31"> 祂不在这里，已经复活了。你们要记得，祂还在加利利的时候怎样对你们说，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:21"> 人子必须被交在罪人手里，被钉十字架，第三天复活。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:16; 约翰福音 14:26; 约翰福音 2:19–22"> 她们就想起耶稣的话，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 马可福音 16:7–8; 马太福音 28:7–8"> 从坟墓那里回去，把这一切事告诉十一个使徒和其余的人。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:56; 约翰福音 20:11–18; 路加福音 8:2–3"> 这些妇女就是抹大拉的马利亚、约亚拿、雅各的母亲马利亚；还有和她们在一起的其他妇女，也把这些事告诉使徒。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 9:16; 马可福音 16:11; 创世记 19:14"> 她们这些话在使徒看来像是胡言乱语，他们就不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 20:3–10"> 彼得却起来，跑到坟墓那里，弯腰往里看，只见细麻布独自放在那里；他就回自己的地方去，心里希奇所发生的事。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 马可福音 16:12–13"> 看哪，就在那一天，他们中间有两个人往一个名叫以马忤斯的村子去，离耶路撒冷约有六十斯塔迪亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六十斯塔迪亚约为十一公里，或约七英里。">a</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命记 6:7; 玛拉基书 3:6"> 他们彼此谈论所发生的这一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:20; 约翰福音 14:18–19; 路加福音 24:36"> 正谈论、彼此讨论的时候，耶稣亲自走近，和他们同行。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 20:14; 约翰福音 21:4; 路加福音 24:31"> 只是他们的眼睛被蒙住了，认不出祂来。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:20–22; 约翰福音 16:6; 以西结 9:4–6"> 耶稣对他们说：<span className="woj">“你们一边走路一边谈论的是什么事？为什么忧愁呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 19:25"> 其中一个名叫革流巴的回答祂说：“你是在耶路撒冷作客的人中，唯一不知道这几天在那里所发生之事的吗？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:11; 使徒行传 7:22; 约翰福音 4:19"> 耶稣对他们说：<span className="woj">“什么事？”</span><br />他们对祂说：“就是关于拿撒勒人耶稣的事。祂在上帝和众百姓面前，是一位说话行事都有大能的先知；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:13–15; 使徒行传 4:8–10; 路加福音 23:13"> 祭司长和我们的官长竟把祂交出去，定了死罪，并且把祂钉在十字架上。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前书 1:18–19; 路加福音 2:38"> 但我们原来盼望，祂就是那要救赎以色列的。不仅如此，这些事发生到现在，已经是第三天了。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 16:9–10; 马太福音 28:7–8; 约翰福音 20:1–2"> 还有，我们中间有几个妇女使我们惊奇；她们清早到了坟墓那里，</span>
<span className="v" id="v23" data-v="23"> 没有找到祂的身体，就回来，说她们也看见了天使显现，天使说祂活着。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 约翰福音 20:1–10"> 我们中间也有人去了坟墓，发现事情正如妇女所说的，只是没有看见祂。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 7:18; 马可福音 9:19; 希伯来书 5:11–12"> 耶稣对他们说：<span className="woj">“无知的人哪，先知所说的一切，你们的心信得何等迟钝！</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:11; 以赛亚书 53:1–12; 撒迦利亚书 13:7"> <span className="woj">基督受这些苦，然后进入祂的荣耀，岂不是必须的吗？”</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:14; 路加福音 24:44; 申命记 18:15"> 于是祂从摩西和众先知开始，凡经上指着自己所说的话，都给他们解释明白。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 6:48; 创世记 19:2; 创世记 32:26"> 他们将近所去的村子，耶稣好像还要往前走。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪下 4:8; 路加福音 14:23; 创世记 19:3"> 他们却强留祂，说：“请同我们住下吧，因为时候晚了，天也快黑了。”<br />耶稣就进去，要同他们住下。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:19; 路加福音 24:35; 马太福音 15:36"> 到了同他们坐席的时候，祂拿起饼来，祝谢了，擘开，递给他们。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 约翰福音 8:59; 路加福音 4:30"> 他们的眼睛开了，就认出祂来；祂却从他们眼前消失了。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米书 23:29; 希伯来书 4:12"> 他们彼此说：“祂在路上和我们说话，又给我们讲解圣经的时候，我们的心岂不是在里面火热吗？”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 16:13; 约翰福音 20:19–26; 使徒行传 1:14"> 他们立刻起来，回到耶路撒冷，找到十一使徒和同他们在一起的人聚集在一处，</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 15:5; 马可福音 16:7; 路加福音 22:54–62"> 说：“主果然复活了，已经向西门显现了！”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 16:12–13; 使徒行传 2:42; 路加福音 24:30–31"> 两个人就把路上所遇见的事，以及擘饼的时候怎样认出祂来，都述说了一遍。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦后书 3:16; 以赛亚书 57:18; 马可福音 16:14"> 他们正说这些事的时候，耶稣亲自站在他们中间，对他们说：<span className="woj">“愿你们平安。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:13; 马太福音 14:26–27; 约伯记 4:14–16"> 他们却惊惶害怕，以为看见了灵。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:14; 希伯来书 4:13; 但以理 4:19"> 耶稣对他们说：<span className="woj">“你们为什么惊慌？为什么心里起疑念呢？</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 20:27; 约翰一书 1:1; 传道书 12:7"> <span className="woj">看我的手、我的脚，就知道真是我。摸我看看；灵没有肉身和骨头，正如你们看见我有一样。”</span></span>
<span className="v" id="v40" data-v="40"> 说了这话，祂就把手和脚给他们看。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 21:5; 诗篇 126:1–2; 创世记 45:26–28"> 他们因欢喜还不敢相信，又很惊奇，耶稣就对他们说：<span className="woj">“你们这里有什么吃的吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 他们给祂一片烤鱼和一些蜂房。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:41"> 祂接过来，在他们面前吃了。</span>
<span className="v" id="v44" data-v="44" data-xref="撒迦利亚书 12:10; 路加福音 24:26–27; 撒迦利亚书 9:9"> 祂对他们说：<span className="woj">“这就是我还与你们同在的时候，对你们所说的话：凡摩西律法、先知书和诗篇上指着我所写的一切，都必须应验。”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="使徒行传 16:14; 约翰一书 5:20; 诗篇 119:18"> 于是祂开他们的心窍，使他们能明白圣经，</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:2–12; 以赛亚书 50:6; 路加福音 24:44"> 又对他们说：<span className="woj">“经上这样写着，基督必须受苦，第三天从死人中复活；</span></span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 5:31; 以赛亚书 49:6; 使徒行传 2:38"> <span className="woj">并且要奉祂的名，从耶路撒冷开始，把悔改和赦罪的道传给万国。</span></span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 1:8; 使徒行传 2:32; 使徒行传 13:31"> <span className="woj">你们就是这些事的见证人。</span></span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 1:8; 使徒行传 1:4; 约珥 2:28–32"> <span className="woj">看哪，我要把我父所应许的差到你们身上；但你们要在耶路撒冷城里等候，直到你们领受从高处来的能力。”</span></span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行传 1:12; 马太福音 21:17; 马可福音 11:1"> 耶稣领他们出去，直到伯大尼附近，就举手给他们祝福。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行传 1:9; 马可福音 16:19; 列王纪下 2:11"> 正祝福他们的时候，祂离开他们，被接到天上去了。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 28:9; 约翰福音 16:22; 诗篇 30:11"> 他们就敬拜祂，满心欢喜地回耶路撒冷去，</span>
<span className="v" id="v53" data-v="53" data-xref="马可福音 16:20; 使徒行传 2:46–47; 使徒行传 5:41–42"> 常在圣殿里赞美、称颂上帝。阿们。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:23–27; 路加福音 19:47–48; 使徒行传 6:12"> 有一天，耶稣在圣殿里教导百姓，传讲福音，祭司<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加有“长”。">a</a></sup>和文士同长老来到祂面前，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:14; 马可福音 11:28–33; 约翰福音 2:18"> 问祂说：“告诉我们，你凭什么权柄做这些事？给你这权柄的是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 15:2–3; 路加福音 22:68; 歌罗西书 4:6"> 耶稣回答他们说：<span className="woj">“我也要问你们一个问题；你们告诉我：</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 马太福音 11:7–19; 马太福音 17:11–12"> <span className="woj">约翰的洗礼是从天上来的，还是从人来的？”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:34; 约翰福音 1:15–18; 约翰福音 1:30"> 他们彼此商议说：“若说‘从天上来的’，祂必说：‘那你们为什么不信他？’</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:26; 马太福音 11:9; 约翰福音 10:41"> 若说‘从人来的’，百姓都要用石头打死我们，因为他们确信约翰是先知。”</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:14; 彼得后书 3:3; 以赛亚书 41:28"> 于是他们回答说，不知道是从哪里来的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 马太福音 21:27; 马可福音 11:33"> 耶稣对他们说：<span className="woj">“我也不告诉你们，我凭什么权柄做这些事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 21:33–46; 马可福音 12:1–12; 以赛亚书 5:1–7"> 耶稣开始对百姓讲这个比喻：<span className="woj">“有一个</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU（括号中）和 TR 加有“某”。">b</a></sup><span className="woj">人栽了一个葡萄园，租给园户，就往外国去了很久。</span></span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 尼希米记 9:26; 马太福音 21:34–36"> <span className="woj">到了时候，他差一个仆人到园户那里，要他们交葡萄园的果子；园户却打了他，叫他空手回去。</span></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿 10:1; 希伯来书 11:36–37; 帖撒罗尼迦前书 2:2"> <span className="woj">他又差另一个仆人去；他们也打了他，并且羞辱他，叫他空手回去。</span></span>
<span className="v" id="v12" data-v="12"> <span className="woj">他又差第三个仆人去；他们也伤了他，把他赶出去。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 3:17; 约翰福音 3:16–17; 耶利米书 36:7"> <span className="woj">葡萄园的主人说：‘我该怎么办呢？我要差我的爱子去；也许他们见了他，会尊重他。’</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:17; 希伯来书 1:2; 使徒行传 2:23"> <span className="woj">“园户看见他，就彼此议论说：‘这是承受产业的。来吧，我们杀了他，好让产业归我们。’</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:12; 马可福音 12:6–9; 马太福音 21:37–40"> <span className="woj">于是他们把他推出葡萄园外，杀了。那么，葡萄园的主人要怎样处置他们呢？</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行传 13:46; 马太福音 21:41"> <span className="woj">他要来除灭这些园户，把葡萄园交给别人。”</span><br />众人听见了，就说：“绝不可如此！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="诗篇 118:22; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣看着他们，说：<span className="woj">“那么，经上所写的是什么意思呢：</span><br /><span className="pl pl-1 woj">‘匠人所弃的石头，</span><br /><span className="pl pl-2 woj">已成了房角的头块石头’？</span></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 8:14–15; 撒迦利亚书 12:3; 但以理 2:44–45"> <span className="pl pl-1 woj">凡跌在那石头上的，必被撞碎；</span><br /><span className="pl pl-2 woj">那石头落在谁身上，就要把谁砸得粉碎。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 马太福音 21:45–46"> 祭司长和文士正想当时下手拿住耶稣，却惧怕百姓；因为他们知道这比喻是指着他们说的。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 马太福音 22:15–22; 马太福音 27:2"> 于是他们窥探耶稣，派奸细装作正直人，要从祂的话中抓住把柄，好把祂交在总督的权柄和管辖之下。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦前书 2:4–5; 马太福音 26:49–50; 马太福音 22:16"> 奸细问祂说：“老师，我们知道你所说所教的都是正道，也不偏待人，乃是按真理教导上帝的道路。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 9:37; 马可福音 12:14–17; 使徒行传 5:37"> 我们纳税给凯撒，合乎律法不合乎？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:18; 哥林多前书 3:19; 路加福音 5:22"> 耶稣看出他们的诡诈，就对他们说：<span className="woj">“你们为什么试探我？</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:28; 使徒行传 11:28; 使徒行传 26:32"> <span className="woj">拿一个银币给我看，上面有谁的像和名号？”</span><br />他们回答说：“凯撒的。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 13:6–7; 马可福音 12:17; 彼得前书 2:13–17"> 耶稣对他们说：<span className="woj">“这样，凯撒的归给凯撒，上帝的归给上帝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多书 1:10"> 他们在百姓面前不能从祂的话中抓住把柄，就希奇祂的回答，闭口无言。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:1–2; 哥林多前书 15:12; 马可福音 12:18–27"> 撒都该人中有几个来见耶稣；他们说没有复活。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 25:5–10; 创世记 38:8; 创世记 38:11"> 他们问祂说：“老师，摩西为我们写着说，若一个人的兄弟死了，留下妻子，没有孩子，他兄弟就当娶那妻，为兄弟立后。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:20; 耶利米书 22:30"> 有兄弟七人，第一个娶了妻，没有孩子就死了；</span>
<span className="v" id="v30" data-v="30"> 第二个也娶了她为妻，也没有孩子就死了；</span>
<span className="v" id="v31" data-v="31"> 第三个也娶了她；七个人都是这样，没有留下孩子就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="传道书 1:4; 传道书 9:5; 希伯来书 9:27"> 后来那女人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 22:24–28; 马可福音 12:19–23"> 这样，复活的时候，她是哪一个人的妻子呢？因为七个人都娶过她为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯来书 13:4"> 耶稣对他们说：<span className="woj">“这世代的人有娶有嫁；</span></span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 1:5; 约翰福音 5:29; 但以理 12:2–3"> <span className="woj">但那些被算为配得那世代，并配从死人中复活的人，也不娶，也不嫁。</span></span>
<span className="v" id="v36" data-v="36" data-xref="启示录 21:4; 腓立比书 3:21; 马太福音 22:30"> <span className="woj">因为他们不能再死；他们像天使一样，又是上帝的儿女，因为他们是复活之子。</span></span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 3:2–6; 马可福音 12:26–27; 使徒行传 7:30–32"> <span className="woj">至于死人复活，摩西在荆棘篇上也显明了，因为他称主为‘亚伯拉罕的上帝，以撒的上帝，雅各的上帝。’</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:25–26; 歌罗西书 3:3–4; 罗马书 6:10–11"> <span className="woj">上帝不是死人的上帝，乃是活人的上帝；因为在祂面前，人都是活的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 23:9; 马可福音 12:28–34; 马太福音 22:34–40"> 有几个文士回答说：“老师，你说得好。”</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 22:46; 马可福音 12:34; 箴言 26:5"> 以后他们再也不敢问祂什么。</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="马可福音 12:35–37; 马太福音 1:1; 马太福音 22:41–45"> 耶稣对他们说：<span className="woj">“人怎么说基督是大卫的子孙呢？</span></span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 110:1; 使徒行传 2:34–35; 希伯来书 1:13"> <span className="woj">大卫自己在诗篇上说：</span><br /><span className="pl pl-1 woj">‘主对我主说：</span><br /><span className="pl pl-2 woj">“你坐在我的右边，</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 19:27; 诗篇 110:1; 启示录 19:14–21"> <span className="pl pl-2 woj">等我使你的仇敌作你的脚凳。”’</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="启示录 22:16; 路加福音 1:31–35; 马太福音 1:23"> <span className="woj">“大卫既称祂为主，祂怎么又是大卫的子孙呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 15:10; 马可福音 12:38–39; 马可福音 8:34"> 众百姓都听着的时候，耶稣对门徒说：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 马可福音 12:38–39; 路加福音 14:7"> <span className="woj">“你们要防备那些文士；他们喜欢穿长袍游行，喜爱人在市场上问安，又喜爱会堂里的首位、筵席上的上座；</span></span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 12:40; 雅各书 3:1; 提多书 1:16"> <span className="woj">他们吞吃寡妇的家产，又假意作很长的祷告。这些人要受更重的刑罚。”</span></span>
</div>
</div>

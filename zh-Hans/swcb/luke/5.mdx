<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 马可福音 3:9"> 有一次，众人拥挤着耶稣，要听上帝的话；祂站在革尼撒勒湖边。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:19; 马太福音 4:21"> 祂看见湖边停着两只船，打鱼的人已经离开船，正在洗网。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:18; 马太福音 13:1–2; 约翰福音 1:41–42"> 祂上了其中一只船，就是西门的船，请他把船稍微撑离岸边；祂就坐下，从船上教导众人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 21:6; 马太福音 17:27"> 讲完了，祂对西门说：<span className="woj">“把船开到水深的地方，下网打鱼。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:5; 约翰福音 15:14; 路加福音 6:46–48"> 西门回答说：“主啊，我们整夜劳苦，什么也没有打着；但凭你的话，我就下网。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 15:58; 约翰福音 21:6–11; 传道书 11:6"> 他们这样做了，就圈住一大群鱼，网几乎要裂开。</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 6:2; 腓立比书 4:3; 使徒行传 11:25"> 他们向另一只船上的同伴招手，请他们来帮助。那些人来了，把两只船都装满，甚至船都快沉下去。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 6:5; 约伯记 42:5–6; 启示录 1:17"> 西门彼得看见，就俯伏在耶稣膝前，说：“主啊，离开我吧！我是个有罪的人。”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; 诗篇 8:8; 马可福音 9:6"> 因为他和一切同在的人，都因他们所打的这一网鱼而惊骇；</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 马太福音 13:47; 以西结 47:9–10"> 西庇太的儿子雅各、约翰，就是西门的伙伴，也同样惊骇。<br />耶稣对西门说：<span className="woj">“不要怕！从今以后，你要得人如得活鱼。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 4:20; 路加福音 5:28; 马太福音 19:27"> 他们把两只船靠了岸，就撇下一切，跟从了祂。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 50:15; 路加福音 17:16; 马太福音 8:2–4"> 有一次，耶稣在一座城里；看哪，有一个满身麻风的人。他看见耶稣，就脸伏于地求祂，说：“主啊，你若愿意，就能使我洁净。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 约翰福音 4:50–53; 何西阿 14:4"> 耶稣伸手摸他，说：<span className="woj">“我愿意；你洁净了吧。”</span><br />麻风立刻离开了他。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 14:2–32; 路加福音 17:14; 马可福音 1:44"> 耶稣嘱咐他不可告诉人，又说：<span className="woj">“只要去，把身体给祭司察看，并且照摩西所吩咐的，为你得洁净献上礼物，作为给他们的见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:30–31; 路加福音 12:1; 马可福音 1:45–2"> 然而关于耶稣的消息越发传开，有许多人聚集来听祂讲道，也要祂医治他们的疾病。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 马可福音 1:35–36; 马太福音 14:23"> 祂却退到旷野去祷告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 马太福音 11:5"> 有一天，耶稣正在教导人，有法利赛人和律法教师坐在那里；他们是从加利利、犹太各乡村和耶路撒冷来的。主的能力与祂同在，使祂能医治人。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 2:3–12; 马太福音 9:2–8; 约翰福音 5:5–6"> 看哪，有几个人用褥子抬着一个瘫痪的人，想把他抬进去，放在耶稣面前。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 2:4; 马太福音 10:27; 马太福音 24:17"> 他们因为人多，找不到办法抬进去，就上了屋顶，从瓦缝中把他连褥子缒下去，放在众人中间，正在耶稣面前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 14:9; 马太福音 9:2; 马可福音 2:5"> 耶稣看见他们的信心，就对那人说：<span className="woj">“朋友，你的罪赦了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 43:25; 马可福音 2:6–7; 路加福音 7:49"> 文士和法利赛人就议论说：“这说亵渎话的是谁？除了上帝以外，谁能赦罪呢？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; 以赛亚书 66:18; 诗篇 139:2"> 耶稣知道他们的议论，就回答他们说：<span className="woj">“你们心里为什么这样议论？</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 2:9; 马太福音 9:5"> <span className="woj">说‘你的罪赦了’，或说‘起来行走’，哪一样容易呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="启示录 1:13; 以赛亚书 53:11; 路加福音 8:54"> <span className="woj">但要叫你们知道，人子在地上有赦罪的权柄，”</span>祂就对瘫痪的人说：<span className="woj">“我吩咐你，起来，拿起你的褥子，回家去吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 9:24; 路加福音 5:13; 诗篇 107:20–22"> 那人立刻在他们面前站起来，拿起自己所躺的褥子，荣耀上帝，回家去了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 9:8; 马太福音 12:23; 路加福音 7:16"> 众人都大大惊奇，荣耀上帝，又满心敬畏，说：“我们今天看见了奇妙的事！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 2:13–22; 马太福音 9:9–17; 约翰福音 1:43"> 这些事以后，耶稣出去，看见一个名叫利未的税吏坐在税关那里，就对他说：<span className="woj">“跟从我！”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 马太福音 19:22–27; 列王纪上 19:19–21"> 他就撇下一切，起来跟从了耶稣。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 2:15; 路加福音 15:1; 哥林多前书 10:27"> 利未在自己家里为耶稣大摆筵席；有一大群税吏和别人同他们一起坐席。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:28–32; 路加福音 5:17; 马可福音 7:3"> 他们的文士和法利赛人就向耶稣的门徒发怨言，说：“你们为什么和税吏并罪人一同吃喝？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 2:17; 马太福音 9:12–13; 耶利米书 8:22"> 耶稣回答他们说：<span className="woj">“健康的人不需要医生，有病的人才需要。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前书 1:15–16"> <span className="woj">我来不是召义人，而是召罪人悔改。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 9:14–17; 马可福音 2:18–22; 约翰福音 3:25"> 他们对祂说：“约翰的门徒常常禁食祷告，法利赛人的门徒也是这样；你的门徒却又吃又喝，这是为什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 3:29; 哥林多后书 11:2; 以赛亚书 54:5"> 耶稣对他们说：<span className="woj">“新郎和陪伴的人同在的时候，你们能叫他们禁食吗？</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行传 14:23; 使徒行传 3:21"> <span className="woj">但日子将到，新郎要从他们中间被取走；到那些日子，他们就要禁食。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马太福音 9:16–17; 马可福音 2:21–22; 哥林多后书 6:16"> 祂又对他们讲一个比喻：<span className="woj">“没有人从新衣服上撕下一块来补在旧衣服上；若是这样，不但撕破了新的，那从新衣服撕下来的补丁也和旧的不相称。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 9:13; 诗篇 119:83; 约书亚记 9:4"> <span className="woj">也没有人把新酒装在旧皮袋里；若是这样，新酒会胀破皮袋，酒就漏出来，皮袋也毁了。</span></span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 8:8–13; 哥林多后书 5:17; 以西结 36:26"> <span className="woj">新酒必须装在新皮袋里，两样就都保全。</span></span>
<span className="v" id="v39" data-v="39" data-xref="希伯来书 11:39; 马可福音 7:7–13; 耶利米书 6:16"> <span className="woj">没有人喝了陈酒，立刻想喝新酒；因为他说：‘陈的好。’”</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 9:1; 但以理 5:31; 但以理 10:18"> “至于我，在米底人大流士元年，我曾起来坚固他、加强他。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:5–6; 但以理 8:26; 启示录 21:5"> “现在我要把真理告诉你。看哪，波斯还要有三位君王兴起。第四位必比众人都富足得多。他因财富而强盛时，就必激动众人攻击希腊国。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理 11:16; 但以理 11:36; 但以理 8:21"> 必有一位强大的王兴起，他要以大权柄统治，按自己的意思行事。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理 8:22; 但以理 8:8; 耶利米书 12:17"> 他兴起以后，他的国必破裂，分向天的四风；却不归他的后裔，也不照他统治时所掌的权柄，因为他的国必被拔除，归给这些人以外的人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理 11:14; 但以理 11:11; 但以理 11:25"> “南方王必强盛。他的一位将领必比他更强盛，并且掌权；他的统治必是大统治。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理 11:13; 但以理 11:40; 但以理 11:7"> 过了若干年，他们必彼此联合；南方王的女儿必到北方王那里去立约，但她不能保住自己膀臂的力量。他也站立不住，他的膀臂也不能站立；她和带她来的人、生她的父亲，以及那时扶助她的人，都必被交出。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理 11:38–39; 但以理 11:19–20; 以赛亚书 9:14"> “但从她根中发出的一枝，必有一人兴起接替他的位置；他必来到军队那里，进入北方王的堡垒，攻击他们，并且得胜。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 37:19; 以赛亚书 46:1–2; 耶利米书 43:12–13"> 他还要把他们的神明、铸成的偶像，以及他们金银的贵重器皿，掳到埃及去。他有几年不去攻击北方王。</span>
<span className="v" id="v9" data-v="9"> 他必进入南方王的国，却要返回自己的地。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 51:42; 但以理 11:7; 但以理 11:26"> 他的儿子们必发动战争，招聚大批强大的军队；这军队必前来，如洪水泛滥，横扫而过。他们必回来争战，直到他的堡垒。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理 8:7; 但以理 11:5; 诗篇 33:16–17"> “南方王必被激怒，出来与他，就是与北方王交战。北方王必派出大军，这大军却必交在南方王手中。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 12:22–23; 列王纪下 14:10; 以赛亚书 10:7–12"> 这大军被带走以后，他的心必自高；他虽使数万人倒下，却不能得胜。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理 4:16; 但以理 12:7; 但以理 11:6–7"> 北方王必回来，派出比先前更大的军队。过了若干年，他必带着大军和充足的装备前来。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 17:17; 使徒行传 4:25–28"> “那时，必有许多人起来攻击南方王。你民中强暴的人也必抬高自己，要使异象成就，但他们必跌倒。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:6; 以西结 17:17; 以西结 4:2"> 于是北方王必前来，筑起攻城土垒，夺取一座坚固城。南方的军力站立不住；他的精兵也站立不住，也没有力量站立。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 8:9; 但以理 11:36; 但以理 11:3"> 但那来攻击他的，必按自己的意思行事，没有人能在他面前站立。他必站在荣美之地，毁灭在他手中。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 12:17; 以西结 4:3; 以西结 4:7"> 他必定意带着全国的力量前来，并带着公平的条件；他必实行这些条件。他要把女子中的女儿给他，为要败坏这国，但她站立不住，也不归他。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿 12:14; 耶利米书 31:10; 西番雅书 2:11"> 此后，他必转面向海岛，夺取许多地方；但有一位首领必止住他所加的羞辱，而且还要使他的羞辱归到他自己身上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 26:21; 诗篇 37:36; 约伯记 20:8"> 然后他必转面向自己地上的堡垒；但他必绊跌仆倒，不再被寻见。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 60:17; 但以理 11:7; 申命记 15:2–3"> “接替他位置而兴起的，必使征税者经过国中，以维持国的荣华；但不多几日，他必被毁灭，不因忿怒，也不因争战。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理 11:34; 但以理 8:25; 士师记 9:1–20"> “接替他位置而兴起的，是一个卑鄙的人；人没有把国的尊荣给他，他却要在太平无事的时候前来，用谄媚的话取得国权。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理 8:10–11; 但以理 11:10; 但以理 9:26"> 如洪水泛滥的军势必在他面前被冲没、被打破；约的领袖也必如此。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理 8:25; 帖撒罗尼迦后书 2:9; 诗篇 52:2"> 与他立约之后，他必行诡诈；因为他必上来，凭少数人变得强盛。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 7:25; 箴言 23:7; 马太福音 9:4"> 在太平无事的时候，他甚至要进入省中最富庶的地方，行他列祖和他列祖的列祖未曾行过的事。他必把战利品、掠物和财富分散给众人。他也必设计谋攻击堡垒，但只是到一个时期。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; 但以理 11:2; 箴言 28:25"> “他必激发自己的力量和勇气，率领大军攻击南方王；南方王也必率领一支极大而强盛的军队与他交战，但他站立不住，因为有人必设计谋害他。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理 11:10; 但以理 11:40; 撒母耳记下 4:2–12"> 吃他美食的人必毁灭他；他的军队必被冲散，许多人必被杀倒下。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 12:2; 耶利米书 9:3–5; 哈巴谷 2:3"> 至于这二王，他们的心都在作恶；他们同席说谎，但这事不能成功，因为结局仍要到指定的时候。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理 11:30–32; 但以理 8:24; 使徒行传 3:25"> 然后他必带着大量财富返回自己的地。他的心必敌对圣约；他必采取行动，然后返回自己的地。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 17:26; 以赛亚书 14:31; 但以理 11:25"> “到了指定的时候，他必回来，进入南方；但后一次必不像前一次。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 10:4; 民数记 24:24; 耶利米书 2:10"> 因为基提的船必来攻击他。因此他必灰心，转回去，向圣约发怒，并且采取行动。他还要回来，看重那些离弃圣约的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="但以理 12:11; 但以理 9:27; 马太福音 24:15"> “从他而来的军队必亵渎圣所，就是堡垒，并除掉常献的燔祭。然后他们必设立那使荒凉的可憎之物。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 28:9; 诗篇 9:10; 约翰福音 17:3"> 他必用谄媚的话败坏那些违背这约作恶的人；但认识他们上帝的子民必刚强行事。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 24:9; 约翰福音 16:2; 玛拉基书 2:7"> “民中有智慧的人必教导许多人；然而他们有许多日子会因刀剑和火焰、因被掳和被掠而跌倒。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 7:15; 罗马书 16:18; 使徒行传 20:29–30"> 他们跌倒的时候，必得到一点帮助；但许多人会用谄媚的话附从他们。</span>
<span className="v" id="v35" data-v="35" data-xref="撒迦利亚书 13:9; 玛拉基书 3:2–4; 启示录 2:10"> 有些智慧人必跌倒，为要熬炼他们、洁净他们，使他们洁白，直到末了的时候，因为还要等到指定的时候。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="启示录 13:5–6; 帖撒罗尼迦后书 2:4; 申命记 10:17"> “这王必按自己的意思行事。他必自高自大，超过一切神明，又要说奇异的话攻击万神之神。他必亨通，直到忿怒成就，因为所定的事必成就。</span>
<span className="v" id="v37" data-v="37" data-xref="帖撒罗尼迦后书 2:4; 以赛亚书 14:13; 提摩太前书 4:3"> 他不顾他列祖的神明，也不顾妇女所恋慕的，任何神明他都不顾；因为他必自大，高过一切。</span>
<span className="v" id="v38" data-v="38" data-xref="启示录 17:1–5; 以赛亚书 44:9; 启示录 13:12–17"> 他却要取而代之，尊崇堡垒之神。他要用金、银、宝石和可悦之物，尊崇他列祖所不认识的神。</span>
<span className="v" id="v39" data-v="39" data-xref="启示录 18:9–13"> 他要靠外邦神的帮助，攻取最坚固的堡垒。凡承认他的，他必加增荣耀；他要使他们管辖许多人，又为价银分地。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="但以理 11:35; 但以理 11:10; 以赛亚书 5:28"> “到末了的时候，南方王必与他争战；北方王必用战车、骑兵和许多船，像旋风一样来攻击他。他必进入列国，如洪水泛滥而过。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 48:47; 耶利米书 49:6; 以赛亚书 11:13–15"> 他也必进入荣美之地，许多国家必被倾覆；但以东、摩押和亚扪人中为首的，必从他手中得解救。</span>
<span className="v" id="v42" data-v="42" data-xref="撒迦利亚书 10:10–11; 以西结 29:14; 启示录 11:8"> 他也必伸手攻击各国。埃及地必不能逃脱。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 12:3; 那鸿书 3:9; 以西结 30:4–5"> 他必掌握埃及金银的宝藏和一切珍宝；利比亚人和古实人必跟随他的脚步。</span>
<span className="v" id="v44" data-v="44" data-xref="启示录 19:19–21; 启示录 16:12; 启示录 17:13"> 但从东方和北方来的消息必使他惊扰；他就大发烈怒出去，要毁灭许多人，将他们彻底扫除。</span>
<span className="v" id="v45" data-v="45" data-xref="帖撒罗尼迦后书 2:4; 但以理 8:25; 启示录 19:19–21"> 他必在海与荣美的圣山之间，支搭他宫殿的帐幕；然而他必来到自己的结局，没有人帮助他。</span>
</div>
</div>

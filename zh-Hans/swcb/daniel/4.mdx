<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 6:25; 彼得前书 1:2; 但以理 3:4"> 尼布甲尼撒王，<br />致住在全地各族、各国、说各种语言的人：<br />愿平安多多加给你们。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="但以理 3:26; 诗篇 66:16; 诗篇 71:18"> 我乐意将至高上帝向我所行的神迹奇事宣告出来。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 145:13; 以赛亚书 25:1; 但以理 2:44"> <span className="pl pl-1">祂的神迹何等伟大！</span><br /><span className="pl pl-2">祂的奇事何等有力！</span><br /><span className="pl pl-1">祂的国是永远的国，</span><br /><span className="pl pl-2">祂的统治直到万代。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 47:7–8; 帖撒罗尼迦前书 5:2–3; 诗篇 30:6–7"> 我尼布甲尼撒在家中安逸，在宫里兴盛。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理 2:1; 约伯记 7:13–14; 但以理 2:28–29"> 我做了一个梦，使我害怕；我在床上的思念和脑中的异象使我惊惶。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理 2:2; 创世记 41:7–8; 以赛亚书 8:19"> 于是我降旨，叫巴比伦所有的智慧人都带到我面前，好让他们把梦的解释告诉我。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 44:25; 但以理 2:7; 创世记 41:8"> 于是术士、法师、迦勒底人和占卜者都进来；我把梦告诉了他们，他们却没有把梦的解释告诉我。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理 1:7; 但以理 5:14; 但以理 4:18"> 最后，但以理来到我面前，他按我神明的名字被称为伯提沙撒，他里面有众圣神明的灵。我把梦告诉他，说：</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="但以理 2:48; 但以理 5:11; 但以理 4:8"> “术士的首领伯提沙撒啊，因为我知道你里面有众圣神明的灵，任何奥秘都不能使你为难，所以请把我所见梦中的异象和它的解释告诉我。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 12:2; 但以理 4:5; 诗篇 37:35–36"> 我在床上脑中的异象是这样：我观看，看哪，地中央有一棵树，树高极大。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 4:21–22; 申命记 9:1; 马太福音 11:23"> 那树生长，变得坚固，高达于天，从地极都能看见。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西结 31:6–7"> 它的叶子美丽，果实丰盛，树上有供众生吃的食物。田野的走兽在树下得荫，天空的飞鸟住在枝上，凡有血肉的都从它得食。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 33:2; 但以理 8:13; 但以理 7:1"> “我在床上脑中的异象中观看，看哪，有一位圣洁的守望者从天而降。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 3:10; 但以理 4:23; 以西结 31:12–13"> 他大声呼喊，说：‘砍倒这树，砍去它的枝子！摇落它的叶子，抛散它的果实！让走兽离开树下，让飞鸟离开枝上。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 14:7–9; 但以理 4:25–27; 以西结 29:14–15"> 然而，要把树根的残干留在地里，用铁圈和铜圈箍住，留在田野的青草中；让它被天露沾湿。让他的分与地上草中的走兽同在。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 4:23; 启示录 12:14; 但以理 4:25"> 使他的心改变，不再是人的心；给他一个兽心。让七个时期经过他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理 4:25; 但以理 2:21; 诗篇 75:6–7"> “‘这判决是出于守望者的命令，这要求是凭圣者的话，为要使活人知道：至高者在人类的国中掌权，要将国赐给谁就赐给谁，并且立人中最低微的治理其上。’</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理 5:15; 创世记 41:8; 但以理 5:8"> “这就是我尼布甲尼撒王所做的梦。伯提沙撒啊，你要说明它的解释，因为我国中所有的智慧人都不能把解释告诉我；但你能，因为你里面有众圣神明的灵。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理 8:27; 但以理 7:28; 但以理 4:24"> 于是但以理，就是名叫伯提沙撒的，一时惊愕无言，心中的思念使他惊惶。王回应说：“伯提沙撒，不要让这梦和它的解释使你惊惶。”<br />伯提沙撒回答说：“我主啊，愿这梦归于恨你的人，它的解释归于你的敌人。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理 4:10–12; 以西结 31:3; 以西结 31:16"> 你所看见的那棵树，生长而坚固，高达于天，从全地都能看见；</span>
<span className="v" id="v21" data-v="21"> 叶子美丽，果实丰盛，树上有供众生吃的食物；田野的走兽住在树下，天空的飞鸟栖息在枝上——</span>
<span className="v" id="v22" data-v="22" data-xref="但以理 2:37–38; 撒母耳记下 12:7; 耶利米书 27:6–8"> 王啊，那就是你；你已经长大而强盛，因为你的伟大已经增长，达到于天，你的统治达到地极。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理 5:21; 但以理 4:13–16"> “至于王看见一位圣洁的守望者从天而降，说：‘砍倒这树，毁坏它；然而，要把树根的残干留在地里，用铁圈和铜圈箍住，留在田野的青草中，让它被天露沾湿。让他的分与田野的走兽同在，直到七个时期经过他。’</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:40; 约伯记 40:11–12; 以赛亚书 46:10–11"> “王啊，解释就是这样：这是至高者的命令，已经临到我主我王：</span>
<span className="v" id="v25" data-v="25" data-xref="但以理 4:17; 耶利米书 27:5; 诗篇 83:18"> 你必被赶离人群，你的住处必与田野的走兽同在。你必被迫像牛一样吃草，被天露沾湿；七个时期必经过你，直到你知道至高者在人类的国中掌权，要将国赐给谁就赐给谁。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理 4:15; 马太福音 5:34; 马太福音 21:20"> 至于有命令要留下树根的残干，这表示你知道天掌权以后，你的国必仍然归你。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 55:6–7; 约拿 3:9; 使徒行传 8:22"> 所以，王啊，愿我的劝告蒙你悦纳：请以行公义断绝你的罪，以怜悯穷人断绝你的罪孽。或许你的安宁可以延长。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数记 23:19; 撒迦利亚书 1:6; 箴言 10:24"> 这一切都临到尼布甲尼撒王。</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 2:21; 传道书 8:11; 彼得前书 3:20"> 过了十二个月，他在巴比伦王宫中行走。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 启示录 18:10; 路加福音 14:11"> 王开口说：“这大巴比伦，不是我用我权能的大力建为王室居所，为要彰显我威严的荣耀吗？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:3–5; 启示录 16:7; 路加福音 12:20"> 这话还在王口中的时候，有声音从天上传来，说：“尼布甲尼撒王啊，有话对你说：‘国位已经离开你了。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 27:5; 但以理 5:21; 箴言 8:15–16"> 你必被赶离人群，你的住处必与田野的走兽同在。你必被迫像牛一样吃草。七个时期必经过你，直到你知道至高者在人类的国中掌权，要将国赐给谁就赐给谁。’”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="但以理 4:32; 但以理 4:25; 但以理 5:5"> 就在那一刻，这话应验在尼布甲尼撒身上。他被赶离人群，像牛一样吃草；他的身体被天露沾湿，直到他的头发长得像鹰毛，指甲像鸟爪。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="启示录 4:10; 耶利米书 10:10; 但以理 12:7"> 日子满了以后，我尼布甲尼撒举目望天，我的理性恢复了；我就称颂至高者，赞美并尊崇那永活者，<br /><span className="pl pl-1">因为祂的统治是永远的统治，</span><br /><span className="pl pl-2">祂的国直到万代。</span></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 42:2; 诗篇 135:6; 诗篇 115:3"> <span className="pl pl-1">地上所有居民都算为无有；</span><br /><span className="pl pl-2">祂按自己的旨意行事，在天上的军队中，</span><br /><span className="pl pl-2">也在地上的居民中；</span><br /><span className="pl pl-1">没有人能拦阻祂的手，</span><br /><span className="pl pl-2">或问祂：“你在做什么？”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理 4:34; 箴言 22:4; 但以理 4:15–16"> 就在那时，我的理性恢复了；为了我国的荣耀，我的威严和光彩也恢复了。我的谋士和大臣都来寻见我；我在国位上得以坚立，又有更大的威荣加给我。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 4:6–7; 诗篇 33:4–5; 彼得前书 5:5–6"> 现在，我尼布甲尼撒赞美、尊崇、荣耀天上的王；因为祂一切作为都是真实，祂的道路都公正；那行事骄傲的人，祂能使他降卑。</span>
</div>
</div>

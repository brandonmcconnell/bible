<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="DAN" data-book-slug="daniel" data-book-name="但以理" data-chapter="3" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷 2:19; 耶利米书 16:20; 以赛亚书 46:6"> 尼布甲尼撒王造了一个金像，高六十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>，宽六肘。他把它立在巴比伦省杜拉平原上。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理 3:27; 箴言 29:12; 列王纪上 12:32"> 尼布甲尼撒王派人召集总督、钦差、省长、法官、司库、谋士、司法官，以及各省所有的官员，来参加尼布甲尼撒王所立之像的奉献礼。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:17; 启示录 17:13; 启示录 13:13–16"> 于是总督、钦差、省长、法官、司库、谋士、司法官，以及各省所有的官员，都聚集来参加尼布甲尼撒王所立之像的奉献礼；他们站在尼布甲尼撒所立的像前。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理 4:1; 但以理 6:25; 弥迦书 6:16"> 传令官大声呼喊说：“各民族、各国家、各语言的人哪，有命令传给你们：</span>
<span className="v" id="v5" data-v="5" data-xref="但以理 3:15; 但以理 3:10; 但以理 3:7"> 你们一听见角、笛、琴、瑟、竖琴、排箫和各样乐器的声音，就要俯伏敬拜尼布甲尼撒王所立的金像。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:50; 马太福音 13:42; 耶利米书 29:22"> 凡不俯伏敬拜的，必立刻被扔进烈火的窑中。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 17:8; 启示录 13:3; 启示录 13:8"> 因此，那时所有的人一听见角、笛、琴、瑟、竖琴、排箫和各样乐器的声音，各民族、各国家、各语言的人就都俯伏敬拜尼布甲尼撒王所立的金像。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–16; 但以理 6:12–13; 以斯帖记 3:8–9"> 因此，那时有几个迦勒底人上前来，控告犹太人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理 5:10; 但以理 6:6; 但以理 6:21"> 他们对尼布甲尼撒王说：“愿王万岁！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理 3:4–7; 但以理 6:12; 以斯帖记 3:12–14"> 王啊，你曾下令，凡听见角、笛、琴、瑟、竖琴、排箫和各样乐器声音的人，都要俯伏敬拜金像；</span>
<span className="v" id="v11" data-v="11"> 凡不俯伏敬拜的，必被扔进烈火的窑中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理 6:13; 但以理 2:49; 使徒行传 17:7"> 有几个犹太人，就是王所派管理巴比伦省事务的沙得拉、米煞、亚伯尼歌。王啊，这些人不尊重你。他们不侍奉你的神明，也不敬拜你所立的金像。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理 3:19; 但以理 2:12; 以斯帖记 3:5–6"> 于是尼布甲尼撒怒气填胸，大发烈怒，吩咐人把沙得拉、米煞、亚伯尼歌带来。于是这些人被带到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 50:2; 但以理 3:1; 以赛亚书 46:1"> 尼布甲尼撒问他们说：“沙得拉、米煞、亚伯尼歌，你们不侍奉我的神明，也不敬拜我所立的金像，这是真的吗？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 5:29; 历代志下 32:15–17; 出埃及记 5:2"> 现在，你们一听见角、笛、琴、瑟、竖琴、排箫和各样乐器的声音，若预备好俯伏敬拜我所造的像，那就罢了；但你们若不敬拜，就必立刻被扔进烈火的窑中。有哪一位神能救你们脱离我的手呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理 1:7; 但以理 3:12"> 沙得拉、米煞、亚伯尼歌回答王说：“尼布甲尼撒啊，在这件事上我们不需要回答你。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:31; 路加福音 1:37; 希伯来书 7:25"> 如果真要这样，我们所侍奉的上帝能救我们脱离烈火的窑；王啊，祂也必救我们脱离你的手。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:29–32; 马太福音 10:39; 启示录 2:10–11"> 即使祂不这样做，王啊，也请你知道：我们决不侍奉你的神明，也不敬拜你所立的金像。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理 3:13; 利未记 26:24; 箴言 21:24"> 于是尼布甲尼撒满心烈怒，向沙得拉、米煞、亚伯尼歌变了脸色。他开口吩咐人把窑烧热，比平常加热七倍。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:23; 使徒行传 16:25; 但以理 3:15"> 他又吩咐军中几个壮士捆绑沙得拉、米煞、亚伯尼歌，把他们扔进烈火的窑中。</span>
<span className="v" id="v21" data-v="21"> 于是这些人穿着裤子、内袍、外衣和其他衣服被捆绑起来，扔进烈火的窑中。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:33; 箴言 21:18; 箴言 11:8"> 因为王的命令紧急，窑又极其炽热，火焰就烧死了那些抬沙得拉、米煞、亚伯尼歌的人。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理 6:16–17; 耶利米书 38:6; 诗篇 34:19"> 沙得拉、米煞、亚伯尼歌这三个人被捆着，落入烈火的窑中。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理 6:7; 但以理 6:22; 但以理 3:9–10"> 那时尼布甲尼撒王惊奇，急忙站起来。他对谋士们说：“我们扔进火中的，不是三个被捆绑的人吗？”<br />他们回答王说：“王啊，确实如此。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:2; 使徒行传 28:5; 马可福音 16:18"> 王回答说：“看哪，我看见有四个人松开了绑，在火中行走，并没有受伤；第四个的形貌好像神明之子。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：“上帝的儿子”。">b</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理 3:17; 以赛亚书 52:12; 启示录 19:5"> 于是尼布甲尼撒走近烈火窑口，开口说：“沙得拉、米煞、亚伯尼歌，至高上帝的仆人哪，出来，到这里来！”<br />沙得拉、米煞、亚伯尼歌就从火中出来。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 43:2; 希伯来书 11:34; 以赛亚书 26:11"> 那些总督、钦差、省长和王的谋士都聚集起来，看见这些人身上火毫无能力；他们头上的发没有烧焦，裤子也没有改变，身上甚至没有火燎的气味。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 14:7–8; 诗篇 34:7–8; 诗篇 84:11–12"> 尼布甲尼撒开口说：“沙得拉、米煞、亚伯尼歌的上帝是应当称颂的！祂差遣祂的天使，救了信靠祂的仆人；他们违抗王的命令，交出自己的身体，为的是不侍奉、不敬拜除自己上帝以外的任何神。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理 2:5; 诗篇 76:10; 申命记 32:31"> 因此我下令：任何民族、国家、语言的人，凡说话亵渎沙得拉、米煞、亚伯尼歌的上帝的，必被肢解，房屋必成为粪堆，因为没有别的神能这样施行拯救。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="但以理 2:49; 撒母耳记上 2:30; 但以理 3:12"> 于是王在巴比伦省使沙得拉、米煞、亚伯尼歌升高。</span>
</div>
</div>

</div>

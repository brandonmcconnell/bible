<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 1:17; 阿摩司 3:7; 但以理 5:1"> 巴比伦王伯沙撒元年，但以理在床上做了梦，头脑中见了异象。于是他把这梦写下来，述说事情的大意。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="启示录 7:1; 启示录 17:15"> 但以理开口说：“我夜里在异象中观看，看哪，天空的四风冲击大海。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 13:1; 但以理 7:17; 但以理 2:32–33"> 有四只大兽从海中上来，彼此各不相同。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:7; 以赛亚书 14:13–17; 以西结 17:3"> “第一只像狮子，有鹰的翅膀。我观看，直到它的翅膀被拔去；它从地上被扶起来，像人一样用两脚站立，又有人心赐给它。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理 2:39; 以赛亚书 13:17–18; 箴言 17:12"> “看哪，又有一只兽，是第二只，像熊。它一边挺起，口中牙齿之间叼着三根肋骨。有声音对它这样说：‘起来！吞吃许多肉吧！’</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 13:2; 但以理 8:20–22; 但以理 8:5–8"> “此后我观看，看哪，又有一只，像豹，背上有鸟的四个翅膀。这兽也有四个头，又有统治权赐给它。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 13:1; 启示录 12:3; 启示录 17:12"> “此后我在夜间的异象中观看，看哪，有第四只兽，可怕、有力、极其强壮；它有大铁牙，吞吃、打碎，剩下的用脚践踏。它与先前所有的兽都不同；它有十只角。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="启示录 13:5–6; 启示录 13:1; 诗篇 12:3"> “我正细看那些角，看哪，其中又长出另一只角，是小角；先前的角中有三只在它面前被连根拔起。看哪，这角上有眼睛，像人的眼睛，又有口说狂傲的话。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 1:14; 马可福音 9:3; 但以理 7:13"> <span className="pl pl-1">“我观看，直到有宝座设立，</span><br /><span className="pl pl-2">亘古常在者坐下。</span><br /><span className="pl pl-1">祂的衣服洁白如雪，</span><br /><span className="pl pl-2">祂头上的发如纯净的羊毛。</span><br /><span className="pl pl-1">祂的宝座是火焰，</span><br /><span className="pl pl-2">宝座的轮子是燃烧的火。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:27; 申命记 33:2; 启示录 20:11–15"> <span className="pl pl-1">有火河从祂面前流出。</span><br /><span className="pl pl-2">千千万万事奉祂，</span><br /><span className="pl pl-2">万万千千站在祂面前。</span><br /><span className="pl pl-1">审判庭就座，</span><br /><span className="pl pl-2">案卷都展开了。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="启示录 19:20; 启示录 20:10; 帖撒罗尼迦后书 2:8"> “那时，我因那角所说狂傲话语的声音而观看。我一直观看，直到那兽被杀，身体被毁，交给火焚烧。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理 8:7; 但以理 7:4–6"> 至于其余的兽，它们的统治权被夺去；然而它们的生命还延长了一段时期和时间。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64; 启示录 1:7; 路加福音 21:27"> “我在夜间的异象中观看，看哪，有一位像人子的，驾着天上的云而来；他来到亘古常在者那里，有人领他到祂面前。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 11:15; 但以理 7:27; 约翰福音 3:35"> 统治权、荣耀和国度都赐给了他，使各民族、各国家、各语言的人都事奉他。他的统治权是永远的统治权，必不废去；他的国度必不毁灭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理 7:28; 耶利米书 17:16; 创世记 40:7–8"> “至于我但以理，我的灵在我身体里面忧伤，我头脑中的异象使我惊惶。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:13–14; 撒迦利亚书 2:3; 启示录 5:5"> 我走近一位侍立者，问他这一切的真相。<br />“于是他告诉我，使我知道这些事的解释。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理 8:19–22; 但以理 2:37–40; 约翰福音 18:36"> ‘这四只大兽就是四个王，必从地上兴起。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理 7:27; 以赛亚书 60:12–14; 启示录 5:10"> 但至高者的圣民必领受国度，并拥有这国度，直到永永远远。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理 7:7; 但以理 2:40–43"> “于是我想知道关于第四只兽的真相；它与其他所有的兽不同，极其可怕，牙齿是铁的，爪子是铜的，吞吃、打碎，剩下的用脚践踏；</span>
<span className="v" id="v20" data-v="20" data-xref="但以理 7:23; 但以理 7:8; 但以理 7:11"> 又想知道它头上的十只角，以及后来长出的那另一只角；在这角面前有三只角倒下，就是那有眼睛、有口说狂傲话的角，它的外貌比同伴更显强大。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理 12:7; 启示录 17:14; 但以理 8:24"> 我观看，见这同一只角与圣民争战，并且胜过他们，</span>
<span className="v" id="v22" data-v="22" data-xref="但以理 7:18; 启示录 20:4; 启示录 5:10"> 直到亘古常在者来到，审判权赐给了至高者的圣民；时候到了，圣民就拥有了国度。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理 2:40; 但以理 7:7; 路加福音 2:1"> “他这样说：‘第四只兽必是地上的第四个国，与所有的国不同，必吞吃全地，践踏并打碎它。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 7:20; 但以理 11:36; 启示录 13:1"> 至于那十只角，就是必有十个王从这国中兴起。此后另有一王兴起；他与先前的不同，必制伏三个王。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理 12:7; 启示录 12:14; 帖撒罗尼迦后书 2:4"> 他必说话敌挡至高者，又必折磨至高者的圣民。他必想要改变时期和律法；他们必被交在他手中，直到一时、二时和半时。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="启示录 20:10–11; 帖撒罗尼迦后书 2:8; 启示录 11:13"> “‘但审判庭必就座，他的统治权必被夺去，直到被消耗、毁灭到底。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 72:11; 路加福音 1:33; 启示录 11:15"> 国度、统治权，以及天下诸国的伟大，都必赐给至高者圣民的百姓。祂的国度是永远的国度，一切掌权的都必事奉祂、顺从祂。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理 10:8"> “这事到此结束。至于我但以理，我的思绪使我大大惊惶，脸色也改变了；但我把这事存在心里。”</span>
</div>
</div>

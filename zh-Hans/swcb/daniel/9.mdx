<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 11:1; 但以理 1:21; 但以理 5:31–1"> 亚哈随鲁的儿子大利乌元年，他是玛代人的后裔，被立为迦勒底国的王——</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 29:10; 耶利米书 25:11–12; 历代志下 36:21"> 在他作王的第一年，我但以理从书卷上明白耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当译作全大写的 “LORD” 或 “GOD” 时，是在翻译上帝的专有名（希伯来文“יהוה”，通常发音为 Yahweh）。">a</a></sup>的话临到耶利米先知，论到耶路撒冷荒凉的年数要满，就是七十年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 33:3; 耶利米书 29:10–13; 雅各书 5:16–18"> 我就定意面向主上帝，用祷告和恳求来寻求祂，禁食，披麻蒙灰。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:28; 出埃及记 20:6; 申命记 5:10"> 我向耶和华我的上帝祷告、认罪，说：<br />“主啊，伟大而可畏的上帝，向爱祂、守祂诫命的人守约并施慈爱，</span>
<span className="v" id="v5" data-v="5" data-xref="玛拉基书 3:7; 但以理 9:11; 但以理 9:15"> 我们犯了罪，行事乖谬，作恶悖逆，偏离了祢的训令和典章。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理 9:10; 历代志下 36:15–16; 路加福音 20:10–12"> 祢的仆人众先知奉祢的名向我们的君王、首领、列祖，以及国中所有百姓说话，我们却没有听从。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:15; 耶利米书 3:25; 耶利米书 2:26–27"> “主啊，公义归于祢；至于我们，正如今日一样，是羞愧满面：犹大人、耶路撒冷的居民，以及所有以色列人，无论近处远处，在祢因他们得罪祢而驱散他们所到的各国，都是如此。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 主啊，羞愧满面归于我们，归于我们的君王、首领和列祖，因为我们得罪了祢。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 1:6–8; 但以理 9:7; 但以理 9:5"> 怜悯和赦免归于主我们的上帝，因为我们悖逆了祂。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理 9:6; 列王纪下 18:12; 尼希米记 9:13–17"> 我们没有听从耶和华我们上帝的声音，没有遵行祂借祂仆人众先知摆在我们面前的律法。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:5–10; 以赛亚书 1:4–6; 申命记 28:15–68"> 是的，以色列全体都违犯了祢的律法，偏离了，不听从祢的声音。<br />“因此，上帝仆人摩西律法中所写的咒诅和誓言倾倒在我们身上，因为我们得罪了祂。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 5:9; 耶利米哀歌 1:12; 约伯记 12:17"> 祂使祂攻击我们和审判我们的士师所说的话应验，把大灾祸降在我们身上；因为在普天之下，从未有过像临到耶路撒冷这样的事。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:15–68; 以赛亚书 9:13; 但以理 9:11"> 正如摩西律法中所写的，这一切灾祸都临到我们身上；然而我们没有恳求耶和华我们上帝施恩，使我们转离自己的罪孽，并明白祢的真理。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 9:7; 尼希米记 9:33; 诗篇 51:14"> 所以耶和华留意这灾祸，使它临到我们；因为耶和华我们的上帝在祂所行的一切事上都是公义的，而我们没有听从祂的声音。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 9:10; 出埃及记 32:11; 尼希米记 1:10"> “现在，主我们的上帝啊，祢曾用大能的手把祢的子民从埃及地领出来，为自己赢得名声，正如今日一样；我们犯了罪，我们行了恶。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 8:3; 约珥 3:17; 诗篇 87:1–3"> 主啊，求祢照祢一切的公义，使祢的怒气和忿怒转离祢的城耶路撒冷，就是祢的圣山；因为我们的罪和我们列祖的罪孽，耶路撒冷和祢的子民成了我们四围所有人的羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 80:19; 耶利米哀歌 5:18; 哥林多后书 1:20"> “现在，我们的上帝啊，求祢垂听祢仆人的祷告和恳求；为主的缘故，使祢的脸光照祢荒凉的圣所。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17; 耶利米书 36:7; 列王纪下 19:16"> 我的上帝啊，求祢侧耳而听；睁眼而看我们的荒凉，以及这称为祢名下的城；因为我们在祢面前献上恳求，不是靠我们的义，而是靠祢丰盛的怜悯。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理 9:18; 以弗所书 1:12; 阿摩司 7:2"> 主啊，求祢垂听！主啊，求祢赦免！主啊，求祢侧耳而行！我的上帝啊，为祢自己的缘故，不要迟延，因为祢的城和祢的子民都是称为祢名下的。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 145:18; 但以理 9:3–4; 罗马书 3:23"> 我说话、祷告，承认我的罪和我百姓以色列的罪，并为我上帝的圣山在耶和华我的上帝面前献上恳求的时候——</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理 8:16; 列王纪上 18:36"> 是的，我正在祷告说话的时候，起初在异象中所见的那人加百列，奉命迅速飞来，在献晚祭的时候触摸我。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理 9:24–27; 但以理 10:21; 但以理 8:16"> 他指教我，与我说话，说：“但以理啊，我现在出来，是要赐给你智慧和悟性。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理 10:19; 马太福音 24:15; 但以理 10:11–12"> 你开始恳求的时候，命令就发出；我来告诉你，因为你大蒙眷爱。所以你要思想这事，明白这异象。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:11–14; 罗马书 5:10; 耶利米书 23:5–6"> “已经为你的民和你的圣城定了七十个七，为要结束悖逆，终结罪恶，为罪孽赎罪，引进永恒的义，封住异象和预言，并膏抹至圣者。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 4:24; 以赛亚书 9:6; 以赛亚书 55:4"> “所以你要知道并明白：从命令发出，要恢复并建造耶路撒冷，直到受膏者<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“受膏者”也可译为“弥赛亚”（与“基督”同义）。">b</a></sup>那位君王，必有七个七和六十二个七。耶路撒冷必重新建造，有街道和壕沟，即使是在艰难时期。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:8; 那鸿书 1:8; 马可福音 13:2"> 六十二个七之后，受膏者<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“受膏者”也可译为“弥赛亚”（与“基督”同义）。">c</a></sup>必被剪除，并且一无所有。那将来的君王的民必毁灭这城和圣所。它的结局必如洪水，战争必持续到末了；荒凉的事已经定下。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:15; 路加福音 21:20; 但以理 12:11"> 他必与许多人坚立一约，为期一个七。在这个七的中间，他必使祭祀和供献停止。在可憎之物的翅膀上，必有使荒凉者来到；直到所定的完全结局，忿怒必倾倒在那荒凉之处。”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="DAN" data-book-slug="daniel" data-book-name="但以理" data-chapter="2" data-verses="49">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 4:5; 以斯帖记 6:1; 约伯记 33:15–17"> 尼布甲尼撒在位第二年，尼布甲尼撒做了梦；他的灵烦乱，睡意离开了他。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理 1:20; 但以理 4:6; 创世记 41:8"> 于是王吩咐人召来术士、用法术的、行邪术的和迦勒底人，要他们把王的梦告诉王。他们就进来，站在王面前。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 40:8; 创世记 41:15; 但以理 4:5"> 王对他们说：“我做了一个梦，我的灵烦乱，想知道这梦。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理 3:9; 但以理 5:10; 以斯拉记 4:7"> 迦勒底人用亚兰语对王说：“愿王万岁！请把梦告诉仆人，仆人就说明它的解释。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理 3:29; 以斯拉记 6:11; 列王纪下 10:27"> 王回答迦勒底人说：“这事已经离开我了。你们若不把梦和梦的解释告诉我，就必被砍成碎块，你们的房屋也必成为粪堆。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理 5:7; 但以理 2:48; 但以理 5:29"> 但你们若说明这梦和它的解释，就必从我这里得到礼物、赏赐和极大的尊荣。所以你们要把梦和梦的解释告诉我。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理 2:4; 但以理 2:9; 传道书 10:4"> 他们第二次回答说：“请王把梦告诉仆人，仆人就说明它的解释。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 4:5; 以弗所书 5:16"> 王回答说：“我确实知道你们是在拖延时间，因为你们看见这事已经离开我了。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 41:23; 但以理 7:25; 以斯帖记 4:11"> 但你们若不把梦告诉我，就只有一条法令对付你们；因为你们已经预备好虚谎败坏的话，要在我面前说，直到局势改变。所以你们要把梦告诉我，我就知道你们能说明它的解释。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理 2:27"> 迦勒底人回答王说：“世上没有人能说明王所问的事，因为从来没有君王、主上或统治者向任何术士、用法术的或迦勒底人要求这样的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 5:11; 以赛亚书 57:15; 创世记 41:39"> 王所要求的是罕见的事，除了众神以外，没有谁能在王面前说明；而众神并不与血肉之人同住。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理 3:13; 马太福音 2:16; 但以理 3:19"> 因此，王恼怒，极其暴怒，吩咐灭绝巴比伦所有的智慧人。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理 1:19–20; 以斯帖记 3:12–15; 以赛亚书 10:1"> 于是命令发出，智慧人都要被杀；人也寻找但以理和他的同伴，要把他们杀死。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理 2:24; 耶利米书 52:12; 撒母耳记下 20:16–22"> 那时，王的护卫长亚略已经出去要杀巴比伦的智慧人；但以理就用谋略和审慎的话回答他。</span>
<span className="v" id="v15" data-v="15"> 他问王的长官亚略：“王的命令为什么这样紧急？”于是亚略把这事告诉了但以理。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 1:18–19; 但以理 2:9–11"> 但以理进去，求王给他指定一个时间，他就可以向王说明解释。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="但以理 1:6–7; 但以理 3:12; 但以理 1:11"> 于是但以理回到自己的家，把这事告诉他的同伴哈拿尼雅、米沙利和亚撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 33:3; 马太福音 18:19; 马太福音 18:12"> 要他们为这奥秘向天上的上帝求怜悯，使但以理和他的同伴不至于与巴比伦其余的智慧人一同灭亡。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 12:6; 阿摩司 3:7; 但以理 7:7"> 这奥秘就在夜间的异象中向但以理显明。于是但以理称颂天上的上帝。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 113:2; 诗篇 145:1–2; 启示录 5:12"> 但以理回应说：<br /><span className="pl pl-1">“上帝的名是应当称颂的，直到永永远远；</span><br /><span className="pl pl-2">因为智慧和能力都属于祂。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 75:5–7; 诗篇 31:14–15; 诗篇 113:7–8"> <span className="pl pl-1">祂改变时候和季节；</span><br /><span className="pl pl-2">祂废王，也立王；</span><br /><span className="pl pl-1">祂赐智慧给智慧人，</span><br /><span className="pl pl-2">赐知识给有悟性的人。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 12:22; 约翰一书 1:5; 耶利米书 23:24"> <span className="pl pl-1">祂显明深奥隐秘的事；</span><br /><span className="pl pl-2">祂知道黑暗中的事，</span><br /><span className="pl pl-2">光明也与祂同住。</span></span>
<span className="v" id="v23" data-v="23" data-xref="但以理 2:18; 出埃及记 3:15; 但以理 2:29–30"> <span className="pl pl-1">我感谢你，赞美你，</span><br /><span className="pl pl-2">我列祖的上帝啊；</span><br /><span className="pl pl-1">你赐给我智慧和能力，</span><br /><span className="pl pl-2">现在又使我知道我们向你所求的事；</span><br /><span className="pl pl-2">因为你已经使我们知道王的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 27:24; 但以理 2:12–14"> 因此，但以理去见亚略，就是王所派要灭绝巴比伦智慧人的那人。他去对他说：“不要灭绝巴比伦的智慧人。请带我到王面前，我要向王说明解释。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 1:27–28; 但以理 6:13; 但以理 5:13"> 于是亚略急忙把但以理带到王面前，对王这样说：“我在犹大被掳的人中找到一个人，他能使王知道解释。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理 1:7; 但以理 5:16; 但以理 5:12"> 王问但以理，就是名叫伯提沙撒的，说：“我所看见的梦和它的解释，你能使我知道吗？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 47:12–14; 但以理 2:2; 以赛亚书 44:25"> 但以理在王面前回答说：“王所询问的奥秘，智慧人、用法术的、术士或占卜的都不能向王说明；</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 40:8; 阿摩司 4:13; 但以理 10:14"> 但是在天上有一位显明奥秘的上帝，祂已经使尼布甲尼撒王知道末后日子必发生的事。你的梦和你在床上头脑中的异象是这样：</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理 2:28; 阿摩司 4:13; 但以理 2:47"> “王啊，至于你，你在床上思想将来要发生的事；那显明奥秘的已经使你知道将要发生的事。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 41:16; 使徒行传 3:12; 但以理 2:17–18"> 至于我，这奥秘向我显明，并不是因为我有超过所有活人的智慧，而是为了使解释可以让王知道，并使你知道你心里的意念。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷 1:7; 以西结 28:7; 但以理 7:3–17"> “王啊，你观看，看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，源自“הִנֵּה”，意思是看、留意、观察、看见或凝视；它常用作感叹词。">a</a></sup>有一个大像。这像巨大，光辉极其灿烂，站在你面前；它的形状令人惧怕。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 51:7; 但以理 7:4–6; 启示录 17:4"> 至于这像，它的头是精金的，胸膛和臂膀是银的，腹部和大腿是铜的，</span>
<span className="v" id="v33" data-v="33" data-xref="但以理 7:19–26; 但以理 7:7–8; 但以理 2:40–43"> 腿是铁的，脚半是铁，半是泥。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理 2:44–45; 但以理 8:25; 撒迦利亚书 12:3"> 你观看，直到有一块非人手凿出来的石头，击打这像半铁半泥的脚，把它们打碎。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 2:2–3; 诗篇 37:10; 启示录 20:11"> 于是铁、泥、铜、银、金一同被打碎，变得像夏天禾场上的糠秕，被风吹散，无处可寻。那击打这像的石头变成一座大山，充满全地。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理 2:23–24"> “这就是梦；我们要在王面前说明它的解释。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结 26:7; 耶利米书 27:6–7; 以斯拉记 7:12"> 王啊，你是诸王之王，天上的上帝已经把国度、权能、力量和荣耀赐给你。</span>
<span className="v" id="v38" data-v="38" data-xref="但以理 4:21–22; 诗篇 50:10–11; 耶利米书 27:5–7"> 无论人类住在哪里，祂都把田野的走兽和天空的飞鸟交在你手中，使你统治它们一切。你就是那金头。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="但以理 5:28–31; 以赛亚书 44:28–5; 但以理 2:32"> “在你以后，必另兴起一国，低于你；又有第三国，就是铜的国，必统治全地。</span>
<span className="v" id="v40" data-v="40" data-xref="但以理 7:7; 但以理 7:19–26; 但以理 11:36–45"> 第四国必坚强如铁，因为铁能打碎并制伏万物；正如铁压碎这一切，那国也必打碎并压碎。</span>
<span className="v" id="v41" data-v="41" data-xref="启示录 17:12; 但以理 2:33–35; 启示录 12:3"> 你既看见脚和脚趾，半是窑匠的泥，半是铁，那国必是分裂的国；然而其中仍有铁的坚硬，因为你看见铁与泥泞的泥混合。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理 7:24; 启示录 13:1"> 脚趾既半是铁，半是泥，那国也必半强半脆。</span>
<span className="v" id="v43" data-v="43"> 你既看见铁与泥泞的泥混合，他们也必与人的后裔相混；但他们彼此不能结合，正如铁不能与泥混合。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 28:18; 路加福音 1:32–33; 但以理 6:26"> “在那些王的日子，天上的上帝必建立一个永不毁灭的国，它的主权也不留给别的民族；却要打碎并灭尽这一切国度，它自己必存到永远。</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 28:16; 创世记 41:32; 申命记 10:17"> 因为你看见有一块石头非人手从山中凿出来，并且打碎铁、铜、泥、银、金；伟大的上帝已经使王知道将来必发生的事。这梦是真确的，它的解释也是可靠的。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行传 10:25; 使徒行传 14:13; 以斯拉记 6:10"> 于是尼布甲尼撒王俯伏在地，敬拜但以理，并吩咐人向他献供物和馨香之物。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理 2:22; 但以理 2:28; 阿摩司 3:7"> 王回答但以理说：“你们的上帝确实是万神之神、万王之主，又是显明奥秘的，因为你能显明这奥秘。”</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="但以理 2:6; 但以理 4:9; 但以理 5:11"> 于是王使但以理尊大，赐给他许多贵重的礼物，又派他治理巴比伦全省，并作巴比伦所有智慧人的总长。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理 1:7; 以斯帖记 2:19; 但以理 3:12–30"> 但以理求王，王就委派沙得拉、米煞和亚伯尼歌管理巴比伦省的事务；但以理却留在王的门庭。</span>
</div>
</div>

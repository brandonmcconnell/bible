<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 1:3; 马可福音 6:21–22; 以赛亚书 21:4–5"> 伯沙撒王为他的一千位大臣设摆盛大的筵席，并在这一千人面前饮酒。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理 1:2; 列王纪下 24:13; 耶利米书 27:16–22"> 伯沙撒尝酒的时候，吩咐人把他父王尼布甲尼撒从耶路撒冷殿中取来的金器银器拿来，好让王和他的大臣、妻子、妃嫔用这些器皿饮酒。</span>
<span className="v" id="v3" data-v="3"> 于是他们把从耶路撒冷上帝殿中取来的金器拿来；王和他的大臣、妻子、妃嫔就用这些器皿饮酒。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理 5:23; 哈巴谷 2:19; 诗篇 135:15–18"> 他们饮酒，赞美金、银、铜、铁、木、石所造的神明。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理 4:31; 但以理 5:24–28; 约伯记 20:5"> 就在那时，有人的手指显出来，在王宫墙壁的灰泥上，靠近灯台的地方写字。王看见那只正在写字的手的一部分。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 7:17; 但以理 7:28; 那鸿书 2:10"> 王的脸色就变了，心思使他惊惶；他两腿关节发软，双膝彼此相碰。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理 5:29; 但以理 5:16; 但以理 2:48"> 王大声喊叫，吩咐人把行法术的、迦勒底人和占兆的带进来。王对巴比伦的智慧人说：“谁能读这文字，并把讲解告诉我，谁就必身穿紫袍，颈戴金链，成为国中第三位掌权者。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理 2:27; 但以理 4:7; 创世记 41:8"> 于是王所有的智慧人都进来了，却不能读那文字，也不能把讲解告诉王。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理 5:6; 但以理 2:1; 耶利米书 6:24"> 伯沙撒王就非常惊惶，脸色变了；他的大臣也都困惑不安。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理 3:9; 但以理 6:6; 但以理 2:4"> 王后因王和他大臣的话，就进入宴会厅。王后说：“愿王万岁！不要让你的心思使你惊惶，也不要让你的脸色改变。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 4:8–9; 但以理 2:47–48; 但以理 4:18"> 你国中有一个人，他里面有圣洁众神的灵；在你父王的日子，他里面显出光明、悟性和智慧，像众神的智慧。你父王尼布甲尼撒王——是的，你父王——曾立他为术士、行法术的、迦勒底人和占兆者的首领，</span>
<span className="v" id="v12" data-v="12" data-xref="但以理 5:14; 但以理 6:3; 但以理 1:7"> 因为在这但以理身上有卓越的灵、知识、悟性，又能讲解梦，说明隐语，解开疑难；王给他起名叫伯提沙撒。现在可以召但以理来，他必把讲解告诉你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理 6:13; 但以理 5:11; 但以理 2:25"> 于是但以理被带到王面前。王对但以理说：“你就是那从犹大被掳之人中的但以理，是我父王从犹大带来的吗？</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 5:11–12"> 我听说你里面有众神的灵，并且在你里面显出光明、悟性和卓越的智慧。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理 5:7–8; 以赛亚书 47:12; 以赛亚书 29:10–12"> 现在，智慧人和行法术的已经被带到我面前，要他们读这文字，并把讲解告诉我；可是他们不能说明这事的讲解。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 5:7; 创世记 40:8; 但以理 5:29"> 但我听说你能给出讲解，解开疑难。现在你若能读这文字，把讲解告诉我，你就必身穿紫袍，颈戴金链，成为国中第三位掌权者。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 5:16; 创世记 14:23; 列王纪下 5:26"> 但以理就在王面前回答说：“你的礼物可以归你自己，你的赏赐可以给别人。然而，我要为王读这文字，并把讲解告诉王。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理 2:37–38; 但以理 4:17; 但以理 4:22–25"> “王啊，至高的上帝曾将国度、伟大、荣耀和威严赐给你父王尼布甲尼撒。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理 3:6; 但以理 2:12–13; 但以理 3:4"> 因着祂所赐给他的伟大，各族、各国、各方言的人都在他面前战兢惧怕。他想杀谁就杀谁，想让谁活就让谁活；想高举谁就高举谁，想贬低谁就贬低谁。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 9:17; 耶利米书 13:18; 希伯来书 3:13"> 但他的心高傲起来，他的灵刚硬，以致行事狂傲，就被废去王位，他的荣耀也被夺去。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理 4:25; 以西结 17:24; 但以理 4:35"> 他被赶离世人，心变得像野兽一样，住处与野驴同在；他被人喂草如牛，身体被天上的露水沾湿，直到他知道至高的上帝在人类的国度中掌权，并且祂愿意立谁治理，就立谁治理。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 33:23; 出埃及记 10:3; 雅各书 4:17"> “伯沙撒啊，你是他的儿子，虽然你知道这一切，却没有谦卑自己的心，</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 12:10; 但以理 4:37; 耶利米书 10:23"> 反而高抬自己，敌对天上的主；有人把祂殿中的器皿带到你面前，你和你的大臣、妻子、妃嫔就用这些器皿饮酒。你赞美那些银、金、铜、铁、木、石所造的神明，它们不能看，不能听，也不能知道；而那位手中掌管你气息、你一切道路都属祂的上帝，你却没有荣耀祂。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 5:5"> 因此，那手的一部分从祂面前被差来，这文字就被写下。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> “所写的文字是：‘弥尼，弥尼，提客勒，乌法珥新。’</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 25:11–12; 以赛亚书 47:1–15; 耶利米书 27:7"> “这事的讲解是这样：<br />弥尼：上帝已经数算你的国，使它终结。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约伯记 31:6; 哥林多前书 3:13; 诗篇 62:9"> 提客勒：你被放在天平里称量，显出亏欠不足。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 13:17; 但以理 6:28; 但以理 5:31"> 毗勒斯：你的国被分裂，交给玛代人和波斯人。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理 5:16; 但以理 5:7"> 于是伯沙撒下令，他们就给但以理穿上紫袍，把金链戴在他颈上，并宣告关于他的事，使他成为国中第三位掌权者。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 51:31; 耶利米书 51:57; 耶利米书 51:39"> 当夜，迦勒底王伯沙撒被杀。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理 9:1; 但以理 6:1"> 玛代人大利乌得了这国，那时他约六十二岁。</span>
</div>
</div>

</div>

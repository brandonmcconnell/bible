<span className="v" id="v2" data-v="2" data-xref="诗篇 83:18; 诗篇 5:11; 诗篇 7:17"> <span className="pl pl-1">我要因你欢喜快乐；</span><br /><span className="pl pl-2">至高者啊，我要歌颂你的名。</span></span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦后书 1:9; 启示录 6:12–17; 诗篇 80:16"> <span className="pl pl-1">我的仇敌转身退后时，</span><br /><span className="pl pl-2">他们就在你面前绊跌灭亡。</span></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 140:12; 彼得前书 2:23; 诗篇 98:9"> <span className="pl pl-1">因为你为我主持公道和正义；</span><br /><span className="pl pl-2">你坐在宝座上，按公义审判。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 10:7; 申命记 9:14; 箴言 13:9"> <span className="pl pl-1">你斥责了列国；</span><br /><span className="pl pl-2">你毁灭了恶人；</span><br /><span className="pl pl-2">你涂抹了他们的名，直到永永远远。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 14:22–23; 出埃及记 14:13; 弥迦书 7:8"> <span className="pl pl-1">仇敌灭亡，永成废墟；</span><br /><span className="pl pl-2">你所倾覆的城邑，连它们的记忆也都灭没了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 103:19; 希伯来书 13:8; 诗篇 102:12"> <span className="pl pl-1">但耶和华永远掌权；</span><br /><span className="pl pl-2">祂已经为审判设立了祂的宝座。</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 96:13; 诗篇 98:9; 启示录 20:12–13"> <span className="pl pl-1">祂要按公义审判世界；</span><br /><span className="pl pl-2">祂要按正直审判万民。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 18:10; 诗篇 91:1–2; 那鸿书 1:7"> <span className="pl pl-1">耶和华也要作受欺压者的高台，</span><br /><span className="pl pl-2">在患难时作高台。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:14; 箴言 18:10; 以赛亚书 26:3–4"> <span className="pl pl-1">认识你名的人必倚靠你，</span><br /><span className="pl pl-2">因为你，耶和华，没有离弃寻求你的人。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 107:22; 诗篇 96:1–2; 诗篇 148:1–5"> <span className="pl pl-1">你们要歌颂住在锡安的耶和华，</span><br /><span className="pl pl-2">在万民中宣扬祂所做的事。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 34:6; 出埃及记 3:7; 启示录 16:6"> <span className="pl pl-1">因为追讨流血罪的那一位记念他们；</span><br /><span className="pl pl-2">祂不忘记困苦人的哀求。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 86:13; 诗篇 30:3; 诗篇 107:18"> <span className="pl pl-1">耶和华啊，求你怜悯我。</span><br /><span className="pl pl-2">求你察看我因恨我的人所受的苦难，</span><br /><span className="pl pl-1">求你把我从死亡之门提拔起来，</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 13:5; 诗篇 51:12; 诗篇 106:2"> <span className="pl pl-2">好叫我述说你一切可赞美的事。</span><br /><span className="pl pl-2">我要在锡安女子的城门中，因你的救恩欢喜快乐。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:15–16; 诗篇 57:6; 诗篇 35:8"> <span className="pl pl-1">列国陷入了自己所挖的坑；</span><br /><span className="pl pl-2">他们的脚在自己暗设的网中被缠住。</span></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:5; 士师记 1:7; 箴言 12:13"> <span className="pl pl-1">耶和华已经显明祂自己；</span><br /><span className="pl pl-2">祂已经施行审判。</span><br /><span className="pl pl-2">恶人被自己手所做的事缠住。 默想。细拉。</span></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 50:22; 约伯记 8:13; 罗马书 2:8–9"> <span className="pl pl-1">恶人必退到阴间，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup><br /><span className="pl pl-2">就是一切忘记上帝的列国。</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 12:5; 箴言 23:18; 箴言 24:14"> <span className="pl pl-1">因为贫乏人不会永远被忘记，</span><br /><span className="pl pl-2">穷人的盼望也不会永远灭没。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 3:7; 诗篇 44:23; 诗篇 7:6"> <span className="pl pl-1">耶和华啊，求你兴起！不要让人得胜。</span><br /><span className="pl pl-2">愿列国在你面前受审判。</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 62:9; 诗篇 82:6–7; 以赛亚书 31:3"> <span className="pl pl-1">耶和华啊，求你使他们惧怕。</span><br /><span className="pl pl-2">愿列国知道自己不过是人。 细拉。</span></span>

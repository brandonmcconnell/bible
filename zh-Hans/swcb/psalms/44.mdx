<span className="v" id="v8" data-v="8" data-xref="诗篇 34:2; 哥林多前书 1:29–31; 耶利米书 9:24"> <span className="pl pl-1">我们终日以上帝夸耀；</span><br /><span className="pl pl-2">我们要称谢你的名，直到永远。 细拉。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v11" data-v="11" data-xref="申命记 4:27; 申命记 28:64; 罗马书 8:36"> <span className="pl pl-1">你使我们像供人吃的羊，</span><br /><span className="pl pl-2">又把我们分散在列国中。</span></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:13; 申命记 32:30; 以赛亚书 52:3–4"> <span className="pl pl-1">你白白卖了你的子民，</span><br /><span className="pl pl-2">从他们的售价中一无所得。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 79:4; 诗篇 80:6; 诗篇 89:41"> <span className="pl pl-1">你使我们成为邻舍的羞辱，</span><br /><span className="pl pl-2">成为周围人的嘲笑和讥讽。</span></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 24:9; 列王纪下 19:21; 约伯记 16:4"> <span className="pl pl-1">你使我们在列国中成为话柄，</span><br /><span className="pl pl-2">在众民中令人摇头。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 69:7; 耶利米书 3:25; 诗篇 89:45"> <span className="pl pl-1">我的羞辱终日在我面前，</span><br /><span className="pl pl-2">羞愧遮盖我的脸，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:2; 诗篇 74:10; 诗篇 74:18"> <span className="pl pl-2">都因那辱骂和毁谤者的声音，</span><br /><span className="pl pl-2">因仇敌和报复者。</span></span>
<span className="v" id="v17" data-v="17" data-xref="但以理 9:13; 申命记 8:14; 申命记 6:12"> <span className="pl pl-1">这一切临到我们身上，</span><br /><span className="pl pl-2">然而我们没有忘记你，</span><br /><span className="pl pl-2">也没有背弃你的约。</span></span>

<span className="v" id="v19" data-v="19" data-xref="约伯记 3:5; 诗篇 23:4; 耶利米书 14:17"> <span className="pl pl-2">虽然你在豺狼出没之地压碎了我们，</span><br /><span className="pl pl-2">又用死荫遮盖我们。</span></span>

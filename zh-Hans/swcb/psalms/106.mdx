<span className="v" id="v2" data-v="2" data-xref="罗马书 11:33; 以弗所书 1:19; 诗篇 145:3–12"> <span className="pl pl-1">谁能述说耶和华大能的作为，</span><br /><span className="pl pl-2">或完全宣扬祂一切可赞美的事呢？</span></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 15:2; 雅各书 1:25; 约翰福音 15:14"> <span className="pl pl-1">持守公正的人有福了；</span><br /><span className="pl pl-2">时时行公义的人有福了。</span></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 119:132; 路加福音 23:42; 尼希米记 13:14"> <span className="pl pl-1">耶和华啊，求你以你向你百姓所施的恩惠记念我；</span><br /><span className="pl pl-2">以你的救恩眷顾我，</span></span>

</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 9:16; 诗篇 78:8; 列王纪上 8:47"> <span className="pl pl-1">我们与我们的祖先一同犯了罪；</span><br /><span className="pl pl-2">我们犯了罪孽；</span><br /><span className="pl pl-2">我们行了邪恶。</span></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 14:11–12; 诗篇 78:42; 诗篇 78:11"> <span className="pl pl-1">我们的祖先在埃及不明白你的奇事；</span><br /><span className="pl pl-2">他们不记念你丰盛的慈爱，</span><br /><span className="pl pl-2">反而在海边悖逆，就是在红海边悖逆。</span></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 9:16; 以西结 20:9; 以西结 20:14"> <span className="pl pl-1">然而，祂为自己的名拯救他们，</span><br /><span className="pl pl-2">好使祂的大能显明出来。</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:15; 以赛亚书 51:10; 以赛亚书 63:11–14"> <span className="pl pl-1">祂斥责红海，海就干了；</span><br /><span className="pl pl-2">祂领他们经过深处，如同行过旷野。</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 14:30; 诗篇 107:2; 弥迦书 6:4"> <span className="pl pl-1">祂救他们脱离恨他们之人的手，</span><br /><span className="pl pl-2">从仇敌的手中救赎他们。</span></span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 15:5; 诗篇 78:53; 出埃及记 14:13"> <span className="pl pl-1">水淹没了他们的敌人；</span><br /><span className="pl pl-2">他们中间连一个也没有剩下。</span></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 14:31–21; 路加福音 8:13; 约翰福音 8:30–31"> <span className="pl pl-1">那时他们信了祂的话，</span><br /><span className="pl pl-2">歌唱赞美祂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 78:11; 出埃及记 15:24; 以赛亚书 48:17–18"> <span className="pl pl-1">他们很快就忘了祂的作为；</span><br /><span className="pl pl-2">不等候祂的旨意，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:9; 民数记 11:4; 哥林多前书 10:6"> <span className="pl pl-2">却在旷野中纵情贪欲，</span><br /><span className="pl pl-2">在荒地试探上帝。</span></span>
<span className="v" id="v15" data-v="15" data-xref="民数记 11:31–34; 以赛亚书 10:16; 诗篇 78:29–31"> <span className="pl pl-1">祂将他们所求的赐给他们，</span><br /><span className="pl pl-2">却使他们的灵魂消瘦。</span></span>
<span className="v" id="v16" data-v="16" data-xref="民数记 16:1–50; 利未记 21:10–12; 利未记 21:6–8"> <span className="pl pl-1">他们又在营中嫉妒摩西，</span><br /><span className="pl pl-2">也嫉妒耶和华的圣者亚伦。</span></span>
<span className="v" id="v17" data-v="17" data-xref="申命记 11:6; 民数记 16:29–33; 民数记 26:10"> <span className="pl pl-1">地裂开，吞下大坍，</span><br /><span className="pl pl-2">掩盖了亚比兰一党。</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:29; 民数记 16:35–40; 民数记 16:46"> <span className="pl pl-1">有火在他们一党中燃起；</span><br /><span className="pl pl-2">火焰烧灭了恶人。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 32:4–8; 出埃及记 32:35; 尼希米记 9:18"> <span className="pl pl-1">他们在何烈造了一只牛犊，</span><br /><span className="pl pl-2">敬拜铸成的像。</span></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 2:11; 出埃及记 20:4–5; 罗马书 1:22–23"> <span className="pl pl-1">这样，他们把自己的荣耀</span><br /><span className="pl pl-2">换成吃草之牛的像。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 2:32; 诗篇 78:42–51; 诗篇 106:13"> <span className="pl pl-1">他们忘了上帝他们的救主，</span><br /><span className="pl pl-2">就是在埃及行大事的那一位，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 105:23; 诗篇 78:51; 出埃及记 14:25–28"> <span className="pl pl-2">在含地行奇妙作为，</span><br /><span className="pl pl-2">在红海边行可畏之事的那一位。</span></span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:13–14; 申命记 9:25; 以西结 22:30"> <span className="pl pl-1">因此祂说要灭绝他们；</span><br /><span className="pl pl-2">若不是祂所拣选的摩西站在祂面前的破口中，</span><br /><span className="pl pl-2">使祂的怒气转消，祂就毁灭他们了。</span></span>
<span className="v" id="v24" data-v="24" data-xref="申命记 1:32; 以西结 20:6; 希伯来书 3:18–19"> <span className="pl pl-1">是的，他们藐视那美地；</span><br /><span className="pl pl-2">他们不信祂的话，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="民数记 14:22; 申命记 1:26–27; 希伯来书 3:15"> <span className="pl pl-2">却在自己的帐棚里发怨言，</span><br /><span className="pl pl-2">不听耶和华的声音。</span></span>
<span className="v" id="v26" data-v="26" data-xref="以西结 20:15; 民数记 14:28–35; 希伯来书 3:11"> <span className="pl pl-1">因此祂向他们起誓，</span><br /><span className="pl pl-2">必使他们倒毙在旷野，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 44:11; 利未记 26:33; 申命记 28:64–65"> <span className="pl pl-2">使他们的后裔倒在列国中，</span><br /><span className="pl pl-2">并把他们分散在各地。</span></span>
<span className="v" id="v28" data-v="28" data-xref="何西阿 9:10; 民数记 25:1–3; 民数记 25:5"> <span className="pl pl-1">他们又与巴力·毗珥联合，</span><br /><span className="pl pl-2">吃了死人的祭物。</span></span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:16–21; 哥林多前书 10:8; 罗马书 1:21–24"> <span className="pl pl-1">这样，他们用自己的行为惹祂发怒；</span><br /><span className="pl pl-2">瘟疫就在他们中间爆发。</span></span>
<span className="v" id="v30" data-v="30" data-xref="民数记 25:6–8; 约书亚记 7:12; 民数记 25:14–15"> <span className="pl pl-1">那时非尼哈站起来施行审判，</span><br /><span className="pl pl-2">瘟疫就止住了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="民数记 25:11–13; 马可福音 14:3–9; 申命记 24:13"> <span className="pl pl-1">这就算为他的义，</span><br /><span className="pl pl-2">直到世世代代，永远如此。</span></span>
<span className="v" id="v32" data-v="32" data-xref="民数记 20:2–13; 民数记 20:23–24; 申命记 4:21"> <span className="pl pl-1">他们又在米利巴水惹祂发怒，</span><br /><span className="pl pl-2">以致摩西因他们受了连累；</span></span>
<span className="v" id="v33" data-v="33" data-xref="民数记 20:10–11; 诗篇 107:11; 雅各书 3:2"> <span className="pl pl-1">因为他们激怒了摩西的灵，</span><br /><span className="pl pl-2">他就用嘴唇说了急躁的话。</span></span>
<span className="v" id="v34" data-v="34" data-xref="申命记 7:2; 申命记 7:16; 士师记 1:21"> <span className="pl pl-1">他们没有灭绝那些民族，</span><br /><span className="pl pl-2">正如耶和华所吩咐他们的，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="士师记 3:5–6; 哥林多前书 15:33; 哥林多前书 5:6"> <span className="pl pl-2">却与列国混杂，</span><br /><span className="pl pl-2">学习他们的行为。</span></span>
<span className="v" id="v36" data-v="36" data-xref="申命记 7:16; 士师记 2:3; 出埃及记 23:33"> <span className="pl pl-1">他们事奉他们的偶像，</span><br /><span className="pl pl-2">这就成了他们的网罗。</span></span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 17:17; 列王纪下 16:3; 申命记 32:17"> <span className="pl pl-1">是的，他们把自己的儿女献祭给鬼魔。</span></span>
<span className="v" id="v38" data-v="38" data-xref="民数记 35:33; 申命记 21:9; 以赛亚书 26:21"> <span className="pl pl-2">他们流了无辜人的血，</span><br /><span className="pl pl-2">就是自己儿女的血；</span><br /><span className="pl pl-2">他们把这些儿女献祭给迦南的偶像。</span><br /><span className="pl pl-2">那地就被血污秽了。</span></span>
<span className="v" id="v39" data-v="39" data-xref="以西结 20:18; 民数记 15:39; 利未记 17:7"> <span className="pl pl-1">这样，他们因自己的行为被玷污，</span><br /><span className="pl pl-2">在自己的作为上行淫。</span></span>
<span className="v" id="v40" data-v="40" data-xref="士师记 2:14; 申命记 9:29; 士师记 2:20"> <span className="pl pl-1">因此耶和华向祂的百姓发烈怒；</span><br /><span className="pl pl-2">祂憎恶祂的产业。</span></span>
<span className="v" id="v41" data-v="41" data-xref="士师记 2:14; 尼希米记 9:27–38; 士师记 3:8"> <span className="pl pl-1">祂把他们交在列国手中；</span><br /><span className="pl pl-2">恨他们的人就辖制他们。</span></span>
<span className="v" id="v42" data-v="42" data-xref="士师记 4:3; 士师记 10:12"> <span className="pl pl-1">他们的仇敌也欺压他们；</span><br /><span className="pl pl-2">他们被制伏在仇敌手下。</span></span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 81:12; 士师记 2:16–18; 诗篇 1:1"> <span className="pl pl-1">祂多次搭救他们，</span><br /><span className="pl pl-2">他们却在自己的计谋中悖逆，</span><br /><span className="pl pl-2">因自己的罪孽降为卑微。</span></span>
<span className="v" id="v44" data-v="44" data-xref="士师记 3:9; 士师记 4:3; 撒母耳记上 7:8–12"> <span className="pl pl-1">然而，祂听见他们哀求的时候，</span><br /><span className="pl pl-2">就顾念他们的困苦。</span></span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 105:8; 耶利米哀歌 3:32; 士师记 2:18"> <span className="pl pl-1">祂为他们记念自己的约，</span><br /><span className="pl pl-2">又照祂丰盛的慈爱回心转意。</span></span>
<span className="v" id="v46" data-v="46" data-xref="以斯拉记 9:9; 耶利米书 42:12; 耶利米书 15:11"> <span className="pl pl-1">祂也使凡掳掠他们的人</span><br /><span className="pl pl-2">都怜悯他们。</span></span>
</div>

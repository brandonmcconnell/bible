<div className="bt">
<div className="hs">交给首席乐师。可拉子孙的诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 78:1; 诗篇 33:8; 马太福音 11:15"> <span className="pl pl-1">万民哪，你们都要听这话；</span><br /><span className="pl pl-2">世上的居民哪，你们都要侧耳听，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 62:9; 箴言 22:2; 耶利米书 5:4–5"> <span className="pl pl-2">无论卑贱尊贵，</span><br /><span className="pl pl-2">贫穷富足，都要一同听。</span></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 19:14; 箴言 22:17; 马太福音 12:35"> <span className="pl pl-1">我的口要说智慧的话；</span><br /><span className="pl pl-2">我的心要发出明达的言语。</span></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 78:2; 马太福音 13:35; 民数记 12:8"> <span className="pl pl-1">我要侧耳听箴言；</span><br /><span className="pl pl-2">我要用琴解开我的谜语。</span></span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 27:24; 罗马书 8:33–34; 阿摩司 5:13"> <span className="pl pl-1">在患难的日子，</span><br /><span className="pl pl-2">当追在我脚后的罪孽环绕我时，我为何惧怕？</span></span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 6:17; 诗篇 52:7; 耶利米书 9:23"> <span className="pl pl-1">那些倚靠自己财富、</span><br /><span className="pl pl-2">因财宝众多而夸耀的人——</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:26; 提摩太前书 2:6; 彼得前书 1:18"> <span className="pl pl-2">他们没有一个能用任何方法赎回自己的弟兄，</span><br /><span className="pl pl-2">也不能把他的赎价交给上帝。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 16:26; 约伯记 36:18–19"> <span className="pl pl-1">因为赎回他们生命的代价极其昂贵，</span><br /><span className="pl pl-2">永远没有足够的偿付，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 89:48; 诗篇 16:10; 传道书 8:8"> <span className="pl pl-2">使他能永远活着，</span><br /><span className="pl pl-2">不见朽坏。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 12:20; 诗篇 39:6; 希伯来书 9:27"> <span className="pl pl-1">因为他看见智慧人也会死；</span><br /><span className="pl pl-2">愚昧人和无知人同样灭亡，</span><br /><span className="pl pl-2">将他们的财富留给别人。</span></span>
<span className="v" id="v11" data-v="11" data-xref="创世记 4:17; 诗篇 5:9; 诗篇 64:6"> <span className="pl pl-1">他们心里想，他们的家宅必永远长存，</span><br /><span className="pl pl-2">他们的住处必存到万代；</span><br /><span className="pl pl-2">他们用自己的名字称呼自己的土地。</span></span>
<span className="v" id="v12" data-v="12" data-xref="传道书 3:18–21; 诗篇 49:20; 诗篇 82:7"> <span className="pl pl-1">然而，人虽然富贵，并不能长存；</span><br /><span className="pl pl-2">他像必灭亡的牲畜一样。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:20; 哥林多前书 3:19; 路加福音 16:27–28"> <span className="pl pl-1">这就是愚昧人的结局，</span><br /><span className="pl pl-2">也是赞同他们话语之人的结局。细拉。</span></span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:3; 哥林多前书 6:2; 但以理 7:22"> <span className="pl pl-1">他们像羊群一样被赶入阴间。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup><br /><span className="pl pl-2">死亡必作他们的牧者。</span><br /><span className="pl pl-1">到了早晨，正直人必管辖他们。</span><br /><span className="pl pl-2">他们的美貌必在阴间</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup><br /><span className="pl pl-2">衰残，</span><br /><span className="pl pl-2">远离他们的华宅。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 73:24; 诗篇 56:13; 诗篇 86:13"> <span className="pl pl-1">但上帝必救赎我的灵魂脱离阴间</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="阴间是死人所在之处。">c</a></sup><br /><span className="pl pl-1">的权势，</span><br /><span className="pl pl-2">因为祂必接纳我。细拉。</span></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:7; 诗篇 37:1; 启示录 21:26"> <span className="pl pl-1">当人致富，</span><br /><span className="pl pl-2">他家的荣耀增加时，你不要惧怕；</span></span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 6:7; 约伯记 27:19; 路加福音 16:24"> <span className="pl pl-1">因为他死的时候，什么也不能带走；</span><br /><span className="pl pl-2">他的荣耀不能随他下去。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:19; 申命记 29:19; 诗篇 10:3"> <span className="pl pl-1">他活着的时候虽然为自己的灵魂祝福——</span><br /><span className="pl pl-2">你善待自己时，人们也称赞你——</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 33:30; 创世记 15:15; 诗篇 56:13"> <span className="pl pl-2">他终必归到他列祖的世代那里。</span><br /><span className="pl pl-2">他们必永远不见光。</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 49:12; 传道书 3:18–19; 约伯记 4:21"> <span className="pl pl-1">人有财富却没有悟性，</span><br /><span className="pl pl-2">就像必灭亡的牲畜一样。</span></span>
</div>

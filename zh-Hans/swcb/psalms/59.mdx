<span className="v" id="v2" data-v="2" data-xref="诗篇 139:19; 诗篇 26:9; 诗篇 55:23"> <span className="pl pl-1">求你救我脱离作恶的人，</span><br /><span className="pl pl-2">救我脱离嗜血的人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 56:6; 诗篇 69:4; 撒母耳记上 24:11"> <span className="pl pl-1">看哪，他们埋伏要害我的性命；</span><br /><span className="pl pl-2">有势力的人聚集攻击我。</span><br /><span className="pl pl-2">耶和华啊，这并不是因我的过犯，也不是因我的罪。</span></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 35:23; 以赛亚书 51:9; 箴言 1:16"> <span className="pl pl-1">我没有行恶，他们却预备攻击我。</span><br /><span className="pl pl-2">求你兴起，察看，并帮助我！</span></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 84:8; 诗篇 55:15; 诗篇 9:15"> <span className="pl pl-1">耶和华万军之上帝，以色列的上帝啊，</span><br /><span className="pl pl-2">求你醒起，惩罚万国。</span><br /><span className="pl pl-2">不要怜悯那些邪恶背信的人。 细拉。</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 59:14; 诗篇 22:16; 撒母耳记上 19:11"> <span className="pl pl-1">他们傍晚回来，像狗一样嚎叫，</span><br /><span className="pl pl-2">围着城游荡。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 57:4; 箴言 15:2; 诗篇 10:11"> <span className="pl pl-1">看哪，他们口中喷吐恶言；</span><br /><span className="pl pl-2">他们嘴唇里有刀剑。</span><br /><span className="pl pl-2">他们说：“谁听见我们呢？”</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 1:26; 诗篇 37:13; 诗篇 2:4"> <span className="pl pl-1">但耶和华啊，你必嗤笑他们；</span><br /><span className="pl pl-2">你必嘲笑万国。</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 9:9; 诗篇 62:2; 诗篇 27:14"> <span className="pl pl-1">我的力量啊，我要等候你，</span><br /><span className="pl pl-2">因为上帝是我的高台。</span></span>

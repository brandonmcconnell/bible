<div className="bt">
<div className="hs">交给指挥。耶和华的仆人大卫的诗，就是在耶和华救他脱离一切仇敌之手和扫罗之手的日子，他向耶和华诵念这歌的话。他说：</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 22:1–51; 歌罗西书 1:11; 约翰一书 4:19"> <span className="pl pl-1">耶和华啊，我爱你；你是我的力量。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 144:2; 诗篇 62:7; 诗篇 19:14"> <span className="pl pl-1">耶和华是我的岩石、我的堡垒、我的拯救者；</span><br /><span className="pl pl-2">我的上帝、我投靠的磐石；</span><br /><span className="pl pl-2">我的盾牌、我拯救的角、我的高台。</span></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 91:15; 诗篇 145:3; 诗篇 62:8"> <span className="pl pl-1">我呼求当受赞美的耶和华，</span><br /><span className="pl pl-2">就蒙拯救脱离我的仇敌。</span></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 116:3; 马太福音 27:24–25; 马可福音 14:33–34"> <span className="pl pl-1">死亡的绳索缠绕我，</span><br /><span className="pl pl-2">不敬虔的洪流使我惧怕。</span></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 86:13; 诗篇 88:3–8; 使徒行传 2:24"> <span className="pl pl-1">阴间</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup><br /><span className="pl pl-1">的绳索围绕我，</span><br /><span className="pl pl-2">死亡的网罗临到我。</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 50:15; 撒母耳记下 22:7; 诗篇 34:15"> <span className="pl pl-1">我在患难中呼求耶和华，</span><br /><span className="pl pl-2">向我的上帝呼救。</span><br /><span className="pl pl-1">祂从祂的殿中听见我的声音；</span><br /><span className="pl pl-2">我在祂面前的呼求进入祂的耳中。</span></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 4:31; 诗篇 68:7–8; 使徒行传 16:25–26"> <span className="pl pl-1">那时，大地摇撼震动，</span><br /><span className="pl pl-2">山的根基也颤抖摇动，</span><br /><span className="pl pl-2">因为祂发怒了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 21:9; 诗篇 11:6; 那鸿书 1:5–6"> <span className="pl pl-1">有烟从祂的鼻孔冒出；</span><br /><span className="pl pl-2">有吞灭的火从祂口中发出，</span><br /><span className="pl pl-2">炭火因它点燃。</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 144:5–15; 申命记 33:26; 撒母耳记下 22:10"> <span className="pl pl-1">祂又使天低垂，亲自降临；</span><br /><span className="pl pl-2">浓密的黑暗在祂脚下。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 104:3; 撒母耳记下 22:11–12; 诗篇 99:1"> <span className="pl pl-1">祂乘坐基路伯飞行，</span><br /><span className="pl pl-2">是的，祂乘着风的翅膀翱翔。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 97:2; 申命记 4:11; 诗篇 91:1"> <span className="pl pl-1">祂以黑暗为藏身之处，以环绕祂的为帐幕，</span><br /><span className="pl pl-2">就是水的黑暗、天空的密云。</span></span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 10:11; 启示录 16:21; 马太福音 17:2"> <span className="pl pl-1">因祂面前的光辉，祂的密云过去，</span><br /><span className="pl pl-2">有冰雹和火炭。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 104:7; 撒母耳记上 7:10; 诗篇 140:10"> <span className="pl pl-1">耶和华也在天空中打雷；</span><br /><span className="pl pl-2">至高者发出祂的声音：</span><br /><span className="pl pl-2">冰雹和火炭。</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:6; 哈巴谷 3:11; 民数记 24:8"> <span className="pl pl-1">祂射出祂的箭，使他们四散；</span><br /><span className="pl pl-2">祂发出许多闪电，使他们溃乱。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 106:9; 出埃及记 15:8; 弥迦书 6:2"> <span className="pl pl-1">耶和华啊，因你的斥责，</span><br /><span className="pl pl-2">因你鼻孔气息的吹袭，水的河道就显露，</span><br /><span className="pl pl-2">世界的根基也露出来。</span></span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 22:17; 诗篇 144:7; 诗篇 57:3"> <span className="pl pl-1">祂从高天伸手，</span><br /><span className="pl pl-2">抓住我，</span><br /><span className="pl pl-2">把我从众水中拉上来。</span></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 2:14–15; 诗篇 35:10; 诗篇 142:6"> <span className="pl pl-1">祂救我脱离我强大的仇敌，</span><br /><span className="pl pl-2">脱离恨我的人；因为他们比我强盛。</span></span>
<span className="v" id="v18" data-v="18" data-xref="俄巴底亚 1:10–14; 申命记 32:35; 诗篇 46:11"> <span className="pl pl-1">我遭灾的日子，他们来攻击我，</span><br /><span className="pl pl-2">但耶和华作我的扶持。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 118:5; 诗篇 31:8; 诗篇 18:36"> <span className="pl pl-1">祂也领我到宽阔之地；</span><br /><span className="pl pl-2">祂救了我，因为祂喜悦我。</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 24:4; 马太福音 6:4; 诗篇 58:11"> <span className="pl pl-1">耶和华按我的义报答我；</span><br /><span className="pl pl-2">按我手中的清洁报偿我。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 119:102; 诗篇 17:4; 诗篇 26:1"> <span className="pl pl-1">因为我谨守耶和华的道路，</span><br /><span className="pl pl-2">没有作恶离开我的上帝。</span></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 119:13; 诗篇 119:112; 诗篇 119:30"> <span className="pl pl-1">因为祂一切的典章都在我面前；</span><br /><span className="pl pl-2">祂的律例我没有从我面前丢弃。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 18:8–9; 诗篇 11:7; 历代志上 29:17"> <span className="pl pl-1">我在祂面前也无可指摘；</span><br /><span className="pl pl-2">我保守自己远离我的罪孽。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:41–42; 路得记 2:12; 撒母耳记上 26:23"> <span className="pl pl-1">所以耶和华按我的义，</span><br /><span className="pl pl-2">按我在祂眼前手中的清洁报答我。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 5:7; 诗篇 62:12; 马太福音 18:33–35"> <span className="pl pl-1">对怜悯人的人，你显出怜悯；</span><br /><span className="pl pl-2">对完全的人，你显出完全。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 3:34; 利未记 26:23–24; 雅各书 2:13"> <span className="pl pl-1">对纯洁的人，你显出纯洁；</span><br /><span className="pl pl-2">对乖僻的人，你显出难以测度。</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 66:2; 雅各书 2:5; 以赛亚书 57:15"> <span className="pl pl-1">因为你必拯救困苦的百姓，</span><br /><span className="pl pl-2">却必使高傲的眼目降卑。</span></span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 22:29; 约伯记 29:3; 以赛亚书 42:16"> <span className="pl pl-1">耶和华啊，你必点亮我的灯；</span><br /><span className="pl pl-2">我的上帝必照亮我的黑暗。</span></span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 22:30; 以弗所书 6:10–13; 哥林多后书 12:9–10"> <span className="pl pl-1">因为靠着你，我冲入敌军；</span><br /><span className="pl pl-2">靠着我的上帝，我跳过墙垣。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 32:4; 箴言 30:5; 撒母耳记下 22:31"> <span className="pl pl-1">至于上帝，祂的道路是完全的；</span><br /><span className="pl pl-2">耶和华的话经过炼净；</span><br /><span className="pl pl-2">凡投靠祂的，祂都是他们的盾牌。</span></span>
<span className="v" id="v31" data-v="31" data-xref="申命记 32:31; 诗篇 86:8; 撒母耳记下 22:32"> <span className="pl pl-1">除了耶和华，谁是上帝？</span><br /><span className="pl pl-2">除了我们的上帝，谁是磐石？</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 45:5; 诗篇 28:7; 撒母耳记下 22:33"> <span className="pl pl-2">这位上帝以力量装备我，使我的道路完全。</span></span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷 3:19; 申命记 32:13; 申命记 33:29"> <span className="pl pl-1">祂使我的脚像鹿的脚，</span><br /><span className="pl pl-2">又使我站在我的高处。</span></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 144:1; 诗篇 46:9; 撒母耳记下 22:36"> <span className="pl pl-1">祂教导我的手争战，</span><br /><span className="pl pl-2">以致我的膀臂能拉开铜弓。</span></span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 22:36; 雅各书 3:17–18; 诗篇 28:7"> <span className="pl pl-1">你也把你拯救的盾牌赐给我；</span><br /><span className="pl pl-2">你的右手扶持我；</span><br /><span className="pl pl-2">你的温柔使我为大。</span></span>
<span className="v" id="v36" data-v="36" data-xref="箴言 4:12; 撒母耳记下 22:37; 约伯记 36:16"> <span className="pl pl-1">你使我脚下的步伐宽阔，</span><br /><span className="pl pl-2">我的脚没有滑跌。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 53:10–12; 诗篇 44:5; 诗篇 35:2"> <span className="pl pl-1">我要追赶我的仇敌，并且追上他们；</span><br /><span className="pl pl-2">不将他们灭尽，我绝不转回。</span></span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 5:1–25; 撒母耳记下 22:39; 撒母耳记上 23:5"> <span className="pl pl-1">我要击穿他们，使他们不能起来；</span><br /><span className="pl pl-2">他们必倒在我的脚下。</span></span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记下 22:40–41; 诗篇 18:32; 哥林多前书 15:25–28"> <span className="pl pl-1">因为你以力量装备我去争战；</span><br /><span className="pl pl-2">你使那些起来攻击我的人屈服在我以下。</span></span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 21:12; 诗篇 94:23"> <span className="pl pl-1">你也使我的仇敌在我面前转背逃跑，</span><br /><span className="pl pl-2">使我剪除恨我的人。</span></span>
<span className="v" id="v41" data-v="41" data-xref="箴言 1:28; 约伯记 27:9; 约伯记 35:12–13"> <span className="pl pl-1">他们呼求，却无人拯救；</span><br /><span className="pl pl-2">甚至呼求耶和华，祂也不回答他们。</span></span>
<span className="v" id="v42" data-v="42" data-xref="以赛亚书 10:6; 撒迦利亚书 10:5; 列王纪下 13:7"> <span className="pl pl-1">那时，我把他们打碎，如风前的尘土；</span><br /><span className="pl pl-2">我把他们倒出，如街上的泥泞。</span></span>
<span className="v" id="v43" data-v="43" data-xref="以赛亚书 55:5; 撒母耳记下 3:1; 以赛亚书 52:15"> <span className="pl pl-1">你救我脱离百姓的纷争；</span><br /><span className="pl pl-2">你立我作列国的元首。</span><br /><span className="pl pl-1">我素不认识的民必服侍我。</span></span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 66:3; 诗篇 81:15; 申命记 33:29"> <span className="pl pl-2">他们一听见我，就必顺服我；</span><br /><span className="pl pl-2">外族人必向我屈服。</span></span>
<span className="v" id="v45" data-v="45" data-xref="弥迦书 7:17; 雅各书 1:11; 以赛亚书 24:4"> <span className="pl pl-1">外族人必衰残，</span><br /><span className="pl pl-2">并且战战兢兢地从他们的堡垒中出来。</span></span>
<span className="v" id="v46" data-v="46" data-xref="撒母耳记下 22:47; 诗篇 57:5; 诗篇 18:2"> <span className="pl pl-1">耶和华是永活的！愿我的磐石受颂赞！</span><br /><span className="pl pl-2">愿拯救我的上帝被高举！</span></span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 47:3; 罗马书 12:19; 那鸿书 1:2"> <span className="pl pl-1">就是那为我施行报应的上帝，</span><br /><span className="pl pl-2">使众民屈服在我以下。</span></span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 140:1; 诗篇 140:4; 诗篇 86:14"> <span className="pl pl-1">祂救我脱离我的仇敌；</span><br /><span className="pl pl-2">是的，你把我高举，超过那些起来攻击我的人；</span><br /><span className="pl pl-2">你救我脱离强暴的人。</span></span>
<span className="v" id="v49" data-v="49" data-xref="罗马书 15:9; 撒母耳记下 22:50–51; 诗篇 72:18–19"> <span className="pl pl-1">因此，耶和华啊，我要在列国中称谢你，</span><br /><span className="pl pl-2">我要歌颂你的名。</span></span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 144:10; 诗篇 132:10; 撒母耳记下 7:13"> <span className="pl pl-1">祂赐极大的拯救给祂所立的王，</span><br /><span className="pl pl-2">向祂的受膏者施行慈爱，</span><br /><span className="pl pl-2">就是向大卫和他的后裔</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：种子。">b</a></sup><br /><span className="pl pl-2">，直到永远。</span></span>

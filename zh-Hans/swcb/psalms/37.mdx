<div className="bt">
<div className="hs">大卫作。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 37:7; 箴言 23:17; 箴言 24:19"> <span className="pl pl-1">不要因作恶的人心怀不平，</span><br /><span className="pl pl-2">也不要嫉妒那些行不义的人。</span></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 92:7; 诗篇 90:5–6; 雅各书 1:10–11"> <span className="pl pl-1">因为他们很快就要像草被割下，</span><br /><span className="pl pl-2">又像青翠的菜蔬枯萎。</span></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 17:7–8; 马太福音 6:31–33; 诗篇 62:8"> <span className="pl pl-1">你要信靠耶和华，并且行善。</span><br /><span className="pl pl-2">住在这地，享受安稳的草场。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 15:7; 诗篇 145:19; 约翰福音 15:16"> <span className="pl pl-1">也要以耶和华为乐，</span><br /><span className="pl pl-2">祂就把你心里所求的赐给你。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前书 5:7; 腓立比书 4:6–7"> <span className="pl pl-1">要把你的道路交托给耶和华。</span><br /><span className="pl pl-2">也要信靠祂，祂必成就这事：</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 54:17; 约伯记 11:17; 以赛亚书 58:8"> <span className="pl pl-1">祂必使你的义如光发出，</span><br /><span className="pl pl-2">使你的公正如正午的太阳。</span></span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 5:7–11; 诗篇 27:14; 诗篇 62:5"> <span className="pl pl-1">要在耶和华面前安静，耐心等候祂。</span><br /><span className="pl pl-2">不要因那在自己道路上亨通的人心怀不平，</span><br /><span className="pl pl-2">也不要因那施行恶谋的人心怀不平。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各书 1:19–20"> <span className="pl pl-1">要止住怒气，离弃烈怒。</span><br /><span className="pl pl-2">不要心怀不平；那只会导致作恶。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:21; 诗篇 25:13; 诗篇 37:29"> <span className="pl pl-1">因为作恶的人必被剪除，</span><br /><span className="pl pl-2">但等候耶和华的人必承受这地。</span></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 24:24; 诗篇 103:16; 诗篇 37:35–36"> <span className="pl pl-1">再过片刻，恶人就不再存在。</span><br /><span className="pl pl-2">是的，你查看他的地方，他也不在那里。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:5; 加拉太书 5:22–23; 以赛亚书 26:3"> <span className="pl pl-1">但谦卑的人必承受这地，</span><br /><span className="pl pl-2">并以丰盛的平安为乐。</span></span>
<span className="v" id="v12" data-v="12" data-xref="弥迦书 2:1; 诗篇 35:16; 诗篇 31:13"> <span className="pl pl-1">恶人图谋害义人，</span><br /><span className="pl pl-2">向他咬牙切齿。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 2:4; 箴言 1:26; 撒母耳记上 26:10"> <span className="pl pl-1">主必嗤笑他，</span><br /><span className="pl pl-2">因为祂看见他的日子将要来到。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 诗篇 11:2; 约翰一书 3:12"> <span className="pl pl-1">恶人已经拔出刀，拉开弓，</span><br /><span className="pl pl-2">要打倒贫穷困苦的人，</span><br /><span className="pl pl-2">要杀害道路正直的人。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14–15; 诗篇 35:8; 耶利米书 51:56"> <span className="pl pl-1">他们的刀必刺入自己的心。</span><br /><span className="pl pl-2">他们的弓必被折断。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前书 6:6"> <span className="pl pl-1">义人所有的一点，</span><br /><span className="pl pl-2">胜过许多恶人的丰裕。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 41:10; 诗篇 63:8; 诗篇 145:14"> <span className="pl pl-1">因为恶人的膀臂必被折断，</span><br /><span className="pl pl-2">但耶和华扶持义人。</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 1:6; 罗马书 6:23; 诗篇 103:17"> <span className="pl pl-1">耶和华知道完全人的日子。</span><br /><span className="pl pl-2">他们的产业必存到永远。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 33:19; 箴言 10:3; 约伯记 5:20–22"> <span className="pl pl-1">在灾难的时候，他们不致羞愧。</span><br /><span className="pl pl-2">在饥荒的日子，他们必得饱足。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="诗篇 68:2; 诗篇 102:3; 路加福音 13:3"> <span className="pl pl-1">但恶人必灭亡。</span><br /><span className="pl pl-2">耶和华的仇敌必像田野的华美。</span><br /><span className="pl pl-2">他们必消逝——</span><br /><span className="pl pl-2">像烟一样消逝。</span></span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 诗篇 112:5; 箴言 22:7"> <span className="pl pl-1">恶人借贷，却不偿还，</span><br /><span className="pl pl-2">义人却慷慨施与。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前书 16:22; 加拉太书 3:13"> <span className="pl pl-1">因为蒙祂赐福的人必承受这地。</span><br /><span className="pl pl-2">被祂咒诅的人必被剪除。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 诗篇 119:133; 箴言 4:26"> <span className="pl pl-1">人的脚步由耶和华立定。</span><br /><span className="pl pl-2">祂喜悦他的道路。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 诗篇 145:14; 诗篇 94:18"> <span className="pl pl-1">他虽失脚，也不致跌倒，</span><br /><span className="pl pl-2">因为耶和华用祂的手扶持他。</span></span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:5; 诗篇 37:28; 诗篇 112:2"> <span className="pl pl-1">我从前年幼，如今年老，</span><br /><span className="pl pl-2">却从未见过义人被离弃，</span><br /><span className="pl pl-2">也未见过他的儿女乞讨食物。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 112:5; 马太福音 5:7; 诗篇 37:21"> <span className="pl pl-1">他终日恩待人，并借给人。</span><br /><span className="pl pl-2">他的后裔蒙福。</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:14; 箴言 16:6; 约翰一书 2:16–17"> <span className="pl pl-1">要离恶行善。</span><br /><span className="pl pl-2">你就永远安然居住。</span></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 11:7; 箴言 2:22; 诗篇 21:10"> <span className="pl pl-1">因为耶和华喜爱公正，</span><br /><span className="pl pl-2">不撇弃祂的圣民。</span><br /><span className="pl pl-2">他们蒙保守直到永远，</span><br /><span className="pl pl-2">但恶人的儿女必被剪除。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:21; 诗篇 37:9; 彼得后书 3:13"> <span className="pl pl-1">义人必承受这地，</span><br /><span className="pl pl-2">并永远住在其中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:6; 箴言 25:11–13; 以弗所书 4:29"> <span className="pl pl-1">义人的口谈论智慧。</span><br /><span className="pl pl-2">他的舌头讲说公正。</span></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 40:8; 申命记 6:6; 以赛亚书 51:7"> <span className="pl pl-1">他上帝的律法在他心里。</span><br /><span className="pl pl-2">他的脚步一步也不滑跌。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 诗篇 10:8–10; 诗篇 37:12"> <span className="pl pl-1">恶人窥伺义人，</span><br /><span className="pl pl-2">想要杀害他。</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 109:31; 彼得后书 2:9; 罗马书 8:1"> <span className="pl pl-1">耶和华必不把他留在恶人的手中，</span><br /><span className="pl pl-2">也不在他受审判时定他的罪。</span></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 27:14; 诗篇 37:9; 箴言 20:22"> <span className="pl pl-1">要等候耶和华，持守祂的道路，</span><br /><span className="pl pl-2">祂就高举你，使你承受这地。</span><br /><span className="pl pl-2">恶人被剪除的时候，你必亲眼看见。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="约伯记 5:3; 以西结 31:18; 以赛亚书 14:14–19"> <span className="pl pl-1">我曾见恶人大有权势，</span><br /><span className="pl pl-2">像本土青翠的树伸展枝叶。</span></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 37:10; 使徒行传 12:22–23; 以赛亚书 10:16–19"> <span className="pl pl-1">但他消逝了，看哪，他不在了。</span><br /><span className="pl pl-2">是的，我寻找他，却找不到。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 32:17; 以赛亚书 57:1–2; 提摩太后书 4:6–8"> <span className="pl pl-1">要留心完全人，观看正直人，</span><br /><span className="pl pl-2">因为和平的人有未来。</span></span>
<span className="v" id="v38" data-v="38" data-xref="箴言 14:32; 诗篇 52:5; 诗篇 1:4–6"> <span className="pl pl-1">至于过犯人，他们必一同被毁灭。</span><br /><span className="pl pl-2">恶人的未来必被剪除。</span></span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 9:9; 诗篇 91:15; 以赛亚书 12:2"> <span className="pl pl-1">但义人的救恩来自耶和华。</span><br /><span className="pl pl-2">祂是他们在患难时的坚固保障。</span></span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 31:5; 历代志上 5:20; 但以理 6:23"> <span className="pl pl-1">耶和华帮助他们，搭救他们。</span><br /><span className="pl pl-2">祂搭救他们脱离恶人，拯救他们，</span><br /><span className="pl pl-2">因为他们投靠祂。</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亚书 4:6–10; 哈该书 1:1; 撒迦利亚书 1:1–21"> 先知哈该和易多的儿子撒迦利亚，奉以色列上帝的名向在犹大和耶路撒冷的犹太人说预言。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 3:2; 以斯拉记 6:14; 撒迦利亚书 3:1–4"> 于是撒拉铁的儿子所罗巴伯和约萨达的儿子耶书亚起来，开始建造在耶路撒冷的上帝殿；上帝的先知们也与他们同在，帮助他们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 6:6; 以斯拉记 6:13; 以斯拉记 5:9"> 同一时候，大河西的总督达乃，和示他·波斯乃及他们的同伴来到他们那里，问他们说：“谁给你们命令，建造这殿，修成这墙呢？”</span>
<span className="v" id="v4" data-v="4"> 他们又询问建造这建筑之人的名字。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 33:18; 以斯拉记 7:6; 以斯拉记 7:28"> 但他们的上帝看顾犹太人的长老，他们没有使他们停工，直到事情呈到大流士那里，并有回信论到此事。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 4:9; 以斯拉记 4:11; 以斯拉记 6:6"> 以下是大河西总督达乃、示他·波斯乃，以及他们大河西的同伴亚法萨迦人，送给大流士王的信件副本。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 4:17; 但以理 6:21; 帖撒罗尼迦后书 3:16"> 他们送信给他，信上写着：<br />愿大流士王万事平安。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 7:6; 马可福音 13:1–2; 但以理 3:26"> 愿王知道，我们到了犹大省，来到伟大上帝的殿那里；这殿正在用巨石建造，墙中也安放木料。这工程勤勉推进，在他们手中顺利进展。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 5:3–4"> 于是我们询问那些长老，对他们这样说：“谁给你们命令，建造这殿，修成这墙呢？”</span>
<span className="v" id="v10" data-v="10"> 我们也询问他们的名字，好报告给您，写下带领他们之人的名字。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:16; 约拿 1:9; 使徒行传 27:23"> 他们这样回答我们说：“我们是天地之上帝的仆人，正在重建这殿；这殿许多年前已经建成，是以色列一位伟大的君王建造并完成的。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 36:16–17; 但以理 9:5; 列王纪下 24:2"> 但因我们的祖先惹天上的上帝发怒，祂就把他们交在迦勒底人、巴比伦王尼布甲尼撒手中；他毁坏了这殿，又把百姓掳到巴比伦。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:3–5; 以赛亚书 44:28–1; 以斯拉记 1:1–8"> 然而巴比伦王古列元年，古列王下令建造这上帝的殿。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯拉记 6:5; 但以理 5:2–3; 以斯拉记 5:16"> 上帝殿中的金银器皿，就是尼布甲尼撒从耶路撒冷的殿中取出、带到巴比伦庙里的那些器皿，古列王也从巴比伦庙中取出，交给一个名叫设巴萨的人；他已任命设巴萨为省长。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 6:3; 以斯拉记 1:2; 以斯拉记 3:3"> 古列对他说：‘你拿这些器皿去，放在耶路撒冷的殿中，并让上帝的殿在原址重建。’</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 3:10; 以斯拉记 6:15; 以斯拉记 3:8"> 于是这位设巴萨来到耶路撒冷，立了上帝殿的根基。从那时直到现在，这殿一直在建造，却还没有完成。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 4:15; 箴言 25:2; 以斯拉记 6:1–5"> 现在，若王看为好，请查考王在巴比伦的宝库，看看古列王是否曾下令在耶路撒冷建造这上帝的殿；也请王把您对此事的旨意告诉我们。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:32; 利未记 23:24; 哥林多前书 1:10"> 到了七月，以色列子孙已经住在各城，众人就如同一人，聚集到耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:17; 以斯拉记 2:2; 哈该书 1:1"> 约萨达的儿子耶书亚和他的弟兄众祭司，以及撒拉铁的儿子所罗巴伯和他的亲属，都起来建造以色列上帝的祭坛，要照上帝之人摩西律法书上所写的，在坛上献燔祭。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 4:4; 民数记 28:2–8; 以斯拉记 8:21–22"> 他们虽然因周围各地的民族而惧怕，仍在原来的基座上立起祭坛；他们在其上向耶和华献燔祭，就是早晨和晚上的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 8:14–17; 民数记 29:12–38; 出埃及记 23:16"> 他们照所写的守住棚节，又按数目献上每日的燔祭，照规例按每天所当献的献上。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 29:39; 民数记 28:19; 出埃及记 29:38–42"> 此后，又献常献的燔祭，以及月朔、耶和华一切分别为圣的定期节期所献的祭，并凡甘心向耶和华献礼物的人所献的祭。</span>
<span className="v" id="v6" data-v="6"> 从七月初一日起，他们开始向耶和华献燔祭；但耶和华殿的根基还没有立定。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 5:6; 使徒行传 9:36; 使徒行传 12:20"> 他们又把银钱给石匠和木匠，也把食物、饮料和油给西顿人和推罗人，使他们照波斯王古列给他们的许可，把香柏木从黎巴嫩运到海边，再运到约帕。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:3; 历代志上 23:4; 历代志上 23:24–32"> 他们来到耶路撒冷上帝殿的第二年二月，撒拉铁的儿子所罗巴伯、约萨达的儿子耶书亚，以及他们其余的弟兄，就是祭司、利未人和所有从被掳之地来到耶路撒冷的人，都开始动工；他们派二十岁以上的利未人监督耶和华殿的工程。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 2:40; 以斯拉记 3:8; 尼希米记 7:43"> 于是耶书亚和他的儿子、弟兄，甲篾和他的儿子，就是犹大的子孙，一同起来监督上帝殿中做工的人；希拿达的子孙和他们的儿子、弟兄，就是利未人，也与他们同工。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 25:1–7; 历代志上 15:27; 历代志上 16:37"> 建筑的人立耶和华殿根基的时候，众人就派祭司穿上礼服，拿着号筒，又派亚萨子孙中的利未人拿着钹，照以色列王大卫的指示赞美耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:1"> 他们彼此唱和，赞美称谢耶和华，说：“因祂本为善，祂向以色列所施的慈爱永远长存。”众人因耶和华殿的根基已经立定，就大声欢呼，赞美耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哈该书 2:3; 马太福音 13:31–32; 以赛亚书 60:22"> 但祭司、利未人和族长中，有许多年长的人曾亲眼见过先前的殿；如今这殿的根基在他们眼前立定，他们就放声大哭；也有许多人欢声高呼，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:37–40; 撒母耳记上 4:5; 尼希米记 12:43"> 以致众人分辨不出欢呼声和哭泣声；因为众人大声呼喊，声音传到远处。</span>
</div>

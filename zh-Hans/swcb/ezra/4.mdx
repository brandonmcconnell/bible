<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 22:9–10; 以斯拉记 1:11; 以斯拉记 10:16"> 犹大和便雅悯的敌人听见被掳归回的人正在为耶和华以色列的上帝建造圣殿，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 19:37; 列王纪下 17:24; 加拉太书 2:4"> 就来见所罗巴伯和族长们，对他们说：“请让我们与你们一同建造，因为我们也像你们一样寻求你们的上帝；自从亚述王以撒哈顿把我们带到这里以来，我们一直向祂献祭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:20; 马太福音 10:16; 历代志下 36:22–3"> 但所罗巴伯、耶书亚和以色列其余的族长对他们说：“你们与我们无分，不能与我们一同为我们的上帝建殿；我们自己要一同为耶和华以色列的上帝建造，正如波斯王古列王吩咐我们的。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 3:3; 尼希米记 6:9; 耶利米书 38:4"> 于是那地的人使犹大百姓的手发软，扰乱他们建造的工作。</span>
<span className="v" id="v5" data-v="5" data-xref="那鸿书 1:11; 以斯拉记 5:5–18; 诗篇 2:1–2"> 他们雇用谋士反对他们，破坏他们的计划，从波斯王古列的日子直到波斯王大流士执政的时候。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 1:1; 但以理 9:1; 使徒行传 24:5–9"> 在亚哈随鲁执政的时候，就是他执政之初，他们写状控告犹大和耶路撒冷的居民。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:26; 但以理 2:4; 以赛亚书 36:11"> 在亚达薛西的日子，比施兰、米提利达、他别和他们其余的同伴写信给波斯王亚达薛西；信是用亚兰文写成，也用亚兰文传达。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:9; 撒母耳记下 8:17; 撒母耳记下 20:25"> 省长利宏和书记伸帅也写了一封控告耶路撒冷的信给亚达薛西王，内容如下。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 5:6; 以斯拉记 6:6; 列王纪下 17:24"> 当时，省长利宏、书记伸帅和他们其余的同伴，就是底拿人、亚法萨提迦人、他毗拉人、亚法萨人、亚基卫人、巴比伦人、书珊迦人、底亥人、以拦人，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 4:17; 以斯拉记 4:11; 以斯拉记 7:12"> 以及伟大尊贵的亚斯那巴所迁移、安置在撒玛利亚城和大河西其余地区的各族人等，都写了这信。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 他们所送的信件副本如下：<br />致亚达薛西王，河西之地您的臣仆呈上。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 5:9; 历代志下 36:13; 以斯拉记 5:3"> 愿王知道，从您那里上来的犹太人已经来到我们这里，到耶路撒冷。他们正在建造这悖逆邪恶的城，已经完成城墙，并修好了根基。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 7:24; 罗马书 13:6–7; 尼希米记 5:4"> 现在愿王知道，若这城建成，城墙完工，他们就不会缴纳贡银、关税和地税，终必使诸王受损。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 19:12–15; 以西结 33:31; 约翰福音 12:5–6"> 如今我们既然食王宫之盐，不宜坐视王受辱，所以我们派人报告王，</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 4:12; 以斯帖记 3:5–8; 列王纪下 24:20–1"> 请王查考您列祖的史册。您必在史册中看见，也知道这城是悖逆之城，损害诸王和各省；他们从古以来就在其中发动叛乱。因此这城才被毁灭。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 4:20; 列王纪上 4:24; 撒母耳记下 8:3"> 我们报告王：若这城建成，城墙完工，那么大河西之地就不再归您所有了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:7; 以斯拉记 5:7; 以斯拉记 4:9–11"> 王就给省长利宏、书记伸帅，以及他们住在撒玛利亚和大河西其余地区的同伴回信：<br />愿你们平安。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="尼希米记 8:8"> 你们送给我们的信，已经清楚地在我面前读过了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 18:7; 箴言 25:2; 申命记 13:14"> 我已下令查考，查明这城从古以来常背叛列王，其中曾发生叛逆和动乱。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 15:18; 列王纪上 4:21; 历代志上 18:3"> 耶路撒冷也曾有强大的君王，统治大河西全境；贡银、关税和地税也都缴给他们。</span>
<span className="v" id="v21" data-v="21"> 现在你们要下令，使这些人停工；这城不可建造，直到我再下命令。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 7:3–4; 以斯帖记 3:8–9; 以斯拉记 4:13"> 你们要谨慎，不可怠慢。为何让损害加重，使列王受亏损呢？</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="罗马书 3:15; 弥迦书 2:1; 以斯拉记 4:17"> 亚达薛西王的信件副本在利宏、书记伸帅和他们的同伴面前读过之后，他们就急忙到耶路撒冷去见犹太人，用武力迫使他们停工。</span>
<span className="v" id="v24" data-v="24" data-xref="哈该书 1:15; 尼希米记 6:9; 以斯拉记 5:5"> 于是耶路撒冷上帝殿的工程停止了，直到波斯王大流士执政第二年才停止。</span>
</div>
</div>

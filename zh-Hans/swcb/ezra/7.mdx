<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:1; 历代志上 6:4–14; 以斯拉记 7:21"> 这些事以后，在波斯王亚达薛西执政的时候，有以斯拉，他是西莱雅的儿子，西莱雅是亚撒利雅的儿子，亚撒利雅是希勒家的儿子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 2:35; 撒母耳记下 8:17"> 希勒家是沙龙的儿子，沙龙是撒督的儿子，撒督是亚希突的儿子，</span>
<span className="v" id="v3" data-v="3"> 亚希突是亚玛利雅的儿子，亚玛利雅是亚撒利雅的儿子，亚撒利雅是米拉约的儿子，</span>
<span className="v" id="v4" data-v="4"> 米拉约是西拉希雅的儿子，西拉希雅是乌西的儿子，乌西是布基的儿子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 6:25; 历代志下 26:20; 历代志上 6:4"> 布基是亚比书的儿子，亚比书是非尼哈的儿子，非尼哈是以利亚撒的儿子，以利亚撒是大祭司亚伦的儿子——</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 8:22; 以斯拉记 7:28; 以斯拉记 8:31"> 这以斯拉从巴比伦上来。他是通达摩西律法的文士，这律法是耶和华以色列的上帝所赐的；王允准他一切所求的，因为耶和华他上帝的手帮助他。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 8:1–20; 历代志上 6:31–48; 历代志上 9:17–27"> 亚达薛西王第七年，有些以色列子孙，以及一些祭司、利未人、歌唱的人、守门的人和殿役，都上耶路撒冷去。</span>
<span className="v" id="v8" data-v="8"> 王第七年五月，以斯拉来到耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 7:6; 尼希米记 2:8; 尼希米记 2:18"> 他在正月初一日开始从巴比伦上来；到五月初一日，他来到耶路撒冷，因为他的上帝施恩的手帮助他。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 2:7; 提摩太后书 4:2; 马太福音 7:24"> 因为以斯拉立定心志，要寻求耶和华的律法，遵行这律法，并在以色列中教导律例和典章。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 5:6; 以斯拉记 7:6; 马太福音 23:2"> 以下是亚达薛西王赐给祭司以斯拉这位文士的信件副本；他是通晓耶和华诫命的话语和赐给以色列之律例的文士：</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理 2:37; 以西结 26:7; 以斯拉记 4:17"> 万王之王亚达薛西，<br />致祭司以斯拉，通达天上完美上帝律法的文士。<br />如今，</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:1; 诗篇 148:6; 历代志下 30:5"> 我下令：在我国境内，凡以色列百姓和他们的祭司、利未人，愿意甘心去耶路撒冷的，都可以与你同去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 1:14; 以斯拉记 7:25–26; 以斯拉记 7:28"> 因为你奉王和七位谋士之命，照你手中你上帝的律法，去查问犹大和耶路撒冷的情况，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 135:21; 历代志下 6:2; 以斯拉记 6:12"> 并带去王和谋士甘心献给以色列上帝的金银；祂的居所是在耶路撒冷。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:6; 以斯拉记 1:4; 历代志上 29:9"> 你也要带上你在巴比伦全省所能得到的一切金银，以及百姓和祭司甘心献给他们上帝在耶路撒冷之殿的礼物。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 12:5–11; 民数记 15:4–13; 以斯拉记 6:9–10"> 所以，你要用这银钱速速买公牛、公绵羊、羔羊，以及同献的素祭和奠祭，献在耶路撒冷你上帝殿的祭坛上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 22:7; 以弗所书 5:17; 列王纪下 12:15"> 至于其余的金银，你和你的弟兄看怎样好，就可照你们上帝的旨意去做。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:17; 以斯拉记 8:33–34; 历代志下 32:19"> 交给你作你上帝殿中服侍之用的器皿，你要交在耶路撒冷的上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 6:4; 以斯拉记 6:8–18"> 你上帝殿中若还需要什么，凡你有机会供给的，都可以从王的宝库中支取。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:16; 以斯拉记 7:6; 以斯拉记 7:10–13"> 我，我亚达薛西王，又向大河西一切司库下令：凡祭司以斯拉，就是天上上帝律法的文士，向你们所要求的，都要速速办理，</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未记 2:13; 以西结 45:14"> 银子最多可达一百他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约30公斤。">a</a></sup>，小麦一百歌珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一歌珥约211升。">b</a></sup>，酒一百罢特<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一罢特约21升；一百罢特约为2100升。">c</a></sup>，油一百罢特，盐则不定数量。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:4; 以斯拉记 7:18; 以斯拉记 6:10–12"> 凡天上上帝所吩咐的，都要为天上上帝的殿准确办理；为何让愤怒临到王和王众子的国呢？</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 7:7; 以斯拉记 4:13; 以斯拉记 2:36–55"> 我们也通知你们：对于这上帝殿的祭司、利未人、歌唱的人、守门的人、殿役或工人，不可向他们征收贡银、关税或地税。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 7:10; 申命记 16:18; 雅各书 1:5"> 以斯拉啊，你要照你手中你上帝所赐的智慧，委任审判官和士师，审判大河西所有明白你上帝律法的百姓；不明白的人，你们要教导他。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 6:11; 申命记 13:1–18; 利未记 20:1–27"> 凡不遵行你上帝律法和王法的人，都要速速执行判决：或处死，或流放，或没收财产，或囚禁。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 6:22; 启示录 17:17; 以赛亚书 60:13"> 耶和华我们列祖的上帝是有福的，祂把这样的心意放在王心里，要使耶路撒冷耶和华的殿得荣耀；</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 4:17–18; 以斯拉记 5:5; 创世记 32:28"> 又在王和他的谋士，以及王所有大能的首领面前向我施展慈爱。我因耶和华我上帝的手帮助我，就得了坚固，并从以色列中聚集首领，与我一同上来。</span>
</div>
</div>

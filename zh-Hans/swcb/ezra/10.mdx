<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 9:20; 诗篇 119:136; 罗马书 9:2"> 以斯拉祷告、认罪、哭泣，并俯伏在上帝殿前的时候，以色列中有一大群男女和孩子聚集到他那里；众人都痛哭不止。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 13:27; 以斯拉记 9:2; 耶利米书 3:12–13"> 以拦子孙中，耶歇的儿子示迦尼回答以斯拉说：“我们得罪了我们的上帝，娶了这地各民族中的外邦女子为妻；然而在这事上，以色列仍有盼望。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:2–3; 以斯拉记 9:4; 约书亚记 23:12–13"> 现在，就让我们与我们的上帝立约，照我主和那些因我们上帝诫命而战兢之人的劝告，休掉所有这些妻子和她们所生的儿女；愿这事照律法而行。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:10; 传道书 9:10; 希伯来书 12:12–13"> 起来吧，因为这事归你处理；我们也与你同在。你当刚强，去行吧。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米记 13:25; 尼希米记 5:12; 箴言 9:9"> 于是以斯拉起来，使祭司长、利未人和以色列众人起誓，要照这话去行；他们就起了誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 9:18; 尼希米记 3:1; 尼希米记 12:22"> 以斯拉从上帝殿前起来，进入以利亚实的儿子约哈难的房间。他到了那里，不吃饭，也不喝水，因为他为被掳归回之人的罪忧伤。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 1:1; 历代志下 30:5"> 他们在犹大和耶路撒冷通告所有被掳归回的人，要他们聚集到耶路撒冷；</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:26; 约翰福音 9:22; 士师记 21:5"> 凡不照首领和长老的劝告，在三日之内来到的，他一切财产都要被没收，他本人也要从被掳归回之人的会众中被隔离。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 12:17–18; 耶利米书 10:13; 以斯拉记 7:8–9"> 于是犹大和便雅悯众人三日之内都聚集到耶路撒冷。那是九月二十日；众人因这事，又因大雨，都坐在上帝殿前的广场上战兢。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 9:6; 民数记 32:14; 马太福音 23:32"> 祭司以斯拉站起来，对他们说：“你们犯了罪，娶了外邦女子，增添了以色列的罪责。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 12:2; 以斯拉记 10:3; 以赛亚书 1:16–18"> 现在，你们要向耶和华你们列祖的上帝认罪，遵行祂的旨意，与这地的民族和外邦女子分别出来。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米记 13:23; 诗篇 78:57; 以斯拉记 10:3–4"> 全会众就大声回答说：“你怎样吩咐我们，我们必须照样去行。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:18–44; 马太福音 7:13–14"> 只是百姓众多，又正逢大雨季节，我们不能站在外面；这事也不是一天两天能办完的，因为我们在这事上大大犯罪。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:10; 历代志下 30:8; 民数记 25:4"> 现在，请为全会众设立我们的首领；凡我们各城中娶了外邦女子的人，都要按指定的时候前来，并有各城的长老和士师同来，直到我们上帝因这事而发的烈怒离开我们。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 11:16; 尼希米记 10:20; 尼希米记 12:33"> 只有亚撒黑的儿子约拿单和特瓦的儿子雅哈谢起来反对这事；米书兰和利未人沙比太帮助他们。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约伯记 29:16; 申命记 13:14; 约翰福音 7:51"> 被掳归回的人就这样行。祭司以斯拉和一些族长，按着他们的宗族，都一一按名被分别出来；他们在十月初一日坐下查办这事。</span>
<span className="v" id="v17" data-v="17"> 到正月初一日，他们查完了所有娶外邦女子的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 5:2; 以斯拉记 3:2; 撒迦利亚书 3:1"> 在祭司的子孙中，查出有娶外邦女子的： 属约萨达的儿子耶书亚和他弟兄的子孙，有玛西雅、以利以谢、雅立和基大利。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 6:6; 列王纪下 10:15; 历代志下 30:8"> 他们伸手起誓，承诺要休掉自己的妻子；他们因有罪，就从羊群中献一只公绵羊作赎愆祭。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:37; 历代志上 24:14; 尼希米记 7:40"> 属音麦的子孙，有哈拿尼和西巴第雅。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 24:8; 以斯拉记 2:39; 尼希米记 7:42"> 属哈琳的子孙，有玛西雅、以利雅、示玛雅、耶歇和乌西雅。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 9:12; 尼希米记 7:41; 以斯拉记 2:38"> 属巴施户珥的子孙，有以利约乃、玛西雅、以实玛利、拿坦业、约撒拔和以利亚撒。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:10; 尼希米记 11:16; 以斯拉记 8:33"> 利未人中，有约撒拔、示每、基拉雅（又名基利他）、毗他希雅、犹大和以利以谢。</span>
<span className="v" id="v24" data-v="24"> 歌唱的人中，有以利亚实。 守门的人中，有沙龙、提联和乌利。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 2:3; 尼希米记 7:8"> 以色列人中：属巴录的子孙，有拉米、耶西雅、玛基雅、米雅民、以利亚撒、玛基雅和比拿雅。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 10:2; 以斯拉记 2:31; 尼希米记 7:12"> 属以拦的子孙，有玛他尼、撒迦利亚、耶歇、押底、耶利末和以利雅。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 7:13; 以斯拉记 2:8"> 属萨土的子孙，有以利约乃、以利亚实、玛他尼、耶利末、撒拔和亚西撒。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯拉记 8:11; 以斯拉记 2:11; 尼希米记 7:16"> 属比拜的子孙，有约哈难、哈拿尼雅、萨拜和亚勒。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 7:15; 尼希米记 10:4; 以斯拉记 2:10"> 属巴尼的子孙，有米书兰、玛鹿、亚大雅、雅述、示押和耶利末。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:4; 尼希米记 7:11; 以斯拉记 2:6"> 属巴哈摩押的子孙，有阿底拿、基拉、比拿雅、玛西雅、玛他尼、比撒列、宾内和玛拿西。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:11; 尼希米记 7:35; 以斯拉记 2:32"> 属哈琳的子孙，有以利以谢、伊示雅、玛基雅、示玛雅、西缅、</span>
<span className="v" id="v32" data-v="32"> 便雅悯、玛鹿和示玛利雅。</span>
<span className="v" id="v33" data-v="33" data-xref="以斯拉记 2:19; 尼希米记 7:22"> 属哈顺的子孙，有玛特乃、玛达他、撒拔、以利法列、耶利买、玛拿西和示每。</span>
<span className="v" id="v34" data-v="34"> 属巴尼的子孙，有玛玳、暗兰、乌益、</span>
<span className="v" id="v35" data-v="35"> 比拿雅、比底雅、基禄希、</span>
<span className="v" id="v36" data-v="36"> 瓦尼雅、米利末、以利亚实、</span>
<span className="v" id="v37" data-v="37"> 玛他尼、玛特乃、雅扫、</span>
<span className="v" id="v38" data-v="38"> 巴尼、宾内、示每、</span>
<span className="v" id="v39" data-v="39"> 示利米雅、拿单、亚大雅、</span>
<span className="v" id="v40" data-v="40"> 玛拿底拜、沙赛、沙赖、</span>
<span className="v" id="v41" data-v="41"> 亚萨利、示利米雅、示玛利雅、</span>
<span className="v" id="v42" data-v="42"> 沙龙、亚玛利雅和约瑟。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 2:29; 尼希米记 7:33"> 属尼波的子孙，有耶利、玛他提雅、撒拔、西比拿、易多、约珥和比拿雅。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; 以斯拉记 10:3; 箴言 2:16"> 这些人全都娶了外邦女子为妻，其中有些妻子已经生了儿女。</span>
</div>

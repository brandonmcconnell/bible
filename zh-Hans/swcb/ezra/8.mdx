<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:7; 以斯拉记 2:62; 历代志上 9:1"> 亚达薛西王执政的时候，从巴比伦同我上来的人，他们的族长和家谱如下：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:22; 历代志上 3:1; 历代志上 6:3–15"> 属非尼哈的子孙，有革顺。 属以他玛的子孙，有但以理。 属大卫的子孙，有哈突。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:3; 尼希米记 10:14; 尼希米记 7:8"> 属示迦尼的子孙，又属巴录的子孙，有撒迦利亚；同他一起按家谱登记的男丁有一百五十名。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 2:6; 尼希米记 10:14; 尼希米记 7:11"> 属巴哈摩押的子孙，有西拉希雅的儿子以利约乃；同他一起的男丁有二百名。</span>
<span className="v" id="v5" data-v="5"> 属示迦尼的子孙，有雅哈悉的儿子；同他一起的男丁有三百名。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 2:15; 尼希米记 10:16; 尼希米记 7:20"> 属亚丁的子孙，有约拿单的儿子以别；同他一起的男丁有五十名。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:31; 尼希米记 7:34; 以斯拉记 2:7"> 属以拦的子孙，有亚他利雅的儿子耶筛亚；同他一起的男丁有七十名。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 11:4; 以斯拉记 2:4; 尼希米记 7:9"> 属示法提雅的子孙，有米迦勒的儿子西巴第雅；同他一起的男丁有八十名。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 7:11; 以斯拉记 2:6"> 属约押的子孙，有耶歇的儿子俄巴底亚；同他一起的男丁有二百一十八名。</span>
<span className="v" id="v10" data-v="10"> 属示罗密的子孙，有约细斐的儿子；同他一起的男丁有一百六十名。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 10:28; 尼希米记 7:16; 以斯拉记 2:11"> 属比拜的子孙，有比拜的儿子撒迦利亚；同他一起的男丁有二十八名。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:12; 尼希米记 7:17"> 属押甲的子孙，有哈加坦的儿子约哈难；同他一起的男丁有一百一十名。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 2:13; 尼希米记 7:18"> 属亚多尼干的子孙，就是末后来的，他们的名字是以利法列、耶利、示玛雅；同他们一起的男丁有六十名。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 10:12; 以斯拉记 2:14; 尼希米记 7:19"> 属比革瓦伊的子孙，有乌太和撒布；同他们一起的男丁有七十名。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 8:21; 以斯拉记 8:31; 以斯拉记 7:7"> 我把他们聚集到流向亚哈瓦的河边；我们在那里扎营三天。我查看百姓和祭司，却发现那里没有利未的子孙。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉记 8:18; 以斯拉记 10:39"> 于是我派人去请以利以谢、亚列、示玛雅、以利拿单、雅立、以利拿单、拿单、撒迦利亚和米书兰这些首领，又请约雅立和以利拿单这两位教师。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:43; 出埃及记 4:15; 民数记 8:22–26"> 我派他们到迦西斐雅地方去见首领易多，并吩咐他们对易多和他在迦西斐雅地方的弟兄，就是殿役，说什么，好让他们为我们上帝的殿带来服侍的人。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:15; 以斯拉记 7:28; 尼希米记 2:8"> 因我们上帝施恩的手帮助我们，他们带给我们一个有见识的人，是以色列的儿子利未的后裔、抹利的子孙，名叫示利比；同他来的还有他的儿子和弟兄，共十八人；</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 6:1; 历代志上 6:16; 尼希米记 10:11"> 又有哈沙比雅，同他来的还有米拉利子孙中的耶筛亚，以及他的弟兄和他们的儿子，共二十人；</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:43; 以斯拉记 7:7; 历代志上 9:2"> 还有殿役二百二十人；他们是大卫和众首领为服侍利未人而设立的殿役。所有这些人都按名指定。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:3; 约珥 1:14; 撒母耳记上 7:6"> 那时，我在亚哈瓦河边宣告禁食，要我们在上帝面前谦卑，向祂寻求一条平坦的路，使我们和我们的孩子，以及一切财物都平安。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 3:12; 诗篇 33:18–19; 历代志下 16:9"> 因为我曾对王说：“我们上帝的手必施恩帮助一切寻求祂的人；但祂的能力和烈怒必攻击一切离弃祂的人。”所以我不好意思向王求步兵和骑兵，帮助我们抵挡路上的敌人。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 29:12–13; 马太福音 7:7–8; 以斯拉记 8:31"> 因此，我们为这事禁食，恳求我们的上帝，祂就应允了我们的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 8:18–19"> 我又从祭司长中分别出十二人，就是示利比、哈沙比雅和他们的弟兄十人，</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 8:33; 以斯拉记 7:14–16; 以斯拉记 1:8"> 把银子、金子和器皿，就是王、他的谋士、他的首领，以及在那里所有以色列人，为我们上帝的殿所献的礼物，都称了交给他们。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 1:9–11"> 我称了交到他们手中的，有银子六百五十他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约30公斤。">a</a></sup>，银器一百他连得，金子一百他连得，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 金碗二十个，重一千达利克<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="达利克是波斯王发行的金币，约重8.4克。">b</a></sup>，又有两个光亮精铜器皿，贵重如金。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 22:2–3; 利未记 21:6–8; 历代志上 23:28"> 我对他们说：“你们归耶和华为圣，这些器皿也为圣；银子和金子是甘心献给耶和华你们列祖上帝的礼物。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉记 8:33–34; 马可福音 13:34–35; 历代志上 26:20–26"> 你们要谨慎看守，直到在耶路撒冷耶和华殿的房间里，在祭司长、利未人和以色列各族首领面前称量交清。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:22; 历代志上 29:2–3; 以赛亚书 60:13"> 于是祭司和利未人接收了所称的银子、金子和器皿，要带到耶路撒冷我们上帝的殿。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉记 8:21–22; 以斯拉记 7:9; 以斯拉记 8:15"> 正月十二日，我们从亚哈瓦河边起行，前往耶路撒冷。我们上帝的手帮助我们，祂救我们脱离了路上敌人和埋伏之人的手。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 2:11; 以斯拉记 7:8–9"> 我们到了耶路撒冷，在那里停留三天。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 3:4; 尼希米记 3:21; 以斯拉记 8:30"> 第四天，银子、金子和器皿都在我们上帝的殿中称量，交到祭司乌利亚的儿子米利末手里；同他在一起的有非尼哈的儿子以利亚撒，还有利未人耶书亚的儿子约撒拔和宾内的儿子挪亚底。</span>
<span className="v" id="v34" data-v="34"> 一切都按数目、按重量交清；当时全部重量都记录下来。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以斯拉记 6:17; 历代志下 29:31–32; 诗篇 66:10–15"> 从被掳之地归回的人，就是被掳归回的子民，向以色列的上帝献燔祭：为全以色列献公牛十二头、公绵羊九十六只、羔羊七十七只，又献公山羊十二只作赎罪祭；这一切都是献给耶和华的燔祭。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉记 7:21–24; 以斯拉记 4:7–23; 以斯拉记 6:13"> 他们把王的谕令交给王的总督和大河西的省长；他们就支持百姓和上帝的殿。</span>
</div>
</div>

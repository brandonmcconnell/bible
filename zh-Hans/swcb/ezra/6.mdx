<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 5:17; 箴言 25:2; 以斯拉记 4:15"> 于是大流士王下令，人就在巴比伦收藏宝物的档案库中查考。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 17:6"> 后来在玛代省亚马他城的宫中发现一卷书，其中有这样的记录：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 36:22–4; 启示录 21:16; 以西结 41:13–15"> 古列王元年，古列王下令：关于在耶路撒冷的上帝殿，要让这殿重建，作为献祭的地方；根基要坚固地立定，高六十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘约为男子从肘部到中指尖的长度，约46厘米。">a</a></sup>，宽六十肘；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 6:36; 诗篇 68:29; 以赛亚书 49:23"> 用三层巨石，一层新木料；费用要由王室支付。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理 5:2; 以斯拉记 5:14; 历代志下 36:6–7"> 还有上帝殿中的金银器皿，就是尼布甲尼撒从耶路撒冷的殿中取出、带到巴比伦的，要归还，重新带到耶路撒冷的殿中，各归原处；你要把它们安放在上帝的殿里。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 5:3; 罗马书 8:31; 箴言 21:30"> 现在，河西总督达乃、示他·波斯乃，以及你们河西的同伴亚法萨迦人，你们要远离那里。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:38–39"> 不要干涉这上帝殿的工程；要让犹太人的省长和犹太人的长老在原址建造这上帝的殿。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 6:4; 哈该书 2:8; 以斯拉记 7:15–22"> 我又下令，关于你们应当为这些犹太长老建造这上帝殿所做的事：要从王的财物，就是大河西的贡银中，迅速拨出费用给这些人，使他们不受阻碍。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 1:10; 诗篇 50:9–13; 马可福音 9:49"> 他们所需要的，包括献给天上上帝作燔祭的公牛犊、公绵羊和羔羊，以及小麦、盐、酒和油，都要照耶路撒冷祭司的话，天天供给，不可有误，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 29:7; 以斯拉记 7:23; 提摩太前书 2:1–2"> 好使他们献馨香的祭给天上的上帝，并为王和王众子的性命祷告。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 3:29; 以斯拉记 7:26; 但以理 2:5"> 我也下令：凡更改这命令的，必从他房屋中抽出一根梁木，把他举起钉在其上；他的房屋也要因此成为粪堆。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 9:3; 申命记 12:5; 申命记 12:11"> 愿那使祂名居住在那里的上帝，倾覆一切伸手更改这命令、要毁坏耶路撒冷这上帝殿的君王和民族。我大流士已经下令，务要速速执行。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 4:9; 以斯拉记 6:6; 约伯记 5:12–13"> 于是大河西总督达乃、示他·波斯乃和他们的同伴，因为大流士王所发的命令，就迅速照办。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以斯拉记 7:1; 以斯拉记 5:13; 以斯拉记 4:24–2"> 犹太人的长老因先知哈该和易多的儿子撒迦利亚所说的预言，就建造并顺利进行。他们照以色列上帝的命令，并照波斯王古列、大流士和亚达薛西的谕旨，建造完成。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 3:7; 以斯帖记 9:21; 以斯帖记 9:1"> 这殿在亚达月初三日完成，正是大流士王执政第六年。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 7:5; 列王纪上 8:63; 约翰福音 10:22"> 以色列子孙、祭司、利未人和其余被掳归回的人，都欢欢喜喜地举行这上帝殿的奉献礼。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 8:35; 启示录 7:4–8; 历代志下 29:21–23"> 他们为这上帝殿的奉献礼献上公牛一百头、公绵羊二百只、羔羊四百只；又照以色列支派的数目，为全以色列献十二只公山羊作赎罪祭。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 3:6; 历代志上 24:1; 历代志下 35:4–5"> 他们又照摩西书上所写的，安排祭司按班次、利未人按班组，在耶路撒冷服侍上帝。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:6–36; 历代志下 30:1–27; 约书亚记 5:10"> 被掳归回的人在正月十四日守逾越节。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 35:11; 希伯来书 7:27; 历代志下 29:34"> 因为祭司和利未人一同洁净自己，他们全都洁净了；他们为所有被掳归回的人，为他们的弟兄众祭司，也为自己宰了逾越节的羊羔。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 9:11; 哥林多后书 7:1; 以赛亚书 52:11"> 从被掳之地归回的以色列子孙，以及一切脱离当地列国污秽、归附他们，为要寻求耶和华以色列上帝的人，都吃了，</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 1:1; 历代志下 30:21; 箴言 21:1"> 又欢欢喜喜地守除酵节七天；因为耶和华使他们喜乐，又使亚述王的心转向他们，坚固他们的手，帮助他们建造上帝——以色列上帝的殿。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 11:10; 诗篇 2:1–4; 士师记 4:2"> 夏琐王耶宾听见这事，就派人去见玛顿王约巴、伸仑王、押煞王，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 12:3; 士师记 1:27; 约书亚记 17:11"> 又去见北方山地、基尼烈以南的亚拉巴、低地，以及西边多珥高地的诸王，</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:3; 约书亚记 18:26; 创世记 31:49"> 也去见东边和西边的迦南人、亚摩利人、赫人、比利洗人、山地的耶布斯人，以及黑门山下米斯巴地的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 7:12; 撒母耳记上 13:5; 创世记 32:12"> 他们和他们所有的军队一同出来，人数众多，多如海边的沙；又有极多的马匹和战车。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:10–12; 启示录 16:14; 以赛亚书 8:9"> 这些王都聚集起来，来到米伦水边一同安营，要与以色列争战。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 10:8; 撒母耳记下 8:4; 士师记 20:28"> 耶和华对约书亚说：“不要因他们惧怕；因为明天这个时候，我必把他们全都交在以色列面前，使他们被杀。你要砍断他们马的蹄筋，用火焚烧他们的战车。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:9; 帖撒罗尼迦前书 5:2–3"> 于是约书亚和所有战士来到米伦水边，突然攻击他们。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:6; 约书亚记 19:28; 撒迦利亚书 9:2"> 耶和华把他们交在以色列手中，以色列人击杀他们，追赶他们，直到西顿大城，直到米斯利弗·玛音，又向东直到米斯巴谷。他们击杀他们，直到没有留下一个存活的人。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 11:6; 以西结 39:9–10"> 约书亚照耶和华吩咐他的去做，砍断他们马的蹄筋，用火焚烧他们的战车。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 11:1; 士师记 4:2"> 那时，约书亚转回，攻取夏琐，用刀击杀它的王；因为夏琐从前是这些王国的首领。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 10:40; 申命记 20:16"> 他们用刀刃击杀城中所有的人，将他们尽行毁灭。凡有气息的，一个也没有留下。约书亚又用火焚烧夏琐。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 20:16–17; 申命记 7:2; 民数记 33:50–53"> 约书亚夺取那些王的一切城邑和其中的王，用刀刃击杀他们，将他们尽行毁灭，正如耶和华的仆人摩西所吩咐的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 30:18"> 至于那些建在土丘上的城，除了夏琐以外，以色列没有焚烧其中任何一座；只有夏琐，约书亚把它焚烧了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 20:14; 民数记 31:9; 约书亚记 8:27"> 这些城邑一切的掠物和牲畜，以色列人都取为自己的战利品；但所有人，他们都用刀刃击杀，直到把他们灭尽。凡有气息的，他们一个也没有留下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:7; 出埃及记 34:11–13; 使徒行传 20:20"> 耶和华怎样吩咐祂的仆人摩西，摩西也怎样吩咐约书亚；约书亚就照样做了。凡耶和华吩咐摩西的，约书亚没有一件不做的。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 10:41; 约书亚记 11:21; 约书亚记 12:8"> 这样，约书亚夺取了那全地，就是山地、整个南地、歌珊全地、低地、亚拉巴、以色列的山地和其低地，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 7:24; 约书亚记 11:3; 约书亚记 13:5"> 从上西珥去的哈拉山，直到黑门山下黎巴嫩谷的巴力·迦得。他擒获他们所有的王，击杀他们，把他们处死。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 14:7–10; 约书亚记 11:23"> 约书亚与那些王争战了很长时间。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 9:3–27"> 除了住基遍的希未人以外，没有一座城与以色列人讲和；以色列人都是在战斗中夺取的。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:18; 申命记 20:16–17; 出埃及记 4:21"> 因为使他们的心刚硬，来与以色列争战，是出于耶和华，好将他们尽行毁灭，使他们得不到恩待，而是把他们毁灭，正如耶和华吩咐摩西的。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 9:2; 民数记 13:22–23; 约书亚记 15:13–14"> 那时，约书亚来到，从山地、从希伯仑、从底璧、从亚拿伯、从犹大全山地，以及从以色列全山地剪除了亚衲人。约书亚把他们连同他们的城邑尽行毁灭。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 17:4; 历代志上 18:1; 约书亚记 15:46"> 在以色列人的地，亚衲人一个也没有留下；只有在迦萨、迦特和亚实突，还有一些存留。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 21:44–45; 民数记 26:52–55; 约书亚记 14:1–15"> 这样，约书亚照耶和华对摩西所说的一切，夺取了全地；约书亚按着以色列各支派的分队，把地给他们作产业。于是那地从战争中得了安息。</span>
</div>

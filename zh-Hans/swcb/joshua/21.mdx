<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:1; 约书亚记 19:51; 约书亚记 17:4"> 利未人父家的首领近前来，到以利亚撒祭司、嫩的儿子约书亚，以及以色列子孙各支派父家的首领那里。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:1; 民数记 35:2–8; 马太福音 10:10"> 他们在迦南地的示罗对他们说：“耶和华曾借着摩西吩咐，要给我们城邑居住，也要给我们城邑周围的牧场，供我们的牲畜使用。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 49:7; 申命记 33:8–10; 历代志上 6:54–81"> 于是以色列子孙照耶和华的命令，从自己的产业中把以下这些城邑和城邑周围的牧场给了利未人。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 6:54–60; 约书亚记 24:33; 约书亚记 21:8–19"> 拈阄的结果落在哥辖人的各家族。利未人中亚伦祭司的子孙，从犹大支派、西缅人支派和便雅悯支派，拈阄得了十三座城。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 21:20–26; 出埃及记 6:16–25; 历代志上 6:66–70"> 哥辖其余的子孙，从以法莲支派的各家族、但支派和玛拿西半支派，拈阄得了十座城。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:27–33; 历代志上 6:71–76; 出埃及记 6:16–17"> 革顺的子孙，从以萨迦支派的各家族、亚设支派、拿弗他利支派和巴珊的玛拿西半支派，拈阄得了十三座城。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:34–40; 历代志上 6:77–81; 出埃及记 6:19"> 米拉利的子孙按着他们的各家族，从吕便支派、迦得支派和西布伦支派，得了十二座城。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 21:3; 约书亚记 18:6; 民数记 33:54"> 以色列子孙照耶和华借摩西所吩咐的，把这些城邑和城邑周围的牧场拈阄给了利未人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 6:65; 约书亚记 21:13–18"> 他们从犹大子孙支派和西缅子孙支派，给了以下这些按名列出的城邑：</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 21:4; 民数记 3:27; 出埃及记 6:20–26"> 这些城归给亚伦的子孙，就是利未子孙中哥辖人的各家族；因为第一阄是他们的。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 6:55; 路加福音 1:39; 撒母耳记下 5:1–5"> 他们把以亚衲的祖先亚巴命名的基列·亚巴（又叫希伯仑），就是犹大山区的一座城，连同城周围的牧场，给了他们。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 14:13–15; 历代志上 6:55–57"> 但他们把那城的田地和所属的村庄，给了耶孚尼的儿子迦勒作他的产业。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:42; 约书亚记 10:29; 约书亚记 15:54"> 他们给了亚伦祭司的子孙希伯仑和城周围的牧场，就是误杀人的逃城；又给了立拿和城周围的牧场，</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:48; 约书亚记 15:50; 撒母耳记上 30:27–28"> 雅提珥和城周围的牧场，以实提莫和城周围的牧场，</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:49; 约书亚记 15:51; 约书亚记 12:13"> 何仑和城周围的牧场，底璧和城周围的牧场，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 15:10; 历代志上 6:59; 约书亚记 15:55"> 亚因和城周围的牧场，淤他和城周围的牧场，以及伯·示麦和城周围的牧场；从这两个支派中，共九座城。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 18:24–25; 约书亚记 9:3; 历代志上 6:60"> 从便雅悯支派，给了基遍和城周围的牧场，迦巴和城周围的牧场，</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 10:30; 历代志上 6:60; 耶利米书 1:1"> 亚拿突和城周围的牧场，以及亚勒们和城周围的牧场；共四座城。</span>
<span className="v" id="v19" data-v="19"> 亚伦子孙这些祭司的城邑，共十三座城，连同城周围的牧场。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 6:66; 约书亚记 21:5"> 哥辖子孙的各家族，就是利未人中哥辖其余的子孙，从以法莲支派得了他们拈阄所得的城。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 20:7; 士师记 9:1; 列王纪上 12:1"> 他们给了他们以法莲山区的示剑和城周围的牧场，就是误杀人的逃城；又给了基色和城周围的牧场，</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 6:68; 约书亚记 16:3; 约书亚记 18:13–14"> 基伯先和城周围的牧场，以及伯·和仑和城周围的牧场；共四座城。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 19:44–45"> 从但支派，给了伊利提基和城周围的牧场，基比顿和城周围的牧场，</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:42; 约书亚记 10:12; 历代志上 6:69"> 亚雅仑和城周围的牧场，迦特·临门和城周围的牧场；共四座城。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 17:11; 士师记 5:19"> 从玛拿西半支派，给了他纳和城周围的牧场，以及迦特·临门和城周围的牧场；共两座城。</span>
<span className="v" id="v26" data-v="26"> 哥辖其余子孙的各家族所得的城，共十座，连同城周围的牧场。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 6:71; 申命记 1:4; 约书亚记 20:8"> 他们给了利未人各家族中革顺的子孙，从玛拿西半支派中给了巴珊的哥兰和城周围的牧场，就是误杀人的逃城；又给了比·施提拉和城周围的牧场；共两座城。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:12; 历代志上 6:72–73"> 从以萨迦支派，给了基善和城周围的牧场，大比拉和城周围的牧场，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:23; 约书亚记 12:11; 约书亚记 10:3"> 耶末和城周围的牧场，隐·干宁和城周围的牧场；共四座城。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 6:74–75; 约书亚记 19:25–28"> 从亚设支派，给了米沙勒和城周围的牧场，押顿和城周围的牧场，</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 18:21; 历代志上 6:75; 士师记 1:31"> 黑甲和城周围的牧场，以及利合和城周围的牧场；共四座城。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 6:76; 约书亚记 20:7; 约书亚记 19:37"> 从拿弗他利支派，给了加利利的基低斯和城周围的牧场，就是误杀人的逃城；又给了哈末·多珥和城周围的牧场，以及加珥坦和城周围的牧场；共三座城。</span>
<span className="v" id="v33" data-v="33"> 革顺人按着他们各家族所得的城，共十三座城，连同城周围的牧场。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="历代志上 6:77; 约书亚记 19:11; 约书亚记 21:7"> 至于米拉利子孙的各家族，就是其余的利未人，从西布伦支派给了约念和城周围的牧场，加珥他和城周围的牧场，</span>
<span className="v" id="v35" data-v="35"> 丁拿和城周围的牧场，以及拿哈拉和城周围的牧场；共四座城。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 20:8; 申命记 4:43; 民数记 21:23"> 从吕便支派，给了比悉和城周围的牧场，雅杂和城周围的牧场，</span>
<span className="v" id="v37" data-v="37"> 基底莫和城周围的牧场，以及米法押和城周围的牧场；共四座城。</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 32:2; 列王纪上 22:3; 历代志上 6:80"> 从迦得支派，给了基列的拉末和城周围的牧场，就是误杀人的逃城；又给了玛哈念和城周围的牧场，</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 16:8–9; 民数记 32:35; 民数记 32:1"> 希实本和城周围的牧场，雅谢和城周围的牧场；总共四座城。</span>
<span className="v" id="v40" data-v="40"> 这些都是米拉利子孙按着他们各家族所得的城，就是利未人其余各家族所得的城。他们拈阄所得的共十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:1–8; 申命记 33:10; 创世记 49:7"> 利未人在以色列子孙的产业中所得的城，共四十八座城，连同城周围的牧场。</span>
<span className="v" id="v42" data-v="42"> 这些城各有周围的牧场；这些城全都是这样。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="创世记 13:15; 诗篇 106:42–45; 出埃及记 23:27–31"> 这样，耶和华把祂起誓要赐给他们列祖的全地都赐给了以色列。他们就得了那地为业，并住在其中。</span>
<span className="v" id="v44" data-v="44" data-xref="约书亚记 11:23; 希伯来书 4:9; 申命记 31:3–5"> 耶和华照祂向他们列祖所起的一切誓，使他们四境安宁。他们一切仇敌中没有一人能在他们面前站立得住；耶和华把他们所有的仇敌都交在他们手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 8:56; 约书亚记 23:14–15; 民数记 23:19"> 耶和华对以色列家所说一切美好的话，没有一句落空，全都应验了。</span>
</div>

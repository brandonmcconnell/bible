<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 1:9; 申命记 7:18; 申命记 1:21"> 耶和华对约书亚说：“不要惧怕，也不要惊惶。你要带着所有战士，起来，上艾城去。看哪，我已经把艾城的王和他的百姓、他的城、他的地都交在你手里。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 20:14; 约书亚记 6:21; 历代志下 20:22"> 你怎样待耶利哥和它的王，也要照样待艾城和它的王；只是城中的财物和牲畜，你们可以为自己取去。你要在城后设下伏兵。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:39; 马太福音 25:6; 帖撒罗尼迦前书 5:2"> 于是约书亚起来，和所有战士上艾城去。约书亚选了三万勇猛的战士，夜间派他们出去。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 20:29; 约书亚记 8:16; 士师记 20:36"> 他吩咐他们说：“看哪，你们要在城后埋伏，攻击那城；不要离城太远，你们都要准备好。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:5; 马太福音 10:16; 士师记 20:31–33"> 我和跟随我的所有百姓要接近那城。事情将是这样：他们像初次一样出来攻击我们的时候，我们就在他们面前逃跑。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 20:32; 出埃及记 15:9; 传道书 8:11"> 他们会出来追赶我们，直到我们把他们引离那城；因为他们会说：‘他们像初次一样在我们面前逃跑了。’所以我们要在他们面前逃跑，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王纪下 5:1; 约书亚记 8:1"> 你们就要从埋伏的地方起来，占领那城；因为耶和华你们的上帝必把那城交在你们手里。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 13:28; 约书亚记 1:16; 约书亚记 1:9"> 你们夺取那城以后，就要放火烧城。你们要照耶和华的话去做。看哪，我已经吩咐你们了。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 7:2; 创世记 12:8; 以斯拉记 2:28"> 约书亚派他们出去；他们就去设伏，停留在伯特利和艾城之间，在艾城的西边；但约书亚那夜住在百姓中间。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 6:12; 诗篇 119:60; 创世记 22:3"> 约书亚清早起来，点齐百姓，他和以色列的长老在百姓前面上艾城去。</span>
<span className="v" id="v11" data-v="11"> 所有百姓，就是跟随他的战士，都上去，靠近那城，来到城前，在艾城北边安营。约书亚和艾城之间有一个山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 8:2–3"> 他取了约五千人，叫他们埋伏在伯特利和艾城之间，在城的西边。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:12; 约书亚记 8:8"> 于是他们部署百姓，就是在城北的全军，以及城西的伏兵；约书亚那夜进入山谷中间。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:39; 士师记 20:34–36; 申命记 1:1"> 艾城的王看见了，就急忙清早起来，城里的人出去迎战以色列；他和他的所有百姓，在所定的时候，面向亚拉巴而去；但他不知道城后有伏兵要攻击他。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 18:12; 约书亚记 16:1; 士师记 20:36"> 约书亚和全以色列在他们面前装败，沿着通往旷野的路逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 20:31; 士师记 20:36–39; 约书亚记 8:5–6"> 城里所有的百姓都被召集起来追赶他们。他们追赶约书亚，就被引离了那城。</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 5:13; 约书亚记 8:3; 以赛亚书 19:11–13"> 艾城或伯特利没有一个人不出来追赶以色列。他们撇下城门敞开，去追赶以色列。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约书亚记 8:26; 约伯记 15:25; 撒母耳记上 17:41"> 耶和华对约书亚说：“把你手里的标枪伸向艾城，因为我要把那城交在你手里。”<br />约书亚就把手里的标枪伸向那城。</span>
<span className="v" id="v19" data-v="19"> 伏兵一见他伸出手，就迅速从他们的地方起来，跑进城去，夺取了那城。他们急忙放火烧城。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 76:5; 约伯记 11:20; 创世记 19:28"> 艾城的人回头一看，看哪，城中的烟升上天空；他们无力向这边或那边逃跑。那些逃往旷野的百姓转身攻击追赶他们的人。</span>
<span className="v" id="v21" data-v="21"> 约书亚和全以色列见伏兵已经夺取了城，又见城中的烟升起，就转身击杀艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:2; 约书亚记 10:28; 约书亚记 6:21"> 其他人也从城里出来攻击他们，他们就被夹在以色列人中间，一边有以色列人，另一边也有以色列人。以色列人击杀他们，没有让他们有一人存留或逃脱。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 15:8; 约书亚记 10:17; 启示录 19:20"> 他们活捉了艾城的王，把他带到约书亚那里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 11:10–14; 约书亚记 10:30–41; 民数记 21:24"> 以色列人在田野、在他们追赶艾城人的旷野中，杀尽了艾城的所有居民；他们都倒在刀下，直到灭尽。然后全以色列回到艾城，用刀击杀城中的人。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 20:16–18"> 那一天倒下的，无论男女，共有一万二千人，就是艾城的所有人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:11–12; 约书亚记 8:18"> 约书亚伸出标枪的手没有收回，直到他把艾城所有的居民尽行毁灭。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:2; 民数记 31:26; 诗篇 50:10"> 以色列人只把那城的牲畜和财物为自己取去，是照耶和华吩咐约书亚的话。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 13:16; 耶利米书 49:2; 列王纪下 19:25"> 约书亚焚烧艾城，使它永远成为废墟，成了荒场，直到今日。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 7:26; 撒母耳记下 18:17; 申命记 21:22–23"> 他把艾城的王挂在树上，直到晚上。日落的时候，约书亚下令，他们就把他的尸体从树上取下来，丢在城门口，又在尸体上堆起一大堆石头，直到今日还在那里。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命记 27:4–6; 出埃及记 20:24; 创世记 12:7–8"> 那时，约书亚在以巴路山上为耶和华——以色列的上帝筑了一座坛，</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 27:5–7; 出埃及记 20:24–25; 约书亚记 8:34–35"> 正如耶和华的仆人摩西吩咐以色列人的，也正如摩西律法书上所写的：一座用未凿过的石头筑成的坛，没有人用铁器动过那些石头。他们在坛上向耶和华献燔祭，也献平安祭。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 27:2–3; 申命记 27:8"> 他在那里，当着以色列人的面，把摩西律法的副本写在石头上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 11:29; 申命记 31:12; 申命记 31:9"> 全以色列，包括他们的长老、官长和审判官，都站在约柜两旁，在抬耶和华约柜的利未祭司面前；外族人和本地人都在场。一半人站在基利心山前，一半人站在以巴路山前，正如耶和华的仆人摩西起初所吩咐的，要为以色列百姓祝福。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 8:2–3; 尼希米记 13:1; 申命记 31:10–12"> 以后，约书亚宣读律法的一切话，就是祝福和咒诅，都是照律法书上所写的一切宣读的。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 31:12; 尼希米记 8:2; 耶利米书 26:2"> 凡摩西所吩咐的一切话，约书亚没有一句不在以色列全会众，以及妇女、孩子和寄居在他们中间的外族人面前宣读。</span>
</div>
</div>

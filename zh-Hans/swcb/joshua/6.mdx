<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 2:24; 约书亚记 2:9–14; 诗篇 127:1"> 耶利哥因以色列人的缘故严密关闭，无人出去，也无人进来。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:24; 约书亚记 8:1; 约书亚记 2:24"> 耶和华对约书亚说：“看哪，我已经把耶利哥和它的王，以及大能的勇士，都交在你手中。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:7; 民数记 14:9; 约书亚记 6:7"> 你们所有战士都要绕城行走，围绕这城一次。你们要这样行六天。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 20:17; 启示录 16:1; 列王纪上 18:43"> 七个祭司要拿七只羊角号，走在约柜前面。第七天，你们要绕城七次，祭司也要吹号。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 10:4–5; 希伯来书 11:30; 出埃及记 19:19"> 当他们吹长长的羊角声，你们听见号声的时候，全体百姓都要大声呼喊；那时城墙就必倒塌成平地，百姓都要上去，各人径直往前。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:1; 申命记 20:2–4; 约书亚记 3:3"> 嫩的儿子约书亚召了祭司来，对他们说：“你们抬起约柜，让七个祭司拿七只羊角号，走在耶和华的柜前。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:13; 约书亚记 6:3; 约书亚记 1:14"> 他们对百姓说：“前进！绕城行走，让武装的人走在耶和华的柜前。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 32:20; 约书亚记 6:3–4"> 约书亚对百姓说完以后，七个祭司拿着七只羊角号，在耶和华面前前进，并且吹号；耶和华的约柜跟随他们。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 6:13; 民数记 10:25; 以赛亚书 58:8"> 武装的人走在吹号的祭司前面，后队跟在约柜后面。他们边走边吹号。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:49; 马太福音 12:19; 以赛亚书 42:2"> 约书亚吩咐百姓说：“你们不可呼喊，不可让人听见你们的声音，也不可有一句话从你们口中发出，直到我吩咐你们呼喊的那一天；那时你们才可以呼喊。”</span>
<span className="v" id="v11" data-v="11"> 于是约书亚使耶和华的柜绕城，围绕了一次。然后他们回到营中，住在营里。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 3:1; 希伯来书 11:7–8; 创世记 22:3"> 约书亚清早起来，祭司抬起耶和华的柜。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:9; 马太福音 24:13; 历代志上 15:26"> 七个祭司拿着七只羊角号，走在耶和华的柜前面，不断前行并吹号；武装的人走在他们前面，后队跟在耶和华的柜后面。他们边走边吹号。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 6:15; 约书亚记 6:11; 约书亚记 6:3"> 第二天，他们绕城一次，就回到营中。他们这样行了六天。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:147; 彼得后书 1:19; 马太福音 28:1"> 第七天，他们在天刚亮的时候清早起来，照同样的方式绕城七次；只有这一天，他们绕城七次。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 13:15; 约书亚记 6:5; 历代志下 20:22–23"> 到第七次，祭司吹号的时候，约书亚对百姓说：“呼喊吧，因为耶和华已经把这城赐给你们了！</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 20:17; 雅各书 2:25; 弥迦书 4:13"> 这城和城中所有的，都要归耶和华为当灭之物。只有妓女喇合，以及所有与她同在屋里的人，可以存活，因为她藏了我们所派的使者。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 5:21; 以弗所书 5:11; 约书亚记 7:1"> 至于你们，务要远离当灭之物，免得你们把它分别为当灭之后，又取了当灭之物；这样就会使以色列营成为被咒诅的，并使它遭祸。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 26:20; 马太福音 27:6; 马可福音 12:41"> 但所有的银子、金子和铜铁器皿，都分别为圣归耶和华；它们要归入耶和华的库中。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:30; 哥林多后书 10:4–5; 约书亚记 6:5"> 于是百姓呼喊，祭司吹号。百姓听见号声的时候，就大声呼喊；城墙就倒塌成平地，百姓便进城，各人径直往前，于是夺取了那城。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 137:8–9; 耶利米书 48:18; 约书亚记 11:14"> 他们用刀刃把城中所有的，不拘男女、老幼，以及牛、羊、驴，都完全毁灭。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:31; 约书亚记 6:17; 以西结 17:18–19"> 约书亚对那两个窥探那地的人说：“你们进那妓女的家，照你们向她所起的誓，把那女人和她所有的一切从那里带出来。”</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:7; 创世记 18:24; 使徒行传 27:24"> 那些作探子的年轻人进去，把喇合和她的父亲、母亲、兄弟，以及她所有的一切都带出来；他们也把她所有的亲属带出来，安置在以色列营外。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 8:28; 启示录 17:16; 列王纪下 25:9"> 他们用火焚烧那城和城中所有的一切；只有银子、金子和铜铁器皿，他们都放入耶和华殿的库中。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 马太福音 1:5; 士师记 1:24–25"> 至于妓女喇合、她父亲的家属，以及她所有的一切，约书亚都使他们存活。她住在以色列中间直到今日，因为她藏了约书亚所派去窥探耶利哥的使者。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪上 16:34; 使徒行传 19:13; 民数记 5:19–21"> 约书亚当时叫他们起誓说：“在耶和华面前，凡兴起重建这耶利哥城的人必受咒诅。他立城根基时，必丧长子；安城门时，必丧幼子。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 9:3; 约书亚记 1:5; 马太福音 28:20"> 耶和华与约书亚同在；约书亚的名声传遍全地。</span>
</div>
</div>

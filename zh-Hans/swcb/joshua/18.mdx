<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 19:51; 撒母耳记上 1:3; 约书亚记 21:2"> 以色列全会众聚集在示罗，把会幕设立在那里。那地已经在他们面前被制伏了。</span>
<span className="v" id="v2" data-v="2"> 以色列人中还剩下七个支派，还没有分得他们的产业。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 18:9; 箴言 13:4; 箴言 10:4"> 约书亚对以色列人说：“耶和华——你们列祖的上帝已经把这地赐给你们，你们还要懈怠多久，不进去得这地为业呢？</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:6; 约书亚记 4:2; 约书亚记 18:3"> 你们要从每个支派为自己选派三个人；我要差遣他们，他们就要起身，走遍那地，按着他们应得的产业把地记录下来，然后回到我这里。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 16:1–10; 约书亚记 19:1–9; 约书亚记 15:1–12"> 他们要把那地分成七份。犹大要住在南方自己的境内，约瑟家要住在北方自己的境内。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:2; 约书亚记 18:10; 使徒行传 13:19"> 你们要把那地勘察成七份，把所记录的带到这里给我；我要在这里，在耶和华我们的上帝面前，为你们抽签。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 13:33; 约书亚记 13:8–31; 民数记 18:20"> 然而，利未人在你们中间没有分；因为耶和华的祭司职分就是他们的产业。迦得、流便和玛拿西半个支派，已经在约旦河东得了他们的产业，是耶和华的仆人摩西给他们的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:10; 罗马书 14:19; 撒母耳记上 14:41"> 那些人起身去了。约书亚吩咐那些去勘察那地的人说：“你们去走遍那地，勘察它，然后回到我这里；我要在示罗这里，在耶和华面前，为你们抽签。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:19"> 那些人去了，走遍那地，按城邑把地分成七份，写在册子上；然后他们回到示罗营中，到约书亚那里。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 1:12; 使徒行传 13:19; 约书亚记 18:6"> 约书亚在示罗，在耶和华面前为他们抽签。约书亚在那里按以色列人的分配，把地分给他们。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 16:1–10; 约书亚记 15:1–8; 申命记 10:1–22"> 便雅悯子孙支派的签，按着他们的宗族抽了出来。他们抽签所得之地的边界，在犹大子孙和约瑟子孙之间。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 16:1; 约书亚记 7:2; 约书亚记 2:1"> 他们北边的边界是从约旦河起；这边界上到耶利哥的北侧，又向西上到山地，直到伯亚文的旷野为止。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 28:19; 约书亚记 16:2–3; 约书亚记 10:11"> 这边界从那里经过路斯，直到路斯（也叫伯特利）的南侧；又下到亚他绿亚达，到下伯和仑南边的山旁。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:9; 历代志上 13:5–6; 撒母耳记上 7:1–2"> 这边界延伸，从伯和仑南边对面的山，沿西边转向南方，直到犹大子孙的一座城基列巴力（也叫基列耶琳）为止。这是西边。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:9"> 南边是从基列耶琳的尽头起；这边界向西延伸，直到尼弗多亚的水泉。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:10; 约书亚记 15:7–8; 以赛亚书 30:33"> 这边界下到欣嫩子谷前面那座山的尽头，就是利乏音谷北边；又下到欣嫩谷，沿耶布斯人的南侧，下到隐罗结。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:6"> 它向北延伸，到隐示麦，又到亚都冥坡对面的基利绿；再下到流便之子波罕的石头那里。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:6; 约书亚记 15:61"> 它经过亚拉巴对面北边的一侧，下到亚拉巴。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 14:3; 约书亚记 15:2; 民数记 34:3"> 这边界经过伯曷拉北侧；边界的尽头是在盐海的北湾，就是约旦河的南端。这是南界。</span>
<span className="v" id="v20" data-v="20"> 约旦河是东边的边界。这就是便雅悯子孙按着他们的宗族所得的产业，和四围的边界。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 18:12; 约书亚记 6:1; 约书亚记 18:19"> 便雅悯子孙支派按着他们宗族所得的城邑是：耶利哥、伯曷拉、以麦基悉、</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 15:6; 列王纪上 12:29–32; 约书亚记 18:18"> 伯亚拉巴、洗玛脸、伯特利、</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 13:17"> 亚文、巴拉、俄弗拉、</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 2:26; 约书亚记 21:17; 以赛亚书 10:29"> 基法阿摩尼、俄弗尼、迦巴；共十二座城，还有所属的村庄。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:17; 列王纪上 3:4–5; 约书亚记 10:2"> 又有基遍、拉玛、比录、</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 10:17; 以斯拉记 2:25; 约书亚记 9:17"> 米斯巴、基非拉、摩撒、</span>
<span className="v" id="v27" data-v="27"> 利坚、伊利毗勒、他拉拉、</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 21:14; 约书亚记 15:8; 士师记 20:4–5"> 洗拉、以利弗、耶布斯人之城（也叫耶路撒冷）、基比亚、基列；共十四座城，还有所属的村庄。这就是便雅悯子孙按着他们宗族所得的产业。</span>
</div>

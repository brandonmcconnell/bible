<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 13:1; 约书亚记 21:44; 约书亚记 11:23"> 过了许多日子，耶和华使以色列从四围仇敌手中得享安息；约书亚年纪老迈，寿数已高。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 申命记 31:28; 历代志上 28:1"> 约书亚召了全以色列人来，就是他们的长老、首领、审判官和官长，对他们说：“我年纪老迈，寿数已高。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:14; 约书亚记 10:42; 约书亚记 10:14"> 耶和华你们的上帝因你们的缘故向这些国所做的一切，你们都亲眼看见了；因为为你们争战的，是耶和华你们的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:6–7; 约书亚记 18:10; 约书亚记 13:2"> 看哪，从约旦河起，直到日落方向的大海，我已经把这些剩下的国，以及我所剪除的一切国，都分给你们各支派为产业。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 11:23; 约书亚记 13:6; 出埃及记 33:2"> 耶和华你们的上帝必把他们从你们面前赶出去，从你们眼前驱逐出去。你们必占有他们的土地，正如耶和华你们的上帝对你们所说的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 5:32; 申命记 28:14; 箴言 4:26–27"> “所以，你们要非常刚强，谨守遵行写在摩西律法书上的一切，不可偏离，或向右，或向左；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 23:13; 诗篇 16:4; 申命记 7:2–3"> 不可进入这些国民中间，就是这些仍留在你们中间的国民；也不可提他们神明的名，不可使人指着它们起誓，不可侍奉它们，也不可向它们下拜；</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 10:20; 约书亚记 22:5; 申命记 13:4"> 只要紧紧跟随耶和华你们的上帝，像你们直到今日所行的一样。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 1:5; 申命记 11:23; 约书亚记 23:5"> “因为耶和华已经把又大又强的国民从你们面前赶出去。至于你们，直到今日，没有一人能在你们面前站立得住。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:30; 利未记 26:8; 申命记 3:22"> 你们一人必追赶千人；因为为你们争战的，是耶和华你们的上帝，正如祂对你们所说的。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 22:5; 申命记 6:5–12; 箴言 4:23"> 所以，你们要格外谨慎自己，爱耶和华你们的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 7:3; 以西结 18:24; 西番雅书 1:6"> “但是，如果你们转身退后，紧紧依附这些国的余民，就是这些仍留在你们中间的人，与他们通婚，你们到他们那里去，他们也到你们这里来；</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 7:16; 民数记 33:55; 出埃及记 23:33"> 你们要确实知道，耶和华你们的上帝必不再把这些国民从你们眼前赶出去；他们却要成为你们的网罗和陷阱，成为你们肋旁的鞭、眼中的刺，直到你们从耶和华你们的上帝赐给你们的这美地上灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王纪上 2:2; 利未记 26:3–13"> “看哪，今天我要走全地之人必走的路了。你们全心全魂都知道，耶和华你们的上帝论到你们所说的一切美好之事，没有一句落空；都为你们成就了，没有一句落空。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:15–68; 利未记 26:14–46; 士师记 3:8"> 耶和华你们的上帝对你们所说的一切美好之事怎样临到你们，耶和华也必照样使一切灾祸临到你们，直到祂把你们从耶和华你们的上帝赐给你们的这美地上毁灭；</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:25–26; 列王纪下 24:20"> 如果你们违背耶和华你们的上帝吩咐你们所守的祂的约，去侍奉别的神明，向它们下拜，那时耶和华的怒气必向你们发作，你们就必迅速从祂赐给你们的美地上灭亡。”</span>
</div>

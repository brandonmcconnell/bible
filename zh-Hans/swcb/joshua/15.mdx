<span className="v" id="v2" data-v="2" data-xref="创世记 14:3; 以西结 47:8; 以赛亚书 11:15"> 他们的南界是从盐海的尽头，就是朝南的海湾开始；</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 34:4; 士师记 1:36; 民数记 20:1"> 往亚克拉滨坡的南边出去，经过寻，上到加低斯·巴尼亚的南边，又经过希斯仑，上到亚达，转向甲加；</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 34:5; 约书亚记 13:3; 出埃及记 23:31"> 又经过押们，通到埃及溪；边界的终点在海边。这要作你们的南界。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 34:12; 约书亚记 18:15–19; 民数记 34:10"> 东界是盐海，直到约旦河口。北边的边界，是从约旦河口的海湾开始。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 18:17; 约书亚记 18:19–21"> 边界上到伯曷拉，经过伯亚拉巴的北边；边界又上到吕便之子波罕的石头那里。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 1:9; 撒母耳记下 17:17; 约书亚记 7:26"> 边界从亚割谷上到底璧，又向北，朝着吉甲，就是在河的南边、亚都冥坡对面的地方。边界经过隐示麦水泉，终点在隐罗结。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:16; 约书亚记 15:63; 约书亚记 18:28"> 边界又沿欣嫩子谷上到耶布斯人城（又叫耶路撒冷）的南侧；边界再上到一座山的山顶，这山在欣嫩谷西边对面，在利乏音谷北边的尽头。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 13:6; 约书亚记 18:15; 士师记 18:12"> 边界从山顶延伸到尼弗多亚水泉，又通到以弗仑山的各城；边界再延伸到巴拉（又叫基列·耶琳）；</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 14:1; 士师记 14:5; 创世记 38:12–13"> 边界从巴拉转向西边，到西珥山，经过耶琳山（又叫基撒仑）的北侧，下到伯示麦，又经过亭拿；</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:45; 列王纪下 1:2–3; 撒母耳记上 5:10"> 边界通到以革伦的北侧；边界延伸到施基仑，经过巴拉山，通到雅比聂；边界的出口在海边。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 34:6–7; 约书亚记 15:47; 以西结 47:20"> 西界是大海的海岸。这就是犹大子孙按着宗族所得之地的边界。</span>

<span className="v" id="v14" data-v="14" data-xref="士师记 1:20; 士师记 1:10; 民数记 13:22–23"> 迦勒从那里赶出了亚衲的三个儿子：示筛、亚希幔、挞买，他们都是亚衲的子孙。</span>

<span className="v" id="v16" data-v="16" data-xref="士师记 1:12–13; 士师记 1:6"> 迦勒说：“谁攻打基列·西弗并夺取它，我就把我的女儿押撒给他为妻。”</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 3:9; 士师记 1:13; 约书亚记 14:6"> 迦勒的兄弟基纳斯的儿子俄陀聂夺取了那城；迦勒就把女儿押撒给他为妻。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 24:64; 撒母耳记上 25:23"> 押撒来的时候，叫他向她父亲求一块田。她下了驴，迦勒对她说：“你要什么？”</span>
</div>
<div className="bp">

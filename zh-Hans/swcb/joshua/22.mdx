<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 32:18–33; 申命记 29:7–8"> 于是约书亚召了流便人、迦得人和玛拿西半个支派来，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:12–18; 申命记 3:16–20; 民数记 32:20–29"> 对他们说：“耶和华的仆人摩西所吩咐你们的一切，你们都遵守了；凡我所吩咐你们的，你们也都听从了我的话。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:23–27"> 这么多日子以来，直到今日，你们没有离弃你们的弟兄，反而尽了耶和华你们上帝命令的本分。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:8; 民数记 32:18; 申命记 3:20"> 如今耶和华你们的上帝已经照祂所应许的，使你们的弟兄得享安息。所以现在你们可以回去，到你们的帐棚去，到耶和华的仆人摩西在约旦河那边赐给你们为业之地去。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:37; 出埃及记 20:6; 罗马书 8:28"> 只是你们要格外谨慎，遵行耶和华的仆人摩西所吩咐你们的诫命和律法，爱耶和华你们的上帝，行祂一切的道路，守祂的诫命，紧紧跟随祂，全心全意事奉祂。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:13; 路加福音 24:50; 创世记 47:7"> 于是约书亚为他们祝福，送他们离去；他们就回自己的帐棚去了。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 17:1–12; 民数记 32:33; 约书亚记 13:29–31"> 摩西已经把巴珊之地给了玛拿西半个支派为业；但约书亚把约旦河西边，在他们弟兄中间的地，给了另半个支派。约书亚送他们回帐棚的时候，也为他们祝福，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 31:27; 申命记 8:9–14; 箴言 3:16"> 对他们说：“你们带着许多财物，带着极多的牲畜、银子、金子、铜、铁和极多的衣服，回你们的帐棚去吧。你们要把从仇敌所得的掠物，与你们的弟兄分了。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 32:29; 民数记 32:26; 民数记 32:1"> 流便子孙、迦得子孙和玛拿西半个支派离开了在迦南地示罗的以色列子孙，回到基列地，就是他们照耶和华借摩西所吩咐而得为业、归他们所有的地。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:26–27; 创世记 31:46–52; 约书亚记 4:5–9"> 他们到了迦南地、约旦河附近的地区，流便子孙、迦得子孙和玛拿西半个支派就在那里，靠近约旦河筑了一座坛；那坛看起来很高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 13:12–14; 利未记 17:8–9; 约书亚记 2:7"> 以色列子孙听见这事，说：“看哪，流便子孙、迦得子孙和玛拿西半个支派，在迦南地边界、约旦河一带，属于以色列子孙的那一边，筑了一座坛。”</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–11; 申命记 13:15; 加拉太书 4:17–18"> 以色列子孙听见了，以色列子孙全会众就聚集在示罗，要上去攻打他们。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 25:7; 诗篇 106:30–31; 出埃及记 6:25"> 以色列子孙打发祭司以利亚撒的儿子非尼哈，到基列地去见流便子孙、迦得子孙和玛拿西半个支派。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:4; 出埃及记 18:25"> 与他同去的有十个首领，按以色列各支派，每个宗族各派一个首领；他们各是在以色列千人中自己宗族的族长。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:3; 撒母耳记上 15:23; 申命记 30:17"> 他们来到基列地，见流便子孙、迦得子孙和玛拿西半个支派，对他们说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 12:13–14"> “耶和华的全会众这样说：‘你们今日转离不跟随耶和华，为自己筑一座坛，今日悖逆耶和华；你们向以色列的上帝犯的这罪，究竟算什么呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 25:1–18; 诗篇 106:28–29; 申命记 4:3–4"> 从前毗珥的罪孽，对我们还算小事吗？虽然瘟疫曾临到耶和华的会众，我们直到今日还没有从那罪中洁净自己，</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 16:22; 约书亚记 22:16; 约书亚记 7:11"> 你们今日竟要转离不跟随耶和华吗？你们今日既悖逆耶和华，明日祂必向以色列全会众发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 18:1; 历代志下 11:16–17; 使徒行传 10:14–15"> 只是，如果你们所得为业之地是不洁净的，就可以渡过来，到耶和华产业之地，就是耶和华的帐幕所在之地，在我们中间得产业；但不可悖逆耶和华，也不可悖逆我们，在耶和华我们上帝的坛以外为自己筑坛。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:1; 约书亚记 7:5; 约书亚记 7:18"> 从前谢拉的儿子亚干岂不是在当灭之物上犯罪，以致忿怒临到以色列全会众吗？那人并不是独自在自己的罪孽中灭亡。’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:19; 箴言 16:1; 彼得前书 3:15"> 于是流便子孙、迦得子孙和玛拿西半个支派回答以色列千人的族长们说：</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 8:39; 诗篇 44:21; 申命记 10:17"> “大能者上帝耶和华，大能者上帝耶和华，祂知道；以色列也必知道：如果这是出于悖逆，或是向耶和华犯罪——愿祂今日不要拯救我们——</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:16; 申命记 18:19; 以西结 3:18"> 如果我们为自己筑坛，是要转离不跟随耶和华，或是在坛上献燔祭、素祭，或献平安祭，就愿耶和华亲自追究。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 4:6; 申命记 6:20; 创世记 30:33"> “不，我们这样做，确是出于忧虑，并且有缘故；我们说：‘日后你们的子孙可能对我们的子孙说：“你们与耶和华以色列的上帝有什么关系呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 12:16; 以斯拉记 4:2–3; 撒母耳记上 26:19"> 因为耶和华把约旦河定为我们和你们之间的边界，你们流便子孙和迦得子孙在耶和华里没有分。”’这样，你们的子孙就可能使我们的子孙不再敬畏耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> “所以我们说：‘现在让我们预备为自己筑一座坛，不是为献燔祭，也不是为献别的祭；</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 24:27; 创世记 31:48; 申命记 12:17–18"> 而是作为我们和你们之间，以及我们以后世世代代之间的见证，好使我们可以在耶和华面前，用我们的燔祭、祭物和平安祭来事奉耶和华；’免得日后你们的子孙对我们的子孙说：‘你们在耶和华里没有分。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:40; 以西结 43:10–11; 希伯来书 8:5"> “所以我们说：‘日后他们若这样对我们，或对我们的后代说，我们就说：“看哪，这是耶和华祭坛的样式，是我们祖先所造的；不是为献燔祭，也不是为献别的祭，而是作为我们和你们之间的见证。”’</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 24:16; 申命记 12:13–14; 约书亚记 22:23"> “我们绝不敢悖逆耶和华，今日转离不跟随耶和华，在耶和华我们上帝的帐幕前那座坛以外，另筑一座坛为献燔祭、素祭或别的祭！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:33; 以斯帖记 1:21; 箴言 15:1"> 祭司非尼哈和会众的首领，就是与他同来的以色列千人的族长们，听见流便子孙、迦得子孙和玛拿西子孙所说的话，就都觉得满意。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 15:2; 利未记 26:11–12; 以赛亚书 12:6"> 祭司以利亚撒的儿子非尼哈对流便子孙、迦得子孙和玛拿西子孙说：“今日我们知道耶和华在我们中间，因为你们没有向耶和华犯这罪。现在你们救了以色列子孙脱离耶和华的手。”</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 22:12–14; 箴言 25:13"> 祭司以利亚撒的儿子非尼哈和众首领，从基列地流便子孙、迦得子孙那里，回到迦南地以色列子孙那里，把话带回给他们。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 29:20; 路加福音 2:28; 但以理 2:19"> 这事使以色列子孙满意；以色列子孙称颂上帝，不再说要上去攻打他们，毁坏流便子孙和迦得子孙所居住的地。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 22:27; 马太福音 4:10; 以赛亚书 43:10"> 流便子孙和迦得子孙给那坛起名叫“我们中间的见证：耶和华是上帝。”</span>
</div>
</div>

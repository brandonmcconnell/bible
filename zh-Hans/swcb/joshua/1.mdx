<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 34:9; 申命记 1:38; 申命记 31:23"> 耶和华的仆人摩西死了以后，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在英文中以全大写字母呈现的“LORD”或“GOD”，是上帝专有名（希伯来文“יהוה”，通常读作 Yahweh）的译法。">a</a></sup>耶和华对摩西的侍从、嫩的儿子约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 3:28; 申命记 31:7; 民数记 27:16–21"> “我的仆人摩西死了。现在你要起来，和这全体百姓渡过这约旦河，往我正在赐给他们，就是赐给以色列子孙的地去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 11:24; 约书亚记 14:9; 提多书 1:2"> 你们脚掌所踏的每一处地方，我都已经赐给你们，正如我对摩西所说的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 23:31; 创世记 15:18–21; 申命记 3:25"> 从旷野和这黎巴嫩，直到大河，就是幼发拉底河，赫人的全地，又到日落方向的大海，都要作你们的边界。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:31; 申命记 31:6–8; 马太福音 28:20"> 你一生的日子，没有人能在你面前站立得住。我怎样与摩西同在，也必照样与你同在；我必不撇下你，也不离弃你。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理 10:19; 以弗所书 6:10; 约书亚记 1:9"> “你要刚强壮胆，因为你要使这百姓承受我向他们列祖起誓要赐给他们的地为业。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 22:13; 申命记 5:32; 约书亚记 1:8"> 只要刚强，大大壮胆，谨慎遵行我仆人摩西吩咐你的一切律法。不可偏离左右，使你无论往哪里去，都可以顺利。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 119:15; 诗篇 19:14; 歌罗西书 3:16"> 这律法书不可离开你的口，总要昼夜默想，好使你谨慎遵行书上所写的一切；这样，你的道路就必亨通，你也必顺利。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 28:15; 耶利米书 1:7–8; 约书亚记 1:6–7"> 我不是吩咐过你吗？你要刚强壮胆。不要惧怕，也不要惊惶，因为无论你往哪里去，耶和华你的上帝<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译为“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>都与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 于是约书亚吩咐百姓的官长说：</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 9:1; 何西阿 6:2; 列王纪下 20:5"> “你们要走遍营中，吩咐百姓说：‘要预备粮食；因为三天之内，你们就要渡过这约旦河，进去取得耶和华你们的上帝赐给你们为业的地。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 32:20–22"> 约书亚对吕便人、迦得人和玛拿西半支派的人说：</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:20–28; 申命记 3:18–20; 约书亚记 22:1–4"> 当抬着全地之主耶和华约柜的祭司，脚掌踏在约旦河水中，约旦河的水就必断绝；从上游流下来的水必立起成一堆。”</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 20:8; 出埃及记 13:18; 启示录 17:4"> 你们的妻子、孩子和牲畜可以住在摩西赐给你们的约旦河东之地；但你们所有英勇的战士都要带着兵器，在你们弟兄前面过去，帮助他们，</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 2:4; 民数记 32:17–22; 哥林多前书 12:26"> 直到耶和华使你们的弟兄得安息，像祂使你们得安息一样，并且他们也取得耶和华你们的上帝赐给他们的地。然后你们可以回到你们所得为业的地，占有它，就是耶和华的仆人摩西赐给你们的约旦河那边、向日出方向的地。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="提多书 3:1; 申命记 5:27; 彼得前书 2:13–15"> 他们回答约书亚说：“你所吩咐我们的一切，我们都必去做；你差遣我们到哪里，我们都必去。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 1:5; 列王纪上 1:37; 约书亚记 1:9"> 我们怎样凡事听从摩西，也必照样听从你。惟愿耶和华你的上帝与你同在，像祂与摩西同在一样。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 6:10; 约书亚记 1:9; 以斯拉记 10:4"> 凡违背你的命令，不听从你所吩咐他一切话的人，必被处死。只要刚强壮胆。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:21; 希伯来书 7:1; 约书亚记 8:2"> 耶路撒冷王亚多尼洗德听见约书亚怎样攻取艾城，并且将城尽行毁灭；他怎样待耶利哥和耶利哥的王，也怎样待艾城和艾城的王；又听见基遍的居民怎样与以色列人讲和，并住在他们中间，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 11:25; 约书亚记 2:24; 出埃及记 15:14–16"> 他们就非常惧怕，因为基遍是一座大城，像王城之一，比艾城更大，而且城中所有的人都是勇士。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:9; 弥迦书 1:13; 约书亚记 10:1"> 因此，耶路撒冷王亚多尼洗德派人去见希伯仑王何咸、耶末王毗兰、拉吉王雅非亚和伊矶伦王底璧，说：</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:15; 约书亚记 10:1; 以赛亚书 8:9–10"> “请上来帮助我。我们去攻打基遍，因为他们已经与约书亚和以色列人讲和了。”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:9–10; 创世记 15:16; 约书亚记 10:6"> 于是，五个亚摩利人的王，就是耶路撒冷王、希伯仑王、耶末王、拉吉王和伊矶伦王，聚集起来，他们和他们所有的军队都上去，对着基遍安营，攻打那城。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 9:6; 约书亚记 5:10; 申命记 1:15"> 基遍人派人到吉甲营中去见约书亚，说：“不要离弃你的仆人！请快上来拯救我们！帮助我们，因为住在山地的亚摩利诸王都聚集起来攻击我们。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 8:1; 以赛亚书 8:12; 以赛亚书 8:14"> 于是约书亚从吉甲上去，他和所有跟随他的军兵，包括一切英勇的战士。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 8:31; 申命记 3:2; 诗篇 27:1–2"> 耶和华对约书亚说：“不要怕他们，因为我已经把他们交在你手里。他们没有一个人能在你面前站立得住。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="传道书 9:10; 提摩太后书 2:3; 箴言 24:11–12"> 约书亚就突然来到他们那里。他从吉甲连夜行军。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:14; 约书亚记 16:3; 约书亚记 16:5"> 耶和华使他们在以色列人面前溃乱。祂在基遍大大击杀他们，又沿着伯和仑上坡的路追赶他们，击杀他们直到亚西加和玛基大。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:2; 士师记 5:20; 诗篇 18:12–14"> 他们从以色列人面前逃跑，正在伯和仑下坡的时候，耶和华从天上向他们降下大石头，直到亚西加，他们就死了。死于冰雹石的人，比以色列人用刀所杀的还多。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哈巴谷 3:11; 以赛亚书 38:8; 以赛亚书 60:20"> 当耶和华把亚摩利人交在以色列人面前的那一天，约书亚对耶和华说话。他在以色列人眼前说：“太阳啊，停在基遍！月亮啊，止在亚雅仑谷！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷 3:11; 以赛亚书 38:8; 约书亚记 10:14"> 于是太阳停住，月亮止住，直到这国向仇敌报了仇。这事不是写在《雅煞珥书》上吗？太阳停在天空当中，大约一整天没有急速下落。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:30; 出埃及记 14:14; 约书亚记 10:42"> 在那日以前或以后，从没有像那样的一天，耶和华听从一个人的声音；因为耶和华为以色列争战。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:43; 约书亚记 10:6"> 约书亚和所有跟随他的以色列人回到吉甲的营中。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 24:8; 阿摩司 9:2; 诗篇 139:7–10"> 这五个王逃跑，藏在玛基大的洞里。</span>
<span className="v" id="v17" data-v="17"> 有人告诉约书亚说：“那五个王已经找到了，他们藏在玛基大的洞里。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:66; 约伯记 21:30; 阿摩司 9:1"> 约书亚说：“把大石头滚到洞口遮住，派人在那里看守他们；</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:37–41; 耶利米书 8:14; 以赛亚书 9:14–15"> 但你们不要停留在那里。要追赶你们的仇敌，袭击他们的后队，不要让他们进自己的城，因为耶和华你们的上帝已经把他们交在你们手里。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 8:24; 撒母耳记下 20:6; 约书亚记 10:10"> 约书亚和以色列人把他们大大击杀，直到他们被消灭；他们中剩下的残余进入了坚固城。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 11:7; 以赛亚书 54:17; 以赛亚书 57:4"> 众人就平平安安回到玛基大营中，到约书亚那里。没有人敢对任何以色列人说一句反对的话。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 15:32"> 约书亚说：“打开洞口，把那五个王从洞里带出来，到我这里。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约书亚记 10:1; 约书亚记 10:5; 约书亚记 10:3"> 他们就这样做，把那五个王从洞里带出来，到他那里：就是耶路撒冷王、希伯仑王、耶末王、拉吉王和伊矶伦王。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 4:3; 罗马书 16:20; 启示录 2:26–27"> 他们把这些王带到约书亚那里以后，约书亚召来以色列众人，对那些与他同去的战士首领说：“你们近前来，把脚踏在这些王的颈项上。”<br />他们就近前来，把脚踏在他们的颈项上。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 1:10; 约书亚记 1:9; 以弗所书 6:10"> 约书亚对他们说：“不要害怕，也不要惊惶。要刚强壮胆，因为耶和华必这样对待你们所攻打的一切仇敌。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约书亚记 8:29; 撒母耳记下 21:9; 马太福音 27:25"> 随后，约书亚击杀他们，把他们处死，挂在五棵树上。他们就挂在树上直到晚上。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:29; 申命记 21:22–23; 约书亚记 7:26"> 到日落的时候，约书亚吩咐人把他们从树上取下来，扔进他们曾藏身的洞里，又把大石头放在洞口，直到今日还在那里。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:21; 申命记 7:16; 申命记 20:16–17"> 当日，约书亚攻取玛基大，用刀锋击杀那城和城中的王。他将那城和其中所有的人尽行毁灭，没有留下一个幸存者。他怎样待耶利哥王，也怎样待玛基大王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 21:13; 约书亚记 15:42; 耶利米书 52:1"> 约书亚和所有跟随他的以色列人从玛基大往立拿去，攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和华也把立拿和立拿的王交在以色列人手里。他用刀锋击杀那城和其中所有的人，没有在城中留下一个幸存者。他怎样待耶利哥王，也怎样待立拿王。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:3; 约书亚记 12:11; 约书亚记 10:5"> 约书亚和所有跟随他的以色列人从立拿往拉吉去，对着拉吉安营，攻打那城。</span>
<span className="v" id="v32" data-v="32"> 耶和华把拉吉交在以色列人手里。他第二天攻取那城，用刀锋击杀那城和其中所有的人，照他向立拿所做的一切而行。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 16:10; 士师记 1:29; 约书亚记 16:3"> 那时，基色王何兰上来帮助拉吉；约书亚击杀他和他的百姓，直到没有给他留下一个幸存者。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 10:3; 约书亚记 12:12; 约书亚记 15:39"> 约书亚和所有跟随他的以色列人从拉吉往伊矶伦去；他们对着伊矶伦安营，攻打那城。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 26:44; 约书亚记 10:37; 约伯记 19:10"> 当日他们攻取那城，用刀锋击杀那城。那一天，他将城中所有的人尽行毁灭，照他向拉吉所做的一切而行。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士师记 1:10; 约书亚记 15:13; 约书亚记 14:13–14"> 约书亚和所有跟随他的以色列人从伊矶伦上到希伯仑；他们攻打那城。</span>
<span className="v" id="v37" data-v="37"> 他们攻取那城，用刀锋击杀那城、城中的王和所属的一切城镇，以及城中所有的人。他没有留下一个幸存者，照他向伊矶伦所做的一切而行；他将那城和其中所有的人尽行毁灭。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约书亚记 15:15; 约书亚记 12:13; 约书亚记 15:49"> 约书亚和所有跟随他的以色列人转回到底璧，攻打那城。</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亚 1:18; 约书亚记 11:8; 申命记 3:3"> 他攻取那城、城中的王和所属的一切城镇。他们用刀锋击杀这些城，将城中所有的人尽行毁灭。他没有留下一个幸存者。他怎样待希伯仑，也怎样待底璧和底璧的王；又照他怎样待立拿和立拿的王一样。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 7:2–16; 出埃及记 23:31–33; 约书亚记 8:27"> 这样，约书亚击打全地，就是山地、南地、低地、山坡，以及他们所有的王。他没有留下一个幸存者，却将一切有气息的尽行毁灭，正如耶和华以色列的上帝所吩咐的。</span>
<span className="v" id="v41" data-v="41" data-xref="约书亚记 11:16; 约书亚记 15:51; 申命记 9:23"> 约书亚击打他们，从加低斯·巴尼亚直到迦萨，又击打歌珊全地，直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:14; 诗篇 46:7; 诗篇 80:3"> 约书亚一次就夺取了这些王和他们的土地，因为耶和华以色列的上帝为以色列争战。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 10:15; 约书亚记 4:19; 撒母耳记上 11:14"> 约书亚和所有跟随他的以色列人回到吉甲的营中。</span>
</div>
</div>

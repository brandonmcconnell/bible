<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 34:6; 出埃及记 3:17; 出埃及记 23:23"> 约旦河那边、山地、低地，以及黎巴嫩对面大海沿岸所有的王，就是赫人、亚摩利人、迦南人、比利洗人、希未人和耶布斯人，听见这事，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:14; 约珥 3:9–13; 诗篇 2:1–2"> 就同心聚集，要与约书亚和以色列争战。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 10:2; 约书亚记 9:17; 撒母耳记下 21:1–2"> 基遍的居民听见约书亚向耶利哥和艾所做的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 马太福音 10:16; 马可福音 2:22"> 他们也施行诡计；他们去，装作使节，把旧口袋驮在驴上，又带着破裂又缝补过的旧酒囊，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命记 33:25; 申命记 29:5"> 脚上穿着旧而补过的鞋，身上穿着旧衣服。他们所带作食物的饼全都又干又发霉。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 5:10; 列王纪下 20:14; 约书亚记 9:9"> 他们到吉甲营中见约书亚，对他和以色列人说：“我们从远方来。现在请你们与我们立约。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 11:19; 士师记 2:2; 出埃及记 34:12"> 以色列人对希未人说：“也许你们住在我们中间，我们怎能与你们立约呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 20:11; 列王纪下 10:5; 约书亚记 9:11"> 他们对约书亚说：“我们是你的仆人。”<br />约书亚对他们说：“你们是谁？从哪里来？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 20:15; 约书亚记 9:24; 以赛亚书 55:5"> 他们对他说：“你的仆人是因耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="全大写的 LORD 或 GOD 源自希伯来文 יהוה Yahweh（雅威），除非另有注明是源自短形式 יה Yah（雅）。">a</a></sup>你上帝的名，从极远的地方来的；因为我们听见了祂的名声，以及祂在埃及所做的一切，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–35; 申命记 1:4; 约书亚记 12:4"> 又听见祂向约旦河那边两个亚摩利人的王所做的一切，就是向希实本王西宏和在亚斯他录的巴珊王噩所做的。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 9:8; 以斯帖记 8:17; 约书亚记 1:11"> 我们的长老和我国所有居民对我们说：‘你们手里要带着路上的食物，去迎接他们，对他们说：“我们是你们的仆人。现在请你们与我们立约。”’</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 9:4–5"> 我们出发到你们这里来的那天，我们的这些饼是从家里拿出来作食物的，还是热的；现在，看哪，已经又干又发霉了。</span>
<span className="v" id="v13" data-v="13"> 这些酒囊，我们装酒的时候还是新的；看哪，现在已经破裂了。我们的这些衣服和鞋，也因路途非常遥远而变旧了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民数记 27:21; 历代志上 10:13–14"> 以色列人尝了他们的食物，却没有求问耶和华口中的指示。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:2; 申命记 20:10–11; 约书亚记 11:19"> 约书亚与他们讲和，与他们立约，容他们存活；会众的首领也向他们起誓。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 与他们立约之后，过了三天，以色列人才听说他们是自己的邻居，住在他们中间。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:25; 约书亚记 18:25–28; 约书亚记 18:14"> 以色列子孙起行，第三天来到他们的城。他们的城是基遍、基非拉、比录和基列·耶琳。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 15:4; 撒母耳记下 21:7; 传道书 5:6"> 以色列子孙没有击杀他们，因为会众的首领已经指着耶和华以色列的上帝向他们起誓。全会众就向首领发怨言。</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 8:2; 约书亚记 9:20; 传道书 9:2"> 但所有首领对全会众说：“我们已经指着耶和华以色列的上帝向他们起誓，现在不可动他们。</span>
<span className="v" id="v20" data-v="20" data-xref="玛拉基书 3:5; 箴言 20:25; 提摩太前书 1:10"> 我们要这样待他们，让他们活着；免得因我们向他们所起的誓，有忿怒临到我们。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 29:11; 约书亚记 9:27; 约书亚记 9:23"> 首领对会众说：“让他们活着。”这样，他们就照首领论到他们所说的，为全会众劈柴打水。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 9:6; 约书亚记 9:16; 创世记 3:13–14"> 约书亚召了他们来，对他们说：“你们既然住在我们中间，为什么欺骗我们，说‘我们离你们很远’呢？</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 9:21; 创世记 9:25–26; 约书亚记 9:27"> 现在你们受咒诅；你们中间必不断有人作奴仆，就是为我上帝的殿劈柴打水的人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 20:15–17; 申命记 7:1–2; 出埃及记 23:31–33"> 他们回答约书亚说：“因为确实有人告诉你的仆人，耶和华你的上帝怎样吩咐祂的仆人摩西，要把全地赐给你们，并从你们面前灭绝这地所有的居民。所以我们因你们的缘故，为自己的性命非常惧怕，才做了这事。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 16:6; 士师记 10:15; 耶利米书 26:14"> 现在，看哪，我们在你手中；你看怎样待我们为善、为正，就怎样做吧。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 于是约书亚这样待他们，从以色列子孙手中救出他们，以色列子孙就没有杀他们。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5"> 那一天，约书亚使他们为会众和耶和华的坛劈柴打水，直到今日，在祂所要选择的地方。</span>
</div>
</div>

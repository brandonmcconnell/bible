<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 19:9; 创世记 49:5–7; 约书亚记 18:6–11"> 第二签为西缅抽出，就是为西缅子孙的支派，按着他们的宗族。他们的产业在犹大子孙产业的中间。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 4:28–30; 尼希米记 11:26–30; 创世记 21:31"> 他们所得的产业有别是巴（或示巴）、摩拉大、</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 15:28–29"> 哈萨书亚、巴拉、以森、</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 15:30; 士师记 1:17"> 伊利多拉、比土力、何珥玛、</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 30:1; 历代志上 4:31; 约书亚记 15:31"> 洗革拉、伯玛加博、哈萨苏撒、</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 15:32"> 伯利巴勿和沙鲁险，共十三座城，以及所属的村庄；</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:42; 约书亚记 15:32; 民数记 33:19–20"> 又有亚因、利门、以帖和亚珊，共四座城，以及所属的村庄；</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 4:33; 撒母耳记上 30:27"> 还有这些城四围所有的村庄，直到巴拉比珥，就是南地的拉玛。这是西缅子孙支派的产业，按着他们的宗族。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 8:14–15; 出埃及记 16:18"> 西缅子孙的产业是从犹大子孙所得的分中取出来的；因为犹大子孙的分对他们来说太多了。因此西缅子孙在他们产业的中间得了产业。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 18:11; 约书亚记 18:6; 创世记 49:13"> 第三签为西布伦子孙抽出，按着他们的宗族。他们产业的边界到了撒立。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 12:22; 历代志上 6:68; 列王纪上 4:12"> 他们的边界向西上去，直到玛拉拉，达到大巴设，又达到约念前面的溪。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 4:6; 历代志上 6:72; 约书亚记 19:22"> 又从撒立转向日出方向的东边，到基斯绿他泊的边界；又出去到大比拉，上到雅非亚。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 14:25"> 从那里向东经过迦特希弗，到以特加汛；又出去到临门，就是延伸到尼亚的地方。</span>
<span className="v" id="v14" data-v="14"> 边界在北面绕到哈拿顿，止于伊弗他伊勒谷；</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 11:1; 路得记 1:19; 撒母耳记下 23:15"> 还有加他、拿哈拉、伸仑、以大拉和伯利恒，共十二座城，以及所属的村庄。</span>
<span className="v" id="v16" data-v="16"> 这些城和所属的村庄，就是西布伦子孙的产业，按着他们的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 第四签为以萨迦抽出，就是为以萨迦子孙，按着他们的宗族。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 28:4; 列王纪下 4:8; 何西阿 1:4–5"> 他们的边界到耶斯列、基苏律、书念、</span>
<span className="v" id="v19" data-v="19"> 哈弗连、示按、亚拿哈拉、</span>
<span className="v" id="v20" data-v="20"> 拉璧、基善、亚别、</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 21:29"> 利篾、隐干宁、隐哈大和伯帕薛。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 4:6; 历代志上 6:77; 约书亚记 19:38"> 边界达到他泊、沙哈洗玛和伯示麦；他们的边界止于约旦河，共十六座城，以及所属的村庄。</span>
<span className="v" id="v23" data-v="23"> 这些城和所属的村庄，就是以萨迦子孙支派的产业，按着他们的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 2:26–38"> 第五签为亚设子孙支派抽出，按着他们的宗族。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 12:20; 约书亚记 11:1; 撒母耳记下 2:16"> 他们的边界有黑甲、哈利、比田、押煞、</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王纪上 18:42; 以赛亚书 33:9"> 亚拉米勒、亚末、米沙勒；向西达到迦密，又到西曷立纳。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 9:13; 撒母耳记上 5:2"> 又转向日出方向，到伯大衮，达到西布伦，又到北边伊弗他伊勒谷，到伯以墨和尼业；又从左边出去到迦步勒，</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 1:31; 约书亚记 11:8; 以赛亚书 23:12"> 以及以伯仑、利合、哈们和加拿，直到大西顿。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:31; 撒母耳记下 5:11; 弥迦书 1:14"> 边界转到拉玛，到坚固城推罗；边界又转到何萨，止于海边，靠近亚革悉一带；</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 21:31; 列王纪上 20:30; 撒母耳记上 4:1"> 又有乌玛、亚弗和利合，共二十二座城，以及所属的村庄。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 33:24–25; 创世记 49:20"> 这些城和所属的村庄，就是亚设子孙支派的产业，按着他们的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 第六签为拿弗他利子孙抽出，就是为拿弗他利子孙，按着他们的宗族。</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 4:11"> 他们的边界是从希利弗，从撒拿音的橡树、亚大米尼吉和雅比聂，到拉共，止于约旦河。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 33:23; 约书亚记 19:12; 约书亚记 19:22"> 边界向西转到亚斯纳他泊，又从那里出去到户割；南边达到西布伦，西边达到亚设，向日出方向达到约旦河边称为“犹大”的地方。</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 11:2; 列王纪上 8:65; 创世记 10:18"> 坚固城有西丁、侧耳、哈末、拉甲、基尼烈、</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 11:1; 约书亚记 11:20; 约书亚记 12:19"> 亚大玛、拉玛、夏琐、</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 20:7; 约书亚记 12:22"> 基低斯、以得来、隐夏琐、</span>
<span className="v" id="v38" data-v="38"> 以利稳、密大伊勒、何利、伯亚纳和伯示麦，共十九座城，以及所属的村庄。</span>
<span className="v" id="v39" data-v="39"> 这些城和所属的村庄，就是拿弗他利子孙支派的产业，按着他们的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 第七签为但子孙支派抽出，按着他们的宗族。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 2:53; 约书亚记 15:33; 士师记 13:25"> 他们产业的边界有琐拉、以实陶、伊珥示麦、</span>
<span className="v" id="v42" data-v="42" data-xref="士师记 1:35; 约书亚记 10:12; 约书亚记 21:24"> 沙拉宾、亚雅仑、伊提拉、</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 38:12; 撒母耳记上 5:10; 士师记 14:1–2"> 以伦、亭拿、以革伦、</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 15:27; 列王纪上 16:15; 列王纪上 9:18"> 伊利提基、基比顿、巴拉、</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 21:24"> 耶户、比尼比拉、迦特临门、</span>
<span className="v" id="v46" data-v="46" data-xref="约拿 1:3; 使徒行传 9:36; 历代志下 2:16"> 美耶昆和拉昆，以及约帕对面的边界。</span>
<span className="v" id="v47" data-v="47" data-xref="士师记 1:34–35; 士师记 18:1–29"> 但子孙的边界越过了他们；因为但子孙上去攻打利善，夺取那城，用刀刃击杀城中的人，占有那城，住在那里，并按他们祖先但的名字，给利善起名叫但。</span>
<span className="v" id="v48" data-v="48"> 这些城和所属的村庄，就是但子孙支派的产业，按着他们的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以西结 45:7–8"> 这样，他们按边界分完了那地为产业。以色列子孙在他们中间把一份产业给了嫩的儿子约书亚。</span>
<span className="v" id="v50" data-v="50" data-xref="约书亚记 24:30; 士师记 2:9; 历代志上 7:24"> 他们照耶和华的命令，把约书亚所求的城，就是以法莲山地的亭拿西拉，给了他；他修建那城，并住在那里。</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 18:10; 约书亚记 14:1; 约书亚记 18:1"> 这些就是祭司以利亚撒、嫩的儿子约书亚，以及以色列子孙各支派父家的首领，在示罗会幕门口，在耶和华面前，抽签所分的产业。这样，他们分完了那地。</span>

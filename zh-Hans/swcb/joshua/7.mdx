<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 22:20; 传道书 9:18; 历代志上 2:6–7"> 以色列子孙却在当灭之物上犯了罪；因为犹大支派中，谢拉的儿子撒底，撒底的儿子迦米，迦米的儿子亚干，取了一些当灭之物。因此，耶和华的怒气向以色列子孙发作。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:12; 何西阿 4:15; 撒母耳记上 14:23"> 约书亚从耶利哥派人到艾城去；艾城在伯亚文旁边，伯特利的东边。他对他们说：“你们上去窥探那地。”<br />那些人就上去窥探艾城。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 6:11–12; 路加福音 13:24; 彼得后书 1:5"> 他们回到约书亚那里，对他说：“不必让所有百姓都上去，只要约有二三千人上去攻打艾城就可以了。不要让所有百姓都在那里劳累，因为他们人少。”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:25; 利未记 26:17; 申命记 32:30"> 于是百姓中约有三千人上到那里，却在艾城人面前逃跑了。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:11; 约书亚记 2:9; 利未记 26:36"> 艾城人击杀了他们约三十六人，从城门前追赶他们直到示巴琳，又在下坡击杀他们。百姓的心就融化，变得像水一样。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 37:29; 创世记 37:34; 启示录 18:19"> 约书亚撕裂衣服，他和以色列的长老在耶和华的约柜前脸伏于地，直到晚上；他们把尘土撒在头上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:5; 列王纪下 3:10; 马太福音 17:20"> 约书亚说：“唉！主耶和华啊，你为什么竟领这百姓过约旦河，把我们交在亚摩利人手中，使我们灭亡呢？但愿我们满足于住在约旦河那边！</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:5–6; 以斯拉记 9:10; 哈巴谷 2:1"> 主啊，以色列既在仇敌面前转背逃跑，我还能说什么呢？</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 32:12; 诗篇 83:4; 以西结 36:22–23"> 迦南人和这地所有的居民听见了，就会围困我们，把我们的名从地上除灭。那时，你要为你的大名做什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:22; 出埃及记 14:15; 撒母耳记上 16:1"> 耶和华对约书亚说：“起来！你为什么这样脸伏于地呢？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:1–2; 希伯来书 4:13; 约书亚记 6:17–19"> 以色列犯了罪；他们确实违背了我所吩咐他们的约；他们确实取了一些当灭之物，又偷窃，又欺骗，甚至把它放在自己的物品中。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 5:4–5; 以赛亚书 59:2; 约书亚记 6:18"> 因此，以色列子孙不能在仇敌面前站立。他们在仇敌面前转背逃跑，因为他们成了当灭的。你们若不把那当灭之物从你们中间毁灭，我就不再与你们同在。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 约书亚记 3:5; 马太福音 7:5"> 起来！使百姓分别为圣，并说：‘你们要使自己分别为圣，预备明天，因为耶和华——以色列的上帝这样说：“以色列啊，你们中间有当灭之物。你们若不把那当灭之物从你们中间除去，就不能在仇敌面前站立。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 约拿 1:7; 约书亚记 7:17–18"> 所以，到了早晨，你们要按支派近前来。耶和华所选中的支派，要按宗族近前来；耶和华所选中的宗族，要按家族近前来；耶和华所选中的家族，要一个一个近前来。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 34:7; 撒母耳记上 14:38–39; 士师记 20:6"> 被查出有当灭之物的人，连同他一切所有的，都要用火焚烧，因为他违背了耶和华的约，并且在以色列中做了可耻的事。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:60; 约书亚记 3:1; 创世记 22:3"> 于是约书亚清早起来，使以色列按他们的支派近前来；犹大支派被选中了。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:20; 历代志上 2:4–7; 创世记 38:30"> 他使犹大的宗族近前来，就选中了谢拉人的宗族；他使谢拉人的宗族一个一个近前来，撒底被选中了。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 32:23; 使徒行传 5:1–10; 撒母耳记上 14:42"> 他使撒底的家族一个一个近前来，犹大支派中，谢拉的儿子撒底，撒底的儿子迦米，迦米的儿子亚干被选中了。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 6:5; 耶利米书 13:16; 约翰福音 9:24"> 约书亚对亚干说：“我儿，请你将荣耀归给耶和华——以色列的上帝，并向祂认罪。现在告诉我你做了什么！不要向我隐瞒！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 38:18; 约伯记 33:27; 创世记 42:21"> 亚干回答约书亚说：“我确实得罪了耶和华——以色列的上帝。我所做的是这样：</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:15; 诗篇 119:37; 约翰一书 2:15–16"> 我在掠物中看见一件美丽的巴比伦外袍、二百舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司。">a</a></sup>银子，和一条重五十舍客勒的金条，就贪爱这些东西，把它们取了。看哪，它们藏在我帐篷中间的地里，银子在下面。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 于是约书亚派使者，他们就跑到帐篷那里。看哪，那些东西藏在他的帐篷里，银子在下面。</span>
<span className="v" id="v23" data-v="23"> 他们从帐篷中间取出来，带到约书亚和以色列全体子孙那里，摆在耶和华面前。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前书 6:9–10; 约书亚记 7:26"> 约书亚和与他同在的全以色列，带着谢拉的子孙亚干、银子、外袍、金条，以及亚干的儿子、女儿、牛、驴、羊、帐篷和他一切所有的，把他们带到亚割谷。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:18; 历代志上 2:7; 利未记 24:14"> 约书亚说：“你为什么使我们受连累呢？耶和华今天必使你受连累。”全以色列用石头打他，又用火焚烧他们，并用石头打他们。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 65:10; 何西阿 2:15; 申命记 13:17"> 他们在他身上堆起一大堆石头，直到今日还在。耶和华就转离祂烈怒的怒气。因此，那地方名叫“亚割谷”，直到今日。</span>
</div>

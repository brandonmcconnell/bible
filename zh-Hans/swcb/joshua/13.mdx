<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:10; 申命记 31:3; 约书亚记 24:29"> 约书亚年纪老迈，岁数已高。耶和华对他说：“你年纪老迈，岁数已高，还有许多土地尚未占领。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 13:11; 撒母耳记上 27:8; 约珥 3:4"> “这是还剩下的土地：非利士人的各地区，以及基述人的全地；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 2:23; 士师记 3:3; 耶利米书 2:18"> 从埃及前面的西曷起，直到北边以革伦的边界，这地算为迦南人的；非利士人的五个首领，就是迦萨人、亚实突人、亚实基伦人、迦特人、以革伦人；还有南方的亚卫人；</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 19:30; 撒母耳记上 4:1; 士师记 1:34–36"> 迦南人的全地，以及属于西顿人的米亚拉，直到亚弗，直到亚摩利人的边界；</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 5:18; 约书亚记 12:7; 诗篇 83:7"> 又有迦巴勒人的地，以及日出方向的整个黎巴嫩，从黑门山下的巴力迦得，直到哈马口；</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 11:8; 约书亚记 23:13; 士师记 2:21–23"> 从黎巴嫩到米斯利弗玛音，山地所有的居民，就是所有西顿人，我必把他们从以色列人面前赶出去。你只要照我所吩咐你的，把这地分给以色列为产业。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 26:53–56; 民数记 33:54; 以西结 48:23–29"> 现在，你要把这地分给九个支派和玛拿西半个支派为产业。”</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 12:6; 申命记 3:12–17; 约书亚记 22:4"> 吕便人和迦得人与玛拿西另半个支派一起，已经领受了他们的产业，就是耶和华的仆人摩西在约旦河东边赐给他们的，正如摩西赐给他们的：</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 13:16; 民数记 21:30; 约书亚记 12:2"> 从亚嫩谷边的亚罗珥，以及谷中的城，并从米底巴的整个平原，直到底本；</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–26"> 还有在希实本作王的亚摩利王西宏所有的城，直到亚扪子孙的边界；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 2:23; 约书亚记 12:2–5; 申命记 4:47–48"> 还有基列，基述人和玛迦人的边界，整个黑门山，以及整个巴珊，直到撒迦；</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 12:4; 约书亚记 14:3–4; 民数记 21:23–35"> 又有噩在巴珊的全王国，他曾在亚斯她录和以得来作王；他是利乏音人残余中所剩下的。摩西攻击这些人，把他们赶了出去。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:12–13; 约书亚记 13:11; 民数记 33:55"> 然而，以色列人没有赶出基述人和玛迦人；基述和玛迦仍住在以色列中，直到今日。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:20–24; 约书亚记 14:3–4; 申命记 18:1–2"> 只是摩西没有把产业赐给利未支派。献给耶和华以色列上帝的火祭，是他的产业，正如祂对他说的。</span>
<span className="v" id="v15" data-v="15"> 摩西按着吕便子孙的家族，把产业赐给他们的支派。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 13:9; 约书亚记 12:2; 以赛亚书 16:7–9"> 他们的边界是从亚嫩谷边的亚罗珥，以及谷中的城，并靠近米底巴的整个平原；</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 22:41; 民数记 32:38; 民数记 21:19"> 希实本和在平原上属它的所有城；底本、巴末巴力、伯巴力勉、</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 约书亚记 21:36–37; 历代志上 6:78–79"> 雅杂、基底莫、米法押、</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 32:37–38"> 基列亭、西比玛、谷中山上的细列沙辖、</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 12:3; 申命记 4:46; 以西结 25:9"> 伯毗珥、毗斯迦山坡、伯耶西末、</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 31:8; 申命记 3:10; 申命记 2:30–36"> 平原上的所有城，以及在希实本作王的亚摩利王西宏的全王国。摩西击杀了西宏，也击杀了住在那地的米甸首领以未、利金、苏珥、户珥和利巴；他们都是西宏的首领。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 31:8; 犹大书 1:11; 彼得后书 2:15"> 以色列人也在所杀的人中，用刀杀了比珥的儿子占卜者巴兰。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 吕便子孙的边界是约旦河沿岸。这就是吕便子孙按着他们的家族所得的产业，包括这些城和所属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 32:34–36"> 摩西按着迦得子孙的家族，把产业赐给迦得支派，就是迦得子孙。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 撒母耳记下 11:1; 民数记 32:35"> 他们的边界是雅谢、基列的所有城，以及亚扪子孙之地的一半，直到拉巴附近的亚罗珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 17:27; 撒母耳记下 2:8; 士师记 10:17"> 又从希实本到拉末米斯巴和比多宁；从玛哈念到底璧的边界；</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 32:36; 民数记 34:11; 创世记 33:17"> 又有谷中的伯哈兰、伯宁拉、疏割和撒分，就是希实本王西宏王国其余的地，以及约旦河沿岸，直到约旦河东边基尼烈海的尽头。</span>
<span className="v" id="v28" data-v="28"> 这就是迦得子孙按着他们的家族所得的产业，包括这些城和所属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 摩西把产业赐给玛拿西半个支派。这是按着玛拿西子孙半个支派的家族所赐的。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 13:26; 申命记 3:13–15; 民数记 32:39–41"> 他们的边界是从玛哈念起，包括整个巴珊、巴珊王噩的全王国，以及在巴珊的睚珥所有村庄，共六十座城。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 12:4; 民数记 32:39–40"> 基列的一半，以及亚斯她录和以得来，就是噩在巴珊王国的城，归给玛拿西儿子玛吉的子孙，就是按着他们的家族归给玛吉子孙的一半。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 这些就是摩西在摩押平原、约旦河东、耶利哥对面所分配的产业。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 18:7; 约书亚记 13:14; 申命记 18:1–2"> 但摩西没有把产业赐给利未支派。耶和华以色列的上帝是他们的产业，正如祂对他们说的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 27:2; 约书亚记 3:17"> 全体国民都完全过了约旦河以后，耶和华对约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 3:12; 民数记 1:4–15; 列王纪上 18:31"> “你要从民中选取十二个人，每个支派一人，</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 4:19–20; 约书亚记 3:13; 约书亚记 4:8"> 吩咐他们说：‘你们要从约旦河中，就是祭司脚站稳的地方，取十二块石头，带着它们过去，放在你们今晚住宿的地方。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 4:2; 马可福音 3:14–19"> 于是约书亚召集他从以色列人中预备的那十二个人，每个支派一人。</span>
<span className="v" id="v5" data-v="5"> 约书亚对他们说：“你们要走到耶和华你们上帝的约柜前面，进入约旦河中；你们每个人都要按以色列人支派的数目，拿起一块石头扛在肩上；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:14; 约书亚记 4:21; 诗篇 44:1"> 这可以在你们中间作为记号。将来你们的儿女问：‘这些石头对你们有什么意思？’</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:14; 民数记 16:40; 出埃及记 28:12"> 你们就要告诉他们：‘因为约旦河的水在耶和华的约柜前断绝了。约柜过约旦河的时候，约旦河的水就断绝了。这些石头要永远作为以色列人的纪念。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 4:2–5; 约书亚记 1:16–18; 约书亚记 4:20"> 以色列人照约书亚所吩咐的做了；他们按耶和华对约书亚所说的，照以色列人支派的数目，从约旦河中取了十二块石头。他们把石头带到住宿的地方，放在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 7:12; 士师记 1:26; 历代志下 5:9"> 约书亚又在约旦河中，就是抬约柜的祭司脚站立的地方，立了十二块石头；那些石头直到今日还在那里。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 3:13; 诗篇 119:60; 箴言 27:1"> 抬约柜的祭司站在约旦河中，直到耶和华吩咐约书亚对百姓说的一切事都完成，正如摩西吩咐约书亚的一切；百姓就急速过去。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 3:8; 约书亚记 4:18; 约书亚记 3:17"> 全体百姓都完全过去以后，耶和华的约柜和祭司也在百姓面前过去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 32:20–32; 约书亚记 1:14"> 吕便人、迦得人和玛拿西半个支派的人，照摩西对他们所说的，带着兵器在以色列人前面过去。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:11; 耶利米书 39:5; 耶利米书 52:8"> 约有四万人，预备好兵器，可以作战，在耶和华面前过去，到耶利哥的平原去争战。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 3:7; 历代志下 30:12; 列王纪上 3:28"> 那一天，耶和华在全以色列眼前使约书亚尊大；在他一生的日子里，他们敬畏他，像敬畏摩西一样。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华对约书亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:19; 出埃及记 25:16–22; 约书亚记 3:3–6"> “你要吩咐抬约柜的祭司，从约旦河里上来。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 8:16–18; 使徒行传 16:35–39; 使徒行传 16:23"> 于是约书亚吩咐祭司说：“从约旦河里上来！”</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 3:15; 历代志上 12:15; 约书亚记 3:13"> 抬耶和华约柜的祭司从约旦河中上来；祭司的脚掌一踏上干地，约旦河的水就回到原处，像从前一样涨过两岸。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:9; 弥迦书 6:5; 出埃及记 12:2–3"> 正月初十，百姓从约旦河里上来，在耶利哥东边的边界，在吉甲安营。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:3; 约书亚记 4:8"> 约书亚把他们从约旦河中取出的那十二块石头立在吉甲。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 4:6; 诗篇 145:4–7; 诗篇 105:2–5"> 他对以色列人说：“将来你们的儿女问他们的父亲：‘这些石头是什么意思？’</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:17; 以赛亚书 51:10; 以赛亚书 44:27"> 那时你们要让你们的儿女知道，说：‘以色列曾在干地上过了这约旦河。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:21; 以赛亚书 43:16; 以赛亚书 63:12–14"> 因为耶和华你们的上帝在你们面前使约旦河的水干了，直到你们都过去，正如耶和华你们的上帝从前在我们面前使红海干了，直到我们都过去一样，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 106:8; 诗篇 89:13; 列王纪上 8:42–43"> 为要使地上万民都知道耶和华的手大有能力，也使你们永远敬畏耶和华你们的上帝。’”</span>
</div>
</div>

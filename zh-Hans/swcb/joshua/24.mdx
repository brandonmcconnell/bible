<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="JOS" data-book-slug="joshua" data-book-name="约书亚记" data-chapter="24" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:2; 撒母耳记上 10:19; 创世记 33:18–19"> 约书亚把以色列所有支派聚集到示剑，又召了以色列的长老、族长、审判官和官长来；他们就站在上帝面前。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:15; 以西结 16:3; 创世记 31:30"> 约书亚对全体百姓说：“耶和华——以色列的上帝这样说：‘古时你们的祖先住在大河那边，就是亚伯拉罕的父亲、拿鹤的父亲他拉；他们事奉别的神。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1–4; 创世记 21:2–3; 使徒行传 7:2–3"> 我从大河那边带出你们的祖先亚伯拉罕，领他走遍迦南全地，又使他的子孙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“种子”">a</a></sup>增多，并把以撒赐给他。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 36:8; 申命记 2:5; 创世记 25:24–26"> 我把雅各和以扫赐给以撒；我把西珥山赐给以扫为业。雅各和他的儿女下到埃及去了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:10; 出埃及记 7:1–12; 诗篇 105:26–36"> “‘我差遣摩西和亚伦，又照我在埃及人中所行的降灾给埃及；后来我把你们带出来。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 7:36; 希伯来书 11:29; 以赛亚书 63:12–13"> 我把你们的祖先从埃及带出来；你们到了海边，埃及人用战车和骑兵追赶你们的祖先，直到红海。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:34; 出埃及记 14:10; 出埃及记 14:20"> 他们向耶和华呼求，祂就在你们和埃及人之间安置黑暗，又使海水淹没埃及人，遮盖他们；你们亲眼看见我在埃及所行的事。你们在旷野住了许多日子。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 21:21–35; 诗篇 135:10–11; 尼希米记 9:22"> “‘我领你们进入住在约旦河那边的亚摩利人的土地。他们与你们争战，我把他们交在你们手中。你们占有了他们的土地，我也从你们面前除灭了他们。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 11:25; 弥迦书 6:5; 民数记 22:2"> 那时，摩押王、西拨的儿子巴勒起来攻击以色列；他派人召比珥的儿子巴兰来咒诅你们，</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 23:5; 民数记 24:5–10; 以赛亚书 54:17"> 但我不肯听巴兰；所以他反而祝福你们。这样，我把你们从他的手中救出来。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 4:10–12; 约书亚记 3:14–17; 诗篇 114:5"> “‘你们过了约旦河，来到耶利哥。耶利哥人与你们争战，亚摩利人、比利洗人、迦南人、赫人、革迦撒人、希未人和耶布斯人也与你们争战；我把他们交在你们手中。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:20; 出埃及记 23:28; 诗篇 44:3–6"> 我差遣黄蜂在你们前面，把他们，就是亚摩利人的两个王，从你们面前赶出去；这不是靠你们的刀，也不是靠你们的弓。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 6:10–12; 申命记 8:7; 约书亚记 21:45"> 我赐给你们并非你们劳作得来的土地，和并非你们建造的城邑，你们就住在其中。你们吃并非你们栽种的葡萄园和橄榄园的出产。’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 12:24; 申命记 10:12; 创世记 35:2"> “现在，你们要敬畏耶和华，以诚实和真诚事奉祂。你们要除掉你们祖先在大河那边和在埃及所事奉的神，事奉耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:21; 约翰福音 6:67–68; 路得记 1:15–16"> 如果你们认为事奉耶和华不好，今天就选择你们所要事奉的是谁：是你们祖先在大河那边所事奉的神呢，还是你们所居之地亚摩利人的神呢？至于我和我家，我们必事奉耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 10:38–39; 撒母耳记上 12:23; 罗马书 6:2"> 百姓回答说：“我们绝不离弃耶和华去事奉别的神；</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 19:4; 以赛亚书 63:7–14; 以赛亚书 46:4"> 因为耶和华我们的上帝把我们和我们的祖先从埃及地、从为奴之家领上来，在我们眼前行了那些大神迹，并在我们所走的一切路上，在我们经过的各族民中间保护了我们。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 4:2; 出埃及记 10:2; 诗篇 116:16"> 耶和华又从我们面前赶出各族民，就是住在这地的亚摩利人。所以我们也要事奉耶和华，因为祂是我们的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 5:16; 出埃及记 23:21; 诗篇 99:9"> 约书亚对百姓说：“你们不能事奉耶和华，因为祂是圣洁的上帝；祂是忌邪的上帝。祂必不赦免你们的悖逆和你们的罪。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 以西结 18:24; 历代志上 28:9"> 如果你们离弃耶和华，去事奉外族的神，祂在善待你们之后，必转而降祸给你们，灭绝你们。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:19; 以赛亚书 44:5; 申命记 5:27–28"> 百姓对约书亚说：“不，我们一定要事奉耶和华。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 119:173; 诗篇 119:11; 约伯记 15:6"> 约书亚对百姓说：“你们自己选择耶和华，要事奉祂；你们就是指证自己的见证人。”<br />他们说：“我们是见证人。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:16–18; 约书亚记 24:14; 希伯来书 12:28–29"> “现在，你们要除掉你们中间外族的神，把你们的心归向耶和华——以色列的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 24:7; 出埃及记 24:3; 申命记 5:27–29"> 百姓对约书亚说：“我们必事奉耶和华我们的上帝，也必听从祂的声音。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="尼希米记 9:38; 历代志下 23:16; 出埃及记 15:25"> 那一天，约书亚就与百姓立约，并在示剑为他们制定律例和典章。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 9:6; 创世记 35:4; 约书亚记 4:20–24"> 约书亚把这些话写在上帝律法书上；又拿了一块大石头，立在耶和华圣所旁的橡树下。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 约书亚记 22:34; 约书亚记 22:27–28"> 约书亚对全体百姓说：“看哪，这块石头必作指证我们的见证，因为它听见了耶和华对我们所说的一切话。因此，它也必作指证你们的见证，免得你们不认你们的上帝。”</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 2:6"> 于是约书亚打发百姓离去，各归自己的产业。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 2:8; 提摩太后书 4:7–8; 申命记 34:5"> 这些事以后，耶和华的仆人、嫩的儿子约书亚死了，享年一百一十岁。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:50; 士师记 2:9; 撒母耳记下 23:30"> 人们把他葬在他产业的境内，在以法莲山地的亭拿西拉，就是迦实山的北边。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 2:7; 申命记 31:13; 申命记 11:2"> 约书亚在世的所有日子，以及约书亚死后仍在世的长老们的所有日子，以色列都事奉耶和华；这些长老知道耶和华为以色列所行的一切事。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 50:25; 创世记 33:19; 出埃及记 13:19"> 以色列人从埃及带上来的约瑟骸骨，人们葬在示剑，就是雅各从示剑的父亲哈抹的子孙手中用一百块银子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希伯来文：克西塔。克西塔是一种银币。">b</a></sup>买来的那块田里；这块地成了约瑟子孙的产业。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 22:13; 出埃及记 6:25; 以赛亚书 57:1–2"> 亚伦的儿子以利亚撒死了，人们把他葬在他儿子非尼哈所得的山丘上；那山丘是在以法莲山地赐给他的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:29; 创世记 41:51; 创世记 50:23"> 这是给玛拿西支派的阄分；玛拿西是约瑟的长子。玛拿西的长子玛吉，是基列的父亲；因为他是战士，所以得了基列和巴珊。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 7:18; 民数记 26:29–32; 士师记 6:11"> 这也是给玛拿西其余子孙按宗族所得的：亚比以谢的子孙、希勒的子孙、亚斯列的子孙、示剑的子孙、希弗的子孙、示米大的子孙。这些按宗族都是约瑟的儿子玛拿西的男性子孙。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 27:1; 民数记 26:33; 民数记 36:2–11"> 但西罗非哈是希弗的儿子，希弗是基列的儿子，基列是玛吉的儿子，玛吉是玛拿西的儿子；西罗非哈没有儿子，只有女儿。他女儿的名字是：玛拉、挪阿、曷拉、密迦和得撒。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 14:1; 民数记 27:5–7; 加拉太书 3:28"> 她们来到祭司以利亚撒、嫩的儿子约书亚和众首领面前，说：“耶和华曾吩咐摩西，在我们的弟兄中把产业给我们。”因此，约书亚照耶和华的命令，在她们父亲的弟兄中把产业给了她们。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 17:2–3; 民数记 32:30–42; 约书亚记 13:29–31"> 除了约旦河东的基列地和巴珊地以外，玛拿西还分得十份；</span>
<span className="v" id="v6" data-v="6"> 因为玛拿西的女儿们在他的儿子们中间得了产业。基列地属于玛拿西其余的儿子。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:21; 约书亚记 20:7; 约书亚记 24:32"> 玛拿西的边界是从亚设到示剑前面的密米他；边界向右延伸，到隐·他普亚的居民那里。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 16:8; 约书亚记 15:34; 约书亚记 12:17"> 他普亚地属于玛拿西；但玛拿西边界上的他普亚属于以法莲子孙。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 16:3; 约书亚记 19:29; 约书亚记 16:8–9"> 边界下到迦拿溪，在溪的南边。这些城在玛拿西的城邑中属于以法莲。玛拿西的边界在溪的北边，尽于海。</span>
<span className="v" id="v10" data-v="10"> 南边是以法莲的，北边是玛拿西的，海是玛拿西的边界。他们北接亚设，东接以萨迦。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 7:29; 列王纪下 9:27; 士师记 5:19"> 玛拿西在以萨迦和亚设境内，也有伯善和所属的乡镇、以伯莲和所属的乡镇、多珥及所属乡镇的居民、隐多珥及所属乡镇的居民、他纳及所属乡镇的居民，以及米吉多及所属乡镇的居民。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 1:27–28; 出埃及记 23:29–33; 罗马书 6:12–14"> 可是玛拿西的子孙不能赶出那些城的居民；迦南人坚持要住在那地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 16:10; 腓立比书 4:13; 士师记 1:35"> 以色列子孙强盛起来的时候，就使迦南人服苦役，却没有把他们全然赶出去。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 26:34–37; 创世记 48:19; 创世记 48:22"> 约瑟的子孙对约书亚说：“耶和华既然直到如今这样赐福给我们，使我们族大人多，你为什么只给我一个阄、一个份作为产业呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 13:7; 创世记 14:5; 路加福音 12:48"> 约书亚对他们说：“如果你们是人数众多的民，就上森林去，在比利洗人和利乏音人之地为自己开垦土地，因为以法莲山地对你们太狭窄了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:12; 士师记 4:3; 士师记 1:19"> 约瑟的子孙说：“山地不够我们用；凡住在谷地的迦南人都有铁车，包括在伯善和所属乡镇的人，以及在耶斯列谷的人。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 约书亚对约瑟家，就是对以法莲和玛拿西说：“你们是人数众多的民，又大有力量；你们不该只有一个阄分。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:6; 罗马书 8:31; 民数记 14:6–9"> 山地也要归你们。虽然它是森林，你们也要砍伐；它最远的境界都要归你们。因为你们必赶出迦南人，虽然他们有铁车，虽然他们强盛。”</span>
</div>

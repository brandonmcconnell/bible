<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:31; 雅各书 2:25; 马太福音 1:5"> 嫩的儿子约书亚从什亭暗中派出两个人作探子，说：“你们去察看那地，包括耶利哥。”他们就去了，来到一个名叫喇合的妓女家里，在那里过夜。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:13; 但以理 4:35; 箴言 21:30"> 有人告诉耶利哥王说：“看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”源自“הִנֵּה”，意思是看、注意、观察、看见或凝视。它常用作感叹词。">a</a></sup>今夜有以色列人中的几个人来到这里，要窥探这地。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:3; 创世记 42:9–12; 使徒行传 12:6"> 耶利哥王派人去见喇合，说：“把那些来到你这里、进了你家的人带出来；因为他们来是要窥探全地。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 6:19; 撒母耳记下 17:19–20; 撒母耳记下 16:18–19"> 那女人却带着那两个人，把他们藏了起来。然后她说：“不错，那些人来过我这里，可是我不知道他们是从哪里来的。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 50:20; 以西结 47:12; 启示录 21:25"> 天黑、城门快要关闭的时候，那些人出去了。他们往哪里去，我不知道。你们快去追赶他们，也许能追上。”</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 11:23; 雅各书 2:25; 歌罗西书 3:3"> 其实她已经带他们上了屋顶，把他们藏在屋顶上摆放整齐的麻秆下面。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 3:28; 约书亚记 2:5; 士师记 12:5"> 那些人沿着通往约旦河渡口的路追赶他们。追赶的人一出去，城门就关上了。</span>
<span className="v" id="v8" data-v="8"> 两个探子还没有躺下，喇合就上屋顶到他们那里，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 23:27; 申命记 2:25; 约书亚记 2:11"> 对他们说：“我知道耶和华已经把这地赐给你们了，你们带来的恐惧已经临到我们，地上所有的居民在你们面前都胆战心惊。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:21–35; 出埃及记 15:14–16; 出埃及记 14:21–31"> 因为我们听说，你们从埃及出来的时候，耶和华怎样在你们面前使红海的水干了；又听说你们怎样对待约旦河东的两个亚摩利王，就是西宏和噩，把他们完全毁灭。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 4:39; 约书亚记 5:1; 约书亚记 7:5"> 我们一听见这些，心就融化了；因为你们的缘故，人人都丧失了勇气；因为耶和华你们的上帝，祂是天上地下的上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 2:18; 约书亚记 9:18–20; 提摩太后书 1:16–18"> 现在，请你们指着耶和华向我起誓：既然我以恩慈待你们，你们也要以恩慈待我父亲的家，并给我一个确实的凭据；</span>
<span className="v" id="v13" data-v="13"> 你们要使我的父亲、母亲、兄弟、姐妹，以及他们所有的一切都存活，救我们的性命脱离死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 5:7; 士师记 1:24–25; 创世记 24:49"> 那两个人对她说：“如果你不泄露我们的这件事，我们就以自己的性命担保你们的性命；等耶和华把这地赐给我们的时候，我们必以恩慈和诚实待你。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:25; 哥林多后书 11:33; 约书亚记 6:20"> 于是喇合用绳子把他们从窗户缒下去；因为她的房子在城墙边上，她就住在城墙上。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:25; 撒母耳记上 23:14; 诗篇 11:1"> 她对他们说：“你们往山上去，免得追赶的人遇见你们。你们要在那里躲藏三天，等追赶的人回来；然后你们就可以走自己的路。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 30:2; 撒母耳记下 21:7; 创世记 24:3–8"> 那两个人对她说：“你叫我们起的这个誓，我们可以不担罪。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 6:23; 约书亚记 2:21; 约书亚记 2:12–13"> 看哪，我们进入这地的时候，你要把这条朱红线绳系在你缒我们下去的窗户上，并且要把你的父亲、母亲、兄弟和你父亲全家都聚集到你家里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 27:31; 列王纪上 2:36–42; 出埃及记 12:13"> 凡走出你家门到街上的，他的血必归到自己头上，我们就不担罪；凡与你同在屋里的，若有人下手害他，他的血就归到我们头上。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 但如果你泄露我们的这件事，那么你叫我们起的誓，我们就不担罪。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 2:5; 约书亚记 2:18; 马太福音 7:24"> 她说：“就照你们所说的办吧。”于是她送他们离开，他们就走了。随后她把朱红线绳系在窗户上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 19:10–12; 撒母耳记下 17:20; 诗篇 32:6–7"> 他们走了，来到山上，在那里住了三天，直到追赶的人回来。追赶的人沿路寻找他们，却没有找到。</span>
<span className="v" id="v23" data-v="23"> 于是那两个人回来，下了山，过了河，来到嫩的儿子约书亚那里，把发生在他们身上的一切事都告诉他。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 23:31; 约书亚记 1:8; 约书亚记 2:9–11"> 他们对约书亚说：“耶和华确实已经把全地交在我们手中了；而且地上所有的居民在我们面前都胆战心惊。”</span>
</div>
</div>

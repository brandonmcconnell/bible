<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 21:8; 以赛亚书 62:6; 撒母耳记下 18:24"> 我要站在我的守望所，立在城楼上；我要瞭望，看祂要对我说什么，我又要怎样回答我的申诉。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:8; 启示录 14:13; 启示录 1:18–19"> 耶和华回答我说：“把异象写下来，清楚地写在版上，使奔跑的人也能读。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 27:14; 希伯来书 10:36–37; 以西结 12:25"> 因为这异象还有指定的时期，它急速奔向结局，必不落空。虽然迟延，仍要等候；因为它必定来到，决不耽延。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:17; 希伯来书 10:38; 加拉太书 3:11–12"> 看哪，他的心骄傲，在他里面不正直；但义人必因他的信心而活。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 5:11–12; 箴言 27:20; 箴言 20:1"> 不但如此，酒也诡诈；狂傲的人不安居，他扩张自己的欲望如阴间；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>他像死亡，不能满足，却聚集万国归自己，招聚万民归自己。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 23:7; 弥迦书 2:4; 耶利米书 50:13"> 这些人岂不都要提起比喻攻击他，用讥讽的箴言攻击他，说：‘那增添不属自己之物、靠勒索使自己富足的人有祸了！要到几时呢？’</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:1; 以赛亚书 47:11; 耶利米书 8:17"> 你的债主岂不忽然兴起，使你战栗的人岂不醒来，你就成为他们的掠物吗？</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 33:1; 哈巴谷 2:17; 耶利米书 27:7"> 因为你掠夺了许多国家，万民中所有余剩的人也必掠夺你；这是因为人的血，以及对土地、城市和其中一切居民所施的暴行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 49:16; 耶利米书 22:13–19; 以赛亚书 28:15"> 那为自己的家谋取恶利，好把自己的窝安在高处，以便脱离灾祸之手的人有祸了！</span>
<span className="v" id="v10" data-v="10" data-xref="那鸿书 1:14; 列王纪下 9:26; 耶利米书 36:31"> 你剪除许多民族，为自己的家策划羞辱，也犯罪害了自己的灵魂。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:40; 约书亚记 24:27; 约伯记 31:38–40"> 因为墙里的石头必呼喊，木构中的梁木必回应它。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 3:10; 但以理 4:27–31; 那鸿书 3:1"> 那用血建造城镇、以罪孽建立城市的人有祸了！</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 51:58; 以赛亚书 50:11; 箴言 21:30"> 看哪，万民劳碌所得归于火，列国疲乏终成虚空，这岂不是出于万军之耶和华吗？</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 11:9; 诗篇 22:27; 诗篇 72:19"> 因为大地必充满对耶和华荣耀的认识，如同水充满海洋。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 51:7; 创世记 9:22; 启示录 18:3"> “那给邻舍酒喝，倒出你那使人发热的酒，直到他们醉了，好观看他们赤裸身体的人有祸了！</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 47:3; 那鸿书 3:5–6; 以赛亚书 51:21–23"> 你满受羞辱，而不是荣耀。你也要喝，也要暴露自己！耶和华右手中的杯必传到你那里，羞辱必遮盖你的荣耀。</span>
<span className="v" id="v17" data-v="17" data-xref="哈巴谷 2:8; 诗篇 55:23; 撒迦利亚书 11:1"> 因为对黎巴嫩所施的暴行必淹没你；毁灭牲畜的事必使你惊恐；这是因为人的血，以及对土地、各城和其中居民所施的暴行。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 10:8; 哥林多前书 12:2; 以赛亚书 44:9–10"> “雕刻的偶像有什么价值呢？它不过是制造它的人雕刻出来的；铸造的偶像，就是谎言的教师，又有什么价值呢？塑造它形状的人竟倚靠它，制造哑巴偶像！</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 135:17; 耶利米书 10:4; 列王纪上 18:26–29"> 那对木头说‘醒来！’或对哑巴石头说‘起来！’的人有祸了！这能教导人吗？看哪，它包上金银，里面却全无气息。</span>
<span className="v" id="v20" data-v="20" data-xref="撒迦利亚书 2:13; 西番雅书 1:7; 诗篇 46:10"> 但耶和华在祂的圣殿中。全地都当在祂面前肃静！”</span>
</div>

## 务要传道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 10:42; 提摩太后书 4:8; 提摩太前书 5:21"> 在上帝和审判活人死人的基督耶稣面前，我凭基督的显现和祂的国郑重嘱咐你：</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:14; 提摩太前书 4:15–16; 提多书 2:15"> 务要传道，无论时机好坏，都要准备好，以百般的忍耐和教导督责人、警戒人、勉励人。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得后书 2:1–3; 提摩太后书 3:1–6; 提摩太前书 4:1–3"> 因为有一天，人们会厌倦纯正的教导，耳朵发痒，寻找许多迎合他们私欲的老师。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 7:11; 提摩太前书 1:4; 使徒行传 7:57"> 他们掩耳不听真理，反而偏向无稽之谈。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 1:8; 彼得前书 1:13; 提摩太后书 2:3"> 然而，你要谨慎行事，不怕吃苦，专心传道，尽忠职守。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:23; 腓立比书 2:17; 彼得后书 1:14–15"> 我的生命如同奉献在祭坛上的酒正倾倒出来，我离世的日子快要到了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 6:12; 哥林多前书 9:24–27; 希伯来书 12:1–2"> 那美好的仗，我打过了；当跑的路，我跑完了；所信的道，我守住了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:12; 启示录 2:10; 彼得前书 5:4"> 从此，有公义的冠冕为我预备，按公义审判的主会在祂来的那一天把它赐给我，不但会赐给我，也会赐给所有爱慕祂显现的人。</span>
</div>
</div>

## 最后的嘱咐

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:4; 提摩太后书 4:21"> 请你尽快到我这里来，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:15–16; 提摩太后书 1:15; 歌罗西书 4:14–15"> 因为底马贪爱世界，离弃我跑到帖撒罗尼迦去了。革勒士去了加拉太，提多去了挞马太，</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 12:25"> 只剩下路加一人在我身边。你要把马可一起带来，因为他在传道的工作上对我很有帮助。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 6:21; 使徒行传 20:4; 提多书 3:12"> 至于推基古，我派他到以弗所去了。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 4:11; 哥林多后书 11:27; 使徒行传 16:11"> 你来的时候，要把我在特罗亚时留给加布的外衣带来，也要带来那些书卷，特别是那些羊皮卷。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前书 1:20; 帖撒罗尼迦后书 1:6; 诗篇 28:4"> 铜匠亚历山大做了许多恶事害我，主必按他的所作所为报应他。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 3:8; 腓立比书 3:2; 马太福音 10:16–17"> 你也要提防他，因为他极力反对我们所传的道。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:60; 约翰福音 16:32; 马可福音 14:50"> 我第一次在法庭申辩的时候，没有人帮助我，众人都离弃了我，但愿他们不会因此而获罪。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 5:8; 腓立比书 1:12–14; 撒母耳记上 17:37"> 然而主站在我身旁加给我力量，使我可以把福音完整地传给所有的外族人。主把我从狮子口里救了出来。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:7; 帖撒罗尼迦后书 3:3; 犹大书 1:24–25"> 主必救我脱离一切邪恶的攻击，带我进入祂的天国。愿荣耀归给主，直到永永远远。阿们！</span>
</div>
</div>

## 问候

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 哥林多前书 16:19; 罗马书 16:3–4"> 请代我问候百基拉和亚居拉，以及阿尼色弗一家。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:4; 使徒行传 19:22; 腓立比书 2:26–27"> 以拉都留在了哥林多，我把生病的特罗非摩留在了米利都。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:9; 腓立比书 4:22; 约翰三书 1:14"> 你要尽快在冬天之前赶到这里来。友布罗、布田、利奴、革劳底亚和众弟兄姊妹都问候你。</span>
<span className="v" id="v22" data-v="22" data-xref="腓利门书 1:25; 加拉太书 6:18; 歌罗西书 4:18"> 愿主与你的灵同在！愿恩典与你们同在！</span>
</div>
</div>

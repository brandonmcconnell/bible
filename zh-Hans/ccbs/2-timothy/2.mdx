## 基督的精兵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:9–10; 以弗所书 6:10; 提摩太后书 1:7"> 我儿啊！你要靠着基督耶稣的恩典刚强起来。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太后书 1:13–14; 提摩太前书 4:6; 提摩太前书 6:12"> 以前你在许多见证人面前听过我的教导，你要把这些教导传给忠信可靠、能教导他人的人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:2–3; 雅各书 1:12; 提摩太后书 4:5"> 你要做基督耶稣的精兵，与我同受苦难。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:4; 路加福音 8:14; 彼得后书 2:20"> 当兵的若让其他事务缠身，就不能取悦征召他的上司。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 9:24–27; 启示录 3:11; 提摩太后书 4:7–8"> 同样，参加比赛的人若不遵守比赛规则，就不可能得奖。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 哥林多前书 9:7–11; 哥林多前书 3:6–9"> 辛劳的农夫理当先享受收成。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:5; 约翰一书 5:20; 路加福音 24:45"> 你要思想我说的话，因为主必使你领悟这一切。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:24; 罗马书 2:16; 哥林多前书 15:11–20"> 你要切记我所传的福音：耶稣基督是大卫的后裔，祂从死里复活了。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 1:7; 使徒行传 28:31; 提摩太后书 1:8"> 我为这福音受苦，甚至像犯人一样被囚禁，但上帝的道是囚禁不住的。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:10; 歌罗西书 1:24; 提摩太后书 2:3"> 我为了上帝的选民忍受一切痛苦，使他们可以获得在基督耶稣里的救恩和永远的荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:8; 歌罗西书 3:3–4; 罗马书 6:5"> 有真实可信的话说：<br /><span className="pl pl-1">“我们若与基督同死，</span><br /><span className="pl pl-1">就必与祂同活。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 8:17; 马太福音 10:33; 启示录 20:4"> <span className="pl pl-1">我们若忍耐到底，</span><br /><span className="pl pl-1">就必与祂一同做王。</span><br /><span className="pl pl-1">我们若不承认祂，</span><br /><span className="pl pl-1">祂也必不承认我们。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民数记 23:19; 罗马书 3:3; 帖撒罗尼迦后书 3:3"> <span className="pl pl-1">我们纵然会失信，</span><br /><span className="pl pl-1">祂仍然信实可靠，</span><br /><span className="pl pl-1">因为祂不能否认自己。”</span></span>
</div>
</div>

## 做无愧的工人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提多书 3:9–11; 提摩太后书 2:23; 提摩太后书 4:1"> 你要提醒众人这些事，在上帝面前嘱咐他们：不要为言词争辩，因为那对听见的人有害无益。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:4; 彼得后书 1:10; 提摩太前书 4:6"> 你应当竭力在上帝面前做经得起考验、问心无愧的工人，正确讲解真理之道。</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 3:9; 提摩太前书 6:20; 提摩太后书 2:14"> 要远避一切世俗的空谈，因为好空谈的人只会越来越不敬虔。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:20; 那鸿书 3:15; 雅各书 5:3"> 他们讲的话像毒疮越烂越大，许米乃和腓理徒就是例子。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:12; 提摩太前书 1:19; 希伯来书 3:10"> 他们离经背道，说复活的事已成过去，动摇了一些人的信心。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 10:14; 哥林多前书 8:3; 那鸿书 1:7"> 然而，上帝所立的坚实根基屹立不摇，这根基上刻着：“主认识那些属于祂的人”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="民数记16:5。">a</a></sup>，“凡承认主名的人都要离弃罪恶。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:21–23; 彼得前书 2:5; 提摩太前书 3:15"> 大户人家不但有金器银器，也有木器瓦器，这些器皿的用途有贵贱之分。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:17; 以弗所书 2:10; 哥林多后书 7:1"> 人若洁身自爱，远离卑贱的事，就必成为圣洁无瑕的贵重器皿，可以被主用来成就各种善事。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:11; 彼得前书 3:11; 哥林多前书 6:18"> 你要逃避年轻人的邪情私欲，要跟那些以清洁的心求告主的人一同追求公义、信心、仁爱、和平。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:14; 提多书 3:9; 提摩太前书 4:7"> 不要参与愚昧无知的辩论，因为你知道这些事只会引起纷争。</span>
<span className="v" id="v24" data-v="24" data-xref="提多书 3:2; 雅各书 1:19–20; 提摩太前书 3:2–3"> 主的奴仆不可与人争执，总要温和待人，善于教导，心存忍耐。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 11:18; 加拉太书 6:1; 提摩太前书 2:4"> 要温柔地规劝那些反对的人，也许上帝会赐给他们悔改的心，使他们明白真理，</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 3:7; 以赛亚书 49:25–26; 诗篇 124:7"> 让他们这些被魔鬼掳去、受其摆布的人能够醒悟过来，脱离魔鬼的网罗。</span>
</div>
</div>

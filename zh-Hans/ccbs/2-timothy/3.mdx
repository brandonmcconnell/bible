## 末世的情形

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 3:3; 提摩太后书 4:3; 提摩太前书 4:1–3"> 你要知道，末世必有艰难的日子，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:21; 罗马书 1:29–31; 犹大书 1:16"> 因为那时的人都自私自利、贪爱钱财、狂妄自夸、骄傲自负、毁谤亵渎、违背父母、忘恩负义、心不圣洁、</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 罗马书 1:31; 马太福音 10:21"> 冷漠无情、不愿和解、好说谗言、毫无节制、蛮横凶暴、不爱良善、</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 3:18–19; 提摩太前书 3:6; 犹大书 1:4"> 出卖朋友、任意妄为、自高自大、沉溺享乐、不爱上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 23:27–28"> 徒有敬虔的外表，却无敬虔的实质。你要避开这样的人。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:4; 彼得后书 3:17; 提多书 3:3"> 这些人溜进别人家里，哄骗那些意志薄弱的妇女。那些妇女心中充满罪恶，受各种邪情私欲驱使，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:3–4; 以弗所书 4:14; 提摩太前书 2:4"> 虽然常常学习，却始终不能明白真理。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:8–11; 启示录 2:20; 提摩太前书 6:5"> 现在这些人敌对真理，就像从前雅尼和佯庇反对摩西一样，他们的心思坏透了，他们的信仰是虚假的。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 3:8; 出埃及记 7:12; 耶利米书 28:15–17"> 不过，他们猖狂不了多久，因为他们的愚昧行径必暴露在众人面前，就像雅尼和佯庇的下场一样。</span>
</div>
</div>

## 圣经的益处

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:11; 提多书 2:7; 彼得后书 1:5–7"> 但你熟知我的教导、言行、志向、信心、忍耐、爱心、毅力，</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 34:19; 使徒行传 14:5–6; 哥林多后书 11:23–28"> 也知道我在安提阿、以哥念、路司得遭遇了何等的迫害和苦难。但主从这一切患难中救了我。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14; 彼得前书 4:12–16; 彼得前书 2:20–21"> 其实凡立志在基督耶稣里过敬虔生活的人都会受到迫害。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 4:1; 彼得后书 2:20; 提多书 3:3"> 而恶人和骗子会变本加厉地作恶，迷惑人，也被人迷惑。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 提摩太后书 2:2; 提摩太后书 1:13"> 但你要坚守自己所学所信的，因为你知道是跟谁学的，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:98–99; 路加福音 24:45; 箴言 22:6"> 并且你从小就熟悉圣经。圣经能给你智慧，使你借着信基督耶稣而得救。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 15:4; 希伯来书 4:12; 彼得后书 1:19–21"> 圣经全部是上帝启示的，有益于教导、督责、使人归正、培养人行义，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 2:21; 以弗所书 2:10; 哥林多后书 9:8"> 使属上帝的人得到充分的装备，去行各种善事。</span>
</div>
</div>

## 对以色列和犹大的审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿书 9:8; 弥迦书 7:2; 弥迦书 3:9"> <span className="pl pl-1">“祭司啊，要听！</span><br /><span className="pl pl-1">以色列家啊，要留心听！</span><br /><span className="pl pl-1">王室啊，要侧耳听！</span><br /><span className="pl pl-1">这是对你们的审判，</span><br /><span className="pl pl-1">因为你们像设在米斯巴的圈套，</span><br /><span className="pl pl-1">像铺在他泊山的网罗。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿书 9:15; 以赛亚书 29:15; 何西阿书 6:9"> <span className="pl pl-1">你们这些叛逆之徒大肆杀戮，</span><br /><span className="pl pl-1">我要责罚你们所有人。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 3:2; 希伯来书 4:13; 何西阿书 13:1"> <span className="pl pl-1">我对以法莲一清二楚，以色列瞒不过我。</span><br /><span className="pl pl-1">以法莲做了妓女，以色列被玷污了。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿书 4:12; 约翰一书 2:3–4; 何西阿书 4:1"> <span className="pl pl-1">他们的恶行阻挠他们归向自己的上帝，</span><br /><span className="pl pl-1">因为淫乱之灵占据了他们的心，</span><br /><span className="pl pl-1">以致他们不认识耶和华。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="弥迦书 6:6–7; 约翰福音 7:34; 箴言 1:28"> <span className="pl pl-1">他们牵着牛羊去寻求耶和华，</span><br /><span className="pl pl-1">却寻不到，</span><br /><span className="pl pl-1">因为祂已离他们而去。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 6:7; 以赛亚书 48:8; 耶利米书 3:20"> <span className="pl pl-1">他们对耶和华不忠，</span><br /><span className="pl pl-1">所生的是私生子，</span><br /><span className="pl pl-1">他们和他们的田地必在朔日被吞噬。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 1:6; 以赛亚书 46:10; 何西阿书 9:11–17"> <span className="pl pl-1">以法莲啊，你要在受惩罚的日子沦为废墟！</span><br /><span className="pl pl-1">我要在以色列各支派中宣告将来必要发生的事！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 19:14; 申命记 27:17; 诗篇 93:3–4"> <span className="pl pl-1">犹大的首领如同擅移地界的人，</span><br /><span className="pl pl-1">侵吞以色列的领土，</span><br /><span className="pl pl-1">我要将烈怒如洪水般倾泻在他们身上。</span><br /></span>

<span className="v" id="v12" data-v="12" data-xref="以赛亚书 51:8; 约伯记 13:28; 以赛亚书 50:9"> <span className="pl pl-1">我要使以法莲像虫蛀的衣服，</span><br /><span className="pl pl-1">使犹大家像朽烂的木头。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿书 7:11; 何西阿书 12:1; 何西阿书 10:6"> <span className="pl pl-1">“以法莲见自己患病，</span><br /><span className="pl pl-1">犹大见自己有伤，</span><br /><span className="pl pl-1">以法莲便向强大的亚述王</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“强大的亚述王”或译为“耶雷布王”，同10:6。">a</a></sup><br /><span className="pl pl-1">求救。</span><br /><span className="pl pl-1">亚述王却不能医治你们，</span><br /><span className="pl pl-1">也无法为你们疗伤。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 7:2; 弥迦书 5:8; 何西阿书 13:7–8"> <span className="pl pl-1">我要像狮子一样对待以法莲，</span><br /><span className="pl pl-1">如猛狮一样对待犹大家，</span><br /><span className="pl pl-1">将他们撕碎、拖走，</span><br /><span className="pl pl-1">无人能营救他们。</span><br /></span>

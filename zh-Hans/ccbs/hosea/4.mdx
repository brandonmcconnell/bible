## 耶和华指控以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 4:22; 弥迦书 6:2; 以赛亚书 3:13–14"> <span className="pl pl-1">以色列人啊，</span><br /><span className="pl pl-1">你们要听耶和华的话。</span><br /><span className="pl pl-1">祂指控住在这片土地上的居民，说：</span><br /><span className="pl pl-1">“这片土地上的人不忠不信，</span><br /><span className="pl pl-1">毫无良善，不认识上帝。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿书 6:9; 耶利米书 6:7; 何西阿书 7:1"> <span className="pl pl-1">他们赌咒、撒谎、凶杀、偷窃、通奸，</span><br /><span className="pl pl-1">为所欲为，血案累累。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="西番雅书 1:3; 以赛亚书 24:4–12; 那鸿书 1:4"> <span className="pl pl-1">所以，这片土地要哀鸣，</span><br /><span className="pl pl-1">所有的居民都要消亡，</span><br /><span className="pl pl-1">田间的野兽、空中的飞鸟、</span><br /><span className="pl pl-1">水里的鱼类也要灭绝。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="申命记 17:12; 何西阿书 4:17; 阿摩司书 5:13"> 耶和华说：<br /><span className="pl pl-1">“谁都不要指控别人，</span><br /><span className="pl pl-1">谁都不要责备别人，</span><br /><span className="pl pl-1">因为我要指控你们这些祭司。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 15:8; 何西阿书 2:2; 加拉太书 4:26"> <span className="pl pl-1">你们白天黑夜都要跌倒，</span><br /><span className="pl pl-1">先知也要跟你们一起跌倒，</span><br /><span className="pl pl-1">所以我要毁灭你们的母亲。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 5:13; 箴言 19:2; 何西阿书 6:6"> <span className="pl pl-1">我的子民因无知而遭灭。</span><br /><span className="pl pl-1">因为你们拒绝认识我，</span><br /><span className="pl pl-1">我也要拒绝让你们做我的祭司；</span><br /><span className="pl pl-1">因为你们忘记你们上帝的律法，</span><br /><span className="pl pl-1">我也要忘记你们的儿女。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 13:6; 腓立比书 3:19; 撒母耳记上 2:30"> <span className="pl pl-1">你们祭司越增多，</span><br /><span className="pl pl-1">所犯的罪也越多，</span><br /><span className="pl pl-1">所以我要使你们的尊荣变为羞耻。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="弥迦书 3:11; 以赛亚书 56:11; 提多书 1:11"> <span className="pl pl-1">你们祭司食用我子民的赎罪祭，</span><br /><span className="pl pl-1">满心希望他们犯罪。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 24:2; 耶利米书 5:31; 马太福音 15:14"> <span className="pl pl-1">将来，我的子民如何，</span><br /><span className="pl pl-1">你们祭司也如何。</span><br /><span className="pl pl-1">我要照你们的所作所为惩罚你们、报应你们，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:14; 利未记 26:26; 哈该书 1:6"> <span className="pl pl-1">使你们吃却不得饱足，</span><br /><span className="pl pl-1">行淫却不得后代</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“行淫却不得后代”此处的意思是指责以色列人祭拜迦南人掌管生育的神明。他们以为这样能带来更多后代。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">因为你们背弃耶和华，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 20:1; 路加福音 21:34; 以赛亚书 28:7"> <span className="pl pl-1">沉溺酒色，丧失心智。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:27; 何西阿书 5:4; 哈巴谷书 2:19"> <span className="pl pl-1">“我的子民祈求木头，</span><br /><span className="pl pl-1">随从木杖的指引。</span><br /><span className="pl pl-1">淫乱的心使他们走入歧途，</span><br /><span className="pl pl-1">他们不忠不贞，背弃他们的上帝。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:29; 耶利米书 3:6; 以西结书 6:13"> <span className="pl pl-1">他们在山顶和高岗上的橡树、</span><br /><span className="pl pl-1">杨树和栗树下献祭烧香，</span><br /><span className="pl pl-1">因为树荫怡人。</span><br /><span className="pl pl-1">“所以，你们的女儿淫乱，</span><br /><span className="pl pl-1">你们的儿媳通奸。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="何西阿书 4:1; 约翰福音 8:43; 以弗所书 4:18"> <span className="pl pl-1">但我不会因此而惩罚她们，</span><br /><span className="pl pl-1">因为你们也与娼妓苟合，</span><br /><span className="pl pl-1">与庙妓一起献祭。</span><br /><span className="pl pl-1">无知的民族必走向灭亡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="何西阿书 12:11; 何西阿书 9:15; 阿摩司书 4:4"> <span className="pl pl-1">“虽然以色列如同妓女，对我不忠，</span><br /><span className="pl pl-1">但不要使犹大犯罪。</span><br /><span className="pl pl-1">不要到吉甲去，</span><br /><span className="pl pl-1">不要到伯·亚文</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“伯·亚文”意思是“罪恶之家”，在此指伯特利。“伯特利”意思是“上帝之家”，但当时已变成祭拜偶像之地。">b</a></sup><br /><span className="pl pl-1">去，</span><br /><span className="pl pl-1">不要凭永活的耶和华起誓。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 7:24; 耶利米书 8:5; 耶利米书 3:11"> <span className="pl pl-1">以色列桀骜不驯，</span><br /><span className="pl pl-1">如同桀骜不驯的母牛。</span><br /><span className="pl pl-1">耶和华怎能牧养他们，</span><br /><span className="pl pl-1">如同在草场上牧养羊羔呢？</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 81:12; 启示录 22:11; 何西阿书 13:2"> <span className="pl pl-1">以法莲</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“以法莲”为北国以色列最大的支派，圣经中有时用来代指北国以色列。本卷书中下同。">c</a></sup><br /><span className="pl pl-1">与偶像为伍，</span><br /><span className="pl pl-1">任由他吧！</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 3:11; 阿摩司书 5:12; 列王纪下 17:7–17"> <span className="pl pl-1">他们酒足兴尽之后，</span><br /><span className="pl pl-1">便不住地行淫；</span><br /><span className="pl pl-1">他们的首领恋慕羞耻之事。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 1:29; 耶利米书 4:11–12; 何西阿书 13:15"> <span className="pl pl-1">风要把他们卷走，</span><br /><span className="pl pl-1">他们必因所献的祭而蒙羞。</span></span>
</div>

## 脚注

<ol className="fnl">
<li id="fn-a"><a href="#fnref-a" className="fnb">a</a> <span className="fnr">4:10</span> “行淫却不得后代”此处的意思是指责以色列人祭拜迦南人掌管生育的神明。他们以为这样能带来更多后代。</li>
<li id="fn-b"><a href="#fnref-b" className="fnb">b</a> <span className="fnr">4:15</span> “伯·亚文”意思是“罪恶之家”，在此指伯特利。“伯特利”意思是“上帝之家”，但当时已变成祭拜偶像之地。</li>
<li id="fn-c"><a href="#fnref-c" className="fnb">c</a> <span className="fnr">4:17</span> “以法莲”为北国以色列最大的支派，圣经中有时用来代指北国以色列。本卷书中下同。</li>
</ol>

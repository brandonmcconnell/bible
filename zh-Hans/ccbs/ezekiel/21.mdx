## 耶和华审判的刀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 20:46; 以西结书 4:7; 以西结书 25:2"> “人子啊，你要面向耶路撒冷，开口斥责圣所，说预言斥责以色列，</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 9:22; 耶利米书 21:13; 以西结书 5:8"> 告诉以色列，耶和华这样说，‘看啊，我要与你为敌，我要拔刀出鞘，将你那里的义人和恶人一同消灭。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 20:47; 以西结书 7:2; 以西结书 6:11–14"> 由于我要将你那里的义人和恶人一同消灭，我的刀必出鞘从南到北杀向所有的人，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 21:30; 那鸿书 1:9; 撒母耳记上 3:12"> 使世人都知道我耶和华已拔刀出鞘，不再收回。’</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 22:4; 以西结书 6:11; 耶利米书 19:10"> 人子啊，你要在他们面前哀叹，要伤心欲绝地哀叹。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 7:17; 以西结书 7:26; 以赛亚书 13:7"> 如果他们问你为什么哀叹，你就说因为有噩耗传来，听见的人都胆战心惊、两手发软、精神萎靡、膝弱如水。灾难来了，必很快发生。这是主耶和华说的。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 耶和华对我说：</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 34:5–6; 以西结书 21:28; 以西结书 21:3"> “人子啊，你要说预言，告诉他们，主这样说，<br /><span className="pl pl-1">“‘有一把刀，</span><br /><span className="pl pl-1">有一把刀磨快擦亮了，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 110:5–6; 以西结书 20:47; 以西结书 21:25–27"> <span className="pl pl-1">磨利以行杀戮，</span><br /><span className="pl pl-1">擦得亮如闪电。</span><br />我们岂能因我儿的权杖而快乐？这刀鄙视一切权杖。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 21:19; 耶利米书 25:33; 耶利米书 51:20–23"> 这刀已交给人去擦亮，好握在手中，这刀已磨快擦亮，预备交给屠杀的人。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 21:6; 约珥书 1:13; 以西结书 21:14"> 人子啊，号啕大哭吧，因为这刀要攻击我的子民和所有以色列的首领，他们都要死于刀下。所以你要捶胸顿足。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 21:10; 哥林多后书 8:2; 以西结书 21:25"> 这刀必试验他们，这刀所鄙视的权杖若不复存在，又怎么办呢？这是主耶和华说的。’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 24:1; 民数记 24:10; 利未记 26:24"> “人子啊，你要拍掌对他们说预言，你要拿刀挥舞两三次，预示这刀要从四面八方大肆杀戮，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 21:10; 耶利米书 17:27; 以西结书 21:22"> 使他们吓得肝胆俱裂，许多人倒在家门口。我已赐下这亮如闪电的刀，用来杀戮。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 21:20; 以西结书 21:4; 以西结书 14:17"> 刀啊，你要左砍右劈，横扫四方。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 5:13; 以西结书 21:14; 撒迦利亚书 6:8"> 我也要拍掌，我的烈怒要平息。这是我耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶和华对我说：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 4:1–3; 耶利米书 1:10; 以西结书 5:1–17"> “人子啊，你要为巴比伦王的刀画出两条进攻之路，两条路要从一个地方出发，要在通往城邑的路口设路标。</span>
<span className="v" id="v20" data-v="20" data-xref="阿摩司书 1:14; 耶利米书 49:2; 以西结书 25:5"> 为刀画一条路进攻亚扪的拉巴城，再画一条路进攻犹大的坚城耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 18:20; 箴言 16:33; 士师记 17:5"> 巴比伦王会站在两条路的岔口占卜，摇签求问他的神像，察看祭牲的肝。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 4:2; 以西结书 26:9; 耶利米书 51:14"> 他右手拿到的是攻打耶路撒冷的签，于是他架起撞城锤，号令杀戮，高声呐喊，用撞城锤攻打城门，建垒筑台围攻城池。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 5:15; 以西结书 21:24; 以西结书 29:16"> 犹大人必认为这是虚假的占卜。他们曾向巴比伦王宣誓效忠，但巴比伦王要使他们想起自己的罪，并掳走他们。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="何西阿书 4:2; 弥迦书 3:10–12; 耶利米书 3:2"> “所以，主耶和华说，‘因为你们的过犯昭然若揭，使人想起你们的罪恶，你们的所作所为都显出你们的罪过。因此，你们必遭掳掠。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 35:5; 以西结书 21:29; 以西结书 17:19"> 你这邪恶败坏的以色列首领啊！你的结局到了，最终审判的日子来了。’</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 17:24; 诗篇 75:7; 耶利米书 13:18"> 主耶和华说，‘取下你的礼帽，摘下你的冠冕吧，时局转变了。要提拔卑微的，贬抑高贵的。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 5:2; 耶利米书 23:5–6; 撒迦利亚书 9:9"> 毁灭，毁灭，我要毁灭这国，使它荡然无存，直到那应得的人来到，我要把这国交给他。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 21:20; 以西结书 21:9–10; 西番雅书 2:8–10"> “人子啊，你要说有关亚扪人及其耻辱的预言，告诉他们，主耶和华说，‘有刀，有刀已出鞘，为要杀戮；它亮如闪电，要行毁灭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 21:25; 以西结书 22:28; 诗篇 37:13"> 他们为你们看的异象是虚假的，所做的占卜谎话连篇，你们将与亵渎的恶人一同被杀，因为他们的结局到了，最终审判的日子来了。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 16:38; 创世记 15:14; 耶利米书 47:6–7"> 你们要收刀入鞘，我要在你们的受造之处，在你们的出生之地审判你们，</span>
<span className="v" id="v31" data-v="31" data-xref="那鸿书 1:6; 耶利米书 6:22–23; 以西结书 14:19"> 我要把烈怒倒在你们身上，将我的怒火喷在你们身上，把你们交在嗜杀成性的恶徒手中，</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 25:10; 玛拉基书 4:1; 以西结书 20:47–48"> 你们必被当作柴焚烧，你们的血必流在自己的土地上，无人再记得你们。因为这是我耶和华说的。’”</span>
</div>
</div>

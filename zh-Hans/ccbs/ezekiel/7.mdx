## 以色列的结局近了

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 8:2; 彼得前书 4:7; 以西结书 7:3"> “人子啊，主耶和华对以色列这样说，‘结局到了，以色列全境的结局到了！</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 18:30; 以西结书 5:13; 以西结书 33:20"> 以色列，你的结局到了，我的怒气必倾倒在你身上，我必按你的行为审判你，照你一切的可憎之事报应你。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 6:7; 以西结书 11:21; 以西结书 5:11"> 我必不顾惜你，也不怜悯你，我必按你的所作所为和可憎之事报应你。这样，你必知道我是耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="那鸿书 1:9; 列王纪下 21:12–13; 以西结书 5:9"> 主耶和华说：“看啊，灾祸来了，一场空前的灾祸来了！</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亚书 13:7; 以西结书 7:3; 彼得后书 2:5"> 结局到了，结局到了！你的结局到了。看啊，结局到了！</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 12:28; 以西结书 7:12; 以赛亚书 22:5"> 以色列境内的居民啊，灾难降临了！时候已到，日子已近，山上一片恐慌，欢乐荡然无存。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 9:8; 以西结书 14:19; 以西结书 20:8"> 我快要向你倾倒我的烈怒，发出我的怒气。我必按你的所作所为审判你，照你一切的可憎之事报应你。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 20:13; 弥迦书 6:9; 以赛亚书 9:13"> 我必不顾惜你，也不怜悯你，我必按你的恶行报应你。这样，你就知道击打你的是我耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 10:5; 雅各书 4:6; 帖撒罗尼迦前书 5:3"> “看啊，那日子！看啊，那日到了，灾祸临头了！杖已经发芽，傲慢已经开花。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅书 1:18; 以西结书 7:23; 以赛亚书 59:6–8"> 暴行成了惩罚邪恶的杖，以色列人必没有一个能够存留，他们的财富和尊荣必不复存在。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 5:13–14; 哥林多前书 7:29–31; 以西结书 7:5–7"> 时候到了，日子近了，买主不要欢乐，卖主也不要忧愁，因为烈怒临到了所有的人。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 25:24–28; 利未记 25:31; 约伯记 15:25"> 即使卖主活着，也无法赎回他所卖的，因为关乎每一个人的异象必然应验，他们因为罪恶，无人能保存性命。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 4:5; 耶利米书 7:20; 耶利米书 51:27"> “他们吹响了号角，做好了一切准备，却无人出战，因为我的烈怒临到了他们所有的人。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 14:18; 以西结书 5:12; 耶利米哀歌 1:20"> 城外有刀剑，城内有饥荒瘟疫；城外的必丧身刀下，城内的必死于饥荒瘟疫。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:11; 以赛亚书 38:14; 以斯拉记 9:15"> 侥幸逃到山上的，都必像谷中哀鸣的鸽子，为自己的罪恶哀鸣。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 21:7; 希伯来书 12:12; 耶利米书 6:24"> 他们必吓得两手发软，双腿颤抖。</span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司书 8:10; 以赛亚书 15:2–3; 以赛亚书 3:24"> 他们必身披麻衣，战栗发抖。他们必剃光头发，满脸尽是耻辱。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 11:4; 西番雅书 1:18; 路加福音 12:19–20"> 他们必把银子抛在街上，视金子为污秽之物。在耶和华发烈怒的日子，金银不能拯救他们，也不能填饱他们的肚腹或满足他们的胃口，因为金银使他们跌入罪恶中。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 24:21; 耶利米书 7:30; 以西结书 8:15–16"> 他们以华美的饰物为骄傲，并用它制造丑恶可憎的神像，因此，我必使这一切变成他们眼中的污秽之物。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 24:13; 诗篇 74:2–8; 历代志下 36:18–19"> 我必使这一切成为外族人手中的猎物，恶人手中的战利品，被任意糟蹋。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 18:17; 诗篇 74:18–23; 诗篇 74:10–11"> 我必转脸不看他们，任由外族人亵渎我的殿，强盗必进入殿里大肆亵渎。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结书 9:9; 耶利米书 27:2; 以西结书 11:6"> “你要预备锁链，因为这地方充满了血腥的罪恶，城里充斥着暴行。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 28:7; 诗篇 106:41; 以西结书 21:31"> 我必让最凶恶的外族人侵占他们的房屋。我必挫败强悍之人的傲气，使他们的圣所遭受亵渎。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 8:15–16; 以赛亚书 57:21; 耶利米哀歌 4:17–18"> 恐怖的日子来临了，他们想寻求平安，却得不到平安。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 4:20; 以西结书 14:1; 弥迦书 3:6"> 灾祸接踵而至，噩耗不断传来。那时，他们必求问先知，但祭司的教导必消逝，长老们必无计可施。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 18:30; 以西结书 7:4–8; 以西结书 26:16"> 君王必悲哀，首领必惊恐，百姓的手都必颤抖。我必按他们的恶行对付他们，使他们受到应得的审判。这样，他们就知道我是耶和华。”</span>
</div>
</div>

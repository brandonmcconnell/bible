## 被掳的预兆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 4:12; 耶利米书 5:21; 诗篇 78:40"> “人子啊，你住在叛逆的人当中。他们有眼睛却视而不见，有耳朵却听而不闻，因为他们是叛逆的人。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 提摩太后书 2:25; 耶利米书 26:3"> 所以，人子啊，你要准备流亡的行装，在白天出去流亡。你要像流亡者一样，当着他们的面从你住的地方搬到别处。他们虽然叛逆，或许还会明白其中的意思。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4; 以西结书 12:12; 列王纪下 25:4"> 你要在白天当着他们的面把预备流亡的行装拿出来，你要在晚上当着他们的面像流亡的人一样出去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 25:4; 耶利米书 39:2–4"> 你要当着他们的面在墙上挖一个洞，带着行装钻出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 4:3; 以赛亚书 8:18; 以西结书 24:24"> 你要在天黑时当着他们的面背着行装出发。你要蒙着脸使自己看不见地，因为我要使你成为以色列人的预兆。”</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 24:18; 以西结书 37:10; 以西结书 37:7"> 于是，我遵命而行。白天我把预备流亡的行装拿出来，晚上用手挖通了墙，当着他们的面背着行装在天黑时出发。</span>
<span className="v" id="v8" data-v="8"> 第二天早晨，耶和华对我说：</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 24:19; 以西结书 17:12; 以西结书 20:49"> “人子啊，那些叛逆的以色列人不是问你在做什么吗？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:25; 以赛亚书 13:1; 耶利米书 24:8"> 你要告诉他们，‘主耶和华说：这是关于耶路撒冷的首领和城中以色列人的预兆。’</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 52:15; 耶利米书 15:2; 耶利米书 52:28–30"> 你要说，‘我就是给你们的预兆，我所做的必发生在你们身上，你们必被掳流亡。’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:4; 耶利米书 39:4; 以西结书 12:6"> 他们当中的首领必在天黑时背着行装出发，在墙上挖洞钻出去，而且必蒙着脸，看不见地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:7; 何西阿书 7:12; 以西结书 17:20"> 我必撒开网罗捕捉他，把他带到迦勒底人的巴比伦。他必看不见那地方，却要死在那里。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 5:2; 列王纪下 25:4–5; 以西结书 17:21"> 我要把他周围的随从和所有军队驱散到四方，并且拔刀追杀他们。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 6:7; 以西结书 12:16; 以西结书 12:20"> 当我把他们驱赶到各国，分散到列邦时，他们就知道我是耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:8–9; 以西结书 14:22–23; 以西结书 6:8–10"> 然而，我要使他们当中一些人免遭刀剑、饥荒和瘟疫，使他们可以在所去的各国供述自己的一切可憎行为。他们就知道我是耶和华。”</span>
<span className="v" id="v17" data-v="17"> 耶和华对我说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 诗篇 80:5; 约伯记 3:24"> “人子啊，你要战战兢兢地吃饭，惶惶恐恐地喝水，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 7:14; 以西结书 6:6–7; 以西结书 6:14"> 然后对这地方的人说，‘关于耶路撒冷和以色列的居民，主耶和华这样说，他们必焦虑不安地吃饭，惶恐不已地喝水，他们的土地必因其中居民的暴行而荒无人烟。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:7; 以赛亚书 7:23–24; 耶利米书 25:9"> 他们居住的城邑必沦为废墟，土地必一片荒凉，他们就知道我是耶和华。’”</span>
<span className="v" id="v21" data-v="21"> 耶和华对我说：</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 18:2–3; 以西结书 11:3; 以西结书 12:27"> “人子啊，你们以色列有一句俗语，‘光阴流逝，异象都落空。’</span>
<span className="v" id="v23" data-v="23" data-xref="约珥书 2:1; 以西结书 7:5–7; 西番雅书 1:14"> 现在你要告诉他们，主耶和华这样宣告：我要废掉这句俗语，使它从以色列人的口中消失。你要对他们说，‘日子已近，异象都要应验。’</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 14:13–16; 以西结书 13:23; 撒迦利亚书 13:2–4"> 在以色列人中必不再有虚假的异象和谄媚的预言。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷书 1:5; 以西结书 12:28; 以赛亚书 55:11"> 我是耶和华，我的话都必实现，决不迟延。你们这叛逆的人啊，我说的话必在你们有生之年应验！”这是主耶和华说的。</span>
<span className="v" id="v26" data-v="26"> 耶和华对我说：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 10:14; 以西结书 12:22; 彼得后书 3:4"> “人子啊，你看，以色列人在说，‘他见的异象是关乎多年后的事，他说的预言是针对遥远的未来。’</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 12:23–25; 马可福音 13:32–37; 帖撒罗尼迦前书 5:2–3"> 因此，你要对他们说，‘主耶和华这样说：我的话必应验，不再迟延。’这是主耶和华说的。”</span>

## 斥责假先知

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 13:17; 耶利米书 37:19; 以西结书 22:28"> “人子啊，你要说预言斥责以色列那些说预言的先知，告诉那些私自说预言的人，‘你们要听耶和华的话。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 2:14; 耶利米书 23:28–32; 何西阿书 9:7"> 主耶和华说，愚顽的先知有祸了！他们没有看到异象，却私自说预言。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:20; 弥迦书 2:11; 帖撒罗尼迦后书 2:9–10"> 以色列人啊，你们的先知像废墟中的狐狸，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 22:30; 诗篇 106:23; 以赛亚书 58:12"> 你们没有上去堵住缺口，也没有重建以色列的围墙，使以色列在耶和华的日子来临时的争战中坚立。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 29:8; 以西结书 22:28; 耶利米书 28:15"> 他们看见的异象是虚假的，他们的占卜谎话连篇。他们口口声声说是传达耶和华的话，其实耶和华并没有差遣他们。他们竟然指望自己的谎言能够应验。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 13:6; 马太福音 24:23–24; 以西结书 13:2–3"> 你们说这是耶和华说的，其实我并没有说。你们岂不是见了虚假的异象，说了欺诈的占卜吗？’”</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 5:8; 以西结书 21:3; 以西结书 28:22"> 所以主耶和华说：“因为你们的假异象和谎言，我要攻击你们。这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 87:6; 诗篇 69:28; 以西结书 20:38"> 我必动手攻击那些见虚假异象、说欺诈占卜的先知。他们必从我的子民当中被剔除，不被收录在以色列人的名册上，也不能进入以色列的土地。这样，你们就知道我是主耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:28; 以西结书 13:16; 耶利米书 6:14"> 因为他们欺骗我的子民说，‘平安！’其实并没有平安，就像有人筑了一道薄墙，用白灰加以粉饰。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 38:22; 以赛亚书 28:2; 那鸿书 1:7–8"> 所以，你要警告那些粉刷白灰的人，说，‘墙必倒塌，暴雨要来临，冰雹势必降下，狂风也必大作。’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 3:13; 耶利米哀歌 2:14–15; 士师记 9:38"> 墙倒塌之后，一定会有人问，‘你们粉饰的白灰在哪里呢？’</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 30:30; 启示录 16:21; 诗篇 148:8"> 因此，主耶和华说，‘我必在烈怒中用狂风暴雨和冰雹来摧毁这墙，</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 1:6; 耶利米书 14:15; 耶利米书 6:15"> 我必把你们粉饰的墙夷为平地，使其露出根基。墙倒塌的时候，你们必葬身其中。这样，你们就知道我是耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:13; 诗篇 62:3; 尼希米记 4:3"> 我要向这墙和粉饰这墙的人发烈怒，惩罚他们。我告诉你们，这墙完了！粉饰这墙的人也完了！</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 13:10; 耶利米书 6:14; 耶利米书 8:11"> 他们就是那些向耶路撒冷说假预言，在这城没有平安的时候宣称看到了平安异象的以色列先知。这是主耶和华说的。’</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 13:2; 列王纪下 22:14; 士师记 4:4"> “人子啊，你要说预言斥责你同胞中私自说预言的女子，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:14; 以西结书 13:20; 提摩太后书 4:3"> 告诉她们主耶和华这样说，‘你们这些妇女有祸了！你们为了猎取人命，给人缝制戴在手腕上的符咒和各种尺寸的头巾。你们猎取我子民的性命，还想保住自己的性命吗？</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 3:5; 箴言 28:21; 耶利米书 23:17"> 你们为了几把大麦和几块饼，在我的子民中亵渎我，向那些肯听谎言的说谎，杀死那些不该死的，救活那些不该活的。’</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 13:18; 提摩太后书 3:8–9; 以西结书 13:8–9"> “所以主耶和华说，‘你们用符咒猎取人命如同捕鸟，我要除去你们的符咒，从你们手臂上扯掉它们，释放你们像捕鸟一样猎取的人。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 91:3"> 我还要撕去你们的头巾，把我的子民从你们手中拯救出来，使他们不再做你们手中的猎物。这样，你们就知道我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:14; 耶利米书 14:13–17; 彼得后书 2:18–19"> 我没有使义人伤心，你们却以谎言叫他们灰心。你们怂恿恶人不要改邪归正，以致他们丧命。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 13:21; 以西结书 12:24; 弥迦书 3:6"> 因此，你们必不再见假异象，也不再占卜。我必从你们手中拯救我的子民。这样，你们就知道我是耶和华。’”</span>

## 犯罪者必灭亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 31:29–30; 耶利米哀歌 5:7; 以西结书 37:11"> “你们谈论以色列地时为什么说‘父亲吃了酸葡萄，儿子的牙酸倒了’这句俗语呢？</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 18:19–20; 以西结书 33:11–20; 以西结书 18:30"> 主耶和华说，我凭我的永恒起誓，你们在以色列必不再用这句俗语。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:20; 罗马书 6:23; 民数记 16:22"> 因为所有的生命都属于我，父和子都属于我。谁犯罪，谁死亡。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 33:14; 约翰一书 3:7; 箴言 21:3"> “倘若有义人秉公行义，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 18:15; 申命记 4:19; 以西结书 6:13"> 不在山上的庙宇里吃祭物，不拜以色列人的偶像，不玷污别人的妻子，不亲近经期中的妇女；</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 18:16; 出埃及记 22:26; 以西结书 18:12"> 不欺压人，反而退还债户的抵押品；不抢夺财物，反而给饥饿的人食物吃，给赤身露体的人衣服穿；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 22:25; 撒迦利亚书 8:16; 申命记 23:19–20"> 不放债取利，不犯罪作恶，反而公平待人，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:11; 哈巴谷书 2:4; 阿摩司书 5:4"> 遵守我的律例，切实遵行我的典章——这样的人是义人，必能活着。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:12; 约翰一书 3:12; 约翰福音 18:40"> “倘若这人生的儿子凶残暴戾，嗜杀成性，无恶不作，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 22:14; 马太福音 7:21–27; 列王纪上 13:8"> 常在山上的庙宇吃祭偶像之物，玷污别人的妻子，</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:17; 以西结书 8:6; 列王纪下 21:11"> 欺压贫穷困苦的人，抢夺财物，扣留债户的抵押品，祭拜偶像，行可憎之事，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:25; 利未记 20:9; 以西结书 3:18"> 放债取利，这样的人还能活着吗？他必不能活。他多行可憎之事，必自取灭亡，自害己命。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:21; 箴言 23:24; 耶利米书 8:6"> “倘若这不肖子有一个好儿子，他看见父亲的所作所为，不愿步父亲的后尘。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 18:6–7; 以西结书 18:11–13"> 他不在山上吃祭偶像之物，不拜以色列人的偶像，不玷污别人的妻子，</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 18:7; 以赛亚书 58:7–10; 约伯记 22:7"> 不欺压他人，不扣留抵押品，不抢夺财物，反而给饥饿的人食物吃，给赤身露体的人衣服穿，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 18:8–9; 马太福音 18:27–35; 以西结书 18:13"> 不压榨贫穷的人，不放债取利，反而遵守我的典章，顺从我的律例，这人必不因父亲的罪恶而死亡，他必活着。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 3:18; 以西结书 18:26; 以西结书 18:24"> 他父亲因肆意欺诈，掠夺同胞，多行不义，必死于自己的罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:5; 撒迦利亚书 1:3–6; 申命记 5:9"> “你们会问，‘儿子为什么不用承担父亲的罪恶呢？’这是因为儿子秉公行义，谨遵我的律例，所以他必活着。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 24:16; 列王纪下 14:6; 以西结书 18:4"> 谁犯罪，谁死亡，儿子不用承担父亲的罪恶，父亲也不用承担儿子的罪恶。义人的义必归自己，恶人的恶也必归自己。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 18:27–28; 提多书 2:11–14; 以西结书 33:19"> “恶人若肯改邪归正，遵守我的律例，秉公行义，就必活着，不致死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 7:19; 以西结书 33:16; 以赛亚书 43:25"> 他犯的一切罪过不会被追究，他必因行事正直而活着。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:11; 提摩太前书 2:4; 彼得后书 3:9"> 主耶和华说，我难道喜欢恶人死亡吗？我岂不是更愿他们改邪归正并活着吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 33:18; 箴言 21:16; 约翰二书 1:8"> 义人若弃善行恶，与恶人同流合污，这人岂能活着？他从前的义行不会被记念，他必因自己的背信和罪恶而死亡。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结书 33:17; 玛拉基书 3:13–15; 玛拉基书 2:17"> “你们说，‘主行事不公平。’以色列人啊，你们听着，是我行事不公平呢？还是你们行事不公平呢？</span>
<span className="v" id="v26" data-v="26"> 义人若离义行恶，必因恶行而死。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 18:21; 以赛亚书 1:18; 以赛亚书 55:7"> 恶人若改邪归正、秉公行义，必保全性命。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:29; 路加福音 15:17–18; 雅各书 2:10–12"> 因为他醒悟过来，改邪归正，必能活着，不致死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 18:25; 箴言 19:3; 以西结书 18:2"> 以色列人却说，‘主行事不公平！’以色列人啊，是我行事不公平呢？还是你们行事不公平呢？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结书 18:21; 马太福音 16:27; 马太福音 3:2"> “所以主耶和华说，‘以色列人啊，我必按你们各人的行为审判你们。你们要悔改，改邪归正，免得死在罪中。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 51:10; 以西结书 36:26; 以西结书 11:19"> 你们要离弃从前所有的罪恶，洗心革面。以色列人啊！你们何必走向灭亡呢？’</span>
<span className="v" id="v32" data-v="32" data-xref="彼得后书 3:9; 以西结书 18:23; 以西结书 33:11"> 主耶和华说，‘我断不喜欢任何人死亡，你们要悔改，便得存活。’”</span>
</div>
</div>

## 为法老唱哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 30:20; 以西结书 32:17; 以西结书 31:1"> 第十二年十二月一日，耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 29:3; 那鸿书 2:11–13; 以西结书 27:2"> “人子啊，你要为埃及王法老唱哀歌，对他说，<br /><span className="pl pl-1">“‘你自认为是列邦中的雄狮，</span><br /><span className="pl pl-1">其实你像激荡江河、</span><br /><span className="pl pl-1">用脚把江河搅浑的海怪。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 12:13; 耶利米书 16:16; 传道书 9:12"> <span className="pl pl-1">主耶和华说：</span><br /><span className="pl pl-1">我要借多国联军把我的网撒在你身上，</span><br /><span className="pl pl-1">他们要用我的网把你拉上来。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 18:6; 以西结书 29:5; 以西结书 31:12–13"> <span className="pl pl-1">我要把你抛在地上，扔在田野，</span><br /><span className="pl pl-1">让天上的飞鸟落在你身上，</span><br /><span className="pl pl-1">让地上的走兽吞吃你。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 31:12"> <span className="pl pl-1">我要把你的肉撒在山间，</span><br /><span className="pl pl-1">把你的尸首填满山谷，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 34:3; 以赛亚书 34:7; 启示录 14:20"> <span className="pl pl-1">用你的血浇灌大地，</span><br /><span className="pl pl-1">漫过群山，溢满沟壑。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:29; 约珥书 2:31; 以赛亚书 13:10"> <span className="pl pl-1">当我消灭你的时候，</span><br /><span className="pl pl-1">我要遮蔽天空，使星辰昏暗；</span><br /><span className="pl pl-1">我要用云遮蔽太阳，使月亮无光。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:14; 箴言 20:20"> <span className="pl pl-1">我要遮蔽天上所有的光，</span><br /><span className="pl pl-1">使黑暗笼罩你的四境。</span><br /><span className="pl pl-1">这是主耶和华说的。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 18:10–15; 以西结书 30:26; 耶利米书 25:15–25"> “‘我把你灭亡的消息带到你不认识的列国时，必使列邦惶恐不安。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 26:16; 以西结书 27:35; 列王纪上 9:8"> 我在他们面前挥刀攻击你的时候，各国的人都必因你而惊骇，他们的君王必胆战心惊。在你倾覆那天，他们都必时刻为自己的性命战战兢兢。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 43:10; 以西结书 26:7; 以西结书 30:22–25"> “主耶和华这样说，‘巴比伦王的刀必来攻击你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 28:7; 以西结书 29:19; 以西结书 31:11"> 我要使你的人民丧身在各国中最残暴的勇士刀下。<br /><span className="pl pl-1">“‘他们必摧毁埃及的骄傲，</span><br /><span className="pl pl-1">消灭她的人民。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 29:11; 以西结书 29:8; 以西结书 30:12"> <span className="pl pl-1">我要杀尽她河边的牲畜，</span><br /><span className="pl pl-1">使人足兽蹄不再搅浑河水。</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">我要使埃及的河流清澈见底，</span><br /><span className="pl pl-1">像油一样缓缓流淌。</span><br /><span className="pl pl-1">这是主耶和华说的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 6:7; 出埃及记 7:5; 出埃及记 14:4"> <span className="pl pl-1">我要使埃及的土地荒凉，</span><br /><span className="pl pl-1">毁灭其中的一切，</span><br /><span className="pl pl-1">击杀其中的所有居民，</span><br /><span className="pl pl-1">那时他们就知道我是耶和华。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 1:17; 历代志下 35:25; 以西结书 26:17"> “‘这是列国为埃及唱的哀歌，各国的妇女要为埃及和她的人民唱这哀歌。这是主耶和华说的。’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以西结书 32:1; 以西结书 33:21; 以西结书 1:2"> 第十二年十二月十五日，耶和华对我说：</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 31:14; 以西结书 32:2; 耶利米书 1:10"> “人子啊，为埃及的众民哀哭吧！我要把她与各强国的人民一同送入阴间，与坠入坟墓的人在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 31:18; 以西结书 32:29–30; 耶利米书 9:25–26"> <span className="pl pl-1">“埃及啊，你比谁更美呢？</span><br /><span className="pl pl-1">你下去跟未受割礼的人躺在一起吧！</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 28:3; 以西结书 32:23–26; 以西结书 32:29–30"> “埃及人要倒毙在丧身刀下的人当中。刀已出鞘，她和她的国民要被拖走。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 14:9–10; 以西结书 32:27; 以西结书 32:19"> 英勇的统领要在阴间谈论埃及王及其盟友说，‘这些丧身刀下、未受割礼的人下来长眠了。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 32:26; 以西结书 32:29–30; 以西结书 32:24"> “亚述和她的大军都在那里，她周围是她大军的坟墓。他们都是丧身刀下的人。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 26:20; 以西结书 32:24–27; 诗篇 27:13"> 他们的坟墓在阴间的最深处，她的大军躺卧在她坟墓的周围。他们生前曾使人恐惧，如今却丧身刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 32:18; 以西结书 26:20; 耶利米书 49:34–39"> 以拦在那里，她的百姓在她坟墓的周围。他们都未受割礼，丧身刀下，下到了阴间。他们生前曾使人恐惧，如今却和下坟墓的人一同抱愧蒙羞。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 139:8; 历代志上 10:4; 撒母耳记下 1:20"> 以拦躺卧在被杀的人当中，周围是她百姓的坟墓。他们都未受割礼、丧身刀下。他们生前曾使人恐惧，如今却和下坟墓的人一同抱愧蒙羞，躺卧在被杀的人当中。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西结书 27:13; 创世记 10:2; 以西结书 38:2–3"> “米设和土巴都在那里，周围是她们百姓的坟墓。他们都未受割礼，生前曾使人恐惧，如今却丧身刀下。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:18–19; 约伯记 3:13–15; 以西结书 32:21"> 他们没有古代<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“古代”有古卷作“未受割礼的”。">a</a></sup>勇士的荣耀葬礼，那些勇士带着兵器下到阴间，头枕着刀，尸骨上盖着盾，他们生前曾使人恐惧。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理书 2:34–35"> “法老啊，你要被毁灭，跟那些未受割礼、丧身刀下的人躺在一起。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 49:7–22; 玛拉基书 1:3–4; 俄巴底亚书 1:1–9"> “以东也在那里，她的君王和官长尽管力量强大，却和丧身刀下的人在一起，与那些未受割礼、下坟墓的人躺在一起。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结书 38:6; 以西结书 39:2; 以西结书 28:21"> “北方的诸王和所有的西顿人也在那里，虽然他们力量强大，令人恐惧，却羞辱地与被杀的人下到了阴间。他们未受割礼，与丧身刀下的人躺在一起，与下坟墓的人一同蒙羞。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西结书 31:16; 以西结书 14:22; 耶利米哀歌 2:13"> “法老看见他们，便为他大群丧身刀下的民众和全军感到欣慰。这是主耶和华说的。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 32:27; 创世记 35:5; 哥林多后书 5:11"> 我曾使法老给世人带来恐惧，但他和他的民众最后还是要躺卧在未受割礼、丧身刀下的人当中。这是主耶和华说的。”</span>
</div>

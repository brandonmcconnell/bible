## 耶路撒冷被困的预兆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="何西阿书 1:2–9; 阿摩司书 3:2; 以西结书 12:3–16"> “人子啊，你去拿一块砖放在自己面前，把耶路撒冷城画在上面。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 21:22; 耶利米书 6:6; 路加福音 19:42–44"> 然后围困这城，建垒筑台，扎营围攻，四面架起撞城锤。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 12:6; 以赛亚书 8:18; 以赛亚书 20:3"> 拿一个铁盘当作铁墙放在你和城中间。你要面向这城，围困攻击这城。这是给以色列人的一个征兆。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 16:22; 利未记 10:17; 民数记 18:1"> “你要向左侧卧，担当以色列人的罪恶。要用你向左侧卧的天数担当以色列人的罪恶。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 14:34; 以赛亚书 53:6"> 他们犯罪多少年，我要让你侧卧多少天。你要担当以色列人的罪恶三百九十天。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:34; 但以理书 12:11–12; 但以理书 9:24–26"> 然后，你再向右侧卧，担当犹大的罪恶四十天。你侧卧的天数代表他们犯罪的年数。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 52:10; 以西结书 21:2; 以西结书 6:2"> 你要面向被围困的耶路撒冷，光着臂膀说预言斥责这城。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 3:25"> 我要用绳索捆绑你，使你不能翻身，直到你围城的日子期满。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 4:13; 以赛亚书 28:25; 以西结书 4:16"> “你要拿小麦、大麦、豆、扁豆、小米和粗麦，装在一个器皿中用来为自己做饼。你在三百九十天侧卧期间要吃这饼。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 26:26; 以西结书 45:12; 申命记 28:51–68"> 你每天要按时按量吃二百克，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:13; 约翰福音 3:34; 以西结书 4:16"> 每天要按时按量喝六百毫升水。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 36:12; 创世记 18:6"> 你要像吃大麦饼一样吃这些饼，要在众人面前用人粪来烤饼。”</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 1:8; 何西阿书 9:3–4"> 耶和华说：“我把以色列人驱逐到各国的时候，他们也要这样在那里吃不洁净的食物。”</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 10:14; 以西结书 20:49; 以西结书 9:8"> 我说：“唉，主耶和华啊！我从来没有玷污过自己，我自幼至今从未吃过自然死去的或被野兽撕碎的动物，不洁净的肉从未入过我的口。”</span>
<span className="v" id="v15" data-v="15"> 于是祂对我说：“好吧，我容许你用牛粪代替人粪来烤饼。”</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 5:16; 以赛亚书 3:1; 利未记 26:26"> 祂又说：“人子啊，我要断绝耶路撒冷的粮源，叫他们怀着焦虑限量吃饼，怀着恐惧限量喝水。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 24:23; 利未记 26:39; 以西结书 33:10"> 他们必缺粮少水，绝望地面面相觑，因自己的罪恶而灭亡。”</span>

## 两个淫妇的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 16:44–46; 耶利米书 3:7–10"> “人子啊，有一对同胞姊妹，</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 17:7; 以西结书 16:22; 约书亚记 24:14"> 她们在埃及做娼妓，年轻时就淫乱，任人抚摸她们的胸，玩弄她们处女的乳。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 16:8; 诗篇 76:2; 耶利米书 2:2–3"> 姐姐名叫阿荷拉，妹妹名叫阿荷利巴。后来她们都归属了我，并且生儿育女。阿荷拉即撒玛利亚，阿荷利巴即耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="何西阿书 5:13; 列王纪下 17:3; 列王纪下 16:7"> “阿荷拉归属我后仍然淫乱，贪恋她的情人亚述战士。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 23:23"> 他们都是身穿紫衣的省长和总督，都是英俊的年轻骑士。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 5:3; 何西阿书 6:10; 以西结书 22:3–4"> 她便与这些亚述的精英放纵情欲，拜他们的偶像，玷污自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 23:19; 以西结书 23:3; 出埃及记 32:4"> 她没有放弃在埃及的淫荡行为，她年轻的时候，就有人与她同寝，玩弄她处女的乳，发泄情欲。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 11:5; 列王纪下 15:29; 列王纪下 17:23"> 因此，我把她交在她所恋慕的亚述人手里。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:29; 何西阿书 2:10; 耶利米书 22:8–9"> 他们扒光她的衣服，夺去她的儿女，用刀杀了她。她受了报应，成了妇女口中的笑柄。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:8–11; 以西结书 16:47–51; 以西结书 23:4"> “她妹妹阿荷利巴看见这一切，不但没有引以为戒，反而比姐姐更加放荡淫乱。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:7–15; 以西结书 23:23; 历代志下 28:16–23"> 她贪恋亚述的省长和总督，那些衣着华丽、英俊的年轻骑士。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 12:1–2; 列王纪下 17:18–19; 以西结书 23:31"> 我看见她玷污了自己，与姐姐的行径如出一辙。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 8:10; 耶利米书 22:14; 耶利米书 50:2"> 她还变本加厉地放荡淫乱，看见墙上用朱砂画着迦勒底人的像，</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:18; 撒母耳记上 18:4; 以赛亚书 22:21"> 腰间束带，头巾飘扬，都像是来自迦勒底的巴比伦人的将领，</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 16:29; 马太福音 5:28; 约伯记 31:1"> 便恋上了他们，差遣使者到他们那里。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 23:28; 以西结书 23:22; 创世记 10:10"> 巴比伦人便来上她的床，放纵情欲玷污了她。之后，她便厌弃他们。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 78:59; 诗篇 106:40; 耶利米书 12:8"> 她继续公开地淫乱，在众人面前赤身露体，我厌弃她，像厌弃她姐姐一样。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 23:3; 以西结书 20:7; 以西结书 16:51"> 她却更加淫乱，怀念自己年轻时在埃及为娼的日子，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 17:15; 以西结书 16:26; 耶利米书 5:8"> 贪恋那些体壮精足、如驴似马的情人，</span>
<span className="v" id="v21" data-v="21"> 渴望重温早年的淫行，任埃及人摸胸弄乳的日子。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 16:37; 启示录 17:16; 耶利米书 6:22–23"> “因此，主耶和华说，‘阿荷利巴啊，我要促使那些你始乱终弃的情人从四面八方来攻击你。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 50:21; 列王纪下 24:2; 列王纪下 20:14–17"> 他们是巴比伦人，还有从比割、书亚和哥亚来的所有迦勒底人以及亚述人，都是骑马的英俊青年，有省长、总督及有名将领。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 24:14; 以西结书 26:10; 以西结书 23:45"> 他们率领大队人马，带着兵器、战车和军需车来攻击你。他们顶盔贯甲，手拿盾牌从四面八方进攻你。我要让他们惩罚你，他们会按自己的律例来审判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 23:47; 以西结书 8:1–18; 以西结书 15:6–7"> 我要借着他们向你倾倒我的义愤，他们要在愤怒中对付你，割去你的鼻子和耳朵，掳去你的儿女，城中剩下的人都要死于刀下，被火吞噬。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 16:39; 耶利米书 13:22; 以西结书 23:29"> 他们要剥下你的衣服，夺去你的珠宝。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 16:41; 以西结书 23:3; 以西结书 23:19"> 我要借此制止你从埃及染上的淫乱和放荡，使你不再向往和留恋埃及。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 23:22; 以西结书 23:17; 耶利米书 34:20"> “主耶和华说，‘我要把你交在你憎恶的人手中，交在那些你始乱终弃的人手中，</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 16:39; 以西结书 23:25–26; 以西结书 23:45–47"> 他们必满怀仇恨地对付你，夺去你努力得来的一切，留下你赤身露体，使你淫荡的丑恶公布于众。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 6:9; 诗篇 106:35–38; 耶利米书 2:18–20"> 因为你与各国苟合，被他们的偶像玷污，这些事必临到你身上。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 21:13; 耶利米书 7:14–15; 以西结书 16:47–51"> 你既然步你姐姐的后尘，我要让你喝她喝的那杯。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 51:17; 诗篇 60:3; 以西结书 22:4–5"> “主耶和华说，<br /><span className="pl pl-1">“‘你必喝你姐姐那又大又深的杯，</span><br /><span className="pl pl-1">你必遭人耻笑和辱骂，</span><br /><span className="pl pl-1">因为那杯能盛很多。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 51:17; 耶利米书 25:27; 耶利米书 25:15–16"> <span className="pl pl-1">你姐姐撒玛利亚的杯盛满了恐惧和凄凉。</span><br /><span className="pl pl-1">你喝了后必酩酊大醉，</span><br /><span className="pl pl-1">满心忧愁。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 18:7"> <span className="pl pl-1">你必把它喝光，一滴不剩，</span><br /><span className="pl pl-1">然后把杯摔成碎片，</span><br /><span className="pl pl-1">抓破自己的胸脯，</span><br /><span className="pl pl-1">因为我已经宣告。</span><br /><span className="pl pl-1">这是主耶和华说的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:9; 以赛亚书 17:10; 耶利米书 32:33"> “主耶和华说，‘你既忘记我，把我抛在脑后，就要受自己放荡淫乱的报应。’”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结书 22:2; 以赛亚书 58:1; 以西结书 16:2"> 耶和华又对我说：“人子啊，你要审判阿荷拉和阿荷利巴，指出她们的丑行。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 16:36; 耶利米书 32:35; 耶利米书 7:31"> 她们淫荡，手上沾满血腥，与偶像淫乱，把为我所生的儿女烧死献给偶像。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结书 20:13; 列王纪下 21:7; 以西结书 7:20"> 同时，她们还这样在同一天玷污我的圣所，亵渎我的安息日，</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪下 21:4; 以西结书 44:7; 耶利米书 23:11"> 她们焚烧自己的儿女献祭给偶像，并在当天进入我的圣所，亵渎圣所。这就是她们在我圣所里的恶行。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王纪下 9:30; 耶利米书 4:30; 以西结书 16:13–16"> “她们甚至派使者去请远方的人，请来之后，就沐浴洗身，描眉画眼，佩戴首饰，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖记 1:6; 耶利米书 44:17; 以赛亚书 65:11"> 坐在华丽的床上，面前的桌子上摆设着我的香料和膏油。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 16:11–12; 启示录 12:3; 出埃及记 32:18–19"> 她们身边传出一群人的作乐声，从旷野来的酒徒和粗汉把镯子戴在这对姊妹的手腕上，把华冠戴在她们的头上。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 23:3; 耶利米书 13:23; 以斯拉记 9:7"> 关于这因纵欲而色衰的妇人，我说，‘这些人会继续与她淫乱。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 23:9–13; 以西结书 23:3"> 他们与这对淫妇阿荷拉和阿荷利巴淫乱，好像与娼妓淫乱一样。</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿书 6:5; 利未记 20:10; 以西结书 23:36–39"> 她们是双手沾满血腥的淫妇，必有义人按她们应得的报应审判她们。’</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以西结书 16:40; 耶利米书 15:4; 耶利米书 24:9"> “主耶和华说，‘我要使许多人起来攻击、抢掠她们，叫她们胆战心惊。</span>
<span className="v" id="v47" data-v="47" data-xref="以西结书 16:40–41; 耶利米书 39:8; 以西结书 24:21"> 这些人要用石头打死她们，用刀杀戮她们，并杀死她们的儿女，用火烧毁她们的房屋。</span>
<span className="v" id="v48" data-v="48" data-xref="以西结书 6:6; 以西结书 23:27; 以西结书 16:41"> 这样，我便清除了这地方的淫乱，所有的妇女都引以为戒，不敢效法她们。</span>
<span className="v" id="v49" data-v="49" data-xref="以西结书 9:10; 以西结书 7:4; 以西结书 6:7"> 她们淫乱，必得报应；她们拜偶像，必受惩罚。这样，她们就知道我是主耶和华。’”</span>
</div>
</div>

## 君王，利未人和祭司

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 43:1; 以西结书 40:17; 以西结书 42:14"> 那人又把我带到圣所外院的东门，门关闭着。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 43:2–4; 出埃及记 24:10; 以赛亚书 6:1–5"> 耶和华对我说：“这门必须关闭，不可打开。人不可从这门进入，因为以色列的上帝耶和华已从这门进入，所以这门必须关闭。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 46:2; 以西结书 34:24; 以西结书 37:25"> 只有君王可以坐在里面，在耶和华面前进食。他要从门廊进入，也要从原路出去。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:28; 启示录 1:17; 以西结书 3:23"> 他带我从北门来到殿前，我看见耶和华的荣光充满了祂的殿，我就俯伏在地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 40:4; 以西结书 43:10–11; 申命记 12:32"> 耶和华对我说：“人子啊，你要认真看，仔细听我讲有关耶和华圣殿的一切规矩和法则，记住所有的出入口。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 3:9; 以西结书 45:9; 彼得前书 4:3"> 然后告诉那些叛逆的以色列人，主耶和华这样说，‘以色列人啊，你们行可憎的事，该够了吧！</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 22:25; 耶利米书 9:26; 以西结书 44:9"> 你们献上食物、脂肪和血的同时，竟将那些身心未受割礼的外族人领进我的圣所，亵渎我的殿，破坏我的约，使你们罪上加罪。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 44:14; 民数记 18:3–5; 以西结书 40:45–46"> 你们自己不管理我的圣物，却把我的圣所给外人治理。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约珥书 3:17; 以西结书 44:7; 撒迦利亚书 14:21"> “‘因此，主耶和华说：以色列人中身心未受割礼的外族人不可进入我的圣所。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:26; 以西结书 48:11; 列王纪下 23:8–9"> “‘以色列人走入歧途时，有些利未人也远离我、追随偶像，他们必须承担自己犯罪的后果。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 16:9; 历代志下 29:34; 历代志下 30:17"> 然而，他们仍可以在我的圣殿供职，看管殿门，为百姓屠宰燔祭牲和其他祭牲，服侍他们。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:10–16; 诗篇 106:26; 以西结书 14:3–4"> 因为利未人带动以色列人拜偶像，使以色列人陷入罪中，所以我起誓，他们必承担自己犯罪的后果。这是主耶和华说的。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 18:3; 列王纪下 23:9; 以西结书 16:61"> 他们不得走近我，不可做我的祭司，也不得走近我的圣物或至圣之物，他们必因自己的可憎行径蒙羞。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 23:28–32; 民数记 18:4"> 然而，我要委派他们管理圣殿，办理殿中所有的事务。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 10:8; 以西结书 48:11; 以西结书 44:7"> “‘以色列人走入歧途时，利未祭司——撒督的子孙仍然在我的圣所尽忠职守，因此他们可以接近我、事奉我，侍立在我面前，献上祭牲的脂肪和血。这是主耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 41:22; 玛拉基书 1:12; 民数记 18:7–8"> 只有他们可以进入我的圣所，在我的桌前事奉我，遵行我的吩咐。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 19:8; 出埃及记 28:43; 出埃及记 39:27–29"> 他们从内院的门进入殿内供职的时候，要穿细麻布衣服，不可穿羊毛衣服。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 39:28; 哥林多前书 11:4–10; 以赛亚书 3:20"> 他们要戴细麻布头巾，穿细麻布裤子，不可穿使人容易出汗的衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 46:20; 利未记 6:27; 利未记 6:10–11"> 他们出去外院见百姓的时候，必须脱下供职时穿的衣服，放在圣屋，穿上普通的衣服后再出去，免得通过圣衣把圣洁带到百姓身上。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 11:14; 民数记 6:5; 利未记 21:5–24"> 他们不可剃光头，也不可留长头发，只可修剪头发。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 10:9; 提多书 1:7–8; 提摩太前书 5:23"> 祭司进入内院时，不可喝酒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 21:7; 利未记 21:13–14; 提摩太前书 3:2"> 他们不可娶寡妇或被休的妇女为妻，只能娶以色列的处女或祭司的遗孀。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 22:26; 利未记 10:10–11; 提摩太后书 2:24–25"> 他们要教导我的子民辨别圣与俗，洁净与不洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 23:4; 以西结书 22:26; 历代志下 19:8–10"> 他们要审理诉讼之事，按我的律例断是非。他们必须按我定的律例和法度遵守一切节期，守安息日为圣日。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 5:16; 利未记 22:4; 马太福音 8:21–22"> 他们不可走近死尸，免得玷污自己，除非死者是自己的父母、子女、弟兄或未出嫁的姊妹。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:13–14; 民数记 19:11–14; 民数记 6:10–21"> 祭司得到洁净后，必须再等七天。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 6:9–11; 以西结书 44:17; 利未记 4:3–35"> 他进入内院的圣所事奉时，要为自己献上赎罪祭，这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 13:33; 民数记 18:20; 申命记 18:1–2"> “‘我是祭司的产业。祭司不可在以色列拥有自己的产业，因为我就是他们的产业。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 18:14; 利未记 27:21; 利未记 27:28"> 他们的食物是以色列人献上的素祭、赎罪祭和赎过祭。凡以色列人献给耶和华的都归他们，</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 10:35–37; 历代志下 31:10; 申命记 18:4"> 各种初熟的出产和各种供物中上好的部分都要归给祭司。你们将初熟的麦子磨成面给祭司，福气就必临到你们的家。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 22:8; 出埃及记 22:31; 申命记 14:21"> 无论是自然死亡的，还是被其他野兽咬死的禽兽，祭司都不可吃。</span>
</div>
</div>

## 祭司用的厢房

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 40:20; 以西结书 40:17; 以西结书 42:13"> 那人带我出了圣殿，向北来到外院的厢房，一排在空地对面，一排在北边的建筑物对面。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 41:13"> 厢房长五十米，宽二十五米，有北门。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 41:15–16; 以西结书 41:10; 雅歌 7:5"> 内院十米宽的空地对面和外院的铺石地对面有三层走廊，彼此相对。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 46:19; 路加福音 13:24; 马太福音 7:14"> 在两排厢房之间有一条五米宽、五十米长的通道，厢房的门都向北。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 41:7"> 上层的厢房比下层和中层的窄，因为上层走廊占去较大的面积。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 41:6; 列王纪上 6:8"> 这建筑物不像外院那样有柱子，所以上层比中层和下层窄。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 42:12; 以西结书 42:10"> 厢房旁边有道外墙与厢房及外院平行，长二十五米。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 41:13–14"> 靠近外院的厢房长二十五米，靠近圣殿的厢房则长五十米。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 46:19; 以西结书 44:5"> 下层厢房的东面有一道门，可以从外院进入。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 42:1; 以西结书 42:13; 以西结书 41:12–15"> 南面<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“南面”希伯来文是“东面”。">a</a></sup>的院墙有两排厢房，一排在空地对面，一排在南面的建筑物对面，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 42:4"> 厢房前面有通道。这些厢房与北面的厢房一样，长宽相同，出入口和结构也一样。</span>
<span className="v" id="v12" data-v="12"> 南厢房的门也和北面的一样，厢房东面通道的前端有一道门可以进入。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 10:17; 利未记 7:6; 以西结书 40:46"> 他对我说：“这些在南北两面对着圣殿空地的厢房都是圣洁的，供事奉耶和华的祭司在那里吃至圣的祭物，并放置素祭、赎罪祭和赎过祭等至圣的祭物，因为这是圣洁的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 44:19; 利未记 8:7; 出埃及记 29:4–9"> 祭司在圣所供职后，不可直接到外院，要先在这些厢房里脱下供职时所穿的圣衣，换上普通衣服，才可以到外面的百姓那里。”</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 43:1; 以西结书 41:15; 以西结书 40:6–16"> 他量完圣殿里面，便带我出了东门，量圣殿外围。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 40:3; 启示录 11:1–2; 撒迦利亚书 2:1"> 他用量竿量了东面，长二百五十米；</span>
<span className="v" id="v17" data-v="17"> 又量了北面，长二百五十米；</span>
<span className="v" id="v18" data-v="18"> 又量了南面，长二百五十米；</span>
<span className="v" id="v19" data-v="19"> 然后又去量西面，长二百五十米。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 45:2; 以西结书 22:26; 以西结书 40:5"> 他量了圣殿的四围，四围有一道墙，长宽都是二百五十米，这墙是为了把圣地和俗地隔开。</span>

## 预言赐福以色列

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 37:4; 以西结书 34:14; 以西结书 37:22"> “人子啊，你要向以色列的山岭预言说，‘以色列的山岭啊，你们要听耶和华的话！</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:13; 以西结书 25:3; 以西结书 35:10"> 主耶和华这样说：仇敌说，“哈哈，这古老的山峰归我们了！”’</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米书 18:16"> 所以你要说预言，宣告主耶和华这样说：他们四面蹂躏、摧毁你们，使你们归列国所有，成了外族人的话柄和笑谈。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 34:28; 申命记 11:11; 以西结书 36:6"> 因此，以色列的山岭啊，你们要听主耶和华的话。以下是主耶和华对高山和丘陵，溪流和河谷，荒凉的废墟，以及被周围列国掳掠和讥笑的废弃城邑所说的话。</span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:8; 以西结书 36:3; 诗篇 137:7"> 主耶和华说：我要在怒火中斥责列国和以东，他们幸灾乐祸，满腹愤恨地把我的土地据为己有，侵占其中的草场。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 123:3–4; 以西结书 34:29; 诗篇 74:23"> 所以你要对以色列说预言，告诉以色列的高山、丘陵、溪流和河谷，主耶和华这样说：因为你们遭到列国的羞辱，我怀着义愤和烈怒发言。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 20:5; 阿摩司书 1:1–15; 以西结书 20:15"> 我起誓要让你们四围的列国也受羞辱。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 27:6; 希伯来书 10:37; 以西结书 34:26–29"> “‘以色列的山岭啊，你们要为我的以色列子民长出枝叶，结出果子，因为他们快要回来了。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 46:11; 何西阿书 2:21–23; 以西结书 36:34"> 看啊，我要帮助你们，垂顾你们，使你们被耕种。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 36:33; 耶利米书 33:12; 以西结书 36:37"> 我要使你们那里的以色列人增加，使城邑有人居住，废墟得以重建。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:12; 耶利米书 23:5–8; 耶利米书 31:27"> 我要使你们那里的人畜兴旺，生养众多，我要使人们居住在你们那里，好像以前一样，让你们比以前更兴盛。这样，你们就知道我是耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:7; 以西结书 36:13; 耶利米书 32:44"> 我要引领我的以色列子民在你们那里出入，使你们成为他们的产业，不再夺走他们的儿女。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 13:32"> 主耶和华说：虽然人们说你们吞吃以色列人、夺走他们的儿女，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 37:25–28; 阿摩司书 9:15; 以赛亚书 60:21"> 但你们今后必不再吞吃以色列人，不再夺走他们的儿女。这是主耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 34:29; 诗篇 89:50; 以西结书 36:6"> 我必不再使你们听见列国的辱骂，你们必不再遭受列邦的嘲笑，也不再使你们的国民丧失儿女。这是主耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华对我说：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 2:7; 民数记 35:33–34; 弥迦书 2:10"> “人子啊，当以色列人住在本土时，他们的恶行玷污了那里，他们的行为在我眼中就像经期的妇女一样污秽。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 34:21; 以西结书 7:8; 耶利米哀歌 2:4"> 他们杀人流血，祭拜偶像，玷污了那地方，所以我要把我的烈怒倾倒在他们身上，</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 39:24; 申命记 28:64; 以西结书 5:12"> 把他们驱散到列国，分散到列邦，照他们的行为报应他们。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 2:24; 以赛亚书 52:5; 耶利米书 33:24"> 他们无论分散到何处，都使我的圣名受到亵渎，因为外族人都谈论他们说，‘这些人是耶和华的子民，却不得不离开耶和华的土地。’</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 48:9; 诗篇 74:18; 以西结书 20:9"> 我顾惜我的圣名，就是以色列人在所去的列国亵渎的圣名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 106:8; 以西结书 36:32; 诗篇 115:1–2"> “因此，你要告诉以色列人，主耶和华这样说，‘以色列人啊，我要行这事并非因为你们的缘故，而是因为我圣名的缘故，就是你们在所去列国亵渎的圣名。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 20:41; 以赛亚书 5:16; 以西结书 39:7"> 我要使我伟大的名，就是你们在列国中所亵渎的名，彰显它的圣洁。我要当着列国的面在你们身上彰显我的圣洁，那时他们就知道我是耶和华。这是主耶和华说的。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 37:21; 以西结书 34:13; 阿摩司书 9:14–15"> 我要把你们从列国领出来，从列邦招聚你们，带你们返回故土。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:22; 约翰福音 3:5; 耶利米书 33:8"> 我要在你们身上洒清水洁净你们，洗净你们所有的污秽，除掉你们一切的偶像。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 11:19–20; 诗篇 51:10; 哥林多后书 5:17"> 我要赐你们一颗新心，把新的灵放在你们里面。我要除去你们的石心，赐给你们一颗肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多书 3:3–6; 希伯来书 13:21; 哥林多前书 3:16"> 我要把我的灵放在你们里面，使你们恪守我的律例、谨遵我的典章。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 31:33; 耶利米书 32:38; 以西结书 37:27"> 这样，你们必安居在我赐给你们祖先的土地上，你们要做我的子民，我要做你们的上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 1:7–9; 马太福音 1:21; 何西阿书 2:21–23"> 我要拯救你们脱离一切污秽之事。我要使你们五谷丰登，不让饥荒侵害你们。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 34:27; 约珥书 2:26; 申命记 29:23–28"> 我要使树木硕果累累，田间出产丰盛，免得你们因饥荒再被外族人讥笑。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 6:9; 以西结书 20:43; 尼希米记 9:26–35"> 那时，你们便会想起自己邪恶的行径，并因自己的罪恶和可憎行为而厌恶自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 9:5; 以西结书 36:22; 提摩太后书 1:9"> 主耶和华说：你们要知道，我这样做并不是为了你们。以色列人啊，你们应当为自己的行为抱愧蒙羞。’</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 58:12; 以西结书 36:10; 耶利米书 33:10"> “主耶和华说，‘在我洗净你们一切罪恶的日子，我要使你们的城邑有人居住，废墟得以重建。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 6:14; 耶利米书 25:9–11; 历代志下 36:21"> 荒凉之地必有人耕种，路人再也看不见荒地。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 51:3; 约珥书 2:3; 耶利米书 33:9"> 他们会说：以前的荒凉之地如今竟变得像伊甸园，被毁坏废弃的荒凉城邑已经设防，有人居住。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 24:35; 民数记 23:19; 以西结书 17:24"> 这样，你们四周其余的列国便知道我耶和华已重建毁坏之处，重新耕种荒废之地。我耶和华言出必行。’</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 5:14; 希伯来书 10:21–22; 以西结书 14:3"> “主耶和华说，‘我要再次答应以色列人的恳求，使他们的人口增加，多如羊群。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 8:63; 使徒行传 2:5–11; 约翰福音 10:16"> 我要使毁坏的城邑住满人，多如耶路撒冷在节期所献上的羊群。这样，他们就知道我是耶和华。’”</span>
</div>
</div>

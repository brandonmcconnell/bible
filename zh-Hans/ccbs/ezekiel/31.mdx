## 香柏树的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 30:20; 耶利米书 52:5–6; 以西结书 1:2"> 第十一年三月一日，耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 29:19; 以西结书 30:10; 以西结书 31:18"> “人子啊，你要对埃及王法老和他的百姓说，<br /><span className="pl pl-1">“‘谁能比你强大呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 10:33–34; 但以理书 4:10; 但以理书 4:20–23"> <span className="pl pl-1">看啊，亚述曾是黎巴嫩的一棵香柏树，</span><br /><span className="pl pl-1">枝繁叶茂，遮天蔽日，</span><br /><span className="pl pl-1">高耸入云。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 17:15; 箴言 14:28; 以西结书 17:5"> <span className="pl pl-1">水源滋润它，</span><br /><span className="pl pl-1">深泉使它茁壮成长，</span><br /><span className="pl pl-1">溪流四围环绕它，</span><br /><span className="pl pl-1">浇灌着林间的树木。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 4:11; 以西结书 17:5; 诗篇 1:3"> <span className="pl pl-1">丰沛的水源使它高过田间所有的树木，</span><br /><span className="pl pl-1">枝子长得又粗又长。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:23; 马太福音 13:32; 但以理书 4:12"> <span className="pl pl-1">空中的飞鸟都在它的枝头上搭窝，</span><br /><span className="pl pl-1">田间的野兽都在它的枝条下生产，</span><br /><span className="pl pl-1">所有的大国都住在它的荫下。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">它高大美丽，枝干修长，</span><br /><span className="pl pl-1">因为树根深入丰沛的水源，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 28:13; 创世记 13:10; 以赛亚书 51:3"> <span className="pl pl-1">连上帝园中的香柏树也不能与它相比。</span><br /><span className="pl pl-1">松树不能与它的枝干相比，</span><br /><span className="pl pl-1">枫树不能与它的枝条相比，</span><br /><span className="pl pl-1">上帝园中的树木没有一棵能与它媲美。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 28:13; 但以理书 2:37–38; 创世记 13:10"> <span className="pl pl-1">我使它枝繁叶茂，美丽无比，</span><br /><span className="pl pl-1">以致上帝伊甸园里的树木都羡慕它。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 28:17; 但以理书 5:20; 历代志下 32:25"> “因此，主耶和华说，‘因为它树干高大，树梢高耸入云，心高气傲，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 32:11–12; 那鸿书 3:18; 但以理书 5:18–19"> 我要把它交在列国的首领手里，他必按照它的邪恶惩治它。我丢弃了它。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 28:7; 以西结书 35:8; 以西结书 30:11"> 列邦中最残暴的人要把它砍倒，丢弃在那里，它折断的枝干散落在山间和河谷中。世上各族都离开它的荫下，弃他而去，</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 32:4; 以西结书 29:5; 以赛亚书 18:6"> 天上的飞禽要栖身在那折断的树干上，地上的走兽要躺卧在它的枝条中。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 63:9–10; 尼希米记 13:18; 彼得后书 2:6"> 故此，水边的树木都不再傲然矗立，高耸入云，水源充足的大树也不再如此高大，因为它们都注定要与下坟墓的人一同死亡，落到阴间的深处。’</span>
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 3:4; 那鸿书 2:8–10; 启示录 18:9–11"> “主耶和华说，‘它下到阴间的那天，我要使哀声响起，使深渊闭塞，江河止息，洪水停滞。我要使黎巴嫩为它哀哭，田野的树木都因它而枯萎。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 14:15; 以赛亚书 14:8; 以西结书 26:15"> 我将它与下坟墓的人一同抛到阴间时，列国听见它坠落的响声，都恐惧颤抖。伊甸园中的树木和黎巴嫩水源充足的上好树木都在阴间得到安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:17; 以西结书 31:6; 以西结书 31:3"> 列国中活在它荫庇下的爪牙都与它一同坠入阴间，到丧身刀下的人那里。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 32:19; 以西结书 32:21; 以西结书 28:10"> “‘伊甸园的树木中，谁能与你的威荣相比呢？然而你必与伊甸园的树木一同下到阴间，躺卧在未受割礼的人当中，与丧身刀下的人在一起。 “‘这就是法老和他百姓的结局。这是主耶和华说的。’”</span>

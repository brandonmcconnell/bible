## 耶和华立以西结为守望者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 33:30; 以西结书 33:17; 以西结书 3:11"> “人子啊，你要告诉你的同胞，‘如果我使战争降临某地，那地方的百姓就应从他们中间选一人做守望者。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 8:1; 尼希米记 4:20; 尼希米记 4:18"> 守望者若发现敌人来攻打，便吹号警告百姓。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:13; 使徒行传 18:6; 耶利米书 6:17"> 凡听见号声而不接受警告的，敌人来把他杀了，这流血的罪就要由他自己承担。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 9:19–21; 希伯来书 11:7; 约翰福音 8:39"> 因为他听见号声，却不接受警告，他的死是咎由自取。他若接受警告，就保全了自己的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 3:18–20; 以西结书 33:8–9; 创世记 42:22"> 但如果守望者看见敌人来攻打却不吹号警告百姓，以致有人被敌人杀了，那人固然是因自己的罪恶而被杀，我却要向守望者追讨那人被杀的血债。’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 3:17–21; 耶利米书 26:2; 以西结书 2:7–8"> “人子啊，我立你为以色列人的守望者，你要听我口中的话并替我告诫他们。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 20:26–27; 以西结书 33:6; 以西结书 33:14"> 如果我说恶人必定死，你却不告诫他改邪归正，他必因自己的罪而死，我却要向你追讨他的血债。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 3:19; 使徒行传 20:26; 箴言 15:10"> 如果你告诫恶人要改邪归正，他却不肯，他必因自己的罪而死，而你必保全性命。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 49:14; 以西结书 37:11; 以西结书 24:23"> “人子啊，你要对以色列人说，‘你们说：我们背负过犯和罪恶，正因此而灭亡。我们怎能存活下去呢？</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:4; 以西结书 18:23; 彼得后书 3:9"> 你要告诉他们，主耶和华说：我凭我的永恒起誓，我绝不喜欢恶人死亡，我更愿意恶人改邪归正，得以存活。以色列人啊，回头吧！改邪归正吧！何必自取灭亡呢？’</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 7:14; 以西结书 33:18–19; 罗马书 3:25"> 人子啊，你要对你的同胞说，‘当义人犯罪时，他以往的义救不了他；当恶人悔改时，他以往的恶不会使他灭没。义人若犯罪，他以往的义不能使他存活。’</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 18:24; 希伯来书 10:38; 以西结书 18:4"> 我虽对义人说他必能存活，但如果他仗着自己的义而作恶，他从前的义行不会被记念，他必因自己的恶行而死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 18:27; 耶利米书 18:7–8; 何西阿书 14:1"> 我虽对恶人说他必定要死，但他若改邪归正，秉公行义，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 20:11; 路加福音 19:8; 出埃及记 22:1–4"> 偿还抵押，归还赃物，遵行生命之律例，不再犯罪，就必活着，不致死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 43:25; 以西结书 18:22; 弥迦书 7:18–19"> 他犯的罪不会被追究，他必因秉公行义而活着。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 25:24–26; 以西结书 18:25; 以西结书 18:29"> “你的同胞却说：主行事不公平。其实是他们自己行事不公。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 33:12–13; 彼得后书 2:20–22; 希伯来书 10:38"> 义人若离义行恶，必因恶行而死。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 18:27–28; 以西结书 33:14"> 恶人若改邪归正、秉公行义，必因此而活。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 16:27; 以西结书 18:25; 以西结书 33:17"> 可是你们却说，主行事不公平。以色列人啊，我必按你们各人的行为审判你们。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 1:2; 耶利米书 39:1–8; 列王纪下 25:4"> 在我们被掳后第十二年十月五日，有人从耶路撒冷逃出来对我说：“城已经沦陷了。”</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 1:3; 以西结书 3:26–27; 以西结书 24:26–27"> 逃难的人来的前一晚，耶和华的手一直按在我身上，开了我的口。那人早上来到我这里时，耶和华已经开了我的口。于是我就开口说话，不再沉默。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华对我说：</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 33:27; 以赛亚书 51:2; 使徒行传 7:5"> “人子啊，那些住在以色列废墟中的人说，‘亚伯拉罕一人尚且能拥有这片土地，我们这么多人更能拥有这片土地为业。’</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 12:16; 耶利米书 7:9–10; 创世记 9:4"> 因此，你要告诉他们，主耶和华这样说，‘你们吃带血的肉，仰赖偶像，又杀人流血，怎能拥有这片土地呢？</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:40; 弥迦书 2:1–2; 西番雅书 3:3"> 你们靠刀剑行可憎之事，个个玷污别人的妻子，你们怎能拥有这片土地呢？’</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 13:6; 耶利米书 42:22; 以西结书 39:4"> 你要告诉他们，主耶和华这样说，‘我凭我的永恒起誓，那些住在废墟中的必死于刀下，逃到田野的必被野兽吞吃，躲进堡垒和洞穴的必死于瘟疫。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 7:24; 耶利米书 44:2; 耶利米书 44:6"> 我要使这片土地荒凉不堪，使她所夸耀的势力消逝。以色列的山必荒凉，杳无人迹。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 6:7; 以西结书 36:17–18; 以西结书 22:2–15"> 因为他们所行的一切可憎之事，我必使这地方荒凉不堪，那时他们就知道我是耶和华。’</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 22:16–17; 耶利米书 23:35; 以赛亚书 29:13"> “人子啊，你的同胞在墙边和门口彼此议论你说，‘来，听听从耶和华而来的信息。’</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 13:22; 诗篇 78:36–37; 雅各书 1:22–24"> 他们蜂拥而来，坐在你面前聆听你的话，俨然是我的子民。但他们不付诸实行，嘴里说的是甜言蜜语，心中却追求不义之财。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 6:20; 马可福音 4:16–17; 约翰福音 5:35"> 他们只听不做，你在他们眼中只不过是嗓音优美、善唱情歌、长于奏乐的人。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 28:9; 撒母耳记上 3:19–20; 以西结书 2:5"> 看吧，你所说的必定应验。当一切应验的时候，他们就知道有先知在他们当中。”</span>
</div>
</div>

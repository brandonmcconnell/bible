## 以色列人的悖逆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 30:20; 以西结书 24:1"> 第七年五月十日，有几个以色列的长老来求问耶和华，他们坐在我面前。</span>
<span className="v" id="v2" data-v="2"> 耶和华对我说：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 马太福音 15:8–9; 诗篇 50:15–21"> “人子啊，你要告诉他们，主耶和华这样说，‘你们是来求问我吗？我凭我的永恒起誓，我决不让你们求问。’这是主耶和华说的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 22:2; 以西结书 23:36; 以西结书 14:20"> 人子啊，你要审判他们吗？你要审判他们吗？要使他们知道他们祖先所做的可憎之事。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:6; 以西结书 20:15; 出埃及记 3:8"> 你要告诉他们，主耶和华这样说，‘我拣选以色列那日，曾向雅各家的后裔起誓，又在埃及让他们认识我，告诉他们我是他们的上帝耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:8; 耶利米书 32:22; 以西结书 20:15"> 那日我向他们起誓，要带领他们离开埃及，到我为他们选定的奶蜜之乡，世上最佳美的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 18:3; 以西结书 20:8; 利未记 11:44"> 我告诉他们要除掉他们祭拜的可憎之物，不可让埃及的偶像玷污自己，因为我是他们的上帝耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 20:7; 以赛亚书 63:10; 以西结书 20:21"> “‘然而，他们却背叛我，不听我的话，没有除去他们恋慕的可憎之物，也没有弃绝埃及的偶像。我本想在埃及向他们发烈怒，倾倒我的怒火，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 39:7; 以西结书 20:22; 出埃及记 32:12"> 但我没有这样做，以免我的名在他们寄居的列邦面前被亵渎。因为我曾在列邦眼前让以色列人认识我，把他们带出埃及。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 15:22; 出埃及记 13:17–18; 出埃及记 14:17–22"> 于是，我带他们离开埃及，进入旷野，</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 10:5; 利未记 18:5; 申命记 4:8"> 向他们颁布我的律例并显明我的典章，遵行的人必因此而活。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 20:20; 以西结书 37:28; 利未记 21:23"> 我又让他们遵守我的安息日，作为我与他们之间的记号，好叫他们知道是我耶和华使他们成为圣洁之民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:21; 以西结书 20:8; 以赛亚书 56:6"> “‘可是，以色列人却在旷野背叛我，不遵行我的律例，还弃绝我的典章，而遵行的人必因此而活。他们大肆亵渎我的安息日。我本想在旷野向他们发烈怒，灭绝他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 20:9; 以西结书 36:22–23; 以西结书 20:22"> 但我没有这样做，以免我的名在周围列邦面前被亵渎，因为我在列邦眼前把以色列人带出埃及。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 95:11; 诗篇 106:26; 希伯来书 3:18"> 而且，我在旷野曾向他们发誓，不带他们进入我赐给他们的那奶蜜之乡，那世上最佳美的地方，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 15:39; 以西结书 20:8; 以西结书 14:3–4"> 因为他们弃绝我的典章，不顺从我的律例，亵渎我的安息日，心恋偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 11:13; 耶利米书 4:27; 耶利米书 5:18"> 但我怜悯他们，没有毁灭他们，没有在旷野把他们全部灭绝。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 1:2–4; 诗篇 78:6–8; 彼得前书 1:18"> “‘我在旷野曾对他们的子孙说，不要效法你们祖先的律例，不要遵守他们的规条，不要拜他们的偶像，以致玷污自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:27; 申命记 5:32–8; 以西结书 37:24"> 我是你们的上帝耶和华，你们要恪守我的律例，谨遵我的典章，</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 58:13; 耶利米书 17:22; 出埃及记 31:13–17"> 尊我定的安息日为圣日，作为我与你们之间的记号，使你们知道我是你们的上帝耶和华。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 20:13; 民数记 21:5; 以西结书 20:8"> “‘可是，他们的子孙却背叛我，不恪守我的律例，不谨遵我的典章，而遵行的人必因此而活。他们亵渎我的安息日。我本想在旷野向他们发烈怒，倾倒我的怒气，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:14; 以西结书 20:9; 耶利米书 14:21"> 但我没有这样做，以免我的名在周围列邦面前被亵渎，因为我在列邦眼前把以色列人带出埃及。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:33; 申命记 28:64–68; 申命记 32:26–27"> 而且，我在旷野起誓要把他们驱散到列国，分散到列邦，</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 20:16; 以西结书 6:9; 阿摩司书 2:4"> 因为他们不遵行我的典章，弃绝我的律例，亵渎我的安息日，眼睛恋慕他们祖先的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:12; 以赛亚书 66:4; 以西结书 20:39"> 所以，我任由他们遵行无用的律例，遵守无法使人活着的规条，</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 6:7; 利未记 18:21; 以西结书 20:31"> 任由他们把自己的长子烧作祭物献给偶像，以致玷污自己，好使他们充满恐惧，这样他们便知道我是耶和华。’</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 2:24; 以西结书 2:7; 以西结书 3:11"> “人子啊，你要告诉以色列人，主耶和华这样说，‘你们的祖先还背信弃义，亵渎了我。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 6:13; 尼希米记 9:22–26; 耶利米书 3:6"> 当我引领他们进入我曾起誓要赐给他们的土地时，他们在所见的每一处高山或茂密的树下献祭，献上惹我发怒的供物，焚烧馨香的祭，向偶像奠酒。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 16:24–25; 以西结书 16:31"> 我问他们，你们所去的高处是什么地方？’从此，那高处一直叫巴麻<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“巴麻”即“高处”的意思。">a</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 16:12; 耶利米书 7:26; 士师记 2:19"> “所以，你要告诉以色列人，主耶和华这样说，‘你们仍像你们祖先一样玷污自己，与可憎的偶像苟合吗？</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 20:26; 诗篇 106:37–39; 耶利米书 7:31"> 你们至今仍焚烧自己的儿子献为祭物，用你们的一切偶像玷污自己。以色列人啊，我会让你们求问我吗？主耶和华说，我凭我的永恒起誓，我决不让你们求问。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 11:5; 耶利米书 44:17; 诗篇 139:2"> “‘你们说要像列邦列族一样去供奉木头石头，你们的想法绝不能实现！’</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 21:5; 以西结书 8:18; 耶利米书 44:6"> “主耶和华说，‘我凭我的永恒起誓，我要发烈怒，伸出臂膀用大能的手治理你们。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 20:38; 阿摩司书 9:9–10; 以西结书 34:16"> 我要发烈怒，伸出臂膀用大能的手把你们从列国中领出来，从你们散居的列邦聚集你们，</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿书 2:14; 耶利米书 2:35; 以西结书 17:20"> 领你们进入列国的旷野，面对面地审判你们。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 10:5–10; 民数记 11:1–35; 以西结书 20:13"> 我从前在埃及的旷野怎样审判你们的祖先，也必怎样审判你们。这是主耶和华说的。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 33:13; 利未记 27:32; 马太福音 25:32–33"> 我要对你们严加管教<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“对你们严加管教”希伯来文是“让你们在杖下经过”。">b</a></sup>，使你们遵守我的约。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结书 13:9; 阿摩司书 9:9–10; 诗篇 95:11"> 我要铲除你们中间叛逆和犯罪的人。虽然我要领他们离开寄居之地，他们却不能回以色列。这样，你们就知道我是耶和华。’</span>
<span className="v" id="v39" data-v="39" data-xref="何西阿书 4:17; 以赛亚书 1:13–15; 以西结书 43:7"> “主耶和华说，‘你们以色列人若不听我的话，就去供奉你们的偶像吧！但将来你们必不再向偶像献祭物亵渎我的圣名！’</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 56:7; 玛拉基书 3:4; 以赛亚书 60:7"> “主耶和华说，‘在我的圣山，就是以色列的高山上，所有的以色列人都要事奉我，我要在那里悦纳你们，要求你们献上供物、最好的礼物和一切圣物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 28:25; 以西结书 11:17; 以西结书 38:23"> 当我把你们从列国领出来，从你们散居的列邦聚集起来时，你们必如馨香之祭一样蒙我悦纳，我必当着列国的面在你们中间彰显我的圣洁。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 34:13; 以西结书 38:23; 以西结书 36:23–24"> 我要把你们带回我起誓要赐给你们祖先的以色列，这样你们就知道我是耶和华。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 6:9; 何西阿书 5:15; 耶利米书 31:18"> 你们在那里会想起以往玷污自己的行径，并因自己的一切恶行而憎恶自己。’</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 24:24; 诗篇 115:1; 以西结书 20:9"> 主耶和华说，‘以色列人啊，我为了自己的名，没有照你们邪恶败坏的行径惩罚你们，这样你们便知道我是耶和华。’”</span>
<span className="v" id="v45" data-v="45"> 耶和华对我说：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司书 7:16; 以西结书 21:2; 耶利米书 13:19"> “人子啊，你要面向南方，开口斥责南方，说预言斥责南地的树林。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米书 21:14; 以赛亚书 24:1–6; 以西结书 17:24"> 你要对南地的树林说，‘你要听耶和华的话。主耶和华说，我要在你那里燃起火来，烧毁你所有的青树和枯树。这不熄的烈火要从南到北烧焦一切。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 40:2–3; 耶利米书 7:20; 申命记 29:24–28"> 这样，世人便知道这烈火是我耶和华点燃的，它绝不会熄灭。’”</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 16:25; 使徒行传 17:18; 以西结书 17:2"> 于是我说：“唉，主耶和华啊，他们在议论我说，‘他岂不是在说比喻吗？’”</span>

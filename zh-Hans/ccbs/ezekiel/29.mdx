## 预言审判埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 29:17; 以西结书 26:1; 以西结书 20:1"> 第十年十月十二日，耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 6:2; 耶利米书 44:30; 耶利米书 46:2–16"> “人子啊，你要面向埃及王法老，说预言斥责他和整个埃及，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 32:2; 以赛亚书 27:1; 耶利米书 44:30"> 你要告诉他，主耶和华这样说，<br /><span className="pl pl-1">“‘埃及王法老啊，</span><br /><span className="pl pl-1">你这躺卧在自己河中的大怪物，</span><br /><span className="pl pl-1">我要与你为敌。</span><br /><span className="pl pl-1">你说这尼罗河属于你，</span><br /><span className="pl pl-1">是你为自己造的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:28; 以西结书 38:4; 阿摩司书 4:2"> <span className="pl pl-1">但我要钩住你的腮，</span><br /><span className="pl pl-1">使河中的鱼贴在你的鳞甲上，</span><br /><span className="pl pl-1">把你连同贴在你鳞甲上的鱼一起从河中拉上来，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 34:20; 以西结书 32:4–6; 耶利米书 8:2"> <span className="pl pl-1">把你和你河中的鱼都丢弃在旷野。</span><br /><span className="pl pl-1">你必暴尸野外，无人收殓。</span><br /><span className="pl pl-1">我要让你成为走兽飞禽的食物。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 18:21; 以赛亚书 36:6; 出埃及记 9:14"> “‘这样，所有的埃及人就知道我是耶和华，因为你不过是一根以色列人无法依靠的芦苇杖。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 36:6; 以西结书 17:15–17; 耶利米书 17:5–6"> 当他们用手握住你的时候，你就断裂，刺伤了他们的肩；当他们倚靠你的时候，你就折断，闪了他们的腰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 14:17; 以西结书 30:10; 以西结书 29:19–20"> “‘因此，主耶和华说，看啊，我要使刀剑临到你，消灭你的人畜，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 29:3; 箴言 16:18; 以西结书 29:10–12"> 使埃及一片荒凉。这样，他们就知道我是耶和华。因为你说这尼罗河属于你，是你造的。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 30:12; 以西结书 30:6–9; 出埃及记 14:2"> 因此，我要攻击你和你的河流，使埃及从密夺到色弗尼，一直到古实的边界全都荒废。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 32:13; 耶利米书 43:11–12; 以西结书 30:10–13"> 四十年之内，这里必无人居住，人畜踪迹灭绝。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 46:19; 以西结书 30:7; 以西结书 30:23"> 我必使埃及成为荒地中的荒地，让埃及的城邑沦为废墟中的废墟四十年。我要将埃及人驱赶到列国，分散到列邦。’</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 46:26; 以赛亚书 19:22"> “主耶和华说，‘四十年之后，我要把分散的埃及人从各国聚集起来。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 30:14; 以赛亚书 11:11; 耶利米书 44:1"> 我要让被掳的埃及人返乡，使他们回到本土巴特罗，成为一个卑微的国家，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 10:11; 以西结书 30:13; 以西结书 17:14"> 在列国中最衰微，再也不能雄居列国之上。我要使埃及国势衰弱，再也不能统治列国。</span>
<span className="v" id="v16" data-v="16" data-xref="何西阿书 8:13; 以赛亚书 20:5; 以西结书 29:6–7"> 埃及必不再是以色列人的指望，反而会使以色列人想起自己投靠埃及的罪。这样，他们便知道我是主耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 29:1; 以西结书 1:2; 以西结书 24:1"> 第二十七年一月一日，耶和华对我说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 27:6; 耶利米书 25:9; 以西结书 26:7–12"> “人子啊，巴比伦王尼布甲尼撒派兵苦攻泰尔，以致士兵的头都秃了，肩也破了，却是徒劳无功。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 30:24–25; 耶利米书 43:10–13; 以西结书 32:11"> 所以主耶和华说，‘我要把埃及赐给巴比伦王尼布甲尼撒，他必把埃及的财富洗劫一空，用来犒赏自己的军队。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 25:9; 以赛亚书 10:6–7; 以赛亚书 45:1–3"> 他和他的军队为我效力，所以我把埃及赐给他作为酬劳。’这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 2:10; 路加福音 21:15; 诗篇 132:17"> “到那天，我必复兴以色列<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我必复兴以色列”希伯来文是“我必使一只角从以色列兴起”。">a</a></sup>，使你以西结在他们当中开口说话，这样他们就知道我是耶和华。”</span>
</div>
</div>

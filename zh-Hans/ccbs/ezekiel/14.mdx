## 斥责拜偶像的以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 20:1; 列王纪下 6:32"> 那时，几位以色列的长老到我这里来，坐在我面前。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 3:7; 列王纪上 14:4"> 耶和华对我说：</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 14:7; 以西结书 7:19; 以西结书 20:3"> “人子啊，这些人在心里立起偶像，把导致犯罪的绊脚石放在自己面前，我岂能让他们来求问？</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 66:4; 以西结书 14:7; 以赛亚书 3:11"> 你告诉他们，主耶和华这样说，‘任何以色列人若在心里立起偶像，把导致犯罪的绊脚石放在自己面前，又来求问先知，我耶和华必按他心中偶像的数目亲自用惩罚回答他，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 1:4; 撒迦利亚书 11:8; 罗马书 1:28"> 好夺回以色列人的心，他们都因为拜偶像而远离我。’</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 18:30; 以赛亚书 30:22; 以西结书 36:31–32"> “因此，你要告诉以色列人，主耶和华这样说，‘你们要悔改，离弃你们的偶像，离弃一切可憎之事。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:48; 以赛亚书 58:1–2; 利未记 24:22"> 因为任何以色列人或是在以色列定居的外族人若背弃我，在心中树立偶像，把导致犯罪的绊脚石放在自己面前，又来向先知求问我的旨意，我耶和华必亲自用惩罚回答他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 15:7; 耶利米书 44:11; 以西结书 5:15"> 我必严惩他，使他成为众人的鉴戒和笑柄。我必将他从我的子民中铲除。这样，你们就知道我是耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:25; 耶利米书 4:10; 诗篇 81:11–12"> 如果先知受迷惑说预言，那是我耶和华任他受迷惑，我必伸手惩治他，把他从我的以色列百姓中除灭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:49; 以西结书 14:4; 耶利米书 8:11–12"> 他们必担当自己的罪过，假先知与求问的人要担当同样的罪过。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 37:23; 以西结书 44:10; 启示录 21:7"> 这样，以色列人便不再偏离我，不再犯罪玷污自己。他们要做我的子民，我要做他们的上帝。这是主耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华对我说：</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 26:26; 以西结书 4:16; 以赛亚书 24:20"> “人子啊，若有国家犯罪背叛我，我必伸手断绝他们的粮源，使饥荒遍地，毁灭人和牲畜。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 14:20; 耶利米书 15:1; 以西结书 28:3"> 即使挪亚、但以理和约伯三人在那里，他们也只能因义行而自己得救。这是主耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 5:17; 利未记 26:22; 耶利米书 15:3"> 倘若我使猛兽在那里横行、肆虐，以致那里荒凉、人踪绝迹，</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:29; 雅各书 5:16; 以西结书 33:11"> 纵然这三个义人在那里，我凭我的永恒起誓，他们也不能救自己的儿女，只能自己得救，那里却要荒凉。这是主耶和华说的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 26:25; 以西结书 21:3–4; 西番雅书 1:3"> 倘若我使刀剑临到那里，让刀剑横扫那里，毁灭人和牲畜，</span>
<span className="v" id="v18" data-v="18"> 纵然这三个义人在那里，我凭我的永恒起誓，他们也不能救自己的儿女，只能自己得救。这是主耶和华说的。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 38:22; 以西结书 5:12; 耶利米书 14:12"> 倘若我叫瘟疫在那里肆虐，在杀戮中倾倒我的烈怒，毁灭那里的人和牲畜，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:14; 约翰一书 2:29; 以赛亚书 3:10"> 纵然挪亚、但以理和约伯在那里，我凭我的永恒起誓，他们也不能救自己的儿女，只能因义行而自己得救。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 33:27; 以西结书 5:17; 以西结书 14:13"> “主耶和华说，‘我要把刀剑、饥荒、猛兽和瘟疫这四大刑罚降在耶路撒冷，毁灭人和牲畜。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 12:16; 以西结书 20:43; 希伯来书 12:6–11"> 然而，其中仍有幸免的人带着儿女逃出来。他们会逃到你们这里，你们看见他们的所作所为，便会对我在耶路撒冷所降的一切灾难感到欣慰。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 22:8–9; 启示录 15:4; 申命记 8:2"> 你们看见他们的所作所为，就知道我不是无缘无故地惩罚耶路撒冷。’这是主耶和华说的。”</span>
</div>
</div>

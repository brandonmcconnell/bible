## 对歌革的预言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 39:1; 以西结书 27:13; 以西结书 38:3"> “人子啊，你要面向玛各地区的歌革，就是米设和土巴的首领，说预言斥责他，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 13:8; 以西结书 39:1–10; 以西结书 29:3"> 告诉他，主耶和华这样说，‘米设和土巴的首领歌革啊，我要与你为敌。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 29:4; 但以理书 11:40; 以西结书 38:15"> 我要把你调转过来，用钩子钩住你的腮，把你和你那些全副武装、拿着大小盾牌、挥动刀剑的军队、马匹和骑兵都拖出来。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 27:10; 创世记 10:6; 以西结书 30:5"> 你的军队中有拿着盾牌、戴着头盔的波斯人、古实人和弗人，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 27:14; 创世记 10:2–3; 历代志上 1:5–6"> 还有歌篾及其全军和从遥远的北方来的陀迦玛及其全军。许多国家的军队都与你在一起。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 25:8; 约珥书 3:9–12; 以赛亚书 37:22"> “‘你和聚集到你那里的联军都要时刻预备好，你要做他们的统帅。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 38:16; 以赛亚书 24:22; 以西结书 38:11–12"> 再过多日，你必被征召出战。在以后的岁月，你将去攻打一片已从战争中恢复的土地，以色列久已荒凉的山上有从各国招聚回来的百姓。他们从列国中被领回来，如今都在那里安然居住。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 28:2; 耶利米书 4:13; 约珥书 2:2"> 你和你的军队以及各国的联军一起上来，如暴风来临，又如密云覆盖大地。’</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 36:4; 弥迦书 2:1; 诗篇 83:3–4"> “‘主耶和华说：那时你必心起歹念，筹划恶谋。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 2:4–5; 箴言 3:29–30; 耶利米书 49:31–32"> 你必说，我要攻打那没有围墙保护的乡村，毁灭那毫无戒备、在无墙无门无闩之地安然居住的百姓。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 10:6; 以西结书 38:8; 以西结书 29:19"> 我要抢掠他们的财物，下手攻击那曾是废墟的城邑和从列国归来的百姓。他们住在世界的中心，牲畜货物甚多。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 27:15; 以西结书 27:22–23; 以西结书 32:2"> 示巴人、底但人以及他施的客商和首领都必问：你是来抢掠吗？你聚集军队是来抢夺金银财宝，掳掠牲畜和货物吗？’</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 38:8; 撒迦利亚书 2:5; 耶利米书 23:6"> “因此，人子啊，你要说预言告诉歌革，主耶和华这样说，‘当我的以色列子民安然居住的时候，难道你会不知道吗？</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 39:2; 以西结书 38:6; 启示录 20:8"> 你召集各国联军，组成庞大的军队，骑着马从遥远的北方来。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 39:21; 以西结书 38:23; 何西阿书 3:5"> 歌革啊，你必如密云一样遮天蔽日，前来攻击我的以色列子民。将来，我要领你来攻击我的土地，我要在列国面前借着你彰显我的圣洁，使他们认识我。’</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 11:40–45; 以赛亚书 63:1–6; 约珥书 3:9–14"> “主耶和华说，‘歌革啊，我从前借我的仆人——以色列的先知所预言的那位就是你，那时他们曾多年预言我要领你上来攻击以色列。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 36:5–6; 希伯来书 12:29; 诗篇 89:46"> 当歌革上来攻击以色列的时候，我必发烈怒。这是主耶和华说的。</span>
<span className="v" id="v19" data-v="19" data-xref="哈该书 2:6–7; 启示录 11:13; 启示录 16:20"> 我要在义愤和烈怒中宣告，那天在以色列必有大地震。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿书 4:3; 那鸿书 1:4–6; 启示录 6:12–13"> 海里的鱼，空中的鸟，田野的走兽，地上的一切爬虫和人类都要在我面前战栗。山岭必倒塌，悬崖必崩裂，墙垣必坍塌。</span>
<span className="v" id="v21" data-v="21" data-xref="哈该书 2:22; 士师记 7:22; 以西结书 14:17"> 我要在我的山岭上叫刀剑攻击歌革，使他们自相残杀。这是主耶和华说的。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 66:16; 诗篇 11:6; 启示录 16:21"> 我要用瘟疫和杀戮惩罚他，将暴雨、冰雹、烈火和硫磺倾倒在他及其军队和随从的列邦身上。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 9:16; 启示录 19:1–6; 以西结书 38:16"> 我要彰显我的伟大和圣洁，使列国的人都认识我。这样他们就知道我是耶和华。’</span>

## 圣城中的可憎之事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 20:1; 以西结书 1:2–3; 以西结书 14:1"> 第六年六月五日，我正在家中与犹大的众长老同坐，主耶和华的手按在我身上。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 1:4; 以西结书 1:26–27; 但以理书 7:9–10"> 我观看，只见有一位形状像人，祂的腰部以下像火，腰部以上像闪亮的金属。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 32:16; 以西结书 11:1; 以西结书 5:11"> 祂好像伸出一只手，抓住我的头发。在异象中，耶和华的灵把我举到天地之间，将我带到耶路撒冷圣殿内院的北门，那里供奉着惹耶和华愤恨的神像。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 3:22–23; 出埃及记 40:34–35; 以西结书 11:22–23"> 我忽然看见那里有以色列上帝的荣耀，跟我在平原所见的一样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 8:3; 耶利米书 3:2; 耶利米书 32:34"> 祂对我说：“人子啊，你举目北望。”于是，我举目朝北一望，见在祭坛门北面的入口处有惹耶和华愤恨的神像。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 5:11; 以西结书 10:19; 以西结书 8:9"> 祂又对我说：“人子啊，你看见以色列人的所作所为了吗？他们在这里行那些极其可憎的事，以致我远离我的圣所。你会看到更可憎的事。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 21:5; 列王纪上 7:12"> 祂带我到院子的门口，我看见墙上有一个洞。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 29:15; 约伯记 34:22; 阿摩司书 9:2–3"> 祂对我说：“人子啊，你挖这墙。”我挖开墙后，看见一道门。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:8"> 祂对我说：“你进去看看他们在这里做的邪恶可憎的事吧。”</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 1:23; 出埃及记 20:4; 耶利米书 16:18"> 我进去后，看见四周的墙上画满了各种爬虫、可憎的兽类和以色列人拜的所有偶像。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 16:17; 民数记 16:35; 民数记 11:16"> 偶像前面站着以色列的七十个长老，沙番的儿子雅撒尼亚也在当中，他们每人手中都拿着香炉，烟雾缭绕。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 29:15; 以西结书 9:9; 以西结书 8:15"> 祂又对我说：“人子啊，你看见以色列的长老在自己藏偶像的房间里暗中所做的了吗？他们说，‘耶和华看不见我们，祂已经抛弃了这片土地。’”</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 8:6; 耶利米书 9:3; 以西结书 8:15"> 祂继续说：“你会看到他们做更可憎的事。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 46:9; 以西结书 44:4"> 祂带我来到耶和华殿的北门，看见一些妇女坐在那里为搭模斯神像哭泣。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 8:12–13; 以西结书 8:9; 以西结书 8:6"> 祂对我说：“人子啊，你看见了吗？你会看到更可憎的事。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 4:19; 申命记 17:3; 耶利米书 32:33"> 祂带我来到耶和华殿的内院，在殿门口，走廊和祭坛中间约有二十五个人背向耶和华的殿，面向东方朝拜太阳。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 9:9; 以西结书 7:23; 耶利米书 6:7"> 祂又对我说：“人子啊，你看见了吗？犹大人的这些可憎行径还算小事吗？他们到处行残暴之事，再三惹我发怒。看啊，他们手拿树枝举向鼻前。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 3:4; 耶利米书 11:11; 以赛亚书 1:15"> 因此，我必愤怒地对待他们，我必不顾惜他们，也不怜悯他们，即使他们大声向我呼求，我也不听。”</span>
</div>
</div>

</div>

## 以色列的牧人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 23:1; 耶利米书 3:15; 以赛亚书 40:11"> “人子啊，你要这样说预言斥责以色列的牧人，‘主耶和华说：以色列的牧人啊，你们有祸了！你们只顾喂养自己，牧人岂不应该喂养羊群吗？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 11:16; 耶利米书 2:30; 以西结书 33:25–26"> 但你们只顾吃羊的脂肪，穿羊毛衣，宰杀肥羊，却不喂养羊群。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 18:12–13; 马太福音 9:36; 以西结书 34:16"> 你们没有养壮瘦弱的，没有医治生病的，没有包扎受伤的，没有领回走散的，没有寻找迷失的。你们反用暴力辖制他们。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:36; 历代志下 18:16; 耶利米书 23:2"> 因为没有牧人，羊群便流离失散，成了所有野兽的食物。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 142:4; 彼得前书 2:25; 约翰福音 10:16"> 我的羊在群山和高岗上游荡，分散在各地，没有人寻找他们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 22:2–3; 弥迦书 3:8–9; 诗篇 82:1–7"> “‘所以，你们这些牧人啊，要听耶和华的话。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得后书 2:13; 使徒行传 20:33; 以西结书 34:5–6"> 主耶和华说：我凭我的永恒起誓，我的羊因为没有牧人而成了猎物，沦为所有野兽的食物。我的牧人不去寻找我的羊，他们只喂养自己，不喂养我的羊，</span>
<span className="v" id="v9" data-v="9"> 所以你们这些牧人啊，要听耶和华的话。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 34:2; 撒迦利亚书 10:3; 以西结书 13:8"> 主耶和华说，我要攻击这些牧人，从他们手中要回我的羊，不再让他们喂养羊群，使他们无法再喂养自己。我要从他们口中救回我的羊，不再让羊成为他们的食物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:16; 路加福音 19:10; 耶利米书 23:3"> “‘主耶和华说：看啊，我要亲自寻找我的羊，找到他们。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:11; 约翰福音 10:11–12; 路加福音 19:10"> 牧人怎样寻找他四散的羊，我也照样寻找我的羊，他们在密云幽暗的日子失散到各地，我要把他们从那里救回来。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:25–26; 以西结书 11:17; 以赛亚书 11:11–16"> 我要把他们从列邦领出来，从列国招聚他们，带他们回到自己的故土，我要在以色列的山岭上、溪水旁和境内可居之地牧养他们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:9; 耶利米书 31:25; 诗篇 31:8–10"> 我要在佳美的草场上牧养他们，以色列的山岭必成为他们的草场。他们要在佳美的草场上安卧，在以色列山岭的肥美草场上吃草。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:15; 诗篇 23:1–2; 约翰福音 21:15"> 我要亲自喂养我的羊，让他们得到安歇。这是主耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西结书 34:4; 以西结书 34:11"> 我要寻找迷失的，领回失散的，包扎受伤的，医治患病的，但我要消灭肥壮的。我要秉公牧养他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:20–22; 马太福音 25:32–33; 撒迦利亚书 10:3"> “‘我的羊群啊！至于你们，主耶和华这样说：我要在你们中间施行审判，在公绵羊和公山羊之间进行审判。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 23:13; 路加福音 11:52; 民数记 16:13"> 你们肥壮的羊在茂盛的草场上吃还不够吗？你们非要用蹄子践踏吃剩的草吗？你们喝清水还不够吗？你们非要用蹄子搅浑剩下的水吗？</span>
<span className="v" id="v19" data-v="19"> 我其余的羊只得吃你们践踏的草，喝你们搅浑的水。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:31–46; 以西结书 34:10; 诗篇 22:12–16"> “‘因此，主耶和华对他们说：看啊，我要亲自在肥羊和瘦羊之间施行审判。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 11:5; 申命记 33:17; 路加福音 13:14–16"> 你们肥羊用胁和肩拱，用角抵瘦弱的，使他们四散。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:2–3; 诗篇 72:12–14; 以西结书 34:10"> 因此我要拯救我的羊，使他们不再成为猎物，我要在羊与羊之间施行审判。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 37:24–25; 耶利米书 30:9; 以赛亚书 40:11"> 我要立我的仆人大卫做他们的牧人，他将牧养他们，做他们的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 31:33; 以西结书 36:28; 耶利米书 23:5–6"> 我耶和华要做他们的上帝，我的仆人大卫要在他们当中做王，这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:6–9; 以西结书 37:26; 利未记 26:6"> “‘我要跟他们立平安的约，除去地上的恶兽，让他们在旷野安居，在丛林安睡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:12; 以赛亚书 44:3; 利未记 26:4"> 我要赐福他们，也要赐福我圣山的周围，我要按季节降雨给他们，使恩福如雨降下。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:8; 利未记 26:4; 利未记 26:13"> 田间的树木必结果子，土地必长出庄稼，他们要在故乡安居。我要折断他们所负的轭，从奴役他们的人手中把他们拯救出来，那时他们便知道我是耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 46:27; 耶利米书 30:10; 以西结书 39:26"> 他们必不再成为列国的猎物，也不会被地上的野兽吞吃。他们必安居乐业，不再受人惊吓。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 36:29; 以赛亚书 4:2; 以西结书 34:26–27"> 我要把沃土赐给他们，使他们不再被境内的饥荒吞噬，也不再受各国的侮辱。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 37:27; 以西结书 34:24; 诗篇 46:11"> 这样，以色列人就知道我耶和华——他们的上帝与他们同在，他们以色列人是我的子民，这是主耶和华说的。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 100:3; 约翰福音 10:16; 诗篇 78:52"> 你们是我草场上的羊，你们是我的子民，我是你们的上帝。这是主耶和华说的。’”</span>
</div>
</div>

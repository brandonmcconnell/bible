<div className="bp poetry">

## 泰尔王的终局

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11"> 耶和华对我说：</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 19:1; 以西结书 26:17; 哥林多后书 1:22"> “人子啊，你要为泰尔王唱哀歌，告诉他，主耶和华这样说，<br /><span className="pl pl-1">“‘你曾经是完美的典范，</span><br /><span className="pl pl-1">充满智慧，美丽无瑕。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:15; 创世记 2:8; 以西结书 27:16"> <span className="pl pl-1">你曾在上帝的伊甸园中，</span><br /><span className="pl pl-1">你曾佩戴各种宝石，</span><br /><span className="pl pl-1">有红宝石、黄玉、钻石、</span><br /><span className="pl pl-1">绿宝石、红玛瑙、碧玉、</span><br /><span className="pl pl-1">蓝宝石、绿松石、翡翠，</span><br /><span className="pl pl-1">底座镶嵌着精美的黄金，</span><br /><span className="pl pl-1">这些在你受造的那天都已经预备妥当。</span><br /></span>

<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:4; 以西结书 28:17–18; 罗马书 7:9"> <span className="pl pl-1">你从受造那天开始所行的纯全无过，</span><br /><span className="pl pl-1">但后来在你那里查出不义。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 6:9–10; 哈巴谷书 2:8; 哈巴谷书 2:17"> <span className="pl pl-1">因为贸易发达，</span><br /><span className="pl pl-1">你便充满暴力，犯罪作恶。</span><br /><span className="pl pl-1">因此，看守约柜的基路伯天使啊，</span><br /><span className="pl pl-1">我把你当作污秽之物逐出上帝的山，</span><br /><span className="pl pl-1">从闪闪发光的宝石中除掉你。</span><br /></span>

<span className="v" id="v18" data-v="18" data-xref="玛拉基书 4:3; 启示录 18:8; 阿摩司书 1:9–10"> <span className="pl pl-1">你多行不义，</span><br /><span className="pl pl-1">交易不公，</span><br /><span className="pl pl-1">亵渎了你的圣所，</span><br /><span className="pl pl-1">因此我使火在你那里燃起，吞噬你，</span><br /><span className="pl pl-1">在众目睽睽之下把你烧成地上的灰烬。</span><br /></span>

<div className="bt">
<div className="bp poetry">

<span className="v" id="v21" data-v="21" data-xref="以西结书 6:2; 创世记 10:15; 耶利米书 25:22"> “人子啊，你要面对西顿，说预言斥责她，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 39:13; 出埃及记 14:17; 以西结书 20:41"> 告诉她，主耶和华这样说，<br /><span className="pl pl-1">“‘西顿啊，我要与你为敌，</span><br /><span className="pl pl-1">我要在你那里彰显我的荣耀。</span><br /><span className="pl pl-1">我要审判你，在你中间彰显我的圣洁，</span><br /><span className="pl pl-1">那时，人们就知道我是耶和华。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 38:22; 以西结书 26:6; 以西结书 25:11"> <span className="pl pl-1">我要使瘟疫进入你境内，</span><br /><span className="pl pl-1">刀剑从四面八方临到你，</span><br /><span className="pl pl-1">被杀的人横尸城中，血流街头，</span><br /><span className="pl pl-1">这样人们就知道我是耶和华。</span></span>

<span className="v" id="v26" data-v="26" data-xref="以西结书 28:24; 以西结书 28:22; 耶利米书 32:15"> 他们将在那里安然居住，兴建房屋，栽种葡萄园。我审判鄙视他们的四邻后，他们必安然居住。这样，他们便知道我是他们的上帝耶和华。’”</span>

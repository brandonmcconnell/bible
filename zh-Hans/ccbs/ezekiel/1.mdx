## 以西结的异象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 3:16; 以西结书 11:24; 使徒行传 7:56"> 第三十年四月五日，我正在迦巴鲁河畔被掳的人当中，那时天开了，我看见了上帝的异象。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 24:12–15; 以西结书 8:1; 以西结书 20:1"> 那是约雅斤王被掳第五年的四月五日，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 3:14; 以西结书 3:22; 列王纪下 3:15"> 就在迦勒底人境内的迦巴鲁河畔，耶和华的话传给了布西的儿子以西结祭司，耶和华的手按在他身上。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:27; 以西结书 8:2; 耶利米书 23:19"> 在异象中，我看见一阵狂风从北方刮来，有一大朵云闪耀着火光，四周环绕着灿烂的光芒，火的中心像发光的金属。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 4:6–8; 以西结书 1:26; 启示录 6:6"> 火中有四个像人形的活物，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 10:14; 启示录 4:7–8; 以西结书 1:15"> 每个活物有四张脸和四个翅膀。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 1:15; 但以理书 10:6; 诗篇 104:4"> 他们的腿是直的，脚如同牛犊的蹄，都亮如磨光的铜。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 10:21; 以西结书 10:11; 以赛亚书 6:6"> 四面的翅膀下都有人的手，四个活物都有脸和翅膀，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 10:22; 以西结书 10:11; 以西结书 1:11–12"> 翅膀彼此相连。他们移动时不必转身，各朝前面移动。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 10:14; 启示录 4:7; 哥林多前书 9:9–10"> 四个活物的脸是这样的：正面是人的脸，右面是狮子的脸，左面是牛的脸，后面是鹰的脸。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 6:2; 以西结书 1:23; 以西结书 10:19"> 他们的翅膀向上展开，每个活物的一对翅膀与两侧活物的翅膀相连，另外一对翅膀遮蔽身体。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 1:9; 以西结书 10:22; 希伯来书 1:14"> 每个活物都往前直行，耶和华的灵往哪里去，他们也往哪里去，移动时不用转身。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 4:5; 诗篇 104:4; 马太福音 28:3"> 四个活物的形象如燃烧的火炭，又像火把。活物之间有火上下移动，非常明亮，从火中发出闪电。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:27; 撒迦利亚书 4:10; 马可福音 13:27"> 这些活物像闪电一样往来飞驰。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 7:9; 以西结书 10:9; 以西结书 1:19–21"> 当我观看这些活物的时候，发现每个活物旁边的地上都有一个轮子。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 10:6; 以西结书 10:9–11; 出埃及记 39:13"> 四个轮子的形状和结构都一样，好像轮套轮，如同闪耀的绿宝石。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 1:9; 以西结书 1:12; 以赛亚书 55:11"> 他们可以向四面移动，移动时轮子不必转向。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 10:12; 启示录 4:6; 启示录 4:8"> 轮圈高而可畏，周围布满了眼睛。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 10:16; 以西结书 10:19; 诗篇 103:20"> 活物行走，轮子也在旁边行走；活物上升，轮子也上升。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:12; 以西结书 10:17; 哥林多前书 14:32"> 灵往哪里去，活物也往哪里去，轮子也跟着往哪里去，因为活物的灵在轮子里。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 10:17; 以西结书 1:19–20; 罗马书 8:2"> 活物行走，轮子也行走；活物站立不动，轮子也站立不动；活物上升，轮子也跟着上升，因为活物的灵在轮子里。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:1; 以西结书 1:26; 启示录 4:6"> 活物的头上好像铺展着茫茫的穹苍，如同顶着耀眼的水晶。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 4:18; 以西结书 1:11–12; 诗篇 89:7"> 穹苍下四个活物伸展翅膀，彼此相对，各用另两个翅膀遮蔽身体。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 43:2; 但以理书 10:6; 启示录 1:15"> 他们移动时，我听见他们翅膀发出的响声如洪涛之声，既像全能者的声音，又像军队的呐喊。活物站住的时候，便将翅膀垂下。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 1:22"> 他们站立垂下翅膀时，有声音从他们头顶的穹苍之上传来。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 10:1; 出埃及记 24:10; 启示录 1:13"> 在他们头顶的穹苍之上仿佛有蓝宝石的宝座，有一位形状像人的高坐在宝座上。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 1:4; 以西结书 8:2; 希伯来书 12:29"> 我看到祂的腰部以上好像烧红发亮的金属，好像有火四面环绕。腰部以下如同火焰。祂周围有耀眼的光辉，</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 10:1; 启示录 4:3; 创世记 17:3"> 仿佛雨天云中的彩虹。 这是耶和华荣耀的形象。我一看见，便俯伏在地，随后听见有说话的声音。</span>

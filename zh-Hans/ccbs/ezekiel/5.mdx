<span className="v" id="v1" data-v="1" data-xref="以赛亚书 7:20; 以西结书 44:20; 利未记 21:5"> “人子啊，去拿一把快刀当作剃头刀，剃掉你的头发和胡须，然后用天平把须发平均分成三份。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 5:12; 利未记 26:33; 以西结书 4:1–8"> 围城期满后，你要把三分之一的须发焚烧在城中，三分之一在城的四周用刀砍断，三分之一要扬在风中吹散，因为我要拔刀追杀它们。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 52:16; 耶利米书 40:6; 耶利米书 39:10"> 你要从须发中取出几缕用衣服包上，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:4; 耶利米书 41:1–18; 列王纪下 25:25"> 再从中取出几根扔进火里焚烧，必有火从这里燃起，蔓延到整个以色列。”</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 4:1; 申命记 4:6; 耶利米书 6:6"> 主耶和华说：“这就是耶路撒冷！我把她安置在万邦的中央，使列国环绕着她。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 11:10; 以西结书 16:47–48; 尼希米记 9:16–17"> 但她违背我的典章，作恶甚于列邦，触犯我的律例甚于她周围的列国。他们拒绝我的典章，不遵守我的律例。”</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:10–11; 历代志下 33:9; 列王纪下 21:9–11"> 所以主耶和华说：“你们比周围的国家更混乱不堪，你们没有遵行我的律例，不谨守我的典章，连周围的国家都不如。”</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 15:7; 耶利米书 24:9; 以西结书 21:3"> 因此主耶和华这样说：“看啊，我要亲自对付你们，我必在列国面前审判你们。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:21; 但以理书 9:12; 阿摩司书 3:2"> 因为你们一切的恶行，我必向你们施行空前绝后的惩罚。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 2:6; 申命记 28:64; 以西结书 12:14"> 在你们中间，父亲要吃自己的儿子，儿子要吃自己的父亲。我必惩罚你们，把你们余下的人分散到各地各方。”</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 7:20; 以西结书 7:9; 以西结书 11:18"> 主耶和华说：“因为你们用一切可憎的偶像和恶行玷污我的圣所，我凭我的永恒起誓，我必毫不留情地铲除你们。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 5:2; 耶利米书 15:2; 耶利米书 43:10–11"> 你们三分之一的人要死于瘟疫和饥荒，三分之一的人要死于刀下，我必把其余的三分之一分散到各地各方，并拔刀追杀他们。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:24; 以西结书 36:5–6; 以西结书 21:17"> 这样，我的怒气才会发完，我对你们的怒火才会尽消，我才会息怒。我把烈怒倾倒在你们身上的时候，你们就会知道我耶和华说这话是出于痛恨不贞。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 22:4; 尼希米记 2:17; 诗篇 79:1–4"> 我必使你们的家园荒凉，使你们在周围的列国中，在路人眼前饱受羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 25:17; 耶利米书 22:8–9; 列王纪上 9:7"> 当我在怒气，义愤和烈怒中严厉地审判你们时，你们在各国必受羞辱和嘲讽，成为警戒，下场可怕。这是我耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 4:16; 申命记 32:23–24; 以西结书 14:13"> 我要向你们射出饥荒的毒箭，破坏和毁灭你们，并且使饥荒越来越严重，断绝你们的粮源。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 38:22; 以西结书 14:21; 利未记 26:22"> 我必让饥荒和猛兽来侵害你们，夺走你们的儿女，使你们饱受瘟疫、暴行和刀剑之灾，这是我耶和华说的。”</span>

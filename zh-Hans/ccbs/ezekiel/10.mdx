## 耶和华的荣耀离开圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 24:10; 启示录 4:2–3; 启示录 1:13"> 我观看，只见基路伯天使头顶上的穹苍之中好像有一个蓝宝石宝座。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 8:5; 以西结书 10:16; 以西结书 1:13"> 耶和华对那穿细麻衣的人说：“你到基路伯天使下边旋转的轮子中间，双手捧满火炭，撒在城上。”我见他进去了。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 43:4; 以西结书 9:3; 以西结书 8:16"> 当他进去的时候，基路伯天使站在殿的南边，内院充满了云彩。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:28; 以西结书 9:3; 出埃及记 40:35"> 耶和华的荣耀从基路伯天使的上面升起，停在殿的门口，殿里充满了云彩，院子也充满了耶和华荣耀的光辉。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 1:24; 约伯记 40:9; 出埃及记 19:16"> 基路伯天使展翅的响声好像全能上帝说话的声音，在外院也可以听见。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 10:2; 诗篇 99:1; 诗篇 80:1"> 祂对那穿细麻衣的人说：“你要从基路伯天使下面旋转的轮子中取火。”那人便进去，站在一个轮子旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 13:41–42; 以西结书 1:13; 以西结书 41:23–26"> 有一个基路伯天使伸手到他们中间的火里，取了些火放在那穿细麻衣的人手里，那人就拿了出去。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 1:8; 以西结书 10:21; 以赛亚书 6:6"> 基路伯天使的翅膀下仿佛有人的手。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 1:15–17; 但以理书 10:6; 启示录 21:20"> 我又看见四个基路伯天使旁各有一个闪耀如绿宝石的轮子。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 1:16; 诗篇 36:6; 诗篇 104:24"> 四个轮子结构一样，好像轮套轮。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 1:17; 以西结书 10:22; 以西结书 1:20"> 基路伯天使移动时，不必转身就可以向四方移动。前轮朝哪个方向移动，其他轮子也朝哪个方向移动，不必转向。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 1:18; 启示录 4:8; 启示录 4:6"> 这四个基路伯天使的手、背、翅膀及全身都布满了眼睛，包括他们的四个轮子。</span>
<span className="v" id="v13" data-v="13"> 我听见他们称这些轮子为“旋转轮”。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 4:7; 以西结书 10:21; 列王纪上 7:36"> 每一个基路伯天使都有四张脸：第一张是基路伯天使的脸，第二张是人的脸，第三张是狮子的脸，第四张是鹰的脸。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 1:5; 何西阿书 9:12; 以西结书 11:22"> 然后，这些基路伯天使都向上升去，他们就是我在迦巴鲁河边所见的活物。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 1:19–21"> 基路伯天使移动，轮子也随之移动；基路伯天使展翅飞离地面，轮子也随之离开地面，不离他们旁边；</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 1:20–21; 罗马书 8:2; 以西结书 1:12"> 基路伯天使停住，轮子也随之停住；基路伯天使上升，轮子也随之上升。因为活物的灵在轮子中。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 18:10; 马太福音 23:37–39; 诗篇 78:60–61"> 那时，耶和华的荣耀离开了殿的门口，停在基路伯天使上面。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 8:16; 以西结书 1:17–21; 以西结书 1:26–28"> 我正观看时，基路伯天使展翅飞离地面，他们旁边的轮子也随之飞离。他们停在耶和华殿的东门口，以色列上帝的荣耀在他们上面。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:1; 以西结书 10:15; 列王纪上 7:36"> 这些是我在迦巴鲁河边所看见的活物，他们在以色列上帝的下面。我知道他们是基路伯天使。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 1:6; 以西结书 41:18–19; 以西结书 10:14"> 他们各有四张脸，两对翅膀，翅膀下仿佛有人的手，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:11; 以西结书 1:10; 以西结书 1:12"> 他们的面貌和我在迦巴鲁河边所见的一样，每一个都向前直走。</span>

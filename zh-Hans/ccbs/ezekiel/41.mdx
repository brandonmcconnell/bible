<span className="v" id="v1" data-v="1" data-xref="以西结书 40:2–3; 以西结书 40:17; 以西结书 41:23"> 那人带我进入殿堂，量两边的墙柱，各三米宽。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 6:17; 历代志下 3:3; 列王纪上 6:2"> 殿的入口宽五米，两边的墙各宽两米半。殿堂长二十米，宽十米。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 40:16"> 他到内殿的入口，量两边的墙柱，各一米宽，门宽三米，两边的墙各宽三米半。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 6:20; 希伯来书 9:3–8; 出埃及记 26:33–34"> 他量了内殿，长宽各十米。他对我说：“这是至圣所。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:5–6; 以西结书 42:3–14; 以西结书 41:6–9"> 他又量殿墙，厚三米，殿的外围有厢房，每间宽二米。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:10; 列王纪上 6:5–6; 以西结书 40:17"> 厢房是一层叠一层的，共有三层，每层有三十个房间。殿墙外围有支撑厢房梁木的墙坎，以免梁木插入殿墙中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 6:8; 希伯来书 6:1; 马太福音 13:32"> 这些厢房的设计是越往上层越宽，殿周围的建筑是层层向上建的，所以越往上层，房间越宽，有楼梯自下层经过中层到上层。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 40:5; 启示录 21:16"> 我看见殿的周围有突出的平台，高一竿，构成厢房的根基。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 41:11; 以西结书 42:4; 以西结书 42:1"> 厢房外墙厚二米半，厢房与祭司房之间是一块围绕着殿的空地，宽十米。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 41:9; 以西结书 42:4"> 厢房有两个门口朝着空地，一南一北。厢房周围与空地相连的平台宽两米半。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 42:1; 以西结书 42:13; 以西结书 41:13–15"> 在殿前空地向西的地方有一栋建筑物，宽三十五米，长四十五米，墙厚两米半。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 40:47"> 他量了殿，长五十米。殿的院子，那栋建筑物和墙共长五十米。</span>
<span className="v" id="v14" data-v="14"> 殿东边的空地宽五十米。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 42:3; 以西结书 42:1; 以西结书 41:12"> 他量了殿后面、空地对面的那栋建筑物，及其两边走廊的长度，共长五十米。 圣所、至圣所、院子的门廊，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 6:4; 以西结书 40:25; 以西结书 40:16"> 它们周围的门槛、格子窗和走廊从地面到窗沿都镶有木板。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 42:15"> 殿的入口和内殿里外四周的墙也按尺寸镶着木板。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:36; 以西结书 40:16; 以西结书 40:22"> 木板上刻着基路伯天使和棕树，两者彼此相间排列。每个基路伯天使有两个面孔：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 10:14; 以西结书 1:10"> 一个是人的脸，面向一边的棕树；一个是狮子的脸，面向另一边的棕树。整个殿四围都刻着基路伯天使和棕树。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 41:18"> 从地板到门以上殿内墙壁上都刻着基路伯天使和棕树。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 41:1; 列王纪上 6:33; 以西结书 40:14"> 圣所的门框是方形的，至圣所前的门框也一样。</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 1:12; 以西结书 23:41; 玛拉基书 1:7"> 圣所里面有一座木头做的祭坛，高一米半，长宽各一米，坛的四角、底及四面都是木造的。他对我说：“这是耶和华面前的桌子。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 6:31–35; 历代志下 4:22; 以西结书 41:1"> 圣所和至圣所各有一道双扇的门，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:34; 以西结书 40:48"> 每扇都是可以折叠的双页门，</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 41:18"> 圣所的门上也刻有基路伯天使和棕树，与墙上所刻的一样。门廊上有木造的廊檐。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 41:16; 以西结书 40:16; 以西结书 41:5"> 圣殿门廊两侧的墙壁上有格子窗和棕树雕刻，厢房都有房檐。</span>

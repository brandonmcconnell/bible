## 鹰和葡萄树的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 20:49; 马太福音 13:35; 哥林多前书 13:12"> “人子啊，你要向以色列人出谜语，讲比喻，</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 8:1; 耶利米书 48:40; 以西结书 17:7"> 告诉他们，主耶和华说，‘有一只大鹰翅膀宽大，羽毛丰满，色彩缤纷。这只鹰飞到黎巴嫩的香柏树上，折去树梢，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 43:14; 以赛亚书 47:15; 启示录 18:11–19"> 掐下树梢的嫩枝，叼到一个商贾云集的城市，栽在那里。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 44:4; 申命记 8:7–9; 耶利米书 37:1"> 它又把以色列的树苗像栽柳树一样，栽在水源丰沛的沃土里。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:14; 箴言 16:18–19"> 树苗发了芽，成为向四面蔓延的矮小葡萄树，它向下扎根，长出枝干，枝子向着鹰伸展。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 31:4; 以西结书 17:15; 列王纪下 24:20"> “‘又有一只大鹰，翅膀宽大，羽毛丰满。这葡萄树把根和枝子从园圃中转向这只鹰，好得到它的浇灌。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 17:5–6"> 但这树已栽在水源丰沛的沃土里，可以生枝结果，成为美好的葡萄树。’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结书 17:10; 耶利米书 32:5; 以赛亚书 30:1–7"> “你要告诉他们，主耶和华这样说，‘这树能长得茂盛吗？难道那鹰不把它连根拔起，摘掉它的果子，使树和嫩叶全部枯萎吗？不必费多大力气，也不需要多少人就可以把它连根拔起。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 13:15; 约翰福音 15:6; 马太福音 21:19"> 这树虽然被栽种了，又岂能长得茂盛呢？东风一吹，它岂不在园圃中完全枯萎吗？’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对我说：</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 24:19; 以西结书 17:3; 以西结书 1:2"> “你要对这些悖逆的人说，‘你们不明白这比喻的意思吗？’要告诉他们，巴比伦王攻取了耶路撒冷，把其中的君王和大臣掳到巴比伦，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 36:13; 列王纪下 24:15–17; 以西结书 17:5"> 并从犹大王室中选出一人与他立约，要他宣誓效忠。巴比伦王也掳去犹大国的重臣，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 29:14; 申命记 28:43; 撒母耳记上 2:30"> 使犹大国臣服于他，无法图强，只能遵守盟约，以求生存。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:3; 耶利米书 38:18; 以西结书 17:7"> 后来，犹大王背叛了巴比伦王，派使者到埃及请求支援军队马匹。他能成功吗？他这样做怎能逃脱惩罚呢？他这样背约怎能逃脱惩罚呢？</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结书 12:13; 耶利米书 52:11; 以西结书 17:18–19"> “主耶和华说，‘我凭我的永恒起誓，巴比伦王立他做王，他却藐视所起的誓，背弃所立的约，他必死在巴比伦。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 37:7; 以西结书 4:2; 以西结书 29:6–7"> 敌人筑起围攻的土垒和高台大肆杀戮的时候，法老虽然兵强马壮，人多势众，仍无法帮他抗敌。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 29:24; 历代志下 30:8; 耶利米哀歌 5:6"> 他起誓降服，却弃约背誓，出尔反尔，所以绝不能逃避后果。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 5:11; 耶利米书 5:9; 耶利米书 5:2"> “‘因此，主耶和华说：我凭我的永恒起誓，他既藐视我的誓言，背弃我的约，我必惩罚他。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 12:13; 以西结书 32:3; 耶利米书 2:35"> 我要撒开网罗抓住他，把他带到巴比伦，审判他对我不忠的罪。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:5; 列王纪下 25:11; 以西结书 12:14"> 他所有的精兵都要丧身刀下，余下的也要四散逃窜。这样，你们就知道这是我耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:2; 撒迦利亚书 6:12–13; 以赛亚书 11:1–5"> “‘主耶和华说：我要从香柏树高高的树梢上折下一根细枝栽上，我要从树的顶端折下嫩枝栽在巍峨的高山上。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:32; 以西结书 31:6; 以赛亚书 2:2"> 我要把它栽在以色列的高山上，使它生枝结果，成为一棵美丽的香柏树，各类飞鸟都要栖息在树上，栖息在枝头的树荫里。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 9:11; 哥林多前书 1:27–28; 以西结书 24:14"> 田野所有的树都会知道我耶和华使高树倒下、矮树长高、青树枯萎、枯树发荣。我耶和华言出必行。’”</span>
</div>
</div>

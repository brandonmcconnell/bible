## 耶和华的荣光充满圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 44:1; 以西结书 42:15; 以西结书 46:1"> 后来，那人带我来到东门，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 18:1; 以西结书 11:23; 以赛亚书 6:3"> 只见以色列上帝的荣光从东方而来，祂的声音如澎湃的洪涛，大地也因祂的荣耀而发出光芒。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 9:5; 以西结书 9:1; 耶利米书 1:10"> 这异象如同我从前在祂毁灭耶路撒冷时看见的异象，也像我在迦巴鲁河边看见的异象，我便俯伏在地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 10:18–19; 以西结书 44:2; 以西结书 43:2"> 耶和华的荣光从东门进入圣殿。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:2–4; 列王纪上 8:10–11; 以西结书 8:3"> 上帝的灵把我举起，带我进入内院，只见耶和华的荣光充满圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 40:3; 以赛亚书 66:6; 启示录 16:1"> 那人仍然站在我身旁，我听见有一位从殿中对我说：</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 43:9; 诗篇 47:8; 利未记 26:30"> “人子啊，这里是我的宝座，是我踏脚的地方，我要在这里永远住在以色列人当中。以色列的君民必不再因不忠贞，或在丘坛为他们死去的君王立碑而玷污我的圣名。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 5:11; 以西结书 8:3–16; 历代志下 33:7"> 他们不再在我圣殿旁边建庙宇，使它们的门槛和门柱紧挨着我的门槛和门柱，以致我与它们只有一墙之隔。他们行可憎的事，玷污了我的圣名，所以我发怒消灭他们。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 43:7; 以西结书 37:26–28; 以西结书 18:30–31"> 现在，他们要从我面前远远地除去他们的不忠贞和先王的碑，我就永远住在他们当中。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 40:4; 以西结书 16:61; 以西结书 16:63"> “人子啊，你要向以色列人描述所看见的圣殿，让他们思考圣殿的设计，使他们为自己的罪恶而羞愧。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 36:27; 以西结书 11:20; 马太福音 28:20"> 他们若为自己的行为感到羞愧，你就把殿的构造、出入口等整个设计，以及殿中的一切律例和法则告诉他们，并且当着他们的面写下来，让他们忠于设计，遵行殿的一切律例。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 40:2; 启示录 21:27; 诗篇 93:5"> 殿所在的山顶周围都是至圣之地，这是有关殿的法则。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 40:5; 出埃及记 27:1–8; 以西结书 41:8"> “以下是祭坛的尺寸，底槽深五十厘米，宽五十厘米，周围环绕着一条二十五厘米高的边框。</span>
<span className="v" id="v14" data-v="14"> 从底座到下层台座高一米，边宽五十厘米，下层台座到上一层高二米，边宽五十厘米。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 27:2; 诗篇 118:27; 利未记 9:9"> 最高一层是祭台，高二米，祭台上的四角向上突起。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1; 历代志下 4:1; 出埃及记 38:1–2"> 祭台是方形的，长宽各六米，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:26; 以西结书 40:6; 出埃及记 25:25"> 下面的台座也是方形的，长宽各七米，周围环绕着一条二十五厘米高的边框。底座四围的边宽五十厘米，上祭台的石阶在东面。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:29; 希伯来书 10:4–12; 以西结书 2:1"> 祂对我说：“人子啊，主耶和华这样说，‘祭坛建成后，要按以下的规矩在上面献燔祭和洒血。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 40:46; 以西结书 44:15; 民数记 16:40"> 你要将一头公牛犊作为赎罪祭给撒督后裔中的利未祭司，他们可以前来事奉我。这是主耶和华说的。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 16:19; 利未记 8:15; 出埃及记 29:12"> 取些公牛犊的血抹在祭坛的四角、台座的四角和四边，使祭坛洁净，为祭坛赎罪，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:14; 利未记 4:12; 利未记 8:17"> 并把赎罪用的公牛犊拿到圣所外指定的圣殿区焚烧。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 43:25–26; 以西结书 43:20; 彼得前书 1:19"> 第二天，你要献上一头毫无残疾的公山羊作赎罪祭，就像献公牛一样，使祭坛洁净。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:1"> 祭坛洁净后，你要取来一头毫无残疾的公牛犊和一只毫无残疾的公绵羊，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 2:13; 马可福音 9:49–50; 民数记 18:19"> 祭司要把盐撒在祭牲上，作为燔祭献在耶和华面前。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:33; 出埃及记 29:35–37; 利未记 8:35"> 一连七天，每天都要献上一只公山羊、一头公牛犊和一只公绵羊作赎罪祭，都不可有残疾。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:24; 利未记 8:34; 出埃及记 32:29"> 在这七天之内，他们要为祭坛赎罪，使坛洁净，成为圣坛。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 9:1; 以西结书 20:40–41; 彼得前书 2:5"> 七天结束后，从第八天开始，祭司要在祭坛上献你们的燔祭和平安祭，我必悦纳你们。这是主耶和华说的。’”</span>
</div>
</div>

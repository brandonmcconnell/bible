## 预言泰尔遭审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 20:1; 以西结书 1:2; 耶利米书 39:2"> 第十一年十一月一日，耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 23:1–18; 以西结书 36:2; 约珥书 3:4"> “人子啊，泰尔讥笑耶路撒冷说，‘哈哈！那通往列国的门户已遭破坏，城门向我大开，她已荒凉，我必兴盛。’</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 51:42; 以赛亚书 5:30; 弥迦书 4:11"> 所以主耶和华说，‘泰尔啊，我要跟你作对，我要激起多国来攻击你，就像大海掀起波浪一样。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 23:11; 阿摩司书 1:10; 以西结书 26:9"> 他们要破坏你的墙垣，拆毁你的城楼。我要铲净你的瓦砾，使你成为光秃秃的磐石。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 29:19; 以西结书 27:32; 以西结书 25:7"> 你必在海中做晒网的地方，因为我已经宣告，这是主耶和华说的。你必被列国掳掠，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 16:46; 以西结书 26:8; 耶利米书 49:2"> 你陆地上的居民必死于刀下，这样你就知道我是耶和华。’</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:12; 但以理书 2:37; 以西结书 23:24"> “主耶和华说，‘我要使那王中之王的巴比伦王尼布甲尼撒率领大队人马、战车和骑兵从北方来攻打泰尔。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 21:22; 耶利米书 52:4; 耶利米书 32:24"> 他必用刀剑杀戮你陆地上的居民，建垒筑台围困你，举着盾牌攻击你。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 26:15"> 他必用撞城锤击破你的城墙，用铁锤捣毁你的城楼。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 26:15; 以西结书 27:28; 耶利米书 47:3"> 他人马众多，扬起的尘土足以遮盖你。他要像攻破城池一样进入你的城门，他的骑兵、军需车和战车的响声要震动你的城墙。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:28; 以赛亚书 26:5; 哈巴谷书 1:8"> 他战马的铁蹄必踏遍你的街道。他必挥刀屠杀你的居民，推倒你坚固的神柱，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 23:8; 历代志下 32:27; 撒迦利亚书 9:3–4"> 掠夺你的财富，洗劫你的货物，摧毁你的城墙，夷平你华丽的房屋，把你的石头、木头和瓦砾抛到海里。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:34; 以赛亚书 23:16; 以赛亚书 14:11"> 我必使你的歌声消逝，琴音断绝。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 1:4; 约伯记 12:14; 民数记 23:19"> 我要使你成为光秃秃的磐石，做晒网的地方，你必不得重建，因为我耶和华已经宣告。这是主耶和华说的。’</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 27:35; 耶利米书 49:21; 以西结书 26:18"> “主耶和华对泰尔这样说，‘你倾覆的声音，伴随着你里面的杀戮声和受伤之人的惨叫声岂不震动沿海地区吗？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 32:10; 约拿书 3:6; 约伯记 8:22"> 沿海诸王都吓得浑身发抖，从宝座上下来，除去王袍，脱掉锦衣，坐在地上抖个不停，因你而惊惧不已。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:12; 以西结书 19:1; 撒母耳记下 1:25–27"> 他们必为你唱哀歌说，<br /><span className="pl pl-1">“‘赫赫名城啊，你曾是海上众民的居所，</span><br /><span className="pl pl-1">向来称雄海上，威震邻邦，</span><br /><span className="pl pl-1">现在怎么被毁灭了呢？</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 26:15; 以赛亚书 23:5–7; 以西结书 27:35"> <span className="pl pl-1">你倾覆的日子，</span><br /><span className="pl pl-1">沿海各国都战战兢兢，</span><br /><span className="pl pl-1">众海岛看见你被毁灭，</span><br /><span className="pl pl-1">都心惊胆战。’</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:7–8; 以西结书 26:3; 但以理书 11:40"> “主耶和华说，‘我要使你成为荒无人烟的城邑，我要使海水上升淹没你。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 27:13; 路加福音 10:15; 撒迦利亚书 2:8"> 那时，我要使你与那些堕入阴间的人一同下到作古之人那里，使你与那些堕入阴间的人一同住在大地深处久已荒凉的地方，好让你荒无人烟，在活人之地毫无尊荣。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 27:36; 以西结书 28:19; 启示录 18:21"> 我要使你遭受可怕的灾难，你便不复存在，就是有人寻找你，也永远找不到，这是主耶和华说的。’”</span>

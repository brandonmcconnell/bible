## 划分圣地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 48:29; 撒迦利亚书 14:20–21; 民数记 34:13"> “‘当你们抽签把土地分给以色列各支派作产业的时候，要分出一块献给耶和华作圣地。圣地要长十二公里半，宽十公里，整块地都要圣洁。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 42:16–20; 以西结书 27:28"> 你们要在其中分出一块长宽各二百五十米的地建圣所。圣所的周围要有二十五米宽的空地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 48:10"> 圣地当中要量一块长十二公里半、宽五公里的地，其中要有圣所，是至圣的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 43:19; 民数记 16:5; 以西结书 40:45"> 这块圣地应归那些在圣所供职并事奉耶和华的祭司，作为他们的居所和建圣所之用。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 48:13; 尼希米记 10:38–39; 以西结书 48:20"> 另一块十二公里半长、五公里宽的土地给那些在圣殿工作的利未人建城居住，作他们的产业<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“作他们的产业”或译作“有二十间房作他们的产业”。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 48:15–18; 以西结书 48:30–35"> “‘在圣地旁边要分出一块十二公里半长、两公里半宽的地建城，归给所有以色列人。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 48:21; 以西结书 34:24; 以西结书 46:16–18"> “‘在圣地和城的东西两边是给君王的土地，西边延伸至西边的边境，东边延伸至东边的边境，从西到东长度与各支派分得的土地一样。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 11:3–5; 以西结书 46:18; 以西结书 22:27"> 这地方要作君王在以色列的产业。我的君王必不再欺压我的子民，而是按支派把地分给他们。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 8:16; 耶利米书 22:3; 以西结书 44:6"> “‘主耶和华说，你们这些以色列的君王啊，够了！你们应当放弃暴行和抢掠，按公平和正义行事，不要再向我的子民横征暴敛了！这是主耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:10–11; 阿摩司书 8:4–6; 箴言 16:11"> 你们要用公道的天平、伊法和罢特。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:10"> 伊法和罢特容量要相同，量固体的伊法是十分之一贺梅珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一贺梅珥相当于一百五十公斤或二百升。">b</a></sup>，量液体的罢特也是十分之一贺梅珥，贺梅珥是标准的容量单位。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:25"> 舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约合十一克。">c</a></sup>是标准的重量单位，一舍客勒是二十季拉。六十舍客勒等于一弥那。</span>
<span className="v" id="v13" data-v="13"> “‘以下是你们应当献的供物，每一贺梅珥小麦要献上六分之一伊法，每一贺梅珥大麦也要献上六分之一伊法。</span>
<span className="v" id="v14" data-v="14"> 献橄榄油要按规定以罢特计量，每一柯珥的油要献十分之一罢特，一柯珥等于十罢特或一贺梅珥，因为一贺梅珥等于十罢特。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 6:30; 歌罗西书 1:21"> 在以色列肥美的草场上，每二百只羊便要献上一只。这些供物用来作素祭、燔祭和平安祭，为以色列人赎罪。这是主耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:14–15; 以赛亚书 16:1"> 所有的以色列人都要这样拿供物来献给君王。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 46:4–12; 历代志下 31:3; 以赛亚书 66:23"> 君王要在节期、朔日<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“朔日”即每月初一。">d</a></sup>、安息日等以色列人一切的节期献上燔祭、素祭和奠祭。他要预备赎罪祭、素祭、燔祭和平安祭的祭物，为以色列人赎罪。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 16:16; 出埃及记 12:2; 以西结书 43:22"> “‘主耶和华说，一月初一，你要献一只毫无残疾的公牛犊，洁净圣所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 43:20; 以西结书 43:14; 利未记 16:18–20"> 祭司要取些赎罪祭牲的血抹在圣殿的门柱、祭台的四角和内院门口的柱子上。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 19:12; 利未记 4:27–35; 以西结书 45:15"> 到了一月七日，要同样为一切在无意和无知中犯罪的人赎罪，使圣殿洁净。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 23:5–8; 哥林多前书 5:7–8; 民数记 9:2–14"> “‘一月十四日开始，你们要守逾越节七天，节期间要吃无酵饼。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:14; 哥林多后书 5:21; 马太福音 20:28"> 在逾越节当天，君王要预备一头公牛为自己和全体百姓作赎罪祭。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 42:8; 利未记 23:8; 民数记 23:1–2"> 在七天的节期间，他要每天预备毫无残疾的公牛七头、公绵羊七只作燔祭献给耶和华，公山羊一只作赎罪祭。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:5–7; 民数记 28:12–15"> 他要预备细面粉和油作素祭与牛羊一同献上。每头公牛或公绵羊要同献十公斤细面粉和四升油。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:33–43; 民数记 29:12–38; 历代志下 5:3"> 在七月十五日开始一连七天的住棚节期间，君王也要供应同样的赎罪祭、燔祭、素祭和油。’</span>
</div>

## 锈锅的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 20:1; 以西结书 29:17"> 第九年十月十日，耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 39:1; 耶利米书 52:4; 列王纪下 25:1"> “人子啊，今天是巴比伦王围攻耶路撒冷的日子，你要记下今天这日子。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 11:3; 以西结书 17:2; 以西结书 20:49"> 你要向叛逆的以色列人说比喻，告诉他们，主耶和华这样说，<br /><span className="pl pl-1">“‘把锅放在火上，</span><br /><span className="pl pl-1">里面倒上水，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:2–3; 以西结书 22:18–22; 马太福音 7:2"> <span className="pl pl-1">把羊腿、羊肩等上好的肉块放进锅里，</span><br /><span className="pl pl-1">让锅里盛满精选的骨头。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 52:24–27; 耶利米书 52:10; 耶利米书 39:6"> <span className="pl pl-1">要从羊群中选一头上好的羊，</span><br /><span className="pl pl-1">把柴堆在锅下，</span><br /><span className="pl pl-1">烧开锅煮里面的骨头。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 22:2; 那鸿书 3:1; 俄巴底亚书 1:11"> 因此，主耶和华说：“这像锈锅一样充满血腥的城有祸了！要把肉从这锈迹斑斑的锅中一块块地取出来，无需挑选。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 17:13; 申命记 12:16; 约伯记 16:18"> 这城沾满血腥，任凭受害者的血流在光秃秃的磐石上，而不是流在地上用土掩盖。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 32:21–22; 启示录 18:5–10; 以西结书 22:30–31"> 我任凭这城把受害者的血洒在光秃秃的磐石上，不加掩盖，好激起我的烈怒，使她受报应。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 24:6; 哈巴谷书 2:12; 以赛亚书 31:9"> 所以主耶和华说，‘血腥的城啊，你有祸了！我要预备大堆木柴。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米书 17:3; 耶利米哀歌 1:10"> 要添柴点火，把肉煮烂，加入香料，烧焦骨头。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 玛拉基书 4:1; 以赛亚书 1:25"> 然后，把倒空的锅放在炭火上烧热，把铜烧红，好熔化它的杂质，除净锈垢，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 9:5; 耶利米书 2:13; 耶利米书 5:3"> 却徒劳无功，因为锈垢太厚，就是用火也不能清除。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 22:24; 以西结书 5:13; 西番雅书 3:2"> 耶路撒冷啊，淫荡使你污秽不堪，我本想洁净你，你却不愿被洁净。所以，除非我向你倾尽一切愤怒，否则你的污秽必不得清除。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:27; 以西结书 18:30; 以赛亚书 3:11"> 我耶和华言出必行，决不退缩，也不宽容，也不留情，我必照你的所作所为来审判你。’这是主耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华对我说：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:10; 耶利米书 13:17; 雅歌 7:10"> “人子啊，我要击打你，夺去你心爱的人，你不可悲伤，也不可流泪哭泣。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 9:4; 撒母耳记下 15:30; 利未记 10:6"> 你要默然哀叹，不可为死人办丧事，仍要缠着头巾，穿着鞋，不可蒙着脸，也不可吃丧家的饭。”</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 7:29–30"> 早晨我把这事告诉百姓，晚上我的妻子便死了。次日早晨，我便遵照耶和华的吩咐行。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 12:9; 以西结书 37:18; 玛拉基书 3:7–8"> 百姓问我：“你可以告诉我们，你这样做跟我们有什么关系吗？”</span>
<span className="v" id="v20" data-v="20"> 我告诉他们：“耶和华对我说，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 23:47; 以西结书 23:25; 诗篇 27:4"> ‘你告诉以色列人，主耶和华说：我要使我的圣所，就是你们引以为傲、眼中所爱、心里所慕的受到亵渎。你们留下的儿女必死于刀下。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:64; 耶利米书 16:4–7; 以西结书 24:16–17"> 那时，你们将像我的仆人一样不蒙脸，不吃丧家的饭。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:10; 以西结书 4:17; 利未记 26:39"> 你们仍将裹着头巾，穿着鞋，不哭泣，也不悲伤。你们必因自己的罪恶而默然叹息，逐渐灭亡。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 4:3; 以赛亚书 20:3; 路加福音 11:29–30"> 以西结做的事都是你们的预兆，你们也将做他做的。当这事发生时，你们就知道我是主耶和华。’</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结书 24:21; 诗篇 48:2; 耶利米书 11:22"> “人子啊，有一天我要夺去他们所喜悦、所夸耀、眼中所爱、心里所慕的堡垒，也要夺去他们的儿女。</span>
<span className="v" id="v26" data-v="26" data-xref="约伯记 1:15–19; 以西结书 33:21–22; 撒母耳记上 4:12–18"> 那日，幸存的人必来告诉你这个消息。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 33:22; 以西结书 29:21; 路加福音 21:15"> 那时，你必开口向那人说话，不再沉默。你必成为他们的预兆，他们就知道我是耶和华。”</span>
</div>
</div>

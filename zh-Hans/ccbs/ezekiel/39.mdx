## 预言歌革被灭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 38:2–3; 以西结书 35:3; 那鸿书 3:5"> “人子啊，你要说预言斥责歌革，告诉他，主耶和华这样说，‘米设和土巴的首领歌革啊，我要与你为敌。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 40:14; 以西结书 38:15; 以赛亚书 37:29"> 我要把你调转过来，使你从遥远的北方来到以色列的山中。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 76:3; 何西阿书 1:5; 耶利米书 21:4–5"> 我要打掉你左手的弓，击落你右手的箭。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 39:17–20; 以西结书 33:27; 以西结书 38:21"> 你和你的军队，以及与你同来的各国联军都要倒毙在以色列的山岭上，我要把你们的尸体给各种猛禽野兽作食物。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 22:19; 以西结书 32:4; 耶利米书 8:2"> 你必倒毙在田野之间，因为我已经宣告。这是主耶和华说的。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 30:16; 阿摩司书 1:4; 以西结书 30:8"> 我要火烧玛各和安居在海岛的人，他们就知道我是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 38:16; 以西结书 38:23; 出埃及记 20:7"> “‘我要让我的以色列子民知道我的圣名，不再让我的圣名被亵渎。这样列国就知道我是以色列的圣者耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 38:17; 启示录 16:17; 以西结书 7:2–10"> 我所说的日子将要来临，一切必然实现。这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 46:9; 以赛亚书 66:24; 玛拉基书 1:5"> “‘以色列各城邑的居民都要出去捡兵器当柴烧，其中包括大小的盾牌、弓箭、矛枪等，足够用七年。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 33:1; 以赛亚书 14:2; 弥迦书 5:8"> 他们不必到田间拾柴，或到林中伐木，因为有兵器当柴烧。他们要抢夺那些抢夺过他们的人，掳掠那些掳掠过他们的人。这是主耶和华说的。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 47:18; 民数记 34:11; 以西结书 38:2"> “‘那一天，我要把以色列境内通往盐海东边的旅客谷作为歌革的坟地，埋葬他和他的军队。这坟地将截断行人的去路，因此人称那地方为哈们·歌革谷。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 21:23; 以西结书 39:14; 以西结书 39:16"> 以色列人要用七个月来埋葬他们，使那地方洁净。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:22; 西番雅书 3:19–20; 耶利米书 33:9"> 以色列人都要来埋葬他们。我彰显荣耀的那天将是以色列人名声大振的日子。这是主耶和华说的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 39:12; 民数记 19:11–19"> 七个月之久，他们会派人不断巡视那里，埋葬遗留在地面上的尸体，使那里洁净。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:44"> 如果巡视的人发现了骸骨，便在旁边立一个标记，等待负责埋葬的人将骸骨埋葬在哈们·歌革谷，</span>
<span className="v" id="v16" data-v="16"> 他们要这样使那地方洁净。那里有一座城叫哈摩那<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“哈摩那”意思是“大群”。">a</a></sup>。’</span>
<span className="v" id="v17" data-v="17" data-xref="西番雅书 1:7; 启示录 19:17–18; 以赛亚书 34:6"> “人子啊，主耶和华说，‘你要召唤各类飞鸟和野兽，让它们聚集起来，从四面八方来赴我为它们预备的祭宴，就是以色列山岭上的大祭宴，在那里吃肉饮血。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 22:12; 耶利米书 51:40; 启示录 19:17–18"> 它们将吃到勇士的肉，喝到君王的血，好像吃公绵羊、羊羔、公山羊、公牛这些巴珊的肥畜。</span>
<span className="v" id="v19" data-v="19"> 它们要在我为它们设的祭宴中任意吃肉饮血，直到吃饱喝醉为止。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 19:18; 哈该书 2:22; 诗篇 76:5–6"> 它们在我的宴席上要饱餐战马、骑兵、勇士和所有军人的肉。这是主耶和华说的。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 38:16; 以西结书 38:23; 以赛亚书 37:20"> “‘我要在列国中彰显我的荣耀，万国必看见我用大能在他们身上施行的审判。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 24:7; 以西结书 28:26; 以西结书 39:28"> 从那天起，以色列必知道我是他们的上帝耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 22:8–9; 以赛亚书 1:15; 以赛亚书 59:2"> 列国必知道以色列人被掳走是因为他们犯罪背叛我，以致我掩面不顾他们，把他们交在敌人手中，让他们丧身刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 36:19; 耶利米书 2:17; 耶利米书 4:18"> 我照他们的污秽和罪恶报应他们，掩面不顾他们。’</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 34:13; 以赛亚书 27:12–13; 何西阿书 1:11"> “因此，主耶和华说，‘我要使雅各被掳的人返乡，我要怜悯全体以色列人，热心维护我的圣名。</span>
<span className="v" id="v26" data-v="26" data-xref="弥迦书 4:4; 列王纪上 4:25; 以西结书 16:63"> 当他们在故土安居，没有人来威胁他们的时候，他们就会忘记自己所有的羞辱和得罪我的恶事。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 38:16; 以西结书 38:23; 以西结书 36:23–24"> 我从列国把他们领回，从敌国把他们召回来的时候，我要借着他们向列国彰显我的圣洁。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 39:22; 阿摩司书 9:9; 以赛亚书 27:12"> 我让他们被掳到列国，将来必召集他们返回故土，不撇下一人。这样，他们便知道我是他们的上帝耶和华。</span>
<span className="v" id="v29" data-v="29" data-xref="约珥书 2:28; 约翰一书 3:24; 以赛亚书 32:15"> 我不再掩面不顾以色列人，因为我要把我的灵浇灌在他们身上。这是主耶和华说的。’”</span>

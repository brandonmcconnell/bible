## 君王与节期

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 66:23; 以西结书 44:1–2; 出埃及记 20:9"> “主耶和华说，‘圣殿内院的东门在平时工作的六日内都要关闭，只在安息日和朔日才打开。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 44:3; 以西结书 46:8; 历代志上 29:10–12"> 在这些日子，君王要从东门穿过门廊通道进入内院，站在门框旁边。祭司要为他献燔祭和平安祭。他在入口的门槛那里敬拜，然后离去。这门要到晚上才关闭。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 约翰福音 10:9; 希伯来书 10:19–22"> 在安息日和朔日，以色列人要站在这门口敬拜耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 45:17; 民数记 28:9–10"> 君王在安息日献给耶和华的燔祭应是羊羔六只、公绵羊一只，都要毫无残疾。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 45:24; 以西结书 46:7; 申命记 16:17"> 至于同献的素祭，一只公绵羊要同献十公斤细面粉，与羊羔同献的素祭则可随意奉献。每十公斤细面粉要加四升油。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 46:1"> 要在朔日献公牛犊一头、羊羔六只、公绵羊一只，都要毫无残疾。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 46:5"> 他也要预备素祭，每一头公牛犊要同献十公斤细面粉，公绵羊也是一样。与羊羔同献的素祭则可随意奉献。每十公斤细面粉要加四升油。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 46:2; 以西结书 44:1–3; 歌罗西书 1:18"> 君王从门廊进去，也要从原路出来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 16:16; 出埃及记 23:14–17; 彼得后书 2:20–21"> “‘以色列人在节期进去敬拜耶和华的时候，从北门进去的要从南门出来，从南门进去的要从北门出来。谁都不可回头从进去的门出来，必须从对面的门出来。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 42:4; 历代志上 29:20; 历代志上 29:22"> 在这些节期君王应和百姓一同进殿敬拜，百姓离开的时候，君王也要一同离开。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 46:5; 以西结书 46:7; 民数记 15:1–41"> “‘每逢节期和特定的圣会，要有与祭牲同献的素祭，每头公牛献十公斤细面粉，公绵羊也是一样，与羊羔同献的素祭则可以随意奉献。每十公斤细面粉要加四升油。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 46:1–2; 以西结书 45:17; 以西结书 44:3"> 倘若君王自愿向耶和华献燔祭或平安祭，便要为他打开东门。他献的燔祭或平安祭要与安息日所献的一样。他献完后就从东门出去，门也跟着关闭。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 50:4; 约翰福音 1:29; 出埃及记 12:5"> “‘每天早晨，你们要献给耶和华一只毫无残疾的一岁羊羔为燔祭，</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 28:5"> 同献的素祭是三公斤细面粉，调上一升油。献给耶和华的这种素祭是永久不变的律例。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:1–10; 民数记 28:6; 出埃及记 29:42"> 所以，每天早晨都要预备羊羔、素祭和油，作为日常献的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 21:3; 加拉太书 4:7; 创世记 25:5–6"> “‘主耶和华说，如果君王把一部分产业作为礼物赐给他儿子，这产业便归了他儿子，由他儿子的后代继承。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 25:10; 路加福音 19:25–26; 加拉太书 4:30–31"> 如果君王把一部分产业作为礼物赐给他的仆人，他的仆人在得到自由之前可以拥有这产业，到他自由的那年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“自由的那年”即“禧年”，参见利未记25:8‑17。">a</a></sup>，这份产业仍要归还给君王，因为君王的产业只能由他的后代继承。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 45:8; 列王纪上 21:19; 以西结书 22:27"> 君王不可驱逐百姓离开他们的土地，强夺他们的产业。他必须把自己拥有的产业赐给儿子，免得我的子民从自己的土地上被驱散。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 42:9; 以西结书 44:4–5; 以西结书 40:44–46"> 然后，那人领我从大门旁边的入口来到圣所北面的祭司圣屋，让我看圣屋西边的地方。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 35:13; 以西结书 44:29; 以西结书 44:19"> 他对我说：“这是祭司煮赎过祭牲、赎罪祭牲和烤素祭的地方。他们在这里烤煮，免得把圣肉带到外院，以致把圣洁传到百姓身上。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 他又领我到外院，巡察外院的四个角落。我看见院中每个角落都有一个小庭院，</span>
<span className="v" id="v22" data-v="22"> 每个庭院的四周都有围墙，长二十米，宽十五米，四角的庭院大小都一样。</span>
<span className="v" id="v23" data-v="23"> 每个庭院的墙周围都有一排石屋，屋里有炉灶。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:20; 约翰福音 21:15–17; 彼得前书 5:2"> 他对我说：“这是圣殿的仆役替百姓煮祭物的地方。”</span>
</div>
</div>

## 为埃及唱哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 13:6; 以西结书 21:12; 约珥书 1:11"> “人子啊，你要说预言，宣告主耶和华这样说，<br /><span className="pl pl-1">“‘哀号吧！你们要为那日悲伤。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="俄巴底亚书 1:15; 约珥书 2:1–2; 约珥书 1:15"> <span className="pl pl-1">因为日子近了，耶和华的日子近了，</span><br /><span className="pl pl-1">那将是乌云密布的日子，</span><br /><span className="pl pl-1">是列国沦亡的时候。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 29:19; 以西结书 29:8; 以赛亚书 16:7"> <span className="pl pl-1">必有刀剑攻击埃及，</span><br /><span className="pl pl-1">埃及必尸横遍野，</span><br /><span className="pl pl-1">古实必痛苦不堪。</span><br /><span className="pl pl-1">敌人要掳掠埃及的财富，</span><br /><span className="pl pl-1">摧毁她的根基。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 25:20; 以西结书 27:10; 耶利米书 25:24"> <span className="pl pl-1">古实、弗、路德、阿拉伯和利比亚及其他盟友都必与她一同死于刀下。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西结书 29:10; 以赛亚书 20:3–6; 以赛亚书 31:3"> <span className="pl pl-1">“耶和华说，</span><br /><span className="pl pl-1">‘埃及的盟友都要覆灭，</span><br /><span className="pl pl-1">埃及的傲气必荡然无存，</span><br /><span className="pl pl-1">从密夺到色弗尼的居民都要丧身刀下。</span><br /><span className="pl pl-1">这是主耶和华说的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 29:12; 耶利米书 25:18–26; 以西结书 32:18–32"> <span className="pl pl-1">埃及要变成荒地中的荒地，</span><br /><span className="pl pl-1">她的城邑要沦为废墟中的废墟。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 29:6; 以西结书 29:16; 阿摩司书 1:7"> <span className="pl pl-1">我要点火烧埃及，</span><br /><span className="pl pl-1">埃及的所有盟友都要灭亡。</span><br /><span className="pl pl-1">那时，他们就知道我是耶和华。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 18:1–2; 以赛亚书 23:5; 以西结书 32:9–10"> “‘在那日，我要差遣使者乘船出去惊吓安逸的古实人，在埃及遭难的日子，他们必痛苦不堪。看啊，这日子快到了。’</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 29:19; 以西结书 32:11–16; 以西结书 29:4–5"> “主耶和华说，<br /><span className="pl pl-1">“‘我要借巴比伦王尼布甲尼撒的手消灭埃及的百姓。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 28:7; 以西结书 32:12; 以西结书 39:11–20"> <span className="pl pl-1">他和追随他的都是万民中最残暴的人。</span><br /><span className="pl pl-1">他们去毁灭埃及，</span><br /><span className="pl pl-1">拔刀攻击那里，</span><br /><span className="pl pl-1">使埃及尸骨遍野。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 29:3; 那鸿书 1:4; 启示录 16:12"> <span className="pl pl-1">我要使尼罗河干涸，</span><br /><span className="pl pl-1">把土地卖给恶人，</span><br /><span className="pl pl-1">我要借外族人的手使埃及及其境内的一切都荒废，</span><br /><span className="pl pl-1">这是我耶和华说的。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="撒迦利亚书 10:11; 耶利米书 46:14; 耶利米书 2:16"> <span className="pl pl-1">“主耶和华说，</span><br /><span className="pl pl-1">‘我要毁灭偶像，</span><br /><span className="pl pl-1">铲除挪弗的神像。</span><br /><span className="pl pl-1">埃及再没有君王，</span><br /><span className="pl pl-1">我要使埃及境内充满恐惧。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 29:14; 耶利米书 46:25; 诗篇 78:43"> <span className="pl pl-1">我要使巴特罗荒废，</span><br /><span className="pl pl-1">放火焚烧琐安，</span><br /><span className="pl pl-1">审判底比斯。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="启示录 16:1; 那鸿书 1:6; 诗篇 11:6"> <span className="pl pl-1">我要把我的烈怒倾倒在埃及的训堡垒，</span><br /><span className="pl pl-1">消灭底比斯的百姓。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 30:8–9; 以西结书 28:18"> <span className="pl pl-1">我要放火烧埃及，</span><br /><span className="pl pl-1">训必受极大的痛苦，</span><br /><span className="pl pl-1">底比斯要被攻破，</span><br /><span className="pl pl-1">挪弗终日困苦不已，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 41:45"> <span className="pl pl-1">亚文和比伯实的壮丁必死于刀下，</span><br /><span className="pl pl-1">众城都要遭受掳掠。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 30:3; 以西结书 29:15; 以赛亚书 10:27"> <span className="pl pl-1">我粉碎埃及势力的那天，</span><br /><span className="pl pl-1">答比匿必日月无光，</span><br /><span className="pl pl-1">她的锐气全消。</span><br /><span className="pl pl-1">乌云必笼罩她，</span><br /><span className="pl pl-1">她城邑的居民必被掳去。</span><br /></span>

<span className="v" id="v20" data-v="20" data-xref="以西结书 29:17; 以西结书 26:1; 以西结书 29:1"> 第十一年一月七日，耶和华对我说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 30:13; 耶利米书 46:11; 诗篇 37:17"> “人子啊，我打断了埃及王法老的一只臂膀，没有人替他敷药包扎，以致他无力拿刀。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 37:17; 耶利米书 37:7; 列王纪下 24:7"> 因此，主耶和华说，‘我要与埃及王法老为敌，我要把他那强壮的臂膀和曾经受伤的臂膀一起打断，使刀从他手中掉落。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 30:26; 以西结书 30:17–18; 以西结书 29:12–13"> 我要把埃及人驱散到列国，分散到列邦。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 30:25; 西番雅书 2:12; 以赛亚书 45:5"> 我要使巴比伦王的臂膀强壮有力，把我的刀交在他手中。我要打断法老的臂膀，使法老在他面前像受了致命伤的人一样呻吟。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 29:21; 以西结书 32:15; 以西结书 29:16"> 我要使巴比伦王的臂膀强壮有力，而法老的双臂必软弱无力。我要把我的刀交在巴比伦王手中，让他挥刀攻击埃及。那时他们就知道我是耶和华。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 11:42; 以西结书 29:12; 以西结书 30:23"> 我要把埃及人驱散到列国，分散到列邦，这样他们就知道我是耶和华。’”</span>

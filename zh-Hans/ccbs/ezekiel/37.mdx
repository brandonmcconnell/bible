## 枯骨复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 3:22; 以西结书 1:3; 使徒行传 8:39"> 耶和华的手按在我身上，耶和华借祂的灵把我带到一个山谷，那里遍地都是骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 141:7; 以西结书 37:11; 申命记 11:30"> 祂领我在骸骨间走了一圈，我看到谷中的骸骨相当多，都是枯骨。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:25–26; 约翰福音 5:21; 申命记 32:39"> 祂对我说：“人子啊，这些骸骨能复活吗？”我说：“主耶和华啊，只有你知道。”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 5:25; 约翰福音 5:28–29; 马太福音 21:21"> 祂又对我说：“你对这些骸骨说预言，‘枯骨啊，你们要听耶和华说的话！</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 37:14; 诗篇 104:29–30; 创世记 2:7"> 主耶和华对这些骸骨说：我要使气息进入你们里面，你们就必复活过来。</span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:27; 以赛亚书 49:23; 约珥书 3:17"> 我必给你们加上筋，使你们长出肉，再包上皮，将气息放在你们里面，你们就复活了。这样，你们就知道我是耶和华。’”</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:2; 列王纪上 19:11–13; 耶利米书 13:5–7"> 于是，我便按耶和华的吩咐向枯骨说预言，我正说预言的时候，忽然有响声，是震动的声音，骨头便彼此连在了一起。</span>
<span className="v" id="v8" data-v="8"> 我又看见骨头上有了筋，长了肉，包上了皮，只是还没有气息。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:8; 雅歌 4:16; 诗篇 104:30"> 耶和华对我说：“人子啊，你要向气息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“气息”希伯来文又作“灵”，“风”。">a</a></sup>说预言，告诉气息，主耶和华这样说，‘气息啊，从四方吹来，吹在这些被杀的人身上，使他们复活。’”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 11:11; 诗篇 104:30; 启示录 20:4–5"> 于是，我便按耶和华的吩咐说预言，气息就进入他们里面，他们便复活了，并且站立起来，成为一支大军。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:1; 诗篇 77:7–9; 以西结书 39:25"> 耶和华对我说：“人子啊，这些骸骨就是所有的以色列人。他们说，‘我们骨头枯干，希望幻灭，彻底完了。’</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 26:19; 何西阿书 13:14; 帖撒罗尼迦前书 4:16"> 因此，你要说预言，告诉他们，‘主耶和华说：我的子民啊，我要打开你们的坟墓，领你们出来，我要领你们返回以色列。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 37:6; 以西结书 16:62; 诗篇 126:2–3"> 我的子民啊，当我这样做的时候，你们就知道我是耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 36:27; 约珥书 2:28–29; 以西结书 36:36"> 我要把我的灵放在你们里面，使你们复活，安居在自己的土地上，那时你们就知道我耶和华言出必行。这是耶和华说的。’”</span>
<span className="v" id="v15" data-v="15"> 耶和华对我说：</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 历代志下 10:19; 历代志下 10:17"> “人子啊，你拿一根杖来，写上‘犹大和他的以色列同伴’，然后再拿另一根杖，写上‘约瑟，即以法莲，与他的以色列同伴’。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 1:11; 耶利米书 50:4; 以赛亚书 11:13"> 然后把这两根杖连成一根，拿在手中。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 24:19; 以西结书 12:9; 以西结书 17:12"> 当你的同胞问你这是什么意思时，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 10:6; 以西结书 37:16–17; 以弗所书 2:13–14"> 你就告诉他们，主耶和华这样说，‘我要把约瑟和他的以色列同伴的杖，就是以法莲手中的杖，与犹大的杖连接在一起，在我手中成为一根。’</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 12:3; 民数记 17:6–9; 何西阿书 12:10"> 你要拿着这两根写着字的杖让他们看，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 36:24; 耶利米书 29:14; 耶利米书 23:8"> 告诉他们，主耶和华这样说，‘我要把以色列人从他们流亡的列国领出来，从四围招聚他们，带他们回归故土。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 37:24; 以西结书 34:23–24; 耶利米书 3:18"> 我要使他们在以色列的土地和群山上成为一国，只有一位王统治他们，不再是两个国家，不再分为两个王国。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 21:3–4; 以西结书 36:28–29; 约翰一书 1:9"> 他们不会再因偶像、可憎之物或任何过犯而玷污自己，我要从他们犯罪的地方把他们救出来，洗净他们的罪。他们要做我的子民，我要做他们的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 34:23–24; 何西阿书 3:5; 以西结书 37:25"> “‘我的仆人大卫要做王治理他们，成为他们唯一的牧人。他们必恪守我的典章，谨遵我的律例。</span>
<span className="v" id="v25" data-v="25" data-xref="阿摩司书 9:15; 以西结书 37:24; 以西结书 28:25"> 他们要安居在我赐给我仆人雅各的土地上，就是你们祖先居住的地方。他们世世代代都要永远居住在那里，我仆人大卫要永远做他们的王。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 55:3; 耶利米书 30:19; 以西结书 34:25"> 我要与他们订立平安之约，是永远的约，使他们安居，人丁兴旺，并且我的圣所要永远设立在他们当中。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 21:3; 约翰福音 1:14; 以西结书 37:23"> 我要住在他们中间。我要做他们的上帝，他们要做我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17–19; 以西结书 20:12; 出埃及记 31:13"> 我的圣所永远设立在他们当中之时，列国便会知道我耶和华使以色列圣洁。’”</span>
</div>

## 新圣殿的异象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 33:21; 以西结书 1:2–3; 以西结书 3:14"> 在我们被掳的第二十五年，就是耶路撒冷沦陷的第十四年一月十日，耶和华的手按在我身上，祂带我到了那里。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 1:1; 但以理书 7:1; 但以理书 7:7"> 在异象中上帝把我带到以色列的一座高山上，山的南面仿佛有一座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 47:3; 启示录 11:1; 但以理书 10:5–6"> 祂把我带到那里。城的入口站着一个面色如铜的人，手中拿着一条麻绳和一根量竿。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 44:5; 马太福音 10:27; 以西结书 2:7–8"> 那人对我说：“人子啊，你要留心用眼看，专心用耳听，注意我要指示你的一切，因为我带你来这里正是为了要指示你。你要把所见到的一切告诉以色列人。”</span>
</div>
</div>

## 外院的门

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 42:20; 以赛亚书 26:1; 启示录 21:12"> 我看见殿的四周有墙，那人拿了一根三米长的量竿量这墙，量出墙厚一竿，高一竿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 43:1; 以西结书 8:16; 以西结书 11:1"> 然后，他带我到殿的东门，走上台阶，量了门洞，深一竿。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 40:36; 以西结书 40:33; 历代志上 23:28"> 门内有守卫室，长度和宽度都是一竿。室与室之间相距两米半，挨着通往圣殿门廊的门洞深一竿。</span>
<span className="v" id="v8" data-v="8"> 他量了通往圣殿的门廊，宽度也是一竿，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 45:19"> 连墙柱在内共四米宽，墙柱宽一米。</span>
<span className="v" id="v10" data-v="10"> 东门内共有六间守卫室，每边三间，大小面积都是一样，两边的墙柱尺寸也相同。</span>
<span className="v" id="v11" data-v="11"> 他量了门的入口，宽五米，长六米半。</span>
<span className="v" id="v12" data-v="12"> 两边守卫室前面的矮墙高五十厘米，守卫室都是边长三米的正方形。</span>
<span className="v" id="v13" data-v="13"> 他又量门的宽度，即这边守卫室的屋顶到对面守卫室的屋顶，是十二米半。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:9; 以赛亚书 62:9; 以西结书 42:1"> 他从门口的墙柱量到外院的墙柱，是三十米。</span>
<span className="v" id="v15" data-v="15"> 由门口到通道尽头的内廊共二十五米，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 3:5; 列王纪上 6:4; 以西结书 41:26"> 守卫室、墙柱上和门廊周围都有格子窗，墙柱上刻着棕树。</span>
</div>
</div>

## 外院

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 11:2; 以西结书 42:1; 历代志上 23:28"> 他带我到外院，外院靠墙的四周是铺石地，沿着铺石地共有三十间厢房。</span>
<span className="v" id="v18" data-v="18"> 铺石地在门口的两边，比内院低，宽度与入口的长度一样。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 40:23; 以西结书 40:27; 以西结书 46:1–2"> 他从外院的内门口量到内院的外门口，东侧和北侧距离都是五十米。</span>
</div>
</div>

## 北门

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 40:6"> 他又量了外院的北门的长和宽，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 40:29–30; 以西结书 40:25–26; 以西结书 40:10–16"> 通道两边各有三间守卫室，墙柱和门廊的长度和宽度跟东门一样，分别是二十五米和十二米半。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 40:31; 以西结书 40:37; 以西结书 40:6"> 它的窗户、门廊、墙柱上雕刻的棕树都和东门的尺寸相同。登上七级石阶便到达门口，通道的尽头是门廊。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 40:19; 以西结书 40:27–28; 出埃及记 38:9–12"> 内院的北门与外院的北门相对，正如它的东门和外院的东门相对，他量了相对两门之间的距离，是五十米。</span>
</div>
</div>

## 南门

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:9; 以西结书 40:6; 以西结书 40:20–21"> 他又带我到南门，量了墙柱和门廊，都与其他门的尺寸相同，</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 40:33; 以西结书 40:16; 以西结书 40:21–22"> 通道与门廊四周都有窗户，和其他的窗户一样，通道长二十五米，宽十二米半。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 40:22; 以西结书 40:16; 以西结书 40:6"> 登上七级石阶便到达门口，通道尽头是门廊，两边的墙柱也同样刻着棕树。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 40:23; 以西结书 40:32; 以西结书 40:19"> 内院也有南门，他量了与外院南门之间的距离，是五十米。</span>
</div>
</div>

## 内院的门

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 40:35; 以西结书 40:32"> 他带我从南门走进内院，量了南门，跟其他门的尺寸一样。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 40:25; 以西结书 40:16; 以西结书 40:7"> 守卫室、墙柱，门廊都和其他的尺寸一样，通道与门廊四周有窗户，通道长二十五米，宽十二米半。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 40:21; 以西结书 40:36; 以西结书 40:25"> 内院周围的门廊都是长十三米，宽二米半。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 40:26; 以西结书 40:34; 以西结书 40:22"> 这些门廊对着外院，两边的墙柱刻着棕树，上去的石阶共有八级。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结书 40:35; 以西结书 40:28–31"> 他又带我从东门进入内院，量了东门，跟其他门的尺寸一样，</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 40:21; 以西结书 40:36; 以西结书 40:25"> 守卫室、墙柱、门廊都和其他的尺寸一样，通道与门廊四周有窗户，通道长二十五米，宽十二米半。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 40:22; 以西结书 40:31; 以西结书 40:37"> 门廊对着外院，两边的墙柱刻着棕树，那里的石阶共有八级。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西结书 47:2; 以西结书 40:32; 以西结书 44:4"> 他又带我到北门，量了北门，跟其他门的尺寸一样。</span>
<span className="v" id="v36" data-v="36" data-xref="以西结书 40:29; 以西结书 40:21; 以西结书 40:16"> 守卫室、墙柱、门廊和其他门的尺寸一样，通道长二十五米，宽十二米半，四周有窗户。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 40:34; 以西结书 40:31"> 门廊对着外院，两边的墙柱刻着棕树，那里的石阶共有八级。</span>
</div>
</div>

## 厢房

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志下 4:6; 以西结书 40:17; 利未记 8:21"> 门口的墙柱旁边有一个带门的房间，是洗燔祭牲的地方。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 46:2; 利未记 1:3–17; 利未记 4:2–3"> 门廊两边各有两张用来屠宰燔祭牲、赎罪祭牲和赎过祭牲的桌子。</span>
<span className="v" id="v40" data-v="40"> 内院北门的门廊外墙边有两张桌子，门廊的另一边也有两张桌子。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 40:39–40"> 大门两侧各有四张桌子，共八张，供祭司屠宰祭牲之用。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 40:39; 出埃及记 20:25"> 另有四张用石头凿成的桌子用来预备燔祭牲，屠宰燔祭牲及其他祭牲的器具都放在桌上。桌子长宽各七十五厘米，高五十厘米。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 1:8; 利未记 1:6; 利未记 8:20"> 廊内四周挂着八厘米长的双钩。桌上放着祭肉。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="历代志上 6:31–32; 历代志上 16:41–43; 以西结书 40:27"> 在内院的内门旁有两间歌乐手用的厢房，一间向南，在北门旁，一间向北，在南门旁。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 9:23; 诗篇 134:1; 利未记 8:35"> 他对我说：“向南的厢房是给殿内供职的祭司用的，</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 44:15; 以西结书 43:19; 列王纪上 2:35"> 向北的厢房是给坛前供职的祭司用的。他们都是撒督的子孙，利未人中唯有他们可以到耶和华面前事奉。”</span>
<span className="v" id="v47" data-v="47" data-xref="以西结书 40:19; 以西结书 40:23; 以西结书 40:27"> 他量了殿前的院子，是边长五十米的正方形，祭坛在殿前面。</span>
</div>
</div>

## 圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="历代志下 3:4; 列王纪上 6:3"> 他带我来到殿前通往圣所的门廊，量了两旁的墙柱，各两米半宽，门宽七米，门两边的墙各一米半厚，</span>
<span className="v" id="v49" data-v="49" data-xref="列王纪上 7:15–21; 以西结书 40:34; 历代志下 3:17"> 门廊长十米，宽六米。有一排台阶上到门廊，墙柱两旁各有一根柱子。</span>
</div>
</div>

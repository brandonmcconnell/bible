## 审判以色列的首领

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 3:14; 以西结书 11:24; 以西结书 11:13"> 那时，耶和华的灵将我举起，带我到耶和华殿的东门，我见门口那里有二十五个人，当中有百姓的首领押朔的儿子雅撒尼亚和比拿雅的儿子毗拉提。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:1; 耶利米书 5:5; 诗篇 2:1–2"> 耶和华对我说：“人子啊，这些人在这城里专给人出毒计，设恶谋。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 12:27; 以西结书 12:22; 以西结书 11:7–11"> 他们说，‘建造房屋的时候还没有到。我们的城像铁锅一样坚固，我们像在锅里的肉一样得到保护。’</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 20:46–47; 以西结书 21:2; 以西结书 3:2–15"> 人子啊，你要说预言，说预言斥责他们。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 17:10; 耶利米书 16:17; 启示录 2:23"> 耶和华的灵降在我身上，并吩咐我说：“耶和华这样说，‘以色列人啊，我知道你们口中在说什么，心里在想什么。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 7:23; 以西结书 22:27; 以西结书 22:12"> 你们在城中大肆屠杀，大街小巷遍地尸体。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 24:3–13; 弥迦书 3:2–3; 列王纪下 25:18–22"> 所以，主耶和华说，你们在城中杀死的人就是肉，这城就是锅，但我必把你们从锅中拉出来。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以赛亚书 24:17–18; 约伯记 3:25"> 你们惧怕刀剑，我必使刀剑临到你们。这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 5:8; 诗篇 106:41; 申命记 28:36"> 我必把你们从城中赶出去，交给外族人。我必审判你们，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 14:25; 耶利米书 52:9–10; 列王纪下 25:19–21"> 使你们死于刀下。我要审判整个以色列，这样你们就知道我是耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 11:3; 以西结书 11:7–10"> 这城必不是你们的锅，你们也必不是其中的肉，我必在以色列全境施行审判。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:10; 以西结书 8:16; 以西结书 8:14"> 这样你们就知道我是耶和华。因为你们没有遵行我的律例，没有顺从我的典章，却效法你们四邻外族的规矩。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 11:1; 以西结书 9:8; 使徒行传 5:5"> 我正在说预言的时候，比拿雅的儿子毗拉提就死了。我便俯伏在地大喊：“唉，主耶和华啊，你要灭绝以色列的余民吗？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华对我说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 33:24; 以赛亚书 65:5; 约翰福音 16:2"> “人子啊，留在耶路撒冷的居民会这样谈论你、你的亲人和一切被掳的以色列人，说，‘他们远离了耶和华，这地方已经给了我们。’</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:14; 申命记 30:3–4; 诗篇 90:1"> 因此，你要说，‘主耶和华这样说，我虽然把以色列人赶到远方各国，分散在列邦，却要在他们所去的国家暂作他们的圣所。’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 28:25; 耶利米书 3:18; 以西结书 34:13"> “你要说，‘主耶和华这样说，我必从各国召集你们，从你们被驱散到的列邦中聚集你们，将以色列的土地再赐给你们。’</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 37:23; 以西结书 5:11; 以西结书 42:7–8"> 他们回来后，必除掉此地一切丑恶可憎的事。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:26–27; 耶利米书 31:33; 诗篇 51:10"> 我必赐给他们一颗专一的心，将新灵放在他们里面，除去他们的石心，赐给他们肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:11; 诗篇 105:45; 耶利米书 30:22"> 使他们恪守我的律例，谨遵我的典章。他们要做我的子民，我要做他们的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 9:10; 传道书 11:9; 耶利米书 1:16"> 至于那些心里恋慕丑恶可憎之物的人，我必按他们所行的报应他们。这是主耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:19; 以西结书 1:19–20"> 于是，基路伯天使展开翅膀，轮子跟在他们旁边，在他们上面有以色列上帝的荣耀。</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 14:4; 以西结书 8:4; 以西结书 10:4"> 耶和华的荣耀从城中升起，停在城东的山上。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 3:12; 以西结书 8:3; 以西结书 11:1"> 上帝的灵将我举起，在祂所赐的异象中把我带到迦勒底被掳的人那里，我所见的异象从我面前上升消失了。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 3:4; 以西结书 3:27; 以西结书 3:17"> 我把耶和华让我看到的一切都告诉了那些被掳的人。</span>
</div>
</div>

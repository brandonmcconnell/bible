## 耶路撒冷的罪恶

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 58:1; 以西结书 24:6; 以西结书 24:9"> “人子啊，你要审判这杀人流血的城吗？你要审判她？那就使她知道自己一切可憎的行为。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 22:27; 罗马书 2:5; 彼得后书 2:3"> 你要向她宣告主耶和华的话，说，‘唉，你这杀人流血、制造偶像玷污自己的城啊，你的末日到了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:16; 诗篇 44:13–14; 以西结书 22:2"> 你既犯罪杀人，制造偶像玷污自己，使你灭亡的日子近了，你的大限到了，我要使你成为列国列邦侮辱和讥讽的对象。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 22:2; 耶利米书 15:2–3"> 你这声名狼藉、混乱不堪的城将要受到远近各国的耻笑。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 22:27; 以赛亚书 1:23; 撒迦利亚书 3:3"> “‘看啊，在你城中的以色列首领各逞权势，杀人流血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:16; 出埃及记 22:21–22; 利未记 20:9"> 他们轻慢父母，压迫寄居者，欺负孤儿寡妇。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 23:38–39; 以西结书 22:26; 以西结书 20:13"> 你藐视我的圣物，亵渎我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 4:14; 利未记 19:16; 何西阿书 4:10"> 在你这城中，有人好诽谤、杀人流血，有人在山上吃祭物，有人淫乱，</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 18:19; 利未记 18:7–8; 以西结书 18:6"> 有人与继母通奸，羞辱父亲，有人奸污经期不洁的妇女，</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 18:15; 撒母耳记下 13:14; 利未记 20:17"> 有人与邻居的妻子干出可憎之事，有人玷污自己的儿媳妇，有人奸污自己的同父姊妹。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:25; 以西结书 23:35; 诗篇 106:21"> 在你这城中，他们受贿杀人，放债取利，压榨邻居，早把我忘了。这是主耶和华说的。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 21:17; 以赛亚书 33:15; 阿摩司书 2:6–8"> “‘我见你谋财害命，就击掌叹息。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 21:7; 以西结书 17:24; 以西结书 24:14"> 在我惩罚你的日子，你还有勇气和力量吗？我耶和华言出必行，</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 1:8; 以西结书 22:22; 申命记 4:27"> 我要把你驱散到列国，分散到列邦，我要除掉你的污秽。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 6:7; 诗篇 83:18; 以西结书 7:24"> 你必在列国面前受凌辱，你便知道我是耶和华。’”</span>
<span className="v" id="v17" data-v="17"> 耶和华对我说：</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:119; 以赛亚书 1:22; 耶利米书 6:28–30"> “人子啊，在我看来，以色列人已经变成了渣滓。他们是炉中的铜、锡、铁、铅，都是银渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:30; 以西结书 24:3–6; 弥迦书 4:12"> 所以主耶和华说，‘你们既都是渣滓，我要把你们聚集在耶路撒冷城。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:11–12; 以赛亚书 54:16; 以西结书 24:13"> 我要在义愤和烈怒中把你们聚集在城里熔化，就像人把银、铜、铁、铅、锡聚在炉中，吹旺炉火熔化一样。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:7; 那鸿书 1:6; 诗篇 50:3"> 我要聚集你们，把我的怒火倒在你们身上，你们必在城中熔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:8; 以西结书 20:33; 何西阿书 5:10"> 你们要在城中熔化，就像银在炼炉中熔化。你们就知道我耶和华已将我的烈怒倾倒在你们身上。’”</span>
<span className="v" id="v23" data-v="23"> 耶和华对我说：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–16; 耶利米书 2:30; 历代志下 28:22"> “人子啊，你要对以色列说，‘在我发怒的日子，将没有雨水滋润你这不洁之地。’</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 6:9; 耶利米书 2:34; 以西结书 13:19"> 你的首领图谋恶事，好像咆哮着撕碎猎物的狮子，他们草菅人命，抢夺财宝，使多人变成寡妇。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:10; 以西结书 44:23; 以西结书 22:8"> 你的祭司强解我的律法，亵渎我的圣物。他们圣俗不分，也不教导人分辨洁净的和不洁净的。他们藐视我的安息日，以致我在他们当中被亵渎。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 22:13; 以赛亚书 1:23; 以西结书 22:6"> 你的首领好像撕碎猎物的豺狼，杀人流血，谋取不义之财。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 13:6–7; 以西结书 13:10–16; 耶利米书 23:25–32"> 你的先知粉饰他们的罪恶，对他们说虚假的异象和谎话连篇的占卜，谎称‘耶和华说’，其实耶和华没有说。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 22:7; 出埃及记 23:9; 出埃及记 22:21"> 你的居民强取豪夺，欺压贫困的，虐待寄居的，无法无天。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:16; 耶利米书 5:1; 诗篇 106:23"> 我想在他们中间寻找一位重修城墙的人，站在我面前为这地方堵住缺口，免得我毁灭这里。可是，我一个也找不到。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 16:43; 以西结书 7:8–9; 以西结书 9:10"> 因此，我要向他们倾倒我的烈怒，用怒火灭尽他们，照他们的所作所为报应他们。这是主耶和华说的。”</span>

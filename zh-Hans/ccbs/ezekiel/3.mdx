<span className="v" id="v1" data-v="1" data-xref="启示录 10:9–10; 以西结书 3:17–21; 以西结书 2:8–9"> 祂对我说：“人子啊，要把你得到的吃下去，要吃下这书卷，然后去向以色列人传讲。”</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 25:17; 使徒行传 26:19"> 我张开口，祂就给我吃那书卷，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 15:16; 启示录 10:9–10; 诗篇 119:103"> 并对我说：“人子啊，吃下我赐你的这书卷，让它充满你的肚腹。”我便吃了，书卷在我嘴里甘甜如蜜。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:5–6; 使徒行传 1:8; 以西结书 2:3"> 祂又对我说：“人子啊，现在你要到以色列人那里，把我的话传给他们。</span>
<span className="v" id="v5" data-v="5" data-xref="约拿书 1:2; 以赛亚书 33:19; 约拿书 3:2–4"> 你不是奉命去语言陌生、难懂的民族那里，而是到以色列人当中。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 11:20–24; 罗马书 9:30–33; 约拿书 3:5–10"> 我不是派你到那些语言陌生、艰涩难懂的民族中。我若果真派你到他们那里，他们一定会听你的话。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 以西结书 2:4; 撒母耳记上 8:7"> 然而以色列人却不肯听从你，因为他们额头刚硬，心里顽固，不肯听从我。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 1:18; 使徒行传 7:51–56; 弥迦书 3:8"> 不过，我要使你的脸像他们的脸一样刚硬，使你的额头像他们的额头一样刚硬。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 2:6; 耶利米书 1:8; 以赛亚书 50:7"> 我要使你的额头比火石更硬，如同金刚石。他们虽然是一群叛逆的人，你不要害怕，也不要因为他们的脸色而惊慌。”</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 119:11; 约伯记 22:22; 以西结书 3:1–3"> 祂又说：“人子啊，你要留心听我说的一切话，牢记在心。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 2:7; 以西结书 3:27; 以西结书 33:30"> 你要到你那些被掳的同胞那里，不论他们听不听，你都要向他们宣告，‘主耶和华这样说。’”</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:3; 使徒行传 8:39; 以西结书 11:1"> 那时，耶和华的灵把我举起，我听见后面有隆隆的声音说：“耶和华的荣耀在祂所在之地当受称颂！”</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 1:24; 以西结书 10:16–17; 以西结书 10:5"> 我听见活物的翅膀相碰的声音，以及他们旁边的轮子发出的隆隆声。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 37:1; 耶利米书 20:7–9; 列王纪下 3:15"> 耶和华的灵把我举起带走了。我心里苦闷，充满愤怒，耶和华大能的手按在我身上。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 137:1; 约伯记 2:13; 创世记 50:10"> 我来到住在提勒·亚毕的被掳的人中，他们在迦巴鲁河边。我感到无比震惊，在他们中间坐了七天。</span>

## 告诫以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 42:7"> 过了七天，耶和华对我说：</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 52:8; 希伯来书 13:17; 历代志下 19:10"> “人子啊，我立你为以色列人的守望者，你要听我口中的话并替我告诫他们。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 33:6; 雅各书 5:19–20; 以西结书 3:20"> 如果我说恶人必定死，你却不告诫他，劝诫他改邪归正，好保全性命，他必因自己的罪而死，我却要向你追讨他的血债。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 33:9; 以西结书 14:20; 提摩太前书 4:16"> 如果你告诫恶人，他却不肯改邪归正、停止作恶，他必因自己的罪而死，而你必保全性命。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 18:24; 以西结书 18:26; 以西结书 33:12–13"> 如果一个义人偏离正道、犯罪作恶，我会使他绊倒，他必死亡。如果你不告诫他，他必死在罪恶之中，他以前的义行也不会被记念，而我要追究你的责任。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:16; 箴言 9:9; 提多书 2:15"> 如果你告诫他不要犯罪，他听了你的告诫不再犯罪，他必存活，你也必保住性命。”</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:6; 以西结书 37:1; 以西结书 8:4"> 在那里，耶和华的手按在我身上，对我说：“你起来前往平原，我要在那里对你说话。”</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 1:28; 使徒行传 7:55; 启示录 1:17"> 我就起来，到了平原，看见耶和华的荣耀停在那里，那荣耀和我在迦巴鲁河边所见的一样，我就俯伏在地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 2:2; 但以理书 10:19; 但以理书 10:8–10"> 这时耶和华的灵进入我里面，使我站立起来。耶和华对我说：“你要把自己关在房子里。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 4:8; 使徒行传 9:16; 马可福音 3:21"> 人子啊，他们必把你捆绑起来，使你不能到百姓当中。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 24:27; 弥迦书 3:6–7; 阿摩司书 8:11–12"> 同时，我要使你的舌头紧贴上膛，使你不能开口责备他们，因为他们是一群叛逆的人。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 12:2–3; 以西结书 24:27; 以西结书 3:11"> 但当我对你说话的时候，我必开启你的口，你要向他们宣告，‘主耶和华这样说。’肯听的就让他听，不肯听的就由他不听，因为他们是一群叛逆的人。”</span>
</div>

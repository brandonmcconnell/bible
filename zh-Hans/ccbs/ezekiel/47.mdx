## 从圣殿流出的水

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 22:1; 撒迦利亚书 14:8; 约珥书 3:18"> 他又领我回到圣殿门口，我看见有水从圣殿的门槛下往东流去。殿的正面朝东，这水从殿的南侧经祭坛的南边往下流。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 44:4; 以西结书 44:2"> 随后他领我由北门出来，从外面绕到外院的东门，我见水从东门的南面涓涓流出。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结书 40:3; 使徒行传 10:45–46; 使徒行传 11:16–18"> 那人手拿量绳向东量了五百米，然后领我涉水前行，水深及踝。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:6; 罗马书 15:19; 使徒行传 19:10–20"> 他又量了五百米，领我涉水前行，水深及膝。他又量了五百米，领我涉水前行，水深及腰。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 11:9; 哈巴谷书 2:14; 马太福音 13:31–32"> 他又量了五百米，水已高涨成河，足可游泳，无法再涉水穿过。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 44:5; 以西结书 40:4; 撒迦利亚书 4:2"> 他问我：“人子啊，你看见了吗？”<br />然后，他带我回到河边，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 47:12; 启示录 22:2; 列王纪下 2:13"> 我发现河的两岸长满了树木。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 3:16; 申命记 3:17; 列王纪下 2:19–22"> 他对我说：“这水向东流，经过亚拉巴流到盐海，使那里的咸水变为淡水。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 7:37–38; 约翰福音 6:63; 约翰福音 4:14"> 河水流经的地方，万物滋长，鱼产丰盛，因为河水使那里的咸水变成淡水了，所以河水流经之处万物滋长。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 诗篇 104:25; 民数记 34:6"> 渔夫要站在岸边捕鱼，从隐·基底到隐·以革莲都是晒网的地方。那里的鱼就像大海的鱼一样种类繁多。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 29:23; 启示录 22:11; 耶利米书 17:6"> 但沼泽和湿洼之地却不会变淡，留作产盐之地。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 22:2; 诗篇 1:3; 耶利米书 17:8"> 沿河两岸长着各种果树，树的叶子不会枯干，果实也不会断绝。树必月月结出新果，不但果实可吃，叶子还可作药用，因为这水是从圣所流出来的。”</span>
</div>
</div>

## 地界

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 48:4–6; 耶利米书 3:18; 民数记 34:2–12"> 主耶和华说：“你们要按照我划定的地界，把土地分给以色列的十二支派作产业，约瑟支派<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“约瑟支派”就是以法莲和玛拿西两支派。">a</a></sup>要得两份地业。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 20:5–6; 创世记 12:7; 以西结书 48:29"> 其他各支派都要均分，因为我曾起誓将这地方赐给你们祖先。这地方必成为你们的产业。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 34:8; 以西结书 48:1"> “以下是这地方的地界：北界从地中海岸经希特伦到哈马口、西达达、</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 48:1; 民数记 13:21; 撒母耳记下 8:8"> 比罗他和大马士革与哈马边界中间的西伯莲，一直到浩兰边界的哈撒·哈提干。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 48:1; 民数记 34:9"> 这样，疆界是从地中海岸一直到大马士革边界的哈萨·以难，北面以哈马为界。这是北界。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 13:10; 创世记 31:23; 创世记 31:47"> “东界是从北界南下经浩兰和大马士革之间，沿着基列和以色列中间的约旦河为界，一直伸展到东部的海。这是东界。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 48:28; 申命记 32:51; 民数记 34:5"> “南界从他玛延伸到米利巴·加低斯泉，沿埃及小河直到地中海。这是南界。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 34:6; 以西结书 48:1"> “西界从南界沿地中海的海岸到北界哈马口对面的地方。这是西界。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> “你们要按照以色列的各支派分这块地，</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:11; 以弗所书 3:6; 使徒行传 11:18"> 用抽签的方法来分产业，也要分给在你们中间居住、生儿育女的外族人。你们要视他们如同以色列人，要让他们在以色列各支派中与你们同分产业。</span>
<span className="v" id="v23" data-v="23"> 他们居住在哪一支派，就要在哪一支派中分产业给他们。这是主耶和华说的。”</span>
</div>
</div>

</div>

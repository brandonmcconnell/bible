## 耶路撒冷的不忠

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 22:2; 以西结书 20:4; 以赛亚书 58:1"> “人子啊，你要使耶路撒冷知道她的可憎行径。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 16:45; 以赛亚书 51:1–2; 申命记 20:17"> 你要告诉她，主耶和华这样对她说，‘你祖居迦南，生于迦南。你的父亲是亚摩利人，母亲是赫人。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 2:3; 创世记 15:13; 出埃及记 5:16–21"> 你出生之日没人剪断你的脐带，没人用水洗你的身体，没人用盐擦净你，没人用布包裹你。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:10; 创世记 21:10; 出埃及记 1:22"> 没有人可怜你，同情你，为你做以上的事。你生下来便遭人厌恶，被扔在野外。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 2:4–5; 约翰福音 5:25; 提多书 3:3–7"> “‘我从你旁边经过，见你在血泊中挣扎，便对血泊中的你说，活下去！</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 1:10; 出埃及记 1:7; 以赛亚书 62:3"> 我使你像田间的植物一样茁壮生长。你渐渐发育成熟，长得亭亭玉立，双乳丰满，秀发垂肩，但仍然赤身露体。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 3:9; 耶利米书 2:2–3; 罗马书 5:8"> “‘后来我又从你旁边经过，见你正值少女怀春，我便用我的衣襟遮盖你赤露的身体，向你起誓，与你定下婚约，你便属于我。这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 23:5; 路得记 3:3; 约翰一书 2:27"> 我用水清洗你，洗净你身上的血污，给你涂上馨香的油，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 16:18; 以西结书 16:13; 以赛亚书 61:10"> 给你穿上锦绣的衣裳和海狗皮的鞋，披上细麻衣和丝绸外袍。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 24:22; 以赛亚书 3:19; 创世记 41:42"> 我用首饰来装扮你，给你戴上手镯、项链、</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 3:21; 以赛亚书 28:5; 耶利米书 13:18"> 鼻环、耳环和华冠。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 32:13–14; 诗篇 50:2; 列王纪上 4:21"> 这样，你戴的是金银首饰，穿的是绫罗绸缎，吃的是细面粉、蜂蜜和油。你变得美艳绝伦，晋升为王后。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 10:24; 耶利米哀歌 2:15; 哥林多前书 4:7"> 你的美貌名扬列国，因为我给你的华贵使你美貌无比。这是主耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 57:8; 耶利米书 2:20; 以西结书 16:25"> “‘你却仗着自己的美貌和名声纵情淫乱，与所有过路的人纵情苟合。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:7; 以西结书 7:20; 历代志下 28:24"> 你用自己的衣服在拜偶像的丘坛结彩，在那里行淫。这样的事真是空前绝后！</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 23:14–21; 耶利米书 3:9; 以西结书 16:11"> 你用我给你的金银首饰为自己制造男人的像，与它们苟合。</span>
<span className="v" id="v18" data-v="18"> 你给它们穿上锦绣衣服，把我给你的膏油和香料供奉它们。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 16:13; 何西阿书 2:8–13; 创世记 8:21"> 你把我赐你吃的细面粉、油和蜂蜜作为馨香的供物奉献在它们面前。这是主耶和华说的。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 23:37; 以西结书 20:31; 耶利米书 7:31"> 你还把你给我生的儿女献给偶像作食物。难道你淫乱还不够吗？</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 17:17; 利未记 18:21; 申命记 18:10"> 你竟屠杀我的儿女，把他们焚烧献给偶像。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 2:2; 何西阿书 11:1; 以西结书 16:43"> 你做这一切可憎、淫乱的事，忘记了你幼年赤身露体在血泊中挣扎的日子。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 12:12; 以西结书 2:10; 以西结书 24:6"> “‘主耶和华说，你有祸了！你有祸了！你不但做了这些恶事，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:58; 以西结书 16:39; 以西结书 16:31"> 还为自己筑祭坛，在各广场建高高的神庙。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 16:31; 耶利米书 3:2; 创世记 38:21"> 你在街头巷尾建高高的神庙，糟蹋自己的美貌。你向每一个过路的人投怀送抱，纵情淫乱。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 23:19–21; 以西结书 20:7–8; 以西结书 8:10"> 你还与放纵情欲的邻邦埃及人苟合，纵情淫乱，激起我的愤怒。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 9:12; 以西结书 16:57; 以西结书 16:37"> 看啊，我要伸手攻击你，削减你的口粮，把你交给憎恨你的非利士人，任他们宰割。他们都为你的淫荡行为感到羞耻。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 16:7; 何西阿书 10:6; 列王纪下 16:10–18"> 你欲海难填，又跟亚述人行淫，但你仍不满足，</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 21:9; 士师记 2:12–19; 以西结书 13:14–23"> 于是又跟那商贾之地的迦勒底人纵情淫乱，但你仍不满足。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 3:3; 以赛亚书 1:3; 以赛亚书 3:9"> “‘主耶和华说，你的心败坏至极，所作所为简直就像不知羞耻的娼妓。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 16:33–34; 以赛亚书 52:3; 以西结书 16:39"> 你在街头巷尾筑祭坛，在广场建高高的神庙，甚至不屑于收嫖资，实在连妓女都不如。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 2:28; 以西结书 23:37; 耶利米书 2:25"> 你这荡妇，宁愿跟外人淫乱，也不爱自己的丈夫！</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 57:9; 何西阿书 8:9–10; 以西结书 16:41"> 妓女接受嫖资，你却送礼物给所有的情人，引诱他们从四方前来跟你淫乱。</span>
<span className="v" id="v34" data-v="34"> 你卖淫不同于别的妓女，没有人找你买春，没有人给你嫖资，你倒贴钱给人，你真是与众不同。</span>
</div>
</div>

## 主对耶路撒冷的审判和应许

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 4:18; 列王纪上 22:19; 约翰福音 4:10"> “‘你这淫妇，要听耶和华的话。</span>
<span className="v" id="v36" data-v="36" data-xref="以西结书 23:10; 以西结书 24:13; 西番雅书 3:1"> 主耶和华说，你放纵情欲，赤身露体地与众情人苟合。你祭拜一切可憎的偶像，把自己儿女的血献给它们。</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿书 2:10; 耶利米书 13:22; 何西阿书 2:3"> 因此，我要把你所爱和所恨的情人都聚集起来。我要聚集他们从四方攻击你，让你赤裸裸地暴露在他们面前，让他们看到你赤身露体。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 20:10; 创世记 9:6; 西番雅书 1:17"> 我要惩罚你，像惩罚淫乱和杀人的妇女一样。我要把烈怒和义愤倒在你身上，报应你杀人流血的罪。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 23:26; 何西阿书 2:3; 以西结书 16:24–25"> 我要把你交在你的情人手里。他们必拆毁你的祭坛，夷平你高高的神庙，剥去你的衣裳，夺走你的珠宝，留下你赤身露体。</span>
<span className="v" id="v40" data-v="40" data-xref="以西结书 23:47; 哈巴谷书 1:6–10; 约翰福音 8:5–7"> 他们要聚众攻击你，用石头打你，用刀剑砍碎你，</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 23:48; 耶利米书 52:13; 耶利米书 39:8"> 烧毁你的房屋，在众妇女面前审判你。我要阻止你的淫乱行为，使你不再倒贴钱给情人。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 5:13; 以西结书 21:17; 以赛亚书 40:1–2"> 这样，我的烈怒才会平息，我的义愤才会消除，我才会平静下来，不再发怒。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 16:22; 以西结书 11:21; 诗篇 78:42"> 因为你忘记了幼年的日子，做这些事来惹我发怒，我要照你的所作所为报应你。因为你不仅行一切可憎的事，还放荡淫乱。这是主耶和华说的。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 18:2–3; 诗篇 106:35–38; 撒母耳记上 24:13"> “‘看啊，好说俗语的人都会讥讽你说，有其母必有其女。</span>
<span className="v" id="v45" data-v="45" data-xref="撒迦利亚书 11:8; 以赛亚书 1:4; 以西结书 23:37–39"> 你和你母亲及姊妹如出一辙，都厌弃自己的丈夫和儿女。你母亲是赫人，你父亲是亚摩利人。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 23:4; 以西结书 16:48–49; 以西结书 16:53–56"> 你姐姐是撒玛利亚，她和她的女儿们住在你的北面。你妹妹是所多玛，她和她的女儿们住在你的南面。</span>
<span className="v" id="v47" data-v="47" data-xref="列王纪下 21:9; 以西结书 16:51; 以西结书 5:6–7"> 你不仅追随和效法她们可憎的行径，还很快超过了她们。</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 10:15; 路加福音 10:12; 使徒行传 7:52"> 我凭我的永恒起誓，与你妹妹所多玛和她女儿们相比，你和你女儿们的行径有过之而无不及。这是主耶和华说的。</span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 138:6; 以西结书 28:2; 创世记 13:10"> 看啊，你妹妹所多玛和她的女儿们狂妄自大，安逸饱足，对穷困的人漠不关心。这就是你妹妹所多玛的罪过。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 19:24; 创世记 18:20; 创世记 19:5"> 她们心骄气傲，在我面前做可憎的事，我看见后便除掉了她们。</span>
<span className="v" id="v51" data-v="51" data-xref="耶利米书 3:8–11; 路加福音 12:47–48; 罗马书 3:9–20"> 撒玛利亚的罪还不及你的一半，你比她们做了更多可憎之事，以致与你的可憎行径相比，你的姊妹倒显得公义了。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 7:1–5; 以西结书 36:15; 以西结书 16:56"> 既然你帮了你的姊妹，使她们显得公义，你就蒙受羞辱吧！因为你犯的罪比你姊妹犯的罪更可憎，以致她们显得比你更公义。因此，你就自取其辱，抱愧蒙羞吧！</span>
<span className="v" id="v53" data-v="53" data-xref="以西结书 29:14; 耶利米书 12:16; 以西结书 39:25"> “‘然而，我要使所多玛、撒玛利亚及她们的女儿们复兴，并使你一同复兴，</span>
<span className="v" id="v54" data-v="54" data-xref="以西结书 14:22–23; 耶利米书 2:26; 以西结书 36:31–32"> 让你自取其辱，深感羞愧，因为你的一切恶行使她们反得安慰。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结书 36:11; 玛拉基书 3:4; 以西结书 16:53"> 你姊妹所多玛、撒玛利亚和她们的众女儿，以及你和你的众女儿必恢复起初的光景。</span>
<span className="v" id="v56" data-v="56" data-xref="以赛亚书 65:5; 路加福音 15:28–30; 西番雅书 3:11"> 在你骄傲的日子，你的恶行还没有被揭露的时候，你觉得妹妹所多玛不屑一提。但现在，你却成为以东的众女儿和她四邻非利士的众女儿的笑柄。你周围的人都鄙视你。</span>
<span className="v" id="v58" data-v="58" data-xref="以西结书 23:49; 耶利米哀歌 5:7; 创世记 4:13"> 你要承担淫荡和可憎行径带来的惩罚。这是耶和华说的。</span>
<span className="v" id="v59" data-v="59" data-xref="以赛亚书 24:5; 以西结书 17:19; 申命记 29:25"> “‘主耶和华说，你背誓毁约，我必照你的所作所为报应你。</span>
<span className="v" id="v60" data-v="60" data-xref="何西阿书 2:19–20; 希伯来书 12:24; 以西结书 16:8"> 然而，我顾念在你幼年时与你所立的约，我要与你立一个永远的约。</span>
<span className="v" id="v61" data-v="61" data-xref="希伯来书 8:13; 加拉太书 4:26–31; 以赛亚书 66:7–12"> 你接纳你姊妹的时候，会想起自己的所作所为并自觉羞愧。我要将你姊妹赐给你作女儿，我这样做并不是出于我与你所立的约。</span>
<span className="v" id="v62" data-v="62" data-xref="耶利米书 24:7; 以西结书 6:7; 以西结书 39:22"> 我要和你立约，使你知道我是耶和华。</span>
<span className="v" id="v63" data-v="63" data-xref="诗篇 39:9; 罗马书 3:19; 以西结书 36:31–32"> 我要赦免你所有的罪，那时你想起这事会羞愧难当，不敢再开口。这是主耶和华说的。’”</span>
</div>

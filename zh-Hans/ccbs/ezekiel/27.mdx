## 为泰尔唱哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 19:1; 耶利米书 9:10; 以西结书 28:12"> “人子啊，你要为泰尔唱哀歌，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 27:4; 以赛亚书 23:11; 以赛亚书 23:2–3"> 告诉位于海口、跟沿海各民族通商的泰尔，主耶和华这样说，<br /><span className="pl pl-1">“‘泰尔啊，</span><br /><span className="pl pl-1">你曾夸耀自己完美无瑕。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 26:5"> <span className="pl pl-1">你的疆域在大海上，</span><br /><span className="pl pl-1">你的建造者把你造得完美无瑕。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:9; 以赛亚书 14:8; 雅歌 4:8"> <span className="pl pl-1">他们用示尼珥的松木做你的船板，</span><br /><span className="pl pl-1">用黎巴嫩的香柏木做桅杆，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 10:4; 以赛亚书 2:13; 撒迦利亚书 11:2"> <span className="pl pl-1">用巴珊的橡木做你的桨，</span><br /><span className="pl pl-1">把象牙镶嵌在基提沿岸的黄杨木上做甲板，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 10:9; 出埃及记 25:4; 创世记 10:4"> <span className="pl pl-1">用埃及来的绣花细麻布做你的帆，</span><br /><span className="pl pl-1">作为你的旗号，</span><br /><span className="pl pl-1">用以利沙岛来的蓝布和紫布做船篷。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 10:18; 列王纪上 9:27; 以西结书 27:11"> <span className="pl pl-1">西顿和亚发的居民是你的船夫，</span><br /><span className="pl pl-1">你的智者在船上为你掌舵。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 5:18; 约书亚记 13:5; 诗篇 83:7"> <span className="pl pl-1">迦巴勒的老手和巧匠在船上为你修补船篷，</span><br /><span className="pl pl-1">所有海船和水手都来与你做生意。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 38:5; 以西结书 30:5; 以赛亚书 66:19"> “‘你军队中的战士有波斯人、路德人、弗人，他们在你的墙上挂起盾牌和头盔，展示你的光彩。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 27:3–4"> 亚发人和你的军队都守卫在你的城墙上，歌玛底人把守你的城楼，他们在你四围的墙上挂满盾牌，使你完美无瑕。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 10:4; 以赛亚书 23:10; 以西结书 38:13"> “‘他施人因你有丰富的货物，就拿银、铁、锡、铅来跟你交易。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:2; 以赛亚书 66:19; 以西结书 39:1"> 雅完人、土巴人、米设人也跟你通商，用奴隶和铜器来换取你的货物。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:3; 以西结书 38:6; 历代志上 1:6"> 陀迦玛人用马匹、战马和骡子来跟你交易。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 10:7; 启示录 18:12; 列王纪上 10:22"> 底但人也是你的客商，你的市场远及沿海一带，他们拿象牙、乌木来跟你交易。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 以西结书 28:13; 撒母耳记下 10:6"> 因为你的货物丰富，亚兰人也成了你的客户，他们用绿宝石、紫布、刺绣、细麻布、珊瑚和红宝石与你交换货物。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 11:33; 列王纪上 5:9; 耶利米书 8:22"> 犹大和以色列也是你的客商，他们用米匿的麦、饼、蜜、油和香料与你交换货物。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 7:8; 创世记 15:2; 以西结书 47:16–18"> 大马士革见你的货物丰富，就用黑本的酒和沙哈的羊毛来跟你交易。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 30:23–24; 诗篇 45:8; 雅歌 4:13–14"> 从乌萨来的威但人和雅完人用熟铁、肉桂、菖蒲与你交换货物。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 25:3; 以西结书 27:15"> 底但人用马鞍垫来跟你交易。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 60:7; 创世记 25:13; 列王纪上 10:15"> 阿拉伯人和基达的所有首领都来做你的客商，他们用羊羔、绵羊和山羊来跟你交易。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 10:7; 以赛亚书 60:6; 诗篇 72:10"> 示巴和拉玛的商人用各类上等香料、宝石和黄金交换你的货物。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 19:12; 以赛亚书 37:12; 阿摩司书 1:5"> 哈兰、干尼、伊甸、示巴、亚述和基抹的商人都来跟你交易，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 2:8"> 他们把华丽衣服、蓝布、刺绣和彩色地毯捆扎结实，拿来跟你交易。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 2:16; 诗篇 48:7; 以赛亚书 23:14"> <span className="pl pl-1">“‘他施的船只替你运货，</span><br /><span className="pl pl-1">你在海上载满沉甸甸的货物。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 48:7; 以西结书 26:19; 使徒行传 27:14"> <span className="pl pl-1">船夫把你摇到汪洋之中，</span><br /><span className="pl pl-1">但东风要把你击碎在海中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; 以西结书 27:24; 以西结书 27:12"> <span className="pl pl-1">你的财富、货物、商品、</span><br /><span className="pl pl-1">水手、舵手、修补匠、客商、</span><br /><span className="pl pl-1">战士和人民在你倾覆的日子都要沉到深海里。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 26:10; 出埃及记 15:14; 以西结书 31:16"> <span className="pl pl-1">你舵手的哀号声必震动海岸，</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 26:16; 以西结书 32:10; 启示录 18:17–24"> <span className="pl pl-1">所有的船夫、水手、舵手都必弃船登岸，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 6:26; 撒母耳记下 1:2; 耶利米哀歌 2:10"> <span className="pl pl-1">为你放声痛哭，</span><br /><span className="pl pl-1">把尘埃撒在头上，</span><br /><span className="pl pl-1">在灰中打滚，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 7:18; 以赛亚书 22:12; 以赛亚书 15:2"> <span className="pl pl-1">又为你剃光头发，腰束麻布，</span><br /><span className="pl pl-1">并为你伤心哭泣，痛苦哀号。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 26:17; 启示录 18:18; 以西结书 27:2"> <span className="pl pl-1">他们在痛哭中为你唱起哀歌，</span><br /><span className="pl pl-1">哀悼你说，</span><br /><span className="pl pl-1">有哪一座城像泰尔一样在深海中销声匿迹呢？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="启示录 18:19; 以西结书 27:3; 以西结书 28:16"> <span className="pl pl-1">你的货物由海上运出，</span><br /><span className="pl pl-1">满足了许多国家；</span><br /><span className="pl pl-1">你的资财和货物使地上的君王富裕。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 27:26–27; 撒迦利亚书 9:3–4; 以西结书 26:19–21"> <span className="pl pl-1">如今你在汪洋中被海浪击碎，</span><br /><span className="pl pl-1">你的货物和人民都一同沉没了。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="以西结书 32:10; 以赛亚书 23:6; 以西结书 26:15–18"> <span className="pl pl-1">沿海的居民因你而惊骇，</span><br /><span className="pl pl-1">君王都吓得面容失色。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 18:16; 诗篇 37:10; 西番雅书 2:15"> <span className="pl pl-1">各国商人都嗤笑你，</span><br /><span className="pl pl-1">你那可怕的末日来临了，</span><br /><span className="pl pl-1">你将永远不复存在。’”</span></span>

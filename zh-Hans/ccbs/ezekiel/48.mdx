## 分地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 47:15–17; 约书亚记 19:40–47; 启示录 7:4–8"> “以下是各支派分得的土地：<br />“但的地业在北部：从希特伦经哈马口到大马士革边界的哈萨·以难，北面靠近哈马，横跨东西两地。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 19:24–31; 创世记 30:12–13"> 亚设的地业从东到西与但的地业接壤。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 19:32–39; 创世记 30:7–8"> 拿弗他利的地业从东到西与亚设的地业接壤。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:1–11; 约书亚记 13:29–31; 创世记 48:14–20"> 玛拿西的地业从东到西与拿弗他利的地业接壤。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 17:8–10; 约书亚记 17:14–18; 约书亚记 16:1–10"> 以法莲的地业从东到西与玛拿西的地业接壤。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 13:15–21; 创世记 29:32; 创世记 49:3–4"> 吕便的地业从东到西与以法莲的地业接壤。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:1–63; 约书亚记 19:9; 创世记 29:35"> 犹大的地业从东到西与吕便的地业接壤。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 45:1–6; 以赛亚书 12:6; 以赛亚书 33:20–22"> “犹大边界以南将是你们划分出来的那块地，宽十二公里半，由东至西的长度与其他各支派的地相同，圣殿在那块地的中央。</span>
<span className="v" id="v9" data-v="9"> 你们献给耶和华的圣地长十二公里半、宽五公里，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 45:4; 以西结书 44:28; 马太福音 10:10"> 南北面各长十二公里半，东西面各宽五公里。耶和华的圣所在这块地的中央。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 40:46; 以西结书 44:10; 马太福音 24:45–46"> 这块地要归给忠心事奉我的圣洁祭司撒督的子孙。当以色列人步入歧途时，他们没有与利未人同流合污。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 27:21; 以西结书 45:4"> 这块从圣地中划出的至圣之地要归给他们，它与利未人所得的地业相邻。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 45:3; 申命记 12:19; 以西结书 45:5"> 利未人的地与祭司的地并排挨着，长十二公里半，宽五公里。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:28; 利未记 27:9–10; 出埃及记 22:29"> 他们不可把这块地出卖或交换，不可把这块最好的地转让给他人，因为它是归给耶和华的圣地。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 42:20; 以西结书 45:6; 以西结书 44:23"> “剩下的十二公里半长、两公里半宽的地方作公共用地，用来建城邑、房屋和草场，城要建在这地方的中央。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 21:16"> 城是正方形的，东、西、南、北各长两公里半。</span>
<span className="v" id="v17" data-v="17"> 城四周要有郊野，东西南北各长一百二十五米，</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 9:27; 以斯拉记 2:43–58; 以西结书 45:6"> 与圣地相邻，城外东西两侧剩下的地各长五公里，地里的出产要作城内工人的食物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 45:6; 列王纪上 4:7–23; 尼希米记 11:1–36"> 所有在这城里做工的以色列各支派的人都要耕种这片土地。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 21:16; 希伯来书 12:17"> 你们所献的这块圣地和城区是方形的，四面各长十二公里半。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 48:22; 以西结书 37:24; 以西结书 48:8"> “圣地和城区东西两边的余地要归君王。两边的余地从圣地十二公里半宽的东西边界开始，沿各支派所分的地，分别向东向西延伸到以色列的东界和西界。圣地和圣殿在地的中央。</span>
<span className="v" id="v22" data-v="22"> 利未人的产业和城区在君王土地的中央，君王的土地在犹大和便雅悯支派之间。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约书亚记 18:21–28; 以西结书 48:1–7; 创世记 35:16–19"> “以下是其他各支派所分的地业：<br />“便雅悯的一份地业从东跨到西。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:1–9; 创世记 29:33; 创世记 49:5–7"> 西缅的一份地业从东到西与便雅悯的地业接壤。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 19:17–23; 创世记 30:14–18"> 以萨迦的一份地业从东到西与西缅的地业接壤。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 19:10–16; 创世记 30:19–20"> 西布伦的一份地业从东到西与以萨迦的地业接壤。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 13:24–28; 创世记 30:10–11"> 迦得的一份地业从东到西与西布伦的地业接壤。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 47:15; 历代志下 20:2; 以西结书 47:19–20"> 迦得的南界是从他玛延伸到米利巴·加低斯泉，沿埃及小河，一直到地中海。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 13:1–21; 民数记 34:2; 民数记 34:13"> 这就是你们要抽签分给以色列各支派的土地，作为他们的产业。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结书 48:16; 启示录 21:16; 以西结书 48:32–35"> “以下是城的各个出口。北面的墙是两公里半长，</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 21:12–13; 以赛亚书 26:1–2; 启示录 21:21"> 有三道门，按以色列的各支派命名，分别是吕便门、犹大门和利未门。</span>
<span className="v" id="v32" data-v="32"> 东面的墙是两公里半长，有三道门，分别是约瑟门、便雅悯门和但门。</span>
<span className="v" id="v33" data-v="33"> 南面的墙是两公里半长，有三道门，分别是西缅门、以萨迦门和西布伦门。</span>
<span className="v" id="v34" data-v="34"> 西面的墙是两公里半长，有三道门，分别是迦得门、亚设门和拿弗他利门。</span>
<span className="v" id="v35" data-v="35" data-xref="启示录 21:3; 撒迦利亚书 2:10; 启示录 22:3"> 城的四周共长九公里半，从那时起，这城必叫‘耶和华的所在’。”</span>
</div>
</div>

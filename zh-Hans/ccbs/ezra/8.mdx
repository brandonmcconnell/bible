## 归回之人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:7; 以斯拉记 2:62; 历代志上 9:1"> 亚达薛西王年间，与我一起从巴比伦上到耶路撒冷之人的族长和家谱如下：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:22; 历代志上 3:1; 历代志上 6:3–15"> 非尼哈的子孙有革顺；以他玛的子孙有但以理；大卫的子孙有哈突；</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:3; 尼希米记 10:14; 尼希米记 7:8"> 巴录的后裔、示迦尼的子孙有撒迦利亚及一百五十名与他一同记入族谱的男子；</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 2:6; 尼希米记 10:14; 尼希米记 7:11"> 巴哈·摩押的子孙有西拉希雅的儿子以利约乃及二百名男子；</span>
<span className="v" id="v5" data-v="5"> 萨土<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“萨土”参照《七十士译本》，希伯来文无此字。">a</a></sup>的子孙有雅哈悉的儿子示迦尼及三百名男子；</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 2:15; 尼希米记 10:16; 尼希米记 7:20"> 亚丁的子孙有约拿单的儿子以别及五十名男子；</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:31; 尼希米记 7:34; 以斯拉记 2:7"> 以拦的子孙有亚他利雅的儿子耶筛亚及七十名男子；</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 11:4; 以斯拉记 2:4; 尼希米记 7:9"> 示法提雅的子孙有米迦勒的儿子西巴第雅及八十名男子；</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 7:11; 以斯拉记 2:6"> 约押的子孙有耶歇的儿子俄巴底亚及二百一十八名男子；</span>
<span className="v" id="v10" data-v="10"> 巴尼<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“巴尼”参照《七十士译本》，希伯来文无此字。">b</a></sup>的子孙有约细斐的儿子示罗密及一百六十名男子；</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 10:28; 尼希米记 7:16; 以斯拉记 2:11"> 比拜的子孙有比拜的儿子撒迦利亚及二十八名男子；</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:12; 尼希米记 7:17"> 押甲的子孙有哈加坦的儿子约哈难及一百一十名男子；</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 2:13; 尼希米记 7:18"> 稍后归回的亚多尼干的子孙有以利法列、耶利、示玛雅及六十名男子；</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 10:12; 以斯拉记 2:14; 尼希米记 7:19"> 比革瓦伊的子孙有乌太、撒刻及七十名男子。</span>
</div>
</div>

## 以斯拉为圣殿召集利未人

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 8:21; 以斯拉记 8:31; 以斯拉记 7:7"> 我把他们召集在流往亚哈瓦的河边，我们在那里扎营三天。我察看民众和祭司，发现他们当中没有利未人。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉记 8:18; 以斯拉记 10:39"> 于是，我派人把首领以利以谢、亚列、示玛雅、以利拿单、雅立、以利拿单、拿单、撒迦利亚、米书兰及两位教师约雅立和以利拿单叫来。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:43; 出埃及记 4:15; 民数记 8:22–26"> 我派他们去见迦西斐雅的首领易多，请他们告诉易多及其做殿役的亲族带一些人来我们上帝的殿里事奉。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:15; 以斯拉记 7:28; 尼希米记 2:8"> 我们的上帝施恩帮助我们，他们给我们带来一位能干的人示利比及其弟兄和儿子共十八人。示利比是以色列的儿子利未的后裔抹利的子孙。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 6:1; 历代志上 6:16; 尼希米记 10:11"> 他们还带来哈沙比雅和米拉利的子孙耶筛亚，以及哈沙比雅的弟兄和儿子共二十人。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:43; 以斯拉记 7:7; 历代志上 9:2"> 此外还有二百二十名殿役，他们都是被点名指派的。从前大卫和众官员曾指派殿役服侍利未人。</span>
</div>
</div>

## 以斯拉带领百姓禁食

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:3; 约珥书 1:14; 撒母耳记上 7:6"> 然后，我在亚哈瓦河边宣布禁食，为要在我们的上帝面前谦卑下来，祈求祂保护我们、我们的儿女及财物一路平安。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 3:12; 诗篇 33:18–19; 历代志下 16:9"> 我羞于求王派步兵和骑兵沿途帮助我们御敌，因为我们曾经告诉王：“我们的上帝会施恩帮助寻求祂的人，但会向背弃祂的人发烈怒。”</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 29:12–13; 马太福音 7:7–8; 以斯拉记 8:31"> 因此，我们为这事禁食、寻求我们的上帝，祂应允了我们。</span>
</div>
</div>

## 献给圣殿的礼物

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 8:18–19"> 我选出十二位祭司长：示利比、哈沙比雅和他们的十个弟兄。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 8:33; 以斯拉记 7:14–16; 以斯拉记 1:8"> 王及其谋士和将领，以及所有在场的以色列人献给我们上帝殿的金银和器皿，我都秤了交给他们。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 1:9–11"> 我交给他们的有四十四万两银子、价值六万八千两银子的器皿、六万八千两金子、</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 共重八公斤半的二十个金碗和两件贵重如金子的上等精铜器皿。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 22:2–3; 利未记 21:6–8; 历代志上 23:28"> 我对他们说：“你们和这些器皿是献给耶和华的，金银是自愿献给你们祖先的上帝耶和华的礼物。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉记 8:33–34; 马可福音 13:34–35; 历代志上 26:20–26"> 你们要好好保管，护送到耶路撒冷耶和华殿的库房里，要在祭司长、利未人和以色列的各族长面前过秤。”</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:22; 历代志上 29:2–3; 以赛亚书 60:13"> 于是，祭司和利未人接过这些称过的金、银和器皿，要带去耶路撒冷我们上帝的殿里。</span>
</div>
</div>

## 返回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉记 8:21–22; 以斯拉记 7:9; 以斯拉记 8:15"> 一月十二日，我们从亚哈瓦河边出发上耶路撒冷。我们的上帝施恩帮助我们，救我们脱离仇敌和路上埋伏之人的攻击。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 2:11; 以斯拉记 7:8–9"> 到耶路撒冷后，我们休息了三天。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 3:4; 尼希米记 3:21; 以斯拉记 8:30"> 第四天，我们在上帝的殿里把金银和器皿过秤，交给乌利亚的儿子米利末祭司。在场的还有非尼哈的儿子以利亚撒，利未人耶书亚的儿子约撒拔和宾内的儿子挪亚底。</span>
<span className="v" id="v34" data-v="34"> 每样东西都被数过、称过，其重量都被记录下来。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以斯拉记 6:17; 历代志下 29:31–32; 诗篇 66:10–15"> 从流亡之地归回的人又献燔祭给以色列的上帝，为全体以色列人献上十二头公牛、九十六只公绵羊和七十七只绵羊羔，并献上十二只公山羊作赎罪祭。这些都是献给耶和华的燔祭。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉记 7:21–24; 以斯拉记 4:7–23; 以斯拉记 6:13"> 他们将王的谕旨交给王的总督和幼发拉底河西的省长，众官员都为民众和上帝殿的工作提供帮助。</span>
</div>
</div>

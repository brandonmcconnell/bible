## 以斯拉到达耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:1; 历代志上 6:4–14; 以斯拉记 7:21"> 这些事以后，波斯王亚达薛西年间，以斯拉从巴比伦上到耶路撒冷。以斯拉是西莱雅的儿子，西莱雅是亚撒利雅的儿子，亚撒利雅是希勒迦的儿子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 2:35; 撒母耳记下 8:17"> 希勒迦是沙龙的儿子，沙龙是撒督的儿子，撒督是亚希突的儿子，</span>
<span className="v" id="v3" data-v="3"> 亚希突是亚玛利雅的儿子，亚玛利雅是亚撒利雅的儿子，亚撒利雅是米拉约的儿子，</span>
<span className="v" id="v4" data-v="4"> 米拉约是西拉希雅的儿子，西拉希雅是乌西的儿子，乌西是布基的儿子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 6:25; 历代志下 26:20; 历代志上 6:4"> 布基是亚比书的儿子，亚比书是非尼哈的儿子，非尼哈是以利亚撒的儿子，以利亚撒是大祭司亚伦的儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 8:22; 以斯拉记 7:28; 以斯拉记 8:31"> 这以斯拉是位从巴比伦上来的律法教师，精通以色列的上帝耶和华赐下的摩西律法。他的上帝耶和华出手帮助他，使王批准他的一切要求。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 8:1–20; 历代志上 6:31–48; 历代志上 9:17–27"> 亚达薛西王第七年，一些以色列人、祭司、利未人、歌乐手、殿门守卫和殿役来到耶路撒冷。</span>
<span className="v" id="v8" data-v="8"> 这年一月一日，以斯拉从巴比伦启程去耶路撒冷，五月一日就到达那里，因为他的上帝施恩帮助他。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 2:7; 提摩太后书 4:2; 马太福音 7:24"> 以斯拉专心研读、遵行耶和华的律法，并在以色列教导律例和典章。</span>
</div>
</div>

## 亚达薛西王给以斯拉的谕旨

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 5:6; 以斯拉记 7:6; 马太福音 23:2"> 以斯拉是祭司和律法教师，精通耶和华赐给以色列的诫命和律例。亚达薛西王降旨给以斯拉，内容如下：</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 2:37; 以西结书 26:7; 以斯拉记 4:17"> “王中之王亚达薛西降旨给精通天上上帝律法的教师以斯拉祭司，愿你平安！</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:1; 诗篇 148:6; 历代志下 30:5"> “我现在降旨，我国中的以色列人、祭司和利未人，凡愿意上耶路撒冷的都可以与你同去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 1:14; 以斯拉记 7:25–26; 以斯拉记 7:28"> 我和七位谋士派你去按照你手中上帝的律法察看犹大和耶路撒冷的情况，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 135:21; 历代志下 6:2; 以斯拉记 6:12"> 并带去我和谋士们自愿献的金银，献给住在耶路撒冷的以色列的上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:6; 以斯拉记 1:4; 历代志上 29:9"> 还要带去你在巴比伦省得到的金银，以及民众和祭司为耶路撒冷的上帝之殿自愿奉献的祭物。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 12:5–11; 民数记 15:4–13; 以斯拉记 6:9–10"> 你一定要用这些金银购买公牛、公绵羊和绵羊羔，以及素祭和奠祭用品，把这一切献在耶路撒冷你们上帝殿的祭坛上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 22:7; 以弗所书 5:17; 列王纪下 12:15"> 至于余下的金银，你和你的弟兄可以按你们上帝的心意妥善使用。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:17; 以斯拉记 8:33–34; 历代志下 32:19"> 那些交托给你、用来在你上帝的殿里敬拜的器皿，你要带到耶路撒冷的上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 6:4; 以斯拉记 6:8–18"> 如果你们上帝的殿还需要你供应什么，你可以从国库支取费用。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:16; 以斯拉记 7:6; 以斯拉记 7:10–13"> “我亚达薛西王降旨给河西所有的财政大臣，精通天上上帝律法的律法教师以斯拉祭司无论向你们要什么，都要速速办理，</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未记 2:13; 以西结书 45:14"> 可以给他六万八千两银子、两万两千升麦子、两千二百升酒、两千二百升油，盐可以随意取用。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:4; 以斯拉记 7:18; 以斯拉记 6:10–12"> 不论天上的上帝为祂的殿有何要求，都要认真办理，以免祂的烈怒临到王及众王子的国。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 7:7; 以斯拉记 4:13; 以斯拉记 2:36–55"> 我们也通知你们不可向这座上帝殿的祭司、利未人、歌乐手、殿门守卫、殿役或其他工人征收赋税。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 7:10; 申命记 16:18; 雅各书 1:5"> “你以斯拉要运用上帝赐给你的智慧委派官员和审判官，让他们治理河西省的人民，就是所有明白你上帝律法的人。你要教导那些不明白你上帝律法的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 6:11; 申命记 13:1–18; 利未记 20:1–27"> 凡不遵行你上帝的律法和王法的，要对他严加治罪，或处死，或发配，或抄家，或监禁。”</span>
</div>
</div>

## 以斯拉赞美上帝

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 6:22; 启示录 17:17; 以赛亚书 60:13"> 以斯拉说： “我们祖先的上帝耶和华当受赞美！因为祂使王有这样的心意尊崇耶路撒冷耶和华的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 4:17–18; 以斯拉记 5:5; 创世记 32:28"> 祂又在王及其谋士和所有权贵面前施恩于我。因为我的上帝耶和华出手帮助我，我便有勇气召集以色列的首领与我一同上去。”</span>
</div>
</div>

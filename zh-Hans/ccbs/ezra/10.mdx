## 终止杂婚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:20; 诗篇 119:136; 罗马书 9:2"> 以斯拉祷告、认罪、哭泣、俯伏在上帝的殿前时，一大群以色列人，包括男女和孩子，都聚集到他那里，与他一起痛哭。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 13:27; 以斯拉记 9:2; 耶利米书 3:12–13"> 以拦的后裔耶歇的儿子示迦尼对以斯拉说：“我们对我们的上帝不忠，娶这地方的外族女子为妻，但以色列还有希望。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:2–3; 以斯拉记 9:4; 约书亚记 23:12–13"> 现在，我们来与我们的上帝立约，听从你和那些敬畏我们上帝诫命之人的指示，遵照律法行事，送走这些妻子和她们的儿女。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:10; 传道书 9:10; 希伯来书 12:12–13"> 起来吧！这事由你处理，我们支持你，放胆去做吧！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米记 13:25; 尼希米记 5:12; 箴言 9:9"> 于是，以斯拉起来，要祭司长、利未人和所有以色列人起誓照这话去做，他们就都起了誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 9:18; 尼希米记 3:1; 尼希米记 12:22"> 以斯拉从上帝的殿前起来，进了以利亚实的儿子约哈难的房间。他在那里不吃不喝，为流亡归来者的不忠而忧伤。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 1:1; 历代志下 30:5"> 他们在犹大和耶路撒冷发出通告，要求所有流亡归来的人在耶路撒冷集合。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:26; 约翰福音 9:22; 士师记 21:5"> 按照众首领和长老的决定，三天之内未到者，其财产会被没收，还要把他本人从流亡归来的会众中逐出。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 12:17–18; 耶利米书 10:13; 以斯拉记 7:8–9"> 三天内，所有的犹大人和便雅悯人都聚集在耶路撒冷。九月二十日，民众都坐在上帝的殿前面的广场上。因为这事，加上当时下大雨，众人都战战兢兢。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 9:6; 民数记 32:14; 马太福音 23:32"> 以斯拉祭司站起来对他们说：“你们对上帝不忠，娶外族的女子为妻，加重了以色列的罪恶。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 12:2; 以斯拉记 10:3; 以赛亚书 1:16–18"> 现在，你们要向你们祖先的上帝耶和华认罪，遵行祂的旨意，与这地方的人和你们的外族妻子断绝关系。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米记 13:23; 诗篇 78:57; 以斯拉记 10:3–4"> 会众都高声回答说：“你说的对，我们必照你的话做。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:18–44; 马太福音 7:13–14"> 可是，人这么多，又逢雨季，我们不能总站在外面，并且这事一两天也解决不了，因为我们在这事上犯了大罪。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:10; 历代志下 30:8; 民数记 25:4"> 不如让我们的首领为全体会众处理这事，让那些娶了外族女子为妻的人在指定的时间，与本城的长老和审判官一起来找首领解决，直到我们的上帝因这事而发的烈怒离开我们。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 11:16; 尼希米记 10:20; 尼希米记 12:33"> 只有亚撒黑的儿子约拿单和特瓦的儿子雅哈谢反对这事，支持他们的还有米书兰和利未人沙比太。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约伯记 29:16; 申命记 13:14; 约翰福音 7:51"> 流亡归来的人都遵命而行。以斯拉祭司按家族选出各族长，都是点名指定的。他们从十月一日开始着手查办这事，</span>
<span className="v" id="v17" data-v="17"> 到次年一月一日才查清娶外族女子为妻的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 5:2; 以斯拉记 3:2; 撒迦利亚书 3:1"> 祭司中娶外族女子为妻的有耶书亚的子孙约萨达的儿子及其弟兄玛西雅、以利以谢、雅立和基大利。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 6:6; 列王纪下 10:15; 历代志下 30:8"> 他们起誓答应休掉自己的妻子，并从羊群中献上一只公绵羊为自己赎罪。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:37; 历代志上 24:14; 尼希米记 7:40"> 音麦的子孙中有哈拿尼和西巴第雅。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 24:8; 以斯拉记 2:39; 尼希米记 7:42"> 哈琳的子孙中有玛西雅、以利雅、示玛雅、耶歇和乌西雅。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 9:12; 尼希米记 7:41; 以斯拉记 2:38"> 巴施户珥的子孙中有以利约乃、玛西雅、以实玛利、拿坦业、约撒拔和以利亚撒。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:10; 尼希米记 11:16; 以斯拉记 8:33"> 利未人中有约撒拔、示每、基拉雅——又名基利他、毗他希雅、犹大和以利以谢。</span>
<span className="v" id="v24" data-v="24"> 歌乐手中有以利亚实。殿门守卫中有沙龙、提联、乌利。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 2:3; 尼希米记 7:8"> 其他以色列人中有巴录的子孙拉米、耶西雅、玛基雅、米雅民、以利亚撒、玛基雅和比拿雅。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 10:2; 以斯拉记 2:31; 尼希米记 7:12"> 以拦的子孙中有玛他尼、撒迦利亚、耶歇、押底、耶利末和以利雅。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 7:13; 以斯拉记 2:8"> 萨土的子孙中有以利约乃、以利亚实、玛他尼、耶利末、撒拔和亚西撒。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯拉记 8:11; 以斯拉记 2:11; 尼希米记 7:16"> 比拜的子孙中有约哈难、哈拿尼雅、萨拜和亚勒。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 7:15; 尼希米记 10:4; 以斯拉记 2:10"> 巴尼的子孙中有米书兰、玛鹿、亚大雅、雅述、示押和耶利末。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:4; 尼希米记 7:11; 以斯拉记 2:6"> 巴哈·摩押的子孙中有阿底拿、基拉、比拿雅、玛西雅、玛他尼、比撒列、宾内和玛拿西。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:11; 尼希米记 7:35; 以斯拉记 2:32"> 哈琳的子孙中有以利以谢、伊示雅、玛基雅、示玛雅、西缅、</span>
<span className="v" id="v32" data-v="32"> 便雅悯、玛鹿、示玛利雅。</span>
<span className="v" id="v33" data-v="33" data-xref="以斯拉记 2:19; 尼希米记 7:22"> 哈顺的子孙中有玛特乃、玛达他、撒拔、以利法列、耶利买、玛拿西和示每。</span>
<span className="v" id="v34" data-v="34"> 巴尼的子孙中有玛玳、暗兰、乌益、</span>
<span className="v" id="v35" data-v="35"> 比拿雅、比底雅、基禄、</span>
<span className="v" id="v36" data-v="36"> 瓦尼雅、米利末、以利亚实、</span>
<span className="v" id="v37" data-v="37"> 玛他尼、玛特乃和雅扫。</span>
<span className="v" id="v38" data-v="38"> 宾内的子孙中有示每、</span>
<span className="v" id="v39" data-v="39"> 示利米雅、拿单、亚大雅、</span>
<span className="v" id="v40" data-v="40"> 玛拿底拜、沙赛、沙赖、</span>
<span className="v" id="v41" data-v="41"> 亚萨利、示利米雅、示玛利雅、</span>
<span className="v" id="v42" data-v="42"> 沙龙、亚玛利雅和约瑟。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 2:29; 尼希米记 7:33"> 尼波的子孙中有耶利、玛他提雅、撒拔、西比拿、雅玳、约珥和比拿雅。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; 以斯拉记 10:3; 箴言 2:16"> 以上这些人都娶了外族女子为妻，其中有些还生了子女。</span>
</div>
</div>

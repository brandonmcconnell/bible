## 重建祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:32; 利未记 23:24; 哥林多前书 1:10"> 到了七月，以色列人已安居各城，他们齐心聚集在耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:17; 以斯拉记 2:2; 哈该书 1:1"> 约萨达的儿子耶书亚及其祭司同僚、撒拉铁的儿子所罗巴伯及其亲属，一起重新筑造以色列上帝的祭坛，为要照上帝的仆人摩西在律法书上的记载在坛上献燔祭。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 4:4; 民数记 28:2–8; 以斯拉记 8:21–22"> 他们虽然惧怕当地的居民，还是在原来的根基上重建祭坛，并早晚在上面向耶和华献燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 8:14–17; 民数记 29:12–38; 出埃及记 23:16"> 他们照律法书的记载守住棚节，每天按规定的数目献上燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 29:39; 民数记 28:19; 出埃及记 29:38–42"> 之后，他们献上日常的燔祭，并在朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup>和耶和华所定的一切节期献祭，又向耶和华献上自愿献的祭。</span>
<span className="v" id="v6" data-v="6"> 虽然耶和华殿的根基还没有立好，但他们从七月一日起就开始向耶和华献燔祭。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 5:6; 使徒行传 9:36; 使徒行传 12:20"> 他们付给石匠和木匠银子，并经波斯王塞鲁士批准，供给泰尔人和西顿人食物、酒和油，换取他们把香柏木从黎巴嫩经海路运到约帕。</span>
</div>
</div>

## 开始重建圣殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:3; 历代志上 23:4; 历代志上 23:24–32"> 在回到耶路撒冷上帝殿的第二年二月，撒拉铁的儿子所罗巴伯、约萨达的儿子耶书亚及其他祭司和利未亲族，以及所有从流亡之地回到耶路撒冷的人，开始重建耶和华的殿，并派二十岁以上的利未人做督工。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 2:40; 以斯拉记 3:8; 尼希米记 7:43"> 何达威雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“何达威雅”希伯来文是“犹大”，参考2:40。">b</a></sup>的后裔，即耶书亚及其子孙和弟兄、甲篾及其子孙，与利未人希拿达的子孙及其弟兄，同心协力地监督在上帝殿里做工的人。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 25:1–7; 历代志上 15:27; 历代志上 16:37"> 工人立耶和华殿的根基时，祭司身穿礼服拿着号角，利未人亚萨的子孙拿着钹各就各位，照以色列王大卫所定的规矩赞美耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:1"> 他们彼此唱和，赞美、称谢耶和华，说：<br /><span className="pl pl-1">“祂是美善的，</span><br /><span className="pl pl-1">因为祂向以色列人永施慈爱！”</span>所有人都高声欢呼赞美耶和华，因为耶和华殿的根基已经立好。</span>
<span className="v" id="v12" data-v="12" data-xref="哈该书 2:3; 马太福音 13:31–32; 以赛亚书 60:22"> 许多曾见过旧殿的年长祭司、利未人和族长看见这殿立了根基，不禁放声大哭，也有很多人高声欢呼。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:37–40; 撒母耳记上 4:5; 尼希米记 12:43"> 人们无法分辨是痛哭声还是欢呼声，因为众人都大声呼喊，声音传到远处。</span>
</div>

## 献素祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:14–18; 利未记 9:17; 以赛亚书 66:20"> “如果有人献素祭给耶和华，要用细面粉作祭物。要在细面粉上浇油、加乳香，</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 5:12; 利未记 6:15; 使徒行传 10:4"> 带到做祭司的亚伦子孙那里。祭司要抓一把浇了油的细面粉，连同所有乳香放在坛上焚烧，作为象征。这是蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 10:12–13; 民数记 18:9; 利未记 21:22"> 剩下的素祭要归亚伦及其子孙，这在献给耶和华的火祭中是至圣之物。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:2; 哥林多前书 5:7–8; 诗篇 22:14"> “如果献用炉子烤的素祭，要献调油的无酵细面饼，或涂油的无酵薄饼。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:21; 利未记 7:9"> “如果献用平底锅烤的素祭，要献调油的无酵细面饼。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:1–19; 诗篇 22:1–21; 马可福音 14:1–15"> 要把饼掰成碎块，浇上油。这是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:1–2; 利未记 7:9"> “如果献用煎锅煎的素祭，要献用细面粉和油做的祭物。</span>
<span className="v" id="v8" data-v="8"> “要把这样做好的素祭带到耶和华面前，交给祭司献在祭坛上。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:2; 腓立比书 4:18; 利未记 6:15"> 祭司要从中取出一部分，作为象征放在祭坛上焚烧。这是蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 2:3"> 剩下的素祭要归亚伦及其子孙。这在献给耶和华的火祭中是至圣之物。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 5:9; 路加福音 12:1; 出埃及记 23:18"> “献给耶和华的任何素祭都不可含酵，因为你们不可把酵或蜜当作火祭献给耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:19; 创世记 23:10–11; 出埃及记 22:29"> 你们可以把酵和蜜作为初熟之祭献给耶和华，但不可作为馨香之祭献在祭坛上。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 43:24; 马太福音 5:13; 歌罗西书 4:6"> 所有素祭都要用盐调味，不可少了你们与上帝立约的盐。所有祭物中都要放盐。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 23:10; 玛拉基书 1:11; 民数记 28:2"> “如果将初熟的谷物献给耶和华作素祭，要用烘好后压碎的新麦穗，</span>
<span className="v" id="v15" data-v="15"> 加上油和乳香。这是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 5:7; 罗马书 8:26–27; 以赛亚书 61:1"> 祭司要将一些压碎的麦穗、油及所有乳香作为象征焚烧。这是献给耶和华的火祭。</span>

<span className="v" id="v1" data-v="1" data-xref="利未记 5:17; 箴言 29:24; 利未记 19:8"> “如果有人当庭作证，却不肯把自己所知所见的说出来，就是犯罪，要担负罪责。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 5:17; 申命记 14:8; 哈该书 2:13"> 如果有人接触了不洁净之物，如不洁净的野兽的尸体、家畜的尸体或爬虫的尸体，即使没有察觉也已不洁净，是有罪的。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 19:11–16; 利未记 15:1–33; 利未记 12:1–8"> 如果有人无意中接触了别人的不洁之物，当他意识到后，就有罪了。</span>
<span className="v" id="v4" data-v="4" data-xref="传道书 5:2–6; 使徒行传 23:12; 士师记 11:31"> 如果有人草率起誓，不论出于善意还是恶意，即使当初没有察觉，后来才意识到，也是有罪的。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 28:13; 民数记 5:7; 利未记 26:40"> 如果有人意识到自己犯了以上任何一种罪，就必须认罪。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 4:28; 利未记 4:32; 利未记 4:20"> 为了赎过，他必须献给耶和华一只母绵羊或母山羊作赎罪祭。祭司要为他赎罪。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 12:8; 利未记 14:21–22; 马太福音 3:16"> “他若献不起羊，就要献给耶和华两只斑鸠或两只雏鸽，一只作赎罪祭，一只作燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 1:15; 利未记 1:17; 罗马书 4:25"> 他要把它们带到祭司那里，祭司要先用一只鸟献赎罪祭，要扭断鸟脖子，但不可扯掉头。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 4:30; 利未记 4:34; 利未记 4:18"> 要把一些鸟血洒在祭坛边，再把剩下的血倒在坛脚。这是赎罪祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:14–17; 利未记 4:26; 利未记 4:20"> 祭司要依照献燔祭的条例献上另一只鸟。这样，祭司为他赎了罪，他就会得到赦免。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 5:15; 利未记 2:1–2; 出埃及记 16:36"> “他若献不起两只斑鸠或雏鸽，就要献一公斤细面粉作赎罪祭。细面粉中不可浇油或加乳香，因为这是赎罪祭。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 4:35; 利未记 2:9; 利未记 2:2"> 他要把细面粉带到祭司那里，祭司要从中取出一把作为象征放在坛上，与献给耶和华的火祭一起焚烧。这是赎罪祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:3; 利未记 4:26; 哥林多前书 9:13"> 这样，祭司为他赎了罪，他就会得到赦免。剩下的细面粉要归祭司，像献素祭一样。”</span>

## 献赎过祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华对摩西说：</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 30:13; 利未记 4:2; 利未记 6:6"> “如果有人无意中干犯了耶和华圣物的条例，为了赎过，他要从羊群中选一只毫无残疾的公绵羊献给耶和华，或按圣所的秤献上同等价值的银子。这是赎过祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 22:14; 民数记 5:7; 利未记 27:27"> 他要赔偿所造成的损失，并加赔五分之一，要把这些都交给祭司。祭司要为他献上公绵羊作赎过祭，为他赎罪，他就会得到赦免。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:27; 利未记 4:13; 利未记 4:2–4"> “如果有人触犯耶和华的任何诫命，即使他不知道，也是犯罪，必须担当罪责。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 5:15–16; 提摩太前书 2:5–6; 利未记 1:4"> 他要从羊群中选一只毫无残疾的公绵羊，或把同等价值的银子带到祭司那里作赎过祭。祭司要为他的无心之过赎罪，他就会得到赦免。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 51:4; 玛拉基书 3:8; 哥林多后书 5:19–21"> 这是赎过祭，因为他在耶和华面前确实有罪。”</span>
</div>
</div>

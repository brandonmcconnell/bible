## 祭司保持圣洁的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 44:25; 利未记 21:11; 利未记 10:6–7"> 耶和华对摩西说：“你要告诉做祭司的亚伦子孙：祭司不可因接触死去的族人而使自己不洁净，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 4:13; 利未记 18:6"> 但骨肉至亲，如父母、儿女、兄弟，</span>
<span className="v" id="v3" data-v="3"> 以及未出嫁仍是处女的姊妹例外。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 24:16–17"> 祭司不可因姻亲的关系而玷污自己。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译“作为民中的首领，祭司不可玷污自己。”">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 14:1; 以西结书 44:20; 利未记 19:27–28"> 祭司不可剃光头、修剪胡须或割伤身体。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 3:11; 利未记 18:21; 彼得前书 2:9"> 他们要做上帝的圣洁之民，不可亵渎我的名。因为他们负责献我的火祭，即我的食物，所以要保持圣洁。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:13–14; 以西结书 44:22; 利未记 21:8"> 他们不可娶妓女或被休的女人为妻，因为祭司要向上帝保持圣洁。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 20:7–8; 利未记 19:2; 利未记 11:44–45"> 要视祭司为圣洁的，因为他们负责献你们上帝的食物。要视他们为圣洁的，因为使你们圣洁的我耶和华是圣洁的。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 38:24; 利未记 19:29; 以西结书 9:6"> 如果有祭司的女儿做妓女，辱没自己，她就是辱没自己的父亲，必须烧死她。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 10:6–7; 利未记 16:32; 马太福音 26:65"> “大祭司在众祭司中职分最高，头上浇过膏油，已经承受圣职、穿上圣衣，他不可披头散发、撕裂衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:14; 利未记 21:1–2; 民数记 6:7"> 他不可接近死者，即使是父母也不可，以免玷污自己。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:7; 出埃及记 29:6–7; 利未记 8:9–12"> 他不可走出他上帝的圣所，以免亵渎圣所，因为我的膏油已经使他圣洁。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 21:7; 哥林多后书 11:2; 启示录 14:4"> 他必须娶处女为妻，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 21:7; 以西结书 44:22"> 不可娶寡妇、被休的女人或被玷污的妓女，只可娶本族中的处女为妻，</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 11:16; 哥林多前书 7:14; 尼希米记 13:23–29"> 以免在民中玷污自己的子孙，因为我是使他们圣洁的耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华对摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 65:4; 民数记 16:5; 利未记 10:3"> “你告诉亚伦：你世世代代的子孙中，任何有残疾的人都不可前来向他的上帝献食物。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 3:2–3; 利未记 22:19–25; 提多书 1:7"> 任何残疾的人，如瞎眼的、瘸腿的、五官不正的、畸形的、</span>
<span className="v" id="v19" data-v="19"> 四肢伤残的、</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 23:1; 以赛亚书 56:3"> 驼背的、侏儒、患眼疾的、长疥癣的或睪丸受损的，都不可近前来献祭。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 21:6; 利未记 21:8; 利未记 21:17"> 亚伦祭司的子孙中有残疾的都不可向耶和华献火祭。他们既然有残疾，就不可近前来献耶和华的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 2:3; 民数记 18:19; 利未记 24:8–9"> 他们可以吃上帝的食物，圣的和至圣的都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:12; 以西结书 44:9–14; 出埃及记 30:6–8"> 但他们不可走近幔子或祭坛，因为他们有残疾。这样做是为了避免他们亵渎我的圣所。我是使圣所圣洁的耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 1:18; 玛拉基书 2:1–7; 提摩太后书 2:2"> 摩西把这些条例告诉了亚伦父子们和所有的以色列人。</span>
</div>
</div>

<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:9; 使徒行传 5:4; 利未记 5:15"> “如果有人拒绝归还同胞委托他保管的物品或抵押品，或抢掠同胞，或欺骗同胞，或捡到失物却矢口否认，或起假誓，或犯其他类似的罪，因而失信于耶和华，</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:18; 阿摩司书 3:10; 利未记 5:3–4"> 一旦他意识到自己犯了罪，必须归还一切靠偷盗、欺诈、侵占、拾遗、</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 5:16; 路加福音 19:8; 民数记 5:7–8"> 或起假誓得来的东西，他必须在献赎过祭那天如数归还物主，并加赔五分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:15; 利未记 5:18; 以赛亚书 53:10–11"> 他要从羊群中选一只毫无残疾的公绵羊，或把同等价值的银子带到祭司那里，献给耶和华作赎过祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 4:26; 约翰一书 1:9; 约翰一书 2:1–2"> 祭司要在耶和华面前为他赎罪，他的过犯就会得到赦免。”</span>
</div>
</div>

## 祭司献燔祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华对摩西说：</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 6:12–13; 民数记 28:3; 出埃及记 29:38–42"> “你要吩咐亚伦及其子孙遵行以下献燔祭的条例。<br />“燔祭要整夜留在祭坛上，坛上的火要不停地燃烧。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:39–43; 利未记 16:4; 利未记 1:13"> 早晨，祭司要穿上细麻衣袍和内衣，将燔祭坛上的灰烬清理好，放在祭坛旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 4:12; 以西结书 44:19; 希伯来书 13:11–13"> 然后，他要更换衣服，把灰烬拿到营外洁净的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 9:24; 出埃及记 29:38–42; 尼希米记 13:31"> 祭坛上的火要不断燃烧，不能熄灭。祭司每天早上要在坛上加柴，摆上燔祭，在上面烧平安祭牲的脂肪。</span>
<span className="v" id="v13" data-v="13"> 坛上的火必须不断燃烧，不可熄灭。</span>
</div>
</div>

## 祭司献素祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 15:4; 利未记 2:1–2; 约翰福音 6:32"> “以下是献素祭的条例。<br />“亚伦的子孙要在祭坛前向耶和华献素祭。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:2; 利未记 2:9"> 祭司要从素祭中拿一把调油的细面粉和所有的乳香，作为象征放在坛上焚烧，作蒙耶和华悦纳的馨香之祭。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 44:29; 利未记 2:3; 利未记 10:12–13"> 亚伦及其子孙要吃剩下的祭物，要在会幕院子里的圣洁之处做无酵饼吃。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:3; 利未记 2:11; 民数记 18:9–10"> 做饼时不可加酵。这些祭物是我从献给我的火祭中赐给他们的，像赎罪祭和赎过祭一样是至圣之物。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 6:29; 民数记 18:10; 哈该书 2:12–14"> 亚伦的子孙中，男子都可以吃耶和华的火祭。这是他们世世代代应得之份。凡接触到这些祭物的都会变得圣洁。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华对摩西说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:2; 出埃及记 16:36; 利未记 2:1–16"> “亚伦及其子孙受膏那天，要献给耶和华一公斤细面粉作为日常献的素祭，早晚各献一半。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 2:5; 利未记 7:9; 历代志上 9:31"> 要把这些细面粉调上油，用煎锅做饼，切成块献上，作为蒙耶和华悦纳的馨香素祭。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:22–25; 以赛亚书 53:10; 利未记 8:21"> 亚伦子孙中继任大祭司的，受膏时要献上素祭。这种祭物必须全部烧掉献给耶和华，这是永远的律例。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 2:10; 利未记 6:16–17"> 祭司献的这种素祭不可吃，要全部烧掉。”</span>
</div>
</div>

## 祭司献赎罪祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24"> 耶和华对摩西说：</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:24; 利未记 1:11; 利未记 1:3"> “你把以下赎罪祭的条例告诉亚伦及其子孙。<br />“赎罪祭是至圣的，要在杀燔祭牲的地方，在耶和华面前宰祭牲。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:17–18; 以西结书 44:28–29; 何西阿书 4:8"> 献赎罪祭的祭司要在会幕院子里的圣洁之处吃这祭牲。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 29:37; 哈该书 2:12; 哥林多后书 7:1"> 凡接触到这些祭肉的，都会变得圣洁。如果衣服被溅上血，则要在圣洁之处把衣服洗净。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:33; 利未记 15:12; 希伯来书 9:9–10"> 用来煮祭肉的瓦锅，用后都要打碎。如果用的是铜锅，要擦干净并用水冲洗。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 6:25; 利未记 6:17–18; 民数记 18:10"> 这些祭肉是至圣之物，祭司家族中的男子都可以吃。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 10:18; 利未记 16:27–28; 希伯来书 13:11"> 如果赎罪祭牲的血被带进会幕，在圣所内进行赎罪，就不可吃祭肉，必须全部烧掉。</span>
</div>
</div>

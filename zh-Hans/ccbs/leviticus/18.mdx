## 禁止淫乱的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:7; 利未记 11:44; 以西结书 20:5"> “你要告诉以色列人：我是你们的上帝耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 20:23; 出埃及记 23:24; 彼得前书 4:2–4"> 你们曾经住在埃及，但不可效法埃及人的行为。我要把你们带到迦南，但你们不可效法迦南人的行为，不可随从他们的风俗。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 18:2; 利未记 18:26; 以西结书 20:19"> 你们必须遵行我的典章，持守我的律例。我是你们的上帝耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 10:5; 以西结书 20:11; 加拉太书 3:12"> 你们要遵守我的典章和律例，遵行的人必因此而活。我是耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 20:17–21; 利未记 18:7–19; 利未记 20:11–12"> “你们任何人不可与近亲乱伦。我是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 20:11; 以西结书 22:10; 利未记 18:8–16"> 不可与你母亲乱伦而羞辱你父亲。她是你的母亲，不可与她乱伦。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 20:11; 哥林多前书 5:1; 申命记 27:20"> 不可与你父亲的妻妾乱伦，那会羞辱你的父亲。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 20:17; 申命记 27:22; 以西结书 22:11"> 不可与你的姊妹乱伦。不论是同父异母的，还是同母异父的，生长在同一家庭的，还是不同家庭的，都不可与她乱伦。</span>
<span className="v" id="v10" data-v="10"> 不可与孙女或外孙女乱伦，那会自取羞辱。</span>
<span className="v" id="v11" data-v="11"> 不可与你父亲妻妾的女儿乱伦。她是你的姊妹，不可与她乱伦。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 20:19; 出埃及记 6:20"> 不可与姑母乱伦，她是你父亲的至亲。</span>
<span className="v" id="v13" data-v="13"> 不可与姨母乱伦，她是你母亲的至亲。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:20"> 不可与伯母或婶母乱伦而羞辱你伯父或叔父，她是你的伯母或婶母。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 20:12; 创世记 38:26; 以西结书 22:11"> 不可与儿媳乱伦。她是你儿子的妻子，不可与她乱伦。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 25:5; 利未记 20:21; 马太福音 22:24"> 不可与兄嫂或弟媳乱伦，她是你兄弟的妻子，那会羞辱你的兄弟。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 20:14; 阿摩司书 2:7; 申命记 27:23"> “不可与一个女人性交，又与她女儿性交，也不可与她孙女或外孙女性交。她们是她的近亲。这都是邪恶行为。</span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 2:15; 创世记 30:15; 创世记 29:28"> 妻子还在世时，不可娶她姊妹并与她性交，使她们彼此作对。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 20:18; 利未记 15:24; 以西结书 22:10"> 女人在月经期间不洁净，不可与她性交。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:14; 哥林多前书 6:9; 希伯来书 13:4"> 不可与邻居的妻子性交，那会玷污自己。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 12:31; 利未记 20:2–5; 申命记 18:10"> 不可把儿女当作祭物献给假神摩洛，不可亵渎你上帝的名。我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 20:13; 罗马书 1:26–27; 哥林多前书 6:9"> 男人不可与男人同寝，像和女人同寝一样，这是可憎的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 22:19; 利未记 20:15–16; 利未记 20:12"> 不可与兽类交合，玷污自己。女人也不可与兽类交合。这是变态行为。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 18:12; 利未记 18:30; 利未记 20:22–23"> “你们不可做这些事玷污自己，因为我要在你们面前赶走的各国，正是因为这些行为而玷污了自己。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 18:28; 利未记 20:22–23; 耶利米书 2:7"> 他们居住的土地也都被玷污了，所以我因他们的罪恶而惩罚那片土地，我要使那片土地吐出其中的居民。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 18:5; 利未记 17:10; 利未记 18:30"> 你们必须遵守我的律例和典章。不论你们还是寄居在你们中间的外族人，都不可做这些可憎之事。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 36:14; 利未记 18:24; 申命记 23:18"> 因为在你们之前居住在那里的人做了这些可憎之事，玷污了那片土地。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 3:16; 利未记 20:22; 利未记 18:25"> 如果你们玷污了那片土地，它也会像吐出从前的居民一样把你们吐出去。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:6; 出埃及记 12:15; 利未记 17:10"> 凡做这些可憎之事的，要将他从民中铲除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:23; 申命记 18:9–12; 利未记 22:9"> 你们要遵守我的命令，不要效法那片土地上居民的恶俗，以致玷污自己。我是你们的上帝耶和华。”</span>
</div>

## 献赎罪祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 19:12; 希伯来书 9:7; 利未记 4:27"> “你把以下条例告诉以色列人。<br />“如果有人无意中犯罪，触犯耶和华的任何诫命，要按以下方式献赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:27–28; 利未记 4:14; 利未记 9:2"> “若大祭司犯罪，祸及众民，他必须献给耶和华一头毫无残疾的公牛犊作赎罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 1:3–4; 但以理书 9:26; 以赛亚书 53:6"> 他要把公牛犊牵到会幕门口，将手放在牛头上，在耶和华面前宰牛。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:14; 民数记 19:4; 利未记 4:16–17"> 他要取一些公牛的血带进会幕里，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 16:14; 利未记 14:18; 利未记 26:28"> 在耶和华面前用手指蘸血向圣所的幔子弹洒七次，</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 8:15; 利未记 9:9; 利未记 16:18"> 也要把一些公牛的血抹在耶和华面前的香坛凸起的四角上，再把剩下的血倒在会幕门口的燔祭坛脚。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:3–5; 利未记 4:26; 利未记 4:31"> 他要取出作赎罪祭的公牛犊的所有脂肪，即包裹内脏的脂肪和内脏上的脂肪、</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 3:4"> 两个肾脏和肾脏上靠近腰部的脂肪以及肝叶，</span>
<span className="v" id="v10" data-v="10"> 正如取出平安祭牲的脂肪一样。他要将这一切放在燔祭坛上焚烧。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:5; 出埃及记 29:14; 利未记 9:8–11"> 至于公牛剩下的部分，即皮、所有的肉、头、腿、内脏和粪便，他要带到营外洁净之处，就是倒坛灰的地方，放在柴上焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 5:17; 利未记 5:2–5; 何西阿书 5:15"> “以色列全体会众若无意中触犯耶和华的任何诫命，即使没有意识到，也是犯罪。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:28"> 他们察觉自己犯罪后，必须献上一头公牛犊作赎罪祭。要将公牛犊带到会幕前，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 16:21; 利未记 8:14"> 会众的长老要把手放在公牛的头上，在耶和华面前宰牛。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:5–12; 希伯来书 9:12–14"> 大祭司要带一些牛血进入会幕，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:6–7"> 在耶和华面前用手指蘸血向幔子弹洒七次，</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7"> 也要把一些血抹在耶和华面前的香坛凸起的四角上，再把剩下的血倒在会幕门前的燔祭坛脚。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 5:6; 利未记 4:26; 民数记 15:25"> 他要取出公牛犊的所有脂肪，放在祭坛上焚烧，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 15:25; 希伯来书 10:10–12; 利未记 12:8"> 正如取出赎罪祭牲的脂肪一样。这样，祭司为全体会众赎了罪，他们就会得到赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 16:15; 马太福音 20:28; 哥林多后书 5:21"> 他要把这公牛犊剩下的部分拿到营外焚烧，像焚烧前一头公牛犊一样。这是为全体会众所献的赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:13; 民数记 31:13"> “首领若无意中触犯他上帝耶和华的任何诫命，也是犯罪。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:14; 罗马书 8:3; 民数记 7:22"> 他察觉自己犯罪后，必须献上一只毫无残疾的公山羊作祭物。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 3:13; 利未记 7:2; 利未记 4:3–35"> 他要把手放在羊头上，在杀燔祭牲的地方，在耶和华面前宰羊。这是他的赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:7; 利未记 4:18; 利未记 4:30"> 祭司要用手指蘸一些赎罪祭牲的血抹在燔祭坛凸起的四角上，再把剩下的血倒在燔祭坛脚。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 4:20; 利未记 4:31; 利未记 4:35"> 要像焚烧平安祭牲的脂肪一样，把羊的所有脂肪都放在坛上焚烧。这样，祭司为他赎了罪，他就会得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 4:2; 民数记 15:27; 利未记 4:13"> “平民若无意中触犯耶和华的任何诫命，也是犯罪。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:32"> 他察觉自己犯罪后，必须献上一只毫无残疾的母山羊作赎罪祭。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 4:4; 利未记 4:24; 利未记 1:4"> 他要把手放在赎罪祭牲的头上，在杀燔祭牲的地方宰羊。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 4:7; 利未记 4:25; 利未记 4:34"> 祭司要用手指蘸一些羊血抹在燔祭坛凸起的四角上，再把剩下的血倒在燔祭坛脚。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 4:26; 利未记 4:35; 利未记 1:9"> 献祭者要像取出平安祭牲的脂肪一样，取出母山羊的所有脂肪。祭司要把这一切放在坛上焚烧，作为蒙耶和华悦纳的馨香之祭。这样，祭司为他赎了罪，他就会得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 4:28; 彼得前书 3:18; 彼得前书 2:22"> “他若献绵羊作赎罪祭，必须献一只毫无残疾的母绵羊。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 4:29–31; 利未记 4:4"> 他要把手放在羊头上，在杀燔祭牲的地方宰羊。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 4:30; 利未记 4:25; 利未记 4:7"> 祭司要用手指蘸一些羊血抹在燔祭坛凸起的四角上，再把剩下的血倒在燔祭坛脚。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 4:26; 利未记 4:20; 利未记 14:18"> 献祭者要像取出平安祭牲的脂肪一样，取出母绵羊的所有脂肪。祭司要把这一切放在坛上，与献给耶和华的祭物一起焚烧。这样，祭司为他赎了罪，他就会得到赦免。</span>
</div>

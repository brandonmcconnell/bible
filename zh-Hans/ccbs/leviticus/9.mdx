## 亚伦献祭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 28:1; 以西结书 43:26–27; 利未记 15:14"> 到了第八天，摩西召来亚伦父子们和以色列的众长老。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 4:3; 希伯来书 10:10–14; 利未记 8:14"> 他对亚伦说：“你要在耶和华面前献上一头公牛犊作赎罪祭、一只公绵羊作燔祭，这些祭牲都要毫无残疾。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 6:17; 启示录 5:9; 提多书 2:14"> 然后，你要告诉以色列人，‘你们要取一只公山羊作赎罪祭、毫无残疾的一头一岁牛犊和一只一岁羊羔作燔祭、</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:43; 以西结书 43:2; 利未记 9:23"> 一头公牛和一只公绵羊作平安祭，连同调油的素祭一起献给耶和华，因为今天耶和华要向你们显现。’”</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2–3; 出埃及记 19:17; 尼希米记 8:1"> 于是，以色列人遵照摩西的吩咐，把祭物带到会幕前。全体会众都聚集到那里，站在耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 9:23; 以西结书 43:2; 出埃及记 24:16"> 摩西对他们说：“耶和华吩咐你们这样做，是为了向你们显出祂的荣耀。”</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 5:3; 希伯来书 5:1; 利未记 4:3"> 随后，摩西对亚伦说：“你要到坛前来，献上你的赎罪祭和燔祭，为自己和民众赎罪。也要按照耶和华的吩咐，为百姓献上他们的祭物，为他们赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 4:1–12; 利未记 1:4–5; 利未记 4:29"> 于是，亚伦走到坛前，宰杀为他作赎罪祭的牛犊。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 4:6–7; 利未记 8:15; 利未记 4:25"> 他儿子们把牛犊的血递给他，他用手指蘸血抹在祭坛凸起的四角上，再把剩下的血倒在坛脚。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 8:16–17; 箴言 23:26; 利未记 3:9–11"> 他照耶和华对摩西的吩咐，在坛上焚烧赎罪祭牲的脂肪、肾脏和肝叶，</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 8:17; 利未记 4:11–12; 利未记 16:27–28"> 把皮和肉带到营外焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:2; 以弗所书 5:25–27; 利未记 1:1–17"> 亚伦宰了燔祭祭牲，他儿子们把祭牲的血递给他，他把血洒在祭坛四周。</span>
<span className="v" id="v13" data-v="13"> 他们将祭牲一块一块地连头一起交给亚伦献在坛上焚烧。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 8:21"> 亚伦洗净祭牲的内脏和腿，放在祭坛的燔祭上焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 4:27–31; 希伯来书 5:3; 利未记 9:3"> 随后，亚伦为民众献祭。他牵来那只为民众作赎罪祭的公山羊，宰杀后，像刚才为自己献赎罪祭一样为他们献上赎罪祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 9:12–14; 利未记 8:18–21; 希伯来书 10:1–22"> 他又牵来燔祭祭牲，依照条例献上燔祭。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:1–2; 约翰福音 6:53; 利未记 9:1"> 除了早晨的燔祭，亚伦又取来素祭，从中拿了一把献在坛上焚烧。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20; 罗马书 5:1; 以弗所书 2:14–17"> 然后，他宰了公牛和公绵羊，为民众献平安祭。他儿子们把祭牲的血递给他，他把血洒在祭坛四周。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 3:16; 利未记 9:10; 利未记 3:9"> 他们把公牛和公绵羊的脂肪、肥尾巴、包裹内脏的脂肪、肾脏和肝叶，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 3:14–17; 利未记 7:29–34"> 放在祭牲的胸脯上，然后亚伦把那些脂肪放在坛上焚烧，</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 7:30–34; 利未记 7:24; 出埃及记 29:24"> 将胸肉和右腿肉作为摇祭在耶和华面前摇一摇，都遵照摩西的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 21:5; 路加福音 24:50; 民数记 6:23–27"> 亚伦举手为民众祝福，他献完赎罪祭、燔祭和平安祭后走下祭坛。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 9:6; 民数记 16:19; 路加福音 1:21–22"> 之后，摩西和亚伦走进会幕，又出来为民众祝福。这时，耶和华的荣耀向所有民众显现。</span>
<span className="v" id="v24" data-v="24" data-xref="士师记 6:21; 列王纪上 18:38–39; 历代志上 21:26"> 有火从耶和华那里降下来，烧尽祭坛上的燔祭和脂肪。民众看见这景象，都欢呼起来，俯伏在地。</span>
</div>
</div>

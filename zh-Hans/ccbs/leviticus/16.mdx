## 赎罪日的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–2"> 亚伦的两个儿子死在耶和华面前以后，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:10; 列王纪上 8:10–12; 希伯来书 10:19–20"> 耶和华对摩西说：“告诉你哥哥亚伦，他不可随意进入幔子里面的至圣所，到约柜上的施恩座前，免得死亡，因为我要在施恩座之上的云彩中显现。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 4:3; 希伯来书 9:24–25; 希伯来书 9:7"> 亚伦进入圣所时，要带一头作赎罪祭的公牛犊和一只作燔祭的公绵羊。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:39–43; 以西结书 44:17–18; 出埃及记 30:20"> 他要穿上圣洁的细麻内袍和细麻裤子，束上细麻腰带，戴上细麻礼冠。这些是圣洁的衣物，他必须沐浴后才可穿戴。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:21; 利未记 8:2; 以斯拉记 6:17"> 他要从以色列会众那里取两只公山羊作赎罪祭，一只公绵羊作燔祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 9:7; 希伯来书 9:7; 希伯来书 7:27"> 亚伦要先献上那头公牛犊作赎罪祭，为自己和全家赎罪。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:1; 利未记 4:4; 马太福音 16:21"> 然后，他要把两只公山羊带到会幕门口，放在耶和华面前。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:23–26; 约拿书 1:7; 箴言 16:33"> 他要为这两只羊抽签，决定哪只归耶和华，哪只归阿撒泻勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“阿撒泻勒”是希伯来文的音译，意义不确定。">a</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:27–28; 使徒行传 2:23"> 亚伦要献上那只归耶和华的公山羊作赎罪祭，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:2; 利未记 16:21–22; 希伯来书 9:23–24"> 要将那只归阿撒泻勒的公山羊活着献给耶和华，用来赎罪，然后把它放到旷野归阿撒泻勒。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 16:6; 希伯来书 7:27; 希伯来书 9:7"> “亚伦要把那头为他作赎罪祭的公牛犊牵来宰杀，为自己和全家赎罪，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:1; 出埃及记 30:34–38; 启示录 8:3–4"> 然后拿一个香炉，盛满从耶和华面前的祭坛上取的火炭，再拿两把磨细的香带进幔子里。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:21; 出埃及记 30:1; 出埃及记 30:7–8"> 他要在耶和华面前烧香，使香的烟笼罩约柜上的施恩座，免得他死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 9:25; 利未记 4:5–6; 希伯来书 9:13"> 他要取一些公牛的血，用手指弹洒在施恩座的东面，并在施恩座前用手指弹洒七次。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:7; 希伯来书 2:17; 希伯来书 9:3"> 然后，亚伦要出去宰杀那只为民众作赎罪祭的公山羊，把羊血带进幔子里，像洒公牛的血一样洒在施恩座的上面和前面。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 9:22–23; 利未记 16:18; 以西结书 45:18–19"> 因以色列人的污秽、叛逆和罪恶，他要这样为至圣所赎罪。他也要同样为会幕赎罪，因为会幕坐落在以色列人中间，处在他们的污秽中。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:6; 路加福音 1:10; 出埃及记 34:3"> 从他进入圣所为自己、家人和以色列全体会众赎罪开始，直到他赎完罪出来为止，任何人都不可待在会幕里。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7; 希伯来书 5:7–8; 利未记 16:16"> 之后，他要来到耶和华面前的祭坛那里，为祭坛赎罪。他要取一些牛血和羊血，抹在祭坛凸起的四角上，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:1; 以西结书 43:18–22"> 然后用手指向祭坛洒血七次，除掉以色列人的污秽，使祭坛圣洁。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 16:16; 以西结书 45:20; 歌罗西书 1:20"> “他为至圣所、会幕和祭坛赎罪后，要牵来那只活山羊，</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 53:6; 哥林多后书 5:21; 以斯拉记 10:1"> 把双手放在羊头上，承认以色列人的所有过犯、叛逆和罪恶，将这一切罪归到公山羊的头上，然后派人把它送到旷野。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:28; 以赛亚书 53:11–12; 约翰福音 1:29"> 这只羊要把他们一切的罪过带到偏远的地方，那人要把羊留在旷野。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 44:19; 以西结书 42:14; 利未记 16:4"> “亚伦要走进会幕，脱下他进至圣所时穿的细麻衣服，放在会幕里。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 16:3–5; 希伯来书 10:19–22; 出埃及记 28:4–14"> 他要在圣洁之处沐浴，穿上平时的衣服出去为自己和民众献燔祭，为自己和民众赎罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:13; 利未记 4:8–10; 利未记 16:6"> 他要将赎罪祭牲的脂肪焚烧在祭坛上。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 16:10; 希伯来书 7:19; 民数记 19:21"> 把羊送交阿撒泻勒的人要洗衣、沐浴，然后才可回到营里。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 4:21; 利未记 6:30; 利未记 4:11–12"> 作赎罪祭的公牛和公山羊的血被带进圣所用来赎罪后，要把公牛和公山羊带到营外，用火焚烧它们的皮、肉和粪。</span>
<span className="v" id="v28" data-v="28"> 负责焚烧的人要洗衣、沐浴，然后才可回到营里。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 58:3; 民数记 29:7; 出埃及记 20:10"> “每年七月十日，不论是你们，还是寄居在你们中间的外族人，都要禁食，停止所有工作。这是你们永远当守的律例。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 33:8; 诗篇 51:2; 以弗所书 5:26"> 因为在这一天要为你们赎罪，使你们在耶和华面前洁净，脱离一切的罪。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 23:32; 以赛亚书 58:5; 利未记 25:4"> 这天是你们完全休息的安息日，你们要禁食。这是一条永远不变的律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:4; 出埃及记 29:29–30; 利未记 4:5"> 那受膏、接替父亲担任圣职的大祭司要行赎罪礼。他要穿上圣洁的细麻衣，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 16:16; 利未记 16:24; 利未记 16:6"> 为至圣所、会幕和祭坛赎罪，也要为祭司和全体会众赎罪。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 9:7; 希伯来书 9:25; 出埃及记 30:10"> 这是你们当守的永久律例：每年一次为以色列人赎罪。” 于是，摩西遵行了耶和华的吩咐。</span>

## 献平安祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 6:14; 利未记 1:3; 罗马书 5:1–2"> “如果有人用牛献作平安祭，必须在耶和华面前献上毫无残疾的公牛或母牛。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 29:10; 利未记 1:4–5; 使徒行传 2:36–38"> 献祭者要把手放在祭牲的头上，在会幕门口宰杀。做祭司的亚伦子孙要把牛血洒在祭坛四周。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 4:8–9; 出埃及记 29:22"> 献祭者要从平安祭中献上火祭给耶和华。他要取出包裹内脏的脂肪和内脏上的脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:10; 利未记 8:25; 出埃及记 29:22"> 两个肾脏和肾脏上靠近腰部的脂肪以及肝叶。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:12; 出埃及记 29:13; 彼得前书 2:5"> 亚伦的子孙要把这一切放在祭坛燃烧的木柴上和燔祭一起焚烧，作为蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:11–12; 加拉太书 3:28; 利未记 1:2"> “如果用羊作祭物向耶和华献平安祭，必须献毫无残疾的公羊或母羊。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 8:62; 以弗所书 5:12; 利未记 17:8–9"> 如果献的是绵羊羔，献祭者要把羊羔带到耶和华面前，</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 1:5; 以弗所书 3:12; 利未记 3:13"> 将手放在祭牲的头上，在会幕前宰杀。亚伦的子孙要把羊羔的血洒在祭坛四周。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 29:22; 利未记 9:19; 利未记 8:25"> 献祭者要从平安祭中取出脂肪作为火祭献给耶和华。他要从靠近脊椎骨处取下整条肥尾巴、包裹内脏的脂肪、内脏上的脂肪、</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 3:4"> 两个肾脏和肾脏上靠近腰部的脂肪以及肝叶。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 21:17; 利未记 21:6; 利未记 3:16"> 祭司要把这一切放在祭坛上焚烧，作为献给耶和华的火祭。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 9:15; 以赛亚书 53:2; 哥林多后书 5:21"> “如果献的是山羊，献祭者要把山羊带到耶和华面前，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:8; 罗马书 5:15–21; 哥林多后书 5:21"> 将手放在羊头上，在会幕门口宰杀。亚伦的子孙要把羊血洒在祭坛四周。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:38; 马太福音 22:37; 利未记 3:9–11"> 献祭者要取出包裹内脏的脂肪和内脏上的脂肪、两个肾脏和肾脏上靠近腰部的脂肪以及肝叶，作为火祭献给耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 马太福音 22:37; 以赛亚书 53:10"> 祭司要把这一切放在祭坛上焚烧，作为蒙耶和华悦纳的馨香火祭。所有的脂肪都属于耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 9:4; 马太福音 26:28; 申命记 15:23"> 你们无论住在哪里，都不可吃脂肪和血，这是你们世代当守的永久律例。”</span>

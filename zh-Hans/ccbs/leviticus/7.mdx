## 祭司献赎过祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:17; 利未记 5:14–7; 利未记 6:25"> “以下是献赎过祭的条例。 “赎过祭是至圣的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 1:5; 利未记 6:25; 利未记 1:11"> 要在杀燔祭牲的地方宰赎过祭祭牲，祭牲的血要洒在祭坛周围。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 3:15–16; 诗篇 51:6"> 要献上祭牲的所有脂肪，包括肥尾巴、包裹内脏的脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:4"> 两个肾脏和肾脏上靠近腰部的脂肪以及肝叶。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 1:13; 加拉太书 5:24; 彼得前书 4:1–2"> 祭司要在坛上焚烧这一切，作为献给耶和华的火祭。这是赎过祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 6:29; 民数记 18:9–10; 利未记 2:3"> 祭司家的任何男子都可以吃剩下的祭肉，但要在圣洁之处吃，因为这是至圣之物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 6:25–26; 利未记 14:13; 哥林多前书 9:13"> 祭物要归主持祭礼的祭司，这一条例也适用于赎罪祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 4:11; 出埃及记 29:14; 罗马书 13:14"> 燔祭牲的皮要归主持祭礼的祭司。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:9; 以西结书 44:29; 利未记 2:10"> 至于素祭，不论是用炉烤的，还是用平底锅或煎锅做的，都要归主持祭礼的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 8:14; 出埃及记 16:18"> 但调油的或干的素祭要归亚伦的子孙，由他们均分。</span>
</div>
</div>

## 献平安祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 22:18–21; 以西结书 45:15; 利未记 3:1–17"> “以下是向耶和华献平安祭的条例。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 2:4; 民数记 6:15; 彼得前书 2:5"> “有人若为感谢耶和华而献平安祭，除了献祭牲以外，要一同献上调油的无酵饼、涂油的无酵薄饼及调油的细面饼，</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 4:5; 利未记 23:17; 马太福音 13:33"> 也要一同献上有酵饼。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:19; 出埃及记 29:27–28; 民数记 18:24–32"> 他要从每种饼中各取一个，作为举祭献给耶和华。举祭归洒平安祭祭牲血的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 22:29–30"> 至于为感恩而献的平安祭祭肉，要在献祭的当天吃完，不可留到次日早晨。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 19:5–8; 申命记 12:6; 诗篇 116:14"> 如果是自愿献的或为了还愿而献的祭物，要在献祭当天吃祭肉，剩下的可以留到第二天吃。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:10; 何西阿书 6:2; 哥林多前书 15:4"> 但到第三天，必须烧掉剩下的祭肉。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 19:7–8; 利未记 11:41; 民数记 18:27"> 如果第三天仍然吃祭肉，所献的祭便不蒙悦纳，毫无价值，是不洁净的。吃的人要自担罪责。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多书 1:15; 使徒行传 10:15–16"> “祭肉如果接触到任何不洁之物，都不可吃，要烧掉。洁净的人都可以吃祭肉。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 15:2–33; 创世记 17:14; 利未记 22:3–7"> 如果有人不洁净，却吃献给耶和华的平安祭祭肉，要将他从民中铲除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 12:1–59; 利未记 11:20; 以西结书 4:14"> 如果有人接触到人或兽的不洁之物，或任何不洁的可憎之物，又吃献给耶和华的平安祭祭肉，要将他从民中铲除。”</span>
<span className="v" id="v22" data-v="22"> 耶和华对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 3:16–17; 利未记 17:6; 撒母耳记上 2:15–17"> “你把以下条例告诉以色列人。 “你们不可吃牛、绵羊或山羊的脂肪。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 22:31; 利未记 17:15; 利未记 22:8"> 自然死亡或被野兽咬死的动物的脂肪也不可吃，但可以作其他用途。</span>
<span className="v" id="v25" data-v="25"> 无论谁吃了献给耶和华的火祭祭牲的脂肪，都要将他从民中铲除。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 9:4; 利未记 3:17; 使徒行传 15:20"> 你们无论住在哪里，都不可吃鸟和兽的血。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 10:29; 利未记 7:20–21; 利未记 7:25"> 凡吃血的，要将他从民中铲除。”</span>
<span className="v" id="v28" data-v="28"> 耶和华对摩西说：</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 1:20; 约翰一书 1:7; 利未记 3:1–17"> “你把以下条例告诉以色列人。 “凡向耶和华献平安祭的，都要从平安祭中取出一份献给耶和华作礼物。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 6:20; 利未记 3:9; 利未记 3:14"> 他要亲手将这献给耶和华的火祭带来，将祭牲的脂肪和胸肉带来，在耶和华面前将胸肉摇一摇，当作摇祭献上。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 3:5; 利未记 3:11; 利未记 3:16"> 祭司要把脂肪放在坛上焚烧，胸肉归亚伦及其子孙。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 6:20; 利未记 7:34; 利未记 9:21"> 你们要把平安祭牲的右腿献为举祭，归给祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 26:1–46; 利未记 6:1–30; 利未记 7:3"> 要把右腿归给亚伦子孙中献平安祭的血和脂肪的那位祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 18:18–19; 利未记 10:14–15; 出埃及记 29:9"> 因为耶和华已经从以色列人献的平安祭中，把作摇祭的胸肉和作举祭的腿肉赐给祭司亚伦及其子孙，这是他们在以色列人中永远当得的份。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:20; 约翰一书 2:27; 民数记 18:7–19"> 从亚伦及其子孙受膏为祭司事奉耶和华开始，在献给耶和华的火祭中，这是他们应得之份。</span>
<span className="v" id="v36" data-v="36" data-xref="利未记 8:12; 利未记 8:30; 出埃及记 40:13–15"> 祭司受膏之日，耶和华就命令以色列人把这部分祭肉分给他们，这是他们世世代代应得之份。”</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:1; 利未记 1:1–6; 利未记 6:9–18"> 以上是献燔祭、素祭、赎罪祭、赎过祭、平安祭和授圣职时所献之祭的条例。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 1:1–2"> 这些条例是耶和华在西奈山上吩咐摩西的。当天，摩西命令以色列人在西奈旷野向耶和华献祭。</span>
</div>

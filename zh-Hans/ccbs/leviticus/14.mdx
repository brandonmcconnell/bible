## 麻风病患者的洁净条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 马可福音 1:40–44"> “以下是有关麻风病患者的洁净条例。<br />“麻风病患者痊愈后，要被带到祭司那里。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要到营外去检查，如果发现他的病已痊愈，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 19:6; 利未记 14:6; 希伯来书 9:19"> 要吩咐人为他拿来两只洁净的活鸟、香柏木、朱红色线和牛膝草。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 14:50; 希伯来书 2:14; 哥林多后书 5:1"> 祭司要吩咐人在一个盛清水的陶器上宰杀一只鸟，</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:5; 撒迦利亚书 13:1; 腓立比书 2:9–11"> 然后祭司要把另一只鸟，连同香柏木、朱红色线和牛膝草一起蘸在掺了清水的鸟血里。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 以西结书 36:25; 以赛亚书 52:15"> 祭司要用鸟血在他身上洒七次，宣布他是洁净的，然后放走那只活鸟，让它飞向田野。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:25; 民数记 8:7; 彼得前书 3:21"> 他要洗净衣服，剃去所有毛发，沐浴之后便洁净了，可以回到营内，但要住在自己的帐篷外七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 6:9; 利未记 14:8; 民数记 8:7"> 第七天，他要再次剃掉头发、胡须和眉毛等各处毛发，并洗衣、沐浴，之后便洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 2:1; 马太福音 8:4; 路加福音 5:14"> “第八天，他要带来两只毫无残疾的公羊羔、一只毫无残疾的一岁母羊羔、三公斤作素祭的调油的细面粉和一杯油。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:26–27; 出埃及记 29:1–4; 民数记 8:21"> 主持洁净礼的祭司要把他及其祭物带到会幕门口、耶和华面前，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 29:24; 利未记 6:6–7; 利未记 8:27–29"> 并献上一只公羊羔和一杯油作赎过祭，作为摇祭在耶和华面前摇一摇。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:11; 利未记 1:11; 利未记 4:24"> 他要在杀赎罪祭牲和燔祭牲的圣洁之处宰公羊羔。赎过祭的祭物要归祭司，像赎罪祭一样，这是至圣之物。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:20; 利未记 8:23–24; 哥林多后书 7:1"> 祭司要拿一些赎过祭祭牲的血抹在求洁净者的右耳垂、右手大拇指和右脚大脚趾上。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 45:7; 约翰福音 3:34; 约翰一书 2:20"> 祭司要拿那杯油，倒一些在自己左手掌中，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:17; 哥林多前书 10:31; 利未记 4:6"> 用右手手指蘸左手掌里的油，在耶和华面前弹洒七次，</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 1:2; 以西结书 36:27; 利未记 14:14"> 然后用手掌中剩下的油抹求洁净者的右耳垂、右手大拇指和右脚大脚趾，就是抹了赎过祭祭牲血的地方。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:26; 哥林多后书 1:21–22; 以弗所书 1:17–18"> 祭司要把手掌里剩下的油抹在求洁净者的头上。这样，祭司在耶和华面前为他赎了罪。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 14:12; 利未记 5:1; 利未记 12:6–8"> 祭司要献上赎罪祭，为求洁净者赎罪。然后，祭司要宰杀燔祭牲，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 14:10; 以弗所书 5:2; 利未记 14:8"> 在祭坛上献燔祭和素祭，为他赎罪，他就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 5:7; 利未记 12:8; 箴言 17:5"> “他如果贫穷，献不起那么多祭物，可以献一只公羊羔作赎过祭，用摇祭的方式赎罪；也要献一公斤作素祭的调油的细面粉和一杯油；</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 7:16; 以赛亚书 59:11; 耶利米书 48:28"> 还要按自己的能力献两只斑鸠或雏鸽，一只作赎罪祭，一只作燔祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 14:10–11"> 第八天，他必须把这些祭物带到会幕门口，在耶和华面前交给祭司，好使自己洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:12; 利未记 14:10"> 祭司要用作赎过祭的羊羔和一杯油作摇祭，在耶和华面前摇一摇。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 5:1; 诗篇 40:6; 利未记 14:14–20"> 接着，祭司要宰杀作赎过祭的羊羔，拿一些羊血抹在求洁净者的右耳垂、右手大拇指和右脚大脚趾上。</span>
<span className="v" id="v26" data-v="26"> 祭司也要把一些油倒在自己左手掌中，</span>
<span className="v" id="v27" data-v="27"> 用一根右手指蘸左手掌中的油，在耶和华面前弹洒七次，</span>
<span className="v" id="v28" data-v="28"> 然后把手掌中的一些油抹在求洁净者的右耳垂、右手大拇指和右脚大脚趾上，就是抹了赎过祭祭牲血的地方。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 14:18; 约翰一书 2:1–2; 出埃及记 30:15–16"> 祭司要把手掌里剩下的油抹在求洁净者的头上，在耶和华面前为他赎罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 14:22; 罗马书 8:3; 利未记 12:8"> 然后献上那人按自己能力带来的两只斑鸠或雏鸽，</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 14:18; 利未记 5:7"> 一只作赎罪祭，一只作燔祭，和素祭一起献上。这样，祭司在耶和华面前为求洁净者赎了罪。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 14:10; 利未记 14:21; 马太福音 11:5"> 这是献不起洁净礼所需祭物的麻风病患者应当遵守的条例。”</span>
</div>
</div>

## 处理房子发霉的条例

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华对摩西和亚伦说：</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="申命记 32:49; 创世记 17:8; 民数记 32:22"> “你们到了我赐给你们作产业的迦南以后，如果我使那里的房屋中有发霉现象，</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 91:10; 申命记 7:26; 撒迦利亚书 5:4"> 屋主必须去告诉祭司，‘我的房子里好像有发霉现象。’</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 18:4; 希伯来书 12:15; 提摩太后书 2:17–18"> 祭司进去检查前，要吩咐人把房子腾空，免得房子里的一切都变得不洁净。之后，祭司要进去检查，</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 13:42; 利未记 13:3; 利未记 13:19–20"> 如发现墙壁上出现红色或绿色霉斑，并且侵入墙中，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 13:50"> 祭司就要从房门出来，把房子封闭七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未记 13:36; 利未记 13:27; 利未记 13:22"> 第七天，祭司要回去检查。若发现墙壁上的霉斑蔓延，</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 2:20; 提多书 3:10; 哥林多前书 5:5–6"> 就要下令拆掉有霉斑的石块，丢到城外不洁净的地方，</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 65:4; 启示录 22:15; 马太福音 24:51"> 然后命人刮掉屋内墙壁上的灰泥，倒在城外不洁净的地方。</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太后书 2:2; 提摩太前书 5:21–22; 历代志下 17:7–9"> 要另找石块补被拆掉的地方，并用灰泥重新粉刷房子。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 6:28–30; 犹大书 1:12; 彼得后书 2:20"> “如果拆掉石块、刮掉灰泥、重新粉刷以后，房子再度出现霉斑，</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 13:51–52; 撒迦利亚书 5:4"> 祭司要去检查，若发现霉斑已蔓延，就是恶性霉变，那房子就不洁净。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 10:27; 马太福音 24:2; 列王纪上 9:6–9"> 房主要拆掉房子，把石块、木料和所有灰泥都丢到城外不洁净的地方。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 19:21–22; 利未记 22:6; 利未记 11:28"> 房子封闭期间，任何人进去，都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 14:8–9; 利未记 11:25"> 凡在房内睡觉或吃饭的人，都必须洗净衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 6:11; 约伯记 5:18; 马可福音 5:29"> “祭司检查粉刷后的房子，若发现房内没有再度出现霉斑，就要宣布房子是洁净的，因为霉斑已消失。</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 14:4"> 为洁净房子，祭司要取两只鸟、香柏木、朱红色线和牛膝草，</span>
<span className="v" id="v50" data-v="50"> 在一个盛清水的陶器上宰杀一只鸟，</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 51:7"> 然后用香柏木、牛膝草、朱红色线和另一只活鸟，蘸掺了清水的鸟血，向房子洒七次。</span>
<span className="v" id="v52" data-v="52"> 祭司用鸟血、清水、活鸟、香柏木、牛膝草和朱红色线洁净那房子后，</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 14:20; 利未记 14:7"> 要放走那只活鸟，让它飞到城外的田野。这样，祭司为那房子赎了罪，房子就洁净了。”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未记 15:32; 利未记 14:32; 利未记 6:9"> 以上条例是有关麻风病、疥癣、</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 13:47–59"> 衣物或房子发霉、</span>
<span className="v" id="v56" data-v="56" data-xref="利未记 13:2"> 肿包、皮疹或白斑的条例。</span>
<span className="v" id="v57" data-v="57" data-xref="利未记 10:10; 以西结书 44:23; 耶利米书 15:19"> 根据这些条例，可以分辨有关的人或物何时洁净、何时不洁净。</span>
</div>
</div>

</div>

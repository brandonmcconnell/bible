## 遵行诫命蒙祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 19:4; 申命记 27:15; 民数记 33:52"> “你们不可为自己制造偶像，不可竖立神像和神柱，也不可在你们境内安放祭拜用的石像。我是你们的上帝耶和华。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 19:30"> 你们要守我的安息日，敬畏我的圣所。我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:19; 申命记 11:13–15; 申命记 28:1–14"> 如果你们遵行我的律例，谨守我的诫命，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 8:12; 诗篇 67:6; 利未记 25:21"> 我就按时降雨给你们，使土地长出庄稼、田间果树结出果实。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司书 9:13; 约珥书 2:26; 约珥书 2:19"> 你们要打粮食打到摘葡萄的时候，摘葡萄摘到播种的时候。你们必丰衣足食，安然居住。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 35:9; 西番雅书 3:13; 诗篇 147:14"> “我要使你们境内太平，安枕无忧。我要除掉你们境内的猛兽，也要使你们免遭刀剑之灾。</span>
<span className="v" id="v7" data-v="7"> 你们将追赶仇敌，使他们倒在你们刀下。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 23:10; 申命记 28:7; 申命记 32:30"> 你们五人要追赶一百人，一百人要追赶一万人，他们必死在你们刀下。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 17:6–7; 尼希米记 9:23; 以西结书 16:62"> 我要眷顾你们，使你们生养众多，人丁兴旺，也要坚守与你们所立的约。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:22; 列王纪下 19:29; 路加福音 12:17"> 你们存粮充足，甚至要搬出陈粮来储存新粮。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:8; 启示录 21:3; 出埃及记 29:45"> 我要住在你们中间，我必不厌弃你们。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 6:16; 耶利米书 30:22; 耶利米书 7:23"> 我要走在你们中间。我要做你们的上帝，你们要做我的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 34:27; 利未记 25:38; 诗篇 116:16"> 我是你们的上帝耶和华。我曾带领你们离开埃及，使你们不再做埃及人的奴隶。我打碎了你们身上的重轭，使你们昂首前行。</span>
</div>
</div>

## 违背诫命受惩罚

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 28:15–68; 利未记 26:18; 耶利米书 17:27"> “如果你们不听从我，不遵行我的这一切诫命；</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 17:15; 申命记 31:16; 撒迦利亚书 7:11–13"> 如果你们弃绝我的律例，厌弃我的典章，不听从我的命令，破坏我与你们所立的约，</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:8; 耶利米书 5:17; 弥迦书 6:15"> 我要惩罚你们，使你们陷入恐慌、患痨病和热症，使你们眼睛昏花、心力衰竭。你们撒种却一无所获，因为敌人要吃尽你们所种的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 箴言 28:1; 诗篇 53:5"> 我要严惩你们，使你们败在敌人手下；你们要被那些恨你们的人统治，即使没有人追赶，你们也要逃命。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 26:21; 利未记 26:28; 利未记 26:24"> “如果你们经历这些后，仍然不听从我，我要使你为罪多受七倍的惩罚。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:23; 列王纪上 17:1; 但以理书 4:37"> 我要重挫你们的傲气，使你们头上的天如铁，脚下的地如铜。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 127:1; 申命记 11:17; 以赛亚书 49:4"> 你们劳作也是徒然，因为你们的土地必不长庄稼，果树也不结果实。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 26:18; 利未记 26:27"> “如果你们仍然与我作对，不肯听从我，我要用七倍的灾难惩治你们的罪。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 14:15; 申命记 32:24; 士师记 5:6"> 我要让野兽攻击你们，残害你们的子女，吞噬你们的牲畜，使你们人口锐减，道路荒凉。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 5:3; 耶利米书 2:30; 阿摩司书 4:6–12"> “如果你们还是不服管教，继续与我作对，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 18:26; 撒母耳记下 22:27; 约伯记 9:4"> 我也要与你们作对，用七倍的灾难惩治你们的罪。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 14:12; 以西结书 5:17; 耶利米书 29:17–18"> 因为你们毁约，我要用战祸报应你们。你们躲进各城的时候，我要在你们中间降下瘟疫，使你们落在敌人手里。</span>
<span className="v" id="v26" data-v="26" data-xref="弥迦书 6:14; 以赛亚书 3:1; 诗篇 105:16"> 我要断绝你们的粮源。那时候，十个妇女将用一个烤炉烤饼，按定量分饼给你们，你们吃却吃不饱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 26:24; 利未记 26:21"> “如果你们仍然不肯听从我，继续与我作对，</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:18; 耶利米书 21:5; 以赛亚书 66:15"> 我也要与你们作对，向你们发烈怒，把比先前严厉七倍的惩罚加在你们身上。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 5:10; 耶利米哀歌 4:10; 马太福音 24:19"> 你们要吃自己儿女的肉。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 23:20; 以赛亚书 27:9; 以西结书 6:13"> 我要毁灭你们的丘坛，拆掉你们的香坛，把你们的尸体堆在你们的死偶像上。我必厌恶你们。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:3; 耶利米哀歌 1:10; 希伯来书 10:26"> 我要使你们的城邑沦为废墟，使你们的敬拜场所荒凉，也不再悦纳你们的馨香之祭。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 9:11; 耶利米书 19:8; 耶利米书 18:16"> 我要使你们的土地荒废，连占据那里的敌人也为此而震惊。</span>
<span className="v" id="v33" data-v="33" data-xref="撒迦利亚书 7:14; 以西结书 20:23; 申命记 28:64–66"> 我要把你们驱散到各国，还要拔刀追杀你们。你们的土地将荒废，城邑将沦为废墟。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 36:21; 利未记 26:43; 利未记 25:2–4"> 你们被掳到敌国的时候，你们的土地将荒废，享受安息。那时土地必休息，享受安息。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 24:5–6; 罗马书 8:22"> 你们住在那里的时候，没有在安息年让土地安息，因此土地在荒废的日子里将享受安息。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结书 21:7; 以赛亚书 30:17; 利未记 26:17"> “我要使你们当中的那些幸存者在敌国心惊胆战，过着风声鹤唳、惶恐不安的生活。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 7:12–13; 士师记 2:14; 耶利米书 37:10"> 即使无人追赶，他们也将仓皇逃命，互相绊倒，如同躲避刀剑一样。你们必无力抵挡敌人。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 28:48; 以赛亚书 27:13; 耶利米书 42:17–18"> 你们将葬身列国，死在敌人的土地上。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 4:17; 以西结书 24:23; 以西结书 33:10"> 你们当中的幸存者将因自己的罪和祖先的罪而消亡在敌人的土地上。</span>
</div>
</div>

## 认罪悔改蒙眷顾

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; 尼希米记 9:2–5; 约翰一书 1:8–10"> “如果他们承认自己和祖先的罪，就是背叛我、与我作对的恶行，</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 44:7; 历代志下 32:26; 历代志下 12:6–7"> 以致我与他们作对，把他们流放到敌国；如果他们顽固<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“顽固”希伯来文是“未受割礼”。">a</a></sup>的心谦卑下来，甘愿为罪受罚，</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 106:45; 出埃及记 6:5; 以西结书 16:60"> 我便顾念我与亚伯拉罕、以撒和雅各所立的约，眷顾那片土地。</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 8:7; 利未记 26:15; 约翰福音 7:7"> 土地被他们离弃，荒无人烟，得享安息。他们却要因拒绝遵守我的典章、厌弃我的律例而饱受惩罚。</span>
<span className="v" id="v44" data-v="44" data-xref="罗马书 11:2; 尼希米记 9:31; 申命记 4:29–31"> 然而，他们流落敌国的时候，我不会弃绝他们，不会因厌恶而毁灭他们，也不会违背我与他们所立的约。我是他们的上帝耶和华。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 25:38; 以西结书 20:22; 以西结书 20:9"> 为了他们的缘故，我必顾念我与他们祖先所立的约。我曾在列国面前带领他们的祖先离开埃及，为要做他们的上帝。我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未记 27:34; 申命记 12:1; 申命记 6:1"> 以上是耶和华借摩西在西奈山上颁布给以色列人的律例、典章和法度。</span>
</div>
</div>

## 许愿的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:2; 撒母耳记上 1:28; 士师记 11:30–31"> “你要告诉以色列人：如果有人许下特别的愿，以付身价的方式奉献一个人给耶和华，就要为被奉献者估定身价。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:13; 利未记 27:25; 民数记 18:16"> 以圣所的秤为准，要为二十至六十岁的男子估价十两银子，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 27:9–10; 撒迦利亚书 11:12–13; 马太福音 26:15"> 女子则估价七两银子；</span>
<span className="v" id="v5" data-v="5"> 五至二十岁的男子估价四两银子，女子则估价二两银子；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:40–43; 民数记 18:14–16"> 满月至五岁的男子估价一两银子，女子则估价半两多银子；</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 90:10"> 六十岁以上的男子估价三两银子，女子则估价二两银子。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:7; 利未记 14:21–22; 路加福音 21:1–4"> 如果许愿的人因贫穷而负担不起，就要把他带到祭司面前，祭司要按他的能力另行估价。</span>
<span className="v" id="v9" data-v="9"> “如果有人许愿献牲畜给耶和华作供物，所献的牲畜就会成为圣物。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 27:15–33; 雅各书 1:8"> 不可更换所献的牲畜，不可以坏换好，也不可以好换坏。如果更换，两头牲畜都会成为圣物。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 23:18; 玛拉基书 1:14"> 如果许愿献的是不洁净的牲畜，即不能献给耶和华作供物的牲畜，那人就要把牲畜带到祭司面前，</span>
<span className="v" id="v12" data-v="12"> 由祭司评定它的好坏，祭司估价多少就是多少。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:19; 利未记 27:15; 利未记 22:14"> 那人如果有意赎回，必须支付祭司估定的价值，再加付五分之一。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:14; 利未记 25:29–31; 利未记 27:21"> “如果有人把房子分别出来献给耶和华，祭司就要评定房子的好坏，祭司估价多少就是多少。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:13"> 那人如果想赎回房子，必须支付祭司估定的价值，再加付五分之一，房子便仍归他所有。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 45:11–14; 何西阿书 3:2; 使徒行传 4:34–37"> “如果有人把自己继承的部分土地分别出来献给耶和华，祭司就要按照土地的播种量来估价，撒二百升大麦种子的土地值十两银子。</span>
<span className="v" id="v17" data-v="17"> 如果有人在禧年奉献土地，所估的价便是定价。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 25:15–16; 利未记 25:51–52; 利未记 25:27"> 如果是在禧年以后献的，祭司要按照距下个禧年的年数来估价，估价要逐年减低。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 27:13"> 如果那人想赎回所献的土地，要在估价的基础上加付五分之一，土地便仍归他所有。</span>
<span className="v" id="v20" data-v="20"> 他如果没有赎回土地，而是卖给别人，便再也不能赎回。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 44:29; 民数记 18:14; 利未记 25:31"> 到了禧年，那土地要像永远献给耶和华的土地一样归耶和华，成为祭司的产业。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 25:10; 利未记 25:25"> “如果献给耶和华的土地不是自己的产业，而是买来的，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 27:18; 利未记 27:12"> 祭司就要按照距下个禧年的年数来估价。那人要当天付清地价，地价归耶和华。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 25:28; 利未记 27:20"> 到了禧年，他要把所献的土地归还给卖主，就是土地的原主。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:13; 民数记 18:16; 民数记 3:47"> 所有价银的称量要以圣所的秤为准，即二十季拉为一舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约合十一克。">a</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:2; 出埃及记 13:12–13; 民数记 18:17"> “洁净牲畜的头胎，无论是牛是羊，已经属于耶和华，任何人不可再把它献给耶和华。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 27:11"> 如果是不洁净牲畜的头胎，他可以在祭司的估价基础上，加付五分之一把它赎回；如果不赎回，就要按估价把它卖掉。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:17–19; 利未记 27:21; 出埃及记 22:20"> 凡永远献上的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“永远献上的”指完全献给耶和华、永不可赎回的人或物，一般要被毁灭。此律多适用于战争中被攻占的城邑或战俘。">b</a></sup>，不论是人、牲畜或是田产，都不可卖掉，也不可赎回，因为这一切都是耶和华的至圣之物。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:18–23; 民数记 21:2–3"> 凡永远献上的人不可被赎回，必须被处死。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 23:23; 尼希米记 13:12; 创世记 28:22"> “土地的所有出产中，不论是谷物还是树上的果实，十分之一属于耶和华，是耶和华的圣物。</span>
<span className="v" id="v31" data-v="31"> 如果有人想从那十分之一中赎回一部分，他要加付估价的五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 33:13; 以西结书 20:37; 弥迦书 7:14"> 至于牛羊，要让它们从牧人的杖下经过，每十只的第十只要归耶和华作圣物。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 27:10"> 不论是好是坏，不可挑拣，不可更换。如果更换，两只都要作圣物，不可赎回。”</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 26:46; 民数记 1:1; 希伯来书 12:18–25"> 以上是耶和华在西奈山上借摩西向以色列人颁布的诫命。</span>

## 有关圣洁生活的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 11:44–45; 利未记 20:7; 彼得前书 1:15–16"> “你要告诉以色列全体会众，‘你们要圣洁，因为我——你们的上帝耶和华是圣洁的。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 20:12; 出埃及记 20:8; 希伯来书 12:9"> 你们每个人都必须孝敬父母，遵守我的安息日。我是你们的上帝耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:1; 出埃及记 20:23; 诗篇 115:4–7"> 不要祭拜虚无的神明，也不要为自己铸造神像。我是你们的上帝耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 22:19; 利未记 22:29; 利未记 7:16"> 你们献平安祭给我时，要使你们所献的蒙悦纳。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 7:11–17"> 要在献祭当天或第二天吃完祭物。如果第三天还有剩余，都要烧掉。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 7:18–21; 利未记 22:25; 耶利米书 16:18"> 如果有人第三天还吃那些祭物，祭物就不洁净，我不会悦纳。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 22:15; 利未记 5:1"> 那人要自担罪责，因为他亵渎了我的圣物。要将他从民中铲除。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 23:22; 申命记 24:19–22; 路得记 2:2"> “‘你们收割的时候，不要割净田角地边的庄稼，也不要捡那些掉在田里的穗子。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 17:6; 利未记 25:6; 以赛亚书 24:13"> 不要摘净葡萄园里的葡萄，也不要捡掉在地上的葡萄。要把这些留给穷人和寄居在你们中间的外族人。我是你们的上帝耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 101:7; 以弗所书 4:25; 歌罗西书 3:9"> 不可偷盗，不可撒谎，不可互相欺骗。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:7; 申命记 5:11; 利未记 18:21"> 不可奉我的名起假誓，从而亵渎你们上帝的名。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:4; 玛拉基书 3:5; 申命记 24:14–15"> 不可欺压邻居，也不可抢夺他的东西。要当天支付雇工的工钱，不可拖到第二天。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 27:18; 利未记 19:32; 利未记 25:17"> 不可咒骂耳聋的，也不可把绊脚石放在盲人面前，应当敬畏你们的上帝。我是耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 1:17; 箴言 24:23; 申命记 27:19"> 不可徇私枉法，不可偏袒穷人，不可谄媚权贵之人，要秉公审判。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:1; 出埃及记 23:7; 箴言 20:19"> 不可到处搬弄是非，不可危害邻居的生命安全。我是耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 2:9; 约翰一书 2:11; 路加福音 17:3"> 对同胞不可心中怀恨。同胞有错，要当面指正，免得自己因他而担罪。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 13:9; 马太福音 22:39–40; 马可福音 12:31–34"> 不可报复，不可埋怨同胞，要爱邻如己。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 6:14–17; 申命记 22:9–11; 马太福音 9:16–17"> “‘你们要遵守我的律例。不可让牲畜杂交；不可在同一块田播撒两种不同的种子；不可穿两种材料织成的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 22:23–24; 出埃及记 21:20–21"> “‘一个已经许配人的婢女尚未被赎或未获自由时，如果有人与她同寝，就要受到处罚，但不可处死他们，因为那婢女还未获自由。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 6:6–7; 利未记 5:1–6; 利未记 5:15"> 和她同寝的人要把一只公绵羊牵到会幕门口，作为赎过祭献给耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:26; 利未记 4:20"> 祭司要用作赎过祭的公绵羊在耶和华面前为那人赎罪，他犯的罪便得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="利未记 22:27; 使徒行传 7:51; 耶利米书 9:25–26"> “‘你们到了迦南，在那里栽种各样果树后，前三年不可吃树上的果子，要视它们是不洁净的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“不洁净的”希伯来文是“未受割礼的”。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 3:9; 申命记 18:4; 民数记 18:12–13"> 第四年，树上的所有果子都是圣洁的，要献给耶和华作颂赞之祭。</span>
<span className="v" id="v25" data-v="25" data-xref="哈该书 1:9–11; 玛拉基书 3:8–10; 利未记 26:3–4"> 第五年，你们可以吃树上的果子。你们这样做，果树会为你们结出更多果子。我是你们的上帝耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 18:10–14; 列王纪下 17:17; 历代志下 33:6"> “‘不可吃带血的肉，不可占卜或行巫术。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 21:5; 申命记 14:1; 以西结书 44:20"> 不可修剪鬓角或胡须。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 14:1; 利未记 21:5; 列王纪上 18:28"> 不可因哀悼死人而割伤身体，也不可纹身。我是耶和华。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 23:17–18; 利未记 21:7; 何西阿书 4:12–14"> 不可辱没自己的女儿，使她沦为娼妓，免得你们居住的地方充满淫乱和邪恶。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 26:2; 利未记 19:3; 传道书 5:1"> 要遵守我的安息日，敬畏我的圣所。我是耶和华。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 8:19; 利未记 20:27; 利未记 20:6–7"> 不可求问灵媒或巫师，玷污自己。我是你们的上帝耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="提摩太前书 5:1; 耶利米哀歌 5:12; 箴言 16:31"> “‘在年长者面前，要恭敬站立，要敬重年长者。要敬畏你们的上帝。我是耶和华。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 23:9; 出埃及记 22:21; 玛拉基书 3:5"> 不可欺负住在你们境内的外族人，</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 10:19; 利未记 19:18; 出埃及记 12:48–49"> 要视他们如同胞，爱他们如爱自己，因为你们也曾经寄居埃及。我是你们的上帝耶和华。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 25:15; 申命记 25:13; 箴言 16:11"> 在称重和度量时，不可欺诈。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 11:1; 出埃及记 20:2; 申命记 25:13–15"> 要使用准确的秤、尺子和升斗。我是你们的上帝耶和华，曾带领你们离开埃及。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 8:1; 利未记 18:4–5; 申命记 5:1"> 你们要遵行我的一切律例和典章。我是耶和华。’”</span>
</div>
</div>

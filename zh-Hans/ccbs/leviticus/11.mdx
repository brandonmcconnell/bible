## 有关食物的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:11; 利未记 11:11; 希伯来书 9:10"> “你们把以下条例告诉以色列人。 “地上的动物，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多后书 6:17; 申命记 6:6–7"> 凡蹄子分瓣且反刍的动物，你们都可以吃。</span>
<span className="v" id="v4" data-v="4"> 但你们不可吃只是蹄子分瓣或只反刍的动物。骆驼不洁净，因为它虽反刍但蹄子不分瓣；</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:18; 箴言 30:26; 马太福音 7:26"> 石獾不洁净，因为它虽反刍但蹄子不分瓣；</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:7"> 野兔不洁净，因为它虽反刍但蹄子不分瓣；</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 66:17; 以赛亚书 65:4; 以赛亚书 66:3"> 猪不洁净，因为它虽蹄子分瓣但不反刍。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 52:11; 歌罗西书 2:16; 希伯来书 9:10"> 你们不可吃它们的肉，也不可摸它们的尸体，因为它们对你们来说不洁净。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 5:6; 雅各书 2:18; 使徒行传 20:21"> “海洋与河流里的动物，凡有鳍有鳞的，你们都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未记 7:18; 诗篇 139:21–22"> 但海洋与河流里无鳍无鳞的动物，你们要憎恶。</span>
<span className="v" id="v11" data-v="11"> 它们都是可憎之物，你们不可吃它们的肉，也不可摸它们的尸体。</span>
<span className="v" id="v12" data-v="12"> 水中任何无鳍无鳞的动物，你们都要视为可憎之物。</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 39:27–30; 耶利米书 4:22; 提多书 3:3"> “你们不可吃以下鸟类，要视为可憎之物。它们是雕、胡兀鹫、黑秃鹫、</span>
<span className="v" id="v14" data-v="14"> 鸢、隼类、</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王纪上 17:6; 箴言 30:17"> 乌鸦类、</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 34:11–15; 以弗所书 5:7–11; 以弗所书 2:2–3"> 鸵鸟、夜鹰、海鸥、鹰类、</span>
<span className="v" id="v17" data-v="17"> 小鸮、鸬鹚、大鸮、</span>
<span className="v" id="v18" data-v="18"> 仓鸮、鹈鹕、鱼鹰、</span>
<span className="v" id="v19" data-v="19"> 鹳、鹭鸟类、戴胜和蝙蝠。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:10; 腓立比书 3:18–19; 利未记 11:23"> “你们要憎恶会飞的四足爬行昆虫，</span>
<span className="v" id="v21" data-v="21"> 但可以吃其中会飞会跳的昆虫，</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 3:4; 马可福音 1:6; 出埃及记 10:4–5"> 包括蝗虫类、蟋蟀类和蚱蜢类。</span>
<span className="v" id="v23" data-v="23"> 你们要憎恶所有会飞的四足爬行昆虫。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:33; 以弗所书 2:1–3; 哥林多后书 6:17"> “以下的动物会使你们不洁净。任何人接触到它们的尸体，都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:5; 利未记 14:8; 民数记 31:24"> 任何人拿它们的尸体，都必须洗净所穿的衣服，要等到傍晚才能洁净。</span>
<span className="v" id="v26" data-v="26"> 蹄子不分瓣或不反刍的动物，你们要视为不洁净，碰到它们的人都不洁净。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 11:23; 利未记 11:20"> 所有以脚掌走路的四足动物，你们要视为不洁净，碰到它们尸体的人都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:24–25"> 凡拿它们尸体的人都必须洗净所穿的衣服，要等到傍晚才能洁净。你们要视它们为不洁净的动物。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 11:41–42; 提摩太后书 3:2–5; 诗篇 10:3"> “地上不洁净的动物有鼬鼠、老鼠、大蜥蜴类、</span>
<span className="v" id="v30" data-v="30"> 壁虎、巨蜥、小蜥蜴和变色龙。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 11:24–25; 利未记 11:8"> 这些爬虫都是不洁净的。任何人碰到它们的尸体，都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 15:12; 提多书 3:5; 提多书 2:14"> 如果它们的尸体掉在什么东西上，不管是木器、衣物、皮件还是袋子，不管作何用途，都会变得不洁净。要把那东西放在水中，一直到傍晚才能洁净。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 6:28; 利未记 15:12; 利未记 14:45"> 如果它们的尸体掉在陶器里，陶器里盛的东西都不洁净。你们必须打碎那陶器。</span>
<span className="v" id="v34" data-v="34" data-xref="提多书 1:15; 箴言 21:4; 箴言 21:27"> 陶器里的水如果滴到食物上，食物就不洁净；如果滴到盛饮品的器皿里，饮品也不洁净。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 15:12; 利未记 6:28; 利未记 11:33"> 它们的尸体无论掉在什么东西上，那东西都不洁净，无论是炉是锅都要打碎。它们不洁净，也理当被你们视为不洁净。</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 13:1; 约翰福音 4:14"> 如果它们的尸体掉进水泉或储水池里，水泉和储水池仍然是洁净的，但碰到尸体的人是不洁净的。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:37; 彼得前书 1:23; 约翰一书 5:18"> 如果它们的尸体接触到将要播撒的种子，种子仍是洁净的。</span>
<span className="v" id="v38" data-v="38"> 但如果它们的尸体碰到泡过水的种子，种子就不洁净。</span>
<span className="v" id="v39" data-v="39" data-xref="利未记 11:40; 利未记 11:24; 利未记 15:7"> “一只可以食用的动物死后，任何人如果碰到它的尸体，都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v40" data-v="40" data-xref="利未记 22:8; 以西结书 44:31; 申命记 14:21"> 任何人如果吃它的肉，或拿它的尸体，都必须洗净衣服，等到傍晚才能洁净。</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 11:29; 利未记 11:20; 利未记 11:23"> “地上所有的爬虫都是可憎的，你们不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多书 1:12; 以赛亚书 65:25; 哥林多后书 11:3"> 你们不可吃用肚子、四脚或多脚爬行的动物，这些都是可憎的。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 20:25; 利未记 11:41–42"> 不可让这些动物使你们成为可憎的，不可因它们而玷污自己，使自己不洁净。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 20:2; 彼得前书 1:15–16; 利未记 19:2"> 我是你们的上帝耶和华。你们要分别出来做圣洁的人，因为我是圣洁的。不可让地上的爬虫玷污你们。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 11:44; 出埃及记 20:2; 出埃及记 6:7"> 我是耶和华，我带你们出埃及，为要做你们的上帝。你们要圣洁，因为我是圣洁的。</span>
<span className="v" id="v46" data-v="46" data-xref="利未记 14:54; 利未记 15:32; 以西结书 43:12"> “以上是有关飞禽走兽、水族和地上一切爬虫的条例，</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 10:10; 以西结书 44:23; 罗马书 14:13–23"> 使你们可以区分什么是洁净的、什么是不洁净的、什么是可吃的、什么是不可吃的。”</span>
</div>

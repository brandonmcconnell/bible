## 灯和供饼的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 4:6; 以弗所书 5:8–14; 出埃及记 27:20–21"> “你要吩咐以色列人把榨的纯橄榄油给你拿来点灯，使灯常明。</span>
<span className="v" id="v3" data-v="3"> 亚伦要负责照看会幕内遮掩约柜的幔子外的灯，使灯从晚上到早晨一直在耶和华面前亮着。这是你们世代当守的永久律例。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 31:8; 出埃及记 37:17–24; 出埃及记 39:37"> 亚伦要在耶和华面前常常照看这些放在纯金灯台上的灯。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:30; 列王纪上 18:31; 出埃及记 40:23"> “你要用细面粉烤十二个饼，每个饼用两公斤细面粉。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:48; 出埃及记 25:23–24; 历代志下 4:19"> 你要把饼摆成两行，放在耶和华面前的纯金桌子上，每行六个，</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:2; 启示录 8:3–4; 创世记 9:16"> 每行饼上放一些纯乳香，象征这些饼是献给耶和华的火祭。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 2:4; 民数记 4:7; 历代志上 9:32"> 每逢安息日，要定期把饼摆在耶和华面前。这是以色列人要永远遵守的约。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 8:31; 路加福音 6:4; 马可福音 2:26"> 这些饼要归亚伦及其子孙。他们要在圣洁之处吃，因为在献给耶和华的火祭中，这是至圣之物，要永远归祭司所有。”</span>
</div>
</div>

## 处死亵渎圣名者

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 11:4; 出埃及记 12:38"> 有一个人，母亲是以色列人，父亲是埃及人，他在营中与一个以色列人打起架来。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 24:15–16; 出埃及记 3:15"> 他说咒诅的话，亵渎了上帝的名，他们把他带到摩西那里。他母亲叫示罗密，是但支派底伯利的女儿。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 18:15–16; 民数记 15:34; 民数记 27:5"> 他们把他关押起来，等候耶和华的指示。</span>
<span className="v" id="v13" data-v="13"> 耶和华对摩西说：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:7; 利未记 20:27; 申命记 21:21"> “把那亵渎圣名的人带到营外，所有听见的人都把手放在他头上，然后全体会众要用石头打死他。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:13; 出埃及记 22:28; 利未记 5:1"> 你要告诉以色列人，谁咒诅上帝，谁就要承担自己的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 12:31; 雅各书 2:7; 约翰福音 10:33–36"> 凡亵渎耶和华圣名的，必须被处死，全体会众要用石头打死他。不论是外族人还是以色列人，凡亵渎圣名的，都必须被处死。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 9:5–6; 申命记 19:11–12; 申命记 27:24"> 凡杀人的，必须被处死。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 24:21; 出埃及记 21:34–36"> 打死别人牲畜的，必须赔偿牲畜，以命还命。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:38; 马太福音 7:2; 申命记 19:21"> 伤害邻舍的，必须受同样的伤害，</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 19:21; 马太福音 5:38; 出埃及记 21:23–25"> 要以伤还伤，以眼还眼，以牙还牙。他怎样伤害别人，也要怎样伤害他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 24:17–18; 出埃及记 21:33"> 打死别人牲畜的，必须赔偿牲畜；杀人的，必须偿命。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:49; 民数记 15:15–16; 民数记 9:14"> 不论是以色列人还是外族人，都要遵守这些律法。我是你们的上帝耶和华。”</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 10:28–29; 希伯来书 2:2–3; 民数记 15:35–36"> 于是，摩西把这些话告诉以色列人，他们就按照耶和华对摩西的吩咐，把那亵渎圣名的人带到营外，用石头打死了。</span>
</div>
</div>

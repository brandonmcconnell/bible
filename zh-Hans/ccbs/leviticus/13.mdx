## 有关麻风病的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 24:8; 利未记 14:56; 利未记 14:3"> “如果有人皮肤上长肿包、皮疹或白斑，出现麻风病<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“麻风病”此处为传统译法，希伯来文的意思指包括麻风病在内的各种严重皮肤病。">a</a></sup>症状，要将他带到祭司亚伦或亚伦做祭司的子孙那里。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 3:19–20; 使徒行传 20:28; 玛拉基书 2:7"> 祭司要检查患处，如果病灶深入皮下，患处的毛发变白，就是麻风病。祭司检查后，要宣布他是不洁净的。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 12:15; 哥林多前书 4:5; 提摩太前书 5:24"> 如果那人的患处有白斑，但病灶没有深入皮下，患处的毛发也没有变白，祭司要把他隔离七天。</span>
<span className="v" id="v5" data-v="5"> 第七天，祭司要再次检查患处，如果病灶没有恶化，没有在皮肤上扩散，祭司要把他再隔离七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 11:25; 利未记 14:8; 申命记 32:5"> 第七天，祭司要再次检查，如果患处颜色变淡，也没有扩散，祭司要宣布他是洁净的。他患的不过是皮疹，他要洗净衣物，便会洁净。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 38:3; 利未记 13:35–36; 提摩太后书 2:16–17"> 如果祭司已查看并宣布他是洁净的，但皮疹又扩散，他必须再去见祭司。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 15:7–8; 腓立比书 3:18–19; 使徒行传 8:21"> 祭司检查时，如果发现皮疹已扩散，就要宣布他是不洁净的，患了麻风病。</span>
<span className="v" id="v9" data-v="9"> “如果有人患麻风病，必须将他带到祭司面前。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 5:27; 历代志下 26:19–20; 利未记 13:14–15"> 祭司检查时，如果发现他皮肤上有白色肿包，毛发变白，患处长出新肉，</span>
<span className="v" id="v11" data-v="11"> 他就是患了慢性麻风病，祭司要宣布他是不洁净的。他无须被隔离，因他已经不洁净。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 1:8–10; 约伯记 42:6; 罗马书 7:14"> 如果他的麻风病已扩散，头上脚上到处可见，</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:41; 以赛亚书 64:6"> 祭司就要检查。如果发现麻风病已扩散到他全身，全身的皮肤变白，祭司就要宣布他是洁净的。</span>
<span className="v" id="v14" data-v="14"> 一旦他身上出现新长的肉，他便不洁净。</span>
<span className="v" id="v15" data-v="15"> 祭司看到他身上新长的肉，就要宣布他是不洁净的，因为新长的肉是不洁净的，表明他患了麻风病。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 1:14–16; 罗马书 7:14–24; 腓立比书 3:6–8"> 如果新长的肉变白了，他就要去见祭司。</span>
<span className="v" id="v17" data-v="17"> 祭司检查时，若发现患处确已变白，就要宣布他是洁净的，他便洁净了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:9; 以赛亚书 38:21; 诗篇 38:3–7"> “如果有人皮肤上长疮，又痊愈了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 13:24"> 但原患处出现白色肿包或白里带红的斑，他就要去让祭司检查。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 5:14; 利未记 13:3; 彼得后书 2:20"> 祭司检查时，若发现病灶深入皮下，患处的毛发变白，就要宣布他是不洁净的。这是疮变成了麻风病。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 5:5"> 但祭司检查时，若发现患处没有白毛，病灶也没有深入皮下，且颜色变淡，就要把他隔离七天。</span>
<span className="v" id="v22" data-v="22"> 隔离期间，若病灶在皮肤上扩散，祭司要宣布他是不洁净的，是患了麻风病。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 约伯记 34:31–32; 马太福音 26:75"> 如果患处的斑保持原样，没有扩散，便是疮疤，祭司要宣布他是洁净的。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 3:24"> “如果有人被火烧伤，伤处变白或白中带红，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 13:18–20; 利未记 13:4"> 祭司要检查他的伤处。如果伤处毛发变白，且深入皮下，就是烧伤已变成麻风病，祭司要宣布他是不洁净的，因为他患了麻风病。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 13:23; 利未记 13:4–5"> 祭司检查时，若发现伤处没有白毛，也没有深入皮下，且颜色变淡，就要把他隔离七天。</span>
<span className="v" id="v27" data-v="27"> 第七天，祭司要再次检查，若发现伤处扩散，就要宣布他是不洁净的，因为他患了麻风病。</span>
<span className="v" id="v28" data-v="28"> 如果伤处保持原样，没有扩散，且颜色变淡，就是烧伤引起的肿包，祭司要宣布他是洁净的，因为那不过是烧伤的疤痕。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:15; 马太福音 13:14–15; 哥林多后书 4:3–4"> “如果有男女头上或下巴长疮，</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 13:34–37; 利未记 14:54"> 祭司要检查患处，若发现患处病灶深入皮下，上面有黄色细毛，就要宣布那人是不洁净的，因为那是疥癣，是麻风病。</span>
<span className="v" id="v31" data-v="31"> 祭司检查时，若发现病灶没有深入皮下，也没有黑毛，就要将那人隔离七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 13:30; 马太福音 23:5; 路加福音 18:9–12"> 第七天，祭司要检查患处，若发现疥癣没有扩散，上面没有黄毛，也没有深入皮下，</span>
<span className="v" id="v33" data-v="33"> 那人要剃去头发和胡须，但不可剃患处的毛发。祭司要将他再隔离七天。</span>
<span className="v" id="v34" data-v="34" data-xref="犹大书 1:22; 约翰一书 4:1; 启示录 2:2"> 第七天，祭司要再次检查，若发现疥癣没有在皮肤上扩散，也没有深入皮下，就要宣布那人是洁净的。那人要洗净衣服，便洁净了。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 13:27; 提摩太后书 2:16–17; 利未记 13:7"> 那人洁净以后，疥癣若再次扩散，</span>
<span className="v" id="v36" data-v="36"> 祭司就要再次检查。如果疥癣确已扩散，祭司不必再找黄毛，那人是不洁净的。</span>
<span className="v" id="v37" data-v="37"> 如果祭司看到疥癣原样未变，患处长出黑毛，那人就已经痊愈，是洁净的。祭司要宣布那人是洁净的。</span>
<span className="v" id="v38" data-v="38"> “如果有男女身上长白斑，</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:22–25; 雅各书 3:2; 传道书 7:20"> 祭司要检查患处，若发现斑呈灰白色，就是皮疹，那人是洁净的。</span>
<span className="v" id="v40" data-v="40" data-xref="加拉太书 4:13; 罗马书 8:10; 雅歌 5:11"> “如果有人脱发，成了秃头，他是洁净的。</span>
<span className="v" id="v41" data-v="41"> 如果有人前额脱发，他只是前额光秃，仍是洁净的。</span>
<span className="v" id="v42" data-v="42"> 如果在光秃的头上或前额上长出白里带红的疮，那就是麻风病。</span>
<span className="v" id="v43" data-v="43"> 祭司要检查患处，若发现疮周围肿胀、白中带红，看起来像麻风病，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得后书 2:1–2; 马太福音 6:23; 以赛亚书 1:5"> 就是得了麻风病，那人是不洁净的。祭司要因那人头上的疮而宣布他是不洁净的。</span>
<span className="v" id="v45" data-v="45" data-xref="弥迦书 3:7; 利未记 10:6; 以西结书 24:17"> “患麻风病的人必须撕裂衣服，披头散发，遮住脸的下半部，高喊‘不洁净！不洁净！’</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪下 7:3; 列王纪下 15:5; 历代志下 26:21"> 只要病不痊愈，他就不洁净，要独自住在营外。</span>
</div>

## 霉变衣物的条例

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="犹大书 1:23; 罗马书 13:12; 以西结书 16:16"> “如果衣物出现霉斑，不论是羊毛衣、细麻衣、</span>
<span className="v" id="v48" data-v="48" data-xref="利未记 13:51; 启示录 3:4; 申命记 8:11"> 羊毛织品、细麻织品，还是皮革或皮革制品，</span>
<span className="v" id="v49" data-v="49"> 只要发现霉斑是绿色或红色的，那就是霉变，要拿给祭司检查。</span>
<span className="v" id="v50" data-v="50" data-xref="以西结书 44:23"> 祭司检查后，要把那衣物隔离七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未记 14:44"> 第七天，祭司要再次检查，若发现衣物、编织品或皮革上的霉斑蔓延，就是恶性霉变，那衣物就不洁净。</span>
<span className="v" id="v52" data-v="52" data-xref="利未记 11:35; 利未记 11:33; 利未记 14:44–45"> 不论那是衣服、羊毛或细麻织品，还是皮革制品，祭司都必须把它烧掉，因为那是恶性霉变，必须烧掉霉变的衣物。</span>
<span className="v" id="v53" data-v="53"> 如果祭司发现衣服、编织品或皮革上的霉斑没有蔓延，</span>
<span className="v" id="v54" data-v="54"> 就要吩咐人洗净衣物，再隔离七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结书 24:13; 希伯来书 6:4–8; 彼得后书 2:20–22"> 之后，祭司要再次检查洗过的衣物，若发现霉斑原样未变，即使没有蔓延，那衣物也是不洁净的。无论衣物里面还是外面霉变，都必须把它烧掉。</span>
<span className="v" id="v56" data-v="56"> 如果祭司发现洗过后霉斑退色，就要把霉变的部分从衣服、皮革、编织品上撕下来。</span>
<span className="v" id="v57" data-v="57" data-xref="马太福音 22:7; 启示录 21:8; 马太福音 3:12"> 以后衣物、编织品或皮革上若再次出现霉斑，便是旧患复发，要把它烧掉。</span>
<span className="v" id="v58" data-v="58" data-xref="列王纪下 5:14; 启示录 1:5; 诗篇 51:2"> 如果洗过衣服、编织品或皮革后，霉斑消失了，要再洗一次就洁净了。</span>
<span className="v" id="v59" data-v="59"> “羊毛衣、细麻衣、编织品或皮革制品出现霉变时，以上条例可用来鉴定这些衣物是否洁净。”</span>
</div>

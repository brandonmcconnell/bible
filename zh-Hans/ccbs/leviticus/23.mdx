## 安息日

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 19:3; 出埃及记 23:12; 出埃及记 35:2–3"> “你们一周可以工作六天，但第七天是完全休息的安息日，你们要举行圣会。不可做任何工，无论你们住在哪里，都要守耶和华的安息日。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 23:2; 出埃及记 23:14; 利未记 23:37"> “以下是耶和华所定的节期，你们要在这些日子召开圣会。</span>
</div>

## 逾越节和除酵节

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 申命记 16:1–8; 民数记 28:16–17"> “从一月十四日傍晚开始是耶和华的逾越节。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 34:18; 申命记 16:8; 出埃及记 12:15–16"> 从一月十五日开始是耶和华的除酵节，你们要连续七天吃无酵饼。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 28:18–25; 利未记 23:8; 利未记 23:21"> 在除酵节的第一天，你们要举行圣会，不可做日常工作。</span>
<span className="v" id="v8" data-v="8"> 一连七天你们要献火祭给耶和华。第七天，你们要举行圣会，不可做日常工作。”</span>
</div>
</div>

## 初熟节

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 34:26; 出埃及记 23:19; 申命记 16:9"> “你把以下条例告诉以色列人。 “你们进入耶和华将要赐给你们的那片土地以后，每逢收割庄稼之时，你们要带一捆初熟的谷物交给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 29:24; 利未记 10:14; 利未记 9:21"> 祭司要在安息日后第一天把那捆谷物在耶和华面前摇一摇，你们所献的就会得到悦纳。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:10–12; 彼得前书 1:19; 利未记 1:10"> 在献谷物那天，你们要献给耶和华一只毫无残疾、一岁的公羊羔作燔祭，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:14–16; 约珥书 1:9; 民数记 28:10"> 同时要把两公斤调油的细面粉作素祭，一起献给耶和华作馨香的火祭，也要献一升酒作奠祭。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 34:26; 创世记 4:4–5; 利未记 3:17"> 你们必须先将这些供物献给你们的上帝后，才可以吃饼、烘烤的谷物和新鲜穗子。不论住在哪里，这是你们世代当守的永久律例。</span>
</div>
</div>

## 五旬节

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 23:10–11; 利未记 25:8; 申命记 16:9–10"> “从安息日后第一天，即你们献上摇祭的那天算起，你们要数整整七周，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:1; 民数记 28:26"> 一直数到第七个安息日后的第一天，共五十天。到那天，你们要把新收的谷物作为素祭献给耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:10; 出埃及记 34:26; 出埃及记 34:22"> 你们要用两公斤细面粉加上酵，烤成两个饼作摇祭，从你们居住的地方带来献给耶和华作初熟之祭。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 28:27–31; 利未记 23:12–13; 玛拉基书 1:13–14"> 你们要把七只毫无残疾的一岁公羊羔、一头公牛犊、两只公绵羊和那两个饼，一起献给耶和华作燔祭。这些一起献上的燔祭、素祭和奠祭，是蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 28:30; 利未记 4:23–28; 利未记 7:11–18"> 你们也要献一只公山羊作赎罪祭，两只一岁的公绵羊作平安祭。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 18:4; 以弗所书 2:14; 民数记 18:8–12"> 祭司要把这两只公绵羊和初熟之物做的饼作为摇祭，在耶和华面前摇一摇。这些是献给耶和华的圣物，归祭司所有。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 23:2; 利未记 23:4; 民数记 18:23"> 你们要在那天召开圣会，不可做日常工作。不论住在哪里，这是你们世代当守的永久律例。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 24:19–21; 利未记 19:9–10; 以赛亚书 58:10"> 你们收割时，不可割尽田角地边的庄稼，也不可捡落在地里的，要把这些留给穷人和外族人。我是你们的上帝耶和华。”</span>
</div>
</div>

<div className="bp">

## 赎罪日

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华对摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 16:29–31; 出埃及记 30:10; 利未记 16:24"> “七月十日是赎罪日，你们要举行圣会，禁食，献火祭给耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 3:9; 利未记 16:34; 希伯来书 10:10"> 那是在你们的上帝耶和华面前为自己赎罪的日子，你们不可工作。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:14; 民数记 5:2; 利未记 23:27"> 那天，凡不禁食的，要将他从民中铲除；</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:3; 西番雅书 2:5; 耶利米书 15:7"> 凡在那天工作的，耶和华要毁灭他。</span>
<span className="v" id="v31" data-v="31"> 你们不可做任何工作。不论住在哪里，这是你们世代当守的永久律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:31; 马太福音 11:28–30; 诗篇 69:10–11"> 那是你们完全休息的安息日。从七月九日傍晚至次日傍晚，你们必须禁食。”</span>
</div>
</div>

## 住棚节

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华对摩西说：</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 7:2; 尼希米记 8:14; 以斯拉记 3:4"> “你把以下条例告诉以色列人。 “从七月十五日开始，你们要一连七天向耶和华守住棚节。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 23:24–25; 利未记 23:7–8"> 第一天，你们要举行圣会，不可做日常工作。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 8:18; 约翰福音 7:37; 历代志下 7:8–11"> 一连七天你们要献火祭给耶和华。第八天要举行圣会，献火祭给耶和华。这是庄严的聚会，你们不可做日常工作。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 23:2; 利未记 23:4; 传道书 3:1"> “以上是耶和华所定的节期。在这些节期里，你们要召开圣会，按规定的日子献给耶和华燔祭、素祭、奠祭和其他祭物。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 29:39; 利未记 19:3; 以斯拉记 2:68–69"> 除了守安息日并向耶和华献供物、还愿祭和自愿献的祭以外，你们还要守这些节期。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 23:16; 申命记 16:13; 利未记 23:34"> “你们收割完后，从七月十五日起，要一连七天庆祝耶和华的节期，第一天和第八天是完全休息的安息日。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 4:4; 启示录 7:9; 申命记 16:14–15"> 第一天，你们要摘下树上结的上好果子，折下棕树枝、叶子浓密的树枝与河边的柳枝，在你们的上帝耶和华面前欢庆七天。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 29:12; 尼希米记 8:18"> 在每年七月的这七天，你们要向耶和华守这节期。这是你们世代当守的永久律例。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 8:14–17; 创世记 33:17; 民数记 24:5"> 你们要搭棚居住七天，所有以色列人都要住在棚里。</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 31:10–13; 诗篇 78:5–6; 出埃及记 13:14"> 这样，你们的后代就会知道，我带领以色列人离开埃及后，曾让他们住在棚里。我是你们的上帝耶和华。”</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 23:1–2; 马太福音 18:20; 利未记 21:24"> 于是，摩西向以色列人宣布了耶和华所定的这些节期。</span>
</div>
</div>

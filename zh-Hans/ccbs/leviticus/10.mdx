## 拿答和亚比户之死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:61; 申命记 12:32; 利未记 16:12"> 亚伦的儿子拿答和亚比户各拿自己的香炉，点火加香，在耶和华面前献上凡火。他们这样做不合耶和华的吩咐。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 26:61; 民数记 16:35; 利未记 9:24"> 于是，有火从耶和华面前出来吞噬了他们，他们就死在耶和华面前。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:22; 利未记 21:6; 以赛亚书 49:3"> 摩西告诉亚伦：“耶和华曾说过，‘我要在事奉我的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“事奉我的人”希伯来文是“靠近我的人”。">a</a></sup>中显明我的圣洁，在所有子民面前彰显我的荣耀。’”亚伦默默无言。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:22; 出埃及记 6:18; 使徒行传 5:6"> 摩西叫来亚伦的叔父乌薛的儿子米沙利和以利撒反，对他们说：“过来，把你们弟兄的尸体从圣所前抬到营外去。”</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 8:13"> 他们就遵照摩西的吩咐，把仍穿着内袍的尸体抬到营外。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 22:18; 约书亚记 7:1; 民数记 16:22"> 摩西对亚伦和他剩下的两个儿子以利亚撒和以他玛说：“你们不要蓬头散发，也不要撕裂衣服，免得你们死亡，也免得耶和华向全体会众发怒。不过，你们的所有以色列同胞都可以为耶和华用火烧死的人哀伤。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:12; 利未记 8:30; 使徒行传 10:38"> 你们不可走出会幕门口，免得你们死亡，因为耶和华的膏油在你们身上。”他们就遵照摩西的话去做。</span>
</div>
</div>

## 有关祭司的条例

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华对亚伦说：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:15; 提摩太前书 3:3; 以弗所书 5:18"> “你和你儿子们进会幕前，淡酒烈酒都不可喝，免得你们死亡。这是你们世代当守的永久律例。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:26; 彼得前书 1:14–16; 利未记 11:47"> 你们必须区分什么是圣洁的、什么是世俗的，什么是洁净的、什么是不洁净的。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 28:20; 玛拉基书 2:7; 尼希米记 8:8"> 你们必须将我借摩西赐给以色列人的一切律例教导他们。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 21:22; 民数记 18:9–10; 利未记 7:9"> 摩西对亚伦及其两个儿子以利亚撒和以他玛说：“你们要把献给耶和华的火祭中剩下的素祭做成无酵饼，在坛边吃，因为这是至圣之物。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:3; 利未记 6:16; 民数记 18:10"> 你们要在圣洁之处吃，因为在献给耶和华的火祭中，这是你们和你们的子孙应得之份。这是耶和华对我的吩咐。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:11; 利未记 7:29–34; 出埃及记 29:24–28"> 至于作摇祭的胸肉和作举祭的腿肉，你们和你们的子孙可以在洁净的地方吃。因为在以色列人所献的平安祭中，这是你们应得之份。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 7:34; 创世记 17:13; 利未记 7:29–30"> 在献火祭的脂肪时，要把作举祭的腿肉和作摇祭的胸肉，一起带到耶和华面前作为摇祭摇一摇，这些永远是你们和你们的子孙应得之份，正如耶和华的吩咐。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 9:3; 利未记 9:15; 利未记 6:26"> 摩西到处寻找那只作赎罪祭的公山羊，却发现那只羊已经被焚烧了。他愤怒地对亚伦剩下的两个儿子以利亚撒和以他玛说：</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 7:6–7; 民数记 18:1; 利未记 6:24–30"> “你们为什么不在圣洁之处吃这赎罪祭？这是至圣之物，耶和华赐给你们是要叫你们为会众担罪，在耶和华面前为他们赎罪。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 6:30; 利未记 6:26"> 既然这祭牲的血没有被带进圣所，你们本应按照我的吩咐在圣洁之处吃这祭肉。”</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 9:12; 利未记 9:8; 耶利米书 14:12"> 亚伦对摩西说：“看啊，他们今天向耶和华献赎罪祭和燔祭，却有这样的灾祸发生在我身上。今天我如果吃了这赎罪祭的祭肉，耶和华会悦纳吗？”</span>
<span className="v" id="v20" data-v="20" data-xref="撒迦利亚书 7:8–9; 马太福音 12:20; 历代志下 30:18–20"> 摩西听了亚伦的回答，感到满意。</span>
</div>
</div>

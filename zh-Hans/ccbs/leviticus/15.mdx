## 有关漏症患者的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 3:7; 利未记 13:1; 利未记 11:1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 5:2; 撒母耳记下 3:29; 利未记 22:4"> “你们把以下条例告诉以色列人。<br />“如果有男人患了漏症，他下体的排泄物是不洁净的。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 23:20; 以西结书 16:26; 利未记 12:3"> 不论他下体的排泄物止住与否，他都是不洁净的。</span>
<span className="v" id="v4" data-v="4" data-xref="提多书 1:15; 以弗所书 5:11; 哥林多前书 15:33"> 他睡过的床或坐过的东西都不洁净。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:25; 利未记 16:26; 利未记 17:15"> 凡碰到他睡过的床的人都不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 4:8; 以赛亚书 1:16"> 凡坐他坐过之物的人都不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v7" data-v="7"> 凡碰到他的人都不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:4; 彼得后书 2:1–3; 以赛亚书 1:16"> 如果他吐唾沫在一个洁净的人身上，那人便不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:34"> 他骑过的鞍子是不洁净的。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 4:8; 诗篇 26:6; 利未记 15:8"> 凡碰到他坐过之物的人都不洁净，要等到傍晚才能洁净。碰到这些东西的人都不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v11" data-v="11"> 如果他没有洗手就碰到别人，那人便不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 6:28; 利未记 11:32–33; 哥林多后书 5:1"> 必须打碎他摸过的陶器，用水清洗他摸过的木器。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 14:8; 利未记 8:33; 利未记 15:28"> 他病愈后，必须经过七天的洁净期，要洗净衣服，用清水沐浴，这样就洁净了。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 12:8; 利未记 12:6; 希伯来书 10:10"> 第八天，他要把两只斑鸠或雏鸽带到会幕门前，在耶和华面前交给祭司献祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 14:30–31; 利未记 4:26; 马太福音 3:17"> 一只作赎罪祭，一只作燔祭。这样，祭司便在耶和华面前为他的漏症赎了罪。</span>
</div>
</div>

## 有关遗精的条例

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 23:10–11; 利未记 22:4; 利未记 15:5"> “男人若遗精，便不洁净，必须沐浴全身，等到傍晚才能洁净。</span>
<span className="v" id="v17" data-v="17"> 沾了精液的衣物或皮革都不洁净，必须用水清洗，等到傍晚才能洁净。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 15:5; 帖撒罗尼迦前书 4:3–5; 哥林多前书 6:12"> 如果男女同房，二人都不洁净，必须沐浴，等到傍晚才能洁净。</span>
</div>
</div>

## 有关女人月经的条例

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 12:2; 马太福音 15:19; 马可福音 5:25"> “女人在月经期间，要不洁净七天。凡碰到她的人都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 15:4–9; 箴言 2:16–19; 箴言 6:35"> 月经期间，她躺过或坐过的东西都不洁净。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 7:14; 哥林多后书 7:1; 以赛亚书 22:14"> 凡碰过她床的人都不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v22" data-v="22"> 人若碰到她坐过的地方，也不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v23" data-v="23"> 不论是她的床，还是她坐的东西，碰到的人都不洁净，要等到傍晚才能洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 20:18; 彼得前书 2:11; 利未记 18:19"> 男人若与她同房，沾染了她的经血，就要不洁净七天，他躺过的床也不洁净。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 5:25; 马太福音 9:20; 路加福音 8:43"> “女人若在经期以外多日血漏或经期过长，在此期间便不洁净，像在经期内一样。</span>
<span className="v" id="v26" data-v="26"> 在血漏期间，她躺的床或坐的东西都不洁净，像在经期内一样。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 15:21; 希伯来书 10:22; 利未记 17:15–16"> 凡碰到这些东西的人都不洁净，必须洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 15:13–15; 加拉太书 3:13; 以弗所书 1:6–7"> 血漏停止后，她要等七天才洁净。</span>
<span className="v" id="v29" data-v="29"> 第八天，她要把两只斑鸠或雏鸽带到会幕门口，交给祭司献祭，</span>
<span className="v" id="v30" data-v="30"> 一只作赎罪祭，一只作燔祭。这样，祭司便在耶和华面前为她赎了血漏的不洁之罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 19:20; 民数记 19:13; 以西结书 5:11"> 你们要使以色列人远离不洁之物，免得他们因不洁而玷污我设在他们中间的圣幕，以致死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 11:46; 利未记 13:59; 民数记 6:13"> 以上条例是为患漏症的人，包括遗精、</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 15:19; 利未记 20:18; 利未记 15:24–25"> 行经的女人、患漏症的男女、与不洁净女人同房的男人所设立的条例。</span>
</div>
</div>

</div>

## 安息年的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 加拉太书 4:24–25; 出埃及记 19:1"> 耶和华在西奈山上对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:21; 利未记 26:34–35; 出埃及记 23:10"> “你要告诉以色列人：你们到了我将要赐给你们的土地后，要让土地在耶和华面前守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:10"> 六年之内，你们可以耕种田地，修整葡萄园，收获出产。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 36:21; 利未记 25:20–23; 出埃及记 23:10–11"> 但第七年是要向耶和华守的安息年，土地要完全休息。你们不可耕种，不可修整葡萄园。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:29; 以赛亚书 37:30"> 不可收割自生自长的庄稼，也不可摘未经修剪而结的葡萄。这一年土地要完全休耕。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 2:44; 出埃及记 23:11; 使徒行传 4:34–35"> 但安息年间土地里自生自长的，你们和你们的仆婢、雇工与住在你们中间的外族人都可以吃，</span>
<span className="v" id="v7" data-v="7"> 你们的牲畜和境内的野兽也可以吃。</span>
</div>
</div>

## 禧年的条例

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 23:15; 创世记 2:2"> “你们要计算七个安息年，即七个七年，共四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:24; 利未记 23:27; 帖撒罗尼迦前书 1:8"> 第五十年的七月十日赎罪日那天，你们要在境内各地吹号。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:8; 以赛亚书 63:4; 彼得前书 2:16"> 你们要以这一年为圣年，向境内所有居民宣告自由。这一年将成为你们的禧年。你们要各归祖业，各回本家。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 27:17; 利未记 25:4–5"> 第五十年是你们的禧年。这一年你们不可耕种，不可收割自生自长的庄稼，也不可摘未经修剪而结的葡萄。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 25:6–7"> 这是禧年，是你们的圣年，你们可以吃土地里自生自长的。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 25:10; 利未记 27:17–24; 民数记 36:4"> 在禧年，各人要回到祖业。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 19:13; 利未记 25:17; 撒母耳记上 12:3–4"> 因此，你们和同胞买卖田地时，不可彼此亏负。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:18–23; 腓立比书 4:5"> 买卖双方要按照距下个禧年的年数和收成的年数定价。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 25:27; 利未记 25:51"> 距下个禧年的年数多，价钱就高；年数少，价钱就低。因为卖的是田地收成的次数。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 19:14; 利未记 19:32; 利未记 25:43"> 要敬畏你们的上帝，不可彼此亏负。我是你们的上帝耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 23:6; 申命记 12:10; 箴言 1:33"> 你们要遵行我的律例，持守我的典章，就可以在那片土地上安居。</span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:26; 诗篇 85:12; 利未记 26:5"> 土地会出产丰富，使你们丰衣足食、安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 25:4; 路加福音 12:29; 民数记 11:4"> 你们可能会问，‘第七年不种不收，我们吃什么？’</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 28:8; 箴言 10:22; 哥林多后书 9:10"> 我要在第六年赐福给你们，使田地的出产够你们吃三年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 19:29; 利未记 26:10; 以赛亚书 37:30"> 第八年开始耕种时，你们仍会吃陈粮，一直吃到第九年的收割季节。</span>
</div>
</div>

## 赎回土地的条例

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:11; 诗篇 39:12; 以西结书 48:14"> “你们不可永远卖掉土地，因为土地是我的，你们只不过是寄居在那片土地上的过客。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 1:7; 利未记 25:51–53; 利未记 25:27"> 你们购买每一块土地时，都必须让原主保留赎回的权利。</span>
<span className="v" id="v25" data-v="25" data-xref="路得记 2:20; 耶利米书 32:7–8; 路得记 3:12"> 如果有人因贫穷而卖掉土地，他的近亲要把卖掉的土地赎回来。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 5:7"> 如果无人为他赎回，而他自己渐渐富裕起来，有能力赎回，</span>
<span className="v" id="v27" data-v="27"> 他要计算卖掉土地的年数，退还距下个禧年所剩年数的地价，便可以赎回自己的土地。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 35:9–10; 利未记 25:10; 彼得前书 1:4–5"> 如果他没有能力赎回，所卖的土地在禧年之前要属于买主。到了禧年，买主必须把土地归还原主。</span>
</div>
</div>

## 赎回房屋的条例

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29"> “如果有人卖掉自己城里的房子，要保留一年赎回权。卖掉房子的一年之内，他可以赎回。</span>
<span className="v" id="v30" data-v="30"> 如果一年之内他没有赎回，房子便永远归买主所有，就是到了禧年也不用归还。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 49:7–8"> 如果房子在四围无墙的乡村，要视房子为乡下的土地，原主可以赎回；到了禧年，买主必须将房子归还。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:1–45; 民数记 35:1–8"> 在利未人的城邑里，利未人永远有权赎回所卖的房子。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:20–24; 申命记 18:1–2"> 如果他们没有赎回，到了禧年要把房子归还他们，因为在利未人的城里，利未人的房屋是他们在以色列人中所拥有的产业。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 25:23; 使徒行传 4:36–37; 民数记 35:2–5"> 但不可出卖利未人城郊的草场，那是他们永远拥有的产业。</span>
</div>
</div>

## 照顾同胞的条例

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命记 15:7–8; 使徒行传 11:29; 利未记 25:25"> “如果你们的同胞生活日益贫穷，难以维生，你们要像照顾外族人和寄居者一样照顾他的生活，让他住在你们当中。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 22:25; 申命记 23:19–20; 以西结书 18:8"> 不可向他放债取利，要敬畏你们的上帝，让他住在你们当中。</span>
<span className="v" id="v37" data-v="37"> 你们借钱给他，不可收取利息；借粮给他，不可谋利。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 11:45; 民数记 15:41; 出埃及记 20:2"> 我是你们的上帝耶和华。我曾经带领你们离开埃及，为要把迦南赐给你们，并做你们的上帝。</span>
</div>
</div>

## 买卖奴隶的条例

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 21:2; 列王纪上 9:22; 列王纪下 4:1"> “如果你们的同胞穷得把自己卖给你们，不可把他当作奴隶，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 21:2–3"> 要待他像雇工和寄居者一样。他要为你工作到禧年。</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 25:28; 出埃及记 21:3; 约翰福音 8:32"> 到了禧年，他和孩子们便可以离开你们，回到自己的宗族和祖业。</span>
<span className="v" id="v42" data-v="42" data-xref="利未记 25:55; 罗马书 6:22; 哥林多前书 7:21–23"> 因为以色列人是我的仆人，是我从埃及带出来的，所以他们不可卖身为奴。</span>
<span className="v" id="v43" data-v="43" data-xref="歌罗西书 4:1; 利未记 25:46; 出埃及记 1:13–14"> 你们也不可苛待他们，要敬畏你们的上帝。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 12:44; 诗篇 2:8–9; 以赛亚书 14:1–2"> 你们可以从邻国购买奴隶，</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 56:3–6"> 也可以买居住或出生在你们境内的外族人。这些人可以作你们的产业。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 14:2; 利未记 25:43"> 你们可以将他们作为产业传给你们的子孙，使他们终身做奴隶。但你们不可苛待自己的同胞。</span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 2:5; 利未记 25:26; 撒母耳记上 2:7–8"> “如果你们中间的外族人渐渐富裕，你们同胞中却有人日益贫穷，把自己卖给外族人或他们的族人，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 5:5; 希伯来书 2:11–13; 利未记 25:35"> 他可以保留赎身的权利。他的兄弟、</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 25:26"> 叔伯、堂兄弟或其他近亲都可以赎回他。如果他富裕起来，也可以赎回自己。</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 16:14; 以赛亚书 21:16; 利未记 25:53"> 他要和买主计算从自己卖身为奴到下个禧年之间的年数，然后按雇工的工价，照年数计算赎价。</span>
<span className="v" id="v51" data-v="51"> 如果离禧年还有很多年，他就要按年数和当初卖价的比例偿还赎价。</span>
<span className="v" id="v52" data-v="52"> 如果离禧年只有不多的几年，他就要按年数偿还赎身费。</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 25:46; 利未记 25:43"> 买主要待他如按年雇用的工人。你们要确保买主不会苛待他。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 21:2–3; 利未记 25:40–41; 以赛亚书 49:9"> 如果禧年来临前他没有被赎回，到了禧年他和孩子们都要获得自由。</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 25:42; 以赛亚书 43:3; 出埃及记 13:3"> 因为以色列人是我的仆人，是我从埃及领出来的仆人。我是你们的上帝耶和华。</span>
</div>
</div>

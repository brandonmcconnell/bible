## 各种罪的惩处条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 21:21; 利未记 18:21; 利未记 20:27"> “你要告诉以色列人：在你们或寄居在你们中间的外族人中，如果有人把子女献给假神摩洛，必须处死他，当地的人要用石头打死他。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 18:21; 以西结书 5:11; 以西结书 23:38–39"> 我也必严惩那人，将他从民中铲除。因为他把子女献给摩洛，玷污我的圣所，亵渎我的圣名。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 17:2–5; 使徒行传 17:30; 列王纪上 20:42"> 如果那地方的人对此置之不理，没有处死那人，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:39; 何西阿书 2:13; 何西阿书 2:5"> 我必严惩那人及其家人，从民中铲除他和那些追随他与摩洛苟合的人。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 19:31; 以赛亚书 8:19; 利未记 20:27"> 如果有人求问灵媒或巫师，与他们苟合，我必严惩，将他从民中铲除。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 11:44; 利未记 19:2; 彼得前书 1:15–16"> 你们要分别出来，做圣洁的人，因为我是你们的上帝耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 31:13; 雅各书 1:22; 帖撒罗尼迦前书 5:23"> 你们要遵行我的律例。我是使你们圣洁的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 21:17; 马可福音 7:10; 申命记 27:16"> “咒骂父母的，必被处死。他咒骂父母，罪有应得。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:4–5; 申命记 22:22–24; 申命记 5:18"> 如果有人与别人的妻子通奸，奸夫淫妇必须被处死。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 27:20; 申命记 27:23; 阿摩司书 2:7"> 如果有人与父亲的妻妾同寝，就是羞辱他的父亲。要把二人处死，他们罪有应得。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:15; 利未记 18:23; 创世记 38:18"> 如果有人与儿媳同寝，二人都必须被处死。他们乱伦，罪有应得。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 6:9; 利未记 18:22; 犹大书 1:7"> 如果男人与男人同寝，好像男人与女人同寝一样，他们的行为可憎，必须被处死。他们罪有应得。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 18:17; 申命记 27:23; 约书亚记 7:15"> 如果有人娶妻，又娶岳母，便是大恶。要把他们三人烧死，使你们杜绝这种败坏之事。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 18:23; 申命记 27:21; 出埃及记 22:19"> 如果有男人与兽类交合，他和兽都要被处死。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:32; 出埃及记 19:13; 希伯来书 12:20"> 如果有女人与兽类交合，女人和兽都要被处死。他们必须被处死，他们罪有应得。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 18:9; 申命记 27:22; 以西结书 22:11"> “如果有人娶了同父异母或同母异父的姊妹，这是可耻之事，必须公开铲除他们。他与自己的姊妹乱伦，羞辱了她，要承担自己的罪。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 15:24; 利未记 18:19; 以西结书 18:6"> 如果有人与经期的女人同寝，他就暴露了女人的血泉，女人也自露血泉。要将他们二人从民中铲除。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 18:6; 利未记 18:12–30; 出埃及记 6:20"> 不可与姨母或姑母乱伦，因为这是羞辱自己的亲人。二人要承担自己的罪。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 18:14; 约伯记 18:19; 路加福音 23:29"> 如果有人与伯母或婶母同寝，就是羞辱他的伯父或叔父。二人要承担自己的罪，必无子女而死。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 18:16; 马太福音 14:3–4"> 如果有人娶兄嫂或弟媳，这是污秽行为，羞辱了自己的兄弟。二人必无儿无女。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 18:25–28; 以西结书 36:27; 利未记 18:4–5"> “你们要遵行我的一切律例和典章，免得我要带你们去居住的那片土地把你们吐出去。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:5; 利未记 18:24; 利未记 18:30"> 我要在你们面前赶走那片土地上的各族，你们不要随从他们的习俗。他们做了以上那些事，所以我厌恶他们。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 14:2; 出埃及记 6:8; 申命记 7:6"> 我曾说你们必占据他们的土地，我要把那片奶蜜之乡赐给你们作产业。我是你们的上帝耶和华，我已经把你们从万族中分别出来。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 14:3–21; 利未记 11:1–47; 使徒行传 10:11–15"> 所以，你们要区分洁净和不洁净的兽类与鸟类。不可吃那些我视为不洁净的飞禽、走兽和爬虫，以免玷污自己。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:15–16; 利未记 20:7; 利未记 20:24"> 你们要圣洁，因为我耶和华是圣洁的。我把你们从万族中分别出来，使你们做我的子民。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 19:31; 利未记 20:6; 撒母耳记上 28:7–9"> 如果有人做灵媒或巫师，不论男女，都必须被处死。你们要用石头打死他们，他们罪有应得。”</span>
</div>
</div>

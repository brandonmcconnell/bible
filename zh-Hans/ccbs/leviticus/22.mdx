## 吃圣物的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 18:21; 申命记 15:19; 利未记 22:32"> “你告诉亚伦父子们要谨慎处理以色列人献给我的圣物，免得亵渎我的圣名。我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 7:20–21; 民数记 19:13; 诗篇 16:11"> “你告诉他们：你们世世代代的子孙中，如果有人不洁净，却接近以色列人分别出来献给我的圣物，必须把他从我面前铲除。我是耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:39; 利未记 15:2–3; 利未记 15:13–16"> 亚伦的子孙中若有人患了麻风病或漏症，在他洁净之前，不可吃圣物。如果有人遗精，或碰到因接触尸体而不洁净之物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:43–44; 利未记 15:7; 利未记 15:19"> 或碰到不洁净的爬虫，或碰到任何使他不洁净的爬虫或人，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 15:5; 希伯来书 10:22; 哈该书 2:13"> 这人就不洁净，要到傍晚之后才能洁净。他要沐浴后才可吃圣物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:22; 申命记 18:3–4; 哥林多前书 9:13–14"> 日落之后，他就洁净了，可以吃圣物，因为那是他应得的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 17:15; 出埃及记 22:31; 以西结书 44:31"> 他不可吃自然死亡或被野兽撕裂的动物，免得因此而不洁净。我是耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 28:43; 民数记 18:22; 民数记 18:32"> 他们要遵守我的命令，免得他们犯罪，因亵渎我的命令而死亡。我是使他们圣洁的耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 12:4; 撒母耳记上 21:6; 出埃及记 29:33"> “祭司家以外的人不可吃圣物，在祭司家中寄居的或做雇工的都不可吃，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:13; 出埃及记 12:44; 民数记 18:11–13"> 但出生在祭司家里或祭司用钱买来的奴隶都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:13; 利未记 21:3"> 如果祭司的女儿嫁给本族以外的人，她便不可再吃圣洁的举祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 10:14; 创世记 38:11; 民数记 18:11–19"> 如果祭司的女儿守寡或被休，无儿无女，又像年轻时回到父亲家居住，便可以吃父亲的食物。除此以外，不属于祭司家的人都不可吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:15; 利未记 27:13; 利未记 5:15–19"> 任何人如果误吃圣物，就要如数偿还给祭司，并加赔五分之一。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 18:32; 利未记 19:8; 以西结书 22:26"> 祭司不可亵渎以色列民众献给耶和华的圣物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 22:9; 彼得前书 2:24; 以赛亚书 53:11–12"> 以免因擅自吃圣物而担罪、受罚。我是使他们圣洁的耶和华。”</span>
</div>
</div>

## 选择祭牲的条例

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 1:2; 申命记 12:6; 民数记 15:3"> “你要告诉亚伦父子们及所有以色列人：任何以色列人或寄居在以色列的外族人，若向耶和华献燔祭，无论是为了还愿还是出于自愿，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 1:10; 利未记 1:3; 以弗所书 5:27"> 都必须献毫无残疾的公牛、公绵羊或公山羊才能蒙悦纳。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 17:1; 玛拉基书 1:8; 申命记 15:21"> 不可献有残疾的，因为不蒙悦纳。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 15:8; 民数记 15:3; 利未记 3:6"> 如果有人为了还愿或自愿献牛羊作平安祭给耶和华，必须献毫无残疾的牛羊才能蒙悦纳。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:20; 玛拉基书 1:8; 利未记 1:9"> 不可献给耶和华瞎眼的、伤残的、断肢的、长疥癣的牲畜，也不可把这些牲畜献给耶和华作火祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:18"> 至于畸形或发育不全的公牛或绵羊羔，可以用作自愿献的祭，但用作还愿祭将不蒙悦纳。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 22:20; 申命记 23:1; 利未记 21:20"> 不可献给耶和华睪丸受损、被压碎、破裂或被阉割的牲畜。在你们境内不可做这样的事，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 21:8; 以斯拉记 6:8–10; 民数记 15:14–16"> 也不可从外族人手中接受这类牲畜，来献给你们的上帝作食物。因为这些牲畜是畸形的、残疾的，不蒙悦纳。”</span>
<span className="v" id="v26" data-v="26"> 耶和华对摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:30; 利未记 19:23–24; 利未记 22:25"> “刚出生的牛、绵羊或山羊，前七天要与母亲在一起。从第八天起，把它们献给我作火祭必蒙悦纳。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 22:6–7; 申命记 14:21; 出埃及记 34:26"> 不可在同一天内宰杀母牛和小牛或母羊和小羊。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 116:17; 诗篇 107:22; 阿摩司书 4:5"> 你们献感恩祭给耶和华时，要使你们所献的蒙悦纳。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 7:15–18; 出埃及记 16:19–20; 利未记 19:7"> 要当天吃完祭物，不可留到早晨。我是耶和华。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 4:40; 利未记 19:37; 民数记 15:40"> 你们要遵行我的一切诫命。我是耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:21; 路加福音 11:2; 马太福音 6:9"> 不可亵渎我的圣名，我要在以色列人中被尊为圣，我是使你们圣洁的耶和华。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 11:45; 出埃及记 6:7; 利未记 25:38"> 我领你们离开埃及，是要做你们的上帝。我是耶和华。”</span>
</div>
</div>

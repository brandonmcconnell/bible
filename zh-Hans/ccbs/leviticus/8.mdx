## 膏立亚伦父子们做祭司

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:2–4; 出埃及记 39:41; 希伯来书 7:27"> “你把亚伦父子们带来，也要带圣衣、膏油、一头作赎罪祭的公牛、两只公绵羊和一篮无酵饼，</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 30:13; 使徒行传 2:1; 尼希米记 8:1"> 然后把全体会众招聚到会幕门前。”</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 39:26; 出埃及记 39:7; 出埃及记 39:5"> 摩西按照耶和华的指示行事，会众都聚集在会幕门前。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:4–37"> 摩西告诉会众：“这是耶和华吩咐我做的事。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 6:11; 以弗所书 5:26; 出埃及记 29:4"> 他把亚伦父子们带来，用水洗他们。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 以赛亚书 61:10; 加拉太书 3:27"> 摩西给亚伦穿上内袍，束上腰带，穿上外袍，套上以弗得，用精巧的带子把以弗得系在亚伦身上，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:63; 帖撒罗尼迦前书 5:8; 以赛亚书 59:17"> 然后给他戴上胸牌，把乌陵和土明放在胸牌内，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 2:9–11; 撒迦利亚书 6:11–14; 出埃及记 28:36–38"> 再把礼冠戴在他头上，在礼冠前系上金牌，即圣冠，都遵照耶和华的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:9–11; 利未记 8:2; 出埃及记 30:23–29"> 摩西拿膏油抹圣幕和圣幕里的一切物件，使它们圣洁；</span>
<span className="v" id="v11" data-v="11" data-xref="提多书 3:6; 出埃及记 30:29; 出埃及记 16:19"> 再用膏油在祭坛上洒七次，又抹祭坛和祭坛上的器具、洗濯盆和盆座，使它们圣洁。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:30; 诗篇 133:2; 出埃及记 29:7"> 然后，摩西把膏油倒在亚伦头上膏立他，使他圣洁。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:8–9; 启示录 5:10; 启示录 1:6"> 摩西又把亚伦的儿子们带来，给他们穿上内袍，束上腰带，戴上头巾，都遵照耶和华的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 43:19; 诗篇 66:15; 彼得前书 3:18"> 摩西牵来那头作赎罪祭的公牛，亚伦父子们把手按在牛头上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 4:7; 希伯来书 9:18–23; 以西结书 43:19–27"> 摩西宰了牛，用手指蘸一些牛血抹在祭坛凸起的四角上，以洁净祭坛，再把剩下的血倒在坛脚，使祭坛圣洁，为祭坛赎罪。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:13; 利未记 3:3–5; 利未记 4:8–9"> 他取出内脏上的脂肪、肝叶、两个肾脏和肾脏上的脂肪，放在祭坛上烧掉，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:11–12; 出埃及记 29:14; 利未记 6:30"> 又照耶和华的吩咐，把公牛的皮、肉和粪便带到营外烧掉。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 8:2; 利未记 1:4–13; 出埃及记 29:15–18"> 然后，摩西献上作燔祭的公绵羊，亚伦父子们把手按在羊头上。</span>
<span className="v" id="v19" data-v="19"> 摩西宰了那只羊，把血洒在祭坛四周；</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 1:8"> 把羊切成块，焚烧羊头、肉块和脂肪；</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 5:2; 出埃及记 29:18; 利未记 1:17"> 用水洗净羊的内脏和腿，把整只羊放在祭坛上焚烧，这是燔祭，作蒙耶和华悦纳的馨香火祭，都遵照耶和华的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 8:2; 利未记 8:29; 出埃及记 29:19–31"> 摩西献上另一只为授圣职而献的公绵羊。亚伦父子们把手按在羊头上。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:20; 利未记 14:14; 罗马书 12:1"> 摩西宰了羊，将一些羊血抹在亚伦的右耳垂、右手大拇指和右脚大脚趾上。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:18–22"> 他又把亚伦的儿子们带来，将一些血抹在他们的右耳垂、右手大拇指和右脚大脚趾上，然后把剩下的血都洒在祭坛四周。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 3:9; 利未记 3:3–5; 以赛亚书 53:10"> 他取下羊的脂肪、肥尾巴、内脏上的脂肪、肝叶、两个肾脏、肾脏上的脂肪和右腿，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:23; 提摩太前书 2:5; 使徒行传 5:12"> 又从放在耶和华面前盛无酵饼的篮子里取一个无酵饼、一个油饼和一个薄饼，放在羊的右腿和脂肪上。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:21; 希伯来书 9:14; 出埃及记 29:24–37"> 他把这些都放在亚伦父子们手中，作为摇祭在耶和华面前摇一摇。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 29:25; 诗篇 22:13–14; 希伯来书 10:14–22"> 随后，他从他们手上拿过这些祭物，放在祭坛的燔祭上焚烧，作为授圣职时献的祭。这是蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:31; 彼得前书 4:11; 利未记 7:30–34"> 摩西又把公绵羊的胸肉作为摇祭在耶和华面前摇一摇，这是他授圣职时所应得之份，都遵照耶和华的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 29:21; 民数记 3:3; 出埃及记 30:30"> 摩西拿了一些膏油和坛上的血，洒在亚伦和他的衣服上，也洒在他儿子们和他们的衣服上，使亚伦父子们和他们的衣服圣洁。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 29:31–32; 加拉太书 2:20; 撒母耳记上 2:13–17"> 摩西对亚伦父子们说：“你们要照我的吩咐在会幕门口煮祭肉吃，也要吃篮子里为授圣职而献的饼。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 29:34; 出埃及记 12:10; 希伯来书 3:13–14"> 吃剩的肉和饼，你们要烧掉。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 29:35; 民数记 19:12; 以西结书 43:25–27"> 你们的授圣职礼历时七天，这七天之内，你们不可离开会幕门口。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:27; 希伯来书 7:16; 希伯来书 10:11–12"> 今天所做的这一切都是耶和华吩咐的，是为你们赎罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 3:7; 申命记 11:1; 列王纪上 2:3"> 七天之内，你们必须日夜待在会幕门口，要遵守耶和华的吩咐，免得你们死亡。这是耶和华对我的吩咐。”</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 12:32; 申命记 4:2; 出埃及记 40:16"> 于是，亚伦父子们遵行了耶和华借摩西吩咐的一切。</span>
</div>
</div>

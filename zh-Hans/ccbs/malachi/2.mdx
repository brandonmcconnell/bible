<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="何西阿书 5:1; 玛拉基书 1:6; 耶利米书 13:13"> 祭司们啊，这诫命是传给你们的。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:18; 启示录 14:7; 诗篇 69:22"> 万军之耶和华说：“如果你们不听从我的话，也不从内心尊崇我的名，我必使咒诅临到你们，把你们的福气变成咒诅。其实我已经咒诅了你们，因为你们不把我的诫命放在心上。</span>
<span className="v" id="v3" data-v="3" data-xref="那鸿书 3:6; 玛拉基书 2:9; 约伯记 20:7"> 我必斥责你们的子孙，把你们祭牲的粪便抹在你们脸上，又把你们和粪便一同丢掉，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 3:12; 以西结书 38:23; 马太福音 3:12"> 你们便知道我这样告诫你们，是为了使我与你们祖先利未所立的约坚立。这是万军之耶和华说的。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 25:12–13; 以西结书 34:25; 以西结书 37:26"> 我与他所立的是生命和平安之约，我将生命和平安赐给他，使他心存敬畏。他就尊崇我，敬畏我的名。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 12:3; 提摩太后书 2:15–16; 启示录 14:5"> 他口中教导真理，嘴里毫无诡诈。他带着平安和正直与我同行，并引导许多人远离罪恶。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 2:24–25; 利未记 10:11; 申命记 21:5"> 祭司的嘴唇应持守知识，民众应从他口中寻求训诲，因为他是万军之耶和华的使者。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 13:29; 耶利米书 18:15; 以赛亚书 30:11"> 然而，你们却偏离正道，你们的教导使许多人跌倒，你们破坏了我和利未所立的约。这是万军之耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 2:30; 申命记 1:17; 马太福音 19:17–18"> 因此，我必使你们在众人面前被藐视和轻贱。因为你们不遵守我的道，在教导上偏心待人。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 100:3; 玛拉基书 2:11; 哥林多前书 8:6"> 我们岂不有同一位父亲吗？岂不由同一位上帝所造吗？为何要彼此欺骗，背弃上帝与我们祖先所立的约呢？</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 6:14–18; 以斯拉记 9:1–2; 尼希米记 13:23–29"> 犹大人不忠贞，在以色列和耶路撒冷做了可憎的事，他们娶信奉外邦神明的女子为妻，亵渎了耶和华所爱的圣所。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:29; 利未记 20:3; 以西结书 24:21"> 愿耶和华从雅各的帐篷中铲除所有做这事并献供物给万军之耶和华的人！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:11–15; 耶利米书 14:12; 诗篇 78:34–37"> 另外，你们痛哭哀号，眼泪甚至淹没了耶和华的祭坛，因为耶和华不再理会你们的供物，不再悦纳你们所献的。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 2:15; 传道书 9:9; 以赛亚书 54:6"> 你们还问为什么。因为耶和华在你和你的发妻中间作证，她是你的配偶，是你盟约的妻子，你却对她不忠。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 19:4–6; 玛拉基书 2:14; 马可福音 10:6–8"> 上帝不是把你们合为一体，叫你们肉体和心灵都归祂吗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此句希伯来文语意不清。">a</a></sup>？祂为何这样做？是为了得敬虔的后裔。所以，你们要小心谨慎，不可对自己的发妻不忠。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 19:3–9; 马太福音 5:31–32; 马可福音 10:2–12"> 以色列的上帝耶和华说：“我憎恶休妻和暴虐待妻的人。所以你们要小心谨慎，不可不忠。”这是万军之耶和华说的。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 43:24; 彼得后书 3:3–4; 传道书 8:11"> 你们说的话使耶和华厌烦，然而你们还说：“我们哪里令祂厌烦了？”因为你们说：“耶和华视作恶者皆为好人，并且喜悦他们。”还说：“公义的上帝在哪里？”</span>
</div>

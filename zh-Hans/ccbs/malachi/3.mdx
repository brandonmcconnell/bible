<span className="v" id="v4" data-v="4" data-xref="历代志下 7:1–3; 以赛亚书 56:7; 撒迦利亚书 8:3"> 这样，犹大和耶路撒冷所献的祭物就会蒙耶和华悦纳，如同以往的日子、从前的岁月。</span>

## 十分之一奉献

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 23:19; 希伯来书 13:8; 雅各书 1:17"> “我耶和华永恒不变，所以你们这些雅各的子孙才没有灭绝。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 1:3; 罗马书 10:21; 罗马书 10:3"> 从你们祖先开始，你们就常常偏离我的律例，不肯遵从。现在你们要转向我，我就转向你们。这是万军之耶和华说的。可是你们竟然说，‘我们该怎样转向你呢？’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 3:9–10; 马太福音 22:21; 马可福音 12:17"> “人怎可抢夺上帝的东西呢？可是你们不但抢夺我的东西，还说，‘我们哪里抢过你的东西？’<br />“你们在十分之一的奉献和其他供物上抢夺我的东西。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 28:15–19; 哈该书 1:6–11; 哈该书 2:14–17"> 举国上下都是如此，所以你们必受咒诅。”</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 9:6–8; 马太福音 6:33; 箴言 3:9–10"> 万军之耶和华说：“你们要把当纳的十分之一全部送到我的仓库，使我的殿中有粮。你们这样试试，看我会不会为你们打开天上的窗户，把祝福倾倒给你们，直到无处可容。”</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 11:14; 约珥书 2:22; 撒迦利亚书 8:12"> 万军之耶和华说：“我必为你们驱除害虫，不许它们毁坏你们地里的出产，你们田间的葡萄必不会未熟先落。”</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 61:9; 以赛亚书 62:4; 撒迦利亚书 8:23"> 万军之耶和华说：“万国必称你们为有福的，因为这地方必成为一片乐土。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 2:17; 以赛亚书 37:23; 罗马书 9:20"> 耶和华说：“你们出言毁谤我，还问，‘我们哪里毁谤你了？’</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 58:3; 西番雅书 1:12; 诗篇 73:8–13"> 你们说，‘事奉上帝是虚空的。遵从上帝的吩咐，在万军之耶和华面前痛悔有什么益处？</span>
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 4:1; 耶利米书 12:1–2; 玛拉基书 2:17"> 如今我们称狂傲的人有福。作恶的人凡事顺利，他们虽然试探上帝，却仍能逃过灾祸。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 20:12; 诗篇 56:8; 玛拉基书 4:2"> 那时，敬畏耶和华的彼此交谈，耶和华必留心倾听，祂面前的纪念册上记录着敬畏祂和尊崇祂名的人。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 19:5; 申命记 7:6; 哥林多后书 6:18"> 万军之耶和华说：“到我所定的日子，他们必成为我宝贵的产业，我要怜悯他们，如同父亲怜悯他的孝顺儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 25:46; 诗篇 58:10–11; 创世记 18:25"> 那时，你们将再度看出义人与恶人之间的区别，事奉上帝者和不事奉上帝者之间的不同。</span>
</div>
</div>

## 在摩押立约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 5:2–3; 希伯来书 8:9; 出埃及记 24:2–8"> 耶和华除了与以色列人在何烈山立约外，还在摩押吩咐摩西与以色列人立以下的约。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:4; 出埃及记 8:12; 约书亚记 24:5–6"> 摩西召来所有以色列人，对他们说：“你们曾亲眼见过耶和华在埃及怎样对付法老及其臣仆和国民，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:32–35; 尼希米记 9:9–11; 申命记 7:18–19"> 亲眼看见祂怎样降下巨大的灾难，行伟大的神迹奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:18; 以赛亚书 6:9–10; 箴言 20:12"> 但耶和华至今还没有赐给你们能明白的心、能看见的眼、能听清的耳。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 8:4; 尼希米记 9:21; 申命记 8:2"> 四十年来，耶和华领你们走过旷野，你们身上的衣服没有穿破，脚上的鞋没有穿坏；</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:3; 以弗所书 5:18; 哥林多前书 9:25"> 你们没有吃饼，也没有喝淡酒和烈酒。这是为了让你们知道耶和华是你们的上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:24–17; 民数记 32:33–42; 诗篇 135:10–12"> 我们来到这里的时候，希实本王西宏和巴珊王噩都出来攻击我们，我们击败了他们，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 3:12–13; 民数记 32:33"> 并将占领的土地分给吕便支派、迦得支派和玛拿西半个支派作产业。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:3; 申命记 4:6; 路加福音 11:28"> 所以，你们要谨遵这约上的话，以便凡事顺利。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约珥书 2:16–17; 启示录 20:12; 申命记 31:12–13"> “今天，你们全都站在你们的上帝耶和华面前，包括你们的族长、长老、官员、所有以色列男子、</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:38; 约书亚记 9:21–27; 出埃及记 12:48–49"> 你们的孩子、妻子和寄居在你们营中为你们砍柴挑水的外族人，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:12–15; 列王纪下 11:17; 申命记 5:2–3"> 为要接受你们的上帝耶和华今天与你们立的誓约。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 6:7; 创世记 17:7; 申命记 28:9"> 这样，祂今天将确立你们作祂的子民、祂作你们的上帝，正如祂对你们的应许和对你们祖先亚伯拉罕、以撒和雅各的誓言。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:31–34; 希伯来书 8:7–12"> 耶和华的这誓约不仅是与你们立的，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:39; 哥林多前书 7:14; 耶利米书 50:5"> 也是与今天一同站在我们的上帝耶和华面前的人，以及今天不在这里的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“今天不在这里的人”或译“我们将来的子孙”。">a</a></sup>立的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 2:19; 申命记 2:9; 申命记 2:4"> “你们知道我们如何在埃及生活，也知道我们如何穿越列国来到这里。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:36"> 你们也见过他们可憎的木、石、金、银偶像。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:15; 申命记 11:16–17; 申命记 13:1–15"> 你们中间，不论男人或女人，家族或支派，切不可有人背弃我们的上帝耶和华，去祭拜列国的神明，你们中间切不可有残根长出苦毒的果实，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:24; 民数记 15:30; 民数记 15:39"> 免得有人听了这誓言后，心存侥幸地说，‘即使我一意孤行，连累他人，也必平安无事。’</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 74:1; 诗篇 79:5; 申命记 9:14"> 耶和华绝不会赦免这样的人，祂必向这样的人发烈怒和义愤，使记在这书上的一切咒诅临到他身上，从世上抹去他的名字。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:41; 约书亚记 7:1–26; 以西结书 13:9"> 耶和华必把他从以色列各支派中隔离出来，使他按律法书上约中的一切咒诅受惩罚。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 19:8"> “你们的子孙后代和从远方来的外族人，必看见耶和华降在这地方的灾祸和疾病。</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅书 2:9; 耶利米书 17:6; 以赛亚书 34:9"> 遍地将是硫磺和盐，无法耕种，寸草不生，如同耶和华盛怒之下毁灭的所多玛、蛾摩拉、押玛和洗扁。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 22:8–9; 列王纪上 9:8–9; 罗马书 2:5"> 万国必问，‘耶和华为什么要这样对待这地方？祂为什么大发烈怒？’</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:9; 以赛亚书 47:6; 耶利米书 50:7"> 必有人回答说，‘因为这地方的人背弃了他们祖先的上帝耶和华领他们出埃及时与他们所立的约，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:64; 士师记 2:12–13; 士师记 5:8"> 去供奉其他神明，祭拜他们不认识、也非耶和华分派给他们的神明。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 9:11–14; 申命记 28:15–68; 申命记 27:15–26"> 因此，耶和华向这片土地发怒，把这书上写的一切咒诅都降在这里。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 7:20; 列王纪上 14:15; 诗篇 52:5"> 耶和华在怒气、义愤和烈怒中把他们从这地方连根拔起，扔到别的地方，正如今日的情形。’</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:22; 使徒行传 1:7; 罗马书 11:33–34"> “奥秘的事属于我们的上帝耶和华，只有显明的事永远属于我们和我们的子孙，以便我们可以遵守这律法上的一切话。”</span>
</div>
</div>

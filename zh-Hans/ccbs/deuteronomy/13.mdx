## 不可拜假神

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 23:25–28; 约翰一书 4:1; 耶利米书 29:8"> “如果你们中间出现了先知或解梦的人，要显神迹奇事给你们看，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 13:6; 马太福音 7:22–23; 启示录 13:13–14"> 劝你们随从、供奉不认识的其他神明，即使他们显的神迹奇事应验了，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:2; 哥林多前书 11:19; 诗篇 66:10"> 你们也不可听从他们。因为这是你们的上帝耶和华在试验你们，要看看你们是否全心全意地爱祂。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:10; 申命记 10:20; 哥林多前书 6:17"> 你们要跟从你们的上帝耶和华，敬畏祂，遵守祂的诫命，听从祂的话，事奉祂，倚靠祂。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:13; 申命记 18:20; 耶利米书 14:15"> 必须处死那些先知或解梦的人，因为他们怂恿你们背叛你们的上帝耶和华、偏离祂吩咐你们当走的道路。你们的上帝耶和华曾带你们离开埃及，救赎你们脱离奴役。你们必须清除你们当中的邪恶。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 17:2–7; 彼得后书 2:1; 以弗所书 4:14"> “如果你们的亲兄弟、儿女、爱妻或挚友暗中引诱你们去拜你们和你们祖先都不认识的其他神明，</span>
<span className="v" id="v7" data-v="7"> 引诱你们去拜你们周围各族的神明，或在附近或远在天边，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 19:13; 箴言 1:10; 申命记 7:16"> 你们不可迁就、听从他们，不可怜惜他们，不可放过或包庇他们。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:58; 路加福音 14:26; 马太福音 10:37"> 必须处死他们。你们要首先下手，然后众人一起打死他们。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 7:25; 利未记 24:14–16; 出埃及记 20:2"> 你们要用石头打死他们，因为他们企图使你们背弃你们的上帝耶和华，祂曾把你们从受奴役之地埃及领出来。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 19:20; 申命记 17:13; 提摩太前书 5:20"> 这样，所有以色列人听了就会害怕，必无人再敢在你们中间做这种恶事。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–17; 约书亚记 22:11–34"> “在你们的上帝耶和华将要赐给你们居住的各城中，如果你们听说某城里有恶人引诱城中的居民偏离正路，唆使他们去供奉你们不认识的其他神明，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:4; 以赛亚书 11:3–4; 约翰福音 7:24"> 你们要认真查明真相。如果传闻属实，你们当中确有此恶行，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 22:20; 利未记 27:28; 申命记 7:2"> 你们一定要用刀杀光那城中的居民和牲畜。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 49:2; 约书亚记 8:28; 以赛亚书 25:2"> 你们要把城中的财物堆在广场中心，然后放火焚烧那城和城中的财物，作为燔祭献给你们的上帝耶和华。城要永远荒废，不可重建。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 26:4; 申命记 7:26; 约书亚记 7:26"> 你们不可保留任何应当被毁灭的东西，这样耶和华就不再向你们发怒，转而施恩怜悯你们。<br />“只要你们遵守我今天吩咐你们的一切诫命，做耶和华视为正的事，祂必按照祂对你们祖先所起的誓，怜悯你们，使你们人丁兴旺。</span>
</div>
</div>

</div>

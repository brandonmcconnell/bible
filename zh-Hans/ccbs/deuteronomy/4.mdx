## 当守律法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 10:5; 以西结书 20:11; 利未记 18:5"> “以色列人啊，要聆听我传授给你们的律例和典章，要切实遵行，以便你们可以存活，并进去占据你们祖先的上帝耶和华赐给你们的那片土地。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:32; 箴言 30:6; 启示录 22:18–19"> 我吩咐你们的，你们不可做任何增减，你们要遵守你们的上帝耶和华的命令。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 25:1–9; 诗篇 106:28–29; 约书亚记 22:17"> 你们亲眼看见耶和华在巴力·毗珥事件中的作为，你们的上帝耶和华毁灭了你们中间所有拜巴力·毗珥的人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 10:20; 约书亚记 23:8; 约翰福音 6:67–69"> 但你们这些信靠你们的上帝耶和华的人至今都还活着。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 28:20; 帖撒罗尼迦前书 4:1–2; 希伯来书 3:5"> 看啊，遵照我的上帝耶和华的吩咐，我把律例和典章传授给你们，好让你们在将要进去占领的土地上遵守。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 28:28; 诗篇 111:10; 提摩太后书 3:15"> 你们要谨遵这些律例和典章，因为这样就会让外族人看见你们的智慧和聪明。他们听见这些律例后，必说，‘这伟大的民族真有智慧和聪明！’</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:18; 撒母耳记下 7:23; 诗篇 34:18"> 我们的上帝耶和华与我们如此亲近，随时垂听我们的呼求，有哪个伟大民族的神明能与之相比？</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 147:19–20; 罗马书 7:12–14; 诗篇 119:127–128"> 有哪个伟大的民族拥有我今天所传授给你们的如此公义的律例和典章？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 6:7; 申命记 11:19; 诗篇 78:3–8"> “要谨慎、小心，不可忘记亲眼所见的事，要一生铭记在心，并且告诉子子孙孙。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:9; 希伯来书 12:18–19; 出埃及记 19:16"> 那天，你们在何烈山站在你们的上帝耶和华面前，耶和华对我说，‘把民众招聚起来，让他们听我的教诲，学习一生敬畏我，并传授给自己的儿女。’</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 5:23; 出埃及记 19:16–18; 希伯来书 12:18–19"> 你们来到山脚下，站在那里，山上烈焰冲天、乌云密布、极其幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:15; 申命记 5:4; 申命记 5:22"> 耶和华在火焰中对你们说话，你们只听见祂的声音，却看不见祂的形象。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:28; 出埃及记 31:18; 申命记 9:9–11"> 祂向你们宣告祂的约，就是祂吩咐你们遵守的十诫，并写在两块石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 105:44–45; 以西结书 21:1–23"> 那时，耶和华吩咐我把律例和典章传授给你们，好让你们在将要占领的土地上遵守。</span>
</div>
</div>

## 不可拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 4:12; 以赛亚书 40:18; 哥林多后书 4:4–6"> “你们要格外小心，耶和华在何烈山的火焰中对你们说话时，你们没有看见任何形象，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:29; 申命记 5:8; 出埃及记 20:4–5"> 所以不可堕落，去为自己制造任何形状的神像——男人、女人、</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:23"> 飞禽走兽、</span>
<span className="v" id="v18" data-v="18"> 爬虫或鱼类的像。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:25; 申命记 17:3; 列王纪下 21:3"> 当你们举目观看你们的上帝耶和华赐给天下万民的日、月、星辰等天上万象时，不要受诱惑去跪拜、供奉它们。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 8:51; 耶利米书 11:4; 出埃及记 19:5–6"> 耶和华拯救你们脱离埃及那座铁熔炉，让你们做祂自己的子民，正如今日的情形。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:37; 民数记 20:12; 诗篇 106:32–33"> 因你们的缘故，耶和华向我发怒，起誓不让我过约旦河、进入祂赐给你们作产业的那片佳美之地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 3:25; 申命记 3:27; 彼得后书 1:13–15"> 我将死在约旦河这边，过不了约旦河。但你们必过去得到那片佳美之地。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:9; 希伯来书 3:12; 约书亚记 23:16"> 你们要谨慎，不可忘记你们的上帝耶和华与你们所立的约，不可违背你们上帝耶和华的禁令，去制造任何形状的神像。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:29; 那鸿书 1:6; 申命记 9:3"> 因为你们的上帝耶和华是烈火，是痛恨不贞的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 4:16; 何西阿书 9:9; 哥林多前书 10:22"> “将来，即使你们在那里安顿已久、子孙满堂，也不可堕落、制造任何形状的神像，不可做你们的上帝耶和华视为邪恶的事，惹祂发怒。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:1; 弥迦书 6:2; 耶利米书 22:29"> 否则，今天我叫天地作证，你们必很快从约旦河对面将要占领的土地上灭亡，你们必被彻底消灭，不得在那里长久居住。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 28:62–64; 利未记 26:33; 以西结书 12:15"> 耶和华必把你们驱散到列邦，使你们在列邦中的人数所剩无几。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:64; 耶利米书 16:13; 申命记 28:36"> 你们必在那里供奉人用木石造的不会看、不会听、不会吃、不会闻的神像。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:2; 耶利米书 29:12–14; 历代志下 15:4"> 但你们若在那里寻求你们的上帝耶和华，全心全意地寻求祂，就必寻见。</span>
<span className="v" id="v30" data-v="30" data-xref="约珥书 2:12–13; 耶利米书 23:20; 何西阿书 3:5"> 日后，当你们遭遇这些事，受尽苦难的时候，必归向你们的上帝耶和华，听从祂。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 31:8; 诗篇 116:5; 尼希米记 9:31"> 因为你们的上帝耶和华充满怜悯，祂不会抛弃你们，灭绝你们，也不会忘记祂与你们祖先所立的誓约。</span>
</div>
</div>

## 独一的上帝

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约伯记 8:8; 马太福音 24:31; 诗篇 44:1"> “你们可以查考历史，自上帝在世上造人以来，这样的奇事，天地之间何曾有过？谁曾听闻？</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 6:22; 申命记 5:24; 出埃及记 33:20"> 有哪个民族像你们一样，听见了上帝在火中说话，还活了下来？</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 26:8; 申命记 5:15; 出埃及记 6:6"> 有哪个神明像你们的上帝耶和华那样在埃及当着你们的面降灾祸、行神迹奇事、发起战争、伸出臂膀、施展大能的手、以伟大而可畏的作为拯救一族脱离异邦？</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 45:18; 撒母耳记上 2:2; 以赛亚书 45:5"> 耶和华行这样的事，是要叫你们知道祂是上帝，除祂以外，别无他神。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 19:9; 出埃及记 19:19; 申命记 4:33"> 祂让你们听见祂从天上来的声音，好教导你们，又在地上让你们看见祂的烈火，并听见祂在烈火中说的话。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 10:15; 以赛亚书 63:9; 出埃及记 13:9"> 因为祂爱你们的祖先，所以拣选他们的子孙，亲自用大能带你们出埃及，</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 7:1; 申命记 9:1–5; 出埃及记 23:27–28"> 赶走比你们强大的民族，领你们进入他们的土地，把他们的土地赐给你们作产业，正如今日的情形。</span>
<span className="v" id="v39" data-v="39" data-xref="约书亚记 2:11; 申命记 4:35; 历代志上 29:11"> 所以，今天你们要知道并谨记，耶和华是天上地下的上帝，此外别无他神。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 6:3; 以弗所书 6:3; 申命记 12:28"> 我今天将祂的律例和诫命传授给你们，你们要遵守，以便你们及子孙都蒙福，在你们上帝耶和华所赐的土地上得享长寿。”</span>
</div>
</div>

## 设立避难城

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:6; 民数记 35:14–15; 约书亚记 20:2–9"> 那时，摩西在约旦河东划出三座城作避难城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:18; 申命记 19:1–10; 民数记 35:15–28"> 供素无冤仇却误杀他人者逃往避难。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 20:8; 列王纪上 4:13; 约书亚记 21:27"> 三座城分别是供吕便人避难的比悉，在旷野高原；供迦得人避难的拉末，在基列；供玛拿西人避难的哥兰，在巴珊。</span>
</div>

## 重申律法

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命记 27:3; 利未记 27:34; 玛拉基书 4:4"> 以下是摩西颁布给以色列人的律法，</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 2:3; 申命记 4:1; 诗篇 119:7"> 即在离开埃及后传授给他们的法度、律例和典章。</span>
<span className="v" id="v46" data-v="46" data-xref="申命记 3:29; 申命记 4:47; 申命记 1:4–5"> 当时他们在约旦河以东伯·毗珥对面的山谷，那里原属于希实本的亚摩利王西宏。摩西领以色列人离开埃及后消灭了西宏，</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 3:1–14; 民数记 21:33–35; 申命记 29:7–8"> 占领了他的土地，还占领了巴珊王噩的土地。西宏和噩是约旦河东亚摩利人的两个王，</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 3:9; 申命记 2:36; 申命记 3:12"> 其国土从亚嫩谷边的亚罗珥一直到西云山，即黑门山，</span>
<span className="v" id="v49" data-v="49" data-xref="申命记 3:17; 约书亚记 13:20; 申命记 34:1"> 包括约旦河东的整个亚拉巴，远至毗斯迦山脚的亚拉巴海。</span>
</div>
</div>

## 不可忘记耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 5:32–3; 帖撒罗尼迦前书 4:1–2"> “你们要谨遵我今日吩咐你们的一切诫命，以便能够存活，人丁兴旺，进入并得到耶和华起誓要赐给你们祖先的土地。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:3; 彼得前书 1:7; 申命记 8:16"> 要记住这四十年来，你们的上帝耶和华怎样在旷野一路引领你们，祂磨炼你们、考验你们，好知道你们的心意如何、肯不肯遵守祂的诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:4; 路加福音 4:4; 希伯来书 13:5–6"> 祂让你们忍饥挨饿，然后赐给你们祖祖辈辈从未见过的吗哪吃，为了使你们明白人活着不是单靠食物，而是靠耶和华口中的每一句话。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:21; 申命记 29:5; 马太福音 26:25–30"> 这四十年来，你们的衣服没有穿破，双脚也没有走肿。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:19; 箴言 3:12; 撒母耳记下 7:14"> 你们心里要明白，你们的上帝耶和华管教你们，如同父亲管教儿子。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志下 6:31; 申命记 5:33; 撒母耳记上 12:24"> “所以，你们要遵守你们的上帝耶和华的诫命，行祂的道，敬畏祂，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:9–12; 出埃及记 3:8; 以西结书 20:6"> 因为祂要带你们到一个佳美之地。那里的谷中和山间流淌着条条溪流、股股清泉；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 6:13; 诗篇 147:14; 申命记 32:14"> 那里盛产大麦、小麦、葡萄、无花果、石榴、橄榄油和蜂蜜；</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 22:14; 申命记 33:25; 约书亚记 22:8"> 那里食物充足，一无所缺；那里矿产资源丰富，石头就是铁，山中可以采铜。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 103:2; 罗马书 14:6; 箴言 3:9"> 你们吃饱喝足后，要赞美你们的上帝耶和华，因为祂赐给你们那佳美之地。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:21; 何西阿书 2:8–9; 箴言 1:32"> “你们要谨慎，免得忘记你们的上帝耶和华，不遵守我今天吩咐你们的诫命、典章和律例。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命记 28:47; 申命记 32:15"> 否则，当你们丰衣足食、居室华美、</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 1:3; 创世记 13:1–5; 路加福音 12:13–21"> 牛羊成群、金银财物增多的时候，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 106:21; 哥林多前书 4:7–8; 申命记 8:11"> 切勿心骄气傲，忘记你们的上帝耶和华。祂把你们从受奴役之地埃及救出来，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:6; 民数记 20:11; 耶利米书 2:6"> 带领你们走过干旱、可怕、毒蛇和蝎子出没的大旷野。祂使坚硬的磐石流出水来给你们喝，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 8:3; 雅各书 1:12; 出埃及记 16:15"> 在旷野中把你们祖先从未见过的吗哪赐给你们吃，为要磨炼你们、考验你们，使你们最终得到益处。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 9:4; 哥林多前书 4:7; 但以理书 4:30"> 你们切勿以为是凭自己的双手和能力致富的。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿书 2:8; 申命记 7:8"> 要记住，是你们的上帝耶和华赐给你们致富的能力，为要坚立祂给你们祖先的誓约，正如今日的情形。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 4:26; 撒母耳记上 12:25; 西番雅书 1:18"> “我今天警告你们，如果你们忘记你们的上帝耶和华，去追随、供奉、祭拜其他神明，你们必灭亡。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 9:11–12; 历代志下 36:16–17"> 如果你们不听从你们的上帝耶和华，你们必灭亡，正如祂使列国在你们面前灭亡一样。</span>
</div>
</div>

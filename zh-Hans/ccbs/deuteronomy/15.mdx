## 安息年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 31:10; 出埃及记 23:10–11; 利未记 25:2–4"> “每逢第七年末，你们要免除他人的债务。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各书 2:13; 路加福音 6:34–38"> 你们要这样做，所有债主都要免除同胞所欠的债务，不可向他们追讨，因为宣布免除债务的是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:20; 马太福音 17:25–26; 哥林多前书 6:6–7"> 你们可以向外族人讨债，但无论同胞欠你什么债务，都要免除。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:10–11; 箴言 28:27; 箴言 11:24–25"> 只要你们留心听从你们上帝耶和华的话，谨遵我今天吩咐你们的诫命，祂必使你们在祂赐给你们作产业的土地上蒙福，你们中间不会有穷人。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:12–13; 路加福音 6:35; 尼希米记 9:27"> 你们的上帝耶和华必照祂的应许赐福给你们，你们必借贷给多国，却不需要向他们借贷。你们必统治多国，却不被他们统治。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:16–17; 申命记 15:9; 箴言 21:13"> “在进入你们的上帝耶和华将要赐给你们的土地后，如果你们居住的城中有贫穷的同胞，你们不可硬着心肠拒施援手。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 马太福音 5:42"> 你们要伸出援手，按他们的所需慷慨地借给他们。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 24:15; 马太福音 20:15; 耶利米书 17:10"> 你们要谨慎，不可因为免除债务的第七年将近，就心怀恶念，对贫穷同胞冷眼相待，拒施援手。否则，他们会向耶和华控诉你们，那时你们便有罪了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯来书 13:16; 以赛亚书 58:10"> 你们要慷慨给予，并且无怨无悔，因为你们的上帝耶和华必在你们所做的一切事上赐福给你们。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 14:7; 马太福音 26:11; 约翰福音 12:8"> 你们居住的地方总会有穷人，所以我吩咐你们要慷慨地帮助贫穷和有需要的同胞。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 34:14; 利未记 25:39–41; 出埃及记 21:2–6"> “如果你们的希伯来同胞，不论男女，卖身给你们为奴，他们要服侍你们六年，到第七年，你们要给他们自由。</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 3:5; 耶利米书 22:13; 箴言 3:27–28"> 你们释放他们时，不可让他们空手离去，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 16:2; 箴言 10:22; 诗篇 68:10"> 要慷慨地把你们的上帝耶和华赐给你们的羊、五谷和酒分给他们。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:12; 马太福音 18:32–33; 申命记 5:14–15"> 要记住，你们曾在埃及做奴隶，你们的上帝耶和华救赎了你们。所以，我今天吩咐你们这样做。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:5–6; 诗篇 40:8; 诗篇 40:6"> 如果你们的奴仆因为爱你们和你们的家人，与你们相处融洽，不愿意离去，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 1:22; 利未记 25:39–42"> 你们就要让他靠在门上，用锥子在他耳朵上扎个洞，他便终身成为你们的奴仆。对待婢女也要这样。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以赛亚书 16:14; 以赛亚书 21:16"> 你们释放奴仆时，不要不情愿，因为他们服侍你们六年，所做的是普通雇工的两倍。而且，你们的上帝耶和华也会在你们所做的一切事上赐福给你们。</span>
</div>
</div>

## 头生的牛羊

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 13:12; 利未记 27:26"> “你们要把头生的公牛和公羊分别出来，献给你们的上帝耶和华。不可用头生的公牛耕田，也不要剪头生公羊的毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 12:17; 申命记 14:23; 申命记 12:5–7"> 每年，你们全家要去你们的上帝耶和华选定的地方，在祂面前吃这些头生的牛羊。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 17:1; 玛拉基书 1:7–8; 利未记 22:19–25"> 如果这些牛羊有什么残疾，如瘸腿、瞎眼或其他缺陷，就不可献给你们的上帝耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:21–22; 申命记 12:15–16"> 要在你们的城里吃这些牛羊。洁净的人和不洁净的人都可以吃，就像吃羚羊和鹿一样。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:16; 利未记 7:26; 申命记 12:23"> 但不可吃它们的血，要把血倒在地上，像倒水一样。</span>
</div>
</div>

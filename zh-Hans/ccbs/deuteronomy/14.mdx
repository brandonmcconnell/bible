## 做圣洁的子民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 21:5; 罗马书 9:8; 加拉太书 3:26"> “你们是你们上帝耶和华的儿女，不可为死人割伤自己或剃光前额。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:6; 利未记 20:26; 出埃及记 19:5–6"> 因为你们是你们的上帝耶和华的圣民，祂从天下万族中拣选你们作祂宝贵的产业。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 4:14; 罗马书 14:14; 利未记 20:25"> “你们不可吃任何可憎之物。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:2–45; 使徒行传 10:14; 列王纪上 4:23"> 但你们可以吃牛、绵羊、山羊、</span>
<span className="v" id="v5" data-v="5"> 鹿、羚羊、狍子、野山羊、瞪羚、黄羊和野绵羊。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多后书 6:17; 诗篇 1:1–2"> 凡蹄子分瓣且反刍的动物，你们都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:22–23; 提多书 1:16; 提摩太后书 3:5"> 在那些只反刍或只是蹄子分瓣的动物中，你们不可吃骆驼、野兔和石獾，因为它们虽反刍但蹄子不分瓣，是不洁净的。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:26–27; 以赛亚书 66:3; 彼得后书 2:22"> 你们也不可吃猪，因为猪虽蹄子分瓣但不反刍，是不洁净的。你们不可吃这些动物的肉，也不可摸它们的尸体。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 11:9–12"> “水族中，凡有鳍有鳞的，你们都可以吃。</span>
<span className="v" id="v10" data-v="10"> 凡无鳍无鳞的都不洁净，你们不可吃。</span>
<span className="v" id="v11" data-v="11"> “你们可以吃洁净的鸟类。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 11:13–19"> 不可吃的鸟类有雕、胡兀鹫、黑秃鹫、</span>
<span className="v" id="v13" data-v="13"> 鸢、隼类、</span>
<span className="v" id="v14" data-v="14"> 乌鸦类、</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 30:29"> 鸵鸟、夜鹰、海鸥、鹰类、</span>
<span className="v" id="v16" data-v="16"> 小鸮、大鸮、仓鸮、</span>
<span className="v" id="v17" data-v="17"> 鹈鹕、鱼鹰、鸬鹚、</span>
<span className="v" id="v18" data-v="18"> 鹳、鹭鸟类、戴胜和蝙蝠。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:19; 利未记 11:20–23"> “凡有翅膀、会爬的昆虫都不洁净，你们不可吃。</span>
<span className="v" id="v20" data-v="20"> 凡有翅膀的洁净之物，你们都可以吃。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:19; 出埃及记 34:26; 利未记 22:8"> “你们不可吃死掉的动物，但可以送给住在你们城里的外族人吃，或卖给其他外族人。因为你们是你们的上帝耶和华的圣民。你们不可用母山羊的奶煮它的羊羔。</span>
</div>
</div>

## 十一奉献

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 10:37; 申命记 12:17; 申命记 26:12–15"> “你们每年要献出收成的十分之一；</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:5–7; 申命记 4:10; 申命记 12:17–18"> 要在你们的上帝耶和华选定的敬拜场所，在祂面前吃所献的十分之一的谷物、新酒、油以及头生的牛羊。这是为了让你们学习一生敬畏你们的上帝耶和华。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:21; 申命记 12:5; 申命记 11:24"> 如果你们的上帝耶和华赐福你们，使你们丰收，而你们住的地方离祂选定的敬拜场所太远，以致不能把收成的十分之一送去，</span>
<span className="v" id="v25" data-v="25"> 就可以把那些收成换成银钱，带到你们的上帝耶和华选定的场所。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:7; 申命记 12:7; 马太福音 21:12"> 在那里，你们可以随意买牛、羊、淡酒或烈酒，然后一家人在你们的上帝耶和华面前吃喝快乐。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:20; 申命记 14:29; 申命记 12:12"> 不可忘记住在你们城里的利未人，因为利未人没有分到土地作产业。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 14:22; 阿摩司书 4:4; 申命记 26:12–15"> “每逢第三年末，你们要把那年所有出产的十分之一拿出来，存放在你们的城里，</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 15:10; 申命记 14:27; 箴言 19:17"> 让你们城中没有土地的利未人、寄居者和孤儿寡妇都可以来吃饱。这样，你们的上帝耶和华必使你们凡事蒙福。</span>
</div>
</div>

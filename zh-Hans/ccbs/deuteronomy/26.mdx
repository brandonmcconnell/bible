## 奉献初熟的物产

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:14; 申命记 13:9; 申命记 6:1–10"> “你们进入你们的上帝耶和华将要赐给你们作产业的土地，占领那里，安居下来以后，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 23:19; 出埃及记 23:16; 以西结书 44:30"> 要把在那里收获的各种初熟的物产放在篮子里，带到你们的上帝耶和华为祂的名选定的居所。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 105:9–10; 申命记 19:17; 创世记 26:3"> 你们要对当值的祭司说，‘今天我要向我们的上帝耶和华宣告，我已经进入祂向我们祖先起誓要赐给我们的土地。’</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 23:19; 马太福音 5:23–24; 希伯来书 13:10–12"> 祭司要从你们手中接过篮子，放在你们的上帝耶和华的祭坛前。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:27; 创世记 31:20"> 你们要在你们的上帝耶和华面前宣告，‘我们的祖先原是漂泊的亚兰人。他下到埃及寄居时，家中人丁稀少，后来成为人口众多的强大民族。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 1:11; 出埃及记 1:14; 出埃及记 5:23"> 埃及人苦待我们，压迫我们，强迫我们做苦工。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:23–4; 以弗所书 3:20–21; 出埃及记 3:9"> 于是，我们呼求我们祖先的上帝耶和华。祂听见我们的呼求，看见我们的痛苦、艰辛和所受的压迫，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:34; 申命记 5:15; 诗篇 78:12–13"> 就伸出臂膀，用大能的手行神迹奇事，以伟大而可畏的作为带我们出埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 诗篇 105:44; 诗篇 107:7–8"> 祂带领我们来到这个地方，把这奶蜜之乡赐给我们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 26:2; 申命记 18:4; 启示录 22:9"> 耶和华啊，现在我从你赐给我的土地上带来初熟的物产。’你们要把篮子放在你们的上帝耶和华面前，敬拜祂。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 16:11; 申命记 12:7; 腓立比书 4:4"> 你们和利未人以及住在你们中间的外族人，都要因你们的上帝耶和华赐给你们和你们家人的福祉而欢喜快乐。</span>
</div>
</div>

## 十一奉献年

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 27:30; 民数记 18:24; 腓立比书 4:18–19"> “每逢第三年是十一奉献年。你们应当把自己所有出产的十分之一拿出来分给利未人、寄居者和孤儿寡妇，使他们在你们居住的城邑吃饱喝足。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:176; 诗篇 119:153; 诗篇 119:141"> 然后，你们要在你们的上帝耶和华面前宣告，‘我已经按照你的诫命，从家里拿出圣物分给利未人、寄居者和孤儿寡妇。我没有触犯也没有忘记你的任何诫命。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 7:20; 利未记 21:11; 何西阿书 9:4"> 这些圣物，我守丧期间没有吃过，不洁净时没有拿过，也没有献给死人。我听从我的上帝耶和华，遵行你的一切吩咐。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:15; 撒迦利亚书 2:13; 耶利米书 31:23"> 求你从天上圣洁的居所垂看，赐福给你的以色列子民和你赐给我们的土地，就是你向我们祖先起誓应许的奶蜜之乡。’</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 12:1; 约翰福音 14:15; 约翰一书 5:2–3"> “你们的上帝耶和华今天吩咐你们遵守这些律例和典章，你们要全心全意地谨慎遵守。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:7; 以赛亚书 12:2; 哥林多前书 6:19–20"> 你们今天已经宣布耶和华是你们的上帝，并愿意遵行祂的道，谨守祂的一切律例、诫命和典章，听从祂的话语。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 7:6; 申命记 14:2; 申命记 28:9"> 耶和华今天已经照祂的应许宣布你们是祂的子民，是祂宝贵的产业。因此，你们要遵守祂的一切诫命，</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 2:9; 申命记 7:6; 申命记 28:1"> 这样祂必使你们备受赞誉和尊崇，超越祂所造的万国，并照着祂的应许使你们做祂的圣民。”</span>
</div>

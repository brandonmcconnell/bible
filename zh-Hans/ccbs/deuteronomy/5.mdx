## 十诫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 马太福音 23:3; 申命记 29:10"> 摩西把所有的以色列人召来，对他们说：“以色列人啊，要留心听我今天对你们宣讲的律例和典章，要学习并谨慎遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:23; 出埃及记 19:5–8; 出埃及记 24:8"> 我们的上帝耶和华曾在何烈山与我们立约，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:10–15; 创世记 17:21; 创世记 17:7"> 这约不是与我们祖先立的，而是与我们今天还活着的人立的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 19:18–19; 申命记 34:10; 出埃及记 19:9"> 耶和华在山上的烈火中面对面跟你们说话。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:19; 出埃及记 19:16; 出埃及记 20:18–21"> 那时，因为你们害怕那烈火，没有到山上去，我就站在耶和华和你们中间，把耶和华的话传给你们。耶和华说：</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 20:2–17; 诗篇 81:5–10; 利未记 26:1–2"> “‘我是你的上帝耶和华，曾把你从受奴役之地埃及领出来。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:3; 马太福音 4:10; 约翰一书 5:21"> 除我以外，你不可有别的神明。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:4; 申命记 4:15–19"> 不可为自己雕刻神像，不可仿照天上、地上和地底下水中的任何形象造神像，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:4–6; 出埃及记 34:7; 但以理书 9:4–9"> 不可跪拜它们，也不可供奉它们，因为我——你的上帝耶和华痛恨不贞，我必追讨背弃我之人的罪，从父到子直到三四代。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:28; 约翰一书 1:7; 耶利米书 32:18"> 但那些爱我、遵守我诫命的人，我必以慈爱待他们，直到千代。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 19:12; 申命记 6:13"> 不可妄用你上帝耶和华的名，违者必被耶和华定罪。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:8–11; 以赛亚书 58:13; 以赛亚书 56:6"> 要遵照你的上帝耶和华的吩咐守安息日为圣日。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:12; 路加福音 13:14–16; 出埃及记 23:12"> 你一周可劳碌工作六天，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:4; 创世记 2:2; 出埃及记 23:12"> 但第七天是你的上帝耶和华的安息日，这一天你和儿女、仆婢、牛驴等牲畜及你那里的外族人不可做任何工，好让仆婢和你一样得到休息。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 5:6; 申命记 15:15; 申命记 16:12"> 要记住，你曾在埃及做奴隶，你的上帝耶和华伸出臂膀，用大能的手把你从那里领出来。因此，你的上帝耶和华吩咐你守安息日。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 歌罗西书 3:20"> 要遵照你的上帝耶和华的吩咐孝敬父母，以便在你的上帝耶和华要赐给你的土地上享长寿，蒙祝福。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:13; 罗马书 13:9; 马太福音 5:21–22"> 不可杀人。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 20:14; 路加福音 18:20; 利未记 20:10"> 不可通奸。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:15; 罗马书 13:9; 以弗所书 4:28"> 不可偷盗。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:16; 出埃及记 23:1; 箴言 19:9"> 不可作伪证陷害人。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:17; 罗马书 13:9; 路加福音 12:15"> 不可贪恋别人的妻子，不可贪图别人的房屋、田地、仆婢、牛驴，或其他任何物品。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:12; 出埃及记 31:18; 申命记 4:12–15"> “这是耶和华在山上的烈火、乌云和幽暗中高声颁布给你们全体会众的诫命。此外，祂没有说别的。祂把这些话写在两块石版上交给我。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 20:18–19; 希伯来书 12:18–21"> 当时，山上燃烧着烈焰，你们听见声音从黑暗中传来。你们各支派的首领和长老都到我跟前，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 4:33; 出埃及记 19:19; 出埃及记 33:20"> 说，‘看啊，我们的上帝耶和华向我们彰显了祂的荣耀和威严，我们听见了祂从火中发出的声音。今天我们已经看见，人听见上帝说话后还能活着。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:16; 加拉太书 3:10; 哥林多后书 3:7–9"> 但我们何必冒死，被这烈火吞噬呢？我们若再次听到我们的上帝耶和华的声音，必然丧命。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 4:33; 罗马书 3:20; 马太福音 26:63"> 世上有谁像我们一样，听见永活上帝从火中说话后还能活着呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 20:19; 希伯来书 12:19"> 你近前听我们上帝耶和华所说的话，然后回来把祂的话告诉我们，我们必听从、遵行。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 18:17; 民数记 36:5; 民数记 27:7"> “耶和华听见了你们的话，就对我说，‘我听见了民众对你说的话，他们所说的都对。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 48:18; 以西结书 33:31–32; 申命记 11:1"> 但愿他们常常敬畏我，遵从我的一切诫命，以便他们和他们的子孙世世代代可以蒙福。</span>
<span className="v" id="v30" data-v="30"> 你吩咐他们回到自己的帐篷，</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 3:19; 以西结书 20:11; 申命记 5:1"> 但你要留在我这里，我要把所有的诫命、律例和典章都赐给你，你要把这些传授给众人，使他们可以在我要赐给他们的土地上遵行。’</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 23:6; 箴言 4:27; 约书亚记 1:7"> 所以，你们要谨遵你们上帝耶和华的吩咐，不可偏离左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:23; 申命记 4:40; 路加福音 1:6"> 你们要遵行你们上帝耶和华的一切吩咐，就可以在你们将要占领的土地上存活、亨通、长久。</span>
</div>
</div>

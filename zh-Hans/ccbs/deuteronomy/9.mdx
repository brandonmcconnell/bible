## 以色列人的悖逆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 11:31; 申命记 4:38; 申命记 1:28"> “以色列人啊，你们要听！今天你们要过约旦河，去赶出那些比你们强大的民族。他们住在城墙高耸入云的大城里，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 13:22; 那鸿书 1:6; 申命记 7:24"> 是长得高大威猛的亚衲人。你们了解他们，也听人说过，‘谁能抵挡亚衲人呢？’</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:24; 希伯来书 12:29; 罗马书 8:31"> 但今天你们要知道，你们的上帝耶和华要走在你们前面，像烈火一样吞噬他们。祂要制服他们，使你们迅速赶走他们，毁灭他们，正如祂对你们的应许。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 8:17; 申命记 9:5; 申命记 18:9–14"> “你们的上帝耶和华从你们面前赶走他们以后，你们心里不要以为耶和华带领你们占领那片土地是因为你们公义，其实是因为那里的民族邪恶，耶和华才将他们从你们面前赶走。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 3:5; 创世记 17:8; 创世记 26:4"> 你们能占领他们的土地并非因为你们公义、行为正直。你们的上帝耶和华从你们面前赶走那些民族，是因为他们邪恶，也是为了实现祂给你们祖先亚伯拉罕、以撒和雅各的誓言。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:16; 使徒行传 7:51; 申命记 31:27"> 你们要知道，耶和华赐给你们那佳美之地不是因为你们公义。其实你们是顽固不化的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:2; 出埃及记 14:11; 民数记 21:5"> “要牢记你们在旷野怎样触怒你们的上帝耶和华。从你们离开埃及那天来到这里，你们屡屡背叛耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:19–22; 出埃及记 32:16; 出埃及记 32:7–10"> 在何烈山，你们触怒了耶和华，以致祂要毁灭你们。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 34:28; 出埃及记 24:18; 列王纪上 19:8"> 那时，我上山去接受耶和华与你们立约的石版，在山上待了四十昼夜，没吃也没喝。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:4"> 耶和华把两块立约的石版交给我，上面刻着那天你们聚会时祂在山上的火焰中对你们说的话，是祂用手指刻上去的。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 9:9; 民数记 10:33; 希伯来书 8:6–10"> 四十昼夜后，耶和华把那两块刻着约的石版交给我，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:7–8; 申命记 31:29; 士师记 2:17"> 对我说，‘快下山吧，因为你从埃及领出来的百姓已经败坏了。他们这么快就偏离了我吩咐他们走的道，为自己铸造了神像。’</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 9:6; 列王纪下 17:14; 申命记 10:16"> “耶和华又对我说，‘我已看出，这是顽固不化的百姓。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 29:20; 出埃及记 32:10–13; 诗篇 9:5"> 不要拦我，我要毁灭他们，从世上抹去他们的名字。我要使你成为一个比他们更强大的民族。’</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:18; 申命记 5:23; 申命记 4:11"> 我双手拿着那两块约版，转身从烈火熊熊的山上下来，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 32:19; 使徒行传 7:40–41"> 看见你们为自己铸造了牛犊像，得罪了你们的上帝耶和华，这么快就偏离了耶和华吩咐你们走的道，</span>
<span className="v" id="v17" data-v="17"> 就当着你们的面摔碎了那两块石版。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:28; 申命记 9:9; 诗篇 106:23"> “我又俯伏在耶和华面前，四十昼夜不吃不喝，因为你们犯了大罪，做耶和华憎恶的事，惹祂发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 10:10; 出埃及记 32:14; 雅各书 5:16–17"> 耶和华向你们发烈怒，要毁灭你们，我非常惧怕。但耶和华再次垂听了我的祈求。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 32:35; 出埃及记 32:21; 希伯来书 7:26–28"> 耶和华对亚伦非常愤怒，以致要杀掉他，于是我也为他祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 32:20; 以赛亚书 31:7; 以赛亚书 2:18–21"> 我焚烧了你们铸造的罪恶之物牛犊像，把它打碎、磨成粉末，撒在从山上流下来的溪水中。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 11:34; 出埃及记 17:7; 民数记 11:1–5"> “你们在他备拉、玛撒和基博罗·哈他瓦三番四次地触怒耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 106:24–25; 希伯来书 4:2; 诗篇 78:22"> 你们的上帝耶和华吩咐你们离开加低斯·巴尼亚，去占领祂赐给你们的土地，你们却违背祂的命令，不信靠祂，也不听从祂。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 31:27; 使徒行传 7:51; 申命记 9:6–7"> 自从我认识你们以来，你们就不断地背叛耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 9:18; 申命记 9:16"> “因为耶和华说要毁灭你们，我就俯伏在耶和华面前四十昼夜，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 32:11–13; 提多书 2:14; 诗篇 107:2"> 向祂祈求说，‘主耶和华啊，求你不要毁灭你的子民！他们是你的产业，是你用大能的手从埃及救赎并带出来的。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 14:21; 弥迦书 7:18–19; 撒母耳记上 25:25"> 求你看在你仆人亚伯拉罕、以撒和雅各的份上，不要计较这个民族的顽固、邪恶和罪过，</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:16; 出埃及记 32:12"> 免得你带领我们离开之地的人说，你不能把他们领到你应许给他们的地方，你憎恶他们，所以把他们带到旷野杀了。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 1:10; 列王纪上 8:51; 申命记 9:26"> 他们毕竟是你的子民，你的产业，是你伸出大能的臂膀从埃及带出来的。’</span>
</div>
</div>

</div>

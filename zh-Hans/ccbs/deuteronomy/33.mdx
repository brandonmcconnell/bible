## 摩西最后的祝福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:6; 诗篇 90:1; 创世记 27:4"> 以下是上帝的仆人摩西临终时给以色列人的祝福：</span>
<span className="v" id="v2" data-v="2" data-xref="犹大书 1:14; 哈巴谷书 3:3; 启示录 5:11"> <span className="pl pl-1">“耶和华从西奈山来，</span><br /><span className="pl pl-1">从西珥山向我们显现，</span><br /><span className="pl pl-1">祂从巴兰山发出光辉；</span><br /><span className="pl pl-1">祂带着千万圣者来临，</span><br /><span className="pl pl-1">祂右边有闪耀的光芒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 10:39; 玛拉基书 1:2; 申命记 7:6–8"> <span className="pl pl-1">祂深爱自己的子民，</span><br /><span className="pl pl-1">众圣者都听命于祂，</span><br /><span className="pl pl-1">伏在祂的脚前，</span><br /><span className="pl pl-1">领受祂的训诲。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:17; 诗篇 119:111; 约翰福音 7:19"> <span className="pl pl-1">摩西将律法颁布给我们，</span><br /><span className="pl pl-1">作为雅各子孙的产业。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:15; 士师记 17:6; 民数记 23:21"> <span className="pl pl-1">百姓的众首领齐聚，</span><br /><span className="pl pl-1">以色列各支派集合之时，</span><br /><span className="pl pl-1">耶和华在耶书仑做王。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="创世记 49:8; 民数记 32:31–32; 约书亚记 22:1–9"> <span className="pl pl-1">摩西祝福吕便支派说：</span><br /><span className="pl pl-1">“尽管吕便人数稀少，</span><br /><span className="pl pl-1">愿他存活，不致灭没。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="创世记 49:8–12; 诗篇 20:2; 撒母耳记下 7:9–12"> <span className="pl pl-1">摩西祝福犹大支派说：</span><br /><span className="pl pl-1">“耶和华啊，</span><br /><span className="pl pl-1">求你听犹大人的呼求，</span><br /><span className="pl pl-1">带他们回归本族，</span><br /><span className="pl pl-1">出手为他们争战，</span><br /><span className="pl pl-1">帮他们对抗仇敌。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 17:7; 出埃及记 28:30; 民数记 20:13"> <span className="pl pl-1">摩西祝福利未支派说：</span><br /><span className="pl pl-1">“耶和华啊，</span><br /><span className="pl pl-1">求你把土明和乌陵赐给虔诚的利未人，</span><br /><span className="pl pl-1">你曾经在玛撒试验他们，</span><br /><span className="pl pl-1">在米利巴泉边与他们争论。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:37; 出埃及记 32:25–29; 马太福音 12:48"> <span className="pl pl-1">为了听从你的话，遵守你的约，</span><br /><span className="pl pl-1">他们不顾父母，</span><br /><span className="pl pl-1">舍弃弟兄，抛下儿女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:11; 诗篇 51:19; 申命记 17:9–11"> <span className="pl pl-1">他们把你的典章传授给雅各，</span><br /><span className="pl pl-1">把你的律法传授给以色列；</span><br /><span className="pl pl-1">他们要把香献在你面前，</span><br /><span className="pl pl-1">把全牲燔祭献在你的坛上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 24:23; 以西结书 43:27; 以西结书 20:40–41"> <span className="pl pl-1">耶和华啊，</span><br /><span className="pl pl-1">求你赐他们力量，</span><br /><span className="pl pl-1">悦纳他们的工作，</span><br /><span className="pl pl-1">击碎仇敌的腰杆，</span><br /><span className="pl pl-1">使敌人一蹶不振。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:2; 诗篇 91:4; 马太福音 23:37"> <span className="pl pl-1">摩西祝福便雅悯支派说：</span><br /><span className="pl pl-1">“耶和华所爱的人，</span><br /><span className="pl pl-1">安居在祂身边，</span><br /><span className="pl pl-1">安居在祂怀中，</span><br /><span className="pl pl-1">终日蒙祂庇护。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="创世记 49:22–26; 弥迦书 5:7; 以赛亚书 18:4"> <span className="pl pl-1">摩西祝福约瑟家族说：</span><br /><span className="pl pl-1">“愿他们的土地蒙耶和华赐福，</span><br /><span className="pl pl-1">得天上的甘霖，</span><br /><span className="pl pl-1">及地下的泉源；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19; 马太福音 5:45; 诗篇 8:3"> <span className="pl pl-1">得日月之辉，物产丰美；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="哈巴谷书 3:6; 创世记 49:26; 雅各书 5:7"> <span className="pl pl-1">得古老群山之精华，</span><br /><span className="pl pl-1">永存丘陵之富饶；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:35; 诗篇 24:1; 出埃及记 3:2–4"> <span className="pl pl-1">得大地的丰肥，</span><br /><span className="pl pl-1">蒙荆棘火中之上帝的恩宠。</span><br /><span className="pl pl-1">愿这些福气落在约瑟头上，</span><br /><span className="pl pl-1">临到弟兄中的王者身上。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 22:11; 民数记 23:22; 诗篇 44:5"> <span className="pl pl-1">约瑟威武如头生的公牛，</span><br /><span className="pl pl-1">有野牛的角，</span><br /><span className="pl pl-1">他用角抵万邦，</span><br /><span className="pl pl-1">直到地极。</span><br /><span className="pl pl-1">他的两角是数以万计的以法莲人和数以千计的玛拿西人。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="创世记 49:13–15; 约书亚记 19:11; 士师记 5:14"> <span className="pl pl-1">摩西祝福西布伦和以萨迦支派说：</span><br /><span className="pl pl-1">“愿西布伦人欣然外出，</span><br /><span className="pl pl-1">愿以萨迦人在帐篷中欢喜。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 60:5; 以赛亚书 2:3; 诗篇 4:5"> <span className="pl pl-1">他们要招聚众人上山，</span><br /><span className="pl pl-1">一同献上公义的祭；</span><br /><span className="pl pl-1">他们汲取海里的财富和沙中的宝藏。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="创世记 49:19; 创世记 9:26–27; 历代志上 5:18–21"> <span className="pl pl-1">摩西祝福迦得支派说：</span><br /><span className="pl pl-1">“扩张迦得疆界的那位当受称颂！</span><br /><span className="pl pl-1">迦得蹲伏如母狮，</span><br /><span className="pl pl-1">撕碎头颅和臂膀。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民数记 32:16–42; 士师记 5:11; 士师记 5:2"> <span className="pl pl-1">他为自己选了最好的土地，</span><br /><span className="pl pl-1">是留给首领的那份。</span><br /><span className="pl pl-1">他与众首领同行，</span><br /><span className="pl pl-1">施行耶和华的公义和祂给以色列的典章。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="士师记 18:27; 约书亚记 19:47; 士师记 15:8"> <span className="pl pl-1">摩西祝福但支派说：</span><br /><span className="pl pl-1">“但像一只从巴珊跃出的幼狮。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="创世记 49:21; 诗篇 36:8; 马太福音 4:16"> <span className="pl pl-1">摩西祝福拿弗他利支派说：</span><br /><span className="pl pl-1">“拿弗他利人啊，</span><br /><span className="pl pl-1">你们饱尝耶和华的恩宠，</span><br /><span className="pl pl-1">满得祂的赐福，</span><br /><span className="pl pl-1">拥有西方和南方的土地。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="创世记 49:20; 约伯记 29:6; 罗马书 14:18"> <span className="pl pl-1">摩西祝福亚设支派说：</span><br /><span className="pl pl-1">“愿亚设在众子中最蒙福，</span><br /><span className="pl pl-1">受众弟兄的恩待，</span><br /><span className="pl pl-1">双脚沐浴橄榄油，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10; 诗篇 138:3; 腓立比书 4:13"> <span className="pl pl-1">城门有铜锁铁闩，</span><br /><span className="pl pl-1">一生都充满力量。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 15:11; 以赛亚书 43:11–13; 耶利米书 10:6"> <span className="pl pl-1">“耶书仑啊，</span><br /><span className="pl pl-1">上帝独一无二，</span><br /><span className="pl pl-1">祂驰骋诸天，前来助你，</span><br /><span className="pl pl-1">穿越长空，充满威严。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 18:2; 诗篇 90:1–2; 诗篇 46:1"> <span className="pl pl-1">亘古的上帝是你的庇护，</span><br /><span className="pl pl-1">祂永恒的臂膀是你的依托。</span><br /><span className="pl pl-1">祂赶走你面前的仇敌，</span><br /><span className="pl pl-1">下令毁灭他们。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 23:9; 创世记 27:28; 出埃及记 33:16"> <span className="pl pl-1">以色列安然居住，</span><br /><span className="pl pl-1">雅各独居一处，</span><br /><span className="pl pl-1">那里盛产五谷新酒，</span><br /><span className="pl pl-1">有天上的雨露滋润。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 45:17; 以赛亚书 12:2; 诗篇 115:9–11"> <span className="pl pl-1">以色列啊，你多么有福！</span><br /><span className="pl pl-1">蒙耶和华拯救之人啊，谁能像你？</span><br /><span className="pl pl-1">祂是你的盾牌，你得胜的宝剑。</span><br /><span className="pl pl-1">敌人要向你屈服，被你践踏。”</span></span>
</div>

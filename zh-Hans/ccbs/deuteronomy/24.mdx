## 关于婚姻的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 19:7–9; 马可福音 10:4–12; 以赛亚书 50:1"> “如果有人娶妻后，发觉妻子行为不检，因而嫌弃她，他可以写休书给她，让她离开夫家。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 10:11; 哥林多前书 7:15; 以西结书 44:22"> 她离开后，可以自由再婚。</span>
<span className="v" id="v3" data-v="3"> 如果她的后夫也嫌弃她，写休书给她，让她离开夫家，或者后夫死了，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 3:1; 约书亚记 22:17–18; 利未记 18:24–28"> 前夫不可再娶这已被玷污的女子，因为那是耶和华所憎恶的。你们不可把这种罪恶带到你们的上帝耶和华将要赐给你们的土地上。</span>

## 体恤人情

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 5:18; 申命记 20:7; 创世记 2:24"> “不可叫新婚的人从军出征或办理公务。他可以留在家里一年，使新婚的妻子快乐。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 20:19; 路加福音 12:15; 启示录 18:22"> “不可拿别人的磨或磨的上盘作抵押品，因为这等于拿他们的生命作抵押。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 21:16; 提摩太前书 1:10; 出埃及记 22:1–4"> “如果有人绑架自己的同胞，奴役他或卖掉他，必须处死绑架者，除掉你们中间的罪恶。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 14:2; 马可福音 1:44; 利未记 13:1–46"> “遇到麻风病，你们要谨遵利未祭司的指示。你们要谨遵我对他们的吩咐。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 12:10–15; 哥林多前书 10:11; 哥林多前书 10:6"> 要记住你们离开埃及后，你们的上帝耶和华在米利暗身上的作为。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 15:8; 出埃及记 22:27"> “如果你们借贷给同胞，不可走进他家里索取抵押物；</span>
<span className="v" id="v11" data-v="11"> 要站在外面，等他把抵押物拿出来。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 24:17; 约伯记 22:6; 约伯记 24:3"> 如果他是穷人，用自己的外袍作抵押，你们不可把他的外袍留到第二天，</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 6:25; 但以理书 4:27; 出埃及记 22:26–27"> 要在当天日落之前还给他，好让他盖着外袍睡觉。他会因此祝福你们，你们的上帝耶和华也会将此视为你们的义行。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 3:5; 箴言 14:31; 箴言 22:16"> “不可欺压穷苦的雇工，不论他们是你们的同胞，还是住在你们城中的外族人。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 19:13; 箴言 3:27–28; 雅各书 5:4"> 你们要在每天日落前付给他们工钱，因为他们穷苦，靠工钱维生；否则他们向耶和华控诉你们，你们就有罪了。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 18:20; 历代志下 25:4; 耶利米书 31:29–30"> “不可因孩子犯罪而处死父亲，也不可因父亲犯罪而处死孩子。各人要自负罪责。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:19; 申命记 27:19; 出埃及记 23:6"> “你们要公正地对待寄居者和孤儿，不可拿寡妇的衣物作抵押。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 5:15; 申命记 15:15; 申命记 16:12"> 要记住，你们曾在埃及做过奴隶，你们的上帝耶和华救赎了你们。所以，我吩咐你们这样行。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 23:22; 利未记 19:9–10; 申命记 14:29"> “你们在田间收割庄稼时若遗落了一捆，不可回去取，要留给孤儿寡妇和寄居者。这样，你们的上帝耶和华必使你们凡事蒙福。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 19:10"> 你们打橄榄时，打过一次后不可再打，要把剩下的留给孤儿寡妇和寄居者。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 19:9–10; 申命记 24:19"> 你们摘葡萄时，摘过一次后不可再摘，要把剩下的留给孤儿寡妇和寄居者。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 24:18; 约翰一书 4:10–11; 申命记 5:14–15"> 要记住，你们曾在埃及做过奴隶。所以，我吩咐你们这样行。</span>
</div>
</div>

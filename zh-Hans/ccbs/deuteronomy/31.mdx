## 立约书亚做摩西的接班人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西继续对以色列人说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 34:7; 民数记 27:17; 列王纪上 3:7"> “我现在已经一百二十岁了，无法再继续带领你们，耶和华曾说我不得过约旦河。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:3; 申命记 31:23; 申命记 3:28"> 你们的上帝耶和华要亲自带领你们过河，在你们面前消灭那里的各族，使你们占领他们的土地。约书亚将带领你们过河，正如耶和华所言。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 23:28–31; 申命记 2:33; 申命记 3:3–11"> 耶和华要毁灭那里的各族，像毁灭亚摩利二王西宏和噩及其国家一样。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:2; 申命记 20:16–17; 出埃及记 23:32–33"> 耶和华要把他们交给你们，你们要照我的一切吩咐处置他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:9; 以弗所书 6:10; 诗篇 27:14"> 你们要刚强勇敢，不要惧怕他们，因为你们的上帝耶和华与你们同行，祂不会撇下你们，也不会离弃你们。”</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 3:28; 申命记 31:6; 申命记 1:38"> 摩西把约书亚叫来，当着全体以色列人的面对他说：“你要刚强勇敢！因为你要与百姓一同进入耶和华起誓要赐给他们祖先的土地，把土地分给他们作产业。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 33:14; 申命记 31:6; 约书亚记 1:9"> 耶和华必带领你，与你同在。祂不会撇下你，也不会离弃你。不要惊慌害怕。”</span>
</div>
</div>

## 每七年当众宣读律法一次

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 4:15; 约书亚记 3:3; 申命记 17:18"> 摩西把这律法写好，交给抬耶和华约柜的利未祭司和以色列的众长老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 23:34–43; 申命记 15:1–2"> 摩西吩咐他们说：“每逢免除债务的第七年的住棚节，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:2; 约书亚记 8:34–35; 申命记 16:16–17"> 所有以色列人到你们的上帝耶和华选定的地方朝见祂时，你们要当众大声宣读这律法。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:10; 诗篇 34:11–14; 申命记 6:6–7"> 要招聚所有男女、孩童以及住在你们中间的外族人，让他们聆听这律法，学习敬畏你们的上帝耶和华，谨遵律法上的一切话。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 11:2; 申命记 6:7; 箴言 22:6"> 这样，他们那些还不知道这律法的孩子便有机会听到律法，在你们将要占领的约旦河西岸的土地上，学习终生敬畏你们的上帝耶和华。”</span>
</div>
</div>

## 上帝对摩西和约书亚的指示

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 27:13; 申命记 31:23; 约伯记 2:1"> 耶和华对摩西说：“你快要离世了。叫约书亚与你一起到会幕，我要委派他。”摩西和约书亚就来到会幕。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 40:38; 诗篇 99:7; 出埃及记 33:9–10"> 有云柱停在会幕入口的上方，耶和华在云柱中向他们显现。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 士师记 10:13; 士师记 2:12"> 耶和华对摩西说：“你快要与祖先同眠了。这些百姓将很快在要占领的土地上与外族人的神明苟合，背弃我，违背我与他们所立的约。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:42; 以赛亚书 8:17; 诗篇 104:29"> 那时，我要向他们发怒，离弃他们，掩面不理他们。他们将被吞灭，遭遇许多祸患和灾难，以致他们会说，‘这些祸患临到我们，岂不是因为上帝不在我们中间了吗？’</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 31:16–17"> 那时，我必掩面不理他们，因为他们祭拜其他神明，行为邪恶。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 申命记 31:21–22; 申命记 31:26"> “现在，你要写一首歌，教导以色列人，让他们吟唱，作为我指控他们的证据。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿书 13:6; 申命记 6:10–12; 尼希米记 9:25–26"> 因为当我把他们带到我起誓应许他们祖先的奶蜜之乡后，当他们在那里吃饱喝足后，就会嫌弃我，违背我与他们所立的约，去供奉其他神明。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 5:3; 诗篇 139:2; 约翰福音 2:24–25"> 当许多祸患和灾难临到他们的时候，这首歌就要成为指控他们的证据，因为这首歌要在他们的子孙中世代流传。虽然我还没有带领他们进入我起誓应许之地，我已经知道他们的心思意念。”</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 31:19; 申命记 31:9"> 当天，摩西就写下这首歌，传授给以色列人。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 31:7–8; 申命记 31:14; 使徒行传 7:45"> 耶和华嘱咐嫩的儿子约书亚：“你要刚强勇敢，因为你要带领以色列人进入我起誓应许他们的土地，我必与你同在。”</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 31:9; 申命记 17:18"> 摩西把这律法都写在书上以后，</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 31:9"> 就吩咐抬耶和华约柜的利未人：</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 31:19; 列王纪下 22:8–11; 加拉太书 2:19"> “把这律法书放在你们的上帝耶和华的约柜旁，作为指控你们的证据。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 32:20; 申命记 9:24; 使徒行传 7:51"> 因为我知道你们悖逆、顽固不化，我还活在你们中间的时候，你们尚且背叛上帝，何况我死后呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:1; 申命记 4:26; 申命记 30:19"> 把你们各支派的长老和首领招聚来，我要把这些话告诉他们，叫天地作证来指控他们。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 2:19; 申命记 32:5; 路加福音 21:24"> 我知道，我死后你们会彻底堕落，偏离我吩咐你们行的道，做耶和华视为恶的事，惹祂发怒，将来祸患必临到你们。”</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 3:2; 申命记 4:5; 约翰福音 12:49"> 然后，摩西把这首诗歌从头到尾读给以色列全体会众听。</span>
</div>
</div>

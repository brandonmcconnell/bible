## 要听从耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 6:5; 申命记 10:12; 路加福音 1:74–75"> “你们要爱你们的上帝耶和华，时刻遵守祂的吩咐、律例、典章和诫命。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 8:2–5; 申命记 29:10; 使徒行传 26:22"> 要记住，我现在是对你们，而不是对你们的孩子说话。他们没有亲身经历、亲眼见过你们上帝耶和华的管教、威严、大能的手和伸出的臂膀；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:19; 申命记 4:34; 诗篇 105:27–45"> 祂怎样在埃及行神迹奇事对付埃及王法老及其整个国家；</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 106:11; 出埃及记 14:23–31; 出埃及记 15:19"> 怎样使红海淹没追赶你们的埃及军队和车马，将他们永远毁灭；</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 77:20; 诗篇 106:12–48; 诗篇 78:14–72"> 怎样在旷野一路看顾你们，一直来到这里；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:9–10; 诗篇 106:17; 民数记 16:1–35"> 怎样对付吕便人以利押的儿子大坍和亚比兰，使大地在以色列人当中裂开，吞没了他们及其家人、帐篷和所有随从。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:4–6; 诗篇 145:12; 诗篇 150:2"> 你们亲眼目睹了耶和华的这些伟大作为。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:10; 约书亚记 1:6–7; 以弗所书 3:16"> “因此，你们要遵守我今天吩咐你们的诫命，以便有力量过河，攻取你们将要攻取的土地，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 申命记 4:40; 申命记 6:2"> 长久居住在耶和华起誓要赐给你们祖先及其后裔的奶蜜之乡。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 14:18"> 你们将要攻取的那片土地不像你们离开的埃及。在埃及你们撒种后，要像浇菜园一样辛勤灌溉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“辛勤灌溉”希伯来文是“用脚灌溉”。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:7; 申命记 8:7–9; 诗篇 65:12–13"> 而你们将要占领的那片土地却有山有谷，雨水充足，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 24:6; 诗篇 33:18; 列王纪上 9:3"> 你们的上帝耶和华从岁首到年终时时看顾那里。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 10:12; 申命记 4:29; 申命记 6:17"> “如果你们谨遵我今天吩咐你们的诫命，全心全意地爱你们的上帝耶和华，事奉祂，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 5:7; 利未记 26:4; 以西结书 34:26"> 祂就会按时给你们的土地降下秋雨和春雨，使你们收获谷物、新酒和油，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 104:14; 申命记 6:11; 约珥书 2:19"> 有草场饲养牲畜，丰衣足食。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:27; 希伯来书 3:12; 希伯来书 2:1"> 你们要谨慎，免得被迷惑，转而供奉、祭拜其他神明。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 8:35; 申命记 6:15; 历代志下 6:26"> 否则，耶和华必向你们发怒，使天不下雨、地无出产，以致你们在祂赐给你们的佳美之地上迅速灭亡。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 3:16; 申命记 6:6–9; 箴言 3:1"> “所以，你们要把我的这些吩咐铭记在心，系在手上，戴在额上作记号；</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 以赛亚书 38:19; 申命记 4:9–10"> 要用这些话教导你们的儿女，无论坐在家里或行在路上，或起或卧，都要讲论；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:9"> 也要写在城门上和自家的门框上。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 这样，你们及子孙就可以生活在耶和华起誓要赐给你们祖先的土地上，与天地同长。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 6:17; 申命记 11:13; 申命记 10:20"> 如果你们谨遵我吩咐你们的这一切诫命——爱你们的上帝耶和华，遵行祂的旨意，依靠祂，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:38; 申命记 9:1; 申命记 7:1–2"> 耶和华就会为你们赶走那些比你们强大的民族，你们也必占领他们的土地。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 14:9; 出埃及记 23:31; 创世记 15:18–21"> 你们脚掌踏过的地方都要归你们。你们的疆界南到旷野，北到黎巴嫩，东到幼发拉底大河，西到地中海。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:24; 出埃及记 23:27; 约书亚记 1:5"> 所到之处无人能抵挡你们，因为你们的上帝耶和华会使那些地方的人对你们充满惧怕，正如祂对你们的应许。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 30:1; 申命记 30:15–20; 加拉太书 3:10"> “看啊，我今天把祝福和咒诅摆在你们面前。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:19; 申命记 28:1–14; 以赛亚书 3:10"> 你们若遵行我今天吩咐你们的诫命，就会蒙福。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:15–68; 罗马书 2:8–9; 加拉太书 3:10"> 你们若不遵行你们的上帝耶和华的诫命，偏离我今天吩咐你们当走的道路，随从不认识的其他神明，必受咒诅。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 27:12–26; 约书亚记 8:30–35"> 你们的上帝耶和华带领你们进入并占领那片土地时，你们要在基利心山上宣告祝福，在以巴路山上宣告咒诅。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 12:6; 士师记 7:1; 约书亚记 4:19"> 基利心山和以巴路山属于住在亚拉巴的迦南人，位于约旦河西岸的日落之处，在吉甲对面，靠近摩利橡树。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 1:11; 申命记 9:1; 约书亚记 3:13–17"> 你们就要穿过约旦河，占领耶和华赐给你们的土地了。你们占领那里并定居下来以后，</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 28:20; 申命记 12:32; 帖撒罗尼迦前书 4:1–2"> 要谨遵我今天颁布给你们的一切律例和典章。</span>
</div>

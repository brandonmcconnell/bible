## 合宜的敬拜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:40; 约伯记 7:1; 申命记 4:19"> “只要你们生活在你们祖先的上帝耶和华赐给你们的土地上，就要谨遵以下律例和典章。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:5; 列王纪下 16:4; 民数记 33:51–52"> “你们赶走那里的列邦后，要彻底摧毁他们在高山上、丘陵上、绿树下供奉其神明的地方。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 2:2; 撒迦利亚书 13:2; 民数记 33:52"> 你们要拆毁他们的祭坛，打碎他们的神柱，焚烧他们的亚舍拉神像，砍倒他们神明的雕像，使他们的名字从那里消失。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:23; 申命记 20:18; 申命记 16:21–22"> 你们不可按照他们的方式敬拜你们的上帝耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 12:11; 申命记 26:2; 历代志下 7:12"> 你们的上帝耶和华要在你们众支派中选一个地方作祂的居所，你们要去那里敬拜祂，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:19–20; 玛拉基书 3:10; 利未记 27:32–33"> 把你们的燔祭及其他祭物、十一奉献、举祭、还愿祭、自愿献的祭和头生的牛羊带到那里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 12:18; 利未记 23:40; 申命记 14:26"> 你们和家人要在那里，在你们的上帝耶和华面前吃喝；要为你们所做的一切蒙祂赐福而欢喜快乐。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 21:25; 士师记 17:6; 箴言 21:2"> “你们不可再像今日这样各行其是，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 8:56; 诗篇 95:11; 申命记 25:19"> 因为到如今你们还没有进入你们的上帝耶和华赐给你们作产业的安歇之地。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 33:11; 以西结书 34:28; 申命记 3:27"> 但不久你们将渡过约旦河，定居在那片土地上。你们的上帝耶和华将使你们四境太平，安然居住，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 12:5; 申命记 15:20; 申命记 17:8"> 你们要把我吩咐你们献的燔祭、各种牲祭、十一奉献、举祭和一切还愿祭，带到你们的上帝耶和华选定的敬拜场所。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:7; 申命记 10:9; 申命记 26:12"> 在那里，你们和儿女、仆婢及同城中没有分到土地作产业的利未人，要一起在你们的上帝耶和华面前欢喜快乐。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:28–32; 列王纪上 15:34; 历代志下 15:17"> 你们切不可随处向耶和华献燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 12:11; 哥林多后书 5:19; 申命记 12:5"> 耶和华会在你们的一个支派中选定敬拜的场所，你们只可以在那里献燔祭，做我吩咐你们的一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 14:5; 申命记 15:22–23; 申命记 14:26"> “你们可以随意在居住的各城宰杀牲畜吃，享受你们的上帝耶和华所赐的福，像吃羚羊和鹿一样。洁净的人和不洁净的人都可以吃。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:4; 申命记 15:23; 申命记 12:23–24"> 但你们不可吃血。要把血倒在地上，像倒水一样。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 26:14; 申命记 12:6; 申命记 14:22–29"> 不可在你们的城里吃十一奉献的谷物、新酒和油、头生的牛羊、还愿祭、自愿献的祭和举祭；</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:7; 申命记 14:23; 申命记 12:5"> 要在你们的上帝耶和华选定的地方，与儿女、仆婢及同城的利未人一起在你们的上帝耶和华面前吃。要为你们所做的一切，在你们的上帝耶和华面前欢喜快乐。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 31:4–21; 尼希米记 10:34–39; 申命记 14:27–29"> 切记，只要你们还住在自己的土地上，就不可忘记利未人。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 19:8; 申命记 11:24; 出埃及记 34:24"> “你们的上帝耶和华按照祂的应许扩展你们的疆域后，你们若想吃肉，随时都可以吃。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 12:5; 列王纪上 14:21; 申命记 16:11"> 如果你们的上帝耶和华选定的敬拜场所离你们太远，你们可以在自己的城里，按照我的吩咐，随时宰杀耶和华赐给你们的牛羊吃，</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:15–16"> 就像你们吃羚羊和鹿一样。洁净的人和不洁净的人都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 17:11; 创世记 9:4; 利未记 17:13–14"> 但你们切不可吃血，因为血就是生命；你们不可把生命和肉一起吃。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:16; 申命记 15:23"> 你们切不可吃血，要把血倒在地上，像倒水一样。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:38; 申命记 4:40; 以赛亚书 3:10"> 你们要做耶和华视为正的事——不可吃血，以便你们及子孙凡事顺利。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 18:19; 民数记 5:9–10; 申命记 12:11"> 你们要把圣物和还愿祭带到耶和华选定的地方。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 1:13; 利未记 17:11; 利未记 1:9"> 你们要在你们的上帝耶和华的祭坛上献燔祭，连肉带血都要献上。要把其他祭牲的血倒在坛上，但可以吃祭肉。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 4:40; 约翰福音 15:14; 约翰福音 15:10"> 你们要认真听从我给你们的这些吩咐，做你们的上帝耶和华视为正与善的事，以便你们及子孙凡事顺利，直到永远。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 23:4; 申命记 19:1; 申命记 9:3"> “你们的上帝耶和华将为你们铲除列国。你们要赶走他们，住在他们的土地上。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:2; 以西结书 20:32; 申命记 7:16"> 他们从你们面前被毁灭之后，你们要谨慎，不可受诱惑去效法他们的习俗，不可打听他们神明的事，说，‘这些民族怎样供奉他们的神明呢？我也要效法。’</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 32:35; 申命记 18:9–10; 列王纪下 17:15–17"> 你们不可按照他们的方式敬拜你们的上帝耶和华。他们祭拜自己神明的种种行为令耶和华憎恶，他们甚至焚烧自己的儿女献给他们的神明。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 4:2; 启示录 22:18–19; 约书亚记 1:7"> “你们要谨遵我的一切吩咐，不可增添，也不可删减。</span>

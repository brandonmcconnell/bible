## 前言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 25:1; 约书亚记 22:7; 民数记 33:17–18"> 以下是摩西对以色列人说的话。当时以色列人在约旦河东的旷野、疏弗对面的亚拉巴，即巴兰、陀弗、拉班、哈洗录和底撒哈之间。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 32:8; 民数记 13:26; 申命记 9:23"> 从何烈山取道西珥山到加低斯·巴尼亚，需十一天。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 33:38; 申命记 4:1–2; 民数记 20:1"> 在离开埃及后第四十年的十一月一日，摩西把耶和华的一切吩咐告诉了以色列人。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:21–35; 约书亚记 12:2–6; 约书亚记 13:10–12"> 那时，他已经打败了希实本的亚摩利王西宏，以及盘踞在以得来和亚斯她录的巴珊王噩。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 4:8; 申命记 32:46; 申命记 31:9"> 摩西在约旦河东的摩押讲解律法，说：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:1; 民数记 10:11–13; 出埃及记 19:1–2"> “我们的上帝耶和华在何烈山对我们说，‘你们在这山上已经住了足够时日，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:24; 约书亚记 10:40; 阿摩司书 2:9"> 现在该启程前往亚摩利人的山区、亚拉巴地区、山地、丘陵、南地、沿海一带、迦南人之地和黎巴嫩，直到幼发拉底大河。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 创世记 12:7; 创世记 26:3–4"> 看啊，我把那片土地赐给你们了，你们去占领吧，那是耶和华起誓要赐给你们祖先亚伯拉罕、以撒、雅各和他们后裔的地方。’</span>
</div>
</div>

## 摩西设立首领

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 18:18; 民数记 11:17; 民数记 11:11–14"> “那时，我对你们说，‘我无法独自承担管理你们的重任，</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 10:22; 出埃及记 32:13; 创世记 22:17"> 因为你们的上帝耶和华使你们人丁兴旺，以致今天人数多如天上的星星。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 115:14; 创世记 22:17; 民数记 6:27"> 愿你们祖先的上帝耶和华使你们人数更增千倍，照祂的应许赐福给你们。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 列王纪上 3:7–9; 哥林多后书 2:16"> 但我怎能独自担当解决你们问题和争端的重任呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 18:21; 使徒行传 1:21–23; 民数记 11:16–17"> 你们要从各支派中选出有智慧、有见识、受尊重的人，我要立他们做你们的首领。’</span>
<span className="v" id="v14" data-v="14"> 你们都同意这样的做法。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:18; 出埃及记 18:25–26; 以弗所书 4:11"> 于是，我把各支派中有智慧和受敬重的人立为你们的首领，即千夫长、百夫长、五十夫长、十夫长和其他官长，治理你们。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:24; 出埃及记 22:21; 历代志下 19:6–10"> 我吩咐这些官员要聆听案件，公正地审理同胞之间，或与外族人之间的诉讼，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:19; 出埃及记 18:26; 雅各书 2:9"> 不可偏私，不分贵贱，不惧情面，因为判决来自上帝。如果案件太难，可以交给我处理。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:32; 申命记 4:5; 使徒行传 20:20"> 那时，我把一切当行之事都告诉了你们。</span>
</div>
</div>

## 派人打探迦南

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 1:2; 申命记 8:15; 耶利米书 2:6"> “我们照我们上帝耶和华的吩咐，从何烈山出发，走过你们所见的那大而可怕的旷野，前往亚摩利山区，来到加低斯·巴尼亚。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 1:7–8"> 我对你们说，‘我们的上帝耶和华赐给我们的亚摩利山区到了。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:9; 诗篇 46:1; 民数记 14:8–9"> 看啊，你们祖先的上帝耶和华已把那片土地赐给你们，你们要照着祂的应许去占领那里，不要惊慌害怕。’</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 13:1–20"> 你们都来对我说，‘我们要先派人去打探那地方，回来好告诉我们当走哪条路，当占哪些城。’</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:3–33"> 我同意你们的建议，便从你们当中选出十二人，每支派选一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 13:21–27; 约书亚记 2:1–2"> 他们前往山区，到了以实各谷，打探那地方。</span>
<span className="v" id="v25" data-v="25"> 他们带回来一些那里的果子，禀告说，‘我们的上帝耶和华赐给我们的地方很好。’</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 14:1–4; 使徒行传 7:51; 诗篇 106:24–25"> “但你们却违背你们上帝耶和华的命令，不肯上去。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 9:28; 诗篇 106:25; 民数记 14:3"> 你们在帐篷中埋怨说，‘耶和华憎恨我们，所以才领我们离开埃及，要把我们交在亚摩利人手里，让他们消灭我们。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 13:28–33; 申命记 9:1–2; 约书亚记 15:14"> 我们能上哪里去呢？我们弟兄的报告让我们胆战心惊，他们说那里的人比我们高大，城邑雄伟，城墙高达云霄，还有亚衲人在那里。’</span>
<span className="v" id="v29" data-v="29"> 我对你们说，‘不要惊慌，不要怕他们。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 14:14; 尼希米记 4:20; 罗马书 8:31"> 你们的上帝耶和华必带领你们，为你们争战，正如祂当着你们的面在埃及所行的一样。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 46:3–4; 使徒行传 13:18; 何西阿书 11:3–4"> 你们在旷野曾目睹你们的上帝耶和华像父亲抱儿子一样，一路把你们抱到这地方。’</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:24; 犹大书 1:5; 希伯来书 3:18–19"> 祂为你们开路，为你们找安营的地方，夜间用火柱、白天用云柱为你们引路。尽管如此，你们还是不信靠你们的上帝耶和华。</span>
</div>
</div>

## 惩罚叛逆

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 14:22–30; 诗篇 95:11; 以西结书 20:15"> “你们的埋怨惹耶和华发怒，祂起誓说，</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 95:11"> ‘这邪恶的一代没有一人能看见我起誓要赐给他们祖先的佳美之地，</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 14:24; 约书亚记 14:6–14; 民数记 32:12"> 只有耶孚尼的儿子迦勒能看见，我必把他所踏之地赐给他和他的子孙，因为他一心追随我。’</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 20:12; 申命记 4:21; 申命记 34:4"> 因为你们的缘故，耶和华也向我发怒，说，‘你也不能进入那片土地，</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 3:28; 民数记 14:30; 申命记 31:7–8"> 但你的助手、嫩的儿子约书亚可以进入。你要鼓励他，因为他将带领以色列承受那片土地。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 7:15–16; 民数记 14:3; 民数记 14:31"> 你们说你们的子女会被掳去，但这些还不知善恶的孩子都将进入那片土地，我要把那里赐给他们，他们将占领那里。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 14:25"> 而你们要掉头，沿红海的路回到旷野。’</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 14:39–45; 箴言 19:3; 民数记 22:34"> “于是，你们对我说，‘我们得罪了耶和华，现在我们愿意遵从我们的上帝耶和华的吩咐，上去作战。’你们便各自拿起兵器，以为可以轻易攻占山区。</span>
<span className="v" id="v42" data-v="42" data-xref="民数记 14:41–43; 约书亚记 7:8–13; 以赛亚书 59:1–2"> 但耶和华让我告诉你们，‘不要上去作战，以免被敌人打败，因为我不与你们同在。’</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 14:44; 以赛亚书 63:10; 使徒行传 7:51"> 我把耶和华的话转告了你们，但你们不听，竟违背耶和华的命令，擅自前往山区。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 118:12; 民数记 14:45; 民数记 21:3"> 住在山区的亚摩利人蜂拥出击，打败了你们，从西珥追杀你们，一直追到何珥玛。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 12:17; 诗篇 78:34"> 你们回来在耶和华面前哭泣，但耶和华不理会你们的哭声。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 20:1; 民数记 20:22; 士师记 11:16–17"> 因此，你们在加低斯住了很久。</span>
</div>
</div>

</div>

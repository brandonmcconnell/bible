## 击败巴珊王噩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:33–35; 申命记 1:4; 申命记 29:7"> “之后，我们前往巴珊，巴珊王噩率全军在以得来迎战我们。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 2:10; 历代志下 20:17; 民数记 21:23–25"> 耶和华对我说，‘不要怕他，因为我已把他及其众民和土地交在你手中，你要像从前对付希实本的亚摩利王西宏一样对付他。’</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 21:35; 约书亚记 13:12; 约书亚记 13:30"> “我们的上帝耶和华把巴珊王噩及其众民交在我们手中，我们杀了他们，一个不留。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 4:13; 约书亚记 12:4; 约书亚记 13:30–31"> 我们占领了亚珥歌伯全境，即巴珊王噩的所有城邑，共六十座。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 1:28; 民数记 13:28; 希伯来书 11:30"> 这些城邑围墙高耸，门闩牢固。我们还占领了许多没有城墙的乡村。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:34; 诗篇 135:10–12; 申命记 2:24"> 像对付希实本王西宏一样，我们将这些城邑夷为平地，城中的男女老幼一个不留，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:35; 约书亚记 8:27; 约书亚记 11:11–14"> 只留下牲畜和财物作战利品。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:9–12; 约书亚记 12:2–6; 民数记 32:33–42"> 于是，我们攻占了约旦河东两个亚摩利王的土地，从亚嫩谷一直到黑门山——</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 5:23; 诗篇 29:6; 以西结书 27:5"> 西顿人称黑门山为西连，亚摩利人称之为示尼珥——</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 13:31; 约书亚记 13:11–12; 申命记 4:49"> 我们攻占了高原的城邑、整个基列和巴珊，远至巴珊王噩的城邑撒迦和以得来。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:5; 耶利米书 49:2; 撒母耳记下 12:26"> 巴珊王噩是最后一个利乏音人。他的床是铁做的，存放在亚扪人的拉巴城，长四米，宽一米八。</span>
</div>
</div>

## 分配约旦河东之地

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 2:36; 民数记 32:32–38; 约书亚记 13:8–28"> “我们占领了这片土地后，我把亚嫩谷边的亚罗珥以北地区和基列山区的一半及其城邑，分给吕便支派和迦得支派，</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:39–42; 约书亚记 13:29–32; 历代志上 5:23–26"> 把基列山区的另一半，以及噩的王国巴珊全境——整个亚珥歌伯分给玛拿西半个支派。巴珊地区又被称为利乏音人之地。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:41; 约书亚记 13:13; 撒母耳记下 3:3"> 玛拿西的子孙雅珥得到亚珥歌伯全境，远至基述人和玛迦人的边界。他按自己的名字给巴珊取名叫哈倭特·雅珥，沿用至今。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:39–40; 约书亚记 17:1–3; 约书亚记 22:7"> 我又把基列分给玛吉，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 21:24; 申命记 2:37; 撒母耳记下 24:5"> 把从基列到亚嫩谷，以谷中央为界，远至亚扪人的边界雅博河地区，分给吕便支派和迦得支派。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 12:3; 创世记 14:3; 约书亚记 3:16"> 我还把亚拉巴，就是以约旦河为界，从基尼烈直到东面毗斯迦山脚的亚拉巴海，即盐海地区给了他们。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 32:20–24; 约书亚记 4:12–13; 约书亚记 1:12–15"> “那时我吩咐他们说，‘你们的上帝耶和华已经把这些地方赐给你们，但你们所有的战士必须带着兵器过河，做以色列同胞的先锋。</span>
<span className="v" id="v19" data-v="19"> 我知道你们有许多牲畜，你们的妻子、儿女和牲畜可以留在我分给你们的城邑。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 22:4; 约书亚记 22:8"> 等你们的上帝耶和华使其他以色列人和你们一样有了安身之所，占领了耶和华赐给他们的约旦河西之地后，你们才可以返回我分给你们的家园。’</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 27:18–23; 哥林多后书 12:10; 诗篇 9:10"> 那时我吩咐约书亚说，‘你们的上帝耶和华怎样对付那两个王，你都亲眼看见了。耶和华必以同样的方式对付你将去攻占的各国。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 14:14; 申命记 20:4; 申命记 1:30"> 不要怕他们，因为你的上帝耶和华将为你们争战。’</span>
</div>
</div>

## 摩西不得进入迦南

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 12:8–9"> “那时，我恳求耶和华，说，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 15:11; 申命记 11:2; 诗篇 71:19"> ‘主耶和华啊，你已向仆人彰显你的伟大和权能，天上地下没有神明可与你的大能作为相比！</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 4:21–22; 以西结书 20:6; 出埃及记 3:8"> 求你让我过去看看约旦河那边的佳美之地，那美好的山区和黎巴嫩。’</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 1:37; 申命记 31:2; 历代志上 22:7–9"> 但因你们的缘故，耶和华向我发怒，不听我的恳求，祂对我说，‘够了，不要再跟我提这件事。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 27:12; 申命记 34:1–4; 创世记 13:14–15"> 你可以上毗斯迦山顶，向东南西北眺望，亲眼看看那片土地，因为你不可过约旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 31:3; 申命记 31:7; 申命记 1:38"> 你要委任约书亚，勉励他，支持他，因为他必带领以色列人过河，使他们承受你眺望的那片土地。’</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:6; 申命记 4:46; 民数记 25:3"> 当时，我们驻扎在伯·毗珥对面的谷中。</span>
</div>
</div>

## 最大的诫命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 12:1; 申命记 4:45"> “你们的上帝耶和华吩咐我教导你们以下的诫命、律例和典章，以便你们在将要占领的土地上遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:40; 申命记 13:4; 出埃及记 20:20"> 这样，你们就会得享长寿，你们及子孙就会终生敬畏你们的上帝耶和华，遵守祂借我吩咐你们的一切律例和诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 22:17; 出埃及记 3:8; 创世记 26:4"> 以色列人啊，你们要留心听，谨慎遵行，以便你们在那奶蜜之乡可以凡事顺利、人口极其繁盛，正如你们祖先的上帝耶和华给你们的应许。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 12:29–32; 以赛亚书 44:6; 提摩太前书 2:5"> 听啊，以色列人，耶和华是我们的上帝，耶和华是独一的。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 12:30; 马太福音 22:37; 路加福音 10:27"> 你们要全心、全意、全力爱你们的上帝耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:16; 箴言 7:3; 耶利米书 31:33"> 要将我今天吩咐你们的话牢记在心，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:19; 以弗所书 6:4; 诗篇 78:4–6"> 并教导你们的儿女，无论坐在家里或行在路上，或起或卧，都要讲论这些律例和诫命。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命记 11:18"> 要把它们系在手上、戴在额上作记号，</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 11:20; 以赛亚书 30:8; 以赛亚书 57:8"> 要写在城门上和自家的门框上。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:13; 诗篇 105:44; 尼希米记 9:25"> “你们的上帝耶和华将带你们进入祂向你们祖先亚伯拉罕、以撒和雅各起誓要赐给你们的土地。那里宏伟壮观的城邑不是你们建造的，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 7:12–18; 申命记 8:10–20; 以西结书 16:10–20"> 满屋的美物不是你们积攒的，井不是你们挖掘的，葡萄园和橄榄树也不是你们栽种的。你们在那里吃饱喝足之后，</span>
<span className="v" id="v12" data-v="12"> 要小心，不可忘记把你们从受奴役之地埃及救出来的耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:8; 申命记 10:20; 马太福音 4:10"> 要敬畏你们的上帝耶和华，事奉祂，凭祂的名起誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:6; 约翰一书 5:21; 申命记 13:7"> 不可随从周围各族的神明，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:24; 出埃及记 20:5; 申命记 7:4"> 免得你们的上帝耶和华向你们发怒，把你们从世上消灭；因为祂住在你们当中，祂痛恨不贞。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 17:7; 路加福音 4:12; 马太福音 4:7"> “不可像在玛撒那样试探你们的上帝耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 11:22; 诗篇 119:4; 哥林多前书 15:58"> 要谨遵你们的上帝耶和华吩咐你们的诫命、法度和律例。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 4:40; 申命记 12:25; 罗马书 12:2"> 你们要做耶和华视为正与善的事，以便凡事顺利，得到耶和华起誓要赐给你们祖先的佳美之地，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 33:52–53; 出埃及记 23:28–30; 士师记 3:1–4"> 从你们面前赶出所有敌人，正如耶和华所言。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:14; 出埃及记 12:26; 约书亚记 4:6–7"> “将来你们的子孙会问，‘我们的上帝耶和华给你们颁布这些法度、律例和典章是什么意思？’</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:17–18; 以弗所书 2:11–12; 申命记 15:15"> 你们要告诉他们，‘我们曾在埃及做法老的奴隶，耶和华用大能的手带我们出埃及。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 4:34; 诗篇 58:10–11; 申命记 7:19"> 我们亲眼看见耶和华行伟大而可畏的神迹奇事，惩罚埃及和法老全家。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 6:18; 申命记 6:10; 出埃及记 13:5"> 祂带领我们离开埃及，为要把我们带进祂起誓要赐给我们祖先的这片土地。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:39; 诗篇 41:2; 申命记 10:12–13"> 我们的上帝耶和华吩咐我们遵守这一切律例、敬畏祂，以便我们可以终生受益，生命无忧，正如今日的情形。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 24:13; 罗马书 10:3; 利未记 18:5"> 我们若按照我们的上帝耶和华的吩咐，在祂面前谨遵这一切诫命，便被算为义人。’</span>

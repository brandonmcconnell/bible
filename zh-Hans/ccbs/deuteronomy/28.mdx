## 遵守诫命蒙祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 1:19; 出埃及记 23:22; 利未记 26:3–13"> “你们若全心顺服你们的上帝耶和华，谨遵祂今天借我吩咐你们的一切诫命，祂必使你们超越天下万国。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 1:6; 申命记 28:15; 提摩太前书 4:8"> 你们若听从你们的上帝耶和华的话，以下这些福气必临到你们，追随你们。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 144:12–15; 创世记 39:5; 哈该书 2:19"> “无论你们在城里还是乡间，都必蒙福。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 创世记 49:25; 申命记 7:13"> “你们必子孙昌盛，五谷丰登，牛羊成群。</span>
<span className="v" id="v5" data-v="5"> “你们的篮子和揉面盆都必蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 121:8; 民数记 27:17; 历代志下 1:10"> “你们出入都必蒙福。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:38–41; 利未记 26:7–8; 诗篇 89:23"> “耶和华必使来犯之敌败在你们面前、溃不成军、四散逃命。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:10; 利未记 26:10; 箴言 3:9–10"> “耶和华必使你们凡事蒙福、五谷满仓。你们的上帝耶和华必在祂赐给你们的土地上赐福你们。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 申命记 26:18–19"> “你们若遵守你们上帝耶和华的诫命，遵行祂的旨意，祂必按自己的誓言立你们作祂圣洁的子民。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 7:14; 申命记 11:25; 耶利米书 33:9"> 天下万民将看出你们是耶和华名下的子民，并惧怕你们。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 30:9; 箴言 10:22; 利未记 26:9"> “在耶和华向你们祖先起誓要赐给你们的土地上，祂必使你们子孙昌盛、牛羊成群、五谷丰登。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 15:6; 约珥书 2:23–24; 申命记 15:10"> 耶和华要为你们打开天上的宝库，使你们风调雨顺、凡事蒙福。你们必借贷给多国，却无需向别国借贷。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:1; 申命记 4:6–9; 腓立比书 1:27"> 你们若听从你们的上帝耶和华借我今天吩咐你们的诫命，谨慎遵行，毫不偏离，也不随从、供奉其他神明，祂必使你们做首不做尾，居上不居下。</span>
</div>
</div>

## 违背诫命受咒诅

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 2:2; 申命记 28:2; 申命记 29:20"> “你们若不听从你们的上帝耶和华，不谨遵祂今天借我吩咐你们的一切诫命和律例，祂必使以下的咒诅临到你们，追随你们。</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 3:9–12; 箴言 3:33; 约珥书 1:4"> “无论你们在城里还是乡间，都必受咒诅。</span>
<span className="v" id="v17" data-v="17" data-xref="哈该书 1:6; 申命记 28:5; 诗篇 69:22"> “你们的篮子和揉面盆都必受咒诅。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 26:26; 利未记 26:19–20; 约伯记 18:16–19"> “妇女所生的，土地所产的，牛羊所生的都必受咒诅。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:6; 士师记 5:6–7; 历代志下 15:5"> “你们出入都必受咒诅。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 66:15; 玛拉基书 2:2; 申命记 4:26"> “因为你们作恶、背弃耶和华，祂要使你们凡事受咒诅、混乱不堪、饱受责罚，直到你们被毁灭，迅速灭亡。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 26:25; 耶利米书 24:10; 耶利米书 16:4"> “耶和华要使瘟疫紧紧跟随你们，直到你们在将要占领的土地上被灭绝。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司书 4:9; 利未记 26:16; 哈该书 2:17"> “耶和华要使你们遭受痨病、热症、炎症、炙热、刀剑、干旱和霉烂之灾。这些要危害你们，直到你们灭亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:19; 耶利米书 14:1–6; 列王纪上 18:2"> “耶和华要使你们头顶的天如铜，脚下的地如铁。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 28:12; 以赛亚书 5:24; 阿摩司书 4:11"> “耶和华要使雨水变为尘土，降在你们身上，直到你们灭亡。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 30:17; 以西结书 23:46; 耶利米书 24:9"> “耶和华要使你们被敌人击败、溃不成军、四散逃命，下场令天下万国惊惧。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 34:20; 耶利米书 16:4; 耶利米书 7:33"> 你们的尸体要成为飞禽走兽的食物，必无人赶走它们。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 5:6; 申命记 28:35; 利未记 21:20"> “耶和华要使你们患埃及的脓疮、肿瘤和癣疥，无药可治。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:9–11; 以赛亚书 19:11–17; 以赛亚书 6:9–10"> “耶和华要使你们发疯、瞎眼、心智错乱。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 59:10; 约伯记 5:14; 士师记 6:1–6"> “你们必在大白天摸索，就像盲人在黑暗中摸索一样，你们的道路必不得亨通，你们要终日受人欺压抢掠，无人搭救。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司书 5:11; 耶利米书 8:10; 约伯记 31:10"> “你们聘了妻子，别人必占有她们；你们盖了房屋，必不能住在里面；你们栽种葡萄园，必吃不到园中的出产。</span>
<span className="v" id="v31" data-v="31" data-xref="约伯记 1:14–15; 士师记 6:1"> “你们必看着自己的牛被宰杀却吃不到肉，自己的驴被抢走后一去不还，自己的羊被敌人掳走却无人搭救，</span>
<span className="v" id="v32" data-v="32" data-xref="约珥书 3:6; 申命记 28:41; 约伯记 17:5"> 自己的儿女被外族人掳走，你们终日望眼欲穿，却无能为力。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 5:17; 申命记 28:29–30; 以赛亚书 1:7"> “与你们素不相识的民族必吃光你们土地的出产和劳碌所得，你们必常受欺压，</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 16:10–11; 申命记 28:68; 以赛亚书 33:14"> 以致眼前的一切令你们发疯。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 28:27; 以赛亚书 3:24; 以赛亚书 3:17"> “耶和华要使你们从头到脚长满毒疮，无药可治。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 16:13; 申命记 4:28; 列王纪下 25:11"> “耶和华要带你们和你们立的王，到一个你们和你们祖先都不知道的国家，你们要在那里供奉木石神像。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 25:9; 列王纪上 9:7–8; 耶利米书 24:9"> “在耶和华驱逐你们去的列国，你们的下场令人惊骇，被人嘲笑和讥讽。</span>
<span className="v" id="v38" data-v="38" data-xref="哈该书 1:6; 弥迦书 6:15; 约珥书 1:4"> “你们种的多，却收的少，因为庄稼必被蝗虫吃掉。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 17:10–11; 约珥书 2:2–4; 约拿书 4:7"> “你们栽种、修剪葡萄园，却吃不到葡萄，也喝不到葡萄酒，因为葡萄必被虫子吃掉。</span>
<span className="v" id="v40" data-v="40" data-xref="弥迦书 6:15; 诗篇 23:5; 诗篇 104:15"> “你们境内长满橄榄树，却没有橄榄油抹身，因为橄榄必未熟先落。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 28:32; 耶利米哀歌 1:5; 列王纪下 24:14"> “你们生儿育女，却留不住一个，因为他们必被掳走。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司书 7:1–2; 申命记 28:38–39"> “蝗虫要吃光你们的树木和地上的出产。</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 28:13; 撒母耳记上 13:19–23; 列王纪下 17:20"> “你们中间的外族人要日益兴旺，你们却要日渐衰微。</span>
<span className="v" id="v44" data-v="44" data-xref="申命记 28:12–13; 耶利米哀歌 1:5"> “他们要借贷给你们，你们却不能借贷给他们。他们要做首，你们要做尾。</span>
<span className="v" id="v45" data-v="45" data-xref="申命记 28:15; 以赛亚书 1:20; 耶利米书 24:9–10"> “因为你们不听从你们上帝耶和华的话，不遵守祂吩咐你们的诫命和律例，这些咒诅都必临到你们、追赶你们，直到毁灭你们。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 8:18; 申命记 28:37; 以西结书 14:8"> 这些咒诅要永远作为你们和你们子孙的神迹奇事。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 16:11; 申命记 12:7–12; 尼希米记 9:35–37"> 因为你们在富足时不心甘情愿地事奉你们的上帝耶和华，</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 28:13–14; 耶利米哀歌 5:2–6; 以西结书 4:16–17"> 所以你们必饥饿干渴、赤身裸体、一无所有地侍奉耶和华派来攻击你们的敌人。祂要把铁轭加在你们的颈上，直到消灭你们。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米书 49:22; 耶利米书 48:40"> “耶和华要使一国从遥远的地极兴起，他们要如鹰飞来袭击你们。你们不懂他们的语言。</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 47:6; 历代志下 36:17; 路加福音 21:23–24"> 他们面目狰狞，不尊重年老的，也不怜悯年少的。</span>
<span className="v" id="v51" data-v="51" data-xref="申命记 28:33; 以赛亚书 62:8; 利未记 26:26"> 他们要吃光你们的牛羊、五谷、新酒和油，直到消灭你们。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米书 52:4–7; 以西结书 4:1–8; 马太福音 24:15–16"> 在你们的上帝耶和华所赐给你们的整片土地上，他们要把你们围困在各个城邑中，直到你们所依赖的高大坚固的城墙都倒塌。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米书 19:9; 利未记 26:29"> “当你们被敌人围困、陷入绝境时，你们必吃自己的亲生骨肉，就是你们的上帝耶和华赐给你们的儿女。</span>
<span className="v" id="v54" data-v="54" data-xref="申命记 15:9; 马太福音 20:15; 申命记 13:6"> 你们被敌人围困在各城中，陷入绝境时，连你们中间最温柔体贴的男人也要独自吞吃子女的肉，不肯分给自己的兄弟、爱妻和剩下的儿女，因为他别无所有。</span>
<span className="v" id="v56" data-v="56" data-xref="申命记 28:54; 以赛亚书 3:16; 耶利米哀歌 4:3–6"> 你们被敌人困在各城中，陷入绝境时，连你们中间最温柔、娇嫩得连脚也不肯踏在地上的妇女，都要偷偷吃掉自己生的婴儿和胎胞，不肯分给所爱的丈夫和子女。</span>
<span className="v" id="v58" data-v="58" data-xref="以赛亚书 42:8; 耶利米书 7:9–10; 玛拉基书 1:14"> “如果你们不谨遵这书上所写的一切律法，不敬畏你们的上帝耶和华那荣耀、可畏的名，</span>
<span className="v" id="v59" data-v="59" data-xref="马可福音 13:19; 申命记 28:46; 但以理书 9:12"> 祂必使你们及子孙遭遇严重而长久的灾难和疾病，</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 7:15; 出埃及记 15:26; 申命记 28:27"> 使你们所惧怕的埃及人的一切疾病都降在你们身上，缠住你们，</span>
<span className="v" id="v61" data-v="61" data-xref="申命记 4:25–26"> 还使各种未记在这律法书上的疾病和灾难降在你们身上，直到消灭你们。</span>
<span className="v" id="v62" data-v="62" data-xref="申命记 10:22; 尼希米记 9:23; 申命记 4:27"> 因为你们不听从你们的上帝耶和华的话，即使你们的人数多如天上的星，也将所剩无几。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米书 32:41; 申命记 30:9"> 正如耶和华喜欢赐福你们，使你们人丁兴旺，祂也同样会不惜消灭你们，使你们在将要占领的土地上被铲除。</span>
<span className="v" id="v64" data-v="64" data-xref="申命记 4:27–28; 利未记 26:33; 耶利米书 16:13"> “耶和华要把你们分散到天下万邦，你们要在那里供奉祖祖辈辈素不认识的木石神像。</span>
<span className="v" id="v65" data-v="65" data-xref="利未记 26:36; 罗马书 11:10; 阿摩司书 9:4"> 你们在万邦中将不得安宁，没有落脚之地，耶和华必使你们胆战心惊、目光呆滞、精神颓废。</span>
<span className="v" id="v66" data-v="66" data-xref="耶利米哀歌 1:13; 希伯来书 10:27; 启示录 6:15–17"> 你们必惴惴不安，昼夜恐惧，生死难料。</span>
<span className="v" id="v67" data-v="67" data-xref="申命记 28:34; 约伯记 7:3–4; 启示录 9:6"> 你们必看见可怕之事，以致心中充满恐惧，早上盼望天黑，晚上盼望天亮。</span>
<span className="v" id="v68" data-v="68" data-xref="耶利米书 44:12; 耶利米书 43:7; 何西阿书 8:13"> 耶和华必沿着我曾说你们再不会走的路线，用船把你们送回埃及。你们将在那里卖身做敌人的仆婢，却无人买。”</span>
</div>

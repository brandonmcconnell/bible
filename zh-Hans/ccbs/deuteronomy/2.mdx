## 旷野漂流

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:4; 申命记 1:40; 民数记 14:25"> “之后，我们遵照耶和华的吩咐掉转头，沿红海的路前往旷野，在西珥山区绕行了很久。</span>
<span className="v" id="v2" data-v="2"> 后来，耶和华对我说，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:6; 申命记 2:14; 申命记 2:7"> ‘你们在这山区绕行的日子够了，现在转向北方吧。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 20:14–21; 出埃及记 15:15; 申命记 23:7"> 你要吩咐民众：你们将经过西珥，那里住着你们的亲属以扫的子孙。他们惧怕你们，所以你们要格外谨慎，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 36:8; 约书亚记 24:4; 耶利米书 27:5"> 不可挑起战争，因为我已把西珥山赐给以扫作产业，他们的土地，我一寸也不会赐给你们。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:12; 民数记 20:19; 罗马书 12:17"> 你们吃的、喝的，都要花钱向他们买。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米记 9:21; 申命记 8:2–4"> 你们的上帝耶和华使你们凡事蒙福，看顾着你们走过这辽阔的旷野，四十年来与你们同在，使你们一无所缺。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 9:26; 士师记 11:18; 列王纪下 16:6"> “于是，我们绕过我们亲属以扫的子孙所住的西珥，沿亚拉巴的路，经过以拉他、以旬·迦别，向摩押旷野走去。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 19:36–37; 民数记 21:15; 民数记 21:28"> 耶和华对我说，‘不可骚扰摩押人，不可挑起战争，因为我不会把他们的土地赐给你，我已把亚珥赐给罗得的子孙为业。’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 14:5; 申命记 2:11; 民数记 13:22"> “从前以米人住在亚珥，他们人数众多，像亚衲人一样身材高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:28; 民数记 13:28; 创世记 14:5"> 以米人同亚衲人一样也被称为利乏音人，但摩押人称他们为以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:22; 创世记 14:6; 申命记 2:32–11"> 以前，何利人也住在西珥，但以扫的子孙消灭了他们，占领了他们的土地，住在那里，正如后来以色列人占领了耶和华赐给他们的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 21:12; 民数记 13:23"> 耶和华又说，‘现在，你们要动身过撒烈溪。’于是，我们过了撒烈溪。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 26:64–65; 民数记 14:28–35; 申命记 1:34–35"> 我们从离开加低斯·巴尼亚到穿过撒烈溪，用了三十八年。期间，那一代战士都死光了，正如耶和华的誓言。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 106:26; 以赛亚书 66:14; 诗篇 32:4"> 其实是耶和华的手攻击他们，直到把他们从营中全部消灭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> “民中所有的战士都死后，</span>
<span className="v" id="v17" data-v="17"> 耶和华对我说，</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 以赛亚书 15:1; 民数记 21:15"> ‘今天你要经过摩押边境亚珥。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:9; 士师记 11:13–27; 历代志下 20:10"> 到亚扪人之地后，不可骚扰他们，不可挑起战争，因为我不会把他们的土地赐给你们，我已把那里赐给罗得的子孙作产业。’</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 14:5"> 那里以前也是利乏音人住的地方，亚扪人称利乏音人为散送冥，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 27:7–8; 申命记 1:28; 申命记 2:22"> 利乏音族人数众多，像亚衲人一样身材高大。耶和华在亚扪人面前消灭了他们，让亚扪人占领他们的土地，住在那里。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 36:8; 创世记 36:20–30; 申命记 2:12"> 耶和华也曾为以扫的子孙消灭住在西珥的何利人，让他们占据何利人的土地，住在那里，直到今日。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 10:14; 约书亚记 13:3; 阿摩司书 9:7"> 同样，来自克里特的迦斐托人消灭了迦萨附近乡村的亚卫人，住在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 27:5; 但以理书 4:17; 士师记 11:18–21"> 耶和华说，‘起来穿过亚嫩谷。看啊，我已将亚摩利人希实本王西宏和他的土地交在你手中，你要攻打他，占领他的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 11:25; 出埃及记 15:14–16; 申命记 28:10"> 从今天起，我要使天下万民在你面前惊恐万状，一听到你的名字就吓得发抖。’</span>
</div>
</div>

## 击败希实本王

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 约书亚记 13:18"> “于是，我从基底莫旷野派使者去见希实本王西宏，提出和平的建议，说，</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 11:19; 申命记 2:6; 民数记 21:21–23"> ‘请允许我们从贵国经过，我们只走大路，不会偏离。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 20:19"> 我们吃的喝的，都会花钱向你买，只求让我们步行经过，</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 20:18; 士师记 11:17–18; 申命记 23:3–4"> 就像西珥的以东人和亚珥的摩押人那样对待我们，直到我们越过约旦河，进入我们的上帝耶和华所赐之地。’</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 21:23; 出埃及记 4:21; 约书亚记 11:19–20"> 希实本王西宏却拒绝我们的请求，因为我们的上帝耶和华使他心灵刚硬、顽固不化，好让我们击败他，正如今日的情形。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:8; 申命记 2:24"> 耶和华对我说，‘看啊，我已把西宏和他的土地交给你了，去占领他的土地吧。’</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 21:23–30; 士师记 11:20–23; 诗篇 136:19"> 西宏率领全军在雅杂与我们交战。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 7:2; 约书亚记 21:44; 申命记 3:2–3"> 我们的上帝耶和华使西宏父子及其军队败在我们手下，全军覆没。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 7:2; 撒母耳记上 15:3; 申命记 3:6"> 我们攻占了西宏的所有城邑，将其夷为平地，杀光城中的男女老幼，一个不留，</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 8:27; 申命记 20:14; 民数记 31:9–11"> 只留下牲畜和财物作战利品。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 13:9; 申命记 4:48; 申命记 3:12"> 从亚嫩谷边的亚罗珥和谷中的城，直到基列的所有城邑全被我们攻克，我们的上帝耶和华把这一切都交给了我们。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:24; 申命记 3:16; 创世记 32:22"> 我们遵照我们的上帝耶和华的吩咐，没有进犯亚扪人的土地，即雅博河一带和山区的城邑。</span>
</div>
</div>

## 杀人疑案的处理

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 26:21; 诗篇 5:6; 箴言 28:17"> “在你们的上帝耶和华将要赐给你们的土地上，如果发现有人被杀，陈尸野外，却不知道凶手是谁，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 13:3–4; 申命记 16:18–19"> 当地的长老和审判官就要去测量一下尸体距附近各城邑的距离。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 19:2; 马太福音 11:28–30; 耶利米书 31:18"> 距离尸体最近的那城的长老们要牵一头从未负过轭、从未耕过地的小母牛，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:21–24; 彼得前书 3:18"> 去有溪流但无人耕种过的山谷，在那里把它的颈项打断。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:13; 玛拉基书 2:7; 申命记 10:8"> 利未祭司也要去，因为你们的上帝耶和华拣选他们在祂面前事奉、奉祂的名为人祝福，并审理各种纠纷及人身伤害的事。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 73:13; 诗篇 26:6; 诗篇 51:7"> 那城的长老们要在被打断颈项的小母牛上方洗手，</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 21:21–23; 约伯记 21:31–34; 撒母耳记下 16:8"> 然后祷告说，‘我们的手没有杀这人，我们的眼也没有看见谁杀了他。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 1:14; 列王纪下 24:4; 以西结书 23:24–25"> 耶和华啊，求你赦免你已经救赎的以色列子民，不要把杀害这无辜之人的罪算在你的子民身上。’这样，杀人的罪便可得到赦免。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 19:12–13; 列王纪下 10:30–31; 申命记 13:18"> 你们做耶和华视为正的事，就可以从你们中间除去杀害无辜之人的罪。</span>
</div>
</div>

## 娶女俘的条例

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 20:10–16; 约书亚记 21:44"> “你们和敌人交战时，你们的上帝耶和华会把敌人交给你们，使他们成为你们的俘虏。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 创世记 34:3; 创世记 12:14–15"> 如果你们有人在俘虏中看见美丽的女子，被她吸引，想娶她为妻，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 14:9; 民数记 6:9; 以弗所书 4:22"> 就可以带她回家，让她剃去头发，修剪指甲，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 45:10–11; 路加福音 14:26–27"> 换掉被俘时所穿的衣服，住在那人家中为她父母哀悼一个月。之后，那人便可以和她结为夫妻。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 22:29; 创世记 34:2; 申命记 22:19"> 如果那人不喜欢她，则要让她自由离去，绝不可卖掉她，也不可奴役她，因为他已经羞辱了她。</span>
</div>
</div>

## 长子的权利

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 29:33; 创世记 29:20; 创世记 29:18"> “如果一个人有两个妻子，一个受他宠爱，一个不受他宠爱，二人都给他生了儿子，但长子是不受宠爱的妻子生的，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:10; 历代志上 5:2; 历代志下 21:3"> 分产业的时候，他不可废长立幼，把长子的权利给他所爱之妻生的儿子。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:3; 创世记 25:31–34; 诗篇 105:36"> 他必须承认他不爱之妻所生的长子的名分，分给他双份产业，因为长子是他壮年时所生的儿子，应享有长子的权利。</span>
</div>
</div>

## 惩处逆子的条例

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 19:3; 出埃及记 20:12; 阿摩司书 4:11–12"> “如果一个人的儿子冥顽不灵、悖逆父母、屡教不改，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:3; 申命记 21:2; 申命记 16:18"> 他父母要抓住他，把他带到城门口去见本城的长老，对他们说，</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> ‘我们这个儿子冥顽不灵、悖逆成性，不肯听从我们，是个贪吃好酒之徒。’</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 19:19–20; 申命记 13:10–11; 利未记 24:16"> 全城的人都要用石头打死他，从你们中间除掉这种罪恶。所有以色列人听说后，都会感到害怕。</span>
</div>
</div>

## 罪犯尸体的处理

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 19:31–38; 使徒行传 26:31; 路加福音 23:33"> “如果有人犯了死罪，被处死后挂在木头上，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:13; 约翰福音 19:31; 哥林多后书 5:21"> 不可让尸体在木头上过夜，必须当天埋葬，因为凡挂在木头上的人都是上帝所咒诅的。你们不可玷污你们的上帝耶和华将要赐给你们的土地。</span>
</div>
</div>

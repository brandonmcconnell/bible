## 摩西重新接受诫命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:1–2; 出埃及记 25:10–15; 申命记 10:3–4"> “当时耶和华对我说，‘你要凿出两块石版，与前两块一样，也要做一个木柜，然后上山来见我。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 8:9; 申命记 10:5; 申命记 4:13"> 我要把你摔碎的那两块石版上的话重新写在你凿的石版上。你要把它们放在柜子里。’</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 34:4; 出埃及记 37:1–9; 出埃及记 25:10"> 于是，我用皂荚木做了一个柜子，又凿出两块石版，与前两块一样，然后带着石版上了山。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 9:10; 出埃及记 34:28; 希伯来书 12:18–19"> 耶和华把你们在山脚下聚会时，祂在山上的火焰中向你们颁布的十条诫命，重新刻在石版上，并把石版交给我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:29; 出埃及记 40:20; 申命记 10:2"> 我下山后，遵照耶和华的吩咐把石版放在我做的柜子里。现在石版仍放在那里。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 33:38; 民数记 20:23–28; 民数记 33:30–33"> “我们从亚干人的井<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚干人的井”或译“比罗比尼·亚干”或“比尼亚干井”。">a</a></sup>出发，来到摩西拉。亚伦死在那里，并葬在那里，他儿子以利亚撒接替他做大祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:32–34"> 我们从那里走到谷歌大，又走到溪流之乡约巴他。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:5; 申命记 18:5; 民数记 6:23–26"> 那时，耶和华把利未支派分别出来，派他们抬祂的约柜，侍立在祂面前事奉祂，奉祂的名祝福，至今未变。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:28; 民数记 18:20–24; 申命记 18:1–2"> 因此，利未人在众支派中没有分到土地作产业，耶和华是他们的产业，这是你们的上帝耶和华对他们的应许。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 9:18–19; 申命记 9:25; 出埃及记 34:28"> “和前一次一样，我又在山上待了四十昼夜，耶和华又听了我的祈求，答应不毁灭你们。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:1; 出埃及记 32:34"> 耶和华对我说，‘起来，带民众走吧，去占领我起誓要赐给他们祖先的土地。’</span>
</div>
</div>

## 耶和华的要求

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 6:8; 申命记 6:5; 路加福音 10:27"> “以色列人啊，你们的上帝耶和华对你们有何要求？无非要你们敬畏祂，遵行祂的旨意，爱祂，全心全意地事奉祂，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:39; 申命记 6:24; 雅各书 1:25"> 遵守祂的诫命和律例。我今天把这些诫命和律例赐给你们，是为了你们的益处。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:5; 诗篇 24:1; 诗篇 115:16"> 看啊，天和天上的天、大地和地上的万物，都属于你们的上帝耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:37; 申命记 7:7–8; 罗马书 9:13–23"> 但耶和华只喜爱你们的祖先，从万族中拣选了他们的后裔——你们，正如今日的情形。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 4:4; 申命记 30:6; 利未记 26:41"> 所以，你们要洗心革面，不可再顽固不化。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34; 罗马书 2:11; 但以理书 2:47"> 你们的上帝耶和华是万神之神、万主之主，是伟大、全能、可畏的上帝。祂不徇情面，不受贿赂；</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 146:9; 诗篇 68:5; 耶利米书 49:11"> 祂为孤儿寡妇主持公道，关爱寄居者，供给他们衣食。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 22:21; 利未记 19:33–34; 路加福音 17:18"> 所以，你们要爱寄居者，因为你们也曾寄居埃及。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:13; 申命记 13:4; 路加福音 4:8"> 你们要敬畏你们的上帝耶和华，事奉祂，倚靠祂，凭祂的名起誓。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:14; 诗篇 106:21–22; 出埃及记 15:2"> 你们要赞美祂，祂是你们的上帝，你们亲眼目睹了祂为你们做的伟大而可畏的事。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 46:27; 出埃及记 1:5; 创世记 15:5"> 当年你们祖先下埃及时，只有七十人，现在你们的上帝耶和华使你们多如天上的星辰。</span>
</div>
</div>

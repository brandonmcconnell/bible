## 做上帝的子民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 31:3; 使徒行传 13:19; 申命记 4:38"> “你们的上帝耶和华带领你们进入将要占领的土地时，必从你们面前赶走赫人、革迦撒人、亚摩利人、迦南人、比利洗人、希未人和耶布斯人这七个比你们强大的民族。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 2:2; 出埃及记 23:32–33; 申命记 20:16–17"> 当你们的上帝耶和华把他们交在你们手里、使你们打败他们后，你们必须彻底毁灭他们。不可与他们立约，不可怜悯他们。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:2; 约书亚记 23:12–13; 出埃及记 34:15–16"> 不可与他们通婚，不可让你们的儿女与他们的儿女通婚，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 6:15; 士师记 2:11; 申命记 4:26"> 因为他们会让你们的儿女离弃耶和华去拜其他神明，以致耶和华向你们发怒，迅速毁灭你们。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:24; 申命记 12:2–3; 出埃及记 34:13"> 你们要这样对待他们：拆毁他们的祭坛，打碎他们的神柱，砍下他们的亚舍拉神像，焚烧他们的偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:2; 出埃及记 19:5–6; 彼得前书 2:9"> 因为你们是你们的上帝耶和华的圣民，祂从天下万族中拣选你们做祂宝贵的子民。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 10:22; 罗马书 9:11–15; 罗马书 11:6"> “耶和华喜爱你们、拣选你们，不是因为你们的人口比别的民族多——其实你们在万族中是最小的——</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:2; 出埃及记 32:13; 以弗所书 2:4–5"> 而是因为祂爱你们，遵守祂向你们祖先所起的誓。因此，祂用大能的手把你们从受奴役之地领出来，从埃及王法老手中救赎了你们。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:23; 提摩太后书 2:13; 帖撒罗尼迦后书 3:3"> 所以你们要知道，你们的上帝耶和华是上帝，是信实的上帝，祂向爱祂、遵守祂诫命的人守约、施慈爱直到千代。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:18; 那鸿书 1:2; 罗马书 12:19"> 但祂必毫不迟延地当面报应、毁灭那些恨祂的人。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 14:15; 申命记 4:1; 申命记 5:32"> 所以，你们要谨遵我今天吩咐你们的诫命、律例和典章。</span>
</div>
</div>

## 遵守诫命必蒙福

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 28:1–14; 申命记 7:9; 利未记 26:3–13"> “如果你们听从并谨遵这些典章，你们的上帝耶和华就会信守祂给你们祖先的誓约，以慈爱待你们。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:21; 约翰福音 15:10; 申命记 28:3–5"> 祂会爱你们，赐福给你们，使你们在祂向你们祖先起誓要赐给你们的土地上人丁兴旺，牛羊成群，收获丰富的谷物、新酒和油。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 23:26–33; 申命记 28:4; 诗篇 127:3"> 天下万族之中，你们是最蒙福的，你们的男人、女人和牲畜没有不能生育的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 15:26; 诗篇 105:36–37; 利未记 26:3–4"> 耶和华要使你们免患疾病，免遭你们在埃及所见的恶疾，祂要把那些恶疾降在一切憎恶你们的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:33; 士师记 8:27; 申命记 13:8"> 你们必须灭绝你们的上帝耶和华交在你们手里的各族，不可怜悯他们，不可供奉他们的神明，因为那样会使你们陷入网罗。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 13:32; 民数记 33:53; 申命记 18:21"> “也许你们心里会说，‘这些民族都比我们强大，我们怎能赶走他们呢？’</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 105:5; 申命记 31:6; 申命记 1:29"> 不要怕他们，要牢记你们的上帝耶和华曾如何对付法老和整个埃及，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:34; 尼希米记 9:10–11; 耶利米书 32:20–21"> 你们亲眼目睹祂如何降下大灾难、行神迹奇事、伸出臂膀和大能的手领你们离开埃及，祂也要这样对付你们所惧怕的各族。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 24:12; 出埃及记 23:28–30"> 你们的上帝耶和华还要派黄蜂去攻击他们，直到躲藏起来的残存者也全部灭亡。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 1:5; 申命记 10:17; 尼希米记 9:32"> 不要惧怕他们，因为你们的上帝耶和华住在你们当中，祂是伟大而可畏的上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:29–30; 约书亚记 15:63"> 你们的上帝耶和华将在你们前面逐渐赶走那些民族，你们不可急速地灭尽他们，否则你们周围的野兽会大增，危害你们。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 8:20; 申命记 2:15; 耶利米书 17:18"> 你们的上帝耶和华要将他们交给你们，使他们惊恐万状，直到被灭绝。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 10:8; 约书亚记 23:9; 约书亚记 1:5"> 祂要将他们的王交在你们手中，无人能抵挡你们，你们要毁灭他们，使他们的名字从世上绝迹。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 32:20; 历代志上 14:12; 申命记 17:1"> 你们要烧毁他们的神像，不可贪图神像上的金银，不可将那些金银据为己有，免得你们因此陷入网罗；因为那是你们的上帝耶和华所憎恶的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 13:17; 何西阿书 14:8; 以西结书 11:18"> 不可把可憎之物带到家里，否则你们会像它们一样被毁灭。你们要极其憎恶、厌弃它们，因为它们是当毁灭之物。</span>
</div>
</div>

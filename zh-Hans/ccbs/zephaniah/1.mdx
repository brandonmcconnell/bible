## 耶和华审判的日子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="弥迦书 7:13; 列王纪下 22:16–17; 以西结书 33:27–29"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“我必毁灭地上的一切。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 4:3; 以西结书 7:19; 耶利米书 12:4"> <span className="pl pl-1">我必毁灭人类、兽类、</span><br /><span className="pl pl-1">天上的鸟和海里的鱼。</span><br /><span className="pl pl-1">我必使恶人倒毙，</span><br /><span className="pl pl-1">我必铲除地上的人类。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿书 10:5; 弥迦书 5:13; 列王纪下 23:4–5"> <span className="pl pl-1">“我必伸手攻击犹大，</span><br /><span className="pl pl-1">攻击耶路撒冷的所有居民，</span><br /><span className="pl pl-1">清除巴力的残迹及拜偶像之祭司的名号。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 19:13; 列王纪上 11:33; 列王纪下 17:33"> <span className="pl pl-1">我必铲除那些在屋顶祭拜天上万象的人，</span><br /><span className="pl pl-1">铲除敬拜耶和华并凭祂起誓又凭米勒公起誓的人，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 1:4; 耶利米书 2:13; 耶利米书 15:6"> <span className="pl pl-1">铲除离弃耶和华、不寻求祂、不求问祂的人。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷书 2:20; 撒迦利亚书 2:13; 西番雅书 1:14"> <span className="pl pl-1">要在主耶和华面前肃静，</span><br /><span className="pl pl-1">因为耶和华的日子近了。</span><br /><span className="pl pl-1">耶和华已准备好祭物，</span><br /><span className="pl pl-1">洁净了祂邀请的人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 24:21; 以赛亚书 3:18–24; 耶利米书 22:24–30"> <span className="pl pl-1">耶和华说：“在给耶和华献祭之日，</span><br /><span className="pl pl-1">我必惩罚首领和王子，</span><br /><span className="pl pl-1">以及所有穿外族服装的人。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 5:5; 阿摩司书 3:10; 撒母耳记上 2:15–16"> <span className="pl pl-1">到那日，我必惩罚所有跳过门槛</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“跳过门槛……的人”指祭拜偶像的人，参见撒母耳记上5:5。">a</a></sup><br /><span className="pl pl-1">、</span><br /><span className="pl pl-1">使主人的家充满暴力和欺诈的人。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 33:14; 阿摩司书 8:3; 列王纪下 22:14"> <span className="pl pl-1">到那日，鱼门必传出哭喊声，</span><br /><span className="pl pl-1">新区必响起哀号声，</span><br /><span className="pl pl-1">山陵必发出崩裂的巨响。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 5:1; 耶利米书 25:34; 何西阿书 12:7–8"> <span className="pl pl-1">市场区的居民啊，哀哭吧！</span><br /><span className="pl pl-1">因为所有的商人必灭亡，</span><br /><span className="pl pl-1">所有做买卖的必被铲除。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司书 6:1; 耶利米书 48:11; 以西结书 8:12"> <span className="pl pl-1">那时，我必提着灯巡察耶路撒冷，</span><br /><span className="pl pl-1">惩罚那些安于罪中的人。</span><br /><span className="pl pl-1">他们心想，‘耶和华不赐福也不降祸。’</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 5:11; 弥迦书 6:15; 申命记 28:30"> <span className="pl pl-1">他们的财物必遭抢掠，</span><br /><span className="pl pl-1">家园必沦为废墟。</span><br /><span className="pl pl-1">他们建造房屋，却不能住在里面；</span><br /><span className="pl pl-1">栽种葡萄园，却喝不到葡萄酒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 以西结书 30:3; 西番雅书 1:7"> <span className="pl pl-1">“耶和华的大日子近了，</span><br /><span className="pl pl-1">近了，很快就到了。</span><br /><span className="pl pl-1">那将是痛苦的日子，</span><br /><span className="pl pl-1">勇士也必凄声哀号。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约珥书 2:2; 以赛亚书 22:5; 启示录 6:17"> <span className="pl pl-1">那是降烈怒的日子，</span><br /><span className="pl pl-1">是困苦艰难的日子，</span><br /><span className="pl pl-1">是摧残毁坏的日子，</span><br /><span className="pl pl-1">是黑暗幽冥的日子，</span><br /><span className="pl pl-1">是阴霾密布的日子，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="何西阿书 8:1; 阿摩司书 3:6; 以赛亚书 32:14"> <span className="pl pl-1">是吹号呐喊、</span><br /><span className="pl pl-1">攻打坚城高垒的日子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="启示录 3:17; 诗篇 83:10; 耶利米书 2:17"> <span className="pl pl-1">“我要使灾难临到人类，</span><br /><span className="pl pl-1">以致他们行路像瞎眼的，</span><br /><span className="pl pl-1">因为他们得罪了耶和华。</span><br /><span className="pl pl-1">他们的血必如灰尘般被倒出，</span><br /><span className="pl pl-1">他们的尸体必如粪便般被丢弃。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:8; 以西结书 7:19; 箴言 11:4"> <span className="pl pl-1">在耶和华发怒的日子，</span><br /><span className="pl pl-1">他们的金银救不了他们。</span><br /><span className="pl pl-1">祂的怒火必吞噬大地，</span><br /><span className="pl pl-1">祂必骤然毁灭一切世人。”</span></span>
</div>
</div>

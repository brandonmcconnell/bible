## 追求长进

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:10; 提摩太后书 1:9; 罗马书 8:28–30"> 因为我们认识了用自己的荣耀和美德呼召我们的上帝，上帝以祂神圣的能力将生命与敬虔所需要的一切赐给了我们。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:23–24; 以西结书 36:25–27; 哥林多后书 3:18"> 借此，祂已将既宝贵又伟大的应许赏给了我们，使我们脱离世上私欲带来的败坏，能够有份于上帝的性情。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:8; 箴言 4:23; 彼得后书 3:18"> 正因如此，你们要加倍努力，不仅要有信心，还要有美德；不仅要有美德，还要有知识；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 罗马书 5:3–4; 路加福音 21:19"> 不仅要有知识，还要有自制；不仅要有自制，还要有忍耐；不仅要有忍耐，还要有敬虔；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:1; 罗马书 12:10; 帖撒罗尼迦前书 3:12"> 不仅要有敬虔，还要有爱弟兄姊妹的心；不仅要有爱弟兄姊妹的心，还要有爱众人的心。</span>
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 约翰福音 15:2; 希伯来书 6:12"> 你们如果具备这些品质，并且不断加强，就不会对我们主耶稣基督的认识停滞不前，毫无果效。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得后书 2:18–20; 以弗所书 5:26; 提多书 2:14"> 缺乏上述品质的人则是目光短浅，甚至瞎眼，忘记他从前的罪已经得到洁净。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 3:17; 路加福音 6:47–49; 希伯来书 6:11"> 所以，弟兄姊妹，你们要更加努力，以确定自己蒙了呼召和拣选。你们这样做，就绝不会失足犯罪，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 5:10; 马太福音 25:34; 启示录 3:21"> 进入我们的主和救主耶稣基督永恒国度的大门必为你们敞开。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 2:21; 罗马书 15:14–15; 腓立比书 3:1"> 虽然你们已经知道这些事，并且在已有的真道上也很笃定，但我还是要常常提醒你们。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 3:1; 彼得后书 1:14; 希伯来书 13:3"> 我觉得应当趁着我还在世的时候<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“还在世的时候”希腊文是“还在这帐篷里的时候”，作者用帐篷指自己的身体。">a</a></sup>提醒你们，激励你们，</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:6; 约翰福音 21:18–19; 申命记 31:14"> 因我知道自己离世的日子已经不远了，正如我们的主耶稣基督指示我的。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 31:19–29; 诗篇 71:18; 约书亚记 24:24–29"> 我要尽力使你们在我离世以后仍然常常记得这些事。</span>
</div>
</div>

## 见证基督的荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:14; 约翰福音 1:14; 提摩太前书 1:4"> 我们从前告诉你们有关主耶稣基督的大能和祂降临的事，并非根据巧妙虚构的传说，而是我们亲眼见过祂的威荣。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:7; 马太福音 17:5; 马太福音 3:17"> 祂从父上帝那里得到了尊贵和荣耀，那时从至大荣光中有声音对祂说：“这是我的爱子，我喜悦祂。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="马太福音17:5；马可福音9:7；路加福音9:35。">b</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:6; 约书亚记 5:15; 出埃及记 3:5"> 当时我们和祂一同在圣山上，亲耳听见了这来自天上的声音。</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 22:16; 以赛亚书 9:2; 诗篇 119:105"> 这使我们更加确信先知的预言。你们要好好留意这些预言，把这些预言看作照耀在黑暗中的明灯，一直到天破晓、晨星在你们心中升起。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:3; 罗马书 12:6; 罗马书 6:6"> 你们首先该知道：圣经上的一切预言都不可随人的私意解释，</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:15–17; 彼得前书 1:11; 撒母耳记下 23:2"> 因为预言绝非出于人的意思，都是人受了圣灵的感动，讲出上帝的信息。</span>
</div>
</div>

## 假教师

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 犹大书 1:4; 申命记 13:1–3"> 以往曾经有假先知在百姓中出现，将来在你们中间也同样会有假教师出现。他们暗地里引进使人灭亡的异端邪说，甚至否认那位买赎他们的主。这些人正迅速地自招灭亡。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 2:24; 犹大书 1:10; 彼得前书 2:12"> 许多人会效法他们邪恶无耻的行为，致使真理之道被人毁谤。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 2:17; 申命记 32:35; 罗马书 16:18"> 他们贪婪成性，会用花言巧语在你们身上牟利。这种人的刑罚自古已经判定，他们很快就会灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="犹大书 1:6; 马太福音 25:41; 罗马书 8:32"> 即使天使犯了罪，上帝也没有容忍他们，而是把他们扔进地狱里，囚在幽暗的深坑等候审判。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:7; 彼得后书 3:6; 犹大书 1:14–15"> 上帝也没有容忍远古的世代，曾用洪水淹灭了世上不敬虔的恶人，只留下传讲公义的挪亚和他的七位家人。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 路加福音 17:28–30; 申命记 29:23"> 上帝也审判了所多玛和蛾摩拉，将二城毁灭，烧为灰烬，作为以后不敬虔之人的警戒。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 19:16; 创世记 19:29; 创世记 19:7–8"> 祂只拯救了因恶人的淫乱放荡而忧伤的义人罗得，</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 119:158; 以西结书 9:4; 诗篇 119:136"> 因为义人罗得住在他们当中，天天耳闻目睹他们的不法行为，他正直的心很痛苦。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 34:15–19; 哥林多前书 10:13; 启示录 3:10"> 可见上帝知道怎样拯救敬虔的人脱离试炼，把不义的人拘禁在刑罚之下，等候审判的日子，</span>
<span className="v" id="v10" data-v="10" data-xref="犹大书 1:16; 犹大书 1:10; 犹大书 1:18"> 尤其是那些放纵污秽的情欲、轻视权柄的人。他们胆大妄为，肆无忌惮地毁谤有尊荣的。</span>
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:9; 帖撒罗尼迦后书 1:7; 诗篇 104:4"> 即使力量和权能更大的天使都不在主面前用毁谤的话控告有尊荣的。</span>
<span className="v" id="v12" data-v="12" data-xref="犹大书 1:10; 耶利米书 12:3; 加拉太书 6:8"> 但他们好像没有理性，生下来就是预备让人捉去宰杀的牲畜，对自己不懂的事也随口毁谤，最终必像牲畜一样被毁灭。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:13; 罗马书 2:8–9; 希伯来书 2:2–3"> 他们多行不义，必自食恶果。他们喜爱在大白天寻欢作乐，是败类和渣滓，一面和你们同席，一面以欺骗为乐。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 2:3; 彼得后书 2:18; 以弗所书 2:3"> 他们眼中充满淫欲，不停地犯罪，引诱那些信心不坚定的人。他们贪婪成性，实在是该受咒诅！</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 2:14; 犹大书 1:11; 申命记 23:4–5"> 他们离弃正道，走入歧途，重蹈比珥之子巴兰的覆辙。巴兰贪爱不义之财，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 22:21–33; 传道书 7:25; 路加福音 16:11"> 因自己的罪而受了责备。不能说话的驴竟然像人一样说起话来，制止了他狂妄的行为。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:12–13; 以弗所书 4:14; 耶利米书 14:3"> 他们如同枯干的水井和被狂风吹散的雾气，有幽幽黑暗留给他们。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:20; 犹大书 1:15–16; 罗马书 13:13"> 他们口出狂言，空话连篇，以肉体的邪情私欲为饵，诱惑那些刚刚摆脱了荒谬生活的人。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:34; 罗马书 6:16–22; 加拉太书 5:13"> 他们许诺给人自由，而自己却被败坏奴役，因为人被什么制服，就被什么奴役。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 希伯来书 6:4–8; 腓立比书 3:19"> 他们如果借着认识我们的主和救主耶稣基督，已经摆脱了世俗的污秽，但后来又被这些事缠住、俘虏了，结局会比以前更糟糕。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 18:24; 希伯来书 6:4–6; 雅各书 4:17"> 他们明知道正路，却背弃了传给他们的神圣诫命，这样倒不如不知道的好。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 26:11"> 俗语说得好：“狗转身吃自己所吐的；猪洗干净了，又回到污泥里去打滚。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="箴言26:11。">a</a></sup>这些话正好用在他们身上。</span>
</div>

## 主再来的应许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:6; 彼得后书 1:12–15; 彼得前书 1:22"> 亲爱的弟兄姊妹，我现在写给你们的是第二封信。这两封信都是为了提醒你们，激励你们保持真诚的心，</span>
<span className="v" id="v2" data-v="2" data-xref="犹大书 1:17; 彼得后书 2:21; 路加福音 1:70"> 叫你们记得从前圣先知们说的预言，以及我们的主和救主借使徒传给你们的诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 提摩太前书 4:1–2; 彼得后书 2:10"> 最重要的是，你们要知道，末世必出现冷嘲热讽、放纵自己邪情私欲的人。他们说：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 17:15; 玛拉基书 2:17; 耶利米书 5:12–13"> “主要降临的应许在哪里？从我们的祖先长眠地下直到现在，万物依旧与创世之初一样。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:3; 创世记 1:9; 诗篇 24:2"> 他们故意忽略：太初，上帝凭口中的话语创造了诸天，并借着水从水中造出了地；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:38–39; 彼得后书 2:5; 路加福音 17:27"> 后来，那个世界被水淹没而毁灭了。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得后书 3:10; 以赛亚书 51:6; 彼得后书 3:12"> 现在的天地同样是凭上帝的话语保留到被火焚烧的日子，就是不敬虔的人被审判和毁灭的日子。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 90:4; 罗马书 11:25; 哥林多前书 12:1"> 亲爱的弟兄姊妹，有一件事你们不可忽略，就是主看一日如千年，千年如一日。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 2:4; 罗马书 2:4; 哈巴谷书 2:3"> 主的应许还未实现，有人以为祂拖延，其实祂不是拖延，而是在宽容你们。祂不愿任何人灭亡，愿意人人都悔改。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:1; 马太福音 24:35; 彼得后书 3:7"> 不过，主的日子会像贼一样突然临到。那日，诸天必在一声巨响中消失，有形有质的都要被烈火熔化，大地和其中的一切将不复存在。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 1:15; 腓立比书 1:27; 彼得前书 2:12"> 既然一切都要这样被熔化，你们在热切等候上帝的日子来临期间，该过怎样圣洁、敬虔的生活啊！因为到那日，天要被火焚毁，有形有质的都要被烈火熔化。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 65:17; 启示录 21:1; 以赛亚书 66:22"> 但我们等候的是上帝应许的新天新地，有公义住在其中。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 5:23; 帖撒罗尼迦前书 3:13; 腓立比书 1:10"> 所以，亲爱的弟兄姊妹，你们既然盼望这些事，就当努力使自己在主面前毫无瑕疵，无可指责，安然无惧。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 2:4; 彼得后书 3:9; 提摩太前书 1:16"> 你们要把我们主的宽容看作是让众人得救的机会，正如我们亲爱的弟兄保罗按着上帝赐给他的智慧写信告诉你们的。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:6; 希伯来书 5:11; 雅各书 1:8"> 他所有的书信都谈到这些事。一些不学无术、反复无常的人曲解了信中一些难懂的地方，就像曲解其他经文一样，他们是自取灭亡。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 3:14; 歌罗西书 2:8; 哥林多后书 11:13–15"> 因此，亲爱的弟兄姊妹，你们既然预先知道了这些事，就应该小心谨慎，不要让那些不法之徒用错谬的理论引诱你们，使你们失去原本坚定的立场。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:10; 以弗所书 4:15; 彼得前书 2:2"> 相反，你们要在我们的主和救主耶稣基督的恩典中不断长进，越来越认识祂。 愿荣耀归给祂，从现在直到永远。阿们！</span>

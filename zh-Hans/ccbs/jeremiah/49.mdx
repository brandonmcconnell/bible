## 审判亚扪的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 1:13–15; 西番雅书 2:8–11; 以西结书 25:2–10"> 关于亚扪人，耶和华说：<br /><span className="pl pl-1">“难道以色列没有子孙？</span><br /><span className="pl pl-1">没有继承人吗？</span><br /><span className="pl pl-1">为什么祭拜米勒公的人占据了迦得，住在城邑中？”</span><br /></span>

<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 48:7; 耶利米书 48:37; 以赛亚书 15:2"> <span className="pl pl-1">“希实本啊，哀哭吧！</span><br /><span className="pl pl-1">因为艾城毁灭了。</span><br /><span className="pl pl-1">拉巴的居民啊，痛哭吧！</span><br /><span className="pl pl-1">披上麻衣悲伤地在城墙内跑来跑去吧！</span><br /><span className="pl pl-1">因为米勒公及其祭司和官长都要被掳走。</span><br /></span>

## 审判以东的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 1:11–12; 耶利米书 25:21; 创世记 36:15"> <span className="pl pl-1">关于以东，万军之耶和华说：</span><br /><span className="pl pl-1">“提幔再没有智慧了吗？</span><br /><span className="pl pl-1">谋士已无计可施了吗？</span><br /><span className="pl pl-1">他们都失去智慧了吗？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 25:23; 耶利米书 46:21; 耶利米书 49:30"> <span className="pl pl-1">底但的居民啊，</span><br /><span className="pl pl-1">你们要转身逃命，</span><br /><span className="pl pl-1">藏在深洞里，</span><br /><span className="pl pl-1">因为我必在所定之时降灾祸惩罚以扫。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亚书 1:5–6; 以赛亚书 17:6"> <span className="pl pl-1">人们到你那里摘葡萄，难道不留下几串吗？</span><br /><span className="pl pl-1">盗贼夜间来偷东西，难道不只偷所需要的吗？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 17:14; 玛拉基书 1:3–4; 以赛亚书 45:3"> <span className="pl pl-1">但我要把以扫洗劫一空，</span><br /><span className="pl pl-1">我要使他无处藏身，无法隐藏。</span><br /><span className="pl pl-1">他及其孩子、弟兄和邻居必一同灭亡。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 68:5; 何西阿书 14:3; 雅各书 1:27"> <span className="pl pl-1">撇下你的孤儿吧！</span><br /><span className="pl pl-1">我必使他们存活；</span><br /><span className="pl pl-1">你的寡妇也可以倚靠我。”</span></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 25:28–29; 俄巴底亚书 1:16; 耶利米书 25:15"> 耶和华说：“看啊，那些本不该喝这杯愤怒的人尚且要喝，更何况你们呢？你必难逃惩罚，你一定要喝这杯愤怒。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 22:16; 以赛亚书 34:6; 创世记 36:33"> 因为我已凭自己起誓，波斯拉必沦为废墟，令人惊骇，被人嘲笑和咒诅。它周围的城邑要永远荒凉。这是耶和华说的。”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 30:4; 以赛亚书 37:7; 以西结书 7:25–26"> <span className="pl pl-1">我从耶和华那里听到消息，</span><br /><span className="pl pl-1">有位使者被派去对列国说：</span><br /><span className="pl pl-1">“聚集起来攻打以东，</span><br /><span className="pl pl-1">准备争战吧！”</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:51; 俄巴底亚书 1:2; 弥迦书 7:10"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“以东啊，我要使你在列国中最弱小，</span><br /><span className="pl pl-1">被世人藐视。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:25; 阿摩司书 9:2; 约伯记 39:27"> <span className="pl pl-1">你这栖身在岩穴中、盘踞在高山上的民族啊，</span><br /><span className="pl pl-1">你令人惊惧、心高气傲，</span><br /><span className="pl pl-1">其实只是自欺。</span><br /><span className="pl pl-1">尽管你像老鹰在高处搭窝，</span><br /><span className="pl pl-1">我也必把你拉下来。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 35:7; 耶利米书 50:13; 耶利米书 49:13"> “以东的下场必令人惊骇，它的满目疮痍令所有路人惊骇和嗤笑。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 49:33; 申命记 29:23; 耶利米书 50:40"> 那里要像所多玛、蛾摩拉及其周围的城邑一样被毁灭，人烟绝迹。这是耶和华说的。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 12:5; 耶利米书 30:21; 耶利米书 50:44–46"> 看啊，我必在瞬间把以东人赶离家园，如约旦河边丛林中跳出的狮子赶散草场的羊群。我要派我拣选的人统治这地方。谁能与我相比？谁能与我较量？哪位首领能抵挡我？”</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 50:45; 玛拉基书 1:3–4; 耶利米书 49:7"> 因此，你们要听听耶和华攻击以东的策略，听听祂攻击提幔居民的计划。他们的孩子要被拖走，他们的家园要被毁灭。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 50:46; 以西结书 32:10; 以赛亚书 14:4–15"> 以东倾覆的声音震动大地，哭喊声直传到红海。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 48:40–41; 何西阿书 8:1; 以赛亚书 13:8"> 看啊，敌人必像展翅飞来的鹰一样冲下来攻击波斯拉。到那日，以东的勇士必像临盆的妇女一样胆战心惊。</span>
</div>
</div>

## 审判以拦的预言

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 10:22; 但以理书 8:2; 耶利米书 25:25"> 犹大王西底迦执政初期，耶和华告诉了耶利米先知有关以拦的事。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 22:6; 耶利米书 51:56; 诗篇 46:9"> 万军之耶和华说：“看啊，我要摧毁以拦的弓箭手，那是他们的精锐之师。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 49:32; 启示录 7:1; 以西结书 5:10"> 我要使敌人从四面八方如风而来，把以拦人驱散到四方，使他们流落到列国。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 9:16; 耶利米书 48:2; 耶利米书 49:22"> 我要使以拦人在想杀他们的仇敌面前惊恐万分，我要发烈怒降祸给他们，用刀剑追杀他们，直到彻底消灭他们。这是耶和华说的。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 43:10; 但以理书 7:9–14"> 我要在以拦设立我的宝座，消灭那里的君王和官长。这是耶和华说的。</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米书 48:47; 何西阿书 3:5; 弥迦书 4:1"> 但将来有一天，我要使被掳的以拦人返乡。这是耶和华说的。”</span>

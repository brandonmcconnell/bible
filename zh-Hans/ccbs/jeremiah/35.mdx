## 顺服的利甲族和悖逆的犹大人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 23:35; 耶利米书 1:3; 耶利米书 25:1"> 约西亚的儿子犹大王约雅敬执政期间，耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:55; 历代志上 9:26; 列王纪上 6:5–6"> “你去利甲族那里，邀请他们到耶和华殿的一个房间，给他们酒喝。”</span>
<span className="v" id="v3" data-v="3"> 于是，我将哈巴洗尼雅的孙子、雅利米雅的儿子雅撒尼亚，以及雅撒尼亚的弟兄和儿子等利甲全族的人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 33:1; 列王纪下 12:9; 历代志下 8:14"> 领到耶和华的殿，进入上帝的仆人伊基大利之子哈难众儿子的房间。这房间靠近官长的房间，在殿门守卫沙龙的儿子玛西雅的房间上面。</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 9:7; 阿摩司书 2:12; 哥林多后书 2:9"> 我把盛满酒的杯和壶摆在利甲全族面前，请他们喝酒。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 1:15; 历代志上 2:55; 列王纪下 10:15"> 他们却说：“我们不喝酒，因为我们的祖先利甲的儿子约拿达曾吩咐我们和我们的子孙永远不可喝酒，</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 35:10; 创世记 25:27; 尼希米记 8:14–16"> 不可盖房，不可撒种，不可栽植葡萄或拥有葡萄园，一辈子都要住帐篷，以便在你们寄居之地长久居住。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:20; 箴言 4:10; 箴言 1:8–9"> 我们遵守他的一切吩咐，我们和我们的妻子儿女从不喝酒，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 6:6; 耶利米书 35:7; 诗篇 37:16"> 不盖房，也没有葡萄园、田地和种子。</span>
<span className="v" id="v10" data-v="10"> 我们住帐篷，遵守我们祖先约拿达的一切吩咐。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:14; 耶利米书 4:5–7; 但以理书 1:1–2"> 但当巴比伦王尼布甲尼撒进攻这里的时候，我们决定来耶路撒冷躲避迦勒底和亚兰的军队。因此，我们现在住在耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华对耶利米说：</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:33; 耶利米书 5:3; 耶利米书 6:8–10"> “这是以色列的上帝——万军之耶和华的话，你去告诉犹大人和耶路撒冷的居民，‘耶和华说：你们不肯受教并听从我的话吗？</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:3–4; 耶利米书 7:24–26; 箴言 1:20–33"> 利甲的儿子约拿达吩咐他的子孙不可喝酒，他们直到现在都不喝酒，因为他们听从祖先的吩咐。但我屡次告诫你们，你们却不听我的话。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 18:11; 以西结书 18:30–32; 耶利米书 25:5–6"> 我再三差遣我的仆人——众先知劝你们各自改邪归正，不要追随、祭拜其他神明，以便你们可以在我赐给你们和你们祖先的土地上安居乐业，你们却充耳不闻，毫不理会。</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 1:6; 耶利米书 35:14; 路加福音 15:11–13"> 利甲的儿子约拿达的子孙尚且听从他们祖先的吩咐，你们却不听从我的话。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 66:4; 以赛亚书 65:12; 罗马书 10:21"> 因此，以色列的上帝——万军之耶和华说，我要给犹大和耶路撒冷的居民降下我宣布的一切灾祸。因为我对他们说话，他们不听；我呼唤他们，他们不理会。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16; 出埃及记 20:12; 以弗所书 6:1–3"> 然后，耶利米对利甲族说：“以色列的上帝——万军之耶和华说，‘你们听从祖先约拿达的吩咐，遵守他的一切命令，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 15:19; 路加福音 21:36; 耶利米书 33:17–18"> 因此，利甲的儿子约拿达的子孙必永远事奉我。这是以色列的上帝——万军之耶和华说的。’”</span>
</div>
</div>

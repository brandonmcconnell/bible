<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="创世记 18:23–32; 历代志下 16:9; 以西结书 22:30"> 耶和华说：<br /><span className="pl pl-1">“你们在耶路撒冷街头四处看看，</span><br /><span className="pl pl-1">在广场找找，</span><br /><span className="pl pl-1">如果你们能找到一个公正诚实的人，</span><br /><span className="pl pl-1">我就赦免这城。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:16; 耶利米书 4:2; 何西阿书 4:1–2"> <span className="pl pl-1">虽然他们凭永活的耶和华起誓，</span><br /><span className="pl pl-1">却口是心非。”</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 2:30; 耶利米书 7:28; 以赛亚书 9:13"> <span className="pl pl-1">耶和华啊，你关注的不是诚实吗？</span><br /><span className="pl pl-1">你责打他们，他们不感到疼痛；</span><br /><span className="pl pl-1">你严惩他们，他们仍不受教。</span><br /><span className="pl pl-1">他们拒不悔改，</span><br /><span className="pl pl-1">脸比石头还硬。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 8:7; 何西阿书 4:6; 以赛亚书 28:9–13"> <span className="pl pl-1">我想：“他们贫穷、愚昧，</span><br /><span className="pl pl-1">不明白耶和华的道，</span><br /><span className="pl pl-1">也不知道他们上帝的法令。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 2:20; 雅各书 2:5–7; 马太福音 19:23–26"> <span className="pl pl-1">我要找他们的首领说话，</span><br /><span className="pl pl-1">因为这些首领明白耶和华的道，</span><br /><span className="pl pl-1">知道他们上帝的法令。”</span><br /><span className="pl pl-1">然而，他们却一致折断轭，</span><br /><span className="pl pl-1">挣开绳索。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 4:7; 哈巴谷书 1:8; 西番雅书 3:3"> <span className="pl pl-1">因此，林中的狮子必袭击他们，</span><br /><span className="pl pl-1">荒野的豺狼必残害他们，</span><br /><span className="pl pl-1">豹子也蹲伏在他们的城外，</span><br /><span className="pl pl-1">伺机撕裂出城的人，</span><br /><span className="pl pl-1">因为他们罪大恶极，屡屡叛道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:8; 约书亚记 23:7; 耶利米书 2:11"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“耶路撒冷啊，我怎能赦免你呢？</span><br /><span className="pl pl-1">你的儿女背弃我，</span><br /><span className="pl pl-1">凭假神起誓。</span><br /><span className="pl pl-1">我供应他们的一切需要，</span><br /><span className="pl pl-1">他们却纵情淫乱，</span><br /><span className="pl pl-1">涌向娼妓的家。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 13:27; 申命记 5:18; 撒母耳记下 11:2–4"> <span className="pl pl-1">他们像吃得肥壮、发情的公马，</span><br /><span className="pl pl-1">个个垂涎邻居的妻子。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:9; 耶利米书 5:29; 以赛亚书 1:24"> <span className="pl pl-1">我怎能不惩罚他们呢？</span><br /><span className="pl pl-1">我怎能不亲自报应这样的国民呢？</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 4:27; 马太福音 22:7; 阿摩司书 9:8"> <span className="pl pl-1">你们要上去毁坏她的葡萄园，</span><br /><span className="pl pl-1">但不可彻底毁坏。</span><br /><span className="pl pl-1">要砍掉枝子，</span><br /><span className="pl pl-1">因为那些枝子不属于耶和华。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:20; 以赛亚书 48:8; 何西阿书 6:7"> <span className="pl pl-1">以色列家和犹大家全然背叛我。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="历代志下 36:16; 以西结书 12:22–28; 耶利米书 23:14–17"> <span className="pl pl-1">“他们毁谤耶和华说，</span><br /><span className="pl pl-1">‘祂不会管的，灾祸不会临到我们，</span><br /><span className="pl pl-1">我们必不会遇见刀剑和饥荒。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 14:15; 约伯记 8:2; 耶利米书 14:13"> <span className="pl pl-1">先知不过是一阵风，</span><br /><span className="pl pl-1">他们的话并非来自上帝，</span><br /><span className="pl pl-1">他们预言的灾祸必降临到自己身上。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:29; 耶利米书 1:9; 何西阿书 6:5"> <span className="pl pl-1">因此，万军之上帝耶和华对我说：</span><br /><span className="pl pl-1">“因为他们说了这话，</span><br /><span className="pl pl-1">我要使我的话在你口中成为火，</span><br /><span className="pl pl-1">使他们像柴一样被烧毁。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:49; 耶利米书 4:16; 以赛亚书 33:19"> <span className="pl pl-1">以色列家啊，我要使一个国家，</span><br /><span className="pl pl-1">一个历久不衰的古国从远方来攻击你们，</span><br /><span className="pl pl-1">你们不明白他们的语言，</span><br /><span className="pl pl-1">也听不懂他们说的话。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 5:28; 诗篇 5:9; 罗马书 3:13"> <span className="pl pl-1">他们都是勇士，</span><br /><span className="pl pl-1">他们的箭袋像敞开的坟墓。</span><br /></span>

<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 5:10; 罗马书 11:1–5; 耶利米书 4:27"> 耶和华说：“即使在那时，我也不会彻底毁灭你们。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 9:8–9; 申命记 28:47–48; 耶利米书 22:8–9"> 耶利米啊，如果有人问，‘为什么我们的上帝耶和华这样待我们？’你可以对他们说，‘你们怎样背弃耶和华，在自己的土地上供奉外族的神明，也要怎样在异地他乡服侍外族人。’</span>
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">“要向雅各家宣告，</span><br /><span className="pl pl-1">在犹大传讲，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 28:26; 以西结书 12:2; 以赛亚书 6:9–10"> <span className="pl pl-1">‘听着，你们这群愚昧无知的人啊，</span><br /><span className="pl pl-1">你们视而不见，</span><br /><span className="pl pl-1">听而不闻。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 38:10–11; 诗篇 104:9; 约伯记 26:10"> <span className="pl pl-1">难道你们不该敬畏我吗？</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /><span className="pl pl-1">难道你们在我面前不该颤抖吗？</span><br /><span className="pl pl-1">我以沙石为海的界限，</span><br /><span className="pl pl-1">使水永远不能越过它。</span><br /><span className="pl pl-1">汹涌的波涛不能逾越，</span><br /><span className="pl pl-1">澎湃的海浪不能漫过。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 6:28; 申命记 21:18; 诗篇 95:10"> <span className="pl pl-1">但你们这些人心里顽固，</span><br /><span className="pl pl-1">悖逆成性。</span><br /><span className="pl pl-1">你们离我而去。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 147:8; 约珥书 2:23; 创世记 8:22"> <span className="pl pl-1">你们心中从不说，</span><br /><span className="pl pl-1">我们要敬畏我们的上帝耶和华，</span><br /><span className="pl pl-1">祂按时降下秋雨和春雨，</span><br /><span className="pl pl-1">让我们按时收割。</span><br /></span>

<span className="v" id="v26" data-v="26" data-xref="箴言 1:11; 诗篇 64:5; 以西结书 22:2–12"> <span className="pl pl-1">我的子民中有恶人，</span><br /><span className="pl pl-1">他们像捕鸟人一样埋伏等候，</span><br /><span className="pl pl-1">设下网罗陷害人。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 1:12; 耶利米书 9:6; 何西阿书 12:7–8"> <span className="pl pl-1">他们的家里充满了诡诈，</span><br /><span className="pl pl-1">就像笼子装满了鸟。</span><br /><span className="pl pl-1">他们变得有财有势，</span><br /></span>

<span className="v" id="v30" data-v="30" data-xref="何西阿书 6:10; 耶利米书 23:14; 以赛亚书 1:2"> <span className="pl pl-1">这地方发生了一件令人震惊、恐惧的事，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 13:6; 耶利米书 14:14; 弥迦书 2:11"> <span className="pl pl-1">就是先知说假预言，</span><br /><span className="pl pl-1">祭司滥用权力，</span><br /><span className="pl pl-1">我的子民却以此为乐。</span><br /><span className="pl pl-1">但当最后的结局来临时，</span><br /><span className="pl pl-1">他们还能做什么呢？</span></span>

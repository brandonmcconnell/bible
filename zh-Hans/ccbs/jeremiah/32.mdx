## 耶利米买田

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 39:1–2; 列王纪下 25:1–2; 耶利米书 25:1"> 犹大王西底迦第十年，就是尼布甲尼撒第十八年，耶和华的话传给了耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 37:21; 尼希米记 3:25; 耶利米书 33:1"> 那时，巴比伦王的军队正围攻耶路撒冷。耶利米先知被囚禁在犹大王宫中护卫的院子里。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 34:2–3; 耶利米书 21:4–7; 耶利米书 26:8–9"> 犹大王西底迦囚禁了他，责问他为什么预言说：“耶和华说，‘看啊，我要把这座城交在巴比伦王手中，他必攻占这座城。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4–7; 列王纪下 25:4–7; 耶利米书 37:17"> 犹大王西底迦逃不出迦勒底人的手心，必落入巴比伦王手中，与他面对面、眼对眼地说话。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 39:7; 以西结书 17:9–10; 以西结书 17:15"> 他必把西底迦带到巴比伦，西底迦要住在那里，直到我惩罚他。你们和迦勒底人作战注定要失败。这是耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶利米说：“耶和华对我说，</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:1; 耶利米书 11:21; 利未记 25:25"> ‘看啊，你叔父沙龙的儿子哈拿篾会来找你，让你买下他在亚拿突的那块田地，说你是他的近亲，理当买下它。’”</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 32:7; 耶利米书 32:2; 耶利米书 33:1"> 果然如耶和华所言，我堂兄弟哈拿篾到护卫的院子里对我说：“我在便雅悯境内的亚拿突有一块田，求你买下它，因为你有权承接和买赎。求你买下吧！”我知道这是耶和华的旨意。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 11:12–13; 以斯帖记 3:9; 列王纪上 20:39"> 于是，我从堂兄弟哈拿篾手里买了亚拿突的那块田。我签订了契约，封好，请来证人并秤了四两银子给他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前书 11:16; 使徒行传 26:3"> 我拿着列明条款、一份加了封印和一份没有加封印的地契，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:16; 耶利米书 51:59; 耶利米书 36:4–5"> 当着堂兄弟哈拿篾、在地契上签名的证人和护卫院子里所有犹大人的面，把地契交给玛西雅的孙子、尼利亚的儿子巴录。</span>
<span className="v" id="v13" data-v="13"> 我当众对巴录说：</span>
<span className="v" id="v14" data-v="14"> “以色列的上帝——万军之耶和华吩咐你把封印的和没有封印的两份地契放在一个瓦瓶里，长期保存。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 3:10; 阿摩司书 9:14–15; 耶利米书 30:18"> 因为以色列的上帝——万军之耶和华说，将来必有人在这里重新买房屋、田地和葡萄园。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 12:1; 创世记 32:9–12; 腓立比书 4:6–7"> 我把地契交给尼利亚的儿子巴录之后，便向耶和华祷告说：</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> “主耶和华啊，看啊，你伸出臂膀以大能创造天地，你无所不能。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 10:16; 申命记 5:9–10; 出埃及记 34:7"> 你恩待千万人，也向后世的子孙追讨他们祖先所犯的罪。伟大全能的上帝啊！你名叫万军之耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:10; 马太福音 16:27; 诗篇 62:12"> 你有伟大的计划和大能的作为，你鉴察世人的一举一动，按照各人的行为施行赏罚。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:10; 撒母耳记下 7:23; 出埃及记 10:2"> 你曾在埃及行神迹奇事，现今仍在以色列和世人中间行神迹奇事，使自己威名远扬，正如今日。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:6; 申命记 26:8; 诗篇 105:43"> 你伸出臂膀用大能的手行神迹奇事及可畏的事，领你的以色列子民出了埃及。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 3:8; 出埃及记 13:5; 耶利米书 11:5"> 你信守对他们祖先的应许，赐给他们这奶蜜之乡。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:7; 诗篇 78:54–55; 但以理书 9:10–14"> 他们进入并得到这块土地之后，却不听你的话，也不遵行你的律法，对你的吩咐置若罔闻，因此你使他们大祸临头。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:36; 申命记 4:26; 约书亚记 23:15–16"> 看啊，敌人已经修筑高台要攻打这城，这城要因刀剑、饥荒和瘟疫而落入迦勒底人手中。你所说的都应验了，你也看见了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:24; 诗篇 97:2; 诗篇 77:19"> 主耶和华啊！虽然这城快要落入迦勒底人手中了，可是你还要我在证人面前买下这块地。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华对耶利米说：</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:17; 以赛亚书 64:8"> “看啊，我是耶和华，是所有世人的上帝，难道有我做不到的事吗？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 32:3; 耶利米书 32:24; 耶利米书 19:7–12"> 看啊，我要把这城交在巴比伦王尼布甲尼撒和他率领的迦勒底人手中，让他们攻取这城。这是耶和华说的。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 21:10; 耶利米书 19:13; 耶利米书 52:13"> 攻城的迦勒底人必放火焚城，把城中的房屋付之一炬，城中的居民曾在房顶上向巴力烧香、向其他神明奠酒，惹我发怒。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 7:22–26; 申命记 9:7–12; 耶利米书 25:7"> 以色列人和犹大人自幼就行我视为恶的事，以色列人的所作所为惹我发怒。这是耶和华说的。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:27; 耶利米书 27:10; 列王纪下 21:4–7"> 这城自从建立以来直到如今一直惹我发怒，以致我决意从眼前毁灭它。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理书 9:8; 耶利米书 2:26; 以赛亚书 1:4–6"> 以色列和犹大的君王和官长、祭司和先知、犹大百姓和耶路撒冷居民的恶行让我愤怒。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:13; 耶利米书 2:27; 以西结书 8:16"> 他们不是面向我而是背对我，我不厌其烦地教导他们，他们却不肯听，不受教。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 7:30; 以西结书 8:5–16; 列王纪下 21:4–7"> 他们把可憎的神像放在我的殿中，玷污了我的殿；</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 7:31; 历代志下 33:6; 利未记 18:21"> 他们在欣嫩子谷为巴力建丘坛，用自己的儿女作祭物献给摩洛，使犹大陷入罪中。我从未吩咐他们做如此可憎之事，连想都没想过。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 32:24; 耶利米书 32:3; 耶利米书 32:28"> “你们说这座城要因刀剑、饥荒和瘟疫而落入巴比伦王手中，但以色列的上帝耶和华说，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 23:3; 耶利米书 23:6; 以西结书 34:12–14"> ‘看啊，我曾在怒气、义愤和烈怒中把他们驱散到各地，我也必招聚他们，领他们回到故土，使他们安居乐业。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 24:7; 以西结书 11:19–20; 希伯来书 8:10"> 他们要做我的子民，我要做他们的上帝。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 11:19–20; 使徒行传 4:32; 约翰福音 17:21"> 我要使他们同心合意，永远敬畏我，使他们和子孙得到福乐。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米书 31:31–33; 以西结书 36:26; 耶利米书 24:7"> 我要与他们立永远的约，永远恩待他们，使他们对我心存敬畏，不再背弃我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 24:6; 西番雅书 3:17; 以赛亚书 62:5"> 我必以恩待他们为乐，全心全意在这地方培育他们。’</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="耶利米书 31:28; 约书亚记 23:14–15; 耶利米书 33:10–11"> “耶和华说，‘我曾降下这一切灾祸给他们，我也要把我应许的福乐赐给他们。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 37:11–14; 耶利米书 32:15; 耶利米书 32:36"> 你们说这地方落在了迦勒底人手中，变得一片荒凉，人畜绝迹。但将来这地方必再有人置买田产。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米书 17:26; 耶利米书 33:26; 耶利米书 33:11"> 在便雅悯境内，耶路撒冷周围和犹大的城邑，以及山区、丘陵、南地的城邑中，必有人用银子置买田地，签订地契，盖封印，请人作证，因为我必使被掳的人回到故土。这是耶和华说的。’”</span>
</div>
</div>

## 耶利米的书卷被焚毁

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 25:1; 历代志下 36:5; 耶利米书 45:1"> 约西亚的儿子犹大王约雅敬执政第四年，耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 30:2; 耶利米书 25:3; 耶利米书 1:10"> “你拿一个卷轴来，把从约西亚执政时期直到现在我告诉你有关以色列、犹大和各国的事都写在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:8; 使徒行传 3:19; 耶利米书 26:3"> 或许犹大人听了我打算要降给他们的灾祸，便各自改邪归正，我就赦免他们的过犯和罪恶。”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:12; 耶利米书 36:32; 以西结书 2:9"> 耶利米就叫来尼利亚的儿子巴录。巴录按耶利米的口述把耶和华吩咐他的话都写在卷轴上，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:2; 耶利米书 33:1; 哥林多后书 11:23"> 耶利米对他说：“我被囚禁，不能进入耶和华的殿，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 36:8–9; 耶利米书 26:2; 耶利米书 22:2"> 所以你要在禁食的日子，去耶和华的殿向百姓宣读我口授你记录在卷轴上的耶和华的话。你要向犹大各城来的人宣读。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 36:3; 耶利米书 21:5; 历代志下 33:12–13"> 或许他们会恳求耶和华施怜悯，并各自改邪归正，因为耶和华宣布要向他们大发怒气和烈怒。”</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 1:17; 哥林多前书 16:10; 路加福音 4:16–30"> 尼利亚的儿子巴录照耶利米先知的吩咐，在耶和华的殿中宣读卷轴上耶和华的话。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 20:3; 约拿书 3:5; 以斯帖记 4:16"> 约西亚的儿子犹大王约雅敬执政第五年九月，耶路撒冷和犹大各城的人都在耶和华面前宣告禁食。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:11; 耶利米书 26:10; 耶利米书 52:25"> 巴录来到耶和华殿新门入口处的上院，在沙番的儿子书记基玛利雅的房间，向众人宣读卷轴上耶利米的话。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 36:10; 历代志下 34:20; 列王纪下 25:22"> 沙番的孙子、基玛利雅的儿子米该亚听了卷轴上耶和华的话，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 26:22; 列王纪下 22:12; 耶利米书 36:25"> 就下到王宫，进入书记的房间。房间内坐着所有官长，即书记以利沙玛、示玛雅的儿子第莱雅、亚革波的儿子以利拿单、沙番的儿子基玛利雅和哈拿尼雅的儿子西底迦及其他官长。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 22:10; 历代志下 34:24; 历代志下 34:16–18"> 米该亚将巴录向众人宣读的话都告诉了他们。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 36:2; 耶利米书 41:18; 耶利米书 41:1–2"> 众官长就派古示的曾孙、示利米雅的孙子、尼探雅的儿子犹底去请巴录把当众宣读的卷轴拿来。尼利亚的儿子巴录拿着卷轴到他们那里，</span>
<span className="v" id="v15" data-v="15"> 他们请他坐下，把卷轴读给他们听。巴录就读给他们听。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 13:18; 耶利米书 36:24; 阿摩司书 7:10–11"> 他们听后吓得面面相觑，对巴录说：“我们必须把这些话禀告王！”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:15; 约翰福音 9:10–11; 约翰福音 9:26–27"> 他们问巴录：“请告诉我们，你是怎么写下这些话的？是耶利米口授的吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 36:4; 耶利米书 36:2; 箴言 26:4–5"> 巴录说：“都是耶利米口授、我用笔墨记录在卷轴上的。”</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 17:3; 列王纪上 18:10; 耶利米书 26:20–24"> 他们说：“你和耶利米都要藏起来，不可让人知道你们在哪里。”</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 36:12; 耶利米书 36:21"> 他们把卷轴存放在书记以利沙玛的房间，然后进宫把整件事禀告王。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 22:10; 历代志下 34:18; 以西结书 2:4–5"> 王就派犹底去把卷轴取来，犹底便从书记以利沙玛的房间取来卷轴，读给王和侍立在王周围的官长听。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司书 3:15; 耶利米书 22:14–16; 耶利米书 36:9"> 那时正是九月，王坐在冬宫，面前摆着一盆炭火。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 22:8; 箴言 21:30; 列王纪上 22:27"> 王和臣仆听了这些话，既不惧怕，也没有撕裂衣服。犹底每读三四段，王就用书记的小刀把那几段割下来扔进火盆里，直到全卷被烧毁。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:22; 耶利米书 36:12; 使徒行传 5:34–39"> 虽然以利拿单、第莱雅和基玛利雅恳求王不要把卷轴烧掉，王却不听，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 17:3; 列王纪上 19:1–3; 列王纪上 19:14"> 还命令自己的儿子耶拉篾、亚斯列的儿子西莱雅和亚伯德的儿子示利米雅，去拘捕书记巴录和耶利米先知。但耶和华把他们藏了起来。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 36:4"> 王把耶利米口述、巴录记录的卷轴烧掉后，耶和华对耶利米说：</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 1:5–6; 约伯记 23:13; 耶利米书 44:28"> “你再拿一卷轴，把犹大王约雅敬先前烧毁的卷轴上的话写下来。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 30:10; 耶利米书 26:9; 申命记 29:19"> 你要告诉犹大王约雅敬，‘耶和华说：你把卷轴烧掉，还说为什么上面写着巴比伦王必来毁灭这地方和其中的人畜。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:30; 列王纪下 24:12–15; 创世记 31:40"> 所以关于犹大王约雅敬，耶和华说：他的子孙没有一人能登大卫的宝座，他必曝尸荒野，遭受烈日的暴晒和夜霜的侵袭。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; 耶利米书 19:15; 耶利米书 35:17"> 我要因他、他后裔和他臣仆的罪恶而惩罚他们。因为他们不听我的警告，我要给他们以及耶路撒冷和犹大的居民降下我说过的灾祸。’”</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 36:4; 耶利米书 36:18; 出埃及记 4:15–16"> 于是，耶利米又拿了一个卷轴，交给尼利亚的儿子书记巴录，他按耶利米的口述，把犹大王约雅敬烧毁的那卷轴上的话都记下来，还增添了许多类似的话。</span>

## 审判巴比伦的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 25:26–27; 耶利米书 51:1–14; 以赛亚书 13:1–3"> 关于迦勒底人居住的巴比伦，耶和华对耶利米先知说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 46:1; 以赛亚书 21:9; 耶利米书 51:44"> <span className="pl pl-1">“你们要在列国中传扬和宣告，</span><br /><span className="pl pl-1">要竖起旗帜，毫不隐瞒地宣告，</span><br /><span className="pl pl-1">‘巴比伦要沦陷了！</span><br /><span className="pl pl-1">她的神明彼勒必蒙羞，</span><br /><span className="pl pl-1">米罗达必惊慌；</span><br /><span className="pl pl-1">巴比伦的神像都蒙羞，</span><br /><span className="pl pl-1">偶像都必惊慌。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="西番雅书 1:3; 耶利米书 51:11; 耶利米书 51:62"> <span className="pl pl-1">因为有一个来自北方的国家要攻击它，</span><br /><span className="pl pl-1">使她的土地荒凉、人畜绝迹。’”</span></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 31:31; 何西阿书 1:11; 何西阿书 3:5"> 耶和华说：“那时，以色列人要与犹大人一同来，流着泪寻求他们的上帝耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:40; 希伯来书 8:6–10; 以赛亚书 55:3"> 他们必打听前往锡安的路，朝锡安走去。他们必凭永不被遗忘的约归附耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 53:6; 马太福音 9:36; 以西结书 34:14"> 我的子民成了一群迷路的羊，他们的牧人使他们步入歧途，在高山丘陵间流浪，忘了自己的安歇之处。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 14:8; 耶利米书 2:3; 撒迦利亚书 11:5"> 遇见他们的人都吞噬他们。他们的敌人说，‘我们没有错！这是因为他们冒犯了他们真正的安歇之处——耶和华，他们祖先的盼望——耶和华。’</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 48:20; 耶利米书 51:6; 启示录 18:4"> 我的子民啊，你们要逃离巴比伦，离开迦勒底人的土地，要像带领羊群的公山羊一样离开。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 51:11; 耶利米书 15:14; 撒母耳记下 1:22"> 看啊，我要使来自北方的列强联合起来攻打巴比伦，他们要列阵攻占它，他们的勇士箭术高超，从不空手而归。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 25:12; 以赛亚书 33:23; 以赛亚书 33:4"> 他们要在迦勒底肆意掳掠，直到心满意足。这是耶和华说的。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 47:6; 以西结书 25:15–17; 以西结书 26:2–3"> <span className="pl pl-1">“抢夺我产业的巴比伦人啊，</span><br /><span className="pl pl-1">你们欢喜快乐，</span><br /><span className="pl pl-1">像草场上欢跳的母牛犊，</span><br /><span className="pl pl-1">又像嘶鸣的公马。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 51:43; 耶利米书 49:2; 加拉太书 4:26"> <span className="pl pl-1">但你们的母亲巴比伦将羞愧难当，</span><br /><span className="pl pl-1">生养你们的将蒙受耻辱，</span><br /><span className="pl pl-1">她将排在列国之末，</span><br /><span className="pl pl-1">沦为旷野、旱地和荒漠。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 18:16; 耶利米书 49:17; 耶利米哀歌 2:15–16"> <span className="pl pl-1">由于耶和华的愤怒，</span><br /><span className="pl pl-1">巴比伦必无人居住，</span><br /><span className="pl pl-1">荒凉不堪。</span><br /><span className="pl pl-1">她满目疮痍，</span><br /><span className="pl pl-1">令路人惊惧、嗤笑。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 50:29; 哈巴谷书 2:17; 撒母耳记上 17:20"> <span className="pl pl-1">弓箭手啊，你们要列阵围攻巴比伦，</span><br /><span className="pl pl-1">向她猛射，</span><br /><span className="pl pl-1">不要吝啬箭枝，</span><br /><span className="pl pl-1">因为她得罪了耶和华。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 51:58; 启示录 18:6; 耶利米书 46:10"> <span className="pl pl-1">你们要从四面向她呐喊，</span><br /><span className="pl pl-1">她必投降，</span><br /><span className="pl pl-1">她的堡垒将倾倒，</span><br /><span className="pl pl-1">城墙将坍塌，</span><br /><span className="pl pl-1">因为耶和华要报应她。</span><br /><span className="pl pl-1">你们要向她复仇，</span><br /><span className="pl pl-1">她怎样对待别人，</span><br /><span className="pl pl-1">你们也要怎样对待她。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 51:9; 耶利米书 46:16; 以赛亚书 13:14"> <span className="pl pl-1">你们要铲除在巴比伦撒种的和收割的。</span><br /><span className="pl pl-1">为躲避敌人的刀剑，</span><br /><span className="pl pl-1">人们各自逃到故土亲族那里。</span></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 2:15; 约翰福音 10:10–12; 列王纪下 18:9–13"> “以色列人是一群被狮子驱散的羊，先被亚述王吞噬，后被巴比伦王尼布甲尼撒咬碎骨头。”</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 10:12; 西番雅书 2:13–15; 那鸿书 1:1–3"> 因此，以色列的上帝——万军之耶和华说：“看啊，我要像惩罚亚述王一样惩罚巴比伦王和他的国家。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:18; 弥迦书 7:14; 耶利米书 30:18"> 我要带领以色列人返回他们的草场，让他们在迦密和巴珊吃草，在以法莲和基列的山上吃得饱足。</span>
<span className="v" id="v20" data-v="20" data-xref="弥迦书 7:19; 耶利米书 31:34; 以赛亚书 1:9"> 那时，在以色列必找不到过犯，在犹大必找不到罪恶，因为我必赦免我保留下来的余民。这是耶和华说的。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 23:23; 撒母耳记上 15:3; 耶利米书 50:3"> <span className="pl pl-1">“你们要去攻打米拉大翁和比割的居民，</span><br /><span className="pl pl-1">照我的命令追杀他们，彻底消灭他们。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 4:19–21; 耶利米书 51:54–56; 以赛亚书 21:2–4"> <span className="pl pl-1">巴比伦境内传来战争和大毁灭的声音。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 51:20–24; 以赛亚书 14:4–6; 启示录 18:16"> <span className="pl pl-1">威震天下的锤子巴比伦竟被砍断、打碎了！</span><br /><span className="pl pl-1">它的下场令列国震惊！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 9:4; 但以理书 5:30–31; 约伯记 40:2"> <span className="pl pl-1">巴比伦啊，我给你设下了陷阱，</span><br /><span className="pl pl-1">你在懵然不知中被捉住，</span><br /><span className="pl pl-1">你因为与耶和华为敌，</span><br /><span className="pl pl-1">才被找到并擒获。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 51:55; 耶利米书 51:25; 阿摩司书 3:6"> <span className="pl pl-1">耶和华已打开祂的兵器库，</span><br /><span className="pl pl-1">取出倾泻祂烈怒的兵器。</span><br /><span className="pl pl-1">因为主——万军之耶和华要惩罚迦勒底人。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 14:23; 耶利米书 50:10; 以赛亚书 45:3"> <span className="pl pl-1">你们要从远方前来攻打巴比伦，</span><br /><span className="pl pl-1">打开她的粮仓，</span><br /><span className="pl pl-1">使她沦为一堆废墟，</span><br /><span className="pl pl-1">彻底毁灭她，不留一物。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 46:21; 以赛亚书 34:7; 耶利米书 48:44"> <span className="pl pl-1">你们要杀掉她所有的士兵，</span><br /><span className="pl pl-1">把他们全部屠杀。</span><br /><span className="pl pl-1">他们大祸临头了，</span><br /><span className="pl pl-1">惩罚他们的日子到了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 48:20; 耶利米书 50:15; 耶利米哀歌 1:10"> “从巴比伦逃出来的人在锡安述说我们的上帝耶和华如何报仇，为祂的圣殿报仇。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 51:56; 以赛亚书 47:10; 但以理书 4:37"> “要召集所有的弓箭手来攻打巴比伦，在她四围扎营，不让一人漏网。要照她的所作所为报应她；她怎样对待别人，也要怎样对待她，因为她藐视以色列的圣者耶和华。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 49:26; 耶利米书 18:21; 耶利米书 9:21"> 她的青年要倒毙街头，那时她所有的战士都要灭亡。”这是耶和华说的。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 21:13; 耶利米书 50:29; 以西结书 39:1"> <span className="pl pl-1">“主——万军之耶和华说，</span><br /><span className="pl pl-1">‘狂傲的人啊，我要与你为敌，</span><br /><span className="pl pl-1">我惩罚你的时候到了。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 21:14; 耶利米书 49:27; 以赛亚书 10:12–15"> <span className="pl pl-1">狂傲的人要踉踉跄跄，</span><br /><span className="pl pl-1">跌倒在地，无人扶起。</span><br /><span className="pl pl-1">我要焚烧她的城邑，</span><br /><span className="pl pl-1">使她周围的一切化为灰烬。’”</span></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 14:17; 出埃及记 9:2–3; 以赛亚书 58:6"> 万军之耶和华说：“以色列人和犹大人要一同受压迫，掳走他们的人必控制他们，不肯释放他们。</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 54:5; 耶利米书 15:21; 以赛亚书 41:14"> 但他们的救赎主——万军之耶和华大有能力，祂必为他们申冤，使他们的家园安宁，使巴比伦的居民不得安宁。”</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 47:6; 但以理书 5:30; 但以理书 5:7–8"> 耶和华说：<br /><span className="pl pl-1">“敌人要攻击巴比伦的居民及其首领和谋士；</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 49:22; 那鸿书 3:13; 以赛亚书 44:25"> <span className="pl pl-1">敌人要攻击巴比伦的假先知，</span><br /><span className="pl pl-1">使他们显出愚昧；</span><br /><span className="pl pl-1">敌人要攻击巴比伦的勇士，</span><br /><span className="pl pl-1">使他们充满恐惧；</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 51:30; 那鸿书 3:13; 耶利米书 51:21"> <span className="pl pl-1">敌人要攻击巴比伦人的战车战马和他们的盟军，</span><br /><span className="pl pl-1">使他们柔弱得像妇女；</span><br /><span className="pl pl-1">敌人要攻打他们的库房，</span><br /><span className="pl pl-1">肆意抢夺他们的财宝。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="启示录 16:12; 以赛亚书 44:27; 耶利米书 50:2"> <span className="pl pl-1">旱灾必临到巴比伦，</span><br /><span className="pl pl-1">使那里的河流干涸，</span><br /><span className="pl pl-1">因为那里神像遍地，</span><br /><span className="pl pl-1">人们都沉迷于祭拜偶像。</span></span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 13:20–22; 启示录 18:2; 耶利米书 25:12"> “因此，巴比伦必杳无人烟，永远荒凉，成为豺狼等野兽出没之地、鸵鸟的栖身之所。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 19:24–25; 犹大书 1:7; 以赛亚书 13:19–20"> 上帝要毁灭巴比伦，像毁灭所多玛、蛾摩拉及其周围的城邑一样，使那里人烟绝迹。这是耶和华说的。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 51:27–28; 耶利米书 6:22–23; 以赛亚书 13:2–5"> <span className="pl pl-1">“看啊，有一个民族要从北方来，</span><br /><span className="pl pl-1">有一个强国及许多君王要从地极发动进攻。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以赛亚书 5:30; 以赛亚书 13:17–18; 以赛亚书 47:6"> <span className="pl pl-1">少女巴比伦啊，他们残酷无情，</span><br /><span className="pl pl-1">手持弓箭和矛枪，</span><br /><span className="pl pl-1">骑马奔来，声势如怒海狂涛，</span><br /><span className="pl pl-1">列阵攻击你。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="耶利米书 51:31; 耶利米书 49:24; 以赛亚书 21:3–4"> <span className="pl pl-1">巴比伦王听到风声，</span><br /><span className="pl pl-1">四肢发软，痛苦不堪，</span><br /><span className="pl pl-1">如分娩的妇人。</span></span>
<span className="v" id="v44" data-v="44" data-xref="耶利米书 49:19–21; 以赛亚书 46:11; 诗篇 89:6"> “看啊，我必在瞬间把巴比伦人赶离家园，如约旦河边丛林中跳出的狮子赶散草场的羊群。我要派我拣选的人统治这地方。谁能与我相比？谁能与我较量？哪位首领能抵挡我？”</span>
<span className="v" id="v45" data-v="45" data-xref="耶利米书 49:20; 耶利米书 51:10–11; 启示录 17:16–17"> 因此，你们要听听耶和华攻击巴比伦的策略，听听祂攻击迦勒底人的计划。他们的孩子要被拖走，他们的家园要被毁灭。</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米书 49:21; 启示录 18:9–19; 以西结书 31:16"> 巴比伦被毁灭的消息震动大地，哭喊声传到列国。</span>

## 耶利米被带到埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 26:8; 耶利米书 51:63; 耶利米书 42:22"> 耶利米向众人宣告了他们的上帝耶和华的话，就是他们的上帝耶和华派他去说的一切话。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:13; 以赛亚书 7:9; 耶利米书 40:8"> 何沙雅的儿子亚撒利雅、加利亚的儿子约哈难和一些狂妄之徒对耶利米说：“你在撒谎！我们的上帝耶和华并没有派你来告诉我们不可去埃及居住。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 45:1–3; 耶利米书 36:4; 耶利米书 36:26"> 是尼利亚的儿子巴录怂恿你反对我们，好叫我们落在迦勒底人手中，任由他们宰杀或掳到巴比伦。”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 42:5–6; 诗篇 37:3; 历代志下 25:16"> 于是，加利亚的儿子约哈难和众将领及民众都不听从耶和华让他们留在犹大的命令。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 40:11–12; 耶利米书 41:15–16; 撒母耳记上 26:19"> 加利亚的儿子约哈难和众将领率领民众下到埃及的答比匿。他们没有听从耶和华的命令。民众中有流亡到各国又返回犹大的余民和护卫长尼布撒拉旦留给沙番的孙子、亚希甘的儿子基大利管理的男女妇孺、公主以及耶利米先知和尼利亚的儿子巴录。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 2:16; 诗篇 139:7; 提摩太后书 2:9"> 耶和华在答比匿对耶利米说：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 18:2–12; 耶利米书 19:1–15; 耶利米书 51:63–64"> “你当着犹大人的面搬几块大石头，埋在答比匿的法老宫门口铺砖路面的灰泥中，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 44:28–1; 耶利米书 1:15; 诗篇 31:20"> 然后告诉他们以色列的上帝——万军之耶和华说，‘看啊，我必召来我的仆人巴比伦王尼布甲尼撒，把他的宝座安置在我让你埋的石头上面，他要在上面搭起他的帐篷。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 15:2; 耶利米书 44:13; 以西结书 29:19–20"> 他要前来攻打埃及，叫那些该死的死、该被掳的被掳、该被杀的被杀。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 30:13; 诗篇 109:18–19; 以赛亚书 19:1"> 他要点火焚烧埃及的神庙，掳走神像；他要像牧人披上外衣一样轻而易举地征服埃及，然后安然离去。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 19:18"> 他要摧毁埃及太阳神庙的神柱，烧毁埃及的神庙。’”</span>

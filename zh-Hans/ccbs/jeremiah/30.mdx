## 上帝应许拯救祂的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 26:15; 耶利米书 1:1–2"> 耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 36:32; 以赛亚书 30:8; 哈巴谷书 2:2–3"> “以色列的上帝耶和华这样说，‘你要把我对你说的一切话写在书卷上。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:14; 耶利米书 16:15; 耶利米书 30:18"> 耶和华说：看啊，时候将到，我要使我被掳的以色列和犹大子民返乡，回到我赐给他们祖先的土地上，恢复他们的地业。这是耶和华说的。’”</span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">以下是耶和华谈论以色列和犹大的话。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="西番雅书 1:10–11; 阿摩司书 8:10; 以赛亚书 5:30"> <span className="pl pl-1">耶和华说：“我听见惊恐战栗的喊叫声，</span><br /><span className="pl pl-1">没有平安。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鸿书 2:10; 约珥书 2:6; 耶利米书 4:31"> <span className="pl pl-1">你们去问问看，</span><br /><span className="pl pl-1">男人能分娩吗？</span><br /><span className="pl pl-1">为什么我看见男人们都双手捂着肚子，</span><br /><span className="pl pl-1">好像分娩的妇人，</span><br /><span className="pl pl-1">脸色苍白呢？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 12:1; 撒迦利亚书 14:1–2; 玛拉基书 4:1"> <span className="pl pl-1">唉！无比可怕的日子快来了，</span><br /><span className="pl pl-1">那将是雅各子孙的苦难之日，</span><br /><span className="pl pl-1">但他们必得拯救。”</span></span>
<span className="v" id="v8" data-v="8" data-xref="那鸿书 1:13; 以西结书 34:27; 以赛亚书 9:4"> 万军之耶和华说：“那日，我要折断他们颈上的轭，砍断他们的锁链，使他们不再受外族人奴役。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 3:5; 以赛亚书 55:3–5; 路加福音 1:69"> 他们要事奉他们的上帝耶和华，服侍我为他们选立来坐大卫宝座的王。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 46:27–28; 以赛亚书 43:5; 耶利米书 29:14"> <span className="pl pl-1">“我的仆人雅各啊，不要害怕；</span><br /><span className="pl pl-1">以色列啊，不要惊慌。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /><span className="pl pl-1">因为我必从远方拯救你，</span><br /><span className="pl pl-1">从流亡之地拯救你的后裔，</span><br /><span className="pl pl-1">使雅各重归故土，安享太平，</span><br /><span className="pl pl-1">不受惊吓。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 10:24; 耶利米书 1:19; 以赛亚书 8:10"> <span className="pl pl-1">因为我与你同在，</span><br /><span className="pl pl-1">要拯救你。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /><span className="pl pl-1">我要彻底毁灭列国，</span><br /><span className="pl pl-1">就是我曾使你流亡的地方。</span><br /><span className="pl pl-1">但我不会彻底毁灭你，</span><br /><span className="pl pl-1">也不会放过你，</span><br /><span className="pl pl-1">我必公正地惩治你。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:18; 耶利米书 30:15; 耶利米书 14:17"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“你们的创伤无法医治，</span><br /><span className="pl pl-1">你们的伤口无法痊愈。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 46:11; 耶利米书 8:22; 耶利米书 30:17"> <span className="pl pl-1">没有人为你们辩护，</span><br /><span className="pl pl-1">你们的伤处无药可治，</span><br /><span className="pl pl-1">你们无法痊愈。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 5:6; 约伯记 30:21; 耶利米哀歌 1:2"> <span className="pl pl-1">你们的盟友都忘了你们，</span><br /><span className="pl pl-1">对你们漠不关心。</span><br /><span className="pl pl-1">我要像你们的仇敌一样击打你们，</span><br /><span className="pl pl-1">像敌人一样残酷地惩罚你们，</span><br /><span className="pl pl-1">因为你们罪大恶极，罪过无数。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 30:14; 耶利米书 30:12; 耶利米书 6:6–7"> <span className="pl pl-1">你们缘何为自己的创伤哭泣？</span><br /><span className="pl pl-1">你们的创伤无法医治。</span><br /><span className="pl pl-1">因为你们罪大恶极，罪过无数，</span><br /><span className="pl pl-1">我才这样惩罚你们。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 10:25; 以赛亚书 33:1; 出埃及记 23:22"> <span className="pl pl-1">然而，吞吃你们的必被吞吃，</span><br /><span className="pl pl-1">你们的敌人全被掳走，</span><br /><span className="pl pl-1">掳掠你们的必被掳掠，</span><br /><span className="pl pl-1">抢夺你们的必被抢夺。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 107:20; 耶利米书 33:6; 彼得前书 2:24"> <span className="pl pl-1">因为你们被称为弃儿，</span><br /><span className="pl pl-1">是无人关心的锡安，</span><br /><span className="pl pl-1">我要医治你们的创伤，</span><br /><span className="pl pl-1">使你们康复。</span><br /><span className="pl pl-1">这是耶和华说的。”</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="哈该书 2:7–9; 诗篇 102:13; 耶利米书 30:3"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“看啊，我要使雅各家被掳的子孙返乡，</span><br /><span className="pl pl-1">我要怜悯他们的家园，</span><br /><span className="pl pl-1">使他们在废墟上重建城邑，</span><br /><span className="pl pl-1">在原处重修宫殿。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 33:22; 以赛亚书 51:11; 以赛亚书 60:22"> <span className="pl pl-1">那里必传出感谢和欢乐的声音。</span><br /><span className="pl pl-1">我必使他们人丁兴旺，</span><br /><span className="pl pl-1">不再减少；</span><br /><span className="pl pl-1">我必使他们得享尊荣，</span><br /><span className="pl pl-1">不再受歧视。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 32:39; 耶利米书 2:3; 耶利米书 50:33–34"> <span className="pl pl-1">他们的儿女要如往日一样兴旺，</span><br /><span className="pl pl-1">我要使他们的会众坚立，</span><br /><span className="pl pl-1">我要惩罚所有压迫他们的人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:5; 以西结书 34:23–24; 使徒行传 5:31"> <span className="pl pl-1">他们的首领将是自己的同胞，</span><br /><span className="pl pl-1">他们的元首将出自本族。</span><br /><span className="pl pl-1">我必带领他近前来，他必到我面前，</span><br /><span className="pl pl-1">因为无人敢贸然来到我面前。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="启示录 21:3; 以西结书 36:28; 耶利米书 31:33"> <span className="pl pl-1">你们要做我的子民，</span><br /><span className="pl pl-1">我要做你们的上帝。”</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:19–20; 撒迦利亚书 9:14; 耶利米书 25:32"> <span className="pl pl-1">看啊，耶和华的怒气必如风暴一样横扫过来，</span><br /><span className="pl pl-1">刮到恶人头上。</span><br /></span>

## 致信给被掳的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 9:20; 使徒行传 15:23; 希伯来书 13:22"> 耶哥尼雅王、太后、宫廷侍臣、犹大和耶路撒冷的官员、技工和工匠被尼布甲尼撒王掳到巴比伦后，耶利米先知从耶路撒冷送信给被掳之人中幸存的长老、祭司、先知和众民。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 8:11; 历代志下 34:20; 耶利米书 39:14"> 信是由沙番的儿子以利亚萨和希勒迦的儿子基玛利送去的。当时犹大王西底迦派二人去见巴比伦王尼布甲尼撒。以下是信的内容：</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 24:5; 以赛亚书 10:5–6; 以赛亚书 45:7"> 以色列的上帝——万军之耶和华对所有从耶路撒冷被掳到巴比伦的人说：</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 29:28; 耶利米书 29:10; 以西结书 28:26"> “你们要建造房子住下来，要耕种田园，吃田中的出产。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3–4; 创世记 24:51; 创世记 28:1–4"> 你们要娶妻生子，也要让你们的儿女婚嫁，使他们生儿育女，你们好在那里人丁兴旺，不致人口减少。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 2:1–2; 以斯拉记 6:10; 彼得前书 2:13–17"> 你们要为我放逐你们去住的城市谋求福祉，向耶和华祷告，因为你们的福祉有赖于那城的福祉。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:6; 耶利米书 5:31; 帖撒罗尼迦后书 2:9–11"> 以色列的上帝——万军之耶和华说，‘不要被你们中间的先知和占卜者欺骗，不要听信他们做的梦。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 27:15; 耶利米书 29:31; 耶利米书 29:23"> 他们奉我的名对你们说假预言，其实我并没有差遣他们。这是耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理书 9:2; 撒迦利亚书 7:5; 耶利米书 24:6–7"> 耶和华说：“你们被掳到巴比伦七十年期满后，我就要眷顾你们，成就我充满恩典的应许，把你们带回这地方。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 55:8–12; 诗篇 33:11; 弥迦书 4:12"> 因为我知道我为你们安排的计划：是要赐福给你们，而非降祸给你们，使你们的未来充满希望。这是耶和华说的。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 7:7–8; 耶利米书 33:3; 诗篇 50:15"> 那时，你们必呼求我，向我祷告，我也必垂听。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:29–31; 诗篇 119:2; 马太福音 7:7"> 你们寻求我，就必寻见。只要你们全心寻求我，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 36:1–38; 耶利米书 30:3; 历代志上 28:9"> 我必让你们寻见。这是耶和华说的。我必把你们从流放的各国各地招聚起来，使你们回到故土，我曾把你们从那里掳走。这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 29:8–9; 耶利米书 28:1–17; 以西结书 1:3"> “你们说耶和华在巴比伦为你们选立了先知。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 38:2–3; 耶利米书 38:17–23; 以西结书 17:12–21"> 关于坐在大卫宝座上的君王和这城里的百姓，就是没有与你们一同被掳的同胞，</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 24:8–10; 耶利米书 29:18; 耶利米书 24:1–3"> 万军之耶和华这样说，‘看啊，我必使刀剑、饥荒和瘟疫临到他们，使他们像烂得不能吃的无花果。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 29:8; 耶利米书 15:4; 耶利米书 42:18"> 我要使他们饱受刀剑、饥荒和瘟疫之灾，使他们的遭遇令天下万国惊惧。在我流放他们去的各国，他们必受凌辱、嘲笑、讥讽和咒诅。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 6:19; 耶利米书 26:5; 耶利米书 7:24–26"> 这都是因为他们不听我的话。这是耶和华说的。我曾屡次差遣我的仆人——众先知去警告他们，他们却不肯听。’这是耶和华说的。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:5; 弥迦书 4:10; 以西结书 3:15"> 因此，你们这些我从耶路撒冷流放到巴比伦的人啊！要听耶和华的话。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 14:14–15; 耶利米哀歌 2:14; 耶利米书 29:8–9"> 以色列的上帝——万军之耶和华说，‘哥赖雅的儿子亚哈和玛西雅的儿子西底迦奉我的名说假预言，我要把他们交在巴比伦王尼布甲尼撒的手中，他要当着你们的面处死他们。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 65:15; 但以理书 3:6; 但以理书 3:21"> 所有被掳到巴比伦的犹大人咒诅人的时候会说：愿耶和华使你的下场像被巴比伦王烧死的西底迦和亚哈一样！</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:14; 希伯来书 4:13; 玛拉基书 3:5"> 因为他们二人在以色列做了恶事，与邻舍的妻子通奸。我没有委派他们，他们却奉我的名说假预言。我洞悉一切，我是见证人。’这是耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 29:31–32"> 耶和华吩咐我对尼希兰人示玛雅说：</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 37:3; 耶利米书 29:29; 耶利米书 52:24"> “以色列的上帝——万军之耶和华说，‘你曾以自己的名义写信给住在耶路撒冷的众民、玛西雅的儿子西番雅祭司及所有其他祭司。你在信中对西番雅说：</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 20:1–2; 列王纪下 9:11; 约翰福音 10:20"> 耶和华已立你为祭司代替耶何耶大祭司，管理耶和华的殿，负责拘捕妄自发预言的狂人，给他们戴上铁链枷锁。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 25:16; 耶利米书 43:2–3; 耶利米书 29:26"> 现在，亚拿突人耶利米在你们当中自称为先知，你为什么不斥责他呢？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 29:5; 耶利米书 29:1; 耶利米书 29:10"> 他甚至送信给我们这些在巴比伦的人，说被掳的日子还很长久，要我们建房子住下来，耕种田园，吃田中的出产。’”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 29:25"> 西番雅祭司就把示玛雅的信读给耶利米先知听。</span>
<span className="v" id="v30" data-v="30"> 耶和华对耶利米说：</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 29:9; 耶利米书 29:23–24; 耶利米书 14:14–15"> “你派人送信给所有被掳的人，说，‘耶和华说祂没有差遣尼希兰人示玛雅，他却说预言，诱使你们听信谎言，</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 28:16; 列王纪下 7:19–20; 耶利米书 17:6"> 所以耶和华说：我必惩罚他和他的后代，他必断子绝孙，看不到我赐给我子民的福祉，因为他说了悖逆耶和华的话。这是耶和华说的。’”</span>
</div>
</div>

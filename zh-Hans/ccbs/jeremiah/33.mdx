## 应许以色列人必复兴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 38:28; 耶利米书 37:21; 耶利米书 32:2–3"> 耶利米仍被囚禁在护卫院子里的时候，耶和华第二次对他说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:3; 出埃及记 15:3; 以赛亚书 37:26"> “耶和华创造大地，使其成形、根基稳固，祂名叫耶和华。祂说，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:12; 以赛亚书 65:24; 以弗所书 3:20"> ‘你呼求我，我就回应你，并且把你不知道的伟大奥妙之事告诉你。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:24; 哈巴谷书 1:10; 以西结书 4:2"> 关于耶路撒冷城中的房屋和犹大王宫被拆毁，用来抵御攻城台和刀剑一事，以色列的上帝耶和华说：</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:17; 耶利米书 21:10; 耶利米书 21:4–7"> 他们与迦勒底人争战只会使这些房屋堆满死尸，因为我要在怒气和烈怒中杀死他们。他们作恶多端，我必掩面不理这城。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:10; 以赛亚书 30:26; 提多书 3:5–6"> 但有一天，我必医治这城的创伤，恢复我子民的健康，使他们繁荣安定。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:26; 耶利米书 30:3; 阿摩司书 9:14–15"> 我要使被掳的犹大人和以色列人返乡，使他们重建如初。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亚书 13:1; 弥迦书 7:18–19; 诗篇 51:2"> 我要除去他们干犯我的一切罪恶，赦免他们悖逆我的一切罪过。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:2–3; 以赛亚书 60:5; 西番雅书 3:17–20"> 这城要使我在天下万国面前得到尊崇、颂赞和荣耀，因为他们必听见我赐给这城的一切福乐。因为我使这城繁荣安定，他们都必恐惧战栗。’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:43; 耶利米书 32:36; 以西结书 37:11"> 耶和华说：“你们说犹大的城邑和耶路撒冷的街道一片荒凉、人畜绝迹，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:22"> 但这些地方必传出欢乐声、新郎新娘的欢笑声和在耶和华殿中献感恩祭者的歌唱声，<br /><span className="pl pl-1">“‘要感谢万军之耶和华，</span><br /><span className="pl pl-1">因为耶和华是美善的，</span><br /><span className="pl pl-1">祂的慈爱永远长存。’</span><br />因为我必使被掳的人返乡，重建家园。这是耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 65:10; 以西结书 34:12–15; 耶利米书 36:29"> 万军之耶和华说：“在这一片荒凉、人畜绝迹的地方，在它所有城邑必再有供牧人放羊的草场。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:32; 路加福音 15:4; 耶利米书 17:26"> 在山区、丘陵和南地的城邑，以及便雅悯地区、耶路撒冷周围和犹大的城邑必再次有人清点羊群。这是耶和华说的。”</span>
<span className="v" id="v14" data-v="14" data-xref="哈该书 2:6–9; 耶利米书 23:5; 历代志上 17:13–14"> 耶和华说：“看啊，时候将到，我要实现我给以色列人和犹大人的美好应许。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 11:1–5; 耶利米书 23:5–6; 以赛亚书 4:2"> 那日那时，我要使大卫公义的苗裔兴起，他要在地上秉公行义。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:6; 哥林多前书 1:30; 以赛亚书 45:17"> 那时，犹大必得拯救，耶路撒冷必安享太平并被称为‘耶和华是我们的义’。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 2:4; 诗篇 89:29–37; 路加福音 1:32–33"> 因为耶和华说，‘我应许大卫的后裔必永远坐在以色列的宝座上，</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 56:7; 启示录 1:6; 申命记 18:1"> 利未家的祭司必永远有人在我面前献燔祭、素祭及其他祭物。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华对耶利米说：</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 8:22; 诗篇 89:37; 以赛亚书 54:9–10"> “耶和华这样说，‘除非你们能废除我与白昼黑夜所立的约，叫白昼黑夜不再按时更替，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 89:34; 历代志下 7:18; 撒母耳记下 23:5"> 才能废除我与我仆人大卫所立的约，使他的王位后继无人，也才能废除我与事奉我的利未祭司所立的约。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 15:5; 创世记 22:17; 希伯来书 11:12"> 我要使我仆人大卫的后裔和事奉我的利未人，像天上的星和海边的沙一样不可胜数。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华对耶利米说：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 4:2–4; 诗篇 83:4; 诗篇 44:13–14"> “你看到了吗？人们说，‘耶和华已经弃绝了祂所拣选的以色列和犹大两个国家。’他们藐视我的子民，视他们为亡国之民。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 74:16–17; 耶利米书 31:35–36; 诗篇 104:19"> 然而，耶和华说，‘正如我决不废弃我所定的昼夜交替之约和天地运行之律，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 31:37; 以赛亚书 14:1; 何西阿书 2:23"> 我也决不弃绝雅各和我仆人大卫的后裔。我必让大卫的后裔做王统治亚伯拉罕、以撒和雅各的子孙，因为我必使被掳的人回到故土，也必怜悯他们。’”</span>
</div>

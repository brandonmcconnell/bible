## 耶利米陷在枯井里

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 7:9; 以斯拉记 2:3; 使徒行传 4:6–10"> 玛坦的儿子示法提雅、巴施户珥的儿子基大利、示利米雅的儿子犹甲、玛基雅的儿子巴施户珥听见耶利米对众人说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 39:18; 耶利米书 34:17; 耶利米书 45:5"> “耶和华这样说，‘凡留在这城的，必死于刀剑、饥荒和瘟疫；凡出去向迦勒底人投降的，必保全性命，得以存活。’</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:10; 耶利米书 32:3–5"> 耶和华说，‘这城必落在巴比伦王的军队手中，他们必攻占这城。’”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 26:11; 使徒行传 16:20; 尼希米记 6:9"> 这几位官长就对西底迦王说：“求你处死这人！因为他的话令这城的军民士气低落。这人不为人民着想，反要害他们。”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:12–16; 撒母耳记下 3:39; 撒母耳记下 19:22"> 西底迦王说：“你们可以随意处置他，我不会阻止你们。”</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 37:21; 耶利米书 38:22; 耶利米书 37:16"> 于是，他们拿住耶利米，用绳子把他缒到王子玛基雅的蓄水池里。那池子在护卫的院子里，池中没有水，只有淤泥。耶利米就陷在淤泥中。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 21:19; 阿摩司书 5:10; 耶利米书 29:2"> 那时，王正坐在便雅悯门口。宫廷侍臣古实人以伯·米勒听说他们把耶利米囚在蓄水池里，</span>
<span className="v" id="v8" data-v="8"> 便离开王宫，去对王说：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 37:21–6; 以斯帖记 7:4–6; 箴言 31:8–9"> “我主我王啊！这些人对耶利米先知太狠毒了。他们把他扔在蓄水池里，他必饿死在那里，因为城中绝粮了。”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 21:1; 以斯帖记 8:7; 以斯帖记 5:2"> 于是，王吩咐古实人以伯·米勒率领三十人，趁耶利米先知还没死，把他从池中救出来。</span>
<span className="v" id="v11" data-v="11"> 以伯·米勒带着他的手下进入王宫，从库房下面的房间拿了些碎布和破衣，用绳索缒到池底给耶利米，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:10; 以弗所书 4:32; 罗马书 12:15"> 让他把这些碎布和破衣放在腋下垫绳索。耶利米就照做了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 37:21; 使徒行传 28:16; 使徒行传 23:35"> 他们便用绳索把耶利米从池中拉上来。耶利米仍留在护卫的院子里。</span>
</div>
</div>

## 西底迦王密会耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 37:17; 列王纪上 22:16; 耶利米书 21:1–2"> 西底迦王派人把耶利米先知带到耶和华殿的第三道门那里与他会面。他对耶利米说：“我要问你一件事，你不可有任何隐瞒。”</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:67–68"> 耶利米说：“我若从实禀告，你一定会杀我。我就是给你建议，你也不会听。”</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 37:17; 耶利米书 38:1–6; 以赛亚书 57:16"> 于是，他私下向耶利米发誓说：“我凭那赐给我们生命的永活的耶和华起誓，我决不杀你，也不把你交在想杀你的人手中。”</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 27:12; 耶利米书 27:17; 耶利米书 38:2"> 耶利米说：“以色列的上帝——万军之上帝耶和华说，‘如果你出去向巴比伦王的将领投降，就可以保住你和你全家的性命，这城也不会被烧毁。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:3; 耶利米书 24:8–10; 列王纪下 25:4–10"> 但如果你不出去向巴比伦王的将领投降，这城必落在迦勒底人手里，被付之一炬，你也逃不掉。’”</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:42; 耶利米书 38:22; 约翰福音 19:12–13"> 西底迦王说：“我害怕那些已经向迦勒底人投降的犹大人，恐怕迦勒底人会把我交给他们，任由他们羞辱。”</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 4:27; 以赛亚书 55:3; 耶利米书 26:13"> 耶利米说：“你不会被交给他们的。求你听从耶和华吩咐我对你说的话，这样你就可以平安无事，保全性命。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 2:7; 以西结书 2:4–5; 耶利米书 26:15"> 如果你不肯投降，耶和华已让我看到以下景象：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 43:6; 耶利米哀歌 1:2; 耶利米哀歌 5:11"> 所有留在犹大王宫的妇女都必被带到巴比伦王的将领那里，她们会对你说，‘你被好友欺骗和左右，当你陷入泥潭时，他们就离弃了你。’</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 41:10; 耶利米书 39:6; 耶利米书 38:18"> “你的嫔妃和儿女必被交给迦勒底人，你也逃不掉，必被巴比伦王所擒。这城也要被付之一炬。”</span>
<span className="v" id="v24" data-v="24"> 西底迦说：“不可让人知道我和你交谈，否则你会丧命。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 38:27; 耶利米书 38:4–6"> 如果有官长听说我和你交谈，前来逼你说出我们谈话的内容，否则就杀死你，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 37:20; 耶利米书 37:15; 以斯帖记 4:8"> 你可以告诉他们，你是在求我不要把你押回约拿单的房子，以免死在那里。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 10:15–16; 列王纪下 6:19; 使徒行传 23:6"> 果然，众官长前来查问耶利米，他就照王的吩咐回复他们，他们便不再追问，因为他跟王的谈话无人知道。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 37:21; 耶利米书 39:14; 诗篇 23:4"> 耶利米被囚在护卫的院子里，一直到耶路撒冷沦陷。</span>
</div>
</div>

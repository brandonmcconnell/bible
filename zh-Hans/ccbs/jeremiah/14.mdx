## 预言旱灾

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 17:8"> 耶和华告诉耶利米有关旱灾的事：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 3:26; 耶利米书 8:21; 撒母耳记上 5:12"> <span className="pl pl-1">“犹大悲泣，</span><br /><span className="pl pl-1">她的城邑衰败，</span><br /><span className="pl pl-1">人人坐在地上痛哭，</span><br /><span className="pl pl-1">耶路撒冷哀鸣四起。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 15:30; 诗篇 40:14; 列王纪下 18:31"> <span className="pl pl-1">贵族派仆人去水池打水，</span><br /><span className="pl pl-1">仆人去那里发现没有水，</span><br /><span className="pl pl-1">就带着空瓶垂头丧气、</span><br /><span className="pl pl-1">羞愧地抱头而归。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约珥书 1:19–20; 约珥书 1:11; 耶利米书 3:3"> <span className="pl pl-1">天不下雨，</span><br /><span className="pl pl-1">土地干裂，</span><br /><span className="pl pl-1">农夫沮丧地抱着头。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 29:9; 约伯记 39:1–4; 以赛亚书 15:6"> <span className="pl pl-1">因为没有草，</span><br /><span className="pl pl-1">田野的母鹿抛弃了刚生下来的小鹿；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 2:24; 约伯记 39:5–6; 约珥书 1:18"> <span className="pl pl-1">因为没有草，</span><br /><span className="pl pl-1">野驴站在光秃的山头上像豺狼一样喘气，双目无神。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 25:11; 何西阿书 5:5; 耶利米书 14:20–21"> <span className="pl pl-1">耶和华啊，虽然我们的罪控告我们，</span><br /><span className="pl pl-1">我们屡屡叛逆得罪你，</span><br /><span className="pl pl-1">求你为了自己的名而拯救我们。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 17:13; 耶利米书 50:7; 以赛亚书 43:3"> <span className="pl pl-1">以色列的盼望和患难时的救主啊，</span><br /><span className="pl pl-1">你为什么在本地像个异乡人，</span><br /><span className="pl pl-1">像个只住一夜的客旅呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 63:19; 以赛亚书 59:1; 耶利米书 15:16"> <span className="pl pl-1">你为什么像个受惊的人，</span><br /><span className="pl pl-1">像个无力救人的勇士呢？</span><br /><span className="pl pl-1">耶和华啊，你一直都在我们中间，</span><br /><span className="pl pl-1">我们属于你的名下，</span><br /><span className="pl pl-1">求你不要抛弃我们。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="何西阿书 9:9; 何西阿书 8:13; 诗篇 119:101"> <span className="pl pl-1">关于这些百姓，耶和华说：</span><br /><span className="pl pl-1">“他们喜欢游荡，</span><br /><span className="pl pl-1">不约束自己的脚步，</span><br /><span className="pl pl-1">因此耶和华不悦纳他们。</span><br /><span className="pl pl-1">现在祂要追忆他们的罪恶，</span><br /><span className="pl pl-1">追讨他们的罪。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 7:16; 耶利米书 11:14; 出埃及记 32:32–34"> 耶和华对我说：“你不要为这百姓求好处。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 11:11; 以西结书 8:18; 箴言 1:28"> 即使他们禁食，我也不会听他们的呼求；他们献上燔祭和素祭，我也不会悦纳。我要用刀剑、饥荒和瘟疫灭绝他们。”</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 6:14; 耶利米书 4:10; 彼得后书 2:1"> 我说：“主耶和华啊！众先知不停地告诉他们不会有战争，也不会遭遇饥荒，说耶和华必在这地方赐给他们永久的平安。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以西结书 13:6–7; 以西结书 12:24; 耶利米书 29:8–9"> 耶和华对我说：“那些先知奉我的名说假预言，我并没有差派他们，没有委任他们，也没有对他们说话。他们对你们说的预言是假异象，是占卜，是他们心中的妄想。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 5:12–13; 以西结书 14:10; 耶利米书 23:14–15"> 我没有差派他们，他们却奉我的名预言这地方必没有刀剑和饥荒。他们必死于刀剑和饥荒。这是耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 7:33; 箴言 1:31; 耶利米书 15:2–3"> 听他们说预言的人及其妻子儿女，必因饥荒和战争而暴尸耶路撒冷街头，无人掩埋。因为我要使他们受到应得的报应。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 8:21; 耶利米书 9:1; 耶利米书 13:17"> <span className="pl pl-1">“耶利米，你要对他们说，</span><br /><span className="pl pl-1">‘让我昼夜泪眼汪汪吧，</span><br /><span className="pl pl-1">因为我的处女同胞遭受重创，</span><br /><span className="pl pl-1">伤势危重。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 7:15; 耶利米哀歌 1:20; 耶利米书 8:10"> <span className="pl pl-1">我走到田间，</span><br /><span className="pl pl-1">眼前是死于刀下的尸体；</span><br /><span className="pl pl-1">我进入城里，</span><br /><span className="pl pl-1">见饥荒肆虐，</span><br /><span className="pl pl-1">先知和祭司也流亡异乡</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“先知和祭司也流亡异乡”或译“连先知和祭司也浑浑噩噩，茫然无措”。">a</a></sup><br /><span className="pl pl-1">。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="耶利米哀歌 5:22; 耶利米书 8:15; 耶利米书 6:30"> <span className="pl pl-1">耶和华啊，你完全丢弃犹大了吗？</span><br /><span className="pl pl-1">你厌恶锡安吗？</span><br /><span className="pl pl-1">你为什么重重地打我们，以致无法医治？</span><br /><span className="pl pl-1">我们期待平安，却没有祥和；</span><br /><span className="pl pl-1">渴望得到医治，却饱受惊吓。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 3:25; 诗篇 32:5; 约翰一书 1:7–9"> <span className="pl pl-1">耶和华啊，我们承认自己和我们祖先的罪，</span><br /><span className="pl pl-1">我们诚然得罪了你。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 14:7; 诗篇 106:45; 耶利米书 3:17"> <span className="pl pl-1">为了你的尊名，</span><br /><span className="pl pl-1">求你不要厌恶我们，</span><br /><span className="pl pl-1">不要让你荣耀的宝座蒙羞。</span><br /><span className="pl pl-1">求你顾念你与我们立的约，</span><br /><span className="pl pl-1">不要废除它。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="约珥书 2:23; 耶利米书 5:24; 诗篇 135:7"> <span className="pl pl-1">在列国供奉的偶像中，</span><br /><span className="pl pl-1">谁能赐下雨水呢？</span><br /><span className="pl pl-1">天能自降甘霖吗？</span><br /><span className="pl pl-1">我们的上帝耶和华啊，</span><br /><span className="pl pl-1">难道不是只有你能行这些事吗？</span><br /><span className="pl pl-1">是你行了这一切，</span><br /><span className="pl pl-1">所以我们仰望你。</span></span>
</div>

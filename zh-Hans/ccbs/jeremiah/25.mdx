## 预言被掳七十年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 36:1; 列王纪下 24:1–2; 但以理书 1:1"> 约西亚的儿子犹大王约雅敬执政第四年，即巴比伦王尼布甲尼撒元年，耶和华告诉了耶利米有关犹大百姓的事。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 18:11; 耶利米书 19:14–15; 马可福音 7:14–15"> 耶利米先知对犹大人和耶路撒冷的所有居民说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 11:7; 耶利米书 26:5; 耶利米书 1:2"> “从亚们的儿子犹大王约西亚执政第十三年，到今天已有二十三年。在这期间，我不断把耶和华对我说的话传给你们，你们却充耳不闻。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 25:3; 耶利米书 26:5; 耶利米书 13:10–11"> 耶和华屡次差遣祂的仆人——众先知警告你们，你们却充耳不闻，毫不理会。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 7:7; 创世记 17:8; 以赛亚书 55:6–7"> 他们对你们说，‘你们人人都要改邪归正，以便永远住在耶和华赐给你们和你们祖先的土地上。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:19; 耶利米书 7:6; 耶利米书 35:15"> 不要随从、供奉、祭拜其他神明，不要制造神像惹耶和华发怒，免得祂惩罚你们。’”</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 21:15; 箴言 8:36; 申命记 32:21"> 耶和华说：“然而，你们不听我的话，制造神像惹我发怒，自招惩罚。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 因此，万军之耶和华说：“由于你们不遵行我的命令，</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 13:3; 耶利米书 18:16; 耶利米书 1:15"> 我要召集北方各族和我的仆人巴比伦王尼布甲尼撒，去攻击这片土地和其中的居民，以及周围各国。我要彻底毁灭他们，使他们的下场令人惊骇和嗤笑，土地永远荒凉。这是耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 7:34; 启示录 18:22–23; 以西结书 26:13"> 我要使他们的欢乐声、新郎新娘的欢笑声、推磨声和灯光都消失。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 9:2; 撒迦利亚书 1:12; 历代志下 36:21–22"> 整片土地要变得荒凉可怕，列国要臣服于巴比伦王七十年。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 9:2; 以赛亚书 13:19; 耶利米书 29:10"> 七十年后，我要因巴比伦王和他国民迦勒底人的罪而惩罚他们，使他们的土地永远荒凉。这是耶和华说的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 1:10; 耶利米书 1:5; 但以理书 5:31"> 我借耶利米所说有关列国的预言都记在这书上了，我的这些话必应验在他们的土地上。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 51:6; 耶利米书 27:7; 耶利米书 50:9"> 他们必受许多国家和强大君王的奴役，我要按他们的所作所为报应他们。”</span>
</div>
</div>

## 上帝审判列国

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 14:10"> 以色列的上帝耶和华对我说：“你从我手中接过这盛满我烈怒的酒杯，到我差遣你去的国家给他们喝。</span>
<span className="v" id="v16" data-v="16" data-xref="那鸿书 3:11; 耶利米书 51:7; 耶利米书 51:39"> 他们喝了之后必东倒西歪、行为疯狂，因为我要使战祸临到他们。”</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 1:10; 耶利米书 25:28; 以西结书 43:3"> 于是，我从耶和华手中接过杯，奉祂的差遣到列国去给他们喝。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:9; 诗篇 60:3; 耶利米书 44:22"> 我给耶路撒冷和犹大的城邑，以及犹大的君王和官员喝这杯烈怒，使他们的城邑沦为废墟，令人惊骇，被人嘲笑和咒诅，正如今日一样。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 46:13–26; 那鸿书 3:8–10; 耶利米书 46:2"> 喝这杯烈怒的还有埃及王法老及其官长臣仆和全体百姓，</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:1; 以西结书 30:5; 以赛亚书 20:1"> 他们当中所有的外族人，乌斯的众王和统治亚实基伦、迦萨、以革伦以及亚实突余民的非利士众王，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 48:1–22; 诗篇 137:7; 耶利米书 9:26"> 以东、摩押和亚扪人，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 47:4; 阿摩司书 1:9–10; 以西结书 28:22–23"> 泰尔的众王、西顿的众王和海岛上的众王，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 9:26; 耶利米书 49:32; 耶利米书 49:8"> 底但、提玛、布斯和所有剃鬓发的人，</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 9:14; 耶利米书 25:20; 以西结书 30:5"> 阿拉伯的众王和荒野各族的诸王，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:11; 创世记 10:22; 以赛亚书 13:17"> 心利的众王、以拦的众王和玛代的众王，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 51:41; 耶利米书 25:9; 耶利米书 50:1–46"> 无论远近的一个个北方的王，以及天下万国，最后是巴比伦王。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 25:16; 哈巴谷书 2:16; 以西结书 21:4–5"> 耶和华对我说：“你要告诉他们，以色列的上帝——万军之耶和华说，‘你们要喝这杯烈怒，喝得大醉、呕吐、倒地不起，因为我要使刀剑临到你们。’</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 34:33; 耶利米书 51:29; 以赛亚书 14:24–27"> 如果他们不肯从你手中接过杯来喝，你就告诉他们，万军之耶和华说，‘你们必须喝！</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 38:21; 箴言 11:31; 彼得前书 4:17"> 看啊，我开始在属我的城中降下灾祸，难道你们可以逃脱惩罚吗？你们必逃不过惩罚，因为我要使刀剑临到天下万民。’这是万军之耶和华说的。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司书 1:2; 约珥书 3:16; 以赛亚书 42:13"> 耶利米啊，你要告诉他们这些预言，<br /><span className="pl pl-1">“‘耶和华要在高天怒吼，</span><br /><span className="pl pl-1">从祂的圣所发出雷鸣；</span><br /><span className="pl pl-1">祂要向祂的子民怒吼，</span><br /><span className="pl pl-1">向地上的居民呐喊，</span><br /><span className="pl pl-1">好像踩踏葡萄的人一样。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="何西阿书 4:1; 约珥书 3:2; 以赛亚书 66:16"> <span className="pl pl-1">呐喊声必传到地极，</span><br /><span className="pl pl-1">因为耶和华要指控列国，审判世人，</span><br /><span className="pl pl-1">使恶人丧身刀下。</span><br /><span className="pl pl-1">这是耶和华说的。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 23:19; 以赛亚书 34:2; 历代志下 15:6"> <span className="pl pl-1">万军之耶和华说：</span><br /><span className="pl pl-1">“看啊，灾难正蔓延到列国，</span><br /><span className="pl pl-1">有大暴风从地极卷起。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 66:16; 耶利米书 8:2; 诗篇 79:3"> 到那日，遍地都是被耶和华杀戮的人，无人哀悼、收殓和埋葬，他们好像地上的粪便。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 6:26; 耶利米书 50:27; 诗篇 2:9"> <span className="pl pl-1">你们这群牧人啊，要痛哭哀号！</span><br /><span className="pl pl-1">你们这群百姓的首领啊，</span><br /><span className="pl pl-1">要在灰尘中伤心地打滚！</span><br /><span className="pl pl-1">因为你们被宰杀和驱散的时候到了，</span><br /><span className="pl pl-1">你们必跌倒，像精美的器皿一样被摔碎。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 11:20; 阿摩司书 2:14; 耶利米书 52:8–11"> <span className="pl pl-1">牧人必无路可逃，</span><br /><span className="pl pl-1">百姓的首领必无处藏身。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 4:8; 耶利米书 25:34"> <span className="pl pl-1">听听牧人的哭喊，</span><br /><span className="pl pl-1">百姓首领的哀号吧，</span><br /><span className="pl pl-1">因为耶和华正在毁灭他们的家园。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 27:10–11; 以赛亚书 32:14"> <span className="pl pl-1">因为耶和华的震怒，</span><br /><span className="pl pl-1">宁静的草场变得一片荒凉。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:7; 耶利米书 5:6; 何西阿书 13:7–8"> <span className="pl pl-1">耶和华离开了祂的居所，</span><br /><span className="pl pl-1">就像狮子离开了洞穴。</span><br /><span className="pl pl-1">他们的土地因强敌的刀剑和耶和华的烈怒而一片荒凉。</span></span>
</div>
</div>

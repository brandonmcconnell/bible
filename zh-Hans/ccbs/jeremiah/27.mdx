## 耶利米负轭的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 27:3; 耶利米书 28:1; 耶利米书 27:12"> 约西亚的儿子犹大王约雅敬执政初期，耶和华的话传给了耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 7:1; 阿摩司书 7:4; 耶利米书 27:12"> 耶和华对我说：“你要用皮带和木头做个轭，套在自己颈上。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 1:9–3; 以西结书 25:1–17; 以西结书 17:15–21"> 然后请那些到耶路撒冷朝见犹大王西底迦的使者传话给他们的主人以东王、摩押王、亚扪王、泰尔王和西顿王，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 51:19; 耶利米书 10:10; 耶利米书 25:27"> 说，‘以色列的上帝——万军之耶和华说，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:17; 耶利米书 51:15; 诗篇 115:15–16"> 我伸出大能的臂膀创造了大地、地上的人类和动物，我想把大地赐给谁就赐给谁。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 28:14; 耶利米书 25:9; 但以理书 2:37–38"> 现在，我要把你们的国家交给我的仆人巴比伦王尼布甲尼撒，连田野的走兽也要归他管辖。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 52:31; 启示录 13:5–10; 但以理书 5:25–31"> 各国都要臣服于他和他的子孙，直到他的国家灭亡。那时，许多国家和强大的君王必奴役他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 14:21; 以西结书 17:19–21; 耶利米书 38:17–19"> 如果哪一邦或哪一国不肯臣服于巴比伦王尼布甲尼撒，不肯负巴比伦王的轭，我必用刀剑、饥荒和瘟疫惩罚他们，直到我借巴比伦王的手毁灭他们。这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 14:14; 玛拉基书 3:5; 耶利米书 29:8"> 你们不可听信你们的先知、占卜者、解梦者、巫师和术士的话，他们说你们不会臣服于巴比伦王。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:31; 耶利米书 28:16; 耶利米书 23:25"> 他们的预言是骗人的，只会使你们远离家园。我会赶走你们，使你们灭亡。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:8; 耶利米书 27:2; 耶利米书 38:2"> 但如果哪一国肯负巴比伦王的轭，臣服于他，我必使那国的人们留在本国耕种居住。这是耶和华说的。’”</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 28:1; 耶利米书 38:17; 历代志下 36:11–13"> 我同样对犹大王西底迦说：“你们要负巴比伦王的轭，臣服于他和他的人民，就可存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 18:31; 耶利米书 27:8; 箴言 8:36"> 你和你的人民何必死于刀剑、饥荒和瘟疫呢？耶和华要降这些灾难给不肯臣服于巴比伦王的国家。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 14:14; 哥林多后书 11:13–15; 耶利米书 29:8–9"> 不要听信那些先知骗人的预言，他们说你们不会臣服于巴比伦王。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 27:10; 历代志下 25:16; 耶利米书 6:13–15"> 耶和华并没有派他们，他们却奉祂的名说假预言。如果你们听信他们的话，耶和华必把你们和向你们说预言的先知赶走，使你们一同灭亡。”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 24:13; 耶利米书 28:3; 但以理书 1:2"> 我也对祭司和全体民众说：“耶和华说，‘你们不要听信假先知骗人的预言，他们说耶和华殿里的器皿很快就要从巴比伦运回来了。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 38:17; 耶利米书 38:23; 耶利米书 7:34"> 你们不可听信他们的话。你们要臣服于巴比伦王，以便存活。何必使这城沦为废墟呢？</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 7:8; 耶利米书 18:20; 撒母耳记上 12:19"> 如果他们真的是先知，有耶和华给他们的信息，就让他们求万军之耶和华不要使圣殿中、犹大王宫内和耶路撒冷剩余的器皿被掳到巴比伦去。’</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 25:13; 耶利米书 52:17–23; 列王纪下 25:17"> 巴比伦王尼布甲尼撒把约雅敬的儿子犹大王耶哥尼雅，以及犹大和耶路撒冷的贵族从耶路撒冷掳到巴比伦去的时候，没有带走耶和华殿的铜柱、铜海、铜底座及其他器皿。</span>
<span className="v" id="v21" data-v="21"> 关于耶和华殿中、犹大王宫内和耶路撒冷剩下的物件，以色列的上帝——万军之耶和华说：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 29:10; 以斯拉记 7:19; 耶利米书 32:5"> ‘它们必被掳到巴比伦，留在那里，一直到我眷顾以色列人的日子，那时我必把它们带回原处。这是耶和华说的。’”</span>

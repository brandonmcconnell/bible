## 陶器的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 1:1; 使徒行传 9:6; 耶利米书 19:1–2"> “你去陶匠家，在那里我有话告诉你。”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:14; 约拿书 1:3; 使徒行传 26:19"> 我便下到陶匠家，见他正用轮盘做器皿。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:20–23; 耶利米书 18:6; 以赛亚书 45:9"> 他手中陶造的器皿做坏了，他就用那块泥做成别的器皿，想怎么做就怎么做。</span>
<span className="v" id="v5" data-v="5"> 这时，耶和华对我说：</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 64:8; 罗马书 9:20–21; 耶利米书 18:4"> “以色列人啊，难道我不能像陶匠对待陶泥一样对待你们吗？以色列人啊，你们在我手中就像陶泥在陶匠手中一样。这是耶和华说的。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:10; 耶利米书 12:14–17; 耶利米书 45:4"> 当我宣布要铲除、推翻、毁灭哪一邦或哪一国的时候，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 18:21; 耶利米书 26:13; 约拿书 3:9–10"> 如果他们悔过自新，我必施怜悯，取消我原本要降给他们的灾祸。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:28; 阿摩司书 9:11–15; 耶利米书 1:10"> 当我宣布要建造和栽培哪一邦或哪一国的时候，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 33:18; 撒母耳记上 2:30; 以西结书 18:24"> 如果他们做我视为恶的事，不听从我的话，我必改变心意，取消我原本要赐给他们的福气。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 17:13; 以赛亚书 55:6–7; 耶利米书 35:15"> 因此，你去告诉犹大人和耶路撒冷的居民，‘耶和华说，我正计划降灾祸惩罚你们。你们要离开罪恶，改邪归正。’</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:25; 耶利米书 7:24; 申命记 29:19"> 他们却说，‘没用！我们要随心所欲，为所欲为。’”</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 5:30; 何西阿书 6:10; 耶利米书 23:14"> <span className="pl pl-1">因此耶和华说：</span><br /><span className="pl pl-1">“你们问问列国，</span><br /><span className="pl pl-1">看看谁曾听过这样的事？</span><br /><span className="pl pl-1">少女以色列竟做了一件极可怕的事。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 6:68"> <span className="pl pl-1">黎巴嫩山岭上的积雪会融化吗？</span><br /><span className="pl pl-1">从远方流来的冰凉溪水会停止吗？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:16; 耶利米书 2:32; 何西阿书 11:2"> <span className="pl pl-1">然而，我的子民却把我忘记，</span><br /><span className="pl pl-1">向虚无的神明烧香，</span><br /><span className="pl pl-1">以致他们跌倒，偏离古道，走入僻陋的小路。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 22:7; 耶利米书 25:9; 耶利米书 19:8"> <span className="pl pl-1">因此，他们的土地必荒凉，</span><br /><span className="pl pl-1">永远遭人嗤笑，</span><br /><span className="pl pl-1">经过此地的人无不惊惧，</span><br /><span className="pl pl-1">摇头叹息。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 13:24; 耶利米书 2:27; 约伯记 27:21"> <span className="pl pl-1">我要在敌人面前驱散他们，</span><br /><span className="pl pl-1">就像东风吹散尘土一样。</span><br /><span className="pl pl-1">在他们遭难的时候，</span><br /><span className="pl pl-1">我必以背相向，</span><br /><span className="pl pl-1">不理睬他们。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="诗篇 52:2; 耶利米书 11:19; 玛拉基书 2:7"> 他们说：“来！我们设计对付耶利米吧，反正我们一直有祭司教导律法，有智者出谋划策，有先知传讲预言。来吧！我们抨击他，不要理会他的话。”</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:9; 耶利米书 20:12; 诗篇 55:16–17"> <span className="pl pl-1">耶和华啊，求你眷顾我，</span><br /><span className="pl pl-1">听听敌人对我的指控。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 35:7; 诗篇 57:6; 诗篇 106:23"> <span className="pl pl-1">人岂能以恶报善？</span><br /><span className="pl pl-1">他们竟设陷阱谋害我，</span><br /><span className="pl pl-1">求你顾念我怎样站在你面前为他们求情，</span><br /><span className="pl pl-1">怎样求你不要向他们发烈怒。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 109:9–20; 耶利米哀歌 5:3; 阿摩司书 4:10"> <span className="pl pl-1">因此，求你让他们丧身刀下，</span><br /><span className="pl pl-1">儿女饿死，</span><br /><span className="pl pl-1">妻子丧夫亡子，</span><br /><span className="pl pl-1">男人被杀，</span><br /><span className="pl pl-1">青年死于战场！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 6:26; 诗篇 140:5; 西番雅书 1:10–11"> <span className="pl pl-1">当你使敌军突袭他们时，</span><br /><span className="pl pl-1">愿他们家中传出哭喊声，</span><br /><span className="pl pl-1">因为他们挖陷阱要捕捉我，</span><br /><span className="pl pl-1">设圈套要绊我的脚。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 35:4; 诗篇 69:22–28; 尼希米记 4:4–5"> <span className="pl pl-1">耶和华啊，你知道他们害我的各种诡计，</span><br /><span className="pl pl-1">求你不要赦免他们的罪过，</span><br /><span className="pl pl-1">不要从你眼前涂抹他们的罪恶。</span><br /><span className="pl pl-1">求你使他们倒在你面前，</span><br /><span className="pl pl-1">求你在烈怒中惩罚他们。</span></span>
</div>

## 犹大的灭亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 24:18; 约书亚记 10:29; 历代志下 36:11"> 西底迦二十一岁登基，在耶路撒冷执政十一年。他母亲叫哈慕她，是立拿人耶利米的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 14:22; 列王纪下 24:19–20; 以西结书 17:16–20"> 西底迦像约雅敬一样做耶和华视为恶的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 3:4–5; 历代志下 36:13; 以赛亚书 3:1"> 因此，耶和华向耶路撒冷和犹大的人发怒，最终把他们从祂面前赶走。 后来，西底迦背叛了巴比伦王。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:1; 撒迦利亚书 8:19; 以西结书 24:1–2"> 在他执政第九年十月十日，巴比伦王尼布甲尼撒率领全军攻打耶路撒冷，在城外安营，修筑围城的高台。</span>
<span className="v" id="v5" data-v="5"> 城一直被围困到西底迦王执政第十一年。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 39:2; 以赛亚书 3:1; 列王纪下 25:3"> 那年四月九日，城里饥荒非常严重，百姓无粮可吃。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 39:4–7; 耶利米书 51:32; 列王纪下 25:4"> 城被攻破，西底迦和士兵便在夜间从靠近御花园的两城墙中间的门逃往亚拉巴。当时迦勒底人仍四面包围着城。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 34:21; 耶利米书 32:4; 耶利米书 38:23"> 迦勒底的军队追赶西底迦，在耶利哥平原追上了他。他的军队都四散而逃。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 39:5; 民数记 13:21; 列王纪下 25:6"> 迦勒底人擒住西底迦，把他押到哈马的利比拉去见巴比伦王。巴比伦王在那里审判他，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 22:30; 列王纪下 25:7; 创世记 21:16"> 当着他的面杀了他的众子和犹大所有的官员，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 12:13; 耶利米书 34:3–5"> 又剜去他的双眼，把他用铜链锁着押往巴比伦，将他终生囚在牢里。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:8; 耶利米书 39:9; 耶利米书 52:29"> 巴比伦王尼布甲尼撒执政第十九年五月十日，他的臣仆护卫长尼布撒拉旦进入耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 79:1; 弥迦书 3:12; 历代志下 36:19"> 放火焚烧耶和华的殿、王宫及耶路撒冷所有的房屋。他烧毁了所有重要建筑。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 1:3; 列王纪下 25:10"> 他率领的迦勒底军队拆毁了耶路撒冷四围的城墙。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1–2; 撒迦利亚书 14:2"> 护卫长尼布撒拉旦掳去最贫穷的人、城中的余民、那些投降巴比伦王的人和剩下的技工，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 25:12; 耶利米书 39:9–10; 耶利米书 40:5–7"> 只留下一些最贫穷的人，让他们照料葡萄园、耕种田地。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 27:19–22; 耶利米书 52:21–23; 历代志下 4:12–15"> 迦勒底人打碎耶和华殿中的铜柱、铜底座和铜海，把铜运往巴比伦，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:3; 民数记 4:14; 列王纪上 7:45"> 并带走了盆、铲、灯剪、碗、碟及一切献祭用的铜器。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:49–50; 历代志下 4:6–22; 利未记 26:12"> 护卫长还带走了杯、火鼎、碗、盆、灯台、碟和奠酒的杯等所有金银器皿。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 7:47; 列王纪下 25:16; 历代志下 4:18"> 所罗门王为耶和华的殿所造的两根铜柱、一个铜海、铜海下面的十二头铜牛，以及一些铜底座，用的铜多得无法计算。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:17; 列王纪上 7:15–21; 历代志下 3:15–17"> 两根铜柱中空，高八米，周长五米四，铜壁厚四指。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:25; 列王纪下 25:17; 历代志下 3:15"> 铜柱有柱冠，柱冠高两米二，柱冠周围装饰着铜网和铜石榴。两根柱子都一样。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 7:20"> 每根铜柱周围装饰着九十六个石榴，网子四周共有一百个石榴。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 25:18; 耶利米书 29:25; 耶利米书 35:4"> 护卫长掳走祭司长西莱雅、副祭司长西番亚和三名殿门守卫，</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 25:19; 以斯帖记 1:14; 马太福音 18:10"> 又从城中掳走一名统管士兵的将领、王的七个亲信、一名负责招兵的书记和城中找到的六十名平民，</span>
<span className="v" id="v26" data-v="26"> 把他们带到利比拉去见巴比伦王。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 33:28; 以赛亚书 32:13–14; 以赛亚书 6:11–12"> 巴比伦王在哈马地区的利比拉处死了他们。犹大人就这样被掳去，离开了家园。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 24:12–16; 列王纪下 24:2–3; 但以理书 1:1–3"> 以下是尼布甲尼撒掳去的人数：他执政第七年掳去三千零二十三名犹大人；</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 52:12; 创世记 12:5; 列王纪下 25:11"> 他执政第十八年，从耶路撒冷掳去八百三十二人；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 52:15; 耶利米书 6:9"> 他执政第二十三年，他的护卫长尼布撒拉旦掳去七百四十五名犹大人。总共四千六百人。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 25:27–30; 诗篇 3:3; 创世记 40:13"> 犹大王约雅斤被掳后第三十七年，即巴比伦王以未·米罗达元年十二月二十五日，巴比伦王恩待约雅斤，释放了他，</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; 但以理书 5:18–19; 但以理书 2:37"> 并好言相待，使他的地位高过被掳到巴比伦的其他各王。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 9:7; 列王纪上 2:7; 创世记 41:14"> 约雅斤脱去了囚服，终生与巴比伦王一起吃饭。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 9:10; 路加福音 11:3; 马太福音 6:11"> 在他有生之年，巴比伦王供应他每天的需用，直到他去世。</span>

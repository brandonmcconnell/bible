## 真假先知

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 27:1; 约书亚记 9:3; 以赛亚书 9:15"> 同一年，就是犹大王西底迦执政的第四年五月，基遍人押朔的儿子哈拿尼雅先知在耶和华的殿中当着祭司和全体民众的面对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="弥迦书 3:11; 以西结书 13:5–16; 耶利米书 27:2–12"> “以色列的上帝——万军之耶和华说，‘我必折断巴比伦王奴役你们的轭。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 24:13; 历代志下 36:10; 但以理书 1:2"> 两年之内，我必把巴比伦王尼布甲尼撒从耶和华殿中掳到巴比伦的一切器皿带回来；</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 22:24; 列王纪下 25:27–30; 耶利米书 28:2"> 我也必把约雅敬的儿子犹大王耶哥尼雅和其他所有被掳到巴比伦的犹大人带回来，因为我要折断巴比伦王奴役你们的轭。这是耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 28:1; 耶利米书 26:2; 耶利米书 19:14"> 耶利米先知当着站在耶和华殿里的祭司和民众的面对哈拿尼雅先知说：</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 41:13; 列王纪上 1:36; 耶利米书 11:5"> “诚愿如此！愿耶和华这样做，愿耶和华应验你的预言，把祂殿中的器皿和所有被掳的人从巴比伦带回来。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 22:28"> 不过，请你和众人都听我说，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:26–27; 列王纪上 17:1; 列王纪上 22:8"> 在你我之前的古代先知曾预言许多地方和强国要遭遇战争、灾祸和瘟疫。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 18:22; 耶利米书 6:14; 耶利米书 4:10"> 至于那预言会有平安的先知，只有他的话应验了，才能确认他是耶和华派来的。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 27:2; 耶利米书 28:4; 玛拉基书 3:13"> 哈拿尼雅先知把轭从耶利米先知的颈上取下并折断，</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 14:7; 历代志下 18:22–23; 耶利米书 27:2–12"> 然后当众说：“耶和华说，‘两年之内，我要照样折断巴比伦王尼布甲尼撒加在列国颈上的轭。’”于是耶利米先知离开了那里。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:2; 但以理书 9:2; 列王纪下 20:4"> 哈拿尼雅先知把耶利米先知颈上的轭折断后不久，耶和华对耶利米说：</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 149:8; 耶利米书 27:15; 耶利米哀歌 2:14"> “你去告诉哈拿尼雅，耶和华说，‘你折断了木轭，却要换来铁轭。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:48; 耶利米书 27:6–7; 但以理书 2:38"> 我要把铁轭放在所有这些国家的颈上，他们都要臣服于巴比伦王尼布甲尼撒，连田野的走兽也要交给他管辖。’这是以色列的上帝——万军之耶和华说的。”</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 14:14–15; 耶利米书 27:15; 耶利米书 23:21"> 耶利米先知就对哈拿尼雅先知说：“哈拿尼雅，听着！耶和华并没有差派你，你却诱使这些民众相信你的谎话。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 29:32; 创世记 7:4; 出埃及记 32:12"> 因此，耶和华说，‘我要把你从世上除掉，你今年必死，因为你说了悖逆耶和华的话。’”</span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 1:6; 以赛亚书 44:25–26"> 哈拿尼雅先知便在当年七月死了。</span>
</div>
</div>

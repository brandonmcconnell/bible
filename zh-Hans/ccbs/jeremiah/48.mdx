## 关于摩押的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 32:3; 民数记 32:37–38; 耶利米书 48:22–23"> 关于摩押，以色列的上帝——万军之耶和华说：<br /><span className="pl pl-1">“尼波大祸临头了！</span><br /><span className="pl pl-1">它必被毁灭；</span><br /><span className="pl pl-1">基列亭必蒙羞沦陷，</span><br /><span className="pl pl-1">堡垒必蒙羞被毁。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民数记 32:37; 耶利米书 31:36; 以赛亚书 16:14"> <span className="pl pl-1">摩押不再受称赞，</span><br /><span className="pl pl-1">敌人在希实本图谋害她，说，</span><br /><span className="pl pl-1">‘来吧！我们铲除这个国家。’</span><br /><span className="pl pl-1">玛得缅啊，你也将变得死寂无声，</span><br /><span className="pl pl-1">刀剑必追杀你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 15:5; 耶利米书 48:34; 耶利米书 48:5"> <span className="pl pl-1">“从何罗念传来呼喊声，</span><br /><span className="pl pl-1">‘荒凉了！毁灭了！’</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 137:9; 民数记 21:27–30; 以斯帖记 8:11"> <span className="pl pl-1">摩押灭亡了，</span><br /><span className="pl pl-1">她的孩童放声哀哭。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 15:5"> <span className="pl pl-1">摩押人痛哭着走上鲁希坡，</span><br /><span className="pl pl-1">他们在何罗念的下坡听见悲惨的哀号。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 17:6; 耶利米书 51:6; 约伯记 30:3–7"> <span className="pl pl-1">逃命吧！像灌木一样藏到旷野去吧！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:29; 耶利米书 9:23; 诗篇 52:7"> <span className="pl pl-1">摩押啊，你要被攻占，</span><br /><span className="pl pl-1">因为你倚仗自己的成就和财富。</span><br /><span className="pl pl-1">你的神明基抹及供奉它的祭司和官长都要被掳去。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 6:26; 耶利米书 51:56; 耶利米书 25:9"> <span className="pl pl-1">毁灭者必攻击每一座城邑，</span><br /><span className="pl pl-1">无一幸免；</span><br /><span className="pl pl-1">山谷遭践踏，</span><br /><span className="pl pl-1">平原被毁坏，</span><br /><span className="pl pl-1">正如耶和华所说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 11:1; 耶利米书 48:28; 以赛亚书 16:2"> <span className="pl pl-1">“给摩押翅膀让她飞走吧</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“给摩押翅膀让她飞走吧，”或译作“给摩押竖起墓碑吧，因为她将被毁灭”或“在摩押撒盐吧，因为她将被毁灭”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">因为她的城邑将沦为废墟，</span><br /><span className="pl pl-1">杳无人迹。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:3; 列王纪上 20:42; 士师记 5:23"> <span className="pl pl-1">不殷勤地为耶和华做工，</span><br /><span className="pl pl-1">不挥刀斩杀摩押人的必受咒诅。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="西番雅书 1:12; 撒迦利亚书 1:15; 耶利米书 48:29"> <span className="pl pl-1">“摩押自幼常享安逸，</span><br /><span className="pl pl-1">从未被掳到别处，</span><br /><span className="pl pl-1">好像沉淀的酒没有被从这缸倒到那缸，</span><br /><span className="pl pl-1">味道依旧，香气未变。</span></span>
<span className="v" id="v12" data-v="12" data-xref="那鸿书 2:2; 以赛亚书 30:14; 以西结书 25:9–10"> “不过，看啊，时候将到，我要派倒酒的人去把她倒出来，倒空酒缸，把缸打碎。这是耶和华说的。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 45:16; 士师记 11:24; 耶利米书 48:39"> 摩押人必因他们的神明基抹而羞愧，就像以色列人因信靠伯特利的神像而羞愧一样。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 33:16; 以赛亚书 10:13; 以赛亚书 10:16"> <span className="pl pl-1">“摩押人啊，</span><br /><span className="pl pl-1">你们怎能自称为骁勇善战的英雄呢？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 50:27; 耶利米书 46:18; 耶利米书 51:57"> <span className="pl pl-1">摩押要灭亡了，</span><br /><span className="pl pl-1">她的城邑要被摧毁，</span><br /><span className="pl pl-1">她最勇敢的青年将被杀戮。</span><br /><span className="pl pl-1">这是名叫万军之耶和华的君王说的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 13:22; 耶利米书 1:12; 以西结书 12:28"> <span className="pl pl-1">摩押快要被毁灭了，</span><br /><span className="pl pl-1">她的灾难就要来临。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 9:4; 以赛亚书 14:4–5; 以西结书 19:11–14"> <span className="pl pl-1">她的近邻和知道她名望的人啊，</span><br /><span className="pl pl-1">你们都要为她哀悼，</span><br /><span className="pl pl-1">‘那强大、辉煌的权势竟然崩溃了！’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="民数记 21:30; 以赛亚书 47:1; 以赛亚书 15:2"> <span className="pl pl-1">“底本的居民啊，</span><br /><span className="pl pl-1">你们要从荣耀的位子上下来，</span><br /><span className="pl pl-1">坐在干旱的地上，</span><br /><span className="pl pl-1">因为毁灭摩押的要来攻击你们，</span><br /><span className="pl pl-1">摧毁你们的堡垒。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:36; 撒母耳记上 4:16; 撒母耳记上 4:13–14"> <span className="pl pl-1">亚罗珥的居民啊！</span><br /><span className="pl pl-1">你们要站在路旁观望，</span><br /><span className="pl pl-1">询问逃难的男女究竟发生了什么事。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 16:2; 民数记 21:26–28; 申命记 2:36"> <span className="pl pl-1">你们会得知摩押沦陷了，</span><br /><span className="pl pl-1">她羞愧难当。</span><br /><span className="pl pl-1">你们哀伤痛哭吧！</span><br /><span className="pl pl-1">你们要在亚嫩河边宣告，</span><br /><span className="pl pl-1">‘摩押被毁灭了！’</span></span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 13:18; 以赛亚书 15:4; 耶利米书 48:8"> “审判降临在平原上的何伦、雅杂、米法押、</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 48:18; 民数记 33:46; 民数记 32:34"> 底本、尼波、伯·低比拉太音、</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 13:17; 耶利米书 48:1; 民数记 32:38"> 基列亭、伯·迦末、伯·米恩、</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 2:2; 耶利米书 48:41; 约书亚记 21:36"> 加略、波斯拉等摩押远近各地的城邑。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 75:10; 诗篇 10:15; 撒迦利亚书 1:19–21"> 摩押的权势被粉碎了，她的力量被摧毁了。这是耶和华说的。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 48:42; 以赛亚书 29:9; 耶利米书 51:39"> “你们要灌醉她，因为她藐视耶和华。她必在自己的呕吐物中打滚，被人耻笑。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 2:26; 弥迦书 7:8–10; 西番雅书 2:8"> 摩押啊，你不是曾经嘲笑以色列吗？以色列难道是强盗吗？你每次谈到她总是不屑地摇头。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 55:6–7; 士师记 6:2; 雅歌 2:14"> <span className="pl pl-1">“摩押人啊，</span><br /><span className="pl pl-1">你们要离开城邑，住到岩洞里，</span><br /><span className="pl pl-1">像鸽子在岩缝里筑巢一样。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 16:6; 诗篇 138:6; 以赛亚书 2:11–12"> <span className="pl pl-1">我们听说摩押傲气冲天，</span><br /><span className="pl pl-1">狂妄自大、心中高傲。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 50:36; 以赛亚书 16:6; 以赛亚书 37:28–29"> <span className="pl pl-1">我知道摩押的狂傲不过是外强中干，</span><br /><span className="pl pl-1">她的夸耀不过是虚张声势。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 15:5; 列王纪下 3:25; 耶利米书 48:36"> <span className="pl pl-1">因此，我要为她哀号，</span><br /><span className="pl pl-1">为摩押人痛哭，</span><br /><span className="pl pl-1">为吉珥·哈列设人悲伤。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 16:8–9; 民数记 21:32; 约书亚记 13:19"> <span className="pl pl-1">西比玛的葡萄树啊，</span><br /><span className="pl pl-1">我为你比为雅谢人哭得更悲痛！</span><br /><span className="pl pl-1">你的枝条虽然延伸到大海，</span><br /><span className="pl pl-1">一直到雅谢，</span><br /><span className="pl pl-1">但毁灭者已在蹂躏你夏日的果子和葡萄！</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 5:10; 哈该书 2:16; 耶利米书 25:9–10"> <span className="pl pl-1">摩押的沃土上再没有欢喜快乐的声音。</span><br /><span className="pl pl-1">我使榨酒池不出酒，</span><br /><span className="pl pl-1">再没有踩踏葡萄的欢呼声，</span><br /><span className="pl pl-1">欢呼被呐喊取代。</span></span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 15:4–6; 民数记 32:3; 申命记 34:3"> “哀哭声从希实本传到以利亚利和雅杂，又从琐珥传到何罗念和伊基拉·施利施亚，因为连宁林的水也干涸了。”</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 15:2; 以赛亚书 16:12; 民数记 28:14"> 耶和华说：“我要灭绝摩押那些在丘坛献祭和向他们神明烧香的人。</span>
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 15:7; 以赛亚书 16:11; 以赛亚书 15:5"> 我的心为摩押悲鸣，好像凄凉的箫声；我的心为吉珥·哈列设人悲鸣，好像凄凉的箫声。他们的一切财富都消失了。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 41:5; 创世记 37:34; 耶利米书 47:5"> 他们都悲哀地剃去发须，割伤双手，腰束麻布。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 22:28; 耶利米书 25:34; 以赛亚书 22:1"> 在摩押境内的屋顶和街头巷尾，哀声处处可闻，因为我已把摩押打得粉碎，好像打碎没人要的器皿。这是耶和华说的。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 20:4–6; 耶利米哀歌 4:1; 耶利米哀歌 2:1"> 摩押破碎不堪！她嚎啕痛哭，羞愧难当，令四围的人嗤笑、惊惧。”</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 8:8; 申命记 28:49; 耶利米书 49:22"> 耶和华说：<br /><span className="pl pl-1">“看啊，敌人必像展翅疾飞的大鹰一样来攻击摩押。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 21:3; 以赛亚书 13:8; 弥迦书 4:9–10"> <span className="pl pl-1">他们要攻取城池，占领堡垒。</span><br /><span className="pl pl-1">那时，摩押的勇士像临盆的妇人一样心惊胆战。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 48:2; 以赛亚书 7:8; 以赛亚书 37:23"> <span className="pl pl-1">摩押必被摧毁，最后亡国，</span><br /><span className="pl pl-1">因为她藐视耶和华。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="耶利米哀歌 3:47; 以赛亚书 24:17–18; 申命记 32:23–25"> <span className="pl pl-1">摩押人啊！</span><br /><span className="pl pl-1">你们要充满恐惧，</span><br /><span className="pl pl-1">陷入深坑和网罗。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>

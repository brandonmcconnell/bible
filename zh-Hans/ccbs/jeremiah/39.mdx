## 耶路撒冷沦陷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 24:1–2; 耶利米书 52:4–7; 列王纪下 25:1–12"> 犹大王西底迦执政第九年十月，巴比伦王尼布甲尼撒率领全军包围耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 52:6–7; 弥迦书 2:12–13; 列王纪下 25:3–4"> 西底迦执政第十一年四月九日，耶路撒冷沦陷。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:4; 耶利米书 38:17; 耶利米书 39:13"> 尼甲·沙利薛、三甲·尼波、撒西金和另一个尼甲·沙利薛等巴比伦王的所有官长都进城坐在中门。</span>
<span className="v" id="v4" data-v="4" data-xref="阿摩司书 2:14; 历代志下 32:5; 列王纪下 25:4–7"> 犹大王西底迦和所有军兵见势不妙，便在夜间穿过御花园，从两城墙中间的门逃往亚拉巴。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:33; 约书亚记 5:10; 耶利米书 52:26–27"> 但迦勒底的军队追赶他们，在耶利哥平原追上并擒住西底迦，把他押到哈马的利比拉去见巴比伦王尼布甲尼撒，在那里接受王的审判。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 52:10; 耶利米书 34:19–21; 耶利米书 24:8–10"> 巴比伦王在利比拉当着西底迦的面杀了他的众子和犹大所有的贵族，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 12:13; 列王纪下 25:7; 耶利米书 52:11"> 又剜去他的双眼，把他用铜链锁着押往巴比伦。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 1:3; 耶利米书 38:18; 耶利米书 21:10"> 迦勒底人放火焚烧王宫和民居，拆毁耶路撒冷的城墙。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 40:1; 创世记 37:36; 耶利米书 10:18"> 护卫长尼布撒拉旦把城中的余民以及投降的人都掳到巴比伦，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 25:12; 耶利米书 40:7; 耶利米书 52:16"> 却让那些一贫如洗的穷人留在犹大，将葡萄园和田地分给他们。</span>
</div>

## 耶利米获释

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:23; 耶利米书 15:21; 约伯记 5:19"> 至于耶利米，巴比伦王尼布甲尼撒吩咐护卫长尼布撒拉旦：</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; 耶利米书 40:4; 箴言 21:1"> “你把耶利米带去好好照顾，切不可伤害他。他有什么要求，你都要满足。”</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:3; 耶利米书 39:9"> 于是，护卫长尼布撒拉旦、尼布沙斯班、尼甲·沙利薛等巴比伦王的所有将领，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 38:28; 列王纪下 22:12; 耶利米书 26:24"> 便派人把耶利米从护卫的院子提出来，让沙番的孙子、亚希甘的儿子基大利带他回家。从此，耶利米就生活在百姓当中。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 2:9; 耶利米书 32:1–2; 耶利米书 36:1–5"> 耶利米被监禁在护卫院子里的时候，耶和华对他说：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 9:12; 撒迦利亚书 1:6; 约书亚记 23:14–15"> “你去告诉古实人以伯·米勒，以色列的上帝——万军之耶和华说，‘看啊，我必照我说的使这城遭受灾祸，得不到祝福。你必亲眼看见这一切发生。’</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 41:1–2; 诗篇 91:14–15; 诗篇 50:15"> 耶和华说，‘但那时，我必拯救你，使你不致落在你所惧怕的人手中。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:2; 诗篇 34:22; 耶利米书 21:9"> 我必拯救你，使你保全性命，不致丧身刀下，因为你信靠我。这是耶和华说的。’”</span>
</div>

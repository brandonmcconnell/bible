## 耶和华降灾难的日子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:2; 耶利米书 2:1; 耶利米书 1:4"> 耶和华对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:26–27; 路加福音 23:29; 创世记 19:14"> “你不可在这地方娶妻，也不可生儿育女。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 16:9; 耶利米书 16:5; 耶利米书 6:21"> 至于在这地方出生的孩子和他们的父母，耶和华说，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 25:33; 诗篇 83:10; 耶利米书 9:22"> ‘他们必死于恶疾，无人哀悼，无人埋葬，他们好像地上的粪便。他们必死于战争和饥荒，尸首必成为飞禽走兽的食物。’”</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 24:16–23; 以赛亚书 27:11; 耶利米书 15:1–4"> 耶和华对我说：“你不要进入丧家，也不要为他们哀悼悲伤，因为我已收回我赐给这些百姓的平安、慈爱和怜悯。这是耶和华说的。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:1; 耶利米书 41:5; 耶利米书 47:5"> 他们无论尊卑都要死在这里，无人埋葬，无人哀悼，也无人为他们的死而割伤身体、剃光头发。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 9:4; 以西结书 24:17; 申命记 26:14"> 无人用食物安慰哀悼者，也无人给丧父或丧母者一杯安慰酒。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 15:17; 传道书 7:2–4; 以赛亚书 22:12–14"> 你不可进入宴乐之家与他们同坐吃喝。”</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 25:10; 耶利米书 7:34; 以西结书 26:13"> 因为以色列的上帝——万军之耶和华说：“在他们有生之年，我要使这地方的欢乐声和新郎新娘的欢笑声从他们眼前消失。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:19; 列王纪上 9:8–9; 申命记 29:24–25"> “当你把这些话告诉他们的时候，他们会质问你，‘耶和华为什么给我们降这大灾难？我们有什么罪？我们哪里得罪了我们的上帝耶和华？’</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:35–41; 申命记 29:25–26; 耶利米书 22:9"> 你要对他们说，‘耶和华说，这是因为你们的祖先背弃我，去跟随、供奉、祭拜其他神明；他们背弃我，不遵守我的律法。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 13:10; 耶利米书 7:26; 传道书 9:3"> 可是，你们的行为比他们更邪恶。看啊，你们心存恶念，一意孤行，不听从我。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:36; 申命记 4:26–28; 耶利米书 15:14"> 所以，我要把你们从这里驱逐到你们和你们祖先都不认识的地方，你们在那里要日夜供奉其他神明，因为我不再恩待你们。’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:7–8; 申命记 15:15; 出埃及记 20:2"> 耶和华说：“时候将到，那时人不再凭把以色列人带出埃及的耶和华起誓，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:18; 耶利米书 24:6; 耶利米书 32:37"> 而是凭把他们从北方之地和流亡的列国领回来的永活的耶和华起誓。因为我必领他们回到我赐给他们祖先的地方。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="哈巴谷书 1:14–15; 阿摩司书 4:2; 弥迦书 7:2"> 耶和华说：“看啊，我要召来许多渔夫把他们捕捞上来，然后我要召来许多猎人去各山岭和岩穴猎取他们。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 15:3; 耶利米书 23:24; 箴言 5:21"> 因为我鉴察他们的一切行为，他们在我面前无法隐藏，他们的罪恶逃不过我的眼晴。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 35:33–34; 以赛亚书 40:2; 启示录 18:6"> 首先，我要让他们因自己的罪与恶而受加倍的报应，因为他们用没有生命气息的可憎偶像玷污我的土地，使可憎之物充满我的产业。”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 25:4; 耶利米书 17:17; 那鸿书 1:7"> <span className="pl pl-1">耶和华啊，你是我的力量，</span><br /><span className="pl pl-1">是我的堡垒，</span><br /><span className="pl pl-1">是我患难时的避难所。</span><br /><span className="pl pl-1">万国都要从地极来朝见你，</span><br /><span className="pl pl-1">说：“我们祖先所拜的神像虚假无用，一无是处。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 37:19; 诗篇 115:4–8; 加拉太书 4:8"> <span className="pl pl-1">难道人可以为自己制造神明吗？</span><br /><span className="pl pl-1">其实那些神明并不是真神。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 9:16; 诗篇 83:18; 耶利米书 33:2"> 耶和华说：“所以，看啊，这一次我要让他们知道我的权柄和能力，他们就知道我名叫耶和华。”</span>
</div>

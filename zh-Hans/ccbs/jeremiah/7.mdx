## 圣殿讲道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 26:2; 启示录 3:22; 阿摩司书 7:16"> “你站在耶和华殿的门口这样宣告，‘所有从这些门进殿敬拜耶和华的犹大人啊，你们要听耶和华的话。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:11; 耶利米书 26:13; 以赛亚书 1:16–19"> 以色列的上帝——万军之耶和华说，你们改过自新，我便让你们在这里安居。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:11; 马太福音 3:9–10; 西番雅书 3:11"> 你们不要相信那些谎言，说这是耶和华的殿，这是耶和华的殿，这是耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:12–13; 以赛亚书 1:19; 耶利米书 7:3"> “‘如果你们真正改过自新，彼此公平相待，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:21–24; 撒迦利亚书 7:9–12; 耶利米书 13:10"> 不欺压异乡人和孤儿寡妇，不在这地方滥杀无辜，不拜其他神明自取毁灭，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:40; 耶利米书 25:5; 耶利米书 3:18"> 我便让你们在这块我永远赐给你们祖先的土地上安居。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:15; 以西结书 13:6–16; 耶利米书 23:14–16"> “‘然而，你们竟相信那些空洞的谎言。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:6; 出埃及记 20:3; 雅各书 4:1–4"> 难道你们偷盗、谋杀、通奸、起假誓、向巴力献祭、拜不认识的神明，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:34; 以西结书 23:37; 以西结书 23:39"> 然后来到这用来敬拜我的殿，站在我面前说自己安全了，就以为可以继续做可憎之事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以赛亚书 56:7; 马太福音 21:13"> 难道这用来敬拜我的殿在你们眼中竟成了贼窝吗？这些事，我都看在眼里。这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 26:6; 撒母耳记上 4:10–11"> “‘你们去我曾选为我名所在之地的示罗，看看我是怎样因我以色列子民的罪而惩罚那地方的。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 65:12; 历代志下 36:15–16; 耶利米书 7:25"> 我对你们的所作所为一再提出警告，你们却充耳不闻；我呼唤你们，你们却不回应。这是耶和华说的。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:60; 列王纪下 25:9; 耶利米书 7:4"> 因此，我要像对待示罗一样，对待你们所倚靠的这用来敬拜我的殿，对待我赐给你们和你们祖先的地方。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1; 列王纪下 17:23; 耶利米书 52:3"> 我要把你们从我面前赶走，好像从前赶走你们的弟兄以法莲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以法莲”此处指“北国以色列”。">a</a></sup>人一样。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 11:14; 耶利米书 14:11–12; 耶利米书 15:1"> “耶利米啊，不要为这些百姓祷告，不要替他们呼求祷告，不要为他们向我祈求，因为我必不听。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 8:6–18; 以西结书 14:23; 耶利米书 6:27"> 你没有看见他们在犹大各城和耶路撒冷街道上所做的事吗？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 19:13; 耶利米书 44:17–19; 哥林多前书 10:22"> 孩子拾柴，父亲点火，妇人揉面做饼向天后献祭，向其他神明奠酒，惹我发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 20:11; 耶利米书 2:19; 但以理书 9:7–8"> 难道他们是在惹我发怒吗？难道他们不是自害己身，自取羞辱吗？这是耶和华说的。”</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 42:18; 耶利米哀歌 2:3–5; 以赛亚书 42:25"> 因此，主耶和华说：“我要向这地方的人、牲畜、田野的树木和地里的出产发怒，发烈怒，如熊熊怒火，无法熄灭。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿书 8:13; 耶利米书 6:20; 阿摩司书 5:21–23"> 以色列的上帝——万军之耶和华说：“你们把燔祭和其他祭物都拿去吃吧！</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 6:6; 撒母耳记上 15:22; 诗篇 51:16–17"> 因为我把你们祖先带出埃及的时候，并没有吩咐他们献燔祭或其他祭物，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:26; 申命记 5:33; 出埃及记 19:5–6"> 只吩咐他们一件事，‘你们要听从我的话，我就做你们的上帝，你们做我的子民；你们遵行我的一切吩咐，就必蒙福。’</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 耶利米书 8:5; 耶利米书 7:26"> 他们却掩耳不听，一意孤行，任意行恶，越来越坏。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 36:15; 耶利米书 25:4; 尼希米记 9:26"> 从你们的祖先离开埃及那天起，一直到今天，我日复一日地差遣我的仆人——众先知到你们那里，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 16:12; 历代志下 30:8; 耶利米书 7:24"> 但你们掩耳不听，顽固不化，比你们的祖先更邪恶。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 26:2; 耶利米书 1:7; 以赛亚书 65:12"> “耶利米啊，你将这番话告诉他们，他们也不会听；你向他们呼吁，他们也不会回应。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:14–15; 箴言 1:7; 以赛亚书 1:4–5"> 你要对他们说，‘这就是不听他们上帝耶和华的话、不肯受管教的国民。忠信丧尽，他们已绝口不提。</span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 弥迦书 1:16; 耶利米书 6:30"> <span className="pl pl-1">“‘你们要剪去头发扔掉，</span><br /><span className="pl pl-1">在光秃的山上唱哀歌，</span><br /><span className="pl pl-1">因为耶和华已弃绝这惹祂发怒的世代。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 32:34; 以西结书 7:20; 但以理书 9:27"> 耶和华说：“犹大人做了我视为邪恶的事，把可憎的偶像放在用来敬拜我的圣殿中，玷污了圣殿。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:10; 耶利米书 32:35; 利未记 18:21"> 他们在欣嫩子谷的陀斐特建造丘坛，焚烧自己的儿女。我从未吩咐他们这样做，连想都没想过。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 19:11; 耶利米书 19:6; 列王纪下 23:10"> 因此，看啊，时候将到，那地方必不再叫陀斐特或欣嫩子谷，而要叫杀戮谷。他们要在那里埋葬死人，直到无处可埋。这是耶和华说的。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 12:9; 申命记 28:26; 启示录 19:17–18"> 飞禽走兽必吃这百姓的尸体，无人驱赶它们。</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 18:23; 何西阿书 2:11; 以西结书 26:13"> 我要使犹大各城和耶路撒冷街上的欢乐声、新郎和新娘的欢笑声全部消失，因为大地必荒凉。”</span>
</div>
</div>

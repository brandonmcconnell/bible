## 犹大毁约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 11:6; 出埃及记 19:5; 历代志下 29:10"> “你要听这约上的话，把内容告诉犹大人和耶路撒冷的居民。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 27:26; 申命记 28:15–68; 申命记 29:19–20"> 你要告诉他们，以色列的上帝耶和华说，‘不遵守这约的人必受咒诅。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:12; 耶利米书 7:22–23; 申命记 4:20"> 我把你们的祖先从苦难的铁熔炉埃及带出来，那时我吩咐他们遵守这约。他们若听从我的话，遵行我的吩咐，就必做我的子民，我也必做他们的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:12–13; 诗篇 105:9–11; 耶利米书 28:6"> 这样，我就实现我向你们祖先起的誓，赐给他们那奶蜜之乡，正如今日一样。’”我回答说：“耶和华啊，遵命！”</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:22; 罗马书 2:13; 耶利米书 7:2"> 耶和华对我说：“你要在犹大各城和耶路撒冷的街头宣告，呼吁百姓听从、遵行这约。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 36:15; 以弗所书 4:17; 撒母耳记上 8:9"> 因为自从我带你们祖先出埃及那天一直到今日，我一再劝诫他们要听从我的话。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 7:24; 耶利米书 7:26; 耶利米书 35:15"> 然而，他们却不听不理，人人凭自己顽固的恶念行事。因此，我要使约中的一切咒诅临到他们，因为我吩咐他们遵守这约，他们却不遵守。”</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 6:9; 马太福音 26:3–4; 弥迦书 3:11"> 耶和华对我说：“犹大人和耶路撒冷的居民阴谋背叛我。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 31:16; 以西结书 16:59; 诗篇 78:8–10"> 他们重蹈祖先的覆辙，不听从我的话，跟从、祭拜其他神明。以色列和犹大都违背了我与他们祖先立的约。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:18; 箴言 1:28; 以赛亚书 1:15"> 所以我要使他们灾难临头，无法逃脱，任他们高声呼求，我也不听。这是耶和华说的。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:28; 申命记 32:37; 历代志下 28:22"> 那时，犹大各城和耶路撒冷的居民必去呼求他们烧香供奉的神明，但灾难来临时，那些神明根本救不了他们。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:28; 列王纪下 23:13; 以赛亚书 2:8"> 犹大啊，你的神明多如你的城邑，你给可憎的巴力烧香的祭坛多如耶路撒冷的街道。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 7:16; 耶利米书 11:11; 约翰一书 5:16"> “因此，耶利米啊，你不要为这些人祈祷，不要为他们呼求祷告，因为他们遭难时向我呼求，我必不理会他们。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多书 1:15; 耶利米书 3:1–2"> 我所爱的子民既然罪恶滔天，还在我殿里做什么？难道祭肉可以为他们消灾免祸吗？他们以作恶为乐。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:17–24; 以赛亚书 27:11; 诗篇 52:8"> 耶和华曾称他们为枝繁叶茂、果实佳美的橄榄树，但现在祂要在呼啸的风暴中把它点燃，烧毁它的枝条。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 5:2; 耶利米书 2:21; 耶利米书 12:2"> 我万军之耶和华曾栽培以色列人和犹大人，如今我要降祸给他们，因为他们作恶，向巴力献祭，惹我发怒。”</span>
</div>
</div>

## 谋害耶利米

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 23:11–12; 列王纪下 6:9–10; 以西结书 8:6–18"> 有人想谋害我，耶和华告诉了我，我才知道，那时祂让我看见他们的所作所为。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 53:7–8; 耶利米书 20:10; 诗篇 83:4"> 我好像一只被牵去宰杀的驯良羊羔，不知他们要谋害我。他们说：<br /><span className="pl pl-1">“我们把这棵树连果子一同毁灭，</span><br /><span className="pl pl-1">我们从世上除掉它，</span><br /><span className="pl pl-1">使它的名字被遗忘吧！”</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 20:12; 耶利米书 17:10; 撒母耳记上 16:7"> <span className="pl pl-1">然而，审判公正、洞察肺腑心肠的万军之耶和华啊，</span><br /><span className="pl pl-1">愿我能看见你报应他们，</span><br /><span className="pl pl-1">因为我已向你陈明我的冤屈。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 20:10; 阿摩司书 2:12; 路加福音 13:33–34"> 亚拿突人想杀我，他们威胁我说：“你不要奉耶和华的名说预言，免得死在我们手上。”因此，万军之耶和华说：“看啊，我必惩罚他们。他们的青年必丧身刀下，他们的子女必死于饥荒，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:12; 弥迦书 7:4; 何西阿书 9:7"> 一个不留。因为在亚拿突人受罚之年，我必降灾难给他们。”</span>
</div>

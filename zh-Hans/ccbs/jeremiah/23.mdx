## 将来的盼望

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 10:21; 撒迦利亚书 11:15–17; 以西结书 34:2–10"> 耶和华说：“牧养我子民的首领有祸了！因为他们残害、驱散我草场上的羊群。”</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 32:34; 耶利米书 21:12; 弥迦书 7:4"> 以色列的上帝耶和华这样斥责那些牧养祂子民的首领：“你们驱散我的羊群，没有照顾他们。看啊，我必因你们的恶行而惩罚你们。这是耶和华说的。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 9:14–15; 耶利米书 32:37; 以赛亚书 43:5–6"> 我要把我幸存的子民从我流放他们去的各地召集起来，领他们回到故土，使他们生养众多，人丁兴旺。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 3:14–15; 彼得前书 1:5; 以西结书 34:23–31"> 我要设立首领照顾他们，使他们不再担惊受怕，也不再迷失。这是耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 1:32–33; 以赛亚书 4:2; 以赛亚书 9:7"> 耶和华说：“看啊，时候将到，我要为大卫兴起一个公义的苗裔，使他执掌王权。他必秉公行义，治国有方。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 1:30; 耶利米书 33:16; 腓立比书 3:9"> 在他掌权的日子，犹大必得拯救，以色列必安享太平并被称为‘耶和华是我们的公义’。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 16:14–15; 耶利米书 23:3; 以赛亚书 43:18–19"> 耶和华说：“看啊，时候将到，那时人不再凭把以色列人带出埃及的耶和华起誓，</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 43:5–6; 阿摩司书 9:14–15; 以西结书 34:13"> 而是凭把他们从北方之地和流放的列国领回来的永活耶和华起誓。他们必在自己的国土上安居乐业。”</span>
<span className="v" id="v9" data-v="9" data-xref="哈巴谷书 3:16; 耶利米哀歌 3:15; 诗篇 60:3"> <span className="pl pl-1">谈及那些先知，</span><br /><span className="pl pl-1">我的心都碎了，</span><br /><span className="pl pl-1">我的骨头都颤抖。</span><br /><span className="pl pl-1">因为耶和华和祂圣言的缘故，</span><br /><span className="pl pl-1">我好像不胜酒力的醉汉。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 4:2–3; 诗篇 107:34; 耶利米书 9:2"> <span className="pl pl-1">这里到处是不忠贞的人，</span><br /><span className="pl pl-1">他们行为邪恶，滥用权力。</span><br /><span className="pl pl-1">大地因受咒诅而悲哀，</span><br /><span className="pl pl-1">旷野的草场都枯干了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="西番雅书 3:4; 耶利米书 6:13; 马太福音 21:12–13"> <span className="pl pl-1">耶和华说：“先知和祭司都不敬虔，</span><br /><span className="pl pl-1">我甚至看见他们在我的圣殿里行恶。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 13:16; 耶利米书 11:23; 诗篇 35:6"> <span className="pl pl-1">因此，他们必被赶到黑暗中，</span><br /><span className="pl pl-1">在湿滑的路上跌倒，</span><br /><span className="pl pl-1">因为我必在他们受罚的日子降灾祸给他们。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:8; 以赛亚书 9:16; 列王纪上 18:18–21"> <span className="pl pl-1">我看见撒玛利亚的先知行可憎之事，</span><br /><span className="pl pl-1">他们靠巴力说预言，</span><br /><span className="pl pl-1">引诱我的子民以色列走入歧途。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 1:9–10; 耶利米书 29:23; 以西结书 22:25"> <span className="pl pl-1">我也看见耶路撒冷的先知行为可恶，</span><br /><span className="pl pl-1">他们通奸，谎话连篇，</span><br /><span className="pl pl-1">怂恿恶人，</span><br /><span className="pl pl-1">以致无人悔过自新。</span><br /><span className="pl pl-1">在我眼中，他们就像所多玛人，耶路撒冷人像蛾摩拉人一样败坏。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 8:14; 耶利米书 9:15; 耶利米哀歌 3:5"> <span className="pl pl-1">因此，关于这些先知，万军之耶和华说，</span><br /><span className="pl pl-1">‘看啊，我要使他们吃苦艾，</span><br /><span className="pl pl-1">喝毒水，因为亵渎之风从耶路撒冷的先知那里蔓延，</span><br /><span className="pl pl-1">遍及全境。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 14:14; 以西结书 13:6; 加拉太书 1:8–9"> 万军之耶和华对耶路撒冷人说：“你们不要听信这些先知的预言，他们使你们充满虚假的盼望，他们的预言是自己的想象，不是耶和华说的。</span>
<span className="v" id="v17" data-v="17" data-xref="弥迦书 3:11; 耶利米书 13:10; 阿摩司书 9:10"> 他们不断对藐视我的人说，‘耶和华说你们必安享太平。’他们对那些执迷不悟的人说，‘灾祸不会降到你们身上。’</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 23:22; 以赛亚书 40:13–14; 阿摩司书 3:7"> <span className="pl pl-1">“然而，他们谁曾站在耶和华面前看见并听见祂说话呢？</span><br /><span className="pl pl-1">他们谁曾留心听祂的话呢？</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 30:23; 耶利米书 25:32; 阿摩司书 1:14"> <span className="pl pl-1">看啊，耶和华的烈怒像暴风一样袭来，</span><br /><span className="pl pl-1">像旋风一样吹到恶人头上。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 30:24; 以赛亚书 55:11; 撒迦利亚书 1:6"> <span className="pl pl-1">耶和华不完成祂心中的计划决不息怒。</span><br /><span className="pl pl-1">将来你们会清楚地明白这一切。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 14:14; 耶利米书 27:15; 耶利米书 23:32"> <span className="pl pl-1">“我没有差遣这些先知，</span><br /><span className="pl pl-1">他们却妄自行动；</span><br /><span className="pl pl-1">我没有对他们说话，</span><br /><span className="pl pl-1">他们却乱发预言。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:18; 撒迦利亚书 1:4; 耶利米书 25:5"> <span className="pl pl-1">他们若曾站在我面前听我说话，</span><br /><span className="pl pl-1">早就向我的子民宣告我的话，</span><br /><span className="pl pl-1">使他们改邪归正了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 139:1–10; 列王纪上 20:23; 列王纪上 20:28"> 耶和华说：“我难道不是远近无处不在的上帝？”</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:3; 诗篇 139:7; 诗篇 90:8"> 耶和华说：“难道人藏在隐秘处我就看不见了吗？我岂不是充满天地吗？这是耶和华说的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 23:32; 耶利米书 23:28; 耶利米书 29:8"> 我已听见这些先知奉我的名所说的假预言，他们说，‘我做了个梦！我做了个梦！’</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 4:1–2; 耶利米书 14:14; 帖撒罗尼迦后书 2:9–11"> 这些先知谎话连篇，凭空预言要到何时呢？</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 8:33–34; 士师记 3:7; 使徒行传 13:8"> 他们彼此传讲所做的梦，想借此使我的子民忘记我的名，正如他们的祖先因祭拜巴力而忘记了我的名。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多后书 2:17; 提摩太前书 1:12; 哥林多前书 3:12–13"> 让做梦的先知尽管宣扬他们的梦吧，但得到我话语的先知要忠心地传达我的话。糠秕怎能与麦子相比呢！这是耶和华说的。”</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 4:12; 耶利米书 5:14; 路加福音 24:32"> 耶和华说：“难道我的话不像火吗？不像击碎岩石的铁锤吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 18:20; 以西结书 13:8; 耶利米书 14:14–15"> 耶和华说：“看啊，我要对付那些假先知，他们盗用彼此的话，却妄称是我的话。”</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 23:17; 历代志下 18:10–12; 历代志下 18:5"> 耶和华说：“看啊，我要对付那些假先知，他们妄自说预言，却谎称是耶和华的话。”</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 13:7–18; 西番雅书 3:4; 耶利米哀歌 2:14"> 耶和华说：“看啊，我要对付那些假先知，他们凭虚谎之梦说预言，并四处传扬，用弥天大谎把我的子民引入歧途。其实我并没有差遣他们，也没有委派他们，他们对我的子民毫无益处。这是耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="玛拉基书 1:1; 耶利米书 12:7; 哈巴谷书 1:1"> 耶和华说：“耶利米啊，如果有百姓、先知或祭司问你，‘耶和华有什么启示？’你要对他们说，‘你们就是耶和华的重担<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“重担”希伯来文也有“启示”的意思。">a</a></sup>，耶和华说要丢弃你们。’</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 13:3; 耶利米哀歌 2:14"> 如果有先知、祭司或百姓宣称有耶和华的启示，我必惩罚他和他全家。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 31:34; 耶利米书 42:4; 耶利米书 33:3"> 你们各人要问自己的亲友，‘耶和华有什么答复？’或‘耶和华说了什么？’</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 10:10; 彼得后书 3:16; 以赛亚书 3:8"> 你们不可再说有耶和华的启示，因为你们把自己的话当成祂的启示，曲解我们永活的上帝——万军之耶和华的话。</span>
<span className="v" id="v37" data-v="37"> 耶利米啊，你要这样问先知，‘耶和华有什么答复？耶和华说了什么？’</span>
<span className="v" id="v38" data-v="38" data-xref="历代志下 11:13–14"> 如果他们说，‘这是耶和华的启示。’你就说，‘耶和华说，我警告你们不可宣称有耶和华的启示，你们却偏偏宣称有我的启示，</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米书 23:33; 以西结书 8:18; 箴言 13:13"> 我必彻底忘记你们，把你们和我赐给你们及你们祖先的城邑抛弃。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米书 20:11; 以西结书 5:14–15; 耶利米书 42:18"> 我要使你们永远蒙羞受辱，难以忘怀。’”</span>
</div>

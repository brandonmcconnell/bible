## 关于埃及的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:10; 撒迦利亚书 2:8; 耶利米书 4:7"> 耶和华把有关列国的事告诉了耶利米先知。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 23:29; 耶利米书 46:14; 耶利米书 25:19"> 约西亚的儿子犹大王约雅敬执政第四年，埃及王法老尼哥的军队在幼发拉底河边的迦基米施被巴比伦王尼布甲尼撒击败。关于埃及，耶和华说：</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 21:5; 约珥书 3:9; 那鸿书 2:1"> <span className="pl pl-1">“要预备大小盾牌，</span><br /><span className="pl pl-1">冲向战场。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 21:9–11; 耶利米书 51:3; 撒母耳记上 17:5"> <span className="pl pl-1">要套好战车，</span><br /><span className="pl pl-1">骑上战马，</span><br /><span className="pl pl-1">擦亮矛枪，</span><br /><span className="pl pl-1">顶盔贯甲，</span><br /><span className="pl pl-1">准备作战。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 49:29; 耶利米书 6:25; 耶利米书 46:21"> <span className="pl pl-1">可是，我看见什么？</span><br /><span className="pl pl-1">他们惊慌后退，</span><br /><span className="pl pl-1">勇士败逃，不敢回头，</span><br /><span className="pl pl-1">惊恐不安。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 11:19; 耶利米书 46:12; 诗篇 27:2"> <span className="pl pl-1">善跑者跑不掉，</span><br /><span className="pl pl-1">强壮者逃不了，</span><br /><span className="pl pl-1">他们仆倒在北面的幼发拉底河边。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 47:2; 以赛亚书 8:7–8; 但以理书 11:22"> <span className="pl pl-1">“那如尼罗河涨溢，</span><br /><span className="pl pl-1">如江水奔腾的是谁呢？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 10:13–16; 以西结书 32:2; 以赛亚书 37:24–26"> <span className="pl pl-1">埃及如尼罗河涨溢，</span><br /><span className="pl pl-1">如江水奔腾。</span><br /><span className="pl pl-1">她说，‘我要涨溢，淹没大地，</span><br /><span className="pl pl-1">毁灭城邑和其中的居民。’</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 66:19; 以西结书 27:10; 那鸿书 3:9"> <span className="pl pl-1">战马奔腾吧！</span><br /><span className="pl pl-1">战车疾驶吧！</span><br /><span className="pl pl-1">勇士啊，就是那些手拿盾牌的古实人和弗人以及箭法娴熟的吕底亚人啊，出战吧！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:42; 约珥书 1:15; 耶利米书 46:2"> <span className="pl pl-1">因为这是主——万军之耶和华向敌人报仇的日子。</span><br /><span className="pl pl-1">刀剑必吞噬他们，</span><br /><span className="pl pl-1">痛饮他们的血，</span><br /><span className="pl pl-1">因为要在北方的幼发拉底河边向主——万军之耶和华献祭。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:22; 弥迦书 1:9; 那鸿书 3:19"> <span className="pl pl-1">处女埃及啊，</span><br /><span className="pl pl-1">去基列取乳香吧！</span><br /><span className="pl pl-1">然而，再多的良药也是徒然，</span><br /><span className="pl pl-1">你们无法得医治。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="那鸿书 3:8–10; 以赛亚书 19:2; 耶利米书 46:6"> <span className="pl pl-1">你们的耻辱传遍列国，</span><br /><span className="pl pl-1">你们的哀哭响彻大地，</span><br /><span className="pl pl-1">你们的勇士彼此碰撞，</span><br /><span className="pl pl-1">倒在一起。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 44:30; 耶利米书 43:10–13; 以赛亚书 19:1–25"> 关于巴比伦王尼布甲尼撒要来攻打埃及的事，耶和华对耶利米先知说：</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 46:10; 耶利米书 44:1; 耶利米书 46:3–4"> <span className="pl pl-1">“你们要在埃及宣布，在密夺、挪弗和答比匿宣告，</span><br /><span className="pl pl-1">‘要摆好阵势，准备作战，</span><br /><span className="pl pl-1">因为刀剑要吞噬你们周围的人。’</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 66:15–16; 诗篇 68:2; 诗篇 18:39"> <span className="pl pl-1">你们的勇士为何仆倒？</span><br /><span className="pl pl-1">他们无法站立，</span><br /><span className="pl pl-1">因为耶和华击倒了他们，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="利未记 26:36–37; 耶利米书 51:9; 耶利米书 46:6"> <span className="pl pl-1">使他们跌跌绊绊，纷纷倒下。</span><br /><span className="pl pl-1">他们说，‘起来，我们回到同胞那里，回到故乡吧，</span><br /><span className="pl pl-1">好躲避敌人的刀剑。’</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 19:11–16; 出埃及记 15:9; 列王纪上 20:10"> <span className="pl pl-1">他们在那里喊叫，</span><br /><span className="pl pl-1">‘埃及王法老只会虚张声势，</span><br /><span className="pl pl-1">他已错失良机。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 48:15; 士师记 4:6; 约书亚记 19:22"> <span className="pl pl-1">名叫万军之耶和华的王说：</span><br /><span className="pl pl-1">“我凭我的永恒起誓，</span><br /><span className="pl pl-1">将有一位要来，</span><br /><span className="pl pl-1">他的气势如群山中的他泊山，</span><br /><span className="pl pl-1">又像海边的迦密山。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 20:4; 耶利米书 48:18; 以西结书 30:13"> <span className="pl pl-1">住在埃及的人啊，</span><br /><span className="pl pl-1">收拾行装准备流亡吧！</span><br /><span className="pl pl-1">因为挪弗必荒废，</span><br /><span className="pl pl-1">沦为废墟，杳无人迹。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="何西阿书 10:11; 耶利米书 47:2; 耶利米书 1:14"> <span className="pl pl-1">“埃及像头肥美的母牛犊，</span><br /><span className="pl pl-1">但从北方却来了牛虻。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 46:5; 俄巴底亚书 1:13; 列王纪下 7:6"> <span className="pl pl-1">埃及的佣兵好像肥牛犊，</span><br /><span className="pl pl-1">都转身逃之夭夭，无力抵挡，</span><br /><span className="pl pl-1">因为他们遭难、受罚的日子到了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 14:8; 以赛亚书 29:4; 弥迦书 1:8"> <span className="pl pl-1">“敌军列队进攻的时候，</span><br /><span className="pl pl-1">埃及必像蛇一样嘶嘶地溜走。</span><br /><span className="pl pl-1">敌军必拿着斧头蜂拥而来，</span><br /><span className="pl pl-1">像樵夫砍树一样攻击他们。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="士师记 7:12; 士师记 6:5; 约珥书 2:25"> <span className="pl pl-1">埃及的人口虽然稠密如林，</span><br /><span className="pl pl-1">敌军必像无数的蝗虫一样扫平他们。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 1:15; 以西结书 29:1–21; 耶利米书 46:11"> <span className="pl pl-1">埃及人必蒙羞，</span><br /><span className="pl pl-1">落在北方人的手中。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="西番雅书 2:11; 耶利米书 43:12–13; 以赛亚书 20:5–6"> 以色列的上帝——万军之耶和华说：“看啊，我要惩罚底比斯的神明亚扪、埃及的其他神明、法老、首领以及依靠法老的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 32:11; 耶利米书 44:30; 以西结书 29:8–14"> 我要把他们交在想杀他们的巴比伦王尼布甲尼撒及其官长手中。然而，日后埃及必再有人居住，如往日一样。这是耶和华说的。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 43:5; 耶利米书 30:10–11; 以赛亚书 43:1"> <span className="pl pl-1">“我的仆人雅各啊，不要害怕！</span><br /><span className="pl pl-1">以色列啊，不要惊慌！</span><br /><span className="pl pl-1">因为我要从远方拯救你，</span><br /><span className="pl pl-1">从流亡之地拯救你的后裔。</span><br /><span className="pl pl-1">雅各必重返家园，安享太平，</span><br /><span className="pl pl-1">不受惊吓。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 11:32; 启示录 3:19; 耶利米书 10:24"> <span className="pl pl-1">我的仆人雅各啊，不要害怕，</span><br /><span className="pl pl-1">因为我与你同在。</span><br /><span className="pl pl-1">我曾使你流亡到列国，</span><br /><span className="pl pl-1">我必彻底毁灭列国，</span><br /><span className="pl pl-1">但不会彻底毁灭你，</span><br /><span className="pl pl-1">也不会放过你，</span><br /><span className="pl pl-1">我必公正地惩治你。</span><br /><span className="pl pl-1">这是耶和华说的。”</span></span>
</div>

## 以色列人必回归

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 30:22; 耶利米书 30:24; 撒迦利亚书 13:9"> 耶和华说：“那时，我要做以色列各宗族的上帝，他们必做我的子民。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 10:33; 诗篇 95:11; 马太福音 11:28"> <span className="pl pl-1">“逃脱刀兵之灾的以色列人必在旷野蒙恩，</span><br /><span className="pl pl-1">找到安息之所。</span><br /><span className="pl pl-1">这是耶和华说的。”</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 103:17; 以赛亚书 54:8–9; 何西阿书 11:4"> <span className="pl pl-1">从前，耶和华向以色列</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以色列”参照《七十士译本》，希伯来文作“我”。">a</a></sup><br /><span className="pl pl-1">显现，说：</span><br /><span className="pl pl-1">“我以永远的爱爱你，</span><br /><span className="pl pl-1">我以不变的慈爱吸引你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 33:7; 耶利米书 31:13; 阿摩司书 5:2"> <span className="pl pl-1">少女以色列啊，</span><br /><span className="pl pl-1">我要重建你，你必得到重建，</span><br /><span className="pl pl-1">你要再次拿起铃鼓与欢乐的人一同跳舞。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="诗篇 14:7; 诗篇 28:9; 以赛亚书 37:31"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“你们要为雅各欢呼歌唱，</span><br /><span className="pl pl-1">向列国之首喝采。</span><br /><span className="pl pl-1">你们要传扬颂赞，说，</span><br /><span className="pl pl-1">‘耶和华啊，</span><br /><span className="pl pl-1">求你拯救你以色列剩余的子民！’</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 34:16; 以赛亚书 42:16; 耶利米书 23:8"> <span className="pl pl-1">看啊，我要从北方把他们带回来，</span><br /><span className="pl pl-1">从地极招聚他们，</span><br /><span className="pl pl-1">其中有瞎眼的、瘸腿的、孕妇和产妇，</span><br /><span className="pl pl-1">他们要成群结队地回到这里。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 5:4; 耶利米书 3:4; 出埃及记 4:22"> <span className="pl pl-1">我必引领他们回来，</span><br /><span className="pl pl-1">他们必一路含泪祷告。</span><br /><span className="pl pl-1">我要使他们走在溪水边，</span><br /><span className="pl pl-1">行在平坦的路上，</span><br /><span className="pl pl-1">他们必不会跌倒，</span><br /><span className="pl pl-1">因为我是以色列的父亲，</span><br /><span className="pl pl-1">以法莲是我的长子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 40:11; 以西结书 34:12; 申命记 30:4"> <span className="pl pl-1">“列国啊，你们要听耶和华的话，</span><br /><span className="pl pl-1">要在远方的海岛宣告，</span><br /><span className="pl pl-1">‘驱散以色列的那位必聚集他们，</span><br /><span className="pl pl-1">像牧人守护羊群一样守护他们。’</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 48:20; 提多书 2:14; 以赛亚书 44:23"> <span className="pl pl-1">因为耶和华必拯救雅各，</span><br /><span className="pl pl-1">必从强敌手中救赎他们。</span><br /></span>

<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:25; 彼得前书 2:9; 耶利米书 33:9"> <span className="pl pl-1">我要使祭司有充足的供应，</span><br /><span className="pl pl-1">使我的子民饱享美物。</span><br /><span className="pl pl-1">这是耶和华说的。”</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 2:16–18; 耶利米书 40:1; 诗篇 77:2"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“在拉玛有痛哭哀号的声音，</span><br /><span className="pl pl-1">是拉结在为儿女哀恸，</span><br /><span className="pl pl-1">不肯接受安慰，</span><br /><span className="pl pl-1">因为他们都死了。”</span></span>

<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:21; 耶利米书 29:11–16; 耶利米哀歌 3:18"> <span className="pl pl-1">你将来必有盼望，</span><br /><span className="pl pl-1">你的儿女必重返家园。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>

<span className="v" id="v20" data-v="20" data-xref="以赛亚书 55:7; 弥迦书 7:18–19; 以赛亚书 63:15"> <span className="pl pl-1">耶和华说：“以法莲不是我的爱子吗？</span><br /><span className="pl pl-1">他不是我喜悦的孩子吗？</span><br /><span className="pl pl-1">我虽然常常责备他，</span><br /><span className="pl pl-1">但仍然惦记着他。</span><br /><span className="pl pl-1">我深深地想念他，</span><br /><span className="pl pl-1">我必怜悯他。</span></span>

<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 50:5; 以赛亚书 62:10; 诗篇 84:5"> <span className="pl pl-1">“以色列人啊，</span><br /><span className="pl pl-1">你们要为自己设置路标，</span><br /><span className="pl pl-1">竖起路牌，</span><br /><span className="pl pl-1">牢记你们走过的大道。</span><br /><span className="pl pl-1">以色列人啊，</span><br /><span className="pl pl-1">回来吧！回到你们的城邑吧！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 49:4; 耶利米书 7:24; 马太福音 1:21"> <span className="pl pl-1">背信的子民啊！</span><br /><span className="pl pl-1">你们四处流浪要到何时呢？</span><br /><span className="pl pl-1">耶和华在地上开辟了一件新事——女子将要护卫男子。”</span></span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 8:3; 以赛亚书 1:26; 耶利米书 50:7"> 以色列的上帝——万军之耶和华说：“我使被掳的犹大人回到故乡后，他们要在犹大各城邑再次呼喊，<br /><span className="pl pl-1">“‘公义的居所啊，</span><br /><span className="pl pl-1">圣山啊，愿耶和华赐福给你！’</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 8:4–8; 以西结书 36:10; 撒迦利亚书 2:4"> “农夫和牧人必住在犹大的各城邑。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 5:6; 马太福音 11:28; 约翰福音 4:14"> 我要使疲乏的人振作起来，使愁苦的人快乐起来。”</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 127:2; 撒迦利亚书 4:1–2"> 这时，我醒过来，觉得这一觉实在香甜。</span>
<span className="v" id="v27" data-v="27" data-xref="何西阿书 2:23; 撒迦利亚书 10:9; 以西结书 36:9"> 耶和华说：“看啊，时候将到，我要使以色列和犹大人丁兴旺，牲畜繁多。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 24:6; 耶利米书 1:10; 耶利米书 18:7–9"> 我曾决意铲除、拆毁、推翻、剿灭他们，降灾给他们，将来我必塑造、栽培他们。这是耶和华说的。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 5:7; 以西结书 18:2–3; 耶利米书 31:30"> 那时，人再不会说，<br /><span className="pl pl-1">“‘父亲吃酸葡萄，</span><br /><span className="pl pl-1">儿子的牙酸倒了。’</span></span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 18:20; 以赛亚书 3:11; 申命记 24:16"> 因为各人都要因自己的罪而死，谁吃酸葡萄，谁的牙酸倒。”</span>
<span className="v" id="v31" data-v="31" data-xref="希伯来书 10:16–17; 以西结书 37:26; 耶利米书 31:31–34"> 耶和华说：“看啊，时候将到，我要与以色列家和犹大家另立新约，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 24:6–8; 申命记 5:3; 出埃及记 19:5"> 这约不同于我与他们祖先所立的约，那是我牵着他们祖先的手领他们离开埃及时立的。虽然我是他们的丈夫，他们却违背了我的约。这是耶和华说的。”</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 3:3; 希伯来书 10:16; 希伯来书 8:10"> 耶和华说：“那些日子以后，我将与以色列家立这样的约，我要把我的律法放在他们脑中，写在他们心上。我要做他们的上帝，他们要做我的子民。</span>

<span className="v" id="v35" data-v="35" data-xref="耶利米书 10:16; 以赛亚书 51:15; 诗篇 136:7–9"> <span className="pl pl-1">指定太阳白天照耀、</span><br /><span className="pl pl-1">命令星月晚上发光、</span><br /><span className="pl pl-1">搅动大海，使之波涛汹涌的万军之耶和华说：</span><br /></span>

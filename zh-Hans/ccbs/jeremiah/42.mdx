## 耶利米警告犹大人勿去埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:11; 耶利米书 40:13; 耶利米书 6:13"> 加利亚的儿子约哈难、何沙雅的儿子耶撒尼亚和其他将领及民众，无论尊卑，都近前来，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 36:7; 利未记 26:22; 使徒行传 8:24"> 对耶利米先知说：“求你答应我们的恳求，为我们这些余民向你的上帝耶和华祷告。你亲眼看见了，我们本来人数众多，现在却寥寥无几。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 86:11; 箴言 3:6; 诗篇 25:4–5"> 愿你的上帝耶和华指示我们该去哪里，该做什么。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 12:23; 撒母耳记上 3:17–18; 出埃及记 8:29"> 耶利米先知说：“好。我必照你们说的向你们的上帝耶和华祷告，并把祂的话毫不隐瞒地告诉你们。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:50; 士师记 11:10; 玛拉基书 3:5"> 他们说：“倘若我们不照你的上帝耶和华派你传给我们的一切话去做，愿耶和华作信实可靠的证人指控我们！</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:23; 申命记 5:29; 罗马书 8:7"> 我们派你去我们的上帝耶和华那里，祂的话不论中听不中听，我们都愿意听从。我们若听从祂的话，就必亨通。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:14; 以赛亚书 28:16; 哈巴谷书 2:3"> 十天之后，耶和华的话传给了耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:1; 耶利米书 41:11–16; 耶利米书 43:2–5"> 耶利米便召集加利亚的儿子约哈难和众将领及民众，无论尊卑，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 19:4; 耶利米书 42:2; 列王纪下 19:6"> 对他们说：“你们让我替你们向以色列的上帝耶和华祈求，耶和华这样说，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:28; 以西结书 36:36; 耶利米书 24:6"> ‘如果你们留在这地方，我必造就你们，决不毁灭你们；我必栽培你们，决不铲除你们。因为我为降在你们身上的灾祸而难过。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:31; 耶利米书 1:19; 耶利米书 1:8"> 不要惧怕巴比伦王，不要怕他，因为我必与你们同在，拯救你们脱离他的权势。这是耶和华说的。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 1:11; 诗篇 106:45–46; 箴言 16:7"> 我必怜悯你们，让他也怜悯你们，使你们重归故土。’</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 44:16; 出埃及记 5:2; 耶利米书 42:10"> 然而，如果你们不听你们的上帝耶和华的话，不留在这地方，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 41:17; 耶利米书 4:19; 以赛亚书 31:1"> 非要去埃及住，以为那里没有战争，听不见号角声，也不会忍饥挨饿，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 17:16; 耶利米书 44:12–14; 耶利米书 42:17"> 那么，你们这些犹大的余民就要听耶和华的话。以色列的上帝——万军之耶和华说，‘如果你们决意去埃及住，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 44:27; 以西结书 11:8; 阿摩司书 9:1–4"> 你们所害怕的刀剑必追上你们，你们所惧怕的饥荒必紧紧地跟着你们到埃及。你们必死在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 42:22; 耶利米书 44:28; 耶利米书 44:13–14"> 凡决意去埃及住的人必要死于刀剑、饥荒和瘟疫，无人能逃脱我降的灾祸，幸存下来。’</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 7:20; 耶利米书 18:16; 耶利米书 29:18"> “以色列的上帝——万军之耶和华说，‘我曾把我的怒气和烈怒倾倒在耶路撒冷人身上，如果你们去埃及，我也要把我的怒气倾倒在你们身上。你们的下场将很可怕，被人责骂、咒诅和羞辱，再也见不到故土。’</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 17:16; 以赛亚书 30:1–7; 尼希米记 9:26"> 犹大的余民啊，耶和华已告诉你们不要去埃及。别忘了我今日给你们的警告，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:3–4; 以西结书 33:31; 马太福音 22:15–18"> 你们是在自欺，因为原是你们请我去向你们的上帝耶和华祷告，让我毫不隐瞒地把祂的话告诉你们，你们答应遵行。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 2:7; 撒迦利亚书 7:11–12; 使徒行传 20:26–27"> 今日，我把你们的上帝耶和华要我传的话告诉你们，你们却不听从。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 42:17; 以西结书 6:11; 何西阿书 9:6"> 因此，你们要清楚知道，在你们想去居住的地方，你们必死于刀剑、饥荒和瘟疫。”</span>
</div>
</div>

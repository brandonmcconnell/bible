## 西底迦求耶利米代祷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 22:24; 列王纪下 24:17; 列王纪下 24:12"> 巴比伦王尼布甲尼撒立约西亚的儿子西底迦代替约雅敬的儿子哥尼雅做犹大王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 24:19–20; 箴言 29:12; 历代志下 36:12–16"> 西底迦和他的臣仆及人民却没有听从耶和华借耶利米先知说的话。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:1–2; 耶利米书 29:25; 耶利米书 42:20"> 西底迦王派示利米雅的儿子犹甲和玛西雅的儿子祭司西番雅来对耶利米先知说：“求你为我们向我们的上帝耶和华祷告。”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 37:15; 耶利米书 32:2–3"> 当时，耶利米还可以在百姓中自由来往，因为他还没有被囚在狱中。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 17:15; 耶利米书 37:11; 耶利米书 34:21"> 那时，法老的军队已从埃及出发，正在围攻耶路撒冷的迦勒底人听见消息就退兵了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶和华对耶利米先知说：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米哀歌 4:17; 列王纪下 22:18; 以西结书 17:17"> “以色列的上帝耶和华这样说，‘犹大王派你们来求问我，你们告诉他：前来支援你们的法老军队必返回本国埃及，</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 39:2–8; 耶利米书 38:23; 耶利米书 34:21–22"> 而迦勒底人必卷土重来，攻占这城，将它付之一炬。</span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亚书 1:3; 耶利米书 29:8; 加拉太书 6:3"> 耶和华说，你们不要自欺，以为迦勒底人必撤军。其实他们不会撤军。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 50:45; 以赛亚书 30:17; 约珥书 2:11"> 即使你们能打败迦勒底全军，他们营中受伤的残兵也必起来烧毁这城。’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 37:5"> 当迦勒底人因害怕法老的军队而从耶路撒冷撤军的时候，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:1; 尼希米记 6:11; 列王纪上 19:3"> 耶利米起身离开耶路撒冷，前往便雅悯境内去接收他在同族中应得的地业。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亚书 14:10; 耶利米书 38:7; 路加福音 23:2"> 当耶利米先知来到便雅悯门时，哈拿尼亚的孙子、示利米雅的儿子守门官伊利雅逮捕了他，说：“你想去投奔迦勒底人！”</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 52:1–2; 耶利米书 40:4–6; 诗篇 27:12"> 耶利米说：“胡说，我不是去投奔迦勒底人。”但伊利雅不信，就把他抓起来押到众官长那里。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 38:26; 耶利米书 20:1–3; 耶利米书 26:16"> 官长们大怒，命人打耶利米，把他囚禁在书记约拿单的房子里，因为他们已把这房子改作监牢。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 38:6; 耶利米书 38:10–13; 耶利米哀歌 3:53"> 耶利米被囚禁在地牢中许多天。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 21:7; 耶利米书 24:8; 列王纪上 14:1–4"> 后来，西底迦王派人把他带到自己的宫中，私下问他：“耶和华有什么话给你吗？”耶利米说：“有，你要被交在巴比伦王手中。”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 25:8; 约翰福音 10:32; 但以理书 6:22"> 耶利米又问他：“我在什么事上得罪了你、你的臣仆或人民，以致你们把我囚在监牢中？</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 2:28; 耶利米书 28:10–17; 耶利米书 6:14"> 那些曾向你们预言‘巴比伦王绝不会来这里攻打你们’的先知如今在哪里呢？</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 36:7; 耶利米书 38:6–9; 使徒行传 28:18–19"> 现在，我主我王啊，请恩准我的恳求！求你不要把我送回书记约拿单的房子，免得我死在那里。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 38:13; 耶利米书 38:28; 耶利米书 38:9"> 于是，西底迦王下令把耶利米囚在护卫的院子里，派人每天从饼铺取一个饼给他，直到城中绝粮。耶利米就这样住在护卫的院子里。</span>
</div>
</div>

## 瓦瓶的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:11–12; 以赛亚书 30:14; 耶利米哀歌 4:2"> 耶和华对我说：“你去向陶匠买一个瓦瓶，带着百姓和祭司中的一些首领到哈珥西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="-2 “哈珥西”意思是“碎陶片”。">a</a></sup>城门旁的欣嫩子谷，在那里宣告我的话。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 3:11; 耶利米书 17:20; 以赛亚书 28:19"> 你要说，‘犹大王和耶路撒冷的居民啊，你们要听耶和华的话！以色列的上帝——万军之耶和华说，看啊，我要在这里降下灾祸，听见这消息的人都必耳鸣。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 2:34; 申命记 28:20; 列王纪下 21:16"> 因为他们背弃了我，污渎了这地方。他们向自己、自己的祖先及犹大君王都不认识的神明烧香，使这地方流满了无辜人的血。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:35; 申命记 12:31; 利未记 18:21"> 他们为巴力建丘坛，烧死自己的儿子作燔祭献给巴力。我从未吩咐他们这样做，连提都没提过，连想都没想过。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 15:8; 以赛亚书 30:33; 耶利米书 19:2"> 因此，看啊，时候将到，这地方不再叫陀斐特或欣嫩子谷，要叫杀戮谷。这是耶和华说的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 26:17; 耶利米书 16:4; 诗篇 33:10–11"> 我要在这地方挫败犹大人和耶路撒冷居民的计谋，使他们丧身在敌人刀下，死在仇敌手中。我要把他们的尸体给飞禽走兽作食物。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 18:16; 耶利米书 49:13; 列王纪上 9:8"> 我必摧毁这城，使它令人惊骇和嗤笑，它的满目疮痍必令所有路人惊骇和嗤笑。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 9:20; 利未记 26:29; 耶利米哀歌 4:10"> 我必使他们在敌人的围困之下陷入绝境，以致吃儿女和亲友的肉。’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 51:63–64; 耶利米书 48:12; 耶利米书 19:1"> “耶利米啊，你要在同去的人面前打碎那瓦瓶，</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 2:9; 以赛亚书 30:14; 耶利米哀歌 4:2"> 然后告诉他们万军之耶和华说，‘我要把这百姓和这城打碎，正如人打碎瓦器，再也不能修复。人们要在陀斐特埋死人，直到无处可埋。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 10:13; 耶利米书 11:5"> 我必这样惩罚这城和其中的居民，使这城像陀斐特一样。这是耶和华说的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:29; 列王纪下 23:12; 西番雅书 1:5"> 耶路撒冷的房屋和犹大君王的宫殿将被玷污，像陀斐特一样，因为他们在房顶向天上的万象烧香，向其他神明奠酒。’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 26:2; 历代志下 20:5; 耶利米书 19:2–3"> 耶利米奉耶和华之命到陀斐特说预言回来后，站在耶和华殿的院子中对众民说：</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 7:26; 耶利米书 17:23; 尼希米记 9:29"> “以色列的上帝——万军之耶和华说，‘看啊，我要把我说过的灾祸降在这城及其周围的村庄，因为他们顽固不化，不肯听我的话。’”</span>
</div>

## 警告犹大的王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 34:2; 路加福音 3:19–20; 撒母耳记下 24:11–12"> 耶和华对我说：“你下到犹大王的宫殿这样宣告，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 1:32; 以赛亚书 9:7; 耶利米书 22:4"> ‘坐在大卫宝座上的犹大王啊，你和你的臣仆以及经过这些城门的百姓都要听耶和华的话。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:12; 弥迦书 6:8; 耶利米书 22:17"> 耶和华说，你们要秉公行义，要从欺压者手中解救受剥削的人。不要欺凌、虐待异乡人和孤儿寡妇，不可在这地方滥杀无辜。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 17:25"> 如果你们谨遵我的命令，坐在大卫宝座上的君王必率领臣民乘车、骑马进出王宫。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司书 6:8; 希伯来书 6:13; 创世记 22:16"> 但如果你们不遵守我的命令，我凭自己起誓，这王宫必沦为废墟。这是耶和华说的。’”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 107:34; 以赛亚书 6:11; 以赛亚书 27:10"> <span className="pl pl-1">关于犹大王的宫殿，耶和华说：</span><br /><span className="pl pl-1">“虽然它在我眼中美如基列，</span><br /><span className="pl pl-1">又像黎巴嫩的山峰，</span><br /><span className="pl pl-1">但我必使它变成不毛之地，</span><br /><span className="pl pl-1">变成荒无人烟的城邑。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 37:24; 以赛亚书 10:33–34; 耶利米书 4:6–7"> <span className="pl pl-1">我要派人拿着兵器来摧毁它，</span><br /><span className="pl pl-1">他们要砍下它最好的香柏木，</span><br /><span className="pl pl-1">扔进火里。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 9:8–9; 历代志下 7:20–22; 申命记 29:23–26"> “各国的人经过这城时都会彼此议论说，‘为什么耶和华这样对待这座大城？’</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 22:17; 历代志下 34:25; 耶利米书 50:7"> 有人会回答，‘因为城里的人背弃了他们的上帝耶和华的约，供奉、祭拜其他神明。’”</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 4:2; 耶利米书 22:11; 以赛亚书 57:1"> <span className="pl pl-1">你们不要为死去的王哀哭，</span><br /><span className="pl pl-1">也不要为他悲伤，</span><br /><span className="pl pl-1">但要为被掳走的王切切哀哭，</span><br /><span className="pl pl-1">因为他必一去不返，</span><br /><span className="pl pl-1">永别故土。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 3:15; 历代志下 36:1–4; 列王纪下 23:34"> 因为关于接替父亲约西亚做犹大王、后来被掳走的沙龙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“沙龙”也叫“约哈斯”。">a</a></sup>，耶和华说：“他必一去不返，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 23:34; 耶利米书 22:18"> 客死流亡之地，永别故土。”</span>
</div>
</div>

## 对约雅敬的审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:4; 弥迦书 3:10; 利未记 19:13"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“犹大王约雅敬啊，你有祸了！</span><br /><span className="pl pl-1">你以不公不义的手段建造宫廷殿宇，</span><br /><span className="pl pl-1">使同胞白白做工，</span><br /><span className="pl pl-1">不给他们工钱。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 7:2; 以赛亚书 5:8–9; 哈该书 1:4"> <span className="pl pl-1">你说要为自己建造宏伟的宫殿、宽敞的楼房。</span><br /><span className="pl pl-1">你安上窗户，</span><br /><span className="pl pl-1">镶上香柏木板，</span><br /><span className="pl pl-1">涂上红漆。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:25; 以赛亚书 3:10; 传道书 10:17"> <span className="pl pl-1">难道你大肆使用香柏木就能显出你做王的气派吗？</span><br /><span className="pl pl-1">你父亲也吃也喝，</span><br /><span className="pl pl-1">但他秉公行义，</span><br /><span className="pl pl-1">所以他凡事顺利；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 9:24; 以赛亚书 1:17; 约翰一书 2:3–4"> <span className="pl pl-1">他为困苦和贫穷的人申冤，</span><br /><span className="pl pl-1">所以他凡事顺利。</span><br /><span className="pl pl-1">这才是真正认识我。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得后书 2:14; 列王纪下 24:4; 耶利米书 22:3"> <span className="pl pl-1">可是，你心里眼里贪图不义之财，</span><br /><span className="pl pl-1">只顾滥杀无辜，横征暴敛。”</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:30; 耶利米书 16:6; 耶利米书 16:4"> <span className="pl pl-1">因此，关于约西亚的儿子犹大王约雅敬，耶和华说：</span><br /><span className="pl pl-1">“没有人会为他哀悼说，</span><br /><span className="pl pl-1">‘唉，我的弟兄啊！</span><br /><span className="pl pl-1">唉，我的姊妹啊！’</span><br /><span className="pl pl-1">没有人会为他哀悼说，</span><br /><span className="pl pl-1">‘唉，主人啊！</span><br /><span className="pl pl-1">唉，他的尊荣！’</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 36:30; 列王纪上 21:23–24; 历代志下 36:6"> <span className="pl pl-1">他必像死驴一样被拖出去扔在耶路撒冷的城门外，暴尸荒野。”</span></span>
</div>
</div>

## 对哥尼雅的审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 37:1; 雅歌 8:6; 历代志上 3:16"> 耶和华说：“约雅敬的儿子犹大王哥尼雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“哥尼雅”即“耶哥尼雅”，又叫“约雅斤”。">b</a></sup>啊，我凭我的永恒起誓，即使你是我右手上盖章的戒指，我也要把你摘下来，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 34:20–21; 耶利米书 21:7; 列王纪下 24:15–16"> 交给那些想杀你的人，交给你所惧怕的巴比伦王尼布甲尼撒和迦勒底军队。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 24:15; 耶利米书 15:2–4; 以赛亚书 22:17"> 我要把你和你的生母赶到异乡，那里不是你们的出生之地，却是你们的葬身之处。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 44:14; 列王纪下 25:27–30; 诗篇 86:4"> 你们渴望回到故乡，却不能如愿以偿。”</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 31:12; 何西阿书 8:8; 耶利米书 48:38"> <span className="pl pl-1">难道哥尼雅这人是被鄙视的破瓶子，是无人要的器皿吗？</span><br /><span className="pl pl-1">为什么他和他的子孙被赶到陌生之地？</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:1; 弥迦书 1:2; 耶利米书 6:19"> <span className="pl pl-1">大地啊，大地啊，大地啊，</span><br /><span className="pl pl-1">要听耶和华的话！</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 36:30; 诗篇 94:20; 马太福音 1:11–16"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“你要把这人作为无儿无女、</span><br /><span className="pl pl-1">一生失败的人记录下来，</span><br /><span className="pl pl-1">因为他的后裔中无一人能成功地继承大卫的宝座，</span><br /><span className="pl pl-1">统治犹大。”</span></span>
</div>

## 给西底迦的警告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:15; 但以理书 2:37–38; 列王纪下 25:1–9"> 巴比伦王尼布甲尼撒率领他的军队和他统治的各邦国攻打耶路撒冷及其周围城邑时，耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 21:10; 耶利米书 34:22; 耶利米书 37:8–10"> “以色列的上帝耶和华这样说，‘你去告诉犹大王西底迦，以色列的上帝耶和华说：看啊，我要把这城交在巴比伦王的手中，他要将城付之一炬。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 32:4; 耶利米书 21:7; 列王纪下 25:4–7"> 你必逃不出巴比伦王的手心，你必被抓，落入他手中。你必和巴比伦王面对面、眼对眼地说话，然后被带到巴比伦。</span>
<span className="v" id="v4" data-v="4"> 犹大王西底迦啊！你要听耶和华关于你的话。耶和华说：你必不会死在刀剑之下，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 22:18; 历代志下 16:14; 列王纪下 22:20"> 你必安然去世。人们必为你烧香，像为你的先王烧香一样，他们必为你哀悼说，唉，我主啊！’这是我耶和华说的。”</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 15:16–24; 撒母耳记上 3:18; 列王纪上 21:19"> 耶利米先知就在耶路撒冷把这番话告诉了犹大王西底迦。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:3; 耶利米书 4:5; 列王纪下 18:13–14"> 那时，巴比伦王的军队正攻打耶路撒冷以及犹大仅存的两座坚城拉吉和亚西加。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 25:10; 列王纪下 23:2–3; 列王纪下 11:17"> 耶和华的话传给耶利米之前，西底迦王与耶路撒冷的居民立约，宣布释放自己的奴隶。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 15:12; 利未记 25:39–46; 出埃及记 3:18"> 各人都要释放自己的希伯来男女奴隶，谁都不应使自己的希伯来同胞做奴隶。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 26:16; 耶利米书 26:10; 耶利米书 38:4"> 所有立约的首领和人民都答应守约，不再奴役他们。他们按约释放了自己的男女奴隶。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 2:20–22; 箴言 26:11; 马太福音 12:43–45"> 但事后他们却反悔，抓回先前释放的男女奴隶，再次奴役他们。</span>
<span className="v" id="v12" data-v="12"> 那时，耶和华对耶利米说：</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 6:8; 约书亚记 24:17; 申命记 5:27"> “以色列的上帝耶和华这样说，‘我曾带领你们的祖先离开埃及，使他们不再受奴役，那时我与他们立约说，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 15:12; 列王纪上 9:22; 列王纪下 17:13–14"> 如果你们的希伯来同胞卖身做你们的奴隶，服侍你们六年后，到第七年你们要给他们自由。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记15:12。">a</a></sup>你们的祖先却掩耳不听。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 34:8; 列王纪下 23:3; 尼希米记 10:29"> 不久前，你们回心转意，做我视为正的事，释放自己的同胞，并且在我的殿中当着我的面立了约。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 19:12; 出埃及记 20:7; 耶利米书 34:11"> 然而，你们却反悔，各自抓回先前释放的男女奴隶，再次奴役他们，亵渎了我的名。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 7:2; 申命记 28:25; 加拉太书 6:7"> 因此耶和华说，既然你们不听我的话，不给自己的同胞自由，看啊，我必给你们自由，使你们自由地死于刀剑、瘟疫和饥荒，使你们的遭遇令天下万国惊惧。这是耶和华说的。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 15:10; 创世记 15:17–18; 何西阿书 6:7"> 犹大与耶路撒冷的官员、宫廷侍臣、祭司和全体百姓曾把牛犊劈成两半，从中间走过跟我立约，后来却又违背跟我立的约，不守在我面前所立之约的规定，所以我必使他们的下场像他们劈开的牛犊一样。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 7:33; 耶利米书 16:4; 耶利米书 19:7"> 我要把他们交在想杀他们的敌人手中，他们的尸体要成为飞禽走兽的食物。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 52:24–27; 耶利米书 39:6; 耶利米书 52:10"> 我要把犹大王西底迦及其官员交在想杀他们的敌人手中，交在刚撤军的巴比伦王手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 9:11; 耶利米书 39:8; 耶利米书 39:1–2"> 看啊，我要吩咐他们回来攻占这城，将它付之一炬，我要使犹大的城邑荒无人烟。这是耶和华说的。’”</span>
</div>

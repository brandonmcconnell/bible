## 犹大的罪与罚

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 3:3; 哥林多后书 3:3; 箴言 7:3"> “犹大人的罪是用铁笔记录的，用钻石镌刻的，写在了他们心坎上和祭坛角上。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 24:18; 耶利米书 2:20; 士师记 3:7"> 他们的儿女念念不忘他们在绿树下、高岗上和山野间的祭坛和亚舍拉神像。因为他们境内罪恶泛滥，我必使敌人掳掠他们的财宝和丘坛。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 15:14; 耶利米哀歌 5:2; 以赛亚书 5:25"> 他们必失去我赐给他们的产业，被敌人掳到陌生的异乡做奴隶，因为他们激起了我的怒火，永难熄灭。”</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:8–9; 诗篇 146:3–4; 以赛亚书 2:22"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“信靠世人、倚靠血肉之躯、</span><br /><span className="pl pl-1">心中背叛耶和华的人该受咒诅！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 20:17; 申命记 29:23; 诗篇 1:4"> <span className="pl pl-1">这样的人毫无福乐，</span><br /><span className="pl pl-1">像沙漠中的灌木。</span><br /><span className="pl pl-1">他要住在旷野的干旱之处，</span><br /><span className="pl pl-1">住在无人的盐碱地。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 26:3–4; 诗篇 34:8; 诗篇 40:4"> <span className="pl pl-1">信靠耶和华、倚靠耶和华的人有福了！</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 1:3; 以赛亚书 58:11; 以西结书 47:12"> <span className="pl pl-1">这样的人像一棵栽在水边的树，</span><br /><span className="pl pl-1">根扎入溪水旁，</span><br /><span className="pl pl-1">不怕炎热，不怕干旱，</span><br /><span className="pl pl-1">绿叶如荫，不断结果。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="马可福音 7:21–22; 马太福音 15:19; 传道书 9:3"> <span className="pl pl-1">“人心比什么都诡诈，</span><br /><span className="pl pl-1">无可救药，</span><br /><span className="pl pl-1">谁能识透呢？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 16:7; 罗马书 8:27; 耶利米书 11:20"> <span className="pl pl-1">我耶和华鉴察人心，</span><br /><span className="pl pl-1">察看人的意念，</span><br /><span className="pl pl-1">按照各人的所作所为报应人。”</span></span>

## 遵守安息日

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:2; 耶利米书 26:2; 使徒行传 5:20"> 耶和华对我说：“你去站在犹大君王出入的人民门门口和耶路撒冷的各城门口，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 19:3; 耶利米书 22:2; 诗篇 49:1–2"> 向他们宣告，‘从这些城门进出的犹大君王、所有百姓以及耶路撒冷的居民啊，你们都要听耶和华的话。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 13:15–21; 民数记 15:32–36; 约翰福音 5:9–12"> 耶和华说，如果你们想保住性命，就要小心，不要在安息日带货物进耶路撒冷的城门，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:12; 出埃及记 20:8–10; 以赛亚书 58:13"> 也不要从家中运出货物，不要在安息日做任何工作。要按照我对你们祖先的吩咐守安息日为圣日。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 29:1; 耶利米书 11:10; 使徒行传 7:51"> 然而，他们却不理不听，顽固不化，不肯听从和受教。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 17:21–22; 申命记 11:13; 彼得后书 1:5–10"> “‘耶和华说，你们要留心听我的话，在安息日不可运货物进耶路撒冷的城门，不可做任何工作，要守安息日为圣日。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 22:4; 以赛亚书 9:7; 希伯来书 12:22"> 这样，坐大卫宝座的君王及其官员必乘车骑马和犹大人以及耶路撒冷的居民进入城门。这城必永远有人居住。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 33:13; 耶利米书 32:44; 撒迦利亚书 7:7"> 人们必带着燔祭、平安祭、素祭、乳香和感恩祭从犹大的城邑、耶路撒冷四周、便雅悯地区、丘陵、山区和南地去耶和华的殿。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 25:9; 耶利米书 7:20; 耶利米书 21:14"> 但如果你们不听我的话，不守安息日为圣日，仍在安息日运货物进耶路撒冷的城门，我必在各城门点起无法扑灭的大火，烧毁耶路撒冷的宫殿。’”</span>
</div>

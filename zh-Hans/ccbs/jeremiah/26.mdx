## 耶利米被捕

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="历代志下 36:4–5; 耶利米书 27:1; 列王纪下 23:34–36"> 约西亚的儿子犹大王约雅敬执政初期，耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:2; 使徒行传 20:27; 马太福音 28:20"> “这是耶和华说的：你要站在我殿的院子里，把我吩咐你的话一字不漏地告诉从犹大各城前来敬拜的人。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 以赛亚书 1:16–19; 耶利米书 18:7–10"> 或许他们都会听从我的话，改邪归正，那样我会施怜悯，取消原本用来惩治他们罪恶的灾祸。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:6; 耶利米书 44:10; 以赛亚书 1:20"> 你要告诉他们，耶和华这样说，‘如果你们不听从我的话，不遵行我给你们设立的律法，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 11:7; 列王纪下 9:7; 耶利米书 7:13"> 不听从我差遣我的仆人——众先知屡次传给你们的话，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 24:9; 列王纪下 22:19; 耶利米书 25:18"> 我必使这殿像示罗一样被毁，使耶路撒冷被万国咒诅。’”</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 5:31; 弥迦书 3:11; 使徒行传 5:17"> 祭司、先知和民众都听见了耶利米在耶和华的殿里说的这些话。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:13–14; 使徒行传 7:52; 耶利米书 18:18"> 耶利米向民众传达完耶和华的话之后，祭司、先知和民众就抓住他，说：“你真该死！</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:17–19; 使徒行传 19:24–32; 弥迦书 2:6"> 你为什么奉耶和华的名预言这殿必像示罗一样被毁，这城必要荒无人烟呢？”于是，他们聚在耶和华的殿里围住耶利米。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:10; 耶利米书 38:4–6; 耶利米书 37:14–16"> 犹大的官员得知后，就离开王宫，上到耶和华的殿，坐在耶和华殿新门的入口。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 38:4; 马太福音 26:66; 申命记 18:20"> 祭司和先知对官员和民众说：“这人该被处死！因为他预言这城要被毁，这是你们亲耳听到的。”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:29; 耶利米书 26:15; 使徒行传 4:19"> 耶利米对官员和民众说：“你们刚才听见了耶和华差我对这殿和这城说的预言。</span>
<span className="v" id="v13" data-v="13" data-xref="约拿书 3:9; 约拿书 4:2; 以赛亚书 1:19"> 你们要改邪归正，听从你们上帝耶和华的话，这样耶和华必施怜悯，取消祂宣布要降给你们的灾祸。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 9:25; 撒母耳记下 15:26; 耶利米书 38:5"> 至于我，我已落在你们手中，你们认为怎样好就怎样待我吧！</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 35:33; 箴言 6:17; 马太福音 26:25"> 不过，你们要确知，如果你们置我于死地，你们和这城及城中的居民必担当滥杀无辜的罪，因为确实是耶和华派我来告诉你们这些预言的。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 5:34–39; 使徒行传 23:29; 使徒行传 25:25"> 官员和民众便对祭司和先知说：“这人不该被处死，因为他是奉我们上帝耶和华的名对我们说话。”</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:34; 弥迦书 1:1"> 有几个长老站起来对聚集的民众说：</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 1:1; 尼希米记 4:2; 撒迦利亚书 8:3"> “犹大王希西迦执政期间，摩利沙人弥迦对犹大民众预言说，<br /><span className="pl pl-1">“‘万军之耶和华说锡安必被夷为平地，</span><br /><span className="pl pl-1">耶路撒冷必沦为废墟，</span><br /><span className="pl pl-1">圣殿山必成为长满荒林的高岗。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="弥迦书3:12。">a</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 32:14; 撒母耳记下 24:16; 以赛亚书 37:15–20"> “但犹大王希西迦和犹大众人并没有处死他。希西迦敬畏耶和华，求祂开恩，耶和华就施怜悯，没有把宣布的灾祸降给他们。若处死这人，我们就会大祸临头。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 7:2; 约书亚记 9:17; 约书亚记 15:60"> 当时，基列·耶琳人示玛雅的儿子乌利亚也奉耶和华的名预言这城和这地方将被毁，内容与耶利米说的一样。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:23; 马太福音 14:5; 耶利米书 36:26"> 约雅敬王及其官长臣仆听见乌利亚的话，王就想处死他。乌利亚得知后，吓得逃到埃及去了。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 36:12; 列王纪下 22:12; 列王纪下 22:14"> 约雅敬王便派亚革波的儿子以利拿单率随从去埃及捉拿他。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 2:30; 启示录 11:7; 以西结书 19:6"> 他们把乌利亚从埃及押送到约雅敬王面前，王用刀杀了他，把尸首抛在平民的坟地中。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 40:5–7; 耶利米书 39:14; 耶利米书 1:18–19"> 不过，沙番的儿子亚希甘保护耶利米，他才没被交给民众处死。</span>
</div>

## 呼吁背信的以色列悔改

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:7–17; 以西结书 16:31; 耶利米书 7:24"> 在约西亚王执政期间，耶和华对我说：“你看见背信的以色列所行的了吗？她上到高山上、在绿树下淫乱。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 16:46; 何西阿书 6:1–4; 何西阿书 14:1"> 我以为她淫乱之后会回到我身边，她却执迷不悟。她不贞的妹妹犹大也看见了这事。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 24:1; 何西阿书 4:15–17; 以赛亚书 50:1"> 因为背信的以色列淫乱，我给她休书，把她休掉。她不贞的妹妹犹大却不害怕，竟也去淫乱。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 2:27; 以赛亚书 57:6; 耶利米书 3:2"> 以色列对淫乱不以为然，竟与石头木头苟合，玷污了土地。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 7:14; 耶利米书 12:2; 历代志下 34:33–18"> 尽管如此，她不贞的妹妹犹大只是假装归向我，并不诚心。这是耶和华说的。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西结书 23:11; 以西结书 16:51–52; 何西阿书 11:7"> 耶和华对我说：“背信的以色列比不贞的犹大罪过还轻。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 86:15; 以西结书 33:11; 申命记 4:29–31"> 你去向北方宣告，<br /><span className="pl pl-1">“‘耶和华说，</span><br /><span className="pl pl-1">背信的以色列啊，回转吧！</span><br /><span className="pl pl-1">我必不向你们发怒，</span><br /><span className="pl pl-1">因为我充满慈爱，</span><br /><span className="pl pl-1">不会永远怀怒。’</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:25; 耶利米书 3:6; 申命记 12:2"> <span className="pl pl-1">‘你必须要承认自己的罪，</span><br /><span className="pl pl-1">承认背叛了你的上帝耶和华，</span><br /><span className="pl pl-1">在绿树下祭拜各种外邦的神明，</span><br /><span className="pl pl-1">不听从我的话。’</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="何西阿书 2:19–20; 耶利米书 2:19; 耶利米书 31:32"> <span className="pl pl-1">“‘背信的子民啊，回转吧！</span><br /><span className="pl pl-1">因为我是你们的主人</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“主人”或译作“丈夫”。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">我要从你们中间选些人带回锡安，</span><br /><span className="pl pl-1">每座城邑选一人，每个宗族选二人。’</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:4; 使徒行传 20:28; 以弗所书 4:11–12"> “‘我要赐给你们合我心意的牧人，让他们用知识与智慧牧养你们。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 65:17; 阿摩司书 9:14–15; 以西结书 37:26"> 你们在地上繁衍昌盛的时候，人们不会再提及耶和华的约柜，不会再把它放在心上，不会再想起它，不会再感到需要它，也不会再造一个。这是耶和华说的。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 43:7; 弥迦书 4:1–5; 耶利米书 17:12"> 那时，耶路撒冷必被称为“耶和华的宝座”，万国都要聚集在耶路撒冷尊崇耶和华的名，不再执迷不悟地作恶。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:8; 何西阿书 1:11; 阿摩司书 9:15"> 那时，犹大人必与以色列人一同从北方来到我赐给你们祖先作基业的地方。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:4; 耶利米书 31:9; 以赛亚书 63:16"> <span className="pl pl-1">“‘我曾想，我多么愿意把你们当成我的儿女，</span><br /><span className="pl pl-1">赐给你们万国中最肥美的土地。</span><br /><span className="pl pl-1">我原以为你们会叫我“父亲”，</span><br /><span className="pl pl-1">再不离我而去。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 48:8; 耶利米书 5:11; 何西阿书 5:7"> <span className="pl pl-1">然而，以色列家啊！</span><br /><span className="pl pl-1">你们竟对我不忠，</span><br /><span className="pl pl-1">就像不贞的妻子离开丈夫。</span><br /><span className="pl pl-1">这是耶和华说的。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 7:10; 耶利米书 31:9; 耶利米书 2:32"> <span className="pl pl-1">从光秃的山头传来声音，</span><br /><span className="pl pl-1">是以色列子民哭泣呼求的声音，</span><br /><span className="pl pl-1">因为他们走入歧途，</span><br /><span className="pl pl-1">忘掉了他们的上帝耶和华。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="何西阿书 9:10; 以西结书 16:63; 以西结书 16:61"> “从我们年幼时，那些可耻的神像就吞噬了我们祖先辛苦得来的牛羊和儿女。</span>

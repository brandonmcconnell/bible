## 耶和华给流亡埃及之人的信息

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 46:14; 以赛亚书 11:11; 出埃及记 14:2"> 关于住在埃及的密夺、答比匿、挪弗和巴特罗地区的犹大人，耶和华对耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 6:11; 耶利米书 9:11; 耶利米书 34:22"> “以色列的上帝——万军之耶和华说，‘你们已看见了我降在耶路撒冷和犹大各城的灾祸。如今它们一片荒凉，杳无人迹。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:26; 申命记 13:6; 申命记 32:17"> 这都是因为那里的居民犯罪作恶，向他们、你们和你们祖先都不认识的神明烧香祭拜，惹我发怒。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 26:5; 耶利米书 7:25; 耶利米书 7:13"> 我屡次差遣我的仆人——众先知警告他们不要再做让我深恶痛绝的事，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 11:10; 耶利米书 19:13; 历代志下 36:16"> 他们却毫不理会，不肯离弃邪恶，仍向其他神明烧香。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:20; 耶利米书 21:5; 以赛亚书 51:17"> 因此，我的怒气和烈怒在犹大的城邑和耶路撒冷的街上燃烧，使它们沦为荒凉的废墟，正如今日一样。’</span>
<span className="v" id="v7" data-v="7" data-xref="哈巴谷书 2:10; 耶利米书 51:22; 以西结书 33:11"> 现在以色列的上帝——万军之上帝耶和华说，‘你们为什么自招大祸，使你们当中的男人、女人、孩童和婴儿都从犹大灭亡，无一幸免呢？</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:18; 耶利米书 25:6–7; 耶利米书 44:3"> 你们为什么在所居住的埃及制作偶像，向其他神明烧香，惹我发怒，自招毁灭，成为天下万国咒诅和羞辱的对象呢？</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:17–18; 约书亚记 22:17–20; 耶利米书 44:15–19"> 难道你们忘记了你们的祖先、犹大列王及其嫔妃，以及你们自己和妻子在犹大和耶路撒冷街上的恶行吗？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:14; 彼得前书 5:6; 启示录 15:4"> 你们至今既不悔悟也不惧怕，不遵行我给你们和你们祖先设立的律法和诫命。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 利未记 26:17; 利未记 20:5–6"> “‘因此，以色列的上帝——万军之耶和华说：看啊，我必严惩你们，毁灭整个犹大。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 42:15–18; 耶利米书 42:22; 以赛亚书 65:15"> 我要毁灭那些执意去埃及住的犹大余民。他们都必在埃及灭亡，死于刀剑和饥荒，无论尊卑，无一幸免。他们的下场将很可怕，成了人们责骂、咒诅和羞辱的对象。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 11:22; 耶利米书 43:11; 耶利米书 44:27–28"> 我要像惩罚耶路撒冷一样用刀剑、饥荒和瘟疫惩罚那些住在埃及的人。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 9:27; 耶利米书 22:26–27; 耶利米书 42:17"> 那些去埃及住的犹大余民没有几个能逃脱，并活着返回他们渴望居住的故乡犹大，除了少数幸存者外，他们都不得回去。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 11:21; 耶利米书 5:1–5; 创世记 19:4"> 那时，所有知道妻子向其他神明烧香的男人和一大群在场的妇女，以及所有住在埃及的巴特罗地区的人对耶利米说：</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 21:14–15; 路加福音 19:27; 耶利米书 16:15–17"> “我们不会听从你奉耶和华的名对我们说的话。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 7:18; 尼希米记 9:34; 耶利米书 44:21"> 但我们必照所许的愿向天后烧香奠酒，正如我们和我们的祖先、君王和官长在犹大各城和耶路撒冷街上所做的一样。那时，我们食物充足，生活幸福，无灾无祸。</span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 3:13–15; 民数记 11:5–6; 约伯记 21:14–15"> 但自从我们停止向天后烧香奠酒后，我们便一无所有，不断有人死于刀剑和饥荒。”</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:18; 耶利米书 44:15; 列王纪上 21:25"> 那些烧香的妇女说：“你以为我们的丈夫不知道我们向天后烧香奠酒、照着她的形象做祭饼吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 于是，耶利米对在场所有答复他的男女说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 44:17; 耶利米书 44:9; 耶利米书 11:13"> “你们和你们的祖先、君王、官长及其他所有百姓在犹大各城和耶路撒冷的街上烧香，耶和华岂不记得，岂能遗忘？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 25:18; 以赛亚书 7:13; 玛拉基书 2:17"> 你们的可憎恶行令耶和华忍无可忍，以致祂使你们的土地一片荒凉，无人居住，被人咒诅，正如今天的情形。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 9:9; 但以理书 9:11–12; 尼希米记 13:18"> 你们遭遇今天的灾祸是因为你们向其他神明烧香得罪耶和华，不听从祂的话，不遵行祂的律法、诫命和教诲。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 43:7; 耶利米书 44:15–16; 耶利米书 42:15"> 耶利米又对在场的男女说：“你们住在埃及的犹大人都要听耶和华的话。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 14:9; 使徒行传 23:12–15; 以赛亚书 28:15"> 以色列的上帝——万军之耶和华说，‘你们和你们的妻子曾许愿向天后烧香奠酒，并且着手还了所许的愿。那么，就去履行你们的许诺吧！还你们所许的愿吧！’</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 50:16; 以西结书 20:39; 希伯来书 6:13"> 住在埃及的所有犹大人啊，你们都要听耶和华的话。耶和华说，‘看啊，我以自己伟大的名起誓，再没有一个住在埃及的犹大人会凭永活的主耶和华起誓。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:28; 列王纪下 21:14; 耶利米书 1:10"> 看啊，我一定要给你们降下灾祸而非祝福，使所有住在埃及的犹大人死于刀剑和饥荒，直到灭绝。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 44:14; 以赛亚书 27:12–13; 以赛亚书 10:19"> 刀下余生、从埃及返回犹大的人必寥寥无几。那时，你们这些来埃及住的犹大余民必知道谁的话会实现，是我的还是你们的。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 19:21; 马太福音 24:15–16; 耶利米书 44:30"> 我必在这地方惩罚你们，我要给你们一个预兆，好叫你们知道我言出必行，必降灾给你们。这是耶和华说的。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 25:4–7; 耶利米书 43:9–13; 耶利米书 34:21"> 我必把埃及王法老何弗拉交在想杀他的仇敌手中，就像我把犹大王西底迦交在想杀他的仇敌巴比伦王尼布甲尼撒手中一样。这是耶和华说的。’”</span>
</div>
</div>

## 始祖犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:3; 哥林多后书 11:14; 启示录 12:9"> 在耶和华上帝所造的田野的各种动物中，蛇最狡猾。蛇对女人说：“上帝真的说过‘你们不可吃园中任何树上的果子’吗？”</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 58:4"> 女人回答说：“我们可以吃园中树上的果子，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 2:16–17; 哥林多后书 6:17; 出埃及记 19:12–13"> 只是上帝说过，‘你们不可吃园子中间那棵树的果子，也不可摸，免得死亡。’”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:44; 哥林多后书 11:3; 提摩太前书 2:14"> 蛇对女人说：“你们一定不会死！</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 28:2; 帖撒罗尼迦后书 2:4; 哥林多后书 11:13–15"> 上帝那样说是因为祂知道你们吃了那树的果子以后，眼睛就会打开，像上帝一样懂得分辨善恶。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰一书 2:16; 雅各书 1:14–15; 提摩太前书 2:14"> 女人见那棵树上的果子可口，悦人眼目，可使人有智慧，就摘下来吃了。她又把果子给跟她在一起的丈夫，他也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 59:6; 创世记 2:25; 创世记 3:5"> 二人的眼睛就打开了，发觉自己原来赤身露体，便编起无花果树的叶子来遮体。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:24; 箴言 15:3; 希伯来书 4:13"> 天起凉风时，那人和他妻子听见耶和华上帝在园中行走的声音，就藏在园子的树丛中，想躲避耶和华上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 4:9; 创世记 16:8; 创世记 18:20–21"> 耶和华上帝呼唤那人说：“你在哪里？”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 2:25; 诗篇 119:120; 以赛亚书 47:3"> 那人说：“我在园中听见你的声音，就害怕得躲了起来，因为我赤身露体！”</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:20; 创世记 4:10; 诗篇 50:21"> 耶和华上帝问：“谁告诉你，说你赤身露体？难道你吃了我吩咐你不可吃的果子吗？”</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各书 1:13–15; 约伯记 31:33"> 那人说：“你赐给我作伴的女人把那树上的果子给我，我就吃了。”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:3; 提摩太前书 2:14; 创世记 4:10–12"> 耶和华上帝对女人说：“你这是做的什么事？”女人说：“是蛇诱骗我，我才吃的。”</span>
</div>
</div>

## 上帝的审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="弥迦书 7:17; 以赛亚书 65:25; 诗篇 72:9"> 耶和华上帝对蛇说：<br /><span className="pl pl-1">“你既然做了这事，</span><br /><span className="pl pl-1">你要比一切牲畜和野兽受更重的咒诅，</span><br /><span className="pl pl-1">你要用肚子爬行，</span><br /><span className="pl pl-1">一生都要吃尘土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:20; 约翰一书 3:8; 启示录 12:17"> <span className="pl pl-1">我要使你和女人结仇，</span><br /><span className="pl pl-1">你的后裔和女人的后裔也要彼此为仇，</span><br /><span className="pl pl-1">女人的后裔必伤你的头，</span><br /><span className="pl pl-1">你必伤他的脚跟。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="提多书 2:5; 歌罗西书 3:18; 哥林多前书 11:3"> 耶和华上帝对女人说：<br /><span className="pl pl-1">“我必大大加重你怀孕的痛苦，</span><br /><span className="pl pl-1">你分娩时必受痛苦。</span><br /><span className="pl pl-1">你必恋慕</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“恋慕”或译“想控制”。">a</a></sup><br /><span className="pl pl-1">自己的丈夫，</span><br /><span className="pl pl-1">你的丈夫必管辖你。”</span></span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:20–22; 创世记 5:29; 以赛亚书 24:5–6"> 耶和华上帝又对亚当说：<br /><span className="pl pl-1">“因为你听从妻子的话，</span><br /><span className="pl pl-1">吃了我吩咐你不可吃的那树上的果子，</span><br /><span className="pl pl-1">地必因你而受咒诅。</span><br /><span className="pl pl-1">你必终生艰辛劳苦，</span><br /><span className="pl pl-1">才能吃到地里出产的食物。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:7; 约伯记 5:5; 以赛亚书 7:23"> <span className="pl pl-1">地必给你长出荆棘和蒺藜，</span><br /><span className="pl pl-1">你要吃田间长出来的菜蔬。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="传道书 12:7; 约伯记 34:15; 诗篇 104:29"> <span className="pl pl-1">你必汗流满面，才有饭吃，</span><br /><span className="pl pl-1">一直到你归回土地。</span><br /><span className="pl pl-1">因为那是你的本源。</span><br /><span className="pl pl-1">你本是尘土，也必归回尘土。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 2:23; 马太福音 1:23; 创世记 5:29"> 亚当给他的妻子取名叫夏娃，因为她是众生之母。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 61:10; 哥林多后书 5:21; 哥林多后书 5:2–3"> 耶和华上帝做了皮衣给他们夫妇穿上。</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 2:7; 启示录 22:14; 箴言 3:18"> 耶和华上帝说：“看啊，那人已经与我们相似，能分辨善恶。现在，恐怕他会伸手去摘生命树的果子吃，就永远活着。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 4:2; 创世记 3:19; 创世记 4:12"> 因此，耶和华上帝就把亚当赶出伊甸园，让他去开垦土地——那是他的本源。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 1:7; 诗篇 104:4; 出埃及记 25:18–22"> 祂赶走了亚当以后，在伊甸园东边安排基路伯天使和一把旋转的火剑，守住通往生命树的路。</span>
</div>

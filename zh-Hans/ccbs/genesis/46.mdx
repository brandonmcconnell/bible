## 以色列全家下埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 28:13; 创世记 26:22–25; 创世记 28:10"> 以色列带着他所有的一切来到别示巴，向他父亲以撒的上帝献祭。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 15:1; 约伯记 33:14–15; 约伯记 4:13"> 晚上，上帝在异象中对他说：“雅各！雅各！”他说：“我在这里。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:2; 申命记 26:5; 以赛亚书 43:1–2"> 上帝说：“我是上帝，是你父亲的上帝，不要害怕下到埃及，因为我要使你在那里成为大族。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 3:8; 创世记 28:15; 创世记 48:21"> 我必跟你一起下到埃及，也必带领你回来，约瑟必为你送终。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 45:21; 创世记 45:19; 创世记 45:27"> 于是，雅各从别示巴启程。以色列的儿子们带着父亲和妻儿，乘坐法老派来的车，</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 24:4; 以赛亚书 52:4; 使徒行传 7:15"> 带着在迦南获得的牲畜和财物前往埃及。这样，雅各带着他所有的子孙，</span>
<span className="v" id="v7" data-v="7"> 就是他的儿子、孙子、女儿和孙女一起去了埃及。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 1:1–5; 申命记 33:6; 历代志上 2:1–55"> 以下是去埃及的以色列人，即雅各和他后代的名字。<br />雅各的长子是吕便，</span>
<span className="v" id="v9" data-v="9"> 吕便的儿子是哈诺、法路、希斯伦和迦米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:15; 创世记 29:33; 创世记 28:1"> 西缅的儿子是耶姆利、雅悯、阿辖、雅斤、琐辖和迦南女子生的扫罗。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 29:34; 历代志上 6:16; 民数记 8:1–26"> 利未的儿子是革顺、哥辖和米拉利。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 4:21; 创世记 38:10; 创世记 29:35"> 犹大的儿子是珥、俄南、示拉、法勒斯和谢拉，珥和俄南死在了迦南，法勒斯的儿子是希斯仑和哈姆勒。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 12:32; 创世记 35:23; 创世记 30:14–18"> 以萨迦的儿子是陀拉、普瓦、约伯和伸仑。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:18–19; 民数记 26:26–27; 民数记 1:30–31"> 西布伦的儿子是西烈、以伦和雅利。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:32–35; 创世记 30:17–21; 创世记 34:1–31"> 这些都是利亚在巴旦·亚兰给雅各生的儿孙，加上女儿底娜共有三十三人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 26:15–17; 创世记 30:11; 民数记 1:24–25"> 迦得的儿子是洗非芸、哈基、书尼、以斯本、以利、亚罗底和亚列利。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 创世记 30:13; 民数记 1:13"> 亚设的儿子是音拿、亦施瓦、亦施韦、比利亚和他们的妹妹西拉，比利亚的儿子是希别和玛结。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 29:24; 创世记 35:26; 创世记 30:9–13"> 这些是悉帕给雅各生的儿孙，共有十六人，悉帕是拉班给女儿利亚的婢女。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 44:27; 创世记 29:18; 创世记 35:24"> 雅各的妻子拉结生的儿子是约瑟和便雅悯。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:50–52; 创世记 41:45; 申命记 33:13–17"> 约瑟在埃及生的儿子是玛拿西和以法莲，他们的母亲是安城祭司波提非拉的女儿亚西纳。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 7:6–12; 历代志上 8:1–7; 民数记 26:38–40"> 便雅悯的儿子是比拉、比结、亚实别、基拉、乃幔、以希、罗实、姆平、户平和亚勒。</span>
<span className="v" id="v22" data-v="22"> 这些是拉结给雅各生的儿孙，共有十四人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民数记 1:38–39; 创世记 49:16–17; 民数记 1:12"> 但的儿子是户伸。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 7:13; 民数记 1:42–43; 创世记 35:25"> 拿弗他利的儿子是雅薛、沽尼、耶色和示冷。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 29:29; 创世记 35:25; 创世记 30:3–8"> 这些是辟拉给雅各生的儿孙，共有七人，辟拉是拉班给女儿拉结的婢女。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 1:5; 创世记 35:11; 士师记 8:30"> 跟雅各一同到埃及去的儿孙共有六十六人，他的儿媳妇不算在内。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 10:22; 使徒行传 7:14; 出埃及记 1:5"> 加上约瑟在埃及生的两个儿子，雅各一家来到埃及的共有七十人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 45:10; 创世记 44:16–34; 创世记 49:8"> 雅各派犹大先去见约瑟，请他派人引路到歌珊去。他们来到歌珊，</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 创世记 45:14–15; 创世记 33:4"> 约瑟备好车前去迎接父亲以色列。父子重逢，约瑟抱住父亲哭了很久。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 创世记 45:28"> 以色列对约瑟说：“我现在看到你还活着，就是死也安心了。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 47:1–3; 希伯来书 2:11; 使徒行传 18:3"> 约瑟对他的弟兄们和其他家人说：“我要上奏法老，‘我在迦南的弟兄和父亲全家已经来到我这里。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 47:3; 列王纪上 9:27; 列王纪上 18:5–6"> 他们是牧人，以畜牧为业，已经把羊群、牛群和所有的一切都带来了。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 46:32; 创世记 47:2–4; 约拿书 1:8"> 等法老召见你们，问你们以什么为业，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:26; 创世记 43:32; 创世记 46:32"> 你们要说，‘仆人们跟我们的祖先一样，从小以畜牧为业。’这样，你们就可以住在歌珊，因为埃及人厌恶牧羊的。”</span>
</div>
</div>

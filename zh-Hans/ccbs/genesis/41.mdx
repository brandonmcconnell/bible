## 约瑟为法老解梦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 20:3; 创世记 29:14; 出埃及记 4:9"> 两年后，法老做了个梦，梦见自己站在尼罗河边，</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 19:6"> 有七头肥美、健壮的母牛从河里上来，在芦苇丛中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 41:20–21; 创世记 41:4"> 随后又有七头丑陋、瘦弱的母牛从河里上来，与那七头母牛一同站在河边。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:15"> 后来，七头丑陋、瘦弱的母牛吃掉了七头肥美、健壮的母牛。这时，法老醒了过来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命记 32:14"> 之后，他又睡着了，又做了个梦。他梦见一株麦子上长了七个饱满的穗子。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:10; 何西阿书 13:15; 以西结书 19:12"> 后来这株麦子上面又长了七个干瘪的穗子，它们被东风吹焦了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:5; 创世记 20:3"> 七个干瘪的穗子吞食了七个饱满的穗子。法老醒过来，原来是一场梦。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理书 4:7; 出埃及记 7:22; 马太福音 2:1"> 早上法老心中不安，就派人召来埃及所有的术士和智者，把梦告诉他们，可是没有一个人能为他解梦。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 40:14; 创世记 40:23; 创世记 40:1–3"> 这时酒侍对法老说：“我今天才想起我的罪过。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 39:20; 创世记 40:2–3; 创世记 37:36"> 我从前和膳司惹法老生气，被他囚禁在护卫长府内的牢里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 40:5–8"> 一天晚上，我俩都做了梦，我们的梦各有不同的意思。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 40:12–19; 创世记 37:36; 创世记 39:1"> 当时有一个希伯来青年跟我们一起被囚在牢里，他是护卫长的仆人。我们把梦告诉他，他就分别为我们解梦。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 43:3; 创世记 40:20–22; 创世记 40:12"> 后来，他为我们解的梦都应验了，我恢复了原职，膳司被挂在木头上处死了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 2:25; 诗篇 113:7–8; 诗篇 105:19–22"> 于是，法老派人去召约瑟，他们急忙从牢里释放约瑟。约瑟剃头刮脸，更换衣服，去见法老。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:16; 但以理书 5:12; 诗篇 25:14"> 法老对约瑟说：“我做了一个梦，没有人能为我解梦。我听说你能解梦。”</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5; 创世记 40:8; 但以理书 2:47"> 约瑟回答说：“我自己不会解梦，但上帝却能给王圆满的解释。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 法老对约瑟说：“我梦见自己站在尼罗河边，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:8; 耶利米书 24:1–3; 耶利米书 24:5"> 有七头肥美、健壮的母牛从河里上来，在芦苇丛中吃草。</span>
<span className="v" id="v19" data-v="19"> 随后又有七头丑陋、瘦弱的母牛从河里上来，我在全埃及从来没有见过有这么丑陋的牛。</span>
<span className="v" id="v20" data-v="20"> 这些丑陋、瘦弱的母牛吃掉先前的七头肥母牛。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 3:3; 诗篇 37:19; 启示录 10:9–10"> 可是，它们吃了以后就像没吃一样，仍然和以前一样丑陋。这时，我就醒了。</span>
<span className="v" id="v22" data-v="22"> 后来我又梦见一株麦子，上面长了七个饱满的穗子，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 129:6–7; 何西阿书 13:15; 列王纪下 19:26"> 接着又长出七个被东风吹焦的干瘪穗子，</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 4:7; 创世记 41:8; 出埃及记 8:19"> 这些干瘪的穗子吞了那七个饱满的穗子。我把梦告诉了术士，却没有人能为我解梦。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="但以理书 2:45; 启示录 4:1; 以弗所书 1:17"> 约瑟对法老说：“王的梦都是同一个意思，上帝已经借着梦把祂将要做的事指示王了。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 41:47; 创世记 41:2; 创世记 41:53"> 七头肥美的母牛和七个饱满的穗子都代表七年，是同样的意思。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 8:1; 撒母耳记下 24:19"> 随后上来的七头瘦弱、丑陋的母牛和七个干瘪、被东风吹焦的穗子也代表七年，是七年饥荒。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 41:25; 创世记 41:16"> 正如我刚才说的，上帝已经把祂将要做的事向王显明了。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 41:26; 创世记 41:46–47; 创世记 41:49"> 埃及全境很快会有七年大丰收，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:13; 创世记 41:54; 雅各书 5:17"> 随后是七年饥荒肆虐全国，之前的丰收将被忘记。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 24:20; 撒母耳记上 5:6"> 饥荒将非常严重，之前的丰收将荡然无存。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 23:19; 以赛亚书 46:10–11; 以赛亚书 14:24–27"> 王的梦出现了两次，表示上帝的心意已定，上帝必很快成就这事。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 41:39; 使徒行传 6:3; 申命记 1:13"> 王应该选一个精明聪慧的人，派他治理埃及。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 王也应该在各地委派官员，在七年丰收期内征收全国出产的五分之一，</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 45:6–7; 创世记 41:56; 出埃及记 4:13"> 把在丰年收集的粮食储存在各城，归王管理。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 47:13–25"> 这些粮食要留到埃及七年饥荒时用，免得这片土地被饥荒毁灭。”</span>
</div>
</div>

## 约瑟做埃及宰相

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 7:10; 列王纪上 21:2; 撒母耳记下 3:36"> 法老和他所有的臣仆都赞同约瑟的建议。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:8; 但以理书 5:14; 民数记 27:18"> 法老对臣仆说：“我们哪里找像这样有上帝的灵同在的人呢？”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 41:33; 创世记 41:28; 创世记 41:25"> 法老对约瑟说：“上帝既然把梦的意思指示给你，可见没人有你这样的见识和智慧。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行传 7:10; 诗篇 105:21–22"> 你要管理我家，我的人民都要遵从你的命令，只有我权力比你大。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 28:18; 腓立比书 2:9–11; 创世记 42:6"> 法老又说：“我现在派你治理埃及全国。”</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 5:29; 但以理书 5:7; 以斯帖记 3:10"> 于是，法老摘下手上用来盖印的戒指，戴在约瑟的手上，给他穿上细麻袍，把金链戴在他颈上，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 7:10; 创世记 45:8; 创世记 45:26"> 让他坐在自己的第二辆御车上，并有人在御车前高呼：“跪下！”这样，法老派约瑟治理整个埃及。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 105:22; 出埃及记 11:7"> 法老对约瑟说：“我是法老，但没有你的命令，埃及的任何人都不得擅自行事。”</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 46:20; 以西结书 30:17; 出埃及记 2:16"> 法老赐给约瑟一个名字，叫撒发那忒·巴内亚，又把安城祭司波提非拉的女儿亚西纳赐给他为妻。约瑟巡视了整个埃及。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="但以理书 1:19; 列王纪上 12:6; 撒母耳记上 16:21"> 约瑟三十岁开始为法老效劳，他离开法老去巡视埃及各地。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 26:12; 诗篇 72:16"> 七个丰年之内，埃及粮食大丰收，</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 41:34–36; 创世记 47:21"> 约瑟收集埃及七个丰年出产的所有粮食，储藏进各城，每一座城附近出产的粮食都存放在本城。</span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 78:27; 士师记 6:5; 创世记 22:17"> 约瑟积存了大量五谷，多如海沙，不可胜数。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="创世记 46:20; 创世记 48:5; 撒母耳记下 8:18"> 荒年到来前，安城祭司波提非拉的女儿亚西纳给约瑟生了两个儿子。</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 30:5; 箴言 31:7; 申命记 33:17"> 约瑟给长子取名叫玛拿西，因为他说：“上帝使我忘记一切困苦和父亲全家。”</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 49:22; 创世记 50:23; 创世记 17:6"> 约瑟给次子取名叫以法莲，因为他说：“上帝使我在受苦之地昌盛。”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="创世记 41:29–31; 诗篇 73:20; 路加福音 16:25"> 七个丰年结束后，</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 45:11; 使徒行传 7:11; 诗篇 105:16"> 七个荒年接踵而至，正如约瑟所言。各地都有饥荒，只有埃及全国有粮食。</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 17:5; 马太福音 3:17; 耶利米书 14:1–6"> 后来，埃及全国也遭遇饥荒，百姓就向法老求粮，法老对他们说：“你们去找约瑟吧，要照他的吩咐做。”</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="创世记 42:6; 撒迦利亚书 5:3; 路加福音 21:35"> 饥荒蔓延到整个埃及时，约瑟便开仓卖粮给埃及人。那时，埃及的饥荒非常严重。</span>
<span className="v" id="v57" data-v="57" data-xref="创世记 41:54; 创世记 42:5; 创世记 41:56"> 各地的人都到埃及来向约瑟买粮，因为天下到处都是大饥荒。</span>
</div>
</div>

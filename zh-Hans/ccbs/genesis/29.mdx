## 雅各到达舅父家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:3; 士师记 6:33; 何西阿书 12:12"> 雅各继续前行，来到东方人住的地方，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 4:14; 以赛亚书 49:10; 约翰福音 4:6"> 看见田间有一口井，有三群羊卧在井边，因为当地人用那口井的水饮羊。井口封着一块大石头。</span>
<span className="v" id="v3" data-v="3"> 羊群聚集在井旁的时候，牧人就把井口的石头滚开饮羊，随后再把石头放回原处。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:10; 创世记 27:43; 使徒行传 7:2"> 雅各问牧人：“弟兄们，你们是从哪里来的？”他们说：“我们是从哈兰来的。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 24:24; 创世记 24:29; 创世记 31:53"> 雅各问道：“你们认识拿鹤的孙子拉班吗？”他们说：“我们认识。”</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 20:9; 创世记 37:14; 出埃及记 18:7"> 雅各又问：“他好吗？”他们回答说：“很好。你看，他的女儿拉结带着羊群来了。”</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:16; 加拉太书 6:9–10"> 雅各对他们说：“太阳还高，不到把羊关起来的时候，你们饮了羊，再放它们去吃草吧！”</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 16:3; 路加福音 24:2; 创世记 34:14"> 他们说：“不行，要等所有的羊群到齐，把井口的石头滚开后，才能饮羊。”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:21; 雅歌 1:7–8; 出埃及记 2:15–16"> 雅各还在跟他们说话的时候，拉结就带着她父亲的羊群来到井边，她是个牧羊女。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 2:17"> 雅各看见表妹拉结和舅父拉班的羊群来了，就上前把井口的石头滚开，饮他舅父的羊。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 33:4; 创世记 45:14–15; 创世记 45:2"> 他亲吻拉结，并放声大哭。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:28; 创世记 13:8; 创世记 14:14–16"> 雅各告诉拉结自己是她父亲的外甥，是利百加的儿子。拉结便跑去告诉她父亲。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 24:29; 使徒行传 20:37; 罗马书 16:16"> 拉班听见外甥雅各来了，就跑去迎接他，拥抱他，亲吻他，然后把他接到自己家里。雅各把事情的经过告诉他。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:12–13; 创世记 2:23; 士师记 9:2"> 拉班说：“你真是我的骨肉至亲啊！”雅各在拉班家里住了一个月。</span>
</div>
</div>

## 雅各娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 30:28; 创世记 31:7"> 一天，拉班对他说：“虽然我们是亲戚，也不能让你白白地替我工作。告诉我，你希望得到什么报酬？”</span>
<span className="v" id="v16" data-v="16" data-xref="路得记 4:11; 创世记 49:31; 创世记 31:4"> 拉班有两个女儿，大的叫利亚，小的叫拉结。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 12:11; 创世记 46:19–22; 创世记 24:16"> 利亚两眼无神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“两眼无神”或译“两眼很美丽”。">a</a></sup>，而拉结长得美丽多姿。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿书 12:12; 出埃及记 22:16–17; 创世记 34:12"> 雅各爱上了拉结，于是对拉班说：“我愿意为你工作七年，请把你小女儿拉结许配给我。”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 6:11; 以赛亚书 6:5; 诗篇 12:2"> 拉班说：“把她嫁给你比嫁给外人好，你就留下来吧！”</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 13:7; 以弗所书 5:2; 何西阿书 12:12"> 雅各为了拉结给拉班工作了七年。因为他深爱拉结，所以这七年在他眼中就像短短的几天。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 15:1; 创世记 29:20; 创世记 4:1"> 一天，雅各对拉班说：“期限已经满了，现在请把我妻子给我，我好和她同房。”</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 19:9; 路得记 4:10–13; 士师记 14:10–18"> 于是，拉班就摆设宴席款待当地的人。</span>
<span className="v" id="v23" data-v="23" data-xref="弥迦书 7:5; 创世记 38:14–15; 创世记 24:65"> 到了晚上，拉班却把女儿利亚交给雅各，雅各和她同房。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:1; 创世记 30:9–12; 创世记 46:18"> 拉班又把自己的婢女悉帕送给女儿利亚做婢女。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 7:2; 箴言 11:31; 哥林多前书 3:13"> 早上，雅各才发现娶的是利亚，就对拉班说：“你对我做的是什么事啊！我服侍你不就是为了拉结吗？你为什么骗我？”</span>
<span className="v" id="v26" data-v="26"> 拉班说：“依照本地的习俗，妹妹不能比姐姐先出嫁。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 18:18; 士师记 14:12; 创世记 2:2–3"> 等这女儿七天的婚期过了，我就把那个女儿也许配给你，你再替我工作七年。”</span>
<span className="v" id="v28" data-v="28"> 雅各同意了。过了七天，拉班把女儿拉结嫁给雅各，</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 35:22; 创世记 29:24; 创世记 30:3–8"> 又把自己的婢女辟拉送给拉结。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 31:41; 创世记 29:20; 创世记 31:15"> 雅各也和拉结同房，他深爱拉结胜过爱利亚。他又替拉班工作了七年。</span>
</div>
</div>

## 雅各的儿女

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 2:21; 马太福音 10:37; 申命记 21:15"> 耶和华看见利亚失宠，就使利亚生育，但拉结却不生育。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 26:7; 出埃及记 4:31; 出埃及记 3:7"> 利亚怀孕生了一个儿子，给孩子取名叫吕便<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“吕便”意思是“看，一个儿子”，此词发音像希伯来文“他看见了我的痛苦”一词的发音。">b</a></sup>。她说：“耶和华看见了我的痛苦，现在我丈夫一定会爱我。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 34:25; 创世记 49:5–6; 创世记 34:30"> 她又怀孕生了一个儿子，就说：“耶和华听见我失宠，所以又给我这个儿子。”于是，她给孩子取名叫西缅<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“西缅”意思是“听见”。">c</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 32:26–29; 创世记 49:5–7; 创世记 46:11"> 她又再度怀孕，生了一个儿子，就说：“这次我丈夫一定会依恋我，因为我给他生了三个儿子。”于是，他给孩子取名叫利未<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“利未”意思是“联合”。">d</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:2; 历代志上 5:2; 创世记 49:8–12"> 后来，利亚再次怀孕，生了一个儿子，她说：“这次我要赞美耶和华！”于是，她给孩子取名叫犹大<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“犹大”意思是“赞美”。">e</a></sup>。之后，利亚停止了生育。</span>
</div>

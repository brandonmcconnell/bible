## 上帝应许撒拉生子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:13; 创世记 48:3; 创世记 13:18"> 耶和华在幔利的橡树那里向亚伯拉罕显现。那时天气很热，亚伯拉罕坐在帐篷口，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 13:2; 创世记 18:22; 创世记 19:1"> 抬头看见三个人站在对面，就从帐篷口跑去迎接他们，俯伏在地，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 32:5"> 说：“我主，若我在你面前蒙恩，请不要从仆人这里走过去。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 24:32; 创世记 19:2; 创世记 43:24"> 我让人拿点水来，你们洗洗脚，在树下歇一会儿。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:15; 士师记 13:15; 士师记 6:18"> 你们既然路过仆人这里，我拿点饼来，你们补充一下体力再上路吧。”他们说：“好，就照你说的做吧！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:33; 希伯来书 13:2; 使徒行传 16:15"> 于是，亚伯拉罕连忙进帐篷对撒拉说：“快准备三斗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“三斗”希伯来文是“三细亚”，大约是十公斤。">a</a></sup>细面粉，和面烤饼。”</span>
<span className="v" id="v7" data-v="7" data-xref="玛拉基书 1:14; 路加福音 15:27; 路加福音 15:30"> 亚伯拉罕又跑到牛群中牵了一头肥嫩的小牛，交给仆人赶快去准备。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:3; 士师记 13:15; 启示录 3:20"> 亚伯拉罕把奶、奶酪和准备好的牛肉摆在他们面前，自己在树荫下侍立一旁，伺候他们用餐。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提多书 2:5; 创世记 24:67; 创世记 4:9"> 他们问亚伯拉罕：“你妻子撒拉在哪里？”亚伯拉罕回答说：“在帐篷里。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 21:2; 创世记 17:21; 罗马书 9:8–9"> 其中一人说：“明年这时候，我必回到你这里，撒拉必生一个儿子。”撒拉在那人后面的帐篷口听见了。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:17; 希伯来书 11:11–12; 路加福音 1:36"> 亚伯拉罕和撒拉已经年纪老迈，撒拉早已绝经。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:6; 创世记 17:17; 路加福音 1:18–20"> 撒拉暗自发笑，心想：“我已经老了，还会有这种福气吗？况且我的丈夫也老了。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 2:25"> 耶和华问亚伯拉罕：“撒拉为什么偷笑说，‘我这把年纪还会有孩子吗？’</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:37; 马太福音 19:26; 马可福音 10:27"> 什么事能难得了耶和华呢？明年这时候，我必回到你这里，撒拉必生一个儿子。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 1:8; 箴言 28:13; 以弗所书 4:23"> 撒拉听见后非常害怕，连忙否认说：“我没有笑！”但耶和华说：“不，你确实笑了。”</span>
</div>
</div>

## 亚伯拉罕为所多玛求情

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 15:3; 使徒行传 21:5; 使徒行传 20:38"> 那三个人起身朝所多玛眺望，亚伯拉罕与他们同行，要送他们一程。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司书 3:7; 诗篇 25:14; 约翰福音 15:15"> 耶和华说：“我要做的事怎么可以瞒着亚伯拉罕呢？</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:8; 创世记 26:4; 加拉太书 3:14"> 亚伯拉罕必成为强盛的大国，天下万国必因他而蒙福。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:6–7; 申命记 4:9–10; 提摩太前书 3:4–5"> 我拣选了他，是要他教导自己的子孙后代持守我的道、秉公行义。这样，我必实现对他的应许。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 19:13; 以西结书 16:49–50; 以赛亚书 3:9"> 耶和华说：“所多玛和蛾摩拉罪恶深重，人们怨声载道。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:8; 创世记 11:5; 西番雅书 1:12"> 我现在要下去看看他们的恶行是否如我听到的控诉一样，如果不是，我也会知道。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 19:1; 使徒行传 7:55; 以西结书 22:30"> 其中二人转身向所多玛走去，亚伯拉罕却仍旧站在耶和华面前。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 16:22; 撒母耳记下 24:17; 创世记 20:4"> 亚伯拉罕上前说：“你要把义人和恶人一同毁灭吗？</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 5:1; 以赛亚书 1:9; 马太福音 7:13–14"> 倘若城中有五十个义人，你还要毁灭那城吗？你会不会为了五十个义人而饶恕那座城呢？</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 8:3; 以赛亚书 3:10–11; 约伯记 8:20"> 你绝不会黑白不分，把义人和恶人一同毁灭。你绝不会这么做！你是普天下的审判者，难道不秉公行事吗？”</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 5:1; 马太福音 24:22; 以赛亚书 65:8"> 耶和华回答说：“我若在所多玛城中找到五十个义人，就因他们的缘故饶恕全城。”</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 3:19; 以赛亚书 6:5; 哥林多前书 15:47–48"> 亚伯拉罕说：“主啊，我虽然渺小如灰尘，还斗胆问你，</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 18:29; 列王纪上 20:32–33; 创世记 18:26"> 倘若只有四十五个义人，你会因为少了五个义人而毁灭全城吗？”耶和华说：“我若在城里找到四十五个义人，也不会毁灭那城。”</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:18; 希伯来书 4:16"> 亚伯拉罕又说：“倘若在那里找到四十个义人呢？”耶和华说：“为了那四十个人的缘故，我不会毁灭那城。”</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 89:7; 诗篇 9:12; 以斯帖记 4:11–16"> 亚伯拉罕说：“求主不要发怒，容许我再问一次，倘若在那里只找到三十个义人呢？”耶和华说：“倘若在那里只找到三十个，我也不会毁灭那城。”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 11:8; 创世记 18:27; 路加福音 18:1"> 亚伯拉罕说：“我大胆再问一次，倘若在那里只找到二十个义人呢？”耶和华说：“为了那二十个人的缘故，我也不会毁灭那城。”</span>
<span className="v" id="v32" data-v="32" data-xref="雅各书 5:15–17; 士师记 6:39; 马太福音 7:7"> 亚伯拉罕又说：“求主不要发怒，让我问最后一次，倘若在那里只找到十个义人呢？”耶和华说：“为了那十个人的缘故，我也不会毁灭那城。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 18:22; 创世记 32:26; 创世记 31:55"> 耶和华跟亚伯拉罕说完话便离开了，亚伯拉罕也回家去了。</span>
</div>
</div>

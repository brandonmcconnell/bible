## 犹大与她玛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 22:1; 列王纪下 4:8; 箴言 13:20"> 那时，犹大离开了他的兄弟们，到亚杜兰人希拉的家里住。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:3; 创世记 24:3; 创世记 6:2"> 他在那里遇见了迦南人书亚的女儿，就娶她为妻，与她同房。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:12; 民数记 26:19"> 她怀孕生了一个儿子，犹大给他取名叫珥。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:12; 民数记 26:19"> 她又怀孕生了一个儿子，给他取名叫俄南。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 26:20; 创世记 38:26; 创世记 46:12"> 她再次怀孕生了一个儿子，给他取名叫示拉。示拉是在基悉出生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3; 创世记 21:21; 马太福音 1:3"> 犹大给长子珥娶了她玛为妻。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 2:3; 创世记 46:12; 民数记 26:19"> 耶和华见犹大的长子珥邪恶，就取走了他的性命。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 25:5–10; 马太福音 22:23–27; 路得记 4:5–11"> 犹大对俄南说：“你要与嫂子她玛同房，向她尽娶寡嫂的本分，好替你哥哥传宗接代。”</span>
<span className="v" id="v9" data-v="9" data-xref="提多书 3:3; 申命记 25:6; 雅各书 3:16"> 俄南知道生了儿子也不归自己，所以每次与她玛同房都把精液遗在地上，以免给哥哥留后。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 46:12; 民数记 11:1; 历代志上 21:7"> 耶和华见俄南行为邪恶，就取走了他的性命。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 22:13; 路得记 1:11–13"> 犹大恐怕示拉会像他的两个哥哥一样死去，就对儿媳她玛说：“示拉还没有长大，你先回娘家守寡吧。”她玛就回娘家去住了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:10; 撒母耳记下 13:39; 士师记 14:1"> 多年后，犹大的妻子，即书亚的女儿死了。丧期过后，犹大就和他的朋友亚杜兰人希拉去亭拿，到给他剪羊毛的人那里。</span>
<span className="v" id="v13" data-v="13"> 有人告诉她玛说：“你公公上亭拿去剪羊毛了。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 38:26; 创世记 38:11–13; 耶利米书 3:2"> 她玛见示拉已经长大，却仍然没有娶她，就脱下寡妇的衣服，用帕子蒙上脸，换了装束，坐在去亭拿路上的伊拿印城门口。</span>
<span className="v" id="v15" data-v="15"> 犹大看见她蒙着脸，以为她是妓女，</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 6:10; 马太福音 26:15; 撒母耳记下 13:11"> 就走到路边去找她，说：“你来陪我睡觉吧。”犹大不知道她是自己的儿媳妇。她玛问道：“我陪你睡觉，你给我什么呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 16:33; 创世记 38:20; 箴言 20:16"> 犹大回答说：“我会从羊群中取一只山羊羔送给你。”她玛问道：“羊还没有送来以前，你给我什么作抵押呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 38:25–26; 何西阿书 4:11; 耶利米书 22:24"> 犹大问：“你要什么作抵押呢？”她玛说：“我要你的印、印带和你的手杖。”犹大给了她，然后跟她睡觉。她玛就怀了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 38:14; 撒母耳记下 14:5; 撒母耳记下 14:2"> 事后，她玛起来走了。她拿掉蒙脸的帕子，仍旧穿上寡妇的装束。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 20:9; 利未记 19:17; 撒母耳记下 13:3"> 犹大托他的朋友亚杜兰人送去一只山羊羔，要从那女人手中换回抵押物，却找不到她。</span>
<span className="v" id="v21" data-v="21"> 他的朋友就问当地的人：“伊拿印路旁的庙妓在哪里？”他们回答说：“这里没有庙妓。”</span>
<span className="v" id="v22" data-v="22"> 他的朋友只好回去对犹大说：“我找不着她，当地人说那里没有庙妓。”</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:12; 箴言 6:33; 启示录 16:15"> 犹大说：“让她留着我的东西吧，免得我们成为笑柄。反正我把羊送过去了，只是你找不到她。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 21:9; 以西结书 23:19; 士师记 19:2"> 大约过了三个月，有人告诉犹大说：“你的儿媳妇她玛不守妇道，并且怀孕了。”犹大说：“把她拉出来烧死！”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:32; 创世记 38:18; 哥林多前书 4:5"> 他们正要把她拉出来，她请人传信给她公公，说：“这些东西的主人使我怀了孕，请你看看这印、印带和杖是谁的？”</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 24:17; 约翰福音 8:9; 提多书 2:11–12"> 犹大认出是自己的东西，就说：“她比我更有理，因为我没有让儿子示拉娶她。”犹大没有再与她睡觉。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 25:24"> 她玛临产的时候，才知道腹中是一对双胞胎。</span>
<span className="v" id="v28" data-v="28"> 生产的时候，一个婴儿先伸出手来，接生婆就把一条红线系在他的手上，说：“他是先出生的。”</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 2:4; 马太福音 1:3; 创世记 46:12"> 可是那婴儿随后却把手缩回去，他的胞兄先出生了，接生婆说：“你怎么冲出来了！”因此，他的名字叫法勒斯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“法勒斯”意思是“冲出来”。">a</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 9:6; 历代志上 2:4; 马太福音 1:3"> 后来，那个手上系有红线的孩子也出生了，给他取名叫谢拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“谢拉”意思是“红色”或“光明”。">b</a></sup>。</span>
</div>
</div>

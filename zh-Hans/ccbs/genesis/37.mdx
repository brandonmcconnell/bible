## 约瑟的梦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:8; 创世记 23:4; 创世记 36:7"> 雅各住在他父亲寄居的迦南，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:25–26; 创世记 35:22; 撒母耳记上 2:22–24"> 以下是有关雅各一家的记载。 十七岁的少年约瑟跟哥哥们，就是他父亲雅各的妾辟拉和悉帕生的儿子们一同放羊。他向父亲报告哥哥们做的坏事。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 创世记 37:32; 撒母耳记下 13:18"> 约瑟是以色列年老时生的，众子中以色列最爱他，为他做了一件彩衣。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 27:41; 约翰一书 3:12; 约翰一书 4:20"> 约瑟的哥哥们见父亲偏爱他，就怀恨在心，对他恶言相向。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 28:12; 创世记 42:9; 约翰福音 17:14"> 约瑟做了一个梦，并告诉了哥哥们，他们更恨他了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 44:18; 士师记 9:7"> 约瑟对哥哥们说：“你们听听我做的梦：</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 44:14; 创世记 42:6; 创世记 43:26"> 我们在田里捆庄稼，我捆的庄稼站立起来，你们捆的庄稼都围着我捆的庄稼下拜。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 10:27; 使徒行传 7:35; 希伯来书 10:29"> 他的哥哥们回答说：“难道你真要做我们的王吗？真要统治我们吗？”因为约瑟的梦和他说的话，他们就更加恨他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:9–14; 创世记 37:7; 但以理书 8:10"> 后来，约瑟又做了一个梦，他又去对哥哥们说：“你们听听我做的另一个梦，我梦见太阳、月亮和十一颗星星都向我下拜。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:29; 腓立比书 2:10–11; 以赛亚书 60:14"> 约瑟把梦告诉了父亲和哥哥们，他父亲就责备他说：“你做的是什么梦！难道你的父母弟兄真的都要来向你俯伏下拜吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 7:9; 路加福音 2:19; 路加福音 2:51"> 约瑟的哥哥们嫉恨他，他父亲却把这些话记在心里。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 37:1; 创世记 33:18; 创世记 34:25–31"> 约瑟的哥哥们到示剑放父亲的羊。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:1–3; 撒母耳记上 3:8; 撒母耳记上 3:16"> 以色列对约瑟说：“你哥哥们在示剑放羊，我要派你去他们那里。”约瑟说：“好的。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 35:27; 路加福音 19:42; 诗篇 125:5"> 以色列说：“你去看看你哥哥们以及羊群是否平安，然后回来告诉我。”于是，他派约瑟从希伯仑谷出发，前往示剑。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:27; 士师记 4:22; 创世记 21:14"> 有人见约瑟在田野走迷了路，就问他：“你在找什么？”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 雅歌 1:7"> 约瑟回答说：“我在找我哥哥们，你知道他们在哪里放羊吗？”</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 6:13"> 那人说：“他们已经走了，我听他们说要到多坍去。”约瑟就赶往多坍，在那里找到了他们。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 23:12; 诗篇 37:12; 诗篇 37:32"> 约瑟的哥哥们远远看见他走来，趁他还没有到跟前，就合谋要杀死他。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 28:12; 创世记 37:11; 创世记 37:5"> 他们彼此商量说：“看！做梦的来了。</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:3; 箴言 27:4; 马太福音 2:2–16"> 来吧！我们杀了他，把他扔在井里，就说有野兽把他吃掉了，看他的梦怎么实现。”</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 创世记 35:22; 约书亚记 10:28"> 吕便听后想救约瑟的性命，就说：“我们不要害他性命。”</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 22:12; 申命记 13:9; 创世记 42:22"> 他又说：“不要杀人流血，把他扔在这旷野的井里吧，不要下手害他。”吕便想从他们手上救下约瑟，把他交回给父亲。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:3; 马太福音 27:28; 创世记 42:21"> 这时候，约瑟来到哥哥们那里，他们就剥去他身上的彩衣，</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 38:6; 诗篇 130:1–2; 撒迦利亚书 9:11"> 抓住他把他扔到井里。当时，那口井是干的，没有水。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:28; 创世记 43:11; 耶利米书 8:22"> 他们坐下来吃饭的时候，抬头看见一支从基列来的以实玛利商队用骆驼驮着香料、乳香、没药去埃及。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 37:20; 创世记 4:10; 创世记 25:32"> 犹大对他的众弟兄说：“我们杀死弟弟、掩盖他的血迹有什么益处呢？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:26; 创世记 42:21; 撒母耳记上 18:17"> 不如把他卖给以实玛利人，不要下手害他，他毕竟是我们的弟弟，我们的骨肉啊！”其他弟兄都赞成他的意见。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 7:9; 诗篇 105:17; 创世记 45:4–5"> 于是，那些米甸商人经过的时候，他们就把约瑟从井里拉上来，以四两银子的价钱把他卖给了以实玛利人。这些商人把他带到埃及去了。</span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 创世记 37:34; 创世记 44:13"> 吕便回到井边发现约瑟不见了，就伤心地撕裂了身上的衣服，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:13; 耶利米书 31:15; 创世记 42:32"> 回到弟兄们那里说：“那少年不见了，我现在怎么办？”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 37:23; 箴言 28:13; 创世记 37:3"> 他们宰了一只公山羊，把约瑟的彩衣拿来沾上血，</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 15:30; 创世记 37:3; 创世记 44:20–23"> 拿去给父亲，说：“我们捡到这件衣服，你看看是不是你儿子的？”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 37:20; 创世记 44:28; 约翰福音 13:7"> 雅各认出那件彩衣，说：“这是我儿子的衣服，一定是野兽把他吃了，约瑟一定被撕碎了！”</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 37:29; 撒母耳记下 3:31; 诗篇 69:11"> 雅各撕裂自己的衣服，腰间束上麻布，为约瑟哀伤了好多天。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 42:38; 约伯记 2:11; 撒母耳记下 12:17"> 他的儿女都来安慰他，他却不肯接受他们的安慰，说：“我一定会悲悲伤伤地下到阴间，去我儿子那里。”约瑟的父亲为他哀哭。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 40:4; 创世记 37:28; 列王纪下 25:8"> 那些米甸人把约瑟带到埃及后，卖给了法老的内臣护卫长波提乏。</span>

## 洪水泛滥

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:37–39; 彼得后书 2:5–9; 创世记 6:9"> 耶和华对挪亚说：“你和你全家都进入方舟，因为这个世代只有你在我眼中是义人。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 8:20; 利未记 10:10; 利未记 11:1–47"> 洁净的动物，你要每样带七公七母，不洁净的动物每样带一公一母，</span>
<span className="v" id="v3" data-v="3"> 飞鸟每样带七公七母，叫它们以后可以在地上繁衍后代。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 6:13; 创世记 7:12; 创世记 7:17"> 因为七天之后，我要在地上降雨四十昼夜，从地上毁灭我所造的一切活物。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 6:22; 路加福音 8:21; 出埃及记 39:32"> 凡耶和华所吩咐的，挪亚都照办了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 5:32; 创世记 8:13"> 洪水在大地上泛滥那年，挪亚六百岁了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 创世记 6:18; 马太福音 24:38"> 挪亚与妻子、儿子们和儿媳们都进了方舟，躲避洪水。</span>
<span className="v" id="v8" data-v="8"> 洁净的动物、不洁净的动物、飞禽和地上的一切爬虫，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 7:16; 创世记 2:19; 耶利米书 8:7"> 都一公一母成对地到挪亚那里，进了方舟，正如上帝对挪亚的吩咐。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 6:17; 创世记 7:4; 路加福音 17:27"> 七天过后，洪水在地上泛滥起来。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 8:2; 玛拉基书 3:10; 箴言 8:28–29"> 挪亚六百岁那年的二月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“二月”按犹太历计算，本卷书所用月份都是按犹太历计算。">a</a></sup>十七日，所有深渊的泉源都裂开了，天上的水闸也打开了，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:4; 马太福音 4:2; 创世记 7:17"> 地上大雨降了四十昼夜。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 6:18; 创世记 7:1; 创世记 6:10"> 就在那天，挪亚与他的儿子闪、含和雅弗，还有挪亚的妻子和三个儿媳妇都进了方舟。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:8–9; 创世记 7:2–3"> 所有的野兽、牲畜、地上的爬虫和飞鸟都按种类进入方舟。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:19–20; 以赛亚书 11:6"> 一切有生命气息的活物都成对地到挪亚那里，进入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 25:10; 路加福音 13:25; 诗篇 91:1–10"> 所有进入方舟的动物都是一公一母，正如上帝对挪亚的吩咐。然后，耶和华关上了方舟的门。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 7:4; 创世记 7:12"> 洪水在地上泛滥了四十天，水不断往上涨，把方舟漂了起来。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:28; 诗篇 69:15; 约伯记 22:16"> 洪水来势汹汹，淹没大地，方舟漂浮在水面上。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:6–9; 诗篇 46:2–3; 彼得后书 3:6"> 水势越来越大，把天下各处的高山都淹没了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 3:23; 诗篇 104:6"> 水淹没了群山，高出群山七米。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 6:13; 创世记 7:4; 创世记 6:17"> 地上所有的飞禽、走兽、牲畜、爬虫等动物和人类都死了。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 2:7; 创世记 6:17"> 陆地上所有鼻孔有生命气息的活物都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:5; 彼得前书 3:20; 希伯来书 11:7"> 地上的人类、飞禽走兽和爬虫等一切活物都被毁灭了，只剩下挪亚和跟他同在方舟里的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 8:3–4"> 洪水淹没大地一百五十天。</span>
</div>

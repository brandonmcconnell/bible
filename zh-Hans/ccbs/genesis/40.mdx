## 约瑟解梦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 40:13; 创世记 39:20–23; 以斯帖记 6:1"> 后来，埃及王的酒侍和膳司得罪了他们的主人埃及王，</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 诗篇 76:10"> 法老对这两个臣仆发怒，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 39:20; 创世记 39:23"> 把他们囚禁在护卫长波提乏府内的监牢里，也就是约瑟被囚的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:1; 诗篇 37:5; 创世记 37:36"> 护卫长派约瑟去伺候他们。他们在监牢待了一段日子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 41:11; 创世记 40:8; 创世记 37:5–10"> 一天晚上，关在监狱中的埃及王的酒侍和膳司两人都做了梦，他们的梦各有不同的意思。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 41:8; 但以理书 2:1–3; 创世记 40:8"> 第二天早上，约瑟过来见他们神情沮丧，</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:2; 撒母耳记上 1:8; 路加福音 24:17"> 就问这两位同被关在他主人府内的法老臣仆：“你们今天为什么满面愁容？”</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 2:47; 创世记 41:15–16; 但以理书 2:28"> 他们回答说：“我们都做了梦，可是没有人能给我们解梦。”约瑟说：“解梦不是上帝的事吗？请你们把梦告诉我。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 7:13–15; 创世记 37:5–10; 但以理书 4:8"> 酒侍便把自己的梦告诉约瑟，说：“我梦见我前面有一棵葡萄树，</span>
<span className="v" id="v10" data-v="10"> 树上有三根枝子，枝子发芽开花，结出串串成熟的葡萄。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 1:11–1; 列王纪上 10:5; 历代志下 9:4"> 我手上拿着法老的酒杯，摘下葡萄，把汁挤在酒杯中，然后递到法老手中。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 41:12; 士师记 7:14; 创世记 41:25–26"> 约瑟说：“这梦的意思是，三根枝子代表三天，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 3:3; 耶利米书 52:31; 列王纪下 25:27"> 三天之内，法老必让你出头并官复原职。你仍要和从前一样伺候法老饮酒。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 2:12; 路加福音 23:42; 撒母耳记上 20:14–15"> 当你再被重用的时候，请你记得恩待我，在法老面前提及我，救我出狱。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17–18; 创世记 39:20; 提摩太前书 1:10"> 我是从希伯来人那里被拐来的，无辜被囚在监牢。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 40:1–2"> 膳司见梦解得好，就对约瑟说：“我也做了个梦，我梦见自己头上顶着三筐白饼，</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 历代志上 12:20"> 最上面的一筐里放着为法老烤制的各种食物，有鸟来吃我头上筐内的食物。”</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 40:12; 创世记 41:26; 哥林多前书 11:24"> 约瑟说：“这梦的意思是，三筐就是三天，</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 40:22; 使徒行传 20:27; 撒母耳记下 21:6"> 三天之内，法老必砍下你的头，把你挂在木头上，鸟要来吃你的肉。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 40:19; 创世记 40:13; 马太福音 14:6"> 第三天是法老的生日，他宴请文武百官，把酒侍和膳司从监牢里提出来，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 40:13; 尼希米记 2:1"> 恢复了酒侍的职位，让他仍旧伺候自己饮酒，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:19; 创世记 41:16; 但以理书 2:30"> 却将膳司挂在木头上，正应验了约瑟的话。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 31:12; 约伯记 19:14; 诗篇 105:19"> 然而，法老的酒侍没有记念约瑟，竟把他遗忘了。</span>
</div>
</div>

</div>

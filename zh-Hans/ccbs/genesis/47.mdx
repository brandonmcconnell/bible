## 雅各全家定居埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 45:10; 创世记 46:31; 创世记 46:28"> 约瑟来到法老面前，对他说：“我父亲和我的弟兄们已经带着他们的羊群、牛群和所有的一切从迦南来了，现在就在歌珊。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:13; 歌罗西书 1:28; 犹大书 1:24"> 约瑟从弟兄中带了五个人去见法老。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:33–34; 帖撒罗尼迦后书 3:10; 创世记 4:2"> 法老问他们：“你们做什么工作？”他们回答说：“仆人们祖祖辈辈都是牧羊的。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:34; 创世记 15:13; 申命记 26:5"> 迦南的饥荒很严重，羊群没有草吃，所以我们到这里来寄居，求你准许仆人们住在歌珊。”</span>
<span className="v" id="v5" data-v="5"> 法老对约瑟说：“你父亲和弟兄们都来了，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 18:21; 箴言 22:29; 创世记 47:11"> 整个埃及就在你面前，尽管安排他们住在国中最好的地方。他们可以住在歌珊。如果你知道他们中间有能干的人，可以派他们看管我的牲畜。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 47:10; 撒母耳记下 8:10; 撒母耳记上 2:20"> 约瑟又带父亲雅各去见法老，雅各就为法老祝福。</span>
<span className="v" id="v8" data-v="8"> 法老问雅各：“你多大岁数了？”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 39:12; 诗篇 39:5; 约伯记 14:1"> 雅各回答说：“我在世上寄居一百三十年了，我的日子又苦又短，不像我祖先当年那样高寿。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:7; 诗篇 129:8; 希伯来书 7:7"> 雅各为法老祝福后，就告退了。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 47:6; 出埃及记 1:11; 出埃及记 12:37"> 约瑟遵照法老之命把埃及最好的地方兰塞境内的土地给他父亲和弟兄们居住，作他们的产业。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 45:11; 提摩太前书 5:8; 创世记 47:1"> 约瑟按各家人口供应粮食给父亲、弟兄及其他家人。</span>
</div>
</div>

## 饥荒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:11; 列王纪上 18:5; 耶利米哀歌 4:9"> 饥荒很严重，到处都缺粮，埃及和迦南都饱受饥荒之苦。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:56; 路加福音 16:10–12; 路加福音 16:1–2"> 约瑟把埃及人和迦南人向他买粮的银子收集起来，存放在法老的库房里。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:8; 诗篇 37:3; 马太福音 6:11"> 埃及人和迦南人的银子都用光了，埃及人就来见约瑟，对他说：“我们的钱财都用光了，求你给我们粮食，免得我们饿死在你面前。”</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 但以理书 6:5–7; 哥林多前书 10:32"> 约瑟说：“你们的钱财如果用尽了，可以用你们的牲畜来交换粮食。”</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 2:4; 出埃及记 9:3; 以赛亚书 31:1"> 于是，他们把牲畜赶到约瑟那里，用他们的牛、羊、驴和马跟约瑟换粮食。那一年，他们就依靠换来的粮食生活。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:26; 耶利米书 38:9"> 到了第二年，他们又来见约瑟，对他说：“不瞒我主，我们的钱都用光了，牲畜也给我主了，除了我们自己和田地以外，我们一无所有。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 5:2–3; 约伯记 2:4; 耶利米哀歌 1:11"> 求你不要让我们人死地荒。我们愿意用自己和我们的田地来换粮食，我们和我们的田地都归法老。求你给我们种子，我们好活下去，不致饿死，土地也不致荒废。”</span>
<span className="v" id="v20" data-v="20"> 埃及人为饥荒所迫，纷纷卖掉自己的田地。约瑟替法老收购了埃及全国的田地，最后，所有的田地都归法老了。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:48"> 约瑟使埃及全境的人都成为法老的奴仆。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 7:24; 尼希米记 13:10; 帖撒罗尼迦后书 3:10"> 约瑟唯独没有买祭司的田地，因为祭司吃法老的俸禄，有足够的供给，不用卖地。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 112:5; 诗篇 41:1; 传道书 11:6"> 约瑟对百姓说：“我为法老买了你们和你们的土地，这里有种子，你们可以拿去耕种。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 41:34; 诗篇 41:1; 诗篇 112:5"> 但是你们在收成时要把五分之一给法老，其余的，你们可以留下来作种子和全家人的口粮。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 33:15; 箴言 11:26–27; 创世记 18:3"> 他们说：“你救了我们的命，愿你恩待我们，我们愿做法老的奴仆。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 47:22; 以西结书 7:24"> 于是，约瑟立下一条关于埃及土地的法令，到今天还有效，就是埃及出产的五分之一归给法老。只有祭司的田地不归法老。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 46:3; 出埃及记 1:7; 使徒行传 7:17"> 以色列人住在埃及的歌珊，在那里获得了产业，人口兴旺。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 90:10; 创世记 47:8–9; 创世记 37:2"> 雅各在埃及住了十七年，享年一百四十七岁。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 31:14; 创世记 24:49; 创世记 24:2"> 以色列快要离世的时候，把儿子约瑟叫来，说：“你如果恩待我，请把手放在我大腿底下起誓，你会以慈爱和信实待我，不把我葬在埃及。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 49:29–32; 创世记 23:19; 创世记 25:9"> 我与祖先同眠后，你要把我带出埃及，安葬在我祖先的墓地。”约瑟说：“我必照你说的做。”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 1:47; 希伯来书 11:21; 创世记 24:3"> 他要约瑟起誓，约瑟就向他起誓。于是，以色列在床头<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“在床头”或译“拄着拐杖”。">a</a></sup>敬拜上帝。</span>
</div>
</div>

## 约瑟遭陷害

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 37:28; 诗篇 105:17; 创世记 37:36"> 约瑟被以实玛利商人带到埃及，卖给了一个埃及人，他是法老的内臣护卫长波提乏。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 18:14; 诗篇 91:15; 耶利米书 15:20"> 约瑟住在他的埃及主人家中，耶和华与他同在，使他凡事亨通。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 1:3; 创世记 30:27; 马太福音 5:16"> 他主人看出耶和华与他同在，使他凡事亨通，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:21–22; 箴言 27:18; 创世记 19:19"> 就赏识他，让他服侍自己，派他管理自己的家务及其一切所有。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 撒母耳记下 6:11–12; 使徒行传 27:24"> 自从埃及人波提乏派约瑟管理自己家中一切事务以后，耶和华因为约瑟的缘故而赐福埃及人的家，使他家里和田间的一切都蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 16:12; 路加福音 19:17; 箴言 31:11"> 于是，波提乏把一切事都交给约瑟管理，除了自己要吃的食物以外，什么也不管。 约瑟体格健壮，相貌英俊。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 13:11; 以西结书 16:34; 彼得后书 2:14"> 后来，他主人的妻子看中了约瑟，向他眉目传情，要引诱他上床。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 约瑟拒绝了她，说：“我主人信任我，家里一切事务概不过问，都交给我管理。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 12:13; 创世记 20:6; 创世记 42:18"> 在这家里，没有人比我权力更大了，我主人把一切都交给了我，唯独你除外，因为你是他的妻子。我怎能做如此恶事得罪上帝呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 2:11; 创世记 39:8; 帖撒罗尼迦前书 5:22"> 但她还是每天勾引约瑟，约瑟不从，并尽量避开她。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:12; 以弗所书 5:3; 玛拉基书 3:5"> 一天，约瑟进屋里办事，那时屋里没有其他人。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:22; 箴言 7:13–27; 传道书 7:26"> 她抓住约瑟的外衣，硬要与他上床。约瑟丢下外衣，逃了出去。</span>
<span className="v" id="v13" data-v="13"> 她见约瑟丢下外衣逃了出去，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:21; 彼得前书 2:20; 诗篇 35:11"> 就叫来家里的人，对他们说：“你们看，我丈夫带回家的这个希伯来人戏弄我们！他进来要与我上床，我就大声呼喊，</span>
<span className="v" id="v15" data-v="15"> 他听见我大声喊叫，就把衣服丢在我这里，逃了出去。”</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:32; 耶利米书 4:22; 耶利米书 9:3–5"> 她把约瑟的外衣留在身边，等她丈夫回来后，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 23:1; 列王纪上 18:17; 诗篇 37:14"> 就对他说：“你带回来的那个希伯来奴隶进来要调戏我，</span>
<span className="v" id="v18" data-v="18"> 我大声喊叫，他就把衣服丢在我这里，逃了出去。”</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 4:5–6; 箴言 18:17; 箴言 6:34–35"> 波提乏听了妻子讲述约瑟如何对待她之后，勃然大怒，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 40:15; 提摩太后书 2:9; 诗篇 105:18–19"> 把约瑟关进王囚禁犯人的监牢。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:21; 以赛亚书 41:10; 彼得前书 3:17"> 约瑟坐牢的时候，耶和华与他同在，恩待他，使监狱长赏识他。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:3–4; 创世记 39:4; 撒母耳记上 2:30"> 监狱长把狱中所有囚犯及一切事务都交给约瑟管理。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:2; 创世记 39:2–3; 诗篇 1:3"> 凡交到约瑟手中的事情，监狱长都很放心，因为耶和华与约瑟同在，使他凡事亨通。</span>

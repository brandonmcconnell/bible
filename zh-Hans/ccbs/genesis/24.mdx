## 亚伯拉罕为以撒娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 112:1–3; 加拉太书 3:9; 马太福音 6:33"> 亚伯拉罕已经年迈，耶和华在一切事上都赐福给他。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 47:29; 创世记 39:4–6; 创世记 15:2"> 亚伯拉罕对负责他所有产业的老总管说：“请你把手放在我大腿底下，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 6:14–17; 创世记 26:34–35; 创世记 28:8"> 我要你凭掌管天地的上帝耶和华起誓，你不会找我所居之地的迦南女子做我儿子的妻子。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:2; 创世记 22:20–23; 创世记 12:7"> 你要回到我的家乡，在我的亲族中为以撒物色妻子。”</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 4:2; 出埃及记 9:2; 出埃及记 20:7"> 老总管问他：“如果那女子不肯跟我到这里来呢？我要把你儿子带回你的家乡吗？”</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:1; 彼得后书 2:20–22; 希伯来书 10:39"> 亚伯拉罕说：“你千万不可带我的儿子回那里！</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 33:2; 创世记 13:15; 希伯来书 1:14"> 因为带领我离开父家和本乡的天上的上帝耶和华，曾经向我说话，起誓应许把这片土地赐给我的后裔。祂必派天使在你前面引路，好让你在那里为我儿子找到妻子。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 2:17–20; 民数记 30:5; 民数记 30:8"> 如果那女子不肯跟你来，你也算履行了你向我起的誓，只是你不可带我儿子回那里。”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 24:2"> 于是，老总管就把手放在他主人亚伯拉罕的大腿底下，为这事向他起誓。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 11:31; 申命记 23:4; 创世记 27:43"> 老总管带着主人的十匹骆驼和各种上好的礼物，启程前往美索不达米亚，来到拿鹤住的城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:11; 出埃及记 2:16; 约翰福音 4:7"> 黄昏，妇女们出来打水的时候，他让骆驼跪在城外的井旁，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:27; 出埃及记 3:6; 创世记 26:24"> 然后祷告说：“我主人亚伯拉罕的上帝耶和华啊，求你施恩给我家主人亚伯拉罕，让事情今天能够成就。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 24:43; 诗篇 37:5; 出埃及记 2:16"> 现在，我站在这泉水旁，城里的女子正出来打水。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 6:37; 士师记 6:17; 创世记 15:8"> 如果我对哪个少女说‘请放下你的水罐，让我喝点水’，如果她说‘请喝，我也打水给你的骆驼喝’，愿那女子做你为自己的仆人以撒选定的妻子。这样，我就知道你施恩给我的主人了。”</span>
</div>
</div>

## 老总管井旁遇利百加

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="创世记 11:29; 创世记 24:45; 以赛亚书 65:24"> 老总管的话还没有说完，利百加肩上扛着水罐走出来。她是彼土利的女儿，彼土利是亚伯拉罕的兄弟拿鹤和密迦所生的儿子。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:7; 民数记 31:17–18; 创世记 39:6"> 利百加长得非常美丽，是个处女，没有男人亲近过她。她下到井旁，把水罐盛满了水后上来。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:7; 以赛亚书 21:14; 创世记 26:1–35"> 老总管跑上前去对她说：“求你给我一点水喝。”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 31:26; 彼得前书 3:8; 创世记 24:14"> 她回答说：“我主，请喝！”说完，立刻放下水罐，托在手上让他喝。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 24:14; 彼得前书 4:9; 创世记 24:45–46"> 等他喝完以后，利百加又说：“我再为你的骆驼打水，让它们喝饱。”</span>
<span className="v" id="v20" data-v="20"> 于是，她迅速把水罐里的水倒进水槽里，又跑到井边为所有的骆驼打水。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:43; 创世记 24:12; 撒母耳记下 7:18–20"> 老总管默不作声地注视着利百加，要看看耶和华是否使他此行顺利。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 16:11–12; 出埃及记 32:2–3; 创世记 23:15–16"> 骆驼喝过水以后，老总管拿出一只约六克重的金环和一对约一百一十克重的金镯给利百加，</span>
<span className="v" id="v23" data-v="23"> 对她说：“请问你是谁的女儿？你父亲家里有地方让我们住宿吗？”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 24:15; 创世记 22:23; 创世记 22:20"> 利百加回答说：“我是彼土利的女儿，我父亲是拿鹤和密迦的儿子。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 32:8; 彼得前书 4:9; 士师记 19:19–21"> 我家里有充足的粮草，也有地方让你留宿。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 24:48; 出埃及记 4:31; 创世记 24:52"> 老总管听了，就俯伏敬拜耶和华，</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 24:48; 创世记 24:12; 诗篇 98:3"> 说：“我主人亚伯拉罕的上帝耶和华当受称颂，因为祂一直以慈爱和信实对待我的主人。耶和华也一路引导我走到我主人兄弟的家里。”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 24:67; 创世记 24:55; 创世记 31:33"> 利百加跑回家中，把这事告诉了母亲家的人。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 29:5; 创世记 29:13; 创世记 24:55"> 利百加有个哥哥名叫拉班。</span>
<span className="v" id="v30" data-v="30"> 他看见妹妹的金环和手上的金镯，听了她叙述老总管的话，就跑到井旁，见老总管跟骆驼仍然站在那里，</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 3:10; 创世记 26:29; 诗篇 115:15"> 便对他说：“你这蒙耶和华赐福的人，请到我家。为什么站在外面呢？我已经为你预备好了房间，也为骆驼预备了地方。”</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 19:21; 创世记 43:24; 创世记 18:4"> 老总管就到了拉班的家里，拉班卸下骆驼背上的东西，给骆驼喂上草料，打水给老总管和随行的人洗脚。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 132:3–5; 提摩太前书 6:2; 以弗所书 6:5–8"> 然后晚餐准备好了，老总管却说：“不，等我说明来意后再吃。”拉班说：“请说。”</span>
<span className="v" id="v34" data-v="34"> 老总管说：“我是亚伯拉罕的仆人。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 24:1; 创世记 13:2; 箴言 10:22"> 耶和华赐给我主人极大的福气，使他非常富有。耶和华赐给他牛群、羊群、金子、银子、仆婢、骆驼和驴。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 25:5; 创世记 21:10; 创世记 21:1–7"> 我主人的妻子撒拉在晚年生了一个儿子，主人把所有的财产都给了他。</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 27:46; 以斯拉记 9:1–3; 创世记 24:2–9"> 主人要我起誓，他说，‘你不可给我的儿子娶我居住的迦南当地女子为妻，</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 24:4; 创世记 31:19; 创世记 12:1"> 你要到我家乡的亲族中为我儿子物色妻子。’</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:5"> 我问我的主人，‘如果那女子不愿意跟我回来怎么办？’</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 23:20; 诗篇 16:8; 创世记 5:24"> 他说，‘我忠心事奉的耶和华必派天使与你同行，使你一路顺利，为我儿子在家乡的亲族中物色妻子。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 24:8; 申命记 29:12"> 你去我亲族那里就是履行了你向我起的誓，如果我的亲族不肯把女子交给你，你也算履行了你向我起的誓。’</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 1:11; 创世记 24:12–14; 以斯拉记 8:21"> “今天我来到井旁时曾祷告说，‘我主人亚伯拉罕的上帝耶和华啊，求你使我一路顺利。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:13–14"> 我现在站在井旁，有女子出来打水的时候，我会对她说，请让我喝一点你罐里的水，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 24:14; 彼得前书 3:8; 创世记 2:22"> 如果她说，请喝，我也打水给你的骆驼喝，就让她做你为我家主人的儿子预备的妻子吧。’</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 7:7; 使徒行传 12:12–17; 创世记 24:15–20"> “我心中的话还没有说完，就看见利百加肩上扛着水罐到井旁打水。我上前向她要水喝，</span>
<span className="v" id="v46" data-v="46" data-xref="创世记 24:18–19"> 她就连忙放下肩上的水罐，说，‘请喝，我也打水饮你的骆驼。’我喝了，她又打水饮骆驼。</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 45:13–14; 创世记 24:22–24; 以赛亚书 62:3–5"> 我问她是谁家的女儿，她说，‘是拿鹤和密迦的儿子彼土利的女儿。’我就给她戴上金鼻环和金手镯，</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 3:5–6; 创世记 24:26–27; 诗篇 48:14"> 然后俯伏敬拜、颂赞我主人亚伯拉罕的上帝耶和华，祂引导我走对路，使我找到了我主人兄弟的孙女给我主人的儿子做妻子。</span>
<span className="v" id="v49" data-v="49" data-xref="创世记 47:29; 约书亚记 2:14; 箴言 3:3"> 现在，你们若愿意以慈爱和信实对待我的主人，答应这门亲事，请告诉我；如果不答应，也请告诉我，好让我知道应该怎么办。”</span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 118:23; 创世记 31:24; 创世记 31:29"> 拉班和彼土利回答说：“既然这是耶和华的安排，我们就无话可说了。</span>
<span className="v" id="v51" data-v="51" data-xref="创世记 20:15; 创世记 24:15; 撒母耳记下 16:10"> 你看，利百加就在这里，你可以照耶和华的话，把她带回去给你主人的儿子做妻子。”</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 24:26; 创世记 24:48; 诗篇 116:1–2"> 亚伯拉罕的老总管听见这话，就俯伏在地上敬拜耶和华，</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 24:22; 创世记 24:10; 出埃及记 12:35"> 然后拿出金银首饰和衣裳送给利百加，又把贵重的礼物送给她的哥哥和母亲。</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 24:56; 创世记 24:59; 创世记 28:5–6"> 老总管和随行的人用过晚饭以后，在那里住了一夜。早晨，老总管说：“请让我返回我主人那里。”</span>
<span className="v" id="v55" data-v="55" data-xref="创世记 4:3; 利未记 25:29; 士师记 14:8"> 但利百加的哥哥和母亲说：“让她和我们住上十来天再去吧！”</span>
<span className="v" id="v56" data-v="56" data-xref="箴言 25:25; 约书亚记 1:8; 以赛亚书 48:15"> 可是，老总管说：“既然耶和华已经使我一路顺利，请你们不要挽留我，请让我回到我主人那里。”</span>
<span className="v" id="v57" data-v="57"> 他们说：“我们问问利百加的意见吧。”</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:38; 诗篇 45:10–11"> 他们就叫来利百加，问她：“你愿意跟这个人同去吗？”利百加说：“我愿意！”</span>
<span className="v" id="v59" data-v="59" data-xref="创世记 35:8; 民数记 11:12; 创世记 24:50"> 于是，他们让妹妹利百加和她的奶妈跟老总管及随行的人一同离去，</span>
<span className="v" id="v60" data-v="60" data-xref="创世记 22:17; 创世记 17:16; 路得记 4:11–12"> 并为利百加祝福，说：<br /><span className="pl pl-1">“我们的妹妹啊，</span><br /><span className="pl pl-1">愿你成为千万人之母！</span><br /><span className="pl pl-1">愿你的后裔占领敌城！”</span></span>
</div>

## 以撒与利百加成婚

<div className="bt">
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="诗篇 45:10; 创世记 2:24; 以斯帖记 8:14"> 于是，利百加和她的婢女们准备妥当，骑上骆驼，跟着老总管离去。老总管就这样带着利百加走了。</span>
<span className="v" id="v62" data-v="62" data-xref="创世记 25:11; 创世记 16:14; 创世记 12:9"> 那时，以撒住在南地，他刚从庇耳·拉海·莱回来。</span>
<span className="v" id="v63" data-v="63" data-xref="诗篇 119:15; 诗篇 1:2; 诗篇 104:34"> 傍晚的时候，以撒来到田间默想，他抬头一看，见一队骆驼迎面而来。</span>
<span className="v" id="v64" data-v="64" data-xref="士师记 1:14; 约书亚记 15:18"> 利百加抬头看见以撒，就从骆驼上下来，</span>
<span className="v" id="v65" data-v="65" data-xref="提摩太前书 2:9; 哥林多前书 11:5–6; 哥林多前书 11:10"> 问老总管：“那从田间来迎接我们的是谁？”老总管说：“是我的主人！”利百加听了就蒙上面纱。</span>
<span className="v" id="v66" data-v="66" data-xref="马可福音 6:30"> 老总管向以撒讲述整个事情的经过。</span>
<span className="v" id="v67" data-v="67" data-xref="雅歌 8:2; 以弗所书 5:22–33; 创世记 23:1–2"> 以撒就带利百加进入他母亲撒拉的帐篷，娶她为妻，并且爱她。自从母亲去世后，以撒这才得到安慰。</span>
</div>

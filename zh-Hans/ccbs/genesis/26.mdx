## 以撒寄居基拉耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 25:11; 创世记 21:22–32"> 亚伯拉罕在世的时候，那地方闹过一次饥荒，这时又遭遇饥荒。以撒就迁到基拉耳的非利士王亚比米勒那里。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:7; 诗篇 37:3; 创世记 17:1"> 耶和华向以撒显现说：“不要下埃及去，要住在我指示你住的地方。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 诗篇 105:9; 创世记 17:8"> 你寄居在这里，我必与你同在，赐福给你，因为我必把这些土地赐给你和你的后代，坚立我对你父亲亚伯拉罕的誓约。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 3:25; 创世记 15:5; 创世记 22:17–18"> 我必使你的后代多如天上的繁星，将这些土地都赐给他们，天下万国必因你的后裔而蒙福。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 7:24; 创世记 22:18; 创世记 22:16"> 因为亚伯拉罕听从我的话，遵守我的吩咐、命令、典章和律法。”</span>
</div>
</div>

## 亚比米勒斥责以撒

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 20:1"> 于是，以撒就在基拉耳住下来。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 创世记 12:13; 创世记 20:2"> 那里的人问起他的妻子时，他便说：“她是我妹妹。”他不敢说：“她是我妻子。”他担心当地的人会因为利百加而杀害他，因为利百加长得非常美丽。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 62:5; 箴言 5:18–19; 箴言 7:6"> 以撒在那里住了许久。一天，非利士王亚比米勒从窗口看见以撒在爱抚利百加，</span>
<span className="v" id="v9" data-v="9"> 便召见以撒，问他：“她明明是你妻子，为什么你说她是你妹妹呢？”以撒回答说：“我担心别人为了她而杀害我！”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 20:9–10; 创世记 12:18–19"> 亚比米勒说：“你怎么可以这样对我们呢？万一百姓中有人占有了她，你就使我们陷入罪中了。”</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 105:15; 创世记 20:6; 箴言 6:29"> 于是，亚比米勒下令全国：“凡伤害他们二人的，必被处死。”</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:8; 创世记 24:1; 创世记 26:3"> 以撒在那里耕种，耶和华赐福给他，那一年他得了百倍的收成。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 112:3; 箴言 10:22; 创世记 24:35"> 他的财富越来越多，成了大富户。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 37:11; 创世记 13:2; 箴言 27:4"> 他拥有很多的牛羊和仆婢，非利士人嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 21:30; 创世记 21:25"> 他父亲亚伯拉罕生前派人挖的那些水井，全被非利士人用土塞住了。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:9"> 亚比米勒对以撒说：“请你离开我们吧，因为你太强盛了。”</span>
<span className="v" id="v17" data-v="17"> 以撒就离开那里，把帐篷迁往基拉耳谷居住。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 13:2; 何西阿书 2:17; 民数记 32:38"> 他的父亲亚伯拉罕生前挖的水井都被非利士人塞住了，以撒便重新挖开，并沿用父亲生前给那些水井起的名字。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 4:10–11; 约翰福音 7:38; 雅歌 4:15"> 以撒的牧人在谷中挖得一口活水井，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:25"> 基拉耳的牧人与以撒的牧人争吵起来，都说：“这口井是我们的。”于是，以撒便称那口井为埃色<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“埃色”意思是“相争”。">a</a></sup>，因为他们与他相争。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:6"> 后来，以撒的仆人又挖了一口井，他们双方又为那口井发生争执，以撒便称那口井为西提拿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“西提拿”意思是“敌对”。">b</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 17:6; 出埃及记 1:7; 诗篇 118:5"> 以撒离开那里，又挖了一口水井。这次，他们没有为那口井争吵。所以，以撒称那口井为利河伯<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“利河伯”意思是“宽阔之地”。">c</a></sup>。以撒说：“如今耶和华给了我们一个宽阔的地方，我们可以在这里繁荣兴旺。”</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:1; 创世记 21:31; 创世记 46:1"> 以撒从那里上别示巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 15:1; 出埃及记 3:6; 以赛亚书 43:1–2"> 当晚，耶和华向他显现说：“我是你父亲亚伯拉罕的上帝。你不要害怕，因为我与你同在。为了我仆人亚伯拉罕的缘故，我必赐福给你，使你人丁兴旺。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 13:18; 诗篇 116:17; 创世记 12:7–8"> 以撒在那里筑了一座坛求告耶和华的名，并且在那里搭起帐篷住下来。他的仆人又在那里挖了一口井。</span>
</div>
</div>

## 以撒和亚比米勒起誓立约

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 21:22–32; 创世记 20:3"> 一天，亚比米勒带着他的参谋亚户撒、将领非各从基拉耳来见以撒。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:16; 士师记 11:7; 使徒行传 7:14"> 以撒说：“你们既然憎恨我，把我赶走，为什么又来找我？”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 21:22–23; 以赛亚书 45:14; 以赛亚书 61:9"> 他们回答说：“我们清楚知道耶和华与你同在，我们双方应该订立誓约。我们要跟你立约，</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 24:31; 创世记 21:22; 创世记 22:17"> 使你不伤害我们，就像我们没有侵犯你，总是善待你，让你平安地离开一样。你是蒙耶和华赐福的人。”</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 19:3; 罗马书 12:18; 希伯来书 12:14"> 于是，以撒为他们摆设宴席，一同吃喝。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 20:16–17; 希伯来书 6:16; 创世记 25:33"> 第二天早晨，以撒和他们互相起誓之后，送他们平安地离去。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 当天，以撒的仆人将挖井的事告诉他，说：“我们找到水了。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 21:31; 创世记 26:28"> 以撒便称那口井为示巴<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“示巴”意思是“誓约”。">d</a></sup>，因此那城叫别示巴，沿用至今。</span>
</div>
</div>

## 以扫娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 36:2; 创世记 36:13; 出埃及记 34:16"> 以扫四十岁时，娶了赫人比利的女儿犹蒂与赫人以伦的女儿巴实抹。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 27:46–2; 创世记 28:8; 创世记 6:2"> 她们二人常使以撒和利百加伤心。</span>
</div>

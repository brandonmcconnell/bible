## 亚伯拉罕买地葬撒拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:17"> 撒拉享年一百二十七岁。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 23:19; 创世记 13:18; 历代志上 6:57"> 她在迦南境内的基列·亚巴，即希伯仑去世。亚伯拉罕在那里痛哭，哀悼她。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 10:15; 创世记 23:7; 撒母耳记上 26:6"> 他从亡妻旁边站起来对赫人说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:15; 希伯来书 11:9; 创世记 17:8"> “我在你们中间是异乡客旅，请你们给我一块坟地，我好埋葬我的亡妻。”</span>
<span className="v" id="v5" data-v="5"> 赫人答道：</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:35; 创世记 14:14; 出埃及记 32:22"> “我主，请听我们说，你在我们中间是一位尊贵的王子，你可以选我们这里最好的坟地，没有人会反对你使用他的坟地埋葬你的妻子。”</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:14; 创世记 19:1; 箴言 18:24"> 亚伯拉罕就起身向当地的赫人下拜，说：</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 25:9; 约翰一书 2:1–2; 列王纪上 2:17"> “如果你们愿意让我安葬亡妻，就请答应我，代我求琐辖的儿子以弗仑，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 13:8; 罗马书 12:17"> 把他地头的麦比拉洞卖给我。请他当着你们的面按实价卖给我作坟地。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 34:20; 创世记 34:24; 创世记 23:18"> 当时以弗仑正坐在赫人当中，于是他当着所有出入城门口的赫人答复亚伯拉罕说：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以赛亚书 32:8; 申命记 19:15"> “不可！我主，请听我说，我当着族人的面，把那块地和其中的山洞送给你。去安葬你的死者吧！”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 23:7; 创世记 18:2; 创世记 19:1"> 亚伯拉罕向当地的人下拜，</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:8; 撒母耳记下 24:24; 创世记 14:22–23"> 当众对以弗仑说：“你若愿意，请听我说，我要把地钱给你，请你收下，好让我在那里安葬我的妻子。”</span>
<span className="v" id="v14" data-v="14"> 以弗仑回答说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 45:12; 出埃及记 30:13; 出埃及记 30:15"> “我主，请听我说，九十两银子的地对你我来说算什么呢？去安葬你的妻子吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 11:12; 耶利米书 32:9; 出埃及记 30:13"> 于是，亚伯拉罕听了以弗仑的意思，就照当众提出的价钱，按市价秤了九十两银子给他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 25:9; 创世记 50:13; 创世记 23:20"> 这样，以弗仑在麦比拉、靠近幔利的那块地和山洞及地界内所有的树木，</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 4:1; 耶利米书 32:12; 创世记 34:20"> 都归了亚伯拉罕。这是在城门口的赫人面前买下的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 50:13; 传道书 12:7; 传道书 12:5"> 之后，亚伯拉罕把妻子撒拉安葬在迦南的幔利附近、麦比拉田间的洞里。幔利就是希伯仑。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 32:10–14; 路得记 4:7–10; 创世记 49:31–32"> 这块赫人的地和其中的山洞从此成了亚伯拉罕家的坟地。</span>
</div>
</div>

</div>

## 雅各祝福以法莲和玛拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 41:50–52; 创世记 46:20; 诗篇 128:6"> 后来，有人来通知约瑟，说他父亲病了，约瑟就带着两个儿子玛拿西和以法莲去探望父亲。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:10; 撒母耳记上 23:16; 申命记 3:28"> 雅各听说他儿子约瑟来了，就强撑着从床上坐起来，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 35:9–12; 出埃及记 6:3; 创世记 28:3"> 对约瑟说：“全能的上帝曾经在迦南的路斯向我显现，赐福给我。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 17:8; 创世记 35:11; 创世记 26:4"> 祂对我说，‘我必使你生养众多，人丁兴旺，并把迦南赐给你的子孙永远作产业。’</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 41:50–52; 约书亚记 14:4; 创世记 46:20"> “我来之前，你在埃及生的两个儿子以法莲和玛拿西都算我的，他们跟吕便和西缅一样是我的。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:4"> 除了他们以外，你其他子女仍然归你，这些子女可以在他们弟兄的名下继承产业。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:16–19; 马太福音 2:18; 创世记 35:9"> 我从巴旦回来的路上，拉结死在了迦南，那地方离以法他还有一段路程，我把她葬在通往以法他的路旁。”以法他就是伯利恒。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 以色列看见约瑟的两个儿子，就问：“他们是谁？”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 27:4; 创世记 33:5; 希伯来书 11:21"> 约瑟说：“是上帝在这里赐给我的儿子。”以色列说：“把他们带过来，我要祝福他们。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:1; 创世记 27:27; 撒母耳记上 3:2"> 以色列年纪老迈，眼睛昏花，看不清楚。约瑟把儿子带到他面前，他就亲吻他们、拥抱他们。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:20; 创世记 45:26; 创世记 42:36"> 以色列对约瑟说：“我以为再也见不到你了，上帝竟然还让我见到了你的儿子！”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:6; 利未记 19:32; 创世记 19:1"> 约瑟把两个儿子从以色列的膝上领开，自己向父亲俯伏下拜，</span>
<span className="v" id="v13" data-v="13"> 随后左手牵着玛拿西，右手牵着以法莲，把他们分别领到以色列的右边和左边。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:51; 诗篇 118:16; 马太福音 19:15"> 但以色列却两手交叉，把右手放在约瑟次子以法莲的头上，左手放在约瑟长子玛拿西的头上。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:1; 歌罗西书 2:6; 以赛亚书 33:16"> 他祝福约瑟说：“愿我祖先亚伯拉罕和以撒敬拜的上帝，就是牧养我一生直到今天的上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 34:22; 创世记 49:22; 创世记 48:5"> 救我脱离一切患难的天使，赐福这两个孩子。愿我和我祖先亚伯拉罕及以撒的名字借着他们流传。愿他们在地上子孙兴旺。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 48:14; 罗马书 9:7–8; 历代志上 21:7"> 约瑟见父亲把右手放在以法莲的头上，感到不悦，就把父亲的右手从以法莲的头上挪到玛拿西头上，</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 19:18; 创世记 29:26; 创世记 43:33"> 对父亲说：“父亲，你弄错了，这才是长子，你应该把右手按在他的头上。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 33:17; 民数记 1:33–35; 创世记 25:28"> 他父亲却不同意，说：“我儿啊，我知道，我知道。他必发展成一个强大的民族，但他弟弟将比他更强大，他弟弟的后裔必成为多个民族。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:60; 路得记 4:11–12; 创世记 28:3"> 雅各那天祝福他们，说：“以色列人必引用你们的名祝福人，说，‘愿上帝使你们像以法莲和玛拿西一样！’”他把以法莲排在玛拿西前面。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 50:24; 创世记 46:4; 创世记 28:15"> 以色列对约瑟说：“我快死了，但上帝必与你们同在，带你们回到你们祖先的土地。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:5; 约书亚记 24:32; 历代志上 5:2"> 我要把我用刀和弓从亚摩利人手上夺来的那块地留给你，让你比其他弟兄多得一份。”</span>
</div>
</div>

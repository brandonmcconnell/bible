## 雅各预备见以扫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:4"> 雅各继续前行，上帝的天使遇见了他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 2:8; 约书亚记 5:14; 约书亚记 21:38"> 雅各看见他们，就说：“这是上帝的军队！”于是称那地方为玛哈念<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛哈念”意思是“两营军队”。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 25:30; 约书亚记 24:4; 申命记 2:5"> 雅各先派使者到西珥，就是以东地区，去见他哥哥以扫，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 3:6; 路加福音 14:11; 创世记 33:8"> 并吩咐他们：“你们要这样对我主以扫说，‘你仆人雅各说他一直寄居在拉班家里，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:8; 创世记 33:15; 创世记 33:11"> 现在他带了牛羊、驴和仆婢回来见我主，派我们来报信，希望在你面前蒙恩。’”</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 33:1; 创世记 32:8; 创世记 32:11"> 报信的人回到雅各那里，说：“我们到了你哥哥以扫那里，他正带着四百人前来见你。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 哥林多后书 1:8–10; 出埃及记 14:10"> 雅各听了非常害怕，忧心忡忡，便把随从、牛群、羊群和骆驼分成两队，</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:16; 创世记 33:1–3"> 心想：“如果以扫来攻击一队，另一队还可以逃生。”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:42; 诗篇 34:4–6; 创世记 31:3"> 他祷告说：“耶和华，我祖父亚伯拉罕和我父亲以撒的上帝啊！你吩咐我回到家乡和亲族那里，答应厚待我。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:35; 创世记 24:27; 撒母耳记下 7:18"> 我不配蒙你以慈爱和信实相待，我先前过约旦河的时候，手上只有一根杖，现在却有两队人畜。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 59:1–2; 箴言 18:19; 马太福音 6:13"> 求你救我脱离我哥哥以扫的手，我怕他会来杀我和我的妻儿。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 28:13–15; 希伯来书 6:17; 提多书 1:2"> 然而，你曾说，‘我必厚待你，使你的后代多如海沙，不可胜数。’”</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 创世记 43:11; 箴言 19:6"> 那天晚上，雅各就在那里过夜，又从产业中挑选牲畜送给哥哥以扫作礼物：</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 1:3; 申命记 8:18; 约伯记 42:12"> 母山羊二百只、公山羊二十只、母绵羊二百只、公绵羊二十只、</span>
<span className="v" id="v15" data-v="15"> 哺乳的骆驼三十头及其小骆驼、母牛四十头、公牛十头、母驴二十头、公驴十头。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 33:8–9; 创世记 32:20; 箴言 2:11"> 雅各把牲畜每类分成一群，交给仆人看管，对他们说：“你们走在前头，每群牲畜之间要保持一段距离！”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 33:3"> 又吩咐走在最前面的仆人说：“我哥哥以扫遇到你的时候，如果问你是谁家的人？要到哪里去？你前头这些牲畜是谁的？</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 32:4–5"> 你就说，‘是你仆人雅各的，是送给他主人以扫的礼物，他自己就在后面。’”</span>
<span className="v" id="v19" data-v="19"> 雅各又吩咐赶第二群、第三群及其余牲畜的仆人遇见以扫时也要这样回答，</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 42:8–9; 箴言 21:14; 创世记 43:11"> 并且一定要说：“你仆人雅各就在后面。”雅各想先用礼物去化解以扫的怨恨，也许见面时以扫会善待他。</span>
<span className="v" id="v21" data-v="21"> 于是，他派人先把礼物送过去，自己则留在营里过夜。</span>
</div>
</div>

## 雅各遇见上帝

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 3:16; 申命记 2:37; 提摩太前书 5:8"> 当夜，雅各起来带着两个妻子、两个婢女和十一个儿子渡过雅博渡口。</span>
<span className="v" id="v23" data-v="23"> 雅各把他们连同一切所有都送过河以后，</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿书 12:3–5; 以弗所书 6:12; 路加福音 13:24"> 自己独自留下。有一个人来和他摔跤，直到黎明。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 12:7–9; 何西阿书 12:3–4; 马太福音 26:41"> 那人见胜不过雅各，就在他的大腿窝摸了一下，他大腿的关节就脱臼了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 12:4; 诗篇 115:12–13; 哥林多后书 12:8–9"> 那人说：“天亮了，让我走吧！”但雅各说：“你不祝福我，我就不让你走。”</span>
<span className="v" id="v27" data-v="27"> 那人问道：“你叫什么名字？”他说：“我叫雅各。”</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 2:17; 创世记 35:10; 以赛亚书 62:2–4"> 那人说：“你以后不要再叫雅各了，你要叫以色列，因为你跟上帝和人角力都得胜了。”</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:6; 士师记 13:16–18; 约伯记 11:7"> 雅各说：“请你告诉我你的名字。”那人说：“你为什么问我的名字？”他就在那里给雅各祝福。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:10–11; 民数记 12:8; 以赛亚书 6:5"> 雅各称那地方为毗努伊勒，因为他说：“我面对面见过上帝，竟能活命。”</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 12:7; 创世记 19:15; 士师记 8:8"> 雅各经过毗努伊勒的时候，太阳出来了，那时他的大腿瘸了。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 5:5"> 以色列人至今都不吃大腿窝的筋，因为那人摸过雅各大腿窝的筋。</span>
</div>

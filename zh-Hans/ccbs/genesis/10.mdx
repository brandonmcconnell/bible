## 挪亚三个儿子的后代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 2:4; 创世记 9:7; 创世记 5:1"> 洪水以后，挪亚的儿子闪、含和雅弗都生了儿子，以下是他们的后代。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 38:2; 以西结书 38:6; 启示录 20:8"> 雅弗的儿子是歌篾、玛各、玛代、雅完、土巴、米设、提拉。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 27:14; 耶利米书 51:27"> 歌篾的儿子是亚实基拿、利法、陀迦玛。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 11:30; 以赛亚书 23:12; 民数记 24:24"> 雅完的儿子是以利沙、他施、基提、多单。</span>
<span className="v" id="v5" data-v="5" data-xref="西番雅书 2:11; 以赛亚书 42:4; 耶利米书 2:10"> 雅弗的这些后代各按宗族、语言和民族分散在沿海自己的国土上。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 1:8–16; 以西结书 27:10; 诗篇 105:23"> 含的儿子是古实、麦西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“麦西”希伯来文是Mizraim，就是“埃及”，13节亦同。">a</a></sup>、弗、迦南。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 27:22; 以西结书 27:15; 以赛亚书 21:13"> 古实的儿子是西巴、哈腓拉、撒弗他、拉玛、撒弗提迦。拉玛的儿子是示巴和底但。</span>
<span className="v" id="v8" data-v="8" data-xref="弥迦书 5:6"> 古实也是宁录之父，宁录是世上第一位勇士，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 28:22; 创世记 6:11; 创世记 25:27"> 在耶和华眼中是个孔武有力的猎人，因此有俗话说：“要像宁录那样在耶和华眼中是个孔武有力的猎人。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 11:9; 创世记 11:2; 创世记 14:1"> 他首先在示拿地区的巴别、以力、亚甲、甲尼各地建国，</span>
<span className="v" id="v11" data-v="11" data-xref="弥迦书 5:6; 诗篇 83:8; 那鸿书 1:1"> 后来扩展到亚述，在那里建立了尼尼微、利河伯、迦拉，</span>
<span className="v" id="v12" data-v="12"> 以及尼尼微与迦拉之间的利鲜大城。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:11–12; 耶利米书 46:9; 以西结书 30:5"> 麦西的后代有路低人、亚拿米人、利哈比人、拿弗土希人、</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 47:4; 历代志上 1:12; 申命记 2:23"> 帕斯鲁细人、迦斯路希人和迦斐托人。非利士人是迦斐托人的后代。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 34:2–15; 出埃及记 34:11; 创世记 23:3"> 迦南生长子西顿和次子赫，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 24:18; 士师记 1:21; 撒迦利亚书 9:7"> 他的后代还有耶布斯人、亚摩利人、革迦撒人、</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 34:2"> 希未人、亚基人、西尼人、</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 18:22; 撒母耳记下 8:9; 以西结书 27:8"> 亚瓦底人、洗玛利人和哈马人。后来迦南各宗族散居在各地。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 14:2; 创世记 19:24–25; 约书亚记 12:7–8"> 迦南的疆域从西顿向基拉耳延伸，远至迦萨，再向所多玛、蛾摩拉、押玛、洗扁延伸，远至拉沙。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 10:6; 创世记 11:1–9"> 以上记载的都是含的子孙，他们根据自己的宗族、语言、国土和民族散居各处。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 24:24; 创世记 11:10–26"> 雅弗的哥哥闪是希伯子孙的祖先，他也生了儿子。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 66:19; 耶利米书 25:25; 创世记 14:1–9"> 闪的儿子是以拦、亚述、亚法撒、路德、亚兰。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 1:1; 耶利米书 25:20"> 亚兰的儿子是乌斯、户勒、基帖、玛施。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:35; 创世记 11:12–15"> 亚法撒生沙拉，沙拉生希伯，</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 1:19; 创世记 10:32; 申命记 32:8"> 希伯有两个儿子，一个名叫法勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“法勒”意思是“分开”。">b</a></sup>，因为那时人们分地而居。法勒的兄弟叫约坍。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 1:20–28"> 约坍生亚摩答、沙列、哈萨玛非、耶拉、</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 1:20–28"> 哈多兰、乌萨、德拉、</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 1:20–28; 列王纪上 10:1; 创世记 25:3"> 俄巴路、亚比玛利、示巴、</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 9:28; 历代志上 9:13; 创世记 2:11"> 阿斐、哈腓拉、约巴。这些都是约坍的儿子。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 23:7"> 他们居住的地方，从米沙直到东边的西发山区。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 10:5; 创世记 10:20; 使徒行传 17:26"> 以上记载的都是闪的子孙，他们按着自己的宗族、语言、国土和民族散居各处。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 9:19; 使徒行传 17:26; 创世记 10:1"> 这些人都是洪水以后挪亚三个儿子所生的子孙，他们按着自己的民族和家系散居在各地，繁衍出地上各个民族。</span>

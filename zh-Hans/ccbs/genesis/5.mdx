## 亚当的后代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 4:24; 歌罗西书 3:10; 创世记 1:26–27"> 以下是关于亚当后代的记载。<br />上帝造人的时候，是照祂自己的样式造的。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:4; 马可福音 10:6; 创世记 2:23"> 祂造了男人和女人，又赐福给他们，并在造他们的那日称他们为“人”。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 4:25; 约伯记 25:4; 诗篇 51:5"> 亚当一百三十岁时生了一子，样式和形象与自己相似，就给他取名叫塞特。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 1:1–3; 路加福音 3:36–38; 创世记 5:26"> 亚当生了塞特以后，又活了八百年，生儿育女，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 5:8; 创世记 5:11; 创世记 3:19"> 共活了九百三十岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 4:26"> 塞特一百零五岁时生以挪士，</span>
<span className="v" id="v7" data-v="7"> 之后又活了八百零七年，生儿育女，</span>
<span className="v" id="v8" data-v="8"> 共活了九百一十二岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:37; 历代志上 1:2"> 以挪士九十岁时生该南，</span>
<span className="v" id="v10" data-v="10"> 之后又活了八百一十五年，生儿育女，</span>
<span className="v" id="v11" data-v="11"> 共活了九百零五岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:37"> 该南七十岁时生玛勒列，</span>
<span className="v" id="v13" data-v="13"> 之后又活了八百四十年，生儿育女，</span>
<span className="v" id="v14" data-v="14"> 共活了九百一十岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 1:2"> 玛勒列六十五岁时生雅列，</span>
<span className="v" id="v16" data-v="16"> 之后又活了八百三十年，生儿育女，</span>
<span className="v" id="v17" data-v="17"> 共活了八百九十五岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 4:17; 历代志上 1:3; 犹大书 1:14–15"> 雅列一百六十二岁时生以诺，</span>
<span className="v" id="v19" data-v="19"> 之后又活了八百年，生儿育女，</span>
<span className="v" id="v20" data-v="20"> 共活了九百六十二岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:37"> 以诺六十五岁时生玛土撒拉，</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:12; 创世记 17:1; 创世记 6:9"> 之后与上帝亲密同行三百年，生儿育女，</span>
<span className="v" id="v23" data-v="23"> 共活了三百六十五岁。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 11:5–6; 约翰一书 1:7; 创世记 5:22"> 以诺与上帝亲密同行，后来被上帝接去，不在世上了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 4:18"> 玛土撒拉一百八十七岁时生拉麦，</span>
<span className="v" id="v26" data-v="26"> 之后又活了七百八十二年，生儿育女，</span>
<span className="v" id="v27" data-v="27"> 共活了九百六十九岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 拉麦一百八十二岁时生了一个儿子，</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 2:5; 希伯来书 11:7; 马太福音 24:37"> 取名叫挪亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯来文中“挪亚”与“安慰”谐音。">a</a></sup>，他说：“耶和华咒诅了大地，这孩子必使我们从艰辛劳苦中得安慰。”</span>
<span className="v" id="v30" data-v="30"> 拉麦生挪亚之后，又活了五百九十五年，生儿育女，</span>
<span className="v" id="v31" data-v="31"> 共活了七百七十七岁才去世。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 6:10; 创世记 10:21; 创世记 9:18–19"> 挪亚五百岁后生闪、含和雅弗。</span>
</div>
</div>

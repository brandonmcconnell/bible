## 上帝再次与亚伯兰立约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 4:13; 以弗所书 3:20; 路加福音 1:6"> 亚伯兰九十九岁那年，耶和华向他显现说：“我是全能的上帝。你要遵行我的旨意，做纯全无过的人。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:4–6; 创世记 12:2; 诗篇 105:8–11"> 我要与你立约，我要使你子孙极其繁盛。”</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 13:20; 创世记 17:17; 民数记 16:45"> 亚伯兰就俯伏在地，上帝又对他说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:11; 加拉太书 3:28–29; 创世记 12:2"> “我要与你立约，你必成为万族之父。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 1:21–23; 尼希米记 9:7; 创世记 17:15"> 以后你的名字不再叫亚伯兰，要改为亚伯拉罕<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚伯拉罕”意思是“万族之父”。">a</a></sup>，因为我已立你为万族之父。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 17:4; 马太福音 1:6–17; 创世记 35:11"> 我要使你生养众多，民族必由你而生，君王必从你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–9; 使徒行传 2:39; 创世记 26:24"> 我要和你并你的子子孙孙立永远的约，我要做你和你子孙的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 26:12; 诗篇 105:11; 出埃及记 6:7"> 我要把你现在寄居的整个迦南赐给你和你的子孙永远作产业，我也必做他们的上帝。”</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 56:4–5; 诗篇 25:10; 诗篇 103:18"> 上帝又对亚伯拉罕说：“你和你的子孙世世代代都要遵守我的约。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:11–12; 罗马书 4:9–11; 使徒行传 7:8"> 你们所有的男子都要受割礼，这是我与你和你的子孙所立的约，你们要遵守。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:11; 使徒行传 7:8; 申命记 10:16"> 你们都要割包皮，作为我与你们立约的记号。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 12:3; 路加福音 2:21; 出埃及记 12:48–49"> 你们世世代代的男子在出生后的第八日都要接受割礼，包括在你家里出生的和用钱从外族人那里买来的奴仆。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 12:44; 创世记 37:36; 尼希米记 5:8"> 不论是在你家里生的，还是你用钱买来的男子，都要接受割礼，这样我的约就在你们的肉体上成为永远的约。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 4:24–26; 民数记 15:30–31; 出埃及记 12:19"> 任何没有接受割礼的男子，要将他从民中铲除，因为他违背了我的约。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:25; 创世记 32:28; 创世记 17:5"> 上帝对亚伯拉罕说：“你的妻子撒莱以后不要叫撒莱，她的名字要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:11; 创世记 17:6; 以赛亚书 49:23"> 我必赐福给她，让她为你生一个儿子。我必赐福给她，让她成为列国之母，列邦的君王必从她而出。”</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 11:16; 创世记 21:6; 创世记 18:12"> 亚伯拉罕就俯伏在地，笑了起来，心想：“一百岁的人还能有孩子吗？撒拉已经九十岁了，还能生育吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 2:39; 诗篇 41:12; 诗篇 4:6"> 亚伯拉罕对上帝说：“愿以实玛利蒙你赐福。”</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 创世记 21:2–3; 列王纪下 4:16–17"> 上帝说：“不，你妻子撒拉必为你生一个儿子，你要给他取名叫以撒，我必与他坚立我的约，作为他后代永远的约。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:18; 创世记 21:13; 创世记 25:12–18"> 至于以实玛利，我已听见你的祈求，我必赐福给他，使他生养众多、子孙极其繁盛。他必做十二个族长的父亲，我必使他成为大国。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:2–3; 创世记 26:2–5; 加拉太书 3:29"> 撒拉必在明年这时候给你生以撒，我必向他坚守我的约。”</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 18:33; 创世记 35:9–15; 士师记 6:21"> 上帝说完以后，便离开亚伯拉罕上升而去。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:60; 创世记 18:19; 创世记 17:10–14"> 亚伯拉罕就在那天照着上帝的吩咐，为儿子以实玛利和家中所有的男子，不论是在家中出生的，还是买回来的，都行了割礼。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 4:11; 创世记 17:17; 罗马书 4:19–20"> 亚伯拉罕接受割礼的时候九十九岁。</span>
<span className="v" id="v25" data-v="25"> 他的儿子以实玛利接受割礼的时候十三岁。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 119:60; 创世记 22:3–4; 创世记 12:4"> 他们父子二人就在那天接受了割礼。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 18:19"> 亚伯拉罕家里所有的男子，包括家中出生的和买回来的，都一起接受了割礼。</span>
</div>

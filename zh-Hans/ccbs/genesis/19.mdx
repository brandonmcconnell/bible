## 上帝毁灭所多玛和蛾摩拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 18:22; 创世记 18:1–5; 希伯来书 13:2"> 那两个天使在黄昏的时候来到所多玛，罗得正坐在城门口，看见他们，便起来迎接，俯伏在地上说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 18:4; 路加福音 24:28–29; 希伯来书 13:2"> “我主啊，请到仆人家洗洗脚，住一夜，早上再继续赶路吧！”他们说：“不，我们要在街上过夜。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 18:6–8; 士师记 6:19; 撒母耳记上 28:24"> 罗得执意邀请他们，他们便跟着进了他家。罗得设宴款待他们，烤了无酵饼，他们就吃了。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 13:13; 箴言 4:16; 出埃及记 23:2"> 他们正准备就寝的时候，所多玛城的男人从老到少全都出来，团团围住罗得的房子，</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 以赛亚书 3:9; 犹大书 1:7"> 对罗得大喊大叫：“今晚到你家中作客的人在哪里？把他们交出来，我们要跟他们交合！”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:23"> 罗得走出来，随手关上门，到众人面前，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 6:9–11; 士师记 19:23; 利未记 20:13"> 对他们说：“各位弟兄，请不要做这种邪恶的事！</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 19:24; 创世记 19:31–38; 士师记 9:15"> 我有两个女儿，还是处女，我把她们交出来，任凭你们处置，只是请你们不要动这两个人，因为他们到我舍下做客。”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:14; 彼得后书 2:7–8; 创世记 13:12"> 他们对罗得说：“走开！”又说：“这个寄居的人竟当起审判官来啦！现在我们要用更狠的手段对付你。”众人便推挤罗得，想要破门而入。</span>
<span className="v" id="v10" data-v="10"> 那两位天使伸手把罗得拉进屋里，关上了门，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 6:18; 使徒行传 13:11; 申命记 28:28–29"> 并让门外的人，不论老少都眼目昏迷，摸来摸去也找不着罗得家的门。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:1; 彼得后书 2:7; 启示录 18:4"> 天使对罗得说：“你这里还有什么人吗？你要带儿女、女婿和城里其他亲人离开这里，</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 18:20; 马太福音 13:49–50; 犹大书 1:7"> 因为我们就要毁灭这城了。耶和华已经听见对城中百姓的极大控诉，祂差遣我们来毁灭这城。”</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 16:21; 耶利米书 51:6; 民数记 16:45"> 罗得听了就去通知他女儿的未婚夫说：“赶快离开这地方！耶和华要毁灭这城了！”可是他们却以为他是在开玩笑。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 16:24–27; 启示录 18:4; 创世记 19:22"> 天刚亮的时候，天使便催促罗得说：“赶快带着你的妻子和这里的两个女儿离开，免得所多玛城因罪恶受惩罚的时候，你也一起被毁灭。”</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:15–16; 提多书 3:5; 约翰福音 6:44"> 罗得却犹豫不决，天使便拉着罗得及其妻子和两个女儿的手出去，将他们带出去，安置在城外，因为耶和华怜悯他们。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:16–18; 路加福音 9:62; 腓立比书 3:13–14"> 带他们到了城外之后，其中一位说：“赶快逃命！不要回头看，也不要留在平原，要往山上逃，免得你们被毁灭。”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 13:6–8; 使徒行传 10:14; 创世记 32:26"> 罗得说：“我主啊，请不要这样。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 27:1; 诗篇 103:1–22; 提摩太前书 1:14–16"> 仆人蒙你厚爱、施恩相救，但我无法逃到山上，要是这灾难追上我，我就没命了！</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 119:175; 箴言 3:5–7; 创世记 19:30"> 请看，那座城离这里不远，容易跑到，又是座小城，请让我逃到那座小城活命吧！”</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 145:19; 诗篇 34:15; 诗篇 102:17"> 天使回答说：“好吧，我也答应你，不毁灭你说的那座城。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 13:10; 创世记 14:2; 创世记 32:25–28"> 你赶快逃去那里吧，因为你到达那里之前，我不能动手。”因此那城便叫琐珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“琐珥”意思是“小”。">a</a></sup>。</span>
<span className="v" id="v23" data-v="23"> 罗得到达琐珥的时候，太阳已经出来了。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 29:23; 以赛亚书 13:19; 阿摩司书 4:11"> 耶和华亲自从天上把燃烧的硫磺降在所多玛和蛾摩拉两地，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 107:34; 创世记 14:3; 创世记 13:10"> 毁灭了这些城和其中的居民，包括整个平原和地上的植物。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 创世记 19:17; 箴言 14:14"> 罗得的妻子跟在他后面，她回头一望，就变成了一根盐柱。</span>
<span className="v" id="v27" data-v="27" data-xref="哈巴谷书 2:1; 诗篇 5:3; 希伯来书 2:1"> 亚伯拉罕清早起来，到他从前站在耶和华面前的地方，</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 18:9; 启示录 9:2; 启示录 21:8"> 向所多玛、蛾摩拉和整个平原眺望，只见那里浓烟滚滚，好像火窑的烟一样。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 8:1; 申命记 9:5; 创世记 18:23–33"> 这样，上帝顾念亚伯拉罕，在毁灭平原各城的时候，让罗得逃离所住的城市，免遭毁灭。</span>
</div>
</div>

## 罗得与他的女儿

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 19:19; 以赛亚书 15:5; 雅各书 1:8"> 罗得不敢住在琐珥，便带着两个女儿来到山上，住在一个洞里。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 25:5; 以赛亚书 4:1; 创世记 16:2"> 他的大女儿对小女儿说：“我们的父亲年纪大了，这里又没有男子可以照着世上的习俗娶我们。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:6–7; 创世记 11:3; 创世记 9:21"> 来，我们灌醉父亲，然后跟他睡觉，借着他传宗接代吧。”</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷书 2:15–16; 箴言 23:29–35; 箴言 20:1"> 于是，那晚她们灌醉了父亲，大女儿进去和父亲睡。她什么时候躺下，什么时候起来，罗得完全不知道。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 8:12; 耶利米书 6:15; 以赛亚书 3:9"> 第二天，大女儿对妹妹说：“昨晚我已经和父亲睡了，今晚我们再灌醉他，然后你进去和他睡。这样，我们就可以借着父亲传宗接代。”</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 诗篇 8:4; 彼得前书 4:7"> 当晚，她们又灌醉了父亲，小女儿进去与他睡。她什么时候躺下，什么时候起来，罗得完全不知道。</span>
<span className="v" id="v36" data-v="36" data-xref="哈巴谷书 2:15; 士师记 1:7; 马太福音 7:2"> 这样，罗得的两个女儿都从父亲怀了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 2:9; 列王纪下 3:1–27; 民数记 21:29"> 大女儿生了一个儿子，给他取名叫摩押<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“摩押”意思是“出自父亲”。">b</a></sup>，他是今天摩押人的祖先。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 2:19; 士师记 10:6–40; 诗篇 83:4–8"> 小女儿也生了一个儿子，给他取名叫便·亚米<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“便·亚米”意思是“亲人的儿子”。">c</a></sup>，他是今天亚扪人的祖先。</span>

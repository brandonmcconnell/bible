<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:17; 出埃及记 20:11; 诗篇 33:6"> 天地万物都造好了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:4; 出埃及记 31:17; 申命记 5:14"> 第七日，上帝完成了祂的创造之工，就在第七日歇了一切的工。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 20:12; 马可福音 2:27; 利未记 23:3"> 上帝赐福给第七日，将其定为圣日，因为祂在这一日歇了祂一切的创造之工。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 5:1; 启示录 1:8; 创世记 1:4"> 这是有关创造天地的记载。 上帝造亚当和夏娃 耶和华上帝创造天地的时候，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 3:23; 希伯来书 6:7; 约伯记 5:10"> 地上还没有草木，也没有长出菜蔬，因为耶和华上帝还没有降雨在地上，土地也没有人耕作，</span>
<span className="v" id="v6" data-v="6"> 但有水从地里涌出，浇灌大地。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:7; 约伯记 33:4; 哥林多前书 15:45"> 耶和华上帝用地上的尘土造人，把生命的气息吹进他的鼻孔里，他就成了有生命的人。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 28:13; 创世记 3:24; 创世记 13:10"> 耶和华上帝在东方的伊甸开辟了一个园子，把祂所造的人安置在里面。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 3:22; 启示录 2:7; 启示录 22:14"> 耶和华上帝使地里长出各种树木，它们既好看又有好吃的果子。在园子的中间有生命树和分别善恶的树。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 22:1; 诗篇 46:4"> 有一条河从伊甸流出来灌溉那园子，又从那里分成四条河流。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 25:18; 创世记 10:29; 撒母耳记上 15:7"> 第一条支流叫比逊河，它环绕着哈腓拉全境，那里有金子，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:20; 民数记 11:7; 以西结书 28:13"> 且是上好的金子，还有珍珠和红玛瑙。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:6; 以赛亚书 11:11"> 第二条支流叫基训河，它环绕着古实全境。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 10:4; 创世记 15:18; 申命记 1:7"> 第三条支流叫底格里斯河，它流经亚述的东边。第四条支流叫幼发拉底河。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 128:2; 创世记 2:8; 以弗所书 4:28"> 耶和华上帝把那人安置在伊甸的园子里，让他在那里耕种、看管园子。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 15:22; 提摩太前书 4:4; 提摩太前书 6:17"> 耶和华上帝吩咐那人说：“你可以随意吃园中各种树上的果子，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:23; 雅各书 1:15; 创世记 3:19"> 只是不可吃那棵分别善恶树的果子，因为你吃的日子必定死。”</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 4:9–12; 哥林多前书 11:7–12; 箴言 18:22"> 耶和华上帝说：“那人独自一人不好，我要为他造一个相配的帮手。”</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 8:4–8; 创世记 1:28; 创世记 9:2"> 耶和华上帝用尘土造了各种田野的走兽和空中的飞鸟，把它们带到那人跟前，看他怎么叫它们。他叫这些动物什么，它们的名字就是什么。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 2:18"> 那人给所有的牲畜及空中的飞鸟和田野的走兽都起了名字。可是他找不到一个跟自己相配的帮手。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:12; 约伯记 4:13; 撒母耳记上 26:12"> 耶和华上帝使那人沉睡，然后在他沉睡的时候从他身上取出一根肋骨，再把肉合起来。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:8–9; 提摩太前书 2:13; 希伯来书 13:4"> 耶和华上帝用那根肋骨造了一个女人，把她带到那人跟前。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:28–30; 哥林多前书 11:8–9; 撒母耳记下 5:1"> 那人说：<br /><span className="pl pl-1">“这才是我骨中的骨，</span><br /><span className="pl pl-1">肉中的肉，</span><br /><span className="pl pl-1">要称她为女人，</span><br /><span className="pl pl-1">因为她是从男人身上取出来的。”</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:3–9; 以弗所书 5:28–31; 马可福音 10:6–12"> 因此，人要离开父母，与妻子结合，二人成为一体。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 3:7; 创世记 3:10–11; 罗马书 10:11"> 当时，他们夫妇二人都赤身露体，并不觉得羞耻。</span>

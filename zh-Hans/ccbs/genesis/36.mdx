## 以扫的后代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 22:17; 历代志上 1:35; 申命记 23:7"> 以下是以扫的后代，以扫就是以东。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 36:25; 创世记 28:9; 创世记 9:25"> 以扫娶了迦南女子为妻，她们是赫人以伦的女儿亚大和希未人祭便的孙女、亚拿的女儿阿何利巴玛。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:9; 创世记 25:13"> 他还娶了以实玛利的女儿、尼拜约的妹妹巴实抹。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 1:35; 出埃及记 2:18; 约伯记 2:11"> 亚大给以扫生了以利法，巴实抹生了流珥，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 35:29"> 阿何利巴玛生了耶乌施、雅兰和可拉。他们都是以扫的儿子，是在迦南出生的。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 32:3; 创世记 12:5; 创世记 17:8"> 以扫带着他在迦南所得的妻子、儿女和家中所有人员，以及所有的牛羊等牲畜和财产离开他弟弟雅各，迁往别处。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 13:6; 创世记 17:8; 创世记 28:4"> 因为以扫和雅各两家的财产和牲畜太多，那地方不够他们住，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:3; 玛拉基书 1:3; 以西结书 35:2–7"> 于是以扫，即以东，搬到了西珥山居住。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 19:37"> 以扫是西珥山区以东人的祖先，以下是他的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 36:3–4; 历代志上 1:35–54"> 以扫的妻子亚大生了以利法，他妻子巴实抹生了流珥。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 36:15–16; 历代志上 1:35–36"> 以利法的儿子是提幔、阿抹、洗玻、迦坦、基纳斯，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 17:8–16; 申命记 25:17–19; 撒母耳记上 15:2–9"> 以利法的妾亭纳为他生了亚玛力，他们都是以扫妻子亚大的子孙。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:37; 创世记 36:17"> 流珥的儿子是拿哈、谢拉、沙玛和米撒，他们都是以扫妻子巴实抹的子孙。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 36:2; 创世记 36:18; 历代志上 1:35"> 以扫的妻子阿何利巴玛是祭便的孙女、亚拿的女儿，她给以扫生了耶乌施、雅兰和可拉。</span>
<span className="v" id="v15" data-v="15" data-xref="俄巴底亚书 1:9; 约伯记 2:11; 创世记 36:11–12"> 以下是以扫子孙中的族长。 以扫的长子以利法的子孙中有提幔族长、阿抹族长、洗玻族长、基纳斯族长、</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:15"> 可拉族长、迦坦族长、亚玛力族长，他们都是以利法在以东的后代，即亚大的子孙。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 36:13; 历代志上 1:37; 创世记 36:4"> 以扫的儿子流珥的子孙中有拿哈族长、谢拉族长、沙玛族长、米撒族长，他们都是流珥在以东的后代，即以扫的妻子巴实抹的子孙。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 36:14; 历代志上 1:35; 创世记 36:5"> 以扫的妻子阿何利巴玛的子孙中有耶乌施族长、雅兰族长和可拉族长。这些都是以扫的妻子、亚拿的女儿阿何利巴玛子孙中的族长。</span>
<span className="v" id="v19" data-v="19"> 这些族长都是以扫的子孙，以扫又名以东。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 2:12; 申命记 2:22; 创世记 14:6"> 以下是住在以东境内何利人西珥的儿子：罗坍、朔巴、祭便、亚拿、</span>
<span className="v" id="v21" data-v="21"> 底顺、以察、底珊。这些西珥的儿子是以东境内何利人的族长。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 1:39"> 罗坍的儿子是何利和希幔，罗坍的妹妹是亭纳。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 1:40"> 朔巴的儿子是亚勒文、玛拿辖、以巴录、示玻和阿南。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 2:10; 撒母耳记下 18:9; 列王纪上 4:28"> 祭便的儿子是埃亚和亚拿，在旷野为父亲放驴时发现温泉的就是亚拿。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 36:2; 创世记 36:18; 历代志上 1:41"> 亚拿的儿子是底顺、女儿名叫阿何利巴玛。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 1:41"> 底顺的儿子是欣但、伊是班、益兰和基兰。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 1:42; 创世记 36:21; 历代志上 1:38"> 以察的儿子是辟罕、撒番和亚干。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米哀歌 4:21; 约伯记 1:1; 耶利米书 25:20"> 底珊的儿子是乌斯和亚兰。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 36:20; 创世记 36:28; 历代志上 1:41–42"> 以下是何利人的族长：罗坍族长、朔巴族长、祭便族长、亚拿族长、</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 7:23; 以赛亚书 23:15; 列王纪下 11:19"> 底顺族长、以察族长、底珊族长。他们是西珥地区何利人各宗族的族长。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 17:6; 历代志上 1:43–50; 创世记 17:16"> 以色列人有君王统治之前，在以东做王的人如下：</span>
<span className="v" id="v32" data-v="32"> 比珥的儿子比拉在以东做王，定都亭哈巴。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 49:13; 耶利米书 49:22; 阿摩司书 1:12"> 比拉死后，波斯拉人谢拉的儿子约巴继位。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 36:11; 约伯记 2:11; 创世记 36:15"> 约巴死后，提幔地区的户珊继位。</span>
<span className="v" id="v35" data-v="35"> 户珊死后，比达之子哈达继位，定都亚未得，他曾在摩押平原击败米甸人。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 1:47"> 哈达死后，玛士利加人桑拉继位。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 1:48; 创世记 10:11"> 桑拉死后，大河边的利河伯人扫罗继位。</span>
<span className="v" id="v38" data-v="38"> 扫罗死后，亚革波的儿子巴勒·哈南继位。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 15:15; 历代志上 1:50"> 亚革波的儿子巴勒·哈南死后，哈达继位，定都巴乌，他的妻子名叫米希她别，是米·萨合的孙女、玛特列的女儿。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志上 1:51–54; 出埃及记 15:15; 创世记 36:31"> 以下是按宗族在各地区做族长的以扫的后代：亭纳、亚勒瓦、耶帖、</span>
<span className="v" id="v41" data-v="41"> 阿何利巴玛、以拉、比嫩、</span>
<span className="v" id="v42" data-v="42"> 基纳斯、提幔、米比萨、</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 45:8; 历代志上 4:14; 创世记 25:30"> 玛基叠、以兰。这些人在所住的以东各地做族长。以扫是以东人的始祖。</span>

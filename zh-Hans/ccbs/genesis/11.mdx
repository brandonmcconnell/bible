## 巴别塔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 2:6; 西番雅书 3:9; 以赛亚书 19:18"> 那时，天下人都用同一种语言，讲同一种话。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 10:10; 但以理书 1:2; 创世记 14:1"> 人们向东迁移时，在示拿地区找到一处平原，定居下来。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:10; 出埃及记 1:14; 出埃及记 2:3"> 他们彼此商量说：“来呀，我们制作砖，把砖烧透吧。”他们用砖作石块，用柏油作灰泥来造塔，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:28; 约翰福音 5:44; 路加福音 1:51"> 说：“来吧，让我们造一座城和一座高耸入云的塔，这样我们可以为自己扬名，不致分散在普天之下。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 18:21; 诗篇 33:13–14; 约翰福音 3:13"> 耶和华下来察看人建造的城和塔。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 2:1–4; 创世记 3:22; 创世记 11:1"> 耶和华说：“看啊，他们同属一个民族，都用同一种语言，现在就开始做这样的事，如果继续下去，他们会为所欲为。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 33:10; 诗篇 55:9; 约伯记 5:12–13"> 来吧，我们下去变乱他们的语言，使他们彼此言语不通。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命记 32:8; 创世记 10:25"> 于是，耶和华把他们从那里分散到普天之下，他们便停止建城了。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 10:10; 创世记 10:5; 创世记 10:20"> 因此，人称那城为巴别，因为耶和华在那里变乱了世人的语言，把他们分散到普天之下。</span>
</div>
</div>

## 闪的后代

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 1:17–27; 创世记 10:21–22; 路加福音 3:34–36"> 以下是闪的后代。 洪水过后两年，闪一百岁时生亚法撒，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 9:7; 诗篇 144:12; 创世记 1:28"> 之后又活了五百年，生儿育女。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亚法撒三十五岁时生沙拉，</span>
<span className="v" id="v13" data-v="13"> 之后又活了四百零三年，生儿育女。</span>
<span className="v" id="v14" data-v="14"> 沙拉三十岁时生希伯，</span>
<span className="v" id="v15" data-v="15"> 之后又活了四百零三年，生儿育女。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 10:21; 历代志上 1:19; 民数记 24:24"> 希伯三十四岁时生法勒，</span>
<span className="v" id="v17" data-v="17"> 之后又活了四百三十年，生儿育女。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒三十岁时生拉吴，</span>
<span className="v" id="v19" data-v="19"> 之后又活了二百零九年，生儿育女。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吴三十二岁时生西鹿，</span>
<span className="v" id="v21" data-v="21"> 之后又活了二百零七年，生儿育女。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 24:2"> 西鹿三十岁时生拿鹤，</span>
<span className="v" id="v23" data-v="23"> 之后又活了二百年，生儿育女。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 约书亚记 24:2"> 拿鹤二十九岁时生他拉，</span>
<span className="v" id="v25" data-v="25"> 之后又活了一百一十九年，生儿育女。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 24:2; 历代志上 1:26–27; 创世记 22:20–24"> 他拉七十岁后，生了亚伯兰、拿鹤和哈兰。</span>
</div>
</div>

## 他拉的后代

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 12:4; 创世记 14:12; 创世记 11:31"> 以下是他拉的后代。 他拉生亚伯兰、拿鹤和哈兰，哈兰生罗得。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:7; 尼希米记 9:7; 使徒行传 7:2–4"> 哈兰比他父亲他拉先去世，他死在自己的家乡迦勒底的吾珥。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:15; 创世记 22:20; 创世记 24:15"> 亚伯兰和拿鹤都娶了妻子，亚伯兰的妻子名叫撒莱，拿鹤的妻子名叫密迦，是哈兰的女儿。哈兰是密迦和亦迦的父亲。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 29:31; 创世记 21:1–2; 路加福音 1:7"> 撒莱不能生育，没有孩子。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 9:7; 使徒行传 7:2–4; 创世记 24:10"> 他拉带着儿子亚伯兰、孙子——哈兰的儿子罗得、儿媳妇——亚伯兰的妻子撒莱，离开迦勒底的吾珥前往迦南，他们来到哈兰，在那里定居下来。</span>
<span className="v" id="v32" data-v="32"> 他拉在那里去世，享年二百零五岁<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“二百零五岁”有古卷作“一百四十五岁”。">a</a></sup>。</span>
</div>
</div>

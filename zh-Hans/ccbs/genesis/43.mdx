## 约瑟的哥哥们再下埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 使徒行传 7:11–13; 耶利米哀歌 5:10"> 那地方的饥荒仍然非常严重，</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 6:6–8; 箴言 16:18; 箴言 15:16"> 他们从埃及带回来的粮食吃完了，他们的父亲对他们说：“你们再去买些粮食吧。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 44:23; 创世记 43:5; 撒母耳记下 3:13"> 犹大说：“那人严厉地警告我们，‘不把你们的弟弟带来，你们就不要再来见我。’</span>
<span className="v" id="v4" data-v="4"> 你若让弟弟跟我们同去，我们就去给你买粮。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:12; 创世记 44:26; 创世记 42:38"> 你若不让他跟我们同去，我们就不去给你买粮。因为那人说，‘你们不把弟弟带来，就不要再来见我。’”</span>
<span className="v" id="v6" data-v="6"> 以色列说：“你们为什么这样害我，告诉他你们还有一个弟弟呢？”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 43:3; 创世记 42:13; 创世记 43:27"> 他们回答说：“那人详细询问我们和我们家人的情况，问我们的父亲是否在世，还有没有弟兄。我们如实回答，怎会想到他非要我们把弟弟带去呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 42:2; 申命记 33:6; 创世记 45:19"> 犹大对父亲以色列说：“你就让这孩子跟我同去吧，我们好立刻动身，这样我们一家老小才能保住性命，不致饿死。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 42:37; 腓利门书 1:18–19; 希伯来书 7:22"> 我亲自担保他的安全，你可以向我要人。我若不把他带回来见你，情愿一生担罪。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 19:16"> 我们若是没有耽搁的话，现在已经往返两趟了。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 37:25; 耶利米书 8:22; 以西结书 27:17"> 他们的父亲以色列说：“事到如今，只好这样了。你们袋子里带一些上好的乳香、蜂蜜、香料、没药、榧子和杏仁等土产，去送给那人作礼物吧。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:25; 创世记 42:35; 帖撒罗尼迦前书 4:6"> 你们还要带双倍的钱，好归还上次留在你们口袋中的钱，那次可能是弄错了。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 42:38"> 带你们的弟弟去见那人吧！</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 4:16; 创世记 17:1; 使徒行传 21:14"> 愿全能的上帝叫那人怜悯你们，让西缅和便雅悯回来。我若丧子就丧子吧！”</span>
<span className="v" id="v15" data-v="15"> 于是，他们就带着便雅悯、礼物和双倍的钱去埃及见约瑟。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 44:1; 创世记 43:19; 创世记 24:2–10"> 约瑟看见便雅悯和他们同来，就对管家说：“你带他们到我家里去，宰杀牲畜，预备宴席，中午他们要跟我一起吃饭。”</span>
<span className="v" id="v17" data-v="17"> 管家照约瑟的吩咐，带他们到约瑟家里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 42:35; 罗马书 7:8; 创世记 42:21"> 他们被带到约瑟家后非常害怕，说：“他把我们带到这里来，是因为上次放回我们口袋的钱。他想害我们，强迫我们做他的奴仆，抢我们的驴。”</span>
<span className="v" id="v19" data-v="19"> 他们走到约瑟的管家跟前，在房门口对他说：</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 42:3; 创世记 42:10; 创世记 42:27"> “主啊，我们上次曾来这里买粮。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:12; 创世记 42:27–35; 罗马书 13:8"> 但在回家的途中住宿时，我们打开口袋，发现我们带来买粮的钱分毫不少地放在那里。我们把这些钱带回来了，</span>
<span className="v" id="v22" data-v="22"> 又另外带了一些钱来买粮。我们不知道谁把买粮的钱放进了我们的口袋。”</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 20:26; 创世记 42:24; 约翰福音 14:27"> 管家说：“你们放心，不要害怕，你们口袋里的钱财是你们的上帝，你们父亲的上帝赐给你们的。我已经收了你们买粮的钱。”他就把西缅带出来见他们，</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 18:4; 创世记 24:32; 路加福音 7:44"> 接着带他们进约瑟的家，给他们水洗脚，给他们的驴喂草料。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:11; 创世记 43:16"> 他们知道要在那里吃午餐，就预备好礼物，等约瑟中午回来。</span>
<span className="v" id="v26" data-v="26" data-xref="腓立比书 2:10–11; 创世记 27:29; 创世记 42:6"> 约瑟回到家里后，他们就把带来的礼物献给他，向他俯伏下拜。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 42:13; 撒母耳记上 25:5; 撒母耳记上 17:22"> 约瑟向他们问好，然后说：“你们提起过你们的老父亲，他安康吗？还健在吗？”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 37:7; 创世记 43:26; 撒母耳记下 14:4"> 他们回答说：“你仆人——我们的父亲仍然健在，安康。”说完了，又向他下拜。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 42:13; 民数记 6:25; 创世记 30:22–24"> 约瑟抬眼看见了自己的同胞弟弟便雅悯，就问道：“这就是你们所说那位最小的弟弟吗？”他又对便雅悯说：“孩子，愿上帝施恩给你。”</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:24; 耶利米书 31:20; 列王纪上 3:26"> 约瑟爱弟之心油然而生，急忙出去找哭的地方。他到自己的房间里哭了一场。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 45:1; 彼得前书 3:10; 以赛亚书 42:14"> 他洗过脸出来，控制着自己的感情，吩咐人摆饭。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 46:34; 出埃及记 8:26; 创世记 43:16"> 约瑟自己一桌，他的弟兄们一桌，那些和他们一起吃饭的埃及人一桌，因为埃及人厌恶希伯来人，不与他们同席。</span>
<span className="v" id="v33" data-v="33"> 约瑟让他的弟兄们按照长幼次序在他对面坐，他们面面相觑，非常惊讶。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 45:22; 撒母耳记下 11:8; 撒母耳记上 1:5"> 约瑟吩咐人把自己面前的菜肴分给他们，便雅悯得的那份比其他弟兄多五倍。他们尽情地和约瑟一同吃喝。</span>

## 约瑟的哥哥们到埃及买粮

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:12; 约书亚记 7:10; 列王纪下 8:3–4"> 雅各得知埃及有粮食，就对儿子们说：“你们为什么还在这儿互相观望呢？</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 43:8; 创世记 45:9; 创世记 43:2"> 我听说埃及有粮食，你们快到埃及去买些粮食回来吧，我们好活命，不致饿死。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:5; 创世记 42:13"> 于是，约瑟的十个哥哥下到埃及买粮。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 42:38; 创世记 43:29; 创世记 11:4"> 雅各没有让约瑟的弟弟便雅悯与他们同去，恐怕他会遭害。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:57; 使徒行传 7:11; 创世记 12:10"> 以色列的儿子们加入了买粮的行列，因为迦南也遭遇饥荒。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 3:9; 创世记 37:7–10; 创世记 41:40–41"> 那时，约瑟治理埃及，负责卖粮给百姓。约瑟的哥哥们来到他面前，向他俯伏下拜。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 42:30; 创世记 42:14–17; 马太福音 15:23–26"> 约瑟一眼就认出了他们，却不动声色。他疾言厉色地问道：“你们从哪里来？”他们回答说：“我们是从迦南来买粮食的。”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 37:2; 约翰福音 20:14; 路加福音 24:16"> 约瑟认得他哥哥们，但他哥哥们却认不出他来。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 37:5–9; 出埃及记 32:35; 约书亚记 2:1"> 约瑟想起了自己从前做的两个梦，就对他们说：“你们是奸细，是来探听我们虚实的！”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 37:8; 撒母耳记上 26:17; 创世记 27:37"> 他们说：“我主啊，不是的！仆人们是来买粮的。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 42:19; 哥林多后书 6:4; 约翰福音 7:18"> 仆人们都是一个父亲所生，是诚实人，不是奸细。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 约瑟说：“不对，你们是来探听我们虚实的。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 37:30; 创世记 42:32; 创世记 44:20"> 他们说：“仆人们共有弟兄十二人，父亲住在迦南，最小的弟弟在父亲身边，还有一个已经去世。”</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:21–28; 约伯记 13:24; 创世记 42:9–11"> 约瑟说：“我说你们是奸细一点不错。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 17:55; 耶利米书 5:7; 创世记 42:16"> 我以法老的性命起誓，你们最小的弟弟不来这里，你们都不能走，这是对你们的验证。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 42:11"> 你们派一个人回去把你们的弟弟带来，其他人都要被囚禁在这里，我要看看你们说的是真还是假。要是你们说的是假话，我以法老的性命起誓，你们一定是奸细。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 40:4; 希伯来书 12:10; 创世记 40:7"> 于是，约瑟把他们囚禁了三天。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 25:43; 尼希米记 5:15; 路加福音 18:2"> 到了第三天，约瑟对他们说：“我是敬畏上帝的人，你们照我的话做就能活命。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 45:23; 以赛亚书 42:7; 创世记 40:3"> 如果你们是诚实人，就把一个人留在监牢，其他人带粮食回去接济你们的家人。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 44:23; 创世记 43:5; 创世记 42:34"> 但你们一定要带你们最小的弟弟回来，以证实你们说的是实话，这样你们就不会死。”他们同意了，</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 5:15; 马可福音 9:43–45; 创世记 37:23–28"> 彼此议论说：“我们一定是在遭报应。从前我们的弟弟苦苦地哀求我们，我们却不理会，现在这场痛苦临到我们了。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 24:22; 诗篇 9:12; 列王纪上 2:32"> 吕便说：“我不是劝你们不要犯罪害那孩子吗？你们不听，现在我们必须偿还血债了。”</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:20; 约翰福音 16:13–14"> 他们不知道约瑟听得懂他们的话，因为约瑟是通过翻译跟他们谈话。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 43:30; 犹大书 1:22–23; 希伯来书 4:15"> 约瑟听后转身出去哭了，然后又回来跟他们谈话，从他们中间选了西缅，当着他们的面把西缅捆绑起来。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:9; 罗马书 12:17–21; 创世记 45:21"> 约瑟又吩咐人把他们的袋子装满粮食，把各人买粮的钱放在他们的口袋中，还为他们预备了路上的食物。仆人一一办妥了。</span>
<span className="v" id="v26" data-v="26"> 约瑟的哥哥们把粮食驮在驴上，启程离去。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:24; 路加福音 2:7; 路加福音 10:34"> 他们来到一处住宿的地方，其中一人打开口袋拿饲料喂驴，却发现自己的钱在里面，</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 45:7; 耶利米哀歌 3:37; 创世记 42:36"> 就对其他弟兄说：“你们看，我的钱被退回来了，在我的口袋里！”他们心惊胆战地彼此议论说：“上帝这样对待我们是什么意思呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 他们回到他们在迦南的父亲雅各那里，把事情的经过告诉了他，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:7"> 说：“埃及的宰相对我们说话很凶，还把我们当成去那里打探的奸细。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 42:11"> 我们对他说，‘我们是诚实人，不是奸细。</span>
<span className="v" id="v32" data-v="32"> 我们是一个父亲所生的十二兄弟，其中有一个已经去世，年纪最小的跟父亲留在迦南。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 42:19–20; 创世记 42:15"> 那地的宰相却对我们说，‘我要看看你们是不是诚实人，你们把一个弟兄留在我这里，其他人带粮食回去接济家人吧。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 34:10; 创世记 34:21; 列王纪上 10:15"> 但你们要把最小的弟弟带来见我，这样我便知道你们不是奸细，是诚实人。我就会释放你们的弟兄，你们也可以在这里自由地买卖。’”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 43:21; 创世记 43:12; 创世记 43:15"> 后来他们倒口袋时，发现每个人买粮的钱袋都在自己的口袋里，他们和父亲看见钱袋，都害怕起来。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 43:14; 罗马书 8:31; 以赛亚书 27:9"> 他们的父亲雅各说：“你们使我连连失去儿子，约瑟没了，西缅没了，你们还要带走便雅悯！灾祸都落在了我头上！”</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 46:9; 弥迦书 6:7; 创世记 43:9"> 吕便对父亲说：“要是我不把便雅悯带回你身边，你就杀了我的两个儿子！请你把便雅悯交给我，我一定会把他带回你身边。”</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 37:35; 创世记 42:4; 创世记 37:33"> 雅各说：“我的儿子不可跟你们去。他哥哥已经死了，现在只剩下他。要是他在路上遇到什么意外，你们会使我这白发苍苍的老人凄凄惨惨地下阴间。”</span>
</div>
</div>

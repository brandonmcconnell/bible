## 上帝与挪亚立约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 9:7; 创世记 1:28; 创世记 8:17"> 上帝赐福给挪亚和他的儿子们，对他们说：“你们要生养众多，遍布地面。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 8:4–8; 创世记 1:28; 雅各书 3:7"> 所有地上的走兽和爬虫、空中的飞鸟及海里的鱼都必惧怕你们，它们都归你们管理。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 14:14; 歌罗西书 2:21–22; 哥林多前书 10:31"> 凡是活的动物都可作你们的食物，就像绿色菜蔬一样，我把一切都赐给你们了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:23; 申命记 15:23; 申命记 12:16"> 只是你们不可吃带血的肉，因为血就是生命。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 21:28–29; 出埃及记 21:12; 创世记 4:9–10"> 凡是杀害你们的，无论人或兽，我必向他们追讨血债。凡杀人的，我必追讨他的血债。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 24:17; 马太福音 26:52; 启示录 13:10"> 凡杀害人的，也必被人杀害，因为人是上帝照着自己的形象造的。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 1:28; 创世记 9:1; 创世记 9:19"> 你们要生养众多，使地上人口兴旺。”</span>
<span className="v" id="v8" data-v="8"> 上帝又对挪亚和他身边的儿子们说：</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 6:18; 以赛亚书 54:9–10; 罗马书 1:3"> “我要跟你们和你们的后代立约，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 8:1; 创世记 9:15–16; 诗篇 36:5–6"> 包括所有和你们在一起的生物，就是那些和你们一起从方舟出来的飞禽走兽和牲畜。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 54:9; 创世记 8:21–22; 创世记 7:21–23"> 我与你们立约，不再让洪水灭绝一切生命，也不再让洪水毁灭大地。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:11; 马太福音 26:26–28; 出埃及记 12:13"> 上帝说：“我与你们及所有和你们在一起的生物立世代永存的约，这是我立约的记号。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 1:28; 启示录 4:3; 启示录 10:1"> 我把彩虹放在云中，作为我跟大地立约的记号。</span>
<span className="v" id="v14" data-v="14"> 我使云彩覆盖大地的时候，会有彩虹在云中出现。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 7:9; 以西结书 16:60; 以赛亚书 54:8–10"> 这样我会顾念我与你们及一切有血气的生物所立的约，水就不会再泛滥、毁灭所有生命。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 54:8–10; 耶利米书 32:40; 撒母耳记下 23:5"> 当我看见彩虹在云中出现的时候，就会顾念我与地上一切活物立的永远之约。”</span>
<span className="v" id="v17" data-v="17"> 上帝对挪亚说：“这是我与地上一切生命立约的记号。”</span>
</div>
</div>

## 挪亚和他的儿子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="创世记 10:1; 创世记 10:6; 创世记 9:25–27"> 与挪亚一起出方舟的有他的儿子闪、含、雅弗。含是迦南的父亲。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 1:4–28; 创世记 8:17; 创世记 5:32"> 这是挪亚的三个儿子，他们的后代遍布天下。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 20:6; 箴言 10:11; 以赛亚书 28:24–26"> 挪亚做了农夫，他是第一个栽种葡萄园的人。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; 哈巴谷书 2:15–16; 箴言 23:31–32"> 一天，他喝葡萄酒喝醉了，赤裸着身体躺在帐篷里。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 加拉太书 6:1; 马太福音 18:15"> 迦南的父亲含看见父亲赤身露体，便去告诉外面的两个弟兄。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 出埃及记 20:12; 提摩太前书 5:17"> 于是，闪和雅弗拿了一件衣服搭在肩上，倒退着走进帐篷，把衣服盖在父亲身上，他们背着脸不看父亲赤裸的身体。</span>
<span className="v" id="v24" data-v="24"> 挪亚酒醒后，知道了小儿子做的事，</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:23; 申命记 27:16; 士师记 1:28–30"> 就说：<br /><span className="pl pl-1">“迦南该受咒诅，</span><br /><span className="pl pl-1">必做他弟兄的仆人的仆人。”</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 144:15; 创世记 12:1–3; 路加福音 3:23–36"> 又说：<br /><span className="pl pl-1">“闪的上帝耶和华当受称颂！</span><br /><span className="pl pl-1">愿迦南做闪的仆人。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 11:12; 罗马书 15:12; 希伯来书 11:9–10"> <span className="pl pl-1">愿上帝扩张雅弗的疆界，</span><br /><span className="pl pl-1">愿他住在闪的帐篷里，</span><br /><span className="pl pl-1">愿迦南做他的仆人。”</span></span>
<span className="v" id="v28" data-v="28"> 洪水以后，挪亚又活了三百五十年，</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 5:27; 诗篇 90:10; 创世记 5:32"> 共活了九百五十岁才去世。</span>
</div>

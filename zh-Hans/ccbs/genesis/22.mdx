## 上帝考验亚伯拉罕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:17; 雅各书 2:21; 申命记 8:2"> 这些事以后，上帝要考验亚伯拉罕，就呼唤他：“亚伯拉罕！”他回答说：“我在这里。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 3:16; 罗马书 8:32; 希伯来书 11:17"> 上帝说：“带着你的儿子，你的独生子，你疼爱的以撒前往摩利亚，在我指示你的山上把他献为燔祭。”</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 119:60; 马太福音 10:37; 路加福音 14:26"> 亚伯拉罕清早起来，准备好驴，劈好献燔祭用的柴，带着两个仆人和儿子以撒动身前往上帝指示他的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 马太福音 17:23; 何西阿书 6:2"> 到了第三天，亚伯拉罕抬头远远看见那地方，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:19; 希伯来书 12:1"> 就对仆人说：“你们和驴在这里等着，我和孩子到那边敬拜上帝，然后便回来。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:17; 彼得前书 2:24; 以赛亚书 53:6"> 亚伯拉罕把献燔祭用的柴放在儿子以撒肩上，自己手里拿着火种和刀。父子二人一同向前走。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:15; 马太福音 26:39; 创世记 8:20"> 以撒说：“父亲。”亚伯拉罕说：“儿子，什么事？”以撒说：“你看，火种和柴都有了，但献燔祭用的羊羔在哪里呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:36; 约翰福音 1:29; 启示录 5:12"> 亚伯拉罕说：“儿子，上帝会亲自预备献燔祭的羊羔。”二人就一同向前走。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 2:21; 希伯来书 11:17–19; 腓立比书 2:7–8"> 他们到了上帝指示的地方，亚伯拉罕就筑起祭坛，把柴摆在上面，然后把以撒捆起来放在祭坛上面的柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 2:21–23; 希伯来书 11:17–19; 以赛亚书 53:6–12"> 亚伯拉罕伸手拿起刀来，要杀他的儿子。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 21:17; 出埃及记 3:4; 创世记 16:9–10"> 耶和华的天使从天上呼唤他说：“亚伯拉罕！亚伯拉罕！”他回答说：“我在这里。”</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 2:21–22; 雅各书 2:18; 撒母耳记上 15:22"> 天使说：“不可动孩子，不可伤害他！现在我知道你敬畏上帝，因为你不惜把你的儿子，你的独生子献给我。”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 诗篇 40:6–8; 哥林多后书 1:9–10"> 这时亚伯拉罕抬头一看，见有一只公绵羊两角卡在稠密的树丛中，于是把羊取来代替他的儿子献为燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:13; 出埃及记 17:15; 创世记 22:8"> 亚伯拉罕称那地方为“耶和华以勒”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“耶和华以勒”或译“耶和华必预备”。">a</a></sup>。直到今天人们还说：“在耶和华的山上必有预备。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的天使再次从天上呼唤亚伯拉罕，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:13–14; 路加福音 1:73; 诗篇 105:9"> 对他说：“耶和华说，‘你既然不惜献上你的儿子，你的独生子，我凭自己起誓，</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:5; 创世记 24:60; 耶利米书 33:22"> 我必赐福给你，使你的后裔多如天上的星和海边的沙。你的后裔必夺取仇敌的城池，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 3:25; 创世记 12:3; 加拉太书 3:16"> 天下万国必因你的后裔而蒙福，因为你听从了我的话。’”</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 21:31; 士师记 20:1; 约书亚记 15:28"> 于是，亚伯拉罕回到仆人那里，他们一同返回亚伯拉罕居住的别示巴。</span>
</div>
</div>

## 拿鹤的后代

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 11:29; 创世记 24:24; 箴言 25:25"> 过了些日子，有人告诉亚伯拉罕：“密迦为你兄弟拿鹤生了几个儿子，</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 1:1; 约伯记 32:2; 诗篇 60:1–12"> 长子乌斯、乌斯的弟弟布斯、亚兰的父亲基姆利、</span>
<span className="v" id="v22" data-v="22"> 基薛、哈琐、必达、益拉和彼土利。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:15; 创世记 28:5; 创世记 24:51"> 彼土利是利百加的父亲。密迦为亚伯拉罕的兄弟拿鹤生了这八个儿子。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:3; 创世记 25:6; 箴言 15:25"> 拿鹤的妾流玛生了提八、迦含、他辖和玛迦。</span>
</div>

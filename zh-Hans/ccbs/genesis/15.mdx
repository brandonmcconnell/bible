## 上帝与亚伯兰立约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 41:10; 诗篇 119:114; 诗篇 84:11"> 这些事以后，耶和华在异象中对亚伯兰说：“亚伯兰，你不要害怕，我是你的盾牌，我要大大赏赐你。”</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 25:21; 使徒行传 7:5; 创世记 12:1–3"> 亚伯兰说：“主耶和华啊，你要赐我什么呢？我没有儿子，继承我家业的人是大马士革人以利以谢。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:14; 箴言 29:21; 传道书 2:7"> 亚伯兰又说：“你没有赐我后裔，我家中的仆人将继承我的产业。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 17:16; 加拉太书 4:28; 撒母耳记下 7:12"> 耶和华对他说：“这人不会成为你的继承人，你亲生的儿子才是你的继承人。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:12; 罗马书 4:18; 申命记 1:10"> 耶和华把亚伯兰带到外面，对他说：“你抬头看看天空，数数繁星，你能数得尽吗？”接着又对他说：“你的后裔必这么多。”</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:23; 加拉太书 3:6–14; 罗马书 4:9"> 亚伯兰信耶和华，耶和华便算他为义人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 12:1; 使徒行传 7:2–4; 罗马书 4:13"> 耶和华又对他说：“我是耶和华，我带你离开了迦勒底的吾珥，为要把这片土地赐给你作产业。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:18; 路加福音 1:34; 以赛亚书 7:11"> 亚伯兰说：“主耶和华啊，我怎么知道我会得到这片土地呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 2:24; 利未记 14:30; 利未记 14:22"> 耶和华说：“你要给我预备三岁的母牛、母山羊和公绵羊各一头，斑鸠和雏鸽各一只。”</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:18–19; 利未记 1:17; 创世记 15:17"> 亚伯兰一一照办，把牲畜都劈成两半，一半对着一半地摆列，但没有劈开鸟。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:4; 诗篇 119:13; 以西结书 17:3"> 有鸷鸟飞到那些尸体上，亚伯兰赶走了它们。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 约伯记 33:15; 但以理书 10:8–9"> 太阳下山的时候，亚伯兰睡得很沉，忽然有可怕的黑暗笼罩着他。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:6–7; 出埃及记 1:11; 出埃及记 12:40–41"> 耶和华对他说：“你要清楚知道，你的后裔必流落异乡，被奴役和虐待四百年。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 9:9–11; 出埃及记 6:5–6; 出埃及记 12:32–38"> 但我必惩罚那奴役他们的国家，之后他们必带着大量财物离开那里。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 5:26; 创世记 25:7–9; 历代志下 34:28"> 而你必享长寿，得到安葬，归到列祖那里。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 21:26; 但以理书 8:23; 出埃及记 12:40"> 到了第四代<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“代”希伯来文可能指人一生的年日。">a</a></sup>，你的子孙必重回此地，因为亚摩利人现在还没有恶贯满盈。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 34:18–19; 士师记 6:21; 耶利米书 11:4"> 太阳下山，夜幕降临，突然有冒烟的火炉和点着的火炬在肉块中经过。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 1:3–4; 创世记 12:7; 创世记 24:7"> 就在那天，耶和华跟亚伯兰立约，说：“我必将这片土地赐给你的后裔，从埃及河一直延伸到幼发拉底大河，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 24:21–22"> 就是基尼人、基尼洗人、甲摩尼人、</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 17:5; 创世记 14:5"> 赫人、比利洗人、利乏音人、</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 10:15–19; 出埃及记 23:23–28; 申命记 7:1"> 亚摩利人、迦南人、革迦撒人和耶布斯人的土地。”</span>
</div>
</div>

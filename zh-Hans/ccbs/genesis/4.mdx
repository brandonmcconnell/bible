## 该隐和亚伯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 3:12; 创世记 3:15; 创世记 4:25"> 亚当和他妻子夏娃同房，夏娃便怀孕，生了该隐。她说：“耶和华让我得了一个男孩。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:15; 约翰一书 3:12; 路加福音 11:51"> 后来，夏娃又生了该隐的弟弟亚伯。亚伯做了牧羊人，该隐做了农夫。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 18:12; 利未记 2:1–11; 列王纪上 17:7"> 过了些日子，该隐把地里的出产当祭物献给耶和华，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:4; 箴言 3:9; 出埃及记 13:12"> 亚伯也把羊群中头生的羊及其最肥美的部分献给耶和华。耶和华悦纳亚伯和他的祭物，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:4; 约伯记 5:2; 路加福音 15:28–30"> 却不悦纳该隐和他的祭物。该隐便非常恼火，面色阴沉。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 1:18; 约伯记 5:2; 路加福音 15:31–32"> 耶和华问该隐：“你为什么恼火？为什么面色阴沉？</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:15; 罗马书 2:6–10; 以赛亚书 3:10–11"> 如果你做得对，难道不会蒙悦纳吗？如果你做得不对，罪就蹲伏在你的门口，要控制你，但你必须制服罪。”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 23:35; 约翰一书 3:12–15; 犹大书 1:11"> 该隐对弟弟亚伯说：“我们去田间吧！”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我们去田间吧！”参照《七十士译本》，希伯来文无此句。">a</a></sup>他们在田间的时候，该隐动手打亚伯，把他杀了。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; 约翰福音 8:44; 诗篇 9:12"> 后来，耶和华问该隐：“你弟弟亚伯在哪里？”他说：“我不知道！难道我是我弟弟的看护人吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 12:24; 诗篇 72:14; 希伯来书 11:4"> 耶和华说：“你做了什么事？你弟弟的血从地里向我哭诉。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:10; 约伯记 16:18; 创世记 3:14"> 地张开口从你手上接受了你弟弟的血，现在你在地上必受咒诅。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿书 9:17; 利未记 26:36; 利未记 26:20"> 你种地，地却不会再为你效力，你必在地上四处漂泊。”</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 15:22; 启示录 16:9; 启示录 16:11"> 该隐对耶和华说：“这惩罚太重！我承受不了。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 35:19; 诗篇 143:7; 约伯记 15:20–24"> 今天你把我从此地赶出去，使我不能再见你的面。我在地上四处漂泊，见到我的人都会杀我。”</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 9:4; 诗篇 79:12; 创世记 4:24"> 耶和华对他说：“不会的，因为凡杀你的，必遭受七倍的报应。”于是，耶和华在该隐身上留下一个记号，免得见到他的人杀他。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:39; 约伯记 2:7; 创世记 4:14"> 该隐离开耶和华，来到伊甸东边的挪得住下来。</span>
</div>
</div>

## 该隐的后代

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="诗篇 49:11; 传道书 2:4–11; 但以理书 4:30"> 该隐和妻子同房，他的妻子就怀孕，生了以诺。该隐建了一座城，用他儿子的名字给这城取名叫以诺。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 36:2; 创世记 5:21"> 以诺生以拿，以拿生米户雅利，米户雅利生玛土撒利，玛土撒利生拉麦。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 2:24; 马太福音 19:8; 创世记 2:18"> 拉麦娶了两个妻子，一个叫亚大，另一个叫洗拉。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 4:2; 耶利米书 35:9–10; 约翰福音 8:44"> 亚大生了雅八，雅八是游牧民族的祖先，</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 21:12; 以赛亚书 5:12; 创世记 31:27"> 雅八的弟弟叫犹八，他是弹琴吹笛之人的鼻祖。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 33:25; 申命记 8:9; 历代志下 2:7"> 洗拉生了土八·该隐，他是打造各种铜铁器具的匠人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“他是打造各种铜铁器具的匠人”或译“他是铜匠、铁匠的祖先”。">b</a></sup>，他的妹妹叫拿玛。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 23:18; 出埃及记 20:13; 利未记 19:18"> 拉麦对他的两个妻子说：<br /><span className="pl pl-1">“亚大，洗拉，你们听我的声音；</span><br /><span className="pl pl-1">拉麦的妻子啊，侧耳听我的话，</span><br /><span className="pl pl-1">有人伤我，我杀了他，</span><br /><span className="pl pl-1">青年打我，我宰了他。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:22; 创世记 4:15"> <span className="pl pl-1">杀该隐的遭受七倍的报应，</span><br /><span className="pl pl-1">杀拉麦的遭受七十七倍的报应。”</span></span>
</div>
</div>

## 塞特和以挪士

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 4:8; 创世记 4:10–11; 历代志上 1:1"> 亚当又与妻子夏娃同房，夏娃生了一个儿子，取名叫塞特，因为她说：“上帝赐我另一个儿子来代替亚伯，因为该隐杀了他。”</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 116:17; 列王纪上 18:24; 约珥书 2:32"> 塞特生了一个儿子，给他取名叫以挪士。那时候，人开始求告耶和华的名。</span>
</div>

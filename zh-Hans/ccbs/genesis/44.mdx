## 约瑟试验弟兄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 42:25; 创世记 43:16; 创世记 24:2"> 约瑟吩咐管家说：“给他们的口袋装满粮食，他们能带多少就装多少，把各人的钱放回他们的口袋中，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 8:8; 创世记 42:20; 申命记 8:16"> 再把我的银杯和买粮的钱一起放在最小的兄弟的口袋中。”管家遵命而行。</span>
<span className="v" id="v3" data-v="3"> 清早，他们就牵着驴被送走了。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:32; 诗篇 35:12; 箴言 17:13"> 他们出城不久，约瑟对管家说：“你快去追他们，追上了就对他们说，‘你们为什么以恶报善？</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 利未记 19:26; 列王纪下 21:6"> 为什么偷我主人用来喝酒和占卜的银杯？你们这是作恶！’”</span>
<span className="v" id="v6" data-v="6"> 于是，管家追上他们，按约瑟的话问他们。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 38:16–18; 创世记 37:18–32; 列王纪下 8:13"> 他们回答说：“我主为什么这样说？我们绝不会做这种事。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 43:12; 创世记 42:35; 罗马书 13:9"> 你看，我们把上次在口袋里发现的钱都从迦南带回来还你了，又怎么会偷你主人家的金银呢？</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:32; 诗篇 7:3–5; 约伯记 31:38–40"> 你若在仆人中任何人身上搜到银杯，他就要死！我们也要做我主的奴仆。”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:3; 创世记 44:17; 创世记 44:33"> 管家说：“好，就照你们的话做吧！银杯从谁那里搜出来，谁就做我的奴仆，其他人都没有罪。”</span>
<span className="v" id="v11" data-v="11"> 于是，他们急忙把各自的口袋卸到地上打开。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 44:26–32; 创世记 42:36–38; 创世记 43:14"> 管家就从最年长的开始搜查，结果在最年幼的便雅悯口袋里搜出了银杯。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 1:11; 创世记 37:29–34; 撒母耳记下 1:2"> 他们伤心地撕裂衣服，把东西放回驴背上，返回城里。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 50:18; 创世记 43:25; 创世记 43:16"> 犹大和他兄弟们回到约瑟家时，约瑟还在那里，他们就俯伏在他面前。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 4:10; 创世记 21:26; 创世记 3:13"> 约瑟对他们说：“你们做的是什么事？难道你们不知道像我这样的人是懂得占卜的吗？”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 44:9; 但以理书 9:7; 民数记 32:23"> 犹大说：“我们能对我主说什么呢？我们还有什么话可说呢？我们如何洗脱罪名呢？上帝既然查出你仆人们的罪，我们跟那个手上被发现有银杯的一起做我主的奴仆吧！”</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳记下 23:3; 创世记 18:25"> 约瑟回答说：“不！我决不会这样做。从谁那里搜出了银杯，谁就做我的奴仆，其他人平安地回去见你们的父亲吧。”</span>
</div>
</div>

## 犹大求情

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 32:22; 创世记 41:40; 创世记 18:30"> 犹大近前来对他说：“我主啊，你就像法老一样，求你容仆人说一句话，不要向仆人发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 43:7; 创世记 43:29; 创世记 42:7–10"> 我主曾经问仆人们是否有父亲和弟兄，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 37:3; 创世记 42:38; 路加福音 7:12"> 我们对我主说，‘我们有年迈的老父，他在晚年得了一个儿子，这孩子的哥哥已经死了，他母亲只剩下他这一个儿子，他父亲很疼爱他。’</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:15; 创世记 42:20; 阿摩司书 9:4"> 你吩咐仆人们把弟弟带来给你亲眼看看，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 44:30; 创世记 42:38"> 我们对我主说，‘这孩子不能离开他父亲，他若离开，他父亲一定会死。’</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 43:5; 创世记 43:3; 创世记 42:15–20"> 可是，你说如果仆人们不把最小的弟弟带来，就不得再见你的面。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 42:29–34"> 我们回到你仆人——我们的父亲那里，把我主的话告诉了他。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:2; 创世记 43:5"> “后来，他又吩咐仆人们回来买些粮，</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 创世记 43:4–5"> 我们告诉他，我们不能来，只有我们最小的弟弟同来，我们才能来。否则，我们不能见你的面。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 46:19; 创世记 35:16–18; 创世记 30:22–25"> 你仆人——我的父亲就对我们说，‘你们知道，我妻子给我生了两个儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 37:33; 创世记 37:13–14; 创世记 42:36"> 其中一个离我而去，我想他一定被野兽撕碎了，我再没有见过他。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 42:38; 创世记 43:14; 申命记 31:17"> 要是你们把这个也带走，遇上什么意外的话，你们会使我这白发苍苍的老人凄凄惨惨地下阴间。’</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:1; 撒母耳记下 18:33; 创世记 44:31"> “我们父亲的命与这孩子的命紧密相连，倘若我没有把这孩子带回到你仆人——我的父亲身边，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 44:29; 创世记 37:35; 哥林多后书 7:10"> 他一看这孩子不在，一定会死。仆人们会使自己白发苍苍的父亲凄凄惨惨地下阴间。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 43:8–9; 创世记 43:16"> 仆人曾经向父亲担保这孩子的安全，说我若不把这孩子带回他身边，情愿一生担罪。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰一书 3:16; 出埃及记 32:32; 希伯来书 7:22"> 现在请准许仆人代替这孩子做我主的奴仆，让他跟他哥哥们回去吧。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖记 8:6; 诗篇 116:3; 诗篇 119:143"> 这孩子若不和我一同回去，我如何见我父亲呢？我不愿看到灾难临到我父亲。”</span>

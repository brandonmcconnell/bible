## 弟兄重逢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 32:6–7; 创世记 27:41–42; 创世记 32:16"> 雅各抬头看见以扫带着四百人迎面而来，便把孩子们分别交给利亚、拉结和两个婢女，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:30; 创世记 30:22–24; 创世记 37:3"> 又让两个婢女和她们的孩子走在前面，利亚和她的孩子跟在后面，拉结和约瑟走在最后。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:6; 路加福音 14:11; 创世记 18:2"> 他自己则走在他们前面，接连俯伏下拜七次，直到他哥哥跟前。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 45:14–15; 诗篇 34:4; 路加福音 15:20"> 以扫跑上去迎接他，拥抱他，亲吻他，二人抱头痛哭。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 127:3; 以赛亚书 8:18; 创世记 48:9"> 以扫抬眼看见跟在雅各后面的妇女和孩子，就问：“这些和你同行的是谁？”雅各说：“这些孩子是上帝施恩赐给你仆人的。”</span>
<span className="v" id="v6" data-v="6"> 雅各的两个婢女和她们的孩子上前下拜，</span>
<span className="v" id="v7" data-v="7"> 利亚和她的孩子也上前下拜，最后约瑟和拉结也上前向以扫下拜。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 32:5; 创世记 39:5; 创世记 32:13–20"> 以扫说：“我在路上遇见的那一群群牲畜是怎么回事？”雅各回答说：“我带来这些是想在我主面前蒙恩。”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 27:39; 腓利门书 1:7; 创世记 27:41"> 以扫说：“弟弟，我已经有很多了，你自己留着吧！”</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 33:26; 启示录 22:4; 创世记 32:30"> 雅各说：“不，你若赏脸，就请收下！我见了你的面就像见了上帝的面，因为你这样善待我。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:27; 腓立比书 4:18; 创世记 30:43"> 请你收下我的礼物吧，因为上帝恩待了我，使我富足。”雅各再三恳求，以扫才收下。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 以扫说：“我们走吧！我陪你们走。”</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 40:11; 以西结书 34:15–16; 以西结书 34:23–25"> 雅各却说：“我主知道孩子们还幼小，而且，我还要照料正在哺乳的牛羊，如果整天赶路，牛羊都会累死。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 32:3; 以赛亚书 40:11; 罗马书 15:1"> 请我主先走，我迁就牲畜和孩子的脚步慢慢走，我在西珥与我主会合。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路得记 2:13; 创世记 47:25; 创世记 34:11"> 以扫说：“我给你留几个随从吧。”雅各说：“不用了，能得到我主的恩待就够了。”</span>
<span className="v" id="v16" data-v="16"> 于是，以扫在当天先回西珥去了，</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 60:6; 约书亚记 13:27; 士师记 8:5"> 雅各却去了疏割，在那里为自己建造房屋，为牲畜搭起棚子。因此那地方叫疏割<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“疏割”意思是“棚子”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 9:1; 使徒行传 7:16; 约书亚记 24:1"> 这样，雅各从巴旦·亚兰平安地回到迦南的示剑城，在城外搭营居住。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:16; 约翰福音 4:5; 约书亚记 24:32"> 他搭营居住的这块地是他用一百块银子向示剑的父亲哈抹的子孙买的。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:7; 创世记 21:33; 创世记 32:28"> 雅各在那里筑了一座坛，称之为伊利·伊罗伊·以色列<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“伊利·伊罗伊·以色列”意思是“以色列的上帝”。">b</a></sup>。</span>
</div>
</div>

</div>

## 以撒出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 12:6; 创世记 18:10; 创世记 18:14"> 耶和华按着自己说过的话眷顾撒拉，成就给她的应许。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 4:22; 希伯来书 11:11; 创世记 18:10"> 亚伯拉罕年老的时候，撒拉怀了孕，在上帝指定的日期为他生了一个儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 17:19; 罗马书 9:7; 创世记 21:6"> 亚伯拉罕为撒拉所生的儿子取名叫以撒。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:8; 申命记 12:32; 约翰福音 7:22–23"> 以撒出生后第八天，亚伯拉罕就照着上帝的吩咐为他行了割礼。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:17; 罗马书 4:19; 创世记 17:1"> 以撒出生时亚伯拉罕已经一百岁。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 126:2; 以赛亚书 54:1; 创世记 17:17"> 撒拉说：“上帝使我欢笑，凡听见这事的人也必跟我一同欢笑。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 18:11–12; 以赛亚书 66:8; 帖撒罗尼迦后书 1:10"> 谁会对亚伯拉罕说撒拉要哺养孩子呢？我竟然在他年老的时候给他生了儿子。”</span>
</div>
</div>

## 夏甲和以实玛利被逐

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 1:22; 何西阿书 1:8; 创世记 40:20"> 以撒渐渐长大，亚伯拉罕在他断奶的那天大摆宴席。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:29; 创世记 16:15; 加拉太书 4:22"> 撒拉见埃及人夏甲给亚伯拉罕生的儿子以实玛利嘲笑以撒，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:35; 约翰一书 2:19; 加拉太书 4:22–31"> 就对亚伯拉罕说：“赶走这婢女和她的儿子，因为这婢女的儿子不可和我的儿子以撒一同承受产业。”</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 创世记 17:18; 马太福音 10:37"> 亚伯拉罕因儿子以实玛利的事非常苦恼。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:18; 罗马书 9:7–8; 创世记 17:19"> 上帝对亚伯拉罕说：“你不要再为这孩子和你的婢女苦恼，只管照撒拉的话做，因为以撒生的才可算为你的后裔。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 16:10; 创世记 17:20; 创世记 21:18"> 至于婢女的儿子以实玛利，我也会使他自成一国，因为他也是你的后裔。”</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 9:10; 诗篇 119:60; 创世记 16:7"> 第二天，亚伯拉罕清早起来，把食物和一皮袋水给了夏甲，放在她肩上，让她和孩子离开。夏甲就走了，在别示巴的旷野流浪。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 3:9; 诗篇 63:1; 耶利米书 14:3"> 皮袋的水喝光了，夏甲把儿子留在一丛灌木下，</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:15; 创世记 29:11; 撒母耳记上 24:16"> 自己走到离孩子约一箭之远的地方，对着孩子坐下，说：“我不忍心看着他死啊！”夏甲坐在那里放声大哭起来。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 16:11; 诗篇 50:15; 出埃及记 3:7"> 上帝听见孩子的哭声，就差遣天使从天上安慰夏甲说：“夏甲，你怎么了？不要害怕，上帝已经听见孩子的哭声了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:13; 创世记 16:10; 创世记 17:20"> 你去扶他起来，用手搀着他，我必使他成为大国。”</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 22:31; 列王纪下 6:17–20; 以赛亚书 35:5–6"> 上帝开了夏甲的眼睛，让她看见一口水井，她就上前把皮袋装满水拿给儿子喝。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 28:15; 创世记 39:21; 创世记 16:12"> 在上帝的看顾下，孩子渐渐长大。他住在旷野，成为一个射箭能手。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 26:34–35; 创世记 24:3–4; 民数记 12:16"> 他住在巴兰旷野，他母亲为他娶了一个埃及女子。</span>
</div>
</div>

## 亚伯拉罕与亚比米勒立约

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:7; 创世记 26:26; 创世记 26:28"> 那时，亚比米勒和他的将领非各对亚伯拉罕说：“你做的一切都有上帝保佑。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 2:12; 创世记 20:14; 希伯来书 6:16"> 现在请你在这里当着上帝的面向我起誓，你不会欺骗我和我的子孙后代。我怎样善待你，请你也同样善待我以及你所寄居之地的百姓。”</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 6:16; 创世记 14:13; 罗马书 12:18"> 亚伯拉罕说：“我愿起誓。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 26:15–22; 创世记 29:8; 箴言 25:9"> 由于亚比米勒的仆人霸占了一口水井，亚伯拉罕就指责亚比米勒。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 13:7; 列王纪下 5:20–24"> 亚比米勒说：“我不知道是谁做的，你以前没有告诉我，我今天才听说这事。”</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 14:22–23; 以赛亚书 32:8; 罗马书 1:31"> 亚伯拉罕把牛羊送给亚比米勒，他们二人立了约。</span>
<span className="v" id="v28" data-v="28"> 亚伯拉罕又从羊群中分出七只母羊羔。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:14; 创世记 33:8; 出埃及记 12:26"> 亚比米勒问亚伯拉罕：“你分出七只母羊羔是什么意思？”</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 31:52; 约书亚记 24:27; 约书亚记 22:27–28"> 亚伯拉罕回答说：“你要从我手中接受这七只母羊羔，以证明这口井是我挖的。”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 26:33; 创世记 21:14; 列王纪上 4:25"> 所以，那地方被称为别示巴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“别示巴”意思是“盟誓之井”。">a</a></sup>，因为他们二人在那里起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 13:17; 创世记 21:27; 士师记 13:1"> 他们在别示巴立约以后，亚比米勒和他的将领非各便回非利士去了。</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太前书 1:17; 以赛亚书 40:28; 诗篇 90:2"> 亚伯拉罕在别示巴栽了一棵柳树，又在那里呼求永恒上帝耶和华的名。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 29:15; 彼得前书 2:11; 希伯来书 11:9"> 亚伯拉罕在非利士人那里住了很长时间。</span>
</div>
</div>

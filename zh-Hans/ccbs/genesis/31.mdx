## 雅各逃离拉班

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 4:4; 诗篇 49:16–17; 约伯记 31:31"> 雅各听见拉班的儿子们说：“雅各夺去了我们父亲的一切！他的财富都是从我们父亲那里得来的。”</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:19; 撒母耳记上 18:9–11; 创世记 4:5"> 雅各发觉拉班对他的态度不如从前了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 创世记 32:9; 希伯来书 13:5"> 这时，耶和华对雅各说：“回到你的家乡和亲族那里吧！我必与你同在。”</span>
<span className="v" id="v4" data-v="4"> 于是，雅各就派人把拉结和利亚叫到放羊的地方，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:2–3; 创世记 31:53; 创世记 48:15"> 对她们说：“我感到你们父亲对我不如从前了，但我父亲的上帝常与我同在。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 30:29; 以弗所书 6:5–8; 提多书 2:9–10"> 你们知道我是怎样尽心尽力地替你们父亲工作，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:28; 创世记 31:29; 民数记 14:22"> 他却欺骗我，把我的工酬更改了十次。然而，上帝不让他苦待我。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 30:32"> 如果他说把有斑点的羊给我当酬劳，羊群生的就都是有斑点的；如果他说把有条纹的给我，羊群生的就都是有条纹的。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:1; 创世记 31:16; 箴言 13:22"> 上帝就这样把你们父亲的牲畜夺过来给了我。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 13:1; 创世记 30:39; 创世记 20:6"> “在羊群交配的季节，我在梦中抬头看见和母羊交配的公羊都是有条纹或有斑点的。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:9; 创世记 31:13; 撒母耳记上 3:6"> 在梦中，上帝的天使叫我，我说，‘我在这里。’</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 3:7; 申命记 24:15; 创世记 31:42"> 他说，‘拉班对你的所作所为，我都看见了。现在你抬头看看，与母羊交配的公羊都是有条纹或有斑点的。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 31:3; 创世记 32:9; 创世记 28:12–22"> 我就是你在伯特利遇见的上帝。你在那里用油浇过柱子，向我许过愿。现在，你马上离开这里，回到你的家乡。’”</span>
<span className="v" id="v14" data-v="14" data-xref="路得记 4:11; 创世记 2:24; 创世记 29:24"> 拉结和利亚说：“父亲的家产没有我们的份儿，</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:15–20; 创世记 31:41; 创世记 29:27–30"> 我们早就被当作外人了，他卖了我们，把我们的身价全部吞了。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 30:35–1; 创世记 31:9; 诗篇 45:10"> 上帝从我们父亲那里夺过来的一切财产，理当属于我们和我们的儿女。现在你只管照上帝的吩咐做吧！”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 30:17; 创世记 24:61; 创世记 24:10"> 雅各便起来让儿女和妻子都骑上骆驼，</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:1–2; 创世记 27:41; 创世记 35:27–29"> 带着他在巴旦·亚兰得到的所有牲畜和财物，启程去迦南他父亲以撒那里。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:13; 创世记 31:30; 何西阿书 3:4"> 那时拉班正在外面剪羊毛，拉结偷了父亲家中的神像。</span>
<span className="v" id="v20" data-v="20"> 雅各不辞而别，背着亚兰人拉班偷偷地跑了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 12:17; 创世记 37:25; 创世记 46:28"> 他带着所有的一切渡过幼发拉底河，逃往基列山区。</span>
</div>
</div>

## 拉班追赶雅各

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:12–13; 创世记 30:36; 出埃及记 14:5–31"> 到了第三天，拉班才得知雅各逃走了。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 13:8; 创世记 24:27; 出埃及记 2:11"> 于是，他带着族人去追赶，追了七天，在基列山区追上了雅各。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 24:50; 创世记 31:29; 创世记 20:3"> 当晚，上帝在梦中对亚兰人拉班说：“你要当心，不可对雅各多说什么。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 12:8; 创世记 33:18; 希伯来书 11:9"> 拉班追上了雅各，那时雅各在基列山搭起帐篷，拉班和他的族人也在那里搭起帐篷。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 30:2; 创世记 12:18; 创世记 20:9–10"> 拉班对雅各说：“你做的是什么？你欺瞒我，把我的女儿像战俘一样带走。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 15:20; 箴言 26:23–26; 创世记 31:3–5"> 你为什么要偷偷地逃跑？你为什么不告诉我，我好击鼓、弹琴、唱歌欢送你？</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 31:55; 路得记 1:14; 使徒行传 20:37"> 你甚至不让我亲吻外孙和女儿，与他们道别，你这样做真愚蠢。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 31:53; 创世记 31:42; 创世记 31:24"> 我有能力伤害你，但你父亲的上帝昨夜对我说，‘你要小心，不可对雅各多说什么。’</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:11; 创世记 31:19; 士师记 18:24"> 你思家心切，一定要走，但你为什么要偷走我的神像呢？”</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 创世记 31:26–27; 创世记 20:11"> 雅各对拉班说：“我逃跑是因为害怕，我以为你会从我身边夺走你的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:3–5; 创世记 31:30; 创世记 31:19"> 至于你的神像，你在谁身上搜出来，谁就是该死的。你可以当着众弟兄的面察看，如果在我这里有什么物件是你的，你只管拿走。”雅各不知道拉结偷走了神像。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 24:67; 创世记 24:28"> 拉班进入雅各、利亚和两个婢女的帐篷搜查，却搜不出什么。拉班离开利亚的帐篷进入拉结的帐篷，</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 31:19; 创世记 31:17"> 那时拉结已经把神像藏在骆驼的鞍座里，自己坐在上面。拉班搜遍了整个帐篷，什么也找不到。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 19:32; 出埃及记 20:12; 彼得前书 2:18"> 拉结对父亲说：“请我主别生气，我有月事在身，不能起身。”结果，拉班搜来搜去找不到神像。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 4:26; 创世记 49:7; 民数记 16:15"> 雅各发怒，斥责拉班说：“我做错了什么、犯了什么罪，以致你对我穷追不舍？</span>
<span className="v" id="v37" data-v="37" data-xref="彼得前书 2:12; 哥林多前书 6:4–5; 撒母耳记上 12:3–4"> 你搜遍我所有的东西，搜到了什么？现在就当着众弟兄的面拿出来，让他们评评理吧！</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 30:27; 申命记 28:4; 以西结书 34:2–4"> 我在你家这二十年，你的母绵羊、母山羊没有掉过胎，我也没有吃过你公羊的肉。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 22:31; 出埃及记 22:10–13; 利未记 22:8"> 我没有把被野兽撕裂的羊带来给你，而是自己赔上。无论在白昼或黑夜被偷去的，你都要我赔偿。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:8; 出埃及记 2:19–22; 彼得前书 5:2–4"> 我白天受尽烈日煎熬，晚上饱尝夜露寒霜，不得好睡。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 31:7; 哥林多前书 15:10; 哥林多后书 11:26"> 这二十年来，我为了你的两个女儿，替你工作了十四年，又用了六年才从你那里得到这些羊，你把我的工钱更改了十次。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 31:7; 创世记 31:53; 以赛亚书 8:13"> 如果不是我父亲以撒敬畏的上帝，就是亚伯拉罕的上帝与我同在，你肯定会让我两手空空地回家。但上帝看见了我的难处和劳苦，所以在昨夜责备了你。”</span>
</div>
</div>

## 雅各和拉班立约

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43"> 拉班回答说：“女儿是我的，孩子是我的，羊群也是我的，你的一切都是我的，我又怎会伤害我的女儿和她们的孩子呢？</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:52; 约书亚记 24:25–27; 约书亚记 22:27"> 来吧，你我立约为证。”</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 28:18–22"> 于是，雅各拿来一块石头，立作柱子，</span>
<span className="v" id="v46" data-v="46" data-xref="传道书 3:5; 创世记 31:23; 创世记 31:54"> 又吩咐众弟兄去收集石头。他们把石头堆成一堆，在旁边吃喝。</span>
<span className="v" id="v47" data-v="47" data-xref="希伯来书 12:1"> 拉班称那石堆为伊迦尔·撒哈杜他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“伊迦尔·撒哈杜他”意思是“做见证的石堆”。">a</a></sup>，雅各却称那石堆为迦累得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“迦累得”意思是“以石堆为证”。">b</a></sup>。</span>
<span className="v" id="v48" data-v="48" data-xref="约书亚记 24:27; 约书亚记 13:8–9; 创世记 31:23"> 拉班说：“今日，这石堆是你我之间的凭证。”因此，那地方名叫迦累得，</span>
<span className="v" id="v49" data-v="49" data-xref="士师记 11:29; 士师记 10:17; 撒母耳记上 7:5–6"> 又叫米斯巴，因为拉班说：“我们分手以后，愿上帝亲自鉴察我们。</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 42:5; 耶利米书 29:23; 弥迦书 1:2"> 倘若你虐待我的女儿，或在她们以外另娶妻子，即使没人知道，也有上帝在你我之间做见证。”</span>
<span className="v" id="v51" data-v="51"> 拉班又说：“看我在你我之间立的这石堆和石柱。</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 31:48; 创世记 31:44–45"> 这石堆和石柱都是凭证，我不会越过石堆去害你，你也不可越过石堆和石柱来害我。</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 31:42; 创世记 16:5; 约书亚记 24:2"> 愿亚伯拉罕的上帝和拿鹤的上帝，就是他们父亲的上帝，在你我之间判断是非。”雅各便凭他父亲以撒敬畏的上帝起誓，</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 18:12; 创世记 37:25; 创世记 26:30"> 又在山上献祭，请众弟兄吃饭。饭后，他们一同在山上过夜。</span>
<span className="v" id="v55" data-v="55" data-xref="创世记 31:28; 申命记 23:5; 创世记 18:33"> 拉班清早起来，亲吻外孙和女儿，给他们祝福，然后回家去了。</span>
</div>

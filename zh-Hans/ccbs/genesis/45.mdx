## 约瑟与弟兄相认

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:15; 使徒行传 10:41; 创世记 43:30–31"> 约瑟在侍从面前再也控制不住自己，于是令所有侍从都出去。这样，约瑟跟弟兄们相认时，没有外人在场。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 46:29; 使徒行传 20:37; 民数记 14:1"> 约瑟放声大哭，埃及人听见了他的哭声，法老家也听到了消息。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:13; 使徒行传 9:5; 撒迦利亚书 12:10"> 约瑟对他的弟兄们说：“我是约瑟！我的父亲还健在吗？”他的弟兄们吓得说不出话来。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 37:28; 马太福音 14:27; 创世记 50:18"> 约瑟叫他们走近一点，等他们靠近了，便说：“我是被你们卖到埃及的弟弟约瑟！</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 50:20; 使徒行传 7:9–15; 创世记 45:7–8"> 现在，你们不要因为把我卖到这里而自怨自责。上帝差我先来这里，是为了保住大家的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 47:23; 创世记 41:54; 创世记 41:56"> 地上的饥荒已经两年了，我们还有五年不能种、不能收。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:4; 使徒行传 7:35; 诗篇 18:50"> 上帝差我先来，是要为你们保留后代，又要大施拯救，保住你们的性命。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:16; 罗马书 9:16; 约翰福音 19:11"> 这样看来，不是你们，是上帝把我送到这里的。祂使我成为法老的宰相，管理他的家和整个埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:19–20; 创世记 45:13"> 你们快回去告诉我父亲，他儿子约瑟说，‘上帝已经使我管理整个埃及，请你立刻来我这里。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 9:26; 出埃及记 8:22; 创世记 46:34–6"> 你可以带着你的子孙、牛羊及一切所有住在歌珊。那里离我很近，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 47:12; 创世记 47:6; 马太福音 15:5–6"> 我可以奉养你，以免你和全家老少及仆婢牲畜都陷入绝境，因为还有五年的饥荒。’</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:23; 路加福音 24:39; 约翰福音 20:27"> 你们和我弟弟便雅悯都亲眼看见了，这是我亲口对你们说的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:14; 启示录 21:23; 彼得前书 1:10–12"> 你们要把我在埃及享有的尊荣和你们见到的一切都告诉父亲，尽快把他接来。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 33:4; 创世记 29:11; 创世记 46:29"> 约瑟和弟弟便雅悯抱头痛哭，</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳记上 10:1; 诗篇 77:4"> 又亲吻其他哥哥，抱着他们痛哭，然后弟兄们跟他交谈起来。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 41:33; 以斯帖记 1:21; 创世记 20:15"> 约瑟的弟兄们到来的消息传到法老的王宫，法老和他的臣仆都感到高兴。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 42:25–26; 创世记 44:1–2"> 法老对约瑟说：“你去吩咐你的弟兄给牲畜驮上货物，返回迦南，</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:28; 民数记 18:12; 创世记 47:6"> 把你们的父亲和家眷都接到我这里。我要把埃及最好的土地赐给他们，让他们享受这里肥美的物产。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 46:5; 创世记 45:27; 创世记 31:17–18"> 吩咐你的弟兄从埃及带着车去把他们的妻子、儿女和你们的父亲接来。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 1:19; 路加福音 17:31; 申命记 7:16"> 不要舍不得你们在迦南的财产，因为埃及全国的美物都是你们的。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 45:19; 以西结书 23:24; 耶利米哀歌 1:18"> 以色列的儿子们就这样做了。约瑟遵照法老的吩咐，为他的弟兄们预备好车辆和路上需用的粮食，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 43:34; 列王纪下 5:5; 士师记 14:12"> 又给他们每人一套新衣服，但给了便雅悯五套新衣服和三百块银子。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:10; 出埃及记 16:3; 创世记 43:11"> 约瑟送给父亲十头公驴，驮着埃及的美物，还送了十头母驴，驮着粮食、饼和其他食物，让父亲路上用。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:13; 诗篇 133:1–3; 创世记 42:21–22"> 约瑟送弟兄们回去，临行前嘱咐他们路上不要争吵。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 于是，他们离开埃及，回到迦南的父亲雅各那里，</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 44:28; 创世记 37:35; 路加福音 24:34"> 对父亲说：“约瑟还活着，并且做了埃及的宰相。”雅各惊呆了，不敢相信他们的话。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 85:6; 以赛亚书 57:15; 创世记 45:19"> 雅各听了他们转述约瑟的话，又看见约瑟派来接他的车，才回过神来。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 约翰福音 16:21–22; 创世记 46:30"> 以色列说：“我信了！我儿约瑟还活着，我要在死之前去见他。”</span>
</div>
</div>

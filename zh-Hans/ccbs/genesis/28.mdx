<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 28:3–4; 创世记 24:3; 创世记 27:46"> 以撒把雅各叫来，给他祝福，又嘱咐他说：“你不要娶迦南的女子为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 25:20; 何西阿书 12:12; 创世记 24:50"> 马上去巴旦·亚兰，到你外祖父彼土利家，在你舅父拉班的女儿中选一个做妻子。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 48:3; 创世记 35:11; 创世记 1:28"> 愿全能的上帝赐福给你，使你生养众多，人丁兴旺，成为许多民族。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 3:14; 创世记 12:7; 以弗所书 1:3"> 愿上帝把赐给亚伯拉罕的福气赐给你和你的后代，让你承受你寄居之地为产业，就是上帝赐给亚伯拉罕的土地。”</span>
<span className="v" id="v5" data-v="5"> 以撒让雅各前往巴旦·亚兰，去亚兰人彼土利的儿子拉班那里。拉班是雅各和以扫的舅父。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 27:33; 创世记 28:1"> 以扫看见以撒给雅各祝福，让他到巴旦·亚兰娶妻，叮嘱他不要娶迦南的女子，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:1; 以弗所书 6:3; 歌罗西书 3:20"> 又看见雅各听从父母到巴旦·亚兰去了，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:3; 创世记 26:34–35; 撒母耳记上 8:6"> 就知道父亲以撒不喜欢迦南的女子。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 36:3; 创世记 36:18; 创世记 36:13"> 他便到亚伯拉罕的儿子以实玛利那里，娶了以实玛利的女儿、尼拜约的妹妹玛哈拉为妻。他娶玛哈拉以前已经有两个妻子了。</span>
</div>
</div>

## 雅各的梦

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:2; 创世记 11:31; 创世记 32:10"> 雅各离开别示巴，前往哈兰。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 8:20; 创世记 28:18; 创世记 31:46"> 到了一个地方，太阳已经下山，他便在那里过夜。他就地取了一块石头枕在头下睡觉，</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:51; 民数记 12:6; 创世记 32:1–2"> 梦中看见有个梯子立在地上，直通到天上，梯子上有上帝的天使上上下下。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 13:15; 创世记 48:3; 创世记 35:12"> 耶和华站在梯子上面<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“梯子上面”或译“他旁边”。">a</a></sup>对雅各说：“我是耶和华，是你祖父亚伯拉罕的上帝，也是以撒的上帝。我要把你现在躺卧的地方赐给你和你的后代。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 12:3; 使徒行传 3:25; 创世记 18:18"> 你的后代必多如地上的尘土，遍布四方，地上万族必因你和你的后裔而蒙福。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:5; 以赛亚书 41:10; 耶利米书 1:19"> 我与你同在，无论你去哪里，我都会保护你，领你返回这片土地。我必实现对你的应许，决不离弃你。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 5:15; 出埃及记 3:5; 出埃及记 15:11"> 雅各一觉醒来，说：“耶和华诚然在这里，我竟不知道。”</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 3:15; 创世记 35:1–13; 传道书 5:1"> 他就害怕起来，说：“这地方何等可畏！这里正是上帝的殿，是通天的大门。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 35:14; 创世记 31:45; 创世记 31:13"> 雅各清早起来，把枕的那块石头立成柱子，在上面浇上油。</span>
<span className="v" id="v19" data-v="19" data-xref="何西阿书 12:4–5; 创世记 35:1; 创世记 48:3"> 他称那地方为伯特利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“伯特利”意思是“上帝的家”。">b</a></sup>，那地方以前叫路斯。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 6:8; 撒母耳记下 15:8; 创世记 31:13"> 雅各许愿说：“如果上帝与我同在，一路保护我，供给我衣食，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:31; 申命记 26:17; 撒母耳记下 19:24"> 带领我平安地回到父亲家，我就一定奉耶和华为我的上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 35:7; 创世记 14:20; 申命记 14:22–23"> 我立为柱子的这块石头必成为上帝的殿。凡你赐给我的，我必把十分之一献给你。”</span>
</div>
</div>

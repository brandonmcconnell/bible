## 以撒为儿子祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 3:2; 创世记 48:10; 创世记 25:23–25"> 以撒年老的时候，眼睛昏花，几乎看不见。他把大儿子以扫叫来，说：“我儿啊！”以扫说：“我在这里。”</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 4:14; 传道书 9:10; 箴言 27:1"> 以撒说：“我年老了，不知道还能活多久。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 25:27–28; 创世记 10:9; 哥林多前书 6:12"> 现在，带着你的弓箭去田野为我打些野味来，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:20; 创世记 48:9; 创世记 49:28"> 照我喜欢的口味，做成美食给我吃，以便我在死前给你祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 利百加听见了以撒跟儿子以扫说的话。以扫出去打猎后，</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 25:28"> 利百加就对她儿子雅各说：“我听见你父亲对你哥哥以扫说，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 6:26; 撒母耳记上 24:19; 申命记 33:1"> ‘你去打些野味回来，做成美食给我吃，以便我死之前在耶和华面前给你祝福。’</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:1; 创世记 27:13; 使徒行传 5:29"> 现在，我儿，你要听我的话，照我的吩咐去做。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:15; 撒母耳记上 16:20"> 你到羊群里牵两只上好的山羊羔给我，我好照你父亲喜爱的口味做成美食，</span>
<span className="v" id="v10" data-v="10"> 由你拿去给他吃，让他死前为你祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 25:25"> 雅各对母亲利百加说：“哥哥以扫浑身是毛，我的皮肤光滑。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:18; 创世记 25:27; 玛拉基书 1:14"> 如果父亲用手摸我，一定会发觉我骗他，那时候我不但得不到祝福，反会招来咒诅。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 27:25; 撒母耳记上 25:24; 撒母耳记下 14:9"> 他母亲利百加对他说：“我儿啊，有咒诅，我来承担。你只管听我的话，把羊羔牵来。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 27:9; 箴言 23:2–3; 创世记 25:28"> 于是，雅各把羊牵来交给母亲，他母亲就照他父亲喜爱的口味做成美食。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 27:27; 路加福音 20:46; 路加福音 15:22"> 利百加又拿了大儿子以扫留在家里的最好的衣服，给小儿子雅各穿上，</span>
<span className="v" id="v16" data-v="16"> 再用山羊皮把雅各的手和脖子的光滑处都包起来，</span>
<span className="v" id="v17" data-v="17"> 然后把做好的美味和饼交给儿子雅各。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18"> 雅各来到父亲跟前，叫了一声：“父亲。”以撒回答说：“我在这里，儿子，你是哪一个？”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 28:15; 马太福音 26:70–74; 撒迦利亚书 13:3–4"> 雅各对父亲说：“我是你的大儿子以扫，你吩咐我的事，我已经办好了。请你坐起来，吃我打的野味，然后给我祝福。”</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:7; 约伯记 13:7; 创世记 24:12"> 以撒对他说：“我儿，你怎么这么快就打到野味了？”雅各回答说：“因为你的上帝耶和华让我碰见好机会。”</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:8; 以赛亚书 57:19; 创世记 27:12"> 以撒对雅各说：“我儿，过来，让我摸摸看你是不是我儿以扫。”</span>
<span className="v" id="v22" data-v="22"> 雅各挨到父亲跟前，以撒摸着他说：“声音是雅各的声音，手却是以扫的手。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 27:16; 希伯来书 11:20; 罗马书 9:11–12"> 因为雅各手上有毛，与他哥哥以扫的手一样，以撒分辨不出来，就给他祝福。</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:9; 以弗所书 4:25; 箴言 12:22"> 以撒又问：“你真是我的儿子以扫吗？”雅各回答说：“我是。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 27:4"> 以撒便说：“把你打的野味拿给我，我吃了好为你祝福。”雅各递上野味，以撒吃了；雅各又拿酒给他喝，他也喝了。</span>
<span className="v" id="v26" data-v="26"> 父亲以撒对他说：“我儿，你过来亲吻我。”</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 6:7; 诗篇 65:10; 希伯来书 11:20"> 雅各就挨上前去亲了父亲。以撒闻到他衣服上的香气，就祝福他说：<br /><span className="pl pl-1">“我儿子的香气就像蒙耶和华赐福之田地的香气。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:28; 申命记 33:13; 诗篇 133:3"> <span className="pl pl-1">愿上帝赐你天上的甘露、肥沃的土地并丰富的五谷和新酒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="创世记 12:3; 民数记 24:9; 以赛亚书 49:23"> <span className="pl pl-1">愿万民都侍奉你，</span><br /><span className="pl pl-1">万国都向你下拜。</span><br /><span className="pl pl-1">愿你成为你弟兄的主人，</span><br /><span className="pl pl-1">愿你母亲的儿子向你下拜。</span><br /><span className="pl pl-1">咒诅你的，愿他受咒诅；</span><br /><span className="pl pl-1">祝福你的，愿他蒙祝福。”</span></span>
</div>
</div>

## 以扫求父亲祝福

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30"> 雅各接受了以撒的祝福才刚离开，他的哥哥以扫就打猎回来了。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 27:4"> 以扫也做好美味，拿到父亲跟前，说：“父亲，请起来吃你儿子打的野味，好给我祝福。”</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 27:18"> 他父亲以撒问道：“你是谁？”以扫回答说：“我是你的儿子，你的长子以扫。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 28:3–4; 罗马书 11:29; 以弗所书 1:3"> 以撒惊得剧烈颤抖，说：“在你来之前拿野味给我吃的是谁呢？我已经吃了，也给那人祝福了，他将来必蒙祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="希伯来书 12:17; 箴言 1:31; 撒母耳记上 30:4"> 以扫听了放声痛哭，说：“父亲啊，求你也为我祝福！”</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦前书 4:6; 约伯记 13:7; 玛拉基书 2:10"> 以撒说：“你弟弟已经用诡计把你的福分夺去了。”</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 25:26; 约翰福音 1:47; 创世记 32:28"> 以扫说：“怪不得他叫雅各，他已经骗了我两次，先前把我长子的名分夺去，现在又夺去我的福分！”接着他对父亲说：“难道你没有留下别的祝福可以给我吗？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 8:14; 创世记 27:28–29; 创世记 25:23"> 以撒对以扫说：“我已经立他做你的主人，使他的众弟兄做他的仆人，并给他五谷和新酒。我儿啊，我还能为你做什么呢？”</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 12:17; 创世记 27:34; 以赛亚书 65:14"> 以扫对父亲说：“父亲啊，你只有一个祝福吗？父亲啊，求你也为我祝福！”以扫又放声大哭。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 27:28; 希伯来书 11:20; 约书亚记 24:4"> 以撒对他说：<br /><span className="pl pl-1">“你住的地方必远离肥沃的土地，</span><br /><span className="pl pl-1">也不会有天上的甘霖。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 8:20–22; 创世记 25:23; 历代志下 25:11–12"> <span className="pl pl-1">你必倚靠刀剑生活，</span><br /><span className="pl pl-1">又必服侍你的弟弟。</span><br /><span className="pl pl-1">到你无法忍受的时候，</span><br /><span className="pl pl-1">必挣脱他放在你颈上的轭。”</span></span>
</div>
</div>

## 雅各逃往舅父家

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰一书 3:12–15; 创世记 37:4; 创世记 50:3–4"> 以扫因为父亲把祝福给了雅各，就对雅各怀恨在心，暗自思量说：“父亲已经不久人世，我服完丧就把我弟弟雅各杀掉！”</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 37:18–20; 撒母耳记上 30:5; 创世记 42:21–22"> 大儿子以扫的计谋传到利百加耳中。她就派人把小儿子雅各叫来，对他说：“你哥哥以扫想要杀你泄愤！</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 27:8; 创世记 11:31; 创世记 27:13"> 我儿，听我的话，现在就逃到哈兰我哥哥拉班那里，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:38; 创世记 31:41"> 与他住些日子，一直住到你哥哥的气消了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 创世记 4:8–16; 创世记 9:5–6"> 等他对你的气消了，忘了你对他所做的事，我会派人接你回来。我何必在一天之内失去你们两个呢？”</span>
<span className="v" id="v46" data-v="46" data-xref="创世记 24:3; 创世记 26:34–35; 创世记 28:8"> 利百加对以撒说：“我被这些赫人女子烦死了。如果雅各也娶那些赫人女子为妻，我活着还有什么意思呢？”</span>
</div>
</div>

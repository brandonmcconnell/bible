## 上帝创造天地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:1–3; 希伯来书 11:3; 以赛亚书 45:18"> 太初，上帝创造了天地。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 4:23; 诗篇 104:30; 以赛亚书 45:18"> 那时，大地空虚混沌，黑暗笼罩着深渊，上帝的灵运行在水面上。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:6; 约翰福音 1:5; 以赛亚书 45:7"> 上帝说：“要有光！”就有了光。</span>
<span className="v" id="v4" data-v="4" data-xref="传道书 2:13; 创世记 1:18; 传道书 11:7"> 上帝看光是好的，就把光和黑暗分开。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 74:16; 以赛亚书 45:7; 帖撒罗尼迦前书 5:5"> 上帝称光为昼，称黑暗为夜。晚上过去，早晨到来，这是第一日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“这是第一日”或译“这是一日”。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:15; 诗篇 33:6; 约伯记 37:18"> 上帝说：“水与水之间要有穹苍，把水分开。”</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 诗篇 148:4; 马太福音 8:27"> 果然如此。上帝造了穹苍，将穹苍之下的水和穹苍之上的水分开。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:5; 创世记 1:19; 创世记 1:10"> 上帝称穹苍为天空。晚上过去，早晨到来，这是第二日。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得后书 3:5; 约拿书 1:9; 耶利米书 5:22"> 上帝说：“天空下面的水要聚在一处，使干地露出来。”果然如此。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:4; 诗篇 104:31; 创世记 1:4"> 上帝称干地为陆地，称汇聚的水为海洋。上帝看了，觉得美好。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 104:14–17; 希伯来书 6:7; 诗篇 147:8"> 上帝说：“陆地要长出植物——各类结种子的菜蔬和结果子的树木，果子内都有籽。”果然如此，</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:28; 以赛亚书 55:10–11; 马太福音 13:24–26"> 陆地长出了植物——各类结种子的菜蔬和结果子的树木，果子内都有籽。上帝看了，觉得美好。</span>
<span className="v" id="v13" data-v="13"> 晚上过去，早晨到来，这是第三日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19–20; 申命记 4:19; 耶利米书 31:35"> 上帝说：“天空要有光体，以区分昼夜，作记号，定节令，计算年日，</span>
<span className="v" id="v15" data-v="15"> 在天空发光，普照大地。”果然如此。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 136:7–9; 申命记 4:19; 诗篇 8:3"> 上帝造了两个大光体，大的管昼，小的管夜，又造了星辰。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 8:3; 诗篇 8:1; 约伯记 38:12"> 上帝把这些光体摆列在天空，让它们发光普照大地，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:35; 诗篇 19:6"> 管理昼夜，分开光和黑暗。上帝看了，觉得美好。</span>
<span className="v" id="v19" data-v="19"> 晚上过去，早晨到来，这是第四日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 2:19; 诗篇 104:24–25; 列王纪上 4:33"> 上帝说：“水中要充满各种动物，空中要有禽鸟飞翔。”</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 104:24–26; 创世记 1:25; 创世记 8:19"> 上帝就创造了海中的大鱼等各类水族和各类禽鸟。上帝看了，觉得美好。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 40:15; 创世记 8:17; 诗篇 107:38"> 上帝赐福给这一切生物，说：“水族要多多地生养繁衍，充满海洋，禽鸟也要在地上多多地繁衍。”</span>
<span className="v" id="v23" data-v="23"> 晚上过去，早晨到来，这是第五日。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 50:9–10; 创世记 6:20; 创世记 8:19"> 上帝说：“大地要繁衍各类动物——各类的牲畜、爬虫和野兽。”果然如此。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 27:5; 约伯记 12:8–10; 创世记 2:19–20"> 上帝造了地上的各类野兽、牲畜和爬虫。上帝看了，觉得美好。</span>
</div>
</div>

## 上帝照自己的形象造人

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:10; 以弗所书 4:24; 诗篇 8:4–8"> 上帝说：“我们要照着我们的形象，按着我们的样式造人，让他们管理海里的鱼、空中的鸟和地上的牲畜及一切爬虫。”</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:4; 以弗所书 2:10; 创世记 5:1–2"> 上帝就照着自己的形象造了人，祂照着自己的形象造了男人和女人。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 9:1; 创世记 9:7; 利未记 26:9"> 上帝赐福给他们，对他们说：“你们要生养众多，遍满地面，治理大地，管理海里的鱼、空中的鸟以及地上的各种动物。”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 9:3; 诗篇 104:14–15; 诗篇 145:15–16"> 上帝说：“看啊，我把地上所有结种子的谷蔬和所有树上有籽的果子都赐给你们作食物。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 104:14; 诗篇 145:15–16; 诗篇 147:9"> 我把绿色植物赐给所有地上的走兽、空中的飞鸟及地上的爬虫等有气息的动物作食物。”果然如此。</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太前书 4:4; 诗篇 104:24; 诗篇 19:1–2"> 上帝看了祂所造的一切，觉得非常美好。晚上过去，早晨到来，这是第六日。</span>
</div>
</div>

## 亚伯兰与罗得分道扬镳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:9–20; 约书亚记 10:40; 撒母耳记下 24:7"> 亚伯兰带着妻子、侄儿罗得和所有的一切，离开埃及去南地。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 24:35; 诗篇 112:1–3; 创世记 26:12–13"> 那时亚伯兰已经拥有很多牲畜和金银。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:8–9; 创世记 12:6"> 他从南地渐渐迁移到伯特利，到了他从前在伯特利和艾中间搭帐篷和筑坛的地方。他又在那里求告耶和华的名。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 49:29; 创世记 25:27; 创世记 4:20"> 和亚伯兰同行的罗得也有牛群、羊群和帐篷。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 36:6–7; 传道书 5:10–11; 提摩太前书 6:9"> 他们的牲畜很多，那地方容纳不下，他们无法住在一起。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 26:20; 创世记 12:6; 雅各书 3:16"> 亚伯兰的牧人和罗得的牧人之间起了纷争。那时，迦南人和比利洗人也住在那里。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 6:6–7; 使徒行传 7:26; 诗篇 133:1"> 亚伯兰对罗得说：“我们之间不该有纷争，我们的牧人之间也不该有纷争，因为我们是骨肉至亲。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 20:15; 创世记 34:10; 彼得前书 3:8–12"> 整片土地不就在你面前吗？我们分开吧。如果你往左边去，我就往右边走；如果你往右边去，我就往左边走。”</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 34:3; 以赛亚书 51:3; 创世记 14:8"> 罗得举目眺望，看见整个约旦河平原，远至琐珥，水源充足。在耶和华毁灭所多玛和蛾摩拉之前，那地方就好像耶和华的园子，又像埃及。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 13:9; 彼得前书 2:17; 希伯来书 10:25"> 于是，罗得选了整个约旦河平原，向东迁移，他们便分开了。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 19:29; 创世记 14:12; 创世记 19:1"> 亚伯兰住在迦南，罗得则住在平原的城邑里，并渐渐把帐篷迁移到所多玛附近。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:10; 彼得后书 2:6–8; 犹大书 1:7"> 所多玛人极其邪恶，在耶和华眼中罪恶滔天。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 49:18; 申命记 3:27; 创世记 28:14"> 罗得离开后，耶和华对亚伯兰说：“从你站的地方向东西南北眺望，</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 20:7; 创世记 35:12; 创世记 15:18"> 你所能看见的地方，我都要赐给你和你的后裔，直到永远。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 28:14; 民数记 23:10; 创世记 32:12"> 我要使你的后裔多如地上的尘土，人若能数算地上的尘土，才能数算你的后裔。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 13:15; 民数记 13:17–24"> 你起来走遍这片土地，因为我要把这片土地赐给你。”</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 18:1; 创世记 8:20; 创世记 35:27"> 亚伯兰就把帐篷迁移到希伯仑，在幔利的橡树附近居住，在那里为耶和华筑了一座祭坛。</span>

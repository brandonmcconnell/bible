## 夏甲与以实玛利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:24; 创世记 12:16; 创世记 15:2–3"> 亚伯兰的妻子撒莱没有给他生孩子。撒莱有个婢女名叫夏甲，是埃及人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 21:4; 创世记 18:10; 创世记 3:17"> 撒莱对亚伯兰说：“耶和华不让我生育，请你与我的婢女同房，也许我可以借着她得子立后。”亚伯兰同意了撒莱的话。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 16:5; 创世记 12:4–5; 撒母耳记下 5:13"> 于是，撒莱把埃及婢女夏甲给亚伯兰做妾。那时亚伯兰已经在迦南住了十年。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:23; 撒母耳记下 6:16; 哥林多前书 13:4–5"> 亚伯兰与夏甲同房，她就怀了孕。夏甲知道自己怀了孕，就轻视女主人撒莱。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:53; 出埃及记 5:21; 诗篇 7:8"> 撒莱对亚伯兰说：“我受气都是因为你。我把婢女放在你怀里，她仗着自己怀了孕就轻视我，愿耶和华在你我之间主持公道。”</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 38:5; 箴言 14:29; 彼得前书 3:7"> 亚伯兰对撒莱说：“婢女在你手中，随你处置。”于是，撒莱苦待夏甲，夏甲就逃走了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 25:18; 出埃及记 15:22; 创世记 21:17"> 耶和华的天使在旷野中，通往书珥之路的水泉旁找到了夏甲，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 3:9; 创世记 4:10; 传道书 10:4"> 便问她：“撒莱的婢女夏甲，你从哪里来？要到哪里去？”她回答说：“我是从女主人撒莱那里逃出来的。”</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:5–6; 传道书 10:4; 提多书 2:9"> 耶和华的天使对她说：“你要回到女主人那里顺服她。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:20; 诗篇 83:6–7; 创世记 25:12–18"> 又说：“我必使你的后裔多得不可胜数。”</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 2:23–24; 出埃及记 3:7; 以赛亚书 7:14"> 接着又说：“你现在怀了孕，将来会生一个男孩，你要给他取名叫以实玛利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以实玛利”意思是“上帝听见了”。">a</a></sup>，因为耶和华已经听见你痛苦的哀声。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:18; 创世记 21:20; 约伯记 39:5–8"> 这孩子性情必像野驴，他要跟人作对，人也要跟他作对。他必与他所有的弟兄为敌。”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 139:1–12; 创世记 32:30; 箴言 5:21"> 夏甲称对她说话的耶和华为“看顾人的上帝”，她说：“我竟然在这里看见了那位看顾我的。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 24:62; 创世记 25:11; 创世记 21:31"> 因此，那口井被称为庇耳·拉海·莱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“庇耳·拉海·莱”意思是“看顾我的永恒上帝之井”。">b</a></sup>，位于加低斯和巴列之间。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 25:12; 创世记 21:9–21; 创世记 17:25–26"> 后来夏甲为亚伯兰生了一个儿子，亚伯兰给他取名叫以实玛利。</span>
<span className="v" id="v16" data-v="16"> 夏甲生以实玛利时，亚伯兰八十六岁。</span>
</div>

## 雅各迁往伯特利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 31:13; 何西阿书 12:4; 诗篇 91:15"> 上帝对雅各说：“你到伯特利去住，你要在那里为上帝筑一座坛，祂在你逃避你哥哥以扫时曾向你显现。”</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:14; 出埃及记 19:10; 以西结书 18:31"> 于是，雅各吩咐家人和所有的随从：“你们要除掉你们当中的外族神像，洁净自己，更换衣服。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 43:2; 创世记 32:7; 创世记 31:3"> 我们要上伯特利去，在那里为上帝筑一座坛，祂在我遭遇患难时听了我的祷告，一路都与我同在。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:6; 申命记 7:25; 出埃及记 32:20"> 他们把所有外族的神像和自己的耳环都交给雅各，雅各把这些东西埋在示剑的橡树下。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:27; 历代志下 17:10; 约书亚记 5:1"> 他们就出发了，上帝使恐惧笼罩周围的城邑，没有人敢追赶他们。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 28:19; 创世记 28:22; 创世记 12:8"> 雅各和所有的随从来到迦南的路斯，也就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:13"> 他在那里建造了一座坛，称那地方为伊勒·伯特利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“伊勒·伯特利”意思是“伯特利的上帝”。">a</a></sup>，因为在他逃避哥哥的时候，上帝曾在那里向他显现。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:59; 撒母耳记上 31:13; 士师记 2:5"> 后来利百加的奶妈底波拉死了，葬在伯特利下面的橡树下，那棵树叫亚伦·巴古<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“亚伦·巴古”意思是“哭泣的橡树”。">b</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 35:1; 创世记 18:1; 创世记 26:2"> 雅各从巴旦·亚兰回来后，上帝又向他显现，赐福给他。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:5; 创世记 32:27–28; 创世记 17:15"> 上帝对他说：“你叫雅各，但从今以后不要再叫雅各了，你要改名叫以色列。”这样雅各改名为以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:1; 创世记 9:1; 创世记 22:17"> 上帝又说：“我是全能的上帝，你要生养众多，人丁兴旺，一国，甚至多国必从你而出，许多君王必出自你的子孙。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:7; 创世记 28:13; 创世记 26:3–4"> 我要把赐给亚伯拉罕和以撒的土地赐给你和你的后代。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 17:22; 创世记 18:33; 士师记 6:21"> 上帝说完就离开雅各升上天去。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 28:18–19; 撒母耳记上 7:12; 出埃及记 17:15"> 雅各在上帝跟他说话的地方立了一根石柱，又在柱子上奠酒、浇油，</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 28:19"> 称那地方为伯特利。</span>
</div>
</div>

## 拉结和以撒去世

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="弥迦书 5:2; 创世记 48:7; 列王纪下 5:19"> 他们从伯特利继续前行，离以法他还有一段路时，拉结要分娩，出现难产。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:24; 撒母耳记上 4:19–21"> 接生婆对难产的她说：“不要害怕，你又添了一个儿子！”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行传 7:59; 路加福音 23:46"> 拉结咽气前给儿子取名叫便·俄尼<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“便·俄尼”意思是“我在苦难中生的儿子”。">c</a></sup>，雅各却叫他便雅悯<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“便雅悯”意思是“右手之子”，“右手”希伯来文有幸运或力量的意思。">d</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 5:2; 创世记 48:7; 路得记 4:11"> 拉结死后就葬在通往以法他的路旁，以法他即伯利恒。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:2; 创世记 35:14; 撒母耳记下 18:17–18"> 雅各在她的坟上立了石碑，这碑至今还在。</span>
<span className="v" id="v21" data-v="21" data-xref="弥迦书 4:8; 路加福音 2:8"> 以色列继续前行，在以得塔附近搭起了帐篷。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 5:1; 利未记 18:8; 撒母耳记下 20:3"> 以色列在那里居住时，吕便和父亲的妾辟拉通奸，以色列也知道这件事。 雅各有十二个儿子。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 30:18–20; 创世记 46:8–15; 创世记 29:32–35"> 利亚生了雅各的长子吕便，还有西缅、利未、犹大、以萨迦和西布伦。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 30:22–24; 创世记 46:19–22; 创世记 35:16–18"> 拉结生了约瑟和便雅悯。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 46:23–25; 创世记 37:2; 创世记 30:4–8"> 拉结的婢女辟拉生了但和拿弗他利。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 30:9–13; 创世记 46:16–18; 创世记 25:20"> 利亚的婢女悉帕生了迦得和亚设。他们都是雅各的儿子，是在巴旦·亚兰出生的。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 13:18; 创世记 23:19; 创世记 18:1"> 雅各来到他父亲以撒住的幔利，即基列·亚巴，也就是亚伯拉罕和以撒寄居的地方。基列·亚巴就是希伯仑。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 25:7; 创世记 50:26; 创世记 47:28"> 以撒享年一百八十岁，</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 15:15; 创世记 49:33; 创世记 49:31"> 年纪老迈，寿终正寝，归到他祖先那里。他的儿子以扫和雅各把他安葬了。</span>
</div>

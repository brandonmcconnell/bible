## 亚伯拉罕的其他后代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 1:32–33; 创世记 23:1–2; 创世记 28:1"> 亚伯拉罕又娶了基土拉为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 1:32–33; 民数记 25:17–18; 约伯记 2:11"> 基土拉为亚伯拉罕生了心兰、约珊、米但、米甸、伊施巴和书亚。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 25:13; 耶利米书 49:8; 以西结书 27:20"> 约珊生了示巴和底但，底但的子孙是亚书利族、利都示族和利乌米族。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 60:6"> 米甸的儿子是以法、以弗、哈诺、亚比大和以勒大。这些都是基土拉的子孙。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 24:36; 希伯来书 1:2; 加拉太书 3:29"> 亚伯拉罕把所有的财产都给了以撒。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 21:14; 士师记 6:3; 使徒行传 14:17"> 他趁自己还在世的时候，把一些财物送给他的妾所生的儿子们，让他们离开他的儿子以撒到东方去。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 12:4"> 亚伯拉罕活了一百七十五岁，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:28–29; 创世记 15:15; 历代志上 29:28"> 享尽天年，寿终正寝，归到他祖先那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 50:13; 创世记 35:29; 创世记 49:29–30"> 他的两个儿子以撒和以实玛利把他安葬在麦比拉洞，那山洞在幔利附近、赫人琐辖的儿子以弗仑的地里。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 23:16; 创世记 49:31"> 那块地是亚伯拉罕向赫人买的，他和妻子撒拉都葬在那里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 22:17; 创世记 16:14; 创世记 24:62"> 亚伯拉罕去世以后，上帝赐福给他的儿子以撒。以撒住在庇耳·拉海·莱附近。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:6; 创世记 17:20; 创世记 21:13"> 以实玛利是亚伯拉罕和撒拉的婢女埃及人夏甲所生的儿子，以下是以实玛利的后代。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:29–31; 以赛亚书 60:7; 雅歌 1:5"> 以实玛利的儿子按出生的次序名字如下：长子尼拜约，然后是基达、亚德别、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 21:11; 以赛亚书 21:16"> 米施玛、度玛、玛撒、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 5:19; 约伯记 2:11"> 哈大、提玛、伊突、拿非施、基底玛。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:20; 创世记 17:23"> 这些都是以实玛利的儿子，他们按照其村庄和营寨分别做了十二个族的族长。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:15; 创世记 25:7–8"> 以实玛利活了一百三十七岁，寿终正寝，归到他祖先那里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 16:12; 创世记 20:1; 列王纪下 23:29"> 他子孙居住的地方从哈腓拉一直延伸到埃及东面、通往亚述方向的书珥，他们与其他亲属作对<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“与其他亲属作对”或译“住在其他亲属的东面”。">a</a></sup>。</span>
</div>
</div>

## 利百加生以扫和雅各

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:2; 路加福音 3:34; 使徒行传 7:8"> 以下是关于亚伯拉罕的儿子以撒的记载。<br />亚伯拉罕生以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:29; 创世记 24:67; 创世记 22:23"> 以撒四十岁娶利百加，利百加是巴旦·亚兰的亚兰人彼土利的女儿、拉班的妹妹。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以赛亚书 58:9; 以斯拉记 8:23"> 以撒因为利百加不生育，就为她祈求耶和华。耶和华应允了他的祈求，利百加就怀了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 撒母耳记上 28:6; 撒母耳记上 30:8"> 两个胎儿在她腹中彼此相争，她说：“怎么会这样？”于是，她去求问耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 9:10–13; 创世记 27:40; 创世记 27:29"> 耶和华对她说：<br /><span className="pl pl-1">“你腹中有两个国家，</span><br /><span className="pl pl-1">两族从你里面分出，</span><br /><span className="pl pl-1">一族要比另一族强大，</span><br /><span className="pl pl-1">将来大的要服侍小的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 到了生产的时候，利百加果然生下双胞胎。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 27:11; 创世记 27:16; 创世记 27:23"> 先出生的婴儿身体通红，浑身长毛，好像穿了皮衣，因此给他取名叫以扫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“以扫”意思是“有毛”。">b</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:36; 何西阿书 12:3; 创世记 38:28–30"> 随后出生的弟弟手抓着以扫的脚跟，因此给他取名叫雅各<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“雅各”意思是“抓住”。">c</a></sup>。那时以撒六十岁。</span>
</div>
</div>

## 以扫出卖长子名分

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯来书 11:9; 创世记 21:20; 创世记 10:9"> 孩子们渐渐长大，以扫擅长狩猎，常在田野活动；雅各性情安静，喜欢待在家里。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 27:19; 创世记 27:31; 创世记 27:4"> 以撒疼爱以扫，因为他喜欢吃以扫打的野味，利百加却疼爱雅各。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以赛亚书 40:30–31; 撒母耳记上 14:28"> 一天，雅各正在熬汤，以扫筋疲力尽地从田野回来。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 36:1; 出埃及记 15:15; 创世记 36:9"> 以扫对雅各说：“我要累死了，给我一些红汤喝吧！”因此，以扫又叫以东<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“以东”意思是“红色”。">d</a></sup>。</span>
<span className="v" id="v31" data-v="31"> 雅各回答说：“你今天把长子的名分卖给我吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="玛拉基书 3:14; 约伯记 21:15; 约伯记 22:17"> 以扫说：“我都快死了，长子的名分对我有什么用呢？”</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 12:16; 创世记 27:36; 希伯来书 6:16"> 雅各说：“你现在向我起誓保证吧！”于是，以扫就起誓把长子的名分卖给了雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比书 3:18–19; 希伯来书 12:16–17; 哥林多前书 15:32"> 雅各把饼和豆汤给以扫，以扫吃完喝完便起身走了。以扫就这样轻看自己长子的名分。</span>
</div>
</div>

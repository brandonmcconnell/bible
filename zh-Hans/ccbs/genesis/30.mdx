<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 5:2; 创世记 29:31; 创世记 37:11"> 拉结见自己没有给雅各生孩子，就嫉妒姐姐。她对雅各说：“你给我孩子，不然我还不如死了！”</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 16:2; 诗篇 127:3; 列王纪下 5:7"> 雅各气愤地说：“使你不能生育的是上帝，难道我能代替上帝吗？”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 50:23; 约伯记 3:12; 路得记 4:11"> 拉结说：“你去跟我的婢女辟拉同房吧，让她替我生孩子，我也可以借她留后。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:22; 创世记 21:10; 撒母耳记下 12:11"> 于是拉结把婢女辟拉给丈夫做妾，雅各和辟拉同房。</span>
<span className="v" id="v5" data-v="5"> 辟拉怀了孕，为雅各生下一个儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 诗篇 35:24; 诗篇 43:1"> 拉结说：“上帝为我申冤，也听了我的恳求，赐给我一个儿子。”拉结就给孩子取名叫但<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“但”意思是“申冤”。">a</a></sup>。</span>
<span className="v" id="v7" data-v="7"> 拉结的婢女辟拉又怀孕，为雅各生了第二个儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:24–25; 创世记 23:6; 创世记 49:21"> 拉结说：“我跟姐姐激烈相争，我得胜了。”她就给这孩子取名叫拿弗他利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“拿弗他利”意思是“相争”。">b</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 30:4; 创世记 30:17; 创世记 29:35"> 利亚见自己不再生育，就把婢女悉帕给雅各做妾。</span>
<span className="v" id="v10" data-v="10"> 利亚的婢女悉帕给雅各生了一个儿子。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 49:19; 以赛亚书 65:11; 创世记 35:26"> 利亚说：“真幸运！”她便给孩子取名叫迦得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“迦得”意思是“幸运”。">c</a></sup>。</span>
<span className="v" id="v12" data-v="12"> 利亚的婢女悉帕又给雅各生了第二个儿子，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 利亚说：“我真有福啊！妇女们会说我有福！”她就为孩子取名叫亚设<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“亚设”意思是“有福”。">d</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 创世记 25:30"> 在收麦子的季节，吕便在田间找到一些风茄，拿回家给母亲利亚。拉结对利亚说：“请给我一些你儿子找到的风茄。”</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 16:13; 哥林多前书 4:3; 民数记 16:9–10"> 利亚说：“你抢了我丈夫还不够吗？现在还要抢我儿子的风茄吗？”拉结回答说：“你给我风茄，今夜雅各就跟你同房。”</span>
<span className="v" id="v16" data-v="16"> 那天晚上，雅各从田间回来，利亚就出来迎接他说：“你要来跟我同房，因为我已经用儿子的风茄把你雇下来了。”于是，那天晚上雅各便跟利亚同房。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:6; 创世记 30:22; 出埃及记 3:7"> 上帝答应利亚的祈求，使她怀孕，为雅各生了第五个儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 49:14–15; 申命记 33:18; 创世记 46:13"> 利亚说：“我把婢女送给丈夫，现在上帝给我报酬了。”因此，她就为孩子取名叫以萨迦<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“以萨迦”意思是“报酬”。">e</a></sup>。</span>
<span className="v" id="v19" data-v="19"> 后来，利亚又怀孕，给雅各生下第六个儿子。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:23; 马太福音 4:13; 创世记 49:13"> 她说：“上帝赐给我珍贵的礼物，现在我丈夫会尊重我，因为我给他生了六个儿子。”于是，她就给这个儿子取名叫西布伦<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“西布伦”意思是“尊重”。">f</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:1–3; 创世记 34:26; 创世记 46:15"> 后来，利亚又生了一个女儿，给她取名叫底娜。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 29:31; 诗篇 113:9; 诗篇 127:3"> 上帝眷顾拉结，听了她的祷告，使她可以生育。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 创世记 29:31; 路加福音 1:27"> 她就怀孕，生了一个儿子，说：“上帝除去了我的羞辱。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:22–26; 创世记 35:24; 创世记 37:2"> 她给孩子取名叫约瑟<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="“约瑟”意思是“增添”。">g</a></sup>，说：“愿上帝再给我添一个儿子！”</span>
</div>
</div>

## 雅各与拉班的协议

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 24:54; 创世记 24:56; 创世记 28:15"> 拉结生约瑟以后，雅各对拉班说：“请让我走吧！我好回故乡，</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 29:30; 何西阿书 12:12; 创世记 31:26"> 请把我的妻儿给我，我好离开。她们都是我替你工作得来的，你知道我怎样努力为你工作。”</span>
<span className="v" id="v27" data-v="27" data-xref="路得记 2:13; 使徒行传 7:10; 以赛亚书 61:9"> 拉班却挽留他，说：“如果你肯赏光，请你留下来！因为我占卜得知上帝为了你的缘故才赐福给我。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 29:15; 创世记 29:19"> 你要多少酬劳，只管说出来，我一定会给你。”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 31:6; 创世记 31:38–40; 彼得前书 2:18"> 雅各回答说：“你知道我怎样努力地服侍你，照顾你的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 5:8; 哥林多后书 12:14; 申命记 11:10"> 我来以前，你的财产很少。耶和华因为我的到来而赐福给你，使你财产大增。但我自己什么时候才能兴家立业呢？”</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 21:4–6; 希伯来书 13:5; 诗篇 118:8"> 拉班问：“我该给你什么呢？”雅各说：“你不用给我什么，只要你答应一件事，我就继续照料你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 31:8; 创世记 31:10; 创世记 30:35"> 今天让我走遍你的羊群，从中挑出有斑点的绵羊、黑色的小羊和有斑点的山羊作为我的薪酬。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 13:14; 撒母耳记下 22:21; 撒母耳记上 26:23"> 以后，如果你在给我作薪酬的羊群中查出没有斑点的山羊或非黑色的绵羊，就算是我偷的。这样你可以知道我是否诚实。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 7:7; 民数记 22:29; 哥林多前书 14:5"> 拉班说：“好，就照你的话做！”</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 31:9"> 当天，拉班把有条纹或斑点的公山羊以及有斑点或夹杂白纹的母山羊，连同黑色的绵羊都挑出来，交给自己的儿子们看管。</span>
<span className="v" id="v36" data-v="36"> 然后，他离开雅各，彼此相隔三天的路程。雅各继续为他照料其余的羊。</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 31:9–13; 以西结书 31:8"> 雅各折下一些杨树、杏树和枫树的嫩枝，削掉部分树皮，露出白色的条纹，</span>
<span className="v" id="v38" data-v="38"> 然后把这些嫩枝插在羊喝水的水槽和水沟里。羊群来喝水时互相交配。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 12:35–36; 创世记 31:9–12; 创世记 31:40"> 它们对着这些树枝交配，就生下有条纹和有斑点的羊羔。</span>
<span className="v" id="v40" data-v="40"> 雅各把这些羊羔分出来，又让羊群对着拉班那些有条纹和黑色的羊。他把自己的羊安置在一处，不与拉班的羊掺杂在一起。</span>
<span className="v" id="v41" data-v="41"> 每当肥壮的羊交配时，雅各就把有条纹的枝子插在水沟里，使羊对着树枝交配。</span>
<span className="v" id="v42" data-v="42"> 但如果交配的羊是瘦弱的，他就不插枝子。这样，瘦弱的羊归拉班，肥壮的羊归雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:35; 创世记 30:30; 创世记 26:13–14"> 因此，雅各变得极其富有，拥有很多羊、骆驼、驴和仆婢。</span>
</div>

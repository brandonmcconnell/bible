## 亚伯兰救回罗得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 10:10; 创世记 10:22; 以赛亚书 37:12"> 那时，示拿王暗拉非、以拉撒王亚略、以拦王基大老玛和戈印王提达联合攻打以下五王：所多玛王比拉、蛾摩拉王比沙、押玛王示纳、洗扁王善以别和比拉王，即琐珥王。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 3:16; 申命记 3:17; 民数记 34:12"> 五王会师西订谷，即盐海。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 9:25–26; 以西结书 17:15"> 他们受基大老玛统治十二年，在第十三年叛变了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:11; 创世记 15:20; 申命记 1:4"> 第十四年，基大老玛联合其他王在亚特律·加宁打败利乏音人，在哈麦打败苏西人，在沙微·基列亭打败以米人，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:22; 申命记 2:12; 创世记 21:21"> 在西珥山打败住在那里的何利人，直杀到靠近旷野的伊勒·巴兰。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 20:2; 创世记 16:14; 创世记 20:1"> 然后，他们返回安·密巴，即加低斯，征服了亚玛力全境以及住在哈洗逊·他玛的亚摩利人。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:22; 创世记 13:10; 创世记 19:20"> 那时，所多玛王、蛾摩拉王、押玛王、洗扁王和比拉王，即琐珥王出战，在西订谷摆开阵势，</span>
<span className="v" id="v9" data-v="9"> 抵抗以拦王基大老玛、戈印王提达、示拿王暗拉非和以拉撒王亚略：四王跟五王交战。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 19:17; 创世记 19:30; 以赛亚书 24:18"> 西订谷布满柏油坑，所多玛王和蛾摩拉王败走的时候，有些人掉进坑里，其他人都往山上逃命。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:21; 创世记 14:16; 申命记 28:31"> 四王把所多玛和蛾摩拉所有的财物和粮食洗劫一空，扬长而去，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:5; 创世记 11:27; 启示录 3:19"> 并劫走亚伯兰的侄儿罗得和他的财物，那时罗得正住在所多玛。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 13:18; 创世记 14:24; 创世记 40:15"> 有一个逃出来的人把这件事情告诉了希伯来人亚伯兰。那时，亚伯兰住在亚摩利人幔利的橡树那里。幔利是以实各和亚乃的兄弟，三人都是亚伯兰的盟友。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 18:29; 创世记 15:3; 创世记 17:27"> 亚伯兰听见侄儿被掳的消息，便率领家中三百一十八名训练有素的壮丁去追赶他们，一直追到但。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:2; 诗篇 112:5; 列王纪上 15:18"> 夜里，亚伯兰和他的随从分头出击，大败他们，一直追杀到大马士革北面的何巴，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 30:18–19; 撒母耳记上 30:8; 创世记 12:2"> 夺回所有被劫的财物，并救出他侄儿罗得及其财物、妇女和其他人。</span>
</div>
</div>

## 麦基洗德祝福亚伯兰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 18:18; 箴言 19:4; 希伯来书 7:1"> 亚伯兰大败基大老玛及其盟军各王凯旋的时候，所多玛王到沙微谷来迎接。沙微谷即王谷。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:20–3; 诗篇 110:4; 希伯来书 5:6"> 撒冷王麦基洗德也带着饼和酒出来相迎，他是至高上帝的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 7:6–7; 创世记 14:22; 诗篇 24:1"> 他祝福亚伯兰说：<br /><span className="pl pl-1">“愿创造天地的主、至高的上帝赐福给亚伯兰！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 28:22; 希伯来书 7:4–9; 玛拉基书 3:10"> <span className="pl pl-1">将敌人交在你手中的至高上帝当受称颂！”</span><br />于是，亚伯兰把所得财物的十分之一给了他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 所多玛王对亚伯兰说：“请把我的人民交还给我，你可以把财物拿去。”</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 12:7; 但以理书 4:34; 申命记 32:40"> 亚伯兰对他说：“我向创造天地的主、至高的上帝耶和华举手起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 5:16; 哥林多后书 11:9–12; 以斯帖记 9:15–16"> 凡是你的东西，就是一根线、一条鞋带，我都不会拿，免得你说，‘我使亚伯兰发了财！’</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 14:13; 箴言 3:27; 马太福音 7:12"> 除了我的随从已经吃用的以外，我什么也不要。至于我的盟友亚乃、以实各和幔利所当得之份，请让他们拿去。”</span>
</div>
</div>

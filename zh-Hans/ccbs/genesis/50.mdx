## 安葬雅各

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:4; 申命记 6:7–8; 使徒行传 8:2"> 约瑟伏在父亲身上痛哭，亲吻他，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:26; 历代志下 16:14; 约翰福音 19:39–40"> 然后吩咐医生用香料保存父亲的遗体。医生遵命而行，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 20:29; 申命记 34:8; 创世记 50:10"> 按照常例花了四十天用香料处理遗体。埃及人为他哀悼七十天。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 18:3; 以斯帖记 4:2"> 哀悼的日子完了，约瑟对法老宫中的人说：“如果你们恩待我，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 16:14; 以赛亚书 22:16; 马太福音 27:60"> 请告诉法老，我父亲死前要我起誓把他葬在迦南他自己预备好的坟地。请准许我到迦南去安葬我父亲，我办完丧事就回来。”</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 48:21"> 法老说：“去按照你的誓言埋葬你父亲吧。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 14:16"> 于是，约瑟启程去埋葬他的父亲，随行的有法老所有的臣仆和埃及所有的达官显贵，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 32:24–27; 出埃及记 10:26; 出埃及记 10:8–9"> 以及约瑟全家、他的众弟兄和雅各的家眷，只有他们的孩子和牛羊仍然留在歌珊。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 14:28; 列王纪下 18:24; 雅歌 1:9"> 随行的还有大队车辆和骑兵，人数众多。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 2:13; 使徒行传 8:2; 撒母耳记下 1:17"> 他们来到约旦河附近的亚达麦场，在那里痛哭哀悼。约瑟为父亲哭丧七天。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 10:15–19; 创世记 24:6; 申命记 11:30"> 迦南人看见他们在亚达麦场痛哭，就说：“埃及人在痛哭哀悼。”因此，约旦河附近的那个地方叫亚伯·麦西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚伯·麦西”意思是“埃及人在哀哭”。">a</a></sup>。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:16; 创世记 49:29–32; 以弗所书 6:1"> 雅各的儿子们遵照父亲的遗言，</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 49:29–31; 创世记 23:16–18; 使徒行传 7:16"> 把父亲的遗体带回迦南，安葬在幔利附近、麦比拉田间的洞里。洞和田地都是亚伯拉罕向赫人以弗仑买来作坟地的。</span>
<span className="v" id="v14" data-v="14"> 葬礼之后，约瑟就跟众弟兄和一切随行的人返回埃及。</span>
</div>
</div>

## 上帝的美好旨意

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 创世记 42:21–22; 诗篇 53:5"> 约瑟的哥哥们见父亲死了，就说：“约瑟会不会怀恨在心，因我们以前恶待他而报复我们呢？”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 于是，他们派人去对约瑟说：“你父亲临终时交待这样的话给你，</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所书 4:32; 马太福音 6:14–15; 创世记 45:8"> ‘从前你哥哥们恶待你，求你饶恕他们的罪恶和过犯。’我们是你父亲的上帝的仆人，求你饶恕我们的罪恶。”约瑟听见这些话，就哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:7–11; 创世记 42:6; 创世记 45:3"> 约瑟的哥哥们来见他，俯伏在他面前，说：“我们是你的奴仆。”</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 12:19; 创世记 45:5; 创世记 30:2"> 约瑟对他们说：“你们不要害怕，我岂能代替上帝？</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:28; 诗篇 119:71; 创世记 45:5–8"> 从前你们是要加害于我，但上帝有祂的美意，祂借此保全许多人的性命，正如今日的光景。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:12; 彼得前书 3:9; 创世记 45:10–11"> 因此，你们不要害怕，我会照顾你们和你们的儿女。”约瑟好言好语地宽慰他们。</span>
</div>
</div>

## 约瑟去世

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 约瑟和他父亲全家住在埃及。约瑟享年一百一十岁。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:39; 创世记 30:3; 约伯记 42:16"> 他看到了以法莲的孙子，也曾把玛拿西的儿子玛吉刚出生的孩子抱在膝上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 3:16–17; 创世记 35:12; 创世记 26:3"> 一天，约瑟对他的弟兄们说：“我快要死了，但上帝必看顾你们，带你们离开这里，回到祂起誓应许给亚伯拉罕、以撒和雅各的地方。”</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 13:19; 约书亚记 24:32; 创世记 47:29–31"> 约瑟让以色列的子孙起了誓，并说：“上帝必看顾你们，你们要把我的骸骨带回迦南。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 50:2–3; 创世记 47:9; 约书亚记 24:29"> 约瑟享年一百一十岁。他们把他的遗体用香料保存好，放在棺材里，停放在埃及。</span>
</div>
</div>

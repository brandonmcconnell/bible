## 底娜受辱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:21; 耶利米书 2:36; 创世记 30:13"> 一天，利亚给雅各所生的女儿底娜到外面去见当地的女子。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 约伯记 31:1; 约伯记 31:9"> 当地首领希未人哈抹的儿子示剑看到她，就抓住她，强行玷污了她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 2:14; 以赛亚书 40:2; 历代志下 30:22"> 他恋慕雅各的女儿底娜，爱上了这个少女，就用甜言蜜语讨她欢心。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 14:2; 撒母耳记下 13:13; 创世记 21:21"> 他求父亲哈抹为他说亲，把底娜娶过来。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 13:22; 利未记 10:3; 撒母耳记上 10:27"> 底娜被玷污的消息传到雅各耳中时，他的儿子们正在田野放牧。他只好忍气吞声，等儿子们回来再作打算。</span>
<span className="v" id="v6" data-v="6"> 示剑的父亲哈抹来和雅各商议。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 7:15; 士师记 20:6; 申命记 22:21"> 雅各的儿子们一听说这事，就从田野赶回来。大家都非常愤怒，因为示剑玷污了雅各的女儿，对以色列家做了不该做的丑事。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 11:2; 诗篇 119:20; 诗篇 84:2"> 哈抹跟他们商议说：“我儿子示剑爱慕你们家的女儿，请你们把女儿嫁给他吧！</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:3; 创世记 26:34–35; 创世记 19:14"> 我们可以互相通婚，你们可以把女儿嫁给我们的儿子，也可以娶我们的女儿为妻。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 20:15; 创世记 47:27; 创世记 42:34"> 你们可以在我们这里安顿下来，这片土地就在你们面前，住在这里做买卖、置产业吧。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 33:15; 创世记 18:3"> 示剑对底娜的父亲和她的弟兄们说：“请你们恩待我，你们要什么，我都给你们。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 22:16–17; 申命记 22:28–29; 撒母耳记上 18:25–27"> 只要你们把这少女嫁给我，无论你们要多少聘金和礼物，我必如数奉上。”</span>
</div>
</div>

## 雅各之子计杀示剑人

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 25:27–34; 以赛亚书 59:13; 约伯记 13:4"> 雅各的儿子们因为示剑玷污了他们的妹妹底娜，就假意对示剑和他的父亲哈抹说：</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 23:1–39; 撒母耳记下 15:7; 创世记 17:11"> “我们不能把妹妹嫁给没有受过割礼的人，这对我们是一种羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:12"> 除非你们所有的男子都跟我们一样受割礼，我们才会答应你们，</span>
<span className="v" id="v16" data-v="16"> 我们才会和你们通婚，共同生活，结成一个民族。</span>
<span className="v" id="v17" data-v="17"> 如果你们不肯这样做，我们就把妹妹带走。”</span>
<span className="v" id="v18" data-v="18"> 哈抹父子欣然答应。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:12; 使徒行传 13:50; 撒母耳记上 22:14"> 示剑毫不迟延地照办，因为他热恋底娜。在哈抹家族中，他最受人尊重。</span>
<span className="v" id="v20" data-v="20" data-xref="路得记 4:1; 箴言 31:23; 阿摩司书 5:12"> 哈抹父子来到城门口，对那城的居民说：</span>
<span className="v" id="v21" data-v="21"> “这些人跟我们相处和睦，就让他们在这里定居、做买卖吧。我们这里有足够的地方可以容纳他们，我们可以和他们通婚。</span>
<span className="v" id="v22" data-v="22"> 可是，他们有一个条件，就是要我们所有的男子和他们一样接受割礼，他们才答应和我们一起生活，结成一个民族。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 约翰福音 6:26–27; 约翰福音 2:16"> 到时候，他们的财产和牛羊等所有牲畜不全归我们了吗？我们同意他们吧，这样他们就会在我们这里定居。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 23:10; 哥林多前书 7:19; 以赛亚书 1:10–16"> 在城门进出的人听了哈抹父子的话，都表示赞同。于是，城里的男子都接受了割礼。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 49:5–7; 创世记 29:33–34; 民数记 31:7"> 到了第三天，他们伤口正疼痛的时候，雅各的两个儿子——底娜的哥哥西缅和利未拿着利剑，乘众人没有防备，进城杀掉了所有的男子，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 2:26; 申命记 32:42; 以赛亚书 31:8"> 包括哈抹和示剑，从示剑家里带走了底娜。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 7:13; 约书亚记 7:21; 出埃及记 2:14"> 雅各的众子又到被杀之人的城里掳掠，因为他们的妹妹在那里被人玷污。</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 1:15–16; 申命记 8:17–18; 约伯记 20:5"> 他们抢走牛群、羊群、驴群和城里城外所有的东西，</span>
<span className="v" id="v29" data-v="29"> 并带走所有财物、妇孺以及房屋里的一切。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 105:12; 约书亚记 7:25; 出埃及记 5:21"> 雅各责备西缅和利未说：“你们为什么要给我惹麻烦，使我在当地的迦南人和比利洗人中留下臭名呢？我们人数很少，要是他们联手来攻击我们，我们全家必遭灭门之祸。”</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 创世记 34:13; 创世记 49:7"> 他们说：“他怎么能把我们的妹妹当妓女对待？”</span>
</div>
</div>

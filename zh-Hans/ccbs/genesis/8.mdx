## 洪水消退

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:22; 创世记 19:29; 诗篇 136:23"> 上帝眷顾挪亚及方舟里的野兽和牲畜，就使风吹在大地上，水便开始消退。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 7:11; 马太福音 8:26–27; 箴言 8:28"> 深渊的泉源和天上的水闸都关闭了，大雨也停了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 7:24; 创世记 7:11"> 地上的洪水慢慢消退，过了一百五十天，水退下去了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:37; 耶利米书 51:27; 以赛亚书 37:38"> 七月十七日，方舟停在亚拉腊山上。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 7:11"> 水继续消退一直到十月，到十月一日，山顶都露出来了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 6:16; 但以理书 6:10"> 又过了四十天，挪亚打开他在方舟上所造的窗户，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 147:9; 列王纪上 17:6; 列王纪上 17:4"> 放出一只乌鸦。它一直在空中飞来飞去，直到地上的水都干了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 马太福音 10:16"> 然后，挪亚放出一只鸽子，以便了解地面的水是否已经消退。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:28; 诗篇 116:7; 申命记 28:65"> 但遍地都是水，鸽子找不到歇脚的地方，就飞回了方舟，挪亚伸手把鸽子接进方舟里。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 7:4; 创世记 7:10; 创世记 8:12"> 挪亚又等了七天，再把鸽子放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 8:15; 撒迦利亚书 4:12–14; 罗马书 10:15"> 到了黄昏，鸽子飞回来，嘴里衔着一片新拧下来的橄榄叶，挪亚便知道地上的水已经退了。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 25:9; 以赛亚书 30:18; 创世记 8:10"> 他又等了七天，再放出鸽子，这次鸽子没有回来。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 7:11"> 挪亚六百零一岁那年的一月一日，地上的水干了。挪亚打开方舟的盖观望，看见地面都干了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:13–14; 创世记 7:11"> 到了二月二十七日，大地完全干了。</span>
<span className="v" id="v15" data-v="15"> 上帝对挪亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 7:13; 诗篇 121:8; 诗篇 91:11"> “你与妻子、儿子和儿媳都要出方舟。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:22; 创世记 9:1; 耶利米书 31:27–28"> 你要把方舟里的飞禽走兽及爬虫等所有动物都带出来，让它们在地上多多滋长，生养繁衍。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:8"> 于是，挪亚与妻子、儿子和儿媳都出了方舟。</span>
<span className="v" id="v19" data-v="19"> 方舟里的飞禽走兽和爬虫等所有地上的动物，都按种类出了方舟。</span>
</div>
</div>

## 挪亚献祭

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 13:15–16; 罗马书 12:1; 创世记 22:9"> 挪亚为耶和华筑了一座坛，在上面焚烧各种洁净的牲畜和飞鸟作为燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 2:15; 以弗所书 5:2; 以赛亚书 54:9–10"> 耶和华闻到这燔祭的馨香，心想：“虽然人从小就心存恶念，但我再不会因为人的缘故而咒诅大地，再不会像这次一样毁灭一切活物了。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 5:7; 诗篇 74:16–17; 耶利米书 5:24"> 只要大地尚存，播种收割、夏热冬寒、白昼黑夜必不停息。”</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:11–12; 哥林多前书 1:1; 罗马书 1:1"> 我是保罗，我做使徒并非受人委派，也不是倚靠人，而是由耶稣基督和叫祂从死里复活的父上帝委派的。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 16:1; 腓立比书 4:21; 使徒行传 16:5–6"> 我和所有跟我在一起的弟兄写信给加拉太的各教会。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰二书 1:3; 哥林多后书 13:14; 罗马书 1:7–15"> 愿我们的父上帝和主耶稣基督赐给你们恩典和平安！</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 20:28; 罗马书 4:25; 加拉太书 2:20"> 基督遵照我们父上帝的旨意为我们的罪献上了自己，好拯救我们脱离这罪恶的世代。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 11:36; 犹大书 1:25; 诗篇 72:19"> 愿荣耀归给上帝，直到永永远远。阿们！</span>
</div>
</div>

## 勿随别的福音

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:4; 加拉太书 5:7–8; 以赛亚书 29:13"> 我很惊讶，你们竟然那么快就背弃了借着基督的恩典呼召你们的上帝，去追随别的福音！</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 15:24; 罗马书 16:17–18; 加拉太书 5:10"> 其实那并不是福音，只是某些人扰乱你们的信仰，想篡改基督的福音。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 11:13–14; 加拉太书 1:9; 启示录 22:18–19"> 即便是我们或天使，若另传福音给你们，与我们以前传给你们的相悖，也该受咒诅！</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:17; 箴言 30:6; 申命记 4:2"> 我们已经说过，现在我再说一次：如果有人向你们传别的福音，与你们以前接受的相悖，那人该受咒诅！</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:4; 使徒行传 5:29; 以弗所书 6:6"> 我现在是要赢得人的赞同吗？还是要赢得上帝的赞同？难道我是要讨好人吗？我如果仍旧要讨好人，就不是基督的奴仆了。</span>
</div>
</div>

## 保罗受上帝委派传福音

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 1:1; 哥林多前书 2:9–10; 哥林多前书 11:23"> 弟兄姊妹，我告诉你们，我传的福音不是出于人的意思，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:16; 哥林多前书 2:10; 加拉太书 1:1"> 因为这福音既不是我从人那里领受的，也不是我跟人学来的，而是耶稣基督亲自启示我的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:3; 哥林多前书 15:9; 使徒行传 22:3–5"> 你们都听说过我信奉犹太教时的所作所为，我怎样残酷地迫害上帝的教会，试图摧毁它。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 2:8; 使徒行传 26:5; 腓立比书 3:4–6"> 我在犹太教里比许多同辈的犹太人更进取，狂热地维护祖先的传统。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 以赛亚书 49:5; 以赛亚书 49:1"> 然而，当我还在母腹中的时候，上帝就施恩将我分别出来并呼召了我。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:17; 以弗所书 3:5–10; 以弗所书 6:12"> 上帝既然乐意把祂的儿子启示给我，叫我向外族人传扬祂，我就没有跟任何人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“人”希腊文是“血肉”。">a</a></sup>商量，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:20–25; 哥林多后书 11:32–33; 加拉太书 1:18"> 也没有上耶路撒冷去见那些比我先做使徒的人，而是去了阿拉伯，然后回到大马士革。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:22–23; 使徒行传 9:26–29; 使徒行传 22:17–18"> 过了三年，我才到耶路撒冷去拜会矶法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“矶法”即“彼得”，下同。">b</a></sup>，和他一起住了十五天。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:55; 马可福音 6:3; 马太福音 12:46"> 我也见了主耶稣的弟弟雅各，此外没有见过其他使徒。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:1; 哥林多后书 11:31; 哥林多后书 11:10–11"> 我在上帝面前保证，我写给你们的绝无谎言。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 15:41; 使徒行传 9:30; 使徒行传 6:9"> 后来我又到了叙利亚和基利迦地区。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:14; 罗马书 16:7; 帖撒罗尼迦后书 1:1"> 那时，犹太境内基督的众教会都还没有见过我的面。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:8–10; 使徒行传 9:13; 提摩太前书 1:13–16"> 他们只是听说：“那个从前迫害我们的人如今在传扬他曾试图摧毁的信仰。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 9:8; 使徒行传 11:18; 路加福音 15:10"> 于是他们因为我的缘故将荣耀归给上帝。</span>
</div>
</div>

## 互相扶持

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:1; 提摩太后书 2:25; 帖撒罗尼迦后书 3:15"> 弟兄姊妹，如果有人不慎犯了罪，你们属灵的人就应该温柔地挽回他，同时也要小心，免得自己也受诱惑。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 15:1; 帖撒罗尼迦前书 5:14; 约翰福音 13:34"> 你们要分担彼此的重担，这样就成全了基督的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 26:12; 哥林多前书 8:2; 哥林多前书 3:18"> 一个一无是处的人如果自以为了不起，就是自欺。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 13:5; 诗篇 26:2; 哥林多前书 11:28"> 人人都应该省察自己的行为，即使觉得有可夸之处，自己知道就好了，不必在别人面前炫耀。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:19; 罗马书 14:10–12; 哥林多后书 5:10–11"> 因为人人都应该为自己的行为负责。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:17–18; 罗马书 15:27; 申命记 12:19"> 在真道上受教的人应该把一切美好的东西分享给教导他的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:6; 何西阿书 10:12; 约伯记 4:8"> 不要自欺，上帝是轻慢不得的。人种什么收什么。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 8:13; 雅各书 3:18; 彼得后书 2:19"> 顺从本性撒种的，必从本性收取败坏的恶果；顺从圣灵撒种的，必从圣灵收取永生。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:58; 帖撒罗尼迦后书 3:13; 以赛亚书 40:30–31"> 我们行善不可灰心气馁，因为到时候必有收获。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:16; 箴言 3:27; 帖撒罗尼迦前书 5:15"> 我们要把握机会为众人做善事，对待信徒更要如此。</span>
</div>
</div>

## 最后的劝勉和祝福

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 16:21–23; 罗马书 16:22"> 你们看，我亲手写给你们的字是多么大啊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗可能有眼疾，故由别人代笔写信。他亲手写的部分字体较大。">a</a></sup>！</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:11; 歌罗西书 2:23; 使徒行传 15:1"> 那些想做表面工夫的人才勉强你们接受割礼，他们无非是怕为基督的十字架受迫害。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 3:3; 哥林多前书 5:6; 罗马书 2:17–25"> 那些接受割礼的人自己也不能遵行律法。他们要你们接受割礼，无非是想借着你们的肉体夸耀。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 6:6; 耶利米书 9:23–24; 加拉太书 2:20"> 至于我自己，我绝不夸耀别的，只夸耀我们主耶稣基督的十字架。因为对我来说，世上的一切都已经被钉在十字架上；对这世界来说，我已经被钉在十字架上。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:17; 歌罗西书 3:10–11; 以弗所书 2:10"> 受不受割礼根本无关紧要，做一个新造的人才至关重要。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 3:29; 罗马书 9:6–8; 腓立比书 3:3"> 愿上帝的平安和怜悯归给那些愿意按这原则生活的人，也归给上帝的以色列子民<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“也归给上帝的以色列子民”或译“即上帝的以色列子民”。">b</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 1:5; 歌罗西书 1:24; 哥林多后书 11:23–25"> 但愿从今以后，再也没有人来搅扰我了，因为我身上已经烙上了耶稣的印记。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 16:20; 提摩太后书 4:22; 腓利门书 1:25"> 弟兄姊妹，愿我们主耶稣基督的恩典与你们的灵同在。阿们！</span>
</div>
</div>

## 众使徒接纳保罗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 2:3; 使徒行传 14:12; 哥林多后书 8:23"> 十四年后，我和巴拿巴又去耶路撒冷，并带了提多同去。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 2:6; 腓立比书 2:16; 帖撒罗尼迦前书 3:5"> 我是遵照上帝的启示去的。我私下拜会了那些有名望的教会领袖，陈明我在外族人中间所传的福音，免得我过去或是现在的努力都白费了。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:2–6; 使徒行传 16:3; 哥林多前书 9:20–21"> 跟我同去的提多虽然是希腊人，也没有人勉强他接受割礼。</span>
<span className="v" id="v4" data-v="4" data-xref="犹大书 1:4; 加拉太书 5:1; 加拉太书 4:3"> 事情的缘由是因为有一些假信徒偷偷混了进来，要窥探我们在基督耶稣里享有的自由，想叫我们做律法的奴隶。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 2:14; 加拉太书 4:16; 歌罗西书 1:5"> 但为了叫福音的真理常在你们当中，我们丝毫没有向他们妥协。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:2; 使徒行传 10:34; 哥林多后书 12:11"> 至于那些德高望重的教会领袖，他们的地位对我来说无关紧要，因为上帝不以貌取人。他们对我所传的并没有增加什么。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 提摩太前书 2:7; 加拉太书 1:16"> 相反，他们都已看到，上帝委托我向外族人传福音，就像祂委托彼得向犹太人传福音一样。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:15; 使徒行传 22:21; 使徒行传 2:14–41"> 上帝感动了彼得，呼召他做犹太人的使徒，祂也同样感动了我，呼召我做外族人的使徒。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 12:3; 启示录 3:12; 加拉太书 2:2"> 当时被誉为教会柱石的雅各、矶法和约翰明白了上帝赐给我的恩典之后，就与我和巴拿巴用右手行相交之礼，让我们向外族人传福音，他们向受割礼的人传福音。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 24:17; 约翰一书 3:17; 希伯来书 13:16"> 他们只要求我们顾念那些贫困的人，这正是我一向热衷的事。</span>
</div>
</div>

## 保罗面责矶法

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:20; 哥林多后书 5:16; 使徒行传 15:1"> 后来，矶法到了安提阿，因他做错了事，我就当面反对他。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:28; 路加福音 15:2; 使徒行传 11:2–3"> 从雅各那里来的人抵达之前，他和外族的信徒一起吃饭。但那些人抵达以后，他因为怕那些坚持行割礼的犹太人批评，就与外族的信徒分开了。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 15:33; 以弗所书 4:14; 希伯来书 13:9"> 其他犹太基督徒也跟着他装假，甚至连巴拿巴也随从了他们的虚伪。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:5; 使徒行传 10:28; 使徒行传 15:10–11"> 我看见他们不照福音的真理行，就当众对矶法说：“你身为犹太人，如果行事为人像外族人，不像犹太人，又怎能强迫外族人按犹太人的规矩生活呢？”</span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 以弗所书 2:3; 以弗所书 2:11–12"> 我们生来是犹太人，不是外族罪人，</span>
<span className="v" id="v16" data-v="16" data-xref="腓立比书 3:9; 诗篇 143:2; 罗马书 9:30"> 但我们知道人被称为义人不是靠遵行律法，而是靠信耶稣基督。所以我们信了基督耶稣，以便因信基督被称为义人，而不是靠遵行律法，因为无人能够靠遵行律法被称为义人。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:1–2; 约翰一书 3:8–10; 约翰一书 3:5"> 如果我们寻求在基督里被称为义人，结果却仍是罪人，难道基督助长罪恶吗？当然不是！</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 4:9–12; 加拉太书 2:4–5; 加拉太书 2:12–16"> 倘若我重建我所拆毁的东西，就表明我是罪人。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:4; 罗马书 6:2; 帖撒罗尼迦前书 5:10"> 其实，我因无法满足律法的要求而向律法死了，使我可以为上帝而活。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:24; 哥林多后书 5:15; 罗马书 6:4–6"> 我已经与基督一同被钉在十字架上，现在活着的不再是我，而是基督活在我里面。我如今活在肉身中的生命是靠信上帝的儿子活着，祂爱我，为我舍命。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 11:6; 加拉太书 3:21; 希伯来书 7:11"> 我不废弃上帝的恩典，倘若靠遵行律法可以得到义，基督的死便毫无意义了。</span>
</div>

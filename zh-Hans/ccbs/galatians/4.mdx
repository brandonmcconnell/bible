## 儿子与奴仆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:23; 加拉太书 4:29; 创世记 24:2–3"> 然而，继承人还年幼时，虽然身为产业的主人，实际上和奴仆没有分别。</span>
<span className="v" id="v2" data-v="2"> 他一样要受监护人和管家的约束，一直到他父亲指定他继承产业的日子为止。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:20; 歌罗西书 2:8; 加拉太书 4:9"> 我们也一样，在孩童时期受世界基本规条的辖制。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 7:14; 约翰福音 1:14; 罗马书 1:3"> 然而，时候一到，上帝就差遣自己的儿子借着一位女子降生，并受律法的约束，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 9:15; 以弗所书 1:5; 彼得前书 1:18–20"> 为要救赎一切受律法约束的人，使我们成为祂的儿女。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 8:15–17; 罗马书 5:5; 罗马书 8:9"> 我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我们”希腊文是“你们”。">a</a></sup>既然成为儿女，上帝就差遣祂儿子的灵进入我们的心里，呼求：“阿爸，父啊！”</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:16–17; 加拉太书 3:29–2; 加拉太书 3:26"> 由此可见，你们从今以后不再是奴仆，而是儿女。既然身为儿女，就可以靠着上帝成为产业继承人。</span>
</div>
</div>

## 保罗对加拉太人的关怀

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 8:4; 以弗所书 2:11–12; 帖撒罗尼迦后书 1:8"> 从前，你们不认识上帝，做那些假神的奴隶。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 8:3; 加拉太书 3:3; 罗马书 8:3"> 现在，你们既然认识了上帝，或者更应该说是上帝认识了你们，为什么还要回到那些脆弱无用的基本规条之下，甘愿再做它们的奴隶呢？</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:16–17; 罗马书 14:5; 利未记 23:1–44"> 你们竟然还在拘守什么日子、月份、节期和年份！</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 3:5; 腓立比书 2:16; 加拉太书 2:2"> 我真担心我在你们身上的一番心血都枉费了。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:5; 列王纪上 22:4; 创世记 34:15"> 弟兄姊妹，我劝你们现在要像我一样，因为我已经像你们一样。你们向来没有亏待过我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 2:3; 哥林多后书 12:7–10; 哥林多后书 11:30"> 你们知道，当初是因为我生病才有机会首次向你们传福音。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:40; 帖撒罗尼迦前书 2:13; 希伯来书 13:2"> 那时，你们虽然因为我生病而受累，却没有轻视我、嫌弃我，反而接待我，就像接待上帝的天使，接待基督耶稣一样。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:2; 约翰一书 3:16–18; 歌罗西书 4:13"> 我可以为你们作证，如果可能的话，你们那时就是把眼睛剜出来给我，也心甘情愿。你们当初的善意哪里去了？</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 5:10; 箴言 9:8; 约翰福音 8:45"> 现在我因为告诉你们真理，就成了你们的仇人吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:18; 哥林多后书 11:13–15; 彼得后书 2:3"> 那些人非常热心地对待你们，其实他们心怀不轨，想要离间你们和我们的关系，使你们热心地对待他们。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:12; 启示录 3:19; 腓立比书 1:27"> 有人热心待你们当然很好，但总要动机纯正、始终如一，不应该只是我和你们在一起时才热心待你们。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:13; 罗马书 8:29; 罗马书 13:14"> 孩子们，为了你们，我像一位母亲再次经历生产的剧痛，一直到基督的生命在你们里面成形。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 2:17–18; 哥林多前书 4:19–21; 帖撒罗尼迦前书 3:9"> 我恨不得立刻赶到你们身边，换种口气说话，因为我为你们困惑不安。</span>
</div>
</div>

## 夏甲与撒拉的例子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 3:10; 加拉太书 3:23–24; 罗马书 7:5–6"> 你们这些甘愿在律法之下的人啊！告诉我，你们没听过律法怎么说吗？</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 16:15; 创世记 21:10; 创世记 21:1–2"> 律法书上说：亚伯拉罕有两个儿子，一个是婢女生的，一个是主母生的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:11; 罗马书 9:7–8; 加拉太书 4:28–29"> 婢女的儿子是按着人的意愿生的，主母的儿子是按着上帝的应许生的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 21:9–13; 希伯来书 10:15–18; 创世记 16:8"> 这些事都有寓意，两个妇人代表两个约。夏甲代表颁布于西奈山的约，她生的孩子是奴仆。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行传 1:11; 加拉太书 1:17"> 这夏甲代表阿拉伯的西奈山，相当于现今的耶路撒冷，她和她的儿女都是奴仆。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 12:22; 腓立比书 3:20; 弥迦书 4:1–2"> 那天上的耶路撒冷则是自由的，是我们的母亲。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 54:1–5; 诗篇 113:9; 路得记 4:14–16"> 因为圣经上说：<br /><span className="pl pl-1">“不生育、未生养的妇人啊，</span><br /><span className="pl pl-1">要快乐；</span><br /><span className="pl pl-1">未曾生产的女子啊，</span><br /><span className="pl pl-1">要高声欢呼，</span><br /><span className="pl pl-1">因为没有丈夫的比有丈夫的儿女更多。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书54:1。">b</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 4:23; 罗马书 9:8–9; 罗马书 4:13–18"> 弟兄姊妹，你们都像以撒一样是照着上帝的应许出生的。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 21:9; 罗马书 8:13; 加拉太书 5:11"> 当时，那按着人的意愿生的儿子迫害那靠着圣灵生的儿子，现在的情况也和当时一样。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 21:10–12; 约翰福音 8:35; 罗马书 8:15–17"> 但圣经上怎么说呢？圣经上说：“赶走婢女和她的儿子，因为婢女的儿子不能与主母的儿子一同承受产业。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="创世记21:10。">c</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:36; 约翰福音 1:12–13; 加拉太书 5:1"> 弟兄姊妹，这样看来，我们不是婢女的儿女，而是主母的儿女。</span>
</div>
</div>

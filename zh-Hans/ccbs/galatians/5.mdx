## 基督徒的自由

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 3:17; 加拉太书 5:13; 彼得前书 2:16"> 基督释放了我们，好让我们得自由。所以，要站稳了，不要再被奴仆的轭辖制。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 5:6; 使徒行传 15:1; 罗马书 9:31–32"> 听着！我保罗郑重地告诉你们，如果你们接受割礼，基督对你们就毫无益处。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:10; 罗马书 2:25; 雅各书 2:10–11"> 我再次警告所有接受割礼的人，他们必须遵守全部的律法。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:31–32; 彼得后书 2:20–22; 罗马书 11:6"> 你们若想靠遵行律法被称为义人，就与基督隔绝了，并且离开了上帝的恩典。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 130:5; 帖撒罗尼迦前书 1:10; 诗篇 62:5"> 但我们要靠着圣灵，凭信心热切等候所盼望的义。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:15; 哥林多前书 7:19; 雅各书 2:14–26"> 因为在基督耶稣里，受不受割礼根本无关紧要，借着爱表现出来的信心才至关重要。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 9:24; 加拉太书 3:1; 希伯来书 12:1"> 你们本来在信心的路上一直跑得很好。现在是谁拦阻了你们，叫你们不再信从真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 1:6; 罗马书 8:28"> 这种劝导当然不是出于呼召你们的上帝！</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:33; 哥林多前书 5:6–7; 马可福音 8:15"> “一点面酵能使整团面发起来。”</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:12; 哥林多后书 2:3; 加拉太书 1:7"> 我在主里深信你们不会有二心，但无论谁搅扰你们，都必受惩罚。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:23; 加拉太书 6:12; 加拉太书 4:29"> 弟兄姊妹，我如果仍旧主张行割礼，怎么还会受迫害呢？如果是那样，十字架冒犯人的地方就被消除了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:10; 哥林多前书 5:13; 提多书 3:10"> 我恨不得那些搅扰你们的人把自己阉了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“把自己阉了”或作“与你们隔离”。">a</a></sup>！</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:16; 哥林多前书 9:19; 哥林多前书 8:9"> 弟兄姊妹，你们蒙召得了自由，但不要以自由为借口来放纵本性，要本着爱心互相服侍，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:12; 利未记 19:18; 加拉太书 6:2"> 因为全部的律法可以总结成一句话：“要爱邻如己。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="利未记19:18。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 3:3; 雅各书 3:14–3; 加拉太书 5:26"> 你们要谨慎，如果你们相咬相吞，恐怕会同归于尽。</span>
</div>
</div>

## 顺从圣灵

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:24–25; 罗马书 8:12–14; 加拉太书 6:8"> 因此，我劝你们行事为人要顺从圣灵的引导，这样就不会放纵本性的私欲。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:13; 约翰福音 3:6; 罗马书 8:5–8"> 因为人本性的私欲与圣灵作对，圣灵也与人本性的私欲作对，两者势不两立，使你们不能做自己想做的事。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:14; 罗马书 6:14–15; 加拉太书 5:25"> 但你们如果顺从圣灵的引导，就不在律法之下。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 6:9–10; 歌罗西书 3:5–8; 马太福音 15:18–19"> 顺从本性去做的事显而易见，如淫乱、污秽、邪荡、</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:10; 哥林多前书 11:19; 启示录 21:8"> 拜偶像、行邪术、仇恨、争斗、忌恨、恼怒、纷争、冲突、分裂<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“分裂”或译“异端”。">c</a></sup>、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:9–10; 罗马书 8:13; 罗马书 13:13"> 嫉妒、凶杀、醉酒和荒宴无度等。我从前警告过你们，现在再一次警告你们：行这些事的人必不能承受上帝的国。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:12–17; 哥林多前书 13:4–7; 约翰福音 15:5"> 但圣灵所结的果子是仁爱、喜乐、和平、忍耐、恩慈、良善、信实、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 1:9; 使徒行传 24:25; 提多书 2:2"> 温柔、自制。没有律法会禁止这些事。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 罗马书 13:14; 罗马书 8:13"> 那些属基督耶稣的人，已经把本性及其邪情私欲都钉在十字架上了。</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:16; 罗马书 8:4–5; 罗马书 8:2"> 我们如果是靠圣灵生活，就当凡事顺从圣灵的引导。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 3:14–16; 腓立比书 2:1–3; 雅各书 4:16"> 我们不要自高自大，彼此惹气，互相嫉妒。</span>
</div>
</div>

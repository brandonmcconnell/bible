## 行律法与信基督

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:7–8; 哥林多后书 11:3; 加拉太书 1:6"> 无知的加拉太人啊！谁又蛊惑了你们呢？耶稣基督被钉在十字架上的事，早就像一幅画一样展现在你们眼前了。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 10:16–17; 加拉太书 3:14; 使徒行传 15:8"> 我只想问，你们领受了圣灵是靠遵行律法呢，还是因为相信所听见的福音呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:4–8; 加拉太书 4:7–10; 希伯来书 7:16–19"> 你们既然靠圣灵开始了基督徒的生活，现在却想靠肉体达到纯全吗？你们就这么无知吗？</span>
<span className="v" id="v4" data-v="4" data-xref="约翰二书 1:8; 哥林多前书 15:2; 希伯来书 10:32–39"> 你们受了许多苦，难道都是徒然的吗？真白受了吗？</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:2; 使徒行传 14:9–10; 使徒行传 19:11–12"> 上帝将圣灵赐给你们，又在你们中间行神迹，是因为你们遵行律法呢，还是因为你们相信所听到的福音呢？</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 15:6; 罗马书 4:21–22; 雅各书 2:23"> 圣经上说：“亚伯拉罕信上帝，就被算为义人。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记15:6。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–8; 加拉太书 3:9; 加拉太书 3:26–29"> 因此，你们要明白，那些信的人才是亚伯拉罕的子孙。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 12:3; 创世记 22:18; 创世记 28:14"> 圣经早就指明，上帝要叫外族人因信被称为义人，祂预先将福音传给亚伯拉罕，说：“万国必因你而蒙福。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="创世记12:3；18:18；22:18。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 4:16; 加拉太书 3:29; 罗马书 4:24"> 所以那些信的人必和有信心的亚伯拉罕一同蒙福。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 27:26; 罗马书 8:7; 罗马书 3:19–20"> 凡以遵行律法为本的人都在咒诅之下，因为圣经上说：“凡不遵行律法书上一切命令的人必受咒诅。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命记27:26。">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷书 2:4; 罗马书 1:17; 希伯来书 10:38"> 非常明显，没有人能靠遵行律法在上帝面前被称为义人，因为圣经上说：“义人必靠信心而活。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="哈巴谷书2:4。">d</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:5; 罗马书 10:5–6; 尼希米记 9:29"> 律法并非以信心为本，而是说：“遵行律法的人必因此而活。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="利未记18:5。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:24; 申命记 21:23; 希伯来书 9:12"> 但基督替我们受了咒诅，从而救赎我们脱离了律法的咒诅，因为圣经上说：“凡挂在木头上的人都是受咒诅的。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="申命记21:23。">f</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 以西结书 36:26–27"> 这样，赐给亚伯拉罕的福气可以借着基督耶稣临到外族人，使我们也可以借着信得到上帝应许赐给我们的圣灵。</span>
</div>
</div>

## 律法与应许

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:17; 罗马书 6:19; 罗马书 3:5"> 弟兄姊妹，我举个日常生活中的例子。世人的合约一经双方签订之后，就不能作废，也不能加添。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:7–8; 罗马书 4:13; 路加福音 1:55"> 上帝曾向亚伯拉罕和他的后裔赐下应许，不过这里没有说“后裔们”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="创世记12:7；13:15；24:7。">g</a></sup>——指许多人，而是说“你的后裔”——指一个人，就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 11:39–40; 创世记 15:13; 罗马书 4:13–14"> 我的意思是：四百三十年后颁布的律法不会废除上帝先前立下的约，以致应许落空。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:12–15; 加拉太书 2:21; 罗马书 4:13–16"> 我们如果是靠遵行律法去承受产业，就不是倚靠上帝的应许。但上帝是凭应许把产业赐给了亚伯拉罕。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:53; 罗马书 7:7–13; 希伯来书 2:2"> 那么，为什么会有律法呢？律法是为了使人知罪而增设的，一直存到那位承受应许的后裔来临。律法是通过天使交给一位中保颁布的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 2:5; 申命记 6:4; 约伯记 9:33"> 中保代表双方，但上帝则单方面赐下应许。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:21; 罗马书 9:31; 罗马书 3:20–22"> 这样看来，上帝的律法和上帝的应许是否互相矛盾呢？当然不是！如果颁布的律法能带给人生命，人就可以靠律法得到义了。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 11:32; 希伯来书 9:15; 加拉太书 3:23"> 但圣经说万物都困在罪的权势下，为要使那些信的人因为信耶稣基督而得到应许<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="“因为相信耶稣基督而得到应许”或译“因为耶稣基督的信实而得到应许”。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:18; 加拉太书 3:24–25; 加拉太书 3:19"> 信耶稣的时代<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="“信耶稣的时代”希腊文是“信心”，下同25节。">i</a></sup>来临以前，律法暂时监管我们。等到信耶稣之道显明出来后，律法就不再监管了。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 10:4; 使徒行传 13:38–39; 罗马书 7:24–25"> 因此，律法是我们的监护人，负责引领我们归向基督，使我们可以因信被称为义人。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 6:14; 罗马书 7:4; 希伯来书 10:15–18"> 现在信耶稣的时代已经来临，我们不再受律法监管。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 1:5; 哥林多后书 6:18; 约翰福音 1:12–13"> 你们都借着信基督耶稣而成为上帝的儿女，</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 13:14; 哥林多前书 12:13; 罗马书 6:3–4"> 因为你们受洗归入基督就是披戴基督<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="“披戴基督”是个隐喻，主要的意思是“像基督”，象征有基督的生命与品格。">j</a></sup>。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 12:12–13; 歌罗西书 3:11; 罗马书 3:29–30"> 从此不再分犹太人和希腊人，自由人和奴隶，男人和女人，因为你们都在基督耶稣里合而为一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 3:6; 罗马书 9:7–8; 加拉太书 3:7"> 你们若属于基督，就是亚伯拉罕的子孙，并且按照上帝的应许是产业继承人。</span>
</div>
</div>

</div>

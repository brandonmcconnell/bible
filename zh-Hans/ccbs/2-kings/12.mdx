## 约阿施做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:11; 列王纪下 11:21; 列王纪下 11:1–4"> 以色列王耶户执政第七年，约阿施登基，在耶路撒冷执政四十年。他母亲叫西比亚，是别示巴人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 24:17–22; 历代志下 26:4; 历代志下 25:2"> 在耶何耶大祭司的教导下，约阿施一生做耶和华视为正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 14:4; 列王纪上 22:43; 列王纪上 15:14"> 但他没有拆除丘坛，人们仍在那里献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 22:4; 出埃及记 35:5; 历代志上 29:3–9"> 约阿施对祭司们说：“你们要收集那些奉献到耶和华殿的圣银，就是人口普查时收取的银子、个人还愿的银子和自愿奉献的银子。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 58:12; 列王纪上 11:27; 列王纪下 22:5–6"> 每位祭司要从奉献的人手中收取银子，用来修缮殿的破损之处。”</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 29:34; 彼得前书 5:2; 以赛亚书 56:10–12"> 可是，直到约阿施王执政第二十三年，祭司仍未动工。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 24:16; 历代志下 24:5–14; 列王纪下 11:4"> 约阿施召来耶何耶大祭司及其他祭司，对他们说：“你们为什么还不修殿呢？不要再向奉献的人收银子了，要把所收的银子交出来修殿。”</span>
<span className="v" id="v8" data-v="8"> 祭司们答应不再向民众收钱，但也不动工修殿。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 12:41; 诗篇 84:10; 耶利米书 35:4"> 耶何耶大祭司在耶和华殿的入口右边的祭坛旁放了一个箱子，箱盖上开了个洞。守门的祭司将奉献到耶和华殿的所有银子放进箱子里。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:17; 列王纪下 22:12; 列王纪下 19:2"> 箱子里的银子多了，王的书记和大祭司就把这些耶和华殿里的银子点好，装在袋子里。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 22:5–6; 历代志下 24:11–12; 历代志下 34:9–11"> 他们将称好的银子交给修耶和华殿的督工。督工把报酬转交给在殿里工作的木匠、建筑工人、</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 22:5–6; 列王纪上 5:17–18; 以斯拉记 3:7"> 泥水匠和石匠，购买修耶和华殿用的木料和凿好的石头，并支付其他修殿费用。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 24:14; 列王纪上 7:48–50; 以斯拉记 1:9–11"> 献到耶和华殿里的银子没有用于制造殿里的银碗、灯剪、盆、号及其他金银器皿，</span>
<span className="v" id="v14" data-v="14"> 而是给工人，用于修耶和华的殿。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 22:7; 约翰三书 1:5; 哥林多前书 4:2–3"> 经手银子的督工们办事忠诚可靠，不需要跟他们清算账目。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:7; 利未记 5:15–18; 利未记 4:24"> 赎过祭和赎罪祭的银子没有带到耶和华的殿里，而是归给祭司。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 24:23–24; 路加福音 9:53; 耶利米书 42:15"> 那时，亚兰王哈薛攻陷了迦特，准备进攻耶路撒冷。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 15:18; 列王纪下 18:15–16; 列王纪下 12:4"> 犹大王约阿施把先王约沙法、约兰、亚哈谢和他自己奉献的圣物，以及耶和华殿里和王宫库房里的所有金子都送给了亚兰王哈薛，哈薛便从耶路撒冷退兵。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪上 14:29; 列王纪上 14:19; 列王纪上 11:41"> 约阿施其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 24:24–27; 列王纪下 14:5; 撒母耳记下 5:9"> 约阿施的臣仆谋反，在去悉拉途中的米罗宫杀了他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 14:1; 历代志下 24:26–27"> 杀他的是示米押的儿子约撒甲和朔默的儿子约萨拔。约阿施葬在大卫城他的祖坟里。他儿子亚玛谢继位。</span>
</div>
</div>

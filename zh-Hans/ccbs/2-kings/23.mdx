## 约西亚的改革

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 34:29–33; 历代志下 30:2; 申命记 31:28"> 于是，王派人召集犹大和耶路撒冷的所有长老，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 22:8; 申命记 31:10–13; 启示录 20:12"> 与祭司、先知、犹大人、耶路撒冷的居民等全体民众，不论贵贱，一同上到耶和华的殿。王把在殿中发现的约书读给他们听。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 11:14; 列王纪下 11:17; 申命记 13:4"> 王站在柱旁，在耶和华面前立约，要全心全意地跟随耶和华，遵从祂的一切诫命、法度和律例，履行约书上的规定。民众都答应守约。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:3; 列王纪下 21:7; 历代志下 33:3"> 王吩咐大祭司希勒迦及其副手和殿门守卫清除耶和华殿里用来祭拜巴力、亚舍拉及天上万象的一切器具，在耶路撒冷城外汲沦溪旁的田野烧掉它们，又把灰烬带到伯特利。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 44:17–19; 列王纪下 21:3–4; 何西阿书 10:5"> 从前，犹大各王任命祭司在犹大各城和耶路撒冷周围的丘坛烧香。现在，约西亚除掉那些祭司，又除掉向巴力、日、月、星辰及天上万象烧香的祭司。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 34:4; 列王纪下 23:15; 列王纪上 14:23"> 他将亚舍拉神像从耶和华的殿里搬到耶路撒冷城外汲沦溪旁烧掉，磨成灰撒在平民的坟墓上。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:12; 以西结书 16:16; 列王纪上 14:24"> 他又拆毁耶和华的殿内男庙妓的房屋，就是妇女为亚舍拉编织帐幔的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:22; 约书亚记 21:17; 列王纪上 19:3"> 他召集犹大各城中的祭司，污渎从迦巴到别示巴的各丘坛，那些祭司曾在那里烧香。他拆毁耶路撒冷城门左边、约书亚总督门前的丘坛。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:10–14; 撒母耳记上 2:36; 玛拉基书 2:8–9"> 然而，在丘坛烧香的祭司不能在耶路撒冷耶和华的祭坛那里事奉，只可以和其他祭司一起吃无酵饼。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:33; 耶利米书 19:6; 利未记 18:21"> 他污渎欣嫩子谷中的陀斐特，使人们不能焚烧自己的儿女献给摩洛。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:16; 申命记 4:19; 历代志下 14:5"> 他从耶和华的殿门口除掉犹大各王献给太阳神的马匹，这些马匹在太监拿单·米勒房子旁边的院子里。他烧掉了那些献给太阳神的战车。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 21:5; 西番雅书 1:5; 耶利米书 19:13"> 他推倒犹大各王在亚哈斯楼顶上建造的祭坛，摧毁玛拿西在耶和华殿的两个院子里所筑的祭坛，把它们打碎，把灰倒进汲沦溪。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 11:7; 列王纪上 11:5; 民数记 21:29"> 他污渎耶路撒冷东面、腐烂山南面的丘坛。这些丘坛都是以色列王所罗门为西顿人可憎的神明亚斯她录、摩押人可憎的神明基抹和亚扪人可憎的神明米勒公建造的。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 7:5; 出埃及记 23:24; 列王纪下 23:16"> 他砸碎神柱，砍倒亚舍拉神像，用死人骨头填满那些地方。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:6; 列王纪上 14:16; 列王纪上 21:22"> 他拆掉伯特利高岗上的祭坛，即尼八的儿子耶罗波安诱使以色列人犯罪时建造的祭坛，把祭坛烧毁，捣碎成灰，又焚烧亚舍拉神像。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:1–2; 列王纪上 13:32; 约翰福音 10:35"> 约西亚转身看见山上的坟墓，就派人取出墓中的尸骨，放在那祭坛上焚烧，污渎了那祭坛，应验了耶和华借祂的仆人所说的预言。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 13:1; 列王纪上 13:30–31"> 约西亚问：“我看到的那墓碑是谁的？”那城里的人告诉他：“是上帝仆人的，他曾从犹大来预言你对伯特利祭坛所做的这些事。”</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:31; 列王纪上 13:1–22"> 他说：“不要动他，不要动他的尸骨。”于是，他们没有动那位先知和撒玛利亚来的先知的尸骨。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 34:6–7; 列王纪下 17:9; 以西结书 8:17–18"> 他拆毁以色列各王从前建在撒玛利亚各城高岗上、惹耶和华发怒的神庙，就像他在伯特利所做的一样。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:18; 历代志下 34:5; 出埃及记 22:20"> 他在祭坛上杀死那些丘坛的祭司，又在坛上焚烧死人骨头。之后，他返回耶路撒冷。</span>
</div>
</div>

## 约西亚守逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 16:1–8; 民数记 9:2–5; 历代志下 35:1–19"> 约西亚王吩咐民众：“你们应当依照约书的记载庆祝逾越节，以尊崇你们的上帝耶和华。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 30:1–3; 历代志下 30:13–20; 历代志下 35:3–19"> 约西亚执政第十八年，他们在耶路撒冷庆祝逾越节，以尊崇耶和华。自士师治理以色列起，至以色列和犹大列王统治期间，都没有这样庆祝过逾越节。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 19:31; 列王纪下 21:6; 创世记 31:19"> 为了遵守祭司希勒迦在耶和华殿里找到的律法书上的话，约西亚彻底清除了耶路撒冷和犹大境内的灵媒、巫师、家庭神像及其他一切可憎之物。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 18:5; 耶利米书 29:13; 申命记 6:5"> 约西亚全心、全意、全力归向耶和华，遵行摩西的一切律法，在犹大列王中空前绝后。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11–13; 列王纪下 24:4; 耶利米书 3:7–10"> 然而，玛拿西所行的一切惹怒耶和华，耶和华对犹大仍盛怒未息。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 18:11; 列王纪下 21:13; 列王纪下 21:4"> 耶和华说：“我要像驱逐以色列人一样将犹大人从我面前赶走。我要撇弃我所拣选的耶路撒冷城和我宣告我名常在的殿。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="参列王纪上8:29。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 20:20"> 约西亚其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 46:2; 历代志下 35:20–24; 士师记 5:19"> 约西亚执政期间，埃及王尼哥前往幼发拉底河援助亚述王，约西亚出兵迎战尼哥，结果在米吉多被杀。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 9:28; 历代志下 36:1–4; 列王纪下 21:24"> 他的臣仆用车把他的尸体从米吉多运回耶路撒冷，葬在他的墓穴里。民众膏立他儿子约哈斯接替他做王。</span>
</div>
</div>

## 约哈斯做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志上 3:15; 列王纪下 24:18; 耶利米书 22:11"> 约哈斯二十三岁登基，在耶路撒冷执政三个月。他母亲叫哈慕她，是立拿人耶利米的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 21:2–7; 列王纪下 21:21–22"> 约哈斯像他祖先一样做耶和华视为恶的事。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:65; 列王纪下 25:6; 耶利米书 39:5–6"> 埃及王尼哥把约哈斯囚禁在哈马的利比拉，不准他在耶路撒冷做王，又罚犹大国六万八千两银子和六百八十两金子。</span>
</div>
</div>

## 约雅敬做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以西结书 19:3–4; 列王纪下 24:17; 历代志上 3:15"> 埃及王尼哥立约西亚的另一个儿子以利雅敬为王，给他改名为约雅敬。约哈斯被尼哥带到埃及，并死在那里。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 23:33; 列王纪下 15:19–20"> 为了缴纳法老索要的金银，约雅敬向全国征税，按照民众家产的多少征收金银。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 36:5; 耶利米书 26:1; 历代志上 3:15"> 约雅敬二十五岁登基，在耶路撒冷执政十一年。他母亲叫西布妲，是鲁玛人毗大雅的女儿。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 33:22–23; 以西结书 19:5–9; 耶利米书 36:31"> 他像他祖先一样做耶和华视为恶的事。</span>
</div>
</div>

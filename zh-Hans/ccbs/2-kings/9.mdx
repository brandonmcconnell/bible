## 耶户被立为以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 10:1; 列王纪下 4:29; 列王纪上 1:39"> 以利沙先知叫来一个先知，吩咐他：“你要束上腰带，拿着这瓶膏油去基列的拉末。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 9:5; 列王纪上 19:16–17; 列王纪下 9:11"> 到了以后，你去找宁示的孙子、约沙法的儿子耶户，带他离开同僚，进入密室，</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:16; 出埃及记 29:7; 撒母耳记上 16:2"> 把这瓶膏油倒在他头上，告诉他，‘耶和华说，我膏立你为以色列王。’然后，你要马上开门逃走，不可迟延。”</span>
<span className="v" id="v4" data-v="4"> 于是，那位年轻的先知启程前往基列的拉末。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 3:19"> 到了那里，他看见众将领正坐在一起，便说：“将军，我有话对你说。”耶户说：“你想对我们哪一个说话？”他说：“将军啊，我有话对你说。”</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 22:7; 列王纪上 19:16; 列王纪下 9:3"> 耶户便站起来，进入屋里。他将膏油倒在耶户头上，说：“以色列的上帝耶和华说，‘我膏立你做我以色列子民的王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:15; 列王纪上 18:4; 申命记 32:43"> 你要杀你主人亚哈的全家，这样我就可以为我的仆人——众先知及其他仆人报仇，他们被耶洗别杀害。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:22; 申命记 32:36; 列王纪下 14:26"> 亚哈全家必灭亡，我要从以色列铲除他家所有的男子，不论奴隶还是自由人，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 15:29; 列王纪上 21:22; 列王纪上 14:10–11"> 使他家像尼八的儿子耶罗波安家和亚希雅的儿子巴沙家一样。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:23; 列王纪下 9:35–36; 列王纪下 9:3"> 耶洗别的尸体必在耶斯列的田间被狗吃，无人埋葬。’”说完这话，那位年轻的先知便开门逃跑了。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 29:26; 使徒行传 26:24; 何西阿书 9:7"> 耶户出来回到同僚那里，一个人问他：“没事吧？那疯子为什么来找你？”耶户答道：“你们认得他，也知道他会说什么。”</span>
<span className="v" id="v12" data-v="12"> 他们说：“我们不知道，你告诉我们吧！”耶户说：“他告诉我，耶和华说膏立我做以色列王。”</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:7–8; 列王纪上 1:39; 列王纪上 1:34"> 他们连忙将自己的衣服铺在耶户脚下的台阶上，吹响号角，高喊：“耶户做王了！”</span>
</div>
</div>

## 以色列王约兰被杀

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 8:28; 列王纪上 22:3; 列王纪上 16:16"> 宁示的孙子、约沙法的儿子耶户背叛了约兰。当时，约兰率领全体以色列人在基列的拉末防御亚兰王哈薛，</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 8:29; 撒母耳记上 27:9–11; 历代志下 22:6"> 他与哈薛交战受伤后，回到耶斯列养伤。耶户对属下说：“你们如果要我做王，就不要让任何人逃出城去耶斯列报信。”</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:6–7; 列王纪下 8:28–29"> 于是，耶户驾车去了耶斯列，因为约兰在耶斯列养伤，犹大王亚哈谢也在那里探望他。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 16:4; 以西结书 33:2–9; 列王纪下 7:14"> 耶斯列城楼上的守望者看见耶户的人马朝耶斯列奔来，就报信说：“我见到一队人马！”约兰下令：“派一个骑兵去看看他们是否为平安而来。”</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 9:19; 列王纪下 9:22; 耶利米书 16:5"> 骑兵出去迎接耶户，对他说：“王问你是否为平安而来。”耶户说：“这与你何干？你跟在我后面。”守望者禀告说：“使者到了那里，却没有回来。”</span>
<span className="v" id="v19" data-v="19"> 王又派一个骑兵到耶户那里，对他说：“王问你是否为平安而来。”耶户说：“这与你何干？你跟在我后面。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 18:27; 列王纪上 19:17; 传道书 9:10"> 守望者又禀告说：“他到了那里，也没有回来。那人驾车很猛，像是宁示的孙子耶户。”</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 21:1–7; 历代志下 22:7; 弥迦书 1:13"> 约兰下令备车。以色列王约兰和犹大王亚哈谢各乘自己的战车去见耶户。他们和耶户在耶斯列人拿伯的田里相遇。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 21:13; 那鸿书 3:4; 列王纪上 16:30–33"> 约兰问他：“耶户，你为平安而来吗？”耶户答道：“国中到处都是你母亲耶洗别的偶像和邪术，怎能平安呢？”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 11:14; 历代志下 23:13"> 约兰调转车头逃跑，向亚哈谢大喊：“亚哈谢，他反了！”</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 22:34; 箴言 21:30; 帖撒罗尼迦前书 5:3"> 耶户张弓搭箭，射中约兰的后背，箭穿透他的心脏，他倒毙在车上。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 21:19; 列王纪上 21:24–29; 以赛亚书 13:1"> 耶户对将领毕甲说：“你去把他扔在耶斯列人拿伯的田里。你该记得，你我一起驾车跟随他父亲亚哈的时候，耶和华曾预言亚哈的事说，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 21:19; 申命记 5:9; 历代志下 25:4"> ‘我昨天看见拿伯和他儿子们被杀，我必使你在这块田里受到报应，这是耶和华说的。’现在你照耶和华的话，把他扔在这块田里吧。”</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 1:27; 约书亚记 17:11; 列王纪下 8:29"> 犹大王亚哈谢见状就沿着通往伯哈干的道路逃跑。耶户在后面追，并大喊：“也把他射死！”他们在以伯莲附近的姑珥坡把亚哈谢射伤在车上。他逃到米吉多后，伤重身亡。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:24; 列王纪下 23:30; 列王纪下 12:21"> 他的臣仆用车把他的尸体运回耶路撒冷，安葬在大卫城他的祖坟里。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 21:18–19; 历代志下 22:1–2; 列王纪下 8:24–25"> 亚哈的儿子约兰执政第十一年，亚哈谢登基做犹大王。</span>
</div>
</div>

## 耶洗别被杀

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 4:30; 以西结书 23:40; 以西结书 24:17"> 耶户去了耶斯列。耶洗别闻讯，便梳头描眉，向窗外眺望。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 16:9–20"> 耶户进城时，耶洗别高声喊道：“谋杀主人的心利啊，平安吗？”</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 2:15; 出埃及记 32:26; 历代志下 11:12"> 耶户抬头望着窗口，喊道：“谁拥护我？谁？”有两三个太监从窗口往外看他。</span>
<span className="v" id="v33" data-v="33" data-xref="弥迦书 7:10; 耶利米哀歌 1:15; 以赛亚书 25:10"> 耶户说：“把她扔下来！”那几个太监便把耶洗别扔下去，血溅在墙壁上和马匹身上。耶户驾车轧过她的身体，</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:31; 列王纪上 21:25; 以赛亚书 65:15"> 他进入王宫，吃喝完毕，然后吩咐部下说：“处理掉那受咒诅的妇人，把她埋了，她毕竟是王的女儿。”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 12:23; 以赛亚书 14:18–20; 约伯记 31:3"> 他们出去埋葬她，却只找到她的头骨、手掌和脚，</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 21:23; 利未记 8:36; 列王纪下 14:25"> 便回去禀告耶户。耶户说：“这正应验耶和华借祂仆人提斯比人以利亚说的话，‘狗必在耶斯列的田间吃耶洗别的肉，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 8:2; 诗篇 83:10; 耶利米书 16:4"> 耶洗别的尸体必像耶斯列田间的粪便，无人能认出那是耶洗别。’”</span>
</div>
</div>

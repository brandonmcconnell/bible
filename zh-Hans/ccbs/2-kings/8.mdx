## 书念妇人得回产业

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈该书 1:11; 列王纪下 4:31–35; 路得记 1:1"> 以利沙曾经救活了一位书念妇人的儿子。他对那妇人说：“你和家人要离开这里去别处寄居，因为耶和华已决定使这里遭受七年饥荒。”</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 5:8; 士师记 3:3; 撒母耳记上 27:1–3"> 那妇人遵照上帝仆人的话，举家迁往非利士，在那里寄居了七年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 22:16; 路加福音 18:3–5; 列王纪下 4:13"> 七年后，她从非利士返回，去向王请求收回自己的房屋和田地。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 5:20–27; 列王纪下 2:14; 列王纪下 6:32"> 那时，王正与上帝仆人的侍者基哈西谈话，让基哈西把以利沙所做的一切大事讲给他听。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 4:35; 马太福音 10:29–30; 列王纪下 6:26"> 基哈西正在向王讲述以利沙如何使死人复活的时候，以利沙救活的孩子的母亲刚好进宫为自己的房屋和田地来求王，基哈西便说：“我主我王，这就是那妇人，这是她那个被以利沙救活的儿子。”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:7; 箴言 21:1; 撒母耳记下 9:7"> 王问那妇人，她便如实禀告王。王委派一位臣仆处理她的事情，并吩咐说：“凡属于这妇人的东西，包括从她离开本地直到今天她田地的所有出产，要全部还给她。”</span>
</div>
</div>

## 以利沙对哈薛的预言

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪上 11:24; 列王纪下 6:24; 列王纪上 20:1"> 一天，以利沙到了大马士革。当时亚兰王便·哈达正在生病，他得知上帝的仆人来了，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 19:15; 列王纪下 1:2; 撒母耳记上 9:7"> 便对哈薛说：“你带着礼物去见上帝的仆人，请他求问耶和华，看看我这病能否痊愈。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 5:13; 列王纪下 13:14; 列王纪上 19:15"> 哈薛用四十头骆驼驮着大马士革的各种美物前去拜见以利沙。到了那里，他站在以利沙面前说：“你儿子亚兰王便·哈达派我来问你，他的病能否痊愈？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 7:7; 创世记 2:17; 阿摩司书 7:1"> 以利沙对哈薛说：“你去告诉他，他一定会痊愈。不过，耶和华告诉我他必死。”</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:41; 罗马书 9:2; 耶利米书 9:18"> 他目不转睛地盯着哈薛，盯得他很不安。然后，上帝的仆人哭了。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿书 13:16; 那鸿书 3:10; 列王纪下 15:16"> 哈薛问：“我主为什么哭呢？”以利沙说：“因为我知道你会加害以色列人。你会放火烧他们的堡垒，用刀杀戮他们的壮丁，摔死他们的孩童，剖开他们的孕妇。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 17:43; 列王纪上 19:15; 撒母耳记下 9:8"> 哈薛说：“你仆人算什么，不过是一条狗，怎能做这样的大事呢？”以利沙说：“耶和华告诉我，你要做亚兰王。”</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 8:10; 马太福音 26:16; 列王纪下 5:25"> 哈薛辞别以利沙回到他主人那里。王问他：“以利沙对你说什么？”他答道：“以利沙告诉我，你一定会痊愈。”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 8:13; 列王纪上 15:28; 列王纪上 11:26–37"> 第二天，哈薛拿了一床浸透水的被子，蒙在王的脸上，王窒息而死。于是哈薛篡位。</span>
</div>
</div>

## 约兰做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 1:17; 列王纪下 3:1; 历代志下 21:1–20"> 亚哈的儿子以色列王约兰执政第五年，犹大王约沙法让位给儿子约兰。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 21:5–10"> 约兰三十二岁登基，在耶路撒冷执政八年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 8:26; 列王纪上 11:1–5; 历代志下 21:13"> 他与亚哈家一样步以色列诸王的后尘，因为他娶了亚哈的女儿为妻，做耶和华视为恶的事。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 11:36; 撒母耳记下 7:12–13; 路加福音 1:32–33"> 但耶和华因祂仆人大卫的缘故而不愿毁灭犹大，因为祂曾应许让大卫和他的子孙永远做王。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:47; 列王纪下 3:9; 列王纪下 8:22"> 约兰执政期间，以东人脱离犹大的统治，自己立王。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 18:17"> 约兰率领所有战车前往撒益，他和战车长们被以东人包围。他们乘夜出击，突出重围，各自逃回家去。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 19:8; 约书亚记 21:13; 创世记 27:40"> 以东人至今仍脱离犹大的统治。立拿人也在那时候叛变了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 15:36; 列王纪上 11:41; 历代志下 21:11–20"> 约兰其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 22:6; 历代志下 25:23; 历代志下 21:1"> 约兰与祖先同眠后，葬在大卫城他的祖坟里。他儿子亚哈谢继位。</span>
</div>
</div>

## 亚哈谢做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪下 9:29; 列王纪下 8:16–17; 历代志下 21:20–6"> 亚哈的儿子以色列王约兰执政第十二年，犹大王约兰的儿子亚哈谢登基。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 22:2; 列王纪下 9:21–27; 列王纪下 11:1"> 他二十二岁登基，在耶路撒冷执政一年。他母亲叫亚她利雅，是以色列王暗利的孙女。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 22:3–4; 哥林多后书 6:14–17; 传道书 7:26"> 亚哈谢是亚哈家的女婿，他步亚哈家的后尘，做耶和华视为恶的事。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="历代志下 22:5; 列王纪上 4:13; 历代志下 19:2"> 他联合亚哈的儿子约兰到基列的拉末与亚兰王哈薛交战。约兰受了伤，</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 9:15–16; 列王纪下 8:28; 历代志下 22:5–7"> 便回到耶斯列养伤。约兰的儿子犹大王亚哈谢下到耶斯列探望他，因为他病了。</span>
</div>
</div>

</div>

## 耶何耶大立约阿施为王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:1; 列王纪下 25:25; 历代志下 22:10–12"> 亚哈谢的母亲亚她利雅见儿子死了，便动手除掉整个王室。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 33:26; 耶利米书 35:2; 以赛亚书 7:6–7"> 但约兰王的女儿、亚哈谢的妹妹约示巴把亚哈谢的儿子约阿施从将要被杀的王子中偷出来，把他和他的乳母藏在一间卧室里，才躲过亚她利雅的杀戮。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 12:8; 历代志下 22:12; 玛拉基书 3:15"> 约阿施和他的乳母在耶和华的殿里藏了六年，那时亚她利雅当政。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 11:19; 列王纪下 11:9; 列王纪下 11:17"> 第七年，耶何耶大派人召迦利人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“迦利人”指雇来保护王的外族卫兵。">a</a></sup>和卫兵的百夫长们到耶和华的殿里，与他们立约，让他们在耶和华的殿里起誓，然后把约阿施王子带到他们面前。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:25; 以西结书 44:2–3; 历代志上 23:32"> 耶何耶大吩咐他们说：“你们在安息日值班的，三分之一的人要守卫王宫，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 23:4–5; 历代志上 26:13–19"> 三分之一的人要守卫苏珥门，三分之一的人要守住卫兵院后门。你们要轮流守卫。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 23:6; 列王纪下 11:5"> 安息日不值班的两队要在耶和华的殿里保护王，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 27:17; 历代志下 23:7; 列王纪上 2:28–31"> 各人要手持兵器护卫在王周围。凡擅自闯入者，一律处死。无论王去哪里，你们都要紧随左右。”</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 23:8; 列王纪下 11:4; 历代志上 26:26"> 众百夫长遵令而行，各自带着在安息日值班和休班的属下来见耶何耶大。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:7; 历代志上 18:7; 历代志下 5:1"> 耶何耶大祭司把耶和华殿中大卫王的矛枪和盾牌交给百夫长。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 11:8; 以西结书 8:16; 列王纪下 11:10"> 卫兵都手持兵器，从殿右到殿左，在祭坛和殿周围护卫王。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:16; 撒母耳记上 10:24; 列王纪上 1:39"> 耶何耶大领王子出来，给他戴上王冠，把约书交给他，膏立他为王。众人都鼓掌高呼：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 23:12–15"> 亚她利雅听见卫兵和众人的欢呼声，便走进耶和华的殿，众人都聚集在那里。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:31; 列王纪下 23:3; 列王纪下 9:23"> 她看见王照例站在柱旁，百夫长和吹号的人侍立在王左右，众人都欢呼吹号，便撕裂衣服喊道：“反了！反了！”</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 9:7; 历代志下 23:14; 历代志下 23:9"> 耶何耶大祭司认为不可在耶和华的殿里处死亚她利雅，便命令带兵的百夫长：“把她带出去并用刀杀死所有跟随她的人。”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:6; 历代志下 23:15; 马太福音 7:2"> 他们抓住她，把她带到马匹进出王宫的入口，在那里杀了她。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 5:3; 历代志下 15:12–14; 历代志下 34:31"> 耶何耶大让王和民众与耶和华立约，做耶和华的子民，也让王与民众立约。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:3; 列王纪下 10:26; 列王纪上 18:40"> 于是，民众出去拆毁了巴力庙，砸碎祭坛和偶像，在坛前杀了巴力的祭司玛坦。耶何耶大派守卫保护耶和华的殿，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:25; 耶利米书 22:4; 历代志下 23:19"> 然后率领百夫长、迦利人、卫兵和全体民众，护送王从耶和华的殿下来，经过卫兵院的门进入王宫。这样，约阿施坐上了王位。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:10; 箴言 29:2; 列王纪下 11:14"> 民众都欢喜快乐，城里安定，因为亚她利雅已在王宫那里被处死。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 24:1–14; 列王纪下 22:1; 列王纪下 11:4"> 约阿施七岁登基。</span>
</div>
</div>

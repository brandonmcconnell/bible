## 耶户铲除亚哈家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:30; 列王纪上 13:32; 列王纪上 21:8–14"> 亚哈在撒玛利亚有七十个子孙。耶户写信并送到撒玛利亚，交给耶斯列的首领、长老以及亚哈子孙的监护人，说：</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:6"> “既然你们主人的子孙和你们在一起，你们也拥有车马、坚城和兵器，你们接到这封信后，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:8–9; 列王纪上 12:20–21; 撒母耳记下 2:12–17"> 就可以从你们主人的子孙中选立一个最好的继承王位，为你们主人家而战。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 9:24; 列王纪下 9:27; 以赛亚书 27:4"> 他们都十分害怕，便说：“两位王都不能抵挡他，我们怎能抵挡呢？”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 20:32; 列王纪上 20:4; 约书亚记 9:11"> 宫廷总管、总督、长老和众监护人便派人送信给耶户，说：“我们是你的仆人，你怎样吩咐，我们就怎样做。我们不会立任何人为王，你认为怎样好，就怎样办吧。”</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 2:20–23; 申命记 5:9; 民数记 25:4"> 耶户又写了一封信，说：“你们如果归顺我，愿意听从我，明天这个时候，带着你们主人子孙的首级来耶斯列见我。”当时亚哈的七十个子孙都养在城中显贵的府中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:21; 列王纪下 11:1; 列王纪下 10:9"> 这些显贵们接到信后，便杀了亚哈的七十个子孙，把他们的首级放在篮子里，送到耶斯列的耶户那里。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:23; 撒母耳记下 11:18–21; 马可福音 6:28"> 使者告诉耶户：“他们将王众子孙的首级送来了。”耶户下令：“把首级分成两堆，放在城门口，一直放到明天早上。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:14–24; 以赛亚书 5:3; 何西阿书 1:4"> 第二天早晨，耶户出去站在城门口，对众人说：“你们都没有罪，是我背叛我主人，把他杀了。可是，是谁杀了这些人呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:29; 列王纪上 21:19; 列王纪下 9:7–10"> 由此可知，耶和华对亚哈家的预言一句也没有落空。耶和华借祂仆人以利亚所说的一切都应验了。”</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:19; 列王纪上 18:19; 列王纪上 22:6"> 耶户杀了亚哈家留在耶斯列的亲属、大臣、朋友和祭司，一个不留。</span>
<span className="v" id="v12" data-v="12"> 耶户动身去撒玛利亚，经过牧人剪羊毛的地方时，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 8:29; 列王纪下 8:24; 历代志下 21:17"> 遇见犹大王亚哈谢的亲属，就问：“你们是谁？”他们答道：“我们是亚哈谢的亲属，现在去问候王和太后一家。”</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 22:10; 列王纪下 10:6; 列王纪下 10:10–11"> 耶户下令活捉他们，他的手下便捉住他们，在伯‧艾克特的井旁全部杀掉，共四十二人，一个不留。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 35:14–19; 以斯拉记 10:19; 以西结书 17:18"> 耶户继续前行，遇见前来迎接他的利甲的儿子约拿达。耶户问候他，并说：“我对你忠诚，你对我也一样忠诚吗？”约拿达答道：“当然！”耶户说：“既然如此，把手伸给我。”他伸出手来，耶户把他拉上车，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 19:10; 马太福音 6:5; 列王纪下 10:31"> 说：“跟我来，看我怎样热心为耶和华工作。”于是耶户让他坐在车上。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 9:8; 历代志下 22:8; 玛拉基书 4:1"> 到了撒玛利亚，他把亚哈家在撒玛利亚剩下的人全部杀光，一个不留，应验了耶和华对以利亚说的话。</span>
</div>
</div>

## 耶户计杀拜巴力之人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 16:31–32; 列王纪下 3:2; 罗马书 3:8"> 耶户召集了所有的人，对他们说：“亚哈供奉巴力还不够热心，我耶户要更热心地供奉他。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:6; 列王纪上 18:19; 哥林多后书 11:3"> 我要向巴力献大祭，你们去把巴力的先知和祭司及所有拜巴力的人一个不漏地召来。凡不来的人休想活命。”耶户这样做，是想用计杀尽拜巴力的人。</span>
<span className="v" id="v20" data-v="20" data-xref="约珥书 1:14; 出埃及记 32:5; 列王纪上 18:19–20"> 耶户下令召开祭拜巴力的庄严聚会，于是他们发出通告。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 16:32; 列王纪下 11:18; 约珥书 3:2"> 耶户派人送信到以色列各地，凡拜巴力的人全都来了，没有一个缺席。他们把整个巴力庙塞得满满的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:2; 马太福音 22:11–12"> 耶户吩咐掌管礼服的人拿出礼服给拜巴力的人穿上，他就拿出礼服给他们穿上。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:30; 马太福音 25:32–33; 马太福音 13:41"> 然后他和利甲的儿子约拿达进庙向他们宣布说：“你们仔细察看，这里不可有事奉耶和华的人，只允许拜巴力的人在这里。”</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:30–42"> 耶户和约拿达在庙里献上祭物和燔祭。此前，他预先派了八十人在庙外守着，并下令：“我把这些人交在你们手中，谁放走一个，谁就要以命抵偿。”</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 16:6–7; 以西结书 22:21–22; 列王纪上 18:40"> 耶户献完燔祭出来，便命令卫兵和将领说：“进去杀死他们，不要放走一人。”卫兵和将领挥刀杀了他们，把尸首抛出去后，走入巴力庙的内殿，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:23; 列王纪下 3:2; 列王纪下 19:18"> 将巴力神柱搬出去烧了。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 3:29; 以斯拉记 6:11; 但以理书 2:5"> 他们摧毁了巴力的神柱和庙，把庙当作厕所，至今未变。</span>
<span className="v" id="v28" data-v="28"> 这样，耶户从以色列扫除了巴力。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:28–30; 列王纪上 14:16; 列王纪上 13:33–34"> 可是，他重蹈尼八的儿子耶罗波安的覆辙，拜伯特利和但两地的金牛犊，使以色列人陷入罪中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 10:35; 列王纪下 13:1; 列王纪下 13:10"> 耶和华对耶户说：“你已经做了我视为正的事，照我的意思除掉了亚哈一家，因此你的子孙必做以色列王，直到第四代。”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 10:29; 箴言 4:23; 希伯来书 2:1"> 但耶户没有全心全意地遵守以色列的上帝耶和华的律法，却重蹈耶罗波安的覆辙，使以色列人陷入罪中。</span>
</div>
</div>

## 耶户去世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪下 8:12; 列王纪上 19:17; 列王纪下 13:22"> 那时，耶和华开始削减以色列的领土。哈薛攻打以色列各处，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司书 1:3–4; 申命记 2:36; 约书亚记 13:9–12"> 侵占了约旦河以东的土地，包括基列全境，即迦得人、吕便人和玛拿西人住的地方，从亚嫩谷附近的亚罗珥起，直到基列和巴珊。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪上 14:19"> 耶户其他的事及一切所为和功业都记在《以色列列王史》上。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪上 1:21"> 他与祖先同眠后葬在撒玛利亚，他儿子约哈斯继位。</span>
<span className="v" id="v36" data-v="36"> 耶户在撒玛利亚统治以色列二十八年。</span>
</div>

## 何细亚做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:30"> 犹大王亚哈斯执政第十二年，以拉的儿子何细亚在撒玛利亚登基做以色列王，执政九年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 3:2; 列王纪下 13:11; 历代志下 30:5–11"> 他做耶和华视为恶的事，不过没有他之前的以色列诸王那么败坏。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 10:14; 列王纪下 15:19; 列王纪下 19:36–37"> 亚述王撒缦以色攻打以色列，何细亚纳贡称臣。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:21; 列王纪下 24:20; 以西结书 17:13–19"> 然而，何细亚差遣使者向埃及王梭求援，不再像往年那样向亚述王进贡。亚述王发现后，把他抓起来囚在狱中。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿书 13:16; 列王纪下 25:1–3; 列王纪下 18:9"> 亚述王攻打以色列全境，并围困撒玛利亚三年。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 何西阿书 13:16; 申命记 28:64"> 何细亚执政第九年，撒玛利亚沦陷。亚述王把以色列人掳到亚述，安置在哈腊、歌散的哈博河一带以及玛代人的各城。</span>
</div>
</div>

## 以色列人的罪恶史

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 23:16; 诗篇 106:35–41; 尼希米记 9:26"> 以色列人之所以有如此下场，是因为他们的上帝耶和华带他们出埃及，从埃及王法老手中救出他们，他们却犯罪得罪祂。他们祭拜其他神明，</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 18:3; 列王纪下 16:3; 申命记 18:9"> 效法耶和华在他们面前赶走的外族人的风俗和以色列诸王奉行的习俗。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:8; 约伯记 31:27; 申命记 13:6"> 以色列人暗中做不义之事，冒犯他们的上帝耶和华。从瞭望塔到坚城，他们在各地建丘坛，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 14:23; 弥迦书 5:14; 出埃及记 34:13"> 在各高岗上、绿树下立神柱和亚舍拉神像，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 28:25; 列王纪下 21:6; 耶利米书 44:17"> 在各丘坛烧香，如同耶和华在他们面前赶走的外族人一样。他们邪恶的行为激怒了耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:4; 出埃及记 20:3–5; 申命记 4:23–25"> 尽管耶和华警告他们不可祭拜偶像，他们仍然执迷不悟。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="参出埃及记20:4‑5。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 35:15; 撒母耳记上 9:9; 耶利米书 18:11"> 耶和华借着祂的众先知和先见警告以色列人和犹大人说：“你们要离开恶道，按照我吩咐你们祖先的一切律法遵守我的诫命和律例，这律法是借着我的仆人——众先知传给你们的。”</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 31:27; 使徒行传 7:51; 诗篇 106:24"> 但他们充耳不闻，像他们祖先一样顽固不化，不信靠他们的上帝耶和华，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 12:30–31; 申命记 32:21; 罗马书 1:21–23"> 拒绝遵守祂的律例和祂与他们祖先所立的约，无视祂的警告。他们随从虚无的偶像，自己也变得虚无。他们违背耶和华的命令，效法周围的外族人。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:23; 列王纪上 16:31; 列王纪上 14:15"> 他们弃绝他们的上帝耶和华的诫命，铸造了两个金牛犊，还造了亚舍拉神像。他们祭拜巴力和天上的万象，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 21:6; 列王纪下 16:3; 申命记 18:10–12"> 把自己的儿女烧死献作祭物。他们占卜，行邪术，出卖自己去做耶和华视为恶的事，惹祂发怒。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 12:20; 列王纪上 11:13; 何西阿书 11:12"> 因此，耶和华非常愤怒，从祂面前赶走以色列人，只留下犹大一个支派。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 16:3; 列王纪上 14:22–23; 以西结书 16:51–52"> 但犹大人也不遵守他们的上帝耶和华的诫命，反而效法以色列人的习俗。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 耶利米书 6:30; 列王纪下 13:3"> 于是，耶和华弃绝了以色列全族，使他们饱尝痛苦，任人宰割，直至把他们从自己眼前赶走。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 11:11; 列王纪上 11:31; 列王纪上 14:16"> 祂使以色列从大卫家分裂出来，以色列人便拥立尼八的儿子耶罗波安为王。耶罗波安诱使以色列人远离耶和华，使他们犯了大罪。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 3:3; 列王纪下 13:6; 列王纪下 13:11"> 以色列人沉溺于耶罗波安所犯的一切罪中，始终不肯回头，</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 17:6; 列王纪下 17:13; 列王纪下 17:20"> 直到耶和华把他们从自己眼前赶走，正如祂借着自己的仆人——众先知对他们的警告。这样，以色列人被掳到亚述，至今仍住在那里。</span>
</div>
</div>

## 外族人移居撒玛利亚

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪下 18:34; 列王纪下 17:30–31; 马太福音 10:5"> 亚述王把巴比伦、古他、亚瓦、哈马、西法瓦音等地的一些居民迁移到撒玛利亚各城，代替以色列人占据各城，住在其中。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 17:32; 列王纪下 17:34; 列王纪下 17:41"> 刚迁居到那里的时候，他们不敬畏耶和华，所以耶和华差遣狮子闯入他们当中，咬死了一些人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 17:27; 撒母耳记上 8:9; 阿摩司书 8:14"> 有人禀告亚述王说：“你迁移到撒玛利亚各城的那些人不知道当地神明的规矩，所以神明就差遣狮子闯入他们当中，咬死了一些人。”</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 17:13; 列王纪上 12:31; 列王纪上 13:2"> 亚述王便下令：“派一位被掳来的祭司回去，让他住在那里，把当地神明的规矩教导给他们。”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 12:29–32; 以赛亚书 29:13; 马太福音 15:14"> 于是，有一位从撒玛利亚被掳走的祭司回去住在伯特利，教导他们怎样敬拜耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:31; 弥迦书 4:5; 列王纪上 13:32"> 可是，这些从各地迁来的民族都在所住的各城为自己制造神像，供奉在撒玛利亚人在高岗上建造的神庙中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:24"> 巴比伦人造疏割·比讷神像，古他人造匿甲神像，哈马人造亚示玛神像，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:24; 列王纪下 17:17; 列王纪下 19:37"> 亚瓦人造匿哈和他珥他神像，西法瓦音人焚烧儿女向他们的神明亚得米勒和亚拿米勒献祭。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 12:31; 列王纪下 17:29; 列王纪上 13:33"> 他们也敬畏耶和华，却委任各种人做祭司，在高岗上的神庙为他们献祭。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 17:41; 路加福音 16:13; 马太福音 6:24"> 他们就这样既敬畏耶和华，又各按各的风俗供奉自己的神明。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 32:28; 创世记 35:10; 列王纪下 17:27–28"> 直到现在，他们依然持守旧俗，不敬畏耶和华，也不遵行耶和华赐给雅各子孙的律例、典章、法度和诫命。耶和华曾给雅各取名叫以色列，</span>
<span className="v" id="v35" data-v="35" data-xref="士师记 6:10; 约书亚记 23:16; 约书亚记 23:7"> 与他的子孙立约，吩咐他们：“不可敬奉其他神明，不可跪拜和供奉它们，也不可向他们献祭。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 6:6; 申命记 6:13; 利未记 19:32"> 耶和华伸出大能的臂膀把你们领出埃及，你们要敬畏祂，要向祂跪拜、献祭。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 19:37; 申命记 5:31–2; 申命记 4:44–45"> 你们要永远谨遵祂所定的律例、典章、法度和诫命，不可敬奉其他神明。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 4:23; 申命记 6:12; 申命记 8:14–18"> 不可忘记我与你们立的约，不可敬奉其他神明。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:74–75; 撒母耳记上 12:24; 马太福音 10:28"> 我是你们的上帝耶和华，你们要敬畏我，我必从一切仇敌手中救你们。”</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 4:28; 列王纪下 17:8; 耶利米书 13:23"> 但是他们没有听从，依然持守旧俗。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 6:24; 西番雅书 1:5; 列王纪上 18:21"> 那些移民到撒玛利亚各城的外族人既敬畏耶和华，又供奉自己的偶像。直到今日，他们的子孙仍是这样。</span>
</div>
</div>

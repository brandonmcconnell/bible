## 玛拿西做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 62:4; 历代志下 32:33–9; 马太福音 1:10"> 玛拿西十二岁登基，在耶路撒冷执政五十五年。他母亲叫谢西巴。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:31; 历代志下 36:14; 历代志下 33:2–4"> 他做耶和华视为恶的事，效法耶和华在以色列人面前赶走的外族人的可憎行径。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:4; 列王纪下 17:16; 申命记 17:3"> 他重建他父亲希西迦拆毁的丘坛，效法以色列王亚哈为巴力筑造祭坛，制造亚舍拉神像，并祭拜和供奉天上的万象。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:29; 撒母耳记下 7:13; 耶利米书 32:34"> 耶和华曾指着祂的殿说：“我的名必立在耶路撒冷，”他却在耶和华的殿内建造异教的祭坛。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:12; 列王纪下 23:4; 列王纪下 23:12"> 他在耶和华殿的两个院子里为天上万象建造祭坛；</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:17; 利未记 19:31; 利未记 18:21"> 他烧死自己的儿子，献作祭物；他行邪术，占卜，求问灵媒和巫师，做了许多耶和华视为恶的事，惹耶和华发怒。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 7:16; 列王纪上 9:3; 撒母耳记下 7:13"> 他雕刻亚舍拉神像，放在耶和华的殿中。关于这殿，耶和华曾对大卫和他儿子所罗门说：“我从以色列各支派中选择了这殿和耶路撒冷，我的名要永远立在这里。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:28–29; 诗篇 81:11–16"> 只要以色列人谨遵我对他们的一切吩咐和我仆人摩西交给他们的律法，我就不再把他们从我赐给他们祖先的土地上赶走。”</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; 尼希米记 9:26; 列王纪上 14:16"> 可是他们不肯听从。玛拿西诱使他们作恶，比耶和华在以色列人面前所毁灭的各族更严重。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 23:34–37; 历代志下 33:10; 历代志下 36:15"> 于是，耶和华借着祂的仆人——众先知宣告：</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 24:3–4; 列王纪上 21:26; 列王纪下 21:9"> “玛拿西王做的这些可憎之事，比以前住在这里的亚摩利人更严重，使犹大人祭拜偶像，陷入罪中。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 19:3; 撒母耳记上 3:11; 但以理书 9:12"> 所以，以色列的上帝耶和华说，‘我要在耶路撒冷和犹大降下大灾难，凡听见这事的人都必耳鸣。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 7:7–8; 耶利米哀歌 2:8; 以赛亚书 34:11"> 我要像惩罚撒玛利亚和亚哈家一样惩罚耶路撒冷。我要洁净耶路撒冷，就像人擦净盘子后倒扣过来。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:33; 列王纪下 19:4; 诗篇 89:38–45"> 我要撇弃我剩余的子民，把他们交给敌人，任其掳掠。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 20:30; 申命记 31:27; 以西结书 20:21"> 因为从他们祖先离开埃及那天起直到今天，他们一直做我视为恶的事，惹我发怒。’”</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 35:33; 历代志下 33:9; 列王纪下 21:11"> 玛拿西不仅使犹大人犯罪，做耶和华视为恶的事，还滥杀无辜，使耶路撒冷血流遍地。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 20:20–21; 历代志下 33:1–20"> 玛拿西其他的事及一切所为，包括他犯的罪，都记在《犹大列王史》上。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:20; 列王纪下 21:26; 历代志下 32:33"> 他与祖先同眠后，葬在他王宫的花园，即乌撒花园。他儿子亚们继位。</span>
</div>
</div>

## 亚们做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 33:21–23; 列王纪上 22:51; 历代志上 3:14"> 亚们二十二岁登基，在耶路撒冷执政两年。他母亲叫米舒利密，是约提巴人哈鲁斯的女儿。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 23:32; 列王纪下 21:11; 使徒行传 7:51"> 他像他父亲玛拿西一样做耶和华视为恶的事，</span>
<span className="v" id="v21" data-v="21"> 步他父亲的后尘，祭拜和供奉同样的偶像。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 22:17; 列王纪上 11:33; 历代志上 28:9"> 他背弃他祖先的上帝耶和华，没有遵行耶和华的教导。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:20; 列王纪下 14:19; 历代志下 33:24–25"> 他的臣仆谋反，在王宫里杀了他。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 14:5; 列王纪下 11:17; 列王纪下 14:21"> 民众杀死那些背叛亚们王的人，让他儿子约西亚接续他做王。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 20:20; 列王纪下 21:17"> 亚们其他的事都记在《犹大列王史》上。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:18; 马太福音 1:10; 列王纪上 13:5"> 他葬在乌撒花园内他的坟墓里，他儿子约西亚继位。</span>
</div>
</div>

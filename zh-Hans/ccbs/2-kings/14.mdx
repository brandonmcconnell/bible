## 亚玛谢做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 13:10; 历代志下 25:1–4; 列王纪下 14:15"> 约哈斯的儿子以色列王约阿施执政第二年，犹大王约阿施的儿子亚玛谢登基。</span>
<span className="v" id="v2" data-v="2"> 他二十五岁登基，在耶路撒冷执政二十九年。他母亲叫约耶但，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 25:2–3; 撒迦利亚书 1:4–6; 列王纪上 11:4"> 亚玛谢做耶和华视为正的事，虽不如他祖先大卫，但事事效法他父亲约阿施。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 12:3; 列王纪下 16:4; 列王纪下 15:35"> 然而，他没有拆除丘坛，人们仍在那里献祭烧香。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:3–4; 列王纪下 12:20–21; 民数记 35:33"> 他巩固王位后，立即处死了杀他父王的臣仆，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 24:16; 以西结书 18:20; 以西结书 18:4"> 但没有处死他们的孩子，好遵行耶和华在摩西律法书中的吩咐：“不可因孩子犯罪而处死父亲，也不可因父亲犯罪而处死孩子。各人要自负罪责。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记24:16。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 8:13; 历代志上 18:12; 约书亚记 15:38"> 亚玛谢曾在盐谷杀了一万以东人，攻占了西拉，把西拉改名为约帖，沿用至今。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 25:17–24; 撒母耳记下 2:14–17; 列王纪下 14:11"> 后来，亚玛谢差遣使者对耶户的孙子、约哈斯的儿子、以色列王约阿施说：“来，我们战场上见。”</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 9:8–15; 列王纪上 4:33; 历代志下 33:11"> 以色列王约阿施派人回复犹大王亚玛谢说：“黎巴嫩的蒺藜派使者去对黎巴嫩的香柏树说，‘将你女儿嫁给我儿子吧。’后来黎巴嫩的一只野兽经过，把那蒺藜践踏在脚下。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 26:16; 申命记 8:14; 历代志下 32:25"> 你打败了以东人就趾高气扬，还是待在家里庆祝胜利吧，何必惹祸上身，使你和犹大一同灭亡呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 19:38; 历代志下 25:16; 约书亚记 15:10"> 但亚玛谢不理会他的劝告。于是，以色列王约阿施起兵攻打犹大王亚玛谢，两王会战于犹大的伯·示麦。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 18:17; 撒母耳记上 4:10; 列王纪上 22:36"> 犹大人被以色列人打败，兵将都各自逃回家去了。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 8:16; 尼希米记 12:39; 撒迦利亚书 14:10"> 以色列王约阿施在伯·示麦擒获亚哈谢的孙子、约阿施的儿子犹大王亚玛谢，然后前往耶路撒冷，拆毁从以法莲门到角门约一百八十米长的耶路撒冷城墙，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:26; 列王纪上 7:51; 列王纪上 15:18"> 抢走耶和华殿里和王宫库房里的所有金银和器皿，并带着人质返回撒玛利亚。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:12–13; 列王纪上 14:19–20; 列王纪下 10:34–35"> 约阿施其他的事和功业，包括他英勇对抗犹大王亚玛谢的事迹，都记在《以色列列王史》上。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 13:9; 列王纪下 13:13; 列王纪上 1:21"> 约阿施与祖先同眠后，葬在撒玛利亚的以色列王陵。他儿子耶罗波安继位。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 25:25–28; 列王纪下 13:10; 列王纪下 14:23"> 约哈斯的儿子以色列王约阿施死后，约阿施的儿子犹大王亚玛谢又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪下 13:8"> 亚玛谢其他的事都记在《犹大列王史》上。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 10:31; 列王纪下 15:25; 列王纪下 12:20–21"> 耶路撒冷有人谋反，亚玛谢就逃到拉吉，但叛党派人追到那里杀了他。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 9:28; 列王纪下 12:21; 历代志下 33:20"> 有人用马将他的尸体驮回耶路撒冷，葬在大卫城他的祖坟里。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 21:24; 马太福音 1:8–9; 列王纪下 15:13"> 犹大民众拥立亚玛谢十六岁的儿子亚撒利雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“亚撒利雅”即乌西雅。">b</a></sup>为王。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 16:6; 列王纪上 9:26; 申命记 2:8"> 亚玛谢与祖先同眠后，亚撒利雅为犹大收回了以拉他，并重新修建。</span>
</div>
</div>

## 耶罗波安二世

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿书 1:1; 阿摩司书 7:9–11; 阿摩司书 1:1"> 约阿施的儿子犹大王亚玛谢执政第十五年，以色列王约阿施的儿子耶罗波安在撒玛利亚登基，执政四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 13:6; 列王纪下 13:11; 创世记 38:7"> 他做耶和华视为恶的事，没有离开尼八的儿子耶罗波安使以色列人犯的那些罪。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 3:17; 马太福音 12:39–40; 约书亚记 19:13"> 他收复了从哈马口到死海<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“死海”希伯来文是“亚拉巴海”。">c</a></sup>一带的以色列边境，正如以色列的上帝耶和华借祂仆人迦特希弗人亚米太的儿子约拿先知所言。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:36; 出埃及记 3:7; 列王纪下 13:4"> 因为耶和华看见以色列人，无论自由人还是奴隶都十分痛苦，没有人帮助他们。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 13:23; 列王纪下 13:5; 罗马书 11:2–12"> 耶和华没有说要从世上抹去以色列的名，因此祂借着约阿施的儿子耶罗波安拯救他们。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 11:24; 历代志上 18:5–6; 撒母耳记下 8:6"> 耶罗波安其他的事及一切所为和功业，包括他英勇收复大马士革和一度属犹大国的哈马的事迹，都记在《以色列列王史》上。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 15:8"> 耶罗波安与祖先——以色列的先王们同眠后，他儿子撒迦利雅继位。</span>
</div>

## 耶和华责备亚哈谢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 8:2; 民数记 24:7; 列王纪下 3:4–5"> 亚哈死后，摩押背叛以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 1:16; 马太福音 10:25; 马可福音 3:22"> 一天，亚哈谢从撒玛利亚王宫的楼台上掉下来，受了伤，就派使者去求问以革伦的神明巴力·西卜，看自己能否痊愈。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 17:1; 约拿书 2:8; 使徒行传 12:7–11"> 耶和华的天使对提斯比人以利亚说：“你去截住撒玛利亚王的使者，对他们说，‘你们去求问以革伦的神明巴力·西卜，是因为以色列没有上帝吗？’</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 3:4; 创世记 2:17; 以西结书 18:4"> 因此耶和华对王说，‘你再也不能下床了，你必定死。’”以利亚就去了。</span>
<span className="v" id="v5" data-v="5"> 王的使者回去见王。王问他们：“你们为什么回来了？”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 16:4; 历代志上 10:13–14; 以赛亚书 41:22–23"> 他们答道：“有一个人在路上截住我们，要我们回来告诉你，耶和华对你说，‘你差人去求问以革伦的神明巴力·西卜，是因为以色列没有上帝吗？因此，你再也不能下床了，你必定死。’”</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 28:14; 士师记 8:18"> 王又问他们：“在路上截住你们、对你们说这些话的，是什么样的人？”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 3:4; 撒迦利亚书 13:4; 马可福音 1:6"> 他们答道：“那人身穿毛皮衣服，腰束皮带。”王说：“他是提斯比人以利亚。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 6:13–14; 路加福音 6:11–12; 希伯来书 11:36"> 于是，王派一个五十夫长率领五十人去见以利亚。那时，以利亚正坐在山顶上。五十夫长到了那里，对他说：“上帝的仆人啊，王命令你下来。”</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:54; 但以理书 3:25; 列王纪上 18:36–38"> 以利亚说：“我若是上帝的仆人，愿火从天降下烧死你和你的五十个部下。”火立刻从天降下，烧死了五十夫长和他的五十个部下。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 2:16; 路加福音 22:63–64; 耶利米书 5:3"> 亚哈谢王又派一个五十夫长率领五十人去以利亚那里，五十夫长对以利亚说：“上帝的仆人啊，王命令你马上下来。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 1:9–10"> 以利亚说：“我若是上帝的仆人，愿火从天降下，烧死你和你的五十个部下。”上帝的火从天降下，烧死了五十夫长和他的五十个部下。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:5; 撒母耳记上 26:21; 传道书 9:3"> 王再次派一个五十夫长率领五十人前去。五十夫长上去，双膝跪在以利亚面前，哀求道：“上帝的仆人啊，求你饶了我和你的五十名仆人的性命。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 20:24; 诗篇 49:8; 箴言 6:26"> 前两个五十夫长和他们的部下都被天上降下的火烧死了，现在求你饶我一命！”</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 51:12; 以西结书 2:6; 耶利米书 1:17"> 耶和华的天使对以利亚说：“不要害怕，跟他去吧！”以利亚就起来跟他去见王。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 1:2–4; 列王纪上 22:28; 出埃及记 4:22–23"> 以利亚对王说：“耶和华说，‘你派使者去求问以革伦的神明巴力·西卜，是因为以色列没有上帝可以求问吗？因此，你再也不能下床了，你必定死。’”</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 3:1; 列王纪上 22:51; 列王纪下 8:16–17"> 亚哈谢果然死了，正如耶和华借以利亚所说的。他没有儿子，他兄弟约兰继位，那年是犹大王约沙法的儿子约兰执政第二年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 22:39; 列王纪上 14:19"> 亚哈谢其他的事都记在《以色列列王史》上。</span>

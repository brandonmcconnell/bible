## 希西迦向以赛亚求助

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 21:27; 列王纪下 18:37; 历代志下 32:20–22"> 希西迦王听后就撕裂衣服，披上麻衣，进入耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:1; 以赛亚书 2:1; 马太福音 4:14"> 他派身披麻衣的宫廷总管以利亚敬、书记舍伯那和祭司中的长者，去见亚摩斯的儿子以赛亚先知，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 30:5–7; 以赛亚书 66:9; 何西阿书 13:13"> 对他说：“希西迦说，‘今天是遭难、蒙羞、受辱的日子，就像婴儿要出生，产妇却无力生产一样。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 16:12; 罗马书 9:27; 约书亚记 14:12"> 亚述王派他的将军来辱骂永活的上帝，也许你的上帝耶和华听见那些话，就会惩罚他。因此，请你为我们这些剩下的人祷告。’”</span>
<span className="v" id="v5" data-v="5"> 希西迦王的臣仆前来见以赛亚，</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 18:35; 列王纪下 18:17; 以赛亚书 37:6–38"> 以赛亚对他们说：“告诉你们主人，耶和华这样说，‘你不要因为听到亚述王的仆人那些亵渎我的话而害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="俄巴底亚书 1:1; 列王纪下 7:6; 诗篇 18:14–15"> 我必惊动<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“惊动”希伯来文是“使灵进入”。">a</a></sup>亚述王的心，让他听见一些风声后便返回本国，使他在那里死于刀下。’”</span>
</div>
</div>

## 希西迦向上帝祷告

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 18:14; 约书亚记 10:29; 约书亚记 12:11"> 亚述的将军听说亚述王已经离开拉吉，便回去见王，发现王在攻打立拿。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 23:27; 以赛亚书 37:9; 列王纪下 18:17"> 亚述王听说古实王特哈加来攻打他，便再次派使者去见希西迦，说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:5; 列王纪下 18:29–30; 历代志下 32:15–19"> “不要让你所倚靠的上帝愚弄你，说什么耶路撒冷必不会落在亚述王手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 10:8–11; 历代志下 32:13–14; 列王纪下 19:17–18"> 你肯定听过亚述诸王扫灭列国的事，难道你能幸免吗？</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 17:6; 创世记 11:31; 以西结书 27:23"> 我先祖毁灭了歌散、哈兰、利色和提·拉撒的伊甸，这些国家的神明救得了他们吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:34; 列王纪下 17:24; 以赛亚书 11:11"> 哈马王、亚珥拔王、西法瓦音王、希拿王和以瓦王如今在哪里呢？”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 37:14; 诗篇 91:1–2; 诗篇 123:1–4"> 希西迦从使者手中接过信，读完后上到耶和华的殿，在耶和华面前展开信，</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 44:6; 列王纪下 5:15; 但以理书 4:34–35"> 祷告说：“坐在基路伯天使之上、以色列的上帝耶和华啊，唯有你是天下万国的上帝，你创造了天地。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 6:40; 诗篇 31:2; 列王纪下 19:4"> 耶和华啊，求你侧耳垂听！耶和华啊，求你睁眼察看！求你听听西拿基立派人来辱骂永活上帝的话。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 5:26; 约伯记 9:2; 哥林多前书 14:25"> 耶和华啊，亚述诸王确实扫灭列国，使他们的土地荒凉，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 17:29; 以赛亚书 44:9–20; 耶利米书 10:3–9"> 把他们的神像扔进火中烧毁。因为那些神像只是人用木头石头制造的，根本不是神明。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 83:18; 列王纪上 8:43; 诗篇 67:1–2"> 我们的上帝耶和华啊，现在求你从亚述王手中拯救我们，让天下万国都知道唯有你耶和华是上帝。”</span>
</div>
</div>

## 以赛亚给希西迦的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 20:5; 历代志下 32:20–21; 耶利米书 33:3"> 亚摩斯的儿子以赛亚派人对希西迦说：“以色列的上帝耶和华说，‘我已经听见你关于亚述王西拿基立的祷告。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米哀歌 2:13; 约伯记 16:4; 耶利米书 14:17"> 以下是耶和华对他的判语，<br /><span className="pl pl-1">“‘处女锡安藐视你，嘲笑你；</span><br /><span className="pl pl-1">少女耶路撒冷朝你的背影摇头。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:24; 诗篇 71:22; 以赛亚书 30:11–12"> <span className="pl pl-1">你侮辱、亵渎谁呢？</span><br /><span className="pl pl-1">你高声谩骂、傲眼蔑视谁呢？</span><br /><span className="pl pl-1">是以色列的圣者！</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 18:17; 诗篇 20:7; 以赛亚书 10:18"> <span className="pl pl-1">你借你的使者辱骂主，</span><br /><span className="pl pl-1">你说你率领许多战车上到高山，</span><br /><span className="pl pl-1">上到黎巴嫩的顶峰，</span><br /><span className="pl pl-1">砍下最高的香柏树和上好的松树，</span><br /><span className="pl pl-1">征服最高的山和最美的树林。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 19:6; 出埃及记 15:9; 撒母耳记下 17:13"> <span className="pl pl-1">你说你已在外邦之地挖井取水，</span><br /><span className="pl pl-1">已用脚掌踏干埃及所有的河流。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:7; 以赛亚书 10:5–6; 以赛亚书 37:26–27"> <span className="pl pl-1">“‘难道你没有听过这是我起初所定、</span><br /><span className="pl pl-1">亘古筹划的吗？</span><br /><span className="pl pl-1">如今我实现了所定的计划：</span><br /><span className="pl pl-1">借着你使坚城沦为废墟。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 51:30; 诗篇 102:11; 耶利米书 51:32"> <span className="pl pl-1">城中的居民软弱无力，</span><br /><span className="pl pl-1">惊慌失措，羞愧难当，</span><br /><span className="pl pl-1">脆弱如野草和菜蔬，</span><br /><span className="pl pl-1">又像还未长大就被晒焦的房顶草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 37:28–29; 耶利米书 23:23–24; 诗篇 139:1–11"> <span className="pl pl-1">“‘你起你坐，你出你进，</span><br /><span className="pl pl-1">你向我发怒，我都知道。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 29:4; 以西结书 38:4; 列王纪下 19:33"> <span className="pl pl-1">因为你向我发怒，</span><br /><span className="pl pl-1">你狂傲的话传到了我耳中，</span><br /><span className="pl pl-1">我要用钩子钩住你的鼻子，</span><br /><span className="pl pl-1">把嚼环放在你嘴里，</span><br /><span className="pl pl-1">使你原路返回。’</span></span>
<span className="v" id="v29" data-v="29" data-xref="利未记 25:20–22; 列王纪下 20:8–9; 出埃及记 3:12"> “希西迦啊，我要给你一个兆头，你们今年要吃野生的，明年要吃自然生长的，后年要播种收割，栽种葡萄园，吃园中的果子。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 19:4; 以赛亚书 27:6; 历代志下 32:22–23"> 犹大的幸存者要再次向下扎根，向上结果。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 9:7; 罗马书 11:5; 罗马书 9:27"> 因为将有余民从耶路撒冷出来，有幸存者从锡安山出来。万军之耶和华必热切地成就这事。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 8:7–10; 撒母耳记下 20:15; 以赛亚书 37:33–35"> “至于亚述王，耶和华说，‘他必不能进这城或向这里射一箭，必不能手持盾牌兵临城下或修筑攻城的高台。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:28; 列王纪下 19:36"> 他必原路返回，不得进入这城。这是耶和华说的。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪下 20:6; 列王纪上 15:4"> 我必为自己和我仆人大卫的缘故而保护、拯救这城。’”</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 32:21–22; 撒母耳记下 24:16; 出埃及记 12:29–30"> 当晚，耶和华的天使到亚述营中杀了十八万五千人。人们清早起来，发现到处都是尸体。</span>
<span className="v" id="v36" data-v="36" data-xref="约拿书 1:2; 列王纪下 19:7; 列王纪下 19:33"> 亚述王西拿基立便拔营回国，住在尼尼微。</span>
<span className="v" id="v37" data-v="37" data-xref="以斯拉记 4:2; 创世记 8:4; 列王纪下 19:7"> 一天，亚述王在庙里祭拜他的神明尼斯洛时，他的儿子亚得米勒和沙利色用刀杀了他，逃往亚拉腊。他儿子以撒哈顿继位。</span>
</div>

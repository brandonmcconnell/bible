<span className="v" id="v2" data-v="2"> 城一直被围困到西底迦王执政第十一年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 52:6; 以西结书 5:12; 耶利米书 38:2"> 那年四月九日，城里饥荒非常严重，百姓无粮可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 33:21; 列王纪下 25:5; 耶利米书 39:2–7"> 城被攻破，城里的所有士兵便在夜间从两城墙中间、靠近御花园的门逃往亚拉巴。当时迦勒底人仍四面包围着城。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 30:16; 耶利米书 39:5; 阿摩司书 2:14–16"> 迦勒底军队追赶西底迦，在耶利哥平原追上了他，他的军队都四散而逃。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 23:33; 耶利米书 34:21–22; 耶利米书 21:7"> 迦勒底人擒住西底迦，把他押到利比拉见巴比伦王，在那里审判他。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 32:4–5; 士师记 16:21; 耶利米书 39:6–7"> 巴比伦王当着西底迦的面杀了他的众子，又剜去他的双眼，把他用铜链锁着押往巴比伦。</span>
</div>

## 圣殿被毁

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 52:12–16; 耶利米书 40:1–4; 耶利米哀歌 4:12"> 巴比伦王尼布甲尼撒执政第十九年五月七日，他的臣仆护卫长尼布撒拉旦来到耶路撒冷，</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 2:5; 诗篇 74:3–7; 列王纪上 9:8"> 放火焚烧耶和华的殿、王宫及耶路撒冷所有的房屋。他烧毁了所有重要建筑。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 1:3; 耶利米书 39:8; 耶利米书 52:14–23"> 他率领的迦勒底军队拆毁了耶路撒冷四围的城墙。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 5:2; 耶利米书 15:1–2; 耶利米书 39:9"> 护卫长尼布撒拉旦掳去城里剩下的百姓、投降巴比伦王的人以及其他人，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 40:7; 列王纪下 24:14; 以西结书 33:24"> 只留下一些最贫穷的人，让他们照料葡萄园、耕种田地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 36:18; 耶利米哀歌 1:10; 列王纪下 20:17"> 迦勒底人打碎耶和华殿中的铜柱、铜底座和铜海，把铜运往巴比伦，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:3; 列王纪上 7:47–50; 出埃及记 38:3"> 并带走了盆、铲、灯剪、碟子及一切献祭用的铜器。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:2–3; 民数记 7:13–14; 列王纪上 7:48–51"> 护卫长还带走了火鼎、碗等一切金银器具。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:47"> 所罗门为耶和华的殿所造的两根铜柱、一个铜海和一些铜底座，用的铜多得无法计算。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:15–22; 耶利米书 52:21–23"> 铜柱高八米，铜柱有柱冠，高一米半。柱冠周围装饰着铜网和铜石榴。两根柱子都一样。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 29:25; 以斯拉记 7:1; 耶利米书 21:1"> 护卫长尼布撒拉旦掳走祭司长西莱雅、副祭司长西番亚和三名殿门守卫，</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖记 1:14"> 还从城中掳走一名统管士兵的将领、王的五个亲信、一名负责招兵的书记和六十名平民。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 4:16; 耶利米书 52:26–27; 列王纪下 23:33"> 护卫长尼布撒拉旦把他们带到利比拉去见巴比伦王，</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 28:64; 列王纪下 23:27; 申命记 4:26"> 巴比伦王在那里处死了他们。犹大人就这样被掳去，离开了家园。</span>
</div>
</div>

## 基大利做犹大省长

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 39:14; 列王纪下 22:12; 耶利米书 41:2"> 巴比伦王尼布甲尼撒委任沙番的孙子、亚希甘的儿子基大利治理犹大的余民。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 40:7–9; 耶利米书 40:11–12; 约书亚记 18:26"> 犹大众将领和他们的下属听到巴比伦王委任基大利治理犹大的消息后，便来到米斯巴见基大利。他们是尼探雅的儿子以实玛利、加利亚的儿子约哈难、尼陀法人单户篾的儿子西莱雅、玛迦人雅撒尼亚。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 40:9–10; 耶利米书 43:6; 撒母耳记下 19:23"> 基大利对他们和他们的下属起誓说：“你们不要害怕那些迦勒底官员，只管住在此地臣服于巴比伦王，你们会平安无事。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒迦利亚书 7:5; 撒迦利亚书 8:19; 耶利米书 40:15"> 七月，王室后裔以利沙玛的孙子、尼探雅的儿子以实玛利带着十个人在米斯巴刺杀了基大利以及跟他一起的犹大人和迦勒底人。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 43:4–7; 耶利米书 41:16–18; 耶利米书 42:14–22"> 因为害怕迦勒底人报复，犹大众人不论贵贱，都和众将领一起逃往埃及。</span>
</div>
</div>

## 约雅斤获释

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 52:31–34; 创世记 40:20; 创世记 40:13"> 巴比伦王以未·米罗达在他执政的元年十二月二十七日，即犹大王约雅斤被掳后第三十七年，施恩释放了约雅斤，</span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 2:37; 耶利米书 27:6–11; 但以理书 5:18–19"> 并好言相待，使他的地位高过被掳到巴比伦的其他各王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 9:7; 以赛亚书 61:3; 创世记 41:42"> 约雅斤脱去了囚服，终生与巴比伦王一起吃饭。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 11:3; 马太福音 6:11; 尼希米记 11:23"> 在他有生之年，巴比伦王供应他每天的需用。</span>
</div>
</div>

## 亚哈斯做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 1:1; 以赛亚书 7:1; 列王纪下 15:38"> 利玛利的儿子比加执政第十七年，犹大王约坦的儿子亚哈斯登基。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:1–4; 列王纪下 15:34; 列王纪上 11:4–8"> 他二十岁登基，在耶路撒冷执政十六年。他没有效法他祖先大卫做耶和华视为正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 12:31; 利未记 18:21; 列王纪下 21:2"> 反而步以色列诸王的后尘，效法耶和华在以色列人面前赶走的外族人的可憎行径，把自己的儿子焚烧献作祭物。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:2; 列王纪上 14:23; 耶利米书 17:2"> 他还在丘坛、山冈和绿树下献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 15:37; 以赛亚书 9:6–7; 以赛亚书 8:9–10"> 亚兰王利汛和利玛利的儿子以色列王比加前来攻打耶路撒冷，围住亚哈斯，但屡攻不下。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 14:22; 申命记 2:8; 列王纪上 9:26"> 当时，亚兰王利汛收复以拉他，赶走城内的犹大人。亚兰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚兰”有古卷作“以东”。">a</a></sup>人至今居住在那里。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 15:29; 耶利米哀歌 4:17; 何西阿书 14:3"> 亚哈斯差遣使者去见亚述王提革拉·毗列色，对他说：“我是你的仆人、你的儿子，现在亚兰王和以色列王攻打我，求你从他们手中拯救我。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 12:17–18; 历代志下 28:20–21; 历代志下 16:2"> 亚哈斯把耶和华殿里和王宫库房里所有的金银送给亚述王。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 9:7; 以赛亚书 22:6; 阿摩司书 1:3–5"> 亚述王答应了他，起兵攻陷大马士革，杀了利汛，把城中的居民掳到吉珥。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 以西结书 23:16–17; 以赛亚书 8:2"> 亚哈斯王在大马士革见亚述王提革拉·毗列色的时候，看到一座坛，便派人将坛的模型和详细的制造方法送到乌利亚祭司那里。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿书 4:6; 历代志下 26:17–18; 何西阿书 5:11"> 乌利亚祭司按照送来的模型，在亚哈斯王从大马士革返回之前建造了一座坛。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 26:16–19; 历代志下 28:25; 列王纪上 13:1"> 王从大马士革回来，看见那座坛，就到上面献祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 1:1–3"> 他在上面献上燔祭、素祭和奠祭，又将平安祭祭牲的血洒在坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:1; 出埃及记 40:6; 出埃及记 40:29"> 他把献给耶和华的铜坛从耶和华的殿前搬到新坛的北边，铜坛原来放在殿和新坛之间。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:39–41; 列王纪上 8:64; 历代志下 29:21–24"> 他吩咐乌利亚祭司：“要在这座大坛上献早晨的燔祭、晚上的素祭，王的燔祭、素祭，国中民众的燔祭、素祭和奠祭，燔祭牲和平安祭牲的血也要洒在上面，但铜坛要供我个人求问之用。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 4:19; 使徒行传 5:29; 犹大书 1:11"> 乌利亚祭司遵命而行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 4:14–15; 耶利米书 52:20; 历代志下 28:24"> 亚哈斯王拆掉盆座的镶板，搬走盆，将铜海从铜牛背上搬下来，放在铺石的地上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 11:5; 列王纪上 10:5; 以西结书 46:2"> 为讨好亚述王，他挪走耶和华殿里为安息日而盖的走廊，封闭了王从外面进耶和华殿的入口。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪下 15:36; 历代志下 28:26; 列王纪下 20:20–21"> 亚哈斯其他的事都记在《犹大列王史》上。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:9; 以赛亚书 1:1; 历代志上 3:13"> 亚哈斯与祖先同眠后，葬在大卫城他的祖坟里。他儿子希西迦继位。</span>
</div>
</div>

## 希西迦做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 28:27–1; 马太福音 1:9–10; 历代志上 3:13"> 以拉的儿子以色列王何细亚执政第三年，犹大王亚哈斯的儿子希西迦登基。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:1–2"> 他二十五岁登基，在耶路撒冷执政二十九年。他母亲叫亚比雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚比雅”此处的希伯来文为亚比，是亚比雅的变体。">a</a></sup>，是撒迦利雅的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 20:3; 列王纪上 11:4; 历代志下 31:20–21"> 希西迦事事效法他祖先大卫，做耶和华视为正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 31:1; 民数记 21:8–9; 列王纪下 18:22"> 他拆除丘坛，砸碎神柱，砍倒亚舍拉神像，打碎摩西造的铜蛇，因为当时以色列人仍向铜蛇烧香，称之为尼忽士旦<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“尼忽士旦”可能是“蛇”和“铜”的组合词。">b</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:25; 列王纪下 19:10; 马太福音 27:43"> 希西迦信靠以色列的上帝耶和华，在他前后的犹大诸王没有一个可与他相比。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 23:8; 申命记 10:20; 约翰福音 14:15"> 他对耶和华忠心不渝，遵守耶和华颁给摩西的诫命。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:31; 创世记 39:2–3; 列王纪下 16:7"> 耶和华与他同在，他凡事顺利。他反抗亚述王的统治，不再臣服于他。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 14:29; 列王纪下 17:9; 历代志下 28:18"> 他击败非利士人，从他们的瞭望塔到坚城，一直打到迦萨及其四境。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿书 10:14; 列王纪下 17:3–23; 列王纪下 18:1"> 希西迦执政第四年，即以拉的儿子以色列王何细亚执政第七年，亚述王撒缦以色起兵攻打撒玛利亚，将城包围。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 6:7; 阿摩司书 9:1–4; 弥迦书 1:6–9"> 三年之后，就是希西迦执政第六年，以色列王何细亚执政第九年，撒玛利亚失陷。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 5:26; 列王纪下 17:6; 以赛亚书 37:12"> 亚述王把以色列人掳到亚述，将他们安置在哈腊、歌散的哈博河一带以及玛代人的城邑里。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:17; 彼得前书 2:8; 弥迦书 3:4"> 这都是因为以色列人没有听从他们的上帝耶和华，违背了祂的约，不遵行祂仆人摩西所吩咐的一切。</span>
</div>
</div>

## 亚述人攻打耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 36:1–22; 历代志下 32:1–23; 以赛亚书 7:17–25"> 希西迦王执政第十四年，亚述王西拿基立起兵攻取了犹大所有的坚城。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:7; 路加福音 14:32; 列王纪上 20:4"> 犹大王希西迦差遣使者去拉吉见亚述王说：“我错了，求你退兵！我愿意满足你的任何要求。”亚述王向希西迦索要二十万两银子和两万两金子。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 16:8; 列王纪上 15:18–19; 列王纪下 12:18"> 希西迦将耶和华殿里和王宫库房里的所有银子都给了他，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:3; 列王纪上 6:31–35"> 又刮下他包在耶和华殿门和门柱上的金子，一并送给亚述王。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 20:1; 列王纪下 20:20; 以赛亚书 7:3"> 但亚述王派他的元帅、都统和将军从拉吉率领大军到耶路撒冷的希西迦王那里。到了耶路撒冷后，他们驻扎在上池的水沟旁、通往漂布场的路上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 19:2; 以赛亚书 36:3; 撒母耳记下 8:16–17"> 他们要求见王。希勒迦的儿子宫廷总管以利亚敬、书记舍伯那和亚萨的儿子史官约亚出来见他们。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:4; 列王纪下 19:10; 以赛亚书 10:8–14"> 亚述的将军对他们说：“你们去告诉希西迦，伟大的亚述王说，‘你凭什么这样自信呢？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你所谓的战略和军力不过是空话。你究竟倚靠谁，竟敢背叛我？</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 30:7; 以西结书 29:6–7; 以赛亚书 30:2–3"> 看啊，你所倚靠的埃及不过是一根破裂的芦苇杖，倚靠它的必被刺破手。倚靠埃及王法老的下场都是这样。’</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:1; 列王纪下 18:4–5; 马太福音 27:43"> 也许你们会说，‘我们倚靠我们的上帝耶和华。’希西迦不是拆除了祂的丘坛和祭坛，又吩咐犹大和耶路撒冷的人必须在耶路撒冷的这座祭坛前敬拜吗？</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:42; 列王纪上 20:10; 尼希米记 4:2–5"> 来，跟我主人亚述王打个赌，你若能找到两千骑士，我就给你两千匹马！</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 10:8; 申命记 17:16; 以赛亚书 36:6"> 你们即使依靠埃及的战车和骑兵，又怎能打败我主人的一个最小的将领呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 19:6; 以赛亚书 10:5–6; 列王纪下 19:22–37"> 更何况我来攻打、毁灭这地方，不正是耶和华的意思吗？耶和华吩咐我攻打、毁灭这地方。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 4:7; 但以理书 2:4; 以赛亚书 36:11–12"> 以利亚敬、舍伯那和约亚对亚述的将军说：“求你用亚兰语跟仆人们说话，我们都听得懂。求你不要用犹大话跟我们说话，免得城墙上的人听见。”</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 73:8; 耶利米哀歌 4:5; 以西结书 4:15"> 亚述的将军却说：“难道我主人派我来只对你们和你们的主人说这些话吗？不也是对坐在城墙上的人说吗？他们和你们一样都要吃自己的粪，喝自己的尿。”</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 36:13–18; 以赛亚书 10:8–13; 以西结书 29:3"> 于是，他站着用犹大话大喊：“你们要听伟大的亚述王的话。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 32:15; 帖撒罗尼迦后书 2:8; 历代志下 32:11"> 王说，‘你们不要被希西迦欺骗，他不能从我手中救你们。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 125:1–2; 路加福音 23:35; 列王纪下 19:32–34"> 不要听希西迦的话去倚靠耶和华，说什么耶和华必拯救你们，这城必不会落在亚述王手中。’</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 4:25; 列王纪上 4:20; 撒迦利亚书 3:10"> 不要听希西迦的话。亚述王说，‘你们要跟我讲和，出来归顺我，这样就可以吃自己葡萄树和无花果树的果子，喝自己井里的水。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 8:7–9; 出埃及记 3:8; 申命记 11:12"> 以后我会来领你们到一个地方，那里和这里一样有五谷和新酒、饼和葡萄园、橄榄树和蜂蜜，好让你们存活，不至于死。希西迦说耶和华必拯救你们，不要听信他的话，他在哄骗你们。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 10:10–11; 列王纪下 19:12–13; 历代志下 32:19"> 列国有哪个神明从亚述王手中救了它的国家呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 10:9; 列王纪下 17:23–33; 耶利米书 49:23"> 哈马和亚珥拔的神明在哪里呢？西法瓦音、希拿和以瓦的神明在哪里呢？它们从我手中救撒玛利亚了吗？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理书 3:15; 以赛亚书 10:15; 出埃及记 5:2"> 这些国家有哪个神明从我手中救了它的国家呢？难道耶和华能从我手中救耶路撒冷吗？’”</span>
<span className="v" id="v36" data-v="36" data-xref="阿摩司书 5:13; 箴言 9:7; 马太福音 7:6"> 民众默不作声，一言不发，因为希西迦王曾吩咐他们不要答话。</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 22:11; 创世记 37:29; 列王纪下 5:7"> 这时，管希勒家的儿子宫廷总以利亚敬、书记舍伯那和亚萨的儿子史官约亚都撕裂衣服去见希西迦，把亚述将军的话回禀他。</span>
</div>
</div>

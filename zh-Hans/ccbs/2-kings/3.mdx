## 以色列与摩押争战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 1:17; 列王纪上 22:51; 列王纪下 8:16"> 犹大王约沙法执政第十八年，亚哈的儿子约兰在撒玛利亚登基做以色列王，执政十二年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 10:18; 列王纪下 10:26–28; 列王纪上 21:25"> 他做耶和华视为恶的事，不过没有他父母那么败坏，因为他除掉了他父亲立的巴力神柱。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪下 15:18"> 可是他沉溺于尼八的儿子耶罗波安所犯的罪恶，使以色列人陷入罪中。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 8:2; 创世记 26:13–14; 约伯记 1:3"> 摩押王米沙以牧羊为业，每年向以色列王进贡十万只公绵羊的羊毛和十万只羊羔。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 1:1; 列王纪下 8:20; 历代志下 21:8–10"> 亚哈死后，米沙背叛了以色列王。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 24:1–25; 撒母耳记上 11:8; 撒母耳记上 15:4"> 那时，约兰王从撒玛利亚出发，召集以色列全军。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 22:4; 历代志下 22:10–12; 历代志下 18:3"> 他还传信给犹大王约沙法，说：“摩押王背叛了我，你愿意和我一起去攻打摩押吗？”约沙法回复说：“我愿意去。你我不分彼此，我的民就是你的民，我的马就是你的马。</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 1:2–3; 民数记 21:4"> 我们从哪一条路进攻呢？”约兰答道：“从以东的旷野。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:47; 民数记 20:2; 出埃及记 17:1"> 于是，以色列王跟犹大王和以东王联合出兵。他们绕道行了七天，军队和随行的牲畜都没有水喝了。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:34–36; 以赛亚书 51:20; 以赛亚书 8:21"> 以色列王叫道：“唉！怎么办呢？耶和华招聚我们三王，是要把我们交给摩押王！”</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 22:7; 列王纪上 19:21; 列王纪下 3:3"> 约沙法说：“这里有没有耶和华的先知？我们可以托他求问耶和华。”以色列王的一个臣仆答道：“沙法的儿子以利沙在这里，以前他是以利亚的助手。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 5:15; 列王纪下 2:21; 以赛亚书 60:14"> 约沙法说：“耶和华会借他说话。”于是以色列王、约沙法和以东王一起去见以利沙。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:6; 列王纪上 18:19; 列王纪上 22:10–11"> 以利沙对以色列王说：“我与你有什么关系？你去问你父母的先知吧！”以色列王说：“不要这样说，耶和华招聚我们三王，是要把我们交给摩押王！”</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 5:16; 列王纪上 17:1; 历代志下 19:3–4"> 以利沙说：“我事奉的是永活的万军之耶和华，我凭祂起誓，若不是看犹大王约沙法的情面，我决不理你，也不会见你。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:23; 以弗所书 5:18–19; 以西结书 1:3"> 现在你们给我找一个琴师来。”琴师弹琴的时候，耶和华的手按在以利沙身上，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 2:16–18; 列王纪下 4:3"> 他就说：“耶和华吩咐你们要在这山谷中到处挖沟，</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 107:35; 以赛亚书 41:17–18; 以赛亚书 48:21"> 因为耶和华说，‘你们虽不见风，也不见雨，但这谷中必到处有水，人畜都会有水喝。’</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 32:27; 路加福音 1:37; 耶利米书 32:17"> 这对耶和华来说是微不足道的事，祂还要把摩押人交在你们手中。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 13:17; 申命记 20:19–20; 士师记 6:16"> 你们必攻陷所有的坚城重镇，砍倒各种佳美的树木，堵塞所有水泉，用石头毁坏一切良田。”</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:39–40; 但以理书 9:21; 列王纪上 18:36"> 次日早晨，约在献祭的时候，水从以东流来，遍地都是水。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 6:14; 列王纪上 20:11"> 摩押人听说三王联军进攻他们，于是把凡能打仗的，不论老少都聚集起来，把守在边界上。</span>
<span className="v" id="v22" data-v="22"> 第二天早晨，日光照在水面上，摩押人起来后，看见对面的水像血一样红，</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 5:30; 出埃及记 15:9; 以赛亚书 10:14"> 便说：“那是血啊！一定是三王内讧，自相残杀。摩押人啊，我们去抢财物吧！”</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:3–4; 约书亚记 8:20–22; 士师记 20:40–46"> 他们到了以色列营，以色列人奋起迎战，杀得他们转身逃跑。以色列人乘胜追击，杀入摩押境内，击杀摩押人，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 16:7; 耶利米书 48:36; 耶利米书 48:31"> 摧毁城邑，人人抛掷石头填满所有良田，堵塞一切水泉，砍倒各种佳美树木。摩押境内仅剩的吉珥·哈列设城也遭到甩石的士兵围攻。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 3:9; 阿摩司书 2:1"> 摩押王见战事不利，就率领七百名刀兵，企图从以东王那边突围，但没有成功。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 6:7; 申命记 12:31; 士师记 11:31"> 于是，他在城上将本应继承自己王位的长子杀掉，献为燔祭。有怒火向以色列人发作，他们便退兵回国了。</span>

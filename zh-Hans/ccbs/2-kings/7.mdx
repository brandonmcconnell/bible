## 撒玛利亚城获救

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 13:45–46; 民数记 5:2–4; 列王纪下 7:4"> 城门口有四个麻风病人，他们商量说：“我们为什么坐在这里等死呢？</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 14:18; 路加福音 15:17–19; 撒母耳记下 14:14"> 如果我们进城，城里正遭遇饥荒，我们会饿死；但我们坐在这里也是死，不如去投靠亚兰军。如果他们不杀我们，我们就能活命；不然的话，死就死吧！”</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 28:7; 申命记 32:25; 撒母耳记上 30:17"> 傍晚时分，他们动身去亚兰人的营地，到了营地外边，却发现人影全无。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 5:24; 以赛亚书 31:1; 列王纪上 10:29"> 原来，主使亚兰人听见大队人马和战车的声音。他们以为以色列王雇用了赫人的诸王和埃及人的诸王来攻营，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 28:1; 诗篇 48:4–6; 希伯来书 6:18"> 便在傍晚时分撇下帐篷、马和驴，弃营而逃。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 13:44; 约书亚记 7:21; 马太福音 25:18"> 那几个麻风病人到了营地，走进一个帐篷，又吃又喝，把那里的金银和衣服拿走收藏起来，再回来进入另一个帐篷，把财物拿走收藏起来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 52:7; 腓立比书 2:4; 那鸿书 1:15"> 后来，他们彼此说：“我们这样做不对。今天是个报好消息的日子，我们却不作声。如果等到天亮，我们会受惩罚的。走，我们给王报信去！”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 7:11; 马可福音 13:34–35; 诗篇 127:1"> 他们就去喊城门守卫，对他们说：“我们到了亚兰人的营中，里面不见人影也没有人声，只有拴着的马和驴，帐篷仍在那里。”</span>
<span className="v" id="v11" data-v="11"> 城门守卫就高声宣告消息，有人去禀告王。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 6:25–29; 约书亚记 8:4"> 王连夜起来，对臣仆说：“我告诉你们是怎么回事。亚兰人知道我们正遭遇饥荒，就故意离开军营，埋伏在田野，等我们以色列人出城后，好活捉我们，并攻入城中。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪下 7:4; 耶利米哀歌 4:9; 列王纪下 5:13"> 一个臣仆说：“不如派人骑着城中仅存的五匹马出去打探一下。反正他们和城中剩下的以色列人一样快要死了。”</span>
<span className="v" id="v14" data-v="14"> 他们预备了两辆马车，王便命人出去追踪亚兰军，查明实情。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 22:24; 马太福音 24:16–18; 希伯来书 12:1"> 探子一路追到约旦河，沿路看见到处都是亚兰军仓皇逃走时丢弃的衣服和装备，便回去禀告王。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 7:1; 以赛亚书 33:4; 以赛亚书 33:23"> 于是，民众出城抢掠亚兰人的营地。那时，三公斤细面粉只卖一两银子，六公斤大麦也只卖一两银子，正如耶和华所言。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 7:2; 列王纪下 6:32; 士师记 20:43"> 王派那位搀扶他的将领守在城门口维持秩序，那将领却被涌出的人群踩死，应验了上帝的仆人在王去见他时所说的话。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 18:14; 列王纪下 7:1–2; 列王纪下 6:32"> 上帝的仆人曾对王说：“明天约这时候，在撒玛利亚城门口，三公斤细面粉只卖一两银子，六公斤大麦也只卖一两银子。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪下 7:2"> 但那将领对上帝的仆人说：“即使耶和华打开天上的窗户，也不可能发生这样的事！”上帝的仆人说：“你必亲眼看见，却吃不到。”</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 17:5–6; 历代志下 20:20; 约伯记 20:23"> 这话果然应验在他身上，他被人群踩死在城门口。</span>
</div>
</div>

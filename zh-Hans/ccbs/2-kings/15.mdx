## 亚撒利雅做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 26:3–4; 列王纪下 14:21; 历代志下 26:1"> 以色列王耶罗波安执政第二十七年，犹大王亚玛谢的儿子亚撒利雅登基。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 26:3–4"> 他十六岁登基，在耶路撒冷执政五十二年。他母亲叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 14:3–4; 列王纪下 12:2–3; 历代志下 26:4"> 他事事效法他父亲亚玛谢，做耶和华视为正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 15:35; 列王纪下 14:4; 列王纪下 12:3"> 但他没有拆除丘坛，人们仍在那里献祭烧香。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 13:46; 民数记 12:14; 列王纪下 7:3"> 耶和华降灾给他，使他患了麻风病，一直到死。他被隔离在别的宫中，他儿子约坦管理王室，治理国家。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 26:5–15; 列王纪下 14:18"> 亚撒利雅其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 26:23; 以赛亚书 6:1"> 亚撒利雅与祖先同眠后，葬在大卫城他的祖坟里。他儿子约坦继位。</span>
</div>
</div>

## 撒迦利雅做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 14:16–17; 列王纪下 14:29–1; 列王纪下 14:21"> 犹大王亚撒利雅执政第三十八年，耶罗波安的儿子撒迦利雅在撒玛利亚登基做以色列王，执政六个月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 14:24; 列王纪下 13:2; 列王纪下 13:11"> 他做耶和华视为恶的事，重蹈祖先的覆辙，没有离开尼八的儿子耶罗波安使以色列人犯的那些罪。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:28; 列王纪下 15:14; 列王纪下 9:24"> 雅比的儿子沙龙谋反，当众杀了撒迦利雅，篡位做了以色列王。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:28"> 撒迦利雅其他的事都记在《以色列列王史》上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 10:30; 马可福音 13:31; 列王纪下 13:13"> 这件事应验了从前耶和华对耶户的应许：“你的子孙必做以色列王，直到第四代。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="参列王纪下10:30。">a</a></sup></span>
</div>
</div>

## 沙龙做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪下 15:1; 马太福音 1:8–9; 列王纪下 15:8"> 犹大王乌西雅执政第三十九年，雅比的儿子沙龙登基，在撒玛利亚执政一个月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:17; 列王纪上 16:17; 列王纪上 16:15"> 迦底的儿子米拿现从得撒去撒玛利亚杀了雅比的儿子沙龙，篡位做了以色列王。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 14:19; 列王纪上 14:29; 列王纪下 15:11"> 沙龙其他的事及其谋反的经过都记在《以色列列王史》上。</span>
</div>
</div>

## 米拿现做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 8:12; 列王纪上 4:24; 何西阿书 13:16"> 那时，米拿现从得撒起兵攻打提斐萨及其四境。因为城中的居民不肯打开城门投降，他就杀光他们，剖开所有孕妇的肚腹。</span>
<span className="v" id="v17" data-v="17"> 犹大王亚撒利雅执政第三十九年，迦底的儿子米拿现在撒玛利亚登基做以色列王，执政十年。</span>
<span className="v" id="v18" data-v="18"> 他做耶和华视为恶的事，一生没有离开尼八的儿子耶罗波安使以色列人犯的那些罪。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 14:5; 历代志上 5:25–26; 列王纪下 18:16"> 亚述王普勒犯境，米拿现献给他六十八万两银子，以获得他的支持并巩固自己的王位。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 18:14–17; 列王纪下 23:35; 列王纪下 17:3–4"> 这些银子是米拿现向以色列的所有富户征收来的，每人十两。于是亚述王从以色列境内退兵回国。</span>
<span className="v" id="v21" data-v="21"> 米拿现其他的事及一切所为都记在《以色列列王史》上。</span>
<span className="v" id="v22" data-v="22"> 米拿现与祖先同眠后，他儿子比加辖继位。</span>
</div>
</div>

## 比加辖做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 15:25; 列王纪上 22:51; 约伯记 20:5"> 犹大王亚撒利雅执政第五十年，米拿现的儿子比加辖在撒玛利亚登基做以色列王，执政两年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 15:9; 列王纪下 15:18"> 他做耶和华视为恶的事，没有离开尼八的儿子耶罗波安使以色列人犯的那些罪。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:6; 列王纪下 9:14; 列王纪上 16:9"> 比加辖的一名将军、利玛利的儿子比加谋反，率领五十名基列人在撒玛利亚王宫里刺杀了比加辖、亚珥歌伯和亚利耶。比加篡位做了以色列王。</span>
<span className="v" id="v26" data-v="26"> 比加辖其他的事及一切所为都记在《以色列列王史》上。</span>
</div>
</div>

## 比加做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:4; 以赛亚书 7:1; 列王纪下 15:23"> 犹大王亚撒利雅执政第五十二年，利玛利的儿子比加在撒玛利亚登基做以色列王，执政二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 15:18; 列王纪下 13:6; 列王纪下 15:9"> 他做耶和华视为恶的事，没有离开尼八的儿子耶罗波安使以色列人犯的那些罪。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:26; 列王纪下 17:6; 列王纪下 16:7"> 以色列王比加执政期间，亚述王提革拉·毗列色来犯，夺取了以云、亚伯·伯·玛迦、亚挪、基低斯、夏琐、基列、加利利及拿弗他利全境，把那里的居民掳往亚述。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:1; 历代志下 28:4–6; 列王纪下 16:1"> 乌西雅的儿子约坦执政第二十年，以拉的儿子何细亚谋反，杀了利玛利的儿子比加，篡位做了以色列王。</span>
<span className="v" id="v31" data-v="31"> 比加其他的事及一切所为都记在《以色列列王史》上。</span>
</div>
</div>

## 约坦做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="历代志上 3:12; 列王纪下 15:7; 历代志下 27:1–9"> 利玛利的儿子以色列王比加执政第二年，犹大王乌西雅的儿子约坦登基。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 27:1"> 他二十五岁登基，在耶路撒冷执政十六年。他母亲叫耶路莎，是撒督的女儿。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 26:4–5; 列王纪下 15:3–4; 历代志下 27:2"> 约坦事事效法他父亲乌西雅，做耶和华视为正的事，</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 12:3; 历代志下 23:20; 历代志下 27:3–9"> 但他没有拆除丘坛，人们仍在那里献祭烧香。他执政期间，曾建造耶和华殿的上门。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 27:4–9; 列王纪下 15:6–7"> 约坦其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 16:5; 以赛亚书 7:1; 路加福音 21:28"> 那时，耶和华差遣亚兰王利汛和利玛利的儿子比加攻打犹大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪下 16:1"> 约坦与祖先同眠后，葬在大卫城他的祖坟里。他儿子亚哈斯继位。</span>
</div>
</div>

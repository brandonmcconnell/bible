<span className="v" id="v1" data-v="1" data-xref="但以理书 1:1; 耶利米书 25:1; 耶利米书 25:9"> 约雅敬执政期间，巴比伦王尼布甲尼撒进犯，约雅敬臣服于他，三年后又背叛了他。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 35:11; 列王纪下 23:27; 列王纪下 21:12–14"> 耶和华差遣迦勒底、亚兰、摩押和亚扪军队来攻打约雅敬，毁灭犹大，正如祂借着祂的仆人——众先知所说的。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:25; 列王纪下 21:2–11; 列王纪下 23:26–27"> 这些灾祸临到犹大是出自耶和华的命令。耶和华要把犹大人从自己面前赶走，是因为玛拿西所犯的一切罪，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:16; 诗篇 106:38; 民数记 35:33"> 包括他滥杀无辜，使耶路撒冷血流遍地，耶和华不会赦免这些罪行。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 36:8; 耶利米书 26:1–24; 耶利米书 22:13–17"> 约雅敬其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 22:18–19; 历代志下 36:6; 耶利米书 36:30"> 约雅敬与祖先同眠后，他儿子约雅斤继位。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 37:5–7; 耶利米书 46:2; 创世记 15:18"> 埃及王不再迈出国境，因为巴比伦王夺取了从埃及小河至幼发拉底河之间的埃及领土。</span>
</div>

## 约雅斤做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 36:9; 历代志上 3:16; 耶利米书 37:1"> 约雅斤十八岁登基，在耶路撒冷执政三个月。他母亲叫尼护施她，是耶路撒冷人以利拿单的女儿。</span>
<span className="v" id="v9" data-v="9"> 他像他父亲一样做耶和华视为恶的事。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 25:2; 但以理书 1:1–2"> 那时，巴比伦王尼布甲尼撒派将领围攻耶路撒冷城。</span>
<span className="v" id="v11" data-v="11"> 围城期间，巴比伦王尼布甲尼撒亲自来到耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 24:1; 耶利米书 52:28; 列王纪下 25:27"> 犹大王约雅斤及其母亲、臣仆和文官武将向尼布甲尼撒投降。巴比伦王尼布甲尼撒在他执政第八年俘虏了约雅斤，</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 39:6; 列王纪下 20:17; 耶利米书 20:5"> 拿走了耶和华殿里和王宫里的宝物，砍坏以色列王所罗门为耶和华的殿所造的一切金器，正如耶和华所言。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 52:28; 列王纪下 25:12; 列王纪下 24:16"> 他又掳走住在耶路撒冷的所有将领、勇士、工匠和铁匠共一万人，只留下了境内最贫穷的人。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 36:10; 耶利米书 22:24–28; 以斯帖记 2:6"> 他把约雅斤及其母亲、妃嫔、臣仆和国中政要从耶路撒冷掳到巴比伦。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 52:28; 列王纪下 24:14; 耶利米书 29:2"> 此外被掳到巴比伦的还有能征善战的勇士七千人，工匠和铁匠一千人。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 37:1; 历代志下 36:4; 列王纪下 23:34"> 巴比伦王让约雅斤的叔叔玛探雅接替约雅斤做王，给玛探雅改名叫西底迦。</span>
</div>
</div>

## 西底迦做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪下 23:31; 耶利米书 52:1–11; 耶利米书 37:1"> 西底迦二十一岁登基，在耶路撒冷执政十一年。他母亲叫哈慕她，是立拿人耶利米的女儿。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 23:37; 耶利米书 24:8; 以西结书 21:25"> 西底迦像约雅敬一样做耶和华视为恶的事。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 36:13; 帖撒罗尼迦后书 2:9–11; 耶利米书 38:17–21"> 因此，耶和华向耶路撒冷和犹大的人发怒，最终把他们从祂面前赶走。 耶路撒冷陷落 后来，西底迦背叛了巴比伦王。</span>
</div>
</div>

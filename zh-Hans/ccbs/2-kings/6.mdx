## 以利沙找回斧头

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 2:3; 列王纪下 4:1; 约书亚记 17:14"> 一群先知对以利沙说：“你看，我们住的地方实在太小了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 21:3; 使徒行传 18:3; 帖撒罗尼迦前书 2:9"> 请让我们去约旦河吧，我们每人都可以从那里砍一根木头盖房子居住。”以利沙说：“你们去吧。”</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 6:28; 士师记 19:6; 列王纪下 5:23"> 其中一人请以利沙一起去，以利沙答应了，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 19:5; 申命记 29:11"> 便和他们一起去约旦河砍伐树木。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:21; 传道书 10:10; 列王纪下 6:15"> 有个人砍树的时候，斧头掉进了水里。他大喊：“唉！师傅，这把斧头是借来的。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 2:21; 马可福音 8:23–25; 列王纪下 4:41"> 上帝的仆人问：“斧头掉在哪里了？”他就指给以利沙看。以利沙砍了一根树枝抛进水里，斧头便浮了上来。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 4:36; 出埃及记 4:4; 列王纪下 4:7"> 以利沙说：“你去拿上来吧！”他便伸手拿起了斧头。</span>
</div>
</div>

## 以利沙使亚兰军败退

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 6:24; 箴言 21:30; 箴言 20:18"> 亚兰王与以色列人交战，他和臣仆商议要在某处安营。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 3:7; 启示录 1:1; 列王纪下 6:12"> 上帝的仆人传信给以色列王，说：“你要小心，不要经过那个地方，因为亚兰人埋伏在那里。”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 13:14; 列王纪下 5:14; 使徒行传 27:24"> 以色列王派人到上帝的仆人所说的地方，警告那里的人要小心防备。这样的事情发生了好几次。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:7–11; 以赛亚书 57:20–21; 马太福音 2:3–12"> 亚兰王因此十分恼怒，召来臣仆质问他们：“你们当中谁向以色列王泄露了我们的计划？”</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 2:28–30; 阿摩司书 3:7; 列王纪下 6:9–10"> 一位臣仆说：“我主我王啊，没有人泄露。是以色列的先知以利沙将王在寝宫所谈的事告诉了以色列王。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 37:17; 约翰福音 11:47–53; 撒母耳记上 23:22–23"> 王说：“去找出他在哪里，我派人去捉拿他。”王得知以利沙在多坍后，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:17; 撒母耳记上 24:2; 撒母耳记上 23:26"> 便派出大队人马和战车前往那里，他们在夜间抵达多坍，把城围住。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 8:26; 历代志下 20:12; 诗篇 53:5"> 上帝仆人的侍者清早起来，走到外面，看见城被军队、车马包围，就对上帝的仆人说：“唉！我主啊，我们该怎么办呢？”</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 41:10–14; 罗马书 8:31; 约翰一书 4:4"> 上帝的仆人说：“不要害怕！我们的兵马比他们的还要多。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 68:17; 诗篇 34:7; 撒迦利亚书 6:1–7"> 他随后祷告：“耶和华啊，求你开他的眼睛，让他看见。”于是，耶和华开那个侍者的眼睛，他就看见山上到处都是火车火马围绕着以利沙。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 13:11; 约翰福音 12:40; 创世记 19:11"> 亚兰人向以利沙冲来，以利沙祈求耶和华说：“求你使他们瞎眼。”耶和华听了以利沙的祷告，使他们瞎了眼。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 24:16; 撒母耳记下 16:18–19; 路加福音 9:23"> 以利沙对他们说：“不是这条路，也不是这座城。跟我来，我带你们到你们要找的人那里。”以利沙把他们领到撒玛利亚。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 6:17; 路加福音 24:31; 路加福音 16:23"> 他们进城后，以利沙祷告：“耶和华啊，求你开他们的眼睛，让他们看见。”耶和华开了他们的眼睛，他们就看见了，发现自己在撒玛利亚城中。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 5:13; 列王纪下 8:9; 列王纪下 2:12"> 以色列王看见他们，问以利沙说：“我父啊，我可以杀他们吗？”</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 12:20–21; 创世记 48:22; 何西阿书 2:18"> 以利沙答道：“不可杀他们。岂可杀用刀和弓抓来的俘虏呢？给他们吃的喝的，让他们吃喝完了回自己主人那里吧。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 5:2; 列王纪下 24:2; 路加福音 6:35"> 于是，以色列王为他们大摆宴席，等他们吃喝完毕，便放他们回自己主人那里。之后，亚兰人不再侵犯以色列。</span>
</div>
</div>

## 撒玛利亚城被围困

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:1; 列王纪上 22:31; 传道书 9:14"> 后来，亚兰王便·哈达召集全军围困撒玛利亚。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 6:28–29; 耶利米书 14:18; 耶利米书 14:13–15"> 撒玛利亚被困后，城里陷入严重饥荒，以致一个驴头可卖二十两银子，二百克鸽子粪可卖一两银子。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:4; 以赛亚书 10:3; 路加福音 18:3"> 一天，以色列王从城墙上走过，一个妇人向他呼喊：“我主我王啊，求你帮帮我！”</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 118:8–9; 诗篇 124:1–3; 诗篇 60:11"> 王说：“如果耶和华不帮助你，我怎能帮助你呢？我岂有麦子和酒？</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 14:5; 士师记 18:23; 耶利米哀歌 4:10"> 你有什么难处呢？”妇人说：“这个女人对我说，‘我们今天吃你儿子，明天再吃我儿子。’</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 26:29; 申命记 28:53; 申命记 28:57"> 于是我们把我儿子煮了吃。第二天我叫她把她儿子交出来，她却把儿子藏了起来。”</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 21:27; 列王纪下 5:7; 列王纪下 19:1"> 王听了妇人的话，就撕裂衣服。王走在城墙上，人们都看见他贴身穿着麻衣。</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 1:17; 列王纪上 19:2; 约翰福音 11:50"> 王说：“如果今天沙法的儿子以利沙的头颅还留在他颈项上，愿上帝重重地惩罚我！”</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 20:1; 列王纪上 18:4; 以西结书 8:1"> 王派使者去以利沙那里。那时，以利沙正与长老们坐在他家中。使者到达之前，以利沙对长老说：“你们看，这凶手派人来斩我的头。使者到达时，你们要把他关在门外。他后面不就是他主人的脚步声吗？”</span>
<span className="v" id="v33" data-v="33" data-xref="约伯记 2:9; 以赛亚书 8:21; 创世记 4:13"> 话音未落，使者已经到了，说：“既然这祸是从耶和华来的，我何必再仰望祂呢？”</span>
</div>

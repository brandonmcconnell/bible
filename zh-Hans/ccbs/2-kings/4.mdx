## 以利沙帮助穷寡妇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:25; 列王纪下 2:3; 尼希米记 5:2–5"> 有一个先知的妻子哀求以利沙说：“你仆人——我丈夫怎样敬畏耶和华，你是知道的。如今他去世了，债主来要把我的两个孩子带去做奴隶。”</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 17:12; 雅各书 2:5; 列王纪下 6:26–27"> 以利沙问她：“我该怎样帮你呢？告诉我，你家里有什么？”妇人答道：“婢女家什么也没有，只有一瓶油。”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 2:7; 诗篇 81:10; 约翰福音 16:24"> 以利沙说：“你去向所有邻居借空器皿，要尽量多借一些。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 8:5–9; 马太福音 6:6; 以弗所书 3:20"> 然后回家关上门，你和你儿子在屋里把那瓶油倒在所有借来的器皿中，装满的放在一边。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 5:11; 希伯来书 11:7–8; 列王纪上 17:15–16"> 于是，妇人辞别以利沙，回去后把自己和儿子关在屋里，儿子递给她器皿，她就倒油。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 14:20; 列王纪下 13:19; 路加福音 6:19"> 器皿都装满了，她对儿子说：“再拿个器皿给我。”儿子说：“已经没有了。”这时，油止住了。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦后书 3:7–12; 列王纪上 12:22; 罗马书 12:17"> 妇人将经过告诉上帝的仆人，上帝的仆人对她说：“你去把油卖了还债，你们母子可以用剩下的钱度日。”</span>
</div>
</div>

## 以利沙和书念妇人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 19:18; 创世记 19:3; 列王纪下 4:11–12"> 一天，以利沙路过书念，那里一位富有的妇人挽留他吃饭。此后以利沙每次路过那里，总到她家里吃饭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 17:24; 箴言 31:10–11; 列王纪下 4:7"> 那妇人对丈夫说：“我看常路过我们这里的这位是上帝圣洁的仆人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:13; 马太福音 10:41–42; 马太福音 25:40"> 不如我们在房顶上给他盖一间小屋，里面放床、桌子、椅子和灯。这样，他来我们家时，可以在那里休息。”</span>
<span className="v" id="v11" data-v="11"> 一天，以利沙又到了那里，便在那间小屋里休息。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 8:4–5; 列王纪下 3:11; 列王纪下 4:29–31"> 以利沙吩咐仆人基哈西去请书念的妇人。他就请来妇人，妇人站在以利沙面前。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:16–18; 腓立比书 4:18–19; 希伯来书 6:10"> 以利沙吩咐基哈西说：“你对她说，‘你为我们费了不少心，我们该为你做些什么呢？要不要我们在王或元帅面前为你说些好话呢？’”她答道：“我在本族中安居无事。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:7; 创世记 15:2–3; 撒母耳记上 1:8"> 以利沙问基哈西：“我们能为她做什么呢？”基哈西说：“她没有儿子，丈夫也已经老了。”</span>
<span className="v" id="v15" data-v="15"> 以利沙说：“你再去请她来。”她来了，站在门口。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 18:10; 路加福音 1:13; 列王纪下 4:28"> 以利沙对她说：“明年这时候，你必抱一个儿子。”她说：“上帝的仆人，我主啊，不要骗婢女。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 113:9; 路加福音 1:36; 创世记 21:1"> 那妇人果然怀了孕，在第二年的那时候生了一个儿子，应验了以利沙对她说的话。</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 2:4"> 孩子渐渐长大。一天，他到收割的人那里找他父亲。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 14:1–2; 耶利米书 4:19"> 突然，他对他父亲喊道：“我的头啊！我的头啊！”他父亲见状立刻吩咐仆人抱他到他母亲那里。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:12; 约翰福音 11:3; 约翰福音 11:14"> 仆人把他抱起来，送到他母亲那里。孩子坐在母亲的膝上，到中午就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 4:32; 列王纪下 4:10; 列王纪下 4:7"> 他母亲上楼把他放在上帝仆人的床上，关上门出来。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:38; 列王纪下 4:26; 约翰福音 11:3"> 她叫来丈夫，对他说：“请你预备一个仆人和一头驴，我好赶快去见上帝的仆人，然后返回来。”</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 10:10; 民数记 28:11; 历代志上 23:31"> 她丈夫说：“今天不是朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup>，也不是安息日，你为什么要去见他？”妇人说：“放心吧。”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 4:20; 列王纪上 13:13; 撒母耳记上 25:19–20"> 她骑上驴，对仆人说：“快走吧！我不吩咐你，就不要慢下来。”</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 2:25; 以赛亚书 35:2; 列王纪上 18:19"> 她就去迦密山见上帝的仆人。上帝的仆人远远望见她，就对仆人基哈西说：“你看，书念的妇人来了！</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:36; 列王纪下 4:23; 撒母耳记上 17:18"> 你跑去迎接她，问问她和她的丈夫与孩子都好吗。” 妇人对以利沙的仆人说：“一切都好。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 7:3; 创世记 18:17; 阿摩司书 3:7"> 可是，她上山见到上帝的仆人后，就抱住他的脚。基哈西想要推开她，但上帝的仆人说：“由她吧！因为她心里非常痛苦。耶和华没有告诉我发生了什么事。”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 30:1; 列王纪下 4:16"> 妇人说：“我何尝向我主求过儿子呢？我不是对你说不要骗我吗？”</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 2:14; 列王纪上 18:46; 出埃及记 14:16"> 以利沙吩咐基哈西：“你要束上腰带，拿着我的杖去她家。路上不论遇见谁，都不要问候他。有人问候你，也不要作答。去把我的杖放在孩子脸上。”</span>
<span className="v" id="v30" data-v="30" data-xref="路得记 1:16–18; 列王纪下 2:2; 出埃及记 33:12–16"> 孩子的母亲说：“我凭永活的耶和华和你的性命起誓，你若不同去，我决不离开你。”于是，以利沙跟她同去。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 11:11; 马可福音 5:39; 马可福音 9:19–29"> 基哈西先赶到，把杖放在孩子脸上，可是孩子一点动静也没有。他就回去找以利沙，路上碰见他，便说：“孩子还没醒过来。”</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 8:52–53; 约翰福音 11:17; 列王纪上 17:17"> 以利沙进了屋子，看见孩子死了，躺在床上，</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 6:6; 列王纪下 4:4; 使徒行传 9:40"> 就关上门，向耶和华祈祷。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 17:21; 使徒行传 20:10"> 祷告后，他上床伏在孩子身上，口对口，眼对眼，手对手，孩子的身体渐渐变暖了。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 8:5; 列王纪下 13:21; 列王纪上 17:22"> 然后，以利沙起来在房内来回走了一趟，又上床伏在孩子身上。孩子打了七个喷嚏，便睁开了眼睛。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 11:35; 列王纪上 17:23; 路加福音 7:15"> 以利沙叫基哈西请那妇人来。他便请来妇人，以利沙对妇人说：“把你儿子抱走吧。”</span>
<span className="v" id="v37" data-v="37" data-xref="希伯来书 11:35; 列王纪下 2:15; 列王纪上 17:24"> 妇人进来，在以利沙脚前下拜，然后抱起儿子出去了。</span>
</div>
</div>

## 用面粉解毒

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王纪下 8:1; 列王纪下 2:3; 列王纪下 2:1"> 以利沙回到吉甲，那里正遭遇饥荒。一群先知坐在他面前，他吩咐仆人把一口大锅放在火上给他们煮汤。</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米书 2:21; 以赛亚书 5:4; 马太福音 15:13"> 有个先知到田间摘野菜，看见一棵野瓜藤，便摘了一兜野瓜回来，切碎了放进锅里，却不知道那是什么瓜。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 16:18; 出埃及记 15:23; 出埃及记 10:17"> 汤煮好后倒出来给众人喝，他们刚喝了一点，就叫道：“上帝的仆人啊，锅里有剧毒！”他们都不敢喝了。</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪下 2:21; 出埃及记 15:25; 哥林多前书 1:25"> 以利沙说：“拿点面粉来。”他把面粉撒在锅里，说：“倒出来给众人喝吧。”于是，锅里没有毒了。</span>
</div>
</div>

## 用二十个饼喂饱百人

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 9:7; 约翰福音 6:9; 马太福音 14:16–21"> 从巴力·沙利沙来了一个人，他带了二十个用初熟大麦做的饼和一些麦穗送给上帝的仆人。上帝的仆人说：“分给众人吃吧。”</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:13; 马太福音 14:20; 约翰福音 6:9"> 仆人说：“这怎么够一百人吃呢？”以利沙说：“你只管分给众人吃。因为耶和华说，‘众人都能吃饱，并且还会剩下。’”</span>
<span className="v" id="v44" data-v="44"> 于是，仆人将食物摆在众人面前，他们都吃饱了，果然还有剩余，正如耶和华所言。</span>
</div>

## 以利沙医治乃缦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:27; 罗马书 15:18; 箴言 21:31"> 乃缦是亚兰王的元帅，甚得亚兰王器重，因为耶和华借他使亚兰人打了许多胜仗。他是英勇的战士，只是患了麻风病。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 6:23; 列王纪下 13:20; 撒母耳记上 13:17–18"> 亚兰人袭击以色列时，曾掳回一个以色列少女，这少女做了乃缦妻子的婢女。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:29; 路加福音 17:12–14; 民数记 11:29"> 有一天，她对主母说：“要是我主人去见撒玛利亚的那位先知就好了！他一定能治好我主人的麻风病。”</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:26–27; 约翰福音 4:28–29; 约翰福音 1:42–46"> 乃缦把这以色列少女的话告诉亚兰王。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 14:12; 列王纪下 8:8–9; 民数记 22:17–18"> 亚兰王说：“你去吧。我会写信给以色列王。”于是，乃缦带了六千八百两银子、一千四百两金子和十套衣服，启程前往以色列。</span>
<span className="v" id="v6" data-v="6"> 他带给以色列王的信上写着：“谨以此信介绍我的臣仆乃缦到你那里，你要治好他的麻风病。”</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:6; 列王纪上 20:7; 创世记 30:2"> 以色列王读完信后，就撕裂衣服说：“难道我是上帝吗？我能操纵人的生死吗？这人竟叫我治好一个人的麻风病！他只是想找借口攻打我。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 18:36–37; 何西阿书 12:13; 以西结书 2:5"> 上帝的仆人以利沙听说以色列王撕裂了衣服，便派人去对王说：“你为什么撕裂衣服呢？让那人到我这里来，我要让他知道以色列有先知。”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 16:37–39; 列王纪下 6:32; 以赛亚书 60:14"> 乃缦带领车辆和马匹到了以利沙的家，站在门口。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 9:7; 哥林多前书 6:11; 利未记 14:7"> 以利沙派使者出去对乃缦说：“你到约旦河里洗七次，你的皮肤就会复原，并得到洁净。”</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 15:27; 路加福音 14:11; 马太福音 8:8"> 乃缦却怒冲冲地走了。他说：“我以为他一定会出来见我，为我站着求告他的上帝耶和华的名，用手在我的患处晃一晃，治好我的麻风病。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 1:9; 列王纪下 5:17; 列王纪下 2:14"> 大马士革的亚巴拿河和法珥法河不比以色列所有的河都好吗？难道我在那里洗就不能得到洁净吗？”于是，他怒冲冲地转身走了。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 6:21; 列王纪下 13:14; 列王纪下 2:12"> 他的仆人上前对他说：“我父啊，先知若吩咐你做一件大事，难道你不去做吗？何况他只是说你去洗洗就可以洁净！”</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 33:25; 路加福音 4:27; 路加福音 5:13"> 乃缦就去约旦河，照上帝仆人的话在河里洗了七次，他的皮肤复原，像小孩子的一样，他便洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 2:47; 但以理书 6:26–27; 约书亚记 2:9–11"> 乃缦率领全体随从回到上帝的仆人那里，站在他面前说：“我如今才知道，除了以色列，普天下没有上帝。请你收下仆人的礼物。”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 5:26; 列王纪下 5:20; 列王纪下 3:14"> 以利沙说：“我凭我事奉的永活的耶和华起誓，我决不接受。”乃缦再三请求，他仍不肯接受。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 26:18; 列王纪下 5:12; 罗马书 14:1"> 乃缦说：“你如果不肯接受礼物，请容许仆人用两头骡子驮些泥土回去。从此以后，我不再献燔祭或平安祭给其他神明，只献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 7:2; 列王纪下 7:17; 列王纪下 17:35"> 但有一件事，愿耶和华饶恕仆人。我主人进入临门庙祭拜时，他会扶着我的手，这样我也得随着他弯腰。如果我在临门庙里弯腰，愿耶和华饶恕我。”</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 1:17; 马可福音 5:34; 出埃及记 4:18"> 以利沙对他说：“你安心走吧。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 4:12; 列王纪下 4:31; 列王纪下 6:31"> 乃缦刚走不远，上帝仆人以利沙的侍者基哈西心想：“我主人没有收亚兰人乃缦带来的礼物就让他走了。我凭永活的耶和华起誓，我一定要追上去，向他要点东西。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 7:6–7; 列王纪下 9:17–22; 列王纪下 4:26"> 他便去追赶乃缦。乃缦见后面有人赶来，就下车迎接他，问他：“一切都好吗？”</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 5:5; 以赛亚书 59:3; 使徒行传 5:3–4"> 基哈西答道：“一切都好。我主人派我来告诉你，刚才有两位年轻的先知从以法莲山区来见他，请你赐给他们七百两银子和两套衣服。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:10; 列王纪上 20:7; 列王纪下 2:17"> 乃缦说：“请你拿走一千四百两银子吧！”并再三请基哈西接受，然后把一千四百两银子装进两个袋子，连同两套衣服，交给他的两个仆人抬走，基哈西跟在他们后面。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 21:16; 约书亚记 7:11–12; 约书亚记 7:1"> 到了山冈，基哈西接过银子和衣服，放进屋里，便让他们回去了。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 5:22; 创世记 16:8; 箴言 30:20"> 基哈西进去侍立在他主人以利沙面前，以利沙问他：“基哈西，你刚才去哪里了？”基哈西答道：“仆人哪里也没去。”</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:5; 哥林多前书 5:3; 列王纪下 6:12"> 以利沙对他说：“那人下车回头迎接你的时候，我的心不也在那里吗？现在岂是接受人家银子、衣服、橄榄园、葡萄园、牛羊和仆婢的时候？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:6; 民数记 12:10; 列王纪下 15:5"> 因此，你和你的后代会永远沾染乃缦的麻风病。”基哈西离开以利沙时，患了麻风病，皮肤像雪一样白。</span>
</div>

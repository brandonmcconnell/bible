## 营地的安排

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 14:40; 民数记 10:22; 民数记 1:50"> “以色列人要各归本旗，按本族的旗号，在会幕四围稍远的地方安营。”</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 2:10; 路得记 4:20; 路加福音 3:32–33"> 东边，即日出的方向，是犹大营区及其旗号。犹大人的首领是亚米拿达的儿子拿顺，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:22; 民数记 1:27"> 他的队伍有七万四千六百人。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 1:8; 民数记 7:18; 民数记 7:23"> 在犹大支派旁边安营的是以萨迦支派，以萨迦人的首领是苏押的儿子拿坦业，</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:25; 民数记 1:29"> 他的队伍有五万四千四百人。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 1:9; 民数记 7:24; 民数记 10:16"> 然后是西布伦支派，西布伦人的首领是希伦的儿子以利押，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:26–27; 民数记 1:31"> 他的队伍有五万七千四百人。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 10:14"> 犹大营区的队伍共计十八万六千四百人，他们是前队。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 1:5; 创世记 49:3–4; 民数记 7:35"> 南边是吕便营区及其旗号。吕便人的首领是示丢珥的儿子以利苏，</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 26:7; 民数记 1:21"> 他的队伍有四万六千五百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 1:6; 民数记 10:19; 民数记 7:41"> 在吕便支派旁边安营的是西缅支派，西缅人的首领是苏利沙代的儿子示路蔑，</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 26:14; 民数记 1:23"> 他的队伍有五万九千三百人。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:14; 民数记 7:42; 民数记 7:47"> 然后是迦得支派，迦得人的首领是丢珥的儿子以利雅萨，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:18; 民数记 1:25"> 他的队伍有四万五千六百五十人。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 10:18; 民数记 2:9; 民数记 2:24"> 吕便营区的队伍共计十五万一千四百五十人，他们是第二队。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 10:21; 民数记 10:17; 民数记 3:38"> 随后是会幕和利未人的营区，在其他各营中间。他们各就各位，各归本旗，照安营时的次序出发。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 1:10; 民数记 10:22; 创世记 48:14–20"> 西边是以法莲营区及其旗号。以法莲人的首领是亚米忽的儿子以利沙玛，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:33; 民数记 26:37"> 他的队伍有四万零五百人。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:10; 民数记 7:54; 民数记 10:23"> 以法莲支派旁边是玛拿西支派，玛拿西人的首领是比大苏的儿子迦玛列，</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 26:34; 民数记 1:35"> 他的队伍有三万二千二百人。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 1:11; 民数记 7:60; 民数记 10:24"> 然后是便雅悯支派，便雅悯人的首领是基多尼的儿子亚比但，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:37; 民数记 26:41"> 他的队伍有三万五千四百人。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 10:22; 民数记 2:31; 诗篇 80:2"> 以法莲营区的队伍共计十万八千一百人，他们是第三队。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 1:12; 民数记 7:66; 民数记 10:25"> 北边是但营区及其旗号。但人的首领是亚米沙代的儿子亚希以谢，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 26:43; 民数记 1:39"> 他的队伍有六万二千七百人。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:13; 民数记 7:77; 民数记 7:72"> 在但支派旁边安营的是亚设支派，亚设人的首领是俄兰的儿子帕结，</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 1:41; 民数记 26:47"> 他的队伍有四万一千五百人。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:15; 民数记 10:27; 民数记 26:48–50"> 然后是拿弗他利支派，拿弗他利人的首领是以南的儿子亚希拉，</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 1:42–43; 民数记 26:50"> 他的队伍有五万三千四百人。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 10:25; 民数记 2:16; 民数记 2:9"> 但营区的队伍共计十五万七千六百人，他们是后队。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 2:9"> 以上是照家系和队伍统计的各营中的以色列人，共六十万三千五百五十名。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 26:57–62; 民数记 1:47–49"> 照耶和华对摩西的吩咐，利未人没被统计在以色列人中。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 119:6; 民数记 24:2; 民数记 24:5–6"> 于是，以色列人照耶和华对摩西的吩咐，各按自己的旗号安营，各按自己的宗族和家系启行。</span>
</div>
</div>

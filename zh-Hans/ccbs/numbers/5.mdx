## 送不洁净之人出营

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 21:1; 利未记 13:46; 民数记 12:14"> “你吩咐以色列人把所有患麻风病、漏症和因碰过死尸而不洁净的人，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:14; 利未记 26:11–12; 诗篇 68:18"> 无论男女，都送到营外，免得他们玷污了营地，因为我住在其中。”</span>
<span className="v" id="v4" data-v="4"> 以色列人遵命而行，照耶和华对摩西的吩咐，把这些人送到营外。</span>
</div>
</div>

## 赔偿条例

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:1–4; 利未记 5:14–7"> “你把以下条例告诉以色列人：无论男女，若亏负别人，以致失信于耶和华，就是犯罪。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 5:5; 利未记 26:40; 约书亚记 7:19"> 那人必须认罪，赔偿受害人全部损失，并加赔五分之一。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 6:6–7; 利未记 7:7; 利未记 25:25–26"> 如果受害人已死，又没有可以接受赔偿的近亲，赔偿就属于耶和华，要归祭司所有。那人还要再献上一只公绵羊为自己赎罪。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 18:3–4; 利未记 7:6–14; 利未记 6:17–18"> 以色列人带来奉献的一切圣物都要归祭司所有。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:13"> 各人奉献的圣物，无论是什么，都要归祭司所有。”</span>
</div>
</div>

## 疑妻不贞

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 5:19–20; 箴言 2:16–17"> “你把以下条例告诉以色列人：若有人怀疑妻子出轨，暗中与人通奸，玷污了自己，却没有证人，也没有当场抓住她，在无法确定是自己疑心还是妻子不贞的情况下，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 29:16; 列王纪上 17:18; 利未记 5:11"> 他要带妻子到祭司那里，同时为妻子带去一公斤大麦面粉作为供物。不可在上面浇油或加乳香，因为这是因疑心而献上的素祭，是让人回忆过犯的素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 2:22–23; 耶利米书 17:10; 希伯来书 13:4"> “祭司要把那妇人带到耶和华面前，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 30:18; 约翰福音 8:6; 民数记 19:2–9"> 用陶器盛一些圣水，从圣幕的地上取一些尘土撒在水中，</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民数记 5:22; 启示录 10:9–10"> 然后让那妇人站在耶和华面前，解开她的头发，把回忆过犯的素祭，就是因疑心而献的素祭放在她手里。祭司要拿着带给罪人咒诅的苦水，</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:2; 民数记 5:12; 马太福音 26:63"> 叫她发誓。祭司要对她说，‘如果你没有背着丈夫与人通奸，没有因出轨而玷污自己，就不会被这苦水所害。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 5:12"> 如果你曾出轨，背着丈夫与人通奸，以致玷污自己，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 6:26; 尼希米记 10:29; 撒母耳记上 14:24"> 愿耶和华使你大腿消瘦、肚腹肿胀，使你在同胞中成为咒诅。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 109:18; 诗篇 89:52; 约伯记 31:39–40"> 愿这可带来咒诅的苦水进入你体内，使你肚腹肿胀、大腿消瘦。’她要说，‘阿们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“阿们”是“诚然如此”的意思。">a</a></sup>！阿们！’</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 诗篇 51:1; 诗篇 51:9"> 祭司要把这咒诅写在书卷上，再放在苦水里把字洗掉。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 5:3–4; 玛拉基书 3:5"> 祭司要让妇人喝这可带来咒诅的苦水，不忠的妇人喝下后，肚子会感到剧痛。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:27; 民数记 5:18; 民数记 5:15"> 祭司要从妇人手中接过她丈夫因疑心而献的素祭，在耶和华面前摇一摇，然后带到祭坛那里。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 2:2; 利未记 2:9; 利未记 5:12"> 他要从素祭中取出一把面粉，作为象征放在祭坛上焚烧，然后叫那妇人喝下苦水。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 42:18; 撒迦利亚书 8:13; 耶利米书 29:18"> 如果她曾玷污自己，背叛了丈夫，这可带来咒诅的苦水进入她体内后，会引起剧痛，使她肚腹肿胀、大腿消瘦，她将在同胞中成为咒诅。</span>
<span className="v" id="v28" data-v="28" data-xref="弥迦书 7:7–10; 哥林多后书 4:17; 诗篇 113:9"> 但如果她是贞洁的，没有玷污自己，就不会受伤害，仍能生育。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 5:19; 民数记 5:12; 民数记 5:15"> “这就是处理丈夫怀疑妻子不贞的条例。遇到妻子背着丈夫与人通奸，</span>
<span className="v" id="v30" data-v="30"> 或是丈夫怀疑妻子不贞，就要让妻子站在耶和华面前，由祭司对她执行这条例。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 20:10; 罗马书 2:8–9; 以西结书 18:4"> 无论结果怎样，丈夫都无罪，但妻子若有罪，必承担罪责。”</span>
</div>
</div>

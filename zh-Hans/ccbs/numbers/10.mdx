## 银号

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:13; 约珥书 1:14; 诗篇 81:3"> “你要用银子打造两支号，用来招聚会众和发出拔营的号令。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 4:5; 约珥书 2:15–16"> 吹响两支号时，全体会众要在会幕门口聚集到你面前。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 7:2; 出埃及记 18:21; 民数记 1:4–16"> 如果只吹响一支号，担任首领的以色列各族长要聚集到你面前。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 2:3–9; 民数记 10:14; 以赛亚书 58:1"> 如果吹响拔营的号令，在东面扎营的就要启行；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 10:18; 民数记 2:10–16"> 第二次吹响拔营号令时，在南面扎营的就要启行。拔营号令是启行的信号。</span>
<span className="v" id="v7" data-v="7" data-xref="约珥书 2:1; 民数记 10:3–4"> 但吹号招聚会众时，不要用拔营号令。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:4–16; 民数记 31:6; 历代志上 15:24"> 做祭司的亚伦子孙要负责吹号，这是你们世代当守的永久律例。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 10:18; 士师记 2:18; 创世记 8:1"> 当你们在自己的土地上跟来犯之敌作战时，要吹响两支号，你们的上帝耶和华必眷顾你们，救你们脱离敌人。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 81:3; 帖撒罗尼迦前书 4:16; 哥林多前书 11:24–26"> 在节期和朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup>这些欢乐的日子献燔祭和平安祭的时候，你们要吹号，好在你们的上帝面前蒙眷顾。我是你们的上帝耶和华。”</span>
</div>
</div>

## 离开西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:17; 民数记 1:1; 民数记 9:11"> 第二年的二月二十日，云彩从安放约柜的圣幕上升起，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 21:21; 民数记 12:16; 民数记 9:5"> 以色列人就从西奈旷野启行，直到云彩停在巴兰旷野时才停下来。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 1:6; 民数记 9:23"> 这是他们初次照耶和华借摩西的吩咐启行。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 2:3–9; 民数记 1:7; 民数记 7:12"> 犹大旗下的营队率先出发，率领犹大支派的是亚米拿达的儿子拿顺，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:18; 民数记 1:8"> 率领以萨迦支派的是苏押的儿子拿坦业，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 7:24; 民数记 1:9"> 率领西布伦支派的是希伦的儿子以利押。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:6–8; 民数记 1:51; 希伯来书 12:28"> 然后，圣幕被拆卸，革顺和米拉利的子孙抬着圣幕出发。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 2:10–16; 民数记 1:5; 民数记 26:5–18"> 随后出发的是吕便旗下的营队，率领吕便支派的是示丢珥的儿子以利苏，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:6; 民数记 7:36"> 率领西缅支派的是苏利沙代的儿子示路蔑，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:14; 民数记 2:14; 民数记 7:42"> 率领迦得支派的是丢珥的儿子以利雅萨。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 10:17; 民数记 7:9; 民数记 4:4–16"> 随后出发的是哥辖人，他们抬着圣物前行。在他们到达之前，圣幕应已支好。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 2:18–24; 民数记 1:10; 民数记 26:23–41"> 随后出发的是以法莲旗下的营队，率领以法莲支派的是亚米忽的儿子以利沙玛，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:10; 民数记 7:54"> 率领玛拿西支派的是比大苏的儿子迦玛列，</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 1:11; 民数记 7:60"> 率领便雅悯支派的是基多尼的儿子亚比但。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:9; 民数记 1:12; 创世记 49:16–17"> 殿后的是但旗下的营队，率领但支派的是亚米沙代的儿子亚希以谢，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:13; 民数记 7:72"> 率领亚设支派的是俄兰的儿子帕结，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:15; 民数记 7:78"> 率领拿弗他利支派的是以南的儿子亚希拉。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 2:34; 民数记 24:4–5; 哥林多前书 14:33"> 这是以色列各营队拔营前行的次序。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 12:7; 士师记 4:11; 出埃及记 3:1"> 摩西对岳父米甸人流珥之子何巴说：“我们就要动身前往耶和华应许给我们的地方，祂曾说要把那地方赐给我们。请你跟我们一起去吧，我们必厚待你，耶和华已经应许要赐福给以色列人。”</span>
<span className="v" id="v30" data-v="30" data-xref="路得记 1:15–17; 诗篇 45:10; 马太福音 21:29"> 何巴说：“我不去了，我要回到我的家乡和亲族那里。”</span>
<span className="v" id="v31" data-v="31" data-xref="约伯记 29:15; 加拉太书 6:2; 哥林多前书 12:14–21"> 摩西说：“请不要离开我们。你熟悉旷野，可以做我们的向导，告诉我们在哪里扎营。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 1:16; 申命记 10:18; 约翰一书 1:3"> 如果你跟我们同去，我们一定与你分享耶和华赐给我们的福气。”</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 1:33; 出埃及记 3:1; 诗篇 95:11"> 以色列人离开耶和华的山，走了三天的路程，期间耶和华的约柜一直在队伍的前头，为他们寻找安歇之地。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 9:12; 尼希米记 9:19; 诗篇 105:39"> 他们拔营前行的时候，白天总有耶和华的云彩在他们上面。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 68:1–2; 以赛亚书 17:12–14; 诗篇 132:8"> 每当约柜出发的时候，摩西就说：“耶和华啊，求你兴起，击溃你的仇敌，使恨你的人从你面前逃窜。”</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 1:10; 诗篇 90:13–17; 以赛亚书 63:17"> 约柜停下来的时候，他就说：“耶和华啊，求你回到以色列的千万人中。”</span>
</div>
</div>

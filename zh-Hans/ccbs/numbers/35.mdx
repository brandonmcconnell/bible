## 利未人分到的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 22:1; 民数记 31:12; 民数记 33:50"> 在耶利哥对面、约旦河边的摩押平原，耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 14:3–4; 以西结书 48:8; 约书亚记 21:2–42"> “你告诉以色列人，要从分得的产业中把一些城邑及其周围的草场分给利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:14; 约书亚记 21:11; 以西结书 45:2"> 城邑供他们居住，草场供他们牧放牛羊等牲畜。</span>
<span className="v" id="v4" data-v="4"> 划分给利未人的草场是从城墙往外延伸四百五十米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“四百五十米”《七十士译本》作“九百一十米”。">a</a></sup>，</span>
<span className="v" id="v5" data-v="5"> 要以城为中心，东南西北四郊每边向外量九百米，作利未人的草场。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:13; 约书亚记 21:3; 诗篇 9:9"> 要分给利未人四十二座城邑，另外再加六座供误杀人者逃命的避难城，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:3–42; 历代志上 6:54–81"> 共分给利未人四十八座城邑，包括城周围的草场。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:54; 民数记 33:54; 约书亚记 21:1–42"> 以色列各支派要按比例从自己承受的产业中分一些城邑给利未人，人多的支派多给，人少的支派少给。”</span>
</div>
</div>

## 避难城

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 12:9; 申命记 19:1–2; 利未记 14:34"> “你要告诉以色列人，‘你们过了约旦河进入迦南以后，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 21:13; 约书亚记 20:2; 民数记 35:6"> 要选一些城邑作为你们的避难城，供误杀人者逃去避难，</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 20:3–6; 申命记 19:6; 约书亚记 20:9"> 躲避复仇的人，以免误杀人者未在会众面前受审，便被杀死。</span>
<span className="v" id="v13" data-v="13"> 你们要选六座城作为避难城，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 19:8–10; 申命记 4:41–43; 约书亚记 20:7–9"> 三座在约旦河东岸，三座在迦南。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 15:16; 加拉太书 3:28; 罗马书 3:29"> 凡误杀人的，无论是以色列人，还是在他们当中寄居的外族人，都可以逃到这些城避难。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 24:17; 创世记 9:5–6; 申命记 19:11–13"> “‘倘若有人用铁器打人致死，他就是故意杀人，杀人犯必须被处死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 21:18"> 倘若有人用足以致命的石头打人致死，他就是故意杀人，杀人犯必须被处死。</span>
<span className="v" id="v18" data-v="18"> 倘若有人用足以致命的木器打人致死，他就是故意杀人，杀人犯必须被处死。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 20:3; 申命记 19:6; 申命记 19:12"> 报血仇的人要亲自处死故意杀人者，一找到他就要处死他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 21:14; 申命记 19:11; 撒母耳记下 3:27"> 倘若有人因仇恨把人推倒致死，或故意扔东西砸人致死，</span>
<span className="v" id="v21" data-v="21"> 或因仇恨徒手伤人致死，他就是故意杀人，杀人犯必须被处死，报血仇的人一找到他就要处死他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 35:11; 出埃及记 21:13; 约书亚记 20:3"> “‘倘若有人并非出于怀恨，而是偶然推倒人致死，或无意间扔东西砸人致死，</span>
<span className="v" id="v23" data-v="23"> 或因没有看见而扔石头砸人致死，鉴于他与对方并非仇人，也无意加害对方，</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 20:6; 民数记 35:12"> 会众就要照这些律例在误杀人者与报血仇者之间做出判决。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:7; 利未记 4:3; 罗马书 3:24–26"> 会众要把误杀人者从报血仇者手里救出来，让他回到他原先逃往的避难城。他要住在那里，一直住到受圣油膏立的大祭司逝世。</span>
<span className="v" id="v26" data-v="26"> 但倘若误杀人者离开避难城，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:2; 申命记 19:10; 申命记 19:6"> 报血仇的人在城外找到他，将他杀死也不用担血债。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 3:14; 希伯来书 10:26–30; 希伯来书 6:4–8"> 因为误杀人者必须留在避难城内，等到大祭司逝世之后，才可返回家园。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 27:11; 民数记 27:1"> 这是你们世世代代无论住在哪里都要遵守的律例。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:28; 申命记 19:15; 马太福音 18:16"> “‘倘若有人被控谋杀，必须有几个人作证才可以处死他，不可凭一个人的证词处死他。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 19:11–13; 创世记 9:5–6; 诗篇 51:14"> 犯了死罪的杀人犯必须偿命，不可让他付赎金免死。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:12; 加拉太书 3:10–13; 加拉太书 2:21"> 不可收逃进避难城之人的赎金，让他在大祭司逝世前返回家园。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 诗篇 106:38; 何西阿书 4:2–3"> 这样，你们就不致玷污你们所居住的土地，因为血会玷污土地。除非用凶手的血作抵偿，否则被血玷污的土地无法得到洁净。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 5:3; 诗篇 135:21; 启示录 21:27"> 不可玷污你们所居住的土地，那也是我居住的地方，因为我耶和华住在以色列人中间。’”</span>
</div>
</div>

</div>

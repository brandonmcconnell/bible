## 逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 出埃及记 40:2"> 以色列人离开埃及后第二年的一月，耶和华在西奈旷野对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 16:1–2; 哥林多前书 5:7–8; 历代志下 35:1"> “以色列人要在指定的时间守逾越节，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 12:6–11; 利未记 23:5; 历代志下 30:2"> 就是在一月十四日黄昏，按照相关律例和典章守逾越节。”</span>
<span className="v" id="v4" data-v="4"> 于是，摩西吩咐以色列人守逾越节。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 马太福音 28:20; 出埃及记 12:1–13"> 一月十四日黄昏，以色列人在西奈旷野守逾越节。以色列人遵行了耶和华对摩西的一切吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 27:2; 出埃及记 18:15; 民数记 5:2"> 可是，有几个人因碰到死尸而不洁净，不能在那天守逾越节，他们就来见摩西和亚伦，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 16:2; 哥林多前书 5:7–8; 出埃及记 12:27"> 说：“我们因碰到死尸而不洁净，为什么不准我们跟其他以色列人一起在指定的时间向耶和华献供物？”</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 85:8; 民数记 27:5; 哥林多前书 4:4"> 摩西说：“你们等一下，我要去听听耶和华对你们有什么吩咐。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:1–2; 以弗所书 2:12–13; 哥林多前书 11:28"> “你告诉以色列人：<br />“你们或你们的子孙中，若有人因为碰了死尸而不洁净，或是出了远门，他们仍然要为耶和华守逾越节。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:2–15; 出埃及记 12:43–49; 约翰福音 19:36"> 他们可以在二月十四日黄昏守逾越节，要配无酵饼和苦菜一起吃逾越节的羊羔。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 19:36; 出埃及记 12:46; 出埃及记 12:10"> 食物不可留到早晨，也不可折断羊羔的一根骨头。要按照一切律例守逾越节。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 17:14; 出埃及记 12:15; 民数记 9:7"> 如果有人是洁净的，又没有出远门，却不守逾越节，要将他从民中铲除。因为他没有在指定的时间向耶和华献供物，就必须自负罪责。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 12:48–49; 利未记 24:22; 以赛亚书 56:3–7"> 如果寄居在你们中间的外族人也想为耶和华守逾越节，他们也要按照这些律例和典章守逾越节。不论是外族人还是本地人，都要遵守同样的律例。”</span>
</div>
</div>

## 云彩遮盖会幕

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 13:21; 出埃及记 40:34; 尼希米记 9:19"> 安放约柜的圣幕支起来那天，云彩遮盖了它。整个晚上，云彩在圣幕上方像火焰一般。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 9:12; 出埃及记 40:38; 哥林多前书 10:1"> 之后，总是如此：白天云彩遮盖圣幕，晚上云彩像火。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 40:36–38; 诗篇 32:8; 约翰福音 10:9"> 云彩什么时候从圣幕上升起，以色列人就启行；云彩在哪里停下来，以色列人就在哪里安营。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:1; 约翰二书 1:6; 出埃及记 17:1"> 他们无论启行还是安营，都遵照耶和华的吩咐。云彩在圣幕上停留多久，他们就安营多久。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 3:7; 民数记 1:52–53; 民数记 3:8"> 有时云彩在圣幕上停留多日，他们就遵照耶和华的吩咐安营多日。</span>
<span className="v" id="v20" data-v="20"> 有时云彩在圣幕上只停留几天，他们就遵照耶和华的吩咐只安营几天。随后再照耶和华的吩咐启行。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 9:19; 尼希米记 9:12"> 有时云彩整夜停留在圣幕上，到早晨才升起，他们就早晨才启行。不管白天黑夜，云彩一升起，他们就启行。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 32:8; 出埃及记 40:36–37; 出埃及记 40:16"> 不管是两天、一个月或是一年，只要云彩停留在圣幕上，以色列人就安营不动；云彩一升起，他们就启行。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 22:3; 民数记 9:19; 创世记 26:5"> 他们遵照耶和华的吩咐安营，也遵照耶和华的吩咐启行。他们遵行耶和华借摩西吩咐的话。</span>
</div>
</div>

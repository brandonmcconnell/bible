## 米利暗受罚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:21; 创世记 26:34–35; 创世记 24:37"> 米利暗和亚伦因摩西娶了一个古实的女子而批评他，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 35:12–13; 民数记 16:3; 弥迦书 6:4"> “难道耶和华只借着摩西说话吗？祂不也借着我们说话吗？”耶和华听见了这话。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 11:29; 雅各书 3:13; 哥林多后书 11:5"> 其实摩西为人十分谦和，比世上任何人都谦和。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:9; 民数记 16:16–21"> 耶和华突然对摩西、亚伦和米利暗说：“你们三人都出来到会幕去。”他们就去了。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 11:25; 出埃及记 34:5; 诗篇 99:7"> 耶和华在云柱中降临，站在会幕门口呼唤亚伦和米利暗，二人就走到前面。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 3:5; 创世记 31:10–11; 创世记 46:2"> 耶和华说：“你们听我说，你们中间若有先知，我耶和华必在异象中向他显现，在梦中跟他说话。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 3:2–6; 约书亚记 1:1; 诗篇 105:26"> 但我不是这样对待我的仆人摩西，他在我家里忠信可靠，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 34:10; 哥林多前书 13:12; 出埃及记 33:11"> 我跟他面对面说话，清清楚楚，不用谜语，他看得见我的形象。你们怎敢批评我的仆人摩西？”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 17:22; 何西阿书 5:15; 民数记 11:1"> 耶和华向他们发怒，然后离去。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 24:9; 列王纪下 5:27; 出埃及记 4:6"> 云彩从会幕上离开的时候，米利暗身上患了麻风病，像雪一样白。亚伦见状，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 19:19; 撒母耳记下 24:10; 箴言 30:32"> 便对摩西说：“我主啊，求你不要因我们愚昧犯罪而惩罚我们。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 88:4–5; 哥林多前书 15:8; 提摩太前书 5:6"> 求你不要让她像那一出母腹便半身腐烂的死胎。”</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:21; 路加福音 6:28; 雅各书 5:15"> 于是，摩西呼求耶和华：“上帝啊，求你医治她！”</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 25:9; 约伯记 30:10; 以赛亚书 50:6"> 耶和华对摩西说：“如果她父亲在她脸上吐唾沫，她岂不也要蒙羞七天吗？现在把她关在营外，七天后再让她回来。”</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 24:8–9; 弥迦书 7:8–9; 弥迦书 6:4"> 于是，米利暗被关在营外七天，民众等她回营后才继续前行。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:35; 民数记 33:18; 民数记 10:12"> 他们离开哈洗录，到巴兰旷野安营。</span>

## 以色列人发怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:5; 民数记 16:35; 列王纪下 1:12"> 民众因为困难而发怨言，传到耶和华耳中。耶和华听见后便向他们发怒，使火在他们中间燃烧，烧毁了营地的边缘部分。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 21:7; 雅各书 5:16; 民数记 16:45–48"> 民众呼求摩西，摩西便向耶和华祷告，火就熄了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:22"> 那地方叫他备拉，因为耶和华的火曾在他们中间燃烧。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:6; 出埃及记 12:38; 诗篇 106:14"> 他们中间有一群乌合之众贪恋美食，以色列人也哭着说：“要是有肉吃多好啊！</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:3; 诗篇 17:14; 腓立比书 3:19"> 还记得在埃及的时候，我们不花钱就可以吃鱼，还有黄瓜、西瓜、韭菜、葱和蒜。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 21:5; 撒母耳记下 13:4"> 我们现在毫无胃口，眼前除了吗哪外，什么都没有。”</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:31; 创世记 2:12; 出埃及记 16:14–15"> 吗哪的形状像芫荽籽，又像珍珠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 16:31; 出埃及记 16:16–18; 出埃及记 16:23"> 每天晚上露水降在营地上时，吗哪也随着降下来。早晨民众到四周捡吗哪，把吗哪用磨磨碎或在臼中捣碎后，放在锅里煮，再做成饼，味道就像油饼。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:21; 民数记 16:27; 民数记 14:1–2"> 摩西感到难过，因为他听见民众都在自己帐篷门口哭泣，以致耶和华大发烈怒。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:12; 出埃及记 5:22; 耶利米书 15:10"> 他对耶和华说：“你为什么苦待仆人？我做了什么令你不悦的事，你竟把管理这些民众的重担放在我身上？</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 49:23; 以赛亚书 40:11; 帖撒罗尼迦前书 2:7"> 难道是我孕育生养了他们吗？为什么你要我像父亲呵护吃奶的婴儿一样，把他们抱到你应许给他们祖先的地方呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:33; 马可福音 8:4; 约翰福音 6:5–9"> 他们都哭着向我要肉吃，我去哪里找肉给他们吃呢？</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 18:18; 申命记 1:9–12; 哥林多后书 2:16"> 管理民众的责任实在是太重了，我一个人担当不起啊！</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:20–24; 列王纪上 19:4; 约拿书 4:3"> 你既然这样对待我，求你施恩杀了我吧，别让我受苦了！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:1; 出埃及记 24:9; 申命记 16:18"> 耶和华对摩西说：“你给我招聚七十个以色列人的长老，就是你所了解的长老和首领，把他们带到会幕，让他们站在你身边。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:25; 撒母耳记上 10:6; 哥林多前书 12:4–11"> 我要在那里降临，对你说话，把降在你身上的灵也赐给他们，让他们为你分担管理民众的责任，免得你独自承担。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 19:10; 使徒行传 7:39; 出埃及记 16:3–7"> 你要叫民众洁净自己，明天就会有肉吃。因为我听见了他们哭着要肉吃、说埃及的日子更好，我必给他们肉吃。</span>
<span className="v" id="v19" data-v="19"> 他们将不止吃一天、两天、五天、十天或二十天，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:15; 民数记 21:5; 诗篇 78:27–30"> 而是要吃整整一个月，直到肉从他们鼻孔里喷出来，令他们厌腻。因为他们厌弃住在他们中间的我，在我面前哭诉，后悔离开埃及。”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:37; 民数记 1:46; 创世记 12:2"> 摩西说：“和我同行的，仅男子就有六十万，你还说要让他们吃整整一个月的肉！</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:33; 列王纪下 7:2; 约翰福音 6:9"> 就是把牛羊都宰了，够他们吃吗？就是把海里的鱼都捕来，够他们吃吗？”</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:1; 以赛亚书 50:2; 创世记 18:14"> 耶和华说：“难道我的臂膀短小无力吗？你很快将看见我的话会不会应验。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 11:16; 民数记 11:26"> 摩西就出去把耶和华的话转告民众，又召集了七十位长老，叫他们站在会幕周围。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 11:17; 约珥书 2:28–29; 撒母耳记上 10:10"> 耶和华在云中降临，对摩西说话，把降在摩西身上的灵也赐给七十位长老。灵一降在他们身上，他们就说起预言来，但只说了这一次。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 36:5; 撒母耳记上 20:26; 撒母耳记上 10:22"> 七十位长老中的伊利达和米达没有到会幕去，但耶和华的灵也降在他们身上，他们就在营中说起预言来。</span>
<span className="v" id="v27" data-v="27"> 有一个青年跑去禀告摩西说：“伊利达和米达正在营中说预言。”</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:38–40; 路加福音 9:49–50; 约翰福音 3:26"> 摩西拣选的助手嫩的儿子约书亚就说：“我主摩西，请你禁止他们。”</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 14:5; 马太福音 9:37–38; 路加福音 10:2"> 摩西说：“你是为我的缘故而嫉妒吗？愿耶和华的子民都成为先知！愿耶和华把祂的灵降在他们身上！”</span>
<span className="v" id="v30" data-v="30"> 之后，摩西和以色列的长老都返回营中。</span>
</div>
</div>

## 耶和华赐下鹌鹑

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 16:13; 诗篇 105:40; 诗篇 78:26–29"> 耶和华刮起一阵风，把鹌鹑从海面刮到营地四周，约一米厚，方圆数公里。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 45:11; 出埃及记 16:36"> 民众花了两天一夜的时间去捕捉鹌鹑，每人至少捉了一吨半。他们把鹌鹑摊在营地的周围。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 78:30–31; 诗篇 106:14–15; 民数记 25:9"> 他们口中的肉还没嚼烂，耶和华的怒气就已向他们发作，降下了大灾。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 9:22; 哥林多前书 10:6; 民数记 33:16"> 因此，那地方叫基博罗·哈他瓦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基博罗·哈他瓦”意思是“贪欲之墓”。">a</a></sup>，因为那些贪食之徒埋葬在那里。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 33:17; 民数记 12:16; 申命记 1:1"> 民众从基博罗·哈他瓦前往哈洗录，在哈洗录住了下来。</span>
</div>

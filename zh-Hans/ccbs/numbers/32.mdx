## 约旦河东的支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:32; 民数记 32:3; 创世记 13:10–11"> 吕便和迦得的子孙有许多牲畜，他们见雅谢和基列适于放牧，</span>
<span className="v" id="v2" data-v="2"> 就来见摩西、以利亚撒祭司和会众的首领，说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 48:34; 以赛亚书 16:8–9; 民数记 32:34–38"> “亚他录、底本、雅谢、宁拉、希实本、以利亚利、示班、尼波和比稳——</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:34; 申命记 2:24–35; 民数记 21:24"> 这些耶和华为以色列会众攻取的地方适于放牧，而仆人们有许多牲畜。</span>
<span className="v" id="v5" data-v="5" data-xref="路得记 2:10; 约书亚记 7:7; 耶利米书 31:2"> 如果你们恩待我们，请将这些地方赐给我们作产业，别让我们过约旦河了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 13:5; 撒母耳记下 11:11; 腓立比书 2:4"> 摩西对他们说：“难道你们的同胞去打仗，你们却坐在这里吗？</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27–4; 民数记 32:9; 申命记 1:28"> 你们为何使以色列人军心动摇，不敢进入耶和华所赐之地？</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 1:19–25; 民数记 14:2; 民数记 13:2–26"> 从前我在加低斯·巴尼亚派你们的祖先去打探那地方的时候，他们就是这样。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 13:23–10; 申命记 1:24–28"> 他们到以实各谷打探那地方，回来后竟动摇军心，使以色列人不敢进入耶和华所赐之地。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:11; 诗篇 95:11; 以西结书 20:15"> 那天耶和华发怒，起誓说，</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 14:28–30; 民数记 14:24; 民数记 26:2"> ‘从埃及出来、二十岁以上的人都看不到我起誓要赐给亚伯拉罕、以撒和雅各的土地，因为他们没有一心追随我；</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 1:36; 民数记 14:30; 民数记 14:24"> 只有基尼洗族耶孚尼的儿子迦勒和嫩的儿子约书亚可以看到，因为他们一心追随我。’</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:5; 民数记 14:33–35; 希伯来书 3:16–19"> 耶和华向以色列人发怒，使他们在旷野漂泊了四十年，直到在耶和华面前作恶的那一代都死了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 诗篇 78:57; 马太福音 23:31–33"> “现在，你们这群罪人的后代竟然重蹈前人的覆辙，加剧耶和华向以色列所发的怒气。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:11–12; 历代志下 15:2; 历代志下 7:19–22"> 如果你们离弃祂，祂必再次把以色列人丢弃在旷野，这样你们就毁了整个民族。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 33:17; 民数记 34:22"> 他们上前对摩西说：“我们要在这里为牲畜建棚圈，为家小筑城邑，</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 4:12–13; 民数记 32:29–32; 申命记 3:18–20"> 让他们留在坚固的城内，免受当地居民的威胁。然后我们必拿起兵器率先上阵，直到帮其他以色列同胞夺取他们的土地。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 22:1–5"> 在其他同胞占领各自的产业之前，我们决不回家。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 13:8; 约书亚记 12:1–6; 民数记 34:15"> 但我们不会跟他们在约旦河西岸分土地，我们已经得到约旦河东边作产业。”</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:12–13; 申命记 3:18–20; 约书亚记 1:13–15"> 摩西说：“如果你们信守承诺，拿起兵器在耶和华面前出战，</span>
<span className="v" id="v21" data-v="21"> 你们全军就要在耶和华面前渡过约旦河，直到祂赶走祂面前的仇敌，</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 22:9; 约书亚记 22:4; 申命记 3:20"> 征服那地方。之后，你们才可以回家，才算在耶和华和以色列人面前尽了自己的责任，这地方就在耶和华面前归给你们作产业。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:12; 箴言 13:21; 创世记 44:16"> 但你们如果不这样做，就是得罪耶和华，必难逃罪责。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 32:16; 民数记 30:2; 民数记 32:34–42"> 你们现在去为家小筑城邑，为牛羊建棚圈吧，但别忘了信守承诺。”</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 1:13–14"> 迦得和吕便的子孙对摩西说：“仆人们一定遵命而行。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 1:14"> 我们的妻子、孩子、牛羊等牲畜都会留在基列的各城。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:12; 民数记 32:17; 民数记 12:11"> 仆人当中所有能上阵打仗的人都会照你的吩咐在耶和华面前过河作战。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 1:13"> 于是，摩西对以利亚撒祭司、嫩的儿子约书亚和以色列各支派的族长说：</span>
<span className="v" id="v29" data-v="29"> “如果迦得和吕便子孙中所有能上阵打仗的人，在耶和华面前跟你们一同过河作战，你们征服那片土地以后，就要把基列给他们作产业。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:19"> 如果他们不带着兵器跟你们一起过河作战，就只能在迦南与你们同分产业。”</span>
<span className="v" id="v31" data-v="31"> 迦得和吕便的子孙再次说：“凡耶和华所吩咐的，仆人们一定照办。</span>
<span className="v" id="v32" data-v="32"> 我们一定带着兵器在耶和华面前过河，进入迦南，但我们要拥有约旦河东边作产业。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 12:6; 申命记 29:8; 申命记 3:12–17"> 摩西就把亚摩利王西宏和巴珊王噩的国土及周围的城邑，都给了迦得的子孙、吕便的子孙和约瑟儿子玛拿西的半个支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 2:36; 民数记 32:3; 以赛亚书 17:2"> 迦得的子孙重建了底本、亚他录、亚罗珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 32:1; 民数记 32:3"> 亚他录·朔反、雅谢、约比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 32:3"> 伯·宁拉和伯·哈兰，使之成为坚固的城池，并建了羊圈。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:27; 民数记 32:3; 以赛亚书 15:4"> 吕便的子孙重建了希实本、以利亚利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 46:1; 民数记 32:3; 约书亚记 23:7"> 尼波、巴力·免和西比玛。他们为重建的城邑起了新名字，如尼波和巴力·免。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 50:23; 约书亚记 17:1; 民数记 26:29"> 玛拿西之子玛吉的子孙占领了基列，赶走了那里的亚摩利人。</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 17:1; 约书亚记 13:29–31; 申命记 3:13–15"> 摩西就把基列赐给玛拿西的儿子玛吉，他便住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 3:14; 士师记 10:4; 约书亚记 13:30"> 玛拿西的子孙雅珥占领了基列的村庄，将它们改名为哈倭特·雅珥。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 49:11; 撒母耳记下 18:18"> 挪巴占领了基纳及其周围的村庄，就按自己的名字称基纳为挪巴。</span>
</div>
</div>

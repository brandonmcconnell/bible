## 女儿的继承权

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:33; 加拉太书 3:28; 历代志上 7:15"> 西罗非哈是约瑟之子玛拿西的玄孙、玛吉的曾孙、基列的孙子、希弗的儿子。他的女儿是玛拉、挪阿、曷拉、密迦和得撒。她们前来，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 15:33–34; 申命记 17:8–10; 出埃及记 18:19–26"> 站在会幕门口对摩西、以利亚撒祭司、众首领和全体会众说：</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:64–65; 以西结书 18:4; 民数记 14:35"> “我们的父亲死在旷野，他并没有跟可拉一伙一起反叛耶和华，而是因自己的罪而死，没有留下儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:4; 诗篇 109:13; 出埃及记 32:11"> 难道因为他没有儿子，他的名字就要从族中消失吗？请让我们在父亲的家族中分一份产业吧。”</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 24:12–13; 约伯记 23:4; 箴言 3:5–6"> 摩西就把她们的请求呈到耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:28; 诗篇 68:5–6"> 耶和华对摩西说：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 3:28; 耶利米书 49:11; 约书亚记 17:4"> “西罗非哈的女儿说得有理。你要从她们父亲的家族中分一份产业给她们，让她们继承父亲的产业。</span>
<span className="v" id="v8" data-v="8"> 你要告诉以色列人，‘人死后如果没有儿子，就由女儿继承产业；</span>
<span className="v" id="v9" data-v="9"> 如果没有女儿，就由其兄弟继承；</span>
<span className="v" id="v10" data-v="10"> 如果没有兄弟，就由其父的兄弟继承；</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:29; 路得记 4:3–6; 耶利米书 32:8"> 如果其父没有兄弟，就由其族中最近的亲属继承。’”这是耶和华吩咐摩西颁布给以色列人的律例。</span>
</div>
</div>

## 约书亚接替摩西做首领

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 33:47–48; 申命记 34:1–4; 申命记 3:23–27"> 耶和华对摩西说：“你上这亚巴琳山去看看我赐给以色列人的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 10:6; 民数记 31:2; 民数记 20:24–28"> 看了以后，你就要像你哥哥亚伦一样归到祖先那里了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:37; 民数记 20:8–13; 出埃及记 17:7"> 因为会众在荀旷野反叛我的时候，你们二人违背我的命令，在取水的事上没有在他们面前尊我为圣。”这是指米利巴泉事件，发生在荀旷野的加低斯。</span>
<span className="v" id="v15" data-v="15"> 摩西对耶和华说：</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 16:22; 耶利米书 3:15; 希伯来书 12:9"> “耶和华啊，你是赐人生命的上帝，求你立一个人做会众的首领，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:5; 马可福音 6:34; 列王纪上 22:17"> 在前面带领他们或进或退，免得你的会众像没有牧人的羊群。”</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 34:9; 民数记 27:23; 创世记 41:38"> 耶和华对摩西说：“嫩的儿子约书亚心里有圣灵，你把他召来，把手按在他身上，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 3:28; 申命记 31:7–8; 申命记 31:23"> 让他站在以利亚撒祭司和全体会众面前，当着他们的面任命他做首领，</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 1:16–18; 撒母耳记上 10:9; 列王纪下 2:9–10"> 把你的权柄赐给他，使以色列全体会众都听从他。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 9:14; 撒母耳记上 28:6; 出埃及记 28:30"> 他要去以利亚撒祭司那里，让祭司借着乌陵为他求问我。他和全体会众或进或出，都要听从以利亚撒的指示。”</span>
<span className="v" id="v22" data-v="22"> 摩西遵命而行，把约书亚召来，让他站在以利亚撒祭司和全体会众面前，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 3:28; 民数记 27:19; 申命记 31:7–8"> 然后照耶和华对摩西的吩咐把手按在他头上，任命他做首领。</span>
</div>
</div>

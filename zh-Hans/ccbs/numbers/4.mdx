## 哥辖子孙的职责

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 3:27; 民数记 3:19"> “你要按宗族和家系统计利未人中哥辖子孙的人数，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:23; 历代志上 23:3–5; 列王纪下 11:4–12"> 登记所有可在会幕司职的三十岁到五十岁的男子。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 4:19; 马可福音 13:34; 民数记 4:30"> 他们在会幕里的职责是照料至圣之物。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:51; 希伯来书 9:3; 出埃及记 40:3"> “拔营出发的时候，亚伦父子们要进会幕解下圣所和至圣所之间的幔子，用它遮盖约柜，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:13–15; 出埃及记 35:19; 民数记 4:7–8"> 再在上面依次盖上海狗皮和纯蓝色的布，然后穿上抬约柜的横杠。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 24:5–8; 出埃及记 37:10–16; 出埃及记 25:23–30"> “要在摆放供饼的桌子上铺一块蓝布，把盘、碟及献酒用的杯和瓶摆在上面。桌上要有常供的饼。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:6–7; 民数记 4:11–13; 民数记 4:9"> 这些东西上面要盖朱红色的布，再盖上海狗皮，然后穿上抬桌子的横杠。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:31–39; 出埃及记 37:17–24; 启示录 1:20–1"> “要用蓝布把灯台、灯盏、灯剪、灯盘和盛油的器皿全遮盖起来，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:12; 民数记 4:6"> 再在上面盖上海狗皮，然后放在抬架上。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:5; 出埃及记 30:1–19; 出埃及记 40:26–27"> “金坛上面要盖蓝色布，再盖上海狗皮，穿上抬金坛的横杠。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:29; 出埃及记 25:9; 历代志下 4:22"> “圣所里面供职用的一切器皿都要用蓝色布包好，盖上海狗皮，放在抬架上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 6:12–13; 出埃及记 39:1; 出埃及记 39:41"> “要清除祭坛上的灰烬，铺上紫色布，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:19; 出埃及记 38:1–7"> 然后把供职用的火鼎、肉叉、铲、碗等所有的祭坛器具都放在上面，再盖上海狗皮，穿上抬祭坛的横杠。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 6:6–7; 民数记 7:9; 申命记 31:9"> “拔营出发时，要等到亚伦父子们把圣所和圣所的所有器具都盖好后，哥辖的子孙才可以来抬。他们负责抬这些会幕的器具，但不可触摸这些圣物，免得死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:6; 利未记 24:2; 出埃及记 30:23–38"> 亚伦祭司的儿子以利亚撒负责管理整个圣幕，以及里面的灯油、香料、日常献的素祭、膏油及一切器具和物品。”</span>
<span className="v" id="v17" data-v="17"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 6:6–7; 民数记 17:10; 民数记 18:5"> “不可让哥辖宗族在利未人中灭绝。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 4:15"> 他们走近至圣之物以前，亚伦父子们要先进去指派他们做什么、抬什么，以免他们死亡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 6:19; 出埃及记 19:21; 民数记 4:15"> 他们不可进去看圣物，一刻都不可，免得死亡。”</span>
</div>
</div>

## 革顺子孙的职责

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和华对摩西说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 3:18; 民数记 3:21; 民数记 3:24"> “你要按宗族和家系统计革顺子孙的人数，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 4:3; 提摩太前书 1:18; 哥林多前书 9:7"> 登记所有可在会幕司职的三十岁到五十岁的男子。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:19; 民数记 4:31–32; 民数记 4:47"> 以下是革顺宗族负责的搬运工作及其他事务：</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 3:25–26; 出埃及记 26:14; 民数记 7:5–7"> “他们要抬圣幕的幔子、会幕、会幕顶盖、顶盖上的海狗皮、会幕门帘、</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 27:9"> 围绕圣幕和祭坛的院子的帷幔、院门门帘、绳索及司职用的一切器具，还负责其他相关事务。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前书 11:2"> 你们要把抬的任务分配给革顺的子孙，他们要遵照亚伦父子们的吩咐司职。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 4:33; 哥林多前书 12:5–6"> 这是革顺宗族的人在会幕里的职责，他们要按祭司亚伦的儿子以他玛的吩咐司职。</span>
</div>
</div>

## 米拉利子孙的职责

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 3:33–35"> “你要按宗族和家系统计米拉利子孙的人数，</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 4:3; 民数记 4:23; 提摩太后书 2:4"> 登记所有可在会幕司职的三十岁到五十岁的男子。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 3:36–37; 出埃及记 26:15; 民数记 7:8–9"> 他们在会幕里负责抬圣幕的木板、横闩、柱子、带凹槽的底座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 38:21; 历代志上 9:29; 民数记 3:8"> 院子四周的柱子及其带凹槽的底座、橛子、绳索和其他相关器具。你们要把当抬的物件一一指派给他们。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 4:28; 约书亚记 3:6; 以赛亚书 3:6"> 这是米拉利宗族的人在会幕的职责，由祭司亚伦的儿子以他玛监督。”</span>
<span className="v" id="v34" data-v="34"> 于是，摩西、亚伦和会众的首领按宗族和家系统计哥辖的子孙，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 23:24; 民数记 4:23; 历代志上 23:3"> 登记了所有可在会幕司职的三十岁到五十岁的男子，</span>
<span className="v" id="v36" data-v="36"> 共两千七百五十人。</span>
<span className="v" id="v37" data-v="37"> 这是哥辖宗族在会幕司职的人数，是摩西和亚伦照耶和华的吩咐统计的。</span>
<span className="v" id="v38" data-v="38"> 按宗族和家系统计，革顺的子孙中三十岁到五十岁、可在会幕司职的共两千六百三十人。</span>
<span className="v" id="v41" data-v="41"> 这是革顺宗族在会幕司职的人数，是摩西和亚伦照耶和华的吩咐统计的。</span>
<span className="v" id="v42" data-v="42"> 按宗族和家系统计，米拉利的子孙中三十岁到五十岁、可在会幕司职的共三千二百人。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 4:29"> 这是米拉利宗族的人数，是摩西和亚伦照耶和华的吩咐统计的。</span>
<span className="v" id="v46" data-v="46"> 摩西、亚伦和以色列人的首领按宗族和家系统计了利未人的人数，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前书 12:4–31; 罗马书 12:6–8; 民数记 4:3"> 三十岁到五十岁、可司职和搬运会幕器具的利未人，共八千五百八十人。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 1:54; 民数记 4:31; 民数记 4:15"> 照耶和华对摩西的吩咐，每个人都被统计在内，都有指定的职责和当抬的器具。这样，照耶和华对摩西的吩咐，人口统计完毕。</span>
</div>
</div>

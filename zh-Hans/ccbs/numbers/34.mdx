## 迦南的疆域

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:8; 诗篇 105:11; 申命记 1:7–8"> “你把以下指示告诉以色列人。 “你们进入赐给你们作产业的迦南后，你们四境的疆界如下：</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:3; 以西结书 47:13; 约书亚记 3:16"> “南部疆界从荀旷野沿着以东边界延伸，东起死海的尽头，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 32:8; 约书亚记 15:3–4; 民数记 13:26"> 往南至亚克拉滨坡南面，经荀直到加低斯·巴尼亚南面，再延伸至哈萨·亚达，经押们，</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 15:4; 创世记 15:18; 列王纪上 8:65"> 转向埃及河，直到地中海。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:4; 以西结书 47:20; 以西结书 47:15"> “西部以地中海为界，这是你们西部的边界。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:37; 民数记 34:6; 民数记 34:3"> “北部疆界从地中海开始直到何珥山，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 13:21; 列王纪下 14:25; 约书亚记 13:5–6"> 从何珥山再到哈马口，经西达达、</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 47:17"> 西斐仑直到哈萨·以难。</span>
<span className="v" id="v10" data-v="10"> “东部疆界从哈萨·以难一直划到示番，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:33; 申命记 3:17; 约书亚记 11:2"> 从示番往南到亚延东面的利比拉，再往南到基尼烈湖东岸。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 34:3; 创世记 13:10; 创世记 19:24–26"> 然后沿约旦河南下直到死海。这是你们国土四面的疆界。”</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 34:1; 约书亚记 14:1–5"> 摩西又对以色列人说：“这就是耶和华吩咐用抽签的方式分给你们九个半支派的土地。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:33; 民数记 32:23; 约书亚记 14:2–3"> 吕便支派和迦得支派已经按着家系得到了他们的产业，玛拿西半个支派也得到了他们的产业。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:32"> 这两个半支派的产业在耶利哥对面的约旦河东岸。”</span>
</div>
</div>

## 分地的首领

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华对摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 14:1; 约书亚记 19:51; 民数记 13:8"> “负责给你们分地的是以利亚撒祭司和嫩的儿子约书亚。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:4–16"> 每支派要选出一位首领来协助分地。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:65; 民数记 13:30; 民数记 14:24"> “以下是这些首领的名字： 犹大支派耶孚尼的儿子迦勒，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 49:5"> 西缅支派亚米忽的儿子示姆利，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 49:27; 诗篇 68:27"> 便雅悯支派基斯伦的儿子以利达，</span>
<span className="v" id="v22" data-v="22"> 但支派约利的儿子布基，</span>
<span className="v" id="v23" data-v="23"> 约瑟之子玛拿西支派以弗的儿子汉聂，</span>
<span className="v" id="v24" data-v="24"> 以法莲支派拾弗但的儿子基姆利，</span>
<span className="v" id="v25" data-v="25"> 西布伦支派帕纳的儿子以利撒番，</span>
<span className="v" id="v26" data-v="26"> 以萨迦支派阿散的儿子帕铁，</span>
<span className="v" id="v27" data-v="27"> 亚设支派示罗米的儿子亚希忽，</span>
<span className="v" id="v28" data-v="28"> 拿弗他利支派亚米忽的儿子比达黑。”</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:51; 民数记 34:18"> 这些是奉耶和华之命在迦南给以色列人分产业的首领。</span>
</div>
</div>

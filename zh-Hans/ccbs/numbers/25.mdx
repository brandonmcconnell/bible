## 以色列人被诱犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 10:8; 民数记 33:49; 约书亚记 2:1"> 以色列人驻扎在什亭期间，有些人与摩押女子行淫。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:20; 出埃及记 20:5; 出埃及记 34:15–16"> 那些女子邀这些人祭祀她们的神明，他们吃了祭物，并跪拜她们的神明。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 22:17; 诗篇 106:28–29; 何西阿书 9:10"> 结果以色列与巴力·毗珥苟合。耶和华大怒，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 13:17; 申命记 4:3; 申命记 21:23"> 对摩西说：“把为首的人都抓起来，当着我的面在大白天处死他们，以消除我对以色列人的怒气。”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:21; 列王纪上 18:40; 申命记 13:9"> 于是，摩西对以色列的审判官说：“你们各自把手下与巴力·毗珥苟合的人处死。”</span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:17; 民数记 22:4; 耶利米书 36:23"> 摩西和以色列全体会众正在会幕门口痛哭的时候，有个以色列人当着他们的面，把一个米甸女子带进自家的帐篷。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 6:25; 诗篇 106:30; 约书亚记 22:30–31"> 亚伦祭司的孙子、以利亚撒的儿子非尼哈看见了，便起身离开会众，拿着矛枪，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:46–48; 诗篇 106:29–31; 历代志上 21:22"> 跟着进入那人的帐篷，用枪刺透那对男女的腹部。以色列人当中的瘟疫马上止住了，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:8; 申命记 4:3–4; 民数记 25:4–5"> 但已有两万四千人死于瘟疫。</span>
<span className="v" id="v10" data-v="10"> 耶和华对摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 32:21; 诗篇 78:58; 申命记 32:16"> “亚伦祭司的孙子、以利亚撒的儿子非尼哈，消了我对以色列人的怒气。因为在会众中他与我一样痛恨不贞，我才没有愤然消灭他们。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 2:4–5; 玛拉基书 3:1; 以赛亚书 54:10"> 你告诉他，我要赐给他平安的约，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17; 罗马书 10:2–4; 耶利米书 33:22"> 使他和他的后代凭此约可以永远做祭司，因为他为我除掉了不贞之人，为以色列人赎了罪。”</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:23; 民数记 26:14; 历代志下 19:7"> 与米甸女子一同被杀的以色列人名叫心利，是撒路的儿子，是西缅支派的一个族长。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:8; 约书亚记 13:21; 民数记 25:18"> 被杀的米甸女子名叫哥斯比，她父亲苏珥是米甸人的一个族长。</span>
<span className="v" id="v16" data-v="16"> 耶和华对摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 31:1–3; 启示录 18:6"> “你要攻打米甸人，击杀他们。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 2:14; 出埃及记 32:35; 哥林多后书 11:3"> 因为他们心存恶意，在毗珥陷害你们，他们的姊妹——米甸首领的女儿哥斯比诱惑你们，她在毗珥事件招来瘟疫之日被杀。”</span>

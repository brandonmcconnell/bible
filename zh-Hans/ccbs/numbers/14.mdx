## 以色列人发怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 1:45; 民数记 11:1–4"> 当晚，全体会众放声大哭。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 15:24; 出埃及记 17:3; 民数记 16:41"> 全体以色列会众埋怨摩西和亚伦说：“我们还不如死在埃及或旷野！</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:31–32; 耶利米书 9:3; 诗篇 78:40"> 耶和华为什么把我们领到这里来，让我们死于刀下？我们的妻儿必被掳去。我们还不如返回埃及。”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:39; 尼希米记 9:16–17; 申命记 17:16"> 他们彼此议论说：“我们选一位首领带我们回埃及吧！”</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:4; 民数记 16:22; 民数记 16:45"> 摩西和亚伦俯伏在以色列全体会众面前。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:30; 民数记 13:30; 民数记 14:38"> 打探迦南的人中，嫩的儿子约书亚和耶孚尼的儿子迦勒撕裂衣服，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27; 申命记 1:25; 申命记 8:7–9"> 对以色列全体会众说：“我们去打探的地方极其美好。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 22:20; 以赛亚书 62:4; 民数记 13:27"> 如果耶和华喜悦我们，祂必把我们带到那片土地，将那奶蜜之乡赐给我们。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:18; 罗马书 8:31; 申命记 31:6"> 你们不要背叛耶和华，也不要害怕那里的人，他们不过是我们的猎物，他们已失去庇护。耶和华与我们同在，不要怕他们。”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 17:4; 撒母耳记上 30:6; 利未记 9:23"> 但全体会众威胁要用石头打死他们二人。这时耶和华的荣光在会幕中向全体以色列人显现。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:32; 诗篇 106:24; 诗篇 78:22"> 耶和华对摩西说：“这些人藐视我要到何时呢？我在他们中间行了这么多神迹，他们还要不信我到何时呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:10; 民数记 25:9; 撒母耳记下 24:12–15"> 我要用瘟疫毁灭他们，不让他们承受那片土地。但我要使你成为大国，比他们更强盛。”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:23; 以西结书 20:9; 申命记 32:27"> 摩西对耶和华说：“你曾经用大能把以色列人从埃及领出来，埃及人听说这事后，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:14; 出埃及记 33:11; 申命记 5:4"> 一定会告诉迦南的居民。那里的居民早已听说你耶和华与以色列人同在，你面对面向他们显现，你的云彩停留在他们上面，你白天用云柱、黑夜用火柱引导他们。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 6:16"> 如果你把他们全部消灭，那些听过你威名的列国就会议论说，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 9:28; 约书亚记 7:9; 约书亚记 7:7"> ‘耶和华无法把以色列人领到祂起誓要赐给他们的地方，所以在旷野把他们杀了。’</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:6; 马太福音 9:8; 弥迦书 3:8"> 因此，求主彰显伟大的权能，正如你所宣告的，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:6–7; 诗篇 145:8; 出埃及记 20:5"> ‘耶和华不轻易发怒，充满慈爱；祂赦免罪恶和过犯，但决不免除罪责，必向子孙追讨父辈的罪债，直到三四代。’</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:9; 诗篇 78:38; 诗篇 106:45"> 从他们离开埃及直到现在，你一直在饶恕他们，求你以伟大的慈爱再次赦免这些人的罪。”</span>
<span className="v" id="v20" data-v="20" data-xref="弥迦书 7:18–20; 雅各书 5:16; 诗篇 106:23"> 耶和华说：“我听你的祈求，赦免他们。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 72:19; 哈巴谷书 2:14; 以赛亚书 6:3"> 但我凭我的永恒起誓，正如大地充满我的荣耀一样确实，</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 19:3; 创世记 31:7; 出埃及记 32:1"> 他们绝对一个也看不到我起誓要赐给他们祖先的土地，藐视我的人都看不到那片土地。这些人见过我的荣耀，见过我在埃及和旷野所行的神迹，却仍然不听我的话，试探我十次之多。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 14:6–9; 约书亚记 14:6–14; 以弗所书 6:6"> 但我的仆人迦勒力排众议，全心跟从我，所以我必带他进入那片他去过的土地，让他的子孙拥有那片产业。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:40; 民数记 13:29; 诗篇 81:11–13"> 由于亚玛力人和迦南人住在山谷中，明天你们要转回，沿红海的路前往旷野。”</span>
<span className="v" id="v26" data-v="26"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 16:12; 哥林多前书 10:10; 出埃及记 16:28"> “这邪恶的会众向我发怨言要到何时呢？我已听见以色列人对我的埋怨。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:21; 希伯来书 3:17; 民数记 14:2"> 你们去把我的话告诉他们，‘以色列人啊，我凭我的永恒起誓，我必照你们所说的对待你们。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:45; 哥林多前书 10:5; 希伯来书 3:17"> 你们当中凡登记在册、二十岁以上向我发怨言的人，必倒毙在这旷野中，</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 26:65; 民数记 14:38; 申命记 1:36–38"> 除耶孚尼的儿子迦勒和嫩的儿子约书亚之外，你们无人能进入我向你们起誓应许之地。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:39; 诗篇 106:24; 民数记 26:64"> 你们说你们的儿女会被掳去，但我要把他们带到那里，让他们享有那片你们厌弃的土地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 10:5; 民数记 14:29; 希伯来书 3:17"> 而你们必死在这旷野。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 23:35; 民数记 32:13; 申命记 2:14"> 你们的儿女要在旷野飘泊四十年，为你们的不忠而受苦，直到你们都死在旷野。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 4:6; 民数记 13:25; 耶利米书 18:9–10"> 你们打探了那地方四十天，你们要为自己的罪受苦四十年，一年顶一天。那时，你们就知道与我为敌的后果。’</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 23:19; 哥林多前书 10:5; 希伯来书 3:19"> 我耶和华已经说过，我必这样对付这群集合起来与我为敌的邪恶会众。他们必死在旷野，全部丧命。”</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 13:31–33; 民数记 13:4–16"> 摩西派去打探迦南的人回来以后危言耸听，以致全体会众向摩西发怨言。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 10:10; 民数记 16:49; 希伯来书 3:17"> 这些危言耸听的人因而染上瘟疫，死在耶和华面前。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 14:6–10; 民数记 26:65"> 前去打探的人中只有嫩的儿子约书亚和耶孚尼的儿子迦勒得以幸存。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 33:4; 马太福音 8:12; 希伯来书 12:17"> 摩西传达完耶和华的话后，以色列人非常悲伤。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 1:41; 马太福音 7:21–23; 路加福音 13:25"> 他们清早起来上到山顶，说：“我们知罪了，现在我们要去耶和华应许的地方。”</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 24:20; 约伯记 4:9; 耶利米书 2:37"> 摩西说：“你们为什么要违背耶和华的命令？你们不会成功的。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 1:42; 约书亚记 7:8; 约书亚记 7:12"> 不要上去！因为耶和华不与你们同在，你们会被敌人打败。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 13:29; 民数记 14:25; 历代志下 15:2"> 你们会遇见亚玛力人和迦南人，并丧身在他们刀下，因为你们离弃耶和华，祂不再与你们同在。”</span>
<span className="v" id="v44" data-v="44" data-xref="申命记 1:43; 撒母耳记上 4:3–11; 民数记 31:6"> 尽管耶和华的约柜和摩西都没有出营，他们却擅自上山顶去。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 21:3; 士师记 1:17; 申命记 1:44"> 住在山区的亚玛力人和迦南人下来击溃了他们，一路追杀他们到何珥玛。</span>

## 拿细耳人的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:5; 阿摩司书 2:11–12; 罗马书 1:1"> “你把以下条例告诉以色列人：无论男女，如果许愿做拿细耳人，把自己献给耶和华，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前书 5:23; 阿摩司书 2:12"> 就要禁戒淡酒和烈酒、淡酒或烈酒做的醋、葡萄汁、葡萄和葡萄干。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 6:5; 民数记 6:21; 民数记 6:8–9"> 在做拿细耳人期间，葡萄树所结的，包括葡萄核和葡萄皮，都不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 1:11; 士师记 16:17; 士师记 13:5"> 在许愿做拿细耳人期间，不可用剃刀剃头，要任由头发生长，要保持圣洁，一直到献给耶和华的日期满了。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 21:11; 利未记 19:28; 利未记 21:1–3"> 在献给耶和华期间，不可挨近死尸，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 9:6; 利未记 21:1–2; 利未记 21:10–12"> 即使父母或是兄弟姊妹死了，也不可挨近，以免沾染不洁，因为他头上有将自己奉献给上帝的记号。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:17–18"> 在做拿细耳人期间，他是奉献给耶和华的人。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 6:18; 使徒行传 18:18; 利未记 14:9"> 如果有人在他身边暴毙，使他的头发沾染不洁，他要在第七天洁净的日子剃掉头发。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 15:29; 利未记 1:14; 利未记 15:14"> 第八天，他要带两只斑鸠或雏鸽到会幕门口交给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 14:30–31; 利未记 5:8–10"> 祭司要献一只作赎罪祭，另一只作燔祭，为他碰过死尸赎罪。他要在当日使头圣洁，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 5:6; 马太福音 24:13; 利未记 14:24"> 重新开始过奉献给耶和华的日子，还要带一只一岁的公羊羔作赎过祭。他以前做拿细耳人的日子无效，因为他沾染了不洁之物。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 21:26"> “献给耶和华的日子期满后，拿细耳人要遵行以下条例。他要被带到会幕门口，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 3:6; 利未记 4:32; 利未记 4:2–3"> 在那里献给耶和华一只毫无残疾、一岁的公羊羔作燔祭，一只毫无残疾、一岁母羊羔作赎罪祭，一只毫无残疾的公绵羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:4; 出埃及记 29:2; 民数记 15:10"> 一篮调油的无酵细面饼和涂油的无酵薄饼，以及素祭和奠祭。</span>
<span className="v" id="v16" data-v="16"> 祭司要把这些祭物带到耶和华面前，为他献上赎罪祭和燔祭，</span>
<span className="v" id="v17" data-v="17"> 然后把公绵羊和那篮无酵饼献给耶和华作平安祭，再献上素祭和奠祭。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:9; 使徒行传 18:18"> 拿细耳人要在会幕门口剃掉作为奉献记号的头发，把头发放在平安祭下面的火里烧掉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 2:15; 利未记 7:30; 出埃及记 29:23–28"> 拿细耳人剃头以后，祭司要取出一条煮好的公绵羊前腿，再从篮中拿出一块无酵饼和一块无酵薄饼，放在拿细耳人手中。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 9:7; 出埃及记 29:27–28; 民数记 5:25"> 然后，祭司要把这些祭物作为摇祭在耶和华面前摇一摇。这些祭物与作摇祭的胸肉和作举祭的腿肉一样，都是归给祭司的圣物。此后，拿细耳人便可以喝酒。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 以斯拉记 2:69; 民数记 5:29"> “以上是许愿献供物给耶和华的拿细耳人当守的条例和当献的祭物。但如果他额外许愿献上力所能及之物，就必须还所许的愿。”</span>
</div>
</div>

## 祭司的祝福

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 21:5; 历代志上 23:13; 创世记 48:20"> “你告诉亚伦父子们要这样为以色列人祝福，</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:23; 诗篇 121:4–7; 腓立比书 4:7"> ‘愿耶和华赐福给你，保护你；</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 80:19; 诗篇 119:135; 诗篇 31:16"> 愿耶和华以祂的容光照耀你，施恩给你；</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 4:6; 诗篇 29:11; 帖撒罗尼迦后书 3:16"> 愿耶和华笑颜垂顾你，赐你平安。’</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 7:14; 但以理书 9:18–19; 申命记 28:10"> 他们要奉我的名为以色列人祝福，我必赐福给他们。”</span>
</div>

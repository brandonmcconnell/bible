## 日常献祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 3:11; 创世记 8:21; 民数记 9:2–3"> “你要吩咐以色列人，在规定的时间献上蒙我悦纳的馨香火祭，作为我的食物。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 6:9; 但以理书 11:31; 约翰福音 1:29"> 以下是他们要献给耶和华的火祭：每天两只毫无残疾、一岁的公羊羔作日常燔祭，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 9:21; 列王纪上 18:36; 出埃及记 12:6"> 早晨和黄昏各献一只，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 2:1; 出埃及记 16:36; 出埃及记 29:38–42"> 同时献上一公斤细面粉，并调上一升橄榄油作素祭。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 5:25; 利未记 6:9; 诗篇 50:8"> 这是在西奈山上规定的日常燔祭，是献给耶和华的馨香火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 29:42; 民数记 28:14; 以赛亚书 57:6"> 与每只羊羔一同献上的还有一升酒，要将酒洒在圣所，作为献给耶和华的奠祭。</span>
<span className="v" id="v8" data-v="8"> 黄昏献第二只羊羔时，也要跟早晨一样同时献上素祭和奠祭，作为蒙耶和华悦纳的馨香火祭。</span>
</div>
</div>

## 安息日献的祭

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:13; 诗篇 92:1–4; 启示录 1:10"> “安息日，要献两只毫无残疾、一岁的公羊羔，同时献上奠祭以及两公斤调油的细面粉作素祭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 46:4–5; 民数记 29:22; 民数记 29:31"> 这是在日常燔祭和奠祭以外安息日所献的燔祭。</span>
</div>
</div>

## 初一献的祭

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 10:10; 以西结书 46:6; 以斯拉记 3:5"> “在朔日，要给耶和华献燔祭——两头公牛犊、一只公绵羊和七只一岁公羊羔，都要毫无残疾。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 15:4–12; 以西结书 46:5–7; 民数记 29:10"> 同时要献上调了油的细面粉作素祭，每头公牛需献三公斤素祭，每只公绵羊需献两公斤素祭，</span>
<span className="v" id="v13" data-v="13"> 每只公羊羔需献一公斤素祭。这馨香的燔祭是献给耶和华的火祭。</span>
<span className="v" id="v14" data-v="14"> 献燔祭时要同时献上奠祭，每头公牛需献二升奠酒，每只公绵羊需献一升半奠酒，每只羊羔需献一升奠酒。这是朔日要献的燔祭，一年之中月月如此。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 28:3; 民数记 28:22; 民数记 15:24"> 除了日常的燔祭和奠祭以外，还要把一只公山羊献给耶和华作赎罪祭。</span>
</div>
</div>

## 逾越节献的祭

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 16:1–8; 出埃及记 12:18; 利未记 23:5–8"> “一月十四日是耶和华的逾越节，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:6; 出埃及记 23:15; 出埃及记 13:6"> 十五日开始节庆，你们要连续七天吃无酵饼。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 12:16; 利未记 23:7–8"> 第一天要举行圣会，不可做日常工作。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 15:21; 以西结书 45:21–25; 民数记 29:8"> 你们要把毫无残疾的两头公牛犊、一只公绵羊和七只一岁的公羊羔，献给耶和华作燔祭；</span>
<span className="v" id="v20" data-v="20"> 同时要献上调了油的细面粉作素祭，每头公牛需献三公斤素祭，每只公绵羊需献两公斤素祭，</span>
<span className="v" id="v21" data-v="21"> 每只公羊羔需献一公斤素祭；</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 8:3"> 同时还要献一只公山羊作赎罪祭，为你们赎罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 28:3; 民数记 28:10"> 除了早晨献的日常燔祭以外，要献上这些祭物。</span>
<span className="v" id="v24" data-v="24"> 接连七天，除了日常的燔祭和同献的奠祭以外，还要照上面的规定给耶和华献上馨香的火祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:8; 民数记 28:18; 出埃及记 13:6"> 第七天，你们要举行圣会，不可做日常工作。</span>
</div>
</div>

## 七七收获节献的祭

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:16; 出埃及记 34:22; 利未记 23:10"> “七七收获节庄稼初熟之日，就是你们把新素祭献给耶和华的日子，要召开圣会，不可做日常工作。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 23:18–19; 民数记 28:11; 民数记 28:19"> 你们要把两头公牛犊、一只公绵羊和七只一岁的公羊羔，献给耶和华作馨香的燔祭。</span>
<span className="v" id="v28" data-v="28"> 同时要献上调了油的细面粉作素祭，每头公牛需献三公斤素祭，每只公绵羊需献两公斤素祭，</span>
<span className="v" id="v29" data-v="29"> 每只公羊羔需献一公斤素祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 28:15; 民数记 28:22; 彼得前书 2:24"> 此外，还要献上一只公山羊作赎罪祭，为你们赎罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 28:19; 民数记 28:3; 玛拉基书 1:13–14"> 除了日常的燔祭和同献的素祭以外，还要献上奠祭。祭牲不可有残疾。</span>
</div>

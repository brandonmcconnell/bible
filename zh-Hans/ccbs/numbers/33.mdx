## 从埃及到约旦河

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 77:20; 弥迦书 6:4; 出埃及记 12:51"> 以下是以色列人在摩西和亚伦的领导下离开埃及列队行军的路线。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:17–23; 申命记 10:11; 民数记 10:6"> 摩西遵照耶和华的吩咐记录启行的地点，以下是他们停留过的地方。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:8; 出埃及记 12:37; 出埃及记 13:4"> 一月十五日，即逾越节的第二天，埃及人眼睁睁地看着以色列人昂首挺胸地离开了兰塞。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 12:12; 以赛亚书 19:1; 出埃及记 18:11"> 当时埃及人正埋葬他们的长子，耶和华击杀了他们当中的长子，并惩罚了他们的众神明。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 12:37"> 以色列人从兰塞启行，至疏割扎营；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:20"> 从疏割启行，至旷野边界的以倘扎营；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 14:2; 出埃及记 14:9; 民数记 33:8"> 从以倘启行，又转到巴力·洗分对面的比哈·希录，在密夺附近扎营；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 15:22–26; 出埃及记 14:21–31"> 从比哈·希录启行，经过红海到书珥旷野，在伊坦旷野走了三天，至玛拉扎营；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:27"> 从玛拉启行，至以琳扎营，那里有十二股水泉和七十棵棕树；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:1; 出埃及记 17:1"> 从以琳启行，至红海岸边扎营；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:1"> 从红海启行，至汛旷野扎营；</span>
<span className="v" id="v12" data-v="12"> 从汛旷野启行，至脱加扎营；</span>
<span className="v" id="v13" data-v="13"> 从脱加启行，至亚录扎营；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 17:1–8; 出埃及记 19:2"> 从亚录启行，至利非订扎营，在那里民众没有水喝；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:1–2; 出埃及记 16:1"> 从利非订启行，至西奈旷野扎营；</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:34; 民数记 10:11–13; 民数记 10:33"> 从西奈旷野启行，至基博罗·哈他瓦扎营；</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:35"> 从基博罗·哈他瓦启行，至哈洗录扎营；</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 12:16"> 从哈洗录启行，至利提玛扎营；</span>
<span className="v" id="v19" data-v="19"> 从利提玛启行，至临门·帕烈扎营；</span>
<span className="v" id="v20" data-v="20"> 从临门·帕烈启行，至立拿扎营；</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:1"> 从立拿启行，至勒撒扎营；</span>
<span className="v" id="v22" data-v="22"> 从勒撒启行，至基希拉他扎营；</span>
<span className="v" id="v23" data-v="23"> 从基希拉他启行，至沙斐山扎营；</span>
<span className="v" id="v24" data-v="24"> 从沙斐山启行，至哈拉大扎营；</span>
<span className="v" id="v25" data-v="25"> 从哈拉大启行，至玛吉希录扎营；</span>
<span className="v" id="v26" data-v="26"> 从玛吉希录启行，至他哈扎营；</span>
<span className="v" id="v27" data-v="27"> 从他哈启行，至他拉扎营；</span>
<span className="v" id="v28" data-v="28"> 从他拉启行，至密加扎营；</span>
<span className="v" id="v29" data-v="29"> 从密加启行，至哈摩拿扎营；</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 10:5–6"> 从哈摩拿启行，至摩西录扎营；</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 10:6; 创世记 36:27; 历代志上 1:43"> 从摩西录启行，至比尼·亚干扎营；</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 10:7"> 从比尼·亚干启行，至曷·哈吉甲扎营；</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 10:7"> 从曷·哈吉甲启行，至约巴他扎营；</span>
<span className="v" id="v34" data-v="34"> 从约巴他启行，至阿博拿扎营；</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 2:8; 列王纪上 9:26; 列王纪上 22:48"> 从阿博拿启行，至以旬·迦别扎营；</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 20:1; 民数记 27:14; 申命记 32:51"> 从以旬·迦别启行，至荀旷野的加低斯扎营；</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:4; 民数记 20:22–23; 民数记 20:16"> 从加低斯启行，至以东边界的何珥山扎营。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="申命记 10:6; 申命记 32:50; 民数记 20:24–28"> 以色列人离开埃及后的第四十年五月一日，亚伦祭司遵照耶和华的吩咐上了何珥山，并在那里离世，</span>
<span className="v" id="v39" data-v="39"> 享年一百二十三岁。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数记 21:1–9"> 在南地的迦南人亚拉得王得知了以色列人要来的消息。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 21:4"> 以色列人从何珥山启行，至撒摩拿扎营；</span>
<span className="v" id="v42" data-v="42"> 从撒摩拿启行，至普嫩扎营；</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 21:10"> 从普嫩启行，至阿伯扎营；</span>
<span className="v" id="v44" data-v="44" data-xref="民数记 21:11"> 从阿伯启行，至摩押边境的以耶·亚巴琳扎营；</span>
<span className="v" id="v45" data-v="45"> 从以耶·亚巴琳启行，至底本·迦得扎营；</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米书 48:18; 以西结书 6:14; 以赛亚书 15:2"> 从底本·迦得启行，至亚门·低比拉太音扎营；</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 32:49; 申命记 34:1; 民数记 27:12"> 从亚门·低比拉太音启行，至尼波对面的亚巴琳山扎营；</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 22:1"> 从亚巴琳山启行，至耶利哥对面、约旦河边的摩押平原扎营。</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 2:1; 约书亚记 13:20; 民数记 25:1–9"> 他们沿着约旦河在摩押平原扎营，营地从伯·耶施末一直延伸到亚伯·什亭。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民数记 33:48–49"> 耶和华在耶利哥对面、约旦河边的摩押平原对摩西说：</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 3:17; 申命记 9:1; 申命记 7:1"> “你告诉以色列人，‘你们过约旦河进了迦南以后，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及记 23:24; 利未记 26:1; 申命记 20:16–18"> 一定要赶走当地的居民，毁掉他们一切的石像和铸像，拆毁他们所有的丘坛。</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 11:31; 诗篇 115:16; 申命记 32:8"> 你们要占领那片土地，住在那里，因为我已经把那里赐给你们作产业了。</span>
<span className="v" id="v54" data-v="54" data-xref="民数记 26:53–56; 约书亚记 18:11–48; 约书亚记 15:1–12"> 你们要按宗族抽签分配土地，人口多的多分，人口少的少分，抽到哪块地就得哪块地。你们要按照支派分配土地。</span>
<span className="v" id="v55" data-v="55" data-xref="士师记 2:3; 诗篇 106:34–36; 申命记 7:16"> 如果你们不赶走那里的居民，留下来的人必成为你们眼里的刺和肋旁的荆棘，在你们所居之地搅扰你们，</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命记 28:63; 利未记 20:23"> 我也会用预备对付他们的方法来对付你们。’”</span>
</div>
</div>

</div>

## 第二次人口统计

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 25:9"> 瘟疫过后，耶和华对摩西和亚伦祭司的儿子以利亚撒说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 38:25–26; 民数记 1:2–3; 出埃及记 30:11–16"> “你们要统计以色列全体会众的人数，按家系登记所有二十岁以上、有作战能力的男子。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 22:1; 民数记 33:48; 民数记 35:1"> 摩西和以利亚撒祭司就在约旦河边、耶利哥对面的摩押平原对以色列人说：</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 1:1; 历代志上 21:1"> “你们要按照耶和华对摩西的吩咐，统计二十岁以上的男子。” 以下是从埃及出来的以色列人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 5:3; 创世记 46:8–9; 出埃及记 6:14"> 以色列的长子是吕便，吕便的子孙有哈诺族、法路族、</span>
<span className="v" id="v6" data-v="6"> 希斯伦族和迦米族。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 46:9; 民数记 26:21; 民数记 2:11"> 这些是吕便的各宗族，共登记了四万三千七百三十人。</span>
<span className="v" id="v8" data-v="8"> 法路的儿子是以利押，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 1:16; 民数记 16:1–35; 诗篇 106:17"> 以利押的儿子是尼姆利、大坍和亚比兰。大坍、亚比兰原是会众所推选的首领，他们与可拉一伙，一起反叛摩西和亚伦，反叛耶和华，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 16:38; 彼得后书 2:6; 民数记 16:31–35"> 以致大地裂开，将他们全部吞了下去，当时大火还烧灭了二百五十人。他们成了后人的警戒。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 6:24; 诗篇 42:1; 民数记 16:33"> 然而，可拉的子孙没有被灭绝。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 4:24; 创世记 46:10; 出埃及记 6:15"> 按着宗族，西缅的子孙有尼姆利族、雅悯族、雅斤族、</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 46:10"> 谢拉族和扫罗族。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:22–23; 民数记 2:12–13"> 这些是西缅的各宗族，共登记了两万二千二百人。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 46:16; 民数记 2:14"> 按着宗族，迦得的子孙有洗分族、哈基族、书尼族、</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 46:16"> 阿斯尼族、以利族、</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 46:16"> 亚律族和亚列利族。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:24–25; 民数记 2:14–15"> 这些是迦得的各宗族，共登记了四万零五百人。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 46:12; 创世记 38:1–10; 历代志上 2:3–8"> 珥和俄南是犹大的儿子，他们死在了迦南。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 11:24; 创世记 46:12; 路加福音 3:33"> 按着宗族，犹大的子孙有示拉族、法勒斯族、谢拉族。</span>
<span className="v" id="v21" data-v="21"> 法勒斯的子孙有希斯仑族和哈姆勒族。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 1:26–27; 民数记 2:3–4; 创世记 49:8"> 这些是犹大的各宗族，共登记了七万六千五百人。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 46:13; 历代志上 7:1; 创世记 30:17–18"> 按着宗族，以萨迦的子孙有陀拉族、普瓦族、</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 46:13"> 雅述族和伸仑族。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 2:5–6; 民数记 1:28–29"> 这些是以萨迦各宗族，共登记了六万四千三百人。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 46:14; 创世记 30:19–20"> 按着宗族，西布伦的子孙有西烈族、以伦族和雅利族。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:30–31; 民数记 2:7–8"> 这些是西布伦的各宗族，共登记了六万零五百人。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 46:20; 创世记 48:5; 创世记 41:51–52"> 按着宗族，约瑟的儿子有玛拿西和以法莲。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 17:1; 民数记 36:1; 历代志上 7:14–19"> 玛拿西的子孙有玛吉族和基列族。基列是玛吉的儿子。基列族来自基列。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 6:11; 士师记 6:34; 士师记 6:24"> 基列的子孙有伊以谢族、希勒族、</span>
<span className="v" id="v31" data-v="31"> 亚斯烈族、示剑族、</span>
<span className="v" id="v32" data-v="32"> 示米大族和希弗族。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 27:1; 民数记 36:10–12"> 希弗的儿子西罗非哈没有儿子，只有女儿玛拉、挪阿、曷拉、密迦和得撒。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 1:34–35; 民数记 2:20–21"> 这些是玛拿西的各宗族，共登记了五万二千七百人。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 7:20–21"> 按着宗族，以法莲的子孙有书提拉族、比结族和他罕族。</span>
<span className="v" id="v36" data-v="36"> 书提拉的子孙有以兰族。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 1:32–33; 民数记 2:18–19"> 这些是以法莲各宗族，共登记了三万二千五百人，他们按宗族都是约瑟的子孙。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 8:1; 历代志上 7:6–12; 创世记 46:2"> 按着宗族，便雅悯的子孙有比拉族、亚实别族、亚希兰族、</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 46:21"> 书反族和户反族。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志上 8:3"> 比拉的子孙有亚勒族和乃幔族。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 2:22–23; 创世记 46:21; 民数记 1:36–37"> 这些是便雅悯的各宗族，共登记了四万五千六百人。</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 46:23"> 按着宗族，但的子孙有书含族，书含族来自书含，这些是但的宗族。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 1:38–39; 民数记 2:25–26"> 书含族共登记了六万四千四百人。</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 46:17; 历代志上 7:30"> 按着宗族，亚设的子孙有音拿族、亦施韦族和比利亚族。</span>
<span className="v" id="v45" data-v="45"> 比利亚的子孙有希别族和玛结族。</span>
<span className="v" id="v46" data-v="46" data-xref="创世记 46:17"> 亚设的女儿名叫西拉。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 2:27–28; 民数记 1:40–41"> 这些是亚设的各宗族，共登记了五万三千四百人。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 46:24; 历代志上 7:13"> 按着宗族，拿弗他利的子孙有雅薛族、沽尼族、</span>
<span className="v" id="v49" data-v="49" data-xref="历代志上 7:13"> 耶色族和示冷族。</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 1:42–43; 民数记 2:29–30"> 这些是拿弗他利的各宗族，共登记了四万五千四百人。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 1:46; 民数记 2:32; 出埃及记 12:37"> 登记的以色列男子共有六十万一千七百三十人。</span>
<span className="v" id="v52" data-v="52"> 耶和华对摩西说：</span>
<span className="v" id="v53" data-v="53" data-xref="约书亚记 11:23; 约书亚记 14:1; 诗篇 105:44"> “你要按着各支派登记的人数，把土地分给他们作产业；</span>
<span className="v" id="v54" data-v="54" data-xref="民数记 33:54; 民数记 32:3; 民数记 32:5"> 人数多的多分产业，人数少的少分产业，要按登记的人数分配。</span>
<span className="v" id="v55" data-v="55" data-xref="民数记 34:13; 民数记 33:54; 约书亚记 14:2"> 以色列人要按各自的支派抽签分地，承受产业。</span>
<span className="v" id="v56" data-v="56" data-xref="哥林多前书 12:4; 罗马书 11:7"> 无论大小支派，都要用抽签的方法分配产业。”</span>
<span className="v" id="v57" data-v="57" data-xref="创世记 46:11; 历代志上 6:1; 出埃及记 6:16–19"> 按着宗族，利未的子孙有革顺族、哥辖族和米拉利族。</span>
<span className="v" id="v58" data-v="58" data-xref="民数记 16:1; 民数记 3:17–21; 出埃及记 6:20"> 立尼族、希伯伦族、玛利族、姆示族和可拉族也是利未的子孙。哥辖生暗兰。</span>
<span className="v" id="v59" data-v="59" data-xref="出埃及记 6:20; 出埃及记 2:1–2; 利未记 18:12"> 暗兰的妻子叫约基别，是利未女子，出生在埃及。她给暗兰生了亚伦、摩西和他们的姐姐米利暗。</span>
<span className="v" id="v60" data-v="60" data-xref="民数记 3:2; 民数记 3:8"> 亚伦生拿答、亚比户、以利亚撒和以他玛。</span>
<span className="v" id="v61" data-v="61" data-xref="民数记 3:4; 利未记 10:1–2; 历代志上 24:1–2"> 拿答和亚比户在用凡火向耶和华献祭时死去了。</span>
<span className="v" id="v62" data-v="62" data-xref="申命记 10:9; 民数记 35:2–8; 民数记 3:39"> 利未人中一个月以上的男性共登记了两万三千人，他们的人数没有登记在以色列人中，因为他们在以色列人中不分产业。</span>
<span className="v" id="v63" data-v="63" data-xref="民数记 26:3"> 以上是摩西和以利亚撒祭司在约旦河边、耶利哥对面的摩押平原统计的以色列人数，</span>
<span className="v" id="v64" data-v="64" data-xref="申命记 2:14–15; 申命记 4:3–4; 哥林多前书 10:5"> 其中没有一个是摩西和祭司亚伦从前在西奈旷野登记的以色列人。</span>
<span className="v" id="v65" data-v="65" data-xref="哥林多前书 10:5–6; 民数记 14:38; 罗马书 11:22"> 因为耶和华说过，那批人都要死在旷野。所以，除了耶孚尼的儿子迦勒和嫩的儿子约书亚以外，上次登记的人无一存活。</span>

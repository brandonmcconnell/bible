## 摩押王召巴兰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 34:1; 申命记 3:8; 民数记 21:20"> 以色列人继续前行，抵达约旦河东岸的摩押平原，在耶利哥对面安营。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:25; 民数记 21:20–35; 民数记 21:3"> 西拨的儿子摩押王巴勒得知以色列人对亚摩利人的所作所为，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:15; 以赛亚书 23:5; 约书亚记 9:24"> 又见他们人多势众，就惊恐万状。摩押人被以色列人吓坏了，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 25:15–18; 民数记 31:8; 民数记 24:17"> 就对米甸的长老说：“这群人将吞掉我们周围的一切，如同牛吃光田间的草一样。”那时，西拨的儿子巴勒做摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 23:4; 约书亚记 24:9; 弥迦书 6:5"> 他差遣使者去幼发拉底河附近，到比珥的儿子巴兰的家乡毗夺，去召巴兰，说：“有一个民族从埃及铺天盖地而来，就住在我对面。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 24:9; 民数记 23:7–8; 使徒行传 16:16"> 他们比我强大，求你为我咒诅他们。这样，我也许就能击败他们，把他们赶走。我知道你祝福谁，谁就蒙福；你咒诅谁，谁就遭祸。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 9:7–8; 弥迦书 3:11; 罗马书 16:18"> 摩押和米甸的长老们带着占卜的礼金去见巴兰，把巴勒的话转告他。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:12; 民数记 22:19–20; 耶利米书 12:2"> 巴兰说：“你们今夜住在这里，我必照耶和华的旨意回复你们。”摩押的官长就在巴兰那里住下。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 20:3; 民数记 22:20; 创世记 16:8"> 晚上，上帝来问巴兰：“住在你这里的是谁？”</span>
<span className="v" id="v10" data-v="10"> 巴兰回答说：“他们是摩押王西拨的儿子巴勒派来的，</span>
<span className="v" id="v11" data-v="11"> 说，‘有一个民族从埃及铺天盖地而来。请你来咒诅那民族，这样我或许能击败他们，把他们赶走。’”</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 以弗所书 1:3; 创世记 12:2"> 上帝对巴兰说：“你不可跟他们去，也不可咒诅那民族，因为那民族是蒙福的。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 23:5; 民数记 22:14"> 巴兰清早起来，对巴勒的官长说：“你们回去吧，耶和华不准我跟你们去。”</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 22:37; 民数记 22:13"> 摩押的官长回去对巴勒说：“巴兰不肯跟我们来。”</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:7–8; 民数记 22:7–8"> 巴勒又派去更多、更尊贵的官长。</span>
<span className="v" id="v16" data-v="16"> 他们到了巴兰那里，对他说：“西拨的儿子巴勒请你务必去一趟，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 24:11; 以斯帖记 5:11; 马太福音 4:8–9"> 他必有重赏。你要什么都可以，只求你去为他咒诅那民族。”</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 24:13; 列王纪上 22:14; 历代志下 18:13"> 巴兰回答说：“巴勒就是把他满屋的金银都给我，我也不能在任何事上违背我的上帝耶和华的命令。</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:11; 彼得后书 2:3; 提摩太前书 6:9–10"> 请你们在这里过夜，我好看看耶和华对我还有什么吩咐。”</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 23:12; 民数记 24:13; 民数记 23:26"> 当夜，上帝来对巴兰说：“这些人既然来请你，你就跟他们去吧，但你只可照我说的做。”</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 巴兰清早起来，备好驴，跟摩押的官长去了。</span>
</div>
</div>

## 上帝拦阻巴兰

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 4:24; 耶利米哀歌 2:4; 民数记 22:32"> 巴兰这一去，激怒了上帝。巴兰骑着驴，带着两个仆人正走在途中，耶和华的天使拦住他的去路。</span>
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:11; 彼得后书 2:16; 哥林多前书 1:27–29"> 驴看见耶和华的天使拔刀拦在路上，就离开大路，跑进田间。巴兰打驴，要它回到路上。</span>
<span className="v" id="v24" data-v="24"> 耶和华的天使又站在葡萄园之间的一条窄路上，两边都是墙。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:12; 约伯记 5:13–15"> 驴看见耶和华的天使，就靠着墙边走，将巴兰的脚挤在墙上了。巴兰又打它。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 2:6; 以赛亚书 26:11"> 耶和华的天使又走到前面，站在狭窄之处，两边都无侧身通过的余地。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各书 1:19; 箴言 27:3–4"> 巴兰身下的驴看见耶和华的天使，就卧在地上，巴兰大怒，便用杖打它。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得后书 2:16; 路加福音 1:37; 出埃及记 4:11"> 耶和华使驴开口对巴兰说：“我做错了什么，你竟打我三次？”</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 马太福音 15:19; 箴言 12:16"> 巴兰说：“因为你戏弄我。如果我手中有刀，早就把你宰了！”</span>
<span className="v" id="v30" data-v="30" data-xref="彼得后书 2:16; 哥林多前书 1:27–28"> 驴对巴兰说：“我不是你从小就骑的驴吗？我可曾这样对你？”巴兰说：“没有。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 21:19; 路加福音 24:31; 使徒行传 26:18"> 那时，耶和华开了巴兰的眼，他才看见耶和华的天使拔刀拦在路上，便俯身下拜。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行传 13:10; 民数记 22:22"> 耶和华的天使对他说：“你为何三次打你的驴？我来阻挡你，因为你走的路在我眼中是邪路。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 16:33–35; 民数记 14:37; 列王纪上 13:24–28"> 你的驴看见我，一连躲避了三次，驴若没有躲开，我早已杀了你，只放过驴。”</span>
<span className="v" id="v34" data-v="34" data-xref="约伯记 34:31–32; 撒母耳记下 12:13; 撒母耳记上 15:24"> 巴兰对耶和华的天使说：“我有罪了，我不知道是你拦在路上。现在你如果反对我去，我就回去。”</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:9–12; 以赛亚书 37:26–29; 民数记 22:20–21"> 耶和华的天使说：“跟这些人去吧，但你只许按我的指示说话。”于是，巴兰跟巴勒的官长去了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 16:2; 使徒行传 28:15; 耶利米书 48:20"> 巴勒听见巴兰来了，就来到边界尽头、亚嫩河边的摩押城迎接他。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 24:11; 约翰福音 5:44; 马太福音 4:8–9"> 巴勒对巴兰说：“上次派人请你，你为何不肯来？难道我不能给你重赏吗？”</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 22:18; 箴言 19:21; 民数记 23:16"> 巴兰对巴勒说：“现在我已经来了，但我不能随便发言，我只能按上帝的指示说话。”</span>
<span className="v" id="v39" data-v="39"> 巴兰和巴勒一同来到基列·胡琐。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 23:14; 箴言 1:16; 民数记 23:2"> 巴勒宰牛杀羊赏给巴兰和随行的官长。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 23:13; 民数记 25:2–3; 历代志下 11:15"> 次日清晨，巴勒领巴兰上到巴末·巴力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“巴末·巴力”希伯来文是“巴力的高岗”之意。">a</a></sup>，从那里可以看到一部分以色列人。</span>
</div>
</div>

## 巴兰的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 23:29; 犹大书 1:11; 出埃及记 27:1–8"> 巴兰对巴勒说：“你在这里为我筑七座祭坛，预备七头公牛和七只公绵羊。”</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:14; 民数记 23:30"> 巴勒就照巴兰的话做了。他们二人在每座坛上献上一头公牛和一只公绵羊，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 23:15; 创世记 8:20; 创世记 22:2"> 巴兰对巴勒说：“你留在燔祭旁边，我到前面去，也许耶和华会向我显现。无论祂有什么指示，我必告诉你。”巴兰就上到一处光秃秃的高地。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 23:16; 以弗所书 2:9; 路加福音 18:12"> 上帝向巴兰显现。巴兰对上帝说：“我已经预备了七座祭坛，每座祭坛上献了一头公牛和一只公绵羊。”</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 18:18; 耶利米书 1:9; 以赛亚书 59:21"> 耶和华告诉他当说的话，命他回去转告巴勒。</span>
<span className="v" id="v6" data-v="6"> 巴兰就回到巴勒那里，看见他和摩押的官长都站在燔祭旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 23:4; 民数记 24:3; 民数记 22:5–6"> 巴兰吟诗预言说：<br /><span className="pl pl-1">“巴勒领我出亚兰，</span><br /><span className="pl pl-1">摩押王请我出东山，</span><br /><span className="pl pl-1">说，‘来为我咒诅雅各，</span><br /><span className="pl pl-1">来斥责以色列！’</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:23; 以赛亚书 44:25; 民数记 23:20"> <span className="pl pl-1">上帝没有咒诅的，</span><br /><span className="pl pl-1">我怎能咒诅？</span><br /><span className="pl pl-1">耶和华没有斥责的，</span><br /><span className="pl pl-1">我怎能斥责？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命记 33:28; 申命记 32:8; 出埃及记 33:16"> <span className="pl pl-1">我从峰顶观看他们，</span><br /><span className="pl pl-1">从高岗眺望他们，</span><br /><span className="pl pl-1">这独居一方之民，</span><br /><span className="pl pl-1">不与万国同列。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 37:37; 创世记 13:16; 诗篇 116:15"> <span className="pl pl-1">雅各的子孙多如尘土，</span><br /><span className="pl pl-1">谁能数得清？</span><br /><span className="pl pl-1">谁能数清以色列人的四分之一？</span><br /><span className="pl pl-1">我愿像义人一样死去，</span><br /><span className="pl pl-1">如义人般终此一生。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 13:2; 民数记 24:10; 民数记 22:17"> 巴勒对巴兰说：“你这是做什么？我请你来咒诅我的仇敌，你竟祝福他们！”</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:38; 民数记 23:20; 民数记 23:26"> 巴兰说：“耶和华让我说的话，我岂能不说？”</span>
</div>
</div>

## 巴兰第二次预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 109:17; 雅各书 3:9–10; 民数记 22:41"> 巴勒说：“请你跟我去另一个地方，那里看不见全部以色列人，只能看见一部分，你要在那里为我咒诅他们。”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 46:6; 民数记 23:29; 以赛亚书 1:10–11"> 他领巴兰上到毗斯迦山顶的琐腓田，在那里筑了七座祭坛，每座坛上都献了一头公牛和一只公绵羊。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 23:3; 民数记 22:8"> 巴兰对巴勒说：“你留在这些燔祭旁边，我到那边去见耶和华。”</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 23:5; 民数记 24:1; 民数记 22:35"> 耶和华向巴兰显现，告诉他当说的话，让他转告巴勒。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 23:26; 撒母耳记上 3:17; 耶利米书 37:17"> 巴兰回到巴勒那里，看见他和摩押的官长都站在燔祭旁边。巴勒问道：“耶和华说了什么？”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 3:20"> 巴兰吟诗预言说：<br /><span className="pl pl-1">“巴勒啊，要留心听！</span><br /><span className="pl pl-1">西拨的儿子啊，请听我言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 15:29; 雅各书 1:17; 玛拉基书 3:6"> <span className="pl pl-1">上帝并非世人，祂不撒谎；</span><br /><span className="pl pl-1">上帝不是凡人，祂不反悔。</span><br /><span className="pl pl-1">祂言出必行，信守承诺。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:27–29; 民数记 22:12; 创世记 12:2"> <span className="pl pl-1">我奉命祝福，祂已赐福，</span><br /><span className="pl pl-1">我不能改变。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 23:4; 马太福音 1:23; 耶利米书 50:20"> <span className="pl pl-1">雅各的子孙中未见有罪恶，</span><br /><span className="pl pl-1">以色列人中看不见有祸患。</span><br /><span className="pl pl-1">他们的上帝耶和华与他们同在，</span><br /><span className="pl pl-1">他们向自己的君王欢呼。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="民数记 24:8; 申命记 33:17; 约伯记 39:9–11"> <span className="pl pl-1">上帝带他们出埃及，</span><br /><span className="pl pl-1">祂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“祂”有古卷作“他们”。">a</a></sup><br /><span className="pl pl-1">的力量如野牛之角。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 10:18–19; 约书亚记 13:22; 加拉太书 1:23–24"> <span className="pl pl-1">没有邪术能害雅各，</span><br /><span className="pl pl-1">没有咒语可伤以色列。</span><br /><span className="pl pl-1">时候一到，人们必谈论雅各，</span><br /><span className="pl pl-1">谈论以色列，说，‘看啊，</span><br /><span className="pl pl-1">上帝的作为何等伟大！’</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:27; 创世记 49:9; 民数记 24:17"> <span className="pl pl-1">看啊，这民族挺身如母狮，</span><br /><span className="pl pl-1">跃起像雄狮，</span><br /><span className="pl pl-1">不吞食猎物、</span><br /><span className="pl pl-1">不喝猎物的血不躺卧。”</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–3"> 巴勒对巴兰说：“你可以不咒诅他们，但也不该为他们祝福啊！”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:29; 民数记 22:18; 使徒行传 4:19–20"> 巴兰回答说：“我不是说过，我必须按耶和华的指示做吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 11:29; 箴言 21:30; 民数记 23:19–20"> 巴勒说：“来吧，我带你去另一个地方，也许上帝会同意你在那里为我咒诅他们。”</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:20; 诗篇 106:28"> 他领着巴兰登上俯瞰旷野的毗珥山顶。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 23:1–2"> 巴兰对巴勒说：“你在这里为我筑七座祭坛，预备七头公牛和七只公绵羊。”</span>
<span className="v" id="v30" data-v="30"> 巴勒就照巴兰的话，在每座祭坛上献了一头公牛和一只公绵羊。</span>
</div>

## 打探迦南

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 1:22–25; 民数记 32:8; 民数记 34:18"> “你要派十二位首领，每个支派一位，去打探我要赐给以色列人的迦南。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 12:16; 民数记 32:8; 申命记 1:19"> 摩西就按耶和华的吩咐，从巴兰旷野派出了以色列人的十二位首领。</span>
<span className="v" id="v4" data-v="4"> 他们的名字如下：吕便支派撒刻的儿子沙姆亚，</span>
<span className="v" id="v5" data-v="5"> 西缅支派何利的儿子沙法，</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 34:19; 民数记 14:6; 民数记 13:30"> 犹大支派耶孚尼的儿子迦勒，</span>
<span className="v" id="v7" data-v="7"> 以萨迦支派约色的儿子以迦，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:13; 民数记 11:28; 民数记 13:16"> 以法莲支派嫩的儿子何西阿，</span>
<span className="v" id="v9" data-v="9"> 便雅悯支派拉孚的儿子帕提，</span>
<span className="v" id="v10" data-v="10"> 西布伦支派梭底的儿子迦叠，</span>
<span className="v" id="v11" data-v="11"> 约瑟的子孙、玛拿西支派稣西的儿子迦底，</span>
<span className="v" id="v12" data-v="12"> 但支派基玛利的儿子亚米利，</span>
<span className="v" id="v13" data-v="13"> 亚设支派米迦勒的儿子西帖，</span>
<span className="v" id="v14" data-v="14"> 拿弗他利支派缚西的儿子拿比，</span>
<span className="v" id="v15" data-v="15"> 迦得支派玛基的儿子臼利。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 13:8; 出埃及记 17:9; 民数记 14:6"> 以上是摩西派去打探迦南的人，他称嫩的儿子何西阿为约书亚。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 1:9; 创世记 12:9; 士师记 1:19"> 摩西派他们去打探迦南，并嘱咐说：“你们先去南地，然后再进山区，</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 34:14; 出埃及记 3:8"> 察看那地方，看看那里的居民是强是弱，是多是少；</span>
<span className="v" id="v19" data-v="19"> 他们住的地方是好是坏，人们住的是坚固的城池还是不设防的营地；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 31:23; 申命记 31:6–8; 以西结书 34:14"> 土地是肥沃还是贫瘠，有没有树木。尽力带些当地的果子回来。”当时是葡萄初熟的季节。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 20:1; 民数记 33:36; 民数记 27:14"> 于是，他们从荀旷野一直打探到哈马口附近的利合。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:12; 诗篇 78:43; 以赛亚书 19:11"> 他们经南地到达希伯仑。希伯仑城比埃及的琐安城还要早建七年，那里住着亚衲人的子孙亚希幔、示筛和挞买。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:24; 民数记 32:9; 申命记 1:24–25"> 他们来到以实各谷，在那里砍下一根葡萄枝，上面有一串葡萄，由两个人用杠子抬着，又采了一些石榴和无花果。</span>
<span className="v" id="v24" data-v="24"> 因为他们在那里砍了一串葡萄，所以就称那地方为以实各<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以实各”意思是“一串”。">a</a></sup>谷。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:28; 出埃及记 24:18; 民数记 14:33–34"> 过了四十天，他们打探完毕，返回营地。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 32:8; 民数记 20:1; 申命记 1:19"> 他们来到巴兰旷野的加低斯向摩西、亚伦和以色列全体会众汇报，把当地的果子给大家看。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:8; 出埃及记 3:17; 出埃及记 13:5"> 他们对摩西说：“我们到了你派我们去的那地方，果然是奶蜜之乡，这些都是那里的果子。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 9:1–2; 申命记 1:28; 民数记 13:33"> 但那里的居民很强悍，城邑高大坚固。我们在那里还见到亚衲人的子孙。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 14:43; 士师记 6:3; 创世记 15:19–21"> 亚玛力人住在南地，赫人、耶布斯人和亚摩利人住在山区，迦南人住在海边和约旦河沿岸。”</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 14:24; 罗马书 8:31; 腓立比书 4:13"> 迦勒让站在摩西面前的民众安静，然后说：“我们立刻上去占领那地方吧！我们必能取胜。”</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:28; 约书亚记 14:8; 希伯来书 3:19"> 跟他一起去打探的人却说：“我们不能上去攻打那些人，他们比我们强大。”</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司书 2:9; 民数记 14:36–37; 以西结书 36:13–14"> 他们还危言耸听，说：“我们去打探的地方是吞吃居民之地，我们看见的人个个身材高大。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 1:28; 以赛亚书 40:22; 创世记 6:4"> 我们在那里看见了亚衲人的子孙，他们是巨人的后裔，我们跟他们相比就像蚱蜢，他们看我们也像蚱蜢。”</span>

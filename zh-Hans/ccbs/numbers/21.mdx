## 击败迦南人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 1:16; 民数记 33:40; 约书亚记 12:14"> 住在南地的迦南人亚拉得王听说以色列人取道亚他林而来，就攻打他们，俘虏了一些人。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:30; 创世记 28:20; 撒母耳记上 1:11"> 以色列人向耶和华许愿说：“要是你将这些人交在我们手中，我们必彻底摧毁<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“摧毁”希伯来文有“销毁，以示奉献给耶和华”之意。">a</a></sup>他们的城邑。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:45; 申命记 1:44; 诗篇 10:17"> 耶和华答应了他们的祈求，把迦南人交在他们手中，使他们彻底毁灭了迦南人及其城邑。从此，那地方叫何珥玛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“何珥玛”意思是“毁灭”。">b</a></sup>。</span>
</div>
</div>

## 铜蛇

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:9; 士师记 11:18; 民数记 32:7"> 以色列人为了绕过以东，便从何珥山出发，沿通往红海的路行进。途中，民众心里烦躁，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 78:19; 民数记 16:13–14; 出埃及记 17:2–3"> 埋怨上帝和摩西说：“你们为什么带我们出埃及，叫我们死在旷野呢？这里无粮无水，我们厌恶这难吃的东西！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:9; 耶利米书 8:17; 申命记 8:15"> 于是，耶和华派毒蛇进入以色列人中，咬死了许多人。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 8:24; 民数记 11:2; 诗篇 78:34"> 他们来找摩西，说：“我们埋怨耶和华和你，犯了罪，求你向耶和华祷告，好叫蛇离开我们。”摩西就为他们祷告。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:14; 诗篇 106:43–45; 诗篇 145:8"> 耶和华对摩西说：“你去造一条毒蛇挂在杆子上，凡被咬的一望这蛇，就可活命。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:14–15; 希伯来书 12:2; 约翰福音 6:40"> 摩西就造了一条铜蛇，挂在杆子上。被蛇咬的人一望铜蛇，就保住了性命。</span>
</div>
</div>

## 前往摩押

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 33:43–45"> 以色列人继续前行，在阿伯安营；</span>
<span className="v" id="v11" data-v="11"> 又从阿伯动身，走到摩押东边的旷野，在以耶·亚巴琳安营；</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:13–14"> 又从那里前行，走到撒烈谷安营；</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 11:18; 民数记 22:36; 以赛亚书 16:2"> 又从那里出发，走到亚嫩河北岸的旷野安营。那里毗邻亚摩利人的边境，亚嫩河是摩押和亚摩利人之间的疆界。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 10:13; 撒母耳记下 1:18"> 因此，《耶和华的战记》上说：“苏法的哇哈伯，亚嫩河谷，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:28; 申命记 2:18; 申命记 2:9"> 以及靠近摩押边界并延伸到亚珥城的河谷的斜坡。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="民数记 20:8; 以赛亚书 12:3; 以赛亚书 41:17–18"> 以色列人又往前走，来到比珥<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“比珥”意思是“井”。">c</a></sup>。耶和华曾在那里对摩西说：“把民众招聚起来，我要给他们水喝。”</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:13; 出埃及记 15:1–2; 诗篇 106:12"> 当时，以色列人唱了这首歌：<br /><span className="pl pl-1">“井啊，涌出水来！</span><br /><span className="pl pl-1">你们要歌唱这口井，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 33:22; 提摩太前书 6:17–18; 雅各书 4:12"> <span className="pl pl-1">它是首领挖的，</span><br /><span className="pl pl-1">是民中的贵族掘的，</span><br /><span className="pl pl-1">用令牌和权杖挖掘的。”</span><br />他们从旷野前往玛他拿，</span>
<span className="v" id="v19" data-v="19"> 从玛他拿前往拿哈列，从拿哈列前往巴末，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 23:28; 民数记 23:14; 申命记 1:5"> 从巴末前往摩押的谷地，从那里的毗斯迦山顶可以俯视旷野。</span>
</div>
</div>

## 击败亚摩利王和巴珊王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命记 2:26–28; 民数记 20:14–19; 士师记 11:19–21"> 以色列人派使者去见亚摩利王西宏，说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 20:17"> “请允许我们从贵国经过，我们只走王的大路，不会踏入田地和葡萄园，也不会喝井里的水，直到走出贵国的土地。”</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 11:20; 申命记 29:7–8; 以赛亚书 15:4"> 但西宏不让以色列人经过他的领土，还招聚军队到旷野攻击他们。他们来到雅杂与以色列人交战。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 2:9; 约书亚记 24:8; 创世记 32:22"> 以色列人用刀杀了西宏，占领了他的土地——从亚嫩河到雅博河，远至防守严密的亚扪人边界。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 32:33–42; 以赛亚书 16:8–9; 耶利米书 48:2"> 以色列人攻占了亚摩利人的所有城邑，包括希实本及其周围的村庄，住在其中。</span>
<span className="v" id="v26" data-v="26"> 希实本是亚摩利王西宏的都城。西宏曾与摩押的先王交战，占领了他所有的领土，远至亚嫩河。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:4; 民数记 21:14; 哈巴谷书 2:6"> 因此有人作诗说：<br /><span className="pl pl-1">“来希实本吧！</span><br /><span className="pl pl-1">愿西宏的城被修建起来。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:15; 耶利米书 48:45–46; 以赛亚书 15:1–2"> <span className="pl pl-1">希实本烈焰熊熊，</span><br /><span className="pl pl-1">西宏的城火光冲天，</span><br /><span className="pl pl-1">烧毁摩押的亚珥，</span><br /><span className="pl pl-1">吞噬亚嫩河的高岗。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="士师记 11:24; 列王纪下 23:13; 耶利米书 48:46"> <span className="pl pl-1">摩押啊，你大祸临头了！</span><br /><span className="pl pl-1">拜基抹神明的人啊，</span><br /><span className="pl pl-1">你们要灭亡了！</span><br /><span className="pl pl-1">基抹任由自己的儿子逃亡、</span><br /><span className="pl pl-1">女儿被亚摩利王西宏掳走。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 48:18; 以赛亚书 15:2; 耶利米书 48:22"> <span className="pl pl-1">但我们击溃了亚摩利人，</span><br /><span className="pl pl-1">从希实本一直到底本都被摧毁，</span><br /><span className="pl pl-1">从挪法到米底巴都沦为废墟。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 13:8–12; 民数记 32:33–42; 申命记 3:16–17"> 于是，以色列人住在亚摩利境内。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 48:32; 民数记 32:1; 民数记 32:35"> 摩西派人去雅谢打探，然后出兵攻占了雅谢及其周围的村庄，赶走那里的亚摩利人。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 13:12; 申命记 1:4; 申命记 29:7"> 以色列人回师前往巴珊，巴珊王噩率全军出动，在以得来迎战以色列人。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 135:10–11; 约书亚记 8:7; 申命记 3:2–3"> 耶和华对摩西说：“不要怕他，因为我已把他及其众民和土地交在你手中。你要像从前对付希实本的亚摩利王西宏一样对付他。”</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 29:7–8; 约书亚记 13:12; 申命记 3:3–17"> 于是，以色列人杀了噩及其儿子和人民，一个不留，并夺取了他的国土。</span>
</div>
</div>

## 攻打米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 27:13; 民数记 25:14–18; 启示录 6:10"> “你要为以色列人向米甸人报仇，之后你将归到祖先那里。”</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 26:25; 民数记 25:11; 列王纪下 10:30"> 于是，摩西对民众说：“你们的人要拿起兵器去攻打米甸，为耶和华报仇。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:8; 撒母耳记上 14:6; 士师记 7:2"> 以色列的每个支派要派一千人出战。”</span>
<span className="v" id="v5" data-v="5"> 于是，他们从以色列每个支派选出一千人，武装了一万二千军兵。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:44; 民数记 10:8–9; 历代志下 13:12–15"> 每个支派选出的一千军兵由摩西派遣出战，以利亚撒祭司的儿子非尼哈拿着圣所的器具和号角随行。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:11; 列王纪上 11:15–16; 撒母耳记上 27:9"> 他们照耶和华对摩西的吩咐，去攻打米甸人，杀死了米甸的所有男子，</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:21–22; 民数记 25:15; 启示录 2:14"> 包括以未、利金、苏珥、户珥和利巴五个米甸的王，还杀了比珥的儿子巴兰。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 20:14; 历代志下 28:8–10; 历代志下 28:5"> 以色列人掳获了米甸的妇女、孩子、所有牛羊和财物，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 1:7; 撒母耳记上 30:1; 约书亚记 6:24"> 将他们的城邑营寨付之一炬，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 20:14; 约书亚记 8:2"> 带走了掳掠的人畜等战利品。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:1"> 他们来到耶利哥对面、约旦河边的摩押平原，把战利品交给摩西、以利亚撒祭司和以色列全体会众。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2; 撒母耳记上 30:21; 民数记 31:12"> 摩西、以利亚撒祭司以及所有民众的首领都到营外迎接他们。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 13:19; 撒母耳记上 15:13–14; 民数记 31:48"> 摩西对出征回来的千夫长和百夫长等将领发怒，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:3; 耶利米书 48:10; 申命记 2:34"> 说：“你们为什么让这些妇女活着？</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 25:1–9; 彼得后书 2:15; 启示录 2:14"> 就是她们听了巴兰的指使，在毗珥引诱以色列人背叛耶和华，以致瘟疫降在耶和华的会众身上。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 21:11–12; 申命记 20:16–18; 申命记 7:2"> 现在，你们要杀掉所有的男孩，以及与男人发生过关系的女子，</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 21:10–14; 历代志下 28:8–10; 申命记 20:14"> 但可以留下那些处女。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 19:11–22; 民数记 5:2; 历代志上 22:8"> 你们凡杀了人和碰过死人的都要在营外待七天。在第三天和第七天，你们要洁净自己及掳来的人，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 19:22; 创世记 35:2; 出埃及记 19:10"> 也要洁净自己所有的衣服、皮具、山羊毛制品和木器。”</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 30:16"> 以利亚撒祭司对打仗回来的军兵说：“以下是耶和华借摩西颁布的律例。</span>
<span className="v" id="v22" data-v="22"> 金、银、铜、铁、锡、铅，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 19:9; 民数记 19:17; 哥林多前书 3:13"> 凡耐火之物都要用火来洁净，还要用除秽水加以洁净；不耐火之物要用水来洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 11:25; 利未记 15:13; 利未记 14:9"> 第七天，你们洗完衣服后就洁净了，可以回营。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华对摩西说：</span>
<span className="v" id="v26" data-v="26"> “你和以利亚撒祭司以及会众的各族长，要统计俘虏和牲畜的数目，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 22:8; 诗篇 68:12; 撒母耳记上 30:24–25"> 然后把这些战利品分成两份，一份给出征的战士，一份给其余会众。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 18:26; 民数记 31:30; 民数记 31:47"> 要从战士分得的俘虏、牛、驴和羊群中抽出五百分之一，献给耶和华，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 29:27; 申命记 12:19; 申命记 12:12"> 要把那五百分之一交给以利亚撒祭司，献给耶和华作举祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 3:31; 民数记 3:7–8; 民数记 3:25"> 要从以色列人分得的俘虏和牛、驴、羊等牲畜中抽出五十分之一，交给在我圣幕司职的利未人。”</span>
<span className="v" id="v31" data-v="31"> 摩西和以利亚撒祭司遵命而行。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 战士掳获的战利品中有六十七万五千只羊，</span>
<span className="v" id="v33" data-v="33"> 七万二千头牛，</span>
<span className="v" id="v34" data-v="34"> 六万一千头驴，</span>
<span className="v" id="v35" data-v="35"> 三万二千名处女。</span>
<span className="v" id="v36" data-v="36"> 战士分得的战利品有三十三万七千五百只羊，</span>
<span className="v" id="v37" data-v="37"> 其中六百七十五只献给耶和华；</span>
<span className="v" id="v38" data-v="38"> 三万六千头牛，其中七十二头献给耶和华；</span>
<span className="v" id="v39" data-v="39"> 三万零五百头驴，其中六十一头献给耶和华；</span>
<span className="v" id="v40" data-v="40"> 一万六千名处女，其中三十二人献给耶和华。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 18:8; 民数记 18:19; 希伯来书 7:9–12"> 摩西照耶和华的吩咐，把献给耶和华的举祭交给以利亚撒祭司。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 以色列会众分得的那一半战利品，即摩西从出征之人的战利品中分出来给他们的，</span>
<span className="v" id="v43" data-v="43"> 有三十三万七千五百只羊、</span>
<span className="v" id="v44" data-v="44"> 三万六千头牛、</span>
<span className="v" id="v45" data-v="45"> 三万零五百头驴、</span>
<span className="v" id="v46" data-v="46"> 一万六千名处女。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 31:30; 路加福音 10:1–8; 以赛亚书 56:10–11"> 摩西照耶和华的吩咐，从中抽出五十分之一，交给在圣幕里司职的利未人。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 统领军队的千夫长和百夫长来见摩西，</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 18:9; 撒母耳记上 30:18–19; 诗篇 72:14"> 说：“仆人们统计了手下出征的战士，未失一兵一卒。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 30:12; 出埃及记 30:15–16; 诗篇 116:12"> 现在我们把各自掳获的臂环、镯子、图章戒指、耳环、项链等金器都带来献给耶和华，在祂面前为我们赎罪。”</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 7:2–6"> 摩西和以利亚撒祭司收了他们所献的各种金制品。</span>
<span className="v" id="v52" data-v="52"> 千夫长和百夫长献给耶和华作举祭的金子共三千八百两。</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 20:14; 民数记 31:32"> 战士则保留了自己掳获的财物。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 30:16; 撒迦利亚书 6:14; 使徒行传 10:4"> 摩西和以利亚撒祭司就把千夫长和百夫长献的金子带进会幕，在耶和华面前作以色列人的纪念。</span>
</div>
</div>

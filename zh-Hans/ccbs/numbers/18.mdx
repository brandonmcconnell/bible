## 祭司和利未人的职责

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 28:38; 希伯来书 13:17; 彼得前书 2:24"> 耶和华对亚伦说：“你和你的儿子及亲族要承担触犯圣所的罪责；你和你儿子也要承担触犯祭司职务的罪责。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:34; 民数记 18:4; 以西结书 44:15"> 你和你儿子在安放约柜的圣幕前供职时，要把你们利未支派的亲族也一同带去，让他们协助你。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:15; 民数记 16:40; 民数记 4:19–20"> 他们要遵守你的吩咐，看守整个圣幕，但不可接近圣所的器具和祭坛，以免他们和你们都死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 6:19; 民数记 1:51; 民数记 3:10"> 他们要和你一起负责看守圣幕，办理圣幕的一切事务。外人不可靠近。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:21; 利未记 24:3; 民数记 16:46"> 你们要看守圣所和祭坛，以免我的愤怒再临到以色列人。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:9; 民数记 3:12; 民数记 3:45"> 我已从以色列人中选出你们的利未亲族归给我，协助你们在会幕中司职。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 15:15–16; 约翰福音 3:27; 民数记 3:10"> 你和你儿子要尽祭司的本分，负责祭坛和至圣所的一切事务。祭司的职分是我赏赐给你们的，外人若近前来，必被处死。”</span>
</div>
</div>

## 祭司当得之物

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 6:16; 利未记 7:6; 出埃及记 29:29"> 耶和华对亚伦说：“你看！我让你照管以色列人献给我的举祭，把一切圣物赐给你和你的子孙，作为你们永远当得的份。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 7:7; 利未记 14:13; 利未记 6:25–26"> 以色列人献给我的至圣之物素祭、赎罪祭和赎过祭中留下不烧的部分，都归你和你的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 7:6; 利未记 6:29; 利未记 6:16"> 你们男子都可以吃这些圣物，要在极其圣洁的地方吃。要把这些视为圣物。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 18:3; 出埃及记 29:27–28; 利未记 10:14"> 以色列人献的举祭和摇祭也都归你，我已把它们赐给你和你的儿女，作为你们永远当得的份。你家中所有洁净的人都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 18:4; 出埃及记 23:19; 出埃及记 34:26"> 我把以色列人献给耶和华的初熟之物——最好的新油、新酒和五谷都赐给你。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:29; 出埃及记 23:19; 弥迦书 7:1"> 他们献给耶和华的一切初熟之物都归你，你家中洁净的人都可以吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:28; 以西结书 44:29"> 以色列人永远献上的一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“永远献上的一切”指彻底奉献给耶和华的人或物，要么被毁灭，要么被献为供物。">a</a></sup>都要归你。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:20; 出埃及记 13:2; 出埃及记 13:12–13"> 奉献给耶和华的长子和头生的牲畜都归你，但要赎出长子和不洁净的头生牲畜。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:2–7"> 他们要在满月的时候被赎回，以圣所的秤为准，即一舍客勒是二十季拉，赎价是一两银子。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 29:16; 申命记 15:19–22; 利未记 3:2–5"> 头生的牛、绵羊和山羊不用赎出来，它们都是圣物。你要把它们的血洒在祭坛上，把脂肪烧掉，作为献给耶和华的馨香火祭；</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 7:31–34; 出埃及记 29:26–28"> 它们的肉要归你，正如摇祭的胸肉和举祭的右腿肉一样。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 13:5; 利未记 2:13; 民数记 18:11"> 以色列人献给耶和华的圣物中，我把举祭赐给你和你的儿女，作为你们永远当得的份，这是我与你及你的后代所立的永世之约。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 44:28; 申命记 10:9; 约书亚记 13:33"> 耶和华对亚伦说：“你在以色列人的土地上不可有产业，在他们的财物上不可有份，因为我是你在以色列人中的所得之份，是你的产业。</span>
</div>
</div>

## 利未人应得之物

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="尼希米记 12:44; 申命记 14:22–29; 尼希米记 10:37"> “我要把以色列人出产的十分之一赐给利未人作产业，作为他们在会幕司职的酬劳。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:9; 民数记 1:51–52; 民数记 3:38"> 今后以色列人不可走近会幕，以免因犯罪而死。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 3:7; 民数记 18:20; 民数记 18:1"> 只有利未人可在会幕司职，他们要担负触犯圣幕的罪责，这是你们世代当守的永久律例。利未人在以色列人中不可有产业，</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 18:26; 玛拉基书 3:8–10"> 因为我已经把以色列人献给耶和华的十分之一举祭赐给他们作产业。因此，我吩咐他们不可在以色列人中有产业。”</span>
</div>
</div>

## 利未人应纳的十分之一

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华对摩西说：</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 10:38; 民数记 18:21"> “你把以下条例告诉利未人。<br />“你们从以色列人手中得到我赐给你们作产业的十分之一后，要从中取出十分之一，作为举祭献给耶和华，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:30; 申命记 15:14; 列王纪下 6:27"> 这就算作你们献上了麦场的五谷和榨酒池的酒。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 6:20–10; 创世记 14:18"> 这样，你们要从以色列人给你们的十分之一中，拿出一部分献给耶和华作举祭，将这举祭归给亚伦祭司。</span>
<span className="v" id="v29" data-v="29"> 你们要把所得之物中至圣至好的献给耶和华作举祭。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 3:9–10; 创世记 43:11; 马太福音 6:33"> “你要告诉利未人，‘你们奉献了最好的以后，其余的算作你们麦场上的五谷和榨酒池的酒，</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 9:10–14; 提摩太前书 5:17–18; 路加福音 10:7"> 你们和家人可以在任何地方吃，因为这些是你们在会幕司职的酬劳。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 19:8; 利未记 22:2; 玛拉基书 1:7"> 你们献上最好的以后，享用这些就不会获罪了。你们不可亵渎以色列人献上的圣物，免得死亡。’”</span>
</div>
</div>

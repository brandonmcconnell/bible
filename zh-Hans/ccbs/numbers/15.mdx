## 献祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:10; 民数记 15:18; 利未记 25:2"> “你把以下条例告诉以色列人。 “你们进入耶和华赐给你们的家园后，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:18; 创世记 8:21; 腓立比书 4:18"> 要用牛羊作火祭献给耶和华，作蒙耶和华悦纳的馨香之祭。不管是献燔祭、还愿祭、自愿献的祭还是节期的祭，都当如此。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:40; 利未记 23:13; 利未记 6:14"> 献祭者要同时将一公斤细面粉调上一升油，作素祭献给耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:7; 民数记 28:14; 士师记 9:13"> 无论燔祭还是别的祭，每献一只羊羔，要同时献上一升酒作奠祭；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 28:12–14; 民数记 15:4"> 每献一只公绵羊，要同时将两公斤细面粉调上一升半油作素祭献上，</span>
<span className="v" id="v7" data-v="7"> 还要献一升半酒作奠祭。这是蒙耶和华悦纳的馨香之祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:1; 利未记 7:11–18; 利未记 1:3"> 如果用公牛献给耶和华作燔祭、还愿祭或平安祭，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 28:14; 民数记 28:12; 利未记 6:14"> 就要将三公斤细面粉调上两升油作素祭和公牛一同献上，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 15:5; 民数记 6:15"> 还要献上两升酒作奠祭。这是蒙耶和华悦纳的馨香之祭。</span>
<span className="v" id="v11" data-v="11"> “献公牛、公绵羊、绵羊羔或山羊羔时，都要这样办理。</span>
<span className="v" id="v12" data-v="12"> 无论献多少牲畜，每只都要这样办理。</span>
<span className="v" id="v13" data-v="13"> 凡以色列人献上蒙耶和华悦纳的馨香火祭时，都要这样办理。</span>
<span className="v" id="v14" data-v="14"> 住在你们中间的外族人，不管是暂住还是世代居住的，若愿意献上蒙耶和华悦纳的馨香火祭，也要这样办理。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:14; 民数记 15:29; 出埃及记 12:49"> 以色列人和寄居的外族人都要遵守一样的条例，永世不变。你们在耶和华面前怎样做，外族人也要怎样做。</span>
<span className="v" id="v16" data-v="16"> 你们和寄居在你们那里的外族人要遵行一样的条例和规定。”</span>
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 15:2; 申命记 26:1–15"> “你把以下条例告诉以色列人。 “你们到达耶和华领你们去的地方，</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:11–12"> 吃当地的出产时，要拿出一份作举祭献给耶和华。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 2:14; 出埃及记 34:26; 申命记 26:2–10"> 你们要用初熟的麦子磨面做饼，当作举祭献上，好像献麦场的举祭一样。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:28; 民数记 18:26"> 你们世世代代都要用初熟的麦子磨面，当作举祭献给耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:27; 利未记 5:15–17"> “如果你们无意间违背了耶和华借摩西吩咐你们遵守的命令，</span>
<span className="v" id="v23" data-v="23"> 就是吩咐你们从祂颁布之日起，要世世代代遵守的命令，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 4:23; 利未记 4:13–21; 利未记 5:15"> 如果是因会众的无知而造成无心之过，全体会众就要献上一头公牛犊作燔祭，作蒙耶和华悦纳的馨香之祭，同时按规定献上素祭和奠祭，外加一只公山羊作赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:20; 罗马书 3:25; 希伯来书 2:17"> 祭司要为以色列全体会众赎罪，这样他们就得到了赦免，因为是无心之过，并且他们已经向耶和华献上火祭和赎罪祭。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 15:24"> 这样，以色列全体会众和寄居的外族人都必蒙赦免，因为无心之过牵涉到所有人。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 4:27–28; 使徒行传 17:30; 使徒行传 3:17"> “倘若是个人无意间犯了罪，他就要献上一只一岁的母山羊作赎罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:35"> 祭司要为这无意间犯罪的人在耶和华面前赎罪，使他获得赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 15:15; 利未记 16:29; 利未记 17:15"> 无论是以色列人或是寄居的外族人，凡是犯无心之过的都要按这规条办理。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:26; 诗篇 19:13; 申命记 1:43"> 但不管是以色列人还是外族人，若任意妄为，亵渎了耶和华，都要从民中被铲除，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 12:9; 箴言 13:13; 以西结书 18:20"> 因为他藐视耶和华的话，违背耶和华的命令，必须被铲除，罪责自负。”</span>
</div>
</div>

## 处死干犯安息日者

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 35:2–3; 出埃及记 31:14–15; 出埃及记 20:8–10"> 以色列人在旷野的时候，发现有人在安息日捡柴，</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:3–20"> 他们就把捡柴的人带到摩西、亚伦和全体会众那里，</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 24:12; 民数记 9:8"> 把他关起来，因为不知道如何处置他。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:58; 出埃及记 31:14–15; 列王纪上 21:13"> 耶和华对摩西说：“必须处死那人，全体会众要在营外用石头打死他。”</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 7:25"> 于是，全体会众照耶和华对摩西的吩咐，把他拉到营外，用石头打死了他。</span>
</div>
</div>

## 衣服穗子的条例

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和华对摩西说：</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:5; 申命记 22:12; 马太福音 9:20"> “你要吩咐以色列人世世代代在衣角缝上穗子，穗子上系一条蓝色细带。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 106:39; 箴言 28:26; 诗篇 73:27"> 穗子是用来提醒他们，要遵行我的一切命令，不要随从自己心中和眼目的情欲而背信弃义。</span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 12:1; 帖撒罗尼迦前书 4:7; 利未记 11:44–45"> 这样，你们就会记得遵守我的一切命令，做你们上帝的圣洁之民。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得前书 2:9–10; 以西结书 36:25–27; 希伯来书 11:16"> 我是你们的上帝耶和华，我把你们从埃及领出来，是要做你们的上帝。我是你们的上帝耶和华。”</span>
</div>

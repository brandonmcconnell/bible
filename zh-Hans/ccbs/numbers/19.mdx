## 红母牛的灰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 22:20–25; 申命记 21:3; 撒母耳记上 6:7"> “要吩咐以色列人遵行我颁布的以下律法条例。 “以色列人要牵来一头毫无残疾、从未负过轭的红母牛。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 4:12; 利未记 4:21; 利未记 16:27"> 你们要把牛交给以利亚撒祭司，然后牵到营外，当着他的面把牛宰了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 4:17; 利未记 4:6; 利未记 16:14"> 以利亚撒祭司要用指头蘸牛血，向会幕前面弹七次。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:14; 利未记 4:11–12; 诗篇 22:14"> 然后，要当着他的面焚烧红母牛，牛的皮、肉、血和粪都要烧掉。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 14:4; 利未记 14:49; 诗篇 51:7"> 祭司要把香柏木、牛膝草、朱红色线扔进烧牛的火里。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 11:25; 利未记 11:40; 民数记 19:8"> 之后，祭司要洗衣沐浴，才能回营，但要等到傍晚才能洁净。</span>
<span className="v" id="v8" data-v="8"> 负责烧牛的人也要洗衣、沐浴，并且要等到傍晚才能洁净。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:13; 民数记 19:13; 民数记 19:20–21"> 要由一个洁净的人把红母牛灰收起来，放在营外洁净的地方，留给以色列会众作除秽水，作除罪之用。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:49; 民数记 19:7–8; 歌罗西书 3:11"> 收起母牛灰的人也要洗净衣服，等到傍晚才能洁净。这是以色列人和在他们中间寄居的外族人永远当守的律例。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 5:2; 民数记 31:19; 利未记 21:1"> “碰过尸体的人，七天不洁净。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:19; 启示录 7:14; 利未记 7:17"> 他要在第三天和第七天用除秽水自洁，才能洁净，否则就不能洁净。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 15:31; 利未记 22:3; 利未记 7:20"> 若有人碰过尸体却不自洁，他就玷污了耶和华的圣幕，要将他从以色列人中铲除，因为除秽水没有洒在他身上，他不洁净，污秽还留在他身上。</span>
<span className="v" id="v14" data-v="14"> 若有人死在帐篷里，就要遵守这样的条例：当时走进帐篷的或在场的人都七天不洁净。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 14:36; 利未记 11:32; 民数记 31:20"> 帐篷里没有盖的敞口器皿都不洁净。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 31:19; 马太福音 23:27; 路加福音 11:44"> 人若在野外碰过被杀或自然死亡之人的尸体，或碰过死人的骸骨或坟墓，就七天不洁净。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:38; 创世记 26:19; 启示录 7:17"> 要为不洁净的人拿些除罪用的红母牛灰，放在器皿里，倒上清水，</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 36:25–27; 希伯来书 9:14; 民数记 19:9"> 然后由一个洁净的人拿牛膝草蘸这水洒在帐篷及里面所有人和器具上，也要洒在碰过骸骨、坟墓、被杀者尸体，或自然死亡者尸体的人身上。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 希伯来书 10:22; 以西结书 36:25"> 要由洁净的人在第三天和第七天把水洒在不洁净的人身上，并在第七天洁净他们。接受洁净礼的人要洗衣、沐浴，等到傍晚才能洁净。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 16:16; 创世记 17:14; 民数记 19:13"> 若有人沾了污秽却没有用除秽水自洁，他就不洁净，要将他从会众中铲除，因为他玷污了耶和华的圣所。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:13–14; 希伯来书 10:4; 希伯来书 9:10"> 这是你们永远当守的律例。洒除秽水的人要洗净衣服。碰过除秽水的人要等到傍晚才能洁净。</span>
<span className="v" id="v22" data-v="22" data-xref="哈该书 2:13; 利未记 7:19; 马太福音 15:19–20"> 不洁净的人碰过的东西都不洁净，碰过这些东西的人傍晚之前都不洁净。”</span>
</div>

## 磐石出水

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 13:21; 出埃及记 15:20; 民数记 33:36"> 一月，以色列全体会众抵达荀旷野，在加低斯安营。米利暗离世，葬在那里。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 16:19; 民数记 16:42; 出埃及记 15:23–24"> 会众没有水喝，就聚集起来反对摩西和亚伦，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 17:2; 民数记 14:1–2; 民数记 16:31–35"> 他们跟摩西吵闹说：“还不如当初跟我们的弟兄一起死在耶和华面前！</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:3; 诗篇 106:21; 民数记 16:13–14"> 你们为什么领耶和华的会众到这旷野来，要叫我们和牲畜都死在这里吗？</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:14; 耶利米书 2:2; 耶利米书 2:6"> 你们为什么带我们出埃及，到这不毛之地？这里没有五谷、无花果树、葡萄树和石榴树，甚至没有水喝。”</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:5; 民数记 16:4; 民数记 16:19"> 摩西和亚伦离开会众到会幕门口，俯伏在地。耶和华的荣光向他们显现。</span>
<span className="v" id="v7" data-v="7"> 耶和华对摩西说：</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:17; 使徒行传 2:1–4; 启示录 22:17"> “你拿着杖和你哥哥亚伦招聚会众，当着他们的面吩咐磐石流出水来，水就会从磐石流出，供会众和牲畜喝。”</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 17:10"> 摩西遵命而行，从耶和华面前取了杖，</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 106:32–33; 使徒行传 14:9–15; 路加福音 9:54–55"> 然后和亚伦把会众招聚到磐石前，说：“你们这些叛逆之徒听着，非要我们叫磐石给你们流出水来吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:4; 出埃及记 17:6; 申命记 8:15"> 接着，摩西举起手中的杖击打磐石两下，水便喷涌而出，会众和牲畜都喝了。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 1:37; 民数记 27:14; 以西结书 36:23"> 耶和华对摩西和亚伦说：“你们对我没有足够的信心，没有当着以色列人的面尊我为圣，所以你们不得带领会众进入我所赐之地。”</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 17:7; 诗篇 95:8; 申命记 33:8"> 这地方叫米利巴泉，因为以色列人在那里与耶和华争闹，耶和华就向他们彰显了祂的圣洁。</span>
</div>
</div>

## 以东王不借路

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 11:16–17; 申命记 23:7; 俄巴底亚书 1:10–12"> 摩西从加低斯派使者去见以东王，说：“你的弟兄以色列人说，你知道我们遭遇的种种困难。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:40; 申命记 26:6; 创世记 46:6"> 我们祖先到埃及寄居多年，我们世代受埃及人虐待。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:19; 出埃及记 23:20; 出埃及记 33:2"> 但我们呼求耶和华，祂就垂听了我们的声音，差遣天使带我们出埃及。现在我们来到你边境的加低斯城，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 2:27; 申命记 2:29; 民数记 21:22–24"> 求你容我们借道贵国。我们不会踏入田地和葡萄园，也不会喝井里的水，只走王的大路，不会偏离左右，直到走出贵国。”</span>
<span className="v" id="v18" data-v="18"> 以东王却说：“你们不可从我这里经过，否则我必兵戎相见。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:28; 申命记 2:6; 出埃及记 12:38"> 以色列人说：“我们只走大路，倘若我们和牲畜喝了你的水，我们会付钱。我们别无他求，只求步行穿过贵国。”</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 11:17; 阿摩司书 1:11; 创世记 32:6"> 但以东王仍然不准，还率领大军严阵以待。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:18; 申命记 2:29; 申命记 2:4–8"> 由于以东王不让以色列人穿过他的领土，以色列人只好绕道。</span>
</div>
</div>

## 亚伦离世

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 20:1; 民数记 20:14; 民数记 21:4"> 以色列全体会众从加低斯出发，来到何珥山。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 33:37"> 耶和华在位于以东边界的何珥山对摩西和亚伦说：</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:8; 申命记 32:50; 民数记 31:2"> “亚伦要归到他祖先那里，他不能进入我赐给以色列人的土地，因为你们在米利巴泉违背了我的命令。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 33:38–39"> 你要带亚伦和他儿子以利亚撒上何珥山，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 20:24; 以赛亚书 22:21–22; 希伯来书 7:11"> 把亚伦的圣衣脱下来给他儿子以利亚撒穿上，因为亚伦将归到他祖先那里，死在山上。”</span>
<span className="v" id="v27" data-v="27"> 摩西遵命而行。他们三人就当着全体会众的面上了何珥山。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 10:6; 出埃及记 29:29–30; 申命记 34:9"> 摩西把亚伦的圣衣脱下，给他儿子以利亚撒穿上。随后亚伦在山顶离世。摩西和以利亚撒便下了山。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:8; 历代志下 35:24–25; 创世记 1:10"> 以色列全体会众得知亚伦离世，就为他哀悼了三十天。</span>
</div>
</div>

## 巴兰第三次预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 23:3; 民数记 23:23; 民数记 23:28"> 巴兰见耶和华乐意赐福给以色列人，就不再像先前两次那样去求兆头，而是转向旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 19:20; 历代志下 15:1; 撒母耳记上 19:23"> 他举目眺望，看见以色列人按支派扎营。上帝的灵降在他身上，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 22:31; 民数记 24:16; 民数记 23:7"> 他便吟诗预言说：<br /><span className="pl pl-1">“比珥之子巴兰的预言，</span><br /><span className="pl pl-1">是眼睛明亮者的话，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; 启示录 1:10; 民数记 12:6"> <span className="pl pl-1">他得听上帝之言，</span><br /><span className="pl pl-1">俯伏在地，眼目睁开</span><br /><span className="pl pl-1">得见全能者的异象。</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">雅各啊，</span><br /><span className="pl pl-1">你的帐篷何等华美！</span><br /><span className="pl pl-1">以色列啊，</span><br /><span className="pl pl-1">你的居所何等佳美！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 1:3; 以赛亚书 58:11; 诗篇 104:16"> <span className="pl pl-1">像连绵的山谷，</span><br /><span className="pl pl-1">如河畔的园子；</span><br /><span className="pl pl-1">像耶和华栽种的沉香，</span><br /><span className="pl pl-1">如水边的香柏树。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 5:12; 历代志上 14:2; 启示录 17:1"> <span className="pl pl-1">他们沐浴充沛的甘霖，</span><br /><span className="pl pl-1">撒种于湿润的沃土。</span><br /><span className="pl pl-1">他们的君王高过亚甲，</span><br /><span className="pl pl-1">国度名震四方。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 45:5; 诗篇 2:9; 民数记 14:9"> <span className="pl pl-1">上帝带他们出埃及，</span><br /><span className="pl pl-1">祂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“祂”或译“他们”。">a</a></sup><br /><span className="pl pl-1">的力量如野牛之角。</span><br /><span className="pl pl-1">他们要吞灭敌国，</span><br /><span className="pl pl-1">打碎敌人的骨头，</span><br /><span className="pl pl-1">用利箭射穿仇敌。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:3; 创世记 27:29; 创世记 49:9"> <span className="pl pl-1">他们蹲伏如雄狮，</span><br /><span className="pl pl-1">躺卧如母狮，谁敢招惹？</span><br /><span className="pl pl-1">愿祝福他们的人蒙祝福！</span><br /><span className="pl pl-1">愿咒诅他们的人受咒诅！”</span></span>
<span className="v" id="v10" data-v="10" data-xref="民数记 23:11; 以西结书 21:14; 以西结书 21:17"> 巴勒听了大怒，用力击掌，对巴兰说：“我请你来咒诅我的仇敌，你竟三次祝福他们。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 22:17; 民数记 22:37; 希伯来书 11:24–26"> 现在快回家去吧！我说过要给你重赏，但耶和华不让你得到。”</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:18; 民数记 22:38"> 巴兰说：“我不是对你派来的使臣说过吗？</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 16:28; 民数记 22:18; 民数记 22:20"> 就是你把满屋的金银都给我，我也不能违背耶和华的命令、凭自己的意思行事——无论好事坏事。我只能说耶和华让我说的话。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 6:5; 启示录 2:14; 创世记 49:1"> 现在我要回本族去了。但我要告诉你日后以色列人会怎样对待你的人民。”</span>
</div>
</div>

## 巴兰第四次预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="民数记 24:3–4; 民数记 23:7; 马太福音 13:35"> 巴兰吟诗预言说：<br /><span className="pl pl-1">“比珥之子巴兰的预言，</span><br /><span className="pl pl-1">是眼睛明亮者的话，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民数记 24:4; 哥林多前书 8:1; 撒母耳记下 23:1–2"> <span className="pl pl-1">他得听上帝之言，</span><br /><span className="pl pl-1">明白至高者的旨意，</span><br /><span className="pl pl-1">俯伏在地，眼目睁开，</span><br /><span className="pl pl-1">得见全能者的异象。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="启示录 22:16; 路加福音 1:32–33; 创世记 49:10"> <span className="pl pl-1">我所见的尚未发生，</span><br /><span className="pl pl-1">我目睹的关乎将来。</span><br /><span className="pl pl-1">一颗星要从雅各家升起，</span><br /><span className="pl pl-1">一位君王要从以色列兴起。</span><br /><span className="pl pl-1">他要打烂摩押的前额，</span><br /><span className="pl pl-1">击碎塞特人的头颅。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司书 9:12; 创世记 27:29; 撒母耳记下 8:14"> <span className="pl pl-1">他必征服以东，</span><br /><span className="pl pl-1">占领敌疆西珥，</span><br /><span className="pl pl-1">以色列必勇往直前。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="创世记 49:10; 弥迦书 5:2; 诗篇 2:1–12"> <span className="pl pl-1">雅各的后裔必掌权，</span><br /><span className="pl pl-1">消灭城中的余民。”</span></span>
</div>
</div>

## 巴兰最后的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 17:14; 士师记 6:3; 历代志上 4:43"> 巴兰观看亚玛力人，并以诗歌预言说：<br /><span className="pl pl-1">“亚玛力原是列国之首，</span><br /><span className="pl pl-1">但他的结局却是灭亡。”</span></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:19; 士师记 1:16; 约伯记 29:18"> 巴兰又观看基尼人，并以诗歌预言说：<br /><span className="pl pl-1">“虽然你的居所坚固，</span><br /><span className="pl pl-1">你的巢筑在峭壁，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 83:8; 创世记 10:22; 以斯拉记 4:2"> <span className="pl pl-1">但你必遭灭顶，</span><br /><span className="pl pl-1">被亚述掳去。”</span></span>
<span className="v" id="v23" data-v="23" data-xref="民数记 23:23; 玛拉基书 3:2; 列王纪下 5:1"> 巴兰又以诗歌预言说：<br /><span className="pl pl-1">“唉！若上帝做这事，</span><br /><span className="pl pl-1">谁能存活呢？</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 10:4; 民数记 24:20; 但以理书 10:20"> <span className="pl pl-1">船只从基提驶来，</span><br /><span className="pl pl-1">征服亚述和希伯，</span><br /><span className="pl pl-1">但他也要灭亡。”</span></span>
<span className="v" id="v25" data-v="25" data-xref="民数记 31:8; 约书亚记 13:22; 民数记 24:11"> 说完，巴兰动身返回家乡，巴勒也回去了。</span>
</div>

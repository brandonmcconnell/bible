## 利未人的职分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 6:20; 创世记 10:1; 出埃及记 6:16"> 以下是耶和华在西奈山与摩西说话期间亚伦和摩西的后代。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:23; 民数记 26:60; 出埃及记 28:1"> 亚伦的长子是拿答，其他儿子是亚比户、以利亚撒和以他玛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:41; 利未记 8:30; 利未记 8:12"> 亚伦的儿子都是受膏的祭司，由摩西授予他们圣职做祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 10:1–2; 民数记 26:61"> 拿答和亚比户在西奈旷野用凡火向耶和华献祭时死在祂面前，没有留下儿子，因而只剩下以利亚撒和以他玛在父亲亚伦身边担任祭司。</span>
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:8; 民数记 2:33; 民数记 1:49–53"> “你去叫利未支派来协助亚伦祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 1:50; 民数记 8:15; 民数记 8:11"> 他们要为亚伦和全体会众在会幕司职，办理圣幕的事务，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:33; 民数记 10:17; 以赛亚书 52:11"> 也要负责看守会幕里面的所有器具，为以色列人办理圣幕的事务。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 8:19; 民数记 18:6–7; 以弗所书 4:8"> 你要把利未人交给亚伦父子们，因为他们是从以色列人中选出来单单协助亚伦的。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 1:51; 民数记 3:38; 罗马书 12:7"> 你要指派亚伦父子们尽祭司的职分，外人若近前来，必被处死。”</span>
<span className="v" id="v11" data-v="11"> 耶和华又对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 3:41; 民数记 8:16; 民数记 18:6"> “我从以色列人中拣选利未人代替以色列人所有的长子。利未人要属于我，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及记 13:12; 出埃及记 13:2"> 因为所有头生的都属于我。我杀死埃及人所有的长子和头生的牲畜那天，已把以色列人所有的长子和头生的牲畜都分别出来，使之圣洁，归给我。我是耶和华。”</span>
<span className="v" id="v14" data-v="14"> 耶和华在西奈旷野对摩西说：</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:62; 马可福音 10:14; 提摩太后书 3:15"> “你要按利未人的宗族和家系统计他们的人口，登记所有年龄在一个月以上的男性。”</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:39; 民数记 4:37; 民数记 4:49"> 于是，摩西照耶和华的吩咐统计利未人。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 46:11; 出埃及记 6:16–19; 民数记 15:5–23"> 利未的儿子是革顺、哥辖和米拉利。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:17; 历代志上 26:1–32; 出埃及记 6:17–19"> 按照宗族，革顺的儿子是立尼和示每。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 15:17–21"> 按照宗族，哥辖的儿子是暗兰、以斯哈、希伯仑和乌薛。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 6:19; 历代志上 6:19; 民数记 3:33"> 按照宗族，米拉利的儿子是抹利和姆示。他们按家系都属于利未人的宗族。</span>
<span className="v" id="v21" data-v="21"> 革顺宗族有立尼和示每两个家族，</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 4:38–40"> 其中年龄在一个月以上的男性共七千五百人。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:53; 民数记 2:17"> 革顺宗族要在圣幕后面，即西面安营，</span>
<span className="v" id="v24" data-v="24"> 家族首领是拉伊勒的儿子以利雅萨。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 25:9; 历代志上 23:32; 历代志上 9:14–33"> 革顺人负责看守会幕，即圣幕、圣幕的罩棚、顶盖和门帘、</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 38:9–16; 出埃及记 27:9–16"> 围绕圣幕和祭坛的院子的帷幔、门帘、绳索及一切相关的物品。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 26:23; 民数记 3:19; 历代志上 23:12"> 哥辖宗族有暗兰家族、以斯哈家族、希伯仑家族和乌薛家族，</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 3:31; 民数记 4:35–36; 民数记 3:7"> 其中年龄在一个月以上的男性共有八千六百人，他们负责看守圣所。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:53; 民数记 3:23; 民数记 2:10"> 哥辖宗族要在圣幕南面安营，</span>
<span className="v" id="v30" data-v="30"> 家族首领是乌薛的儿子以利撒反。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 36:35–36; 出埃及记 27:1–8; 出埃及记 26:31–33"> 他们负责照管约柜、桌子、灯台、两座坛、圣所内用的器具、幔子及一切物品。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 4:27; 民数记 4:16; 民数记 20:25–28"> 亚伦祭司的儿子以利亚撒是利未人的最高首领，负责监督那些照料圣所的人。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 3:20; 历代志上 6:19; 历代志上 23:21"> 米拉利宗族有抹利和姆示两个家族，</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 2:9; 民数记 2:11; 民数记 1:21"> 其中年龄在一个月以上的男性共六千二百人，</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 1:53; 民数记 2:25; 民数记 3:28–29"> 家族领袖是亚比亥的儿子苏列。他们要在圣幕的北面安营。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 26:32; 出埃及记 26:37; 出埃及记 26:15–29"> 米拉利人负责照管圣幕的木板、横闩、柱子、带凹槽的底座、圣幕的一切器具和所有相关事务，</span>
<span className="v" id="v37" data-v="37"> 还有院子四周的柱子及其带凹槽的底座、橛子和绳索。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 3:10; 民数记 1:53; 民数记 2:3"> 摩西、亚伦和亚伦的儿子们要在圣幕东面、朝日出的方向安营，替以色列人在圣所司职。外人若近前来，必被处死。</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 26:62; 马太福音 7:14; 民数记 4:47–48"> 摩西和亚伦照耶和华的吩咐，按宗族统计利未人，年龄在一个月以上的男性共两万二千人。</span>
</div>
</div>

## 利未人代替长子的地位

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数记 3:15; 路加福音 10:20; 诗篇 87:6"> 耶和华对摩西说：“你要统计以色列人中年龄在一个月以上的长子，登记他们的名字。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 3:12; 民数记 3:45; 民数记 8:16"> 我是耶和华，你要把利未人归给我，代替以色列人所有的长子，也要把利未人的牲畜献给我，代替以色列人所有头生的牲畜。”</span>
<span className="v" id="v42" data-v="42"> 摩西就照耶和华的吩咐，统计了以色列人的所有长子，</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 3:39"> 年龄在一个月以上的共两万二千二百七十三人。</span>
<span className="v" id="v44" data-v="44"> 耶和华又对摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 3:12; 民数记 3:40–41"> “你要用利未人代替以色列人所有的长子，用利未人的牲畜代替以色列人所有头生的牲畜。利未人是属于我的，我是耶和华。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 13:13; 民数记 18:15–16"> 以色列人所有长子的人数比利未人总数多二百七十三人，这些多出来的人需要被赎回，</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 30:13; 利未记 27:6; 民数记 18:16"> 每人一两银子，要以圣所的秤为准，即一舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约合十一克。">a</a></sup>是二十季拉。</span>
<span className="v" id="v48" data-v="48"> 要把多出来之人的赎银交给亚伦父子们。”</span>
<span className="v" id="v49" data-v="49"> 摩西就收取了利未人所赎人数之外那些多出来之人的赎银，</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 3:46–47; 彼得前书 3:18; 马太福音 20:28"> 以圣所的秤计算，共从以色列人的长子收取了二百七十三两银子。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:48; 民数记 16:15; 撒母耳记上 12:3–4"> 他照耶和华的吩咐，将赎银交给亚伦父子们。</span>
</div>

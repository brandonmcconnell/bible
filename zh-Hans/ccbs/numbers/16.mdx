## 可拉之乱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="犹大书 1:11; 申命记 11:6; 出埃及记 6:21"> 可拉是利未的曾孙、哥辖的孙子、以斯哈的儿子。他跟吕便支派以利押的两个儿子大坍和亚比兰，以及比勒的儿子安，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 26:9; 以西结书 23:10; 创世记 6:4"> 联合二百五十名在以色列会众中有声望的首领反叛摩西，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 106:16; 民数记 14:14; 出埃及记 19:6"> 一起攻击摩西和亚伦，说：“你们太过分了！全体会众都是圣洁的，有耶和华住在他们当中，你们凭什么将自己置于耶和华的会众之上？”</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 14:5; 民数记 20:6; 约书亚记 7:6"> 摩西听了这话，就俯伏在地，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 65:4; 民数记 17:5; 提摩太后书 2:19"> 对可拉一伙人说：“到了明天早上，耶和华必显明谁是属于祂的，谁是圣洁的。祂必让祂所拣选的人到祂面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 10:1; 民数记 16:46–48; 列王纪上 18:21–23"> 可拉啊，你们要这样做，你和你的同伙明天带香炉来，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 16:3; 以弗所书 1:4; 列王纪上 18:17–18"> 在耶和华面前点火添香。耶和华拣选谁，谁就是圣洁的。你们利未人太过分了！”</span>
<span className="v" id="v8" data-v="8"> 摩西又对可拉说：“利未人啊，你们听我说！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 7:13; 申命记 10:8; 以西结书 44:10–11"> 以色列的上帝把你们从以色列会众中分别出来，使你们可以到祂面前，在祂的圣幕里司职，替会众办事，你们还不满足吗？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 约翰三书 1:9; 民数记 18:7"> 可拉啊，耶和华使你和其他利未人事奉祂，你们还要贪求祭司的职分吗？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:7–8; 出埃及记 17:2; 民数记 16:3"> 其实你和你的同伙合谋反叛的是耶和华。亚伦是何人，你们竟埋怨他？”</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 2:13–14; 犹大书 1:8; 箴言 29:9"> 摩西派人去召以利押的儿子大坍和亚比兰，他们却说：“我们不去！</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:35; 出埃及记 2:14; 民数记 11:5"> 你带我们离开奶蜜之乡，要让我们死在旷野，这还不够吗？你还想自立为王管辖我们吗？</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:24; 民数记 36:8–10; 民数记 20:5"> 你并没有领我们到奶蜜之乡，也没有给我们田地和葡萄园作产业，你还想继续蒙骗我们吗？我们不去！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 4:4–5; 哥林多后书 7:2; 帖撒罗尼迦前书 2:10"> 摩西非常愤怒，就对耶和华说：“求你不要接纳他们的祭物。我没有取过他们一头驴，也没有害过他们任何人。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 12:3; 撒母耳记上 12:7; 提摩太后书 2:14"> 摩西对可拉说：“明天你和你的同伙要跟亚伦一起站在耶和华面前。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:7"> 每人要拿自己的香炉，放上香，带到耶和华面前，共二百五十个。你和亚伦也要各拿自己的香炉。”</span>
<span className="v" id="v18" data-v="18"> 于是，他们都拿着香炉，盛着火和香，跟摩西和亚伦一起站在会幕门口。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 14:10; 民数记 16:42; 出埃及记 16:7"> 可拉把全体会众招聚到会幕门口，要对付摩西和亚伦。这时，耶和华的荣光向全体会众显现。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:45; 出埃及记 32:10; 诗篇 73:19"> “你们离开这些会众，我好在顷刻之间消灭他们。”</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 27:16; 撒迦利亚书 12:1; 约伯记 12:10"> 摩西和亚伦就伏在地上说：“上帝啊，赐人生命气息的上帝啊！一人犯罪，你就要向全体会众发怒吗？”</span>
<span className="v" id="v23" data-v="23"> 耶和华对摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 16:21"> “你叫会众离可拉、大坍和亚比兰的帐篷远一点。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 11:16–17; 民数记 11:25; 民数记 11:30"> 于是，摩西起来去大坍和亚比兰那里，以色列的长老也跟着他。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 启示录 18:4"> 他对会众说：“你们离这些恶人的帐篷远一点，不要碰他们的任何东西，免得你们因他们的罪而受牵连，同遭毁灭。”</span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 9:4; 以赛亚书 28:14; 约伯记 40:10–11"> 会众便离开可拉、大坍和亚比兰的帐篷。大坍和亚比兰带着妻小出来，站在自己的帐篷门口。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:38; 出埃及记 3:12; 约翰福音 14:11"> 摩西对会众说：“你们很快就知道，我所做的事都是奉耶和华之命而行，并非出于私意。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王纪上 22:28; 出埃及记 32:34"> 如果这些人像常人一样死去，遭遇跟世人无异，我就不是耶和华派来的。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 55:15; 民数记 16:33; 约伯记 31:3"> 但如果耶和华做一件前所未有的事，使地裂开，吞下他们和属于他们的一切，使他们活生生地坠入阴间，你们就知道这些人藐视耶和华了。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 106:17–18; 民数记 27:3; 申命记 11:6"> 摩西的话刚说完，这些人脚下的地就裂开，</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:17; 民数记 26:11; 启示录 12:16"> 吞下了他们和他们的家眷，以及所有可拉一伙的人和财物。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 32:18; 以赛亚书 14:9; 诗篇 9:15"> 他们和属于他们的一切就这样活活地坠入阴间，地在他们上面合拢起来，他们就从会众中灭亡了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 14:5; 以赛亚书 33:3; 启示录 6:15–17"> 他们四围的以色列人听到他们的喊叫声，纷纷逃跑，生怕自己也被地吞下去。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 26:10; 利未记 10:2; 诗篇 106:18"> 耶和华又降下烈火，烧死了那二百五十个献香的人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 耶和华对摩西说：</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 27:28; 民数记 16:18; 民数记 16:7"> “你叫亚伦祭司的儿子以利亚撒去从火中把香炉捡起来，把炭火撒在远处，因为那些香炉是圣洁的。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 26:10; 以西结书 14:8; 彼得后书 2:6"> 要把那些因犯罪而丧命之人的香炉打成薄片，用来包祭坛，因为那些香炉曾被献在耶和华面前，是圣洁的，并且可让以色列人引以为戒。”</span>
<span className="v" id="v39" data-v="39"> 于是，以利亚撒祭司取来被烧死之人所献的铜香炉，叫人打成薄片用来包祭坛，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 3:10; 民数记 18:4–7; 历代志下 26:16–21"> 让以色列人引以为戒，使亚伦子孙以外的人不致到耶和华面前烧香，以免像可拉及其同伙一样灭亡。这是按照耶和华借摩西的吩咐做的。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 16:1–7; 诗篇 106:23; 民数记 14:2"> 第二天，以色列全体会众都埋怨摩西和亚伦说：“你们害死了耶和华的子民。”</span>
<span className="v" id="v42" data-v="42" data-xref="民数记 16:19; 利未记 9:23; 民数记 20:6"> 会众聚集起来反对摩西和亚伦，他们向会幕观看，忽然有云彩遮盖了会幕，耶和华的荣光显现。</span>
<span className="v" id="v43" data-v="43"> 摩西和亚伦来到会幕前，</span>
<span className="v" id="v44" data-v="44"> 耶和华对摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 16:21–22; 民数记 16:24; 民数记 20:6"> “你们离开这些会众，我好在顷刻之间消灭他们。”他们二人就俯伏在地。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 8:19; 历代志上 27:24; 利未记 10:6"> 摩西对亚伦说：“取香炉来，里面放些祭坛上的火，添上香，赶快带到会众那里为他们赎罪，因为耶和华发怒了，瘟疫已经开始。”</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 5:44; 申命记 33:10–11; 诗篇 106:29"> 亚伦就照着摩西的吩咐取来香炉，跑到会众当中。那时瘟疫已经在人群中蔓延起来。他就在炉中放上香为民众赎罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳记下 24:25; 希伯来书 7:24–25; 民数记 16:18"> 他站在活人和死人之间，瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 25:9; 民数记 16:32–35; 希伯来书 2:1–3"> 除了在可拉事件中死亡的人以外，有一万四千七百人死于瘟疫。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志上 21:26–30; 民数记 16:43"> 瘟疫止住后，亚伦便回到在会幕门口的摩西那里。</span>
</div>
</div>

## 以色列的第一次人口统计

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:22; 出埃及记 19:1; 民数记 10:11–12"> 以色列人离开埃及后第二年的二月一日，耶和华在西奈旷野的会幕中对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 38:26; 出埃及记 30:12; 民数记 1:18"> “你要按以色列人的宗族和家系统计全体会众，登记所有男子的名字。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:14; 民数记 14:29; 民数记 33:1"> 你和亚伦要一队一队地统计以色列人中所有二十岁以上、有作战能力的男子。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 1:16; 出埃及记 18:25; 民数记 13:2–15"> 每一支派要有一个人来协助你们。他们都是各宗族的族长，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:30; 创世记 30:5–20; 创世记 49:1–33"> 名单如下：<br />“吕便支派示丢珥的儿子以利苏、</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 7:36; 民数记 2:12"> 西缅支派苏利沙代的儿子示路蔑、</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民数记 10:14; 马太福音 1:2–5"> 犹大支派亚米拿达的儿子拿顺、</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 7:18; 民数记 10:15; 民数记 2:5"> 以萨迦支派苏押的儿子拿坦业、</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 7:24; 民数记 10:16; 民数记 2:7"> 西布伦支派希伦的儿子以利押、</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 7:54; 民数记 7:48; 历代志上 7:26–27"> 约瑟的后裔——以法莲支派亚米忽的儿子以利沙玛和玛拿西支派比大苏的儿子迦玛列、</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 7:60; 民数记 10:24; 民数记 2:22"> 便雅悯支派基多尼的儿子亚比但、</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 7:66; 民数记 2:25; 民数记 10:25"> 但支派亚米沙代的儿子亚希以谢、</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 7:72; 民数记 10:26; 民数记 2:27"> 亚设支派俄兰的儿子帕结、</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 2:14; 民数记 7:42; 民数记 10:20"> 迦得支派丢珥的儿子以利雅萨、</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:78; 民数记 10:27; 民数记 2:29"> 拿弗他利支派以南的儿子亚希拉。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 7:2; 出埃及记 18:21; 出埃及记 18:25"> 他们都是从会众中选出来的，是各支派的首领，也是以色列的将领。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:3; 启示录 7:4–17; 民数记 1:5–15"> 摩西和亚伦带着这些被点名的人，</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 2:59; 尼希米记 7:61; 希伯来书 7:3"> 在二月一日招聚全体会众，按照宗族和家系统计人口，一一登记所有二十岁以上的男子。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:2; 民数记 26:1–2; 撒母耳记下 24:1–10"> 摩西照耶和华的吩咐在西奈旷野统计人口。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:5–7; 民数记 2:10–11; 创世记 46:9"> 以色列的长子吕便支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有四万六千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 26:12–14; 创世记 34:25–30; 民数记 2:12–13"> 西缅支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有五万九千三百人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 26:15–18; 创世记 46:16; 民数记 2:14–15"> 迦得支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有四万五千六百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 29:35; 民数记 26:19–22; 撒母耳记下 24:9"> 犹大支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有七万四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 46:13; 创世记 49:14–15; 创世记 30:18"> 以萨迦支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有五万四千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 26:26–27; 创世记 49:13; 创世记 30:20"> 西布伦支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有五万七千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 26:35–37; 申命记 33:17; 创世记 46:20"> 约瑟的后裔中，以法莲支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有四万零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 26:28–34"> 玛拿西支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有三万二千二百人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 49:27; 创世记 44:20; 启示录 7:8"> 便雅悯支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有三万五千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 46:23; 创世记 30:5–6; 创世记 49:16–17"> 但支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有六万二千七百人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="创世记 30:12–13; 创世记 46:27; 创世记 49:20"> 亚设支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有四万一千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="创世记 49:21; 民数记 26:48–50; 创世记 46:24"> 拿弗他利支派中，二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，共有五万三千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民数记 26:64; 民数记 1:2–16"> 以上就是摩西、亚伦和各代表自己族系的十二位以色列首领所统计的男子人数。</span>
<span className="v" id="v45" data-v="45"> 这样，以色列人中二十岁以上、有作战能力的男子按宗族、家系和名字一一被登记下来，</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 12:37; 民数记 26:51; 出埃及记 38:26"> 共有六十万三千五百五十人。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 2:33; 民数记 3:1–49; 民数记 26:57–62"> 然而，利未人没有按祖先的支派列在其中，</span>
<span className="v" id="v48" data-v="48"> 因为耶和华曾经对摩西说：</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 26:62; 民数记 2:33"> “你不可统计利未支派的人数，不可把他们的人数算在以色列人中。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 38:21; 出埃及记 31:18; 民数记 4:15"> 你要派利未人管理、搬运和照料放约柜的圣幕及其所有器具和附属物，他们要在圣幕四围扎营。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:38; 民数记 3:10; 撒母耳记上 6:19"> 在迁移的时候，利未人要负责拆卸和支搭圣幕。外人若近前来，必被处死。</span>
<span className="v" id="v52" data-v="52" data-xref="民数记 2:2; 民数记 2:34; 民数记 10:1–36"> 以色列人要按照他们的队伍各自扎营，各归本旗。</span>
<span className="v" id="v53" data-v="53" data-xref="民数记 16:46; 历代志上 23:32; 利未记 10:6"> 但利未人要在安放约柜的圣幕四周扎营，以免以色列人触怒耶和华。利未人负责看守放约柜的圣幕。”</span>
<span className="v" id="v54" data-v="54" data-xref="申命记 12:32; 出埃及记 40:16; 出埃及记 39:32"> 以色列人就按耶和华对摩西的吩咐行了。</span>
</div>
</div>

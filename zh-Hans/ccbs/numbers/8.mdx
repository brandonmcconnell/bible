## 安置七盏灯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 25:37; 出埃及记 40:25; 利未记 24:1–2"> “你告诉亚伦，‘你安放灯的时候，七盏灯都要照在灯台前面。’”</span>
<span className="v" id="v3" data-v="3"> 亚伦就照耶和华对摩西的吩咐把灯放好，使灯照亮灯台前面。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:31–40; 出埃及记 25:9; 出埃及记 25:18"> 整座灯台，从灯座到花朵，都是照耶和华指示摩西的样式用金子锤制而成的。</span>
</div>
</div>

## 为利未人行洁净与奉献礼

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 7:1; 雅各书 4:8; 出埃及记 19:15"> “你要把利未人从其他以色列人中分别出来，洁净他们。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 19:13; 民数记 19:7–10; 利未记 8:6"> 要用以下的方法洁净他们，把洁净水洒在他们身上，叫他们用剃刀剃净全身，洗净衣服，这样他们就洁净了。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 2:1; 出埃及记 29:1; 利未记 16:3"> 然后叫他们带来一头公牛犊及作素祭的调了油的细面粉，你要另献一头公牛犊作赎罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 40:12; 利未记 8:3; 出埃及记 29:4–37"> 你要招聚以色列全体会众，将利未人带到会幕前，</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 使徒行传 6:6; 提摩太前书 4:14"> 带到耶和华面前，会众要把手按在他们身上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 7:30; 利未记 8:29; 民数记 1:49–53"> 亚伦要把他们献给耶和华，作为以色列人献的摇祭，使他们可以事奉耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4–10; 出埃及记 29:10; 利未记 1:4"> 利未人要把手按在那两头公牛的头上，然后你要把一头作为赎罪祭，一头作为燔祭献给耶和华，好为利未人赎罪。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 8:21; 民数记 8:11; 罗马书 15:16"> 你要让利未人站在亚伦父子们面前，把他们当作摇祭献给耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 3:45; 玛拉基书 3:17; 民数记 18:6"> 这样，你就把利未人从其他以色列人中分别出来，使他们归给我。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 8:11; 民数记 8:13; 民数记 3:23–37"> 利未人被洁净、当作摇祭献上以后，就可以进会幕司职，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:12; 民数记 3:45; 民数记 3:9"> 因为在以色列人中，他们完全属于我，我拣选他们归我所有，以代替以色列人所有的长子。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 13:2; 路加福音 2:23; 出埃及记 13:12–15"> 以色列人所有的长子和头生的牲畜都属于我。我击杀埃及人所有的长子和头生的牲畜那天，已把以色列人所有的长子和头生的牲畜都分别出来，使之圣洁，归给我。</span>
<span className="v" id="v18" data-v="18"> 我现在已拣选利未人代替以色列人所有的长子。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:53; 民数记 16:46; 历代志下 26:16–20"> 我从以色列人中把利未人作为礼物交给亚伦父子们，替以色列人在会幕中司职，为以色列人赎罪，免得以色列人因接近圣所而遭祸。”</span>
<span className="v" id="v20" data-v="20"> 摩西、亚伦和以色列全体会众，就按照耶和华对摩西的吩咐把利未人献上。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 8:7; 民数记 19:19; 民数记 8:15"> 利未人自洁、洗净衣服后，亚伦把他们当作摇祭献给耶和华，又为他们赎罪，使他们洁净。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:2; 历代志下 35:8–15; 民数记 8:15"> 之后，利未人便进入会幕，在亚伦父子们的监督下司职。以色列人照耶和华对摩西的吩咐奉献了利未人。</span>
<span className="v" id="v23" data-v="23"> 耶和华对摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:3; 历代志上 23:3; 民数记 4:23"> “二十五岁以上的利未人都要到会幕司职，</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 4:23; 提摩太后书 4:7"> 五十岁时退休，不再司职。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:53; 民数记 3:32; 提摩太前书 4:15"> 退休之后，他们可以协助本族弟兄看守会幕，不用再司职。你要这样给他们分派工作。”</span>
</div>
</div>

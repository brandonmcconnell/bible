## 灵的分辨

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:21; 彼得后书 2:1; 提摩太前书 4:1"> 亲爱的弟兄姊妹，不要什么灵都信，总要试验那些灵是否出于上帝，因为许多假先知已经来到世上！</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:14; 哥林多前书 12:3; 提摩太前书 3:16"> 任何灵若承认耶稣基督曾降世为人，就是从上帝来的，你们可以凭这一点认出上帝的灵。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 2:22; 约翰二书 1:7; 约翰一书 2:18"> 任何灵若不承认耶稣，就不是从上帝来的，而是敌基督者的灵。以前你们听说敌基督者要来，现在他已经在世上了。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:31; 约翰一书 5:4; 罗马书 8:37"> 孩子们，你们属于上帝，并且已经胜过那些假先知，因为在你们里面的灵比世上的灵更大。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:23; 彼得后书 2:2–3; 约翰福音 17:14"> 他们属于世界，所以谈论世界的事，世人也听从他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:17; 约翰福音 10:27; 哥林多前书 2:12–14"> 我们属于上帝，认识上帝的人听从我们，不属于上帝的人不听从我们。这样，我们就可以分辨真理的灵和错谬的灵。</span>
</div>
</div>

## 上帝是爱

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:20–1; 约翰一书 4:8; 彼得前书 1:22"> 亲爱的弟兄姊妹，我们要彼此相爱，因为爱是从上帝来的。凡爱人者都是从上帝生的，并且认识上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:16; 诗篇 86:15; 哥林多后书 13:11"> 不爱人者不认识上帝，因为上帝就是爱。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:16; 约翰一书 5:11; 罗马书 8:32"> 上帝差遣祂独一的儿子到世上来，是为了叫我们靠祂而活，从而显明了祂对我们的爱。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:4–5; 罗马书 5:8–10; 约翰一书 4:19"> 不是我们爱上帝，而是上帝爱我们，并且差遣祂儿子为我们的罪作了赎罪祭，这就是爱。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12–13; 歌罗西书 3:13; 约翰福音 13:34"> 亲爱的弟兄姊妹，上帝既然这样爱我们，我们也理当彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:18; 约翰一书 2:5; 约翰一书 4:17–18"> 从来没有人见过上帝，如果我们彼此相爱，上帝就住在我们里面，祂的爱也在我们身上完全流露出来。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:20–22; 约翰一书 3:24; 哥林多前书 3:16–17"> 上帝将祂的灵赐给了我们，所以我们知道自己住在祂里面，祂也住在我们里面。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:10; 约翰福音 3:16–17; 约翰福音 4:42"> 我们看见过，现在做见证：父差遣了祂的儿子成为世人的救主。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 10:9; 约翰一书 5:5; 马太福音 10:32"> 无论是谁，他若承认耶稣是上帝的儿子，上帝必住在他里面，他也住在上帝里面。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 3:24; 诗篇 36:7–9; 约翰一书 3:1"> 我们已经认识并且相信上帝对我们的爱。 上帝就是爱，住在爱中的，就是住在上帝里面，上帝也住在他里面。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:12; 约翰一书 2:28; 罗马书 8:29"> 这样，爱就在我们身上得以纯全，使我们在审判的日子可以坦然无惧，因为我们在这世上像耶稣一样。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太后书 1:7; 罗马书 8:15; 约翰一书 4:12"> 爱里没有恐惧，纯全的爱能驱除恐惧，因为恐惧意味着怕受惩罚。恐惧的人尚未在爱中得以纯全。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:10; 约翰福音 3:16; 约翰福音 15:16"> 我们爱，因为上帝先爱了我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 3:17; 约翰一书 2:9; 约翰一书 4:12"> 人若声称爱上帝，却恨自己的弟兄姊妹，就是说谎的，因为人若不爱看得见的弟兄姊妹，又怎能爱看不见的上帝呢？</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 22:37–39; 利未记 19:18; 约翰一书 3:11"> 爱上帝的人也要爱弟兄姊妹，这是上帝给我们的命令。</span>
</div>
</div>

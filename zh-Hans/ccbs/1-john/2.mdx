<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:5; 罗马书 8:34; 约翰福音 14:6"> 我的孩子们，我写这些话给你们，是为了叫你们不要犯罪。如果有人犯了罪，在父那里我们有一位护慰者，就是那位义者耶稣基督。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:14; 彼得前书 3:18; 约翰一书 4:10"> 祂为我们的罪作了赎罪祭，不只是为我们的罪，也是为天下人的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 路加福音 6:46"> 我们若遵行上帝的命令，就知道自己确实认识祂。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 1:6; 提多书 1:16; 雅各书 2:14–16"> 若有人说“我认识祂”，却不遵行祂的命令，这人是说谎的，他里面没有真理。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 14:23; 约翰福音 14:21; 约翰一书 4:12–13"> 人若遵行祂的道，就完全活出了祂的爱，我们借此知道自己是在祂里面。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:21; 约翰福音 13:15; 哥林多前书 11:1"> 所以，自称住在祂里面的人，行事为人理当和耶稣一样。</span>
</div>
</div>

## 新命令

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:11; 利未记 19:18; 马可福音 12:29–34"> 亲爱的弟兄姊妹，我写给你们的并不是一条新命令，而是你们起初接受的旧命令，这旧命令就是你们已经听过的道。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:8; 罗马书 13:12; 约翰福音 13:34"> 然而，我写给你们的也是新命令，在基督和你们身上都显明是真实的，因为黑暗渐渐消逝，真光已经在照耀。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 4:20; 约翰一书 2:11; 约翰一书 3:13–17"> 人若说自己在光明中，却恨他的弟兄姊妹，他仍然活在黑暗里。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 3:14; 罗马书 9:32–33; 罗马书 14:13"> 爱弟兄姊妹的人住在光明中，没有什么可以绊倒他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“没有什么可以绊倒他”或译“他也不会绊倒别人”。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:35; 提多书 3:3; 约翰一书 1:6"> 恨弟兄姊妹的人活在黑暗中，走在黑暗中，不知何去何从，因为黑暗弄瞎了他的眼睛。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:43; 使徒行传 13:38; 以弗所书 1:7"> 孩子们，我写信给你们，因为靠着祂的名，你们的罪已经得到赦免。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:7; 约翰一书 2:14; 路加福音 10:22"> 父老们，我写信给你们，因为你们已经认识从太初就存在的那位。年轻人，我写信给你们，因为你们已经战胜了那恶者。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 119:11; 约翰一书 2:13; 歌罗西书 3:16"> 孩子们，我曾写信给你们，因为你们认识了父。父老们，我曾写信给你们，因为你们认识了从太初就存在的那位。年轻人，我曾写信给你们，因为你们刚强，上帝的道常在你们里面，并且你们战胜了那恶者。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 4:4; 罗马书 12:2; 马太福音 6:24"> 不要爱世界和世上的事，因为人若爱世界，就不会再有爱父的心了。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 13:14; 加拉太书 5:17; 诗篇 119:36–37"> 凡属世界的，如肉体的私欲、眼目的私欲和今生的骄傲都不是从父那里来的，而是从世界来的。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:35; 罗马书 12:2; 哥林多前书 7:31"> 这世界和其中一切的私欲都在消逝，但遵守上帝旨意的人永远长存。</span>
</div>
</div>

## 防备敌基督者

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:3; 约翰二书 1:7; 马太福音 24:24"> 孩子们，现在是末世了。你们从前听说敌基督者要来，其实现在许多敌基督者已经出现了，由此可知，现在是末世了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 20:30; 哥林多前书 11:19; 路加福音 8:13"> 这些人是从我们中间出去的，但他们不属于我们。他们如果属于我们，就会留在我们当中。他们的离去显明他们都不属于我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:26; 约翰一书 2:27; 哥林多后书 1:21–22"> 你们从那位圣者领受了恩膏，所以明白真理。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 1:12; 犹大书 1:5; 箴言 1:5"> 我写信给你们，不是因为你们不明白真理，而是因为你们明白真理，并且知道真理中毫无谎言。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰二书 1:7; 约翰一书 4:3; 约翰一书 2:18"> 谁是说谎的呢？不就是那否认耶稣是基督的吗？那不承认父和子的就是敌基督者。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 4:15; 约翰福音 8:19; 约翰福音 5:23"> 凡否认子的，都没有父；凡承认子的，连父也有了。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 14:23; 约翰福音 15:9–10; 约翰一书 4:13"> 你们务要把起初所听见的道谨记在心，这样，你们就必住在子里面，也必住在父里面。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:28; 提多书 3:7; 犹大书 1:21"> 基督应许给我们的是永生。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:1–3; 约翰二书 1:7; 使徒行传 20:29–30"> 我写这些话给你们，是针对那些诱骗你们的人。</span>
</div>
</div>

## 顺从圣灵

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:26; 约翰一书 2:20–21; 哥林多前书 2:13"> 既然你们从那位圣者领受的恩膏常在你们里面，就无需他人指教你们，祂的恩膏必在一切事上指教你们。这恩膏真实无伪，你们要按这恩膏的指教住在基督里。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰一书 4:17; 马可福音 8:38; 约翰一书 3:2"> 孩子们，你们要住在基督里。这样，当祂显现的时候，就是祂再来的时候，我们便能坦然无惧，在祂面前不至羞愧。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 3:3–5; 约翰一书 3:7; 约翰一书 5:1"> 你们既然知道祂是公义的，也该知道所有行义的人都是从上帝生的。</span>
</div>
</div>

## 上帝的儿女

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12; 加拉太书 3:26; 哥林多后书 6:18"> 你们看，父上帝何等爱我们，称我们为祂的儿女！我们也实在是祂的儿女，世人之所以不认识我们，是因为他们不认识父上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:21; 歌罗西书 3:4; 哥林多前书 13:12"> 亲爱的弟兄姊妹，我们现在是上帝的儿女，将来如何还未显明。但我们知道，当基督显现的时候，我们会像祂，因为我们必见到祂的本相。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:1; 约翰一书 2:6; 彼得后书 3:14"> 凡心存这种盼望的人都会自洁，因为祂是圣洁的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 5:17; 罗马书 3:20; 罗马书 4:15"> 人犯罪就是违背上帝的律法，违背上帝的律法就是犯罪。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:21; 希伯来书 9:28; 彼得前书 3:18"> 你们知道，耶稣降世是为了除掉罪，祂里面毫无罪恶。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:11; 约翰一书 2:4; 约翰一书 3:9"> 住在祂里面的人不会犯罪；不断犯罪的人既没见过祂，也不认识祂。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 2:29; 彼得前书 1:15–16; 罗马书 2:13"> 孩子们，不要受人诱骗，行义的才是义人，正如耶稣是公义的。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 2:14; 约翰福音 8:44; 歌罗西书 2:15"> 一直犯罪的人是属魔鬼的，因为魔鬼从起初便犯罪，但上帝儿子的显现是为了摧毁魔鬼的工作。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 彼得前书 1:23; 约翰福音 1:13"> 从上帝生的人不会继续犯罪，因为他里面有上帝的生命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“上帝的生命”希腊文是“上帝的种子”。">a</a></sup>。他不能继续犯罪，因为他是从上帝生的。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:8; 约翰三书 1:11; 路加福音 6:35"> 这样，就可以看出谁是上帝的儿女，谁是魔鬼的儿女。凡不行义、不爱弟兄姊妹的人，都不是上帝的儿女。</span>
</div>
</div>

## 彼此相爱

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12; 约翰二书 1:5; 约翰一书 4:7"> 我们应当彼此相爱，这是你们起初听见的信息。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:4; 创世记 4:4–15; 箴言 29:27"> 不要步该隐的后尘。他属于那恶者，杀害了自己的弟弟。他为什么要杀害自己的弟弟呢？因为他行为邪恶，他弟弟却秉行公义。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 约翰福音 17:14; 路加福音 21:17"> 弟兄姊妹，世人若恨你们，不要惊奇。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:35; 约翰一书 5:2; 约翰一书 4:20–21"> 我们因爱弟兄姊妹，便知道自己已经出死入生了。不爱弟兄姊妹的，仍然陷在死亡中。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:21–22; 箴言 26:24–26; 启示录 21:8"> 恨弟兄姊妹的就是杀人的，你们知道：杀人者里面没有永生。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:9–11; 以弗所书 5:2; 约翰福音 13:34"> 耶稣为我们舍命，我们由此便知道什么是爱，我们也理当为弟兄姊妹舍命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:16; 以赛亚书 58:7–10; 申命记 15:7–11"> 如果一个丰衣足食的人看见贫穷的弟兄姊妹，却毫无怜悯之心，怎能说他爱上帝呢？</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 2:15–16; 罗马书 12:9; 彼得前书 1:22"> 所以，孩子们啊，不要单在言语和口头上说爱人，总要按真理行出来。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:22; 约翰一书 3:21; 希伯来书 6:10–11"> 这样，我们必知道自己属于真理，即使我们心中自责，也可以在上帝面前安心，因为上帝比我们的心大，祂洞悉一切。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:28; 希伯来书 4:16; 哥林多后书 1:12"> 亲爱的弟兄姊妹，我们若能凡事问心无愧，就可以在上帝面前坦然无惧。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 15:7; 约翰福音 9:31; 约翰一书 5:14"> 这样，我们无论向上帝祈求什么，都必得到，因为我们遵守祂的命令，做祂喜悦的事。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:29; 约翰福音 13:34; 彼得前书 1:22"> 上帝的命令是：我们要信祂儿子耶稣基督的名，遵照祂的命令彼此相爱。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 3:16; 约翰一书 4:15–16; 约翰一书 4:12–13"> 遵行上帝命令的人就住在上帝里面，上帝也住在他里面。我们借着上帝赐给我们的圣灵知道：祂住在我们里面。</span>
</div>
</div>

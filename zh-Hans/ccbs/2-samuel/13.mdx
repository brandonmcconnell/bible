## 暗嫩玷污她玛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:9; 撒母耳记下 3:2–3; 撒母耳记下 13:15"> 后来，大卫的儿子暗嫩爱上了美丽的她玛，她玛是大卫的儿子押沙龙的妹妹。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:10; 列王纪上 21:4; 雅歌 5:8"> 她仍是处女，住在深宫里，暗嫩无法接近她，相思成病。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:9; 哥林多前书 3:19; 雅各书 3:15"> 暗嫩有一个朋友名叫约拿达，是大卫长兄示米亚的儿子，生性狡猾。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:17; 利未记 18:9; 以斯帖记 5:13–14"> 他问暗嫩：“王子，你为什么一天比一天消沉？能告诉我吗？”暗嫩答道：“我爱上了我兄弟押沙龙的妹妹她玛。”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 6:24–25; 箴言 19:27; 使徒行传 23:15"> 约拿达说：“你回去躺在床上装病，你父亲来探望你的时候，你就请求他叫你妹妹她玛来，在你面前预备食物，请她亲手递给你吃。”</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:6; 马太福音 13:33"> 暗嫩就躺在床上装病。王来看他的时候，他便对王说：“请你叫我妹妹她玛来这里，在我面前做两个饼，请她亲自递给我吃。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大卫便派人进宫对她玛说：“你去你哥哥暗嫩房里为他预备食物吧。”</span>
<span className="v" id="v8" data-v="8"> 她玛到了哥哥暗嫩的家，暗嫩正躺在床上装病。她拿了面团在他面前揉面做饼，把饼烤熟了。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:1; 约翰福音 3:20; 士师记 3:19"> 她拿着锅在他面前把饼倒出来，但暗嫩却不肯吃。暗嫩命令仆人：“你们全都出去吧！”仆人就都退下了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩对她玛说：“你把食物拿到我的卧房来，亲手递给我吃。”她玛便拿着饼进了她哥哥暗嫩的卧房里，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:11–12"> 上前给他吃，暗嫩却抓住她，说：“妹妹，与我同寝吧！”</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 19:23; 利未记 20:17; 士师记 20:6"> 她玛说：“哥哥，不要，不要玷污我！在以色列不应当发生这种事，不要做这种恶事。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 19:24; 创世记 20:12; 创世记 19:8"> 你这样叫我怎么见人呢？你在以色列也必遭人唾弃。你可以请求王，他会同意把我许配给你。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 12:11; 以斯帖记 7:8; 士师记 20:5"> 暗嫩却充耳不闻，因为他力气比她玛大，就把她强奸了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 23:17"> 事后暗嫩非常憎恨她玛，对她的恨比以前对她的爱还强烈。他对她玛说：“你起来走吧！”</span>
<span className="v" id="v16" data-v="16"> 她玛哀求道：“不要这样对我！你赶我走是更大的恶行。”暗嫩却不听，</span>
<span className="v" id="v17" data-v="17"> 他吩咐随从：“把这女人赶出去，随后锁上门。”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:30; 创世记 37:3; 诗篇 45:13–14"> 他的随从就把她玛赶出去，随后锁上了门。那时，她玛穿着彩色的长衣，没有出嫁的公主都穿这种衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 耶利米书 2:37; 撒母耳记下 1:11"> 她玛把灰尘撒在头上，撕破身上的彩衣，双手抱着头，一面走一面哭。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:19; 创世记 46:15; 创世记 34:2"> 她的哥哥押沙龙问她：“是不是你哥哥暗嫩污辱了你？妹妹，不要声张，他是你哥哥，不要把这件事放在心上。”于是她玛就忧忧郁郁地住在押沙龙家里。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 34:7; 撒母耳记下 3:28–29; 撒母耳记上 2:29"> 大卫王听见了这件事以后，非常生气。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 19:17–18; 创世记 31:24; 创世记 24:50"> 押沙龙好话坏话都没有对暗嫩说一句话，只是心里暗暗地恨他，因为他玷污了妹妹她玛。</span>
</div>
</div>

## 押沙龙为妹妹报仇

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 38:12–13; 撒母耳记上 25:4; 历代志下 26:10"> 两年后，押沙龙的工人在以法莲附近的巴力·夏琐剪羊毛，押沙龙邀请王的众子去那里。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 11:8–15; 耶利米书 41:6–7; 诗篇 55:21"> 他去见王，说：“工人正在为仆人剪羊毛，请王和众臣仆跟仆人一起去吧。”</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士师记 19:7–10; 撒母耳记下 14:22"> 王说：“我儿，我们不必都去打扰你。”押沙龙再三邀请，王还是推辞了，但他为押沙龙祝福。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 20:9; 撒母耳记下 3:27; 撒母耳记下 11:13–15"> 押沙龙说：“王若不去，请让我兄弟暗嫩跟我们去吧。”大卫说：“何必要他同去呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 但押沙龙再三恳求，王就让暗嫩和其他王子一同去了。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 19:6; 士师记 19:22; 士师记 19:9"> 押沙龙吩咐仆人说：“你们要留意，当暗嫩喝得正高兴的时候，我叫你们动手，你们就要杀他。不要害怕，要刚强勇敢！因为这是我的命令。”</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 18:9; 列王纪上 1:33; 列王纪下 1:9–12"> 押沙龙的仆人就照命令把暗嫩杀了。王的众子都起来骑上骡子逃走了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 他们还在路上的时候，有人禀告大卫说：“押沙龙把王子都杀了，无一幸免！”</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 1:11; 撒母耳记下 12:16; 约伯记 1:20"> 王便站起来撕裂衣服，躺在地上。众臣仆也都撕裂衣服，站在旁边。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:9; 撒母耳记下 13:3; 创世记 27:41"> 大卫的长兄示米亚的儿子约拿达说：“我主不要以为所有的王子都被杀了，其实只有暗嫩一人死了。自从暗嫩奸污押沙龙的妹妹她玛以来，押沙龙便决定要报仇了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:19"> 所以，我主我王啊，不要相信这消息，不是所有的王子都死了，只有暗嫩一人死了。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 4:8–14; 箴言 28:17; 阿摩司书 5:19"> 此时，押沙龙已经逃走了。守望的人举目瞭望，见有一大群人从西面山坡的路上下来。</span>
<span className="v" id="v35" data-v="35"> 约拿达对王说：“请看，王子们都回来了！正如仆人所言。”</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:33; 撒母耳记下 12:21; 撒母耳记下 13:15"> 话刚说完，众王子已经来到他们跟前放声大哭，王和众臣仆也哀痛不已。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 3:3; 撒母耳记下 14:32; 撒母耳记下 13:34"> 押沙龙逃到了亚米忽的儿子基述王达买那里，在那里住了三年。大卫王天天为他儿子暗嫩悲伤，</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:67; 创世记 38:12; 创世记 37:35"> 后来心情恢复平静，开始想念押沙龙。</span>
</div>
</div>

</div>

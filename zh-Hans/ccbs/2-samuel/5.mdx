## 大卫统治全以色列

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 11:1–3; 撒母耳记下 19:13; 创世记 29:14"> 以色列各支派都来希伯仑见大卫，对他说：“看啊，我们是你的骨肉同胞。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:4; 以西结书 34:23"> 从前扫罗做王的时候，率领以色列人出征打仗的是你，耶和华也曾应许让你做祂以色列子民的牧者和首领。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:4; 撒母耳记上 16:13; 撒母耳记上 23:18"> 以色列的长老都到希伯仑见大卫王，大卫与他们在耶和华面前立约，他们膏立大卫做以色列的王。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:27; 路加福音 3:23; 列王纪上 2:11"> 大卫三十岁登基，执政共四十年。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 2:11; 历代志上 3:4; 列王纪上 2:11"> 他在希伯仑统治犹大七年半，在耶路撒冷统治以色列和犹大三十三年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 1:8; 耶利米书 37:10; 历代志上 11:4–9"> 大卫率领军队来到耶路撒冷，要攻打那里的耶布斯人。耶布斯人对大卫说：“你攻不进来，就连我们这里瞎眼的和瘸腿的都可以把你赶走。”他们以为大卫攻不进去。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 2:10; 撒母耳记下 6:16; 撒母耳记下 6:12"> 然而，大卫攻取了锡安的堡垒，即后来的大卫城。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:16–17; 历代志上 11:6–9; 撒母耳记上 17:25"> 那天，大卫下令军队从地下水道爬进城去，攻打那些“瞎眼的和瘸腿的”，他憎恶这些耶布斯人。后来便有一句俗语：“瞎眼的和瘸腿的不得进殿！”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:15; 列王纪上 9:24; 历代志下 32:5"> 大卫住在锡安的堡垒里，并称之为大卫城，他又从米罗向内兴建环城围墙。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 3:1; 罗马书 8:31; 诗篇 46:11"> 大卫日渐强盛，因为万军之上帝耶和华与他同在。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 14:1; 列王纪上 5:1–2; 列王纪上 5:18"> 泰尔王希兰差遣使者带着香柏木、木匠和石匠去为大卫建造宫殿。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 7:16; 列王纪上 10:9; 历代志上 14:2"> 那时，大卫知道耶和华已立他做以色列王，并因祂以色列子民的缘故而使他国家兴旺。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志上 3:9; 申命记 17:17; 历代志下 13:21"> 大卫从希伯仑迁到耶路撒冷以后，又选立妃嫔，生了更多儿女。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 3:5–9; 路加福音 2:31; 历代志上 14:4"> 他在耶路撒冷生的孩子有沙姆亚、朔罢、拿单、所罗门、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 3:6; 历代志上 14:5"> 益辖、以利书亚、尼斐、雅非亚、</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 3:8; 历代志上 14:7"> 以利沙玛、以利雅大和以利法列。</span>
</div>
</div>

## 大卫战胜非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 23:14; 历代志上 14:8–9; 历代志上 11:16"> 非利士人听说大卫已被膏立为以色列王，就全军出动，搜寻大卫。大卫听说后，便退到堡垒里。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:8; 撒母耳记下 23:13; 创世记 14:5"> 非利士人大军压境，散布在利乏音谷。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:1; 撒母耳记上 23:2; 撒母耳记下 5:23"> 大卫求问耶和华：“我可以去迎战非利士人吗？你会把他们交在我手里吗？”耶和华说：“去吧，我必把他们交在你手里。”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 28:21"> 大卫前往巴力·毗拉心，在那里打败了他们。他说：“耶和华像洪水决堤一样为我冲垮了仇敌。”因此那地方叫巴力·毗拉心<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“巴力·毗拉心”意思是“冲垮之主”。">a</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 14:11–12; 申命记 7:5; 撒母耳记上 5:2–6"> 大卫和他的军队带走了非利士人所丢弃的神像。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 14:13; 撒母耳记下 5:18; 列王纪上 20:22"> 后来非利士人又卷土重来，散布在利乏音谷。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 14:14; 马太福音 9:29–30; 马太福音 8:23–25"> 大卫又求问耶和华，耶和华说：“你不要正面出击，要绕到他们后面，从桑林对面攻打他们。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 7:6; 士师记 4:14; 士师记 7:15"> 当你听见桑树梢上响起脚步声时，就要快速进攻，因为那表示耶和华已在你前头去攻击非利士的军队了。”</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 14:16; 约书亚记 16:10; 以赛亚书 28:21"> 大卫遵命而行，打败非利士人，从迦巴一直杀到基色。</span>
</div>
</div>

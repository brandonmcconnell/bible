## 运约柜到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 13:1–4; 列王纪上 8:1; 历代志上 13:6–14"> 大卫又召集了三万名以色列精兵，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:4; 撒母耳记上 7:1; 诗篇 80:1"> 率领他们到犹大的巴拉去接上帝的约柜。这约柜以坐在基路伯天使之间的万军之耶和华的名字命名。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 6:7; 民数记 7:4–9; 民数记 4:5–12"> 他们把上帝的约柜从坐落在山上的亚比拿达家抬出来，放在一辆新车上，由亚比拿达的两个儿子乌撒和亚希约赶车，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:7; 撒母耳记上 7:1–2"> 亚希约走在约柜前面。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 13:8; 诗篇 150:3–5; 阿摩司书 5:23"> 大卫和全体以色列人在耶和华面前用琴、瑟、鼓、钹和锣奏乐，尽情歌舞。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 13:9; 民数记 4:15; 民数记 4:19–20"> 他们走到拿肯的麦场时，拉车的牛失蹄，乌撒就伸手去扶上帝的约柜。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 6:19; 历代志上 15:13; 历代志上 13:10"> 耶和华上帝便向他发怒，因他的不敬而击杀了他。他死在了约柜旁边。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 4:1; 历代志上 13:11–12; 约拿书 4:9"> 大卫因耶和华击杀乌撒而烦恼，就称那地方为毗列斯·乌撒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“毗列斯·乌撒”意思是“向乌撒发怒”。">a</a></sup>，沿用至今。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 119:120; 历代志上 13:11–12; 民数记 17:12–13"> 那天，大卫惧怕耶和华，就说：“耶和华的约柜怎能运到我这里？”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 26:4–8; 撒母耳记下 15:19; 历代志上 15:18"> 他不愿把耶和华的约柜运进大卫城，而是把它运到迦特人俄别·以东家。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:5; 创世记 30:27; 箴言 3:9–10"> 耶和华的约柜在俄别·以东家存放了三个月，耶和华赐福给俄别·以东和他全家。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 15:25–3; 列王纪上 8:1; 马太福音 10:42"> 大卫听说耶和华因为约柜而赐福给俄别·以东全家及其一切所有，就欢欢喜喜地去把上帝的约柜从俄别·以东家接进大卫城。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:5; 历代志上 15:15; 民数记 4:15"> 这一次，抬耶和华约柜的人走了六步，大卫就献上公牛和肥犊为祭。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 2:18; 出埃及记 15:20; 诗篇 150:4"> 大卫穿着细麻布的以弗得，在耶和华面前尽情跳舞。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 68:24–27; 历代志上 15:28; 历代志上 15:25"> 大卫和全体以色列人在欢呼声和号角声中把耶和华的约柜迎进大卫城。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 2:14; 历代志上 15:29; 诗篇 69:7"> 耶和华的约柜进大卫城的时候，扫罗的女儿米甲从窗户往外观看，见大卫在耶和华面前又跳又舞，心里就轻视他。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 15:1; 历代志下 1:4; 列王纪上 8:5"> 众人把耶和华的约柜抬进去，安放在大卫所搭的帐幕里。大卫在耶和华面前献上燔祭和平安祭，</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 8:55; 历代志上 16:2; 创世记 14:19"> 然后奉万军之耶和华的名给民众祝福，</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 8:10; 历代志下 35:7–8; 历代志上 16:3"> 还分给所有以色列人，不论男女，每人一个饼、一块肉和一个葡萄饼。众人就各自回家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 6:16; 撒母耳记下 6:14; 士师记 9:4"> 大卫回到家为自己的家人祝福，米甲出来迎接他，说：“今天以色列王好光彩呀！居然像个粗俗之人，在臣仆和婢女面前露体！”</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:22; 诗篇 89:19–20; 撒母耳记上 13:14"> 大卫对她说：“我是在耶和华面前跳舞。祂不用你父亲和你父亲家里的人，而是选立我来治理祂的以色列子民，所以我要在祂面前欢庆。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:14; 希伯来书 12:2; 以赛亚书 51:7"> 我要让自己更卑微，自视低贱，但你说的那些婢女会尊重我。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:25; 以赛亚书 22:14; 以赛亚书 4:1"> 扫罗的女儿米甲终生都没有生育。</span>

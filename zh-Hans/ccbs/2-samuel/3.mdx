## 押尼珥之死

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:30; 箴言 4:18–19; 约伯记 8:7"> 扫罗和大卫两家长期争战，大卫家的势力越来越强，扫罗家却日益衰微。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:1–4; 创世记 49:3–4; 撒母耳记下 13:1–29"> 大卫在希伯仑生的儿子有耶斯列人亚希暖所生的长子暗嫩，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 27:8; 历代志上 3:1; 申命记 3:14"> 迦密人拿八的遗孀亚比该所生的次子基利押，基述王达买的女儿玛迦所生的三子押沙龙，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13–25; 列王纪上 1:5–18"> 哈及所生的四子亚多尼雅，亚比她所生的五子示法提雅，</span>
<span className="v" id="v5" data-v="5"> 大卫的妻子以格拉所生的六子以特念。大卫的这些儿子都是在希伯仑生的。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 2:8–9; 历代志下 25:8; 以赛亚书 8:9–10"> 在扫罗和大卫两家争战期间，押尼珥在扫罗家权势日增。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:8–11; 列王纪上 2:21–22; 撒母耳记下 12:8"> 他跟扫罗的一个妃嫔、爱亚的女儿利斯巴通奸，伊施·波设问他：“你为什么睡我父亲的妃嫔呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 9:8; 撒母耳记下 16:9; 马可福音 6:18–19"> 押尼珥听了非常愤怒，说：“难道我是犹大的走狗吗？我至今还这样厚待你父亲扫罗家和他的亲戚朋友，没有把你交给大卫，今天你竟为了这个女人来责备我！</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:28; 列王纪上 19:2; 路得记 1:17"> 倘若我不照着耶和华应许大卫的誓言，把扫罗的江山夺过来交给大卫，让他统治全以色列和犹大，从但到别示巴，愿耶和华重重地惩罚我！”</span>
<span className="v" id="v11" data-v="11"> 伊施·波设一句话也不敢答，因为他害怕押尼珥。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 12:38–40; 撒母耳记下 3:21; 路加福音 16:5–8"> 押尼珥派使者送信给大卫，说：“这是谁的土地呢？如果你与我立约，我必帮助你统一以色列。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 43:3; 撒母耳记上 19:11–17; 创世记 44:23"> 大卫回答说：“好，我与你立约，但有一个要求：你一定要把扫罗的女儿米甲带来才能见我。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 18:27; 撒母耳记上 18:25; 撒母耳记下 2:10"> 于是，大卫派使者去见扫罗的儿子伊施·波设说：“请把我的妻子米甲送回来，因为她是我用一百个非利士人的包皮作聘礼娶来的。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:44"> 伊施·波设就派人把米甲从她丈夫、拉亿的儿子帕铁那里接回来。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:5; 撒母耳记下 19:16; 列王纪上 2:8"> 帕铁一路跟着米甲，边走边哭，一直到巴户琳。押尼珥对他说：“你回去吧！”他就回去了。</span>
<span className="v" id="v17" data-v="17"> 押尼珥和以色列的长老商量说：“你们以前一直都希望大卫做你们的王，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:28; 诗篇 89:19–23; 撒母耳记上 9:16"> 现在是时候了，因为耶和华曾说要借着祂仆人大卫的手，从非利士人和其他所有敌人手中拯救祂的以色列子民。”</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 12:29; 撒母耳记上 10:20–21; 诗篇 68:27"> 押尼珥也跟便雅悯人商谈，然后到希伯仑把以色列人和便雅悯人的愿望告诉大卫。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 26:30; 以斯帖记 1:3"> 当时，他带了二十个人前往希伯仑见大卫，大卫就设宴款待他们。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:12; 列王纪上 11:37; 撒母耳记下 3:10"> 押尼珥对大卫说：“我要去招聚所有以色列人到我主我王这里，好跟你立约，你便可以如愿以偿，统治全以色列。”于是大卫为他送行，他就平安地回去了。</span>
<span className="v" id="v22" data-v="22"> 大卫送押尼珥平安离开后不久，约押就率领大卫的军队袭敌归来，并带回许多战利品。</span>
<span className="v" id="v23" data-v="23"> 约押率领全军回来后，有人告诉他：“尼珥的儿子押尼珥刚才来朝见王，王送他平安地离去了。”</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 3:8; 撒母耳记下 19:5–7; 约翰福音 18:35"> 约押听后，就去见王，说：“你这做的是什么事？押尼珥来见你，你为什么放他走呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 28:6; 以赛亚书 37:28; 民数记 27:17"> 你要知道，尼珥的儿子押尼珥想来骗你，探听你的虚实。”</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 约押从大卫那里出来，派使者去追押尼珥，他们在西拉井追上了他，把他带了回来。大卫对这件事一无所知。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:5; 撒母耳记下 20:9–10; 列王纪上 2:32"> 押尼珥回到希伯仑的时候，约押就把他带到城门的瓮洞，装作与他密谈，乘机用短剑刺入他的肚子，把他杀死了，为他兄弟亚撒黑报了仇。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 35:33; 出埃及记 21:12; 创世记 9:6"> 后来，大卫听到消息就说：“我和我的国在耶和华面前永远跟尼珥的儿子押尼珥的死无关。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 1:16; 诗篇 109:8–19; 利未记 13:44–46"> 约押和他全家要承担这罪，愿他的后代永远有长疮的、患皮肤病的、拄拐杖的、被刀剑所杀的或挨饿的。”</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行传 28:4; 撒母耳记下 2:19–23"> 约押和他兄弟亚比筛之所以杀押尼珥，是因为押尼珥在基遍杀了他们的兄弟亚撒黑。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 37:34; 撒母耳记下 1:11; 撒母耳记下 1:2"> 大卫对约押和部下说：“你们要撕裂衣服，腰束麻布，在押尼珥棺前哭丧！”大卫王也跟在棺后送葬。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 约伯记 31:28; 撒母耳记上 30:4"> 他们就把押尼珥葬在希伯仑。大卫王和众人在墓旁大哭一场。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 1:17; 历代志下 35:25; 路加福音 12:19–20"> 大卫王哀悼押尼珥，说：<br /><span className="pl pl-1">“押尼珥啊！</span><br /><span className="pl pl-1">你怎能死得糊里糊涂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“糊里糊涂”希伯来文是“像愚笨人”。">a</a></sup><br /><span className="pl pl-1">呢？</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="士师记 16:21; 撒母耳记下 1:12; 约伯记 24:14"> <span className="pl pl-1">你的手没有被捆，</span><br /><span className="pl pl-1">你的脚没有被锁，</span><br /><span className="pl pl-1">你是死在奸恶之人的手里啊！”</span>于是众人都为押尼珥哀哭。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 12:17; 撒母耳记下 1:12; 路得记 1:17"> 大卫整天没有进食，众人来劝他吃一点东西，但他起誓说：“我若在日落以前吃任何东西，愿上帝重重地惩罚我！”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 7:37; 诗篇 62:9; 马可福音 15:11–13"> 众人听见了，都很喜悦，王做的每一件事都令他们喜悦。</span>
<span className="v" id="v37" data-v="37"> 那天全以色列的人都看出尼珥的儿子押尼珥的死与大卫无关。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:9; 撒母耳记下 2:8; 撒母耳记下 3:12"> 大卫王对他的随从说：“你们难道不知道今天以色列损失了一位伟大的将领吗？</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 2:33–34; 诗篇 101:8; 诗篇 28:4"> 今天我虽然是被膏立的王，但仍势单力薄，无法对付洗鲁雅的两个儿子，愿耶和华报应他们的恶行。”</span>

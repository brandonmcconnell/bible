## 押沙龙谋反

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 1:5; 撒母耳记下 12:11; 撒母耳记上 8:11"> 后来，押沙龙为自己备了车马，又派五十个人在他前面开道。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:14; 路得记 4:1; 约伯记 24:14"> 他常常清早起来，站在城门的通道旁边。每当有人来找王审理争讼时，押沙龙便问他是从哪一座城来的，那人就会报上自己所属的支派。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:15; 以西结书 22:7; 彼得前书 2:17"> 押沙龙会对他说：“你的申诉合情合理，可惜王没有派人来听你申诉。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:29; 士师记 9:1–5; 箴言 27:2"> 他接着会说：“要是我被立为国中的审判官就好了！那样，任何人有争讼都可以来找我，我一定会为他主持公道。”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:33; 诗篇 55:21; 箴言 26:25"> 每当有人要向他叩拜，他都伸手扶他，亲吻他。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:18; 彼得后书 2:3; 箴言 11:9"> 押沙龙这样对待每一个来向王申诉的以色列人，赢得了民心。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 58:4; 撒母耳记上 16:13; 撒母耳记上 16:1–2"> 过了四年，押沙龙对王说：“请让我到希伯仑去还我向耶和华许下的愿吧。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:20–21; 撒母耳记下 13:37–38; 撒母耳记上 1:11"> 仆人住在亚兰的基述时曾许愿，如果耶和华带领我回到耶路撒冷，我必在希伯仑敬拜祂。”</span>
<span className="v" id="v9" data-v="9"> 王说：“你平安地去吧！”押沙龙就去了希伯仑。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 12:38; 撒母耳记下 5:5; 撒母耳记下 3:2–3"> 他派密使通知以色列各支派一听见号角的响声，便喊：“押沙龙在希伯仑做王了！”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:13; 撒母耳记上 22:15; 罗马书 16:18–19"> 有二百人应邀随同押沙龙一起从耶路撒冷去希伯仑，他们对内情一无所知。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 41:9; 撒母耳记下 15:31; 约书亚记 15:51"> 押沙龙献祭的时候，还派人去把大卫的谋士亚希多弗从他的故乡基罗请来。反叛的势力大增，拥护押沙龙的民众越来越多。</span>
</div>
</div>

## 大卫逃离耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 9:3; 马太福音 27:22; 撒母耳记下 15:6"> 有人来禀告大卫：“以色列的民心都归向押沙龙了。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:9; 以西结书 46:18; 诗篇 55:3–11"> 大卫便对在耶路撒冷跟随他的臣仆说：“我们赶快逃命吧！否则，我们都难逃押沙龙的追捕。我们要马上离开！免得他赶到残害我们，屠杀全城。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:66–69; 箴言 18:24; 路加福音 22:28–29"> 臣仆对王说：“臣等谨遵我主我王的决定。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:21–22; 撒母耳记下 20:3; 诗篇 3:1"> 于是王就带着全家逃命，只留下十个妃嫔看守宫殿。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 3:1–2; 传道书 10:7; 诗篇 66:12"> 大卫王带着众民离开耶路撒冷，走到最后的那座房子时，停了下来。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 8:18; 撒母耳记上 30:14; 撒母耳记下 20:7"> 他的臣仆都从他身边过去了，包括基利提人、比利提人以及从迦特来的六百个随从。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 18:2; 路得记 1:11–13"> 王问迦特人以太说：“你为什么要跟我们一起逃难呢？回去留在新王那里吧！你是流亡到这里的外族人。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:13; 撒母耳记下 2:6; 约翰福音 1:17"> 你刚来不久，我怎么可以叫你跟我们一同四处飘流呢？我甚至不知道往何处去。你还是和你的弟兄回去吧，愿耶和华以慈爱和信实待你！”</span>
<span className="v" id="v21" data-v="21" data-xref="路得记 1:16–17; 箴言 17:17; 列王纪下 4:30"> 以太却答道：“我凭永活的耶和华和我主我王的性命起誓，不管我王去哪里，仆人都要誓死追随到底！”</span>
<span className="v" id="v22" data-v="22"> 大卫便对以太说：“那就继续前行吧！”于是，迦特人以太带着他的人及所有的家眷继续前行。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:2; 列王纪上 2:37; 约翰福音 18:1"> 众人离开时，当地的百姓都放声大哭。王带着所有的人过了汲沦溪，向旷野走去。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 4:15; 撒母耳记下 8:17; 撒母耳记下 20:25"> 祭司撒督、亚比亚他和抬上帝约柜的利未人都来了，他们把约柜放下，让城里出来的人先走过去。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 25:30; 诗篇 26:8; 诗篇 43:3–4"> 王对撒督说：“你把上帝的约柜抬回城去吧。耶和华若恩待我，必使我重返家园，重见约柜和会幕；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 3:18; 撒母耳记下 22:20; 列王纪上 10:9"> 但我若使祂不悦，也甘愿听凭祂的处置。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 9:9; 撒母耳记下 17:17; 撒母耳记下 24:11"> 你是个有先见之明的人，安心带着你的儿子亚希玛斯和亚比亚他的儿子约拿单回城吧。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 17:16; 撒母耳记下 15:23; 撒母耳记下 17:1"> 我会在旷野渡口那里等你们的消息。”</span>
<span className="v" id="v29" data-v="29"> 于是，撒督和亚比亚他便把上帝的约柜抬回耶路撒冷，留了下来。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 6:12; 撒母耳记下 19:4; 路加福音 19:41"> 大卫蒙着头，赤着脚登上橄榄山，边走边哭，他的随从也蒙着头，哭着走上山。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 17:14; 撒母耳记下 17:23; 雅各书 3:15"> 有人告诉大卫，亚希多弗也叛变，投奔了押沙龙，大卫就祷告说：“耶和华啊，求你使亚希多弗的谋算都变得愚不可及。”</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 16:2; 撒母耳记下 1:2; 诗篇 3:3–5"> 大卫来到山顶敬拜上帝的地方，看见亚基人户筛撕破了衣服，头蒙灰尘前来迎接他。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:35"> 大卫对他说：“你跟我一同逃命，只会给我带来不便。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:2; 撒母耳记下 16:16–19; 马太福音 10:16"> 你若回到城中，告诉押沙龙你愿意做他的臣仆，就像以前做我的臣仆一样，就可以帮我破坏亚希多弗的计谋。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 17:15–16"> 祭司撒督和亚比亚他都在那里，你在宫内听到什么消息就告诉他们。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 17:17; 撒母耳记下 15:27; 撒母耳记下 18:19–33"> 撒督的儿子亚希玛斯和亚比亚他的儿子约拿单也在那里，你听到什么消息，可以派他们传信给我。”</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 16:15–16; 历代志上 27:33"> 于是，大卫的朋友户筛便回到城里。那时，押沙龙也进了耶路撒冷。</span>
</div>
</div>

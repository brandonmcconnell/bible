## 大卫统计人口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 21:1; 历代志上 27:23–24; 雅各书 1:13–14"> 耶和华又向以色列人发怒，祂促使大卫来对付他们，让大卫统计以色列和犹大的人口。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 3:10; 士师记 20:1; 撒母耳记下 20:23"> 大卫对统领军队的约押说：“你去走遍以色列各支派，从但到别示巴，统计以色列和犹大的人口，让我知道国民的数目。”</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:11; 诗篇 115:14; 箴言 14:28"> 约押说：“我主我王，愿你的上帝耶和华使国民的人数比现在增加百倍，让你亲眼看到。但我主我王为什么要做这事呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:29; 传道书 8:4; 历代志上 21:4"> 但大卫不听约押和其他将领的规劝。他们只好去统计以色列的人数。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 13:9; 申命记 2:36; 约书亚记 13:16"> 他们过了约旦河，在谷中亚罗珥城南面安营，又经过迦得前往雅谢。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 19:28; 创世记 31:47–48; 士师记 18:28–29"> 然后，他们到基列、他停·合示地区、但·雅安，绕到西顿，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:29; 约书亚记 11:3; 创世记 21:22–33"> 再去泰尔的堡垒及希未人和迦南人的城邑。最后，他们到了犹大南部的别示巴。</span>
<span className="v" id="v8" data-v="8"> 他们花了九个月零二十天的时间，走遍全国，最后回到耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:23–24; 历代志上 21:5–6; 民数记 1:44–46"> 约押把统计的人数奏告王：“以色列有八十万英勇的刀兵，犹大有五十万。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:13; 撒母耳记上 13:13; 箴言 28:13"> 大卫统计了人口以后，内心不安，就对耶和华说：“我做这事犯了大罪。耶和华啊，求你赦免仆人的罪，我做了极其愚昧的事。”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 22:5; 撒母耳记上 9:9; 历代志上 29:29"> 大卫第二天早上起来，耶和华对大卫的先见迦得先知说：</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:6–10; 启示录 3:19; 箴言 3:12"> “你去告诉大卫，耶和华说，‘我有三样灾祸，你可以选择让我降哪一样给你。’”</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 21:12; 利未记 26:25; 撒母耳记下 21:1"> 迦得就来见大卫，对他说：“你愿意国内有七年饥荒呢？还是被敌人追杀三个月呢？还是国内发生三天瘟疫呢？请你考虑好后告诉我，我好回复那差我来的。”</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 51:1; 诗篇 119:156; 历代志上 21:13"> 大卫说：“我实在为难！不过我宁愿落在耶和华的手中，也不愿落在人的手中，因为耶和华有极大的怜悯。”</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:14; 历代志上 27:24; 民数记 25:9"> 于是，耶和华在以色列降下瘟疫，从那天早晨一直持续到所定的时间，从但到别示巴共有七万人死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="约珥书 2:13–14; 创世记 6:6; 出埃及记 12:23"> 当天使准备伸手毁灭耶路撒冷的时候，耶和华心生怜悯，就对灭命天使说：“够了，住手吧！”当时，耶和华的天使正站在耶布斯人亚劳拿的麦场上。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 74:1; 历代志上 21:16–17; 撒母耳记下 24:10"> 大卫看见灭命天使，就对耶和华说：“是我犯了罪，做了恶事，这些百姓有什么过错呢？愿你的手惩罚我和我的家族。”</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 21:18–30; 撒母耳记下 24:11"> 就在那天，迦得来见大卫，对他说：“你要去耶布斯人亚劳拿的麦场，在那里为耶和华建一座坛。”</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:8; 尼希米记 9:26; 历代志下 36:16"> 大卫就照耶和华借迦得所说的话去了麦场。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 18:2; 路得记 2:10; 历代志上 21:20–21"> 亚劳拿看见王及他的臣仆来了，就上前俯伏在地，向王下拜，</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 21:22; 民数记 25:8; 撒母耳记下 21:3–14"> 说：“我主我王到仆人这里有什么事？”大卫说：“我要买你的麦场，好在这里为耶和华筑一座坛，使民中的瘟疫止息。”</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:21; 撒母耳记上 6:14; 历代志上 21:22"> 亚劳拿说：“我主我王喜欢什么，就拿去献祭吧。这里有牛可以作燔祭，还有打麦的器具和牛轭可以作柴。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 20:40–41; 以赛亚书 32:8; 诗篇 20:3–4"> 王啊，仆人亚劳拿愿意把这一切都献给你，愿你的上帝耶和华悦纳你。”</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:24–25; 玛拉基书 1:12–14; 创世记 23:13"> 王却说：“不可，我一定要出钱买，我不要用白白得来之物作为燔祭献给我的上帝耶和华。”大卫就用十两银子买了亚劳拿的麦场和牛。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 21:14; 耶利米哀歌 3:32–33; 创世记 8:20"> 大卫在那里为耶和华建了一座坛，献上燔祭和平安祭，耶和华垂听了他的祷告，瘟疫就在以色列止住了。</span>

## 约押劝告大卫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 18:5; 撒母耳记下 18:14; 箴言 17:25"> 有人告诉约押，说：“王在为押沙龙哀伤痛哭。”</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 19:12; 箴言 16:15"> 士兵们听说王为押沙龙哀痛，胜利的欢腾顿时变为一片哀愁。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 31:27; 撒母耳记下 19:32; 撒母耳记下 17:24"> 那一天，众人都静悄悄地回城去，好像败兵一样羞愧。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:33; 撒母耳记下 15:30"> 王仍掩面痛哭：“我儿押沙龙啊！押沙龙！我儿！我儿啊！”</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:47–48; 诗篇 3:8; 尼希米记 9:27"> 约押就进到屋里，对王说：“你的仆人们救了你和你妻妾儿女的性命，你今天却使他们感到羞愧。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 23:5; 撒母耳记下 3:24–25; 箴言 19:9–10"> 仇视你的人，你倒去爱他；那些爱你的人，你反憎恶他们。这表明我王的心中根本没有我们这些将领和部下。如今我明白了，要是死去的不是押沙龙而是我们，你就高兴了。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 14:28; 创世记 34:3; 箴言 19:15"> 你现在应该出去安抚士兵们。我凭耶和华起誓，如果你不这样做，今晚必无一人再追随你。那将是你一生所遭遇的最大灾难！”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 18:24; 撒母耳记下 18:4; 撒母耳记下 19:3"> 于是王出去坐在城门口，众人听说后，都来到他面前。这时，跟随押沙龙的以色列人都各自逃回家去了。</span>
</div>
</div>

## 大卫返回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 15:14; 创世记 3:12–13; 撒母耳记下 8:1–14"> 以色列各支派的人都在纷纷议论：“王曾把我们从众仇敌和非利士人手中救出来。如今他为了躲避押沙龙而逃离本国。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14; 士师记 18:9; 何西阿书 8:4"> 我们膏立为王的押沙龙已经死了，为什么无人说请王回来呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 15:29; 列王纪上 2:35; 撒母耳记下 15:35–36"> 大卫王派人去对祭司撒督和亚比亚他说：“你们去问犹大的长老，‘全以色列已经准备迎接王回宫，你们为什么迟迟没有反应？</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 5:1; 创世记 2:23; 以弗所书 5:30"> 你们是王的弟兄，是王的骨肉，为什么迟迟没有迎接王回宫？’</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 17:25; 列王纪上 19:2; 路得记 1:17"> 你们也要对亚玛撒说，‘你是我的骨肉，要是我不立你为元帅取代约押，愿上帝重重地处罚我。’”</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:1; 使徒行传 4:32; 诗篇 110:2–3"> 王的这番话打动了所有犹大人的心，他们派人去请王和王的臣仆回来。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 5:9; 撒母耳记上 11:14–15"> 王便启程回宫。他来到约旦河时，犹大人都到吉甲来迎接他，要护送他过河。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:8; 撒母耳记下 16:5–13; 列王纪上 2:36–46"> 来自巴户琳的便雅悯人基拉的儿子示每也急忙跟着犹大人赶来迎接大卫王，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 16:1–4; 撒母耳记下 9:2; 撒母耳记下 9:10"> 有一千便雅悯人跟示每一起去迎接大卫王。扫罗的仆人洗巴带着十五个儿子和二十个仆人也赶到约旦河。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 81:15; 启示录 3:9; 诗篇 66:3"> 他们渡到河对面帮助王的家眷过河，为王效劳。王正要过河的时候，基拉的儿子示每就俯伏在他面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 22:15; 撒母耳记下 13:20; 撒母耳记下 13:33"> 说：“求我主饶恕仆人的罪过！仆人在我主我王离开耶路撒冷时所犯的罪，求我王不要记在心上。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 12:25; 诗篇 78:34–37; 创世记 48:14"> 仆人自知有罪，所以今天我是整个约瑟家族中第一个迎接我主我王的人。”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 22:28; 撒母耳记上 26:9; 列王纪上 21:10–11"> 洗鲁雅的儿子亚比筛说：“示每曾经咒骂耶和华所膏立的君王，难道不应该处死他吗？”</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 11:13; 撒母耳记下 16:10; 撒母耳记下 3:39"> 大卫说：“洗鲁雅的儿子，不要管我的事。你今天是在跟我作对。今天在以色列怎么可以处死人呢？难道我不知道今天我是以色列的王吗？”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:46; 列王纪上 2:8–9; 列王纪上 2:37"> 于是大卫起誓不杀示每。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 41:5; 马太福音 6:16; 撒母耳记下 15:30"> 扫罗的孙子米非波设也来迎接王。从王离开那天，直到大卫平安回来之日，他没有修过脚，没有剃过胡子，也没有洗过衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 16:17"> 他到耶路撒冷来迎接王，王问他：“米非波设，当时你为什么不跟我一起走呢？”</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 16:2–3; 撒母耳记下 4:4; 撒母耳记下 9:3"> 米非波设答道：“我主我王，我是瘸腿的，我本想预备一头驴骑着与我王同去，是我的仆人洗巴欺骗了我。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 14:17; 撒母耳记下 14:20; 撒母耳记上 29:9"> 他在我主我王面前毁谤我。我主我王就像上帝的天使，请王定夺。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 9:13; 撒母耳记下 9:10; 撒母耳记下 21:6–9"> 我父全家在我主我王面前都是该死的，但王却让我与王同席吃饭，我还能向王要求什么呢？”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 18:15; 诗篇 101:5; 诗篇 82:2"> 王对他说：“不要再提这事了，我决定让你和洗巴平分土地。”</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 1:20; 使徒行传 20:24; 撒母耳记下 1:26"> 米非波设说：“把土地都给他吧，我主我王平安地回来就好了。”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:7; 尼希米记 7:63; 以斯拉记 2:61"> 基列人巴西莱也从罗基琳下来护送王过约旦河，然后送王上路。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 25:2; 约伯记 1:3; 箴言 16:31"> 那时，巴西莱已经是八十高龄了。王留在玛哈念的时候，他曾供应王食物，因为他非常富有。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 25:34–40; 路加福音 22:28–30; 撒母耳记下 9:11"> 王对巴西莱说：“你跟我一同回耶路撒冷，我会照顾你。”</span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:14; 哥林多前书 7:29; 创世记 47:8–9"> 巴西莱说：“我何必跟王一同去耶路撒冷呢？我还能活多久呢？</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 15:33; 以斯拉记 2:65; 诗篇 90:10"> 我已经八十岁了，美丑难分，食不知味，乐不辨音，何必为我主我王添麻烦呢？</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:38"> 仆人只不过是陪王过约旦河，王何必给我这么大的赏赐呢？</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪上 2:7; 耶利米书 41:17; 撒母耳记下 19:40"> 请准我回去，我好死在故乡，葬在父母的墓旁。这里有王的仆人金罕，让他跟我主我王一起去。你看怎么好，就怎么对待他吧。”</span>
<span className="v" id="v38" data-v="38"> 王说：“金罕可以跟我去，我会照你的心愿待他。无论你有什么要求，我都会答应你。”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 31:55; 路得记 1:14; 创世记 47:7"> 王和众人过了约旦河以后，就亲吻巴西莱，为他祝福。巴西莱返回了家乡。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:9; 创世记 49:10; 撒母耳记下 19:11–15"> 王过河后，来到吉甲，金罕跟随着他。护送王的有犹大的士兵和半数的以色列士兵。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 8:1; 士师记 12:1; 约翰福音 7:5–6"> 后来，所有的以色列人来见王，说：“为什么我们的弟兄犹大人偷偷地送王、王的家眷和王的部下渡河？”</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 19:12; 撒母耳记下 5:1; 历代志上 2:3–17"> 犹大人答道：“我们这样做是因为王是我们的亲族。你们为什么生气呢？难道我们吃了王的供应，得了什么礼物吗？”</span>
<span className="v" id="v43" data-v="43" data-xref="加拉太书 5:20; 撒母耳记下 5:1; 列王纪上 11:30–31"> 以色列人说：“但我们和王有十份的情分，我们在大卫身上比你们更有份。你们为什么轻视我们？难道不是我们首先提出要请王回来的吗？” 但犹大人的态度比以色列人还要强硬。</span>

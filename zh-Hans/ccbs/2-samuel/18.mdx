## 押沙龙之死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 8:10; 撒母耳记上 8:12; 出埃及记 17:9"> 大卫召集军队，设立了千夫长和百夫长率领他们。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 7:16; 撒母耳记下 15:19–22; 撒母耳记下 10:7–10"> 他兵分三队，一队由约押率领，一队由洗鲁雅的儿子、约押的兄弟亚比筛率领，一队由迦特人以太率领。大卫对部下说：“我必与你们一同出战。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 21:17; 出埃及记 17:10–12; 列王纪上 22:31"> 他们却说：“你不要出战。因为如果我们败逃，敌方不会放在心上；即使我们一半人阵亡，敌方也不会放在心上。你一人比我们一万人更宝贵。你还是留在城中支援我们吧。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:24; 撒母耳记下 18:1; 撒母耳记上 29:2"> 王说：“你们认为怎样好，我就怎样做。”于是，大卫王站在城门旁边，军兵百人一队、千人一队地出城了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 21:18–21; 撒母耳记下 16:11; 诗篇 103:13"> 大卫王吩咐约押、亚比筛和以太说：“你们要看在我的份上对年轻的押沙龙手下留情。”全体的军兵都听见了大卫吩咐众将领的话。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 17:18; 约书亚记 17:15; 士师记 12:4–6"> 大卫的军队在以法莲的树林里跟以色列人交战。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 24:21; 撒母耳记下 2:31; 撒母耳记下 2:26"> 以色列人被大卫的部下打败，伤亡惨重，有两万人阵亡。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 15:10; 约书亚记 10:11; 诗篇 43:1"> 战事蔓延到整个郊野，那天死在树林里的人比死在刀下的人还多。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 14:26; 箴言 30:17; 约伯记 31:3"> 押沙龙碰巧遇见大卫的部下。他骑着骡子逃走，骡子从一棵大橡树的茂密枝条下经过，押沙龙的头发被树枝缠住，整个人吊在半空中，胯下的骡子也跑了。</span>
<span className="v" id="v10" data-v="10"> 大卫的一个部下看见，就向约押禀告说：“我看见押沙龙正吊在橡树上。”</span>
<span className="v" id="v11" data-v="11"> 约押对那报信的说：“什么！你看见他吊在树上，为什么不把他杀掉呢？要是你把他杀了，我会赏你十块银子和一条腰带。”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 18:5"> 他却答道：“就是你赏我一千块银子，我也不敢加害王的儿子啊！我们曾听见王吩咐你、亚比筛和以太不可伤害年轻的押沙龙。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 14:19–20; 希伯来书 4:13; 撒母耳记下 4:10–12"> 如果我胆敢杀死押沙龙，王迟早会查出真相，到时你就撒手不管了。”</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 45:5; 马太福音 12:40; 撒母耳记下 14:30"> 约押说：“我不跟你浪费时间。”趁着押沙龙还吊在橡树上，他拿起三杆矛枪剌入了他的心脏。</span>
<span className="v" id="v15" data-v="15"> 十个为约押拿兵器的年轻人围上去将押沙龙杀死。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 2:28; 撒母耳记下 20:22; 哥林多前书 14:8"> 随后，约押吹起收兵的号角，军兵便停止追赶以色列人。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 7:26; 约书亚记 8:29; 撒母耳记下 19:8"> 他们把押沙龙的尸体扔在林中的一个坑里，在上面堆了一大堆石头。以色列人都各自逃回家去了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 14:17; 撒母耳记下 14:27; 撒母耳记上 15:12"> 押沙龙生前没有儿子为他留名，所以他曾在王谷立了一根石柱，以自己的名字命名，称为“押沙龙柱”，沿用至今。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 15:36; 撒母耳记下 18:31; 诗篇 9:4"> 撒督的儿子亚希玛斯对约押说：“请让我跑回去向王禀告，让王知道耶和华已从仇敌手中救了他。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 18:5; 撒母耳记下 18:33; 撒母耳记下 17:16–21"> 但约押对他说：“你今天不要去报信，改天再报吧。你今天不要去，因为王的儿子死了。”</span>
<span className="v" id="v21" data-v="21"> 约押吩咐一个古实人：“你去把所看见的禀报给王。”那人就拜别了约押，马上跑回去报信。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 1:28; 以弗所书 5:4"> 撒督的儿子亚希玛斯再次对约押说：“无论怎样，求你让我与古实人一同去吧！”约押说：“我的孩子，你何必要去呢？你报这个消息是不会得到赏赐的。”</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 20:4"> 他说：“无论怎样，我想跑去报信。”约押答应了。亚希玛斯沿平原的路跑，跑到了古实人的前面。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 19:8; 撒母耳记下 13:34; 以西结书 33:2–7"> 那时，大卫正坐在内城门和外城门中间。有一个守望者爬上城门楼顶观望，看见一个人独自跑来。</span>
<span className="v" id="v25" data-v="25"> 守望者就大声向王禀告。王说：“他若是独自一人，带来的一定是好消息。”那人越来越近了。</span>
<span className="v" id="v26" data-v="26"> 这时候，守望者又看见另一个人跑来，就大声对守城门的说：“又有一个人独自跑来了！”王说：“他也一定是传好消息的。”</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 9:20; 列王纪上 1:42; 罗马书 10:15"> 守望者又说：“从跑的姿势看，那跑在前面的人好像撒督的儿子亚希玛斯。”王说：“他是个好人，他一定带来了好消息。”</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 14:4; 创世记 14:20; 创世记 24:27"> 亚希玛斯高声对王说：“一切平安！”他在王面前俯伏叩拜，说：“你的上帝耶和华当受称颂，祂已经消灭了那些攻击我主我王的敌人。”</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 18:22; 撒母耳记下 20:9; 撒母耳记下 18:19–20"> 王问道：“年轻的押沙龙平安吗？”亚希玛斯答道：“约押派仆人来的时候，仆人看见一阵大骚动，但不知道是什么事。”</span>
<span className="v" id="v30" data-v="30"> 王说：“你先退到一边去。”亚希玛斯就退下，站在一边。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 18:19; 撒母耳记下 18:28; 路加福音 18:7–8"> 这时，古实人也到了，他说：“我有好消息向我主我王禀告，今日耶和华已经从一切反叛之人手中救了我主我王。”</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 5:31; 撒母耳记上 25:26; 但以理书 4:19"> 王问古实人：“年轻的押沙龙平安吗？”古实人答道：“愿我主我王的仇敌和一切要加害我王的人，下场都与那青年一样。”</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:4; 撒母耳记下 12:10–23; 箴言 17:25"> 王听了十分难过，就走上城门楼去痛哭，边走边说：“我儿押沙龙啊！我儿，我儿押沙龙啊！我恨不得可以替你死！押沙龙，我儿啊！我儿！”</span>

## 拿单斥责大卫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:35–41; 诗篇 51:1–19; 撒母耳记下 11:10–17"> 耶和华派拿单先知去见大卫。拿单对大卫说：“一座城里有两个人，一个富有，一个贫穷。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 15:16; 约伯记 1:3; 撒母耳记下 5:13–16"> 富人拥有许多牛羊，</span>
<span className="v" id="v3" data-v="3" data-xref="弥迦书 7:5; 撒母耳记下 11:3; 箴言 5:18–19"> 穷人除了自己买来养活的一只母羊羔外，什么也没有。他让它跟自己的儿女一起长大。他吃什么，羊也吃什么，他喝什么，羊也喝什么，甚至让它睡在自己怀里，就像他女儿一样。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 1:14; 撒母耳记下 11:3–4; 创世记 18:2–7"> 一天，富人家中来了客人，他舍不得拿自己的牛羊款待客人，却宰了穷人的羊给客人吃。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 38:24; 罗马书 2:1; 撒母耳记上 26:16"> 大卫听后非常愤怒，对拿单说：“我凭永活的耶和华起誓，做这事的人实在该死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:1; 路加福音 19:8; 箴言 6:31"> 他这样做真是没有半点怜悯之心，他必须偿还那穷人四倍！”</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:14; 撒母耳记上 16:13; 撒母耳记下 22:1"> 拿单对大卫说：“那人就是你！以色列的上帝耶和华这样说，‘我膏立你做以色列的王，从扫罗手中救你，</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 84:11; 罗马书 8:32; 撒母耳记下 9:7"> 将你主人的家业和妻妾交给你，把以色列和犹大的国权赐给你。倘若还不够，我会再加倍地赐给你。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:19; 诗篇 139:1–2; 撒母耳记上 15:23"> 你为什么蔑视我的命令，做出我视为可憎的事呢？你借亚扪人的刀杀了赫人乌利亚，把他的妻子据为己有。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14–15; 马太福音 26:52; 罗马书 2:4"> 因为你藐视我，把赫人乌利亚的妻子据为己有，从今以后，杀戮流血的事必永不离开你的家。’</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 16:21–22; 申命记 28:30; 撒母耳记下 15:10"> 耶和华说，‘我要在你家中降下灾祸，我要当着你的面把你的妻妾交给你的近臣，他必在光天化日之下与她们行淫。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 16:22; 撒母耳记下 11:4–15; 传道书 12:14"> 你在暗地里做这恶事，我要让这样的恶事当着以色列人的面在光天化日之下临到你。’”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:4; 撒母耳记下 24:10; 箴言 28:13"> 大卫对拿单说：“我得罪了耶和华。”拿单说：“耶和华已经赦免了你的罪，使你不致死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:24; 以赛亚书 52:5; 诗篇 89:31–33"> 但你做的丑事给了仇敌大肆亵渎耶和华的机会，所以你这个孩子必定死。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:38; 诗篇 104:29; 历代志下 13:20"> 拿单说完，便回家去了。 耶和华击打乌利亚的妻子给大卫生的孩子，使他患重病。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 13:31; 使徒行传 9:9; 诗篇 69:10"> 大卫为这孩子向上帝哀求，并且禁食，他进到里面，整夜躺在地上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 撒母耳记上 28:23"> 宫里的老臣在旁边伺候，想要扶他起来，他却不肯，也不肯与他们一同吃饭。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 20:15"> 到了第七日，孩子死了。大卫的臣仆都不敢把这消息告诉他，因为他们心里想：“孩子还活着的时候，我们劝他，他尚且不听，若告诉他孩子死了，他会怎样折磨自己呢？”</span>
<span className="v" id="v19" data-v="19"> 大卫看见他们交头接耳，知道孩子死了，便问他们：“孩子死了？”他们答道：“是的，他死了。”</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:20; 路得记 3:3; 耶利米哀歌 3:39–41"> 大卫听后，便从地上起来，沐浴更衣，抹上香膏，然后到耶和华的殿去敬拜。他回宫以后，吩咐人摆上食物，自己开始用膳。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 2:15"> 他的臣仆诧异地问他：“你这是什么意思？孩子还活着的时候，你禁食、哀哭。孩子死了，你反倒起来进食。”</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 38:1–3; 以赛亚书 38:5; 约拿书 3:9–10"> 大卫说：“不错，孩子活着的时候我禁食、哀哭，因为我想也许耶和华会向我开恩，让他活命。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:35; 约伯记 30:23; 路加福音 23:43"> 但现在他既然死了，我禁食又有什么用呢？能让他起死回生吗？我必去他那里，他却不能返回我这里了。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:6; 历代志上 28:5–6; 历代志上 22:9–10"> 大卫安慰妻子拔示巴，与她同房，她便生了一个儿子。大卫给孩子取名叫所罗门。耶和华喜爱这孩子，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 7:4; 尼希米记 13:26; 列王纪上 1:11"> 祂差遣拿单先知去赐给他一个名字，叫耶底底亚，意思是耶和华喜爱他。</span>
</div>
</div>

## 大卫打败亚扪人

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 20:1–3; 申命记 3:11; 撒母耳记下 11:25"> 那时，约押正攻打亚扪人的拉巴，占领了王城。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 21:20; 撒母耳记下 11:1; 申命记 3:11"> 他派使者去向大卫禀告说：“我攻打拉巴，已经占领了城的水源。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 7:18"> 请你赶快带领其余的兵马前来围攻并占领这城，免得我攻取这城以后，人们用我的名字为这城命名。”</span>
<span className="v" id="v29" data-v="29"> 于是，大卫便召集了所有的人去攻打拉巴，攻陷了那城，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 20:2"> 夺取了亚扪王头上的金冠。这金冠重达三十四公斤，上面还镶着宝石，人们将它戴在大卫头上。大卫从城里获得许多战利品，</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 20:3; 诗篇 21:8–9; 阿摩司书 1:3"> 又把城里的人带出来，让他们从事锯木、耕田、砍树的工作，还让他们制作砖。他用同样的方式对待亚扪其他城邑的居民。之后，大卫和全军返回耶路撒冷。</span>

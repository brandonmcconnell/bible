## 大卫的遗言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 16:12–13; 撒母耳记下 7:8–9; 诗篇 89:20"> 耶西的儿子大卫是雅各的上帝膏立的王，他身居高位，在以色列能歌善咏。以下是他的遗言：</span>
<span className="v" id="v2" data-v="2" data-xref="彼得后书 1:21; 马太福音 22:43; 马可福音 12:36"> <span className="pl pl-1">“耶和华的灵借着我说话，</span><br /><span className="pl pl-1">祂的言语在我口中。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 22:32; 申命记 32:4; 出埃及记 18:21"> <span className="pl pl-1">以色列的上帝告诉我，</span><br /><span className="pl pl-1">以色列的磐石对我说，</span><br /><span className="pl pl-1">‘以公义治理人民，</span><br /><span className="pl pl-1">敬畏上帝的君王，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="士师记 5:31; 诗篇 72:6; 何西阿书 6:5"> <span className="pl pl-1">就像旭日的光辉、</span><br /><span className="pl pl-1">晴朗的早晨，</span><br /><span className="pl pl-1">又像雨后的光芒，</span><br /><span className="pl pl-1">使大地长出青草。’</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 55:3; 撒母耳记下 7:14–16; 以赛亚书 9:6–7"> <span className="pl pl-1">我的家在上帝面前不正是如此吗？</span><br /><span className="pl pl-1">上帝与我立下永远的约，</span><br /><span className="pl pl-1">这约稳妥可靠。</span><br /><span className="pl pl-1">祂必拯救我，成全我的愿望。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 2:6; 以赛亚书 33:12; 申命记 13:13"> <span className="pl pl-1">但恶人要像荆棘一样被丢弃，</span><br /><span className="pl pl-1">没人用手拿起他们，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 6:8; 帖撒罗尼迦后书 2:8; 以赛亚书 27:4"> <span className="pl pl-1">人要拿铁器和长矛把他们收集起来焚毁。”</span></span>
</div>
</div>

## 大卫的勇士

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 27:2; 历代志上 11:11–47; 历代志上 27:32"> 以下是大卫的勇士：他革扪人约设·巴设，又称伊斯尼人亚底挪，是三勇士之首，曾在一次交战中杀掉八百敌人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:4; 历代志上 11:12–14; 撒母耳记上 17:26"> 其次是亚哈希人朵多的儿子以利亚撒，他是三勇士之一。有一次，以色列人和非利士人打仗，他跟随大卫向非利士人骂阵。以色列人都撤退了，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:5; 撒母耳记上 11:13; 士师记 15:14"> 他却坚守阵地，奋勇杀敌，直到手臂发麻，握刀的手无法松开。那天，耶和华使以色列人大获全胜。以色列军队回到以利亚撒那里来捡死人的财物。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 11:13–14; 历代志上 11:27; 撒母耳记下 23:33"> 第三位勇士是哈拉人亚基的儿子沙玛。有一次非利士人聚集在一块长满扁豆的田中和以色列人打仗，以色列人都逃跑了，</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳记下 23:10; 诗篇 3:8"> 沙玛却站在田中间坚守麦田，击杀非利士人。耶和华使以色列人大获全胜。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:1; 撒母耳记下 5:18; 约书亚记 12:15"> 在收割的时候，非利士军队在利乏音谷扎营，三十位统领中有三位到亚杜兰洞见大卫。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 22:4–5; 撒母耳记上 13:4; 撒母耳记上 10:5"> 那时大卫留守在堡垒里，非利士人的驻军在伯利恒。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:14; 诗篇 42:1–2; 以赛亚书 41:17"> 大卫渴了，说：“但愿有人给我打些伯利恒城门旁的井水喝！”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:14; 哥林多后书 5:14; 腓立比书 2:17"> 这三位勇士就冲过非利士人的营地，到伯利恒城门旁的井打水，带回来给大卫。大卫却不肯喝，他把水浇奠在耶和华面前，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 马可福音 14:24; 哥林多前书 15:30"> 说：“耶和华啊！这三人冒死去打水，这些水就像是他们的血，我决不能喝！”因此，大卫不肯喝。这是三勇士的事迹。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:10; 撒母耳记下 10:14; 历代志上 11:20–21"> 洗鲁雅的儿子、约押的兄弟亚比筛是这三位<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“三位”有些希伯来文抄本作“三十位”。">a</a></sup>勇士的统领，他曾挥矛刺死三百人，在三勇士中出了名，</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:8; 马太福音 13:23; 哥林多前书 15:41"> 最有声望，因此做了他们的统领，只是不及前三位勇士。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 8:18; 约书亚记 15:21; 撒母耳记下 20:23"> 甲薛人耶何耶大的儿子比拿雅是位勇士，做过非凡的事。他曾杀死摩押的两个勇猛战士，也曾在下雪天跳进坑中杀死一头狮子，</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 17:51; 历代志上 11:23; 歌罗西书 2:15"> 还杀死了一个埃及勇士。当时埃及人拿着长矛，比拿雅拿着棍子迎战，他夺了对方的长矛，用那矛刺死了对方。</span>
<span className="v" id="v22" data-v="22"> 这是耶何耶大的儿子比拿雅的事迹，他像那三位勇士一样赢得了名声。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 20:23; 历代志上 27:6; 撒母耳记上 22:14"> 他比那三十勇士更有声望，只是不及前三位勇士。大卫派他做护卫长。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 2:18; 历代志上 27:7; 历代志上 11:26"> 三十位勇士中有：约押的兄弟亚撒黑、伯利恒人朵多的儿子伊勒哈难、</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 7:1; 历代志上 11:27–28"> 哈律人沙玛、哈律人以利加、</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 历代志上 11:27–28; 历代志上 27:9–10"> 帕勒提人希利斯、提哥亚人益吉的儿子以拉、</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 21:18; 历代志上 11:19; 历代志上 11:28"> 亚拿突人亚比以谢、户沙人米本乃、</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:13; 列王纪下 25:23; 历代志上 11:30"> 亚哈希人撒们、尼陀法人玛哈莱、</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 11:30–31; 约书亚记 18:28; 历代志上 27:15"> 尼陀法人巴拿的儿子希立、便雅悯支派基比亚人利拜的儿子以太、</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 12:15; 历代志上 27:14; 士师记 12:13"> 比拉顿人比拿雅、迦实溪人希太、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:16; 历代志上 11:32–33"> 伯·亚拉巴人亚比亚本、巴鲁米人押斯玛弗、</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 11:34"> 沙本人以利雅哈巴、雅善的儿子们、哈拉人沙玛的儿子约拿单、</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 11:27; 撒母耳记下 23:11; 历代志上 11:35"> 哈拉人沙拉的儿子亚希暗、</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 11:3; 撒母耳记下 15:12; 撒母耳记下 10:6"> 玛迦人亚哈拜的儿子以利法列、基罗人亚希多弗的儿子以连、</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 11:37; 约书亚记 15:55"> 迦密人希斯莱、亚巴人帕莱、</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 8:3; 历代志上 11:38"> 琐巴人拿单的儿子以甲、迦得人巴尼、</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 11:37; 历代志上 11:39; 撒母耳记下 4:2"> 亚扪人洗勒、为洗鲁雅的儿子约押拿兵器的比录人拿哈莱、</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 2:53; 撒母耳记下 20:26; 历代志上 11:40"> 以帖人以拉、以帖人迦立、</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记下 11:3; 马太福音 1:6; 列王纪上 15:5"> 赫人乌利亚，共三十七名勇士。</span>
</div>

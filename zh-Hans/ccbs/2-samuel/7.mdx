## 上帝对大卫的应许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王纪上 5:4"> 大卫住在王宫里，耶和华使他安享太平，不受四围的仇敌侵扰。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 16:1; 撒母耳记下 5:11; 哈该书 1:4"> 一天，王对拿单先知说：“你看，我住在香柏木建的王宫中，上帝的约柜却还在帐幕里。”</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:7; 列王纪上 8:17–18; 列王纪下 4:27"> 拿单答道：“你有什么想法，就去做吧，因为耶和华与你同在。”</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 17:3; 民数记 12:6; 阿摩司书 3:7"> 当晚耶和华对拿单说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:3–32; 列王纪上 5:3–4; 列王纪上 8:16–19"> “你去告诉我的仆人大卫，‘耶和华说，你要建造殿宇给我居住吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:16; 约书亚记 18:1; 出埃及记 40:18–19"> 从我把以色列人带出埃及那天起，直到今天，我从未住过殿宇，一路上都住在帐幕里。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:6; 撒母耳记下 5:2; 利未记 26:11–12"> 在我与以色列人同行的日子，我从未责问任何我委派牧养我子民的士师，你为何不为我建香柏木的殿宇呢？’</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 78:70–71; 撒母耳记下 6:21; 撒母耳记下 12:7"> “现在你要告诉我的仆人大卫，万军之耶和华说，‘你原本在草场牧羊，我召你来做我以色列子民的首领。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 5:10; 历代志上 17:8; 撒母耳记上 18:14"> 无论你去哪里，我都与你同在，为你铲除所有仇敌。现在我要使你声名远扬，与世上的伟人齐名。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 9:15; 历代志上 17:9; 耶利米书 24:6"> 我必为我的以色列子民预备一个地方，栽培他们，使他们住在自己的家园，不再受惊扰，不会像从前我设立士师治理他们的时候那样受恶人压迫。我必使你安定，免受仇敌的侵扰。我耶和华向你宣告，我必为你建立王朝。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 8:20; 使徒行传 2:30; 使徒行传 13:36"> 你离世与祖先同眠时，我必兴起你亲生的后裔接替你，使他的国稳固。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王纪上 8:19; 撒母耳记下 7:16"> 他必为我的名建造殿宇，我必使他的国度王位永固。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 1:5; 启示录 3:19; 历代志上 17:13"> 我要做他的父亲，他要做我的儿子。如果他犯了罪，我必用人的杖、世人的鞭子来惩治他，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:23; 撒母耳记上 15:28; 诗篇 89:28"> 我的慈爱曾离开从你面前被废的扫罗，但我的慈爱必不离开他。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 诗篇 89:36–37; 撒母耳记下 7:13"> 你的家和你的国必在我面前永远坚立，你的王位必永远稳固。’”</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:15; 使徒行传 20:27; 哥林多前书 15:3"> 拿单就把所听到的启示全部告诉大卫。</span>
</div>
</div>

## 大卫的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 8:4; 历代志上 17:16; 撒母耳记上 18:18"> 于是，大卫王进去，在耶和华面前坐下，说：“主耶和华啊，我是谁？我的家算什么？你竟这样厚待我。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 55:8–9; 历代志上 17:17; 诗篇 36:7"> 主耶和华啊，在你眼中这还不够，你还说到仆人家的将来。主耶和华啊，你竟这样恩待世人！</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 21:17; 撒母耳记上 16:7; 诗篇 139:1"> 主耶和华啊，大卫还能对你说什么呢？因为你深知你的仆人。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 115:1; 诗篇 138:2; 以弗所书 1:9"> 你让仆人知道你凭自己的应许、按自己的心意成就这大事。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 86:10; 出埃及记 15:11; 诗篇 86:8"> 主耶和华啊，你真伟大！我们从未听过有谁能与你相比，你是独一无二的上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:26; 申命记 10:21; 申命记 15:15"> 世上哪个民族比得上你的以色列子民呢？你从埃及救赎他们，让他们做你的子民，又彰显你的大名，行伟大而可畏的事，把列国及其神明从你的以色列子民面前赶走。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 26:18; 彼得前书 2:10; 创世记 17:7"> 你让以色列人永远做你的子民，你耶和华做他们的上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 119:49; 以西结书 36:37; 创世记 32:12"> “耶和华上帝啊，求你永远信守你对仆人和仆人家的应许，求你成就你的应许。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 17:23–24; 诗篇 72:18–19; 马太福音 6:9"> 这样，你的名必永远被尊崇，人们必说，‘万军之耶和华是以色列的上帝。’你仆人大卫的家必在你面前坚立。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 17:25–26; 诗篇 10:17; 路得记 4:4"> 以色列的上帝——万军之耶和华啊，因为你曾启示仆人，说要为仆人建立王朝，仆人才敢这样向你祈祷。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17; 出埃及记 34:6; 民数记 23:19"> 主耶和华啊，唯有你是上帝，你的话真实可靠，你给了仆人美好的应许。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 6:24–26; 历代志上 17:27; 诗篇 115:12–15"> 现在求你赐福给仆人家，使仆人家在你面前永续不断。主耶和华啊，这些都是你的应许，愿你永远赐福给仆人家。”</span>
</div>
</div>

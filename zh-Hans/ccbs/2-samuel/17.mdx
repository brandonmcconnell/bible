## 亚希多弗计谋落空

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 59:7–8; 诗篇 109:2–4; 诗篇 3:3–5"> 亚希多弗对押沙龙说：“请让我挑选一万二千人，今夜启程追赶大卫，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 16:14; 列王纪上 22:31; 撒迦利亚书 13:7"> 趁他疲惫无力的时候袭击他，使他惊慌失措，他的随从必逃命。我只把王一个人杀掉，</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 5:3; 以赛亚书 48:22; 以赛亚书 57:21"> 把他的部下全都带来归顺你。你寻索的人既然死了，跟随他的人必然会归顺你。这样，大家就平安无事了。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 18:20–21; 罗马书 1:32; 历代志下 30:4"> 押沙龙和以色列的长老都赞成这个提议。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 15:32–37; 撒母耳记下 16:16–19"> 押沙龙说：“召亚基人户筛进来，我们也听听他的意见。”</span>
<span className="v" id="v6" data-v="6"> 户筛来了，押沙龙就把亚希多弗的建议告诉他，问他：“我们应该照亚希多弗的提议去做吗？如果不可行，说说你的看法吧。”</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> 户筛答道：“亚希多弗这次的主意不好！</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿书 13:8; 撒母耳记上 16:18; 希伯来书 11:32–34"> 你知道你父亲和他的部下，他们都是勇士，现在他们就像丢了熊崽的母熊一样凶猛。况且你父亲是个身经百战的人，他一定不会跟部下睡在一处。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 24:3; 撒母耳记上 14:14–15; 士师记 20:32–33"> 他现在可能藏在山洞或某个地方。要是他袭击我们的人马，听见的人会说押沙龙的军队惨败了。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 2:9–11; 出埃及记 15:15; 创世记 49:9"> 那时候，你手下的人再胆量过人，也会胆战心惊。因为全以色列都知道你父亲是英雄，他的部下都是勇士。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 22:17; 士师记 20:1; 诗篇 9:16"> 因此，我认为你应该把从但到别示巴的那多如海沙的以色列人都聚集起来，然后你亲自率领他们出征。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 23:23; 俄巴底亚书 1:3; 列王纪上 20:10"> 这样不管在哪里找到大卫，我们就像露水一样铺天盖地地袭击他，让他全军覆没。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:2; 弥迦书 1:6"> 如果大卫退进一座城里，我们以色列全军就拿绳索把那城拉到河谷，连一块石头都不留。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 15:34; 哥林多前书 1:19–20; 箴言 19:21"> 押沙龙和以色列众人都说：“亚基人户筛的主意比亚希多弗的好！”其实是耶和华决定破坏亚希多弗的巧计，好把灾祸降在押沙龙身上。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:35–36"> 户筛把亚希多弗和自己为押沙龙及以色列长老所提的建议告诉祭司撒督和亚比亚他，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 15:28; 哥林多前书 15:54; 哥林多后书 5:4"> 并说：“你们现在快派人去通知大卫，告诉他今晚不可在旷野的渡口过夜，务必要渡过约旦河，免得他和随从全军覆没。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 15:36; 约书亚记 18:16; 撒母耳记下 15:27"> 当时，约拿单和亚希玛斯待在隐·罗结，不敢进城，怕被人看见。有一个婢女从城中出来给他们报信，他们便去通知大卫王。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 3:16; 撒母耳记下 16:5; 撒母耳记下 19:16"> 不料，有一个少年发现了他们，就去告诉押沙龙。他们二人急忙逃走，来到巴户琳的一户人家，藏到那家院子里的一口井内，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 1:19; 约书亚记 2:4–24"> 那家的妇人用盖子盖上井口，然后在上面撒了一些麦子，没有人知道这件事。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 1:19; 约书亚记 2:22–23; 撒母耳记上 19:12–17"> 押沙龙的部下来到妇人家查问约拿单和亚希玛斯的下落，妇人说他们已经过河了。押沙龙的部下就去搜索，结果一无所获，就返回耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 17:15–16"> 押沙龙的部下离开后，约拿单和亚希玛斯便从井里爬出来，去向大卫王报信，把亚希多弗的计谋告诉他，请他赶快渡过约旦河。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 10:16; 约翰福音 18:9; 箴言 27:12"> 大卫王和部下就动身过约旦河，在黎明之前，所有的人都过去了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:5; 列王纪下 20:1; 撒母耳记下 15:12"> 亚希多弗见自己的提议不被接纳，便备上驴，启程回乡，安顿好家事以后，就自缢身亡了。他被安葬在他父亲的墓穴里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 32:2; 撒母耳记下 2:8; 约书亚记 13:26"> 大卫来到玛哈念，押沙龙也率领以色列全军渡过了约旦河。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 2:13; 撒母耳记下 19:13; 撒母耳记下 20:9–12"> 押沙龙任命亚玛撒为元帅，代替约押的位置。亚玛撒是以实玛利人以特拉的儿子，他母亲是拿辖的女儿亚比该。亚比该与约押的母亲洗鲁雅是姊妹。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 17:1; 申命记 3:15; 民数记 32:1–42"> 押沙龙和以色列人在基列地区安营。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:7; 撒母耳记下 10:1–2; 撒母耳记下 9:4"> 大卫来到玛哈念后，得到亚扪族拉巴人拿辖的儿子朔比、罗·底巴人亚米利的儿子玛吉和基列的罗基琳人巴西莱的款待。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 25:18; 俄巴底亚书 1:3; 撒母耳记下 16:1–2"> 他们带来被褥、碗盆、瓦器、小麦、大麦、面粉、炒麦、豆子、扁豆、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 16:2; 以赛亚书 21:14; 撒母耳记下 16:14"> 蜂蜜、奶油、绵羊和奶酪，送给大卫和跟随他的人，因为他们想：“众人在旷野一定饥渴疲乏了。”</span>
</div>
</div>

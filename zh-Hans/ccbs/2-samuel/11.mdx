## 大卫犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 20:1; 列王纪上 20:26; 列王纪上 20:22"> 第二年春天，诸王又要发动战争。大卫差遣约押率领众将领和以色列大军出征，自己却留在耶路撒冷。他们打败了亚扪人之后又围攻拉巴。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 诗篇 119:37; 约伯记 31:1"> 一天黄昏，大卫从床上起来在王宫顶上散步，看见一个长得非常漂亮的女人在沐浴。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 23:39; 历代志上 3:5; 雅各书 1:14–15"> 大卫就派人去打听这个女人是谁，得知她是以连的女儿、赫人乌利亚的妻子拔示巴。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 18:19; 雅各书 1:14–15; 诗篇 51:1–19"> 大卫派使者把她接来，她来了，大卫就与她同寝，那时她的月经刚洁净。事后，她便回家去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22; 箴言 6:34"> 拔示巴怀孕了，就派人去告诉大卫。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 创世记 4:7; 撒母耳记上 15:30"> 大卫便传信给约押，说：“你派赫人乌利亚来见我。”约押就派乌利亚去见大卫。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:14; 撒母耳记上 17:22; 创世记 29:6"> 乌利亚来了，大卫问他有关约押、士兵和战争的情况，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 18:4; 创世记 43:34; 以赛亚书 29:15"> 然后吩咐他回家休息。乌利亚离开王宫后，收到王送的一份礼物。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; 约伯记 5:12–14"> 但他跟王的其他仆人一同睡在王宫门口，没有回家。</span>
<span className="v" id="v10" data-v="10"> 大卫得知乌利亚没有回家，便对他说：“你远道而来，为什么不回家休息呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:2; 撒母耳记下 20:6; 撒母耳记下 7:6"> 乌利亚答道：“约柜、以色列人和犹大人都在帐篷里，而我主约押及其军队也在田间扎营，我怎么可以回家吃喝，与妻子同房呢？我以王的性命起誓，我决不做这样的事！”</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:37; 耶利米书 2:22–23"> 大卫对乌利亚说：“你再住一天，明天我会派你回去。”于是乌利亚那日就留在耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:15; 创世记 19:32–35; 箴言 20:1"> 第二天，大卫邀请他一同吃饭，把他灌醉了。可是到了晚上，乌利亚还是不肯回家，仍然跟王的其他士兵一同住宿。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 17:9; 列王纪上 21:8–10; 诗篇 19:13"> 第二天早上，大卫给约押写了一封信，要乌利亚带去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:9; 诗篇 51:4; 耶利米书 20:13"> 大卫在信上吩咐约押：“你把乌利亚派到前线最险恶的地方，到时其他人都要撤退，好让敌人杀死他。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; 撒母耳记上 22:17–19; 使徒行传 5:29"> 于是约押围攻城池时，便派乌利亚到他知道的最强悍的敌人那里。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:9; 诗篇 51:14"> 敌人出来迎战约押，大卫的军中有几位阵亡，赫人乌利亚也死了。</span>
<span className="v" id="v18" data-v="18"> 约押就派人去向大卫禀告战争的详情，</span>
<span className="v" id="v19" data-v="19"> 并叮嘱信使：“你向王禀告战情后，</span>
<span className="v" id="v20" data-v="20"> 他若发怒责问你，‘为什么还冒死逼近城池呢？你们难道不知道敌人会从城墙上射箭吗？</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 7:1; 士师记 9:50–54; 撒母耳记下 3:27"> 难道你们不知道耶路·比设<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“耶路·比设”又名“耶路·巴力”，参见士师记6:32。">a</a></sup>的儿子亚比米勒是谁杀的吗？一个妇人从城墙上扔下一块磨石，把他砸死在提备斯。你们为什么还要逼近城墙呢？’你就对王说，‘你的仆人赫人乌利亚也死了。’”</span>
<span className="v" id="v22" data-v="22"> 于是，信使前来见大卫，照约押的吩咐向大卫禀告。</span>
<span className="v" id="v23" data-v="23"> 他说：“敌军势力强大，在城外跟我们交战，但我们把他们追到城门口。</span>
<span className="v" id="v24" data-v="24"> 敌军的弓箭手从城墙上射死了王的几个士兵，赫人乌利亚也死了。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 约书亚记 7:8–9; 传道书 9:1–3"> 大卫便对信使说：“你去告诉约押不要为这事难过，因为刀剑无情。让他只管竭力攻陷城池。要这样勉励约押。”</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 创世记 27:41; 撒母耳记下 3:31"> 拔示巴听到丈夫乌利亚的死讯之后就为他哭丧。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 51:4–5; 撒母耳记下 12:9; 申命记 22:29"> 丧期过后，大卫便派人把她接进宫里，她就做了大卫的妻子，并给他生了个儿子。然而，大卫的所作所为令耶和华十分不悦。</span>

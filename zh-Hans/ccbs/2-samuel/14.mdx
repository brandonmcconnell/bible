## 押沙龙回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 13:39; 撒母耳记下 2:18; 撒母耳记下 18:33"> 洗鲁雅的儿子约押知道王想念押沙龙，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:6; 阿摩司书 1:1; 路得记 3:3"> 就派人到提哥亚去召来一个聪明的妇人，对她说：“你假扮哀悼的人，穿上丧服，不要用油抹身，要装成为死者哀悼很久的妇人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:19; 出埃及记 4:15; 以赛亚书 51:16"> 然后到王那里，对他这样这样说。”约押把应该说的话都告诉妇人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 1:2; 列王纪下 6:26–28; 撒母耳记上 25:23"> 提哥亚妇人来到王面前，俯伏在地上说：“王啊，求你救救我吧！”</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 9:8–15; 撒母耳记下 12:1–3"> 王问她：“你有什么事？”妇人说：“婢女是个寡妇，丈夫死了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 4:8; 申命记 22:26–27; 出埃及记 2:13"> 我本来有两个儿子，有一次他们在田间发生争执，当时没有人劝解，其中一个儿子被打死了。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:19; 马太福音 21:38; 撒母耳记下 12:17"> 现在整个家族都起来反对婢女，说，‘把那打死亲兄弟的凶手交出来，我们要他以命偿命，除掉这个继承人。’他们要让我家断子绝孙，使婢女的丈夫既不能留名，也不能留后。”</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; 以赛亚书 11:3–4; 约伯记 29:16"> 王说：“你回家去吧！我会为你作主。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 25:24; 列王纪上 2:33; 马太福音 27:25"> 提哥亚妇人说：“我主我王，愿罪过<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“罪过”可能指违背摩西律法杀人偿命的规定。">a</a></sup>都落在婢女和婢女家族，跟王和王位无关。”</span>
<span className="v" id="v10" data-v="10"> 王说：“若有人为难你，你就把他带来，他必不敢再找你的麻烦。”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 14:45; 马太福音 10:30; 民数记 35:19"> 妇人说：“求王凭你的上帝耶和华起誓，不许报血仇者杀人，留我儿一命。”王说：“我凭永活的耶和华起誓，你的儿子必毫发无损。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 18:27; 撒母耳记上 25:24; 使徒行传 26:1"> 妇人说：“求我主我王再容婢女说一句。”王说：“说吧！”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 13:37–38; 撒母耳记下 12:7; 士师记 20:2"> 妇人说：“王怎么想出这样的事来针对上帝的子民呢？王刚才所说的话正表明王的不是了，因为王不让被流放的儿子回来。</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 30:23; 民数记 35:28; 希伯来书 9:27"> 人都难免一死，就像覆水难收。然而，上帝不是要夺取人的性命，而是要设法使流亡的人重新回来。</span>
<span className="v" id="v15" data-v="15"> 我向我主我王说出这番话，是因为人们恐吓我。我想，不如向王请命，也许王会成全婢女的心愿。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:19"> 有人要害我和我儿子的性命，叫我们不得承受上帝所赐的产业，也许王能从这人手中救我们。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 29:9; 撒母耳记下 19:27; 撒母耳记下 14:20"> 婢女想，我主我王的话必能安慰我，因为我主我王就像上帝的天使一样能明辨是非。愿王的上帝耶和华常与王同在！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:25; 撒母耳记上 3:17–18; 耶利米书 38:14"> 王对妇人说：“我有一件事要问你，你要实实在在地回答我。”妇人说：“我主我王请说。”</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:3; 撒母耳记上 1:26; 撒母耳记上 20:3"> 王说：“这是不是约押的主意？”妇人说：“我凭我主我王的性命起誓，王所说的一点不错，这些话是你臣仆约押吩咐婢女说的。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 14:17; 撒母耳记下 19:27; 约伯记 32:21–22"> 他这样做是希望扭转局面。我主如上帝的天使一样有智慧，洞悉天下之事。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 14:11; 撒母耳记上 14:39; 马可福音 6:26"> 于是，王对约押说：“我答应你的请求，你去把年轻的押沙龙带回来吧。”</span>
<span className="v" id="v22" data-v="22" data-xref="路得记 2:2; 约伯记 31:20; 约伯记 29:11"> 约押俯伏在地，叩谢王恩，说：“今天仆人在我主我王面前蒙了恩，因为王应允了仆人的请求。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:3; 撒母耳记下 13:37–38"> 约押便到基述把押沙龙接回耶路撒冷。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 22:4; 创世记 43:3; 撒母耳记下 3:13"> 王说：“让押沙龙回自己的家，不要让他来见我！”押沙龙便返回自己家中，没有朝见王。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 1:6; 申命记 28:35; 约伯记 2:7"> 在整个以色列，没有人像押沙龙那样因相貌英俊而为人称道，他从头到脚毫无瑕疵。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 44:20; 哥林多前书 11:14; 撒母耳记下 18:9"> 他的头发浓密，每年年终会很沉重，需要剪发，剪下的头发按王的重量标准约重两公斤。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 18:18; 撒母耳记下 13:1; 以赛亚书 14:22"> 押沙龙有三儿一女，女儿名叫她玛，长得非常美丽。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 押沙龙在耶路撒冷住了两年，没有跟王见过面。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 14:30–31; 以斯帖记 1:12; 马太福音 22:3"> 他派人去请约押来，托他去求见王，但约押不肯来。第二次再请，他还是不肯来。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 15:4–5; 列王纪下 10:6–7; 列王纪下 9:33"> 押沙龙就吩咐仆人：“你们看，约押的田就在我的田旁边，他种了大麦，你们去放火把它烧了。”押沙龙的仆人便把麦田烧了。</span>
<span className="v" id="v31" data-v="31"> 约押便来到押沙龙家里，问他：“你为什么叫仆人放火烧我的田？”</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 20:8; 出埃及记 14:12; 箴言 28:13"> 押沙龙答道：“我派人请你来，希望你替我去问王，‘我为什么要从基述回来呢？倒不如仍然留在那里。’现在我要见王，如果我有什么罪过，就让他杀了我吧！”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 33:4; 路加福音 15:20; 创世记 27:26"> 约押就去见王，把押沙龙的话告诉他，王便召见押沙龙。押沙龙来到王面前俯首叩拜，王就亲吻他。</span>
</div>
</div>

## 以色列人战胜亚扪人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 11:1–3; 士师记 11:12–28; 士师记 10:7–9"> 后来，亚扪王死了，他儿子哈嫩继位。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 11:1; 申命记 23:3–6; 尼希米记 13:1–3"> 大卫说：“我要恩待拿辖的儿子哈嫩，就像他父亲曾经恩待我一样。”他便派臣仆去安慰丧父的哈嫩。大卫的臣仆来到亚扪境内，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:16; 创世记 42:9; 哥林多前书 13:5"> 亚扪的官长却对哈嫩说：“大卫派人来安慰你，你以为他是来吊唁你父亲吗？他派臣仆来见你，不过是要探听虚实，想摧毁这城。”</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 20:4; 耶利米书 41:5; 历代志上 19:3–4"> 哈嫩便把大卫的臣仆抓起来，剃去他们一半胡须，从臀部割去他们下半身的衣服，然后放走他们。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 19:5; 列王纪上 16:34; 约书亚记 6:24–26"> 消息传到大卫那里，他就派人去迎接他们，因为他们倍受羞辱。王告诉他们留在耶利哥，等胡须长好了再回来。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 8:3; 撒母耳记下 8:5; 创世记 34:30"> 亚扪人知道得罪了大卫，便派人到伯·利合和琐巴招募了两万名亚兰步兵、玛迦王的一千人和一万二千名陀伯人。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 23:8–39; 历代志上 19:8–19"> 大卫听见消息后，就派约押率领全体勇士出战。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 10:6; 约书亚记 19:28; 民数记 13:21"> 亚扪人在城门前列阵，琐巴和利合的亚兰人、陀伯人以及玛迦人在郊野列阵。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 20:42–43; 约书亚记 8:21–22"> 约押见自己腹背受敌，就从以色列军中挑选一些精兵列阵迎战亚兰人，</span>
<span className="v" id="v10" data-v="10"> 把余下的军兵交给他的兄弟亚比筛带领，列阵迎战亚扪人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 6:2; 尼希米记 4:20; 腓立比书 1:27–28"> 他对亚比筛说：“倘若我胜不过亚兰人，你便过来支援我；倘若你胜不过亚扪人，我便过去支援你。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 16:13; 申命记 31:6; 撒母耳记上 3:18"> 你要刚强，我们要为我们的人民和我们上帝的城邑奋勇作战。愿耶和华成全祂自己的旨意！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 20:13–21; 列王纪上 20:28–30; 历代志上 19:14–15"> 于是，约押率领军兵进攻亚兰人，亚兰人败逃。</span>
<span className="v" id="v14" data-v="14"> 亚扪人见亚兰人败逃，便也从亚比筛面前逃回城去。约押就离开亚扪人，回师耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 14:2–3; 弥迦书 4:11–12; 以赛亚书 8:9–10"> 亚兰人见自己败给以色列人，便再次聚集起来。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 19:16; 撒母耳记下 8:3–8; 历代志上 18:3"> 哈大底谢派人把幼发拉底河那边的亚兰人调到希兰来，由他的将军朔法率领。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 19:17"> 大卫听到消息后，就召集以色列全军，渡过约旦河，来到希兰。亚兰人列阵迎战大卫，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 19:18; 撒母耳记下 8:4; 诗篇 46:11"> 结果又在以色列人面前败逃。大卫杀了七百名战车兵、四万骑兵，还杀了他们的将军朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 8:6; 启示录 18:10; 诗篇 48:4–5"> 哈大底谢属下的诸王见自己败给以色列人，便向以色列人求和，臣服于他们。从此，亚兰人不敢再支援亚扪人了。</span>
</div>
</div>

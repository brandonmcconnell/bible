## 大卫做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 30:31; 撒母耳记上 23:4; 创世记 32:2"> 这事以后，大卫求问耶和华：“我可以回到犹大的城邑吗？”耶和华说：“可以。”大卫又问：“我应该回到哪一座城呢？”耶和华说：“希伯仑。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 25:42–43; 撒母耳记上 30:5; 路加福音 22:28–29"> 大卫就带着他的两个妻子耶斯列人亚希暖和迦密人拿八的遗孀亚比该，一起上到希伯仑。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 30:1; 历代志上 12:1–7; 撒母耳记上 27:2–3"> 他还把部下和他们的家属一起带去，住在希伯仑地区的城邑。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 5:5; 撒母耳记上 31:11–13; 撒母耳记下 5:3"> 犹大人到希伯仑膏立大卫做犹大支派的王。 大卫听说是基列·雅比人埋葬了扫罗，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 23:21; 诗篇 115:15; 路得记 2:20"> 就派使者去告诉他们：“你们这样厚待你们的主人扫罗，把他安葬，愿耶和华赐福给你们！</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及记 34:6; 马太福音 5:44"> 愿耶和华以慈爱和信实待你们，我也会厚待你们，因为你们做了这事。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:10; 撒母耳记下 10:12; 创世记 15:1"> 现在你们的主扫罗已经死了，犹大支派已经膏立我做他们的王，你们要刚强勇敢。”</span>
</div>
</div>

## 大卫家与扫罗家争战

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 14:50; 创世记 32:2; 撒母耳记下 3:7–8"> 那时，扫罗的元帅——尼珥的儿子押尼珥带着扫罗的儿子伊施·波设过河来到玛哈念，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 19:18; 约书亚记 13:8–11; 民数记 1:40"> 立他为王统治基列、亚书利、耶斯列、以法莲、便雅悯和以色列其余的地方。</span>
<span className="v" id="v10" data-v="10"> 扫罗的儿子伊施·波设四十岁登基，统治以色列两年。犹大支派则跟随大卫。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 大卫在希伯仑做王统治犹大支派七年半。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:25; 约书亚记 10:2; 约书亚记 9:3"> 有一次，尼珥的儿子押尼珥带领扫罗的儿子伊施·波设的军队，从玛哈念前往基遍。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 8:16; 历代志上 2:16; 撒母耳记下 20:23"> 洗鲁雅的儿子约押带领大卫的军队出来，在基遍池与他们相遇。一方坐在池这边，一方坐在池那边。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥对约押说：“让双方的青年起来，在我们面前较量一下吧。”约押说：“好啊。”</span>
<span className="v" id="v15" data-v="15"> 于是，伊施·波设的便雅悯人和大卫的仆人双方都起身选了十二人出来，</span>
<span className="v" id="v16" data-v="16"> 他们各自抓住对方的头发，用刀刺对方的肋旁，同归于尽。于是基遍的那个地方叫“刀田”。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:1"> 那天，两军恶战，押尼珥和以色列人被大卫的人马杀败。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 12:8; 哈巴谷书 3:19; 雅歌 8:14"> 当时，洗鲁雅的三个儿子约押、亚比筛和亚撒黑都在场。亚撒黑跑得飞快如田野的鹿，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:21; 约书亚记 1:7; 箴言 4:27"> 他跟在押尼珥后面，不偏不离，穷追不舍。</span>
<span className="v" id="v20" data-v="20"> 押尼珥回头问道：“你是亚撒黑吗？”亚撒黑说：“正是。”</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 14:19"> 押尼珥说：“你离开我，去追赶别人，夺取他的兵器吧。”但亚撒黑还是穷追不舍。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:27; 箴言 29:1; 列王纪下 14:10–12"> 押尼珥又对他说：“别追我了，非逼我杀你吗？我若杀了你，还有何颜面见你哥哥约押呢？”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:27; 撒母耳记下 4:6; 撒母耳记下 5:6"> 但亚撒黑还是不肯罢休。押尼珥就用枪柄刺入他的肚腹，穿透了他的后背，他便倒地身亡。众人赶到那里，都停了下来。</span>
<span className="v" id="v24" data-v="24"> 但约押和亚比筛却继续追赶押尼珥。太阳落山时，他们追到了基亚附近的亚玛山，通往基遍旷野的路旁。</span>
<span className="v" id="v25" data-v="25"> 便雅悯人在押尼珥的带领下聚集在一个山头上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 46:14; 耶利米书 46:10; 使徒行传 7:26"> 押尼珥向约押喊道：“我们非要无休止地杀下去吗？难道你不知道这样下去必有苦果吗？你什么时候才命令你的人停止追杀自己的同胞呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳记下 2:14; 箴言 15:1"> 约押说：“我凭永活的上帝起誓，你要是不这样说，我们会一直追到天亮。”</span>
<span className="v" id="v28" data-v="28"> 于是，约押吹响号角，所有的人便停止了战斗，不再追击以色列人。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8; 雅歌 2:17"> 押尼珥和随从连夜赶路，穿过了亚拉巴，过了约旦河，第二天又马不停蹄地走了一个上午，回到玛哈念。</span>
<span className="v" id="v30" data-v="30"> 约押追赶押尼珥回来后细点人数，发现除亚撒黑外大卫的军队还损失了十九个人。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:1; 列王纪上 20:11"> 大卫的军队杀了三百六十个跟随押尼珥的便雅悯人。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 2:13–16; 撒母耳记上 17:58; 历代志下 21:1"> 约押和他的随从把亚撒黑送到伯利恒，葬在他父亲的坟墓里。然后，他们整夜赶路，黎明的时候回到了希伯仑。</span>
</div>

## 大卫和洗巴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 25:18; 撒母耳记下 15:32; 撒母耳记下 9:2–13"> 大卫刚越过了山顶，就看见米非波设的仆人洗巴牵着两头驴，驴背上驮着二百个面饼、一百个葡萄饼、一百个夏天的果饼和一皮袋酒来迎接他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 17:29; 士师记 10:4; 士师记 5:10"> 王问洗巴说：“你带这些来做什么？”洗巴说：“驴是给王的家眷骑的，饼和夏天的水果是给你的随从吃的，酒是供他们在旷野疲惫时喝的。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 9:9–10; 诗篇 15:3; 撒母耳记下 19:24–30"> 王又问他：“你主人的孙子米非波设在哪里？”洗巴说：“他在耶路撒冷，因为他相信现在以色列人会把他祖父的国归还给他。”</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 18:13; 箴言 18:17; 箴言 19:2"> 王就对洗巴说：“米非波设的一切现在都归你了。”洗巴说：“我叩拜我主我王，愿我在你面前蒙恩。”</span>
</div>
</div>

## 示每咒诅大卫

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:16; 撒母耳记上 17:43; 出埃及记 22:28"> 大卫王来到巴户琳时，扫罗家族基拉的儿子示每出来向着大卫边走边骂，</span>
<span className="v" id="v6" data-v="6"> 还朝大卫和他的臣仆扔石头，无视大卫身边的众多随从和勇士。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 13:13; 撒母耳记上 25:17; 列王纪上 21:10"> 示每骂大卫：“滚吧！滚吧！你这个杀人凶手，你这个败类！</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 1:16; 撒母耳记下 3:28–29; 列王纪上 2:32–33"> 你杀扫罗的家人，夺他的王位，耶和华报应了你，把江山交给了你儿子押沙龙。你这杀人凶手是自食恶果！”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 22:28; 撒母耳记下 9:8; 撒母耳记上 24:14"> 洗鲁雅的儿子亚比筛对王说：“这死狗竟敢咒骂我主我王，让我过去砍掉他的头！”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 19:22; 罗马书 9:20; 约翰福音 18:11"> 王却说：“洗鲁雅的儿子啊，不要管我的事。如果是耶和华叫他来咒骂我，谁能干涉他呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 17:1–4; 创世记 45:5; 撒母耳记下 12:11–12"> 大卫对亚比筛和他所有臣仆说：“我的亲生儿子尚且要取我的命，何况这个便雅悯人呢？由他去吧！让他咒骂吧！因为这是耶和华的意思。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 希伯来书 12:10; 诗篇 25:18"> 也许耶和华会体察我的困苦，因我今天所受的咒骂而赐福给我。”</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 23:23; 撒母耳记下 16:5–6"> 于是，大卫和随从继续赶路，示每也沿着对面的山坡边走边骂，向他们扔石头，撒灰尘。</span>
<span className="v" id="v14" data-v="14"> 王和众人来到约旦河边时，疲惫不堪，便在那里歇息。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:37; 撒母耳记下 15:12"> 押沙龙和以色列众人进了耶路撒冷，亚希多弗也和他在一起。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 11:12; 撒母耳记上 10:24; 列王纪上 1:25"> 大卫的朋友亚基人户筛去见押沙龙，对他说：“愿王万岁！愿王万岁！”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 19:25; 撒母耳记下 15:32–37; 申命记 32:6"> 押沙龙问户筛说：“这就是你对朋友的忠诚吗？你为什么不跟你的朋友去呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:13; 撒母耳记下 5:1–3"> 户筛说：“我不去，谁是耶和华和全体以色列人民所拣选的，我就归属谁，留在谁那里。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 15:34; 诗篇 55:21; 撒母耳记上 28:2"> 再说，我应该服侍谁呢？难道不该服侍王的儿子吗？我要像服侍你父亲一样服侍你。”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:10; 诗篇 37:12–13; 以赛亚书 29:15"> 押沙龙问亚希多弗下一步应该怎么办。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 20:3; 撒母耳记下 15:16; 撒迦利亚书 8:13"> 亚希多弗说：“你父亲留下几个妃嫔看守宫殿，你要跟她们同寝，叫所有的以色列人知道你与父亲誓不两立，这样支持你的人会更坚定。”</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 12:11–12; 撒母耳记下 15:16; 撒母耳记下 20:3"> 于是，他们便为押沙龙在殿顶盖了一座帐篷，他就当着所有以色列人的面与父亲的妃嫔同寝。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 15:12; 撒母耳记下 17:14; 撒母耳记下 17:23"> 那时，亚希多弗出的主意如同是来自上帝的话，大卫曾对他言听计从，现在押沙龙也是一样。</span>
</div>

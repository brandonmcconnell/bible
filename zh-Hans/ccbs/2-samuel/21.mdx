## 基遍人向扫罗家复仇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 7:11–12; 创世记 26:1; 创世记 12:10"> 在大卫执政期间，连续有三年饥荒，大卫就求问耶和华。耶和华说：“发生这饥荒是因为扫罗一家人的血债，他们杀害了基遍人。”</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 9:3–21; 列王纪下 10:31; 撒母耳记上 14:44"> 原来基遍人不是以色列人，他们是亚摩利人的遗民。以色列人曾起誓不伤害他们，但扫罗为以色列人和犹大人发热心，试图铲除基遍人。大卫就召来基遍人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 20:19; 希伯来书 9:22; 撒母耳记上 26:19"> 问他们：“我可以为你们做些什么？我该怎样赎罪，你们才愿意祝福耶和华的子民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“子民”希伯来文是“产业”。">a</a></sup>呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 49:6–8; 彼得前书 1:18–19"> 基遍人答道：“金银不能解决我们和扫罗一家人的问题，我们也不想处死任何以色列人。”大卫说：“你们要我怎么办？”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 21:1; 但以理书 9:26; 马太福音 7:2"> 他们说：“扫罗曾试图灭绝我们，把我们从以色列境内铲除。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:24; 民数记 25:4–5; 撒母耳记上 11:4"> 请把他的七个子孙交给我们，我们好在耶和华面前把他们吊死在基比亚，就是耶和华选立扫罗的地方。”王说：“我必把他们交给你们。”</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 20:15; 撒母耳记上 18:3; 撒母耳记上 23:18"> 大卫王因为与扫罗的儿子约拿单在耶和华面前起过誓，就没有把扫罗的孙子、约拿单的儿子米非波设交出来。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:19; 撒母耳记下 3:7"> 他把爱亚的女儿利斯巴为扫罗所生的两个儿子亚摩尼、米非波设，以及扫罗女儿米拉为米何拉人巴西莱的儿子亚得列所生的五个儿子交给基遍人。</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 1:22; 申命记 21:1–9; 撒母耳记下 6:17"> 基遍人在耶和华面前把他们七人吊死在山上。他们都一同死去，那时正好是收割大麦的时候。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 21:23; 列王纪上 21:27; 约珥书 2:23"> 爱亚的女儿利斯巴取麻布为自己铺在磐石上。她白天不让飞鸟靠近，夜间不容野兽走近，从开始收割大麦，一直守到降下雨来。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 2:4; 路得记 2:11–12"> 大卫知道扫罗的嫔妃——爱亚的女儿利斯巴的事以后，</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 17:11; 撒母耳记上 31:10–13; 撒母耳记下 2:5–7"> 就去基列·雅比人那里把扫罗和约拿单的骸骨运来。从前非利士人在基利波杀死扫罗和约拿单，把他们的尸体挂在伯·珊的广场，后来基列·雅比人把尸体偷走了。</span>
<span className="v" id="v13" data-v="13"> 大卫运回扫罗和约拿单的骸骨，又收殓了扫罗那七个子孙的骸骨。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 18:28; 撒母耳记下 24:25; 约书亚记 7:26"> 众人按照大卫的吩咐，把扫罗和约拿单的骸骨埋葬在扫罗父亲基士的墓里，在便雅悯境内的洗拉。此后，上帝垂听了人们为国家的祷告。</span>
</div>
</div>

## 与非利士人交战

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 14:10–11; 撒母耳记下 5:22; 传道书 12:3"> 非利士人又和以色列人交战，大卫亲自出征。在他十分疲倦的时候，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 21:18; 撒母耳记下 21:20; 撒母耳记上 17:4–5"> 一个名叫以实·比诺的巨人佩戴新刀，手拿三公斤半重的铜矛，冲上来要杀他。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 11:36; 撒母耳记下 18:3; 诗篇 132:17"> 洗鲁雅的儿子亚比筛赶来救驾，杀死了非利士巨人。这事以后，大卫的部下向他起誓说：“你绝不可再跟我们一起出战，免得以色列的灯熄灭。”</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 11:29; 撒母耳记下 21:20; 撒母耳记下 21:16"> 后来，以色列人与非利士人在歌伯交战，户沙人西比该杀了另一个非利士巨人撒弗。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 20:5; 撒母耳记上 17:4–11; 历代志上 11:26"> 在歌伯与非利士人的另一次交战中，伯利恒人雅雷·俄珥金的儿子伊勒哈难杀了迦特人歌利亚。歌利亚的枪杆粗如织布机的轴。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 21:18; 撒母耳记下 21:16; 历代志上 20:6"> 在迦特的一次交战中，有一个非利士巨人每只手和脚各有六个手指和脚趾，共二十四个手指和脚趾。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 17:10; 撒母耳记上 17:36; 撒母耳记上 16:9"> 他向以色列人骂阵，大卫的哥哥示米亚的儿子约拿单杀了他。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 20:8; 罗马书 8:31; 耶利米书 9:23"> 这四个迦特巨人的后裔都死在大卫和他的部下手里。</span>
</div>

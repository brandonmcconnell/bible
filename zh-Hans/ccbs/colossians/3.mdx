## 追求属天的事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 8:6; 马太福音 6:33; 哥林多后书 4:18"> 你们既然和基督一同复活了，就应当追求天上的事，那里有坐在上帝右边的基督。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 2:15–17; 历代志上 22:19; 歌罗西书 3:1"> 你们要思想天上的事，而不是地上的事，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:20; 罗马书 6:2; 歌罗西书 2:20"> 因为你们的旧生命已经死了，你们的新生命与基督一同藏在上帝里面。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:25; 约翰一书 3:2; 加拉太书 2:20"> 基督就是你们的新生命，祂显现的时候，你们也必和祂一起在荣耀中显现。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:13; 加拉太书 5:19–21; 加拉太书 5:24"> 所以，你们要治死身上属世的罪恶，如淫乱、污秽、邪情、恶欲和贪心，贪心就是拜偶像，</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 5:6; 罗马书 1:18; 彼得前书 1:14"> 因为上帝的烈怒必临到做这些事的悖逆之人。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:2; 彼得前书 4:3–4; 罗马书 6:19–20"> 你们过去也过着罪恶的生活，</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 4:29; 以弗所书 4:22; 雅各书 1:20–21"> 但现在必须杜绝怒气、愤恨、恶毒、毁谤和污言秽语等恶事。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:22; 以弗所书 4:25; 利未记 19:11"> 不要彼此说谎，因为你们已经脱去了旧人和旧人的行为，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:23–24; 罗马书 12:2; 以弗所书 2:10"> 穿上了新人。这新人在知识上不断更新，更像他的造物主。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 罗马书 10:12"> 从此，不再分希腊人、犹太人，受割礼的、未受割礼的，野蛮人、未开化的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“未开化的人”希腊文是“西古提人”。">a</a></sup>，奴隶和自由人，基督就是一切，并且在一切之中。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 以弗所书 4:2; 约翰一书 4:19"> 所以，你们既然是上帝所拣选的，是圣洁、蒙爱的人，就要心存怜悯、恩慈、谦卑、温柔和忍耐。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:32; 马可福音 11:25; 雅各书 2:13"> 倘若彼此之间有怨言，总要互相宽容，彼此饶恕，主怎样饶恕你们，你们也要照样饶恕他人。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:8; 以弗所书 5:2; 哥林多前书 13:1–13"> 最重要的是要有爱，爱能把一切完美地联合在一起。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 4:6–7; 约翰福音 14:27; 以赛亚书 26:3"> 要让基督的平安掌管你们的心，你们就是为此而蒙召成为一个身体。要常存感恩的心。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:11; 以弗所书 5:19; 约翰福音 15:7"> 要将基督的话丰丰富富地存在心里，用一切智慧彼此教导，互相劝诫，以感恩的心用诗篇、圣诗、灵歌颂赞上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 10:31; 歌罗西书 3:23; 箴言 3:6"> 你们无论说什么和做什么，都要奉主耶稣的名来说和做，并借着祂感谢父上帝。</span>
</div>
</div>

## 和谐家庭

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:22–9; 提多书 2:4–5; 哥林多前书 11:3"> 你们做妻子的，要顺服丈夫，信主的人应当这样做。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:7; 创世记 2:23–24; 歌罗西书 3:21"> 你们做丈夫的，要爱妻子，不可恶待她们。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 箴言 6:20"> 你们做儿女的，凡事要听从父母，因为这是主所喜悦的。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所书 6:4; 诗篇 103:13"> 你们做父亲的，不要激怒儿女，免得他们灰心丧志。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:5–7; 提摩太前书 6:1–2; 加拉太书 1:10"> 你们做奴仆的，凡事要听从你们世上的主人，不要只做讨好人的表面工夫，要以敬畏主的心真诚服侍。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 3:17; 以弗所书 6:6–7; 罗马书 14:8"> 无论做什么事，都要发自内心，像是为主做的，而不是为人做的，</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 6:8; 加拉太书 1:10; 使徒行传 20:32"> 因为你们知道自己一定会从主那里得到基业为奖赏。你们事奉的是主基督，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:34; 罗马书 2:11; 哥林多后书 5:10"> 凡作恶的人终必自食恶果，因为上帝不偏待人。</span>
</div>
</div>

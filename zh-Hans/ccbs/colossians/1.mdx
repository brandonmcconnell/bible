## 感恩与祷告

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 1:2; 歌罗西书 1:9; 提摩太后书 1:3"> 我们听说了你们对基督耶稣的信心和对众圣徒的爱心，为你们祷告的时候，常常感谢我们主耶稣基督的父上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:3–4; 以弗所书 1:13; 提摩太后书 4:8"> 你们能有这样的信心和爱心是因为那为你们存在天上的盼望，就是你们之前从福音真道中听到的盼望。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 腓立比书 1:11; 歌罗西书 1:23"> 这福音不但传到了你们那里，也传到了世界各地，不断结出果实并发展壮大，正如你们当初听了福音并真正明白上帝恩典后的情形。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 4:12; 腓利门书 1:23; 歌罗西书 4:7"> 这福音是你们从我们亲爱的同工以巴弗那里学到的。他代表我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我们”有古卷作“你们”。">a</a></sup>做基督的忠仆，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 15:30; 提摩太后书 1:7; 加拉太书 5:22"> 并把圣灵赐给你们的爱心告诉了我们。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 3:17; 腓立比书 1:9–11; 雅各书 1:5"> 因此，从听到你们的消息那天起，我们便不断地为你们祷告，求上帝使你们在一切属灵的智慧和悟性上完全明白祂的旨意，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:1; 希伯来书 13:21; 彼得后书 1:2–3"> 以便你们行事为人对得起主，凡事蒙祂喜悦，在一切善事上结出果实，对上帝的认识不断增加。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:16; 腓立比书 4:13; 以弗所书 4:2"> 愿上帝用祂荣耀的权能使你们刚强，无论遇到什么事都能长久忍耐，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:32; 以弗所书 1:11; 以弗所书 1:18"> 欢喜地感谢天父，因祂使你们有资格跟众圣徒在光明中同享基业。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 使徒行传 26:18; 彼得前书 2:9"> 祂把我们从黑暗的权势下拯救出来，迁入祂爱子的国度里。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:7; 罗马书 3:24–25; 彼得前书 1:19–20"> 我们借着祂的爱子蒙救赎，罪得到赦免。</span>
</div>
</div>

## 基督超越一切

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 1:3; 约翰福音 14:9; 约翰福音 1:1"> 爱子是那不能看见之上帝的真像，超越<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“超越”或译“先存于”，希腊文是“长子”，常用来指地位上的优越或时间上的优先。">b</a></sup>一切受造之物。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:36; 约翰福音 1:3; 哥林多前书 8:6"> 因为万物都是借着祂创造的，天上的、地上的、有形的、无形的、做王的、统治的、执政的、掌权的，一切都是借着祂也是为了祂而创造的。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 1:3; 哥林多前书 8:6; 使徒行传 17:28"> 祂存在于万物之先，万物都靠祂维系。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:22–23; 启示录 1:5; 以弗所书 4:15–16"> 祂是教会的头，教会是祂的身体；祂是开始，是首先从死里复活的，好在一切事上居首位。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 2:9; 约翰福音 1:16; 以弗所书 1:23"> 因为上帝乐意让一切的丰盛住在祂里面，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:18–21; 以弗所书 1:10; 约翰一书 4:9–10"> 又借着祂在十字架上所流的血成就了和平，使天地万物借着祂与上帝和好。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所书 2:12; 提多书 3:3–7; 以弗所书 2:1–3"> 你们从前与上帝隔绝，行事邪恶，心思意念与祂为敌；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:27; 犹大书 1:24; 以弗所书 1:4"> 但现在上帝借着基督肉身的死使你们与祂和好了，让你们在祂面前成为圣洁无瑕、无可指责的人。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 3:14; 希伯来书 3:6; 马太福音 24:13–14"> 只是你们必须恒心持守所信的道，根基稳固，坚定不移，不要失去你们听到福音后所得到的盼望。这福音传给了天下万民。我保罗也做了这福音的使者。</span>
</div>
</div>

## 保罗为教会受苦

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="罗马书 5:3; 提摩太后书 1:8; 哥林多后书 1:5–8"> 我现在因着能为你们受苦而欢喜，并且我是为基督的身体——教会的缘故，在自己身上补满基督未受尽的苦难。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所书 3:2; 歌罗西书 1:23; 加拉太书 2:7–8"> 我受上帝的委派成为教会的仆人，要把上帝的道完整地传给你们。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 罗马书 16:25–26; 以弗所书 3:3–10"> 这道是历世历代一直隐藏的奥秘，现在已经向祂的众圣徒显明了。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:20; 罗马书 8:10; 以弗所书 3:16–17"> 上帝要他们知道这奥秘在外族人中有何等丰盛的荣耀，这奥秘就是：基督在你们里面，使你们有荣耀的盼望。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:27; 耶利米书 3:15; 以弗所书 4:11–13"> 我们传扬基督，用一切智慧劝诫、教导众人，使他们在基督里长大成熟，好把他们交给上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 15:10; 以弗所书 1:19; 哥林多前书 9:25–27"> 为此，我按着祂在我身上运行的大能尽心竭力，不辞劳苦。</span>
</div>
</div>

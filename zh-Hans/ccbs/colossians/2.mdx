## 生活以基督为中心

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 1:10; 约翰一书 2:6; 帖撒罗尼迦前书 4:1"> 你们既然接受了基督耶稣为主，就当继续遵从祂，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 3:17; 耶利米书 17:8; 以弗所书 2:20–22"> 按照你们所受的教导在祂里面扎根成长，信心坚固，满怀感恩。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 6:20; 以弗所书 5:6; 马太福音 7:15"> 你们要谨慎，免得有人用空洞虚假的哲学把你们掳去。这些哲学不是出于基督，而是出于人的传统和世界的基本规条。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:19; 约翰福音 10:30; 约翰福音 1:14"> 因为上帝的本质全部有形有体地蕴含在基督里，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:19; 歌罗西书 1:16–18; 以弗所书 1:20–23"> 你们在基督里得到了丰盛的生命。祂是一切执政者和掌权者的元首。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 2:29; 腓立比书 3:3; 罗马书 6:6"> 你们也在基督里受了非人手所行的割礼，是基督为除掉你们罪恶本性而行的割礼。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:3–5; 彼得前书 3:21; 加拉太书 3:27"> 你们接受洗礼时已经与基督一同埋葬了，并借着相信上帝使基督从死里复活的大能，与基督一同复活了。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:5–6; 罗马书 8:11; 以弗所书 2:1"> 你们从前死在过犯和未被割除的本性中，但现在上帝却使你们与基督一同活了过来。上帝赦免了我们一切的过犯，</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 44:22; 以弗所书 2:14–16; 以赛亚书 43:25"> 撤销了指控我们违背律法的罪状，把它钉在十字架上，将它消除。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 2:14; 以弗所书 4:8; 马太福音 12:29"> 祂扫除了灵界的诸多权势，用十字架上的胜利公开羞辱它们。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 14:5–6; 罗马书 14:10; 加拉太书 4:10"> 所以，不可让人在饮食、节期、朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup>或安息日的事上论断你们。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:1; 希伯来书 8:5; 约翰福音 1:17"> 这些都不过是将来之事的影子，实体就是基督。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:8; 约翰一书 4:1–2; 歌罗西书 2:23"> 有些人喜欢故作谦卑，敬拜天使，沉迷于所看见的幻象，你们不要因他们而失去得奖赏的资格。他们随从自己堕落的思想无故自高自大，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:15–16; 约翰福音 15:4–6; 彼得后书 3:18"> 没有与身体的头基督联结。其实，全身靠关节和筋络维系，从基督得到供应，按上帝的旨意渐渐成长。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 歌罗西书 2:16; 加拉太书 4:3"> 你们既然和基督一同死了，摆脱了世界的基本规条，为什么仍像活在世俗中，</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:3; 创世记 3:3; 以赛亚书 52:11"> 服从“不可拿、不可尝、不可摸”等规条呢？</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 29:13; 提多书 1:14; 哥林多前书 6:13"> 这些规条不过是人的戒律和说教，经不起应用，</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 4:8; 歌罗西书 2:18; 歌罗西书 2:8"> 看似充满智慧，其实只不过是自创宗教、自表谦卑、苦待己身，对于克制邪情私欲毫无用处。</span>
</div>
</div>

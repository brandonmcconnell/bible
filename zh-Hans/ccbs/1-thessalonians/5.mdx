## 主来的日子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:7; 帖撒罗尼迦前书 4:9; 马太福音 24:36"> 弟兄姊妹，这件事会在什么日期、什么时候发生，不必我写信告诉你们，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:15; 彼得后书 3:10; 马太福音 24:42–44"> 因为你们已经清楚知道，主的日子会像夜间的贼一样突然临到。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 21:34–35; 马太福音 24:37–39; 路加福音 17:26–30"> 当人们正在说一切平安稳妥的时候，灾祸会像产痛临到孕妇一样突然临到他们，他们将无法逃脱。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:8; 彼得后书 3:10; 申命记 19:6"> 然而，弟兄姊妹，你们不是活在黑暗里，因此那日子不会像贼一样突然临到你们。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:8; 使徒行传 26:18; 约翰福音 12:36"> 你们都是光明之子，白昼之子。我们既不属于黑夜，也不属于黑暗。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 1:13; 马太福音 24:42; 路加福音 22:46"> 所以不要像其他人一样沉睡，要警醒戒备，</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 13:13; 哥林多前书 15:34; 彼得后书 2:13"> 因为睡觉的人是在夜里睡，醉酒的人是在夜里醉。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:12–13; 以弗所书 6:11; 彼得前书 1:13"> 我们既属于白昼，就应当保持清醒，要把信心和爱心当作护心镜遮胸，把得救的盼望当作头盔戴上。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 彼得前书 2:10; 提摩太后书 2:10"> 因为上帝不是预定我们受惩罚，而是预定我们靠着主耶稣基督得救。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:8–9; 彼得前书 3:18; 罗马书 8:34"> 主替我们死，使我们无论是醒是睡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“是醒是睡”或译“是生是死”。">a</a></sup>，都可以与祂同活。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 4:29; 希伯来书 10:25; 罗马书 15:2"> 所以，你们要彼此鼓励、互相造就，正如你们一向所做的。</span>
</div>
</div>

## 劝勉与问候

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:17; 希伯来书 13:7; 提摩太前书 5:17–18"> 弟兄姊妹，我劝你们要敬重那些在你们当中辛勤工作、在主里领导和劝诫你们的人。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 9:50; 希伯来书 12:14; 加拉太书 6:6"> 因为他们的工作，你们要怀着爱心格外敬重他们。你们要彼此和睦相处。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:2; 罗马书 14:1; 使徒行传 20:35"> 弟兄姊妹，我劝你们要告诫懒惰的人，鼓励灰心的人，扶持软弱的人，耐心对待所有的人。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:9; 加拉太书 6:10; 利未记 19:18"> 你们要小心，谁都不可冤冤相报，总要彼此善待，也要善待众人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:12; 腓立比书 4:4; 马太福音 5:12"> 要常常喜乐，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:12; 歌罗西书 4:2; 以弗所书 6:18"> 不断地祷告，</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:20; 腓立比书 4:6; 歌罗西书 3:17"> 凡事谢恩，因为这是上帝在基督耶稣里给你们的旨意。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:30; 使徒行传 7:51; 提摩太后书 1:6"> 不要抑制圣灵的感动，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 14:3–6; 哥林多前书 14:1; 民数记 11:25–29"> 不要轻视先知的信息。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1; 罗马书 12:2; 以弗所书 5:10"> 凡事都要小心察验，持守良善的事，</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 6:3; 腓立比书 4:8; 哥林多前书 10:31–33"> 杜绝所有的恶事。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:24; 希伯来书 4:12; 哥林多前书 1:8–9"> 愿赐平安的上帝亲自使你们完全圣洁！愿祂保守你们的灵、魂、体，使你们在主耶稣基督再来的时候无可指责！</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 3:3; 民数记 23:19; 哥林多前书 1:9"> 呼召你们的主是信实可靠的，祂必为你们成就这事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:18–19; 腓立比书 1:19; 腓利门书 1:22"> 弟兄姊妹，请为我们祷告。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 16:16; 哥林多前书 16:20"> 要以圣洁的吻问候众弟兄姊妹。</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 4:16; 使徒行传 19:13; 提摩太前书 1:3"> 我奉主的名吩咐你们把这封信读给所有弟兄姊妹听。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 16:20; 帖撒罗尼迦后书 3:18; 罗马书 16:23"> 愿我们主耶稣基督的恩典与你们同在！</span>
</div>
</div>

</div>

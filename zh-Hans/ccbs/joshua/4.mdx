## 堆石为证

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 27:2; 约书亚记 3:17"> 民众都过河之后，耶和华对约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 3:12; 民数记 1:4–15; 列王纪上 18:31"> “你去从民众中选出十二个人，每支派选一人，</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 4:19–20; 约书亚记 3:13; 约书亚记 4:8"> 吩咐他们从约旦河床祭司站立的地方取十二块石头，放在你们今晚住宿的地方。”</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 4:2; 马可福音 3:14–19"> 约书亚便召来他从以色列人中选的十二个人，每支派一人，对他们说：</span>
<span className="v" id="v5" data-v="5"> “从你们上帝耶和华的约柜前过去，到约旦河中间，以色列每个支派中有一人扛一块石头回来，一共十二块，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:14; 约书亚记 4:21; 诗篇 44:1"> 留在你们中间作记号。以后，倘若你们的子孙问你们，‘这些石头是什么意思？’</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:14; 民数记 16:40; 出埃及记 28:12"> 你们就告诉他们，‘约旦河水在耶和华的约柜前曾经被截断，当约柜过河的时候，河水被截断了。这些石头要在以色列人当中作为永久的纪念。’”</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 4:2–5; 约书亚记 1:16–18; 约书亚记 4:20"> 以色列人遵行了约书亚的吩咐。他们按以色列人支派的数目，从约旦河中取了十二块石头，搬来放在住宿的地方，正如耶和华对约书亚的吩咐。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 7:12; 士师记 1:26; 历代志下 5:9"> 约书亚又在约旦河床抬约柜的祭司站立的地方立了十二块石头。石头至今还在那里。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 3:13; 诗篇 119:60; 箴言 27:1"> 抬约柜的祭司站在约旦河中间，一直站到耶和华吩咐约书亚交待民众做的每一件事都完成了，正如摩西对约书亚的吩咐。民众迅速过了河。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 3:8; 约书亚记 4:18; 约书亚记 3:17"> 所有人都过河以后，祭司才抬着耶和华的约柜在民众注视下过了河。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 32:20–32; 约书亚记 1:14"> 吕便支派、迦得支派和玛拿西半个支派的人照摩西从前的嘱咐，带着兵器走在以色列人前面。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:11; 耶利米书 39:5; 耶利米书 52:8"> 大约有四万武装好的以色列人在耶和华面前过了河，前往耶利哥平原，准备作战。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 3:7; 历代志下 30:12; 列王纪上 3:28"> 那一天，耶和华在以色列众人面前提升约书亚，在他有生之年，他们像敬畏摩西一样敬畏他。</span>
<span className="v" id="v15" data-v="15"> 耶和华对约书亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:19; 出埃及记 25:16–22; 约书亚记 3:3–6"> “你去吩咐抬约柜的祭司从约旦河里上来。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 8:16–18; 使徒行传 16:35–39; 使徒行传 16:23"> 约书亚便吩咐他们从约旦河里上来。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 3:15; 历代志上 12:15; 约书亚记 3:13"> 抬耶和华约柜的祭司从河床上来，脚刚一踏上岸，约旦河的水立刻恢复原状，像以往一样涨过两岸。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:9; 弥迦书 6:5; 出埃及记 12:2–3"> 那天是一月十日。以色列人从约旦河上来后，就在耶利哥东边的吉甲扎营。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:3; 约书亚记 4:8"> 约书亚把从约旦河取来的十二块石头立在吉甲，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 4:6; 诗篇 145:4–7; 诗篇 105:2–5"> 并对以色列人说：“以后，你们的子孙问你们这堆石头是什么意思，</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:17; 以赛亚书 51:10; 以赛亚书 44:27"> 你们就告诉他们，‘这是代表以色列人曾走干地穿过约旦河。’</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:21; 以赛亚书 43:16; 以赛亚书 63:12–14"> 因为你们的上帝耶和华使约旦河成为干地、让你们穿过，就像祂从前使红海成为干地、让我们穿过一样。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 106:8; 诗篇 89:13; 列王纪上 8:42–43"> 这是要让天下万民都知道耶和华的手大有能力，要让你们永远敬畏你们的上帝耶和华。”</span>

## 艾城之战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 1:9; 申命记 7:18; 申命记 1:21"> 耶和华对约书亚说：“不要惊慌害怕。只管率领全军去攻打艾城，我已经将艾城的王、他的人民、城池和土地都交在你手里了。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 20:14; 约书亚记 6:21; 历代志下 20:22"> 你怎样对待耶利哥和耶利哥王，也要照样对待艾城和艾城的王。不过你们可以拿城中的财物和牲畜。你要在城后设下伏兵。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:39; 马太福音 25:6; 帖撒罗尼迦前书 5:2"> 于是，约书亚率领全军前往艾城。他挑选了三万精兵，派他们在黑夜出发，</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 20:29; 约书亚记 8:16; 士师记 20:36"> 并吩咐他们说：“你们要在城后埋伏，不可离城太远，全体保持戒备。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:5; 马太福音 10:16; 士师记 20:31–33"> 我会率领军队正面攻城，当敌人像上次那样出城应战时，我们便逃跑。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 20:32; 出埃及记 15:9; 传道书 8:11"> 他们必定乘胜追击，我们便引他们离城，因为敌人一定会以为我们又像上次一样临阵逃跑。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王纪下 5:1; 约书亚记 8:1"> 那时，你们便从埋伏的地方冲出来攻占艾城，你们的上帝耶和华一定会把艾城交在你们手里。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 13:28; 约书亚记 1:16; 约书亚记 1:9"> 你们攻陷艾城后，要照耶和华的话放火焚城。这是我的命令。”</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 7:2; 创世记 12:8; 以斯拉记 2:28"> 于是，约书亚派遣他们出去。他们去埋伏在伯特利和艾城之间，就是艾城的西面。那一夜，约书亚住在民众当中。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 6:12; 诗篇 119:60; 创世记 22:3"> 清早，约书亚召集民众，与以色列的众首领率全军前往艾城。</span>
<span className="v" id="v11" data-v="11"> 随他同去的军队都向前推进，来到城外，在城的北面扎营，与艾城相隔一个山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 8:2–3"> 约书亚选了五千人，让他们埋伏在艾城和伯特利之间，就是艾城的西面。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:12; 约书亚记 8:8"> 于是，城北的主力军队和城西的伏兵都部署好了。当晚，约书亚在山谷里过夜。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:39; 士师记 20:34–36; 申命记 1:1"> 艾城的王见以色列人兵临城下，清早便急忙和全城的人起来出城迎战，在亚拉巴谷附近跟以色列军交锋，他不知道城后有伏兵。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 18:12; 约书亚记 16:1; 士师记 20:36"> 约书亚带领以色列军诈败，沿着通往旷野的路逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 20:31; 士师记 20:36–39; 约书亚记 8:5–6"> 艾城的人都被召去追赶以色列人，他们追击约书亚，被诱出城来。</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 5:13; 约书亚记 8:3; 以赛亚书 19:11–13"> 这样，伯特利和艾城的人倾巢而出，追杀以色列人，他们的城门大开。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约书亚记 8:26; 约伯记 15:25; 撒母耳记上 17:41"> 耶和华对约书亚说：“把你手中的矛指向艾城，因为我要将这城交在你手里。”约书亚就把手中的矛指向艾城。</span>
<span className="v" id="v19" data-v="19"> 他一伸手，城后的伏兵立即行动，迅速冲进城去，一举占领艾城，随即放火烧城。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 76:5; 约伯记 11:20; 创世记 19:28"> 艾城的人回头发现城内烟气冲天，却无路可逃，因为那些逃往旷野的以色列人已掉头攻击他们。</span>
<span className="v" id="v21" data-v="21"> 约书亚和以色列全军见伏兵已经占领艾城，城中浓烟滚滚，便掉头攻击艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:2; 约书亚记 10:28; 约书亚记 6:21"> 伏兵也出城追击艾城的人。以色列军前后夹攻，把敌人围困在中间全部歼灭，无一漏网。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 15:8; 约书亚记 10:17; 启示录 19:20"> 他们生擒了艾城的王，将他押到约书亚那里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 11:10–14; 约书亚记 10:30–41; 民数记 21:24"> 以色列军在田间和旷野用刀杀尽了追赶他们的艾城人后，又进城杀了留在城里的人，</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 20:16–18"> 当天被杀的艾城人男男女女共有一万二千人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:11–12; 约书亚记 8:18"> 一直到艾城所有的人都被杀光了，约书亚才收回手中的矛。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:2; 民数记 31:26; 诗篇 50:10"> 以色列人照耶和华对约书亚的吩咐，只带走了城中的牲畜和财物。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 13:16; 耶利米书 49:2; 列王纪下 19:25"> 约书亚烧毁全城，使城永远成为一堆废墟，至今仍一片荒凉。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 7:26; 撒母耳记下 18:17; 申命记 21:22–23"> 约书亚又将艾城王的尸体挂在树上示众。黄昏时，他才吩咐人把尸体取下来扔在城门口，又在尸体上堆了一大堆石头。石堆至今还在。</span>
</div>
</div>

## 重申律法

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命记 27:4–6; 出埃及记 20:24; 创世记 12:7–8"> 约书亚照耶和华的仆人摩西对以色列人的吩咐，在以巴路山上为以色列的上帝耶和华筑了一座祭坛。这坛是按照摩西律法书的记载，用未经铁器凿过的原石筑的。以色列人就在这坛上把燔祭和平安祭献给耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 27:2–3; 申命记 27:8"> 约书亚又在众人面前，将摩西所写的律法刻在石头上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 11:29; 申命记 31:12; 申命记 31:9"> 所有以色列人与他们的长老、官员和审判官都站在耶和华的约柜两旁，面对着抬约柜的利未祭司，寄居的外族人和本族人都在场。他们一半人站在基利心山前，一半人站在以巴路山前，正如耶和华的仆人摩西从前祝福他们时所吩咐的。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 8:2–3; 尼希米记 13:1; 申命记 31:10–12"> 随后，约书亚按照摩西律法书的记载，向民众宣读一切祝福和咒诅的话。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 31:12; 尼希米记 8:2; 耶利米书 26:2"> 他在全体会众，包括妇女、小孩以及住在他们中间的外族人面前，一字不漏地宣读摩西的一切吩咐。</span>
</div>
</div>

## 约书亚的诀别之言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 13:1; 约书亚记 21:44; 约书亚记 11:23"> 此后很长时间，耶和华使以色列人四境太平，没有战事。约书亚年事已高，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 申命记 31:28; 历代志上 28:1"> 他召来全体以色列人，包括长老、族长、审判官和官长，对他们说：“我已经老了，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:14; 约书亚记 10:42; 约书亚记 10:14"> 你们都亲眼看见你们的上帝耶和华怎样为了你们而对付列邦，亲自为你们争战。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:6–7; 约书亚记 18:10; 约书亚记 13:2"> 从约旦河到西边地中海的这片土地，无论是已征服的还是没有征服的，我已经用抽签的方式分给你们各支派作产业。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 11:23; 约书亚记 13:6; 出埃及记 33:2"> 你们的上帝耶和华必把列邦从你们面前驱离赶走，让你们占据他们的土地，正如你们的上帝耶和华的应许。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 5:32; 申命记 28:14; 箴言 4:26–27"> 所以，你们要刚强，谨遵摩西律法书上所记载的一切，不可有半点偏离。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 23:13; 诗篇 16:4; 申命记 7:2–3"> 不可与你们中间剩下的异族混杂，不可提他们的神明或凭它们起誓，不可供奉和祭拜他们的神明。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 10:20; 约书亚记 22:5; 申命记 13:4"> 你们要一如既往地倚靠你们的上帝耶和华，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 1:5; 申命记 11:23; 约书亚记 23:5"> 因为祂为你们赶走了强大的外族人，至今无人敌得过你们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:30; 利未记 26:8; 申命记 3:22"> 你们一个人能打败他们一千人，因为你们的上帝耶和华照着祂的应许为你们争战。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 22:5; 申命记 6:5–12; 箴言 4:23"> 所以你们要特别谨慎，爱你们的上帝耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:3; 以西结书 18:24; 西番雅书 1:6"> 如果你们悖逆，跟你们当中剩下的异族人联合，通婚往来，</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 7:16; 民数记 33:55; 出埃及记 23:33"> 毫无疑问，你们的上帝耶和华必不再为你们赶走他们。相反，他们还要成为设在你们当中的圈套和陷阱，你们的肉中刺、眼中钉，直到你们在你们的上帝耶和华所赐给你们的这块美好的土地上灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王纪上 2:2; 利未记 26:3–13"> “我快要走完人世的路程了。你们深知你们的上帝耶和华赐给你们的一切美好应许没有一句落空，都已经应验了。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:15–68; 利未记 26:14–46; 士师记 3:8"> 正如你们的上帝耶和华已成就祂应许给你们的一切福气，祂也会照样降各样灾祸给你们，直到把你们从祂所赐的这美好土地上毁灭。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:25–26; 列王纪下 24:20"> 你们如果违背你们的上帝耶和华吩咐你们遵守的约，去供奉、祭拜其他神明，祂必向你们发怒，使你们在祂所赐的这美好土地上迅速灭亡。”</span>
</div>
</div>

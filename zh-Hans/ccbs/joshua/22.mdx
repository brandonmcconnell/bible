## 建祭坛之争

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 32:18–33; 申命记 29:7–8"> 约书亚召来了吕便、迦得和玛拿西半个支派的人来，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:12–18; 申命记 3:16–20; 民数记 32:20–29"> 对他们说：“你们都遵守了耶和华的仆人摩西的一切吩咐，也听从了我的一切吩咐。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:23–27"> 这些日子以来，你们从没有离弃自己的弟兄，遵守了你们的上帝耶和华的吩咐。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:8; 民数记 32:18; 申命记 3:20"> 现在你们的上帝耶和华已经照祂的应许使你们的弟兄安居，你们可以回到约旦河东，到摩西赐给你们作产业的地方。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:37; 出埃及记 20:6; 罗马书 8:28"> 不过，你们要谨遵耶和华的仆人摩西吩咐你们的诫命和律法，要爱你们的上帝耶和华，遵行祂的旨意，听从祂的命令，依靠祂，全心全意地事奉祂。”</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:13; 路加福音 24:50; 创世记 47:7"> 于是，约书亚为他们祝福，送他们回去，他们就各自返回家园去了。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 17:1–12; 民数记 32:33; 约书亚记 13:29–31"> 摩西已经在巴珊把土地分给了玛拿西半个支派，约书亚把约旦河西的土地分给了玛拿西另外的半个支派及其他支派。约书亚派他们回家的时候，为他们祝福，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 31:27; 申命记 8:9–14; 箴言 3:16"> 说：“现在你们带着大量财物、牲畜、金银、铜、铁和衣物返回家园，要把从敌人那里得来的财物分给你们的弟兄。”</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 32:29; 民数记 32:26; 民数记 32:1"> 于是，吕便、迦得和玛拿西半个支派的人便离开在迦南的示罗的以色列人，返回耶和华借摩西分配给他们的基列。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:26–27; 创世记 31:46–52; 约书亚记 4:5–9"> 他们来到约旦河附近的迦南境内，就在约旦河边筑了一座高大的祭坛。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 13:12–14; 利未记 17:8–9; 约书亚记 2:7"> 以色列人听见吕便、迦得和玛拿西半个支派的人在约旦河西的迦南境内筑起了一座祭坛，</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–11; 申命记 13:15; 加拉太书 4:17–18"> 便全部聚集在示罗，要讨伐他们。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 25:7; 诗篇 106:30–31; 出埃及记 6:25"> 以色列人派祭司以利亚撒的儿子非尼哈去基列见他们，</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:4; 出埃及记 18:25"> 又从每支派差遣一位族长，共十位随行。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:3; 撒母耳记上 15:23; 申命记 30:17"> 他们来到基列的吕便、迦得和玛拿西半个支派的人那里，对他们说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 12:13–14"> “耶和华的全体会众问你们，你们怎能这样背叛以色列的上帝，离弃耶和华，为自己另建祭坛呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 25:1–18; 诗篇 106:28–29; 申命记 4:3–4"> 从前拜毗珥的罪恶不够大吗？那一次，瘟疫降到耶和华的会众身上，直到今日我们还没有洗净这罪。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 16:22; 约书亚记 22:16; 约书亚记 7:11"> 你们今日要离弃耶和华吗？今日你们背叛耶和华，明日祂必向以色列全体会众发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 18:1; 历代志下 11:16–17; 使徒行传 10:14–15"> 你们如果认为自己的土地不洁净，可以搬到耶和华的土地上跟我们一起居住，这里有耶和华的圣幕。只是不可在耶和华的祭坛以外，为自己另筑祭坛，以致背叛耶和华，背叛我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:1; 约书亚记 7:5; 约书亚记 7:18"> 从前谢拉的曾孙亚干私自留下那些耶和华吩咐要毁灭之物，耶和华的烈怒难道没有临到以色列全体会众吗？因他的罪而死的不只他一个人！”</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:19; 箴言 16:1; 彼得前书 3:15"> 吕便、迦得和玛拿西半个支派的人便回答这些以色列的族长说：</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 8:39; 诗篇 44:21; 申命记 10:17"> “大能的上帝耶和华，大能的上帝耶和华，祂知道一切！以色列人也当知道！如果我们悖逆或干犯耶和华，愿祂今天就不放过我们！</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:16; 申命记 18:19; 以西结书 3:18"> 如果我们离弃耶和华，为自己造祭坛，或在坛上献燔祭、素祭和平安祭，愿耶和华亲自惩罚我们。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 4:6; 申命记 6:20; 创世记 30:33"> 我们这样做是怕以后你们的子孙可能会对我们的子孙说，‘你们和以色列的上帝耶和华有什么关系？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 12:16; 以斯拉记 4:2–3; 撒母耳记上 26:19"> 耶和华把约旦河定为我们跟你们吕便人和迦得人的边界，你们与耶和华一点关系也没有。’这样，恐怕你们的子孙会使我们的子孙不再敬畏耶和华。</span>
<span className="v" id="v26" data-v="26"> 因此，我们便商议在这里筑一座祭坛，这坛不是用来献燔祭或别的祭，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 24:27; 创世记 31:48; 申命记 12:17–18"> 只是在你们和我们之间，也在彼此的后人之间立个证据，证明我们也献燔祭、平安祭及其他祭事奉耶和华，免得日后你们的子孙对我们的子孙说，‘你们与耶和华一点关系也没有。’</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:40; 以西结书 43:10–11; 希伯来书 8:5"> 我们商议，万一你们对我们或我们的子孙这样说，我们可以回答说，‘你们看我们祖先筑的这座祭坛跟耶和华的祭坛一模一样，只是这座坛不是用来献燔祭或别的祭，而是作为你们和我们之间的证据！’</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 24:16; 申命记 12:13–14; 约书亚记 22:23"> 我们根本无意背叛、离弃我们的上帝耶和华，在祂圣幕前的祭坛以外另筑祭坛来献燔祭、素祭和别的祭。”</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:33; 以斯帖记 1:21; 箴言 15:1"> 祭司非尼哈和以色列会众的族长听了他们的解释，都很满意。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 15:2; 利未记 26:11–12; 以赛亚书 12:6"> 以利亚撒的儿子祭司非尼哈对他们说：“今日我们知道耶和华在我们当中，因为你们没有对耶和华不忠，现在你们使以色列人免遭耶和华的惩罚了。”</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 22:12–14; 箴言 25:13"> 以利亚撒的儿子非尼哈祭司和众族长便离开吕便人和迦得人，从基列回到迦南向以色列人报告这事。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 29:20; 路加福音 2:28; 但以理书 2:19"> 众人听后，都很满意，便颂赞耶和华，打消了出兵讨伐吕便人和迦得人、毁灭他们家园的念头。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 22:27; 马太福音 4:10; 以赛亚书 43:10"> 吕便人和迦得人给那座祭坛取名叫“证坛”，意思是这坛在我们中间证明耶和华是上帝。</span>

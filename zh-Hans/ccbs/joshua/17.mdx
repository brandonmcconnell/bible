<span className="v" id="v1" data-v="1" data-xref="民数记 26:29; 创世记 41:51; 创世记 50:23"> 以下是约瑟的长子玛拿西支派分到的土地：玛拿西的长子、基列的父亲玛吉是个战士，因此分到了基列和巴珊两地。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 7:18; 民数记 26:29–32; 士师记 6:11"> 玛拿西其他子孙也按宗族分到了土地，他们属于亚比以谢、希勒、亚斯烈、示剑、希弗和示米大宗族。这些男子按宗族都是约瑟的儿子玛拿西的后代。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 27:1; 民数记 26:33; 民数记 36:2–11"> 玛拿西的玄孙、玛吉的曾孙、基列的孙子、希弗的儿子西罗非哈没有儿子，只有五个女儿，名叫玛拉、挪阿、曷拉、密迦、得撒。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 14:1; 民数记 27:5–7; 加拉太书 3:28"> 她们来见祭司以利亚撒、嫩的儿子约书亚和各首领，说：“耶和华曾经吩咐摩西在我们亲族中分给我们产业。”约书亚便照耶和华的吩咐，让她们在叔伯中也分到产业。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 17:2–3; 民数记 32:30–42; 约书亚记 13:29–31"> 除了约旦河东的基列和巴珊两地以外，玛拿西人还分到十块土地，</span>
<span className="v" id="v6" data-v="6"> 因为在玛拿西的后代中，女性也分到了产业。玛拿西其他子孙分到基列地区。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:21; 约书亚记 20:7; 约书亚记 24:32"> 玛拿西支派分到的土地从亚设开始，到示剑东面的密米他，再向南到隐·他普亚人居住的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 16:8; 约书亚记 15:34; 约书亚记 12:17"> 他普亚地属于玛拿西，但在玛拿西边界上的他普亚城属于以法莲的子孙。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 16:3; 约书亚记 19:29; 约书亚记 16:8–9"> 边界继续向南到加拿河，在河南侧玛拿西境内的城邑都归以法莲。玛拿西的边界沿着加拿河北侧直到地中海。</span>
<span className="v" id="v10" data-v="10"> 这样，南面归以法莲，北面归玛拿西，西部边界是地中海，北接亚设，东邻以萨迦。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 7:29; 列王纪下 9:27; 士师记 5:19"> 在以萨迦和亚设境内，玛拿西拥有伯·善、以伯莲、多珥、隐·多珥、他纳和米吉多及其附近的乡村。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 1:27–28; 出埃及记 23:29–33; 罗马书 6:12–14"> 可是，玛拿西人没能把这些城邑的迦南人赶走，因为他们执意不肯离开。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 16:10; 腓立比书 4:13; 士师记 1:35"> 以色列人国势强盛的时候，就让迦南人服劳役，但始终没有把他们完全赶走。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 26:34–37; 创世记 48:19; 创世记 48:22"> 约瑟的子孙对约书亚说：“耶和华赐福给我们，使我们人口众多，为什么你只让我们抽一支签，分一份产业呢？”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 13:7; 创世记 14:5; 路加福音 12:48"> 约书亚对他们说：“你们如果人口众多，认为以法莲山区窄小，可以到比利洗人和利乏音人居住的地方开辟林区。”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:12; 士师记 4:3; 士师记 1:19"> 他们答道：“那些山区不够我们住，况且住在伯·善一带和耶斯列平原的迦南人都有铁战车。”</span>
<span className="v" id="v17" data-v="17"> 约书亚对约瑟的子孙以法莲人和玛拿西人说：“你们人口众多，势力强大，不应只得一签之地，</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:6; 罗马书 8:31; 民数记 14:6–9"> 山区也要分给你们，虽然全是森林，但可以开辟土地，使整个地区归你们。虽然迦南人强盛，有铁战车，但你们必能赶走他们。”</span>

## 以色列人被基遍人欺骗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 34:6; 出埃及记 3:17; 出埃及记 23:23"> 住在约旦河西的山区、丘陵以及地中海沿岸、远至黎巴嫩的诸王，就是那些赫人、亚摩利人、迦南人、比利洗人、希未人和耶布斯人的王听说这件事，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:14; 约珥书 3:9–13; 诗篇 2:1–2"> 就联合起来对抗约书亚和以色列人。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 10:2; 约书亚记 9:17; 撒母耳记下 21:1–2"> 基遍的居民听说约书亚在耶利哥和艾城所做的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 马太福音 10:16; 马可福音 2:22"> 便想出一个诡计来。他们装作特使，把旧皮袋和缝补过的酒囊驮在驴背上，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命记 33:25; 申命记 29:5"> 穿着缝补过的旧鞋和破烂衣服，带着又干又发霉的饼，</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 5:10; 列王纪下 20:14; 约书亚记 9:9"> 到吉甲营去见约书亚。他们对约书亚和以色列人说：“我们从很远的地方来，求你们跟我们缔结盟约。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 11:19; 士师记 2:2; 出埃及记 34:12"> 以色列人对这些希未人说：“你们也许就住在附近。我们怎么能跟你们缔结盟约呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 20:11; 列王纪下 10:5; 约书亚记 9:11"> 他们对约书亚说：“我们是你的奴仆。”约书亚说：“你们是什么人？从哪里来？”</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 20:15; 约书亚记 9:24; 以赛亚书 55:5"> 他们答道：“仆人们因为你的上帝耶和华的大名，才从很远的地方来。我们听说了祂在埃及的一切作为，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–35; 申命记 1:4; 约书亚记 12:4"> 以及祂怎样对付约旦河东的两个亚摩利王——希实本王西宏和亚斯她录的巴珊王噩。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 9:8; 以斯帖记 8:17; 约书亚记 1:11"> 我们的长老和民众就派我们带着干粮来迎接你们，甘做你们的仆人，希望跟你们缔结盟约。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 9:4–5"> 我们出来的时候带的饼是热的，看啊，现在又干又发霉了。</span>
<span className="v" id="v13" data-v="13"> 这些皮酒囊原来也是新的，但现在已经破了。因为长途跋涉，我们的衣服和鞋也都破旧不堪了。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民数记 27:21; 历代志上 10:13–14"> 以色列人接受了他们的食物，却没有求问耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:2; 申命记 20:10–11; 约书亚记 11:19"> 约书亚与他们立了和平盟约，容他们存活，会众的首领也向他们起誓守约。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 立约三天后，以色列人才得知他们原来是邻居，就住在附近。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:25; 约书亚记 18:25–28; 约书亚记 18:14"> 以色列人启程，走了三天来到他们居住的基遍、基非拉、比录和基列·耶琳各城。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 15:4; 撒母耳记下 21:7; 传道书 5:6"> 会众的首领曾凭以色列的上帝耶和华向他们起过誓，所以不能杀他们。全体会众因此向首领大发怨言。</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 8:2; 约书亚记 9:20; 传道书 9:2"> 首领便对全体会众说：“我们曾凭以色列的上帝耶和华向他们起誓，我们现在不能动他们。</span>
<span className="v" id="v20" data-v="20" data-xref="玛拉基书 3:5; 箴言 20:25; 提摩太前书 1:10"> 我们要容他们存活，免得我们因违背誓言而惹耶和华发怒。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 29:11; 约书亚记 9:27; 约书亚记 9:23"> 首领又说：“就容他们存活吧。”首领就叫他们为全体会众劈柴挑水。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 9:6; 约书亚记 9:16; 创世记 3:13–14"> 于是，约书亚召来他们，对他们说：“你们为什么要欺骗我们，说你们住得很远？其实你们就住在附近。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 9:21; 创世记 9:25–26; 约书亚记 9:27"> 因此，你们是受咒诅的。你们要永远做奴仆，为我上帝的殿劈柴挑水。”</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 20:15–17; 申命记 7:1–2; 出埃及记 23:31–33"> 他们答道：“仆人们这样做是因为害怕丧命。我们确实听说你的上帝耶和华曾经应许祂仆人摩西，要把这整片土地都赐给你们，并从你们面前将这里的居民杀尽。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 16:6; 士师记 10:15; 耶利米书 26:14"> 现在我们既然落在你的手中，你们想怎样对待我们就怎样对待吧。”</span>
<span className="v" id="v26" data-v="26"> 约书亚不让以色列人加害他们，因此他们没有被杀死。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5"> 那天，约书亚让他们在耶和华指定的地方，为会众和耶和华的祭坛劈柴挑水。他们至今仍做这样的工作。</span>
</div>
</div>

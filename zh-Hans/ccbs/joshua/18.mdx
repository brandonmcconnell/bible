## 其余土地的分配

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 19:51; 撒母耳记上 1:3; 约书亚记 21:2"> 征服了这些地方以后，以色列全体会众都聚集在示罗，把会幕设立在那里。</span>
<span className="v" id="v2" data-v="2"> 这时，以色列还有七个支派没有分到产业。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 18:9; 箴言 13:4; 箴言 10:4"> 约书亚对他们说：“你们等到什么时候才去占领你们祖先的上帝耶和华赐给你们的土地呢？</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:6; 约书亚记 4:2; 约书亚记 18:3"> 你们每支派要派出三个人，我要差他们走遍那地，按各支派应得的土地绘制地图，然后回来禀告我。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 16:1–10; 约书亚记 19:1–9; 约书亚记 15:1–12"> 他们要把土地划分作七份。犹大要留在南部自己的领土上，约瑟家族要留在北部自己的领土上。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:2; 约书亚记 18:10; 使徒行传 13:19"> 你们把这七份土地绘成地图交给我，我要在我们的上帝耶和华面前为你们抽签。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 13:33; 约书亚记 13:8–31; 民数记 18:20"> 你们当中的利未人没有份，因为做耶和华的祭司这职任就是他们的产业。至于迦得支派、吕便支派和玛拿西半个支派，耶和华的仆人摩西已把约旦河东的土地分给他们了。”</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:10; 罗马书 14:19; 撒母耳记上 14:41"> 那些画地图的人启程出发的时候，约书亚嘱咐他们说：“你们要走遍那里，绘制地图，然后回来禀告我，我要在示罗，在耶和华面前为你们抽签。”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:19"> 于是，他们走遍那里，把所有城邑分作七份，绘在册上，然后回到示罗见约书亚。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 1:12; 使徒行传 13:19; 约书亚记 18:6"> 约书亚便在示罗按照以色列的支派，在耶和华面前为他们抽签分地。</span>
</div>
</div>

## 便雅悯支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 16:1–10; 约书亚记 15:1–8; 申命记 10:1–22"> 便雅悯支派按宗族抽签分到的领土，坐落在犹大和约瑟支派的领土之间。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 16:1; 约书亚记 7:2; 约书亚记 2:1"> 他们北部的边界从约旦河起，沿耶利哥北面的山坡直上，往西穿过山区，直到伯·亚文的旷野；</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 28:19; 约书亚记 16:2–3; 约书亚记 10:11"> 从那里经路斯，即伯特利南面山坡到下伯·和仑南面山区的亚他录·亚达。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:9; 历代志上 13:5–6; 撒母耳记上 7:1–2"> 西面的边界自伯·和仑对面山的西侧，向南直到犹大人的基列·巴力城，即基列·耶琳。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:9"> 南部边界从基列·耶琳的边界开始，向西直到尼弗多亚的水泉，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:10; 约书亚记 15:7–8; 以赛亚书 30:33"> 又往下到欣嫩子谷对面的山麓，也就是利乏音谷北边，然后往南，经欣嫩谷到耶布斯的南坡，直到隐·罗结；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:6"> 然后，向北先后到隐·示麦，亚都冥山坡对面的基利绿，吕便的儿子波罕所立的大石，</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:6; 约书亚记 15:61"> 以及亚拉巴的对面，再往北下到亚拉巴；</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 14:3; 约书亚记 15:2; 民数记 34:3"> 又沿着伯·曷拉的北面直到盐海的北岸，也就是约旦河的南部河口。这是南部的边界。</span>
<span className="v" id="v20" data-v="20"> 东面以约旦河为界。这是便雅悯人按宗族分到的土地四周的边界。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 18:12; 约书亚记 6:1; 约书亚记 18:19"> 以下是便雅悯支派按宗族分到的城邑：耶利哥、伯·曷拉、伊麦·基悉、</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 15:6; 列王纪上 12:29–32; 约书亚记 18:18"> 伯·亚拉巴、西玛莲、伯特利、</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 13:17"> 亚文、巴拉、俄弗拉、</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 2:26; 约书亚记 21:17; 以赛亚书 10:29"> 基法·阿摩尼、俄弗尼、迦巴，共十二座城及其附近的乡村。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:17; 列王纪上 3:4–5; 约书亚记 10:2"> 还有基遍、拉玛、比录、</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 10:17; 以斯拉记 2:25; 约书亚记 9:17"> 米斯巴、基非拉、摩撒、</span>
<span className="v" id="v27" data-v="27"> 利坚、伊利毗勒、他拉拉、</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 21:14; 约书亚记 15:8; 士师记 20:4–5"> 洗拉、以利弗、耶布斯，即耶路撒冷、基比亚、基列，共十四座城及其附近的乡村。 这就是便雅悯各宗族所分到的土地。</span>
</div>
</div>

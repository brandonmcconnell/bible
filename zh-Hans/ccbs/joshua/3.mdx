## 走过约旦河

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 2:1; 马可福音 1:35; 民数记 25:1"> 约书亚清早起来，率领全体以色列人离开什亭，来到约旦河边安营，等候过河。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:10–11"> 过了三天，官长走遍各营，吩咐民众说：</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 撒母耳记下 6:13; 申命记 31:25"> “你们看见做祭司的利未人抬着你们上帝耶和华的约柜出发时，就要起身跟在后面。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 89:7; 希伯来书 12:28–29; 出埃及记 3:5"> 这样，你们就会知道路，因为你们从来没有走过这条路。但你们要跟约柜保持九百米的距离，不要走近约柜。”</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:13; 利未记 20:7; 约珥书 2:16"> 约书亚又对民众说：“你们要洁净自己，因为明天耶和华要在你们当中行奇事。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:2–3; 民数记 14:15; 弥迦书 2:13"> 约书亚又对祭司说：“抬起约柜，率领民众过河吧！”他们就抬起约柜，走在民众前面。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:14; 约书亚记 1:5; 历代志上 29:25"> 耶和华对约书亚说：“从今天开始，我要使你在以色列人面前得到尊荣，让他们知道我与你同在，正如从前我跟摩西同在一样。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 3:3; 约书亚记 3:17; 历代志下 29:15"> 你要吩咐抬约柜的祭司走到约旦河边，站在水中。”</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 4:1; 申命记 12:8"> 约书亚对以色列人说：“你们要来听你们的上帝耶和华的话。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 7:1; 出埃及记 33:2; 诗篇 44:2–3"> 今天你们会明白永活的上帝就在你们当中，祂必在你们面前赶走迦南人、赫人、希未人、比利洗人、革迦撒人、亚摩利人和耶布斯人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 6:5; 撒迦利亚书 4:14; 诗篇 24:1"> 看啊，天下之主的约柜要在你们前面过约旦河。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 4:2; 约书亚记 4:9; 约书亚记 4:4"> 现在，你们要从以色列的十二支派中选出十二个人来，每支派选一人。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 15:8; 诗篇 78:13; 约书亚记 3:15–16"> 当祭司抬着天下之主耶和华的约柜一踏进约旦河，往下流的河水必止住，形成一道水堤。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:44–45; 约书亚记 6:6; 哥林多前书 1:24–25"> 那时是收割的季节，河水高涨，淹没两岸。民众拔营准备过河，抬约柜的祭司走在前头。祭司的脚刚一踏进河水，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 3:13; 列王纪上 4:12; 列王纪上 7:46"> 往下流的水立刻止住了，在很远的撒拉但附近的亚当城那里涨成一道水墙。流入亚拉巴海，即盐海的水完全被截断了，民众便走到对面的耶利哥。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:22; 出埃及记 14:29; 诗篇 66:6"> 以色列人过河的时候，抬耶和华约柜的祭司站在河中间的干地上，直到所有人都从干地上过了约旦河。</span>
</div>
</div>

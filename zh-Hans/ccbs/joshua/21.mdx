## 分给利未人的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:1; 约书亚记 19:51; 约书亚记 17:4"> 利未人的众族长到迦南的示罗见祭司以利亚撒、嫩的儿子约书亚和以色列各支派的首领，说：“耶和华借着摩西曾吩咐你们把一些城邑分给我们住，并把城郊的草场给我们牧养牲畜。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 49:7; 申命记 33:8–10; 历代志上 6:54–81"> 以色列人便按照耶和华的吩咐，从他们的产业中把以下的城邑及其草场分给了利未人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 6:54–60; 约书亚记 24:33; 约书亚记 21:8–19"> 首先哥辖宗族抽了签。利未人哥辖宗族中大祭司亚伦的子孙从犹大、西缅和便雅悯支派的产业中，抽签得了十三座城。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 21:20–26; 出埃及记 6:16–25; 历代志上 6:66–70"> 哥辖宗族中其他人也从以法莲、但和玛拿西半个支派的产业中，抽签得了十座城。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:27–33; 历代志上 6:71–76; 出埃及记 6:16–17"> 革顺的子孙从以萨迦、亚设、拿弗他利和在巴珊的玛拿西半个支派的产业中，抽签得了十三座城。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:34–40; 历代志上 6:77–81; 出埃及记 6:19"> 米拉利的子孙按宗族从吕便、迦得和西布伦支派的产业中，抽签得了十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 21:3; 约书亚记 18:6; 民数记 33:54"> 以色列人照耶和华对摩西的吩咐，把这些城邑及其草场用抽签的方式分给利未人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 6:65; 约书亚记 21:13–18"> 因为利未支派哥辖宗族中亚伦的子孙抽到第一签，以色列人就从犹大和西缅两支派的产业中点名划出以下城邑分给他们：</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 6:55; 路加福音 1:39; 撒母耳记下 5:1–5"> 犹大山区的基列·亚巴及其草场，亚巴原是亚衲人的祖先，基列·亚巴就是希伯仑。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 14:13–15; 历代志上 6:55–57"> 而城周围的田地和乡村已经分给耶孚尼的儿子迦勒作产业。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:42; 约书亚记 10:29; 约书亚记 15:54"> 以色列人把避难城希伯仑分给祭司亚伦的子孙，并把立拿、</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:48; 约书亚记 15:50; 撒母耳记上 30:27–28"> 雅提珥、以实提莫、</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:49; 约书亚记 15:51; 约书亚记 12:13"> 何仑、底璧、</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 15:10; 历代志上 6:59; 约书亚记 15:55"> 亚因、淤他、伯·示麦共九座城及其草场分给了他们。这都是从犹大和西缅两支派分出来的。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 18:24–25; 约书亚记 9:3; 历代志上 6:60"> 从便雅悯支派的产业中分给他们的城有：基遍、迦巴、</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 10:30; 历代志上 6:60; 耶利米书 1:1"> 亚拿突、亚勒们四座城及其草场。</span>
<span className="v" id="v19" data-v="19"> 做祭司的亚伦子孙共分到十三座城邑及其草场。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 6:66; 约书亚记 21:5"> 利未人哥辖宗族其他子孙从以法莲支派的产业中抽签分到的城邑有：</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 20:7; 士师记 9:1; 列王纪上 12:1"> 以法莲山区的避难城示剑、基色、</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 6:68; 约书亚记 16:3; 约书亚记 18:13–14"> 基伯先和伯·和仑共四座城及其草场。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 19:44–45"> 从但支派的产业中分给他们的城邑有：伊利提基、基比顿、</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:42; 约书亚记 10:12; 历代志上 6:69"> 亚雅仑和迦特·临门四座城及其草场。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 17:11; 士师记 5:19"> 他们从玛拿西半个支派的产业中分到他纳和迦特·临门两座城及其草场。</span>
<span className="v" id="v26" data-v="26"> 以上是哥辖其他子孙所分到的十座城及其草场。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 6:71; 申命记 1:4; 约书亚记 20:8"> 以色列人分给利未支派中革顺子孙的城邑有：玛拿西半个支派中巴珊的哥兰避难城和比·施提拉两座城及其草场；</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:12; 历代志上 6:72–73"> 以萨迦支派的基善、大比拉、</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:23; 约书亚记 12:11; 约书亚记 10:3"> 耶末、隐·干宁四座城及其草场；</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 6:74–75; 约书亚记 19:25–28"> 亚设支派的米沙勒、押顿、</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 18:21; 历代志上 6:75; 士师记 1:31"> 黑甲、利合四座城及其草场；</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 6:76; 约书亚记 20:7; 约书亚记 19:37"> 拿弗他利支派的哈末·多珥、加珥坦和加利利的避难城基低斯三座城及其草场。</span>
<span className="v" id="v33" data-v="33"> 革顺人按宗族共分到十三座城邑及其草场。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 6:77; 约书亚记 19:11; 约书亚记 21:7"> 其余的利未人，就是米拉利的子孙所分到的城邑有：西布伦支派的约念、加珥他、</span>
<span className="v" id="v35" data-v="35"> 丁拿、拿哈拉四座城及其草场；</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 20:8; 申命记 4:43; 民数记 21:23"> 吕便支派的比悉、雅杂、</span>
<span className="v" id="v37" data-v="37"> 基底莫、米法押四座城及其草场；</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 32:2; 列王纪上 22:3; 历代志上 6:80"> 迦得支派的玛哈念、基列的避难城拉末、</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 16:8–9; 民数记 32:35; 民数记 32:1"> 希实本、雅谢四座城及其草场。</span>
<span className="v" id="v40" data-v="40"> 利未人中米拉利的子孙按宗族所分到的城邑共有十二座。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:1–8; 申命记 33:10; 创世记 49:7"> 利未人从以色列各支派共分到四十八座城及其草场，</span>
<span className="v" id="v42" data-v="42"> 这些城周围都有草场，城城如此。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="创世记 13:15; 诗篇 106:42–45; 出埃及记 23:27–31"> 这样，耶和华把从前起誓要赐给以色列人祖先的整个地区，都赐给了以色列人，以色列人都分到土地，住了下来。</span>
<span className="v" id="v44" data-v="44" data-xref="约书亚记 11:23; 希伯来书 4:9; 申命记 31:3–5"> 耶和华照着给他们祖先的应许，使他们四境安宁，没有仇敌能抵挡他们。耶和华将所有仇敌都交在了他们手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 8:56; 约书亚记 23:14–15; 民数记 23:19"> 耶和华给以色列人的美好应许没有一句落空，全部实现了。</span>
</div>
</div>

## 打败北方诸王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 11:10; 诗篇 2:1–4; 士师记 4:2"> 夏琐王耶宾听见这些消息，就派人去见玛顿王约巴、伸仑王、押煞王，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 12:3; 士师记 1:27; 约书亚记 17:11"> 还有北方山区、基尼烈南面的亚拉巴、西部丘陵和多珥高原的各王，</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:3; 约书亚记 18:26; 创世记 31:49"> 以及东西两面的迦南人、山区的亚摩利人、赫人、比利洗人、耶布斯人和黑门山麓米斯巴地区的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 7:12; 撒母耳记上 13:5; 创世记 32:12"> 这些王便率领自己的军队，带着许多马匹和战车倾巢出动，人数多如海边的沙。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:10–12; 启示录 16:14; 以赛亚书 8:9"> 他们在米伦河会师，一同扎营，要跟以色列人交战。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 10:8; 撒母耳记下 8:4; 士师记 20:28"> 耶和华对约书亚说：“你不要怕他们。明天这个时候，我必把他们全部交给以色列人杀灭，你要砍断他们马匹的蹄筋，烧毁他们的战车。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:9; 帖撒罗尼迦前书 5:2–3"> 于是，约书亚率领所有的军兵在米伦河边突袭敌军。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:6; 约书亚记 19:28; 撒迦利亚书 9:2"> 耶和华把敌军交在以色列人手中，以色列人打败了他们，追杀他们直到西顿大城、米斯利弗·玛音和东面的米斯巴谷，全部消灭了他们，一个没留。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 11:6; 以西结书 39:9–10"> 约书亚照耶和华的吩咐，砍断他们马匹的蹄筋，烧毁他们的战车。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 11:1; 士师记 4:2"> 然后，约书亚回师攻陷夏琐，用刀杀了夏琐王。夏琐曾经在诸国中为首。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 10:40; 申命记 20:16"> 以色列人用刀杀了城内的人，一个没留。约书亚放火烧了夏琐。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 20:16–17; 申命记 7:2; 民数记 33:50–53"> 约书亚攻占了诸王所有的城池，擒获诸王。他照耶和华的仆人摩西的吩咐，用刀杀死诸王，毁掉城池。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 30:18"> 以色列人只烧毁了夏琐，没有烧建在山丘上的其他城池。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 20:14; 民数记 31:9; 约书亚记 8:27"> 他们用刀杀掉城内所有的居民，一个没留，掳掠了城内所有的财物和牲畜。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:7; 出埃及记 34:11–13; 使徒行传 20:20"> 耶和华怎样吩咐祂的仆人摩西，摩西也怎样吩咐约书亚，约书亚都一一照办，没有遗漏任何耶和华吩咐摩西的事。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 10:41; 约书亚记 11:21; 约书亚记 12:8"> 约书亚占领了整个地区，包括山区、南地、歌珊全境、丘陵、亚拉巴和以色列山区及平原，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 7:24; 约书亚记 11:3; 约书亚记 13:5"> 从哈拉山起到西珥，直到黑门山山麓黎巴嫩山谷的巴力·迦得城。约书亚擒获了各城的王，杀死了他们。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 14:7–10; 约书亚记 11:23"> 约书亚跟这些地区的诸王争战了很久。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 9:3–27"> 除了基遍的希未人以外，其他没有一城向以色列人求和，以色列人全部攻占这些城。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:18; 申命记 20:16–17; 出埃及记 4:21"> 原来耶和华使他们的心刚硬，跟以色列人作战，好让他们遭受无情的毁灭，正如耶和华对摩西的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 9:2; 民数记 13:22–23; 约书亚记 15:13–14"> 那时，约书亚又出兵把希伯仑、底璧、亚拿伯、以色列和犹大各山区的亚衲人和他们的城邑全部毁灭。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 17:4; 历代志上 18:1; 约书亚记 15:46"> 除了在迦萨、迦特和亚实突有一些残余之外，以色列境内没有亚衲人了。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 21:44–45; 民数记 26:52–55; 约书亚记 14:1–15"> 约书亚照耶和华对摩西的指示，夺取整个地区，把土地按照支派分给以色列人作产业。于是境内国泰民安，没有战事了。</span>
</div>

## 犹大支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:55–56; 约书亚记 14:2; 民数记 33:36–37"> 犹大支派按宗族抽签分到的土地，南到以东的边界，到最南端的荀旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 14:3; 以西结书 47:8; 以赛亚书 11:15"> 南面的边界始于盐海南端的海湾，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 34:4; 士师记 1:36; 民数记 20:1"> 沿亚克拉滨山坡南面，经荀，北上至加低斯·巴尼亚南面，经过希斯仑到亚达珥，再绕到甲加，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 34:5; 约书亚记 13:3; 出埃及记 23:31"> 经过押们、顺着埃及小河直到地中海。这是犹大支派的南部边界。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 34:12; 约书亚记 18:15–19; 民数记 34:10"> 东面以盐海到约旦河口为边界。<br />北界从约旦河口的海湾开始，</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 18:17; 约书亚记 18:19–21"> 到伯·曷拉，经过伯·亚拉巴北面，直到吕便的儿子波罕所立的大石；</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 1:9; 撒母耳记下 17:17; 约书亚记 7:26"> 从亚割谷往北到底璧，到谷南亚都冥隘口对面的吉甲，经隐·示麦泉，直到隐·罗结；</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:16; 约书亚记 15:63; 约书亚记 18:28"> 然后再沿着欣嫩子谷而上，直到耶布斯，即耶路撒冷的南面，再到欣嫩谷西面、利乏音谷北端的山顶；</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 13:6; 约书亚记 18:15; 士师记 18:12"> 从山顶到尼弗多亚泉，到以弗仑山的各城，直到巴拉，即基列·耶琳；</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 14:1; 士师记 14:5; 创世记 38:12–13"> 从巴拉向西绕到西珥山，到耶琳山北坡，即基撒仑，到伯·示麦，经亭拿，</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:45; 列王纪下 1:2–3; 撒母耳记上 5:10"> 再到以革伦北坡，转向施基仑，经巴拉山和雅比聂，直到地中海。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 34:6–7; 约书亚记 15:47; 以西结书 47:20"> 西面的边界是地中海沿岸。以上是犹大人根据宗族所得地业的四界。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 13:30; 申命记 1:34–36; 民数记 14:23–24"> 约书亚又照耶和华的吩咐，在犹大支派所分到的土地之中划出基列·亚巴，即希伯仑，分给耶孚尼的儿子迦勒。亚巴是亚衲人的祖先。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:20; 士师记 1:10; 民数记 13:22–23"> 迦勒赶走了住在那里的亚衲族的三个族长，即示筛、亚希幔和挞买，</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:38; 约书亚记 10:3; 士师记 1:11–13"> 再从那里出兵攻打底璧，底璧从前叫基列·西弗。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 1:12–13; 士师记 1:6"> 迦勒说：“谁攻取基列·西弗，我就把女儿押撒嫁给他。”</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 3:9; 士师记 1:13; 约书亚记 14:6"> 迦勒的弟弟基纳斯的儿子俄陀聂攻取了那城，迦勒便把女儿押撒嫁给他。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 24:64; 撒母耳记上 25:23"> 押撒出嫁的时候，劝丈夫向她父亲要一块田。她刚下驴，迦勒便问她：“你想要什么？”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 1:14–15; 撒母耳记上 25:27; 申命记 33:7"> 押撒答道：“求你赐福给我，你既然把南地赐给我，求你也把水泉赐给我吧。”迦勒就把上泉和下泉都给了她。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 49:8–12; 申命记 33:7"> 以下是犹大支派按宗族所得的产业：</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 35:21; 尼希米记 11:25"> 在最南面靠近以东的城邑有甲薛、以得、雅姑珥、</span>
<span className="v" id="v22" data-v="22"> 基拿、底摩拿、亚大达、</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 12:22; 民数记 33:37; 申命记 1:19"> 基低斯、夏琐、以提楠、</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 23:14; 撒母耳记上 23:24; 撒母耳记上 23:19"> 西弗、提链、比亚绿、</span>
<span className="v" id="v25" data-v="25"> 夏琐·哈大他、加略·希斯仑，即夏琐、</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 4:28"> 亚曼、示玛、摩拉大、</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 11:26"> 哈萨·迦大、黑实门、伯·帕列、</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 26:33; 历代志上 4:28; 创世记 21:31–33"> 哈萨·书亚、别示巴、比斯约他、</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 15:9–11; 约书亚记 19:3; 历代志上 4:29"> 巴拉、以因、以森、</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:4; 民数记 14:45; 申命记 1:44"> 伊勒多腊、基失、何珥玛、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 27:6; 撒母耳记上 30:1; 历代志上 12:1"> 洗革拉、麦玛拿、三撒拿、</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 34:11; 尼希米记 11:29"> 利巴勿、实忻、亚因和临门，共二十九座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士师记 13:25; 士师记 16:31; 民数记 13:23"> 在丘陵地带有以实陶、琐拉、亚实拿、</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 12:17; 约书亚记 15:53"> 撒挪亚、隐·干宁、他普亚、以楠、</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 17:1; 撒母耳记上 22:1; 约书亚记 10:3"> 耶末、亚杜兰、梭哥、亚西加、</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 17:52"> 沙拉音、亚底他音、基底拉和基底罗他音，共十四座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 还有洗楠、哈大沙、麦大·迦得、</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪下 14:7; 士师记 20:1; 撒母耳记上 10:17"> 底连、米斯巴、约帖、</span>
<span className="v" id="v39" data-v="39" data-xref="约书亚记 10:3; 列王纪下 22:1; 约书亚记 10:31–32"> 拉吉、波斯加、伊矶伦、</span>
<span className="v" id="v40" data-v="40"> 迦本、拉幔、基提利、</span>
<span className="v" id="v41" data-v="41" data-xref="约书亚记 10:21; 约书亚记 12:16; 约书亚记 10:10"> 基低罗、伯·大衮、拿玛、玛基大，共十六座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:29; 列王纪下 8:22; 约书亚记 19:7"> 还有立拿、以帖、亚珊、</span>
<span className="v" id="v43" data-v="43"> 益弗他、亚实拿、尼悉、</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 38:5; 弥迦书 1:14–15; 撒母耳记上 23:1–14"> 基伊拉、亚革悉、玛利沙，共九座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约书亚记 13:3; 阿摩司书 1:8; 撒母耳记上 6:17"> 还有以革伦及其附近的城邑和乡村。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="历代志下 26:6; 阿摩司书 1:8; 撒母耳记上 5:1"> 还有以革伦到地中海一带所有靠近亚实突的城邑和乡村，</span>
<span className="v" id="v47" data-v="47" data-xref="约书亚记 15:4; 出埃及记 23:31; 阿摩司书 1:6–7"> 亚实突及其附近的城邑和乡村，迦萨及其附近的城邑和乡村，直到埃及小河和地中海沿岸。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="约书亚记 21:14"> 在山区有沙密、雅提珥、梭哥、</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 15:15; 士师记 1:11"> 达拿、基列·萨拿，即底璧、</span>
<span className="v" id="v50" data-v="50"> 亚拿伯、以实提莫、亚念、</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 11:16; 约书亚记 10:41; 撒母耳记下 15:12"> 歌珊、何仑、基罗，共十一座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="以赛亚书 21:11"> 还有亚拉、度玛、以珊、</span>
<span className="v" id="v53" data-v="53"> 雅农、伯·他普亚、亚非加、</span>
<span className="v" id="v54" data-v="54" data-xref="约书亚记 15:13; 创世记 23:2; 约书亚记 14:15"> 宏他、基列·亚巴，即希伯仑、洗珥，共九座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 25:2; 约书亚记 15:24; 撒母耳记上 23:25"> 还有玛云、迦密、西弗、淤他、</span>
<span className="v" id="v56" data-v="56"> 耶斯列、约甸、撒挪亚、</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 15:10; 创世记 38:12; 耶利米书 14:1"> 该隐、基比亚、亭拿，共十座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="历代志上 4:39"> 还有哈忽、伯·夙、基突、</span>
<span className="v" id="v59" data-v="59"> 玛腊、伯·亚诺、伊勒提君，共六座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="约书亚记 18:14; 撒母耳记上 7:1"> 还有基列·巴力，即基列·耶琳、拉巴两座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="约书亚记 15:6; 约书亚记 18:18"> 在旷野有伯·亚拉巴、密丁、西迦迦、</span>
<span className="v" id="v62" data-v="62" data-xref="撒母耳记上 23:29; 历代志下 20:2"> 匿珊、盐城、隐·基底，共六座城及其附近的乡村。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="士师记 1:21; 士师记 1:8; 撒母耳记下 5:6–9"> 犹大人没能把住在耶路撒冷的耶布斯人赶出去，他们至今仍然跟犹大人一同居住。</span>
</div>

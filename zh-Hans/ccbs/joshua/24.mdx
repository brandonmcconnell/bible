## 重申耶和华的约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:2; 撒母耳记上 10:19; 创世记 33:18–19"> 约书亚在示剑招聚以色列各支派，他召来以色列的长老、族长、审判官和官长。他们一同站在上帝面前。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:15; 以西结书 16:3; 创世记 31:30"> 约书亚对全体民众说：“以色列的上帝耶和华这样说，‘从前你们的祖先，包括亚伯拉罕和拿鹤二人的父亲他拉，住在幼发拉底河那边拜其他神明。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1–4; 创世记 21:2–3; 使徒行传 7:2–3"> 我把你们的祖先亚伯拉罕从幼发拉底河那边带出来，领他走遍迦南，使他人丁兴旺。我把以撒赐给他，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 36:8; 申命记 2:5; 创世记 25:24–26"> 把雅各和以扫赐给以撒，把西珥山赐给以扫作产业，雅各和他的子孙则去了埃及。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:10; 出埃及记 7:1–12; 诗篇 105:26–36"> 后来，我差遣了摩西和亚伦，并用灾祸攻击埃及人，把你们领出来。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 7:36; 希伯来书 11:29; 以赛亚书 63:12–13"> 我带你们的祖先出埃及，到达红海，埃及人带领战车骑兵追了上来。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:34; 出埃及记 14:10; 出埃及记 14:20"> 你们的祖先大声呼求我，我就降下黑暗，把你们和埃及人分开，又用海水淹没埃及人。你们亲眼见过我在埃及的作为。后来，你们在旷野住了很长时间。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 21:21–35; 诗篇 135:10–11; 尼希米记 9:22"> 我领你们来到约旦河东边亚摩利人居住的地方。他们跟你们争战，我把他们交在你们手中，使你们占领他们的土地作自己的产业。我把他们从你们面前全部消灭。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 11:25; 弥迦书 6:5; 民数记 22:2"> 那时，摩押王西拨的儿子巴勒起兵攻打你们，并派人去召比珥的儿子巴兰来咒诅你们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 23:5; 民数记 24:5–10; 以赛亚书 54:17"> 但我不听巴兰的话，反而使他为你们连连祝福。这样，我从巴勒手中救了你们。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 4:10–12; 约书亚记 3:14–17; 诗篇 114:5"> 你们过了约旦河来到耶利哥。耶利哥人、亚摩利人、比利洗人、迦南人、赫人、革迦撒人、希未人和耶布斯人都跟你们交战，但我把他们交在你们手中。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:20; 出埃及记 23:28; 诗篇 44:3–6"> 我差黄蜂飞在你们前面，把亚摩利的两个王从你们面前赶走，没有动用你们一刀一弓。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 6:10–12; 申命记 8:7; 约书亚记 21:45"> 你们没有开垦土地，也没有建造城邑，但我赐给你们土地和城邑，使你们住在其中，享用别人栽种的葡萄园和橄榄园的果子。’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 12:24; 申命记 10:12; 创世记 35:2"> “所以，你们要敬畏耶和华，诚心诚意地事奉祂，弃绝你们祖先在幼发拉底河那边和在埃及所拜的神明，专心事奉耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:21; 约翰福音 6:67–68; 路得记 1:15–16"> 你们如果不愿事奉耶和华，今天就选择你们的神明吧，或大河那边你们祖先事奉的神明，或你们这里亚摩利人的神明。至于我和我全家，我们必事奉耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 10:38–39; 撒母耳记上 12:23; 罗马书 6:2"> 民众答道：“我们决不背弃耶和华去事奉其他神明，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 19:4; 以赛亚书 63:7–14; 以赛亚书 46:4"> 因为我们的上帝耶和华曾领我们和我们的祖先脱离埃及人的奴役，在我们眼前行大神迹，一路保护我们安然经过列邦。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 4:2; 出埃及记 10:2; 诗篇 116:16"> 耶和华把这地方的亚摩利人等外族人从我们面前赶走了，我们必事奉祂，因为祂是我们的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 5:16; 出埃及记 23:21; 诗篇 99:9"> 约书亚说：“你们不能事奉耶和华，祂是圣洁的上帝，祂痛恨不贞，必不赦免你们的过犯和罪恶。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 以西结书 18:24; 历代志上 28:9"> 如果你们背弃耶和华，去拜外族的神明，祂虽然恩待了你们，也必转而降祸给你们，毁灭你们。”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:19; 以赛亚书 44:5; 申命记 5:27–28"> 民众答道：“不，我们一定要事奉耶和华。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 119:173; 诗篇 119:11; 约伯记 15:6"> 约书亚说：“现在你们自己作证，你们已选择事奉耶和华。”民众答道：“我们愿意自己作证。”</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:16–18; 约书亚记 24:14; 希伯来书 12:28–29"> 约书亚说：“这样，你们现在就要弃绝你们中间的外族神明，专心归向以色列的上帝耶和华。”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 24:7; 出埃及记 24:3; 申命记 5:27–29"> 民众答道：“我们必事奉我们的上帝耶和华，听从祂的话。”</span>
<span className="v" id="v25" data-v="25" data-xref="尼希米记 9:38; 历代志下 23:16; 出埃及记 15:25"> 当天约书亚与民众立约，在示剑为他们订立律例和典章。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 9:6; 创世记 35:4; 约书亚记 4:20–24"> 约书亚把这些话都写在上帝的律法书上，又把一块大石头竖立在耶和华圣所旁边的橡树下。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 约书亚记 22:34; 约书亚记 22:27–28"> 然后，他对民众说：“看啊，这块石头可以为我们作证，它听到了耶和华所吩咐我们的话。如果你们背弃上帝，它必作证。”</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 2:6"> 于是，约书亚命民众各自返回自己的地方。</span>
</div>
</div>

## 约书亚去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 2:8; 提摩太后书 4:7–8; 申命记 34:5"> 后来，耶和华的仆人、嫩的儿子约书亚去世了，享年一百一十岁。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:50; 士师记 2:9; 撒母耳记下 23:30"> 以色列人把他葬在他的土地上，就是在迦实山北边、以法莲山区的亭拿·西拉。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士师记 2:7; 申命记 31:13; 申命记 11:2"> 约书亚在世的时候，以色列人都事奉耶和华。他死后，在那些经历过耶和华奇妙作为的长老还健在期间，以色列人仍事奉耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 50:25; 创世记 33:19; 出埃及记 13:19"> 以色列人把从埃及带出来的约瑟的骸骨葬在示剑，在从前雅各用一百块银子向哈抹的子孙买的那块地里。哈抹是示剑的父亲。后来那块地成了约瑟子孙的产业。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 22:13; 出埃及记 6:25; 以赛亚书 57:1–2"> 亚伦的儿子以利亚撒也死了，他们把他葬在他儿子非尼哈分到的以法莲山区的基比亚。</span>
</div>
</div>

</div>

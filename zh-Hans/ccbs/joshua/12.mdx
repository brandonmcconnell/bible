## 被击败的诸王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 3:8–9; 士师记 11:18; 约书亚记 1:15"> 以色列人在约旦河东岸杀死了两个王，占据了他们的领土：自亚嫩谷直到黑门山，包括东面的整个亚拉巴。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 32:22; 士师记 11:22; 诗篇 136:19–20"> 这两个王一个是住在希实本的亚摩利王西宏。他统辖的地区从亚嫩谷旁的亚罗珥，包括山谷中部和基列的一半，直到亚扪人边境的雅博河。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 3:17; 约书亚记 13:20; 约书亚记 11:2"> 他的领土还包括约旦河谷东部：从加利利湖至亚拉巴海，也就是盐海，到伯·耶施末，直到毗斯迦的山麓。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:4; 申命记 3:10–11; 约书亚记 13:12"> 另一个王是巴珊王噩，他原是利乏音的遗民，住在亚斯她录和以得来。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:14; 撒母耳记上 27:8; 约书亚记 13:11"> 他所统辖的地区包括黑门山、撒迦、整个巴珊，直到基述人和玛迦人的边境，还包括基列的另一半，直到希实本王西宏的国界。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 32:33; 民数记 32:29; 路加福音 22:29–42"> 耶和华的仆人摩西带领以色列人征服了这两个王，并把他们的土地分给吕便支派、迦得支派和玛拿西半个支派的人作产业。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 11:17; 约书亚记 11:23–1; 约书亚记 1:3–4"> 约书亚带领以色列人征服了约旦河西的诸王，占领的土地包括从黎巴嫩谷地的巴力·迦得直到西珥的哈拉山。约书亚按以色列的支派把这些土地分给以色列人。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 11:16; 约书亚记 10:40; 约书亚记 9:1"> 那里有山区、丘陵、河谷、山坡、旷野和南地，就是赫人、亚摩利人、迦南人、比利洗人、希未人、耶布斯人住的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 8:29–35; 约书亚记 6:2–21; 约书亚记 8:1"> 这些王是耶利哥王、伯特利附近的艾王、</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 10:23; 约书亚记 10:36–37; 约书亚记 10:3"> 耶路撒冷王、希伯仑王、</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 10:31–32; 约书亚记 10:3–23"> 耶末王、拉吉王、</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 10:33; 约书亚记 15:39; 约书亚记 10:3"> 伊矶伦王、基色王、</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 10:38; 约书亚记 10:3; 约书亚记 15:36"> 底璧王、基德王、</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 21:1; 民数记 14:45; 民数记 21:3"> 何珥玛王、亚拉得王、</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:29–30; 撒母耳记上 22:1"> 立拿王、亚杜兰王、</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 10:28; 士师记 1:22; 约书亚记 8:17"> 玛基大王、伯特利王、</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 4:10; 约书亚记 15:34; 约书亚记 19:13"> 他普亚王、希弗王、</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 19:30; 以赛亚书 33:9; 约书亚记 13:4"> 亚弗王、拉沙仑王、</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 11:1; 士师记 4:2; 约书亚记 11:10–11"> 玛顿王、夏琐王、</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 11:1; 约书亚记 19:15; 约书亚记 19:25"> 伸仑·米仑王、押煞王、</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 17:11; 列王纪下 23:29–30; 士师记 5:19"> 他纳王、米吉多王、</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 19:37; 约书亚记 21:32; 约书亚记 15:23"> 基低斯王、迦密附近的约念王、</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 11:2; 创世记 14:1–2; 约书亚记 4:19"> 多珥山上的多珥王、吉甲的戈印王、</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 15:14; 列王纪上 16:23; 申命记 7:24"> 得撒王，共三十一个王。</span>

## 主对约书亚的吩咐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 34:9; 申命记 1:38; 申命记 31:23"> 耶和华的仆人摩西死了以后，耶和华对摩西的助手——嫩的儿子约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 3:28; 申命记 31:7; 民数记 27:16–21"> “我的仆人摩西已经死了，你和全体以色列人现在要准备渡过约旦河，到我要赐给你们的地方去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 11:24; 约书亚记 14:9; 提多书 1:2"> 我已把你们脚掌将踏之地都赐给了你们，正如我对摩西的应许。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 23:31; 创世记 15:18–21; 申命记 3:25"> 从南部的旷野直到北部的黎巴嫩，从东部的幼发拉底大河直到西部的地中海，包括赫人居住的全境，都将是你们的领土。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:31; 申命记 31:6–8; 马太福音 28:20"> 在你有生之年，没有人能够抵挡你。过去我怎样与摩西同在，也必照样与你同在，我必不离开你，也不丢弃你。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 10:19; 以弗所书 6:10; 约书亚记 1:9"> 你要刚强勇敢，因为你要带领这些人占领我起誓要赐给他们祖先的土地。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 22:13; 申命记 5:32; 约书亚记 1:8"> 你只要刚强勇敢，谨遵我仆人摩西所吩咐你的一切律法，毫不偏离，就可以无往不利。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 119:15; 诗篇 19:14; 歌罗西书 3:16"> 你要常常诵读这律法书，昼夜不断地思想，以便谨遵律法书上的一切指示。这样，你必亨通、顺利。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 28:15; 耶利米书 1:7–8; 约书亚记 1:6–7"> 我再次吩咐你，要刚强勇敢！不要惊慌害怕，因为你无论走到哪里，你的上帝耶和华必与你同在。”</span>
<span className="v" id="v10" data-v="10"> 于是，约书亚吩咐民众的首领说：</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 9:1; 何西阿书 6:2; 列王纪下 20:5"> “你们要走遍全营，吩咐民众预备好食物。因为三天之内，你们就要过约旦河，去占领你们的上帝耶和华赐给你们的土地。”</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 32:20–22"> 约书亚又对吕便支派、迦得支派和玛拿西半个支派的人说：</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:20–28; 申命记 3:18–20; 约书亚记 22:1–4"> “你们要牢记耶和华的仆人摩西吩咐你们的话，他说你们的上帝耶和华要把这片土地赐给你们，让你们安居。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 20:8; 出埃及记 13:18; 启示录 17:4"> 你们的妻子儿女和牲畜可以留在约旦河东岸摩西分给你们的土地上，但你们当中所有的勇士要带着兵器先过约旦河，帮助你们的弟兄。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 2:4; 民数记 32:17–22; 哥林多前书 12:26"> 要等到你们的上帝耶和华使你们的弟兄像你们一样得到祂所赐的土地，安居以后，你们才可以回到约旦河东日出之地，在耶和华的仆人摩西分给你们的土地上定居。”</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 3:1; 申命记 5:27; 彼得前书 2:13–15"> 他们回答约书亚说：“凡你命令我们的，我们一定遵行。无论你派我们去哪里，我们一定去。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 1:5; 列王纪上 1:37; 约书亚记 1:9"> 我们在一切事上怎样服从摩西，也必照样服从你，唯愿你的上帝耶和华与你同在，像与摩西同在一样。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 6:10; 约书亚记 1:9; 以斯拉记 10:4"> 任何人违抗你的命令，不悉数遵行你的吩咐，都要被处死。你要刚强勇敢！”</span>

## 耶利哥城塌陷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 2:24; 约书亚记 2:9–14; 诗篇 127:1"> 因为害怕以色列人，耶利哥城门紧闭，无人出入。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:24; 约书亚记 8:1; 约书亚记 2:24"> 耶和华对约书亚说：“看啊，我已经把耶利哥及其王和英勇的战士都交在你手中了。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:7; 民数记 14:9; 约书亚记 6:7"> 所有军队要每天绕城一圈，连续六天，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 20:17; 启示录 16:1; 列王纪上 18:43"> 让七个祭司拿着七个羊角号走在约柜前面。到了第七天，你们要绕城七圈，祭司要吹响号角。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 10:4–5; 希伯来书 11:30; 出埃及记 19:19"> 当你们听到号角长鸣时，所有人都要高声呐喊，城墙就会坍塌，众人便可以直冲上去。”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:1; 申命记 20:2–4; 约书亚记 3:3"> 嫩的儿子约书亚便召来祭司，对他们说：“你们抬起约柜，派七位祭司拿着七个羊角号走在耶和华的约柜前面。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:13; 约书亚记 6:3; 约书亚记 1:14"> 他又对民众说：“你们要前去绕着城墙走，军队要走在耶和华的约柜前面。”</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 32:20; 约书亚记 6:3–4"> 约书亚吩咐完毕，七个祭司便在耶和华面前拿着羊角号边走边吹，耶和华的约柜就跟在他们后面，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 6:13; 民数记 10:25; 以赛亚书 58:8"> 军队走在吹号的祭司前面，殿后军队跟在约柜后面。祭司一路上吹着号角。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:49; 马太福音 12:19; 以赛亚书 42:2"> 约书亚吩咐民众：“我哪天叫你们呐喊，你们再呐喊。在此之前，不许作声，一句话也不许说。”</span>
<span className="v" id="v11" data-v="11"> 这样，约书亚让人抬着耶和华的约柜绕城一圈，然后众人各自回营过夜。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 3:1; 希伯来书 11:7–8; 创世记 22:3"> 第二天，约书亚一早起来，祭司又抬起耶和华的约柜。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:9; 马太福音 24:13; 历代志上 15:26"> 七个祭司拿着七个羊角号走在耶和华的约柜前面，一边走一边吹号。军队走在祭司前面，殿后军队跟在耶和华的约柜后面，伴随着持续不断的号角声。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 6:15; 约书亚记 6:11; 约书亚记 6:3"> 这一天他们又绕城一圈，然后各自回营。六天都是这样。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:147; 彼得后书 1:19; 马太福音 28:1"> 第七天黎明时分，他们起来照样绕城，只是这一天他们绕城七次。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 13:15; 约书亚记 6:5; 历代志下 20:22–23"> 绕到第七次，祭司吹响了号角，约书亚吩咐民众说：“呐喊吧！因为耶和华已经将这城交给你们了。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 20:17; 雅各书 2:25; 弥迦书 4:13"> 要把这座城和城里所有的东西毁灭，作为献给耶和华之物。只有妓女喇合和她家中所有的人可以活命，因为她曾把我们派去的探子隐藏起来。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 5:21; 以弗所书 5:11; 约书亚记 7:1"> 你们要小心，不可私拿任何应当毁灭的东西，免得你们自取灭亡，并使以色列全营遭受灭顶之灾。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 26:20; 马太福音 27:6; 马可福音 12:41"> 所有金银和铜铁器皿都是耶和华的圣物，要放进耶和华的库房。”</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:30; 哥林多后书 10:4–5; 约书亚记 6:5"> 于是，民众呐喊，号角响起，当民众伴随着号角声高声呐喊时，城墙坍塌了。民众便一拥而上，占领了耶利哥城，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 137:8–9; 耶利米书 48:18; 约书亚记 11:14"> 用刀杀了城里所有的男女老少、牛羊和驴。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:31; 约书亚记 6:17; 以西结书 17:18–19"> 约书亚对那两个探子说：“你们到那个妓女家里，照着你们向她起过的誓，把她和她的家人都带出来。”</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:7; 创世记 18:24; 使徒行传 27:24"> 于是，那两个年轻探子便进去，把喇合和她的父母、兄弟及所有的亲人都带出来，安置在以色列人的营外。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 8:28; 启示录 17:16; 列王纪下 25:9"> 以色列人烧毁全城和城内的一切，只把金银和铜铁器皿放在耶和华的库房里。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 马太福音 1:5; 士师记 1:24–25"> 约书亚因为妓女喇合把两个派到耶利哥的探子隐藏起来，就饶了她和她一家人的性命。他们至今仍住在以色列人当中。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 16:34; 使徒行传 19:13; 民数记 5:19–21"> 之后，约书亚起誓说：<br /><span className="pl pl-1">“重建耶利哥城的人必定在耶和华面前受咒诅，</span><br /><span className="pl pl-1">他立地基的时候必死长子，</span><br /><span className="pl pl-1">建城门的时候必丧幼子。”</span></span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 9:3; 约书亚记 1:5; 马太福音 28:20"> 耶和华与约书亚同在，他的声名传遍整个地方。</span>

## 太阳停止

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:21; 希伯来书 7:1; 约书亚记 8:2"> 耶路撒冷王亚多尼·洗德听说约书亚夺取并毁灭了艾城，像对付耶利哥和耶利哥王一样对付艾城和艾城的王，又听说基遍人已经跟以色列人缔结盟约，住在他们中间，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 11:25; 约书亚记 2:24; 出埃及记 15:14–16"> 便大为惊恐。因为基遍是一座大城，宏伟得像座都城，比艾城更大，城中的人都骁勇善战。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:9; 弥迦书 1:13; 约书亚记 10:1"> 耶路撒冷王亚多尼·洗德便派遣使者去见希伯仑王何咸、耶末王毗兰、拉吉王雅非亚和伊矶伦王底璧，说：</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:15; 约书亚记 10:1; 以赛亚书 8:9–10"> “求你们上来帮助我攻打基遍，因为这城已经与约书亚和以色列人缔结盟约。”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:9–10; 创世记 15:16; 约书亚记 10:6"> 于是，五位亚摩利王，就是耶路撒冷王、希伯仑王、耶末王、拉吉王和伊矶伦王，便联合起来，率领他们所有的军队在基遍附近扎营，攻打基遍。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 9:6; 约书亚记 5:10; 申命记 1:15"> 基遍人派人去吉甲告诉约书亚说：“住在山区的亚摩利众王正联合起来攻打我们，求你赶快来救我们！不要不顾你的仆人。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 8:1; 以赛亚书 8:12; 以赛亚书 8:14"> 于是，约书亚便率领全军，包括所有精兵，从吉甲上去。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 8:31; 申命记 3:2; 诗篇 27:1–2"> 耶和华对约书亚说：“不要害怕，我已经把他们交在你手中，他们没有一人能抵挡你。”</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 9:10; 提摩太后书 2:3; 箴言 24:11–12"> 约书亚从吉甲出发，连夜赶路，突袭敌人。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:14; 约书亚记 16:3; 约书亚记 16:5"> 耶和华使亚摩利联军阵脚大乱，以色列人就在基遍大败敌军，在去伯·和仑的上坡路上追杀他们，一直追到亚西加和玛基大。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:2; 士师记 5:20; 诗篇 18:12–14"> 敌人在从伯·和仑到亚西加的下坡路上逃窜的时候，耶和华降下大冰雹，被冰雹砸死的人比以色列人用刀杀死的还要多。</span>
<span className="v" id="v12" data-v="12" data-xref="哈巴谷书 3:11; 以赛亚书 38:8; 以赛亚书 60:20"> 耶和华将亚摩利人交在以色列人手中，那天约书亚当众向耶和华祷告：<br /><span className="pl pl-1">“太阳啊，停在基遍！</span><br /><span className="pl pl-1">月亮啊，停在亚雅仑谷！”</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 3:11; 以赛亚书 38:8; 约书亚记 10:14"> <span className="pl pl-1">果然太阳停住了，</span><br /><span className="pl pl-1">月亮也不动了，</span><br /><span className="pl pl-1">直到以色列人杀败敌人。</span>《雅煞珥书》记载了这事。约有一天的时间，太阳停留在天空，没有西沉。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:30; 出埃及记 14:14; 约书亚记 10:42"> 耶和华这样垂听一个人的祈求是空前绝后的，这是因为耶和华要为以色列争战。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:43; 约书亚记 10:6"> 后来，约书亚率领以色列军返回了吉甲的营地。</span>
</div>
</div>

## 亚摩利五王被杀

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 24:8; 阿摩司书 9:2; 诗篇 139:7–10"> 那五王逃进玛基大的山洞里，躲藏起来。</span>
<span className="v" id="v17" data-v="17"> 有人告诉约书亚那五个王藏在玛基大的山洞里，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:66; 约伯记 21:30; 阿摩司书 9:1"> 约书亚便下令说：“滚几块大石头堵住洞口，派人看守。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:37–41; 耶利米书 8:14; 以赛亚书 9:14–15"> 你们不可停下来，要继续追杀敌人，不要让他们逃回城，你们的上帝耶和华已经把他们交在你们手中了。”</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 8:24; 撒母耳记下 20:6; 约书亚记 10:10"> 约书亚和以色列人把敌人杀得大败，几乎全军覆没，一些残余都逃进了坚固的城垒。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 11:7; 以赛亚书 54:17; 以赛亚书 57:4"> 以色列人都安然无恙地回到约书亚驻扎的玛基大营。再也没有人敢威胁以色列人了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 15:32"> 约书亚说：“打开洞口，把里面的五个王押出来见我。”</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 10:1; 约书亚记 10:5; 约书亚记 10:3"> 众人便把耶路撒冷王、希伯仑王、耶末王、拉吉王、伊矶伦王从洞里押出来，带到约书亚面前。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 4:3; 罗马书 16:20; 启示录 2:26–27"> 约书亚召来全体以色列人，然后对那些跟他一起出征的将领说：“你们上前来，用脚踏在这些王的脖子上。”各将领便照着约书亚的吩咐做了。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 1:10; 约书亚记 1:9; 以弗所书 6:10"> 约书亚对他们说：“你们不要惊慌害怕，要刚强勇敢，因为耶和华要使你们攻打的所有仇敌都落此下场。”</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 8:29; 撒母耳记下 21:9; 马太福音 27:25"> 随后约书亚将这五个王杀死，把尸体分别挂在五棵树上，直到傍晚。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:29; 申命记 21:22–23; 约书亚记 7:26"> 日落时，约书亚才下令把尸体放下，扔在他们先前躲藏的山洞里，用大石头堵住洞口，石头至今还在那里。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:21; 申命记 7:16; 申命记 20:16–17"> 约书亚在当天占领了玛基大，把玛基大王和所有的居民都用刀杀了，一个没留。他对待玛基大王跟以前对待耶利哥王一样。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 21:13; 约书亚记 15:42; 耶利米书 52:1"> 约书亚和以色列军又从玛基大出发，去攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和华将立拿城和立拿王交在以色列人手中，他们用刀杀了全城的人，一个没留。他们对待立拿王跟以前对待耶利哥王一样。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:3; 约书亚记 12:11; 约书亚记 10:5"> 约书亚和以色列军从立拿前往拉吉，他们在城外扎营，攻打拉吉。</span>
<span className="v" id="v32" data-v="32"> 耶和华将拉吉交在以色列人手中，第二天约书亚便攻占了拉吉，用刀杀了全城的人，就像在立拿所行的一样。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 16:10; 士师记 1:29; 约书亚记 16:3"> 基色王何兰前来支持拉吉，结果也被约书亚杀得一个不剩。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 10:3; 约书亚记 12:12; 约书亚记 15:39"> 约书亚又率领以色列全军从拉吉前往伊矶伦，在城外扎营，攻打伊矶伦。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 26:44; 约书亚记 10:37; 约伯记 19:10"> 他们当天就攻陷该城，用刀杀了城内所有的人，就像在拉吉所行的一样。</span>
<span className="v" id="v36" data-v="36" data-xref="士师记 1:10; 约书亚记 15:13; 约书亚记 14:13–14"> 约书亚和全体以色列人又从伊矶伦去攻打希伯仑。</span>
<span className="v" id="v37" data-v="37"> 他们攻陷该城及其附属城邑，用刀杀了希伯仑王和城邑中的居民，一个没留，就像在伊矶伦所行的一样。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 15:15; 约书亚记 12:13; 约书亚记 15:49"> 然后，约书亚和全体以色列人再回兵攻打底璧，</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亚书 1:18; 约书亚记 11:8; 申命记 3:3"> 攻取了该城及其附属城邑，擒获底璧王，用刀杀了城中所有的人，一个没留，就像对待希伯仑、立拿和立拿王一样。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 7:2–16; 出埃及记 23:31–33; 约书亚记 8:27"> 这样，约书亚征服了整个地区，包括山区、南地、丘陵和山坡及那里的众王。他按照以色列的上帝耶和华的吩咐，消灭了一切有生命气息的，一个没留。</span>
<span className="v" id="v41" data-v="41" data-xref="约书亚记 11:16; 约书亚记 15:51; 申命记 9:23"> 约书亚征服了各地，从加低斯·巴尼亚到迦萨，歌珊全境，直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:14; 诗篇 46:7; 诗篇 80:3"> 约书亚能一鼓作气杀败诸王，征服他们的土地，都是因为有以色列的上帝耶和华为以色列人争战。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 10:15; 约书亚记 4:19; 撒母耳记上 11:14"> 之后，约书亚率领以色列人回到吉甲的营地。</span>
</div>

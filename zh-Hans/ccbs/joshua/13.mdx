## 尚未攻取之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:10; 申命记 31:3; 约书亚记 24:29"> 约书亚年事已高，耶和华对他说：“你年纪大了，但还有许多地方有待征服，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 13:11; 撒母耳记上 27:8; 约珥书 3:4"> 就是非利士人和基述人的全境，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 2:23; 士师记 3:3; 耶利米书 2:18"> 即从埃及东面的西曷河直到北面以革伦的边境，这一带都算是迦南，是统治迦萨人、亚实突人、亚实基伦人、迦特人、以革伦人的五个非利士王的地方；南方亚卫人的地方；</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 19:30; 撒母耳记上 4:1; 士师记 1:34–36"> 整个迦南人的地方，从西顿人的米亚拉直到亚摩利人边境的亚弗；</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 5:18; 约书亚记 12:7; 诗篇 83:7"> 迦巴勒人的地方；东部从黑门山山麓的巴力·迦得直到哈马口的整个黎巴嫩。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 11:8; 约书亚记 23:13; 士师记 2:21–23"> 我必为以色列人赶走从黎巴嫩到米斯利弗·玛音一带山区的所有西顿人。你只管照我的吩咐，把这些土地分给以色列人作产业，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 26:53–56; 民数记 33:54; 以西结书 48:23–29"> 分给其他九个支派和玛拿西半个支派作产业。”</span>
</div>
</div>

## 约旦河东土地的分配

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 12:6; 申命记 3:12–17; 约书亚记 22:4"> 玛拿西半个支派和吕便、迦得两支派已经得到耶和华的仆人摩西在约旦河东分给他们的产业：</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 13:16; 民数记 21:30; 约书亚记 12:2"> 从亚嫩谷旁的亚罗珥起，包括谷中的城，直到底本的整个米底巴平原，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–26"> 以及希实本的亚摩利王西宏统治的各城，直到亚扪的边境。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 2:23; 约书亚记 12:2–5; 申命记 4:47–48"> 此外，还包括基列、基述人和玛迦人的疆域、整个黑门山和直到撒迦的整个巴珊地，</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 12:4; 约书亚记 14:3–4; 民数记 21:23–35"> 以及巴珊王噩的国土。噩曾经在亚斯她录和以得来做王，是仅存的利乏音人。摩西打败了这些人，赶走了他们。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:12–13; 约书亚记 13:11; 民数记 33:55"> 以色列人却没有赶走基述人和玛迦人，他们到今天还住在以色列人当中。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 18:20–24; 约书亚记 14:3–4; 申命记 18:1–2"> 摩西并没有把土地分给利未支派作产业，因为献给以色列的上帝耶和华的火祭就是他们的产业，正如耶和华对他们的应许。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 以下是摩西按宗族分给吕便支派的产业：</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 13:9; 约书亚记 12:2; 以赛亚书 16:7–9"> 从亚嫩谷旁边的亚罗珥城、谷中的城和米底巴附近的整个平原，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 22:41; 民数记 32:38; 民数记 21:19"> 到希实本城和希实本平原的所有城邑，即底本、巴末·巴力、伯·巴力·勉、</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 约书亚记 21:36–37; 历代志上 6:78–79"> 雅杂、基底莫、米法押、</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 32:37–38"> 基列亭、西比玛、谷中山丘上的细列·沙辖、</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 12:3; 申命记 4:46; 以西结书 25:9"> 伯毗珥、毗斯迦山坡和伯·耶施末，</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 31:8; 申命记 3:10; 申命记 2:30–36"> 平原的各城邑和亚摩利王西宏的国土。西宏曾在希实本做王，摩西打败了他和他的米甸首领以未、利金、苏珥、户珥和利巴。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 31:8; 犹大书 1:11; 彼得后书 2:15"> 以色列人用刀所杀的人中有比珥的儿子术士巴兰。</span>
<span className="v" id="v23" data-v="23"> 吕便支派的土地以约旦河为界。以上是吕便支派按宗族分到的城邑和村庄。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 32:34–36"> 以下是摩西按宗族分给迦得支派的土地：</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 撒母耳记下 11:1; 民数记 32:35"> 雅谢和基列境内所有的城邑；亚扪人的一半领土，直到拉巴附近的亚罗珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 17:27; 撒母耳记下 2:8; 士师记 10:17"> 从希实本直到拉抹·米斯巴和比多宁，从玛哈念到底璧的边境；</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 32:36; 民数记 34:11; 创世记 33:17"> 还有谷中的伯亚兰、伯·宁拉、疏割、撒分，就是希实本王西宏国中其余的土地，以约旦河为界，沿东岸直到加利利湖的顶端。</span>
<span className="v" id="v28" data-v="28"> 以上这些城邑、村庄便是迦得支派按宗族所分到的产业。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 以下是摩西按宗族分给玛拿西半个支派的土地：</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 13:26; 申命记 3:13–15; 民数记 32:39–41"> 从玛哈念开始，包括整个巴珊，就是巴珊王噩的国土及其境内雅珥的六十座城邑，</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 12:4; 民数记 32:39–40"> 还有基列的一半和巴珊王噩的两座城亚斯她录和以得来。玛拿西的儿子玛吉的一半子孙按宗族分到这些土地。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 以上是摩西在耶利哥对面约旦河东的摩押平原分给以色列人的产业。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 18:7; 约书亚记 13:14; 申命记 18:1–2"> 摩西并没有分给利未支派任何产业，因为以色列的上帝耶和华就是他们的产业，正如耶和华对他们的应许。</span>
</div>
</div>

</div>

## 喇合营救探子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:31; 雅各书 2:25; 马太福音 1:5"> 嫩的儿子约书亚暗中从什亭派出两个探子，去侦察那片土地，特别是耶利哥的情况。他们进到一个名叫喇合的妓女家中，就住在那里。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:13; 但以理书 4:35; 箴言 21:30"> 有人告诉耶利哥王说：“今晚有以色列人来这里刺探。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:3; 创世记 42:9–12; 使徒行传 12:6"> 耶利哥王便派人到喇合那里，对她说：“把来到你家里的人交出来，因为他们是来刺探这地方的。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 6:19; 撒母耳记下 17:19–20; 撒母耳记下 16:18–19"> 但喇合已经把二人藏起来了，她答道：“不错，他们来过，可是我不知他们是从哪里来的。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 50:20; 以西结书 47:12; 启示录 21:25"> 天黑要关城门的时候，他们就离开了，我不知道他们去哪里了。你们快去追吧，还可以追上。”</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 11:23; 雅各书 2:25; 歌罗西书 3:3"> 其实喇合已经把二人带到屋顶上，藏在那里的麻秆堆里了。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 3:28; 约书亚记 2:5; 士师记 12:5"> 追捕的人便沿着通往约旦河渡口的路追去，他们一出城，城门便关闭了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 在两个探子睡觉前，喇合上到屋顶对他们说：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 23:27; 申命记 2:25; 约书亚记 2:11"> “我知道耶和华已经把这地方赐给你们，我们对你们充满恐惧。这里所有的居民都吓得胆战心惊。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:21–35; 出埃及记 15:14–16; 出埃及记 14:21–31"> 因为你们离开埃及过红海的时候，耶和华怎样使红海在你们面前成为干地，你们怎样对付约旦河东的两个亚摩利王西宏和噩，把他们彻底消灭，我们都听说了。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 4:39; 约书亚记 5:1; 约书亚记 7:5"> 我们听了这些事，感到心惊胆战、勇气尽失。你们的上帝耶和华是天地万物的上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 2:18; 约书亚记 9:18–20; 提摩太后书 1:16–18"> 我既然恩待了你们，现在请你们凭耶和华向我起誓，你们同样会恩待我家，并且给我一个可靠的凭据，</span>
<span className="v" id="v13" data-v="13"> 保证放过我的父母、兄弟、姊妹和他们所有的亲人，救我们脱离死亡。”</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 5:7; 士师记 1:24–25; 创世记 24:49"> 二人便对她说：“只要你不泄露我们的事，我们愿意用性命担保，当耶和华把这地方赐给我们的时候，我们一定守信善待你。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:25; 哥林多后书 11:33; 约书亚记 6:20"> 喇合的房子就在城墙边，她就住在城墙上，于是她用绳子把二人从窗口缒下去，</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:25; 撒母耳记上 23:14; 诗篇 11:1"> 并对他们说：“你们往山上去，免得被追捕的人发现。你们要在那里躲三天，等追捕的人回城后再走。”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 30:2; 撒母耳记下 21:7; 创世记 24:3–8"> 二人对她说：“要让我们信守誓言，你必须这样做：</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 6:23; 约书亚记 2:21; 约书亚记 2:12–13"> 我们来攻占这座城的时候，你要把这条朱红色绳子系在缒我们下去的窗户上，并且把你的父母、兄弟、姊妹和他们的亲人都召集到你家里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 27:31; 列王纪上 2:36–42; 出埃及记 12:13"> 倘若有人离开这房子跑到街上遭遇不测，我们不负任何责任。我们一定保证屋内所有人的性命安全。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 如果你泄露我们的事，你要我们起的誓也就作废了。”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 2:5; 约书亚记 2:18; 马太福音 7:24"> 喇合说：“一言为定！”于是她送走他们，把朱红色的绳子系在窗户上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 19:10–12; 撒母耳记下 17:20; 诗篇 32:6–7"> 二人到山上躲藏了三天，等追捕的人回去。追捕的人沿途搜索，毫无所获，便回去了。</span>
<span className="v" id="v23" data-v="23"> 二人便下山，过河回到嫩的儿子约书亚那里，向他禀告整个经过，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 23:31; 约书亚记 1:8; 约书亚记 2:9–11"> 又说：“耶和华确实将那整片土地交给我们了，那里的居民听到我们的消息，都吓得胆战心惊。”</span>
</div>
</div>

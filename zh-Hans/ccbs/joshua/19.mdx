## 西缅支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 19:9; 创世记 49:5–7; 约书亚记 18:6–11"> 西缅支派按宗族得到第二签，所得的产业在犹大人的疆界内，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 4:28–30; 尼希米记 11:26–30; 创世记 21:31"> 有别示巴，又名示巴、摩拉大、</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 15:28–29"> 哈萨·书亚、巴拉、以森、</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 15:30; 士师记 1:17"> 伊勒多腊、比土力、何珥玛、</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 30:1; 历代志上 4:31; 约书亚记 15:31"> 洗革拉、伯·玛加博、哈萨·苏撒、</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 15:32"> 伯·利巴勿、沙鲁险共十三座城及其附近的乡村，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:42; 约书亚记 15:32; 民数记 33:19–20"> 还有亚因、利门、以帖、亚珊四座城及其村庄，</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 4:33; 撒母耳记上 30:27"> 包括周围所有的村庄，远至巴拉·比珥，即南地的拉玛。这些都是西缅支派按宗族所得的产业。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 8:14–15; 出埃及记 16:18"> 西缅人的产业是从犹大人的产业中拨出来的，因为犹大支派所分到的地区过于广大，所以要拨出一部分来分给西缅人。</span>
</div>
</div>

## 西布伦支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 18:11; 约书亚记 18:6; 创世记 49:13"> 西布伦人按宗族得了第三签，他们分到的土地远至撒立。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 12:22; 历代志上 6:68; 列王纪上 4:12"> 从撒立向西到玛拉拉、大巴设，直到约念东边的小河；</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 4:6; 历代志上 6:72; 约书亚记 19:22"> 从撒立向东朝日出方向到吉斯绿·他泊的边界，经大比拉、直到雅非亚；</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 14:25"> 再往东，经迦特·希弗、以特·加汛、临门，直到尼亚；</span>
<span className="v" id="v14" data-v="14"> 北上转向哈拿顿，直到伊弗他·伊勒山谷。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 11:1; 路得记 1:19; 撒母耳记下 23:15"> 还有加他、拿哈拉、伸仑、以大拉、伯利恒，共十二座城及其附近的乡村。</span>
<span className="v" id="v16" data-v="16"> 以上这些城邑和乡村是西布伦人按宗族所得的产业。</span>
</div>
</div>

## 以萨迦支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 以萨迦人按宗族得了第四签，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 28:4; 列王纪下 4:8; 何西阿书 1:4–5"> 他们的土地包括耶斯列、基苏律、书念、</span>
<span className="v" id="v19" data-v="19"> 哈弗连、示按、亚拿哈拉、</span>
<span className="v" id="v20" data-v="20"> 拉璧、基善、亚别、</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 21:29"> 利篾、隐·干宁、隐·哈大、伯·帕薛、</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 4:6; 历代志上 6:77; 约书亚记 19:38"> 他泊、沙哈洗玛、伯·示麦，直到约旦河，共十六座城及其附近的乡村。</span>
<span className="v" id="v23" data-v="23"> 这些城邑和乡村都是以萨迦支派按宗族分到的产业。</span>
</div>
</div>

## 亚设支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 2:26–38"> 亚设支派按宗族得了第五签，</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 12:20; 约书亚记 11:1; 撒母耳记下 2:16"> 他们得到的土地包括黑甲、哈利、比田、押煞、</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王纪上 18:42; 以赛亚书 33:9"> 亚拉米勒、亚末和米沙勒，西至迦密和希曷·立纳，</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 9:13; 撒母耳记上 5:2"> 然后向东到伯·大衮，挨着西布伦和伊弗他·伊勒谷，经伯·以墨和尼业向北到迦步勒；</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 1:31; 约书亚记 11:8; 以赛亚书 23:12"> 再经义伯仑、利合、哈们、加拿直到西顿大城；</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:31; 撒母耳记下 5:11; 弥迦书 1:14"> 再转到拉玛、坚固的泰尔城，然后转到何萨，直到亚革悉一带的地中海。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 21:31; 列王纪上 20:30; 撒母耳记上 4:1"> 还有乌玛、亚弗和利合，共二十二座城及其附近的乡村。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 33:24–25; 创世记 49:20"> 这些城邑和乡村都是亚设支派按宗族分到的产业。</span>
</div>
</div>

## 拿弗他利支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32"> 拿弗他利人按宗族得了第六签，</span>

<span className="v" id="v34" data-v="34" data-xref="申命记 33:23; 约书亚记 19:12; 约书亚记 19:22"> 又向西到亚斯纳·他泊、户割，南接西布伦，西接亚设，东接约旦河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“约旦河”参照《七十士译本》，希伯来文作“约旦河的犹大”。">a</a></sup>。</span>

## 但支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40"> 但支派按宗族得了第七签，</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 2:53; 约书亚记 15:33; 士师记 13:25"> 他们的土地包括琐拉、以实陶、伊珥·示麦、</span>
<span className="v" id="v42" data-v="42" data-xref="士师记 1:35; 约书亚记 10:12; 约书亚记 21:24"> 沙拉宾、亚雅仑、伊提拉、</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 38:12; 撒母耳记上 5:10; 士师记 14:1–2"> 以伦、亭拿他、以革伦、</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 15:27; 列王纪上 16:15; 列王纪上 9:18"> 伊利提基、基比顿、巴拉、</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 21:24"> 伊胡得、比尼·比拉、迦特·临门、</span>

<span className="v" id="v47" data-v="47" data-xref="士师记 1:34–35; 士师记 18:1–29"> 但支派无法夺取他们的土地，于是就去攻打利善城，用刀杀了城内的居民，占据了这座城，用他们祖先的名字把城改名为但，</span>
<span className="v" id="v48" data-v="48"> 这些城邑和村庄都是但支派按宗族得到的产业。</span>

## 约书亚分得之地

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以西结书 45:7–8"> 以色列人把地分配完毕以后，又从中划出土地给嫩的儿子约书亚。</span>
<span className="v" id="v50" data-v="50" data-xref="约书亚记 24:30; 士师记 2:9; 历代志上 7:24"> 以色列人遵从耶和华的吩咐，把约书亚想要的以法莲山区的亭拿·西拉城分给他。约书亚重修那城，住在那里。</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 18:10; 约书亚记 14:1; 约书亚记 18:1"> 以上是祭司以利亚撒、嫩的儿子约书亚和以色列各支派的首领，在示罗的会幕门口，在耶和华面前抽签所分配的土地。至此，他们把地分完了。</span>
</div>

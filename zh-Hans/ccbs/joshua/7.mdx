## 亚干犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 22:20; 传道书 9:18; 历代志上 2:6–7"> 以色列人在当毁灭之物的事上犯了罪。因为犹大支派中谢拉的曾孙、撒底的孙子、迦米的儿子亚干拿了一些本该毁灭之物，耶和华便向以色列人发怒。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:12; 何西阿书 4:15; 撒母耳记上 14:23"> 当时，约书亚从耶利哥派人去伯特利东边靠近伯·亚文的艾城，并吩咐道：“你们去侦察那地方。”那些人便上去侦察艾城。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 6:11–12; 路加福音 13:24; 彼得后书 1:5"> 他们侦察回来后对约书亚说：“那里的居民很少，我们不必全军出动，只要派两三千人上去便可以攻取艾城，不必劳师动众。”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:25; 利未记 26:17; 申命记 32:30"> 于是，大约有三千以色列人去攻打艾城，不料却被艾城人击溃。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:11; 约书亚记 2:9; 利未记 26:36"> 艾城的人杀了他们三十六人，从城门前追杀他们，一直到示巴琳，在下坡处杀败他们。以色列人吓得心惊胆战。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 37:29; 创世记 37:34; 启示录 18:19"> 约书亚和以色列的长老便撕裂衣服，把灰撒在头上，俯伏在耶和华的约柜面前，直到晚上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:5; 列王纪下 3:10; 马太福音 17:20"> 约书亚说：“唉！主耶和华啊，你为什么把我们带过约旦河，交给亚摩利人毁灭呢？倒不如让我们住在约旦河东岸！</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:5–6; 以斯拉记 9:10; 哈巴谷书 2:1"> 主啊，现在以色列人被仇敌打败，我还有什么话可说呢？</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 32:12; 诗篇 83:4; 以西结书 36:22–23"> 迦南人和这一带的人听到这消息以后，必从四面八方来围攻我们，将我们从地上斩尽杀绝。那时候，你的大名怎么办呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:22; 出埃及记 14:15; 撒母耳记上 16:1"> 耶和华对约书亚说：“起来吧！你为何俯伏在地？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:1–2; 希伯来书 4:13; 约书亚记 6:17–19"> 以色列人犯了罪，违背了我吩咐他们应守的约，拿了本该毁灭之物放在自己的行囊里，又偷窃又撒谎。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 5:4–5; 以赛亚书 59:2; 约书亚记 6:18"> 所以，以色列人无法抵挡敌人，掉头败逃，因为他们已成当毁之物。你必须将那些本该毁灭之物从你们中间除掉，不然我就不再与你们同在。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 约书亚记 3:5; 马太福音 7:5"> 起来吧！去吩咐民众洁净自己，让他们为明天洁净自己，因为以色列的上帝耶和华这样说，‘以色列啊！你们中间有当毁之物，你们不除掉它们就无法抵挡敌人。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 约拿书 1:7; 约书亚记 7:17–18"> 明天早上，你们要按支派一个一个前来，耶和华指出哪个支派，哪支派的各宗族便要前来。耶和华指出哪个宗族，哪宗族的各家族便要前来。耶和华指出哪个家族，哪家族的各成员便要前来。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 34:7; 撒母耳记上 14:38–39; 士师记 20:6"> 哪个人被指出拿了本该毁灭之物，哪个人及其所有的东西就要被火焚烧。因为他违背了耶和华的约，在以色列人中做了可耻的事。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:60; 约书亚记 3:1; 创世记 22:3"> 第二天清早，约书亚按照支派召来以色列人，结果抽中犹大支派；</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:20; 历代志上 2:4–7; 创世记 38:30"> 他让犹大支派各宗族前来，结果抽中谢拉宗族；他让谢拉宗族前来，结果抽中撒底家族；</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 32:23; 使徒行传 5:1–10; 撒母耳记上 14:42"> 他让撒底家族的人一个一个前来，结果抽中犹大支派中谢拉的曾孙、撒底的孙子、迦米的儿子亚干。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 6:5; 耶利米书 13:16; 约翰福音 9:24"> 约书亚对亚干说：“孩子啊，我劝你把荣耀归给以色列的上帝耶和华，向祂认罪，把你所做的事告诉我，不要隐瞒。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 38:18; 约伯记 33:27; 创世记 42:21"> 亚干答道：“我的确得罪了以色列的上帝耶和华。事情是这样的，</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:15; 诗篇 119:37; 约翰一书 2:15–16"> 在夺得的财物中，我看上了一件漂亮的示拿外衣、四十五两银子和十两金子，我一时贪心便拿去了，藏在我帐篷的地底下，银子就放在衣服下面。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 约书亚派人跑到他帐篷里，果然那件外衣藏在他帐篷里，银子在衣服下面。</span>
<span className="v" id="v23" data-v="23"> 他们从帐篷里取出这些东西，将它们带到约书亚和全体民众那里，摆在耶和华面前。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前书 6:9–10; 约书亚记 7:26"> 约书亚和全体以色列人把谢拉家族的亚干、那些银子、衣服和金子及其儿女、牛、驴、羊、帐篷和一切所有都带到亚割谷。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:18; 历代志上 2:7; 利未记 24:14"> 约书亚对亚干说：“你为什么给我们惹祸呢？耶和华今天要降祸给你。”于是，以色列人便拿石头打死了他及其一切，将他们烧毁。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 65:10; 何西阿书 2:15; 申命记 13:17"> 他们在亚干身上堆起一大堆石头，那些石头今天还在。耶和华这才息怒，因此那地方至今还叫亚割<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚割”意思是“连累”。">a</a></sup>谷。</span>
</div>
</div>

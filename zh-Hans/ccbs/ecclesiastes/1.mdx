## 万事虚空

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="传道书 12:8–10; 传道书 1:12; 传道书 7:27"> 以下是在耶路撒冷做王的大卫之子传道者的话。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 144:4; 罗马书 8:20; 传道书 5:10"> <span className="pl pl-1">传道者说：虚空的虚空，</span><br /><span className="pl pl-1">虚空的虚空，一切都是虚空。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="传道书 3:9; 传道书 5:16; 传道书 2:22"> <span className="pl pl-1">人在日光之下的一切劳碌有什么益处呢？</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 104:5; 撒迦利亚书 1:5; 传道书 6:12"> <span className="pl pl-1">一代过去，一代又来，</span><br /><span className="pl pl-1">大地却永远长存。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 19:4–6; 哈巴谷书 3:11; 诗篇 42:1"> <span className="pl pl-1">太阳升起，太阳落下，</span><br /><span className="pl pl-1">匆忙回到升起之地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:8; 传道书 11:5; 诗篇 107:25"> <span className="pl pl-1">风吹向南，又转向北，</span><br /><span className="pl pl-1">循环不息，周而复始。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 38:10–11; 诗篇 104:6–9"> <span className="pl pl-1">江河涌流入海，海却不会满溢；</span><br /><span className="pl pl-1">江河从何处流出，又返回何处。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 27:20; 马太福音 11:28; 传道书 4:8"> <span className="pl pl-1">万事令人厌烦，人述说不尽。</span><br /><span className="pl pl-1">眼看，看不饱；</span><br /><span className="pl pl-1">耳听，听不够。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="传道书 3:15; 传道书 6:10; 传道书 2:12"> <span className="pl pl-1">以往发生的事，将来还会发生；</span><br /><span className="pl pl-1">先前做过的事，将来也必再做。</span><br /><span className="pl pl-1">日光之下，根本没有新事。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:51; 路加福音 17:26–30; 马太福音 23:30–32"> <span className="pl pl-1">人可以指着哪件事说</span><br /><span className="pl pl-1">“看啊，这是新事”？</span><br /><span className="pl pl-1">所谓的新事在我们以前早就有了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="传道书 2:16; 诗篇 9:6; 传道书 9:5"> <span className="pl pl-1">过去的事无人记得，</span><br /><span className="pl pl-1">将来的事后人也不记得。</span></span>
</div>
</div>

## 智慧之虚空

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="传道书 1:1; 列王纪上 4:1–19"> 我传道者曾在耶路撒冷做以色列的王。</span>
<span className="v" id="v13" data-v="13" data-xref="传道书 3:10; 创世记 3:19; 提摩太前书 4:15"> 我专心用智慧去研究、探索天下万事，发现上帝给世人的是极重的苦工。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 2:11; 传道书 2:17; 传道书 2:26"> 我观察一切日光之下所做的事，看啊，都是虚空，好像捕风。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 7:12–13; 以赛亚书 40:4; 传道书 3:14"> 弯曲的不能变直，缺少的无法补足<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“补足”希伯来文是“数算”。">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 2:9; 列王纪上 4:30; 列王纪上 10:7"> 我心里想：“我获得极大的智慧，远超过以前统治耶路撒冷的人。我拥有丰富的智慧和知识。”</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 2:3; 帖撒罗尼迦前书 5:21; 传道书 1:13–14"> 我又专心察明智慧和知识、狂妄和愚昧，却发现这也是捕风。</span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 28:28; 传道书 12:12–13; 哥林多前书 3:18–20"> 因为智慧越高，愁烦越多；知识越多，痛苦越深。</span>
</div>

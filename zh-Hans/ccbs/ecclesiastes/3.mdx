## 万物有时

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="传道书 3:17; 马太福音 16:3; 传道书 8:5–6"> <span className="pl pl-1">天下万物都有定期，</span><br /><span className="pl pl-1">凡事都有定时。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 9:27; 约伯记 14:5; 马太福音 15:13"> <span className="pl pl-1">出生有时，死亡有时；</span><br /><span className="pl pl-1">耕种有时，拔出有时；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 6:1–2; 撒母耳记上 2:6; 耶利米书 45:4"> <span className="pl pl-1">杀戮有时，医治有时；</span><br /><span className="pl pl-1">拆毁有时，建造有时；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 12:15; 诗篇 30:5; 雅各书 4:9"> <span className="pl pl-1">哭泣有时，欢笑有时；</span><br /><span className="pl pl-1">哀伤有时，雀跃有时；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 3:25; 约书亚记 10:27; 约书亚记 4:3–9"> <span className="pl pl-1">抛石有时，堆石有时</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“抛石有时，堆石有时”意义不明，有犹太拉比说是“同房有时，分房有时”。">a</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">拥抱有时，避开有时；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 3:7–8; 路加福音 9:24–25; 马可福音 8:35–37"> <span className="pl pl-1">寻找有时，遗失有时；</span><br /><span className="pl pl-1">保存有时，丢弃有时；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 5:13; 弥迦书 7:5; 耶利米哀歌 3:28"> <span className="pl pl-1">撕裂有时，缝合有时；</span><br /><span className="pl pl-1">沉默有时，发言有时；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:25; 以弗所书 5:28–29; 路加福音 14:26"> <span className="pl pl-1">爱慕有时，憎恶有时；</span><br /><span className="pl pl-1">争战有时，和好有时。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="传道书 1:3; 传道书 5:16; 箴言 14:23"> 那么，人劳碌做工有什么益处呢？</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 1:13–14; 创世记 3:19; 传道书 2:26"> 我察觉上帝给世人重担，使他们忙碌不休。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 11:33; 罗马书 1:19–20; 约伯记 11:7"> 祂使万事各按其时变得美好，又把永恒的意识放在人心里，人却不能测透上帝从始至终的作为。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 37:3; 传道书 3:22; 提摩太前书 6:18"> 我认识到，人生在世没有什么比欢乐、享受更好。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 128:2; 传道书 9:7; 传道书 2:24"> 人人都该吃喝、享受自己劳苦的成果，这是上帝的恩赐。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 诗篇 33:11; 罗马书 11:36"> 我知道，上帝所做的都会存到永远，谁也不能增减。祂这样安排是叫人敬畏祂。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 1:9–10; 传道书 6:10"> 现在的事并不是新事，未来的事也早已发生过。上帝使过去的事再次出现。</span>
</div>

## 世间的不公

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="传道书 4:1; 传道书 5:8; 诗篇 94:21–22"> 我又看到日光之下，即使在公道和正义之地也有邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 5:10; 传道书 12:14; 马太福音 16:27"> 我心里想：“不论义人或恶人，上帝必审判，因为万事万务都有定时。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 73:22; 诗篇 49:12; 希伯来书 9:27"> 我又想：“至于世人，上帝试验他们，是要他们知道自己与兽类无异。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 49:12; 诗篇 49:20; 诗篇 89:47–48"> 因为人和兽的际遇并无分别，两者都难逃一死，活着都靠一口气。人并不比兽强，一切都是虚空。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:19; 约伯记 34:15; 传道书 12:7"> 两者都同归一处，出于尘土，也归于尘土。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 12:7; 约翰福音 14:3; 哥林多后书 5:1"> 谁知道人的气息<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“气息”或译“灵”，本节同。">b</a></sup>会向上升，兽的气息会降到地下呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="传道书 2:24; 传道书 3:11–12; 传道书 10:14"> 因此，我觉得没有什么比人享受工作之乐更好，因为这是人当得的。人死后，谁能使他看到世间的事呢？</span>
</div>
</div>

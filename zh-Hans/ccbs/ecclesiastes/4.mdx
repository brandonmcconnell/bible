<span className="v" id="v1" data-v="1" data-xref="传道书 3:16; 传道书 5:8; 以赛亚书 5:7"> 于是，我又观察日光之下的一切欺压之事。我看见受欺压的泪流满面，无人安慰。因为欺压者有权有势，所以无人安慰他们。</span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 3:11–26; 传道书 2:17; 传道书 9:4–6"> 因此，我认为那已死的人比活着的人幸福。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:29; 传道书 6:3–5; 马太福音 24:19"> 不过，比以上两种人更幸运的是那从未出生的人，他们从未见过日光之下的恶行。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 3:12; 传道书 1:14; 传道书 2:26"> 我又看见人的一切劳碌和成就原是出于争强好胜。这也是虚空，如同捕风。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 9:20; 箴言 13:4; 箴言 6:10–11"> 愚人游手好闲，最后只能饿死。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:8; 箴言 15:16–17; 诗篇 37:16"> 拥有不多，心里安宁，胜过拥有很多，仍劳碌捕风。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 4:1; 诗篇 78:33; 撒迦利亚书 1:6"> 我又看见日光之下一件虚空的事：</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 2:16; 箴言 27:20; 路加福音 12:20"> 有一个人孤孤单单，没有儿子也没有兄弟，却终身劳碌。他虽然家道丰裕，仍不满足，从未想过：“我不停地劳碌，放弃一切享受，究竟是为了谁？”这也是虚空，是一种悲哀。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 27:17; 创世记 2:18; 哥林多前书 12:18–21"> 两个人总比一个人好，因为二人劳碌同得美好的成果。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 5:11; 帖撒罗尼迦前书 4:18; 以赛亚书 35:3–4"> 一人跌倒，总有同伴相扶。但孤身一人、跌倒了无人相扶的真悲惨！</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 1:1–4"> 还有，二人同睡会暖和，一人独睡怎能暖和呢？</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 3:16–17; 以弗所书 4:3; 撒母耳记下 23:9"> 遭遇攻击，一人独自不能抵挡，二人并肩就能对付。三股拧成的绳子不容易断。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 25:16; 历代志下 16:9–10; 箴言 19:1"> 贫穷但有智慧的青年，胜过年老、愚昧、不再纳谏的君王。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 113:7–8; 创世记 41:14; 约伯记 5:11"> 虽然这青年在本国出身贫寒，却能从囚犯成为君王。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:6"> 我看见所有日光之下的人都起来拥护这位代替老君王的青年。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 1:14; 列王纪上 1:40; 传道书 2:17"> 拥护他的人不计其数，以后的世代却对他不满。这也是虚空，如同捕风。</span>

<span className="v" id="v4" data-v="4" data-xref="马太福音 8:14–16; 撒母耳记上 25:36; 路加福音 7:12–13"> <span className="pl pl-1">智者的心思考死亡，</span><br /><span className="pl pl-1">愚人的心只顾作乐。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 诗篇 141:5; 启示录 3:19"> <span className="pl pl-1">听智者的责备，</span><br /><span className="pl pl-1">胜过听愚人的颂歌。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 58:9; 诗篇 118:12; 传道书 2:2"> <span className="pl pl-1">愚人的笑声像锅底下烧荆棘的噼啪声。</span><br /><span className="pl pl-1">这也是虚空。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="申命记 16:19; 出埃及记 23:8; 箴言 17:23"> <span className="pl pl-1">欺压使智者变愚昧，</span><br /><span className="pl pl-1">贿赂败坏人心。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:36; 箴言 14:29; 诗篇 126:5–6"> <span className="pl pl-1">事情的结局胜过事情的开端；</span><br /><span className="pl pl-1">恒久忍耐胜过心骄气傲。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="士师记 6:13; 诗篇 14:2–3; 创世记 6:11–12"> <span className="pl pl-1">不要问为什么过去比现在好，</span><br /><span className="pl pl-1">因为这样问不明智。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="传道书 11:7; 提摩太前书 6:17–19; 传道书 2:13"> <span className="pl pl-1">智慧如同产业一样美好，</span><br /><span className="pl pl-1">有益于得见日光的世人。</span><br /></span>

</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="传道书 8:12–14; 传道书 6:12; 诗篇 73:3–13"> 在我虚空的一生中，我见过义人行义，反而灭亡；恶人行恶，却享长寿。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 箴言 25:16; 歌罗西书 2:18"> 为人不要过分正直，也不要过于聪明，何必自取毁灭呢？</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:27; 诗篇 55:23; 约伯记 22:16"> 不要过分邪恶，也不要做愚人，何必时候未到就死呢？</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 12:13; 玛拉基书 4:2; 传道书 11:6"> 最好是持守这个教训也不放松那个教训，因为敬畏上帝的人必避免两个极端。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:22; 歌罗西书 1:9–11; 箴言 24:5"> 智慧使一个智者比城里十个官长更有能力。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 3:23; 以赛亚书 53:6; 约翰一书 1:8–10"> 诚然，在地上无法找到一个一生行善、从未犯罪的义人。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 30:10; 以赛亚书 29:21; 撒母耳记下 16:10"> 你不要斤斤计较别人所说的每一句话，免得听见你的仆人咒诅你，</span>

<span className="v" id="v23" data-v="23" data-xref="罗马书 1:22; 创世记 3:5; 哥林多前书 1:20"> 我用智慧试验过这一切。我说：“我要做智者”，谁知智慧却离我甚远。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:33; 提摩太前书 6:16; 以赛亚书 55:8–9"> 智慧如此遥不可及、深不可测，谁能找得到呢？</span>

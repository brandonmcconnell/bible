## 敬畏上帝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:19; 希伯来书 12:28–29; 箴言 15:8"> 你进入上帝的殿时要小心谨慎，近前倾听胜过愚人献祭，因为他们不知道自己是在作恶。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:7; 箴言 10:19; 以赛亚书 55:9"> 在上帝面前不要冒失开口，不可急于发言，因为祂在天上，你在地上。所以，你要少言寡语。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 传道书 10:12–14"> 事务繁杂，夜里多梦；多言多语，显出愚昧。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 30:2; 申命记 23:21–23; 诗篇 76:11"> 你向上帝许愿，不可迟迟不还，因为祂不喜欢愚人。要还所许的愿。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:4; 申命记 23:22; 箴言 20:25"> 与其许了愿不还，倒不如不许。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:26; 约翰二书 1:8; 雅各书 3:2"> 不要在言语上犯罪，也不要在祭司<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“祭司”希伯来文是“使者”。">a</a></sup>面前说许错了愿。为什么用言语惹上帝发怒，以致祂摧毁你手中的工作呢？</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:13; 马太福音 12:36; 传道书 8:12"> 多梦多言都是虚空。你只要敬畏上帝！</span>
</div>
</div>

## 财富虚空

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 12:5; 传道书 4:1; 传道书 3:16"> 若你在某地看见穷人受欺压，公平正义被践踏，不要震惊，因为官上有官，在众官之上还有更高的官鉴察。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:7–23; 诗篇 115:16; 创世记 1:29–30"> 况且，地的出产滋养万人，就是君王也需要从田地得到供应。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:10; 马太福音 6:24; 路加福音 12:15"> 贪爱钱财的，金银不能使他满足；贪图富裕的，再多的收益也不能叫他称心。这也是虚空！</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:16; 哈巴谷书 2:13; 诗篇 119:36–37"> 财富增加，消费的人也增加，这对财富的主人有什么益处呢？只是过眼云烟罢了！</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 诗篇 4:8; 耶利米书 31:26"> 劳力的人不管吃多吃少，总是睡得香甜；富人的家财却害得他不能成眠。</span>
<span className="v" id="v13" data-v="13" data-xref="传道书 6:1–2; 路加福音 18:22–23; 创世记 19:14"> 我看到日光之下有一件可悲的事：有人积攒财宝，反而害了自己。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 6:19–20; 哈该书 2:16–17; 箴言 23:5"> 经营不善，财富尽失，什么也不能留给子孙。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 49:17; 约伯记 1:21; 提摩太前书 6:7"> 人怎样从母腹空空而来，也必照样空空而去；劳碌一生，什么也不能带走。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 传道书 1:3; 约翰福音 6:27"> 这是极大的悲哀！人怎样来，也要怎样去，为风劳碌有什么益处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 127:2; 以西结书 4:16–17; 诗篇 90:7–11"> 他一生活在黑暗中，饱受烦恼、病痛和愤怒的困扰。</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 2:24; 传道书 3:12–13; 传道书 3:22"> 我认为人生最美最善的是，在上帝所赐的短暂岁月中尽情吃喝，享受自己在日光之下劳苦得来的成果。因为这是人当得的。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 8:18; 传道书 3:13; 传道书 6:2"> 上帝不单给人财富和产业，也叫他能吃能喝，享用自己所当得的，并在劳碌中得到快乐，这都是上帝的恩赐。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:21–24; 以赛亚书 65:13–14; 诗篇 37:16"> 他不用担忧自己寿命的长短，因为上帝使他心里充满喜乐。</span>
</div>
</div>

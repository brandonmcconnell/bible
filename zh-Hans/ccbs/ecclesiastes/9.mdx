<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 33:3; 约翰福音 10:27–30; 彼得前书 1:5"> 我仔细思想、探究这一切事，就知道义人、智者及他们的行事为人都由上帝掌管，人无法知道前面等待自己的是爱还是恨。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:18; 传道书 2:14–16; 玛拉基书 3:5"> 义人和恶人、好人和坏人、洁净的和污秽的、献祭的和不献祭的、行善的和犯罪的、敢于起誓的和不敢起誓的人，命运都一样。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 17:9; 传道书 8:11; 传道书 1:17"> 在日光之下有一件可悲的事，就是人的命运都一样。况且，人内心都充满邪恶，活着的时候行事狂妄，之后都步入死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 14:7–12; 以赛亚书 38:18; 路加福音 16:26–29"> 有生命就有希望，一条活狗总比一头死狮子强。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 26:14; 传道书 1:11; 诗篇 6:5"> 因为活着的人还知道自己终有一死，但死了的人什么都不知道，再也得不到任何赏赐，他们被忘得一干二净。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 146:3–4; 传道书 6:12; 约伯记 3:17–18"> 他们的爱、恨和嫉妒早已不复存在，他们再也无法参与日光之下的任何事。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="传道书 3:12–13; 申命记 12:7; 传道书 10:19"> 去欢欢喜喜、快快乐乐地吃喝吧！因为上帝已经悦纳你所做的。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 19:14; 启示录 3:4–5; 启示录 19:8"> 你的衣服要经常保持洁白，头上也不要缺少膏油。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 5:18–19; 传道书 2:10; 玛拉基书 2:15"> 在你虚空的人生中，就是在上帝所赐、日光之下虚空的岁月里，你要与爱妻快乐度日，因为这是你一生在日光之下的劳碌中所当得的。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 3:23; 以弗所书 5:16; 罗马书 12:11"> 凡你的手能做的，都要尽力去做，因为在你要去的阴间没有工作，没有计划，也没有知识和智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 9:23; 箴言 21:30–31; 耶利米哀歌 3:37–38"> 我又发现，日光之下，跑得快的未必能得奖，强大的未必能得胜，智者未必得温饱，聪明人未必得财富，博学者未必受爱戴，因为时机和境遇左右众人。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:3; 路加福音 21:34–36; 传道书 8:5–7"> 再者，人无法知道何时大难临头。祸患突然临到时，人根本无法摆脱，就像鱼落入险恶的网中，又像鸟儿陷入网罗。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="传道书 8:16; 传道书 7:15; 传道书 6:1"> 我看见日光之下有一种智慧，对我来说意义深远。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 20:15–22; 列王纪下 6:24–20"> 有一个势力强大的君王来攻击一个人口不多的小城，他建造营垒围困这城。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 4:13; 创世记 40:23; 以斯帖记 6:2–3"> 这城里有一个贫穷的智者，他用智慧拯救了这城，事后却无人记念他。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 7:19; 箴言 24:5; 箴言 21:22"> 我认为智慧胜过武力，然而那位穷人的智慧却被轻视，他所说的话也无人理会。</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 3:17–18; 箴言 28:23; 雅各书 1:20"> 听智者的细语，胜过听官长在愚人中的喊叫。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 7:11–12; 传道书 9:16; 约书亚记 7:5"> 智慧胜过兵器，但一个罪人却能破坏许多善事。</span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 6:15; 申命记 28:50; 彼得后书 1:20"> <span className="pl pl-1">谁像有智慧的人呢？</span><br /><span className="pl pl-1">谁知道事情的原委呢？</span><br /><span className="pl pl-1">智慧能使人容光焕发，</span><br /><span className="pl pl-1">使冷酷的面孔柔和。</span></span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 2:43; 提多书 3:1; 箴言 24:21"> 我劝你遵守王的命令，因为你曾在上帝面前这样发誓。</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 10:4; 使徒行传 5:8–9; 但以理书 4:35"> 不要在王面前鲁莽行事，也不要参与恶行，因为王可以随意行事。</span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 9:12; 罗马书 13:1–4; 但以理书 4:35"> 况且，王的命令至高无上，谁敢质问他：“你在做什么？”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 5:14; 彼得前书 3:13–14; 腓立比书 1:9–10"> 遵从王命的必免遭祸患，因为智者心里懂得做事的时机和方法。</span>
<span className="v" id="v6" data-v="6" data-xref="传道书 3:1; 传道书 3:17; 传道书 3:11"> 尽管人面临重重困难，但做任何事都有时机和方法。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 10:14; 传道书 9:12; 箴言 24:22"> 无人知道未来的事，谁能告诉人将来的事呢？</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 89:48; 约伯记 14:5; 希伯来书 9:27"> 无人能掌管生命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“生命”也可译作“风”或“气息”。">a</a></sup>，留住生命，也无人能掌管死期。无人能免于这场争战，邪恶也救不了作恶者。</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 5:8; 传道书 4:7–8; 传道书 5:13"> 这一切我都见过了，我用心思考日光之下的一切事。有时人欺压人，使人受伤害。</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 9:5; 传道书 2:16; 箴言 10:7"> 我看见恶人死后被安葬。他们生前出入圣所，还在他们作恶的城中受到称赞，这也是虚空。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 26:10; 诗篇 50:21–22; 罗马书 2:4–5"> 对犯罪者的刑罚不迅速执行，世人便尽情作恶。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 37:11; 彼得后书 2:9; 路加福音 1:50"> 虽然罪人作恶多端仍得长寿，我却认为敬畏上帝的人必亨通，因为他们对上帝心存敬畏。</span>
<span className="v" id="v13" data-v="13" data-xref="传道书 6:12; 以赛亚书 3:11; 约伯记 14:2"> 然而，恶人得不到祝福，他们必像幻影一样不能长久，因为他们不敬畏上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 7:15; 传道书 2:14; 玛拉基书 3:15"> 世上有一件虚空的事，就是义人遭受了恶人当受的报应，恶人却享受了义人该享的福乐。我认为这也是虚空。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 2:24; 传道书 5:18; 传道书 3:12–13"> 因此，我便赞赏享乐，因为在日光之下没有什么比吃喝快乐更好。这是人在上帝所赐的年日里，从劳碌中当得的享受。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 1:13; 诗篇 127:2; 传道书 2:23"> 我全心去寻求智慧，观察世上所发生的事，甚至昼夜不眠，</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 3:11; 诗篇 73:16; 罗马书 11:33"> 我看清了上帝的一切作为，便知道人无法理解日光之下所发生的事。尽管人努力不懈地去寻找，也找不到答案；即使智者自以为明白，他其实仍不能参透。</span>

<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 传道书 8:15; 雅各书 5:5"> 我心里想：“来吧，不妨试试享乐，好好享受！”唉！结果这也是虚空。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 传道书 7:2–6; 彼得前书 4:2–4"> 我说：“欢笑只不过是一阵狂妄，享乐又有什么用！”</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 传道书 1:17; 箴言 31:4–5"> 于是，我决意用酒使自己快乐，在体验愚昧的同时仍然保持理智，直到我明白在短暂的人生岁月中做何事才有益。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 7:1–12; 历代志下 8:11; 历代志下 26:10"> 我大动工程，为自己建造房屋，栽种葡萄园；</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米书 39:4"> 我为自己开垦花圃园囿，在其中种植各种果树；</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 2:14; 诗篇 1:3; 耶利米书 17:8"> 我为自己开凿池塘，用来浇灌茂林。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:4; 创世记 15:3; 列王纪上 4:23"> 我买了仆婢，又有生在家中的仆婢，拥有的牛羊远超过历来在耶路撒冷的任何人。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 10:10; 列王纪上 9:28; 撒母耳记下 19:35"> 我为自己积聚金银，搜罗列王和各省的奇珍异宝，得到世人所想望的男女歌优及许多妃嫔。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 29:25; 传道书 1:16; 列王纪上 10:23"> 这样，我便财势日增，超过耶路撒冷历来所有的人。然而，我仍然保持智慧。</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 9:9; 传道书 5:18; 传道书 3:22"> 凡我眼睛爱看的、心里渴慕的，我都随心所欲，尽情享受。我的心从劳碌中得到欢乐，这是我劳碌所得的回报。</span>
<span className="v" id="v11" data-v="11" data-xref="传道书 1:14; 约翰一书 2:16–17; 传道书 1:3"> 然而，当我回顾双手成就的一切和所付的辛劳时，唉，却发现都是虚空，都是捕风；日光之下的一切都毫无益处。</span>
<span className="v" id="v12" data-v="12" data-xref="传道书 1:17; 传道书 7:25; 传道书 1:9–10"> 于是，我转念思考什么是智慧、狂妄和愚昧。其实以后接替君王的人除了重演历史之外，还能做什么呢？</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 传道书 7:11–12; 马太福音 6:23"> 我领悟到智慧胜过愚昧，如同光明胜过黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 49:10; 箴言 17:24; 传道书 9:11"> 智者高瞻远瞩，愚人却在黑暗中摸索。但我知道两者都有同样的命运。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 6:8; 传道书 1:14; 传道书 1:2"> 于是，我想：“既然愚人的命运也将是我的命运，我有智慧又怎么样呢？”我只能说：“这也是虚空。”</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 1:11; 传道书 9:5; 诗篇 88:12"> 因为智者和愚人一样，不过被人记得一时，日后都会被遗忘。两者都难逃死亡。</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 2:11; 约拿书 4:8; 传道书 4:2"> 所以，我憎恶生命，因为在日光之下所做的一切都让我愁烦。唉！这一切都是虚空，都是捕风。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 39:6; 诗篇 49:10; 路加福音 16:27–28"> 我憎恶自己在日光之下劳碌得来的一切，因为这些必留给后人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 3:17; 传道书 3:22; 传道书 9:13"> 谁知道后人是智者还是愚人呢？他却要接管我在日光之下用智慧辛劳经营的产业。这也是虚空。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 43:14; 约伯记 17:11–15; 哥林多后书 1:8–10"> 因此，我对自己在日光之下一切的劳碌感到绝望。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 2:17–18; 历代志下 31:20–21; 历代志下 34:2"> 因为一个人用智慧、知识和技能所得来的一切，却要留给不劳而获的人享用，这也是虚空，是极大的不幸！</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 127:2; 传道书 1:3; 腓立比书 4:6"> 世人在日光之下劳心劳力，究竟得到什么呢？</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 14:1; 约伯记 5:7; 诗篇 6:6–7"> 他们一生充满痛苦，劳碌中尽是愁烦，即使夜间心里也不安宁。这也是虚空。</span>
<span className="v" id="v24" data-v="24" data-xref="传道书 3:22; 传道书 8:15; 提摩太前书 6:17"> 对人而言，没有什么比吃喝并享受劳碌之乐更好，我看这也是出自上帝的手。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 2:1–12; 列王纪上 4:21–24"> 离了上帝，谁还能吃喝享受呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 约伯记 27:16–17; 箴言 28:8"> 上帝把智慧、知识和喜乐赐给祂喜悦的人，却让罪人忙于积攒财富，然后把他们的财富赐给祂喜悦的人。这也是虚空，也是捕风。</span>

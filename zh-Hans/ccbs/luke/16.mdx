## 善用钱财

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 马太福音 25:14–30; 雅各书 4:3"> 耶稣又对门徒说：“某财主有个管家，有人控告这管家浪费主人的财物。</span>
<span className="v" id="v2" data-v="2" data-xref="传道书 11:9–10; 彼得前书 4:5; 启示录 20:12"> 财主便把管家召来，对他说，‘听说你浪费我的财物，到底是怎么回事？把帐目交代清楚，你不能再当管家了。’</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 5:31; 以赛亚书 10:3; 箴言 18:9"> “管家心里盘算，‘主人要辞退我了，怎么办呢？锄地我没有力气，乞讨我又感到羞耻。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:9; 耶利米书 4:22; 雅各书 3:15"> 我知道该怎么办了！就算被辞退了，也会有人照应我。’</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:41–42; 马太福音 18:24"> 于是，他把欠他主人债的一个一个召来，问第一个，‘你欠了我主人多少？’</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 2:10; 路加福音 16:12; 路加福音 16:9"> “他回答说，‘一百桶油。’<br />“管家说，‘这是你的帐，快坐下，改成五十吧！’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="雅歌 8:11–12; 路加福音 20:9; 路加福音 20:12"> “管家又问另一个，‘你欠多少？’<br />“他回答说，‘一百石麦子。’<br />“管家说，‘这是你的帐，改成八十石吧。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:5; 以弗所书 5:8; 箴言 6:6–8"> “主人夸奖这个不义的管家精明。因为今世的儿女在处理世事方面比光明的儿女更精明。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 19:21; 提摩太前书 6:17–19; 但以理书 4:27"> “我告诉你们，要善用今世<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“今世”希腊文是“不义”。">a</a></sup>的财富，广结朋友。这样，当财富不管用时，他们会接你们到永远的居所。</span>
</div>
</div>

## 见微知著

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:11–12; 马太福音 25:21; 路加福音 19:17"> “一个人在小事上忠心，在大事上也会忠心；在小事上靠不住，在大事上也靠不住。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 12:33; 雅各书 2:5; 箴言 8:18–19"> 如果你们不能忠心地处理今世的财富，谁会把真正的财富交托给你们呢？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 19:13–26; 马太福音 25:14–29; 约伯记 1:21"> 如果你们不能忠心地处理别人的产业，谁会把你们名下的产业交给你们呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 2:15–16; 马太福音 6:24; 雅各书 4:4"> 一个仆人不能服侍两位主人，因为他不是恨这位、爱那位，就是重这位、轻那位。你们不能又事奉上帝，又事奉金钱。”</span>
</div>
</div>

## 警戒贪财的法利赛人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:35; 路加福音 20:47; 耶利米书 6:13"> 法利赛人向来贪财，他们一面听一面嗤笑耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:7; 箴言 21:2; 哥林多前书 4:5"> 耶稣对他们说：“你们在人面前自以为义，但上帝能看透你们的心。因为世人所看重的东西在上帝看来却是可憎的。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 11:9–14; 马太福音 21:32; 使徒行传 3:24–25"> 约翰还没有来以前，律法书和先知书是你们的准则。他出来后，上帝国的福音开始广传，人人都在努力进上帝的国。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:18; 路加福音 21:33; 彼得前书 1:25"> 然而，就是天地都消失，律法的一点一划也不会失效。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 19:9; 马可福音 10:11–12; 马太福音 5:31–32"> 任何人休妻另娶，就是犯通奸罪，娶被休的女子也是犯通奸罪。”</span>
</div>
</div>

## 财主和乞丐

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 16:49; 阿摩司书 6:4–6; 路加福音 18:24–25"> 耶稣又说：“有个财主天天衣着华丽，生活奢侈。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:2; 撒母耳记上 2:8; 雅各书 2:5"> 又有一个名叫拉撒路的乞丐身上长满了脓疮，被人放在财主家门口。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 15:27; 马可福音 7:28; 约翰福音 6:12"> 他渴望吃到财主桌上掉下来的食物残渣，就连狗也来舔他的疮。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:24; 诗篇 49:16–19; 雅各书 1:11"> “后来，乞丐死了，天使带他到亚伯拉罕身边。财主也死了，被人埋葬了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:4; 路加福音 16:28; 马太福音 18:9"> 他在阴间受折磨，抬头远远地看见亚伯拉罕和他身边的拉撒路，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 4:10; 启示录 22:1; 启示录 7:16–17"> 就高喊，‘我的先祖亚伯拉罕啊！求你可怜我，派拉撒路用指尖蘸点水来润润我的舌头吧！我在这火中痛苦不堪。’</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:24; 约翰一书 2:15; 诗篇 17:14"> “亚伯拉罕说，‘孩子啊！你要想想，你生前享福，而拉撒路受苦；如今他在这里得到安慰，而你痛苦不堪。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 3:36; 诗篇 49:14; 诗篇 50:22"> 况且，在你我中间隔着一道深渊，这边的人不能到你那边去，你那边的人也不能到这里来。’</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> “财主说，‘我的先祖啊，那么求你派拉撒路去我父亲家里，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:40; 诗篇 49:12–13; 帖撒罗尼迦前书 4:6"> 因为我有五个弟兄。让拉撒路去警告他们，以免他们也来到这痛苦的地方。’</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:21; 路加福音 24:27; 路加福音 16:16"> “但是亚伯拉罕却说，‘他们可以听从摩西和众先知的话呀！’</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 16:9–11; 路加福音 16:24; 路加福音 13:5"> “财主回答说，‘我的先祖亚伯拉罕啊！他们不会听的。但如果有一个死而复活的人去他们那里，他们肯定会悔改！’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:3; 使徒行传 19:8; 约翰福音 11:43–53"> “亚伯拉罕说，‘如果他们不听从摩西和众先知的话，即使一个人从死里复活，他们也不会信服。’”</span>
</div>
</div>

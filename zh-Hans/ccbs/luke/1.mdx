## 天使预告施洗者约翰出生

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:10; 马太福音 2:1; 尼希米记 12:4"> 犹太王希律执政期间，亚比雅班里有位祭司名叫撒迦利亚，他妻子伊丽莎白是亚伦的后裔。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 7:1; 创世记 17:1; 腓立比书 2:15"> 夫妻二人遵行主的一切诫命和条例，无可指责，在上帝眼中是义人。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:11; 创世记 18:11; 撒母耳记上 1:2"> 但他们没有孩子，因为伊丽莎白不能生育，二人又年纪老迈。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:14; 历代志上 24:19; 历代志下 31:2"> 有一天，轮到撒迦利亚那一班祭司在上帝面前司职，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:11; 出埃及记 30:7–8; 历代志上 23:13"> 他们按照祭司的规矩抽签，抽中撒迦利亚到主的殿里去烧香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:17; 启示录 8:3; 希伯来书 4:14"> 他烧香的时候，众百姓都在外面祷告。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:26–27; 使徒行传 10:3–4; 士师记 13:3"> 那时，主的天使站在香坛的右边向撒迦利亚显现，</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:22; 士师记 6:22; 路加福音 2:9–10"> 撒迦利亚见了，又惊又怕。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 2:21; 使徒行传 10:31; 创世记 25:21"> 天使对他说：“撒迦利亚，不要害怕，你的祷告已蒙垂听。你的妻子伊丽莎白要为你生一个儿子，你要给他取名叫约翰。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 创世记 21:6"> 你必欢喜快乐，许多人也会因为他的诞生而欣喜雀跃，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 民数记 6:2–4; 路加福音 7:33"> 因为他将成为主眼中伟大的仆人。他必滴酒不沾，并且在母腹里就被圣灵充满。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:3–5; 马太福音 21:32; 玛拉基书 3:1"> 他将使许多以色列人回心转意，归顺主——他们的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 4:5–6; 马太福音 11:14; 路加福音 1:76"> 他将以先知以利亚的心志和能力做主的先锋，使父亲的心转向儿女，使叛逆的人转向义人的智慧，为主预备合用的子民。”</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 38:22; 创世记 17:17; 路加福音 1:7"> 撒迦利亚对天使说：“我已经老了，我的妻子也上了年纪，我怎么能确定这件事呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 马太福音 18:10; 但以理书 9:21–23"> 天使回答说：“我是侍立在上帝面前的加百列，奉命来向你报这喜讯。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 3:26; 以西结书 24:27; 路加福音 1:22"> 我说的这些话到时候必定应验。但因为你不肯相信我的话，所以这事成就以前，你会变成哑巴，不能说话。”</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 6:23–27"> 人们在等候撒迦利亚，见他在圣殿里迟迟不出来，都感到奇怪。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 约翰福音 13:24; 使徒行传 21:40"> 后来他出来了，却成了哑巴，不能说话，只能打手势，人们意识到他在圣殿里看见了异象。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 9:25; 列王纪下 11:5–7"> 撒迦利亚供职期满，就回家去了。</span>
<span className="v" id="v24" data-v="24"> 之后，伊丽莎白果然怀了孕，她有五个月闭门不出。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 30:22–23; 以赛亚书 54:1–4; 创世记 21:1–2"> 她说：“主真是眷顾我，除掉了我在人群中的羞耻。”</span>
</div>
</div>

## 天使预告耶稣降生

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 2:23; 路加福音 1:19; 约翰福音 7:41"> 伊丽莎白怀孕六个月的时候，天使加百列又奉上帝的命令到加利利的拿撒勒，</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:18; 以赛亚书 7:14; 马太福音 1:16"> 去见一位叫玛丽亚的童贞女。玛丽亚已经和大卫的后裔约瑟订了婚。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 6:12; 但以理书 10:19; 路加福音 1:30"> 天使到了玛丽亚那里，说：“恭喜你，蒙大恩的女子，主与你同在！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:17; 路加福音 1:12; 使徒行传 10:4"> 玛丽亚听了觉得十分困惑，反复思想这话的意思。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 罗马书 8:31; 路加福音 12:32"> 天使对她说：“玛丽亚，不要害怕，你在上帝面前已经蒙恩了。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 7:14; 马太福音 1:21; 马太福音 1:25"> 听着，你要怀孕生子，并给祂取名叫耶稣。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 9:6–7; 以赛亚书 16:5; 撒母耳记下 7:11–13"> 祂伟大无比，将被称为至高者的儿子，主上帝要把祂祖先大卫的王位赐给祂。</span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 2:44; 希伯来书 1:8; 但以理书 7:13–14"> 祂要永远统治雅各家，祂的国度永无穷尽。”</span>
<span className="v" id="v34" data-v="34" data-xref="士师记 13:8–12; 使徒行传 9:6"> 玛丽亚对天使说：“这怎么可能呢？我还是童贞女。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:18; 约翰福音 1:49; 马太福音 1:20"> 天使回答说：“圣灵要临到你身上，至高者的能力要荫庇你，所以你要生的那圣婴必称为上帝的儿子。</span>
<span className="v" id="v36" data-v="36"> 看啊，你的亲戚伊丽莎白年纪老迈，一向不能生育，现在已经怀男胎六个月了。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:26; 耶利米书 32:27; 马可福音 10:27"> 因为上帝无所不能。”</span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 4:20–21; 诗篇 119:38; 诗篇 116:16"> 玛丽亚说：“我是主的婢女，愿你所说的话在我身上成就。”于是天使离开了她。</span>
</div>
</div>

## 玛丽亚看望伊丽莎白

<div className="bt">
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:65; 约书亚记 15:48–59; 约书亚记 10:40"> 不久，玛丽亚便动身赶往犹太山区的一座城，</span>
<span className="v" id="v40" data-v="40"> 进了撒迦利亚的家，向伊丽莎白请安。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 1:67; 使徒行传 4:8; 路加福音 1:44"> 伊丽莎白一听见玛丽亚的问安，腹中的胎儿便跳动起来，伊丽莎白被圣灵充满，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 1:28; 士师记 5:24; 创世记 22:18"> 高声呼喊：“在妇女中你是最蒙福的！你腹中的孩子也是蒙福的！</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 20:28; 约翰福音 13:13; 路加福音 2:11"> 我主的母亲来探望我，我怎么敢当呢？</span>
<span className="v" id="v44" data-v="44"> 我一听到你问安的声音，腹中的孩子就欢喜跳动。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 20:29; 约翰福音 11:40; 路加福音 11:27–28"> 那相信主所说的话必定实现的女子有福了！”</span>
<span className="v" id="v46" data-v="46" data-xref="撒母耳记上 2:1–10; 诗篇 34:2–3; 诗篇 35:9"> <span className="pl pl-1">玛丽亚说：</span><br /><span className="pl pl-1">“我的心尊主为大，</span><br /></span>

<span className="v" id="v48" data-v="48" data-xref="诗篇 138:6; 玛拉基书 3:12; 哥林多前书 1:26–28"> <span className="pl pl-1">因祂眷顾我这卑微的婢女，</span><br /><span className="pl pl-1">从今以后，</span><br /><span className="pl pl-1">世世代代都要称我是有福的。</span><br /></span>

## 施洗者约翰出生

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="路加福音 1:13; 创世记 21:2–3; 路加福音 2:6–7"> 伊丽莎白的产期到了，生下一个儿子。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:25; 路加福音 1:14; 罗马书 12:15"> 亲戚和邻居听见主向她大施怜悯，都和她一同欢乐。</span>
<span className="v" id="v59" data-v="59" data-xref="创世记 17:12; 利未记 12:3; 腓立比书 3:5"> 到了第八天，他们来给孩子行割礼，想照他父亲的名字给他取名叫撒迦利亚。</span>
<span className="v" id="v60" data-v="60" data-xref="路加福音 1:13; 撒母耳记下 12:25; 路加福音 1:63"> 但伊丽莎白说：“不！要叫他约翰。”</span>
<span className="v" id="v61" data-v="61"> 他们说：“你们家族中没有人用这个名字啊！”</span>
<span className="v" id="v62" data-v="62" data-xref="路加福音 1:22"> 他们便向他父亲打手势，问他要给孩子起什么名字。</span>

<span className="v" id="v64" data-v="64" data-xref="路加福音 1:20; 出埃及记 4:15–16; 以西结书 33:22"> 突然，撒迦利亚可以开口了，舌头也灵活了，便开口赞美上帝。</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 1:39; 使徒行传 5:11; 路加福音 7:16"> 住在周围的人都很惧怕，这消息很快就传遍了整个犹太山区。</span>
<span className="v" id="v66" data-v="66" data-xref="使徒行传 11:21; 路加福音 2:19; 路加福音 2:51"> 听见的人都在想：“这孩子将来会怎样呢？因为主的能力伴随着他。”</span>
</div>

## 撒迦利亚的预言

<div className="bt">
<div className="bp poetry">

<span className="v" id="v68" data-v="68" data-xref="诗篇 106:48; 路加福音 7:16; 诗篇 41:13"> <span className="pl pl-1">“主——以色列的上帝当受称颂，</span><br /><span className="pl pl-1">因祂眷顾、救赎了自己的子民，</span><br /></span>

## 差遣门徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 6:7–13; 路加福音 9:52; 民数记 11:24–26"> 事后，主另外拣选了七十个门徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“七十个门徒”有古卷为“七十二个门徒”。">a</a></sup>，差遣他们两个两个地出去，先到祂将要去的各个城镇和村庄，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36–38; 约翰福音 4:35–38; 哥林多前书 3:6–9"> 并对他们说：“要收割的庄稼很多，工人却很少，因此你们要祈求庄稼的主人派工人去收割祂的庄稼。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:16; 使徒行传 20:29; 以西结书 2:3–6"> “你们去吧！我差你们出去，就像把羊羔送入狼群。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:35; 列王纪下 4:29; 路加福音 10:4–12"> 钱袋、背包和鞋都不要带，在路上也不要与人寒暄。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 25:6; 马太福音 10:12–13; 以赛亚书 57:19"> 无论到哪一户人家，要先说，‘愿平安临到这家！’</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:16; 哥林多后书 2:15–16; 以弗所书 5:6"> 如果那里有配得平安的人，平安必临到那人，否则平安仍归给你们。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 5:17–18; 马太福音 10:10–11; 加拉太书 6:6"> 不要搬来搬去，要固定住在一家，接受那家的款待，因为工人理应得到工钱。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:27; 马太福音 10:40; 路加福音 10:10"> “你们无论到哪一个城镇，如果人们接待你们，就吃他们摆上的饮食。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:2; 约翰福音 3:5; 路加福音 10:11"> 要医治那城里的病人，告诉他们，‘上帝的国临近你们了。’</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 18:6; 马太福音 10:14; 使徒行传 13:51"> 但如果哪一个城镇的人不欢迎你们，你们就到街上宣告，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:9; 使徒行传 13:51; 使徒行传 13:26"> ‘就连你们城里的尘土粘在我们脚上，我们都要擦掉，但是要知道，上帝的国临近了。’</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:15; 马太福音 11:24; 耶利米哀歌 4:6"> 我告诉你们，在审判之日，那城将比所多玛受更重的刑罚！</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 23:1–18; 约珥书 3:4–8; 以西结书 26:1–26"> “哥拉汛啊，你有祸了！伯赛大啊，你有祸了！因为如果把在你们当中所行的神迹行在泰尔和西顿，那里的人早就身披着麻衣、头蒙着灰尘坐在地上悔改了。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 15:22–25; 罗马书 2:1; 路加福音 12:47–48"> 在审判之日，你们将比泰尔和西顿受更重的刑罚！</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 14:13–15; 马太福音 4:13; 路加福音 13:28"> “迦百农啊，你将被提升到天上吗？不！你将被打落到阴间。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 13:20; 马太福音 10:40; 帖撒罗尼迦前书 4:8"> 耶稣继续对门徒说：“谁听从你们，就是听从我；谁拒绝你们，就是拒绝我；谁拒绝我，就是拒绝差我来的那位。”</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:20; 马可福音 16:17; 路加福音 9:1"> 七十个门徒兴高采烈地回来说：“主啊，我们奉你的名甚至降服了鬼魔。”</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 12:7–9; 以赛亚书 14:12; 启示录 9:1"> 耶稣回答说：“我看见撒旦像闪电一样从天上坠下。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 91:13; 马可福音 16:18; 罗马书 16:20"> 我已经给你们权柄，使你们能践踏蛇和蝎子，胜过仇敌一切的权势，没有什么能伤害你们。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:15; 启示录 20:12; 希伯来书 12:23"> 然而，不要为了邪灵向你们降服而高兴，要因你们的名字记录在天上而高兴。”</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 4:3; 马太福音 13:11–16; 马太福音 11:25–27"> 就在这时候，耶稣受圣灵感动，充满喜乐地说：“父啊，天地的主，我颂赞你！因为你把这些事向聪明、有学问的人隐藏起来，却启示给像孩童一般的人。父啊！是的，这正是你的美意。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:27; 约翰福音 1:18; 约翰福音 6:44–46"> 我父将一切交给了我。除了父，没有人认识子；除了子和受子启示的人，没有人认识父。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:16–17"> 随后，耶稣转身单独对门徒说：“谁看到你们今日所看到的，谁就有福了。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 8:56; 希伯来书 11:13; 彼得前书 1:10–12"> 我告诉你们，以前有许多先知和君王渴望看见你们所看见的，听见你们所听见的，却未能如愿。”</span>
</div>
</div>

## 好撒玛利亚人的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:34–39; 路加福音 18:18; 马太福音 19:16–19"> 有一次，一名律法教师站起来试探耶稣，说：“老师，我该做什么才能承受永生呢？”</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 10:5; 以赛亚书 8:20; 加拉太书 3:21–22"> 耶稣反问他：“律法怎么说？你怎么理解？”</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 12:30–31; 马太福音 22:37–40; 申命记 6:5"> 律法教师答道：“‘你要全心、全情、全力、全意爱主你的上帝’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命记6:5。">b</a></sup>，又要‘爱邻如己。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="利未记19:18。">c</a></sup>”</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 20:11; 利未记 18:5; 马太福音 19:17"> 耶稣说：“你答得对，照着做就得生命。”</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 16:15; 罗马书 4:2; 利未记 19:34"> 律法教师想证明自己有理，就问：“那么，谁是我的邻居呢？”</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 88:4; 路加福音 18:31; 耶利米哀歌 2:12"> 耶稣回答说：“有个人从耶路撒冷下去耶利哥，途中被劫。强盗剥了他的衣服，把他打个半死，丢在那里，然后扬长而去。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 3:16–18; 诗篇 69:20; 耶利米书 5:31"> “刚好有位祭司经过，看见那人，连忙从旁边绕过去了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行传 18:17; 诗篇 109:25"> 又有个利未人经过，看见那人，也跟先前那个祭司一样从旁边绕过去了。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:50; 耶利米书 38:7–13; 路加福音 7:13"> “后来，有位撒玛利亚人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="犹太人向来轻视撒玛利亚人，认为他们血统不纯正，因此互不往来。">d</a></sup>经过，看见那人，就动了慈心，</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 12:20; 诗篇 147:3; 帖撒罗尼迦前书 5:15"> 连忙上前用油和酒替他敷伤口，包扎妥当，然后把他扶上自己的牲口，带到附近的客店照料。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; 路加福音 14:13; 罗马书 16:23"> 次日还交给店主两个银币，说，‘请好好照顾这个人。如果钱不够的话，等我回来再补给你。’</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 7:42; 马太福音 21:28–31; 马太福音 17:25"> 那么，你认为这三个人中谁是被劫者的邻居呢？”</span>
<span className="v" id="v37" data-v="37" data-xref="约翰一书 3:16–18; 弥迦书 6:8; 彼得前书 2:21"> 律法教师说：“是那个同情他的人。” 耶稣说：“你去照样做吧。”</span>
</div>
</div>

## 上好的福分

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:19–20; 约翰福音 11:1–5; 约翰福音 12:1–3"> 耶稣和门徒去耶路撒冷的途中路过一个村庄，遇到一位名叫玛大的女子接待他们到家里作客。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; 路加福音 8:35; 约翰福音 12:3"> 玛大的妹妹玛丽亚坐在主的脚前听道，</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:27; 路加福音 12:29; 马太福音 14:15"> 玛大为了招待客人忙乱不已，于是上前对耶稣说： “主啊，我妹妹让我一个人伺候，你都不管吗？请你叫她来帮帮我吧。”</span>
<span className="v" id="v41" data-v="41" data-xref="腓立比书 4:6; 路加福音 21:34; 马太福音 6:25–34"> 耶稣对她说：“玛大，玛大，你为太多事情忧虑烦恼。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 27:4; 诗篇 16:5–6; 约翰福音 10:27–28"> 其实最要紧的事只有一件，玛丽亚选择了上好的，是夺不走的。”</span>
</div>

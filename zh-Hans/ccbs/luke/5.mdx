## 呼召门徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 马可福音 3:9"> 一天，耶稣站在革尼撒勒湖边，众人拥挤着祂，要听上帝的道。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:19; 马太福音 4:21"> 祂看见湖边停着两条船，渔夫离了船正在洗网，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:18; 马太福音 13:1–2; 约翰福音 1:41–42"> 就上了西门的那条船，请西门把船稍微划离岸边，然后坐在船上教导众人。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 21:6; 马太福音 17:27"> 耶稣讲完之后对西门说：“把船划到水深的地方去撒网捕鱼。”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:5; 约翰福音 15:14; 路加福音 6:46–48"> 西门说：“老师，我们劳碌了一整夜，一无所获。既然你这样吩咐，我就撒网。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 15:58; 约翰福音 21:6–11; 传道书 11:6"> 他们把网撒下去，果然捕获很多鱼，网差点被撑破了。</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 6:2; 腓立比书 4:3; 使徒行传 11:25"> 他们便招呼另一条船上的同伴来帮忙，他们就过来一起把两条船都装满了鱼，船几乎要沉下去了。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 6:5; 约伯记 42:5–6; 启示录 1:17"> 西门·彼得见状便跪倒在耶稣膝前说：“主啊，离开我，我是个罪人！”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; 诗篇 8:8; 马可福音 9:6"> 他和所有同伴对捕到这么多鱼感到非常惊讶，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 马太福音 13:47; 以西结书 47:9–10"> 包括西庇太的两个儿子雅各和约翰。耶稣对西门说：“不要怕，从今以后，你将成为得人的渔夫。”</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 4:20; 路加福音 5:28; 马太福音 19:27"> 于是他们把船靠岸后，撇下一切跟从了耶稣。</span>
</div>
</div>

## 洁净麻风病人

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 50:15; 路加福音 17:16; 马太福音 8:2–4"> 有一次，耶稣在一个小镇遇见一个浑身患麻风病的人，那人一看见耶稣，就俯伏在地上恳求说：“主啊，如果你肯，就能使我洁净。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 约翰福音 4:50–53; 何西阿书 14:4"> 耶稣伸手摸他，说：“我肯，你洁净了吧！”他身上的麻风病立刻消失了。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 14:2–32; 路加福音 17:14; 马可福音 1:44"> 耶稣又嘱咐他：“不要把这事告诉别人，要去让祭司察看你的身体，照摩西的规定献祭，向众人证明你已经洁净了。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:30–31; 路加福音 12:1; 马可福音 1:45–2"> 结果耶稣的名声传得更广了，成群的人聚集到祂那里听祂讲道、求祂医病。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 马可福音 1:35–36; 马太福音 14:23"> 不过，祂还是常常退到旷野去祷告。</span>
</div>
</div>

## 叫瘫痪的行走

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 马太福音 11:5"> 有一天，耶稣在教导人，旁边坐着来自加利利和犹太各乡村，以及耶路撒冷的法利赛人和律法教师，主的能力伴随着耶稣，使祂能治病。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 2:3–12; 马太福音 9:2–8; 约翰福音 5:5–6"> 有人用担架抬着一个瘫痪的想进到屋里，把他放在耶稣面前。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 2:4; 马太福音 10:27; 马太福音 24:17"> 可是人太多了，他们抬不进去，就爬上屋顶，掀开瓦片，把那病人连同担架缒到耶稣面前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 14:9; 马太福音 9:2; 马可福音 2:5"> 耶稣看见他们的信心，就对那人说：“朋友，你的罪得到赦免了！”</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 43:25; 马可福音 2:6–7; 路加福音 7:49"> 那些律法教师和法利赛人开始议论起来：“这个说话亵渎上帝的人是谁啊？除了上帝以外，谁能赦罪呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; 以赛亚书 66:18; 诗篇 139:2"> 耶稣知道他们的想法，就问：“你们为什么心里议论呢？</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 2:9; 马太福音 9:5"> 说‘你的罪得到赦免了’容易呢，还是说‘你起来行走’容易呢？</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 1:13; 以赛亚书 53:11; 路加福音 8:54"> 如今我要让你们知道人子在世上有赦罪的权柄。”于是对瘫痪的人说：“我吩咐你起来！拿上你的担架回家去吧。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 9:24; 路加福音 5:13; 诗篇 107:20–22"> 那人立刻当众站了起来，拿起他躺卧的担架回家去了，不住地赞美上帝。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 9:8; 马太福音 12:23; 路加福音 7:16"> 众人都十分惊奇，一同赞美上帝，心里充满了敬畏，说：“今天我们看到奇事了！”</span>
</div>
</div>

## 呼召利未

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 2:13–22; 马太福音 9:9–17; 约翰福音 1:43"> 后来耶稣外出时，看见一个名叫利未的税吏坐在收税站里，就对他说：“跟从我！”</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 马太福音 19:22–27; 列王纪上 19:19–21"> 利未就起来，撇下一切跟从了耶稣。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 2:15; 路加福音 15:1; 哥林多前书 10:27"> 随后，他在家设宴款待耶稣，赴宴的人中有许多税吏和其他人。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:28–32; 路加福音 5:17; 马可福音 7:3"> 法利赛人和律法教师就向耶稣的门徒抱怨说：“你们为何跟税吏和罪人一起吃喝？”</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 2:17; 马太福音 9:12–13; 耶利米书 8:22"> 耶稣答道：“健康的人不需要医生，有病的人才需要。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前书 1:15–16"> 我来不是召义人悔改，而是召罪人悔改。”</span>
</div>
</div>

## 论禁食

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 9:14–17; 马可福音 2:18–22; 约翰福音 3:25"> 他们说：“约翰的门徒常常禁食祷告，法利赛人的门徒也是一样，可是你的门徒却又吃又喝。”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 3:29; 哥林多后书 11:2; 以赛亚书 54:5"> 耶稣说：“新郎和宾客还在一起的时候，岂能让宾客禁食？</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行传 14:23; 使徒行传 3:21"> 但有一天新郎将被带走，那时他们就要禁食了。”</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 9:16–17; 马可福音 2:21–22; 哥林多后书 6:16"> 耶稣又给他们讲了一个比喻，说：“没有人会从新衣服上撕下一块布来，补在旧衣服上。否则，不但新衣服撕破了，旧衣服和新补丁也不相称。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 9:13; 诗篇 119:83; 约书亚记 9:4"> 也没有人把新酒装在旧皮囊里，否则新酒会把旧皮囊胀破，酒也漏了，皮囊也毁了。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 8:8–13; 哥林多后书 5:17; 以西结书 36:26"> 所以新酒一定要装在新皮囊里。</span>
<span className="v" id="v39" data-v="39" data-xref="希伯来书 11:39; 马可福音 7:7–13; 耶利米书 6:16"> 没有人喝过陈酒以后想喝新酒，因为人都说陈酒好。”</span>
</div>
</div>

## 百夫长的信心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:5–13; 路加福音 7:1–10; 马太福音 7:28–29"> 耶稣向众人讲完道后，进了迦百农。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:2–3; 创世记 24:27; 约翰福音 4:46–47"> 当时，有一个百夫长很赏识的奴仆病了，生命垂危。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 8:5; 约翰福音 4:47; 路加福音 9:38"> 百夫长听说耶稣的事，就托几位犹太人的长老去请耶稣来医治他的奴仆。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 马太福音 10:11; 路加福音 7:6–7"> 他们便来恳求耶稣，说：“这位百夫长值得你帮助，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 2:11–12; 历代志上 29:3–9; 列王纪上 5:1"> 因为他爱我们的同胞，为我们建造会堂。”</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 5:24; 创世记 32:10; 雅各书 4:6"> 耶稣就跟他们去了。 快抵达时，那百夫长又请几位朋友去见耶稣，对祂说：“主啊，不用劳驾，你亲临舍下，我不敢当。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 107:20; 诗篇 33:9; 路加福音 4:36"> 我自认不配去见你的面，只要你说一句话，我仆人就会痊愈。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:22; 使徒行传 23:17; 使徒行传 22:25–26"> 因为我有上司，也有部下。我命令这个部下去，他就去；要那个部下来，他就来。我吩咐奴仆做什么，他就做什么。”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 15:28; 罗马书 3:1–3; 马太福音 8:10"> 耶稣听了这番话，感到惊奇，转身对跟随祂的众人说：“我告诉你们，就是在以色列，我也从未见过信心这么大的人。”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:50–53; 马太福音 8:13; 马太福音 15:28"> 派去的几位朋友回到百夫长家里，发现那奴仆已经痊愈了。</span>
</div>
</div>

## 寡妇的独子起死回生

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 10:38"> 过了不久<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“过了不久”有古卷作“次日”。">a</a></sup>，耶稣去拿因城，随行的有门徒和一大群人。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王纪上 17:9"> 耶稣快到城门口时，从城里走出一队送殡的人，死者是一个寡妇的独子，有许多城中的人陪着她。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:13; 以赛亚书 63:9; 诗篇 86:15"> 主看见那寡妇，怜悯之心油然而生，就对她说：“不要哭！”</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:25; 约翰福音 11:43–44; 使徒行传 9:40–41"> 随即上前按住棺架，抬的人停了下来。耶稣说：“年轻人，我吩咐你起来！”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 列王纪下 4:32–37; 列王纪上 17:23–24"> 那死者就坐了起来，并开口说话。耶稣把他交给他母亲。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 人们都惊惧万分，把荣耀归给上帝，说：“我们中间出了一位大先知！”又说：“上帝眷顾了祂的子民！”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 4:24; 马可福音 6:14; 马太福音 9:26"> 有关祂的这消息传遍了犹太和附近地区。</span>
</div>
</div>

## 施洗者约翰的疑问

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:26; 马太福音 11:2–19"> 约翰从自己的门徒那里获悉这些事后，</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:6–7; 约翰福音 4:25; 创世记 22:18"> 就叫了两个门徒来，派他们去问主：“将要来的那位就是你吗？还是我们要等别人呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 他们来到耶稣面前，便问：“施洗者约翰派我们来请教你，‘将要来的那位就是你吗？还是我们要等别人呢？’”</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:10; 诗篇 90:7–9; 希伯来书 12:6"> 那时，耶稣刚治好了许多患各种疾病和被邪灵附身的人，又使许多瞎眼的能看见。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 35:5–6; 以赛亚书 61:1–3; 路加福音 4:18"> 耶稣回答说：“你们回去把所见所闻告诉约翰，就是瞎眼的看见，瘸腿的走路，麻风病人得洁净，耳聋的听见，死人复活，穷人听到福音。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 11:6; 彼得前书 2:7–8; 罗马书 9:32–33"> 凡对我笃信不疑的人有福了！”</span>
</div>
</div>

## 耶稣称赞施洗者约翰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以弗所书 4:14; 约翰福音 1:23; 路加福音 1:80"> 约翰的门徒离去后，耶稣对众人谈论约翰，说：“你们从前去旷野要看什么呢？看随风摇动的芦苇吗？</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 59:17; 以斯帖记 8:15; 以斯帖记 1:3"> 如果不是，你们出去到底想看什么？是看穿绫罗绸缎的人吗？那些衣着华丽、生活奢侈的人住在王宫里。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 约翰福音 5:35; 路加福音 20:6"> 你们出去究竟想看什么？看先知吗？是的，我告诉你们，他不只是先知。</span>
<span className="v" id="v27" data-v="27" data-xref="玛拉基书 3:1; 路加福音 1:76; 马可福音 1:2"> 圣经上说，‘看啊，我要差遣我的使者在你前面为你预备道路。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="玛拉基书3:1。">b</a></sup>这里所指的就是约翰。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 13:16–17; 马太福音 11:11; 歌罗西书 1:25–27"> 我告诉你们，凡妇人所生的，没有一个比约翰大，但上帝国中最微不足道的也比他大。”</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行传 18:25"> 众百姓和税吏听了这番话，都承认上帝是公义的，因为他们接受了约翰的洗礼。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多后书 6:1; 马太福音 22:35"> 但那些法利赛人和律法教师没有接受约翰的洗礼，拒绝了上帝为他们所定的旨意。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 11:16–19; 耶利米哀歌 2:13; 马可福音 4:30"> 主又说：“我用什么来比拟这个世代的人呢？他们像什么呢？</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 11:16–19; 耶利米书 5:3–5; 箴言 17:16"> 他们就如孩童坐在集市上彼此呼喊，<br /><span className="pl pl-1">“‘我们吹娶亲的乐曲，</span><br /><span className="pl pl-1">你们不跳舞；</span><br /><span className="pl pl-1">我们唱送葬的哀歌，</span><br /><span className="pl pl-1">你们不哭泣。’</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 马可福音 1:6; 约翰福音 8:52"> 施洗者约翰来了，不吃饼，不喝酒，你们就说他被鬼附身；</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 约翰福音 12:2"> 人子来了，又吃又喝，你们就说，‘看啊，祂是个贪吃好酒之徒，与税吏和罪人为友！’</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 马太福音 11:19; 何西阿书 14:9"> 然而，智慧通过所有顺从智慧的人显明为义。”</span>
</div>
</div>

## 罪妇的悔改

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:3–9; 马太福音 26:5–6; 路加福音 14:1"> 有一个法利赛人请耶稣到他家里吃饭，耶稣应邀赴宴。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 14:3–9; 马太福音 26:6–13; 马太福音 21:31"> 那城里住着一个罪恶的女人。她听说耶稣在那法利赛人家里吃饭，就带了一玉瓶香膏进去。</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 126:5–6; 诗篇 51:17; 创世记 18:4"> 她站在耶稣背后，挨着祂的脚哭，泪水滴湿了祂的脚，就用自己的头发擦干，又连连亲祂的脚，并抹上香膏。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 马可福音 7:21"> 邀请耶稣的法利赛人看在眼里，心想：“这人如果是先知，就该知道摸祂的是谁，是个什么样的女人，她是个罪人。”</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 16:19; 路加福音 5:31; 以西结书 33:31"> 耶稣对他说：“西门，我有话跟你说。” 西门答道：“老师，请说。”</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 罗马书 5:20; 马太福音 18:28"> 耶稣说：“有一个债主借给一个人五百个银币，又借给另一个人五十个银币。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 9:18–19; 歌罗西书 3:13; 罗马书 3:24"> 二人都没有能力还债，这位债主就免了他们的债务。那么，哪一位会更爱债主呢？”</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 116:16–18; 提摩太前书 1:13–16; 路加福音 7:47"> 西门答道：“我相信是那个被免去更多债的人。” 耶稣说：“你判断得对！”</span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前书 5:10; 士师记 19:21; 创世记 18:4"> 随后祂转向那女人，继续对西门说：“你看见这女人了吗？我到你家里来，你没有拿水给我洗脚，这女人却用眼泪湿了我的脚，还用头发擦干。</span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳记下 15:5; 撒母耳记下 19:39; 罗马书 16:16"> 你没有亲吻我，但我进来以后，这女人却不停地吻我的脚。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 23:5; 传道书 9:8; 马太福音 6:17"> 你没有用油为我抹头，这女人却用香膏抹我的脚。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰一书 4:19; 约翰一书 3:18; 以赛亚书 1:18"> 所以我告诉你，她许多的罪都被赦免了，因此她的爱深切；那些获得赦免少的，他们的爱也少。”</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 9:2; 马可福音 2:5; 路加福音 5:20"> 耶稣对那女人说：“你的罪都被赦免了。”</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 马太福音 9:3; 马可福音 2:7"> 同席的人彼此议论说：“这人是谁？竟然能赦免人的罪！”</span>
<span className="v" id="v50" data-v="50" data-xref="马可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 耶稣又对那女人说：“你的信心救了你，平安地走吧！”</span>
</div>

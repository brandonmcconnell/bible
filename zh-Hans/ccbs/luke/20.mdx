## 质问耶稣的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:23–27; 路加福音 19:47–48; 使徒行传 6:12"> 有一天，耶稣正在圣殿里教导人、传讲福音，祭司长、律法教师和长老上前来，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:14; 马可福音 11:28–33; 约翰福音 2:18"> 质问祂：“告诉我们，你凭什么权柄做这些事？谁授权给你了？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 15:2–3; 路加福音 22:68; 歌罗西书 4:6"> 耶稣回答说：“我也问你们一个问题。你们告诉我，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 马太福音 11:7–19; 马太福音 17:11–12"> 约翰的洗礼是从天上来的，还是从人间来的？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:34; 约翰福音 1:15–18; 约翰福音 1:30"> 他们彼此议论说：“如果我们说‘是从天上来的’，祂一定会问，‘那你们为什么不信他？’</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:26; 马太福音 11:9; 约翰福音 10:41"> 如果我们说‘是从人间来的’，百姓会拿石头打死我们，因为他们相信约翰是先知。”</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:14; 彼得后书 3:3; 以赛亚书 41:28"> 于是，他们回答说：“我们不知道是从哪里来的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 马太福音 21:27; 马可福音 11:33"> 耶稣说：“我也不告诉你们我凭什么权柄做这些事。”</span>
</div>
</div>

## 利欲熏心的佃户

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 21:33–46; 马可福音 12:1–12; 以赛亚书 5:1–7"> 接着耶稣对众人讲了个比喻：“有人开垦了一个葡萄园，把园子租给佃户，就出远门了。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 尼希米记 9:26; 马太福音 21:34–36"> 到了收获的季节，他派奴仆去葡萄园向佃户收取他的那份果实，佃户却把奴仆打了一顿，使他空手而归。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿书 10:1; 希伯来书 11:36–37; 帖撒罗尼迦前书 2:2"> 园主又派另一个奴仆去，他们照样将他殴打并羞辱一番，使他空手而归。</span>
<span className="v" id="v12" data-v="12"> 园主又派第三个奴仆去，他们又把他打伤，抛在园外。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 3:17; 约翰福音 3:16–17; 耶利米书 36:7"> “园主说，‘我该怎样办呢？不如叫我所疼爱的儿子去吧。他们大概会尊重他。’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:17; 希伯来书 1:2; 使徒行传 2:23"> “可是那些佃户看见园主的儿子，就彼此商量说，‘这是产业继承人，我们杀掉他，产业就归我们了！’</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:12; 马可福音 12:6–9; 马太福音 21:37–40"> 于是他们把园主的儿子扔到葡萄园外杀了。<br />“那么，园主会怎样处置他们呢？</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行传 13:46; 马太福音 21:41"> 他必来杀掉这些佃户，把葡萄园租给别人。”<br />众人听了就说：“但愿这种事永远不会发生！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="诗篇 118:22; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣定睛看着他们，问道：“那么，圣经上说，<br /><span className="pl pl-1">“‘工匠丢弃的石头已成了房角石’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇118:22。">a</a></sup><br /><span className="pl pl-1">，</span><br />这句话是什么意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 8:14–15; 撒迦利亚书 12:3; 但以理书 2:44–45"> 凡跌在这石头上的人，都会粉身碎骨；这石头落在谁身上，会把谁砸烂。”</span>
</div>
</div>

## 纳税问题

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 马太福音 21:45–46"> 律法教师和祭司长听出这比喻是针对他们说的，便想立刻下手捉拿耶稣，但又害怕百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 马太福音 22:15–22; 马太福音 27:2"> 于是，他们严密监视耶稣，又派遣密探假装好人，想从祂的话里找把柄，好把祂交给总督处置。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦前书 2:4–5; 马太福音 26:49–50; 马太福音 22:16"> 那些密探问耶稣：“老师，我们知道你所讲所传的道都是正确的，也知道你不徇情面，而是按真理传上帝的道。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 9:37; 马可福音 12:14–17; 使徒行传 5:37"> 那么，我们向凯撒纳税对不对呢？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:18; 哥林多前书 3:19; 路加福音 5:22"> 耶稣看破他们的阴谋，</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:28; 使徒行传 11:28; 使徒行传 26:32"> 就叫他们拿一个银币来，问他们：“上面刻的是谁的像和名号？”他们说：“凯撒的。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 13:6–7; 马可福音 12:17; 彼得前书 2:13–17"> 耶稣说：“属于凯撒的，要给凯撒；属于上帝的，要给上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多书 1:10"> 耶稣的回答令他们惊奇，他们无法当众找到把柄，只好闭口不言。</span>
</div>
</div>

## 论死人复活

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:1–2; 哥林多前书 15:12; 马可福音 12:18–27"> 撒督该人向来不相信有复活的事。有几个这一派的人来问耶稣：</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 25:5–10; 创世记 38:8; 创世记 38:11"> “老师，按摩西为我们写的律例，如果有人娶妻后没有孩子就死了，他的兄弟当娶嫂嫂，替哥哥传宗接代。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:20; 耶利米书 22:30"> 有弟兄七人，老大结了婚，没有孩子就死了。</span>
<span className="v" id="v30" data-v="30"> 二弟、</span>
<span className="v" id="v31" data-v="31"> 三弟、一直到七弟都相继娶了嫂嫂，都没有留下孩子就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="传道书 1:4; 传道书 9:5; 希伯来书 9:27"> 最后那女人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 22:24–28; 马可福音 12:19–23"> 那么，到复活的时候，她将是谁的妻子呢？因为七个人都娶过她。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯来书 13:4"> 耶稣说：“今世的人才有嫁娶，</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 1:5; 约翰福音 5:29; 但以理书 12:2–3"> 但那些配得将来的世界、从死里复活的人不娶也不嫁，</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 21:4; 腓立比书 3:21; 马太福音 22:30"> 就像天使一样永远不会死。他们既然从死里复活，就是上帝的儿女。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 3:2–6; 马可福音 12:26–27; 使徒行传 7:30–32"> 在火中荆棘的记载中，摩西也证实死人会复活，因为他称主是‘亚伯拉罕的上帝，以撒的上帝，雅各的上帝’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及记3:6。">b</a></sup>。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:25–26; 歌罗西书 3:3–4; 罗马书 6:10–11"> 上帝不是死人的上帝，而是活人的上帝。因为在祂那里的人都是活人。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 23:9; 马可福音 12:28–34; 马太福音 22:34–40"> 几位律法教师说：“老师答得好！”</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 22:46; 马可福音 12:34; 箴言 26:5"> 此后，再没人敢用问题刁难耶稣。</span>
</div>
</div>

## 论基督

<div className="bt">
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="马可福音 12:35–37; 马太福音 1:1; 马太福音 22:41–45"> 耶稣问他们：“人怎么说基督是大卫的后裔呢？</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 110:1; 使徒行传 2:34–35; 希伯来书 1:13"> 大卫自己曾在诗篇里说，<br /><span className="pl pl-1">“‘主对我主说，</span><br /><span className="pl pl-1">你坐在我的右边，</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 19:27; 诗篇 110:1; 启示录 19:14–21"> <span className="pl pl-1">等我使你的仇敌成为你的脚凳。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇110:1。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="启示录 22:16; 路加福音 1:31–35; 马太福音 1:23"> 既然大卫称基督为主，基督又怎么会是大卫的后裔呢？”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 15:10; 马可福音 12:38–39; 马可福音 8:34"> 大家正听的时候，耶稣对门徒说：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 马可福音 12:38–39; 路加福音 14:7"> “你们要提防律法教师。他们爱穿着长袍招摇过市，喜欢人们在大街上问候他们，又喜欢会堂里的上座和宴席中的首位。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 12:40; 雅各书 3:1; 提多书 1:16"> 他们侵吞寡妇的家产，还假意做冗长的祷告。这种人必受到更严厉的惩罚！”</span>
</div>
</div>

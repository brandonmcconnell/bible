## 论罪、信心和本分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:7; 罗马书 14:13; 哥林多前书 11:19"> 耶稣教导门徒说：“引人犯罪的事是免不了的，但引人犯罪的人有祸了。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 9:42; 马太福音 18:14; 马太福音 18:3–6"> 谁使一个卑微的人失足犯罪，他的下场比把大磨石拴在他脖子上扔到海里还要惨。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 19:17; 马太福音 18:21; 马太福音 18:15–17"> 你们要小心谨慎！你的弟兄若犯了罪，要责备他。他若悔改，要饶恕他。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12–13; 马太福音 18:21–22; 罗马书 12:20"> 就算他一天得罪你七次，每次都对你说，‘我悔改’，你都要饶恕他。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 9:24; 希伯来书 12:2; 腓立比书 4:13"> 使徒对主说：“请你加添我们的信心。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:20; 马太福音 21:21; 马可福音 9:23"> 主说：“你们若有芥菜种那么大的信心，就算叫这棵桑树连根拔起，栽在大海里，它也会服从你们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:11; 路加福音 13:15; 路加福音 14:5"> “你们谁会对种田或放羊回来的奴仆说，‘请赶快坐下来吃饭’？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 创世记 43:16; 撒母耳记下 12:20"> 不都是吩咐他‘给我准备晚饭，束上腰带伺候我，等我吃喝完毕，你才可以吃喝’吗？</span>
<span className="v" id="v9" data-v="9"> 奴仆照着吩咐去做，主人会谢他吗？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 9:16–17; 约伯记 22:2–3; 彼得前书 5:5–6"> 同样，你们按吩咐把所有事情办妥后，也该这样说，‘我们是无用的奴仆，所做的不过是分内的事。’”</span>
</div>
</div>

## 十个麻风病人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 约翰福音 4:3–4"> 耶稣继续前往耶路撒冷，途经撒玛利亚和加利利的交界处。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 13:45–46; 路加福音 5:12; 列王纪下 7:3"> 祂进入一个村庄时，十个麻风病人迎面而来。他们远远地站着，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:22; 马太福音 20:30–31; 马太福音 9:27"> 高声呼喊道：“耶稣，老师啊，求你可怜我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未记 13:1–46; 列王纪下 5:14"> 耶稣看见他们，就说：“去让祭司察看你们的身体。”<br />他们去的时候，就洁净了。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 30:11–12; 诗篇 103:1–4; 诗篇 118:18–19"> 其中一个发现自己痊愈了，就跑回来，高声赞美上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 8:5–25; 马太福音 10:5; 启示录 19:10"> 又俯伏在耶稣的脚前连连称谢。这人是撒玛利亚人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 诗篇 106:13; 创世记 3:9"> 耶稣说：“被洁净的不是有十个人吗？其他九个呢？</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 50:23; 马太福音 15:24–28; 诗篇 106:13"> 回来赞美称颂上帝的只有这个外族人吗？”</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 马可福音 10:52"> 于是祂对那人说：“起来回去吧！你的信心救了你。”</span>
</div>
</div>

## 上帝国的降临

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 18:36; 路加福音 19:11; 但以理书 2:44"> 法利赛人问耶稣：“上帝的国什么时候降临？”<br />耶稣回答说：“上帝国的降临并没有看得见的征兆。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:28; 罗马书 14:17; 马可福音 13:21"> 没有人能说，‘看啊，上帝的国在这里！’或说，‘在那里！’因为上帝的国就在你们当中<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“在你们当中”或作“在你们里面”。">a</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 5:35; 马太福音 9:15; 约翰福音 8:21–24"> 祂又对门徒说：“时候将到，你们将渴望见到人子降临的日子，可是你们却见不到。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 马太福音 24:23–26; 路加福音 17:21"> 有人将对你们说，‘看啊，祂在这里！’或说，‘看啊，祂在那里！’你们不要出去，也不要追随他们。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 24:27; 马太福音 24:30; 玛拉基书 4:1–2"> 因为人子降临的时候必如划过长空的闪电，从天这边一直照到天那边。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 16:21; 路加福音 9:22; 马可福音 8:31"> 但祂必须先受许多苦，被这个世代弃绝。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:37–39; 路加福音 17:24; 创世记 7:7–23"> “人子降临时的情形将像挪亚的时代，</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒罗尼迦前书 5:1–3; 路加福音 16:19–23"> 人们吃喝嫁娶，一直到挪亚进方舟那天，洪水来了，把他们全毁灭了；</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 16:49–50; 创世记 18:20–21; 雅各书 5:1–5"> 又像罗得的时代，人们吃喝、买卖、耕地、盖房。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 2:6; 西番雅书 2:9; 犹大书 1:7"> 在罗得离开所多玛那天，烈火和硫磺从天而降，把他们全毁灭了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 1:7; 帖撒罗尼迦后书 1:7; 启示录 1:7"> “人子显现之日的情形也是如此。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 21:21; 马可福音 13:14–16; 耶利米书 45:5"> 那天，在屋顶上的，不要下来拿屋内的东西；田间的人也不要回家。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 19:26; 希伯来书 10:38–39; 彼得后书 2:18–22"> 你们要记住罗得妻子的事。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:35–37; 马太福音 10:39; 约翰福音 12:25"> 凡想保全生命的，必丧失生命；凡丧失生命的，必保全生命。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 24:40–41; 彼得后书 2:9; 玛拉基书 3:16–18"> 我告诉你们，那天晚上，两个人睡在一张床上，一个将被接去，一个将被撇下；</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:41; 出埃及记 11:5; 士师记 16:21"> 两个女人一起推磨，一个将被接去，一个将被撇下；</span>
<span className="v" id="v36" data-v="36"> 两个人在田间，一个将被接去，一个将被撇下。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷无36节。">b</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马太福音 24:28; 约伯记 39:29–30; 启示录 19:17–18"> 门徒问：“主啊，在哪里有这事呢？”<br />耶稣回答说：“尸体在哪里，秃鹰就会聚集在哪里。”</span>
</div>
</div>

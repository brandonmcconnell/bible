## 安息日的主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 马太福音 12:1–8"> 有一个安息日，耶稣和门徒经过一片麦田，门徒掐些麦穗用手搓着吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:2; 约翰福音 5:16; 约翰福音 5:9–11"> 有些法利赛人说：“你们为什么做安息日不准做的事？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 马可福音 2:25–26; 马太福音 12:3–5"> 耶稣答道：“你们没有读过大卫的事迹吗？当时大卫和随从饿了，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9"> 他进入上帝的殿，拿了献给上帝的供饼。这饼只有祭司才可以吃，大卫不但自己吃了，还分给他的随从吃。”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 2:27; 启示录 1:10; 马可福音 9:7"> 耶稣又对他们说：“人子是安息日的主。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 3:1–6; 马太福音 12:9–14; 路加福音 4:31"> 又有一个安息日，耶稣进入会堂教导人，那里有一个右手萎缩的人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; 诗篇 38:12; 路加福音 13:14"> 律法教师和法利赛人监视耶稣，看祂会不会在安息日治病，好找借口控告祂。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 42:4; 马太福音 9:4; 路加福音 5:22"> 耶稣知道他们的心思，就对那个右手萎缩的人说：“起来，站在中间！”那人就起来站在那里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:4; 马太福音 12:12–13; 路加福音 14:3"> 耶稣问众人：“我问你们，在安息日应该行善呢，还是作恶呢？救人呢，还是害人呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:6–7; 马可福音 3:5; 约翰福音 5:8"> 祂环视众人，然后对那人说：“把手伸出来！”那人的手一伸就复原了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 2:1–2; 使徒行传 5:33; 传道书 9:3"> 但法利赛人和律法教师却怒火中烧，开始商议对付耶稣的办法。</span>
</div>
</div>

## 拣选十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 5:7; 马可福音 6:46; 马可福音 1:35"> 一天，耶稣出去到山上整夜向上帝祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 3:13–19; 马太福音 9:36–4; 启示录 21:14"> 天明时分，祂召集门徒，从中选出十二人立为使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:13; 马太福音 4:21; 马太福音 4:18"> 他们是：西门——耶稣给他取名叫彼得、西门的兄弟安得烈、雅各、约翰、腓力、巴多罗买、</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 9:9; 马可福音 3:18; 使徒行传 1:13"> 马太、多马、亚勒腓的儿子雅各、激进党人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当时激进的民族主义者，常以行动反抗统治他们的罗马政府。">a</a></sup>西门、</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:22; 约翰福音 6:70–71; 马可福音 3:18"> 雅各的儿子犹大和出卖耶稣的加略人犹大。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:21; 马太福音 4:23–25; 诗篇 107:17–20"> 耶稣和他们下了山，站在一处平地上，身边有一大群门徒，还有大批从犹太、耶路撒冷以及泰尔和西顿沿海地区来的人，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:15; 马太福音 15:22; 使徒行传 5:16"> 要听祂讲道，盼望祂医治他们的疾病。那些被污鬼缠身的人也得到了医治。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 14:36; 马可福音 3:10; 使徒行传 5:15–16"> 众人都想去摸祂，因为有能力从祂身上发出来，治好了所有人。</span>
</div>
</div>

## 论四福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:5; 路加福音 6:20–24; 哥林多后书 8:9"> 耶稣抬头望着门徒，对他们说：<br /><span className="pl pl-1">“贫穷的人有福了，</span><br /><span className="pl pl-1">因为上帝的国属于你们！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 6:35; 马太福音 5:6; 雅各书 1:12"> <span className="pl pl-1">现在饥饿的人有福了，</span><br /><span className="pl pl-1">因为你们将得饱足！</span><br /><span className="pl pl-1">现在哀哭的人有福了，</span><br /><span className="pl pl-1">因为你们将要欢笑！</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:10–12; 马太福音 10:22; 彼得前书 4:12–16"> 你们为人子的缘故遭人憎恨、弃绝、侮辱、毁谤，就有福了！</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:41; 启示录 21:7; 启示录 3:12"> 那时你们要欢喜雀跃，因为你们在天上有大赏赐！他们的祖先也曾这样恶待以前的先知。</span>
</div>
</div>

## 论四祸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:2; 雅各书 5:1–6; 诗篇 49:6–7"> <span className="pl pl-1">“富有的人有祸了，</span><br /><span className="pl pl-1">因为你们已经享尽了人世间的安逸！</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 65:13; 雅各书 4:9; 箴言 14:13"> <span className="pl pl-1">现在饱足的人有祸了，</span><br /><span className="pl pl-1">因为你们将要挨饿！</span><br /><span className="pl pl-1">现在欢笑的人有祸了，</span><br /><span className="pl pl-1">因为你们将要哀哭！</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:19; 雅各书 4:4; 马太福音 7:15"> <span className="pl pl-1">人人都夸赞你们的时候，</span><br /><span className="pl pl-1">你们就有祸了，</span><br /><span className="pl pl-1">因为他们的祖先也是这样夸赞假先知！</span></span>
</div>
</div>

## 论爱仇敌

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 5:15; 路加福音 6:35; 罗马书 12:17–21"> “但是，我告诉你们这些听道的人，要爱你们的仇敌，要善待恨你们的人，</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 3:9; 哥林多前书 4:12; 罗马书 12:14"> 要为咒诅你们的人祝福，要为恶待你们的人祷告。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 10:34; 马太福音 5:39–42; 哥林多后书 11:20"> 如果有人打你一边的脸，连另一边也转过来让他打。如果有人夺你的外衣，连内衣也由他拿去。</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 15:7–10; 哥林多后书 9:6–14; 马太福音 6:12"> 有人向你求什么，就给他；有人拿了你的东西，不要追讨。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 7:12; 加拉太书 5:14; 马太福音 22:39"> 想要别人怎样对待你们，你们就要怎样对待别人。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 5:46–47; 彼得前书 2:19–20"> 如果你们只爱那些爱你们的人，有什么功劳呢？就是罪人也会这样做。</span>
<span className="v" id="v33" data-v="33"> 如果你们只善待那些善待你们的人，有什么功劳呢？就是罪人也会这样做。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> 如果你们借钱给人，指望收回，有什么功劳呢？即使罪人也会借给罪人，日后再如数收回。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 5:44–45; 约翰福音 13:35; 箴言 19:17"> “然而，要爱你们的仇敌，善待他们，借给人什么不要指望偿还。这样，你们将有大赏赐，并且将成为至高者的儿子，因为祂恩待那些忘恩负义和作恶的人。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:1–2; 马太福音 5:48; 彼得前书 1:15–16"> 你们要怜悯人，像你们的天父怜悯人一样。</span>
</div>
</div>

## 责人先责己

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以弗所书 4:32; 雅各书 5:9; 马太福音 7:1–5"> “不要论断人，免得你们被论断；不要定人的罪，免得你们也被定罪。要饶恕人，这样你们也必蒙饶恕。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多后书 9:6–8; 申命记 15:10; 马可福音 4:24"> 你们要给他人，这样上帝必给你们，并且会用大号升斗摇匀压实，满满地倒给你们，因为你们用什么量器量给别人，上帝也会用什么量器量给你们。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 15:14; 提摩太后书 3:13; 提摩太前书 6:3–5"> 耶稣又给他们讲了个比喻，说：“瞎眼的岂能给瞎眼的领路？二人岂不都要掉进坑里吗？</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:16; 马太福音 10:24–25; 约翰福音 15:20"> 学生不能高过老师，学成之后不过像老师一样。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 8:7; 雅各书 1:24; 罗马书 2:1"> 为什么你只看见你弟兄眼中的小刺，却看不见自己眼中的大梁呢？</span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 2:21–29; 帖撒罗尼迦前书 2:10–12; 诗篇 51:9–13"> 你既看不见自己眼中的大梁，又怎能对弟兄说‘让我除去你眼中的小刺’呢？你这伪君子啊！要先除掉自己眼中的大梁，才能看得清楚，好清除弟兄眼中的小刺。</span>
</div>
</div>

## 树和果子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 2:21; 马太福音 12:33; 马太福音 7:16–20"> “好树不结坏果子，坏树也不结好果子。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 12:33; 雅各书 3:12; 加拉太书 5:19–23"> 树的好坏从果子就可以分辨出来。人不会从荆棘中采集无花果，也不会在蒺藜上摘取葡萄。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; 马太福音 12:34–37; 以弗所书 4:29"> 善人心存良善，就从他里面发出良善；恶人心存邪恶，就从他里面发出邪恶。因为心里充满的，口里自然会说出来。</span>
</div>
</div>

## 两种盖房子的人

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="加拉太书 6:7; 玛拉基书 1:6; 马太福音 7:21–23"> “你们为什么‘主啊，主啊’地称呼我，却不遵行我的话呢？</span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 1:22–25; 马太福音 7:24–27; 路加福音 11:28"> 我要告诉你们那到我这里来，听了我的话又去遵行的人是什么样。</span>
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 3:10–15; 诗篇 62:2; 马太福音 7:25–26"> 他好比一个人盖房子，把地挖深，将根基立在磐石上。当河流泛滥，洪水冲击那房子时，房子仍屹立不摇，因为它的根基稳固。</span>
<span className="v" id="v49" data-v="49" data-xref="以西结书 33:31; 雅各书 1:22–26; 马太福音 23:3"> 但听了我的话却不遵行的人，好比一个人没有打根基，便将房子盖在地面上，洪水一冲，那房子立刻倒塌，完全毁坏了。”</span>
</div>

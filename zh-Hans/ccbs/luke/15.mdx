## 迷失的羊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 1:15; 马太福音 9:10–13; 路加福音 5:29–32"> 许多税吏和罪人都来听耶稣讲道，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 法利赛人和律法教师埋怨说：“这个人竟和罪人来往，还跟他们一起吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 耶稣给他们讲了一个比喻：</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 34:16; 以西结书 34:11–12; 马太福音 18:12–14"> “假如你们当中有人有一百只羊，走失了一只，难道他不暂时把那九十九只留在草场上，去找那只迷失的羊，一直到找着为止吗？</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 12:2; 路加福音 19:9; 以赛亚书 46:3–4"> 他找到后，会欢欢喜喜地把那只羊扛回家，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前书 2:25"> 并邀来朋友邻居，说，‘我走失的羊找到了，来和我一同庆祝吧！’</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> 我告诉你们，一个罪人悔改，在天上也要这样为他欢喜，甚至比有九十九个不用悔改的义人还欢喜。</span>
</div>
</div>

## 丢钱的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西结书 34:12; 约翰福音 10:16"> “又比如一个妇人有十块钱，弄丢了一块，难道她不点亮灯，打扫房子，仔细寻找一直到找着为止吗？</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> 她找到后，会邀朋友邻居来，说，‘我丢的钱找到了，来和我一同庆祝吧！’</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多后书 7:10; 以西结书 33:11"> 我告诉你们，一个罪人悔改，上帝的众天使也会这样为他欢喜。”</span>
</div>
</div>

## 浪子回头

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 21:23–31"> 耶稣又说：“某人有两个儿子。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 21:16–17; 马可福音 12:44; 路加福音 15:30"> 小儿子对父亲说，‘父亲，请你把我应得的家产分给我。’父亲就把财产分给了两个儿子。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米书 2:5; 箴言 21:17"> “没过几天，小儿子带着他所有的财物出门远游去了。他终日在外花天酒地，挥金如土，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 33:11; 阿摩司书 8:9–12; 何西阿书 2:9–14"> 很快囊空如洗，又遇到严重的饥荒，就穷困潦倒，</span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 提摩太后书 2:25–26; 以赛亚书 1:5"> 只好投靠一个当地人。那人派他到田里去放猪，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:19–21; 耶利米哀歌 4:5; 何西阿书 12:1"> 他饿到恨不得拿喂猪的豆荚充饥，可是连这些也没有人给他。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 18:28; 以弗所书 2:4–5; 路加福音 15:18–19"> 最后，他醒悟过来，心想，‘我父亲家那么多雇工的口粮都绰绰有余，我现在却要在这里饿死吗？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 约翰一书 1:8–10; 路加福音 15:21"> 我要动身回到我父亲身边，对他说，父亲，我得罪了天，也得罪了你，</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 42:6; 路加福音 5:8; 诗篇 84:10"> 今后，我再也不配做你的儿子，请把我当作雇工看待吧。’</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 103:10–13; 诗篇 86:5; 诗篇 86:15"> 于是他动身回父亲那里。<br />“他父亲远远地看见他，就动了慈心，跑上前去抱着他连连亲吻。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 51:4; 路加福音 15:18–19; 耶利米书 3:13"> 小儿子说，‘父亲，我得罪了天，也得罪了你，今后，我再也不配做你的儿子。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 41:42; 以斯帖记 8:2; 启示录 6:11"> “父亲却对奴仆说，‘赶快拿最好的袍子来给他穿上，给他戴上戒指，穿上鞋，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 25:6; 马太福音 22:2–14; 诗篇 63:5"> 把那头肥牛犊牵来宰了，让我们一同欢宴庆祝！</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 2:5; 以西结书 34:16; 路加福音 19:10"> 因我这儿子是死而复活、失而复得的。’于是他们开始欢庆。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 150:4; 耶利米书 31:4; 路加福音 15:11–12"> “那时，大儿子正在田间。他回来还没到门口，就听见家里传出奏乐跳舞的声音。</span>
<span className="v" id="v26" data-v="26"> 他叫来一个奴仆问个究竟。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 9:17; 腓利门书 1:16; 使徒行传 22:13"> “奴仆回答说，‘你弟弟回来了！你父亲因他安然无恙地回来，特地宰了那头肥牛犊。’</span>
<span className="v" id="v28" data-v="28" data-xref="约拿书 4:9; 撒母耳记上 18:8; 约拿书 4:1–4"> 大儿子很生气，不肯进去。父亲就出来劝他。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亚书 7:3; 以赛亚书 65:5"> “他对父亲说，‘你看，我伺候你这么多年，从来没有违背过你的命令，可是你没有给过我一只羊羔，让我和朋友一同欢宴。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> 但你这个儿子在娼妓身上耗尽家财，一回来，你倒为他宰了肥牛犊！’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:27–28; 罗马书 9:4; 罗马书 11:1"> “父亲对他说，‘孩子啊！你一直在我身边，我所有的一切都是你的。</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 2:1–10; 路加福音 15:24; 以赛亚书 35:10"> 可是你弟弟是死而复活、失而复得的，所以我们应该欢喜快乐。’”</span>
</div>
</div>

</div>

## 施洗者约翰的传道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:24; 创世记 49:10; 路加福音 9:7"> 凯撒提庇留执政第十五年，本丢·彼拉多任犹太总督，希律做加利利的分封王，他的弟弟腓力做以土利亚和特拉可尼两地的分封王，吕撒聂做亚比利尼的分封王，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:6; 约翰福音 18:24; 路加福音 1:80"> 亚那和该亚法当大祭司。当时，上帝的话临到旷野中撒迦利亚的儿子约翰。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:77; 马太福音 3:5–6; 使徒行传 13:24"> 他就到约旦河附近宣讲悔改就得赦罪的洗礼。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 40:3–5; 约翰福音 1:23; 路加福音 1:76–79"> 这正应验了以赛亚先知书上的话：“有人在旷野大声呼喊，<br /><span className="pl pl-1">“‘预备主的道，</span><br /><span className="pl pl-1">修直祂的路。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 40:4; 以赛亚书 42:16; 以赛亚书 45:2"> <span className="pl pl-1">一切山谷要被填满，</span><br /><span className="pl pl-1">大山小丘要被削平，</span><br /><span className="pl pl-1">弯曲的道路要变得笔直，</span><br /><span className="pl pl-1">崎岖的路径要变得平坦。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 52:10; 以赛亚书 40:5; 诗篇 98:2–3"> <span className="pl pl-1">世人都要看见上帝的救恩。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书40:3‑5。">a</a></sup><br /><span className="pl pl-1">”</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 23:33; 马太福音 12:34; 帖撒罗尼迦前书 1:10"> 约翰对前来接受他洗礼的人群说：“你们这些毒蛇的后代！谁指示你们逃避那将临的烈怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 18:27–31; 使徒行传 26:20; 以赛亚书 1:16–18"> 你们要结出与悔改相称的果子。不要心里说，‘我们是亚伯拉罕的子孙。’我告诉你们，上帝可以从这些石头中兴起亚伯拉罕的子孙。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 7:19; 约翰福音 15:6; 路加福音 13:9"> 现在斧头已经放在树根上了，凡不结好果子的树都要被砍下扔进火里。”</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:37; 路加福音 3:14; 使徒行传 16:30"> 众人问道：“那么，我们该怎么办呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:7–11; 约翰一书 3:17; 提摩太前书 6:18"> 约翰回答说：“有两件衣服的，应当分一件给没有的；食物充足的，应当分些给饥饿的。”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 7:29; 路加福音 15:1–2; 路加福音 18:13"> 有些税吏也来受洗，并问约翰：“老师，我们该怎么办呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:8; 以弗所书 4:28; 哥林多前书 6:10"> 约翰说：“除了规定的税以外，一分钱也不可多收。”</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:5–6; 出埃及记 20:16; 出埃及记 23:1"> 有些军人问：“我们该怎么办呢？”约翰说：“不可敲诈勒索，自己有粮饷就当知足。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:24; 约翰福音 3:28–29; 约翰福音 1:19–28"> 当时的百姓正期待着基督的来临，大家心里都在猜想，也许约翰就是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 3:11; 使徒行传 1:5; 使徒行传 11:15–16"> 约翰对众人说：“我用水给你们施洗，但有一位比我更有能力的要来，我连给祂解鞋带都不配。祂要用圣灵和火给你们施洗。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 15:7; 马太福音 13:30; 弥迦书 4:12"> 祂手里拿着簸箕，要扬净祂的麦场，把麦子收进仓库，用不灭的火把糠秕烧尽。”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:29–36; 约翰福音 1:34; 约翰福音 1:29"> 约翰向众人传福音，讲了许多劝勉的话。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:1; 马太福音 11:2; 马可福音 6:17–18"> 分封王希律娶了自己弟弟的妻子希罗底，又做了许多恶事，因而受到约翰的指责，</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 24:17–22; 约翰福音 3:24; 帖撒罗尼迦前书 2:15–16"> 可是他却恶上加恶：将约翰关进监牢里。</span>
</div>
</div>

## 耶稣受洗

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:32–34; 马太福音 3:13–17; 约翰福音 12:27–28"> 众人都受了洗，耶稣也接受了洗礼。祂正在祷告的时候，天开了，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 2:7; 彼得后书 1:17–18; 约翰福音 1:32"> 圣灵降在祂身上，形状像鸽子，又有声音从天上传来：“你是我的爱子，我喜悦你。”</span>
</div>
</div>

## 耶稣的家谱

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 4:22; 马太福音 13:55; 民数记 4:3"> 耶稣开始传道的时候，年纪约三十岁，照人的看法， 祂是约瑟的儿子， 约瑟是希里的儿子，</span>
<span className="v" id="v24" data-v="24"> 希里是玛塔的儿子， 玛塔是利未的儿子， 利未是麦基的儿子， 麦基是雅拿的儿子， 雅拿是约瑟的儿子，</span>
<span className="v" id="v25" data-v="25"> 约瑟是玛他提亚的儿子， 玛他提亚是亚摩斯的儿子， 亚摩斯是拿鸿的儿子， 拿鸿是以斯利的儿子， 以斯利是拿该的儿子，</span>
<span className="v" id="v26" data-v="26"> 拿该是玛押的儿子， 玛押是玛他提亚的儿子， 玛他提亚是西美的儿子， 西美是约瑟的儿子， 约瑟是犹大的儿子， 犹大是约亚拿的儿子，</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:12"> 约亚拿是利撒的儿子， 利撒是所罗巴伯的儿子， 所罗巴伯是撒拉铁的儿子， 撒拉铁是尼利的儿子， 尼利是麦基的儿子，</span>
<span className="v" id="v28" data-v="28"> 麦基是亚底的儿子， 亚底是哥桑的儿子， 哥桑是以摩当的儿子， 以摩当是珥的儿子， 珥是约细的儿子，</span>
<span className="v" id="v29" data-v="29"> 约细是以利以谢的儿子， 以利以谢是约令的儿子， 约令是玛塔的儿子， 玛塔是利未的儿子，</span>
<span className="v" id="v30" data-v="30"> 利未是西缅的儿子， 西缅是犹大的儿子， 犹大是约瑟的儿子， 约瑟是约南的儿子， 约南是以利亚敬的儿子，</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 3:5; 撒母耳记下 5:14; 撒迦利亚书 12:12"> 以利亚敬是米利亚的儿子， 米利亚是迈南的儿子， 迈南是玛达他的儿子， 玛达他是拿单的儿子， 拿单是大卫的儿子，</span>
<span className="v" id="v32" data-v="32" data-xref="路得记 4:18–22; 马太福音 1:3–6; 以赛亚书 11:1–2"> 大卫是耶西的儿子， 耶西是俄备得的儿子， 俄备得是波阿斯的儿子， 波阿斯是撒门的儿子， 撒门是拿顺的儿子，</span>
<span className="v" id="v33" data-v="33" data-xref="路得记 4:19–20; 创世记 49:8; 创世记 38:29"> 拿顺是亚米拿达的儿子， 亚米拿达是兰<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷作“亚米拿达是亚德民的儿子，亚德民是亚尼的儿子，亚尼是希斯仑的儿子”，其他古卷内容各异。">b</a></sup>的儿子， 兰是希斯仑的儿子， 希斯仑是法勒斯的儿子， 法勒斯是犹大的儿子，</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 21:3; 约书亚记 24:2; 历代志上 1:24–28"> 犹大是雅各的儿子， 雅各是以撒的儿子， 以撒是亚伯拉罕的儿子， 亚伯拉罕是他拉的儿子， 他拉是拿鹤的儿子，</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 11:12–21; 创世记 10:24–25"> 拿鹤是西鹿的儿子， 西鹿是拉吴的儿子， 拉吴是法勒的儿子， 法勒是希伯的儿子， 希伯是沙拉的儿子，</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 5:28–32; 创世记 10:21–22; 创世记 9:1"> 沙拉是该南的儿子， 该南是亚法撒的儿子， 亚法撒是闪的儿子， 闪是挪亚的儿子， 挪亚是拉麦的儿子，</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 1:1–3; 创世记 5:6–28"> 拉麦是玛土撒拉的儿子， 玛土撒拉是以诺的儿子， 以诺是雅列的儿子， 雅列是玛勒列的儿子， 玛勒列是该南的儿子， 该南是以挪士的儿子，</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 2:7; 以赛亚书 64:8; 哥林多前书 15:45"> 以挪士是塞特的儿子， 塞特是亚当的儿子， 亚当是上帝的儿子。</span>

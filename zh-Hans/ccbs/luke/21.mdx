## 穷寡妇的奉献

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 12:41–44; 约翰福音 8:20; 马太福音 27:6"> 耶稣抬头观看，见有钱人正把捐项投进奉献箱里，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 12:42"> 又见一个穷寡妇投进两个小铜钱，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:12; 使徒行传 10:34; 哥林多后书 8:2–3"> 就说：“我实在告诉你们，这位穷寡妇奉献的比其他人都多。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:44–45; 路加福音 15:12; 使徒行传 4:34"> 因为他们不过奉献了自己富余的，但这穷寡妇奉献了她赖以为生的一切。”</span>
</div>
</div>

## 预言将来的事

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:20; 马太福音 24:1–51; 马可福音 13:1–37"> 有些人正在谈论由精美的石头和珍贵的供物所装饰的圣殿，</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:2; 马可福音 13:2; 耶利米哀歌 5:18"> 耶稣说：“你们现在所见到的，将来有一天要被完全拆毁，找不到两块叠在一起的石头。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 1:6–7; 马可福音 13:14; 马可福音 13:3–4"> 他们问：“老师，这些事什么时候会发生？发生的时候有什么预兆？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:1; 马可福音 13:5–6; 以弗所书 5:6"> 耶稣回答说：“你们要小心提防，不要被迷惑。因为将来会有许多人冒我的名来，说，‘我是基督’，或说，‘时候到了’，你们切勿跟从他们。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 马太福音 24:6–8; 马可福音 13:7–8"> 你们听见打仗和叛乱的事，不要害怕，因为这些事一定会先发生，但末日将不会立刻来临。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:19–20; 马可福音 13:8; 历代志下 15:5–6"> 耶稣接着说：“民族将攻打民族，国家将攻打国家，</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:29–30; 路加福音 21:25–27"> 将有大地震，各处将有饥荒和瘟疫，天上也将出现恐怖的景象和大异兆。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:12–14; 使徒行传 5:40; 使徒行传 22:30"> “这些事情出现之前，人们要拘捕你们，迫害你们，把你们押到会堂和监牢，你们将为了我的名被君王和官长审问。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:12; 腓立比书 1:28; 帖撒罗尼迦后书 1:5"> 那时，正是你们为我做见证的机会。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 马可福音 13:11; 马太福音 10:19–20"> 你们要立定心志，不要先思虑如何申辩，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:9; 以弗所书 6:19; 路加福音 12:12"> 因为我会赐给你们口才、智慧，使你们的仇敌全无反驳的余地。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 启示录 6:9; 弥迦书 7:5–6"> 你们将被父母、弟兄、亲戚、朋友出卖，你们有些人会被他们害死。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:19; 路加福音 6:22; 约翰福音 15:21"> 你们将为我的名而被众人憎恨，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 10:30; 撒母耳记上 14:45; 路加福音 12:7"> 但你们连一根头发也不会失落。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:36; 马太福音 10:22; 雅各书 1:3"> 你们只要坚忍到底，必能保全自己的灵魂。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理书 9:27; 马可福音 13:14"> “你们看见耶路撒冷被重兵包围时，就知道它被毁灭的日子快到了。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 6:1; 创世记 19:17; 路加福音 17:31–33"> 那时，犹太地区的人要逃到山上去，城里的人要跑到城外，乡村的人不要进城，</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 9:7; 以赛亚书 65:12–16; 以赛亚书 63:4"> 因为那是报应的日子，要应验圣经的全部记载。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 13:17; 马太福音 24:19; 路加福音 23:29"> 那时，孕妇和哺育婴儿的母亲们可就遭殃了！因为将有大灾难降在这地方，烈怒要临到这些百姓。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:25; 启示录 11:2; 以赛亚书 63:18"> 他们要丧身刀下，要被掳到列国去。耶路撒冷要被外族人践踏，直到外族人肆虐的日期满了为止。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 13:10; 约珥书 2:30–31; 启示录 6:12–14"> “日月星辰必显出异兆，怒海汹涌、波涛翻腾，令各国惊恐不安。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:29; 申命记 28:65–67; 彼得后书 3:10–12"> 天体必震动，人类想到世界要面临的事都吓得魂不附体。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:30; 启示录 1:7; 马可福音 13:26"> 那时，他们要看见人子驾着云、带着能力和极大的荣耀降临。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 8:23; 以赛亚书 60:1–2; 以弗所书 4:30"> 当这些事发生时，你们要昂首挺胸，因为你们蒙救赎的日子近了。”</span>
</div>
</div>

## 警醒祷告

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:32–35; 马可福音 13:28–30"> 耶稣又讲了一个比喻：“你们看无花果树及其他树木，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:57"> 你们看见它们发芽长叶，就知道夏天近了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 5:9; 希伯来书 10:37; 彼得前书 4:7"> 同样，你们看见这些事情发生时，就知道上帝的国近了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:30; 马太福音 24:34; 马太福音 23:36"> “我实在告诉你们，这个世代还没有过去，这一切都要发生。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 40:8; 马可福音 13:31; 马太福音 24:35"> 天地都要消逝，但我的话永不消逝。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> “你们要小心，不要被宴乐、醉酒和人生的挂虑拖累你们的心，免得那日子像网罗般突然临到你们，</span>
<span className="v" id="v35" data-v="35" data-xref="启示录 16:15; 诗篇 11:6; 耶利米书 48:43–44"> 因为那日子将要临到世上每一个人。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰一书 2:28; 马太福音 25:13; 彼得前书 5:8"> 你们要时刻警醒，常常祷告，使你们能逃过这一切将要发生的灾难，并能站在人子面前。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 马可福音 11:19; 马太福音 21:17"> 耶稣每天在圣殿里讲道，晚上则到城外的橄榄山上过夜。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:1–2"> 百姓一早都赶去圣殿听祂的教导。</span>
</div>
</div>

</div>

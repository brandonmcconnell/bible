## 论安息日治病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:2; 路加福音 20:20; 诗篇 62:4"> 有个安息日，耶稣到一位法利赛人的首领家里作客，人们严密监视祂。</span>
<span className="v" id="v2" data-v="2"> 当时有一个患水肿病的人在耶稣面前，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:10; 马可福音 3:4; 路加福音 13:14–16"> 耶稣问法利赛人和律法教师：“在安息日可以医病吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 22:46; 马太福音 21:25–27"> 他们都闭口不言。耶稣便扶着那人把他治好，叫他走了，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及记 23:4–5; 马太福音 12:11–12"> 然后又问他们：“如果你们有驴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“驴”另有抄本作“儿子”。">a</a></sup>或牛在安息日掉进井里，难道你们不会立刻把它拉上来吗？”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行传 6:10"> 他们都哑口无言。</span>
</div>
</div>

## 论谦卑

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:3; 路加福音 11:43; 马太福音 23:6"> 耶稣在宴席中看见宾客们都挑选首位，就用比喻对他们说：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> “参加婚宴的时候，不要坐在首位，因为也许有比你尊贵的宾客来赴宴，</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> 主人会把他带到你面前，说，‘请你把首位让给他吧！’你就要满面羞愧地退到末位去了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳记上 15:17"> 你去赴宴时，应该坐在末位，这样主人会对你说，‘朋友，请上坐！’那时，你在宾客面前就有光彩了。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 马太福音 23:12; 箴言 29:23"> 因为自高的人必遭贬抑，谦卑的人必得尊荣。”</span>
</div>
</div>

## 论待客之道

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:46; 雅各书 2:1–6; 路加福音 6:32–36"> 耶稣又对主人说：“摆设午宴、晚宴时，不要邀请你的朋友、弟兄、亲戚或有钱的邻居，免得他们回请你，你便得到报答了。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以赛亚书 58:10; 箴言 14:31"> 相反，你设宴时，要邀请贫穷的、残疾的、瘸腿的、瞎眼的，</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行传 24:15; 约翰福音 5:29"> 这样你就有福了，因为他们都没有能力回报你，到了义人复活的时候，上帝一定会赏赐你。”</span>
</div>
</div>

## 大宴席的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 路加福音 22:30; 路加福音 13:29"> 同席的一个客人听了这番话，就对耶稣说：“能够在上帝的国坐席的人多么有福啊！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 22:2–14; 启示录 22:17; 以赛亚书 55:1–7"> 于是，耶稣对他说：“有一个人大摆宴席，邀请了许多客人。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:27–29; 马太福音 10:1–4; 马太福音 22:3–4"> 要开席的时候，主人就派奴仆去对客人说，‘一切都准备好了，来赴宴吧！’</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> 可是，他们都找借口推辞。头一个说，‘我刚买了一块田，必须去看一看，请恕我不能参加。’</span>
<span className="v" id="v19" data-v="19"> 另一个说，‘我新买了五对牛，要去试一试，请恕我不能参加。’</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 24:5; 哥林多前书 7:33; 路加福音 14:26–28"> 还有一个说，‘我刚结了婚，所以不能去。’</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 马太福音 11:5; 路加福音 14:24"> 奴仆回来将这些话告诉主人，家主非常生气，就对奴仆说，‘快出去到城里的大街小巷把贫穷的、残疾的、瘸腿的、瞎眼的都请来。’</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 14:2; 以弗所书 3:8; 提摩太前书 2:5–6"> 奴仆说，‘主人啊，我照你的吩咐办了，可是还有空位。’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:9–10; 歌罗西书 1:28; 使徒行传 13:47–48"> 主人又说，‘出去到大路上、篱笆旁硬把人拉来，让我家里座无虚席。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:43; 使徒行传 13:46; 约翰福音 8:24"> 我告诉你们，原来邀请的那些人没有一个能尝到我的宴席！’”</span>
</div>
</div>

## 做门徒的代价

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:24–27; 路加福音 12:1"> 有一大群人跟着耶稣，祂转身对他们说：</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:37; 约翰福音 12:25; 腓立比书 3:8"> “若有人要跟从我，就要爱我胜过爱他的父母、妻子、儿女、弟兄、姊妹，甚至自己的生命，否则就不能做我的门徒。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 10:38; 路加福音 9:23–25; 马可福音 8:34–37"> 凡不背起自己的十字架跟从我的，都不能做我的门徒。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 马太福音 10:22; 约书亚记 24:19–24"> “你们哪有人建楼房不事先坐下来计算成本，看能否建成？</span>
<span className="v" id="v29" data-v="29"> 否则，打好了地基却不能完工，徒惹别人嘲笑说，</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 6:11; 约翰二书 1:8; 哥林多前书 3:11–14"> ‘这个人开了工，却不能完工！’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王纪下 18:20–22"> “哪有王要跟另一个王打仗时，不先坐下来酌量一下自己的一万人是否敌得过对方的两万人？</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 12:20; 雅各书 4:6–10; 路加福音 12:58"> 如果自知不敌，一定趁敌人还远的时候，就差使者去求和。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="腓立比书 3:7–8; 约翰一书 2:15–16; 路加福音 5:28"> “同样，你们若不撇下一切，就不能做我的门徒。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:13; 歌罗西书 4:6; 马可福音 9:49–50"> 盐本是好的，但如果失去咸味，怎能使它再变咸呢？</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 11:15; 路加福音 9:44; 启示录 2:11"> 没有味的盐，既不利于土壤，也不适宜作肥料，只好丢掉。有耳可听的，都应当听。”</span>
</div>
</div>

## 耶稣死里复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 20:1–2; 马可福音 16:1–8; 马太福音 28:1–8"> 周日黎明时分，几位妇女带着预备好的香料来到坟前，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:3–4; 马太福音 27:60–66; 马可福音 15:46–47"> 发现墓口的大石头已经滚到旁边，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 约翰福音 20:6–7; 马太福音 16:5"> 便进去，却没有看见主耶稣的遗体。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:5; 约翰福音 20:11–12; 使徒行传 1:10"> 正在猜疑之间，突然有两个衣服发光的人站在旁边，</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:5–6; 马太福音 28:3–5; 启示录 1:18"> 她们吓得俯伏在地。那两个人对她们说：“你们为什么在死人中找活人呢？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:22–23; 路加福音 9:22; 马可福音 8:31"> 祂不在这里，已经复活了！记住祂在加利利对你们说的话，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:21"> ‘人子必须被交在罪人的手中，被钉在十字架上，在第三天复活。’”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:16; 约翰福音 14:26; 约翰福音 2:19–22"> 她们这才想起耶稣的话来，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 马可福音 16:7–8; 马太福音 28:7–8"> 便离开坟墓，回去把事情的经过告诉十一个使徒和其他人。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:56; 约翰福音 20:11–18; 路加福音 8:2–3"> 把这些事告诉使徒的妇女有抹大拉的玛丽亚、约亚娜、雅各的母亲玛丽亚及其他人。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 9:16; 马可福音 16:11; 创世记 19:14"> 他们听了都不相信，认为是无稽之谈。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 20:3–10"> 彼得却起身跑到墓地，屈身往墓里张望，只见细麻布在那里，便离开了，对发生的事大惑不解。</span>
</div>
</div>

## 耶稣的显现

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 马可福音 16:12–13"> 同一天，有两个门徒前往离耶路撒冷十一公里的以马忤斯村，</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命记 6:7; 玛拉基书 3:6"> 一路谈论着最近发生的一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:20; 约翰福音 14:18–19; 路加福音 24:36"> 正谈论的时候，耶稣走过来和他们同行。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 20:14; 约翰福音 21:4; 路加福音 24:31"> 可是，他们认不出耶稣。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:20–22; 约翰福音 16:6; 以西结书 9:4–6"> 耶稣问他们：“你们一路上在谈论什么？” 他们停下脚步，满面愁容，</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 19:25"> 其中一个叫革流巴的说：“难道在耶路撒冷作客的人中，只有你不知道近日发生在那里的事吗？”</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:11; 使徒行传 7:22; 约翰福音 4:19"> 耶稣问：“什么事？” 他们说：“就是拿撒勒人耶稣的事。祂本来是个先知，在上帝和百姓面前言谈举止充满力量。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:13–15; 使徒行传 4:8–10; 路加福音 23:13"> 我们的祭司长和官长却把祂押去判了死刑，钉在十字架上。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前书 1:18–19; 路加福音 2:38"> “我们一直希望祂就是要救赎以色列的那位。还有，今天是事发后的第三天，</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 16:9–10; 马太福音 28:7–8; 约翰福音 20:1–2"> 我们当中有几位妇女让我们惊奇。她们一早到坟墓那里，</span>
<span className="v" id="v23" data-v="23"> 发现耶稣的遗体不见了，回来说天使曾向她们显现，并告诉她们耶稣还活着。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 约翰福音 20:1–10"> “后来我们有几个人去坟墓察看，发现果然像她们所说的，不过没有看见耶稣。”</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 7:18; 马可福音 9:19; 希伯来书 5:11–12"> 耶稣对他们说：“无知的人啊！为什么迟迟不肯相信先知的话呢？</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:11; 以赛亚书 53:1–12; 撒迦利亚书 13:7"> 基督岂不是要先这样受害，然后进入祂的荣耀吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:14; 路加福音 24:44; 申命记 18:15"> 耶稣接着从摩西和众先知的记载开始，把有关自己的经文都向他们讲解明白。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 6:48; 创世记 19:2; 创世记 32:26"> 快到以马忤斯村时，耶稣好像还要继续前行。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 4:8; 路加福音 14:23; 创世记 19:3"> 他们极力挽留祂，说：“天快黑了，时候不早了，跟我们一同住宿吧。”耶稣就和他们一起进村住下。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:19; 路加福音 24:35; 马太福音 15:36"> 吃饭的时候，耶稣拿起饼来，祝谢后，掰开递给他们。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 约翰福音 8:59; 路加福音 4:30"> 忽然他们眼睛明亮了，认出是耶稣。耶稣就从他们眼前消失了。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米书 23:29; 希伯来书 4:12"> 二人彼此议论说：“一路上祂和我们说话、为我们解释圣经的时候，我们心里不是很火热吗？”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 16:13; 约翰福音 20:19–26; 使徒行传 1:14"> 二人马上动身赶回耶路撒冷，看到十一位使徒及其同伴正聚在一起谈论：</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 15:5; 马可福音 16:7; 路加福音 22:54–62"> “主真的复活了，并向西门显现了。”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 16:12–13; 使徒行传 2:42; 路加福音 24:30–31"> 二人也把路上发生的事以及掰饼时认出主的经过述说了一遍。</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦后书 3:16; 以赛亚书 57:18; 马可福音 16:14"> 正说的时候，耶稣亲自站在他们中间，说：“愿你们平安！”</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:13; 马太福音 14:26–27; 约伯记 4:14–16"> 他们又惊又怕，以为是看见了幽灵。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:14; 希伯来书 4:13; 但以理书 4:19"> 耶稣说：“你们为什么惴惴不安？为什么心存疑惑呢？</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 20:27; 约翰一书 1:1; 传道书 12:7"> 你们看我的手和脚，就知道真的是我。来摸摸看，幽灵没有骨和肉，你们看！我有。”</span>
<span className="v" id="v40" data-v="40"> 说完，祂把手和脚给他们看。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 21:5; 诗篇 126:1–2; 创世记 45:26–28"> 门徒又惊又喜，难以相信。耶稣问：“你们这里有吃的吗？”</span>
<span className="v" id="v42" data-v="42"> 他们便给祂一片烤鱼，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:41"> 祂接过来在他们面前吃了。</span>
<span className="v" id="v44" data-v="44" data-xref="撒迦利亚书 12:10; 路加福音 24:26–27; 撒迦利亚书 9:9"> 耶稣对他们说：“我跟你们在一起的时候曾经说过，摩西的律法书、先知的书以及诗篇里有关我的记载都要应验。”</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 16:14; 约翰一书 5:20; 诗篇 119:18"> 于是，耶稣开了他们的心窍，使他们明白圣经，</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:2–12; 以赛亚书 50:6; 路加福音 24:44"> 又对他们说：“圣经上说，基督必受害，然后在第三天从死里复活，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 5:31; 以赛亚书 49:6; 使徒行传 2:38"> 人们要奉祂的名传扬悔改、赦罪的福音，从耶路撒冷一直传遍万国。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 1:8; 使徒行传 2:32; 使徒行传 13:31"> “你们是这些事的见证人，</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 1:8; 使徒行传 1:4; 约珥书 2:28–32"> 我要把我父的应许赐给你们。不过，你们要留在城里，直到得着天上来的能力。”</span>
</div>
</div>

## 耶稣升天

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行传 1:12; 马太福音 21:17; 马可福音 11:1"> 耶稣带着门徒来到伯大尼附近，举起双手为他们祝福。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行传 1:9; 马可福音 16:19; 列王纪下 2:11"> 正祝福的时候，祂就离开了他们，被接到天上去了。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 28:9; 约翰福音 16:22; 诗篇 30:11"> 门徒都敬拜祂，然后欢欢喜喜地回到耶路撒冷。</span>
<span className="v" id="v53" data-v="53" data-xref="马可福音 16:20; 使徒行传 2:46–47; 使徒行传 5:41–42"> 他们常在圣殿里颂赞上帝。</span>
</div>

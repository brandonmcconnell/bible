## 耶稣降生伯利恒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马太福音 24:14; 使徒行传 25:21"> 那时候，凯撒奥古斯都颁下谕旨，命罗马帝国的百姓都登记户口。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 马太福音 4:24; 使徒行传 26:30"> 这是第一次户口登记，正值居里纽任叙利亚总督。</span>
<span className="v" id="v3" data-v="3"> 人们都回到本乡办理户口登记。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 5:2; 约翰福音 7:42; 撒母耳记上 16:1"> 约瑟因为是大卫家族的人，就从加利利的拿撒勒镇赶到犹太地区大卫的故乡伯利恒，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22–27; 马太福音 1:18–19"> 要和已许配给他、怀着身孕的玛丽亚一起登记。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 33:11; 启示录 12:1–5; 弥迦书 5:2"> 他们在那里的时候，玛丽亚产期到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:4; 哥林多后书 8:9; 以赛亚书 53:2–3"> 便生下第一胎，是个儿子。她用布把孩子裹好，放在马槽里，因为客房没有地方了。</span>
</div>
</div>

## 牧羊人和天使

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 31:39–40; 诗篇 78:70–71; 撒母耳记上 17:34–35"> 当晚，伯利恒郊外有一群牧羊人正在看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:1; 哥林多后书 3:18; 列王纪上 8:11"> 忽然，主的天使向他们显现，主的荣光四面照着他们，他们非常害怕。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 40:9; 以赛亚书 61:1; 以赛亚书 52:7"> 天使对他们说：“不要害怕！我告诉你们一个有关万民的大喜讯，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 9:6; 马太福音 1:21; 使徒行传 2:36"> 今天在大卫的城里有一位救主为你们降生了，祂就是主基督！</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 7:14; 以赛亚书 53:1–2; 以赛亚书 7:11"> 你们将看见一个婴孩包着布躺在马槽里，这就是给你们的记号。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:20–21; 启示录 5:11; 诗篇 148:2"> 忽然，有一大队天军出现，与那天使一同赞美上帝说：</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 5:1; 路加福音 19:38; 歌罗西书 1:20"> <span className="pl pl-1">“在至高之处荣耀归于上帝！</span><br /><span className="pl pl-1">在地上平安临到祂所喜悦的人！”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:22; 马太福音 2:1–2; 马太福音 2:9–11"> 众天使离开他们升回天上之后，牧羊人便商议说：“我们现在去伯利恒，看看主告诉我们的这件已发生的事吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 他们就连忙进城，找到了玛丽亚和约瑟以及躺在马槽里的婴孩。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 66:16; 路加福音 8:39; 诗篇 71:17–18"> 他们看过之后，就把天使告诉他们有关这婴孩的事传开了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 听见的人都对牧羊人的话感到惊讶。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 但玛丽亚把这些事牢记在心里，反复思想。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:48; 以赛亚书 29:19; 使徒行传 11:18"> 牧羊人就回去了，不住地赞美和归荣耀给上帝，因为他们的所见所闻跟天使告诉他们的一样。</span>
</div>
</div>

## 奉献圣婴

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 创世记 17:12; 加拉太书 4:4–5"> 在第八天，婴孩接受了割礼，祂的名字叫耶稣，是玛丽亚怀孕前天使取的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 12:1–8"> 摩西律法规定的洁净期满后，约瑟和玛丽亚把婴孩带到耶路撒冷去献给主，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 13:2; 出埃及记 22:29; 民数记 3:13"> 因为主的律法规定：必须把长子分别出来献给主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记13:2、12。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 12:6–8; 利未记 12:2; 哥林多后书 8:9"> 他们又按照主的律法献上祭物，即一对斑鸠或两只雏鸽<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="利未记12:8。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 25:9; 路加福音 2:38; 路加福音 1:6"> 耶路撒冷有一位公义敬虔、有圣灵同在的人名叫西缅，他一直期待着以色列的安慰者到来。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:51; 希伯来书 11:5; 路加福音 9:27"> 圣灵曾启示他：他去世前必能亲眼看见主所立的基督。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="马太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 那天，他受圣灵感动进入圣殿，看见约瑟和玛丽亚抱着婴孩耶稣进来，要依照律法的规定为祂行礼，</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 就把祂抱过来，称颂上帝说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 14:13; 创世记 15:15; 腓立比书 1:23"> <span className="pl pl-1">“主啊，现在可以照你的话，</span><br /><span className="pl pl-1">让奴仆安然离世了，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因为我已亲眼看到你的救恩，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 62:1–2; 以赛亚书 42:1–4; 诗篇 98:2–3"> <span className="pl pl-1">就是你为万民所预备的救恩。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 60:1–3; 以赛亚书 49:6; 使徒行传 26:23"> <span className="pl pl-1">这救恩是启示外族人的光，</span><br /><span className="pl pl-1">也是你以色列子民的荣耀。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以赛亚书 8:18; 路加福音 2:48"> 耶稣的父母听见关于祂的这番话，感到惊奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 1:23; 彼得前书 2:7–8; 以赛亚书 8:14–15"> 西缅给他们祝福后，就对孩子的母亲玛丽亚说：“看啊，这孩子必使以色列许多人跌倒、许多人兴起。祂将成为众人攻击的对象，</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 8:2; 哥林多前书 11:19; 马太福音 12:24–35"> 好叫许多人的心思意念暴露出来，你自己则会心如刀割。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及记 15:20; 创世记 30:13; 使徒行传 21:9"> 亚设支派中有一位八十四岁高龄的女先知名叫亚拿，是法内利的女儿，婚后七年便开始守寡，之后一直住在圣殿里，禁食祷告，日夜事奉上帝。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多后书 9:15; 马可福音 15:43"> 正在那时，她也前来感谢上帝，并把耶稣的事报告给所有盼望耶路撒冷蒙救赎的人。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太书 4:4–5; 申命记 12:32"> 约瑟和玛丽亚按照主的律法办完一切事之后，就回到他们的家乡加利利的拿撒勒。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以赛亚书 11:1–5"> 耶稣渐渐长大，变得强健，充满智慧，上帝的恩典与祂同在。</span>
</div>
</div>

## 少年耶稣圣殿论道

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及记 12:14; 民数记 28:16; 申命记 12:18"> 耶稣的父母每年都上耶路撒冷去过逾越节。</span>
<span className="v" id="v42" data-v="42"> 耶稣十二岁那年，跟父母照例上去过节。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 30:21–23; 出埃及记 12:15; 历代志下 25:17"> 节期完了，祂父母便启程回家，并不知道少年耶稣仍然留在耶路撒冷，</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 122:1–4; 以赛亚书 2:3; 诗篇 42:4"> 还以为祂跟在同行的人中间。他们走了一天的路后，才开始在亲戚朋友中找祂，</span>
<span className="v" id="v45" data-v="45"> 结果没有找到，只好回到耶路撒冷去找祂。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以赛亚书 49:1–2; 以赛亚书 50:4"> 三天后，他们才在圣殿里找到耶稣，祂正和教师们坐在一起，一边听一边提问题。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 7:28; 路加福音 4:32; 诗篇 119:99"> 祂的聪慧和对答令听见的人感到惊奇。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 马太福音 12:46; 路加福音 3:23"> 约瑟和玛丽亚看见耶稣在那里，大为惊奇。<br />玛丽亚对祂说：“儿子，你为什么这样对我们呢？你看，你父亲和我急得到处找你！”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="约翰福音 6:38; 约翰福音 8:29; 玛拉基书 3:1"> 耶稣对他们说：“你们为什么找我呢？难道你们不知道我应该在我父的家吗？”</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 马可福音 9:32"> 但他们不明白祂在讲什么。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理书 7:28; 创世记 37:11"> 于是，耶稣随父母回到拿撒勒，并顺从他们。玛丽亚把这一切事牢记在心。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳记上 2:26"> 耶稣的智慧和身量不断增长，越来越受上帝和人们的喜爱。</span>
</div>
</div>

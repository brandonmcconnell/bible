## 撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:23; 罗马书 10:15; 马太福音 9:35"> 此后，耶稣到各城镇去传扬上帝国的福音。同行的有十二使徒，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:9; 马太福音 27:55–56; 马可福音 15:40–41"> 还有几个曾被邪灵和疾病缠身、现在已被医治的妇女。其中有抹大拉的玛丽亚，耶稣曾经从她身上赶出七个鬼，</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 4:46–53; 哥林多后书 8:9; 使徒行传 9:36–39"> 还有希律的管家苦撒的妻子约亚娜，此外还有苏撒娜等其他妇女。她们用自己的钱财资助耶稣和门徒。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 4:1–9; 马太福音 13:2–9"> 那时，人群络绎不绝地从各个城镇聚集到耶稣面前，耶稣就讲了一个比喻：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:1; 雅各书 1:23–24; 马可福音 4:15"> “有一个农夫出去撒种，有些种子落在路旁，被人践踏，又被飞鸟吃掉了；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 3:7–8; 路加福音 8:13; 马可福音 4:5–6"> 有些落在石头地上，因水分不足，幼苗刚长出来就枯萎了；</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 路加福音 21:34"> 有些落在荆棘丛中，荆棘一同长起来便把幼苗挤住了；</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 11:15; 启示录 2:11; 启示录 2:7"> 有些落在沃土里，发芽生长，结出百倍的果实。”耶稣讲完这番话后，高声说：“有耳可听的，都应当听。”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 4:10; 马太福音 13:10; 马太福音 13:18"> 门徒请耶稣解释这比喻的意思，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 6:9; 马可福音 4:11; 马太福音 11:25"> 耶稣便说：“上帝国的奥秘只让你们知道，对其他人，我就用比喻，使他们看却看不见，听却听不明白<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书6:9。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:19; 马可福音 4:14–20; 雅各书 1:21"> 这个比喻的意思是这样，种子就是上帝的道。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:9–14; 启示录 12:9; 雅各书 1:23–24"> 种子落在路旁是指人听了道，随后魔鬼来把道从他们心里夺走了，不让他们相信并得救。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 6:4; 约翰福音 5:35; 箴言 12:12"> 种子落在石头地上是指人听了道，便欣然接受，但他们没有根基，不过是暂时相信，一遇到试炼就放弃了。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> 种子落在荆棘丛中是指人听了道，后来被生活的忧虑、钱财和享乐缠住了，以致结不出成熟的果实来。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:36; 加拉太书 5:22–26; 歌罗西书 1:10"> 种子落在沃土里则是指人听了道，用诚实良善的心坚忍持守，最终结出果实。</span>
</div>
</div>

## 点灯的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 马太福音 5:15–16; 马可福音 4:21–22"> “没有人点亮灯，却用器皿把它盖起来或放到床底下，而是放在灯台上，使进来的人能看见光。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 马太福音 10:26; 马可福音 4:22"> 掩盖的事终会暴露出来，隐藏的秘密终会被人知道。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:12; 路加福音 19:26; 马可福音 4:23–25"> 因此，你们要留心听，因为凡有的，还要给他更多；凡没有的，连他自以为已经拥有的也要夺去。”</span>
</div>
</div>

## 耶稣的亲属

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 12:46–50; 马可福音 3:31–35; 马可福音 3:21"> 这时，耶稣的母亲和兄弟来找祂，由于人太多，他们无法靠近耶稣，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 1:14; 马可福音 6:3; 马太福音 13:55–56"> 有人就对祂说：“你的母亲和兄弟站在外面想见你。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各书 1:22; 约翰福音 13:17"> 耶稣却说：“听见上帝的话语并遵行的人就是我的母亲和我的弟兄。”</span>
</div>
</div>

## 平静风浪

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 8:23–27; 马可福音 4:35–41; 马可福音 6:45"> 有一天，耶稣对门徒说：“我们渡到湖对岸去吧。”于是他们坐船前往对岸。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 93:3–4; 诗篇 124:2–4; 诗篇 148:8"> 耶稣途中睡着了。湖面上忽然狂风大作，船灌满了水，非常危险。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:25–29; 路加福音 4:39; 诗篇 104:6–9"> 门徒过来唤醒耶稣，说：“老师！老师！我们快淹死了！” 耶稣醒来，就斥责风浪，顿时风平浪静了。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 8:26; 箴言 30:4; 马可福音 4:40–41"> 耶稣对他们说：“你们的信心在哪里呢？” 门徒又惊又怕，彼此议论说：“祂到底是谁？一发命令，连风浪都听从祂！”</span>
</div>
</div>

## 格拉森赶鬼

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 5:1–20; 马太福音 8:28–34"> 他们渡过加利利湖，到了对岸的格拉森地区。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 5:2–5; 撒母耳记上 19:24; 民数记 19:16"> 耶稣上岸后，迎面遇见当地一个被鬼附身的人。那人长期不穿衣服，不住在房屋里，而是住在坟墓里。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:29; 彼得后书 2:4; 马可福音 5:6–8"> 他一见到耶稣，就仆倒在祂面前，高声喊叫：“至高上帝的儿子耶稣啊，我和你有什么关系？求求你，不要折磨我！”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:3–5; 路加福音 9:39; 提摩太后书 2:25–26"> 这是因为耶稣已命令污鬼离开那人。那人多次被污鬼操纵，人们用铁链脚镣把他锁起来看管，他竟把锁链也扯断，被鬼催逼到荒野。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 26:53; 路加福音 8:2; 马太福音 8:29"> 耶稣问他：“你叫什么名字？” 他说：“群。”因为有一大群鬼附在那人身上。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:41; 腓立比书 2:10–11; 约伯记 2:5"> 鬼不断央求耶稣不要叫它们到无底坑去。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 65:4; 以赛亚书 66:3; 启示录 20:7"> 当时有一大群猪在山坡上吃食，污鬼就央求耶稣准许它们进入猪群，耶稣答应了。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 5:8; 约翰福音 8:44; 路加福音 8:22–23"> 于是那群鬼便离开那人，进入猪群。那群猪就一路奔下陡坡，冲进湖里淹死了。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 5:14; 马太福音 8:33; 马太福音 28:11"> 放猪的人见状就逃走了，把这事传遍了城里乡间。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行传 22:3; 约翰一书 3:8"> 人们出来看个究竟，到了耶稣那里，发现那曾被鬼附身的人衣着整齐、神智清醒地坐在耶稣脚前，他们都很害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 4:24"> 目击者把被鬼附身的人得救的经过告诉了他们。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 16:39; 路加福音 8:28; 路加福音 10:10–11"> 格拉森地区的居民都十分害怕，请求耶稣离开那里，耶稣便乘船回去了。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:13–16; 马可福音 5:18–20; 诗篇 145:3–12"> 那不再被鬼附身的人恳求耶稣让他随行，耶稣却让他回去，说：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前书 5:8; 申命记 10:21"> “你回家吧，把上帝为你所行的奇事告诉别人。”他就回去，走遍全城，四处传扬耶稣为他所行的奇事。</span>
</div>
</div>

## 雅鲁求救

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:1; 马可福音 5:21; 马可福音 6:20"> 耶稣回到对岸，在那里等候的百姓都欢迎祂。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 5:22–43; 路加福音 13:14; 使徒行传 18:8"> 有个名叫雅鲁的会堂主管走过来俯伏在耶稣脚前，求耶稣到他家去，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; 约伯记 1:18–19"> 因为他有一个大约十二岁的独生女快要死了。 耶稣前去雅鲁家的时候，人群拥挤着祂。</span>
</div>
</div>

## 患血漏病妇人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马可福音 5:25–26; 马太福音 9:20–22; 利未记 15:25–33"> 有一个患了十二年血漏病的妇人耗尽了积蓄，到处求医，但没有人能医治她。</span>
<span className="v" id="v44" data-v="44" data-xref="马可福音 5:27–28; 申命记 22:12; 使徒行传 19:12"> 妇人挤到耶稣的背后，摸了祂衣服的穗子，她的血漏立刻止住了。</span>
<span className="v" id="v45" data-v="45" data-xref="马可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶稣问：“谁摸我？”没有人承认。 彼得说：“老师，众人都在拥挤你。”</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前书 2:9"> 耶稣却说：“一定有人摸了我，因为我感觉有能力从我身上发出。”</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 5:33; 路加福音 17:15–16; 哥林多前书 2:3"> 那妇人知道无法隐瞒，就战战兢兢地走过来，俯伏在耶稣脚前，把她摸耶稣的原因及怎样立刻痊愈的经过当众说了出来。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 马太福音 9:22; 希伯来书 4:2"> 耶稣对她说：“女儿，你的信心救了你！安心去吧。”</span>
</div>
</div>

## 雅鲁女儿死而复活

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:35–43; 以赛亚书 7:12; 路加福音 7:6"> 耶稣还在说话的时候，有人从雅鲁家赶来，对雅鲁说：“你的女儿已经死了，不用麻烦老师了。”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 11:25; 马可福音 5:36"> 耶稣听了，就对雅鲁说：“不要怕，只要信。你的女儿一定会好的！”</span>
<span className="v" id="v51" data-v="51" data-xref="马可福音 14:33; 马太福音 6:5–6; 列王纪上 17:19–23"> 到了雅鲁家，耶稣只准彼得、雅各、约翰和女孩的父母跟祂进去。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 约翰福音 11:4; 撒迦利亚书 12:10"> 人们都在为那女孩哀伤哭泣，耶稣说：“不要哭，她没有死，只是睡着了。”</span>
<span className="v" id="v53" data-v="53" data-xref="路加福音 16:14; 以赛亚书 53:3; 约翰福音 11:39"> 众人就讥笑祂，因为他们都知道那女孩死了。</span>
<span className="v" id="v54" data-v="54" data-xref="耶利米书 31:32; 约翰福音 11:43; 马可福音 1:31"> 耶稣拉着那女孩的手，说：“孩子，起来！”</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 11:44; 列王纪上 17:21–23; 马可福音 5:43"> 她的灵魂就回来了，她立刻起来了。耶稣吩咐人给她东西吃。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 8:4; 马太福音 9:30; 路加福音 5:14"> 她的父母非常惊讶，耶稣却嘱咐他们不要把这事传开。</span>
</div>

## 撒该悔改

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:1–27; 路加福音 18:35; 列王纪下 2:18–22"> 耶稣进了耶利哥，正从城里经过。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 18:24–27; 历代志下 17:5–6"> 有个人名叫撒该，是税吏长，家财丰厚。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:8; 路加福音 9:7–9; 约翰福音 12:21"> 他想看看耶稣是谁，可是因为周围人多，他身材矮小，无法看见。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 9:10; 路加福音 5:19; 列王纪上 10:27"> 他便跑到前面，爬上一棵桑树观看，因为耶稣会从那里经过。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:20; 约翰福音 14:23; 希伯来书 13:2"> 耶稣走到那里，抬头招呼他说：“撒该，快下来！今天我必须住在你家。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:29; 使徒行传 16:34; 使徒行传 16:15"> 撒该连忙爬下来，兴高采烈地迎接耶稣。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:2; 路加福音 7:39; 路加福音 7:34"> 百姓见状都埋怨说：“祂怎么到一个罪人家里作客？”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 12:6; 民数记 5:7; 路加福音 18:22–23"> 撒该站起来对主说：“主啊，我要把一半的财产分给穷人。我欺骗过谁，就还谁四倍。”</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:7; 路加福音 13:16; 罗马书 4:16"> 耶稣说：“今天救恩临到这家了，因为他也是亚伯拉罕的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 34:16; 马太福音 1:21; 提摩太前书 1:13–16"> 人子来是要寻找和拯救迷失的人。”</span>
</div>
</div>

## 十个奴仆的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 17:20; 使徒行传 1:6; 帖撒罗尼迦后书 2:1–3"> 众人在听的时候，耶稣又为他们讲了一个比喻，因为祂快到耶路撒冷了，人们以为上帝的国马上就要显现了。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:14–30; 路加福音 19:12–27; 路加福音 20:9"> 耶稣说：“有一位贵族要到远方去受封为王，然后返回。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 25:14–15; 约翰福音 12:26; 哥林多前书 12:7–11"> 临行前，他召集了十个奴仆，发给每人一千个银币，吩咐他们，‘你们在我出门期间要用这些钱做生意。’</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 8:7; 使徒行传 7:51–52; 使徒行传 3:14–15"> “可是他的人民却憎恨他，他们随后派一个代表团去请愿说，‘我们不要这人做我们的王。’</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:1–5; 罗马书 14:10–12; 诗篇 2:4–6"> “那贵族受封为王回来后，召齐十个奴仆，想知道他们做生意赚了多少。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:18–26; 提摩太后书 4:7–8; 哥林多前书 15:10"> 第一个奴仆上前禀告说，‘主啊，我用你给我的一千个银币赚了一万个银币。’</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 16:10; 马太福音 25:21; 启示录 2:26–29"> “主人说，‘好，你真是个好奴仆！你既然在小事上忠心，就派你管理十座城。’</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:20; 马太福音 13:23; 哥林多后书 8:12"> “第二个奴仆上前说，‘主啊，我用你给我的一千个银币赚了五千个银币。’</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 15:58; 哥林多前书 15:41–42; 哥林多前书 3:8"> “主人说，‘我派你管理五座城。’</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:24; 箴言 26:13–16; 雅各书 4:17"> “另一个奴仆上前说，‘主啊，这是你先前给我的一千个银币，我一直把它包在手帕里。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:24–25; 罗马书 8:7; 约翰一书 4:18"> 因为你很严厉，没有存还要取，没有种还要收，所以我怕你。’</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 1:16; 马太福音 12:37; 约伯记 15:5–6"> “主人对那奴仆说，‘你这个恶奴仆！我要按你自己的话定你的罪。你既然知道我很严厉，没有存还要取，没有种还要收，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 22:25–27; 罗马书 2:4–5; 申命记 23:19–20"> 为什么不把我的银币存进钱庄，等我回来可以连本带利收回来？’</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 16:2; 路加福音 12:20"> “接着，他吩咐站在旁边的奴仆，‘收回他的一千银币，给那个有一万银币的。’</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 16:2; 撒母耳记下 7:19; 以赛亚书 55:8–9"> “他们说，‘主啊，那个人已经有一万银币了。’</span>
<span className="v" id="v26" data-v="26" data-xref="约翰二书 1:8; 路加福音 8:18; 马太福音 21:43"> “主人答道，‘我告诉你们，凡有的，还要给他更多；凡没有的，连他仅有的也要夺去。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:14; 诗篇 21:8–9; 马太福音 22:7"> 至于那些反对我做王的仇敌，把他们带来，在我面前处决。’”</span>
</div>
</div>

## 骑驴进耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:51; 希伯来书 12:2; 彼得前书 4:1"> 耶稣说完这个比喻，就走在众人前面上耶路撒冷去。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 1:12; 马太福音 21:17; 马太福音 21:1–11"> 快到橄榄山的伯法其和伯大尼时，耶稣派了两个门徒，并嘱咐说：</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 22:8–13; 路加福音 19:32; 撒母耳记上 10:2–9"> “你们去前面的村庄，一进村就会看见一头从来没有人骑过的驴驹拴在那里，你们把它解开牵来。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 24:1; 诗篇 50:10–12; 马可福音 11:3–6"> 若有人问你们为什么把它解开，就说，‘主要用它。’”</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 22:13"> 两个门徒出去后，所遇见的情形正如耶稣所说的。</span>
<span className="v" id="v33" data-v="33"> 当他们解开驴驹时，主人问他们：“你们解开驴驹干什么？”</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 9:9; 约翰福音 10:35; 哥林多后书 8:9"> 他们说：“主要用它。”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 11:7–8; 马太福音 21:7; 约翰福音 12:14"> 他们把驴驹牵到耶稣那里，把自己的外衣搭在驴背上，扶耶稣上驴。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 9:13; 马太福音 21:8"> 耶稣骑着驴前行，众人把衣服铺在路上。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:12–13; 以斯拉记 3:10–13; 马太福音 21:1"> 祂正走下橄榄山，将近耶路撒冷的时候，众门徒因为以往所见的神迹奇事，就欢腾起来，高声赞美上帝：</span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亚书 9:9; 路加福音 13:35; 诗篇 118:22–26"> <span className="pl pl-1">“奉主名来的王当受称颂！”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇118:26。">a</a></sup><br /><span className="pl pl-1">“天上有平安，至高之处有荣耀！”</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 4:1–2; 马太福音 23:13; 使徒行传 4:16–18"> 百姓中有几个法利赛人对耶稣说：“老师，责备你的门徒吧。”</span>
<span className="v" id="v40" data-v="40" data-xref="哈巴谷书 2:11; 以赛亚书 55:12; 马太福音 3:9"> 耶稣说：“我告诉你们，如果他们闭口不言，这些石头都要呼喊了！”</span>
</div>
</div>

## 为耶路撒冷哀哭

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 13:34–35; 约翰福音 11:35; 诗篇 119:136"> 耶稣快到耶路撒冷时，看见那城，就为它哀哭，</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 32:29; 希伯来书 10:26–29; 以赛亚书 48:18"> 说：“今天你若知道那能带给你平安的事就好了！可惜这事现在是隐藏的，你看不见！</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 21:20–24; 以赛亚书 29:1–4; 以西结书 4:2"> 因为有一天敌人要在你周围筑垒把你团团围住，四面攻击你。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 21:6; 路加福音 13:34–35; 约翰福音 3:18–21"> 他们要把你夷为平地，毁灭你城墙里的儿女，不会留下两块叠在一起的石头，因为你没有认出上帝眷顾你的时刻。”</span>
</div>
</div>

## 耶稣洁净圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 21:12–13; 马可福音 11:15–17; 约翰福音 2:13–17"> 耶稣进入圣殿赶走里面做买卖的人，</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 56:7; 耶利米书 7:11; 诗篇 93:5"> 并对他们说：“圣经上说，‘我的殿要成为祷告的殿’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书56:7。">b</a></sup>，你们竟把它变成了贼窝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶利米书7:11。">c</a></sup>。”</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 11:18; 马太福音 26:55; 马可福音 11:27–33"> 祂天天在圣殿教导人，祭司长、律法教师和百姓的官长都想杀祂，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 8:3; 使徒行传 16:14; 约翰福音 7:46–49"> 只是无从下手，因为百姓都十分喜爱听祂讲道。</span>

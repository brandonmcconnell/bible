## 犹大出卖耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:6–23; 马太福音 26:2–5; 约翰福音 11:55–57"> 除酵节，又名逾越节，快到了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 11:47–53; 马太福音 12:14; 路加福音 20:19"> 祭司长和律法教师因为害怕百姓，便密谋如何杀害耶稣。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 13:2; 马可福音 14:10–11; 约翰福音 13:26–27"> 这时，撒旦进入加略人犹大的心，这人原是十二使徒之一。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:1; 使徒行传 5:24; 路加福音 22:52"> 他去见祭司长和圣殿护卫长，商议如何把耶稣出卖给他们，</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 26:15–16; 使徒行传 1:18; 马太福音 27:3–5"> 他们喜出望外，答应给犹大酬金。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 14:2; 马太福音 26:5"> 犹大同意了，便伺机找百姓不在的场合将耶稣交给他们。</span>
</div>
</div>

## 最后的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:18; 马可福音 14:12–16; 哥林多前书 5:7"> 除酵节到了，那天要宰杀逾越节的羔羊。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:13–16; 使徒行传 4:19; 使徒行传 4:13"> 耶稣差派彼得和约翰出去，说：“你们去为我们预备逾越节吃的晚餐。”</span>
<span className="v" id="v9" data-v="9"> 他们问：“你想让我们在哪里预备呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 16:4; 马太福音 26:18–19; 使徒行传 8:26–29"> 耶稣回答说：“你们进城的时候，一个男子会扛着一瓶水迎面走来，你们要跟着他，他进哪所房子，你们也进去，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:28; 启示录 3:20; 路加福音 19:34"> 对房子的主人说，‘老师问：客房在哪里？祂要和门徒在里面吃逾越节的晚餐。’</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:14–15; 使徒行传 1:13; 约翰福音 2:25"> 主人会带你们看楼上一间布置整齐的大房间，你们就在那里预备吧。”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:33; 路加福音 19:32; 约翰福音 2:5"> 他们进了城，所遇见的果然和耶稣所说的一样。他们便在那里预备逾越节的晚餐。</span>
</div>
</div>

## 设立圣餐

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:20; 马可福音 14:17; 申命记 16:6–7"> 时候到了，耶稣和使徒们一同坐席。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:50; 约翰福音 4:34; 约翰福音 17:1"> 耶稣对他们说：“我一直盼望在受难之前和你们同吃这个逾越节的宴席。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 14:15; 启示录 19:9; 路加福音 22:30"> 我告诉你们，在这宴席成就在上帝的国之前，我不会再吃这宴席了。”</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:19; 诗篇 116:13; 申命记 8:10"> 祂接过杯来，祝谢后，说：“你们拿去分着喝吧。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 26:29; 路加福音 22:16; 马可福音 14:25"> 我告诉你们，在上帝的国降临之前，我不会再喝这葡萄酒。”</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 11:23–29; 哥林多前书 10:16; 马可福音 14:22–24"> 接着，祂拿起饼来，祝谢后，掰开分给他们，说：“这是我为你们牺牲的身体，你们要这样做来记念我。”</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 26:28; 哥林多前书 11:25; 撒迦利亚书 9:11"> 饭后，祂照样拿起杯来，说：“这杯是用我的血立的新约，这血是为你们流的。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 41:9; 约翰福音 13:26; 约翰福音 13:21–22"> “但是看啊，那出卖我之人的手和我的手都在桌子上。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:23; 诗篇 109:6–15; 诗篇 55:12–15"> 按照所定的，人子要离世了，但那出卖人子的人有祸了！”</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:22–25; 马可福音 14:19; 马太福音 26:22"> 他们开始彼此追问谁会出卖耶稣。</span>
</div>
</div>

## 谁最伟大

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 9:46; 马可福音 9:34; 马可福音 10:37–41"> 门徒又开始争论他们当中谁最伟大。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 20:25–28; 马可福音 10:41–45"> 耶稣对他们说：“外族人有君王统治他们，那些统治者被称为恩主，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 5:5; 路加福音 9:48; 马太福音 18:3–5"> 但你们不可这样。相反，你们中间位分最高的，要像最卑微的；做首领的，要像服侍人的。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 20:28; 路加福音 12:37; 约翰福音 13:5–16"> 坐席的和服侍的哪个位分高呢？难道不是坐席的那个吗？然而，我在你们当中像是服侍的。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:18; 希伯来书 4:15; 使徒行传 1:25"> “在我患难之时，你们一直在我身边，</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 25:34; 提摩太后书 2:12; 雅各书 2:5"> 所以，我父怎样将国赐给我，我也照样将国赐给你们，</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:28; 马太福音 8:11; 启示录 2:26–27"> 使你们在我的国中和我同席吃喝，并且坐在宝座上审判以色列的十二个支派。”</span>
</div>
</div>

## 预言彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:8; 撒迦利亚书 3:1; 约伯记 1:6–12"> 耶稣说：“西门！西门！撒旦已经要求像筛麦子一样筛你们，</span>
<span className="v" id="v32" data-v="32" data-xref="彼得前书 5:8–10; 约翰福音 21:15–17; 约翰福音 17:9–11"> 但我已经为你祷告了，叫你不至于失去信心。你回头以后，要让你的弟兄刚强。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 14:31; 马太福音 26:33–35; 马可福音 14:29"> 西门·彼得说：“主啊，我已准备好和你一起坐牢，一起受死！”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 13:38; 马太福音 26:34; 马可福音 14:30"> 耶稣说：“彼得，我告诉你，今早鸡叫之前，你会三次不认我。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 10:9–10; 路加福音 10:4; 诗篇 23:1"> 耶稣又问门徒：“我从前派你们出去，没有带钱袋、背包和鞋，你们有任何缺乏吗？” 他们答道：“没有。”</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:22–25; 帖撒罗尼迦前书 3:4; 帖撒罗尼迦前书 2:14–15"> 耶稣说：“但现在如果有钱袋或背包，都要带着；如果没有刀，要卖掉衣服买刀。</span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 53:12; 路加福音 23:32; 哥林多后书 5:21"> 我告诉你们，‘祂被列在罪犯中’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书53:12。">a</a></sup>这句经文必在我身上应验，因为圣经上有关我的事情快要实现了。”</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:49; 马太福音 26:52–54; 约翰福音 18:36"> 他们说：“主啊，请看，这里有两把刀。”耶稣说：“够了。”</span>
</div>
</div>

## 橄榄山上的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 21:37; 约翰福音 18:1–2; 马太福音 21:1"> 耶稣出去，照常前往橄榄山，门徒也跟着祂。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 6:13; 马太福音 26:36–46; 路加福音 22:46"> 到了地方，祂对门徒说：“你们要祷告，以免陷入诱惑！”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 26:39; 马可福音 14:35; 路加福音 18:11"> 然后，祂独自走到离门徒约有扔一块石头那么远的地方跪下祷告：</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:27–28; 马太福音 26:39; 马太福音 26:42"> “父啊，若你愿意，求你撤去此杯。然而，愿你的旨意成就，而非我的意愿。”</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:11; 马太福音 26:53; 诗篇 91:11–12"> 有一位从天上来的天使向祂显现，给祂加添力量。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米哀歌 1:12; 希伯来书 5:7; 诗篇 22:12–21"> 祂心中极其悲痛，祷告更恳切，汗珠如血滴落在地上。</span>
<span className="v" id="v45" data-v="45" data-xref="马可福音 14:40–41; 马太福音 26:43; 马太福音 26:40"> 祂祷告完后，便起身回到门徒那里，看见他们因忧愁而疲惫地睡着了，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 22:40; 约拿书 1:6; 路加福音 21:34–36"> 就说：“你们为什么睡觉呢？要起来祷告，以免陷入诱惑！”</span>
</div>
</div>

## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马可福音 14:41–50; 约翰福音 18:2–11; 路加福音 22:3–6"> 耶稣还在说话的时候，十二使徒中的犹大已带着一群人赶到，他上前亲吻耶稣。</span>
<span className="v" id="v48" data-v="48" data-xref="马可福音 14:44–46; 撒母耳记下 20:9–10; 箴言 27:6"> 耶稣对他说：“犹大，你用亲吻的暗号来出卖人子吗？”</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 22:38"> 跟随耶稣的人见势不妙，就说：“主啊，我们要挥刀反击吗？”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 18:10–11; 马可福音 14:47; 罗马书 12:19"> 其中一人挥刀朝大祭司的奴仆砍过去，削掉了他的右耳。</span>
<span className="v" id="v51" data-v="51" data-xref="罗马书 12:21; 哥林多后书 10:1; 彼得前书 2:21–23"> 耶稣却说：“住手！够了！”于是祂摸那奴仆的耳朵，治好了他，</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 22:4; 马可福音 14:48–49; 约翰福音 17:12"> 然后对前来抓祂的祭司长、圣殿护卫长和长老说：“你们像对付强盗一样拿着刀棍来抓我吗？</span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 12:27; 以弗所书 6:12; 使徒行传 26:18"> 我天天和你们一起在圣殿里，你们没有抓我。但现在正是黑暗当权、你们得势的时候了！”</span>
</div>
</div>

## 彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="马可福音 14:53–54; 马太福音 26:57–58; 约翰福音 18:12–17"> 他们抓住耶稣，把祂押到大祭司的府第。彼得远远地跟在后面。</span>
<span className="v" id="v55" data-v="55" data-xref="诗篇 26:4–5; 哥林多后书 6:15–17; 马可福音 14:66–72"> 他们在庭院当中生起了火，围坐一团，彼得也坐在他们中间。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 18:17; 马可福音 14:6; 马可福音 14:17"> 有个婢女看见彼得坐在火堆边，就盯着他看，说：“这人跟耶稣是一伙的！”</span>
<span className="v" id="v57" data-v="57" data-xref="约翰一书 1:9; 约翰福音 18:25; 马太福音 26:70"> 彼得却否认说：“你这女子，我不认识祂。”</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 18:25; 马太福音 26:71–72; 马可福音 14:69–70"> 过了一会儿，又有个人看见了彼得，就说：“你也是他们一伙的！” 彼得说：“你这人，我不是！”</span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 18:26–27; 马可福音 14:69–70; 马太福音 26:73–74"> 大约一小时之后，又有人断言：“这人肯定跟祂是一伙的，因为他也是加利利人。”</span>
<span className="v" id="v60" data-v="60" data-xref="马太福音 26:74–75; 路加福音 22:34; 马可福音 14:71–72"> 彼得说：“你这人，我不知道你在说什么！”话音未落，鸡就叫了。</span>
<span className="v" id="v61" data-v="61" data-xref="路加福音 22:34; 以赛亚书 57:15–18; 耶利米书 31:18–20"> 这时，主转过头来望着彼得，彼得想起主对他说的话：“今早鸡叫之前，你会三次不认我。”</span>
<span className="v" id="v62" data-v="62" data-xref="马太福音 26:75; 哥林多前书 10:12; 马可福音 14:72"> 他就到外面，痛哭起来。</span>
</div>
</div>

## 在公会受审

<div className="bt">
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="约翰福音 18:22; 马可福音 14:55–65; 约伯记 16:9–10"> 看守耶稣的人嘲弄祂，殴打祂，</span>
<span className="v" id="v64" data-v="64" data-xref="士师记 16:25; 士师记 16:21"> 蒙住祂的眼睛，对祂说：“说预言吧！是谁在打你？”</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 12:10; 马太福音 12:31–32; 马太福音 27:39"> 还说了许多侮辱祂的话。</span>
<span className="v" id="v66" data-v="66" data-xref="马太福音 27:1; 马可福音 15:1; 使徒行传 22:5"> 天亮后，百姓的长老、祭司长和律法教师聚在一起，把耶稣押到他们的公会，</span>
<span className="v" id="v67" data-v="67" data-xref="马太福音 11:3–5; 约翰福音 8:43–45; 马太福音 26:63–68"> 对祂说：“如果你是基督，就告诉我们。” 耶稣说：“即使我告诉你们，你们也不会相信。</span>
<span className="v" id="v68" data-v="68" data-xref="路加福音 20:41–44; 路加福音 20:3–7"> 如果我问你们，你们也不会回答。</span>
<span className="v" id="v69" data-v="69" data-xref="但以理书 7:13–14; 诗篇 110:1; 马可福音 16:19"> 但从今以后，人子要坐在大能上帝的右边。”</span>
<span className="v" id="v70" data-v="70" data-xref="路加福音 23:3; 马太福音 27:11; 马太福音 26:64"> 他们都问：“那么，你是上帝的儿子吗？”耶稣回答说：“你们说我是。”</span>
<span className="v" id="v71" data-v="71" data-xref="马太福音 26:65–66; 马可福音 14:63–64"> 他们说：“我们还需要什么见证呢？我们亲耳听见祂自己说的。”</span>
</div>

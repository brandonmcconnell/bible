## 约拿的祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米哀歌 3:53–56; 诗篇 130:1–2; 诗篇 91:15"> 约拿在鱼腹中向他的上帝耶和华祷告说：</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 18:4–6; 诗篇 120:1; 诗篇 34:6"> <span className="pl pl-1">“耶和华啊，我遭遇患难的时候向你求告，</span><br /><span className="pl pl-1">你就应允我。</span><br /><span className="pl pl-1">我在阴间的深处呼求你，</span><br /><span className="pl pl-1">你也垂听我的声音。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 42:7; 耶利米哀歌 3:54; 诗篇 69:1–2"> <span className="pl pl-1">你把我抛进深海，</span><br /><span className="pl pl-1">抛进大洋的腹地，</span><br /><span className="pl pl-1">洋流围困我，</span><br /><span className="pl pl-1">你的巨浪洪涛淹没我。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 31:22; 诗篇 5:7; 历代志下 6:38"> <span className="pl pl-1">我心想，我从你面前被赶走，</span><br /><span className="pl pl-1">但我还要再瞻仰你的圣殿。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 69:1–2; 耶利米哀歌 3:54; 诗篇 40:2"> <span className="pl pl-1">波涛吞噬我，</span><br /><span className="pl pl-1">深海围困我，</span><br /><span className="pl pl-1">海草缠绕着我的头。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 30:3; 诗篇 16:10; 以赛亚书 38:17"> <span className="pl pl-1">我下沉到山的根基，</span><br /><span className="pl pl-1">大地的门闩把我永远关住；</span><br /><span className="pl pl-1">然而，我的上帝耶和华啊，</span><br /><span className="pl pl-1">你却把我的性命从深坑中拯救出来。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 18:6; 历代志下 30:27; 诗篇 11:4"> <span className="pl pl-1">我的生命渐渐消逝的时候，</span><br /><span className="pl pl-1">我就想起了耶和华。</span><br /><span className="pl pl-1">我的祷告进入你的圣殿，</span><br /><span className="pl pl-1">达到你面前。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 31:6; 列王纪下 17:15; 耶利米书 2:13"> <span className="pl pl-1">那些信奉虚无神明的人，</span><br /><span className="pl pl-1">背弃了怜爱他们的上帝</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“背弃了怜爱他们的上帝”或译“背弃了他们对上帝的忠诚”。">a</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 3:8; 诗篇 50:14; 传道书 5:4–5"> <span className="pl pl-1">但我要用感谢的声音向你献祭，</span><br /><span className="pl pl-1">我必还我许的愿，</span><br /><span className="pl pl-1">因为救恩来自耶和华。”</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 8:26–27; 诗篇 33:9; 创世记 1:3"> <span className="pl pl-1">于是，耶和华命令那条鱼，</span><br /><span className="pl pl-1">鱼就把约拿吐到陆地上。</span></span>

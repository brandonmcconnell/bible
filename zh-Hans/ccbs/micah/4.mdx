## 耶路撒冷的将来

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 2:1–4; 耶利米书 3:17; 使徒行传 2:17"> <span className="pl pl-1">在末后的日子，</span><br /><span className="pl pl-1">耶和华殿所在的山必耸立，</span><br /><span className="pl pl-1">高过群山，超过万岭，</span><br /><span className="pl pl-1">万民都要涌向它。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 2:3; 耶利米书 31:6; 使徒行传 1:8"> <span className="pl pl-1">列国都必来，说：</span><br /><span className="pl pl-1">“来吧，让我们登耶和华的山，</span><br /><span className="pl pl-1">去雅各之上帝的殿。</span><br /><span className="pl pl-1">祂必教导我们行祂的道，</span><br /><span className="pl pl-1">让我们走祂的路。”</span><br /><span className="pl pl-1">因为训诲必出于锡安，</span><br /><span className="pl pl-1">耶和华的话语必来自耶路撒冷。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 2:4; 约珥书 3:9–16; 马太福音 25:31–32"> <span className="pl pl-1">祂必在列邦施行审判，</span><br /><span className="pl pl-1">为远方的强国平息纷争。</span><br /><span className="pl pl-1">他们必把刀剑打成犁头，</span><br /><span className="pl pl-1">将矛枪打成镰刀。</span><br /><span className="pl pl-1">国与国不再刀兵相见，</span><br /><span className="pl pl-1">人们也不再学习战事。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 3:10; 列王纪上 4:25; 以西结书 39:26"> <span className="pl pl-1">人人都安然坐在自己的葡萄树和无花果树下，</span><br /><span className="pl pl-1">不再担惊受怕。</span><br /><span className="pl pl-1">这是万军之耶和华亲口说的。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 10:12; 约书亚记 24:15; 歌罗西书 3:17"> <span className="pl pl-1">万民都遵从自己神明的名，</span><br /><span className="pl pl-1">但我们要永远遵从我们的上帝耶和华的名。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="西番雅书 3:19; 以西结书 34:12–17; 以赛亚书 35:3–6"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“到那日，我要聚集瘸腿的，</span><br /><span className="pl pl-1">招聚被掳的和被我惩罚的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:14; 以赛亚书 24:23; 弥迦书 2:12"> <span className="pl pl-1">我要使瘸腿的成为余民，</span><br /><span className="pl pl-1">让被掳的成为强国。</span><br /><span className="pl pl-1">耶和华要在锡安山做王治理他们，</span><br /><span className="pl pl-1">从那时直到永远。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 1:26; 启示录 22:5; 撒迦利亚书 9:10"> <span className="pl pl-1">“你这羊群的瞭望塔，</span><br /><span className="pl pl-1">少女锡安的坚垒啊！</span><br /><span className="pl pl-1">你从前的国权必得恢复，</span><br /><span className="pl pl-1">少女耶路撒冷的王位必归你。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 8:19; 以赛亚书 3:1–7; 耶利米哀歌 4:20"> <span className="pl pl-1">现在你为何大声哭喊？</span><br /><span className="pl pl-1">是因为你没有王吗？</span><br /><span className="pl pl-1">难道你的谋士都死了吗，</span><br /><span className="pl pl-1">以致你像分娩的妇人一样痛苦不堪？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 48:20; 以赛亚书 52:9–12; 列王纪下 20:18"> <span className="pl pl-1">少女锡安啊，</span><br /><span className="pl pl-1">你要像分娩的妇人一样辗转呻吟，</span><br /><span className="pl pl-1">因为你现在要离开这城，</span><br /><span className="pl pl-1">住在荒野，被掳到巴比伦。</span><br /><span className="pl pl-1">在那里，你将得到解救；</span><br /><span className="pl pl-1">在那里，耶和华必从敌人手中救赎你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="俄巴底亚书 1:12; 以赛亚书 5:25–30; 弥迦书 7:10"> <span className="pl pl-1">现在许多国家一起来攻击你，说：</span><br /><span className="pl pl-1">“愿锡安遭蹂躏，</span><br /><span className="pl pl-1">我们要看着锡安被毁灭。”</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 55:8; 耶利米书 29:11; 罗马书 11:33–34"> <span className="pl pl-1">他们却不知道耶和华的心意，</span><br /><span className="pl pl-1">也不明白祂的计划。</span><br /><span className="pl pl-1">祂聚集他们，</span><br /><span className="pl pl-1">像把禾捆堆积在麦场一样。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 41:15–16; 但以理书 2:44; 撒迦利亚书 9:13–15"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“少女锡安啊，</span><br /><span className="pl pl-1">起来打谷吧！</span><br /><span className="pl pl-1">我要给你铁角，</span><br /><span className="pl pl-1">我要给你铜蹄。</span><br /><span className="pl pl-1">你要打碎列国，</span><br /><span className="pl pl-1">将他们的不义之财献给耶和华，</span><br /><span className="pl pl-1">把他们的财富献给普天下的主。”</span></span>
</div>

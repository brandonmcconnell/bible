## 欺压者的命运

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 36:4; 以赛亚书 32:7; 诗篇 7:14–16"> <span className="pl pl-1">躺在床上图谋不轨、</span><br /><span className="pl pl-1">盘算作恶的人有祸了！</span><br /><span className="pl pl-1">天一亮，他们就依仗手中的权势行恶。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 5:8; 耶利米书 22:17; 阿摩司书 8:4"> <span className="pl pl-1">他们贪图田地，就去霸占；</span><br /><span className="pl pl-1">想要房屋，就去抢夺。</span><br /><span className="pl pl-1">他们欺压人的全家，</span><br /><span className="pl pl-1">诈取别人的产业。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 8:3; 阿摩司书 5:13; 以赛亚书 2:11–12"> <span className="pl pl-1">所以，耶和华说：</span><br /><span className="pl pl-1">“我正计划降灾惩罚你们这族，</span><br /><span className="pl pl-1">你们无法逃脱，</span><br /><span className="pl pl-1">再也不能趾高气扬，</span><br /><span className="pl pl-1">因为这是你们灾祸临头的日子。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="哈巴谷书 2:6; 耶利米书 9:10; 耶利米书 9:17–21"> <span className="pl pl-1">到那日，人们要唱悲戚的哀歌讥讽你们说，</span><br /><span className="pl pl-1">‘我们彻底完了，</span><br /><span className="pl pl-1">耶和华把我们的产业转给别人。</span><br /><span className="pl pl-1">祂竟拿走我们的产业，</span><br /><span className="pl pl-1">把田地分给掳掠我们的人。’”</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:8; 约书亚记 18:4; 约书亚记 18:10"> <span className="pl pl-1">因此，他们在耶和华的会众中将无人抽签分地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 2:12; 以赛亚书 30:10; 使徒行传 5:40"> <span className="pl pl-1">他们的先知说：</span><br /><span className="pl pl-1">“不要说预言了，</span><br /><span className="pl pl-1">不要预言这种事，</span><br /><span className="pl pl-1">我们不会蒙受羞辱。”</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 84:11; 诗篇 15:2; 耶利米书 15:16"> <span className="pl pl-1">雅各家啊，你们怎能说：</span><br /><span className="pl pl-1">“耶和华已经不耐烦了吗？</span><br /><span className="pl pl-1">祂会做这些事吗？”</span><br /><span className="pl pl-1">耶和华说：“我的话岂不有益于行为正直的人吗？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 120:6–7; 撒母耳记下 20:19; 以赛亚书 9:21"> <span className="pl pl-1">近来，你们像仇敌一样起来攻击我的子民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“你们像仇敌一样起来攻击我的子民”或译“我的子民如仇敌一样兴起来”。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">你们剥去那些如从战场归来一样毫无戒备的过路人的外衣。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="哈巴谷书 2:14; 以西结书 39:21; 哥林多后书 4:6"> <span className="pl pl-1">你们把我子民中的妇女从她们的幸福家园赶走，</span><br /><span className="pl pl-1">又从她们的子女身上永远地夺去我的尊荣。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 12:9; 诗篇 106:38; 列王纪下 17:6"> <span className="pl pl-1">你们起来走吧！</span><br /><span className="pl pl-1">这里不再是你们的安居之地！</span><br /><span className="pl pl-1">因为这里已遭玷污，</span><br /><span className="pl pl-1">被彻底毁坏。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 5:31; 以赛亚书 30:10–11; 哥林多后书 11:13–15"> <span className="pl pl-1">倘若有骗子撒谎说，</span><br /><span className="pl pl-1">‘我预言你们会有美酒佳酿。’</span><br /><span className="pl pl-1">他就会成为这个民族的先知。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 4:6–7; 弥迦书 7:18; 何西阿书 1:11"> <span className="pl pl-1">“雅各家啊，</span><br /><span className="pl pl-1">我必把你们都聚集起来，</span><br /><span className="pl pl-1">我必把以色列的余民集合起来。</span><br /><span className="pl pl-1">我要将他们安顿在一起，</span><br /><span className="pl pl-1">好像羊圈里的羊，</span><br /><span className="pl pl-1">又如草场上的羊群；</span><br /><span className="pl pl-1">那里必人声鼎沸。</span><br /></span>

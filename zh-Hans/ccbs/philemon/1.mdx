<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:25; 歌罗西书 4:17; 罗马书 16:5"> 亚腓亚姊妹和我们的战友亚基布，以及在你家聚会的弟兄姊妹。</span>

## 称赞腓利门

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:8; 以弗所书 1:16; 帖撒罗尼迦后书 1:3"> 腓利门弟兄，我每次为你们祷告时都会感谢我的上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:4; 以弗所书 1:15; 哥林多前书 16:1"> 因为我听说了你对众圣徒的爱心和对主耶稣的信心。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:9–11; 彼得后书 1:8; 歌罗西书 1:9"> 我求上帝使你因着有份于信仰而明白我们在基督里所拥有的一切福分。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:13; 帖撒罗尼迦前书 3:9; 哥林多后书 7:4"> 弟兄啊，你的爱心给我带来极大的喜乐和安慰，因为你使众圣徒感到欣慰。</span>
</div>
</div>

## 凭爱心求情

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 2:6; 哥林多后书 10:8; 哥林多后书 3:12"> 因此，我尽管可以靠着基督吩咐你去做当做的事，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:20; 以弗所书 4:1; 罗马书 12:1"> 然而我这上了年纪又为基督耶稣的缘故被囚禁的保罗宁愿凭爱心求你，</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 4:9; 哥林多前书 4:15; 提摩太前书 1:2"> 就是替阿尼西谋<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“阿尼西谋”这个名字意思是有用、有益处。">a</a></sup>求你。他是我在狱中带领归主的属灵儿子，</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 4:11; 约伯记 30:1–2; 彼得前书 2:10"> 他过去对你没有什么益处，但现在对你对我都有益处。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:14–15; 耶利米书 31:20; 马可福音 11:25"> 我现在派我深爱的阿尼西谋回你那里。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:7; 以弗所书 3:1; 哥林多前书 16:17"> 我本想把他留在身边，让他在我为传福音而坐牢期间替你服侍我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:7; 历代志上 29:17; 彼得前书 5:2–3"> 不过，未经你同意，我不愿这样做，免得你的善行是出于勉强，而非自愿。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 50:20; 创世记 45:5–8; 以赛亚书 20:6"> 也许他暂时离开你是为了让你以后永远得到他。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:22; 马太福音 23:8; 哥林多前书 7:22"> 你得到的不再是一个奴隶，而是一位远超过奴隶的亲爱弟兄。对我而言，的确如此；从人的角度和主内关系而言，他更是你亲爱的弟兄。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:23; 马太福音 10:40; 腓利门书 1:12"> 你若当我是同伴，就请你像接纳我一样接纳他。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:4–7"> 如果他得罪你，或亏欠你什么，都记在我的账上吧。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:11; 加拉太书 5:2; 哥林多前书 4:15"> 我保罗在此亲笔保证，我必偿还。其实我不说你也知道，你欠我的是你整个人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰三书 1:4; 腓利门书 1:7; 腓利门书 1:12"> 弟兄啊，看在主的份上，让我从你那里得益处，在基督里心得安慰吧！</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦后书 3:4; 哥林多后书 2:3; 哥林多后书 7:16"> 我写信给你，深信你一定会照办，甚至超过我的要求。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 1:11; 腓立比书 2:24; 约翰二书 1:12"> 同时，也请你为我预备住处，因为我盼望借着你们的祷告，我可以蒙恩到你们那里。</span>
</div>
</div>

## 问候

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:7; 罗马书 16:7; 歌罗西书 4:12"> 为了基督耶稣的缘故和我一同坐牢的以巴弗问候你。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10–11; 歌罗西书 4:14; 歌罗西书 4:10"> 此外，我的同工马可、亚里达古、底马和路加都问候你。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 4:22; 罗马书 16:23; 罗马书 16:20"> 愿我们主耶稣基督的恩典与你们的灵同在。阿们！</span>
</div>
</div>

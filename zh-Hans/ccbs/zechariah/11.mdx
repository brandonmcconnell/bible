## 羊群必遭杀戮

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 22:6–7; 耶利米书 22:23; 路加福音 21:23–24"> 黎巴嫩啊，打开你的门吧，<br /><span className="pl pl-1">好让火焰吞噬你的香柏树。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 2:12–17; 以西结书 31:17; 以赛亚书 10:33–34"> <span className="pl pl-1">松树啊，哀号吧，</span><br /><span className="pl pl-1">因为香柏树已经倒下，</span><br /><span className="pl pl-1">挺拔的树木已被毁坏。</span><br /><span className="pl pl-1">巴珊的橡树啊，哀号吧，</span><br /><span className="pl pl-1">因为茂密的树林已被砍倒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 50:44; 耶利米书 25:34–36; 撒迦利亚书 11:8"> <span className="pl pl-1">听啊，牧人在哀号，</span><br /><span className="pl pl-1">因为他们肥美的草场已被毁坏。</span><br /><span className="pl pl-1">听啊，狮子在吼叫，</span><br /><span className="pl pl-1">因为约旦河畔的丛林已被毁坏。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 11:7; 马太福音 23:37; 罗马书 15:8"> 我的上帝耶和华说：“你去牧养这群待宰的羊。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 50:7; 何西阿书 12:8; 提摩太前书 6:5–10"> 买羊的宰羊却不受惩罚，卖羊的说，‘耶和华当受称颂！我发财了。’它们的牧人毫不怜悯它们。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 13:14; 马太福音 22:7; 以赛亚书 9:19–21"> 我不再怜悯这地方的居民，我要使他们落在邻人及其君王手中，任这地方被摧毁，必不从敌人手中拯救他们。这是耶和华说的。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 11:14; 撒迦利亚书 11:4; 以赛亚书 11:4"> 于是，我牧养这群最困苦的待宰之羊。我拿了两根杖，一根叫“恩惠”，一根叫“联合”，开始牧养这群羊。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 49:7; 马太福音 23:34–36; 约翰福音 15:18"> 我在一个月之内除掉了三个牧人。<br />我厌烦羊群，他们也厌恶我。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 43:11; 马太福音 13:10–11; 马太福音 21:19"> 于是我说：“我不再牧养你们了。要死的就死吧，要亡的就亡吧，让剩下的互相吞吃吧。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 11:7; 诗篇 89:39; 希伯来书 8:8–13"> 然后，我拿起那根叫“恩惠”的杖，把它折断，以废除我与万民所立的约。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅书 3:12; 路加福音 2:38; 申命记 31:21"> 约就在当天废除了，那些注视着我的困苦羊便知道这是上帝的话。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:15; 出埃及记 21:32; 路加福音 22:3–6"> 我对他们说：“你们若认为好，就给我工钱，不然就算了。”于是，他们给了我三十块银子作工钱。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 27:3–10; 使徒行传 1:18–19; 以赛亚书 53:2–3"> 耶和华对我说：“把这一大笔钱丢给窑户吧，这就是我在他们眼中的价值！”我便把三十块银子丢给圣殿中的窑户。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 9:21; 以赛亚书 11:13; 使徒行传 23:7–10"> 我又把那根叫“联合”的杖折断，以断开犹大和以色列之间的手足之情。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 6:10–12; 路加福音 11:40; 耶利米书 2:26–27"> 耶和华又对我说：“你再拿起愚昧牧人的器具，</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 34:2–6; 耶利米书 23:2; 马太福音 23:2–4"> 因为我要使一位牧人在地上兴起，他不照顾丧亡的，不寻找失散的，不医治受伤的，不牧养健壮的，反而吃肥羊的肉，撕掉它们的蹄子。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 23:1; 以西结书 13:3; 哥林多前书 8:4"> <span className="pl pl-1">“丢弃羊群的无用牧人有祸了！</span><br /><span className="pl pl-1">愿刀砍在他的臂膀和右眼上！</span><br /><span className="pl pl-1">愿他的臂膀彻底枯槁，</span><br /><span className="pl pl-1">他的右眼完全失明！”</span></span>
</div>

## 耶和华的日子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 13:9; 以赛亚书 2:12; 以赛亚书 13:6"> 看啊，耶和华的日子快到了，那时你那里的财物必被抢掠和瓜分。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:20–24; 以赛亚书 13:16; 罗马书 9:27–29"> 因为我必招聚万国去攻打耶路撒冷。那时，城必失守，房屋必被洗劫，妇女必被玷污。半城的人必被掳去，剩下的人必不会从城中被铲除。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 12:9; 西番雅书 3:19; 撒迦利亚书 2:8–9"> 那时，耶和华必出来与万国争战，像从前争战的日子一样。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 1:3–4; 以西结书 11:23; 使徒行传 1:11–12"> 到那天，祂的脚必踏在耶路撒冷东面的橄榄山上，这山必从东至西分成两半，一半向北移，一半向南移，中间形成极大的山谷。</span>
<span className="v" id="v5" data-v="5" data-xref="犹大书 1:14–15; 阿摩司书 1:1; 马太福音 25:31"> 你们要从我的山谷逃跑，因为山谷必延伸到亚萨。你们必逃跑，像犹大王乌西雅年间的人躲避大地震一样。我的上帝耶和华必带着所有的圣者降临。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 97:10–11; 诗篇 112:4; 约翰福音 12:46"> 到那天，将没有光、严寒和冰霜。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 22:5; 帖撒罗尼迦前书 5:2; 但以理书 12:4"> 那将是奇特的日子，没有昼夜之分，晚上仍然有光，只有耶和华知道那日何时来临。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="启示录 22:1–2; 约翰福音 7:38; 约翰福音 4:14"> 到那天，必有活水从耶路撒冷涌出，一半流向死海，一半流向地中海，冬夏不变。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:5–6; 启示录 11:15; 但以理书 7:27"> 耶和华必做普世的王。到那天，必唯祂独尊，唯祂的名独尊。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 12:6; 约书亚记 15:32; 列王纪上 15:22"> 从迦巴直到耶路撒冷南边的临门，整个地区都要变为平原。从便雅悯门到旧门，再到角门，从哈楠业楼到王的榨酒池，耶路撒冷必仍然矗立在原处。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 22:3; 耶利米书 23:5–6; 阿摩司书 9:15"> 城内必有人居住，不再遭毁灭的咒诅。耶路撒冷必安享太平。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 39:17–20; 以赛亚书 66:15–16; 弥迦书 4:11–13"> 耶和华必降瘟疫给攻打耶路撒冷的万邦，使他们活着的时候皮肉已经腐烂，眼睛烂在眼眶中，舌头烂在口中。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亚书 12:4; 启示录 17:12–17; 士师记 7:22"> 到那天，耶和华必使他们慌乱不堪，彼此揪住，互相殴打。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 23:18; 撒迦利亚书 12:2; 历代志下 20:25–27"> 犹大也必在耶路撒冷争战，四围列国的财物，包括大量的金银和衣服，必被收聚起来。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 14:12"> 同样的瘟疫也必降在马匹、骡子、骆驼、驴和营中的其他牲畜身上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 14:17–19; 以赛亚书 66:23; 以赛亚书 66:18–21"> 前来攻打耶路撒冷的万国中的幸存者，必每年上来敬拜大君王万军之耶和华，并且守住棚节。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司书 4:7–8; 以赛亚书 60:12; 耶利米书 14:4"> 地上万族中若有人不上耶路撒冷敬拜大君王万军之耶和华，他们必得不到雨水。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 14:15; 申命记 11:10–11; 撒迦利亚书 14:12"> 埃及人若不上来敬拜，也必得不到雨水，耶和华必使他们和不上来守住棚节的列国一样遭受瘟疫。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 3:19"> 这将是埃及和不上来守住棚节的万国所得的惩罚。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 3:16–17; 出埃及记 39:30; 利未记 8:9"> 到那天，马铃上也必刻上“耶和华的圣物”的字样。耶和华殿内的锅必像祭坛前的碗一样圣洁。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 44:9; 罗马书 14:6–7; 哥林多前书 10:31"> 耶路撒冷和犹大的锅都是万军之耶和华的圣物，来献祭的人都可以用这些锅煮祭肉。到那天，万军之耶和华的殿中必再也没有商人。</span>
</div>

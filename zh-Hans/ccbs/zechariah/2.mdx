## 准绳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 40:3; 撒迦利亚书 1:16; 以西结书 47:4"> 我又举目观看，见有人拿着准绳。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 31:39; 以西结书 45:6; 启示录 21:15–17"> 于是我问：“你要去哪里？”他回答说：“去丈量耶路撒冷，看看有多宽多长。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 1:19; 撒迦利亚书 1:8–11; 撒迦利亚书 4:5"> 此前与我说话的天使离去时，另一位天使迎着他走来，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 1:17; 耶利米书 33:22; 以西结书 38:11"> 对他说：“快跑去告诉那青年，‘耶路撒冷必像没有城墙限制的村庄，因为里面的人和牲畜太多了。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 4:5; 撒迦利亚书 9:8; 诗篇 3:3"> 耶和华说，我要成为一堵火墙环绕耶路撒冷，作城中的荣耀。’</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 48:20; 以西结书 17:21; 以赛亚书 52:11–12"> “耶和华说，‘快快逃离北方之地吧！因为我曾把你们分散到天下四方，这是耶和华说的。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 48:20; 创世记 19:17; 以赛亚书 52:11"> 住在巴比伦城的人啊，快逃到锡安吧！’”</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 17:8; 申命记 32:10; 约翰福音 15:21–23"> 万军之耶和华为了彰显祂的荣耀，差遣我去那些掳掠你们的国家，因为谁动你们，就是动祂的瞳仁。祂说：</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 19:16; 以赛亚书 14:2; 撒迦利亚书 4:9"> “看啊，我要出手攻击他们，使他们被自己的奴隶掳掠。那时你们便知道是万军之耶和华差遣了我。”</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 28:20; 约翰福音 1:14; 西番雅书 3:14–15"> 耶和华说：“少女锡安啊，高声欢唱吧！因为我要来住在你里面。”</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 11:15; 彼得前书 2:9–10; 使徒行传 28:28"> 到那天，许多国家都要归向耶和华，做祂的子民。祂要住在你们当中。那时你们便知道，是万军之耶和华差遣我到你们这里来的。</span>
<span className="v" id="v12" data-v="12" data-xref="撒迦利亚书 1:17; 申命记 32:9; 耶利米书 10:16"> 耶和华必拥有犹大作祂圣地的产业，祂必再次拣选耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:20; 诗篇 68:5; 诗篇 78:65"> 世人都当在耶和华面前肃静，因为祂要从圣所起身行动。</span>

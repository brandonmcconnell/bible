## 对耶路撒冷的应许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 万军之耶和华的话传给了我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 2:18; 撒迦利亚书 1:14–16; 以赛亚书 42:13–14"> “万军之耶和华说，‘我笃爱锡安，我为锡安而大发烈怒。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 1:16; 撒迦利亚书 2:10–11; 约翰福音 1:14"> 我要回到锡安，住在耶路撒冷。耶路撒冷必被称为忠信之城，万军之耶和华的山必被称为圣山。这是耶和华说的。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 65:20–22; 约伯记 5:26; 耶利米哀歌 5:11–15"> 必再次有年纪老迈、手拿拐杖的男女坐在耶路撒冷的街上。这是万军之耶和华说的。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 31:13; 马太福音 11:16–17; 耶利米书 30:19–20"> 街上必到处都是玩耍的男女孩童。’</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 32:27; 罗马书 4:20–21; 民数记 11:22–23"> 万军之耶和华说，‘那时，这事在这些余民看来是稀奇的，但在我看来毫不稀奇。这是万军之耶和华说的。’</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 31:8; 罗马书 11:25–27; 玛拉基书 1:11"> 万军之耶和华说，‘看啊，我要从日出之地和日落之处救出我的子民，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 36:28; 以西结书 11:20; 耶利米书 31:33"> 带他们回到耶路撒冷居住。本着信实和公义，他们要做我的子民，我要做他们的上帝。’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 35:4; 历代志上 22:13; 以斯拉记 5:1–2"> “万军之耶和华说，‘在奠立万军之耶和华殿的根基那天，众先知都在场。现今听见这些先知之言的人啊，你们要刚强，以便建造圣殿！</span>
<span className="v" id="v10" data-v="10" data-xref="哈该书 1:6–11; 哈该书 2:16–18; 阿摩司书 3:6"> 那日之前，人和牲畜都得不到工钱。在敌人的威胁下，人们出入没有平安。因为我使众人彼此为敌。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 12:1; 哈该书 2:19; 撒迦利亚书 8:8–9"> 如今我不会像从前那样对待这些余民了。这是万军之耶和华说的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 26:4–5; 申命记 33:13; 创世记 27:28"> 因为他们必平安地撒种，葡萄树必结果子，土地必出产五谷，天必降下甘霖，我必把这些福气赐给这些余民。</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:20; 撒迦利亚书 8:9; 诗篇 72:17"> 犹大家和以色列家啊，从前你们在列国中是受咒诅的，现在我要拯救你们，使你们成为蒙福的人。你们不要害怕，要刚强。’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:28; 以西结书 24:14; 耶利米书 4:28"> “万军之耶和华说，‘从前你们的祖先惹我发怒，我决定毫不留情地降祸给他们。这是万军之耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 8:13; 弥迦书 7:18–20; 路加福音 12:32"> 现在我决定赐福给耶路撒冷和犹大家。你们不要害怕。</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所书 4:25; 撒迦利亚书 7:9; 诗篇 15:2"> 你们所当做的是：彼此说真话，在城门口秉公断案，使人和睦。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; 弥迦书 2:1–3; 耶利米书 44:4"> 不可设阴谋彼此相害，不可贪爱假誓，因为这些都是我所憎恶的。这是耶和华说的。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 万军之耶和华的话传给了我，说：</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 8:16; 耶利米书 39:2; 撒迦利亚书 7:5"> “万军之耶和华说，‘四月、五月、七月、十月的禁食必成为犹大家欢喜快乐的日子和幸福的节期。因此，你们要喜爱真理与和平。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 2:2–3; 弥迦书 4:1–2; 撒迦利亚书 2:11"> 各族的人和各城的居民都必来这里。这是万军之耶和华说的。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 7:2; 何西阿书 6:3; 诗篇 146:1–2"> 这一城的居民必到那一城，说，我们快去向耶和华求恩，去寻求万军之耶和华吧！我自己也去。</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亚书 8:21; 以赛亚书 60:3–22; 启示录 21:24"> 许多民族和强国必来耶路撒冷寻求万军之耶和华，向耶和华求恩。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 55:5; 哥林多前书 14:25; 以赛亚书 60:3"> 那时，十个来自列国、讲不同语言的人必拉住一个犹大人的衣角，说，让我们跟你们同去吧，因为我们听说上帝与你们同在。这是万军之耶和华说的。’”</span>
</div>
</div>

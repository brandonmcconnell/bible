## 呼吁公义和怜悯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 1:1; 以斯拉记 6:14–15; 撒迦利亚书 1:1"> 大流士王执政第四年九月，即基斯流月四日，耶和华的话传给了撒迦利亚。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 8:21; 耶利米书 26:19; 撒母耳记上 13:12"> 那时，伯特利人差遣沙利色、利坚米勒及其随从去向耶和华求恩。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 8:19; 雅各书 4:8–10; 玛拉基书 2:7"> 他们问万军之耶和华殿里的祭司和先知：“我们还要照多年的惯例在五月哀伤、禁食吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 10:16"> 万军之耶和华对我说：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 1:12; 以赛亚书 58:4–6; 哥林多前书 10:31"> “你要对境内的民众和祭司说，‘这七十年来，你们在五月和七月禁食、哀伤，难道真的是为了我吗？</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 11:20–21; 哥林多前书 11:26–29; 何西阿书 8:13"> 你们吃喝，难道不是为自己吃、为自己喝吗？</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:16–20; 耶利米书 17:26; 耶利米书 7:5"> 这些岂不是耶和华借从前的先知所宣告的吗？当时耶路撒冷和周围的城邑人口兴盛、繁荣，南地和丘陵都有人居住。’”</span>
<span className="v" id="v8" data-v="8"> 耶和华又对撒迦利亚说：</span>
<span className="v" id="v9" data-v="9" data-xref="弥迦书 6:8; 诗篇 82:2–4; 箴言 21:3"> “万军之耶和华曾对你们的祖先说，‘要秉公行义，彼此以慈爱和怜悯相待。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:28; 以赛亚书 1:23; 雅各书 5:4"> 不可欺压寡妇、孤儿、寄居者和穷人，不可设阴谋彼此相害。’</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 9:29; 耶利米书 8:5; 何西阿书 4:16"> 他们却不理会，顽梗地背过身去，充耳不闻，</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 11:19; 尼希米记 9:29–30; 历代志下 36:16"> 心如铁石，不遵从律法，也不遵从万军之耶和华借着祂的灵指示从前的先知所说的话。因此，万军之耶和华非常愤怒。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 1:24–28; 耶利米书 14:12; 以赛亚书 1:15"> 祂说，‘我曾呼唤他们，他们不听；将来他们呼求我，我也不听。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:33; 申命记 28:64; 耶利米书 23:19"> 我要用旋风把他们吹散到陌生的万国中，使他们的土地荒凉、杳无人迹，因为他们使美好的土地一片荒凉。’”</span>

## 耶路撒冷必蒙拯救

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 42:5; 耶利米书 51:15; 以赛亚书 57:16"> 以下是耶和华关于以色列的启示。 铺展穹苍、奠立大地的根基、造人里面灵魂的耶和华说：</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 14:14; 诗篇 75:8; 以赛亚书 51:22–23"> “看啊，我要使耶路撒冷成为令周围万民昏醉的酒杯。耶路撒冷被围困时，犹大也必受困。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:44; 撒迦利亚书 14:2–4; 但以理书 2:34–35"> 到那天，当地上的列国聚集起来攻击耶路撒冷的时候，我要使耶路撒冷成为一块沉重的石头。凡试图举起它的，必伤自己。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:28; 撒迦利亚书 12:3; 撒迦利亚书 12:6"> 到那天，我要使所有的战马惊恐，使骑士癫狂。我必看顾犹大家，使列邦的马匹瞎眼。这是耶和华说的。</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 10:12; 约珥书 3:16; 诗篇 18:32"> 那时，犹大的族长必心里说，‘耶路撒冷居民的力量来自他们的上帝——万军之耶和华。’</span>
<span className="v" id="v6" data-v="6" data-xref="俄巴底亚书 1:18; 弥迦书 5:5–8; 撒迦利亚书 2:4"> “到那天，我必使犹大的族长像木柴中的火盆，像禾捆中的火把，吞噬左右四围的列邦，但耶路撒冷人必仍在原处，仍在耶路撒冷城安居。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 30:18; 罗马书 3:27; 路加福音 1:51–53"> “耶和华必首先拯救犹大的帐篷，免得大卫家和耶路撒冷居民的荣耀超过犹大。</span>
<span className="v" id="v8" data-v="8" data-xref="弥迦书 5:2–4; 撒迦利亚书 9:8; 约珥书 3:16–17"> 到那天，耶和华必保护耶路撒冷的居民，使他们当中最软弱的像大卫一样刚强，使大卫家如同上帝，如同走在他们前面的耶和华的天使。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 54:17; 撒迦利亚书 14:2–3; 哈该书 2:22"> 到那天，我必毁灭前来攻击耶路撒冷的列国。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 1:7; 以西结书 39:29; 约珥书 2:28–29"> “我必将施恩和祷告的灵浇灌在大卫家和耶路撒冷的居民身上。他们必仰望我，就是他们所刺的那位，如丧独子一般为祂哀伤，如丧长子一般为祂痛哭。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 35:24; 列王纪下 23:29"> 到那天，耶路撒冷必一片哀声，犹如米吉多平原的哈达临门的哀声。</span>
<span className="v" id="v12" data-v="12" data-xref="撒迦利亚书 7:3; 路加福音 3:31; 撒母耳记下 5:14"> 境内家家户户都必哀哭。大卫家族的男子在一处，女子在一处；拿单家族的男子在一处，女子在一处；</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 23:7; 撒母耳记下 16:5; 历代志上 23:10"> 利未家族的男子在一处，女子在一处；示每家族的男子在一处，女子在一处。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 9:12"> 其余各家族也都是男子在一处，女子在一处。</span>

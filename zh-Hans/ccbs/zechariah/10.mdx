## 耶和华应许拯救以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="雅各书 5:16–18; 马太福音 7:7–8; 以赛亚书 44:3"> <span className="pl pl-1">要在春季向耶和华求雨。</span><br /><span className="pl pl-1">祂造出雷雨，</span><br /><span className="pl pl-1">为世人降下甘霖，</span><br /><span className="pl pl-1">赐人田间的菜蔬。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36; 耶利米书 27:9; 以西结书 34:5"> <span className="pl pl-1">因为神像说的是虚言，</span><br /><span className="pl pl-1">占卜者讲的是谎话，</span><br /><span className="pl pl-1">他们诉说的是假梦，</span><br /><span className="pl pl-1">他们的安慰是空话。</span><br /><span className="pl pl-1">所以人们如迷失的羊，</span><br /><span className="pl pl-1">因无牧人而遭受困苦。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西结书 34:2; 以西结书 34:7–10; 耶利米书 23:1–2"> <span className="pl pl-1">“我必向牧人发怒，</span><br /><span className="pl pl-1">我必惩罚这些首领</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“首领”希伯来文作“公山羊”。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">因为万军之耶和华必眷顾祂的羊群犹大家，</span><br /><span className="pl pl-1">使他们像战场上的骏马。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 9:10; 撒迦利亚书 9:8; 民数记 24:17"> <span className="pl pl-1">房角石、橛子、战弓，</span><br /><span className="pl pl-1">以及所有掌权者必出自犹大。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哈该书 2:22; 撒迦利亚书 9:13; 诗篇 20:7"> <span className="pl pl-1">他们必如战场上的勇士，</span><br /><span className="pl pl-1">将仇敌践踏在街上的泥土中。</span><br /><span className="pl pl-1">他们必争战，</span><br /><span className="pl pl-1">因为耶和华与他们同在。</span><br /><span className="pl pl-1">他们必使敌方的骑兵蒙羞。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="撒迦利亚书 13:9; 撒迦利亚书 10:12; 耶利米书 3:18"> <span className="pl pl-1">“我必使犹大家强盛，</span><br /><span className="pl pl-1">我必拯救约瑟家。</span><br /><span className="pl pl-1">我必带他们回到故土，</span><br /><span className="pl pl-1">因为我怜悯他们。</span><br /><span className="pl pl-1">他们必好像从未被我抛弃一样，</span><br /><span className="pl pl-1">因为我是他们的上帝耶和华，</span><br /><span className="pl pl-1">我必应允他们的祷告。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 9:15; 撒迦利亚书 9:17; 撒母耳记上 2:1"> <span className="pl pl-1">以法莲人必如勇士，</span><br /><span className="pl pl-1">他们必心里畅快，如同喝了酒，</span><br /><span className="pl pl-1">他们的儿女见状也必喜乐，</span><br /><span className="pl pl-1">他们必因耶和华而欢欣。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 5:26; 以赛亚书 7:18; 耶利米书 33:22"> <span className="pl pl-1">“我必吹哨聚集他们，</span><br /><span className="pl pl-1">因为我救赎了他们，</span><br /><span className="pl pl-1">他们必像从前一样人数众多。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 6:9; 何西阿书 2:23; 以斯帖记 8:17"> <span className="pl pl-1">虽然我把他们分散到列国，</span><br /><span className="pl pl-1">他们必在远方想起我，</span><br /><span className="pl pl-1">他们及其子女必得以幸存，</span><br /><span className="pl pl-1">并且回到故土。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 11:11; 弥迦书 7:14; 撒迦利亚书 8:7"> <span className="pl pl-1">我必从埃及领他们归回，</span><br /><span className="pl pl-1">从亚述招聚他们，</span><br /><span className="pl pl-1">领他们到基列和黎巴嫩，</span><br /><span className="pl pl-1">那里将不够他们居住。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 30:13; 弥迦书 5:5–6; 以赛亚书 43:2"> <span className="pl pl-1">祂必经过苦海，</span><br /><span className="pl pl-1">击打海浪，</span><br /><span className="pl pl-1">尼罗河必干涸，</span><br /><span className="pl pl-1">亚述的骄傲必扫地，</span><br /><span className="pl pl-1">埃及的势力必灭没。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 41:10; 以赛亚书 2:5; 撒迦利亚书 10:6"> <span className="pl pl-1">我必让他们靠耶和华而强盛，</span><br /><span className="pl pl-1">他们必奉祂的名行事。</span><br /><span className="pl pl-1">这是耶和华说的。”</span></span>
</div>

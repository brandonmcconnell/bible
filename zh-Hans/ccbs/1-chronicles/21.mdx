## 大卫统计人口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 24:1–25; 撒迦利亚书 3:1; 约伯记 2:4–6"> 撒旦起来攻击以色列，挑动大卫统计以色列人的数目。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 27:23–24; 撒母耳记下 3:10; 撒母耳记下 24:15"> 大卫对约押和其他军中的首领说：“你们要去，从别示巴一直到但，统计以色列的人口，然后回来禀告我，我好知道他们的数目。”</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:11; 以赛亚书 26:15; 历代志上 19:13"> 约押说：“愿耶和华使祂子民的人数比现在增加百倍。但我主我王啊，他们不都是你的仆人吗？我主为什么要这样做？为什么使以色列人陷于罪中呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:29; 出埃及记 1:17; 但以理书 3:18"> 但王不听约押的规劝。约押只好出去，走遍以色列，然后回到耶路撒冷，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 24:9; 历代志上 27:23"> 将人数奏告大卫：全以色列有一百一十万刀兵，犹大有四十七万。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 27:24; 民数记 1:47–49; 撒母耳记下 20:9–10"> 约押没有把利未人和便雅悯人算在其中，因为他厌恶王的这个命令。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:5; 约书亚记 7:5; 撒母耳记下 21:14"> 上帝也不喜悦这事，便降灾给以色列人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 12:13; 约翰一书 1:9; 创世记 34:7"> 大卫对上帝说：“我做这事犯了大罪。求你赦免仆人的罪，我做了极其愚昧的事。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 9:9; 撒母耳记下 24:11; 历代志上 29:29"> 耶和华对大卫的先见迦得说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 13:21–22; 启示录 3:19; 箴言 1:29–31"> “你去告诉大卫，我有三样灾祸，他可以选择让我降哪一样给他。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> 迦得就来见大卫，对他说：“耶和华说，‘你可以任选一样：</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 28:27; 使徒行传 12:23; 以西结书 14:19–21"> 或三年的饥荒，或被敌人的刀击败并追杀三个月，或国中被耶和华的刀惩罚，就是三天的瘟疫，让耶和华的天使在以色列全境施行毁灭。请你考虑好后告诉我，我好回复那差我来的。’”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 130:7; 以赛亚书 55:7; 腓立比书 1:23"> 大卫说：“我实在为难！不过我宁愿落在耶和华的手中，也不愿落在人的手中，因为耶和华有极大的怜悯。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 12:30; 历代志上 27:24; 列王纪下 19:35"> 于是，耶和华在以色列降下瘟疫，有七万人死亡。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:6; 出埃及记 32:14; 耶利米书 26:18"> 上帝差遣天使去毁灭耶路撒冷。天使正要毁灭的时候，耶和华见了就心生怜悯，对施行毁灭的天使说：“够了，住手吧！”当时，耶和华的天使正站在耶布斯人阿珥楠的麦场上。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 14:5; 列王纪上 21:27; 列王纪下 6:17"> 大卫举目看见耶和华的天使站在天地之间，手握着已出鞘的刀，指向耶路撒冷。大卫和众长老都身披麻衣，脸伏于地。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 16:63; 撒母耳记下 24:17; 约翰福音 10:11–12"> 大卫对上帝说：“吩咐统计人民数目的不是我吗？是我犯了罪，做了恶事，这些百姓有什么过错呢？我的上帝耶和华啊，愿你的手惩罚我和我的家族，不要把瘟疫降在你的子民身上。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:1; 撒母耳记下 24:18; 历代志上 21:11"> 耶和华的天使吩咐迦得去告诉大卫，他要在耶布斯人阿珥楠的麦场上为耶和华建一座坛。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:6; 约翰福音 2:5; 列王纪下 5:10–14"> 大卫照迦得奉耶和华之名所说的话去了麦场。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 6:11"> 那时，阿珥楠正在打麦子，他转身看见了天使，跟他在一起的四个儿子都躲了起来。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 25:23; 撒母耳记下 24:18–20"> 阿珥楠看见大卫来了，就从麦场出来，俯伏在地，向大卫下拜。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 24:21; 列王纪上 21:2; 民数记 25:8"> 大卫对他说：“请你将这块麦场卖给我，我要在这里为耶和华筑一座坛，使民中的瘟疫止息。你全价卖给我吧。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 24:22–23; 撒母耳记上 6:14; 创世记 23:4–6"> 阿珥楠说：“我主我王只管用我的麦场！我愿献出牛作燔祭，打麦的器具作柴，麦子作素祭，我愿献出这一切。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 16:16–17; 创世记 14:23; 创世记 23:13"> 大卫王对他说：“不可，我一定要付你全价，我不要拿你的东西献给耶和华，也不要把白白得来的献作燔祭。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 24:24–25"> 于是，大卫就用一百四十两金子买了阿珥楠的麦场。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 9:24; 士师记 6:21; 箴言 15:8"> 大卫在那里为耶和华建了一座坛，献上燔祭和平安祭，并求告耶和华。耶和华垂听了他的祷告，从天上降火在祭坛上，</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 18:11; 诗篇 103:20; 历代志上 21:15–16"> 又命令天使收刀入鞘。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 大卫见耶和华在耶布斯人阿珥楠的麦场上应允了他的祷告，就在那里献祭。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 1:13"> 那时候，摩西在旷野为耶和华所造的圣幕和燔祭坛都在基遍的丘坛。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 1:17; 希伯来书 12:28–29; 启示录 15:4"> 但大卫因为惧怕耶和华天使的刀，不敢去那里求问上帝。</span>
</div>
</div>

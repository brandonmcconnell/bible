## 吕便的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 35:22; 创世记 29:32; 创世记 48:15–22"> 以色列的长子原是吕便，但因为他玷污了父亲的床<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="指跟父亲的妾通奸一事，参见创世记35:22。">a</a></sup>，他长子的名分就给了他弟弟约瑟的后代。因此，按家谱他不是长子。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:2; 希伯来书 7:14"> 犹大虽然在众弟兄中最强大，君王也是出自他的后裔，长子的名分却属于约瑟。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:9; 出埃及记 6:14; 民数记 26:5–9"> 以色列长子吕便的儿子是哈诺、法路、希斯伦和迦米。</span>
<span className="v" id="v4" data-v="4"> 约珥的儿子是示玛雅，示玛雅的儿子是歌革，歌革的儿子是示每，</span>
<span className="v" id="v5" data-v="5"> 示每的儿子是米迦，米迦的儿子是利亚雅，利亚雅的儿子是巴力，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 列王纪下 15:29; 历代志下 28:20"> 巴力的儿子是备拉。备拉是吕便支派的首领，被亚述王提革拉·毗尼色掳去。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 5:17"> 按家谱记载，他做族长的亲族是耶利、撒迦利雅和比拉。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 5:4; 民数记 32:34; 民数记 32:38"> 比拉是亚撒的儿子，亚撒是示玛的儿子，示玛是约珥的儿子。约珥住在亚罗珥至尼波和巴力·免一带。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 22:8–9"> 他们的牲畜在基列增多，便又向东迁移到幼发拉底河西边的旷野。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 21:9; 历代志上 5:18–21; 诗篇 83:6"> 扫罗执政期间，吕便人与夏甲人交战，打败了夏甲人，占领了他们在基列东边的整片土地。</span>
</div>
</div>

## 迦得的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 13:11; 约书亚记 13:24–28; 申命记 3:10–17"> 迦得的后代住在毗邻吕便支派的巴珊，向东远至撒迦。</span>
<span className="v" id="v12" data-v="12"> 在巴珊做首领的有族长约珥、副族长沙番以及雅乃和沙法。</span>
<span className="v" id="v13" data-v="13"> 他们同族的弟兄有米迦勒、米书兰、示巴、约赖、雅干、细亚和希伯，共七人。</span>
<span className="v" id="v14" data-v="14"> 这些都是亚比孩的儿子。亚比孩是户利的儿子，户利是耶罗亚的儿子，耶罗亚是基列的儿子，基列是米迦勒的儿子，米迦勒是耶示筛的儿子，耶示筛是耶哈多的儿子，耶哈多是布斯的儿子。</span>
<span className="v" id="v15" data-v="15"> 古尼的孙子、押比碟的儿子亚希是他们家族的族长。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 27:29; 雅歌 2:1; 以赛亚书 35:2"> 他们住在基列、巴珊和巴珊附近的乡村以及沙仑所有的草原，直到四围的边界地带。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:16; 列王纪下 14:28; 列王纪下 15:32"> 这些人是在犹大王约坦和以色列王耶罗波安执政期间被记录在族谱里的。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:3; 约书亚记 4:12–13"> 吕便支派、迦得支派和玛拿西半个支派中善用盾牌、刀剑、弓箭、能征善战的勇士共有四万四千七百六十人。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 25:15; 历代志上 1:31; 历代志上 5:10"> 他们与夏甲人、伊突人、拿非施人和挪答人打仗，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 22:4–5; 诗篇 9:10; 历代志下 18:31"> 击败了夏甲人及其盟军，因为他们信靠上帝，在作战的时候向上帝求助，上帝应允了他们的祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 18:13; 民数记 31:35"> 他们从敌人那里掳走了五万只骆驼、二十五万只羊、两千头驴和十万人口。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:8; 罗马书 8:31; 约书亚记 23:10"> 敌人伤亡惨重，因为他们有上帝相助。他们占据敌人的土地，一直到被掳的时候。</span>
</div>
</div>

## 玛拿西的半个支派

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 3:8–9; 雅歌 4:8; 诗篇 133:3"> 玛拿西半个支派的人住在从巴珊到巴力·黑门、示尼珥和黑门山一带，他们人数众多。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 4:38"> 他们的族长以弗、以示、以利业、亚斯列、耶利米、何达威雅、雅叠都是英勇的战士，是著名的人物和各家族的首领。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 17:5; 诗篇 106:34–39; 出埃及记 34:15"> 可是，他们却背弃他们祖先的上帝，与当地居民的神明苟合。上帝曾在他们面前毁灭那些居民。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 15:19; 列王纪下 17:6; 列王纪下 15:29"> 因此，以色列的上帝驱使亚述王普勒，即提革拉·毗尼色，把吕便人、迦得人、玛拿西半个支派的人掳到哈腊、哈博、哈拉和歌散河边，他们至今还在那里。</span>
</div>
</div>

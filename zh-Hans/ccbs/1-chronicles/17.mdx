## 上帝对大卫的应许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 6:7–9; 历代志上 15:1; 历代志上 17:5"> 大卫住进宫殿后，对拿单先知说：“你看，我住在香柏木建的王宫中，耶和华的约柜却还在帐幕里。”</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 28:2; 哥林多前书 13:9; 撒迦利亚书 8:23"> 拿单对大卫说：“你有什么想法，就去做吧！因为上帝与你同在。”</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 3:7; 民数记 12:6; 以赛亚书 30:21"> 当晚，上帝对拿单说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:2–3; 以赛亚书 55:8–9; 历代志下 6:8–9"> “你去告诉我的仆人大卫，‘耶和华说，你不可建造殿宇给我居住。’</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 7:6; 出埃及记 40:2–3; 列王纪上 8:16"> 从我把以色列人带出埃及那天起，直到今天，我从未住过殿宇，都住在四处迁移的帐幕里。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:7; 民数记 10:33–36; 哥林多后书 6:16"> 在我与以色列人同行的日子，我从未责问任何我委派牧养我子民的士师，‘你为何不为我建香柏木的殿宇呢？’</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 6:21; 出埃及记 3:1–10; 撒母耳记上 17:15"> “现在你要告诉我的仆人大卫，‘万军之耶和华说：你原本在草场牧羊，我召你来做我以色列子民的首领。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:14; 历代志上 17:2; 诗篇 113:7–8"> 无论你去哪里，我都与你同在，为你铲除所有仇敌。现在我要使你声名远扬，与世上的伟人齐名。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:23; 以西结书 28:4; 以弗所书 5:6"> 我必为我的以色列子民预备一个地方，栽培他们，使他们住在自己的家园，不再受惊扰，不会像从前我设立士师治理他们的时候那样受恶人压迫。我必使你安定，免受仇敌的侵扰，我耶和华向你宣告，我必为你建立王朝。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 132:11; 列王纪上 1:21; 历代志上 28:5"> 你离世归祖时，我必兴起你亲生的后裔接替你，使他的国稳固。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 5:5; 但以理书 2:44; 以赛亚书 9:7"> 他要为我建造殿宇，我必坚立他的王位，直到永远。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:5; 以赛亚书 55:3; 历代志上 17:12"> 我要做他的父亲，他要做我的儿子。我的慈爱曾离开在你之前的那位，但我的慈爱必不离开他。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 89:36; 路加福音 1:32–33; 诗篇 72:17"> 我要使他永远治理我的家和我的国。他的王位必永远稳固。’”</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:28; 使徒行传 20:27; 撒母耳记下 7:17"> 拿单就把所听到的启示全部告诉大卫。</span>
</div>
</div>

## 大卫的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 7:18; 创世记 32:10; 以弗所书 3:8"> 于是，大卫王进去，在耶和华面前坐下，说：“耶和华上帝啊，我是谁？我的家算什么？你竟这样厚待我。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:11–15; 腓立比书 2:8–11; 以赛亚书 49:6"> 上帝啊，在你眼中这还不够，你还说到仆人家的将来。耶和华上帝啊，你视我为尊贵的人。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 21:17; 撒母耳记上 2:30; 撒母耳记下 7:20–24"> 你将尊荣加于仆人，大卫还能对你说什么呢？因为你深知你的仆人。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 37:35; 撒母耳记下 7:21; 但以理书 9:17"> 耶和华啊，你按照自己的心意为仆人成就这大事，以显明这一切伟大之事。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 44:6; 耶利米书 10:6–7; 以弗所书 3:20"> 耶和华啊，我们从未听过有谁能与你相比，你是独一无二的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 20:9–10; 以赛亚书 63:9; 以赛亚书 48:9"> 世上哪个民族比得上你的以色列子民呢？你从埃及救赎他们，让他们做你的子民，行伟大而可畏的事，把外族人从他们面前赶走，以彰显你的大名。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 19:5–6; 彼得前书 2:9; 罗马书 11:1–12"> 你让以色列人永远做你的子民，你耶和华做他们的上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:49; 耶利米书 11:5; 路加福音 1:38"> “耶和华啊，求你永远信守你对仆人和仆人家的应许，求你成就你的应许。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:13; 耶利米书 31:1; 启示录 21:3"> 这样，你的名必永远坚立，被尊崇，人们必说，‘以色列的上帝——万军之耶和华是以色列的上帝’，你仆人大卫的家必在你面前坚立。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 9:15; 以西结书 36:37; 诗篇 10:17"> 我的上帝啊，因为你曾启示仆人，说要为仆人建立王朝，仆人才敢这样向你祈祷。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 34:6–7; 希伯来书 6:18; 提多书 1:2"> 耶和华啊，唯有你是上帝，你应许要将这福气赐给仆人。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 1:3; 罗马书 11:29; 诗篇 72:17"> 愿你赐福给仆人家，使仆人家在你面前永续不断。耶和华啊，你已赐下祝福，你的祝福是永远的！”</span>
</div>
</div>

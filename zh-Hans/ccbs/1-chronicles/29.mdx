## 为建殿而献的礼物

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 22:5; 列王纪上 3:7; 历代志下 13:7"> 大卫王又对全体会众说：“我儿所罗门是上帝特别拣选的，但他还年轻，缺乏经验。建殿的工程浩大，因为这殿不是为人造的，而是为耶和华上帝造的。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 22:3–5; 哥林多后书 8:3; 以赛亚书 54:11–12"> 我已竭尽所能为我上帝的殿预备了制作金器、银器、铜器、铁器和木器所需的金银铜铁及木头，还有大量玛瑙、镶嵌用的宝石、彩石、大理石及其他贵重的石头。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 21:24; 诗篇 27:4; 诗篇 26:8"> 而且，我因为爱慕我上帝的殿，除了预备以上物品外，还把自己珍藏的金银献上，用来建造我上帝的殿。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:28; 历代志上 22:14; 约伯记 28:16"> 我献上两百万两俄斐金、四百八十万两纯银，用来贴殿墙，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:2–3; 出埃及记 35:5–9; 以斯拉记 7:15–16"> 供匠人制作金器银器。今天，有谁乐意向耶和华奉献？”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 9:7; 历代志上 27:25–1; 以赛亚书 60:3–10"> 结果，各族长、以色列各支派的首领、千夫长、百夫长和负责王室事务的官员都乐意奉献，</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 7:70–71; 以斯拉记 2:69"> 他们为上帝的殿奉献了三百四十万两金子，六百八十万两银子，六百二十吨铜，三千四百吨铁。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 23:8; 历代志上 26:21–22"> 有宝石的人都把宝石交到耶和华殿的库房，由革顺人耶歇保管。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 9:7–8; 哥林多后书 8:3; 列王纪上 8:61"> 因为他们诚心诚意地把东西献给耶和华，百姓欢喜不已，大卫王也非常欢喜。</span>
</div>
</div>

## 大卫颂赞耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 1:7"> 大卫在会众面前颂赞耶和华，说：“我们先祖以色列的上帝耶和华啊，你永永远远当受颂赞！</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 1:3; 但以理书 4:34–35; 提摩太前书 1:17"> 耶和华啊，伟大、权能、荣耀、尊贵和威严都是你的，天上地下的一切都是你的。耶和华啊，国度是你的，你是万有的至高主宰。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 3:16; 历代志下 20:6; 申命记 8:18"> 富贵和尊荣都从你而来，你掌管一切，你手中有权柄和能力，能使人尊大、强盛。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:1; 哥林多后书 9:15; 哥林多后书 8:16"> 我们的上帝啊，我们称颂你，赞美你荣耀的名。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 哥林多后书 3:5; 罗马书 11:36"> “我算什么，我的人民算什么，怎么能向你奉献？因为万物都从你而来，我们只是把从你那里得来的献给你。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 144:4; 利未记 25:23; 诗篇 102:11"> 我们在你面前只是客旅，是寄居的，像我们祖先一样；我们在世的日子就像影子一样转瞬即逝。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:14; 诗篇 24:1; 历代志下 31:10"> 我们的上帝耶和华啊，我们为你的圣名建造殿宇所预备的这一切财物，都是从你那里来的，都属于你。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 17:10; 箴言 11:20; 历代志上 28:9"> 我的上帝啊，我知道你洞察人心，喜爱正直的人。我怀着正直的心甘愿献上这一切，我也看见你这里的子民甘心乐意地将财物献给你。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 32:39; 耶利米书 10:23; 希伯来书 13:21"> 我们祖先亚伯拉罕、以撒、以色列的上帝耶和华啊！求你使你的子民常存这样的心志，使他们的心忠于你。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 72:1; 历代志上 28:9; 雅各书 1:17"> 求你赐给我儿所罗门忠诚的心，以遵行你的诫命、法度和律例，用我预备的材料建造殿宇。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 95:6; 出埃及记 4:31; 诗篇 135:19–21"> 大卫对全体会众说：“你们要颂赞你们的上帝耶和华。”于是，全体会众颂赞他们祖先的上帝耶和华，向耶和华和王俯伏下拜。</span>
</div>
</div>

## 所罗门被立为王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 7:4–9; 民数记 15:7; 以斯拉记 6:17"> 次日，他们向耶和华献平安祭和燔祭。他们代表全以色列献上一千头公牛、一千只公绵羊、一千只羊羔，同时还献上奠祭及许多其他祭。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 2:35; 历代志上 23:1; 出埃及记 24:11"> 那一天，他们在耶和华面前欢欢喜喜地吃喝。 他们再次拥立大卫的儿子所罗门做王，在耶和华面前膏立他做首领，又膏立撒督做祭司。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:12; 历代志上 28:5; 罗马书 13:1"> 于是，所罗门登上了耶和华所赐的王位，接替他父亲大卫做王。他凡事亨通，以色列众人都服从他，</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 2:3–9; 以西结书 17:18; 创世记 24:2"> 众首领、勇士和大卫王的众子都效忠于他。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 1:12; 历代志下 1:1; 传道书 2:9"> 耶和华使所罗门倍受以色列人尊崇，赐他君王的威严，超过在他之前的所有以色列王。</span>
</div>
</div>

## 大卫去世

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 18:14; 诗篇 78:71–72"> 耶西的儿子大卫是全以色列的王，</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 他统治以色列四十年，他在希伯仑执政七年，在耶路撒冷执政三十三年。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:15; 使徒行传 13:36; 历代志上 23:1"> 大卫年纪老迈，享尽富贵尊荣后，寿终正寝。他儿子所罗门继位。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 9:9; 撒母耳记下 12:1–7; 历代志上 21:9–11"> 大卫王的事迹自始至终都记在撒母耳先见、拿单先知和迦得先见的史记上。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 4:25; 但以理书 4:23; 但以理书 2:21"> 书中记述了他的政绩和英勇事迹，还有他和以色列及列国所遭遇的事。</span>
</div>
</div>

## 大卫击败亚扪人和亚兰人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 11:1–2; 撒母耳记下 10:1–19; 撒母耳记上 12:12"> 后来，亚扪王拿辖死了，他儿子继位。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:3–6; 撒母耳记上 30:26; 创世记 19:37–38"> 大卫说：“我要恩待拿辖的儿子哈嫩，因为他父亲曾经恩待我。”他便派使臣去安慰丧父的哈嫩。大卫的臣仆来到亚扪境内要安慰哈嫩，</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:23–24; 哥林多前书 13:5–7; 列王纪上 12:8–11"> 亚扪的官长却对哈嫩说：“大卫派人来安慰你，你以为他是来吊唁你父亲吗？他的臣仆来见你，不过是要探听虚实，想摧毁这地方。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 10:4–5; 以赛亚书 15:2; 马可福音 12:4"> 哈嫩便把大卫的臣仆抓起来，剃去他们的胡须，从臀部割去他们下半身的衣服，然后放走他们。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:24–26; 马太福音 18:31; 列王纪上 16:34"> 消息传到大卫那里，他就派人去迎接他们，因为他们倍受羞辱。王告诉他们留在耶利哥，等胡须长好了再回来。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:5; 创世记 34:30; 历代志上 18:9"> 哈嫩及其他亚扪人知道得罪了大卫，就派人用六十八万两银子从美索不达米亚、亚兰玛迦和琐巴招兵买马，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:30; 约书亚记 13:9; 约书亚记 13:16"> 雇了三万二千辆战车和玛迦王及其军队。他们在米底巴附近扎营，亚扪人也从各城出来汇集在一起，准备作战。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:6; 历代志上 11:10–47; 撒母耳记下 23:8–39"> 大卫听见消息后，就派约押率领全体勇士出战。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 20:1; 列王纪上 20:24; 以赛亚书 28:6"> 亚扪人在城门前列阵，来助战的诸王在郊野列阵。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 10:9–14; 士师记 20:42–43; 约书亚记 8:22"> 约押见自己腹背受敌，就从以色列军中挑选一些精兵列阵迎战亚兰人，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 18:12; 历代志上 11:20; 历代志上 19:9"> 把余下的军兵交给他的兄弟亚比筛带领，列阵迎战亚扪人。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比书 1:27–28; 尼希米记 4:20; 传道书 4:9–12"> 他对亚比筛说：“倘若我胜不过亚兰人，你便过来支援我；倘若你胜不过亚扪人，我便过去支援你。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:14; 诗篇 27:14; 撒母耳记下 10:12"> 你要刚强，我们要为我们的人民和我们上帝的城邑奋勇作战。愿耶和华成全祂自己的旨意！”</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 20:19–21; 历代志下 13:5–16; 耶利米书 46:15–16"> 于是，约押率领军兵进攻亚兰人，亚兰人败逃。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:31; 利未记 26:7"> 亚扪人见亚兰人败逃，便也从亚比筛面前逃回城去。约押便回师耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 10:16; 撒迦利亚书 14:1–3; 弥迦书 4:11–12"> 亚兰人见自己败给以色列人，就派使者调来幼发拉底河那边的亚兰人，由哈大底谢的将军朔法率领。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 22:6–7; 历代志上 19:9"> 大卫听到消息后，就召集以色列全军，渡过约旦河，去攻打亚兰人，列阵与他们交战。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:18; 诗篇 33:16; 诗篇 18:32"> 亚兰人在以色列人面前败逃，大卫杀了他们七千名战车兵、四万步兵，还杀了他们的将军朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 10:19; 约书亚记 9:9–11; 列王纪上 20:1"> 哈大底谢的属下见自己败给以色列人，便向大卫求和，臣服于他。从此，亚兰人不愿再支援亚扪人了。</span>
</div>
</div>

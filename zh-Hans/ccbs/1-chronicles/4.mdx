## 复述犹大的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:12; 创世记 38:29; 民数记 26:20–21"> 犹大的后代是法勒斯、希斯仑、迦米、户珥、朔巴。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 历代志上 2:52–54; 约书亚记 15:33"> 朔巴的儿子利亚雅生雅哈，雅哈生亚户买和拉哈。他们都属于琐拉人的宗族。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 15:11; 历代志下 11:6"> 以坦的儿子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“儿子”希伯来文是“父亲”。">a</a></sup>是耶斯列、伊施玛和伊得巴，女儿名叫哈悉勒玻尼。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 4:18; 历代志上 2:50; 历代志上 4:39"> 基多的父亲是毗努伊勒，户沙的父亲是以谢珥。这些人都是伯利恒的父亲、以法她的长子户珥的后代。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 2:24"> 提哥亚的父亲亚施户有两个妻子，一个名叫希拉，一个名叫拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉给他生了亚户撒、希弗、提米尼和哈辖斯他利。这些都是拿拉的儿子。</span>
<span className="v" id="v7" data-v="7"> 希拉的儿子是洗列、琐辖和伊提南。</span>
<span className="v" id="v8" data-v="8"> 哥斯生亚诺和琐比巴，他也是哈伦的儿子亚哈黑宗族的祖先。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 4:21; 历代志上 7:23; 创世记 35:18"> 雅比斯比他的众弟兄尊贵，他母亲给他取名叫雅比斯，意思是：“我生他时非常痛苦。”</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–11; 诗篇 116:1–4; 箴言 10:22"> 雅比斯向以色列的上帝祷告说：“愿你赐福给我，扩展我的疆域，愿你的手扶持我，使我远离患难、免受痛苦。”上帝答应了他的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 书哈的弟兄基绿生米黑，米黑是伊施屯的父亲。</span>
<span className="v" id="v12" data-v="12"> 伊施屯生伯‧拉巴、巴西亚和提欣拿，提欣拿是珥拿辖的父亲。这些都是利迦人。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:17; 士师记 1:13; 士师记 3:9–11"> 基纳斯的儿子是俄陀聂和西莱雅。俄陀聂的儿子是哈塔、悯挪太。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 11:35; 列王纪下 24:14"> 悯挪太生俄弗拉。西莱雅生革·夏纳欣人的祖先约押。他们都是工匠。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 13:6; 民数记 14:6–10; 约书亚记 15:13–20"> 耶孚尼的儿子是迦勒，迦勒的儿子是以路、以拉和拿安，以拉的儿子是基纳斯。</span>
<span className="v" id="v16" data-v="16"> 耶哈利勒的儿子是西弗、西法、提利和亚撒列。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 4:19; 历代志上 6:57; 约书亚记 15:50"> 以斯拉的儿子是益帖、米列、以弗和雅伦。米列娶了法老的女儿比提雅为妻，她给米列生了米利暗、沙迈和以实提摩的父亲益巴。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 2:42; 历代志上 4:39; 约书亚记 15:58"> 米列还娶了一个犹大人为妻，她生了基多的父亲雅列、梭哥的父亲希伯和撒挪亚的父亲耶古铁。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 15:44; 撒母耳记上 23:1–13"> 荷第雅的妻子是拿含的妹妹，她的儿子们是迦米人基伊拉和玛迦人以实提摩的父亲。</span>
<span className="v" id="v20" data-v="20"> 示门的儿子是暗嫩、林拿、便·哈南和提伦。以示的儿子是梭黑和便·梭黑。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 38:5; 历代志上 2:3; 民数记 26:20"> 犹大有个儿子名叫示拉。示拉的后代是利迦的父亲珥、玛利沙的父亲拉大、在伯‧亚实比织细麻布的各家族、</span>
<span className="v" id="v22" data-v="22"> 约敬、哥西巴人、约阿施以及统治摩押和雅叔比利恒的萨拉。这都是古代的记录。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 81:6; 历代志上 4:14"> 他们都是住在尼他英和基低拉的陶匠，他们在那里为王效力。</span>
</div>
</div>

## 西缅的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 46:10; 出埃及记 6:15; 民数记 26:12–14"> 西缅的儿子是尼姆利、雅悯、雅立、谢拉和扫罗。</span>
<span className="v" id="v25" data-v="25"> 扫罗的儿子是沙龙，沙龙的儿子是米比衫，米比衫的儿子是米施玛，</span>
<span className="v" id="v26" data-v="26"> 米施玛的儿子是哈姆利，哈姆利的儿子是撒刻，撒刻的儿子是示每。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 26:14; 民数记 26:22; 民数记 2:13"> 示每有十六个儿子和六个女儿，他弟兄的儿女不多。他们整个宗族的人不如犹大宗族的人多。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:2–3; 约书亚记 15:28–29; 约书亚记 19:9"> 西缅人住在别示巴、摩拉大、哈萨·书亚、</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:3–4"> 辟拉、以森、陀腊、</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 11:28; 约书亚记 19:4–5; 撒母耳记上 30:1"> 彼土利、何珥玛、洗革拉、</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:5–6"> 伯·玛加博、哈萨·苏撒、伯·比利、沙拉音。在大卫做王以前，这些都是西缅人的城邑。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 19:7"> 他们还有五座城邑：以坦、亚因、临门、陀健、亚珊，</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:8"> 以及这些城附近的村庄，远至巴力。这些都是他们的住处。他们有自己的家谱。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 西缅的后代还有米所巴、雅米勒、亚玛谢的儿子约沙、</span>
<span className="v" id="v35" data-v="35"> 约珥、约示比的儿子耶户。约示比是西莱雅的儿子，西莱雅是亚薛的儿子。</span>
<span className="v" id="v36" data-v="36"> 西缅的后代还有以利约乃、雅哥巴、约朔海、亚帅雅、亚底业、耶西篾、比拿雅、</span>
<span className="v" id="v37" data-v="37"> 示非的儿子细撒。示非是亚龙的儿子，亚龙是耶大雅的儿子，耶大雅是申利的儿子，申利是示玛雅的儿子。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 5:24; 创世记 6:4"> 以上所提的这些人都是族长，各宗族都人丁兴旺。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志上 4:4; 历代志上 4:18; 约书亚记 15:58"> 他们前往平原东边的基多谷寻找牧羊的草场，</span>
<span className="v" id="v40" data-v="40" data-xref="士师记 18:7–10; 诗篇 105:23; 诗篇 78:51"> 找到了一片肥沃的草场，又辽阔又安静。从前含族人在那里居住。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 14:28–32; 列王纪下 18:8–12; 历代志上 4:34–38"> 在犹大王希西迦执政期间，以上这些西缅人的族长来攻打含族人的驻地和那里所有的米乌尼人，消灭了他们，占据了那里，一直住到今天，因为那里有可以牧羊的草场。</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 36:8–9; 申命记 1:2"> 有五百个西缅人在以示的儿子毗拉提、尼利雅、利法雅和乌薛的带领下前往西珥山，</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:17; 撒母耳记上 15:7–8; 撒母耳记下 8:12"> 铲除了残余的亚玛力人，从此定居在那里，直到今日。</span>
</div>
</div>

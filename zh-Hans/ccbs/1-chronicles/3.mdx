## 大卫的子孙

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 3:2–5; 约书亚记 15:56; 撒母耳记下 13:1"> 以下是大卫在希伯仑生的儿子：长子暗嫩，由耶斯列人亚希暖所生；次子但以利，由迦密人亚比该所生；</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 19:4–10; 撒母耳记下 3:4; 列王纪上 2:24–25"> 三子押沙龙，由基述王达买的女儿玛迦所生；四子亚多尼雅，由哈及所生；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 3:5"> 五子示法提雅，由亚比她所生；六子以特念，由大卫的妻子以格拉所生。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 2:11; 撒母耳记下 5:4–5; 列王纪上 2:11"> 以上六人都是大卫在希伯仑生的。大卫在希伯仑做王七年零六个月，在耶路撒冷做王三十三年。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 11:3; 撒母耳记下 12:24–25; 撒母耳记下 12:1–15"> 大卫在耶路撒冷生的儿子有示米亚、朔罢、拿单和所罗门，这四人的母亲是亚米利的女儿拔示巴。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 5:15; 历代志上 14:5; 撒母耳记上 14:5"> 大卫的儿子还有益辖、以利沙玛、以利法列、</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 5:15–16"> 挪迦、尼斐、雅非亚、</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 14:7; 撒母耳记下 5:14–16"> 以利沙玛、以利雅大和以利法列，共九人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 13:1–20; 撒母耳记下 5:13"> 这些都是大卫的儿子，不包括嫔妃生的儿子。大卫还有个女儿，名叫她玛。</span>
</div>
</div>

## 所罗门的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 11:43; 列王纪上 14:31–1; 列王纪上 15:24"> 所罗门的儿子是罗波安，罗波安的儿子是亚比雅，亚比雅的儿子是亚撒，亚撒的儿子是约沙法，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 8:24; 历代志下 21:17; 列王纪下 11:21"> 约沙法的儿子是约兰，约兰的儿子是亚哈谢，亚哈谢的儿子是约阿施，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 25:1; 列王纪下 14:21; 列王纪下 14:1"> 约阿施的儿子是亚玛谢，亚玛谢的儿子是亚撒利雅，亚撒利雅的儿子是约坦，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:1; 列王纪下 16:1; 历代志下 29:1"> 约坦的儿子是亚哈斯，亚哈斯的儿子是希西迦，希西迦的儿子是玛拿西，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 23:30; 历代志下 34:1; 列王纪下 21:19"> 玛拿西的儿子是亚们，亚们的儿子是约西亚。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:34"> 约西亚的儿子有长子约哈难、次子约雅敬、三子西底迦、四子沙龙。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 24:6; 马太福音 1:11; 列王纪下 24:17"> 约雅敬的儿子是耶哥尼雅和西底迦。</span>
</div>
</div>

## 耶哥尼雅的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 3:2; 以斯拉记 5:2; 马太福音 1:12"> 被掳的耶哥尼雅的儿子是撒拉铁、</span>
<span className="v" id="v18" data-v="18"> 玛基兰、毗大雅、示拿萨、耶加米、何沙玛、尼达比雅。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯拉记 2:2; 以斯拉记 3:2; 哈该书 2:2"> 毗大雅的儿子是所罗巴伯和示每。所罗巴伯的儿子是米书兰和哈拿尼雅，女儿是示罗密，</span>
<span className="v" id="v20" data-v="20"> 他还有五个儿子：哈舒巴、阿黑、比利迦、哈撒底、于沙·希悉。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 10:22"> 哈拿尼雅的儿子是毗拉提和耶筛亚。耶筛亚生利法雅，利法雅生亚珥南，亚珥南生俄巴底亚，俄巴底亚生示迦尼，</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 8:2"> 示迦尼的儿子是示玛雅，示玛雅的儿子是哈突、以甲、巴利亚、尼利雅、沙法。</span>
<span className="v" id="v23" data-v="23"> 尼利雅的三个儿子是以利约乃、希西迦和亚斯利干。</span>
<span className="v" id="v24" data-v="24"> 以利约乃的七个儿子是何大雅、以利亚实、毗莱雅、阿谷、约哈难、第莱雅和阿拿尼。</span>

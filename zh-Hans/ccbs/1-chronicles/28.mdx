## 大卫对所罗门的嘱咐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 23:2; 历代志上 11:10–47; 历代志上 27:1–34"> 大卫召以色列的众首领到耶路撒冷。于是，各支派的首领、王手下的各班将领、千夫长、百夫长、负责王和王子的财产及牲畜的官员、宫廷侍臣、勇士和能征善战者都来了，</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 99:5; 以赛亚书 66:1; 历代志上 17:1–2"> 大卫王站起来说：“我的弟兄，我的人民啊，请听我说。我本想建造一座殿宇安放耶和华的约柜，作我们上帝的脚凳，我已准备好建造的材料。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:8; 历代志上 17:4; 历代志下 6:8–9"> 但上帝对我说，‘你不可为我的名建造殿宇，因为你是个战士，曾流过人的血。’</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 16:1; 历代志上 5:2; 撒母耳记上 16:6–13"> 以色列的上帝耶和华从我父家永远拣选我做以色列的王。因为祂拣选了犹大支派做首领；在犹大支派中，祂拣选了我父亲家；在我父亲的众子中，祂喜悦我，立我做以色列的王。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 3:1–9; 历代志上 23:1; 历代志上 22:9–10"> 耶和华赐给我许多儿子，祂在我众子中拣选了所罗门，让他坐耶和华国的王位，治理以色列。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:13–14; 历代志上 22:9–10; 希伯来书 3:6"> 耶和华对我说，‘你儿子所罗门必建造我的殿宇和庭院，因为我拣选他做我的儿子，我也必做他的父亲。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 22:13; 列王纪上 8:61; 列王纪上 6:12–13"> 倘若他像今天一样继续坚守我的诫命和典章，我必使他的国永远稳固。’</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:1; 申命记 5:32–3; 箴言 2:1–5"> 现在，当着耶和华的会众——全体以色列人的面，趁着我们的上帝在垂听，你们要谨遵你们的上帝耶和华的一切诫命，以便你们可以拥有这片佳美之地，并且把它传给你们的子孙作永远的产业。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 29:13; 雅各书 4:8–11; 马太福音 7:7–8"> “我儿所罗门啊，你要认识你父亲的上帝耶和华，诚心乐意地事奉祂，因为祂洞察人心，知道人一切的心思意念。倘若你寻求祂，祂必让你寻见；倘若你背弃祂，祂必永远丢弃你。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 28:6; 提摩太前书 4:16; 历代志上 22:16–19"> 现在你要谨慎，因为耶和华拣选你来建造殿宇作圣所。你要坚定不移地去做。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 28:19; 列王纪上 6:3; 出埃及记 25:40"> 大卫将殿的走廊、房舍、库房、楼房、内室和安放施恩座的圣所的图样都交给他儿子所罗门，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 26:20; 列王纪上 14:26; 出埃及记 25:40"> 又将心里构想的耶和华殿的院子、四周的房屋、殿的库房和圣物库房的图样都交给他。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 9:29; 历代志上 25:1–31; 列王纪上 7:1–51"> 大卫还让他知道祭司和利未人的班次、耶和华殿里各样的工作及一切所需的器皿，</span>
<span className="v" id="v14" data-v="14"> 制造圣殿中各种金器银器所需金银的分量，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 25:31–39; 撒迦利亚书 4:11–14; 启示录 1:12–13"> 就是金灯台和金灯的分量，银灯台和银灯的分量，按每座灯台和灯的分量及每座灯台的用途酌定金银的分量，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:48; 历代志下 4:8; 出埃及记 25:23–30"> 每张放供饼的金桌子的分量，银桌子的分量，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 10:21; 历代志下 4:20–22; 民数记 7:13–14"> 纯金的叉子、碗、瓶的分量，每个金碗和银碗的分量，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 25:18–22; 出埃及记 30:1–10; 诗篇 80:1"> 纯金香坛的分量，以及在施恩车座上展开翅膀遮盖耶和华约柜的基路伯天使的样式。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:11–12; 出埃及记 25:40; 以西结书 3:14"> 大卫说：“以上这一切都是耶和华亲手指示我的，让我明白工作的细节。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 22:13; 约书亚记 1:5–9; 以赛亚书 41:10"> 大卫又对儿子所罗门说：“你要坚定勇敢地去做！不要惊慌害怕，因为我的上帝耶和华必不撇下你，也不丢弃你，祂必与你同在，直到圣殿的一切工作完毕。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 24:1–26; 历代志上 22:17–18; 出埃及记 31:3"> 你看，在上帝殿里司职的各班祭司和利未人已准备就绪，又有各种能工巧匠乐意在各种工作上帮你，众官长和百姓都听你调遣。”</span>
</div>
</div>

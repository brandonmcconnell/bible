## 投奔大卫的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 27:2–6; 历代志上 11:24–25; 历代志上 8:33"> 大卫在洗革拉躲避基士的儿子扫罗的时候，有些勇士来投奔他，帮助他作战。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 3:15; 士师记 20:16; 撒母耳记上 17:49"> 他们是弓箭手，左右手都能甩石射箭，来自便雅悯支派，与扫罗同族。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 11:28; 撒母耳记下 21:6; 历代志上 11:33"> 他们的首领是亚希以谢，其次是约阿施，都是基比亚人示玛的儿子，还有亚斯玛威的儿子耶薛和毗力，以及比拉迦、亚拿突人耶户，</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:3; 约书亚记 15:36; 历代志上 11:15"> 统领三十位勇士的杰出战士基遍人以实买雅，他在三十人中是勇士，另有耶利米、雅哈悉、约哈难、基得拉人约撒拔、</span>
<span className="v" id="v5" data-v="5"> 伊利乌赛、耶利摩、比亚利雅、示玛利雅、哈律弗人示法提雅、</span>
<span className="v" id="v6" data-v="6"> 可拉人以利加拿、耶西亚、亚萨列、约以谢、雅朔班、</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:58; 历代志上 4:18; 历代志上 4:39"> 基多人耶罗罕的儿子犹拉和西巴第雅。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 2:18; 撒母耳记下 17:10; 撒母耳记下 23:20"> 有些迦得支派的人到旷野的堡垒投奔大卫，他们是能征惯战的勇士，善用盾和矛，貌似雄狮，快如山鹿。</span>
<span className="v" id="v9" data-v="9"> 他们为首的是以薛，其次是俄巴底雅，第三是以利押，</span>
<span className="v" id="v10" data-v="10"> 第四是弥施玛拿，第五是耶利米，</span>
<span className="v" id="v11" data-v="11"> 第六是亚太，第七是以利业，</span>
<span className="v" id="v12" data-v="12"> 第八是约哈难，第九是以利萨巴，</span>
<span className="v" id="v13" data-v="13"> 第十是耶利米，第十一是末巴奈。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 32:30; 利未记 26:8"> 这些迦得人都是将领，级别最低的统领一百人，最高的统领一千人。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 3:15; 约书亚记 4:18; 耶利米书 49:19"> 一月，约旦河水涨过两岸的时候，他们渡到河对岸，把住在平原的人打得东奔西逃。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16"> 便雅悯支派和犹大支派中也有人到堡垒投奔大卫，</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:23; 犹大书 1:9; 哥林多后书 13:11"> 大卫出去迎接他们，说：“如果你们是好心来帮助我的，我就与你们结盟，但如果你们把我这无罪之人出卖给敌人，愿我们祖先的上帝鉴察、惩罚你们。”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:34; 士师记 3:10; 撒母耳记下 17:25"> 当时，上帝的灵感动那三十位勇士的首领亚玛撒，他就说：<br /><span className="pl pl-1">“大卫啊，我们是你的人！</span><br /><span className="pl pl-1">耶西的儿子啊，我们拥护你！</span><br /><span className="pl pl-1">愿你无比昌盛！</span><br /><span className="pl pl-1">愿帮助你的人也都昌盛！</span><br /><span className="pl pl-1">因为你的上帝帮助你。”</span><br />大卫便收留他们，派他们统领他的队伍。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 29:2–9"> 从前，大卫和非利士人一同去攻打扫罗的时候，有些玛拿西人来投奔大卫。但大卫及其部下没有帮助非利士人作战，因为非利士人的首领商议后，害怕大卫拿着非利士人的头颅去归顺他的主人扫罗，便让他们走了。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 33:17; 申命记 1:15; 撒母耳记上 29:11"> 大卫回洗革拉的时候，玛拿西支派的千夫长押拿、约撒拔、耶叠、米迦勒、约撒拔、以利户、洗勒太都来投奔他。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 30:1–17; 历代志上 12:20; 历代志上 5:24"> 他们都是作战英勇的将领，帮助大卫抗击匪徒。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:1; 约伯记 17:9; 创世记 32:2"> 那时天天有人来投效大卫，以致形成一支大军，好像上帝的军队。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 2:3–4; 历代志上 11:10; 撒母耳记上 16:1"> 有些武装好的军兵也到希伯仑投奔大卫，要把扫罗的国权交给大卫，正如耶和华的应许。以下是这些人的数目：</span>
<span className="v" id="v24" data-v="24"> 从犹大支派来了手持盾牌和长矛的六千八百名战士；</span>
<span className="v" id="v25" data-v="25"> 从西缅支派来了七千一百名英勇的战士；</span>
<span className="v" id="v26" data-v="26"> 从利未支派来了四千六百人；</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 11:9; 列王纪下 25:18; 历代志上 6:49–57"> 亚伦家族中的首领耶何耶大和他的三千七百个随从；</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 8:17; 历代志上 6:8; 历代志上 6:53"> 年轻、英勇的撒督和他家族的二十二个将领；</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8–9; 历代志上 12:2; 创世记 31:23"> 扫罗的亲族、便雅悯支派中有三千人，大部分便雅悯人仍然效忠扫罗家；</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 6:4"> 来自以法莲支派、在本族中有名望的两万零八百个英勇的战士；</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 17:1–18"> 来自玛拿西半个支派、被点名选出来拥立大卫做王的一万八千人；</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 5:17; 路加福音 12:56–57; 以斯帖记 1:13"> 来自以萨迦支派、洞悉时事且深明以色列当行之道、统领族人的二百位族长；</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 12:2; 约翰福音 1:47"> 来自西布伦支派、能征善战、拥有各种兵器、训练有素、忠心耿耿的五万人；</span>
<span className="v" id="v34" data-v="34"> 来自拿弗他利支派的一千名将领和三万七千名手持盾牌和长矛的随从；</span>
<span className="v" id="v35" data-v="35"> 来自但支派的两万八千六百名能征善战的人；</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 12:33; 约珥书 2:7"> 来自亚设支派的四万名能征善战的精兵；</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 14:3; 申命记 3:12–16; 约书亚记 13:7–32"> 来自约旦河东边的吕便支派、迦得支派和玛拿西半个支派的十二万拥有各种兵器的人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 49:8–10; 列王纪上 8:61; 诗篇 101:2"> 以上这些人都是训练有素的勇士，他们诚心诚意到希伯仑拥立大卫做以色列王，其余的以色列人也都齐心要立大卫做王。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 31:54; 撒母耳记下 19:42; 创世记 26:30"> 他们在那里与大卫一起吃喝了三天，因为他们的亲族为他们预备了食物。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记上 25:18; 撒母耳记下 16:1; 耶利米书 23:5–6"> 他们周围的人，远至以萨迦、西布伦和拿弗他利各支派的人，都用驴、骆驼、骡子和牛驮来面饼、无花果饼、葡萄干、酒和油，又牵来许多牛和羊，以色列充满了欢乐。</span>
</div>
</div>

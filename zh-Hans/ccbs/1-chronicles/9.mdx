<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 7:64; 历代志上 5:25–26; 耶利米书 52:14–15"> 所有以色列人都按照谱系记在《以色列列王史》上。 归回的被掳之民 犹大人因为对上帝不忠而被掳到了巴比伦。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:73; 以斯拉记 2:58; 以斯拉记 2:70"> 首先从巴比伦回到自己城邑和地业居住的有祭司、利未人、殿役和其他以色列人。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 11:1; 历代志下 11:16; 尼希米记 11:4–9"> 一些犹大人、便雅悯人、以法莲人和玛拿西人住在耶路撒冷，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 2:5; 创世记 46:12; 民数记 26:20"> 其中有犹大的儿子法勒斯的后代乌太。乌太是亚米忽的儿子，亚米忽是暗利的儿子，暗利是音利的儿子，音利是巴尼的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 26:20; 尼希米记 11:5"> 示罗的子孙中包括长子亚帅雅及其众子，</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:20; 历代志上 2:6; 创世记 38:30"> 谢拉的后代耶乌利及其亲族共六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 10:20; 尼希米记 11:7; 尼希米记 8:4"> 便雅悯人有哈西努的曾孙、何达威雅的孙子、米书兰的儿子撒路，</span>
<span className="v" id="v8" data-v="8"> 耶罗罕的儿子伊比尼雅，米基立的孙子、乌西的儿子以拉，伊比尼雅的曾孙、流珥的孙子、示法提雅的儿子米书兰，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 11:8"> 以及他们的亲族，按照家谱的记载共有九百五十六人。以上这些人都是各家的族长。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 12:19; 尼希米记 11:10–24"> 回来的祭司有耶大雅、耶何雅立和雅斤，</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 11:11; 列王纪下 25:18; 民数记 4:33"> 还有管理上帝殿的亚萨利雅。亚撒利雅是希勒迦的儿子，希勒迦是米书兰的儿子，米书兰是撒督的儿子，撒督是米拉约的儿子，米拉约是亚希突的儿子。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 7:40; 以斯拉记 2:37; 尼希米记 11:12–13"> 回来的祭司还有玛基雅的曾孙、巴施户珥的孙子、耶罗罕的儿子亚大雅，以及亚第业的儿子玛赛。亚第业是雅希细拉的儿子，雅希细拉是米书兰的儿子，米书兰是米实利密的儿子，米实利密是音麦的儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 11:14; 历代志上 26:30; 历代志上 26:32"> 回来的祭司共一千七百六十人，全是族长，善于办理上帝殿的事务。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 26:57; 尼希米记 10:11; 历代志上 6:29"> 回来的利未人有米拉利的后代哈沙比雅的曾孙、押利甘的孙子、哈述的儿子示玛雅，</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 11:22; 尼希米记 11:17; 历代志上 11:17"> 拔巴甲、黑勒施、加拉和亚萨的曾孙、细基利的孙子、米迦的儿子玛探雅，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 25:1; 历代志下 35:15; 历代志上 12:25"> 耶杜顿的曾孙、迦拉的孙子、示玛雅的儿子俄巴底，以利加拿的孙子、亚撒的儿子比利迦。他们都住在尼陀法人的村庄里。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:1–32; 历代志上 23:5; 尼希米记 11:19"> 负责守门的是沙龙、亚谷、达们、亚希幔和他们的亲族，沙龙是他们的首领，</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 46:1–2; 以西结书 44:2–3; 列王纪上 10:5"> 在朝东的王门任职至今；他们曾是利未营中的守门人。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:9–11; 诗篇 44:1; 列王纪下 11:15"> 可拉的曾孙、以比雅撒的孙子、可利的儿子沙龙和其他可拉族人负责看守会幕的门，他们的祖先曾负责看守耶和华居所的门。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 31:6; 民数记 3:32; 民数记 4:33"> 以利亚撒的儿子非尼哈曾做他们的首领，耶和华也与他同在。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 26:14; 历代志上 26:2"> 米施利米雅的儿子撒迦利雅是在会幕守门的。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 历代志上 28:13; 历代志上 23:1–32"> 被选来守门的共有二百一十二人，都按各自所住的村庄载入家谱。大卫和撒母耳先见委派他们担此重任。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 44:14; 历代志下 23:19; 以西结书 44:10–11"> 他们及其子孙负责看守耶和华的殿门，也就是会幕的门。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 26:14–18"> 东西南北四面都有守卫。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 11:5; 历代志下 23:8; 列王纪下 11:7"> 他们村庄的同族弟兄每隔七天就来换班。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 13:5; 尼希米记 10:38–39; 历代志上 26:20–27"> 四个殿门守卫长都是利未人，负责看守上帝殿的房间和库房。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:30–32; 玛拉基书 1:10; 撒母耳记上 3:15"> 他们住在殿周围负责看殿，每天早晨开门。</span>
<span className="v" id="v28" data-v="28" data-xref="尼希米记 13:4–5; 尼希米记 12:44; 历代志上 26:22–26"> 有些利未人负责管理敬拜时用的器皿，每次取出或送回，他们都要统计清楚。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:29; 出埃及记 30:23–38; 出埃及记 27:20"> 还有一些人负责管理圣所的其他器具，以及细面粉、酒、油、乳香和香料。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 30:23–25; 出埃及记 37:29; 出埃及记 30:35–38"> 有些祭司负责配制香料。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 9:19; 历代志上 9:22; 利未记 6:21"> 利未人玛他提雅是可拉族沙龙的长子，他负责烤祭饼。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 24:5–8; 历代志上 6:33–48; 出埃及记 25:30"> 哥辖宗族中还有些人负责预备每个安息日需用的供饼。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 6:31–33; 诗篇 134:1–2; 历代志上 16:4–6"> 利未各宗族的族长负责歌乐，他们住在圣殿的房间里，昼夜专做这项工作，不做别的事。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 11:1–15; 历代志上 9:13"> 按照家谱的记载，以上都是利未人的各族长，他们住在耶路撒冷。</span>
</div>

## 扫罗王的族谱

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="历代志上 2:23–24; 历代志上 2:50–52; 历代志上 8:29–40"> 耶利建立了基遍城，定居在那里，他妻子名叫玛迦。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 9:39; 历代志上 8:33"> 他的长子是亚伯顿，其他儿子还有苏珥、基士、巴力、尼珥、拿答、</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 8:31"> 基多、亚希约、撒迦利雅和米基罗。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 8:32"> 米基罗是示米暗的父亲。这些人也住在耶路撒冷，与他们的亲族为邻。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 13:22; 历代志上 8:33–38; 历代志上 10:2"> 尼珥生基士，基士生扫罗，扫罗生约拿单、麦基舒亚、亚比拿达和伊施·巴力。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 4:4; 历代志上 8:34–36"> 约拿单生米力·巴力，米力·巴力生米迦，</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 8:35"> 米迦生毗敦、米勒、他利亚、亚哈斯，</span>
<span className="v" id="v42" data-v="42" data-xref="历代志上 8:36"> 亚哈斯生雅拉，雅拉生亚拉篾、亚斯玛威和心利，心利生摩撒，</span>
<span className="v" id="v43" data-v="43" data-xref="历代志上 8:37"> 摩撒生比尼亚，比尼亚生利法雅，利法雅生以利亚萨，以利亚萨生亚悉。</span>
<span className="v" id="v44" data-v="44"> 亚悉有六个儿子，他们是亚斯利干、波基路、以实玛利、示亚利雅、俄巴底雅和哈难。这些都是亚悉的儿子。</span>

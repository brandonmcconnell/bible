## 大卫的颂歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:1; 诗篇 18:1; 撒母耳记下 23:1–2"> 那一天，大卫初次指派亚萨和他的亲族唱诗歌颂耶和华，说：</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 105:1–15; 以赛亚书 12:4; 列王纪下 19:19"> <span className="pl pl-1">“你们要称谢耶和华，</span><br /><span className="pl pl-1">呼求祂的名，</span><br /><span className="pl pl-1">在列邦传扬祂的作为。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:16; 诗篇 96:1–3; 诗篇 98:1–4"> <span className="pl pl-1">要歌颂、赞美祂，</span><br /><span className="pl pl-1">述说祂一切奇妙的作为。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–8; 耶利米书 29:13; 诗篇 34:2"> <span className="pl pl-1">要以祂的圣名为荣，</span><br /><span className="pl pl-1">愿寻求耶和华的人心中快乐。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:8–9; 西番雅书 2:2–3; 诗篇 68:35"> <span className="pl pl-1">要寻求耶和华和祂的能力，</span><br /><span className="pl pl-1">时常来到祂面前。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 111:4; 诗篇 119:20; 诗篇 103:2"> <span className="pl pl-1">祂仆人以色列的后裔啊，</span><br /><span className="pl pl-1">祂所拣选的雅各的子孙啊，</span><br /><span className="pl pl-1">要记住祂所行的神迹奇事和祂口中的判词。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="诗篇 48:10–11; 以赛亚书 26:9; 出埃及记 15:2"> <span className="pl pl-1">“祂是我们的上帝耶和华，</span><br /><span className="pl pl-1">祂在普天下施行审判。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 105:8; 玛拉基书 4:4; 申命记 7:9"> <span className="pl pl-1">要永远铭记祂的约，</span><br /><span className="pl pl-1">历经千代也不可忘记祂的应许，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:3; 创世记 17:2; 创世记 35:11"> <span className="pl pl-1">就是祂与亚伯拉罕所立的约，</span><br /><span className="pl pl-1">向以撒所起的誓。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 17:7–8; 创世记 35:11–12; 约书亚记 24:11–13"> <span className="pl pl-1">祂将这约定为律例赐给雅各，</span><br /><span className="pl pl-1">定为永远的约赐给以色列。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="创世记 13:15; 弥迦书 2:5; 创世记 17:8"> <span className="pl pl-1">祂说，‘我必把迦南赐给你，</span><br /><span className="pl pl-1">作为你的产业。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="创世记 34:30; 申命记 7:7; 使徒行传 7:5"> <span className="pl pl-1">“那时他们人丁稀少，</span><br /><span className="pl pl-1">寥寥可数，在当地寄居，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 46:6; 创世记 20:1; 创世记 46:3"> <span className="pl pl-1">他们在异国他乡流离飘零。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 12:17; 创世记 20:3; 出埃及记 7:15–18"> <span className="pl pl-1">耶和华不容人压迫他们，</span><br /><span className="pl pl-1">还为他们的缘故责备君王，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="创世记 20:7; 诗篇 105:15; 创世记 49:8–10"> <span className="pl pl-1">说，‘不可加害我膏立的人，</span><br /><span className="pl pl-1">也不可伤害我的先知。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="诗篇 96:1–13; 诗篇 71:15; 以赛亚书 51:6–8"> <span className="pl pl-1">“普世都要歌颂耶和华，</span><br /><span className="pl pl-1">天天传扬祂的救恩；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 12:2–6; 但以理书 4:1–3; 诗篇 22:27"> <span className="pl pl-1">要在列国述说祂的荣耀，</span><br /><span className="pl pl-1">在万民中述说祂的奇妙作为。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 89:7; 诗篇 76:7; 诗篇 66:3–5"> <span className="pl pl-1">因为耶和华无比伟大，</span><br /><span className="pl pl-1">当受至高的颂扬；</span><br /><span className="pl pl-1">祂超越一切神明，</span><br /><span className="pl pl-1">当受敬畏。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 102:25; 利未记 19:4; 以赛亚书 42:5"> <span className="pl pl-1">列邦的神明都是假的，</span><br /><span className="pl pl-1">唯独耶和华创造了诸天。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:11; 诗篇 96:6; 诗篇 28:7–8"> <span className="pl pl-1">祂带着尊贵和威严，</span><br /><span className="pl pl-1">祂的圣所充满能力和喜乐。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:10; 腓立比书 4:13; 诗篇 100:1–2"> <span className="pl pl-1">“万族万民啊，</span><br /><span className="pl pl-1">要把荣耀和能力归给耶和华，</span><br /><span className="pl pl-1">归给耶和华！</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 100:4; 诗篇 96:9; 以赛亚书 6:3"> <span className="pl pl-1">要将耶和华之名当得的荣耀归给祂，</span><br /><span className="pl pl-1">要将供物献给祂，</span><br /><span className="pl pl-1">要穿圣衣敬拜耶和华</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译“要敬拜圣洁荣耀的耶和华”。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 33:9; 诗篇 148:5–6; 希伯来书 1:3"> <span className="pl pl-1">大地要在祂面前颤抖；</span><br /><span className="pl pl-1">世界坚立不摇。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 96:10; 启示录 19:6; 诗篇 97:1"> <span className="pl pl-1">愿天欢喜，愿地快乐；</span><br /><span className="pl pl-1">愿他们在列国宣告，</span><br /><span className="pl pl-1">‘耶和华执掌王权！’</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 148:9–10; 以赛亚书 44:23; 诗篇 98:7–8"> <span className="pl pl-1">愿海洋和其中的万物都欢呼，</span><br /><span className="pl pl-1">愿田野和其中的一切都欢腾！</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 98:9; 诗篇 96:12–13; 启示录 11:17–18"> <span className="pl pl-1">那时，林中的树木都要在耶和华面前欢唱，</span><br /><span className="pl pl-1">因为祂要来审判天下。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 106:1; 历代志下 7:3; 诗篇 107:1"> <span className="pl pl-1">你们要称谢耶和华，</span><br /><span className="pl pl-1">因为祂是美善的，</span><br /><span className="pl pl-1">祂的慈爱永远长存！</span></span>
</div>

<span className="v" id="v35" data-v="35" data-xref="诗篇 106:47–48; 彼得前书 2:9; 诗篇 14:7"> <span className="pl pl-1">“要说，‘拯救我们的上帝啊，</span><br /><span className="pl pl-1">求你拯救我们，招聚我们，</span><br /><span className="pl pl-1">把我们从列国中救出来，</span><br /><span className="pl pl-1">我们好称谢你的圣名，</span><br /><span className="pl pl-1">以赞美你为荣。’</span><br /></span>

## 分派事奉的人员

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="历代志下 8:14; 以斯拉记 3:4; 历代志上 16:4–6"> 大卫派亚萨及其亲族天天在约柜前事奉耶和华，尽当尽的职分；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 26:10; 历代志上 13:14; 历代志上 25:3"> 又派俄别·以东及其六十八位亲族、何萨和耶杜顿的儿子俄别·以东守门；</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 3:4; 历代志上 15:11; 历代志下 1:3–4"> 并派祭司撒督及其他祭司在基遍丘坛的耶和华的圣幕前供职，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 28:3–8; 出埃及记 29:38–42; 历代志下 31:3"> 按照耶和华在律法书上对以色列人的吩咐，每日早晚在祭坛上献燔祭给耶和华。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 5:13; 历代志上 25:1–6; 历代志下 20:21"> 与他们一同供职的有希幔、耶杜顿和其他人，他们被特别选出来称谢上帝，因为祂的慈爱永远长存。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 150:3–6; 历代志上 25:6–7; 历代志下 29:25–28"> 希幔和耶杜顿负责用号、钹及其他乐器伴奏歌颂上帝。耶杜顿的子孙负责守门。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 6:19–20; 创世记 18:19; 诗篇 101:2"> 于是，众民各自回家，大卫也回去为家人祝福。</span>

## 圣殿的守卫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 23:19; 民数记 26:9–11; 诗篇 44:1"> 以下是殿门守卫的班次： 可拉族亚萨的后代有可利的儿子米施利米雅。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 9:21"> 米施利米雅的长子是撒迦利亚，次子是耶叠，三子是西巴第雅，四子是耶提聂，</span>
<span className="v" id="v3" data-v="3"> 五子是以拦，六子是约哈难，七子是以利约乃。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:38; 历代志上 15:24; 历代志上 15:18"> 俄别·以东的长子是示玛雅，次子是约萨拔，三子是约亚，四子是沙甲，五子是拿坦业，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 128:1"> 六子是亚米利，七子是以萨迦，八子是毗乌利太，因为上帝赐福俄别·以东。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 12:28; 提摩太前书 6:12; 士师记 6:12"> 他儿子示玛雅有几个儿子都很能干，在各自的家族中做首领。</span>
<span className="v" id="v7" data-v="7"> 他们是俄得尼、利法益、俄备得、以利萨巴。他们的亲族以利户和西玛迦也很能干。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 3:6; 彼得前书 4:11; 哥林多前书 12:4–11"> 这些都是俄别·以东的子孙，他们和他们的儿子及亲族共有六十二人，都是能干称职的人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 26:14; 历代志上 26:1"> 米施利米雅的儿子及亲族共十八人，都很能干。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 16:38; 历代志上 5:1–2"> 米拉利的后代何萨的长子是申利，他本来不是长子，是被他父亲立为长子的。</span>
<span className="v" id="v11" data-v="11"> 次子是希勒迦，三子是底巴利雅，四子是撒迦利亚。何萨的儿子及亲族共十三人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:8"> 这些按族长分成小组的殿门守卫在耶和华的殿里按班次供职，与他们的亲族一样。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 25:8; 历代志上 24:31; 历代志上 24:5"> 他们无论大小，都按照族系抽签，以决定看守哪个门。</span>
<span className="v" id="v14" data-v="14"> 示利米雅抽中东门，他儿子撒迦利亚是个精明的谋士，抽中北门。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 25:24; 历代志上 26:17"> 俄别·以东抽中南门，他儿子抽中库房。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 12:24; 历代志上 26:10–12; 列王纪上 10:5"> 书聘和何萨抽中西门和上行之路的沙利基门，守卫与守卫相对而立。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 8:14; 历代志上 9:24"> 每天有六个利未人守东门，四人守北门，四人守南门，守库房的二人一组。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 23:11"> 至于西面的走廊，守卫街道的有四人，守卫走廊的有二人。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 16:11"> 以上是可拉的子孙和米拉利的子孙守门的班次。</span>
</div>
</div>

## 圣殿里的其他职务

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:22; 历代志上 28:12–19; 历代志上 22:14–16"> 利未人亚希雅负责掌管上帝殿里的库房和放圣物的库房。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:7; 历代志上 6:17; 历代志上 29:8"> 革顺族拉但的子孙中做族长的有耶希伊利。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:8; 尼希米记 10:38; 历代志上 26:20"> 耶希伊利的两个儿子西坦和约珥负责管理耶和华殿里的库房。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 3:27; 历代志上 23:12; 民数记 3:19"> 暗兰族、以斯哈族、希伯伦族、乌薛族也各有其职。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 24:20; 历代志上 23:15–16"> 摩西的孙子、革舜的儿子细布业是库房的主管。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 23:17–18; 历代志上 23:15; 出埃及记 18:4"> 细布业的亲族有以利以谢，以利以谢的儿子是利哈比雅，利哈比雅的儿子是耶筛亚，耶筛亚的儿子是约兰，约兰的儿子是细基利，细基利的儿子是示罗密。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:11; 历代志上 29:2–9; 历代志上 22:14"> 示罗密及其亲族负责管理库房中的圣物，这些物品是大卫王、众族长、千夫长、百夫长和将领献给上帝的圣物。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 12:14; 约书亚记 6:19; 尼希米记 10:32–34"> 他们把战争中掳掠的财物献出来，以备修缮耶和华的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 9:9; 撒母耳记上 17:55; 撒母耳记下 10:9–14"> 撒母耳先见、基士的儿子扫罗、尼珥的儿子押尼珥、洗鲁雅的儿子约押及其他人奉献的圣物都由示罗密及其亲族管理。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:4; 尼希米记 11:16; 历代志下 34:13"> 以斯哈族的基拿尼雅及其众子做官长和审判官，为以色列管理圣殿以外的事务。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:17; 历代志上 23:19; 历代志上 23:12"> 希伯伦族的哈沙比雅及其亲族一千七百人都很能干，他们在以色列的约旦河以西办理耶和华和王的事务。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 23:19; 约书亚记 21:39; 历代志上 29:27"> 按家谱记载，希伯伦宗族的族长是耶利雅。大卫执政第四十年，经过调查，在基列的雅谢从希伯伦族中找到一些能干的人。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 19:11; 历代志上 12:37; 历代志上 23:24"> 耶利雅的亲族有两千七百人，都是能干的族长。大卫王派他们在吕便支派、迦得支派和玛拿西半个支派中办理一切有关上帝和王的事务。</span>
</div>

## 便雅悯的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:21; 历代志上 7:6–12; 民数记 26:38"> 便雅悯的长子是比拉，次子是亚实别，三子是亚哈拉，</span>
<span className="v" id="v2" data-v="2"> 四子是挪哈，五子是拉法。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:21; 民数记 26:40"> 比拉的儿子是亚大、基拉、亚比忽、</span>
<span className="v" id="v4" data-v="4"> 亚比书、乃幔、亚何亚、</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 7:12; 民数记 26:39; 士师记 3:15"> 基拉、示孚汛、户兰。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 2:54; 士师记 3:20–30; 历代志上 7:10"> 以忽的儿子是乃幔、亚希亚和基拉，他们是迦巴居民的族长，后来被掳到了玛拿辖。基拉是乌撒和亚希忽的父亲。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 1:1; 创世记 25:6"> 沙哈连休了妻子户伸和巴拉，后来在摩押与妻子贺得生了约巴、洗比雅、米沙、玛拉干、</span>
<span className="v" id="v10" data-v="10"> 耶乌斯、沙迦、米玛。这些儿子都是族长。</span>
<span className="v" id="v11" data-v="11"> 户伸给沙哈连生的儿子是亚比突和以利巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:33; 尼希米记 7:37; 尼希米记 6:2"> 以利巴力的儿子是希伯、米珊和沙麦。沙麦建立了阿挪和罗德两座城及其周围的村庄。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:52; 约书亚记 19:42; 历代志上 4:4"> 以利巴力另外的两个儿子比利亚和示玛是亚雅仑居民的族长，他们赶走了迦特人。</span>
<span className="v" id="v14" data-v="14"> 亚希约、沙煞、耶利末、</span>
<span className="v" id="v15" data-v="15"> 西巴第雅、亚拉得、亚得、</span>
<span className="v" id="v16" data-v="16"> 米迦勒、伊施巴和约哈都是比利亚的儿子。</span>
<span className="v" id="v17" data-v="17"> 西巴第雅、米书兰、希西基、希伯、</span>
<span className="v" id="v18" data-v="18"> 伊施米莱、伊斯利亚和约巴都是以利巴力的儿子。</span>
<span className="v" id="v19" data-v="19"> 雅金、细基利、撒底、</span>
<span className="v" id="v20" data-v="20"> 以利乃、洗勒太、以利业、</span>
<span className="v" id="v21" data-v="21"> 亚大雅、比拉雅和申拉都是示每的儿子。</span>
<span className="v" id="v22" data-v="22"> 伊施班、希伯、以利业、</span>
<span className="v" id="v23" data-v="23"> 亚伯顿、细基利、哈难、</span>
<span className="v" id="v24" data-v="24"> 哈拿尼雅、以拦、安陀提雅、</span>
<span className="v" id="v25" data-v="25"> 伊弗底雅和毗努伊勒都是沙煞的儿子。</span>
<span className="v" id="v26" data-v="26"> 珊示莱、示哈利、亚他利雅、</span>
<span className="v" id="v27" data-v="27"> 雅利西、以利亚和细基利都是耶罗罕的儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 1:21; 约书亚记 15:63; 尼希米记 11:1"> 按照家谱记载，以上这些人都是族长，住在耶路撒冷。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 9:35–38"> 耶利建立了基遍城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“耶利建立了基遍城”或译“基遍之父耶利”。">a</a></sup>，定居在那里，他妻子名叫玛迦。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 9:36–37"> 他的长子是亚伯顿，其他儿子还有苏珥、基士、巴力、拿答、</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 9:37"> 基多、亚希约、撒迦和米基罗。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 9:38"> 米基罗是示米暗的父亲。这些人也住在耶路撒冷，与他们的亲族为邻。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 9:1; 撒母耳记下 2:8; 撒母耳记上 31:2"> 尼珥生基士，基士生扫罗，扫罗生约拿单、麦基舒亚、亚比拿达和伊施·巴力。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 4:4; 撒母耳记下 9:12; 撒母耳记下 9:10"> 约拿单生米力·巴力，米力·巴力生米迦，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 9:41"> 米迦生毗敦、米勒、他利亚、亚哈斯，</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 9:42"> 亚哈斯生耶何阿达，耶何阿达生亚拉篾、亚斯玛威和心利，心利生摩撒，</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 9:43"> 摩撒生比尼亚，比尼亚生拉法，拉法生以利亚萨，以利亚萨生亚悉。</span>
<span className="v" id="v38" data-v="38"> 亚悉有六个儿子，他们是亚斯利干、波基路、以实玛利、示亚利雅、俄巴底雅和哈难。这些都是亚悉的儿子。</span>
<span className="v" id="v39" data-v="39"> 亚悉的兄弟以设的儿子有长子乌兰，次子耶乌施，三子以利法列。</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 128:3–6; 历代志下 14:8; 历代志上 12:2"> 乌兰的儿子都是善射的英勇战士。他们子孙昌盛，共有一百五十人。以上都是便雅悯支派的人。</span>
</div>

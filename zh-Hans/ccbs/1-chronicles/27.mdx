## 以色列的军队

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 4:27; 历代志下 26:11–13; 申命记 1:15"> 以色列人的族长、千夫长、百夫长及其他官长都分定班次，每班两万四千人，每年按月轮流服侍王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 11:11; 撒母耳记下 23:8"> 撒巴第业的儿子雅朔班负责第一班，在一月当值，他班内有两万四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:20; 民数记 10:14; 创世记 49:8–10"> 他是法勒斯的后代，统管一月当值的所有将领。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 23:9; 历代志上 11:12"> 亚哈希人朵代负责二月的班次，他的副官是密基罗，他班内有两万四千人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 18:17; 列王纪上 4:4–5"> 祭司耶何耶大的儿子比拿雅负责第三班，在三月当值，他班内有两万四千人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 23:20–23; 历代志上 11:22–25; 撒母耳记下 22:20–23"> 比拿雅是当时的三十位勇士之一，也是三十位勇士之首。他儿子暗米萨拔在他班内做统领。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:26; 撒母耳记下 23:24; 撒母耳记下 2:18–23"> 约押的兄弟亚撒黑负责第四班，在四月当值，他班内有两万四千人，他儿子西巴第雅后来接替了他。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:27; 撒母耳记下 23:25; 历代志上 26:29"> 伊斯拉人珊合负责第五班，在五月当值，他班内有两万四千人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 11:28; 撒母耳记下 23:26"> 提哥亚人益吉的儿子以拉负责第六班，在六月当值，他班内有两万四千人。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:27; 撒母耳记下 23:26"> 以法莲的子孙比伦人希利斯负责第七班，在七月当值，他班内有两万四千人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 21:18; 历代志上 11:29; 民数记 26:20"> 谢拉族的户沙人西比该负责第八班，在八月当值，他班内有两万四千人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 11:28; 撒母耳记下 23:27"> 便雅悯的子孙亚拿突人亚比以谢负责第九班，在九月当值，他班内有两万四千人。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 11:30; 撒母耳记下 23:28"> 谢拉族的尼陀法人玛哈莱负责第十班，在十月当值，他班内有两万四千人。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 11:31; 撒母耳记下 23:30"> 以法莲的子孙比拉顿人比拿雅负责第十一班，在十一月当值，他班内有两万四千人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 23:29; 历代志上 4:13; 士师记 3:9"> 俄陀聂族的尼陀法人黑玳负责第十二班，在十二月当值，他班内有两万四千人。</span>
</div>
</div>

## 以色列各支派的官长

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 以下是以色列各支派的首领：吕便支派的首领是细基利的儿子以利以谢；西缅支派的首领是玛迦的儿子示法提雅；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:30; 历代志上 24:31; 历代志上 12:27–28"> 利未支派的首领是基姆利的儿子哈沙比雅；亚伦子孙的首领是撒督；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 撒母耳记上 17:29; 撒母耳记上 17:13"> 犹大支派的首领是大卫的哥哥以利户；以萨迦支派的首领是米迦勒的儿子暗利；</span>
<span className="v" id="v19" data-v="19"> 西布伦支派的首领是俄巴第雅的儿子伊施玛雅；拿弗他利支派的首领是亚斯列的儿子耶利摩；</span>
<span className="v" id="v20" data-v="20"> 以法莲支派的首领是阿撒细雅的儿子何细亚；玛拿西半个支派的首领是毗大雅的儿子约珥；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:27; 撒母耳记上 14:50–51; 撒母耳记下 3:37"> 基列的玛拿西另半个支派的首领是撒迦利亚的儿子易多；便雅悯支派的首领是押尼珥的儿子雅西业；</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 28:1"> 但支派的首领是耶罗罕的儿子亚萨列。以上这些人是以色列各支派的首领。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:5; 历代志上 21:2–5; 希伯来书 11:12"> 大卫没有统计二十岁以下的以色列人，因为耶和华曾经应许要使以色列的人数像天上的星那样多。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:1–17; 撒母耳记下 24:1–15"> 洗鲁雅的儿子约押开始统计人数，但没有完成，因为耶和华因此事而向以色列人发烈怒，因此统计的数目没有收录在《大卫王记》上。</span>
</div>
</div>

## 王室产业的主管

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 16:2; 出埃及记 1:11; 历代志下 26:10"> 亚叠的儿子押斯马威管理王室的库房。乌西雅的儿子约拿单管理乡间、城邑、村庄和堡垒的库房。</span>
<span className="v" id="v26" data-v="26"> 基绿的儿子以斯利管理耕田种地的人。</span>
<span className="v" id="v27" data-v="27"> 拉玛人示每管理葡萄园。实弗米人撒巴底管理葡萄园的酒窖。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 10:27; 历代志下 1:15; 列王纪上 4:7"> 基第利人巴勒·哈南管理丘陵的橄榄树和桑树。约阿施管理油仓。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:16; 以赛亚书 65:10"> 沙仑人施提莱管理沙仑的牛群。亚第莱的儿子沙法管理山谷中的牛群。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:6; 约伯记 1:3"> 以实玛利人阿比勒管理骆驼群。米仑人耶希底亚管理驴群。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 5:10"> 夏甲人雅悉管理羊群。以上这些人都是替大卫王管理产业的。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 21:21; 撒母耳记下 13:3; 历代志上 11:11"> 大卫的叔叔约拿单很精明，任谋士和书记。哈摩尼的儿子耶歇做众王子的老师。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 15:12; 撒母耳记下 15:37; 撒母耳记下 15:32"> 亚希多弗也是王的谋士。亚基人户筛是王的朋友。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 11:6; 列王纪上 1:7; 历代志上 27:5"> 后来，比拿雅的儿子耶何耶大和亚比亚他接替亚希多弗做谋士。约押在王的军队中做元帅。</span>
</div>
</div>

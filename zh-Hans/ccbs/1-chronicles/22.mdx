## 大卫筹备建殿

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:17; 列王纪上 9:20–21; 列王纪上 5:17–18"> 大卫下令召集住在以色列的外族人，派他们当中的石匠采凿建上帝殿用的石头。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:14; 历代志上 29:2; 列王纪上 7:47"> 大卫预备了大量的铁，用来做门扇的钉子和钩子，又预备了不计其数的铜。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 5:6–10; 以斯拉记 3:7; 历代志下 2:3"> 他还预备了无数的香柏木，都是西顿人和泰尔人给他运来的。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 3:7; 历代志上 29:1; 约翰福音 3:30"> 大卫说：“为耶和华建造的殿宇必须宏伟辉煌，闻名于世，而我的儿子所罗门年纪还轻、阅历尚浅，所以我要为这殿预备材料。”因此，大卫在去世前为建殿预备了许多材料。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 27:23; 使徒行传 20:25–31; 使徒行传 1:2"> 大卫召来儿子所罗门，嘱咐他要为以色列的上帝耶和华建造殿宇。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 132:5; 列王纪上 8:16–20; 历代志下 6:7–9"> 他对所罗门说：“儿啊，我本想为我的上帝耶和华的名建造一座殿宇。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:3; 历代志上 28:3; 历代志上 17:4–10"> 但耶和华对我说，‘你杀了许多人，打了很多仗，在我眼前使许多人血洒大地，因此你不可为我的名建造殿宇。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:25; 列王纪上 5:4; 列王纪上 4:20"> 你将生一个儿子，我必使他安享太平，不受四围的仇敌侵扰。他的名字要叫所罗门，他执政期间，我必使以色列太平安宁。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 1:5; 撒母耳记下 7:13–14; 历代志上 17:12–14"> 他将为我的名建造殿宇，他要做我的儿子，我要做他的父亲，我要使他在以色列的王位永固。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 22:16; 历代志上 28:20; 提摩太后书 4:22"> “儿啊，愿耶和华与你同在，使你亨通，照你的上帝耶和华的吩咐去建造祂的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:5; 箴言 14:8; 列王纪上 3:9–12"> 你的上帝耶和华赐你权柄治理以色列时，愿祂赐你聪明和智慧，以便你遵行祂的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:6–9; 历代志上 28:20; 历代志上 28:7"> 你若谨遵耶和华借摩西吩咐以色列的律例和典章，就必亨通。你要刚强勇敢，不要惊慌害怕。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 22:3; 列王纪下 25:16; 历代志上 29:4–7"> 看啊，我历尽艰辛，为耶和华的殿预备了六千八百万两金子、六亿八千万两银子和不计其数的铜和铁。我还预备了木料和石头。你还要多加预备。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:6; 出埃及记 35:32; 列王纪上 7:14"> 你有许多工匠，如凿石匠、砌石匠、木匠等各种能工巧匠，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 22:11; 腓立比书 4:13; 以弗所书 5:14"> 还有不计其数的金匠、银匠、铜匠和铁匠。现在动工吧，愿耶和华与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 28:1–6; 约翰三书 1:8; 历代志上 29:6"> 大卫又吩咐以色列的众首领帮助他儿子所罗门，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 22:9; 历代志上 23:25; 撒母耳记下 7:1"> 他说：“你们的上帝耶和华与你们同在，使你们四境平安。祂将这地方的居民交在我手中，使这地方归顺祂和祂的子民。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:9; 申命记 4:29; 历代志上 16:11"> 现在，你们要全心全意地寻求你们的上帝耶和华，去建造耶和华上帝的圣所，好将祂的约柜和圣洁器皿都放在里面。”</span>
</div>
</div>

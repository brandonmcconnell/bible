## 约柜被运到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 16:1; 历代志上 17:1–5; 诗篇 132:5"> 大卫在大卫城为自己建造宫殿，并为上帝的约柜预备地方，支搭帐幕。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 10:8; 申命记 31:9; 民数记 18:1–8"> 大卫说：“除了利未人以外，谁也不可抬上帝的约柜，因为耶和华只拣选他们抬上帝的约柜，永远事奉祂。”</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:1; 历代志上 13:5; 历代志上 15:1"> 大卫召集以色列人到耶路撒冷，要把耶和华的约柜抬到他所预备的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:16–22; 历代志上 12:26–28; 历代志上 6:16–30"> 大卫又召集了亚伦的子孙和利未人：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 6:22–24"> 哥辖的后代乌列族长和他的一百二十个族人；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 6:29–30"> 米拉利的后代亚帅雅族长和他的二百二十个族人；</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 15:11; 历代志上 23:8"> 革顺的后代约珥族长和他的一百三十个族人；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 6:22"> 以利撒反的后代示玛雅族长和他的二百个族人；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 6:18; 历代志上 23:19; 历代志上 26:30–31"> 希伯伦的后代以利业族长和他的八十个族人；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 23:12"> 乌薛的后代亚米拿达族长和他的一百一十二个族人。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 12:28; 列王纪上 2:35; 撒母耳记上 22:20–23"> 大卫召来撒督和亚比亚他两位祭司以及利未人乌列、亚帅雅、约珥、示玛雅、以利业、亚米拿达，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:6; 出埃及记 19:14–15; 历代志上 15:14"> 对他们说：“你们是利未人的族长，你们和你们的族人都要洁净自己，好将以色列的上帝耶和华的约柜抬到我所预备的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 6:3; 哥林多前书 14:40; 约翰一书 1:8–10"> 先前你们没有抬约柜，我们也没有按规矩求问我们的上帝耶和华，以致祂向我们发怒。”</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:15; 约珥书 2:16–17; 历代志下 29:34"> 于是祭司和利未人就洁净自己，好将以色列的上帝耶和华的约柜抬上来。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 4:15; 民数记 7:9; 历代志下 5:9"> 利未人按照耶和华借摩西颁布的命令，用杠把上帝的约柜抬在肩上。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 13:8; 历代志下 5:13; 历代志上 16:42"> 大卫又吩咐利未人的族长去派他们的族人做歌乐手，伴着琴瑟和钹的乐声欢唱。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:39; 历代志上 6:44; 历代志上 6:33"> 于是，利未人指派约珥的儿子希幔和他的亲族比利迦的儿子亚萨，以及他的亲族米拉利的后代古沙雅的儿子以探。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:4; 历代志上 26:8; 历代志上 13:14"> 协助他们的亲族有撒迦利雅、雅薛、示米拉末、耶歇、乌尼、以利押、比拿雅、玛西雅、玛他提雅、以利斐利户、弥克尼雅，以及守门的俄别·以东和耶利。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 25:6; 历代志上 16:5; 历代志上 13:8"> 歌乐手希幔、亚萨和以探负责敲铜钹，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 46:1–11"> 撒迦利雅、雅薛、示米拉末、耶歇、乌尼、以利押、玛西雅、比拿雅负责鼓瑟，调用高音。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 10:5; 历代志上 25:6–7; 诗篇 81:1–2"> 玛他提雅、以利斐利户、弥克尼雅、俄别·以东、耶利、亚撒西雅负责带领弹琴，调用低音。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 15:27; 历代志上 15:16; 历代志上 25:7–8"> 利未人的族长基拿尼雅善于歌唱，是歌乐手的领班。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 84:10; 列王纪下 22:4; 历代志上 9:21–23"> 比利迦和以利加拿负责看守约柜。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 16:6; 民数记 10:8; 历代志上 15:28"> 祭司示巴尼、约沙法、拿坦业、亚玛赛、撒迦利雅、比拿亚和以利以谢负责在上帝的约柜前吹号，俄别·以东和耶希亚也负责看守约柜。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 6:12–23; 弥迦书 5:2; 腓立比书 3:3"> 大卫和以色列的长老以及千夫长去俄别·以东家，欢欢喜喜地把耶和华的约柜抬上来。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 23:29; 历代志上 29:14; 诗篇 66:13–15"> 耶和华上帝恩待抬约柜的利未人，他们就献上七头公牛和七只公羊为祭物。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:18; 撒母耳记下 6:14"> 大卫和抬约柜的利未人、歌乐手及其领班基拿尼雅都穿上细麻布外袍，大卫也穿上细麻布的以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 13:8; 历代志上 15:16; 历代志下 5:12–13"> 以色列人把耶和华的约柜抬了上来，一路上欢呼、吹角、鸣号、敲钹、鼓瑟、弹琴，大声奏乐。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 6:20–23; 撒母耳记下 6:16; 申命记 31:26"> 耶和华的约柜进大卫城的时候，扫罗的女儿米甲从窗户往外观看，见大卫王在兴高采烈地跳舞，心里就轻视他。</span>

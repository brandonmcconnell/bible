## 大卫的胜利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 8:1–18; 撒母耳记上 5:8; 撒母耳记下 1:20"> 后来，大卫打败并征服了非利士人，夺取了迦特及其周围的村庄。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 3:4–5; 列王纪上 10:25; 以赛亚书 16:1"> 他又打败了摩押人，使他们称臣、进贡。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 60:1; 撒母耳记下 8:3; 创世记 15:18"> 琐巴王哈大底谢出来，要巩固他在幼发拉底河一带的势力，大卫打败了他，一直攻到哈马，</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 8:4; 列王纪上 10:26; 列王纪上 4:2"> 俘获一千辆战车、七千骑兵、两万步兵，砍断拉战车的马匹的蹄筋，只留下够拉一百辆战车的马匹。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 19:6; 撒母耳记下 8:5–6; 撒母耳记上 14:47"> 大马士革的亚兰人前来支援琐巴王哈大底谢，大卫杀了他们两万二千人，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 17:8; 诗篇 121:8; 箴言 21:31"> 还在大马士革的亚兰境内驻军，亚兰人臣服于大卫，向他进贡。耶和华使大卫无往而不胜。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 9:15–16; 列王纪上 10:16–17; 历代志下 12:9–10"> 大卫夺走哈大底谢侍从的金盾牌，带回耶路撒冷，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:8; 历代志下 4:12–18; 列王纪上 7:15–47"> 又从哈大底谢统治的提巴和均两座城中夺走大量的铜。后来所罗门用这些铜制造铜海、铜柱及各种铜器。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 8:9"> 哈马王陀乌听说大卫打败琐巴王哈大底谢全军，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:10; 以赛亚书 39:1; 历代志下 9:1"> 就派儿子哈多兰带着许多金银铜器去朝见大卫王，向他请安，祝贺他打败了哈大底谢。因为陀乌常常和哈大底谢交战。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 30:13; 历代志上 26:26–27; 列王纪上 7:51"> 于是，大卫王把这些器皿和他从以东、摩押、亚扪、非利士和亚玛力各国夺来的金银都分别出来，奉献给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 19:11; 撒母耳记下 10:10; 撒母耳记下 8:13–14"> 洗鲁雅的儿子亚比筛在盐谷杀了一万八千名以东人。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 18:6; 创世记 27:37; 诗篇 144:10"> 大卫在以东驻军，以东人都臣服于他。耶和华使他无往而不胜。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 33:15; 诗篇 89:14; 诗篇 78:71–72"> 大卫治理全以色列，对百姓秉公行义。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 11:6; 列王纪上 4:3; 撒母耳记下 8:16"> 那时，洗鲁雅的儿子约押做元帅；亚希律的儿子约沙法做史官；</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 8:17; 撒母耳记下 20:25; 列王纪上 4:3"> 亚希突的儿子撒督和亚比亚他的儿子亚希米勒做祭司长；沙威沙做书记；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 8:18; 撒母耳记下 15:18; 列王纪上 2:34–35"> 耶何耶大的儿子比拿雅统管基利提人和比利提人。大卫王的众子都在他左右做首领。</span>
</div>
</div>

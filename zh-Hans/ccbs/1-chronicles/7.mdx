## 以萨迦的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:13; 民数记 26:23–24"> 以萨迦的四个儿子是陀拉、普瓦、雅述和伸仑。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 24:1–9; 历代志上 27:23–24; 历代志上 27:1"> 陀拉的儿子是乌西、利法雅、耶勒、雅买、易伯散和示姆利，他们都是陀拉宗族的族长。在大卫执政年间，陀拉家共有两万二千六百个英勇的战士。</span>
<span className="v" id="v3" data-v="3"> 乌西的儿子是伊斯拉希。伊斯拉希的儿子是米迦勒、俄巴底亚、约珥、伊示雅，他们五人都是族长。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 12:32"> 他们妻儿众多，因此各宗族中可以出征作战的共有三万六千人。</span>
<span className="v" id="v5" data-v="5"> 按照家谱的记载，以萨迦支派的各族中共有八万七千个英勇的战士。</span>
</div>
</div>

## 便雅悯的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 46:21; 历代志上 8:1–40; 历代志上 7:10–11"> 便雅悯的三个儿子是比拉、比结和耶叠。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 17:17–18; 历代志上 21:1–5"> 比拉的五个儿子是以斯本、乌西、乌薛、耶利摩和以利，他们都是族长，是英勇的战士。按家谱记载，他们宗族共有两万二千零三十四个战士。</span>
<span className="v" id="v8" data-v="8"> 比结的儿子是细米拉、约阿施、以利以谢、以利约乃、暗利、耶利末、亚比雅、亚拿突和亚拉篾。</span>
<span className="v" id="v9" data-v="9"> 比结的儿子都是族长。按家谱的记载，他们宗族共有两万零二百个英勇的战士。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 3:15–30"> 耶叠的儿子是比勒罕，比勒罕的儿子是耶乌施、便雅悯、以笏、基拿拿、细坦、他施和亚希沙哈。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:13–19"> 这些耶叠的儿子都是族长，宗族中可以英勇作战的共一万七千二百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 26:38–39; 创世记 46:21; 历代志上 7:15"> 以珥的儿子是书品和户品，亚黑的儿子是户伸。</span>
</div>
</div>

## 拿弗他利的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 26:48–49; 创世记 30:3–8; 创世记 35:22"> 拿弗他利的儿子是雅薛、沽尼、耶色和沙龙。他们都是辟拉的后代。</span>
</div>
</div>

## 玛拿西的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 32:30–42; 士师记 5:14; 申命记 3:13–15"> 玛拿西的妾是亚兰人，她给玛拿西生的儿子是亚斯烈，另外还生了基列的父亲玛吉。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:33; 民数记 36:1–12; 民数记 27:1–11"> 玛吉娶了户品和书品的妹妹玛迦。玛拿西另一个后代名叫西罗非哈，西罗非哈只有几个女儿。</span>
<span className="v" id="v16" data-v="16"> 玛吉的妻子玛迦生了一个儿子，给他取名叫毗利施。毗利施的兄弟名叫示利施，示利施的儿子是乌兰和利金。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:11"> 乌兰的儿子是比但。这些都是基列的子孙。基列是玛吉的儿子，玛吉是玛拿西的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:24; 士师记 6:11; 士师记 8:2"> 基列的妹妹哈摩利吉生了伊施荷、亚比以谢和玛拉。</span>
<span className="v" id="v19" data-v="19"> 示米大的儿子是亚现、示剑、利克希和阿尼安。</span>
</div>
</div>

## 以法莲的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:35–36"> 以法莲的后代有书提拉，书提拉的儿子是比列，比列的儿子是他哈，他哈的儿子是以拉大，以拉大的儿子是他哈，</span>
<span className="v" id="v21" data-v="21"> 他哈的儿子是撒拔，撒拔的儿子是书提拉。以法莲的另外两个儿子以谢和以列下去夺迦特人的牲畜，被当地人所杀。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 2:11; 创世记 37:34"> 他们的父亲以法莲为他们悲伤了多日，弟兄们都来安慰他。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 23:5"> 后来，以法莲与妻子同房，妻子怀孕，生了一个儿子。以法莲因家里遭遇不幸，就给孩子取名叫比利亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“比利亚”意思是“不幸”。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 16:3; 约书亚记 16:5; 历代志下 8:5"> 以法莲有一个女儿叫舍伊拉，她建造了上伯·和仑、下伯·和仑和乌羡·舍伊拉。</span>
<span className="v" id="v25" data-v="25"> 比利亚的儿子是利法和利悉，利悉的儿子是他拉，他拉的儿子是他罕，</span>
<span className="v" id="v26" data-v="26"> 他罕的儿子是拉但，拉但的儿子是亚米忽，亚米忽的儿子是以利沙玛，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 13:8; 民数记 13:16; 出埃及记 17:9–14"> 以利沙玛的儿子是嫩，嫩的儿子是约书亚。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 28:19; 约书亚记 16:2–3; 历代志上 6:66–67"> 以法莲人的地业和住处包括伯特利及其四围的村庄、东部的拿兰、西部的基色及其四围的村庄、示剑及其四围的村庄，远至艾雅及其四围的村庄。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:22–29; 撒迦利亚书 12:11; 列王纪下 9:27"> 玛拿西人的地业包括伯·善、他纳、米吉多、多珥以及它们四围的村庄。这些是以色列之子约瑟的后代居住的地方。</span>
</div>
</div>

## 亚设的后裔

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 46:17; 民数记 26:44–46"> 亚设的儿子是音拿、亦施瓦、亦施韦、比利亚，女儿是西拉。</span>
<span className="v" id="v31" data-v="31"> 比利亚的儿子是希别和玛结，玛结的儿子是比撒威。</span>
<span className="v" id="v32" data-v="32"> 希别的儿子是雅弗勒、朔默、何坦，女儿是书雅。</span>
<span className="v" id="v33" data-v="33"> 雅弗勒的儿子是巴萨、宾哈和亚施法。这三人是雅弗勒的儿子。</span>
<span className="v" id="v34" data-v="34"> 朔默的儿子是亚希、罗迦、耶户巴和亚兰。</span>
<span className="v" id="v35" data-v="35"> 朔默的兄弟希连的儿子是琐法、音那、示利斯和亚抹。</span>
<span className="v" id="v36" data-v="36"> 琐法的儿子是书亚、哈尼弗、书阿勒、比利、音拉、</span>
<span className="v" id="v37" data-v="37"> 比悉、河得、珊玛、施沙、益兰、比拉。</span>
<span className="v" id="v38" data-v="38"> 益帖的儿子是耶孚尼、毗斯巴、亚拉。</span>
<span className="v" id="v39" data-v="39"> 乌拉的儿子是亚拉、汉尼业和利谢。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志上 21:1–5; 撒母耳记下 24:1–9"> 这些都是亚设的后代。他们都是族长，是英勇的战士和杰出的首领。按照家谱的记载，他们宗族中可以出征作战的共有两万六千人。</span>
</div>
</div>

## 大卫做以色列人的王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 5:1–16; 历代志上 12:23–40; 士师记 9:2"> 以色列人都聚集到希伯仑来见大卫，对他说：“看啊，我们是你的骨肉同胞。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 5:2; 约翰福音 10:4; 诗篇 78:71"> 从前，扫罗做王的时候，率领以色列人出征打仗的是你。你的上帝耶和华也曾应许让你做祂以色列子民的牧者和首领。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:12–13; 撒母耳记上 16:1; 撒母耳记下 5:3"> 以色列的长老都到希伯仑见大卫王，大卫与他们在耶和华面前立约，他们膏立大卫做以色列的王，这应验了耶和华借撒母耳所说的话。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 1:21; 创世记 15:21; 约书亚记 15:8"> 大卫和以色列众人来到耶路撒冷，即耶布斯。那时耶布斯人住在那里。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2; 列王纪上 8:1; 诗篇 87:2"> 耶布斯人对大卫说：“你攻不进来。”然而，大卫攻取了锡安的堡垒，即后来的大卫城。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 8:16; 撒母耳记下 20:23; 撒母耳记下 3:27"> 大卫说：“谁先攻打耶布斯人，谁就做元帅。”洗鲁雅的儿子约押首先进攻，于是就做了元帅。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:5; 撒母耳记下 5:7; 诗篇 2:6"> 大卫住在堡垒里，因此那堡垒就叫大卫城。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 9:6; 列王纪上 11:27; 列王纪下 12:20"> 大卫又从米罗开始，在四围修建城墙，其余的部分由约押修建。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 3:1; 以赛亚书 41:10; 历代志上 9:20"> 大卫日渐强盛，因为万军之耶和华与他同在。</span>
</div>
</div>

## 大卫的勇士

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:3; 撒母耳记上 16:1; 历代志上 12:38"> 以下是大卫手下众勇士的统领，他们和以色列百姓竭力拥护大卫做王，正如耶和华对以色列的应许。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 23:8; 历代志上 27:2; 历代志上 12:18"> 大卫的勇士有哈革摩尼人雅朔班，他是三勇士之首，曾在一次交战中挥矛刺死了三百人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 27:4; 撒母耳记下 23:17–19; 撒母耳记下 23:23"> 其次是亚哈希人朵多的儿子以利亚撒，他是三勇士之一。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 23:11–12; 撒母耳记上 17:1"> 他曾在巴斯·大闵与大卫抵抗非利士人。那里有一块大麦田，以色列人战败逃跑，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:10; 列王纪下 5:1; 撒母耳记上 14:23"> 他们却站在田中间坚守麦田，击杀非利士人。耶和华使以色列人大获全胜。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 14:9; 撒母耳记下 5:18; 以赛亚书 17:5"> 一次，三十位统领中有三位到亚杜兰洞附近的磐石那里见大卫，当时非利士军队在利乏音谷扎营。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 10:5; 撒母耳记上 13:4; 撒母耳记上 13:23"> 那时大卫留守在堡垒里，非利士人的驻军在伯利恒。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:14; 以赛亚书 12:3; 撒母耳记下 23:15–16"> 大卫渴了，说：“但愿有人给我打些伯利恒城门旁的井水喝！”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:13; 撒母耳记上 19:5; 使徒行传 20:24"> 这三位勇士就冲过非利士人的营地，到伯利恒城门旁的井打水，带回来给大卫。大卫却不肯喝，他把水浇奠在耶和华面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 23:17; 诗篇 72:14; 士师记 9:17"> 说：“我的上帝啊！这三人冒死去打水，这些水就像是他们的血，我决不能喝。”因此，大卫不肯喝。这是三勇士的事迹。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:6; 历代志上 2:16; 撒母耳记下 20:6"> 约押的兄弟亚比筛是这三位勇士的统领，他曾挥矛刺死三百人，在三勇士中出了名，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 15:41; 马太福音 13:8"> 最有声望，因此做了他们的统领，只是不及前三位勇士。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 23:20–23; 撒母耳记下 8:18; 约书亚记 15:21"> 甲薛人耶何耶大的儿子比拿雅是位勇士，做过非凡的事。他曾杀死摩押的两个勇猛战士，也曾在下雪天跳进坑中杀死一头狮子，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:7; 撒母耳记上 17:4; 申命记 3:11"> 还杀死一个两米多高的埃及巨人。当时埃及人拿着织布机轴般粗的长矛，比拿雅拿着棍子迎战，他夺了对方的长矛，用那矛刺死了对方。</span>
<span className="v" id="v24" data-v="24"> 这是耶何耶大的儿子比拿雅的事迹，他像那三位勇士一样赢得了名声。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 20:23"> 他比那三十勇士更有声望，只是不及前三位勇士。大卫派他做护卫长。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 27:7; 撒母耳记下 21:19; 撒母耳记下 2:18–23"> 其他勇士有：约押的兄弟亚撒黑、伯利恒人朵多的儿子伊勒哈难、</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 23:25–26"> 哈律人沙玛、比伦人希利斯、</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:12; 历代志上 27:9; 撒母耳记下 23:27"> 提哥亚人益吉的儿子以拉、亚拿突人亚比以谢、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 23:27–28; 历代志上 27:11"> 户沙人西比该、亚哈希人以莱、</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:13; 历代志上 27:15; 撒母耳记下 23:29"> 尼陀法人玛哈莱、尼陀法人巴拿的儿子希立、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 23:29"> 便雅悯支派基比亚人利拜的儿子以太、比拉顿人比拿雅、</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 23:30–31"> 迦实溪人户莱、亚拉巴人亚比、</span>
<span className="v" id="v33" data-v="33"> 巴路米人押斯玛弗、沙本人以利雅哈巴、</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 23:32–33"> 基孙人哈深的众子、哈拉人沙基的儿子约拿单、</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 23:33–34"> 哈拉人沙甲的儿子亚希暗、吾珥的儿子以利法勒、</span>
<span className="v" id="v36" data-v="36"> 米基拉人希弗、比伦人亚希雅、</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 23:35"> 迦密人希斯罗、伊斯拜的儿子拿莱、</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 23:36"> 拿单的兄弟约珥、哈基利的儿子弥伯哈、</span>
<span className="v" id="v39" data-v="39"> 亚扪人洗勒、为洗鲁雅的儿子约押拿兵器的比录人拿哈莱、</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 20:26"> 以帖人以拉、以帖人迦立、</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 2:36; 撒母耳记下 23:39; 撒母耳记下 11:6–27"> 赫人乌利亚、亚莱的儿子撒拔、</span>
<span className="v" id="v42" data-v="42"> 示撒的儿子亚第拿——吕便支派中率领三十人的首领、</span>
<span className="v" id="v43" data-v="43"> 玛迦的儿子哈难、弥特尼人约沙法、</span>
<span className="v" id="v44" data-v="44"> 亚施他拉人乌西亚、亚罗珥人何坦的儿子沙玛和耶利、</span>
<span className="v" id="v45" data-v="45"> 提洗人申利的儿子耶叠和他的兄弟约哈、</span>
<span className="v" id="v46" data-v="46"> 玛哈未人以利业、伊利拿安的儿子耶利拜和约沙未雅、摩押人伊特玛、</span>
<span className="v" id="v47" data-v="47"> 以利业、俄备得和米琐巴人雅西业。</span>

## 祭司的职务

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 23:6; 出埃及记 6:23; 民数记 26:60"> 下面是亚伦子孙的班次。亚伦的儿子是拿答、亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 10:2; 民数记 3:4; 民数记 26:61"> 拿答和亚比户比父亲先死，而且没有留下儿子，因此以利亚撒和以他玛做了祭司。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:17; 历代志上 24:31; 撒母耳记上 21:1"> 在以利亚撒的子孙撒督和以他玛的子孙亚希米勒的协助下，大卫将亚伦的子孙分成班次，让他们各司其职。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:24; 民数记 25:11–13; 历代志上 15:6–12"> 以利亚撒的子孙中做首领的比以他玛的子孙中做首领的多，他们被分成班次：以利亚撒的子孙中有十六个族长，以他玛的子孙中有八个族长。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:31; 约书亚记 18:10; 使徒行传 4:1"> 因为以利亚撒和以他玛的子孙中都有人在圣所做首领事奉上帝，他们便用抽签的方法公平地分班。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:16; 马太福音 8:19; 尼希米记 8:1"> 利未人拿坦业的儿子示玛雅是书记。他在君王、首领、撒督祭司、亚比亚他的儿子亚希米勒、众祭司和利未人的族长面前把抽出的名字记录下来。他们从以利亚撒的子孙中抽出一族，从以他玛的子孙中抽出一族。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:36; 尼希米记 11:10; 尼希米记 12:19"> 第一签抽出来的是耶何雅立，第二签是耶大雅，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:39; 尼希米记 7:35; 尼希米记 12:15"> 第三签是哈琳，第四签是梭琳，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 12:17"> 第五签是玛基雅，第六签是米雅民，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:5; 尼希米记 12:4; 尼希米记 12:17"> 第七签是哈歌斯，第八签是亚比雅，</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 2:36; 尼希米记 12:10; 尼希米记 7:39"> 第九签是耶书亚，第十签是示迦尼，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 12:10"> 第十一签是以利亚实，第十二签是雅金，</span>
<span className="v" id="v13" data-v="13"> 第十三签是胡巴，第十四签是耶是比押，</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 7:40; 以斯拉记 2:37; 以斯拉记 10:20"> 第十五签是璧迦，第十六签是音麦，</span>
<span className="v" id="v15" data-v="15"> 第十七签是希悉，第十八签是哈辟悉，</span>
<span className="v" id="v16" data-v="16"> 第十九签是毗他希雅，第二十签是以西结，</span>
<span className="v" id="v17" data-v="17"> 第二十一签是雅斤，第二十二签是迦末，</span>
<span className="v" id="v18" data-v="18"> 第二十三签是第来雅，第二十四签是玛西亚。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 9:25; 哥林多前书 14:40; 希伯来书 7:11"> 他们照这班次，按以色列的上帝耶和华借他们的祖先亚伦所定的条例，在耶和华的殿里司职。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:24; 历代志上 23:16; 历代志上 6:18"> 其他利未人还有暗兰的后代书巴业，书巴业的后裔耶希底亚，</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:17; 历代志上 26:25"> 利哈比雅的长子伊示雅，</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:18; 民数记 3:27; 民数记 3:19"> 以斯哈的后代示罗摩，示罗摩的后代雅哈，</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 23:19; 历代志上 26:31"> 希伯伦的长子耶利雅、次子亚玛利亚、三子雅哈悉、四子耶加缅，</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 23:20"> 乌薛的后代米迦，米迦的后代沙密，</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 15:20; 历代志上 15:18; 历代志上 23:20"> 米迦的弟兄伊示雅，伊示雅的后代撒迦利雅，</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:21"> 米拉利的儿子抹利、姆示、雅西雅，雅西雅的儿子比挪，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> 米拉利的后代雅西雅的儿子比挪、朔含、撒刻、伊比利，</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 23:22"> 抹利的儿子以利亚撒，以利亚撒没有儿子，</span>
<span className="v" id="v29" data-v="29"> 基士的后代耶拉篾，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 23:23; 历代志上 6:47"> 姆示的儿子末力、以得、耶利摩。这些按宗族都是利未人的后代。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 24:5–6; 历代志上 26:13; 历代志上 25:8"> 他们也在大卫王、撒督、亚希米勒、众祭司和利未人的族长面前抽签，不分长幼，正如他们的亲族亚伦的后代所做的一样。</span>

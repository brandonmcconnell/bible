## 利未人的职务

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 29:28; 历代志上 28:5; 列王纪上 1:33–39"> 大卫年纪老迈，寿数将尽，就立他儿子所罗门为以色列王。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 历代志下 34:29–30; 历代志上 13:1"> 他召集了以色列的众首领、祭司和利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 23:24; 民数记 4:2–49"> 凡三十岁以上的利未人都在统计之列，共有三万八千男子，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 19:8; 申命记 16:18; 历代志上 26:29–31"> 其中有两万四千人在耶和华的殿里司职，六千人做官长和审判官，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:25–26; 历代志下 8:14; 诗篇 87:7"> 四千人守门，四千人用大卫提供的乐器颂赞耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 8:14; 历代志上 6:1; 历代志上 6:16"> 大卫将利未人革顺、哥辖和米拉利的子孙分成班次。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 26:21; 出埃及记 6:17; 历代志上 6:17–20"> 革顺的儿子有拉但和示每。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 6:33–34; 历代志上 15:20–21; 历代志上 15:7"> 拉但有长子耶歇，还有西坦和约珥，共三个儿子，</span>
<span className="v" id="v9" data-v="9"> 都是拉但族的族长。示每的儿子有示罗密、哈薛和哈兰三人。</span>
<span className="v" id="v10" data-v="10"> 示每的儿子还有雅哈、细撒、耶乌施和比利亚四人。</span>
<span className="v" id="v11" data-v="11"> 雅哈是长子，细撒是次子。耶乌施和比利亚的子孙不多，所以合为一族。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 6:18; 民数记 3:27; 民数记 26:58"> 哥辖有暗兰、以斯哈、希伯伦、乌薛四个儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 21:5; 出埃及记 6:20; 撒母耳记上 2:28"> 暗兰的儿子是亚伦和摩西。亚伦和他的子孙永远被分别出来事奉耶和华，向祂献至圣之物，在祂面前烧香，奉祂的名祝福，直到永远。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:1; 诗篇 90:1; 历代志上 26:23–25"> 上帝的仆人摩西的子孙归在利未支派的名下。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 18:3–4; 出埃及记 2:22; 出埃及记 4:20"> 摩西的儿子是革舜和以利以谢。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:24; 历代志上 25:20; 历代志上 24:20"> 革舜的长子是细布业。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:25"> 以利以谢只有一个儿子利哈比雅，但利哈比雅子孙众多。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:26; 历代志上 24:22"> 以斯哈的长子是示罗密。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 24:23; 历代志上 15:9; 历代志上 23:12"> 希伯伦的长子是耶利雅，次子是亚玛利亚，三子是雅哈悉，四子是耶加缅。</span>
<span className="v" id="v20" data-v="20"> 乌薛的长子是米迦，次子是耶西雅。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:19; 历代志上 6:20; 历代志上 24:26–30"> 米拉利的儿子是抹利和姆示。抹利的儿子是以利亚撒和基士。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 24:28; 民数记 36:6–8"> 以利亚撒终生没有儿子，只有女儿，同族人基士的儿子娶了她们为妻。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 24:30"> 姆示的三个儿子是末力、以得和耶利摩。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 10:17; 民数记 10:21; 历代志上 23:3"> 以上是利未各宗族的子孙，他们登记在各自族长的名下，凡二十岁以上的男子都在耶和华的殿里任职。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 132:13–14; 历代志上 22:18; 撒母耳记下 7:11"> 大卫说：“以色列的上帝耶和华已使祂的子民安享太平，祂永远住在耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 4:5; 民数记 7:9; 民数记 4:15"> 利未人再不用抬圣幕和其中的器皿了。”</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:24; 诗篇 72:20; 撒母耳记下 23:1"> 按照大卫临终时的嘱咐，二十岁以上的利未人都在统计之列。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:3–6; 历代志下 31:11; 历代志下 35:11–14"> 他们的任务是帮助亚伦的子孙在耶和华的殿里司职，管理殿的院子和厢房，负责洁净圣物等事务。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 19:35–36; 出埃及记 25:30; 利未记 6:20–23"> 他们还负责供饼、做素祭的细面粉、无酵薄饼的调和、烤制、分量和尺寸。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 92:1–3; 以斯拉记 3:10–11; 历代志上 9:33"> 他们每天早晚要肃立、颂赞耶和华，</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 1:13–14; 民数记 28:1–29; 民数记 10:10"> 每逢安息日、朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup>或其他节期，他们要按照规定的数目将燔祭献给耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 1:53; 民数记 3:38; 民数记 3:6–9"> 他们负责看守会幕和圣所，帮助他们的亲族亚伦的子孙在耶和华的殿里供职。</span>

## 参孙和大利拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:47; 以斯拉记 9:1–2; 创世记 38:16–18"> 一天，参孙去迦萨，看见一个妓女，就与她亲近。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 118:10–12; 撒母耳记上 23:26; 使徒行传 9:24"> 迦萨人得知参孙来了，便包围那地方，整夜埋伏在城门口，没有动手，心想：“等天一亮，我们就杀掉他。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 2:24; 诗篇 107:16; 以赛亚书 63:1–5"> 可是，参孙睡到半夜就起来，把城门的门扇连门框和门闩一同拆下，扛到希伯仑对面的山顶上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:6; 箴言 22:14; 尼希米记 13:26"> 后来，参孙在梭烈谷爱上一位名叫大利拉的女子。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 13:3; 士师记 14:15; 提摩太前书 6:9–10"> 非利士人的首领就上去见这女子，对她说：“请你哄参孙说出他为何有这么大力气，我们怎样才能制服他，把他绑起来。事后，我们每人会给你一千一百块银子。”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 7:21; 箴言 6:26; 箴言 22:14"> 于是，大利拉问参孙：“求你告诉我，你为什么有这么大力气？用什么办法才能把你绑起来制服你？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 21:2–3; 罗马书 3:8; 撒母耳记上 27:10"> 参孙说：“如果他们用七根还没干的青绳子绑住我，我就会像普通人一样软弱。”</span>
<span className="v" id="v8" data-v="8" data-xref="传道书 7:26"> 非利士人的首领便把七根还没干的青绳子交给大利拉，她用那些绳子把参孙绑起来。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 58:9"> 有人已预先埋伏在她的内室，于是她喊道：“参孙，非利士人来捉你了！”但参孙挣断了绳子，就像挣断火烧过的麻线一样。因此，仍然没有人知道他为何力气过人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 16:13; 路加福音 22:48; 士师记 16:7"> 大利拉对参孙说：“你说谎捉弄我。现在请你告诉我，用什么方法才能绑住你？”</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:5; 以弗所书 4:25; 箴言 13:3"> 参孙回答说：“如果他们用从未用过的新绳子绑住我，我就会像普通人一样软弱。”</span>
<span className="v" id="v12" data-v="12"> 于是，大利拉让人埋伏在内室，她用七根新绳子绑住参孙，然后喊道：“参孙，非利士人来捉你了！”结果，参孙挣断了手臂上的绳子，就像挣断一根线一样。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 大利拉对参孙说：“到现在你还是说谎捉弄我。请你告诉我，用什么方法才能绑住你？”参孙说：“你把我的七根发辫和织布机的线编在一起，用梭子扎紧，我就会像普通人一样软弱。”</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 106:43; 以斯拉记 9:13–14"> 于是，大利拉把他的发辫和织布机的线编在一起，用梭子扎紧，然后喊道：“参孙，非利士人来捉你了！”参孙醒来，挣脱了织布机的梭子和线。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 14:16; 约翰一书 2:15–16; 约翰福音 14:21–24"> 大利拉对参孙说：“你既然不跟我说真心话，还说什么爱我！你捉弄了我三次，没告诉我你为何力气过人。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 7:21–23; 路加福音 18:5; 马可福音 14:24"> 大利拉天天在他跟前唠叨不停，以致他烦得要死，</span>
<span className="v" id="v17" data-v="17" data-xref="弥迦书 7:5; 士师记 13:5; 箴言 12:23"> 就把秘密告诉了她。他说：“我从不剃发，因为我一出生就献给上帝做拿细耳人了。如果剃掉我的头发，我就会失去力气，像普通人一样软弱。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 26:15; 士师记 16:5; 提摩太前书 6:10"> 大利拉见他说出了心中的秘密，就派人去通知非利士人的首领，说：“你们再来一次吧，他已经把秘密告诉我了。”于是，他们带着银子去了。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 7:26–27; 箴言 7:21–23; 传道书 7:26"> 大利拉哄参孙枕着她的腿睡觉，然后叫人来剃掉他的七根发辫，使他力气尽失，无力反抗。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 14:42–43; 撒母耳记上 16:14; 约书亚记 7:12"> 她喊道：“参孙，非利士人来捉你了！”参孙醒来，心想：“我要像前几次一样挣脱捆绑。”他却不知道耶和华已经离开他了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 2:19; 箴言 14:14; 以赛亚书 47:2"> 非利士人拿住他，剜了他的眼睛，把他带到迦萨，用铜链锁住他，让他在监牢里推磨。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 107:13–14; 诗篇 106:44–45; 利未记 26:44"> 后来，他的头发又渐渐长出来了。</span>
</div>
</div>

## 参孙之死

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 5:2–5; 箴言 24:17; 诗篇 35:15–16"> 非利士人的首领聚在一起向他们的神明大衮献大祭，欢呼说：“我们的神把仇敌参孙交在我们手中了。”</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 5:4; 但以理书 5:23; 士师记 15:16"> 众人看见参孙，就赞美他们的神明，说：“我们的神把仇敌交在我们手中了，他曾毁坏我们的田地，杀死我们许多人。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 13:28; 士师记 19:6; 士师记 9:27"> 他们都兴高采烈，并喊道：“把参孙带来让我们消遣消遣。”于是，有人把参孙从监牢里提出来供他们消遣，他们让他站在两根柱子中间。</span>
<span className="v" id="v26" data-v="26"> 参孙对拉着他手的童仆说：“带我到支撑这庙宇的柱子那里，我想靠一靠。”</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 22:8; 撒母耳记下 11:2; 约书亚记 2:8"> 那时，庙里挤满了男男女女，非利士人的首领们都在场，房顶上还有三千男女看参孙的热闹。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="耶利米书 15:15; 耶利米哀歌 3:31–32; 诗篇 143:12"> 参孙呼求耶和华，说：“主耶和华啊，求你眷顾我！上帝啊，求你再赐给我一次力量，使我向非利士人报剜眼之仇。”</span>
<span className="v" id="v29" data-v="29"> 参孙就抱住庙宇中央的两根柱子，一手抱一根，</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 2:8; 马太福音 16:25; 马太福音 24:38–39"> 然后喊道：“我要跟非利士人同归于尽！”于是，他用尽全力推柱子，庙宇倒塌，压住里面的首领和民众。参孙死时杀的人比他活着时杀的还多。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 15:20; 士师记 13:25; 士师记 13:2"> 参孙的兄弟和家人取走他的尸体，葬在琐拉和以实陶之间他父亲玛挪亚的墓地里。参孙做以色列的士师二十年。</span>
</div>
</div>

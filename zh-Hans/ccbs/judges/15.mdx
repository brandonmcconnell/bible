## 参孙向非利士人报仇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 38:17; 创世记 29:21; 路加福音 15:29"> 过了些日子，在割麦的时候，参孙带着一只山羊羔去探望他妻子。他说：“我要进内室见我妻子。”他岳父却不让他进去，</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 14:20; 士师记 14:16; 创世记 38:14"> 并对他说：“我以为你非常恨她，所以我把她改嫁给你的伴郎了。她妹子不是比她更美吗？你可以娶来代替她。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士师记 14:15"> 参孙说：“这次我要加害非利士人，可不能怪我了。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="雅歌 2:15; 诗篇 63:10; 耶利米哀歌 5:18"> 于是，他出去捉了三百只狐狸，把它们的尾巴一对一对绑起来，将火把绑在两条尾巴中间，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:30; 出埃及记 22:6"> 然后点燃火把，把狐狸放进非利士人的麦田里，将割好的麦捆和未割的麦子、葡萄园和橄榄园都烧毁了。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 14:15; 帖撒罗尼迦前书 4:6; 箴言 22:8"> 非利士人问：“这是谁干的？”有人回答说：“是亭拿人的女婿参孙干的，因为他岳父把他的妻子嫁给了他的伴郎。”非利士人就去放火烧死了参孙的妻子和岳父。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 14:4; 罗马书 12:19; 士师记 14:19"> 参孙说：“你们既然这样做，我不向你们报仇誓不罢休。”</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 63:3; 以赛亚书 63:6; 以赛亚书 25:10"> 参孙大肆击杀他们，杀死了很多人。事后，他下到以坦，住在那里的岩洞里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 15:17; 士师记 15:19; 士师记 15:14"> 非利士人进犯犹大，在利希一带扎营。</span>
<span className="v" id="v10" data-v="10"> 犹大人问他们：“你们为什么来攻打我们？”非利士人回答说：“我们来捉拿参孙，向他以报还报。”</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 13:1; 士师记 14:4; 申命记 28:47–48"> 于是，有三千犹大人去以坦的岩洞找参孙，对他说：“难道你不知道非利士人是我们的统治者吗？你为什么连累我们？”参孙回答说：“我只是以牙还牙。”</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 8:21; 使徒行传 7:25; 列王纪上 2:25"> 犹大人说：“我们来是要捉拿你，把你交给非利士人。”参孙说：“你们要起誓不会亲手杀我。”</span>
<span className="v" id="v13" data-v="13"> 他们说：“我们不会杀你，只将你绑起来交给非利士人。”于是，他们用两根新绳子把参孙捆绑起来带出岩洞。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="士师记 14:19; 士师记 3:10; 诗篇 118:11"> 参孙来到利希，非利士人就呐喊着迎了上去。耶和华的灵突然降在参孙身上，绑在他手臂上的绳子就像被火烧的麻线一样脱落下来。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 23:10; 利未记 26:8; 士师记 3:31"> 他看到一块还没有干的驴腮骨，就捡起来用它杀了一千个非利士人。</span>
<span className="v" id="v16" data-v="16"> 参孙说：<br /><span className="pl pl-1">“用这驴腮骨，我杀人成堆；</span><br /><span className="pl pl-1">用这驴腮骨，我杀死千人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 说完，他扔掉了手中的驴腮骨。因此，那地方叫拉末·利希<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拉末·利希”意思是“腮骨岗”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:7–8; 希伯来书 11:32; 士师记 8:4"> 参孙觉得非常口渴，便向耶和华呼求说：“你既然借着仆人的手大败敌人，难道你会让我渴死、落在这些未受割礼的人手中吗？”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 44:3; 创世记 45:27; 诗篇 34:6"> 于是，上帝使利希的一处洼地裂开，涌出水来。参孙喝后恢复了精神。因此，那水泉叫隐·哈歌利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“隐·哈歌利”意思是“呼求者的泉”。">b</a></sup>。那水泉今天还在利希。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 13:1; 士师记 16:31; 士师记 13:5"> 在非利士人统治期间，参孙做以色列的士师二十年。</span>
</div>
</div>

</div>

## 参孙的出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 12:9; 士师记 6:1; 罗马书 2:6"> 以色列人又做耶和华视为恶的事，耶和华就把他们交在非利士人手中四十年。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 19:41; 路加福音 1:7; 约书亚记 15:33"> 琐拉城住了一个但支派的人，名叫玛挪亚。他妻子不能生育，没有孩子。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:13; 路加福音 1:11; 士师记 6:11–12"> 耶和华的天使向那妇人显现，对她说：“你虽然不生育，但不久你必怀孕生一个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:15; 士师记 13:14; 民数记 6:2–3"> 现在，你要留心，不可喝淡酒和烈酒，不可吃任何不洁之物。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 6:5; 撒母耳记上 1:11; 历代志上 18:1"> 你必怀孕生一个儿子，你不可为他剃头，因为他一出生就要归给上帝做拿细耳人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拿细耳人”参见民数记6:1‑8。">a</a></sup>。他要从非利士人手中拯救以色列人。”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 13:17–18; 撒母耳记上 9:6; 马太福音 28:3–4"> 妇人就去对丈夫说：“有一位上帝的仆人向我显现，他的容貌像上帝的天使，非常可畏。我没有问他从哪里来，他也没有把名字告诉我。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 13:4"> 他对我说，‘你必怀孕生一个儿子，现在不可喝淡酒和烈酒，不可吃任何不洁之物，因为孩子一出生就要献给耶和华，终生做拿细耳人。’”</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:6; 约伯记 34:32; 箴言 3:5–6"> 玛挪亚向耶和华祈求说：“主啊，求你再派你的仆人到这里来，教我们怎样照顾要出生的孩子。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 65:2; 马太福音 7:7–11"> 上帝应允了他的祈求。他妻子正坐在田间的时候，上帝的天使再次向她显现。当时她丈夫玛挪亚不在场。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:28–29; 约翰福音 1:41–42"> 她赶忙跑去告诉她丈夫说：“那天来的那人又向我显现了。”</span>
<span className="v" id="v11" data-v="11"> 玛挪亚起来跟随妻子来到那人面前，问他：“跟我妻子说话的就是你吗？”他答道：“是我。”</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; 以弗所书 6:4; 创世记 18:19"> 玛挪亚问道：“你的话应验以后，我们应该怎样抚养这孩子？他该做什么？”</span>
<span className="v" id="v13" data-v="13"> 耶和华的天使说：“你的妻子必须谨记我的一切吩咐。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 2:5; 士师记 13:4; 帖撒罗尼迦后书 3:4"> 她不可吃葡萄树所结的果实，淡酒和烈酒都不可喝，不可吃任何不洁之物。她必须遵行我的一切吩咐。”</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 6:18–19; 创世记 18:3–5; 士师记 13:3"> 玛挪亚说：“请你留下来，我们要预备一只山羊羔给你吃。”</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 13:23; 士师记 6:20; 士师记 6:26"> 当时，玛挪亚仍然不知道那人是耶和华的天使。天使说：“我就是留下来也不会吃你预备的食物。你如果预备燔祭，就把它献给耶和华吧！”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 32:29"> 玛挪亚说：“请告诉我你的名字，当一切应验的时候，我们好向你表达敬意。”</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 32:29; 以赛亚书 9:6; 士师记 13:6"> 耶和华的天使说：“何必问我的名字呢？我的名字奇妙难测。”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 6:19–21; 列王纪上 18:30–38"> 于是，玛挪亚就把一只山羊羔和素祭放在磐石上，献给耶和华。就在这时候，天使在玛挪亚夫妇面前行了一件奇妙的事：</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 9:24; 历代志上 21:16; 列王纪下 2:11"> 火焰从祭坛上升起的时候，耶和华的天使也在祭坛的火焰中升上去了。玛挪亚夫妇见状便俯伏在地。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 6:22; 何西阿书 12:4–5; 士师记 13:16"> 耶和华的天使后来没再向玛挪亚夫妇显现，玛挪亚才知道他是耶和华的天使。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 申命记 5:26; 约翰福音 1:18"> 玛挪亚对妻子说：“我们必死无疑，因为我们看见了上帝。”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 25:14; 哥林多前书 12:21; 约翰福音 15:15"> 他妻子却说：“耶和华如果要杀我们，就不会接受我们的燔祭和素祭了，也不会让我们看见这些事，更不会这时候跟我们说这些话。”</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:80; 撒母耳记上 3:19; 希伯来书 11:32"> 后来玛挪亚的妻子生了个儿子，她给孩子取名叫参孙。这孩子渐渐长大，耶和华赐福给他。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 3:10; 约书亚记 15:33; 约翰福音 3:34"> 当他在琐拉和以实陶之间的玛哈尼·但的时候，耶和华的灵开始感动他。</span>
</div>

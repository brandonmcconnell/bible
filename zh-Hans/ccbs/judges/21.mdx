## 为便雅悯支派娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:1; 马可福音 6:23; 使徒行传 23:12"> 以色列人曾在米斯巴起誓不把女儿嫁给便雅悯人。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 20:26; 士师记 20:18; 撒母耳记上 30:4"> 他们来到伯特利，坐在上帝面前放声痛哭，直到黄昏。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 74:1; 约书亚记 7:7–9; 以赛亚书 63:17"> 他们说：“以色列的上帝耶和华啊，以色列现今为何少了一个支派呢？为何发生了这样的事呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 24:25; 列王纪上 8:64; 诗篇 78:34–35"> 第二天，众人清早起来在那里筑了一座祭坛，献上燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 5:23; 士师记 21:18; 士师记 21:1"> 他们彼此议论说：“我们到米斯巴聚集在耶和华面前的时候，各支派中谁没有来呢？”原来，他们曾经起誓说：凡不到米斯巴聚集在耶和华面前的人都要被处死。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 21:15; 士师记 20:23; 路加福音 19:41–42"> 以色列人为他们的同胞便雅悯人难过，说：“如今以色列绝了一个支派。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:1; 士师记 21:18; 撒母耳记上 14:28–29"> 我们曾经在耶和华面前起誓，决不把女儿嫁给便雅悯人，现在我们应该怎么办，才能使他们剩下来的人得到妻子呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 31:11–13; 撒母耳记上 11:1–3; 撒母耳记下 2:5–6"> 他们又查问各支派中谁没有到米斯巴聚集在耶和华面前，结果发现基列·雅比人缺席，</span>
<span className="v" id="v9" data-v="9"> 因为点兵的时候，没有一个基列·雅比人在场。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 5:23; 士师记 21:5; 撒母耳记上 11:7"> 于是，会众派出一万二千精兵，命令他们用刀杀掉基列·雅比人及其妇女和孩子。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 31:17–18; 申命记 2:34"> 他们对精兵说：“你们所要做的就是消灭所有的男子和已婚妇女。”</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 7:12; 诗篇 78:60"> 他们在基列·雅比的居民中找到四百名处女，把她们带回迦南的示罗营地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 20:47; 申命记 20:10; 以弗所书 2:17"> 全体会众又派人到临门岩去跟便雅悯人讲和。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 21:12; 哥林多前书 7:2; 士师记 20:47"> 于是，便雅悯人返回了家乡，以色列人把从基列·雅比居民中留下来的四百个处女给他们做妻子，但还是不够。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 21:6; 历代志上 15:13; 以赛亚书 58:12"> 众人为便雅悯支派难过，因为耶和华使以色列少了一个支派。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 会众的长老说：“便雅悯支派的女子都死了，我们应该怎么办才能使余下的人有妻子呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:55; 民数记 36:7"> 便雅悯的余民必须成家立后，以免以色列失去一个支派。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 21:1; 士师记 11:35"> 可是我们又不能把女儿嫁给他们，因为我们曾经起誓，‘把女儿嫁给便雅悯人的必受咒诅。’”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 16:10; 申命记 16:1; 申命记 16:13"> 有人想起在示罗每年都有耶和华的节期。示罗在利波拿以南、伯特利以北至示剑的大路东面。</span>
<span className="v" id="v20" data-v="20"> 于是，他们对便雅悯人说：“你们去埋伏在葡萄园里，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:34; 出埃及记 15:20; 传道书 3:4"> 见到示罗的女子出来跳舞时，就冲出去各自抢一个，带回便雅悯做妻子。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 21:1; 士师记 21:18; 士师记 21:14"> 倘若她们的父亲或弟兄前来抱怨，我们会说，‘求你们看在我们的情面上恩待他们，因为我们从战场上带回的女子不够分给他们做妻子。何况又不是你们把女儿嫁给他们的，所以罪不在你们。’”</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:48"> 便雅悯人就依计行事，从跳舞的女子中各自抢了一个，带回自己的家乡做妻子。他们重建城邑，住在其中。</span>
<span className="v" id="v24" data-v="24"> 于是，以色列人离开那里，各回自己的支派、宗族和家园。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 12:8; 士师记 17:6; 箴言 3:5"> 那时，以色列没有王，人人各行其是。</span>
</div>
</div>

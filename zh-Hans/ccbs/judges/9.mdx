## 亚比米勒做王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:31; 诗篇 83:2–4; 撒母耳记下 15:6"> 耶路·巴力的儿子亚比米勒去示剑的舅舅家，对外祖父全家说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:14; 士师记 8:30; 希伯来书 2:14"> “请你们去问示剑人，耶路·巴力的七十个儿子统治他们好呢，还是一个人统治他们好呢？别忘记我是你们的骨肉至亲。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 29:15; 诗篇 10:3; 箴言 1:11–14"> 他们便将他的话转告示剑人。示剑人因为亚比米勒是他们的亲戚，都拥护他，</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 8:33; 使徒行传 17:5; 历代志下 13:7"> 从巴力·比利土的庙里拿了七十块银子给他。他用这些钱收买了一班无赖做随从。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 11:1–2; 历代志下 21:4; 士师记 6:24"> 他前往俄弗拉，来到他父亲家，在一块磐石上杀死了他七十个同父异母的兄弟，只有耶路·巴力的小儿子约坦躲了起来，幸免于难。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 5:9; 列王纪上 12:20; 列王纪下 12:20"> 示剑和米罗的人都聚集到示剑石柱旁的橡树下，拥立亚比米勒为王。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:29; 约翰福音 4:20; 申命记 27:12"> 约坦听见这消息，便上到基利心山顶，高喊：“示剑人啊，你们要听我说，这样上帝也会听你们说。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 8:22–23; 但以理书 4:10–18; 列王纪下 14:9"> 从前，树木要选一个王，它们对橄榄树说，‘你来做我们的王。’</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:1; 出埃及记 29:7; 使徒行传 4:27"> 橄榄树说，‘我怎能因为贪图凌驾于众树之上而停止出产用来尊崇神明与人的橄榄油呢？’</span>
<span className="v" id="v10" data-v="10"> 树木对无花果树说，‘你来做我们的王。’</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> 无花果树说，‘我怎能因为贪图凌驾于众树之上而停止出产甜美的果子呢？’</span>
<span className="v" id="v12" data-v="12"> 于是，树木对葡萄树说，‘你来做我们的王。’</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 104:15; 传道书 10:19; 民数记 15:5"> 葡萄树说，‘我怎能因为贪图凌驾于众树之上而停止出产令神明和世人都快乐的美酒呢？’</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 14:9"> 最后，所有的树木都对荆棘说，‘你来做我们的王。’</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:2; 士师记 9:20; 何西阿书 14:7"> 荆棘回答说，‘你们如果诚心立我为你们的王，就投靠在我的荫下吧；不然，愿火从荆棘中冒出来吞噬黎巴嫩的香柏树。’</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 8:35"> “现在你们立亚比米勒为王，光明正大吗？你们有没有善待耶路·巴力和他一家？有没有按他的功绩对待他？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:4; 罗马书 5:8; 启示录 12:11"> 你们想想，从前我父亲为你们出生入死，从米甸人手中拯救你们。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 9:5–6; 士师记 8:30–31; 士师记 9:14"> 现在你们却背叛我父亲家，在一块磐石上杀死他七十个儿子。因为他婢女的儿子亚比米勒是你们的亲戚，你们就立亚比米勒为示剑居民的王。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:6; 雅各书 4:16; 腓立比书 3:3"> 如果你们光明正大地对待了耶路·巴力一家，愿你们给亚比米勒带来快乐，也愿亚比米勒给你们带来快乐。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 9:15; 士师记 9:56–57; 历代志下 20:22–23"> 否则，愿亚比米勒烧灭你们示剑人和米罗人，也愿你们示剑人和米罗人烧灭亚比米勒。”</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 21:16; 撒母耳记下 20:14; 约书亚记 19:8"> 约坦因惧怕他的兄弟亚比米勒，就逃往比珥居住。</span>
</div>
</div>

## 亚比米勒毁灭示剑

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 亚比米勒治理以色列三年后，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:1; 以赛亚书 19:14; 以赛亚书 19:2"> 上帝派遣一个邪灵挑起亚比米勒和示剑人之间的争端，示剑人用诡诈的手段对待亚比米勒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 2:32; 诗篇 7:16; 以斯帖记 9:25"> 这是要惩罚亚比米勒和帮他残杀耶路·巴力七十个儿子的示剑人。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 8:12–13; 箴言 1:11–12; 约书亚记 8:4"> 示剑人在山顶设下埋伏，等候亚比米勒，他们抢劫所有过路的行人。有人把这事告诉了亚比米勒。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 13:8; 创世记 19:7"> 以别的儿子迦勒和他的弟兄来到示剑，示剑人都信任他们。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 9:4; 士师记 9:46; 诗篇 109:17"> 示剑人出城到田间采摘葡萄，踩榨葡萄汁，然后在他们的神庙中欢宴，尽情吃喝，咒诅亚比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 34:2; 创世记 34:6; 撒母耳记上 25:10"> 以别的儿子迦勒说：“亚比米勒是谁？我们示剑人是谁，竟要服侍他？他不就是耶路·巴力的儿子吗？他的帮手不就是西布勒吗？我们为什么要服侍他？你们要服侍示剑人祖先哈抹的后代。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 15:4; 撒母耳记下 2:14–17; 以赛亚书 36:8–9"> 要是这百姓归我领导就好了！我会除掉亚比米勒，我会挑战他召集全军来战<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我会挑战他召集全军来战”参照《七十士译本》；希伯来文作“他对亚比米勒说：‘召集你的全军来战吧！’”">a</a></sup>。”</span>
<span className="v" id="v30" data-v="30"> 示剑城的官长西布勒听见以别的儿子迦勒的话，勃然大怒，</span>
<span className="v" id="v31" data-v="31"> 暗中派人对亚比米勒说：“以别的儿子迦勒和他的弟兄已经到了示剑，正在煽动全城反对你。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 3:15; 诗篇 36:4; 箴言 1:11–16"> 请你晚上带着部下埋伏在田间，</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 10:7; 传道书 9:10; 利未记 25:26"> 清晨日出时攻城。迦勒带着部下出来应战时，你便可以见机行事。”</span>
<span className="v" id="v34" data-v="34"> 于是，亚比米勒带领军队夜间出发，兵分四路埋伏在示剑城外。</span>
<span className="v" id="v35" data-v="35"> 早晨，以别的儿子迦勒出来站在城门口时，亚比米勒带领部下从埋伏的地方冲了出来。</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 8:24; 以西结书 7:7"> 迦勒看见他们，便对西布勒说：“看！有人正从山顶下来。”西布勒说：“你把山影看成人了吧。”</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 18:14"> 迦勒说：“看！有人正从山上下来，还有一队人正从占卜橡树那边的路上奔来。”</span>
<span className="v" id="v38" data-v="38" data-xref="士师记 9:28–29; 列王纪下 14:8–14; 撒母耳记下 2:26–27"> 西布勒说：“你的豪气哪里去了？你曾说，‘亚比米勒是谁，我们竟要服侍他？’这些不就是你讥笑的人吗？出去迎战吧！”</span>
<span className="v" id="v39" data-v="39"> 于是，迦勒率领示剑人出城迎战亚比米勒。</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 20:18–21; 列王纪上 20:30"> 迦勒败逃，亚比米勒紧追不舍，沿途有许多人受伤倒在地上，一直到城门口。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 9:28; 士师记 9:30"> 之后，亚比米勒住在亚鲁玛，西布勒把迦勒和他的弟兄逐出示剑。</span>
<span className="v" id="v42" data-v="42"> 第二天，示剑人出城来到田间。亚比米勒得知后，</span>
<span className="v" id="v43" data-v="43"> 把部下兵分三队，埋伏在田间，等城里的人出来时，伏击他们。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太书 5:15; 士师记 9:15; 士师记 9:20"> 亚比米勒率领一队人冲到示剑的城门口，截断示剑人的退路，其他两队击杀田间的示剑人。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 3:25; 申命记 29:23; 雅各书 2:13"> 亚比米勒鏖战一天，攻陷了示剑城，杀了城内的居民，把整座城夷为平地，还撒上了盐。</span>
<span className="v" id="v46" data-v="46" data-xref="士师记 8:33; 士师记 9:4; 列王纪上 8:26"> 示剑楼的人听到风声，躲进了伊勒·比利土神庙的内堂。</span>
<span className="v" id="v47" data-v="47"> 亚比米勒得知他们都聚在那里后，</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 68:14; 箴言 1:11–12; 士师记 7:17–18"> 便领兵上撒们山用斧头砍下树枝，扛在肩上，并命令部下赶紧照做。</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太书 5:15; 雅各书 3:16; 士师记 9:20"> 他们都砍下树枝，跟着亚比米勒把树枝堆在神庙内堂的四周，放火烧死了示剑楼里所有的人，男女约一千人。</span>
<span className="v" id="v50" data-v="50"> 随后，亚比米勒去围攻提备斯，占领了该城。</span>
<span className="v" id="v51" data-v="51"> 全城的人连男带女都逃进城中一座坚固的城楼内，锁上大门，爬上楼顶。</span>
<span className="v" id="v52" data-v="52" data-xref="士师记 9:48–49; 列王纪下 14:10; 列王纪下 15:16"> 亚比米勒攻打城楼，走到城楼门口正准备放火时，</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳记下 11:21; 约伯记 31:3; 耶利米书 49:20"> 有个妇人扔下一块磨石，砸烂了他的头。</span>
<span className="v" id="v54" data-v="54" data-xref="撒母耳记上 31:4–5"> 亚比米勒连忙对为他拿兵器的年轻人说：“拔刀杀了我吧，免得人们说，‘一位妇人杀了他。’”于是，那年轻人刺死了他。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳记下 18:16; 撒母耳记下 20:21–22; 列王纪上 22:35–36"> 以色列人见亚比米勒已死，便各自回家了。</span>
<span className="v" id="v56" data-v="56" data-xref="诗篇 94:23; 士师记 9:24; 箴言 5:22"> 上帝就这样使亚比米勒得到了报应，因为他残杀了自己的七十个兄弟，</span>
<span className="v" id="v57" data-v="57" data-xref="士师记 9:20; 约书亚记 6:26; 列王纪上 16:34"> 上帝也让示剑人因自己的一切恶行而得到了报应。耶路·巴力的儿子约坦的咒诅临到了他们。</span>
</div>

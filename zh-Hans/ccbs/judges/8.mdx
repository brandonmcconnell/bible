## 基甸擒杀米甸二王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 19:41; 士师记 12:1–6; 约伯记 5:2"> 后来，以法莲人对基甸说：“你攻打米甸人时为什么不召我们去？你为什么这样对待我们？”他们与他激烈地争论起来。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 13:4–7; 腓立比书 2:2–3; 雅各书 3:13–18"> 基甸说：“我怎能比得上你们呢？以法莲人摘剩的葡萄岂不比我们亚比以谢族收获的葡萄更好吗？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士师记 7:24–25; 约翰福音 4:37"> 上帝把两名米甸人的首领俄立和西伊伯交在了你们手中，我所做的怎能跟你们相比呢？”基甸这么一说，他们的怒气就平息了。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 6:9; 哥林多后书 4:16; 撒母耳记上 14:28–29"> 基甸率领他的三百人渡过约旦河，虽然疲惫不堪，仍紧追敌人。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:17; 诗篇 60:6; 撒母耳记上 25:18"> 基甸对疏割的人说：“我们在追赶西巴和撒慕拿两个米甸王，十分疲惫，请给我的军队一些饼吃。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 20:11; 腓立比书 2:21; 箴言 18:23"> 疏割的首领却说：“你还没有抓到西巴和撒慕拿，我们凭什么给你的军队饼吃？”</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 7:15"> 基甸说：“好吧，耶和华把西巴和撒慕拿交在我们手中后，我必回来用荒野的荆棘抽打你们。”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:30–31; 列王纪上 12:25"> 基甸又去毗努伊勒提出同样的请求，他们的答复跟疏割人一样。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 8:17; 列王纪上 22:27–28"> 基甸对那里的人说：“我平安归来时，必拆毁你们的这座城楼。”</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 7:12; 士师记 20:25; 士师记 20:2"> 那时，西巴和撒慕拿率领东方各族的残余军队一万五千人驻扎在加各，因为已经有十二万刀兵被杀。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 32:35; 民数记 32:42; 士师记 18:27"> 基甸取道挪巴和约比哈东边游牧者走的路，出其不意地突袭米甸人。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:11; 阿摩司书 2:14; 约伯记 12:16–21"> 米甸二王西巴和撒慕拿逃跑，基甸追上去擒住他们，击溃他们全军。</span>
<span className="v" id="v13" data-v="13"> 约阿施的儿子基甸从战场返回，经过希列斯山坡时，</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:24–25; 撒母耳记上 30:11–15"> 抓住一个疏割的青年，问他疏割的首领和长老是谁，他就写下疏割七十七位首领和长老的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:6–7"> 基甸到了疏割，对那里的人说：“你们曾经讥笑我说，‘你还没有抓到西巴和撒慕拿，我们凭什么给你疲惫的军队饼吃？’看！西巴和撒慕拿在这里！”</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 8:7; 以斯拉记 2:6; 箴言 10:13"> 说完，就捉住城中的长老，用荒野的荆棘抽打他们。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 8:9; 列王纪上 12:25"> 他又去拆毁毗努伊勒的城楼，杀了城里的人。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 4:6; 犹大书 1:16; 诗篇 89:12"> 基甸问西巴和撒慕拿：“你们在他泊山杀的人是什么样子？”他们回答说：“他们长得像你，都像王子一样。”</span>
<span className="v" id="v19" data-v="19"> 基甸说：“他们是我同母所生的兄弟，我凭永活的耶和华起誓，如果你们当初不杀他们，今天我就不杀你们了。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 149:9; 撒母耳记上 15:33; 约书亚记 10:24"> 于是，基甸对长子益帖说：“你杀死他们。”但益帖年纪小，心中害怕，不敢动手。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 83:11; 士师记 8:26; 以赛亚书 3:18"> 西巴和撒慕拿对基甸说：“你亲自动手吧！这是男子汉做的事。”基甸便亲手杀了他们，拿走了他们骆驼颈上的月牙饰物。</span>
</div>
</div>

## 基甸造以弗得

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 6:15; 士师记 9:8–15; 撒母耳记上 12:12"> 以色列人对基甸说：“你从米甸人手中救了我们，请你和你的子孙统治我们。”</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:22; 撒母耳记上 12:12; 撒母耳记上 10:19"> 基甸回答说：“我和我子孙都不统治你们，统治你们的是耶和华。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:13; 创世记 37:25; 创世记 37:28"> 他又说道：“我有一个要求，请你们把抢来的耳环都给我。”原来米甸人属于以实玛利族，都戴金耳环。</span>
<span className="v" id="v25" data-v="25"> 他们欣然同意，便铺开一件外衣，各自把抢来的金耳环都放在上面，</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 18:16; 约翰福音 19:2; 启示录 18:12"> 重约二十公斤。此外，还有米甸王的月牙饰物、耳坠、紫袍以及骆驼颈上的金链。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 17:5; 士师记 18:14; 诗篇 106:39"> 基甸用这些金子造了一件以弗得圣衣，放在自己的家乡俄弗拉。后来，以色列人拜那件以弗得，玷污自己，使基甸及其全家陷入网罗。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 5:31; 士师记 3:11; 士师记 3:30"> 这样，米甸人被以色列人征服了，从此一蹶不振。基甸在世之日，以色列境内安享太平四十年。</span>
</div>
</div>

## 基甸去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 6:32; 士师记 7:1; 撒母耳记上 12:11"> 约阿施的儿子耶路·巴力返回家乡居住。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 9:5; 士师记 9:2; 列王纪上 11:3"> 他有许多妻子，生了七十个儿子。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 9:18; 创世记 22:24; 创世记 16:15"> 他的妾住在示剑，也给他生了一个儿子，他给孩子取名叫亚比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 25:8; 士师记 6:24; 约伯记 5:26"> 约阿施的儿子基甸年高寿终，葬在亚比以谢族的俄弗拉，在他父亲约阿施的坟墓里。</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 9:46; 士师记 2:19; 士师记 9:4"> 基甸刚去世，以色列人便又与巴力苟合，奉巴力·比利土为他们的神明，</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 78:42; 诗篇 106:21; 诗篇 78:11"> 忘记了他们的上帝耶和华曾经从四围的仇敌手中拯救他们，</span>
<span className="v" id="v35" data-v="35" data-xref="传道书 9:14–15; 士师记 9:5; 士师记 9:16–19"> 也没有因耶路·巴力，就是基甸的功绩而厚待他的家人。</span>
</div>

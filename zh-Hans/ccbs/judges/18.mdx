## 米迦和但支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 17:6; 士师记 19:1; 士师记 1:34"> 那时以色列没有王。但支派的人正在寻找可以居住的地方，因为他们在以色列各支派中还没有得到属于自己的土地。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 约书亚记 2:1; 士师记 18:11"> 但支派的人从琐拉和以实陶派本族的五名勇士去打探、察看那个地方，并吩咐说：“你们去察看那个地方。”他们到了以法莲山区，在米迦家里借宿。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 12:6; 创世记 27:22; 马太福音 26:73"> 他们到了米迦家，听出那利未青年的口音，就转身进去问他：“谁带你来这里的？你在这里做什么？你为什么在这里？”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 17:10; 以西结书 13:19; 箴言 28:21"> 那青年便把米迦聘他做祭司的事告诉了他们。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:10; 以赛亚书 30:1; 列王纪上 22:5"> 他们说：“请你求问上帝，看看我们是否一路顺利。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 22:6; 列王纪上 22:15; 诗篇 33:18"> 祭司说：“你们安心去吧，耶和华会一路眷顾你们。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:47; 士师记 18:27–28; 撒母耳记上 3:13"> 五人启程来到拉亿，发现当地人像西顿人一样无忧无虑，生活安宁，毫无防范，繁荣富足。他们离西顿很远，与外界没有来往。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 18:11; 士师记 18:2; 士师记 13:2"> 五人回到琐拉和以实陶后，族人问他们：“你们有什么发现吗？”</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 2:23–24; 民数记 13:30; 约书亚记 18:3"> 他们回答说：“我们前去攻取那地方吧！我们已经打探清楚了，那地方非常好。你们还等什么？要赶快去占领那地方。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 18:27; 士师记 18:7; 申命记 2:29"> 你们到了那里，会看见当地的居民毫无防范，那里地大物博，一无所缺。上帝已经把那地方赐给我们了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士师记 18:16"> 但支派便从琐拉和以实陶派出六百个带兵器的人。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:25; 约书亚记 15:60; 历代志下 1:4"> 他们来到犹大的基列·耶琳的西边安营。因此，那地方至今仍叫玛哈尼·但<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛哈尼·但”意思是“但的军营”。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 24:30; 士师记 19:1; 士师记 18:2–3"> 然后，他们去以法莲山区，来到米迦的家。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 17:5; 士师记 18:3–4; 撒母耳记上 14:28"> 侦察过拉亿的五个人对其余的人说：“你们知道吗？这家有以弗得、一些家庭神像、一个雕刻的偶像和一个金属铸像。想一想我们该怎么办。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 43:27; 撒母耳记上 17:22; 约翰福音 14:27"> 那五个人就进入米迦的家里，到年轻的利未人房间向他问安，</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 18:11"> 随行的六百人带着兵器留在门口。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 18:14; 士师记 17:4–5; 士师记 18:2"> 当时祭司也和那六百个带兵器的人站在门口。那五个人进去拿走了雕刻的偶像、以弗得、家庭神像及金属铸像。</span>
<span className="v" id="v18" data-v="18"> 祭司见那五人进入米迦家拿走雕刻的偶像、以弗得、家庭神像及金属铸像，就问他们：“你们在做什么？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约伯记 29:9; 约伯记 21:5; 士师记 17:10"> 他们说：“安静，别作声，跟我们来，做我们的师父和祭司吧。做以色列一个支派、一个宗族的祭司难道不比做一家人的祭司更好吗？”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 56:11; 以西结书 13:19; 箴言 30:15"> 祭司听了非常高兴，就带着以弗得、家庭神像及雕刻的偶像跟随了他们。</span>
<span className="v" id="v21" data-v="21"> 他们转身离去，儿女、牲畜和财物在队伍前面。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 他们离开米迦的家一段路后，米迦召集邻居赶了上来，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 114:5; 撒母耳记下 14:5; 撒母耳记上 11:5"> 向他们大喊。但支派的人转身问米迦：“你们召集这么多人来做什么？”</span>
<span className="v" id="v24" data-v="24" data-xref="哈巴谷书 2:18–19; 以赛亚书 44:18–20; 诗篇 115:8"> 米迦说：“你们带走了我的神像和祭司，把我洗劫一空，还问我想做什么！”</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 27:2; 约伯记 3:5; 撒母耳记上 30:6"> 但支派的人说：“别再多说了，不然我们当中性情暴躁的人会攻击你们，使你全家丧命。”</span>
<span className="v" id="v26" data-v="26"> 但支派的人继续赶路。米迦见对方人多势众，就回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:47; 士师记 18:7; 士师记 18:10"> 但支派的人带着米迦的神像和他的祭司来到拉亿，那里的人生活安宁，毫无防范。他们用刀杀掉当地的居民，放火烧了城。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 10:6; 士师记 18:7; 民数记 13:21"> 拉亿离西顿很远，当地的居民与外界没有来往，以致孤立无援。这城位于伯·利合附近的山谷中，但支派的人重建该城，住在那里。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:47; 创世记 14:14; 列王纪上 15:20"> 这座城原来叫拉亿，他们用祖先以色列的儿子但的名字为该城重新命名。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 4:10–11; 士师记 13:1; 士师记 17:5"> 但支派的人把神像竖立起来，又指派摩西的孙子、革舜的儿子约拿单及其子孙做但支派的祭司，直到该地遭受掳掠为止。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 18:1; 撒母耳记上 1:3; 士师记 19:18"> 上帝的会幕设立在示罗期间，米迦的神像一直竖立在但。</span>
</div>
</div>

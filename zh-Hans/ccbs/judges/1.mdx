## 犹大支派攻打迦南人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:18; 民数记 27:21; 士师记 20:28"> 约书亚去世以后，以色列人求问耶和华：“我们哪一个支派先上去攻打迦南人呢？”</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 5:5; 希伯来书 7:14; 民数记 2:3"> 耶和华说：“犹大支派先去，我已把那片土地交在他们手中了。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:11; 约书亚记 19:1; 士师记 1:17"> 犹大人对同胞西缅人说：“请跟我们一同到我们分得的地方攻打迦南人，我们也会同样帮助你们。”于是，西缅人便与犹大人同去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 11:8; 出埃及记 23:28–29; 约书亚记 11:6–8"> 犹大人上去攻打迦南人和比利洗人，耶和华使他们得胜，在比色杀了一万敌军。</span>
<span className="v" id="v5" data-v="5"> 他们又在那里遇见亚多尼·比色，与他交战，打败了他带领的迦南人和比利洗人。</span>
<span className="v" id="v6" data-v="6"> 亚多尼·比色逃跑，他们追上去擒住他，砍掉他的大拇指和大脚趾。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 15:33; 启示录 13:10; 路加福音 6:37–38"> 亚多尼·比色说：“从前七十个王被我砍掉大拇指和大脚趾，在我桌下捡食物碎屑，现在上帝照我的行为报应我了。”他们把他带到耶路撒冷，他就死在那里。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:63; 士师记 1:21"> 犹大人攻陷耶路撒冷，用刀杀了城内的所有居民，并放火焚城。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:13–20; 约书亚记 11:21; 约书亚记 10:36"> 随后，他们下去攻打住在山区、南地和丘陵的迦南人，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 14:15; 耶利米书 9:23"> 又进攻住在希伯仑的迦南人，杀了示筛、亚希幔和挞买。希伯仑从前叫基列·亚巴。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:15; 约书亚记 10:38–39"> 他们从那里出兵攻打底璧，底璧从前叫基列·西弗。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:16–17; 撒母耳记上 17:25; 撒母耳记上 18:23"> 迦勒说：“谁攻取基列·西弗，我就把女儿押撒嫁给他。”</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 3:9"> 迦勒的弟弟基纳斯的儿子俄陀聂攻取了那城，迦勒便把女儿押撒嫁给他。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:18–19"> 押撒出嫁的时候，劝丈夫向她父亲要一块田。她刚下驴，迦勒便问她：“你想要什么？”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:18; 哥林多后书 9:5; 彼得前书 3:9"> 她回答说：“求你赐福给我，你既然把南地赐给我，求你也把水泉给我吧。”迦勒就把上泉和下泉都给了她。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 10:29–32; 士师记 4:11; 撒母耳记上 15:6"> 摩西岳父的后代基尼人和犹大人一同离开棕树城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“棕树城”即“耶利哥”。">a</a></sup>，到犹大南部旷野的亚拉得附近，跟当地人一起居住。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 21:3; 士师记 1:3; 约书亚记 19:4"> 之后，犹大人随同胞西缅人一起攻打洗法城内的迦南人，彻底毁灭了那城。因此那城叫何珥玛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“何珥玛”意思是“覆灭之城”。">b</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:22; 士师记 3:3; 约书亚记 15:45–47"> 犹大人又夺取了迦萨、亚实基伦和以革伦三座城邑及周围地区。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 41:10; 士师记 1:2; 诗篇 60:12"> 耶和华与犹大人同在。他们攻占了山区，却没能赶走平原的居民，因为那里的人有铁战车。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 1:10; 约书亚记 15:13–14; 民数记 14:24"> 照摩西的吩咐，迦勒得到了希伯仑。他把亚衲三族的人从那里赶走。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 15:63; 士师记 19:10–12; 士师记 1:8"> 便雅悯人没有赶走居住在耶路撒冷的耶布斯人，耶布斯人至今仍和他们住在一起。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 1:19; 列王纪下 18:7; 民数记 1:32"> 约瑟家族也上去攻打伯特利，耶和华与他们同在。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 28:19; 创世记 35:6; 创世记 48:3"> 他们先派人去打探伯特利，那里从前名叫路斯。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 2:12–14; 撒母耳记上 30:15"> 探子看见一个人从城里出来，就对他说：“请你告诉我们进城的路，我们必善待你。”</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:22–25"> 那人便告诉他们进城的路，他们用刀杀了城内所有的居民，只放走了那人及其全家。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 7:6; 历代志下 1:17"> 后来，那人搬到赫人的地方，筑了一座城，称之为路斯，沿用至今。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 17:11–13; 耶利米书 48:10; 诗篇 106:34–35"> 玛拿西人没有赶走伯·善、他纳、多珥、以伯莲和米吉多众城邑及其周围村庄的居民，因为这些迦南人执意住在那里。</span>
<span className="v" id="v28" data-v="28"> 以色列人强盛时，就强迫他们服劳役，却没有全部赶走他们。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 16:10; 列王纪上 9:16"> 以法莲人没有赶走住在基色的迦南人，这些迦南人仍然住在他们当中。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:15"> 西布伦人没有赶走基伦和拿哈拉的居民，这些迦南人仍然住在他们当中，为他们服劳役。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:24–30"> 亚设人没有赶走亚柯、西顿、亚黑拉、亚革悉、黑巴、亚弗革和利合的居民。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:34–35"> 亚设人因为没有赶出当地的迦南人，就住在他们当中。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:32–38; 士师记 1:30; 诗篇 18:24"> 拿弗他利人没有赶走伯·示麦和伯·亚纳的居民，于是就住在这些迦南人当中，强迫他们服劳役。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 19:47; 士师记 18:1"> 亚摩利人强迫但人住在山区，不准他们下到平原。</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 19:42; 士师记 12:12; 约书亚记 10:12"> 亚摩利人执意住在希烈山、亚雅仑和沙宾，但约瑟家族强盛时，就强迫他们服劳役。</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 34:4; 约书亚记 15:2–3"> 亚摩利人的边界从亚克拉滨山坡起，一直到西拉以北。</span>

## 参孙娶非利士女子为妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:10; 约书亚记 19:43; 约翰一书 2:16"> 参孙下到亭拿，在那里看中了一个非利士女子。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 34:4; 创世记 21:21; 创世记 24:2–3"> 他回到家里便对父母说：“我在亭拿看中一个非利士女子，把她给我娶来做妻子吧！”</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 15:18; 撒母耳记上 17:36; 撒母耳记上 14:6"> 他父母说：“难道我们的亲族和同胞中没有合适的女子吗？你为什么要娶未受割礼的非利士人的女子呢？”参孙却说：“我很喜欢她，请给我把她娶过来吧！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 11:20; 诗篇 115:3; 士师记 13:1"> 他的父母不知道这事是出于耶和华的旨意，祂要找机会对付非利士人。那时，非利士人统治着以色列。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 参孙跟父母一起去亭拿，走到亭拿的葡萄园时，有一头猛狮吼叫着扑向他。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 3:10; 士师记 13:25; 撒母耳记上 11:6"> 耶和华的灵突然降在参孙身上，他虽然手无寸铁，竟撕裂了那头狮子，就像撕裂一只山羊羔一样。他没有把这事告诉父母。</span>
<span className="v" id="v7" data-v="7"> 到了亭拿，参孙跟那女子交谈，很喜欢她。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 1:20; 创世记 29:21"> 过了些日子，参孙下去迎娶她，途中他顺便去看那只死狮子，见死狮子体内有一群蜜蜂和一些蜂蜜，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 14:25–30; 箴言 25:15"> 就用手取了一些蜜，边走边吃。到了父母那里，他给了他们一些，他们也吃了。但他没有告诉父母蜂蜜是从死狮子体内取的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="创世记 29:22; 启示录 19:9; 以斯帖记 1:7–22"> 参孙的父亲去那女子家，参孙按习俗摆设宴席。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 9:15; 撒母耳记上 16:6; 撒母耳记上 10:23"> 众人看见参孙，就安排了三十个人陪他。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 10:1; 以西结书 17:2; 创世记 45:22"> 参孙对他们说：“我出一个谜语，如果你们可以在这七天的婚宴期间猜出来，我就送你们三十件细麻衣和三十件外袍。</span>
<span className="v" id="v13" data-v="13"> 如果猜不中，你们就要给我三十件细麻衣和三十件外袍。”他们说：“请你出谜语吧！”</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:2–4; 列王纪上 17:6; 罗马书 8:37"> 参孙说：<br /><span className="pl pl-1">“食物出自食者，</span><br /><span className="pl pl-1">甜物出自强者。”</span><br />三天过后，他们仍然猜不出来。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="士师记 16:5; 士师记 15:6; 箴言 6:26"> 到了第四天，他们对参孙的妻子说：“你要哄你的丈夫把谜底说出来，不然我们就把你和你父亲一家全烧死。你们邀请我们来，难道是要夺取我们的家产吗？”</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 16:15; 创世记 2:24"> 于是，参孙的妻子向他哭诉说：“你是恨我，不是爱我。你给我的族人出了谜语，却没有告诉我谜底。”参孙回答说：“我连父母都没有告诉，又怎能告诉你呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 16:16; 约伯记 2:9; 士师记 16:13"> 在七天的婚宴期间，她一直在丈夫跟前哭哭啼啼。到了第七天，参孙经不住妻子的催逼就把谜底告诉了她。她把谜底告诉了她的族人。</span>
<span className="v" id="v18" data-v="18"> 在第七天日落之前，城里的人对参孙说：<br /><span className="pl pl-1">“有什么比蜂蜜更甜？</span><br /><span className="pl pl-1">有什么比狮子更强？”</span><br />参孙说：<br /><span className="pl pl-1">“你们若不是利用我的小母牛耕田，</span><br /><span className="pl pl-1">肯定猜不出来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 11:6; 士师记 3:10; 士师记 13:25"> 耶和华的灵突然降在参孙身上，他便去亚实基伦杀了三十个人，取走他们的衣服，交给猜中谜语的那些人，然后怒气冲冲地回父亲家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 15:2; 约翰福音 3:29; 诗篇 55:12–13"> 参孙的妻子后来归了他的伴郎。</span>
</div>
</div>

## 士师底波拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 5:3; 士师记 3:12; 士师记 3:7"> 以笏死后，以色列人又做耶和华视为恶的事。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 11:1; 士师记 4:16; 士师记 4:13"> 耶和华把他们交在统治夏琐的迦南王耶宾手中。耶宾王的将军叫西西拉，住在夏罗设。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:19; 诗篇 106:42; 士师记 3:9"> 耶宾王拥有九百辆铁战车，他残暴地压迫以色列人二十年。以色列人向耶和华呼求。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 15:20; 路加福音 2:36; 列王纪下 22:14"> 当时做以色列士师的是女先知底波拉，她是拉比多的妻子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:19; 耶利米书 31:15; 出埃及记 18:26"> 经常坐在以法莲山区拉玛和伯特利之间的底波拉棕树下，审理以色列人的纠纷。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 13:47; 士师记 8:18; 希伯来书 11:32"> 她派人去拿弗他利的基低斯召来亚比挪庵的儿子巴拉，对他说：“以色列的上帝耶和华命你率领一万拿弗他利人和西布伦人上他泊山。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 18:40; 以西结书 38:10–16; 诗篇 83:9–10"> 祂必使耶宾的将军西西拉率领全军和战车到基顺河与你交战，祂必把西西拉交在你手中。”</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:10–14; 马太福音 14:30–31"> 巴拉回答说：“你跟我去，我就去；你不跟我去，我就不去。”</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 2:14; 撒母耳记上 2:30; 士师记 4:17–22"> 底波拉说：“好，我一定与你同去。不过，你这次出征一定得不到荣耀，因为耶和华要把西西拉交在一名妇人手上。”于是，底波拉起身与巴拉一同前往基低斯。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 5:18; 士师记 5:15; 士师记 4:14"> 巴拉招聚了一万名拿弗他利人和西布伦人，底波拉与他一起出征。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 1:16; 约书亚记 19:33; 民数记 10:29"> 摩西的岳父何巴的后人基尼人希百离开自己的族人，在基低斯附近撒拿音的橡树旁搭帐篷居住。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 89:12; 耶利米书 46:18; 约书亚记 19:12"> 西西拉得知亚比挪庵的儿子巴拉已经上了他泊山，</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 4:2–3; 士师记 4:7"> 便召集全军和九百辆铁战车离开夏罗设，向基顺河进军。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 9:3; 撒母耳记下 5:24; 以赛亚书 52:12"> 底波拉对巴拉说：“出击吧！今天耶和华要把西西拉交在你手中。看啊，耶和华已经率先出战了！”于是，巴拉率领一万人下了他泊山，</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:10; 诗篇 83:9–10; 士师记 5:20–21"> 进攻西西拉。耶和华使西西拉的战车和军队溃乱，败在巴拉刀下。西西拉弃车徒步逃跑，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 2:12; 利未记 26:7–8; 雅各书 2:13"> 巴拉追击他的战车和军队，直到夏罗设。西西拉全军都死于刀下，无一逃脱。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:22; 以赛亚书 57:21; 阿摩司书 5:19–20"> 只有西西拉一人徒步逃到基尼人希百的妻子雅亿的帐篷，因为夏琐王耶宾和希百家向来友好。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:19"> 雅亿出来迎接西西拉，对他说：“我主，请进，不用怕！”西西拉便走进帐篷，雅亿为他盖上毯子。</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 5:25–26; 创世记 24:43; 以赛亚书 41:17"> 西西拉说：“我口渴，请给我一点水吧。”雅亿打开皮袋给他奶喝，然后又给他盖上毯子。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 2:3–5; 撒母耳记下 17:20"> 西西拉又说：“请你守着门口，倘若有人查问，你就说没人来过这里。”</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 5:26–27; 哥林多前书 1:27; 士师记 3:21"> 西西拉因疲劳过度，沉沉入睡。雅亿乘机拿起锤子和一根帐篷的橛子，悄悄地走到他身旁，把橛子钉进他的太阳穴，直插到地里。西西拉就这样死了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 17:10–15; 撒母耳记下 17:3"> 巴拉追来了，雅亿出来迎接他，对他说：“你找的人在这里，进来看看吧。”巴拉和她进了帐篷，见西西拉死在那里，太阳穴上还插着橛子。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 9:24; 诗篇 18:47; 诗篇 18:39"> 那天，上帝使以色列人战胜了迦南王耶宾。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 3:12"> 以色列人越战越勇，最终消灭了迦南王耶宾。</span>

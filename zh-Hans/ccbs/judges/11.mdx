## 士师耶弗他

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:32; 士师记 6:12; 列王纪下 5:1"> 基列人耶弗他是个英勇的战士，他父亲名叫基列，母亲是个妓女。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:10; 箴言 2:16; 申命记 23:2"> 基列的妻子还生了几个儿子，他们长大后，便把耶弗他赶出家门，说：“你是别的女人生的，你休想继承我们父亲的任何产业。”</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 9:4; 撒母耳记上 22:2; 撒母耳记下 10:8"> 耶弗他只好逃走，住在陀伯地区。有一群匪徒聚集到他身边，跟随了他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 10:9"> 后来，亚扪人攻打以色列，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:22–23; 使徒行传 7:35–39; 哥林多前书 1:27–29"> 基列的众长老就去陀伯请耶弗他，</span>
<span className="v" id="v6" data-v="6"> 对他说：“请你回来做统帅带领我们对抗亚扪人。”</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 3:9; 创世记 45:4–5; 以赛亚书 60:14"> 耶弗他说：“从前你们不是厌恶我，把我从父亲家赶走的吗？现在你们遭难，为什么来找我？”</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 10:18; 列王纪上 13:6; 出埃及记 10:17"> 基列的众长老说：“我们现在是来请你跟我们一起回去抵抗亚扪人，你可以做所有基列人的首领。”</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 32:20–29"> 耶弗他说：“如果你们请我回去与亚扪人作战，耶和华让我打败他们，我就真的可以做你们的首领吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 42:5; 创世记 31:50; 耶利米书 29:23"> 基列的首领们说：“我们必听从你的吩咐，有耶和华为我们作证。”</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 10:17; 撒母耳记上 10:17; 士师记 20:1"> 于是，耶弗他便跟他们一起回去。民众拥立他做他们的首领和元帅。耶弗他在米斯巴将之前所说的话在耶和华面前重申一遍。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 2:26; 马太福音 18:15–16; 箴言 25:8–9"> 然后，他派遣使者去问亚扪王：“你与我有什么相干？为什么要攻打我的领土？”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 32:22; 民数记 21:24–26; 申命记 2:37"> 亚扪王对他的使者说：“因为以色列人从埃及出来的时候占据了我们的土地，从亚嫩河到雅博河，一直到约旦河。现在你们要和平地归还我们。”</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:11; 罗马书 12:18; 希伯来书 12:14"> 耶弗他再差遣使者去见亚扪王，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 2:19; 申命记 2:9; 民数记 21:27–30"> 对他说：“以色列人并没有占据摩押和亚扪的土地。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 14:25; 申命记 1:40; 民数记 20:1"> 当年以色列人离开埃及，经旷野渡过红海来到加低斯，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 20:14–21; 申命记 2:4–9; 民数记 20:1"> 然后派遣使者去见以东王，说，‘求你让我们经过你的领土。’以东王却不答应。他们又派遣使者去见摩押王，摩押王也不答应。于是，以色列人就住在加低斯。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 2:1–8; 民数记 22:36; 民数记 21:4–13"> 后来，他们走过旷野，绕过以东和摩押，到了摩押的东边，在摩押的边界亚嫩河东岸扎营，并没有进入摩押境内。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 21:21–35; 申命记 2:26–36; 申命记 3:1–17"> 以色列人派遣使者去见希实本的亚摩利王西宏，对他说，‘求让我们经过你的领土前往我们自己的土地。’</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 13:15–32; 民数记 21:23–25; 诗篇 136:17–21"> 但西宏不信任以色列人，拒绝了他们的请求，并招聚全军驻扎在雅杂，攻打他们。</span>
<span className="v" id="v21" data-v="21"> 但以色列的上帝耶和华帮助以色列人战胜西宏和他的军队，占领了亚摩利人所有的土地，</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 2:36"> 从亚嫩河直到雅博河，从旷野直到约旦河。</span>
<span className="v" id="v23" data-v="23"> 既然是以色列的上帝耶和华为祂的以色列子民赶走了亚摩利人，你凭什么要夺取这块土地？</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 21:29; 诗篇 78:55; 弥迦书 4:5"> 你拥有你们的神明基抹给你们的土地，我们也要拥有我们的上帝耶和华赐给我们的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 6:5; 约书亚记 24:9–10; 申命记 23:3–4"> 难道你比摩押王西拨的儿子巴勒更强吗？他从未挑战过以色列人，也未和以色列人交过战。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 2:36; 约书亚记 12:5; 士师记 10:8"> 三百年来，以色列人一直住在希实本及其周围的乡村、亚罗珥及其周围的乡村和亚嫩河沿岸一带的城邑。在这期间，你们为什么不收回这些土地呢？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 24:15; 创世记 16:5; 撒母耳记上 24:12"> 我们没有得罪你们，你们却攻打我们。愿审判者耶和华今天在以色列人和亚扪人之间主持公道。”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 14:11; 箴言 16:18"> 可是，亚扪王不理会耶弗他派使者所传的话。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 11:25; 士师记 3:10; 士师记 13:25"> 那时，耶和华的灵降在耶弗他身上，他便经过基列和玛拿西，来到基列的米斯巴，然后从那里去迎战亚扪人。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 28:20; 撒母耳记上 1:11; 传道书 5:1–2"> 他向耶和华许愿说：“如果你把亚扪人交在我手中，</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 66:13–14; 利未记 27:28–29; 撒母耳记上 1:28"> 让我平安归来，第一个从我家门出来迎接我的人必归给你，我必把他献给你作燔祭。”</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 1:4; 士师记 2:18; 士师记 3:10"> 于是，耶弗他率军与亚扪人作战，耶和华把敌人交在他手中，</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 27:17; 申命记 2:36"> 他大败敌军，摧毁了从亚罗珥到米匿、远至亚备勒·基拉明的二十座城。这样，以色列人征服了亚扪人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米书 31:4; 出埃及记 15:20; 士师记 10:17"> 耶弗他返回自己在米斯巴的家，他的独生女儿敲着鼓、跳着舞出来迎接他。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 14:7–9; 创世记 37:29–30; 创世记 42:36–38"> 他一见自己的女儿，便撕裂衣服，说：“唉，我的女儿啊，你真让我伤心欲绝，祸患临头！我向耶和华许了愿，不能收回了！”</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:19; 腓立比书 2:30; 罗马书 16:4"> 他女儿说：“父亲啊，你既然向耶和华许了愿，就照你许的愿对待我吧！因为耶和华帮你打败了敌军亚扪人，为你报了仇。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 1:25; 撒母耳记上 1:6"> 但求你先给我两个月的时间，让我和同伴到山上去为我终身未嫁哀哭。”</span>
<span className="v" id="v38" data-v="38"> 耶弗他答应了，给了她两个月的时间。于是，她便和同伴到山上为自己终身未嫁哀哭。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 66:3; 士师记 11:31; 利未记 27:28–29"> 两个月后，她回到父亲那里。她父亲履行了自己所许的愿。她从未与男人同房。自此以后，在以色列有个习俗：</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 9:25; 士师记 5:11"> 每年以色列的女子都去为基列人耶弗他的女儿哀哭四天。</span>
</div>
</div>

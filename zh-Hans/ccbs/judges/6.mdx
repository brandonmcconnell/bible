## 士师基甸

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 9:26–29; 士师记 2:19–20; 士师记 2:13–14"> 后来，以色列人又做耶和华视为恶的事，耶和华就把他们交在米甸人手下七年。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:38; 撒母耳记上 13:6; 申命记 28:47–48"> 米甸人势力强盛，以色列人只好躲进山里，藏在洞穴和营寨中。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 6:33; 士师记 3:13; 士师记 7:12"> 每当他们撒种的时候，米甸人、亚玛力人及东方人就前来进犯，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:16; 申命记 28:51; 弥迦书 6:15"> 在他们境内安营，摧毁他们远至迦萨一带的庄稼，不给他们留下任何粮食，也不留下一只羊、一头牛或驴。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 7:12; 士师记 8:10; 耶利米书 46:23"> 入侵者带着牲畜和帐篷像蝗虫一样涌来，人和骆驼不计其数，摧毁了整个地区。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 3:9; 耶利米书 5:17; 诗篇 50:15"> 以色列人因米甸人的入侵而极其贫乏，就呼求耶和华。</span>
<span className="v" id="v7" data-v="7"> 当以色列人因米甸人的入侵而呼求耶和华的时候，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 20:5–32; 以赛亚书 63:9–14; 诗篇 136:10–16"> 耶和华就差遣先知对他们说：“以色列的上帝耶和华说，‘我曾把你们从受奴役之地埃及领出来，</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 44:2–3"> 将你们从埃及人及一切欺压者的手中拯救出来，从你们面前赶走他们，把他们的土地赐给你们。’</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 10:2; 列王纪下 17:35–39; 耶利米书 9:13"> 我曾对你们说，‘我是你们的上帝耶和华。你们虽然住在亚摩利人的地方，但不可祭拜他们的神明。’你们却充耳不闻。”</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 17:2; 希伯来书 11:32; 士师记 13:3"> 一天，耶和华的天使来到俄弗拉，坐在亚比以谢族人约阿施的橡树下。约阿施的儿子基甸因为要躲避米甸人，正躲在榨酒池里打麦子。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 路加福音 1:28; 士师记 2:18"> 耶和华的天使向基甸显现，对他说：“英勇的战士啊，耶和华与你同在。”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 77:7–9; 历代志下 15:2; 以赛亚书 59:1–2"> 基甸说：“我主啊，如果耶和华与我们同在，我们怎会有这些遭遇？我们的祖先说耶和华曾带他们出埃及，但如今祂那些奇妙的作为在哪里呢？现在祂已经丢弃我们，把我们交在米甸人手里。”</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 1:5–9; 希伯来书 11:34; 撒母耳记上 12:11"> 耶和华转向他，说：“你尽自己的力量去从米甸人手中拯救以色列人吧，我现在派你去。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 9:21; 出埃及记 3:11; 出埃及记 4:10"> 基甸说：“主啊，我出身于玛拿西支派最弱小的家族，在家里最微不足道，我怎能拯救以色列人呢？”</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 1:5; 出埃及记 3:12; 使徒行传 11:21"> 耶和华说：“我必与你同在，你必如击打一人一样击打米甸人。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 86:17; 出埃及记 33:13; 以赛亚书 7:11"> 基甸说：“如果我在你面前蒙恩，求你给我一个凭据，使我知道与我说话的真是你耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 13:15; 创世记 18:3; 创世记 18:5"> 请你在这里等一等，让我回去拿礼物献给你。”耶和华说：“我必等你回来。”</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 18:6–8; 士师记 13:15–19; 利未记 2:4"> 基甸回家预备了一只山羊羔，用十公斤面粉做了无酵饼，把肉放进篮子，把汤盛在壶中，然后拿到橡树下献上。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 13:19; 列王纪上 18:33–34"> 上帝的天使对基甸说：“把肉和无酵饼放在这磐石上，把汤倒在上面。”他一一照做。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 9:24; 列王纪上 18:38; 历代志下 7:1"> 耶和华的天使伸出手中的杖碰了一下饼和肉，火就从磐石中喷出来烧尽了它们。耶和华的天使也不见了。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 出埃及记 33:20; 申命记 5:26"> 基甸发现他果然是耶和华的天使，便说：“唉！主耶和华啊，不好了，我面对面见了你的天使。”</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 10:19; 约翰福音 20:26; 创世记 43:23"> 耶和华对他说：“放心吧，不要害怕，你不会死。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 22:14; 出埃及记 17:15; 士师记 8:32"> 基甸在那里为耶和华筑了一座坛，称之为“耶和华赐平安”。这坛如今仍在亚比以谢族的俄弗拉。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:13; 士师记 3:7; 使徒行传 5:29"> 那天晚上，耶和华吩咐基甸：“牵来你父亲的第二头牛，就是那头七岁的公牛，拆毁你父亲为巴力筑的祭坛，砍倒坛旁的亚舍拉神像。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 14:40; 撒母耳记下 24:18; 哥林多前书 14:33"> 然后，在这座山顶上把石头堆放整齐，为你的上帝耶和华筑一座祭坛，用砍倒的亚舍拉神像作柴，把那头公牛献作燔祭。”</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 2:4; 约翰福音 2:5; 申命记 4:1"> 于是，基甸带了十个仆人遵命而行。不过，他因为害怕家人和城中的人，不敢在白天行动，便在夜间行动。</span>
<span className="v" id="v28" data-v="28"> 清早，城里的人起来后，发现巴力的祭坛已经被人拆毁，坛旁的亚舍拉神像被砍倒，第二头公牛被献在新建的祭坛上。</span>
<span className="v" id="v29" data-v="29"> 他们彼此议论说：“这是谁干的？”他们仔细调查后得知是约阿施的儿子基甸所为，</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:9; 腓立比书 3:6; 耶利米书 50:38"> 便对约阿施说：“把你儿子交出来！他拆毁了巴力的祭坛，砍倒了坛旁的亚舍拉神像，我们要处死他！”</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 10:11; 哥林多前书 8:4; 以弗所书 5:11"> 约阿施对气势汹汹的人群说：“你们这样做是要为巴力辩护吗？是要救它吗？谁为巴力辩护，今天早晨就处死谁。有人拆毁巴力的祭坛，如果它是神明，就让它为自己辩护吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:11; 士师记 7:1; 撒母耳记下 11:21"> 因此，那天他们称基甸为耶路·巴力，意思是“让巴力为自己辩护”，因为他拆毁了巴力的祭坛。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 17:16; 士师记 6:3; 罗马书 8:35–39"> 那时，米甸人、亚玛力人及东方人会合在一起，过了约旦河，在耶斯列的平原安营。</span>
<span className="v" id="v34" data-v="34" data-xref="士师记 3:27; 历代志下 24:20; 士师记 3:10"> 耶和华的灵降在基甸身上，他就吹响号角，号召亚比以谢族的人跟从他。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 30:6–12; 士师记 4:6"> 他派人走遍玛拿西、亚设、西布伦和拿弗他利各支派召集军队，人们纷纷前来会合。</span>
<span className="v" id="v36" data-v="36" data-xref="士师记 6:14; 马太福音 16:1; 士师记 6:17–20"> 基甸对上帝说：“若如你所言，你要用我去拯救以色列人，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿书 14:5; 马太福音 10:5–6; 马太福音 15:24"> 求你给个凭据。我把一团羊毛放在麦场上，若明天早晨只是羊毛上有露水，地面却是干的，我就知道，如你所言，你要用我去拯救以色列人。”</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 35:7"> 果然如此，基甸一早醒来，从羊毛中挤出满满一碗露水。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 18:32; 以赛亚书 50:2; 诗篇 107:33–35"> 基甸又对上帝说：“求你不要发怒，容许我再试一次，这次让羊毛是干的，地面有露水。”</span>
<span className="v" id="v40" data-v="40"> 那天晚上，上帝就照他所求使地面布满露水，唯独羊毛是干的。</span>

## 基甸打败米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:32; 传道书 9:10; 创世记 12:6"> 耶路·巴力，也就是基甸，清早起来，率领众人在哈律泉旁扎营，米甸人的军营在他们北边靠近摩利山的谷中。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命记 8:17; 哥林多前书 1:27–29; 哥林多后书 4:7"> 耶和华对基甸说：“你的人太多了，我不能把米甸人交在你们手中，免得以色列人以为是靠自己的力量救了自己。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:8; 启示录 17:14; 启示录 21:8"> 你要向他们宣布，胆小害怕的人可以离开基列山回家。”结果两万二千人离去，只剩下一万人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 33:16; 撒母耳记上 16:7; 撒母耳记上 14:6"> 但耶和华对基甸说：“人还是太多，你带他们到下面的泉水边，我会在那里为你挑选人员，我说谁跟你去谁就去，我说谁不能去谁就不要去。”</span>
<span className="v" id="v5" data-v="5"> 于是，基甸把他们带到泉水边，耶和华对他说：“把像狗一样用舌头舔水喝的和跪着喝水的分开。”</span>
<span className="v" id="v6" data-v="6"> 那时有三百人捧水舔着喝，其余的都跪着喝。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 14:6; 以赛亚书 41:14–16; 士师记 7:18–22"> 耶和华对基甸说：“我要用这三百舔水喝的人拯救你们，我要把米甸人交在你手中。让其余的人都回家吧。”</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:20; 民数记 10:9; 约书亚记 6:4"> 于是，基甸留下这三百人，把其余人的食物和号角收集起来，让他们回家。米甸人的军营就在他们下面的山谷里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 46:2–3; 士师记 3:28; 使徒行传 18:9–10"> 当晚，耶和华吩咐基甸说：“起来，下去攻打敌营吧！我已把敌人交在你手中了。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:10–14; 士师记 4:8–9"> 你如果害怕，可以和你的仆人普拉一起下到敌营，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 6:10; 士师记 7:13–15; 以赛亚书 35:3–4"> 听听他们说什么，你就有胆量攻打敌营了。”于是，基甸就带着仆人普拉下到敌营旁。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 8:10; 士师记 6:5; 约书亚记 11:4"> 米甸人、亚玛力人及东方人像蝗虫一样布满山谷，他们的骆驼如海边的沙一样不计其数。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 以赛亚书 41:14–15; 士师记 4:9"> 基甸到了那里，听见一个人对同伴说：“我做了个梦，梦见一个大麦饼滚进米甸营中，把一个帐篷撞翻在地。”</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 7:6–7; 约书亚记 2:9; 约书亚记 2:24"> 他的同伴说：“那不是别的，正是以色列人约阿施的儿子基甸的刀，上帝把米甸人和整个军营都交在他手中了。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 10:4–6; 创世记 40:8; 历代志下 20:18–19"> 基甸听了这梦和梦的解释，就俯伏敬拜上帝。他回到以色列人的营中，大声喊道：“起来吧，耶和华已经把米甸军营交在你们手中了。”</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 4:7"> 基甸把三百人分成三队，分给他们号角和藏有火把的瓦瓶，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 11:1; 马太福音 16:24; 希伯来书 13:7"> 对他们说：“你们要看我的行动，当我们走到敌营旁边时，我怎么做，你们也要怎么做。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 20:15–17; 撒母耳记上 17:47"> 我们这队吹响号角时，你们也要在敌营四周吹响号角，高喊，‘为了耶和华！为了基甸！’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="诗篇 2:9; 出埃及记 14:24; 马太福音 25:6"> 午夜初，守卫刚换班，基甸带着一百人来到米甸营旁。他们吹响号角，打破手中的瓦瓶。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 27:13; 哥林多后书 4:7; 哥林多前书 15:52"> 其余的二百人也吹响号角，打破瓦瓶。他们左手举着火把，右手拿着号角，高喊：“为耶和华和基甸而战！”</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:17; 箴言 28:1; 列王纪下 7:6–7"> 他们在敌营周围各守其位，米甸全军边喊边逃。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 4:12; 约书亚记 6:20; 约书亚记 6:4"> 基甸的三百人一起吹响号角时，耶和华使米甸人自相残杀。他们逃往西利拉的伯·哈示他，一直逃到靠近他巴的亚伯·米何拉的边境。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士师记 6:35; 撒母耳记上 14:21–22"> 基甸号召拿弗他利、亚设和玛拿西的以色列人追杀米甸败军，</span>
<span className="v" id="v24" data-v="24" data-xref="士师记 3:27–28; 腓立比书 1:27; 罗马书 15:30"> 又派人到整个以法莲山区，吩咐当地人攻打米甸人，占据远至伯·巴拉一带的约旦河渡口。以法莲人都遵命而行，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 10:26; 士师记 8:3–4; 诗篇 83:11–12"> 还生擒了米甸人的两名首领俄立和西伊伯。他们在俄立磐石上杀死了俄立，在西伊伯榨酒池杀了西伊伯。他们继续追杀米甸人，并带着俄立和西伊伯的人头穿过约旦河，交给基甸。</span>
</div>
</div>

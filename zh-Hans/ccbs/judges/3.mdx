## 迦南余族

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 2:21–22; 申命记 7:22; 箴言 17:3"> 耶和华为了考验那些没有经历过迦南战事的以色列人，让他们学习作战，就留下了以下各族：</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 13:3; 约书亚记 13:5; 士师记 10:7"> 五个非利士王、所有的迦南人、西顿人和住在巴力·黑门山到哈马口一带的黎巴嫩山区的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 3:1; 士师记 2:22; 出埃及记 15:25"> 耶和华留下这几个外族是要考验以色列人，看他们是否愿意遵从祂借摩西向他们祖先颁布的诫命。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:34–38; 创世记 10:15–18; 出埃及记 3:8"> 以色列人住在这些迦南人、赫人、亚摩利人、比利洗人、希未人和耶布斯人当中，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 7:3–4; 出埃及记 34:16; 列王纪上 11:1–5"> 跟他们通婚，祭拜他们的神明。</span>
</div>
</div>

## 士师俄陀聂

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 34:13; 列王纪下 23:6; 列王纪上 18:19"> 以色列人做耶和华视为恶的事，忘记他们的上帝耶和华，祭拜假神巴力和亚舍拉。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 2:14; 哈巴谷书 3:7; 士师记 4:9"> 耶和华向他们发怒，把他们交在美索不达米亚王古珊·利萨田的手中，受古珊·利萨田统治八年。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 3:15; 士师记 1:13; 诗篇 22:5"> 他们向耶和华呼求，耶和华就使一位名叫俄陀聂的拯救者兴起，他是迦勒弟弟基纳斯的儿子。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 13:25; 撒母耳记上 11:6; 士师记 14:19"> 耶和华的灵降在俄陀聂身上，他就做了以色列的士师，领兵出战。耶和华将美索不达米亚王古珊·利萨田交在他手中，他便战胜了古珊·利萨田。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 5:31; 士师记 8:28; 约书亚记 11:23"> 此后，国内安享太平四十年，直到俄陀聂去世。</span>
</div>
</div>

## 士师以笏

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 12:9; 士师记 2:19; 士师记 2:14"> 之后，以色列人又做耶和华视为恶的事，耶和华就使摩押王伊矶伦强盛起来，攻打以色列人。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 1:16; 申命记 34:3; 士师记 5:14"> 伊矶伦联合亚扪人和亚玛力人进攻以色列人，占据了棕树城，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:47–48; 申命记 28:40; 利未记 26:23–25"> 以色列人受摩押王伊矶伦统治十八年。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 3:9; 诗篇 78:34; 以赛亚书 36:16"> 他们呼求耶和华，耶和华就使一位名叫以笏的拯救者兴起。他是便雅悯人基拉的儿子，善用左手。以色列人派他去向摩押王伊矶伦进贡。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 启示录 2:12; 诗篇 149:6"> 他造了一把约半米长的两刃利剑，绑在右腿的衣服里。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:20; 约伯记 15:27; 耶利米书 50:11"> 他带着贡物去见极其肥胖的摩押王伊矶伦。</span>
<span className="v" id="v18" data-v="18"> 以笏献上了贡物之后，便让抬贡物的人先回去。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 4:20; 士师记 3:20; 使徒行传 23:18–19"> 他自己从吉甲附近的石雕神像处折回王宫，对王说：“王啊，我有机密禀告。”王就命左右侍从回避，众人便都退去。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 10:7; 阿摩司书 3:15; 诗篇 29:1"> 当时王独自坐在楼上的房间乘凉，以笏近前说：“我有从上帝而来的讯息要禀告。”王从座位上站起来的时候，</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 13:3; 约伯记 20:25; 撒母耳记上 15:33"> 以笏左手拔出藏在右腿上的剑刺进王的肚腹，</span>
<span className="v" id="v22" data-v="22"> 连剑柄也刺了进去，深深嵌入肥肉。以笏没有拔剑，</span>
<span className="v" id="v23" data-v="23"> 便走出房间，把门都关上，锁好。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 24:3"> 以笏走后，王的仆人过来，见房门紧锁，以为王在大解。</span>
<span className="v" id="v25" data-v="25"> 等了很久，门还没开，他们很焦急，就拿钥匙开门，发现他们的主人已经倒毙在地上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 他们等待的时候，以笏已经逃走了。他经过石雕神像处，逃往西伊拉。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 6:34; 撒母耳记上 13:3; 士师记 5:14"> 到了那里，他就在以法莲的山区吹响号角，召集以色列人。众人跟随以笏下山，</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 12:5; 士师记 7:9; 士师记 7:15"> 以笏对他们说：“跟我来！耶和华已经把仇敌摩押人交在你们手中了。”于是，众人跟着他下去占领了通往摩押的约旦河各渡口，不许任何人渡河。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:15; 士师记 3:17; 诗篇 17:10"> 当时他们杀了约一万名强悍善战的摩押勇士，没有一人逃脱。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 3:11; 士师记 5:31"> 这样，以色列人征服了摩押人，国中安享太平八十年。</span>
</div>
</div>

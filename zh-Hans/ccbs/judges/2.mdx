## 耶和华责备以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 20:2; 创世记 17:7–8; 利未记 26:42"> 耶和华的天使从吉甲来到波金，对以色列人说：“我带你们出埃及，领你们来到我起誓要赐给你们祖先的土地。我说，‘我永不废弃跟你们立的约，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:2–4; 耶利米书 2:36; 以斯拉记 9:1–3"> 你们不可跟这里的居民立约，要毁掉他们的祭坛。’可是你们为什么不听呢？</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 23:13; 民数记 33:55; 申命记 7:16"> 因此，我告诉你们，我必不赶走这里的居民，他们必成为你们肋旁的刺，他们的神明必成为你们的网罗。”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 31:9; 箴言 17:10; 撒迦利亚书 12:10"> 耶和华的天使说完这些话，以色列人放声大哭，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 7:9; 创世记 35:8; 约书亚记 7:26"> 他们称那地方为波金<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“波金”意思是“哭泣”。">a</a></sup>，在那里向耶和华献祭。</span>
</div>
</div>

## 约书亚去世

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 24:28–31; 约书亚记 22:6"> 约书亚遣散以色列人后，他们便各自去攻占所分得的土地。</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:12; 约书亚记 24:31; 历代志下 24:2"> 约书亚在世的时候，以色列人都事奉耶和华。他死后，那些目睹耶和华为以色列人行大事的长老还在世的时候，以色列人仍事奉耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 24:29–30"> 耶和华的仆人、嫩的儿子约书亚去世时一百一十岁。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 19:50; 约书亚记 24:30"> 以色列人把他葬在他自己的土地上，在迦实山以北、以法莲山区的亭拿·希烈。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 2:12; 提多书 1:16; 出埃及记 5:2"> 那一代人都去世后，新一代不认识耶和华，也不知道耶和华为以色列人所行的事。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 4:1; 士师记 6:1; 士师记 3:7"> 以色列人做耶和华视为恶的事，祭拜巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:5; 申命记 13:5; 申命记 6:14–15"> 他们背弃了领他们祖先离开埃及的上帝耶和华，追随、祭拜邻邦的各种神明，因而惹耶和华发怒。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 10:6; 诗篇 106:36; 士师记 3:7"> 他们背弃耶和华，去祭拜巴力和亚斯她录。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 17:20; 诗篇 106:40–42; 申命记 32:30"> 耶和华向他们发怒，使他们受到掠夺者的攻击和四周仇敌的压制，毫无抵抗之力。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:15–68; 约书亚记 23:15–16; 利未记 26:14–46"> 他们每次出战，耶和华都出手与他们为敌，使他们战败，正如祂的誓言。他们苦不堪言。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 13:20; 诗篇 106:43–45; 撒母耳记上 12:11"> 后来，耶和华使士师<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“士师”意思是“首领”。">b</a></sup>兴起，从掠夺者手中拯救他们。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 1:6; 申命记 9:12; 士师记 2:7"> 但他们不听从士师的话，与其他神明苟合，祭拜它们，很快偏离他们祖先的道路，没有像他们的祖先那样遵行耶和华的命令。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 32:36; 约书亚记 1:5; 出埃及记 2:24"> 耶和华见他们因敌人的压迫和苦待而哀号，就怜悯他们，使士师陆续兴起，并与每位士师同在。士师在世之日，耶和华从仇敌手中拯救他们。</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 8:33; 士师记 4:1; 马太福音 23:32"> 士师去世以后，他们又故态复萌，追随、祭拜其他神明，比他们的祖先更败坏。他们执迷不悟，怙恶不悛。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 2:14; 约书亚记 23:16; 出埃及记 32:10–11"> 耶和华向他们发怒，说：“这百姓违背了我跟他们祖先所立的约，不听从我的话。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 23:13; 士师记 2:3; 士师记 3:3"> 因此，我不再逐出约书亚去世时还没有赶走的外族人，</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 8:2; 申命记 8:16; 申命记 13:3"> 我要借此试验以色列人，看他们是否像他们祖先一样谨遵我的道。”</span>
<span className="v" id="v23" data-v="23"> 这就是为什么耶和华留下那些外族人，没有立刻把他们赶走，也没有把他们交在约书亚手中。</span>
</div>

## 利未人和他的妾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 18:1; 士师记 17:8; 玛拉基书 2:15"> 那时候，以色列没有王。有一个利未人住在以法莲山区的偏远地带，他娶了犹大的伯利恒的一个女子为妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 16:28; 申命记 22:21; 利未记 21:9"> 那女子不忠，离开丈夫回到犹大的伯利恒的父亲家，住了四个月。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 34:3; 创世记 50:21; 利未记 19:17"> 后来，她丈夫带着一个仆人和两头驴去见她，用好话劝她回去。那女子带他去见自己的父亲。她父亲看见女婿来了，便热情地接待他，</span>
<span className="v" id="v4" data-v="4"> 留他在家里小住。他便在那里住了三天，一起吃住。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:8; 创世记 18:5; 诗篇 104:15"> 第四天，他清早起来准备回家，岳父对他说：“吃点东西补充体力后再走吧。”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:9; 士师记 16:25; 路得记 3:7"> 于是，二人坐下来一起吃喝。岳父对他说：“再住一夜，高兴高兴吧。”</span>
<span className="v" id="v7" data-v="7"> 他不肯答应，起来要走，但岳父一再挽留，他就又住了一夜。</span>
<span className="v" id="v8" data-v="8"> 第五天清早起来，他准备回家，岳父对他说：“吃点东西补充体力，太阳偏西再走吧。”于是，二人一同吃饭。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各书 4:13–14"> 他带着妾和仆人起来要走的时候，岳父对他说：“看啊，太阳偏西了，天色已晚，再住一夜高兴高兴，明天一早再走吧。”</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:63; 约书亚记 15:8; 士师记 1:8"> 可是，他不愿意再留一夜，就备好两头驴，带着他的妾走了，来到耶布斯附近。耶布斯就是耶路撒冷。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:6; 士师记 1:21; 士师记 19:10"> 他们临近耶布斯时，天快黑了，仆人对主人说：“我们不如就在耶布斯人的城里住宿吧。”</span>
<span className="v" id="v12" data-v="12"> 主人说：“我们不可在非以色列人的外邦城邑住宿，不如赶到基比亚。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:26; 何西阿书 5:8; 以赛亚书 10:29"> 他又说：“我们前往基比亚或拉玛住宿吧。”</span>
<span className="v" id="v14" data-v="14"> 于是，他们继续前行，到便雅悯境内的基比亚时，天已经黑了。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 19:18; 马太福音 25:35; 马太福音 25:43"> 他们决定在那里过夜。因为没有人接待他们，他们只好在城中的广场露宿。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 19:1; 诗篇 104:23; 创世记 3:19"> 那时，有一个老人从田间工作回来，经过那里。他本来是以法莲山区的人，现在住在便雅悯境内的基比亚。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 32:17; 创世记 16:8"> 他看见有人在城中的广场露宿，就问：“你们从哪里来，要到哪里去？”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 18:31; 约翰福音 15:6; 撒母耳记上 1:7"> 利未人回答说：“我们从犹大的伯利恒来，正要回家去。我住在以法莲山区的偏远地带。我现在要去耶和华的殿。这里没有人接待我。</span>
<span className="v" id="v19" data-v="19"> 其实我有粮草喂驴，我和我的妾及仆人也有饼和酒，什么也不缺。”</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 6:23; 雅各书 2:15–16; 希伯来书 13:2"> 那老人说：“欢迎到我家来，我会供应你们的需要，千万不可在街头露宿。”</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:24; 创世记 18:4; 路加福音 7:44"> 于是，那老人带他们回家，喂他们的驴。他们洗完脚后，便一起吃喝。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 19:4–5; 哥林多前书 6:9; 士师记 20:5"> 他们正欢乐的时候，城里的一群无赖前来围住房子，连连叩门，对年长的家主说：“把你家里的客人交出来，我们要跟他交合。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 34:7; 撒母耳记下 13:12; 士师记 20:6"> 老人出去对他们说：“弟兄们啊，不要做这种恶事！这人是我的客人，不要干这种卑鄙的事！</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 19:8; 申命记 21:14; 创世记 34:2"> 我有个女儿，仍是处女，还有这人的妾，我把她们交出来，任你们玩弄，只是不要对这人干这种卑鄙的事。”</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 10:9; 何西阿书 9:9; 何西阿书 7:4–7"> 他们却不肯听。利未人就把自己的妾推出去交给他们。他们强暴她，终夜凌辱她，直到天快亮才放她走。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 19:3; 创世记 18:12; 彼得前书 3:6"> 天亮时她回到丈夫住宿的房子门前，就仆倒在地。</span>
<span className="v" id="v27" data-v="27"> 早晨，她丈夫起来打开房门要上路，发现她倒卧在门前，双手搭在门槛上，</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 20:5; 列王纪上 18:29"> 就对她说：“起来，我们走吧！”她却没有反应。于是，他就把她的尸体放在驴背上启程回家。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 20:6–7; 撒母耳记上 11:7; 罗马书 10:2"> 回到家里，他用刀把尸体切成十二块，派人送往以色列全境。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 20:7; 箴言 13:10; 何西阿书 9:9"> 看见的人都说：“自从以色列人离开埃及以来，这种事从未发生过，也从未见过。我们必须商量一下，看看该怎么办。”</span>

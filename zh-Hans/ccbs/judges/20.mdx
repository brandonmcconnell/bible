## 讨伐基比亚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 11:11; 撒母耳记上 3:20; 撒母耳记上 10:17"> 于是，从但到别示巴以及基列的全体以色列人齐心来到米斯巴，聚集在耶和华面前。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 8:10; 士师记 20:17; 士师记 20:15"> 以色列各支派的首领都参加了这次上帝子民的聚会，当时有四十万持刀的步兵。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> 便雅悯人也听见以色列人聚集在米斯巴的消息。以色列人问那个利未人：“请告诉我们，这件邪恶的事是怎么发生的？”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 19:15–28"> 那利未人，就是被害女子的丈夫说：“我和我的妾到便雅悯的基比亚住宿。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 士师记 19:25–26; 创世记 19:4–8"> 那天晚上，基比亚人攻击我，包围我们住宿的房子，要杀死我。他们把我的妾蹂躏致死。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:29; 约书亚记 7:15; 士师记 19:23"> 我就把她的尸体切成块，送到以色列的各个地区，因为基比亚人做了邪恶、无耻的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:30; 哥林多前书 5:6; 哥林多前书 5:10–12"> 以色列人啊，你们看该怎么处理吧！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="传道书 9:10; 士师记 20:1; 箴言 21:3"> 众人起来异口同声地说：“我们谁也不回帐篷，谁也不回家。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿书 1:7; 尼希米记 11:1; 约书亚记 14:2"> 现在我们要抽签去攻打基比亚。</span>
<span className="v" id="v10" data-v="10"> 我们要从各支派中抽出十分之一的人负责运粮，等军队到达便雅悯的基比亚后，就可以讨伐在以色列做出这种卑鄙之事的基比亚人。”</span>
<span className="v" id="v11" data-v="11"> 于是，以色列人团结一致，一起去攻打那城。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 13:14; 申命记 20:10; 罗马书 12:18"> 以色列各支派差人去对便雅悯各地的人说：“你们中间怎么发生了这种邪恶的事！</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 17:12; 申命记 13:13; 士师记 19:22"> 现在把那些基比亚的无赖交出来，我们要处死他们，从以色列铲除罪恶。”便雅悯人却充耳不闻，</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 20:20; 约伯记 15:25–26; 民数记 21:23"> 还从各城聚集到基比亚，要跟以色列人打仗。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:41; 士师记 20:25; 民数记 1:37"> 便雅悯人从各城召集了两万六千刀兵，还从基比亚召集了七百精兵。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 3:15; 历代志上 12:2; 撒母耳记上 17:49–50"> 军中有七百精兵善用左手甩石，毫发不差。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 1:46; 历代志下 17:14–18; 民数记 26:51"> 其他十一个以色列支派则召集了四十万刀兵，个个善战。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 20:23; 士师记 20:26–27; 民数记 27:21"> 以色列人到伯特利去求问上帝，说：“我们当中哪个支派应当先去攻打便雅悯人呢？”耶和华说：“犹大支派。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:16; 约书亚记 3:1; 约书亚记 6:12"> 第二天清早，以色列人起来在基比亚附近安营，</span>
<span className="v" id="v20" data-v="20"> 朝着便雅悯人摆开阵势，准备攻打他们。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 20:25; 诗篇 73:18–19; 历代志下 28:10"> 便雅悯人从基比亚出来，当天杀了以色列军两万二千人。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 64:5; 士师记 20:17; 撒母耳记上 30:6"> 以色列人重整士气，仍在前一天列阵的地方列阵。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:26–27; 诗篇 78:34–36; 约书亚记 7:6"> 列阵之前，他们在耶和华面前一直哀哭到晚上。他们求问耶和华，说：“我们应该再上去攻打我们的同胞便雅悯人吗？”耶和华说：“要上去攻打他们。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 第二天，以色列人前去攻打便雅悯人。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 20:21; 创世记 18:25; 罗马书 2:5"> 便雅悯人从基比亚出来迎战，又杀了以色列军一万八千刀兵。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 20:23; 约珥书 2:12–18; 士师记 20:18"> 以色列全军来到伯特利，坐在耶和华面前哀哭，那天他们一直禁食到晚上，又在耶和华面前献上燔祭和平安祭。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 18:1; 士师记 20:18; 撒母耳记上 4:3–4"> 那时，上帝的约柜就在那里，亚伦的孙子、以利亚撒的儿子非尼哈任祭司。以色列人求问耶和华，说：“我们应该再去攻打我们的同胞便雅悯人吗？还是退兵？”耶和华说：“去攻打吧，因为明天我必把他们交在你们手中。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 8:4; 撒母耳记下 5:23; 士师记 20:34"> 以色列人在基比亚周围设下伏兵。</span>
<span className="v" id="v30" data-v="30"> 第三天，以色列人又像前两次一样在基比亚列阵，攻打便雅悯人。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 19:13–14; 约书亚记 7:5; 以赛亚书 10:29"> 便雅悯人前来迎战，被以色列人诱到城外。他们又像前两次一样击杀以色列人，大约三十名以色列人死在通往基比亚和伯特利的两条路上。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 8:15–16"> 便雅悯人说：“我们又像以前一样打败他们了。”但以色列人已经商议好，用诈败的方法诱敌离城到大路上来。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 8:18–22"> 以色列全军在巴力·他玛列阵反攻，埋伏在基比亚西面的以色列人也冲了出来。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:14; 以赛亚书 47:11; 约伯记 21:13"> 有一万以色列精兵从正面攻打基比亚，战事非常激烈。便雅悯人大祸临头了仍懵然不知。</span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 20:5; 士师记 20:15; 士师记 20:44–46"> 耶和华帮助以色列人战胜了便雅悯人。那天，以色列人杀了便雅悯两万五千一百刀兵。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 8:15–29"> 便雅悯人这才意识到自己战败了。<br />原来以色列人在便雅悯人面前诈败，因为他们仰仗在基比亚附近设下的伏兵。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 8:19; 约书亚记 6:5; 出埃及记 19:13"> 那些伏兵迅速冲进基比亚，用刀杀了全城的人。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 8:20; 创世记 17:21; 列王纪下 4:16"> 以色列人和伏兵已有约定，伏兵在城内点起一股浓烟时，</span>
<span className="v" id="v39" data-v="39" data-xref="士师记 20:32"> 以色列人便转身杀回。便雅悯人杀了诈败的以色列军大约三十人，以为像以前一样打败了他们。</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 8:20; 启示录 19:3; 创世记 19:28"> 这时基比亚城已浓烟滚滚，便雅悯人回头观望，只见全城浓烟四起。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:12; 路加福音 21:26; 启示录 6:15–17"> 以色列人转身杀了回来，便雅悯人大惊失色，知道大祸临头了。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 8:15; 何西阿书 9:9; 耶利米哀歌 1:3"> 他们从以色列人面前转身逃往旷野，却无法逃脱。以色列人从各城出来夹攻他们。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 8:20–22"> 以色列人围攻便雅悯人，一路追杀他们直到基比亚的东边。</span>
<span className="v" id="v44" data-v="44"> 便雅悯人共死了一万八千名勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 15:32; 士师记 21:13; 撒迦利亚书 14:10"> 余下的人都逃往旷野的临门岩，沿途有五千人被杀。以色列人追杀他们，一直追到基顿，又消灭了他们两千人。</span>
<span className="v" id="v46" data-v="46" data-xref="士师记 20:35; 士师记 20:15"> 那天，便雅悯人共死了两万五千名英勇的刀兵，</span>
<span className="v" id="v47" data-v="47" data-xref="以赛亚书 1:9; 诗篇 103:9–10; 哈巴谷书 3:2"> 只有六百人逃到了临门岩，在那里住了四个月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 13:15–17; 历代志下 25:13; 历代志下 28:6–9"> 以色列人回师便雅悯境内，用刀将各城的男女老少以及牲畜全部杀死，又放火烧毁所有的城邑。</span>
</div>
</div>

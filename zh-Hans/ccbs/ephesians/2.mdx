## 靠恩典、凭信心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 2:13; 以弗所书 2:5–6; 歌罗西书 3:1–4"> 你们从前死在过犯和罪恶之中。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:12; 约翰一书 5:19; 以弗所书 2:3"> 那时，你们随从今世的风俗，顺服在空中掌权的魔鬼，就是如今在一切悖逆上帝之人心中运行的邪灵。</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 3:3; 以弗所书 4:22; 加拉太书 5:16–24"> 我们以前也在他们当中随从本性的欲望，放纵肉体和心中的私欲，与其他人一样生来就是惹上帝发怒的人。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 1:3; 以弗所书 1:7; 诗篇 86:15"> 然而上帝有丰富的怜悯，祂深爱我们，</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 3:24; 以弗所书 2:8; 罗马书 5:10"> 尽管我们死在过犯之中，祂仍然使我们与基督一同活了过来。你们得救是因为上帝的恩典。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:1–3; 以弗所书 1:3; 罗马书 6:4–5"> 在基督耶稣里，上帝使我们与基督一同复活，一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 1:16–17; 提多书 3:4; 以弗所书 2:4"> 好借着祂在基督耶稣里向我们所施的恩慈，向后世显明祂无比丰富的恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:22–26; 以弗所书 2:5; 罗马书 4:16"> 你们得救是靠恩典，凭信心。这不是出于你们自己，而是上帝的礼物；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:9; 罗马书 11:6; 提多书 3:3–5"> 也不是由于你们的行为，以免有人自夸。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:13; 歌罗西书 1:10; 希伯来书 13:21"> 我们是上帝的杰作，是在基督耶稣里创造的，为要完成上帝预先安排给我们的美好工作。</span>
</div>
</div>

## 在基督里合而为一

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 2:11; 歌罗西书 2:13; 歌罗西书 3:11"> 因此，你们要记住，从前按照肉体来说你们是外族人，那些肉体上受过人手所行割礼的以色列人，称你们为“没有受过割礼的”。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 4:8; 歌罗西书 1:21; 耶利米书 31:31–34"> 那时，你们与基督无关，也不是以色列人，在上帝应许的诸约上是局外人，你们活在世上没有盼望，没有上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:39; 歌罗西书 1:20–22; 歌罗西书 1:13–14"> 但你们这些从前远离上帝的人，如今在基督耶稣里，靠着祂所流的血已经被带到上帝面前。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28; 歌罗西书 3:11; 歌罗西书 3:15"> 因为基督耶稣亲自给我们带来了和平，用自己的身体拆毁了以色列人和外族人之间充满敌意的隔墙，使双方合而为一，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 2:14; 加拉太书 3:10; 歌罗西书 1:21–22"> 并废除了以诫命和规条为内容的律法制度。祂这样做是为了在自己里面把双方造成一个新人，成就和平，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:20–22; 罗马书 5:10; 哥林多后书 5:18–21"> 并借着十字架消灭彼此间的敌意，使双方借着一个身体与上帝和好。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 57:19–21; 使徒行传 10:36; 罗马书 5:1"> 祂来传扬这平安的福音给你们这些离上帝很远的外族人，也给我们这些离上帝很近的以色列人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:13; 以弗所书 3:12; 罗马书 5:2"> 我们双方都是靠着祂在同一位圣灵的引导下来到父上帝面前。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:20; 约翰一书 3:1; 加拉太书 6:10"> 因此，你们不再是外人或过客，你们与众圣徒一样是天国的子民，是上帝家里的人了。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:4–5; 以赛亚书 28:16; 彼得前书 2:7–8"> 你们已被建立在众使徒和先知们的根基上，基督耶稣自己是房角石。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 3:16–17; 哥林多前书 3:9; 哥林多后书 6:16"> 整座建筑的各部分都靠祂连接在一起，逐渐成为主的圣殿。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:4–5; 哥林多前书 3:16; 约翰一书 4:16"> 你们也靠着祂被建造在一起，成为上帝借着圣灵居住的地方。</span>
</div>
</div>

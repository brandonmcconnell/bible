## 父慈子孝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:20–25; 箴言 23:22; 箴言 6:20"> 你们做儿女的，要按主的旨意听从父母，这是理所当然的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 20:12; 申命记 27:16; 马太福音 15:4–6"> 因为第一条带着应许的诫命就是：“要孝敬父母，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 5:16; 申命记 4:40; 申命记 12:28"> 使你在世上蒙福、长寿。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记5:16。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:21; 箴言 22:6; 箴言 29:15"> 你们做父亲的，不要激怒儿女，要照主的教导和警戒养育他们。</span>
</div>
</div>

## 主仆之间

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:18–21; 提多书 2:9–10; 歌罗西书 3:17–24"> 你们做奴仆的，要战战兢兢、诚诚实实、怀着敬畏的心服从你们世上的主人，就像服从基督一样。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:22–23; 帖撒罗尼迦前书 2:4; 加拉太书 1:10"> 不要只做讨好人的表面工夫，要像基督的奴仆一样从心里遵行上帝的旨意。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:23; 以弗所书 6:5–6; 哥林多前书 10:31"> 要甘心乐意地工作，像是在事奉主，不是在服侍人。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:24; 路加福音 14:14; 箴言 11:18"> 要知道：不管是奴仆还是自由人，每个人所做的善事都会得到主的奖赏。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:25–1; 使徒行传 10:34; 罗马书 2:11"> 你们做主人的也一样，要善待奴仆，不可威吓他们。要知道你们主仆同有一位在天上的主人，祂不偏待人。</span>
</div>
</div>

## 上帝所赐的军装

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 以赛亚书 40:31; 约书亚记 1:9"> 最后，你们要靠着主和祂的大能大力做刚强的人，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 10:4; 罗马书 13:12; 以弗所书 6:13"> 要穿戴上帝所赐的全副军装，以便能够抵挡魔鬼的阴谋。</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 1:13; 哥林多后书 4:4; 以弗所书 2:2"> 因为我们争战的对象不是这世上的血肉之躯，而是在这黑暗世界执政的、掌权的、管辖的和天上属灵的邪恶势力。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 10:4; 路加福音 21:36; 以弗所书 6:11–17"> 因此，你们要用上帝所赐的全副军装装备自己，好在邪恶的时代抵挡仇敌，到争战结束后仍然昂首挺立。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:17; 帖撒罗尼迦前书 5:8; 以赛亚书 11:5"> 务要站稳，用真理当作带子束腰，以公义当作护心镜遮胸，</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 罗马书 10:15; 哥林多后书 5:18–21"> 把和平的福音当鞋穿在脚上准备行动。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 5:8–9; 约翰一书 5:4–5; 箴言 18:10"> 此外，还要拿起信心的盾牌，好灭尽恶者一切的火箭。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 以赛亚书 59:17; 启示录 19:15"> 要戴上救恩的头盔，紧握圣灵的宝剑——上帝的话。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:17; 歌罗西书 4:2; 腓立比书 4:6"> 要靠着圣灵随时多方祷告和祈求，警醒不怠地为众圣徒祷告。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 4:3; 使徒行传 4:29; 帖撒罗尼迦后书 3:1"> 也请你们为我祷告，求上帝赐我口才，让我勇敢地把福音的奥秘讲解明白。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:20; 歌罗西书 4:4; 提摩太后书 2:9"> 我为传福音成了带锁链的使者。请你们为我祷告，使我能尽忠职守，放胆传福音。</span>
</div>
</div>

## 问候

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 提摩太后书 4:12; 提多书 3:12"> 推基古会把我的近况全部告诉你们，好让你们也了解我的处境。他是主内亲爱的弟兄和忠心的仆人。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:25; 歌罗西书 4:7–8; 帖撒罗尼迦后书 2:17"> 我特意派他去你们那里，好让你们知道我们的近况，并且心受鼓舞。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:16; 加拉太书 5:6; 彼得前书 5:14"> 愿父上帝和主耶稣基督赐给各位弟兄姊妹平安、爱心和信心！</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 22:37; 哥林多后书 8:12; 马太福音 6:13"> 愿所有忠贞地爱我们主耶稣基督的人都蒙恩典！</span>
</div>
</div>

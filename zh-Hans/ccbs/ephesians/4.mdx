## 信徒同属一体

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:10; 腓立比书 1:27; 帖撒罗尼迦前书 2:12"> 所以，我这为主被囚禁的劝你们，既然蒙了上帝的呼召，就要过与所蒙的呼召相称的生活。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:12–13; 哥林多前书 13:7; 哥林多前书 13:4–5"> 凡事要谦卑、温柔、忍耐，用爱心互相宽容，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:10; 歌罗西书 3:13–15; 哥林多前书 12:12–13"> 以和平彼此联结，竭力持守圣灵所赐的合一。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:18; 罗马书 12:4–5; 哥林多前书 12:4–13"> 正如你们蒙召后同有一个盼望、一个身体、一位圣灵、</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 8:6; 哥林多前书 12:13; 彼得前书 3:21"> 一位主、一个信仰、一种洗礼、</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 11:36; 玛拉基书 2:10; 哥林多前书 8:6"> 一位上帝，就是万人之父，祂超越万物，贯穿万物，且在万物之中。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10; 罗马书 12:3; 哥林多前书 12:7–11"> 然而，我们各人都是按照基督所赐之量领受恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 68:18; 歌罗西书 2:15; 撒母耳记上 30:26"> 因此圣经上说：<br /><span className="pl pl-1">“祂升上高天时，</span><br /><span className="pl pl-1">带着许多俘虏，</span><br /><span className="pl pl-1">将恩赐赏给众人。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇68:18。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:13; 马太福音 12:40; 箴言 30:4"> 既然说“升上”，岂不表示祂曾经降到地上吗？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 7:26; 希伯来书 4:14; 以弗所书 1:20–23"> 降下的是祂，升到诸天之上的也是祂，这样祂可以充满万物。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:15; 哥林多前书 12:28–29; 以弗所书 2:20"> 祂赐恩让一些人做使徒，一些人做先知，一些人做传福音的，一些人做牧师和教师，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:11–14; 以弗所书 4:16; 哥林多前书 12:27"> 为要装备圣徒，使他们各尽其职，建立基督的身体，</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:28; 约翰福音 17:21; 以弗所书 4:5"> 直到我们对上帝的儿子有一致的信仰和认识，逐渐成熟，达到基督那样完美的生命。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:9; 罗马书 16:17–18; 哥林多前书 14:20"> 这样，我们就不再像小孩子，被各种异端邪说之风吹得飘来飘去，被人的阴谋诡计欺骗。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 3:18; 以弗所书 4:25; 撒迦利亚书 8:16"> 相反，我们说话要凭爱心坚持真理，在各方面都要追求长进，更像元首基督。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:19; 约翰福音 15:5; 歌罗西书 2:2"> 整个身体靠祂巧妙地结合在一起，筋骨相连，各部位各尽其职，身体便渐渐成长，在爱中建立起来。</span>
</div>
</div>

## 新人新生命

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 彼得前书 4:3–4; 帖撒罗尼迦前书 4:1–2"> 因此，我奉主的名郑重劝告各位，不要再像不信的外族人一样过着心灵空虚的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:15; 以弗所书 2:12; 罗马书 1:21–23"> 他们因为愚昧无知、心里刚硬而理智受到蒙蔽，并与上帝所赐的生命隔绝了。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:5; 罗马书 1:24–26; 提摩太前书 4:2"> 他们麻木不仁，放纵情欲，沉溺于各种污秽的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提多书 2:11–14; 约翰福音 6:45; 马太福音 11:29"> 但基督并未这样教导你们。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 5:20; 以弗所书 1:13; 希伯来书 3:7–8"> 你们如果听过祂的事，领受了祂的教导，就是在祂里面的真理，</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 6:6; 希伯来书 12:1; 雅各书 1:21"> 就应该与从前的生活方式一刀两断，脱去因私欲的迷惑而渐渐败坏的旧人，</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 12:2; 罗马书 8:6; 诗篇 51:10"> 洗心革面，</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:10–14; 哥林多后书 5:17; 以弗所书 2:10"> 穿上照着上帝形象所造的新人。这新人有从真理而来的公义和圣洁。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 3:9; 撒迦利亚书 8:16; 箴言 12:22"> 所以不要再说谎，大家都要彼此说真话，因为我们都是一个身体的肢体。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 1:19; 诗篇 4:4; 诗篇 37:8"> 不要因生气而犯罪，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇4:4。">b</a></sup>不要到日落时还怒气未消，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 4:7; 彼得前书 5:8; 以弗所书 6:16"> 不要让魔鬼有机可乘。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前书 6:18; 帖撒罗尼迦前书 4:11–12; 加拉太书 6:10"> 从前偷窃的要改过自新，自食其力，做正当事，以便能够与有需要的人分享所得。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 4:6; 帖撒罗尼迦前书 5:11; 传道书 10:12"> 污言秽语一句都不可出口，要随时随地说造就人的好话，使听的人得益处。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19; 以赛亚书 63:10; 以弗所书 1:13–14"> 不要让上帝的灵担忧，你们已经盖上了圣灵的印记，将来必蒙救赎。</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:8; 传道书 7:9; 提多书 3:2–3"> 要从你们当中除掉一切苦毒、恼恨、怒气、争吵、毁谤和邪恶。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:12–13; 马太福音 6:14–15; 马可福音 11:25"> 总要以恩慈、怜悯的心彼此相待，要互相饶恕，正如上帝在基督里饶恕了你们一样。</span>
</div>
</div>

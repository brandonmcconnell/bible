## 行事与圣徒的身份相称

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:11; 彼得前书 1:15–16; 以弗所书 4:32"> 因此，你们既然是上帝疼爱的儿女，就要效法上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:34; 加拉太书 2:20; 歌罗西书 3:14"> 要以爱心待人，像基督爱我们一样，祂为我们牺牲自己作为献给上帝的馨香供物和祭物。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 3:5; 以弗所书 5:5; 加拉太书 5:19–21"> 一切淫乱、污秽或贪婪的事在你们当中连提都不要提，才合乎圣徒的身份。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:8; 以弗所书 4:29; 帖撒罗尼迦前书 5:18"> 污言秽语、愚昧粗俗的谈笑都不合宜，总要说感恩的话才好。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:21; 哥林多前书 6:9–10; 以弗所书 5:3"> 因为你们清楚知道，淫乱的人、污秽的人，还有贪婪的人，就是拜偶像的人，在基督和上帝的国里没有立足之地。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 1:18; 歌罗西书 2:8; 马太福音 24:4"> 不要被虚空的道理欺骗，因为上帝的烈怒必临到做这些事的悖逆之人。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 18:4; 以弗所书 5:11; 提摩太前书 5:22"> 所以，你们不要与他们同流合污。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:12; 约翰一书 1:7; 使徒行传 26:18"> 你们从前活在黑暗中，现在既然活在主的光明中，行事为人就该像光明的儿女。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:9–10; 加拉太书 5:22–23; 约翰三书 1:11"> 光明总是结出良善、公义和真理的果子。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:1–2; 希伯来书 12:28; 诗篇 19:14"> 你们要察验什么是主所喜悦的事，</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:12; 提摩太前书 5:20; 帖撒罗尼迦后书 3:6"> 不可参与那些黑暗无益的事，反而要揭发，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:3; 耶利米书 23:24; 传道书 12:14"> 因为那些人暗地里做的事就是提起来都觉得可耻。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 3:20–21; 哥林多前书 4:5; 何西阿书 2:10"> 然而，一切事被光一照，都会真相大白，</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 60:1; 罗马书 13:11–12; 以赛亚书 26:19"> 因为光能使一切显明出来。因此有人说：<br /><span className="pl pl-1">“沉睡的人啊，醒来吧！</span><br /><span className="pl pl-1">从死人中起来吧，</span><br /><span className="pl pl-1">基督要光照你了！”</span></span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:5; 雅各书 3:13; 腓立比书 1:27"> 因此，你们要注意自己的生活，不要像愚昧人，要像有智慧的人。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 阿摩司书 5:13; 约翰福音 12:35"> 要爱惜光阴，因为现今是个邪恶的世代。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:2; 帖撒罗尼迦前书 5:18; 歌罗西书 1:9"> 所以，不要做糊涂人，要明白主的旨意。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 罗马书 13:13"> 不要醉酒，醉酒会使人放荡，要被圣灵充满。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:16; 哥林多前书 14:26; 诗篇 95:2"> 要用诗篇、圣诗、灵歌互相激励，从心底唱出赞美主的旋律。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 3:17; 帖撒罗尼迦前书 5:18; 希伯来书 13:15"> 凡事总要奉我们主耶稣基督的名感谢父上帝。</span>
</div>
</div>

## 夫妇之道

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:3; 以弗所书 5:24; 以弗所书 5:22"> 你们要存敬畏基督的心彼此顺服。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:18–1; 彼得前书 3:1–6; 提多书 2:5"> 你们做妻子的，要顺服丈夫，如同顺服主。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 11:3–10; 歌罗西书 1:18; 以弗所书 1:22–23"> 因为丈夫是妻子的头，正如基督是祂的身体——教会的头，又是教会的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 5:33; 歌罗西书 3:20; 提多书 2:7"> 教会怎样顺服基督，妻子也要照样凡事顺服丈夫。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:28"> 你们做丈夫的要爱妻子，正如基督爱教会，为教会舍己，</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:22; 约翰福音 15:3; 以西结书 36:25"> 好借着道用水洗净教会，使她圣洁，</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 1:22; 希伯来书 9:14; 彼得前书 1:19"> 以便把圣洁、完美、没有污点和皱纹等瑕疵的荣耀教会献给祂自己。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:25; 马太福音 19:5; 创世记 2:21–24"> 同样，做丈夫的也要爱妻子如同爱自己的身体，爱妻子就是爱自己。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 34:14–15; 以弗所书 5:31; 传道书 4:5"> 从来没有人会厌恶自己的身体，人会保养和爱惜身体，正如基督对待教会一样，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 6:15; 哥林多前书 12:12–27; 罗马书 12:5"> 因为我们是祂身上的肢体。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 2:24; 马太福音 19:5; 马可福音 10:7–8"> “因此，人要离开父母，与妻子结合，二人成为一体。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记2:24。">a</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="启示录 21:2; 哥林多后书 11:2; 以赛亚书 54:5"> 这是一个极大的奥秘，然而我是指着基督和教会的关系说的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:2–7; 以斯帖记 1:20; 以弗所书 5:25"> 总之，你们做丈夫的都要爱妻子如同爱自己，做妻子的也要敬重丈夫。</span>
</div>
</div>

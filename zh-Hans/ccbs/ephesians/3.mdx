## 外族人的福音使者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:24; 提摩太后书 1:8; 腓立比书 1:13–16"> 为此，我保罗为了把基督耶稣传给你们外族人而做了囚犯。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:25–27; 提摩太前书 1:11; 提摩太后书 1:11"> 相信你们已经听说了，上帝委派我将祂的恩典传给你们，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:12; 罗马书 16:25; 以弗所书 1:9–11"> 借着启示让我明白福音的奥秘，正如我前面简要提过的。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 4:3; 哥林多前书 4:1; 哥林多后书 11:6"> 你们读过之后，就能明白我深知基督的奥秘。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:10–12; 彼得后书 3:2; 提多书 1:1–3"> 自古以来，上帝没有让人知道这奥秘，如今祂借着圣灵将这奥秘启示给祂的圣使徒和先知。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:26–29; 约翰一书 1:3; 约翰一书 2:25"> 这奥秘就是外族人能够在基督耶稣里借着福音与以色列人同做后嗣，同为一体，同享应许。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 1:19; 以弗所书 3:20; 以弗所书 3:2"> 上帝运用大能赐给我恩典，叫我成为这福音的使者。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 1:27; 哥林多前书 15:9; 以弗所书 2:7"> 我本来比最卑微的圣徒还卑微，却蒙上帝赐我这恩典，让我把基督那测不透的丰富传给外族人，</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26; 马太福音 13:35; 提摩太后书 1:9"> 让世人都明白世代隐藏在创造万物的上帝里面的奥秘，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:12; 以弗所书 6:12; 哥林多前书 2:7"> 目的是为了现在透过教会让天上的执政者和掌权者认识上帝丰富的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:11; 以弗所书 1:4"> 上帝这样做是按照祂在我们主基督耶稣里所成就的永恒计划。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 2:18; 罗马书 5:2; 希伯来书 4:14–16"> 我们靠着基督、借着信祂可以坦然无惧、笃定不疑地来到上帝面前。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:24; 帖撒罗尼迦后书 3:13; 哥林多后书 1:6"> 所以，我请求各位不要因我为你们受苦而沮丧，这其实是你们的荣耀。</span>
</div>
</div>

## 基督的爱

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 95:6; 以弗所书 1:16–19; 腓立比书 2:10"> 为此，我跪在创造天地万物的父面前，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:11; 腓立比书 4:13; 以赛亚书 40:29–31"> 祈求祂按照自己丰盛的荣耀，借着祂的灵，以大能使你们内在的生命刚强起来，</span>
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:7; 约翰一书 4:16; 约翰福音 14:23"> 使基督借着你们的信心住在你们心里，使你们在爱中扎根、坚立，</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 103:11–12; 约伯记 11:7–9; 以弗所书 1:18–23"> 以便能够与众圣徒一同领悟基督的爱是多么长阔高深，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:23; 歌罗西书 2:9–10; 歌罗西书 1:10"> 并知道基督的爱远超越人的认知，好叫上帝无限的丰富充满你们。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 9:8; 罗马书 4:21; 耶利米书 32:27"> 上帝照着运行在我们里面的大能，能够丰丰富富地成就一切，超过我们所求所想的。</span>
<span className="v" id="v21" data-v="21" data-xref="犹大书 1:25; 罗马书 11:36; 彼得后书 3:18"> 愿祂在教会中，在基督耶稣里得到荣耀，直到世世代代，永永远远。阿们！</span>
</div>
</div>

</div>

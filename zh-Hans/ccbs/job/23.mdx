<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> <span className="pl pl-1">约伯回答说：</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 10:1; 诗篇 32:4; 约伯记 7:11"> <span className="pl pl-1">“我的哀诉至今充满苦楚，</span><br /><span className="pl pl-1">祂的责罚使我呻吟不止。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 16:21; 耶利米书 14:7; 约伯记 13:3"> <span className="pl pl-1">但愿我知道何处能寻见上帝，</span><br /><span className="pl pl-1">知道怎样去祂的居所。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 13:18; 但以理书 9:18–19; 出埃及记 32:12–13"> <span className="pl pl-1">我好在祂面前陈明案情，</span><br /><span className="pl pl-1">滔滔不绝地为自己申辩；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 13:22–23; 约伯记 10:2; 哥林多前书 4:3–4"> <span className="pl pl-1">我好知道祂的答复，</span><br /><span className="pl pl-1">明白祂对我说的话。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 13:21; 约伯记 9:33–34; 哥林多后书 12:9–10"> <span className="pl pl-1">祂会用大能与我争辩吗？</span><br /><span className="pl pl-1">不会的，祂会垂听我的申诉，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 13:3; 罗马书 8:1; 以赛亚书 1:18"> <span className="pl pl-1">允许正直的人与祂理论，</span><br /><span className="pl pl-1">审判者会让我永远脱罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="诗篇 10:1; 约伯记 9:11; 约伯记 35:14"> <span className="pl pl-1">“然而，我去东边，祂不在那里；</span><br /><span className="pl pl-1">我到西边，也找不到祂。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 89:46; 以赛亚书 8:17"> <span className="pl pl-1">祂在北边工作，我看不见祂；</span><br /><span className="pl pl-1">祂转到南边，我也看不见祂。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:12; 雅各书 1:2–4; 彼得前书 1:7"> <span className="pl pl-1">但祂知道我的一举一动，</span><br /><span className="pl pl-1">我被祂试炼后必如纯金。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="诗篇 115:3; 箴言 19:21; 以赛亚书 46:10"> <span className="pl pl-1">祂独行其事，谁能阻挡祂？</span><br /><span className="pl pl-1">祂按自己的意愿行事。</span><br /></span>

## 约伯咒诅自己

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 20:14–15; 诗篇 106:33; 诗篇 39:2–3"> 后来，约伯开口咒诅自己的生日，</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 18:14"> 说：</span>

<span className="v" id="v5" data-v="5" data-xref="约伯记 10:21–22; 诗篇 23:4; 约伯记 28:3"> <span className="pl pl-1">愿那日被幽暗和浓浓的黑影笼罩，</span><br /><span className="pl pl-1">被密云覆盖，</span><br /><span className="pl pl-1">被阴暗淹没。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="以赛亚书 24:8; 耶利米书 7:34; 启示录 18:22–23"> <span className="pl pl-1">愿那夜无人生育，</span><br /><span className="pl pl-1">毫无快乐之声。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 41:1; 约伯记 41:10; 马可福音 5:38"> <span className="pl pl-1">愿那些咒诅白日、</span><br /><span className="pl pl-1">能惹动海怪的人，</span><br /><span className="pl pl-1">咒诅那夜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 41:18; 耶利米书 13:16; 约伯记 30:26"> <span className="pl pl-1">愿那夜的晨星昏暗，</span><br /><span className="pl pl-1">等不到晨光的出现，</span><br /><span className="pl pl-1">看不见黎明的眼帘。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 20:17; 传道书 6:3–5; 创世记 20:18"> <span className="pl pl-1">因为那夜没有关闭我母胎的门，</span><br /><span className="pl pl-1">也没有遮住我眼前的患难。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v13" data-v="13" data-xref="传道书 9:10; 约伯记 21:13; 约伯记 14:10–12"> <span className="pl pl-1">不然我早已安然躺卧、长眠安息，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 15:28; 诗篇 89:48; 诗篇 49:14"> <span className="pl pl-1">与世上的君王和谋臣作伴——他们为自己建造的宫殿已荒废，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 10:27; 约伯记 22:25; 西番雅书 1:18"> <span className="pl pl-1">与房屋堆满金银的王侯同眠。</span><br /></span>

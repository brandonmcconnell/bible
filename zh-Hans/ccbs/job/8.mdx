## 比勒达发言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约伯记 2:11"> 书亚人比勒达回答说：</span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 6:26; 约伯记 15:2; 列王纪上 19:11"> <span className="pl pl-1">“你要这样絮叨到何时？</span><br /><span className="pl pl-1">你的话犹如阵阵狂风。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命记 32:4; 历代志下 19:7; 创世记 18:25"> <span className="pl pl-1">上帝岂会歪曲正义？</span><br /><span className="pl pl-1">全能者岂会颠倒是非？</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 1:5; 约伯记 1:18–19; 约伯记 5:4"> <span className="pl pl-1">如果你的儿女得罪了祂，</span><br /><span className="pl pl-1">祂会给他们应有的惩罚。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 4:7–10; 希伯来书 3:7–8; 约伯记 11:13"> <span className="pl pl-1">但你若寻求上帝，</span><br /><span className="pl pl-1">向全能者恳求；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 51:9; 以赛亚书 3:10; 箴言 15:8"> <span className="pl pl-1">你若纯洁、正直，</span><br /><span className="pl pl-1">祂必起身相助，</span><br /><span className="pl pl-1">恢复你公义的家园。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 42:12–13; 马太福音 13:31–32; 箴言 19:20"> <span className="pl pl-1">你起初虽然卑微，</span><br /><span className="pl pl-1">日后必兴旺发达。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="申命记 32:7; 申命记 4:32; 约伯记 15:18"> <span className="pl pl-1">“你要请教先辈，</span><br /><span className="pl pl-1">探究祖先的经验。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 29:15; 诗篇 144:4; 约伯记 14:2"> <span className="pl pl-1">因为我们昨天才出生，一无所知，</span><br /><span className="pl pl-1">我们在世的日子如同掠影。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 18:15; 马太福音 12:35; 约伯记 12:7–8"> <span className="pl pl-1">先辈必给你教诲和指点，</span><br /><span className="pl pl-1">向你道出明智之言。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 2:3; 以赛亚书 19:5–7"> <span className="pl pl-1">“蒲草无泥岂可长高？</span><br /><span className="pl pl-1">芦苇无水岂可茂盛？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:6; 诗篇 129:6–7; 马太福音 13:20"> <span className="pl pl-1">它们还在生长、尚未割下，</span><br /><span className="pl pl-1">已比百草先枯萎。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 9:17; 约伯记 11:20; 约伯记 13:16"> <span className="pl pl-1">忘记上帝的人，结局也是如此；</span><br /><span className="pl pl-1">不信上帝的人，盼望终必破灭。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:5–6"> <span className="pl pl-1">他所仰仗的虚若游丝，</span><br /><span className="pl pl-1">他所倚靠的诚如蛛网。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 27:18; 路加福音 6:47–49; 马太福音 7:24–27"> <span className="pl pl-1">他倚靠它，它却支撑不住；</span><br /><span className="pl pl-1">他抓紧它，它却脆弱不稳。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 80:11; 约伯记 21:7–15; 约伯记 5:3"> <span className="pl pl-1">他像阳光下生机勃勃的植物，</span><br /><span className="pl pl-1">枝条爬满了园囿，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 5:24; 马可福音 11:20; 犹大书 1:12"> <span className="pl pl-1">根茎盘绕石堆，</span><br /><span className="pl pl-1">深深扎入石缝。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 7:10; 诗篇 37:36; 约伯记 7:8"> <span className="pl pl-1">一旦他被连根拔起，</span><br /><span className="pl pl-1">原处必否认见过他。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 20:5; 诗篇 113:7; 撒母耳记上 2:8"> <span className="pl pl-1">他的生命就这样消逝</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“他的生命就这样消逝”或译“这就是他一生的乐趣”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">地上会兴起其他人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="约伯记 4:7; 诗篇 37:37; 诗篇 37:24"> <span className="pl pl-1">“上帝绝不会抛弃纯全的人，</span><br /><span className="pl pl-1">也不会扶持邪恶的人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 126:2; 创世记 21:6; 诗篇 126:6"> <span className="pl pl-1">祂要使你笑口常开，</span><br /><span className="pl pl-1">欢声不断。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 132:18; 诗篇 109:29; 诗篇 35:26"> <span className="pl pl-1">憎恨你的人必抱愧蒙羞，</span><br /><span className="pl pl-1">恶人的帐篷必不复存在。”</span></span>

## 以利户的回答

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约伯记 10:7; 约伯记 33:9; 约伯记 10:2"> 三人见约伯自以为义，便不再回答他。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 22:21; 约伯记 40:8; 约伯记 27:2"> 那时，兰族的布西人巴拉迦的儿子以利户对约伯很恼火，因为约伯自以为义，不承认上帝的公义。</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 8:6; 约伯记 24:25; 约伯记 22:5–30"> 他对约伯的三个朋友也很恼火，因为他们说约伯有罪，却无法回答约伯的质问<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“因为他们说约伯有罪，却无法回答约伯的质问”有古卷作“因为他们无法回答约伯的质问，因而置上帝于不公”。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 32:11–12; 箴言 18:13"> 由于不及他们年长，以利户便等他们说完才向约伯发言。</span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 32:2; 出埃及记 32:19"> 他见三人无法回答约伯，很恼火。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 15:10; 提摩太前书 5:1; 提多书 2:6"> 于是，布西人巴拉迦的儿子以利户说：<br /><span className="pl pl-1">“我年纪轻，你们是长辈，</span><br /><span className="pl pl-1">所以我畏惧，不敢向你们陈明观点。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 16:31; 约伯记 12:12; 希伯来书 5:12"> <span className="pl pl-1">我想，前辈当先发言，</span><br /><span className="pl pl-1">长者当传授智慧。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 38:36; 约伯记 33:4; 提摩太后书 3:16"> <span className="pl pl-1">但只有人里面的灵——</span><br /><span className="pl pl-1">全能者的气息赐人悟性。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:25; 约伯记 12:20; 传道书 4:13"> <span className="pl pl-1">长者不一定有智慧，</span><br /><span className="pl pl-1">年老不一定明白是非。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:25; 哥林多前书 7:40"> <span className="pl pl-1">因此，请听我说，</span><br /><span className="pl pl-1">我也要陈明观点。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 29:21; 约伯记 5:27; 箴言 28:11"> <span className="pl pl-1">看啊，我一直等候你们发言，</span><br /><span className="pl pl-1">倾听你们的高见，</span><br /><span className="pl pl-1">等你们斟词酌句。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="约伯记 32:3; 提摩太前书 1:7"> <span className="pl pl-1">我仔细聆听，</span><br /><span className="pl pl-1">发现你们无人能驳倒约伯，</span><br /><span className="pl pl-1">无人能答复他。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 9:23; 哥林多前书 1:27–29; 哥林多前书 3:18"> <span className="pl pl-1">你们不要说，‘我们找到了智慧，</span><br /><span className="pl pl-1">使他折服的是上帝而非人。’</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">约伯没有与我辩论，</span><br /><span className="pl pl-1">我也不会用你们的理论答复他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="约伯记 6:24–25; 马太福音 22:46; 约伯记 29:22"> <span className="pl pl-1">“他们惊慌失措，无言以对，</span><br /><span className="pl pl-1">再也说不出话来。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 1:19; 约伯记 13:5; 阿摩司书 5:13"> <span className="pl pl-1">难道他们不说话，站在那里无言以对，</span><br /><span className="pl pl-1">我就要等下去吗？</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 35:3–4; 约伯记 33:12; 约伯记 32:10"> <span className="pl pl-1">我也要作出答复，</span><br /><span className="pl pl-1">陈明我的观点。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 39:3; 使徒行传 4:20; 哥林多后书 5:13–14"> <span className="pl pl-1">因为我心里积满了话，</span><br /><span className="pl pl-1">我里面的灵催促我说出来。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 9:17"> <span className="pl pl-1">我里面像盛满了酒，却没有出口，</span><br /><span className="pl pl-1">又如将要破裂的新酒袋。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 8:6–7; 约伯记 21:3; 约伯记 13:13"> <span className="pl pl-1">我要一吐为快，</span><br /><span className="pl pl-1">我要开口答复。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="利未记 19:15; 约伯记 13:8; 马太福音 22:16"> <span className="pl pl-1">我不看人的情面，</span><br /><span className="pl pl-1">也不奉承人。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 12:2–3; 帖撒罗尼迦前书 2:5; 箴言 29:5"> <span className="pl pl-1">我不懂奉承，</span><br /><span className="pl pl-1">否则，造物主会很快把我除掉。</span></span>

## 约伯的回应

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 约伯回答说：</span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 4:17; 罗马书 3:20; 约伯记 25:4"> <span className="pl pl-1">“不错，我知道你所言不虚，</span><br /><span className="pl pl-1">但人怎能在上帝面前算为义人？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 10:2; 约伯记 40:2; 以赛亚书 57:15–16"> <span className="pl pl-1">人若想与祂辩驳，</span><br /><span className="pl pl-1">千次也不能胜一次。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 36:5; 罗马书 11:33; 以弗所书 3:20"> <span className="pl pl-1">祂充满智慧，能力无比，</span><br /><span className="pl pl-1">谁能抗拒祂还能平安无恙？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:51; 路加福音 21:11; 哈巴谷书 3:10"> <span className="pl pl-1">祂可猝然挪动群山，</span><br /><span className="pl pl-1">在怒气中把山翻倒。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="哈该书 2:6; 希伯来书 12:26; 诗篇 75:3"> <span className="pl pl-1">祂震动大地，使其挪位，</span><br /><span className="pl pl-1">以致地的支柱摇撼。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 13:10; 阿摩司书 8:9; 路加福音 21:25–26"> <span className="pl pl-1">祂一声令下，</span><br /><span className="pl pl-1">太阳便不再升起，</span><br /><span className="pl pl-1">众星也不再发光。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 44:24; 以赛亚书 40:22; 诗篇 104:2–3"> <span className="pl pl-1">祂独自铺展穹苍，</span><br /><span className="pl pl-1">步行在海浪之上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 5:8; 创世记 1:16; 约伯记 38:31–41"> <span className="pl pl-1">祂创造了北斗星、参星、昴星及南天的星座。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 5:9; 诗篇 72:18; 以弗所书 3:20"> <span className="pl pl-1">祂行的奇事不可测度，</span><br /><span className="pl pl-1">奇迹不可胜数。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 23:8–9; 约伯记 35:14; 诗篇 77:19"> <span className="pl pl-1">祂经过我身旁，我却看不见；</span><br /><span className="pl pl-1">祂从旁边掠过，我也无法察觉。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 45:9; 约伯记 11:10; 约伯记 23:13"> <span className="pl pl-1">祂若夺取，谁能阻挡？</span><br /><span className="pl pl-1">谁敢问祂，‘你做什么？’</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 89:10; 约伯记 26:12; 以赛亚书 30:7"> <span className="pl pl-1">上帝不会忍怒不发，</span><br /><span className="pl pl-1">海怪</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“海怪”希伯来文是“拉哈伯”，下同26:12。">a</a></sup><br /><span className="pl pl-1">的帮手必屈膝在祂脚前。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 8:27; 约伯记 9:3; 约伯记 4:19"> <span className="pl pl-1">“因此，我怎敢与祂辩驳？</span><br /><span className="pl pl-1">怎敢措辞与祂理论？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 10:15; 约伯记 8:5; 约伯记 10:2"> <span className="pl pl-1">我纵然无辜，也无法申诉，</span><br /><span className="pl pl-1">只能乞求我的审判者施恩。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 29:24; 出埃及记 6:9; 诗篇 66:18–20"> <span className="pl pl-1">即使我呼唤祂的时候，祂回应我，</span><br /><span className="pl pl-1">我仍不相信祂会垂听我的声音。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 16:14; 约伯记 2:3; 约伯记 34:6"> <span className="pl pl-1">祂用暴风摧毁我，</span><br /><span className="pl pl-1">无故地使我饱受创伤。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 7:19; 耶利米哀歌 3:15; 诗篇 88:15–18"> <span className="pl pl-1">祂不肯让我喘息，</span><br /><span className="pl pl-1">祂使我尝尽苦头。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 9:32–33; 约伯记 9:4; 哥林多前书 1:25"> <span className="pl pl-1">若论力量，祂甚强大；</span><br /><span className="pl pl-1">若上公堂，谁敢传祂？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 15:5–6; 腓立比书 3:12–15; 诗篇 143:2"> <span className="pl pl-1">即使我清白无辜，我的口也会认罪；</span><br /><span className="pl pl-1">即使我纯全无过，祂也会判我有罪。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 1:1; 诗篇 139:23–24; 箴言 28:26"> <span className="pl pl-1">我虽纯全无过，也已毫不在乎自己，</span><br /><span className="pl pl-1">我厌恶我的生命。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="传道书 9:1–3; 路加福音 13:2–4; 约伯记 10:8"> <span className="pl pl-1">因为，我认为都是一样，</span><br /><span className="pl pl-1">纯全无过的人和恶人都会被祂毁灭。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 24:12; 约伯记 1:13–19; 约伯记 4:7"> <span className="pl pl-1">灾祸突然夺走人命时，</span><br /><span className="pl pl-1">祂嘲笑无辜者的遭遇。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 10:3; 耶利米书 12:1–2; 诗篇 73:3–7"> <span className="pl pl-1">大地落入恶人手中，</span><br /><span className="pl pl-1">蒙蔽审判官眼睛的不是祂是谁？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="约伯记 7:6–7; 雅各书 4:14; 诗篇 90:9–10"> <span className="pl pl-1">“我的年日比信差还快，</span><br /><span className="pl pl-1">匆匆而过，不见幸福。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="哈巴谷书 1:8; 以赛亚书 18:2; 约伯记 39:27–30"> <span className="pl pl-1">我的岁月疾驰如蒲草船，</span><br /><span className="pl pl-1">快如急降抓食的老鹰。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 7:13; 耶利米书 8:18; 约伯记 7:11"> <span className="pl pl-1">即使我说要忘掉怨恨，</span><br /><span className="pl pl-1">抛开愁容，强颜欢笑，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 119:120; 诗篇 88:15–16; 约伯记 21:6"> <span className="pl pl-1">诸多的患难仍使我惧怕，</span><br /><span className="pl pl-1">我知道祂</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“祂”希伯来文是“你”，下同31节。">b</a></sup><br /><span className="pl pl-1">不承认我无辜。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 10:7; 约伯记 21:27; 约伯记 10:14–17"> <span className="pl pl-1">既然我被定为有罪，</span><br /><span className="pl pl-1">又何必徒然挣扎？</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 2:22; 诗篇 26:6; 约翰一书 1:8"> <span className="pl pl-1">即使我用雪水净身，</span><br /><span className="pl pl-1">用碱水洗手，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 64:6; 以赛亚书 59:6; 约伯记 15:6"> <span className="pl pl-1">祂仍会把我扔进污坑，</span><br /><span className="pl pl-1">连我的衣服也嫌弃我。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 9:20; 传道书 6:10; 诗篇 143:2"> <span className="pl pl-1">祂并非世人，与我迥异，</span><br /><span className="pl pl-1">我无法与祂辩驳，一起对簿公堂。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 2:25; 约翰一书 2:1–2; 约伯记 9:19"> <span className="pl pl-1">我俩中间没有仲裁者，</span><br /><span className="pl pl-1">无人为我们断定是非</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“为我们断定是非”希伯来文是“把手按在我们身上”。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 39:10; 约伯记 13:11; 约伯记 33:7"> <span className="pl pl-1">若能拿开祂责打我的刑杖，</span><br /><span className="pl pl-1">使我不再受祂的惊吓，</span><br /></span>
<span className="v" id="v35" data-v="35"> <span className="pl pl-1">我就会放胆发言，不必对祂心存恐惧，</span><br /><span className="pl pl-1">但现在我却不能这样</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“但现在我却不能这样”或译“因为我知道自己的清白”。">d</a></sup><br /><span className="pl pl-1">。</span></span>

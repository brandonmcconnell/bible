<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="诗篇 64:3; 约伯记 18:2; 约伯记 27:2"> <span className="pl pl-1">“你们要折磨我多久？</span><br /><span className="pl pl-1">用言语压碎我到何时？</span><br /></span>

<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:10; 箴言 9:12; 以西结书 18:4"> <span className="pl pl-1">即使我真有过错，</span><br /><span className="pl pl-1">也由我独自承担。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 35:26; 诗篇 38:16; 诗篇 55:12"> <span className="pl pl-1">你们若真要妄自尊大，</span><br /><span className="pl pl-1">利用我的耻辱来指责我，</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="哈巴谷书 1:2–3; 耶利米哀歌 3:8; 约伯记 31:35–36"> <span className="pl pl-1">我喊冤，却无人回应；</span><br /><span className="pl pl-1">我呼救，却不见公道。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 3:7; 约伯记 3:23; 箴言 4:19"> <span className="pl pl-1">上帝筑起墙垒，阻断我的路，</span><br /><span className="pl pl-1">祂使黑暗笼罩我的路途。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 89:44; 约伯记 29:7–14; 诗篇 89:39"> <span className="pl pl-1">祂剥去我的荣耀，</span><br /><span className="pl pl-1">摘走我头上的冠冕。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 24:20; 诗篇 37:35–36; 哥林多后书 4:8–9"> <span className="pl pl-1">祂从四面攻击我，直到我消逝；</span><br /><span className="pl pl-1">祂把我的希望像树一样连根拔除。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 13:24; 约伯记 16:9; 约伯记 33:10"> <span className="pl pl-1">祂向我发烈怒，</span><br /><span className="pl pl-1">视我为仇敌。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="约伯记 30:12; 约伯记 16:13; 以赛亚书 51:23"> <span className="pl pl-1">祂的大军蜂拥而来，</span><br /><span className="pl pl-1">筑起围城坡道攻击我，</span><br /><span className="pl pl-1">在我帐篷四周扎营。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 88:8; 诗篇 88:18; 诗篇 69:8"> <span className="pl pl-1">“祂使我的弟兄远离我，</span><br /><span className="pl pl-1">我的熟人完全背弃我。</span><br /></span>

<span className="v" id="v15" data-v="15" data-xref="约伯记 31:31–32; 诗篇 123:3"> <span className="pl pl-1">我的客人和婢女都视我如陌路，</span><br /><span className="pl pl-1">把我当作外族人。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 1:15–17; 约伯记 1:19"> <span className="pl pl-1">我呼唤仆人，他却不回应；</span><br /><span className="pl pl-1">我开口哀求，他也不理睬。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 2:9–10; 约伯记 17:1"> <span className="pl pl-1">我妻子厌恶我的气息，</span><br /><span className="pl pl-1">我的手足都嫌弃我。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 2:23; 约伯记 30:12; 约伯记 30:1"> <span className="pl pl-1">连小孩子都鄙视我；</span><br /><span className="pl pl-1">我一出现，他们就嘲笑我。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 41:9; 诗篇 109:4–5; 诗篇 55:12–14"> <span className="pl pl-1">我的密友都憎恶我，</span><br /><span className="pl pl-1">我爱的人也反对我。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 102:5; 耶利米哀歌 4:8; 约伯记 33:19–22"> <span className="pl pl-1">我瘦得只剩下皮包骨，</span><br /><span className="pl pl-1">我离死亡仅一线之隔</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我离死亡仅一线之隔”希伯来文是“我只剩牙皮逃脱”。">a</a></sup><br /><span className="pl pl-1">。</span></span>
</div>

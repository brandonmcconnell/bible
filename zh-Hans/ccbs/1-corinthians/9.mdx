## 使徒的权利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:17; 提摩太前书 2:7; 哥林多前书 9:19"> 我不是自由的吗？我不是使徒吗？我不是见过我们的主耶稣吗？你们不是我在主里工作的成果吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 12:12; 约翰福音 6:27; 哥林多后书 3:1–3"> 即使对别人来说我不是使徒，对你们来说我也是使徒，因为你们就是我在主里做使徒的印证。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 12:16–19; 哥林多后书 13:3; 哥林多后书 13:10"> 对那些责难我的人，我的答复是这样：</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:6; 帖撒罗尼迦后书 3:8–9; 路加福音 10:7"> 难道我们没有权利接受弟兄姊妹供应的饮食吗？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:42; 希伯来书 13:4; 马太福音 8:14"> 难道我们没有权利像主的兄弟、矶法和其他使徒一样，带着信主的妻子一同出入吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:7–9; 使徒行传 13:1–2; 使徒行传 4:36"> 难道只有我和巴拿巴要自食其力吗？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命记 20:6; 提摩太后书 2:3–4"> 有谁当兵要自备粮饷呢？有谁栽种葡萄园，却不吃园中出产的葡萄呢？有谁牧养牛羊，却不喝牛羊的奶呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:20; 帖撒罗尼迦前书 4:8; 罗马书 3:31"> 我这样说难道只是人的观点吗？律法不也是这样说的吗？</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 25:4; 提摩太前书 5:18; 诗篇 104:27"> 摩西的律法书上说：“牛在踩谷时，不可笼住它的嘴。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记25:4。">a</a></sup>难道上帝关心的只是牛吗？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太后书 2:6; 罗马书 15:4; 罗马书 4:23–24"> 祂这样说难道不是为了我们吗？这话的确是为我们写的，因为耕耘的和打谷的农夫都应该存着分享收成的盼望劳作。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:27; 加拉太书 6:6; 哥林多后书 11:15"> 我们在你们中间既然撒下了属灵的种子，难道就不能从你们那里收获物质上的供应吗？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:15; 哥林多前书 9:18; 哥林多后书 11:12"> 如果别人有权要求你们供应他们，我们岂不更有权吗？可是我们从来没有用过这权利，反而凡事忍耐，免得妨碍了基督的福音。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 18:8–20; 民数记 5:9–10; 利未记 6:26"> 你们难道不知道，在圣殿里事奉的人可以吃圣殿里的食物，在祭坛前事奉的人可以分享祭坛上的祭物吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:10; 提摩太前书 5:17–18; 哥林多前书 9:4"> 同样，主也曾吩咐：传福音的人理当借着福音得到生活的供应。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:9; 帖撒罗尼迦后书 3:8; 哥林多前书 9:12"> 但是，我完全没有使用这权利，如今我谈这些事，并不是要你们这样待我。因为我宁死也不要让人抹杀我所夸耀的。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:14; 耶利米书 20:9; 歌罗西书 4:17"> 其实我传福音并没有什么可夸的，因为这是托付给我的任务，我不传福音就有祸了！</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:7; 哥林多前书 3:8; 历代志上 28:9"> 我若甘心乐意地传福音，就可以得奖赏；我若不甘愿，责任也已经委托给我了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 11:7–9; 哥林多前书 8:9; 帖撒罗尼迦前书 2:6"> 那么，我能得到什么奖赏呢？就是我可以把福音白白地传给人，不使用自己因传福音而应有的权利。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 5:13; 马太福音 18:15; 雅各书 5:19–20"> 我虽然是自由之身，不受任何人支配，但我甘愿成为众人的奴仆，为了要得到更多的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:3; 加拉太书 5:18; 使徒行传 21:20–26"> 面对犹太人我就做犹太人，为了要赢得犹太人。面对守律法的人，我这不受律法束缚的人就守律法，为了要赢得守律法的人。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:12; 罗马书 2:14; 加拉太书 3:2"> 面对没有律法的人，我就像个没有律法的人，为了要赢得没有律法的人。其实我并非在上帝的律法之外，我是在基督的律法之下。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 10:33; 罗马书 15:1; 哥林多前书 9:19"> 面对软弱的人我就做软弱的人，为了要得软弱的人。面对什么人，我就做什么人，为了要尽可能地救一些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:10; 马可福音 8:35; 哥林多前书 9:25–27"> 我做的一切都是为了福音的缘故，为了要与人分享福音的祝福。</span>
<span className="v" id="v24" data-v="24" data-xref="腓立比书 3:14; 希伯来书 12:1; 提摩太后书 4:7–8"> 你们不知道吗？在运动场上赛跑的人虽然个个都在跑，但冠军只有一个。同样，你们也要努力奔跑，好获得奖赏。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 2:5; 启示录 2:10; 提摩太后书 4:7–8"> 参加比赛的选手都事事自制，以求赢得桂冠，但这桂冠终必朽坏，我们要赢得的却是永不朽坏的桂冠。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 1:10; 腓立比书 1:21; 提摩太后书 2:5"> 因此，我奔跑不是漫无目标，我击拳不是打空气。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 8:13; 哥林多前书 9:25; 歌罗西书 3:5"> 我制服己身，掌控自己，免得我传福音给别人，自己却被淘汰了。</span>

## 论讲道和说方言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 14:39; 提摩太前书 4:14; 哥林多前书 12:1"> 你们要追求爱，也要切慕属灵的恩赐，尤其是做先知讲道的恩赐。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:17; 使徒行传 19:6; 使徒行传 10:46"> 人说方言，是对上帝说的，并非对人说的，因为没有人听得懂，他是在心灵里<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“在心灵里”或译“借着圣灵”。">a</a></sup>述说各种奥秘。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 14:12; 提摩太前书 4:13; 犹大书 1:20"> 但先知讲道是对人讲的，为了要造就、鼓励、安慰人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 14:22; 哥林多前书 14:26; 马可福音 16:17"> 说方言只是造就自己，但做先知讲道是造就教会。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:28–30; 哥林多前书 12:10; 马可福音 16:17"> 我希望你们都能说方言，不过，我更希望你们都能做先知讲道。说方言的不如做先知讲道的重要，除非把方言翻译出来，使教会得造就。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 1:17; 罗马书 6:17; 提摩太后书 3:16"> 弟兄姊妹，我如果到你们那里只说方言，不讲解有关上帝的启示、知识、预言、教导，对你们有什么益处呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 14:8; 路加福音 7:32; 哥林多前书 13:1"> 就连没有生命的箫和琴，如果发出的声音杂乱无章，谁能知道所吹所弹的是什么曲子呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 10:9; 以西结书 33:3–6; 耶利米书 4:19"> 如果号声不清楚，谁会预备打仗呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 9:26"> 同样，除非你们讲出清楚的信息，不然听见的人怎能明白呢？那岂不等于对空气说话吗？</span>
<span className="v" id="v10" data-v="10"> 世上有各种语言，却没有一种是毫无意义的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:2; 罗马书 1:14; 歌罗西书 3:11"> 如果有人对我说话，我却不明白他的语言，我们就成了彼此语言不通的人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 14:26; 哥林多前书 14:3–4; 哥林多前书 14:1"> 你们也是一样，既然渴慕属灵的恩赐，就应该多多追求造就教会的恩赐。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:24; 哥林多前书 12:30; 约翰福音 14:13–14"> 所以说方言的人应当祈求能把方言翻译出来。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 14:2; 哥林多前书 14:15–16; 哥林多前书 14:19"> 如果我用方言祷告，那是我的灵在祷告，但我的悟性没有发挥作用。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 3:16; 约翰福音 4:23–24; 以弗所书 6:18"> 那么，我该怎么做呢？我要用灵祷告，也要用悟性祷告；我要用灵歌唱，也要用悟性歌唱。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 16:36; 诗篇 106:48; 启示录 5:14"> 否则，如果你在聚会中用方言<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="本处“方言”希腊文是“灵”。">b</a></sup>来感恩，在座不懂方言的人不明白你在说些什么，怎能在你感恩的时候说“阿们”呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 14:4; 哥林多前书 14:6"> 你的感恩表达得固然美好，无奈不能造就别人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:4–6; 哥林多前书 4:7"> 感谢上帝，我说方言比你们众人都多。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:21–22; 哥林多前书 14:4"> 但在教会中我宁可用悟性说五句教导人的话，胜过说万句别人不懂的方言。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:2; 哥林多前书 13:11; 罗马书 16:19"> 弟兄姊妹，你们的思想不要像小孩子，要长大成熟，但在罪恶的事上要像婴孩。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 28:11–12; 耶利米书 5:15; 申命记 28:49"> 律法书上记载：<br /><span className="pl pl-1">“主说，‘我要借着讲陌生语言的人和外邦人的口向这些子民说话。</span><br /><span className="pl pl-1">虽然如此，</span><br /><span className="pl pl-1">他们仍然不听从我。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书28:11、12。">c</a></sup><br /><span className="pl pl-1">”</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:6–12; 马可福音 16:17; 哥林多前书 14:1"> 由此可见，讲方言不是显给信徒的标记，而是显给非信徒的标记；但先知讲道是显给信徒的标记，不是显给非信徒的标记。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 2:13; 使徒行传 26:24; 哥林多前书 11:18"> 所以，如果聚会的时候，整个教会的人都说方言，偶然有不懂方言的人或非信徒进来，他们岂不会说你们全都疯了吗？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:37; 哥林多前书 2:15; 希伯来书 4:12–13"> 但如果你们都做先知讲道，偶然有非信徒或是不懂方言的人进来，他会因所听的道而知罪，良心受到谴责，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:14; 撒迦利亚书 8:23; 诗篇 72:11"> 心中的秘密也会显露出来，便俯伏敬拜上帝，说：“上帝真的在你们当中！”</span>
</div>
</div>

## 聚会的原则

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 5:19; 罗马书 14:19; 哥林多前书 12:7–10"> 那么，弟兄姊妹，你们该怎么做呢？你们聚会的时候，不管是唱诗、教导、讲启示、说方言或翻译方言，都应该是为了造就人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 14:26"> 如果有人说方言，应该只限于两个人，最多三个，要轮流说，而且要有人把它翻译出来。</span>
<span className="v" id="v28" data-v="28"> 如果没有人翻译，说方言的人就当在聚会中闭口不言，只向自己和上帝说。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:10; 帖撒罗尼迦前书 5:19–21; 约翰一书 4:1–3"> 做先知讲道的也应该只限于两三个人，其他人应当慎思明辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19–20; 约伯记 33:31–33; 约伯记 32:11"> 但如果上帝的启示临到在座的其他人，正在讲的人要停下来，</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 5:14; 哥林多前书 14:3; 帖撒罗尼迦前书 5:11"> 这样大家都可以轮流讲道，人人都可以得到教导和勉励。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:19–20; 约翰一书 4:1; 撒母耳记上 10:10–13"> 先知的灵受先知控制，</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 3:17–18; 哥林多前书 14:40; 帖撒罗尼迦后书 3:16"> 因为上帝不是叫人混乱的上帝，而是赐人安宁的上帝。 正如圣徒的各教会一样，</span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前书 2:11–12; 创世记 3:16; 民数记 30:3–13"> 妇女<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“妇女”也可译为“妻子”。">d</a></sup>在聚会中要保持安静，因为她们不可发言，总要顺服，正如律法书所说的。</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所书 5:12; 彼得前书 3:7; 以弗所书 5:25–27"> 她们如果想要学什么，可以在家问自己的丈夫，因为妇女在聚会中发言是可耻的。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 18:1–17; 撒迦利亚书 14:8; 使徒行传 17:15"> 难道上帝的道是出自你们吗？难道上帝的道单单传给了你们吗？</span>
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 哥林多后书 10:7; 彼得后书 3:2"> 如果你们当中有人自认为是先知或属灵的人，他就应该知道我现在所写的是主的命令。</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太后书 4:3–4; 何西阿书 4:17; 启示录 22:11–12"> 如果有人对此视而不见，不必理会他。</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:31; 哥林多前书 14:1; 帖撒罗尼迦前书 5:20"> 所以，我的弟兄姊妹，你们要切慕做先知讲道，也不要禁止说方言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌罗西书 2:5; 提多书 1:5; 哥林多前书 14:26–33"> 但无论做什么事，都要按规矩，有次序。</span>
</div>

## 同是上帝的仆人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:13; 哥林多前书 2:14–15; 以弗所书 4:13–14"> 弟兄姊妹，以前我对你们讲话的时候，还不能把你们看作属灵的人，只能把你们看作属肉体的人，是在基督里的婴孩。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:11–14; 约翰福音 16:12; 彼得前书 2:2"> 我只能用奶而不能用饭来喂养你们，因为你们当时不能消化，甚至现在也不能。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:16; 加拉太书 5:15; 提多书 3:3"> 你们仍是属肉体的人，因为你们中间有嫉妒、争斗。这岂不证明你们是属肉体的，行事为人和世人一样吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:12; 哥林多前书 3:3; 哥林多前书 4:6"> 你们有的说：“我是跟随保罗的”，有的说：“我是跟随亚波罗的”，这岂不证明你们和世人一样吗？</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:4; 哥林多后书 6:1; 彼得前书 4:10"> 亚波罗算什么？保罗算什么？我们不过是上帝的仆人，各人照着主所赐的才干引导你们信靠上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:9–10; 箴言 11:25; 哥林多后书 10:14–15"> 我栽种，亚波罗浇灌，但使之生长的是上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:5; 加拉太书 6:3; 诗篇 115:1"> 所以栽种的和浇灌的都算不得什么，一切都在于使之生长的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 2:6; 马太福音 16:27; 约翰二书 1:8"> 其实栽种的人和浇灌的人目标都一样，各人将按照自己的付出得报酬。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:5; 以弗所书 2:20–22; 哥林多后书 6:1"> 因为我们是上帝的同工，你们是上帝的园地和建筑。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 3:11; 以弗所书 2:20; 罗马书 15:20"> 我照着上帝赐给我的恩典，好像一位有智慧的建筑师打下了根基，然后让其他工人在上面建造。但每个人建造的时候要小心，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20; 以赛亚书 28:16; 提摩太后书 2:19"> 因为除了那已经奠定的根基耶稣基督以外，没有人能另立根基。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:3; 提摩太后书 3:7; 提摩太后书 2:20"> 人们用金、银、宝石、草、木或禾秸在这根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 1:7; 哥林多前书 3:14–15; 启示录 20:12"> 每个人的工程将来都会显明出来，因为到了审判的日子，必用火试验各人工程的品质。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 3:8; 马太福音 25:21–23; 哥林多前书 4:5"> 人在这根基上所建造的工程若经得起考验，他必获得奖赏。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰二书 1:8; 哥林多前书 3:12–13; 犹大书 1:23"> 人的工程若被烧毁了，他必遭受损失，自己虽然可以得救，却像火里逃生一样。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 6:19; 以西结书 36:27; 哥林多后书 6:16"> 岂不知你们就是上帝的殿，上帝的灵住在你们里面吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 6:18–20; 以西结书 43:12; 民数记 19:20"> 若有人摧毁上帝的殿，上帝必摧毁那人，因为上帝的殿是神圣的，你们就是这殿。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以赛亚书 5:21; 加拉太书 6:3"> 你们不要自欺。如果你们有人自以为在世上有智慧，他应当变成愚人，好成为真正的智者。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 5:13; 诗篇 141:10; 哥林多前书 1:19–20"> 因为这世上的智慧在上帝的眼中都是愚昧的，正如圣经上说：“上帝使智者中了自己的诡计。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约伯记5:13。">a</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 94:11; 歌罗西书 2:8; 罗马书 1:21"> 又说：“主知道智者的思想虚妄。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇94:11。">b</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:32; 罗马书 8:28; 耶利米书 9:23–24"> 因此，谁都不要仗着人夸耀，因为万物都属于你们，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:11–12; 腓立比书 1:21; 哥林多前书 9:19–22"> 无论是保罗、亚波罗、矶法、世界、生命、死亡、现在的事或将来的事都属于你们，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:29; 哥林多前书 11:3; 约翰福音 17:9–10"> 你们属于基督，基督属于上帝。</span>

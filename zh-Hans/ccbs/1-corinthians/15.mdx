## 基督的复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:6–12; 彼得前书 5:12; 哥林多前书 15:3–11"> 弟兄姊妹，我希望你们记住我传给你们的福音，就是你们所领受并向来坚持的福音。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:6; 希伯来书 2:1; 希伯来书 3:14"> 你们若持守我传给你们的，必因这福音而得救——除非你们没有真正相信。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 2:24; 加拉太书 1:4; 以赛亚书 53:1–12"> 我所领受并传给你们的最重要的信息是：基督照圣经的记载为我们的罪死了，</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 6:2; 马太福音 12:40; 诗篇 16:10–11"> 然后被埋葬了；又照圣经的记载在第三天复活了，</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:14; 哥林多前书 1:12; 约翰福音 1:42"> 并曾向矶法显现，又向十二使徒显现；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 28:10; 马可福音 16:7; 使徒行传 13:36"> 后来有一次向五百多位弟兄姊妹显现，其中有许多至今还健在，也有些已经安息了；</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行传 1:2–12; 路加福音 24:33"> 随后，祂向雅各显现，又向众使徒显现；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 9:1; 使徒行传 26:16; 使徒行传 22:18"> 到最后，竟也向我这好像未按产期出生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗用“未按产期出生”来指自己非比寻常的蒙召经历。">a</a></sup>的人显现。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:7–8; 提摩太前书 1:13–15; 使徒行传 8:3"> 在众使徒中我最微不足道，根本不配称为使徒，因为我曾迫害上帝的教会。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 哥林多后书 3:5; 腓立比书 2:13"> 但靠着上帝的恩典，我成了今天的我，祂赐给我的恩典没有枉费。我比其他人更加劳苦，不过我不是靠自己，而是上帝的恩典与我同在。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:3–4; 哥林多前书 2:2"> 不论是我传的还是其他使徒传的，我们怎样传，你们也怎样相信了。</span>
</div>
</div>

## 死人复活

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:8; 使徒行传 17:32; 提摩太后书 2:18"> 既然我们一直都在传扬基督已经从死里复活，怎么你们当中却有人否定死人复活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:25–26; 罗马书 8:11; 帖撒罗尼迦前书 4:14"> 要是没有死人复活的事，基督也就没有复活。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:17; 帖撒罗尼迦前书 4:14; 加拉太书 2:2"> 如果基督没有复活，我们所传的就是虚空，你们所信的也是虚空。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 约伯记 13:7–10; 使徒行传 2:32"> 而且，我们就是在为上帝做假见证，因为我们见证上帝已经使基督复活了。如果没有死人复活的事，上帝也就没有叫基督复活。</span>
<span className="v" id="v16" data-v="16"> 如果人死了不会复活，基督也就没有复活。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 4:25; 彼得前书 1:3; 哥林多前书 15:14"> 如果基督没有复活，你们的信仰就是虚空，你们依旧沉沦在罪中，</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 4:13–14; 启示录 14:13; 帖撒罗尼迦前书 4:16"> 那些在基督里安息的人也灭亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 1:21; 启示录 14:13; 提摩太后书 1:12"> 如果我们对基督的盼望只在今世，我们就是世上最可怜的人。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 15:23; 使徒行传 26:23; 启示录 1:5"> 然而，基督已经从死里复活，祂是死人中第一个复活的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“是死人中第一个复活的”希腊文是“成为已经睡了之人初熟的果子”。">b</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:25; 罗马书 5:12–17; 哥林多前书 15:22"> 既然死亡的到来是借着一人，复活的到来也是借着一人。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 5:12–21; 哥林多前书 15:45–49; 约翰福音 5:21–29"> 因为正如在亚当里众人都死了，同样，在基督里众人也都要复活。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 26:19; 加拉太书 3:29; 哥林多前书 15:52"> 然而，各人要按照先后次序复活。基督最先复活，以后祂再来时，属祂的人也要复活。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:27; 但以理书 7:14; 马太福音 28:18"> 最后末日来临，那时基督会废除一切执政的、掌权的、有能力的，将国度交给父上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:12–13; 诗篇 110:1; 马太福音 22:44"> 因为基督必执掌王权，直到上帝将所有的仇敌都放在祂脚下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:10; 哥林多前书 15:55; 启示录 21:4"> 祂最后要毁灭的仇敌就是死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 8:6; 希伯来书 2:8; 马太福音 28:18"> 因为圣经上说：“上帝使万物降服在祂脚下。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇8:6。">c</a></sup>当然，这里说的“万物都降服祂”不包括使万物降服祂的上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:11; 哥林多前书 3:23; 以弗所书 1:23"> 到了万物都降服基督以后，圣子基督也要归服那使万物降服祂的上帝，使上帝做万物的主宰。</span>
<span className="v" id="v29" data-v="29" data-xref="罗马书 6:3–4; 哥林多前书 15:16; 马太福音 20:22"> 否则，那些人替死人受洗有什么意义呢？死人如果不会复活，为什么要替他们受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 6:9; 加拉太书 5:11; 哥林多后书 4:7–12"> 我们又何必时刻身临险境呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:10–11; 罗马书 8:36; 哥林多前书 4:9–13"> 我天天面对死亡。弟兄姊妹，我这样说，就跟我在主基督耶稣里以你们为荣一样，没有半点虚假。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 22:13; 以赛亚书 56:12; 路加福音 12:19"> 从人的角度看，我在以弗所与那些恶兽格斗对我有什么益处呢？如果死人不会复活，“让我们吃喝吧！因为明天我们就死了。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以赛亚书22:13。">d</a></sup></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 马太福音 24:4; 哥林多前书 5:6"> 你们不要上当受骗：“坏朋友会败坏好品德。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 6:5; 罗马书 13:11; 希伯来书 5:11–12"> 你们该醒悟了！不要继续犯罪，因为你们当中有些人不认识上帝。我说这话是要叫你们羞愧。</span>
</div>
</div>

## 复活后的身体

<div className="bt">
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="以西结书 37:3; 哥林多前书 15:38–53; 罗马书 9:19"> 也许有人会问：“死人怎样复活呢？复活后会有怎样的身体呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 12:24; 路加福音 11:40; 以弗所书 5:15"> 无知的人啊！你们种下的种子必须先死，然后才能生长。</span>
<span className="v" id="v37" data-v="37"> 而且，你们种下的并不是那将来要长成的形体，仅仅是种子，或麦种，或其他种子。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 3:7; 以赛亚书 61:11; 马可福音 4:26–29"> 上帝按自己的旨意赐给种子形体，每样种子都有自己的形体。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 1:20–26"> 血肉之体各不相同，人、兽、鸟、鱼都各有不同的形体。</span>
<span className="v" id="v40" data-v="40"> 此外，有天上的形体，也有地上的形体，两者的荣光各不相同。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 24:23; 诗篇 148:3–5; 申命记 4:19"> 日有日的荣光，月有月的荣光，星有星的荣光，这颗星和那颗星的荣光也有分别。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:43; 但以理书 12:3; 罗马书 8:21"> 死人复活也是同样的道理。种下去的会朽坏，复活的不会朽坏；</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前书 6:14; 歌罗西书 3:4; 腓立比书 3:20–21"> 种下去的是羞耻的，复活的是荣耀的；种下去的是软弱的，复活的是刚强的；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 15:50; 路加福音 24:31; 约翰福音 20:19"> 种下去的是血肉之躯，复活的是属灵的形体。既有血肉之躯，也必有属灵的形体。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 5:21; 创世记 2:7; 罗马书 8:2"> 圣经上也说：“第一个人亚当成了有生命的人”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="创世记2:7。">e</a></sup>，但末后的亚当是赐人生命的灵。</span>
<span className="v" id="v46" data-v="46" data-xref="歌罗西书 3:9–10; 罗马书 6:6; 以弗所书 4:22–24"> 先有的不是属灵的形体，而是血肉之躯，以后才有属灵的形体。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:31; 创世记 2:7; 创世记 3:19"> 第一个人亚当来自地上，是用尘土造的，但第二个人基督来自天上。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 5:3; 罗马书 5:12–21; 约翰福音 3:6"> 尘土所造的那位是什么样，属地的人也是什么样；从天而来的那位是什么样，属天的人也是什么样。</span>
<span className="v" id="v49" data-v="49" data-xref="罗马书 8:29; 哥林多后书 3:18; 创世记 5:3"> 我们既然有属地的形象，将来也必有属天的形象。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 3:3–6; 马太福音 16:17; 以弗所书 4:17"> 弟兄姊妹，我告诉你们，血肉之躯不能承受上帝的国，必朽坏的身体也不能承受永不朽坏的产业。</span>
<span className="v" id="v51" data-v="51" data-xref="帖撒罗尼迦前书 4:14–17; 腓立比书 3:21; 哥林多前书 15:20"> 听着，我要告诉你们一个奥秘：我们并不是都要死亡<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“死亡”希腊文是“睡觉”。">f</a></sup>，而是都要改变，</span>
<span className="v" id="v52" data-v="52" data-xref="帖撒罗尼迦前书 4:16–17; 马太福音 24:31; 约翰福音 5:28"> 就在一刹那，眨眼之间，最后的号角吹响的时候。因为号角一吹响，死人就要复活成为永不朽坏的，我们也要改变。</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多后书 5:2–4; 约翰一书 3:2; 罗马书 2:7"> 那时，这必朽的身体要变成不朽的，这必死的要变成不死的。</span>
<span className="v" id="v54" data-v="54" data-xref="以赛亚书 25:8; 启示录 20:14; 希伯来书 2:14–15"> 当这一切发生的时候，就应验了圣经上的话：<br /><span className="pl pl-1">“死亡被胜利吞灭了。”</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以赛亚书25:8。">g</a></sup><br /></span>
<span className="v" id="v55" data-v="55" data-xref="何西阿书 13:14; 诗篇 89:48; 使徒行传 2:27"> <span className="pl pl-1">“死亡啊！你得胜的权势在哪里？</span><br /><span className="pl pl-1">死亡啊！你的毒钩在哪里？”</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="何西阿书13:14。">h</a></sup></span>
<span className="v" id="v56" data-v="56" data-xref="罗马书 4:15; 加拉太书 3:10–13; 罗马书 7:5–13"> 死亡的毒钩就是罪，罪的权势就是律法。</span>
<span className="v" id="v57" data-v="57" data-xref="哥林多后书 2:14; 罗马书 8:37; 约翰一书 5:4–5"> 但感谢上帝，祂使我们靠着主耶稣基督得胜。</span>
<span className="v" id="v58" data-v="58" data-xref="加拉太书 6:9; 历代志下 15:7; 希伯来书 6:10"> 所以，我亲爱的弟兄姊妹，你们务要坚定不移，总要竭力做主的工作，因为你们知道自己在主里的辛勤付出不会白费。</span>
</div>

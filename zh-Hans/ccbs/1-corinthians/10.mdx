## 前车之鉴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 14:29; 尼希米记 9:11–12; 诗篇 78:13–14"> 弟兄姊妹，我希望你们知道，我们的祖先曾经在云下，都曾经走过红海，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:2–3; 哥林多前书 1:13–16; 出埃及记 14:31"> 都在云下、在海中受洗跟从了摩西。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:3; 尼希米记 9:15; 出埃及记 16:35"> 他们都吃过同样的灵粮，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:6; 约翰福音 7:37; 以赛亚书 48:21"> 都喝过同样的灵水，因为他们从那与他们同行的属灵磐石中得水喝，那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 3:17; 犹大书 1:5; 民数记 14:37"> 尽管如此，他们当中大多数人不讨上帝的喜悦，倒毙在旷野。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 哥林多前书 10:11; 希伯来书 4:11"> 如今这些事正好警戒我们，叫我们不要像他们那样贪恋罪恶。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:6–8; 诗篇 106:19–20; 哥林多前书 6:9"> 也不要祭拜偶像，像他们当中的人那样，正如圣经上说：“百姓坐下吃喝，起来狂欢。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记32:6。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="民数记 25:1–9; 哥林多前书 6:18; 诗篇 106:29"> 我们也不要淫乱，像他们当中的人那样，结果一天就死了两万三千人。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 21:5–6; 诗篇 78:18; 希伯来书 3:8–11"> 也不要试探主，像他们当中的人那样，结果被蛇咬死了。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:2; 民数记 16:41; 民数记 14:37"> 也不要发怨言，像他们当中的人那样，结果被灭命的天使毁灭了。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:4; 罗马书 13:11; 哥林多前书 9:10"> 发生在他们身上的这些事都是鉴戒，之所以记录下来是为了警戒我们这活在末世的人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:20; 彼得后书 3:17; 箴言 16:18"> 所以，自以为站得稳的人要小心，免得跌倒。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:9; 提摩太后书 4:18; 帖撒罗尼迦后书 3:3"> 你们遇见的诱惑无非是人们常见的。上帝是信实的，祂绝不会让你们遇见无法抵挡的诱惑，祂必为你们开一条出路，使你们经得住诱惑。</span>
</div>
</div>

## 切勿祭拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 21:8; 约翰一书 5:21; 彼得前书 2:11"> 所以，我亲爱的弟兄姊妹，你们要远避祭拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:1; 帖撒罗尼迦前书 5:21; 哥林多前书 11:13"> 你们都是明白事理的人，可以判断我的话对不对。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:26–28; 哥林多前书 11:23–29; 使徒行传 2:42"> 领圣餐时，我们为那福杯献上感谢，这不表示我们有份于基督的血吗？我们吃掰开的饼，这不表示我们有份于基督的身体吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:5; 歌罗西书 3:15; 哥林多前书 12:27"> 我们人数虽多，却同属一个身体，因为饼只有一个，我们同享一个饼。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 3:3–5; 加拉太书 6:16; 利未记 7:6"> 你们看以色列人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“以色列人”希腊文是“从血统上讲是以色列人”。">b</a></sup>，那些吃祭物的难道不是有份于祭坛吗？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 8:4; 哥林多前书 3:7; 哥林多前书 13:2"> 我这话是什么意思呢？是说偶像和祭偶像的食物有什么特别吗？</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 9:20; 诗篇 106:37–39; 申命记 32:16–17"> 当然不是，我的意思是那些异教徒所献的祭是祭鬼魔的，而不是献给上帝的。我不愿意你们与鬼魔有任何关系。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 列王纪上 18:21; 哥林多后书 6:15–17"> 你们不能又喝主的杯又喝鬼魔的杯，不能又吃主的圣餐又吃祭鬼魔的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:21; 申命记 32:16; 希伯来书 10:31"> 我们想惹主嫉妒吗？难道我们比祂更有能力吗？</span>
</div>
</div>

## 信徒的自由

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:12; 哥林多前书 8:9; 以弗所书 4:29"> 凡事我都可以做，但并非事事都有益处；凡事我都可以行，但并非事事都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:1–2; 哥林多前书 10:33; 腓立比书 2:4–5"> 无论是谁，不要求自己的好处，要求别人的好处。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前书 4:4; 哥林多前书 8:7; 提多书 1:15"> 市场上卖的肉，你们都可以吃，不必为良心的缘故而询问什么，</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 24:1; 出埃及记 19:5; 诗篇 50:12"> 因为大地和其中的万物都属于主。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇24:1。">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 10:25; 路加福音 10:7–8; 哥林多前书 5:9–11"> 如果有非信徒邀请你们吃饭，你们又愿意去，那么，只管吃桌上摆的食物，不必为良心的缘故而询问什么。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 8:10–13; 哥林多前书 8:7; 哥林多前书 10:26"> 不过，如果有人告诉你这些是献给偶像的祭物，你为了那告诉你的人和良心的缘故，就不要吃。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:19; 罗马书 14:15–21; 哥林多前书 8:9–13"> 不过我指的不是你的良心，而是那人的良心。也许有人说：“我的自由为什么要受别人的良心限制呢？</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 14:6; 提摩太前书 4:3–4"> 我若存感恩的心吃，为什么还要受谴责呢？”</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:17; 歌罗西书 3:23; 彼得前书 4:11"> 所以，你们或吃或喝，无论做什么，都要为上帝的荣耀而做。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 20:28; 哥林多前书 10:33; 罗马书 14:13"> 不要成为犹太人、希腊人或上帝教会的绊脚石，</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 10:24; 加拉太书 1:10; 哥林多前书 9:19–23"> 就像我凡事尽量让人满意，不求自己的好处，只求众人的好处，以便他们可以得救。</span>
</div>
</div>

## 敬拜的礼仪

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:15; 哥林多前书 4:17; 箴言 31:28–31"> 我赞赏你们，因为你们凡事都想到我，并坚守我传给你们的各种教导。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 3:16; 歌罗西书 1:18; 歌罗西书 3:18"> 我希望你们知道，基督是男人的头，丈夫是妻子的头，上帝是基督的头。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 15:30; 哥林多前书 12:28; 哥林多前书 12:10"> 男人在祷告和讲道时，若蒙着头，就是羞辱自己的头。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 21:12; 路加福音 2:36; 使徒行传 2:17"> 但妇女在祷告和讲道时，若不蒙着头，就是羞辱自己的头，因为她就像剃光了头发一样。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 22:5; 民数记 5:18"> 因此，妇女若不愿意把头蒙起来，就该把头发剪掉。她若觉得剪发或剃头是羞耻的，就应该蒙头。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 11:3; 创世记 5:1; 诗篇 8:6"> 然而，男人不该蒙头，因为男人是上帝的形象和荣耀，而女人是男人的荣耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 2:13; 创世记 2:21–23"> 因为男人并非出自女人，而女人却是出自男人。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 2:18; 创世记 2:23–24; 创世记 2:20"> 并且男人不是为女人而造的，女人却是为男人而造的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 24:64–65; 希伯来书 1:14; 马太福音 18:10"> 因此为了天使的缘故，女人在头上应该有顺服权柄的记号。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28; 哥林多前书 7:10–14; 哥林多前书 12:12–22"> 不过在主里，女人不可没有男人，男人不可没有女人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:36; 哥林多前书 8:6; 希伯来书 1:2–3"> 因为女人从男人而来，男人又是女人生的，但万物都来自上帝。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 约翰福音 7:24; 哥林多前书 10:15"> 你们自行斟酌吧，女人向上帝祷告时不蒙头合适吗？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:26; 哥林多前书 14:35"> 按着人的天性，难道你们不知道男人留长发是他的羞辱，</span>
<span className="v" id="v15" data-v="15"> 女人留长发是她的荣耀吗？因为头发是用来给女人盖头的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 7:17; 提摩太前书 6:3–4; 帖撒罗尼迦前书 2:14"> 如果有谁想反驳这些话，我只能说，这是我们和上帝的众教会向来遵守的规矩。</span>
</div>
</div>

## 守圣餐的规矩

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:25; 哥林多前书 14:23; 哥林多前书 11:22"> 现在我有话要吩咐你们，不是称赞你们，因为你们聚会不但无益，反而有害。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 3:3; 哥林多前书 1:10–12; 哥林多前书 5:1"> 首先，我听说你们在聚会的时候制造分裂，我相信这些话有几分真实。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:19; 提多书 3:10; 使徒行传 20:30"> 你们中间必然会有分裂的事，好显出谁是经得起考验的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 你们聚会的时候，不是在吃主的晚餐。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:13; 犹大书 1:12; 哥林多前书 11:23–25"> 因为你们进餐的时候，各人只顾吃自己的，结果有些人挨饿，有些人醉酒。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 20:28; 箴言 17:5; 雅各书 2:5–6"> 难道你们不能在家里吃喝吗？还是你们轻看上帝的教会，存心羞辱那些贫穷的弟兄姊妹呢？我该说什么呢？称赞你们吗？不可能！</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 马太福音 26:26–28; 哥林多前书 11:23–25"> 我把从主领受的传给了你们，就是：主耶稣被出卖的那天晚上，祂拿起饼来，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:53–58; 哥林多前书 11:27–28; 哥林多前书 10:3–4"> 祝谢后掰开，说，“这是我为你们牺牲的身体，你们要这样做来记念我。”</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯来书 9:15–20; 希伯来书 13:20"> 饭后，祂照样拿起杯来，说，“这杯是用我的血立的新约。你们每逢喝的时候，要这样做来记念我。”</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:28; 启示录 1:7; 约翰福音 14:3"> 所以，每当你们吃这饼、喝这杯的时候，就是宣告主的死，一直到主再来。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 6:51; 哥林多前书 10:21; 希伯来书 10:29"> 因此，无论是谁，若以不正确的心态吃主的饼、喝主的杯，就是得罪主的身体和主的血。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:4; 哥林多后书 13:5; 耶利米哀歌 3:40"> 所以，人要先自我省察，才可以吃这饼喝这杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 11:27; 哥林多前书 11:30; 哥林多前书 11:32–34"> 因为人若不顾这是主的身体，随便吃喝，就是自招审判。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 3:19; 民数记 20:12; 阿摩司书 3:2"> 正因如此，你们当中有许多人身体软弱，疾病缠身，死亡的也不少。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 1:9; 诗篇 32:3–5; 启示录 2:5"> 我们若先自我省察，就不会遭受审判了。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:5–11; 诗篇 118:18; 箴言 3:11–12"> 主审判我们，是对我们的管教，免得我们和世人一同被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 因此，我的弟兄姊妹，当你们聚会吃圣餐时，要彼此等候。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 11:21–22; 哥林多前书 7:17; 哥林多前书 4:19"> 若有人饥饿，可以在家中先吃，免得你们聚会的时候自招审判。至于其余的事，等我到了以后再安排。</span>
</div>
</div>

</div>

## 圣灵的恩赐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 12:4–11; 哥林多前书 14:37; 哥林多前书 14:1–18"> 弟兄姊妹，谈到圣灵的恩赐，我不希望你们无知。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 4:3; 帖撒罗尼迦前书 1:9; 诗篇 115:5"> 你们知道，自己在信主前曾受到迷惑和引诱去拜不会说话的偶像。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 4:2–3; 马太福音 16:16–17; 罗马书 10:9"> 因此我希望你们知道，一个被上帝的灵感动的人绝不会说“耶稣该受咒诅”；若不是受了圣灵的感动，没有人会说“耶稣是主”。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 4:10; 哥林多前书 12:28; 罗马书 12:4–6"> 恩赐各有不同，但圣灵是同一位。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 4:11–12; 罗马书 12:6–8; 罗马书 14:8–9"> 事奉各有不同，但主是同一位。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:7; 哥林多前书 12:11; 约翰福音 5:17"> 工作各有不同，但上帝是同一位，祂在众人当中成就万事。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10–11; 罗马书 12:6–8; 哥林多前书 14:19"> 圣灵给各人不同的恩赐为要使众人得益处。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; 哥林多前书 2:6–10; 诗篇 143:10"> 这人从圣灵领受智慧的话，那人从圣灵领受知识；</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 5:14–15; 哥林多后书 4:13; 以弗所书 2:8"> 圣灵赐这人信心，赐那人医病的恩赐；</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 14:39; 约翰一书 4:1; 马可福音 16:17"> 圣灵使这人能行神迹，使那人能做先知讲道；使这人能辨别诸灵，使那人能说方言<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“方言”或译“语言”。">a</a></sup>，又使另一人能翻译方言。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:4; 希伯来书 2:4; 哥林多后书 10:13"> 这一切都是同一位圣灵所赐的，是祂按自己的旨意分别赐给各人的。</span>
</div>
</div>

## 同属一个身体

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:4–5; 歌罗西书 3:15; 哥林多前书 12:27"> 这如同一个身体有许多肢体，肢体虽多，仍同属一个身体。基督的身体也是这样。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 歌罗西书 3:11; 加拉太书 3:28"> 不论是犹太人或希腊人，是奴隶或自由人，我们都领受了同一位圣灵的洗礼，归入了同一个身体，同饮一位圣灵。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 12:27–28; 哥林多前书 12:12; 以弗所书 4:25"> 人的身体并非只有一个肢体，而是由许多肢体组成的。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 9:8–15; 列王纪下 14:9"> 如果脚说：“我不是手，所以我不属于身体”，难道它就因此不属于身体吗？</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 哥林多前书 12:22; 腓立比书 2:3"> 如果耳朵说：“我不是眼睛，所以我不属于身体，”难道它就因此不属于身体吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 12:21; 诗篇 139:13–16; 箴言 20:12"> 如果整个身体是一只眼睛，哪里有听觉呢？如果整个身体是一只耳朵，哪里有嗅觉呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:28; 罗马书 12:3; 哥林多前书 12:11"> 其实，上帝按自己的旨意将各个肢体安置在身体上了。</span>
<span className="v" id="v19" data-v="19"> 全身如果只有一个肢体，还会是身体吗？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 12:14; 哥林多前书 12:12"> 如今肢体虽多，但身体只有一个。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 10:1–5; 尼希米记 4:16–21; 约伯记 29:11"> 眼睛不能对手说：“我不需要你。”头也不能对脚说：“我不需要你。”</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 传道书 9:14–15; 传道书 4:9–12"> 相反，看起来不太重要的肢体其实是不可或缺的。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 3:21; 创世记 3:7"> 我们认为身体上不体面的肢体，越要加以美化；不雅观的肢体，越要精心呵护。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 3:11; 创世记 2:25"> 我们身上体面的肢体用不着美化。上帝把身体的各肢体安排在一起，使那些不体面的肢体更体面，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 13:11; 哥林多前书 1:10–12; 约翰福音 17:21–26"> 这样身体各肢体才可以彼此相顾，不会分门别类。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 加拉太书 6:2; 希伯来书 13:3"> 如果一个肢体感到痛苦，全身也一同受苦。如果一个肢体得到荣耀，全身也一同喜乐。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:12; 歌罗西书 1:24; 以弗所书 5:30"> 你们就是基督的身体，并且各自都是身体的肢体。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 4:11–13; 罗马书 12:6–8; 哥林多前书 12:18"> 上帝在教会中设立的第一是使徒，第二是先知，第三是教师，其次是行神迹的，然后是有医病恩赐的，帮助别人的，管理事务的，说各种方言的。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:4–11; 哥林多前书 12:14–20"> 岂是都做使徒吗？都做先知吗？都做教师吗？都行神迹吗？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 12:10"> 都有医病的恩赐吗？都会说方言吗？都会翻译方言吗？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 13:1; 哥林多前书 14:39; 马太福音 5:6"> 你们应该热心追求更大的恩赐。 现在，我要将一条奇妙无比的道路指示你们！</span>
</div>
</div>

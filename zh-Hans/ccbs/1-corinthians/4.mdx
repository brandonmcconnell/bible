## 基督的使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 提多书 1:7; 提摩太前书 3:9"> 因此，人应该把我们当作是基督的仆人，是上帝奥秘事的管家。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 对管家的要求是忠心。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 7:24; 哥林多前书 2:15; 撒母耳记上 16:7"> 我对你们或别人给我的评价毫不介意，我也不评价我自己。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 143:2; 约翰一书 3:20–21; 诗篇 130:3"> 就算我今日问心无愧，也不能自以为义，因为评价我的是主。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:7; 哥林多后书 5:10; 哥林多前书 3:13"> 所以，时候未到，不可妄下断语。到主耶稣再来的时候，祂会曝光暗中的隐情，揭开人心里的动机。到时候上帝会给各人应得的称赞。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:6; 哥林多后书 11:4; 哥林多后书 12:19"> 弟兄姊妹，为了你们的益处，我以自己和亚波罗作例子，好让你们效法我们不越过圣经的准则，免得有人自高自大、厚此薄彼。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:27; 彼得前书 4:10; 雅各书 1:17"> 谁使你与众不同呢？你有哪一样不是领受的呢？既然一切都是领受的，你为什么还自夸，好像不是领受的？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; 箴言 13:7; 哥林多前书 5:6"> 你们已经饱足了，富有了，不需要我们，自己已经做王了。我倒希望你们真的做王了，好让我们也和你们一同做王。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:33; 罗马书 8:36; 哥林多后书 4:8–12"> 我想，上帝把我们使徒排在队伍的末尾，好像被判死罪的囚犯，让我们成了一台戏，给宇宙观看，给天使和世人观看。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 2:3; 使徒行传 26:24; 哥林多前书 3:18"> 我们为基督的缘故成了愚昧人，你们在基督里倒成了聪明人；我们软弱，你们倒刚强；你们受人尊敬，我们倒被人藐视。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:35; 哥林多后书 11:23–27; 腓立比书 4:12"> 我们至今还是又饥又渴，衣不蔽体，遭受毒打，居无定所，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:9; 马太福音 5:11; 彼得前书 4:12–14"> 还要亲手劳作。我们被人咒骂，就为对方祝福；受人迫害，就逆来顺受；</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:45; 使徒行传 22:22"> 被人毁谤，就好言相劝。人们至今仍将我们看作世上的废物，万物中的渣滓。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:11; 哥林多前书 4:15; 约翰三书 1:4"> 我之所以写这些事，并非叫你们羞愧，而是像劝诫我亲爱的儿女一样劝诫你们。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:19; 哥林多前书 3:10; 哥林多前书 9:14"> 你们虽然在基督里有千万个导师，却没有许多父亲，因为我借着福音在基督耶稣里成为你们的父亲。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 11:1; 帖撒罗尼迦后书 3:9; 腓立比书 3:17"> 所以，我劝你们效法我。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:2; 哥林多前书 16:10; 哥林多前书 7:17"> 正因如此，我派了提摩太去你们那里。他在主里忠心耿耿，是我所爱的孩子。他会提醒你们我在基督里如何行事为人，在各地、各教会如何教导人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:6–8; 哥林多前书 5:2; 哥林多前书 4:21"> 你们当中有些人以为我不会再去你们那里，就傲慢自大起来。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 13:1–4; 使徒行传 18:21; 使徒行传 19:21"> 但主若许可，我会很快去你们那里。那时我要看看这些骄傲的人究竟是只会空谈，还是真有上帝的权能。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4; 帖撒罗尼迦前书 1:5; 哥林多后书 10:4–5"> 因为上帝的国不在于空谈，而在于权能。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 哥林多后书 13:10; 帖撒罗尼迦前书 2:7"> 到底你们要什么呢？要我带着刑杖去呢？还是要我带着温柔慈爱的心去呢？</span>

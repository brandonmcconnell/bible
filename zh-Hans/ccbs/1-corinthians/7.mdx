## 论婚姻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 7:8; 哥林多前书 7:26–27; 哥林多前书 7:37–38"> 关于你们信上所写的事，我认为男人不亲近女人是好的。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 5:28; 以弗所书 5:33; 哥林多前书 7:9"> 不过，为了避免发生淫乱的事，男婚女嫁也合情合理。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 3:7; 出埃及记 21:10"> 夫妻双方都应当尽自己的本分，过正常的夫妻生活。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 3:3; 马太福音 19:9; 马可福音 10:11–12"> 妻子无权支配自己的身体，丈夫才有权；丈夫也无权支配自己的身体，妻子才有权。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:15; 约珥书 2:16; 撒迦利亚书 12:12–14"> 夫妻不可彼此亏负，除非双方同意，才可以暂时分房，以便专心祈祷。以后，二人仍要恢复正常的夫妻生活，免得撒旦趁你们情不自禁的时候引诱你们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 8:8; 哥林多前书 7:25; 哥林多前书 7:12"> 我这么说是准许你们这样做，并非命令你们。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 19:11–12; 罗马书 12:6; 哥林多前书 9:5"> 虽然我希望人人都像我一样独身，但每个人从上帝所领受的恩赐不同，有的是这样，有的是那样。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:32; 哥林多前书 7:34–35; 哥林多前书 7:26–27"> 至于那些未婚的和寡居的，他们若能像我一样就好了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 7:2; 提摩太前书 5:14; 提摩太前书 5:11"> 但他们若不能自制，就应该结婚，因为与其欲火攻心还不如结婚为好。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 5:32; 路加福音 16:18; 马太福音 19:3–9"> 我也吩咐那些已婚的人，其实不是我吩咐，而是主吩咐：妻子不可离开丈夫，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:1; 哥林多前书 7:10; 以赛亚书 50:1"> 若是离开了，不可再嫁别人，只能与丈夫复合。丈夫也不可离弃妻子。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 11:17; 哥林多前书 7:6; 哥林多前书 7:25"> 至于其他人，主没有吩咐什么，但我要说，如果某弟兄的妻子不信主，但乐意和他同住，他就不应离弃妻子。</span>
<span className="v" id="v13" data-v="13"> 同样，如果某姊妹的丈夫不信主，但乐意和她同住，她就不应离弃丈夫。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 2:15–16; 提摩太前书 4:5; 提多书 1:15"> 因为不信的丈夫因妻子而得以圣洁了。同样，不信的妻子也因丈夫而得以圣洁了。否则你们的孩子就是不洁净的，但如今他们是圣洁的。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:19; 哥林多后书 13:11; 雅各书 3:17–18"> 如果不信的一方坚持要离开的话，就遂其所愿吧。无论是弟兄或姊妹遇到这样的事情都不必勉强。上帝呼召我们，原是要我们和睦相处。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:1–2; 哥林多前书 9:22; 罗马书 11:14"> 你这做妻子的，怎么知道不能救你的丈夫呢？你这做丈夫的，怎么知道不能救你的妻子呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 4:17; 罗马书 12:3–8; 哥林多前书 7:24"> 各人应当依照上帝的呼召和安排生活，这是我对各教会的吩咐。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:5; 使徒行传 15:28; 使徒行传 15:24"> 如果蒙召时已经受了割礼，不必消除割礼；如果蒙召时没有受割礼，也不必去受割礼。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:15; 加拉太书 5:6; 约翰一书 2:3–4"> 受不受割礼都算不得什么，最要紧的是遵行上帝的诫命。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:17; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:12"> 各人应当保持自己蒙召时的身份。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:18–24; 歌罗西书 3:11; 路加福音 10:40–41"> 如果你蒙召时是奴隶，不必因此而烦恼。不过如果你可以获得自由，也不要放过机会。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 腓利门书 1:16; 歌罗西书 3:22–24"> 因为，蒙召信主时做奴隶的，现在是主的自由人；蒙召时做自由人的，现在是基督的奴仆。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:20; 彼得前书 1:18–19; 提多书 2:14"> 你们是主用重价买来的，不要做人的奴隶。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 7:20; 歌罗西书 3:23–24; 哥林多前书 7:17"> 弟兄姊妹，你们要在上帝面前保持自己蒙召时的身份。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 7:6; 哥林多前书 4:2; 哥林多前书 7:40"> 关于独身的问题，主并没有给我任何命令，但我既然深受主恩，成为祂忠心的仆人，就向你们提供一些意见。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 7:1; 哥林多前书 7:8; 彼得前书 4:17"> 鉴于目前时势艰难，我认为各人最好是安于现状。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:20; 哥林多前书 7:12–14"> 已经有妻子的，就不要设法摆脱她；还没有妻子的，就不要想着结婚。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 13:4; 哥林多前书 7:32–36; 哥林多前书 7:26"> 男婚女嫁并不是犯罪，只是有家室的人总免不了许多人生的苦恼，我是盼望你们能够免去这些苦恼。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 2:17; 哥林多前书 7:31; 罗马书 13:11–12"> 弟兄们，我告诉你们，时日不多了，从今以后，那些有妻子的，要像没有妻子的；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哭泣的，要像不哭泣的；欢喜的，要像不欢喜的；置办家业的，要像一无所有的。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 2:17; 彼得前书 4:7; 雅各书 4:14"> 享用世界之物的，不要沉溺其中。因为现今的世界很快就要过去了。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:25–34; 提摩太前书 5:5; 腓立比书 4:6"> 我希望你们无牵无挂。未婚的男子可以关心主的事，想着怎样讨主的喜悦。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:25–33"> 但已婚的男子关心世上的事，想着如何取悦妻子，</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前书 6:20; 路加福音 2:36–37"> 难免分心。没有丈夫的妇女和处女可以关心主的事，叫身体和心灵都圣洁；但已婚的妇女关心世上的事，想着如何取悦丈夫。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 7:33–34; 哥林多前书 7:36; 路加福音 8:14"> 我这样说是为了你们的好处，不是要束缚你们，而是要鼓励你们做合宜的事，好叫你们殷勤、专心事奉主。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 7:37; 哥林多前书 7:9; 撒母耳记上 2:33"> 若有人觉得对待自己的未婚妻有不合宜之处，自己又情欲难禁，就成全他的心愿，让他们结婚吧！这并不算犯罪。</span>
<span className="v" id="v37" data-v="37"> 如果这人心里确信自己没有结婚的需要，又能自己作主，打定主意不结婚，这样做也好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 13:4; 哥林多前书 7:1–2; 哥林多前书 7:8"> 所以，与未婚妻完婚是对的，但不结婚则更好。</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:2–3; 哥林多后书 6:14–16; 哥林多前书 7:10"> 丈夫还活着的时候，妻子必须忠于丈夫。如果丈夫去世了，她就自由了，可以再婚，只是要嫁给信主的弟兄。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 7:35; 彼得后书 3:15–16; 哥林多前书 7:8"> 然而，照我的意见，她若能不再婚就更有福了。我想自己也是受了上帝的灵感动才说这番话的。</span>

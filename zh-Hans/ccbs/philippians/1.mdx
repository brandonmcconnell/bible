## 感恩和祷告

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:4; 帖撒罗尼迦前书 1:2–3; 腓利门书 1:4–5"> 我每逢想起你们，就感谢我的上帝；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 1:2; 罗马书 1:9; 约翰二书 1:4"> 每次为你们众人祷告，心里都带着喜乐。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:14–15; 腓立比书 1:7; 希伯来书 3:14"> 因为你们从最初直到现在，始终和我同心合意地传扬福音。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦前书 5:23–24; 腓立比书 2:13; 以弗所书 4:12"> 我深信，上帝既然在你们心里开始了这美好的工作，就必在耶稣基督再来的时候完成这工作。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:3; 腓立比书 1:5; 歌罗西书 4:18"> 我对你们众人有这样的感受很自然，因为我常把你们放在心上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我常把你们放在心上”或译“你们常把我放在心上”。">a</a></sup>。不论我是身在狱中，还是为福音辩护和作证的时候，你们都与我同蒙恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 罗马书 1:9; 提摩太后书 1:4"> 上帝可以作证，我是怎样以基督耶稣的慈心想念你们的。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 3:12; 歌罗西书 1:9; 彼得后书 1:5–6"> 我所祈求的就是：你们的爱心随着属灵知识和辨别力的提高而日益增长，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 5:23"> 使你们能够择善而从，做诚实无过的人，一直到基督再来的日子，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 约翰福音 15:8; 约翰福音 15:4–5"> 并靠着耶稣基督结满仁义的果子，使上帝得到荣耀与颂赞。</span>
</div>
</div>

## 为基督而活

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:9; 罗马书 8:28; 使徒行传 11:19–21"> 弟兄姊妹，我希望你们知道，我的遭遇反而会使福音传得更广，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 2:9; 以弗所书 3:1; 腓立比书 1:7"> 连所有的皇家卫兵和其他众人都知道我是为了基督的缘故而受囚禁。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 6:19–20; 帖撒罗尼迦前书 2:2; 路加福音 1:74"> 大多数主内的弟兄姊妹因我被囚的缘故，就信心坚定，更加放胆传扬上帝的道。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:17–18; 腓立比书 2:3; 哥林多后书 11:13"> 当然，有些人宣讲基督是出于嫉妒和争强好胜，也有些人是出于善意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:17; 哥林多后书 4:1–2; 诗篇 69:26"> 后者是出于爱心，知道我是上帝派来为福音辩护的。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 1:11–12; 腓立比书 2:3; 腓立比书 1:7"> 前者传讲基督是出于个人野心，动机不纯，以为可以增加我在狱中的痛苦。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 马可福音 9:38–40; 哥林多前书 15:11"> 那又怎样呢？无论他们是出于真心还是假意，基督的福音毕竟被传开了，因此我很欢喜，而且欢喜不已。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 8:28; 使徒行传 16:7; 哥林多后书 1:11"> 因为我知道，借着你们的祷告和耶稣基督之灵的帮助，我终必得到释放。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:16; 哥林多前书 6:20; 以赛亚书 54:4"> 我热切期待和盼望：我不会感到任何羞愧，而是放胆无惧，不管是生是死，都要照常使基督在我身上被尊崇。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:20; 哥林多后书 5:8; 哥林多后书 5:1"> 因为对我来说，活着是为了基督，死了也有益处。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:2; 加拉太书 2:20; 腓立比书 1:24"> 如果活在世上，我的工作肯定富有成果。我真不知道该怎么选择！</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:8; 诗篇 17:15; 启示录 14:13"> 我处在两难之间。我情愿离开世界，与基督在一起，那实在是再好不过了。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:7; 腓立比书 1:22; 腓立比书 1:25–26"> 可是为了你们，我更有必要活在世上。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 2:24; 哥林多后书 1:24; 以弗所书 4:11–13"> 我既然对此深信不疑，就知道自己仍要活下去，继续跟你们在一起，好使你们在信仰上又长进又充满喜乐。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 1:14; 哥林多后书 5:12; 腓立比书 3:3"> 这样，我再到你们那里的时候，你们可以因为我的缘故更加以基督耶稣为荣。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:1; 哥林多前书 16:13–14; 哥林多前书 1:10"> 最要紧的是：你们行事为人要与基督的福音相称。这样，不管是去看你们，还是只听到你们的消息，我都能知道你们同心合意，坚定不移地一起为福音信仰奋斗，</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 1:7–8; 帖撒罗尼迦后书 1:5–6; 马太福音 10:28"> 毫不惧怕敌人的恐吓。这是出于上帝的记号，表明他们必灭亡，你们必得救。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 1:2; 彼得前书 4:13; 使徒行传 5:41"> 因为上帝为了基督的缘故，赐恩使你们不但信基督，而且为祂受苦，</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 2:2; 使徒行传 16:19–40; 提摩太后书 4:7"> 经历你们从前在我身上见过、现在又从我这里听到的同样争战。</span>
</div>
</div>

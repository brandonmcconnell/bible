## 效法基督

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:12; 约翰一书 4:12; 约翰一书 4:7–8"> 所以，你们如果在基督里受到鼓励，得到爱的安慰，与圣灵相通，有慈悲和怜悯之心，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:16; 彼得前书 3:8–9; 哥林多前书 1:10"> 就要同心合意，彼此相爱，灵里合一，思想一致，好让我的喜乐满溢。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 12:10; 加拉太书 5:26; 以弗所书 5:21"> 凡事不可自私自利、爱慕虚荣，要心存谦卑，看别人比自己强。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:24; 罗马书 15:1; 雅各书 2:8"> 各人不要只顾自己的事，也要顾别人的事。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 2:21"> 你们应当有基督耶稣那样的心意。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 5:18; 哥林多后书 4:4; 希伯来书 1:3"> <span className="pl pl-1">祂虽然本质上是上帝，</span><br /><span className="pl pl-1">却不紧抓与上帝同等之位，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:9; 马太福音 20:28; 约翰福音 1:14"> <span className="pl pl-1">反而甘愿放下一切，</span><br /><span className="pl pl-1">取了奴仆的形象，</span><br /><span className="pl pl-1">降生为人的样子。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:18; 希伯来书 12:2; 罗马书 5:19"> <span className="pl pl-1">祂以人的样子出现后，</span><br /><span className="pl pl-1">就自愿卑微，顺服至死，</span><br /><span className="pl pl-1">而且死在十字架上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:16; 马太福音 28:18; 彼得前书 3:22"> <span className="pl pl-1">因此，上帝将祂升为至尊，</span><br /><span className="pl pl-1">赐给祂超乎万名之上的名，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 45:23–25; 马太福音 28:18; 启示录 5:13–14"> <span className="pl pl-1">使一切天上的、</span><br /><span className="pl pl-1">地上的和地底下的，</span><br /><span className="pl pl-1">无不屈膝跪拜在耶稣的名下，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 4:15; 罗马书 14:11; 约翰福音 13:13"> <span className="pl pl-1">无不口称耶稣基督是主，</span><br /><span className="pl pl-1">将荣耀归于父上帝。</span></span>
</div>
</div>

## 暗世明灯

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得后书 1:5–10; 路加福音 13:23–24; 哥林多前书 15:58"> 所以，我亲爱的弟兄姊妹，你们一向都很顺服，不只是当着我的面时才顺服，我不在时你们更加顺服，要战战兢兢地活出你们的救恩。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:21; 哥林多后书 3:5; 提摩太后书 1:9"> 因为你们立志和行事都是上帝在你们心中工作，为要成就祂美好的旨意。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:9; 哥林多前书 10:10; 腓立比书 2:3"> 无论做什么事，都不要抱怨，也不要与人争论，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:14–16; 彼得前书 2:12; 马太福音 5:45"> 好使你们在这个扭曲乖谬的时代中清白无过，做上帝纯洁无瑕的儿女，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记32:5。">a</a></sup>如同明光照耀在世上，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 9:26; 加拉太书 2:2; 约翰一书 1:1"> 坚守生命之道。这样，到了基督再来的时候，我可以夸口自己没有空跑一场，也没有白费功夫。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 4:6; 罗马书 15:16; 希伯来书 13:15–16"> 你们的信心就是献给上帝的祭物，即使在上面浇奠我的生命，我也很喜乐，并且和大家一同喜乐。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:2–4; 腓立比书 4:4; 腓立比书 3:1"> 同样，你们也要喜乐，要和我一同喜乐。</span>
</div>
</div>

## 保罗的得力同工

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:17; 帖撒罗尼迦前书 3:6–8; 帖撒罗尼迦前书 3:2"> 靠着主耶稣，我希望尽快派提摩太去你们那里，好知道你们的近况，使我也感到欣慰。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 2:2; 哥林多前书 16:10; 腓立比书 2:22"> 因为没有人像他那样跟我一同真正关心你们的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:24; 马太福音 16:24; 腓立比书 2:4"> 别人都只顾自己的事，不顾耶稣基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 4:17; 哥林多后书 2:9; 提摩太后书 1:2"> 但你们知道提摩太的为人，他与我在福音事工上一起服侍，情同父子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 22:3; 腓立比书 2:19"> 所以，我的案子一旦明朗了，我会立刻派他去见你们。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰三书 1:14; 腓利门书 1:22; 腓立比书 1:25–26"> 我靠主深信自己很快也会去你们那里。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:18; 腓利门书 1:1–2; 腓立比书 4:3"> 另外，我觉得有必要让以巴弗提回到你们那里。他是我的弟兄、同工和战友，也是你们差遣来服侍我、供应我需用的。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 箴言 12:25; 以弗所书 3:13"> 他很想念你们各位，并且感到不安，因为你们听说了他患病的事。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:19; 腓立比书 2:30; 诗篇 103:3–4"> 他确实病了，几乎丧命，但上帝怜悯了他，不但怜悯他，也怜悯了我，没让我忧上加忧。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:22; 提摩太后书 1:4; 腓立比书 2:26–27"> 所以，我想尽快派他回去与你们相聚，好让你们喜乐，也可以减少我的挂虑。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒罗尼迦前书 5:12; 哥林多前书 16:18; 提摩太前书 5:17"> 你们要在主里欢欢喜喜地接待他，而且要敬重像他这样的人，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 16:17; 使徒行传 20:24; 腓立比书 4:10"> 因为他冒着生命危险弥补你们服侍我的不足之处，为了基督的工作几乎丧命。</span>
</div>
</div>

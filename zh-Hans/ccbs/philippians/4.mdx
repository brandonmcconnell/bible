## 保罗的劝勉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 1:27; 哥林多前书 16:13; 诗篇 27:14"> 我所亲爱、所想念的弟兄姊妹，你们就是我的喜乐和冠冕。我亲爱的弟兄姊妹，你们要靠主坚定不移。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 12:14; 哥林多前书 1:10; 马可福音 9:50"> 我恳求友阿蝶和循都姬要在主里同心。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:5; 启示录 13:8; 路加福音 10:20"> 信实的同工啊，请你帮助她们二人，因为她们曾与我、革利免和其他同工一起为福音辛劳，这些人的名字都在生命册上。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:16–18; 罗马书 12:12; 雅各书 1:2–4"> 你们要靠主常常喜乐！我再说，你们要喜乐！</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:8–9; 马太福音 6:25; 提多书 3:2"> 要让众人都知道你们是谦和宽容的人。主快来了。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 3:5–6; 彼得前书 5:7; 马太福音 6:25–33"> 你们应该一无挂虑，凡事要借着祷告和祈求，怀着感恩把你们的需要告诉上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:27; 以赛亚书 26:3; 帖撒罗尼迦后书 3:16"> 这样，上帝那超越人所能理解的平安必在基督耶稣里保守你们的心思意念。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:17; 提多书 2:7; 罗马书 12:9–21"> 最后，弟兄姊妹，你们要思想一切真实、可敬、公义、纯洁、可爱、有好名声、有美德和值得赞许的事情。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:22; 腓立比书 3:17; 帖撒罗尼迦前书 4:1–8"> 你们从我身上学习、领受、看到和听到的，都要付诸实践。这样，赐平安的上帝就必与你们同在。</span>
</div>
</div>

## 致谢

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 11:9; 加拉太书 6:6; 哥林多后书 7:6–7"> 我靠主非常喜乐，因为你们现在又一次关心我。其实你们向来都很关心我，只是没有机会。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:6–9; 希伯来书 13:5–6; 马太福音 6:31–34"> 我并非因为缺乏才这样说，因为我已经学会在任何处境中都能知足。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 11:29; 哥林多后书 12:7–10; 哥林多后书 11:27"> 我知道如何过贫穷的日子，也知道如何过富足的日子。我学到了秘诀，不论饱足或饥饿，丰裕或缺乏，在任何情况下都可以处之泰然。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 41:10; 哥林多后书 12:9–10; 歌罗西书 1:11"> 靠着赐我力量的那位，我凡事都能做。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:16; 腓立比书 1:7; 希伯来书 10:34"> 然而，你们与我共患难，真是美好。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:5; 哥林多后书 11:8–12; 使徒行传 16:40–5"> 腓立比人啊！你们也知道，在我离开马其顿传福音的初期，除了你们以外，没有别的教会供应我的需要。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:9; 使徒行传 17:1; 帖撒罗尼迦前书 2:18"> 即使我在帖撒罗尼迦的时候，你们也不止一次供应过我的需要。</span>
<span className="v" id="v17" data-v="17" data-xref="提多书 3:14; 希伯来书 6:10; 哥林多后书 9:9–13"> 我不求得到馈赠，只求有更多成果归在你们账上。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 腓立比书 4:12; 哥林多后书 9:12"> 我现在样样都有，丰富有余。我从以巴弗提手上收到了你们送给我的礼物，已经充足了。这些馈赠是蒙上帝悦纳的馨香祭物。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 9:8–11; 诗篇 84:11; 彼得前书 5:10"> 我的上帝必按照祂在基督耶稣里的荣耀，丰丰富富地赐给你们所需用的一切。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 11:36; 诗篇 115:1; 启示录 14:7"> 愿荣耀归给我们的父上帝，直到永永远远。阿们！</span>
</div>
</div>

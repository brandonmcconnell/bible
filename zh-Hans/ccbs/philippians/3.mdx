## 认识基督最宝贵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 5:11; 腓立比书 4:4; 雅各书 1:2"> 此外，弟兄姊妹，你们要靠主喜乐！我再把这些事写给你们，对我来说并不麻烦，对你们却是保障。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 11:13; 提多书 1:16; 启示录 22:15"> 你们要提防那些犬类，提防那些作恶的人，提防那些鼓吹必须受割礼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“割礼”参见创世记17章；希腊文用夸张的字眼描述割礼，有讽刺之意。">a</a></sup>才能得救的人。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:11; 申命记 30:6; 罗马书 7:6"> 因为真正受割礼的人是我们这些靠着上帝的灵敬拜、以基督耶稣为荣、不倚靠自身条件的人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 11:18–22"> 其实我也可以靠自身的条件。如果别人觉得可以靠自身的条件，我更可以。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:22; 罗马书 11:1; 使徒行传 23:6"> 我出生后第八天就受了割礼，我是以色列人，属于便雅悯支派，是地地道道的希伯来人。论守律法，我是法利赛人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:13–14; 使徒行传 8:3; 使徒行传 26:9–10"> 论热心，我曾经迫害教会；论律法要求的义，我是无可指责的。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 马太福音 16:26; 马太福音 13:44–46"> 但是为了基督，我从前以为有价值的，现在认为毫无价值。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 9:23–24; 罗马书 8:18; 腓立比书 3:7"> 不但如此，我看万事都毫无价值，因为认识我主基督耶稣是最宝贵的。我为祂失去了一切，我把失去的一切视为粪土，好得到基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:21; 哥林多前书 1:30; 加拉太书 2:16"> 与祂联合。我并非拥有源于律法的义，而是拥有信靠基督而得的义。这义从上帝而来，以信为基础。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 2:20; 罗马书 8:17; 彼得前书 4:1–2"> 我渴望认识基督和祂复活的大能，与祂一同受苦，甚至到死的地步<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“甚至到死的地步”或译“效法祂的死”。">b</a></sup>，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 启示录 20:5; 使徒行传 23:6"> 这样我无论如何都可以从死里复活。</span>
</div>
</div>

## 直奔标竿

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 6:11–12; 彼得后书 1:5–8; 诗篇 138:8"> 这并不是说我已经得到了或者纯全了，我还要竭力追求，或许可以达到基督耶稣要我达到的目标。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯来书 12:1–2; 腓立比书 3:12"> 弟兄姊妹，我并非以为自己已经得到了，我只专注一件事，就是忘记背后，努力向前，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:24; 彼得前书 5:10; 启示录 3:21"> 直奔目标，要赢得上帝借着基督耶稣从天上呼召我去得的奖赏。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 7:17; 雅各书 1:4–5; 箴言 2:3–6"> 我们中间成熟的基督徒都应该有这样的看法。即使你们有什么不同看法，上帝也必让你们明白。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:6; 启示录 3:3; 启示录 2:4–5"> 然而，我们长进到什么程度，就照着什么程度去行。</span>
<span className="v" id="v17" data-v="17" data-xref="腓立比书 4:9; 哥林多前书 4:16; 彼得前书 5:3"> 弟兄姊妹，你们要一同效法我，也要向那些以我们为榜样的人学习。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 4:17; 以赛亚书 8:11; 加拉太书 6:12"> 我已经多次告诉你们，现在又流着泪提醒你们：有许多人行事为人与基督的十字架为敌。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 16:18; 罗马书 8:5–7; 彼得后书 2:3"> 他们的神就是自己的肚腹，他们以自己的羞耻为荣，只想着地上的事，他们的结局是灭亡。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 2:19; 歌罗西书 3:1–3; 哥林多后书 4:18–1"> 我们却是天上的国民，热切等候从天降临的救主，就是主耶稣基督。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 3:2; 歌罗西书 3:4; 哥林多前书 15:42–56"> 那时，祂要以降服万物的大能将我们这卑贱的躯体改变成像祂那样荣耀的身体。</span>
</div>
</div>

## 上帝呼召摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 19:8; 出埃及记 17:6; 诗篇 78:70–72"> 摩西为岳父米甸祭司叶特罗放羊。一天他领着羊群穿越旷野，来到上帝的山——何烈山。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:30–35; 以赛亚书 43:2; 马可福音 12:26"> 忽然有耶和华的天使在荆棘的火焰中向他显现。摩西看见荆棘虽然在燃烧，却没有被烧毁。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:31; 诗篇 107:8; 约伯记 37:14"> 摩西想：“我要过去看这个奇异的景象，荆棘为什么没有被烧掉呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 33:16; 撒母耳记上 3:6; 使徒行传 9:4"> 耶和华上帝见他要上前观看，就从荆棘丛中呼唤他说：“摩西！摩西！”摩西说：“我在这里。”</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:15; 使徒行传 7:33; 出埃及记 19:12"> 上帝说：“别再靠近，脱下你脚上的鞋，因为你所站的地方是圣地。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:37; 马太福音 22:32; 出埃及记 4:5"> 又说：“我是你祖先的上帝，是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。”摩西害怕看上帝，就把脸蒙起来。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:19; 诗篇 106:44; 出埃及记 2:23–25"> 耶和华说：“我已经看见我子民在埃及所受的苦难，听见了他们因监工的压迫而发出的呼求。我知道他们的痛苦。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 50:24; 创世记 15:18–21; 出埃及记 3:17"> 我下来是要从埃及人手中救他们，带他们离开那里，到一个辽阔肥沃的奶蜜之乡，就是现在迦南人、赫人、亚摩利人、比利洗人、希未人和耶布斯人居住的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 22:22–23; 出埃及记 2:23; 出埃及记 1:13–14"> 现在，以色列人的呼求传到我耳中，我也看到了埃及人怎样压迫他们。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:4; 撒母耳记上 12:6; 诗篇 105:26"> 现在去吧，我要派你到法老那里，带我的以色列子民出埃及。”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 18:18; 哥林多后书 3:5; 出埃及记 6:12"> 但摩西对上帝说：“我是谁啊？怎么能去见法老，带以色列人出埃及呢？”</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 罗马书 8:31; 以赛亚书 41:10"> 上帝说：“我必与你同在，你带百姓出埃及后，你们必在这座山上事奉我——这将是我派你去的证据。”</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 以赛亚书 9:6; 耶利米书 23:6"> 摩西问上帝：“假如我到以色列人那里，对他们说，‘你们祖先的上帝派我来你们这里。’他们如果问我，‘祂叫什么名字？’我该怎样回答他们呢？”</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:58; 希伯来书 13:8; 启示录 1:8"> 上帝对摩西说：“我是自有永有者。你要这样回答以色列人，‘那位自有永有者派我到你们这里。’”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:7–8; 希伯来书 13:8; 玛拉基书 3:6"> 上帝又对摩西说：“你要告诉以色列人是我派遣你到他们那里，我是他们祖先的上帝耶和华，是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。耶和华是我的名字，直到永远，世世代代的人都要这样称呼我。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:4; 出埃及记 4:31; 出埃及记 4:29"> 你去招聚以色列的长老，对他们说，‘你们祖先的上帝耶和华，就是亚伯拉罕、以撒、雅各的上帝向我显现，说祂关切你们，知道你们在埃及的遭遇。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:13–21; 创世记 50:24; 创世记 46:4"> 祂应许要带领你们脱离在埃及所受的苦难，到迦南人、赫人、亚摩利人、比利洗人，希未人和耶布斯人住的地方，那里是奶蜜之乡。’</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:1; 出埃及记 7:16; 出埃及记 10:24–26"> 以色列的长老们必定听从你的话，你就跟他们一起去见埃及王，对他说，‘希伯来人的上帝耶和华向我们显现。现在请你容许我们走三天的路程，到旷野去，向我们的上帝耶和华献祭。’</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 5:2; 出埃及记 6:1; 出埃及记 7:1–14"> 我也知道除非我用大能的手向他施压，不然埃及王不会让你们离开。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:36; 尼希米记 9:10; 出埃及记 9:15"> 因此，我必伸手行各种神迹攻击埃及，之后他必让你们离开。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:36; 诗篇 105:37; 出埃及记 11:3"> 我必使埃及人恩待你们，好叫你们不致空手离开埃及。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 39:10; 出埃及记 11:2; 出埃及记 12:35–36"> 你们的妇女只管向埃及邻居及住在邻居家的妇女索取金器、银器和衣服，给自己的儿女穿戴，你们必这样夺取埃及人的财物。”</span>

## 赔偿条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 19:8; 撒母耳记下 12:6; 箴言 6:31"> “倘若有人偷了别人的牛羊，然后宰了或卖了，他要用五头牛抵偿一头牛，四只羊抵偿一只羊。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 24:43; 马太福音 6:19–20; 民数记 35:27"> 倘若有人打死正入屋偷窃的贼，这人不算犯杀人罪。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 21:2; 以赛亚书 50:1; 马太福音 18:25"> 倘若事情发生在白天，家主就犯了杀人罪。倘若盗贼被擒，他就要赔偿家主，若他一无所有，就要把他卖为奴隶作赔偿。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 22:7; 出埃及记 22:1; 出埃及记 22:9"> 倘若他偷的牲畜如牛、羊或驴在他手上还活着，他要偿还失主双倍。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:3; 出埃及记 22:12; 约伯记 20:18"> “倘若有人在田野或葡萄园里牧放牲畜，任由牲畜吃别人田里的农作物或葡萄，他必须拿自己田里最好的农作物或葡萄作赔偿。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:9; 出埃及记 21:33–34; 撒母耳记下 14:30–31"> 倘若田间起火，烧着荆棘，以致烧掉了别人的庄稼、禾捆或整个田园，那点火的人就要赔偿一切损失。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 22:4; 箴言 6:30–31; 耶利米书 2:26"> “倘若有人把金钱或物件交给邻居保管，结果在邻居家遭盗，盗贼被缉拿归案后要赔偿双倍；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 22:28; 申命记 16:18; 出埃及记 21:6"> 倘若没捉到盗贼，邻居就要到审判官那里证明自己没有偷拿。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 25:1; 出埃及记 22:4; 民数记 5:6–7"> 倘若二人之间有什么纠纷，无论是为了牛、驴、羊、衣服或任何失物，争执的双方要把案件呈报审判官，审判官判谁败诉，谁就要赔偿双倍。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 12:48; 提摩太后书 1:12; 路加福音 16:11"> 倘若有人把驴、牛、羊或别的牲畜交给邻居看管，牲畜死伤或被人抢走，并且无人看见，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:16; 利未记 5:1; 列王纪上 2:42–43"> 看守的人就要在耶和华面前起誓没有动邻居的东西，这样失主就应当作罢，看守的人不用赔偿。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:39; 出埃及记 22:7"> 但倘若牲畜是被人偷去的，受托人就要赔偿失主。</span>
<span className="v" id="v13" data-v="13" data-xref="那鸿书 2:12; 弥迦书 5:8; 以西结书 4:14"> 倘若牲畜被野兽撕碎，受托人要把残骸带来当证据，无需赔偿被撕碎的牲畜。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 23:19–20; 出埃及记 21:34; 申命记 15:2"> 倘若有人向邻居借牲畜，牲畜受伤或死掉，而当时物主不在场，借的人就要赔偿。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 8:10"> 倘若物主当时在场，借的人就不用赔偿。倘若牲畜是租来的，租的人只需付租金不用赔偿。</span>
</div>
</div>

## 社会条例

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 22:28–29; 创世记 34:2–4"> “倘若有人诱奸了尚未许配的处女，他就要交出聘礼，娶她为妻；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 34:12; 撒母耳记上 18:25; 申命记 22:29"> 倘若女方家长反对婚事，男方要付出与聘礼等额的金钱给女方家长。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 20:27; 申命记 18:10–11; 撒母耳记上 28:3"> “凡行邪术的女人，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 18:23; 申命记 27:21; 利未记 20:15–16"> “与动物性交的人，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 17:2–5; 民数记 25:7–8; 申命记 18:20"> “献祭给耶和华以外的其他任何神明的人，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:9; 申命记 10:19; 利未记 19:33"> “不可欺压在你们中间寄居的人，因为你们在埃及也做过寄居的人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 24:17; 以赛亚书 1:17; 以赛亚书 1:23"> “不可亏待寡妇和孤儿，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 18:6; 诗篇 10:17–18; 路加福音 18:7"> 倘若你们亏待他们，他们向我呼求，我必听他们的呼求，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 109:9; 耶利米书 15:8; 诗篇 76:7"> 向你们发怒，用刀杀掉你们，使你们的妻子变为寡妇，儿女成为孤儿。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 15:5; 利未记 25:35–37; 申命记 23:19–20"> “倘若有贫苦的同胞向你借钱，你不可像放债的一样收取利息。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 20:16; 阿摩司书 2:8; 申命记 24:6"> 倘若你的邻居把衣服给你作抵押，你要在日落之前把衣服还给他。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 34:6; 历代志下 30:9; 诗篇 136:10–11"> 因为他只有这件蔽体的衣服，若是没有，他晚上如何睡觉？他若呼求我，我必垂听，因为我是仁慈的。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 23:5; 传道书 10:20; 出埃及记 22:8–9"> 不可亵渎上帝，也不可咒诅百姓的官长。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 23:16; 出埃及记 13:2; 雅各书 1:18"> 你们要向我献上五谷和新酒，不可迟延。要把你们的长子献给我。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 22:27; 申命记 15:19; 出埃及记 13:12"> 也要献上头生的牛羊，它们生下来后可以留在母亲身边七天，第八天要献给我。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 4:14; 利未记 19:2; 申命记 14:21"> 你们要做我圣洁的子民，不可吃田野间被野兽咬死的牲畜，要把它丢给狗吃。</span>
</div>
</div>

## 会幕的工匠

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 36:1; 出埃及记 35:30; 约翰福音 3:27"> “看啊，我已经亲自在犹大支派中选出户珥的孙子、乌利的儿子比撒列，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:31; 以赛亚书 28:26; 列王纪上 7:14"> 用我的灵充满他，使他有聪明智慧，精于各种技能和手艺，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 26:1; 出埃及记 25:32–35; 历代志下 2:13–14"> 能用金、银和铜制造精巧的器具，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:9–21"> 又能雕刻和镶嵌宝石，精通木工和各种手艺。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:10; 出埃及记 35:34–1; 出埃及记 28:3"> 我委派但支派亚希撒抹的儿子亚何利亚伯做他的助手。至于其他能工巧匠，我已赐给他们智慧，好照我对你的吩咐制造一切器具，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 36:8–9; 出埃及记 25:10–22; 出埃及记 26:1–37"> 即会幕、约柜和约柜上面的施恩座、会幕里面所有的器具、</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 37:10–28; 出埃及记 30:1–10; 出埃及记 25:23–40"> 桌子和桌上的器具、纯金的灯台和灯台的一切器具、香坛、</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:1–8; 出埃及记 27:1–8; 出埃及记 40:11"> 燔祭坛和坛上的一切器具、洗濯盆和盆座，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:5–14; 出埃及记 28:1–43; 出埃及记 39:1–43"> 还有精工制作的礼服，即亚伦祭司的圣衣及其众子供祭司之职时穿的礼服，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 37:29; 出埃及记 30:23–38"> 以及膏油和圣所使用的芬芳的香。他们要照我对你的吩咐去做。”</span>
</div>
</div>

## 安息日

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华对摩西说：</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:12; 以西结书 20:20; 利未记 19:30"> “你要吩咐以色列百姓务必守我的安息日，因为这是我与你们之间世世代代的记号，叫你们知道使你们圣洁的是我耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 35:2–3; 民数记 15:32–36; 以西结书 20:21"> 你们要守安息日，以它为圣日。凡不守这日的，必被处死。凡在这天工作的，必从民中被铲除。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 2:2; 出埃及记 16:23; 利未记 23:3"> 一周要工作六天，第七天是完全休息的安息日，是耶和华的圣日。凡在安息日做工的，必被处死。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 50:5; 创世记 9:13; 创世记 17:11"> 因此，以色列人世世代代都要守安息日，作为永久的约，</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:31; 出埃及记 31:13; 创世记 2:2–3"> 这是我和以色列人之间永久的记号。因为耶和华用六天的时间创造天地，在第七天停工休息。”</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 4:13; 出埃及记 32:15–16; 申命记 5:22"> 耶和华在西奈山对摩西说完这些话以后，就把自己用指头刻上诫命的两块石版交给摩西。</span>
</div>
</div>

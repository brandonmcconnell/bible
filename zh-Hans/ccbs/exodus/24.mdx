## 在西奈山立约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 11:16; 出埃及记 6:23; 利未记 10:1–2"> 耶和华又指示摩西说：“你和亚伦、拿答、亚比户及以色列的七十位长老上我这里来，远远地敬拜我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 24:15; 出埃及记 24:13; 希伯来书 10:21–22"> 只有你可以靠近我，其他百姓都不得与你一同走近。”</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:8; 出埃及记 24:7; 约书亚记 24:22"> 摩西下山把耶和华的话和法令都告诉百姓，百姓齐声回答：“我们愿意遵行耶和华的一切吩咐。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:18; 申命记 31:9; 约书亚记 4:8–9"> 摩西把耶和华的这些话记录下来。他清早起来，在山脚筑了一座坛，立了十二根柱子，代表以色列的十二支派。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:12; 利未记 3:1–17; 出埃及记 19:22"> 他又吩咐以色列的青年去给耶和华献燔祭，又献上公牛作平安祭。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 1:19; 出埃及记 24:8; 希伯来书 9:18"> 摩西把祭牲的血一半放在盆里，一半洒在坛上。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 31:11–13; 帖撒罗尼迦前书 5:27; 出埃及记 24:3–4"> 他又把约书念给百姓听，百姓听了都说：“我们愿意遵行耶和华的一切吩咐，我们愿意顺服。”</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:4–5; 出埃及记 24:6; 以西结书 36:25"> 摩西便把盆中的血洒在百姓身上，说：“这是立约的血，是耶和华按所说的话与你们立约的凭据。”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 24:1"> 之后，摩西、亚伦、拿答、亚比户及以色列的七十位长老便上了山。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:18; 以西结书 10:1; 创世记 32:30"> 他们都看见了以色列的上帝，祂的脚下好像是一片蓝宝石，像天一样明净。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 15:23–24; 出埃及记 18:12; 创世记 31:54"> 上帝没有伸手杀这些以色列的首领，允许他们看见祂，在祂面前吃喝。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 5:22; 出埃及记 31:18; 出埃及记 32:15–16"> 耶和华对摩西说：“你上山到我这里来，留在这里，我要把写着律法和诫命的石版赐给你，你可以用来教导百姓。”</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 33:11; 民数记 11:28; 出埃及记 3:1"> 于是，摩西带着他的助手约书亚动身上了上帝的山。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 17:10; 出埃及记 17:12; 创世记 22:5"> 离开之前，摩西吩咐长老说：“你们在这里等候我们回来。亚伦和户珥跟你们在一起，民中有什么诉讼的事情，可以去找他们。”</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:9; 马太福音 17:5; 出埃及记 19:16"> 摩西上了山，密云遮盖着整座山。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 16:10; 民数记 16:42; 以西结书 1:28"> 耶和华的荣耀停留在西奈山上，密云遮盖了山六天。第七天，耶和华在云中召唤摩西。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 12:29; 申命记 4:24; 出埃及记 3:2"> 在以色列人眼中，耶和华的荣耀在山上好像烈火。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 9:9; 出埃及记 34:28; 申命记 10:10"> 摩西上到山上，走进云中，在那里停留了四十昼夜。</span>

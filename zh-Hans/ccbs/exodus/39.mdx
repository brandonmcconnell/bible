## 祭司的衣服

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:10; 出埃及记 35:23; 出埃及记 35:19"> 比撒列等人按照耶和华对摩西的吩咐，用蓝色、紫色、朱红色毛线精工制作在圣所供职时穿的礼服，又为亚伦做圣衣。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:6–12; 利未记 8:7; 出埃及记 25:7"> 他们用金线、细麻及蓝色、紫色、朱红色毛线精工制作以弗得，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:8; 出埃及记 26:1"> 把金子打成薄片，剪成细线，与细麻和蓝色、紫色、朱红色毛线巧妙地织在一起。</span>
<span className="v" id="v4" data-v="4"> 他们做了两条肩带，固定在以弗得两边，用来连接以弗得。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:13; 马太福音 28:20; 以赛亚书 11:5"> 又按耶和华对摩西的吩咐，照以弗得的做法用金线、细麻及蓝色、紫色、朱红色毛线精工制作腰带，缝在以弗得上。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 28:9; 以西结书 28:13; 约伯记 28:16"> 他们选了两块红玛瑙，用刻图章的方法刻上以色列十二个儿子的名字，镶在两个金框里，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:7; 出埃及记 28:12; 出埃及记 28:29"> 再缝在以弗得的两条肩带上，作以色列人的纪念石。这些都是照耶和华对摩西的吩咐做的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:4; 利未记 8:8–9; 以赛亚书 59:17"> 他们精工制作胸牌，像造以弗得一样用金线、细麻及蓝色、紫色、朱红色毛线制作。</span>
<span className="v" id="v9" data-v="9"> 胸牌是方形的，叠成两层，长宽各二十二厘米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:21; 出埃及记 28:16–17; 启示录 21:19–21"> 上面镶上四行宝石：第一行是红宝石、黄玉和翠玉；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 28:18; 以西结书 28:13"> 第二行是绿宝石、蓝宝石和金刚石；</span>
<span className="v" id="v12" data-v="12"> 第三行是紫玛瑙、白玛瑙和紫晶；</span>
<span className="v" id="v13" data-v="13"> 第四行是水苍玉、红玛瑙和碧玉。这些宝石都镶在胸牌的金框上。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:12"> 他们用刻图章的方法在每一颗宝石上刻一个以色列儿子的名字，十二颗宝石代表以色列十二支派。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:28; 约翰福音 17:12; 彼得前书 1:5"> 他们用纯金拧成两条像绳子一样的链子，连在胸牌上，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:12"> 又造两个金框和两个金环，把金环安在胸牌两端。</span>
<span className="v" id="v17" data-v="17"> 把两条金链分别系在胸牌两端的金环上，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 雅歌 1:10"> 又把两条金链的另两端接在两个金框上，安在以弗得前面的肩带上。</span>
<span className="v" id="v19" data-v="19"> 又造了两个金环，安在靠近以弗得内边的胸牌下两端。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 26:3"> 又造了两个金环，安在以弗得前面两条肩带下端，靠近精致的以弗得腰带上方的接缝处。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 16:24; 哥林多前书 1:25; 哥林多前书 1:27"> 用一条蓝色的带子系住以弗得和胸牌上面的金环，使胸牌贴在精工织成的以弗得腰带上，不会从以弗得上松脱。这些都是照耶和华对摩西的吩咐做的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:31–35"> 以弗得的外袍用纯蓝色的线织成，</span>
<span className="v" id="v23" data-v="23"> 上面有领口，领口周围织领边，就像铠甲上的领口，免得领口破裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 28:33; 加拉太书 5:22"> 外袍的底边用细麻和蓝色、紫色、朱红色毛线做成石榴状的饰物，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 28:33–34; 雅歌 4:13; 诗篇 89:15"> 又造纯金的铃铛挂在外袍底边的石榴间，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 28:34; 雅歌 4:13; 雅歌 6:7"> 一个石榴一个金铃铛，相间排列，围在外袍的底边。这件外袍是祭司供职时穿的，正如耶和华对摩西的吩咐。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 44:18; 彼得前书 1:13; 以赛亚书 61:10"> 他们用细麻布为亚伦父子们缝制内袍、</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:4; 以西结书 44:18; 出埃及记 28:39"> 礼冠、头巾和裤子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 28:39"> 还用细麻和蓝色、紫色、朱红色毛线绣制腰带。这是照耶和华对摩西的吩咐做的。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 5:10; 希伯来书 7:26; 希伯来书 1:3"> 又用纯金造了牌子，就是圣冠，上面用刻印章的方法刻上“耶和华的圣物”的字样，</span>
<span className="v" id="v31" data-v="31"> 然后用一条蓝色带子把它系在礼冠上。这些都是照耶和华对摩西的吩咐做的。</span>
</div>
</div>

## 圣幕完工

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 39:42–43; 马太福音 28:20; 出埃及记 25:40"> 圣幕，就是会幕的工作就这样全部完成了，都是以色列人照耶和华对摩西的吩咐做的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 35:11–19; 出埃及记 31:7–11; 出埃及记 36:1–38"> 他们把圣幕和圣幕的各样器具都送到摩西那里，即钩子、木板、横闩、柱子和带凹槽的底座；</span>
<span className="v" id="v34" data-v="34"> 海狗皮顶盖、遮掩约柜的幔子、染成红色的公羊皮盖；</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:5; 出埃及记 25:17; 希伯来书 9:8"> 约柜、抬约柜的横杠、施恩座；</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:30; 列王纪上 7:48"> 桌子、桌上的一切器具和供饼；</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比书 2:15; 出埃及记 27:21; 马太福音 5:14–16"> 纯金的灯台、灯盏、灯台的一切器具、灯油；</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:7; 出埃及记 37:29; 出埃及记 30:3"> 金坛、膏油、芬芳的香；会幕的门帘；</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 8:64; 出埃及记 38:30"> 铜祭坛、祭坛的铜网、抬祭坛的横杠、祭坛用的一切器具、洗濯盆和盆座；</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 27:9–16"> 院子的帷幔、柱子、带凹槽的底座、院子入口的门帘、绳子、橛子和会幕，即圣幕所需的一切器具；</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 28:2; 出埃及记 31:10; 出埃及记 39:1"> 在圣所供职时穿的精制礼服、亚伦祭司的圣衣及其众子供祭司之职时穿的衣服。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 35:10; 出埃及记 23:21–22; 提摩太后书 2:15"> 这一切都是以色列人照耶和华对摩西的吩咐做的。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 6:23–27; 利未记 9:22–23; 撒母耳记下 6:18"> 摩西察看这一切工作，见他们都是按照耶和华的吩咐做的，就给他们祝福。</span>
</div>

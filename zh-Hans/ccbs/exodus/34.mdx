## 新的约版

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 32:19; 出埃及记 31:18; 诗篇 119:89"> 耶和华对摩西说：“你要凿出两块石版，跟你之前摔碎的两块一样，我要把前两块石版上的字刻在上面。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:20; 申命记 9:25; 出埃及记 19:11"> 明天清早你要预备好，你要上西奈山顶来见我。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:12–13; 出埃及记 19:21; 提摩太前书 2:5"> 谁也不可与你同来，整座山上都不可有人，就是牛羊也不得在山前吃草。”</span>
<span className="v" id="v4" data-v="4"> 于是，摩西凿出两块石版，与前两块一样。他清早起来，照着耶和华的吩咐拿着两块石版上了西奈山。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 33:19; 民数记 11:25; 路加福音 9:34–35"> 耶和华在云中降临和摩西一同站在那里，宣告祂的名耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 86:15; 约珥书 2:13; 诗篇 103:8–13"> 耶和华在摩西面前经过，并且宣告说：“我是耶和华，我是耶和华，是有怜悯和恩典的上帝，不轻易发怒，充满慈爱，无比信实，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:5–6; 诗篇 103:3; 申命记 5:9–10"> 向千万代彰显慈爱，赦免罪愆、过犯和罪恶，但决不免除罪责，必向子孙追讨父辈的罪债，直到三四代。”</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:31; 历代志下 20:18; 创世记 17:3"> 摩西急忙俯伏在地上敬拜，</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 33:12; 申命记 32:9; 诗篇 94:14"> 说：“主啊，如果我在你面前蒙了恩，求你与我们同行。虽然百姓顽固不化，求你赦免我们的过犯和罪恶，接纳我们做你的产业。”</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 10:21; 诗篇 77:14; 以赛亚书 64:3"> 耶和华说：“我要与你立约，我要在你所有的百姓面前行奇事，是天下万国从未有过的奇事，你周围的外族人必看见我为你做的可畏之事。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:2; 出埃及记 3:17; 出埃及记 3:8"> 你要遵行我今天的吩咐。我必从你面前赶走亚摩利人、迦南人、赫人、比利洗人、希未人和耶布斯人。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:32–33; 约书亚记 23:12–13; 申命记 7:2"> 你要谨慎，到了目的地后，不可与当地的居民立约，免得因此而陷入网罗。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:4; 出埃及记 23:24; 申命记 7:25–26"> 相反，要拆掉他们的祭坛，打碎他们的神柱，砍下他们的亚舍拉神像。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 4:24; 申命记 32:21; 哥林多前书 10:22"> 不可拜别的神明，因为耶和华是痛恨不贞的上帝，祂名为‘痛恨不贞’。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 2:17; 诗篇 106:28; 民数记 25:2"> “不可与当地的居民立约，免得他们与自己的神明苟合献祭时邀请你，你就吃他们的祭物，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 7:3–4; 列王纪上 11:2–4; 以斯拉记 9:2"> 给儿子娶他们的女儿为妻，以致她们与自己的神明苟合时诱使你的儿子犯同样的罪。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 19:4; 出埃及记 32:8; 以赛亚书 46:6–7"> “不可为自己铸造神像。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 13:4; 利未记 23:6; 出埃及记 13:6–7"> “要守除酵节，照我的吩咐在亚笔月所定的时间吃七天的无酵饼，因为你是在亚笔月离开埃及的。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 22:29; 出埃及记 13:12"> “凡是头胎生的都属于我，包括牲畜中一切头胎生的公牛和公羊。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:13; 出埃及记 23:15; 申命记 16:16"> 头胎生的驴要用羊赎回，如果不用羊赎回，就要打断它的脖子。凡头胎生的男婴，都要赎回他的性命。谁也不可空手来朝见我。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:12; 申命记 21:4; 路加福音 13:14"> “一周工作六天，第七天要休息，就是耕种和收割时也要休息。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:16; 申命记 16:10–15; 约翰福音 7:2"> “在收割初熟麦子的时候，要守七七收获节，年底要守收藏节。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:14; 申命记 16:16; 出埃及记 23:17"> 所有的男子都要每年三次朝见主耶和华——以色列的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:55; 出埃及记 33:2; 箴言 16:7"> 我要从你面前赶走外族人，扩张你的领土。你一年三次朝见你的上帝耶和华时，必没有人贪恋你的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 23:18; 出埃及记 12:10; 哥林多前书 5:7–8"> “不可把祭牲的血和有酵的饼一起献给我，也不可把逾越节的祭物留到早晨。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:19; 申命记 14:21; 申命记 26:2"> “要把田中最好的初熟之物送到你们的上帝耶和华的殿中。 “不可用母山羊的奶煮它的小羊羔。”</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 24:4; 申命记 31:9; 申命记 4:13"> 耶和华又对摩西说：“你要把我说的这些话记录下来，因为我要按这些话跟你和以色列人立约。”</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 34:1; 出埃及记 24:18; 申命记 9:18"> 摩西在耶和华那里待了四十昼夜，不吃也不喝。耶和华把约的内容，就是十条诫命，写在石版上。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 17:2; 路加福音 9:29; 出埃及记 32:15"> 摩西手里拿着两块约版下西奈山，他不知道自己因为曾与耶和华说话而脸上发光。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:3; 路加福音 5:8; 民数记 12:8"> 亚伦和所有的以色列百姓看见摩西脸上发光，都不敢走近他。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:15; 出埃及记 24:1–3; 创世记 45:3"> 摩西召他们过来，亚伦和会众的首领便上前来。摩西与他们说话。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 22:14; 出埃及记 24:3; 马太福音 28:20"> 之后，所有的以色列人都来到他面前，他就把耶和华在西奈山上的吩咐都告诉他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 4:4–6; 哥林多后书 3:13–18; 罗马书 10:4"> 说完之后，他就用帕子遮住自己的脸。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 3:16; 希伯来书 10:19–22; 希伯来书 4:16"> 他每次进到会幕跟耶和华说话时，就揭开帕子，出来后便把耶和华的吩咐告诉以色列百姓。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 34:29–30; 约翰福音 5:35; 但以理书 12:3"> 百姓看到他脸上发光，他就再用帕子遮住脸，直到下次进去与耶和华说话的时候才揭开。</span>

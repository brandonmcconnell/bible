## 金牛犊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:40; 申命记 9:9; 出埃及记 24:18"> 百姓见摩西迟迟没有下山，就聚集到亚伦那里，对他说：“带我们出埃及的那个摩西不知怎样了，你给我们造神像来带领我们吧。”</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 8:24–27; 出埃及记 12:35–36; 以西结书 16:17"> 亚伦对他们说：“你们去摘下妻子、儿女的金耳环，拿来给我。”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 46:6; 以赛亚书 40:19–20; 耶利米书 10:9"> 百姓就都摘下金耳环交给亚伦。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:18; 申命记 9:16; 列王纪上 12:28"> 亚伦接过这些金耳环，用它们铸造了一头牛犊。他们说：“以色列人啊，这就是带你们出埃及的神明。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 10:20; 利未记 23:2; 利未记 23:37"> 亚伦见状便在牛犊前面筑了一座坛，然后宣告说：“明天是耶和华定的节期。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:7; 民数记 25:2; 使徒行传 7:41–42"> 第二天清晨，百姓都上前来献燔祭和平安祭，献完祭后就坐下吃喝，起来狂欢。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:11; 何西阿书 9:9; 士师记 2:19"> 耶和华对摩西说：“你下山吧，你的百姓，就是你从埃及领出来的那些人已经败坏了。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 出埃及记 20:23; 出埃及记 20:3–4"> 他们这么快就偏离了我吩咐他们走的道路，为自己造了一头牛犊来叩拜献祭，说，‘以色列人啊，这就是带你们出埃及的神明。’”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:51; 申命记 9:13; 以赛亚书 48:4"> 耶和华又说：“我看到了，这些百姓真是顽固不化。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:14; 民数记 14:12; 申命记 9:19"> 你不要阻止我，我要向他们发烈怒，毁灭他们。我要使你成为大国。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 9:18–20; 申命记 9:26–29; 诗篇 106:23"> 摩西恳求他的上帝耶和华说：“耶和华啊，你为什么要向你的子民发烈怒呢？这些子民是你亲自用神迹和大能从埃及领出来的。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 14:13–16; 申命记 9:28; 约书亚记 7:9"> 难道你要让埃及人议论说你领他们出来是出于恶意，是为了在山野之间杀掉他们，从地上灭绝他们吗？求你息怒，施怜悯，不要降祸给你的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 6:13; 创世记 12:7; 创世记 22:16"> 求你顾念你的仆人亚伯拉罕、以撒和以色列，你曾凭自己向他们起誓说，‘我必使你们的后代像天上的星星那么多。我应许给你们后代的这整片土地，我必赐给他们作永远的产业。’”</span>
<span className="v" id="v14" data-v="14" data-xref="约拿书 3:10; 诗篇 106:45; 耶利米书 26:13"> 耶和华听了摩西的话，就施怜悯，不把所说的灾祸降在百姓身上。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 9:15; 出埃及记 40:20; 申命记 5:22"> 摩西转身下山，手里拿着两块约版，约版的正反两面都有字。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:1"> 石版是上帝做的，字是上帝刻的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:13; 出埃及记 17:9; 约书亚记 6:20"> 约书亚听见山下百姓嘈杂的喊叫声，便对摩西说：“营地里有打仗的声音。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 15:1–18; 但以理书 5:4; 但以理书 5:23"> 摩西对他说：“这不是打胜仗的声音，也不是打败仗的声音，而是歌唱的声音。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 9:16–17; 耶利米书 31:32; 耶利米哀歌 5:15"> 摩西走近营地的时候，看见牛犊，又看见百姓在跳舞，心中大怒，便把手上的两块石版摔碎在山脚下，</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 9:21; 列王纪下 23:6; 列王纪下 23:15"> 又焚烧他们铸造的牛犊，把它磨成粉末撒在水面上，叫以色列百姓喝。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 20:9; 约书亚记 7:19–26; 列王纪上 21:22"> 摩西对亚伦说：“这些百姓对你做了什么？你竟使他们陷入大罪中！”</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 9:24; 出埃及记 15:24; 出埃及记 16:20"> 亚伦回答说：“求我主不要动怒，你知道这些人专门作恶。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 32:1–4; 出埃及记 32:8"> 他们对我说，‘为我们造神明来带领我们吧，因为带我们出埃及的那个摩西不知怎样了。’</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 32:4; 路加福音 10:29; 罗马书 3:10"> 于是，我吩咐他们摘下金耳环给我，我把这些金耳环扔进火里，这头牛犊就出来了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:3; 弥迦书 1:11; 启示录 16:15"> 摩西见百姓放肆，亚伦纵容他们，使他们成为敌人的笑柄，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 9:32; 马太福音 12:30; 撒母耳记下 20:11"> 便站在营门口对会众说：“凡跟从耶和华的，都站到我这边来。”所有的利未人都聚集到摩西身边。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 25:5; 路加福音 14:26; 申命记 33:8–9"> 摩西对他们说：“以色列的上帝耶和华这样说，‘你们各人带着刀，从这个门到那个门，走遍整个营，不论遇见的是兄弟、伙伴还是邻居，只管杀他们。’”</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:9; 玛拉基书 2:4–6; 哥林多前书 10:8"> 利未人便照摩西的话去做。那一天，约有三千人被杀。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 25:11–13; 马太福音 10:37; 撒迦利亚书 13:3"> 摩西对利未人说：“今天你们已经把自己奉献给耶和华了，因为你们大义灭亲，祂今天必赐福给你们。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 12:20; 民数记 25:13; 列王纪下 17:21"> 第二天，摩西对百姓说：“你们犯了大罪，我现在要到耶和华那里，也许可以为你们赎罪。”</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 20:23; 但以理书 9:11; 但以理书 9:8"> 摩西回到耶和华那里，说：“唉，百姓犯了大罪，用金子为自己造了神像。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 69:28; 罗马书 9:3; 启示录 21:27"> 恳求你赦免他们的罪，不然请你从你的册子上抹掉我的名字吧。”</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 29:20; 以西结书 18:4; 启示录 20:12"> 耶和华对摩西说：“谁得罪我，我就从我的册子上抹掉谁的名字。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 23:20; 申命记 32:35; 马太福音 23:35"> 你现在回去带领这些百姓，往我指示你的地方去，我的天使必在你前面引路。只是到我惩罚的日子，我必因他们的罪惩罚他们。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:41; 出埃及记 32:25; 撒母耳记下 12:9–10"> 耶和华击杀百姓，是因为他们曾与亚伦一起造牛犊。</span>
</div>
</div>

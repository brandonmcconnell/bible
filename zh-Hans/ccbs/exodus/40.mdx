## 支起会幕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 26:30; 出埃及记 13:4; 民数记 7:1"> “你要在一月一日支起圣幕，即会幕，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:12; 民数记 4:5; 启示录 11:19"> 把约柜安置在里面，用幔子遮掩。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:8; 出埃及记 40:22–25; 出埃及记 37:10–24"> 把桌子搬进去，摆好桌上的器具，再把灯台搬进去，点上灯，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 10:19–22; 希伯来书 9:24; 约翰一书 2:1–2"> 把烧香的金香坛放在约柜前面，挂上圣幕入口的帘子。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 40:29; 约翰一书 4:9–10; 希伯来书 13:10"> 要把燔祭坛放在圣幕门口前面，</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 13:1; 约翰一书 1:7; 诗篇 26:6"> 洗濯盆放在会幕和祭坛中间，盆里要有水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 40:33; 以弗所书 4:11–12; 马太福音 16:18"> 用帷幔在圣幕四周围成院子，在院子的入口挂上帘子。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 8:10; 民数记 7:1; 马太福音 3:16"> 你要用膏油抹圣幕和里面所有的器具，使它们分别出来，成为圣洁之物。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 29:36–37; 路加福音 1:35; 以赛亚书 61:1"> 要抹燔祭坛和坛上所有器具，使燔祭坛分别出来，成为至圣之物。</span>
<span className="v" id="v11" data-v="11"> 要抹洗濯盆和盆座，使它们分别出来，成为圣洁之物。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 8:1–13; 利未记 9:1–24; 出埃及记 29:1–35"> 要把亚伦父子们叫到会幕入口，用水为他们沐浴，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 28:41; 约翰一书 2:20; 约翰一书 2:27"> 给亚伦穿上圣衣并膏立他，使他分别出来，做圣洁的祭司事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:10; 罗马书 8:30; 哥林多前书 1:30"> 也要把他的儿子们叫来，给他们穿上内袍，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 25:13; 希伯来书 5:1–14; 希伯来书 8:1–10"> 用同样的仪式膏立他们，使他们做祭司事奉我。他们的受膏将使他们永远做祭司，世代相传。”</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:1; 出埃及记 40:17–32; 申命记 12:32"> 摩西照耶和华的吩咐把事情都办好了。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:1; 出埃及记 40:1–2; 民数记 9:1"> 第二年一月一日，圣幕支起来了。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 37:27–28; 彼得前书 1:5; 利未记 26:11"> 摩西支起圣幕，装上带凹槽的底座，竖起木板，插上横闩，立起柱子，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:1–14; 出埃及记 36:8–19"> 在圣幕上面搭起罩棚，铺上顶盖，都遵照耶和华的吩咐。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:34; 申命记 10:5; 希伯来书 10:19–21"> 摩西把约版放在约柜里，横杠穿在约柜的两旁，施恩座放在约柜上，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:33; 出埃及记 40:3; 出埃及记 35:12"> 把约柜抬进圣幕，挂起幔子遮掩约柜，都遵照耶和华对他的吩咐。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 26:35; 约翰福音 6:53–57; 以弗所书 3:8"> 他把桌子放在会幕内、遮掩约柜的幔子外面、圣幕的北侧，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:30; 出埃及记 40:4; 希伯来书 9:2"> 将献给耶和华的供饼放在桌上，都遵照耶和华的吩咐。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 26:35; 启示录 2:5; 约翰福音 1:1"> 他把灯台放在会幕内的桌子对面，在圣幕的南侧，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 40:4; 出埃及记 25:37; 启示录 4:5"> 然后在耶和华面前点灯，都遵照耶和华的吩咐。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 40:5; 希伯来书 7:25; 约翰福音 11:42"> 他把金坛放在会幕里、遮掩约柜的幔子前面，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 30:7"> 在坛上点燃芬芳的香，都遵照耶和华的吩咐。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 40:5; 希伯来书 10:19–20; 以弗所书 2:18"> 他挂上圣幕入口的帘子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 40:6; 希伯来书 13:5–6; 希伯来书 13:10"> 在会幕，即圣幕入口前面设立燔祭坛，在坛上献燔祭和素祭，都遵照耶和华的吩咐。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 40:7; 出埃及记 38:8; 以西结书 36:25"> 他把洗濯盆放在会幕和祭坛之间，盆里盛水，供洗濯用。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 30:19–20; 诗篇 26:6; 约翰福音 13:10"> 摩西、亚伦及其众子都在盆里清洗手脚，</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 73:19; 出埃及记 30:19–20; 出埃及记 40:19"> 他们进会幕或走近祭坛的时候，都要先清洗，都遵照耶和华的吩咐。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 40:8; 出埃及记 27:9–16; 约翰福音 17:4"> 摩西又在圣幕和祭坛的四周用帷幔围成院子，然后在院子入口挂上帘子。这样，摩西完成了工作。</span>
</div>
</div>

## 耶和华的荣光

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="启示录 15:8; 民数记 9:15–23; 历代志下 7:2"> 那时，有云彩遮盖会幕，耶和华的荣光充满了圣幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 8:11; 利未记 16:2; 历代志下 7:2"> 摩西不能进会幕，因为云彩停在上面，耶和华的荣光充满了圣幕。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 9:19; 民数记 9:17; 出埃及记 13:21–22"> 一路上，云彩从圣幕上升起，他们就出发。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 9:19–22; 诗篇 31:15"> 云彩不升起，他们就不出发，一直等到云彩升起。</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 78:14; 民数记 9:15; 出埃及记 13:21"> 一路上，白天有耶和华的云彩停留在圣幕上面，夜间云中有火光照在以色列百姓眼前。</span>

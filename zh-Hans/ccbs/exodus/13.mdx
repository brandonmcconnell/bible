## 奉献头胎

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 2:23; 民数记 3:13; 申命记 15:19"> “要把以色列人中的长子和头生的牲畜分别出来，使之圣洁，归给我。他们都是我的。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 24:18; 申命记 5:15; 出埃及记 20:2"> 摩西对百姓说：“你们要记住离开埃及的这一天，因为耶和华用大能的手把你们从受奴役之地解救出来。不可吃带酵的食物。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 34:18; 出埃及记 23:15; 出埃及记 12:2"> 你们是在亚笔月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亚笔月是犹太历的第一个月，约在阳历三月中旬到四月中旬，相当于中国的春分时节。">a</a></sup>的这一天从埃及出来的，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:8; 约书亚记 24:11; 出埃及记 12:25–26"> 将来耶和华带领你们进入迦南人、赫人、亚摩利人、希未人和耶布斯人居住的土地以后，你们每逢此月都要为祂守节期。那是耶和华向你们祖先起誓，应许赐给你们那奶蜜之乡。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 12:15–20; 出埃及记 34:18; 利未记 23:8"> 在七天的节期内，你们要吃无酵饼，到了第七天，你们要为耶和华守节期。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:19; 马太福音 16:6"> 七天之内要吃无酵饼，你们境内不得有酵或是带酵的东西。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 13:14; 出埃及记 12:26–27; 诗篇 44:1"> 那时，要告诉你们的子孙，‘这节期是纪念我们出埃及时，耶和华为我们所做的一切。’</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 6:8; 申命记 11:18–19; 民数记 15:39"> 这节期对你们而言，就像你们手上的记号和额上的提醒，叫你们记得耶和华的律法，祂曾经用大能的手带你们出埃及。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:14; 出埃及记 12:24–25; 出埃及记 23:15"> 因此，每一年你们都要按时守这节期。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 13:5"> “耶和华成就祂起誓给你们和你们祖先的应许，领你们进入迦南人的土地，把那里赐给你们以后，</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 18:15; 利未记 27:26; 出埃及记 34:19"> 你们要把所有长子和头生的公畜归给祂。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:20; 民数记 18:15–17; 启示录 14:4"> 所有头生的公驴必须用羊羔赎回，不然就要打断它们的脖子。要赎回你们所有的长子。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 13:3; 约书亚记 4:6; 诗篇 145:4"> 将来你们的子孙问起这件事的意义，你们就回答，‘耶和华曾经用大能的手把我们从受奴役之地埃及带出来。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:29"> 当时法老硬着心不肯放我们走，所以耶和华就把埃及人的长子和头生的牲畜全都杀了。因此，我们把所有头生的公畜当作祭牲献给耶和华，把所有长子都赎回来。’</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 13:9; 申命记 11:18; 申命记 6:7–9"> 这事就像你们手上的记号和额上的标记，以牢记耶和华曾用大能的手带我们出埃及。”</span>
</div>
</div>

## 云柱和火柱

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:11–12; 尼希米记 9:17; 民数记 14:1–4"> 法老让以色列人离开埃及后，上帝没有带领他们穿越非利士地区，虽然那是条捷径。因为上帝说：“如果他们遇上战争，就会改变主意，返回埃及。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:2; 申命记 32:10; 民数记 33:6–8"> 所以，上帝领他们绕道前行，走旷野的路，前往红海<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“红海”或译“芦苇湖”，确切地点约在今红海北端苏伊士运河附近。">b</a></sup>。以色列人离开埃及时都带着兵器。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:24–25; 约书亚记 24:32; 使徒行传 7:16"> 摩西把约瑟的骸骨一起带走，因为约瑟曾叫以色列人郑重发誓，对他们说：“上帝必眷顾你们，那时你们要把我的骸骨也一起带走。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="创世记50:25。">c</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="民数记 33:5–6; 出埃及记 12:37"> 以色列人从疏割启程，来到旷野边缘的以倘安营。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:1–2; 尼希米记 9:12; 申命记 1:33"> 耶和华走在他们前面，白天用云柱为他们指示道路，晚上用火柱照亮他们，这样他们可以日夜赶路。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 121:5–8; 启示录 10:1"> 白天的云柱和晚上的火柱总不从他们前面离开。</span>
</div>
</div>

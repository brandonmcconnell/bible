## 蝗虫之灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 出埃及记 3:20"> 耶和华对摩西说：“你去见法老，我已使他和他臣仆的心刚硬，好在他们当中行我这些神迹。</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 1:3; 申命记 4:9; 申命记 6:20–22"> 这样，你就可以把我如何严惩埃及人以及我在他们当中所行的神迹告诉你的子孙，好叫你们知道我是耶和华。”</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:6; 列王纪上 21:29; 雅各书 4:10"> 摩西和亚伦便去见法老，对他说：“希伯来人的上帝耶和华说，‘你要到什么时候才肯在我面前谦卑下来？放我的子民走，他们好事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 9:3; 约珥书 2:25; 出埃及记 11:4–5"> 你若再不答应，明天我要使蝗虫飞入你的国境。</span>
<span className="v" id="v5" data-v="5" data-xref="约珥书 1:4; 出埃及记 9:32; 约珥书 2:25"> 它们铺天盖地，要吃光冰雹过后田间所剩的，包括一切树木。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 8:21; 出埃及记 8:3; 出埃及记 11:6"> 你的王宫及臣仆和所有埃及人的房屋都要布满蝗虫，这是你祖祖辈辈从未见过的蝗灾。’”摩西说完，便转身离开法老。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 18:21; 出埃及记 23:33; 约书亚记 23:13"> 臣仆对法老说：“这个人害我们要到什么时候呢？让他们离开去事奉他们的上帝耶和华吧！埃及快被毁灭了，你不知道吗？”</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 10:24; 出埃及记 12:31; 出埃及记 8:8"> 法老便召回摩西和亚伦，对他们说：“你们去事奉你们的上帝耶和华吧！但你们谁要去呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:1; 哥林多前书 5:7–8; 申命记 31:12–13"> 摩西回答说：“我们男女老幼都要去，还有我们的牛群和羊群，因为我们要去守耶和华的节期。”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 13:21; 历代志下 32:15; 出埃及记 12:30–31"> 法老听后，说：“我若让你们带走妇女和孩子，最好耶和华能保护你们！你们真是居心叵测。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 10:28; 诗篇 119:69; 出埃及记 5:4"> 不行！只有男子可以去事奉耶和华，这是你们一直要求的。”法老说完，便下令把他们赶出去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 7:19; 出埃及记 10:4–5"> 耶和华对摩西说：“你向埃及伸杖，使蝗虫飞来吃尽冰雹过后田野剩下的一切植物。”</span>
<span className="v" id="v13" data-v="13" data-xref="约拿书 1:4; 诗篇 78:26; 诗篇 148:8"> 摩西就向埃及伸杖。耶和华使东风在埃及境内刮了整整一天一夜，到早晨，东风带来了蝗虫。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:46; 约珥书 1:2–4; 诗篇 105:34–35"> 埃及到处都布满了蝗虫，数目之多实在是空前绝后。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 10:5; 诗篇 78:46; 约珥书 1:6–7"> 蝗虫遍布整个埃及，地上一片黑暗。这些蝗虫吃尽了冰雹过后剩下的农作物和树上的果子，没有留下一点青绿。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 9:27; 撒母耳记下 19:20; 撒母耳记上 15:30"> 法老急忙召见摩西和亚伦，对他们说：“我得罪了你们的上帝耶和华，又得罪了你们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 8:8; 出埃及记 9:28; 列王纪上 13:6"> 现在求你饶恕我的罪，就这一次，为我祈求你们的上帝耶和华撤去这场死亡之灾吧！”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 6:28; 出埃及记 8:28–30; 出埃及记 8:9"> 摩西就离开法老出去祈求耶和华，</span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:20; 出埃及记 13:18; 出埃及记 15:4"> 耶和华就把风向倒转，变成猛烈的西风，把蝗虫刮走，吹进红海。埃及境内一只蝗虫也没留下。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:21; 出埃及记 11:10; 申命记 2:30"> 可是，耶和华又使法老心硬，他不让以色列人离开埃及。</span>
</div>
</div>

## 黑暗之灾

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="启示录 16:10–11; 犹大书 1:6; 路加福音 23:44"> 耶和华对摩西说：“你向天伸杖，使埃及全境漆黑一片，那黑暗浓得甚至可以摸到。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 105:28; 启示录 16:10; 出埃及记 20:21"> 摩西向天伸杖，埃及全境便漆黑了三天之久。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 8:22; 以赛亚书 42:16; 彼得前书 2:9"> 埃及人彼此看不见，谁也不敢移动半步。可是，以色列人住的地方却有光。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 10:8–10; 出埃及记 8:28; 创世记 34:23"> 法老把摩西召来，对他说：“去事奉耶和华吧，你们的妇女和孩子也可以去，但你们要把牛羊留下。”</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 9:22; 利未记 16:9; 出埃及记 29:1–46"> 摩西回答说：“你得允许我们有祭物和燔祭牲献给我们的上帝耶和华。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 23:18; 使徒行传 2:44–45; 箴言 3:9"> 我们要带走所有的牲畜，一只蹄子也不留下，因为我们要从其中选一些来献给我们的上帝耶和华。我们抵达目的地前，还不知道把哪些献给祂。”</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 10:20; 出埃及记 4:21; 出埃及记 14:8"> 但耶和华使法老的心刚硬，他不肯让以色列百姓离开。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 25:16; 历代志下 16:10; 阿摩司书 7:13"> 法老对摩西说：“给我退下！不要再让我见到你，因为你再见我面之日必死。”</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 11:27; 出埃及记 12:30–31; 出埃及记 11:4–8"> 摩西回答说：“你说得好，我必不再见你的面。”</span>
</div>

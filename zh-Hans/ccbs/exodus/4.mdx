## 上帝赐摩西能力

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 3:18; 出埃及记 2:14; 耶利米书 1:6"> 摩西回答说：“他们不会相信我，也不会听我的话，他们会说，‘耶和华根本没有向你显现。’”</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:17; 出埃及记 4:20; 以赛亚书 11:4"> 耶和华对摩西说：“你手里拿的是什么？”摩西说：“是一根手杖。”</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:10–15; 阿摩司书 5:19; 出埃及记 4:17"> 耶和华说：“把它扔在地上！”于是，摩西把杖扔在地上，杖变成了一条蛇。摩西连忙跑开。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:3–6; 创世记 22:1–2; 诗篇 91:13"> 耶和华说：“你伸手抓住它的尾巴！”摩西就伸手抓蛇的尾巴，蛇在他手中变回了杖。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:9; 创世记 48:3; 出埃及记 3:15"> 耶和华说：“这样，他们就会相信他们祖先的上帝耶和华，就是亚伯拉罕、以撒和雅各的上帝，曾经向你显现。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 5:27; 民数记 12:10"> 耶和华又说：“把手放进怀里。”摩西把手放进怀里，手抽出来的时候，竟患了麻风病，像雪一样白。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 申命记 32:39; 马太福音 8:3"> 耶和华说：“再把手放进怀里。”摩西又把手放进怀里，这次再抽出来的时候，手已经复原，跟其他地方的皮肉一样。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:10; 申命记 32:39; 出埃及记 4:30–31"> 耶和华说：“纵然他们不听你的话，不信第一个神迹，也必定相信第二个神迹。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 7:19–25; 出埃及记 1:22; 马太福音 7:2"> 如果他们两个神迹都不相信，还是不听你的话，你就从尼罗河里取些水来倒在旱地上，那水就会在旱地上变成血。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 1:6; 出埃及记 6:12; 使徒行传 7:22"> 摩西对耶和华说：“主啊！我向来不善言辞，即使你对仆人说话以后，我还是不善言辞，因为我是个拙口笨舌的人。”</span>
<span className="v" id="v11" data-v="11" data-xref="阿摩司书 3:6; 诗篇 146:8; 以西结书 3:26–27"> 耶和华对他说：“是谁造人的口舌？是谁使人哑巴或耳聋？是谁使人目明或眼瞎？岂不都是我耶和华吗？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:9; 路加福音 12:11–12; 马太福音 10:19–20"> 去吧！我必赐给你口才，指示你说什么话。”</span>
<span className="v" id="v13" data-v="13" data-xref="约拿书 1:3; 出埃及记 4:1; 马太福音 13:41"> 但是摩西说：“主啊，请派其他人去吧。”</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 14:13–15; 出埃及记 4:27; 历代志上 21:7"> 耶和华向摩西发怒说：“利未人亚伦不是你哥哥吗？我知道他是个能言善辩的人，正要来迎接你。他见到你一定很欢喜。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 51:16; 申命记 18:18; 路加福音 21:15"> 你要把该说的话传给他，我会赐你们口才，教你们如何行事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:1–2; 诗篇 82:6; 约翰福音 10:34–35"> 他要替你向百姓说话，做你的发言人，你对他来说就像上帝一样。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:2; 哥林多前书 1:27; 出埃及记 7:9–20"> 你要把手杖带在身边，以便行神迹。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 撒母耳记上 1:17; 提摩太前书 6:1"> 摩西回到家里，对他的岳父叶特罗说：“求你让我回埃及去探望我的亲人，看看他们是否在世。”叶特罗说：“你平安地去吧。”</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 2:20; 出埃及记 2:23; 出埃及记 2:15"> 耶和华在米甸对摩西说：“你只管放心回埃及去，想害你性命的人都已经死了。”</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 17:9; 民数记 20:8–9; 出埃及记 18:3–4"> 于是，摩西拿着上帝的杖，带着妻子和儿子骑驴返回埃及。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 9:18; 以赛亚书 63:17; 出埃及记 14:8"> 耶和华对摩西说：“你到了埃及，务要照我赐给你的能力在法老面前行神迹。但我要使他的心刚硬，他必不让百姓离开。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 11:1; 罗马书 9:4; 耶利米书 31:9"> 那时，你就告诉法老，‘耶和华说，以色列是我的长子，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 11:5; 出埃及记 12:29; 诗篇 135:8"> 我对你说过让我的长子出去事奉我，但你执意不肯。看啊，我要杀你的长子。’”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 17:14; 民数记 22:22–23; 何西阿书 13:8"> 摩西在途中夜宿的时候，耶和华遇见摩西，想要杀他。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 5:2–3; 创世记 17:14; 撒母耳记下 16:7"> 他的妻子西坡拉拿起锋利的火石，割下儿子的包皮，用它碰摩西的脚，说：“你真是我的血郎。”</span>
<span className="v" id="v26" data-v="26"> 这样，耶和华才放过他。当时，西坡拉说“血郎”是指割礼一事。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:1; 出埃及记 4:14–16; 列王纪上 19:8"> 耶和华对亚伦说：“你到旷野去迎接摩西。”他就在上帝的山上遇见摩西，并亲吻他。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 4:8–9; 出埃及记 4:15–16; 马太福音 21:29"> 摩西把耶和华吩咐他的以及要他行的神迹都告诉了亚伦。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 3:16; 出埃及记 24:11; 出埃及记 24:1"> 摩西和亚伦一起回去招聚以色列的众长老，</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 4:16"> 亚伦把耶和华对摩西的吩咐详细地告诉他们。摩西又在百姓面前行了那些神迹，</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:18; 出埃及记 2:25; 诗篇 106:12–13"> 百姓相信了。以色列人听见耶和华眷顾他们、看到了他们的苦难，都俯伏敬拜祂。</span>
</div>
</div>

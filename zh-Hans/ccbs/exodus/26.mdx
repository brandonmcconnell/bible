## 圣幕的做法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 36:8–19; 出埃及记 26:36; 出埃及记 26:31"> “要用十幅幔子做圣幕，幔子要用细麻和蓝色、紫色、朱红色毛线织成，上面要精工绣制基路伯天使。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 7:2; 民数记 4:25; 历代志上 17:1"> 每幅幔子的尺寸都一样，长十二米半、宽一米八。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:10; 歌罗西书 2:2; 以弗所书 2:21–22"> 每五幅连在一起，形成两幅大幔子。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 36:11–12; 出埃及记 36:17; 出埃及记 26:10–11"> 要在每幅大幔子末幅的边缘钉上蓝色的扣环，</span>
<span className="v" id="v5" data-v="5"> 每幅大幔子钉五十个，扣环要两两相对，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 36:13; 出埃及记 26:11; 出埃及记 26:33"> 再做五十个金钩，把两幅大幔子连在一起，成为一个完整的圣幕。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 26:14; 诗篇 45:13; 出埃及记 26:9"> “要用山羊毛织十一幅幔子作圣幕的罩棚，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 26:13; 出埃及记 26:2"> 每幅长十三米半、宽一米八。十一幅幔子的尺寸都要一样。</span>
<span className="v" id="v9" data-v="9"> 然后，你们要把五幅连成一大幅，其余六幅连成一大幅，第六幅要在罩棚前叠起来。</span>
<span className="v" id="v10" data-v="10"> 要在这两幅大幔子末幅的边缘各钉上五十个扣环，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:3; 出埃及记 26:6"> 再做五十个铜钩，把这两幅大幔子扣在一起，成为一个完整的罩棚。</span>
<span className="v" id="v12" data-v="12"> 铺罩棚所剩下来的半幅幔子要垂到圣幕后面。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 26:2; 出埃及记 26:8"> 两旁余下的幔子可垂在圣幕的两边，每边长四十五厘米，盖着圣幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 36:19; 出埃及记 25:5; 出埃及记 35:23"> 罩棚上面要盖一层染成红色的公羊皮，再盖一层海狗皮做顶盖。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 36:20–33; 民数记 4:31–32; 出埃及记 40:17–18"> “要用皂荚木做支圣幕的木板，</span>
<span className="v" id="v16" data-v="16"> 每块木板长四米半，宽七十厘米。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 36:22; 出埃及记 26:19; 出埃及记 36:24"> 每块木板要有两个接榫，用来衔接。圣幕的所有木板都要这样。</span>
<span className="v" id="v18" data-v="18"> 圣幕的南面要有二十块木板，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 38:27; 出埃及记 38:30–31; 出埃及记 26:37"> 在这些木板下面要造四十个带凹槽的银底座，每块木板下面有两个，套在木板的两个接榫上。</span>
<span className="v" id="v20" data-v="20"> 圣幕北面也要有二十块木板，</span>
<span className="v" id="v21" data-v="21"> 木板下面同样有四十个带凹槽的银底座，每块木板下面有两个银底座。</span>
<span className="v" id="v22" data-v="22"> 圣幕后面，就是西面，要有六块木板。</span>
<span className="v" id="v23" data-v="23"> 圣幕后面的两个拐角要各有一块木板，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 36:29–30; 诗篇 133:1–3; 哥林多前书 1:10"> 木板的下端连于底座<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“连于底座”或译“是双层的”。">a</a></sup>，顶端用一个环固定。两个拐角都要这样做。</span>
<span className="v" id="v25" data-v="25"> 这样，后面共有八块木板，每块木板下面各有两个带凹槽的银底座，一共有十六个银底座。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 15:1; 民数记 4:31; 加拉太书 6:1–2"> “要用皂荚木做横闩，圣幕左右两边和后面的墙板上要各有五根横闩，</span>
<span className="v" id="v28" data-v="28"> 拦腰固定墙板的那根横闩要从这端贯穿到那端。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 25:11–12"> 所有的木板和横闩都要包上金，并要在木板上造金环，用来穿横闩。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 25:40; 希伯来书 8:5; 出埃及记 25:9"> 要照着我在山上所指示你的样式，把圣幕支搭起来。</span>
</div>
</div>

## 造至圣所的条例

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 27:51; 历代志下 3:14; 出埃及记 36:35"> “要用细麻和蓝色、紫色、朱红色毛线织成一幅幔子，上面精工绣上基路伯天使。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:37; 出埃及记 36:38; 以斯帖记 1:6"> 要把这幅幔子挂在四根包金的皂荚木柱上，木柱上有金钩，木柱立在四个带凹槽的银底座上面。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:2–3; 利未记 16:2; 出埃及记 40:21"> 要把整幅幔子挂在木柱的金钩上，把约柜抬进幔子里。这幔子把圣幕分为两个部分，幔子里面是至圣所，外面是圣所。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 40:20; 出埃及记 25:21; 希伯来书 9:5"> 要把施恩座放在至圣所里面的约柜上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 40:24; 出埃及记 40:22; 希伯来书 9:2"> 桌子要放在幔子的外面、圣幕的北面，灯台放在南面，跟桌子相对。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 36:37; 民数记 9:15; 出埃及记 26:31"> 要用细麻和蓝色、紫色、朱红色毛线绣制圣幕的门帘。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 36:38"> 要用皂荚木做五根挂门帘的柱子，柱子包上金，上面要有金钩，并要为柱子铸造五个带凹槽的铜底座。</span>
</div>

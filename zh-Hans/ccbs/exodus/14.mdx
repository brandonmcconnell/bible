## 过红海

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:1; 出埃及记 13:1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 33:7–8; 耶利米书 44:1; 出埃及记 13:17–18"> “你吩咐以色列人改变方向，在比·哈希录附近的海边扎营，在红海和密夺之间，对面是巴力·洗分。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 4:28; 撒母耳记上 23:23; 诗篇 71:11"> 法老必定以为以色列人走迷了路，被困在旷野。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:22–23; 出埃及记 7:5; 罗马书 9:17"> 我要使法老的心刚硬，使他派兵追赶他们。我要在法老和埃及军兵身上得荣耀，好叫埃及人知道我是耶和华。”于是，以色列人遵命而行。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 105:25; 出埃及记 12:33; 路加福音 11:24–26"> 有人向埃及王报信，说以色列百姓逃走了。法老和他的臣仆便改变主意，说：“我们怎么可以让以色列人就这样离开我们，不再服侍我们呢？”</span>
<span className="v" id="v6" data-v="6"> 法老便吩咐人预备战车，他亲自领军，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 15:4; 士师记 4:3; 诗篇 68:17"> 率领埃及所有的战车，包括六百辆最精锐的战车，每辆车上都有战车长。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:17; 民数记 33:3; 申命记 26:8"> 耶和华使埃及王法老的心刚硬，法老就追赶毫无惧色地离开埃及的以色列人。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:9; 约书亚记 24:6; 出埃及记 14:2"> 埃及大军的战车骑兵倾巢而出，在巴力·洗分对面、比·哈希录附近的海边追上了安营的以色列人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:7; 诗篇 34:17; 尼希米记 9:9"> 法老渐渐逼近，以色列人抬头看见埃及人追了上来，非常害怕，便呼求耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:7–8; 民数记 14:1–4; 出埃及记 15:23–24"> 他们对摩西说：“难道埃及没有坟地，要你带我们出来死在旷野吗？为什么要带我们出埃及呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约拿书 4:3; 出埃及记 6:9; 约拿书 4:8"> 我们在埃及岂不是对你说过，别管我们，就让我们服侍埃及人吗？服侍埃及人总比死在旷野好啊！”</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 20:17; 历代志下 20:15; 出埃及记 14:30"> 摩西对百姓说：“你们不要害怕，站稳了，看耶和华今天怎样解救你们。你们再也看不到你们今天看到的埃及人了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 3:22; 申命记 20:4; 历代志下 20:17"> 耶和华必为你们争战，你们要保持安静。”</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 7:10; 以斯拉记 10:4–5; 尼希米记 9:9"> 耶和华对摩西说：“为什么向我呼求呢？吩咐以色列人往前走吧。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:19; 出埃及记 4:20; 出埃及记 4:2"> 你举手向海伸出手杖，把海水分开，以色列人可以从中间的干地走过去。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:8; 出埃及记 14:4; 以西结书 34:11"> 我要使埃及人的心刚硬，他们会尾随你们下到海中。我要在法老及其大军、战车和骑兵身上得荣耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:5; 出埃及记 14:4; 出埃及记 7:17"> 当我在法老及其战车和骑兵身上得到荣耀时，埃及人就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 63:9; 出埃及记 32:34; 出埃及记 23:20–21"> 这时，在以色列队伍前面领路的上帝的天使，转到百姓后面，云柱也随着移到后面立住。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:14; 哥林多后书 2:15–16; 箴言 4:18–19"> 云柱停在埃及队伍和以色列队伍的中间，埃及人这边一片黑暗，以色列人那边却有光，彼此整夜都无法接近对方。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 63:12; 出埃及记 15:8; 诗篇 66:6"> 摩西向海伸出手，耶和华便整夜用强劲的东风吹退海水，将海底变成干地。海水分开后，</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:29; 诗篇 66:6; 出埃及记 15:19"> 以色列人踏着干地走入海中，海水在他们左右形成水墙。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:19; 出埃及记 14:17; 出埃及记 15:9"> 法老的军兵车马紧追不舍，都跟着下到海中。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 13:21; 诗篇 77:16–19; 出埃及记 14:25"> 到了破晓时分，耶和华从云柱火柱中俯视埃及军队，使他们陷入混乱。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 14:14; 申命记 3:22; 约伯记 20:24"> 祂使他们战车的轮子脱落，难以前行。于是，埃及人说：“我们逃命吧，因为耶和华在帮助以色列人攻击我们！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 14:16; 出埃及记 8:5; 雅各书 2:13"> 耶和华对摩西说：“你向海伸出手，使海水回流，淹没埃及人及其战车和马兵。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:18; 诗篇 78:53; 希伯来书 11:29"> 天刚亮的时候，摩西向海伸出手，海水便恢复原状。埃及人纷纷向岸上逃命，耶和华却使大水把他们卷回海中。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:53; 诗篇 106:9–11; 哈巴谷书 3:13"> 海水回流，法老的战车和人马都淹没在大海之中，全军覆没。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:22; 诗篇 77:19–20; 以赛亚书 43:2"> 以色列人却在干地上走过红海，海水在他们左右形成水墙。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 106:8; 诗篇 106:10; 诗篇 92:9–11"> 那天，耶和华就这样从埃及人手中拯救了以色列人。以色列人看见埃及人的尸体横在海边。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 2:11; 约翰福音 11:45; 约翰福音 2:23–25"> 以色列百姓亲眼看见耶和华怎样以大能对付埃及人，他们就敬畏耶和华，又信服祂和祂的仆人摩西。</span>
</div>
</div>

## 十诫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 5:22; 申命记 5:4; 申命记 4:36"> 以下是上帝的训示：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命记 5:6; 何西阿书 13:4; 利未记 26:13"> “我是你的上帝耶和华，曾把你从受奴役之地埃及领出来。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 5:7; 马太福音 4:10; 诗篇 81:9"> “除我以外，你不可有别的神明。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 5:8; 利未记 26:1; 申命记 4:15–19"> 不可为自己雕刻神像，不可仿照天上、地上和地底下水中的任何形象造神像，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 5:9; 民数记 14:18; 申命记 4:24"> 不可跪拜它们，也不可供奉它们，因为我——你的上帝耶和华痛恨不贞，我必追讨背弃我之人的罪，从父到子直到三四代。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 7:9; 约翰福音 14:21; 约翰一书 5:3"> 但那些爱我、遵守我诫命的人，我必以慈爱待他们，直到千代。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 5:11; 利未记 19:12; 雅各书 5:12"> 不可妄用你上帝耶和华的名，违者必被耶和华定罪。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 26:2; 利未记 19:3; 出埃及记 31:13–16"> 要谨记安息日，守为圣日。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 13:14; 出埃及记 34:21; 出埃及记 23:12"> 你一周可劳碌工作六天，</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 5:14–15; 出埃及记 34:21; 民数记 15:32–36"> 但第七天是你的上帝耶和华的安息日，这一天你和儿女、仆婢、牲畜及你那里的外族人不可做任何工。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 1:1–2; 创世记 2:2–3; 出埃及记 31:17"> 因为耶和华用六天创造了天地、海洋和其中的万物，第七天便休息了，所以耶和华赐福安息日，把它定为圣日。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 6:1–3; 歌罗西书 3:20; 申命记 5:16"> 要孝敬父母，以便在你的上帝耶和华要赐给你的土地上享长寿。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:9; 申命记 5:17; 创世记 9:5–6"> 不可杀人。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:4; 申命记 5:18; 罗马书 7:2–3"> 不可通奸。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 13:9; 以弗所书 4:28; 利未记 19:11"> 不可偷盗。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 19:5; 马太福音 19:18; 诗篇 15:3"> 不可作伪证陷害人。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:9; 路加福音 12:15; 希伯来书 13:5"> 不可贪恋别人的房屋，不可贪恋别人的妻子、仆婢、牛驴或其他任何物品。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 19:16–18; 耶利米书 23:23; 诗篇 139:7–8"> 那时雷电交加，号角嘹亮，山上冒烟，百姓见此情景，都吓得浑身颤抖，不敢挨近。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 18:16; 使徒行传 7:38; 加拉太书 3:19"> 他们对摩西说：“求你跟我们说话，我们必听从。不要让上帝直接跟我们说话，恐怕我们会丧命！”</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 13:3; 箴言 3:7; 撒母耳记上 12:20"> 摩西对百姓说：“不要害怕，上帝降临是要试验你们，好让你们时时敬畏祂，不致犯罪。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 8:12; 诗篇 97:2; 诗篇 18:9"> 百姓都站得远远的，摩西独自走进上帝所在的密云中。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 9:13; 申命记 4:36; 希伯来书 12:25–26"> 耶和华吩咐摩西对以色列百姓说：“既然你们已经亲眼看见我从天上向你们说话，</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 20:39; 西番雅书 1:5; 列王纪下 17:33"> 你们不可制造神像与我并立，不可为自己制造金银神像。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:5; 历代志下 6:6; 诗篇 132:13–14"> 你们要为我筑一座土坛，把你们的牛羊献在坛上作燔祭和平安祭。凡是我使自己的名被尊崇的地方，我会亲临那里赐福给你们。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 8:31; 申命记 27:5–6"> 你们若为我筑石坛，不可用凿刻的石头，因为用工具凿刻的石头会玷污祭坛。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:16; 传道书 5:1; 利未记 10:3"> 不可踩着台阶登我的祭坛，免得露出你们的下体。</span>
</div>
</div>

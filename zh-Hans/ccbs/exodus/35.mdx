## 安息日的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:32; 出埃及记 31:1–11; 罗马书 2:13"> 摩西招聚以色列全体会众，对他们宣布说：“以下是耶和华吩咐你们遵守的事。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:3; 路加福音 13:14–15; 出埃及记 20:9–10"> 一周可以工作六天，但第七天是你们为耶和华守的圣日，是完全休息的安息日。凡在这一天工作的，必被处死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 16:23; 民数记 15:32–36; 出埃及记 12:16"> 在安息日，你们的任何住处都不可生火。”</span>

## 为造圣幕奉献

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:1–2"> 摩西对以色列全体会众说：“以下是耶和华给你们的吩咐。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 9:7; 诗篇 110:3; 出埃及记 25:2–7"> “你们要献物品给耶和华。凡慷慨乐捐的，都可以把下列物品献给耶和华为礼物，即金、银、铜，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 26:7–14; 出埃及记 26:31; 出埃及记 28:15"> 蓝色、紫色和朱红色毛线，细麻，山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染成红色的公羊皮，海狗皮，皂荚木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 27:20; 出埃及记 25:1–40; 出埃及记 30:23"> 灯油，制作膏油和香的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 39:6–14; 出埃及记 28:9; 出埃及记 25:5"> 镶嵌在以弗得和胸牌上的红玛瑙及其他宝石。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:1–6; 出埃及记 36:1–4"> “你们当中的能工巧匠都要来建造耶和华所吩咐的物件，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:1–37; 出埃及记 36:8–34; 出埃及记 31:7–9"> 即圣幕和圣幕的罩棚、顶盖、钩子、木板、横闩、柱子和带凹槽的底座；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:10–22; 出埃及记 26:31–33; 出埃及记 37:1–9"> 约柜和抬约柜的横杠、施恩座和遮掩约柜的幔子；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:23–30; 利未记 24:5–6; 出埃及记 37:10–16"> 桌子和抬桌子的横杠、桌上的一切器具和供饼；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 25:31–39; 马太福音 5:14–15; 出埃及记 37:17–24"> 灯台和灯台用的器具、灯盏和灯油；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 30:1–10; 出埃及记 30:22–38; 出埃及记 37:25–28"> 香坛和抬香坛的横杠、膏油和芬芳的香；圣幕门口的帘子；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1–8; 出埃及记 30:18–21; 出埃及记 38:1–8"> 燔祭坛、祭坛的铜网、抬祭坛的横杠、祭坛用的一切器具、洗濯盆和盆座；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2; 出埃及记 38:9–20; 出埃及记 27:9–19"> 院子的帷幔、悬挂幔子的柱子和底座、院子入口的门帘；</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:19"> 圣幕及院子用的橛子和绳子；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 31:10; 民数记 4:5–15; 出埃及记 28:1–43"> 在圣所供职时穿的精制礼服、亚伦祭司的圣衣及其众子供祭司之职时穿的衣服。”</span>
<span className="v" id="v20" data-v="20"> 之后，以色列全体会众便从摩西面前退去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:2; 出埃及记 35:26; 历代志上 29:14"> 凡心里有感动又甘愿奉献的，都把礼物拿来献给耶和华，作会幕、会幕中的一切器具及圣衣之用。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 7:70–72; 马太福音 2:11; 以斯拉记 2:68–69"> 凡甘心奉献的，不论男女，都把别针、耳环、戒指、项链等各样金饰拿来献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 29:8; 出埃及记 25:2–7; 出埃及记 35:6–10"> 凡有蓝色、紫色和朱红色毛线，细麻，山羊毛，染成红色的公羊皮，海狗皮的，都把它们拿来了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 8:12"> 凡奉献银器和铜器的，都拿来献给耶和华。凡有皂荚木的，只要用得上，都拿来奉献。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡善于纺线的妇女，都把亲手纺成的细麻和蓝色、紫色、朱红色毛线拿来奉献。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:21; 出埃及记 36:8; 出埃及记 35:29"> 凡心里受感动又善于纺织的妇女都来纺山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 2:68; 历代志上 29:6; 出埃及记 35:9"> 众首领奉献了红玛瑙和其他宝石，用来镶嵌在以弗得和胸牌上。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 30:23–38; 出埃及记 35:8"> 他们又献出香料和油，用来做香、点灯、做膏油。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 9:7; 出埃及记 35:21–22; 出埃及记 35:4"> 以色列人，不论男女、凡是甘心乐意奉献的，都把礼物带来献给耶和华，好完成耶和华借摩西吩咐他们的一切工作。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 31:1–6; 雅各书 1:17; 哥林多前书 12:11"> 摩西对以色列人说：“看啊，耶和华已经亲自在犹大支派中选出户珥的孙子、乌利的儿子比撒列，</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:17; 以赛亚书 11:2–5; 以赛亚书 61:1–3"> 上帝的灵已经充满他，使他有聪明智慧，精于各种技能和手艺，</span>
<span className="v" id="v32" data-v="32"> 能用金、银和铜制造精巧的器具，</span>
<span className="v" id="v33" data-v="33"> 又能雕刻和镶嵌宝石，精通木工和各种手艺。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 31:6; 历代志下 2:14; 以斯拉记 7:27"> 耶和华又使他与但支派亚希撒抹的儿子亚何利亚伯有能力教授别人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 35:31; 列王纪上 7:14; 以赛亚书 28:26"> 耶和华使他们成为能工巧匠，精通各样技艺，包括雕刻、图案设计、纺织，以及用细麻和蓝色、紫色、朱红色毛线刺绣。”</span>
</div>
</div>

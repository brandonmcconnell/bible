## 上帝应许拯救以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:33; 出埃及记 12:31; 出埃及记 3:19–20"> 耶和华对摩西说：“你就要看见我怎样用大能的手对付法老，那时他会让以色列人走，甚至把他们赶出他的国土！”</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 9:24; 玛拉基书 3:6; 使徒行传 17:24–25"> 上帝又对摩西说：“我是耶和华，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 83:18; 诗篇 68:4; 创世记 17:1"> 我曾以全能上帝的身份向亚伯拉罕、以撒和雅各显现，但没有让他们知道我的名字是耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:4; 创世记 15:18; 创世记 17:7–8"> 我坚守与他们所立的约，要把他们寄居的迦南赐给他们。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 2:24; 诗篇 106:44–45; 以赛亚书 63:9"> 我已听见以色列人因受埃及人的奴役而发出的哀声，也顾念我的约。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 26:8; 历代志上 17:21; 出埃及记 7:4"> 所以，你要转告以色列人说，‘我是耶和华。我要解救你们脱离埃及人的辖制，脱离他们的奴役，我要伸出臂膀大行审判，以救赎你们。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 7:6; 申命记 29:13; 申命记 4:20"> 我要接纳你们做我的子民，我要做你们的上帝。这样，你们就知道我是你们的上帝耶和华，曾救你们脱离埃及人的辖制。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 26:3; 创世记 15:18; 以西结书 20:42"> 我必带领你们进入我举手起誓要给亚伯拉罕、以撒和雅各的那片土地，把它赐给你们作产业。我是耶和华。’”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 约伯记 21:4; 出埃及记 14:12"> 摩西把这番话转告百姓，可是他们因为残酷的劳役无比沮丧，不肯听他的话。</span>
<span className="v" id="v10" data-v="10"> 耶和华对摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 6:29; 出埃及记 5:23; 出埃及记 3:10"> “你去告诉埃及王法老，让以色列人离开他的土地。”</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:10; 耶利米书 1:6; 出埃及记 6:30"> 摩西却说：“以色列人都不听我的话，法老又怎么肯听我这拙口笨舌的人呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 27:23; 提摩太前书 6:13; 诗篇 91:11"> 耶和华吩咐摩西和亚伦回到以色列人和法老那里，要他们领以色列人离开埃及。</span>
</div>
</div>

## 摩西和亚伦的族谱

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 46:9; 历代志上 5:3; 民数记 26:5–7"> 以下是以色列各家族的族长： 以色列长子吕便的儿子是哈诺、法路、希斯伦和迦米。这些是吕便的宗族。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 4:24; 创世记 46:10; 民数记 26:12–13"> 西缅的儿子是耶姆利、雅悯、阿辖、雅斤、琐辖和扫罗，扫罗的母亲是迦南人。这些是西缅的各宗族。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:17; 创世记 46:11; 历代志上 6:1"> 按照家谱的记载，利未的儿子是革顺、哥辖和米拉利，利未享年一百三十七岁。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:17; 民数记 3:18; 历代志上 23:7"> 革顺的儿子是立尼和示每，二人各成宗族。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:18; 历代志上 6:2; 民数记 3:19"> 哥辖的儿子是暗兰、以斯哈、希伯仑和乌薛，哥辖享年一百三十三岁。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> 米拉利的儿子是抹利和姆示。这些按家谱的记载是利未的各宗族。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 26:59; 出埃及记 2:1–2; 出埃及记 6:18"> 暗兰娶了他父亲的妹妹约基别，生了亚伦和摩西，暗兰享年一百三十七岁。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:1; 历代志上 6:37–38; 民数记 16:32"> 以斯哈的儿子是可拉、尼斐和细基利。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 10:4; 民数记 3:30; 尼希米记 3:20"> 乌薛的儿子是米沙利、以利撒反和西提利。</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 4:19–20; 民数记 2:3; 民数记 1:7"> 亚伦娶了亚米拿达的女儿、拿顺的妹妹以利沙巴，她生了拿答、亚比户、以利亚撒和以他玛。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 6:22–23; 民数记 16:1; 撒母耳记上 1:1"> 可拉的儿子是亚惜、以利加拿和亚比亚撒，这些是可拉的各宗族。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:33; 民数记 25:7–13; 约书亚记 22:31–32"> 亚伦的儿子以利亚撒与普铁的一个女儿结婚，生了非尼哈。以上是利未各宗族的族长。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 12:51; 出埃及记 12:17; 出埃及记 7:4"> 正是亚伦和摩西受耶和华之命，要按以色列人的队伍把他们带出埃及。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 6:26; 出埃及记 7:10; 诗篇 77:20"> 也是摩西和亚伦要求埃及王法老让他们把以色列人带出埃及。</span>
<span className="v" id="v28" data-v="28"> 那时，耶和华曾经在埃及对摩西说：</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 6:11; 出埃及记 7:2; 出埃及记 6:2"> “我是耶和华，你要把我吩咐你的一切话告诉埃及王法老。”</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 6:12; 出埃及记 4:10; 哥林多前书 9:16–17"> 摩西却对耶和华说：“你看，我拙口笨舌，法老怎肯听我的话？”</span>
</div>

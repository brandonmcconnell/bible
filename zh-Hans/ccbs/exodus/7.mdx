## 亚伦和摩西面见法老

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 4:15–16; 诗篇 82:6; 约翰福音 10:35–36"> 耶和华对摩西说：“我要使你在法老面前像上帝一样，你哥哥亚伦是你的发言人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:15; 出埃及记 6:29; 申命记 4:2"> 你要传达我吩咐你的一切话，你哥哥亚伦要求法老让以色列人离开他的国家。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 4:21; 出埃及记 11:9; 诗篇 105:27–36"> 可是，我要使法老的心刚硬，虽然我在埃及行许多神迹奇事，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 11:9; 出埃及记 6:6; 出埃及记 12:51"> 他仍无动于衷。那时，我必伸手重重地惩罚埃及，然后领我大队的以色列子民离开埃及。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 14:18; 出埃及记 7:17; 出埃及记 8:22"> 我伸手攻击他们，把以色列人带出埃及之时，埃及人就会知道我是耶和华。”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 7:2; 创世记 6:22; 出埃及记 7:10"> 摩西和亚伦便遵命而行。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 34:7; 使徒行传 7:30; 申命记 31:2"> 他们去见法老的时候，摩西八十岁，亚伦八十三岁。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 4:2; 约翰福音 2:18; 以赛亚书 7:11"> “倘若法老要你们行神迹给他看，你就吩咐亚伦把手杖扔在法老面前，使杖变作蛇。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:3; 路加福音 10:19; 阿摩司书 9:3"> 摩西和亚伦照耶和华的吩咐来到法老面前。亚伦把手杖扔在法老和他的臣仆面前，杖就变作蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:22; 提摩太后书 3:8; 出埃及记 8:18"> 法老召智者和巫师前来，这些人是埃及的术士，他们也用邪术如法炮制。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:4; 出埃及记 9:11; 出埃及记 8:18–19"> 各人将自己的手杖扔在地上，杖就变作蛇，但亚伦的杖吞噬了他们的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 4:21; 出埃及记 8:15; 撒迦利亚书 7:11–12"> 法老却仍然硬着心，不肯听从摩西和亚伦，正如耶和华所言。</span>
</div>
</div>

## 水变血之灾

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 10:20; 出埃及记 8:15; 出埃及记 10:1"> 耶和华对摩西说：“法老非常顽固，不肯放百姓走。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 8:20; 出埃及记 2:5; 出埃及记 7:10"> 明天早晨，法老会去尼罗河边，你去河边见他，要拿着曾变成蛇的手杖。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 3:18; 出埃及记 9:1; 出埃及记 9:13"> 你要对他说，‘希伯来人的上帝耶和华差遣我来告诉你，要让祂的子民到旷野去事奉祂，但到如今你还是不肯。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:9; 出埃及记 5:2; 出埃及记 7:5"> 所以祂说要用手杖击打尼罗河水，使河水变成血，好叫你知道祂是耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:24; 出埃及记 7:21; 民数记 11:20"> 河里的鱼会死，河水会发臭，埃及人不能再喝尼罗河的水。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 14:21; 出埃及记 10:12; 出埃及记 8:5–6"> 耶和华对摩西说：“你告诉亚伦，让他向埃及境内的各江河、溪流、池塘伸杖，使水变成血。埃及境内，包括木头和石头器皿中将到处是血。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 78:44; 诗篇 105:29; 出埃及记 7:17–18"> 摩西和亚伦就按着耶和华所吩咐的去做，亚伦在法老和他的众臣仆面前举杖击打尼罗河水，河水都变成了血。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 7:18; 启示录 8:9"> 河里的鱼都死了，河水臭得不能饮用。埃及遍地都是血。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 7:11; 提摩太后书 3:8; 耶利米书 27:18"> 可是，埃及的巫师用邪术同样使水变成血。法老仍然硬着心，不肯听从摩西和亚伦的话，正如耶和华所言。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 36:24; 以西结书 40:4; 玛拉基书 2:2"> 法老若无其事地转身回宫去了。</span>
<span className="v" id="v24" data-v="24"> 因为河水不能饮用，埃及人就在尼罗河两岸掘井取水饮用。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:23; 出埃及记 8:9–10; 撒母耳记下 24:13"> 耶和华击打河水后，七天过去了。</span>
</div>
</div>

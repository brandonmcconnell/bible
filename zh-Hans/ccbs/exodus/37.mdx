## 约柜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:10–20; 出埃及记 26:33; 民数记 10:33–36"> 比撒列用皂荚木造了一个柜，长一米一，宽七十厘米，高七十厘米。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:3"> 这柜子里外都包上纯金，还镶了一圈金边。</span>
<span className="v" id="v3" data-v="3"> 他造了四个金环，安在柜的四个脚上，每边两个环，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 9:15; 彼得前书 1:7; 民数记 4:14–15"> 又用皂荚木造了两根横杠，包上金，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 4:15; 撒母耳记下 6:3–7; 民数记 1:50"> 然后把横杠穿过柜两边的金环，便于抬柜。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 9:5; 提多书 2:14; 罗马书 3:25"> 他用纯金造了一个施恩座，长一米一，宽七十厘米。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 10:2; 诗篇 104:4; 诗篇 80:1"> 又用金子在施恩座的两端打造两个基路伯天使。</span>
<span className="v" id="v8" data-v="8"> 这两个基路伯天使跟施恩座连在一起，在施恩座的两端，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 1:51; 希伯来书 1:14; 创世记 28:12"> 面对面朝向施恩座，向上展开翅膀遮盖施恩座。</span>
</div>
</div>

## 桌子

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:14; 以西结书 40:39–42; 玛拉基书 1:12"> 他用皂荚木造了一张桌子，长九十厘米，宽四十五厘米，高七十厘米。</span>
<span className="v" id="v11" data-v="11"> 整张桌子都包上纯金，四周镶上金边。</span>
<span className="v" id="v12" data-v="12"> 在桌子四周造一个八厘米宽的外框，外框镶上金边。</span>
<span className="v" id="v13" data-v="13"> 他又造四个金环，安在桌子四角的桌腿上，</span>
<span className="v" id="v14" data-v="14"> 金环靠近外框，以便穿横杠抬桌子。</span>
<span className="v" id="v15" data-v="15"> 他用皂荚木造两根横杠，外面包金，用来抬桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:29; 列王纪上 7:50; 列王纪下 12:13"> 又用纯金造桌子上的器具，就是盘、碟及献酒用的杯和瓶。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 25:31–39; 希伯来书 9:2; 历代志下 13:11"> 他用纯金造了一座灯台，灯台的灯座、灯柱、油杯、花瓣和花萼都是用一块纯金打成的。</span>
<span className="v" id="v18" data-v="18"> 灯台两边各伸出三个分枝，共六个分枝。</span>
<span className="v" id="v19" data-v="19"> 每个分枝上都有三个杏花形状、有花瓣和花萼的杯，六个分枝都是这样。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 12:5; 耶利米书 1:11; 出埃及记 25:33"> 灯台上有四个杏花形状、有花瓣和花萼的杯。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:35"> 灯台上每一对分枝的相连处有花萼，三对分枝都是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:5; 出埃及记 25:31; 诗篇 51:17"> 整座灯台，包括花萼和分枝，都是用一块纯金打成的。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 1:12; 出埃及记 25:37; 启示录 1:20–1"> 他又用纯金为这座灯台造了七个灯盏，以及灯剪和灯花盘。</span>
<span className="v" id="v24" data-v="24"> 造整座灯台和灯台的器具共用了六百八十两纯金。</span>
</div>
</div>

## 造香坛

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:1–5; 希伯来书 7:25; 启示录 8:3–4"> 他又用皂荚木造了一座方形的香坛，长宽各四十五厘米，高九十厘米，坛上面凸起的四角与坛连成一体，</span>
<span className="v" id="v26" data-v="26"> 坛顶、坛的四面和坛上凸起的角包上纯金，四周镶上金边。</span>
<span className="v" id="v27" data-v="27"> 他造了两个金环，安在坛两侧的金边下面，</span>
<span className="v" id="v28" data-v="28"> 又用皂荚木造横杠，包上金，穿在两个环里，用来抬香坛。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 141:2; 希伯来书 7:25; 约翰一书 2:20"> 他又用调制香料的方法制作圣膏油和纯净芬芳的香。</span>
</div>
</div>

## 以色列人受欺压

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 2:1–2; 创世记 46:8–26; 创世记 35:23–26"> 以色列的众子带着家眷跟雅各<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“雅各”就是“以色列”，上帝为雅各改名以色列，故事参考创世记32:28。">a</a></sup>一起去了埃及，以下是他们的名字：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:22"> 吕便、西缅、利未、犹大、</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:20; 创世记 35:23"> 以萨迦、西布伦、便雅悯、</span>
<span className="v" id="v4" data-v="4"> 但、拿弗他利、迦得、亚设。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:26–27; 士师记 8:30"> 雅各的子孙总共有七十人。那时，约瑟已经住在埃及。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 50:26; 创世记 50:24; 使徒行传 7:14–16"> 后来，约瑟和他的弟兄以及同辈的人都相继去世。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 46:3; 创世记 1:28; 申命记 26:5"> 以色列人生养众多，人口大增，很快就遍布埃及，成为一个强大的民族。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 7:18; 传道书 2:18–19; 传道书 9:15"> 后来，埃及有一位不认识约瑟的新王登基，</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 105:24–25; 传道书 4:4; 雅各书 3:14–16"> 对他的百姓说：“你们看，以色列人比我们多，又比我们强。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:19; 诗篇 83:3–4; 箴言 1:11"> 来吧！我们要设法阻止他们人口增多，否则一遇到战争，他们便会加入我们敌人的阵营来攻打我们，然后一走了之。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 15:13; 创世记 47:11; 出埃及记 3:7"> 于是，埃及人派监工强迫以色列人服劳役，在比东和兰塞两地为法老兴建储货城。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 105:24; 出埃及记 1:9; 罗马书 8:28"> 以色列人越受奴役，人口增长得越快，散居的范围也越广，令埃及人感到恐惧。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:20"> 于是，埃及人残酷地奴役他们，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:19; 民数记 20:15; 出埃及记 2:23"> 强迫他们和泥造砖，并做田间一切的苦工，使他们痛苦不堪。埃及人残酷地奴役他们做苦工。</span>
<span className="v" id="v15" data-v="15"> 埃及王又命令两个希伯来的接生婆施弗拉和普阿：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:22; 马太福音 21:38; 启示录 12:4"> “你们在替希伯来妇女接生的时候，如果看到生下的是男婴，就把他杀掉；如果是女婴，就让她活下来。”</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:29; 出埃及记 1:21; 马太福音 10:28"> 但这两个接生婆敬畏上帝，没有执行埃及王的命令，而是保留了男婴的性命。</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 8:4; 撒母耳记下 13:28"> 埃及王召见那两个接生婆，质问她们：“你们为什么这样做？为什么让男婴活着？”</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 2:4–24; 撒母耳记下 17:19–20; 撒母耳记上 21:2"> 她们回答说：“因为希伯来妇女跟埃及妇女不同。她们身体强壮，我们还没有赶到，婴儿就生下来了。”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 3:10; 传道书 8:12; 箴言 11:18"> 因此，以色列人口继续增加，更加繁盛。因为这两个接生婆敬畏上帝，上帝便赐福给她们，使她们生儿育女。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 7:19; 箴言 1:16; 出埃及记 1:16"> 后来，法老命令全埃及的人把以色列人生的所有男婴都抛进尼罗河里，只让女婴活着。</span>
</div>

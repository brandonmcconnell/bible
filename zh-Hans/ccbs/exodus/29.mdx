## 立祭司的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 4:3; 玛拉基书 1:13–14; 出埃及记 12:5"> “你要使亚伦父子们分别出来，做圣洁的祭司事奉我。做法如下：你要选一头公牛犊和两只毫无残疾的公绵羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:15; 利未记 2:15; 利未记 7:12"> 用细面粉预备无酵饼、调上油的无酵饼和涂上油的无酵薄饼。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 6:17; 利未记 8:26; 利未记 8:2"> 所有的饼都要用一个篮子盛，连同公牛和绵羊一起带到会幕那里。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 40:12; 希伯来书 10:22; 出埃及记 26:36"> 你要把亚伦父子们带到会幕门口，用水洗他们，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:2–8; 利未记 8:7–8"> 然后给亚伦穿上内袍、以弗得和以弗得的外袍，戴上胸牌，束上精致的以弗得带子，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 8:9; 出埃及记 28:36–39"> 戴上礼冠，把圣冠<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“圣冠”应指28章提到的金牌。">a</a></sup>系在礼冠上。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:25; 利未记 21:10; 约翰福音 3:34"> 之后，把膏油倒在他头上，立他为祭司。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 8:13; 出埃及记 28:40"> 接着轮到亚伦的儿子们，要给他们穿上内袍，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:7; 利未记 8:22–28; 申命记 18:5"> 为他们束上腰带，戴上头巾，他们就按永远的律例得到祭司的职分。你要这样把圣职授予他们。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 利未记 8:14; 出埃及记 29:15"> “你要把公牛牵到会幕前面，亚伦父子们要把手按在公牛头上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 9:8; 利未记 9:12; 出埃及记 29:4"> 你要在会幕门前，在耶和华面前宰公牛。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:2; 利未记 9:9; 利未记 8:15"> 要取些公牛的血带到祭坛那里，用手指把血抹在祭坛凸起的四角上，再把剩下的血倒在坛脚。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:3–4; 撒母耳记上 2:16; 利未记 9:10"> 再把包裹内脏的脂肪、肝叶、两个肾脏和肾脏上的脂肪都放在祭坛上烧掉。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:11–12; 利未记 4:21; 出埃及记 30:10"> 但公牛的皮、肉和粪要拿到营外焚烧。这是赎罪祭。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:19; 出埃及记 29:3; 利未记 8:18–21"> “要把一只公绵羊牵来，亚伦父子们要把手按在羊头上，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:11–12"> 然后你要宰羊，把血洒在祭坛四周。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 4:14; 利未记 1:13; 利未记 1:9"> 再把羊切成块状，用水洗净所有的内脏和腿，跟肉块和头放在一起。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 8:21; 腓立比书 4:18; 创世记 22:7"> 然后，把整只羊放在祭坛上焚烧，这是献给耶和华的燔祭，是蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:3; 利未记 8:22–29"> “你要把另一只公绵羊牵来，亚伦父子们要把手按在羊头上，</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 50:5; 希伯来书 10:22; 利未记 14:16"> 然后你要宰羊，取一点血涂在亚伦和他儿子们的右耳垂、右手大拇指和右脚大脚趾上，剩下的血就洒在祭坛四周。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:22; 出埃及记 29:7; 出埃及记 29:1"> 再从祭坛上取些血，与膏油一起洒在亚伦父子及其衣服上。这样，他们和他们的衣服就会变得圣洁。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:13; 利未记 9:21; 利未记 9:19"> “你要取出羊的脂肪、肥尾巴、包裹内脏的脂肪、肝叶、两个肾脏、肾脏上的脂肪和右腿，因为这是授圣职时所献的羊。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:2–3; 利未记 8:26"> 再从耶和华面前装无酵饼的篮子里取一个饼、一个油饼和一个薄饼。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 7:30; 利未记 8:27; 利未记 9:21"> 把这些都放在亚伦父子们手中，作为摇祭在耶和华面前摇一摇。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:28; 出埃及记 29:41; 利未记 3:16"> 然后，你要把这些祭物接过来，放在祭坛的燔祭上焚烧献给耶和华，成为蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 8:29; 利未记 7:31; 利未记 7:34"> 你要拿起亚伦承受圣职时所献的那只公绵羊的胸肉，作为摇祭在耶和华面前摇一摇。之后，这份祭肉就归你。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 10:15; 民数记 18:11; 申命记 18:3"> “你要将属于亚伦父子们、授圣职时所献公绵羊的摇祭胸肉和举祭腿肉分别出来，使之圣洁。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:19–20; 利未记 7:11–38; 利未记 10:14–15"> 这些祭物要从以色列人所献的平安祭中取出来，归给亚伦父子们，作为永远的定例。这是以色列人当向耶和华献的祭物。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 18:8; 出埃及记 28:3–4; 出埃及记 30:30"> “亚伦的圣衣要留给他的子孙，他们可以穿上这圣衣受膏，承受圣职。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 20:28; 利未记 13:5; 使徒行传 20:6–7"> 接替亚伦做祭司的那位后裔，每次进会幕的圣所供职时，都要一连七天穿着圣衣。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 8:31; 撒母耳记上 2:13; 以西结书 46:20–24"> “你要在圣洁的地方煮授圣职时所用的公绵羊肉。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 12:4; 出埃及记 29:23; 出埃及记 29:2–3"> 亚伦父子们可以在会幕的门前吃这公绵羊祭肉和篮内的饼。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:4; 利未记 10:13–18; 诗篇 22:26"> 他们要吃这些在授圣职时用来赎罪、使他们圣洁的祭物。但祭司以外的人不能吃，因为这些是圣物。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 12:10; 利未记 8:32; 出埃及记 29:22"> 若有授圣职时所献的肉或饼留到早晨，就要烧掉，不可再吃，因为这些都是圣物。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 29:30; 利未记 14:8–11; 利未记 8:4–36"> “你要照我的吩咐，为亚伦父子们举行授圣职礼，历时七天。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 10:11; 希伯来书 9:22–23; 出埃及记 30:28–29"> 每天要献一头公牛作赎罪祭，来洁净祭坛，然后用膏油抹祭坛，使祭坛圣洁。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 40:10; 马太福音 23:19; 出埃及记 30:28–29"> 连续七天都要这样做，使祭坛完全圣洁，凡是碰到祭坛的都变得圣洁。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志下 2:4; 历代志上 16:40; 民数记 28:3–8"> “你每天要在祭坛上献两只一岁的公羊羔，</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 46:13–15; 列王纪下 16:15; 诗篇 5:3"> 早晨和黄昏各献一只。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:17; 以西结书 46:14; 约珥书 2:14"> 要用一公斤细面粉调一升橄榄油做成素祭，与早晨献的羊羔一同献上，再献上一升酒作奠祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 46:13–15; 列王纪上 18:29; 诗篇 141:2"> 黄昏献第二只羊时，也要跟早晨一样同时献上素祭和奠祭，作为蒙耶和华悦纳的馨香火祭。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 25:22"> “你们世世代代要不断地在我面前献上燔祭，祭礼要在会幕门前举行，这会幕就是我跟你们会面交谈的地方。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 8:11; 历代志下 7:1–3; 玛拉基书 3:1"> 我要在那里和以色列人相会，我的荣耀将使会幕圣洁。</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 21:15; 利未记 22:9; 利未记 22:16"> “我要使会幕和祭坛圣洁，也要使亚伦父子们圣洁，做祭司事奉我。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 26:12; 哥林多后书 6:16; 出埃及记 25:8"> 我要住在以色列人中间，做他们的上帝。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 20:2; 耶利米书 31:33; 以西结书 20:5"> 他们必知道我是他们的上帝耶和华。我带领他们离开埃及，就是为了要住在他们中间。我是他们的上帝耶和华。</span>
</div>

## 奉献的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 9:7; 尼希米记 11:2; 以斯拉记 2:68"> “你去吩咐以色列百姓要献礼物给我。你们要为我收下所有甘心乐意献上的礼物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:9; 约伯记 28:2"> 你们要收的礼物是金、银、铜，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:8; 创世记 41:42; 以西结书 16:10"> 蓝色、紫色和朱红色毛线，细麻，山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 26:37–1; 出埃及记 26:14–15; 出埃及记 36:20"> 染成红色的公羊皮，海狗皮，皂荚木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 27:20; 出埃及记 25:37; 出埃及记 40:24–25"> 灯油，制作膏油和香的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 出埃及记 28:6–30"> 镶嵌在以弗得和胸牌上的红玛瑙及其他宝石。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:16; 列王纪上 6:13; 启示录 21:3"> 他们要为我造一座圣所，我好住在他们中间。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:40; 希伯来书 8:5; 使徒行传 7:44"> 你们要完全照我指示的样式造圣幕和里面的各样器具。</span>
</div>
</div>

## 造约柜的条例

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 9:4; 出埃及记 37:1–3; 申命记 10:1–3"> “要用皂荚木做一个柜，长一米一，宽七十厘米，高七十厘米，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:24; 出埃及记 30:3; 历代志下 3:4"> 里外都要包上纯金，要用金子镶柜边。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:7; 出埃及记 25:26; 出埃及记 25:15"> 再铸造四个金环，安在柜的四个脚上，每边两个环。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 15:15; 民数记 4:11; 出埃及记 27:6"> 用皂荚木造两根横杠，包上金，</span>
<span className="v" id="v14" data-v="14"> 然后把横杠穿过柜两边的金环，便于抬柜。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 8:8; 历代志下 5:9"> 横杠穿进柜环以后，不可再抽出来。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 31:26; 列王纪上 8:9; 希伯来书 9:4"> 把我将要赐给你的两块约版放在柜里。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 9:5; 出埃及记 37:6; 希伯来书 4:16"> 要用纯金造一个施恩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“施恩”或译“赎罪”。">a</a></sup>座，长一米一，宽七十厘米。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 10:20; 希伯来书 9:5; 列王纪上 8:6–7"> 用金子在施恩座的两端打造两个基路伯天使，</span>
<span className="v" id="v19" data-v="19"> 跟施恩座连在一起，一端一个。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:18; 列王纪上 8:7; 希伯来书 9:5"> 两个基路伯天使要面对面朝向施恩座，向上展开翅膀，遮盖施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:34; 罗马书 10:4; 出埃及记 25:16–17"> 要把施恩座放在柜上面，把我要赐给你的约版放在柜里。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:42–43; 民数记 7:89; 以赛亚书 37:16"> 我就在那里跟你会面，从约柜上面两个基路伯天使中间的施恩座上，把要传给以色列百姓的一切诫命告诉你。</span>
</div>
</div>

## 造供桌的条例

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 9:2; 出埃及记 37:10–16; 列王纪上 7:48"> “要用皂荚木造一张桌子，长九十厘米，宽四十五厘米，高七十厘米。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 25:11; 列王纪上 6:20–22"> 整张桌子都要包上纯金，四周镶上金边，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:2; 出埃及记 30:3"> 在桌子四周造一个八厘米宽的外框，外框镶上金边。</span>
<span className="v" id="v26" data-v="26"> 要造四个金环，安在桌子四角的桌腿上，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 25:14; 出埃及记 25:28"> 金环要靠近外框，以便穿横杠抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:14; 使徒行传 9:15; 民数记 10:17"> 两根横杠要用皂荚木制作，外面包金，用来抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 4:7; 出埃及记 37:16; 启示录 3:20"> 你们要用纯金造桌子上的盘、碟和献酒用的瓶和杯。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 24:5–9; 马太福音 12:4; 出埃及记 39:36"> 桌子上要一直摆着供饼，献在我面前。</span>
</div>
</div>

## 造灯台的条例

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 7:49; 撒迦利亚书 4:2; 出埃及记 37:17–24"> “要用纯金造一个灯台，灯台的灯座、灯柱、油杯、花萼和花瓣要用一块纯金打造。</span>
<span className="v" id="v32" data-v="32"> 灯台两边要各伸出三个分枝，共六个分枝。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 17:4–8; 耶利米书 1:11–12; 撒迦利亚书 4:3"> 每个分枝上要有三个杏花形状、有花瓣和花萼的杯，六个分枝都是这样。</span>
<span className="v" id="v34" data-v="34"> 灯台上要有四个杏花形状、有花瓣和花萼的杯。</span>
<span className="v" id="v35" data-v="35"> 灯台上每一对分枝的相连处要有花萼，三对都是这样。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:18; 列王纪上 10:16–17; 历代志下 9:15"> 整座灯台，包括花萼和分枝，都要用一块纯金打造。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 8:2; 启示录 1:20–1; 利未记 24:2–4"> 此外，要为灯台造七个灯盏，放在灯台上面，照亮前面的地方。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪下 12:13; 耶利米书 52:18; 列王纪下 25:14"> 灯台用的灯剪和灯花盘都要用纯金造。</span>
<span className="v" id="v39" data-v="39"> 造整座灯台和灯台的器具要用六百八十两纯金。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 8:5; 出埃及记 26:30; 使徒行传 7:44"> 你务要照着在山上指示你的样式造各样器具。</span>
</div>
</div>

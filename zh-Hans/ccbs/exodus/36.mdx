<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 28:3; 出埃及记 35:30–35; 出埃及记 31:1–6"> 摩西说：“比撒列、亚何利亚伯以及所有蒙耶和华赐智慧聪明、有技能、懂得如何建造圣所的人，都要按照耶和华的吩咐去做。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 4:17; 希伯来书 5:4; 出埃及记 31:6"> 于是，摩西召来比撒列、亚何利亚伯和所有蒙耶和华赐智慧、有技能、愿意参与建造的人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:27; 出埃及记 35:5–21"> 他们从摩西那里领取了以色列百姓奉献出来建造圣所的一切礼物。每天早上，百姓仍然甘心乐意地来奉献礼物，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 3:10; 路加福音 12:42; 马太福音 24:45"> 以致所有建造圣所的能工巧匠都放下自己的工作，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 31:6–10; 哥林多后书 8:2–3; 历代志下 24:14"> 前来对摩西说：“百姓的奉献太多了，我们建造耶和华吩咐的圣所用不了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 于是，摩西传令全营：“男女都不用再为圣所奉献礼物了。”百姓这才停止奉献。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:10"> 因为所献的材料已经足够建造圣所，而且绰绰有余。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:23; 出埃及记 26:1–37; 以西结书 1:5–28"> 工人中的能工巧匠用十幅幔子做成了圣幕，幔子用细麻和蓝色、紫色、朱红色毛线织成，上面精工绣制了基路伯天使。</span>
<span className="v" id="v9" data-v="9"> 每幅幔子的尺寸都一样，长十二米半、宽一米八。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 12:27; 出埃及记 26:3; 诗篇 122:3"> 又把每五幅幔子连在一起，共连成两幅大幔子。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:4"> 然后在每幅大幔子末幅的边缘钉上了蓝色的扣环，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 26:5; 出埃及记 26:10"> 每幅大幔子各钉上五十个扣环，都是两两相对。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:4–5; 以弗所书 2:20–22; 哥林多前书 12:20"> 又做了五十个金钩，把两幅大幔子连在一起，成为一个完整的圣幕。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 26:7–13"> 比撒列用山羊毛织成十一幅幔子，做圣幕的罩棚，</span>
<span className="v" id="v15" data-v="15"> 每幅长十三米半、宽一米八。十一幅幔子的尺寸都一样。</span>
<span className="v" id="v16" data-v="16"> 然后把五幅连成一大幅，其余六幅连成一大幅。</span>
<span className="v" id="v17" data-v="17"> 又在这两幅大幔子边缘各钉上五十个对称的扣环，</span>
<span className="v" id="v18" data-v="18"> 再用五十个铜钩，把两幅大幔子连在一起，成为一个完整的罩棚，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:14"> 并在罩棚上面盖一层染成红色的公羊皮，再盖一层海狗皮做顶盖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 25:5; 民数记 25:1; 出埃及记 40:18–19"> 他用皂荚木做支圣幕的木板，</span>
<span className="v" id="v21" data-v="21"> 每块木板长四米半，宽七十厘米，</span>
<span className="v" id="v22" data-v="22"> 上面都有两个接榫，用来衔接。圣幕的所有木板都这样做。</span>
<span className="v" id="v23" data-v="23"> 圣幕的南面立二十块木板，</span>
<span className="v" id="v24" data-v="24"> 在这些木板下面又造了四十个带凹槽的银底座，每块木板下面有两个，套在木板的两个接榫上。</span>
<span className="v" id="v25" data-v="25"> 圣幕北面也立二十块木板，</span>
<span className="v" id="v26" data-v="26"> 木板下面同样有四十个带凹槽的银底座，每块木板下面有两个银底座。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:22; 出埃及记 26:27"> 圣幕后面，就是西面，立六块木板，</span>
<span className="v" id="v28" data-v="28"> 圣幕后面的两个拐角各有一块木板，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:32; 以弗所书 3:18–19; 哥林多前书 1:10"> 木板的下端连于底座，顶端用一个环固定。两个拐角都这样做。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:25"> 这样，后面共有八块木板，每块木板下面各有两个带凹槽的银底座，一共有十六个银底座。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 26:26–29; 出埃及记 25:28; 出埃及记 30:5"> 他用皂荚木做横闩，圣幕左右两边和后面的墙板上各有五根横闩，</span>
<span className="v" id="v33" data-v="33"> 拦腰固定墙板的那根横闩从这端贯穿到那端。</span>
<span className="v" id="v34" data-v="34"> 所有的木板和横闩都包上金，并在木板上造金环，用来穿横闩。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:51; 希伯来书 10:20; 出埃及记 40:21"> 他用细麻和蓝色、紫色、朱红色毛线织成一幅幔子，上面精工绣上基路伯天使，</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 1:18"> 把这幅幔子挂在四根包金的皂荚木柱上，木柱上有金钩，四根柱子下面有四个银底座。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 26:36–37; 出埃及记 40:28"> 他又用细麻和蓝色、紫色、朱红色毛线绣制圣幕的门帘，</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 27:10"> 用皂荚木做五根挂门帘的柱子，上面有金钩，柱顶和箍包上金。柱子的五个带凹槽的底座是铜造的。</span>
</div>
</div>

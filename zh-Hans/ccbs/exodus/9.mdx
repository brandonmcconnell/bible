## 瘟疫之灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 8:1; 出埃及记 10:3; 出埃及记 8:20"> 耶和华对摩西说：“你去见法老，告诉他，‘希伯来人的上帝耶和华说：放我的子民走，他们好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 8:2; 出埃及记 4:23; 利未记 26:27–28"> 如果你不让他们走，继续扣留他们，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:4; 使徒行传 13:11; 撒母耳记上 6:9"> 我必出手使你田间所有的牲畜，包括马、驴、骆驼和牛羊，都染上严重的瘟疫。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 8:22; 出埃及记 10:23; 玛拉基书 3:18"> 但我要把埃及和以色列的牲畜分开，以色列人的牲畜必丝毫无损。’”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 8:23; 出埃及记 10:4; 耶利米书 28:16–17"> 耶和华定了日期，说：“明天耶和华必在此地行这事。”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:48; 出埃及记 9:25; 诗篇 78:50"> 第二天，耶和华就行了这事，埃及人的牲畜都死了，但以色列人的牲畜一头也没死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 7:14; 出埃及记 8:32; 以赛亚书 48:4"> 法老派人去探查，发现以色列人的牲畜一头也没死。可是，他仍然心里顽固，不肯让以色列人离开。</span>
</div>
</div>

## 脓疮之灾

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 8:16"> 耶和华对摩西和亚伦说：“你们去取几把窑里的灰，摩西要在法老面前把灰抛向空中。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 16:2; 申命记 28:27; 约伯记 2:7"> 这灰要变成尘土，散布在埃及全境，落在人或牲畜身上，就会起疱长疮。”</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 28:27"> 摩西和亚伦便取了一些窑里的灰，站在法老面前，摩西把灰抛向空中，埃及人和牲畜身上就开始起疱长疮。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:11–12; 出埃及记 8:18–19; 启示录 16:2"> 埃及的巫师无法与摩西对抗，因为他们及所有埃及人身上都长了脓疮。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 诗篇 81:11–12"> 耶和华使法老的心刚硬，他就不听他们的话，正如耶和华对摩西说的。</span>
</div>
</div>

## 冰雹之灾

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 8:20; 出埃及记 7:15; 出埃及记 9:1"> 耶和华对摩西说：“明天一早你再去见法老，对他说，‘希伯来人的上帝耶和华这样说，你要放我的子民走，他们好事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 8:10; 利未记 26:28; 历代志上 17:20"> 这一次，我要降下大灾祸在你及你的臣仆和百姓身上，好叫你知道普天之下我独一无二。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 3:20; 出埃及记 9:3; 出埃及记 9:16"> 我若用瘟疫攻击你和你的百姓，你们早就灭亡了。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:17; 箴言 16:4; 诗篇 83:17–18"> 我让你活到现在，是为了向你彰显我的权能，使我的名传遍天下。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:29; 以赛亚书 10:15; 以赛亚书 37:23–24"> 但你竟然在我的子民面前狂傲自大，不让他们离开。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 20:6; 诗篇 83:15; 出埃及记 9:22–25"> 明天大约这时候，我要使天上降下大冰雹，是你们埃及立国以来从没有见过的。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 3:2"> 现在，你要叫人到田间把牲畜和属于你的一切都带到安全的地方。凡留在田间的人或牲畜都会被冰雹打死。’”</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯来书 11:7"> 有些法老的臣仆听了耶和华的话就很害怕，赶忙把在田间的仆人和牲畜都召回屋里。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 40:4; 约伯记 34:14; 历代志上 22:19"> 但那些不把耶和华的话放在心上的，仍把他们的奴仆和牲畜留在田间。</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 16:21; 出埃及记 7:19; 出埃及记 8:5"> 耶和华对摩西说：“你向天伸杖，天就会降下冰雹，落在埃及的一切人畜身上，摧毁田间的一切农作物。”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 18:13; 约书亚记 10:11; 以赛亚书 30:30"> 摩西向天伸出手杖，耶和华就发出雷电和冰雹，火光飞向大地。耶和华在埃及降下冰雹。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 9:23; 马太福音 24:21; 出埃及记 10:6"> 那时冰雹夹杂着火降下来，极为严重，在埃及史无前例。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 78:47; 诗篇 105:32–33"> 冰雹摧毁了埃及境内田间的一切人、牲畜和作物，打断了所有的树木，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 11:7; 出埃及记 9:4; 出埃及记 10:23"> 只有以色列人所住的歌珊没有冰雹。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 诗篇 129:4; 出埃及记 10:16"> 法老派人召来摩西和亚伦，对他们说：“这次我犯罪了，耶和华是对的，我和我的百姓错了。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 8:8; 出埃及记 10:17; 出埃及记 8:28"> 请你们向耶和华祈求，我们已经受够了雷电和冰雹。我准许以色列人出去，你们不必再留在这里了。”</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:26; 列王纪上 8:38; 以赛亚书 1:15"> 摩西回答说：“我一出城，就向耶和华举手祷告，雷电和冰雹必立刻停止，这样你就知道普天下都属于耶和华。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 26:10; 箴言 16:6; 以赛亚书 63:17"> 但我知道你和你的臣仆还是不敬畏上帝耶和华。”</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 1:22; 路得记 2:23; 哈巴谷书 3:17"> 这场冰雹打坏了大麦和亚麻，因为正是大麦吐穗和亚麻开花的时候。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:22"> 小麦和粗麦尚未长成，没有被冰雹打坏。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 9:29; 出埃及记 8:12; 雅各书 5:17–18"> 摩西离开法老，走出城外向耶和华举手祷告，雷和冰雹便停了，雨也不下了。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 7:14; 历代志下 36:13; 出埃及记 4:21"> 法老看见雨、雷和冰雹停止了，就又犯罪，他和他的臣仆都心里顽固。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 4:21"> 法老硬着心，不让以色列人离开，正如耶和华借摩西所言。</span>
</div>
</div>

## 如何对待奴仆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:14; 申命记 6:20; 出埃及记 24:3–4"> “你要向百姓颁布下列法令。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 15:12–15; 出埃及记 12:44; 申命记 15:18"> 你若买一个希伯来人当奴仆，他必须服侍你六年，到第七年便可以获得自由，不用支付任何赎金。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 15:12–14"> 他来的时候若是单身，就可以单身离开。他来的时候若有妻子，就可以带妻子一起离开。</span>
<span className="v" id="v4" data-v="4"> 倘若主人给他娶了妻，妻子生了儿女，那么期满的时候，他只能单独离开，他的妻儿要归主人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14–15; 申命记 15:16–17; 以赛亚书 26:13"> 倘若奴仆说，‘我爱我的主人和我的妻子儿女，我不愿意离去做自由人。’</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:17; 利未记 25:40; 申命记 19:17–18"> 主人就要带他到审判官面前，让他靠着门或门框，用锥子为他穿耳洞。这样，他就要永远服侍主人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 5:5; 出埃及记 21:2–3"> 倘若有人把女儿卖为婢女，她不可像男仆那样离开。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:8; 申命记 20:7; 玛拉基书 2:11–15"> 倘若买她的主人本想把她留给自己，后来却不喜欢她，就必须让她赎身。主人无权把她转卖给外族人，因为是主人对她不守信用。</span>
<span className="v" id="v9" data-v="9"> 倘若是买来给自己的儿子，就要把她当作自己的女儿一般看待。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:1–6"> 倘若有人娶了婢女为妻，后来又另娶，他还是要照常供给她饭食和衣服，并履行同房的义务。</span>
<span className="v" id="v11" data-v="11"> 倘若主人不履行以上的三个条件，婢女就可以随时离开，不用缴付任何赎金。</span>
</div>
</div>

## 如何处理人身伤害

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 9:6; 马太福音 26:52; 利未记 24:17"> “打人致死的，必须被处死。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 20:2–9; 撒母耳记上 24:18; 申命记 4:41–43"> 倘若不是故意杀人，而是上帝许可那人死在他手里，他就可以逃往我指定的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 2:28–34; 希伯来书 10:26; 民数记 15:30–31"> 倘若是蓄意杀人，就算他逃到我的祭坛那里，也要把他拉出来处死。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 21:18–21; 箴言 30:17; 提摩太前书 1:9"> 殴打父母的，必须被处死。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 24:7; 提摩太前书 1:10; 出埃及记 22:4"> 绑架他人贩卖或自用的，必须被处死。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 马可福音 7:10–11; 申命记 27:16"> 咒骂父母的，必须被处死。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 21:20; 申命记 25:11; 撒母耳记下 14:6"> 倘若吵架时一方用拳头或石块致另一方受伤、躺卧在床，但不至于死，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 3:29; 撒迦利亚书 8:4"> 日后能起床扶着拐杖到户外走，伤人者便不算有罪，但要赔偿受伤者停工期间的损失，并要负责治好他。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命记 19:21; 民数记 35:19"> “倘若有人用棍子打他的仆婢，导致仆婢当场死亡，他必须受惩罚。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 25:44–46"> 倘若伤者过了一两天才死去，主人就可免刑，因为死者是他的财产。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 22:18–19; 出埃及记 21:30; 申命记 16:18"> 倘若有人彼此斗殴，伤了孕妇，导致早产，但未造成其他伤害，伤人者要按她丈夫所要求的金额，经审判官判定以后，如数赔偿。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 19:21; 民数记 35:31; 利未记 24:19"> 倘若还有其他伤害，伤人者就要以命偿命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 19:21; 马太福音 5:38–40; 马太福音 7:2"> 以眼还眼，以牙还牙，以手还手，以脚还脚，</span>
<span className="v" id="v25" data-v="25"> 以烧伤还烧伤，以创伤还创伤，以殴打还殴打。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 21:20; 约伯记 31:13–15; 诗篇 72:12–14"> “主人若打坏仆婢的一只眼睛，就要因此让仆婢自由离去。</span>
<span className="v" id="v27" data-v="27"> 同样，倘若他打掉了仆婢的一颗牙齿，也要因此而释放仆婢。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 21:32; 利未记 20:15–16; 创世记 9:5–6"> “倘若有牛抵死了人，要用石头打死那头牛，并且不可吃它的肉，牛的主人可算无罪。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 21:1–9"> 但倘若牛常常用角抵人，并且已经有人向牛的主人投诉，他却不拴好牛，以致牛抵死了人，就要用石块打死牛，并处死主人。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 21:22; 出埃及记 30:12; 民数记 35:31–33"> 若判他以钱赎命，不论金额多少，他都得照付。</span>
<span className="v" id="v31" data-v="31"> 牛若抵死了别人的儿女，也要照以上的条例办理。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 26:15; 撒迦利亚书 11:12–13; 马太福音 27:3–9"> 牛若抵死了别人的仆婢，牛的主人要赔七两银子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七两银子约是当时一个奴仆的身价。">a</a></sup>给那仆婢的主人，并要用石头打死牛。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米书 18:20; 传道书 10:8"> 倘若有人打开井盖或挖了井后不把井口盖好，以致有牛或驴掉进井里，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 22:6; 出埃及记 21:29–30; 出埃及记 22:14"> 井的主人就要赔偿牲畜的主人，死牲畜则归井的主人。</span>
<span className="v" id="v35" data-v="35"> 倘若某人的牛抵死了别人的牛，两家的主人就要卖掉活牛，平分所得，同时也要平分那头死掉的牛。</span>
<span className="v" id="v36" data-v="36"> 倘若素知牛好抵，主人却没有拴好它，他就要以牛还牛，死牛则归他。</span>
</div>

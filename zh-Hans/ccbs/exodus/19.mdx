## 以色列人在西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 16:1; 出埃及记 12:6; 利未记 23:16–18"> 以色列人离开埃及满三个月的那一天，他们来到西奈旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 3:1; 出埃及记 17:1; 出埃及记 3:12"> 他们离开利非订，来到西奈旷野，在那里的山下安营。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 3:4; 使徒行传 7:38; 出埃及记 20:21"> 摩西上山到上帝那里，耶和华从山上呼唤他说：“你告诉雅各家，告诉以色列人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 32:11–12; 以赛亚书 63:9; 以赛亚书 40:31"> ‘我怎样对付埃及人，怎样像鹰一样把你们背在翅膀上带来归属我，你们都看见了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 14:2; 申命记 7:6; 申命记 26:18"> 现在，你们若真心听从我的话，遵守我的约，就必在万民中做我宝贵的产业，因为普天下都是我的。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 5:10; 彼得前书 2:9; 彼得前书 2:5"> 你们要归于我，作祭司之国、圣洁之邦。这些话你要告诉以色列人。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 4:29–30; 出埃及记 3:16; 哥林多前书 15:1"> 摩西召集以色列的长老，把耶和华对他的一切吩咐都转告他们。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:7; 出埃及记 24:3; 约书亚记 24:24"> 百姓都齐声回答说：“凡耶和华所吩咐的，我们都愿意遵从。”<br />摩西便把他们的话回报耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 4:36; 出埃及记 19:16; 出埃及记 24:15–16"> 耶和华对摩西说：“我会在密云中临到你那里，使百姓也可以亲耳听见我与你说话的声音，这样他们就会永远信赖你。”摩西把以色列人的话回报耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:22; 创世记 35:2; 利未记 11:44–45"> 耶和华对摩西说：“你现在回到他们那里，吩咐他们今天和明天要洁净自己，洗净衣服，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 19:16; 出埃及记 34:5; 申命记 33:2"> 到后天都要预备好，因为这一天耶和华要在百姓眼前降临在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:20–21; 约书亚记 3:4; 出埃及记 19:21"> 此外，你要在山的四围划定界限，吩咐百姓不得上山或触碰山的边界，触碰者必被处死。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 4:16; 希伯来书 12:20; 出埃及记 19:16"> 你们不可用手碰违例者，要用石头打死他或用箭射死他，无论人畜，都不可存活。等到角声长鸣时，百姓才可上山。”</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:10"> 于是，摩西下山回到百姓那里，吩咐他们各人洁净自己，洗净衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 7:5; 撒母耳记上 21:4–5; 出埃及记 19:11"> 又吩咐他们说：“到后天一切都要准备好，这期间你们不可亲近女人。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:18–19; 诗篇 18:11–14; 希伯来书 12:21"> 到了第三天早晨，山上雷电大作，乌云密布，又有嘹亮的号角声，营中的百姓都胆战心惊。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 4:10; 申命记 5:5"> 摩西率领百姓出营迎接上帝，他们都站在山脚下。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:5; 出埃及记 3:2; 诗篇 144:5"> 因为耶和华在火中降临到西奈山，山上弥漫着浓烟，滚滚上腾，好像一个大火窑，整座山剧烈震动。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 81:7; 出埃及记 19:16; 尼希米记 9:13"> 号角声越来越嘹亮。摩西说话，上帝用雷鸣回应他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:13; 出埃及记 34:2; 出埃及记 19:11"> 耶和华降临在西奈山顶，召摩西到山顶，摩西就上去了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19; 出埃及记 3:5; 希伯来书 12:28–29"> 耶和华对摩西说：“你下去警告百姓不可闯过界限到我这里观看，以免很多人死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:5; 使徒行传 5:10; 历代志上 13:9–11"> 吩咐到我面前来的祭司要洁净自己，免得我忽然出来击杀他们。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 19:12; 约书亚记 3:4–5"> 摩西对耶和华说：“百姓不能上西奈山，因为你已经吩咐我们要在山的四围划定界限，使这山圣洁。”</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 4:16; 希伯来书 12:18–25; 希伯来书 12:29"> 耶和华对他说：“你下去把亚伦一起带来，祭司和百姓仍要留在原来的地方，不得乱闯到我面前，免得我忽然出来击杀他们。”</span>
<span className="v" id="v25" data-v="25"> 摩西就下去，把耶和华的话转告给百姓。</span>
</div>
</div>

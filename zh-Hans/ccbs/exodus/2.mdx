## 摩西出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:59; 历代志上 23:12–14; 出埃及记 6:16–20"> 有一个利未族的人跟他同族的女子结婚。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:23; 使徒行传 7:20; 诗篇 112:5"> 那女子怀孕，生了一个男婴。她看见孩子可爱，就把他藏了三个月。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 1:22; 使徒行传 7:19; 创世记 6:14"> 后来无法再藏下去，她就拿来一个蒲草篮子，外面涂上防水的沥青和柏油，然后把婴儿放在里面，又把篮子放在尼罗河边的芦苇丛中。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:59; 出埃及记 15:20; 弥迦书 6:4"> 婴儿的姐姐远远地站着，要看看她的弟弟究竟会怎样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 7:21; 诗篇 12:5; 诗篇 9:9"> 这时，法老的女儿来到河边沐浴，宫女们在河边行走。公主发现了芦苇丛中的篮子，便吩咐一个婢女去把它取来。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:50; 彼得前书 3:8; 使徒行传 7:21"> 公主打开一看，原来是一个男婴。公主看见孩子在哭，就可怜他，说：“他是希伯来人的孩子。”</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:4; 民数记 26:59; 民数记 12:1"> 婴儿的姐姐对公主说：“我去找一个希伯来妇女当奶妈，为你哺养他好吗？”</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 46:3–4; 诗篇 27:10; 出埃及记 6:20"> 公主回答说：“好！”那女孩就跑去把婴孩的母亲带来。</span>
<span className="v" id="v9" data-v="9"> 公主对那妇女说：“你把孩子抱去，替我哺养他，我会给你工钱。”她便把孩子抱去哺养。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 11:24; 创世记 16:11; 撒母耳记上 1:20"> 孩子渐渐长大，她便把他带到公主那里，孩子就做了公主的儿子。公主给孩子取名叫摩西，意思是“我把他从水中拉了上来”。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 11:24–26; 使徒行传 7:22–24; 出埃及记 1:11"> 后来，摩西长大了，他去看望做苦工的希伯来同胞，看见一个埃及人在殴打他的一个希伯来同胞。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:24–26"> 他左右观望，见四下无人，便下手杀了那埃及人，把尸体埋藏在沙地里。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:26–28; 哥林多前书 6:7–8"> 第二天，他又出去，看见两个希伯来人在打架，便过去对理亏的人说：“你为什么打自己的同胞呢？”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:14; 马太福音 21:23; 创世记 19:9"> 那人说：“谁立你做我们的首领和审判官？难道你要杀我，像杀那个埃及人一样吗？”摩西听了，害怕起来，心想：“我做的事一定被人知道了。”</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 7:29; 希伯来书 11:27; 创世记 24:11"> 法老听说这件事后，便想杀死摩西。摩西为了躲避法老，就逃到米甸居住。一天他坐在一口井旁，</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 24:11; 出埃及记 3:1; 撒母耳记上 9:11"> 米甸祭司的七个女儿来打水，要把水倒进槽里饮她们父亲的羊。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 29:10; 创世记 21:25; 创世记 26:15–22"> 这时，来了另外一群牧人要把她们赶走。摩西便起来帮助她们，打水饮她们的羊群。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 民数记 10:29; 出埃及记 4:18"> 她们回到父亲流珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“流珥”又名“叶特罗”。">a</a></sup>那里，父亲问道：“你们今天怎么这么快就回来了？”</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:11; 创世记 29:10"> 她们答道：“有一个埃及人救我们免遭牧人的欺负，还帮我们打水饮羊群。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 43:25; 希伯来书 13:2"> 他又问女儿们：“现在那人在哪里？你们怎么可以丢下他不管呢？去请他来吃点东西。”</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 31:38–40; 希伯来书 13:5; 希伯来书 11:25"> 后来，摩西同意住在那人家里。那人把女儿西坡拉许配给他。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:13–14; 使徒行传 7:29; 出埃及记 22:21"> 后来，西坡拉生了一个儿子，摩西给他取名叫革舜，意思是“我成了在异乡寄居的人”。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 18:20–21; 雅各书 5:4; 出埃及记 3:7–9"> 过了多年，埃及王死了。以色列人受尽奴役，就哀叹呼求，声音传到上帝那里。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 26:3; 诗篇 105:42; 出埃及记 6:5"> 上帝听见他们的哀声，顾念从前跟亚伯拉罕、以撒、雅各所立的约，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 4:31; 诗篇 55:22; 出埃及记 3:7–8"> 就垂顾他们，体恤他们。</span>
</div>
</div>

## 造香坛的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:3; 出埃及记 37:25–28; 出埃及记 40:5"> “你要用皂荚木造一座烧香用的坛。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2"> 坛是四方形的，长宽各四十五厘米，高九十厘米，坛上面凸起的四角与坛连成一体。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 25:11; 出埃及记 25:24"> 坛顶、坛的四面和坛上凸起的角要包上纯金，四周镶上金边。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:27; 出埃及记 26:29; 出埃及记 27:7"> 要在坛两侧的金边下面安两个金环，使横杠穿过金环，以便抬香坛。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:13; 出埃及记 25:27"> 要用皂荚木造横杠，包上金。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:21–22; 出埃及记 30:36; 利未记 16:13"> 要把香坛放在约柜前幔子的外面，对着约柜上的施恩座，就是我要跟你会面的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:28; 历代志上 23:13; 出埃及记 27:20–21"> “亚伦每天早上料理灯台的时候，要在这坛上烧芬芳的香。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 9:24; 帖撒罗尼迦前书 5:17; 希伯来书 7:25"> 黄昏点灯的时候，他也要在耶和华面前烧香，世世代代都要如此。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 10:1"> 不可在这香坛上烧别的香料，不可用这坛来献燔祭或素祭，也不可在上面浇奠祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:18; 希伯来书 9:22–23; 利未记 16:29–30"> 亚伦每年要用赎罪祭牲的血在坛的角上行一次赎罪礼，世代如此。这是耶和华至圣的坛。”</span>
</div>
</div>

## 人丁的赎价

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:50; 历代志上 27:24; 出埃及记 38:25–26"> “你统计以色列人口的时候，每一个被统计的男子都要缴付赎价给耶和华，赎回自己的性命，免得在统计人口期间发生灾祸。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:25; 民数记 3:47; 以西结书 45:12"> 凡被统计的人都要付六克银子，即十季拉，以圣所的秤为准，作为献给耶和华的礼物。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:20; 民数记 1:18; 民数记 1:3"> 凡被统计的，年龄在二十岁以上的男子都要献此礼物给耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:50; 利未记 17:11; 出埃及记 30:12"> 富有的不用多缴，贫穷的也不可少付，每个人都要献六克银子给耶和华，用来赎自己的性命。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 10:32–33; 民数记 16:40; 出埃及记 38:25–31"> 要向以色列人收赎命的款项，供会幕使用，可以使以色列人在耶和华面前蒙眷顾，赎性命。”</span>
</div>
</div>

## 洗濯盆

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:7; 出埃及记 38:8; 列王纪上 7:23"> “你用铜造一个洗濯盆和盆座，放在会幕和祭坛之间，盆里盛着水，</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 52:11; 出埃及记 40:31–32; 诗篇 26:6"> 供亚伦父子们洗手洗脚，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 10:1–3; 希伯来书 12:28–29; 历代志上 13:10"> 他们进会幕或到坛前给耶和华献火祭之前，一定要用水洗濯才可以供职，免得死亡。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 28:43; 出埃及记 27:21"> 他们要洗手洗脚，免得死亡，这是亚伦及其子孙世代当守的永久律例。”</span>
<span className="v" id="v22" data-v="22"> 耶和华对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 27:19; 雅歌 4:14; 以西结书 27:22"> “要用上等的香料，就是没药汁六公斤、香肉桂和菖蒲各三公斤、</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 45:8; 出埃及记 29:40; 民数记 3:47"> 肉桂皮六公斤，都按圣所的秤为准，再加上橄榄油四升，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:29; 历代志上 9:30; 出埃及记 40:9"> 按着调制香料的方法制作圣膏油。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 7:1; 约翰一书 2:20; 以赛亚书 61:1"> 要用这些膏油来抹会幕、约柜、</span>
<span className="v" id="v27" data-v="27"> 桌子和桌上所有的器具、灯台和灯台上的器具、香坛、</span>
<span className="v" id="v28" data-v="28"> 燔祭坛和坛上所有的器具、洗濯盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 23:19; 出埃及记 29:37; 利未记 6:18"> 你要使这一切圣洁，成为至圣之物。凡碰到它们的都会圣洁。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 8:12; 出埃及记 28:3; 利未记 8:30"> “你也要用这油来膏亚伦父子们，使他们分别出来，做圣洁的祭司事奉我。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 37:29; 利未记 21:10; 诗篇 89:20"> 你要把我的话告诉以色列百姓，‘我要世世代代以这油为圣膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 30:25; 出埃及记 30:37–38; 利未记 21:10"> 不要把这膏油用在普通人身上，也不可仿制，因为这是圣膏油，你们也要视之为圣物。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 30:38; 创世记 17:14; 出埃及记 12:15"> 任何人若仿制或用这油抹祭司以外的人，要将他从民中铲除。’”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 37:29; 出埃及记 25:6; 出埃及记 30:23"> 耶和华对摩西说：“要取各种芬芳的香料，就是苏合香、香螺、白松香和纯乳香，分量相同，</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 2:13; 出埃及记 30:25; 约翰福音 12:3"> 用调制香料的方法调制，加上盐，做成纯净圣洁的香。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:22; 出埃及记 30:6; 出埃及记 16:34"> 你们要把一些香捣成极细的粉末，放在会幕内的约柜前面，就是我与你会面的地方，你们要视这香为至圣之物。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 2:3; 出埃及记 29:37; 出埃及记 30:32–33"> 你们不可用同样的配方为自己做香，要视它为耶和华的圣物。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:33"> 任何人若仿制这香，自己拿来私用<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“私用”希伯来文是“闻这香味”。">a</a></sup>，必从民中被铲除。”</span>
</div>
</div>

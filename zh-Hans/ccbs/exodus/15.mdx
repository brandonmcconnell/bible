## 摩西颂赞耶和华

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="启示录 15:3; 出埃及记 15:21; 诗篇 106:12"> 那时，摩西和以色列人便歌颂耶和华，说：<br /><span className="pl pl-1">“我要歌颂耶和华，</span><br /><span className="pl pl-1">因祂大获全胜，</span><br /><span className="pl pl-1">祂把战马和骑兵都抛进海中。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 12:2; 诗篇 118:14; 诗篇 18:46"> <span className="pl pl-1">耶和华是我的力量，我的诗歌，</span><br /><span className="pl pl-1">也成了我的拯救；</span><br /><span className="pl pl-1">祂是我的上帝，我要赞美祂；</span><br /><span className="pl pl-1">祂是我父亲的上帝，我要尊崇祂。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 24:8; 出埃及记 14:14; 启示录 19:11–21"> <span className="pl pl-1">耶和华是战士，</span><br /><span className="pl pl-1">祂名叫耶和华。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 14:13–28; 出埃及记 14:6–7"> <span className="pl pl-1">祂把法老的战车军兵都抛进海中，</span><br /><span className="pl pl-1">法老的强将都葬身于红海，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 9:11; 出埃及记 15:10; 出埃及记 14:28"> <span className="pl pl-1">大水淹没他们，</span><br /><span className="pl pl-1">他们如同石块沉入深海。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 118:15–16; 以赛亚书 51:9; 启示录 2:27"> <span className="pl pl-1">耶和华啊，你的右手用大能彰显威荣；</span><br /><span className="pl pl-1">耶和华啊，你的右手击碎仇敌。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 5:24; 以赛亚书 47:14; 玛拉基书 4:1"> <span className="pl pl-1">你大显威严，击倒那些起来对抗你的人；</span><br /><span className="pl pl-1">你大发雷霆，他们便像枯草遇火，</span><br /><span className="pl pl-1">一烧而尽。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 4:9; 诗篇 78:13; 出埃及记 14:21–22"> <span className="pl pl-1">你的鼻孔一呼气，海水便堆聚起来，</span><br /><span className="pl pl-1">洪涛便堆起水墙，海底深处也都凝固。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="士师记 5:30; 出埃及记 14:5; 以赛亚书 53:12"> <span className="pl pl-1">敌人说，‘追啊，追上他们，</span><br /><span className="pl pl-1">瓜分他们的财物，尽情掳掠他们，</span><br /><span className="pl pl-1">拔出刀来把他们斩尽杀绝。’</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 14:21; 申命记 11:4; 出埃及记 15:5"> <span className="pl pl-1">你叫风一吹，海水就淹没他们，</span><br /><span className="pl pl-1">他们好像铅块一样沉没在怒海中。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 8:23; 诗篇 89:5–8; 撒母耳记上 2:2"> <span className="pl pl-1">耶和华啊，万神之中，谁能像你？</span><br /><span className="pl pl-1">谁能像你——威严神圣，</span><br /><span className="pl pl-1">可颂可畏，广行神迹？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 15:6"> <span className="pl pl-1">你伸出右手，大地便吞灭他们。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 77:20; 彼得前书 1:5; 诗篇 77:14–15"> <span className="pl pl-1">你以不变的爱引领你所救赎的子民，</span><br /><span className="pl pl-1">以大能带他们进入你的圣所。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="申命记 2:25; 约书亚记 2:9–10; 诗篇 48:6"> <span className="pl pl-1">各邦听见这些事就发抖，</span><br /><span className="pl pl-1">非利士人痛苦不堪，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 5:1; 约书亚记 2:11; 约书亚记 2:9"> <span className="pl pl-1">以东的族长惶恐不安，</span><br /><span className="pl pl-1">摩押的英雄瑟瑟发抖，</span><br /><span className="pl pl-1">迦南的居民胆战心惊。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="申命记 2:25; 诗篇 74:2; 约书亚记 2:9"> <span className="pl pl-1">惊骇恐惧笼罩着他们。</span><br /><span className="pl pl-1">耶和华啊，</span><br /><span className="pl pl-1">你臂膀的大能吓得他们僵立如石，</span><br /><span className="pl pl-1">直到你的子民都安然走过，</span><br /><span className="pl pl-1">直到你买赎的子民都安然走过。</span><br /></span>

</div>

</div>
<div className="bp">

## 苦水

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 16:7; 撒母耳记上 15:7; 创世记 25:18"> 摩西带领以色列人离开红海，来到书珥旷野，走了三天仍然找不到水喝。</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 1:20; 民数记 33:8"> 到了玛拉，那里的水却是苦的，不能喝。因此那地方叫玛拉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛拉”意思是“苦”。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 16:2; 出埃及记 14:11; 民数记 20:2–5"> 百姓就埋怨摩西说：“我们喝什么呢？”</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 8:2; 诗篇 66:10; 士师记 3:1"> 摩西向耶和华呼求，耶和华就指示他一棵树，他把树扔在水中，水就变甘甜了。耶和华又在玛拉给百姓定下律例和法令，并在那里试验他们，</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 103:3; 申命记 7:15; 出埃及记 23:25"> 说：“你们若留心听你们上帝耶和华的话，做我视为正的事，听从我的命令，遵守我的一切律例，我就不把降在埃及的疾病加在你们身上，因为我是医治你们的耶和华。”</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 22:2; 启示录 7:17; 民数记 33:9"> 到了以琳，那里有十二股水泉和七十棵棕树，他们就在水边安营。</span>
</div>

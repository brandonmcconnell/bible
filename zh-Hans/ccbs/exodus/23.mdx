## 公义与怜悯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 101:5; 箴言 19:5; 申命记 19:16–21"> “不可散布谣言，也不可与恶人联手作伪证。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; 路加福音 23:23–24"> 不可随众行恶。在法庭作证时不可附和多数人，颠倒是非。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:17; 利未记 19:15; 诗篇 82:2–3"> 在诉讼的事上不可偏袒穷人。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 22:1–4; 帖撒罗尼迦前书 5:15; 马太福音 5:44"> “倘若看见仇人的牛或驴走迷了路，总要牵回去交给他。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:4"> 倘若遇见仇人的驴被驮的重物压倒，不可径自走开，总要帮助仇人抬开重物。</span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 3:5; 耶利米书 5:28; 利未记 19:15"> “不可在诉讼案中冤枉穷人。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:25; 出埃及记 34:7; 出埃及记 23:1"> 不可诬告别人，不可杀害正直无辜的人，因为我必惩罚作恶之人。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 16:19; 箴言 17:23; 以赛亚书 5:23"> 不可收受贿赂，因为贿赂蒙蔽人的眼目，使人颠倒是非。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 27:19; 出埃及记 22:21; 申命记 24:14–18"> 不可欺凌在你们中间寄居的人，因为你们也曾经在埃及寄居，知道寄居他乡的滋味。</span>
</div>
</div>

## 安息年和安息日

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 25:3–4"> “六年之内你要耕种收割，</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 26:34–35; 利未记 25:2–7; 利未记 25:11–12"> 第七年要让土地休息，不耕不种，你们当中的穷人可以吃田中长出来的，剩下的可以留给动物吃。你也要这样处理葡萄园和橄榄园。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:14; 出埃及记 34:21; 出埃及记 35:3"> 六天之内，你要工作，但第七天要休息。这样，牛、驴可以歇息，你家里的奴仆和寄居的也可以休息。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:7; 撒迦利亚书 13:2; 提摩太前书 4:16"> 你们要谨慎遵从我对你们说的话。不可提其他神明的名字，不可从你口中听到它们的名字。</span>
</div>
</div>

## 三大节期

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 16:16; 出埃及记 34:22–24; 利未记 23:34"> “你每年要向我守三个节期。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:7; 出埃及记 34:20; 民数记 28:16–25"> 要守除酵节，照我的吩咐在每年亚笔月所定的日期连续吃七天的无酵饼，因为你是在这个月离开了埃及。谁也不可空手朝见我。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:22; 出埃及记 22:29; 利未记 23:9–21"> 要在耕种后收取初熟之物的时候守收获节。要在年终从田间收取劳动成果时守收藏节。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:16; 出埃及记 34:23; 出埃及记 23:14"> 所有的男子都要在这三个节期朝见主耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:25; 利未记 2:11; 申命记 16:4"> “不可把祭牲的血和有酵的饼一起献给我，也不可把节期祭牲的脂肪留到早晨。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:26; 申命记 14:21; 申命记 26:10"> 要把田中最好的初熟之物送到你们的上帝耶和华的殿中。不可用母山羊的奶煮它的小羊羔。</span>
</div>
</div>

## 应许赐迦南

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 33:14; 诗篇 91:11; 出埃及记 32:34"> “看啊，我要差遣天使走在你前面，在路上保护你，带领你到达我所预备的地方。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 78:56; 诗篇 78:40; 希伯来书 12:25"> 他是奉我的名来的，你们要谨遵他的话，不可悖逆，不然他必不赦免你们的过犯。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 12:3; 申命记 30:7; 撒迦利亚书 2:8"> “你若认真听从他的吩咐，遵行我的话，我就与你的仇敌为敌，与你的对头作对。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:20; 以赛亚书 5:13; 创世记 15:19–21"> 我的天使要走在你前面，带领你去亚摩利人、赫人、比利洗人、迦南人、希未人和耶布斯人所住的地方，我会把他们全部消灭。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:5; 申命记 12:30–31; 民数记 33:52"> 不可叩拜他们的神明，不可供奉它们，也不可效法他们的行为，要彻底拆毁神像，打碎他们的神柱。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:15; 出埃及记 15:26; 约书亚记 22:5"> 你们要事奉你们的上帝耶和华，我必赐给你食物和水，使疾病远离你们，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 7:14; 约伯记 5:26; 申命记 28:4"> 在你境内必没有人流产或不育，我会使你享尽天年。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 2:25; 创世记 35:5; 申命记 11:25"> 你所到之处，我必使那里的人惶恐不安，使你一切的仇敌都在你面前转身逃跑。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 7:20; 约书亚记 24:11–12"> 我要派黄蜂做你的先锋，赶走那些希未人、迦南人和赫人。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 7:22; 约书亚记 17:12–13; 士师记 3:1–4"> 我不会在一年之内把这些人全部赶走，免得土地荒凉，野兽泛滥。</span>
<span className="v" id="v30" data-v="30"> 我会逐渐地赶走他们，直到你们人丁兴旺，可以占据那片土地。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 15:18; 申命记 11:24; 约书亚记 21:44"> 我给你定下国界，从红海到非利士海岸，从旷野到幼发拉底河。我要把其中所有的居民都交在你手中，你要把他们全部赶出去。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 7:2; 出埃及记 34:12; 出埃及记 34:15"> 不可跟这些民族及其神明立约，</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 106:36; 申命记 7:16; 出埃及记 34:12"> 也不可让这些民族住在你的土地上，免得他们使你得罪我，你若供奉他们的神明，必因此而陷入网罗。”</span>
</div>
</div>

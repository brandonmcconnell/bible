## 叶特罗看望摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:16; 诗篇 77:14–15; 出埃及记 3:1"> 摩西的岳父米甸的祭司叶特罗，听说上帝为摩西和祂的子民以色列人所做的一切事及如何带他们出埃及后，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:21; 出埃及记 4:25–26"> 就带着女儿西坡拉和两个外孙去见摩西。西坡拉是摩西的妻子，摩西曾让她回娘家暂时居住。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 2:22; 使徒行传 7:29; 诗篇 39:12"> 摩西的两个儿子一个叫革舜，因为摩西说：“我成了在异乡寄居的人”；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 13:6; 提摩太后书 4:17; 哥林多后书 1:8–10"> 一个叫以利以谢，因为摩西说：“我父亲的上帝帮助我，从法老的刀下拯救了我。”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:1; 出埃及记 3:12; 出埃及记 24:16–17"> 摩西的岳父叶特罗带着摩西的妻子和两个儿子来到上帝的山见摩西，就是摩西在旷野安营的地方。</span>
<span className="v" id="v6" data-v="6"> 叶特罗事先差人把他带着摩西的妻子和两个儿子要来的消息通知摩西。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 29:13; 创世记 14:17; 撒母耳记下 11:7"> 摩西出去迎接岳父，向他下拜，与他亲吻，彼此问安，然后大家都进了帐篷。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:4–12; 尼希米记 9:9–15; 诗篇 107:2"> 摩西把耶和华为拯救以色列人而向法老和埃及人所行的事，以及怎样救百姓脱离路上遇见的种种困难，都告诉了叶特罗。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 12:26; 罗马书 12:15; 以赛亚书 66:10"> 叶特罗为耶和华恩待以色列人、把他们救出埃及而高兴，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 14:20; 撒母耳记下 18:28; 路加福音 1:68"> 便说：“耶和华当受称颂，因为祂从埃及人和法老手中拯救了你们，把这百姓从埃及人手中拯救了出来。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 95:3; 出埃及记 15:11; 历代志下 2:5"> 我现在知道，耶和华比一切神明都伟大，因为祂惩治了虐待这些百姓的狂妄之徒。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:54; 申命记 12:7; 出埃及记 24:11"> 摩西的岳父叶特罗说完，便向上帝献燔祭及其他祭物。亚伦和以色列的长老都来与他一起在上帝面前吃饭。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 16:5; 约伯记 29:7; 士师记 5:10"> 第二天，摩西坐着审理百姓的纠纷，百姓从早到晚都站在摩西周围。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父叶特罗看见摩西对百姓所行的一切，就对摩西说：“你为什么这样处理百姓的事？为什么你独自坐着，众百姓从早到晚都站在你周围？”</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 15:34; 民数记 27:5; 民数记 9:8"> 摩西对岳父说：“因为他们来我这里求问上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:14; 哥林多前书 6:1; 撒母耳记下 15:3"> 他们有纠纷就来我这里，我为双方定夺是非，教他们认识上帝的律例和法度。”</span>
<span className="v" id="v17" data-v="17"> 摩西的岳父叶特罗劝摩西说：“这不是好方法，</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 11:14–17; 使徒行传 6:1–4; 哥林多后书 12:15"> 你和这些百姓都会疲惫不堪，你一个人无法担当如此繁重的工作。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 27:5; 申命记 5:5; 出埃及记 20:19"> 你要听我的劝告，愿上帝与你同在。你要做百姓的代表，把案件奏明上帝，</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 5:1; 诗篇 143:8; 申命记 1:18"> 又要教导他们律例和法度，指示他们当行的道、当做的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 6:3; 申命记 1:13–17; 历代志下 19:5–10"> 此外，你要在民中挑选一些敬畏上帝、有才干、诚实、正直、憎恶不义之财的人，派他们做千夫长、百夫长、五十夫长和十夫长，管理百姓。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 11:17; 民数记 27:2; 民数记 15:33"> 让他们随时为百姓判案，处理小纠纷，遇到大事才由你审理。有他们分担你的责任，你会更轻省。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 8:6–7; 出埃及记 18:18; 撒母耳记上 8:22"> 如果你这样做，并且上帝也这样吩咐你，你就能承受得住，百姓也可以平安地回家。”</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 10:2; 出埃及记 18:19; 出埃及记 18:2–5"> 于是，摩西接纳了岳父的建议，依言而行，</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:15; 出埃及记 18:21; 使徒行传 6:5"> 从百姓中挑选有才干的人，委派他们做百姓的领袖，担任千夫长、百夫长、五十夫长和十夫长。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 18:22; 出埃及记 18:14–15; 申命记 17:8"> 他们负责随时审理百姓的事，遇到难断的案件就呈到摩西那里，自己则审理普通的事。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 10:29–30; 士师记 19:9; 创世记 31:55"> 之后，摩西为岳父送行，叶特罗就返回了家乡。</span>

## 祭坛、院子和奉献的物品

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 27:1–8; 以西结书 43:13–17; 出埃及记 40:6"> 比撒列用皂荚木造了方形的燔祭坛，长宽各两米二，高一米三，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2; 约伯记 6:12"> 在坛的四角造四个凸起的角，与坛连成一体，坛外面包上铜。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 27:3; 撒母耳记上 2:13"> 他用铜造祭坛用的一切器具，就是锅、铲、碗、肉叉、火鼎。</span>
<span className="v" id="v4" data-v="4"> 又造了一个铜网，铜网在祭坛围边的下方，向下伸展到祭坛的腰部，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:4"> 在铜网的四角铸四个铜环，以便穿横杠。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:3; 出埃及记 25:6"> 他用皂荚木做横杠，包上铜，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 哥林多前书 2:2; 哥林多前书 1:24"> 把横杠穿在坛两旁的铜环里，以便抬坛。坛是中空的，用木板制作。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 2:22; 路加福音 2:37; 出埃及记 40:7"> 他用在会幕门口服侍的妇女们的铜镜造铜盆和盆座。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 27:9–19; 诗篇 89:7; 列王纪上 6:36"> 他用帷幔围成院子，院子南面的帷幔用细麻织成，长四十五米。</span>
<span className="v" id="v10" data-v="10"> 帷幔有二十根柱子，二十个带凹槽的铜底座，柱子上的钩和箍都是银的。</span>
<span className="v" id="v11" data-v="11"> 北面的帷幔也是长四十五米，柱子、铜底座、钩和箍的样式都与南面的一样。</span>
<span className="v" id="v12" data-v="12"> 西面的帷幔宽二十二米半，有十根柱子和十个带凹槽的底座，钩和箍都是银的。</span>
<span className="v" id="v13" data-v="13"> 东面的帷幔也是宽二十二米半。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:14"> 入口两边的帷幔都是宽七米，各有三根柱子和三个带凹槽的底座。</span>
<span className="v" id="v16" data-v="16"> 院子四面的帷幔都用细麻织成。</span>
<span className="v" id="v17" data-v="17"> 柱子带凹槽的底座是铜的，柱子上面的钩和箍是银的，柱顶包银，院子所有的柱子都有银箍。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:14"> 院子入口的门帘用细麻和蓝色、紫色、朱红色毛线绣制，长九米、高两米二，与院子帷幔的高度一样。</span>
<span className="v" id="v19" data-v="19"> 门帘有四根柱子和四个带凹槽的铜底座，柱子上的钩和箍都是银的，柱顶包银。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:9; 出埃及记 27:19; 以弗所书 2:21–22"> 圣幕和院子四围所有的橛子都是铜的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 7:44; 民数记 9:15; 历代志下 24:6"> 以上是安放约柜的圣幕中所用的物品，是照摩西的吩咐，由亚伦祭司的儿子以他玛指挥利未人清点的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 35:30–3; 出埃及记 31:1–5; 诗篇 119:6"> 犹大支派户珥的孙子、乌利的儿子比撒列做好了耶和华吩咐摩西预备的一切物品。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 35:34; 出埃及记 31:6"> 他的助手是但支派亚希撒抹的儿子亚何利亚伯，是雕刻家和设计师，并善用细麻和蓝色、紫色、朱红色毛线刺绣。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 18:16; 民数记 3:47; 利未记 27:25"> 按圣所的秤计算，建造圣所共用了奉献的金子两万两。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:12"> 按圣所的秤计算，从登记的人口所收到的银子是六万八千四百两。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:46; 出埃及记 30:13; 出埃及记 12:37"> 这是所有登记的、年龄在二十岁以上的人所缴纳的银子，共有六十万三千五百五十人，每人交六克银子，以圣所的秤为准。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:19; 出埃及记 26:25; 出埃及记 26:21"> 铸造圣所带凹槽的底座和帷幔柱子带凹槽的底座共用了六万八千两银子，共铸造了一百个底座，每个底座用了六百八十两银子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 27:17"> 剩下的四百两银子用来制造柱子上的钩和箍以及包柱顶。</span>
<span className="v" id="v29" data-v="29"> 百姓奉献的铜共有两千四百公斤，</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:37; 出埃及记 27:17; 出埃及记 27:10"> 用来制造会幕入口带凹槽的底座、祭坛、坛上的铜网及一切器具、</span>
<span className="v" id="v31" data-v="31"> 院子周围和院子入口带凹槽的底座以及圣幕、院子周围所有的橛子。</span>
</div>
</div>

## 祭司圣衣的规定

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 18:7; 希伯来书 5:1–5; 民数记 17:2–9"> “你要从以色列民中把你的哥哥亚伦和他四个儿子拿答、亚比户、以利亚撒和以他玛带到你身边，立他们为祭司事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 8:30; 出埃及记 31:10; 启示录 19:8"> 你要为你哥哥亚伦做圣衣，显明他职位的荣耀和尊贵。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:17; 哥林多前书 12:7–11; 以赛亚书 11:2"> 你要吩咐所有我赋予智慧的巧手裁缝师为亚伦缝制衣服，使他分别出来，做圣洁的祭司事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 6:14; 启示录 9:17; 以赛亚书 59:17"> 他们要做的圣衣包括胸牌、以弗得、外袍、杂色的内袍、礼冠和腰带。要为你哥哥亚伦及其众子做这样的圣衣，好让他们做祭司事奉我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:3–4; 出埃及记 39:2–3"> 要用金线、细麻及蓝色、紫色、朱红色毛线制作圣衣。</span>
</div>
</div>

## 以弗得

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 39:2–7; 出埃及记 26:1"> “以弗得要用金线、细麻及蓝色、紫色、朱红色毛线精工制作。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 39:4"> 要在以弗得两边用两条肩带缝合起来。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:27–28; 利未记 8:7; 出埃及记 29:5"> 用金线、细麻及蓝色、紫色、朱红色毛线精工制作腰带，缝在以弗得上，连成一整件。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 28:13; 历代志下 2:7; 以赛亚书 49:16"> “你要拿两块红玛瑙，刻上以色列十二个儿子的名字，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 1:1–4; 创世记 43:33"> 按他们的长幼次序，每一块宝石刻上六个名字。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 2:19; 启示录 7:2; 耶利米书 22:24"> 要用工匠刻图章的方法将他们的名字刻在两块宝石上，把宝石镶在两个金框里。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:29; 约书亚记 4:7; 出埃及记 39:6–7"> 然后将镶着金框的宝石缝在以弗得的两条肩带上，作以色列人的纪念石。亚伦要把他们的名字带在肩上，在耶和华面前作纪念。</span>
<span className="v" id="v13" data-v="13"> 要做两个金框，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 39:15; 出埃及记 39:17–18; 列王纪上 7:17"> 并像搓绳子一样用纯金搓成两条金链，把链子连接在镶宝石的金框上。</span>
</div>
</div>

## 胸牌

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:30; 出埃及记 26:1; 出埃及记 28:4"> “要精工制作一个用来明白上帝旨意的胸牌，制作的方法和造以弗得一样，用金线、细麻及蓝色、紫色、朱红色毛线制作。</span>
<span className="v" id="v16" data-v="16"> 胸牌是方形的，长宽各二十二厘米，分成上下两层。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 28:13; 出埃及记 39:10–21; 箴言 8:11"> 上面要镶上四行宝石：第一行是红宝石、黄玉和翠玉；</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 27:16; 约伯记 28:6; 雅歌 5:14"> 第二行是绿宝石、蓝宝石和金刚石；</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:12; 出埃及记 39:12"> 第三行是紫玛瑙、白玛瑙和紫晶；</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:16; 启示录 4:3; 但以理书 10:6"> 第四行是水苍玉、红玛瑙和碧玉。这些宝石都要镶在金框上。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:12; 启示录 7:4–8; 列王纪上 18:31"> 要用刻图章的方法在每一颗宝石上刻一个以色列儿子的名字，十二颗宝石代表十二支派。</span>
<span className="v" id="v22" data-v="22"> “要用纯金拧成两条像绳子一样的链子，连在胸牌上，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:11–15"> 造两个金环安在胸牌两端，</span>
<span className="v" id="v24" data-v="24"> 把两条金链分别系在胸牌两端的金环上，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 39:15; 出埃及记 39:4; 出埃及记 28:14"> 再把金链的另两端接在两个金框上，安在以弗得前面的肩带上。</span>
<span className="v" id="v26" data-v="26"> 造两个金环，安在靠近以弗得内边的胸牌下两端。</span>
<span className="v" id="v27" data-v="27"> 再造两个金环，安在以弗得前面两条肩带下端，靠近精致的以弗得腰带上方的接缝处。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:38; 出埃及记 28:31; 出埃及记 39:30–31"> 再用一条蓝色的带子系住以弗得和胸牌上面的金环，使胸牌贴在精工织成的以弗得腰带上，不会从以弗得上松脱。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 28:12; 出埃及记 28:30; 耶利米书 30:21"> 亚伦进圣所时，要佩戴这块刻着以色列众子名字、用来做判断的胸牌，在耶和华面前常作纪念。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 7:65; 以斯拉记 2:63; 民数记 27:21"> 又要把乌陵和土明放在胸牌里面，亚伦到耶和华面前的时候，要佩带这胸牌，以便明白上帝的旨意，为以色列人做决定。</span>
</div>
</div>

## 外袍

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 8:7; 出埃及记 28:4; 出埃及记 39:22–26"> “也要缝制一件蓝色的以弗得的外袍，</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 4:16; 约翰福音 19:23–24; 出埃及记 39:28"> 袍上要留领口，领口周围要织领边，就像铠甲的领口，免得领口破裂。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 39:24–26; 撒迦利亚书 14:20; 列王纪上 7:18"> 外袍的底边要另外用蓝色、紫色、朱红色毛线做成石榴状的饰物，石榴间要挂金铃铛。</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; 约翰福音 15:4–8; 歌罗西书 1:10"> 一个石榴一个金铃铛，相间排列，围在外袍的底边。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:12; 利未记 16:2"> 亚伦事奉的时候，要穿上这外袍，以便他进圣所到耶和华面前和出圣所的时候，铃铛会发出响声，他就不至于死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 14:20; 利未记 8:9; 出埃及记 39:30"> “你也要用纯金造一块牌子，以刻印章的方法刻上‘耶和华的圣物’的字样，</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:6; 出埃及记 28:4; 撒迦利亚书 3:5"> 再拿一条蓝色带子，把它系在礼冠前面。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 2:24; 民数记 18:1; 利未记 10:17"> 亚伦要把这金牌戴在额上，表示他承担以色列人献圣物时的过犯，这圣物是以色列百姓特别献上的礼物。这金牌要常常留在亚伦的额上，好使百姓蒙耶和华悦纳。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 45:14"> “要用细麻布缝制祭司的内袍，用细麻布做礼冠，腰带上要有刺绣，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 39:41; 出埃及记 28:4; 出埃及记 28:2"> 也要为亚伦的儿子们缝制内袍、腰带、头巾，显明他们职位的荣耀和尊贵。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 29:7; 利未记 8:1–36; 出埃及记 40:15"> 给你哥哥亚伦及其众子穿上这些衣服后，你要用油膏立他们，使他们分别出来，做圣洁的祭司事奉我。</span>
</div>
</div>

## 裤子

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="以西结书 44:18; 利未记 6:10; 利未记 16:4"> “要用细麻布为他们做裤子，以遮盖下体，裤子要从腰部到大腿。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及记 27:21; 出埃及记 20:26; 利未记 5:17"> 亚伦父子们进会幕或走近祭坛到圣所事奉的时候，都要穿上裤子，免得担负罪责而死亡。这是亚伦及其子孙永远当守的律例。</span>
</div>
</div>

</div>

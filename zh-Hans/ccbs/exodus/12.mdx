## 逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华在埃及对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 13:4; 申命记 16:1; 出埃及记 34:18"> “你们要以这个月为一月，为一年之首。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 1:2; 哥林多前书 5:7; 约翰福音 1:29"> 你要向以色列全体会众宣布，本月的第十日，每家都要预备一只羊羔，一家一只。</span>
<span className="v" id="v4" data-v="4"> 倘若家人太少，吃不了一只，可以跟最近的邻居共享一只，你们要按人数和各人的食量预备羊羔。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:18–19; 希伯来书 9:13–14; 玛拉基书 1:14"> 羊羔必须是毫无残疾、一岁的公绵羊或公山羊。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 23:5; 历代志下 30:15–18; 民数记 28:16"> 以色列全体会众要把羊留到本月十四日，在黄昏时分宰杀，</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:28; 出埃及记 12:22–23; 希伯来书 9:22"> 然后取点血涂在房子的门框和门楣上，他们要在房子里吃羊肉。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 34:25; 申命记 16:7; 出埃及记 13:3"> 当晚，你们要用火把羊肉烤熟，与无酵饼和苦菜一起吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 12:8; 申命记 16:7; 耶利米哀歌 1:13"> 不可吃生羊肉，也不可煮着吃，要把整只羊，连头带腿和内脏一并烤着吃。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 23:18; 出埃及记 34:25; 出埃及记 29:34"> 不可把肉留到早晨，留到早晨的肉要烧掉。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:27; 以弗所书 6:15; 哥林多前书 5:7"> 你们吃的时候，要束腰、穿鞋、手中拿杖，要赶快吃，这是耶和华的逾越节。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 33:4; 出埃及记 12:23; 诗篇 82:6"> “因为那一夜我要巡遍埃及，把境内所有长子和头生的牲畜全都杀掉，也要严惩埃及所有的神明。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:28; 出埃及记 12:23; 约翰一书 1:7"> 涂在你们房屋上的血是一个记号，我见到这血就会越过你们。我击打埃及的时候，那灾祸不会落到你们身上。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 23:21; 出埃及记 12:24; 出埃及记 13:9–10"> 你们要记住这一天，守为耶和华的节期，作为世代不变的律例。</span>
</div>
</div>

## 除酵节

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 17:14; 申命记 16:3; 出埃及记 23:15"> “七天之内你们都要吃无酵饼。第一天，要清除家中所有的酵。任何人若在这七天当中吃有酵的食物，要将他从以色列人中铲除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 23:7–8; 民数记 28:18; 出埃及记 16:23"> 在节期的第一天和第七天，你们都要举行圣会。这两天所有人都不得工作，除了预备各人要吃的以外，不可做任何工。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 7:5; 出埃及记 13:3; 出埃及记 12:41"> 你们要守这除酵节，因为我在这天把你们的大军从埃及领了出来。你们要守这节期，作为世代不变的律例。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 23:5–8; 出埃及记 12:15; 出埃及记 12:1–2"> 从一月十四日傍晚开始，直到二十一日傍晚，你们都要吃无酵饼。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:15; 出埃及记 23:15; 申命记 16:3"> 在这七天内，你们屋里不能有酵。任何人若吃了有酵的东西，不论他是寄居者还是本地人，都要将他从以色列会众中铲除。</span>
<span className="v" id="v20" data-v="20"> 无论你们住在哪里都要吃无酵饼，不能吃任何有酵的食物。”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:3; 路加福音 22:7–13; 历代志下 35:5–6"> 于是，摩西召集以色列的众长老，对他们说：“你们家家户户都要挑选羔羊，把这逾越节的羔羊宰了。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:28; 民数记 19:18; 诗篇 51:7"> 拿一把牛膝草蘸盆里的血，把血涂在门楣和两边的门框上。天亮前，你们不可踏出门外。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 7:3; 启示录 9:4; 希伯来书 11:28"> 因为耶和华要巡行各地，击杀埃及人，祂看见你们的门框和门楣上有血，就必越过你们的家门，不让灭命者进你们家杀人。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 12:14; 创世记 17:8–10"> 这是你们及后代永远当守的律例。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:17; 出埃及记 3:8; 申命记 12:8–9"> 你们进入耶和华应许给你们的地方以后，要守这逾越节。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:14–15; 申命记 32:7; 诗篇 145:4"> 当你们的儿女问你们守这节期的意义时，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:31; 出埃及记 12:11; 哥林多前书 5:7"> 你们就说，‘这是献给耶和华逾越节的祭，因为我们从前在埃及时，祂击杀埃及人，却越过以色列人所住的房子，救了我们各家。’”百姓听了摩西这番话，都俯伏敬拜。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 11:28"> 耶和华怎么吩咐摩西和亚伦，以色列人就照样遵行。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 78:51; 出埃及记 4:23; 诗篇 105:36"> 到了半夜，耶和华把所有埃及人的长子都杀了，包括坐王位的法老的长子、牢中囚犯的长子和一切头生的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 11:6; 阿摩司书 5:17; 箴言 21:13"> 当晚，法老及其臣仆和所有埃及人都惊醒了，到处都是哭号声，因为没有一家不死人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 6:1; 出埃及记 10:9; 出埃及记 3:19–20"> 法老连夜召见摩西和亚伦，对他们说：“你们和以色列人起来走吧，离开我的人民。就照你们的要求，去事奉耶和华吧！</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:26; 创世记 27:34; 创世记 27:38"> 照你们的要求，把所有的牛羊都带走吧！也要为我祝福。”</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 105:38; 出埃及记 11:1; 创世记 20:3"> 埃及人催促以色列人赶快离开埃及，因为他们说：“我们都要死了。”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:3"> 于是，以色列百姓就把没有酵的面团放在揉面盆里，用衣服包起来扛在肩上，</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 3:21–22; 出埃及记 11:2–3; 创世记 15:14"> 又遵照摩西的吩咐向埃及人索取金器、银器和衣服。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 15:14; 使徒行传 7:10; 出埃及记 3:21–22"> 耶和华使埃及人恩待以色列人，他们要什么，埃及人就给什么。这样，以色列人夺取了埃及人的财富。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 33:3"> 以色列百姓从埃及的兰塞启行，前往疏割，妇女孩童不算在内，单是步行的男子就有六十万，</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 11:4; 撒迦利亚书 8:23"> 同行的还有许多外族人和大群的牛羊。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 11:1; 出埃及记 6:1; 出埃及记 12:31–33"> 他们用从埃及带出来的面团烤成无酵饼，面团没有酵，因为他们被催促离开埃及，没有时间准备食物。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 15:13; 使徒行传 7:6; 使徒行传 13:17"> 以色列人在埃及共住了四百三十年，</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷书 2:3; 约翰福音 7:8; 使徒行传 1:7"> 正好满了四百三十年的那一天，耶和华带领全军离开了埃及。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 16:1–6; 出埃及记 12:14; 出埃及记 13:10"> 那天晚上是耶和华把祂的子民带出埃及之夜，因此以后世世代代的以色列人都要在那日守夜，以尊崇耶和华。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及记 12:48; 民数记 9:14; 出埃及记 12:11"> 耶和华对摩西和亚伦说：“以下是逾越节的条例。 “所有外族人都不可吃逾越节的羊羔，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 17:12–13; 创世记 17:23"> 但那些买来的奴隶若接受了割礼，就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 22:10; 以弗所书 2:12"> 寄居的外族人和雇工不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 9:12; 约翰福音 19:36; 约翰福音 19:33"> 你们吃的时候，应当在房子里吃，不得把肉带到外面去，也不可折断羊羔的一根骨头。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 12:6; 民数记 9:13; 出埃及记 12:3"> 以色列全体会众都要守这节期。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 9:14; 歌罗西书 3:11; 加拉太书 3:28"> 跟你们住在一起的外族人如果想为耶和华守逾越节，他全家的男子都必须接受割礼，这样才可以像以色列人一样守逾越节，但没有接受割礼的人绝不可吃逾越节的羊羔。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 15:15–16; 民数记 15:29; 利未记 24:22"> 本地人和在你们中间寄居的外族人都要遵守这规矩。”</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 7:24–25; 出埃及记 6:26; 出埃及记 7:4"> 耶和华怎样吩咐摩西和亚伦，以色列百姓都遵命而行。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及记 12:41; 出埃及记 6:26"> 就在那一天，耶和华带领以色列大军离开了埃及。</span>

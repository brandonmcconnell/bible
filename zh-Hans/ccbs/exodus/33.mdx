<span className="v" id="v1" data-v="1" data-xref="创世记 12:7; 出埃及记 32:13; 出埃及记 32:7"> 耶和华对摩西说：“现在你和你从埃及领出来的百姓要离开这里，去我向亚伯拉罕、以撒和雅各起誓要赐给他们后代的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 32:34; 约书亚记 24:11; 出埃及记 23:27–31"> 我必差遣天使走在你们前面，赶出当地的迦南人、亚摩利人、赫人、比利洗人、希未人和耶布斯人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:9–10; 出埃及记 3:8; 使徒行传 7:51"> 你们要去那奶蜜之乡。但我不会跟你们一起去，免得我在途中就把你们灭绝了，因为你们是顽固不化的百姓。”</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 14:39; 民数记 14:1; 以西结书 26:16"> 百姓听见这坏消息，都非常哀伤，不再佩戴饰物了。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:21; 民数记 16:45–46; 出埃及记 33:3–4"> 耶和华对摩西说：“你去向以色列百姓宣布，‘你们这些顽固不化的人，我就是跟你们在一起待一刻，都恐怕会灭绝你们。现在你们要摘下自己身上的饰物，我再决定怎样处置你们。’”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 33:4; 出埃及记 32:3; 耶利米书 2:19"> 因此，以色列百姓从何烈山开始就不再佩戴饰物了。</span>

## 耶和华的会幕

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 55:6–7; 出埃及记 29:42–43; 箴言 15:29"> 摩西通常把帐幕支搭在营外离百姓较远的地方，摩西称帐幕为会幕。凡求问耶和华的，都会去那里。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:27"> 当摩西离营去会幕的时候，百姓就都一同起来，各人站在自己的帐篷门口目送摩西走进会幕。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 99:7; 出埃及记 31:18; 出埃及记 13:21–22"> 摩西进入会幕后，便有云柱降下来，停在会幕门口，耶和华就跟摩西说话。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:22; 列王纪上 8:14; 出埃及记 4:31"> 百姓一看见云柱停在会幕门口，就都站在自己的帐篷门口敬拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 12:8; 申命记 34:10; 出埃及记 24:13"> 耶和华跟摩西面对面说话，好像两个朋友谈话一样。然后，摩西返回营中，但他的年轻助手、嫩的儿子约书亚仍然留在会幕。</span>
</div>
</div>

## 耶和华的荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 33:17; 耶利米书 1:5; 约翰福音 10:14–15"> 摩西对耶和华说：“你吩咐我带领这些百姓，却没有告诉我你将要派谁与我同去，只说，‘我凭名字认识你，你在我面前蒙了恩。’</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:33; 诗篇 25:4; 诗篇 27:11"> 我若已经在你面前蒙恩，就求你把你的道路指示我，好让我认识你，继续在你面前蒙恩。求你顾念这民族是你的子民。”</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 21:44; 马太福音 11:28; 约书亚记 1:5"> 耶和华回答他说：“我必亲自与你同去，使你平安稳妥。”</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:9; 诗篇 4:6; 出埃及记 33:3"> 摩西说：“你若不与我们同去，就不要带我们离开这里。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:7; 民数记 14:14; 列王纪上 8:53"> 你若不与我们同去，谁会知道我和你的子民在你面前蒙了恩呢？岂不是因为你的同在，才使我们不同于地上其他民族吗？”</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 65:24; 约翰一书 5:14–15; 出埃及记 33:12"> 耶和华回答说：“我答应你的请求，因为你在我面前蒙了恩，我凭名字认识你。”</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 21:23; 出埃及记 33:20; 提多书 2:13"> 摩西说：“求你向我彰显你的荣耀。”</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:15–18; 以弗所书 1:6–8; 耶利米书 31:14"> 耶和华说：“我必叫你看见我一切的美善，我要在你面前宣告我的名耶和华，我要恩待谁就恩待谁，我要怜悯谁就怜悯谁。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 32:30; 约翰福音 1:18; 提摩太前书 6:16"> 但你不能看我的脸，因为凡看见的人，都不能存活。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 5:31; 撒迦利亚书 3:7; 约书亚记 20:4"> 你要站在我旁边的磐石上，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 91:1; 以赛亚书 2:21; 诗篇 91:4"> 我的荣耀经过你面前的时候，我会先把你安置在石缝里，用我的手遮掩你，直到我从你面前走过。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 33:20; 约翰福音 1:18; 提摩太前书 6:16"> 然后我会收回我的手，你就可以看见我的背，但看不到我的脸。”</span>
</div>
</div>

## 摩西和亚伦见法老

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 10:9; 使徒行传 4:29; 马太福音 10:28"> 之后，摩西和亚伦去见法老，对他说：“以色列的上帝耶和华说，‘放我的子民走，让他们到旷野去为我守节期。’”</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 3:19; 约伯记 21:15; 列王纪下 18:35"> 法老说：“耶和华是谁？我凭什么要听从祂，放走以色列人？我不认识祂，也不会让以色列人离开！”</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 3:18; 撒迦利亚书 14:16–19; 以西结书 6:11"> 摩西和亚伦说：“希伯来人的上帝向我们显现了。求你容我们走三天的路程，到旷野去向我们的上帝耶和华献祭，免得祂用瘟疫或刀剑来攻击我们。”</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 1:11; 使徒行传 24:5; 阿摩司书 7:10"> 埃及王说：“摩西、亚伦，你们为什么让百姓停工！快回去服劳役！”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 1:7–11; 箴言 14:28"> 法老又说：“这地方的以色列人如此多，你竟叫他们停工！”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 5:10; 出埃及记 5:19; 申命记 16:18"> 当天，法老就对埃及监工和以色列人的工头下令：</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:19; 创世记 24:25"> “不许再供应草给他们制砖，叫他们自己去捡，</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:41"> 但上交的砖的数量要和往常一样，一块也不可少。因为他们懒惰，所以才嚷着要去给他们的上帝献祭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:20; 耶利米书 43:2; 约伯记 16:3"> 你们要加重他们的工作，他们就无暇再听那些蛊惑人心的话了！”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 1:11; 出埃及记 3:7; 箴言 29:12"> 于是，那些监工和工头就出来向百姓宣布：“法老下令不再供应草给你们制砖。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 5:13–14"> 你们要自己设法去找，但上交的砖一块也不能少。”</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 15:7; 以赛亚书 5:24; 以赛亚书 47:14"> 百姓只好在埃及各地收集禾秸当草用。</span>
<span className="v" id="v13" data-v="13"> 监工催逼他们说：“你们要完成每天规定的数目，像从前有草时一样。”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 10:24"> 法老的监工又鞭打他们委派的以色列工头，说：“你们这两天为什么没有像从前一样完成规定的砖数？”</span>
<span className="v" id="v15" data-v="15"> 以色列人的工头来见法老，向他哀求说：“你为什么要这样对待仆人们？</span>
<span className="v" id="v16" data-v="16"> 监工不给仆人们草，却命令我们制作砖，还打我们，其实是你百姓的错。”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 26:8; 约翰福音 6:27; 出埃及记 5:8"> 法老说：“你们是懒汉，懒汉！所以才嚷着要去给耶和华献祭。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 18:18; 但以理书 2:9–13"> 回去继续做工！我不再供应草给你们，但砖要如数交齐。”</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 5:8; 传道书 4:1; 申命记 32:36"> 以色列人的工头听见每天做的砖数不可减少，就知道情况不妙。</span>
<span className="v" id="v20" data-v="20"> 他们从法老那里出来的时候，遇见摩西和亚伦站在外面等候，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:30; 撒母耳记上 13:4; 历代志上 19:6"> 便埋怨二人说：“愿耶和华鉴察、惩罚你们！你们使我们在法老和他的臣仆面前有了臭名，无异于把刀递到他们手中来杀我们。”</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 20:7; 列王纪上 19:10; 民数记 11:14–15"> 摩西回到耶和华那里说：“主啊！你为什么这样苦待你的子民呢？为什么要派我去呢？</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 11:21; 希伯来书 10:36–37; 以赛亚书 28:16"> 自从我去法老那里奉你的名说话后，他更加虐待你的子民，你却根本没有拯救他们。”</span>

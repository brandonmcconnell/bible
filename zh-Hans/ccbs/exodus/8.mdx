## 蛙灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 3:18; 出埃及记 3:12; 出埃及记 5:1"> 耶和华对摩西说：“你去告诉法老，‘耶和华说，放我的子民离开，他们好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 78:45; 出埃及记 9:2; 出埃及记 7:14"> 如果你不肯让他们去，我就使青蛙来毁坏你的全境。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 105:30; 出埃及记 12:34"> 尼罗河将充满青蛙，它们要跳到你的宫里、卧室和床铺上，跳到你的臣仆和百姓家里，跳到你的炉灶和揉面盆里。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 19:11; 但以理书 4:37; 使徒行传 12:22–23"> 青蛙还会跳到你和你的百姓及众臣仆身上。’”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 7:19"> 耶和华对摩西说：“你叫亚伦向埃及各地的江河、溪流和池塘伸杖，使青蛙遍布埃及。”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 105:30; 诗篇 78:45; 启示录 16:13"> 亚伦就向水伸杖，青蛙就遍布了埃及全境。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 7:11; 出埃及记 7:22; 申命记 13:1–3"> 巫师也行邪术如法炮制，使青蛙遍布埃及。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 10:17; 出埃及记 9:28; 出埃及记 8:25–28"> 法老召摩西和亚伦进宫，对他们说：“你们要祈求耶和华，使这些青蛙离开我和我的百姓，我便让你们的百姓去献祭给耶和华。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 18:25; 以赛亚书 10:15; 士师记 7:2"> 摩西对法老说：“好吧，你要我在什么时候为你以及你的臣仆和百姓祷告，叫这些青蛙离开你和你的宫殿，只留在河里呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 46:9; 诗篇 86:8; 历代志上 17:20"> 法老说：“明天。”摩西说：“就照你说的，这样你就知道我们的上帝耶和华独一无二。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 8:3; 出埃及记 8:9"> 青蛙会离开你、你的宫殿、你的臣仆和百姓，只留在河里。”</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 5:16–18; 出埃及记 8:30; 出埃及记 10:18"> 摩西和亚伦离开法老后，摩西就为法老所受的蛙灾一事向耶和华呼求。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 34:10–12"> 耶和华答应了摩西的祈求。在房屋内、院子里和田野中的青蛙都死了。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 8:24; 出埃及记 7:21; 约珥书 2:20"> 百姓把青蛙的尸体堆积起来，埃及全境都充满了死青蛙的腐臭气味。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 26:10; 传道书 8:11; 希伯来书 3:8"> 法老看见灾难缓解，便又硬着心，不肯听从摩西和亚伦的话，正如耶和华所言。</span>
</div>
</div>

## 虱灾

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 8:5; 出埃及记 8:17"> 耶和华对摩西说：“你吩咐亚伦伸出他的杖击打地上的尘土，使埃及境内的尘土变成虱子。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 105:31; 以赛亚书 23:9; 使徒行传 12:23"> 他们就照上帝的吩咐去做，亚伦伸杖击打地上的尘土，虱子就跑到人和牲畜身上，全埃及的尘土都变成了虱子。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:11; 出埃及记 9:11; 但以理书 5:8"> 巫师们也试图用邪术变出虱子来，却无法成功。埃及的百姓和牲畜身上长满了虱子。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:20; 诗篇 8:3; 出埃及记 7:5"> 巫师们对法老说：“这是上帝的作为。”法老仍然硬着心，不肯答应摩西和亚伦的要求，正如耶和华所言。</span>
</div>
</div>

## 苍蝇之灾

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 7:15; 出埃及记 9:13; 出埃及记 8:1"> 耶和华对摩西说：“明天清早，你趁法老去河边时去见他，告诉他，‘耶和华说，放我的子民走，他们好事奉我，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 78:45; 以赛亚书 7:18; 诗篇 105:31"> 不然我就叫成群的苍蝇飞到你、你的臣仆和百姓身上，进到你们各自的家中，使埃及遍地布满苍蝇。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 9:4; 玛拉基书 3:18; 出埃及记 10:23"> 但那天，我必把我子民居住的歌珊分别出来，那里必没有成群的苍蝇，这样你就知道我耶和华主宰天下。</span>
<span className="v" id="v23" data-v="23"> 我要把我的子民跟你的百姓分开，明天我必行这神迹。’”</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 105:31; 诗篇 78:45; 出埃及记 8:21"> 耶和华果然这样行。密密麻麻的苍蝇飞进法老的王宫和他臣仆的家里，埃及全国都受到苍蝇的毁坏。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 8:8; 出埃及记 9:27; 出埃及记 10:16"> 法老召见摩西和亚伦，对他们说：“去吧，就在此地给你们的上帝献祭吧。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 43:32; 创世记 46:34; 申命记 7:25–26"> 摩西说：“这怎么行？我们献给我们的上帝耶和华的祭物会令埃及人厌恶。如果我们在埃及人面前献令他们厌恶的祭物，他们岂不会拿石头打死我们？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:18; 出埃及记 3:12; 出埃及记 34:11"> 我们要照我们上帝耶和华的吩咐离开这里，走三天的路程到旷野去献祭给祂。”</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 8:8; 出埃及记 9:28; 列王纪上 13:6"> 法老说：“我让你们去旷野献祭给你们的上帝耶和华，只是不要走得太远。你们要为我祈求。”</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 8:15; 耶利米书 42:20–21; 出埃及记 8:8"> 摩西说：“我离开这里就去祈求耶和华，使成群的苍蝇明天就离开你及你的臣仆和百姓，但这次你不可再食言，阻止以色列人去向耶和华献祭。”</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 8:12; 出埃及记 9:33; 雅各书 5:16"> 摩西说完以后，便离开王宫，去祈求耶和华。</span>
<span className="v" id="v31" data-v="31"> 耶和华就照摩西的祈求，使成群的苍蝇离开法老及其臣仆和百姓，一只也没有留下。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 8:15; 出埃及记 4:21; 罗马书 2:5"> 这一次，法老又硬着心，不肯让百姓离开埃及。</span>
</div>
</div>

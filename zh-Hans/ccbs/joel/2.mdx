## 耶和华审判的日子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约珥书 2:15; 约珥书 1:15; 彼得前书 4:7"> 你们要在锡安吹响号角，<br /><span className="pl pl-1">在我的圣山上发出警讯，</span><br /><span className="pl pl-1">此地的居民都要颤抖，</span><br /><span className="pl pl-1">因为耶和华的日子将要来临，</span><br /><span className="pl pl-1">已经近了。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 1:6; 西番雅书 1:14–15; 约珥书 2:10–11"> <span className="pl pl-1">那是昏暗阴沉的日子，</span><br /><span className="pl pl-1">是乌云密布的日子。</span><br /><span className="pl pl-1">来了一支空前绝后、强盛无比的大军，</span><br /><span className="pl pl-1">它们像曙光一样布满山岭。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 51:3; 约珥书 1:19–20; 创世记 2:8"> <span className="pl pl-1">它们前面有燎原之火，</span><br /><span className="pl pl-1">后面有熊熊烈焰。</span><br /><span className="pl pl-1">它们到来之前，</span><br /><span className="pl pl-1">大地就像伊甸园；</span><br /><span className="pl pl-1">它们过去之后，</span><br /><span className="pl pl-1">大地变成荒凉的旷野。</span><br /><span className="pl pl-1">地上的一切都逃不过这一场浩劫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="启示录 9:7"> <span className="pl pl-1">它们的形状像马，</span><br /><span className="pl pl-1">疾驰如战马，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="启示录 9:9; 以赛亚书 5:24; 以赛亚书 30:30"> <span className="pl pl-1">在山岭上跳跃奔腾，</span><br /><span className="pl pl-1">如隆隆战车，</span><br /><span className="pl pl-1">好像烈火吞噬干草的声音，</span><br /><span className="pl pl-1">又如大军列阵备战。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鸿书 2:10; 以赛亚书 13:8; 耶利米书 30:6"> <span className="pl pl-1">百姓一看到它们，就惊慌失措，</span><br /><span className="pl pl-1">面如死灰。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 30:27; 撒母耳记下 1:23; 撒母耳记下 2:18–19"> <span className="pl pl-1">它们快速奔跑像勇士，</span><br /><span className="pl pl-1">攀登城墙如战士，</span><br /><span className="pl pl-1">有条不紊地前进。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 23:10; 约伯记 33:18; 历代志下 32:5"> <span className="pl pl-1">队伍整齐，各行其道，</span><br /><span className="pl pl-1">长驱直入，势不可挡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:21; 约翰福音 10:1; 出埃及记 10:6"> <span className="pl pl-1">它们冲向城邑，蹿上城墙，</span><br /><span className="pl pl-1">爬进房屋，</span><br /><span className="pl pl-1">如盗贼般破窗而入。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:29; 以赛亚书 13:10; 约珥书 3:15–16"> <span className="pl pl-1">所到之处，</span><br /><span className="pl pl-1">天摇地动，</span><br /><span className="pl pl-1">日月昏暗，</span><br /><span className="pl pl-1">星辰无光。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="玛拉基书 3:2; 那鸿书 1:6; 耶利米书 30:7"> <span className="pl pl-1">耶和华向祂的军队发号施令，</span><br /><span className="pl pl-1">祂的队伍不计其数，</span><br /><span className="pl pl-1">执行祂命令的是劲旅。</span><br /><span className="pl pl-1">耶和华的日子伟大而可畏，</span><br /><span className="pl pl-1">谁能承受得住呢？</span></span>
</div>
</div>

## 呼吁人民悔改

<div className="bt">
<div className="bp poetry">

<span className="v" id="v13" data-v="13" data-xref="诗篇 86:15; 诗篇 34:18; 出埃及记 34:6–7"> <span className="pl pl-1">你们要撕心般地痛悔，</span><br /><span className="pl pl-1">而不是撕裂衣服。</span><br /><span className="pl pl-1">归向你们的上帝耶和华吧，</span><br /><span className="pl pl-1">因为祂有恩典、好怜悯，</span><br /><span className="pl pl-1">不轻易发怒，</span><br /><span className="pl pl-1">充满慈爱，</span><br /><span className="pl pl-1">不忍心降灾祸。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约拿书 3:9; 哈该书 2:19; 列王纪下 19:4"> <span className="pl pl-1">或许祂转念心生怜悯，</span><br /><span className="pl pl-1">给你们留下祝福，</span><br /><span className="pl pl-1">使你们可以再次向你们的上帝耶和华献上素祭和奠祭。</span><br /><span className="pl pl-1">有谁知道呢？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="约珥书 1:14; 约珥书 2:1; 列王纪上 21:12"> <span className="pl pl-1">要在锡安山吹响号角，</span><br /><span className="pl pl-1">宣布禁食的圣日，</span><br /><span className="pl pl-1">举行庄严的聚会。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="诗篇 115:2; 以西结书 8:16; 诗篇 79:10"> <span className="pl pl-1">让事奉耶和华的祭司站在圣殿门廊和祭坛中间，</span><br /><span className="pl pl-1">哭泣恳求说：</span><br /><span className="pl pl-1">“耶和华啊，</span><br /><span className="pl pl-1">求你顾惜你的子民，</span><br /><span className="pl pl-1">不要让外族人侮辱、</span><br /><span className="pl pl-1">讥笑你的产业说，</span><br /><span className="pl pl-1">‘他们的上帝在哪里呢？’”</span></span>
</div>
</div>

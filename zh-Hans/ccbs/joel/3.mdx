## 上帝要审判万国

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 3:19–20; 耶利米书 30:3; 以西结书 39:25"> “到那日，我要使犹大和耶路撒冷被掳的人返乡。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 14:2–4; 以赛亚书 66:16; 西番雅书 3:8"> 那时，我要聚集万国，带他们下到约沙法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“约沙法”意思是“耶和华审判”。">a</a></sup>谷，在那里审判他们，因为他们把我的子民，就是我的产业以色列，分散到各国，并瓜分我的土地。</span>
<span className="v" id="v3" data-v="3" data-xref="那鸿书 3:10; 俄巴底亚书 1:11; 阿摩司书 2:6"> 他们抽签分了我的子民，将男童换妓女，卖女童买酒喝。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="阿摩司书 1:6–10; 耶利米书 47:4; 以赛亚书 59:18"> “泰尔、西顿和非利士境内所有的人啊，你们为什么这样对我？你们要报复我吗？如果你们是报复我，我必速速使你们遭报应。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 21:16–17; 列王纪下 18:15–16; 列王纪下 12:18"> 你们夺去我的金银，抢走我的珍宝，拿去放在你们的庙中，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 27:13; 约珥书 3:3; 申命记 28:68"> 并把犹大和耶路撒冷的居民卖给希腊人，使他们远离家乡。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 43:5–6; 耶利米书 23:8; 帖撒罗尼迦后书 1:6"> 然而，他们被卖到哪里，我要促使他们从哪里离开，并要使你们得到报应，</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 60:14; 约伯记 1:15; 以赛亚书 14:1–2"> 我必把你们的儿女卖给犹大人，犹大人必把他们卖给远方的示巴人。这是耶和华说的。”</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 46:3–4; 以赛亚书 8:9–10; 以西结书 38:7"> <span className="pl pl-1">你们去向列国宣告：</span><br /><span className="pl pl-1">“要召集勇士，征调军队，</span><br /><span className="pl pl-1">前去打仗！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 12:8; 弥迦书 4:3; 历代志下 25:8"> <span className="pl pl-1">要将犁头打成刀剑，</span><br /><span className="pl pl-1">把镰刀铸成矛头，</span><br /><span className="pl pl-1">弱者要说自己是勇士！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 13:3; 西番雅书 3:8; 以西结书 38:9–18"> <span className="pl pl-1">四围的列国啊，</span><br /><span className="pl pl-1">你们快快聚集到那里吧！”</span><br /><span className="pl pl-1">耶和华啊，</span><br /><span className="pl pl-1">求你差遣大能的勇士降临。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="约珥书 3:2; 以赛亚书 2:4; 诗篇 96:13"> <span className="pl pl-1">“列国都要起来，</span><br /><span className="pl pl-1">上到约沙法谷，</span><br /><span className="pl pl-1">因为我要坐在那里审判周边列国。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 14:15–20; 马可福音 4:29; 何西阿书 6:11"> <span className="pl pl-1">开镰吧，因为庄稼熟了；</span><br /><span className="pl pl-1">踩踏吧，因为榨酒池的葡萄满了。</span><br /><span className="pl pl-1">酒池满溢，因为他们恶贯满盈。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="约珥书 3:2; 腓立比书 3:2; 以赛亚书 34:2–8"> <span className="pl pl-1">千千万万的人聚集在审判谷，</span><br /><span className="pl pl-1">因为耶和华的日子要临到那里。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约珥书 2:10; 马太福音 24:29; 约珥书 2:31"> <span className="pl pl-1">日月昏暗，</span><br /><span className="pl pl-1">星辰无光。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 1:2; 约珥书 2:10–11; 哈该书 2:6"> <span className="pl pl-1">耶和华从锡安发出怒吼，</span><br /><span className="pl pl-1">从耶路撒冷发出雷声，</span><br /><span className="pl pl-1">天地为之震动。</span><br /><span className="pl pl-1">但耶和华却是祂子民的避难所，</span><br /><span className="pl pl-1">是以色列人的堡垒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="约珥书 2:27; 那鸿书 1:15; 以赛亚书 52:1"> <span className="pl pl-1">“这样，你们就知道我是你们的上帝耶和华，</span><br /><span className="pl pl-1">我住在我的圣山锡安。</span><br /><span className="pl pl-1">耶路撒冷必为圣城，</span><br /><span className="pl pl-1">外族人必不再侵犯它。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="以西结书 47:1–12; 撒迦利亚书 14:8; 启示录 22:1–2"> <span className="pl pl-1">“到那日，群山要滴下甜酒，</span><br /><span className="pl pl-1">丘陵要流出乳汁。</span><br /><span className="pl pl-1">犹大的溪涧碧水常流，</span><br /><span className="pl pl-1">必有清泉从耶和华的殿中流出，</span><br /><span className="pl pl-1">浇灌什亭谷。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 19:1–15; 耶利米书 51:35; 撒迦利亚书 14:18–19"> <span className="pl pl-1">埃及必一片荒凉，</span><br /><span className="pl pl-1">以东必成为荒凉的旷野，</span><br /><span className="pl pl-1">因为他们曾残暴地对待犹大人，</span><br /><span className="pl pl-1">在犹大滥杀无辜。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 37:25; 阿摩司书 9:15; 以赛亚书 33:20"> <span className="pl pl-1">但犹大必常有人住，</span><br /><span className="pl pl-1">耶路撒冷必存到万代。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 4:4; 启示录 21:3; 以西结书 36:25"> <span className="pl pl-1">我必追讨</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“追讨”希伯来文是“洗净”。">b</a></sup><br /><span className="pl pl-1">尚未追讨的血债，</span><br /><span className="pl pl-1">因为耶和华住在锡安。”</span></span>
</div>

## 哈巴谷的祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 7:1–17; 诗篇 86:1–17; 诗篇 90:1–17"> 以下是哈巴谷先知的祷告，采用流离调<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="流离调是希伯来诗歌的一种曲调。">a</a></sup>。</span>

</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命记 33:2; 诗篇 4:4; 俄巴底亚书 1:9"> <span className="pl pl-1">上帝从提幔来，</span><br /><span className="pl pl-1">圣者从巴兰山来。（细拉）</span><br /><span className="pl pl-1">祂的荣耀遮蔽诸天，</span><br /><span className="pl pl-1">颂赞之声响彻大地。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 60:19–20; 马太福音 17:2; 约伯记 26:14"> <span className="pl pl-1">祂明亮如晨光，</span><br /><span className="pl pl-1">祂的手射出光芒，</span><br /><span className="pl pl-1">其中蕴藏着大能。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 12:29–30; 民数记 16:46–49; 诗篇 78:50–51"> <span className="pl pl-1">瘟疫行在祂前面，</span><br /><span className="pl pl-1">灾病跟在祂脚后。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 49:26; 申命记 33:15; 那鸿书 1:5"> <span className="pl pl-1">祂停下，大地就震动；</span><br /><span className="pl pl-1">祂观看，万民就战栗。</span><br /><span className="pl pl-1">古老的山岳崩裂，</span><br /><span className="pl pl-1">远古的丘陵塌陷，</span><br /><span className="pl pl-1">但祂的作为永远不变。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 15:14–16; 创世记 10:6–7; 创世记 25:1–4"> <span className="pl pl-1">我看见古珊的帐篷遭难，</span><br /><span className="pl pl-1">米甸的幔子颤抖。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 68:17; 申命记 33:26–27; 出埃及记 14:21–22"> <span className="pl pl-1">耶和华啊，你是向江河发怒吗？</span><br /><span className="pl pl-1">你骑着马、乘着得胜的战车而来，</span><br /><span className="pl pl-1">是向江河生气吗？</span><br /><span className="pl pl-1">是向海洋发怒吗？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 7:12–13; 诗篇 105:41; 诗篇 78:15–16"> <span className="pl pl-1">你张弓搭箭，要射出许多箭羽。（细拉）</span><br /><span className="pl pl-1">你以江河分开大地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 4:24; 约书亚记 4:23–24; 诗篇 93:3"> <span className="pl pl-1">群山看见你就战栗，</span><br /><span className="pl pl-1">大水奔腾而过，</span><br /><span className="pl pl-1">深渊鸣响，波浪滔天。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 144:5–6; 诗篇 18:12–14; 约书亚记 10:11–13"> <span className="pl pl-1">你射出的箭闪闪发光，</span><br /><span className="pl pl-1">你的枪熠熠生辉，</span><br /><span className="pl pl-1">以致日月都停在原处。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 51:33; 弥迦书 4:12–13; 民数记 21:23–35"> <span className="pl pl-1">你怀着烈怒走遍大地，</span><br /><span className="pl pl-1">带着怒火践踏列国。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 110:6; 诗篇 105:15; 诗篇 68:19–23"> <span className="pl pl-1">你出来是为了拯救你的子民，</span><br /><span className="pl pl-1">拯救你膏立的王。</span><br /><span className="pl pl-1">你打垮邪恶之人的首领，</span><br /><span className="pl pl-1">从头到脚彻底毁灭他。（细拉）</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亚书 9:14; 但以理书 11:40; 诗篇 118:10–12"> <span className="pl pl-1">你用他的矛刺透其勇士的头颅。</span><br /><span className="pl pl-1">他们如旋风而至，要驱散我们，</span><br /><span className="pl pl-1">他们喜好暗中吞噬贫民。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 77:19; 哈巴谷书 3:8; 出埃及记 15:8"> <span className="pl pl-1">你骑马踩踏汹涌的大海。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:9; 哈巴谷书 1:5–11; 哈巴谷书 3:2"> <span className="pl pl-1">我听到这些，</span><br /><span className="pl pl-1">就胆战心惊，嘴唇哆嗦，</span><br /><span className="pl pl-1">四肢无力，双腿发抖。</span><br /><span className="pl pl-1">但我仍要静候灾难临到入侵者的日子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 5:17; 约珥书 1:16–18; 申命记 28:15–18"> <span className="pl pl-1">即使无花果树不发芽，</span><br /><span className="pl pl-1">葡萄树不结果，</span><br /><span className="pl pl-1">橄榄树无收成，</span><br /><span className="pl pl-1">田地不产粮，</span><br /><span className="pl pl-1">圈里没有羊，</span><br /><span className="pl pl-1">棚里没有牛，</span><br /></span>

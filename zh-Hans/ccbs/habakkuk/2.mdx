<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:8; 启示录 14:13; 启示录 1:18–19"> <span className="pl pl-1">耶和华对我说：</span><br /><span className="pl pl-1">“将我的启示记下来，</span><br /><span className="pl pl-1">清楚地刻在板上，</span><br /><span className="pl pl-1">便于人们阅读。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 27:14; 希伯来书 10:36–37; 以西结书 12:25"> <span className="pl pl-1">这启示还未到实现之时，</span><br /><span className="pl pl-1">它关乎结局，没有虚假。</span><br /><span className="pl pl-1">即使缓慢，也要等候，</span><br /><span className="pl pl-1">因为这事终必发生，不再迟延。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:17; 希伯来书 10:38; 加拉太书 3:11–12"> <span className="pl pl-1">看那骄傲之人，他们心术不正，</span><br /><span className="pl pl-1">但义人必靠信心</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“信心”或译“忠信”。">a</a></sup><br /><span className="pl pl-1">而活。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 5:11–12; 箴言 27:20; 箴言 20:1"> <span className="pl pl-1">财富</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“财富”参照死海古卷，多个希伯来抄本为“酒”。">b</a></sup><br /><span className="pl pl-1">会欺骗骄傲之人，</span><br /><span className="pl pl-1">使他们永不安分，</span><br /><span className="pl pl-1">像阴间一样贪得无厌，</span><br /><span className="pl pl-1">如死亡一般永不满足。</span><br /><span className="pl pl-1">因此，他们征服万国，</span><br /><span className="pl pl-1">掳掠万民。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="民数记 23:7; 弥迦书 2:4; 耶利米书 50:13"> <span className="pl pl-1">“但万国万民必用诗歌和俗语嘲讽他们，说，</span><br /><span className="pl pl-1">‘你们有祸了！</span><br /><span className="pl pl-1">你们吞没别人的财产，</span><br /><span className="pl pl-1">靠剥削别人囤积财富，</span><br /><span className="pl pl-1">要到何时呢？’</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:1; 以赛亚书 47:11; 耶利米书 8:17"> <span className="pl pl-1">你们的债主必突然行动，</span><br /><span className="pl pl-1">使你们战战兢兢，</span><br /><span className="pl pl-1">沦为他们的俘虏。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 33:1; 哈巴谷书 2:17; 耶利米书 27:7"> <span className="pl pl-1">你们从前掳掠许多国家，</span><br /><span className="pl pl-1">杀人流血，</span><br /><span className="pl pl-1">摧毁他们的土地、城市和人民，</span><br /><span className="pl pl-1">所以各国的余民必掠夺你们。</span></span>

<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 49:16; 耶利米书 22:13–19; 以赛亚书 28:15"> <span className="pl pl-1">“为自己的家积蓄不义之财、</span><br /><span className="pl pl-1">在高处搭窝躲避灾祸的人啊，</span><br /><span className="pl pl-1">你们有祸了！</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="路加福音 19:40; 约书亚记 24:27; 约伯记 31:38–40"> <span className="pl pl-1">墙上的石头必高声控诉，</span><br /><span className="pl pl-1">房子的梁木必同声响应。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 3:10; 但以理书 4:27–31; 那鸿书 3:1"> <span className="pl pl-1">“以人血建城邑，</span><br /><span className="pl pl-1">以罪恶造城池的人啊，</span><br /><span className="pl pl-1">你们有祸了！</span><br /></span>

<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 51:7; 创世记 9:22; 启示录 18:3"> <span className="pl pl-1">“让邻居喝酒直到灌醉他们，好观看他们祼体的人啊，</span><br /><span className="pl pl-1">你们有祸了！</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 10:8; 哥林多前书 12:2; 以赛亚书 44:9–10"> <span className="pl pl-1">“雕刻的偶像有什么益处？</span><br /><span className="pl pl-1">骗人的铸像有什么用处？</span><br /><span className="pl pl-1">制造者竟信靠自己造的哑巴偶像！</span><br /></span>

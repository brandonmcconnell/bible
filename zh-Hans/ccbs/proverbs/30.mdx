## 亚古珥的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 31:1; 彼得后书 1:19–21"> 以下是雅基的儿子亚古珥的箴言。<br /><span className="pl pl-2">这人说：上帝啊，我很疲倦；</span><br /><span className="pl pl-2">上帝啊，我很疲倦，精疲力尽。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“这人说”希伯来文或译“这人对以铁说，对以铁和乌甲说”。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 73:22; 哥林多前书 3:18; 以赛亚书 6:5"> <span className="pl pl-1">我比众人都愚蠢，</span><br /><span className="pl pl-2">不具备人的悟性。</span></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:7; 以弗所书 3:18–19; 罗马书 11:33"> <span className="pl pl-1">我从未学到智慧，</span><br /><span className="pl pl-2">也不认识至圣者。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 3:13; 以弗所书 4:8–10; 约伯记 26:8"> <span className="pl pl-1">谁升上高天又降下来？</span><br /><span className="pl pl-2">谁将风聚在掌中？</span><br /><span className="pl pl-2">谁将众水裹在衣服里？</span><br /><span className="pl pl-2">谁定了地的边界？</span><br /><span className="pl pl-2">祂叫什么名字？</span><br /><span className="pl pl-2">祂儿子叫什么名字？</span><br /><span className="pl pl-2">你知道吗？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:30; 雅各书 3:17; 诗篇 12:6"> <span className="pl pl-1">上帝的话句句千真万确，</span><br /><span className="pl pl-2">祂作投靠祂之人的盾牌。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 12:32; 申命记 4:2; 启示录 22:18–19"> <span className="pl pl-1">你不可对祂的话有所添加，</span><br /><span className="pl pl-2">免得祂责备你，</span><br /><span className="pl pl-2">揭穿你的虚谎。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:42; 列王纪下 2:9; 诗篇 27:4"> <span className="pl pl-1">上帝啊，我向你求两件事，</span><br /><span className="pl pl-2">求你在我有生之年赐给我。</span></span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 6:6–8; 诗篇 62:9–10; 诗篇 119:37"> <span className="pl pl-1">求你使虚伪和谎言远离我，</span><br /><span className="pl pl-2">求你让我不贫穷也不富足，</span><br /><span className="pl pl-2">赐给我需用的饮食，</span></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 13:6; 申命记 31:20; 以西结书 16:49–50"> <span className="pl pl-1">免得我因为饱足就不认你，</span><br /><span className="pl pl-2">说：“耶和华是谁呢？”</span><br /><span className="pl pl-2">又恐怕我因穷困而偷窃，</span><br /><span className="pl pl-2">以致辱没我上帝的名。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:4; 传道书 7:21; 申命记 23:15"> <span className="pl pl-1">别向主人毁谤他的仆人，</span><br /><span className="pl pl-2">免得你受咒诅、担当罪责。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 20:20; 箴言 30:17; 出埃及记 21:17"> <span className="pl pl-1">有一种</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“种”希伯来文是“世代”，11-14节也相同。">b</a></sup><br /><span className="pl pl-1">人咒诅父亲，</span><br /><span className="pl pl-2">不为母亲祝福。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 18:11; 箴言 16:2; 提摩太后书 3:5"> <span className="pl pl-1">有一种人自以为纯洁，</span><br /><span className="pl pl-2">却没有洗掉自己的污秽。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 6:17; 以赛亚书 2:11; 诗篇 101:5"> <span className="pl pl-1">有一种人趾高气扬，</span><br /><span className="pl pl-2">目空一切。</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 57:4; 诗篇 3:7; 诗篇 14:4"> <span className="pl pl-1">有一种人牙如剑，</span><br /><span className="pl pl-2">齿如刀，</span><br /><span className="pl pl-2">要吞吃世间的困苦人和贫穷人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="箴言 30:21; 箴言 30:29; 箴言 6:16"> <span className="pl pl-1">水蛭有两个女儿，</span><br /><span className="pl pl-2">她们不停地叫：“给我！给我！”</span><br /><span className="pl pl-1">三样东西从不知足，</span><br /><span className="pl pl-1">永不言“够”的共有四样：</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:20; 哈巴谷书 2:5; 创世记 30:1"> <span className="pl pl-1">阴间、不孕的妇人、</span><br /><span className="pl pl-2">干旱的土地和烧不够的火焰。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 23:22; 申命记 21:18–21; 箴言 30:11"> <span className="pl pl-1">嘲笑父亲、藐视母亲教诲的，</span><br /><span className="pl pl-2">眼睛必被谷中的乌鸦啄出，</span><br /><span className="pl pl-2">被秃鹰吃掉。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="约伯记 42:3; 诗篇 139:6"> <span className="pl pl-1">我测不透的妙事有三样，</span><br /><span className="pl pl-1">我不明白的事共有四样：</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 40:31; 约伯记 39:27; 出埃及记 22:16"> <span className="pl pl-1">鹰在空中飞翔之道，</span><br /><span className="pl pl-2">蛇在石上爬行之道，</span><br /><span className="pl pl-2">船在海中航行之道，</span><br /><span className="pl pl-2">男女相爱之道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 5:6; 箴言 7:13–23; 民数记 5:11–30"> <span className="pl pl-1">淫妇的道是这样：</span><br /><span className="pl pl-2">她吃完就擦擦嘴，</span><br /><span className="pl pl-2">说，“我没有做坏事。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">使大地震动的事有三样，</span><br /><span className="pl pl-1">大地无法承受的事共有四样：</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 19:10; 传道书 10:7; 撒母耳记上 25:10–11"> <span className="pl pl-1">奴仆做王，</span><br /><span className="pl pl-2">愚人吃饱，</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 21:19; 箴言 27:15; 箴言 29:21"> <span className="pl pl-1">丑恶女子出嫁，</span><br /><span className="pl pl-2">婢女取代主母。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="约伯记 12:7"> <span className="pl pl-1">地上有四种动物，</span><br /><span className="pl pl-2">身体虽小却极其聪明：</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:6–8"> <span className="pl pl-1">蚂蚁力量虽小，</span><br /><span className="pl pl-2">却在夏天储备粮食；</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 104:18; 利未记 11:5"> <span className="pl pl-1">石獾虽不强壮，</span><br /><span className="pl pl-2">却在岩石中做窝；</span></span>
<span className="v" id="v27" data-v="27" data-xref="约珥书 2:25; 约珥书 1:6–7; 约珥书 2:7–11"> <span className="pl pl-1">蝗虫虽无君王，</span><br /><span className="pl pl-2">却整齐地列队前进；</span></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">壁虎虽易捕捉，</span><br /><span className="pl pl-2">却居住在王宫大内。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">步履威武的有三样，</span><br /><span className="pl pl-1">走路雄壮的共有四样：</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="民数记 23:24; 士师记 14:18"> <span className="pl pl-1">威震百兽、从不畏缩的狮子，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 3:15–18; 箴言 20:2; 箴言 16:14"> <span className="pl pl-1">昂首阔步的雄鸡，</span><br /><span className="pl pl-2">公山羊和率领军队的君王。</span></span>

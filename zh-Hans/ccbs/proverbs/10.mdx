## 所罗门的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 箴言 29:15; 箴言 17:25"> 以下是所罗门的箴言：<br /><span className="pl pl-2">智慧儿使父亲快乐，</span><br /><span className="pl pl-2">愚昧儿叫母亲忧伤。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 11:4; 箴言 12:28; 诗篇 49:6–10"> <span className="pl pl-1">不义之财毫无益处，</span><br /><span className="pl pl-2">公义救人脱离死亡。</span></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 37:3; 马太福音 6:30–33; 诗篇 37:25"> <span className="pl pl-1">耶和华不让义人挨饿，</span><br /><span className="pl pl-2">祂使恶人的奢望成空。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 21:5; 箴言 20:4; 箴言 19:15"> <span className="pl pl-1">游手好闲招致贫穷，</span><br /><span className="pl pl-2">勤奋努力带来富足。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:8; 箴言 30:25; 箴言 17:2"> <span className="pl pl-1">精明儿夏季时贮藏，</span><br /><span className="pl pl-2">不肖子收成时酣睡。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:2; 箴言 28:20; 约伯记 29:13"> <span className="pl pl-1">祝福临到义人的头，</span><br /><span className="pl pl-2">残暴充满恶人的口。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 112:6; 路加福音 1:48; 马可福音 14:9"> <span className="pl pl-1">义人流芳于世，</span><br /><span className="pl pl-2">恶人名声败坏。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 7:24–25; 箴言 12:1; 雅各书 3:13"> <span className="pl pl-1">心存智慧的接受诫命；</span><br /><span className="pl pl-2">说话愚昧的自招灭亡。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:18; 马太福音 10:26; 诗篇 26:11–12"> <span className="pl pl-1">行正道者活得安稳，</span><br /><span className="pl pl-2">走歪路者终必败露。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 35:19; 箴言 6:13; 约翰三书 1:10"> <span className="pl pl-1">挤眉弄眼，带来忧伤；</span><br /><span className="pl pl-2">胡言乱语，导致灭亡。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:14; 以弗所书 4:29; 箴言 10:6"> <span className="pl pl-1">义人的口是生命之泉，</span><br /><span className="pl pl-2">恶人的口却充满残暴。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:8; 哥林多前书 13:4–7; 箴言 17:9"> <span className="pl pl-1">恨能挑起纷争，</span><br /><span className="pl pl-2">爱能遮掩一切过犯。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 26:3; 箴言 6:32; 以赛亚书 50:4"> <span className="pl pl-1">明哲口中有智慧，</span><br /><span className="pl pl-2">无知者背上受鞭打。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:7; 箴言 10:8; 箴言 13:3"> <span className="pl pl-1">智者储藏知识，</span><br /><span className="pl pl-2">愚人口惹祸端。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 18:11; 箴言 19:7; 诗篇 52:7"> <span className="pl pl-1">钱财是富人的坚城，</span><br /><span className="pl pl-2">贫乏带给穷人毁灭。</span></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:23; 以赛亚书 3:10–11; 希伯来书 6:10"> <span className="pl pl-1">义人的报酬是生命，</span><br /><span className="pl pl-2">恶人的果子是惩罚。</span></span>
<span className="v" id="v17" data-v="17" data-xref="彼得后书 1:5–11; 路加福音 11:28; 箴言 6:23"> <span className="pl pl-1">听从教诲的，走生命之路；</span><br /><span className="pl pl-2">拒绝责备的，必步入歧途。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 26:24–26; 诗篇 55:21; 撒母耳记下 3:27"> <span className="pl pl-1">暗藏仇恨的满口虚谎，</span><br /><span className="pl pl-2">散布流言的愚不可及。</span></span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 1:19; 雅各书 3:2; 箴言 17:27–28"> <span className="pl pl-1">言多必失，智者慎言。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 17:9; 箴言 12:18; 创世记 6:5"> <span className="pl pl-1">义人之舌似纯银，</span><br /><span className="pl pl-2">恶人之心无价值。</span></span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 4:6; 箴言 17:16; 箴言 1:29"> <span className="pl pl-1">义人的口滋养众人，</span><br /><span className="pl pl-2">愚人因无知而死亡。</span></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 107:38; 创世记 26:12; 撒母耳记上 2:7–8"> <span className="pl pl-1">耶和华的祝福使人富足，</span><br /><span className="pl pl-2">祝福中不加任何忧愁</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“祝福中不加任何忧愁”或译“劳苦无法使其加增”。">a</a></sup><br /><span className="pl pl-2">。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:21; 箴言 2:14; 箴言 14:9"> <span className="pl pl-1">愚人以恶为乐，</span><br /><span className="pl pl-2">哲士喜爱智慧。</span></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 145:19; 以赛亚书 66:4; 马太福音 5:6"> <span className="pl pl-1">恶人所怕的必临到他，</span><br /><span className="pl pl-2">义人的心愿必得实现。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 15:5; 诗篇 58:9; 马太福音 7:24–27"> <span className="pl pl-1">暴风扫过，</span><br /><span className="pl pl-2">恶人消逝无踪，</span><br /><span className="pl pl-2">义人永不动摇。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 25:13; 箴言 26:6; 马太福音 25:26"> <span className="pl pl-1">懒汉让差他的人难受，</span><br /><span className="pl pl-2">如醋倒牙，如烟熏目。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 9:11; 箴言 3:2; 诗篇 91:16"> <span className="pl pl-1">敬畏耶和华的享长寿，</span><br /><span className="pl pl-2">恶人的寿数必被缩短。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 8:13; 罗马书 15:13; 诗篇 73:24–26"> <span className="pl pl-1">义人的憧憬带来欢乐，</span><br /><span className="pl pl-2">恶人的希望终必破灭。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 21:15; 罗马书 2:8–9; 腓立比书 4:13"> <span className="pl pl-1">耶和华的道保护正直人，</span><br /><span className="pl pl-2">毁灭作恶之人。</span></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 37:22; 诗篇 125:1; 诗篇 37:9–10"> <span className="pl pl-1">义人永不动摇，</span><br /><span className="pl pl-2">恶人无处容身。</span></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 37:30; 箴言 10:13; 箴言 10:20–21"> <span className="pl pl-1">义人的口发出智慧，</span><br /><span className="pl pl-2">诡诈的舌必被割掉。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 15:28; 箴言 12:6; 箴言 11:11"> <span className="pl pl-1">义人说话得体合宜，</span><br /><span className="pl pl-2">恶人口出乖谬之言。</span></span>

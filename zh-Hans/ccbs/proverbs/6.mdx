<span className="v" id="v8" data-v="8" data-xref="箴言 10:5; 提摩太前书 6:19; 箴言 30:25"> <span className="pl pl-1">却在夏季储备粮食，</span><br /><span className="pl pl-2">在收割时积聚食物。</span></span>

<span className="v" id="v11" data-v="11" data-xref="箴言 13:4; 箴言 10:4; 箴言 24:34"> <span className="pl pl-1">贫穷必像盗贼一样临到你，</span><br /><span className="pl pl-2">缺乏必像武士一样扑向你。</span></span>

<div className="bp poetry">

<span className="v" id="v14" data-v="14" data-xref="罗马书 16:17; 弥迦书 2:1; 何西阿书 8:7"> <span className="pl pl-1">心术不正，图谋恶事，常常挑起争端。</span><br /></span>

<span className="v" id="v16" data-v="16" data-xref="诗篇 11:5; 箴言 8:13; 箴言 11:20"> <span className="pl pl-1">耶和华所憎恶的事有六样，</span><br /><span className="pl pl-1">连祂厌恶的事共有七样：</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 120:2–3; 箴言 12:22; 诗篇 101:5"> <span className="pl pl-1">高傲的眼睛，</span><br /><span className="pl pl-2">撒谎的舌头，</span><br /><span className="pl pl-2">杀害无辜的手，</span></span>
<span className="v" id="v18" data-v="18" data-xref="创世记 6:5; 箴言 1:16; 罗马书 3:15"> <span className="pl pl-1">图谋诡计的心，</span><br /><span className="pl pl-2">奔跑作恶的脚，</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 6:14; 雅各书 3:18"> <span className="pl pl-1">撒谎的假证人，</span><br /><span className="pl pl-2">以及在弟兄中挑起争端的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:1; 申命记 27:16; 箴言 7:1–4"> <span className="pl pl-1">孩子啊，要遵守你父亲的诫命，</span><br /><span className="pl pl-2">不可背弃你母亲的训诲。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:3; 箴言 7:3–4; 哥林多后书 3:3"> <span className="pl pl-1">你要常常将这些系在心坎上，</span><br /><span className="pl pl-2">戴在颈项上。</span></span>

<span className="v" id="v23" data-v="23" data-xref="诗篇 119:105; 彼得后书 1:19; 诗篇 19:8"> <span className="pl pl-1">因为诫命是灯，训诲是光，</span><br /><span className="pl pl-2">管教和责备是生命之道，</span></span>

<span className="v" id="v27" data-v="27" data-xref="约伯记 31:9–12; 何西阿书 7:4–7; 雅各书 3:5"> <span className="pl pl-1">人若将火藏在怀中，</span><br /><span className="pl pl-2">哪能不烧着衣服呢？</span></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">人若行走在火炭上，</span><br /><span className="pl pl-2">哪能不烫伤双脚呢？</span></span>

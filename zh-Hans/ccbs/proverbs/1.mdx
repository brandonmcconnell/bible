## 箴言的价值

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 10:1; 历代志上 22:9; 历代志上 28:5"> 这是大卫的儿子以色列王所罗门的箴言。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="箴言 7:4; 申命记 4:5–6; 提摩太后书 3:15–17"> <span className="pl pl-1">为使人认识智慧和教诲，</span><br /><span className="pl pl-2">领悟真知灼见，</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; 约伯记 22:22; 箴言 8:10–11"> <span className="pl pl-1">接受精明处事的教诲，</span><br /><span className="pl pl-2">为人处事仁义、公平、正直；</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 诗篇 119:9"> <span className="pl pl-1">使愚昧人明智，</span><br /><span className="pl pl-2">使年轻人有知识和明辨力；</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; 哥林多前书 10:15"> <span className="pl pl-1">使智者听了长学问，</span><br /><span className="pl pl-2">明哲听了得指引；</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:2; 马可福音 4:11; 诗篇 49:4"> <span className="pl pl-1">使人领悟箴言和比喻，</span><br /><span className="pl pl-2">明白智者的话和谜语。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 诗篇 111:10–1; 传道书 12:13"> 知识始于敬畏耶和华，<br /><span className="pl pl-2">愚人轻视智慧和教诲。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">孩子啊，</span><br /><span className="pl pl-2">你要听从父亲的教诲，</span><br /><span className="pl pl-2">不可背弃母亲的训诲。</span></span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:29; 箴言 4:9; 创世记 41:42"> <span className="pl pl-1">因为这要作你头上的华冠，</span><br /><span className="pl pl-2">颈上的项链。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 5:11; 箴言 16:29; 诗篇 1:1"> <span className="pl pl-1">孩子啊，恶人若引诱你，</span><br /><span className="pl pl-2">不要屈从。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">他们若说：“跟我们来吧，</span><br /><span className="pl pl-2">我们去埋伏杀人，</span><br /><span className="pl pl-2">任意暗害无辜者；</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 124:3; 诗篇 28:1; 罗马书 3:13"> <span className="pl pl-1">我们要像阴间一样生吞他们，</span><br /><span className="pl pl-2">整个吞没他们，</span><br /><span className="pl pl-2">使他们如坠入坟墓的人；</span></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 6:9–10; 路加福音 12:15; 约伯记 24:2–3"> <span className="pl pl-1">我们必得到各样宝物，</span><br /><span className="pl pl-2">把战利品装满我们的房屋。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">跟我们一起干吧，</span><br /><span className="pl pl-2">大家有福同享！”</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:101; 诗篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">孩子啊，</span><br /><span className="pl pl-2">不要走他们的道，</span><br /><span className="pl pl-2">切莫行他们的路。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">因为他们奔向罪恶，</span><br /><span className="pl pl-2">急速地去杀人流血。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 35:11; 箴言 7:23; 耶利米书 8:7"> <span className="pl pl-1">在飞鸟眼前设网罗，徒劳无功。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 9:16; 以斯帖记 7:10; 箴言 5:22–23"> <span className="pl pl-1">他们埋伏，却自流己血；</span><br /><span className="pl pl-2">他们伏击，却自害己命。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; 彼得后书 2:3; 雅各书 5:1–4"> <span className="pl pl-1">这就是贪爱不义之财者的结局，</span><br /><span className="pl pl-2">不义之财终要夺去他们的性命。</span></span>
</div>
</div>

## 智慧的劝诫

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; 歌罗西书 2:3; 路加福音 11:49"> <span className="pl pl-1">智慧在大街上高喊，</span><br /><span className="pl pl-2">在广场上扬声，</span></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:20; 箴言 9:3; 马太福音 13:2"> <span className="pl pl-1">在热闹的街头宣告，</span><br /><span className="pl pl-2">在城门口发言：</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 诗篇 1:1; 箴言 5:12"> <span className="pl pl-1">“你们愚昧人喜爱愚昧，</span><br /><span className="pl pl-2">嘲讽者以嘲弄为乐，</span><br /><span className="pl pl-2">无知者厌恶知识，</span><br /><span className="pl pl-2">要到什么时候呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 以西结书 33:11; 以西结书 18:27–30"> <span className="pl pl-1">你们若因我的责备而回转，</span><br /><span className="pl pl-2">我就向你们显明我的旨意</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“我就向你们显明我的旨意”希伯来文是“我就将我的灵浇灌你们”。">a</a></sup><br /><span className="pl pl-2">，</span><br /><span className="pl pl-2">叫你们明白我的话语。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:12; 罗马书 10:21; 耶利米书 7:13"> <span className="pl pl-1">我呼唤你们，</span><br /><span className="pl pl-2">你们却充耳不闻；</span><br /><span className="pl pl-2">我向你们招手，</span><br /><span className="pl pl-2">你们却视若无睹。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:11; 路加福音 7:30; 箴言 1:30"> <span className="pl pl-1">你们漠视我的劝诫，</span><br /><span className="pl pl-2">不接受我的责备。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:4; 箴言 10:24; 诗篇 37:13"> <span className="pl pl-1">因此，</span><br /><span className="pl pl-2">你们遭遇灾难时，</span><br /><span className="pl pl-2">我必发笑；</span><br /><span className="pl pl-2">惊恐临到你们时，</span><br /><span className="pl pl-2">我必嗤笑。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; 路加福音 21:34–35; 诗篇 58:9"> <span className="pl pl-1">那时，恐惧如风暴袭击你们，</span><br /><span className="pl pl-2">灾难如旋风临到你们，</span><br /><span className="pl pl-2">忧愁和苦难吞没你们。</span></span>
<span className="v" id="v28" data-v="28" data-xref="弥迦书 3:4; 雅各书 4:3; 耶利米书 11:11"> <span className="pl pl-1">你们呼求我，</span><br /><span className="pl pl-2">我也不回答；</span><br /><span className="pl pl-2">你们恳切地寻找我，</span><br /><span className="pl pl-2">却找不到。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; 约伯记 21:14–15; 箴言 6:23"> <span className="pl pl-1">因为你们厌恶知识，</span><br /><span className="pl pl-2">决定不敬畏耶和华，</span></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 81:11; 箴言 1:25; 路加福音 14:18–20"> <span className="pl pl-1">不接受我的劝诫，</span><br /><span className="pl pl-2">又藐视我的责备。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 14:14; 耶利米书 6:19; 箴言 22:8"> <span className="pl pl-1">所以，你们必自食其果，</span><br /><span className="pl pl-2">因自己的恶谋而吃尽苦头。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 8:36; 耶利米书 2:19; 约翰福音 3:36"> <span className="pl pl-1">愚昧人背离正道，</span><br /><span className="pl pl-2">自招灭亡；</span><br /><span className="pl pl-2">愚顽人逍遥自在，</span><br /><span className="pl pl-2">毁掉自己。</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 25:12–13; 诗篇 112:7–8; 以赛亚书 26:3"> <span className="pl pl-1">然而，那听从我的必安然居住，</span><br /><span className="pl pl-2">得享安宁，</span><br /><span className="pl pl-2">不怕灾祸。”</span></span>
</div>

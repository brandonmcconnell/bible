## 要远离淫妇

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:8; 启示录 1:3; 路加福音 11:28"> <span className="pl pl-1">孩子啊，你要遵从我的吩咐，</span><br /><span className="pl pl-2">把我的诫命珍藏在心中。</span></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 17:8; 箴言 4:4; 利未记 18:5"> <span className="pl pl-1">遵守我的诫命，你便存活。</span><br /><span className="pl pl-2">要爱护我的训诲，</span><br /><span className="pl pl-2">如爱护眼中的瞳仁。</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命记 11:18–20; 箴言 3:3; 申命记 6:8–9"> <span className="pl pl-1">要系在你的指头上，</span><br /><span className="pl pl-2">刻在你的心版上。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 4:6–8; 箴言 2:2–4; 雅歌 8:1"> <span className="pl pl-1">你要把智慧当作姊妹，</span><br /><span className="pl pl-2">将悟性视为亲人。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 2:16; 箴言 6:24; 箴言 5:3"> <span className="pl pl-1">她们能使你远离淫妇，</span><br /><span className="pl pl-2">远离妓女的甜言蜜语。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="创世记 26:8; 士师记 5:28; 撒母耳记下 6:16"> <span className="pl pl-1">我曾在家里的窗前，</span><br /><span className="pl pl-2">透过窗棂往外观看，</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 6:32; 箴言 1:22; 箴言 1:32"> <span className="pl pl-1">只见在愚昧人中，</span><br /><span className="pl pl-2">有个无知的青年，</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 5:8; 箴言 7:12; 士师记 16:1"> <span className="pl pl-1">他穿过靠近淫妇的巷口，</span><br /><span className="pl pl-2">朝她的家门走去，</span></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 24:13–15; 罗马书 13:12–14; 以弗所书 5:11"> <span className="pl pl-1">趁着日暮黄昏，</span><br /><span className="pl pl-2">借着夜色昏暗。</span></span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 2:9; 以赛亚书 3:16–24; 哥林多后书 11:2–3"> <span className="pl pl-1">看啊！一个妓女打扮、</span><br /><span className="pl pl-2">心术不正的女子出来迎接他。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 9:13; 提多书 2:5; 箴言 31:10–31"> <span className="pl pl-1">她喧嚷放荡，不安分守家，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 23:28; 箴言 9:14; 启示录 18:3"> <span className="pl pl-1">有时在街上，有时在广场，</span><br /><span className="pl pl-2">或在各巷口守候。</span></span>
<span className="v" id="v13" data-v="13" data-xref="创世记 39:12; 民数记 25:6–8; 创世记 39:7"> <span className="pl pl-1">她缠着那青年，与他亲吻，</span><br /><span className="pl pl-2">厚颜无耻地说：</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 21:27; 利未记 7:11; 箴言 17:1"> <span className="pl pl-1">“我今天刚献祭还了愿，</span><br /><span className="pl pl-2">家里有平安祭肉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="按犹太律法规定，还愿之后所得的祭肉要在第二天吃完。参考利未记7:16。">a</a></sup><br /><span className="pl pl-2">，</span></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">因此我出来迎接你，寻找你，</span><br /><span className="pl pl-2">终于找到了你！</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 19:9; 以西结书 27:7; 列王纪上 10:28"> <span className="pl pl-1">我已经铺好了床，</span><br /><span className="pl pl-2">铺上了埃及的绣花布，</span></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 45:8; 以赛亚书 57:7–9; 雅歌 4:13–14"> <span className="pl pl-1">又用没药、沉香、肉桂熏了床。</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">来吧，让我们通宵畅饮爱情，</span><br /><span className="pl pl-2">让我们尽情欢爱！</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 20:11; 路加福音 12:45–46; 路加福音 12:39"> <span className="pl pl-1">因为我丈夫不在家，出远门了。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 2:4"> <span className="pl pl-1">他带着钱囊去了，月圆才回来。”</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 5:3; 箴言 7:5; 列王纪下 4:8"> <span className="pl pl-1">淫妇花言巧语勾引他，</span><br /><span className="pl pl-2">用谄媚的话语诱惑他。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 13:27; 使徒行传 16:24; 使徒行传 14:13"> <span className="pl pl-1">那青年立刻随她而去，</span><br /><span className="pl pl-2">像走向屠宰场的公牛，</span><br /><span className="pl pl-2">又像掉入陷阱的雄鹿，</span></span>
<span className="v" id="v23" data-v="23" data-xref="传道书 9:12; 箴言 9:18; 箴言 1:17"> <span className="pl pl-1">直等到利箭射穿他的肝。</span><br /><span className="pl pl-2">他像只自投网罗的飞鸟，</span><br /><span className="pl pl-2">浑然不知要赔上性命！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="箴言 5:7; 箴言 4:1; 约翰一书 2:1"> <span className="pl pl-1">孩子们啊，你们要听从我的话，</span><br /><span className="pl pl-2">留意我口中的训言，</span></span>

## 所罗门的箴言（续）

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 列王纪上 4:32; 弥迦书 1:1"> 以下也是所罗门的箴言，由犹大王希西迦的人抄录。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 29:29; 罗马书 11:33–34; 约伯记 11:7–8"> <span className="pl pl-1">将事隐藏是上帝的荣耀，</span><br /><span className="pl pl-2">把事查明是君王的光荣。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 55:9; 诗篇 103:11; 列王纪上 4:29"> <span className="pl pl-1">天之高，地之厚，</span><br /><span className="pl pl-2">君王的心测不透。</span></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 2:20–21; 以西结书 22:18; 箴言 17:3"> <span className="pl pl-1">除掉银子里的渣滓，</span><br /><span className="pl pl-2">银匠就能铸造器皿。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:12; 箴言 20:8; 诗篇 101:7–8"> <span className="pl pl-1">清除君王身边的恶人，</span><br /><span className="pl pl-2">王位必因公义而巩固。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 27:2; 箴言 25:27; 箴言 16:19"> <span className="pl pl-1">不可在王面前妄自尊大，</span><br /><span className="pl pl-2">不要占据大人物的位子。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:7–11; 路加福音 18:14; 彼得前书 5:5"> <span className="pl pl-1">与其在权贵面前被贬低，</span><br /><span className="pl pl-2">不如等人邀请你坐上座。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:25; 箴言 17:14; 箴言 18:6"> <span className="pl pl-1">不可贸然打官司，</span><br /><span className="pl pl-2">以免被邻舍羞辱，</span><br /><span className="pl pl-2">无所适从。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 18:5–17; 箴言 11:13; 箴言 20:19"> <span className="pl pl-1">遇到跟邻舍对簿公堂，</span><br /><span className="pl pl-2">不可泄露他人的秘密，</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 119:39"> <span className="pl pl-1">免得听见的人辱骂你，</span><br /><span className="pl pl-2">你的恶名将永难洗刷。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 15:23; 以赛亚书 50:4; 传道书 12:10"> <span className="pl pl-1">一句话说得合宜，</span><br /><span className="pl pl-2">就像金苹果放在银器里。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 141:5; 箴言 15:31–32; 箴言 15:5"> <span className="pl pl-1">对受教者而言，</span><br /><span className="pl pl-2">智者的责备犹如金耳环和金饰物。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:17; 箴言 25:25; 腓立比书 2:25–30"> <span className="pl pl-1">忠信的使者叫主人心里舒畅，</span><br /><span className="pl pl-2">就像夏收之时有冰雪的凉气。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:6; 路加福音 14:11; 彼得后书 2:15–19"> <span className="pl pl-1">夸口送礼物却食言的人，</span><br /><span className="pl pl-2">就像没有雨水的风和云。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 15:1; 传道书 10:4; 箴言 16:14"> <span className="pl pl-1">坚忍的耐心说服君王，</span><br /><span className="pl pl-2">柔和的舌头折断骨头。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 25:27; 以弗所书 5:18; 箴言 24:13–14"> <span className="pl pl-1">找到蜂蜜要酌量而食，</span><br /><span className="pl pl-2">免得吃多了呕吐。</span></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 19:2–3; 士师记 19:18–21; 罗马书 15:24"> <span className="pl pl-1">不要频频去邻舍家，</span><br /><span className="pl pl-2">免得惹人烦、遭人厌。</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 57:4; 箴言 12:18; 雅各书 3:6"> <span className="pl pl-1">作伪证陷害邻舍的人，</span><br /><span className="pl pl-2">无异于大锤、快刀和利箭。</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:6; 以西结书 29:6–7; 约伯记 6:14–20"> <span className="pl pl-1">危难时投靠奸诈之人，</span><br /><span className="pl pl-2">形同倚靠坏牙和跛脚。</span></span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:15; 传道书 3:4; 以赛亚书 58:7"> <span className="pl pl-1">对忧伤的人唱歌，</span><br /><span className="pl pl-2">如同天寒脱衣、伤口撒盐。</span></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:20–21; 马太福音 5:44; 出埃及记 23:4–5"> <span className="pl pl-1">你的仇敌若饿了，</span><br /><span className="pl pl-2">就给他吃的；</span><br /><span className="pl pl-2">若渴了，就给他水喝；</span></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 16:12; 马太福音 10:13; 哥林多前书 15:18"> <span className="pl pl-1">因为你这是把炭火堆在他头上，</span><br /><span className="pl pl-2">耶和华必奖赏你。</span></span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 37:22; 诗篇 15:3; 罗马书 1:30"> <span className="pl pl-1">北风带来雨水，</span><br /><span className="pl pl-2">谗言激起愤怒。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 21:19; 箴言 21:9; 箴言 27:15–16"> <span className="pl pl-1">宁愿住在屋顶的一角，</span><br /><span className="pl pl-2">也不跟争闹之妻同屋。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:30; 罗马书 10:15; 诗篇 63:1"> <span className="pl pl-1">有好消息从远方传来，</span><br /><span className="pl pl-2">如凉水滋润干渴的人。</span></span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 34:18–19; 撒母耳记上 22:14–18; 帖撒罗尼迦前书 2:15"> <span className="pl pl-1">义人向恶人低头，</span><br /><span className="pl pl-2">就像清泉被搅浑，</span><br /><span className="pl pl-2">水井受污染。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 5:44; 箴言 27:2; 腓立比书 2:3"> <span className="pl pl-1">蜂蜜吃得太多有害无益，</span><br /><span className="pl pl-2">追求自己的荣耀也不光彩。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 16:32; 箴言 22:24; 历代志下 32:5"> <span className="pl pl-1">无法自制的人就像墙垣被毁之城。</span></span>

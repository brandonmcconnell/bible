## 父亲的教诲

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 2:1; 诗篇 34:11; 箴言 1:8"> <span className="pl pl-1">孩子们啊，</span><br /><span className="pl pl-2">你们要听从父亲的教诲，</span><br /><span className="pl pl-2">留心学习，以便领悟，</span></span>

<span className="v" id="v3" data-v="3" data-xref="历代志上 22:5; 历代志上 29:1; 罗马书 12:16"> <span className="pl pl-1">我年幼时在父亲身边，</span><br /><span className="pl pl-2">是母亲唯一的宠儿。</span></span>

<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:10; 箴言 4:21–22; 以弗所书 3:17"> <span className="pl pl-1">不可离弃智慧，智慧必护佑你；</span><br /><span className="pl pl-2">你要热爱智慧，智慧必看顾你。</span></span>
<span className="v" id="v7" data-v="7" data-xref="传道书 7:12; 传道书 9:16–18; 箴言 23:23"> <span className="pl pl-1">智慧至上，要求取智慧，</span><br /><span className="pl pl-2">要不惜一切获取悟性。</span></span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 12:3; 撒母耳记上 2:30; 箴言 3:35"> <span className="pl pl-1">高举智慧，她必使你受尊崇；</span><br /><span className="pl pl-2">拥抱智慧，她必使你得尊荣。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 1:9; 彼得前书 5:4; 希伯来书 2:7–9"> <span className="pl pl-1">她必为你戴上华冠，</span><br /><span className="pl pl-2">加上荣冕。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:13; 箴言 3:2; 耶利米书 9:20"> <span className="pl pl-1">孩子啊，你要听从我的教导，</span><br /><span className="pl pl-2">就必延年益寿。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 25:4–5; 传道书 12:9; 箴言 8:9"> <span className="pl pl-1">我已经指示你走智慧之道，</span><br /><span className="pl pl-2">引导你行正确的路。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:23; 诗篇 18:36; 彼得前书 2:8"> <span className="pl pl-1">你行走，脚下不受阻碍；</span><br /><span className="pl pl-2">你奔跑，也不会跌倒。</span></span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:1; 箴言 3:18; 箴言 23:23"> <span className="pl pl-1">你要持守教诲，不要松懈；</span><br /><span className="pl pl-2">要守护好，因为那是你的生命。</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 1:1; 哥林多前书 15:33; 箴言 1:10"> <span className="pl pl-1">不要涉足恶人的道，</span><br /><span className="pl pl-2">不要行走坏人的路；</span></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:11; 约伯记 22:23; 帖撒罗尼迦前书 5:22"> <span className="pl pl-1">要避开，不可踏足，</span><br /><span className="pl pl-2">要绕道前行。</span></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 36:4; 弥迦书 2:1; 以赛亚书 57:20"> <span className="pl pl-1">因为他们不作恶就无法入睡，</span><br /><span className="pl pl-2">不绊倒人就无法安眠；</span></span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:4–5; 诗篇 14:4; 弥迦书 6:12"> <span className="pl pl-1">他们吃的是邪恶饼，</span><br /><span className="pl pl-2">喝的是残暴酒。</span></span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:12; 约伯记 11:17; 但以理书 12:3"> <span className="pl pl-1">义人的道路好像黎明的曙光，</span><br /><span className="pl pl-2">越照越亮，直到正午。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:35; 以赛亚书 59:9–10; 约伯记 18:5–6"> <span className="pl pl-1">恶人的道路一片幽暗，</span><br /><span className="pl pl-2">他们不知被何物绊倒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 5:1; 以赛亚书 55:3; 箴言 7:1"> <span className="pl pl-1">孩子啊，你要聆听我的吩咐，</span><br /><span className="pl pl-2">侧耳听我的训言；</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:21; 箴言 3:3; 箴言 7:1–2"> <span className="pl pl-1">不要让它们离开你的视线，</span><br /><span className="pl pl-2">要牢记在心。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:10; 箴言 12:18; 耶利米书 33:6"> <span className="pl pl-1">因为得到它们就得到生命，</span><br /><span className="pl pl-2">全身也必康健。</span></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:45; 马太福音 12:34–35; 马可福音 7:21–23"> <span className="pl pl-1">要一丝不苟地守护你的心，</span><br /><span className="pl pl-2">因为生命之泉从心中涌出。</span></span>

<span className="v" id="v27" data-v="27" data-xref="申命记 5:32; 约书亚记 1:7; 申命记 28:14"> <span className="pl pl-1">不可偏右偏左，</span><br /><span className="pl pl-2">要远离恶事。</span></span>

## 信靠耶和华

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; 约翰福音 14:21–24; 申命记 6:6–9"> <span className="pl pl-1">孩子啊，不要忘记我的训诲，</span><br /><span className="pl pl-2">要把我的诫命存在心里，</span></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:1–3; 箴言 4:10; 诗篇 91:16"> <span className="pl pl-1">因为这必使你延年益寿，</span><br /><span className="pl pl-2">幸福平安。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多后书 3:3; 希伯来书 10:16"> <span className="pl pl-1">不要让慈爱和信实离开你，</span><br /><span className="pl pl-2">要把它们系在你的颈项上，</span><br /><span className="pl pl-2">刻在你的心坎上。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 2:52; 撒母耳记上 2:26; 罗马书 14:18"> <span className="pl pl-1">这样，你必蒙上帝和世人的喜悦，</span><br /><span className="pl pl-2">享有美誉。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:5; 耶利米书 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要全心信靠耶和华，</span><br /><span className="pl pl-2">不可倚靠自己的悟性。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 诗篇 32:8; 腓立比书 4:6"> <span className="pl pl-1">凡事都要信从祂，</span><br /><span className="pl pl-2">祂必指引你走正路。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 罗马书 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以为有智慧，</span><br /><span className="pl pl-2">要敬畏耶和华，远离恶事。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 诗篇 147:3; 箴言 16:24"> <span className="pl pl-1">这样可医治你的身体，</span><br /><span className="pl pl-2">滋润你的筋骨。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命记 26:2–15; 哥林多前书 16:2; 出埃及记 23:19"> <span className="pl pl-1">你要用自己的财富和一切初熟的物产来尊崇耶和华，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命记 28:8; 箴言 22:9"> <span className="pl pl-1">祂必使你五谷满仓，</span><br /><span className="pl pl-2">榨酒池溢出新酿。</span></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 5:17; 启示录 3:19; 希伯来书 12:5–12"> <span className="pl pl-1">孩子啊，不可轻视耶和华的管教，</span><br /><span className="pl pl-2">也不可厌烦祂的责备。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 8:5; 启示录 3:19; 箴言 29:17"> <span className="pl pl-1">因为耶和华管教祂所爱的人，</span><br /><span className="pl pl-2">就像父亲管教他所疼爱的孩子。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 传道书 9:15–18"> <span className="pl pl-1">找到智慧、得到悟性的人有福了，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 约伯记 28:13–19"> <span className="pl pl-1">因为智慧比银子更有价值，</span><br /><span className="pl pl-2">比金子更有益处，</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 约伯记 28:18; 诗篇 73:25–26"> <span className="pl pl-1">比珠宝更珍贵；</span><br /><span className="pl pl-2">你所喜爱的一切都难以相比。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多后书 6:10; 箴言 22:4"> <span className="pl pl-1">智慧的右手有长寿，</span><br /><span className="pl pl-2">左手有富贵和尊荣。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以赛亚书 26:3; 腓立比书 4:8–9"> <span className="pl pl-1">她的路上有福乐，</span><br /><span className="pl pl-2">她的道上有平安。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 启示录 2:7; 箴言 15:4"> <span className="pl pl-1">对持守智慧的人来说，</span><br /><span className="pl pl-2">智慧是生命树，</span><br /><span className="pl pl-2">紧握智慧的人必蒙福。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:24; 耶利米书 10:12; 约翰福音 1:3"> <span className="pl pl-1">耶和华以智慧奠立大地，</span><br /><span className="pl pl-2">以悟性铺设诸天；</span></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 7:11; 诗篇 65:9–12; 约伯记 36:27–28"> <span className="pl pl-1">祂用知识使深渊裂开，</span><br /><span className="pl pl-2">使天上降下甘露。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:8; 申命记 6:6–9; 申命记 32:46–47"> <span className="pl pl-1">孩子啊，你要守护智慧和明辨力，</span><br /><span className="pl pl-2">别让她们离开你的视线。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以赛亚书 38:16"> <span className="pl pl-1">她们必给你带来生命，</span><br /><span className="pl pl-2">作你颈项上华美的装饰。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 诗篇 121:3"> <span className="pl pl-1">如此，你必步履稳健，不致失足；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 3:5; 诗篇 4:8; 箴言 6:22"> <span className="pl pl-1">你必安然躺卧，睡得香甜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10–14; 诗篇 112:7; 彼得前书 3:14"> <span className="pl pl-1">不要怕突来的灾祸，</span><br /><span className="pl pl-2">不要怕恶人遭毁灭，</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 91:3; 撒母耳记上 2:9; 箴言 14:26"> <span className="pl pl-1">因为耶和华是你的靠山，</span><br /><span className="pl pl-2">祂使你的脚不陷入网罗。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太书 6:10; 雅各书 2:15–16; 罗马书 13:7"> <span className="pl pl-1">倘若有力量行善，</span><br /><span className="pl pl-2">就当帮助有需要的人，不要推托。</span></span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:13; 申命记 24:12–15; 哥林多后书 8:11"> <span className="pl pl-1">倘若可以帮忙，</span><br /><span className="pl pl-2">就不可对有求于你的邻人说：</span><br /><span className="pl pl-2">“回去吧，明天再来，我必给你！”</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 诗篇 55:20"> <span className="pl pl-1">邻舍在你附近安分居住，</span><br /><span className="pl pl-2">不可谋害他。</span></span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 2:24; 箴言 29:22; 罗马书 12:18–21"> <span className="pl pl-1">别人若没有害你，</span><br /><span className="pl pl-2">不要无故与他相争。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 诗篇 37:1; 加拉太书 5:21"> <span className="pl pl-1">不要羡慕残暴之徒，</span><br /><span className="pl pl-2">也不可步其后尘，</span></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 25:14; 约翰福音 15:15; 箴言 11:20"> <span className="pl pl-1">因为耶和华憎恶邪僻之徒，</span><br /><span className="pl pl-2">喜爱正直的人。</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 37:22; 利未记 26:14–46; 约伯记 8:6–7"> <span className="pl pl-1">耶和华咒诅恶人的家，</span><br /><span className="pl pl-2">赐福义人的家。</span></span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:6; 彼得前书 5:5; 诗篇 138:6"> <span className="pl pl-1">耶和华讥笑好讥诮的人，</span><br /><span className="pl pl-2">恩待谦卑的人。</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 132:18; 以赛亚书 65:13–15; 诗篇 73:24"> <span className="pl pl-1">智者得尊荣，</span><br /><span className="pl pl-2">愚人受羞辱。</span></span>
</div>

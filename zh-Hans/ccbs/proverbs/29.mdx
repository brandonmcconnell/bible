<span className="v" id="v1" data-v="1" data-xref="箴言 6:15; 撒母耳记上 2:25; 箴言 1:24–31"> <span className="pl pl-1">屡教不改、顽固不化者，</span><br /><span className="pl pl-2">必突然灭亡，无可挽救。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 28:12; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">义人增多，民众欢腾；</span><br /><span className="pl pl-2">恶人得势，民众叹息。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 27:11; 箴言 10:1; 箴言 15:20"> <span className="pl pl-1">爱慕智慧的使父亲欢欣，</span><br /><span className="pl pl-2">结交妓女的必耗尽钱财。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 29:14; 箴言 20:8; 但以理书 11:20"> <span className="pl pl-1">君王秉公行义，国家安定；</span><br /><span className="pl pl-2">他若收受贿赂，国必倾倒。</span></span>
<span className="v" id="v5" data-v="5" data-xref="何西阿书 5:1; 约伯记 17:5; 诗篇 5:9"> <span className="pl pl-1">奉承邻舍，等于设网罗绊他。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="传道书 9:12; 出埃及记 15:1; 提摩太后书 2:26"> <span className="pl pl-1">恶人被自己的罪缠住，</span><br /><span className="pl pl-2">义人却常常欢喜歌唱。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 29:16; 诗篇 41:1; 箴言 21:13"> <span className="pl pl-1">义人关心穷人的冤屈，</span><br /><span className="pl pl-2">恶人对此漠不关心。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 11:11; 耶利米书 15:1; 雅各书 5:15–18"> <span className="pl pl-1">狂徒煽动全城，</span><br /><span className="pl pl-2">智者平息众怒。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 26:4; 传道书 10:13; 马太福音 7:6"> <span className="pl pl-1">智者跟愚人对簿公堂，</span><br /><span className="pl pl-2">愚人会怒骂嬉笑不止。</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:18–19; 约翰一书 3:12–13; 创世记 4:5–8"> <span className="pl pl-1">嗜杀之徒憎恶纯全无过的人，</span><br /><span className="pl pl-2">但正直的人保护他们</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“但正直的人保护他们”或译“索取正直人的性命”。">a</a></sup><br /><span className="pl pl-2">。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:11; 箴言 12:16; 弥迦书 7:5"> <span className="pl pl-1">愚人尽情发泄怒气，</span><br /><span className="pl pl-2">智者默然克制怒气。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 20:8; 列王纪下 10:6–7; 诗篇 52:2–4"> <span className="pl pl-1">君王若听谗言，</span><br /><span className="pl pl-2">臣仆必成奸徒。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:45; 箴言 22:2; 诗篇 13:3"> <span className="pl pl-1">贫穷人和欺压者有共同点：</span><br /><span className="pl pl-2">他们的眼睛都是耶和华所赐。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:12; 以赛亚书 11:4; 诗篇 72:2–4"> <span className="pl pl-1">君王若秉公审判穷人，</span><br /><span className="pl pl-2">他的王位必永远坚立。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 10:1; 箴言 17:25; 箴言 29:17"> <span className="pl pl-1">管教之杖使孩子得智慧，</span><br /><span className="pl pl-2">放纵的子女让母亲蒙羞。</span></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:36; 诗篇 91:8; 诗篇 58:10"> <span className="pl pl-1">恶人当道，罪恶泛滥；</span><br /><span className="pl pl-2">义人必得见他们败亡。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:1; 箴言 29:15; 箴言 23:13–14"> <span className="pl pl-1">好好管教儿子，</span><br /><span className="pl pl-2">他会带给你平安，使你心里喜乐。</span></span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:25; 路加福音 11:28; 约翰福音 13:17"> <span className="pl pl-1">百姓无神谕便任意妄为，</span><br /><span className="pl pl-2">但遵守律法的人必蒙福。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 26:3; 约伯记 19:16; 箴言 30:22"> <span className="pl pl-1">管教仆人不能单靠言语，</span><br /><span className="pl pl-2">因为他虽明白却不理会。</span></span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 1:19; 箴言 26:12; 箴言 14:29"> <span className="pl pl-1">言语急躁的人，</span><br /><span className="pl pl-2">还不如愚人有希望。</span></span>
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">从小娇纵的仆人，</span><br /><span className="pl pl-2">最终必反仆为主。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 15:18; 箴言 17:19; 箴言 26:21"> <span className="pl pl-1">愤怒的人挑起纷争，</span><br /><span className="pl pl-2">暴躁的人多有过犯。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 23:12; 路加福音 14:11; 箴言 11:2"> <span className="pl pl-1">骄傲的人必遭贬抑，</span><br /><span className="pl pl-2">谦卑的人必得尊荣。</span></span>
<span className="v" id="v24" data-v="24" data-xref="利未记 5:1; 箴言 1:11–19; 箴言 8:36"> <span className="pl pl-1">与盗贼为伍是憎恶自己，</span><br /><span className="pl pl-2">他即使发誓也不敢作证。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 118:8; 路加福音 12:4; 箴言 18:10"> <span className="pl pl-1">惧怕人的必自陷网罗，</span><br /><span className="pl pl-2">信靠耶和华的必安稳。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 19:6; 箴言 19:21; 诗篇 20:9"> <span className="pl pl-1">许多人讨君王的欢心，</span><br /><span className="pl pl-2">但正义伸张靠耶和华。</span></span>

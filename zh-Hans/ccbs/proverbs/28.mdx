<span className="v" id="v5" data-v="5" data-xref="诗篇 92:6; 雅各书 1:5; 约翰一书 2:27"> <span className="pl pl-1">邪恶之人不明白公义，</span><br /><span className="pl pl-2">寻求耶和华的全然明白。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; 路加福音 16:19–23"> <span className="pl pl-1">行为正直的穷人，</span><br /><span className="pl pl-2">胜过行事邪僻的富人。</span></span>

<span className="v" id="v8" data-v="8" data-xref="约伯记 27:16–17; 箴言 13:22; 传道书 2:26"> <span className="pl pl-1">人放高利贷牟利，</span><br /><span className="pl pl-2">是为济贫者积财。</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 66:18; 提摩太后书 4:3–4; 撒迦利亚书 7:11–13"> <span className="pl pl-1">人若不听从律法，</span><br /><span className="pl pl-2">他的祷告也可憎。</span></span>

<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 传道书 9:15–17; 箴言 26:16"> <span className="pl pl-1">富人自以为有智慧，</span><br /><span className="pl pl-2">却被明智的穷人看透。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">义人得胜，众民欢腾；</span><br /><span className="pl pl-2">恶人当道，人人躲藏。</span></span>

<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 诗篇 2:11; 以赛亚书 66:2"> <span className="pl pl-1">常敬畏主的必蒙福，</span><br /><span className="pl pl-2">心里刚硬的必遭祸。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 2:16; 箴言 19:12"> <span className="pl pl-1">暴虐的君王辖制穷人，</span><br /><span className="pl pl-2">如咆哮的狮、觅食的熊。</span></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:21; 耶利米书 22:15–17; 传道书 4:1"> <span className="pl pl-1">昏庸的君王残暴不仁，</span><br /><span className="pl pl-2">恨不义之财的享长寿。</span></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 9:6; 列王纪上 21:19; 出埃及记 21:14"> <span className="pl pl-1">背负血债者必终生逃亡，</span><br /><span className="pl pl-2">谁也不要帮他。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; 启示录 3:3"> <span className="pl pl-1">纯全无过的必蒙拯救，</span><br /><span className="pl pl-2">行为邪僻的转眼覆灭。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士师记 9:4; 箴言 27:23–27"> <span className="pl pl-1">勤奋耕耘，丰衣足食；</span><br /><span className="pl pl-2">追求虚荣，穷困潦倒。</span></span>

<span className="v" id="v23" data-v="23" data-xref="箴言 27:5–6; 马太福音 18:15; 诗篇 141:5"> <span className="pl pl-1">责备人的至终比谄媚者更受爱戴。</span><br /></span>

## 利慕伊勒王的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 6:20; 箴言 1:8; 提摩太后书 1:5"> 以下是利慕伊勒王的箴言，<br /><span className="pl pl-1">是他母亲给他的教诲：</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 49:15; 撒母耳记上 1:11; 撒母耳记上 1:28"> <span className="pl pl-1">我儿，我亲生的骨肉，</span><br /><span className="pl pl-2">我许愿得来的孩子啊，</span><br /><span className="pl pl-2">我该怎样教导你呢？</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命记 17:17; 尼希米记 13:26; 箴言 7:26–27"> <span className="pl pl-1">不要在女人身上耗费精力，</span><br /><span className="pl pl-2">不要迷恋那些能毁灭王的人。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 20:1; 传道书 10:17; 以赛亚书 5:22"> <span className="pl pl-1">利慕伊勒啊，</span><br /><span className="pl pl-2">君王不可喝酒，</span><br /><span className="pl pl-2">不可喝酒，</span><br /><span className="pl pl-2">首领不宜喝烈酒，</span></span>
<span className="v" id="v5" data-v="5" data-xref="哈巴谷书 2:5"> <span className="pl pl-1">免得喝酒后忘记律例，</span><br /><span className="pl pl-2">不为困苦人伸张正义。</span></span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:23; 诗篇 104:15; 撒母耳记上 1:10"> <span className="pl pl-1">把烈酒给行将灭亡的人，</span><br /><span className="pl pl-2">把淡酒给心中忧伤的人，</span></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:18"> <span className="pl pl-1">让他们喝了忘掉自己的贫穷，</span><br /><span className="pl pl-2">不再记得自己的痛苦。</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 82:3–4; 箴言 24:11–12; 以斯帖记 4:13–16"> <span className="pl pl-1">要为不能自辩者说话，</span><br /><span className="pl pl-2">为一切不幸的人申冤。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 1:17; 利未记 19:15; 阿摩司书 5:11–12"> <span className="pl pl-1">你要开口秉公审判，</span><br /><span className="pl pl-2">为贫穷困苦者辩护。</span></span>
</div>
</div>

## 贤德的妻子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="箴言 19:14; 箴言 12:4; 箴言 18:22"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="10-30节是字母诗，每一节依次由一个希伯来字母开头。">a</a></sup><span className="pl pl-1">谁能找到贤德之妻？</span><br /><span className="pl pl-2">她的价值远胜过珠宝。</span></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 3:1–7; 列王纪下 4:22–23; 列王纪下 4:9–10"> <span className="pl pl-1">她丈夫信赖她，</span><br /><span className="pl pl-2">什么也不缺乏。</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 25:18–22; 撒母耳记上 25:26–27"> <span className="pl pl-1">她一生对丈夫有益无损。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提多书 2:5; 提摩太前书 5:10; 帖撒罗尼迦后书 3:10–12"> <span className="pl pl-1">她寻找羊毛和细麻，</span><br /><span className="pl pl-2">愉快地亲手做衣。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 31:24; 列王纪上 9:26–28; 以西结书 27:3–36"> <span className="pl pl-1">她好像商船，</span><br /><span className="pl pl-2">从远方运来粮食。</span></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:11; 马可福音 1:35; 路加福音 12:42"> <span className="pl pl-1">天未亮她就起床，</span><br /><span className="pl pl-2">为全家预备食物，</span><br /><span className="pl pl-2">分派婢女做家事。</span></span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 13:44; 雅歌 8:12; 约书亚记 15:18"> <span className="pl pl-1">她选中田地便买下来，</span><br /><span className="pl pl-2">亲手赚钱栽种葡萄园。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 38:3; 彼得前书 1:13; 以弗所书 6:10"> <span className="pl pl-1">她精力充沛，</span><br /><span className="pl pl-2">双臂有力。</span></span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 2:9; 马太福音 25:3–10; 诗篇 127:2"> <span className="pl pl-1">她深谙经营之道，</span><br /><span className="pl pl-2">她的灯彻夜不熄。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 35:25–26"> <span className="pl pl-1">她手拿卷线杆，</span><br /><span className="pl pl-2">手握纺线锤。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 4:28; 希伯来书 13:16; 箴言 22:9"> <span className="pl pl-1">她乐于周济穷人，</span><br /><span className="pl pl-2">伸手帮助困苦者。</span></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 45:22; 撒母耳记下 1:24; 箴言 25:20"> <span className="pl pl-1">她不因下雪而为家人担心，</span><br /><span className="pl pl-2">因为全家都穿着朱红暖衣。</span></span>
<span className="v" id="v22" data-v="22" data-xref="启示录 19:8; 箴言 7:16; 创世记 41:42"> <span className="pl pl-1">她为自己缝制绣花毯，</span><br /><span className="pl pl-2">用细麻和紫布做衣服。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 12:4; 路得记 4:1; 申命记 16:18"> <span className="pl pl-1">她丈夫在城门口与当地长老同坐，</span><br /><span className="pl pl-2">受人尊重。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 27:16; 路加福音 16:19; 箴言 31:19"> <span className="pl pl-1">她缝制细麻衣裳出售，</span><br /><span className="pl pl-2">又制作腰带卖给商人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 40:10; 罗马书 13:14; 约伯记 29:14"> <span className="pl pl-1">她充满力量和尊荣，</span><br /><span className="pl pl-2">她以笑颜迎接未来。</span></span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; 箴言 16:24; 箴言 10:31"> <span className="pl pl-1">她说的话带着智慧，</span><br /><span className="pl pl-2">她的训言充满慈爱。</span></span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前书 5:10; 提多书 2:4; 帖撒罗尼迦后书 3:6"> <span className="pl pl-1">她料理一切家务，</span><br /><span className="pl pl-2">从不偷懒吃闲饭。</span></span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 3:15–17; 提摩太后书 1:5; 列王纪上 2:19"> <span className="pl pl-1">她的儿女肃立，</span><br /><span className="pl pl-2">为她祝福，</span><br /><span className="pl pl-2">她的丈夫也称赞她，</span></span>
<span className="v" id="v29" data-v="29" data-xref="雅歌 6:8–9; 以弗所书 5:27"> <span className="pl pl-1">说：“世上贤德的女子很多，</span><br /><span className="pl pl-2">唯有你无与伦比。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 1:7; 彼得前书 3:4–5; 箴言 11:22"> <span className="pl pl-1">艳丽是虚假的，</span><br /><span className="pl pl-2">美貌是短暂的，</span><br /><span className="pl pl-2">唯有敬畏耶和华的女子配得称赞。</span></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 128:2; 希伯来书 6:10; 马太福音 7:16"> <span className="pl pl-1">愿她享受自己的劳动成果，</span><br /><span className="pl pl-2">愿她的事迹使她在城门口受称赞。</span></span>
</div>

## 预备守逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 5:7–8; 历代志下 11:13; 何西阿书 5:4"> 希西迦派人通告以色列和犹大全境，又写信通知以法莲人和玛拿西人，叫他们到耶路撒冷耶和华的殿，向以色列的上帝耶和华守逾越节。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:10–11; 历代志上 13:1–3; 历代志下 30:13"> 王、众官员及耶路撒冷的全体会众决定在二月守逾越节。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 29:34; 出埃及记 12:6; 出埃及记 12:18"> 他们不能在一月守节期，因为洁净自己的祭司不够多，民众也没有聚集在耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:4"> 王与全体会众都很赞成这个计划。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 20:1; 利未记 23:2; 以斯帖记 8:8–10"> 于是，他们下令通告全以色列，从别示巴直到但，让人们到耶路撒冷向以色列的上帝耶和华守逾越节，因为人们不常照律例守这节期。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:31; 以斯帖记 8:14; 列王纪下 15:19"> 信差遵照王的命令，带着王和众官员的信走遍以色列和犹大，宣告说：“以色列人啊，你们应当归向亚伯拉罕、以撒和以色列的上帝耶和华，好使祂转向你们这些从亚述王手中逃脱的余民。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 29:8; 以西结书 20:13–18; 撒迦利亚书 1:3–4"> 不要效法你们的祖先和亲族，他们对他们祖先的上帝耶和华不忠，所以耶和华使他们的下场令人惊骇，正如你们所见的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 32:9; 历代志下 29:10; 申命记 10:16"> 现在，不要像你们的祖先那样顽固不化；要顺服耶和华，进入祂永远圣洁的圣所，事奉你们的上帝耶和华，好使祂的烈怒转离你们。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 55:7; 弥迦书 7:18; 诗篇 86:5"> 你们若归向祂，你们的弟兄和儿女必蒙掳走他们之人的怜悯，得以回归此地，因为你们的上帝耶和华有恩典，好怜悯。你们若归向祂，祂必不会转脸不顾你们。”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:16; 历代志下 30:6; 尼希米记 2:19"> 信差将这通告逐城传遍以法莲和玛拿西，直到西布伦，可是那些地方的人却嘲笑、戏弄他们。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:18; 历代志下 30:21; 历代志下 30:25"> 然而，有些亚设人、玛拿西人和西布伦人谦卑悔改，来到耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:39; 耶利米书 24:7; 腓立比书 2:13"> 耶和华上帝感动犹大人，使他们一心遵从王与众官员奉祂的指示所下的命令。</span>
</div>
</div>

## 守逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:2; 诗篇 84:7"> 二月，大群的人聚到耶路撒冷守除酵节。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:24; 撒母耳记下 15:23; 历代志下 15:16"> 他们除去耶路撒冷的祭坛和所有香坛，把它们扔进汲沦溪。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 29:34; 历代志下 5:11; 出埃及记 19:22"> 二月十四日，他们宰了逾越节的羔羊。祭司和利未人觉得惭愧，就洁净自己，把燔祭带到耶和华的殿里，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 33:1; 历代志下 35:15; 列王纪下 11:14"> 然后照上帝的仆人摩西的律法照常供职。祭司从利未人手中接过血，洒在坛上。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 29:34; 历代志下 35:3–6; 出埃及记 12:6"> 因为会众中间有许多人没有洁净自己，利未人就为所有不洁之人宰逾越节的羔羊献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 11:28; 雅各书 5:15–16; 但以理书 9:19"> 有许多以法莲人、玛拿西人、以萨迦人和西布伦人，没有洁净自己就吃了逾越节的羊羔，违背了律法的规定。希西迦就为他们祷告说：“凡诚心寻求他祖先的上帝耶和华的人，虽然没有照圣所的律例洁净自己，愿良善的耶和华赦免他！”</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 15:26; 雅各书 5:15–16; 诗篇 103:3"> 耶和华垂听希西迦的祷告，就赦免<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“赦免”希伯来文是“医治”。">a</a></sup>了他们。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:15; 出埃及记 13:6; 申命记 12:12"> 在耶路撒冷的以色列人非常喜乐地守除酵节七天。利未人和祭司用响亮的乐器天天颂赞耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:6; 尼希米记 9:3; 以赛亚书 40:1–2"> 希西迦慰劳所有善于事奉耶和华的利未人。于是，众人欢宴过节七天，又献上平安祭，称谢他们祖先的上帝耶和华。</span>
</div>
</div>

## 再次守节期

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 8:65; 历代志下 7:9"> 全体会众商议要再守节期七天，于是众人又欢欢喜喜地守节期七天。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:34; 历代志下 35:7–8; 以弗所书 4:8"> 犹大王希西迦送给会众一千头公牛和七千只羊，众官员也送给会众一千头公牛和一万只羊，并且很多祭司都已洁净自己。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 30:11; 历代志下 30:18; 历代志上 16:10–11"> 犹大全体会众、祭司、利未人和从以色列来的全体会众，以及寄居在以色列和犹大的人尽都欢喜。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 7:8–10"> 全耶路撒冷都喜气洋洋，因为自以色列王大卫的儿子所罗门时代以来，耶路撒冷从未有过这样的盛会。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 26:15; 诗篇 68:5; 民数记 6:23–26"> 利未祭司起来为民众祝福，他们的祷告得蒙垂听，达到天上的圣所。</span>
</div>

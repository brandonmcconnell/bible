## 犹大王约阿施

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:11; 列王纪下 11:21–15"> 约阿施七岁登基，在耶路撒冷执政四十年。他母亲叫西比亚，是别示巴人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 26:4–5; 历代志下 25:2; 历代志下 24:17–22"> 耶何耶大祭司在世之日，约阿施做耶和华视为正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 24:15; 马太福音 19:4–8; 创世记 4:19"> 耶何耶大为他娶了两个妻子，她们都为他生儿育女。</span>
<span className="v" id="v4" data-v="4"> 之后，约阿施决定整修耶和华的殿，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 12:4–7; 历代志下 34:8–9; 历代志下 29:3"> 便召集祭司和利未人，对他们说：“你们到犹大各城去向所有以色列人征收银子，用来作每年整修你们上帝殿的费用。你们要立刻办理这事。”可是，利未人没有立刻办理。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 30:12–16; 民数记 1:50; 民数记 17:7–8"> 王就召来耶何耶大大祭司，问他：“你为什么不吩咐利未人到耶路撒冷和犹大去收税呢？这税是耶和华的仆人摩西和以色列的会众定的，以备圣幕之用。”</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 21:17; 历代志下 28:22–24; 列王纪下 12:4"> 因为恶妇亚她利雅的爪牙曾闯入耶和华上帝的殿，拿殿里的圣物去供奉巴力。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 12:41; 列王纪下 12:8–9"> 于是，王下令造一个箱子，放在耶和华殿的门外，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 24:6; 马太福音 17:24–27"> 通告犹大和耶路撒冷的人民，要将上帝的仆人摩西在旷野为以色列人定的税带来献给耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:45–47; 哥林多后书 9:7; 历代志上 29:9"> 全体首领和民众都高高兴兴地把银子带来投进箱子里，直到箱子满了。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 12:10–12; 哥林多前书 16:2"> 利未人见银子满了，就抬到王的官员那里。王的书记和大祭司的属下会把箱子倒空，然后把箱子放回原处。日复一日，他们收了很多银子。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 5:15; 历代志下 34:9–11"> 王与耶何耶大把银子交给耶和华殿里的办事人员，他们就雇用石匠、木匠、铁匠和铜匠来整修耶和华的殿。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:7; 马可福音 13:1–2; 哈该书 2:3"> 工人辛勤整修，工程进展顺利，上帝的殿恢复了原貌，而且非常坚固。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 28:2–29; 箴言 27:22; 列王纪下 12:13–14"> 完工后，他们把剩余的银子交给王与耶何耶大，这些银子被用来制造耶和华殿里的器具：供奉和献祭用的器皿、碟子和其他金银器皿。耶何耶大在世之日，民众常在耶和华的殿里献燔祭。</span>
</div>
</div>

## 耶何耶大的政策被废弃

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 47:9; 历代志上 23:1; 诗篇 90:10"> 耶何耶大寿终正寝，享年一百三十岁。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:10; 历代志下 31:20; 尼希米记 13:14"> 民众把他葬在大卫城的王陵里，因为他在以色列为上帝和上帝的殿做了善事。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 31:27; 箴言 26:28; 使徒行传 20:29–30"> 耶何耶大死后，犹大众首领来朝拜王，王对他们言听计从。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 22:20; 历代志下 19:2; 以弗所书 5:6"> 他们离弃他们祖先的上帝耶和华的殿，去供奉亚舍拉神像及其他偶像。因他们所犯的罪，上帝的烈怒临到犹大和耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 42:23; 路加福音 20:9–15; 马太福音 13:9"> 但耶和华仍然派先知到他们中间，引导他们归向祂。先知警告他们，他们却不听。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 14:41; 耶利米书 5:25; 历代志下 15:1–2"> 上帝的灵感动了耶何耶大祭司的儿子撒迦利亚，他便站在高处对民众说：“上帝说，‘你们为什么违反耶和华的诫命，以致不得亨通呢？既然你们背弃我，我也必离弃你们。’”</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 7:58–59; 尼希米记 9:26; 耶利米书 38:4–6"> 他们谋害撒迦利亚，就照王的命令，在耶和华殿的院子里用石头打死了他。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 9:5; 路加福音 11:51; 启示录 6:9–11"> 约阿施王不但不顾念撒迦利亚的父亲耶何耶大对他的恩惠，还杀死了耶何耶大的儿子。撒迦利亚临死的时候说：“愿耶和华鉴察，为我申冤！”</span>
</div>
</div>

## 约阿施被杀

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:17–18; 申命记 32:35; 列王纪上 20:22"> 当年年底，亚兰的军兵前来攻击约阿施，入侵犹大和耶路撒冷，杀了民众的所有首领，把战利品全都送到大马士革王那里。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 22:8; 利未记 26:37; 利未记 26:8"> 虽然亚兰军只来了一小队，但耶和华把大队的犹大军兵交在他们手中，以惩罚约阿施，因为犹大人背弃了他们祖先的上帝耶和华。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 24:21–22; 历代志下 28:27; 历代志下 21:18–20"> 亚兰人退兵的时候，约阿施受了重伤，他的臣仆叛变，把他杀死在床上，为耶何耶大祭司的儿子报了血仇。约阿施死后葬在大卫城，但没有葬在王陵里。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 12:21"> 背叛他的是亚扪妇人示米押的儿子撒拔和摩押妇人示米利的儿子约萨拔。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 16:11; 历代志下 13:22; 历代志下 24:12"> 至于约阿施的众子、他所受的警告和他整修上帝殿的事，都记在列王史上。他儿子亚玛谢继位。</span>
</div>
</div>

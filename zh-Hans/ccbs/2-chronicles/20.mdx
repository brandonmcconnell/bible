## 约沙法祷告退敌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 83:5–8; 以赛亚书 16:6; 历代志下 32:1"> 后来摩押人、亚扪人同一些米乌尼人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“米乌尼人”出现在古希腊译本，但希伯来文是“亚扪人”。">a</a></sup>一起来攻打约沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 14:7; 撒母耳记上 23:29; 约书亚记 15:62"> 有人禀告约沙法说：“有一支大军从死海对岸的以东<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“以东”希伯来文是“亚兰”。">b</a></sup>杀来，已经攻到哈洗逊·他玛。”哈洗逊·他玛就是隐·基底。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 9:3; 历代志下 19:3; 撒母耳记上 7:6"> 约沙法很害怕，决定寻求耶和华，在整个犹大宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 50:15; 诗篇 60:10–12; 诗篇 69:35"> 犹大人聚集起来寻求耶和华。他们从犹大各城前来寻求耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:15–19; 历代志下 6:12–13; 历代志下 34:31"> 约沙法站在耶和华殿的新院前，在犹大和耶路撒冷的会众中，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 4:39; 历代志上 29:11–12; 但以理书 4:17"> 说：“我们祖先的上帝耶和华啊，你不是住在天上的上帝吗？你主宰万邦万国，你手中有权柄和能力，无人能抵挡你。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 41:8; 雅各书 2:23; 诗篇 44:2"> 我们的上帝啊，你不是曾经在你的以色列子民面前驱逐这地方的居民，把这片土地赐给你的朋友亚伯拉罕的后裔永远作产业吗？</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 6:10; 历代志下 2:4"> 你的子民在这里居住，为你的名建造圣所，说，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 6:28–30; 历代志下 6:20; 列王纪上 8:33"> ‘我们若遭遇祸患，无论是战祸、瘟疫或饥荒，在急难中站在这殿前向你呼求，你必定垂听，施行拯救，因为你的名在这殿里。’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 2:19; 申命记 2:4–5; 申命记 2:9"> “从前以色列人离开埃及的时候，你不准他们侵犯亚扪人、摩押人和来自西珥山的人，他们就绕道行进，没有毁灭这些人。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 83:3–12; 士师记 11:23–24; 耶利米书 18:20"> 但现在这些人竟以怨报德，要把我们从你赐给我们作产业的地方赶走。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 121:1–2; 诗篇 25:15; 诗篇 141:8"> 我们的上帝啊，难道你不惩罚他们吗？面对前来攻击的大军，我们无力抵挡，不知道该怎么办，我们只有仰望你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:1; 使徒行传 21:5; 申命记 29:10"> 犹大人都与他们的妻子、儿女和婴孩站在耶和华面前。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 15:1; 历代志下 24:20; 使徒行传 10:31"> 这时，耶和华的灵降在雅哈悉身上。雅哈悉是利未人亚萨的后裔、玛探雅的玄孙、耶利的曾孙、比拿雅的孙子、撒迦利雅的儿子。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 32:7–8; 申命记 31:6; 出埃及记 14:13–14"> 他说：“全体犹大人、耶路撒冷的居民和约沙法王啊，你们要留心听！耶和华对你们说，‘你们不要因敌军强大而恐惧惊慌，因为战争的胜败不在于你们，而在于上帝。</span>
<span className="v" id="v16" data-v="16"> 明天你们下去迎敌，敌军会从洗斯坡上来，你们一定会在耶鲁伊勒旷野前面的谷口遇见他们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:13–14; 历代志下 15:2; 以赛亚书 41:10"> 你们不用与他们交战，只要守住阵势，站立不动，看耶和华为你们施行拯救。犹大人和耶路撒冷人啊，不要恐惧，不要惊慌，明天只管出去迎敌，耶和华必与你们同在！’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 4:31; 历代志下 7:3; 创世记 24:26"> 于是，约沙法面伏于地，所有犹大人和耶路撒冷的居民也都俯伏在耶和华面前敬拜祂。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 15:16–22; 历代志上 16:42; 历代志上 16:5"> 哥辖族和可拉族的利未人都站起来，高声赞美以色列的上帝耶和华。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:31; 约翰福音 14:1; 约翰福音 11:40"> 第二天清晨，众人起来去提哥亚的旷野。他们出发的时候，约沙法站着说：“犹大人和耶路撒冷的居民啊，请听我说！要信靠你们的上帝耶和华，你们就必坚立；要相信祂的先知，你们就必得胜。”</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:1; 诗篇 106:1; 历代志下 5:13"> 约沙法与众人商议后，就派歌乐手穿上圣洁的礼服走在军队前面，赞美耶和华，说：“你们要称谢耶和华，因祂的慈爱永远长存！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 14:20; 以赛亚书 19:2; 以西结书 38:21"> 他们开始唱歌赞美的时候，耶和华就派伏兵击杀前来攻打犹大的亚扪人、摩押人和来自西珥山的人，打败了他们。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 7:22; 撒母耳记上 14:20; 以西结书 35:2–3"> 原来亚扪人和摩押人攻击来自西珥山的人，消灭了他们，然后亚扪人和摩押人又自相残杀。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 37:36; 诗篇 110:6; 历代志上 5:22"> 犹大人来到旷野的瞭望塔俯瞰那支大军，发现敌军尸横遍野，无一逃脱。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 30:19–20; 列王纪下 7:9–16; 民数记 31:15"> 约沙法和他的百姓前去拾财物，发现尸体中有许多财物、衣服和贵重物品，多得拿不完。他们拾了三天才拾完。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:15; 创世记 32:20; 历代志下 5:9"> 第四天，他们聚集到一个山谷，一起称颂耶和华。那里从此名叫比拉迦<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“比拉迦”就是称赞的意思。">c</a></sup>谷，直到今天。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="尼希米记 12:43; 希伯来书 6:20; 诗篇 30:1"> 犹大人和耶路撒冷人在约沙法的带领下，欢欢喜喜地返回耶路撒冷，因为耶和华使他们战胜了仇敌。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 14:2–3; 诗篇 57:8; 诗篇 92:3"> 他们一路弹琴、鼓瑟、吹号回到耶路撒冷，进入耶和华的殿。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 17:10; 列王纪下 7:6; 出埃及记 23:27"> 列邦列国听闻耶和华打败了以色列的敌人，都很惧怕。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 15:15; 历代志下 14:6–7; 撒母耳记下 7:1"> 因此，约沙法执政期间国家太平，因为他的上帝赐他四境平安。</span>
</div>
</div>

## 约沙法逝世

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 22:41–44"> 约沙法三十五岁登基做犹大王，在耶路撒冷执政二十五年。他母亲叫阿苏巴，是示利希的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 14:2–5; 列王纪上 15:11; 历代志下 14:11–13"> 约沙法事事效法他父亲亚撒，不偏不离，做耶和华视为正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 17:6; 历代志下 19:3; 历代志下 12:14"> 但他没有拆除丘坛，民众还没有全心归向他们祖先的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:1; 历代志下 19:2; 列王纪上 16:7"> 约沙法其他的事迹自始至终都记在哈拿尼的儿子耶户的史记上。耶户的史记收录在《以色列列王史》上。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:48–49; 列王纪下 1:2–16"> 后来，犹大王约沙法与作恶多端的以色列王亚哈谢联盟。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 10:22; 历代志下 9:21; 列王纪上 9:26"> 他们在以旬·迦别造船，要去他施。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 历代志下 19:2; 历代志下 9:21"> 玛利沙人多大瓦的儿子以利以谢向约沙法预言说：“因为你与亚哈谢联盟，耶和华必破坏你所造的船只。”那些船只果然坏了，无法前往他施。</span>
</div>
</div>

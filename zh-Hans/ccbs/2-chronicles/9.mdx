## 示巴女王拜访所罗门

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 列王纪上 10:1–13"> 示巴女王听闻所罗门的名声，便来用难题考问他。她率领许多随从，用骆驼驮着香料、宝石和大量黄金，到耶路撒冷晋见所罗门，与所罗门谈论她心中的疑问。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:15; 列王纪上 3:12; 马可福音 4:34"> 所罗门解答了她所有的问题，没有一样难得住他。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 3:1–4; 列王纪上 10:3; 列王纪上 6:1–7"> 示巴女王看见所罗门智慧非凡，又看见他建的宫殿、</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 12:37; 列王纪上 4:22–23; 诗篇 143:7"> 席上的美味、入座的群臣、侍立的仆人、酒侍、他们的服装，以及他在耶和华殿里献的燔祭，感到万分惊奇。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 10:6"> 她对王说：“我在本国听到的有关你的功业和智慧原来都是真的。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 10:7; 历代志下 9:5; 列王纪上 4:34"> 若不是亲眼目睹，我不会相信。其实我听到的还不到一半！你的智慧远超过我听到的传闻。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:4; 箴言 3:14; 箴言 10:21"> 你的百姓真有福气！你的臣仆经常侍立在你面前聆听智言慧语，真有福气！</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 2:11; 历代志上 29:23; 以赛亚书 32:1–2"> 你的上帝耶和华当受称颂！祂喜爱你，立你坐在祂的宝座上替祂掌权。因为你的上帝爱以色列人，要使他们永远坚立，所以立你为他们的王，使你秉公行义。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 9:1; 诗篇 72:10; 诗篇 72:15"> 示巴女王将八万两黄金、大量香料和宝石献给所罗门王。再无人像示巴女王那样献给所罗门王那么多香料。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 8:18; 列王纪上 10:11; 列王纪上 10:22"> 希兰的仆人和所罗门的仆人从俄斐运来黄金、檀香木和宝石。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 10:12; 历代志上 23:5; 诗篇 92:1–3"> 所罗门王用这些檀香木建造耶和华的殿和王宫的阶梯，又为歌乐手制作琴瑟。在犹大从来没有见过这样的物品。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 10:13; 以弗所书 3:20; 诗篇 20:4"> 所罗门王满足了示巴女王的一切要求，回赠她的礼物超过了她带来的。之后，女王和随从就回示巴去了。</span>
</div>
</div>

## 所罗门王的财富

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 72:15; 诗篇 68:29; 列王纪上 10:14–28"> 所罗门每年收到的黄金约四十五万两，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 68:29; 诗篇 72:10"> 此外还有商人、阿拉伯诸王和国中各总督送给他的金银。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 10:16–17; 历代志下 12:9–10"> 所罗门王用锤好的金子打造了二百面大盾牌，每面用一百四十两金子；</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:2"> 又用锤好的金子打造了三百面小盾牌，每面用七十两金子，全部放在黎巴嫩林宫。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 10:18–20; 诗篇 45:8; 启示录 20:11"> 王又造了一个象牙大宝座，外面用纯金包裹。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 24:9; 启示录 5:5; 民数记 23:24"> 这宝座有六级台阶，又有金脚凳与宝座相连，宝座两旁有扶手，扶手两边各站着一头狮子，</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 19:28; 启示录 21:12"> 六级台阶上共站着十二头狮子，每级台阶两端各站一头。这宝座举世无双。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 10:21; 以斯帖记 1:7; 历代志下 9:27"> 所罗门王所有的杯子都是金的，黎巴嫩林宫里所有的器皿都是纯金的，没有一件是用银子造的，因为所罗门年间银子不算什么。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 22:48; 约伯记 39:13; 列王纪上 10:22"> 王有船队与希兰的仆人一起出海去他施，每三年就运回金银、象牙、猿猴和孔雀。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 1:12; 诗篇 89:27; 列王纪上 4:30–31"> 所罗门王的财富和智慧超过天下诸王。</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:5; 雅各书 3:17; 箴言 2:6"> 天下的君王都纷纷来朝见所罗门，聆听上帝赐给他的智言慧语。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 10:25; 约伯记 42:11; 诗篇 72:10"> 他们年年都带来礼物，有金银器皿、衣服、兵器、香料和骡马。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 4:26; 列王纪上 10:26; 历代志下 1:14"> 所罗门有四千个安置战车和马匹的棚，有一万二千名骑兵，驻扎在屯车城和他所在的耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 4:21; 创世记 15:18; 列王纪上 4:24"> 所罗门统管从幼发拉底河到非利士地区，远至埃及边境的诸王。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 以赛亚书 9:10; 列王纪上 10:27–29"> 王使耶路撒冷的银子多如石头，使香柏木多如丘陵的桑树。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 1:16; 列王纪上 10:28; 以赛亚书 31:1"> 所罗门的马匹都是从埃及和其他国家运来的。</span>
</div>
</div>

## 所罗门逝世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:29; 列王纪上 11:41–43; 列王纪上 11:29"> 所罗门其他的事迹自始至终都记在拿单先知的史记、示罗人亚希雅的《预言书》和易多先见论尼八的儿子耶罗波安的《启示书》中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 11:42–43"> 所罗门在耶路撒冷统治整个以色列四十年，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:10; 撒母耳记下 7:12; 列王纪上 1:21"> 他与祖先同眠后，葬在他父亲大卫的城里。他儿子罗波安继位。</span>
</div>
</div>

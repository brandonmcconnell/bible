## 所罗门为民众祝福

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:14; 历代志下 29:29; 列王纪上 8:55–61"> 然后，王转身为站立在那里的以色列全体会众祝福。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 72:18–19; 马太福音 24:35; 诗篇 68:32–35"> 他说：“以色列的上帝耶和华当受称颂！祂亲口给我父大卫的应许，现在祂亲手成就了！</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:24; 列王纪上 8:16; 撒母耳记上 13:13–14"> 祂曾说，‘自从我带我的子民出埃及以来，我并没有在以色列各支派中选出一座城来建造殿宇，作为我名所在之地，也没有选立一人做我以色列子民的君王。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 28:4; 诗篇 132:13; 历代志下 12:13"> 但如今，我拣选了耶路撒冷作为我名所在之地，又拣选了大卫来治理我的以色列子民。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:1; 列王纪上 5:3; 历代志上 22:7"> 所罗门又说：“我父大卫曾想为以色列的上帝耶和华的名建一座殿，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 马可福音 14:8; 列王纪上 8:18–21"> 但耶和华对我父大卫说，‘你想为我的名建造殿宇，这番心意是好的，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 7:12–13; 历代志上 17:4; 历代志上 17:11–12"> 但你不可建，要由你的亲生儿子为我的名建殿。’</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 1:4; 历代志上 28:5; 历代志上 17:11"> 现在耶和华已经成就祂的应许。我继承了我父大卫的王位统治以色列，又为以色列的上帝耶和华的名建了殿。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 5:10; 历代志下 5:7; 列王纪上 8:21"> 我把约柜安放在里面，约柜里有耶和华与以色列人所立的约。”</span>
</div>
</div>

## 所罗门的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 63:4; 以赛亚书 50:10; 约伯记 11:13"> 所罗门当着以色列会众的面，站在耶和华的坛前，向天伸出双手。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:54; 尼希米记 8:4; 诗篇 95:6"> 他曾造一个长两米二，宽两米二，高一米半的铜台，放在院子中间。他站在台上，当着以色列会众的面双膝跪下，向天伸出双手，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:11; 申命记 7:9; 尼希米记 1:5"> 祷告说：“以色列的上帝耶和华啊，天上地下没有神明可以与你相比！你向尽心遵行你旨意的仆人守约、施慈爱。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 撒母耳记下 7:12; 列王纪上 8:24"> 你持守对你仆人——我父大卫的应许，你曾亲口应许，你今天亲手成就了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:4; 约翰福音 15:14–15; 历代志下 7:18"> 以色列的上帝耶和华啊，你曾对你仆人——我父大卫说，‘若你的子孙像你一样谨慎行事，遵行我的律法，你的王朝就不会中断。’求你信守这应许。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 11:5; 以赛亚书 41:17; 历代志下 6:4"> 以色列的上帝耶和华啊，求你实现你对你仆人大卫的应许。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 2:6; 以赛亚书 66:1; 诗篇 139:7–10"> “然而，上帝啊，你真会住在人间吗？看啊，至高的诸天尚且容不下你，更何况我建造的这殿呢？</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 8:28; 路加福音 18:1–7; 约翰福音 17:20"> 可是，我的上帝耶和华啊，求你垂顾你仆人的祷告和祈求，垂听你仆人在你面前的呼求和祷告。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 34:15; 但以理书 6:10; 诗篇 121:5"> 愿你昼夜看顾这殿，就是你应许立你名的地方！你仆人向着这地方祷告的时候，求你垂听。</span>
<span className="v" id="v21" data-v="21" data-xref="弥迦书 7:18; 但以理书 9:19; 以赛亚书 43:25"> 你仆人和你的以色列子民向这地方祈祷的时候，求你从你天上的居所垂听，赦免我们的罪。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 22:11; 利未记 5:1; 民数记 5:19–22"> “如果有人得罪邻舍，被叫到这殿中，在你的坛前起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 3:10–11; 箴言 17:15; 耶利米书 51:56"> 求你从天上垂听，在你众仆人当中施行审判，按他们的行为罚恶赏善。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 26:17; 列王纪下 17:7–18; 约书亚记 7:8"> “当你的以色列子民因得罪你而败在敌人手中时，如果他们回心转意归向你，承认你的名，在这殿里向你祈祷，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 33:6–13; 以斯拉记 1:1–6; 创世记 13:15"> 求你从天上垂听，赦免他们的罪，带领他们回到你赐给他们和他们祖先的土地上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 28:23; 申命记 11:17; 利未记 26:19"> “当你的子民得罪你，你惩罚他们，让天不降雨时，如果他们向着这地方祷告，承认你的名，并离开罪恶，</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 8:35–36; 耶利米书 5:24; 撒迦利亚书 10:1"> 求你在天上垂听，赦免你仆人以色列子民的罪，教导他们走正道，降下甘霖滋润你赐给你子民作产业的土地。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 9:3–11; 约珥书 2:25; 路得记 1:1"> “如果国中有饥荒、瘟疫、旱灾、霉病、蝗灾、虫灾，或是城邑被敌人围困，无论遭遇什么灾祸疾病，</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 50:15; 诗篇 32:2–6; 历代志下 6:12–13"> 只要你的以色列子民，或个人或全体，自知心中痛苦并向着这殿伸手祷告，无论祈求什么，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 28:9; 撒母耳记上 16:7; 启示录 2:23"> 求你从天上的居所垂听，赦免他们。唯独你能洞察人心，你必按各人的行为施行赏罚，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:31; 约伯记 28:28; 诗篇 128:1"> 使你的子民在你赐给我们祖先的土地上终生敬畏你，遵行你的道。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 56:3–7; 列王纪上 8:41–43; 马太福音 8:10–11"> “如果远方有不属于你以色列子民的外族人听说你的大能大力，慕名而来，向着这殿祷告，</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 7:14; 列王纪上 8:16; 启示录 11:15"> 求你从天上的居所垂听，应允他们的祈求，好叫天下万民都像你的以色列子民一样认识你的名、敬畏你，并知道我建造的这殿属于你的名下。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="历代志下 20:6–13; 历代志下 18:31; 历代志下 20:4"> “你的子民奉你的命令上阵与敌人作战，无论他们在哪里，如果他们向着你选择的这城和我为你名建造的这殿祷告，</span>
<span className="v" id="v35" data-v="35" data-xref="但以理书 9:17–19; 诗篇 9:3–4; 耶利米书 5:28"> 求你从天上垂听他们的祈祷，为他们伸张正义。</span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36" data-xref="传道书 7:20; 雅各书 3:2; 约翰一书 1:8–10"> “世上没有不犯罪的人，如果你的子民得罪你，以致你向他们发怒，让敌人把他们掳走，不论远近，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 31:18–20; 但以理书 9:5–11; 以赛亚书 64:6–12"> 若他们在被掳之地回心转意，向你恳求，承认自己犯罪作恶了；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志下 33:11–13; 但以理书 6:10; 但以理书 9:3–4"> 若他们全心全意地归向你，在被掳之地朝着你赐给他们祖先的这片土地、你选择的这城和我为你建的这殿向你祷告，</span>
<span className="v" id="v39" data-v="39" data-xref="弥迦书 7:18–20; 历代志下 6:35; 诗篇 25:18"> 求你从天上的居所垂听他们的祈祷，为他们伸张正义，赦免得罪你的子民。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 7:15; 诗篇 116:2; 尼希米记 1:6"> <span className="pl pl-1">“我的上帝啊，</span><br /><span className="pl pl-1">求你睁眼看、侧耳听在这殿里献上的祷告。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 61:10; 历代志上 28:2; 诗篇 132:8–10"> <span className="pl pl-1">耶和华上帝啊，</span><br /><span className="pl pl-1">求你起来和你大能的约柜一同进入你的安息之所！</span><br /><span className="pl pl-1">耶和华上帝啊，</span><br /><span className="pl pl-1">愿你的祭司披上救恩，</span><br /><span className="pl pl-1">愿你忠心的子民蒙福欢乐！</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以赛亚书 55:3; 诗篇 132:1; 以赛亚书 61:1"> <span className="pl pl-1">耶和华上帝啊，</span><br /><span className="pl pl-1">求你不要弃绝你所膏立的人，</span><br /><span className="pl pl-1">顾念你曾应许以慈爱待你的仆人大卫。”</span></span>
</div>

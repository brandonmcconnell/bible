## 亚比雅与耶罗波安争战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 12:16; 列王纪上 15:1–8"> 耶罗波安王执政第十八年，亚比雅登基做犹大王，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:20; 列王纪上 15:6–7; 士师记 19:16"> 在耶路撒冷执政三年。他母亲叫米该亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“米该亚”在代下11:20是“押沙龙的女儿玛迦”。">a</a></sup>，是基比亚人乌列的女儿。亚比雅和耶罗波安之间常有争战。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 26:12–13; 历代志上 21:5; 撒母耳记上 17:1–3"> 有一次，亚比雅率领四十万精兵出战，耶罗波安率领八十万精兵列阵迎战。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:22; 历代志下 15:2; 创世记 10:18"> 亚比雅站在以法莲山区的西玛莲山上说：“耶罗波安和全体以色列人啊，你们听我说，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 18:19; 利未记 2:13; 马可福音 9:49–50"> 你们不知道以色列的上帝耶和华曾经立下永世之约<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“永世之约”希伯来文是“盐约”。">b</a></sup>，要把以色列国永远赐给大卫和他的子孙吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 11:26; 列王纪上 12:20; 历代志下 10:19"> 尼八的儿子耶罗波安本是大卫的儿子所罗门的仆人，他却背叛他的主人，</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 9:4; 历代志下 12:13; 使徒行传 17:5"> 召集一群无赖，与所罗门的儿子罗波安作对。那时，罗波安年轻怯懦，无力抵抗。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 历代志下 11:15; 路加福音 19:14"> “现在你们仗着人多势众，又有耶罗波安制造的金牛犊作为你们的神明，便企图反抗大卫子孙所治理的耶和华的国度。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 11:14–15; 耶利米书 2:11; 出埃及记 29:35"> 你们赶走了做耶和华祭司的亚伦之后裔和利未人，效法外族人的恶俗为自己设立祭司。任何人牵来一头公牛犊和七只公绵羊，就可以自封为假神的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:5–6; 历代志下 11:16–17; 撒迦利亚书 13:9"> “至于我们，耶和华是我们的上帝，我们没有背弃祂，我们有亚伦的后裔做祭司事奉耶和华，也有利未人各尽其职。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:4; 利未记 24:2–9; 出埃及记 29:38"> 他们每天早晚向耶和华献燔祭，烧芬芳的香，把供饼摆在洁净<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“洁净”指宗教礼仪上的洁净。">c</a></sup>的桌子上，每晚点上金灯台的灯。我们遵守我们上帝耶和华的吩咐，你们却背弃祂。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:39; 罗马书 8:31; 民数记 10:8–9"> 上帝与我们同在，祂率领我们。祂的祭司就要吹响向你们进攻的号角。以色列人啊，不要与你们祖先的上帝耶和华作对，因为你们绝不会得胜。”</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:4; 约书亚记 8:9; 箴言 21:30"> 耶罗波安却在犹大人后面设伏兵，企图前后夹攻他们。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 14:11; 出埃及记 14:10; 约书亚记 8:20"> 犹大人转身，发现自己腹背受敌，就呼求耶和华。祭司吹响号角，</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 14:12; 约书亚记 11:8; 诗篇 118:4–7"> 犹大人便呐喊，上帝使耶罗波安和以色列人败在亚比雅和犹大人面前。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 16:8; 士师记 11:21; 约书亚记 10:12"> 以色列人从犹大人面前逃跑，上帝把他们交在犹大人手中。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 28:6; 历代志下 13:3; 历代志下 13:12"> 亚比雅和他的军队大败以色列人，歼灭了他们五十万精兵。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 5:20; 历代志下 14:11; 那鸿书 1:7"> 这样，以色列人被击败，犹大人因为倚靠他们祖先的上帝耶和华而大获全胜。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 15:8; 约书亚记 15:9; 约书亚记 10:39"> 亚比雅追赶耶罗波安，攻取了伯特利、耶沙拿和以法拉音各城以及它们周围的村庄。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 25:38; 列王纪上 14:20; 使徒行传 12:23"> 亚比雅在世之日，耶罗波安再也没有恢复势力。后来，耶和华攻击他，他就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 9:5; 撒母耳记下 5:12–13; 士师记 10:4"> 亚比雅却日渐强大，他有十四个妻妾、二十二个儿子、十六个女儿。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 9:29; 历代志下 12:15; 历代志下 24:27"> 亚比雅其余的事及其言行都记在易多先知的史记上。</span>
</div>

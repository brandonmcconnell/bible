## 耶和华禁止他们交战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:21–24; 诗篇 33:10; 诗篇 33:16"> 罗波安回到耶路撒冷，从犹大和便雅悯支派召集了十八万精兵，要攻打以色列，收复全国。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:15; 历代志下 12:5–7; 历代志下 8:14"> 然而，耶和华上帝对祂的仆人示玛雅说：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 17:34; 创世记 49:28; 启示录 7:4–8"> “你去告诉所罗门的儿子犹大王罗波安和所有住在犹大和便雅悯的以色列人，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 50:20; 列王纪上 11:29–38; 历代志下 10:15–16"> 耶和华这样说，‘你们不要上去与弟兄交战，都回家吧，因为这事出于我。’”众人听从了耶和华的话，没有去攻打耶罗波安，各自回家去了。</span>
</div>
</div>

## 罗波安加强防御

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 以赛亚书 22:8–11"> 罗波安住在耶路撒冷，他在犹大修筑城池用来防御。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 3:5; 阿摩司书 1:1; 历代志上 4:32"> 他修筑的城池有伯利恒、以坦、提哥亚、</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:35; 撒母耳记上 22:1; 约书亚记 15:58"> 伯·夙、梭哥、亚杜兰、</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 54:1; 约书亚记 15:24; 撒母耳记上 23:19"> 迦特、玛利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:39; 约书亚记 15:35; 约书亚记 10:5"> 亚多莱音、拉吉、亚西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 15:33; 约书亚记 14:14"> 琐拉、亚雅仑、希伯仑，这些都是犹大和便雅悯的坚城。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:19; 以赛亚书 22:10–11; 历代志下 11:23"> 他又在各城池加强防御，派将领驻守，供给食物、油和酒。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 13:22; 历代志下 26:14–15; 历代志下 32:5"> 他在城内储备盾牌和矛枪，使城池非常坚固。犹大和便雅悯都归属他。</span>
</div>
</div>

## 祭司和利未人投奔犹大

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13"> 以色列全境的祭司和利未人都从四面八方来投奔罗波安。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 13:9; 民数记 35:2–5; 列王纪上 12:28–33"> 利未人撇下他们的草场和产业，来到犹大和耶路撒冷，因为耶罗波安和他的众子不准他们做祭司事奉耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:28; 列王纪上 12:31; 列王纪上 13:33"> 耶罗波安却为丘坛、公山羊像和他造的牛犊像设立他自己的祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 使徒行传 11:23; 诗篇 84:5–7"> 以色列各支派中那些诚心寻求以色列的上帝耶和华的人，都跟随利未人到耶路撒冷献祭给他们祖先的上帝耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 12:1; 历代志下 1:1–12; 历代志下 7:17–19"> 他们使犹大国坚固，他们效忠所罗门的儿子罗波安三年之久，并在此期间遵行大卫和所罗门的道。</span>
</div>
</div>

## 罗波安的家室

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 历代志上 27:18; 撒母耳记上 17:13"> 罗波安娶了大卫的儿子耶利摩的女儿玛哈拉为妻，她母亲亚比孩是耶西的儿子以利押的女儿。</span>
<span className="v" id="v19" data-v="19"> 玛哈拉为他生了耶乌施、示玛利雅、撒罕三个儿子。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 13:2; 历代志下 11:21; 历代志下 12:16"> 后来，他又娶了押沙龙的女儿玛迦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“押沙龙的女儿玛迦”或译“押沙龙的孙女玛迦”。">a</a></sup>，生了亚比雅、亚太、细撒、示罗密。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 8:30; 申命记 17:17; 列王纪上 11:3"> 罗波安共有十八个妻子、六十个妾、二十八个儿子、六十个女儿。众妻妾中押沙龙的女儿玛迦最得宠爱，</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 21:15–17; 历代志上 29:1; 历代志上 5:1–2"> 罗波安就立她所生的儿子亚比雅为太子，以便让他继承王位。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:3; 创世记 25:6; 路加福音 16:8"> 罗波安精明地把其他王子派驻到犹大和便雅悯境内的各坚城，给他们充足的供应和许多妻妾。</span>
</div>
</div>

## 圣殿奉献礼

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 18:38; 历代志上 21:26; 利未记 9:23–24"> 所罗门祷告完毕，就有火从天上降下，烧尽了燔祭和其他祭物。殿里充满了耶和华的荣光，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 15:8; 历代志下 5:14; 出埃及记 24:17"> 以致祭司不能进耶和华的殿。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 5:13; 历代志下 20:21; 路加福音 1:50"> 全体以色列人看见有火降下，又看见耶和华的荣光停在殿上，便俯伏在铺石地上敬拜，称谢耶和华说：<br /><span className="pl pl-1">“耶和华是美善的，</span><br /><span className="pl pl-1">祂的慈爱永远长存。”</span></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:62–63"> 所罗门王和全体民众一同向耶和华献祭。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:22; 以西结书 45:17; 历代志下 30:24"> 所罗门王献上两万二千头牛和十二万只羊，王和全体民众为上帝的殿举行奉献典礼。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 5:12; 历代志上 15:16–21; 历代志下 7:3"> 祭司在自己的岗位上侍立，利未人奏着大卫王为颂赞耶和华而为他们制造的乐器，歌颂说：“祂的慈爱永远长存。”他们对面的祭司也吹响号角，全体以色列人都肃立。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 8:64–66; 希伯来书 13:10–12; 历代志下 36:14"> 因所造的铜坛太小，容不下燔祭、素祭和脂肪，所罗门就把耶和华殿前院子中间分别出来作圣洁之地，在那里献上燔祭和平安祭祭牲的脂肪。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 列王纪上 8:65; 尼希米记 8:13–18"> 所罗门和从哈马口直至埃及小河而来的全体以色列人聚成一大群会众，一起守节期七天。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:36; 列王纪上 8:65; 约珥书 1:14"> 第八天举行庄严的聚会，又举行七天献坛礼。之后，他们又欢庆七天。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:66; 诗篇 100:2; 申命记 12:18"> 七月二十三日，所罗门王让民众各回本乡。他们看见耶和华向大卫、所罗门和祂的以色列子民所施的恩惠，就满心欢喜地回家去了。</span>
</div>
</div>

## 耶和华向所罗门显现

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:1–9; 传道书 2:10–11; 历代志下 2:1"> 所罗门建完了耶和华的殿和他自己的王宫，他按计划完成了耶和华殿里和他自己宫里的一切工作。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:1; 列王纪上 9:2; 历代志下 7:16"> 耶和华在夜间向所罗门显现，对他说：“我听了你的祷告，也已选择这殿作为给我献祭的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 6:26–28; 申命记 11:17; 启示录 11:6"> 若我使天不下雨，使蝗虫吞吃地上的出产，或叫瘟疫在我民中流行，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米哀歌 3:40–41; 雅各书 4:9–10; 以赛亚书 55:6–7"> 而这些被称为我名下的子民若谦卑下来，祈祷、寻求我的面，离开恶道，我必从天上垂听，赦免他们的罪，医治他们的土地。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:12; 历代志下 6:40; 尼希米记 1:6"> 现在，我会睁眼看、留心听在这殿里献上的祷告。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 7:15; 历代志下 7:12; 历代志下 6:5–6"> 我已选择这殿，使之圣洁，让我的名永在其中，我必一直眷顾和心系这殿。</span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 3:7; 以西结书 36:27; 列王纪上 11:38"> 如果你像你父亲大卫一样事奉我，遵行我的一切吩咐，谨守我的律例和典章，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 6:16; 耶利米书 33:20–21; 撒母耳记下 7:13–16"> 我必使你的王位稳固，正如我曾与你父亲大卫立约，说，‘你的子孙必永远统治以色列。’</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 26:14; 申命记 28:15; 利未记 26:33–46"> “然而，如果你们背弃我指示你们的律例和诫命，去供奉、祭拜其他神明，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:20; 申命记 28:37; 耶利米书 24:9"> 我必把你们从我赐给你们的土地上铲除，并离弃我为自己的名而使之圣洁的这殿，使它在万民中成为笑柄、被人嘲讽。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 22:8–9; 耶利米书 16:10–12; 耶利米书 19:8"> 这殿虽然宏伟，但将来经过的人必惊讶地问，‘耶和华为什么这样对待这地方和这殿呢？’</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 9:12; 耶利米哀歌 2:16–17; 以西结书 14:23"> 人们会回答，‘因为他们背弃曾领他们祖先离开埃及的他们的上帝耶和华，去追随、祭拜、供奉其他神明，所以耶和华把这一切灾祸降在他们身上。’”</span>
</div>
</div>

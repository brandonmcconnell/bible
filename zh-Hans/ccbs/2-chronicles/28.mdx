## 犹大王亚哈斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:13; 以赛亚书 1:1; 列王纪下 16:1–20"> 亚哈斯二十岁登基，在耶路撒冷执政十六年。他没有效法他祖先大卫做耶和华视为正的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:17; 士师记 2:11; 历代志下 22:3–4"> 反而步以色列诸王的后尘，又铸造巴力神像。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:2; 历代志下 33:6; 利未记 18:21"> 他不但在欣嫩子谷烧香，还效法耶和华在以色列人面前赶走的外族人的可憎行径，把自己的儿女焚烧献作祭物。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 16:4; 申命记 12:2–3; 利未记 26:30"> 他还在丘坛、山冈和绿树下献祭烧香。</span>
</div>
</div>

## 与亚兰和以色列交战

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:1; 历代志下 24:24; 列王纪下 16:5–6"> 因此，他的上帝耶和华把他交在亚兰王手中，亚兰王就打败他，把他的许多人民掳到大马士革。他也被交在以色列王手中，损失惨重。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 15:27; 约书亚记 24:20; 耶利米书 15:6"> 利玛利的儿子比加一天之内杀了犹大十二万勇士，因为他们背弃了他们祖先的上帝耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 43:15; 创世记 41:43; 以斯帖记 10:3"> 以法莲的勇士细基利杀了王子玛西雅、宫廷总管押斯利甘和宰相以利加拿。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 11:4; 申命记 28:25; 申命记 28:41"> 以色列军队从他们的犹大同胞中掳走了二十万妇孺，同时也将大量战利品带回撒玛利亚。</span>
</div>
</div>

## 俄德先知

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 47:6; 以斯拉记 9:6; 启示录 18:5"> 撒玛利亚有一位耶和华的先知名叫俄德，他出城去迎接班师回来的军队，说：“看啊，你们祖先的上帝耶和华向犹大发怒，才将他们交在你们手中。你们竟怒气冲天，对他们大加杀戮。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:39–46; 马太福音 7:2–4; 耶利米书 25:29"> 现在你们竟还想让犹大和耶路撒冷的男女做你们的仆婢。你们岂不也得罪你们的上帝耶和华吗？</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 2:13; 以斯拉记 10:14; 马太福音 5:7"> 你们还是听我的，释放你们掳来的同胞，让他们回去吧！因为耶和华的烈怒已经临到你们了。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 28:1; 耶利米书 26:6"> 约哈难的儿子亚撒利雅、米实利末的儿子比利迦、沙龙的儿子耶希西迦和哈得莱的儿子亚玛撒四位以法莲族长，起来阻挡从战场回来的军队，</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:14; 马太福音 23:32; 约书亚记 22:17–18"> 说：“你们不可把这些俘虏带进来，我们的罪已经够重了，耶和华的烈怒已经临到以色列人，不要再得罪耶和华，加重我们的罪恶了。”</span>
<span className="v" id="v14" data-v="14"> 于是，士兵们便把俘虏和战利品交给众首领和民众。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 25:21–22; 申命记 34:3; 士师记 1:16"> 那些以法莲族长就上前照顾俘虏，从战利品中拿出衣服和鞋给那些赤身露体的俘虏穿上，供应他们吃喝，又给他们的伤口抹上油，让软弱的骑驴。他们把所有的俘虏送到棕树城耶利哥他们的亲族那里，随后返回撒玛利亚。</span>
</div>
</div>

## 亚哈斯向亚述王求援

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 16:5–7; 以赛亚书 7:17; 以赛亚书 7:1–9"> 那时，亚哈斯王派人到亚述王那里求援。</span>
<span className="v" id="v17" data-v="17" data-xref="俄巴底亚书 1:10; 俄巴底亚书 1:13–14; 利未记 26:18"> 原来以东人又来攻打犹大，掳掠民众。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 16:57; 以西结书 16:27; 撒母耳记上 6:9"> 非利士人也入侵犹大丘陵和南地的城镇，攻占了伯·示麦、亚雅仑、基低罗和梭哥、亭拿、瑾锁及这三城周围的村庄，并住在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 21:2; 约伯记 40:12; 申命记 28:43"> 耶和华使犹大衰微，因为以色列王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以色列王”这里可能指统治犹大的王，而非统治北国以色列的王。">a</a></sup>亚哈斯在犹大肆无忌惮，悖逆耶和华。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 历代志上 5:26; 以赛亚书 30:16"> 亚述王提革拉·毗列色来到犹大后，不但不救他，反而压迫他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 16:8–9; 列王纪下 18:15–16; 历代志下 12:9"> 亚哈斯从耶和华的殿里、王宫和官员家中取财宝送给亚述王，但无济于事。</span>
</div>
</div>

## 亚哈斯的恶行

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:5; 以西结书 21:13; 耶利米书 5:3"> 亚哈斯王在患难时越发悖逆耶和华，</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 25:14; 耶利米书 44:20–28; 哈巴谷书 1:11"> 竟去祭拜打败他的大马士革人的神明，说：“既然亚兰王的神明帮助了亚兰人，我要向这些神明献祭，好让它们帮助我。”但那些神明导致了他和全体以色列人的灭亡。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:7; 列王纪下 16:17–18; 历代志下 30:14"> 亚哈斯将耶和华上帝殿里的器皿收集起来打碎，封锁殿门，并在耶路撒冷的每个角落为自己设立祭坛。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:3"> 他还在犹大各城建立丘坛，向其他神明烧香，惹他祖先的上帝耶和华发怒。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 16:19–20; 历代志下 20:34; 历代志下 27:7–9"> 亚哈斯其他的事及一切所为自始至终都记在《犹大和以色列列王史》上。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 21:20; 历代志下 24:25; 箴言 10:7"> 亚哈斯与祖先同眠后，葬在耶路撒冷城中，但没有葬在以色列的王陵。他儿子希西迦继位。</span>
</div>
</div>

## 北方支派背叛罗波安

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:6; 约书亚记 20:7; 历代志上 12:38"> 罗波安前往示剑，因为以色列人都去了那里要立他为王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 11:40; 列王纪上 12:2; 列王纪上 11:28"> 尼八的儿子耶罗波安曾为了躲避所罗门王而逃往埃及，并一直住在那里。他听到消息便从埃及返回以色列。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 12:3"> 以色列人派人去请他，他就和以色列众人去见罗波安，说：</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 12:4; 出埃及记 2:23; 马太福音 11:29–30"> “你父亲使我们负担沉重，求你减轻我们的劳役和负担吧，我们一定服侍你。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 12:5; 箴言 3:28"> 罗波安对他们说：“你们三天之后再来见我。”众人就离开了。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 32:7; 箴言 19:20; 箴言 27:10"> 罗波安王去征询曾服侍他父亲所罗门的老臣的意见，说：“你们认为我该怎样回复这些民众？”</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 创世记 49:21; 列王纪上 12:7"> 他们回禀说：“王若善待这些百姓，使他们喜悦，对他们好言相待，他们会永远做王的仆人。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 17:14; 箴言 1:25; 传道书 10:16"> 罗波安却没有采纳老臣的意见。他又去征询那些和他一起长大的青年臣僚的意见，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 10:6; 撒母耳记下 17:5–6; 列王纪上 22:6–8"> 说：“民众求我减轻我父亲加给他们的重担。你们认为我该怎样回复他们？”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:23; 箴言 13:16; 撒母耳记下 17:7–13"> 他们说：“民众说你父亲使他们负担沉重，请求你减轻他们的负担。你可以这样回复他们，‘我的小指头比我父亲的腰还粗。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:29; 以赛亚书 47:6; 启示录 9:10"> 我父亲使你们负重担，我要使你们负更重的担子；我父亲用鞭子打你们，我要用刺鞭打你们。’”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 12:12–15; 历代志下 10:5"> 过了三天，耶罗波安和民众遵照罗波安王的话来见他。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 10:8; 箴言 19:27; 撒母耳记上 25:10–11"> 罗波安王没有采纳老臣的建议，而是照青年臣僚的建议，疾言厉色地对他们说：“我父亲使你们负重担，我要使你们负更重的担子！我父亲用鞭子打你们，我要用刺鞭打你们！”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 11:29–39; 撒母耳记上 2:25; 历代志下 25:16–20"> 王不听民众的请求。这件事出于上帝，为要应验耶和华借示罗人亚希雅先知对尼八的儿子耶罗波安说的话。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 20:1; 历代志下 10:19; 诗篇 76:10"> 以色列人见王不听他们的请求，就说：<br /><span className="pl pl-1">“我们与大卫有何相干？</span><br /><span className="pl pl-1">我们与耶西的儿子没有关系！</span><br /><span className="pl pl-1">以色列人啊，各自回家吧！</span><br /><span className="pl pl-1">大卫家啊，自己顾自己吧！”</span>于是，以色列人各自回家了。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 11:1; 列王纪上 12:17; 列王纪上 11:36"> 但住在犹大城邑的以色列人仍受罗波安统治。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 5:14; 列王纪上 4:6; 使徒行传 7:57–58"> 罗波安王派劳役总管哈多兰去以色列人那里，以色列人却用石头打死了他，罗波安王连忙上车逃回耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 12:19–20; 以斯拉记 9:7; 历代志下 5:9"> 从此，以色列人反叛大卫家，直到今天。</span>

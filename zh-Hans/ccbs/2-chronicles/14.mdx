## 亚撒王击败古实人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 9:31; 列王纪上 2:10; 列王纪上 14:31"> 亚比雅与祖先同眠后，葬在大卫城，他儿子亚撒继位。亚撒执政期间，国中太平十年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:11; 历代志下 31:20; 列王纪上 15:14"> 亚撒做他的上帝耶和华看为好、视为正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:5; 出埃及记 34:13; 列王纪下 23:14"> 拆除外族的祭坛和丘坛，打碎神柱，砍倒亚舍拉神像，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 30:19; 诗篇 119:10; 诗篇 101:2–8"> 命令犹大人寻求他们祖先的上帝耶和华，遵行祂的律法和诫命。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 34:4; 历代志下 34:7"> 他除掉犹大各城邑的丘坛和香坛，那时国家在他的治理下太平无事。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 15:15; 历代志上 22:9; 约伯记 34:29"> 他还在犹大修筑坚城，那些年国中太平，没有战事，因为耶和华赐他平安。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 3:12; 历代志下 14:6; 耶利米书 29:12–14"> 他对犹大人说：“我们要修筑城邑，在四周建造城墙和望楼，装置大门和门闩。我们仍拥有这片土地，是因为我们寻求我们的上帝耶和华；我们寻求祂，祂就赐我们四境平安。”于是，他们修筑城邑，凡事顺利。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 13:3; 历代志下 17:14–19; 历代志下 11:1"> 亚撒的军队中有三十万持大盾牌和矛枪的犹大人，二十八万持小盾牌和弓箭的便雅悯人。他们都是英勇的战士。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 16:8; 历代志下 12:2–3; 历代志下 11:8"> 古实王谢拉率领一百万大军和三百辆战车攻打犹大，到了玛利沙。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 1:17; 约书亚记 19:4"> 亚撒出兵迎敌，双方在玛利沙的洗法谷摆开阵势。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 1:19; 哥林多后书 12:9–10; 诗篇 22:5"> 亚撒呼求他的上帝耶和华说：“耶和华啊，唯有你才能帮助弱小的胜过强大的。我们的上帝耶和华啊，求你帮助我们，因为我们依靠你，奉你的名迎战这大军。耶和华啊，你是我们的上帝，不要让人胜过你。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 13:15; 诗篇 136:17–18; 申命记 28:7"> 于是，耶和华使古实人败在亚撒和犹大人面前，古实人溃逃。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:19; 创世记 26:1; 创世记 20:1"> 亚撒率领军队乘胜追击，直追到基拉耳。古实人在耶和华和祂的军兵面前大败，伤亡惨重，一蹶不振。犹大人掳走了许多财物，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 17:10; 创世记 35:5; 历代志下 20:29"> 攻陷了基拉耳四周的城邑，因为这些城里的人都惧怕耶和华。他们洗劫各城，因为城中有大量财物。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:30–47; 民数记 31:9; 撒母耳记上 30:20"> 他们毁坏牲畜的棚圈，抢走许多羊和骆驼，然后返回耶路撒冷。</span>
</div>
</div>

## 犹大王希西迦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:1–3; 历代志上 3:13; 历代志下 26:5"> 希西迦二十五岁登基，在耶路撒冷执政二十九年。他母亲叫亚比雅，是撒迦利雅的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 34:2; 历代志下 28:1"> 希西迦事事效法他祖先大卫，做耶和华视为正的事。</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 28:24; 历代志下 29:7; 马太福音 6:33"> 希西迦元年一月，他开启耶和华殿的门，重新修理。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 19:2; 尼希米记 3:29; 历代志下 32:6"> 他把众祭司和利未人召集在东边的广场，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 35:6; 哥林多前书 3:16–17; 历代志下 34:3–8"> 对他们说：“利未人啊，请听我说！现在你们要洁净自己，也要洁净你们祖先的上帝耶和华的殿，除去圣所中的污秽之物。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 8:16; 耶利米书 2:27; 但以理书 9:16"> 我们的祖先行事不忠，做我们的上帝耶和华视为恶的事，背弃祂，转脸背向祂的居所。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 28:24; 利未记 24:2–8; 历代志下 29:3"> 他们封锁殿廊的门，吹灭灯火，不在圣所里向以色列的上帝烧香、献燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 25:9; 耶利米书 25:18; 耶利米书 29:18"> 因此，耶和华的烈怒临到犹大和耶路撒冷，使他们的遭遇令人恐惧、震惊、嗤笑，正如你们亲眼所见的。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 28:17; 历代志下 28:5–8; 耶利米哀歌 5:7"> 所以我们的祖先死在刀下，我们的妻儿也被掳去。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 50:5; 历代志下 23:16; 以斯拉记 10:3"> 现在我决心要与以色列的上帝耶和华立约，好使祂的烈怒转离我们。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:8; 加拉太书 6:7–8; 民数记 8:6–14"> 我的孩子们啊，不要懈怠！因为耶和华拣选你们站在祂面前事奉祂，向祂烧香。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 3:19–20; 历代志上 15:5–7; 民数记 4:2–20"> 于是，利未人开始供职。其中哥辖宗族有亚玛赛的儿子玛哈和亚撒利雅的儿子约珥，米拉利宗族有亚伯底的儿子基士和耶哈利勒的儿子亚撒利雅，革顺宗族有薪玛的儿子约亚和约亚的儿子伊甸，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 6:39; 历代志上 15:8; 历代志上 15:17"> 以利撒反宗族有申利和耶利，亚萨宗族有撒迦利雅和玛探雅，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 6:33; 历代志上 25:1; 历代志上 25:6"> 希幔宗族有耶歇和示每，耶杜顿宗族有示玛雅和乌薛。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 30:12; 历代志上 23:28; 历代志下 29:5"> 他们召集其他利未人一起洁净自己，并遵照王的吩咐和耶和华的命令，进去洁净耶和华的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:16; 马太福音 21:12–13; 马太福音 23:27"> 祭司们进去洁净耶和华的殿，把所有污秽之物搬到耶和华殿的院子里，然后再由利未人运到外面的汲沦溪丢掉。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:2–8; 历代志下 3:4; 列王纪上 6:3"> 他们一月一日开始洁净的工作，到一月八日已经洁净到耶和华殿的走廊，又用八天洁净耶和华的殿，一月十六日完成洁净的工作。</span>
</div>
</div>

## 重新奉献圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 4:1; 历代志下 4:7–8; 历代志下 13:11"> 然后，他们晋见希西迦王，说：“我们已经洁净了整个耶和华的殿、燔祭坛以及坛上的一切器皿、供饼的桌子及桌子上的一切器皿。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 28:24"> 我们已备齐亚哈斯王对上帝不忠时所废弃的器皿，并洁净了它们，现在都放在耶和华的坛前。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 6:12; 耶利米书 25:4; 出埃及记 24:4"> 希西迦王清早起来，召集城中官员一同上到耶和华的殿。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 4:3–14; 约伯记 42:8; 以西结书 45:23"> 他们牵来七头公牛、七只公绵羊、七只羊羔和七只公山羊，作国家、圣所和犹大人的赎罪祭。王吩咐做祭司的亚伦子孙把这些牲畜献在耶和华的坛上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:18; 利未记 8:19; 利未记 8:24"> 他们宰了公牛，祭司取过血来洒在坛上，然后宰了公绵羊并把血洒在坛上，又宰了羊羔并把血洒在坛上。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:15; 利未记 4:24; 利未记 1:4"> 有人把作赎罪祭的公山羊牵到王和会众面前，他们就将手按在公山羊身上。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:20; 以西结书 45:15; 哥林多后书 5:18–21"> 祭司宰了公山羊，把血洒在坛上作赎罪祭，为所有以色列人赎罪，因为王吩咐要为所有以色列人献上燔祭和赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 8:14; 历代志上 23:5; 撒母耳记下 24:11"> 王又分派利未人在耶和华的殿里敲钹、鼓瑟、弹琴，正如大卫王、王的先见迦得和先知拿单的指示，就是耶和华借先知所吩咐的。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:5; 历代志上 15:24; 阿摩司书 6:5"> 利未人拿着大卫的乐器侍立在那里，祭司拿着号角侍立在那里。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 23:18; 诗篇 137:3–4; 历代志下 20:21"> 希西迦下令在坛上献燔祭。开始献燔祭时，伴随着号角声和以色列王大卫的乐器声，响起了颂赞耶和华的歌声。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 5:8–14; 诗篇 89:15; 诗篇 68:24–26"> 全体会众伴着歌声和号角声俯伏敬拜，直到献完燔祭。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:18; 历代志上 29:20; 腓立比书 2:10–11"> 献完燔祭后，王和所有在场的人都俯伏敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 4:4; 诗篇 95:1–2; 历代志上 16:7–36"> 希西迦王与众官员又吩咐利未人用大卫和亚萨先见的诗词颂赞耶和华。他们欢然歌唱，并低头敬拜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 出埃及记 35:22; 利未记 7:12"> 希西迦说：“你们既然已经把自己献给了耶和华，现在就把祭物和感恩祭带到耶和华的殿里来吧。”于是，会众就把祭物和感恩祭送来，有些人甘心乐意地送来燔祭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉记 6:17; 列王纪上 3:4; 历代志上 29:21"> 会众献给耶和华作燔祭的有七十头公牛、一百只公绵羊、二百只羊羔，</span>
<span className="v" id="v33" data-v="33"> 献为圣物的有六百头公牛、三千只绵羊。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:11; 历代志下 30:3; 诗篇 94:15"> 但祭司人数太少，剥不完燔祭牲的皮，于是他们的亲族利未人就来帮助他们，直到献完燔祭，并且别的祭司也洁净了自己，因为利未人比祭司更诚心洁净自己。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 15:5–10; 出埃及记 29:13; 历代志上 16:37–42"> 他们献上大量燔祭和平安祭祭牲的脂肪，以及与燔祭同献的奠祭。<br />从此，耶和华殿里的事奉恢复了。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:41; 帖撒罗尼迦前书 3:8–9; 历代志上 29:9"> 希西迦和民众因上帝为他们做的而欢喜快乐，因为这事很快成就了。</span>
</div>
</div>

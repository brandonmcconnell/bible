## 圣殿的器具

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:64; 以西结书 43:13–17; 列王纪上 9:25"> 所罗门造了一座铜坛，长九米，宽九米，高四米半。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 3:5; 撒迦利亚书 13:1; 出埃及记 30:18–21"> 他又铸了一个圆形的铜海，高两米二，直径四米半，周长十三米半。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 1:10; 以西结书 10:14; 哥林多前书 9:9–10"> 铜海边缘下面有两圈牛的图案，每四十五厘米有十头牛，是跟铜海一起铸造的。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:19–20; 启示录 21:14; 马可福音 16:15"> 有十二头铜牛驮着铜海，三头向北，三头向西，三头向南，三头向东。铜海安在牛上，牛尾向内。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:26"> 铜海厚八厘米，边如杯边，又如百合花，容量为六万六千升。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:38; 出埃及记 30:18–21; 列王纪上 7:40"> 他又造了十个盆，五个放右边，五个放左边，用来清洗献燔祭所用之物。但铜海只供祭司洗涤使用。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 25:31–40; 列王纪上 7:49; 约翰福音 8:12"> 他照着所定的式样，造了十个金灯台放在殿里，五个在右边，五个在左边；</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 7:48; 玛拉基书 1:12; 出埃及记 25:23–30"> 又造了十张桌子放在殿里，五张在右边，五张在左边；还造了一百个金碗。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 6:36; 列王纪下 21:5; 列王纪上 7:12"> 他又建了祭司院、大院及大院的门，门都包上铜。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 7:39"> 铜海放在殿的右边，就是东南方。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 7:40–51; 列王纪上 7:14"> 户兰又造了锅、铲和碗。他为所罗门王完成了上帝殿里的工作。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 7:41; 历代志下 3:15–17"> 户兰所制造的有：两根柱子，两个碗状的柱冠，两个装饰柱冠的网子，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 7:20; 列王纪上 7:42; 耶利米书 52:23"> 四百个安在网子上的石榴，每个网子上两行石榴，用来装饰碗状的柱冠；</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 7:27–43"> 盆座及盆座上的盆；</span>
<span className="v" id="v15" data-v="15"> 铜海和铜海下面的十二头铜牛；</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 2:13; 列王纪上 7:13–14; 历代志下 4:11"> 锅、铲、肉叉及耶和华殿里的一切器具。这些都是巧匠户兰用磨亮的铜为所罗门王制造的。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:46"> 这些都是照王的命令，在疏割和撒利但之间的约旦平原用泥模铸成的。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:47; 耶利米书 52:20; 历代志上 22:14"> 所罗门制造的器具极多，铜的重量无法统计。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 9:13; 但以理书 5:2–3; 出埃及记 25:23–30"> 所罗门又为上帝的殿造了以下器具：金坛和放供饼的桌子，</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 4:7; 出埃及记 25:31–37; 列王纪上 6:5"> 按规定放在内殿前的纯金灯台和灯盏，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 6:29; 出埃及记 37:20; 列王纪上 6:35"> 灯台上的金花、灯盏、火钳、</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 12:13; 列王纪下 25:14; 耶利米书 52:18"> 灯剪、碗、碟和火鼎。殿门和至圣所的门也是金的。</span>
</div>
</div>

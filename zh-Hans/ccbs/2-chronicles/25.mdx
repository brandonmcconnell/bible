## 犹大王亚玛谢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 14:1–6"> 亚玛谢二十五岁登基，在耶路撒冷执政二十九年。他母亲叫约耶但，是耶路撒冷人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 25:14; 雅各书 4:8; 使徒行传 8:21"> 他做耶和华视为正的事，只是没有全心去做。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 24:25–26; 列王纪下 14:5–22; 创世记 9:5–6"> 他巩固王位后，立即处死了杀他父王的臣仆，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 24:16; 以西结书 18:20; 列王纪下 14:5–6"> 但没有处死他们的孩子，好遵行耶和华在摩西律法书中的吩咐：“不可因孩子犯罪而处死父亲，也不可因父亲犯罪而处死孩子。各人要自负罪责。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记24:16。">a</a></sup></span>
</div>
</div>

## 与西珥人交战

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 1:3; 历代志下 17:14–18; 历代志下 11:1"> 亚玛谢召集犹大人，按着犹大和便雅悯宗族设立千夫长和百夫长，并统计二十岁以上、能使用盾牌矛枪且有作战能力的精兵，共有三十万人。</span>
<span className="v" id="v6" data-v="6"> 他又用六万八千两银子从以色列雇来十万精兵。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 19:2; 列王纪上 12:28; 何西阿书 9:13"> 一位上帝的仆人来对他说：“王啊，不要让以色列的军队与你同去，因为耶和华不与以色列，不与以法莲人同在。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:11; 历代志下 20:6; 腓立比书 4:19"> 你若一定要去，即使你奋勇争战，上帝也必使你败在敌人面前，因为上帝有能力帮助，也有能力倾覆。”</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 10:22; 申命记 8:18"> 亚玛谢问上帝的仆人：“我付给以色列军队的六万八千两银子怎么办？”上帝的仆人回答说：“耶和华能赐给你更多银子。”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 12:24; 撒母耳记下 19:43; 箴言 29:22"> 于是，亚玛谢解散从以法莲雇来的军队，让他们回家去。他们非常恼怒犹大人，怒气冲冲地回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:7; 诗篇 60:1; 撒母耳记下 8:13"> 亚玛谢鼓起勇气，率领本国军队去盐谷，杀了一万西珥人，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 20:10; 历代志上 20:3; 撒母耳记下 12:31"> 又把生擒的一万人带到山崖上推下去摔得粉身碎骨。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 8:5; 列王纪上 16:29; 列王纪上 9:17"> 可是，那些被亚玛谢遣返、不许一同出征的以色列军队侵入从撒玛利亚到伯·和仑一带的犹大各城，杀了三千人，抢了大批财物。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:23; 申命记 7:25; 申命记 7:5"> 亚玛谢杀败以东人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以东人又称西珥人。">b</a></sup>后，带回了西珥人的神像，立为自己的神明，向它们祭拜烧香。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 96:5; 历代志下 25:11–12; 历代志下 25:7"> 因此，耶和华向亚玛谢发怒，祂派一个先知去见他，说：“这些神明既然不能从你手中救自己的人民，你为什么还要祭拜它们呢？”</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 18:20–21; 耶利米书 29:26; 历代志下 18:25"> 先知正说话的时候，王就说：“住口！我们立你做王的谋士了吗？你要自取灭亡吗？”先知便不再说什么，只说：“我知道上帝已决定要毁灭你，因为你做了这事，不听我的忠告。”</span>
</div>
</div>

## 与以色列交战

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:8–14; 历代志下 25:13; 箴言 20:3"> 犹大王亚玛谢与群臣商议后，就派人对耶户的孙子、约哈斯的儿子、以色列王约阿施说：“来，我们战场上见。”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 9:8–15; 列王纪上 4:33; 诗篇 80:13"> 以色列王约阿施派人回复犹大王亚玛谢说：“黎巴嫩的蒺藜派使者去对黎巴嫩的香柏树说，‘将你女儿嫁给我儿子吧。’后来黎巴嫩的一只野兽经过，把那蒺藜践踏在脚下。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:16; 历代志下 32:25; 箴言 18:6"> 你打败了以东人就趾高气扬。你还是待在家里吧，何必惹祸上身，使你和犹大一同灭亡呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志下 22:7; 列王纪上 12:15; 彼得前书 2:8"> 但亚玛谢不理会他的劝告。原来这事出于上帝，要把他们交在约阿施手中，因为他们求告以东的神明。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19–20; 撒母耳记上 6:9; 约书亚记 21:16"> 于是，以色列王约阿施起兵攻打犹大王亚玛谢，两王会战于犹大的伯·示麦。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 4:10; 历代志下 28:5–6; 列王纪上 22:36"> 犹大人被以色列人打败，兵将都各自逃回家去了。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:17; 尼希米记 8:16; 历代志下 26:9"> 以色列王约阿施在伯·示麦擒获约哈斯的孙子、约阿施的儿子犹大王亚玛谢，把他带到耶路撒冷，又拆毁从以法莲门到角门约一百八十米长的耶路撒冷城墙，</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 26:15; 历代志下 12:9; 列王纪下 14:14"> 抢走上帝殿中俄别·以东看守的所有金银和器皿，以及王宫里的财宝，并带着人质返回撒玛利亚。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪下 14:17–22"> 约哈斯的儿子以色列王约阿施死后，约阿施的儿子犹大王亚玛谢又活了十五年。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 20:34; 列王纪下 14:15"> 亚玛谢其他的事自始至终都记在《犹大与以色列列王史》上。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 24:25; 约书亚记 10:31; 列王纪下 14:19"> 亚玛谢背弃耶和华后，耶路撒冷有人谋反，他就逃到拉吉，但叛党派人追到那里杀了他。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 14:20"> 有人用马将他的尸体驮回耶路撒冷，葬在犹大城他的祖坟里。</span>
</div>
</div>

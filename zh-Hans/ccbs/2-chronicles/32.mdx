## 希西迦加强防御

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:13–37; 列王纪下 17:6; 历代志下 20:1–2"> 在希西迦忠心地办好这些事以后，亚述王西拿基立起兵入侵犹大，围攻各坚城，企图攻占这些城。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王纪下 12:17"> 希西迦见西拿基立决意要攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就与众官员和将领商议，决定截断城外的水源，众人也都赞成。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 32:30; 列王纪下 18:9; 列王纪上 19:21"> 于是，他们召集大批民众，截断所有的水源和过境的溪流，不让亚述王得到充足的水。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:23; 列王纪上 9:24; 列王纪下 25:4"> 希西迦发愤图强，修筑所有被毁坏的城墙，在上面建造城楼，在城外加建一道墙，并在大卫城的米罗加强防御，制造许多兵器和盾牌。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 40:2; 历代志下 30:22; 尼希米记 8:16"> 他委任将领管理民众，将他们全部召集在城门的广场上，训勉他们说：</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 6:16; 罗马书 8:31; 以弗所书 6:10"> “你们要刚强勇敢，不要在亚述王和他的大军面前恐惧惊慌，因为与我们同在的比与他同在的更有能力。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 17:5; 历代志下 20:17; 以赛亚书 41:10"> 那与他同在的只是血肉之躯，与我们同在的却是我们的上帝耶和华，祂必帮助我们，为我们作战。”众人因犹大王希西迦的这番话而得到鼓舞。</span>
</div>
</div>

## 亚述恐吓耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:17; 约书亚记 10:31; 以赛亚书 36:2"> 之后，亚述王西拿基立率领全军围攻拉吉，同时派遣臣仆到耶路撒冷城，对犹大王希西迦和城中所有的犹大人说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:19; 以赛亚书 36:4"> “亚述王西拿基立这样说，‘你们仍然留在被困的耶路撒冷，究竟倚仗什么呢？</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:43; 诗篇 11:1–3; 以赛亚书 36:18"> 希西迦说你们的上帝耶和华会从亚述王手中拯救你们，难道他不是哄骗你们，要叫你们饿死渴死吗？</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 31:1; 申命记 12:13–14; 申命记 12:26–27"> 这希西迦不是拆除了耶和华的丘坛和祭坛，吩咐犹大和耶路撒冷的人必须在一个祭坛前敬拜并在上面烧香吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:33–35; 以赛亚书 44:8–10; 但以理书 4:30"> 难道你们不知道我和我的祖先怎样对付列国吗？列国有哪个神明能从我手中救它的国家呢？</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 10:11–12; 出埃及记 15:9–11; 以赛亚书 42:8"> 我祖先所灭的列国有哪个神明能从我手中救它的国民呢？难道你们的上帝能从我手中救你们吗？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 5:2; 但以理书 3:15; 以赛亚书 36:18"> 所以，不要让希西迦欺骗、迷惑你们，也不要相信他！任何民族或国家的神明都不能从我和我祖先手中救它的人民，何况你们的上帝呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 73:9; 约翰福音 15:21; 约伯记 15:25–26"> 亚述王的臣仆还用别的话毁谤耶和华上帝和祂的仆人希西迦。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:14; 列王纪下 19:12; 以赛亚书 37:28–29"> 西拿基立还写信侮辱以色列的上帝耶和华说：“列邦的神明既然都不能从我手中救自己的人民，希西迦的上帝也不例外。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 17:10; 列王纪下 18:26–28; 撒母耳记上 17:26"> 亚述王的臣仆用希伯来语大声向城墙上的耶路撒冷人喊话，威吓他们，使他们惧怕，好攻取城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 19:18; 以赛亚书 2:8; 耶利米书 32:30"> 他把耶路撒冷的上帝与世间人手所造的神像相提并论。</span>
</div>
</div>

## 耶和华拯救耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 91:14–15; 以赛亚书 37:14–20; 历代志下 14:11"> 于是，希西迦王和亚摩斯的儿子以赛亚先知向天上的上帝呼求祷告。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 37:36–38; 诗篇 76:5; 诗篇 18:50"> 耶和华就差遣一个天使进入亚述王营中，灭了所有的勇士、官长和将领。西拿基立只好满脸羞愧地返回自己的国家。一天，他去自己的神庙时，他的几个亲生儿子用刀杀了他。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 31:4–5; 诗篇 18:48–50; 帖撒罗尼迦后书 3:5"> 这样，耶和华从亚述王西拿基立及一切仇敌手中拯救了希西迦和耶路撒冷的居民，使他们四境平安。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 17:5; 马太福音 2:11; 历代志下 1:1"> 许多人带着祭物到耶路撒冷献给耶和华，也带许多名贵的礼物送给犹大王希西迦。此后，希西迦受到各国的敬重。</span>
</div>
</div>

## 希西迦的疾病和骄傲

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 38:1–8; 列王纪下 20:1–11; 以赛亚书 38:21–22"> 那时，希西迦病危，他向耶和华祈求。耶和华应允了他，赐给他一个征兆。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 24:18; 历代志下 26:16; 历代志下 32:31"> 希西迦却没有为他所蒙的恩典而感谢上帝，因为他心中骄傲。因此，上帝的烈怒临到他、犹大和耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 26:18–19; 历代志下 34:27–28; 历代志下 33:12"> 后来希西迦和耶路撒冷的居民发觉自己心里骄傲，就谦卑下来。因此，在希西迦有生之年，耶和华的烈怒没有临到他们。</span>
</div>
</div>

## 希西迦的财富和尊荣

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 27:25–31; 历代志下 1:12; 箴言 10:22"> 希西迦极有财富和尊荣。他建造库房来存放他的金、银、宝石、香料、盾牌和各种珍宝，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 7:8; 历代志下 26:10; 列王纪上 4:26"> 又建造仓库来贮藏谷物、新酒和新油，并为各类牲畜盖棚立圏。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:12; 箴言 10:22; 撒母耳记上 2:7"> 他为自己建造城邑，并且拥有大批的牛羊，因为上帝赐他极多的财富。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:33; 以赛亚书 22:9–11; 诗篇 1:1–3"> 他截断基训的上泉，将水引到大卫城的西边。希西迦凡事亨通。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 8:2; 箴言 17:3; 创世记 22:1"> 然而，当巴比伦的使者来见他，询问他有关这地方发生的奇迹时，上帝就让希西迦自行处理，为要试验他，好知道他内心如何。</span>
</div>
</div>

## 希西迦逝世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 36:1–22; 列王纪下 18:1–20; 历代志下 31:20–21"> 希西迦其他的事和忠信的作为都记在亚摩斯的儿子以赛亚先知的《启示书》上和《犹大和以色列列王史》上。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王纪上 1:21; 历代志下 16:14"> 希西迦与祖先同眠后，葬在大卫子孙墓地的高处。所有犹大人和耶路撒冷的居民都向他致哀。他儿子玛拿西继位。</span>
</div>
</div>

## 犹大王玛拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 21:1–18; 历代志上 3:13; 以赛亚书 3:12"> 玛拿西十二岁登基，在耶路撒冷执政五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:3; 申命记 18:9; 列王纪下 17:11"> 他做耶和华视为恶的事，效法耶和华在以色列人面前赶走的外族人的可憎行径。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 16:21; 申命记 17:3; 历代志下 31:1"> 他重建他父亲希西迦拆毁的丘坛，为巴力筑造祭坛，制造亚舍拉神像，并祭拜和供奉天上的万象。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 7:16; 列王纪上 8:29; 申命记 12:11"> 耶和华曾指着祂的殿说：“我的名必永远在耶路撒冷，”他却在耶和华的殿内建造异教的祭坛。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 4:9; 耶利米书 32:34–35; 以西结书 8:7–18"> 他在耶和华殿的两个院子里为天上万象建造祭坛。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 18:21; 利未记 20:6; 历代志下 28:3"> 他还在欣嫩子谷把自己的儿子烧死，献作祭物。他行邪术、占卜、观兆，求问灵媒和巫师，做了许多耶和华视为恶的事，惹耶和华发怒。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 33:4; 历代志下 7:16; 列王纪上 11:13"> 他雕刻神像，放在上帝的殿中。关于这殿，上帝曾对大卫和他儿子所罗门说：“我从以色列各支派中选择了这殿和耶路撒冷，我的名要永远立在这里。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:31–1; 利未记 8:36"> 只要以色列人谨遵我借着摩西颁给他们的一切法度、律例和典章，我就不再把他们从我赐给他们祖先的土地上赶走。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 24:3–4; 箴言 29:12; 历代志下 33:2"> 玛拿西诱使犹大人和耶路撒冷的居民作恶，比耶和华在以色列人面前所毁灭的各族更严重。</span>
</div>
</div>

## 玛拿西悔改

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 耶利米书 44:4–5; 撒迦利亚书 1:4"> 耶和华警告玛拿西和他的百姓，他们却不肯听从。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 28:36; 历代志下 36:6; 尼希米记 9:32"> 所以，耶和华就差遣亚述王的将领来攻击他们，他们捉住玛拿西，把他用钩子钩着、用铜链锁着押往巴比伦。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 10:3; 诗篇 50:15; 历代志下 32:26"> 在困苦中，玛拿西祈求他的上帝耶和华的帮助，并且在他祖先的上帝面前极其谦卑。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 5:20; 但以理书 4:25; 马太福音 7:7–8"> 耶和华应允他的祷告，垂听他的恳求，使他返回耶路撒冷继续做王。玛拿西这才明白耶和华是上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 27:3; 列王纪上 1:33; 尼希米记 3:3"> 这事以后，玛拿西重建大卫城的外墙，从谷中基训泉的西边直到鱼门口，环绕俄斐勒，筑高城墙。他又派将领驻扎犹大各坚城。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 33:3–7; 何西阿书 14:1–3; 列王纪下 21:7"> 玛拿西将偶像和外族人的神像从耶和华的殿中除去，又把他在圣殿山和耶路撒冷筑造的一切祭坛全部拆掉，扔在城外。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 14:4; 列王纪上 18:30; 历代志下 33:9"> 他重建耶和华的祭坛，在上面献平安祭和感恩祭，又吩咐犹大人事奉以色列的上帝耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 32:12; 列王纪上 22:43; 列王纪下 15:4"> 然而，众人仍然在丘坛献祭，只是献给他们的上帝耶和华。</span>
</div>
</div>

## 玛拿西逝世

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:19; 历代志下 33:12–13; 阿摩司书 7:12"> 玛拿西其他的事、他向上帝的祷告和先见奉以色列的上帝耶和华的名对他说的话，都记在《以色列列王史》上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:11; 约翰一书 1:9; 但以理书 5:22"> 他的祷告，上帝的答复，他在谦卑下来之前的罪恶和不忠，他在哪里修筑丘坛以及设立亚舍拉神像和其他偶像的事，都记在《先知书》<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="《先知书》或译《何赛的书》。">a</a></sup>上。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:10; 历代志下 32:33; 列王纪下 21:18–25"> 玛拿西与祖先同眠后，葬在宫内，他儿子亚们继位。</span>
</div>
</div>

## 亚们做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:13–15; 路加福音 12:19–20; 历代志下 33:1"> 亚们二十二岁登基，在耶路撒冷执政两年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 21:20; 以西结书 20:18; 列王纪下 21:1–11"> 亚们像他父亲玛拿西一样做耶和华视为恶的事。他祭拜和供奉他父亲玛拿西制造的一切偶像。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 33:12; 历代志下 33:19; 耶利米书 7:26"> 可是，亚们没有像他父亲玛拿西一样在耶和华面前谦卑下来。相反，他犯的罪越来越多。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:22; 历代志下 25:27–28; 历代志下 24:25–26"> 他的臣仆谋反，在王宫里杀了他。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 35:31; 历代志下 34:1; 历代志下 36:1"> 民众杀死那些背叛亚们王的人，让他儿子约西亚接续他做王。</span>
</div>
</div>

## 米该雅先知警告亚哈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 17:5; 历代志下 21:6; 历代志下 19:2"> 约沙法极有财富和尊荣，他与亚哈结为姻亲。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 9:1; 历代志下 19:2; 列王纪上 1:9"> 几年后，约沙法下到撒玛利亚拜访亚哈。亚哈宰了很多牛羊款待他和他的随从，又劝他与自己一起去攻打基列的拉末。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 22:4; 列王纪下 3:7; 约翰二书 1:10–11"> 以色列王亚哈对犹大王约沙法说：“你愿意跟我一起去攻打基列的拉末吗？”约沙法回答说：“你我不分彼此，我的民就是你的民，我必与你同去。”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 21:2; 撒母耳记下 5:19; 撒母耳记下 2:1"> 约沙法又对以色列王说：“你要先求问耶和华。”</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 4:3; 弥迦书 3:11; 耶利米书 28:1–17"> 于是，以色列王召来四百名先知，问他们：“我该去攻打基列的拉末吗？”他们说：“去吧，上帝必把那城交在王手中。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 22:7–9; 列王纪下 3:11–13"> 但约沙法问：“这里没有耶和华的先知供我们求问吗？”</span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 5:10; 弥迦书 2:7; 列王纪上 21:20"> 以色列王回答说：“还有一个人，是音拉的儿子米该雅，我们可以托他求问耶和华。可是我厌恶他，因为他给我的预言都是有凶无吉。”约沙法说：“王不要这样说。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 22:9; 以赛亚书 39:7; 历代志下 18:25–26"> 以色列王召来一名内侍，说：“你快把音拉的儿子米该雅带来。”</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 14:9; 但以理书 7:9; 马太福音 19:28"> 以色列王和犹大王约沙法身穿朝服，坐在撒玛利亚城门前麦场的宝座上，众先知都在他们面前说预言。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 23:17; 撒迦利亚书 1:18–21; 耶利米书 28:2–3"> 基拿拿的儿子西底迦造了两只铁角，说：“耶和华这样说，‘你必用这铁角抵亚兰人，直到毁灭他们。’”</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 24:24–25; 历代志下 18:33–34; 犹大书 1:16"> 所有的先知也都预言说：“去攻打基列的拉末吧，一定得胜，耶和华必将那城交在王的手中。”</span>
<span className="v" id="v12" data-v="12" data-xref="弥迦书 2:6; 诗篇 10:11; 弥迦书 2:11"> 去召米该雅的使者对米该雅说：“众先知都异口同声地向王说吉言，你也像他们一样说些吉言吧。”</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 22:35; 民数记 24:13; 民数记 22:18–20"> 米该雅回答说：“我凭永活的耶和华起誓，我的上帝对我说什么，我就说什么。”</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:15; 耶利米哀歌 4:21; 阿摩司书 4:4–5"> 米该雅来到王面前，王就问他：“米该雅啊，我们该不该去攻打基列的拉末？”米该雅回答说：“上去攻打吧，一定得胜，敌人必被交在你们手中。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 26:63; 撒母耳记上 14:24; 列王纪上 22:16"> 王却说：“我要你起誓多少次，你才肯奉耶和华的名对我说实话呢？”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:36; 以西结书 34:5–6; 民数记 27:17"> 米该雅说：“我看见以色列人都四散在山上，好像没有牧人的羊群一样。耶和华说，‘这些人没有主人，让他们各自平安地回家去吧。’”</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 18:7; 列王纪上 22:18; 箴言 29:1"> 以色列王对约沙法说：“我不是告诉过你吗？他给我的预言都是有凶无吉。”</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 7:9; 以赛亚书 6:1–5; 列王纪上 22:19–23"> 米该雅说：“你要听耶和华的话。我看见耶和华坐在宝座上，众天军侍立在祂左右。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 14:9; 历代志下 25:19; 箴言 11:5"> 耶和华说，‘谁愿意去引诱以色列王亚哈到基列的拉末去送死呢？’众天军议论纷纷。</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:6; 哥林多后书 11:13–15; 哥林多后书 11:3"> 后来，有一个灵站出来对耶和华说他愿意去。耶和华问他用什么方法，</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:44; 列王纪上 22:21–22; 约翰一书 4:6"> 他说，‘我要去做谎言之灵，进入他众先知的口中。’耶和华说，‘你必成功诱骗他，就这样做吧。’</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:14; 以西结书 14:9; 约伯记 12:16"> 现在，耶和华已经把谎言之灵放进你这些先知口中，耶和华已决意降祸给你。”</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 14:65; 耶利米书 20:2; 历代志下 18:10"> 基拿拿的儿子西底迦听了米该雅的话就上前打他的脸，说：“耶和华的灵怎会离开我向你说话呢？”</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 29:21–22; 以赛亚书 26:20; 耶利米书 28:16–17"> 米该雅说：“你躲进密室的那天就知道了。”</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 18:8; 历代志下 34:8; 耶利米书 38:6–7"> 以色列王下令说：“把米该雅交给亚们总督和约阿施王子，</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 16:10; 诗篇 80:5; 路加福音 23:2"> 告诉他们，‘王说，要把这人关在监牢，只给他一点饼和水，直到我平安回来。’”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:45–46; 阿摩司书 9:10; 弥迦书 1:2"> 米该雅说：“你若能平安回来，耶和华就没有借着我说话。”他又说：“众民啊，你们都要记住我的话。”</span>
</div>

## 亚哈之死

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 22:29–33"> 以色列王和犹大王约沙法出兵攻打基列的拉末。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 28:8; 耶利米书 23:24; 箴言 26:25"> 以色列王对约沙法说：“我要改装上阵，你就穿王袍吧。”以色列王就改装上阵。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 19:11; 申命记 1:17; 列王纪上 20:42"> 亚兰王已经吩咐战车长不要跟对方的大小军兵交锋，只攻击以色列王。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:14; 诗篇 118:13; 哥林多后书 1:9–10"> 战车长看见约沙法，以为他就是以色列王，便转过来攻击他。约沙法高声喊叫，耶和华上帝就帮助他，使敌人离开他。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 22:33"> 战车长见他不是以色列王，便不再追杀他。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 35:23; 撒母耳记下 15:11; 列王纪上 22:34–35"> 有人随手放了一箭，射进了以色列王的铠甲缝中。王对驾车的说：“调转车头拉我离开战场吧，我受了重伤。”</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 13:21; 历代志下 18:27; 箴言 28:17"> 那天的战事非常激烈，以色列王勉强支撑着站在车上迎战亚兰人，直到黄昏。太阳下山的时候，他就死了。</span>

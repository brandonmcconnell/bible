## 犹大王约沙法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 15:24; 以弗所书 6:10; 马太福音 1:8"> 亚撒的儿子约沙法继位，他发愤图强对抗以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 15:8; 历代志下 11:5; 历代志下 11:11–12"> 他派兵驻守犹大所有的坚城，又把守备军安置在犹大和他父亲亚撒所征服的以法莲各城邑。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 22:2; 以赛亚书 41:10; 提摩太后书 4:22"> 耶和华与约沙法同在，因为他效法他祖先大卫起初所行的，没有寻求巴力，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 12:28; 路加福音 1:6; 帖撒罗尼迦前书 2:12"> 只寻求他父亲的上帝，遵行祂的诫命，没有效法以色列人的行为。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 18:1; 马太福音 6:33; 诗篇 127:1"> 因此，耶和华巩固他的王位，所有的犹大人都向他进贡，他极有财富和尊荣。</span>
<span className="v" id="v6" data-v="6" data-xref="何西阿书 14:9; 历代志下 15:17; 历代志下 20:33"> 他专心遵行耶和华的道，铲除犹大境内的丘坛和亚舍拉神像。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 35:3; 尼希米记 8:7–8; 传道书 12:9–10"> 他在执政第三年委派官员便·亥伊勒、俄巴底、撒迦利雅、拿坦业和米该亚到犹大各城教导民众，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:1–6; 历代志下 19:8; 玛拉基书 2:7"> 与他们同去的还有利未人示玛雅、尼探雅、西巴第雅、亚撒黑、示米拉末、约拿单、亚多尼雅、多比雅和驼·巴多尼雅，还有祭司以利沙玛和约兰。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 5:46; 罗马书 3:2; 使徒行传 8:40"> 他们带着耶和华的律法书，走遍犹大各城镇教导民众。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 14:14; 出埃及记 15:14–16; 箴言 16:7"> 犹大周围的列国都惧怕耶和华，不敢与约沙法争战。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 26:8; 历代志下 9:14; 撒母耳记下 8:2"> 一些非利士人向他进贡礼物和银子，阿拉伯人也给他送来公绵羊和公山羊各七千七百只。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 历代志下 32:5"> 约沙法日渐强大，在犹大境内修建堡垒和储货城，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 27:25–31; 历代志下 26:10–15"> 在犹大各城储备大量物资。他又在耶路撒冷屯驻精兵，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 11:1; 创世记 15:5; 民数记 1:18"> 其人数按宗族记在下面。<br />犹大族有千夫长押拿，率领精兵三十万；</span>
<span className="v" id="v15" data-v="15"> 其次是千夫长约哈难，率领军兵二十八万；</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 5:9; 士师记 5:2; 历代志上 29:9"> 其次是自愿事奉耶和华的细基利的儿子亚玛斯雅，率领精兵二十万。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 14:8; 撒母耳记下 1:21–22"> 便雅悯族有勇士以利雅大，率领手持弓箭和盾牌的军兵二十万；</span>
<span className="v" id="v18" data-v="18"> 其次是约萨拔，率领武装好的军兵十八万。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 17:2; 历代志下 11:12; 历代志下 11:23"> 以上都是服侍王的军兵，不包括王派去驻守犹大各坚城的军兵。</span>
</div>
</div>

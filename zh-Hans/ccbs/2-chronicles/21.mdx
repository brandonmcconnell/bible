## 犹大王约兰

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:6; 历代志下 23:2; 历代志下 24:5"> 亚撒利雅、耶歇、撒迦利雅、亚撒列夫、米迦勒和示法提雅是约兰的兄弟、犹大王约沙法的儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:23; 申命记 21:15–17; 历代志下 11:5"> 他们的父亲赐给他们许多金银财宝和犹大境内的坚城，但将王位赐给了约兰，因为他是长子。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:5; 历代志下 21:17; 创世记 4:8"> 约兰登基，巩固了王位后，就用刀杀了他所有的兄弟和一些以色列的首领。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 8:17–22"> 约兰三十二岁登基，在耶路撒冷执政八年。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 18:1; 列王纪上 12:28–30; 列王纪下 8:18"> 他与亚哈家一样步以色列诸王的后尘，因为他娶了亚哈的女儿为妻，做耶和华视为恶的事。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 11:36; 诗篇 132:17–18; 撒母耳记下 7:12–17"> 但耶和华不愿毁灭大卫家，因为祂曾与大卫立约，应许让大卫和他的子孙永远做王。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 21:10; 历代志下 20:22–23; 创世记 27:40"> 约兰执政期间，以东人脱离犹大的统治，自己立王。</span>
<span className="v" id="v9" data-v="9"> 约兰率将领及所有战车前去讨伐，结果被以东人包围。但他们乘夜突出重围。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 15:2; 耶利米书 2:13; 历代志下 13:10"> 以东人至今仍脱离犹大的统治，立拿人也在那时候叛变了，因为约兰背弃了他祖先的上帝耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 20:5; 列王纪上 11:7; 利未记 17:7"> 约兰在犹大的山上修建丘坛，引诱耶路撒冷的居民与假神苟合，使犹大人步入歧途。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 14:2–5; 历代志下 17:3–4; 列王纪下 2:1"> 以利亚先知写信给约兰说：“你祖先大卫的上帝耶和华说，‘你没有效法你父亲约沙法，也没有效法犹大王亚撒，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 21:4; 历代志下 21:11; 列王纪上 16:30–33"> 而是重蹈以色列诸王的覆辙，与亚哈家一样，引诱犹大人和耶路撒冷的居民与假神苟合，还杀了比你好的兄弟。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 26:21; 出埃及记 20:5; 何西阿书 5:11"> 因此，耶和华要降大灾祸给你的人民、儿女、妻妾及一切所有。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 21:18–19; 使徒行传 1:18; 申命记 28:67"> 你必患严重的肠病，并且日益加重，直到你的肠子掉出来。’”</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 17:11; 历代志下 33:11; 列王纪上 11:14"> 耶和华驱使非利士人和古实附近的阿拉伯人攻打约兰。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 22:1; 历代志下 22:6; 历代志下 25:23"> 他们起兵攻打犹大，侵入境内，掳走了王宫里的所有财物以及约兰的儿子和妻妾，只留下他最小的儿子约哈斯。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 21:15; 使徒行传 12:23; 列王纪下 9:29"> 这事以后，耶和华使约兰患了无法医治的肠病，</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 16:14; 耶利米书 34:5"> 日益加重，两年后肠子掉了出来，他痛苦地死去。他的百姓没有像对待他祖先那样向他焚火致哀。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 22:18; 历代志下 28:27; 耶利米书 22:28"> 约兰三十二岁登基，在耶路撒冷执政八年。他死后无人向他致哀。他葬在大卫城，但没有葬在王陵里。</span>

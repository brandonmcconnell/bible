## 犹大王乌西雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 22:1; 马太福音 1:8–9; 历代志下 33:25"> 全体犹大人立十六岁的乌西雅为王，继承他父亲亚玛谢的王位。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 16:6; 历代志下 25:28; 历代志下 25:23"> 亚玛谢王与祖先同眠后，乌西雅为犹大收复了以禄城，并重新修建。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 15:2–3; 阿摩司书 1:1; 何西阿书 1:1"> 乌西雅十六岁登基，在耶路撒冷执政五十二年。他母亲叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 25:2"> 他事事效法他父亲亚玛谢，做耶和华视为正的事。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 15:2; 历代志下 24:2; 历代志上 22:13"> 撒迦利亚在世之日，乌西雅寻求上帝，撒迦利亚教导他敬畏上帝。当他寻求耶和华时，上帝就使他亨通。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 14:29; 撒母耳记上 5:6; 撒母耳记上 5:1"> 他出兵攻打非利士人，把迦特、雅比尼和亚实突的城墙夷平后，在亚实突境内及非利士人的其他地区兴建城邑。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 21:16; 历代志上 5:20; 历代志下 14:11"> 上帝帮助他攻打非利士人和住在姑珥·巴力的阿拉伯人及米乌尼人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:2; 历代志下 17:11; 创世记 19:38"> 亚扪人向他进贡，乌西雅的名声传到埃及，因他非常强大。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:13; 历代志下 25:23; 列王纪下 14:13"> 乌西雅在耶路撒冷的角门、谷门和城墙拐角的地方建造城楼，并加固城楼，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 26:18–21; 以赛亚书 29:17; 列王纪下 3:4"> 又在旷野建造瞭望塔，挖了许多水井，因为他在高原和平原有很多牲畜。他雇人在山区和沃野为他耕种田地和照料葡萄园，因为他喜爱农耕。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 5:2"> 乌西雅有支可以随时列队出战的军兵，由书记耶利和官长玛西雅召集，归王的将军哈拿尼雅统领。</span>
<span className="v" id="v12" data-v="12"> 率领战士的族长有两千六百名，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 25:5; 历代志下 14:8; 历代志下 11:1"> 他们手下有三十万七千五百精兵，帮助王攻打敌人。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:16; 撒母耳记上 17:49"> 乌西雅为全军备有盾牌、矛枪、头盔、铠甲、弓箭和投石器用的石头，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 31:4; 马太福音 4:24; 历代志下 2:7"> 又让巧匠在耶路撒冷设计和制造兵器，安放在城楼和角楼上，用来发射弓箭和大石头。乌西雅威名远扬，因为他得到非常的帮助，极其强盛。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 32:25; 历代志下 25:19; 箴言 16:18"> 乌西雅强盛后，便心高气傲，以致走向灭亡。他干犯他的上帝耶和华，擅自进入耶和华的殿在香坛上烧香。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:10; 历代志上 26:6; 历代志上 12:28"> 祭司亚撒利雅率领八十位耶和华勇敢的祭司跟着进殿，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 30:7–8; 民数记 18:7; 耶利米书 13:18"> 阻止乌西雅王，说：“乌西雅啊，给耶和华烧香不是你可以做的事，而是承受圣职做祭司的亚伦子孙的事。离开圣所吧！你已干犯耶和华上帝，必不能从祂那里得荣耀。”</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 12:10; 历代志下 25:16; 列王纪下 5:25–27"> 手拿香炉要烧香的乌西雅大怒，正当他在耶和华殿里的香坛旁向众祭司发怒的时候，他额头上突然患了麻风病。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 28:22; 以斯帖记 6:12; 利未记 14:34"> 亚撒利雅大祭司和众祭司见状就催促他出殿，他急忙出去了，因为耶和华降灾给他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 13:46; 民数记 12:15; 列王纪下 7:3"> 乌西雅王到死一直有麻风病。他被隔离在别的宫中，不得进耶和华的殿。他儿子约坦管理王室，治理国家。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:1; 以赛亚书 6:1; 历代志下 9:29"> 乌西雅其他的事自始至终都是亚摩斯的儿子以赛亚先知记载的。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 28:27; 历代志下 21:20; 历代志下 26:18"> 乌西雅与祖先同眠后，葬在他祖坟附近一个王室的坟场，因为他有麻风病。他儿子约坦继位。</span>

## 犹大王约西亚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 1:1; 耶利米书 1:2; 历代志下 33:25"> 约西亚八岁登基，在耶路撒冷执政三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:2; 约书亚记 1:7; 列王纪下 22:2"> 他做耶和华视为正的事，效法他祖先大卫，不偏不离。</span>
</div>
</div>

## 约西亚清除偶像

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:22; 历代志下 15:2; 箴言 8:17"> 他执政第八年，虽然还年幼，却开始寻求他祖先大卫的上帝。他执政第十二年，开始清除犹大和耶路撒冷的丘坛、亚舍拉神像、雕刻和铸造的偶像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 32:20; 利未记 26:30; 列王纪下 23:4–6"> 众人在他面前拆毁巴力的祭坛，他砍掉上面高高的香坛，又把亚舍拉神像及雕刻和铸造的偶像打碎并磨成粉末，撒在祭拜它们之人的坟墓上，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:2; 耶利米书 3:10; 民数记 35:33"> 把它们祭司的骸骨放在它们的坛上焚烧。这样，他洁净了犹大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 13:20–21; 以赛亚书 7:25; 历代志下 30:1"> 约西亚还在玛拿西、以法莲、西缅，远至拿弗他利的各城邑及其周围的荒废之地做了同样的事情。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:1; 申命记 9:21; 历代志下 34:1"> 他拆毁祭坛和亚舍拉神像，把偶像磨成粉末，砍掉以色列境内所有的香坛，然后回到耶路撒冷。</span>
</div>
</div>

## 发现律法书

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:16; 历代志上 18:15; 耶利米书 29:25"> 约西亚执政第十八年，在洁净国土和圣殿以后，他差遣亚萨利雅的儿子沙番、耶路撒冷的总督玛西雅和约哈斯做史官的儿子约亚，负责整修他的上帝耶和华的殿。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 30:18; 历代志下 30:10; 历代志下 35:8"> 他们到希勒迦大祭司那里，把献给上帝殿的银子交给他。这银子是守殿门的利未人从玛拿西人和以法莲人，所有剩下的以色列人，所有的犹大人和便雅悯人，以及耶路撒冷的居民那里收来的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 12:11–12; 以斯拉记 3:7; 列王纪下 22:5–6"> 他们把银子交给负责修理耶和华殿的督工，由他们付给修理耶和华殿的工人，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 33:4–7; 历代志下 33:22"> 就是木匠和瓦匠，来购买凿好的石头、木架和栋梁，修缮犹大诸王失修的建筑。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 12:15; 历代志上 23:5; 列王纪下 22:7"> 这些人都忠诚地工作。他们的督工是利未人米拉利的子孙雅哈和俄巴底，哥辖的子孙撒迦利亚和米书兰。其他精通乐器的利未人</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:10; 历代志下 2:18; 耶利米书 8:8"> 负责监督搬运工人及做各种工作的人，还有一些利未人做书记、官员和殿门守卫。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 8:36; 诗篇 1:2; 利未记 10:11"> 他们把奉献到耶和华殿里的银子拿出来的时候，希勒迦祭司发现了摩西所传的耶和华的律法书。</span>
<span className="v" id="v15" data-v="15"> 希勒迦对沙番书记说：“我在耶和华的殿里发现了律法书。”希勒迦把书卷交给沙番。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 22:9–10; 耶利米书 36:20–21"> 沙番把书卷带到王那里，向王禀告说：“凡交给臣仆办的事，都在办理。</span>
<span className="v" id="v17" data-v="17"> 臣仆已经清空耶和华殿里的银子，交给督工和工人。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:46; 耶利米书 36:20–21; 申命记 17:19"> 沙番书记又对王说：“希勒迦祭司交给我一卷书。”沙番就在王面前诵读这书。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 申命记 28:3–68; 列王纪下 22:19"> 王听了律法书上的话，就撕裂衣服，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 22:12; 耶利米书 26:24; 耶利米书 40:9"> 吩咐希勒迦、沙番的儿子亚希甘、米迦的儿子亚比顿、沙番书记和王的臣仆亚撒雅：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 21:2; 以西结书 14:1–11; 历代志下 28:6"> “你们去为我及以色列和犹大的余民求问耶和华有关这书卷上的话。耶和华的烈怒已经临到我们身上，因为我们的祖先没有遵守耶和华的话，没有遵行这书卷上的一切吩咐。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及记 15:20; 列王纪下 22:14"> 于是，王派去的人跟着希勒迦去见女先知户勒妲，她是负责管理礼服的沙龙之妻。沙龙是哈斯拉的孙子、特瓦的儿子。户勒妲住在耶路撒冷第二区。他们向她说明来意，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 37:7–10; 耶利米书 21:3–7; 列王纪下 22:15–20"> 她对他们说：“以色列的上帝耶和华要你们回去告诉差你们来见我的人，</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–20; 约书亚记 23:16; 申命记 28:15–68"> 耶和华说，‘我要照在犹大王面前所读的那书上的一切咒诅，降灾难给这地方及这里的居民。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 7:20; 马可福音 9:43–48; 那鸿书 1:6"> 因为他们背弃我，给其他神明烧香，制造偶像惹我发怒，所以我的怒火要倾倒在这地方，绝不止息。’</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 34:23; 历代志下 34:21"> 你们告诉差你们来求问耶和华的犹大王，‘至于你所听见的那些话，以色列的上帝耶和华说，</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 32:26; 以西结书 9:4; 诗篇 34:18"> 因为你听到我对这地方及其居民的警告，便悔改，在我面前谦卑、撕裂衣服，向我哭泣，我才垂听你的祷告。这是我耶和华说的。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 39:8; 诗篇 37:37; 列王纪上 21:29"> 我会让你平安入土到你祖先那里，你不会看到我要降给这地方及这里居民的一切灾难。’”他们便回去禀告王。</span>
</div>
</div>

## 约西亚立约顺服上帝

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪下 23:1–3; 历代志下 30:2; 马可福音 14:8"> 于是，王派人召集犹大和耶路撒冷的所有长老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:7; 列王纪下 23:2; 历代志下 34:15"> 王与犹大人和耶路撒冷的居民、祭司和利未人等全体民众，不论贵贱，一同上到耶和华的殿。王把在耶和华殿中发现的约书读给他们听。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 23:16; 列王纪下 23:3; 列王纪下 11:14"> 王站在自己的位置上，在耶和华面前立约，要全心全意地跟随耶和华，遵从祂的一切诫命、法度和律例，履行约书上的规定。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 30:12; 耶利米书 3:10; 历代志下 14:4"> 他使耶路撒冷和便雅悯的人都遵行这约。于是，耶路撒冷的居民都遵行他们祖先的上帝的约。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 34:3–7; 约书亚记 24:31; 列王纪下 23:4–20"> 约西亚除去以色列境内所有的可憎之物，又吩咐所有住在以色列的人都事奉他们的上帝耶和华。约西亚在世时，他们都没有偏离他们祖先的上帝耶和华。</span>
</div>
</div>

## 耶何耶大立约阿施为犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 15:12; 列王纪下 11:4–20; 尼希米记 9:38"> 第七年，耶何耶大发愤图强，召来一些百夫长与他们立约。他们是耶罗罕的儿子亚撒利雅，约哈难的儿子以实玛利，俄备得的儿子亚撒利雅，亚大雅的儿子玛西雅，以及细基利的儿子以利沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:13–17; 历代志下 21:2; 历代志上 15:12"> 他们走遍犹大各城，把利未人和以色列的各族长召集到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 21:7; 撒母耳记下 7:12; 历代志下 6:16"> 全体会众到上帝的殿中与王立约。耶何耶大对他们说：“王的儿子当做王！这是耶和华对大卫子孙的应许。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:3–6; 历代志上 26:13–16; 路加福音 1:8–9"> 你们要这样做，在安息日值班的祭司和利未人要拨出三分之一的人把守各门，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 46:2–3; 使徒行传 3:2; 列王纪下 11:5–6"> 三分之一的人把守王宫，三分之一的人把守基址门，所有民众要留在耶和华殿的院子里。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 23:28–32; 列王纪下 11:6–7"> 只有祭司和供职的利未人可以进耶和华的殿，因为他们是圣洁的。其他人一律不准进殿。所有的人都要遵守耶和华的吩咐。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 3:38; 民数记 3:10; 列王纪下 11:8–9"> 利未人要手持兵器护卫在王周围。凡擅自进殿的，一律处死。无论王去哪里，你们都要紧随左右。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 11:9; 历代志上 24:1–26"> 于是，利未人和所有犹大人遵令而行，各自带来在安息日值班和休班的属下，因为耶何耶大祭司没有让他们休班。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 21:9; 撒母耳记下 8:7"> 耶何耶大祭司把上帝殿中大卫王的矛枪和大小盾牌交给百夫长。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:6; 历代志下 6:12; 列王纪下 11:11"> 耶何耶大安排众人手持兵器，从殿右到殿左，在祭坛和殿周围护卫王。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 10:24; 出埃及记 25:16; 列王纪下 11:12"> 耶何耶大及其众子领王子出来，给他戴上王冠，把约书交给他，膏立他为王。众人高呼：“愿王万岁！”</span>
</div>
</div>

## 亚她利雅被处死

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 11:13–16; 列王纪下 9:32–37"> 亚她利雅听到人们奔走称颂王的声音，便走进耶和华的殿，到众人那里。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:2; 历代志下 34:31; 列王纪下 9:23"> 她看见王站在门口的柱旁，百夫长和吹号的人侍立在王左右，众人都欢呼吹号，歌乐手用各种乐器带领众人歌唱颂扬，便撕裂衣服，喊道：“反了！反了！”</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 9:7; 列王纪下 11:8; 列王纪下 11:15"> 耶何耶大祭司认为不可在耶和华的殿里处死亚她利雅，便命令带兵的百夫长出来，对他们说：“把她带出去并用刀杀死所有跟随她的人。”</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 3:28; 耶利米书 31:40; 历代志下 22:10"> 他们抓住她，把她带到马匹进出王宫的入口，在那里杀了她。</span>
</div>
</div>

## 耶何耶大的改革

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:10; 尼希米记 9:38; 列王纪下 11:17"> 耶何耶大让民众和王与他一起立约，要做耶和华的子民。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:40; 列王纪下 10:25–28; 列王纪下 18:4"> 于是，民众出去拆毁了巴力庙，砸碎祭坛和偶像，在坛前杀了巴力的祭司玛坦。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 5:5; 民数记 28:1–31; 历代志下 29:25"> 耶何耶大照大卫的吩咐，让利未祭司负责耶和华殿里的事务。大卫曾吩咐利未祭司在耶和华的殿中司职，照摩西的律法向耶和华献燔祭，欢呼歌唱。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 26:1–32; 历代志上 9:22–24"> 耶何耶大还派门卫把守耶和华殿的各门，禁止一切不洁净的人入内。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:19; 列王纪下 15:35; 列王纪下 11:9–10"> 他率领百夫长、贵族、首领和全体民众护送王从耶和华的殿下来，经上门进入王宫，拥立王登上王位。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 11:20; 启示录 18:20; 启示录 19:1–4"> 民众都欢喜快乐，城里安定，因为亚她利雅已死在刀下。</span>
</div>
</div>

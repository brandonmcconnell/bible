## 预备建圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 5:5; 历代志上 22:10; 列王纪上 7:1"> 所罗门决定为耶和华的名建造殿宇，也为自己兴建王宫。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:18; 列王纪上 5:15–16"> 他征用七万名搬运工、八万名在山上凿石的匠人、三千六百名监工，</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 14:1; 撒母耳记下 5:11; 列王纪上 5:1–11"> 并传信给泰尔王希兰，说：“你曾运香柏木给我父亲建造王宫，请你也照样帮助我。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 30:7; 出埃及记 25:30; 历代志下 2:1"> 现在，我要为我的上帝耶和华的名建一座殿，我要把殿献给祂，在祂面前烧芬芳的香，经常献上供饼，在每天早晚、安息日、朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup>，以及我们的上帝耶和华所定的节期献上燔祭。这是以色列人永远当守的律例。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 16:25; 出埃及记 15:11; 诗篇 135:5"> 我要建造的殿宇极其宏伟，因为我们的上帝超越一切神明。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 66:1; 历代志下 6:18; 列王纪上 8:27"> 诸天尚且容不下祂，谁能为祂建造殿宇呢？我是谁，怎能为祂建造殿宇呢？我不过是建个向祂烧香的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 2:13–14; 历代志上 22:15–16; 出埃及记 31:3–5"> 现在，请你派一位巧匠来，他要懂得雕刻，会用金银铜铁铸造物品，会编织紫色、朱红色和蓝色的布，好与我父大卫在犹大和耶路撒冷所预备的巧匠一起工作。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:6; 列王纪上 10:11; 历代志下 9:10–11"> 也请你从黎巴嫩运些香柏木、松木和檀香木来，因为我知道你的仆人擅长砍伐黎巴嫩的树木。我会派人与你的仆人一起工作。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:8; 历代志下 2:5; 历代志下 7:21"> 我要建的殿宇非常宏伟，所以需要的木料非常多。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 5:11; 以斯拉记 7:22; 罗马书 13:7–8"> 我会供给你的伐木工人四百四十万升小麦、四百四十万升大麦、四十四万升酒和四十四万升油。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 10:9; 历代志下 9:8; 诗篇 72:17"> 泰尔王希兰写信给所罗门说：“耶和华爱祂的子民，所以立你做他们的王。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 33:6; 彼得前书 1:3; 启示录 4:11"> 创造天地的以色列的上帝耶和华当受称颂！祂赐给大卫王一个有智慧、谋略和悟性的儿子来为耶和华建殿，也为他自己建造王宫。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:16"> 现在，我派聪明能干的巧匠户兰去你那里。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:7; 出埃及记 31:3–4; 列王纪上 7:13–14"> 他的母亲是但支派的人，父亲是泰尔人。他精于雕刻和设计，善用金银铜铁和木石制造物品，又会编织细麻布和紫色、蓝色、朱红色的布。你可以让他与你的工匠和你父亲大卫的工匠一起工作。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 2:10; 列王纪上 5:11"> 现在，请我主把许诺的小麦、大麦、油和酒运给仆人。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:46; 列王纪上 5:8–9; 以斯拉记 3:7"> 我们会在黎巴嫩砍伐你需要的木材，扎成木筏，经海道运到约帕，你可以从那里将木材转运到耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 22:2; 列王纪上 5:13–16; 历代志下 8:7–8"> 所罗门依照他父亲大卫的方法，统计所有寄居在以色列的外族人，共有十五万三千六百人。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 2:2"> 他指派其中的七万人做搬运工，八万人在山上采凿石头，三千六百人做监工。</span>
</div>
</div>

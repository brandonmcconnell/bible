## 哈曼图谋灭绝犹太人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 24:7; 以斯帖记 5:11; 但以理书 6:2"> 后来，亚哈随鲁王提拔亚甲人哈米大他的儿子哈曼，使他的权位高过他所有的同僚。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 3:5; 诗篇 15:4; 以斯帖记 5:9"> 王命令所有在宫门供职的臣仆都要向哈曼跪拜，但末底改不肯跪拜。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖记 3:2; 出埃及记 1:17; 以斯帖记 2:19"> 在宫门供职的臣仆问末底改：“你为何违抗王的命令？”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:10; 约拿书 1:9; 但以理书 6:20–28"> 他们天天劝他，他却不听。他们便把这件事告诉哈曼，想看看末底改这样做是否能站得住，因为末底改已告诉他们自己是犹太人。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:19; 以斯帖记 5:9; 箴言 21:24"> 哈曼见末底改不肯向他跪拜，就怒气填胸。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 83:4; 启示录 12:12"> 他得知末底改是犹太人后，便不屑于只害末底改一人，而是要铲除亚哈随鲁王国内所有的犹太人，即末底改的同胞。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 6:15; 以西结书 21:21–22; 以斯帖记 9:24–26"> 亚哈随鲁王十二年一月，即尼散月，有人在哈曼面前抽普珥，也就是抽签，来决定哪月哪日下手，结果抽中十二月，即亚达月。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–15; 使徒行传 16:20–21; 申命记 4:27"> 哈曼对亚哈随鲁王说：“有一个民族散居在王境内各省的众民族中，他们的律例与各族的律例不同，他们不遵守王的律例，所以容忍他们对王不利。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 23:16; 马太福音 18:24"> 王若愿意，就请降旨消灭他们。我愿捐六百八十万两银子交给管理国事的人，纳入王的库房。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 41:42; 以斯帖记 8:2; 以斯帖记 7:6"> 于是，王摘下手上的戒指，交给犹太人的仇敌——亚甲人哈米大他的儿子哈曼，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:25; 耶利米书 40:4; 耶利米书 26:14"> 对他说：“这些银子归你，这个民族也交给你，随你处置。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 21:8; 以斯帖记 1:22; 但以理书 6:12"> 一月十三日，王的书记被召来，他们以亚哈随鲁王的名义，照哈曼的吩咐，用各省的文字和各族的语言写谕旨，用王的戒指盖印，送交各总督、各省省长和各族首领。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:6; 以斯帖记 9:10; 以斯帖记 8:10–14"> 谕旨由信差送到王的各省，限令在一天之内，也就是亚达月十三日，即十二月十三日，把犹太人的男女老少全部铲除、杀光、灭尽，并夺取他们的财物。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 8:13–14"> 谕旨的抄本作为法令颁布到各省，通知各族为那天做好准备。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:15; 约翰福音 16:20; 箴言 29:2"> 信差奉王的命令急忙上路，谕旨也在书珊城里颁布了。王和哈曼坐下饮酒，书珊城一片慌乱。</span>
</div>
</div>

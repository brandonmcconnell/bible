## 末底改求以斯帖帮忙

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:3; 以西结书 27:30–31; 撒母耳记下 13:19"> 末底改得知这事，就撕裂衣服，披上麻衣，头蒙灰尘，在城中行走，放声痛哭，</span>
<span className="v" id="v2" data-v="2"> 一直走到宫门前才停住，因为穿麻衣的不可进宫门。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 22:12; 但以理书 9:3; 以赛亚书 58:5"> 王的命令和谕旨传到各省各地，犹太人极其悲伤，他们禁食、哭泣、哀号，许多人身披麻衣躺在灰中。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 77:2; 耶利米书 31:15; 以斯帖记 1:12"> 以斯帖王后的宫女和太监把这事禀告她，她非常难过，便为末底改送去衣服，让他换下麻衣，他却不肯接受。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 罗马书 12:15; 以斯帖记 1:10"> 于是，以斯帖把王派来服侍她的一个名叫哈他革的太监召来，叫他去见末底改，查明事情的原委。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 4:3; 以斯帖记 7:2; 以斯帖记 9:12"> 哈他革就到宫门前的广场见末底改，</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 3:2–15"> 末底改便将自己的遭遇，以及哈曼为灭绝犹太人而许诺捐入国库的银子数目都告诉了他。</span>
<span className="v" id="v8" data-v="8" data-xref="传道书 10:4; 约伯记 9:15; 提摩太前书 6:13"> 末底改还把一份在书珊城颁布的要消灭犹太人的谕旨抄本交给哈他革，让他给以斯帖看并说明原委，嘱咐她去见王，为自己的同胞向王求情。</span>
<span className="v" id="v9" data-v="9"> 哈他革回去把末底改的话告诉以斯帖。</span>
<span className="v" id="v10" data-v="10"> 以斯帖便吩咐哈他革回复末底改说：</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖记 5:1–2; 以斯帖记 8:4; 但以理书 2:9"> “王的所有臣仆和各省人民都知道有一条法令，不论男女，未蒙宣召擅入内院去见王的必被处死，除非王向他伸出金杖，他才能活命。现在我已有三十天未蒙王召见了。”</span>
<span className="v" id="v12" data-v="12"> 末底改听到以斯帖捎来的话后，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 24:10–12; 腓立比书 2:30; 约翰福音 12:25"> 便回复她说：“你别以为在宫里就比其他犹太人安全。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 45:4–8; 撒母耳记上 12:22; 申命记 32:36"> 如果你此时沉默不语，犹太人必从别处得解脱，蒙拯救，但你和你父亲一家必灭亡。谁知道你得了王后之位不是为了今日之时呢？”</span>
<span className="v" id="v15" data-v="15"> 以斯帖派人回复末底改说：</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 20:24; 历代志下 20:3; 约珥书 2:12–17"> “你去召集书珊城所有的犹太人为我禁食，三天三夜不吃不喝，我和我的宫女也要这样禁食。然后，我要违例去见王，我若死就死吧！”</span>
<span className="v" id="v17" data-v="17"> 于是，末底改便去照以斯帖的一切吩咐行事。</span>

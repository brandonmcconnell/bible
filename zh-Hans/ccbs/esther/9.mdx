## 犹太人的反击

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 3:13; 以斯帖记 8:12; 诗篇 30:11"> 十二月，即亚达月十三日，是执行王谕旨的日子。那天，犹太人的仇敌原本想辖制他们，却反而被他们辖制。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 8:17; 以斯帖记 8:11; 诗篇 71:13"> 犹太人在亚哈随鲁王的各省各城聚集起来，攻击那些要害他们的人，无人能抵挡他们，因为各族都惧怕他们。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 8:36; 以斯帖记 8:5; 但以理书 6:1–2"> 各省的官员、总督、省长和为王办事的人因惧怕末底改，就都帮助犹太人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 3:1; 历代志上 11:9; 撒母耳记上 2:30"> 因为末底改已是王宫要员，他的名声传遍各省，权势日盛。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:34–40; 诗篇 20:7–8; 诗篇 149:6–9"> 犹太人用刀击杀所有敌人，任意消灭恨他们的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 3:15"> 犹太人单在书珊城就杀了五百人。</span>
<span className="v" id="v7" data-v="7"> 他们还杀了巴珊大他、达分、亚斯帕他、</span>
<span className="v" id="v8" data-v="8"> 坡拉他、亚大利雅、亚利大他、</span>
<span className="v" id="v9" data-v="9"> 帕玛斯他、亚利赛、亚利代和瓦耶撒他。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:11; 以斯帖记 8:11; 创世记 14:23"> 这十人是犹太人的仇敌哈曼的儿子、哈米大他的孙子。但犹太人没有动他们的财物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 当天，王获悉在书珊城被杀的人数，</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖记 7:2; 以斯帖记 5:6"> 便对以斯帖王后说：“犹太人在书珊城杀了五百人，还杀了哈曼的十个儿子，在其余各省就更不知怎样了！现在你要什么？必赐给你。你还有何要求？必为你成全。”</span>
<span className="v" id="v13" data-v="13" data-xref="以斯帖记 8:11; 申命记 21:23; 以斯帖记 9:15"> 以斯帖回答说：“王若愿意，就请恩准书珊城的犹太人明天仍执行今天的谕旨，并把哈曼十个儿子的尸体吊在木架上。”</span>
<span className="v" id="v14" data-v="14"> 王允准了，便在书珊城颁布谕旨，哈曼十个儿子的尸体便被吊了起来。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:11; 以斯帖记 9:10; 以斯帖记 9:16"> 亚达月十四日，书珊城的犹太人再次聚集起来，在城中杀了三百人，但没有动他们的财物。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以斯帖记 8:11; 以斯帖记 9:2; 利未记 26:7–8"> 王其他各省的犹太人也都聚集起来自卫，得以脱离仇敌。他们杀了七万五千个仇敌，但没有动他们的财物。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 8:9"> 这事发生在亚达月十三日。十四日，犹太人休息，并以此日为设宴欢庆的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 9:15"> 但书珊城的犹太人在十三、十四日聚集杀敌，十五日才休息，并以此日为设宴欢庆的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖记 8:17; 启示录 11:10; 尼希米记 8:10–12"> 因此，住在乡村的犹太人都以亚达月十四日为设宴欢庆的节日，并互赠礼物。</span>
</div>
</div>

## 普珥节

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 31:19–22; 哥林多后书 1:10–11; 诗篇 145:4–12"> 末底改把这些事记录下来，写信给亚哈随鲁王国内远近各省的犹太人，</span>
<span className="v" id="v21" data-v="21"> 吩咐他们每年在亚达月十四、十五日守节期，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 30:11; 以赛亚书 14:3; 以斯帖记 9:19"> 设宴欢庆，互赠礼物，周济穷人，以记念犹太人在此月此日得以脱离仇敌，化忧为乐，转悲为喜。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 犹太人接受了末底改写给他们的信，同意每年庆祝这个节日。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 3:5–13; 以斯帖记 9:10"> 因为犹太人的仇敌亚甲人哈米大他的儿子哈曼曾经阴谋毁灭犹太人，曾经抽普珥，即抽签，要杀戮、灭绝他们。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 7:16; 诗篇 140:9; 诗篇 141:10"> 但王知道这阴谋后，便降旨使哈曼谋害犹太人的恶计落到他自己头上，将他及其众子吊在木架上。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯帖记 9:20; 民数记 16:40; 以西结书 39:11"> 他们借用普珥这个词，称这两天为普珥节。犹太人因这信上的一切话，又因所看见、所经历的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:11; 以赛亚书 56:6; 以斯帖记 8:17"> 就为自己、自己的后代和归属他们的人定下规矩：每年必按时守这两天为节日，永不废弃。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 13:8–9; 约书亚记 4:7; 诗篇 103:2"> 各省各城、家家户户、世世代代都要记念、遵守这节日，使犹太人永不中断过普珥节，他们的后代也不可忘记。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以斯帖记 9:20; 以斯帖记 2:15; 以斯帖记 8:10"> 亚比孩的女儿以斯帖王后和犹太人末底改以全权写第二封信，嘱咐犹太人守这普珥节，</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 1:1; 以斯帖记 8:9; 撒迦利亚书 8:19"> 用和善、真诚的话写信给亚哈随鲁王国一百二十七省的所有犹太人，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖记 4:3; 以斯帖记 4:16; 约拿书 3:2–9"> 嘱咐他们照犹太人末底改和以斯帖王后的指示，按他们为自己和后代所规定的，按时守普珥节，禁食哀哭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 9:26"> 以斯帖的命令确定了普珥节，这命令被记载下来。</span>
</div>
</div>

</div>

## 犹太人获拯救

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 2:7; 以斯帖记 2:15; 箴言 13:22"> 当天，亚哈随鲁王把犹太人的仇敌哈曼的家产赐给以斯帖王后。末底改也来到王面前，因为以斯帖陈明了他们的亲属关系。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 3:10; 创世记 41:42; 但以理书 2:48"> 王摘下自己的戒指，就是从哈曼手中取回的，赐给末底改。以斯帖派末底改管理哈曼的家产。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿书 12:4; 以赛亚书 38:2; 列王纪下 4:27"> 以斯帖又俯伏在王的脚前，流泪哀求王废掉亚甲人哈曼加害犹太人的阴谋。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯帖记 5:2; 以斯帖记 4:11"> 王向以斯帖伸出金杖，以斯帖就起来站在王面前，</span>
<span className="v" id="v5" data-v="5" data-xref="以斯帖记 7:3; 以斯帖记 5:8; 以斯帖记 3:12–13"> 说：“王若愿意，我若得到王的恩宠，王若认为好，并且喜悦我，就请王降旨，废除亚甲人哈米大他的儿子哈曼阴谋灭绝各省犹太人的谕旨。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 7:4; 罗马书 10:1; 罗马书 9:2–3"> 我怎能忍心看我本族的人受害？我怎能忍心看我的亲族被杀？”</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 7:10–1; 加拉太书 3:13; 箴言 13:22"> 亚哈随鲁王对以斯帖王后和犹太人末底改说：“我已把哈曼的家产赐给以斯帖，并把他吊在木架上了，因为他想害犹太人。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖记 1:19; 以斯帖记 3:12; 以斯帖记 8:5"> 现在，你们尽可奉王的名写谕旨给犹太人，用王的戒指盖印，因为奉王的名所写、用王的戒指盖印的谕旨是不可废除的。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以斯帖记 1:22; 以斯帖记 1:1; 列王纪下 18:26"> 三月，即西弯月二十三日，王的书记被召来，按照末底改的一切吩咐用各省的文字和各族的语言，包括犹太人的文字和语言写谕旨，传给从印度到古实的一百二十七省的犹太人、总督、省长和官员。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 60:6; 耶利米书 2:23; 以赛亚书 66:20"> 末底改奉亚哈随鲁王的名写谕旨，用王的戒指盖印，让信差骑王室快马送往各地。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖记 3:13; 诗篇 37:14–15; 诗篇 146:6–9"> 谕旨上说，王准许各城的犹太人在十二月，即亚达月十三日，聚集起来自卫，铲除、杀光、灭尽各族各省攻击他们的军队及其儿女、妻子，夺取仇敌的财物。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 6:10; 以斯帖记 3:14; 士师记 16:28"> 谕旨的抄本颁布到各省，昭告各族，使犹太人在那天预备好向仇敌报仇。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 3:15; 但以理书 8:2; 以斯帖记 2:3"> 信差接到王的命令，急忙骑上王室快马上路。在书珊城也颁布了谕旨。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:19; 马太福音 6:29; 以斯帖记 3:15"> 末底改身穿蓝色和白色朝服，头戴大金冠，披着紫色细麻布外袍，从王那里出来，书珊城的人都欢呼雀跃。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:10; 诗篇 97:11; 诗篇 18:28"> 犹太人高兴欢喜，感到快乐光荣。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖记 9:19; 撒迦利亚书 8:20–23; 撒母耳记上 25:8"> 各省各城，凡谕旨所到之处，犹太人都欢喜快乐，设宴庆祝。许多当地人因惧怕犹太人而入了犹太籍。</span>
</div>
</div>

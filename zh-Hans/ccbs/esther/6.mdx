## 王赐末底改尊荣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 6:18; 但以理书 2:1; 以斯帖记 2:23"> 那夜王睡不着觉，就吩咐人拿史书念给他听。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 2:21–22"> 刚好念到末底改揭发两位守门太监辟探和提列谋害亚哈随鲁王的事，</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 9:15; 创世记 40:23; 使徒行传 28:8–10"> 王便问：“末底改既行此事，可曾赐他什么尊荣和爵位吗？”服侍王的臣仆回答说：“没有赐他什么。”</span>
<span className="v" id="v4" data-v="4" data-xref="以斯帖记 5:14; 以斯帖记 4:11; 以斯帖记 5:1"> 王问：“谁在院子里？”那时哈曼刚进到王宫外院，想请求王将末底改吊在他预备的木架上。</span>
<span className="v" id="v5" data-v="5"> 服侍王的臣仆回答说：“是哈曼站在院子里。”王说：“让他进来。”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:18; 俄巴底亚书 1:3; 以赛亚书 62:4–5"> 哈曼进来后，王问他：“王想赏识一个人，该怎么做呢？”哈曼心想：“王想赏识的人不是我是谁呢？”</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 6:11; 以斯帖记 6:9"> 于是，他就对王说：“王若想赏识一个人，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 1:33; 路加福音 15:22; 以斯帖记 1:11"> 可以拿来王穿过的袍子，牵来王骑过的戴冠御马，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 41:43; 列王纪上 1:33–34; 撒迦利亚书 9:9"> 交给王最尊贵的一位大臣，给王想赏识的人穿上，让他骑着马在城中的广场上游行，并派人在他前面宣告，‘王想赏识谁，就会这样待他。’”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:7; 但以理书 4:37; 列王纪下 10:10"> 王对哈曼说：“快去照你说的，把王袍和御马赐给坐在宫门供职的犹太人末底改。你所说的一样也不可少。”</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 1:52; 以斯帖记 9:3; 启示录 3:9"> 于是，哈曼将袍子给末底改穿上，让他骑着马在城中的广场上游行，并在他前面宣告：“王想赏识谁，就会这样待他。”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 15:30; 耶利米书 14:3–4; 约伯记 20:5"> 之后，末底改回到宫门那里，哈曼却悲伤地蒙着头匆匆回家去了。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 28:18; 何西阿书 14:9; 创世记 40:19"> 他将自己的遭遇详细告诉妻子细利斯和所有的朋友。他的谋士和他妻子细利斯对他说：“你开始在末底改面前败落。如果他是犹太人，你必胜不过他，终必在他面前败落。”</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 5:8; 以斯帖记 5:14; 申命记 32:35–36"> 他们正在谈论的时候，王的太监来催哈曼赶快去赴以斯帖预备的宴席。</span>

## 亚哈随鲁王大宴群臣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:1; 以斯帖记 8:9; 但以理书 6:1"> 亚哈随鲁在位期间，统治从印度到古实的一百二十七个省。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 1:1; 撒母耳记下 7:1; 但以理书 8:2"> 亚哈随鲁王在书珊城登基，</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 6:21; 以斯帖记 2:18; 但以理书 5:1"> 他在执政第三年大宴群臣，波斯和玛代的将领、各省的贵族和官长都在场。</span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 40:10; 以弗所书 1:18; 诗篇 76:1–4"> 整整一百八十天，他展示自己帝国的财富和王权的威荣。</span>
<span className="v" id="v5" data-v="5" data-xref="以斯帖记 7:7–8; 历代志下 30:21–25; 历代志下 7:8–9"> 之后，他又一连七天在御花园宴请书珊城里所有的居民，无论尊卑。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 6:4; 以西结书 23:41; 阿摩司书 2:8"> 御花园里有白色的棉帐和蓝色的彩帐，用细麻绳和紫色绳系在大理石柱的银环上。有金银制成的床榻摆在各色斑岩、大理石、珍珠贝壳及其他贵重石头铺成的地上。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:2–4; 历代志下 9:20; 以斯帖记 2:18"> 饮酒用的是各式各样的金器皿，御酒大量供应，足显王的慷慨。</span>
<span className="v" id="v8" data-v="8" data-xref="哈巴谷书 2:15–16; 耶利米书 51:7; 耶利米书 35:8"> 喝酒有个规矩，不许勉强人，因为王吩咐过宫里所有的侍从，招待各人要随其所愿。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯帖记 5:8; 以斯帖记 5:4"> 瓦实提王后也在亚哈随鲁王的宫里设宴招待女宾。</span>
</div>
</div>

## 瓦实提王后被废

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 16:25; 以斯帖记 7:9; 箴言 20:1"> 第七天，亚哈随鲁王喝得心中畅快，就吩咐在王身边服侍的米户幔、比斯他、哈波拿、比革他、亚拔他、西达和甲迦七位太监，</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:30; 马可福音 6:21–22; 箴言 16:9"> 去请瓦实提王后戴着后冠到王面前，向百姓和官员展现她的美貌，因为她非常美丽。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 19:12; 箴言 20:2; 彼得前书 3:1"> 但瓦实提王后违抗太监所传的谕旨，拒绝前来，王非常生气，怒火中烧。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 12:32; 但以理书 2:2; 耶利米书 10:7"> 王有事习惯征求通晓律例和法则之人的意见，于是他去问精通时务的哲士。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 25:19; 以斯拉记 7:14; 马太福音 18:10"> 那时，靠近王的有甲示拿、示达、押玛他、他施斯、米力、玛西拿和米慕干七位波斯和玛代的大臣，他们常见王的面，在国中身居高位。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 6:6"> 王问他们：“瓦实提王后违抗太监所传的谕旨，按律该如何处置她？”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 18:14; 哥林多前书 6:7–8; 使徒行传 25:10"> 米慕干当着王和大臣们的面说：“瓦实提王后不但冒犯了王，而且有害于王举国的臣民。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 6:16; 以弗所书 5:33"> 因为王后的事必传到所有妇女耳中，致使她们藐视自己的丈夫，因为她们会说，‘亚哈随鲁王命人请瓦实提王后到他面前，她却不去。’</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 11:3; 士师记 5:29"> 今天，波斯和玛代的贵妇听到王后这事，也会这样对待王的大臣，藐视和恼怒的事必层出不穷。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 15:28; 以斯帖记 8:8; 以斯帖记 3:9"> 王若愿意，就请降旨不准瓦实提再到王面前，把她王后的位分赐给比她更好的女子，并将此谕旨写入波斯和玛代的律法，永不更改。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 3:18; 以弗所书 5:22; 以弗所书 5:33"> 王的谕旨传遍王辽阔的国境后，所有的妇女，无论丈夫贵贱，都必尊重他们。”</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:37; 以斯帖记 2:4; 以斯帖记 1:19"> 王和大臣们都赞同米慕干的建议，王便依照他的建议，</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 3:12; 以斯帖记 8:9; 以弗所书 5:22–24"> 用各省的文字和各族的语言写谕旨，通告各省，丈夫要做一家之主，说话有权柄。</span>
</div>

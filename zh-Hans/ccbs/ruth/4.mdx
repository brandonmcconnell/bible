## 波阿斯娶路得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 25:7; 路得记 3:12; 申命记 16:18"> 波阿斯来到城门口，坐在那里，恰巧看见他所说的那位至亲经过，便招呼他说：“某人啊，请过来坐一坐。”那人便走过来坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 31:23; 列王纪上 21:8; 使徒行传 6:12"> 波阿斯又邀请了城里的十位长老，对他们说：“请过来坐一坐。”他们都坐下以后，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:10; 诗篇 112:5"> 波阿斯便对那位至亲说：“拿俄米从摩押回来了，现在要卖我们族兄以利米勒的那块地，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 25:25–29; 耶利米书 32:7–12; 罗马书 12:17"> 我想应该让你知道这件事。你最有权赎那块地，其次才是我，此外再没有别人了。如果你愿意赎回那块地，请你当着在座各位长老的面表明。如果不愿意，请你让我知道。”那人说：“我愿意赎。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 38:8; 申命记 25:5–6; 马太福音 22:24"> 波阿斯说：“那么，你从拿俄米手中买地的那天，也要娶已死之人的妻子摩押女子路得，好让死者继续在产业上留名。”</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 25:25; 路得记 3:13"> 那位至亲说：“那我就不能赎了，免得损害到我的产业。你来赎吧，我不能赎。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 25:7–10"> 从前在以色列，买赎或交易有这样的规矩：一旦成交，一方要把鞋脱下来交给另一方，以色列人以此为成交的凭据。</span>
<span className="v" id="v8" data-v="8"> 那位至亲对波阿斯说：“你自己买吧！”他就把鞋脱了下来。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 32:10–12; 创世记 23:16–18"> 波阿斯向长老和所有在场的人说：“请各位今天为我作证，所有属于以利米勒、基连和玛伦的产业，我都从拿俄米手上买了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 25:6; 以弗所书 5:25; 创世记 29:27"> 同时，我要娶玛伦的遗孀摩押女子路得为妻，好使死者继续在产业上留名，免得他的名在本族本乡中消失。今天，请各位作证。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 29:32–24; 弥迦书 5:2; 马太福音 2:6"> 聚集在城门口的众人和长老都说：“我们愿意作证。愿耶和华使要进你家门的这女子，像建立以色列家的拉结和利亚一样。愿你在以法他家业兴隆，在伯利恒声名远扬。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 38:29; 撒母耳记上 2:20; 历代志上 2:4"> 愿耶和华借着这年轻女子赐你后裔，使你家像先祖犹大和她玛的儿子法勒斯家一样。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 33:5; 创世记 29:31; 路得记 3:11"> 这样，波阿斯便娶了路得为妻，与她同房。耶和华使她怀孕生了一个儿子。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:5–20; 路加福音 1:58; 创世记 12:2"> 妇女们对拿俄米说：“耶和华当受称颂！因为今日祂赐给你一位至亲，使你后继有人，愿这孩子在以色列得享盛名！</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 55:22; 以赛亚书 46:4; 创世记 45:11"> 他必让你的生命重新得力，奉养你，使你安度晚年，因为他是爱你的儿媳妇所生的。有这儿媳妇比有七个儿子还要好！”</span>
<span className="v" id="v16" data-v="16"> 拿俄米接过婴孩抱在怀中，照顾他。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:58–63"> 邻居的妇女们说：“拿俄米有孩子了！”她们给孩子取名叫俄备得，这俄备得就是耶西的父亲，耶西是大卫的父亲。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 1:3–6; 历代志上 2:4–8; 路加福音 3:33"> 以下是法勒斯的家谱：法勒斯生希斯仑，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:33; 历代志上 2:9–10; 马太福音 1:4"> 希斯仑生兰，兰生亚米拿达，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:7; 路加福音 3:32; 马太福音 1:4"> 亚米拿达生拿顺，拿顺生撒门，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:32; 马太福音 1:5; 历代志上 2:11–12"> 撒门生波阿斯，波阿斯生俄备得，</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 2:15; 以赛亚书 11:1; 马太福音 1:6"> 俄备得生耶西，耶西生大卫。</span>
</div>
</div>

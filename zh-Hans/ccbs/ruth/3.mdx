## 路得麦场见波阿斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得记 1:9; 提摩太前书 5:8; 提摩太前书 5:14"> 一天，路得的婆婆拿俄米对她说：“我的女儿啊，我实在应该为你找个好归宿，使你生活幸福。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:5–10; 路得记 2:20–23; 路得记 2:8"> 波阿斯不是我们的亲戚吗？而且你又常与他的女工在一起。今晚他会在麦场簸大麦。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:2; 提摩太前书 2:9–10; 以斯帖记 5:1"> 你要梳洗打扮、抹上香膏、换件衣服，然后去麦场，但不要让他认出你是谁。等他吃饱喝足，</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:22"> 躺下睡觉的时候，你看准他躺卧的地方，去掀开盖在他脚上的被，躺在那里，到时他必定会告诉你该怎样做。”</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 3:20; 以弗所书 6:1"> 路得说：“好，我一定照你的吩咐去做。”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; 约翰福音 2:5; 出埃及记 20:12"> 于是，路得就到麦场去，照她婆婆吩咐的去做。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:6; 以斯帖记 1:10; 撒母耳记下 13:28"> 波阿斯吃过晚饭，心里舒畅，便躺在麦堆旁边睡着了。路得悄悄过去掀起盖在他脚上的被，躺在他脚旁。</span>
<span className="v" id="v8" data-v="8"> 到了半夜，波阿斯忽然惊醒，翻过身来，发现一个女子躺在他的脚旁，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 16:8; 路得记 2:20; 路得记 3:12"> 便问道：“你是谁？”她答道：“我是你的婢女路得，请用你的衣襟遮盖我，因为你是我的近亲。”</span>
<span className="v" id="v10" data-v="10" data-xref="路得记 2:20; 哥林多前书 13:4–5; 路得记 1:8"> 波阿斯说：“姑娘，愿耶和华赐福给你，因为你一直对婆家情深义重，现在更是如此。你本来可以找一个富有或贫穷的年轻丈夫，然而你却没有这样做。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> 姑娘，不要害怕，你所说的一切，我都会去为你安排，城里所有的人都知道你是个贤德的女子。</span>
<span className="v" id="v12" data-v="12" data-xref="路得记 4:1; 帖撒罗尼迦前书 4:6; 马太福音 7:12"> 不错，我是你的近亲，可是有一个人比我更近。</span>
<span className="v" id="v13" data-v="13" data-xref="路得记 4:5; 耶利米书 4:2; 路得记 2:20"> 你今晚就留在这里，明天早上，如果他答应尽亲属的义务，就由他照顾你；如果他不肯，我凭永活的耶和华起誓，我会尽我的本分。现在你只管安心睡到天亮。”</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 8:21; 罗马书 14:16; 哥林多前书 10:32"> 路得就躺在波阿斯的脚旁。天未亮，还看不清人的时候，路得就起来了。因为波阿斯曾对她说：“不可让别人知道有女人来过麦场。”</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 32:8; 加拉太书 6:10"> 离开的时候，波阿斯对她说：“把你的外衣拿来铺开。”路得就照做了。他用路得的外衣包了六簸箕大麦，帮她扛在肩上，她便回城了。</span>
<span className="v" id="v16" data-v="16"> 回到家中，婆婆问她：“女儿啊，怎么样了？”路得便将事情的经过都告诉了婆婆。</span>
<span className="v" id="v17" data-v="17"> 她又说：“那个人给了我六簸箕大麦，对我说，‘不要空手回去见你婆婆。’”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 37:3–5; 以赛亚书 28:16; 以赛亚书 30:7"> 拿俄米说：“女儿啊！你只管安静等候，看这事怎样发展，因为那人今天不把事情办妥，是绝不会休息的。”</span>

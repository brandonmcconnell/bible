## 路得遇见波阿斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得记 4:21; 路得记 3:12; 路得记 3:2"> 拿俄米的丈夫以利米勒有个亲戚，名叫波阿斯，是个有名望的财主。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:22; 利未记 19:9; 申命记 24:19–21"> 摩押女子路得对拿俄米说：“让我到田里去，跟在那些愿意恩待我的人后面，捡些麦穗回来。”拿俄米说：“去吧，我的女儿！”</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦后书 3:12; 马太福音 10:29; 路加福音 10:31"> 于是，路得便去了。她恰巧来到以利米勒的亲戚波阿斯的田里，跟在收割的人后面捡麦穗。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 129:7–8; 士师记 6:12; 路加福音 1:28"> 当时，波阿斯刚好从伯利恒来到田间，向那些收割的工人问安说：“愿耶和华与你们同在。”他们回答说：“愿耶和华赐福给你。”</span>
<span className="v" id="v5" data-v="5" data-xref="路得记 4:21; 历代志上 2:11–12"> 波阿斯问负责收割的工头说：“那是谁家的女子？”</span>
<span className="v" id="v6" data-v="6" data-xref="路得记 1:22; 马太福音 24:45; 创世记 24:2"> 工头回答说：“她是摩押女子，跟拿俄米刚从摩押回来。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 13:4; 箴言 18:23; 箴言 15:33"> 她求我让她跟在收割的人后面，捡工人扎捆时遗落的麦穗。她一大早就来到这里，一直捡到现在，除了在凉棚里稍微坐了一会儿之外，几乎没有休息。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 5:13; 雅歌 1:7–8; 撒母耳记上 3:6"> 波阿斯对路得说：“姑娘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“姑娘”希伯来文是“女儿”。">a</a></sup>，听我说，你不用到别人的田里去拾麦穗了，也不必离开这里，只管留下来跟我的女工在一起。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 创世记 20:6; 箴言 6:29"> 你看我的工人在哪一块田里收割，就跟着我的女工去，我已经吩咐工人不可欺负你。要是你渴了，就去水罐那里喝工人打回来的水。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 25:23; 路得记 2:13; 路加福音 1:43"> 路得就俯伏在地叩谢他，说：“我不过是个外族人，你为什么这样恩待我、体恤我？”</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 14:33; 路加福音 18:29–30; 路加福音 5:11"> 波阿斯说：“自从你丈夫过世之后，你怎样善待婆婆，怎样离开父母和家乡来到素不相识的人当中，我都听说了。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 36:7; 诗篇 91:4; 诗篇 63:7"> 愿耶和华照你所行的奖赏你！你来投靠在以色列的上帝耶和华的翅膀下，愿祂厚厚地赏赐你。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 1:18; 创世记 34:3; 创世记 33:8"> 路得说：“我主啊！我真是在你面前蒙恩，虽然我连你的婢女都不如，你还好言安慰我。”</span>
<span className="v" id="v14" data-v="14" data-xref="路得记 2:18; 列王纪下 4:43–44; 马太福音 14:20"> 吃饭的时候，波阿斯对路得说：“来，吃一点饼吧，可以蘸着醋吃。”路得便坐在那些收割工人旁边。波阿斯递给她一些烤好的麦穗。她吃饱了，还有剩余的。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 1:5"> 当她起来又要去捡麦穗的时候，波阿斯就吩咐他的工人说：“你们要任由她捡，就算她从麦捆中捡麦穗，你们也不要为难她。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:13; 约翰一书 3:17–18; 申命记 24:19–21"> 甚至要从麦捆中抽一些出来让她捡，不要责骂她。”</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 45:11–12; 箴言 31:27; 出埃及记 16:36"> 于是，路得便在田间继续捡麦穗，到了黄昏，她把捡到的麦穗打了，大约有十公斤大麦。</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 2:14; 约翰福音 6:12–13; 提摩太前书 5:4"> 她把捡来的麦子带回城里给婆婆拿俄米看，又把剩下来的食物给婆婆。</span>
<span className="v" id="v19" data-v="19" data-xref="路得记 2:10; 诗篇 41:1; 列王纪上 7:21"> 婆婆问她：“你今天在哪里拾麦穗？在哪里做工？愿那善待你的人蒙福！”她就告诉婆婆说：“今天我在一个名叫波阿斯的人那里工作。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 2:5; 路得记 3:9–10; 利未记 25:25"> 拿俄米说：“愿耶和华赐福给他，他对活着的和过世的都是那么有情有义。”拿俄米又对路得说：“这人是我们的近亲，有为我们赎业的责任。”</span>
<span className="v" id="v21" data-v="21" data-xref="雅歌 1:7–8; 路得记 2:7–8; 路得记 2:22"> 摩押女子路得说：“他还对我说，‘你可以跟在我的工人后面捡麦穗，直到他们把我的庄稼都收完为止。’”</span>
<span className="v" id="v22" data-v="22" data-xref="雅歌 1:8; 箴言 27:10"> 拿俄米对儿媳路得说：“我的女儿啊，你就跟他的女工一起到田里去，免得去别人的田里被欺负。”</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 6:6–8; 申命记 16:9; 以弗所书 6:1–3"> 因此，路得便常跟波阿斯的女工在一起捡麦穗，直到大麦小麦都收割完毕。路得就这样陪伴婆婆过日子。</span>

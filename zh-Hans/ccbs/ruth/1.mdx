## 拿俄米和路得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 26:1; 以西结书 14:13"> 在士师执政的时代，犹大发生了饥荒。有一个人带着妻子和两个儿子从犹大的伯利恒迁到摩押境内寄居。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:19; 弥迦书 5:2; 撒母耳记上 17:21"> 这个人名叫以利米勒，妻子叫拿俄米，两个儿子分别叫玛伦和基连。他们都是犹大 伯利恒的以法他人。他们来到摩押，就在那里住了下来。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:10–11; 诗篇 34:19; 希伯来书 12:6"> 后来，拿俄米的丈夫以利米勒去世了，留下她和两个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:5; 列王纪上 11:1–2; 申命记 23:3"> 这两个儿子都娶了摩押的女子为妻，一个名叫俄珥巴，一个名叫路得。在那里住了大约十年后，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:39; 诗篇 89:30–32; 以赛亚书 49:21"> 玛伦和基连二人都去世了，只剩下拿俄米，没有了丈夫，也没有了儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 132:15; 出埃及记 3:16; 诗篇 111:5"> 后来，拿俄米在摩押听说耶和华眷顾祂的子民，使他们五谷丰登，就带着两个儿媳妇准备回故乡。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 8:3; 路得记 1:14; 出埃及记 18:27"> 她们离开所居住的地方，动身返回犹大。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 2:20; 路得记 1:5; 歌罗西书 3:18"> 拿俄米对两个儿媳妇说：“你们还是各回娘家去吧！愿耶和华恩待你们，就好像你们恩待死去的丈夫和我一样。</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 3:1; 使徒行传 20:37; 创世记 29:11"> 愿耶和华使你们都有机会再嫁，找到好归宿。”拿俄米说完了，就亲吻她们。她们都放声大哭，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 8:23; 诗篇 16:3; 诗篇 119:63"> 说：“不！我们要跟你一起回你的家乡。”</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 25:5; 创世记 38:11"> 拿俄米说：“我的女儿啊，回娘家去吧！为什么要跟我去呢？难道我还能生儿子做你们的丈夫吗？</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:17; 提摩太前书 5:9"> 回去吧！我的女儿啊，走吧！我已经老了，不可能再嫁人了。就算我还有指望，今晚能再结婚生子，</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 19:21; 士师记 2:15; 诗篇 32:4"> 难道你们能一直不嫁，等到他们长大吗？不要这样，我的女儿啊！这样你们会很苦，我就更苦了，因为耶和华伸手惩罚我。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:24; 马太福音 16:24; 马太福音 10:37"> 她们又放声大哭，俄珥巴就亲吻婆婆，向她道别，但路得却依依不舍，不肯离去。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 11:24; 约书亚记 24:15; 西番雅书 1:6"> 拿俄米说：“你看，你嫂嫂已经回她家乡和她拜的神明那里去了，你也跟着嫂嫂回去吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 15:21; 路得记 2:11–12; 列王纪下 2:2–6"> 路得说：“不要逼我撇你而去。你往哪里去，我也要往哪里去；你住在哪里，我也要住在哪里；你的同胞就是我的同胞，你的上帝就是我的上帝；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 3:17; 列王纪上 2:23; 列王纪下 6:31"> 你死在哪里，我也死在哪里、葬在哪里。只有死才能把我们分开。否则，愿耶和华重重地惩罚我！”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:14; 以弗所书 6:10; 使徒行传 2:42"> 拿俄米见路得坚决要跟她走，就不再劝阻她了。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:10; 以赛亚书 23:7; 耶利米哀歌 2:15"> 于是，二人便一同回到伯利恒。她们进了伯利恒，全城轰动。妇女们问：“这不是拿俄米吗？”</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 6:4; 希伯来书 12:11; 诗篇 73:14"> 拿俄米对她们说：“不要再叫我拿俄米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拿俄米”意思是“甜”。">a</a></sup>了，叫我玛拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“玛拉”意思是“苦”。">b</a></sup>吧！因为全能者叫我过得好苦啊！</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 2:7–8; 约伯记 1:21; 约伯记 16:8"> 我曾满满地离开这里，现在耶和华却使我空空地回来。既然耶和华叫我受苦，全能者使我遭难，为何还叫我拿俄米呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="路得记 2:23; 撒母耳记下 21:9; 出埃及记 9:31–32"> 拿俄米带着她的儿媳妇摩押女子路得从摩押回到了伯利恒，那时正是开始收割大麦的季节。</span>
</div>

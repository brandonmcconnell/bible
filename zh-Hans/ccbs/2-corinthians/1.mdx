## 上帝的安慰

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 15:5–6"> 我们主耶稣基督的父上帝当受赞美！祂是仁慈的父和赐一切安慰的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:11; 以赛亚书 51:12; 帖撒罗尼迦后书 2:16–17"> 我们遭遇任何患难，祂都安慰我们，使我们能够用祂给我们的安慰去安慰那些在各样患难中的人。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:24; 腓立比书 3:10; 哥林多后书 4:10–11"> 正如我们多受基督的苦难，也靠基督多得安慰。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 2:10; 哥林多后书 1:4; 哥林多后书 4:15–18"> 我们遭受患难，是为了使你们得到安慰和拯救；我们得到安慰，也是为了使你们得到安慰，以便你们能忍受像我们所遭遇的各样苦难。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17–18; 帖撒罗尼迦后书 1:4–7; 雅各书 1:12"> 我们对你们坚信不移，因为知道你们既和我们同受苦难，也必和我们同得安慰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 4:7–12; 哥林多前书 15:32; 哥林多前书 4:8"> 弟兄姊妹，希望你们知道我们在亚细亚所遭遇的苦难。那时我们承受极大的压力，超过了我们的极限，甚至连活命的指望都没了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 3:5; 希伯来书 11:19; 哥林多后书 4:7"> 我们心里觉得必死无疑，这使我们不倚靠自己，只倚靠使死人复活的上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 4:10; 诗篇 34:19; 彼得后书 2:9"> 祂曾救我们脱离可怕的死亡，并且还要救我们。我们深信祂必继续救我们。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比书 1:19; 哥林多后书 4:15; 使徒行传 12:5"> 你们也要用祈祷帮助我们，使恩典借着许多人的祷告临到我们，众人便因此为我们感恩。</span>
</div>
</div>

## 保罗改变计划

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:17; 哥林多前书 2:13; 雅各书 3:13–18"> 我们引以为荣的是：我们为人处世是本着上帝所赐的圣洁和诚实，倚靠祂的恩典，不倚靠人的聪明才智，对待你们更是这样。这一点，我们的良心可以作证。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 4:2; 腓利门书 1:6; 哥林多后书 13:6"> 我们不写任何你们不能读、不能懂的内容。你们现在对我们有几分认识，但我盼望你们最终完全认识到：当主耶稣再来的日子，你们将以我们为荣，我们也将以你们为荣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:19; 罗马书 1:11; 罗马书 15:29"> 我有这样的把握，所以早就计划去你们那里，使你们有再次蒙福的机会。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:5–7; 使徒行传 21:5; 使徒行传 19:21–22"> 我打算经过你们那里去马其顿，再从马其顿回到你们那里，然后你们为我送行前往犹太。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:37; 雅各书 5:12; 哥林多后书 10:2–3"> 我定了这计划，难道会反复无常吗？难道我是意气用事，出尔反尔吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:9; 启示录 3:7; 约翰福音 7:28"> 我在信实的上帝面前保证：我们对你们说的话绝不会忽是忽非！</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:8; 启示录 1:17; 约翰二书 1:9"> 我和西拉、提摩太在你们当中传扬的上帝之子耶稣基督，绝不会忽是忽非，在祂只有“是”。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 2:24–25; 加拉太书 3:22; 启示录 7:12"> 因为上帝的一切应许在基督里都是确实的，所以我们也是借着基督说“阿们”，将荣耀归于上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:27; 彼得前书 5:10; 约翰一书 2:20"> 是上帝使我们和你们一同在基督里坚立。祂膏抹了我们，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:30; 哥林多后书 5:5; 以弗所书 1:13–14"> 在我们身上盖了祂自己的印记，并让圣灵住在我们心中作担保。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:20; 哥林多前书 4:21; 罗马书 1:9"> 我求上帝为我做见证：我没有去哥林多，是为了宽容你们。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:3; 哥林多前书 15:1; 腓立比书 1:25–26"> 我们并不是要操纵你们的信仰，而是要帮助你们，使你们喜乐，因为你们在信仰上已经站稳了。</span>
</div>
</div>

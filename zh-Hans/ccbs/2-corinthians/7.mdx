## 保罗的喜乐

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 20:33; 哥林多后书 6:12–13; 哥林多后书 11:9"> 请你们敞开心怀接纳我们。我们没有亏负过任何人，没有败坏过任何人，也没有占过任何人的便宜。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 6:11–12; 帖撒罗尼迦前书 2:8; 哥林多后书 11:11"> 我这样说，并不是要定你们的罪，因为我曾经说过，我们心里常惦记你们，愿意和你们生死与共。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 1:4; 哥林多后书 3:12; 雅各书 1:2"> 我非常信任你们，以你们为荣。我因你们大受激励，在我们所受的一切患难中，我仍然充满喜乐。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 2:13; 申命记 32:25; 使徒行传 20:1"> 我们到马其顿的时候，身心无法安歇，面临着重重患难，外有冲突，内有恐惧。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 1:3–4; 帖撒罗尼迦后书 2:16–17; 哥林多后书 7:13"> 但安慰沮丧之人的上帝借着提多的到来激励了我们。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 5:2; 犹大书 1:3; 哥林多后书 8:16"> 我们得到激励，不但是因为提多来了，也因为看到他从你们那里得到了激励。他把你们对我的想念、对我的热心和你们的哀痛都告诉了我，这使我更加欢喜。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 3:19; 耶利米书 20:7–9; 马太福音 26:21–22"> 我曾为从前写的那封信令你们忧伤而后悔，但现在不后悔了，因为我知道那封信令你们忧伤只是暂时的。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:7; 耶利米书 31:18–20; 哥林多后书 7:10–11"> 现在我很欢喜，当然不是因为你们忧伤而欢喜，而是看见你们因忧伤而悔改了。因为你们这样忧伤合乎上帝的心意，使你们不致因我们而受到任何损失。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:19; 使徒行传 11:18; 提摩太后书 2:25–26"> 合乎上帝心意的忧伤会带来悔改，使人得到救恩，永不后悔，但世俗的忧伤只会带来死亡。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 14:18; 提摩太前书 5:21–22; 提摩太后书 2:15"> 你们看，合乎上帝心意的忧伤使你们产生了何等的热诚啊！你们何等地认真辩白、对罪愤慨、心生敬畏、充满盼望和热情、乐意惩处罪恶。你们在各方面已显明自己在那件事上是清白的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:9; 提摩太前书 3:5; 哥林多后书 2:17"> 因此，虽然我给你们写过信，但并非为了那犯错的人或那受害的人而写的，而是为了让你们在上帝面前看到自己对我们所存的热心。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 7:6; 哥林多前书 12:26; 哥林多前书 16:13"> 我们也因此得到了激励。让我们更欢喜的是提多也很喜乐，因为他的心从你们那里得到了安慰。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 7:4; 帖撒罗尼迦后书 1:4; 哥林多后书 1:18–20"> 我若对提多夸奖了你们什么，也不觉得惭愧，因为我先前向提多夸奖你们的话都证明是真实的，正如我告诉你们的一切都是真实的。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 2:12; 哥林多后书 2:9; 约翰一书 3:17"> 提多想到你们众人的顺服并怎样战战兢兢地接待他，便更加爱你们了。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:3; 腓利门书 1:8; 腓利门书 1:21"> 现在，我对你们可以完全放心了，这真让我欢喜。</span>

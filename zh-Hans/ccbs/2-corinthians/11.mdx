## 保罗与假使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:4; 哥林多前书 1:21; 哥林多后书 11:19"> 请你们包容我的这点愚妄吧！我知道你们一定会包容我。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿书 2:19–20; 以弗所书 5:26–27; 以赛亚书 54:5"> 我以上帝痛恨不贞的爱爱你们。因为我曾把你们当作贞洁的少女许配给一位丈夫——基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:8; 加拉太书 1:6; 以弗所书 4:14"> 但我真怕你们会像被狡猾的蛇欺骗的夏娃一样，思想受迷惑，失去了对基督纯真专一的心。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:6–8; 哥林多前书 3:11; 提摩太前书 2:5"> 有人来传另一位耶稣——与我们所传的不同，或要你们接受另一个灵——与你们所接受的不同，或要你们相信另一种福音——与你们所相信的不同，你们竟欣然容忍。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:11–12; 哥林多前书 15:10; 加拉太书 2:6–9"> 我想，我一点也不比那些“超级使徒”差。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 3:4; 哥林多前书 1:17; 哥林多后书 4:2"> 我虽然不善辞令，但我认识真理。这一点，我们在各方面已经向你们证明了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 12:13; 帖撒罗尼迦前书 2:9; 哥林多后书 10:1"> 我为了把上帝的福音白白地传给你们，甘愿卑微，以提升你们，我这样做有罪吗？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:18; 哥林多后书 11:9; 腓立比书 4:14–16"> 我“抢夺”其他教会，拿了他们的资助，来服侍你们。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:8–9; 帖撒罗尼迦前书 2:9; 帖撒罗尼迦前书 2:6"> 我在你们那里经济拮据的时候，没有拖累过你们任何人，因为马其顿来的弟兄补足了我的缺乏。我没有在任何方面成为你们的负担，将来也不会成为你们的负担。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 9:1; 罗马书 1:9; 使徒行传 18:12"> 我凭我心中基督的真理说，亚该亚地区无人会阻止我这样夸口。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 12:15; 哥林多后书 6:11–12; 哥林多后书 7:3"> 为什么呢？难道我不爱你们吗？上帝知道我爱你们！</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:12; 哥林多前书 5:6; 哥林多后书 5:12"> 我现在所做的，将来还会继续做下去，为了要断绝那些投机分子的机会，使他们无法在所夸耀的事上被认为与我们一样。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 1:7; 启示录 2:2; 约翰一书 4:1"> 其实这些人是假使徒，为人诡诈，冒充基督的使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:8; 哥林多后书 2:11; 哥林多后书 11:3"> 这不足为奇，因为连撒旦都装成光明的天使，</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 3:19; 启示录 9:11; 以赛亚书 9:14–15"> 它的爪牙若冒充公义的仆人，又何足为奇呢？他们最终必得到应得的报应。</span>
</div>
</div>

## 保罗的诸多苦难

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 11:1; 哥林多后书 12:6; 哥林多后书 12:11"> 我再说，谁也别把我当作傻瓜。你们如果真这么想，那就把我当傻瓜看待吧！好让我也能说几句自夸的话。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 7:12; 腓立比书 3:3–6; 哥林多后书 9:4"> 我这样说，并不是主的意思，而是像一个傻瓜一样夸口。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:10; 哥林多后书 11:21–23; 哥林多后书 10:12–18"> 既然许多人凭血气夸口，我当然也可以夸口。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:10; 哥林多前书 10:15; 哥林多前书 8:1"> 因为你们这些聪明人竟然甘愿忍受那些傻瓜，</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:4; 加拉太书 4:3; 加拉太书 5:1"> 就算有人奴役、剥削、利用、侮辱你们，打你们耳光，你们都能逆来顺受！</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 10:10; 哥林多后书 11:17; 哥林多后书 10:1–2"> 惭愧得很，我必须说，我们太软弱了，做不出那样的事！<br />然而，别人敢夸口的，我再讲一句傻话，我也敢。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 3:5; 罗马书 11:1; 罗马书 9:4"> 他们是希伯来人，我也是。他们是以色列人，我也是。他们是亚伯拉罕的子孙，我也是。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:4–5; 哥林多后书 1:9–10; 哥林多后书 6:9"> 他们自称是基督的仆人，我说句狂话，我更是！我比他们更辛苦，坐牢更多，身受更重的鞭打，经常出生入死。</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 13:9; 申命记 25:2–3; 马太福音 10:17"> 我被犹太同胞鞭打了五次，每次三十九鞭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“三十九鞭”希腊文是“四十鞭减一鞭”。">a</a></sup>，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 14:19; 使徒行传 16:37; 希伯来书 11:37"> 被人用棍打了三次，用石头打了一次，遇到船难三次，曾在大海上漂浮了一天一夜。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:5; 使徒行传 17:5; 使徒行传 13:50"> 我常常四处奔波，遭遇江河的危险、盗贼的威胁、同胞的威胁、外族的威胁、城中的危险、旷野的危险、海上的危险和假信徒的威胁。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:12; 哥林多后书 6:5; 帖撒罗尼迦前书 2:9"> 我劳碌困苦，不得安眠，又饥又渴，挨饿受冻，赤身露体。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 7:17; 罗马书 15:16; 使徒行传 20:18–35"> 此外，我还挂虑众教会的事，天天承受着压力。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 8:13; 哥林多前书 9:22; 加拉太书 4:8–20"> 有谁软弱，我不感同身受呢？有谁失足犯罪，我不心急如焚呢？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 12:5–11; 箴言 25:27; 哥林多前书 2:3"> 如果一定要夸耀，我情愿夸耀自己的软弱。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 9:5; 以弗所书 1:3; 约翰福音 10:30"> 主耶稣的父上帝永受称颂，祂知道我不撒谎。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:24–25; 哥林多后书 11:26"> 在大马士革的时候，亚哩达王手下的总督吩咐人把守城门，要逮捕我。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 9:25; 撒母耳记上 19:12; 约书亚记 2:18"> 我被人用筐子从城墙上的窗户缒下去，才逃出他的手掌。</span>
</div>
</div>

## 鼓励信徒慷慨捐助

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 16:9; 哥林多后书 9:2; 哥林多后书 9:4"> 弟兄姊妹，我们现在要让你们知道上帝向马其顿各教会所施的恩典。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:5; 箴言 11:25; 哥林多后书 6:10"> 他们虽然遭遇极大的患难，受尽熬炼，却充满了喜乐，在极度贫穷的情况下仍然十分慷慨乐捐。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:5; 出埃及记 35:21–22"> 我可以证明，他们是甘心乐意，尽其所能地捐助，甚至超过了自己的能力。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:17; 加拉太书 6:10; 哥林多后书 9:1"> 他们恳求我们准许他们参与供应有需要的圣徒。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 12:1; 罗马书 14:7–9; 历代志下 30:12"> 他们这样做超过了我们的期望，并且他们按照上帝的旨意首先把自己献给主，然后献给我们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多后书 8:4"> 所以，我们劝提多要继续完成他早先在你们当中开始的这件善事。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:8; 彼得后书 1:5–8; 帖撒罗尼迦后书 1:3"> 你们既然在信心、口才、知识、热心和对我们的爱心上都有突出的表现，也要在这件善事上有突出的表现。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:6; 约翰一书 3:17–19; 雅各书 2:14–16"> 我说这话并非命令你们，而是借着别人的热心考验一下你们爱心的真伪。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 8:32; 腓立比书 2:6–8; 马太福音 20:28"> 因为你们知道我们主耶稣基督的恩典，祂本来富足，却为你们的缘故变得贫穷，使你们借着祂的贫穷可以变得富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18–19; 希伯来书 13:16; 哥林多后书 9:2"> 关于捐助的事，我把自己的意见告诉你们：你们一年前开始捐助，并且甘心乐意——这对你们有益。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 9:2"> 你们要有始有终，既有恳切愿意的心，就要量力而行，办妥这事。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 12:42–44; 哥林多后书 9:7; 路加福音 21:1–4"> 因为人只要按自己的能力甘心乐意地去做，必蒙上帝悦纳，上帝不会让人做力所不逮之事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 4:34; 罗马书 15:26–27"> 这不是说要别人脱离困境，要你们陷入困境，而是要均平。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:12; 使徒行传 4:34"> 现在你们这些富足的人可以帮补那些有需要的人，以便你们有需要的时候，那些富足的人也可以帮补你们，这样就可以均平了。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:18; 路加福音 22:35"> 正如圣经上说：“多拾的没有剩余，少拾的也没有缺乏。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记16:18。">a</a></sup></span>
</div>
</div>

## 托人送捐款

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 17:17; 耶利米书 32:40; 哥林多后书 2:13–14"> 感谢上帝！祂感动了提多的心，使他像我一样热诚地关怀你们。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:6; 希伯来书 13:22; 哥林多后书 8:10"> 这固然是他听了我们的劝告，但也是他自己非常热诚，自愿去你们那里。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多前书 7:17"> 我们还要派一位弟兄和他同去，这位弟兄在传福音的事上得到各地教会的赞许。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 16:3–4; 哥林多后书 4:15; 哥林多后书 9:8"> 此外，他还受各教会的委派与我们同行，把交给我们的捐款送去，使主得荣耀，并表明我们热诚相助的心。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 5:22; 罗马书 14:16; 以弗所书 5:15"> 我们这样做是为了避免有人挑我们的不是，因我们经手的捐款数目可观。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:17; 彼得前书 2:12; 腓立比书 4:8"> 无论在主面前或在人面前，我们务求行事为人光明磊落。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:20–22"> 我们还要再派一位弟兄和他们一同去你们那里。我们经过多次多方的考验，证实他很热心，而且他因为十分信任你们，现在更热心了。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 2:25; 腓利门书 1:17; 哥林多后书 8:6"> 至于提多，他是我的同伴，与我一同服侍你们。另外两位弟兄是众教会的代表，是基督的荣耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 7:14; 哥林多后书 7:4; 哥林多后书 9:2–4"> 所以，你们要在众教会面前向他们证明你们的爱心，以及我夸耀你们的话并非虚言。</span>
</div>

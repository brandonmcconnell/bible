## 保罗的荐信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:11; 哥林多后书 10:12; 哥林多后书 5:12"> 难道我们又是在称赞自己吗？难道我们像别人一样，需要拿着推荐信去见你们，或拿着你们的推荐信去见别人吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 9:1–2; 帖撒罗尼迦前书 1:8; 罗马书 1:8"> 你们自己就是我们的推荐信，写在了我们心坎上，众所周知，人人可读。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 11:19; 耶利米书 31:33; 希伯来书 8:10"> 显然，你们是从基督而来的一封信，是我们工作的成果。这信不是用笔墨写成的，而是借着永活上帝的灵写成的；不是写在石版上的，而是刻在心版上的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 以弗所书 3:12; 哥林多后书 2:14"> 我们靠着基督在上帝面前有这样的确信。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:9; 腓立比书 4:13; 哥林多前书 15:10"> 我们并不认为自己能够承担什么，我们能够承担全是靠上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 6:63; 罗马书 7:6; 耶利米书 31:31"> 祂使我们能够担任新约的执事。这新约不是用律法条文立的，而是圣灵的工作，因为律法条文带来死亡，但圣灵赐下生命。</span>
</div>
</div>

## 新约的荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:9–11; 罗马书 10:4; 出埃及记 31:18"> 这带来死亡、刻在石版上的律法条文事工尚且有荣耀，甚至使摩西的脸上发出荣光，尽管很快就消逝了，以色列人仍然无法定睛看他，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:16; 以弗所书 2:18; 加拉太书 3:14"> 那么圣灵的事工岂不更有荣耀吗？</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 3:21–22; 希伯来书 12:18–21; 哥林多后书 5:21"> 那定人罪的事工尚且有荣耀，这赐人义的事工岂不更有荣耀吗？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:17; 哈该书 2:7–9; 使徒行传 26:13"> 其实先前的荣耀和现今的大荣耀相比，就黯然失色了。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:20–21; 希伯来书 8:13; 希伯来书 7:21–25"> 那渐渐消逝的尚且有荣耀，这永远长存的更是荣耀无比。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 7:4; 使徒行传 4:13; 腓立比书 1:20"> 我们因为有这极大的盼望，就放胆无惧，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:33–35; 希伯来书 10:1–9; 以弗所书 2:14–15"> 不像摩西将帕子蒙在脸上，以免以色列人看见那渐渐消逝的荣光。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:3–4; 使徒行传 26:18; 罗马书 11:25"> 但以色列人心里刚硬，直到今日，他们每逢读旧约的时候，同样的帕子还在那里，没有揭去。因为只有在基督里，那帕子才能被除去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:27–29"> 时至今日，每逢他们读摩西律法的时候，帕子仍然蒙在他们心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:34; 以赛亚书 29:18; 以赛亚书 25:7"> 然而，他们一旦归向基督，那帕子就被除去了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:2; 加拉太书 5:13; 约翰福音 8:32"> 主就是那灵，主的灵在哪里，哪里就有自由。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:6; 以弗所书 4:22–24; 罗马书 12:2"> 我们这些脸上不再蒙着帕子的人，可以像镜子一样反映主的荣光，渐渐变成主的样子，荣上加荣。这都是主的作为，主就是那灵。</span>
</div>
</div>

## 保罗得到的异象和启示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:12; 哥林多后书 12:7; 约翰一书 5:20"> 自夸虽然无益，但我不得不继续夸下去，谈谈主给我的异象和启示。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:17; 以西结书 8:1–3; 帖撒罗尼迦前书 4:17"> 我知道一位基督徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此人就是保罗本人，他不愿夸耀自己的经历。">a</a></sup>在十四年前曾被提到第三层天上，是在肉身之内还是在肉身之外，我不知道，只有上帝知道。</span>
<span className="v" id="v3" data-v="3"> 我知道这个人曾被提到天上的乐园里，听见了人不可言传的隐秘事，是在肉身之内还是在肉身之外，我不知道，只有上帝知道。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:30; 哥林多前书 2:3; 哥林多后书 12:9–10"> 我要为这人夸口。至于我自己，我除了夸耀自己的软弱以外，别无可夸。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:16; 哥林多后书 11:31; 哥林多后书 12:11"> 就算我夸口，也不是傻瓜，因为我所说的都是实话。只是我不会这样做，恐怕有人把我看得太高，超过了他对我的所见所闻。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:55; 士师记 2:3; 历代志下 32:25–26"> 为了使我不至于因所受的启示太大而自高，有一根刺在我身上，就是有撒旦的爪牙攻击我，免得我骄傲自大。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 5:7; 马太福音 26:39–44; 撒母耳记上 15:11"> 我曾三次祈求主叫这根刺离开我，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 4:13; 哥林多后书 12:10; 以赛亚书 40:29–31"> 但祂说：“我的恩典足够你用，因为我的能力在人的软弱上更显得全备。”所以，我更喜欢夸耀自己的软弱，好让基督的能力荫庇我。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 以弗所书 6:10; 罗马书 5:3"> 因此，为了基督的缘故，我欣然面对软弱、凌辱、艰难、迫害和困苦，因为我什么时候软弱，就什么时候刚强。</span>
</div>
</div>

## 保罗关怀哥林多人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 11:5; 哥林多后书 11:1; 哥林多前书 15:8–10"> 我成了“傻瓜”，是被你们逼的！你们本该称许我才对。我虽然算不了什么，却没有一点比不上那些“超级使徒”。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:18–19; 哥林多后书 11:4; 哥林多后书 4:2"> 我在你们中间百般地忍耐，用神迹、奇事、异能证明自己是使徒。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 9:12; 哥林多前书 9:6; 哥林多后书 11:7–9"> 你们什么地方不及其他教会呢？唯一的区别是我没有成为你们的负担！希望各位原谅我的不公道！</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 创世记 24:35–36; 哥林多前书 10:33"> 如今我打算第三次到你们那里去。我不会拖累你们，因为我想得到的是你们，而不是你们的财物。儿女不必为父母积财，父母应当为儿女积财。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:8; 哥林多后书 1:6; 腓立比书 2:17"> 为了你们的灵魂，我甘愿付出，包括自己的生命。难道我越爱你们，就越得不到你们的爱吗？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:5; 哥林多后书 10:2–3; 哥林多后书 12:13"> 算了！我没有拖累过你们，但竟然有人说我狡猾，用诡计骗你们。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 9:5; 哥林多前书 4:17; 列王纪下 5:20–27"> 请问，在我派到你们那里的人当中，我借着谁占过你们的便宜呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:6; 罗马书 4:12; 使徒行传 20:33–35"> 我恳求提多去你们那里，并派弟兄与他同去。难道提多占过你们的便宜吗？我们行事为人岂不是心灵相通，步调一致吗？</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:1; 哥林多前书 14:26; 哥林多后书 10:8"> 你们一直以为我们是替自己辩白，其实我们这番话是在基督里、在上帝面前说的。亲爱的弟兄姊妹，这一切都是为了造就你们。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:19–21; 彼得前书 2:1; 罗马书 1:29"> 因为我怕到你们那里的时候，我对你们的期望会落空，而你们对我也大失所望。我怕你们当中有纷争、嫉妒、恼怒、仇恨、毁谤、闲话、狂傲和混乱。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 彼得前书 4:2–3; 歌罗西书 3:5"> 我怕再去你们那里时，我的上帝会使我在你们面前感到羞愧，又怕看到许多从前犯罪、道德败坏、淫乱放荡的人仍然不肯悔改，便心里悲伤。</span>
</div>
</div>

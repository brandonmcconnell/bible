## 爱之深责之切

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:23; 哥林多后书 12:20–21; 哥林多后书 13:10"> 我已经决定了，下次到你们那里时不再使大家忧伤。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:8; 哥林多后书 1:14; 哥林多前书 12:26"> 如果我使你们忧伤，那么除了因我而忧伤的你们，还有谁能使我喜乐呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:10; 哥林多后书 8:22; 腓利门书 1:21"> 我曾为这事写信给你们，免得我到你们那里时，那些本该使我喜乐的人反而使我忧伤。我也深信你们会以我的喜乐为你们的喜乐。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 7:12; 箴言 27:5–6; 利未记 19:17–18"> 我心里万分难过、泪流满面地给你们写了前一封信，并非要使你们忧伤，而是要你们明白我是多么爱你们。</span>
</div>
</div>

## 要饶恕犯罪的人

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:12–13; 加拉太书 4:12; 箴言 17:25"> 那个令人忧伤的人与其说使我忧伤，倒不如说使大家都有几分忧伤。我只说几分忧伤，是怕说得太重。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 5:4–5; 提摩太前书 5:20; 哥林多后书 7:11"> 这样的人受了众人的谴责也就够了。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:32; 加拉太书 6:1–2; 歌罗西书 3:13"> 你们现在要饶恕他、安慰他，免得他忧伤过度而一蹶不振。</span>
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:22–23; 加拉太书 6:1–2; 加拉太书 6:10"> 我劝你们要让他确实知道你们仍然爱他。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 10:6; 腓利门书 1:21; 腓立比书 2:22"> 为此，我也曾写信给你们，要考验你们，看你们是否凡事顺服。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:23; 马太福音 18:18; 哥林多后书 5:20"> 你们饶恕谁，我也饶恕谁。我若饶恕，是为了你们的缘故在基督面前饶恕的，</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 5:8; 以弗所书 6:11–12; 哥林多后书 11:3"> 免得撒旦乘虚而入，因为我们并非不知道它的诡计。</span>
</div>
</div>

## 基督的香气

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:8; 使徒行传 14:27; 歌罗西书 4:3"> 我前往特罗亚传扬基督的福音时，主为我打开了传福音的大门。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 7:5–6; 哥林多后书 12:18; 提多书 1:4"> 那时，因为没有找到提多弟兄，我心里不安，便辞别众人前往马其顿。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 5:2; 罗马书 8:37; 哥林多后书 2:15–16"> 感谢上帝，祂常常在基督里率领我们走在凯旋的行列中，又借着我们到处散发那因认识基督而有的香气。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:2; 哥林多前书 1:18; 以西结书 20:41"> 不论是在得救的人当中还是在灭亡的人当中，对上帝来说，我们都是基督的馨香之气。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5–6; 约翰福音 9:39; 彼得前书 2:7–8"> 对灭亡的人而言，这香气是叫人死亡的香气；对得救的人来说，这香气却是叫人得生命的香气。谁能担当这样的重任呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 4:2; 哥林多后书 1:12; 彼得后书 2:1–3"> 我们并不像许多人为了牟利而出卖上帝的道。我们是上帝差遣的，在上帝面前靠着基督诚诚实实地讲道。</span>
</div>
</div>

## 问候

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 1:1; 提摩太前书 6:3; 提摩太后书 2:25"> 我保罗做上帝的奴仆和耶稣基督的使徒，是为了使上帝拣选的人有信心并明白真理，从而过敬虔的生活，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:19; 约翰一书 2:25; 提摩太后书 1:9"> 有永生的盼望。这永生是从不说谎的上帝在亘古以前应许的。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:11; 提多书 3:4–6; 提摩太前书 1:1"> 祂在所定的时候，借着人的传扬将自己的道显明出来。我奉我们救主上帝的命令传扬这道。</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 1:2; 犹大书 1:3; 彼得后书 1:1"> 提多啊，我写信给你，就我们共同的信仰来说，你是我真正的儿子。 愿父上帝和我们的救主基督耶稣赐给你恩典和平安！</span>

## 长老的资格

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:23; 提摩太前书 1:3; 传道书 12:9"> 当初，我把你留在克里特岛，是要你完成未办完的事工，并照我的指示在各城选立长老。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 3:2–7; 提摩太前书 3:12; 提多书 1:6–8"> 做长老的必须无可指责，只有一位妻子，儿女都信主、没有放荡不羁的行为。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:18; 彼得后书 2:10; 彼得前书 4:10"> 身为上帝的管家，做监督的必须无可指责，不傲慢，不暴躁，不酗酒，不好斗，不贪财。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 3:2; 提多书 2:7; 列王纪上 5:7"> 他必须好客、乐善、自制、正直、圣洁、自律，</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 2:15; 提摩太后书 1:13; 提摩太前书 6:3"> 持守所领受的真道，以便能够以纯正的教导劝勉人，驳倒那些反对的人。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 1:6; 约翰一书 4:1; 加拉太书 2:4"> 因为有许多悖逆之人喜欢空谈，善于欺骗，尤其是那些奉行割礼的人。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 3:6; 提摩太前书 6:5; 罗马书 3:19"> 你一定要堵住他们的口，因为他们为了不义之财教不该教的，毁坏别人全家。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 16:18; 提摩太前书 4:2; 使徒行传 17:28"> 克里特人自己的一位先知说：“克里特人说谎成性，邪恶如兽，好吃懒做。”</span>
<span className="v" id="v13" data-v="13" data-xref="提多书 2:2; 提摩太前书 5:20; 提多书 2:15"> 这话是真的。因此你要严正地斥责他们，使他们有纯正的信仰，</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:4; 歌罗西书 2:22; 加拉太书 4:9"> 不理会犹太人的无稽之谈和那些违背真理之人的诫律。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:14; 罗马书 14:20; 哥林多前书 10:23"> 对洁净的人而言，一切都是洁净的；对污秽不信的人而言，什么都不洁净，连他们的思想和良心都是污秽的。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 2:4; 以赛亚书 29:13; 以弗所书 5:6"> 他们自称认识上帝，在行为上却否认祂。他们令人可憎，悖逆成性，一无是处。</span>
</div>
</div>

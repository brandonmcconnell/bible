## 圣灵降临

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:6; 腓立比书 2:2; 使徒行传 1:13–15"> 五旬节那天，门徒都聚集在一起。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:31; 列王纪上 19:11; 诗篇 18:10"> 忽然，天上发出一阵响声，好像狂风呼啸而过，充满了他们所在的房子，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 3:11; 约翰福音 1:32–33; 耶利米书 23:29"> 又有火焰般的舌头显现出来，分别落在各人的头上。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:17; 使徒行传 13:52; 使徒行传 4:31"> 大家都被圣灵充满，靠着圣灵所赐的能力说起别的语言来。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行传 8:2; 歌罗西书 1:23"> 当时耶路撒冷住着从各国回来的虔诚的犹太人。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 2:3; 哥林多前书 16:9; 使徒行传 2:2"> 众人听见这阵响声便赶过来，听见门徒在说他们各自的语言，都十分纳闷，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:12; 使徒行传 1:11; 约翰福音 7:52"> 惊诧地说：“看啊！这些说话的不都是加利利人吗？</span>
<span className="v" id="v8" data-v="8"> 怎么会说我们各自的家乡话呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:1; 使徒行传 18:2; 启示录 1:4"> 我们有帕提亚人、玛代人、以拦人，以及住在美索不达米亚、犹太、加帕多迦、本都、亚细亚、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:6; 撒迦利亚书 8:23; 撒迦利亚书 8:20"> 弗吕迦、旁非利亚、埃及和靠近古利奈的利比亚地区的人，还有从罗马来的犹太人和改信犹太教的人、</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:10; 出埃及记 15:11; 诗篇 78:4"> 克里特人和阿拉伯人。我们都听见他们在用我们各自的语言诉说上帝的大能作为！”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行传 17:20; 路加福音 18:36"> 他们都大感惊奇和困惑，彼此议论说：“这到底是怎么回事？”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:23; 使徒行传 2:15; 撒母耳记上 1:14"> 有些人就讥笑说：“他们不过是被新酒灌醉了！”</span>
</div>
</div>

## 彼得讲道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 51:7; 以赛亚书 51:1; 申命记 27:9"> 彼得和其他十一位使徒都站起来，他大声对众人说：“各位犹太同胞和住在耶路撒冷的人啊，请留心听！我告诉你们这是怎么回事。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:5–8; 撒母耳记上 1:15; 马太福音 20:3"> 你们以为这些人是醉了，其实不是，因为现在才早上九点钟。</span>
<span className="v" id="v16" data-v="16" data-xref="约珥书 2:28–32"> 你们眼前看见的正是先知约珥所说的，</span>
<span className="v" id="v17" data-v="17" data-xref="约珥书 2:28–32; 以赛亚书 44:3; 提多书 3:4–6"> <span className="pl pl-1">“‘上帝说，在末后的日子，</span><br /><span className="pl pl-1">我要将我的灵浇灌所有的人，</span><br /><span className="pl pl-1">你们的儿女要说预言，</span><br /><span className="pl pl-1">青年要见异象，</span><br /><span className="pl pl-1">老人要做异梦。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:28; 歌罗西书 3:11; 哥林多前书 7:21–22"> <span className="pl pl-1">那时，我要将我的灵浇灌我的奴仆和婢女，</span><br /><span className="pl pl-1">他们都要说预言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:30–31; 西番雅书 1:14–18; 玛拉基书 4:1–6"> <span className="pl pl-1">我要在天上显异兆；</span><br /><span className="pl pl-1">我要在地上行神迹，有血、有火、有浓烟。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:10; 阿摩司书 8:9; 马太福音 24:29"> <span className="pl pl-1">太阳要变得昏暗，</span><br /><span className="pl pl-1">月亮要变得血红。</span><br /><span className="pl pl-1">这都要发生在主伟大荣耀的日子来临以前。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 10:12–13; 约珥书 2:32; 诗篇 86:5"> <span className="pl pl-1">那时，凡求告主名的人都必得救。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约珥书2:28‑32。">a</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 3:2; 约翰福音 14:10–11; 马太福音 12:28"> “各位以色列人啊，请听我说。上帝借着拿撒勒人耶稣在你们中间行了异能、奇事和神迹，以证明这人是祂委派的，这是你们自己所知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行传 4:28; 使徒行传 3:18"> 耶稣按上帝的定旨和先见被交在你们手里，你们借着邪恶之人的手把祂钉死在十字架上了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 6:14; 彼得前书 1:21; 使徒行传 2:32"> 但上帝为祂解除了死亡的痛苦，使祂从死里复活，因为祂不可能被死亡拘禁。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 16:8–11; 以赛亚书 41:13; 诗篇 62:6"> 大卫曾这样谈论耶稣，<br /><span className="pl pl-1">“‘我看见主常在我面前，</span><br /><span className="pl pl-1">祂在我右边，我必不动摇。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 16:9; 诗篇 63:5; 诗篇 71:23"> <span className="pl pl-1">因此我的心欢喜，我的口颂赞，</span><br /><span className="pl pl-1">我的身体也要活在盼望中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:10; 使徒行传 2:31; 启示录 1:18"> <span className="pl pl-1">因为你不会把我的灵魂撇在阴间，</span><br /><span className="pl pl-1">也不会让你的圣者身体朽坏。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 16:11; 诗篇 25:4; 诗篇 21:6"> <span className="pl pl-1">你已把生命之路指示我，</span><br /><span className="pl pl-1">叫我在你面前充满喜乐。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇16:8‑11。">b</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 13:36; 列王纪上 2:10; 使徒行传 7:8–9"> “弟兄们，我肯定地对你们说，先祖大卫死了，埋葬了，他的坟墓至今还在我们这里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 132:11–18; 诗篇 89:3–4; 耶利米书 33:14–15"> 大卫是先知，知道上帝曾对他起誓——要从他的后裔中选立一人继承他的王位。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 2:27; 诗篇 16:10; 使徒行传 13:35"> 他预先知道这事，讲到基督的复活，说，‘祂的灵魂不会被撇在阴间，祂的身体也不会朽坏。’</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 3:15; 使徒行传 1:8; 使徒行传 1:22"> 上帝已经使这位耶稣复活了！我们都是这件事的见证人。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:4; 使徒行传 5:31; 使徒行传 2:17"> 现在祂被提升到上帝的右边，从天父领受了所应许的圣灵之后，便将圣灵浇灌下来，你们今天也耳闻目睹了。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 110:1; 马太福音 22:42–45; 希伯来书 1:13"> 大卫并没有升到天上，但他曾说，<br /><span className="pl pl-1">“‘主对我主说，</span><br /><span className="pl pl-1">你坐在我的右边，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="启示录 19:19–3; 罗马书 16:20; 以赛亚书 60:14"> <span className="pl pl-1">等我使你的仇敌成为你的脚凳。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇110:1。">c</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 5:30–31; 罗马书 14:8–12; 哥林多后书 5:10"> “所以，全体以色列人啊！你们应当确实地知道，上帝已经立这位被你们钉在十字架上的耶稣为主，为基督了。”</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行传 22:10; 希伯来书 4:12–13"> 他们听了这番话，觉得扎心，就对彼得和其他使徒说：“弟兄们，我们该怎么办呢？”</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:16; 马可福音 16:16; 使徒行传 8:12"> 彼得说：“你们每一个人都要悔改，奉耶稣基督的名受洗，使你们的罪得到赦免，你们就必领受上帝所赐的圣灵。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 44:3; 创世记 17:7–8; 罗马书 8:30"> 因为这应许是给你们和你们的儿女，以及远方的人，就是所有被主——我们的上帝呼召的人。”</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:15; 申命记 32:5; 马太福音 17:17"> 然后，彼得还讲了其他许多话警戒、劝勉他们，说：“你们要救自己脱离这邪恶的世代。”</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 4:4; 使徒行传 2:47; 使徒行传 16:31–34"> 结果，那天约有三千人相信了他传的道，接受了洗礼。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 10:25; 使徒行传 1:14; 约翰一书 1:3"> 他们都一心遵守使徒的教导，一起团契、掰饼、祷告。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 约翰福音 14:12; 路加福音 8:37"> 大家都满心敬畏上帝。使徒又行了很多神迹奇事。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 4:32; 约翰一书 3:16–18; 哥林多后书 8:14–15"> 信徒聚在一起，共用所有的东西。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰一书 3:17; 提摩太前书 6:18–19; 雅各书 2:14–16"> 他们把田产家业变卖了，按照各人的需要分给大家。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 5:42; 使徒行传 20:7; 使徒行传 2:42"> 他们天天同心合意地聚集在圣殿里敬拜上帝，又在各人家中掰饼聚会，怀着欢喜和慷慨的心分享食物，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 16:5; 使徒行传 5:13–14; 使徒行传 2:41"> 赞美上帝，受到众人的喜爱。主使得救的人数与日俱增。</span>

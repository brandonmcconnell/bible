## 巴拿巴和扫罗接受差遣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:36; 使徒行传 15:35; 使徒行传 11:22–27"> 安提阿教会中有几位先知和教师，就是巴拿巴、绰号“黑人”的西缅、古利奈人路求、与分封王希律一同长大的马念，还有扫罗。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 1:15; 使徒行传 9:15; 哥林多前书 12:11"> 一天，他们正在敬拜主、禁食的时候，圣灵对他们说：“要为我把巴拿巴和扫罗分别出来，好让他们做我呼召他们去做的事。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:6; 提摩太后书 2:2; 使徒行传 13:2"> 于是，他们禁食祷告并把手按在巴拿巴和扫罗身上，然后差遣他们出去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 13:2; 使徒行传 11:19"> 二人受圣灵差遣，下到西流基，从那里乘船去塞浦路斯。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 13:14; 使徒行传 13:46; 使徒行传 14:1"> 他们到了撒拉米，就在各犹太会堂传讲上帝的道。约翰·马可做他们的助手。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:15; 约翰一书 4:1; 哥林多后书 11:13"> 他们走遍全岛，远至帕弗，在那里遇见一个犹太术士兼假先知巴·耶稣。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:38; 使徒行传 13:12; 使徒行传 18:12"> 这人和当地的士求·保罗总督常有来往。士求·保罗是个聪明人，他邀请了巴拿巴和扫罗来，要听上帝的道。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 3:8; 使徒行传 13:6–7; 提摩太后书 4:14–15"> 但希腊名字叫以吕马的这个术士反对使徒，试图拦阻总督信主。</span>
<span className="v" id="v9" data-v="9" data-xref="弥迦书 3:8; 使徒行传 4:8; 使徒行传 2:4"> 又名保罗的扫罗被圣灵充满，盯着他说：</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:44; 哥林多后书 11:3; 马太福音 13:38"> “你这魔鬼的儿子，充满各种诡诈和邪恶，是一切正义之敌，到现在还想歪曲主的正道吗？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 9:3; 诗篇 32:4; 希伯来书 10:31"> 现在主要亲手惩罚你，使你瞎眼，暂时不见天日！”<br />他顿觉眼前一片漆黑，只好四处摸索，求人领他走路。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 10:4–5; 使徒行传 13:7; 路加福音 4:22"> 总督看见所发生的事，被主的道震撼，就信了。</span>
</div>
</div>

## 保罗传扬基督

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 15:38; 使徒行传 2:10; 使徒行传 14:24–25"> 保罗和同伴从帕弗乘船到旁非利亚的别加。约翰·马可在那里离开他们，回耶路撒冷去了。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:13; 使徒行传 14:19; 使徒行传 13:5"> 他们由别加继续前行，来到彼西底区的安提阿。在安息日那天，他们进了会堂坐下来。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:22; 使徒行传 15:21; 马可福音 5:22"> 读完律法书和先知书后，会堂主管派人告诉他们：“弟兄们，你们若有什么劝勉众人的话，请讲。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 12:17; 使徒行传 13:26; 使徒行传 10:2"> 保罗站起来向大家挥手示意，说：“各位以色列同胞和各位敬畏上帝的外族朋友们，请听我说。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 7:6–8; 以赛亚书 63:9–14; 诗篇 105:23–24"> 以色列的上帝拣选了我们的祖先，让他们在埃及寄居期间壮大起来，后来祂伸出臂膀带领他们离开埃及。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 7:36; 诗篇 95:8–11; 诗篇 106:13–29"> 在旷野大约有四十年之久，上帝一直容忍<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“容忍”有古卷作“照顾”。">a</a></sup>他们。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 7:1; 诗篇 78:55; 使徒行传 7:45"> 后来上帝又灭了迦南境内的七族，把土地分给他们作产业，</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 2:16; 撒母耳记上 3:20; 列王纪下 23:22"> 前后历时约四百五十年。之后，上帝又为他们设立士师，直到撒母耳先知的时代。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 10:1; 撒母耳记上 15:1; 撒母耳记上 12:12–19"> “后来，他们求上帝为他们立一位王，上帝就选立便雅悯支派中基士的儿子扫罗做他们的王，执政四十年。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 13:13–14; 列王纪上 15:5; 诗篇 78:70–72"> 之后，上帝废掉扫罗，选立大卫做王，并为他作证说，‘我找到了耶西的儿子大卫，他是合我心意的人，他必遵行我一切的旨意。’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:1; 诗篇 132:11; 启示录 22:16"> 上帝照自己的应许，从大卫的后裔中为以色列人立了一位救主，就是耶稣。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 1:22; 约翰福音 1:6–8; 路加福音 3:2–20"> 在耶稣公开露面以前，约翰已向所有以色列人宣讲悔改的洗礼。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 3:11; 马可福音 1:7; 约翰福音 1:26–27"> 约翰在工作快要完成的时候说，‘你们以为我是谁？我不是那一位。在我之后来的那一位，我连给祂解鞋带都不配。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:77; 罗马书 1:16; 路加福音 1:69"> “弟兄们，各位亚伯拉罕的子孙和敬畏上帝的外族人啊，这救恩之道原是传给我们的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 3:17; 路加福音 24:24–27; 路加福音 24:20"> 可是耶路撒冷的居民和他们的官长不知道耶稣是基督，虽然每个安息日都诵读先知的信息，却把基督判死罪。这正应验了先知们的话。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 23:21–25; 路加福音 23:14–16; 约翰福音 19:4"> 他们虽然找不到判祂死罪的理由，却强求彼拉多将祂处死。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 23:53; 约翰福音 19:28; 约翰福音 19:30"> 祂受死的记载全部应验之后，有人把祂从十字架上取下来，安放在坟墓里。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:24; 使徒行传 17:31; 马太福音 28:6"> 但上帝却使祂从死里复活。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:48; 使徒行传 1:3; 使徒行传 1:11"> 之后有许多天，那些从加利利跟随祂上耶路撒冷的人都看见过祂，他们如今在百姓中都是祂的见证人。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 4:13; 使徒行传 26:6; 以西结书 34:23"> 我们要报给你们一个好消息，就是上帝给我们祖先的应许，</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 2:7; 希伯来书 5:5; 希伯来书 1:5–6"> 祂透过使耶稣复活已为我们这些做子孙的成就了。正如诗篇第二篇所说，<br /><span className="pl pl-1">“‘你是我的儿子，</span><br /><span className="pl pl-1">我今日成为你父亲。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇2:7。">b</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 55:3; 诗篇 89:2–4; 罗马书 6:9"> 上帝曾这样谈到祂使耶稣从死里复活、永不朽坏的事，<br /><span className="pl pl-1">“‘我必将应许大卫的圣洁、</span><br /><span className="pl pl-1">可靠的恩福赐给你们。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书55:3。">c</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="诗篇 16:10; 使徒行传 2:27–31; 诗篇 49:9"> 又在诗篇上说，<br /><span className="pl pl-1">“‘你必不让你的圣者身体朽坏。’</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇16:10。">d</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:29; 撒母耳记下 7:12; 列王纪上 2:10"> “大卫在世时遵行上帝的旨意，最后死了，葬在他祖先那里，身体也朽坏了。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 13:30; 使徒行传 2:24"> 然而，上帝使之复活的那位却没有朽坏。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 24:47; 约翰一书 2:12; 哥林多后书 5:18–21"> 所以，弟兄们，你们应该知道，赦罪的信息是借着耶稣传给你们的。</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 10:4; 加拉太书 2:16; 罗马书 8:3"> 你们靠遵行摩西律法不能被称为义人，只有信靠耶稣才能被称为义人。</span>
<span className="v" id="v40" data-v="40" data-xref="玛拉基书 4:1; 希伯来书 3:12; 玛拉基书 3:2"> 你们要当心，免得先知说的话应验在你们身上，</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷书 1:5; 彼得前书 4:17; 罗马书 11:7–14"> <span className="pl pl-1">“‘藐视真理的人啊，看吧！</span><br /><span className="pl pl-1">你们要在惊惧中灭亡，</span><br /><span className="pl pl-1">因为我要在你们的时代行一件事，</span><br /><span className="pl pl-1">即使有人告诉你们，</span><br /><span className="pl pl-1">你们也绝不会相信。’</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="哈巴谷书1:5。">e</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒行传 28:28; 使徒行传 10:33; 马太福音 19:30"> 保罗和巴拿巴离开会堂时，会堂里的人请求他们下一个安息日再来讲道。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 11:23; 使徒行传 14:22; 以弗所书 2:8"> 散会以后，许多犹太人和诚心改信犹太教的外族人都跟随保罗和巴拿巴，二人就与他们谈论，劝勉他们要坚定不移地信靠上帝的恩典。</span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="诗篇 110:3; 创世记 49:10; 以赛亚书 11:10"> 到了下一个安息日，几乎全城的人都聚集起来，要听主的道。</span>
<span className="v" id="v45" data-v="45" data-xref="犹大书 1:10; 使徒行传 18:6; 使徒行传 5:17"> 犹太人看见那么多人聚集，充满嫉妒，便反驳保罗所讲的，诽谤他。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 28:28; 马太福音 21:43; 使徒行传 18:5–6"> 保罗和巴拿巴毫不畏惧地说：“上帝的道本该先传给你们，你们既然拒绝接受，认为自己不配得永生，我们现在就去传给外族人。</span>
<span className="v" id="v47" data-v="47" data-xref="以赛亚书 49:6; 以赛亚书 42:6; 路加福音 2:32"> 因为主这样吩咐我们，<br /><span className="pl pl-1">“‘我已使你成为外族人的光，</span><br /><span className="pl pl-1">好把救恩带到地极。’</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以赛亚书49:6。">f</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="罗马书 8:29–30; 以弗所书 1:4; 罗马书 11:7"> 外族人听后，非常欢喜，颂赞主的道。凡被选定得永生的人都信了主。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 12:24; 使徒行传 19:10; 使徒行传 19:26"> 主的道传遍了那个地方。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行传 14:19; 使徒行传 13:45; 使徒行传 14:2"> 但犹太人煽动虔诚的贵妇和城中显要迫害保罗和巴拿巴，把二人从当地赶走。</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 10:14; 使徒行传 18:6; 路加福音 9:5"> 保罗和巴拿巴便当众跺掉脚上的尘土<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="表示两不相干，参见马太福音10:14。">g</a></sup>，去了以哥念。</span>
<span className="v" id="v52" data-v="52" data-xref="罗马书 15:13; 帖撒罗尼迦前书 1:6; 使徒行传 4:31"> 门徒满心喜乐，被圣灵充满。</span>
</div>
</div>

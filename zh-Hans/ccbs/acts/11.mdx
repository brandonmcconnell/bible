## 彼得的解释

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 22:27; 玛拉基书 1:11; 以赛亚书 32:15"> 使徒和犹太全境的弟兄姊妹都听说外族人接受了上帝的道。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:45; 使徒行传 10:9; 使徒行传 15:1"> 彼得一回到耶路撒冷，严守割礼的信徒就指责他：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:28; 加拉太书 2:12; 路加福音 15:2"> “你竟然去未受割礼之人的家，还和他们一同吃饭！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行传 14:27; 约书亚记 22:21–31"> 彼得就把事情的经过一一向他们解释，说：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 10:9–32; 使徒行传 9:10; 使徒行传 22:17"> “我在约帕城祷告的时候，看见一个异象，有个东西好像一大块布，四角吊着从天上降到我面前。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行传 3:4"> 我仔细一看，见里面有四脚的牲畜、野兽、爬虫和飞禽。</span>
<span className="v" id="v7" data-v="7"> 接着，我听见有声音对我说，‘彼得，起来，宰了吃！’</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 14:14; 何西阿书 9:3; 哥林多前书 7:14"> 我说，‘主啊，这可不行！我从未吃过任何污秽不洁之物！’</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 15:9; 希伯来书 9:13–14; 使徒行传 10:34–35"> 那从天上来的声音又说，‘上帝已经洁净的，你不可再称之为不洁净。’</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 21:17; 民数记 24:10; 哥林多后书 12:8"> 这样一连三次，然后一切都被收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 4:27; 使徒行传 9:10–12; 出埃及记 4:14"> 就在那时候，有三个从凯撒利亚来的人到我住处的门口来找我。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:29; 罗马书 3:22; 帖撒罗尼迦后书 2:2"> 圣灵吩咐我跟他们同去，不要犹豫。就这样，我和这六位弟兄一同到了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:30–32; 使徒行传 10:3–6; 使徒行传 9:43"> 他告诉我们天使如何在他家中向他显现，并对他说，‘你派人去约帕，请一个叫西门·彼得的人来。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:15; 使徒行传 10:22; 使徒行传 16:31–34"> 他有话告诉你，能使你和你的全家得救。’</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 19:6; 使徒行传 10:34–46; 使徒行传 2:2–12"> “我开口讲话时，圣灵降在他们身上，跟当初降在我们身上的情形一模一样。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 1:5; 马可福音 1:8; 箴言 1:23"> 我就想起主的话，‘约翰用水施洗，但你们要受圣灵的洗。’</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:47; 罗马书 9:20–26; 但以理书 4:35"> 既然上帝赐给他们的恩赐，与赐给我们这些信主耶稣基督之人的一样，我是谁，怎能拦阻上帝？”</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:12–13; 哥林多后书 7:10; 以西结书 36:26"> 众人听了便安静下来，转而归荣耀给上帝，说：“如此看来，上帝把悔改得永生的机会也赐给了外族人。”</span>
</div>
</div>

## 安提阿的教会

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 4:36; 使徒行传 21:2; 使徒行传 15:3"> 司提凡殉道后，信徒们因受迫害而四散到各处，远至腓尼基、塞浦路斯和安提阿，他们只向那里的犹太人传福音。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 27:32; 使徒行传 13:1; 哥林多前书 1:23–24"> 不过，有些塞浦路斯和古利奈的信徒到了安提阿之后，也向希腊人传讲主耶稣的福音。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行传 2:47; 使徒行传 5:14"> 主的能力伴随着他们，有许多人相信并归向了主。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:27; 使徒行传 8:14; 使徒行传 13:1–3"> 耶路撒冷教会的人听到这消息后，就派巴拿巴去安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:58; 使徒行传 14:22; 使徒行传 13:43"> 他到了，看见上帝所赐的恩典后很高兴，就劝勉他们要全心地忠于主。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 11:21; 使徒行传 5:14; 使徒行传 9:31"> 巴拿巴是个被圣灵充满、信心坚定的好人。那时信主的人大大增加。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 9:11; 使徒行传 9:27; 使徒行传 9:30"> 他又到大数去找扫罗，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 4:16; 使徒行传 26:28; 彼得前书 4:14"> 找到后，便带他回安提阿。他们在教会待了一年之久，教导了许多人。门徒被称为“基督徒”就是从安提阿开始的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 13:1; 哥林多前书 12:28; 以弗所书 4:11"> 当时，有几位先知从耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 21:10; 使徒行传 18:2; 路加福音 3:1"> 其中一位名叫亚迦布，他得到圣灵的启示，站起来预言天下将有严重的饥荒。后来，这事果然在克劳狄执政期间发生了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 8:12–14; 加拉太书 2:10; 哥林多后书 8:2–4"> 门徒决定各尽所能，捐款救济住在犹太境内的弟兄姊妹。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:23; 使徒行传 12:25; 使徒行传 15:4"> 他们捐完后，委托巴拿巴和扫罗将款项送交当地教会的长老。</span>
</div>
</div>

</div>

## 保罗在亚基帕王面前申辩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 箴言 1:24; 使徒行传 26:2"> 亚基帕对保罗说：“准你为自己辩护。”于是保罗伸手示意，然后为自己辩护说：</span>
<span className="v" id="v2" data-v="2"> “亚基帕王啊，关于犹太人对我的所有控告，我今天很荣幸可以在你面前申辩，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:14; 使徒行传 26:26; 使徒行传 26:7"> 尤其是你对犹太习俗和争议都十分熟悉。因此，求你耐心听我说。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:13; 提摩太后书 3:10; 腓立比书 3:5"> “我从小在本族和耶路撒冷为人如何，犹太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 23:6; 使徒行传 22:3; 使徒行传 24:5"> 他们认识我很久了，如果肯作证的话，可以证明我一直属于犹太教中最严格的法利赛派。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:13; 使徒行传 24:15; 使徒行传 28:20"> 现在我是因为对上帝给我们祖先的应许充满盼望，才站在这里受审的。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:1; 腓立比书 3:11; 提摩太前书 5:5"> 我们十二支派日夜虔诚地事奉上帝，盼望这应许能够实现。王啊！我就是因为有这样的盼望，才被犹太人控告。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 15:12–20; 使徒行传 4:2; 使徒行传 17:31–32"> 上帝叫死人复活，你们为什么认为不可信呢？</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:13; 使徒行传 22:8; 腓立比书 3:6"> 我自己也曾经认为应该尽一切可能反对拿撒勒人耶稣的名。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 8:3; 使徒行传 9:13–14; 使徒行传 9:21"> 我在耶路撒冷就曾这样做。我得到祭司长的授权，把许多圣徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗在这里指的是信耶稣的基督徒。">a</a></sup>关进监狱。他们被判死刑，我也表示赞同。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 22:19; 马太福音 10:17; 使徒行传 13:45"> 我多次在各会堂惩罚他们，逼他们说亵渎的话，对他们深恶痛绝，甚至到外族城镇去追捕、迫害他们。</span>
</div>
</div>

## 保罗信主的经过

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:10; 使徒行传 22:5–11; 使徒行传 9:1–8"> “那时，我带着祭司长的授权和委托去大马士革。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 17:2; 启示录 21:23; 启示录 1:16"> 王啊！大约正午，我在路上看见一道比太阳还亮的光从天上四面照着我和同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:40; 使徒行传 22:2; 使徒行传 9:7"> 我们都倒在地上，我听见有声音用希伯来话对我说，‘扫罗！扫罗！你为什么迫害我？你用脚踢刺棍自讨苦吃。’</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 15:20–21; 马太福音 25:45; 出埃及记 16:8"> 我说，‘主啊，你是谁？’主说，‘我就是你所迫害的耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 22:14–15; 以西结书 2:1; 但以理书 10:11"> 你站起来。我向你显现，是要派你做我的仆人和见证人，把你所看见的和以后我将启示给你的事告诉世人。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:15; 提摩太前书 2:7; 耶利米书 1:19"> 我将把你从你的同胞和外族人手中救出来。我差遣你到他们那里，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:9; 以弗所书 1:18; 以弗所书 5:8"> 去开启他们的眼睛，使他们弃暗投明，脱离魔鬼的权势，归向上帝，好叫他们的罪得到赦免，与所有因信我而圣洁的人同得基业。’</span>
</div>
</div>

## 保罗放胆传道

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 50:5; 加拉太书 1:16; 以西结书 2:7–8"> “因此，亚基帕王啊！我没有违背这从天上来的异象。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 3:8; 使徒行传 3:19; 使徒行传 2:38"> 我先在大马士革，然后到耶路撒冷、犹太全境和外族人当中劝人悔改归向上帝，行事为人要与悔改的心相称。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 21:30–31; 使徒行传 21:27; 使徒行传 25:3"> 就因为这些事，犹太人在圣殿中抓住我，打算杀我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:14; 约翰福音 5:46; 罗马书 3:21"> 然而，我靠着上帝的帮助，到今天还能站在这里向所有尊卑老幼做见证。我讲的不外乎众先知和摩西说过将要发生的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:1–12; 路加福音 24:26; 歌罗西书 1:18"> 就是基督必须受害，并首先从死里复活，将光明带给犹太人和外族人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 2:13–14; 哥林多前书 1:23; 哥林多前书 4:10"> 这时，非斯都打断保罗的申辩，大声说：“保罗，你疯了！一定是你的学问太大，使你癫狂了！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:26; 提多书 1:9; 提多书 2:7–8"> 保罗说：“非斯都大人，我没有疯。我讲的话真实、合理。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3; 使徒行传 2:1–12; 以赛亚书 30:20"> 王了解这些事，所以我才敢在王面前直言。我相信这些事没有一件瞒得过王，因为这些事并非暗地里做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:22–23"> 亚基帕王啊，你信先知吗？我知道你信。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 马太福音 10:18; 使徒行传 26:29"> 亚基帕王对保罗说：“难道你想三言两语就说服我成为基督徒吗？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:20; 歌罗西书 1:28; 罗马书 10:1"> 保罗说：“不论话多话少，我求上帝不仅使你，也使今天在座的各位都能像我一样，只是不要带着这些锁链。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 18:15; 使徒行传 28:22; 使徒行传 25:23"> 亚基帕王、总督、百妮姬及其他在座的人都站起来，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 23:29; 使徒行传 23:9; 使徒行传 28:18"> 走到一边商量说：“这人没有做什么该判死刑或监禁的事。”</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 28:18; 使徒行传 25:11–12; 使徒行传 25:25"> 亚基帕王对非斯都说：“这人要是没有向凯撒上诉，已经可以获释了。”</span>
</div>
</div>

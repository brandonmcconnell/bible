## 保罗在哥林多传道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 1:2; 提摩太后书 4:20; 哥林多后书 1:1"> 这事之后，保罗离开雅典前往哥林多，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 16:3–4; 哥林多前书 16:19; 提摩太后书 4:19"> 在那里认识了一位在本都出生的犹太人亚居拉。由于克劳狄命令所有的犹太人离开罗马，他最近和妻子百基拉从意大利来到哥林多。保罗拜访了他们。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 4:12; 帖撒罗尼迦前书 2:9; 哥林多后书 11:9"> 他们夫妇跟保罗是同行，都以制造帐篷为业，保罗就留下来和他们同住，一起做工。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:11; 使徒行传 17:17; 使徒行传 28:23"> 保罗每个安息日都到会堂与犹太人和希腊人辩论，劝导他们信主。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14; 使徒行传 18:28; 使徒行传 20:21"> 西拉和提摩太从马其顿来了之后，保罗就把全部时间都用来传道，向犹太人证明耶稣是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 33:4; 撒母耳记下 1:16; 以西结书 33:8–9"> 可是，犹太人反对、毁谤保罗。保罗便抖掉衣服上的灰尘，对他们说：“你们的罪都归在你们自己头上，与我无关！从今以后，我要去外族人那里了。”</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:14; 歌罗西书 4:11; 使徒行传 10:2"> 保罗就离开那里，来到一个敬畏上帝、名叫提多·犹士都的人家里，他家就在会堂隔壁。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 1:13–17; 罗马书 10:14–17; 马可福音 16:15–16"> 会堂主管基利司布和他全家都信了主，许多哥林多人听了道后，也信了主，受了洗。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 23:11; 以弗所书 6:19–20; 使徒行传 27:23–25"> 一天晚上，主在异象中对保罗说：“不要怕，只管继续传讲，不要停！</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 出埃及记 4:12; 以赛亚书 41:10"> 因为我与你同在，没有人能够伤害你，在这城里还有许多属我的子民。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 14:3; 使徒行传 19:10; 使徒行传 20:31"> 保罗就在那里住了一年半，向他们传授上帝的道。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 13:50; 使徒行传 18:27; 使徒行传 13:7"> 迦流出任亚该亚总督时，犹太人联合起来攻击保罗，把他拉上法庭，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:8; 使徒行传 24:5–6; 使徒行传 6:13"> 说：“这个人教唆百姓不按律法敬拜上帝。”</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:14–15; 使徒行传 25:11; 马可福音 9:19"> 保罗刚要开口，迦流就对犹太人说：“你们这些犹太人！如果这事涉及什么罪行冤情，我当然会处理。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:29; 使徒行传 25:19; 提摩太前书 6:4"> 但如果只是关于字句、名称和你们犹太律法的争论，你们自己去解决吧，我不受理！”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 12:16; 诗篇 76:10; 罗马书 13:3–4"> 迦流随即把他们赶出了法庭。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:1; 阿摩司书 6:6; 使徒行传 17:32"> 众人揪住会堂主管所提尼，当庭把他痛打一顿。迦流却置之不理。</span>
</div>
</div>

## 保罗回到安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:18; 民数记 6:5–9"> 保罗继续在哥林多逗留了许多时日，才向弟兄姊妹道别。他和百基拉、亚居拉乘船前往叙利亚。保罗因为许过愿，就在坚革哩剃了头发。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:1; 提摩太前书 1:3; 提摩太后书 1:18"> 到了以弗所，保罗离开亚居拉夫妇，独自进入会堂跟犹太人辩论。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:37–38; 哥林多前书 16:12; 使徒行传 20:16"> 众人请保罗多留几天，保罗谢绝了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 4:19; 雅各书 4:15; 罗马书 15:32"> 他向众人道别，说：“如果上帝许可，我还会回来。”然后上船离开了以弗所。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 8:40; 使徒行传 15:4; 使徒行传 23:23"> 他在凯撒利亚登岸后，先上耶路撒冷去问候教会，再下到安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 14:22; 使徒行传 16:6; 使徒行传 15:41"> 他在安提阿逗留了一些日子，然后离开那里，走遍加拉太和弗吕迦地区，坚固各地的门徒。</span>
</div>
</div>

## 亚波罗放胆传道

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 4:6; 提多书 3:13; 哥林多前书 3:5–6"> 那时有一个生于亚历山大、名叫亚波罗的犹太人来到以弗所。他博学善辩，熟悉圣经。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 19:3; 罗马书 12:11; 何西阿书 14:9"> 他在主的道上曾受过栽培，心里火热，能正确地讲解和教导有关耶稣的事，但他只知道约翰的洗礼。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:25; 使徒行传 14:3; 哥林多前书 12:21"> 他开始在会堂里勇敢地讲道。百基拉和亚居拉听了以后，便请他到家里，给他更详细地讲解上帝的道。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:13–14; 雅各书 1:16–18; 彼得前书 1:2–3"> 亚波罗有意去亚该亚，以弗所的弟兄姊妹就鼓励他，并写信请当地的门徒接待他。亚波罗到了之后，给当地蒙恩信主的人带来很大帮助。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 18:5; 哥林多前书 15:3–4; 使徒行传 9:22"> 他在公众面前有力地驳倒犹太人，引用圣经证明耶稣就是基督。</span>
</div>
</div>

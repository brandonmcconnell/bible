## 保罗在腓利斯面前受审

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:11; 使徒行传 23:2; 使徒行传 25:2"> 五天后，大祭司亚拿尼亚带着几个长老和一位叫帖土罗的律师下到凯撒利亚，向总督控告保罗。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行传 24:26–27"> 保罗被传来后，帖土罗控告他说：“腓利斯大人深谋远虑，在大人的领导下，国中有许多改革，我们常享太平。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 23:26; 使徒行传 26:25; 路加福音 1:3"> 我们对大人的恩德感激不尽。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:32"> 我不敢耽误大人太久，只求大人容我们简单叙述。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 28:22; 使徒行传 24:14; 使徒行传 26:5"> 我们发现这个人惹是生非，到处煽动犹太人闹事。他是拿撒勒教派的一个头目，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:12; 使徒行传 21:27–32; 约翰福音 18:31"> 企图玷污圣殿，被我们抓住了。</span>
<span className="v" id="v7" data-v="7"> 我们想按照犹太律法审问他，不料吕西亚千夫长却硬把他从我们手中抢走，并命令告他的人到大人这里来。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无7节。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 23:35; 使徒行传 25:15–16; 使徒行传 25:5"> 大人亲自审问他，就会知道我们告他的事了。”</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 2:16; 弥迦书 7:2–3; 诗篇 4:2"> 在场的犹太人也随声附和，断言这些事属实。</span>
</div>
</div>

## 保罗的申辩

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前书 3:15; 撒母耳记上 2:25; 路加福音 18:2"> 总督点头示意保罗可以发言，于是保罗说：“我知道大人在犹太执法多年，我很乐意当面为自己申辩。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:1; 使徒行传 21:18; 使徒行传 23:11"> 大人明鉴，从我上耶路撒冷礼拜至今不过十二天。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 25:8; 使徒行传 28:17; 使徒行传 24:18"> 这些人根本没有见过我在圣殿、会堂或城里与人争辩，或聚众闹事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:7; 彼得前书 3:16"> 他们对我的控告毫无证据。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:2; 罗马书 3:21; 使徒行传 3:13"> 但有一点我承认，就是我依照他们称之为异端的道事奉我们祖先的上帝，我也相信律法书和先知书的一切记载，</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 12:2; 约翰福音 5:28–29; 帖撒罗尼迦前书 4:14–16"> 并且我与他们对上帝拥有同样的盼望，就是义人和不义的人都要复活。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:1; 提摩太前书 1:5; 哥林多后书 4:2"> 因此，我一直尽力在上帝和人面前都存无愧的良心。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:10; 罗马书 15:25–28; 哥林多前书 16:1–4"> “我离开耶路撒冷已有多年，这次回来是带着捐款要周济同胞，并献上祭物。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:21; 使徒行传 21:26–30; 使徒行传 24:12"> 他们看见我的时候，我已行过洁净礼，正在圣殿里献祭，没有聚众，也没有作乱。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:30; 使徒行传 25:16"> 当时只有几个从亚细亚来的犹太人在那里，如果他们有事要告我，应该到你这里告我；</span>
<span className="v" id="v20" data-v="20"> 不然，请这些出庭的人指出他们在公会审问我时发现了什么罪。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:6; 使徒行传 4:2; 使徒行传 26:6–8"> 如果有，也无非是当时我站在他们当中喊了一句，‘我今天在你们面前受审与死人复活有关。’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:6; 使徒行传 24:24; 使徒行传 25:26"> 腓利斯原本对这道颇为了解，于是下令休庭，说：“等吕西亚千夫长抵达后，我再断你们的案子。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 28:16; 使徒行传 27:3; 箴言 16:7"> 他派百夫长看守保罗，给他一定的自由，也允许亲友来供应他的需要。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:21; 加拉太书 2:16; 马可福音 6:20"> 几天后，腓利斯和他的妻子犹太人土西拉一同来了，召见保罗，听他讲信基督耶稣的事。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:8; 彼得前书 3:15; 使徒行传 10:42"> 当保罗讲到公义、自制和将来的审判时，腓利斯十分恐惧，说：“你先下去吧，改天有机会，我再叫你来。”</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 6:9–10; 箴言 17:23; 以赛亚书 56:11"> 这期间腓利斯希望保罗贿赂他，所以经常召他来谈话。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 25:9; 使徒行传 25:14; 使徒行传 12:3"> 过了两年，波求·非斯都接任总督，腓利斯为了讨好犹太人，仍然把保罗留在监牢。</span>
</div>
</div>

## 保罗再访马其顿和希腊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 7:5; 使徒行传 19:21; 提摩太前书 1:3"> 这场风波平息后，保罗召集众门徒勉励一番后，便辞别他们去了马其顿。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 2:3; 帖撒罗尼迦前书 4:1; 歌罗西书 1:28"> 他走遍那一带，用许多话鼓励当地的门徒。之后，他又去希腊，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:19; 哥林多后书 11:26; 使徒行传 9:23–24"> 在那里逗留了三个月。保罗正要乘船去叙利亚时，听闻犹太人计划要害他，就决定经马其顿回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:29; 以弗所书 6:21; 提摩太后书 4:20"> 同他到亚细亚去的人有庇哩亚人毕罗斯的儿子所巴特、帖撒罗尼迦人亚里达古和西公都，还有特庇人该犹、提摩太、亚细亚人推基古和特罗非摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:8; 使徒行传 16:10–11; 提摩太后书 4:13"> 他们先到特罗亚等候我们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:3; 使徒行传 16:12; 出埃及记 23:15"> 除酵节过后，我们从腓立比启航，五天后在特罗亚和他们会合，大家同住了七天。</span>
</div>
</div>

## 犹推古死而复活

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 16:2; 使徒行传 2:42; 约翰福音 20:19"> 七日的第一日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="照犹太人的算法，太阳下山后为一日的开始，基督徒又以礼拜天为一周之始，所以七日的第一日很有可能是礼拜六晚上。">a</a></sup>，我们聚会掰饼，保罗因为次日要离开，就向他们讲道，直到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:13; 路加福音 22:12"> 我们聚会的楼上灯火通明。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 13:36; 马太福音 26:40–41; 约拿书 1:5–6"> 有个名叫犹推古的青年坐在窗台上听道。保罗讲了许久，犹推古不胜困倦睡着了，竟从三楼掉了下去。别人将他抱起来时，他已经死了。</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 5:39; 马太福音 9:23–24; 列王纪上 17:21–22"> 保罗下去伏在他身上，抱着他对众人说：“不要惊慌，他还活着！”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 20:7; 使徒行传 20:9"> 保罗说完就回到楼上，与大家一同掰饼、吃了，又谈了很久，直到天亮才离去。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:16; 帖撒罗尼迦前书 5:14; 哥林多后书 1:4"> 大家把活过来的犹推古送回家，都大得安慰。</span>
</div>
</div>

## 保罗告别以弗所的众长老

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 6:46; 马可福音 1:35; 马可福音 6:31–33"> 我们照保罗的吩咐先乘船到亚朔预备在那里接他，他打算由陆路步行过去。</span>
<span className="v" id="v14" data-v="14"> 他到了亚朔，我们接他上船，一同前往米推利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 4:20; 使徒行传 20:17"> 我们从米推利尼启航，第二天到了基阿附近，第三天到达撒摩，第四天在米利都停泊。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:8; 使徒行传 2:1; 使徒行传 19:21"> 保罗急于赶回耶路撒冷，希望在五旬节前赶到，所以决定越过以弗所，免得在亚细亚境内耽误太久。</span>
<span className="v" id="v17" data-v="17" data-xref="提多书 1:5; 使徒行传 11:30; 提摩太前书 5:17"> 保罗从米利都派人到以弗所请教会的长老前来与他相会。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 1:5–6; 使徒行传 18:19; 使徒行传 19:1"> 他们都来了，保罗说：“各位，自从我踏进亚细亚那天起，在你们当中为人如何，你们都很清楚。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:24; 哥林多后书 2:4; 罗马书 12:11"> 我含着眼泪谦卑地事奉主，又遭到犹太人的谋害，历尽艰辛。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:27; 提摩太后书 4:2; 使徒行传 5:42"> 你们也知道，凡是对你们有益的事，我没有避而不宣，我总是在公开场合和各人家中教导你们。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:38; 使徒行传 11:18; 约翰一书 5:11–13"> 我劝犹太人和希腊人都要悔改，归向上帝，信靠主耶稣基督。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 4:14; 哥林多后书 5:14; 彼得后书 1:14"> 现在，我在圣灵的催促下前往耶路撒冷，不知道在那里会发生什么事，</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 9:16; 帖撒罗尼迦前书 3:3; 使徒行传 21:4"> 只知道圣灵在各城指示我，前面必有监禁和苦难等着我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:6–8; 哥林多后书 4:1; 哥林多后书 12:10"> 不过，只要能跑完我当跑的路程，完成主耶稣交托给我的使命——为上帝充满恩典的福音做见证，就是牺牲性命，我也在所不惜。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 28:31; 使徒行传 20:38; 马太福音 4:23"> “我一向在你们中间传扬上帝的国，如今我知道，以后你们再也见不到我的面了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:6; 以西结书 3:18–21; 以西结书 33:2–9"> 所以今天我向你们声明，将来你们有谁灭亡，与我无关。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 20:20; 帖撒罗尼迦前书 2:4; 加拉太书 1:7–10"> 因为上帝的整个计划，我没有向你们避而不宣。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:2–3; 提摩太前书 4:16; 以赛亚书 40:11"> 你们要为自己，也要为教会的群羊警醒，因为圣灵已经任命你们做群羊的监督，牧养上帝的教会。教会是祂用自己的血赎回来的。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 7:15; 彼得后书 2:1; 约翰福音 10:12"> 我知道，在我离开以后，一定会有凶恶的豺狼闯进你们中间，残害羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 1:19–20; 提摩太后书 4:3–4; 箴言 23:33"> 就是你们中间也会有人起来歪曲真理，引诱门徒跟随他们。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:8; 使徒行传 20:19; 使徒行传 19:10"> 所以你们一定要警醒，牢记这三年来我怎样昼夜不住地流着泪劝诫你们。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 1:12; 以弗所书 1:14; 歌罗西书 3:24"> “现在，我把你们交托给上帝和祂充满恩典的道，这道能造就你们，使你们与一切得以圣洁的人同得产业。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 11:9; 哥林多前书 9:12; 哥林多前书 9:18"> 我从未贪图别人的金银和衣服，</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 18:3; 哥林多前书 4:12; 帖撒罗尼迦后书 3:8–9"> 你们都知道，我亲手做工养活自己和同工。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 13:16; 箴言 19:17; 哥林多后书 9:6–12"> 我凡事以身作则，教导你们勤奋工作，帮助软弱的人，并牢记主耶稣的话，‘施比受更有福。’”</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 21:5; 路加福音 22:41; 腓立比书 4:6"> 保罗说完这番话，就和大家一同跪下祷告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 1:4; 哥林多前书 16:20; 帖撒罗尼迦前书 5:26"> 众人都哭了，抱着保罗与他亲吻，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 15:3; 哥林多前书 16:11; 使徒行传 20:25"> 最使他们伤心的就是他说“你们再也见不到我的面了”。随后，众人送他上了船。</span>
</div>
</div>

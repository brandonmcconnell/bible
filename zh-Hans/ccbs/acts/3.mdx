## 彼得医治瘸腿的乞丐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 55:17; 使徒行传 10:3; 使徒行传 4:13"> 一天，在下午三点祷告的时间，彼得和约翰去圣殿。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 14:8; 约翰福音 9:8; 路加福音 16:20"> 有一个生来瘸腿的人天天被人抬到圣殿美门的外面，向进殿的人乞讨。</span>
<span className="v" id="v3" data-v="3"> 他看见彼得和约翰要进殿，就求他们施舍。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:9–10; 约翰福音 11:40; 路加福音 4:20"> 二人定睛看他，彼得说：“看着我们！”</span>
<span className="v" id="v5" data-v="5"> 那人就紧盯着他们，指望得些什么。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 3:16; 使徒行传 10:38; 使徒行传 4:10"> 彼得说：“金子、银子我都没有，但是我把我有的给你。我奉拿撒勒人耶稣基督的名，命令你起来行走！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 1:31; 马可福音 9:27; 使徒行传 9:41"> 彼得拉着他的右手扶他起来，那人的双脚和踝骨立刻变得强壮有力。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 14:10; 以赛亚书 35:6; 诗篇 107:20–22"> 他跳了起来，站稳后开始行走，跟着彼得和约翰进入圣殿，走着跳着赞美上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:21; 使徒行传 4:16; 路加福音 13:17"> 大家看见他一边走一边赞美上帝，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:2; 约翰福音 5:20; 约翰福音 9:3"> 认出他就是那个坐在圣殿美门外面的乞丐，都为发生在他身上的事而感到惊奇、诧异。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:12; 约翰福音 10:23; 路加福音 8:38"> 那乞丐在所罗门廊下正紧紧拉着彼得和约翰的时候，众人都跑过来，大为惊奇。</span>
</div>
</div>

## 彼得传扬基督

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 约翰福音 3:27–28; 但以理书 2:28–30"> 彼得看见这情形，就对大家说：“以色列人啊，何必惊奇呢？为什么一直盯着我们呢？你们以为我们是凭自己的能力和虔诚叫这人行走吗？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 22:32; 使徒行传 7:32; 马太福音 27:17–25"> 亚伯拉罕的上帝，以撒的上帝，雅各的上帝，就是我们祖先的上帝，已经使祂的仆人耶稣得了荣耀。你们把耶稣交给彼拉多，尽管彼拉多想释放祂，你们却在彼拉多面前弃绝祂！</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 1:24; 使徒行传 7:52; 彼得前书 3:18"> 你们弃绝了那圣洁公义者，竟然要求彼拉多给你们释放一个凶手。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 启示录 21:6; 使徒行传 2:32"> 你们杀了生命之主，上帝却使祂从死里复活了。我们都是这事的见证人。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:21–22; 使徒行传 4:10; 使徒行传 14:9"> 你们认识的这个乞丐因为相信耶稣的名，得到了医治。你们都看见了，他能痊愈是因为他信耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行传 13:27; 约翰福音 16:3"> “弟兄们，我知道你们的所作所为是出于无知，你们的官长也是一样。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:1–12; 使徒行传 26:22–23; 使徒行传 2:23"> 但是上帝早已借众先知预言基督要受害，这事果然应验了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:38; 以赛亚书 44:22; 以赛亚书 43:25"> 所以你们要悔改，归向上帝，祂将除去你们的罪恶，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:30–36; 启示录 19:11–16; 帖撒罗尼迦后书 2:2"> 赐给你们焕然一新的日子，也将差遣祂预先为你们选立的基督耶稣降临。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:21; 以赛亚书 1:26; 使徒行传 1:11"> 基督必须留在天上，直到万物更新的时候，这是上帝自古以来借圣先知的口说的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 18:15–19; 使徒行传 7:37; 加拉太书 4:4"> 摩西曾经说，‘主——你们的上帝要在你们中间兴起一位像我一样的先知。你们要留心听祂说的一切话，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 18:19; 约翰福音 12:48; 希伯来书 10:28–30"> 凡不听的，必从民中被彻底铲除。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记18:15、18、19。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 3:21; 路加福音 24:27; 撒母耳记上 3:20"> “从撒母耳到后来的所有先知都宣告过这些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 22:18; 加拉太书 3:8; 使徒行传 2:39"> 你们是先知的子孙，也继承了上帝和你们祖先所立的约。上帝曾对亚伯拉罕说，‘天下万族必因你的后裔而蒙福。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="创世记22:18；26:4。">b</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 1:21; 使徒行传 3:22; 犹大书 1:24"> 上帝兴起祂的仆人，首先差遣祂到你们中间赐福给你们，使你们每个人都脱离罪恶。”</span>
</div>
</div>

## 保罗在以弗所传道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:23–28; 哥林多前书 16:12; 哥林多前书 1:12"> 当亚波罗在哥林多时，保罗已取道内陆重回以弗所，在那里遇见几个门徒。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:39; 使徒行传 11:15–17; 加拉太书 3:5"> 保罗问他们：“你们信的时候有没有领受圣灵？” 他们说：“没有！我们甚至都没有听过有圣灵。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:25; 哥林多前书 12:13; 使徒行传 8:16"> 保罗说：“那么，你们受的是什么洗礼呢？” 他们说：“是约翰的洗礼。”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:29–34; 使徒行传 11:16; 使徒行传 1:5"> 保罗说：“约翰的洗礼是悔改的洗礼，他告诉百姓要信在他以后来的那一位，就是耶稣。”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:12; 使徒行传 8:16; 罗马书 6:3–4"> 他们听后，立刻奉主耶稣的名受了洗。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 6:6; 使徒行传 2:4; 马可福音 16:17"> 保罗把手按在他们身上时，圣灵便降在他们身上，他们就说方言，讲预言。</span>
<span className="v" id="v7" data-v="7"> 他们约有十二个人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 28:23; 使徒行传 1:3; 使徒行传 9:20–22"> 保罗一连三个月勇敢地在会堂里传道，与人辩论上帝国的事，劝导他们。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 19:23; 使徒行传 9:2; 使徒行传 18:6–8"> 可是有些人仍然硬着心不信，还当众毁谤主的道。保罗便带着门徒离开他们，天天在推喇奴的学堂讲论。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 20:31; 提摩太后书 1:15; 使徒行传 16:6"> 这样持续了两年，亚细亚所有的居民，无论是犹太人还是希腊人，都听见了主的道。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 16:17–20; 使徒行传 5:12; 罗马书 15:18–19"> 上帝又借着保罗的手行了一些非凡的神迹，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:15; 列王纪下 13:20–21; 马可福音 16:17"> 甚至只要将保罗身上的手帕或围裙放在病人身上，病人就痊愈了，邪灵也会离开所附的人。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 12:27; 马可福音 9:38; 路加福音 11:19"> 那时，有几个走江湖的犹太术士也想用耶稣的名赶鬼，他们向那些被邪灵附身的人说：“我奉保罗所传讲的耶稣之名，命令你们出来！”</span>
<span className="v" id="v14" data-v="14"> 做这事的有犹太祭司长士基瓦的七个儿子。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 16:17–18; 路加福音 4:33–35; 马可福音 1:34"> 邪灵回答说：“耶稣，我认识；保罗，我也知道。但你们是谁？”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 马可福音 5:3–4; 马可福音 5:15"> 被邪灵附身的人随即扑向他们，攻击他们，制服了他们，使他们赤着身子带着伤从屋里逃走了。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 1:12; 使徒行传 5:5; 腓立比书 2:9–11"> 住在以弗所的犹太人和希腊人知道了这件事，都惊惧不已。主耶稣的名因此大受尊崇。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:10; 诗篇 32:5; 马太福音 3:6"> 许多已经信耶稣的人都前来认罪，公开承认自己的恶行。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:8; 出埃及记 32:20; 创世记 35:4"> 又有许多行邪术的人把他们的书堆在一起，当众焚烧。根据当时的估价，这些书约值五万银币。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 12:24; 使徒行传 6:7; 以赛亚书 55:11"> 主的道就这样传开了，大大兴旺起来。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:22; 使徒行传 20:16; 使徒行传 23:11"> 这些事以后，保罗决定经过马其顿和亚该亚回到耶路撒冷。他说：“到了那里之后，我必须去罗马看看。”</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 16:23; 提摩太后书 4:20; 使徒行传 16:3"> 于是，他派提摩太和以拉都两位同工先去马其顿，自己暂时留在亚细亚。</span>
</div>
</div>

## 以弗所的骚乱

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 19:9; 使徒行传 24:22; 哥林多后书 1:8–10"> 就在这时，由于主的道，以弗所起了很大的骚乱。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 6:9–10; 使徒行传 16:16; 使徒行传 16:19"> 一个名叫底米丢的银匠以制造亚底米女神银龛为业，使从事这门生意的工匠获利丰厚。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:19; 何西阿书 12:7–8; 启示录 18:11–19"> 他召集了工匠和同行的人，说：“各位都知道我们靠这一行发财，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 17:29; 哥林多前书 8:4; 以赛亚书 44:10–20"> 可是你们都耳闻目睹那个保罗在以弗所和亚细亚全境说服、误导了许多人，说什么人手所造的不是神。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 2:11; 提摩太前书 6:5; 马太福音 23:13"> 这样下去，不但我们的行业会遭人贬抑，连亚底米女神庙也会被人轻看，甚至全亚细亚及普世尊崇的女神也会威严扫地！”</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 13:4; 启示录 17:13; 使徒行传 16:19–24"> 众人听后，怒气填胸，高声喊叫：“以弗所人的亚底米真伟大！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 歌罗西书 4:10; 使徒行传 27:2"> 全城陷入一片混乱。众人抓住保罗的两个同伴马其顿人该犹和亚里达古，拖着他们冲进戏院。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 21:39; 撒母耳记下 18:2–3; 使徒行传 17:22–31"> 保罗想进去，但门徒不许他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:10; 使徒行传 21:12; 使徒行传 16:6"> 他的好友——亚细亚的几位官员也派人劝他别冒险进入戏院。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 21:34; 使徒行传 19:40; 马太福音 11:7–9"> 这时，戏院里面有人这样喊，有人那样喊，混乱不堪。其实大部分人根本不知道自己为什么聚在那里。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 12:17; 提摩太后书 4:14; 提摩太前书 1:20"> 这时，人群中的犹太人把亚历山大推到前面，请他解释。亚历山大举手示意大家安静，听他发言。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:28; 马太福音 6:7; 启示录 13:4"> 但众人认出他是个犹太人，便又开始一起高呼：“以弗所人的亚底米真伟大！”这样喊了大约两个小时。</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:10–11; 提摩太前书 4:2; 以弗所书 2:12"> 最后，城里的书记官使民众安静下来，说：“各位以弗所市民，谁不知道以弗所城守护着亚底米神庙和从宙斯那里掉下来的神像呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行传 5:35–39; 箴言 25:8"> 既然这是无可否认的事实，你们就该安静，不可鲁莽行事。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多后书 6:3; 罗马书 2:22; 使徒行传 25:8"> 你们带来的这些人既没有偷庙里的东西，也没有亵渎我们的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:7; 哥林多前书 6:1; 使徒行传 18:14"> 底米丢和他的同行如果要控告谁，大可到法庭或总督那里提出诉讼。</span>
<span className="v" id="v39" data-v="39"> 你们若还有其他要求，也可以通过合法的会议解决。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 17:5–8; 马太福音 26:5; 使徒行传 20:1"> 今天的骚乱实在没有道理，难免会被查问，到时候我们很难交代。”</span>
<span className="v" id="v41" data-v="41" data-xref="传道书 9:17; 诗篇 65:7; 哥林多后书 1:8–10"> 说完，便叫众人散去。</span>
</div>

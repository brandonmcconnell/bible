## 保罗在非斯都面前申辩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 23:34; 使徒行传 25:5; 使徒行传 8:40"> 非斯都上任三天后，便从凯撒利亚启程上耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:15; 箴言 4:16; 使徒行传 24:1"> 祭司长和犹太人的首领向他控告保罗，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 9:24; 使徒行传 23:12–15; 撒母耳记上 23:19–21"> 恳求他将保罗押回耶路撒冷，他们想在路上埋伏杀害保罗。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:23"> 非斯都却说：“保罗现在关押在凯撒利亚，我很快会回到那里。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 25:25; 约翰福音 18:29–30; 使徒行传 25:18–19"> 让你们的首领跟我一起去吧，如果那人有什么过犯，可以在那里告他。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 25:17; 使徒行传 25:10; 马太福音 27:19"> 非斯都在耶路撒冷只逗留了十天八天，便返回了凯撒利亚。第二天，他开庭审讯，命人将保罗带上来。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 24:13; 路加福音 23:10; 使徒行传 25:24"> 保罗被带来后，那些从耶路撒冷下来的犹太人站在他周围，控告他犯了许多重罪，但是都没有证据。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 24:12; 使徒行传 28:17; 哥林多后书 1:12"> 保罗为自己辩护说：“我从来没有违背犹太律法、亵渎圣殿或反叛凯撒！”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 24:27; 使徒行传 12:3; 使徒行传 25:20"> 非斯都为了讨好犹太人，就对保罗说：“你是否愿意回耶路撒冷接受我的审讯？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:18; 哥林多后书 4:2; 使徒行传 28:18"> 保罗说：“我此刻正站在凯撒的法庭上，这就是我应该受审的地方。你很清楚，我并没有做过什么对不起犹太人的事。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:19; 使徒行传 26:32; 使徒行传 25:25"> 我如果做错了，犯了该死的罪，决不逃避！但他们对我的控告毫无根据，谁也不能把我交给他们。我要向凯撒上诉！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:21; 腓立比书 1:12–14; 腓立比书 1:20"> 非斯都和议会商讨后，说：“你说要上诉凯撒，就去见凯撒吧！”</span>
</div>
</div>

## 非斯都请教亚基帕王

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:40; 使徒行传 26:1; 使徒行传 26:27–28"> 过了几天，亚基帕王和百妮姬一起到凯撒利亚问候非斯都。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 24:27"> 他们在那里住了多日，非斯都对王提起保罗的案子，说：“我这里有一个囚犯，是腓利斯留下来的。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1–3; 以斯帖记 3:9; 路加福音 18:3–5"> 上次我去耶路撒冷的时候，犹太人的祭司长和长老控告他，要求我定他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:51; 申命记 19:17–18; 使徒行传 23:30"> 我告诉他们，按照罗马人的规矩，被告还没有跟原告对质和自辩之前，不能定他的罪。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:6; 使徒行传 25:10"> 后来他们跟我一起来到这里，我没有耽误，第二天就开庭，吩咐把那人带出来审讯。</span>
<span className="v" id="v18" data-v="18"> 他们都站起来当面控告他，但所告的并非我料想的罪行，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:29; 使徒行传 18:15; 哥林多前书 15:3–4"> 不过是关于他们的宗教和一个叫耶稣的人的一些争论。耶稣已经死了，保罗却说他仍然活着。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 25:9"> 我不知如何审理这些事情，就问被告是否愿意上耶路撒冷受审。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:16; 路加福音 2:1; 使徒行传 25:10–11"> 但保罗请求留下来，听皇帝定夺，所以我下令仍然扣押他，等着送交凯撒。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:15; 马太福音 10:18; 以赛亚书 52:15"> 亚基帕对非斯都说：“我想亲自听听他的申诉。”<br />非斯都说：“你明天就会听到。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 26:30; 使徒行传 25:13; 约翰一书 2:16"> 第二天，亚基帕和百妮姬在众千夫长和城中达官贵人的陪同下，声势浩大地进了法庭。非斯都下令把保罗带上来后，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 22:22; 使徒行传 25:7; 使徒行传 25:2–3"> 说：“亚基帕王和在座的各位，你们看，就是这个人，所有的犹太人，不管是在这里还是耶路撒冷，都高声呼吁我处死他。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:29; 使徒行传 25:11–12; 路加福音 23:4"> 但我发现他并没有犯什么该死的罪。既然他要向皇帝上诉，我决定把他押去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3"> 只是关于这个人，我没有确切的事由可以奏明皇帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希腊文是“主上”，用于对罗马皇帝的尊称。">a</a></sup>。所以，我把他带到各位面前，特别是亚基帕王面前，以便在审讯之后，我可以有所陈奏。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 7:51; 箴言 18:13"> 因为在我看来，解送犯人却不奏明罪状不合情理。”</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:16; 提摩太后书 1:3; 哥林多后书 1:12"> 保罗注视着公会的人，说：“弟兄们，我在上帝面前行事为人一向问心无愧。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 18:22; 使徒行传 24:1; 弥迦书 5:1"> 大祭司亚拿尼亚一听，就命那些站在旁边的人打保罗的嘴。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 25:1–2; 约翰福音 7:51; 马太福音 23:27–28"> 保罗对亚拿尼亚说：“你这伪君子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“伪君子”希腊文是“粉饰的墙”。">a</a></sup>，上帝要击打你！你坐在那里不是应当照律法审问我吗？你怎么违背律法叫人打我？”</span>
<span className="v" id="v4" data-v="4"> 站在旁边的人说：“你竟敢辱骂上帝的大祭司？”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:28; 传道书 10:20; 犹大书 1:8–9"> 保罗说：“弟兄们，我不知道他是大祭司。因为圣经记载，‘不可咒诅百姓的官长。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及记22:28。">b</a></sup>”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:15; 使徒行传 24:21; 使徒行传 26:5–8"> 保罗发现他们一些是法利赛人，一些是撒都该人，就在公会中高声说：“弟兄们，我是法利赛人，也是法利赛人的子孙。我因为盼望死人复活，才在这里受审！”</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 55:9; 约翰福音 7:40–43; 马太福音 10:34"> 这句话引起法利赛人和撒都该人之间的争论，公会分成了两派。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 马太福音 22:23; 马可福音 12:18"> 因为撒都该人认为没有复活，也没有天使和灵，而法利赛人认为这些都有。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 22:7; 使徒行传 22:17–18; 约翰福音 12:29"> 众人大声喧嚷，有几个法利赛派的律法教师站起来争辩说：“我们找不出这人有什么错处，也许真的有灵或天使跟他说过话呢！”</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:19; 雅各书 3:14–2; 使徒行传 22:24"> 争论越来越激烈，千夫长怕保罗会被他们扯碎了，就派士兵把他从人群中硬抢走，带回军营。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 18:9; 使徒行传 19:21; 提摩太后书 4:17"> 当晚，主站在保罗身旁对他说：“要勇敢！你怎样在耶路撒冷为我做见证，也必照样在罗马为我做见证。”</span>
</div>
</div>

## 阴谋杀害保罗

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 23:30; 以赛亚书 8:9–10; 使徒行传 23:21"> 天亮后，犹太人设下阴谋，并起誓说：“不杀保罗，誓不吃喝！”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 16:2; 撒母耳记下 15:31; 撒母耳记下 15:12"> 有四十多人参与了这个阴谋。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 23:12; 耶利米书 8:12; 以赛亚书 3:9"> 他们去见祭司长和长老，说：“我们已经发了誓，不杀保罗就不吃饭。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7; 诗篇 37:32–33; 箴言 1:16"> 请你们和公会出面通知千夫长，请他把保罗押到你们这里来，就说要进一步审讯他。我们准备在他到达之前杀掉他！”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:10; 哥林多前书 3:19; 使徒行传 23:32"> 保罗的外甥听到这一阴谋，就去军营通知保罗。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 马太福音 8:8–9; 马太福音 10:16"> 保罗请来一位百夫长，说：“请带这青年去见千夫长，他有要事禀告！”</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 3:1; 以弗所书 4:1; 使徒行传 28:17"> 百夫长领他去见千夫长，说：“那囚犯保罗叫我带这青年来，说有要事禀告。”</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 31:32; 以斯帖记 9:12; 以斯帖记 7:2"> 千夫长就拉着那青年的手走到一旁，私下问他：“你有什么事要告诉我？”</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 23:14–15; 使徒行传 23:1; 诗篇 12:2"> 他说：“那些犹太人约好了，要请求你明天带保罗到公会，假装要详细审问他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:12–14; 使徒行传 14:5–6; 哥林多后书 11:26"> 你不要答应他们，因为他们有四十多个人正埋伏在半路，并且还起誓说，‘不杀保罗，誓不吃喝。’他们现在已经准备就绪，就等你答应了。”</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 1:44; 约书亚记 2:14"> 千夫长听后，就叫他回去，并叮嘱道：“你向我禀告的事，不要告诉别人。”</span>
</div>
</div>

## 保罗被押往凯撒利亚

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:25; 使徒行传 23:33; 路加福音 12:38"> 于是，千夫长召来两名百夫长，吩咐道：“预备二百名步兵、七十名骑兵、二百名长枪手，今晚九点出发去凯撒利亚。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 25:14; 使徒行传 23:26; 使徒行传 24:10"> 要给保罗预备坐骑，护送他安全抵达腓利斯总督那里。”</span>
<span className="v" id="v25" data-v="25"> 千夫长写了公文给腓利斯总督，内容如下：</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:23; 使徒行传 26:25; 路加福音 1:3"> “克劳狄·吕西亚敬问腓利斯总督大人安。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 22:25–29; 使徒行传 21:31–33; 使徒行传 24:6"> 这人被犹太人抓住，险些被他们杀害。我得知他是罗马公民，便带兵去救了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 22:30"> 为了弄清楚他们控告他的缘由，我押他到犹太人的公会受审，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 26:31; 使徒行传 25:25; 使徒行传 18:15"> 发现他是因为他们的律法问题而被控告，他并没有犯该被监禁或处死的罪。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:35; 使徒行传 25:16; 使徒行传 25:5–6"> 我得知有人准备暗杀他，便立即护送他到你那里，并吩咐他的控告者去你那里告他。”</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 2:3–4; 路加福音 7:8; 使徒行传 23:23–24"> 军兵奉命行事，连夜护送保罗到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:23; 使徒行传 23:10"> 第二天，由骑兵继续护送，其余军兵返回军营。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 23:26; 使徒行传 23:23–24; 使徒行传 28:16"> 他们到了凯撒利亚，将公文呈交总督，把保罗交给他。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 21:39; 使徒行传 25:1; 但以理书 2:49"> 总督看过公文，便问保罗是哪省的人，得知保罗是基利迦人，就说：</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 23:30; 使徒行传 25:16; 马太福音 27:27"> “等告你的人来了，我会审理你的案子。”于是下令把保罗关在希律的王府里。</span>
</div>

## 希律王的暴行

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:9; 约翰福音 15:20; 马太福音 10:17–18"> 那时，希律王下手残害教会的一些人，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:37; 马太福音 20:23; 马太福音 4:21–22"> 下令杀了约翰的哥哥雅各。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:15; 约翰福音 12:43; 使徒行传 24:27"> 他见这样做能取悦犹太人，便又在除酵节期间拘捕了彼得，</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 19:21; 路加福音 22:33; 路加福音 21:12"> 把他关在监牢，由四班卫兵，每班四人轮流看守，想等逾越节<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="除酵节为期七天，逾越节是其中的第一天，参见出埃及记12章。">a</a></sup>过后当众惩办他。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 帖撒罗尼迦前书 5:17; 雅各书 5:16"> 彼得被囚期间，教会都迫切地为他向上帝祷告。</span>
</div>
</div>

## 彼得神奇出狱

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 21:33; 希伯来书 13:6; 腓立比书 4:6–7"> 在被希律提审前夜，彼得被两条铁链锁着睡在两个卫兵中间，门外警卫森严。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:19; 使徒行传 16:26; 诗篇 146:7"> 忽然，有一位主的天使站在彼得身旁，牢房内一片光明，天使拍他的肋旁，把他叫醒，说：“赶快起来！”铁链就从他手上脱落下来。</span>
<span className="v" id="v8" data-v="8"> 天使对他说：“束上腰带，穿上鞋。”彼得一一照办。天使又说：“披上外衣，跟我来！”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:1; 希伯来书 11:8; 创世记 45:26"> 他跟着天使走出牢房，不知道这一切都是真的，还以为自己看到了异象。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:19; 使徒行传 16:26; 以赛亚书 45:1–2"> 他们一路穿过第一道和第二道守卫，来到通往城里的铁门，那门竟自动打开了。他们就出来，走过一条街之后，天使便离开了彼得。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 6:22; 但以理书 3:28; 彼得后书 2:9"> 彼得这才如梦初醒，说：“现在我确信无疑，主派天使把我从希律手中救了出来，让犹太人期望落空。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 使徒行传 12:5; 马太福音 18:19–20"> 他明白之后，便去约翰·马可的母亲玛丽亚家，很多人正聚集在那里祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:16; 路加福音 13:25; 约翰福音 18:16–17"> 彼得在外面敲门，有一个叫罗大的婢女出来应门。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:41; 马太福音 28:8"> 她听出是彼得的声音，喜出望外，竟然没有开门就跑进去报信说：“彼得在门外！”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:10; 路加福音 24:11; 马可福音 16:14"> 他们说：“你一定疯了。”她坚持说：“是真的！”他们就说：“是他的天使吧！”</span>
<span className="v" id="v16" data-v="16"> 彼得不住地敲门。他们开门看见他，都大吃一惊！</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 21:40; 使徒行传 13:16; 使徒行传 19:33"> 彼得摆手示意他们安静，然后把主怎样领他出狱的经过告诉大家，又说：“把这事告诉雅各和其他弟兄姊妹。”然后，他便离开那里，往其他地方去了。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:22–25; 使徒行传 16:27; 使徒行传 19:23"> 天亮后，卫兵发现彼得不见了，顿时一片骚动。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:27; 诗篇 37:32–33; 约翰福音 12:10–11"> 希律派人四处搜捕，一无所获，于是亲自审问卫兵，下令处决他们。后来希律离开犹太，下到凯撒利亚，并住在那里。</span>
</div>
</div>

## 希律的下场

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 3:7; 马太福音 11:21–22; 以西结书 27:17"> 希律对泰尔和西顿的人非常恼火。于是，他们联合起来去见他，先取得宫廷总管伯拉斯都的支持，然后向他求和，因为他们两地需要从他的辖区获得粮食。</span>
<span className="v" id="v21" data-v="21"> 到了约定的日子，希律穿上王袍，坐在宝座上向众人致词。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 14:10–13; 启示录 13:4; 犹大书 1:16"> 众人齐声高呼：“这是神明的声音，不是凡人的声音！”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 115:1; 使徒行传 10:25–26; 帖撒罗尼迦后书 2:4"> 希律没有把荣耀归给上帝，主的天使立刻击打他，他被虫子啃噬而亡。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 6:7; 使徒行传 19:20; 帖撒罗尼迦后书 3:1"> 上帝的道日见兴旺，越传越广。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 12:12; 彼得前书 5:13; 使徒行传 15:37"> 巴拿巴和扫罗把款项送到以后，就带着约翰·马可从耶路撒冷回去。</span>
</div>

## 唯一的救主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行传 6:12; 使徒行传 23:6–9"> 彼得和约翰向百姓讲道的时候，祭司、圣殿护卫长和撒都该人赶来了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:18; 帖撒罗尼迦前书 4:13–14; 使徒行传 24:14–15"> 他们非常恼怒，因为彼得和约翰在教导百姓，并宣讲借着耶稣死人可以复活。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 5:18; 马太福音 10:16–17; 使徒行传 16:19–24"> 于是他们下手捉拿二人，因天色已晚，就把他们扣押了一夜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:41; 哥林多后书 2:14–17; 提摩太后书 2:9–10"> 但有许多听道的人信了，男人的数目约有五千人。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 4:8; 马太福音 27:1–2; 路加福音 20:1"> 第二天，官长、长老和律法教师都聚集在耶路撒冷，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 约翰福音 18:24; 马太福音 26:3"> 大祭司亚那，以及该亚法、约翰、亚历山大和大祭司的许多亲族都在场。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:23; 马可福音 11:28; 使徒行传 5:40"> 他们让使徒站在当中，质问道：“你们凭什么权柄、奉谁的名这样做？”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 马太福音 10:19–20; 使徒行传 2:4"> 那时彼得被圣灵充满，对他们说：“各位百姓的官长和长老啊，</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:15–17; 使徒行传 3:7; 约翰福音 10:32"> 如果因为那残疾的乞丐得到医治这件善事，你们今天来查问我们他是如何痊愈的，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29–32; 使徒行传 3:6; 使徒行传 2:36"> 那么，你们和所有以色列人都应当知道，他能健康地站在你们面前，全是靠拿撒勒人耶稣基督的名！你们把祂钉在十字架上，但上帝使祂从死里复活了。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 马可福音 12:10–12"> <span className="pl pl-1">“‘祂是你们工匠丢弃的石头，</span><br /><span className="pl pl-1">已成了房角石。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇118:22。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 14:6; 哥林多前书 3:11; 约翰福音 3:36"> 除祂以外，别无救主，因为普天之下没有赐给世人别的名让我们可以靠着得救！”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 约翰福音 7:15; 马太福音 11:25"> 在场的人看到彼得和约翰的胆量，又知道他们原是没有学问的平民百姓，都很惊奇。他们认出这些人跟随过耶稣，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 19:36; 使徒行传 3:8–12; 使徒行传 4:21"> 又见那个被治好的人站在他们旁边，便无话可说，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 26:30–32; 使徒行传 5:34–42; 马太福音 5:22"> 只好命令他们离开公会，然后彼此商量说：</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行传 6:10; 约翰福音 12:18"> “我们该怎样处置这两个人呢？整个耶路撒冷的居民都知道他们行了一个神迹，我们无法否认。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:28; 罗马书 15:18–22; 使徒行传 5:24"> 然而，为了避免这件事在民间传得更广，我们必须警告他们以后不许再奉耶稣的名向任何人传道。”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:40; 路加福音 24:46–48; 使徒行传 5:20"> 于是，他们又把使徒召来，严禁他们再奉耶稣的名讲论或教导。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:29; 出埃及记 1:17; 哥林多前书 10:15"> 但彼得和约翰答道：“要我们听从你们而不听从上帝，这在上帝看来合理吗？你们自己决定吧。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 22:15; 耶利米书 20:9; 哥林多前书 9:16–17"> 我们耳闻目睹的，不能不说！”</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:26; 马太福音 21:46; 路加福音 22:2"> 官长实在不知道如何惩治使徒，只好再次恐吓之后把他们放了，因为百姓都为这个神迹赞美上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:5; 使徒行传 9:33; 路加福音 13:11"> 在这次神迹中蒙上帝医治的那个人已经四十多岁了。</span>
</div>
</div>

## 同心祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:14–17; 使徒行传 12:11–12; 诗篇 119:63"> 彼得和约翰被释放之后，就回到自己人那里，把祭司长和长老的话都告诉大家。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:11; 耶利米书 32:17; 尼希米记 9:6"> 大家听后，一同高声向上帝祷告说：“主啊，你创造了天地、海洋和其中的万物。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–6; 使徒行传 1:16; 使徒行传 2:30"> 你借着圣灵感动你的仆人——我们的祖先大卫说，<br /><span className="pl pl-1">“‘列国为何咆哮？</span><br /><span className="pl pl-1">万民为何枉费心机？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:2; 启示录 17:12–14; 但以理书 9:24"> <span className="pl pl-1">世上的君王一同行动，官长聚集起来，</span><br /><span className="pl pl-1">要抵挡主和祂所膏立的王。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇2:1、2。">b</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 27:2; 使徒行传 4:30; 路加福音 9:22"> “果然如此，希律和本丢·彼拉多、外族人和以色列人都聚集在这城里，要对抗你膏立的圣仆耶稣，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:23; 以赛亚书 46:10; 创世记 50:20"> 然而他们只不过是成就你凭自己的大能和旨意所预定的事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:13; 使徒行传 14:3; 腓立比书 1:14"> 主啊，你看他们这样恐吓我们，求你帮助你的奴仆们坦然无惧地传你的道。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 4:27; 使徒行传 3:6; 使徒行传 5:12"> 求你伸出手医治疾病，借着你圣仆耶稣的名行神迹奇事。”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 21:22; 使徒行传 2:2; 使徒行传 2:4"> 祷告完后，聚会的地方震动起来，他们都被圣灵充满，放胆传扬上帝的道。</span>
</div>
</div>

## 共用一切

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:10; 以弗所书 4:2–6; 彼得前书 3:8"> 当时所有信徒都同心合意，共用所有的东西，没有人说他的财物只属于自己。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:16; 使徒行传 1:22; 使徒行传 1:8"> 使徒充满能力，继续为主耶稣复活的事做见证，上帝也赐下极大的恩典给众人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 2:45; 路加福音 12:33; 路加福音 16:9"> 信徒都一无所缺，因为大家卖掉房屋田产，把所得的钱拿来，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 5:2; 使徒行传 2:45; 哥林多后书 8:20–21"> 放在使徒脚前，按照各人的需要分给大家。</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太书 2:9; 加拉太书 2:13; 加拉太书 2:1"> 有个生在塞浦路斯的利未人名叫约瑟，使徒叫他巴拿巴，意思是劝慰者。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 5:1–2; 使徒行传 4:34–35; 马太福音 19:29"> 他卖掉自己的一块田，把卖得的钱交给了使徒。</span>
</div>

## 在马耳他岛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:26; 使徒行传 27:44; 使徒行传 27:39"> 我们安全上岸后，才知道那个岛的名字叫马耳他。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:14; 希伯来书 13:2; 歌罗西书 3:11"> 岛上的居民对我们非常友善。因为下雨，天气又冷，他们就生火接待我们。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 23:33; 马太福音 12:34; 使徒行传 28:4"> 保罗捡了一捆柴放进火堆里，不料有一条毒蛇经不住热钻了出来，咬住他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 约翰福音 7:24"> 那里的居民看见毒蛇吊在保罗手上，就交头接耳地说：“这人一定是个凶手，虽然侥幸没有淹死，天理却不容他活下去。”</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 马可福音 16:18; 诗篇 91:13"> 可是保罗把蛇甩进火里，并没有受伤。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:22; 使徒行传 14:11–13; 马太福音 21:9"> 他们以为保罗的手一定会肿起来或者他会突然倒毙，但是等了很久，见他还是安然无恙，就改变了想法，说他是个神明。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40–41; 路加福音 19:6–9; 使徒行传 28:2"> 那个岛的首领名叫部百流，他的田产就在附近。他接待我们，热情款待了我们三天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:40; 马可福音 6:5; 雅各书 5:14–16"> 当时，部百流的父亲患痢疾，正发烧躺在床上。保罗去为他祷告，把手按在他身上治好了他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 5:12; 马可福音 6:54–56; 使徒行传 5:15"> 这事以后，岛上其他病人也来了，并得了医治。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:6; 腓立比书 4:11–12; 马太福音 6:31–34"> 他们处处尊敬我们，在我们启航的时候，又赠送我们途中所需用的物品。</span>
</div>
</div>

## 保罗抵达罗马

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 27:6; 哥林多前书 8:4; 以赛亚书 45:20"> 三个月后，我们搭乘一艘停在该岛过冬的船离开。这船叫“双神号<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“双神号”希腊语是“卡斯特与帕勒克”，二者为宙斯的双生子，是航运之神。">a</a></sup>”，来自亚历山大。</span>
<span className="v" id="v12" data-v="12"> 我们先到叙拉古港，在那里停泊三天，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 27:13"> 然后继续前行，到达利基翁。第二天，起了南风，第三天我们抵达部丢利，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:4; 使徒行传 20:6; 使徒行传 19:1"> 在那里遇见几位弟兄姊妹，应邀和他们同住了七天，然后前往罗马。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:3; 罗马书 15:24; 出埃及记 4:14"> 那里的弟兄姊妹听说我们来了，便到亚比乌和三馆迎接我们。保罗见到他们后，就感谢上帝，心中受到鼓励。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 27:3; 使徒行传 24:23; 使徒行传 28:30–31"> 我们进了罗马城后，保罗获准在卫兵的看守下自己一个人住。</span>
</div>
</div>

## 继续传道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:8; 使徒行传 6:14; 使徒行传 25:10"> 三天后，保罗请来当地犹太人的首领，对他们说：“弟兄们，我虽然没有做过任何对不起同胞或违背祖先规矩的事，却在耶路撒冷遭囚禁，又被交到罗马人的手里。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:31–32; 使徒行传 23:29; 使徒行传 22:24–25"> 罗马官员审讯了我，发现我没有什么该死的罪，想释放我，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:32; 使徒行传 25:21; 使徒行传 25:10–12"> 犹太人却反对，我不得已只好上诉凯撒。我并非有什么事要控告自己的同胞。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 提摩太后书 2:9; 使徒行传 26:6–7"> 为此，我才请你们来当面谈，我受捆绑是为了以色列人所盼望的那位。”</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 54:17; 以赛亚书 41:11; 以赛亚书 50:8"> 他们说：“犹太境内的同胞没有给我们写信提你的事，也没有弟兄到这里说你的坏话。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:12; 使徒行传 24:14; 彼得前书 3:16"> 不过，我们倒很想听听你的观点，因为我们知道你们这一派的人到处受人抨击。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 17:2–3; 使徒行传 19:8; 使徒行传 18:28"> 于是，他们和保罗约定了会面的日期。那一天，很多人来到保罗住的地方。从早到晚，保罗向他们讲解和见证上帝的国，引用摩西律法和先知书劝他们相信有关耶稣的事。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 14:4; 使徒行传 17:4–5; 使徒行传 19:8–9"> 有些人相信了他的话，有些人不相信，</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:7; 彼得后书 1:21; 马可福音 7:6"> 他们彼此意见不一。在他们散去之前，保罗说了一句话：“圣灵借以赛亚先知对你们祖先所说的话真是一点不错，</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 6:9–10; 以西结书 12:2; 以赛亚书 42:19–20"> 祂说，<br /><span className="pl pl-1">“‘你去告诉百姓，</span><br /><span className="pl pl-1">你们听了又听，却不明白；</span><br /><span className="pl pl-1">看了又看，却不领悟。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 6:10"> <span className="pl pl-1">因为这百姓心灵麻木，</span><br /><span className="pl pl-1">耳朵发背，眼睛昏花，</span><br /><span className="pl pl-1">以致眼睛看不见，</span><br /><span className="pl pl-1">耳朵听不见，心里不明白，无法回心转意，</span><br /><span className="pl pl-1">得不到我的医治。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书6:9、10。">b</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行传 26:17–18; 罗马书 3:29–30"> 所以你们当知道，上帝的救恩已经传给了外族人，他们也必听。”</span>
<span className="v" id="v29" data-v="29"> 听完保罗的话后，那些犹太人就回去了，他们中间起了激烈的争论。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷无29节。">c</a></sup></span>
<span className="v" id="v30" data-v="30"> 后来，保罗自己租了一间房子，在那里住了整整两年，接待所有到访的人。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 4:29; 以弗所书 6:19–20; 马太福音 4:23"> 他勇敢地传讲上帝的国，教导有关主耶稣基督的事，没有受到任何拦阻。</span>
</div>
</div>

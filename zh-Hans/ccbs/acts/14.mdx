## 在以哥念传道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:4; 使徒行传 13:51; 使徒行传 13:46"> 保罗和巴拿巴一同进入以哥念的犹太会堂讲道，许多犹太人和希腊人信了耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 13:50; 使徒行传 21:27–30; 使徒行传 14:19"> 但那些顽梗不信的犹太人却怂恿外族人敌视信徒。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 2:4; 以弗所书 6:18–20; 使徒行传 20:32"> 二人在那里逗留了好些日子，靠着主勇敢地传道。主赐给他们行神迹奇事的能力，为祂的恩典之道做见证。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:24; 使徒行传 14:14; 路加福音 11:21–23"> 城里的居民分成了两派，有些附和犹太人，有些支持使徒。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:19; 提摩太后书 3:11; 使徒行传 17:5"> 当时，有些外族人、犹太人及其官长企图恶待使徒，用石头打他们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 14:20–21; 马太福音 10:23; 提摩太后书 3:11"> 保罗和巴拿巴得知后，就逃往吕高尼的路司得和特庇二城并周围的地区，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 14:21; 使徒行传 16:10; 帖撒罗尼迦前书 2:2"> 在那里继续传扬福音。</span>
</div>
</div>

## 在路司得和特庇传福音

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:2; 约翰福音 9:1–2; 约翰福音 5:3–5"> 路司得城里坐着一个生来瘸腿的，他双脚无力，不能走路。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:4; 马太福音 15:28; 马太福音 9:28–29"> 他在听保罗讲道。保罗定睛看他，见这个人有信心，可以得医治，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 35:6; 约翰福音 5:8–9; 约翰福音 14:12"> 就高声对他说：“起来，两脚站直！”那人就跳了起来，开始行走。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:6; 使徒行传 8:10; 使徒行传 12:22"> 周围的人看见保罗所行的，就用吕高尼话大声说：“神明化成人形下凡了！”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:35"> 于是，他们称巴拿巴为宙斯，又因为保罗是主要的发言人，就称他为希耳米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希腊神话中天神宙斯是最大的神，希耳米则是为众神传递信息的使者——“传谕之神”。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 2:46; 使徒行传 10:25"> 城外宙斯庙的祭司也牵着牛、拿着花环来到城门口，要和众人一同向使徒献祭。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:65; 哥林多前书 9:5–6; 列王纪下 5:7"> 巴拿巴和保罗二位使徒见此情形，就撕裂衣服，冲进人群中，高喊：</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:26; 哥林多前书 8:4; 雅各书 5:17"> “各位，你们为什么这样做？我们和你们一样只是凡人！我们来这里是要向你们传福音，叫你们离弃这些虚妄的事，转向那创造天地、海洋和其中万物的永活上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:30; 诗篇 81:12; 罗马书 1:28"> 在以往的世代，祂虽然容许万国各行其道，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:19–20; 约珥书 2:23; 约伯记 5:10"> 却从未停止显明自己的存在。祂常施恩惠，降下甘霖，赏赐丰年，又叫你们衣食饱足，满心喜乐。”</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 44:16–17; 创世记 19:9; 创世记 11:6"> 保罗和巴拿巴说了这些话，才勉强制止住人群向他们献祭。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 11:25; 提摩太后书 3:11; 使徒行传 13:50–51"> 有些犹太人从安提阿和以哥念来煽动民众，他们用石头打保罗，以为他死了，就把他拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:9–10; 哥林多后书 6:9; 使徒行传 14:6"> 当门徒围过来看他的时候，他站了起来，走回城里。第二天，保罗和巴拿巴前往特庇。</span>
</div>
</div>

## 返回安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 14:19; 使徒行传 14:1; 使徒行传 13:51"> 他们向那里的人传福音，有很多人做了门徒。然后，他们又回到路司得、以哥念和安提阿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 5:10; 提摩太后书 3:12; 约翰福音 16:33"> 坚固各地门徒的心志，鼓励他们要持守信仰，并且说：“我们在进入上帝国的道路上必经历许多苦难。”</span>
<span className="v" id="v23" data-v="23" data-xref="提多书 1:5; 使徒行传 11:30; 雅各书 5:14"> 二人又为每个教会选立长老，禁食祷告，把他们交托给所信靠的主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 13:13–14; 使徒行传 15:38"> 后来，二人又经过彼西底，来到旁非利亚，</span>
<span className="v" id="v25" data-v="25"> 在别加讲完道，然后下到亚大利，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:40; 使徒行传 11:19; 哥林多后书 1:12"> 从那里乘船回安提阿。当初就是在安提阿，他们被交托在上帝的恩典中去传道，如今工作已经完成了。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 16:9; 使徒行传 15:12; 歌罗西书 4:3"> 他们到达之后，就召集教会的人，报告上帝借着他们所做的一切事，以及上帝如何给外族人开了信仰之门。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 使徒行传 15:35"> 之后，二人和门徒同住了很久。</span>
</div>
</div>

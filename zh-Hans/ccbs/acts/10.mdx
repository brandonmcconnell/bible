## 哥尼流邀请彼得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:1; 马太福音 8:5–13; 马太福音 27:27"> 在凯撒利亚有一位隶属意大利营的百夫长名叫哥尼流。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 7:7–8; 使徒行传 10:4; 使徒行传 10:22"> 他和全家都是虔诚敬畏上帝的人，他慷慨周济穷人，常常祷告。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 9:20–21; 使徒行传 3:1; 使徒行传 5:19"> 一天，大约下午三点，他在异象中清楚地看见一位上帝的天使进来呼唤他：“哥尼流！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 希伯来书 6:10; 使徒行传 10:31"> 哥尼流惊恐地注视着他，问：“主啊，什么事？”<br />天使回答说：“你的祷告和施舍已经在上帝面前蒙悦纳。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:9; 使徒行传 9:38; 使徒行传 15:7"> 如今你要派人去约帕，请一个叫西门·彼得的人来。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:43; 使徒行传 11:13–14; 罗马书 10:14–17"> 他住在海边一个叫西门的皮革匠家里。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓利门书 1:16; 撒母耳记上 14:6–7; 马太福音 8:9–10"> 向他说话的天使离开后，哥尼流叫来两个家仆和自己的一个敬虔侍卫，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:36; 诗篇 119:59–60; 使徒行传 10:33"> 把刚才的事告诉他们，然后差他们去约帕。</span>
</div>
</div>

## 彼得见异象

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="西番雅书 1:5; 诗篇 55:17; 撒母耳记上 9:25"> 第二天中午，他们快要到达约帕时，彼得上屋顶去祷告。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 22:17; 启示录 4:2–3; 哥林多后书 12:2–4"> 他觉得肚子饿了，想吃东西。那家人正在预备午饭的时候，彼得进入异象，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:6; 约翰福音 1:51; 罗马书 16:25–26"> 看见天开了，有个东西好像一大块布，四角吊着降到地上，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:8–9; 约翰福音 7:37; 哥林多前书 6:9–11"> 里面有各种天上的飞禽、地上的爬虫和四脚走兽。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:31–34; 耶利米书 35:2–5; 使徒行传 10:10"> 然后有声音对他说：“彼得，起来，宰了吃！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 20:25; 以西结书 4:14; 但以理书 1:8"> 彼得却说：“主啊！这可不行！我从未吃过任何污秽不洁之物。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 10:25; 马太福音 15:11; 提多书 1:15"> 那声音又一次对他说：“上帝已经洁净的，你不可再称之为不洁净。”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 41:32; 约翰福音 21:17; 哥林多后书 13:1"> 这样一连三次之后，那块布就被收回天上去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 13:12; 使徒行传 10:7–19; 使徒行传 5:24"> 彼得不知所措，正在猜测这异象到底是什么意思，哥尼流的仆人们打听到了西门的家，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 10:5–6; 使徒行传 11:11"> 正站在门口大声问西门·彼得是否住在这里。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 8:29; 使徒行传 11:12; 使徒行传 21:4"> 彼得还在苦苦思索的时候，圣灵对他说：“彼得，有三个人来找你，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:7–9; 撒迦利亚书 2:9–11; 以赛亚书 48:16"> 快下楼跟他们同去，不必多虑，他们是我差来的。”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:38–39; 马可福音 10:51; 使徒行传 10:29"> 彼得就下去见他们，说：“我就是你们要找的人，有什么事？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 11:14; 使徒行传 10:2; 使徒行传 22:12"> 他们说：“哥尼流百夫长是个又正直又敬畏上帝的人，所有犹太人都称赞他。圣天使指示他请你到他家里去，好听你的指教。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 10:45; 使徒行传 11:12; 彼得前书 4:9"> 彼得就留他们住了一夜。第二天，彼得和他们以及几个约帕的弟兄一同出发了。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 8:40; 撒迦利亚书 8:20–23; 撒迦利亚书 3:10"> 又过了一天，他们到达凯撒利亚。哥尼流已经叫来亲朋好友，在等候他们。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 19:10; 启示录 22:8–9; 但以理书 2:46"> 彼得一进来，哥尼流就迎上去俯伏在他脚前拜他。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 19:10; 启示录 22:8–9; 使徒行传 14:14–15"> 彼得连忙把他扶起来，说：“快起来，我也只不过是人。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 2:12; 约翰福音 4:35; 使徒行传 10:24"> 彼得和他边走边谈，进屋后，见聚集了许多人，</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:9; 以弗所书 3:6–7; 加拉太书 2:12–14"> 就对他们说：“你们知道，按照律法，犹太人不可和外族人来往。但上帝已经指示我不可把任何人视为污秽不洁。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:60; 彼得前书 3:15; 使徒行传 10:19–20"> 所以，我受到邀请后，毫不犹豫地来了。请问你们为什么请我来？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 10:3; 但以理书 9:20–21; 尼希米记 9:1–3"> 哥尼流说：“四天前，大约也是下午三点这个时候，我在家里祷告，忽然有一个身穿明亮衣服的人站在我面前，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:4; 但以理书 9:23; 路加福音 1:13"> 说，‘哥尼流，上帝已经垂听了你的祷告，也记念你的施舍。</span>
<span className="v" id="v32" data-v="32"> 你派人去约帕把那个叫西门·彼得的人请来，他住在海边一个叫西门的皮革匠家里。’</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 1:19; 加拉太书 4:14; 历代志下 30:12"> 于是我立刻派人去请你。你能来，真是荣幸，现在我们都在上帝面前，想聆听主吩咐你传给我们的话。”</span>
</div>
</div>

## 福音临到外族人

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="罗马书 2:11; 历代志下 19:7; 申命记 10:17"> 彼得说：“现在我真的明白了，上帝不偏待人。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:29; 使徒行传 10:2; 罗马书 10:12–13"> 无论哪一个民族，只要敬畏祂，秉公行义，都会蒙祂接纳。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 28:18; 使徒行传 2:36; 启示录 17:14"> 上帝借着万物的主宰耶稣基督把平安的福音传给以色列人。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 4:14; 使徒行传 2:22; 使徒行传 28:22"> 你们都知道，自从约翰宣讲洗礼以来，从加利利开始，整个犹太地区发生了什么事。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:18; 使徒行传 2:22; 以赛亚书 61:1–3"> 你们也知道，拿撒勒人耶稣是上帝用圣灵和大能膏立的。祂周游四方，广行善事，医治被魔鬼压制的人，因为上帝与祂同在。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:48; 使徒行传 1:8; 使徒行传 10:41"> 我们亲眼目睹了耶稣在犹太全境和耶路撒冷的一切作为。可是，他们却把祂钉死在十字架上。</span>
<span className="v" id="v40" data-v="40" data-xref="彼得前书 1:21; 使徒行传 13:30–31; 哥林多前书 15:3–4"> 但第三天，上帝使祂从死里复活，并且向人显现，</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 14:22; 使徒行传 10:39; 约翰福音 21:13"> 不是向所有的人显现，而是向被上帝预先拣选为祂做见证的人显现，就是我们这些在祂复活以后与祂一同吃喝过的人。</span>
<span className="v" id="v42" data-v="42" data-xref="哥林多后书 5:10; 提摩太后书 4:1; 彼得前书 4:5"> 祂命令我们向世人传道，见证祂就是上帝指派来审判活人和死人的那位。</span>
<span className="v" id="v43" data-v="43" data-xref="撒迦利亚书 13:1; 使徒行传 2:38; 以赛亚书 53:11"> 所有先知也都为祂做见证说，‘谁信祂，谁的罪就能借着祂的名得到赦免。’”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行传 11:15; 使徒行传 19:6; 使徒行传 15:8"> 彼得还在说话的时候，圣灵就降临在每一个听道的人身上。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 10:23; 使徒行传 2:38; 加拉太书 3:13–14"> 跟彼得一起来的那些严守割礼的信徒看见圣灵的恩赐也浇灌到外族人身上，都很惊奇。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 19:6; 使徒行传 2:4; 马可福音 16:17"> 因为他们听见这些人又说方言又赞美上帝。于是彼得说：</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 8:36; 罗马书 10:12; 使徒行传 11:15–17"> “既然这些人已经和我们一样领受了圣灵，谁能阻止他们接受洗礼呢？”</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 2:38; 使徒行传 8:16; 加拉太书 3:27"> 彼得吩咐他们奉耶稣基督的名受洗。之后，他们又请彼得住了几天。</span>
</div>
</div>

</div>

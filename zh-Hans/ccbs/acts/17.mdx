## 保罗在帖撒罗尼迦传道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 1:1; 腓立比书 4:16; 使徒行传 20:4"> 保罗和西拉经过暗非坡里和亚波罗尼亚，到了帖撒罗尼迦。那里有犹太人的会堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 9:20; 使徒行传 17:17; 使徒行传 18:4"> 保罗照以往的习惯进入会堂，一连三个安息日引用圣经与他们讨论，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:28; 使徒行传 9:22; 路加福音 24:32"> 解释、证明基督必须受害，然后从死里复活，又说：“我向你们宣讲的这位耶稣就是基督。”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 17:12; 使徒行传 13:43; 使徒行传 14:4"> 不少人被说服，成为保罗和西拉的同道，其中有许多是敬畏上帝的希腊人和有名望的妇女。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:26; 使徒行传 17:13; 罗马书 16:21"> 那些不信主的犹太人却妒火中烧，他们召集了一群市井无赖，在城里引发骚乱，闯进耶孙的家企图把保罗和西拉揪出来示众。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:5; 使徒行传 16:19–21; 使徒行传 28:22"> 他们找不到二人，就把耶孙和几个弟兄拉到当地官员面前，高喊：“那些搅乱天下的人到我们这里来了，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行传 16:21; 约翰福音 19:12"> 耶孙接待了他们。他们违抗凯撒的命令，说另有一个王叫耶稣。”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 2:3; 约翰福音 11:48"> 百姓和当地官长听后，深感不安。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 17:5"> 于是，官长命耶孙等人缴纳保释金，然后释放了他们。</span>
</div>
</div>

## 庇哩亚人接受福音

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:2; 帖撒罗尼迦前书 2:2; 使徒行传 17:13–14"> 弟兄姊妹立刻在夜间把保罗和西拉送往庇哩亚。他们二人一到，就进了犹太会堂。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 34:16; 箴言 2:1–5; 约翰福音 5:39"> 当地的人比帖撒罗尼迦人开明，非常乐意接受真道，还天天查考圣经，看看所听的道是否合乎圣经。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:14; 使徒行传 14:1; 使徒行传 13:50"> 结果有很多人信了，包括不少有名望的希腊妇女和男子。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 2:14–16; 箴言 28:25; 使徒行传 6:12"> 可是，帖撒罗尼迦的犹太人听到保罗在庇哩亚宣扬上帝的道，就赶来怂恿、煽动众人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 17:10; 马太福音 10:23; 使徒行传 9:25"> 庇哩亚的弟兄姊妹立刻送保罗到海边，西拉和提摩太仍然留在庇哩亚。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 18:5; 帖撒罗尼迦前书 3:1; 使徒行传 18:1"> 护送保罗的人一直把他送到雅典，然后带着保罗的口信回庇哩亚，交代西拉和提摩太尽快赶去雅典与保罗会合。</span>
</div>
</div>

## 保罗在雅典传道

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:158; 彼得后书 2:7; 诗篇 119:136"> 保罗在雅典等候他们的时候，看见满城都是偶像，心里非常着急。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:16; 使徒行传 14:1–4; 使徒行传 17:2–4"> 于是，他在会堂跟犹太人和虔诚的外族人辩论，每天在广场上跟遇见的人辩论。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:20–21; 歌罗西书 2:8; 路加福音 11:53"> 还有一些伊壁鸠鲁和斯多亚学派的哲学家和保罗争论，有人说：“这人在胡言乱语什么呀？”还有人说：“他好像在宣扬外国的神明。”他们这样说是因为保罗在传讲耶稣和祂复活的福音。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:27; 使徒行传 17:22; 使徒行传 24:24"> 他们带保罗到亚略·巴古议会，问他：“我们可以知道你所教导的这个新道理吗？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 1:23; 何西阿书 8:12; 哥林多前书 2:14"> 你的言论听起来确实稀奇，我们很想知道个究竟。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:16–17; 歌罗西书 4:5; 以弗所书 5:16"> 这些雅典人和侨居在那里的人无所事事，只喜欢谈论和打听一些新鲜事儿。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:19; 使徒行传 19:35; 使徒行传 17:16"> 保罗在亚略·巴古议会中站起来说：“各位雅典人，我看得出你们在各方面都非常虔诚。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:22; 加拉太书 4:8–9; 约翰福音 17:3"> 我在街上走的时候，观察了你们所敬拜的对象，发现一座祭坛上面写着‘献给未知之神’。这位你们不认识却在敬拜的神，我现在介绍给你们。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 8:27; 申命记 10:14; 使徒行传 7:48"> “这位创造宇宙万物的上帝是天地的主宰，并不住在人手建造的庙宇里，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 50:8–13; 创世记 2:7; 以赛亚书 42:5"> 也不需要人的侍奉，因为祂一无所缺。祂亲自将生命、气息和万物赐给世人。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:7–8; 创世记 3:20; 罗马书 5:12–19"> 祂从一人造出万族，让他们散居世界各地，又预先定下他们的期限和居住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 23:23–24; 申命记 4:7; 使徒行传 14:17"> 以便他们寻求祂，或许他们可以摸索着找到祂。祂原本就离我们各人不远，</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 12:10; 歌罗西书 1:17; 希伯来书 1:3"> 我们的生活、行动和存在都靠祂，你们的诗人也说过，‘我们是祂的子孙。’</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 40:25; 出埃及记 20:4; 诗篇 115:4–8"> 我们既然是上帝的子孙，就不该认为上帝是人凭手艺和想象用金、银、石头所雕刻的样子。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:16; 提多书 2:11–12; 路加福音 24:47"> “上帝以往不鉴察世人的无知，现在则命令世上所有的人都要悔改。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:31–46; 彼得后书 3:7; 罗马书 2:16"> 因为祂已经定了日子，要借祂所设立的人按公义审判这个世界。祂叫那人从死里复活，给了世人可信的凭据。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 17:18; 使徒行传 26:8; 使徒行传 25:19"> 听见保罗提到死人复活的事，有些人就嘲笑他，还有些人说：“我们改天再听你讲这个。”</span>
<span className="v" id="v33" data-v="33"> 于是保罗离开了他们。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 17:19; 罗马书 11:5–6; 使徒行传 13:48"> 不过，也有人跟随保罗，信了耶稣，其中有亚略·巴古的会员丢尼修和一位名叫戴玛丽的妇人及其他人。</span>
</div>
</div>

</div>

## 教会受迫害

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 22:20; 但以理书 3:16–18; 使徒行传 5:40"> 当时，扫罗也赞成杀死司提凡。从那天起，耶路撒冷的教会开始遭到极大的迫害。除了使徒之外，门徒都分散到犹太和撒玛利亚各地。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:10–11; 创世记 23:2; 耶利米书 22:18"> 有些虔诚人将司提凡埋葬了，为他大声痛哭。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:13; 加拉太书 1:13; 哥林多前书 15:9"> 扫罗却在摧毁教会，他挨家挨户搜寻，把男女信徒抓进监牢。</span>
</div>
</div>

## 腓利传扬福音

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:23; 使徒行传 11:19; 使徒行传 8:1"> 但那些分散到各地的信徒走到哪里，就将福音传到哪里。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:5; 使徒行传 21:8; 使徒行传 8:35–36"> 腓利来到撒玛利亚城宣讲基督。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 4:41–42; 历代志下 30:12; 马太福音 20:15–16"> 城里的人耳闻目睹他所行的神迹，都聚精会神地听他讲道。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:1; 使徒行传 14:8–10; 马可福音 16:17–18"> 当时有许多人被污鬼附身，那些污鬼大声喊叫着被赶了出来。许多瘫痪的和瘸腿的也被治好了。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:52; 使徒行传 13:48; 使徒行传 8:39"> 城里欢天喜地。</span>
</div>
</div>

## 术士归主

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:6; 使徒行传 5:36; 约翰福音 7:18"> 城中有个名叫西门的术士，向来自命不凡，曾用邪术使撒玛利亚人惊奇不已。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:34; 彼得后书 2:2; 启示录 13:3"> 无论尊卑，众人都听从他，称他为“上帝的大能者”。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 8:9; 加拉太书 3:1; 以赛亚书 44:25"> 他们听从他，因为他长期用邪术迷惑他们。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 2:38; 使徒行传 1:3; 马太福音 28:19"> 后来，他们相信了腓利所传有关上帝国度的福音和耶稣基督的名，男男女女都接受了洗礼。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:6–7; 约翰福音 5:20; 使徒行传 19:11"> 西门本人也信了基督，接受了洗礼，并常常追随腓利左右。腓利所行的神迹奇事令他非常惊奇。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 帖撒罗尼迦前书 3:2; 加拉太书 2:9"> 耶路撒冷的使徒听说撒玛利亚人接受了上帝的道，就派彼得和约翰去那里。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:38; 约翰福音 16:23–24; 约翰福音 14:13–14"> 二人到了，为那些信徒祷告，好让他们领受圣灵，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 19:2; 马太福音 28:19"> 因为他们只是奉耶稣的名受了洗，圣灵还没有降在他们身上。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 19:6; 使徒行传 6:6; 提摩太后书 1:6"> 使徒为他们按手，他们就领受了圣灵。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:5; 马太福音 10:8; 列王纪下 8:9"> 西门看见使徒一按手，就有圣灵赐下来，便拿钱给使徒，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 约翰三书 1:9; 约翰福音 5:44"> 说：“请把这能力也给我吧，以便我把手按在谁身上，就使谁领受圣灵。”</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 5:17; 马太福音 10:8; 使徒行传 2:38"> 彼得责备他说：“你和你的钱都一同毁灭吧！因为你以为可以用钱买上帝的恩赐！</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 4:13; 诗篇 36:1; 马太福音 6:22–24"> 你休想在这事工上有份，因为你在上帝面前心术不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 2:25–26; 但以理书 4:27; 希伯来书 4:12"> 你要悔改，离弃邪恶，向主祷告，或许主会赦免你心中的邪念。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 58:6; 箴言 5:22; 约翰福音 8:34"> 我看得出你充满苦涩的嫉妒，被罪恶捆绑。”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 8:8; 民数记 21:7; 约伯记 42:8"> 西门说：“请为我求求主，免得我遭受你们所说的刑罚。”</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 20:21; 使徒行传 26:22–23; 使徒行传 1:8"> 彼得和约翰为主做见证，传讲主的道。之后，他们启程回耶路撒冷，沿途又在撒玛利亚各村庄传扬福音。</span>
</div>
</div>

## 太监归主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:19; 希伯来书 1:14; 列王纪下 1:3"> 有一天，主的天使对腓利说：“起来，向南走，往耶路撒冷通往迦萨的路去。”那条路很荒凉。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 3:10; 诗篇 68:31; 以赛亚书 56:3–8"> 腓利就动身去那里，结果在那条路上遇见一个埃塞俄比亚的太监。他是埃塞俄比亚女王甘大基手下的重臣，负责管理国库。他刚从耶路撒冷参加敬拜回来，</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:16; 以赛亚书 1:1; 使徒行传 28:25"> 正坐在车上诵读以赛亚先知的书。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:19; 使徒行传 11:12; 使徒行传 20:22–23"> 圣灵吩咐腓利：“赶上去，贴近那辆马车！”</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 约翰福音 5:39; 以弗所书 5:17"> 腓利跑上前，听见太监在诵读以赛亚先知的书，就问：“你明白所读的经文吗？”</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 10:14; 诗篇 73:16–17; 以赛亚书 29:18–19"> 他说：“没有人指点我，我怎能明白呢？”他就请腓利上车和他一起坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 53:7–8; 彼得前书 2:21–24; 耶利米书 51:40"> 他刚才念的那段经文是：<br /><span className="pl pl-1">“祂默然不语，</span><br /><span className="pl pl-1">像被人牵去宰杀的羔羊，</span><br /><span className="pl pl-1">又如在剪毛人手下一声不吭的绵羊。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 53:12; 以赛亚书 53:8; 撒迦利亚书 13:7"> <span className="pl pl-1">祂忍受耻辱，</span><br /><span className="pl pl-1">无人为祂主持公道，</span><br /><span className="pl pl-1">谁能讲述祂的世代呢？</span><br /><span className="pl pl-1">因为祂的生命竟然从世上被夺去。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书53:7、8。">a</a></sup></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 15:15; 马太福音 13:36; 马太福音 2:2–4"> 太监问腓利：“请问先知是在说谁？在说他自己还是在说别人？”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行传 18:28; 使徒行传 28:23"> 腓利就从这段经文入手开口向他传耶稣的福音。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 10:47; 约翰福音 3:5; 提多书 3:5–6"> 他们往前走的时候，经过一处有水的地方，太监说：“你看，这里有水，我可以在这里接受洗礼吗？”</span>
<span className="v" id="v37" data-v="37"> 腓利说：“只要你全心相信，当然可以。”太监说：“我相信耶稣基督是上帝的儿子！”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷无37节。">b</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:1; 约翰福音 3:22–23"> 于是，太监吩咐停车，二人一同下到水里，腓利为他施洗。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:12; 列王纪下 2:16; 以西结书 8:3"> 他们从水里上来时，主的灵把腓利带走了。太监看不见腓利了，就继续前行，满心欢喜。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 21:8; 使徒行传 23:23; 使徒行传 23:33"> 后来，腓利出现在亚锁都。他走遍那里，在各城各乡传扬福音，直到凯撒利亚。</span>
</div>
</div>

## 保罗前往罗马

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 25:25; 使徒行传 25:12; 使徒行传 10:1"> 他们决定让我们坐船去意大利，于是将保罗和其他囚犯都交给一位皇家兵团的百夫长犹流看管。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:29; 腓利门书 1:24; 歌罗西书 4:10"> 有一艘亚大米田的船准备沿着亚细亚海岸航行。我们上船启航，同行的还有帖撒罗尼迦的马其顿人亚里达古。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 24:23; 使徒行传 28:16; 使徒行传 27:43"> 第二天，船停泊在西顿港，犹流宽待保罗，准许他探望当地的朋友，接受他们的照应。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 15:39; 使徒行传 13:4"> 我们从那里启航后，由于遇到逆风，便沿着塞浦路斯的背风岸前行，</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:9; 使徒行传 13:13; 使徒行传 15:41"> 经过基利迦和旁非利亚附近的海域，来到吕迦的每拉。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 28:11; 使徒行传 27:1; 使徒行传 6:9"> 百夫长在那里找到一艘从亚历山大驶往意大利的船，他吩咐我们搭乘那艘船。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 27:21; 提多书 1:5; 提多书 1:12"> 一连多日船速十分缓慢，好不容易才驶近革尼土。因为强风船无法前行，我们只好沿着克里特背风岸航行，经过撒摩尼角。</span>
<span className="v" id="v8" data-v="8"> 船沿着海岸行进，几经艰难才到达拉西亚城附近的佳澳。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 29:7; 利未记 23:27–29; 利未记 16:29–31"> 我们耽误了不少日子，由于禁食的节期<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="指犹太人的赎罪日，约在阳历九月、十月间（参见利未记23:27）。">a</a></sup>已过，航行很危险，保罗就劝告众人说：</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 2:30; 使徒行传 27:20–26; 使徒行传 27:41–44"> “各位，照我看来，我们如果继续航行，不只会损失货物和船只，甚至连我们的性命也难保。”</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 33:4; 希伯来书 11:7; 以西结书 3:17–18"> 但那百夫长只相信船主和舵手的话，不接受保罗的劝告。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:30; 使徒行传 27:8"> 由于佳澳港不适宜过冬，大部分人赞成启航，以为或许可以赶到菲尼基过冬。菲尼基是克里特的一个港口，一面向西南，一面向西北。</span>
</div>
</div>

## 惊涛骇浪

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 约伯记 37:17"> 那时，南风徐徐吹来，他们以为能继续航行，于是起锚沿着克里特行进。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 4:37; 诗篇 107:25–27; 出埃及记 14:21–27"> 可是出发不久，从岛上刮来一股猛烈的东北风<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“猛烈的东北风”希腊文是“友拉革罗飓风”。">b</a></sup>，</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:4; 使徒行传 27:27"> 船被刮得失去控制，我们只好任船随风漂流。</span>
<span className="v" id="v16" data-v="16"> 船沿着一个叫高达的小岛的背风面前进，大家好不容易才控制住救生船。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 27:29; 使徒行传 27:26; 使徒行传 27:41"> 水手把救生船拉上甲板后，又用绳索加固船身。因为怕船会在赛耳底搁浅，于是收起船帆，任船漂流。</span>
<span className="v" id="v18" data-v="18" data-xref="约拿书 1:5; 使徒行传 27:38; 马太福音 16:26"> 第二天，风浪依然猛烈，他们开始把货物抛进海里。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:4; 路加福音 9:24–25; 马可福音 8:35–37"> 第三天，他们又亲手把船上的用具也抛掉了。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:29; 马太福音 8:24–25; 耶利米书 2:25"> 一连好几天都看不到太阳、星辰，加上风浪肆虐，我们完全放弃了得救的指望。</span>
</div>
</div>

## 保罗安慰众人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 诗篇 107:5–6; 使徒行传 27:7"> 这时大家已经多日没有进食，保罗站在他们当中说：“各位当初如果肯听我劝，不离开克里特，就不会遭受这些损失了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 27:25; 使徒行传 27:36; 哥林多后书 4:8–9"> 现在我劝各位放心，你们无人会丧命，只是这艘船保不住了。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:11; 罗马书 1:9; 提摩太后书 4:17"> 因为昨天晚上，我所归属、所事奉的上帝差遣天使站在我身旁，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:11; 提摩太后书 4:16–17; 马太福音 10:28"> 对我说，‘保罗，不用怕，你一定会站在凯撒面前，并且上帝已经赐平安给所有和你同船的人。’</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 4:20–21; 路加福音 1:45; 民数记 23:19"> 所以请各位放心，我深信上帝所说的话必然会成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 28:1; 使徒行传 27:17; 使徒行传 27:29"> 只是我们一定会在某个岛上搁浅。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约拿书 1:6; 使徒行传 27:30; 启示录 18:17"> 第十四天的晚上，我们在亚得里亚海漂来漂去。到了午夜时分，水手觉得离陆地不远了，</span>
<span className="v" id="v28" data-v="28"> 就探测水深，结果约三十七米深，过了一会儿再测水深，只有二十七米左右。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 27:17; 希伯来书 6:19; 申命记 28:67"> 他们怕会触礁，就从船尾抛下四个锚，期待天亮。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 27:16; 使徒行传 27:32"> 水手们想要弃船逃生，假装要从船头抛锚，却偷偷地把救生船放到海里。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 2:13–14; 诗篇 91:11–12; 耶利米书 29:11–13"> 保罗对百夫长和士兵们说：“除非他们留在船上，否则你们都活不了！”</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比书 3:7–9; 路加福音 16:8"> 士兵就砍断绳索，让救生船漂走。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 到了黎明时分，保罗劝大家吃东西，说：“你们提心吊胆、不思饮食已经十四天了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:30; 列王纪上 1:52; 路加福音 21:18"> 我劝你们吃点东西，好活下去，你们必定毫发无损。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 15:36; 哥林多前书 10:30–31; 提摩太前书 4:3–4"> 保罗说完后拿起饼，当众感谢上帝，然后掰开吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 1:4–6; 使徒行传 27:22; 诗篇 27:14"> 于是大家都振作起来，吃了些东西。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 2:41; 罗马书 13:1; 彼得前书 3:20"> 船上共有二百七十六人。</span>
<span className="v" id="v38" data-v="38" data-xref="约拿书 1:5; 马太福音 6:25; 使徒行传 27:18–19"> 吃饱了以后，为了要减轻船的重量，他们把麦子抛进海里。</span>
</div>
</div>

## 安全登陆

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 28:1"> 天亮的时候，水手发现了一片不认识的陆地，看见一个有沙滩的海湾，便决定尽可能在那里靠岸。</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 33:23; 使徒行传 27:29–30"> 于是砍断锚索，把锚扔进海里，同时松开舵绳，升起前帆，顺着风势驶向那沙滩。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多后书 11:25–26; 以西结书 27:26; 使徒行传 27:26–29"> 可是，遇到两流交汇的水域，船就搁浅了，船头卡在那里不能动弹，船尾被大浪撞裂了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马可福音 15:15–20; 传道书 9:3; 诗篇 74:20"> 士兵们想把囚犯全杀掉，怕有人乘机游泳逃走。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 27:3; 箴言 16:7; 使徒行传 27:11"> 但百夫长为了救保罗，不准他们轻举妄动，下令会游泳的先跳到海里游上岸。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 27:22; 诗篇 107:28–30; 约翰福音 6:39–40"> 其余的人利用木板和船体的碎片游上岸。结果，全船的人都平安上岸。</span>
</div>
</div>

## 提摩太加入福音事工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:5; 提摩太后书 1:2; 哥林多前书 4:17"> 保罗来到特庇，然后又到路司得。那里有个门徒名叫提摩太，母亲是信主的犹太人，父亲是希腊人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 5:10; 提摩太后书 3:15; 使徒行传 14:21"> 路司得和以哥念的弟兄姊妹都称赞提摩太。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:3; 哥林多前书 9:20; 加拉太书 5:6"> 保罗打算带提摩太同行。因为当地的犹太人都知道提摩太的父亲是希腊人，保罗就给提摩太行了割礼。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 15:28–29; 使徒行传 15:2; 使徒行传 11:30"> 他们走遍各城，把耶路撒冷的使徒和长老所定下的规条教导当地的门徒遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:31; 使徒行传 2:47; 使徒行传 6:7"> 这样，众教会在信仰上得到坚固，人数天天都在增加。</span>
</div>
</div>

## 马其顿人的呼求

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 18:23; 使徒行传 16:7; 使徒行传 13:2–4"> 由于圣灵禁止他们到亚细亚传福音，他们便经过弗吕迦和加拉太地区，</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:9; 腓立比书 1:19; 加拉太书 4:6"> 来到每西亚的边界，正要进入庇推尼地区，耶稣的灵还是不许。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 2:12; 提摩太后书 4:13; 使徒行传 16:11"> 他们就越过每西亚，下到特罗亚。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:10–12; 使徒行传 19:21; 使徒行传 18:5"> 当晚，保罗在异象中看见一个马其顿人站在那里恳求他：“请到马其顿来帮助我们！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 2:12–13; 使徒行传 14:7; 使徒行传 16:10–17"> 保罗见了这个异象，确定是上帝呼召我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本书作者路加此时加入保罗的行列，故改用第一人称复数“我们”。">a</a></sup>到马其顿去传福音，就立刻准备动身。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:1; 使徒行传 16:8"> 我们从特罗亚启航，直接驶往撒摩特喇，第二天抵达尼亚坡里，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 2:2; 腓立比书 1:1; 使徒行传 20:6"> 再从那里来到腓立比。腓立比是马其顿的主要城市，是罗马的殖民地。我们在那里住了几天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 13:14; 歌罗西书 1:23; 使徒行传 17:2"> 安息日那天，我们到城外的河边，知道那里有一个祷告的地方，就坐下来，向已经聚集的妇女讲道。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:17–18; 路加福音 24:45; 以赛亚书 50:5"> 听众中有个卖紫色布匹的妇人名叫吕底亚，是推雅推喇城的人，向来敬拜上帝。上帝开启她的心，她便留心听保罗讲道。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 11:14; 希伯来书 13:2; 使徒行传 16:33"> 吕底亚和家人接受洗礼之后，极力邀请我们，说：“如果你们认为我是真心信主的话，请来我家住。”于是强留我们住下。</span>
</div>
</div>

## 保罗和西拉入狱

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 19:31; 申命记 18:9–11; 以赛亚书 8:19"> 一天，我们又去河边那个祷告的地方，途中遇到一个被巫鬼附身的女奴。她用占卜为她的主人们赚了不少钱。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 14:6; 彼得前书 2:16; 马可福音 5:7"> 她跟着保罗和我们，大喊大叫：“这些人是至高上帝的奴仆，是来向你们宣讲得救之道的。”</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:17; 路加福音 10:17–19; 使徒行传 3:6"> 一连几天，她都这样喊叫。保罗不胜其烦，就转过身来斥责那鬼：“我奉耶稣基督的名命令你从她身上出来！”那鬼立刻从她身上出去了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 使徒行传 21:30; 使徒行传 8:3"> 她的主人们眼见财路断绝了，就把保罗和西拉揪住，拖到广场去见官长。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 4:4; 约翰福音 15:18–20; 使徒行传 28:22"> 他们在官长面前控告保罗和西拉，说：“这些是犹太人，竟扰乱我们的城市，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 3:8; 使徒行传 26:3; 耶利米书 10:3"> 宣扬我们罗马人不可接受或实行的风俗。”</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:2; 哥林多后书 6:5; 哥林多后书 11:23–25"> 于是，民众一起攻击他们，官长下令剥掉他们的衣服，杖打他们。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 2:10; 提摩太后书 2:9; 撒母耳记上 23:22–23"> 他们被毒打一顿，又被关进监狱，官长命狱卒严加看守。</span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 13:27; 约伯记 33:11; 耶利米书 29:26"> 狱卒接到命令后把他们关进内牢，双脚上了枷锁。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 5:16–18; 诗篇 119:62; 雅各书 1:2"> 半夜，保罗和西拉祷告、唱圣诗赞美上帝，其他囚犯都侧耳倾听。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:31; 使徒行传 5:19; 使徒行传 12:10"> 突然间发生大地震，整座监狱的地基都摇动起来，牢门立刻全开了，囚犯的锁链也都松开了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 12:19; 马太福音 27:5; 士师记 9:54"> 狱卒惊醒后，看见牢门尽开，以为囚犯已经逃走了，就要拔刀自杀。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦前书 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保罗见状大声喝止：“不要伤害自己，我们都在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="启示录 3:9; 使徒行传 24:25; 以赛亚书 60:14"> 狱卒叫人拿灯过来，冲进内牢，战战兢兢地俯伏在保罗和西拉面前。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:37; 约翰福音 6:27–29; 以赛亚书 58:9"> 狱卒领他们出来后问道：“两位先生，我该怎样做才能得救？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:12; 使徒行传 2:38–39; 约翰福音 3:36"> 他们说：“要信主耶稣，你和你一家就必定得救。”</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 1:16; 歌罗西书 1:27–28; 提摩太前书 1:13–16"> 于是保罗和西拉向狱卒和他全家传讲主的道。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 1:16; 使徒行传 16:15; 使徒行传 16:25"> 当晚，狱卒把二人带去，为他们清洗伤口。他一家老小都接受了洗礼。</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 15:13; 使徒行传 2:46; 罗马书 5:11"> 他请二人到家里并为他们摆上饭食，他和全家人充满了喜乐，因为都信了上帝。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="耶利米书 5:22; 诗篇 76:10; 使徒行传 5:40"> 第二天早上，官长派差役来，说：“把他们放了。”</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 15:33; 约翰福音 14:27; 撒母耳记上 1:17"> 狱卒转告保罗说：“官长下令释放你们，现在你们可以平安地走了。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 22:25–29; 诗篇 58:1–2; 马太福音 10:16"> 保罗却说：“我们是罗马公民，他们未经审讯就当众打我们，又把我们关进牢里，现在却想偷偷打发掉我们吗？这样不行，叫他们亲自来领我们出去！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:29; 马太福音 21:46; 马太福音 14:5"> 差役回报官长。官长得知保罗和西拉都是罗马公民，非常害怕，</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 8:34; 马可福音 5:17; 但以理书 6:23"> 连忙到狱中向他们道歉，领他们出监，一再央求他们离开腓立比。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 3:2–3; 使徒行传 16:14; 使徒行传 14:22"> 二人离开监狱，来到吕底亚家中，见了弟兄姊妹，劝勉一番之后，便离开了那里。</span>
</div>
</div>

## 扫罗归主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 8:3; 提摩太前书 1:13; 加拉太书 1:13"> 扫罗继续用凶狠的话恐吓主的门徒。他去见大祭司，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:9; 使徒行传 19:23; 使徒行传 24:14"> 要取得授权书到大马士革的各会堂搜捕信奉这道的人，无论男女，都要把他们绑了押回耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:12–13; 哥林多前书 15:8; 使徒行传 22:6"> 当他快到大马士革的时候，突然有一道光从天上四面照着他。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 2:8; 创世记 22:11; 罗马书 11:22"> 他倒在地上，听见有声音对他说：“扫罗！扫罗！你为什么迫害我？”</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 1:13; 撒母耳记上 3:4–10; 约伯记 9:4"> 他说：“主啊，你是谁？”那声音说：“我就是你所迫害的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 22:10; 使徒行传 26:16; 提摩太前书 1:14–16"> 起来！进城去，有人会告诉你该做的事。”</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 22:9; 但以理书 10:7; 使徒行传 26:13–14"> 同行的人站在那里只听见声音，却看不见人，吓得张口结舌。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 22:11; 使徒行传 9:18; 列王纪下 6:17–20"> 扫罗从地上爬起来，睁大眼睛，却什么也看不见，同伴拉着他的手进了大马士革。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿书 3:6–8; 以斯帖记 4:16; 历代志下 33:12–13"> 一连三天，扫罗什么也看不见，也不吃也不喝。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 22:1; 使徒行传 10:3; 使徒行传 22:12"> 这时候，有个叫亚拿尼亚的门徒住在大马士革，他在异象中听见主呼唤他的名字，就回答说：“主啊，我在这里。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:39; 使徒行传 22:3; 使徒行传 9:30"> 主说：“起来，到直街的犹大家去找一个来自大数、名叫扫罗的人，他正在祷告。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 5:23; 使徒行传 9:10; 使徒行传 9:17–18"> 他在异象中看见一个名叫亚拿尼亚的人去他那里，把手按在他身上，使他恢复视力。”</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 1:13–15; 使徒行传 8:3; 使徒行传 22:19–20"> 亚拿尼亚回答说：“主啊！我听见许多人说他对耶路撒冷的圣徒大加迫害。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:21; 使徒行传 7:59; 提摩太后书 2:22"> 他来这里是得到祭司长的授权，要拘捕所有求告你名的人。”</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:15–16; 以弗所书 3:7–8; 提摩太后书 4:16–17"> 主对亚拿尼亚说：“你放心去吧！他是我拣选的器皿，要向外族人、君王和以色列人宣扬我的名。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 3:3; 使徒行传 21:11; 哥林多后书 6:4"> 我会让他知道，他必为我的名受许多的苦。”</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 8:17; 使徒行传 6:6; 使徒行传 2:4"> 亚拿尼亚去了，进了那家，就把手按在扫罗身上，说：“扫罗弟兄，在你来的路上向你显现的主耶稣派我来使你重见光明、被圣灵充满。”</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 3:14; 使徒行传 22:16; 使徒行传 2:38"> 顿时，扫罗的眼睛上有鳞片似的东西脱落，他就恢复了视力，便起来接受了洗礼。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:20; 撒母耳记上 30:12; 加拉太书 1:17"> 他吃过东西之后，体力也恢复了。他和大马士革的门徒住了几天之后，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 20:28; 加拉太书 2:20; 约翰一书 4:14–15"> 随即到各会堂去宣讲：“耶稣是上帝的儿子。”</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:13–14; 使徒行传 8:3; 帖撒罗尼迦后书 1:10"> 听的人都大吃一惊，说：“他不就是那在耶路撒冷迫害信徒的人吗？他到这里来不是要把他们绑了押去见祭司长吗？”</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 18:5; 以赛亚书 40:29; 路加福音 21:15"> 但扫罗越发有能力，他向大马士革的犹太人证明耶稣是基督，使他们惊慌失措。</span>
</div>
</div>

## 扫罗逃生

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:17–18; 帖撒罗尼迦前书 2:15–16; 使徒行传 14:19"> 过了一段日子，犹太人图谋杀死扫罗。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 11:32; 使徒行传 25:3; 使徒行传 20:3"> 他们昼夜在城门守候，伺机下手，但这阴谋被扫罗知道了。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 2:15; 哥林多后书 11:33; 撒母耳记上 19:11–12"> 他的门徒趁夜间用筐子把他从城墙上缒下去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:20; 加拉太书 1:17–19; 使徒行传 9:19"> 扫罗逃到耶路撒冷后，曾设法与当地的门徒联络，可是他们都怕他，不相信他是门徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:36; 使徒行传 4:29; 使徒行传 4:13"> 只有巴拿巴接待他，带他去见使徒，向他们陈述扫罗如何在路上遇见主，主如何对他说话，他又如何勇敢地在大马士革奉耶稣的名传道。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 1:21; 民数记 27:16–17; 诗篇 121:8"> 于是，扫罗就在耶路撒冷与使徒一起出入来往，奉主的名放胆传道。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 6:1; 犹大书 1:9; 使徒行传 11:20"> 他常常跟那些讲希腊话的犹太人辩论，于是他们打算杀掉他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 11:25; 使徒行传 8:40; 使徒行传 9:11"> 弟兄姊妹知道这消息后，就把扫罗带到凯撒利亚，然后送他到大数去。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 111:10; 约翰福音 14:16–18; 以赛亚书 33:6"> 当时，犹太、加利利、撒玛利亚各地的教会都很平安，得到了坚固。信徒们非常敬畏主，又得到圣灵的安慰，人数越来越多。</span>
</div>
</div>

## 彼得医治瘫痪的人

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:13; 使徒行传 8:25; 箴言 2:8"> 彼得四处奔波，来到吕大探访那里的圣徒，</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 约翰福音 5:5; 马可福音 2:3–11"> 遇见一个瘫痪的人名叫以尼雅，已经卧床八年。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:6; 使徒行传 3:12; 使徒行传 3:6"> 彼得对他说：“以尼雅，耶稣基督医治你了，起来收拾你的垫子吧！”他应声而起。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 11:21; 使徒行传 9:42; 历代志上 5:16"> 吕大和沙仑的居民看见他，都归向了主。</span>
</div>
</div>

## 彼得使死人复活

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多书 3:8; 提多书 2:7; 历代志下 2:16"> 在约帕有个乐善好施的女门徒名叫戴碧达，希腊话叫多加<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“多加”意思是“羚羊”。">a</a></sup>。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 1:13; 使徒行传 20:8; 约翰福音 11:36–37"> 当时，她患病死了。有人将她的尸体洗干净后，停放在楼上。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:36; 使徒行传 11:26; 使徒行传 9:32"> 吕大和约帕相距不远，门徒听说彼得在吕大，就派两个人去恳求他，说：“请立刻来我们这里！”</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒罗尼迦前书 1:3"> 彼得便随他们一同到了那里，有人领他上楼。众寡妇都站在彼得周围哭，并把多加生前缝制的内衣、外衣给他看。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:25; 马可福音 5:40–42; 路加福音 8:54"> 彼得叫她们都出去，自己跪下祷告，然后转身对死者说：“戴碧达，起来！”她便睁开了眼睛，看见彼得，就坐了起来。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 使徒行传 6:1; 创世记 45:26"> 彼得伸手扶她起来后，叫那些在外面等候的圣徒和寡妇进来，把活过来的多加交给他们。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:44; 约翰福音 12:11; 约翰福音 11:45"> 这事传遍了整个约帕，许多人都信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:6; 使徒行传 10:32"> 彼得在约帕和一个名叫西门的皮革匠住了好些日子。</span>
</div>

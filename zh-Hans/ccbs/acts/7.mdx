## 司提凡的申辩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 18:19–21; 马太福音 26:61–62; 使徒行传 6:13–14"> 大祭司问：“这是真的吗？”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:1; 创世记 11:31; 诗篇 29:3"> 司提凡说：“各位父老兄弟，请听我说！我们的祖先亚伯拉罕迁到哈兰之前，住在美索不达米亚，荣耀的上帝向他显现，说，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1; 希伯来书 11:8; 约书亚记 24:3"> ‘你要离开家乡和亲族，到我要指示你的地方去。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记12:1。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="创世记 12:4–5; 创世记 11:31–32; 以赛亚书 41:9"> 亚伯拉罕就离开迦勒底人的地方，在哈兰住了下来。他父亲过世以后，上帝又领他到你们现在住的地方。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:8; 创世记 12:7; 创世记 13:15"> 当时在这片土地上，上帝没有给他任何产业，他甚至连立足之地也没有。但上帝应许要把这片土地赐给他和他的后裔作产业，尽管那时候亚伯拉罕还没有儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 15:13; 出埃及记 12:40–41; 加拉太书 3:17"> 上帝又说，‘你的后裔必流落异乡，被奴役和虐待四百年。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 3:12; 诗篇 105:27–36; 尼希米记 9:9–11"> 但我必惩罚那奴役他们的国家，之后他们必离开那里，在这片土地上事奉我。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="创世记15:13、14。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:23–26; 创世记 17:9–14; 创世记 21:1–4"> 上帝又赐给亚伯拉罕割礼之约。所以，亚伯拉罕生以撒后第八天为他行了割礼。后来，以撒生了雅各，雅各生了十二位先祖。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 39:2; 诗篇 105:17; 以赛亚书 43:2"> “先祖们嫉妒自己的弟弟约瑟，把他卖到了埃及。但上帝一直与他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; 提摩太后书 4:18; 箴言 2:6"> 救他脱离一切危难，又赐他过人的智慧，使他在埃及法老面前得到恩宠，官拜宰相治理全国，并管理王室。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 41:54–57; 创世记 45:11; 创世记 42:5"> “后来，埃及和迦南全境遭遇饥荒，灾情严重，我们的先祖们断了粮。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:1–24; 创世记 43:2"> 雅各听说埃及有粮，就派先祖们去那里买粮，那是我们的先祖初次去埃及。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 45:1–18; 创世记 46:31–10"> 他们第二次去的时候，约瑟才和弟兄们相认，法老也知道了他的家族。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 46:26–27; 申命记 10:22; 出埃及记 1:5"> 后来，约瑟派人去把父亲雅各和全族七十五人都接到埃及。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 49:33; 出埃及记 1:6; 创世记 46:3–7"> 雅各和其他先祖们便定居埃及，直到去世。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 24:32; 创世记 23:16; 出埃及记 13:19"> 后来他们的遗体被带回示剑，安葬在亚伯拉罕买自哈抹子孙的墓地里。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 1:7–12; 使徒行传 7:6; 使徒行传 13:17"> “上帝对亚伯拉罕应许的日子快到的时侯，以色列人在埃及的人口已大大增加。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 1:8"> 后来埃及有一位不认识约瑟的新王登基。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及记1:8。">c</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 105:25; 出埃及记 1:9–22; 启示录 12:4–5"> 他用毒计苦害我们的同胞，虐待我们的祖先，强令他们把婴孩抛弃，不让婴孩存活。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:23; 出埃及记 2:2–10; 撒母耳记上 16:12"> 那时，摩西出生了，长得俊美非凡<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“长得”或译“在上帝眼中”。">d</a></sup>。他的父母在家里偷偷地抚养了他三个月，</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:24; 出埃及记 2:2–10; 申命记 32:26"> 最后把他放到外面。法老的女儿救了他，收为养子。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:11; 但以理书 1:17–20; 历代志下 9:22"> “摩西学会了埃及人一切的学问，成为一个说话办事很有能力的人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 2:11–12; 箴言 21:1; 希伯来书 11:24–26"> 他四十岁那年决定去探望自己的同胞以色列人。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:10–11; 使徒行传 7:28; 约翰福音 18:25–27"> 他到了他们那里，看见一个埃及人正在欺负以色列人，就打抱不平，杀了那个埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:7; 马可福音 9:32; 列王纪下 5:1"> 摩西以为同胞们会明白上帝要借着他的手拯救他们，可是他们并不明白。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 2:13–15; 箴言 18:19; 约翰一书 3:11–15"> 第二天，他看见两个以色列人在打架，就上前劝解说，‘你们二位是同胞，为什么互相伤害呢？’</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 7:35; 路加福音 12:14; 使徒行传 7:54"> 不料那个欺负人的推开摩西说，‘谁立你做我们的首领和审判官？</span>
<span className="v" id="v28" data-v="28"> 难道你要杀我，像昨天杀那个埃及人一样吗？’<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="出埃及记2:14。">e</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 18:2–4; 出埃及记 2:14–22; 出埃及记 4:19–20"> 摩西听了这话，就逃到米甸寄居，在那里生了两个儿子。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 3:1–2; 使徒行传 7:35; 以赛亚书 43:2"> “过了四十年，在西奈山的旷野，有天使在荆棘的火焰中向摩西显现。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:3–4"> 摩西见状很惊奇，正要上前看个究竟，就听见主说，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马太福音 22:32; 约伯记 4:14"> ‘我是你祖先的上帝，是亚伯拉罕、以撒、雅各的上帝。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="出埃及记3:6。">f</a></sup>摩西战战兢兢，不敢观看。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 3:5; 约书亚记 5:15; 传道书 5:1"> 主又说，‘脱下你脚上的鞋，因为你所站的地方是圣地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 3:7–10; 出埃及记 4:31; 诗篇 106:44"> 我已清楚看见我子民在埃及所受的苦难，也听见了他们的哀叹，我下来要救他们。你来，我要派你回埃及。’<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="出埃及记3:5、7、8、10。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:22–23; 路加福音 19:14; 诗篇 113:7–8"> “百姓曾拒绝这位摩西，说，‘谁立你做我们的首领和审判官？’上帝却借着在荆棘中显现的天使亲自差遣他，立他为首领和拯救者。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 12:41; 出埃及记 14:21; 出埃及记 33:1"> 摩西带领以色列人出埃及，过红海，越旷野，四十年间行了许多神迹奇事。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 18:15–19; 使徒行传 3:22–23; 约翰福音 18:37"> 就是这位摩西曾对以色列人说，‘上帝要在你们中间兴起一位像我一样的先知。’<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="申命记18:15。">h</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 3:2; 希伯来书 5:12; 彼得前书 4:11"> 这位摩西曾在旷野的会众中与我们祖先在一起，又在西奈山上与向他传信息的天使在一起，并且领受了生命之道传给我们。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="民数记 14:3–4; 民数记 11:5; 尼希米记 9:16–17"> “可是我们的祖先不肯听从他，甚至弃绝他，心里对埃及恋恋不舍。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 32:1; 出埃及记 32:23"> 他们对亚伦说，‘为我们造一些神像来带领我们吧！因为带我们出埃及的那个摩西不知怎样了。’<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="出埃及记32:1。">i</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="诗篇 106:19–21; 尼希米记 9:18; 启示录 9:20"> 于是，他们造了一个牛犊像，向它献祭，并为自己所做的事沾沾自喜。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司书 5:25–26; 以西结书 20:39; 耶利米书 19:13"> 因此，上帝转脸不顾他们，任由他们祭拜日月星辰，正如先知书的记载，<br /><span className="pl pl-1">“‘以色列家啊，</span><br /><span className="pl pl-1">在旷野的四十年间，</span><br /><span className="pl pl-1">你们向我献过祭物和供物吗？</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="阿摩司书 5:26–27; 出埃及记 20:4–5; 申命记 5:8–9"> <span className="pl pl-1">你们抬着为祭拜而造的神像，</span><br /><span className="pl pl-1">就是摩洛的帐篷和你们理番神明的星，</span><br /><span className="pl pl-1">所以我要把你们流放到比巴比伦还远的地方。’</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="阿摩司书5:25‑27。">j</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="出埃及记 25:40; 出埃及记 38:21; 希伯来书 8:5"> “我们的祖先在旷野的时候，一直带着安放约柜的圣幕，这圣幕是上帝吩咐摩西照他所看见的样式造的。</span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 44:2; 约书亚记 18:1; 约书亚记 23:9"> 后来我们的祖先承受了圣幕。上帝从我们祖先面前赶走外族人，使他们得到了应许之地。他们同约书亚把圣幕带到那里，一直到大卫的时代。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 132:1–5; 使徒行传 13:22; 撒母耳记下 7:1–5"> 大卫蒙上帝悦纳，祈求为雅各的上帝预备一个居所。</span>
<span className="v" id="v47" data-v="47" data-xref="列王纪上 8:20; 列王纪上 6:37–38; 撒母耳记下 7:13"> 结果是他的儿子所罗门为上帝建成了圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="使徒行传 17:24–25; 以赛亚书 66:1–2; 列王纪上 8:27"> “其实至高的上帝并不住人造的殿，祂曾借着先知说，</span>
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 66:1; 诗篇 11:4; 约翰福音 4:21"> 主说：‘天是我的宝座，地是我的脚凳，你们要为我造怎样的殿宇？哪里可作我的安歇之处？</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 32:17; 诗篇 33:6–9; 使徒行传 14:15"> 这一切不都是我亲手创造的吗？’<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="以赛亚书66:1、2。">k</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="申命记 10:16; 以弗所书 4:30; 以赛亚书 63:10"> “你们这些顽固不化、心与耳未受割礼的人，经常抗拒圣灵，所作所为和你们祖先如出一辙！</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 5:12; 历代志下 36:16; 列王纪上 19:10"> 哪一位先知没有被你们祖先迫害？那些预言义者弥赛亚要来的人也被你们的祖先杀害。如今你们竟出卖了那位义者，杀害了祂！</span>
<span className="v" id="v53" data-v="53" data-xref="希伯来书 2:2; 加拉太书 3:19; 使徒行传 7:38"> 你们接受了上帝借天使所传的律法，竟不遵守！”</span>
</div>
</div>

## 司提凡殉道

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒行传 5:33; 诗篇 35:16; 马太福音 25:30"> 众人听了这番话，怒火中烧，对司提凡咬牙切齿。</span>
<span className="v" id="v55" data-v="55" data-xref="马可福音 16:19; 希伯来书 1:3; 哥林多后书 4:6"> 司提凡却被圣灵充满，定睛望天，看见上帝的荣耀和站在上帝右边的耶稣，</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 26:64–65; 使徒行传 10:11; 启示录 11:19"> 就说：“看啊！我看见天开了，人子站在上帝的右边。”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="撒迦利亚书 7:11; 诗篇 58:4; 使徒行传 23:27"> 众人大喊大叫，捂着耳朵，一拥而上，</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行传 22:20; 使徒行传 8:1; 使徒行传 6:13"> 把司提凡拉到城外，用石头打他。指控他的人把他们的衣服交给一个名叫扫罗的青年保管。</span>
<span className="v" id="v59" data-v="59" data-xref="路加福音 23:46; 诗篇 31:5; 使徒行传 22:16"> 在乱石击打之下，司提凡呼求说：“主耶稣啊，接收我的灵魂吧！”然后跪下高声说：</span>
<span className="v" id="v60" data-v="60" data-xref="马太福音 5:44; 路加福音 23:34; 哥林多前书 15:20"> “主啊，不要追究他们的罪！”说完后，就断气了。</span>
</div>
</div>

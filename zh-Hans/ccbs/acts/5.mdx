## 欺骗圣灵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–3; 提摩太后书 2:20; 马太福音 13:47–48"> 一个名叫亚拿尼亚的人与妻子撒非喇也把田产卖了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:37; 彼得后书 2:14–15; 马太福音 23:5"> 他私自留下一部分钱，然后把其余的拿去交给使徒，这件事他妻子也知道。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 23:24; 以赛亚书 29:15; 约翰福音 13:2"> 彼得说：“亚拿尼亚，为什么撒旦充满了你的心，以致你欺骗圣灵，私自留下一些卖地的钱呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:3; 约书亚记 7:25–26; 列王纪下 5:25–27"> 田产没有卖的时候属于你，即使卖了，卖地的钱也由你支配。你怎么想到做这种事呢？你不是欺骗人，你是欺骗上帝！”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:10–11; 使徒行传 2:43; 使徒行传 5:13"> 亚拿尼亚听见这话，当场倒地而死。听见这件事的人都非常惧怕。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:40; 撒母耳记下 18:17; 申命记 21:23"> 有几个青年上前把他的尸体裹起来，抬出去埋葬了。</span>
<span className="v" id="v7" data-v="7"> 大约过了三个小时，亚拿尼亚的妻子也进来了，她还不知道发生了什么事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 5:2"> 彼得问她：“你们卖田地的钱就这么多吗？”她说：“是的，就这么多。”</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:9; 使徒行传 5:3–4; 诗篇 95:8–11"> 彼得说：“你们二人怎么串通起来试探主的灵呢？埋葬你丈夫的人就到门口了，他们也要把你抬出去。”</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:5"> 撒非喇立刻倒在彼得脚前死了。那些青年进来看见她已经死了，便把她抬出去葬在她丈夫的旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:5; 哥林多前书 10:11–12; 使徒行传 19:17"> 整个教会和听见这件事的人都非常惧怕。</span>
</div>
</div>

## 神迹奇事

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:11; 哥林多后书 12:12; 希伯来书 2:4"> 主借着使徒们在百姓中行了许多神迹奇事，大家同心合意地在所罗门廊那里聚会。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:47; 使徒行传 4:21; 约翰福音 12:42"> 其他人不敢接近他们，不过百姓都很敬重他们。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 2:47; 使徒行传 4:4; 以赛亚书 55:11–13"> 信主的人数不断增加，男女都很多。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 14:36; 使徒行传 19:11–12; 约翰福音 14:12"> 人们甚至把病人抬到街上，放在床上或垫子上，希望彼得路过时的影子可以落在病人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 16:17–18; 马可福音 2:3–4; 马太福音 15:30–31"> 还有大群的人从耶路撒冷附近的城镇带着病人和被污鬼搅扰的人赶来，他们都得了医治。</span>
</div>
</div>

## 使徒受迫害

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:45; 使徒行传 7:9; 使徒行传 17:5"> 大祭司和他的同党撒都该人看见这情形，妒火中烧，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 4:3; 路加福音 21:12; 哥林多后书 11:23"> 便把使徒拘捕，关在监牢。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:26; 诗篇 34:7; 使徒行传 12:7–11"> 当晚，有一位主的天使把狱门打开，领他们出来，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 6:63; 约翰福音 6:68; 约翰一书 5:11–12"> 说：“你们到圣殿去，把这生命之道传给百姓。”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:2; 使徒行传 22:15; 使徒行传 12:18–19"> 使徒遵从命令，在黎明的时候进入圣殿开始教导众人。 大祭司和他的同党召集了公会<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公会是犹太人的最高立法与司法机关。">a</a></sup>的全体以色列长老，然后派人去监狱把使徒押来。</span>
<span className="v" id="v22" data-v="22"> 差役来到监狱时，发现使徒已经不见了，就回去禀告，说：</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 2:4; 诗篇 33:10; 但以理书 6:22–24"> “我们看见牢门紧锁，守卫都站在门外，但打开门一看，里面却空无一人！”</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 4:1; 使徒行传 5:26; 约翰福音 12:19"> 圣殿护卫长和祭司长听后，都很困扰，不知道是怎么回事。</span>
<span className="v" id="v25" data-v="25"> 这时有人来报告说：“你们关押在牢里的人正在圣殿里教导人！”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:13; 使徒行传 4:21; 马太福音 26:5"> 圣殿护卫长和差役再去把使徒带来。这次他们不敢动粗，生怕百姓会用石头打他们。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 5:22; 使徒行传 4:7; 路加福音 22:66"> 使徒被带来之后，站在公会前，大祭司盘问他们，说：</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 27:25; 使徒行传 7:52; 使徒行传 4:10–11"> “我们不是严禁你们奉耶稣的名去教导百姓吗？你们竟然在耶路撒冷各处传道，还想把杀那人的血债归到我们身上！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:19; 撒母耳记上 15:24; 马可福音 7:7–9"> 彼得和其他使徒申辩说：“我们要服从的是上帝，而非人。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:13; 彼得前书 2:24; 使徒行传 10:39"> 你们钉死在十字架上的耶稣，我们祖先的上帝已经使祂复活了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行传 2:33; 希伯来书 2:10"> 上帝把祂提升到自己的右边，立祂为君王和救主，好赐给以色列人悔改的机会，使他们的罪得到赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:26–27; 希伯来书 2:3–4; 使徒行传 1:8"> 我们就是这些事的见证人，上帝赐给顺服祂之人的圣灵也同样做见证。”</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 7:54; 使徒行传 2:37; 路加福音 4:28–29"> 他们听了，怒气冲天，打算杀掉使徒。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 22:3; 路加福音 2:46; 路加福音 5:17"> 公会中有一位名叫迦玛列的法利赛人，是个德高望重的律法教师。他站起来，叫人把使徒暂且押到外面，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 22:26; 耶利米书 26:19; 马太福音 27:19"> 然后说：“以色列人啊，你们应当慎重处置这些人。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 8:9; 彼得后书 2:2; 加拉太书 6:3"> 之前，有个名叫杜达的人起来自立山头，吸引了差不多四百个跟随者，但他被杀之后，那些跟随者就各奔东西，销声匿迹了。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 诗篇 7:14–15; 马太福音 26:52"> 后来，又有个加利利人犹大在户口登记期间鼓动百姓跟随他造反。他被杀之后，那些跟随者也烟消云散了。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:13; 耶利米哀歌 3:37; 以赛亚书 8:9–10"> 所以，像现在这种情形，我劝大家还是不要管他们，随他们去吧。他们的计划和行为如果是出于人意，终必失败；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以赛亚书 46:10; 马太福音 16:18"> 但如果是出于上帝，你们不但无法阻止他们，恐怕发现自己是在抵挡上帝！”</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 10:17; 使徒行传 5:28; 使徒行传 4:17–21"> 公会采纳了他的意见，于是把使徒召回来打了一顿，再次警告他们不可奉耶稣的名传道，才放了他们。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各书 1:2; 彼得前书 4:13–16; 路加福音 6:22"> 使徒欢欢喜喜地离开公会，因为他们在主看来配得上为祂的名受辱。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行传 2:46; 使徒行传 20:20; 路加福音 21:37"> 他们每天在圣殿里及各家各户教导人，不断地传扬耶稣是基督。</span>
</div>
</div>

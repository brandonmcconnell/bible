## 保罗前往耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 2:17; 路加福音 5:4; 撒母耳记上 20:41–42"> 我们和众人道别之后，乘船直接驶往哥士，第二天到达罗底，从那里前往帕大喇，</span>
<span className="v" id="v2" data-v="2" data-xref="约拿书 1:3; 使徒行传 11:19; 使徒行传 15:3"> 在帕大喇遇到一艘开往腓尼基的船，就上了船。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 21:16; 使徒行传 4:36; 马太福音 4:24"> 塞浦路斯遥遥在望，船从该岛的南面绕过，一直驶向叙利亚。因为船要在泰尔卸货，我们就在那里上了岸，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 20:22–23; 使徒行传 21:10–12; 使徒行传 20:6–7"> 找到当地的门徒后，便和他们同住了七天。他们受圣灵的感动力劝保罗不要去耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 20:36; 使徒行传 9:40; 诗篇 95:6"> 时间到了，我们继续前行，众门徒和他们的妻子儿女送我们出城。大家跪在岸边祷告之后，彼此道别。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:27; 约翰福音 1:11; 哥林多后书 2:13"> 我们上了船，众人也回家去了。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:24; 撒母耳记上 10:4; 使徒行传 28:12"> 我们从泰尔乘船抵达多利买，上岸问候那里的弟兄姊妹，和他们住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 6:5; 使徒行传 8:26–40; 以弗所书 4:11"> 第二天我们离开那里，来到凯撒利亚，住在传道人腓利家里。他是当初选出的七位执事之一。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 2:17; 启示录 2:20; 约珥书 2:28"> 腓利有四个未出嫁的女儿，都能说预言。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 11:28; 使徒行传 21:4; 使徒行传 20:16"> 过了几天，一个名叫亚迦布的先知从犹太下来。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:33; 耶利米书 13:1–11; 撒母耳记上 15:27–28"> 他到了我们这里，拿保罗的腰带绑住自己的手脚，说：“圣灵说，‘耶路撒冷的犹太人也要这样捆绑这腰带的主人，把他交给外族人。’”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:21–23; 使徒行传 20:22; 使徒行传 21:4"> 听到这话，我们和当地的信徒都苦劝保罗不要去耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:24; 腓立比书 2:17; 腓立比书 1:20–21"> 但保罗说：“你们为什么这样哭泣，让我心碎呢？我为主耶稣的名甘愿受捆绑，甚至死在耶路撒冷。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 马太福音 26:42; 马太福音 26:39"> 我们知道再劝也无济于事，便不再说什么，只说：“愿主的旨意成就。”</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1; 使徒行传 25:6; 使徒行传 25:9"> 过了几天，我们准备妥当，启程上耶路撒冷。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行传 21:8; 诗篇 92:14"> 有几个凯撒利亚的门徒和我们一起去，并带我们到一个信主已久的塞浦路斯人拿孙家里住宿。</span>
</div>
</div>

## 保罗会见雅各和众长老

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 15:4; 罗马书 15:7; 希伯来书 13:1–2"> 我们抵达耶路撒冷后，受到弟兄姊妹的热烈欢迎。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 1:19; 加拉太书 2:9; 使徒行传 15:13"> 第二天，保罗和我们去见雅各，众长老都在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:27; 使徒行传 1:17; 罗马书 15:18–19"> 保罗向大家问安之后，便一一述说上帝借着他的服侍在外族人中所成就的事。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2; 加拉太书 1:14; 使徒行传 22:3"> 大家听了，都同声赞美上帝，又对保罗说：“弟兄，你知道数以万计的犹太人信了主，他们都热衷于律法。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:12–15; 哥林多前书 9:19–21; 加拉太书 5:1–6"> 他们听见有人说你教导所有住在外族人中的犹太人背弃摩西的律法，不给孩子行割礼，也不遵守犹太人的规矩。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:12; 使徒行传 15:22; 使徒行传 19:32"> 他们一定会听到你来这里的消息，这该怎么办？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 18:18; 民数记 6:2–7"> 请你听我们的建议，这里有四位向上帝许过愿的弟兄，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:26; 使徒行传 24:18; 使徒行传 18:18"> 你和他们一起去行洁净礼，并由你替他们付费，让他们可以剃头，好叫众人知道你严守律法，循规蹈矩，关于你的传闻都是假的。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:29; 使徒行传 15:19–20"> 至于那些外族信徒，我们已经写信吩咐他们，不可吃祭过偶像的食物，不可吃血和勒死的牲畜，不可淫乱。”</span>
</div>
</div>

## 保罗被捕

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 24:18; 使徒行传 21:24; 民数记 6:13–20"> 于是，保罗和四位弟兄第二天行了洁净礼，然后上圣殿报告他们洁净期满的日子，届时好让祭司为他们每个人献祭物。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:21; 使徒行传 24:18; 使徒行传 13:50"> 当七日的洁净期将满的时候，有些从亚细亚来的犹太人发现保罗在圣殿里，就煽动众人并抓住他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 24:5–6; 使徒行传 21:21; 使徒行传 26:20–21"> 同时高喊：“以色列人快来帮忙！就是这人到处教唆人反对我们的民族、律法和圣殿。他还带希腊人进圣殿，玷污这圣地。”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 提摩太后书 4:20; 使徒行传 18:19"> 这是因为他们在城里见过一个名叫特罗非摩的以弗所人和保罗在一起，以为保罗一定把他带进圣殿了。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:21; 哥林多后书 11:26; 使徒行传 16:19–22"> 这时，全城轰动。众人一拥而上抓住保罗，把他拖出圣殿，随即关上殿门。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 11:23–33; 使徒行传 17:5; 使徒行传 26:9–10"> 正当他们要杀保罗的时候，有人把耶路撒冷发生骚乱的消息报告给罗马军营的千夫长，</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:27; 以赛亚书 3:15; 使徒行传 5:40"> 千夫长马上带着军兵和几个百夫长赶来了。众人一见千夫长和军队，便停止殴打保罗。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:20; 使徒行传 21:11; 使徒行传 20:23"> 千夫长上前拿住保罗，命人用两条铁链把他锁起来，问他是什么人、做了什么事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:32; 使徒行传 23:10; 使徒行传 22:24"> 人群中有人这样喊，有人那样喊，千夫长无法了解真相，便命人将保罗带回军营。</span>
<span className="v" id="v35" data-v="35" data-xref="哈巴谷书 1:2–3; 诗篇 55:9; 诗篇 58:2"> 保罗刚走上台阶，众人便凶猛地拥挤过来，士兵们只好把他举起来抬着走。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 19:15; 使徒行传 22:22; 路加福音 23:18"> 众人跟在后面高喊：“杀掉他！”</span>
</div>
</div>

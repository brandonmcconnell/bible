<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:2; 使徒行传 28:17; 使徒行传 13:26"> “各位父老兄弟，现在请听我申辩！”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 21:40"> 在场的人听见保罗讲的是希伯来话，更加安静了。保罗说：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:5; 腓立比书 3:5–6; 使徒行传 9:11"> “我是犹太人，生于基利迦的大数，在耶路撒冷长大，曾在迦玛列门下严格地按着我们祖先的律法接受教育，像你们今日一样热心事奉上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 22:19–20; 提摩太前书 1:13–15; 使徒行传 26:9–11"> 我曾经把信奉这道的男女信徒抓进监牢，迫害他们，置他们于死地。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:1–2; 路加福音 22:66; 使徒行传 5:21"> 大祭司和众长老都可以为我作证。我还拿着他们写给大马士革的犹太弟兄的信去拘捕那里的信徒，押回耶路撒冷受刑。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:3–8; 使徒行传 26:12–18; 启示录 1:16"> “当我快到大马士革的时候，大约正午，突然有一道强光从天上四面照着我。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:9; 马太福音 25:45; 创世记 22:11"> 我就倒在地上，听见有声音对我说，‘扫罗！扫罗！你为什么迫害我？’</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:9; 撒母耳记上 8:7; 出埃及记 16:7–8"> 我回答说，‘主啊，你是谁？’他说，‘我就是你迫害的拿撒勒人耶稣！’</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:7; 但以理书 10:7; 使徒行传 26:13"> 我的同伴虽然也看见那道强光，却听不懂那位说话者的声音。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:30; 使徒行传 22:12–16; 使徒行传 2:37"> 接着我又问，‘主啊！我该怎么办？’主说，‘起来，到大马士革去，那里会有人将指派给你的事告诉你。’</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 9:8–9; 使徒行传 13:11; 以赛亚书 42:16"> “那道耀眼的光照得我双眼失明，于是同行的人拉着我的手，带我进了大马士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:22; 使徒行传 6:3; 约翰三书 1:12"> 那里有一个严守律法的虔诚人名叫亚拿尼亚，深受当地所有犹太人称道。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:17–18; 腓利门书 1:16"> 他来探望我，站在我身边说，‘扫罗弟兄，重见光明吧！’就在那一刻，我抬头看见了他。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:12; 哥林多前书 15:8; 哥林多前书 9:1"> 他又说，‘我们祖先的上帝拣选了你，要你明白祂的旨意，又让你亲自看见那位公义者、听到祂的声音。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:11; 使徒行传 4:20; 约翰福音 15:27"> 因为你将做祂的见证人，把所见所闻告诉万民。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 2:21; 提多书 3:5"> 现在你还等什么呢？起来求告祂的名，接受洗礼，洗净你的罪。’</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 12:1–4; 使徒行传 10:9–10; 使徒行传 9:26–28"> “后来，我回到耶路撒冷，在圣殿里祷告的时候，进入异象，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:29; 路加福音 21:21; 以西结书 3:6–7"> 看见主对我说，‘赶快离开耶路撒冷，因为这里的人不会接受你为我做的见证。’</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 22:4; 马太福音 10:17; 使徒行传 8:3"> 我说，‘主啊！他们都知道我从前搜遍各会堂，逮捕和毒打信你的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:58; 使徒行传 8:1; 罗马书 1:32"> 当你的见证人司提凡为你流血殉道时，我自己也站在旁边赞同杀他的人，还替他们保管衣服。’</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:15; 提摩太前书 2:7; 以弗所书 3:6–8"> 主却对我说，‘去吧！我要差遣你到遥远的外族人那里。’”</span>

## 因罗马公民身份而免刑

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:24; 使徒行传 21:36; 约翰福音 19:15"> 众人一听到这里，就高喊：“从世上除掉这样的人！他不配活着！”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:13; 使徒行传 26:11; 传道书 10:3"> 他们大喊大叫，扔掉外衣，扬起尘土。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:31–32; 使徒行传 21:34; 约翰福音 19:1"> 千夫长下令把保罗押回营房，预备鞭打拷问他，要查出众人向他喊叫的缘由。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:37; 使徒行传 25:16; 使徒行传 27:43"> 他们把保罗绑起来正要鞭打，保罗问旁边的百夫长：“未经定罪就拷打罗马公民合法吗？”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 23:27; 使徒行传 22:29"> 百夫长一听，就去禀告千夫长说：“你看该怎么办？这人是罗马公民。”</span>
<span className="v" id="v27" data-v="27"> 千夫长就来问保罗：“告诉我，你是罗马公民吗？” 保罗说：“是的。”</span>
<span className="v" id="v28" data-v="28"> 千夫长说：“我花了很多钱才当上罗马公民！” 保罗说：“我生来就是。”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 21:33; 使徒行传 22:24–26; 使徒行传 16:38–39"> 那些准备拷问保罗的士兵立刻退下了。千夫长也害怕起来，因为发现保罗是罗马公民，他却下令捆绑了保罗。</span>
</div>
</div>

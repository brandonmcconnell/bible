## 耶路撒冷会议

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:6; 使徒行传 15:5; 利未记 12:3"> 有几个从犹太下来的人教导弟兄们说：“你们若不照着摩西的规条接受割礼，就不能得救。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 15:22–23; 使徒行传 15:6–7; 加拉太书 2:1–2"> 保罗和巴拿巴为这件事与他们激烈地辩论，最后大家决定派保罗、巴拿巴和几个当地的信徒上耶路撒冷去跟使徒和长老讨论这件事。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 14:27; 使徒行传 21:5; 哥林多前书 16:11"> 于是教会为他们送行。他们经过腓尼基和撒玛利亚，沿途详述外族人悔改信主的消息，使弟兄姊妹大为欢喜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:27; 使徒行传 15:12; 使徒行传 15:3"> 他们到了耶路撒冷，受到教会、使徒和长老的接待，并报告了上帝借他们所做的一切事。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:1–3; 腓立比书 3:5–8; 使徒行传 15:1"> 有几个信了主的法利赛人站起来说：“外族的信徒必须接受割礼，而且还要遵守摩西的律法。”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯来书 13:7; 希伯来书 13:17"> 使徒和长老们聚集商议这个问题。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 10:17–18; 加拉太书 2:7–9; 历代志上 28:4–5"> 经过许多辩论之后，彼得站起来对大家说：“弟兄们，你们都知道，上帝早已在你们当中拣选我去向外族人传道，让他们也可以听到福音并信主。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:24; 使徒行传 10:47; 使徒行传 14:3"> 洞悉人心的上帝把圣灵赐给他们，正如赐给我们一样，以表明祂也接纳外族人。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:6; 加拉太书 5:6; 使徒行传 10:28"> 上帝对他们和我们一视同仁，祂借着他们的信心洁净了他们的心灵。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:1; 马太福音 23:4; 加拉太书 4:9"> 现在你们为什么要试探上帝，把我们祖先和我们不能负的轭强加在这些门徒肩上？</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:24; 提多书 3:4–7; 提多书 2:11"> 我们相信，他们和我们一样都是靠主耶稣的恩典得救。”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 14:27; 使徒行传 15:4; 使徒行传 21:19"> 众人都沉默不语，继续听巴拿巴和保罗诉说上帝借着他们在外族人中所行的神迹奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:17; 加拉太书 2:12; 雅各书 1:1"> 他们报告完了，雅各站起来说：“弟兄们，请听我说。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:1; 使徒行传 15:7–9; 路加福音 2:31–32"> 刚才西门讲述了上帝当初如何眷顾外族人，从他们当中拣选人归在祂的名下。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:8–12; 使徒行传 13:47"> 这完全与众先知的话相符，正如圣经上说，</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 9:11–12; 诗篇 89:35–49; 路加福音 1:31–33"> <span className="pl pl-1">“‘此后，我要回来重建已倾覆的大卫家，</span><br /><span className="pl pl-1">从废墟中重建它、恢复它，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 2:11; 撒迦利亚书 8:20–23; 以赛亚书 65:1"> <span className="pl pl-1">好叫其余的百姓，</span><br /><span className="pl pl-1">就是凡归在我名下的外族人都寻求主。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阿摩司书9:11、12。">a</a></sup>这是主说的，</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:4; 以弗所书 3:9; 以赛亚书 46:9–10"> 祂从亘古就显明了这事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 15:28; 加拉太书 1:7–10; 使徒行传 15:24"> “所以，我认为不应该为难那些信上帝的外族人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:29; 启示录 2:20; 利未记 3:17"> 我们只需写信吩咐他们远避被偶像玷污之物，不可淫乱，不可吃勒死的牲畜和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:15; 使徒行传 13:27; 哥林多后书 3:14–15"> 因为自古以来，在各城都有人宣讲摩西的律法，每逢安息日，都有人在会堂里诵读。”</span>
</div>
</div>

## 给外族信徒的信

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:27; 使徒行传 15:40; 帖撒罗尼迦前书 1:1"> 最后，使徒、长老和全教会都决定从他们当中选派代表，随保罗和巴拿巴去安提阿。他们选了别号巴撒巴的犹大和西拉，这两位都是教会的领袖。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:26; 雅各书 1:1; 加拉太书 1:21"> 他们带去的书信这样说：“安提阿、叙利亚和基利迦的外族弟兄姊妹，你们的弟兄——众使徒和长老向你们问安！</span>
<span className="v" id="v24" data-v="24" data-xref="加拉太书 5:12; 加拉太书 5:10; 使徒行传 15:1"> “听说有几个人从我们这里去了你们那里，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷此处有“教导你们必须接受割礼并遵守摩西的律法。”">b</a></sup>他们的教导使你们困惑不安。其实我们从来没有授权他们这样做。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得后书 3:15; 使徒行传 1:14; 使徒行传 15:2"> 所以我们一致决定选派代表，随我们敬爱的巴拿巴和保罗去你们那里。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:19; 使徒行传 9:23–25; 腓立比书 2:29–30"> 他们二人为我们主耶稣基督的名已将生死置之度外。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 15:22; 使徒行传 15:32; 约翰三书 1:13"> 我们差派犹大和西拉去向你们报告我们的决定。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:13; 启示录 2:24; 马太福音 11:30"> 因为圣灵和我们都认为不应把额外的重担加在你们身上。但请务必注意以下几件事：</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:20; 使徒行传 21:25; 启示录 2:14"> 要远避祭拜偶像的事，不可吃血，不可吃勒死的牲畜，不可淫乱。你们一一遵守这些事才好。祝平安！”</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 16:4; 使徒行传 6:2; 使徒行传 23:33"> 他们奉命下到安提阿，召集众人，交付书信。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:4–5; 腓立比书 3:3; 加拉太书 5:1"> 众人读过这封信之后，都因信中劝勉的话而欢喜。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 11:23; 使徒行传 14:22; 使徒行传 13:1"> 犹大和西拉也是先知，他们讲了许多勉励、坚立弟兄姊妹的话。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 16:11; 使徒行传 16:36; 希伯来书 11:31"> 住了些日子后，安提阿的弟兄姊妹以平安的祝福为他们送行，让他们回耶路撒冷复命。</span>
<span className="v" id="v34" data-v="34"> 但西拉决定留在那里。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷无34节。">c</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 4:2; 歌罗西书 1:28; 使徒行传 13:1"> 保罗和巴拿巴则继续留在安提阿，与许多人一起教导、传扬主的道。</span>
</div>
</div>

## 保罗与巴拿巴分手

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 14:6; 使徒行传 13:4; 使徒行传 13:51"> 过了一些日子，保罗对巴拿巴说：“我们回到曾传过福音的各城镇去探望弟兄姊妹吧，好知道他们的情况。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 13:5"> 巴拿巴想要带约翰·马可同去，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:13; 箴言 25:19; 路加福音 14:27–34"> 但保罗坚持不带他同行，因为他在旁非利亚离开过他们，没有和他们一起做工。</span>
<span className="v" id="v39" data-v="39" data-xref="歌罗西书 4:10; 传道书 7:20; 使徒行传 4:36"> 二人起了激烈的争执，以致分道扬镳。巴拿巴带着约翰·马可一同乘船去塞浦路斯。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 15:22; 使徒行传 14:26; 使徒行传 11:23"> 保罗则选了西拉同行，弟兄姊妹把他们交托在主的恩典中。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 15:23; 加拉太书 1:21; 使徒行传 15:32"> 保罗走遍了叙利亚和基利迦，坚固当地的教会。</span>
</div>

## 邪恶的舌头

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前书 1:7; 彼得前书 5:3"> 我的弟兄姊妹，不要个个当教师，因为你们知道，我们为人师表的将受到更严格的评判。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:26; 箴言 13:3; 彼得前书 3:10"> 因为我们在许多方面难免有过失。如果谁在言语上没有过失，他就是纯全的人，也能在各方面保持自制。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 32:9; 诗篇 39:1; 雅各书 1:26"> 我们如果把嚼环放在马嘴里，便可以驯服它，驾驭它。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 107:25–27; 马太福音 8:24; 使徒行传 27:14–38"> 一艘大船被强风吹袭时，船身虽然庞大，但舵手只要操纵一个小小的舵，就能随意驾驶它。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米书 9:3–8; 箴言 12:18"> 同样，人的舌头虽然很小，却能说夸大的话。<br />看啊，小火星能点燃大森林。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 120:2–3; 箴言 16:27; 马可福音 7:15"> 舌头就是火，是我们身体上的一个充满邪恶的世界，能玷污人的全身，足以烧毁人的一生，它是从地狱点燃的火。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 5:4"> 自然界中的各类走兽、飞禽、爬虫、水族都可以被驯服，也已经被人类驯服了，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:13; 诗篇 140:3; 诗篇 55:21"> 但无人能驯服自己的舌头，因为舌头是个蠢蠢欲动的邪恶之物，充满了致命的毒气。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 10:7; 创世记 1:26–27; 诗篇 62:4"> 我们用舌头来赞美我们的主和天父，也用舌头来咒诅照着上帝的形象被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:14; 彼得前书 3:9; 哥林多前书 3:3"> 赞美和咒诅竟然从同一张嘴里发出来。我的弟兄姊妹，这是不应该的！</span>
<span className="v" id="v11" data-v="11"> 同一个泉源能涌出甜苦两样水吗？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 马太福音 12:33; 马太福音 7:16–20"> 我的弟兄姊妹，无花果树能结出橄榄吗？葡萄树能结出无花果吗？一个咸水泉必流不出甜水来。</span>
</div>
</div>

## 天上的智慧

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 5:23; 雅各书 3:17; 马太福音 5:5"> 你们当中谁是有智慧、有见识的呢？请他带着从智慧而来的谦和在善行上表现出来。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 3:16; 哥林多前书 13:4; 腓立比书 2:3"> 但如果你们心怀苦涩的嫉妒和自私的野心，就不要自夸，也不要违背真理去撒谎。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 雅各书 1:17; 哥林多前书 3:19"> 这种智慧并非来自天上，而是从世俗、私欲和魔鬼来的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 3:14; 哥林多前书 3:3; 哥林多前书 14:33"> 哪里有嫉妒和自私的野心，哪里就会有混乱和各种恶事。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="加拉太书 5:22–23; 箴言 2:6; 哥林多前书 13:4–7"> 但从天上来的智慧首先是纯洁，然后是爱好和平、温良柔顺、充满怜悯、多结善果、不存偏见、没有虚伪。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 5:9; 何西阿书 10:12; 腓立比书 1:11"> 使人和睦的人撒下和平的种子，必收获仁义的果实。</span>
</div>
</div>

</div>

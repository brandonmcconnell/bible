## 信心和忍耐

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:6–8; 雅各书 1:12; 哥林多后书 12:9–10"> 我的弟兄姊妹，当你们遭遇各种试炼的时候，都要认为是喜乐的事。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 5:3–4; 希伯来书 10:36; 歌罗西书 1:11"> 要知道你们的信心经过考验会产生忍耐。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前书 5:10; 马太福音 5:48"> 你们要忍耐到底，使你们纯全、完备、毫无缺欠。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 约翰福音 15:7; 箴言 3:5–7"> 如果你们谁缺少智慧，就当求慷慨施恩、不责备人的上帝，上帝必赐给他智慧。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:21–22; 希伯来书 11:6; 马可福音 11:22–24"> 但他要凭信心毫不疑惑地祈求，因为疑惑的人就像海上随风翻腾的波涛，起伏不定。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 4:3; 以赛亚书 58:3–4; 箴言 21:27"> 这种人别想从主那里得到什么。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 18:21; 马太福音 6:24; 雅各书 4:8"> 他们三心二意，行事为人没有定见。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:23–24; 雅各书 2:5–6; 箴言 19:1"> 卑微的弟兄高升，应当快乐。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:24; 约翰一书 2:17; 约伯记 14:2"> 富有的弟兄降卑，也要快乐，因为他会像花草一样衰残。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 40:7–8; 诗篇 37:35–36; 诗篇 49:6–14"> 骄阳升起，草就干枯，花也凋谢，美丽随之消失。富有的人在忙碌追求中也会如此衰残。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 彼得前书 1:6–8; 启示录 2:10"> 在试炼中能够忍耐到底的人有福了，因为他若经得起考验，就必得到主应许赐给爱祂之人的生命冠冕。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:12–13; 雅各书 1:12; 罗马书 9:19–20"> 当人受到诱惑时，不可说：“是上帝在诱惑我。”因为上帝不受邪恶的诱惑，也不诱惑人。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 7:21–22; 以弗所书 4:22; 马太福音 15:18"> 其实每个受到诱惑的人都是受自己的私欲怂恿和诱惑。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14; 约伯记 15:35; 罗马书 5:12–21"> 私欲怀了胎，便生出罪，罪一旦长成，便带来死亡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:7; 雅各书 1:19; 腓立比书 2:12"> 我亲爱的弟兄姊妹，不要上当受骗。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 3:27; 马太福音 7:11; 希伯来书 13:8"> 一切良善的施予和完美的恩赐都是从天上，从众光之父那里来的。祂不像转动的影子变幻无常。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:29–31; 彼得前书 1:23; 约翰福音 3:3–5"> 祂按照自己的旨意，借着真道重生了我们，使我们在祂所造的万物中作初熟的果实。</span>
</div>
</div>

## 听道与行道

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 我亲爱的弟兄姊妹，请记住：每个人都要快快地听，慢慢地说，慢慢地动怒。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 2:24–25; 以弗所书 4:26; 雅各书 3:17–18"> 因为人的愤怒不能成就上帝的公义。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:22; 以弗所书 1:13; 彼得前书 2:11"> 所以你们要除去一切污秽和恶习，谦卑地领受那已经栽种在你们心里、能救你们灵魂的真道。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 2:13; 路加福音 6:46–48; 约翰福音 13:17"> 你们要行道，不要只是听道，自己欺骗自己。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:26–27; 以西结书 33:31–32; 雅各书 2:14–26"> 因为人听道而不行道，就像照镜子一样，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得后书 3:11; 路加福音 1:66; 路加福音 7:39"> 照过后就走了，随即忘记了自己的容貌。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 约翰福音 13:17; 哥林多后书 3:17–18"> 但详细查考那带来自由的全备律法并持之以恒的人，不是听了就忘，而是身体力行，这样的人必在他所行的事上蒙福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; 诗篇 141:3; 彼得前书 3:10"> 如果有人自以为虔诚，却不勒住自己的舌头，就是在自己欺骗自己，他的所谓虔诚也毫无价值。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:16–17; 约翰一书 3:17–19; 加拉太书 6:9–10"> 在父上帝看来，纯洁无瑕的虔诚是指照顾患难中的孤儿寡妇，并且不让自己被世俗玷污。</span>
</div>
</div>

## 不要与世俗为友

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:11; 加拉太书 5:17; 罗马书 7:23"> 你们彼此反目、互相争斗的起因是什么呢？不就是你们身体中不断交战的欲望吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 16:24; 马太福音 7:7–8; 雅各书 1:5"> 你们贪心，得不到就去杀人。你们嫉妒，得不到就互相争斗、彼此反目。你们得不到是因为你们不向上帝祈求。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:14; 约翰一书 3:22; 雅各书 1:6–7"> 你们求也得不到是因为你们动机不纯，只为满足自己的欲望。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:15–16; 罗马书 8:7; 约翰福音 15:19"> 你们这些对主不忠的人啊，难道还不明白与世俗为友就是与上帝为敌吗？所以，凡是与世俗为友的，都是上帝的敌人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:16; 哥林多前书 6:19; 民数记 11:29"> 圣经上说：“上帝所赐、住在我们心里的圣灵深愿我们完全属于祂。”你们以为这是空谈吗？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 23:12; 箴言 3:34; 彼得前书 5:5"> 但上帝赐给我们更大的恩典，所以圣经上说：“上帝阻挡骄傲的人，恩待谦卑的人。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="箴言3:34。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="彼得前书 5:8–9; 以弗所书 4:27; 以弗所书 6:11–12"> 因此，你们要服从上帝。要抵挡魔鬼，魔鬼必逃离你们。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:18; 希伯来书 10:22; 玛拉基书 3:7"> 你们亲近上帝，上帝就必亲近你们。有罪的人啊，洗净你们的手吧！三心二意的人啊，洁净你们的心吧！</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 7:10–11; 马太福音 5:4; 路加福音 6:25"> 你们要悲伤、忧愁、痛哭，转欢笑为悲哀，变欢乐为愁苦。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 147:6; 马太福音 23:12; 彼得前书 5:6"> 你们要在主面前谦卑，祂必提升你们。</span>
</div>
</div>

## 不要论断

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="彼得前书 2:1; 罗马书 2:1; 雅各书 5:9"> 弟兄姊妹，不要彼此抨击。抨击或论断弟兄姊妹就是抨击或论断律法。如果你论断律法，你就不是遵行律法的人，而是以审判者自居。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:4; 罗马书 2:1; 马太福音 10:28"> 设立律法和审判人的只有一位，就是能拯救人也能毁灭人的上帝。你是谁，竟然论断邻舍呢？</span>
</div>
</div>

## 警戒自夸

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 27:1; 路加福音 12:17–20; 创世记 11:3–4"> 你们有些人说：“今天或是明天，我们要往某某城去，在那里逗留一年半载，做生意赚钱。”</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 1:24; 诗篇 39:5; 约翰一书 2:17"> 其实你们根本不知道明天会发生什么事。你们的生命是什么呢？你们只不过像一阵雾气，出现片刻，就无影无踪了。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:21; 希伯来书 6:3; 耶利米哀歌 3:37"> 你们应当说：“如果主许可，我们就可以活着，可以做这事或做那事。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:1; 哥林多前书 5:6; 诗篇 52:7"> 现在，你们竟敢傲慢自夸，这实属邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:41; 约翰福音 13:17; 约翰福音 15:22"> 所以人若知道善而不去行，就是犯罪。</span>
</div>
</div>

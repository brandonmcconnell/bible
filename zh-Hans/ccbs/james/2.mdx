## 不可以貌取人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各书 2:9; 利未记 19:15"> 我的弟兄姊妹，你们既然信了我们荣耀的主耶稣基督，就不可以貌取人。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖记 3:10; 以斯帖记 8:2"> 比方说，一个手戴金饰、衣着华丽的人来参加你们的聚会，一个衣衫褴褛的人也来参加，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:9; 雅各书 2:6; 路加福音 7:44–46"> 你们就看重那衣着华丽的，对他说：“请上座。”却对那穷人说：“你站在那边。”或“坐在我的脚凳边。”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:24; 约伯记 34:19; 马太福音 7:1–5"> 你们这样做难道不是偏心待人，心怀恶意地判断人吗？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 5:3; 路加福音 6:20; 启示录 2:9"> 我亲爱的弟兄姊妹，请听我说，上帝不是拣选了世上的穷人，使他们在信心上富足，并承受祂应许赐给那些爱祂之人的国度吗？</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前书 11:22; 箴言 14:31"> 你们反倒侮辱穷人。难道欺压你们、抓你们上法庭的不是那些有钱人吗？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:9–11; 启示录 13:5–6; 提摩太前书 1:13"> 不正是他们亵渎你们所敬奉的尊名吗？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 19:18; 加拉太书 5:14; 马太福音 22:39"> 你们如果能切实行出圣经中“要爱邻如己”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利未记19:18。">a</a></sup>这条至尊的律法，就对了。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 19:15; 雅各书 2:1–4; 约翰一书 3:4"> 你们如果以貌取人，便是犯罪，被律法定为违法者。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 3:10; 马太福音 5:18–19; 申命记 27:26"> 人遵守律法，就要全部遵守，他只要触犯律法中的一条，就等于干犯了全部，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:13–14; 马太福音 5:21–28; 申命记 5:17–18"> 因为那位说“不可通奸”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及记20:14；申命记5:18。">b</a></sup>的，也说过“不可杀人”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及记20:13；申命记5:17。">c</a></sup>。如果你没有犯通奸罪，却杀了人，你仍违背了律法。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:25; 雅各书 2:8; 彼得后书 1:4–8"> 既然你们要按使人自由的律法受审判，就应该按律法行事为人。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:7; 马太福音 6:15; 箴言 21:13"> 因为不怜悯人的会受到无情的审判，但怜悯胜过审判。</span>
</div>
</div>

## 信心和行为

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:26–27; 马太福音 7:21–23; 雅各书 1:22–25"> 我的弟兄姊妹，如果有人自称有信心，却没有行为，有什么用呢？这种信心能够救他吗？</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 马太福音 25:35–40; 以赛亚书 58:7"> 如果有弟兄姊妹缺衣少食，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 约翰一书 3:16–18; 马太福音 25:42–45"> 你们只是对他们说：“安心走吧，愿你们穿得暖，吃得饱”，却不帮助他们解决实际困难，这有什么用呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 2:26; 彼得后书 1:5–9; 雅各书 2:19–20"> 因此，信心若没有行为，就是死的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:13; 雅各书 2:14; 加拉太书 5:6"> 必有人说：“你有信心，我有行为。”请把你没有行为的信心指给我看，我就用行为把我的信心显给你看。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 马可福音 1:24; 马太福音 8:29"> 你相信上帝只有一位，你信得没错，鬼魔也相信，而且恐惧颤抖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:17; 雅各书 2:26; 箴言 12:11"> 愚蠢的人啊，你们不知道没有行为的信心毫无用处吗？</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 22:16–18; 创世记 22:9–12; 约翰福音 8:39"> 我们的祖先亚伯拉罕把儿子以撒献在祭坛上的时候，难道不是因行为被称为义人吗？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 1:3; 希伯来书 11:17–19; 加拉太书 5:6"> 可见他的信心和行为相称，而且信心要有行为才是完全的。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:6; 以赛亚书 41:8; 历代志下 20:7"> 这正应验了圣经的记载：“亚伯拉罕信上帝，就被算为义人”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="创世记15:6。">d</a></sup>，并且被称为“上帝的朋友”。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 2:21–22; 雅各书 2:15–18; 诗篇 60:12"> 可见人被称为义人是因行为，并非单因信心。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 约书亚记 6:22–25; 约书亚记 2:19–21"> 还有妓女喇合，她收留使者，把他们藏在家里，又送他们从别的路逃生，不也是因行为被称为义人吗？</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:20; 雅各书 2:17; 雅各书 2:14"> 身体没有灵魂是死的，同样，信心没有行为也是死的。</span>
</div>
</div>

## 撒母耳膏立大卫做王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 9:1; 撒母耳记上 15:23; 诗篇 78:68–71"> 耶和华对撒母耳说：“我已经拒绝让扫罗做以色列王了，你还要为他哀伤多久呢？把你的角盛满膏油，我要差遣你到伯利恒的耶西那里，我已选了他的一个儿子做王。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:12; 撒母耳记上 20:29; 马太福音 10:16"> 撒母耳说：“我怎么可以去呢？扫罗知道了，一定会杀掉我。”耶和华说：“你带一头牛犊去，就说，‘我是来向耶和华献祭的。’</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 9:16; 撒母耳记上 16:12–13; 撒母耳记下 15:11"> 你要请耶西参加献祭，我会告诉你怎么做，我把谁指示给你，你就要为我膏立谁。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13; 历代志上 12:17–18; 撒母耳记上 21:1"> 撒母耳遵行耶和华的吩咐，他来到伯利恒，那城的长老都战战兢兢地出来迎接他，问道：“你是为平安而来吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 3:5; 利未记 20:7–8; 出埃及记 19:10"> 撒母耳答道：“是的，为平安而来，我是来向耶和华献祭的。你们要洁净自己，然后来和我一起献祭。”撒母耳为耶西及其众子行过洁净礼后，便邀请他们参加献祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:13; 历代志上 2:13; 撒母耳记上 17:22"> 耶西及其众子来了，撒母耳看见以利押，心里想：“这位肯定是耶和华要膏立的人。”</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:24; 耶利米书 17:10; 路加福音 16:15"> 但耶和华对撒母耳说：“不要看他相貌堂堂、身材高大，我要选的不是他。耶和华不像世人那样看人，人看外表，耶和华看内心。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:13; 历代志上 2:13"> 耶西吩咐他的儿子亚比拿达从撒母耳面前走过，但撒母耳说：“这也不是耶和华拣选的人。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 17:13; 历代志上 2:13; 撒母耳记下 13:3"> 耶西又叫沙玛从撒母耳面前走过，但撒母耳说：“这也不是耶和华拣选的人。”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 2:13–15"> 耶西叫七个儿子一个一个从撒母耳面前走过，但撒母耳说他们都不是耶和华拣选的人。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:70–71; 撒母耳记下 7:8; 撒母耳记下 13:3"> 撒母耳问耶西：“你的儿子全都到齐了吗？”耶西答道：“还有一个最小的，他正在田间放羊。”撒母耳对耶西说：“派人叫他回来，他不来，我们就不入座。”</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米哀歌 4:7; 诗篇 89:19–20; 雅歌 5:10"> 耶西就派人去叫他回来。他面色红润，眉清目秀，相貌英俊。耶和华说：“就是他，起来膏立他吧。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:6; 希伯来书 1:9; 约翰福音 3:34"> 撒母耳就拿出盛膏油的角，当着他哥哥们的面膏立他。从那天起，耶和华的灵突然降在大卫身上。事后，撒母耳回拉玛去了。</span>
</div>
</div>

## 大卫服侍扫罗

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 51:11; 撒母耳记上 18:12; 士师记 9:23"> 耶和华的灵离开了扫罗，有个邪灵从耶和华那里来折磨他。</span>
<span className="v" id="v15" data-v="15"> 扫罗的臣仆对他说：“现在有个邪灵从上帝那里来折磨你，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 3:15; 列王纪上 10:8; 撒母耳记上 19:9"> 你<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“你”希伯来文是“我们的主”。">a</a></sup>可以吩咐跟前的臣仆去找一个善于弹琴的人来。邪灵从上帝那里来到你身上的时候，他为你弹琴，你就舒畅了。”</span>
<span className="v" id="v17" data-v="17"> 扫罗说：“你们就为我找一个善于弹琴的人，带他到我这里来。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:19; 创世记 39:23; 创世记 39:2"> 其中有一个仆人说：“我见过伯利恒的耶西的一个儿子，他善于弹琴，英勇善战，谈吐合宜，相貌英俊，并且耶和华与他同在。”</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 16:11; 撒母耳记上 17:15; 诗篇 78:70–72"> 扫罗便差遣使者去见耶西，说：“请让你放羊的儿子大卫到我这里来。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:27; 箴言 18:16; 撒母耳记上 17:18"> 耶西就把一些饼、一皮袋酒和一只山羊羔驮在驴背上，让儿子大卫带去送给扫罗。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:46; 箴言 22:29; 诗篇 146:3"> 大卫到了扫罗那里，做了他身边的侍臣。扫罗非常喜欢大卫，让大卫为他拿兵器。</span>
<span className="v" id="v22" data-v="22"> 扫罗派人去见耶西，说：“你就让大卫留在我的身边吧，因为我喜欢他。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 16:14–16; 撒母耳记上 18:10–11; 路加福音 11:24–26"> 每当有邪灵从上帝那里来到扫罗身上的时候，大卫就为他弹琴，扫罗便觉得舒畅，邪灵也离开了他。</span>
</div>
</div>

## 主呼召撒母耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 8:11–12; 诗篇 74:9; 撒母耳记上 3:21"> 小撒母耳跟着以利事奉耶和华。那时候，耶和华的话语稀少，异象也不多。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:15; 诗篇 90:10; 创世记 27:1"> 一天晚上，老眼昏花的以利正睡在自己的房里。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 27:4; 利未记 24:2–4; 出埃及记 27:20–21"> 上帝的灯还没有熄灭，撒母耳睡在耶和华的殿内，那里有上帝的约柜。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 6:8; 哥林多前书 12:6–11; 出埃及记 3:4"> 耶和华呼唤撒母耳，撒母耳答道：“我在这里！”</span>
<span className="v" id="v5" data-v="5"> 他跑到以利跟前，说：“我来了，你叫我吗？”以利说：“我没有叫你，你去睡吧。”于是，他就回去睡觉。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:2; 撒母耳记上 4:16; 撒母耳记下 18:22"> 耶和华又呼唤撒母耳，撒母耳起来到以利跟前，说：“我来了，你叫我吗？”以利答道：“孩子，我没有叫你，回去睡吧。”</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:2; 耶利米书 9:24"> 那时，撒母耳还不认识耶和华，耶和华的话还没有向他显明。</span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 33:14–15; 哥林多前书 13:11–12"> 耶和华第三次呼唤他，撒母耳起来，到以利面前，说：“我来了，你叫我吗？”这时候，以利才明白原来是耶和华在呼唤这孩子。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:19; 以赛亚书 6:8; 诗篇 85:8"> 他就吩咐撒母耳说：“你回去睡吧，要是再呼唤你，你就说，‘耶和华啊，请吩咐，仆人恭听。’”于是，撒母耳就回去睡下。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 3:8; 撒母耳记上 3:4–6"> 耶和华来站在那里，再次像刚才一样呼唤：“撒母耳！撒母耳！”撒母耳答道：“请吩咐，仆人恭听。”</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷书 1:5; 耶利米书 19:3; 列王纪下 21:12"> 耶和华对撒母耳说：“我要在以色列做一件令人震惊的事。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:27–36; 撒迦利亚书 1:6; 约书亚记 23:15"> 到时候，我要应验我说的有关以利家的一切预言。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; 马太福音 10:37; 撒母耳记上 2:12"> 我对以利说过我要永远惩罚他家，因为他知道自己的儿子亵渎我，却没有约束他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 22:14; 撒母耳记上 2:25; 耶利米书 15:1"> 所以，我向以利家起誓说，‘靠祭物或礼物绝不能赎去以利家的罪恶。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:6–8; 玛拉基书 1:10; 撒母耳记上 1:9"> 撒母耳在床上躺到天亮，然后起来打开耶和华的殿门。他不敢把异象告诉以利。</span>
<span className="v" id="v16" data-v="16"> 以利叫他：“撒母耳，我的孩子。”撒母耳答道：“我在这里。”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 路得记 1:17; 诗篇 141:5"> 以利说：“耶和华对你说了什么？你不要向我隐瞒。如果你隐瞒一句，愿上帝重重地惩罚你。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约伯记 2:10; 以赛亚书 39:8; 士师记 10:15"> 撒母耳就一五一十地告诉了他。以利说：“祂是耶和华，祂看怎样好，就怎样行吧。”</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 39:2; 撒母耳记上 9:6; 列王纪上 8:56"> 撒母耳渐渐长大，耶和华与他同在，使他所说的话没有一句落空。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 20:1; 撒母耳记下 3:10; 提摩太前书 1:12"> 从但到别示巴，全以色列的人都知道撒母耳被立为耶和华的先知。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 3:1; 创世记 12:7; 撒母耳记上 3:4"> 耶和华继续在示罗显现，用自己的话启示撒母耳。</span>
</div>
</div>

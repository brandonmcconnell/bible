## 大卫与约拿单

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 2:9; 哥林多后书 1:12; 约翰一书 3:21"> 大卫从拉玛的拿约逃出来去见约拿单，问他：“我做了什么？犯了什么罪？我什么地方对不起你父亲，他竟追杀我？”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:15; 约翰福音 17:8; 约翰福音 15:15"> 约拿单答道：“绝无此事，你不会死的！我父亲事无大小都会告诉我的，他不会瞒着我这件事，不会的。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 25:26; 申命记 6:13; 列王纪下 2:6"> 大卫发誓说：“你父亲深知你恩待我，他为了不使你伤心，才瞒着你。但我凭永活的耶和华和你的性命起誓，我离死亡仅一步之遥！”</span>
<span className="v" id="v4" data-v="4"> 约拿单说：“你有什么需要？我一定相助。”</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 10:10; 撒母耳记上 19:2; 民数记 28:11"> 大卫答道：“明天是初一，我本该跟王一起用餐，请让我躲到田间，直到第三天晚上。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:58; 撒母耳记上 9:12; 申命记 12:5"> 如果你父亲问起我，你就说我恳求你允许我回到故乡伯利恒，因为我全家正在那里献年祭。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:17; 以斯帖记 7:7; 申命记 1:23"> 如果你父亲说‘好吧’，仆人就平安无事了。如果他发怒，就表示他决意要杀我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 14:32; 撒母耳记上 18:3; 撒母耳记上 23:18"> 请你善待仆人，因你与我在耶和华面前立了盟约。如果我有罪，就请你亲手杀了我，何必把我交给你父亲呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 20:42; 撒母耳记上 19:2; 撒母耳记上 20:38"> 约拿单答道：“我决不会这样做。我如果知道父亲决意要杀你，怎能不通知你呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 25:14; 撒母耳记上 25:17; 创世记 42:30"> 大卫说：“你父亲如果向你发怒，谁来告诉我呢？”</span>
<span className="v" id="v11" data-v="11"> 约拿单说：“我们一起到田野去吧。”于是，二人一起去了田野。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 22:22; 约伯记 31:4; 箴言 25:2–3"> 约拿单对大卫说：“愿以色列的上帝耶和华作证，明天或后天这个时侯我就会打探到我父亲的意思，如果他善意待你，我会派人通知你。</span>
<span className="v" id="v13" data-v="13" data-xref="路得记 1:17; 历代志上 22:11; 约书亚记 1:5"> 如果他有意杀你，而我却不告诉你让你安然逃走，愿耶和华重重地惩罚我。愿耶和华与你同在，像从前与我父亲同在一样。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 9:3; 以弗所书 5:1–2"> 在我有生之年，请你照耶和华的慈爱恩待我，免我一死。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:7; 撒母耳记上 24:21; 撒母耳记下 9:1–7"> 在我死后，即使耶和华把你所有的仇敌都毁灭了，请你仍旧恩待我的后人。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:22; 撒母耳记上 18:3; 撒母耳记下 21:8"> 于是，约拿单与大卫家立下盟约，说：“如果大卫不守盟约，愿耶和华借着仇敌惩罚他。”</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 撒母耳记上 18:1; 撒母耳记上 18:3"> 约拿单因为像爱自己一样爱大卫，便叫他再次起誓。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 20:25; 撒母耳记上 20:5"> 约拿单说：“明天是初一，人们会注意到你缺席。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:2; 撒母耳记上 20:5"> 到了后天，你要赶快去上次出事时躲藏的以色磐石那里。</span>
<span className="v" id="v20" data-v="20"> 我会朝磐石的旁边射三箭，好像射靶子。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 5:2; 阿摩司书 8:14; 耶利米书 12:16"> 然后，我会叫一个少年把箭拾回来。如果你听到我对他说，‘箭就在你旁边，把箭拾回来。’那就表示你可以回来了，我凭永活的耶和华起誓，你必平安无事。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 20:37"> 但如果我对少年说，‘箭就在你前面。’你就要离开，因为是耶和华要你离开。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:14–15; 撒母耳记上 20:42; 创世记 31:50"> 至于我们之间所立的约，耶和华永远为我们作证。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; 以赛亚书 1:11–15; 箴言 21:3"> 于是，大卫就躲到田野。初一到了，扫罗王入席吃饭，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 20:18; 士师记 16:20"> 他照常坐在靠墙的位置，约拿单坐在对面，押尼珥坐在王的身边，大卫的位子空着。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 15:5; 利未记 11:24; 利未记 11:27"> 那一天，扫罗并没有说什么，他以为大卫可能遇到了使自己不洁净的事，不能赴宴。</span>
<span className="v" id="v27" data-v="27" data-xref="彼得前书 2:4; 撒母耳记上 19:15; 撒母耳记上 18:11"> 可是到了第二天，就是初二，大卫的座位还是空的，扫罗就问儿子约拿单：“耶西的儿子为什么这两天都不来赴宴呢？”</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 20:6"> 约拿单答道：“大卫恳求我让他回到伯利恒，</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 17:28"> 因为他家要在城中献祭，他的哥哥要他去。他求我恩准他去见他的哥哥们。所以，他没有来参加王的宴席。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; 雅各书 1:19–20; 箴言 25:28"> 扫罗向约拿单发怒，对他说：“你这邪逆妇人养的！难道我不知道你是站在耶西的儿子那边吗？你这样做不但自取其辱，也使你母亲蒙羞。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 19:6; 撒母耳记上 20:8; 撒母耳记上 19:11–15"> 只要耶西的儿子活在世上，你和你的王位就不得安稳。你派人把他抓到我这里，他非死不可。”</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:23; 撒母耳记上 19:5; 路加福音 23:22"> 约拿单问：“为什么要杀他？他做了什么？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 20:7; 撒母耳记上 18:11; 撒母耳记上 19:10"> 扫罗气得把矛掷向约拿单，想要杀他。约拿单知道父亲决意要杀大卫。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所书 4:26; 马可福音 3:5; 传道书 7:20"> 他怒气冲冲地离席，整天不肯进食，因为他看见父亲如此卑劣地对待大卫，心里非常难过。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 20:5; 撒母耳记上 20:19"> 第二天早晨，约拿单按照和大卫的约定带着一个少年来到田野。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 20:20–22"> 约拿单对少年说：“你跑去把我射的箭拾回来。”少年就向前跑去，约拿单把箭射在他前面。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:22"> 少年跑到落箭之处的时候，约拿单就大声叫道：“箭不是在你前面吗？</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 55:6–9; 箴言 6:4–5; 马可福音 13:14–16"> 快快去，不要耽延。”少年连忙把箭拾起来，回到主人那里。</span>
<span className="v" id="v39" data-v="39"> 他不知道主人的用意，只有约拿单和大卫知道。</span>
<span className="v" id="v40" data-v="40"> 约拿单把弓箭交给那少年，吩咐他带回城中。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 29:11; 撒母耳记上 18:3; 撒母耳记下 9:6"> 少年离开以后，大卫就从磐石南面出来，伏地拜了三拜。二人彼此亲吻，抱头痛哭，大卫更是泣不成声。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 1:17; 撒母耳记上 23:18; 撒母耳记上 20:22–23"> 约拿单说：“我们已凭耶和华的名起誓，有耶和华在你我和你我的子孙之间永远为我们的盟约作证，你就安心去吧。”大卫便起身离开，约拿单也回城去了。</span>
</div>

## 撒母耳的临别警戒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 10:24; 撒母耳记上 11:14–15; 撒母耳记上 10:1"> 撒母耳对以色列人说：“看啊，我已照你们的要求为你们立了一个王。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:5; 撒母耳记上 8:1; 撒母耳记上 8:20"> 你们已经有君王了。我自幼带领你们，现在已年老发白，我的儿子也都在你们这里。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:33; 民数记 16:15; 彼得前书 5:2"> 如今我站在这里，你们只管在耶和华和祂膏立的王面前为我作证，我夺过谁的牛？抢过谁的驴？欺骗过谁？压迫过谁？收过谁的贿赂而徇私枉法？如果有的话，我一定偿还。”</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 6:4; 诗篇 37:5–6; 约翰三书 1:12"> 他们答道：“你没有欺骗、压迫过我们，也没有拿过任何人的东西。”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:4; 使徒行传 24:20; 使徒行传 23:9"> 撒母耳对他们说：“耶和华和祂所膏立的王今天为我作证，我没有拿过你们任何人的东西。”他们说：“是的，耶和华为证。”</span>
<span className="v" id="v6" data-v="6" data-xref="弥迦书 6:4; 出埃及记 6:26; 诗篇 99:6"> 撒母耳继续说：“是耶和华派摩西和亚伦带领你们的祖先离开埃及。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:18; 弥迦书 6:1–5; 使徒行传 17:3"> 现在，你们都要站在耶和华面前，让我来提醒你们有关耶和华为你们和你们祖先所行的一切公义之事。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:14–16; 出埃及记 2:23–24; 诗篇 78:54–55"> 从前，雅各曾迁到埃及，你们的祖先受到埃及人的压迫，向耶和华呼求，耶和华就差遣摩西和亚伦带他们出埃及，到这里居住。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:1; 士师记 10:7; 士师记 3:12"> 他们却忘记了他们的上帝耶和华，于是耶和华让他们落入夏琐的将军西西拉、非利士人和摩押王的手中，这些人便攻击他们。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 10:10; 士师记 2:13; 士师记 3:7"> 他们就向耶和华呼求，‘耶和华啊，我们犯了罪，我们背弃了你去供奉巴力和亚斯她录，现在求你从仇敌手中救我们，我们必事奉你。’</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 6:32; 士师记 4:6; 士师记 8:35"> 耶和华就派耶路·巴力、比但、耶弗他和撒母耳<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“耶路·巴力、比但、耶弗他和撒母耳”有古卷作“基甸、巴拉、耶弗他和参孙”。">a</a></sup>从周围的敌人手中救你们，使你们安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 8:23; 撒母耳记上 8:5–7; 创世记 17:7"> 可是你们看到亚扪王拿辖来攻击你们，就对我说，‘不行，我们要有一个王来统治我们。’其实你们的上帝耶和华就是你们的王。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 13:11; 撒母耳记上 10:24; 撒母耳记上 8:5"> 现在，你们所求所选的王在这里，耶和华为你们立了一位王。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 24:14; 申命记 28:1–14; 诗篇 81:12–15"> 如果你们敬畏耶和华，事奉祂，听从祂的吩咐，不违背祂的命令，你们和统治你们的王都愿意跟从祂，一切都会顺利。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 24:20; 以赛亚书 1:20; 以赛亚书 3:11"> 如果你们不听从耶和华的话，违背祂的命令，祂就会像从前惩罚你们的祖先一样出手惩罚你们。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:13; 出埃及记 14:31; 撒母耳记上 12:7"> 现在你们站着留心看，耶和华就要在你们面前行一件大事。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 8:7; 箴言 26:1; 撒母耳记上 7:9–10"> 你们都知道收割麦子的时候不会下雨。现在，我要向耶和华祷告，求祂打雷降雨，好让你们知道，你们要求立王在耶和华眼中是多么大的罪。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:31; 以斯拉记 10:9; 诗篇 106:12–13"> 于是，撒母耳向耶和华呼求，耶和华便在当天打雷降雨，民众非常害怕耶和华和撒母耳。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 9:28; 约翰一书 5:16; 撒母耳记上 12:23"> 他们求撒母耳，说：“求你为仆人们向你的上帝耶和华祈祷，免得我们死亡！因为我们要求立王是罪上加罪。”</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 11:16; 约书亚记 23:6; 彼得前书 3:16"> 撒母耳说：“不要害怕，你们虽然做了这恶事，但不可离开耶和华，要全心全意地事奉祂。</span>
<span className="v" id="v21" data-v="21" data-xref="哈巴谷书 2:18; 耶利米书 10:15; 耶利米书 16:19"> 不要去追求其他虚无的假神，它们对你们毫无益处，也不能拯救你们。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:7–8; 申命记 14:2; 诗篇 106:8"> 耶和华不会丢弃祂的子民，使自己的大名受损，祂乐意使你们做祂的子民。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:9; 罗马书 1:9; 提摩太后书 1:3"> 至于我，我会不断地为你们祈祷，免得我得罪耶和华。我会教导你们行善道、走正路。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 10:21; 箴言 1:7; 以赛亚书 5:12"> 你们要单单敬畏耶和华，全心全意地事奉祂，想想祂为你们做了何等伟大的事。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:20; 何西阿书 10:3; 撒母耳记上 31:1–5"> 可是，如果你们仍然继续行恶，你们和你们的王都必灭亡。”</span>

## 扫罗试图杀大卫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 18:1; 撒母耳记上 18:9"> 扫罗吩咐他儿子约拿单和众臣仆去杀掉大卫。但约拿单非常喜爱大卫，</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 17:17; 使徒行传 9:24; 撒母耳记上 18:1–3"> 便告诉他，说：“我父亲要杀你，明天早上你要小心，找个僻静的地方躲起来。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 20:9; 撒母耳记上 20:13"> 我会出去和父亲站在你藏身的田间，跟他提你的事，然后把消息告诉你。”</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 18:20; 箴言 31:8–9; 创世记 42:22"> 约拿单就在父亲面前替大卫说好话，他说：“王不要伤害大卫，他从来没有对不起王，他所做的使王大受益处。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 11:13; 历代志上 11:14; 士师记 9:17"> 他冒着生命危险去杀非利士人，耶和华使以色列人大获全胜，当时你看见了，非常欢喜，现在为什么要犯罪，枉杀无辜的大卫呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 26:24–25; 耶利米书 5:2; 诗篇 15:4"> 扫罗听了约拿单的话，就凭永活的耶和华起誓说：“我不杀大卫。”</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 18:2; 撒母耳记上 16:21; 撒母耳记上 18:13"> 约拿单叫来大卫，把经过告诉他，带他去见扫罗，大卫又像以前一样伺候扫罗。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 27:3; 诗篇 18:32–50"> 后来，战事再度爆发，大卫领兵与非利士人交战，大败敌人，杀得他们四散溃逃。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 16:14; 撒母耳记上 18:10–11; 撒母耳记上 16:16"> 一天，扫罗手里拿着矛正坐在家中，从耶和华那里来的邪灵降临在扫罗身上。大卫正在弹琴，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 20:33; 撒母耳记上 18:11; 箴言 21:30"> 扫罗想用矛把大卫刺透，钉在墙上，大卫躲开了，矛插在了墙上。大卫当晚逃走了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 59:1–17; 士师记 16:2"> 扫罗派人去监视大卫的家，要在早上杀死他。大卫的妻子米甲警告他说：“你如果今晚不逃命，明早必死无疑。”</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 2:15; 使徒行传 9:24–25; 诗篇 34:19"> 于是，她从窗口把大卫缒下去，让他逃走了。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 31:19; 士师记 18:17; 士师记 18:14"> 然后她把家中的神像放在床上，头枕在山羊毛的枕头上，盖上衣服。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 2:5; 撒母耳记下 16:17–19; 撒母耳记下 17:20"> 扫罗派人来捉拿大卫的时候，米甲说他病了。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 27:3–4; 诗篇 37:12; 约伯记 31:31"> 扫罗又派人去见大卫，并吩咐说：“把他连床一起抬来，我好杀他。”</span>
<span className="v" id="v16" data-v="16"> 众人进去发现躺在床上的是一个神像，头枕在山羊毛的枕头上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 2:22; 撒母耳记上 22:17; 出埃及记 1:17–19"> 扫罗问米甲：“你为什么欺骗我，让我的敌人逃走？”米甲答道：“他说如果我不让他逃走，就杀了我。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 7:17; 诗篇 116:11; 撒母耳记上 15:34"> 大卫逃到住在拉玛的撒母耳那里，把扫罗的所作所为告诉他。后来，他和撒母耳去拿约住了下来。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 23:19; 撒母耳记上 22:9–10; 撒母耳记上 26:1"> 扫罗听说大卫在拉玛的拿约，</span>
<span className="v" id="v20" data-v="20" data-xref="约珥书 2:28; 约翰福音 7:32; 撒母耳记上 10:5–6"> 就派人去捉拿他。扫罗的人看到一群先知在说预言，撒母耳在当中带领他们。上帝的灵也临到扫罗的人，他们也说起预言来。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 27:22; 耶利米书 13:23; 约珥书 2:28"> 扫罗听说后又派人去，派去的人也说起预言来。扫罗第三次派人去，派去的人同样说起预言来。</span>
<span className="v" id="v22" data-v="22"> 最后扫罗亲自前往拉玛，走到西沽的大井，问撒母耳和大卫在哪里，有人说在拉玛的拿约。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 撒母耳记上 10:10; 撒母耳记上 19:20"> 扫罗便去拉玛的拿约。上帝的灵临到扫罗，他就一边走一边说起预言来，一直到拉玛的拿约。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 6:20; 以赛亚书 20:2; 弥迦书 1:8"> 他脱下自己的衣服，在撒母耳面前说起预言来。他赤身躺了一天一夜。因此有句俗语说：“扫罗也在先知当中吗？”</span>
</div>

## 哈娜的祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 诗篇 13:5; 以赛亚书 12:2–3"> 哈娜祷告说：<br /><span className="pl pl-1">“我的心因耶和华而欢喜，</span><br /><span className="pl pl-1">我的角因耶和华而高举，</span><br /><span className="pl pl-1">我的口向敌人夸耀，</span><br /><span className="pl pl-1">我因耶和华的拯救而快乐。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 22:32; 以赛亚书 44:6; 诗篇 86:8"> <span className="pl pl-1">“耶和华圣洁无比，</span><br /><span className="pl pl-1">独一无二，</span><br /><span className="pl pl-1">没有磐石像我们的上帝。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王纪上 8:39; 箴言 24:12"> <span className="pl pl-1">不要再骄横傲慢、口出狂言，</span><br /><span className="pl pl-1">因为耶和华是无所不知的上帝，</span><br /><span className="pl pl-1">祂衡量人的一切行为。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:3; 诗篇 37:15; 诗篇 46:9"> <span className="pl pl-1">勇士的弓被折断，</span><br /><span className="pl pl-1">软弱的却有力量。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 15:9; 路加福音 1:53; 诗篇 113:9"> <span className="pl pl-1">素来丰衣足食的为糊口而当雇工，</span><br /><span className="pl pl-1">本来食不果腹的却不再挨饿。</span><br /><span className="pl pl-1">不育的妇人现在生了七个孩子，</span><br /><span className="pl pl-1">儿女成群的妇人却孤独憔悴。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 32:39; 以赛亚书 26:19; 启示录 1:18"> <span className="pl pl-1">耶和华掌管生死，</span><br /><span className="pl pl-1">祂使人下到阴间，也使人起死回生。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 75:7; 约伯记 5:11; 申命记 8:17–18"> <span className="pl pl-1">贫穷富足在于祂，</span><br /><span className="pl pl-1">卑微高贵也在于祂。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 113:7–8; 但以理书 2:48; 雅各书 2:5"> <span className="pl pl-1">祂从灰尘中提拔穷苦的人，</span><br /><span className="pl pl-1">从粪堆里提升贫贱的人，</span><br /><span className="pl pl-1">使他们与王子同坐，</span><br /><span className="pl pl-1">得享尊荣。</span><br /><span className="pl pl-1">大地的根基属于耶和华，</span><br /><span className="pl pl-1">祂在上面建立了世界。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 121:3; 诗篇 91:11–12; 诗篇 33:16–17"> <span className="pl pl-1">祂看顾祂圣民的脚步，</span><br /><span className="pl pl-1">使恶人在黑暗中灭亡，</span><br /><span className="pl pl-1">因为得胜不是靠人的勇力。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 2:9; 诗篇 89:24; 诗篇 18:13–14"> <span className="pl pl-1">跟耶和华对抗的人必被击溃，</span><br /><span className="pl pl-1">祂必从天上用雷击打他。</span><br /><span className="pl pl-1">祂必审判天下，</span><br /><span className="pl pl-1">赐力量给祂所立的君王，</span><br /><span className="pl pl-1">使受膏者的角高举。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 3:1; 撒母耳记上 2:18; 撒母耳记上 1:28"> 以利加拿返回了拉玛，小撒母耳却留在了示罗，在祭司以利的带领下事奉耶和华。</span>
</div>
</div>

## 以利的恶子

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:28–30; 耶利米书 2:8; 士师记 2:10"> 以利的两个儿子为人邪恶，不认识耶和华，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 7:29–34"> 对民众不守自己做祭司的职分。每当民众来献祭，还在煮祭肉的时候，他们的仆人便拿着三齿叉来，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:27–28; 以赛亚书 56:11; 撒母耳记上 2:29"> 从罐里、鼎里、釜里或锅里插肉，把插上来的祭肉据为己有。他们这样对待所有到示罗来的以色列人。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 3:16; 利未记 3:3–5; 罗马书 16:18"> 甚至在焚烧脂肪之前，祭司的仆人就来对献祭的人说：“把肉给祭司烤吧！他不要煮过的，只要生的。”</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 利未记 3:16; 彼得前书 5:2–3"> 如果献祭的人答道：“要先焚烧脂肪，之后你可以随便拿，”仆人便会说：“不，你现在就给我，不然我就要抢了。”</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 2:7–9; 创世记 13:13; 玛拉基书 2:13"> 在耶和华的眼中，这两个青年罪恶深重，因为他们轻视献给耶和华的祭物。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:1; 出埃及记 28:4; 撒母耳记上 2:11"> 那时年少的撒母耳穿着细麻布的以弗得，在耶和华面前事奉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 1:3; 撒母耳记上 1:21; 出埃及记 23:14"> 他母亲每年都为他缝一件小外衣，在她和丈夫来献年祭时带给他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 1:27–28; 路加福音 2:34; 路得记 4:11"> 以利祝福以利加拿和他妻子，对他说：“愿耶和华让你妻子再给你生儿育女，代替她求来并献给耶和华的孩子。”他们就回家去了。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳记上 3:19; 创世记 21:1"> 耶和华眷顾哈娜，她又生了三个儿子和两个女儿。年少的撒母耳在耶和华面前渐渐长大。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 38:8; 撒母耳记上 2:13–17; 耶利米书 7:9–10"> 以利年事已高，他听说两个儿子对待以色列人的恶行，以及他们与在会幕门口服侍的妇女行淫的事后，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 8:12; 腓立比书 3:19; 使徒行传 9:4"> 就对他们说：“你们为什么做这样的事？我从百姓口中听说了有关你们的恶行。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 2:8; 提摩太前书 3:7; 使徒行传 6:3"> 我儿啊，不可这样，我听到在耶和华的子民中流传着你们的坏名声。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 3:14; 约书亚记 11:20; 希伯来书 10:26"> 人若得罪了别人，有上帝为他调解。但人若得罪了耶和华，谁能为他求情呢？”然而，他们不肯听从父亲的话，因为耶和华决意要杀他们。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行传 2:47"> 小撒母耳渐渐长大，日益受到耶和华和民众的喜爱。</span>
</div>
</div>

## 预言以利家的遭祸

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 33:1; 出埃及记 4:27; 出埃及记 4:14–16"> 有一个上帝的仆人来见以利，对他说：“耶和华说，‘你的祖先在埃及被法老奴役的时候，我向他们显现。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:1; 利未记 8:7–8; 民数记 18:19"> 我在以色列各支派中选出你的祖先做我的祭司，在我的祭坛上献祭烧香，穿着以弗得事奉我。我把以色列人献的所有火祭都赐给你祖先家。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 10:37; 申命记 32:15; 撒母耳记上 2:13–17"> 你们为什么蔑视献给我的祭物和供物？你为什么把你的儿子看得比我还重要，拿我以色列子民所献的上好祭物来养肥自己？’</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:26; 耶利米书 18:9–10; 箴言 3:9–10"> “所以，以色列的上帝耶和华宣告说，‘我曾经应许让你家族永远做我的祭司。’但现在耶和华宣布，‘这绝不可能了。尊重我的，我必尊重他；藐视我的，必遭藐视。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 22:17–20; 列王纪上 2:26–27; 诗篇 37:17"> 看啊，时候将到，我要切断你和你家族的力量，你家族必没有一个老人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 8:4; 撒母耳记上 4:11; 诗篇 78:59–64"> 你在困苦中必以羡慕的眼光看着我赐福以色列人，你家中却永远没有一个老人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 2:26–27; 列王纪上 1:7; 撒母耳记上 22:21–23"> 我不会把你家中的人从我坛前灭绝，但留下来的人必使你哭瞎双眼、伤心欲绝。你的子孙必盛年早逝。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 4:11; 列王纪上 13:3; 撒母耳记上 4:17"> 你的两个儿子何弗尼和非尼哈必死在同一天，这就是我言出必行的记号。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 7:27; 撒母耳记下 7:11; 列王纪上 11:38"> 我要为自己立一位忠心的祭司，他必照我的心意行事。我要使他的家族坚立，他必永远服侍我膏立的王。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 2:27; 玛拉基书 1:13; 以西结书 44:10–12"> 那时，你家存留下来的人要在他面前下拜，乞讨银子和饼，并恳求说，请给我一个祭司的职位以便糊口！’”</span>
</div>
</div>

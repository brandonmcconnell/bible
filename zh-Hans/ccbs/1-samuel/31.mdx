## 扫罗之死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 10:1–12; 撒母耳记上 28:4; 撒母耳记下 1:21"> 非利士人与以色列人交战，以色列人败逃，许多人在基利波山被杀。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 8:33; 撒母耳记上 14:49; 撒母耳记上 23:17"> 非利士人穷追扫罗及其众子，杀了扫罗的儿子约拿单、亚比拿达和麦基舒亚。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 1:6; 创世记 49:23; 列王纪上 22:34"> 扫罗周围战事激烈，他被弓箭手发现后射成重伤，</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:54; 撒母耳记下 1:6; 撒母耳记下 1:9–10"> 就对为他拿兵器的人说：“拔出你的刀来刺死我吧，免得那些未受割礼的人来刺杀和凌辱我。”但拿兵器的人非常害怕，不敢动手，扫罗就拿起刀来，伏刀自尽了。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 10:5"> 拿兵器的人看见扫罗已死，也伏刀自尽了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 12:17; 何西阿书 13:10–11; 历代志上 10:6"> 那一天，扫罗和他三个儿子，以及为他拿兵器的人和他的军队都死了。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 28:33; 利未记 26:32; 利未记 26:36"> 平原一带和约旦河对面的以色列人见以色列军败逃、扫罗及其众子已死，都弃城而逃。于是，非利士人占据了那些城邑。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 20:25; 历代志上 10:8"> 次日，非利士人来剥阵亡者的衣物，发现扫罗和他的三个儿子横尸基利波山，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 1:20; 士师记 16:23–24; 撒母耳记上 17:54"> 就割下扫罗的头颅，剥下他的盔甲，并派人去非利士全境，在他们偶像的庙里及民众中通告消息。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 2:13; 约书亚记 17:11; 撒母耳记上 21:9"> 非利士人把扫罗的盔甲放在亚斯她录神庙里，把他的尸体钉在伯·珊城墙上。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 11:1–11; 撒母耳记下 2:4"> 基列·雅比人听见非利士人对扫罗的所作所为，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 16:14; 耶利米书 34:5; 撒母耳记下 2:4–7"> 他们所有的勇士就连夜赶到伯·珊，从墙上取下扫罗和他儿子们的尸体，运到雅比火化，</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 21:12–14; 创世记 50:10; 撒母耳记上 22:6"> 把骨灰葬在雅比的柳树下，又为他们禁食了七天。</span>

## 约拿单攻打非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:27; 弥迦书 7:5; 撒母耳记下 1:25–26"> 一天，扫罗的儿子约拿单对为他拿兵器的年轻人说：“来吧，我们去非利士的驻军那里。”但他没有告诉父亲。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 13:15–16; 以赛亚书 10:28–29"> 那时扫罗正待在基比亚边界米矶仑的石榴树下，跟随他的大约有六百人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 22:20; 撒母耳记上 2:28; 撒母耳记上 4:21"> 其中有穿着以弗得的祭司亚希亚，即亚希突的儿子。亚希突是示罗耶和华祭司以利的孙子，非尼哈的儿子，以迦博的哥哥。没有人留意到约拿单出去了。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 13:23"> 约拿单到非利士驻军那里需要经过一个隘口，隘口两边的山峰一个叫播薛，一个叫西尼，</span>
<span className="v" id="v5" data-v="5"> 北面的山峰面对密抹，南面的山峰面对迦巴。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 19:26; 罗马书 8:31; 撒迦利亚书 4:6"> 约拿单对拿兵器的年轻人说：“我们去那些未受割礼之人的军营，也许耶和华会帮助我们。祂使人得胜不在于人数多少。”</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 7:3; 撒迦利亚书 8:23; 撒母耳记上 10:7"> 拿兵器的人答道：“就照你的意思，我会一心追随你。”</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 7:9–14"> 约拿单说：“我们去他们那边，故意让他们发现。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 6:36–40; 创世记 24:13–14"> 如果他们说，‘站住，等我们去你们那里！’我们就待在原地，不去他们那里。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 24:14; 撒母耳记上 10:7; 士师记 7:11"> 但如果他们说，‘你们来我们这里！’我们就去，因为那表示耶和华已经把他们交在我们手里了。”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:6; 撒母耳记上 14:22; 士师记 6:2"> 非利士的驻军看见二人走近，就说：“看！希伯来人从躲藏的洞里爬出来了！”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 17:43–44; 撒母耳记下 5:24; 士师记 7:15"> 驻军对约拿单和拿兵器的人大喊：“上来，我们要教训教训你们。”约拿单就对拿兵器的人说：“跟着我爬上去，耶和华已经把他们交在以色列人手里了。”</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 8:31; 约书亚记 23:10; 利未记 26:7–8"> 于是，约拿单就爬上去击杀非利士人，拿兵器的人紧随其后，一同击杀非利士人。</span>
<span className="v" id="v14" data-v="14"> 他们首次出击，在半亩大小的区域杀了约二十个非利士人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 13:17; 创世记 35:5; 撒母耳记下 5:24"> 营房、田野的所有非利士人，包括驻军和突击队都非常恐慌。大地震动，众人恐惧万分。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 20:22–25; 以赛亚书 19:2; 士师记 7:22"> 扫罗在便雅悯境内基比亚的哨兵看见非利士军队四散奔逃，溃不成军。</span>
<span className="v" id="v17" data-v="17"> 扫罗对跟随他的人说：“你们查一查，看谁离开了军营？”结果发现约拿单和为他拿兵器的人不见了。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 30:7–8; 撒母耳记上 5:2; 士师记 20:23"> 扫罗对亚希亚说：“把上帝的约柜抬来。”那时上帝的约柜在以色列人那里。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:24; 民数记 27:21; 约书亚记 9:14"> 扫罗和祭司说话的时候，非利士人营里越来越混乱。扫罗对祭司说：“停手吧。”</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 7:22; 历代志下 20:23; 撒母耳记上 14:16"> 他和跟随他的人聚集起来，冲入战场，发现非利士人正互相残杀，乱作一团。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 29:4; 士师记 7:23"> 从前加入非利士军队的希伯来人现在也倒戈加入扫罗和约拿单的以色列军队。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 13:6; 撒母耳记上 31:7"> 那些躲在以法莲山区的以色列人听说非利士人溃逃，都出来紧紧地追杀他们。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:30; 撒母耳记上 13:5; 诗篇 44:6–8"> 耶和华在那天拯救了以色列人，战事一直蔓延到伯·亚文。</span>
</div>
</div>

## 约拿单误违父命

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 6:26; 罗马书 10:2; 士师记 1:28"> 那一天，以色列人很困乏，因为扫罗叫他们起誓：“谁在黄昏前，就是在向敌人报完仇以前吃任何东西，谁就要受咒诅。”于是，以色列人整天都没有进食。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:8; 民数记 13:27; 申命记 9:28"> 众人进入树林，见地上有蜂蜜。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:2"> 他们在树林中虽然看见有蜂蜜正在滴落，但没有人敢伸手取蜂蜜吃，因为他们都怕违背誓言。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 14:29; 撒母耳记上 14:43; 撒母耳记上 30:12"> 约拿单没有听见他父亲叫以色列人起誓，他伸出手中的杖蘸蜂房的蜜吃，立刻精神大振。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 14:43; 撒母耳记上 14:24"> 有个士兵告诉约拿单，说：“你父亲曾叫众人郑重起誓，‘今天吃东西的人必受咒诅。’所以众人很疲惫。”</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:18; 约书亚记 7:25"> 约拿单说：“我父亲使大家受苦了。你们看，我只吃了少许蜂蜜，就精神大振，</span>
<span className="v" id="v30" data-v="30" data-xref="传道书 9:18"> 如果大家吃了从敌人那里夺来的食物，我们就会歼灭更多非利士人。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:12; 约书亚记 19:42"> 那天，以色列人追杀非利士人，从密抹一直追杀到亚雅仑，众人疲惫不堪。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 15:19; 利未记 3:17; 利未记 17:10–14"> 他们匆匆把夺来的牛、羊和牛犊在地上宰了，肉还带血就吃了。</span>
<span className="v" id="v33" data-v="33" data-xref="罗马书 2:1; 马太福音 7:5"> 有人告诉扫罗，说：“众人吃了带血的肉，得罪耶和华了。”扫罗说：“你们犯罪了！现在把一块大石头滚到我这里来，</span>
<span className="v" id="v34" data-v="34"> 再去吩咐大家把牛羊都带到这里来宰了吃，不可吃带血的肉得罪耶和华。”当晚，众人都把自己的牛羊带到那里宰杀。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 7:17; 撒母耳记上 7:12; 提摩太后书 3:5"> 扫罗为耶和华筑了一座祭坛，这是他第一次为耶和华筑坛。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 48:1–2; 诗篇 73:28; 玛拉基书 2:7"> 他对以色列人说：“让我们连夜追赶非利士人，抢夺他们的财物，直到天亮，把他们全部歼灭。”众人答道：“就照你的意思。”但祭司说：“让我们先来求问上帝吧。”</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:6; 撒母耳记上 30:7–8; 撒母耳记上 23:9–12"> 于是，扫罗求问上帝，说：“我可以去追杀非利士人吗？你会把他们交在以色列人手里吗？”但耶和华那日没有回答他。</span>
<span className="v" id="v38" data-v="38" data-xref="士师记 20:2; 约书亚记 7:14–26; 民数记 24:17"> 扫罗说：“你们这些百姓的首领到这里来，我们要查出今天究竟谁犯了罪，</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 14:44; 撒母耳记下 12:5; 撒母耳记上 14:24"> 我凭拯救以色列的永活的耶和华起誓，就是我儿子约拿单犯了罪，他也要死！”众人都默不作声。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 15:15; 撒母耳记上 14:7; 撒母耳记上 14:36"> 扫罗对以色列众人说：“你们站在这边，我和我的儿子约拿单站在那边。”众人答道：“就照你的意思。”</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 1:24; 约书亚记 7:16–18; 撒母耳记上 10:20–21"> 扫罗向以色列的上帝耶和华祷告说：“请你把实情告诉我吧。”抽签的结果是约拿单和扫罗犯了罪，民众都是无辜的。</span>
<span className="v" id="v42" data-v="42"> 扫罗和约拿单二人再抽签，结果抽出了约拿单。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 7:19; 撒母耳记上 14:27; 约拿书 1:7–10"> 扫罗对约拿单说：“告诉我，你做了什么事？”约拿单说：“我确实用手中的杖蘸了一点蜂蜜吃，这样我就要死吗？”</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记上 14:39; 路得记 1:17; 撒母耳记上 25:22"> 扫罗说：“约拿单啊，你必须死。否则，愿上帝重重地惩罚我。”</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 21:18; 使徒行传 27:34; 撒母耳记下 14:11"> 但众人对扫罗说：“今天约拿单给以色列人带来这么大的胜利，难道要他死吗？绝不可以！我们凭永活的耶和华起誓，绝不可动他一根头发，因为他今天的行动有上帝的帮助。”众人就这样救了约拿单的性命。</span>
<span className="v" id="v46" data-v="46"> 扫罗便停止了追击，非利士人也回本地去了。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳记下 10:6; 撒母耳记上 14:52; 撒母耳记下 8:3"> 扫罗统治以色列后，常常攻打四围的摩押人、亚扪人、以东人、琐巴的诸王和非利士人等仇敌，无往而不胜。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及记 17:14; 撒母耳记上 15:3–7; 申命记 25:19"> 他奋勇杀敌，打败了亚玛力人，从掠夺者手中救出以色列人。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="历代志上 8:33; 撒母耳记上 31:2; 撒母耳记下 6:20–23"> 他的儿子是约拿单、亦施韦和麦基舒亚，长女叫米拉，次女叫米甲。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳记下 2:8; 撒母耳记上 17:55; 撒母耳记下 3:27"> 他的妻子名叫亚希暖，是亚希玛斯的女儿。扫罗军队的元帅叫押尼珥，是他叔叔尼珥的儿子。</span>
<span className="v" id="v51" data-v="51" data-xref="撒母耳记上 9:1; 撒母耳记上 9:21"> 扫罗的父亲基士和押尼珥的父亲尼珥都是亚别的儿子。</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 8:11; 撒母耳记上 8:1"> 扫罗一生常和非利士人激烈交战。他遇见英勇的壮士，都会征募到自己麾下。</span>
</div>

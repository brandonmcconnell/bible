## 扫罗王被废

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 9:16; 撒母耳记上 12:14; 诗篇 2:10–11"> 一天，撒母耳对扫罗说：“耶和华差遣我膏立你做祂以色列子民的王，所以你要听从祂的话。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:17–19; 出埃及记 17:8–16; 民数记 24:20"> 万军之耶和华说，‘我要惩罚亚玛力人，因为在以色列人离开埃及的时候，他们与以色列人为敌。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:16–18; 民数记 24:20; 民数记 31:17"> 你现在要去攻打他们，彻底消灭他们和他们拥有的一切，把男女老幼、牛羊骆驼和驴全部杀掉，一个不留。’”</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 15:24; 撒母耳记上 11:8; 撒母耳记上 13:15"> 于是，扫罗在提拉因召集了二十万步兵，另有从犹大来的一万人。</span>
<span className="v" id="v5" data-v="5"> 扫罗来到亚玛力的城池，在山谷里埋伏起来。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 1:16; 民数记 10:29–32; 出埃及记 18:19"> 他对基尼人说：“你们离开亚玛力人吧，免得我把你们也一起消灭，因为在以色列人离开埃及的时候，你们曾善待他们。”于是，基尼人离开了亚玛力人。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 16:7; 创世记 25:18; 撒母耳记上 14:48"> 扫罗攻打亚玛力人，从哈腓拉直打到埃及东面的书珥，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:1; 以斯帖记 3:1; 民数记 24:7"> 生擒了亚玛力王亚甲，用刀杀尽了亚玛力人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:15; 撒母耳记上 15:19; 撒母耳记上 15:3"> 扫罗和他的士兵却留下了亚甲和那些上好的牛羊、肥壮的牛犊和羊羔及一切美物，只毁灭了那些瘦弱无用的牲畜。</span>
<span className="v" id="v10" data-v="10"> 那时，耶和华对撒母耳说：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:13; 创世记 6:6; 撒母耳记下 24:16"> “我后悔立扫罗为王，因为他离弃了我，不遵守我的命令。”撒母耳很气愤，整夜呼求耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:55; 撒母耳记下 18:18; 撒母耳记上 25:2"> 清早，撒母耳起来去见扫罗，有人告诉他扫罗已前往迦密山，在那里为自己立了纪念碑，然后去了吉甲。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 17:2; 路得记 3:10; 箴言 31:31"> 撒母耳到了扫罗那里后，扫罗说：“愿耶和华赐福给你，我已经遵守了耶和华的命令。”</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 3:13–15; 耶利米书 2:18–19; 耶利米书 2:34–37"> 撒母耳说：“那么，我现在听见的牛羊叫声是从哪里来的？”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:21; 撒母耳记上 15:9; 出埃及记 32:22–23"> 扫罗答道：“这是众人从亚玛力人那里带回来的，他们留下了这些上好的牛羊要献给你的上帝耶和华，我们毁灭了其余的一切。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 9:27; 列王纪上 22:16; 撒母耳记上 12:7"> 撒母耳对扫罗说：“住口！让我告诉你耶和华昨天晚上对我说的话。”扫罗答道：“请说。”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 10:22; 撒母耳记上 9:21; 撒母耳记上 15:1–3"> 撒母耳说：“你虽然从前觉得自己微不足道，但现在却做了以色列各支派的首领。耶和华膏立你做以色列的王。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 创世记 13:13; 创世记 15:16"> 祂差遣你去攻打那些罪恶的亚玛力人，命你把他们全部消灭。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:32; 历代志下 33:6; 历代志下 36:12"> 你为何不听从祂的命令？你为何急于掠夺财物，做耶和华视为邪恶的事呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 15:13; 马太福音 19:20; 罗马书 10:3"> 扫罗答道：“我的确服从了耶和华的命令，照着耶和华的吩咐做了。我把亚玛力王亚甲带了回来，杀尽了其余的亚玛力人。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:15; 出埃及记 32:22–23; 创世记 3:13"> 士兵们却从本该毁灭的战利品中取了上好的牛羊，准备在吉甲奉献给你的上帝耶和华。”</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 6:6; 诗篇 51:16–17; 箴言 21:3"> 撒母耳说：<br /><span className="pl pl-1">“耶和华喜欢燔祭和其他祭物，</span><br /><span className="pl pl-1">岂如喜欢人们听从祂的话？</span><br /><span className="pl pl-1">顺服胜于献祭，</span><br /><span className="pl pl-1">听从耶和华胜过向祂献上公羊的脂肪。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 28:16; 撒母耳记上 13:14; 利未记 20:6"> <span className="pl pl-1">叛逆不亚于行巫术的罪，</span><br /><span className="pl pl-1">顽固不化无异于拜偶像。</span><br /><span className="pl pl-1">你拒绝耶和华的命令，</span><br /><span className="pl pl-1">祂也拒绝你做王。”</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 12:13; 以赛亚书 51:12–13; 民数记 22:34"> 扫罗对撒母耳说：“我犯罪了！我违背了耶和华的命令和你的指示。我因惧怕百姓，就听从了他们。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:17"> 现在求你赦免我的罪，跟我一起回去，我好敬拜耶和华。”</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 4:6; 撒母耳记上 13:14; 撒母耳记上 16:1"> 但撒母耳说：“我不会跟你回去，你既然拒绝遵行耶和华的命令，祂也拒绝你做以色列的王。”</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 11:30–31"> 撒母耳转身离去，扫罗就抓住他外袍的衣边，结果衣边被撕下来了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 28:17–18; 使徒行传 13:22; 但以理书 4:32"> 撒母耳对他说：“耶和华今天已经从你身上撕下以色列国，赐给了一个比你好的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 24:14; 民数记 23:19; 提多书 1:2"> 以色列荣耀的上帝不说谎、也不改变心意，因为祂不是反复无常的世人。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 5:44; 约翰福音 12:43; 以赛亚书 29:13"> 扫罗说：“我犯了罪，但求你在以色列的长老和百姓面前尊重我，求你跟我回去，我好敬拜你的上帝耶和华。”</span>
<span className="v" id="v31" data-v="31"> 于是，撒母耳跟扫罗一起回去，扫罗就敬拜耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 18:7; 帖撒罗尼迦前书 5:3; 耶利米书 48:44"> 撒母耳说：“把亚玛力王亚甲带到我这里来。”亚甲若无其事地来到他面前，心想自己一定逃过一死了。</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 1:7; 创世记 9:6; 马太福音 7:2"> 但撒母耳对他说：“你的刀怎样使妇人失去儿女，你的母亲也要怎样失去她的儿子。”于是，撒母耳就在吉甲，在耶和华面前把亚甲杀死了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:4; 撒母耳记上 7:17"> 事后，撒母耳回到拉玛，扫罗也返回基比亚自己的家。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 15:11; 撒母耳记上 19:24; 撒母耳记上 16:1"> 撒母耳一直到死没有再见扫罗，但他为扫罗哀伤。耶和华后悔立扫罗做以色列王。</span>

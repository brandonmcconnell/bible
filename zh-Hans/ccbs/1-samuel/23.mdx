## 大卫营救基伊拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:44; 弥迦书 6:15; 尼希米记 3:17–18"> 一天，大卫得知非利士人正在攻打基伊拉，抢掠麦场，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 23:4; 撒母耳记下 5:19; 撒母耳记下 5:23"> 便求问耶和华：“我可以去攻打非利士人吗？”耶和华答道：“你可以去攻打非利士人，营救基伊拉。”</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 12:5; 诗篇 11:1; 撒母耳记上 23:15"> 大卫的部下却对他说：“我们在犹大这里尚且胆战心惊，何况去基伊拉攻打非利士军队呢！”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 7:7; 约书亚记 8:7; 列王纪下 3:18"> 大卫再求问耶和华，耶和华答道：“到基伊拉去吧，我一定把非利士人交在你手里。”</span>
<span className="v" id="v5" data-v="5"> 于是，大卫和部下到基伊拉去攻打非利士人，大败敌人，夺取了他们的牲畜，救出基伊拉人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 22:20; 撒母耳记上 14:3; 撒母耳记上 14:18"> 亚希米勒的儿子祭司亚比亚他到基伊拉投奔大卫时，把以弗得也带了去。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 24:4–6; 约伯记 20:5; 撒母耳记上 26:8–9"> 扫罗得知大卫在基伊拉，就说：“这一次是上帝把他交在我手中了，因为他竟然自投网罗，进入有门有闩的城。”</span>
<span className="v" id="v8" data-v="8"> 扫罗召集全军准备攻打基伊拉，围困大卫和他的部下。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 30:7; 撒母耳记上 23:6; 民数记 27:21"> 大卫知道了扫罗的计谋，便吩咐祭司亚比亚他把以弗得带来，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 3:15–16; 撒母耳记上 23:8; 创世记 18:24"> 然后说：“耶和华，以色列的上帝啊，仆人听说扫罗要来毁灭基伊拉城，因为我在这里。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:3; 诗篇 50:15; 马太福音 7:7–8"> 基伊拉的人会不会把我交给扫罗呢？扫罗是不是像我听说的那样要来这里呢？耶和华，以色列的上帝啊，求你告诉我。”耶和华说：“扫罗一定会来。”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 23:20; 诗篇 31:8; 诗篇 62:1"> 大卫又问耶和华：“基伊拉的人会不会把我和我的部下交给扫罗呢？”耶和华说：“他们一定会。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:2; 撒母耳记上 25:13; 撒母耳记上 30:9–10"> 于是，大卫率领自己的六百部下离开基伊拉，到处流浪。扫罗得知大卫已经离开基伊拉，就不去了。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 54:3–4; 诗篇 32:7; 约书亚记 15:24"> 大卫住在旷野的堡垒或西弗旷野的山区。扫罗天天搜捕大卫，但上帝没有把大卫交在他的手中。</span>
<span className="v" id="v15" data-v="15"> 大卫在西弗旷野的何利沙得知扫罗要来杀他。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 35:3–4; 希伯来书 12:12–13; 约伯记 4:3–4"> 扫罗的儿子约拿单去何利沙见大卫，鼓励大卫坚定地信靠上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:31; 撒母耳记上 24:20; 使徒行传 28:16"> 他对大卫说：“不要害怕，我父亲扫罗害不了你。你将做以色列的王，我将做你的宰相。我父亲也明白这一点。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 21:7; 撒母耳记上 20:42; 撒母耳记上 18:3"> 二人在耶和华面前立了约。之后，大卫仍留在何利沙，约拿单则回家去了。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 26:1; 撒母耳记上 26:3; 诗篇 54:1–7"> 西弗人去基比亚见扫罗，说：“大卫就躲在我们那里，在旷野南面哈基拉山上何利沙的堡垒里。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:12; 箴言 29:26; 箴言 11:23"> 王啊，你随时都可以下来，我们一定把他交在王的手里。”</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 22:8; 以赛亚书 66:5; 弥迦书 3:11"> 扫罗说：“愿耶和华赐福给你们！因为你们体恤我。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:13"> 我听说他非常狡猾，你们再回去弄清楚他的行踪及谁在那里见过他，</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 3:15–16; 马可福音 14:1; 民数记 10:36"> 查明他的藏身之处，回来如实告诉我，然后我会与你们同去。如果他在犹大境内，我要搜遍千家万户，找到他。”</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 25:2; 约书亚记 15:55"> 于是，西弗人先回去了。当时大卫和他的部下在旷野南面的亚拉巴，即玛云旷野。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 15:8; 撒母耳记上 23:28"> 大卫听说扫罗和手下正在搜寻他，便率领部下前往玛云旷野的磐石，住在那里。扫罗得知后，便去玛云旷野追赶大卫。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 17:9; 哥林多后书 1:8; 诗篇 140:1–9"> 扫罗在山这边走，大卫和他的部下在山那边走，急急忙忙地躲避扫罗。扫罗和他的手下四面包围过来，眼看就要抓住他们了。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 19:9; 诗篇 116:3; 申命记 32:36"> 这时，扫罗的信使前来禀报，说非利士人前来犯境，请王速回。</span>
<span className="v" id="v28" data-v="28"> 扫罗只好放弃追赶大卫，回师迎战非利士人。因此，那地方叫“脱险岩”。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:2; 约书亚记 15:62; 以西结书 47:10"> 后来，大卫从那里转移到隐·基底的堡垒里。</span>

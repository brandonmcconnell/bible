## 扫罗嫉妒大卫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 20:17; 箴言 18:24; 撒母耳记上 18:3"> 大卫与扫罗说完话后，约拿单与大卫情投意合，他像爱自己一样爱大卫。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 17:15; 撒母耳记上 16:21–23"> 从那天起，扫罗把大卫留在身边，不让他再回父亲那里。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 20:8–17; 撒母耳记上 20:42; 撒母耳记下 21:7"> 约拿单像爱自己一样爱大卫，他与大卫立了盟约，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 41:42; 路加福音 15:22; 以斯帖记 6:8–9"> 并把身上的外袍、战衣、刀、弓和腰带都送给大卫。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 18:30; 撒母耳记上 18:14–15; 歌罗西书 4:5"> 无论扫罗派大卫办什么事，他都表现出色。扫罗派他做军队的将领，民众和扫罗的臣仆都非常满意。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 15:20; 士师记 11:34; 诗篇 68:25"> 大卫杀死了非利士人歌利亚，与众人归来时，妇女们击鼓弹琴、载歌载舞地从以色列各城出来迎接扫罗王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 21:11; 撒母耳记上 29:5; 出埃及记 15:21"> 她们跳舞歌唱：“扫罗杀死千千，大卫杀死万万。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 15:28; 箴言 13:10; 雅各书 4:5"> 扫罗听了非常愤怒，对这话很反感，就说：“她们将万万归功给大卫，将千千归功给我，只剩我的王位没有给他了！”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 7:22; 创世记 31:2; 马太福音 20:15"> 扫罗从此对大卫起了嫉妒之心。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:9; 帖撒罗尼迦后书 2:11; 列王纪上 18:29"> 第二天，从上帝那里来的邪灵突然降在扫罗身上，他就在屋子里叫闹不停，大卫照常为他弹琴。扫罗当时手上拿着矛，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 20:33; 以赛亚书 54:17; 路加福音 4:30"> 他突然把矛投向大卫，心想：“我要把他刺透，钉在墙上。”他投了两次，大卫都躲过了。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 18:15; 撒母耳记上 18:29; 撒母耳记上 16:13–14"> 耶和华离开了扫罗与大卫同在，所以扫罗忌惮大卫。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 5:2; 诗篇 121:8; 撒母耳记上 18:16–17"> 他把大卫调离自己身边，立为千夫长，让他领兵作战。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 39:23; 马太福音 28:20; 撒母耳记上 16:18"> 耶和华与大卫同在，因此他事事成功。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 歌罗西书 4:5; 雅各书 1:5"> 扫罗看见大卫做事精明，就忌惮他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 18:5; 民数记 27:17; 列王纪上 3:7"> 以色列人和犹大人都爱戴他，因为他带领他们作战。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 17:25; 撒母耳记上 25:28; 撒母耳记上 18:25"> 扫罗对大卫说：“我要把大女儿米拉嫁给你，但你要英勇作战，效忠于我，为耶和华争战。”扫罗心里想：“我不要亲自动手，我要借非利士人的手杀他。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 7:18; 撒母耳记上 9:21; 撒母耳记上 18:23"> 大卫说：“我算什么？我的家族在以色列那么卑微，我怎么配做王的女婿呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 7:22; 撒母耳记下 21:8; 士师记 14:20"> 到了与大卫成婚的日子，扫罗却把米拉嫁给了米何拉人亚得列。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 18:28"> 扫罗的次女米甲爱上了大卫，扫罗知道了非常高兴。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 18:17; 出埃及记 10:7; 耶利米书 9:8"> 他心里想：“我把这个女儿给大卫，让他中圈套，好借非利士人的手杀掉他。”于是，他对大卫说：“你现在还有一次机会做我的女婿。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 36:1–3; 诗篇 55:21; 撒母耳记下 13:28–29"> 他又吩咐臣仆，说：“你们私底下告诉大卫，说王很欣赏他，群臣都爱戴他，劝他做王的女婿。”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:141; 箴言 14:20; 传道书 9:15–16"> 扫罗的臣仆把这话告诉了大卫，大卫却说：“做王的女婿岂是一件小事呢？我不过是个贫穷卑微的人。”</span>
<span className="v" id="v24" data-v="24"> 臣仆把大卫这番话回报扫罗，</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 34:12; 撒母耳记上 18:17; 撒母耳记上 14:24"> 扫罗说：“你们去告诉大卫，就说王只需要一百个非利士人的包皮作聘礼，好向他的敌人报仇。”扫罗想让大卫死在非利士人的手上。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 18:21"> 臣仆把这番话告诉了大卫，大卫欣然答应做王的女婿。期限到来之前，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 3:14; 士师记 14:19; 撒母耳记上 18:13"> 大卫和部下出去杀了二百个非利士人，把他们的包皮全部献给扫罗，好做王的女婿。扫罗便把女儿米甲嫁给了大卫。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 24:20; 撒母耳记上 26:25; 创世记 37:8–11"> 扫罗知道耶和华与大卫同在，自己的女儿米甲也爱他，</span>
<span className="v" id="v29" data-v="29" data-xref="传道书 4:4; 约翰福音 11:53; 雅各书 2:19"> 就更加忌惮大卫，终生与大卫为敌。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:5; 撒母耳记下 11:1; 彼得前书 2:4"> 非利士人的将领常来进犯，大卫每次作战总比扫罗的其他臣仆出色，因而倍受尊重。</span>

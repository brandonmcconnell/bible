## 扫罗犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:5; 弥迦书 6:6"> 扫罗四十岁<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯来文无“四十岁”，一些七十士希腊文译本有此数字。">a</a></sup>登基。他在统治以色列的第二年，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 10:26; 撒母耳记上 13:5; 撒母耳记上 14:31"> 从以色列人中选出三千人，亲自带领其中的两千人到密抹和伯特利山，另外一千人和约拿单留在便雅悯境内的基比亚。他把其余的人遣散回家。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 10:5; 士师记 3:27; 士师记 6:34"> 约拿单攻打迦巴的非利士驻军，非利士人听到了这消息。于是，扫罗在各地吹响号角，通告希伯来人。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 34:30; 出埃及记 5:21; 撒迦利亚书 11:8"> 以色列众人听说扫罗攻打非利士人的驻军，并听说非利士人对以色列人恨之入骨，便响应扫罗的号召，聚集在吉甲。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 14:23; 约书亚记 11:4; 约书亚记 18:12"> 非利士人调兵遣将，要攻打以色列。他们有三万辆战车和六千骑兵，步兵多如海边的沙。大军来到伯·亚文以东的密抹，驻扎在那里。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 6:2; 希伯来书 11:38; 士师记 10:9"> 以色列人看见敌军压境，情势危急，纷纷躲进山洞、丛林、石穴、地洞和坑里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 20:8; 利未记 26:17; 民数记 32:1–5"> 有些希伯来人过了约旦河，逃到迦得和基列。但扫罗仍然留在吉甲，跟随他的人都害怕得发抖。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 10:8"> 扫罗按着撒母耳所定的日期在吉甲等了七天，可是撒母耳还没有来。扫罗的军兵开始散去。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 3:4; 箴言 21:27; 箴言 15:8"> 于是，扫罗说：“你们把燔祭和平安祭带到我这里来。”他就献上了燔祭。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:13; 路得记 2:4; 诗篇 129:8"> 扫罗刚把燔祭献完，撒母耳就来了，扫罗出去迎接他，向他问安。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:23; 撒母耳记上 13:5; 撒母耳记上 13:16"> 撒母耳对扫罗说：“你做的是什么事？”扫罗答道：“我看见民众不断离我而去，你到了约定的时候还没有来，而且非利士人就聚集在密抹。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 66:3; 阿摩司书 8:5; 哥林多后书 9:7"> 我想非利士人就要到吉甲来攻打我了，但我还没有向耶和华求助，我迫不得已，就献上燔祭了。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 15:22; 历代志下 16:9; 撒母耳记上 15:28"> 撒母耳说：“你真糊涂！你违背了你的上帝耶和华的命令。祂本来要使你的王位在以色列永远坚立，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 13:22; 撒母耳记上 15:28; 诗篇 89:19–37"> 但现在你的王位不能长久了，耶和华已经找到一个合祂心意的人，要立他做百姓的君王。因为你没有遵守耶和华的命令。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 14:2; 撒母耳记上 13:2; 撒母耳记上 13:6–7"> 撒母耳离开吉甲去便雅悯境内的基比亚。扫罗数了一下跟随他的人，约有六百人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 13:3"> 扫罗和儿子约拿单及随从留在便雅悯境内的迦巴，非利士人则在密抹扎营。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 18:23; 撒母耳记上 14:15; 约书亚记 19:3"> 非利士人分成三队施行突袭，一队前往书亚境内的俄弗拉，</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米记 11:34; 约书亚记 18:13–14; 约书亚记 16:3"> 一队前往伯·和仑，一队前往边境地区，那里可以俯瞰旷野附近的洗波音谷。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪下 24:14; 士师记 5:8; 耶利米书 24:1"> 那时，以色列全境找不到一个铁匠，这是因为非利士人的禁令，防止希伯来人制造刀枪。</span>
<span className="v" id="v20" data-v="20"> 以色列人都要到非利士的铁匠那里去磨锄、犁、斧和铲。</span>
<span className="v" id="v21" data-v="21"> 磨锄或犁要花八克银子，磨三齿叉、斧头或赶畜棒要花四克银子。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 5:8; 撒迦利亚书 4:6; 撒母耳记上 17:50"> 所以在交战的日子，除了扫罗和约拿单外，其他随从手上都没有刀枪。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 10:28; 撒母耳记上 14:1; 撒母耳记上 14:4–5"> 当时非利士的一队防兵前往密抹的隘口驻守。</span>
</div>
</div>

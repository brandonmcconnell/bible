## 大卫与亚比该

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 28:3; 民数记 20:29; 申命记 34:8"> 撒母耳死了，以色列人都聚在一起哀悼他，把他安葬在拉玛他自己的坟地里。之后，大卫到了巴兰的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 38:13; 撒母耳记上 23:24; 约书亚记 15:55"> 玛云有个富翁拥有三千只绵羊和一千只山羊，他的产业在迦密。当时他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以赛亚书 32:5–7"> 他名叫拿八，是迦勒族人，妻子名叫亚比该，既聪慧又漂亮。拿八粗暴凶恶。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 38:13; 撒母耳记下 13:23"> 大卫在旷野得知拿八正在剪羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 43:23; 撒母耳记上 17:22"> 就派十个部下到迦密去见拿八，吩咐他们以他的名义向拿八问安，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 历代志上 12:18; 诗篇 122:7"> 对拿八说：“愿你和你全家平安，愿你一切顺利！</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:21; 撒母耳记上 25:15–16; 撒母耳记上 22:2"> 我听说你正在剪羊毛。你的牧人与我们在迦密的时候，我们没有欺负过他们，他们没有丢过任何东西。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖记 9:19; 尼希米记 8:10–12; 路加福音 14:12–14"> 你问问你的仆人就知道了。请你恩待我的部下，因为今天是好日子，求你随手赏一点东西给仆人们和晚辈我。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 2:15; 历代志下 14:7; 创世记 8:4"> 大卫的部下就去把大卫的话告诉拿八，等候他的答复。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 9:28; 以赛亚书 32:7; 撒母耳记上 22:7–8"> 拿八说：“大卫是谁？耶西的儿子是谁？这些日子有很多仆人逃离主人，</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 8:6; 加拉太书 6:10; 哥林多后书 6:9"> 我怎能把饼、水和为剪羊毛者预备的肉分给一群来历不明的人呢？”</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 36:21–22; 撒母耳记下 24:13; 希伯来书 13:17"> 大卫的部下回去把拿八的话禀告大卫。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 23:13; 箴言 25:8; 撒母耳记上 24:5–6"> 大卫听了，就吩咐众人备刀，他自己也带了刀去拿八那里。大卫带了四百人去，留下二百人看守辎重。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 13:10; 马可福音 15:29"> 拿八的一个仆人告诉拿八的妻子亚比该说：“大卫从旷野派人来向我们主人问安，主人却辱骂他们。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:7; 撒母耳记上 25:21; 腓立比书 2:15"> 那些人对我们很好，从来不欺负我们。我们跟他们一起在田野的时候，从来没有丢过任何东西。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 1:10; 出埃及记 14:22; 撒迦利亚书 2:5"> 我们在他们附近牧羊的时候，他们昼夜不断地保护我们。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:7; 申命记 13:13; 撒母耳记上 20:9"> 所以，请你赶快想个法子，不然主人和他全家恐怕都会大难临头。主人是个凶暴的人，没有人敢跟他说话。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 16:1; 马太福音 5:25; 箴言 6:4–5"> 亚比该连忙用驴驮上二百块饼、两皮袋酒、五只宰好了的羊、三十七升烤麦、一百块葡萄饼和二百块无花果饼，</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 32:20; 创世记 32:16; 箴言 31:11–12"> 又吩咐仆人说：“你们先去吧！我随后就来。”她没有把这事告诉丈夫拿八。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 4:24"> 她骑着驴下山的时候，就看见大卫和他的部下迎面而来。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所书 4:31; 罗马书 12:21"> 大卫曾说：“我在旷野保护这人的羊群，使它们不致丢失，真是枉费功夫。他竟以怨报德。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 14:10; 撒母耳记上 20:13; 撒母耳记上 3:17"> 如果我让他家里一个男子活到明早，愿上帝重重地惩罚我！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:41; 士师记 1:14; 约书亚记 15:18"> 亚比该看见大卫，连忙下驴俯伏下拜。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 8:3; 撒母耳记上 25:28; 撒母耳记下 14:9"> 她俯伏在大卫脚前说：“我主啊，我愿意承担一切罪过，请听婢女说。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 25:17; 玛拉基书 2:2; 撒母耳记下 13:33"> 请不要理会拿八那个恶徒，他人如其名<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拿八”意思是“愚蠢”。">a</a></sup>，是个名符其实的蠢人。当时婢女没有见到你派来的使者。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 18:32; 罗马书 12:19–20; 创世记 20:6"> 我主啊，既然耶和华阻止你亲手杀人报仇，我就凭永活的耶和华和你的性命起誓，愿你的仇敌和伤害你的人都像拿八一样没有好下场。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 33:11; 撒母耳记上 30:26; 列王纪下 5:15"> 现在，请把婢女带来的礼物分给你的部下吧。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 18:17; 撒母耳记下 7:11; 撒母耳记上 24:11"> 请饶恕婢女的罪过，耶和华必使你的子孙世代做王，因为你是在为耶和华而战，愿你一生没有过错。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 17:21; 马太福音 10:29–30; 玛拉基书 3:17"> 你就是被人追杀，也会在你的上帝耶和华的保护下安然无恙。你敌人的性命却要像石头一样被耶和华用投石器抛出去。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 13:14; 诗篇 89:20; 撒母耳记上 23:17"> 如果你现在没有杀人报仇，伤害无辜，到了耶和华照应许赐福给你、立你做以色列王的时候，你就不会心里不安了。我主啊，耶和华赐福给你的时候，求你不要忘了婢女。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及记 18:10; 诗篇 72:18"> 大卫对亚比该说：“以色列的上帝耶和华当受称颂！祂今天派你来见我。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 25:26; 箴言 28:23; 箴言 9:9"> 你很有见识，你今天拦阻我亲手杀人复仇，值得称赞。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:11; 撒母耳记上 25:26; 约书亚记 10:6"> 我凭阻止我杀你的以色列的上帝——永活的耶和华起誓，若不是你赶来迎接我，拿八家中不会有一个男子活到明天早上。”</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 19:21; 撒母耳记上 20:42; 列王纪下 5:19"> 大卫接受了亚比该的礼物，对她说：“安心回家吧，我答应你的请求。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 25:19; 撒母耳记下 13:23; 撒母耳记下 13:28"> 她回到家时，拿八正在大摆宴席，排场如御宴。她见拿八心情愉快，喝得酩酊大醉，就什么也没告诉他，等第二天早上再说。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 28:28; 撒母耳记上 25:34; 撒母耳记上 25:22"> 次日清晨，拿八酒醒以后，他妻子把发生的一切告诉他，他吓得昏死过去，身体僵硬如石。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记上 26:10; 列王纪下 15:5; 撒母耳记上 6:9"> 过了十天，耶和华击打拿八，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 25:26; 撒母耳记上 25:34; 箴言 22:23"> 大卫听见拿八的死讯，就说：“赞美耶和华！拿八羞辱我，祂为我申了冤，又阻止仆人行恶。祂使拿八得到了报应。”后来，大卫差遣使者去向亚比该求婚。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 24:51; 创世记 24:37–38"> 他的使者就启程到迦密去向亚比该传达大卫的心意。</span>
<span className="v" id="v41" data-v="41" data-xref="提摩太前书 5:10; 约翰福音 13:3–5; 路得记 2:10"> 亚比该听了，立刻俯伏在地上说：“婢女愿意效劳，为我主的仆人洗脚。”</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 24:61–67; 诗篇 45:10–11"> 她连忙骑上驴，带了五个侍女，跟随大卫的使者前去，做了大卫的妻子。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:5; 约书亚记 15:56; 撒母耳记上 27:3"> 大卫已经娶了耶斯列人亚希暖，她们二人就同做大卫的妻子。</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 3:14; 撒母耳记上 18:27; 撒母耳记上 18:20"> 扫罗已经把自己的女儿、大卫的妻子米甲嫁给了迦琳人拉亿的儿子帕提。</span>
</div>

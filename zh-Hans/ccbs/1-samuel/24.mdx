## 大卫不杀扫罗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 23:28–29; 以西结书 22:9; 撒母耳记上 23:19"> 扫罗追击非利士人回来，得知大卫在隐·基底的旷野，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 26:2; 诗篇 104:18; 诗篇 37:32"> 就率领三千以色列精兵去野羊岩附近搜索大卫和他的部下。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:24; 诗篇 57:1–11; 诗篇 142:1–7"> 他们来到路旁的一处羊圈，那里有一个山洞，扫罗进去大解。大卫和他的部下就躲在洞的深处。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 26:8–11; 撒母耳记上 24:10; 撒母耳记上 26:23"> 大卫的部下对大卫说：“耶和华说过要把你的仇敌交在你手中，任你处置，今天机会来了。”大卫就爬过去，偷偷割了扫罗外袍的一角。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 24:10; 列王纪下 22:19; 约翰一书 3:20–21"> 事后，大卫心里不安，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 1:14; 约伯记 31:29–30; 撒母耳记上 26:9–11"> 他对部下说：“我不该做这样的事，我主是耶和华所膏立的王，我绝不出手伤害他，因为他是耶和华所膏立的。”</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 5:44; 诗篇 7:4; 罗马书 12:17–21"> 大卫用这些话拦住他的部下，不让他们杀扫罗。<br />扫罗起来离开山洞走了，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:23–24; 罗马书 13:7; 出埃及记 20:12"> 大卫随后也来到洞外，在后面喊扫罗：“我主我王啊！”扫罗回头一看，见大卫俯伏在地，向他下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 7:21–22; 箴言 29:12; 箴言 16:28"> 大卫对扫罗说：“你为什么听信谗言，认为我要谋害你呢？</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:15; 撒母耳记上 24:4; 撒母耳记上 26:8–9"> 你现在亲眼看见了，刚才在山洞里，耶和华把你交在我手中，有人叫我杀你，我却不肯，因为你是耶和华所膏立的王，我不会动手伤害你。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 26:20; 撒母耳记上 23:14; 撒母耳记上 23:23"> 我父请看，你的这块袍子在我手中。我割下了你的袍角，没有杀你，现在你应该明白我并未图谋背叛你。我没有对不起你，你却要置我于死地。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 43:1; 士师记 11:27; 诗篇 35:1"> 愿耶和华在你我之间判定是非，替我申冤，我却不会动手伤害你。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 7:20; 马太福音 7:16–18; 马太福音 12:33–34"> 俗语说，‘恶事出于恶人’，所以我不会动手伤害你。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 26:20; 撒母耳记上 17:43; 撒母耳记下 9:8"> 以色列王出来要捉拿谁呢？一条死狗吗？一只跳蚤吗？</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 43:1; 诗篇 35:1; 诗篇 119:154"> 愿耶和华做我们的审判官，在你我之间判定是非。愿耶和华鉴察，为我申冤，从你手中拯救我。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:17; 创世记 33:4; 路加福音 21:15"> 大卫说完了，扫罗问道：“我儿大卫啊！是你吗？”便放声大哭起来。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:44; 撒母耳记上 26:21; 创世记 38:26"> 扫罗对大卫说：“你比我公义，因为你善待我，我却恶待你。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 26:23; 诗篇 31:8; 撒母耳记上 23:12"> 你今天使我明白你善待了我，耶和华把我交在你手中，你却没有下手杀我。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:20; 撒母耳记上 23:21; 箴言 25:21–22"> 有谁会让自己手中的仇敌平安离去呢？愿耶和华因你今日善待我而赐福你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:17; 马太福音 2:3–6; 撒母耳记下 3:17–18"> 我知道你必做王，以色列国必在你手中得到坚固。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:23; 撒母耳记下 21:6–8; 撒母耳记上 20:14–17"> 现在请你凭耶和华向我起誓，你不会杀害我的子孙，灭绝我的后代。”</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 23:29; 约翰福音 2:24; 马太福音 10:16–17"> 大卫便向扫罗起誓。之后，扫罗回家了，大卫和部下也回堡垒去了。</span>
</div>

## 扫罗残杀祭司

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 57:1–11; 诗篇 142:1–7; 历代志上 11:15"> 大卫离开迦特，逃到亚杜兰洞。他的兄弟和亲属知道后，都来到他那里，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 11:28; 撒母耳记上 30:22–24; 诗篇 72:12–14"> 所有受压迫的、负债的和心怀不满的人都纷纷来投奔他。大卫就做了他们的首领，跟随他的约有四百人。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 3:18; 撒母耳记下 15:25–26; 士师记 11:29"> 后来，大卫到摩押的米斯巴去，请求摩押王收留他的父母，直到他明白上帝给他的安排为止。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 11:1; 历代志上 12:16; 历代志上 29:29"> 大卫把父母留在了摩押王那里。在大卫住堡垒期间，他的父母一直住在摩押。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:25; 历代志上 21:9; 历代志上 29:29"> 迦得先知吩咐大卫离开堡垒回犹大去，大卫就动身前往哈列的树林。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 19:9; 撒母耳记上 18:10; 撒母耳记上 20:33"> 当时，扫罗正在基比亚的拉玛，坐在柳树下，手中拿着矛，臣仆侍立在左右。他得知大卫一行人的行踪后，</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 12:16; 撒母耳记上 8:14–15; 撒母耳记上 22:13"> 就对左右的臣仆说：“便雅悯人啊，你们听着！难道耶西的儿子会给你们田地和葡萄园吗？他能立你们做千夫长和百夫长吗？</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:3; 撒母耳记上 23:21; 撒母耳记上 20:13–17"> 为什么你们一同谋害我？我的儿子跟耶西的儿子立约，没有人告诉我。就是今天我的儿子鼓动我的臣仆来谋害我，也没有人关心我，告诉我。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 52:1–9; 撒母耳记上 14:3; 以西结书 22:9"> 以东人多益正站在扫罗的臣仆中，他说：“我在挪伯亲眼看见耶西的儿子到了亚希突的儿子亚希米勒那里。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 27:21; 撒母耳记上 30:8; 撒母耳记上 23:4"> 亚希米勒为他求问耶和华，给他食物，还把非利士人歌利亚的刀给了他。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:15"> 于是，扫罗派人把挪伯的祭司——亚希突的儿子亚希米勒及其家人都召来。他们都来到王面前。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 9:6; 撒母耳记上 22:7; 以赛亚书 65:1"> 扫罗说：“亚希突的儿子，听着！”亚希米勒答道：“我主啊，我在这里。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:8; 路加福音 23:2–5; 阿摩司书 7:10"> 扫罗说：“你为什么和耶西的儿子一同谋害我？你为什么把食物和刀给他，又为他求问耶和华，使他像今天这样背叛我，伺机害我呢？”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 20:32; 撒母耳记上 19:4–5; 撒母耳记上 22:13"> 亚希米勒答道：“王的臣仆中有谁像大卫那样忠心呢？他是王的女婿，又是王的护卫长，在王室中受尊重。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:36; 彼得前书 3:16–17; 哥林多后书 1:12"> 那也不是我第一次为他求问耶和华，求王不要因这事加罪于我或我的家人，因为仆人我对这事一无所知。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 28:15; 但以理书 3:19–20; 列王纪上 19:2"> 王却说：“亚希米勒啊，你和你全家都必死无疑！”</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 1:17; 撒母耳记上 14:45; 列王纪下 1:13–14"> 他就命令身旁的护卫，说：“把这些耶和华的祭司杀掉，因为他们跟大卫同谋，明知道大卫在潜逃，却不来告诉我。”扫罗的臣仆不愿意下手杀害耶和华的祭司。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:10–11; 何西阿书 7:3; 撒母耳记上 2:18"> 扫罗就对多益说：“你去把祭司杀掉！”以东人多益就杀了他们。那天，他下手杀了八十五个穿细麻布以弗得的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 15:3; 何西阿书 10:14; 撒母耳记上 21:1"> 他又把祭司城挪伯的男女老少、牛羊和驴全部用刀杀掉。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:6; 撒母耳记上 30:7; 列王纪上 2:26–27"> 但是，亚希突之子亚希米勒有个儿子亚比亚他逃出去，投奔了大卫。</span>
<span className="v" id="v21" data-v="21"> 亚比亚他把扫罗屠杀耶和华祭司的事告诉了大卫，</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 21:1–9; 诗篇 44:22"> 大卫说：“那天我见以东人多益在那里，就知道他一定会告诉扫罗。是我连累了你父亲一家。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:26; 希伯来书 12:1–3; 约翰福音 10:28–30"> 你就放心留在我这里，不要害怕，想杀你的人，也想要杀我。你在我这里很安全。”</span>
</div>
</div>

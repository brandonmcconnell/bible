## 约柜被掳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 29:1; 撒母耳记上 7:12; 撒母耳记上 5:1"> 撒母耳把耶和华的话传遍了以色列。<br />那时，以色列人去迎战非利士人，他们在以便以谢扎营，非利士人在亚弗扎营。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米哀歌 3:40; 撒母耳记上 17:8; 约书亚记 7:5–8"> 非利士人列阵与以色列人交战，大败以色列人，杀了他们约四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 民数记 10:35; 哥林多前书 10:1–5"> 军队回营后，以色列的长老说：“耶和华今天为什么使我们败在非利士人手下？我们从示罗把耶和华的约柜抬来吧，让它<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“它”或作“祂”。">a</a></sup>与我们同去，好从仇敌手中救我们。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 6:2; 民数记 7:89; 诗篇 80:1"> 于是，他们派人去示罗，把那坐在基路伯天使上的万军之耶和华的约柜抬来。以利的两个儿子何弗尼和非尼哈也随上帝的约柜同来。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:5; 约伯记 20:5; 阿摩司书 6:3"> 以色列人看见耶和华的约柜到了营中，就高声欢呼，声音震动大地。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 32:17–18"> 非利士人听见了欢呼声就说：“希伯来人在营中欢呼什么？”后来他们知道是耶和华的约柜到了营中，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 32:30; 出埃及记 14:25; 出埃及记 15:14–16"> 就害怕起来，说：“有神明到了他们营中，我们大祸临头了，我们从来没有遇过这种事情！</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 9:14; 出埃及记 7:5; 诗篇 78:43–51"> 我们大祸临头了！谁能从这些大能的神明手中救我们？在旷野用各种灾祸毁灭埃及人的就是这些神明。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 16:13; 士师记 13:1; 撒母耳记下 10:12"> 非利士人啊，要刚强，做大丈夫。不然，我们就会成为希伯来人的奴隶，像他们做我们的奴隶一样。我们要做大丈夫，奋力征战。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 26:17; 列王纪下 14:12; 申命记 28:25"> 非利士人和以色列人交战，以色列人落败，纷纷逃回家中。他们伤亡惨重，损失了三万步兵。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 2:34; 诗篇 78:64; 撒母耳记上 2:32"> 上帝的约柜被掳走了，以利的两个儿子何弗尼和非尼哈被杀身亡。</span>
</div>
</div>

## 以利之死

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 7:6; 尼希米记 9:1; 撒母耳记下 15:32"> 当天有一个便雅悯人逃出了战场，他撕裂衣服，头蒙灰尘，来到示罗。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 1:9; 撒母耳记上 4:18; 约书亚记 7:9"> 以利正坐在路旁的座位上观望，因为他心里为上帝的约柜担忧。那个从战场回来的人进城报信后，全城的人都放声大哭。</span>
<span className="v" id="v14" data-v="14"> 以利听见哭喊声，就问：“人们为何喊叫？”那人赶忙告诉他。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 3:2; 诗篇 90:10; 列王纪上 14:4"> 那时，以利已经九十八岁，眼睛因为年老而失明。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 1:4; 撒母耳记上 3:6; 约书亚记 7:19"> 报信的人对以利说：“我今天是从战场逃回来的。”以利问：“我的孩子，情况怎么样？”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 3:11; 撒母耳记上 4:10–11"> 报信的答道：“以色列人被非利士人击溃，伤亡惨重，你的两个儿子何弗尼和非尼哈都死了，上帝的约柜也被掳走了。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 4:21–22; 彼得前书 4:17–18; 诗篇 69:9"> 以利年老体胖，听到上帝的约柜被掳去，就从门边的座位上向后跌倒，颈断身亡。他做以色列的士师四十年。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 以利的儿媳妇、非尼哈的妻子当时怀孕在身，接近产期。她听说上帝的约柜被掳、公公和丈夫都死了，就突然阵痛，生下了孩子。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:17–18; 诗篇 77:2; 约翰福音 16:21"> 在她弥留之际，身旁的妇人对她说：“不要怕，你生了一个男孩。”但她既不理会，也不回答。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 26:8; 耶利米书 2:11; 诗篇 78:61"> 她给孩子取名叫以迦博，意思是：“荣耀离开以色列了。”这是因为上帝的约柜被掳走，她的公公和丈夫都死了。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 137:5–6; 约翰福音 2:17"> 她说：“荣耀离开了以色列，因为上帝的约柜已经被掳走了。”</span>
</div>
</div>

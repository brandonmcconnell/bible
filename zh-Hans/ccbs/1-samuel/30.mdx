## 大卫与亚玛力人交战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 15:7; 撒母耳记上 29:11; 撒母耳记上 27:8–10"> 第三天，大卫率领部下回到洗革拉的时候，发现亚玛力人袭击了南地和洗革拉，攻破了洗革拉城，把全城烧毁，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 27:11; 约伯记 38:11; 诗篇 76:10"> 并掳走了城内的妇女及所有老少，没有杀任何人。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 34:19; 彼得前书 1:6–7; 启示录 3:9"> 大卫和部下来到洗革拉城，看到城被烧毁，妻子儿女都被掳走了，</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 11:4; 民数记 14:1; 士师记 21:2"> 便放声大哭，直哭得精疲力尽。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 25:42–43; 撒母耳记下 2:2; 撒母耳记上 1:2"> 大卫的两个妻子耶斯列人亚希暖和拿八的遗孀迦密人亚比该也一起被掳走了。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 56:3–4; 诗篇 56:11; 诗篇 62:5"> 跟随大卫的人因自己的儿女被掳去，心里很痛苦，商议要用石头打死大卫。大卫深陷困境，但他靠着他的上帝耶和华得到了力量。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪上 2:26; 撒母耳记上 22:20–21; 撒母耳记上 23:2–9"> 大卫吩咐亚希米勒的儿子亚比亚他祭司把以弗得拿来，亚比亚他就拿给他。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:18; 箴言 3:5–6; 撒母耳记上 23:2"> 大卫求问耶和华，说：“我该追赶敌人吗？我能追上他们吗？”耶和华答道：“追赶他们吧，你必能追上他们，救回一切。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 27:2"> 于是，大卫率领六百名部下前去追赶，到了比梭溪，有二百人因为太累而不能过溪，就留在那里。大卫率领其余的四百人继续追赶。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 12:20–21; 申命记 23:7; 马太福音 25:35"> 他们在田野遇见一个埃及人，就把他带到大卫那里。他们给他饼吃，给他水喝，</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 15:19; 撒母耳记上 14:27; 撒母耳记上 30:13"> 还给他一块无花果饼和两个葡萄饼。他吃完后，恢复了体力，因为这人已经三天三夜没吃没喝了。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 2:13; 箴言 12:10; 约伯记 31:13–15"> 大卫问他：“你是谁的仆人？你从哪里来？”他答道：“我是埃及人，是亚玛力人的奴仆。三天前，主人因为我患病把我撇弃了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 1:38; 撒母耳记下 8:18; 列王纪上 1:44"> 我们袭击了基利提的南方，犹大地区和迦勒南部，还烧毁了洗革拉。”</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 2:12; 约书亚记 9:19–20; 以西结书 17:16"> 大卫又问他：“你可以领我去这些袭击者那里吗？”他答道：“你先凭上帝向我起誓，你不杀我，也不把我交给我的主人，我就带你去。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 11:10–13; 撒母耳记下 13:28; 士师记 16:23–30"> 他带着大卫找到那里，见亚玛力人正散布在各处吃喝狂欢，因为他们从非利士和犹大抢夺了很多财物。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 11:11; 诗篇 18:42; 撒母耳记上 15:3"> 大卫率领部下从黎明攻打他们，直到次日黄昏。除了四百个青年骑骆驼逃脱外，亚玛力人全军覆没。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 14:16"> 大卫夺回亚玛力人掳去的一切，包括他的两个妻子。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 91:9–10; 撒母耳记上 30:8; 约伯记 1:10"> 他尽数夺回了被掳去的男女老少和财物，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 30:26; 民数记 31:9–12; 历代志下 20:25"> 也夺了所有的牛羊。他的部下把这些牛羊赶到自己的牲畜前面，说：“这是大卫的战利品。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:1; 撒母耳记上 30:10; 士师记 8:15"> 大卫回到留在比梭溪的那二百名因为太疲乏而没有同去的人那里，他们出来迎接大卫和众随从，大卫也上前问候他们。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:12; 申命记 13:13; 列王纪上 21:10"> 大卫随从中那些恶徒和无赖说：“他们没有跟我们一起去打仗，我们抢回来的东西不应分给他们，只让他们带走自己的妻子和儿女就好了。”</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 8:18; 诗篇 44:2–7; 使徒行传 7:2"> 大卫说：“弟兄们，这一切是耶和华赐给我们的，我们不可不分给他们，因为是耶和华保护我们，把敌人交在了我们手里。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 22:8; 民数记 31:27; 诗篇 68:12"> 谁能接受你们的说法呢？上阵打仗的和看守装备的应该得到一样的待遇。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 16:13"> 从那天开始，大卫就把这原则定为以色列的律例和典章，沿用至今。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 25:27; 创世记 33:11; 以赛亚书 32:8"> 大卫来到洗革拉，把部分战利品送给他的朋友犹大的长老们，说：“这些礼物是从耶和华的敌人那里夺来送给你们的。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 15:48; 约书亚记 19:8; 士师记 1:22–23"> 大卫把礼物送给住在伯特利、南地的拉末、雅提珥、</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 13:16; 约书亚记 15:50; 约书亚记 21:14"> 亚罗珥、息末、以实提莫、</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:16; 撒母耳记上 27:10; 撒母耳记上 15:6"> 拉哈勒、耶拉篾和基尼各城、</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 1:17; 约书亚记 19:4; 约书亚记 15:42"> 何珥玛、歌拉珊、亚挞、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 2:1; 撒母耳记下 15:10; 撒母耳记下 4:1"> 希伯仑以及他和部下所到之处的人。</span>
</div>
</div>

## 扫罗寻驴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 14:51; 使徒行传 13:21; 历代志上 9:36–39"> 有一个便雅悯人名叫基士，很有威望，是亚斐亚的玄孙、比歌拉的曾孙、洗罗的孙子、亚别的儿子。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 6:2; 民数记 13:33; 撒母耳记上 16:7"> 他的儿子扫罗年轻英俊，在以色列人中无人能比，高出其他人一个头。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 5:10; 撒母耳记上 10:2; 士师记 10:4"> 一天，基士丢失了几头驴，他就对儿子扫罗说：“你带一个仆人去找驴吧。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 4:42; 约书亚记 24:33; 约翰福音 3:23"> 他们找遍了以法莲的山区、沙利沙地区、沙琳地区和便雅悯地区，都找不着。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 10:2; 撒母耳记上 1:1; 路加福音 12:11"> 最后，他们来到苏弗，扫罗对仆人说：“我们还是回家去吧，恐怕我父亲不再为驴担心，反而为我们担心。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 13:1; 申命记 33:1; 提摩太前书 6:11"> 但仆人答道：“且慢，这城里有一位上帝的仆人，很受人敬重，他所说的都会应验。我们去找他吧，也许他会告诉我们该到哪里去找驴。”</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 14:3; 列王纪下 8:8; 列王纪下 4:42"> 扫罗答道：“如果去的话，我们有什么可以送给他呢？我们袋里的食物也吃完了，我们还有什么可以送给上帝的仆人呢？”</span>
<span className="v" id="v8" data-v="8"> 仆人说：“我这里还有三克银子，我们可以送给上帝的仆人，请他告诉我们去哪里找驴。”</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 30:10; 列王纪下 17:13; 阿摩司书 7:12"> 从前在以色列，如果人们要求问上帝，他们会说：“让我们去找先见吧。”当时“先知”被称为“先见”。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 5:13–14"> 扫罗说：“好主意，我们去吧。”于是，他们前往上帝仆人住的城。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 24:11; 出埃及记 2:16; 创世记 24:18–20"> 他们走上山坡，正要进城的时候，遇见一些少女出来打水，就问：“先见在这里吗？”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:54; 撒母耳记上 16:2; 撒母耳记上 10:5"> 她们答道：“他在这里，就在你们前面。你们快去吧，他今天刚到城里来，因为今天人们在丘坛献祭。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 6:11; 马太福音 26:26; 路加福音 24:30"> 你们一进城，就会在他上丘坛吃祭物之前遇见他。因为他不来，人们不能吃，他要先为祭物祝谢后，人们才可以吃。你们现在上去吧，一定会遇见他。”</span>
<span className="v" id="v14" data-v="14"> 他们就赶往城内，刚走进城，就看见撒母耳迎面而来，要上丘坛去。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:21; 撒母耳记上 15:1; 约伯记 33:16"> 在扫罗来的前一天，耶和华已经启示撒母耳说：</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 10:1; 诗篇 106:44; 出埃及记 3:7–9"> “明天这个时候，我会从便雅悯境内差遣一个人到你这里，你要膏立他做我以色列子民的首领，他会从非利士人手中把我的子民拯救出来，因为我已听到我子民的呼求，我要施恩给他们。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="何西阿书 13:11; 撒母耳记上 16:6–12; 尼希米记 13:25"> 撒母耳看见扫罗的时候，耶和华就对他说：“这就是我对你说的那个人，他将统治我的子民。”</span>
<span className="v" id="v18" data-v="18"> 扫罗来到在城门口的撒母耳面前，问道：“请你告诉我先见住在哪里？”</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:25; 约翰福音 4:29"> 撒母耳答道：“我就是先见。你先上丘坛去，今天你要和我一起吃饭。明天早上我会送你上路，并把你想知道的事都告诉你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 8:5; 撒母耳记上 12:13; 撒母耳记上 9:3"> 不要再挂念三天前丢失的驴了，已经找到了。以色列人所仰慕的人是谁呢？不是你和你父亲全家吗？”</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:17; 士师记 20:46–48; 诗篇 68:27"> 扫罗答道：“我来自以色列最小的便雅悯支派，我的家族在便雅悯支派中最小，你何出此言？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 43:32; 路加福音 14:10"> 撒母耳带着扫罗和他的仆人来到一个大厅，让他们在请来的三十位客人中坐上座。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 1:5; 创世记 43:34"> 撒母耳对厨师说：“把我交给你的那份祭肉拿来。”</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 24:4; 利未记 7:32–33; 出埃及记 29:22"> 厨师就拿来那块腿肉，摆在扫罗面前。撒母耳说：“这是为你留的，请吃吧。这是我在请客人时特意为你留的。”于是，扫罗和撒母耳一起吃饭。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:9; 申命记 22:8; 撒母耳记下 11:2"> 他们从丘坛下来，回到城里后，撒母耳把扫罗带到屋顶上谈话。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 44:4; 约书亚记 7:13; 士师记 19:28"> 黎明时分，撒母耳呼唤屋顶上的扫罗：“起来吧，我该送你上路了。”于是扫罗起床后，与撒母耳一起往外走。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 15:14–15; 撒母耳记上 20:38–39; 列王纪下 9:5–6"> 他们来到城边的时候，撒母耳让扫罗吩咐仆人先走。仆人离去后，他对扫罗说：“你在这里留一会儿，我要把上帝的话告诉你。”</span>
</div>
</div>

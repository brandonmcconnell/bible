## 大卫迎战歌利亚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:35; 历代志下 28:18; 历代志上 11:13"> 非利士人在犹大的梭哥招聚军队，准备作战。他们在梭哥和亚西加之间的以弗·大悯扎营。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 21:9; 撒母耳记上 17:19"> 扫罗和以色列人也聚集起来在以拉谷安营，摆好阵势准备迎战。</span>
<span className="v" id="v3" data-v="3"> 双方的军队各占一座山对峙，中间隔着山谷。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 11:22; 撒母耳记下 21:16–22; 历代志上 20:4–8"> 非利士营中有个名叫歌利亚的巨人出来讨战。他来自迦特，身高三米，</span>
<span className="v" id="v5" data-v="5"> 头戴铜盔，身穿重达五十七公斤的铠甲，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:45; 历代志下 9:15; 列王纪上 10:16"> 腿上有铜护膝，肩背铜戟。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:19; 撒母耳记上 17:41; 历代志上 11:23"> 戟柄粗如织布机的轴，铁戟头重七公斤。有卫士拿着他的盾牌走在前面。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 8:17; 历代志上 21:3; 撒母耳记上 17:26"> 他站在那里挑战以色列人，高喊：“你们为什么列阵打仗呢？我是非利士人，你们是扫罗的仆人，你们选一个人下来跟我一比高下。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 11:1"> 如果他打得过我，将我杀了，我们就做你们的奴隶。但如果我战胜他，把他杀了，你们就要做我们的奴隶，服侍我们。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 17:25–26; 撒母耳记上 17:45; 撒母耳记上 17:36"> 我今天向以色列军队骂阵，你们找一个人出来跟我一决高下吧！”</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 1:9; 申命记 31:8; 箴言 28:1"> 扫罗和所有以色列人听了非利士人的这些话，都吓得惊恐不已。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 16:10–11; 创世记 35:19; 撒母耳记上 16:18"> 大卫是以法他人耶西的儿子。扫罗执政期间，耶西已经年纪老迈，住在犹大的伯利恒，有八个儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:13; 撒母耳记下 21:21; 撒母耳记上 17:28"> 他的三个儿子已经跟随扫罗去打仗了，他们是长子以利押、次子亚比拿达和三子沙玛。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 16:11; 创世记 25:23"> 大卫年纪最小，他的三个哥哥跟随扫罗期间，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:11; 撒母耳记上 16:19–23"> 他有时去扫罗的军营，有时回伯利恒为他父亲放羊。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:2; 路加福音 4:2"> 这非利士人早晚都出来骂阵，长达四十天。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 25:18; 撒母耳记下 17:28; 路得记 2:14"> 一天，耶西对大卫说：“你带上十公斤烤麦和十个饼，赶快到军营中送给你的哥哥们。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:14; 撒母耳记上 16:20; 撒母耳记下 17:29"> 再带十块奶饼送给他们的千夫长，看望一下他们，带个信儿回来。</span>
<span className="v" id="v19" data-v="19"> 他们跟随扫罗率领的以色列军在以拉谷跟非利士人打仗。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:5; 路加福音 19:43; 以弗所书 6:1–2"> 大卫清早起来把羊交给一个牧人看顾，然后照父亲的吩咐带着食物出发了。他来到军营的时候，大军正呐喊着出战。</span>
<span className="v" id="v21" data-v="21"> 以色列人与非利士人摆好阵势，两军对垒。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 10:5–6; 士师记 18:15; 以赛亚书 10:28"> 大卫把带来的东西交给负责看守的人保管，自己跑到阵中去问候哥哥们。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:8–10"> 他们正在交谈的时候，非利士军中的迦特人歌利亚出来，像往常一样向以色列军骂阵，大卫都听见了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 13:6–7; 利未记 26:36; 以赛亚书 7:2"> 以色列人一看见歌利亚都竞相奔逃，极其害怕。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 15:16; 启示录 2:7; 启示录 3:12"> 以色列人彼此议论说：“看那个人！他是来向以色列军骂阵的。谁要能杀死他，王必有重赏，还会把女儿嫁给他为妻，并免去他父亲家在以色列应缴的赋税。”</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 5:26; 撒母耳记上 11:2; 撒母耳记上 14:6"> 大卫问站在旁边的人：“如果有人杀了这非利士人，洗掉以色列人的羞辱，他会得到什么呢？这个未受割礼的非利士人是谁？竟敢向永活上帝的军队骂阵！”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 17:25"> 他们就把刚才的话一一告诉大卫。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 10:36; 创世记 37:11; 箴言 18:19"> 大卫的长兄以利押听见他跟人说话，就愤怒地对他说：“你来这里做什么？你把旷野的那几只羊交给谁了？我知道你骄傲自大，心怀恶意，你来只是想看打仗。”</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 3:9; 哥林多前书 2:15; 箴言 15:1"> 大卫说：“我做错了什么？我问一下都不行吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 17:26–27"> 他又去问其他人同样的问题，得到了同样的答复。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 22:29"> 有人听见了大卫的话，就去告诉扫罗，扫罗便派人来召大卫。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:18; 申命记 20:1–3; 诗篇 3:6"> 大卫对扫罗说：“大家不要因这个非利士人而丧胆，让仆人去战他。”</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 13:31; 申命记 9:2; 启示录 13:4"> 扫罗说：“你不能去，你年纪还小，他却是一个久经沙场的战士。”</span>
<span className="v" id="v34" data-v="34"> 大卫说：“我一直替父亲放羊，有时候狮子或熊会从羊群中叼走羊，</span>
<span className="v" id="v35" data-v="35" data-xref="阿摩司书 3:12; 提摩太后书 4:17–18; 但以理书 6:22"> 我会去追打它，把羊从它口中救出来。如果它起来攻击我，我就揪着它的胡子把它打死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 17:10; 使徒行传 5:38–39; 罗马书 2:28–29"> 我曾打死过狮子和熊。这未受割礼的非利士人竟敢向永活上帝的军队骂阵，他的下场也必像狮子和熊一样。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 4:17–18; 诗篇 138:7–8; 哥林多后书 1:9–10"> 耶和华曾经从狮子和熊的利爪下拯救我，祂也必从这非利士人手中拯救我。”扫罗对大卫说：“去吧，愿耶和华与你同在。”</span>
<span className="v" id="v38" data-v="38"> 扫罗把自己的战袍给大卫穿上，又给他戴上自己的头盔，穿上自己的铠甲。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亚书 4:6; 哥林多后书 10:4–5; 何西阿书 1:7"> 大卫把刀挎在战袍上，试着走了几步，却不习惯这种装束，就对扫罗说：“我穿着这些无法走路，因为我不习惯。”他便摘下头盔，卸下铠甲，</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 1:27–29; 马太福音 10:10; 士师记 15:15–16"> 然后拿着杖，在溪里捡了五块光滑的石头放进牧人用的袋子，拿着投石器向歌利亚走去。</span>
<span className="v" id="v41" data-v="41"> 歌利亚也迎着大卫走来，卫士拿着他的盾牌走在前面。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 16:12; 撒母耳记上 17:33; 诗篇 123:3–4"> 歌利亚见大卫是个面色红润、相貌英俊的少年，就藐视他。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 9:8; 撒母耳记下 3:8; 撒母耳记上 24:14"> 他对大卫说：“你拿着棍子来战我，难道我是一条狗吗？”他就凭自己的神明咒诅大卫，</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 28:9–10; 箴言 18:12; 列王纪上 20:10–11"> 又说：“你过来，我要把你的肉丢给天上的飞禽和地上的走兽。”</span>
<span className="v" id="v45" data-v="45" data-xref="哥林多后书 10:4; 历代志下 32:8; 哥林多后书 3:5"> 大卫答道：“你是靠刀枪剑戟来攻击我，我是靠万军之耶和华的名，就是你所蔑视的以色列军队的上帝来迎战你。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 52:10; 约书亚记 4:24; 列王纪下 19:19"> 今天，耶和华必把你交在我手中，我必杀死你，砍掉你的头，用非利士军兵的尸体喂飞禽走兽，使普天下都知道以色列有上帝。</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 44:6–7; 撒迦利亚书 4:6; 何西阿书 1:7"> 这里所有的人都必知道耶和华拯救人不靠刀枪，因为祂掌管战争的胜负。祂必把你们交在我们手中。”</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 28:1; 诗篇 27:1"> 歌利亚迎面走来的时候，大卫就飞快地跑上去应战，</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:27–28; 列王纪下 9:24; 列王纪上 22:34"> 他从袋里拿出一块石子用投石器猛力抛去，石子击中歌利亚的额头，嵌了进去，他迎面栽倒在地。</span>
<span className="v" id="v50" data-v="50" data-xref="士师记 15:15; 撒母耳记上 17:39; 撒母耳记上 23:21"> 大卫就这样不用刀剑，只用投石器和一块石子战胜了那个非利士人，杀死了他。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 11:34; 撒母耳记上 21:9; 撒母耳记下 23:21"> 大卫跑到那非利士人身边，从他刀鞘里拔出刀杀了他，并割下他的头颅。非利士人看见自己的英雄死了，纷纷逃跑。</span>
<span className="v" id="v52" data-v="52" data-xref="约书亚记 15:11; 约书亚记 15:33–36; 约书亚记 15:45–46"> 以色列人和犹大人乘势呐喊，追杀非利士人，直追到迦特和以革伦的城门。通往迦特和以革伦的沙拉音大道上到处是非利士人的尸体。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米书 4:20; 列王纪下 7:7–16; 耶利米书 30:16"> 以色列军队追杀非利士人回来，又掳掠了他们的营地。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 16:33; 约书亚记 4:7–8; 撒母耳记上 21:9"> 大卫把那非利士人的头颅带到耶路撒冷，把那人的兵器存放在自己的帐篷中。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 16:21–22; 撒母耳记上 17:58"> 扫罗看见大卫出去迎战歌利亚，就问押尼珥元帅：“押尼珥啊，那少年是谁的儿子？”押尼珥答道：“王啊，我向你发誓，我真的不知道。”</span>
<span className="v" id="v56" data-v="56"> 扫罗王说：“你去查查他是谁的儿子。”</span>
<span className="v" id="v57" data-v="57" data-xref="撒母耳记上 17:54"> 大卫杀了歌利亚回来，押尼珥就把他带到扫罗那里，他手上还拿着那非利士人的头颅。</span>
<span className="v" id="v58" data-v="58" data-xref="撒母耳记上 17:12; 撒母耳记上 16:18–19"> 扫罗问他：“年轻人，你是谁的儿子？”大卫答道：“我是你仆人伯利恒人耶西的儿子。”</span>

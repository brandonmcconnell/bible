## 扫罗打败亚扪人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 12:12; 列王纪上 20:34; 以西结书 17:13"> 亚扪人拿辖率军上来围困基列·雅比，城内的居民对拿辖说：“你与我们立约吧！我们愿意服侍你。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 17:26; 创世记 34:14; 民数记 16:14"> 亚扪人拿辖说：“好，但有一个条件，我要挖去你们每一个人的右眼，作为对全体以色列人的羞辱。”</span>
<span className="v" id="v3" data-v="3"> 雅比的长老说：“请宽限我们七天，我们好派遣使者去以色列全境。要是没有人来营救我们，我们就向你投降。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 2:4; 撒母耳记上 10:26; 撒母耳记上 15:34"> 雅比的使者来到扫罗的家乡基比亚，把他们的情况告诉众人，众人听了放声大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 19:19; 士师记 18:23; 创世记 21:17"> 那时扫罗刚好赶着牛从田间回来，便问道：“发生了什么事？为什么众人都在哭？”百姓把雅比的情况告诉了他。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:10; 撒母耳记上 16:13; 士师记 6:34"> 扫罗听后，上帝的灵便突然降在他身上，他勃然大怒，</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:29; 士师记 20:1; 士师记 21:5–11"> 牵来两头牛，把它们切成碎块，然后派使者把碎块分发到以色列全境，并且宣布：“谁拒绝跟随扫罗和撒母耳出战，他的牛就要被砍成这样。”耶和华使百姓充满恐惧，他们都同心合意地响应。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 1:4–5; 撒母耳记下 24:9; 历代志下 17:12–19"> 扫罗在比色统计以色列人，共有三十万，从犹大来的有三万。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:17"> 他们让雅比的使者回去告诉基列·雅比人，说：“明天中午，你们必得拯救。”使者回去告诉雅比人，他们非常欢喜，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 11:2–3"> 便对亚扪人说：“明天我们会出来归顺你们，你们怎样对待我们都可以。”</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 7:16; 雅各书 2:13; 出埃及记 14:24"> 第二天，扫罗把以色列人分成三队，在黎明时分突袭亚扪人的军营，把他们杀得大败，直到中午才收兵。亚扪人的残兵四散奔逃，没有二人在一处的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 10:27; 路加福音 19:27; 诗篇 21:8"> 以色列人对撒母耳说：“是谁说扫罗不该做王？把他们带来，我们要处死他们。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 19:22; 撒母耳记上 19:5; 出埃及记 14:13"> 扫罗却说：“今天不可杀人，因为今天耶和华拯救了以色列。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 10:8; 撒母耳记上 7:16; 历代志上 12:38–39"> 撒母耳对民众说：“来吧，我们到吉甲去，在那里重新立国。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 10:8; 撒母耳记上 10:17; 历代志上 29:21–24"> 于是，他们来到吉甲，在耶和华面前立扫罗为王，又向耶和华献上平安祭。扫罗和全体以色列人都非常欢喜。</span>
</div>

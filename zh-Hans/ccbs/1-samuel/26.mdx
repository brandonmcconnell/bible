## 大卫再次放过扫罗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 23:19; 诗篇 54:1–7; 约书亚记 15:24"> 西弗人到基比亚见扫罗，说：“大卫正躲在旷野附近的哈基拉山中。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 24:2; 撒母耳记上 13:2; 诗篇 140:4–9"> 扫罗就带领三千以色列精兵到西弗的旷野去追捕大卫。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 23:19; 撒母耳记上 26:1"> 他们在旷野附近路边的哈基拉山上扎营。大卫在旷野听说扫罗追来了，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:16; 约书亚记 2:1"> 就派人去打探消息，得知扫罗的追兵果然已到。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 17:55; 撒母耳记上 17:20; 撒母耳记上 14:50–51"> 大卫来到扫罗的营地，看见了他和他的元帅尼珥的儿子押尼珥睡觉的地方，他睡在军营中间，其他人围绕着他扎营。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 7:10–11; 撒母耳记下 2:18; 创世记 15:20"> 大卫问赫人亚希米勒和洗鲁雅的儿子约押的兄弟亚比筛：“谁愿意跟我到扫罗的营里？”亚比筛答道：“我愿意。”</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:2–3"> 大卫和亚比筛就趁夜间走进扫罗的军营，发现扫罗正在熟睡，他的矛插在地上，靠近他的头，押尼珥和其他人睡在他周围。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 24:4; 撒母耳记上 26:23; 申命记 32:30"> 亚比筛对大卫说：“现在上帝把你的敌人交在你手中了，让我一矛把他钉在地上，决不用刺第二下。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 1:14; 诗篇 105:15; 撒母耳记下 1:16"> 大卫却说：“不要杀他，谁杀害耶和华所膏立的王，都难逃罪责。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:29; 申命记 31:14; 诗篇 37:13"> 我凭永活的耶和华起誓，耶和华必亲手击杀他。他要么寿终而死，要么命丧沙场。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 24:6; 撒母耳记上 24:12; 撒母耳记下 1:14"> 我在耶和华面前绝不敢出手伤害祂所膏立的王。我们拿走他旁边的矛和水瓶吧。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 创世记 15:12; 以赛亚书 29:10"> 大卫拿上扫罗的矛和水瓶便同亚比筛离开了，没有人看见，没有人知道，他们都在沉睡，没有人醒来，因为耶和华使他们都熟睡了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 24:8; 士师记 9:7"> 大卫爬上营地对面的山坡，远远地站在山顶上，与他们相距很远。</span>
<span className="v" id="v14" data-v="14"> 他呼喊扫罗的士兵和尼珥的儿子押尼珥：“押尼珥，你回答我！”押尼珥问道：“你是谁，竟敢在王面前喊叫？”</span>
<span className="v" id="v15" data-v="15"> 大卫说：“你不是勇士吗？在以色列有谁比得上你呢？有人来刺杀你的王你的主，你为何没有保护他呢？</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 79:11; 撒母耳记下 12:5; 撒母耳记上 26:9"> 你失职了。我凭永活的耶和华起誓，你们都该死。因为你们没有保护你们的主——耶和华所膏立的王。你看看王头旁的矛和水瓶在哪里？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 24:16; 撒母耳记上 24:8"> 扫罗听出是大卫的声音，就说：“我儿大卫！是你吗？”大卫答道：“我主我王啊，是我。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 24:9; 撒母耳记上 24:11–14; 约翰福音 10:32"> 我主为什么又要追杀仆人呢？我做错了什么，犯了什么罪？</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:16; 撒母耳记下 16:11; 撒母耳记下 20:19"> 我主我王，请听仆人说，如果是耶和华使你与我作对，愿祂悦纳我献上的祭物；如果这是出于人的主意，愿他们在耶和华面前受咒诅。因为他们赶我离开耶和华所赐的产业，叫我去供奉其他神明。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 24:14; 马太福音 26:55; 撒母耳记上 25:29"> 求你不要让我死在远离耶和华的异乡！以色列王为何要像在山上猎杀鹧鸪一样追捕一只跳蚤呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:24; 撒母耳记上 24:17; 出埃及记 9:27"> 扫罗说：“我犯罪了。我儿大卫，你回来吧，我不会再伤害你，因为你今日保存了我的性命。我真是糊涂，犯了大错。”</span>
<span className="v" id="v22" data-v="22"> 大卫答道：“王的矛在这里，请派一个人来拿回去吧。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 62:12; 撒母耳记上 24:6–7; 诗篇 18:20–26"> 耶和华奖赏公义、信实的人。今天耶和华把你交在我手中，但我不愿下手伤害耶和华所膏立的王。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 5:7; 哥林多后书 1:9–10; 诗篇 54:7"> 我今天保存了你的性命，愿耶和华也保存我的性命，救我脱离一切患难。”</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 24:9–10; 箴言 26:25; 撒母耳记上 24:19"> 扫罗对大卫说：“我儿大卫，愿你蒙福。你一定能建功立业，战胜仇敌。”于是，大卫起身离开，扫罗也回家去了。</span>
</div>

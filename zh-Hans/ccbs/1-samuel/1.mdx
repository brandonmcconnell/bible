## 撒母耳的出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 6:34; 历代志上 6:25–27; 撒母耳记上 1:19"> 有一个以法莲人名叫以利加拿，住在以法莲山区的拉玛·琐非城。他是苏弗的玄孙、托户的曾孙、以利户的孙子、耶罗罕的儿子。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 16:1–2; 士师记 13:2; 创世记 29:23–29"> 他有两个妻子，一个叫哈娜，一个叫毗尼娜。毗尼娜有儿有女，哈娜却无儿无女。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 2:41; 约书亚记 18:1; 申命记 12:5–7"> 以利加拿每年都从家乡到示罗去敬拜万军之耶和华，献上祭物。当时以利的两个儿子何弗尼和非尼哈在那里做耶和华的祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:17–18; 申命记 16:11; 申命记 12:5–7"> 每逢献祭的日子，以利加拿就会把祭肉分给毗尼娜和她的儿女。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:2; 创世记 29:30–31; 创世记 45:22"> 但他会给哈娜双份祭肉，因为他爱哈娜，虽然耶和华使她不能生育。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 6:14; 约伯记 24:21; 利未记 18:18"> 毗尼娜见耶和华使她不能生育，便常常刺激她、气她。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:19"> 年复一年都是这样。每年来到耶和华的殿时，毗尼娜总是惹她伤心哭泣，以致她吃不下饭。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 4:15; 约伯记 6:14; 以赛亚书 54:6"> 她的丈夫以利加拿对她说：“哈娜，你为什么哭？为什么不吃饭？为什么心里难过？有我不是比有十个儿子更好吗？”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 3:3; 诗篇 27:4; 诗篇 5:7"> 一天，他们在示罗吃完饭后，哈娜站起来。当时，祭司以利正坐在耶和华殿门口的座位上。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 7:11; 路加福音 22:44; 约伯记 10:1"> 哈娜心中愁苦，一边向耶和华祷告一边伤心地哭泣。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 13:5; 民数记 6:5; 创世记 29:32"> 她向上帝许愿说：“万军之耶和华啊，如果你眷顾婢女的痛苦，不忘记婢女，赐给婢女一个儿子，我必让他终生事奉你，永不剃他的头<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="参见民数记6章。">a</a></sup>。”</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:17; 雅各书 5:16; 路加福音 18:1"> 哈娜在耶和华面前不住地祷告，以利注视着她的嘴唇。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 8:26; 使徒行传 2:13; 创世记 24:42–45"> 哈娜在心中默祷，只动嘴唇，不出声音，以利以为她喝醉了，</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 4:25; 约伯记 8:2; 箴言 6:9"> 便对她说：“你要醉到什么时候呢？醒醒酒吧！”</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 62:8; 耶利米哀歌 2:19; 诗篇 42:4"> 哈娜答道：“我主啊，我没有喝醉，我淡酒和烈酒都没有喝。我是心里非常愁苦，在耶和华面前倾诉心事。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 2:12; 约伯记 6:2–3; 马太福音 12:34–35"> 请不要以为我是堕落的女人，我充满悲伤和痛苦，所以一直在祷告。”</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 5:34; 士师记 18:6; 诗篇 20:3–5"> 以利说：“你安心地回去吧，愿以色列的上帝答应你的祈求。”</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 2:13; 罗马书 15:13; 传道书 9:7"> 哈娜说：“愿婢女在你面前蒙恩。”于是，她就去吃饭，不再愁容满面了。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 21:1; 创世记 30:22; 撒母耳记上 1:11"> 第二天，以利加拿一家清早起来敬拜耶和华，然后回到自己的家乡拉玛。以利加拿与哈娜同房，耶和华顾念哈娜，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:51–52; 马太福音 1:21; 出埃及记 2:10"> 使她怀孕。她后来生了一个儿子，给孩子取名叫撒母耳，因为她说：“他是我向耶和华求来的。”</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 1:3; 申命记 12:11; 约书亚记 24:15"> 第二年，以利加拿带全家人前往示罗，向耶和华献年祭并还所许的愿。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 1:28; 撒母耳记上 1:11; 路加福音 2:22"> 哈娜没有跟他们同去，她告诉丈夫说：“孩子断奶以后，我会把他带去献给耶和华，让他永远住在那里。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 7:25; 路加福音 11:27; 创世记 21:7–8"> 以利加拿说：“就依你的意思吧。可以等孩子断了奶再去。愿耶和华成就祂的应许。”于是，她就留在家中哺养孩子，直到孩子断奶。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 15:9–10; 约书亚记 18:1; 撒母耳记上 4:3–4"> 孩子断奶以后，她就把年幼的孩子带到示罗耶和华的殿，并带去三头公牛、十公斤面粉和一袋酒。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 18:15–16; 路加福音 2:22"> 他们宰了一头公牛后，就把孩子带到以利面前。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 4:30; 列王纪下 2:4; 列王纪下 2:6"> 哈娜说：“我主啊，我敢在你面前起誓，我就是那一次站在你这里向耶和华祈求的妇人。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰一书 5:15; 诗篇 118:5; 马太福音 7:7"> 我求耶和华赐给我这个孩子，祂应允了我的祈求。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 24:26; 创世记 24:52; 提摩太后书 3:15"> 现在，我将他献给耶和华，让他终身事奉耶和华。” 他便在那里敬拜耶和华。</span>

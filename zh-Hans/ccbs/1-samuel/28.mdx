## 扫罗求问巫婆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 17:1; 撒母耳记上 29:1–3; 撒母耳记上 7:7"> 非利士人召集大军与以色列人交战。亚吉对大卫说：“你应该明白，你和部下要随我一起出战。”</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:9; 撒母耳记下 16:16–19; 撒母耳记上 27:10"> 大卫答道：“仆人愿意效劳。”亚吉说：“很好！你就终生做我的护卫吧。”</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 19:31; 撒母耳记上 25:1; 利未记 20:27"> 那时撒母耳已经死了，以色列举国都为他哀悼，把他葬在他的家乡拉玛。当时，扫罗已把所有占卜和行巫术的都逐出了以色列。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 31:1; 约书亚记 19:18; 列王纪下 4:8"> 非利士人集合起来，在书念扎营，扫罗率领以色列军队在基利波扎营。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 57:20–21; 但以理书 5:6; 以赛亚书 21:3–4"> 扫罗看见非利士军队声势浩大，吓得胆战心惊，</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 12:6; 撒母耳记上 14:37; 耶利米哀歌 2:9"> 就求问耶和华，但耶和华没有借着梦、乌陵或先知回答他。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:16; 约书亚记 17:11; 历代志上 10:13"> 于是，扫罗命令臣仆找一个巫婆来，好求问她。臣仆在隐·多珥找到一个巫婆。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:19; 历代志上 10:13; 列王纪上 22:30"> 扫罗乔装打扮，由两个人陪同乘夜赶到那妇人家里，说：“请你用法术把我要求问的亡灵招上来吧。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 28:3; 列王纪下 5:7; 撒母耳记下 18:13"> 妇人对他说：“你知道扫罗铲除了国内占卜的和行巫术的，你为何来陷害我，置我于死地？”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 14:11; 撒母耳记上 19:6; 申命记 18:10–12"> 扫罗凭耶和华向妇人起誓，说：“我凭永活的耶和华起誓，你必不会因为此事而受到惩罚。”</span>
<span className="v" id="v11" data-v="11"> 妇人问道：“你想让我招谁上来呢？”扫罗答道：“招撒母耳上来。”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 28:3; 列王纪上 14:5"> 妇人看见了撒母耳，就惊叫起来，对扫罗说：“你是扫罗，你为什么骗我呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 82:6–7; 约翰福音 10:34–35; 出埃及记 22:28"> 扫罗王对她说：“不要害怕，你看见什么了？”妇人说：“我看见一个灵从地里上来。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 15:27; 列王纪下 2:8; 撒母耳记上 24:8"> 扫罗说：“他是什么模样？”妇人说：“是个身披长袍的老人。”扫罗知道是撒母耳，便俯伏在地，向他下拜。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:23–26; 撒母耳记上 28:6; 撒母耳记上 18:12"> 撒母耳对扫罗说：“你为什么打扰我，招我上来呢？”扫罗答道：“我深陷困境，非利士人与我们交战，上帝也撇弃了我，不再借着先知或梦来回答我。因此，我只好招你上来，好告诉我该怎么办。”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 6:27; 耶利米哀歌 2:5; 诗篇 68:1–3"> 撒母耳说：“既然耶和华已经离弃了你，与你为敌，你为什么还来问我？</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 15:27–29; 撒母耳记上 16:13; 撒母耳记上 13:13–14"> 耶和华应验了祂借着我所说的预言，祂已把你的国权夺去，交给了你的同胞大卫。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:9; 列王纪上 20:42; 诗篇 50:21–22"> 耶和华今天这样对待你，是因为你没有听从祂的吩咐，没有把祂憎恶的亚玛力人灭绝。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:5; 耶利米书 28:16–17; 列王纪上 22:20"> 耶和华必把你和以色列人交在非利士人手里，明天你和你的儿子们必跟我在一起了。耶和华必把以色列的军队交在非利士人手里。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 28:5; 约伯记 26:2; 约伯记 15:20–24"> 扫罗听了撒母耳的话，顿时吓得浑身僵直，倒在地上。他因一天一夜没有进食，已经毫无力气。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 12:3; 约伯记 13:14; 撒母耳记上 19:5"> 妇人到扫罗跟前，看见他惊恐万分，就对他说：“婢女冒着生命危险服从你的命令，照你的吩咐做了。</span>
<span className="v" id="v22" data-v="22"> 现在，请你听婢女的话，让我给你一些食物吃，你好有体力赶路。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 21:4; 路加福音 24:29; 路加福音 14:23"> 扫罗不肯，说：“我不吃。”他的随从和妇人再三劝告，他才同意了，从地上起来坐到床上。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:23; 创世记 18:7–8"> 妇人连忙宰了家中一只小肥牛，又和面烤了无酵饼，</span>
<span className="v" id="v25" data-v="25"> 摆在扫罗和他的随从面前，他们吃完后，当晚就离开了。</span>

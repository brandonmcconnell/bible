## 立扫罗为王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 16:13; 诗篇 78:71; 撒母耳记上 9:16"> 撒母耳把一瓶膏油倒在扫罗的头上，亲吻他，说：“耶和华已经膏立你做祂子民的首领。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:3–5; 创世记 35:19–20; 约书亚记 18:28"> 你今天离开我以后，会在便雅悯境内的谢撒、靠近拉结的墓旁遇见两个人。他们会告诉你，你要找的驴已经找到，现在你父亲不再为驴担心，反为你担心，说，‘我该怎样找到我的儿子呢？’</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:22"> 你继续往前走，会在他泊的橡树那里遇见三个人。他们要到伯特利去敬拜上帝，一个牵着三只山羊羔，一个带着三个饼，一个拿着一皮袋酒。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 18:15"> 他们会问候你，送你两个饼，你要把饼收下。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 3:15; 撒母耳记上 13:3; 撒母耳记上 19:20"> 此后，你会去上帝的山，那里有非利士人的驻军。你一进城，就会遇见一群先知从丘坛下来，前面有人鼓瑟、敲鼓、吹笛、弹琴，先知们会说预言。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:10; 撒母耳记上 19:23–24; 民数记 11:25"> 耶和华的灵会突然降在你身上，你就会跟他们一起说预言，那时，你会变成另一个人。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:12; 约书亚记 1:5; 以赛亚书 7:14"> 这些兆头临到你的时候，你就要见机行事，因为上帝与你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 11:14–15; 撒母耳记上 13:4; 撒母耳记上 13:8–15"> 你先到吉甲去，在那里等我七天，我会到那里献燔祭和平安祭。我到了以后会告诉你怎么做。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 38:7–8; 撒母耳记上 10:2–6; 士师记 7:11"> 扫罗转身离开撒母耳，上帝使他心灵焕然一新。撒母耳所说的兆头那天都应验了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 10:5–6; 撒母耳记上 19:20–24"> 扫罗和他的仆人来到上帝的山，遇见了一群先知。上帝的灵突然降在扫罗身上，他就在他们中间说起预言来。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 19:24; 约翰福音 7:15; 马太福音 13:54–55"> 以前认识扫罗的人看见他跟先知一起说预言，就议论说：“基士的儿子怎么了？扫罗也做了先知吗？”</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 54:13; 约翰福音 6:45; 雅各书 1:17"> 当地的一个人说：“他们的父亲是谁？”自此以后，“扫罗也做了先知吗”就成为一句谚语。</span>
<span className="v" id="v13" data-v="13"> 扫罗说完预言以后，就去了丘坛。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 14:50; 列王纪下 5:25; 撒母耳记上 9:3–10"> 扫罗的叔叔问他和他的仆人：“你们到哪里去了？”扫罗答道：“我们去找驴，没找着，就去见撒母耳。”</span>
<span className="v" id="v15" data-v="15"> 扫罗的叔叔说：“请把撒母耳对你们说的话告诉我。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士师记 14:6; 撒母耳记上 9:20"> 扫罗答道：“他肯定地告诉我们驴已经找到了。”但扫罗没有把撒母耳提到的立王之事告诉叔叔。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士师记 20:1; 撒母耳记上 7:5–6"> 撒母耳把以色列人招聚到米斯巴耶和华那里，</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:8–9; 尼希米记 9:27–28; 士师记 2:1"> 对他们说：“以色列的上帝耶和华这样说，‘我带你们出埃及，从埃及人和压迫你们的各国之人手中救出你们。’</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 12:12; 撒母耳记上 8:19; 约书亚记 24:1"> 但你们现在却背弃了拯救你们脱离一切灾难和困苦的上帝，竟然对祂说，‘我们要你立一位王来统治我们。’所以你们现在就按着支派宗族站在耶和华面前吧！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:16–18; 使徒行传 1:24–26; 撒母耳记上 14:41"> 撒母耳让以色列各支派来抽签，结果抽中了便雅悯支派。</span>
<span className="v" id="v21" data-v="21"> 然后撒母耳让便雅悯支派的各宗族来抽，结果抽中了玛特利家族，最后又抽中了基士的儿子扫罗。众人找扫罗，却找不到他。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 27:21; 士师记 20:18; 撒母耳记上 23:2–4"> 他们便求问耶和华，说：“这人来了吗？”耶和华说：“他来了，躲在物品堆中。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 9:2; 撒母耳记上 16:7; 撒母耳记上 17:4"> 他们就跑去把扫罗请来。扫罗站在百姓当中，高出众人一头。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:25; 列王纪上 1:39; 撒母耳记下 21:6"> 撒母耳对百姓说：“这就是耶和华为你们选的人。在以色列没有人能比得上他。”众人高呼：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 8:11–18; 申命记 17:14–20; 罗马书 13:1–7"> 撒母耳向百姓说明做君王的权利和责任，又把这些都记在册子上，放在耶和华面前，然后让百姓各自回家。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 11:4; 约书亚记 18:28; 撒母耳记上 15:34"> 扫罗返回基比亚自己的家时，有一群被上帝感动的勇士跟随他。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 13:13; 历代志下 17:5; 列王纪上 10:25"> 但有一些市井之徒说：“这人怎能救我们？”就鄙视他，没有送礼物给他，但扫罗没有说什么。</span>
</div>
</div>

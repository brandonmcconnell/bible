<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="罗马书 2:25–29; 创世记 25:32; 传道书 6:11"> 那么，犹太人有什么长处呢？割礼有什么价值呢？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 9:4; 使徒行传 7:38; 哥林多前书 9:17"> 其实在各方面有很多好处！首先，上帝的圣言托付给了犹太人。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 2:13; 希伯来书 4:2; 罗马书 9:6"> 虽然有些人不信，但那有什么关系呢？难道上帝的信实可靠会因他们的不信而化为无有吗？</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 51:4; 诗篇 116:11; 加拉太书 2:17"> 当然不会！纵然人人都撒谎，上帝仍然真实可靠。正如圣经上说：<br /><span className="pl pl-1">“你的判语证明你是公义的；</span><br /><span className="pl pl-1">你虽被人控告，却终必得胜。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇51:4。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 6:19; 加拉太书 3:15; 罗马书 9:18–20"> 我姑且用人的观点说：“如果我们的不义反衬出上帝的公义，我们该怎么说呢？上帝向我们发怒是祂不公正吗？”</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:25; 使徒行传 17:31; 约伯记 8:3"> 当然不是！若是这样，上帝怎么能审判这世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:4; 罗马书 9:19–20; 使徒行传 13:27–29"> 也许有人说：“如果我们的虚谎凸显出上帝的真实，增加祂的荣耀，为什么祂还要把我们当作罪人审判呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 6:1; 罗马书 6:15; 罗马书 5:20"> 为什么不干脆说“我们作恶吧，好成就善事”？有人毁谤我们，说我们传这种道理。这些人受审判是罪有应得！</span>
</div>
</div>

## 没有义人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:22; 罗马书 6:15; 以赛亚书 65:5"> 那么，我们犹太人比别人优越吗？绝对不是！我们已经说过，无论是犹太人还是希腊人，所有的人都在罪的权势之下。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 53:1–3; 诗篇 14:1–3; 罗马书 3:23"> 正如圣经上说：<br /><span className="pl pl-1">“没有义人，连一个也没有，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 14:2–4; 诗篇 53:2; 提多书 3:3"> <span className="pl pl-1">没有人明白，没有人寻求上帝。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 14:3; 传道书 7:20; 以赛亚书 64:6"> <span className="pl pl-1">人人偏离正道，变得毫无价值。</span><br /><span className="pl pl-1">无人行善，连一个也没有。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇14:1‑3；53:1‑3；传道书7:20。">b</a></sup><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 5:9; 诗篇 140:3; 马太福音 23:27–28"> <span className="pl pl-1">他们的喉咙是敞开的坟墓，</span><br /><span className="pl pl-1">舌头上尽是诡诈，</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇5:9。">c</a></sup><br /><span className="pl pl-1">嘴唇有蛇的毒液，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇140:3。">d</a></sup><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 10:7; 诗篇 109:17–18; 诗篇 59:12"> <span className="pl pl-1">满口咒诅，言语恶毒；</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="诗篇10:7。">e</a></sup><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">杀人流血，脚步飞快；</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">所到之处，大肆毁灭；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 59:8; 罗马书 5:1; 路加福音 1:79"> <span className="pl pl-1">他们不知道平安之路；</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以赛亚书59:7、8。">f</a></sup><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">他们眼中对上帝毫无畏惧。”</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="诗篇36:1。">g</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 3:10; 加拉太书 3:22–23; 罗马书 2:12–18"> 我们知道律法所讲的都是针对律法之下的人，好叫所有的人都无话可说，使全世界都伏在上帝的审判之下。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:16; 使徒行传 13:39; 罗马书 3:28"> 因为无人能够靠遵行律法被上帝称为义人，律法的本意是要使人知罪。</span>
</div>
</div>

## 因信称义

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 10:43; 耶利米书 33:16; 腓立比书 3:9"> 但如今，上帝的义在律法以外显明出来，有律法和众先知做见证。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 10:12; 加拉太书 3:28; 罗马书 8:1"> 人只要信耶稣基督，就可以被上帝称为义人，没有一个人例外。</span>
<span className="v" id="v23" data-v="23" data-xref="传道书 7:20; 约翰一书 1:8–10; 罗马书 3:9"> 因为世人都犯了罪，亏缺上帝的荣耀，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 1:18–19; 提多书 3:5–7; 歌罗西书 1:14"> 但蒙上帝的恩典，靠着基督耶稣的救赎，就被无条件地称为义人。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:23–24; 彼得前书 1:18–20; 约翰一书 4:10"> 上帝借基督耶稣所流的血使祂成为赎罪祭，让人凭信心领受。这是为了显明上帝的义，因为祂用忍耐的心宽容人过去的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:4; 罗马书 4:5; 罗马书 3:30"> 好在现今显明祂的义，使人知道祂是公义的，祂也称信耶稣的为义人。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 4:2; 罗马书 2:23; 哥林多前书 1:29–31"> 既然如此，我们哪里能夸口呢？当然没有可夸的。靠什么方法让人不能夸口呢？靠遵行律法吗？不是！是靠信主的方法。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 2:16; 加拉太书 3:8; 提多书 3:7"> 因为我们坚信人被称为义人是借着信，不是靠遵行律法。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 3:11; 以弗所书 3:6; 撒迦利亚书 2:11"> 难道上帝只是犹太人的上帝吗？祂不也是外族人的上帝吗？祂当然也是外族人的上帝。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:8; 加拉太书 3:20; 腓立比书 3:3"> 因为上帝只有一位，祂本着信称受割礼的人为义人，也本着信称未受割礼的人为义人。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:21; 马太福音 5:17; 罗马书 13:8–10"> 这么说来，我们是借着信废掉上帝的律法吗？当然不是！我们反倒是巩固律法。</span>
</div>
</div>

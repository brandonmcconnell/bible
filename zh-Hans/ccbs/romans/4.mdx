## 亚伯拉罕的榜样

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 51:2; 罗马书 4:16; 哥林多后书 11:22"> 那么，从我们的先祖亚伯拉罕身上，我们学到什么呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 1:31; 哥林多后书 11:30; 腓立比书 3:9"> 亚伯拉罕如果是因行为而被称为义人，就可以夸口了，但他在上帝面前没有可夸的。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 15:6; 雅各书 2:23; 加拉太书 3:6–8"> 圣经上不是说“亚伯拉罕信上帝，就被算为义人”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记15:6。">a</a></sup>吗？</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 11:6; 罗马书 9:32; 罗马书 11:35"> 人工作得来的工钱不算是恩典，是应得的。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:9; 罗马书 3:22; 提多书 3:3–7"> 但人不靠行为，只信称不敬虔之人为义人的上帝，他就因信而被算为义人。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 1:9; 腓立比书 3:9; 哥林多前书 1:30"> 大卫也说不靠行为被上帝算为义人的人有福了，他说：</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 32:1–2; 诗篇 130:3–4; 路加福音 7:47–50"> “过犯得到赦免、罪恶被遮盖的人有福了。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 32:2; 彼得前书 2:24; 哥林多后书 5:19–20"> 不被主算为有罪的人有福了。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇32:1、2。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:14; 歌罗西书 3:11; 加拉太书 3:26–28"> 那么，这种福分只给受割礼的人吗？还是也给没有受割礼的人呢？因为我们说，亚伯拉罕信上帝，就被算为义人。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 6:15; 加拉太书 5:6; 创世记 17:10"> 他究竟是怎么被算为义人的呢？是他受割礼以前呢？还是以后呢？不是以后，而是以前。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:22; 路加福音 19:9; 哥林多后书 1:22"> 他后来受割礼只不过是一个记号，表明他在受割礼前已经因信被称为义人了。他因此成为一切未受割礼的信徒之父，使这些信徒也可以被算为义人。</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 约翰福音 8:39–40; 箴言 2:20"> 他也做了受割礼之人的父，这些人不只是受了割礼，还跟随我们先祖亚伯拉罕的脚步，效法他在未受割礼时的信心。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 3:29; 创世记 22:17–18; 创世记 28:14"> 上帝应许将世界赐给亚伯拉罕和他的子孙，不是因为亚伯拉罕遵行了律法，而是因为他因信被称为义人。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:18–24; 腓立比书 3:9; 罗马书 4:16"> 如果只有遵行律法的人才可以承受应许，信心就没有价值，上帝的应许也就落了空。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:13; 加拉太书 3:10; 罗马书 3:19–20"> 因为有律法，就有刑罚；哪里没有律法，哪里就没有违法的事。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 3:24–26; 以弗所书 2:8; 加拉太书 3:22"> 所以，上帝的应许是借着人的信心赐下的，好叫这一切都是出于上帝的恩典，确保应许归给所有亚伯拉罕的子孙，不单是律法之下的人，也包括一切效法亚伯拉罕信心的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:28; 创世记 17:4–5; 约翰福音 5:21"> 亚伯拉罕在上帝面前是我们所有人的父，正如圣经上说：“我已立你为万族之父。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="创世记17:5。">c</a></sup>他所信的上帝是能够使死人复活、使无变有的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:24; 创世记 15:5–6; 使徒行传 27:25"> 他在毫无指望的情况下仍然满怀盼望地相信上帝的应许，因而成为“万族之父”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="创世记15:5。">d</a></sup>，正如上帝的应许：“你的后裔必这么多。”</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:11–19; 罗马书 4:20–21; 创世记 17:17"> 那时他将近百岁，知道自己的身体如同已死，撒拉也已经不能生育，但他的信心仍然没有动摇。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前书 16:13; 但以理书 10:19"> 他没有因不信而怀疑上帝的应许，反倒信心更加坚定，将荣耀归给上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> 完全相信上帝必能实现祂的应许。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 4:6; 罗马书 4:3"> 所以，他因信被算为义人。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 10:11; 罗马书 15:4; 哥林多前书 10:6"> “他被算为义人”这句话不单单是写给他的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:24; 彼得前书 1:21; 使徒行传 13:30"> 也是写给我们的。我们相信使我们主耶稣从死里复活的上帝，所以必被算为义人。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 4:9–10; 以赛亚书 53:5–6; 哥林多后书 5:21"> 耶稣受害而死是为了我们的过犯，祂复活是为了使我们被称为义人。</span>
</div>

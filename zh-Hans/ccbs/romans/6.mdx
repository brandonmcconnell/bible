## 与基督同死同活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:16; 加拉太书 5:13; 罗马书 6:15"> 那么，我们该怎么说呢？我们可以继续犯罪，使恩典更丰富吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:9; 歌罗西书 3:3; 罗马书 7:4"> 当然不可！我们既然向罪死了，岂可继续活在罪中？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:27; 加拉太书 2:20–21; 罗马书 6:8"> 难道你们不知道，我们受洗归属基督耶稣是和祂一同死吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:17; 歌罗西书 3:10; 以弗所书 4:22–24"> 所以，我们借着洗礼和祂同死同埋葬了，为要行事为人有新生命的样式，正如基督借着父的荣耀从死里复活一样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:10–11; 哥林多后书 4:10; 歌罗西书 2:12"> 我们如果已经在基督的死亡上与祂联合，也必在祂的复活上与祂联合。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:20; 以弗所书 4:22; 加拉太书 5:24"> 我们知道，我们的旧人已经和祂一同被钉在十字架上，使辖制我们身体的罪失去力量，使我们不再做罪的奴隶。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:1; 歌罗西书 3:1–3; 罗马书 7:4"> 因为死去的人已经脱离了罪。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 2:11–12; 歌罗西书 3:3–4; 哥林多后书 4:10–14"> 我们如果已经与基督同死，相信也必与祂同活。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:14; 启示录 1:18; 使徒行传 2:24–28"> 因为我们知道，基督既然从死里复活了，就不会再死，死亡也不能再控制祂。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 4:6; 彼得前书 3:18"> 祂死，是向罪死，只死一次；祂活，却是向上帝活着。</span>
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 3:3–5; 哥林多前书 6:20; 罗马书 6:2"> 同样，你们在基督耶稣里应当看自己是向罪死了，向上帝活着。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:16; 罗马书 6:16; 罗马书 8:13"> 所以，不要让罪辖制你们必死的身体，使你们顺从身体的私欲。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:1; 罗马书 6:16; 歌罗西书 3:5"> 也不要将你们的肢体献给罪作不义的工具，而是要像一个从死里复活的人将自己献给上帝，把你们的肢体献给上帝作义的工具。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 罗马书 8:2; 罗马书 7:4–11"> 罪不能再主宰你们，因为你们已经不在律法之下，而是在恩典之中。</span>
</div>
</div>

## 做义的奴仆

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 2:11–14; 以弗所书 2:8–10; 罗马书 6:1–2"> 那么，我们在恩典之中，不在律法之下，就可以任意犯罪吗？当然不可！</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 8:34; 马太福音 6:24; 约书亚记 24:15"> 你们难道不明白吗？你们献身为奴服从谁，就是谁的奴隶。做罪的奴隶，结局是死亡；做上帝的奴仆，就被称为义人。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:9; 提摩太后书 1:13; 罗马书 1:8"> 感谢上帝！你们从前虽然做过罪的奴隶，现在却衷心服从了所传给你们的教导，</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 6:22; 罗马书 8:2; 加拉太书 5:1"> 从罪中得到释放，成为义的奴仆。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 6:13; 彼得前书 4:2–4; 歌罗西书 3:5–7"> 因为你们有人性的软弱，我就用简单的话向你们解释。以前你们将肢体献给肮脏不法的事，任其奴役，助长不法。现在你们要将肢体献给义，为义效劳，成为圣洁的人。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:16–17; 约翰福音 8:34"> 你们做罪的奴隶时，不受义的约束，</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 1:32; 罗马书 7:5; 罗马书 6:23"> 做了现在引以为耻的事，得到什么益处呢？那些事只能导致死亡！</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 罗马书 6:18; 罗马书 8:2"> 但现在你们已从罪中得到释放，做了上帝的奴仆，结果使你们圣洁，最终得到永生。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:36; 罗马书 5:12; 雅各书 1:15"> 因为罪的代价就是死亡，而上帝借着我们的主基督耶稣赐下的礼物则是永生。</span>
</div>
</div>

</div>

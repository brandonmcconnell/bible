## 与上帝和好

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 32:17; 罗马书 15:13; 约翰福音 16:33"> 我们既然因信被称为义人，就借着我们的主耶稣基督与上帝和好了。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 2:18; 以弗所书 3:12; 罗马书 12:12"> 我们又靠着祂，借着信进入现在所站的这恩典中，欢欢喜喜地盼望分享上帝的荣耀。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 1:2–3; 雅各书 1:12; 彼得前书 3:14"> 不但如此，我们在苦难中也欢喜，因为知道苦难使人生忍耐，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 5:10; 雅各书 1:12; 哥林多后书 4:8–12"> 忍耐生品格，品格生盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 4:6; 以弗所书 3:16–19; 腓立比书 1:20"> 这种盼望不会落空，因为上帝的爱借着所赐给我们的圣灵已倾注在我们心中。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 2:1–5; 罗马书 5:8; 歌罗西书 2:13"> 当我们还软弱无助的时候，基督就在所定的日期为罪人死了。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:13; 约翰一书 3:16; 罗马书 16:4"> 为义人死，是罕见的；为好人死，也许有敢做的；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:13; 约翰福音 3:16; 罗马书 5:6"> 但基督却在我们还做罪人的时候为我们死！上帝的爱就这样显明了。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 罗马书 8:1; 以弗所书 2:13"> 现在，我们既然因基督所流的血被称为义人，岂不更要靠着祂免受上帝的烈怒吗？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:18–19; 哥林多后书 4:10–11; 罗马书 8:32"> 我们如果还与上帝为敌的时候，尚且可以借着祂儿子的死亡与祂和好，和好之后岂不更要借着祂儿子的生命得到拯救吗？</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 5:18–19; 罗马书 5:10; 以赛亚书 61:10"> 不但如此，我们借着主耶稣基督与上帝和好之后，还要借着祂以上帝为乐。</span>
</div>
</div>

## 亚当与基督

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 15:21–22; 罗马书 5:19; 罗马书 6:23"> 因此，罪怎样从一个人进入世界并带来死亡，死亡也怎样临到世人，因为世人都犯了罪。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 4:15; 哥林多前书 15:56; 约翰一书 3:4"> 没有律法之前，罪已经在世上；但没有律法，罪也不算为罪。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:45; 罗马书 5:17; 希伯来书 9:27"> 其实，从亚当到摩西的时代，死亡一直辖制着人类，甚至连那些不与亚当犯同样罪的人也不能幸免。亚当是将要来的那位的预表。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 6:23; 以弗所书 2:8; 罗马书 5:12"> 然而，上帝的洪恩远超过亚当的过犯。若因这一人的过犯，众人都要死亡，那么上帝的恩典，也就是通过耶稣基督一人所赐的恩典，岂不要更丰富地临到众人吗？</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 13:38–39; 以赛亚书 1:18; 以赛亚书 44:22"> 再者，上帝的恩赐不同于一人犯罪的后果。因为随一人犯罪而来的审判使人被定罪，随累累过犯而来的恩赐使人被称为义人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 15:21–22; 哥林多前书 15:49; 罗马书 5:12"> 若因一人的过犯，死亡就借着这人做了王，那么接受上帝洪恩又得到祂所赐之义的人，岂不更要借着耶稣基督一人在生命中做王吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:22; 罗马书 5:12; 罗马书 5:15"> 如此说来，因为一次过犯，众人都被定罪；照样，因为一次义行，众人都被称为义人，得到生命。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 5:18; 哥林多后书 5:21; 腓立比书 2:8"> 因为一人的悖逆，众人成为罪人；照样，因为一人的顺服，众人将被称为义人。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:1; 提多书 3:3–7; 罗马书 6:14"> 律法的颁布，使过犯更多地显出来，只是哪里的罪越多，哪里的恩典就越丰富。</span>
<span className="v" id="v21" data-v="21" data-xref="提多书 2:11; 罗马书 5:14; 罗马书 8:10"> 所以，罪怎样掌权带来死亡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“罪怎样掌权带来死亡”或译“罪怎样借着死亡掌权”。">a</a></sup>，恩典也照样借着义掌权，为要借着我们主耶稣基督带来永生。</span>
</div>

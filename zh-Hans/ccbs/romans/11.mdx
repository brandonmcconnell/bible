## 上帝不放弃以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:22; 撒母耳记上 12:22; 腓立比书 3:5"> 这样，我要问，难道上帝放弃了祂的子民吗？当然没有！因我自己也是以色列人，是亚伯拉罕的后裔，属于便雅悯支派。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 94:14; 罗马书 8:29–30; 出埃及记 32:1"> 上帝并没有放弃祂预先拣选的子民。你们不知道圣经上有关以利亚先知的记载吗？他在上帝面前控告以色列人，说：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:10–18; 列王纪上 18:13; 尼希米记 9:26"> “主啊！他们残杀你的先知，拆毁你的祭坛，只剩下我一个人，他们还要杀我。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="列王纪上19:10、14。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 19:18; 民数记 25:3; 西番雅书 1:4"> 上帝怎样回答呢？祂说：“我为自己留下七千人，他们都未曾跪拜巴力。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="列王纪上19:18。">b</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="罗马书 9:27; 以弗所书 1:5–6; 罗马书 9:11"> 现在的情况也是一样，上帝按照拣选的恩典留下了少数人。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:21; 罗马书 4:4–5; 提摩太后书 1:9"> 既然说是出于恩典，就不再基于行为，不然恩典就不再是恩典了。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:18; 罗马书 11:5; 哥林多后书 4:4"> 这该怎么说呢？以色列人努力追求，却一无所得，只有蒙拣选的人得到了，其他人都变得顽固不化。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 29:4; 以赛亚书 29:10; 以西结书 12:2"> 正如圣经上说：<br /><span className="pl pl-1">“上帝使他们至今心智昏迷，</span><br /><span className="pl pl-1">眼睛看不见，耳朵听不到。”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命记29:4；以赛亚书29:10。">c</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 69:22–23; 路加福音 12:20; 诗篇 28:4"> 大卫也说：<br /><span className="pl pl-1">“愿他们的宴席变为他们的网罗、</span><br /><span className="pl pl-1">陷阱、绊脚石和报应；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 69:23; 申命记 28:64–68; 彼得后书 2:4"> <span className="pl pl-1">愿他们眼目昏暗，</span><br /><span className="pl pl-1">无法看见，</span><br /><span className="pl pl-1">永远弯腰驼背。”</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇69:22、23。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 13:46–48; 罗马书 11:31; 罗马书 10:19"> 那么，我再问，以色列人一失足就再也爬不起来了吗？当然不是！恰好相反，因为他们的过犯，救恩临到了外族人，好使他们心生嫉妒。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:25; 歌罗西书 1:27; 罗马书 11:15"> 如果他们的过犯给世界带来富足，他们的失败给外族人带来富足，那么，他们完全恢复时又将带来怎样的祝福呢！</span>
</div>
</div>

## 外族人得救

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:15; 提摩太后书 1:11–12; 以弗所书 3:8"> 现在我有话要对你们外族人说。因为我是外族人的使徒，我尊重自己的职分，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 7:16; 提摩太前书 4:16; 罗马书 9:3"> 希望使我的骨肉同胞心生嫉妒，从而拯救他们当中的一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 罗马书 5:10–11; 歌罗西书 1:20–21"> 如果他们的被弃意味着人类与上帝和好，那么，他们被接纳时岂不意味着死而复生吗？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 44:30; 雅各书 1:18; 箴言 3:9"> 首先用来献祭的那部分面团如果圣洁，整团面也圣洁；树根如果圣洁，树枝也圣洁。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以弗所书 2:11–13; 以弗所书 3:6; 马太福音 21:43"> 如果橄榄树上有些枝子被折下来，你这野橄榄枝被接上去，得以汲取橄榄树根供应的汁浆，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:12; 罗马书 11:20; 以弗所书 2:19–20"> 你就不可向折下来的枝子夸口。你若夸口，就该知道：不是你托住树根，而是树根托住你。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 11:17; 罗马书 11:11–12; 罗马书 11:23–24"> 你也许会说：“原来的枝子被折下来，是为了把我接上去。”</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:16; 哥林多后书 1:24; 哥林多前书 10:12"> 不错，他们因为不信才被折下来，你因为信才被接上去，但不要自高，要心存敬畏。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4–9; 耶利米书 25:29; 耶利米书 49:12"> 上帝既然没有宽容原来的枝子，也不会宽容你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:14; 希伯来书 3:6; 哥林多前书 15:2"> 可见，上帝既慈爱又严厉。祂对堕落的人是严厉的，但只要你一直活在祂的爱中，祂会以慈爱对待你，不然你也会被砍下来。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 3:16; 撒迦利亚书 12:10; 马太福音 23:39"> 况且，以色列人如果不再顽固不信，必重新被接上去，因为上帝能把他们重新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:17–18; 罗马书 11:30"> 你这从野生的橄榄树上砍下来的枝子，尚且可以违反自然，被接到好橄榄树上，何况原来的枝子被接回到原来的树上呢？</span>
</div>
</div>

## 全以色列都要得救

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多后书 3:14–16; 罗马书 16:25"> 弟兄姊妹，我不愿意你们对以下这奥秘一无所知，免得你们自以为聪明。这奥秘就是：虽然有些以色列人的心刚硬，但等到外族人得救的数目满了以后，</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 59:20; 耶利米书 31:31–37; 诗篇 14:7"> 全以色列都要得救。正如圣经上说：“救主必从锡安出来，祂将除去雅各子孙的罪恶。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:31–34; 以赛亚书 59:21; 以西结书 36:25–29"> 这是我与他们所立的约，那时我要除去他们的罪。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以赛亚书59:20、21；27:9；耶利米书31:33、34。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 10:15; 申命记 7:7–8; 马太福音 21:43"> 就福音而论，他们为你们的缘故而成为上帝的仇敌；就上帝的拣选而论，他们因祖先的缘故仍被上帝所爱。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 7:21; 民数记 23:19; 玛拉基书 3:6"> 因为上帝的恩赐和呼召绝不会收回。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 3:7; 以弗所书 2:1–2; 哥林多前书 7:25"> 你们从前不顺服上帝，然而因为他们的不顺服，你们现在反蒙了怜悯。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:15; 罗马书 10:16; 罗马书 11:25"> 同样，他们现在不顺服，是为了通过你们所蒙的怜悯，使他们现在也蒙怜悯。</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太书 3:22; 罗马书 3:9; 提摩太前书 2:4–6"> 因为上帝把世人都归在不顺服之列，是为了要怜悯世人。</span>
</div>
</div>

## 颂赞上帝

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="约伯记 5:9; 约伯记 11:7–9; 诗篇 92:5"> <span className="pl pl-1">啊，上帝的智慧和知识多么博大精深！</span><br /><span className="pl pl-1">祂的判断多么难测！</span><br /><span className="pl pl-1">祂的踪迹多么难寻！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 40:13; 哥林多前书 2:16; 约伯记 15:8"> <span className="pl pl-1">谁曾知道主的心意？</span><br /><span className="pl pl-1">谁曾做过祂的谋士？</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以赛亚书40:13。">f</a></sup><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 41:11; 约伯记 35:7; 哥林多前书 4:7"> <span className="pl pl-1">谁给过祂什么，</span><br /><span className="pl pl-1">要祂偿还呢？</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="约伯记41:11。">g</a></sup><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歌罗西书 1:15–17; 哥林多前书 8:6; 希伯来书 2:10"> <span className="pl pl-1">因为万物都源于祂，</span><br /><span className="pl pl-1">倚靠祂，归于祂。</span><br /><span className="pl pl-1">愿荣耀归给祂，</span><br /><span className="pl pl-1">直到永远。阿们！</span></span>
</div>

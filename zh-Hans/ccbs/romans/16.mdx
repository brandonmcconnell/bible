## 介绍菲比

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:18; 彼得前书 1:22–23; 提摩太前书 5:9–10"> 现在我给你们推荐我们的姊妹菲比，她是坚革哩教会的女执事。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:29; 腓立比书 1:27; 马太福音 10:40–42"> 请你们在主里照着做圣徒的本分接待她。无论她有什么需要，请你们帮助她，因为她帮助过许多人，也帮助过我。</span>
</div>
</div>

## 问候圣徒

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 16:19; 提摩太后书 4:19; 使徒行传 18:26"> 请代我问候百基拉和亚居拉夫妇，他们是我在基督耶稣里的同工，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 2:30; 约翰一书 3:16; 哥林多前书 16:1"> 为了救我将生死置之度外。不但我感谢他们，就是外族人的教会也感谢他们。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 4:15; 腓利门书 1:2; 哥林多前书 16:19"> 请问候在他们家中聚会的教会。请问候我所爱的以拜尼土，在亚细亚他第一个信从基督。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:12; 马太福音 27:55; 提摩太前书 5:10"> 请问候玛丽亚。她为你们多受劳苦。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 16:11; 罗马书 16:21; 腓利门书 1:23"> 请问候安多尼古和犹尼亚，他们是我的亲人，曾与我一同坐牢，在使徒中很有名望，比我先信基督。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 约翰一书 3:14; 罗马书 16:5"> 请问候我在主里所爱的暗伯利。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:2–3; 罗马书 16:21"> 请问候在基督里与我同工的耳巴奴和我所爱的士大古。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:18; 彼得前书 1:7; 申命记 8:2"> 请问候亚比利，他在基督里曾受过考验。请问候亚利多布家里的人。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 16:21; 罗马书 16:7"> 请问候我的亲人希罗天。请问候拿其数家中的信徒。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 6:10–11; 哥林多前书 15:58"> 请问候土非娜和土富撒，她们都为主劳苦。请问候我所爱的彼息，她为主多受劳苦。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:21; 提摩太前书 5:2; 约翰二书 1:1"> 请问候主所拣选的鲁孚，也问候他的母亲，他的母亲就是我的母亲。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:2; 罗马书 8:29; 希伯来书 3:1"> 请问候亚逊其土、弗勒干、黑米、八罗巴、黑马和他们当中的其他弟兄姊妹。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:2; 罗马书 1:7; 罗马书 16:14"> 请问候非罗罗古、犹利亚、尼利亚和他的妹妹、阿林巴和他们那里的众圣徒。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:26; 哥林多前书 16:20; 哥林多后书 13:12"> 你们要以圣洁的吻彼此问候。基督的众教会都问候你们。</span>
</div>
</div>

## 提防悖逆者

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:19; 帖撒罗尼迦后书 3:6; 提摩太前书 6:3–5"> 弟兄姊妹，我劝你们要留意那些制造分裂和障碍、背离你们所学之道的人，你们要避开他们。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:4; 马太福音 7:15; 提摩太前书 6:5"> 他们并不是在事奉我们的主基督，只是为了满足自己的欲望，用花言巧语欺骗单纯幼稚的人。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 10:16; 哥林多前书 14:20; 腓立比书 2:15"> 你们对主的顺服已人人皆知，我为你们高兴，我希望你们在好事上聪明，在坏事上无知。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:19; 约翰一书 3:8; 创世记 3:15"> 赐平安的上帝快要把撒旦践踏在你们脚下了。愿我们主耶稣的恩典与你们同在！</span>
</div>
</div>

## 其他人的问候

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 使徒行传 17:5; 使徒行传 13:1"> 我的同工提摩太和我的亲人路求、耶孙和所西巴德问候你们。</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 6:11; 哥林多前书 16:21; 罗马书 16:8"> 我这代笔写信的德特在主里问候你们。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:14; 使徒行传 19:22; 提摩太后书 4:20"> 接待我也接待全教会的该犹问候你们。主管本城财政的以拉都问候你们，括土弟兄也问候你们。</span>
<span className="v" id="v24" data-v="24"> 愿我们的主耶稣基督赐恩典给你们众人！阿们。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无24节。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 2:7; 罗马书 2:16; 歌罗西书 1:26–27"> 愿荣耀归于上帝！祂能按照我传讲的耶稣基督的福音，并通过启示万古隐藏的奥秘使你们刚强。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 1:5; 加拉太书 3:8; 罗马书 15:18"> 按照永恒上帝的命令，这奥秘如今已经显明出来，并借着先知们所写的经书公诸于世，让万族的人都信从耶稣基督。</span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前书 1:17; 罗马书 11:36; 启示录 7:10–12"> 愿荣耀借着耶稣基督归于独一全智的上帝，直到永远。阿们！</span>
</div>

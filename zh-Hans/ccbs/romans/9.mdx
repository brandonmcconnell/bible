## 上帝的选民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:7; 罗马书 1:9; 加拉太书 1:20"> 我在基督里说真话，绝无谎言。我被圣灵感动的良心可以作证，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:18; 诗篇 119:136; 耶利米书 13:17"> 我心里极为忧愁，痛苦不堪！</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:32; 以斯帖记 8:6; 罗马书 11:14"> 为了我的弟兄——我的同胞以色列人，即使我自己被咒诅、与基督隔绝，我也愿意！</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:12; 诗篇 147:19; 罗马书 9:6"> 身为以色列人，他们拥有上帝儿子的名分、上帝的荣耀、诸约、律法、敬拜礼仪和各种应许。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:30; 约翰福音 1:1–3; 歌罗西书 1:16–19"> 蒙拣选的族长是他们的先祖，基督降世为人也是做以色列人。祂是至大至尊，永远当受称颂的上帝。阿们！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="罗马书 2:28–29; 加拉太书 6:16; 罗马书 11:1–2"> 当然，这并不表示上帝的话落了空，因为从以色列生的，并不都是以色列人，</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 21:12; 希伯来书 11:18; 约翰福音 8:37–39"> 亚伯拉罕的后裔并不都是亚伯拉罕的儿女，圣经上说：“以撒生的才可算为你的后裔。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记21:12。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:13; 罗马书 4:11–16; 加拉太书 3:26–29"> 这话的意思是：凭血气所生的儿女并不是上帝的儿女，只有凭应许所生的才算是后裔。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 18:10; 创世记 18:14; 创世记 17:21"> 因为上帝曾这样应许他：“明年这时候，我会再来，撒拉必生一个儿子。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="创世记18:10、14。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 25:21–23; 路加福音 16:26; 罗马书 5:11"> 后来，利百加和我们的先祖以撒结婚，怀了双胞胎。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 彼得后书 1:10"> 在这对孩子还未出生，还没有显出谁善谁恶之时，上帝为了显明自己拣选人并不是按人的行为，而是按祂自己的旨意，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:22–23; 撒母耳记下 8:14; 列王纪上 22:47"> 便对利百加说：“将来大的要服侍小的。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="创世记25:23。">c</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 1:2–3; 申命记 21:15; 创世记 29:33"> 正如圣经上说：“我爱雅各，厌恶以扫。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="玛拉基书1:2、3。">d</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="历代志下 19:7; 诗篇 145:17; 申命记 32:4"> 这样看来，我们该怎么说呢？难道上帝不公平吗？当然不是！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 33:19; 罗马书 9:16; 弥迦书 7:18"> 祂曾对摩西说：<br /><span className="pl pl-1">“我要怜悯谁就怜悯谁，</span><br /><span className="pl pl-1">要恩待谁就恩待谁。”</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="出埃及记33:19。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以弗所书 2:8; 马太福音 11:25–26; 彼得前书 2:9–10"> 可见这并不在于人的意志和努力，而在于祂的怜悯。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 9:16; 箴言 16:4; 出埃及记 14:17–18"> 圣经记载着上帝对法老说的话：“我使你兴起是为了在你身上彰显我的权能，使我的名传遍天下。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="出埃及记9:16。">f</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:20; 出埃及记 4:21; 罗马书 9:15–16"> 总之，上帝要怜悯谁，就怜悯谁；要叫谁顽固，就叫谁顽固。</span>
</div>
</div>

## 上帝的烈怒和怜悯

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 4:35; 历代志下 20:6; 哥林多前书 15:12"> 这样，你肯定会对我说：“为什么上帝还指责人呢？谁能抗拒祂的旨意呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 29:16; 以赛亚书 45:9–11; 以赛亚书 64:8"> 你这个人啊！你是谁啊？竟敢顶撞上帝！受造之物怎能对造物的说：“你为什么把我造成这样？”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以赛亚书29:16；45:9。">g</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:8; 箴言 16:4; 提摩太后书 2:20–21"> 陶匠难道不可从一团泥中拿一部分造贵重的器皿，又拿一部分造平凡的器皿吗？</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 犹大书 1:4; 罗马书 9:21"> 倘若上帝想要显示祂的烈怒和权能，就尽量容忍祂预备要发烈怒来毁灭的器皿，</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 2:4; 彼得前书 1:2–5; 歌罗西书 1:27"> 以便在祂预备施怜悯、赐荣耀的器皿上彰显祂丰盛的荣耀，又有何不可？</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:11; 使徒行传 13:47–48; 以弗所书 3:6–8"> 那些蒙祂怜悯的器皿就是我们这些从犹太人和外族人中被上帝呼召的人。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 2:23; 彼得前书 2:10; 约翰福音 16:27"> 正如上帝在《何西阿书》上说：<br /><span className="pl pl-1">“本来不是我子民的，</span><br /><span className="pl pl-1">我要称他们为‘我的子民’</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="何西阿书2:23。">h</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">本来不是我所爱的，</span><br /><span className="pl pl-1">我要称他们为‘我所爱的’。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 1:9–10; 约翰一书 3:1–3; 加拉太书 3:26"> <span className="pl pl-1">从前我在什么地方对他们说，</span><br /><span className="pl pl-1">‘你们不是我的子民。’</span><br /><span className="pl pl-1">将来也要在那里对他们说，</span><br /><span className="pl pl-1">‘你们是永活上帝的儿女。’”</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="何西阿书1:10。">i</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 10:20–23; 罗马书 11:4–6; 以赛亚书 1:9"> 关于以色列人，以赛亚先知曾疾呼：<br /><span className="pl pl-1">“以色列人虽多如海沙，</span><br /><span className="pl pl-1">但得救的只是剩余的人，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 10:23; 启示录 19:11; 使徒行传 17:31"> <span className="pl pl-1">因为上帝要在世上迅速、</span><br /><span className="pl pl-1">彻底地执行祂的判决。”</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="以赛亚书10:22、23。">j</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 1:9; 以赛亚书 13:19; 阿摩司书 4:11"> 正如以赛亚先前所言：<br /><span className="pl pl-1">“若不是万军之主给我们存留后裔，</span><br /><span className="pl pl-1">我们早就像所多玛和蛾摩拉一样灭亡了。”</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="以赛亚书1:9。">k</a></sup></span>
</div>
</div>

## 以色列人和福音

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比书 3:9; 希伯来书 11:7; 加拉太书 2:16"> 这样看来，我们该怎么说呢？本来不追求义的外族人却得到了义，就是因信而得的义。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:7; 罗马书 3:20; 雅各书 2:10–11"> 以色列人靠遵行律法追求义，却徒劳无功。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:23; 彼得前书 2:8; 路加福音 7:23"> 为什么会这样呢？因为他们不凭信心、只靠自己的行为去追求义，结果被那块绊脚石绊倒了，</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 28:16; 以赛亚书 8:14–15; 罗马书 10:11"> 正如圣经上说：<br /><span className="pl pl-1">“看啊！我在锡安放了一块绊脚石，</span><br /><span className="pl pl-1">一块使人跌倒的磐石。</span><br /><span className="pl pl-1">但信靠祂的人必不会蒙羞。”</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="以赛亚书8:14；28:16。">l</a></sup></span>
</div>

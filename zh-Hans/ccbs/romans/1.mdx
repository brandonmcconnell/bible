## 问候

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 罗马书 15:16; 哥林多前书 1:1"> 我是基督耶稣的奴仆保罗，蒙召做使徒，特为传上帝的福音。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:2; 路加福音 1:70; 罗马书 3:21"> 这福音是上帝从前借着众先知在圣经中应许的，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 1:1; 加拉太书 4:4; 耶利米书 23:5–6"> 讲的是上帝的儿子——我们主耶稣基督的事。从肉身来看，祂是大卫的后裔；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:14; 希伯来书 5:5–6; 以弗所书 1:19–23"> 从圣洁的灵来看，祂从死里复活，用大能显明自己是上帝的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:15; 罗马书 16:26; 使徒行传 6:7"> 我们从祂领受了恩典并成为使徒，要带领万族的人信从祂，使祂的名得荣耀。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:9; 启示录 17:14; 彼得后书 1:10"> 你们也是其中蒙召信从耶稣基督的人。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 1:2; 犹大书 1:1–2; 以弗所书 1:2"> 我问候所有住在罗马、上帝所爱、蒙召做圣徒的人。愿我们的父上帝和主耶稣基督赐给你们恩典和平安！</span>
</div>
</div>

## 保罗渴望去罗马

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 16:19; 哥林多前书 1:4; 帖撒罗尼迦前书 1:8–9"> 首先，我借着耶稣基督为各位感谢我的上帝，因为你们的信心正在传遍天下。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 6:18; 提摩太后书 1:3; 以弗所书 1:16–19"> 我在祂儿子的福音事工上全心事奉的上帝可以为我做见证：我如何在祷告中常常想到你们，并求上帝让我照祂的旨意最终能去你们那里。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:12; 罗马书 16:25; 罗马书 15:29"> 因为我实在想见你们，好将一些属灵的恩赐分给你们，使你们坚固，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 3:7–10; 约翰三书 1:3–4; 哥林多后书 7:13"> 也可以说是借着我们彼此的信心互相激励。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 19:21; 腓立比书 4:17; 提摩太后书 4:17"> 弟兄姊妹，我希望你们知道，我曾多次计划去你们那里，要在你们中间收获一些福音的果子，像在其他外族人中一样，只是至今仍有拦阻。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:16–23; 使徒行传 9:15; 歌罗西书 3:11"> 不论是希腊人和非希腊人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“非希腊人”希腊文是“未开化的人”，指在希腊、罗马文化影响圈之外的人。">a</a></sup>、智者和愚人，我对他们都有义务。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:20; 以赛亚书 6:8; 哥林多前书 9:17"> 所以，我也切望能将福音传给你们在罗马的人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马可福音 8:38; 提摩太后书 1:8; 彼得前书 4:16"> 我不以福音为耻，因为这福音是上帝的大能，要拯救一切相信的人，先是犹太人，然后是希腊人。</span>
<span className="v" id="v17" data-v="17" data-xref="哈巴谷书 2:4; 加拉太书 3:11; 希伯来书 10:38"> 这福音显明了上帝的义，这义始于信，终于信，正如圣经上说：“义人必靠信心而活。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哈巴谷书2:4。">b</a></sup></span>
</div>
</div>

## 人类的罪恶

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:6; 提摩太前书 4:1–2; 罗马书 1:32"> 上帝的烈怒从天上降下，要惩罚一切心中无神、行为不义的人，就是以不义压制真理的人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:16–17; 诗篇 19:1–6; 罗马书 1:20"> 有关上帝的事情，可以让人类知道的都已经显而易见，因为上帝已经向人类显明了。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:19; 以赛亚书 40:26; 诗篇 19:1–6"> 自从创造天地以来，上帝永恒的大能和神性是明明可知的，虽然肉眼看不见，但透过受造之物就可以领悟，使人无法推诿。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:17–18; 列王纪下 17:15; 耶利米书 2:5"> 他们虽然明知有上帝，却不把祂当作上帝来荣耀祂，也不感谢祂。他们的思想因此变得荒谬无用，无知的心也变得昏暗不明。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 1:19–21; 罗马书 11:25; 箴言 26:12"> 他们自以为聪明，其实愚不可及，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 106:20; 耶利米书 2:11; 使徒行传 17:29"> 以必朽的人、飞禽、走兽和爬虫的形象来取代永恒上帝的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 使徒行传 7:42; 使徒行传 14:16"> 因此，上帝任凭他们随从内心的情欲行污秽的事，玷污彼此的身体。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷书 2:18; 耶利米书 13:25; 约翰一书 2:15–16"> 他们把上帝的真理当作谎言，祭拜、供奉受造之物，却不敬拜、事奉造物主。主是永远值得称颂的。阿们！</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="犹大书 1:7; 提摩太前书 1:10; 罗马书 1:24"> 因此，上帝任凭他们放纵可耻的情欲。女人放弃正常的两性关系，做出变态反常的事。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 20:13; 利未记 18:22; 罗马书 1:23–24"> 同样，男人也背弃了和女人正常的两性关系，男与男彼此欲火焚烧，做出羞耻不堪的事。他们必因变态而遭受应得的报应。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:10–12; 罗马书 1:21; 提多书 1:16"> 既然他们故意不认识上帝，上帝就任凭他们心思败坏，做不当做的事。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 12:20; 箴言 16:28; 诗篇 41:7"> 他们心里塞满了各种不义、邪恶、贪婪、阴险、嫉妒、凶杀、纷争、诡诈和恶毒，他们说长道短、</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 3:2; 犹大书 1:16; 彼得后书 2:18"> 造谣中伤、怨恨上帝、欺侮别人、心骄气傲、自高自大、无恶不作、违背父母、</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 3:3; 箴言 18:2; 罗马书 3:11"> 愚钝无知、言而无信、无情无义、毫无怜悯。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 2:1–5; 罗马书 1:21; 罗马书 6:21"> 他们明明知道，按上帝公义的法则，做这些事的人该死，不但执迷不悟，还喜欢别人跟他们同流合污。</span>
</div>
</div>

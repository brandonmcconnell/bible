## 随从圣灵而活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:18–19; 哥林多后书 5:17; 加拉太书 3:13"> 因此，如今那些在基督耶稣里的人不被定罪，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 6:14; 哥林多后书 3:17; 罗马书 6:18"> 因为赐人生命之圣灵的律，已经在基督耶稣里使我获得自由，脱离了罪与死的律。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 13:39; 加拉太书 4:4–5; 希伯来书 7:18–19"> 律法因为人性软弱而无法成就的事，上帝亲自成就了。祂差遣自己的儿子成为和罪人一样有血有肉的人，作了赎罪祭，废掉了罪的权势，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 5:16; 加拉太书 5:22–25; 歌罗西书 1:22"> 使律法公义的要求实现在我们这些不随从本性、只随从圣灵而活的人身上。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 2:14; 加拉太书 5:19–25; 约翰福音 3:6"> 随从本性的人思想本性的事，随从圣灵的人思想圣灵的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:8; 罗马书 8:7; 罗马书 8:13"> 受本性支配的思想会导致死亡，受圣灵支配的思想会带来生命和平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:14; 约翰一书 2:15–16; 雅各书 4:4"> 因为受本性支配的思想与上帝为敌，不服从上帝的律法，也无力服从。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:5–6; 希伯来书 11:5–6; 罗马书 8:9"> 所以受本性控制的人不能让上帝喜悦。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:6; 哥林多前书 3:16; 提摩太后书 1:14"> 但如果上帝的灵住在你们里面，你们就不再受本性控制，而是受圣灵管理。人若没有基督的灵，就不属于基督。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:17; 加拉太书 2:20; 哥林多后书 5:21"> 如果基督在你们里面，你们的身体虽然因罪而死亡，灵魂却因义而活着<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“灵魂却因义而活着”或译“圣灵必因义而赐下生命”。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 4:14; 罗马书 6:4–5; 哥林多后书 4:11"> 如果使耶稣复活之上帝的灵住在你们里面，叫基督耶稣从死里复活的上帝，也必借着住在你们里面的圣灵，使你们终有一死的身体活过来。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:2–15; 哥林多前书 6:19–20; 彼得前书 4:2–3"> 弟兄姊妹，这样看来，我们不必随从本性活着。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:8; 彼得前书 2:11; 哥林多前书 9:27"> 你们若随从本性活着，必定死亡；若靠着圣灵除去身体的恶行，就必活着。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 约翰福音 1:12; 加拉太书 3:26"> 因为凡有上帝的灵引导的人都是上帝的儿女。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:5–7; 提摩太后书 1:7; 哥林多前书 2:12"> 你们接受的圣灵不是使你们做奴隶，仍旧害怕，而是使你们做儿子，可以称上帝为“阿爸，父亲”。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:13; 哥林多后书 1:22; 哥林多后书 5:5"> 圣灵亲自与我们的心一同见证我们是上帝的儿女。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 4:7; 加拉太书 3:29; 以弗所书 3:6"> 我们既然是儿女，就是继承人，是上帝的继承人，并且与基督同做继承人。所以，我们现在若和基督一同受苦，将来也必和祂一同得荣耀。</span>
</div>
</div>

## 将来的荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:17–18; 彼得前书 4:13; 彼得前书 1:5–7"> 我认为，与将来要显给我们的荣耀相比，现在所受的痛苦简直微不足道。</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:17–18; 罗马书 8:23; 约翰一书 3:2"> 受造之物正热切等候上帝众子的显现，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:17–19; 创世记 5:29; 罗马书 8:22"> 因为受造之物处在虚空之下并非出于情愿，而是出于上帝的旨意。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 22:3–5; 使徒行传 3:21; 彼得后书 3:13"> 不过，受造之物仍然盼望脱离衰亡的束缚，享受上帝儿女荣耀的自由。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 12:4; 耶利米书 12:11; 约翰福音 16:21"> 我们知道一切受造之物至今都在呻吟，如同经历分娩之痛。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:20–21; 哥林多后书 5:2–5; 希伯来书 9:28"> 不但如此，就是我们这些首先得到圣灵的人也在心里叹息，热切等候得到儿子的名分<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“儿子的名分”指被收养为义子，可以享受和亲生儿子一样的权利。">b</a></sup>，就是我们的身体得到救赎。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 5:7; 希伯来书 11:1; 哥林多后书 4:18"> 我们得救的人有这个盼望。不过，看得见的盼望不算盼望，谁会盼望已经看见的呢？</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 12:12; 希伯来书 10:36; 诗篇 27:14"> 但我们若盼望那尚未看见的，就会忍耐等候。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:20; 以弗所书 6:18; 加拉太书 4:6"> 况且，我们软弱的时候，有圣灵帮助我们。我们不知道该怎样祷告，但圣灵亲自用说不出来的叹息替我们祈祷。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 17:10; 约翰一书 5:14–15; 以弗所书 2:18"> 洞悉人心的上帝知道圣灵的意思，因为圣灵是照着上帝的旨意替圣徒祈祷。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:10; 雅各书 1:12; 创世记 50:20"> 我们知道，上帝使万事互相效力<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“上帝使万事互相效力”或译“万事都互相效力”。">c</a></sup>，使那些爱上帝的人，就是上帝按自己的旨意呼召的人得益处。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 1:4–5; 耶利米书 1:5; 以弗所书 1:11"> 因为上帝预先知道谁是属祂的人，并预定这些人要被塑造成祂儿子的形象，使祂的儿子在许多弟兄中成为长子。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 17:14; 罗马书 8:28; 以弗所书 1:11"> 祂所预定的人，祂也呼召他们；祂所呼召的人，祂也称他们为义人；祂称之为义人的，祂也使他们得荣耀。</span>
</div>
</div>

## 上帝的爱

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 118:6; 耶利米书 1:19; 诗篇 56:11"> 对于这些事，我们还可以说什么呢？上帝若帮助我们，谁能与我们对抗？</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:16; 罗马书 8:28; 诗篇 84:11"> 上帝既然连自己的儿子也不顾惜，让祂为我们牺牲，岂不也把万物和祂一同白白地赐给我们吗？</span>
<span className="v" id="v33" data-v="33" data-xref="启示录 12:10–11; 以赛亚书 50:8–9; 以赛亚书 54:17"> 谁能指控上帝拣选的人呢？是上帝称我们为义人。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:25; 罗马书 8:27; 希伯来书 9:24"> 谁能定我们有罪呢？基督耶稣已经替我们死了，而且从死里复活了，如今在上帝的右边正替我们祈祷。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 10:28; 诗篇 103:17; 约翰福音 16:33"> 谁能使我们与基督的爱分离呢？难道是患难吗？困苦吗？迫害吗？饥饿吗？赤身露体吗？危险吗？刀剑吗？</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 44:22; 以赛亚书 53:7; 哥林多前书 15:30"> 正如圣经上说：“为了你，我们终日出生入死，被视为待宰的羊。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇44:22。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:57; 约翰一书 4:4; 哥林多后书 2:14"> 然而，靠着爱我们的主，我们在这一切事上已经得胜有余了。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 10:28; 罗马书 14:8; 提摩太后书 1:12"> 因为我深信无论是死、是生，是天使、是鬼魔，是现在的事、是将来的事，</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:28–30; 罗马书 8:35; 罗马书 5:8"> 是高天之上的、是大地深处的或是其他受造之物，都不能使我们与上帝在主基督耶稣里赐下的爱分离。</span>
</div>
</div>

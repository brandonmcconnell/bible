## 我为人人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:14; 罗马书 14:1; 加拉太书 6:1–2"> 我们坚强的人要担待软弱者的软弱，不该只顾自己的喜好。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 14:19; 哥林多前书 10:24; 腓立比书 2:4–5"> 我们每个人都应该为他人着想，造就他人。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 69:9; 腓立比书 2:8; 约翰福音 4:34"> 因为基督并没有专顾自己，正如圣经上说：“辱骂你之人的辱骂都落在我身上。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇69:9。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:11; 提摩太后书 3:16–17; 罗马书 4:23–24"> 从前写在圣经上的话都是为了教导我们，使我们靠着忍耐和圣经的鼓励而有盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 2:4–5; 彼得前书 3:8; 罗马书 12:16"> 但愿赐忍耐和鼓励的上帝给你们合一的心，去效法基督耶稣的榜样，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:29–30; 启示录 1:6; 以弗所书 1:3"> 使你们一起同声颂赞我们主耶稣基督的父上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40; 约翰福音 13:34; 罗马书 5:2"> 所以，你们应该像基督接纳你们一样彼此接纳，使上帝得荣耀。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 4:4–5; 马太福音 15:24; 约翰福音 1:11"> 我告诉你们，基督为了上帝的真理成为受割礼之人的仆人，好实现上帝对他们祖先的应许，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 22:50; 诗篇 18:49; 罗马书 3:29"> 使外族人也因祂的怜悯而将荣耀归给上帝。正如圣经上说：<br /><span className="pl pl-1">“因此，我要在外族人中赞美你，</span><br /><span className="pl pl-1">歌颂你的名。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="撒母耳记下22:50；诗篇18:49。">b</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 67:3–4; 申命记 32:43; 以赛亚书 42:10–12"> 又说：<br /><span className="pl pl-1">“外族人啊，</span><br /><span className="pl pl-1">你们当与主的子民一同欢乐。”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命记32:43。">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 117:1"> 又说：<br /><span className="pl pl-1">“万邦啊，你们要赞美主！</span><br /><span className="pl pl-1">万民啊，你们要颂扬祂！”</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇117:1。">d</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 11:10; 以赛亚书 11:1; 马太福音 12:21"> 以赛亚先知也说：<br /><span className="pl pl-1">“将来耶西的根要兴起，</span><br /><span className="pl pl-1">祂要统治外族人，</span><br /><span className="pl pl-1">外族人都要仰望祂。”</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以赛亚书11:10。">e</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦后书 2:16–17; 罗马书 12:12; 哥林多后书 9:8"> 愿使人有盼望的上帝，因为你们信祂，将诸般的喜乐和平安充满你们的心，使你们借着圣灵的能力充满盼望！</span>
</div>
</div>

## 福音特使

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 3:16; 彼得后书 1:12; 约翰一书 2:21"> 弟兄姊妹，我深信你们充满良善，知识全备，能彼此劝导。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:3; 哥林多前书 15:10; 罗马书 1:5"> 但我仍放胆写信提醒你们几件事，因为我蒙上帝赐恩，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:13; 罗马书 1:1; 使徒行传 9:15"> 在外族人中做基督耶稣的仆人和上帝福音的祭司，好叫外族人借着圣灵得以圣洁，可以作上帝喜悦的祭物。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 2:14–16; 哥林多后书 12:11–21; 希伯来书 5:1"> 因此，我在基督耶稣里以事奉上帝为荣。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:12; 罗马书 1:5; 使徒行传 21:19"> 别的事我不敢提，只提基督借着我的言语行为，用神迹奇事和圣灵的大能叫外族人顺服，使我把基督的福音从耶路撒冷一直传到了以利哩古。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 10:13–16; 哥林多前书 3:9–15; 以弗所书 2:20–22"> 我立志只去从未听过基督之名的地方传福音，免得我建造在别人的根基上。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 52:15; 以赛亚书 65:1"> 正如圣经上说：“对祂毫无所闻的，将要看见；未曾听过的，将要明白。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以赛亚书52:15。">f</a></sup></span>
</div>
</div>

## 保罗计划去罗马

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 1:13; 帖撒罗尼迦前书 2:17–18"> 因此，我一直受到拦阻，不能去你们那里。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 15:32; 罗马书 1:10–12; 罗马书 15:29"> 如今，我已经把福音传遍了这一带，况且我几年来一直盼望去你们那里，</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:28; 罗马书 1:12; 使徒行传 15:3"> 所以我想去西班牙的途中路过你们那里，稍作停留，享受与你们的相聚之乐，然后由你们资助我上路。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 24:17; 使徒行传 19:21; 使徒行传 20:22"> 但现在我要去耶路撒冷服侍当地的圣徒，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 8:1–9; 使徒行传 11:27–30; 哥林多后书 9:2"> 因为马其顿和亚该亚的教会欣然捐了财物给耶路撒冷的穷困圣徒。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 9:11; 加拉太书 6:6; 腓利门书 1:19"> 这固然是他们慷慨解囊，但也可以说是他们该还的债。外族人既然分享了犹太圣徒属灵的福分，现在以物质报答他们也是应该的。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 15:24; 腓立比书 4:17; 歌罗西书 1:6"> 等我办完这件事，将捐款交付他们之后，我就会途经你们那里去西班牙。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 4:13; 罗马书 1:10–12; 诗篇 16:11"> 我知道我去的时候，必把基督丰盛的恩福带给你们。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:12; 哥林多后书 1:11; 哥林多后书 4:11"> 弟兄姊妹，我借着我们主耶稣基督和圣灵所赐的爱心，恳求你们与我一同竭力祷告，为我祈求上帝，</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 3:2; 哥林多后书 8:4; 哥林多后书 9:1"> 使我脱离犹太地区不信之人的迫害，叫耶路撒冷的圣徒乐意接受我带去的捐款，</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 16:18; 腓利门书 1:20; 腓利门书 1:7"> 并使我按照上帝的旨意去与你们欢聚，一同重新得力。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 13:11; 腓立比书 4:9; 帖撒罗尼迦前书 5:23"> 愿赐平安的上帝常与你们众人同在。阿们！</span>
</div>
</div>

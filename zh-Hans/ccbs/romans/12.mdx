## 为事奉上帝而活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:5; 罗马书 6:13; 希伯来书 13:15–16"> 所以，弟兄姊妹，我凭上帝的怜悯劝你们献上自己的身体，作圣洁、蒙上帝悦纳的活祭。你们理当这样事奉。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:14; 以弗所书 4:22–24; 哥林多后书 5:17"> 你们不可追随这世界的潮流，要随着思想的不断更新而改变，这样就能明辨上帝的旨意，知道什么是良善、纯全、蒙祂悦纳的。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:3; 腓立比书 2:3–8; 箴言 26:12"> 我凭上帝赐给我的恩典劝告各位，不要自视过高，要照着上帝赐给各人的信心中肯地看待自己。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 12:27; 哥林多前书 12:12–14; 以弗所书 4:15–16"> 就像我们每个身体有许多肢体，各肢体功能不同，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:20; 哥林多前书 10:17; 哥林多前书 12:27–28"> 我们虽然人多，但在基督里组成一个身体，彼此联结，互为肢体。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 4:10–11; 哥林多前书 7:7; 哥林多前书 12:28–31"> 我们照所得的恩典各有不同的恩赐。说预言的，要按着信心的程度说预言；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:11; 提摩太后书 4:2; 使徒行传 13:1"> 服侍的，要专心服侍；教导的，要专心教导；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 9:7; 提摩太前书 5:17; 哥林多前书 12:28"> 劝勉的，要专心劝勉；施舍的，要慷慨施舍；治理的，要殷勤治理；怜悯的，要甘心怜悯。</span>
</div>
</div>

## 相爱相顾

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 34:14; 彼得前书 4:8; 提摩太前书 1:5"> 爱必须真诚。要痛恨邪恶，一心向善。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:3; 约翰福音 13:34–35; 希伯来书 13:1"> 要彼此相爱如同手足，互相尊重，彼此谦让。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:10–11; 使徒行传 18:25; 启示录 3:15–16"> 要殷勤，不可懒惰，要常常火热地事奉主。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:13; 希伯来书 10:36; 诗篇 62:8"> 盼望中要有喜乐，患难中要坚忍，祷告要恒切。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:16; 哥林多后书 9:12; 约翰一书 3:17"> 圣徒有缺乏，要慷慨帮助；客人来访，要热诚款待。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:9; 马太福音 5:44; 帖撒罗尼迦前书 5:15"> 迫害你们的，要为他们祝福；要祝福，不可咒诅。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 12:26; 希伯来书 13:3; 诗篇 35:13–14"> 要与喜乐的人同乐，与哀哭的人同哭。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:8; 箴言 3:7; 雅各书 3:13–17"> 要彼此和睦。不可心高气傲，反要俯就卑微的人。不可自以为聪明。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; 帖撒罗尼迦前书 5:15; 马太福音 5:39"> 不要以恶报恶，要留心去做众人看为好的事。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:14; 马太福音 5:9; 罗马书 14:19"> 如果可能，总要尽力与人和睦相处。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 32:35; 希伯来书 10:30; 箴言 24:29"> 亲爱的弟兄姊妹，不要私自报复，要交给发烈怒的上帝，因为圣经上说：<br /><span className="pl pl-1">“主说，‘申冤在我，我必报应。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记32:35。">a</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; 马太福音 5:44; 路加福音 6:27"> 相反，<br /><span className="pl pl-1">“你的仇敌若饿了，就给他吃的；</span><br /><span className="pl pl-1">若渴了，就给他喝的；</span><br /><span className="pl pl-1">你这样做是把炭火堆在他头上。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="箴言25:21、22。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="彼得前书 3:9; 路加福音 6:27–30; 箴言 16:32"> 你不可被恶所胜，反要以善胜恶。</span>
</div>
</div>

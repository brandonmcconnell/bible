## 上帝公义的审判

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:3; 约翰福音 8:7–9"> 因此，你这论断人的啊，不管你是谁，都难逃罪责。你在什么事上论断别人，就在什么事上定了自己的罪，因为你论断别人，自己却在做同样的事。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 9:7–8; 西番雅书 3:5; 诗篇 145:17"> 我们都知道，上帝必按真理审判做这些事的人。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 罗马书 1:32–1"> 你这人啊，你论断别人，自己却做同样的事，你以为自己能逃脱上帝的审判吗？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 3:9; 以赛亚书 30:18; 出埃及记 34:6"> 还是你藐视祂深厚的慈爱、宽容和忍耐，不知道祂的慈爱是要引导你悔改吗？</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 12:14; 罗马书 1:18; 罗马书 2:2–3"> 你这样硬着心不肯悔改，等于是在为自己积蓄烈怒，上帝的烈怒必在祂施行公义审判的日子临到你。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 62:12; 耶利米书 32:19; 马太福音 16:27"> 上帝必照各人的行为施行赏罚。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇62:12；箴言24:12。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:7–8; 路加福音 8:15; 提摩太后书 1:10"> 凡是恒心行善、寻求荣耀、尊贵和永恒福分的人，祂要把永生赐给他们；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:18–21; 帖撒罗尼迦后书 1:8; 提摩太前书 6:3–4"> 凡是自私自利、违背真理、行为不义的人，祂的烈怒和怒气要降在他们身上。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 4:17; 以西结书 18:4; 罗马书 1:16"> 一切作恶之人必受患难和痛苦，先是犹太人，然后是希腊人。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 32:17; 以赛亚书 26:12; 民数记 6:26"> 一切行善之人必享荣耀、尊贵和平安，先是犹太人，然后是希腊人。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:17; 使徒行传 10:34; 历代志下 19:7"> 因为上帝不偏待人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:21; 加拉太书 3:10; 加拉太书 2:16–19"> 没有上帝律法的人若犯罪，虽然不按律法受审判，仍要灭亡；有上帝律法的人若犯罪，必按律法受审判。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:22–25; 约翰一书 3:7; 雅各书 2:21–25"> 因为在上帝面前，不是仅仅听到律法的人是义人，而是遵行律法的人才能被称为义人。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:12; 罗马书 1:19–20; 罗马书 2:27"> 没有律法的外族人若顺着天性做合乎律法的事，他们虽然没有律法，自己就是自己的律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:11; 哥林多后书 1:12; 罗马书 1:18–19"> 这表明律法的要求刻在他们心里，他们的良心也可以做见证，并且他们的思想有时指控他们，有时为他们辩护。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 12:14; 哥林多前书 4:5; 使徒行传 17:31"> 按照我所传的福音，到了审判之日，上帝要借着耶稣基督审判人一切隐秘的事。</span>
</div>
</div>

## 犹太人与律法

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 2:23; 弥迦书 3:11; 以赛亚书 48:1–2"> 你自称是犹太人，倚仗上帝所赐的律法，自夸与上帝有特别的关系；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:21; 申命记 4:8; 雅各书 4:17"> 你受过律法的教导，知道上帝的旨意，能明辨是非；</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 3:17–18; 马太福音 15:14; 以赛亚书 49:6"> 你自信可以做盲人的向导、黑暗中的人的光、</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:5; 提多书 1:16; 提摩太后书 1:13"> 愚昧人的师傅、小孩子的老师，因为你从律法中得到了知识和真理。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 9:27; 马太福音 23:3–28; 路加福音 12:47"> 那么，你这教导别人的，为什么不教导自己呢？你教导人不可偷盗，自己却偷盗吗？</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 3:8; 马太福音 12:39; 马可福音 11:17"> 你告诉他人不可通奸，自己却通奸吗？你憎恶偶像，自己却去偷庙里的东西吗？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 4:16–17; 罗马书 2:17; 罗马书 3:2"> 你以律法自夸，自己却违背律法羞辱上帝吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 36:20–23; 以赛亚书 52:5; 彼得后书 2:2"> 正如圣经上说：“因你们的缘故，上帝的名在外族人中受到亵渎！”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书52:5；以西结书36:22。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米书 4:4; 加拉太书 5:3–6; 使徒行传 7:51"> 如果你遵行律法，割礼才有价值；如果你违背律法，受了割礼也如同未受割礼。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:11; 哥林多前书 7:18–19; 罗马书 8:4"> 如果未受割礼的人遵行律法的教导，他岂不算是受了割礼吗？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:41–42; 罗马书 2:29; 哥林多后书 3:6"> 身体未受割礼却遵行律法的人，必审判你这有律法条文、受了割礼却违背律法的人。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:15; 马太福音 3:9; 罗马书 9:6–8"> 因为徒具外表的犹太人不是真正的犹太人，身体上的割礼也不是真正的割礼。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 30:6; 腓立比书 3:3; 申命记 10:16"> 唯有从心里做犹太人的才是真犹太人，真割礼是借着圣灵在心里受的割礼，不在于律法条文。这样的人得到的称赞不是从人来的，而是从上帝来的。</span>
</div>
</div>

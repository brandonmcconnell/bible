## 所罗门的王宫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:10; 历代志下 8:1; 传道书 2:4–5"> 所罗门用了十三年的时间为自己兴建王宫。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 10:17; 历代志下 9:16; 列王纪上 10:21"> 他建造的黎巴嫩林宫长四十五米，宽二十二米半，高十三米半，有四行香柏木柱，柱子支撑着香柏木横梁。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 6:5"> 每一行木柱有十五根，共四十五根。殿顶铺香柏木板。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 40:22; 以西结书 40:16; 列王纪上 6:4"> 宫殿有三排窗户，窗与窗相对；</span>
<span className="v" id="v5" data-v="5"> 宫殿的门框和窗户都是方形的，三排窗户彼此相对。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:12; 以西结书 41:25–26"> 他又建了一座有柱子的廊子，长二十二米半，宽十三米半，前面还有带柱子的门廊和篷子。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 诗篇 122:5; 以赛亚书 9:7"> 此外，他又建造了一个判案的公堂。堂内从地板到天花板都铺上了香柏木。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:11; 列王纪上 3:1; 列王纪上 9:24"> 所罗门的寝宫就在公堂后面的院内，建筑样式和公堂相同。所罗门又为所娶的法老之女造了一座与公堂相同的宫室。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 7:10–11; 列王纪上 5:17"> 这些宫殿，从根基到墙顶，从外院到内殿用的都是上等的石头，按规格里外用锯切割整齐。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:19–20; 哥林多前书 3:10–11; 以赛亚书 54:11"> 根基用的是非常珍贵的石头，它们的体积巨大，有些甚至是长达三米半至四米半的巨石，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20–22; 彼得前书 2:5"> 上面是按照规格凿好的上等石头以及香柏木。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 6:36; 列王纪上 7:6; 约翰福音 10:23"> 大院周围的墙由三层凿好的石头和一层香柏木建成，正如耶和华殿的内院和殿廊的墙。</span>
</div>
</div>

## 户兰造圣殿的器具

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:11; 历代志下 2:13–14; 列王纪上 7:40"> 所罗门王派人从泰尔把户兰召来。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:14; 历代志下 4:16; 出埃及记 31:2–6"> 户兰是拿弗他利支派一个寡妇的儿子，父亲是泰尔的铜匠。户兰聪明伶俐，技术高超，擅长制造各种铜器。他前来朝见所罗门王，领命负责一切铜器工程。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:21; 历代志下 3:15–17; 列王纪上 7:21"> 他铸造了两根铜柱，每根高八米，周长五米四，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 38:19; 历代志下 4:12–13; 出埃及记 38:17"> 然后用铜铸造了两个高两米二的柱冠，安在柱顶上。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 28:14; 出埃及记 28:24–25; 出埃及记 28:22"> 每一个柱冠上装饰着七条链子织成的网，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 出埃及记 39:15–18; 出埃及记 28:22"> 网周围环绕着两行石榴，用来遮盖柱冠。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:22; 列王纪上 6:32–35; 列王纪上 6:18"> 门廊的柱冠高一米八，形状像百合花。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:16; 历代志下 4:13; 耶利米书 52:22–23"> 在每个柱冠靠近网子鼓起来的地方围着两行石榴，共二百个。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:17; 列王纪上 6:3; 列王纪上 7:12"> 他把两根柱子立在殿廊前，南边那根称为雅斤，北边那根称为波阿斯。</span>
<span className="v" id="v22" data-v="22"> 柱冠的形状像百合花。这样，铜柱就造成了。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 4:2; 列王纪下 25:13; 耶利米书 52:17"> 他又铸了一个圆形铜海，高两米二，直径四米半，周长十三米半。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:18; 历代志下 4:3; 出埃及记 37:17–22"> 铜海边缘下面有两圈野瓜图案，每米有二十个野瓜，是跟铜海一起铸造的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 52:20; 历代志下 4:4–5; 马太福音 28:19"> 有十二头铜牛驮着铜海，三头向北，三头向西，三头向南，三头向东。铜海安在牛上，牛尾向内。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 4:5; 列王纪上 7:38; 列王纪上 6:18"> 铜海厚八厘米，边如杯边，又如百合花，容量是四万四千升。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 4:14; 列王纪下 25:13; 耶利米书 52:17"> 户兰用铜造了十个盆座，每个长一米八，宽一米八，高一米三。</span>
<span className="v" id="v28" data-v="28"> 盆座四面装上镶板，镶板固定在框架上。</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿书 5:14; 以西结书 10:14; 出埃及记 37:7"> 镶板和框架上刻着狮子、牛和基路伯天使，狮子和牛的上面和下面雕刻着花环。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 10:10–13; 以西结书 3:13; 以西结书 1:15–21"> 每一个盆座都有四个铜轮和铜轴，盆放在有四个支脚铸成的盆架上，盆架周围有花环图案。</span>
<span className="v" id="v31" data-v="31"> 盆座的开口呈圆形，深四十五厘米，直径七十厘米，开口周围有雕刻。镶板是方形的，不是圆形的，</span>
<span className="v" id="v32" data-v="32"> 下面有四个七十厘米高的轮子，轮轴固定在盆座上。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 1:18; 以西结书 1:16"> 轮子的样式像战车的轮子，轴、辋、辐、毂都是铸成的。</span>
<span className="v" id="v34" data-v="34"> 每个盆座的四角都有支脚，支脚和盆座铸成一体。</span>
<span className="v" id="v35" data-v="35"> 盆座上有一个高二十三厘米的圆架，上面的支架和镶板与盆座铸成一体。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:29; 列王纪上 6:29; 以西结书 41:18–20"> 支架和镶板都刻上基路伯天使、狮子和棕树的图案，周围有花环图案。</span>
<span className="v" id="v37" data-v="37"> 十个盆座的铸法、大小和形状相同。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 40:11–12; 撒迦利亚书 13:1; 约翰一书 1:7"> 他又用铜制造了十个盆，盆径一米八，容量八百八十升。十个铜盆分别放在十个盆座上。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志下 4:10; 历代志下 4:6"> 殿门左右各放五个盆座。铜海放在殿的东南角。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 4:11–16; 出埃及记 24:6; 出埃及记 39:32–43"> 户兰又造了锅、铲和碗。他为所罗门王完成了耶和华殿的一切工作。</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 7:15–22; 历代志下 4:12"> 他所制造的有两根柱子，两个碗状的柱冠，两个装饰柱冠的网子，</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 7:20"> 四百个安在网子上的石榴，每个网子上两行石榴，用来装饰碗状的柱冠；</span>
<span className="v" id="v43" data-v="43"> 十个盆座及盆座上的十个盆；</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 7:23; 列王纪上 7:25"> 铜海和铜海下面的十二头铜牛；</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及记 27:3; 出埃及记 38:3; 历代志下 4:16"> 锅、铲、碗。这些都是户兰给所罗门王用磨亮的铜为耶和华的殿造的器具。</span>
<span className="v" id="v46" data-v="46" data-xref="约书亚记 3:16; 历代志下 4:17; 创世记 33:17"> 这些都是照王的命令在疏割和撒拉但之间的约旦平原用泥模铸成的。</span>
<span className="v" id="v47" data-v="47" data-xref="历代志上 22:14; 历代志上 22:3; 历代志下 4:18"> 所罗门没有称过这些器具，因为太多，铜的重量无法统计。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及记 37:10–16; 历代志下 4:8; 出埃及记 39:36"> 所罗门又为耶和华的殿造了以下器具：金坛和放供饼的金桌；</span>
<span className="v" id="v49" data-v="49" data-xref="历代志下 4:7; 历代志下 4:20; 撒迦利亚书 4:11–14"> 至圣所前面的纯金灯台，左右各五个；灯台上的金花、灯盏和灯剪；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 25:29; 历代志下 4:21–22; 出埃及记 27:3"> 纯金造的杯、灯剪、碗、碟和火鼎，以及至圣所和外殿入口的金门枢。</span>
<span className="v" id="v51" data-v="51" data-xref="历代志下 5:1; 撒母耳记下 8:7–11; 历代志上 28:11–18"> 所罗门王完成耶和华殿的一切工作后，就把他父亲大卫献给耶和华的金银和器具都搬进耶和华殿的库房。</span>
</div>

## 所罗门求智慧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:24; 列王纪上 11:1; 列王纪上 6:1–15"> 所罗门娶了埃及法老的女儿，与法老联姻。他在自己的王宫、耶和华的殿和耶路撒冷的城墙完工之前，让她一直住在大卫城。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 22:43; 历代志下 33:17; 申命记 12:2–5"> 那时候，用来尊崇耶和华之名的殿还没有建成，以色列人仍然在丘坛献祭。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 8:3; 诗篇 31:23; 申命记 30:16"> 所罗门爱耶和华，遵行他父亲大卫的律例，只是仍然在丘坛献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 7:5"> 有一次，所罗门王上基遍献了一千头祭牲作燔祭，因为那里有最重要的丘坛。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 9:2; 雅各书 1:5–6; 民数记 12:6"> 在基遍，耶和华晚上在梦中向所罗门显现，对他说：“你想要什么，只管向我求。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:4; 列王纪上 1:48; 哥林多后书 9:11"> 所罗门说：“你的仆人——我父大卫本着诚实、公义、正直的心在你面前行事，你就向他大施恩慈，并且一如既往地以厚恩待他，让他儿子今天继承他的王位。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 29:1; 民数记 27:17; 耶利米书 1:6"> 我的上帝耶和华啊，你让仆人继承我父大卫的王位，但仆人还年幼无知，不懂得如何治理国家。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:5; 创世记 13:16; 历代志上 21:2"> 仆人住在你所拣选的子民中，这些子民多得不可胜数。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:5; 箴言 16:16; 希伯来书 5:14"> 求你赐我智慧治理你的子民，并能辨别是非；不然，谁能治理你这众多的子民呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 主喜悦所罗门的祈求，</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:26; 雅各书 4:2–3; 箴言 16:31"> 对他说：“既然你不为自己求寿、求财富，也不求灭绝仇敌，只求有智慧秉公治理我的子民，</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 传道书 1:16; 马太福音 12:42"> 我必应允你，赐给你空前绝后的智慧和悟性。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 3:20; 马太福音 6:33; 箴言 3:16"> 你没有求富贵和尊荣，但我会一并赐给你，使你有生之年在列王中无人能比。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 诗篇 91:16; 列王纪上 15:5"> 你若像你父亲大卫一样遵行我的道，遵守我的律例和诫命，我必使你长寿。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 41:7; 列王纪上 8:65; 以斯帖记 1:3"> 所罗门醒来，发现是做了一个梦。他回到耶路撒冷，站在耶和华的约柜前献上燔祭和平安祭，又宴请群臣。</span>
</div>
</div>

## 智断死婴案

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:16; 士师记 11:1; 民数记 27:2"> 一天，两个妓女到王面前告状。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 创世记 43:20"> 其中一个说：“我主啊，我跟这女人同住，我生了一个男孩，当时她也在场。</span>
<span className="v" id="v18" data-v="18"> 我生产三天后，她也生了一个男孩。我们住在一起，除了我们二人，屋里没有别人。</span>
<span className="v" id="v19" data-v="19"> 一天晚上，她不小心压死了自己的孩子。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:20; 马太福音 13:25; 诗篇 139:11"> 她半夜起来，趁我熟睡的时候抱走了我身边的孩子，放在她怀中，把她的死孩子放在我怀中。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:7; 撒母耳记上 1:23; 耶利米哀歌 4:3–4"> 天快亮的时候，我起来给孩子喂奶，发现孩子死了。天亮后，我仔细察看孩子，发现孩子不是我生的。”</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 3:23–24"> 另一个女人说：“不对！活孩子是我的，死孩子是你的。”第一个女人说：“不对！死孩子是你的，活孩子是我的。”两个女人在王面前争吵起来。</span>
<span className="v" id="v23" data-v="23"> 王见她们二人都说活孩子是自己的，死孩子是对方的，</span>
<span className="v" id="v24" data-v="24"> 就命人拿刀来。侍从把刀拿来后，</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王下令将那活孩子劈成两半，让她们各得一半。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 49:15; 耶利米书 31:20; 约翰一书 3:17"> 活孩子的母亲心疼自己的孩子，就说：“我主啊，把孩子给她吧，千万不要杀他！”但另一个女人却说：“孩子不归我，也不归你，把他劈开吧！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 王说：“不可杀这孩子，把他交给刚才为孩子求情的女人吧！她是孩子的母亲。”</span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 2:47; 列王纪上 3:9–12; 歌罗西书 2:3"> 以色列人听见王这样断案，都敬畏他，因为他们知道他有上帝所赐的智慧，能够秉公断案。</span>
</div>
</div>

</div>

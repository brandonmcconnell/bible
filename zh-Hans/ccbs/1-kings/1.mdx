## 王位之争

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:1–2; 历代志上 29:27–28; 历代志上 23:1"> 大卫王年纪老迈，虽然盖了几层被子，仍然觉得冷。</span>
<span className="v" id="v2" data-v="2" data-xref="传道书 4:11; 创世记 16:5; 弥迦书 7:5"> 他的臣仆建议：“不如选一位少女进宫伺候、照顾我主我王，让她睡在王怀中给王取暖。”</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 19:18; 以斯帖记 2:4; 以斯帖记 2:2"> 于是，他们在以色列全国寻找美貌女子，找到了一位名叫雅比莎的书念少女，把她带到王那里。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:25"> 这女子长得非常美丽，她照顾、伺候王，但王没有与她同房。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 15:1; 撒母耳记下 3:4; 申命记 17:15–16"> 那时，哈及的儿子亚多尼雅妄自尊大，说：“我必做王。”他为自己制备了车辆和骑兵，派五十人在前面开路。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 3:3–4; 撒母耳记上 3:13; 希伯来书 12:5–6"> 他父亲从不责问他：“你这是做什么？”他是押沙龙的弟弟，长得英俊非凡。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 20:25; 列王纪上 2:22; 撒母耳记上 22:20–23"> 亚多尼雅与洗鲁雅的儿子约押及祭司亚比亚他商议，二人都答应支持他。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 4:18; 撒母耳记下 23:8–39; 撒母耳记下 20:25"> 不过，撒督祭司、耶何耶大的儿子比拿雅、拿单先知、示每、利以和大卫的勇士却没有跟随他。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 17:17; 撒母耳记下 13:23–27; 撒母耳记下 15:11–12"> 一天，亚多尼雅在隐·罗结附近的琐希列磐石那里宰了牛羊和肥牛犊献祭，并邀请了众王子和犹大的群臣。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:24; 列王纪上 1:19; 撒母耳记下 12:1–15"> 可是他没有邀请拿单先知、比拿雅、大卫的勇士和他的兄弟所罗门。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 3:4; 撒母耳记下 7:12–17; 撒母耳记下 12:24–25"> 拿单对所罗门的母亲拔示巴说：“你没有听说吗？哈及的儿子亚多尼雅做王了，我们的主大卫还不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行传 27:31; 创世记 19:17"> 事到如今，我有一个主意，可以保住你和你儿子所罗门的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 1:30; 列王纪上 1:17; 诗篇 132:11–12"> 你去见大卫王，对他说，‘我主我王啊，你不是起誓说让臣妾的儿子所罗门继承王位，坐你的宝座吗？怎么现在亚多尼雅做了王呢？’</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 13:1; 列王纪上 1:17–27"> 你跟王还在说话的时候，我会进去证实你的话。”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 1:1"> 拔示巴就进内室去见年迈的王，书念的少女雅比莎正在伺候他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:23; 撒母耳记上 24:8; 撒母耳记上 20:41"> 拔示巴向王屈身下拜。王问道：“你有什么事吗？”</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 1:13; 列王纪上 1:30; 彼得前书 3:6"> 拔示巴回答说：“我主啊，你曾经凭你的上帝耶和华起誓说让臣妾的儿子所罗门继承你的王位，坐你的宝座。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:24; 列王纪上 1:11; 使徒行传 3:17"> 但现在亚多尼雅已经称王了，我主我王还不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 1:25; 列王纪上 1:7–10"> 他宰了许多牛羊和肥牛犊献祭，邀请众王子、亚比亚他祭司和约押元帅，却没有邀请你的仆人所罗门。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 29:1; 诗篇 123:2; 历代志上 22:8–10"> 我主我王啊！以色列举国拭目以待，等你来指定谁坐在我主我王的宝座上继承王位。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 申命记 31:16; 创世记 15:15"> 不然，到我主我王与祖先同眠之后，我和我儿所罗门必被定为罪人。”</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 1:16–18; 创世记 24:15; 但以理书 9:20"> 她与王正说话间，拿单先知进宫来了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 1:16; 彼得前书 2:17; 罗马书 13:7"> 有人奏告王，说：“拿单先知来了。”拿单来到王面前，俯伏在地，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:17–18; 列王纪上 1:5; 列王纪上 1:13–14"> 说：“我主我王啊，你已经宣布让亚多尼雅继承你的王位，坐你的宝座吗？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 10:24; 列王纪上 1:19; 列王纪上 1:9"> 他今天宰了许多牛羊和肥犊献祭，宴请众王子、将领和亚比亚他祭司，他们正在他那里一边吃喝一边说，‘亚多尼雅王万岁！’</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 1:8; 列王纪上 1:10; 撒母耳记下 7:2"> 但他没有邀请臣仆我、撒督祭司、耶何耶大的儿子比拿雅和你的仆人所罗门。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 15:15; 列王纪上 1:24; 列王纪下 4:27"> 这是我主我王的旨意吗？王还没有对臣仆们说过谁坐在我主我王的宝座上继承王位。”</span>
<span className="v" id="v28" data-v="28"> 于是，大卫王召见拔示巴。拔示巴立刻晋见，侍立在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 4:9; 诗篇 136:24; 撒母耳记上 14:45"> 王起誓说：“我凭救我脱离一切苦难的永活的耶和华起誓，</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:13; 列王纪上 1:17"> 我今天必实现我凭以色列的上帝耶和华向你起的誓。你的儿子所罗门必继承王位，坐在我的宝座上。”</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 2:4; 但以理书 5:10; 但以理书 3:9"> 拔示巴就向王俯伏下拜说：“我主大卫王万岁！”</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 1:8; 列王纪上 1:38; 列王纪上 1:26"> 大卫王又召见撒督祭司、拿单先知和耶何耶大的儿子比拿雅。他们都来到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 32:30; 列王纪上 1:38; 历代志下 33:14"> 王嘱咐道：“你们要率领我的随从，让我儿所罗门骑上我的骡子，护送他下到基训。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 1:25; 撒母耳记下 15:10; 撒母耳记上 10:1"> 撒督祭司和拿单先知要在那里膏立他为以色列王。你们要吹响号角，高喊，‘所罗门王万岁！’</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 1:17; 诗篇 72:1–2; 列王纪上 1:13"> 然后，你们要随他回来，他要登基，继承我的王位。我已立他做以色列和犹大的君王了。”</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 28:6; 哥林多前书 14:16; 诗篇 72:19"> 耶何耶大的儿子比拿雅说：“遵命！愿我主我王的上帝耶和华成全这事。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:13; 列王纪上 1:47; 约书亚记 1:17"> 耶和华怎样与我主我王同在，愿祂也照样与所罗门同在，使他的王权比我主大卫王的更强大。”</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 8:18; 列王纪上 1:8; 列王纪上 1:33"> 于是，撒督祭司、拿单先知、耶何耶大的儿子比拿雅，以及基利提人和比利提人请所罗门骑上大卫王的骡子，护送他前往基训。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 89:20; 列王纪上 1:34; 历代志上 29:22"> 撒督祭司从圣幕里拿来盛膏油的角，膏立所罗门为王。他们吹响号角，民众高声欢呼：“所罗门王万岁！”</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 11:14; 撒迦利亚书 9:9; 列王纪下 11:20"> 众人浩浩荡荡地随着所罗门回京，一路上吹笛欢呼，声音震动大地。</span>
<span className="v" id="v41" data-v="41" data-xref="约伯记 15:21–22; 路加福音 17:26–29; 使徒行传 21:31"> 亚多尼雅和他的众宾客刚刚饮宴完毕，听见了这声音。约押听见号角声，便问：“城里为什么如此喧闹？”</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 15:36; 撒母耳记下 17:17; 撒母耳记下 18:27"> 就在这时候，亚比亚他祭司的儿子约拿单来了，亚多尼雅说：“进来！你是个忠勇的人，一定带来了好消息。”</span>
<span className="v" id="v43" data-v="43"> 约拿单说：“我们的主大卫王已经立所罗门为王了。</span>
<span className="v" id="v44" data-v="44"> 王派撒督祭司、拿单先知、耶何耶大的儿子比拿雅，以及基利提人和比利提人护送所罗门骑上王的骡子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 1:40; 但以理书 5:26–28; 撒母耳记上 4:5"> 撒督祭司和拿单先知在基训膏立他为王，他们一路上欢呼着回来了，全城轰动。你们听到的就是他们的声音。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志上 29:23; 诗篇 132:11; 列王纪上 1:13"> 所罗门已经登基掌权，</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 47:31; 列王纪上 1:37; 以斯拉记 6:10"> 王的臣仆也来向我们的主大卫王道喜说，‘愿你的上帝使所罗门比你名声更大，使他的王权比你的更强大。’王在床上俯伏敬拜，</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 3:6; 诗篇 132:11–12; 诗篇 145:2"> 说，‘以色列的上帝耶和华当受称颂，因为祂让我亲眼看见我的继承人今天登基。’”</span>
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 21:4–5; 箴言 28:1; 但以理书 5:4–6"> 亚多尼雅的众宾客听后，吓得四散而去。</span>
<span className="v" id="v50" data-v="50" data-xref="列王纪上 2:28; 出埃及记 21:14; 出埃及记 27:2"> 亚多尼雅惧怕所罗门，就去抓住祭坛的角。</span>
<span className="v" id="v51" data-v="51"> 有人告诉所罗门：“亚多尼雅惧怕王，现在正抓住祭坛的角，要王今天起誓不要杀他。”</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 14:45; 撒母耳记下 14:11; 箴言 13:6"> 所罗门说：“他若做个忠义的人，必毫发无损；他若作恶，必死无疑。”</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪上 1:16; 撒母耳记下 14:24; 撒母耳记下 1:2"> 于是，所罗门王便派人去把亚多尼雅从祭坛上带下来。亚多尼雅前来向所罗门王俯伏下拜，所罗门对他说：“你回家去吧。”</span>

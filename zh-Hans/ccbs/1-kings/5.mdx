## 预备建造圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 14:1; 历代志下 2:3; 列王纪上 5:10"> 泰尔王希兰素来与大卫修好，他听说以色列人膏立了所罗门继承大卫的王位，就派使者来见所罗门。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:3"> 所罗门也传信给希兰，说：</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 28:3; 历代志上 22:8; 诗篇 110:1"> “你知道，我父大卫因周围战事连连，未能为他的上帝耶和华的名建殿，要等到耶和华使仇敌伏在他脚下后再建。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 22:9; 列王纪上 4:24; 使徒行传 9:31"> 现在我的上帝耶和华使我四境太平，内外无患，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 17:12; 历代志上 22:10; 撒母耳记下 7:12–13"> 我想为我的上帝耶和华建殿，因为耶和华曾对我父大卫说，‘我必使你的儿子继承你的王位，他必为我的名建殿。’</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 2:8; 列王纪上 6:9–10; 罗马书 12:17"> 请你命人为我砍伐黎巴嫩的香柏木。我会派人帮助你的人，并按你的要求付你的人工钱。因为你知道，我们没有人像西顿人那样善于砍伐树木。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 23:24; 以赛亚书 9:6; 历代志下 2:11–12"> 希兰听了所罗门的话后，非常高兴，说：“今天当赞美耶和华！祂赐给大卫一个有智慧的儿子治理这伟大的民族。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:34; 历代志下 3:5; 撒母耳记下 6:5"> 他派人回复所罗门说：“我已收到你派人带来的口信。我一定会照你的心愿提供香柏木和松木。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 3:7; 以西结书 27:17; 使徒行传 12:20"> 我的工人会将这些木料从黎巴嫩运到海边，扎成木筏，经海道运到你指定的地点。木筏拆散以后，你就可以点收了。你也要成全我的心愿，供应我家食粮。”</span>
<span className="v" id="v10" data-v="10"> 于是，希兰供应所罗门需用的香柏木和松木，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:10; 列王纪上 4:22"> 所罗门每年供应希兰四百四十万升麦子和四十四万升橄榄油。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 3:12; 阿摩司书 1:9; 雅各书 1:5"> 耶和华照着应许赐给所罗门智慧。他跟希兰修好，缔结盟约。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 9:15; 列王纪上 4:6"> 所罗门王从以色列征集了三万劳工，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 4:6–19; 历代志上 27:1–15"> 派他们每月轮班到黎巴嫩工作，每班一万人，在黎巴嫩一个月，在家两个月。亚多尼兰做他们的总管。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 9:20–22; 历代志下 2:17–18; 历代志下 8:7–9"> 所罗门又征用了七万名搬运工，八万名在山上凿石的匠人。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 9:23; 历代志下 2:2"> 此外，他还派了三千三百名监工，监督工人做工。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 6:7; 历代志上 22:2; 以赛亚书 28:16"> 他们按照王的命令在山上凿出珍贵的巨石，用来作殿的根基。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 13:5; 以西结书 27:9; 诗篇 83:7"> 于是，所罗门和希兰的工匠及迦巴勒人凿好石头，备好木料，准备建殿。</span>
</div>
</div>

</div>

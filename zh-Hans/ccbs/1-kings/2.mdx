## 大卫对所罗门的叮嘱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 47:29; 申命记 31:14; 提摩太前书 1:18"> 大卫临终时，叮嘱他儿子所罗门说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:6–7; 约书亚记 23:14; 以弗所书 6:10"> “我要走世人都必走的那条路了。你要刚强，做大丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:9; 申命记 17:18–20; 箴言 3:1–4"> 你要遵从你的上帝耶和华的吩咐，遵行祂的道，照摩西的律法遵守上帝的律例、诫命、典章和法度。这样，你无论做什么、去哪里都必亨通，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 20:3; 撒母耳记下 7:25; 列王纪上 8:25"> 耶和华必成就给我的应许，祂对我说，‘如果你的子孙谨慎自守，全心全意地在我面前尽忠，你的以色列王朝必世代相传。’</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:27; 撒母耳记下 20:10; 撒母耳记下 18:5"> “你知道洗鲁雅的儿子约押怎样对我，他杀了以色列的两名元帅尼珥的儿子押尼珥和益帖的儿子亚玛撒。他在太平的时候把他们当作战场的敌手杀害，腰带和鞋上沾满了他们的血。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 2:9; 以赛亚书 57:21; 诗篇 37:37"> 你要用智慧处置他，不可让他安享天年。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 17:27–29; 撒母耳记下 9:7; 撒母耳记下 19:31–40"> “你要恩待基列人巴西莱的众子，让他们成为你的座上宾，因为我逃避你哥哥押沙龙的时候，他们曾接待我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 16:5–8; 列王纪上 2:36–46; 撒母耳记下 19:16–23"> “别放过巴户琳的便雅悯人基拉的儿子示每。我逃亡到玛哈念的时候，他曾用恶毒的话咒骂我。后来他到约旦河迎接我的时候，我曾凭耶和华起誓不杀他。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:6; 创世记 42:38; 创世记 44:31"> 但你不要放过他。你是个聪明人，知道该怎样处置他。你要让他白头落地，不得善终。”</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:29; 使徒行传 13:36; 列王纪上 1:21"> 大卫与祖先同眠后，葬在大卫城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:4–5; 历代志上 29:26–27"> 他统治以色列四十年，他在希伯仑执政七年，在耶路撒冷执政三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 1:1; 历代志上 29:23–25; 诗篇 132:12"> 所罗门继承大卫的王位，江山稳固。</span>
</div>
</div>

## 所罗门巩固王位

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 16:4–5; 列王纪上 1:5–10; 路加福音 10:5–6"> 一天，哈及的儿子亚多尼雅来见所罗门的母亲拔示巴，拔示巴问他：“你是为平安而来吗？”亚多尼雅说：“是为平安而来。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:12; 路加福音 7:40"> 又说：“我有事禀告。”拔示巴说：“你说吧。”</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 历代志上 28:5–7; 列王纪上 1:25"> 亚多尼雅说：“你知道，王位本该是我的，整个以色列原指望我做王。不料，王位归了我兄弟，因为这是上帝的旨意。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 诗篇 132:10"> 现在我有一个请求，请你不要推辞。”拔示巴说：“你说吧。”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:8; 列王纪上 1:2–4; 撒母耳记下 3:7"> 他说：“请你求所罗门王将那书念女子雅比莎赐我为妻，他不会拒绝你。”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 拔示巴说：“好吧，我会为你向王请求。”</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 45:9; 列王纪上 15:13; 利未记 19:32"> 拔示巴就为亚多尼雅的事去见所罗门王，王离座迎接，向她下拜，然后坐回位上，命人在自己右边为她摆设座位。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:7–11; 马太福音 11:24; 约翰福音 2:3–4"> 拔示巴说：“我有一件小事求你，请你不要推辞。”王说：“母亲请说，我必不推辞。”</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 1:3; 撒母耳记下 16:21–22"> 拔示巴说：“请将书念女子雅比莎赐给你哥哥亚多尼雅为妻。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 3:2; 历代志上 3:5; 马太福音 20:22"> 所罗门王回答说：“为何只为亚多尼雅求书念女子雅比莎呢？你也为他求这国家吧！他是我哥哥，又有亚比亚他祭司和洗鲁雅的儿子约押支持。”</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 1:17; 诗篇 140:9; 诗篇 64:8"> 所罗门王就凭耶和华起誓说：“亚多尼雅若不为他这样的要求付出性命，愿上帝重重地惩罚我。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:10; 历代志上 17:10; 历代志上 17:17"> 耶和华让我稳稳地坐在父亲大卫的宝座上，照祂的应许为我建立了王朝，我凭永活的耶和华起誓，亚多尼雅今天必被处死。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 8:18; 列王纪上 2:46; 士师记 8:20–21"> 于是，所罗门王命令耶何耶大的儿子比拿雅杀死亚多尼雅。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 21:18; 撒母耳记上 22:20–23; 耶利米书 1:1"> 王对亚比亚他祭司说：“你回亚拿突的老家去吧。你本是该死的，但我念你在我父大卫面前抬过主耶和华的约柜，曾经与我父亲患难与共，才饶你一命。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:27–36; 撒母耳记上 3:12–14; 耶利米书 7:12–14"> 所罗门就罢免了亚比亚他的职位，不许他再做耶和华的祭司。这事应验了耶和华在示罗所说的有关以利家的预言。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 1:50; 列王纪上 1:7; 撒母耳记下 18:2"> 约押虽然没有支持押沙龙，但却支持了亚多尼雅。他听见风声，就逃进圣幕，抓住祭坛的角。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 2:25; 出埃及记 21:14; 列王纪上 2:46"> 有人把这消息告诉所罗门王，说约押已经逃进圣幕，躲在祭坛旁边。所罗门就派耶何耶大的儿子比拿雅去杀他。</span>
<span className="v" id="v30" data-v="30"> 比拿雅来到耶和华的圣幕，对约押说：“王吩咐你出来！”约押却回答说：“不，我要死在这里。”比拿雅回去禀告王。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 21:8–9; 民数记 35:33; 出埃及记 21:14"> 王说：“你就照他的话成全他，埋葬他，把他滥杀无辜的罪从我和我父亲家清除。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 9:24; 士师记 9:57; 诗篇 7:16"> 耶和华要让他血债血还。因为他背着我父亲杀了两名比他良善正直的人，即尼珥的儿子以色列元帅押尼珥和益帖的儿子犹大元帅亚玛撒。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:25; 列王纪上 2:32; 路加福音 2:14"> 所以，杀这二人的血债必永远归到约押和他后代身上。愿耶和华的平安永远伴随大卫和他的后代、他的家、他的王位。”</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 3:1; 约书亚记 15:61; 列王纪上 2:25"> 耶何耶大的儿子比拿雅就去把约押杀死，葬在旷野约押自己的墓地。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 2:27; 历代志上 24:3; 历代志上 29:22"> 王委派耶何耶大的儿子比拿雅替代约押为元帅，命撒督祭司代替亚比亚他。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 16:5–9; 列王纪上 2:8–9; 箴言 20:26"> 王又派人将示每召来，对他说：“你要在耶路撒冷建屋居住，不得出城去其他地方。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 1:16; 撒母耳记下 15:23; 约书亚记 2:19"> 你哪天越过汲沦溪，哪天必死无疑，你的死是咎由自取。”</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 20:4; 列王纪下 20:19"> 示每说：“好，仆人必照我主我王说的做。”示每就一直住在耶路撒冷。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 21:10; 撒母耳记上 27:2–3"> 过了三年，示每的两个仆人逃到迦特王玛迦的儿子亚吉那里。示每知道后，</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前书 6:10"> 就备上驴到迦特的亚吉那里找他的仆人，并把他们带了回来。</span>
<span className="v" id="v41" data-v="41"> 所罗门听说示每从耶路撒冷前往迦特，已经返回，</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 15:4; 列王纪上 2:36–38; 路加福音 15:22"> 就派人召来示每，问道：“我不是叫你凭耶和华起誓不离开耶路撒冷吗？我警告过你，你哪天离开这里，哪天必死无疑。当时你也同意。</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 13:5; 历代志下 30:12; 传道书 8:2"> 现在你为何不守你向耶和华起的誓，不遵行我的命令？”</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 16:5–13; 诗篇 7:16; 以西结书 17:19"> 王又说：“你以前如何恶待我父大卫，你自己心里明白，现在耶和华要追究你的罪行了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王纪上 2:24; 以赛亚书 9:6–7"> 但所罗门王必蒙祝福，大卫的王位必在耶和华面前必永远稳固。”</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 1:1; 列王纪上 2:12; 列王纪上 2:45"> 于是，王命令耶何耶大的儿子比拿雅杀死示每。这样所罗门的江山得以稳固。</span>

## 亚兰王攻打撒玛利亚城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 15:18; 列王纪上 15:20; 列王纪上 22:31"> 亚兰王便·哈达率领全军，联合三十二个王，带着车马围攻撒玛利亚。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 36:2–22; 列王纪下 19:9; 以赛亚书 37:9–10"> 他派遣使者进城对以色列王亚哈说：</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:9; 以赛亚书 10:13–14"> “便·哈达说，‘你的金银和你家中最美的妻妾儿女都是我的。’”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 15:11–13; 申命记 28:48; 撒母耳记上 13:6–7"> 以色列王说：“我主我王啊，我答应你的要求，我和我的一切都是你的。”</span>
<span className="v" id="v5" data-v="5"> 不久，使者又来对他说：“便·哈达说，‘我已派人吩咐你把金银、妻妾和儿女都给我。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 25:34; 约珥书 3:5; 列王纪下 18:31–32"> 明天约这个时候，我会派属下搜查你的王宫和你臣仆的家，他们要拿走你珍爱的一切。’”</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:7; 箴言 6:14; 列王纪上 8:1"> 以色列王亚哈召集国中的长老，说：“你们看，这人是在找麻烦。他之前派人来要我的妻妾、孩子和金银，我没有拒绝他。”</span>
<span className="v" id="v8" data-v="8"> 长老和百姓都说：“别听从他，别答应他。”</span>
<span className="v" id="v9" data-v="9"> 于是，他对使者说：“你们告诉我主我王，他第一次所要的，仆人可以照办，但这一次所要的，仆人不能从命。”使者就去回复便·哈达。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 19:2; 出埃及记 11:8; 列王纪下 19:23–24"> 便·哈达又派人去对亚哈说：“若撒玛利亚的尘土够我的士兵每人抓一把，愿神明重重地惩罚我。”</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 27:1; 以赛亚书 10:15–16; 撒母耳记上 17:44–47"> 以色列王说：“你去告诉便·哈达，叫他别刚穿上盔甲就夸口，打完仗卸下盔甲再夸口吧。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 16:9; 列王纪上 20:16; 箴言 31:4–5"> 便·哈达和诸王正在营中饮酒，听见这话，就吩咐属下准备攻城。</span>
</div>
</div>

## 亚哈打败便·哈达

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 20:28; 以西结书 20:22; 以赛亚书 7:1–9"> 一位先知来见以色列王亚哈，说：“耶和华说，‘你看见这大军了吗？今天我必将他们交在你手里，这样你就知道我是耶和华。’”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 17:50; 创世记 14:14–16; 列王纪上 18:44"> 亚哈问：“谁来完成这任务呢？”先知答道：“耶和华说，省长属下的青年军。”亚哈问：“谁来做统领呢？”先知答道：“你。”</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 7:16; 撒母耳记上 14:2; 士师记 7:7"> 于是，亚哈召集了省长属下的青年军二百三十二人，又召集以色列全军，共七千人。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 10:16–17; 何西阿书 4:11; 列王纪上 16:9"> 中午，便·哈达正跟盟军的三十二个王在营中狂饮的时候，亚哈率军出发了。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 20:14–15; 列王纪上 20:19"> 省长属下的青年军率先出城。便·哈达派出的巡逻队禀告他说：“有人从撒玛利亚城出来了。”</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 14:8–12; 撒母耳记上 14:11–12; 箴言 18:12"> 便·哈达说：“不管他们是来求和还是求战，都要生擒他们！”</span>
<span className="v" id="v19" data-v="19"> 省长属下的青年军率先出城，大军紧随其后，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 30:16–17; 列王纪下 19:36; 传道书 9:11"> 他们见敌人就杀。亚兰人败逃，以色列人乘势追击。亚兰王便·哈达骑着马与一些骑兵落荒而逃。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 3:18; 士师记 3:28; 列王纪下 3:24"> 以色列王出城攻击敌军车马，重创亚兰人。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 11:1; 列王纪上 20:26; 列王纪上 20:13"> 先知又来见以色列王，说：“你要加强防卫，做好准备，因为明年春天亚兰王必卷土重来。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 14:23; 撒母耳记上 4:8; 诗篇 50:21–22"> 臣仆给亚兰王献计说：“以色列人的神明是山神，所以他们占了上风，我们若在平原上跟他们交战，一定会取胜。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 22:31; 箴言 21:30; 列王纪上 20:16"> 王应该撤去诸王，委任将领代替他们，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 10:3"> 再招募军兵，补充失去的战车和人马，好在平原上跟他们交战，这样我们一定会取胜。”王采纳了他们的建议。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 13:17; 列王纪上 20:22; 撒母耳记上 4:1"> 第二年春天，便·哈达召集亚兰人进军亚弗，攻打以色列人。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 6:5; 撒母耳记上 13:5–8; 撒母耳记上 14:2"> 以色列人也召集军队，准备粮草，迎战亚兰人。他们在亚兰人对面安营，像两小群山羊，而亚兰人却满山遍野。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 20:13; 列王纪上 17:18; 以西结书 12:16"> 有位上帝的仆人来见以色列王，说：“耶和华说，‘亚兰人以为我耶和华是山神，不是平原的神，所以我必将这大军交在你手里，这样你们就知道我是耶和华。’”</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 13:17; 历代志下 28:6; 诗篇 10:16"> 以色列人和亚兰人两军对峙，一连七天。第七天，两军交战，以色列军一天杀了十万亚兰步兵，</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 22:25; 历代志下 18:24; 列王纪上 20:26"> 残余的人都逃进亚弗城，但城墙倒塌压死了两万七千人。便·哈达也逃进城，躲在一间房子的内室里。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:31; 创世记 37:34; 列王纪上 20:23"> 臣仆对他说：“我们听说以色列王很仁慈。现在，我们不如腰束麻布，头套绳索，向以色列王请降，也许他会饶王一命。”</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 20:3–6; 约伯记 12:17–18; 但以理书 5:20–23"> 他们便腰束麻布，头套绳索，来见以色列王，说：“仆人便·哈达求王开恩饶命啊！”亚哈回答说：“他还活着吗？他是我的兄弟。”</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 16:8; 列王纪下 10:15; 箴言 25:13"> 他们听见亚哈的口气温和，连忙附和说：“是啊，便·哈达是王的兄弟。”亚哈便吩咐他们去把便·哈达带来见他，然后让便·哈达登上他的战车。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 15:20; 以赛亚书 26:10; 列王纪上 20:42"> 便·哈达对亚哈说：“我必归还我父亲从你父亲那里夺来的城邑，你可以在大马士革设立贸易区，就像我父亲在撒玛利亚所设立的一样。”亚哈回答说：“你依此立个约，我就放你走。”立约之后，亚哈就放便·哈达走了。</span>
</div>
</div>

## 先知责备亚哈

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪下 2:15; 列王纪上 13:17–18; 列王纪下 4:1"> 众先知中有一位奉耶和华的命令对他的同伴说：“你打我吧！”同伴却不肯动手。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 13:21–24; 列王纪上 13:26; 撒母耳记上 15:22–23"> 那位先知就对他说：“你既然不听从耶和华的吩咐，你一离开我，就会被狮子咬死。”那同伴走后，果然遇见狮子，被咬死了。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 21:12; 列王纪上 20:35"> 那先知又找了一个人，叫那人打他，那人就打他，把他打伤了。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 14:2; 马太福音 6:16; 列王纪上 22:30"> 先知用头巾蒙着眼睛，乔装改扮，在路旁等候亚哈王。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪下 10:24; 约伯记 36:18; 彼得前书 1:18–19"> 亚哈王经过的时候，他向王喊道：“仆人在打仗的时候，有人押来一个俘虏，要我看管，他说如果俘虏跑掉，我就要以性命抵偿，或赔偿六百八十两银子。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 12:5–7; 马太福音 25:24–27; 约伯记 15:6"> 可是那俘虏趁仆人忙乱之际跑掉了。”以色列王说：“这是你自己的过失，你要自负其咎。”</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 6:26; 撒母耳记下 13:19; 约伯记 2:8"> 先知立刻拿去蒙眼的头巾，以色列王认出他是个先知。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 22:31–37; 历代志下 18:33–34; 列王纪上 20:39"> 他对王说：“耶和华说，‘你放走了我决定要毁灭的人，所以你的命要抵他的命，你百姓的命要抵他百姓的命。’”</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 21:4; 以斯帖记 5:13; 以斯帖记 6:12–13"> 以色列王闷闷不乐地回撒玛利亚的王宫去了。</span>
</div>

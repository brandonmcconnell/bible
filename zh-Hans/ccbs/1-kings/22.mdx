## 米该雅先知警告亚哈王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:34"> 亚兰和以色列之间三年无战事。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:24; 列王纪上 22:1; 列王纪上 22:41"> 第三年，犹大王约沙法来见以色列王亚哈。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:43; 列王纪上 4:13; 约书亚记 21:38"> 以色列王对臣仆说：“你们都知道基列的拉末是我们的领土，我们岂能坐视不理，不从亚兰王手中夺回来呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 3:7; 以弗所书 5:11; 约翰二书 1:11"> 他问约沙法：“你愿意跟我一起去攻打基列的拉末吗？”约沙法回答说：“你我不分彼此，我的民就是你的民，我的马就是你的马。”</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:5–6; 历代志下 18:4–5; 耶利米书 42:2–6"> 约沙法又对以色列王说：“你要先求问耶和华。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 18:19; 耶利米书 23:14–17; 以西结书 13:7–16"> 于是，以色列王召来约四百名先知，问他们：“我该去攻打基列的拉末吗？”他们说：“去吧，主必把那城交在王手中。”</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:11–13; 历代志下 18:6–7"> 但约沙法问：“这里没有耶和华的先知供我们求问吗？”</span>
<span className="v" id="v8" data-v="8" data-xref="阿摩司书 5:10; 约翰福音 3:19–21; 约翰福音 7:7"> 以色列王回答说：“还有一个人，是音拉的儿子米该雅，我们可以托他求问耶和华。可是我厌恶他，因为他给我的预言都是有凶无吉。”约沙法说：“王不要这样说。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:32; 以赛亚书 39:7; 列王纪上 22:26–27"> 以色列王召来一名内侍，说：“你快把音拉的儿子米该雅带来。”</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:1; 以斯帖记 6:8–9; 列王纪上 18:29"> 以色列王和犹大王约沙法身穿朝服，坐在撒玛利亚城门前麦场的宝座上，众先知都在他们面前说预言。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 1:18–21; 申命记 33:17; 以西结书 22:27–28"> 基拿拿的儿子西底迦造了两只铁角，说：“耶和华这样说，‘你必用这铁角抵亚兰人，直到毁灭他们。’”</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:22; 列王纪上 22:6–15; 列王纪上 22:32–36"> 所有的先知也都预言说：“去攻打基列的拉末吧，一定得胜，耶和华必将那城交在王的手中。”</span>
<span className="v" id="v13" data-v="13" data-xref="弥迦书 2:6–7; 诗篇 11:1; 以赛亚书 30:10–11"> 去召米该雅的使者对米该雅说：“众先知都异口同声地向王说吉言，你也像他们一样说些吉言吧。”</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 24:13; 民数记 22:18; 历代志下 18:12–13"> 米该雅回答说：“我凭永活的耶和华起誓，耶和华对我说什么，我就说什么。”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:27; 士师记 10:14; 马太福音 26:45"> 米该雅来到王面前，王就问他：“米该雅啊，我们该不该去攻打基列的拉末？”米该雅回答说：“上去攻打吧，一定得胜，耶和华必将那城交在王手中。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 19:13; 马太福音 26:63; 约书亚记 6:26"> 王却说：“我要你起誓多少次，你才肯奉耶和华的名对我说实话呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 27:17; 马太福音 9:36; 列王纪上 22:34–36"> 米该雅说：“我看见以色列人都四散在山上，好像没有牧人的羊群一样。耶和华说，‘这些人没有主人，让他们各自平安地回家去吧。’”</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 22:8; 箴言 10:24; 路加福音 11:45"> 以色列王对约沙法说：“我不是告诉过你吗？他给我的预言都是有凶无吉。”</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:1; 约伯记 1:6; 但以理书 7:9–10"> 米该雅说：“你要听耶和华的话。我看见耶和华坐在宝座上，众天军侍立在祂左右。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:9; 约伯记 12:16; 耶利米书 4:10"> 耶和华说，‘谁愿意去引诱亚哈到基列的拉末去送死呢？’众天军议论纷纷。</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 2:1; 列王纪上 22:23; 约伯记 1:6–7"> 后来，有一个灵站出来对耶和华说他愿意去。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 9:23; 撒母耳记上 19:9; 撒母耳记上 16:14"> 耶和华问他用什么方法，他说，‘我要去做谎言之灵，进入他众先知的口中。’耶和华说，‘你必成功诱骗他，就这样做吧。’</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 14:9; 马太福音 24:24–25; 以赛亚书 44:20"> 现在，耶和华已经把谎言之灵放进你这些先知口中，耶和华已决意降祸给你。”</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:2; 耶利米哀歌 3:30; 弥迦书 5:1"> 基拿拿的儿子西底迦听了米该雅的话就上前打他的脸，说：“耶和华的灵怎会离开我向你说话呢？”</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 20:30; 彼得后书 2:1; 启示录 19:20"> 米该雅说：“你躲进密室的那天就知道了。”</span>
<span className="v" id="v26" data-v="26"> 以色列王下令说：“把米该雅交给亚们总督和约阿施王子，</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 16:10; 历代志下 18:25–27; 启示录 2:10"> 告诉他们，‘王说，要把这人关在监牢，只给他一点饼和水，直到我平安回来。’”</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 16:29; 弥迦书 1:2; 使徒行传 13:10–11"> 米该雅说：“你若能平安回来，耶和华就没有借着我说话。”他又说：“众民啊，你们都要记住我的话。”</span>
</div>
</div>

## 亚哈之死

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 18:28; 列王纪上 22:2–9"> 以色列王和犹大王约沙法出兵攻打基列的拉末。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 35:22; 耶利米书 23:24; 撒母耳记上 28:8"> 以色列王对约沙法说：“我要改装上阵，你就穿王袍吧。”以色列王就改装上阵。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 20:24; 历代志下 18:30; 耶利米书 16:6"> 亚兰王已经吩咐他的三十二名战车长不要跟对方的大小军兵交锋，只攻击以色列王。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 13:20; 约拿书 2:1–2; 诗篇 130:1–4"> 战车长看见约沙法，以为他就是以色列王，便转过来攻击他。约沙法高声喊叫，</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 76:10; 列王纪上 22:31"> 战车长见他不是以色列王，便不再追杀他。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:23; 弥迦书 6:13; 撒母耳记上 17:49"> 有人随手放了一箭，射进了以色列王的铠甲缝中。王对驾车的说：“调转车头拉我离开战场吧，我受了重伤。”</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:28; 列王纪上 20:42"> 那天的战事非常激烈，王被人扶着站在车上，迎战亚兰人。到了黄昏，王就死了，车上流满了血。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 14:12; 列王纪上 22:31; 士师记 21:24"> 太阳快要下山的时候，以色列军中传出号令，叫人各回本乡本城。</span>
<span className="v" id="v37" data-v="37"> 王死后，众人把王的尸体运回撒玛利亚安葬，</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 21:19; 马太福音 24:35; 耶利米书 44:21–23"> 并在撒玛利亚妓女洗浴的池边洗他的战车，有狗来舔他的血，正如耶和华所言。</span>
<span className="v" id="v39" data-v="39" data-xref="阿摩司书 3:15; 以西结书 27:6; 诗篇 45:8"> 亚哈其他的事及一切所为，包括他建造的象牙宫和各城邑，都记在《以色列列王史》上。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 7:12; 列王纪下 1:17; 列王纪下 1:2"> 亚哈与祖先同眠后，他儿子亚哈谢继位。</span>
</div>
</div>

## 约沙法做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 20:31; 列王纪上 22:2; 历代志下 17:1"> 以色列王亚哈执政第四年，亚撒的儿子约沙法登基做犹大王。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪下 1:17; 列王纪上 15:2; 列王纪上 15:10"> 约沙法三十五岁登基，在耶路撒冷执政二十五年。他母亲叫阿苏巴，是示利希的女儿。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 15:14; 列王纪下 12:3; 箴言 4:27"> 约沙法事事效法他父亲亚撒，不偏不离，做耶和华视为正的事。但他没有拆除丘坛，人们仍在那里献祭烧香。</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 22:2; 历代志下 19:2; 列王纪下 8:18"> 约沙法与以色列王修好。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 14:29; 列王纪上 11:41; 历代志下 20:34"> 约沙法其他的事迹、功业和战绩都记在《犹大列王史》上。</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪上 15:12; 列王纪上 14:24; 申命记 23:17"> 约沙法从国中除掉了他父亲亚撒时代遗留的男庙妓。</span>
<span className="v" id="v47" data-v="47" data-xref="撒母耳记下 8:14; 列王纪下 3:9; 列王纪下 8:20"> 那时以东没有王，由总督治理。</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 9:26; 列王纪上 10:22; 列王纪上 9:28"> 约沙法又建造了一批他施船，要到俄斐去运载黄金，可是没有成行，因为船只在以旬·迦别坏了。</span>
<span className="v" id="v49" data-v="49"> 后来，亚哈的儿子亚哈谢请求约沙法让他的人跟约沙法的人一起出海，但约沙法拒绝了。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志下 21:1; 列王纪上 22:40; 列王纪上 15:24"> 约沙法与祖先同眠后葬在大卫城他的祖坟里。他儿子约兰继位。</span>
</div>
</div>

## 亚哈谢做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王纪下 1:17; 列王纪上 22:40; 列王纪上 15:25"> 犹大王约沙法执政第十七年，亚哈的儿子亚哈谢在撒玛利亚登基做以色列王，执政两年。</span>
<span className="v" id="v52" data-v="52" data-xref="列王纪上 15:26; 列王纪上 21:25; 启示录 3:20"> 他做耶和华视为恶的事，步他父母的后尘，效法尼八之子耶罗波安，使以色列人陷入罪中。</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪上 16:30–32; 以赛亚书 65:3; 列王纪下 3:2"> 他像他父亲一样供奉、祭拜巴力，惹以色列的上帝耶和华发怒。</span>
</div>

## 示巴女王拜访所罗门

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 历代志下 9:1–12"> 示巴女王听说所罗门因耶和华而名声大震，便来用难题考问他。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:23; 诗篇 4:4; 约伯记 4:2"> 她率领许多随从，用骆驼驮着香料、宝石和大量黄金到耶路撒冷晋见所罗门，与所罗门谈论她心中的疑问。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 马太福音 13:11; 列王纪上 10:1"> 所罗门解答了她所有的问题，没有一样难得住他。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 12:42; 列王纪上 3:28; 历代志下 9:3–4"> 示巴女王见所罗门智慧非凡，又看见他建的宫殿、</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 26:16; 列王纪上 4:22–23; 列王纪下 16:18"> 席上的美味、入座的群臣、侍立的仆人、他们的服装、酒侍，以及他在耶和华殿里献的燔祭，感到万分惊奇。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 9:5–6"> 她对王说：“我在本国听到的有关你的功业和智慧原来都是真的。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:9; 约翰福音 20:25–29; 约翰一书 3:2"> 若不是亲眼目睹，我不会相信。其实我听到的还不到一半！你的智慧和财富远超过我听到的传闻。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的百姓真有福气！你的臣仆经常侍立在你面前聆听智言慧语，真有福气！</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 72:2; 列王纪上 5:7; 撒母耳记下 8:15"> 你的上帝耶和华当受称颂！祂喜爱你，立你为以色列的王。因为祂永远爱以色列，所以立你为王，使你秉公行义。”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 10:2; 马太福音 2:11; 列王纪上 9:14"> 示巴女王将八万两黄金、大量香料和宝石献给所罗门王。此后，再无人像示巴女王那样献给所罗门王那么多香料。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:27–28; 历代志下 8:18; 诗篇 45:9"> 希兰的船只从俄斐运来黄金、大量檀香木和宝石。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:1–31; 诗篇 150:3–5; 启示录 14:2–3"> 所罗门王用这些檀香木为耶和华的殿和王宫造栏杆，又为歌乐手制作琴瑟。此后，再没有人运来或见过这样的檀香木。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 37:4; 马太福音 15:28; 诗篇 20:4"> 所罗门王除了厚赠示巴女王礼物以外，还满足了她的一切要求。之后，女王和随从就回示巴去了。</span>
</div>
</div>

## 所罗门的财富

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 9:13–28; 列王纪上 9:28"> 所罗门每年收到的黄金约四十五万两。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 72:10; 历代志上 9:24; 以赛亚书 21:13"> 此外，还有商人、阿拉伯诸王和国中各总督送来的贡税。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:26–28; 历代志下 12:9–10; 历代志下 9:15–16"> 所罗门王用锤好的金子打造了二百面大盾牌，每面用一百四十两金子；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:2; 列王纪上 14:26"> 又用锤好的金子打造了三百面小盾牌，每面用七十两金子，全部放在黎巴嫩林宫。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 45:8; 列王纪上 10:22; 启示录 20:11"> 王又造了一个象牙大宝座，外面用纯金包裹。</span>
<span className="v" id="v19" data-v="19"> 这宝座有六级台阶，靠背是圆形的，两旁有扶手，扶手两边各站着一头狮子。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 24:9; 创世记 49:9; 民数记 23:24"> 六级台阶上共站着十二头狮子，每级台阶两端各站一头。这宝座举世无双。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 10:17; 列王纪上 7:2; 历代志下 9:20–22"> 所罗门王所有的杯子都是金的，黎巴嫩林宫里所有的器皿都是纯金的，没有一件是用银子造的，因为所罗门年间银子不算什么。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 22:48; 创世记 10:4; 历代志下 20:36–37"> 王有他施船队和希兰的船队一起出海，每三年就运回金银、象牙、猿猴和孔雀。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 3:12–13; 歌罗西书 2:2–3; 列王纪上 4:29–34"> 所罗门王的财富和智慧超过天下诸王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 3:12; 雅各书 1:5; 列王纪上 3:28"> 天下的人都纷纷来朝见他，聆听上帝赐给他的智言慧语。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 42:11; 诗篇 72:10; 诗篇 72:15"> 他们年年都带来礼物，有金银器皿、衣服、兵器、香料和骡马。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 9:25; 列王纪上 4:26; 申命记 17:16"> 所罗门组建了战车和骑兵，有一千四百辆战车、一万二千名骑兵，驻扎在屯车城和他所在的耶路撒冷。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 申命记 17:17; 历代志下 9:27"> 王使耶路撒冷的银子多如石头，使香柏木多如丘陵的桑树。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 17:16; 历代志下 9:28; 以赛亚书 31:1–3"> 所罗门的马匹都是由王室商队从埃及和古厄按市价买来的。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 1:4; 列王纪下 7:6–7; 玛拉基书 1:1"> 他们从埃及买来车马，每辆车六百块银子，每匹马一百五十块银子，他们也把车马卖给赫人诸王和亚兰诸王。</span>
</div>

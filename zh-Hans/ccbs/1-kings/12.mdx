## 北方支派背叛罗波安

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="士师记 9:6; 历代志下 10:1–19; 士师记 9:1"> 罗波安前往示剑，因为以色列人都去了那里，要立他为王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 11:40; 历代志下 10:2–3; 列王纪上 11:26–31"> 尼八的儿子耶罗波安曾为了躲避所罗门王而逃往埃及，并一直住在那里。他听到消息便从埃及返回以色列。</span>
<span className="v" id="v3" data-v="3"> 以色列人派人去请他，他就和以色列会众去见罗波安，说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 8:11–18; 列王纪上 4:7; 马太福音 11:29–30"> “你父亲使我们负担沉重，求你减轻我们的劳役和负担吧，我们一定服侍你。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 12:12"> 罗波安对他们说：“你们先回去，三天之后再来见我。”众人就离开了。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 12:12; 约伯记 32:7; 撒母耳记下 16:20"> 罗波安王去征询曾服侍他父亲所罗门的老臣的意见，说：“你们认为我该怎样回复这些民众？”</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 历代志下 10:6–7; 列王纪上 12:13"> 他们回禀说：“现今王若像仆人一样服侍民众，对他们好言相待，他们会永远做王的仆人。”</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 传道书 10:2–3; 历代志下 10:8"> 罗波安却没有采纳老臣的意见。他又去征询那些和他一起长大的青年臣僚的意见，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:6–8; 撒母耳记下 17:5–6; 历代志下 10:9"> 说：“民众求我减轻我父亲加给他们的重担。你们认为我该怎样回复他们？”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 10:10–11; 箴言 10:14; 以赛亚书 47:6"> 他们说：“民众说你父亲使他们负担沉重，请求你减轻他们的负担。你可以这样回复他们，‘我的小指头比我父亲的腰还粗。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:11; 以西结书 2:6; 耶利米书 28:13–14"> 我父亲使你们负重担，我要使你们负更重的担子；我父亲用鞭子打你们，我要用刺鞭打你们。’”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 12:5; 历代志下 10:12–14"> 过了三天，耶罗波安和民众遵照罗波安王的话来见他。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 3:17; 箴言 13:20; 传道书 10:12"> 王没有采纳老臣的建议，而是照青年臣僚的建议，疾言厉色地对他们说：“我父亲使你们负重担，我要使你们负更重的担子！我父亲用鞭子打你们，我要用刺鞭打你们！”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:24; 申命记 2:30; 士师记 14:4"> 王不听民众的请求。这事出于耶和华，为要应验祂借示罗人亚希雅先知对尼八的儿子耶罗波安说的话。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 20:1; 耶利米书 23:5–6; 历代志下 10:16"> 以色列人见王不听他们的请求，就说：<br /><span className="pl pl-1">“我们与大卫有何相干？</span><br /><span className="pl pl-1">我们与耶西的儿子没有关系！</span><br /><span className="pl pl-1">以色列人啊，各自回家吧！</span><br /><span className="pl pl-1">大卫家啊，自己顾自己吧！”</span>于是，以色列人各自回家了。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 11:36; 列王纪上 11:13; 历代志下 11:13–17"> 但住在犹大城邑的以色列人仍受罗波安统治。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:6; 撒母耳记下 20:24; 列王纪上 5:14"> 罗波安王派劳役总管亚多兰去以色列人那里，以色列人却用石头打死了他，罗波安王连忙上车逃回耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 17:21; 历代志下 10:19; 约书亚记 4:9"> 从此，以色列人反叛大卫家，直到今天。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 11:13; 列王纪上 11:32; 何西阿书 8:4"> 以色列人听说耶罗波安回来了，就请他到会众面前，拥立他做以色列人的王。只有犹大支派仍然效忠大卫家。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 11:1–3; 历代志上 21:5; 历代志下 14:8"> 罗波安回到耶路撒冷，从犹大和便雅悯支派召集了十八万精兵，要攻打以色列人，收复全国。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 11:2; 历代志下 12:5–7; 列王纪上 13:1"> 然而，上帝对祂的仆人示玛雅说：</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 12:17"> “你去告诉所罗门的儿子犹大王罗波安和犹大、便雅悯支派的人以及其他民众，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 12:15; 历代志下 25:7–8; 何西阿书 8:4"> 耶和华这样说，‘你们不要上去与以色列弟兄交战，都回家吧！今日的景况是出于我的旨意。’”众人听从了耶和华的话，各自回家去了。</span>
</div>

## 耶罗波安背弃上帝

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士师记 8:17; 士师记 8:8; 士师记 9:45–49"> 耶罗波安在以法莲山区修建示剑城，住在那里。他后来又去修建毗努伊勒。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 38:18–21; 以赛亚书 7:9; 马可福音 2:6–8"> 他心想：“国权恐怕会重归大卫家。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5–7; 箴言 29:25; 申命记 12:14"> 若百姓去耶路撒冷，在耶和华的殿献祭，他们的心必重新归向他们的主犹大王罗波安。他们会杀了我，然后投奔犹大王罗波安。”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 10:29; 出埃及记 32:8; 列王纪下 17:16"> 他征询臣僚的意见后，就铸造了两个金牛犊，对民众说：“以色列人啊，你们上耶路撒冷敬拜太麻烦了。这两个金牛犊就是带你们出埃及的神明。”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 28:19; 士师记 18:27–31; 何西阿书 4:15"> 他把一个金牛犊安置在伯特利，另一个安置在但。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:21; 列王纪上 13:34; 列王纪下 10:31"> 这使民众陷入罪中，因为他们开始到但去拜金牛犊。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 列王纪下 17:32; 列王纪上 13:32–33"> 耶罗波安又在高岗上修建神庙，任命各种人做祭司，他们并非利未人。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 8:5; 列王纪上 8:2; 阿摩司书 7:10–13"> 耶罗波安规定每年八月十五日为节期，好像犹大的节期一样。他自己在伯特利的祭坛上向金牛犊献祭，又在伯特利为他修建的神庙设立祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 13:1; 民数记 15:39; 马太福音 15:6"> 在八月十五日，就是他私自为以色列人定为节期的日子，他在伯特利自己修建的祭坛上烧香。</span>

## 以利亚战胜巴力的先知

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各书 5:17; 申命记 28:12"> 旱灾持续了三年。一天，耶和华对以利亚说：“你去见亚哈。我要降雨在地上。”</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 6:25; 箴言 28:1; 利未记 26:26"> 以利亚就去见亚哈。当时，撒玛利亚正遭受严重饥荒。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 7:2; 列王纪上 16:9; 马太福音 10:28"> 亚哈的宫廷总管俄巴底非常敬畏耶和华，耶洗别屠杀耶和华的众先知时，他救了一百名先知，把他们分别藏在两个山洞里，每洞五十人，并供应他们饮食。亚哈召见俄巴底，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 14:5–6; 约珥书 1:18; 约珥书 2:22"> 对他说：“我们去各地的水泉和河谷，也许可以找到草救活骡马，不致丧失牲畜。”</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 14:3"> 于是，亚哈和俄巴底分头到不同地区寻找。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 1:6–8; 创世记 44:20; 以赛亚书 60:14"> 俄巴底在路上遇见了以利亚，俄巴底认出了他，就俯伏在地上说：“你是我主以利亚吗？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:7; 列王纪上 18:3; 彼得前书 2:17–18"> 以利亚回答说：“我就是，你去告诉你主人我在这里。”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 列王纪上 18:12; 列王纪上 17:18"> 俄巴底说：“仆人犯了什么罪，你竟叫我去亚哈那里送死？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 17:1; 列王纪上 1:29; 列王纪上 18:15"> 我凭你的上帝——永活的耶和华起誓，王派人到各邦各国寻找你，任何邦国若说你不在那里，王就要他们起誓说真的找不到你。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 18:8; 列王纪上 18:14"> 现在，你叫我去告诉我主人你在这里，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 2:16; 使徒行传 8:39; 以西结书 8:3"> 我离开你以后，不知道耶和华的灵会把你带到哪里。如果我去告诉亚哈，他来了却找不到你，必定会杀我。但仆人自幼就敬畏耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 18:4; 马太福音 25:35; 诗篇 18:21–24"> 耶洗别屠杀耶和华的众先知时，我把一百名先知分别藏在两个山洞里，每洞五十人，供应他们饮食。我主没有听说这事吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28"> 现在，你要我去告诉我主人你在这里，这是让我去送死。”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 17:1; 列王纪上 18:10; 路加福音 2:13–14"> 以利亚说：“我事奉的是永活的万军之耶和华，我凭祂起誓，我今天必出现在亚哈面前。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 于是，俄巴底去禀告亚哈，亚哈就来找以利亚，</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 7:25; 列王纪上 21:20; 使徒行传 16:20"> 见到以利亚后，就说：“给以色列带来灾祸的就是你吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 15:2; 列王纪上 9:9; 耶利米书 2:19"> 以利亚回答说：“给以色列带来灾祸的不是我，而是你和你父亲家，因为你们抛弃耶和华的诫命，去随从巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 19:26; 列王纪上 16:33; 彼得后书 2:1"> 现在，你快派人去召集所有的以色列人到迦密山来见我，把四百五十名巴力的先知和耶洗别所供养的四百名亚舍拉的先知也带来。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:9"> 亚哈便派人把以色列人和那些先知招聚到迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 约书亚记 24:15; 哥林多前书 10:21–22"> 以利亚走到众人面前说：“你们三心二意要到什么时候呢？如果耶和华是上帝，你们当跟从祂；如果巴力是上帝，你们就跟从他吧！”他们都默不作声。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:10; 列王纪上 19:14; 提摩太后书 4:3–4"> 以利亚继续对众人说：“耶和华的先知现在只剩下我一人，巴力的先知却有四百五十人。</span>
<span className="v" id="v23" data-v="23"> 请给我们牵两头公牛来，巴力的先知可以选一头，切成块放在柴上，但不要点火；我会把另一头公牛预备好，放在柴上，也不点火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 18:38; 历代志上 21:26; 历代志下 7:1"> 然后，你们求告你们神明的名字，我求告耶和华的名，那听祷告降下火来的就是上帝。”众人非常赞同他的主意。</span>
<span className="v" id="v25" data-v="25"> 以利亚对巴力的先知说：“你们人数众多，可先选一头公牛预备好，然后呼求你们的神明，但不可点火。”</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 10:5; 哥林多前书 8:4; 马太福音 6:7"> 他们取了公牛预备好，然后从早上到正午不断地呼求巴力的名：“巴力啊，求你应允我们！”可是毫无动静。他们又绕着自己筑的祭坛跳个不停。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="诗篇 78:65–66; 以赛亚书 41:23; 传道书 11:9"> 中午时分，以利亚讥讽他们说：“喊大声点吧，它肯定是神明！也许它在沉思冥想，也许太忙了，也许出游了，也许睡着了，需要人叫醒它！”</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:28; 申命记 14:1; 马可福音 5:5"> 于是，他们更加大声呼求，并按自己的风俗用刀枪自割自刺，直到身体流血。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:26; 撒母耳记上 18:10; 出埃及记 29:39"> 过了中午，他们仍不断地狂呼乱叫，直到献晚祭的时候，仍然毫无动静，没有半点反应。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="历代志下 33:16; 列王纪上 19:14; 列王纪上 19:10"> 以利亚把众人召集到自己跟前，他重修已遭毁坏的耶和华的祭坛，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:34; 创世记 35:10; 创世记 32:28"> 拿了十二块石头分别代表雅各子孙的十二支派。耶和华曾经对雅各说：“你的名字要叫以色列。”</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:17; 出埃及记 20:24–25; 士师记 21:4"> 以利亚就奉耶和华的名用那些石头筑了一座祭坛，又在坛的周围挖了一条能盛十五升谷种的沟，</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 22:9; 士师记 6:20; 利未记 1:6–8"> 然后在坛上摆好柴，把公牛切成块放在柴上，对众人说：“你们去打四桶水倒在祭物和柴上。”他们照做了。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 8:21; 哥林多后书 4:2"> 以利亚吩咐他们再倒一次，他们又倒了一次。以利亚又吩咐他们倒第三次，他们就倒了第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 18:32; 列王纪上 18:38"> 水流到坛的四周，沟里也灌满了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="列王纪上 18:29; 列王纪下 19:19; 出埃及记 3:6"> 到了献晚祭的时候，以利亚先知走到坛前祷告：“亚伯拉罕、以撒、以色列的上帝耶和华啊，求你今天让这些人知道你是以色列的上帝，我是你的仆人，我是按你的命令做这一切事。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理书 9:17–19; 路加福音 1:16–17; 以西结书 36:25–27"> 耶和华啊，求你应允我，应允我，好让众人知道你耶和华是上帝，你要使他们回心转意。”</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 21:26; 利未记 9:24; 历代志下 7:1"> 于是，耶和华降火烧尽了祭物、木柴、石头、尘土，甚至烧干了沟里的水。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:24; 历代志下 7:3; 列王纪上 18:21"> 众人看见这情景，都俯伏在地高呼：“耶和华是上帝！耶和华是上帝！”</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 18:20; 士师记 4:7; 申命记 13:5"> 以利亚对他们说：“抓住巴力的先知，别放走一个人！”众人就抓住他们，以利亚把他们带到基顺河边，在那里杀了他们。</span>
</div>
</div>

## 上帝降雨

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王纪上 18:1; 传道书 9:7; 列王纪上 17:1"> 以利亚对亚哈说：“你去吃喝吧，因为已传来大雨声。”</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理书 9:7; 约书亚记 7:6"> 亚哈就去吃喝。以利亚上到迦密山顶，跪在地上，脸伏在双膝之间。</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷书 2:3; 路加福音 18:7; 路加福音 18:1"> 他吩咐仆人：“你去向海的方向观看。”仆人就去观看，然后说：“什么也没有。”以利亚又让他去观看，前后共七次。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 约伯记 8:7; 撒迦利亚书 4:10"> 第七次，仆人说：“我看见一朵手掌那么大的云从海里升起来了。”以利亚便吩咐他：“你去告诉亚哈，叫他套车下山，免得被雨阻挡。”</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 18:39–40; 约书亚记 17:16; 列王纪上 21:1"> 霎时间，天上乌云密布，狂风大作，下起大雨。亚哈坐着马车回耶斯列。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 3:14; 以西结书 1:3; 列王纪下 9:1"> 耶和华的手按在以利亚身上，他就束上腰带，飞奔回城，在亚哈之前到达耶斯列的城门。</span>
</div>
</div>

## 以利亚预言旱灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25–26; 雅各书 5:17; 路加福音 1:17"> 基列的提斯比人以利亚对亚哈说：“我凭我事奉的以色列的上帝——永活的耶和华起誓：如果我不祷告，这几年必没有雨水和甘露。”</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 18:1; 耶利米书 7:1; 何西阿书 1:1–2"> 耶和华对以利亚说：</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:6; 耶利米书 36:26; 诗篇 83:3"> “你离开这里，往东去，到约旦河以东的基立溪旁躲起来。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 17:9; 诗篇 147:9; 约伯记 38:41"> 你可以喝基立溪的水，我已吩咐乌鸦在那里供应你食物。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 19:9; 马太福音 16:24; 约翰福音 15:14"> 以利亚遵从耶和华的话，到约旦河东的基立溪旁住下来。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:23–24; 马太福音 6:31–33; 耶利米书 37:21"> 乌鸦每天早晚为他叼来饼和肉，他喝溪里的水。</span>
</div>
</div>

## 撒勒法的寡妇

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 54:10; 以赛亚书 40:30–31"> 因为天旱无雨，过了些日子，溪水干了。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 22:14; 列王纪上 17:2; 希伯来书 13:6"> 耶和华对他说：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:26; 俄巴底亚书 1:20; 哥林多后书 4:7"> “你去西顿的撒勒法，住在那里。我已吩咐那里的一个寡妇供养你。”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:7; 创世记 24:17; 创世记 21:15"> 于是，他起身去了撒勒法，他来到撒勒法的城门口，看见一个寡妇在捡柴，就对她说：“请给我一点水喝。”</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 25:35–40; 列王纪上 18:4; 希伯来书 13:2"> 那妇人去拿水的时候，以利亚又说：“请给我拿一点饼。”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 15:33–34; 列王纪上 17:1; 创世记 21:16"> 她说：“我凭你的上帝——永活的耶和华起誓，我没有饼，我坛里只有一把面，瓶里只有一点油。我来捡柴就是要回去做饼，与儿子吃完后，等死。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 6:33; 玛拉基书 3:10; 创世记 22:1–2"> 以利亚说：“不要害怕，你可以照你所说的去做饼，只是你要先做一小块饼给我，然后再做给你和你儿子。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:36–38; 马太福音 14:17–20; 列王纪下 4:42–44"> 因为以色列的上帝耶和华说，‘在耶和华降雨之前，你坛里的面和瓶里的油必不会用完。’”</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 11:17; 马可福音 12:43; 马太福音 15:28"> 那妇人就照以利亚的话做了。妇人一家和以利亚就这样吃了许多天，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:28–30; 约翰福音 4:50–51; 路加福音 1:37"> 坛里的面没有用完，瓶里的油也没有用光，应验了耶和华借以利亚说的话。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得前书 1:7; 但以理书 5:23; 约翰福音 11:14"> 后来，妇人的儿子病了，病情越来越重，最后死了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 5:8; 约翰福音 2:4; 列王纪下 3:13"> 妇人对以利亚说：“上帝的仆人啊，我跟你有什么关系？你到我这里来是要让上帝想起我的罪，取我儿子的性命吗？”</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 4:32; 列王纪下 4:10; 使徒行传 9:37"> 以利亚对妇人说：“把你儿子交给我。”随后，他从妇人怀中接过孩子，抱到楼上自己的房间，放在床上。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 5:15–18; 马太福音 21:22; 约书亚记 7:8–9"> 他向耶和华呼求道：“我的上帝耶和华啊，我寄居在这寡妇家里，你为什么降祸给她，夺去她儿子的性命呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:10; 使徒行传 9:40; 列王纪下 4:33–35"> 他三次伏在孩子身上，求告耶和华说：“我的上帝耶和华啊，求你让这孩子活过来吧！”</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:39; 启示录 11:11; 希伯来书 11:35"> 耶和华听了以利亚的祈求，孩子就活过来了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 4:36–37; 使徒行传 9:41; 路加福音 7:15"> 以利亚将孩子从楼上抱下来，进屋交给他母亲，说：“看，你儿子活过来了！”</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:30; 约翰福音 2:11; 约翰福音 3:2"> 妇人对以利亚说：“现在我知道你是上帝的仆人，耶和华借你口所说的都是真的。”</span>
</div>
</div>

## 所罗门背弃上帝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:17; 箴言 6:24; 尼希米记 13:23–27"> 除了埃及公主以外，所罗门王还宠爱许多外邦女子，有摩押人、亚扪人、以东人、西顿人和赫人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:16; 申命记 7:3–4; 约书亚记 23:12–13"> 耶和华曾告诉以色列人不可跟这些外族人通婚，免得受引诱去随从他们的神明，所罗门却迷恋这些女子。</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 7:28; 撒母耳记下 5:13–16; 历代志下 11:21"> 他娶了七百个公主，还有三百个妃嫔。这些女子使他的心背弃耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:4; 列王纪上 8:61; 列王纪上 11:6"> 所罗门年老的时候，他的嫔妃诱惑他的心去追随其他神明。他没有像他父亲大卫那样忠心顺服他的上帝耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 2:13; 列王纪上 11:7; 列王纪下 23:13"> 所罗门追随西顿人的女神亚斯她录和亚扪人的可憎神明米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:24; 约书亚记 14:8; 约书亚记 14:14"> 他做了耶和华视为恶的事，没有像他父亲大卫那样一心追随耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:29; 士师记 11:24; 使徒行传 7:43"> 在耶路撒冷东面的山上，所罗门为摩押人可憎的神明基抹和亚扪人可憎的神明摩洛修建丘坛。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:11–12; 列王纪上 11:1; 以西结书 16:22–29"> 他又为所有的外邦妃嫔修建丘坛，供她们向自己的神明烧香献祭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:2; 列王纪上 3:5; 申命记 7:4"> 所罗门背弃了曾两次向他显现的以色列的上帝耶和华，违背耶和华的命令去随从其他神明。所以，耶和华向他发怒，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 12:15–16; 列王纪上 11:31; 列王纪下 17:21"> 说：“你既然违背我的命令，不遵守我的约和律例，我必撕裂你的国，将它赐给你的一个臣仆。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 20:19; 撒母耳记上 9:4–5; 列王纪下 22:19–20"> 然而，因你父大卫的缘故，我不会在你有生之年这样做，我要从你儿子手中把国撕裂。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:20; 申命记 12:11; 列王纪上 11:32"> 但我不会把国全部撕掉，为了我仆人大卫和我拣选的耶路撒冷，我会留下一个支派给你儿子。”</span>
</div>
</div>

## 所罗门的敌人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志上 5:26; 诗篇 89:30–34; 以赛亚书 13:17"> 耶和华使以东王的后裔哈达兴起，与所罗门为敌。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 8:14; 历代志上 18:12–13; 申命记 20:13"> 从前大卫征讨以东，元帅约押前去埋葬阵亡的人，将以东的男子都杀了。</span>
<span className="v" id="v16" data-v="16"> 他率领以色列人在那里住了六个月，直到杀光了以东的男子。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 2:13–14; 出埃及记 2:1–10; 列王纪下 11:2"> 那时，哈达年纪还小，他和他父亲的几个以东臣仆一起逃往埃及。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:12; 申命记 33:2; 申命记 1:1"> 他们从米甸逃到巴兰，在那里招聚了一些人，然后又逃到埃及去见埃及王法老。法老赐他粮食、房屋和田地。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 39:4; 耶利米书 43:7–9; 创世记 39:21"> 法老非常喜欢哈达，将王后答比妮的妹妹许配给他。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:7; 撒母耳记上 1:24"> 他们生了一个儿子，取名叫基努拔，由王后在宫中抚养，跟王子们在一起。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 出埃及记 4:19; 马太福音 2:20"> 后来，哈达在埃及知道大卫已与祖先同眠，约押元帅也死了，就求法老准他回国。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 18:22–23; 路加福音 22:35; 马可福音 14:31"> 法老问他：“你为什么要回国呢？你在我这里还缺什么吗？”哈达答道：“什么都不缺，但还是求王准我回国。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 11:14; 撒母耳记下 8:3; 撒母耳记下 10:15–18"> 上帝又使以利亚大的儿子利逊兴起，与所罗门为敌。这人是从他主人琐巴王哈大底谢身边逃走的。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 10:8; 撒母耳记下 10:18; 列王纪上 20:34"> 在大卫征服琐巴人之后，利逊招聚了一群匪徒，自己做头目。利逊又前往大马士革，在那里做王。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 15:2; 诗篇 106:40; 列王纪上 5:4"> 所罗门活着的时候，哈达和利逊不断为患。利逊统治亚兰，他憎恨以色列人。</span>
</div>
</div>

## 耶罗波安叛变

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 13:6; 列王纪上 12:2; 列王纪上 11:28"> 所罗门的一个臣仆耶罗波安也叛变了。他是以法莲支派洗利达人尼八的儿子，母亲洗鲁阿是个寡妇。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 9:24; 列王纪上 9:15; 箴言 30:32"> 以下是他反叛所罗门的缘由： 所罗门当年建造米罗堡，修补大卫城的城墙时，</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳记下 19:20; 士师记 1:22–23"> 发现年轻的耶罗波安勤奋能干，就提拔他监管约瑟家族的一切工程。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:15; 列王纪上 14:2; 历代志下 9:29"> 有一次，耶罗波安出了耶路撒冷，在路上遇见身披新衣的示罗人亚希雅先知。当时野外只有他们二人。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 15:27–28; 撒母耳记上 24:4–5"> 亚希雅将身上的新衣撕作十二片，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 11:11–12"> 对耶罗波安说：“你可以拿十片。以色列的上帝耶和华说，‘我必从所罗门手里撕裂这国，把十个支派赐给你。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 11:13; 列王纪上 12:20–21; 列王纪上 14:21"> 然而，为了我仆人大卫和我在以色列各支派中拣选的耶路撒冷城，我会留下一个支派给所罗门。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 11:9; 列王纪上 11:5–7; 列王纪上 9:5–7"> 所罗门背弃了我，去祭拜西顿人的女神亚斯她录、摩押的神明基抹、亚扪人的神明米勒公。他没有遵行我的道，没有做我视为正的事，也不像他父亲大卫那样遵守我的律例和典章。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪上 11:31; 约伯记 11:6"> 然而，我不会夺走他整个国，我会让他终生为王，因为我所拣选的仆人大卫遵守我的诫命和律法。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 12:20; 列王纪上 11:12; 出埃及记 20:5–6"> 我必从他儿子手中把国夺走，将十个支派赐给你，</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 8:19; 列王纪上 11:13; 列王纪上 15:4"> 只给他儿子留下一个支派，好使我仆人大卫在我面前，在我选为居所的耶路撒冷城常有一盏灯。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 14:26; 列王纪上 11:26; 撒母耳记下 3:21"> 我要让你做王，使你随心所愿地统治以色列。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 7:11; 约书亚记 1:5; 申命记 31:8"> 若你像我仆人大卫一样听从我的一切吩咐，遵行我的道，做我视为正的事，遵守我的律例诫命，我就与你同在，巩固你的王朝，像巩固大卫的王朝一样，使你统治以色列。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以赛亚书 11:1–10"> 因所罗门的所作所为，我必让大卫的后裔遭难，但不会永远如此。’”</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 12:2–9; 以赛亚书 14:24–27; 耶利米哀歌 3:37"> 所罗门想杀耶罗波安，他就逃到埃及投奔埃及王示撒，在那里一直住到所罗门过世。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 9:29–31"> 所罗门其他的事迹、作为和智慧都记在《所罗门记》上了。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 2:11"> 所罗门在耶路撒冷统治整个以色列四十年，</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪下 21:18; 列王纪上 2:10; 马太福音 1:7"> 他与祖先同眠后葬在他父亲大卫的城里。他儿子罗波安继位。</span>
</div>
</div>

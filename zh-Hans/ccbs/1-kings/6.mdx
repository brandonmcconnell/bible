## 建造圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 3:1–2; 使徒行传 7:47; 历代志上 29:19"> 所罗门在做以色列王的第四年二月，即西弗月，开始为耶和华建殿。那时正是以色列人离开埃及后第四百八十年。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 40:1–41; 以西结书 41:1–15; 启示录 21:16–17"> 所罗门王为耶和华建造的殿长二十七米，宽九米，高十三米半。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 28:11; 历代志下 3:3–4; 以西结书 41:15"> 殿前的门廊和殿一样宽九米，进深四米半。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 40:16; 以西结书 41:26; 以西结书 41:16"> 殿有格子窗户。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:16; 列王纪上 6:19–21; 列王纪上 6:31"> 靠殿墙、围着外殿和内殿又造了三层厢房，</span>
<span className="v" id="v6" data-v="6"> 底层宽两米二，中层宽两米七，上层宽三米一。厢房的横梁都搭在殿墙突出的地方，免得插入殿墙。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:5–6; 彼得前书 2:5; 出埃及记 20:25"> 建殿的石头都在采石场凿好了，建殿的时候听不到锤子、斧头或其他铁器的响声。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 41:6–7"> 底层厢房的进口在殿的南面，沿着一道螺旋楼梯可以通到第二层和第三层。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 6:14; 列王纪上 6:38"> 殿建成后，殿顶装上香柏木的梁木和木板。</span>
<span className="v" id="v10" data-v="10"> 靠着殿墙所造的厢房每一层高两米二，用香柏木的梁木与殿墙接连起来。</span>
</div>
</div>

## 耶和华的约

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对所罗门说：</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 22:10; 歌罗西书 1:23; 列王纪上 3:14"> “关于你所建的这殿，若你遵行我的律例，顺从我的典章，谨守我的一切诫命，我必实现我对你父亲大卫的应许。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 31:6; 出埃及记 25:8; 利未记 26:11"> 我必住在以色列人当中，不抛弃我的以色列子民。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 6:9; 列王纪上 6:38; 使徒行传 7:47–48"> 所罗门建造的殿落成了。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:7"> 殿里的墙壁和天花板都铺上了香柏木，地面都铺上了松木板。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 3:8; 列王纪上 8:6; 希伯来书 9:3"> 在殿的后部，从地面至天花板用香柏木板隔出长九米的内殿，就是至圣所。</span>
<span className="v" id="v17" data-v="17"> 在至圣所外面是外殿，长十八米。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:24"> 殿内全部铺上香柏木，不露一点石头，香柏木上刻着野瓜和花朵的图案。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 8:6–10; 诗篇 28:2; 列王纪上 6:5"> 殿的至圣所用来安放耶和华的约柜。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 6:2–3; 列王纪上 6:22; 列王纪上 7:48"> 至圣所长、宽和高都是九米，里面全贴上纯金，香柏木造的祭坛也包上纯金。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:7–9; 历代志下 3:14–16; 列王纪上 6:5"> 殿内全部贴上纯金，至圣所前面有金链拦着，至圣所内也都贴上纯金。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 30:1; 出埃及记 30:3; 历代志下 3:7–14"> 殿内都贴上纯金，至圣所内的祭坛也都包上纯金。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 37:7–9; 创世记 3:24; 彼得前书 1:12"> 至圣所里面放着两个橄榄木造的基路伯天使，各高四米半，</span>
<span className="v" id="v24" data-v="24"> 各有两个两米二长的翅膀，双翅展开，两翅尖相距四米半。</span>
<span className="v" id="v25" data-v="25"> 两个基路伯的大小和形状一模一样，</span>
<span className="v" id="v26" data-v="26"> 高度都是四米半。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 37:9; 出埃及记 25:20; 历代志下 5:8"> 他将两个基路伯安在至圣所内，两个基路伯展开翅膀，各有一个翅膀在至圣所的中央相接，另一个翅膀的尖端触到墙壁。</span>
<span className="v" id="v28" data-v="28"> 这两个基路伯天使也包上金。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 6:32; 诗篇 92:12–15; 历代志下 4:2–5"> 内殿和外殿的墙壁都刻上基路伯天使、棕树和花朵的图案，</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 21:18–21; 以赛亚书 60:17; 以赛亚书 54:11–12"> 地板是铺金的。</span>
<span className="v" id="v31" data-v="31" data-xref="希伯来书 10:19–20; 以弗所书 3:18; 约翰福音 14:6"> 至圣所的门、门楣和门柱都是橄榄木造的，门柱呈五角形。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 6:18; 列王纪上 6:29"> 两扇用橄榄木造的门上都刻着基路伯天使、棕树和花朵的图案，并包上金。</span>
<span className="v" id="v33" data-v="33"> 外殿的四角形门柱也是用橄榄木造的，</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 41:23–25; 列王纪上 5:8"> 两扇门是松木造的，每一扇门都分为可折叠的两片，</span>
<span className="v" id="v35" data-v="35"> 上面刻着基路伯天使、棕树和花朵的图案，并均匀地包上金。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:12; 历代志下 7:7; 出埃及记 27:9–19"> 内院的墙是由三层凿好的石头和一层香柏木建的。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王纪上 6:1; 历代志下 3:2"> 耶和华的殿在所罗门执政第四年的西弗月奠基，</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉记 6:14–15; 列王纪上 7:1; 撒迦利亚书 4:9"> 在他执政的第十一年的布勒月，即八月全部按规格建成，历经七年。</span>
</div>
</div>

</div>

## 亚比央做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:31; 历代志下 13:1–22"> 尼八的儿子耶罗波安王执政第十八年，亚比央登基做犹大王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 13:2; 历代志下 11:20–22; 列王纪上 15:13"> 他在耶路撒冷执政三年，母亲是押沙龙的女儿玛迦。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:4; 诗篇 119:80; 列王纪上 3:14"> 亚比央和他父亲一样作恶多端，没有像他祖先大卫一样忠于他的上帝耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:36; 历代志下 21:7; 以赛亚书 37:35"> 但他的上帝耶和华因为大卫的缘故，仍然让他儿子在耶路撒冷继位，使耶路撒冷坚立。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:8; 撒母耳记下 11:15–17; 列王纪上 15:3"> 除了赫人乌利亚事件以外，大卫一生都做耶和华视为正的事，没有违背耶和华的任何命令。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:30"> 罗波安和耶罗波安之间常有战事，一直延续到亚比央王朝。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 13:2–22; 列王纪上 14:29"> 亚比央和耶罗波安之间也常有战事。亚比央其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:1; 列王纪上 14:31; 马太福音 1:7–8"> 亚比央与祖先同眠后，葬在大卫城，他儿子亚撒继位。</span>
</div>
</div>

## 亚撒做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶罗波安做以色列王第二十年，亚撒登基做犹大王，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:2; 列王纪上 15:13; 历代志下 13:2"> 他在耶路撒冷执政四十一年。他祖母是押沙龙的女儿玛迦。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 14:2; 历代志下 15:17; 列王纪上 15:3"> 亚撒效法他祖先大卫，做耶和华视为正的事。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:46; 列王纪上 14:23–24; 历代志下 14:2–5"> 他从国中驱逐了男庙妓，清除了他祖先制造的一切偶像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 32:20; 申命记 7:5; 撒迦利亚书 13:3"> 亚撒还废除了他祖母玛迦的太后之位，因为她造了可憎的亚舍拉神像。亚撒把她的神像砍倒，放在汲沦溪烧掉。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:43; 列王纪上 8:61; 列王纪上 15:3"> 他虽然没有清除丘坛，但一生忠于耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:51; 历代志下 14:13; 历代志下 15:18"> 他把自己和父亲奉献的金银及器皿都带到耶和华的殿里。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:32; 列王纪上 14:30; 历代志下 16:1–6"> 亚撒和以色列王巴沙执政期间，双方常常交战。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 12:27; 历代志下 16:1–6; 约书亚记 18:25"> 以色列王巴沙上来攻打犹大，并修筑拉玛，不许任何人进出犹大王亚撒的地界。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:26; 列王纪下 12:18; 列王纪上 11:23–24"> 于是，亚撒把耶和华殿里和王宫库房里剩余的金银交给臣仆，派他们送给大马士革的亚兰王，即他伯利们的儿子、希旬的孙子便·哈达，说：</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:31; 历代志下 16:7; 罗马书 3:8"> “我们之间应立盟约，像我们的父辈间立约一样，现在奉上金银为礼，请你取消与以色列王巴沙的盟约。这样，他就会从我境内退兵。”</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 士师记 18:29; 约书亚记 11:2"> 便·哈达接受了亚撒王的提议，派将领攻打以色列的城邑，攻占了以云、但、亚伯·伯·玛迦、基尼烈全境和拿弗他利全境。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:17; 列王纪上 16:15–18; 历代志下 16:5"> 巴沙闻讯，就停止修筑拉玛，退回得撒去了。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 21:17; 约书亚记 18:24; 约书亚记 18:26"> 亚撒王号令全体犹大人出动，任何人不得有误，将巴沙修筑拉玛的石头和木材搬走，用它们修建便雅悯的迦巴和米斯巴。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 16:11–14; 列王纪上 14:29–31; 列王纪上 15:7–8"> 亚撒其他的事，包括他的功业和兴建城邑的事迹都记在《犹大列王史》上。亚撒年老的时候，患了脚疾。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:8; 列王纪上 22:41–43; 历代志下 17:1–9"> 他与祖先同眠后，葬在大卫城他的祖坟里。他儿子约沙法继位。</span>
</div>
</div>

## 拿答做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 14:20; 列王纪上 14:12"> 亚撒做犹大王第二年，耶罗波安的儿子拿答登基做以色列王，执政两年。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪上 15:30"> 拿答行耶和华视为恶的事，像他父亲一样作恶多端，使以色列人陷入罪中。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:44; 约书亚记 21:23; 列王纪上 14:14"> 亚撒做犹大王第三年，拿答率以色列军围攻非利士的基比顿城时，以萨迦支派亚希雅的儿子巴沙叛变，杀了拿答，篡位称王。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 14:9–16; 列王纪下 19:25; 列王纪下 10:10–11"> 巴沙一做王，立刻诛杀耶罗波安全家，不留一个活口，应验了耶和华借祂仆人示罗人亚希雅所说的话。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 15:26; 列王纪上 14:22; 列王纪上 14:9–16"> 这是因为耶罗波安犯罪，并使以色列人陷入罪中，惹以色列的上帝耶和华发怒。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 14:19; 列王纪上 16:20; 列王纪上 16:14"> 拿答其他的事及一切所为都记在《以色列列王史》上。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 15:16"> 亚撒和以色列王巴沙执政期间，双方常常交战。</span>
</div>
</div>

## 巴沙做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王纪上 16:8"> 犹大王亚撒执政第三年，亚希雅的儿子巴沙在得撒登基做以色列王，执政二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28–29"> 他做耶和华视为恶的事，步耶罗波安的后尘，使以色列人陷入罪中。</span>
</div>
</div>

</div>

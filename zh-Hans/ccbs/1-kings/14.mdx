## 亚希雅对耶罗波安的预言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 20:5; 列王纪上 13:33–34; 撒母耳记上 31:2"> 那时，耶罗波安的儿子亚比雅病了，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 28:8; 列王纪上 11:29–38; 撒母耳记下 14:2"> 耶罗波安就吩咐妻子：“你乔装改扮使人认不出你是我妻子，然后去示罗找那位预言我做王的先知亚希雅。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 9:7–8; 列王纪上 13:7; 列王纪下 4:42"> 你要带十个饼、一些薄饼和一瓶蜂蜜去，他将告诉你孩子的病情会怎样。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:29; 撒母耳记上 3:2; 撒母耳记上 4:15"> 耶罗波安的妻子就照他的话做，前往示罗，来到亚希雅家。那时亚希雅因年纪老迈，眼睛已失明。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 6:8–12; 箴言 21:30; 列王纪下 4:27"> 耶和华预先告诉亚希雅说：“耶罗波安的妻子会乔装成别的妇人，前来问你有关她儿子的病情，你要如此如此回答她。”</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 5:17–28; 使徒行传 5:9–10; 路加福音 20:20–23"> 她刚进门，亚希雅听见她的脚步声就说：“耶罗波安的妻子啊，你进来吧，为什么乔装改扮呢？我奉命告诉你一个噩耗。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 16:2; 撒母耳记下 12:7–8; 撒母耳记上 15:16"> 你回去告诉耶罗波安，‘以色列的上帝耶和华说，我从百姓中提升你，立你做我以色列子民的王。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:5; 列王纪上 11:33–38; 历代志下 28:1"> 我把国从大卫家撕开赐给你，你却没有像我仆人大卫那样遵守我的诫命，全心听从我，做我视为正的事，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 23:35; 尼希米记 9:26; 诗篇 50:17"> 反而比前人行恶更甚，为自己设立其他神明，铸造神像，惹我发怒，把我抛在脑后。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:36; 列王纪上 21:21; 列王纪下 14:26"> 所以，我要降祸给耶罗波安家，从以色列铲除耶罗波安家所有的男子，不论是奴隶还是自由人。我要像清除粪便一样，把耶罗波安家焚烧净尽。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 16:4; 耶利米书 15:3; 列王纪上 21:23–24"> 耶罗波安家人中，死在城中的必被狗吃，死在田野的必被鸟吃。这是耶和华说的。’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 14:3; 列王纪上 14:16–17; 列王纪下 1:6"> “现在你回家去吧，你一进城，孩子就会死。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 19:3; 历代志下 12:12; 约伯记 19:28"> 全以色列会为他哀悼，把他埋葬。耶罗波安家人中只有他将得到安葬，因为以色列的上帝耶和华只在他身上看见了良善。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 15:27–29; 以西结书 7:2–7; 以西结书 12:22–28"> 耶和华必为自己立一位君王统治以色列，他必铲除耶罗波安家。现在就是时候了。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 23:15–16; 诗篇 52:5; 列王纪下 15:29"> 耶和华将击打以色列人，使他们像水中的芦苇一样颤抖不已。耶和华将把以色列人从祂赐给他们祖先的佳美之地连根拔起，抛散到幼发拉底河的彼岸，这都是因为他们制造亚舍拉神像，惹耶和华发怒。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:34; 列王纪上 16:2; 列王纪上 13:34"> 因为耶罗波安犯罪作孽，使以色列人陷入罪中，耶和华必抛弃以色列。”</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 15:33; 列王纪上 16:15; 列王纪上 16:23"> 耶罗波安的妻子动身回到得撒，刚迈过家门槛，孩子就死了。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:13"> 以色列人埋葬了他，为他哀悼，正应验了耶和华借祂仆人亚希雅先知说的话。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 13:2–20; 历代志上 27:24; 列王纪上 16:20"> 耶罗波安其他的事，不论文治武功，都记在《以色列列王史》上。</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 14:12; 诗篇 3:5; 列王纪上 11:43"> 他做王二十二年，然后与祖先同眠。他儿子拿答继位。</span>
</div>
</div>

## 罗波安做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 12:13; 列王纪上 11:36; 列王纪上 14:31"> 所罗门的儿子罗波安做犹大王。他四十一岁登基，在耶和华从以色列各支派中选来立祂名的耶路撒冷城执政十七年。罗波安的母亲是亚扪人拿玛。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 12:1; 哥林多前书 10:22; 诗篇 78:58"> 犹大人做耶和华视为恶的事，他们的罪行比他们祖先所做的更惹耶和华发义怒。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:2; 以赛亚书 57:5; 列王纪下 17:9–10"> 他们在各高岗上和绿树下为自己建造丘坛，竖立神柱和亚舍拉神像，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 23:17; 哥林多前书 6:9; 列王纪上 15:12"> 国中甚至男庙妓充斥。犹大人仿效耶和华在以色列人面前赶走的外族人，行各种可憎之事。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:40; 历代志下 12:2–4; 历代志下 12:9"> 罗波安王执政第五年，埃及王示撒上来攻打耶路撒冷，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 15:18; 历代志下 9:15–16; 列王纪上 7:51"> 把耶和华殿里和王宫里的财宝掳掠一空，包括所罗门制造的所有金盾牌。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 8:11; 撒母耳记上 22:17; 列王纪上 18:46"> 罗波安王就造了铜盾牌代替那些金盾牌，交给看守宫门的护卫长看管。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 12:11"> 每次王进耶和华的殿，护卫就带上盾牌，用完后放回护卫房。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 22:45; 列王纪上 15:23; 列王纪上 14:19"> 罗波安其他的事及一切所为都记在《犹大列王史》上。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 12:24; 列王纪上 12:21; 列王纪上 15:6–7"> 罗波安和耶罗波安之间常有争战。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 12:16; 马太福音 1:7; 列王纪上 15:3"> 罗波安与祖先同眠后，葬在大卫城的祖坟里。他母亲是亚扪人拿玛。他儿子亚比央继位。</span>
</div>

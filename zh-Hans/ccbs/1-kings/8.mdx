## 运约柜入圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 5:2–10; 历代志上 15:25; 撒母耳记下 6:12–17"> 所罗门把以色列的长老、各支派的首领和族长召集到他所在的耶路撒冷，准备把耶和华的约柜从大卫城锡安运上来。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="利未记 23:34; 历代志下 7:8–10; 撒迦利亚书 14:16–19"> 在以他念月，即七月住棚节的时候，以色列人都聚集到所罗门王那里。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 约书亚记 3:6; 民数记 4:15"> 以色列的长老到齐后，祭司便抬起约柜，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:4; 历代志下 1:3; 出埃及记 40:2–33"> 祭司和利未人将耶和华的约柜、会幕和会幕里的一切圣器运上来。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 6:13; 历代志上 16:1; 列王纪上 8:62–63"> 所罗门王和聚集到他那里的以色列全体会众在约柜前献祭，献上的牛羊多得不可胜数。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:19; 撒母耳记下 6:17; 列王纪上 6:27"> 祭司把耶和华的约柜抬进内殿，即至圣所，放在两个基路伯天使的翅膀下面。</span>
<span className="v" id="v7" data-v="7"> 基路伯天使展开翅膀，遮盖约柜和抬约柜的横杠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:13–15; 出埃及记 37:4–5; 约书亚记 4:9"> 横杠很长，在至圣所前面的圣所中也看得见横杠的末端，但在圣所外面看不见。横杠至今仍在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:21; 希伯来书 9:4; 出埃及记 40:20"> 约柜里除了两块石版，没有别的东西。石版是以色列人离开埃及后，耶和华在何烈山跟他们立约时，摩西放进去的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:34–35; 历代志下 7:1–2"> 祭司从圣所出来的时候，就有云彩充满了耶和华的殿，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 43:4–5; 以西结书 44:4; 哥林多后书 3:18"> 以致祭司不能在殿里供职，因为殿里充满了耶和华的荣光。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 97:2; 历代志下 6:1–11; 利未记 16:2"> 那时，所罗门说：<br /><span className="pl pl-1">“耶和华啊，</span><br /><span className="pl pl-1">你曾说你要住在密云中，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 7:13; 诗篇 132:13–14; 希伯来书 9:24"> <span className="pl pl-1">现在，我为你建造了雄伟的殿宇，</span><br /><span className="pl pl-1">作你永远的居所。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 6:18; 列王纪上 8:55–56; 历代志下 30:18–20"> 然后，王转身为站立在那里的以色列全体会众祝福。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:68; 历代志上 29:20; 历代志上 29:10"> 他说：“以色列的上帝耶和华当受称颂！祂亲口给我父大卫的应许，现在祂亲手成就了！</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 16:1; 列王纪上 8:29; 撒母耳记下 7:4–8"> 祂曾说，‘自从我带我的以色列子民出埃及以来，我并没有在以色列各支派中选出一座城来建造殿宇，作为我名所在之地。我只是拣选了大卫来治理我的以色列子民。’”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2–3; 历代志上 22:7; 历代志上 28:2"> 所罗门又说：“我父大卫曾想为以色列的上帝耶和华的名建一座殿，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 6:7–9; 哥林多后书 8:12"> 但耶和华对我父大卫说，‘你想为我的名建造殿宇，这番心意是好的，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 7:5; 历代志上 22:8–10; 历代志上 28:6"> 但你不可建，要由你的亲生儿子为我的名建殿。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:5–6; 腓立比书 1:6; 列王纪上 8:15"> “现在耶和华已经成就祂的应许。我继承了我父大卫的王位统治以色列，又为以色列的上帝耶和华的名建了殿，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 8:9; 申命记 31:26; 列王纪上 8:5–6"> 并在殿里预备了放约柜的地方。约柜里有耶和华的约，是祂把我们的祖先带出埃及时跟他们立的。”</span>
</div>
</div>

## 所罗门的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 9:5; 列王纪上 8:54; 出埃及记 9:33"> 所罗门当着以色列会众的面，站在耶和华的坛前，向天伸出双手，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 7:22; 申命记 7:9; 但以理书 9:4"> 祷告说：“以色列的上帝耶和华啊，天上地下没有神明可以与你相比！你向尽心遵行你旨意的仆人守约，施慈爱。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 7:16; 列王纪上 8:15; 撒母耳记下 7:12"> 你持守对你仆人——我父大卫的应许，你曾亲口应许，你今天亲手成就了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 2:4; 列王纪上 9:4–6; 耶利米书 33:17–26"> “以色列的上帝耶和华啊，你曾对你仆人——我父大卫说，‘若你的子孙像你一样谨慎行事、遵行我的旨意，你的王朝就不会中断。’求你信守这应许。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 7:25–29; 以赛亚书 41:17; 撒母耳记上 1:17"> 以色列的上帝耶和华啊，求你实现你对你仆人——我父大卫的应许。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 2:6; 以赛亚书 66:1; 耶利米书 23:24"> “然而，上帝啊，你真会住在人间吗？看啊，至高的诸天尚且容不下你，更何况我建造的这殿呢？</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 88:1–2; 诗篇 5:1; 路加福音 18:1"> 可是，我的上帝耶和华啊，求你垂顾你仆人的祷告和祈求，垂听你仆人今天在你面前的呼求和祷告。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 6:20; 列王纪上 8:16; 历代志下 7:15–16"> 愿你昼夜看顾这殿，就是你应许立你名的地方！你仆人向着这地方祷告的时候，求你垂听。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 8:39; 列王纪上 8:34; 列王纪上 8:36"> 你仆人和你的以色列子民向这地方祈祷的时候，求你从你天上的居所垂听，赦免我们的罪。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 22:8–11; 历代志下 6:22–23; 利未记 5:1"> “如果有人得罪邻舍，被叫到这殿中，在你的坛前起誓，</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 25:1; 以赛亚书 3:10–11; 罗马书 2:6–10"> 求你从天上垂听，在你众仆人当中施行审判，按他们的行为罚恶赏善。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="利未记 26:17; 申命记 28:25; 约拿书 3:10"> “当你的以色列子民因得罪你而败在敌人手中时，如果他们回心转意归向你，承认你的名，在这殿里祈祷，</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 31:4–9; 但以理书 9:12; 创世记 13:15"> 求你从天上垂听，赦免他们的罪，带领他们回到你赐给他们祖先的土地上。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="利未记 26:19; 申命记 11:17; 列王纪上 8:33"> “当你的子民得罪你，你惩罚他们，让天不降雨时，如果他们向着这地方祷告，承认你的名，并离开罪恶，</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 27:11; 撒母耳记上 12:23; 耶利米书 6:16"> 求你在天上垂听，赦免你仆人以色列子民的罪，教导他们走正道，降下甘霖滋润你赐给你子民作产业的土地。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 28:21–22; 利未记 26:16; 历代志下 20:9"> “如果国中有饥荒、瘟疫、旱灾、霉病、蝗灾、虫灾，或是城邑被敌人围困，无论遭遇什么灾祸疾病，</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 73:21–22; 列王纪上 8:22; 腓立比书 4:6"> 只要你的以色列子民，或个人或全体，自知心中痛苦并向着这殿伸手祷告，无论祈求什么，</span>
<span className="v" id="v39" data-v="39" data-xref="历代志上 28:9; 耶利米书 17:10; 使徒行传 1:24"> 求你从天上的居所垂听，赦免他们。唯独你能洞察人心，求你按各人的行为施行赏罚，</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 130:4; 启示录 19:5; 申命记 6:2"> 使你的子民在你赐给我们祖先的土地上终生敬畏你。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王纪上 10:1–2; 使徒行传 8:27–40; 出埃及记 18:8–12"> “如果远方有不属于你以色列子民的外族人听说你的大能大力，慕名而来，向着这殿祷告，</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 102:15; 撒母耳记上 17:46; 诗篇 22:27"> 求你从天上的居所垂听，应允他们的祈求，好叫天下万民都像你的以色列子民一样认识你的名，敬畏你，并知道我建造的这殿属于你的名下。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="历代志下 6:34; 诗篇 78:67–69; 列王纪上 8:16"> “你的子民奉你的命令上阵与敌人作战，无论他们在哪里，如果他们向着你选择的这城和我为你名建造的这殿祷告，</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 18:25; 诗篇 9:4; 耶利米书 5:28"> 求你从天上垂听他们的祈祷，为他们伸张正义。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="传道书 7:20; 箴言 20:9; 约翰一书 1:8–10"> “世上没有不犯罪的人，如果你的子民得罪你，以致你向他们发怒，让敌人把他们掳走，不论远近，</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 106:6; 尼希米记 1:6–11; 尼希米记 9:26–30"> 若他们在被掳之地回心转意，向你恳求，承认自己犯罪作恶了；</span>
<span className="v" id="v48" data-v="48" data-xref="但以理书 6:10; 耶利米书 29:12–14; 申命记 4:29"> 若他们在掳走他们的仇敌那里全心全意地归向你，朝着你赐给他们祖先的这片土地、你选择的这城和我为你建的这殿向你祷告，</span>
<span className="v" id="v49" data-v="49" data-xref="列王纪下 19:19; 列王纪上 8:45; 撒迦利亚书 1:15–16"> 求你从天上的居所垂听他们的祈祷，为他们伸张正义，</span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 106:46; 历代志下 30:9; 使徒行传 7:10"> 赦免得罪你的子民，赦免他们的一切过犯，使掳掠他们的人善待他们。</span>
<span className="v" id="v51" data-v="51" data-xref="尼希米记 1:10; 耶利米书 11:4; 申命记 4:20"> 因为他们是你的子民、你的产业，是你从埃及那铁熔炉里拯救出来的。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="诗篇 145:18; 列王纪上 8:29; 诗篇 86:5"> “愿你垂顾仆人和你的以色列子民的祈求。无论他们什么时候向你祈求，都求你垂听。</span>
<span className="v" id="v53" data-v="53" data-xref="出埃及记 19:5–6; 申命记 14:2; 申命记 32:9"> 主耶和华啊，因为你带我们祖先出埃及的时候，曾经借着你的仆人摩西应许将以色列人从世上万民中分别出来，作你自己的产业。”</span>
</div>
</div>

## 所罗门为民祝福

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="历代志下 7:1; 历代志下 6:12–13; 路加福音 22:45"> 所罗门跪在耶和华的坛前，举手向耶和华祷告完毕，</span>
<span className="v" id="v55" data-v="55" data-xref="列王纪上 8:14; 撒母耳记下 6:18; 民数记 6:23–26"> 便站起来高声为以色列全体会众祝福：</span>
<span className="v" id="v56" data-v="56" data-xref="约书亚记 23:14–15; 约书亚记 21:44–45; 路加福音 21:33"> “耶和华当受称颂！祂照着应许赐平安给祂的以色列子民。祂从前借着仆人摩西赐下的美好应许一句也没有落空。</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 1:5; 申命记 31:6; 申命记 31:8"> 愿我们的上帝耶和华与我们同在，就像与我们的祖先同在一样。愿祂永远都不撇下我们，不丢弃我们，</span>
<span className="v" id="v58" data-v="58" data-xref="诗篇 119:36; 以西结书 36:26–27; 耶利米书 31:33"> 使我们的心归向祂，遵行祂的旨意，谨守祂吩咐我们祖先的诫命、律例和典章。</span>
<span className="v" id="v59" data-v="59" data-xref="诗篇 141:2; 约翰福音 17:9; 约翰福音 17:20–24"> 愿我们的上帝耶和华昼夜顾念我在祂面前的这些祈求，天天为祂的仆人和祂的以色列子民伸张正义，</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 4:35; 耶利米书 10:10–12; 列王纪上 18:39"> 叫地上万民都知道，耶和华是独一无二的上帝。</span>
<span className="v" id="v61" data-v="61" data-xref="列王纪上 11:4; 列王纪下 20:3; 哥林多后书 7:1"> 愿你们像今天一样专心事奉我们的上帝耶和华，遵行祂的律法，谨守祂的诫命。”</span>
</div>
</div>

## 圣殿奉献礼

<div className="bt">
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="撒母耳记下 6:17–19; 以斯拉记 6:16–17; 历代志下 7:4–10"> 王和以色列众民一同向耶和华献祭。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉记 6:16–17; 历代志下 15:11; 尼希米记 12:27"> 所罗门向耶和华献上两万二千头牛和十二万只羊作平安祭，王和以色列众民为耶和华的殿举行奉献典礼。</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="历代志下 4:1; 历代志下 7:7"> 那天，因为耶和华殿前的铜坛太小，容不下燔祭、素祭和平安祭祭牲的脂肪，所罗门王就把殿前院子中间分别出来作圣洁之地，在那里献上燔祭、素祭和平安祭祭牲的脂肪。</span>
<span className="v" id="v65" data-v="65" data-xref="民数记 34:5; 民数记 34:8; 列王纪上 8:2"> 所罗门和从哈马口直至埃及小河而来的全体以色列人聚成一大群会众，在我们的上帝耶和华面前守节期两周，共十四天。</span>
<span className="v" id="v66" data-v="66" data-xref="腓立比书 4:4; 使徒行传 2:46; 撒迦利亚书 9:17"> 节后第二天，所罗门王让民众各回本乡。他们看见耶和华向祂仆人大卫和以色列子民所施的一切恩惠，都为王祝福，并满心欢喜地回家去了。</span>
</div>
</div>

## 葡萄园事件

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:33; 历代志下 28:22; 约书亚记 19:18"> 这事以后，又发生了一件事。耶斯列人拿伯在耶斯列有个葡萄园，在撒玛利亚王亚哈的王宫附近。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:14; 雅各书 1:14–15; 提摩太前书 6:9"> 一天，亚哈对拿伯说：“你的葡萄园靠近我的王宫，你把它让给我作菜园吧。我可以用更好的葡萄园来跟你交换，如果你愿意，我也可以按价付你钱。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 36:7; 利未记 25:23; 以西结书 46:18"> 拿伯说：“耶和华不准我把祖先的产业让给你。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 20:43; 雅各书 1:14; 约拿书 4:9"> 亚哈因为耶斯列人拿伯不肯把祖先的产业让给他，就闷闷不乐地回到宫中，躺在床上生气，饭也不吃。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 16:31; 创世记 3:6; 列王纪上 19:2"> 他妻子耶洗别过来问他：“王为什么烦闷，不思饮食呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 5:9–14; 雅各书 4:2–7; 提摩太前书 6:9–10"> 亚哈回答说：“我要耶斯列人拿伯将他的葡萄园卖给我，如果他愿意，我也可以用别的葡萄园跟他交换，可是他不肯。”</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 8:14; 弥迦书 7:3; 撒母耳记下 13:4"> 耶洗别说：“你不是以色列王吗？起来吃饭吧，高兴点，我必让你得到耶斯列人拿伯的葡萄园。”</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 6:5; 列王纪下 10:11; 以斯拉记 4:7–8"> 于是，耶洗别以亚哈王的名义写信，并盖上王印，送给跟拿伯同居一城的长老和贵族。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:4; 马太福音 23:13; 路加福音 20:47"> 信上说：“你们要宣告禁食，让拿伯在百姓中坐首位，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:28; 使徒行传 6:11; 利未记 24:15–16"> 叫两个无赖坐在他对面控告他咒诅上帝和君王，然后把他拉出去用石头打死。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 4:19; 利未记 19:15; 列王纪下 10:6–7"> 与拿伯同居一城的长老和贵族便照信里的指示行事。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 58:4; 列王纪上 21:8–10"> 他们宣告禁食，让拿伯在百姓中坐首位，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 9:26; 申命记 22:24; 传道书 10:20"> 又叫两名无赖当众作证，指控拿伯咒诅上帝和君王。众人就把拿伯拖出城外，用石头打死了他。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 8:14; 撒母耳记下 11:14–24; 传道书 5:8"> 然后，他们派人去把拿伯被石头打死的消息告诉耶洗别。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王纪上 21:7"> 耶洗别接到消息后，就告诉亚哈说：“耶斯列人拿伯已经死了，你去占他不肯卖给你的葡萄园吧。”</span>
<span className="v" id="v16" data-v="16" data-xref="俄巴底亚书 1:12–14; 罗马书 1:32; 撒母耳记下 11:25–27"> 亚哈听说耶斯列人拿伯死了，就起来，下去霸占拿伯的葡萄园。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:12; 以赛亚书 26:21; 列王纪下 5:26"> 耶和华对提斯比人以利亚说：</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:32; 历代志下 22:9"> “你去撒玛利亚见以色列王亚哈，他正在拿伯的葡萄园，他到那里要霸占那葡萄园。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:38; 撒母耳记下 12:9; 哈巴谷书 2:9"> 你要对他说，‘耶和华说，你杀了人，还要夺他的产业吗？’然后告诉他，耶和华说，‘狗在哪里舔拿伯的血，也必在哪里舔你的血。’”</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:17; 罗马书 7:14; 列王纪上 21:25"> 亚哈见了以利亚，说：“我的对头啊，你又来找我了！”以利亚说：“我又来找你了，因为你一心做耶和华视为恶的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:10; 撒母耳记上 25:34; 列王纪下 10:1–7"> 耶和华说，‘我必降祸给你，彻底毁灭你，从以色列铲除你家所有的男子，不管是奴隶还是自由人。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 16:3; 列王纪上 14:16; 列王纪上 16:11"> 我必使你一家的下场像尼八的儿子耶罗波安家和亚希雅的儿子巴沙家一样，因为你惹我发怒，并且使以色列人陷入罪中。’</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 9:10; 列王纪下 9:30–37; 列王纪上 21:25"> 至于耶洗别，耶和华说，‘狗必在耶斯列的城墙边吃耶洗别的肉。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 16:4; 列王纪上 14:11; 耶利米书 15:3"> 凡属亚哈的人，死在城中的必被狗吃，死在郊野的必被飞鸟吃。’”</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王纪上 21:20; 列王纪上 16:30–33"> 从来没有人像亚哈那样受妻子耶洗别唆使，一心做耶和华视为恶的事。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11; 创世记 15:16; 利未记 18:25–30"> 他像被耶和华驱逐的亚摩利人一样祭拜偶像，行为可憎。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 6:30; 创世记 37:34; 撒母耳记下 3:31"> 亚哈听了以利亚的话，就撕裂衣服，披麻禁食，睡觉也不脱下麻衣，垂头丧气地走来走去。</span>
<span className="v" id="v28" data-v="28"> 耶和华对提斯比人以利亚说：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 3:9; 弥迦书 7:18; 诗篇 86:15"> “你看见亚哈在我面前如何谦卑了吗？因为他在我面前谦卑，我不会在他有生之日降灾，我要等他儿子执政的时候，才降灾给他家。”</span>

## 所罗门的臣仆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 1:12; 历代志下 9:30; 列王纪上 12:19–20"> 所罗门王统治以色列，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:21; 哥林多前书 12:28; 撒母耳记下 8:15–18"> 以下是他的众臣仆：撒督的儿子亚撒利雅做祭司；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16; 以赛亚书 62:6; 历代志上 18:15"> 示沙的儿子以利何烈和亚希亚做书记；亚希律的儿子约沙法做史官；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:35; 列王纪上 2:26–27"> 耶何耶大的儿子比拿雅做元帅；撒督和亚比亚他做祭司长；</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 27:33; 撒母耳记下 15:37; 撒母耳记下 16:16"> 拿单的儿子亚撒利雅掌管吏部；拿单的儿子撒布得祭司做所罗门王的顾问；</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:15; 撒母耳记下 20:24; 列王纪上 12:18"> 亚希煞总管宫廷事务；亚比大的儿子亚多尼兰总管做劳役的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 27:1–15"> 所罗门在以色列全国设立了十二个地方官，负责供给王及王室的需用，每年每人负责一个月。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 24:33; 士师记 19:1; 士师记 17:1"> 这十二个地方官是：便·户珥，负责以法莲山区；</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 21:16; 撒母耳记上 6:20; 撒母耳记上 6:12"> 便·底甲，负责玛迦斯、沙宾、伯·示麦、以伦·伯·哈南；</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:35; 约书亚记 12:17; 约书亚记 17:2"> 便·希悉，负责亚鲁泊，包括梭哥和希弗全境；</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 11:2; 约书亚记 12:23; 约书亚记 17:11"> 所罗门女儿她法的丈夫便·亚比拿达，负责多珥高原；</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 17:11; 士师记 5:19; 约书亚记 3:16"> 亚希律的儿子巴拿，负责他纳和米吉多，靠近撒拉他拿、耶斯列下边的伯·善全境，以及从伯·善到亚伯·米何拉，远至约缅；</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 3:4; 民数记 32:41; 列王纪上 22:3"> 便·基别，负责基列的拉末和玛拿西子孙雅珥在基列的城邑，以及巴珊的亚珥歌伯地区有城墙和铜闩的大城六十座；</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 13:26; 撒母耳记下 17:24; 撒母耳记下 2:8"> 易多的儿子亚希拿达，负责玛哈念；</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 19:32–39; 撒母耳记下 15:27; 撒母耳记上 18:18"> 所罗门的另一个女儿巴实抹的丈夫亚希玛斯，负责拿弗他利；</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:24–31; 撒母耳记下 15:32"> 户筛的儿子巴拿，负责亚设和亚禄；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 19:17–23"> 帕路亚的儿子约沙法，负责以萨迦；</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:8; 约书亚记 18:20–28; 撒迦利亚书 12:13"> 以拉的儿子示每，负责便雅悯；</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:26–17; 约书亚记 13:9–12; 民数记 21:21–35"> 乌利的儿子基别，独自负责从前属亚摩利王西宏和巴珊王噩的基列地区。</span>
</div>
</div>

## 所罗门的财富和智慧

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 22:17; 列王纪上 3:8; 创世记 32:12"> 犹大人和以色列人多如海沙，丰衣足食，生活幸福。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:18; 约书亚记 1:4; 诗篇 68:29"> 所罗门统管列国，从幼发拉底河至非利士，直到埃及边界。所罗门在世的日子，列国都年年进贡称臣。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 所罗门每天的膳食用三千公斤细面粉、六千公斤粗面粉、</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 5:17–18"> 十头肥牛、二十头草场的牛、一百只羊，此外还有鹿、羚羊、狍子及肥禽。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:9; 诗篇 72:11; 诗篇 72:3"> 所罗门统治幼发拉底河西面所有的国家，从提弗萨直到迦萨，四境安宁。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 4:4; 撒迦利亚书 3:10; 士师记 20:1"> 所罗门在世的时候，从但到别示巴的犹大人和以色列人都在自己的葡萄树和无花果树下安居。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 1:14; 历代志下 9:25; 撒母耳记下 8:4"> 所罗门有四万个安置拉战车马匹的马厩和一万二千名骑兵。</span>
<span className="v" id="v27" data-v="27"> 十二个地方官按月供给所罗门王及王室的需用，使他们一无所缺。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖记 8:10; 以斯帖记 8:14; 弥迦书 1:13"> 他们也各按其份提供喂战车马等马匹用的大麦和干草。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 3:12; 雅各书 3:17; 列王纪上 4:20"> 上帝赐予所罗门极大的智慧和悟性，以及如海边的沙一样浩博的学识。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 5:11–12; 创世记 25:6; 但以理书 1:20"> 他的智慧高过东方人和埃及人的一切智慧，</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 2:6; 历代志上 15:19; 列王纪上 3:12"> 无人能比，胜过以斯拉人以探和玛曷的儿子希幔、甲各、达大的智慧。他名扬四周列国。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 马太福音 13:35; 箴言 1:1–31"> 所罗门写下箴言三千句，作诗歌一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:23; 诗篇 51:7; 诗篇 92:12"> 他对飞禽走兽、草木鱼虫，从黎巴嫩的香柏树到长在墙上的牛膝草，都无所不知。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 9:23; 列王纪上 10:1; 历代志下 9:1"> 天下列王风闻所罗门的智慧，都纷纷遣使来求教。</span>
</div>
</div>

</div>

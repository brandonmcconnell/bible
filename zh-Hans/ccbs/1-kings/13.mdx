## 上帝的仆人警告耶罗波安

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:32–33; 列王纪下 23:17; 帖撒罗尼迦前书 4:15"> 有一位上帝的仆人奉耶和华的命令从犹大来到伯特利。那时，耶罗波安正站在祭坛旁烧香。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 36:1; 列王纪下 23:15–18; 列王纪下 22:1–2"> 上帝的仆人奉耶和华的命令向祭坛喊道：“祭坛啊，祭坛啊，耶和华说，必有一子在大卫家出生，他名叫约西亚。他要在你上面杀死那些焚香献祭的丘坛祭司，在你上面焚烧人的骨头。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:22; 出埃及记 4:3–5; 士师记 6:17"> 当日，他又说：“耶和华说要给你们一个征兆，这坛必破裂，坛上的灰必撒出来。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="启示录 11:5; 历代志下 18:25–27; 路加福音 6:10"> 耶罗波安王听了他向伯特利的祭坛所发的呼声，就从坛上伸手指着他说：“给我拿住他！”但王伸出来的手枯干了，不能收回。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:3; 耶利米书 28:16–17; 申命记 18:22"> 这时，祭坛破裂了，坛上的灰也撒了出来，应验了上帝的仆人奉耶和华之命所说的征兆。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 9:28; 使徒行传 8:24; 出埃及记 10:17"> 王对上帝的仆人说：“请你为我祷告，求你的上帝耶和华使我的手复原。”于是，上帝的仆人向耶和华祷告，王的手就复原了。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:15; 撒母耳记上 9:7–8; 士师记 13:15"> 王对上帝的仆人说：“请你跟我回宫，吃点东西吧！我要酬谢你。”</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 24:13; 民数记 22:18; 马可福音 6:23"> 上帝的仆人却说：“你就是把你一半的家产送给我，我也不跟你去，也不在这地方用饭喝水，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 13:17; 申命记 13:13–18; 罗马书 16:17"> 因为耶和华吩咐我不可吃饭喝水，也不可原路返回。”</span>
<span className="v" id="v10" data-v="10"> 上帝的仆人就从另一条路回去了，没有从伯特利原路返回。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:18; 列王纪上 13:20–21; 民数记 24:2"> 在伯特利住着一位老先知，他儿子们把上帝的仆人那天所行的事和对王所说的话告诉了他。</span>
<span className="v" id="v12" data-v="12"> 老先知问道：“上帝的仆人走的哪条路？”他的儿子们就把上帝的仆人走的那条路告诉了他。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 10:4; 撒母耳记下 19:26; 士师记 5:10"> 于是，他嘱咐儿子们为他备驴，然后骑驴去追赶上帝的仆人，看见他正坐在一棵橡树下，便问：“你就是那位从犹大来的上帝的仆人吗？”他说：“是。”</span>
<span className="v" id="v15" data-v="15"> 老先知说：“请你跟我一起回家吃饭吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:8–9; 马太福音 16:23; 民数记 22:19"> 上帝的仆人说：“我不能跟你去，也不能跟你在这里吃饭喝水，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 20:35; 帖撒罗尼迦前书 4:15; 列王纪上 13:1"> 因为耶和华吩咐我不可在这里用饭喝水，也不可原路返回。”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:1; 马太福音 7:15; 民数记 22:35"> 老先知就欺骗他说：“我也是先知，和你一样。耶和华派天使来吩咐我带你到我家吃饭喝水。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 13:1; 创世记 3:6; 使徒行传 4:19"> 上帝的仆人就随他回家吃饭喝水。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:22; 民数记 24:4; 民数记 24:16–24"> 席间，耶和华的话临到老先知，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 13:17; 撒母耳记上 13:13–14; 撒母耳记上 4:18"> 他就对从犹大来的上帝的仆人说：“耶和华说，你违背了你的上帝耶和华的命令，没有遵从祂的吩咐，</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 14:18–20; 列王纪上 14:13; 耶利米书 22:18–19"> 竟然返回祂禁止你吃喝的地方吃饭喝水，因此你的尸体必不得安葬在你的祖坟里。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 吃喝完了，老先知为他带回家的这位先知备驴，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:36; 列王纪下 2:24; 箴言 26:13"> 这位先知在路上遇到一头狮子，被咬死了，尸体倒在路上，驴和狮子都站在尸体旁边。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 13:11"> 过路的人看见尸体倒在路上，旁边还站着一头狮子，就去老先知住的城报告这事。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 9:6; 箴言 11:31; 诗篇 119:120"> 老先知听到消息，就说：“这是上帝的仆人，他违背了耶和华的命令，所以耶和华让狮子咬死了他，正应验了耶和华的话。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 他吩咐儿子们备好驴，</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 17:6; 诗篇 148:7–8; 但以理书 6:22–24"> 去了那里，看见上帝仆人的尸体倒在路上，驴和狮子站在尸体旁。狮子既没有吃尸体，也没有伤害驴。</span>
<span className="v" id="v29" data-v="29"> 老先知把上帝仆人的尸体驮在驴背上，运回城中为他哀悼，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:18; 使徒行传 8:2; 列王纪上 14:13"> 把他葬在自己的坟墓里，哀悼他说：“唉！我的弟兄啊！”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:17–18; 民数记 23:10; 路加福音 16:22–23"> 安葬之后，老先知又对儿子们说：“我死后，你们要把我跟上帝的仆人合葬，让我们的尸骨在一起。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 16:24; 列王纪上 13:2; 列王纪上 12:31"> 因为他奉耶和华的命令咒诅伯特利的祭坛和撒玛利亚各城高岗上神庙的话必应验。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志下 11:15; 历代志下 13:9; 民数记 17:12–13"> 这事以后，耶罗波安没有改邪归正，他任命各种人做丘坛的祭司，不管谁想做祭司，他都封立他们。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 列王纪上 12:30"> 这罪使耶罗波安家走向没落，最终彻底灭亡。</span>
</div>
</div>

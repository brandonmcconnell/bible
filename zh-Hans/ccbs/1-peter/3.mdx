## 夫妻之道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:18; 以弗所书 5:33; 以弗所书 5:22–24"> 照样，你们做妻子的要顺服自己的丈夫。这样，即使丈夫不信从真道，也会因为看见妻子贞洁和敬虔的品行而被无声地感化。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 2:9–10; 罗马书 12:2; 以赛亚书 3:18–24"> 你们不要注重外表的妆饰，像编头发、戴金饰或穿华丽的衣服，</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12; 撒母耳记上 16:7; 罗马书 2:29"> 要以温柔、娴静这些永不褪色的内在美为妆饰，这是上帝所看重的。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 2:3–4; 提摩太前书 5:5; 路加福音 2:37"> 从前那些仰赖上帝的圣洁妇女，都以这些来妆饰自己，并顺服自己的丈夫，</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:12; 罗马书 9:7–9; 以赛亚书 57:11"> 正如撒拉顺服亚伯拉罕，称他为主人。你们如果做对的事，不怕恐吓，就是撒拉的女儿。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:19; 创世记 2:23–24; 马太福音 19:3–9"> 你们做丈夫的也一样，要按情理<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“按情理”希腊文是“按知识”。">a</a></sup>与妻子共同生活，因为她们比你们软弱。要敬重她们，因为她们和你们一同承受生命之恩。这样，你们的祷告就可以畅通无阻了。</span>
</div>
</div>

## 要为义受苦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="罗马书 12:10; 以弗所书 4:31–2; 彼得前书 1:22"> 总而言之，你们要同心合意，互相关怀，彼此相爱，仁慈谦卑。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; 罗马书 12:17; 罗马书 12:14"> 不要以恶报恶，以辱骂还辱骂，反要祝福对方，因为这是你们蒙召的目的，好叫你们蒙福。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 34:12–16; 雅各书 1:26; 彼得前书 2:1"> 圣经上说：<br /><span className="pl pl-1">“若有人热爱生命，</span><br /><span className="pl pl-1">渴望幸福，</span><br /><span className="pl pl-1">就要舌头不出恶言，</span><br /><span className="pl pl-1">嘴唇不说诡诈的话。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:9; 诗篇 34:14; 希伯来书 12:14"> <span className="pl pl-1">要弃恶行善，竭力追求和睦。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 34:15–16; 约翰福音 9:31; 箴言 15:29"> <span className="pl pl-1">因为主的眼睛看顾义人，</span><br /><span className="pl pl-1">祂的耳朵垂听他们的祈求。</span><br /><span className="pl pl-1">但主必严惩作恶之人。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇34:12‑16。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; 罗马书 8:28; 帖撒罗尼迦前书 5:15"> 如果你们热心行善，有谁会害你们呢？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28; 彼得前书 2:19–20; 马太福音 5:10–12"> 就算你们为义受苦，也是有福的。不要害怕别人的恐吓<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“不要害怕别人的恐吓”或译“不要怕别人所怕的”。以赛亚书8:12。">c</a></sup>，也不要惊慌，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:6; 提摩太后书 2:25–26; 路加福音 21:14–15"> 要从心里尊基督为主。如果有人问起你们心中的盼望，你们要随时准备答复，</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 2:12; 希伯来书 13:18; 彼得前书 2:15"> 但态度要温和恭敬，存无愧的良心。这样，那些对你们在基督里的好品行妄加诬蔑的人会自觉羞愧。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:14; 彼得前书 4:19; 马太福音 26:39"> 如果上帝的旨意是要你们因行善而受苦，也总比你们因作恶而受苦强。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 9:28; 希伯来书 9:26; 哥林多后书 5:21"> 因为基督也曾一次为罪受苦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“受苦”有古卷作“受死”。">d</a></sup>，以无罪之身代替不义之人，为要领你们到上帝面前。祂的肉体虽被处死，但祂借着圣灵复活了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 4:6; 以赛亚书 61:1; 以赛亚书 42:7"> 祂还借着圣灵向那些被监禁的灵魂传道，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:7; 彼得后书 2:5; 创世记 6:3"> 就是从前在挪亚造方舟、上帝耐心等候人们悔改的时代中那些不肯信的人。当时进入方舟，从洪水中得救的人很少，只有八个人。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 16:16; 以西结书 36:25–26; 使徒行传 2:38"> 这水预表的洗礼现在借着耶稣基督的复活也拯救了你们，这洗礼不是要除掉肉体的污秽，而是求在上帝面前有无愧的良心。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:24; 希伯来书 12:2; 希伯来书 10:12"> 基督已经升到天上，坐在上帝的右边，众天使、掌权的、有能力的都服从了祂。</span>
</div>
</div>

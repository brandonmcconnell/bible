## 麻风病痊愈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:18; 马太福音 4:25–1; 路加福音 5:15"> 耶稣下山的时候，有许多人跟着。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:25; 路加福音 17:12–19; 马太福音 18:26"> 有一个患麻风病的人过来跪在祂跟前，说：“主啊，如果你肯，就能使我洁净。”</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:13; 诗篇 33:9; 列王纪下 5:14"> 耶稣伸手摸他，说：“我肯，你洁净了吧！”那人的麻风病就立刻洁净了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 14:2–32; 路加福音 5:14; 路加福音 17:14"> 耶稣对他说：“切勿把这事告诉别人，要去让祭司察看你的身体，并照摩西的规定献祭，向众人证明你已经洁净了。”</span>
</div>
</div>

## 百夫长的信心

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:1–10; 使徒行传 27:43; 使徒行传 10:1–33"> 耶稣到了迦百农，一个百夫长前来向祂求助，说：</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 4:1; 马太福音 4:24; 使徒行传 9:33"> “主啊，我的仆人瘫痪，躺在家里，非常痛苦。”</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 9:18–19; 路加福音 7:6; 马可福音 5:23–24"> 耶稣说：“我去医治他。”</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 107:20; 路加福音 7:6–7; 诗篇 33:9"> 百夫长说：“主啊，你亲临舍下，我不敢当。只要你说一句话，我仆人就会痊愈。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:35–36; 提多书 2:9; 歌罗西书 3:22"> 因为我有上司，也有部下。我命令这个部下去，他就去；要那个部下来，他就来。我吩咐奴仆做什么，他就做什么。”</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:28; 路加福音 7:9; 马可福音 6:6"> 耶稣听了，感到惊奇，便对跟随祂的人说：“我实在告诉你们，我在以色列从未见过信心这么大的人。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:28–29; 以弗所书 3:6; 加拉太书 3:28–29"> 我告诉你们，将来有许多从东从西来的人会在天国与亚伯拉罕、以撒和雅各一同欢宴。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:30; 路加福音 13:28; 马太福音 21:43"> 但那些本应承受天国的人反而会被赶到外面的黑暗里，在那里哀哭切齿。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 马可福音 9:23; 约翰福音 4:50"> 耶稣对百夫长说：“你回去吧！就照你所信的给你成就。”就在那时候，他的仆人便痊愈了。</span>
</div>
</div>

## 治病赶鬼

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 4:38–41; 马可福音 1:29–34; 哥林多前书 9:5"> 耶稣来到彼得家，看见彼得的岳母正在发烧，躺在床上。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 路加福音 4:38–39; 路加福音 8:54"> 耶稣一摸她的手，她的烧就退了，她便起来服侍耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:26; 马太福音 14:14; 马可福音 1:32–34"> 当晚，有人带着许多被鬼附身的人来见耶稣。耶稣一句话就把鬼赶出去了，并治好了所有的病人。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:4; 彼得前书 2:24; 马太福音 1:22"> 这是要应验以赛亚先知的话：“祂担当了我们的软弱，背负了我们的疾病。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书53:4。">a</a></sup></span>
</div>
</div>

## 跟从耶稣的代价

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 4:42–43; 路加福音 8:22; 马可福音 4:35"> 耶稣看到人群围着祂，就吩咐门徒渡到湖对岸。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:33–34; 约翰福音 13:36–38; 路加福音 14:25–27"> 这时，有一位律法教师上前对耶稣说：“老师，无论你往哪里去，我都要跟从你。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 84:3; 路加福音 2:7; 以赛亚书 53:2–3"> 耶稣说：“狐狸有洞，飞鸟有窝，人子却没有安枕之处。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 9:59–62; 利未记 21:11–12; 民数记 6:6–7"> 另一个门徒对耶稣说：“主啊，请让我先回去安葬我的父亲。”</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 2:13; 路加福音 15:32; 以弗所书 5:14"> 耶稣对他说：“你跟从我，让死人去埋葬他们的死人吧！”</span>
</div>
</div>

## 平静风浪

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 8:22–25; 马可福音 4:36–41; 马太福音 9:1"> 耶稣上了船，门徒也跟着祂上去。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 8:23; 诗篇 107:23–27; 马可福音 4:37–38"> 忽然，湖面上狂风大作，波涛汹涌，船快要被巨浪吞没，耶稣却在睡觉。</span>
<span className="v" id="v25" data-v="25" data-xref="约拿书 1:6; 历代志下 14:11; 马可福音 4:38–39"> 门徒连忙叫醒耶稣，说：“主啊，救命！我们快淹死了！”</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 41:10–14; 诗篇 65:7; 诗篇 107:28–30"> 耶稣答道：“你们的信心太小了，为什么害怕呢？”于是祂起来斥责风和浪，风浪就完全平静了。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 7:37; 马可福音 6:51; 马太福音 14:33"> 门徒很惊奇，说：“祂究竟是什么人？连风浪都听祂的！”</span>
</div>
</div>

## 治好两个被鬼附身的人

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 8:26–39; 马可福音 5:1–20; 使徒行传 10:38"> 耶稣到了对岸加大拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“加大拉”即格拉森地区。">b</a></sup>人的地方，遇见两个被鬼附身的人。他们从坟墓里出来，非常凶恶，没有人敢从那里经过。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 1:24; 路加福音 4:34; 雅各书 2:19"> 他们高喊：“上帝的儿子啊！我们和你有什么关系？时候还没有到，你就来叫我们受苦吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 14:8; 利未记 11:7; 马可福音 5:11"> 当时，有一大群猪在远处吃食。</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 20:1–2; 路加福音 8:30–33; 马可福音 5:12"> 鬼就央求耶稣：“如果你要赶我们出去，就让我们进入猪群吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 5:13; 使徒行传 2:23; 启示录 20:7"> 耶稣说：“去吧！” 于是，鬼从那二人身上出来，进入猪群，整群猪就一路奔下陡坡，冲进湖里淹死了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:34–36; 马可福音 5:14–16; 使徒行传 19:15–17"> 放猪的人逃进城，把事情的经过以及被鬼附身者的遭遇告诉了城里的人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 16:39; 路加福音 8:37–39; 路加福音 5:8"> 于是，全城的人都出来见耶稣，见到后，便请求祂离开那里。</span>
</div>
</div>

## 天国里谁最伟大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 9:33–37; 路加福音 9:46–48; 马太福音 20:20–28"> 这时，门徒上前来，问耶稣：“在天国谁最伟大？”</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:13–14; 马可福音 9:36–37; 列王纪上 3:7"> 耶稣叫了一个小孩子来站在他们当中，然后说：</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:14–15; 彼得前书 2:2; 马太福音 19:14"> “我实在告诉你们，你们若不回转，变得像小孩子那样，绝不能进天国。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 4:10; 路加福音 14:11; 马可福音 10:43"> 所以，凡像这小孩子一样谦卑的人，在天国才是最伟大的。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 25:40; 马可福音 9:37; 约翰福音 13:20"> “谁为了我的名接待这样一个小孩子，就是接待我。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 9:42; 路加福音 17:1–2; 马太福音 18:10"> 不论谁使这样一个小信徒失足犯罪，他的下场比把大磨石拴在他脖子上沉到深海里还要惨。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前书 11:19; 马太福音 26:24"> 这世界有祸了！因为里面充满了引人犯罪的事。这样的事是免不了的，但引人犯罪的人有祸了！</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:29–30; 腓立比书 3:8–9; 罗马书 13:12"> “如果你的手或脚使你犯罪，就把它砍下来扔掉！肢体残缺着进入永生，胜过四肢健全却被扔进永远不灭的火中。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 14:22; 马太福音 18:8; 马太福音 5:29"> 如果你的一只眼睛使你犯罪，就剜出来丢掉它！独眼进入永生，胜过双目健全却被扔进地狱的火中。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:14"> 你们切不可轻视任何一位卑微的人。我告诉你们，他们的天使在天上常见我天父的面。</span>
</div>
</div>

## 迷失的羊

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> “人子到世界来是要拯救迷失的人。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无11节。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 34:12; 路加福音 15:4–7; 以西结书 34:16"> 如果一个人有一百只羊，其中有一只走迷了路，你们认为他会怎么办呢？难道不会把那九十九只撇在山上，去找那只迷失的羊吗？</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:17; 路加福音 15:5–10; 雅各书 2:13"> 我实在告诉你们，如果找到了，他会非常欢喜，甚至比有那九十九只没有迷失的羊还欢喜。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:12; 约翰福音 6:39–40; 彼得后书 3:9"> 同样，你们的天父也不愿任何一个卑微的人失丧。</span>
</div>
</div>

## 纠正信徒的过错

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 19:17; 路加福音 17:3–4; 加拉太书 6:1"> “如果你的弟兄得罪了你，你要找个机会跟他单独在一起，指出他的错处。如果他肯接受劝告，你就赢得了你的弟兄。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 19:15; 哥林多后书 13:1; 约翰福音 8:17"> 如果他不听，你就带一两位弟兄去见他，这样任何事有两三个证人作证才能定案。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命记19:15。">b</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:6; 哥林多前书 5:9–7; 帖撒罗尼迦后书 3:14–15"> 如果他仍然不听，你就应当告诉教会。如果他连教会也不听，你就把他看作异教徒或税吏<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“税吏”即犹太人眼中的“汉奸”，帮助统治犹太人的罗马政府收税，常从中牟取暴利。">c</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:19; 哥林多后书 2:10; 约翰福音 20:23"> 我实在告诉你们，你们在地上捆绑的，在天上也要捆绑；你们在地上释放的，在天上也要释放。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 7:7; 约翰一书 5:14–16; 马可福音 11:24"> “况且，我实在告诉你们，如果你们当中有两个人在地上同心合意地祈求，不论求什么，我天上的父必为你们成就。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 5:4; 启示录 21:3; 马太福音 28:20"> 因为哪里有两三个人奉我的名聚会，我就在哪里与他们同在。”</span>
</div>
</div>

## 七十个七次

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 马太福音 18:15"> 那时，彼得上前问耶稣：“主啊，如果我的弟兄得罪了我，我该饶恕他多少次呢？七次够了吧？”</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:13; 马可福音 11:25; 马太福音 6:14–15"> 耶稣回答说：“我告诉你，不是七次，是七十个七次。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:24; 罗马书 14:12; 马太福音 3:2"> “因此，天国就像一个王，他要跟奴仆清算债务。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 38:4; 诗篇 130:3–4; 路加福音 16:5"> 正开始清算的时候，有人带着一个欠了六千万银币<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“六千万银币”希腊文是“一万他连得”，一他连得相当于当时一个普通工人20年的工钱。">d</a></sup>的人进来。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 4:1; 尼希米记 5:5; 路加福音 7:42"> 因为这个人无法清还债款，主人就下令把他及其妻儿和所有财产全部卖掉还债。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:29; 路加福音 7:43; 马太福音 8:2"> 那奴仆跪在王面前乞求说，‘请宽容我，我会把债务全部还清的。’</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 145:8; 尼希米记 9:17; 诗篇 86:15"> 主人可怜他，不但释放了他，而且免了他全部的债。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 20:2; 以西结书 45:9; 申命记 15:2"> “可是，那奴仆出去后，遇见一位欠他一百个银币<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一个银币相当于当时普通工人一天的工钱。">e</a></sup>的同伴，就揪住他，掐着他的喉咙说，‘还我钱！’</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 18:26; 马太福音 6:12; 腓利门书 1:18–19"> 同伴跪下哀求道，‘请宽容我，我会还你的。’</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 22:27; 列王纪上 21:27–29"> “那奴仆却不肯，竟把同伴送进监狱，直到他还清债务为止。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 12:15; 希伯来书 13:3; 马可福音 3:5"> 其他奴仆目睹这一切，都愤愤不平，就去把这件事告诉了主人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 马太福音 25:26; 罗马书 3:19"> “于是，主人把那奴仆召来，说，‘你这可恶的奴才！你哀求我，我就免了你所有的债。</span>
<span className="v" id="v33" data-v="33" data-xref="歌罗西书 3:13; 马太福音 6:12; 以弗所书 4:32–2"> 难道你不应该怜悯你的同伴，就像我怜悯你一样吗？’</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:25–26; 雅各书 2:13; 路加福音 12:58–59"> 主人大怒，把他交给狱卒受刑，直到他还清全部的债务。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 6:14–15; 雅各书 2:13; 路加福音 6:37–38"> 如果你们每个人不从心里饶恕自己的弟兄，我的天父也要这样对待你们。”</span>
</div>
</div>

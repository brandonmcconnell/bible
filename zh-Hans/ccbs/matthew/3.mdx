## 开路先锋

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 40:3–6; 约翰福音 1:6–8; 路加福音 1:76"> 那时，施洗者约翰来到犹太的旷野传道，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:17; 马可福音 1:15; 但以理书 2:44"> “悔改吧，因为天国临近了！”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3; 玛拉基书 3:1; 约翰福音 1:23"> 以赛亚先知曾说：“有人在旷野大声呼喊，‘预备主的道，修直祂的路。’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书40:3。">a</a></sup>他指的就是约翰。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 1:8; 撒迦利亚书 13:4; 马可福音 1:6"> 约翰身穿骆驼毛的衣服，腰束皮带，吃的是蝗虫和野蜜。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:5; 路加福音 3:7; 约翰福音 3:23"> 那时，耶路撒冷、犹太各地和约旦河一带的人都来到约翰那里，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 19:18; 马太福音 3:13–16; 使徒行传 2:38–41"> 承认他们的罪，在约旦河里接受他的洗礼。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:34; 帖撒罗尼迦前书 1:10; 罗马书 5:9"> 约翰看见很多法利赛人和撒都该人也来受洗，就对他们说：“你们这些毒蛇的后代！谁指示你们逃避那将临的烈怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 3:8; 使徒行传 26:20; 彼得后书 1:4–8"> 你们要结出与悔改相称的果子。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:8; 罗马书 9:7–8; 加拉太书 3:27–29"> 不要心里说，‘我们是亚伯拉罕的子孙。’我告诉你们，上帝可以从这些石头中兴起亚伯拉罕的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:6; 路加福音 3:9; 马太福音 7:19"> 现在斧头已经放在树根上了，凡不结好果子的树都要被砍下，扔进火里。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 4:4; 路加福音 3:16; 使徒行传 1:5"> 我用水给你们施洗，叫你们悔改。但在我之后，有一位比我更有能力的要来，我连给祂提鞋都不配。祂要用圣灵和火给你们施洗。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 4:1; 马太福音 13:30; 路加福音 3:17"> 祂手里拿着簸箕，要扬净祂的麦场，把麦子收进仓库，用不灭的火把糠秕烧尽。”</span>
</div>
</div>

## 耶稣受洗

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:32–34; 马太福音 2:22; 马可福音 1:9–11"> 后来，耶稣从加利利来到约旦河受约翰的洗礼。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 3:3–7; 使徒行传 1:5–8; 约翰福音 13:6–8"> 约翰想要拦住祂，就说：“我需要受你的洗，你反倒来找我吗？”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:34; 约翰福音 15:10; 诗篇 40:7–8"> 耶稣答道：“你暂且这样做吧！我们理当这样履行一切的义。”于是约翰答应了。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 11:2; 马可福音 1:10; 路加福音 3:21–22"> 耶稣受了洗，刚从水里上来，天就开了。祂看见上帝的灵像鸽子一样降在祂身上，</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1; 诗篇 2:7; 马太福音 17:5"> 又有声音从天上传来：“这是我的爱子，我喜悦祂。”</span>
</div>
</div>

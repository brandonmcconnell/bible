## 谴责律法教师和法利赛人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 马太福音 15:10–20"> 随后，耶稣对众人和门徒说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 20:46; 马可福音 12:38; 玛拉基书 2:7"> “律法教师和法利赛人坐在摩西的位子上讲授律法。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 提多书 1:16; 罗马书 2:19–24"> 你们要谨遵他们的教导，但不要效法他们的行为，因为他们言行不一。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行传 15:10; 加拉太书 6:13"> 他们把难负的重担捆好，放在别人肩上，而自己连一根指头也不肯动！</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 6:1–16; 约翰福音 12:43; 腓立比书 2:3"> “他们的所作所为是为了给人看的，他们把额上佩戴的经文盒子加宽了，又将衣服的穗子加长了。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:9; 路加福音 11:43–54; 马可福音 12:38–39"> 他们喜欢宴席中的上座和会堂里的首位。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 1:38; 约翰福音 1:49; 约翰福音 3:26"> 他们喜欢别人在街市上问候他们，称呼他们为老师<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“老师”希腊文是“拉比”，特指犹太教的老师。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:1; 哥林多前书 1:12–13; 彼得前书 5:3"> 但你们不要让别人称呼你们为老师，因为你们只有一位老师，你们彼此都是弟兄。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:1; 希伯来书 12:9; 玛拉基书 1:6"> 不要称呼地上的人为父亲，因为你们只有一位父亲，祂在天上。</span>
<span className="v" id="v10" data-v="10"> 不要让人称你们为导师，因为你们只有一位导师基督。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 9:19; 加拉太书 5:13; 约翰福音 13:14–15"> 你们当中谁位分最大，谁就要做你们的仆人。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:5; 雅各书 4:6; 箴言 29:23"> 自高的人必遭贬抑，谦卑的人必得尊荣。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 马太福音 23:29; 马太福音 23:23"> “虚伪的律法教师和法利赛人啊，你们有祸了！因为你们当着人们的面关闭天国之门，自己不进去，也不让别人进去。</span>
<span className="v" id="v14" data-v="14"> “虚伪的律法教师和法利赛人啊，你们有祸了！因为你们侵吞寡妇的家产，还假意做冗长的祷告。因此，你们会受到更严厉的刑罚。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷无14节。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 2:3; 使徒行传 13:10; 使徒行传 13:43"> “虚伪的律法教师和法利赛人啊，你们有祸了！因为你们走遍海洋和陆地去引人入教，等人入了教，却使他沦为地狱之子，比你们还坏一倍。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:14; 马太福音 5:33–35; 雅各书 5:12"> “瞎眼的向导啊，你们有祸了！你们说，‘指着圣殿发誓，不算数；但是指着圣殿里的金子发誓，就要遵守誓言。’</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 23:19; 民数记 16:38–39; 诗篇 94:8"> 瞎眼的愚昧人啊！金子重要呢？还是使金子神圣的圣殿重要呢？</span>
<span className="v" id="v18" data-v="18"> 你们又说，‘指着祭坛发誓不算数，但是指着坛上的供物发誓，就要遵守誓言。’</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:37; 出埃及记 30:29"> 瞎眼的人啊！供物重要呢？还是使供物神圣的祭坛重要呢？</span>
<span className="v" id="v20" data-v="20"> 其实指着祭坛发誓，就是指着祭坛和坛上的一切东西发誓。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 26:8; 列王纪上 8:13; 历代志下 6:2"> 指着圣殿发誓，就是指着圣殿和住在里面的上帝发誓。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:34; 诗篇 11:4; 以赛亚书 66:1"> 指着天发誓，就是指着上帝的宝座和坐在宝座上的那位发誓。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; 弥迦书 6:8; 何西阿书 6:6"> “虚伪的律法教师和法利赛人啊，你们有祸了！你们把薄荷、茴香、芹菜献上十分之一，却忽略了律法中更重要的事——公正、怜悯、信实。后者是你们本该做的，前者也不可忽略。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:24; 马太福音 27:6–8; 马太福音 15:2–6"> 瞎眼的向导啊！你们滤出蚊虫，却吞下骆驼。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 马太福音 15:19–20; 马可福音 7:4–13"> “虚伪的律法教师和法利赛人啊，你们有祸了！你们洗净杯盘的外面，里面却盛满了贪婪和放纵。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 7:1; 雅各书 4:8; 希伯来书 10:22"> 瞎眼的法利赛人啊！要先洗净杯盘的里面，好让外面也干净。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="意思是：“里面的思想先干净了，外在的言行才会真正干净。”">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行传 23:3; 民数记 19:16"> “虚伪的律法教师和法利赛人啊，你们有祸了！你们好像粉饰的坟墓，外表好看，里面却装满了死人的骨头和各种污秽之物。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; 诗篇 51:6; 马太福音 23:5"> 所以你们虚有公义的外表，内心却充满了虚伪和罪恶。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行传 2:29"> “虚伪的律法教师和法利赛人啊，你们有祸了！你们为先知建墓，为义人修碑，并且说，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 2:30; 马太福音 23:34–35; 马太福音 21:35–36"> ‘我们如果活在我们祖先的时代，绝不会和他们一起去杀害先知。’</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 7:51–52; 帖撒罗尼迦前书 2:15–16; 约书亚记 24:22"> 这样，你们自己证明自己是杀害先知之人的后代。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 15:16; 民数记 32:14; 帖撒罗尼迦前书 2:16"> 去填满你们祖先的罪恶吧！</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:7; 马太福音 12:34; 马太福音 5:22"> 你们这些蛇，这些毒蛇的后代啊，你们怎能逃脱地狱的刑罚呢？</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:16–17; 马太福音 13:52; 歌罗西书 1:28"> “看啊，我派先知、智者和律法教师到你们当中，有的会遭到你们的杀害，被你们钉在十字架上；有的会在会堂里被你们鞭打，被你们从这城追到那城。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 24:20–22; 撒迦利亚书 1:1; 希伯来书 11:4"> 因此，所有义人在地上所流的血，就是从义人亚伯的血，直到你们在圣所和祭坛之间所杀的巴拉加的儿子撒迦利亚的血，都要归到你们身上。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:23; 马太福音 24:34; 马可福音 13:30–31"> 我实在告诉你们，这一切罪责都要归到这个世代。</span>
</div>
</div>

## 为耶路撒冷哀叹

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; 路得记 2:12; 诗篇 91:4"> “耶路撒冷啊！耶路撒冷啊！你常杀害先知，又用石头打死派到你那里的使者。我多次想要招聚你的儿女，像母鸡把小鸡聚集在翅膀底下，可是你们却不肯。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 22:5; 路加福音 13:35; 路加福音 21:24"> 看啊！你们的家园将一片荒凉。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 118:26; 马太福音 21:9; 罗马书 11:25"> 我告诉你们，从现在起，直到你们说‘奉主名来的当受称颂’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇118:26。">d</a></sup>那天之前，你们再也见不到我了。”</span>

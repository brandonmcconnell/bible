## 八福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:13; 马太福音 15:29; 马可福音 4:1"> 耶稣看见大群的人，就上了山，并坐下，门徒走到祂跟前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 8:35; 路加福音 6:20–26; 使徒行传 10:34"> 祂就开口教导他们，说：</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 66:2; 箴言 29:23; 诗篇 34:18"> <span className="pl pl-1">“心灵贫穷的人有福了，</span><br /><span className="pl pl-1">因为天国是他们的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 21:4; 哥林多后书 7:9–10; 约翰福音 16:20–22"> <span className="pl pl-1">哀痛的人有福了，</span><br /><span className="pl pl-1">因为他们必得安慰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:11; 以赛亚书 29:19; 雅各书 3:13"> <span className="pl pl-1">谦和的人有福了，</span><br /><span className="pl pl-1">因为他们必承受土地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 4:14; 诗篇 107:9; 约翰福音 6:27"> <span className="pl pl-1">切慕公义如饥似渴的人有福了，</span><br /><span className="pl pl-1">因为他们必得饱足。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:32–1; 马太福音 6:14–15; 撒母耳记下 22:26"> <span className="pl pl-1">心存怜悯的人有福了，</span><br /><span className="pl pl-1">因为他们必蒙怜悯。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 24:4; 诗篇 51:10; 希伯来书 10:22"> <span className="pl pl-1">心灵纯洁的人有福了，</span><br /><span className="pl pl-1">因为他们必看见上帝。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 12:14; 雅各书 3:16–18; 罗马书 12:18"> <span className="pl pl-1">使人和睦的人有福了，</span><br /><span className="pl pl-1">因为他们必被称为上帝的儿女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:12; 彼得前书 3:13–14; 哥林多后书 4:17"> <span className="pl pl-1">为义受迫害的人有福了，</span><br /><span className="pl pl-1">因为天国是他们的。</span></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 4:14; 路加福音 21:17; 马可福音 13:13"> “人们若因为我的缘故侮辱、迫害、肆意毁谤你们，你们就有福了。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:23; 雅各书 1:2; 歌罗西书 3:24"> 要欢喜快乐，因为你们在天上有大赏赐。他们也曾这样迫害以前的先知。</span>
</div>

## 盐和光

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 4:6; 路加福音 14:34–35; 马可福音 9:49–50"> “你们是世上的盐。盐如果失去咸味，怎能使它再变咸呢？它将毫无用处，只会被扔在外面任人践踏。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 2:15; 约翰福音 8:12; 以弗所书 5:8–14"> 你们是世上的光。建在山上的城无法隐藏。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:33; 马可福音 4:21; 路加福音 8:16"> 人点亮灯，不会把它放在斗底下，而是放在灯台上，好照亮全家。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 2:12; 提多书 2:7; 约翰福音 15:8"> 同样，你们的光也应当照在人面前，好让他们看见你们的善行，便赞美你们天上的父。</span>
</div>
</div>

## 成全律法

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 10:4; 路加福音 16:17; 加拉太书 4:4–5"> “不要以为我是来废除律法和先知书，我不是来废除，而是来成全。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 16:17; 以赛亚书 40:8; 彼得前书 1:25"> 我实在告诉你们，就是到天地都消失了，律法的一点一划都不会废除，全都要成就。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 12:32; 雅各书 2:10–11; 马太福音 28:20"> 所以，谁违背这些诫命中最小的一条，并教导别人违背，谁在天国将被称为最小的。但谁遵守这些诫命，并教导别人遵守，谁在天国将被称为大的。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2–3; 腓立比书 3:9; 罗马书 9:30–32"> 我告诉你们，你们的义若不胜过律法教师和法利赛人的义，你们绝不能进天国。</span>
</div>
</div>

## 论仇恨

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 5:17; 出埃及记 20:13; 民数记 35:30–34"> “你们听过吩咐古人的话，‘不可杀人，杀人的要受审判。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记20:13。">a</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="约翰一书 3:14–15; 约翰一书 4:20–21; 约翰一书 2:9"> 但我告诉你们，凡无缘无故<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷无“无缘无故”。">b</a></sup>向弟兄发怒的，要受审判；凡骂弟兄是白痴的，要受公会<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“公会”是当时犹太人的最高司法机构，处理宗教、道德和伦理等事务。">c</a></sup>的审判；凡骂弟兄是笨蛋的，难逃地狱的火。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 11:25; 利未记 6:2–6; 马太福音 5:24"> “所以，你在祭坛前献祭的时候，要是想起有弟兄和你有过节，</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 5:16; 罗马书 12:17–18; 马太福音 18:15–17"> 就该把祭物留在祭坛前，先去跟他和好，然后再来献祭。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 12:58–59; 箴言 25:8; 希伯来书 3:13"> “趁着你和告你的人还在去法庭的路上，你要赶紧与对方和解，以免他把你交给审判官，审判官把你交给差役，把你关进监牢。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:34; 路加福音 12:59; 帖撒罗尼迦后书 1:9"> 我实在告诉你，要是有一分钱没有还清，你绝不能从那里出来。</span>
</div>
</div>

## 论通奸

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 5:18; 箴言 6:32; 出埃及记 20:14"> “你们听过这样的话，‘不可通奸。’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="出埃及记20:14。">d</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="约翰一书 2:16; 雅各书 1:14–15; 箴言 6:25"> 但我告诉你们，凡看见妇女就动淫念的，他在心里已经犯了通奸罪。</span>
<span className="v" id="v29" data-v="29" data-xref="罗马书 8:13; 马可福音 9:43–48; 歌罗西书 3:5"> 如果你的右眼使你犯罪，就剜掉它！宁可失去身体的一部分，也比整个人被扔进地狱好。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:43; 马太福音 5:29; 彼得前书 2:8"> 如果你的右手使你犯罪，就砍掉它！宁可失去身体的一部分，也比整个人下地狱好。</span>
</div>
</div>

## 论休妻

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="耶利米书 3:1; 申命记 24:1–4; 马太福音 19:7"> “还有话说，‘人若休妻，必须给她休书’。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="申命记24:1。">e</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 7:3; 哥林多前书 7:10–11; 路加福音 16:18"> 但我告诉你们，除非是妻子不贞，否则休妻就是使妻子犯通奸罪，娶被休的女子也是犯通奸罪。</span>
</div>
</div>

## 论起誓

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命记 23:21; 利未记 19:12; 传道书 5:4–6"> “你们也听过吩咐古人的话，‘不可违背誓言，总要向主遵守所起的誓。’</span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 5:12; 以赛亚书 66:1; 申命记 23:21–23"> 但我告诉你们，不可起誓。不可指着天起誓，因为天是上帝的宝座。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 48:2; 玛拉基书 1:14; 历代志下 6:6"> 不可指着地起誓，因为地是上帝的脚凳。不可指着耶路撒冷起誓，因为那是大君王的城。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 12:25; 马太福音 6:27; 马太福音 23:16–21"> 也不可指着自己的头起誓，因为你不能使一根头发变白或变黑。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 5:12; 歌罗西书 4:6; 歌罗西书 3:9"> 你们说话，是就说是，不是就说不是，多说的便是来自那恶者<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="那恶者即魔鬼，又名撒旦。">f</a></sup>。</span>
</div>
</div>

## 论爱仇敌

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="利未记 24:19–20; 申命记 19:21; 出埃及记 21:22–27"> “你们听过这样的话，‘以眼还眼，以牙还牙。’<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="出埃及记21:24；利未记24:20；申命记19:21。">g</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="帖撒罗尼迦前书 5:15; 彼得前书 3:9; 罗马书 12:17–19"> 但我告诉你们，不要跟恶人作对。有人打你的右脸，连左脸也转过来让他打。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 6:29; 哥林多前书 6:7"> 有人想控告你，要夺你的内衣，连外衣也给他。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:26; 马太福音 27:32; 马可福音 15:21"> 有人强迫你走一里路，你就跟他走二里路。</span>
<span className="v" id="v42" data-v="42" data-xref="箴言 19:17; 希伯来书 13:16; 路加福音 6:30–36"> 有求你的，就给他；有向你借的，不可拒绝他。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 19:18; 诗篇 139:21–22; 加拉太书 5:13–14"> “你们听过这样的话，‘要爱邻居，恨仇敌。’<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="利未记19:18。">h</a></sup></span>
<span className="v" id="v44" data-v="44" data-xref="罗马书 12:14; 彼得前书 3:9; 路加福音 6:27–28"> 但我告诉你们，要爱你们的仇敌，为迫害你们的人祷告。</span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 145:9; 路加福音 6:35; 使徒行传 14:17"> 这样，你们才是天父的孩子。因为祂让阳光照好人也照坏人，降雨给义人也给恶人。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:32–35; 彼得前书 2:20–23; 马太福音 9:10–11"> 如果你们只爱那些爱你们的人，有什么值得嘉奖的呢？就是税吏也会这样做。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 5:20; 路加福音 6:32; 彼得前书 2:20"> 如果你们只问候自己的弟兄，有什么特别呢？就是外族人也会这样做。</span>
<span className="v" id="v48" data-v="48" data-xref="彼得前书 1:15–16; 雅各书 1:4; 利未记 19:2"> 所以，你们要纯全，正如你们的天父是纯全的。</span>
</div>

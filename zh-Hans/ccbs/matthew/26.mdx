## 耶稣受膏

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 14:3–9; 路加福音 7:37–39; 约翰福音 12:1–8"> 当耶稣在伯大尼患过麻风病的西门家里时，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 12:2–3; 路加福音 7:46; 路加福音 7:37–38"> 有个女人趁着祂坐席的时候，把一玉瓶珍贵的香膏倒在祂头上。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:4–6; 马可福音 14:4; 出埃及记 5:17"> 门徒看见后，生气地说：“何必这样浪费？</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:5–6; 马可福音 14:5; 约书亚记 7:20–21"> 这瓶香膏能卖很多钱来周济穷人。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提多书 3:8; 希伯来书 13:21; 提摩太前书 5:10"> 耶稣知道他们的心思，便说：“何必为难这女子？她在我身上做的是一件美事。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 15:11; 马可福音 14:7; 约翰福音 12:8"> 因为你们身边总会有穷人，可是你们身边不会总有我。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 14:8; 约翰福音 12:7; 马可福音 16:1"> 她把香膏浇在我身上是为我的安葬做准备。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 14:9; 马太福音 24:14; 诗篇 112:6"> 我实在告诉你们，无论福音传到世界哪个角落，人们都会传扬这女人的事迹，记念她。”</span>
</div>
</div>

</div>

## 最后的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:7–13; 马可福音 14:12–16; 出埃及记 12:18–20"> 除酵节的第一天，门徒来问耶稣：“你想让我们在哪里为你预备逾越节吃的晚餐呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 14:13–16; 约翰福音 7:6; 约翰福音 17:1"> 耶稣说：“你们进城去，到某人那里对他说，‘老师说祂的时候快到了，祂要与门徒在你家中过逾越节。’”</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 2:5; 约翰福音 15:14; 马太福音 21:6"> 门徒照耶稣的吩咐预备了逾越节的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 14:17–21; 约翰福音 13:21; 路加福音 22:14–16"> 傍晚，耶稣和十二使徒吃晚餐。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:21; 希伯来书 4:13; 约翰福音 6:70–71"> 席间，耶稣说：“我实在告诉你们，你们中间有一个人要出卖我。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 13:22–25; 路加福音 22:23; 马可福音 14:19–20"> 他们都非常忧愁，相继追问耶稣，说：“主啊，肯定不是我吧？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:18; 诗篇 41:9; 约翰福音 13:26–28"> 祂说：“那和我一同在碗里蘸饼吃的就是要出卖我的人。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 26:22–23; 路加福音 24:46; 马太福音 18:7"> 人子要离世了，正如圣经对祂的记载，但那出卖人子的人有祸了，他还不如不生在这世上！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 26:64; 马太福音 27:11; 路加福音 22:70"> 出卖耶稣的犹大问祂：“老师，是我吗？”<br />耶稣说：“你自己说了。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 11:23–29; 路加福音 22:18–20; 哥林多前书 10:16–17"> 他们吃的时候，耶稣拿起饼来，祝谢后，掰开分给门徒，说：“拿去吃吧，这是我的身体。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 25:6; 哥林多前书 10:16; 诗篇 116:13"> 接着祂又拿起杯来，祝谢后递给他们，说：“你们都喝吧，</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 10:4–14; 希伯来书 9:14–22; 利未记 17:11"> 这是我为万人所流的立约之血，为了使罪得到赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 12:2; 启示录 7:17; 马可福音 14:25"> 我告诉你们，从今天起，一直到我在我父的国与你们共饮新酒的那一天之前，我不会再喝这葡萄酒。”</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:1; 以弗所书 5:19–20; 路加福音 22:39"> 他们唱完圣诗，就出门去了橄榄山。</span>
</div>
</div>

## 预言彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒迦利亚书 13:7; 马可福音 14:27–28; 约翰福音 16:32"> 耶稣对门徒说：“今天晚上，你们都要背弃我。因为圣经上说，‘我要击打牧人，羊群将四散。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亚书13:7。">a</a></sup></span>

## 在客西马尼祷告

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:32–42; 马太福音 26:42; 路加福音 22:39–46"> 耶稣和门徒到了一个叫客西马尼的地方，祂对门徒说：“你们坐在这里，我到那边去祷告。”</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 4:21; 马太福音 17:1; 马可福音 5:37"> 祂带了彼得和西庇太的两个儿子一起去。祂感到忧伤和痛苦，</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 12:27; 彼得前书 3:18; 彼得前书 2:24"> 就对他们说：“我心里非常忧伤，几乎要死，你们留在这里跟我一起警醒。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 6:38; 腓立比书 2:8; 路加福音 22:41–42"> 祂稍往前走，俯伏在地上祷告：“我父啊！如果可以，求你撤去此杯。然而，愿你的旨意成就，而非我的意愿。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马可福音 14:37; 路加福音 22:45; 马太福音 26:43"> 耶稣回到三个门徒那里，见他们都睡着了，就对彼得说：“难道你们不能跟我一同警醒半个时辰吗？</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:38; 路加福音 22:46; 以弗所书 6:18"> 你们要警醒祷告，免得陷入诱惑。你们的心灵虽然愿意，肉体却很软弱。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:39; 马可福音 14:39–40; 希伯来书 4:15"> 祂第二次去祷告说：“我父啊！如果此杯不能撤去，必须我喝，愿你的旨意成就。”</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:32; 罗马书 13:1; 箴言 23:34"> 祂回来时见他们又睡着了，因为他们困得眼皮发沉。</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 12:8; 路加福音 18:1; 马太福音 6:7"> 耶稣再次离开他们，第三次去祷告，说了同样的话。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 13:1; 约翰福音 12:27; 马可福音 14:41–42"> 然后，祂回到门徒那里，对他们说：“你们还在睡觉，还在休息吗？看啊！时候到了，人子要被交在罪人手中了。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 9:51; 约翰福音 14:31; 撒母耳记上 17:48"> 起来，我们走吧。看啊，出卖我的人已经来了！”</span>
</div>
</div>

## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒行传 1:16; 马太福音 26:55; 马可福音 14:43–50"> 耶稣还在说话的时候，十二使徒中的犹大来了，同来的还有祭司长和百姓的长老派来的一大群拿着刀棍的人。</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 55:20–21; 诗篇 28:3; 撒母耳记下 3:27"> 出卖耶稣的犹大预先和他们定了暗号，说：“我亲吻谁，谁就是耶稣，你们把祂抓起来。”</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 26:25; 帖撒罗尼迦前书 5:26; 箴言 27:6"> 犹大随即走到耶稣跟前，说：“老师，你好！”然后亲吻耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马太福音 20:13; 马太福音 22:12; 诗篇 41:9"> 耶稣对他说：“朋友，你要做的事，动手吧。”于是那些人上前，下手捉拿耶稣。</span>
<span className="v" id="v51" data-v="51" data-xref="约翰福音 18:36; 马可福音 14:47; 哥林多后书 10:4"> 耶稣的跟随者中有人伸手拔出刀朝大祭司的奴仆砍去，削掉了他一只耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="启示录 13:10; 创世记 9:6; 罗马书 12:19"> 耶稣对他说：“收刀入鞘吧！因为动刀的必死在刀下。</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪下 6:17; 马太福音 4:11; 但以理书 7:10"> 难道你不知道，我可以请求我父马上派超过十二营的天使来保护我吗？</span>
<span className="v" id="v54" data-v="54" data-xref="撒迦利亚书 13:7; 马太福音 26:24; 使徒行传 1:16"> 我若这样做，圣经上有关此事必这样发生的话又怎能应验呢？”</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="马可福音 12:35; 约翰福音 8:2; 路加福音 22:52–53"> 那时，耶稣对众人说：“你们像对付强盗一样拿着刀棍来抓我吗？我天天在圣殿里教导人，你们没有抓我。</span>
<span className="v" id="v56" data-v="56" data-xref="撒迦利亚书 13:7; 约翰福音 16:32; 马可福音 14:50–52"> 不过这一切事的发生，是要应验先知书上的话。”那时，所有门徒都丢下祂逃走了。</span>
</div>
</div>

<span className="v" id="v60" data-v="60" data-xref="申命记 19:15; 诗篇 35:11; 诗篇 27:12"> 很多假证人诬告祂，但都找不到真凭实据。最后有两个人上前说：</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="约翰福音 2:19–21; 马太福音 27:40; 马可福音 15:29"> “这个人曾经说过，‘我能拆毁上帝的殿，三天内把它重建起来。’”</span>

<span className="v" id="v68" data-v="68" data-xref="路加福音 22:63–65; 马可福音 14:65; 彼得前书 2:4–8"> “基督啊！给我们说预言吧，是谁在打你？”</span>

## 彼得三次不认主

<div className="bt">

<div className="bp">

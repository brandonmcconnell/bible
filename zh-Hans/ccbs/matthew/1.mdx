## 耶稣基督的家谱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 22:18; 罗马书 1:3; 加拉太书 3:16"> 耶稣基督是亚伯拉罕的子孙、大卫的后裔，以下是祂的家谱：</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:8; 希伯来书 11:17–18; 创世记 46:8–27"> 亚伯拉罕生以撒， 以撒生雅各， 雅各生犹大和他的兄弟，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:12; 创世记 38:29–30; 历代志上 4:1"> 犹大和她玛生法勒斯和谢拉， 法勒斯生希斯仑， 希斯仑生兰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“兰”希腊文是“亚兰”。">a</a></sup>，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 2:10–12; 民数记 7:12; 民数记 2:3"> 兰生亚米拿达， 亚米拿达生拿顺， 拿顺生撒门，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:31; 路得记 1:16–17; 雅各书 2:25"> 撒门和喇合生波阿斯， 波阿斯和路得生俄备得， 俄备得生耶西，</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 15:5; 撒母耳记上 17:12; 撒母耳记下 12:24–25"> 耶西生大卫王。<br />大卫和乌利亚的妻子生所罗门，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 14:1–15; 列王纪上 14:31; 列王纪上 11:43–24"> 所罗门生罗波安， 罗波安生亚比雅， 亚比雅生亚撒，</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 3:11; 历代志下 26:1–23; 列王纪下 8:16"> 亚撒生约沙法， 约沙法生约兰， 约兰生乌西雅，</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 7:1–13; 历代志下 26:21; 历代志下 27:1–32"> 乌西雅生约坦， 约坦生亚哈斯， 亚哈斯生希西迦，</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 32:33–27; 列王纪上 13:2; 历代志上 3:13–15"> 希西迦生玛拿西， 玛拿西生亚们， 亚们生约西亚，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:20; 耶利米书 52:28–30; 但以理书 1:2"> 约西亚生耶哥尼雅和他的兄弟， 那时以色列人被掳往巴比伦。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 3:17; 以斯拉记 3:2; 路加福音 3:27"> 被掳到巴比伦以后， 耶哥尼雅生撒拉铁， 撒拉铁生所罗巴伯，</span>
<span className="v" id="v13" data-v="13"> 所罗巴伯生亚比玉， 亚比玉生以利亚敬， 以利亚敬生亚所，</span>
<span className="v" id="v14" data-v="14"> 亚所生撒督， 撒督生亚金， 亚金生以律，</span>
<span className="v" id="v15" data-v="15"> 以律生以利亚撒， 以利亚撒生马但， 马但生雅各，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:17; 约翰福音 4:25; 路加福音 3:23"> 雅各生约瑟。 约瑟就是玛丽亚的丈夫， 那被称为基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“基督”意思是“受膏者”。">b</a></sup>的耶稣就是玛丽亚生的。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 1:11–12; 列王纪下 24:14; 马太福音 11:2"> 这样，从亚伯拉罕到大卫共有十四代，从大卫到被掳至巴比伦也是十四代，从被掳至巴比伦到基督降生也是十四代。</span>
</div>
</div>

## 耶稣的降生

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="加拉太书 4:4–5; 路加福音 1:27–38; 约伯记 14:4"> 耶稣基督降生的经过记载如下。 耶稣的母亲玛丽亚和约瑟订了婚，还没有成亲就从圣灵怀了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 22:21–24; 申命记 24:1–4; 约翰福音 8:4–5"> 她未婚夫约瑟是个义人，不愿公开地羞辱她，就想暗中和她解除婚约。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; 路加福音 1:19; 马太福音 1:18"> 他正在考虑这事的时候，主的一位天使在梦中向他显现，说：“大卫的后裔约瑟，不要怕，把玛丽亚娶过来，因为她所怀的孕是从圣灵来的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:23; 使徒行传 4:12; 约翰福音 1:29"> 她将生一个儿子，你要给祂取名叫耶稣<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“耶稣”意思是“救主”。">c</a></sup>，因为祂要把自己的子民从罪恶中救出来。”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:44; 马太福音 2:23; 列王纪上 8:15"> 这一切应验了主借着先知所说的话：</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 7:14; 以赛亚书 9:6–7; 诗篇 46:11"> “必有童贞女怀孕生子，祂的名字要叫以马内利。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以赛亚书7:14。">d</a></sup>以马内利的意思是“上帝与我们同在”。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:14; 雅各书 2:21–26; 约翰福音 2:5–8"> 约瑟醒来，就遵从主的天使所吩咐的娶玛丽亚为妻，</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 2:21; 出埃及记 13:2; 马太福音 1:21"> 只是在她生下孩子之前没有与她同房。约瑟给孩子取名叫耶稣。</span>
</div>
</div>

## 传统与诫命

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:22; 马太福音 23:2; 路加福音 5:21"> 有几个法利赛人和律法教师从耶路撒冷来质问耶稣：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 马可福音 7:2; 歌罗西书 2:20–23"> “为什么你的门徒吃饭前不行洗手礼，破坏祖先的传统呢？”</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:23; 提多书 1:14; 歌罗西书 2:8"> 耶稣回答说：“为什么你们因拘守传统而违背上帝的诫命呢？</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 20:12; 利未记 20:9; 出埃及记 21:17"> 上帝说，‘要孝敬父母’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记20:12；申命记5:16。">a</a></sup>，又说，‘咒骂父母的，必被处死。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及记21:17；利未记20:9。">b</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 7:10–13; 使徒行传 5:29; 马太福音 23:16–18"> 你们却说，‘人如果宣布把供养父母的钱奉献给上帝，</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:8; 耶利米书 8:8; 马可福音 7:13"> 他就不必孝敬父母了。’你们这是用传统来废掉上帝的诫命。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 7:6; 马太福音 23:23–29; 使徒行传 28:25–27"> 你们这些伪君子，以赛亚针对你们说的预言一点没错，</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 29:13; 以西结书 33:31; 使徒行传 8:21"> <span className="pl pl-1">“‘这些人嘴上尊崇我，</span><br /><span className="pl pl-1">心却远离我，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 29:13; 马可福音 7:7; 提摩太前书 1:4"> <span className="pl pl-1">他们的教导无非是人的规条，</span><br /><span className="pl pl-1">他们敬拜我也是枉然。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书29:13。">c</a></sup><br /><span className="pl pl-1">”</span></span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶稣召集了众人，对他们说：“你们要听，也要明白。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 7:15; 马太福音 15:18–20; 雅各书 3:5–8"> 入口的东西不会使人污秽，从口中出来的才会使人污秽。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:13–14; 哥林多前书 10:32–33; 加拉太书 2:5"> 门徒上前对祂说：“你知道吗？法利赛人听见你的话很反感。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:2; 以赛亚书 60:21; 约翰福音 15:6"> 耶稣回答说：“凡不是我天父栽种的都要被连根拔起来。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; 以赛亚书 56:10; 马太福音 23:16–24"> 随便他们吧！他们是瞎眼的向导。瞎眼的给瞎眼的领路，二人都会掉进坑里。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 13:36; 马可福音 4:34; 约翰福音 16:29"> 彼得对耶稣说：“请给我们解释一下这个比喻。”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:9; 马可福音 7:18; 马可福音 9:32"> 耶稣说：“你们也还是这样糊涂吗？</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前书 6:13; 马太福音 7:19–20"> 岂不知入口的东西都是进到肚子里，然后排进厕所吗？</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 马太福音 12:34; 雅各书 3:6–10"> 可是，从口中出来的乃是发自内心，会使人污秽。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 7:21–23; 加拉太书 5:19–21; 耶利米书 17:9"> 因为从心里出来的有恶念、谋杀、通奸、淫乱、偷盗、假见证和毁谤，</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:3–4; 以弗所书 5:3–6; 哥林多前书 6:18–20"> 这些东西才使人污秽。不洗手吃饭并不会使人污秽。”</span>
</div>
</div>

## 迦南妇人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 7:24–30; 马太福音 11:21–23; 士师记 1:31"> 耶稣从那里退到泰尔和西顿境内。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:27; 马可福音 7:25–26; 马太福音 17:15"> 那地方有个迦南的妇人前来大声恳求耶稣：“主啊！大卫的后裔啊！可怜我吧！我的女儿被鬼附身，受尽折磨！”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:15; 马可福音 10:47–48; 耶利米哀歌 3:8"> 耶稣却一言不答。门徒上前求祂说：“请让她走吧！她老是在我们后面喊叫。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:5–6; 罗马书 15:8; 耶利米书 50:6–7"> 耶稣说：“我奉差遣只是来寻找以色列家迷失的羊。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 32:26; 马太福音 20:31; 马太福音 14:33"> 那妇人上前跪下，说：“主啊！求你帮帮我吧！”</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 7:27–28; 马太福音 7:6; 腓立比书 3:2"> 耶稣答道：“把儿女的食物丢给狗吃，不合适。”</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 3:8; 路加福音 16:21; 约伯记 40:4–5"> 妇人说：“主啊，不错，可是狗也吃主人饭桌上掉下来的碎渣呀！”</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 8:13; 诗篇 145:19"> 耶稣说：“妇人，你的信心真大！我答应你的要求。”就在那一刻，她女儿痊愈了。</span>
</div>
</div>

## 耶稣使四千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 4:18; 约翰福音 6:1; 马太福音 5:1"> 耶稣离开那里，来到加利利湖边，上了山，在那里坐下。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行传 5:15–16; 马太福音 14:35–36"> 大群的人把瘸腿的、瞎眼的、残疾的、哑巴及许多别的病人带来，放在祂脚前，祂就医治了他们。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 众人看见哑巴说话，残疾的复原，瘸腿的走路，瞎眼的看见，都很惊奇，就赞美以色列的上帝。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 27:33; 路加福音 12:29–30; 马太福音 9:36"> 耶稣把门徒召集过来，对他们说：“我怜悯这些人，他们跟我在一起已经三天，没有任何吃的。我不愿让他们饿着肚子回去，以免他们在路上体力不支。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 6:37; 马太福音 14:15; 马可福音 8:4–5"> 门徒说：“在这荒郊野外，我们到哪里找足够的食物给这么多人吃呢？”</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 16:9–10; 路加福音 24:41–42; 约翰福音 21:9–10"> 耶稣问：“你们有多少饼？” 门徒答道：“七个，还有几条小鱼。”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 马可福音 6:39–40; 约翰福音 6:10"> 耶稣便吩咐众人坐在地上。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 罗马书 14:6; 约翰福音 6:11"> 祂拿着那七个饼和几条鱼祝谢后，掰开，递给门徒，门徒再分给众人。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 8:19–21; 马太福音 16:9–10; 马太福音 15:33"> 大家都吃了，并且吃饱了，剩下的零碎装满了七个筐子。</span>
<span className="v" id="v38" data-v="38"> 当时吃饭的，除了妇女和小孩，共有四千男人。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 8:10; 马太福音 14:22"> 耶稣遣散众人以后，就坐船去了马加丹地区。</span>
</div>

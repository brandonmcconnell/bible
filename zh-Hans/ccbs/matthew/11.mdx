## 耶稣和施洗者约翰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 61:1–3; 使徒行传 10:38; 路加福音 8:1"> 耶稣嘱咐完十二个门徒，就离开那里，到附近的城镇传道和教导人。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 6:17; 马太福音 14:3; 马太福音 9:14"> 约翰在监狱中听到基督所做的事，就差门徒去问祂：</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:27; 玛拉基书 3:1; 申命记 18:15–18"> “你就是我们所等候的那位吗？还是我们要等别人呢？”</span>
<span className="v" id="v4" data-v="4"> 耶稣回答说：“你们回去把所见所闻告诉约翰，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 35:4–6; 以赛亚书 61:1–3; 路加福音 4:18"> 就是瞎眼的看见，瘸腿的走路，麻风病人得洁净，耳聋的听见，死人复活，穷人听到福音。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 8:14–15; 哥林多前书 2:14; 马太福音 26:31"> 凡对我笃信不疑的人有福了！”</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:6; 约翰福音 5:35; 马可福音 1:3–5"> 他们离开后，耶稣对众人谈论约翰，说：“你们从前去旷野要看什么呢？看随风摇动的芦苇吗？</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 3:4; 列王纪下 1:8; 撒迦利亚书 13:4"> 如果不是，你们出去到底想看什么？是看穿绫罗绸缎的人吗？那些穿绫罗绸缎的人在王宫里。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 马太福音 14:5; 马太福音 21:24–26"> 你们出去究竟想看什么？看先知吗？是的，我告诉你们，他不只是先知。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 3:1; 以赛亚书 40:3; 玛拉基书 4:5"> 圣经上说，‘看啊，我要差遣我的使者在你前面为你预备道路’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="玛拉基书3:1。">a</a></sup>，这里所指的就是约翰。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所书 3:8; 马太福音 3:11"> 我实在告诉你们，凡妇人所生的，没有一个兴起来比施洗者约翰大，然而天国里最微不足道的也比他大。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所书 6:11–13"> “从施洗者约翰到现在，天国在强劲地扩展着，暴力之徒一直在攻击它。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:17–18; 罗马书 3:21; 使徒行传 13:27"> 因为到约翰为止，所有的先知和律法都在预言天国的事。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 马太福音 17:10–13; 马可福音 9:11–13"> 如果你们愿意接受，约翰就是那要来的以利亚。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 马太福音 13:9; 马可福音 4:23"> 有耳朵的，都应当听。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 马太福音 12:34; 马太福音 23:36"> “我用什么来比拟这个世代的人呢？他们好像一群在街上玩耍的儿童对别的孩子说，</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 28:9–13; 以赛亚书 30:29; 耶利米书 9:17–20"> <span className="pl pl-1">“‘我们吹娶亲的乐曲，</span><br /><span className="pl pl-1">你们不跳舞；</span><br /><span className="pl pl-1">我们唱送葬的哀歌，</span><br /><span className="pl pl-1">你们不捶胸。’</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 马太福音 3:4; 约翰福音 10:20"> 约翰来了，也不吃也不喝，他们就说他被鬼附身。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> 人子来了，又吃又喝，他们就说祂是贪吃好酒之徒，与税吏和罪人为友。然而智慧通过她的作为显明为义。”</span>
</div>
</div>

## 不肯悔改的城

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米书 8:6; 提摩太后书 2:25–26"> 那时，耶稣开始责备一些城镇，因为祂在那里行了许多神迹，当地的居民仍不肯悔改。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 3:6–7; 使徒行传 12:20; 路加福音 9:10"> 祂说：“哥拉汛啊，你有祸了！伯赛大啊，你有祸了！因为如果把在你们当中所行的神迹行在泰尔和西顿，那里的人早就身披着麻衣、头蒙着灰尘悔改了。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:24; 马太福音 10:15; 希伯来书 10:26–31"> 所以我告诉你们，在审判之日，你们将比泰尔和西顿受更重的刑罚！</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 14:13–15; 约翰福音 4:46–54; 创世记 13:13"> “迦百农啊，你将被提升到天上吗？不！你将被打落到阴间。因为如果把在你那里所行的神迹行在所多玛，它肯定会存留到今天。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:15; 马太福音 11:22; 马可福音 6:11"> 所以我告诉你们，在审判之日，你们将比所多玛受更重的刑罚！”</span>
</div>
</div>

## 劳苦者得安息

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 21:16; 诗篇 8:2; 马太福音 16:17"> 那时，耶稣说：“父啊，天地的主，我颂赞你，因为你把这些事向聪明、有学问的人隐藏起来，却启示给像孩童一般的人。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:9; 以弗所书 1:11; 约伯记 33:13"> 父啊，是的，这正是你的美意。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:6–9; 马太福音 28:18; 路加福音 10:22"> 我父将一切交给了我。除了父，没有人认识子；除了子和受子启示的人，没有人认识父。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 11:29; 约翰福音 7:37; 约翰福音 6:37"> “所有劳苦困乏、背负重担的人啊，到我这里来吧！我要赐给你们安息。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 6:16; 约翰一书 2:6; 腓立比书 2:7–8"> 我心柔和谦卑，你们要负我的轭，向我学习，这样你们的心灵必得享安息。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:3; 约翰福音 16:33; 腓立比书 4:13"> 因为我的轭容易负，我的担子很轻省。”</span>
</div>

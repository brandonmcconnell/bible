## 责人先责己

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:1–2; 雅各书 4:11–12"> “不要论断人，免得你们被论断。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:13; 马可福音 4:24; 路加福音 6:38"> 因为你们怎样论断别人，也必照样被论断；你们用什么尺度衡量别人，也要用什么尺度衡量你们。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 8:7–9; 加拉太书 6:1; 路加福音 6:41–42"> 为什么你只看见你弟兄眼中的小刺，却看不见自己眼中的大梁呢？</span>
<span className="v" id="v4" data-v="4"> 既然你自己眼中有大梁，又怎么能对弟兄说‘让我除去你眼中的小刺’呢？</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:42; 诗篇 51:9–13; 马太福音 23:13–28"> 你这伪君子啊！要先除掉自己眼中的大梁，才能看得清楚，好清除弟兄眼中的小刺。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 9:7–8; 箴言 23:9; 马太福音 10:14–15"> “不要把圣物给狗，免得狗转过头来咬你们；也不要把珍珠扔在猪前，免得猪践踏珍珠。</span>
</div>
</div>

## 祈求、寻找、叩门

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:22; 约翰一书 3:22; 约翰福音 15:7"> “祈求，就会给你们；寻找，就会寻见；叩门，就会给你们开门。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 81:10; 诗篇 81:16; 路加福音 23:42–43"> 因为凡祈求的，就得到；寻找的，就寻见；叩门的，就给他开门。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:11–13"> “你们谁有儿子求饼，却给他石头呢？</span>
<span className="v" id="v10" data-v="10"> 求鱼，却给他蛇呢？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 11:11–13; 雅各书 1:17; 罗马书 8:32"> 你们虽然邪恶，尚且知道把好东西给儿女，你们的天父岂不更要把好东西赐给求祂的人吗？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:31; 罗马书 13:8–10; 加拉太书 5:13–14"> “所以，无论何事，想要别人怎样对待你们，你们就要怎样对待别人，这是律法和先知的教导。</span>
</div>
</div>

## 辨别与抉择

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:24–25; 箴言 16:25; 约翰福音 14:6"> “你们要进窄门，因为通向灭亡的门宽，路阔，进去的人也多；</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 13:23–30; 马太福音 22:14; 马太福音 16:24–25"> 但通向永生的门小，路窄，找到的人也少。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 4:1; 彼得后书 2:1–3; 马太福音 24:11"> “你们要提防假先知，他们披着羊皮到你们当中，骨子里却是凶残的狼。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:43–45; 马太福音 12:33; 雅各书 3:12"> 你们可以凭他们结的果子认出他们。荆棘怎能结出葡萄呢？蒺藜怎能长出无花果呢？</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 12:33–35; 加拉太书 5:22–24; 以弗所书 5:9"> 同样，好树结好果子，坏树结坏果子；</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 5:17; 约翰一书 3:9–10"> 好树结不出坏果子，坏树也结不出好果子。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 3:10; 希伯来书 6:8; 约翰福音 15:2–6"> 凡不结好果子的树，都要被砍下来扔进火里。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:16; 使徒行传 5:38"> 因此，你们可以凭他们结的果子认出他们。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:13; 路加福音 6:46; 雅各书 1:22"> 并不是所有称呼我‘主啊，主啊’的人都能进天国，只有遵行我天父旨意的人才能进去。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:25–27; 哥林多前书 13:1–2; 玛拉基书 3:17–18"> 在审判那天，很多人会对我说，‘主啊，主啊，我们不是奉你的名传道，奉你的名赶鬼，奉你的名行了许多神迹吗？’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 25:41; 诗篇 6:8; 路加福音 13:25"> 我会清楚地告诉他们，‘我从来不认识你们，你们这些作恶的人走开！’</span>
</div>
</div>

## 两种盖房子的人

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:47–49; 约翰福音 13:17; 哥林多前书 3:10–11"> “所以，凡听了我的这些话就去行的人，就像聪明人把房子建在磐石上。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 1:12; 诗篇 125:1–2; 彼得前书 1:7"> 遇到风吹雨打、洪水冲击，房子仍屹立不倒，因为它建基在磐石上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 8:9; 路加福音 6:49; 雅各书 2:20"> 凡听了我这些话不去行的，就像愚昧人把房子建在沙土上。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 13:19–22; 彼得后书 2:20–22; 哥林多前书 3:13"> 遇到风吹雨打、洪水冲击，房子就倒塌了，而且倒塌得很厉害。”</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 4:32; 马可福音 1:22; 约翰福音 7:46"> 耶稣讲完这番话后，众人对祂的教导感到惊奇，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 4:12–13; 路加福音 20:8; 申命记 18:18–19"> 因为祂教导他们时像个有权柄的人，不像他们的律法教师。</span>
</div>
</div>

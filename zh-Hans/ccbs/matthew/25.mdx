## 十个伴娘的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:35–36; 腓立比书 2:15–16; 马太福音 24:42–51"> “那时，天国就像十个伴娘提着灯去迎接新郎，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 24:2; 哥林多前书 10:1–5; 马太福音 13:19–23"> 其中五个是糊涂的，五个是聪明的。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:15–16; 提摩太后书 3:5; 以赛亚书 48:1–2"> 五个糊涂的只顾拿着灯，却不预备油；</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:9; 约翰一书 2:27; 约翰一书 2:20"> 那些聪明的不但拿着灯，还用器皿预备了油。</span>
<span className="v" id="v5" data-v="5" data-xref="哈巴谷书 2:3; 帖撒罗尼迦前书 5:6–8; 彼得后书 3:4–9"> 新郎迟迟未到，她们等得困倦，便打盹睡着了。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 3:10; 马太福音 24:31; 马太福音 24:44"> “到了半夜，忽然听见有人喊道，‘新郎来了！出来迎接吧！’</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 12:35; 启示录 3:19–20; 彼得后书 3:14"> 伴娘们醒来，把灯点亮。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 13:9; 路加福音 12:35; 希伯来书 4:1"> 糊涂的伴娘对聪明的伴娘说，‘请给我们一些油吧，因为我们的灯快要灭了！’</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 49:7–9; 启示录 3:17–18; 以赛亚书 55:6–7"> “聪明的伴娘回答说，‘不行，我们的油不够大家用的，不如你们自己去油店买吧！’</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:25; 马太福音 24:44; 路加福音 12:36–37"> “当糊涂的伴娘去买油的时候，新郎来了。那些预备好的伴娘跟他一同进去参加婚宴，门就关了。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 7:21–23; 希伯来书 12:16–17"> 后来，其他伴娘回来了，喊道，‘主啊！主啊！给我们开门吧！’</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 8:3; 提摩太后书 2:19; 约翰福音 10:27"> “新郎却说，‘我实在告诉你们，我不认识你们。’</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:42–44; 启示录 16:15; 帖撒罗尼迦前书 5:6"> “所以，你们要警醒，因为你们不知道我回来的日子和时辰。</span>
</div>
</div>

## 才干的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 13:34; 路加福音 19:12–27; 彼得前书 4:9–11"> “天国就像一个人即将远行，他召来自己的奴仆，把产业托付给他们，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:24; 路加福音 19:13–14; 路加福音 12:48"> 按各人的才干分别交给一个人五千银币，一个人两千银币，一个人一千银币，然后便离开了。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰三书 1:5–8; 提摩太前书 6:17–18; 提摩太后书 2:6"> 得到五千银币的立刻去做买卖，结果赚了五千。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 3:9–10; 以弗所书 5:16; 彼得前书 4:10"> 同样，得到两千银币的也赚了两千。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 1:8; 哈该书 1:2–4; 玛拉基书 1:10"> 可是得到一千银币的却挖了一个洞，把主人的钱藏在地里。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 3:12–15; 哥林多后书 5:10; 罗马书 14:7–12"> 过了很久，这些奴仆的主人回来了，要跟他们结帐。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:24; 路加福音 19:16–17; 歌罗西书 1:29"> 得到五千银币的奴仆带来了另外的五千，说，‘主人，你交给我五千银币，请看，我又赚了五千。’</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:23; 路加福音 16:10; 约翰福音 12:26"> “主人说，‘做得好！你真是个又良善又忠心的奴仆。既然你在一点事上忠心，我要把更多的事交给你。进来分享你主人的快乐吧！’</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 8:12; 哥林多后书 8:7–8; 哥林多后书 8:1–3"> “得到两千银币的奴仆也上前说，‘主人，你交给我两千银币，请看，我又赚了两千。’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 25:21; 马可福音 14:8–9; 马可福音 12:41–44"> “主人说，‘做得好！你真是个又良善又忠心的奴仆，既然你在一点事上忠心，我要把更多的事交给你。进来分享你主人的快乐吧！’</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 19:20–22; 路加福音 15:29; 玛拉基书 3:14–15"> “得到一千银币的奴仆也上前说，‘主人，我知道你为人苛刻，没有播种的地方也要收割，没有撒种的地方也要收获。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 1:6–7; 罗马书 8:15; 启示录 21:8"> 我很害怕，就去把你的钱藏在地里。请看，这是你的钱。’</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:32; 约伯记 15:5–6"> “主人说，‘你这又可恶又懒惰的奴仆！你既然知道我没有播种的地方也要收割，没有撒种的地方也要收获，</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 23:19–20; 罗马书 3:19; 犹大书 1:15"> 就应该把钱存入钱庄，等我回来可以连本带利还给我。’</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 19:24; 路加福音 10:42"> “‘所以收回他的一千银币，给那个有一万银币的奴仆。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 8:18; 马可福音 4:25; 马太福音 13:12"> 因为凡有的，还要给他更多，让他丰富有余；凡没有的，连他仅有的，也要夺去。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 8:12; 启示录 3:15–16; 马太福音 13:50"> 把这没用的奴仆扔进外面的黑暗里，他必在那里哀哭切齿。’</span>
</div>
</div>

## 末日的审判

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="启示录 1:7; 帖撒罗尼迦后书 1:7–8; 马太福音 19:28"> “当人子在祂的荣耀中与众天使降临的时候，祂要坐在祂荣耀的宝座上，</span>
<span className="v" id="v32" data-v="32" data-xref="玛拉基书 3:18; 马太福音 13:49; 哥林多后书 5:10"> 万民要聚集在祂面前。祂要把他们分开，就像牧人把绵羊和山羊分开一样。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 100:3; 约翰福音 10:26–28; 约翰福音 21:15–17"> 祂要把绵羊放在右边，山羊放在左边。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:19–20; 雅各书 2:5; 启示录 21:7"> 那时，王会对右边的人说，‘我父所赐福的人啊，来承受创世以来为你们预备的国度吧。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 3:16–19; 雅各书 2:15–16; 申命记 15:7–11"> 因为我饥饿时，你们给我吃的；我口渴时，你们给我喝的；我身在异乡时，你们接待我；</span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 1:27; 提摩太后书 1:16–18; 雅各书 5:14–15"> 我赤身露体时，你们给我穿的；我生病时，你们照顾我；我坐牢时，你们来看我。’</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 6:3; 历代志上 29:14; 彼得前书 5:5–6"> “那些义人会回答说，‘主啊！我们什么时候见你饿了就给你吃的？见你渴了就给你喝的？</span>
<span className="v" id="v38" data-v="38"> 见你身在异乡就接待你？见你赤身露体就给你穿的呢？</span>
<span className="v" id="v39" data-v="39"> 我们又什么时候见你生病或坐牢，就去看你呢？’</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 19:17; 箴言 14:31; 马太福音 10:42"> “王会回答说，‘我实在告诉你们，你们这样对待我最卑微的一个弟兄，就是对待我了。’</span>
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:4; 犹大书 1:6–7; 帖撒罗尼迦后书 1:9"> “王又对左边的人说，‘你们这些被咒诅的人，走开！到专为魔鬼及其使者预备的永远不灭的火里去吧！</span>
<span className="v" id="v42" data-v="42" data-xref="雅各书 2:15–24; 约翰福音 5:23; 马太福音 12:30"> 因为我饥饿时，你们不给我吃的；我口渴时，你们不给我喝的；</span>
<span className="v" id="v43" data-v="43"> 我身在异乡时，你们不接待我；我赤身露体时，你们不给我衣服；我生病和我坐牢时，你们不来照顾我。’</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 7:22; 路加福音 10:29; 马太福音 25:24–27"> “他们会问，‘主啊，我们什么时候见你饿了，或渴了，或身在异乡，或赤身露体，或病了，或坐牢，却没有帮助你呢？’</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 21:13; 箴言 17:5; 箴言 14:31"> “王会回答说，‘我实在告诉你们，你们没有帮助我最卑微的一个弟兄，就是没有帮助我。’</span>
<span className="v" id="v46" data-v="46" data-xref="但以理书 12:2; 约翰福音 3:36; 约翰福音 5:29"> 这些人要受永远的刑罚，但义人要得到永远的生命。”</span>
</div>
</div>

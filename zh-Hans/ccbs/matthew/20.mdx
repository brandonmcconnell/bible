## 葡萄园工人的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 13:47; 马太福音 13:24; 雅歌 8:11–12"> 耶稣接着说：“因为天国就像一个园主清早去外面雇工人到他的葡萄园做工。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 2:26; 传道书 12:1; 马太福音 22:19"> 他跟工人讲好一天的工钱是一个银币，然后派他们去葡萄园。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 5:13; 使徒行传 2:15; 马太福音 20:6–7"> “大约上午九点钟，园主出去看见还有人站在街市上无所事事，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 6:11; 彼得前书 4:2–3; 路加福音 19:7–10"> 就对他们说，‘你们也到我的葡萄园来工作吧，我会给你们合理的工钱。’</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:24–26; 使徒行传 10:3; 马可福音 15:33–34"> “他们便去了。大约正午和下午三点钟，他又出去雇用工人。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 6:12; 约翰福音 9:4; 使徒行传 17:21"> 到了下午五点钟的时候，他再次出去，看见还有人闲站在那里，就问他们，‘为什么你们一整天站在这里无所事事呢？’</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:11–12; 希伯来书 6:10; 约翰福音 9:4"> 他们回答说，‘因为没有人雇用我们。’园主说，‘你们也到我的葡萄园来吧！’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 24:15; 彼得前书 4:10; 罗马书 2:6–10"> “到了傍晚，园主对工头说，‘叫工人来领工钱吧，最晚来的先领，最先来的后领。’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 20:6–7; 路加福音 23:40–43; 马太福音 20:2"> “下午五点来的工人每人得了一个银币。</span>
<span className="v" id="v10" data-v="10"> 最早来的工人来领的时候，以为可以多得一点工钱，谁知也各得一个银币。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 2:16; 路加福音 19:7; 使徒行传 22:21–22"> “他们拿着工钱满腹牢骚地对园主说，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:5–6; 哥林多后书 11:23–28; 路加福音 12:55"> ‘那些最晚来的人只工作了一小时，而我们在烈日下辛苦了一整天，怎么会领同样的工钱呢？’</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:50; 马太福音 22:12; 罗马书 9:14–15"> “园主对他们当中的一个人说，‘朋友，我并没有欠你呀！我们不是讲好付你一个银币吗？</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:2; 路加福音 15:31; 马太福音 6:6"> 拿着你的工钱走吧。我给那后来的和你一样的工钱，是我愿意。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 9:15–24; 申命记 15:9; 约拿书 4:1–4"> 难道我不可随意使用自己的钱吗？因为我慷慨，你就嫉妒吗？’</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 19:30; 马可福音 10:31; 马太福音 22:14"> 因此，为首的将要殿后，殿后的将要为首。”</span>
</div>
</div>

## 耶稣第三次预言自己受难

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 10:32–34; 路加福音 18:31–34; 马太福音 16:13"> 在去耶路撒冷的路上，耶稣把十二个门徒带到一边，对他们说：</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:21; 使徒行传 2:23; 马太福音 27:1"> “看啊，我们现在前往耶路撒冷，人子将被交给祭司长和律法教师。他们要判祂死刑，</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 16:21; 马可福音 15:16–20; 马太福音 27:27–31"> 把祂交给外族人嘲弄、鞭打、钉在十字架上。但第三天祂必复活。”</span>
</div>
</div>

## 一个母亲的请求

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 4:21; 马可福音 10:35–45; 马太福音 8:2"> 当时，西庇太的妻子带着两个儿子上前，跪在耶稣面前，有事要求祂。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 19:28; 马可福音 10:36–37; 以斯帖记 5:3"> 耶稣问她：“你要什么呢？”<br />她说：“在你的国度，请让我这两个儿子一个坐在你右边，一个坐在你左边。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 26:42; 路加福音 22:42; 马太福音 26:39"> 耶稣回答说：“你们不知道自己在求什么。我要喝的那杯，你们能喝吗？”<br />他们说：“我们能。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="启示录 1:9; 马太福音 25:34; 使徒行传 12:2"> 耶稣对他们说：“我要喝的那杯，你们也要喝。不过谁坐在我的左右不是我来定，而是我父为谁预备的，就让谁坐。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:5; 腓立比书 2:3; 马可福音 10:41"> 其他十个门徒听见这事，都对他们兄弟二人十分恼火。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:25–27; 马太福音 20:25–28; 约翰福音 13:12–17"> 于是，耶稣把他们叫来，说：“你们知道，外族人有君王统治他们，有大臣管理他们。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 10:43; 马可福音 9:35; 马可福音 10:45"> 但你们不可这样。你们中间，谁想当首领，谁就要做大家的仆人；</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:26; 马可福音 9:33–35; 马太福音 18:4"> 谁想居首位，谁就要做大家的奴仆。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:27; 希伯来书 9:28; 提多书 2:14"> 正如人子不是来受人服侍，而是来服侍人，并且牺牲性命，作许多人的赎价。”</span>
</div>
</div>

## 治好两个瞎眼的

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:46–52; 路加福音 18:35–43; 马太福音 9:27–31"> 耶稣和祂的门徒离开耶利哥时，有一大群人跟着祂。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 10:46; 以赛亚书 42:16; 马太福音 21:9"> 有两个瞎眼的正坐在路旁，听说耶稣经过，就高声喊叫：“主啊，大卫的后裔啊，可怜我们吧！”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:13; 歌罗西书 4:2; 马太福音 7:7–8"> 众人责备他们，叫他们不要出声，他们却喊得更大声了：“主啊，大卫的后裔啊，可怜我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结书 36:37; 腓立比书 4:6; 马太福音 20:21"> 耶稣停下脚步，叫了他们来，问他们：“你们要我为你们做什么？”</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 119:18; 以弗所书 1:17–19"> 他们说：“主啊，我们想看见。”</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 4:15–16; 马太福音 9:29; 使徒行传 26:18"> 耶稣就动了慈心，摸他们的眼睛，他们立刻得见光明，并跟从了耶稣。</span>
</div>
</div>

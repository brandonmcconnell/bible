## 求神迹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:16; 马太福音 16:6; 使徒行传 4:1"> 有几个法利赛人和撒都该人来试探耶稣，要求祂显个天上的神迹给他们看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:54–56"> 耶稣回答说：“傍晚的时候，你们说，‘天上有红霞，明天必晴朗。’</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 12:56; 历代志上 12:32; 马太福音 11:5"> 早晨的时候，你们说，‘天色又红又暗，今天必有风雨。’你们懂得分辨天色，却不能分辨时代的征兆。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:29–30; 马太福音 12:39–40; 约拿书 1:17"> 一个邪恶淫乱的世代想看神迹，但除了约拿的神迹以外，再没有神迹给他们看。”于是耶稣离开他们走了。</span>
</div>
</div>

## 防备法利赛人和撒都该人的酵

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 8:13–14; 马太福音 15:39"> 门徒渡到湖对岸，忘记带饼了。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:1; 加拉太书 5:9; 马太福音 16:12"> 耶稣对他们说：“你们要小心提防法利赛人和撒都该人的酵。”</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 8:16–18; 马太福音 15:16–18; 使徒行传 10:14"> 门徒彼此议论说：“这是因为我们没有带饼吧。”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:30; 马太福音 14:31; 马太福音 8:26"> 耶稣知道他们的心思，就说：“你们的信心太小了！为什么议论没有带饼的事呢？</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 14:17–21; 约翰福音 6:9–13; 路加福音 9:13–17"> 你们还不明白吗？你们不记得那五个饼让五千人吃饱，又装满多少篮子吗？</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:34–38; 马可福音 8:17–21; 马可福音 8:5–9"> 也不记得那七个饼给四千人吃饱，又装满多少筐子吗？</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 16:6; 路加福音 12:56; 马可福音 8:21"> 我并非和你们谈论饼，你们怎么不明白呢？你们要提防法利赛人和撒都该人的酵。”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:20; 使徒行传 23:8; 马太福音 15:4–9"> 门徒这才恍然大悟，知道耶稣不是叫他们当心什么面酵，而是要提防法利赛人和撒都该人的教导。</span>
</div>
</div>

## 彼得宣告耶稣是基督

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:18–20; 马可福音 8:27–29; 但以理书 7:13"> 到了凯撒利亚·腓立比境内，耶稣问门徒：“人们说人子是谁？”</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:15; 马太福音 14:2; 玛拉基书 4:5"> 门徒回答说：“有人说是施洗者约翰，有人说是以利亚，还有人说是耶利米或其他某位先知。”</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 9:20; 马太福音 13:11; 马可福音 8:29"> 耶稣问：“那么，你们说我是谁？”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 14:33; 约翰福音 11:27; 约翰一书 4:15"> 西门·彼得回答说：“你是基督，是永活上帝的儿子！”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 6:45; 以弗所书 1:17–18; 马太福音 11:25–27"> 耶稣对他说：“约拿的儿子西门啊，你是有福的！因为这件事不是属血肉的人告诉你的，而是我天上的父启示你的。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 2:19–22; 哥林多前书 3:9–11; 以赛亚书 28:16"> 我告诉你，你是彼得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“彼得”希腊文是“磐石”的意思。">a</a></sup>，我要在这磐石上建立我的教会，阴间的势力<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“势力”希腊文是“门”。">b</a></sup>不能胜过它。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:18; 以赛亚书 22:22; 启示录 1:18"> 我要把天国的钥匙交给你。凡你在地上捆绑的，在天上也要捆绑；凡你在地上释放的，在天上也要释放。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 8:30; 路加福音 9:21; 约翰福音 1:41"> 当下，耶稣叮嘱门徒不可告诉别人祂就是基督。</span>
</div>
</div>

## 耶稣预言自己的受害和复活

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 24:6–7; 马太福音 20:17–19; 马太福音 17:22–23"> 从此以后，耶稣开始清楚地指示门徒，祂必须去耶路撒冷，受长老、祭司长和律法教师许多的迫害，并且被杀害，但第三天必复活。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 8:32; 约翰福音 13:6–8; 马太福音 16:16–17"> 彼得把耶稣拉到一边，劝阻祂说：“主啊，千万不可！这件事绝不会发生在你身上！”</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 8:5–8; 歌罗西书 3:2; 腓立比书 3:19"> 耶稣转过身来对彼得说：“撒旦，退到我后面去！你是我的绊脚石，因为你不考虑上帝的意思，只考虑人的意思。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:38; 路加福音 14:27; 彼得前书 4:1–2"> 于是耶稣对门徒说：“人若想跟从我，就当舍己，背起他的十字架跟从我。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 马可福音 8:35; 启示录 12:11"> 因为想救自己生命的，必失去生命；但为了我失去生命的，必得到生命。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 8:36–37; 约伯记 27:8; 路加福音 9:25"> 人就算赚得全世界，却丧失自己的生命，又有什么益处呢？人还能拿什么换回自己的生命呢？</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 诗篇 62:12; 罗马书 2:6"> “因为人子要在祂父的荣耀中与众天使一起降临，那时，祂将按照各人的行为报应各人。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:27; 马可福音 9:1; 约翰福音 8:52"> 我实在告诉你们，有些站在这里的人会在有生之年看见人子降临在祂的国度里。”</span>
</div>
</div>

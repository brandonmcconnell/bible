## 智者来朝拜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="弥迦书 5:2; 约翰福音 7:42; 路加福音 2:4–7"> 希律王执政期间，耶稣降生在犹太的伯利恒城。<br />当时有几位智者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“智者”或译“占星家”下同7节和16节。">a</a></sup>从东方来到耶路撒冷，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 24:17; 耶利米书 23:5; 启示录 22:16"> 问道：“那生来做犹太人之王的在哪里呢？我们在东方看见祂的星，特来朝拜祂。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 17:6–7; 约翰福音 11:47–48; 马太福音 23:37"> 希律王听后，心里不安，全城的人都感到不安。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 21:23; 马太福音 7:29; 使徒行传 6:12"> 希律王就召来祭司长和律法教师，问他们：“基督降生在哪里呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 7:42; 路得记 1:1; 撒母耳记上 16:1"> 他们回答说：“在犹太的伯利恒，因为先知这样记载，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 34:23–25; 弥迦书 5:2; 以赛亚书 9:6–7"> <span className="pl pl-1">“‘犹大地区的伯利恒啊！</span><br /><span className="pl pl-1">你在犹大各城中并不是最小的，</span><br /><span className="pl pl-1">因为有一位君王要从你那里出来，</span><br /><span className="pl pl-1">牧养我的以色列子民。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="弥迦书5:2、4。">b</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 1:10; 撒母耳记上 18:21; 诗篇 55:21"> 于是，希律暗中召见那几位智者，仔细查问那星出现的准确时间，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:19–20; 耶利米书 41:5–7; 路加福音 20:20–21"> 然后派他们去伯利恒，并吩咐道：“你们去仔细寻访那个小孩，找到了，就回来报信，我也好去朝拜祂。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 2:2; 箴言 8:17; 诗篇 25:12"> 他们听了王的吩咐，就去了。忽然，那颗曾在东方出现的星在前引领他们，一直来到小孩所在的地方，然后停在上空。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:3; 路加福音 2:20; 路加福音 2:10"> 他们看见那颗星，喜出望外。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 60:6; 诗篇 72:10; 路加福音 2:16"> 他们进了屋子，看见孩子和祂母亲玛丽亚，就俯伏在地上拜祂，并打开盛宝物的盒子献上黄金、乳香和没药作礼物。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 2:22; 马太福音 2:19; 马太福音 2:13"> 他们在梦中得到指示，不可回希律那里，便改道返回了家乡。</span>
</div>
</div>

## 逃往埃及

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:7; 使徒行传 5:19; 马太福音 1:20"> 他们离开之后，主的天使在梦中向约瑟显现，说：“起来，带着小孩子和祂母亲逃往埃及，住在那里等候我的通知，因为希律要寻找这孩子，杀害祂。”</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 2:20–21; 使徒行传 26:21; 马太福音 1:24"> 于是，约瑟起来带着孩子和祂母亲连夜逃往埃及，</span>
<span className="v" id="v15" data-v="15" data-xref="何西阿书 11:1; 出埃及记 4:22; 民数记 24:8"> 并在那里一直住到希律死了。这就应验了主借着先知所说的话：“我把儿子从埃及召出来。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="何西阿书11:1。">c</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 28:15; 士师记 16:10"> 希律见自己被智者愚弄，大为恼怒，便照着智者所说的时间推算，下令把伯利恒及附近两岁以下的男孩杀光。</span>
<span className="v" id="v17" data-v="17"> 这正应验了耶利米先知的话：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:15; 耶利米书 9:17–21; 耶利米书 4:31"> <span className="pl pl-1">“在拉玛有痛哭哀号的声音，</span><br /><span className="pl pl-1">是拉结在为儿女哀痛，</span><br /><span className="pl pl-1">不肯接受安慰，</span><br /><span className="pl pl-1">因为他们都死了！”</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="耶利米书31:15。">d</a></sup></span>
</div>
</div>

## 定居拿撒勒

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:20; 但以理书 8:25; 马太福音 2:12–13"> 希律死后，主的天使在梦中向在埃及的约瑟显现，说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:19; 列王纪上 12:1–3; 马太福音 2:13"> “起来，带着孩子和祂母亲回以色列去吧！因为要杀害孩子的人已经死了。”</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:8; 创世记 6:22"> 约瑟就起来，带着孩子和祂母亲返回以色列。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 48:17–18; 路加福音 2:39; 约翰福音 7:52"> 但约瑟听说亚基劳继承他父亲希律的王位统治犹太，就不敢回那里。这时，他在梦中得到主的指示，便前往加利利地区，</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 13:5; 约翰福音 1:45–46; 马可福音 1:24"> 定居在拿撒勒镇。这应验了先知的话：“祂将被称为拿撒勒人。”</span>
</div>
</div>

## 施洗者约翰之死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马可福音 8:15; 路加福音 9:7–9"> 那时，分封王希律听见耶稣的名声，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 16:14; 约翰福音 10:41; 马可福音 8:28"> 就对臣仆说：“这个人是施洗者约翰！他从死里复活了，所以能行这些神迹。”</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 6:17; 路加福音 3:19–20; 马太福音 4:12"> 原来希律为他兄弟腓力的妻子希罗底的缘故，拘捕了约翰，把他捆绑起来关在监牢。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:21; 利未记 18:16; 马可福音 6:18"> 因为约翰曾多次对他说：“你娶这个妇人不合法。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:26; 马太福音 11:9; 马可福音 6:19–20"> 他想杀掉约翰，但怕触怒百姓，因为他们都认为约翰是先知。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 6:21–23; 创世记 40:20; 何西阿书 1:5–6"> 在希律的生日那天，希罗底的女儿在众人面前跳舞。希律非常高兴，</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 5:3; 以斯帖记 5:6; 以斯帖记 7:2"> 就起誓答应她无论要什么都可以。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 6:24; 箴言 29:10; 箴言 1:16"> 她受了母亲的指使，说：“请把施洗者约翰的头放在盘子里送给我。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:12–16; 撒母耳记上 14:28; 马可福音 6:26"> 希律感到为难，但既然在众宾客面前起了誓，只好下令给她。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 17:12; 马太福音 21:35–36; 路加福音 9:9"> 他派人进监牢砍了约翰的头，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:6; 创世记 49:7; 以西结书 16:3–4"> 放在盘子里送给女孩，她又转送给她母亲。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:2; 马太福音 27:58–61"> 约翰的门徒把尸体领回安葬后，就去告诉耶稣。</span>
</div>
</div>

## 耶稣使五千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 马太福音 14:1–2; 马可福音 6:30–44"> 耶稣听见这个消息，就独自坐船退到一处荒僻的地方。众人得知后，就从各城步行来跟随祂。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:15; 马太福音 9:36; 希伯来书 2:17"> 耶稣上了岸，看见一大群人，心里怜悯他们，就治好了他们当中的病人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:23; 马可福音 8:3; 马可福音 6:35–36"> 黄昏时，门徒过来对耶稣说：“这里是荒郊野外，天又晚了，请遣散众人，好让他们到村庄去自己买些吃的。”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 4:42–44; 哥林多后书 8:2–3; 传道书 11:2"> 耶稣回答说：“他们不用离开，你们给他们吃的吧。”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:33–34; 马可福音 6:37–38; 路加福音 9:13"> 门徒答道：“我们这里只有五个饼和两条鱼。”</span>
<span className="v" id="v18" data-v="18"> 耶稣说：“拿来给我。”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 8:6–7; 路加福音 24:30; 撒母耳记上 9:13"> 于是，祂叫众人坐在草地上，然后拿起那五个饼和两条鱼，举目望着天祝谢后，掰开饼递给门徒，让他们分给众人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:12; 马可福音 6:42–44; 马太福音 16:8–10"> 大家都吃饱了，把剩下的零碎收拾起来，装满了十二个篮子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 4:19; 哥林多后书 9:8–11; 使徒行传 4:4"> 当时吃饭的，除了妇女和小孩，约有五千男人。</span>
</div>
</div>

## 耶稣在水上行走

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45–51; 约翰福音 6:15–21; 马太福音 15:39"> 随后，耶稣催门徒上船，叫他们先渡到湖对岸，祂则遣散众人。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 马可福音 6:46; 马太福音 26:36"> 等众人都离开了，祂就独自上山去祷告，在那里一直待到晚上。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:18; 马可福音 6:48; 马太福音 8:24"> 那时，门徒的船离岸已远，遇到逆风，船身被波浪撞击得摇摆不定。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 9:8; 约翰福音 6:19; 马可福音 6:48"> 天将破晓的时候，耶稣从水面上朝门徒走去。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:49–50; 启示录 1:17; 路加福音 1:11–12"> 门徒看见祂在湖面上走，都吓坏了，说：“是幽灵！”他们害怕得又喊又叫。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 23:11; 启示录 1:17–18; 约翰福音 16:33"> 耶稣立刻对他们说：“放心吧！是我，不要怕。”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:68; 罗马书 12:3; 马太福音 26:33–35"> 彼得说：“主啊！如果真的是你，就叫我从水面上走到你那里。”</span>
<span className="v" id="v29" data-v="29" data-xref="腓立比书 4:13; 马可福音 9:23; 使徒行传 3:16"> 耶稣说：“你来吧！” 于是，彼得就从船上下去，走在湖面上，要去耶稣那里。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太后书 4:16–17; 马可福音 14:38"> 他看到风浪很大，就害怕起来，身体开始往下沉，便大喊：“主啊，救我！”</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:6–8; 诗篇 138:7; 创世记 22:14"> 耶稣马上伸手拉住他，说：“你信心太小了！为什么怀疑呢？”</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 107:29–30; 马可福音 4:41; 约翰福音 6:21"> 他们上了船，风浪就平静了。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:27; 诗篇 2:7; 罗马书 1:4"> 船上的人都敬拜祂，说：“你真是上帝的儿子。”</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 6:53–56; 路加福音 5:1; 约翰福音 6:24–25"> 他们渡到湖对岸，来到革尼撒勒。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:24–25; 马可福音 6:55; 马可福音 1:28–34"> 当地的人认出是耶稣，就派人去把附近所有的病人都带到祂面前，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 马可福音 3:10; 出埃及记 28:33–43"> 求耶稣让他们只摸一摸祂衣服的穗子，所有摸过的病人都好了。</span>
</div>
</div>

## 耶稣复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:1–8; 约翰福音 20:1–10; 马太福音 27:56"> 安息日刚过，周日黎明时分，抹大拉的玛丽亚和另一位玛丽亚一同到坟墓去察看。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:26; 约翰福音 20:12–13; 马可福音 16:3–5"> 突然，大地剧烈地震动，主的天使从天而降，把墓口的石头滚开，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 9:3; 使徒行传 1:10; 马可福音 16:5"> 他的容貌如闪电，衣裳洁白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; 但以理书 10:7; 马太福音 27:65–66"> 看守墓穴的卫兵吓得浑身发抖，像死人一样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="启示录 1:17–18; 希伯来书 1:14; 以赛亚书 41:10"> 天使对那两个女人说：“不要怕，我知道你们是在找那位被钉十字架的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:6; 马太福音 12:40; 路加福音 24:6–8"> 祂不在这里，正如祂所说的，祂已经复活了。你们来看，这是安放祂的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:32; 路加福音 24:22–24; 马太福音 28:10"> 现在你们快去告诉祂的门徒，祂已经从死里复活，要先你们一步去加利利，你们将在那里见到祂。记住，我已经告诉你们了。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 2:11; 马可福音 16:8; 路加福音 24:36–41"> 她们听了又害怕又欣喜，连忙离开坟墓，跑去告诉门徒。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 28:17; 约翰福音 20:14–17; 马太福音 14:33"> 忽然，耶稣迎面而来，对她们说：“愿你们平安！”她们就上前抱住祂的脚敬拜祂。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:29; 约翰福音 20:17; 马太福音 28:7"> 耶稣对她们说：“不要害怕。你们去告诉我的弟兄，叫他们到加利利去，他们将在那里见到我。”</span>
</div>
</div>

## 行贿造谣

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:65–66; 马太福音 28:4"> 她们还在赶路的时候，有些守墓的卫兵已经进城把整件事告诉祭司长。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:3–4; 使徒行传 4:5–22; 马太福音 27:1–2"> 祭司长和长老聚集商议，决定用重金买通守墓的卫兵，又吩咐他们：</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64"> “你们就说，‘夜里我们熟睡的时候，耶稣的门徒来把祂的尸体偷走了。’</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:2; 使徒行传 12:19"> 如果这件事传到总督那里，我们会跟他解释，保你们无事。”</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 6:10; 马太福音 27:8; 马太福音 26:15"> 守卫收下钱，便依照吩咐去做。于是，这说法在犹太人中一直流传到今天。</span>
</div>
</div>

## 大使命

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:32; 马太福音 28:10; 马太福音 28:7"> 十一个门徒赶到加利利，到了耶稣和他们约定的山上，</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 45:11; 诗篇 2:12; 约翰福音 5:23"> 看到耶稣就敬拜祂，但有些人仍然心存疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:35; 彼得前书 3:22; 马太福音 11:27"> 耶稣上前对门徒说：<br />“天上地下所有的权柄都交给我了。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 16:15–16; 使徒行传 2:38–39; 使徒行传 1:8"> 所以，你们要去使万民做我的门徒，奉父、子、圣灵的名给他们施洗，</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 41:10; 约书亚记 1:5; 使徒行传 18:9–10"> 教导他们遵守我吩咐你们的一切。记住，我必常与你们同在，一直到世界的末了。”</span>
</div>
</div>

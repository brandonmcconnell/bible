<div className="bp">

## 世界末日的预兆

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 13:3–4; 使徒行传 1:7; 帖撒罗尼迦前书 5:1–11"> 耶稣正坐在橄榄山上，门徒私下来问祂：“请告诉我们，这事什么时候会发生？你再来和世界末日的时候会有什么预兆？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 耶利米书 29:8; 帖撒罗尼迦后书 2:3"> 耶稣回答说：“你们要小心，免得被人迷惑。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 24:11; 马太福音 24:24; 耶利米书 14:14"> 因为将来会有许多人冒我的名来，说，‘我是基督’，欺骗许多人。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:7–8; 路加福音 21:9; 彼得前书 3:14–15"> 你们听见战争爆发、战讯频传时，切不可惊慌，因为这些事必然发生，只是末日还没有到。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 启示录 6:8; 以赛亚书 19:2"> 民族将攻打民族，国家将攻打国家，各处将有饥荒和地震。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:3; 彼得前书 4:17–18; 申命记 28:59"> 这些只是灾难<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“灾难”希腊文是“生产之痛”。">a</a></sup>的开始。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 16:2; 约翰福音 15:19–20; 路加福音 21:16–17"> “那时，你们将遭人迫害、杀害，并因我的名而被万民憎恨。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 7:5–6; 路加福音 21:16; 马太福音 11:6"> 那时，许多人会放弃信仰，互相出卖，彼此憎恨。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:24; 马太福音 7:15; 马太福音 24:5"> 许多假先知也会出现，迷惑许多人。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 2:4–5; 雅各书 4:1–4; 启示录 3:15"> 由于罪恶泛滥，许多人的爱心逐渐冷淡。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 10:22; 马可福音 13:13; 启示录 2:10"> 但坚忍到底的必定得救。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 14:6; 罗马书 10:18; 罗马书 16:25–26"> 这天国的福音将传遍天下，让万民都听见，然后末日才会来临。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 9:27; 但以理书 12:11; 马可福音 13:14"> “当你们看见但以理先知所说的‘那带来毁灭的可憎者’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="但以理书9:27；11:31；12:11。">b</a></sup>站立在圣地的时候（读者须会意），</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:15–17; 路加福音 21:21–22; 希伯来书 11:7"> 犹太地区的人要逃到山上去，</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 马可福音 13:15–16; 马太福音 10:27"> 在屋顶上的人不要下来拿屋内的东西，</span>
<span className="v" id="v18" data-v="18"> 在田间的人也不要回家取外衣。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命记 28:53–56; 路加福音 21:23"> 那时，孕妇和哺育婴儿的母亲们可就遭殃了！</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:29; 使徒行传 1:12"> 你们要祈求上帝，不要让你们逃难的时候遇上冬天或安息日。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 12:1; 约珥书 2:2; 玛拉基书 4:1"> 因为那时世上将有空前绝后的大灾难。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 13:20; 提摩太后书 2:10; 马太福音 24:31"> 如果不缩短灾期，恐怕没有人能活命。但为了上帝的选民，灾期必被缩短。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命记 13:1–3"> “那时，如果有人对你们说，‘看啊，基督在这里！’或说，‘基督在那里！’你们不要相信。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 2:9–11; 马可福音 13:22; 启示录 13:13–14"> 因为假基督和假先知将出现，行很大的神迹奇事来迷惑人，如果可能，甚至要迷惑上帝的选民。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:1; 路加福音 21:13; 以赛亚书 48:5–6"> 你们要记住，我已经预先告诉你们了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以赛亚书 40:3; 马太福音 3:1"> “因此，如果有人对你们说，‘看啊，基督在旷野！’你们不要出去；或者说，‘看啊，基督在内室！’你们也不要相信。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亚书 9:14; 约伯记 37:3"> 因为人子降临时的情形就像闪电从东方发出一直照到西方。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 约伯记 39:27–30; 申命记 28:49"> 尸体在哪里，秃鹰就会聚集在哪里。</span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="阿摩司书 8:9; 约珥书 3:15; 以赛亚书 13:10"> “当灾难的日子一过，<br /><span className="pl pl-1">“‘太阳昏暗，</span><br /><span className="pl pl-1">月亮无光，</span><br /><span className="pl pl-1">星宿陨落，</span><br /><span className="pl pl-1">天体震动。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书13:10；34:4。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 1:7; 但以理书 7:13; 路加福音 21:27"> “那时，天上会出现人子降临的预兆，地上的万族都要哀哭，他们将看见人子带着能力和极大的荣耀驾着天上的云降临。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 4:16; 马可福音 13:27; 以赛亚书 27:13"> 在响亮的号声中，祂将差遣天使从四面八方、天涯海角招聚祂拣选的人。</span>
</div>
</div>

## 无花果树的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:28–29; 路加福音 21:29–30"> “你们可以从无花果树学个道理。当无花果树发芽长叶的时候，你们就知道夏天快来了。</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 5:9; 希伯来书 10:37; 以西结书 7:2–14"> 同样，当你们看见这一切事发生时，就知道人子快来了，就在门口。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 13:30–31; 路加福音 21:32–33; 马太福音 16:28"> 我实在告诉你们，这个世代还没有过去，这一切都要发生。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 40:8; 彼得前书 1:25; 民数记 23:19"> 天地都要消逝，但我的话永不消逝。</span>
</div>
</div>

## 警醒准备

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 13:32; 使徒行传 1:7; 马太福音 24:44"> “但没有人知道那日子和时辰何时来到，连天上的天使也不知道，人子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“人子”希腊文是“子”。">d</a></sup>也不知道，只有天父知道。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 创世记 6:1–7; 彼得后书 2:5"> 人子降临时的情形将像挪亚的时代。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 罗马书 13:13–14; 路加福音 14:18–20"> 洪水来临之前的日子里，人们吃吃喝喝，男婚女嫁，一直到挪亚进方舟那天；</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 3:20; 马太福音 24:37; 使徒行传 13:41"> 他们懵然不知，直到洪水来把他们全冲走了。人子降临时的情形也是这样。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得后书 2:7–9; 彼得后书 2:5"> 那时，两个人在田里，一个将被接去，一个将被撇下；</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 11:5; 以赛亚书 47:2; 路加福音 17:35"> 两个女人推磨，一个将被接去，一个将被撇下。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒罗尼迦前书 5:6; 马太福音 25:13"> 所以，你们要警醒，因为你们不知道你们的主会在哪一天来。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 马太福音 24:44; 帖撒罗尼迦前书 5:2–6"> 你们都知道，家主若知道贼会在夜里几点来，就必警醒，不让贼入屋偷窃。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 25:10; 马太福音 24:42; 马太福音 25:13"> 同样，你们也要做好准备，因为在你们意想不到的时候，人子就来了。</span>
</div>
</div>

## 两种奴仆

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 25:21; 马太福音 25:23; 哥林多前书 4:1–2"> “那么，谁是那个受主人委托管理家中大小仆役、按时分粮食给他们、又忠心又精明的奴仆呢？</span>
<span className="v" id="v46" data-v="46" data-xref="启示录 16:15; 路加福音 12:43; 路加福音 12:37"> 主人回家时，看见他尽忠职守，他就有福了。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 25:23; 马太福音 25:21; 路加福音 12:37"> 我实在告诉你们，主人一定会把所有产业都交给他管理。</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 18:32; 以赛亚书 32:6; 路加福音 12:45"> 但如果奴仆邪恶，以为主人不会那么快回来，</span>
<span className="v" id="v49" data-v="49" data-xref="启示录 17:6; 启示录 16:6; 弥迦书 3:5"> 就动手殴打同伴，跟醉汉一起吃喝玩乐，</span>
<span className="v" id="v50" data-v="50" data-xref="帖撒罗尼迦前书 5:2–3; 启示录 3:3; 马太福音 24:42–44"> 主人会在他想不到的日子、不知道的时辰回来，</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 8:12; 马太福音 22:13; 路加福音 12:46"> 严厉地惩罚<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“严厉地惩罚”或作“腰斩”。">e</a></sup>他，判他和伪君子同样的罪。他必在那里哀哭切齿。</span>
</div>

## 差遣使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 马可福音 3:13–15; 马可福音 6:7–13"> 耶稣叫了十二位门徒来，赐他们权柄，能赶出污鬼、医治各样的疾病。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:21; 使徒行传 1:13; 路加福音 5:10"> 以下是这十二位使徒的名字：<br />首先是西门，又名彼得，还有彼得的兄弟安得烈、西庇太的儿子雅各、雅各的兄弟约翰、</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:18; 使徒行传 1:13; 马可福音 2:14"> 腓力、巴多罗买、多马、税吏马太、亚勒腓的儿子雅各、达太、</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:14; 马太福音 26:47; 约翰福音 13:2"> 激进党人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“激进党人”指当时激进的犹太民族主义者，常以行动反抗统治他们的罗马政府。">a</a></sup>西门和出卖耶稣的加略人犹大。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 4:9; 使徒行传 22:21–23; 列王纪下 17:24–41"> 耶稣差遣这十二个人出去，嘱咐他们：“外族人的地方不要去，撒玛利亚人的城镇也不要进，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:6; 以西结书 34:6; 以赛亚书 53:6"> 要到以色列人当中寻找迷失的羊。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 28:31; 马太福音 3:2; 路加福音 9:60"> “你们要边走边传，‘天国临近了！’</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:6; 路加福音 10:9; 使徒行传 4:30"> 要医治病人，叫死人复活，使麻风病人得洁净，赶走邪灵。你们白白地得来，也应当白白地给人。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> 出门时钱袋里不要带金、银、铜币，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前书 5:17–18; 哥林多前书 9:4–14"> 不要带行李、备用的衣服、鞋或手杖，因为工人理应得到供应。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 约伯记 31:32; 士师记 19:16–21"> 你们无论到哪座城、哪个村，要在那里寻找配接待你们的人，然后住在他家，一直住到离开。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 25:6; 路加福音 10:5–6; 使徒行传 10:36"> 你们进他家的时候，要祝他家平安。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 诗篇 35:13; 哥林多后书 2:16"> 如果那家配得平安，你们的平安必临到那家；如果那家不配，平安仍归给你们。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行传 18:6; 尼希米记 5:13"> 如果有人不接待你们，不听你们传的道，你们离开那家或那城时，要跺掉脚上的尘土。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:6; 约翰一书 4:17; 约翰福音 15:22–24"> 我实在告诉你们，在审判之日，那城将比所多玛和蛾摩拉受更重的刑罚！</span>
</div>
</div>

## 将临的迫害

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比书 2:15; 哥林多前书 14:20"> “听着，我差你们出去，就好像把羊送入狼群。所以，你们要像蛇一样机灵，像鸽子一样驯良。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 13:9; 马太福音 23:34; 使徒行传 26:11"> “你们要小心谨慎，因为你们将被送上法庭，并在会堂里被鞭打。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:25–27; 马太福音 8:4; 诗篇 2:1–6"> 你们要因我的缘故被带到官长和君王面前，在他们和外族人面前为我做见证。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 4:12; 马可福音 13:11–13; 提摩太后书 4:17"> 当你们被押去受审时，不要顾虑如何应对，或说什么话，那时必赐给你们当说的话。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行传 6:10; 路加福音 12:12"> 因为那时候说话的不是你们自己，而是你们父的灵借着你们说话。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 弥迦书 7:5–6; 马可福音 13:12–13"> “那时，人将把自己的弟兄置于死地，父亲将把儿子置于死地，儿女将反叛父母，置他们于死地。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:13; 雅各书 1:12; 启示录 2:10"> 你们将为我的名被众人憎恨，但坚忍到底的必定得救。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:28; 使徒行传 8:1; 马可福音 13:26"> 你们如果在一个地方遭迫害，就逃到另一个地方。我实在告诉你们，没等你们走遍以色列的城镇，人子就来了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:20; 路加福音 6:40; 约翰福音 13:16"> “学生不能高过老师，奴仆也不能大过主人。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 马太福音 12:24; 马太福音 9:34"> 学生顶多和老师一样，奴仆顶多和主人一样。连家主都被骂成是别西卜<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“别西卜”是鬼王的名字。">b</a></sup>，更何况祂的家人呢？</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 马可福音 4:22; 耶利米书 1:8"> “不要害怕那些迫害你们的人。因为掩盖的事终会暴露出来，隐藏的秘密终会被人知道。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 5:20; 约翰福音 16:13; 约翰福音 16:1"> 你们要把我暗中告诉你们的公布于众，你们要把听到的耳语在屋顶上传扬。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以赛亚书 8:12–13; 启示录 2:10"> 那些只能杀害身体，不能毁灭灵魂的，不用怕他们。但要畏惧有权将身体和灵魂一同毁灭在地狱里的上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 诗篇 104:27–30"> 两只麻雀不是只卖一个铜钱吗？然而没有天父的许可，一只也不会掉在地上。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳记上 14:45; 使徒行传 27:34"> 就连你们的头发都被数过了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 诗篇 8:5; 马太福音 6:26"> 所以不要害怕，你们比许多麻雀要贵重！</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="启示录 3:5; 罗马书 10:9–10; 路加福音 12:8–9"> “凡在人面前承认我的，我在天父面前也必承认他；</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太后书 2:12; 路加福音 9:26; 路加福音 12:9"> 凡在人面前否认我的，我在天父面前也必否认他。</span>
</div>
</div>

## 跟从主的代价

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行传 14:4; 使徒行传 13:45–50"> “不要以为我来了会让天下太平，我不是带来和平，而是带来刀剑。</span>
<span className="v" id="v35" data-v="35" data-xref="弥迦书 7:5–6; 马太福音 10:21; 路加福音 21:16"> 因为我来是要叫儿子与父亲作对，女儿与母亲作对，媳妇与婆婆作对，</span>
<span className="v" id="v36" data-v="36" data-xref="弥迦书 7:6; 耶利米书 12:6; 诗篇 41:9"> 家人之间反目成仇。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="弥迦书7:6。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 马太福音 22:37; 腓立比书 3:7–9"> “爱父母过于爱我的人不配做我的门徒；爱儿女过于爱我的人不配做我的门徒；</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 马可福音 8:34; 马太福音 16:24"> 不背起自己的十字架跟从我的，不配做我的门徒。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 12:25; 马可福音 8:35–36; 路加福音 17:33"> 保全自己生命的，必失去生命；但为了我失去生命的，必得到生命。</span>
</div>
</div>

## 得赏赐

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> “谁接待你们，就是接待我；谁接待我，就是接待差我来的那位。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰三书 1:5–8; 希伯来书 6:10; 列王纪下 4:16–17"> 因为某人是先知而接待他的，必得到和先知一样的赏赐；因为某人是义人而接待他的，必得到和义人一样的赏赐。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:10; 马太福音 25:40; 马可福音 9:41–42"> 人若接待我门徒中最卑微的人，并因为他是我的门徒而给他一杯凉水喝，我实在告诉你们，那人必得到赏赐。”</span>
</div>

## 安息日的问题

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 路加福音 6:1–5"> 安息日的时候，耶稣经过一片麦田。祂的门徒饿了，便掐些麦穗吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:10; 约翰福音 7:21–24; 路加福音 14:3"> 法利赛人看见后，对耶稣说：“你看，你的门徒做了安息日不准做的事！”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 路加福音 6:3; 马可福音 2:25–26"> 耶稣回答说：“你们没有读过大卫的事迹吗？当时他和随从饿了，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9; 出埃及记 25:30; 利未记 8:31"> 他进入上帝的殿，他们吃了献给上帝的供饼。这饼只有祭司才可以吃，大卫和随从是不准吃的。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:9–10; 约翰福音 7:22–23; 尼希米记 13:17"> 此外律法书又记载，在安息日，祭司在圣殿里干犯安息日的规条也不算有罪。你们没有读过吗？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:41–42; 历代志下 6:18; 彼得前书 2:4–5"> 我告诉你们，这里有一位比圣殿更伟大，</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 6:6; 马太福音 9:13; 弥迦书 6:6–8"> 如果你们明白‘我要的是怜悯，而非祭物’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="何西阿书6:6。">a</a></sup>这句经文的意义，就不会冤枉无辜了。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 2:28; 路加福音 6:5; 约翰福音 5:17–23"> 因为人子是安息日的主。”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:1–6; 路加福音 6:6–11"> 耶稣离开那里，走进犹太人的会堂，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 约翰福音 9:16; 约翰福音 8:6"> 里面有个人，一只手是萎缩的。法利赛人企图控告耶稣，就问祂：“在安息日可以医病吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶稣回答说：“你们如果有一只羊在安息日掉进坑里，难道不把它拉上来吗？</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:26; 路加福音 6:9; 马可福音 3:4"> 人比羊要贵重多了！所以在安息日行善合情合理。”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行传 3:7–8"> 然后，耶稣对那人说：“把手伸出来！”那人一伸手，手就复原了，跟另一只手一样健康。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:53; 约翰福音 10:39; 马可福音 3:6"> 法利赛人却走了出去，策划怎样除掉耶稣。</span>
</div>
</div>

## 上帝的仆人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="马可福音 3:7–12; 马太福音 10:23; 马太福音 19:2"> 耶稣知道了，就离开那里。很多人跟随祂，耶稣治好了所有患病的人，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 8:4; 马太福音 9:30; 马太福音 17:9"> 叮嘱他们不要泄露祂的身份。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1–4; 以赛亚书 42:9; 马太福音 13:35"> 这是要应验以赛亚先知的话：</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 42:1; 路加福音 4:18; 使徒行传 10:38"> <span className="pl pl-1">“看啊！我所拣选、</span><br /><span className="pl pl-1">所眷爱、所喜悦的仆人，</span><br /><span className="pl pl-1">我要将我的灵赐给祂，</span><br /><span className="pl pl-1">祂要向万邦宣扬正义。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 11:29; 约翰福音 18:36–38; 提摩太后书 2:24–25"> <span className="pl pl-1">祂不争竞，不喧嚷，</span><br /><span className="pl pl-1">街上也听不见祂的声音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 42:3–4; 以西结书 34:16; 以赛亚书 61:1–3"> <span className="pl pl-1">压伤的芦苇，祂不折断；</span><br /><span className="pl pl-1">将残的灯火，祂不吹灭；</span><br /><span className="pl pl-1">祂终必使正义得胜。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:10; 罗马书 15:12–13; 以赛亚书 42:4"> <span className="pl pl-1">普世都要仰望祂的圣名。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书42:1‑4。">b</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 马可福音 7:35–37; 以赛亚书 29:18"> 有人带一个被鬼附身、又瞎又哑的人来见耶稣，耶稣便医治他，使他能说能看。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:27; 约翰福音 4:29; 马太福音 22:42–43"> 众人都很惊奇，就说：“这人会不会是大卫的那个后裔？”</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 3:22; 马太福音 9:34; 路加福音 11:15"> 法利赛人听见后却说：“祂不过是靠鬼王别西卜赶鬼罢了。”</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:15; 耶利米书 17:10; 马太福音 9:4"> 耶稣知道他们的心思，就说：“一个国内部自相纷争，必然灭亡；一座城、一个家内部自相纷争，必无法坚立。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 1:13; 启示录 20:2–3; 约翰一书 5:19"> 若撒旦驱逐撒旦，就是自相纷争，它的国怎能维持呢？</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:13–16; 马可福音 9:38–39; 路加福音 9:49–50"> 我若是靠别西卜赶鬼，你们的子弟又是靠谁赶鬼呢？因此，他们要审判你们。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理书 7:14; 马太福音 6:33"> 但我若是靠上帝的灵赶鬼，就是上帝的国已降临在你们中间了。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 49:24; 马可福音 3:27; 路加福音 11:21–22"> “人如何进入壮汉家里抢夺他的财物呢？除非先把那壮汉捆绑起来，才能抢劫他的家。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:40; 路加福音 11:23; 约书亚记 24:15"> “谁不与我为友，就是与我为敌；谁不和我一起收聚，就是在拆散。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 马可福音 3:28–30; 希伯来书 10:29"> 所以我告诉你们，一切罪和亵渎的话都可以得到赦免，但亵渎圣灵的罪必得不到赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 3:29; 希伯来书 10:26–29; 希伯来书 6:4–6"> 说话得罪人子的，还可以得到赦免；但说话冒犯圣灵的，今生永世都得不到赦免。</span>
</div>
</div>

## 树与果

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 马太福音 7:16–20; 雅各书 4:8"> “好树结好果子，坏树结坏果子，看果子就能知道树的好坏。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 马太福音 15:18; 以弗所书 4:29"> 你们这些毒蛇的后代！你们既然邪恶，又怎能讲出好话呢？因为心里充满的，口里自然会说出来。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌罗西书 4:6; 箴言 15:28"> 善人心存良善，就从他里面发出良善；恶人心存邪恶，就从他里面发出邪恶。</span>
<span className="v" id="v36" data-v="36" data-xref="传道书 12:14; 罗马书 2:16; 启示录 20:12"> 我告诉你们，在审判之日，人将为自己所说的每一句闲话负责，</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各书 2:21–25"> 因为将凭你口中的话来判断你是否有罪。”</span>
</div>
</div>

## 求神迹

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 1:22; 马可福音 8:11–12; 路加福音 11:16"> 当时，有几个律法教师和法利赛人对耶稣说：“老师，我们想要看你行个神迹。”</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 16:4; 路加福音 11:29–32; 马可福音 8:38"> 耶稣回答说：“一个邪恶淫乱的世代想看神迹，但除了约拿先知的神迹以外，再没有神迹给他们看。</span>
<span className="v" id="v40" data-v="40" data-xref="约拿书 1:17; 马太福音 27:63–64; 马太福音 16:21"> 约拿在大鱼腹中三日三夜，人子也要在地里三日三夜。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 12:42; 希伯来书 11:7; 马太福音 12:6"> 在审判的日子，尼尼微人要起来<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“起来”或作“复活”。">c</a></sup>定这个世代的罪，因为他们听到约拿的宣告，就悔改了。看啊！这里有一位比约拿更大。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 10:1–13; 历代志下 9:1–12; 希伯来书 1:2–4"> 在审判的日子，南方的女王和这世代的人都要起来，她要定这个世代的罪，因为她曾不远千里来听所罗门王的智言慧语。看啊！这里有一位比所罗门王更大。</span>
</div>
</div>

## 乘虚而入

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 马太福音 8:29"> “有个污鬼离开了它所附的人，在干旱无水之地四处游荡，寻找安歇之处，却没有找到。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰一书 4:4; 启示录 13:8–9; 犹大书 1:4–5"> 于是它说，‘我要回到老地方。’它回去后，看见里面空着，打扫得又干净又整齐，</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 马可福音 5:9; 希伯来书 6:4–8"> 就去带来七个比自己更邪恶的鬼一起住在那里。那人的下场比从前更惨了。这个邪恶的世代也会这样。”</span>
</div>

## 真正的亲属

<div className="bp">

<span className="v" id="v47" data-v="47"> 有人告诉祂：“你的母亲和兄弟站在外面有话要跟你说。”</span>

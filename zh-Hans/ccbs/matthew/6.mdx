## 论周济穷人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 23:5; 约翰福音 12:43; 希伯来书 6:10"> “你们要小心，行义的时候不可张扬，故意叫人看见，否则就不能得你们天父的赏赐了。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:5; 马太福音 6:16; 哥林多后书 9:6–15"> “因此，周济穷人的时候，不要大吹大擂，像那些伪君子在会堂和街市上所行的一样，以博取人们的赞赏。我实在告诉你们，他们得到的赏赐仅此而已。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 7:4; 马太福音 9:30; 马可福音 1:44"> 你们周济穷人的时候，右手所做的别叫左手知道，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 6:18; 马太福音 6:6; 耶利米书 17:10"> 要不声不响地去做。这样，鉴察隐秘事的天父必赏赐你们。</span>
</div>
</div>

## 论祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:10–11; 马太福音 6:2; 路加福音 18:13"> “你们祷告时，不要像伪君子那样。他们喜欢站在会堂里和十字路口上公开祷告，故意让人看见。我实在告诉你们，他们得到的赏赐不过是人的赞赏。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 4:33; 马太福音 14:23; 以赛亚书 65:24"> 你们祷告的时候，要进入内室，关上门，向你们肉眼看不见的父祈祷，鉴察隐秘事的父必赏赐你们。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 5:2–3; 传道书 5:7; 列王纪上 18:26–29"> “你们祷告时不可像外族人那样喋喋不休，他们以为长篇大论，就必蒙垂听。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:32; 路加福音 12:30; 腓立比书 4:6"> 不可像他们那样，因为在你们祈求以前，你们的父已经知道你们的需要了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:1–4; 启示录 4:11; 罗马书 8:15"> “你们应当这样祷告，<br /><span className="pl pl-1">“‘我们天上的父，</span><br /><span className="pl pl-1">愿你的圣名被尊崇，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:36; 马太福音 26:42; 马太福音 12:50"> <span className="pl pl-1">愿你的国度降临，</span><br /><span className="pl pl-1">愿你的旨意在地上成就，就像在天上成就一样。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 30:8; 路加福音 11:3; 马太福音 4:4"> <span className="pl pl-1">求你今天赐给我们日用的饮食。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 马可福音 11:25; 以弗所书 1:7"> <span className="pl pl-1">饶恕我们的罪，</span><br /><span className="pl pl-1">就像我们饶恕了得罪我们的人。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 启示录 7:14–17; 马太福音 26:41"> <span className="pl pl-1">不要让我们陷入诱惑，</span><br /><span className="pl pl-1">救我们脱离那恶者。</span><br /><span className="pl pl-1">因为国度、权柄、荣耀都是你的，直到永远。阿们！’</span></span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 4:32; 马可福音 11:25; 歌罗西书 3:13"> “如果你们饶恕别人的过犯，你们的天父也必饶恕你们的过犯。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:35"> 如果你们不饶恕别人的过犯，你们的天父也不会饶恕你们的过犯。</span>
</div>
</div>

## 论禁食

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 58:3–5; 马太福音 9:14–15; 但以理书 9:3"> “你们禁食的时候，不要像伪君子那样愁眉苦脸，因为他们故意蓬头垢面，好让别人知道他们在禁食。我实在告诉你们，他们得到的赏赐不过是人的赞赏。</span>
<span className="v" id="v17" data-v="17" data-xref="路得记 3:3; 传道书 9:8; 撒母耳记下 12:20"> 你禁食的时候要梳头洗脸，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 6:6; 马太福音 6:4; 哥林多后书 10:18"> 不叫人们看出你在禁食，只让你肉眼看不见的父知道，鉴察隐秘事的父必赏赐你。</span>
</div>
</div>

## 论积财

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:5; 约翰一书 2:15–16; 路加福音 12:21"> “不要为自己在世上积攒财宝，世上有虫子咬，会生锈，又有贼闯进来偷。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:33; 马太福音 19:21; 雅各书 2:5"> 你们要把财宝积攒在天上，天上没有虫子咬，不会生锈，也没有贼闯进来偷。</span>
<span className="v" id="v21" data-v="21" data-xref="歌罗西书 3:1–3; 路加福音 12:34; 哥林多后书 4:18"> 要知道，你的财宝在哪里，你的心也在哪里。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:34–36; 哥林多后书 11:3; 歌罗西书 3:22"> “眼睛是身体的灯。你的眼睛若明亮，全身就光明；</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:11; 马太福音 6:22; 以赛亚书 5:20–21"> 你的眼睛若昏花<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“昏花”或作“邪恶”。">a</a></sup>，全身就黑暗。如果你里面的光黑暗了，那黑暗是多么大啊！</span>
<span className="v" id="v24" data-v="24" data-xref="约翰一书 2:15–16; 路加福音 16:13; 雅各书 4:4"> “一个人不能服侍两位主人，因为他不是恨这位、爱那位，就是重这位、轻那位。你们不能又事奉上帝，又事奉金钱。</span>
</div>
</div>

## 不要忧虑衣食

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:6; 彼得前书 5:7; 罗马书 8:32"> “所以我告诉你们，不要为生活忧虑，比如吃什么、喝什么，也不要为身体忧虑，比如穿什么。难道生命不比饮食重要吗？身体不比穿着重要吗？</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:29–31; 诗篇 147:9; 路加福音 12:24–32"> “你们看天上的飞鸟，它们不种，不收，也不在仓里积存粮食，你们的天父尚且养活它们，难道你们还不如飞鸟贵重吗？</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:25–26; 传道书 3:14; 诗篇 39:5–6"> 你们谁能用忧虑使自己多活片刻呢？</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 6:25; 腓立比书 4:6; 路加福音 12:27"> “何必为穿着忧虑呢？你们看看野地的百合花是如何生长的，它们既不劳苦，也不纺织。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 9:20–22; 历代志下 9:4–6; 彼得前书 3:2–5"> 但我告诉你们，就连所罗门王最显赫时的穿戴还不如一朵百合花！</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:31; 路加福音 12:28; 彼得前书 1:24"> 你们的信心太小了！野地的草今天还在，明天就被扔进炉中，上帝还这样装扮它们，何况你们呢？</span>
<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:7; 路加福音 12:29; 马太福音 4:4"> 所以，你们不要忧虑‘吃什么？喝什么？穿什么？’</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:8; 路加福音 12:30; 以弗所书 4:17"> 因为这些都是外族人的追求，你们的天父知道你们的需要。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 12:31; 马太福音 5:6; 约翰福音 6:27"> “你们要先寻求上帝的国和祂的义，这一切都会赐给你们。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 6:25; 约翰福音 14:27; 希伯来书 13:5–6"> 所以，不要为明天忧虑，因为明天自有明天的忧虑，一天的难处一天担就够了。</span>
</div>
</div>

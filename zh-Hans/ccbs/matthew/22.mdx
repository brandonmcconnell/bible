## 王宴客的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 20:1–16; 马太福音 12:43–45; 路加福音 14:16"> 耶稣又用比喻对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 19:7–9; 马太福音 13:24; 以弗所书 5:24–32"> “天国就像一个王为儿子筹备婚宴。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 22:17; 约翰福音 5:40; 路加福音 14:15–17"> 他派奴仆去请受邀的客人，可是客人都不肯来。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 13:46; 马太福音 21:36; 约翰福音 6:50–57"> 王再派其他奴仆去，说，‘去告诉被邀请的人，我的宴席已经备好，公牛和肥畜都宰了，一切都预备妥当，来赴婚宴吧！’</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:3; 路加福音 14:18–20; 约翰一书 2:15–16"> 那些人却毫不理会地走了，一个去种田，一个去做买卖，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:19–20; 约翰福音 16:2–3; 使徒行传 7:51–57"> 其余的竟然抓住王的奴仆，把他们羞辱一番后杀了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前书 4:17–18; 路加福音 21:24"> 王大怒，派军队去剿灭凶手，烧毁他们的城。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 1:5; 使徒行传 13:46; 启示录 3:4"> “然后，他对奴仆说，‘婚宴已预备好了，只是被邀请的人不配。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 马可福音 16:15–16"> 所以你们到街头巷尾，把所有见到的人都请到宴席上来。’</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 6:9–11; 启示录 19:6–9; 哥林多后书 12:21"> 奴仆到街上把遇到的人都请了来，好人坏人都有，婚宴大厅里满了客人。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 3:4–5; 启示录 19:8; 希伯来书 4:12–13"> “王出来会见在座的客人，发现有一个人没有穿礼服，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:9; 约伯记 5:16; 马太福音 20:13"> 就问他，‘朋友，你来这里怎么不穿婚宴的礼服呢？’那人无言以对。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 8:12; 马太福音 25:30; 马太福音 24:51"> 王便吩咐侍从，‘把他手脚绑起来丢到外面的黑暗里，让他在那里哀哭切齿。’</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:10; 路加福音 13:23–24; 马太福音 7:13–14"> “因为被邀请的人多，选上的人少。”</span>
</div>
</div>

## 以纳税问题刁难耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 马可福音 12:13–17; 诗篇 2:2"> 那时，法利赛人出去策划怎样从耶稣的话里找把柄陷害祂。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 3:6; 马可福音 8:15; 马可福音 12:14"> 他们派了自己的门徒跟希律党人一同去问耶稣：“老师，我们知道你诚实无伪，按真理传上帝的道，不徇情面，因为你不以貌取人。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 罗马书 13:6–7; 马太福音 17:25"> 那么请告诉我们，你认为向凯撒纳税对不对呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:6; 路加福音 5:22; 约翰福音 2:25"> 耶稣看出了他们的恶意，就说：“你们这些伪君子，为什么试探我呢？</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 20:2; 启示录 6:6; 马太福音 18:28"> 拿一个纳税用的钱币来给我看。”他们就拿给祂一个银币。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶稣问他们：“上面刻的是谁的像和名号？”</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:7; 箴言 24:21; 使徒行传 4:19"> 他们说：“凯撒的。” 耶稣说：“那么，属于凯撒的东西应该给凯撒，属于上帝的东西应该给上帝。”</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 12:12; 马太福音 22:46; 路加福音 20:25–26"> 他们听了很惊奇，只好离开祂走了。</span>
</div>
</div>

## 论复活

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:1; 马可福音 12:18–27; 使徒行传 23:6–8"> 同一天，不相信死人会复活的撒都该人也来问耶稣，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 25:5–10; 路加福音 20:28; 路得记 1:11"> 说：“老师，摩西说，‘如果一个人死了，没有儿女，只留下妻子，他的兄弟就当娶嫂嫂，替哥哥传宗接代。’</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 马可福音 12:19–23; 希伯来书 9:27"> 从前，我们这里有弟兄七人，老大结了婚，没有孩子就死了，把妻子留给了弟弟。</span>
<span className="v" id="v26" data-v="26"> 二弟、三弟一直到七弟都相继娶了嫂嫂。</span>
<span className="v" id="v27" data-v="27"> 最后，那女人也死了。</span>
<span className="v" id="v28" data-v="28"> 那么，到复活的时候，她将是谁的妻子呢？因为他们都娶过她。”</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 20:9; 罗马书 15:4; 路加福音 1:37"> 耶稣说：“你们弄错了。你们不明白圣经，也不知道上帝的能力。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 马可福音 12:24–25; 马太福音 24:38"> 因为到复活的时候，人不娶也不嫁，就像天上的天使一样。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 12:3; 马太福音 21:16; 马太福音 21:42"> “关于死人复活的事，你们没有读过上帝对你们说过的话吗？</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马可福音 12:26–27; 路加福音 20:37–38"> 祂说，‘我是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记3:6。">a</a></sup>上帝不是死人的上帝，而是活人的上帝。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 12:17; 马可福音 6:2; 约翰福音 7:46"> 众人听到祂的教导都很惊奇。</span>
</div>
</div>

## 最大的诫命

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 12:28–31; 马太福音 25:3–5; 马太福音 12:14"> 法利赛人听见耶稣使撒都该人无言以对，就聚集在一起。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 其中有位律法专家试探耶稣说：</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 12:28–33; 马太福音 5:19–20; 路加福音 11:42"> “老师，请问律法中哪一条诫命最重要呢？”</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 12:29–30; 路加福音 10:27; 申命记 6:5"> 耶稣回答说：“‘你要全心、全情、全意爱主你的上帝’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命记6:5。">b</a></sup>，</span>
<span className="v" id="v38" data-v="38"> 这是第一条也是最重要的诫命。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 12:31; 路加福音 10:27–37; 利未记 19:18"> 第二条也相似，就是‘要爱邻如己’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="利未记19:18。">c</a></sup>。</span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 13:9; 马太福音 7:12; 约翰一书 4:19–21"> 律法和先知的全部教导都以这两条诫命为基础。”</span>
</div>
</div>

## 基督的身份

<div className="bt">
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 马可福音 12:35–37; 马太福音 22:34"> 耶稣趁着法利赛人聚在那里，就问他们：</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 23:5–6; 约翰福音 6:68–69; 马太福音 16:13–17"> “你们对基督有何看法？祂是谁的后裔？”他们答道：“大卫的后裔。”</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 23:2; 启示录 4:2; 马可福音 12:36"> 耶稣说：“那么，为什么大卫受圣灵感动，称祂为主呢？大卫曾说，</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 110:1; 希伯来书 1:13; 使徒行传 2:34–35"> <span className="pl pl-1">“‘主对我主说，</span><br /><span className="pl pl-1">你坐在我的右边，</span><br /><span className="pl pl-1">等我把你的仇敌放在你脚下。’</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇110:1。">d</a></sup></span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 1:3–4; 启示录 22:16; 约翰福音 8:58"> 既然大卫称基督为主，基督又怎么会是大卫的后裔呢？”</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 没人能回答耶稣的问题。此后，再没人敢用问题刁难耶稣。</span>
</div>

## 耶和华的审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 68:21; 启示录 1:17; 以赛亚书 6:1"> <span className="pl pl-1">我看见主站在祭坛旁，祂说：</span><br /><span className="pl pl-1">“你要击打柱顶，使殿的根基震动；</span><br /><span className="pl pl-1">要打碎它们，使殿宇坍塌压死众人。</span><br /><span className="pl pl-1">侥幸生还的，我要用刀剑杀掉，</span><br /><span className="pl pl-1">无人能逃脱，无人能幸免。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 51:53; 诗篇 139:7–10; 俄巴底亚书 1:4"> <span className="pl pl-1">即使他们挖洞钻进阴间，</span><br /><span className="pl pl-1">我也要把他们揪出来；</span><br /><span className="pl pl-1">即使他们爬上高天，</span><br /><span className="pl pl-1">我也要把他们拉下来；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 16:16; 耶利米书 23:23–24; 以赛亚书 27:1"> <span className="pl pl-1">即使他们藏在迦密山的峰顶，</span><br /><span className="pl pl-1">我也要去搜寻，捉住他们；</span><br /><span className="pl pl-1">即使他们潜到海底，</span><br /><span className="pl pl-1">我也要派海蛇去吞咬他们；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:33; 耶利米书 21:10; 耶利米书 44:11"> <span className="pl pl-1">即使他们被敌人掳去，</span><br /><span className="pl pl-1">我也要命刀剑追杀他们。</span><br /><span className="pl pl-1">我要定睛在他们身上，</span><br /><span className="pl pl-1">不是要赐福而是要降祸。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="阿摩司书 8:8; 诗篇 46:6; 以赛亚书 64:1"> <span className="pl pl-1">主——万军之耶和华触摸大地，</span><br /><span className="pl pl-1">大地就消融，地上的人都要哀号；</span><br /><span className="pl pl-1">大地如埃及的尼罗河涨起退落。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 5:8; 阿摩司书 4:13; 诗篇 104:3"> <span className="pl pl-1">那位在天上建造楼阁，</span><br /><span className="pl pl-1">在大地之上立定穹苍，</span><br /><span className="pl pl-1">召来海水浇在大地上的——</span><br /><span className="pl pl-1">祂的名字是耶和华。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 47:4; 申命记 2:23; 列王纪下 16:9"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“以色列人啊，</span><br /><span className="pl pl-1">在我眼中，你们不是和古实人一样吗？</span><br /><span className="pl pl-1">我不是领你们出埃及，</span><br /><span className="pl pl-1">领非利士人出迦斐托</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“迦斐托”即克里特岛。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">领亚兰人出吉珥吗？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 30:11; 阿摩司书 9:4; 耶利米书 44:27"> <span className="pl pl-1">主耶和华的眼目察看这罪恶的国家，</span><br /><span className="pl pl-1">我要从地上除灭它，</span><br /><span className="pl pl-1">但不会完全毁灭雅各家。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:31; 申命记 28:64; 以赛亚书 30:28"> <span className="pl pl-1">“因为我要下令在万国中筛以色列家，</span><br /><span className="pl pl-1">就像人筛谷物，一粒石子也不会落在地上。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 6:3; 以赛亚书 33:14; 阿摩司书 6:1"> <span className="pl pl-1">在我的子民中，</span><br /><span className="pl pl-1">所有夸口说‘灾祸不会追上我们，也不会迎面而来’的罪人，</span><br /><span className="pl pl-1">都要死在刀下。</span></span>
</div>

## 以色列的复兴

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 15:15–17; 耶利米书 33:14–16; 以赛亚书 16:5"> <span className="pl pl-1">“到那日，</span><br /><span className="pl pl-1">我要重建大卫已倾覆的棚子，</span><br /><span className="pl pl-1">修补它城墙的缺口。</span><br /><span className="pl pl-1">我要从废墟中重建它，</span><br /><span className="pl pl-1">恢复它往日的荣耀。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 43:7; 以赛亚书 65:1; 使徒行传 15:17"> <span className="pl pl-1">这样，以色列人必拥有以东所剩的和所有属于我名下的国家。</span><br /><span className="pl pl-1">这是要成就这事的耶和华说的。”</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约珥书 3:18; 约翰福音 4:35; 利未记 26:5"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“时候将到，</span><br /><span className="pl pl-1">五谷还未收完又该耕种了，</span><br /><span className="pl pl-1">葡萄还未踩完又该栽种了。</span><br /><span className="pl pl-1">甜酒从群山上滴下，在丘岭间流淌。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:4; 耶利米书 30:3; 耶利米书 30:18"> <span className="pl pl-1">我要使我被掳的以色列子民返乡，</span><br /><span className="pl pl-1">他们要重建废城并住在城中，</span><br /><span className="pl pl-1">栽种葡萄园，喝园中酿出的美酒，</span><br /><span className="pl pl-1">整理园圃，吃园中出产的佳果。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 24:6; 以西结书 37:25; 以赛亚书 60:21"> <span className="pl pl-1">我要将以色列人栽种在他们自己的土地上，</span><br /><span className="pl pl-1">他们永不再从我赐给他们的土地上被铲除。”</span><br /><span className="pl pl-1">这是你们的上帝耶和华说的。</span></span>

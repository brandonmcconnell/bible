## 尼布甲尼撒的梦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 4:5; 以斯帖记 6:1; 约伯记 33:15–17"> 尼布甲尼撒在执政第二年做了梦，心里烦乱，无法入睡，</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 1:20; 但以理书 4:6; 创世记 41:8"> 便派人召来术士、巫师、行法术的和占星家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“占星家”亚兰文作“迦勒底人”，同下2:4、5、10节；3:8；4:7；5:7、11。">a</a></sup>，为他解梦。他们都来到王面前。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 40:8; 创世记 41:15; 但以理书 4:5"> 王对他们说：“我做了一个梦，心里烦乱，想知道梦的意思。”</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 3:9; 但以理书 5:10; 以斯拉记 4:7"> 占星家用亚兰话对王说：“愿王万岁！请将梦告诉仆人，仆人好解释梦的意思。”</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:29; 以斯拉记 6:11; 列王纪下 10:27"> 王对占星家说：“我的旨意已定，你们若不能将梦和梦的意思告诉我，必被碎尸万段，你们的家必沦为废墟。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 5:7; 但以理书 2:48; 但以理书 5:29"> 你们若能将梦和梦的意思告诉我，我必给你们礼物、赏赐和极大的尊荣。所以你们要将梦和梦的意思告诉我。”</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 2:4; 但以理书 2:9; 传道书 10:4"> 他们再次对王说：“请王将梦告诉仆人，仆人好解释梦的意思。”</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 4:5; 以弗所书 5:16"> 王说：“我敢肯定，你们是在拖延时间，因为你们知道我的旨意已定，</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 41:23; 但以理书 7:25; 以斯帖记 4:11"> 你们若不将梦告诉我，我必惩治你们。你们串通起来在我面前胡言乱语，以拖待变。现在将梦告诉我，我就相信你们能解梦。”</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 2:27"> 占星家说：“王所要求的，世上无人能做到，因为再伟大、再有权势的君王，也没问过术士、巫师或占星家这样的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 5:11; 以赛亚书 57:15; 创世记 41:39"> 王问的事太难，除了不在人间居住的神明外，无人能为王解答。”</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 3:13; 马太福音 2:16; 但以理书 3:19"> 王大怒，下令处死巴比伦所有的智者。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 1:19–20; 以斯帖记 3:12–15; 以赛亚书 10:1"> 于是，处死智者的谕旨发出，有人便搜寻但以理和他的同伴，要处死他们。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="但以理书 2:24; 耶利米书 52:12; 撒母耳记下 20:16–22"> 王的护卫长亚略奉命去处死巴比伦的智者，但以理机智、谨慎地应对。</span>
<span className="v" id="v15" data-v="15"> 他问王的护卫长亚略：“王的命令为何这样紧急？”亚略就把情况告诉他。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:18–19; 但以理书 2:9–11"> 但以理便进宫求王宽限，以便为王解梦。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 1:6–7; 但以理书 3:12; 但以理书 1:11"> 然后，他回到居所将这事告诉同伴哈拿尼雅、米沙利和亚撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 33:3; 马太福音 18:19; 马太福音 18:12"> 要同伴祈求天上的上帝施怜悯，显明这奥秘，以免他们和其他巴比伦的智者一起被杀。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 12:6; 阿摩司书 3:7; 但以理书 7:7"> 这奥秘在夜间的异象中向但以理显明，他便颂赞天上的上帝，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 113:2; 诗篇 145:1–2; 启示录 5:12"> 说：<br /><span className="pl pl-1">“上帝的名永永远远当受称颂，</span><br /><span className="pl pl-1">因为智慧和能力都属于祂。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 75:5–7; 诗篇 31:14–15; 诗篇 113:7–8"> <span className="pl pl-1">祂改变时令和季节，废王立王，</span><br /><span className="pl pl-1">赐智慧给智者，赐知识给哲士。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 12:22; 约翰一书 1:5; 耶利米书 23:24"> <span className="pl pl-1">祂显明深奥隐秘之事，</span><br /><span className="pl pl-1">洞悉暗中的隐情，</span><br /><span className="pl pl-1">有光与祂同住。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 2:18; 出埃及记 3:15; 但以理书 2:29–30"> <span className="pl pl-1">我祖先的上帝啊，我感谢你，赞美你，</span><br /><span className="pl pl-1">因你赐我智慧和能力，</span><br /><span className="pl pl-1">应允我们的祈求，</span><br /><span className="pl pl-1">使我们明白王的梦。”</span></span>
</div>
</div>

## 但以理解梦

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 27:24; 但以理书 2:12–14"> 于是，但以理去见王指派处死巴比伦智者的亚略，对他说：“不要处死巴比伦的智者，请带我去见王，我要为王解梦。”</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 1:27–28; 但以理书 6:13; 但以理书 5:13"> 亚略急忙带但以理去见王，对王说：“我在被掳的犹大人中找到一个能为王解梦的。”</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 1:7; 但以理书 5:16; 但以理书 5:12"> 王就问又名伯提沙撒的但以理：“你能将我做的梦和梦的意思告诉我吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 47:12–14; 但以理书 2:2; 以赛亚书 44:25"> 但以理回答说：“没有智者、术士、巫师或占星家可以解答王所问的奥秘，</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 40:8; 阿摩司书 4:13; 但以理书 10:14"> 但天上的上帝能揭开奥秘，祂已把将来要发生的事告诉了王。王啊，你躺在床上时想到了将来的事，揭开奥秘的上帝已把将来的事指示给你。上帝将王做的梦启示给我，并非因为我智慧超群，而是要让王知道梦的意思和王的心思。以下是王在床上做的梦和脑中出现的异象。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷书 1:7; 以西结书 28:7; 但以理书 7:3–17"> “王啊，你梦见一个高大宏伟、极其明亮的塑像站在你面前，相貌可怕，</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 51:7; 但以理书 7:4–6; 启示录 17:4"> 有纯金的头、银的胸和臂、铜的肚腹和大腿、</span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 7:19–26; 但以理书 7:7–8; 但以理书 2:40–43"> 铁的小腿和半铁半泥的脚。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理书 2:44–45; 但以理书 8:25; 撒迦利亚书 12:3"> 在你观看的时候，有一块非人手凿出的石头砸在塑像半铁半泥的脚上，砸碎了脚。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 2:2–3; 诗篇 37:10; 启示录 20:11"> 铁、泥、铜、银、金随即粉碎，犹如夏天麦场上的糠秕，被风吹得无影无踪。但打碎这像的石头变成一座大山，充满整个大地。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理书 2:23–24"> “这就是梦的内容。现在我们要为王解梦。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 26:7; 耶利米书 27:6–7; 以斯拉记 7:12"> 王啊，你是王中之王，天上的上帝已将国度、权柄、能力和尊荣赐给你，</span>
<span className="v" id="v38" data-v="38" data-xref="但以理书 4:21–22; 诗篇 50:10–11; 耶利米书 27:5–7"> 也将居住在各地的世人、走兽和飞禽都交在你手中，让你管理。你就是那金头。</span>
<span className="v" id="v39" data-v="39" data-xref="但以理书 5:28–31; 以赛亚书 44:28–5; 但以理书 2:32"> 在你之后，必有另一国兴起，不及你的国强大。之后是将要统治天下的第三个国，是铜的。</span>
<span className="v" id="v40" data-v="40" data-xref="但以理书 7:7; 但以理书 7:19–26; 但以理书 11:36–45"> 接着是坚如铁的第四国，能击垮、打碎列国，正如铁能击垮、打碎一切。</span>
<span className="v" id="v41" data-v="41" data-xref="启示录 17:12; 但以理书 2:33–35; 启示录 12:3"> 你看见半铁半陶泥的脚和脚趾，表示那将是一个分裂的国。正如你看见铁和泥混杂在一起，它必有铁一般的力量。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 7:24; 启示录 13:1"> 半铁半泥的脚趾表示那国必半强半弱。</span>
<span className="v" id="v43" data-v="43"> 你看见铁和泥混杂在一起，这表示那国的民族彼此混杂通婚，却不能团结，正如铁和泥无法混合。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 28:18; 路加福音 1:32–33; 但以理书 6:26"> 在以上列王统治的时候，天上的上帝必设立一个永不被毁的国，这国必不会落入其他民族手中。它将击垮、消灭列国，并且永远长存。</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 28:16; 创世记 41:32; 申命记 10:17"> 你看见那块非人手从山中凿出的石头打碎铁、铜、泥、银和金。伟大的上帝已把将来的事告诉了王。这梦是真实的，解释是可靠的。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行传 10:25; 使徒行传 14:13; 以斯拉记 6:10"> 尼布甲尼撒王俯伏在地，向但以理下拜，并下令给他献供物和香。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理书 2:22; 但以理书 2:28; 阿摩司书 3:7"> 王对但以理说：“你们的上帝真是万神之神、万王之主、奥秘的启示者，因为你能揭开这个奥秘。”</span>
<span className="v" id="v48" data-v="48" data-xref="但以理书 2:6; 但以理书 4:9; 但以理书 5:11"> 王赐但以理高官及许多贵重的礼物，派他治理巴比伦全省，管理巴比伦所有的智者。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理书 1:7; 以斯帖记 2:19; 但以理书 3:12–30"> 王又应允但以理的请求，派沙得拉、米煞和亚伯尼歌负责巴比伦省的事务。但以理仍在朝中供职。</span>
</div>

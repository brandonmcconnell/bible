## 但以理在狮子坑

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 18:21–22; 但以理书 5:31; 以斯帖记 1:1"> 大流士决定设立一百二十个总督治理全国。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 2:48–49; 但以理书 5:29; 以斯帖记 7:4"> 总督之上设三个总长，负责管理总督，以维护王的统治，但以理是其中之一。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 5:14; 箴言 22:29; 创世记 41:38–41"> 因为但以理有非凡的心智，远超过其他总长和总督，王便考虑让他治理全国。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 3:16; 腓立比书 2:15; 彼得前书 2:12"> 于是，其他总长和总督想在但以理的政务中找把柄控告他，却找不到任何把柄或过失，因为他诚实可靠，毫无过失。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 24:13–16; 以斯帖记 3:8; 使徒行传 24:20–21"> 最后他们说：“除非我们从但以理上帝的律法下手，否则找不到指控他的把柄。”</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 2:4; 尼希米记 2:3; 但以理书 6:21"> 于是，这些总长和总督齐来见王，说：“愿大流士王万岁！</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 59:3; 诗篇 62:4; 但以理书 3:27"> 所有总长、行政官、总督、谋士和省长都认为王应该颁布诏书并实施一道禁令，三十天内，任何人不得向王以外的神明或人祷告，违者必被扔进狮子坑。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 6:15; 以斯帖记 1:19; 但以理书 6:12"> 王啊，求你颁布并签署这道禁令，使之不可更改，正如玛代人和波斯人的律令是不可更改的。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 146:3; 诗篇 118:9; 诗篇 62:9–10"> 于是大流士王签署了这道禁令。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29; 诗篇 55:17; 帖撒罗尼迦前书 5:17–18"> 但以理知道王签署禁令后，就回到家里，他楼上房间的窗户朝向耶路撒冷。他像往常一样每日三次跪下向上帝祷告、感恩。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 37:32–33; 诗篇 10:9; 但以理书 6:6"> 那些官员一同来了，发现但以理向他的上帝祷告、祈求，</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 6:8; 但以理书 3:8–12; 以斯帖记 1:19"> 便去见王，提及王的禁令，说：“王啊，你不是签署禁令，三十天内，任何人不得向王以外的神明或人祷告，违者必被扔进狮子坑吗？”王说：“确有此事，按照玛代人和波斯人的律令，这禁令不可更改。”</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 3:12; 使徒行传 5:29; 但以理书 2:25"> 他们对王说：“王啊，被掳来的犹大人但以理不理会你和你的禁令，仍一日三次向他的上帝祈祷。”</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:26; 马太福音 27:17–24; 撒母耳记下 3:28–29"> 王听了这些话，十分愁烦，一心想救但以理，直到日落都在筹划解救之道。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 6:12; 诗篇 94:20–21; 但以理书 6:8"> 那些人齐来见王，说：“王啊，要知道按照玛代人和波斯人的律令，王颁布的禁令和律例是不可更改的。”</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:39–40; 约伯记 5:19; 诗篇 91:14–16"> 王便下令把但以理带来扔进狮子坑。他对但以理说：“愿你一直事奉的上帝拯救你！”</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:53; 使徒行传 12:4; 马太福音 27:60–66"> 有人搬来一块石头封住坑口，王用他和大臣的印加封，使惩办但以理的事不可更改。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖记 6:1; 但以理书 2:1; 撒母耳记下 12:16–17"> 王回宫后，整夜禁食，拒绝娱乐，无法入睡。</span>
<span className="v" id="v19" data-v="19" data-xref="帖撒罗尼迦前书 3:5; 马可福音 16:2; 马太福音 28:1"> 次日黎明，王起来匆忙赶往狮子坑，</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 16:11; 希伯来书 7:25; 但以理书 6:27"> 到了坑边，凄声呼喊但以理：“永活上帝的仆人但以理啊，你一直事奉的上帝有没有救你脱离狮子的口？”</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 2:4; 但以理书 6:6; 尼希米记 2:3"> 但以理对王说：“愿王万岁！</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 4:17; 希伯来书 11:33; 使徒行传 12:11"> 我的上帝差遣天使封住了狮子的口，不让它们伤害我，因为我在上帝面前是清白的。王啊，我在你面前也没有过错。”</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 5:20; 马可福音 9:23; 但以理书 3:27–28"> 王非常高兴，便命人把但以理从坑中拉上来。于是，但以理从坑中被拉了上来，他因为信靠他的上帝，身上毫无损伤。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 38:13; 以斯帖记 7:10; 申命记 24:16"> 王下令把那些恶意控告但以理的人及其儿女妻子都带来，扔进狮子坑。他们还没到坑底，狮子便扑上去，咬碎了他们的骨头。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 4:1; 以斯拉记 1:1–2; 以斯帖记 3:12"> 后来，大流士王传谕境内的各族、各邦、各语种的人，说：“愿你们大享平安！</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 4:34; 路加福音 1:33; 但以理书 3:29"> 我下令，我统治的国民都要敬畏但以理的上帝，<br /><span className="pl pl-1">“因为祂是永活长存的上帝，</span><br /><span className="pl pl-1">祂的国度永不灭亡，</span><br /><span className="pl pl-1">祂的统治直到永远。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 4:2–3; 诗篇 18:50; 使徒行传 4:30"> <span className="pl pl-1">祂庇护、拯救，</span><br /><span className="pl pl-1">在天上地下行神迹奇事，</span><br /><span className="pl pl-1">救但以理脱离狮子的口。”</span></span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 1:21; 历代志下 36:22–2; 以赛亚书 44:28–1"> 因此，在大流士和波斯人塞鲁士执政期间，但以理凡事亨通。</span>

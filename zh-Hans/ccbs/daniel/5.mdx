## 墙上写字

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 1:3; 马可福音 6:21–22; 以赛亚书 21:4–5"> 伯沙撒王盛宴款待一千大臣，与他们一同饮酒。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 1:2; 列王纪下 24:13; 耶利米书 27:16–22"> 王畅饮的时候，命人将先王尼布甲尼撒从耶路撒冷圣殿中掳来的金银器皿拿来，供他与大臣、王后和妃嫔用来饮酒。</span>
<span className="v" id="v3" data-v="3"> 于是，他们把从耶路撒冷上帝殿中掳来的金器拿来，王与大臣、王后和妃嫔便用这些器皿饮酒。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 5:23; 哈巴谷书 2:19; 诗篇 135:15–18"> 他们一边饮酒，一边颂赞金、银、铜、铁、木、石所造的神明。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 4:31; 但以理书 5:24–28; 约伯记 20:5"> 突然，有人的手指出现，在灯台对面王宫的粉墙上写字。王看见那只手在写字，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 7:17; 但以理书 7:28; 那鸿书 2:10"> 脸色骤变，惊恐万分，两腿发软，双膝颤抖。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:29; 但以理书 5:16; 但以理书 2:48"> 他大声传令，召来巫师、占星家和占卜者，对这些巴比伦的智者说：“谁能读墙上的字，把意思告诉我，他必身穿紫袍，颈戴金链，在国中位居第三。”</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 2:27; 但以理书 4:7; 创世记 41:8"> 王所有的智者进来后，竟无人能读懂或把意思告诉王。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:6; 但以理书 2:1; 耶利米书 6:24"> 伯沙撒王愈发恐惧，脸色苍白，他的大臣都不知所措。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理书 3:9; 但以理书 6:6; 但以理书 2:4"> 太后听到王和大臣的喊声，便来到宴会厅，对王说：“愿王万岁！不要惊慌失色。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 4:8–9; 但以理书 2:47–48; 但以理书 4:18"> 你国中有一个人，他里面有圣洁神明的灵。先王在世时，曾发现他有神明一样的灼见、悟性和智慧。先王尼布甲尼撒立他为术士、巫师、占星家和占卜者的首领。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 5:14; 但以理书 6:3; 但以理书 1:7"> 他有非凡的心智、知识和悟性，能解梦、释谜、解惑。他叫但以理，先王给他取名叫伯提沙撒。现在可以把他召来，他必能解释这些字的意思。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理书 6:13; 但以理书 5:11; 但以理书 2:25"> 于是，但以理被带到王面前。王问他：“你就是先王从犹大掳来的但以理吗？</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 5:11–12"> 我听说你有神明的灵，有灼见、悟性和非凡的智慧。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:7–8; 以赛亚书 47:12; 以赛亚书 29:10–12"> 我召智者和巫师来读这些字，为我解释字的意思，但他们都不能解释。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 5:7; 创世记 40:8; 但以理书 5:29"> 我听说你能释梦、解惑。你若能读出墙上的字，把意思告诉我，你必身穿紫袍、颈戴金链，在我的国中位居第三。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 5:16; 创世记 14:23; 列王纪下 5:26"> 但以理回答说：“你的礼物自己留着，你的赏赐可以给别人，不过我会为你读这些字，解释意思。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 2:37–38; 但以理书 4:17; 但以理书 4:22–25"> 王啊，至高的上帝曾将国位、权力、尊荣、威严赐给你的先王尼布甲尼撒，</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 3:6; 但以理书 2:12–13; 但以理书 3:4"> 因为他有上帝所赐的大权，各族、各邦、各语种的人都在他面前恐惧颤抖。他操生杀大权，可随意提升、罢黜。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 9:17; 耶利米书 13:18; 希伯来书 3:13"> 但他变得心高气傲、刚愎自用、狂妄自大，因而被革除王位、剥去尊荣。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 4:25; 以西结书 17:24; 但以理书 4:35"> 他从人群中被赶走，他的心变成兽心，他与野驴同住，像牛一样吃草，被天上的露水浸湿，直到他知道至高的上帝主宰世上万国，祂要把国赐给谁就赐给谁。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 33:23; 出埃及记 10:3; 雅各书 4:17"> “伯沙撒啊，你是他的后裔，你虽然知道这一切事，仍不谦卑，</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 12:10; 但以理书 4:37; 耶利米书 10:23"> 竟在天上的主面前自大，命人拿来祂殿里的器皿，供你和大臣、王后、妃嫔用来饮酒，并颂赞不能看、不能听、一无所知、用金、银、铜、铁、木、石所造的神明，却不尊崇赐你生命气息、掌管你一举一动的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理书 5:5"> “因此，上帝使指头出现，写下这些字，</span>
<span className="v" id="v25" data-v="25"> 就是‘弥尼，弥尼，提客勒，乌法珥新’。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 25:11–12; 以赛亚书 47:1–15; 耶利米书 27:7"> 这些字的意思是这样，弥尼指上帝已经数算你国度的年日，使之到此为止；</span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 31:6; 哥林多前书 3:13; 诗篇 62:9"> 提客勒指你已经被放在秤上称了，发现分量不够；</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 13:17; 但以理书 6:28; 但以理书 5:31"> 乌法珥新<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“乌法珥新”亚兰文是“毗勒斯”，即“乌法珥新”的单数格式。">a</a></sup>指你的国要分裂，归给玛代人和波斯人。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理书 5:16; 但以理书 5:7"> 于是，伯沙撒下令给但以理穿上紫袍，戴上金项链，又宣告他在国中位居第三。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 51:31; 耶利米书 51:57; 耶利米书 51:39"> 当夜，迦勒底王伯沙撒被杀。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 9:1; 但以理书 6:1"> 玛代人大流士夺取了王权，时年六十二岁。</span>
</div>
</div>

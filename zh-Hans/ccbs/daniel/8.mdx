## 公绵羊和公山羊的异象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 11:4; 但以理书 9:2; 但以理书 7:28"> 在看见先前的异象之后，我但以理在伯沙撒王执政第三年又看见一个异象。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 1:2; 尼希米记 1:1; 创世记 10:22"> 我在异象中看见自己在以拦省的书珊城，又看见自己站在乌莱河畔。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 8:20; 但以理书 10:5; 撒迦利亚书 6:1"> 我举目观看，见河边站着一只公绵羊，长着两个长角，一角比另一角长，较长的角是后长出来的。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 11:16; 但以理书 11:36; 但以理书 8:7"> 我看见这公绵羊向西方、北方和南方顶撞，没有兽能抵挡它，或逃脱它的威力。它随心所欲，狂妄自大。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 8:21; 但以理书 11:3; 但以理书 8:8"> 我正沉思的时候，忽然从西面出现一只公山羊，穿越大地，脚不沾地奔来。它双眼之间有一个醒目的角。</span>
<span className="v" id="v6" data-v="6"> 这公山羊来到我之前看见站在河边的双角公绵羊那里，愤怒地向它顶去。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:7; 但以理书 11:11; 约书亚记 8:20"> 我看见公山羊愤怒地顶向公绵羊，攻击它，折断了它的双角。公绵羊无力抵挡公山羊，被撞倒在地，践踏在脚下，无人能救它脱离公山羊的威力。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 7:2; 启示录 7:1; 但以理书 5:20"> 公山羊极其狂妄自大。但正值鼎盛之时，它的大角突然折断，在原处又长出四个醒目的角，朝着天的四方。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 11:16; 以西结书 20:6; 以西结书 20:15"> 其中一个角又长出一个小角，向南方、东方和佳美之地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“佳美之地”指以色列，下同11:16、41。">a</a></sup>扩张势力。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 14:13; 启示录 12:4; 但以理书 8:7"> 它长得高及天军，将一些天军和星宿抛到地上，用脚践踏。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 12:11; 启示录 13:5–7; 但以理书 8:25"> 它狂妄自大，与天军的统帅比高，它废除日常献给祂的祭，毁坏祂的圣所。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 12:1; 以赛亚书 59:14; 但以理书 11:31–36"> 因为反叛的缘故，天军和日常所献的祭都交给了它。它将真理抛在地上，它所行的无不顺利。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 11:2; 启示录 6:10; 路加福音 21:24"> 接着，我听见一位圣者在说话，另一位圣者问他：“异象中出现的有关日常所献的祭，毁灭性的反叛和践踏圣所及天军的事要持续多久呢？”</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 12:7; 但以理书 7:25; 启示录 11:2–3"> 他对我说：“两千三百个昼夜。之后，圣所才会洁净。”</span>
</div>
</div>

## 解释异象

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 10:16; 启示录 1:13; 彼得前书 1:10–11"> 我但以理看见这异象，正想明白它的意思，忽然有一个外貌像人的站在我面前。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:19; 路加福音 1:26; 但以理书 8:2"> 我听见有人声从乌莱河两岸之间呼喊：“加百列啊，要让此人明白这异象。”</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 8:19; 但以理书 12:4; 哈巴谷书 2:3"> 于是，他朝我站的地方走来，当他走来的时候，我吓得俯伏在地。他对我说：“人子啊，你要明白，这异象是关于末后的时期。”</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 10:18; 以西结书 2:2; 但以理书 10:16"> 他和我说话的时候，我伏在地上昏睡过去，他便轻拍我，扶我起来，</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 2:3; 但以理书 11:27; 启示录 17:17"> 对我说：“我要告诉你将来上帝发烈怒的末了所发生的事，因为这异象是关于那定好的末后时期。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 8:3; 但以理书 11:1–2"> 你看见的那只有两角的公绵羊指玛代和波斯的诸王。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 10:20; 但以理书 11:3; 但以理书 8:5–8"> 公山羊指希腊王，在它双眼之间的大角指第一个王。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 11:4; 但以理书 8:3; 但以理书 8:8"> 大角折断后，从原处长出四个角表示四个国必从这国兴起，但都不及这国强大。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 13:11–14; 帖撒罗尼迦后书 2:9–11; 启示录 19:20"> 在四国的末期，人们恶贯满盈的时候，必有一个面貌凶恶、诡计多端的王兴起。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 8:12; 但以理书 11:31–36; 但以理书 7:25"> 他势力强大，却不是靠自己的力量。他必带来可怕的毁灭，而且凡事亨通，他必毁灭强者和圣民。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 8:11; 启示录 17:14; 约伯记 34:20"> 他靠阴谋诡计得逞，心高气傲，乘人不备突然毁灭许多人，甚至要攻击万君之君，然而他终必被击垮，但并非被人的手击垮。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 10:1; 但以理书 12:9; 但以理书 12:4"> 有关两千三百个昼夜的异象是真的。但你要保密，因为这指的是遥远的将来。”</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 7:28; 哈巴谷书 3:16; 但以理书 8:7"> 我但以理精疲力尽，病了几天。后来我起来照常办理王的事务，但我对这异象感到惊奇不已，不明白它的意思。</span>
</div>

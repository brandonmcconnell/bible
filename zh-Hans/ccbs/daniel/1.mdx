## 但以理被掳到巴比伦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 36:5–7; 列王纪下 24:1–2; 列王纪下 24:13"> 犹大王约雅敬执政第三年，巴比伦王尼布甲尼撒前来围攻耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:7; 撒迦利亚书 5:11; 耶利米书 27:19–20"> 主将犹大王约雅敬及上帝殿中的部分器具交在他手中。他把器具掳到巴比伦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“巴比伦”希伯来文是“示拿”，巴比伦的别称。">a</a></sup>的神庙，放在他神明的库房里。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 39:7; 列王纪下 20:17–18; 列王纪下 24:15"> 王吩咐太监长亚施毗拿从以色列的王室和贵族中选一些人，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 5:11; 使徒行传 7:22; 箴言 22:29"> 即毫无残疾、相貌英俊、学问渊博、聪慧善学、能在王宫服侍的青年，教他们迦勒底的语言和文字。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 1:19; 列王纪上 10:8; 但以理书 1:8"> 王安排他们每日享用御用的膳食和酒。他们要受教养三年，期满后好在王身边供职。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 14:14; 马太福音 24:15; 但以理书 2:17"> 被选的人中有犹大人但以理、哈拿尼雅、米沙利和亚撒利雅。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:12; 但以理书 4:8; 但以理书 2:49"> 太监长给他们起了新名字：称但以理为伯提沙撒，哈拿尼雅为沙得拉，米沙利为米煞，亚撒利雅为亚伯尼歌。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 141:4; 以西结书 4:13–14; 利未记 11:45–47"> 然而，但以理决心不用王的膳食和酒，以免玷污自己。他请求太监长准许他不玷污自己。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 39:21; 箴言 16:7; 诗篇 106:46"> 上帝使但以理得到太监长的恩待和同情。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 6:16–18; 约翰福音 12:42–43; 箴言 29:25"> 不过，太监长对但以理说：“我惧怕我主我王，因为这是他指派给你们的饮食。如果他看见你们面容比同龄的青年憔悴，如何是好？你们会使我在王面前人头难保。”</span>
<span className="v" id="v11" data-v="11"> 但以理便对太监长派来监管他、哈拿尼雅、米沙利和亚撒利雅的人说：</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:2; 但以理书 1:16; 创世记 1:29–30"> “求你试试在十天内只让仆人们吃素菜、喝清水，</span>
<span className="v" id="v13" data-v="13"> 然后比较一下我们的面容和那些用御膳的青年的面容，看了之后再作决定。”</span>
<span className="v" id="v14" data-v="14"> 监管同意试他们十天。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 23:25; 箴言 10:22; 列王纪下 4:42–44"> 十天后，但以理和他三个朋友看起来比那些用御膳的青年更俊美健康。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:12"> 于是，监管撤去了指派给他们的膳食和酒，只给他们素菜。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 3:12; 雅各书 1:5; 但以理书 2:21"> 上帝使这四个青年精通各种学问和知识。但以理能明白各种异象和梦兆。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 1:5"> 到了尼布甲尼撒王规定青年们进宫的日子，太监长便带他们去见王。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 创世记 41:46; 但以理书 1:5"> 王与他们谈话，发现无人比得上但以理、哈拿尼雅、米沙利和亚撒利雅，便把他们留在身边供职。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 8:19; 以赛亚书 47:12–14; 列王纪上 4:29–34"> 王询问他们各种各样的事，发现他们的智慧和聪明比全国的术士和巫师高十倍。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 6:28; 但以理书 10:1"> 直到塞鲁士王元年，但以理仍在宫中供职。</span>
</div>
</div>

</div>

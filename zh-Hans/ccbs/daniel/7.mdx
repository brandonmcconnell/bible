## 但以理梦见四兽

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="但以理书 1:17; 阿摩司书 3:7; 但以理书 5:1"> 巴比伦王伯沙撒元年，但以理在床上做了一个梦，脑中出现了异象，便把梦记录下来，讲述其中的大意。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 7:1; 启示录 17:15"> 但以理说：“我在夜间的异象中看见天上有四股风吹来，搅动大海。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 13:1; 但以理书 7:17; 但以理书 2:32–33"> 接着，四只巨兽从海中上来，各有不同的形状。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:7; 以赛亚书 14:13–17; 以西结书 17:3"> 第一只兽像狮子，但有鹰的翅膀。我观看时，见它的翅膀被拔掉。它被扶起来，像人一样双脚站在地上，并被赋予人的头脑。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 2:39; 以赛亚书 13:17–18; 箴言 17:12"> 第二只兽像熊，用两只后腿站立，牙齿间叼着三根肋骨，有声音对它说，‘起来，多吞吃肉吧！’</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 13:2; 但以理书 8:20–22; 但以理书 8:5–8"> “此后，我继续观看，见还有一只兽像豹，背上有四个如鸟翼般的翅膀。这兽有四个头，并被赋予权柄。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 13:1; 启示录 12:3; 启示录 17:12"> 此后，我在夜间的异象中看见第四只兽，恐怖可怕，极其强壮，长着大铁牙吞吃、咬碎猎物，用脚践踏所剩的。这兽与前三只兽不同，它有十个角。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 13:5–6; 启示录 13:1; 诗篇 12:3"> 我观看这些角时，见其中又长出一个小角，先前的角中有三个被连根拔出，由它取而代之。这小角有人的眼睛和说狂言的口。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 1:14; 马可福音 9:3; 但以理书 7:13"> <span className="pl pl-1">“我看见宝座已设立，</span><br /><span className="pl pl-1">上面坐着亘古长存者，</span><br /><span className="pl pl-1">祂的衣服洁白如雪，</span><br /><span className="pl pl-1">头发如纯净的羊毛。</span><br /><span className="pl pl-1">祂的宝座是火焰，</span><br /><span className="pl pl-1">宝座的轮子是烈火。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:27; 申命记 33:2; 启示录 20:11–15"> <span className="pl pl-1">从祂面前流出火河，</span><br /><span className="pl pl-1">事奉祂的有千千，</span><br /><span className="pl pl-1">侍立在祂面前的有万万。</span><br /><span className="pl pl-1">祂坐下要审判，</span><br /><span className="pl pl-1">案卷已经展开。</span></span>
<span className="v" id="v11" data-v="11" data-xref="启示录 19:20; 启示录 20:10; 帖撒罗尼迦后书 2:8"> “因为小角口出狂言，我便继续观看，一直到那兽被杀，身体被毁并被扔进火中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 8:7; 但以理书 7:4–6"> 至于其余的兽，它们的权柄都被夺去，但获准再存活一段时间。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64; 启示录 1:7; 路加福音 21:27"> “我在夜间的异象中看见一位像人子的驾着天上的云而来，到亘古长存者那里，被引到祂面前。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 11:15; 但以理书 7:27; 约翰福音 3:35"> 祂得到权柄、荣耀和国度，各国、各邦、各语种的人都要事奉祂。祂的统治直到永远、没有穷尽，祂的国度永不灭亡。</span>
</div>
</div>

## 解释异象

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 7:28; 耶利米书 17:16; 创世记 40:7–8"> “我但以理心灵不安，脑中出现的异象让我恐惧，</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:13–14; 撒迦利亚书 2:3; 启示录 5:5"> 便走近一位侍立一旁的，问他这些事的意思。他就向我解释说，</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 8:19–22; 但以理书 2:37–40; 约翰福音 18:36"> ‘这四只巨兽是指四个将要在世上兴起的王。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 7:27; 以赛亚书 60:12–14; 启示录 5:10"> 但至高者的圣民必承受这国度，并永永远远拥有这国度。’</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 7:7; 但以理书 2:40–43"> “那时，我想知道关于第四兽的事，它与其余三兽不同，极其可怕，有铁牙铜爪，吞吃、咬碎猎物，用脚践踏所剩的。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 7:23; 但以理书 7:8; 但以理书 7:11"> 我也想知道有关它头上的十角及后来长出的小角的事。有三个角在这小角面前断落，这角有眼和说狂言的口，看起来比其他角更强大。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 12:7; 启示录 17:14; 但以理书 8:24"> 我看见这小角与圣民争战，并占了上风。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 7:18; 启示录 20:4; 启示录 5:10"> 后来亘古长存的至高者来为祂的圣民申冤。圣民拥有国度的时候到了。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 2:40; 但以理书 7:7; 路加福音 2:1"> “那位侍立一旁的说，‘第四只兽是指世上将兴起的第四个国，与其他各国不同，它将吞吃、践踏、咬碎天下。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:20; 但以理书 11:36; 启示录 13:1"> 十角是指这国中将兴起十个王，后来又兴起一王，与先前的王不同，他将制服三个王。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 12:7; 启示录 12:14; 帖撒罗尼迦后书 2:4"> 他必亵渎至高者，迫害至高者的圣民，试图改变节期和律法。圣民将被交在他手中三年半。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 20:10–11; 帖撒罗尼迦后书 2:8; 启示录 11:13"> 然而，审判者将坐下来审判，夺去并永远废除他的权柄。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 72:11; 路加福音 1:33; 启示录 11:15"> 那时，国度、权柄和天下万国的尊荣必赐给至高者的圣民。祂的国度直到永远，一切掌权者都要事奉祂，顺服祂。’</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理书 10:8"> “这就是我的梦。我但以理心中十分害怕，脸色苍白，但我没有把这事告诉别人。”</span>

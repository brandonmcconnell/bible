## 但以理为同胞祷告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 11:1; 但以理书 1:21; 但以理书 5:31–1"> 玛代人亚哈随鲁的儿子大流士被立为迦勒底国王元年，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 29:10; 耶利米书 25:11–12; 历代志下 36:21"> 就是他统治的第一年，我但以理从经书上得知，按照耶和华给耶利米先知的话，耶路撒冷必荒凉七十年。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 33:3; 耶利米书 29:10–13; 雅各书 5:16–18"> 我便禁食，身披麻衣，头蒙灰尘，向主上帝祷告祈求。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:28; 出埃及记 20:6; 申命记 5:10"> 我向我的上帝耶和华祷告、认罪，说：“主啊，你是伟大而可畏的上帝，你向那些爱你、遵守你诫命的人守约，施慈爱。</span>
<span className="v" id="v5" data-v="5" data-xref="玛拉基书 3:7; 但以理书 9:11; 但以理书 9:15"> 我们犯罪作恶，行为邪恶叛逆，偏离你的诫命和典章，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 9:10; 历代志下 36:15–16; 路加福音 20:10–12"> 没有听从你的仆人——众先知奉你的名向我们的君王、首领、先祖及国中百姓所说的话。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:15; 耶利米书 3:25; 耶利米书 2:26–27"> 主啊，你是公义的，我们犹大人和耶路撒冷的居民，以及因对你不忠而被驱散到远近各地的以色列人都受尽羞辱，正如今日一样。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 耶和华啊，我们和我们的君王、首领、先祖因得罪了你而满脸羞愧。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 1:6–8; 但以理书 9:7; 但以理书 9:5"> 虽然我们背叛了主——我们的上帝，祂却有怜悯和饶恕之心。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 9:6; 列王纪下 18:12; 尼希米记 9:13–17"> 我们没有听从我们的上帝耶和华的话，没有遵行祂借着祂的仆人——众先知给我们颁布的律法。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:5–10; 以赛亚书 1:4–6; 申命记 28:15–68"> 以色列人都违背你的律法，偏离正道，不听从你的话。你仆人摩西的律法书上所记载的咒诅和审判都落在了我们身上，因为我们得罪了你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 5:9; 耶利米哀歌 1:12; 约伯记 12:17"> 你把大灾难降在我们身上，应验了你警告我们和我们官长的话。耶路撒冷遭遇的灾祸普天之下从未有过。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:15–68; 以赛亚书 9:13; 但以理书 9:11"> 这一切灾祸降在了我们身上，正如摩西律法书的记载。然而，我们的上帝耶和华啊，我们却没有离开罪恶，也没有认识你的真理并恳求你施恩。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 9:7; 尼希米记 9:33; 诗篇 51:14"> 所以耶和华决意使灾祸降在我们身上，因为我们的上帝耶和华的一切作为都是公义的，我们却没有听从祂的话。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 9:10; 出埃及记 32:11; 尼希米记 1:10"> “主——我们的上帝啊，你曾用大能的手把你的子民领出埃及，使自己威名远扬，如同今日。我们却犯罪作恶。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 8:3; 约珥书 3:17; 诗篇 87:1–3"> 主啊，你一向公义，求你息怒，别再向你的圣山耶路撒冷城发烈怒。由于我们的罪恶和我们祖先的过犯，耶路撒冷和你的子民成了四围邻人嘲讽的对象。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 80:19; 耶利米哀歌 5:18; 哥林多后书 1:20"> 我们的上帝啊，求你垂听仆人的祷告祈求，为你自己的缘故，以容光照耀你荒凉的圣所。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17; 耶利米书 36:7; 列王纪下 19:16"> 我的上帝啊，求你侧耳垂听，睁眼眷顾我们荒凉的土地和属于你名下的城。我们向你祈求，并非因为我们有什么义行，而是因为你充满怜悯。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 9:18; 以弗所书 1:12; 阿摩司书 7:2"> 主啊，求你垂听！主啊，求你赦免！主啊，求你垂听并行动！我的上帝啊，为你自己的缘故，求你不要耽延，因为这城和这民都属于你的名下。”</span>
</div>
</div>

## 加百列解释预言

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 145:18; 但以理书 9:3–4; 罗马书 3:23"> 我继续祷告，承认我和同胞以色列人的罪，为我上帝耶和华的圣山在祂面前祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理书 8:16; 列王纪上 18:36"> 我正祷告的时候，约在献晚祭时，先前在异象中看见的那位加百列奉命疾飞而来。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 9:24–27; 但以理书 10:21; 但以理书 8:16"> 他指教我说：“但以理啊，我现在来是要使你有智慧和悟性。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 10:19; 马太福音 24:15; 但以理书 10:11–12"> 你刚开始祈求，就已赐下答复，我是来告诉你的，因为你倍受眷爱。所以你要留意以下的信息，明白异象的意思。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:11–14; 罗马书 5:10; 耶利米书 23:5–6"> “已经为你的同胞和圣城定了七十个七，以终结叛逆，除掉罪恶，赎尽过犯，带来永远的公义，封住异象和预言，膏抹至圣所<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“至圣所”或译“至圣者”。">a</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 4:24; 以赛亚书 9:6; 以赛亚书 55:4"> 你要知道，也要明白，从重建耶路撒冷的命令发出，到受膏的君王来临，其间有七个七加六十二个七。耶路撒冷城及其广场和壕沟必得重建，且是在艰难时期。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:8; 那鸿书 1:8; 马可福音 13:2"> 六十二个七之后，受膏者必被杀害，一无所有。另有一王要兴起，他的臣民要毁灭这城和圣所。结局必如洪水冲来，战争将持续到末了，到处一片荒凉。这已经命定。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:15; 路加福音 21:20; 但以理书 12:11"> 那王必与许多人缔结一七之久的盟约。一七之半，他必终止祭牲和供物，并且在圣殿里设立带来毁灭的可憎之物，直到所定的结局临到这可憎者。”</span>
</div>
</div>

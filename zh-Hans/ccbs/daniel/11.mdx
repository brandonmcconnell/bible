<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:1; 但以理书 5:31; 但以理书 10:18"> “玛代人大流士元年，我去帮助、护卫米迦勒。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:5–6; 但以理书 8:26; 启示录 21:5"> 现在我要把真相告诉你。波斯将再有三位王兴起，随后的第四位王远比其他王富有。他靠财富强盛后，便会煽动众民去攻打希腊国。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 11:16; 但以理书 11:36; 但以理书 8:21"> 那时必有一位英勇的王兴起，执掌大权，随心所欲。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 8:22; 但以理书 8:8; 耶利米书 12:17"> 但他兴起后不久，他的国必土崩瓦解，在天下一分为四，既不归他的后代统治，也不如他掌权时强盛。因为他的国必被连根拔除，归给外人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 11:14; 但以理书 11:11; 但以理书 11:25"> “南方王必强盛，他的将领中将有一位比他更强盛，这人执掌王权，势力强大。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 11:13; 但以理书 11:40; 但以理书 11:7"> 若干年后，南方王将与北方王联盟。南方王的女儿将到北方王那里缔结盟约。但她必保不住自己的势力，王权也无法长久。她和她的随从、父亲及辅佐者必遭杀害。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理书 11:38–39; 但以理书 11:19–20; 以赛亚书 9:14"> “她家族中必有一人继承王位，率军攻打北方王的军队，侵入他的堡垒，击败他们，</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 37:19; 以赛亚书 46:1–2; 耶利米书 43:12–13"> 将他们的神像、铸造的偶像及金银宝器掳到埃及。此后数年，他不再去攻击北方王。</span>
<span className="v" id="v9" data-v="9"> 后来，北方王必侵入南方王的国土，但终必撤回本国。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 51:42; 但以理书 11:7; 但以理书 11:26"> “北方王的儿子们必发动战争，召集大军，如洪水席卷而来，直打到南方王的堡垒。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 8:7; 但以理书 11:5; 诗篇 33:16–17"> 南方王必大怒，出来迎战北方王的大军，并击败他们。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 12:22–23; 列王纪下 14:10; 以赛亚书 10:7–12"> 南方王获胜后必心高气傲，杀戮成千上万的人，但他的胜利不能持久。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 4:16; 但以理书 12:7; 但以理书 11:6–7"> 因为北方王必召集更庞大的军队，并于数年后带着大量装备卷土重来。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 17:17; 使徒行传 4:25–28"> “那时，许多人必起来反抗南方王。你同胞中的残暴之徒也必反叛，从而使异象应验，但他们必失败。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:6; 以西结书 17:17; 以西结书 4:2"> 北方王必修筑高台攻取南方王的坚城，南方的军兵必无力抵挡，就是精兵也抵挡不住。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 8:9; 但以理书 11:36; 但以理书 11:3"> 北方王必为所欲为，所向无敌。他必侵占佳美之地，手握毁灭之权。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 12:17; 以西结书 4:3; 以西结书 4:7"> 他决意倾全国之力而来，与南方王建立联盟，并将自己的女儿嫁给南方王，旨在推翻他的国。但北方王的计划必然失败，毫无收益。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="何西阿书 12:14; 耶利米书 31:10; 西番雅书 2:11"> “后来，他将转而攻打沿海地区，征服许多地方。但一位将领必终结他的嚣张气焰，使他自取其辱。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 26:21; 诗篇 37:36; 约伯记 20:8"> 他将返回本国的堡垒，从此一蹶不振，销声匿迹。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 60:17; 但以理书 11:7; 申命记 15:2–3"> 继承他王位的人将派税吏横征暴敛，以维持王国的荣耀。但不久他必灭亡，并非死于民怨，也非死于战争。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理书 11:34; 但以理书 8:25; 士师记 9:1–20"> “接着继位的是一个卑鄙的人。他无权继位，却乘人不备用奸计篡位。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 8:10–11; 但以理书 11:10; 但以理书 9:26"> 他横扫千军，击溃他们，包括盟国的王。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 8:25; 帖撒罗尼迦后书 2:9; 诗篇 52:2"> 他与人结盟后，必行欺诈，借不多的人掌握大权。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:25; 箴言 23:7; 马太福音 9:4"> 他必乘人不备入侵最富庶的地区，行他祖先从未行过的事，将掳掠的财物分给部下，并策划攻打堡垒，但这都是短暂的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; 但以理书 11:2; 箴言 28:25"> 他集中力量，鼓起勇气，率领大军进攻南方王。南方王也率领强大的军队迎战，却敌不过他，因为有人暗算南方王。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 11:10; 但以理书 11:40; 撒母耳记下 4:2–12"> 南方王必遭亲信暗算，全军溃败，许多人被杀。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 12:2; 耶利米书 9:3–5; 哈巴谷书 2:3"> 两个王心怀叵测，同席而坐，尔虞我诈，但都不成功，因为结局必在所定的时间到来。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 11:30–32; 但以理书 8:24; 使徒行传 3:25"> 北方王必带着大量财物回国，但他决意反对圣约。他必任意妄为，然后返回本国。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 17:26; 以赛亚书 14:31; 但以理书 11:25"> “到了所定的时间，他必再次攻打南方，但结果与上次不同，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 10:4; 民数记 24:24; 耶利米书 2:10"> 因为基提的战船必来攻击他，使他丧胆而回。他必恼恨圣约，任意妄为，回来支持背弃圣约的人。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 12:11; 但以理书 9:27; 马太福音 24:15"> 他的军队必亵渎作圣所的堡垒，废除日常献的祭，设立带来毁灭的可憎之物。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 28:9; 诗篇 9:10; 约翰福音 17:3"> 他必花言巧语笼络违背圣约的人，但认识上帝的人必奋起反抗。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 24:9; 约翰福音 16:2; 玛拉基书 2:7"> 那些智者必教导许多民众，但他们将在一段时间内被刀剑杀戮，或被烧死，或被掳去，或被抢掠。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 7:15; 罗马书 16:18; 使徒行传 20:29–30"> 他们倒下时会得到一点援助，许多人并非真心实意地加入他们的行列。</span>
<span className="v" id="v35" data-v="35" data-xref="撒迦利亚书 13:9; 玛拉基书 3:2–4; 启示录 2:10"> 有些智者将被害，但这是为了熬炼、净化他们，使他们洁白无瑕，一直到末了。因为结局必在所定的时间到来。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="启示录 13:5–6; 帖撒罗尼迦后书 2:4; 申命记 10:17"> “北方王必任意妄为，自高自大，自以为超越一切神明，肆意诋毁万神之神。他必亨通，一直到上帝发烈怒的日子结束。因为所定的必定成就。</span>
<span className="v" id="v37" data-v="37" data-xref="帖撒罗尼迦后书 2:4; 以赛亚书 14:13; 提摩太前书 4:3"> 他不尊崇他祖先的神明，也不尊崇妇女们爱慕的神明或其他任何神明，因为他自认为超越一切。</span>
<span className="v" id="v38" data-v="38" data-xref="启示录 17:1–5; 以赛亚书 44:9; 启示录 13:12–17"> 他反倒敬奉他祖先不认识的堡垒之神，向它献上金银宝石及贵重的礼物。</span>
<span className="v" id="v39" data-v="39" data-xref="启示录 18:9–13"> 他必靠外族神明的帮助攻打坚固的堡垒，将极大的尊荣赐给顺从他的人，派他们治理民众，分给他们土地作奖赏。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="但以理书 11:35; 但以理书 11:10; 以赛亚书 5:28"> “到了末后，南方王必与北方王交战。北方王必率领战车、骑兵和大批战船攻击他，又如洪水般横扫列国。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 48:47; 耶利米书 49:6; 以赛亚书 11:13–15"> 他必侵入佳美之地，杀死成千上万的人，只有以东、摩押及亚扪人的首领得以逃脱。</span>
<span className="v" id="v42" data-v="42" data-xref="撒迦利亚书 10:10–11; 以西结书 29:14; 启示录 11:8"> 他必攻击列国，埃及也无法逃脱。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 12:3; 那鸿书 3:9; 以西结书 30:4–5"> 他必掌管埃及的金银财宝，利比亚人和古实人必归顺他。</span>
<span className="v" id="v44" data-v="44" data-xref="启示录 19:19–21; 启示录 16:12; 启示录 17:13"> 但从东方和北方传来的消息必令他震惊，他必大怒，出兵杀戮、毁灭许多人。</span>
<span className="v" id="v45" data-v="45" data-xref="帖撒罗尼迦后书 2:4; 但以理书 8:25; 启示录 19:19–21"> 他必在海和荣美的圣山之间搭起他宫殿般的帐幕。但他必灭亡，无人相助。</span>
</div>
</div>

## 尼布甲尼撒的第二个梦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="但以理书 6:25; 彼得前书 1:2; 但以理书 3:4"> 尼布甲尼撒王传谕天下各族、各邦、各语种的人：“愿你们大享平安！</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:26; 诗篇 66:16; 诗篇 71:18"> 我乐意向你们述说至高的上帝对我所行的神迹奇事。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 145:13; 以赛亚书 25:1; 但以理书 2:44"> <span className="pl pl-1">“祂的神迹何其伟大！</span><br /><span className="pl pl-1">祂的奇事何其可畏！</span><br /><span className="pl pl-1">祂的国度永远长存，</span><br /><span className="pl pl-1">祂的统治直到万代。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 47:7–8; 帖撒罗尼迦前书 5:2–3; 诗篇 30:6–7"> “我尼布甲尼撒安居在家，在宫中享受荣华。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 2:1; 约伯记 7:13–14; 但以理书 2:28–29"> 但我做了一个梦，让我害怕。我躺在床上的时候，脑中出现的情景和异象使我恐惧。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 2:2; 创世记 41:7–8; 以赛亚书 8:19"> 我便召巴比伦所有的智者来为我解梦。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 44:25; 但以理书 2:7; 创世记 41:8"> 术士、巫师、占星家和占卜者都来了，我将梦告诉他们，他们却不能给我解梦。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 1:7; 但以理书 5:14; 但以理书 4:18"> 最后但以理来到我面前，他又名伯提沙撒，取自我神明的名，他有圣洁神明的灵。我将梦告诉他，说，</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 2:48; 但以理书 5:11; 但以理书 4:8"> ‘术士的首领伯提沙撒啊，我知道你有圣洁神明的灵，任何奥秘都难不倒你。请你为我解释我梦中所见的异象。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 12:2; 但以理书 4:5; 诗篇 37:35–36"> “‘以下是我躺在床上时脑中出现的异象：我看见大地中央有棵非常高大的树。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 4:21–22; 申命记 9:1; 马太福音 11:23"> 这树长得苍劲有力，高可参天，从地极都能看见。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西结书 31:6–7"> 它的叶子美丽，果实累累，可作众生的食物。野兽在它的荫下躺卧，飞鸟在它的枝头栖息，一切生命都从它那里得到食物。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 33:2; 但以理书 8:13; 但以理书 7:1"> “‘我躺在床上时脑中出现了异象，我看见一位圣洁的守望者从天而降。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 3:10; 但以理书 4:23; 以西结书 31:12–13"> 他大声说，砍倒那棵树，削掉它的枝子，剥光它的叶子，抛散它的果子，使野兽逃离树下，飞鸟离开枝头。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 14:7–9; 但以理书 4:25–27; 以西结书 29:14–15"> 但把树桩留在地里，用铁环和铜环箍住留在野地的青草中，让他被天上的露水浸湿，与野兽一起住在草中。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 4:23; 启示录 12:14; 但以理书 4:25"> 要改变他的人心，给他一个兽心，达七年之久。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 4:25; 但以理书 2:21; 诗篇 75:6–7"> 这是守望者的命令，是圣者的决定，要让众生知道至高者主宰世上万国，祂要把国赐给谁就赐给谁，即使是最卑微的人。’</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理书 5:15; 创世记 41:8; 但以理书 5:8"> “这就是我尼布甲尼撒王所做的梦。伯提沙撒啊，你要为我解梦，因为我国中所有的智者都不能为我解梦。但是你能，因为你里面有圣洁神明的灵。”</span>
</div>
</div>

## 但以理解梦

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 8:27; 但以理书 7:28; 但以理书 4:24"> 但以理，又名伯提沙撒，一时非常惊讶，惶恐不安。王说：“伯提沙撒啊，不要因为这梦和梦的意思而惶恐不安。”伯提沙撒回答说：“我主啊，愿这梦发生在恨你的人身上，梦的意思应验在你的仇敌身上。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 4:10–12; 以西结书 31:3; 以西结书 31:16"> 你梦见的树苍劲高大，高可参天，从地极都能看见。</span>
<span className="v" id="v21" data-v="21"> 它的叶子美丽，果实累累，可作众生的食物。野兽住在它的荫下，飞鸟宿在它的枝头。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 2:37–38; 撒母耳记下 12:7; 耶利米书 27:6–8"> 王啊，这苍劲高大的树就是你，你的威名高达穹苍，你的权柄延至地极。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 5:21; 但以理书 4:13–16"> 王看见圣洁的守望者从天而降，说，‘将这树砍倒、毁灭，但把树桩用铁环和铜环箍住留在野地的青草中，让他被天上的露水浸湿，与野兽一起吃草七年。’</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:40; 约伯记 40:11–12; 以赛亚书 46:10–11"> “王啊，以下是梦的意思，是至高者裁定要临到我主我王的事：</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 4:17; 耶利米书 27:5; 诗篇 83:18"> 你必从人群中被赶走，与野兽同住，像牛一样吃草，被天上的露水浸湿，达七年之久，直到你知道至高者主宰世上万国，祂要把国赐给谁就赐给谁。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 4:15; 马太福音 5:34; 马太福音 21:20"> 守望者命令留下树桩，表示等到你承认上天掌权后，你将重掌国权。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 55:6–7; 约拿书 3:9; 使徒行传 8:22"> 王啊，请接受我的劝谏，你要秉公行义，以断绝罪恶；怜悯穷人，以除掉罪过。这样，你的国运也许可以延续。”</span>
</div>
</div>

## 梦兆应验

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数记 23:19; 撒迦利亚书 1:6; 箴言 10:24"> 这一切事果然发生在尼布甲尼撒王身上。</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 2:21; 传道书 8:11; 彼得前书 3:20"> 十二个月后，他在巴比伦王宫的屋顶散步时，</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 启示录 18:10; 路加福音 14:11"> 说：“这宏伟的巴比伦岂不是我用大能建立为京都，以显我的威严和荣耀吗？”</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:3–5; 启示录 16:7; 路加福音 12:20"> 话未说完，天上就有声音传来，说：“尼布甲尼撒王啊，你听着，你已失去王权。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 27:5; 但以理书 5:21; 箴言 8:15–16"> 你必从人群中被赶走，与野兽同住，像牛一样吃草，达七年之久，直到你知道至高者主宰世上万国，祂要把国赐给谁就赐给谁。”</span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 4:32; 但以理书 4:25; 但以理书 5:5"> 这话立刻应验在尼布甲尼撒身上。他从人群中被赶走，像牛一样吃草，身体被天上的露水浸湿，直到他的头发长如鹰毛，指甲长如鸟爪。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="启示录 4:10; 耶利米书 10:10; 但以理书 12:7"> “七年后，我尼布甲尼撒举目望天，恢复了神智，便称颂至高者，赞美、尊崇永活者。<br /><span className="pl pl-1">“祂的统治永无穷尽，</span><br /><span className="pl pl-1">祂的国度直到万代。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 42:2; 诗篇 135:6; 诗篇 115:3"> <span className="pl pl-1">世人都微不足道，</span><br /><span className="pl pl-1">祂在天军和世人中独行其旨，</span><br /><span className="pl pl-1">无人能拦阻祂的手，</span><br /><span className="pl pl-1">或质问祂的作为。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理书 4:34; 箴言 22:4; 但以理书 4:15–16"> “那时，我恢复了神智，也恢复了我的威严和荣耀，重现我国度的辉煌。我的谋士和大臣都来朝见我，我重掌国权，权势比以前更大。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 4:6–7; 诗篇 33:4–5; 彼得前书 5:5–6"> 现在我尼布甲尼撒颂赞、尊崇、敬奉天上的王，因为祂的作为公正，祂行事公平，能够贬抑行为骄傲的人。”</span>
</div>
</div>

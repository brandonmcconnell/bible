## 金像和火窑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷书 2:19; 耶利米书 16:20; 以赛亚书 46:6"> 尼布甲尼撒王造了一尊高二十七米、宽两米七的金像，立在巴比伦省的杜拉平原。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:27; 箴言 29:12; 列王纪上 12:32"> 他派人召集总督、行政官、省长、谋士、库房官、审判官、司法官及各省的所有官员，前来参加他所立之像的敬奉礼。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:17; 启示录 17:13; 启示录 13:13–16"> 于是总督、行政官、省长、谋士、库房官、审判官、司法官及各省的官员，齐来参加尼布甲尼撒王所立之像的敬奉礼，站在那像面前。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理书 4:1; 但以理书 6:25; 弥迦书 6:16"> 传令官大声宣布说：“各族、各邦、各语种的人啊，王有令，</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:15; 但以理书 3:10; 但以理书 3:7"> ‘你们一听见角、笛、弦琴、竖琴、瑟、笙等各种乐器奏响，就要叩拜尼布甲尼撒王所立的金像。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:50; 马太福音 13:42; 耶利米书 29:22"> 不叩拜的人必立刻被抛进烈焰熊熊的火窑。’”</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 17:8; 启示录 13:3; 启示录 13:8"> 于是，各族、各邦、各语种的人一听见角、笛、弦琴、竖琴、瑟等各种乐器的声音，就都叩拜尼布甲尼撒王所立的金像。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–16; 但以理书 6:12–13; 以斯帖记 3:8–9"> 那时，有几个占星家前来控告犹大人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:10; 但以理书 6:6; 但以理书 6:21"> 他们对尼布甲尼撒王说：“愿王万岁！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 3:4–7; 但以理书 6:12; 以斯帖记 3:12–14"> 王啊，你已下令，角、笛、弦琴、竖琴、瑟、笙等各种乐器一奏响，每个人都要叩拜金像。</span>
<span className="v" id="v11" data-v="11"> 不叩拜的人必被扔进烈焰熊熊的火窑。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 6:13; 但以理书 2:49; 使徒行传 17:7"> 然而，王啊，有几个犹大人，就是王委派负责巴比伦省事务的沙得拉、米煞和亚伯尼歌，却不理会你的命令，不事奉你的神明，也不祭拜你立的金像。”</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 3:19; 但以理书 2:12; 以斯帖记 3:5–6"> 尼布甲尼撒王勃然大怒，下令将沙得拉、米煞、亚伯尼歌带来。于是他们被带到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 50:2; 但以理书 3:1; 以赛亚书 46:1"> 尼布甲尼撒问他们：“沙得拉、米煞和亚伯尼歌啊，你们真的不事奉我的神明，不祭拜我立的金像吗？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 5:29; 历代志下 32:15–17; 出埃及记 5:2"> 现在你们准备好，一听见角、笛、弦琴、竖琴、瑟、笙等各种乐器的声音，就要叩拜我造的像。不然，必立刻将你们扔进烈焰熊熊的火窑。那时什么神明能从我手中救你们呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:7; 但以理书 3:12"> 沙得拉、米煞和亚伯尼歌答道：“尼布甲尼撒啊，我们无需为此事回答你。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:31; 路加福音 1:37; 希伯来书 7:25"> 王啊，我们若真被扔进烈焰熊熊的火窑，我们所事奉的上帝必能救我们脱离火窑，祂必从你手中救我们。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:29–32; 马太福音 10:39; 启示录 2:10–11"> 即或不然，王啊，你要明白，我们也不会事奉你的神明或祭拜你立的金像。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 3:13; 利未记 26:24; 箴言 21:24"> 尼布甲尼撒怒气填胸，向沙得拉、米煞和亚伯尼歌大发雷霆，下令将火窑烧得比平时热七倍，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:23; 使徒行传 16:25; 但以理书 3:15"> 又命令军中的勇士将沙得拉、米煞和亚伯尼歌绑起来，扔进烈焰熊熊的火窑。</span>
<span className="v" id="v21" data-v="21"> 这三人穿着外袍、裤子等衣物，戴着头巾，被绑着扔进烈焰熊熊的火窑。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:33; 箴言 21:18; 箴言 11:8"> 因为王的命令紧急，窑烧得非常热，火焰烧死了那些抬沙得拉、米煞和亚伯尼歌的人。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 6:16–17; 耶利米书 38:6; 诗篇 34:19"> 沙得拉、米煞和亚伯尼歌三人被绑着落入烈焰熊熊的火窑。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理书 6:7; 但以理书 6:22; 但以理书 3:9–10"> 这时，尼布甲尼撒王惊奇地跳起来，问谋士：“我们绑起来扔进火里的不是三个人吗？”他们答道：“王啊，是的。”</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:2; 使徒行传 28:5; 马可福音 16:18"> 王说：“看啊，我见有四个人在火中走来走去，没有被绑着，也没有被烧伤，第四个人的面貌好像神明的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理书 3:17; 以赛亚书 52:12; 启示录 19:5"> 于是，尼布甲尼撒走近火窑的门，喊道：“至高上帝的仆人沙得拉、米煞和亚伯尼歌啊，出来吧，到这里来吧。”沙得拉、米煞和亚伯尼歌便从火中出来。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 43:2; 希伯来书 11:34; 以赛亚书 26:11"> 那些总督、行政官、省长和王的谋士上前围观，见火焰没有烧伤他们的身体，他们的头发没有烧焦，衣服没有烧坏，身上甚至没有火燎的气味。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 14:7–8; 诗篇 34:7–8; 诗篇 84:11–12"> 尼布甲尼撒说：“沙得拉、米煞和亚伯尼歌的上帝当受称颂！祂差遣天使拯救祂的仆人。他们信靠祂，无视王命，宁肯舍命也不供奉、祭拜其他神明。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:5; 诗篇 76:10; 申命记 32:31"> 现在我下令，不论何民、何邦、何族，若毁谤沙得拉、米煞和亚伯尼歌的上帝，必被碎尸万段，他们的家必沦为废墟，因为没有别的神明能这样施行拯救。”</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 2:49; 撒母耳记上 2:30; 但以理书 3:12"> 于是，王让沙得拉、米煞、亚伯尼歌在巴比伦省身居高位。</span>
</div>
</div>

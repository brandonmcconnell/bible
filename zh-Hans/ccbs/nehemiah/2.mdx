## 尼希米返回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:1; 尼希米记 1:11; 尼希米记 1:1"> 亚达薛西王二十年尼散月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“尼散月”即希伯来历的一月，阳历是三月中旬到四月中旬。">a</a></sup>，酒呈到王面前后，我端起酒递给王。在王面前，我一向没有愁容。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 15:13; 创世记 40:7"> 王问我：“你没有病，为什么面带愁容？一定是心中烦恼。”我非常害怕。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 1:3; 但以理书 2:4; 列王纪上 1:31"> 我对王说：“愿王万岁！我祖坟所在的城邑已成废墟，城门也被烧毁，我怎能不面带愁容？”</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 箴言 3:6; 尼希米记 1:4"> 王问我：“你有什么要求？”我向天上的上帝祷告后，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:22; 路得记 2:13; 以斯帖记 7:3"> 回答说：“如果王认为好，如果仆人在王面前蒙恩，请王派我到犹大，重建我祖坟所在的城邑。”</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 13:6; 以赛亚书 65:24; 尼希米记 5:14"> 当时王后坐在王的旁边，王问我：“你要去多久？什么时候回来？”我告诉王一个日期，王欣然批准我去。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:21; 以斯拉记 8:36; 尼希米记 2:9"> 我又说：“如果王认为好，求王赐我诏书，通知河西总督准我通行前往犹大。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:6; 以赛亚书 66:14; 尼希米记 7:2"> 求王再发一道诏书，通知管理王室园林的亚萨，吩咐他供给我木材，用来做圣殿堡垒的门梁及建造城墙和我住的房子。”王批准了我的请求，因为我的上帝施恩帮助我。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 8:22"> 王派将领率骑兵沿途护送我。到了河西总督那里，我把王的诏书交给他们。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 2:19; 尼希米记 4:7; 尼希米记 13:4"> 和伦人参巴拉和官长亚扪人多比雅听到有人来帮以色列人谋求好处，非常不悦。</span>
</div>
</div>

## 尼希米视察耶路撒冷的城墙

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 8:32"> 我到了耶路撒冷，在那里住了三天，</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:17; 以斯拉记 7:27; 耶利米书 31:33"> 然后在夜间起来，带着几个人出去。上帝感动我要为耶路撒冷做的事，我没有告诉任何人。除了我骑的牲口外，我们没有带其他牲口。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 1:3; 尼希米记 2:3; 尼希米记 3:13–14"> 我乘夜穿过谷门，朝龙泉的方向走到粪厂门，在那里察看耶路撒冷倒塌的城墙和被烧毁的城门。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 3:15; 列王纪下 20:20; 历代志下 32:30"> 我又往前走到泉门和王池，我骑的牲口无法通过那里，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:23; 约翰福音 18:1; 耶利米书 31:38–40"> 我就乘夜沿溪而上，察看城墙，然后转身取道谷门回城。</span>
<span className="v" id="v16" data-v="16"> 官员不知道我到过哪里，做过何事，因为我还没有向犹太人、祭司、贵族、官员和其他要参与这工程的人透露我的计划。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 5:14; 尼希米记 1:3; 以赛亚书 35:3–4"> 后来我对他们说：“你们都看到了我们的困境。耶路撒冷已成废墟，城门也被烧毁。来吧，让我们重建耶路撒冷的城墙，免得我们再受凌辱。”</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:13; 历代志下 32:5; 历代志上 19:13"> 然后，我把我的上帝怎样施恩帮助我，以及王对我说的话都告诉了他们。他们就说：“我们起来重建城墙吧！”于是他们开始做这善工。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:6; 尼希米记 6:1–2; 诗篇 44:13–14"> 但和伦人参巴拉和官长亚扪人多比雅，以及阿拉伯人基善听说后，就讥笑我们，藐视我们，说：“你们在做什么？想要背叛王吗？”</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 8:21; 以斯拉记 4:3; 诗篇 35:27"> 我回答他们说：“天上的上帝必使我们亨通，我们身为祂仆人，要起来重建这城墙，但你们在耶路撒冷无份、无权、无业。”</span>
</div>
</div>

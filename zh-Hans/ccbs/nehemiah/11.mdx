## 住在耶路撒冷的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 48:2; 以赛亚书 52:1; 尼希米记 11:18"> 民众的首领住在耶路撒冷。其余的人用抽签的方式抽出十分之一的人口住在圣城耶路撒冷，剩下的人则住在其他城邑。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 5:9; 哥林多后书 8:16–17; 约伯记 29:13"> 众人为所有自愿住在耶路撒冷的人祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:1; 以斯拉记 2:43; 历代志上 9:1–34"> 以色列人、祭司、利未人、殿役和所罗门仆人的子孙住在犹大各城自己的家园，有些来自犹大和便雅悯的人住在耶路撒冷。以下是住在耶路撒冷的犹大省首领： 犹大人中有法勒斯的子孙、乌西雅的儿子亚他雅。乌西雅是撒迦利雅的儿子，撒迦利雅是亚玛利雅的儿子，亚玛利雅是示法提雅的儿子，示法提雅是玛勒列的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:5; 尼希米记 3:15; 民数记 26:20"> 此外还有巴录的儿子玛西雅。巴录是谷何西的儿子，谷何西是哈赛雅的儿子，哈赛雅是亚大雅的儿子，亚大雅是约雅立的儿子，约雅立是撒迦利雅的儿子，撒迦利雅是示罗尼的儿子。</span>
<span className="v" id="v6" data-v="6"> 住在耶路撒冷的法勒斯的子孙共有四百六十八人，都是勇士。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 9:7–9"> 便雅悯人中有米书兰的儿子撒路。米书兰是约叶的儿子，约叶是毗大雅的儿子，毗大雅是歌赖雅的儿子，歌赖雅是玛西雅的儿子，玛西雅是以铁的儿子，以铁是耶筛亚的儿子。</span>
<span className="v" id="v8" data-v="8"> 此外还有迦拜和撒来，共九百二十八人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 9:7"> 细基利的儿子约珥是他们的监督，哈西努亚的儿子犹大是耶路撒冷的副官。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 9:10; 尼希米记 12:6; 尼希米记 12:19"> 祭司中有雅斤，约雅立的儿子耶大雅，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 9:11; 历代志上 6:7–14; 民数记 3:32"> 以及管理上帝殿的西莱雅，他是希勒迦的儿子，希勒迦是米书兰的儿子，米书兰是撒督的儿子，撒督是米拉约的儿子，米拉约是亚希突的儿子；</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:12–13"> 还有他们在殿里供职的弟兄，共八百二十二人；还有耶罗罕的儿子亚大雅，耶罗罕是毗拉利的儿子，毗拉利是暗洗的儿子，暗洗是撒迦利亚的儿子，撒迦利亚是巴施户珥的儿子，巴施户珥是玛基雅的儿子；</span>
<span className="v" id="v13" data-v="13"> 还有他们做族长的弟兄，共二百四十二人；还有亚萨列的儿子亚玛帅，亚萨列是亚哈赛的儿子，亚哈赛是米实利末的儿子，米实利末是音麦的儿子；</span>
<span className="v" id="v14" data-v="14"> 还有他们英勇的弟兄，共一百二十八人。他们的监督是哈基多琳的儿子撒巴第业。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 9:14; 历代志上 9:19"> 利未人中有哈述的儿子示玛雅。哈述是押利甘的儿子，押利甘是哈沙比雅的儿子，哈沙比雅是布尼的儿子。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 6:2–3; 尼希米记 8:7; 以斯拉记 8:33"> 还有利未人的族长沙比太和约撒拔，他们负责上帝殿外面的事务。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 9:15; 历代志上 25:1–6; 尼希米记 12:8–9"> 还有米迦的儿子玛他尼，他是带领祷告和赞美的。米迦是撒底的儿子，撒底是亚萨的儿子。还有他的助手玛他尼的弟兄八布迦。此外，还有沙姆亚的儿子押大。沙姆亚是加拉的儿子，加拉是耶杜顿的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米记 11:1; 启示录 21:2; 但以理书 9:24"> 在圣城的利未人共有二百八十四名。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 7:45; 历代志上 9:17–22; 诗篇 84:10"> 殿门守卫有亚谷和达们，还有他们做殿门守卫的弟兄，共一百七十二人。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 11:3"> 其他以色列人、祭司和利未人住在犹大各城自己的家园。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 3:26; 历代志下 27:3; 尼希米记 3:31"> 殿役住在俄斐勒，他们的首领是西哈和基斯帕。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:42; 历代志上 25:1–6; 以斯拉记 8:19"> 在耶路撒冷的利未人的监督是巴尼的儿子乌西，巴尼是哈沙比雅的儿子，哈沙比雅是玛他尼的儿子，玛他尼是米迦的儿子。乌西是亚萨的子孙，亚萨的子孙是负责圣殿事务的歌乐手。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 7:20–24; 尼希米记 12:47; 以斯拉记 6:8–9"> 歌乐手每天应尽的责任由王决定。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 38:30; 历代志上 18:17; 历代志上 23:28"> 犹大的儿子谢拉的子孙、米示萨别的儿子毗他希雅帮助王处理民众的事务。</span>
</div>
</div>

## 住在其他城邑的人

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 14:15; 约书亚记 15:21–22"> 至于村庄及其周围的田地，一些犹大人住在基列·亚巴、底本、叶甲薛和它们周围的村庄，</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 15:26–27; 约书亚记 19:2"> 耶书亚、摩拉大、伯·帕列、</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:33; 约书亚记 15:28; 士师记 20:1"> 哈萨·书亚、别示巴和别示巴周围的村庄，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 27:6; 约书亚记 15:31"> 洗革拉、米哥拿和米哥拿周围的村庄，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:41; 约书亚记 15:32–33; 约书亚记 15:35"> 音·临门、琐拉、耶末、</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 10:3; 约书亚记 15:8; 约书亚记 18:16"> 撒挪亚、亚杜兰和它们周围的村庄，拉吉及其周围的田地，亚西加及其周围的村庄。他们居住的地方从别示巴一直延伸到欣嫩谷。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 12:8; 约书亚记 8:9; 约书亚记 18:13"> 便雅悯人住的地方由迦巴起直到密抹、亚雅、伯特利和伯特利周围的村庄，</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:18; 以赛亚书 10:30; 撒母耳记上 21:1"> 亚拿突、挪伯、亚南雅、</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 4:3; 撒母耳记上 7:17; 约书亚记 18:25"> 夏琐、拉玛、基他音、</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 13:18"> 哈第、洗编、尼八拉、</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 8:12; 尼希米记 7:37; 历代志上 4:14"> 罗德、阿挪和匠人之谷。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 21:1–45; 创世记 49:7; 历代志上 6:54–81"> 一些原本住在犹大的利未人被安顿在便雅悯。</span>

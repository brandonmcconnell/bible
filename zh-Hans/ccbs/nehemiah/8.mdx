## 以斯拉宣读律法书

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:6; 尼希米记 3:26; 历代志下 34:15"> 全体民众齐心聚集在水门前的广场上。他们请律法教师以斯拉带来耶和华借摩西颁给以色列人的律法书。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:24; 玛拉基书 2:7; 民数记 29:1"> 七月一日，以斯拉祭司把律法书带到能听懂的男女会众面前，</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:22; 启示录 2:29; 希伯来书 2:1–3"> 面向水门前的广场，从清早到正午一直向他们宣读律法书，民众都侧耳倾听。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 10:29; 尼希米记 12:13; 尼希米记 10:20"> 律法教师以斯拉站在为这聚会预备的木台上，站在他右边的是玛他提雅、示玛、亚奈雅、乌利亚、希勒迦和玛西雅；站在他左边的是毗大雅、米沙利、玛基雅、哈顺、哈拔大拿、撒迦利亚和米书兰。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 3:20; 列王纪上 8:14; 路加福音 4:16–17"> 以斯拉站在高处，他在全体会众面前一打开书卷，他们都站了起来。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 2:8; 耶利米哀歌 3:41; 出埃及记 4:31"> 以斯拉称颂伟大的上帝耶和华，全体民众都举手应声说：“阿们！阿们！”他们又面伏于地，俯伏敬拜耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 9:4; 利未记 10:11; 尼希米记 3:23"> 耶书亚、巴尼、示利比、雅悯、亚谷、沙比太、荷第雅、玛西雅、基利他、亚撒利雅、约撒拔、哈难、毗莱雅和利未人帮助民众明白律法，当时民众都站在那里。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:45; 使徒行传 28:23; 路加福音 24:32"> 他们宣读上帝的律法书，并解释清楚，使民众明白所宣读的。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 7:65; 尼希米记 7:70; 申命记 12:12"> 全体民众听到律法书上的话都哭了。尼希米省长、律法教师以斯拉祭司和教导民众的利未人对他们说：“今天是你们上帝耶和华的圣日，不要悲哀、哭泣。”</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 28:7–8; 箴言 17:22; 哥林多后书 12:8–9"> 尼希米又说：“你们去吃肥美的肉，喝甘甜的酒，并分些给没有预备的人，因为今天是我们主的圣日。不要悲伤，因为从耶和华而来的喜乐是你们的力量。”</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 13:30"> 利未人使全体民众安静，说：“请安静，因为今天是圣日。不要悲伤。”</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 119:174; 诗篇 119:111; 诗篇 119:130"> 于是，全体民众去吃喝，并分给他人，非常欢喜，因为他们明白了教导给他们的话。</span>
</div>
</div>

## 守住棚节

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 2:1–6; 箴言 8:33–34; 箴言 12:1"> 第二天，全体民众的族长、祭司和利未人都到律法教师以斯拉那里，要深入研究律法上的话。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 23:34; 申命记 16:13–15; 利未记 23:40–43"> 当时，他们发现耶和华借摩西吩咐的律法上记载，以色列人要在七月节期期间住在棚子里，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 23:40; 申命记 16:16; 利未记 23:4"> 并且要在各城邑和耶路撒冷宣布和传扬以下信息：“你们要上山取橄榄树、野橄榄树、番石榴树、棕树和其他茂密树木的枝子，照着所规定的搭棚。”</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 12:39; 列王纪下 14:13; 尼希米记 12:37"> 于是，民众都出去取来树枝，在自家的屋顶上、庭院里、上帝殿的院子里、水门的广场上和以法莲门的广场上搭棚。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 8:13; 以斯拉记 3:4; 历代志下 7:8–10"> 从流亡之地归回的民众都搭起棚子，住在里面。从嫩的儿子约书亚时代直到那天，以色列人从没有这样做过。民众非常欢喜。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 29:35; 利未记 23:36; 申命记 31:10–13"> 从第一天到最后一天，以斯拉每天都诵读上帝的律法书。他们守节期七天，第八天根据典章举行庄严的聚会。</span>
</div>
</div>

## 以色列人认罪祷告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 13:2–3; 以斯拉记 8:23; 尼希米记 8:2"> 这月二十四日，以色列人聚集禁食。他们身披麻衣，头撒尘土。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 9:3–10; 尼希米记 13:3; 以斯拉记 10:11"> 以色列人与其他外族人隔离，站着承认自己的罪恶和祖先的过犯。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 8:7–8; 尼希米记 8:3–4"> 他们站在自己的地方，宣读他们上帝耶和华的律法书，长达三个小时<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“三个小时”希伯来文是“一天的四分之一”。">a</a></sup>。他们又用了三个小时认罪，敬拜他们的上帝耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 8:7; 尼希米记 12:8; 尼希米记 9:5"> 利未人耶书亚、巴尼、甲篾、示巴尼、布尼、示利比、巴尼和基拿尼站在台阶上，大声呼求他们的上帝耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 103:1–2; 彼得前书 1:3; 哥林多后书 4:6"> 利未人耶书亚、甲篾、巴尼、哈沙尼、示利比、荷第雅、示巴尼和毗他希雅说：“起来称颂你们的上帝耶和华，直到永永远远。耶和华啊，你荣耀的圣名当受称颂！愿你的名被尊崇，超过一切称颂和赞美！</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:16; 创世记 1:1; 启示录 4:11"> “你，唯有你是耶和华！你创造了天、天上的天和天上的万象、地和地上的一切、海和海中的一切，你赐给万物生命。众天军都敬拜你。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 11:31; 创世记 17:5; 以赛亚书 51:2"> 你是耶和华上帝，你拣选了亚伯兰，带他离开迦勒底的吾珥，又给他改名为亚伯拉罕。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:6; 创世记 15:18–21; 希伯来书 6:18"> 你知道他对你忠心，就与他立约，把迦南人、赫人、亚摩利人、比利洗人、耶布斯人及革迦撒人的土地赐给他的后代。你实现了你的应许，因为你是公义的。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:7–9; 使徒行传 7:34; 出埃及记 3:16"> “你看见我们祖先在埃及所受的苦，又听见他们在红海边的呼求，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:20; 但以理书 9:15; 出埃及记 18:11"> 就行神迹奇事对付法老及其所有的臣仆和国民，因为你知道他们对以色列人行事狂傲。你使自己威名远扬直到今日。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:13; 出埃及记 14:21–22; 出埃及记 14:27–28"> 你在我们祖先面前把海水分开，使他们在海中走干地过去；你把追赶他们的人扔进深海，好像把石头扔进大水中。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 13:21–22; 尼希米记 9:19; 诗篇 107:7"> 白天，你用云柱带领他们；夜间，你用火柱照亮他们当走的路。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:160; 出埃及记 20:1; 诗篇 119:127–128"> 你降临在西奈山，从天上与他们说话，赐给他们公正的典章、信实的律法、美好的律例和诫命。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 20:8–11; 创世记 2:3; 以西结书 20:12"> 你使他们知道你的神圣安息日，借你仆人摩西赐给他们诫命、律例和法度。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 10:3–4; 申命记 1:8; 出埃及记 17:6"> 他们饿了，你赐下天粮给他们吃；他们渴了，你使磐石流出水给他们喝。你吩咐他们去占领你起誓要赐给他们的土地。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 9:29; 诗篇 81:11–14; 希伯来书 3:15"> 但我们的祖先行事狂傲，顽固不化，不肯听从你的诫命。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 86:5; 约珥书 2:13; 诗篇 145:8–9"> 他们拒绝听从，忘记了你为他们所行的奇事，顽固不化，自立首领要回埃及做奴隶。但你是乐意饶恕，有恩典，好怜悯，不轻易发怒，充满慈爱的上帝，你没有离弃他们。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 106:19–23; 出埃及记 32:4–8; 以西结书 20:7–44"> 纵使他们为自己铸造了一头牛犊，声称那是带他们出埃及的上帝，大大亵渎了你，</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 106:45; 尼希米记 9:27; 玛拉基书 3:6"> 你还是对他们大施怜悯，没有在旷野离弃他们。白天，云柱没有离开他们，仍然引导他们前行；夜间，火柱仍然照亮他们当走的路。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 143:10; 民数记 11:17; 以赛亚书 63:11–14"> 你差遣你良善的灵去教导他们，没有停止赐他们吗哪吃，也没有停止赐他们水喝。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 2:7; 申命记 8:4; 诗篇 34:10"> 在旷野的四十年间，你供养他们，使他们一无所缺，他们的衣服没有穿破，脚也没有走肿。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 21:21–35; 申命记 3:1–17; 申命记 2:26–36"> “你将列国列邦赐给他们，为他们划分疆界，他们占领了希实本王西宏和巴珊王噩的土地。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 22:17; 创世记 15:5; 历代志上 27:23"> 你使他们的子孙多如天上的星星，你带领他们进入你应许他们祖先的土地。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 21:43; 约书亚记 11:23; 诗篇 44:2–3"> 他们的子孙进去占领了那地方，你在他们面前制服了住在那里的迦南人，把迦南诸王和那地方的人交在他们手里，任由他们处置。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 32:15; 尼希米记 9:35; 申命记 3:5"> 他们夺取坚固的城池、肥沃的土地、装满美物的房屋、挖好的水井、葡萄园、橄榄园以及各样果树。他们吃得饱足，身体发胖，享受你的厚恩。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:9; 士师记 2:11–12; 尼希米记 9:18"> “然而，他们不顺从你，背叛你，把你的律法抛在背后，又杀掉劝诫他们归向你的众先知，大大亵渎了你。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 106:41–45; 列王纪下 14:27; 列王纪下 13:5"> 于是你把他们交在欺压他们的仇敌手中。他们在患难中向你呼求，你就从天上垂听，怀着丰盛的怜悯赐给他们拯救者，把他们从仇敌手中拯救出来。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 5:31–1; 士师记 4:1; 列王纪上 8:39"> 可是，他们得享平安后，又在你面前作恶，于是你离弃他们，把他们交在敌人手中，使敌人统治他们。他们回转向你呼求，你就从天上垂听，你一次次地怀着怜悯拯救他们。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 9:16; 利未记 18:5; 尼希米记 9:26"> 你警告他们，要使他们转向你的律法，但他们行事狂傲，不听从你的诫命，干犯你的典章。遵行这典章的人必因此而活。但他们背弃你，顽固不化，不肯听从。</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 2:4; 历代志下 36:15–16; 以赛亚书 42:24"> 你多年来容忍他们，差遣你的灵借着你的众先知警告他们，但他们依然不肯听从，于是你把他们交在列邦手中。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米哀歌 3:22; 耶利米书 4:27; 尼希米记 9:17"> 然而，你大施怜悯，没有完全毁灭他们，也没有离弃他们，因为你是有恩典、好怜悯的上帝。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 7:9; 尼希米记 1:5; 但以理书 9:4"> “因此，我们的上帝啊，你是伟大、全能、可畏、守约、施慈爱的上帝，求你不要轻看我们的王、首领、祭司、先知、祖先和你的子民，从亚述诸王时代直到今天所受的苦难。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 18:25; 诗篇 106:6; 约伯记 34:23"> 在这临到我们的一切事上，你都是公义的，因为你行事信实，我们行事邪恶。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 29:19; 列王纪下 17:13; 申命记 31:21"> 我们的王、首领、祭司和祖先没有遵行你的律法，也没有留心听从你的诫命和你给他们的警告。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 28:47; 申命记 32:12–15; 耶利米书 5:19"> 他们即使在本国，在你赐给他们广阔肥沃的土地上得享你的厚恩，也不事奉你，不离开恶道。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉记 9:9; 申命记 28:48; 历代志下 12:8"> 今天，我们沦为奴隶，在你赐给我们祖先的土地上，在你让我们祖先享用其出产和各样美物的土地上，我们沦为奴隶。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 28:33; 申命记 28:48; 以斯拉记 7:24"> 因为我们的罪过，这地方的丰富出产都归给了那些你派来统管我们的王。他们随意统管我们和我们的牲畜。我们生活在极大的苦难中。</span>
<span className="v" id="v38" data-v="38" data-xref="尼希米记 10:1; 历代志下 34:31; 以斯拉记 10:3"> “鉴于此，我们郑重立约，记载下来。我们的首领、利未人和祭司都在上面盖了印。”</span>

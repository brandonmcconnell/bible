## 尼希米战胜阻力

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:10; 希伯来书 11:36; 诗篇 35:15–16"> 参巴拉听说我们正在重建城墙，非常愤怒，就嘲笑犹太人，</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:9–10; 哥林多前书 1:27; 以西结书 37:3–13"> 当着他的同僚和撒玛利亚军兵的面说：“这群弱小的犹太人在做什么呢？要重建城墙吗？要献祭吗？要在一日之间建好吗？要用废墟中烧过的石头来建造吗？”</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:19; 列王纪上 20:10; 尼希米记 2:10"> 他身旁的亚扪人多比雅说：“他们建的石墙，一只狐狸上去就能踩倒！”</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 79:12; 诗篇 123:3–4; 箴言 3:34"> 我祷告说：“我们的上帝啊，求你垂听，因为我们被人藐视。求你使他们对我们的凌辱归到他们自己头上，使他们被掳到外邦。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 109:14; 耶利米书 18:23; 诗篇 69:27–28"> 不要遮掩他们的恶行，也不要从你面前涂抹他们的罪恶，因为他们在这些建造的人面前惹你发怒。”</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:13; 尼希米记 6:15; 希伯来书 13:21"> 众人全心做工，把整个城墙连接起来，高达原来的一半。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:10; 尼希米记 4:1; 使徒行传 5:33"> 参巴拉、多比雅、阿拉伯人、亚扪人和亚实突人听说耶路撒冷的城墙正在重建、缺口正在填补，非常愤怒，</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 83:3–11; 以赛亚书 8:9–10; 耶利米书 20:10"> 便一起图谋袭击耶路撒冷，使城内混乱。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:8; 使徒行传 4:24–30; 诗篇 50:15"> 但我们向我们的上帝祷告，并设立守卫昼夜防备他们。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 11:1–2; 哈该书 1:2; 历代志下 2:18"> 犹大人说：“工人已经筋疲力尽，还有太多瓦砾有待清理，我们自己无法重建城墙。”</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 5:2; 使徒行传 23:12; 诗篇 56:6"> 我们的敌人说：“我们要趁他们不知不觉，进入他们中间杀死他们，阻止他们的工作。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:7; 创世记 31:41; 民数记 14:22"> 靠近敌人居住的犹太人十次来告诉我们，说敌人会从各方来袭击我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本节希伯来文意义不明。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:17–18; 以弗所书 6:11–20; 雅歌 3:7–8"> 于是，我按宗族派人手持刀剑、长矛和弓箭，守卫在城墙后面低洼的空地上。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 10:12; 民数记 14:9; 以赛亚书 41:10–14"> 我察看形势后，起来对贵族、官员和其他民众说：“不要怕他们！要记住，主伟大而可畏。要为你们的兄弟、儿女、妻子和家园而战。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 17:14; 罗马书 12:11; 约伯记 5:12–13"> 敌人听说我们知道了他们的阴谋，上帝已破坏他们的诡计，就没有来。我们回到城墙那里，继续各人的工作。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 4:23; 诗篇 101:6; 尼希米记 5:15–16"> 从那时起，我的仆人一半继续修筑城墙，一半身穿盔甲，手持长矛、盾牌和弓箭负责守卫。官长都站在修筑城墙的所有犹大人后面。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 6:7; 提摩太后书 4:7; 提摩太后书 2:3"> 搬运工人一手工作，一手拿兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:9; 历代志下 13:12–17"> 修筑城墙的人工作的时候都腰间佩刀。吹号的人在我旁边，</span>
<span className="v" id="v19" data-v="19"> 我对贵族、官员和其余的民众说：“这工程浩大，范围广阔，我们在城墙上相隔很远。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 14:14; 申命记 1:30; 申命记 20:4"> 因此你们无论在哪里听见号角声，都要聚到我们那里。我们的上帝必为我们争战！”</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:9; 歌罗西书 1:29; 哥林多前书 15:58"> 这样，从黎明直到星星出现，我们一直工作，有一半手持长矛守卫。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 11:1–2"> 那时，我又吩咐众人各带仆人在耶路撒冷住宿。他们夜间可以帮我们守卫，白天帮我们工作。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 9:48; 尼希米记 7:2; 哥林多前书 15:10"> 我和我的兄弟、仆人及跟从我的守卫都衣不解带，刀不离身<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“刀不离身”或译“出去打水时也带着刀”。">b</a></sup>。</span>
</div>

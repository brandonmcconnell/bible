## 尼希米帮助穷苦人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:7; 出埃及记 22:25–27; 哥林多前书 6:6–8"> 那时，民众和他们的妻子都抱怨他们的犹太同胞。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 2:2; 诗篇 128:2–4; 诗篇 127:3–5"> 有的说：“我们和儿女人口众多，需要粮食来活命。”</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 25:35–39; 玛拉基书 3:8–11; 创世记 47:15–25"> 有的说：“因为饥荒的缘故，我们要将田地、葡萄园和房屋作抵押来获取粮食。”</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 4:13; 以斯拉记 4:20; 申命记 28:47–48"> 有的说：“我们要借钱才能缴纳王对我们的田地和葡萄园征收的税。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 4:1; 利未记 25:39–43; 以赛亚书 58:7"> 我们和他们是同胞，我们的孩子就像他们的孩子。但现在我们的儿女要被迫成为仆婢，甚至我们的女儿有些已经沦为奴婢。我们却无能为力，因为我们的田地和葡萄园已经归别人了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 11:8; 尼希米记 13:25; 以弗所书 4:26"> 听到他们的怨声载道后，我非常愤怒。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 23:19–20; 利未记 25:36; 出埃及记 22:25"> 经过深思熟虑后，我便斥责贵族和官员，说：“你们竟然向同胞放高利贷！”于是我召开大会处理他们的问题。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 25:47–49; 哥林多前书 8:11; 马太福音 25:29"> 我对他们说：“我们在尽力赎回那些被卖到外邦的犹太同胞，你们却要卖他们为奴，好让我们再赎回他们吗？”他们都沉默不语，无言以对。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 25:36; 撒母耳记下 12:14; 罗马书 2:24"> 我继续说：“你们的所作所为实在不对。难道你们不应该敬畏上帝，以免我们的仇敌凌辱我们吗？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 6:1; 出埃及记 22:25–27; 以西结书 18:13"> 我和我的兄弟及仆人都借钱、借粮给民众，现在我们要停止收取利息。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:6; 利未记 6:4–5; 路加福音 3:8"> 你们今天就要归还他们的田地、葡萄园、橄榄园和房屋，以及你们向他们所收的五谷、新酒和油的利息。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 10:5; 耶利米书 34:8–10; 马太福音 19:21–22"> 他们说：“我们会照你的话去做，把东西还给他们，不再向他们索债。”于是，我召来祭司，让这些人起誓遵守自己的诺言。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:6; 历代志上 16:36; 马太福音 10:14"> 我抖着衣服说：“如果你们不守誓言，愿上帝也这样抖掉你们的家园和你们劳碌得来的，使你们一无所有。”全体会众都说：“阿们！”他们赞美耶和华，民众都遵照誓言去行。</span>
</div>
</div>

## 尼希米大公无私

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米记 13:6; 帖撒罗尼迦后书 3:8–9; 哥林多前书 9:4–15"> 从亚达薛西王二十年至三十二年，也就是我奉派为犹大省长的十二年间，我和我的弟兄都没有吃省长的俸禄。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 5:9; 以赛亚书 50:10; 箴言 16:6"> 在我之前的省长使民众负担沉重，天天索取食物、酒及十两银子。他们的仆人也欺压民众，但我因敬畏上帝就没有这样做。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:9; 帖撒罗尼迦前书 2:5–6; 哥林多前书 15:58"> 我全心修筑城墙，没有购置田产，我的仆人也都参与修建城墙的工作。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:19; 彼得前书 4:9–10; 撒母耳记下 9:7"> 除了从周围外邦来到我们这里的人之外，还有一百五十名犹太人和官员与我一同吃饭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:22–23; 诗篇 37:21; 诗篇 37:26"> 我每天需要预备一头公牛、六只肥羊和飞禽；每十天还要大量供应各样酒品。即使这样，我仍然没有吃省长的俸禄，因为民众已经负担沉重。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 13:31; 诗篇 106:4; 尼希米记 13:14"> 我的上帝啊，求你记念我为这些民众所做的一切，施恩于我。</span>
</div>
</div>

## 尼希米奉献新城墙

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 15:16; 历代志上 15:28; 历代志下 29:30"> 在耶路撒冷的城墙典礼之际，民众把各处的利未人请到耶路撒冷，来称颂、歌唱、敲钹、鼓瑟、弹琴，欢庆典礼。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 9:16; 历代志上 2:54; 尼希米记 6:2"> 歌乐手的子孙从耶路撒冷周围地区、尼陀法人的村庄、</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:43; 历代志上 6:60; 以斯拉记 2:24"> 伯·吉甲，以及迦巴和亚斯玛弗地区被招聚起来，因为歌乐手已在耶路撒冷周围为自己建立了村庄。</span>
<span className="v" id="v30" data-v="30" data-xref="约伯记 1:5; 出埃及记 19:10; 历代志下 29:5"> 祭司和利未人自洁，然后洁净民众、城门和城墙。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:13; 尼希米记 12:38; 历代志上 13:1"> 我率犹大的首领上到城墙上，使称颂的歌乐手分成两大队，一队从城墙上向右前往粪厂门，</span>
<span className="v" id="v32" data-v="32"> 跟在他们后面的有何沙雅和半数的犹大首领，</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 10:2–7"> 还有亚撒利雅、以斯拉、米书兰、</span>
<span className="v" id="v34" data-v="34"> 犹大、便雅悯、示玛雅和耶利米，</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 6:4; 民数记 10:2–10; 历代志下 5:12"> 还有一些吹号的祭司，包括约拿单的儿子撒迦利亚，约拿单是示玛雅的儿子，示玛雅是玛他尼的儿子，玛他尼是米该亚的儿子，米该亚是撒刻的儿子，撒刻是亚萨的儿子；</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 12:24; 历代志下 8:14; 历代志上 23:5"> 还有撒迦利亚的弟兄示玛雅、亚撒利、米拉莱、基拉莱、玛艾、拿坦业、犹大、哈拿尼，他们都拿着上帝仆人大卫的乐器。队伍由律法教师以斯拉带领。</span>
<span className="v" id="v37" data-v="37" data-xref="尼希米记 3:26; 尼希米记 2:14; 尼希米记 8:3"> 他们经过泉门，沿大卫城的台阶，顺城墙的地势而上，经过大卫的宫殿，走到东面的水门。</span>
<span className="v" id="v38" data-v="38" data-xref="尼希米记 3:8; 尼希米记 3:11; 尼希米记 12:31"> 第二队称颂的歌乐手向左走，我和半数的民众在城墙上跟着他们，经过炉楼一直走到宽墙，</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米记 3:1; 尼希米记 3:3; 尼希米记 8:16"> 然后又经过以法莲门、古门、鱼门、哈楠业楼、哈米亚楼，远至羊门，之后停在护卫门。</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 42:4; 诗篇 134:1–3; 尼希米记 12:31–32"> 这两队称颂的歌乐手站在上帝的殿里，我和半数的首领也站在那里，</span>
<span className="v" id="v41" data-v="41"> 同时还有吹号的祭司以利亚金、玛西雅、米拿民、米该亚、以利约乃、撒迦利亚和哈楠尼亚，</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 81:1; 尼希米记 11:14; 诗篇 100:1–2"> 以及玛西雅、示玛雅、以利亚撒、乌西、约哈难、玛基雅、以拦和以谢。歌乐手在伊斯拉希雅的领导下高声歌唱。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 3:13; 诗篇 92:4; 耶利米书 31:13"> 那天，众人献上许多祭物，满心欢喜，因为上帝赐给他们极大的喜乐，连妇孺也都欢喜，耶路撒冷的欢声远处可闻。</span>
</div>

## 预备圣殿的需要

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="尼希米记 13:12–13; 尼希米记 10:37–39; 历代志下 31:11–13"> 那天，有人被委派管理库房，把举祭、初熟之物和十一奉献收集在库房里。他们要照律法的规定从各城田地收集祭司和利未人当得的份，因为犹大人对祭司和利未人的供职很满意。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 25:1–26; 历代志下 23:6; 历代志上 23:28"> 祭司和利未人遵行上帝的吩咐，遵守洁净的礼。歌乐手和殿门守卫也遵照大卫和他儿子所罗门的命令行事。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 29:30; 诗篇 73:1; 历代志上 25:1–31"> 远在大卫和亚萨的时代就有歌乐手，并有赞美、称颂上帝的诗歌。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 18:21–29; 尼希米记 12:26; 尼希米记 13:10–12"> 在所罗巴伯和尼希米的时代，全体以色列人供应歌乐手和殿门守卫的日常需用，并分出一份给利未人，利未人又分出一份给亚伦的子孙。</span>
</div>

## 重建耶路撒冷的城墙

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 12:39; 耶利米书 31:38; 约翰福音 5:2"> 于是，大祭司以利亚实及其祭司同僚一起重建羊门，将它献给上帝，又安上门。他们重建城墙，一直建到哈米亚楼和哈楠业楼，并将它献给上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:36; 以斯拉记 2:34; 尼希米记 10:12"> 下一段由耶利哥人修建。 再下一段由音利的儿子撒刻修建。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:14; 尼希米记 12:39; 西番雅书 1:10"> 哈西拿的子孙修建鱼门，架上横梁，安上门，装上门闩和门锁。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 8:33; 尼希米记 3:21; 尼希米记 10:7"> 再下一段由哈哥斯的孙子、乌利亚的儿子米利末修筑。 再下一段由米示萨别的孙子、比利迦的儿子米书兰修筑。 再下一段由巴拿的儿子撒督修筑。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 3:27; 撒母耳记下 14:2; 耶利米书 27:2"> 再下一段由提哥亚人修筑，但他们的贵族不肯做督工所分派的工作。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 12:39"> 巴西亚的儿子耶何耶大和比所玳的儿子米书兰修筑古门，架上横梁，安上门，装上门闩和门锁。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:2; 约书亚记 9:3–27; 尼希米记 3:19"> 再下一段由基遍人米拉提、米伦人雅顿和其他基遍人，以及河西省省长管辖的米斯巴人修筑。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 12:38; 尼希米记 3:31–32; 创世记 50:2"> 再下一段由哈海雅的儿子金匠乌薛修筑。 再下一段由制造香料的哈拿尼雅修筑，他们修筑耶路撒冷的城墙，直到宽墙。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:12; 尼希米记 3:17"> 再下一段由户珥的儿子、管理半个耶路撒冷的利法雅修筑。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 3:28–30; 尼希米记 10:4; 尼希米记 3:23"> 接下来，哈路抹的儿子耶大雅修筑他房子对面的那一段。 再下一段由哈沙尼的儿子哈突修筑。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 12:38; 以斯拉记 2:6; 尼希米记 10:14"> 哈琳的儿子玛基雅和巴哈·摩押的儿子哈述修筑另一段城墙，包括炉楼。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 3:9; 使徒行传 21:8–9; 出埃及记 35:25"> 再下一段由哈罗黑的儿子、管理半个耶路撒冷的沙龙和他的女儿们修筑。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 2:13; 约书亚记 15:34; 历代志下 26:9"> 哈嫩与撒挪亚的居民修筑谷门，安上门，装上门闩和门锁，之后又修建城墙四百五十米，直到粪厂门。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 6:1; 尼希米记 2:13; 尼希米记 3:12–13"> 利甲的儿子、管理伯·哈基琳的玛基雅修筑粪厂门，修好后安上门，装上门闩和门锁。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:7; 以赛亚书 8:6; 尼希米记 12:37"> 各荷西的儿子、管理米斯巴的沙仑修筑泉门，修好后盖上门顶，安上门，装上门闩和门锁。他还从靠近御花园的西罗亚池的城墙，一直修到大卫城下来的台阶处。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:29; 尼希米记 3:9; 列王纪下 20:20"> 再下一段由押卜的儿子、管理半个伯·夙的尼希米修筑，他一直修到大卫墓地对面，远至人工池和勇士堂。</span>
</div>
</div>

## 修筑城墙的利未人

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:44; 尼希米记 3:16; 撒母耳记上 23:1–13"> 再下一段由巴尼的儿子利宏带领的利未人修筑。 接下来，管理半个基伊拉的哈沙比雅修筑了自己的辖区。</span>
<span className="v" id="v18" data-v="18"> 再下一段由他的同族兄弟，就是希拿达的儿子、管理半个基伊拉的巴瓦伊修筑。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:9; 尼希米记 10:9; 尼希米记 12:8"> 再下一段由耶书亚的儿子、管理米斯巴的以谢修筑，他从斜坡对面修到城墙转角的兵器库。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 3:1; 传道书 9:10; 罗马书 12:11"> 再下一段由萨拜的儿子巴录修筑，他从城墙转角修到以利亚实大祭司的家门口。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 7:63; 以斯拉记 2:61"> 再下一段由哈哥斯的孙子、乌利亚的儿子米利末修筑，他从以利亚实家门口修到以利亚实家的尽头。</span>
</div>
</div>

## 修筑城墙的祭司

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:28; 尼希米记 6:2"> 再下一段由住在周围郊区的祭司修筑。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:2; 尼希米记 8:4; 尼希米记 3:29–30"> 接下来，便雅悯与哈述修筑自家对面的那一段。 再接下来，亚南尼的孙子、玛西雅的儿子亚撒利雅修筑自家旁边的那一段。</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 3:19; 尼希米记 3:27; 尼希米记 10:9"> 再下一段由希拿达的儿子宾内修筑，他从亚撒利雅的房子修到城墙的转角。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:2; 耶利米书 37:21; 尼希米记 12:39"> 再接下来，乌赛的儿子巴拉修筑了城墙转角的对面和护卫院附近上宫凸出的城楼。 再下一段由巴录的儿子毗大雅与住在俄斐勒的殿役修筑，他们修到东面的水门对面和凸出的城楼那里。</span>
</div>
</div>

## 其他修筑的人

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="尼希米记 3:5"> 再下一段由提哥亚人修筑，他们从凸出来的大城楼对面修到俄斐勒的城墙。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 23:15; 耶利米书 31:40; 列王纪下 11:16"> 接下来，祭司修筑了马门以北的城墙，他们各自修筑自家对面的部分。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 19:2; 以斯拉记 2:37; 尼希米记 7:40"> 再接下来，音麦的儿子撒督修筑自家对面的那一段。 再下一段由看守东门的、示迦尼的儿子示玛雅修筑。</span>
<span className="v" id="v30" data-v="30"> 再下一段由示利米雅的儿子哈拿尼雅和萨拉的第六个儿子哈嫩修筑。 接下来，比利迦的儿子米书兰修筑自家对面的那一段。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:8; 尼希米记 3:32"> 再下一段由金匠玛基雅修筑，他修到哈米弗甲门对面的殿役和商人的房子，直到城的角楼。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 3:1; 约翰福音 5:2; 尼希米记 12:39"> 金匠和商人修筑从城的角楼到羊门的那一段。</span>
</div>

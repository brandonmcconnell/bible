## 做上帝喜悦的事

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:20–1; 彼得前书 3:8; 彼得前书 1:22"> 你们要继续彼此相爱，情同手足。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:35; 创世记 18:1–3; 彼得前书 4:9"> 不要忘记款待客旅，因为曾经有人接待客旅时不知不觉接待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:36; 希伯来书 10:34; 罗马书 12:15"> 要设身处地地顾念那些被囚禁的人，要感同身受地顾念那些被恶待的人。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 2:24; 箴言 5:15–23; 加拉太书 5:19"> 人人都要尊重婚姻，不可玷污婚床，因为上帝必审判淫乱和通奸的人。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 31:8; 约书亚记 1:5; 申命记 31:6"> 不要贪爱钱财，要对自己拥有的知足，因为上帝说过：<br /><span className="pl pl-1">“我永不撇下你，也不离弃你。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命记31:6。">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 118:6–9; 以赛亚书 41:10; 罗马书 8:31"> 这样，我们可以放胆地说：<br /><span className="pl pl-1">“主是我的帮助，</span><br /><span className="pl pl-1">我必不惧怕，</span><br /><span className="pl pl-1">人能把我怎么样？”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇118:6、7。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 13:17; 腓立比书 3:17"> 你们要记住从前带领你们、把上帝的道传给你们的人，留心观察他们行事为人的结果，效法他们的信心。</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 3:6; 雅各书 1:17; 启示录 1:8"> 耶稣基督昨日、今日、直到永远都不改变。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:14; 提摩太前书 6:3–5; 以弗所书 5:6"> 你们不要被五花八门的异端邪说勾引了去，因为心中得到力量是靠上帝的恩典，而不是靠饮食上的规条，这些规条从未使遵守的人受益。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:7–8; 哥林多前书 10:20; 哥林多前书 9:13"> 我们有一座祭坛，坛上的祭物是那些在圣幕里供职的人没有权利吃的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 16:27; 出埃及记 29:14; 利未记 9:11"> 大祭司把祭牲的血带进至圣所作赎罪祭，而祭牲的身体则在营外烧掉。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 9:12–14; 约翰福音 19:17–18; 使徒行传 7:58"> 同样，耶稣为了用自己的血使祂的子民圣洁，也在城门外受难。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:26; 彼得前书 4:14–16; 使徒行传 5:41"> 因此，让我们也走出营外到祂那里，忍受祂所忍受的凌辱吧！</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 3:20; 歌罗西书 3:1–3; 希伯来书 11:12–16"> 我们在地上没有永远的城，我们寻求的是那将来的城。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 107:21–22; 诗篇 50:14; 罗马书 12:1"> 让我们靠着耶稣，常常开口以颂赞为祭献给上帝，这是承认主名的人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“承认主名的人”希腊文是“承认主名的嘴唇”。">c</a></sup>所结的果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:10; 罗马书 12:13"> 不可忘记行善和帮补别人，因为这样的祭是上帝所喜悦的。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦前书 5:12–13; 提摩太前书 5:17; 希伯来书 13:7"> 要顺服和听从引导你们的人，因为他们为你们的灵魂时刻警醒，将来要向上帝交账。你们要让他们怀着喜乐尽此职责，而非充满忧愁，那样对你们毫无益处。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:25; 帖撒罗尼迦后书 3:1; 歌罗西书 4:3"> 请为我们祷告，因为我们自信良心无愧，凡事都愿意遵行正道。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利门书 1:22; 罗马书 1:10–12; 罗马书 15:31–32"> 也请你们特别为我祷告，使我能够早日回到你们那里。</span>
</div>
</div>

## 祝福与问安

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:11; 希伯来书 10:22; 诗篇 23:1"> 愿赐平安的上帝，就是那位凭着立永恒之约的血使群羊的大牧人我主耶稣从死里复活的上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:13; 帖撒罗尼迦后书 2:17; 腓立比书 4:13"> 在各样善事上成全你们，好使你们遵行祂的旨意，并借着耶稣基督在你们心中动工，使你们做祂喜悦的事！愿荣耀归给上帝，直到永永远远。阿们！</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:1; 彼得前书 5:12; 哥林多后书 6:1"> 弟兄姊妹，我简短地写信给你们，希望你们听我劝勉的话。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利门书 1:1; 帖撒罗尼迦前书 3:2; 提摩太后书 1:8"> 你们知道，我们的弟兄提摩太已经被释放了。如果他很快来到，我会与他一起去看你们。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 13:7; 希伯来书 13:17; 使徒行传 18:2"> 请问候所有带领你们的人以及众圣徒。从意大利来的人也问候你们。</span>
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 4:18; 提摩太后书 4:22; 提多书 3:15"> 愿恩典与你们众人同在！</span>
</div>
</div>

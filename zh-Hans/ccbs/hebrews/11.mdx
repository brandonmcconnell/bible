## 论信心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 5:7; 哥林多后书 4:18; 罗马书 8:24–25"> 信心是对盼望的事有把握，对还没看见的事很确定。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:39; 希伯来书 11:4"> 古人凭这样的信心得到了赞许。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 33:6; 彼得后书 3:5; 约翰福音 1:3"> 因为信心，我们知道宇宙是借着上帝的话造成的，所以看得见的是从看不见的造出来的。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 12:24; 创世记 4:3–5; 约翰一书 3:11–12"> 因为信心，亚伯向上帝献的祭比该隐所献的更美，他因此蒙了上帝的悦纳，被称为义人。他虽然死了，却仍然借着信心说话。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 5:21–24; 犹大书 1:14; 希伯来书 11:6"> 因为信心，以诺被接到天上，没有经历死亡。世人找不到他，因为上帝已经把他接走了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记5:24。">a</a></sup>其实他在被接之前，已经被肯定为上帝喜悦的人。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米书 29:13–14; 马太福音 6:33"> 没有信心的人得不到上帝的喜悦，因为来到上帝面前的人必须相信上帝存在，并相信祂会赏赐一切寻求祂的人。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 6:13–1; 彼得前书 3:20; 以西结书 14:14"> 因为信心，挪亚在上帝指示他未来要发生的事之后，就怀着敬畏的心建造方舟挽救全家。他借着信心定了那个世代的罪，并承受了因信而来的义。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 12:1–4; 使徒行传 7:2–4; 马太福音 7:24–25"> 因为信心，亚伯拉罕听到上帝的呼召后，就遵命前往他将要承受为产业的地方，但他出发的时候还不知道自己要去哪里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:8; 创世记 13:18; 创世记 13:3"> 因为信心，他像异乡客旅一样寄居在上帝应许给他的地方。他住在帐篷里，与同受一个应许的以撒和雅各一样。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:14; 腓立比书 3:20; 希伯来书 12:22"> 因为他盼望的是一座有根基的城，是由上帝设计、建造的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:20–21; 希伯来书 10:23; 创世记 18:11–14"> 因为信心，撒拉过了生育年龄后仍然得到了孕育后代的能力，因为她认定赐她应许的上帝言出必行。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 22:17; 创世记 32:12; 创世记 15:5"> 所以，从一个垂暮之年的人生出许多子孙，好像天上的星、海边的沙那么多。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 23:4; 诗篇 39:12; 希伯来书 11:27"> 这些人到死都满怀信心。他们虽然没有得到上帝所应许的，却从远处望见了，就欢然接受，承认自己在世上不过是异乡客旅。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:18–7; 希伯来书 11:16; 希伯来书 13:14"> 他们抱这样的态度，表明他们正在寻找一个家乡。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 24:6–8; 创世记 12:10; 创世记 32:9–11"> 如果他们想念的是自己离开的家乡，早就找机会回去了。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:14; 希伯来书 11:10; 腓立比书 3:20"> 然而，他们渴慕的是天上更美的家乡。所以，上帝不以被他们称为上帝为耻，因为祂已经为他们预备了一座城。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 22:16; 创世记 22:1–12; 雅各书 2:21–24"> 因为信心，亚伯拉罕被试验时，把以撒献为祭物，承受应许的亚伯拉罕当时献上了自己的独生子。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:12; 罗马书 9:7; 创世记 17:19"> 关于这儿子，上帝曾说：“以撒生的才可算为你的后裔。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="创世记21:12。">b</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 4:17–21; 马太福音 9:28; 以弗所书 3:20"> 他认定上帝能使死人复活，从象征意义上说，他也确实从死亡中得回了以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 27:27–40; 创世记 28:2–3"> 因为信心，以撒指着将来的事为雅各和以扫祝福。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:31–1; 创世记 48:5–22"> 因为信心，雅各在临终之时分别为约瑟的两个儿子祝福，并拄着拐杖敬拜上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 13:19; 创世记 50:24–25; 约书亚记 24:32"> 因为信心，约瑟临终之时提到以色列人将来要离开埃及，并交代要如何处理自己的骸骨。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 1:22; 出埃及记 1:16; 希伯来书 13:6"> 因为信心，摩西的父母在他出生后，见他长得俊美，就把他藏了三个月，不怕违抗王的命令。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 2:10–11; 使徒行传 7:21–24"> 因为信心，摩西长大成人后，拒绝做法老之女的儿子，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 84:10; 提摩太后书 2:3–10; 约伯记 36:21"> 宁愿与上帝的子民一同受苦，也不愿享受一时的罪中之乐。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:35; 希伯来书 11:6; 彼得前书 4:14"> 在他眼中，为基督所受的凌辱远比埃及的财富更有价值，因为他盼望的是将来的赏赐。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 4:18; 希伯来书 11:13; 希伯来书 11:1"> 因为信心，他离开埃及，不怕王的愤怒。他坚忍不拔，好像看见了肉眼不能看见的主。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 12:21–30; 希伯来书 9:19; 希伯来书 12:24"> 因为信心，他守逾越节，行洒血的礼，免得那位杀长子的伤害以色列人。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:13–21; 诗篇 106:9–11; 诗篇 78:13"> 因为信心，以色列人渡过红海，如履干地，埃及人试图过去，却被海水淹没。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 6:3–20; 哥林多后书 10:4–5"> 因为信心，以色列人绕着耶利哥城走了七天，城墙就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 2:25; 约书亚记 6:22–25; 马太福音 1:5"> 因为信心，妓女喇合善待以色列的探子，所以没有与那些不顺服的人一同灭亡。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:1; 撒母耳记上 1:20; 撒母耳记上 16:13"> 我还要再说下去吗？我没有时间一一细说基甸、巴拉、参孙、耶弗他、大卫、撒母耳和众先知的事了。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 144:1–2; 希伯来书 6:12–15; 希伯来书 10:36"> 他们凭信心战胜了敌国，行了公义，得到了应许，堵住了狮子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪下 6:16–18; 哥林多后书 12:9–10; 撒母耳记上 17:51–52"> 熄灭了猛烈的火焰，刀下逃生，由软弱变为刚强，作战勇猛，击退外敌。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 4:27–37; 列王纪上 17:22–24; 腓立比书 3:11"> 有些妇女得回了从死里复活的亲人。有些人受尽严刑拷打，仍不肯苟且偷生，为要得到一个复活后更美好的生命。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 20:2; 创世记 39:20; 耶利米书 37:15–21"> 有些人遭受戏弄、鞭打、捆锁和囚禁。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 24:21; 耶利米书 26:23; 列王纪上 19:10"> 他们被人用石头打死，受威逼利诱<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有圣经抄本在此处无“受威逼利诱”。">c</a></sup>，被锯成两截，丧生刀下，披着绵羊和山羊的皮四处奔跑，受尽贫乏、迫害和虐待，</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 18:4; 撒母耳记上 22:1; 列王纪上 19:9"> 在旷野、群山、山洞和地穴中漂泊不定。他们是世界不配有的！</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯来书 11:13; 希伯来书 11:2"> 这些人都因信心而获得赞许，但他们并未得到上帝所应许的，</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 6:11; 希伯来书 8:6; 希伯来书 10:11–14"> 因为上帝为我们预备了更美的，要叫他们与我们一同得到才算完美。</span>

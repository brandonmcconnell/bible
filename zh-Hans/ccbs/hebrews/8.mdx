## 更美之约的大祭司

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 1:3; 歌罗西书 3:1; 启示录 3:21"> 我们所讲的要点是：我们有这样一位大祭司，祂现在已经坐在天上至高上帝的宝座右边，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 33:7; 哥林多后书 5:1; 希伯来书 9:23–24"> 并在圣所里供职。这圣所就是真正的圣幕，不是人建立的，而是主亲手建立的。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 5:2; 希伯来书 5:1; 希伯来书 9:14"> 所有的大祭司都是为了向上帝献礼物和祭物而设立的，因此我们这位大祭司也必须有所献上。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 7:11–15; 希伯来书 5:1; 民数记 17:12–13"> 祂如果是在地上，根本不会做祭司，因为地上已经有照律法向上帝献礼物的祭司了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:40; 歌罗西书 2:17; 希伯来书 10:1"> 这些祭司的事奉都是仿效和反映天上的事，正如摩西建圣幕的时候，上帝警告他说：<br /><span className="pl pl-1">“你务要照着在山上指示你的样式造各样器具。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及记25:40。">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 7:22; 加拉太书 3:16–21; 希伯来书 12:24"> 但如今，耶稣得到了一个更超越的职任，正如祂担任了更美之约的中保，这约是根据更美的应许所立的。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 7:11; 加拉太书 3:21; 希伯来书 7:18"> 因为如果第一个约没有缺点，就不必另立新约了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 31:31–34; 希伯来书 10:16–17; 希伯来书 12:24"> 然而，上帝指责祂的子民，说：<br /><span className="pl pl-1">“主说，看啊，时候将到，</span><br /><span className="pl pl-1">我要与以色列家和犹大家另立新约，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:32; 加拉太书 4:24; 马可福音 8:23"> <span className="pl pl-1">这约不同于我与他们祖先所立的约，</span><br /><span className="pl pl-1">那是我牵着他们祖先的手领他们离开埃及时所立的。</span><br /><span className="pl pl-1">因为他们不持守我的约，</span><br /><span className="pl pl-1">所以我不再理会他们。</span><br /><span className="pl pl-1">这是主说的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 36:26–28; 耶利米书 31:33; 以西结书 11:19–20"> <span className="pl pl-1">主又说，那些日子以后，</span><br /><span className="pl pl-1">我将与以色列家立这样的约，</span><br /><span className="pl pl-1">我要把我的律法放在他们脑中，</span><br /><span className="pl pl-1">写在他们心上。</span><br /><span className="pl pl-1">我要做他们的上帝，</span><br /><span className="pl pl-1">他们要做我的子民。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 31:34; 以赛亚书 54:13; 约翰福音 6:45"> <span className="pl pl-1">谁都无需再教导自己的邻居和弟兄，</span><br /><span className="pl pl-1">说，‘你要认识主。’</span><br /><span className="pl pl-1">因为他们无论尊卑都必认识我。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:16–17; 以赛亚书 43:25; 罗马书 11:27"> <span className="pl pl-1">我要赦免他们的过犯，</span><br /><span className="pl pl-1">忘掉他们的罪恶。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶利米书31:31‑34。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 5:17; 希伯来书 7:18–19; 希伯来书 7:11–12"> 上帝既然说要立新约，就是把第一个约当作旧的了，那渐渐陈旧过时的很快就会消失。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:3; 希伯来书 10:11; 希伯来书 7:27"> 凡从人间选出来的大祭司，都是受委任代表人办理与上帝有关的事，为人的罪向上帝献上礼物和赎罪祭。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:15; 希伯来书 2:18; 哥林多后书 12:9–10"> 他能体谅那些无知和迷失的人，因为他自己也受制于人性的软弱。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 9:7; 希伯来书 9:7; 利未记 16:6"> 所以，他不但要为众人的罪献祭，也要为自己的罪献祭。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:1; 民数记 16:40; 民数记 16:5"> 没有人能自取这大祭司的尊荣，只有像亚伦一样蒙上帝呼召的人才可以做大祭司。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 2:7; 约翰福音 8:54; 使徒行传 13:33"> 同样，基督也没有自取荣耀做大祭司，是上帝对祂说：<br /><span className="pl pl-1">“你是我的儿子，</span><br /><span className="pl pl-1">我今日成为你父亲。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇2:7。">a</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 7:21"> 在圣经的另一处，上帝又说：<br /><span className="pl pl-1">“你照麦基洗德的模式永远做祭司。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇110:4。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:32–39; 路加福音 22:41–44; 约翰福音 17:1"> 基督在世为人的时候，曾经声泪俱下地祈求能救祂脱离死亡的上帝。祂因为敬虔而蒙了应允。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 2:8; 希伯来书 10:5–9; 约翰福音 4:34"> 基督虽然是上帝的儿子，仍然从所受的苦难中学习了顺服。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 2:10; 希伯来书 9:12; 希伯来书 9:15"> 祂既然达到了纯全的地步，就成了所有顺服祂的人得到永恒救恩的源头，</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 5:5–6; 希伯来书 6:20"> 并且被上帝照麦基洗德的模式立为大祭司。</span>
</div>

## 信徒要长进

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:15; 使徒行传 28:27; 彼得后书 3:16"> 关于这方面的事，我们还有很多话要说，但因为你们已经听不进去，很难向你们解释。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 6:1; 哥林多前书 3:1–3; 彼得前书 2:2"> 按你们学习的时间来算，你们本该做别人的老师了，可惜你们还需要别人向你们传授上帝话语的基本道理，成了不能吃干粮、只能吃奶的人。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:20; 彼得前书 2:2; 提摩太后书 3:16"> 因为只能吃奶的人还是婴孩，不熟习公义之道。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 2:14–15; 帖撒罗尼迦前书 5:21; 以弗所书 1:18"> 干粮是给成年人吃的，他们的心思历经锻炼，能够分辨善恶。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:12–14; 哥林多后书 7:1; 希伯来书 9:14"> 所以我们要离开有关基督的初级道理，努力迈向成熟，而不是再次打基础：教导为致死的行为悔改、信靠上帝、</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 15:13–57; 使徒行传 17:31–32; 罗马书 6:3–5"> 各种洗礼、按手礼、死人复活、永远的审判等道理。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:21; 哥林多前书 16:7; 哥林多前书 4:19"> 上帝若许可，我们会这样做。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:26–29; 彼得后书 2:20–22; 马太福音 5:13"> 有些人曾蒙上帝光照，尝过天赐恩典的滋味，有份于圣灵，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:3; 路加福音 8:13; 马太福音 13:20–21"> 尝过上帝之道的甘美，领悟到永世的权能，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 2:21; 希伯来书 10:29; 希伯来书 6:4"> 却背弃了真道，让他们重新悔改是不可能的。因为他们是把上帝的儿子重新钉在十字架上，使祂公开受辱，结果自招损害。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 10:12; 以赛亚书 44:3; 诗篇 65:9–13"> 一块经常受到雨水滋润的田地若为耕种的人长出庄稼来，就蒙上帝赐福；</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 3:17–18; 约翰福音 15:6; 路加福音 13:7–9"> 若长出来的尽是荆棘和蒺藜，就毫无价值，会面临被咒诅的危险，最后必遭焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:39; 哥林多后书 7:10; 希伯来书 6:4–6"> 亲爱的弟兄姊妹，虽然我们这样说，却深信你们的光景比这强，有得救的表现。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 10:42; 希伯来书 13:16; 加拉太书 6:10"> 因为上帝并非不公义，以致忘记你们为祂所做的工作，以及你们过去和现在服侍圣徒所表现的爱心。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:5–8; 希伯来书 3:6; 罗马书 5:2–5"> 愿你们各人从始至终表现出同样的殷勤，以便对所盼望的有完全的把握。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:7; 希伯来书 10:36; 约翰一书 2:25"> 这样，你们就不致懒散，可以效法那些凭信心和忍耐承受应许的人。</span>
</div>
</div>

## 上帝的应许可靠

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 22:15–18; 路加福音 1:73; 耶利米书 22:5"> 当初，上帝赐给亚伯拉罕应许的时候，因为没有比自己更大的可以凭着起誓，就凭自己起誓说：</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:17; 申命记 1:10; 尼希米记 9:23"> “我必赐福给你，使你子孙繁盛。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记22:17。">a</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="创世记 12:2–3; 罗马书 4:17–25; 出埃及记 1:7"> 亚伯拉罕经过耐心的等待，得到了上帝的应许。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 22:11; 希伯来书 6:13; 创世记 31:53"> 人总是指着比自己更大的起誓，并用誓言作保证来了结各种争论。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 6:18; 箴言 19:21; 以赛亚书 55:11"> 同样，上帝为要向承受应许的人显明祂的旨意绝不更改，就用誓言向他们保证。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 23:19; 提多书 1:2; 撒母耳记上 15:29"> 上帝绝不说谎，祂赐下永不改变的应许和誓言，使我们这些寻找避难所的人大得鼓励，持定摆在前面的盼望。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 43:5; 罗马书 5:5–10; 希伯来书 9:7"> 我们有这盼望作我们灵魂的锚，既安稳又可靠，一直通往幔子后面的至圣所。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 4:14; 希伯来书 3:1; 希伯来书 5:6"> 耶稣照麦基洗德的模式成了永远的大祭司，祂是先行者，已经替我们进入了至圣所。</span>
</div>
</div>

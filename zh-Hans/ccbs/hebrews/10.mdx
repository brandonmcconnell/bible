## 永远的赎罪祭

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:5; 希伯来书 9:11; 歌罗西书 2:17"> 律法只是将来美事的一个投影，并非本体的真像，所以年复一年地献同样的祭物，绝不能使前来敬拜的人纯全，</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:25; 弥迦书 7:19; 诗篇 103:12"> 否则，献祭的事早已终止了。因为敬拜的人若献一次祭就能彻底得到洁净，早就不会再觉得有罪了。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 9:7; 出埃及记 30:10; 利未记 23:27–28"> 然而，每年献祭，都会使人想起自己的罪来，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:11; 以赛亚书 1:11–15; 弥迦书 6:6–8"> 因为公牛和山羊的血根本不能除去人的罪。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 40:6–8; 以赛亚书 1:11; 以赛亚书 7:14"> 所以，基督来到世上时曾说：<br /><span className="pl pl-1">“上帝啊，祭物和供物非你所悦，</span><br /><span className="pl pl-1">你为我预备了身体。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 1:10; 马太福音 3:17; 诗篇 147:11"> <span className="pl pl-1">燔祭和赎罪祭非你所爱。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 40:7–8; 约翰福音 4:34; 约翰福音 6:38"> <span className="pl pl-1">于是我说，</span><br /><span className="pl pl-1">‘上帝啊，我来是要遵行你的旨意，</span><br /><span className="pl pl-1">我的事都记在圣经上了。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇40:6‑8。">a</a></sup><br /><span className="pl pl-1">”</span></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:5; 马可福音 12:33"> 基督首先说：“祭物、供物、燔祭和赎罪祭都不是你想要的，也不是你喜爱的。”这些都是依照律法献上的。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 7:18–19; 希伯来书 12:27–28; 希伯来书 10:7"> 然后祂又说：“看啊，我来是要遵行你的旨意。”可见祂为了设立后者，废除了前者。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:14; 希伯来书 10:12; 哥林多前书 6:11"> 靠着上帝的旨意，耶稣基督只一次献上自己的身体，便使我们永远圣洁了。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 5:1; 民数记 28:3; 希伯来书 10:4"> 祭司都要天天站着供职，一次次地献上同样的祭物，只是这些祭物根本不能除罪。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 1:3; 歌罗西书 3:1; 罗马书 8:34"> 而基督一次献上自己成为永远的赎罪祭后，就坐在上帝的右边，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:13; 诗篇 110:1; 路加福音 20:43"> 等待祂的仇敌成为祂的脚凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 7:25; 希伯来书 10:1; 希伯来书 9:14"> 祂凭一次牺牲，使那些得以圣洁的人永远纯全。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7; 启示录 2:11; 启示录 3:6"> 圣灵也向我们做见证，说：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 31:33–34; 希伯来书 8:8–12; 罗马书 11:27"> <span className="pl pl-1">“主说：‘那些日子以后，</span><br /><span className="pl pl-1">我将与他们立这样的约，</span><br /><span className="pl pl-1">我要把我的律法放在他们心上，</span><br /><span className="pl pl-1">写在他们脑中。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶利米书31:33。">b</a></sup><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 31:34; 希伯来书 8:12"> <span className="pl pl-1">我要忘掉他们的罪恶和过犯。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶利米书31:34。">c</a></sup><br /><span className="pl pl-1">”</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 10:2; 希伯来书 10:14"> 既然过犯和罪恶已经得到赦免，就不需要再为罪献祭了。</span>
</div>
</div>

## 坚忍到底

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 2:18; 希伯来书 9:12; 希伯来书 4:16"> 弟兄姊妹，耶稣为我们开辟了一条又新又活的路，使我们可以靠着祂的血穿过幔子，就是祂的身体，坦然进入至圣所。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 2:17; 希伯来书 4:14–16; 希伯来书 8:1"> 并且，我们有一位大祭司管理上帝的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 36:25; 约翰福音 3:5; 以弗所书 5:26"> 祂洁净了我们被罪困扰的良心，用清水洗净了我们的身体。因此，我们要信心十足、真诚地到上帝面前。</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒罗尼迦前书 5:24; 哥林多前书 1:9; 帖撒罗尼迦后书 3:3"> 我们要坚定不移地持守我们所认定的盼望，因为赐应许的那位是信实的。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:11; 约翰一书 3:18; 希伯来书 13:1"> 我们要想办法彼此相顾，激发爱心，勉励行善。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 2:42; 帖撒罗尼迦前书 5:11; 马太福音 18:20"> 不要像那些停止惯了的人一样停止聚会，要互相鼓励，既然知道主再来的日子近了，更要如此。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:20–22; 希伯来书 6:4–6; 约翰福音 9:41"> 因为我们知道了真理以后，若仍然故意犯罪，就再没有赎罪祭了，</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 26:11; 希伯来书 2:3; 西番雅书 1:18"> 只有可怕的审判和烧灭敌对者的烈火等候我们。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:2; 申命记 19:15; 申命记 17:2–13"> 人违背摩西的律法，经两三个人指证后，尚且被毫不留情地处死，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 6:6; 以弗所书 4:30; 以赛亚书 63:10"> 更何况人践踏上帝的儿子，轻看那使人圣洁的立约之血，又藐视赐人恩典的圣灵？这等人该受多么重的刑罚啊！</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 32:35–36; 罗马书 12:19; 那鸿书 1:2"> 我们知道上帝说过：“申冤在我，我必报应。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="申命记32:35。">d</a></sup>祂又说：“主要审判祂的子民。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="申命记32:36；诗篇135:14。">e</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 10:28; 路加福音 12:5; 希伯来书 12:29"> 落在永活上帝的手中是可怕的！</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 6:4; 希伯来书 12:4; 提摩太后书 2:3–13"> 你们要回想当初的日子，那时你们蒙了光照以后，忍受了各种苦难的煎熬。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 4:9; 腓立比书 4:14; 希伯来书 11:36"> 有时候，你们在众目睽睽之下被辱骂，受迫害；有时候，你们和遭受这样苦难的人相依为伴。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:4; 提摩太后书 1:16; 马太福音 5:11–12"> 你们体恤那些坐牢的人，即使你们的家业被抢夺，仍然甘心忍受，因为你们知道自己有更美的、永远长存的家业。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 15:58; 加拉太书 6:8–10; 希伯来书 3:6"> 所以切勿失去勇敢的心，因为勇敢的心会给你们带来大赏赐。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 12:1; 诗篇 37:7; 雅各书 5:7–11"> 你们需要坚忍到底，这样你们遵行了上帝的旨意后，便可以得到祂的应许。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 5:7–9; 哈巴谷书 2:3–4; 路加福音 18:8"> 因为“将要来临的那位很快要来了，绝不迟延。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以赛亚书26:20；哈巴谷书2:3、4。">f</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太书 3:11; 哈巴谷书 2:4; 罗马书 1:17"> 属我的义人必靠信心而活。他若畏缩退后，我必不喜悦他。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="哈巴谷书2:3、4。">g</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="约翰一书 5:5; 彼得前书 1:5; 马可福音 16:16"> 但我们都不是退后走向灭亡的人，而是因为有信心而灵魂得救的人。</span>
</div>

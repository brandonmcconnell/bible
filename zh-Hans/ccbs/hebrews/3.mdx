## 耶稣超越摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:9; 腓立比书 3:14; 希伯来书 4:14–15"> 因此，同蒙天召的圣洁弟兄姊妹，你们应当仔细思想那位我们公认为特使和大祭司的耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 12:7; 提摩太前书 3:15; 以弗所书 2:22"> 祂向委任祂的上帝尽忠，就好像摩西向上帝的全家尽忠一样。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 3:9; 彼得前书 2:5–7; 撒迦利亚书 6:12–13"> 然而祂却比摩西配得更大的荣耀，就好像建造房子的人比房子更尊贵一样。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 3:3; 希伯来书 1:2; 以斯帖记 2:10"> 因为房子都是人建造的，但建造万物的是上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 12:7; 希伯来书 3:2; 出埃及记 14:31"> 摩西以仆人的身份向上帝的全家尽忠，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="民数记12:7。">a</a></sup>为将来要宣告的事做见证。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 6:16; 哥林多前书 3:16; 希伯来书 10:35"> 但基督是以儿子的身份忠心治理上帝的家。我们若持定信念和引以为荣的盼望，就是祂的家了。</span>
</div>
</div>

## 不可存刚硬的心

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 95:7–11; 希伯来书 3:15; 以赛亚书 55:3"> 因此，正如圣灵说：<br /><span className="pl pl-1">“你们今日若听见祂的声音，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及记 17:7; 撒迦利亚书 7:11–12"> <span className="pl pl-1">不可心里顽固，</span><br /><span className="pl pl-1">像从前在旷野试探祂、悖逆祂一样。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:36; 申命记 4:9; 出埃及记 19:4"> <span className="pl pl-1">你们的祖先虽然在那里观看我的作为四十年之久，</span><br /><span className="pl pl-1">却仍然试我、探我。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 95:10; 帖撒罗尼迦后书 2:10–12; 诗篇 67:2"> <span className="pl pl-1">所以，我向那世代的人发怒，</span><br /><span className="pl pl-1">说：‘他们心向歧途，</span><br /><span className="pl pl-1">不认识我的道路。’</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:34–35; 希伯来书 4:3; 民数记 32:10–13"> <span className="pl pl-1">因此我愤然起誓说，</span><br /><span className="pl pl-1">‘他们绝不可进入我的安息。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇95:7‑11。">b</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:5; 耶利米书 7:24; 耶利米书 17:9"> 弟兄姊妹，要谨慎，免得你们当中有人心存恶念，不肯相信，背弃了永活的上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 5:11; 希伯来书 10:24–25; 提摩太后书 4:2"> 趁着还有今日，要天天互相劝勉，免得有人被罪迷惑，心里变得刚硬。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 3:6; 希伯来书 6:11; 希伯来书 12:10"> 如果我们将起初的信念坚持到底，便在基督里有份了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7–8; 诗篇 95:7; 希伯来书 10:38"> 圣经上说：<br /><span className="pl pl-1">“你们今日若听见祂的声音，</span><br /><span className="pl pl-1">不可心里顽固，像从前悖逆祂一样。”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇95:7、8。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 14:2; 民数记 14:30; 民数记 26:65"> 听见祂的声音却又悖逆祂的是谁呢？不就是摩西从埃及领出来的那些人吗？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:29; 民数记 26:64–65; 民数记 14:32–33"> 四十年之久惹上帝发怒的是谁呢？不就是那些犯罪作恶并倒毙在旷野的人吗？</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 14:30; 希伯来书 4:6; 申命记 1:34–35"> 上帝起誓不准谁进入祂的安息呢？不就是那些不肯顺从的人吗？</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:5; 约翰福音 3:36; 马可福音 16:16"> 可见，他们不能进入上帝的安息是因为不信的缘故。</span>
</div>
</div>

## 大祭司麦基洗德

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:18–20; 诗篇 57:2; 希伯来书 6:20"> 这位麦基洗德是撒冷王，也是至高上帝的祭司。当年亚伯拉罕杀败众王凯旋的时候，麦基洗德迎上去为他祝福，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 18:21; 诗篇 85:10–11; 撒母耳记上 8:17"> 亚伯拉罕把所得财物的十分之一给了他。麦基洗德这名字的原意是“公义之王”，后来他又被称为撒冷王，意思是“和平之王”。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:17; 希伯来书 7:23–28; 出埃及记 6:20–27"> 他没有父母，没有族谱，生命无始无终，他跟上帝的儿子相似，永远担任祭司的职分。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 14:20; 使徒行传 2:29; 使徒行传 7:8–9"> 试想，连我们的祖先亚伯拉罕都将战利品的十分之一给了他，可见他是何等的尊贵！</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 27:30–33; 历代志下 31:4–6; 民数记 18:21–32"> 按照摩西律法，那些做祭司的利未后裔可以照例向百姓，就是自己的同胞收取十分之一，尽管他们也是亚伯拉罕的后裔。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 4:13; 希伯来书 7:3–4; 创世记 13:14–17"> 但这位与他们并非同族的麦基洗德，不单接受了亚伯拉罕给他的十分之一，还为承受应许的亚伯拉罕祝福。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 30:27; 创世记 48:15–20; 提摩太前书 3:16"> 毫无疑问，那为人祝福的总比领受祝福的位分大。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 6:20; 希伯来书 5:6; 启示录 1:18"> 那些收取十分之一的利未祭司都是会死的人，但那位收取十分之一的麦基洗德被证明仍然活着。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 5:12; 创世记 14:20; 希伯来书 7:4"> 也可以说，连接受十分之一奉献的利未也透过亚伯拉罕向麦基洗德纳了十分之一。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 35:11; 希伯来书 7:5; 创世记 46:26"> 因为亚伯拉罕遇见麦基洗德时，利未还在他祖先的身体里。</span>
</div>
</div>

## 大祭司耶稣

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 8:7; 加拉太书 2:21; 加拉太书 4:9"> 以色列人在利未祭司制度的基础上承受律法，如果通过这个祭司制度可以达到纯全，又何必照麦基洗德的模式而不是亚伦的模式，另外兴起一位祭司呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 31:31–34; 以赛亚书 66:21; 以西结书 16:61"> 既然这祭司制度更改了，律法也必须更改。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 7:11; 希伯来书 7:14; 民数记 17:5"> 因为这里所说的这位祭司属于别的支派，那支派里从来没有在祭坛前供职的祭司。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 5:2; 以赛亚书 11:1; 路加福音 3:33"> 显然，我们的主属于犹大支派，摩西从来没有说这个支派会出祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 110:4; 希伯来书 7:17–21; 希伯来书 7:3"> 如果照麦基洗德的模式另外兴起一位祭司，祂做祭司不是照律法要求的血统关系，而是照不能朽坏之生命的大能，事情就更加清楚了。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 110:4; 希伯来书 5:6; 希伯来书 7:21"> 因为有一处经文为祂做见证说：“你照麦基洗德的模式永远做祭司。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇110:4。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:3; 使徒行传 13:39; 加拉太书 4:9"> 以前的条例由于本身的弱点和无用被废除了，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:39; 希伯来书 4:16; 希伯来书 9:9"> 因为律法并没有使什么变得纯全。但如今有了一个更美好的盼望，我们凭这个盼望来到上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 18:7; 希伯来书 5:6; 诗篇 110:4"> 此外，耶稣做祭司还有誓言作保证，其他人做祭司却没有誓言作保证。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 6:16–18"> 上帝起誓立耶稣为祭司，说：<br /><span className="pl pl-1">“主起了誓，绝不反悔，</span><br /><span className="pl pl-1">你永远做祭司。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇110:4。">b</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:25; 创世记 44:32; 希伯来书 8:6–12"> 这誓言使耶稣成了更美之约的保证人。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 12:10–11; 历代志上 6:3–14; 希伯来书 7:8"> 以前做祭司的人数极多，但因为受死亡的限制，都不能长久担任圣职。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 12:34; 希伯来书 7:28; 以赛亚书 9:6–7"> 然而，耶稣永远活着，祂的祭司职位也永不更改。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 8:34; 约翰一书 2:1–2; 提摩太前书 2:5"> 所以祂能完全拯救那些靠着祂来到上帝面前的人，因为祂永远活着，为他们祈求。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 5:21; 希伯来书 4:14–15; 彼得前书 2:22"> 我们所需要的，正是这样一位圣洁无瑕、纯全无过、远离罪恶、超越诸天的大祭司。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 9:28; 希伯来书 9:12; 希伯来书 9:14"> 祂无需像其他大祭司那样每天先为自己的罪献祭，然后为百姓的罪献祭，因为祂一次献上自己的生命，便永远完成了赎罪的工作。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:10; 希伯来书 7:21; 希伯来书 1:2"> 根据律法所立的大祭司都有人的软弱，但律法之后凭誓言所立的大祭司圣子永远纯全。</span>
</div>

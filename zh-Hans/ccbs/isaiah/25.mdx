## 赞美之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 15:2; 诗篇 118:28; 民数记 23:19"> 耶和华啊！你是我的上帝，我要尊崇你，赞美你的名。你信实无比，<br /><span className="pl pl-1">按你古时定下的计划行了奇妙的事。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 17:1; 以赛亚书 13:22; 以赛亚书 25:12"> <span className="pl pl-1">你使城邑沦为废墟，</span><br /><span className="pl pl-1">使坚垒沦为荒场。</span><br /><span className="pl pl-1">外族人的宫殿不复存在，</span><br /><span className="pl pl-1">永远不能重建。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 14:9; 以赛亚书 49:23–26; 诗篇 46:10–11"> <span className="pl pl-1">因此，强大的民必颂扬你，</span><br /><span className="pl pl-1">残暴之邦的城邑必敬畏你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="西番雅书 3:12; 以赛亚书 32:2; 雅各书 2:5"> <span className="pl pl-1">你是贫穷人的避难所，</span><br /><span className="pl pl-1">是困苦之人患难中的避难所，</span><br /><span className="pl pl-1">你是避风港，</span><br /><span className="pl pl-1">是酷暑中的阴凉处。</span><br /><span className="pl pl-1">残暴之徒的气息好像吹袭墙垣的暴风，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="启示录 20:8–9; 以赛亚书 49:10; 诗篇 105:39"> <span className="pl pl-1">又像干旱之地的热气。</span><br /><span className="pl pl-1">你平息外族人的喧哗，</span><br /><span className="pl pl-1">止息残暴之徒的歌声，</span><br /><span className="pl pl-1">好像云朵消去酷热。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 8:11; 诗篇 63:5; 撒迦利亚书 9:16–17"> 在锡安山上，万军之耶和华必为天下万民摆设丰盛的宴席，有陈年佳酿和精选的美食。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:18; 以赛亚书 60:1–3; 马太福音 27:51"> 在这山上，祂必除去遮蔽万民的面纱和笼罩万国的幔子。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 21:4; 启示录 7:17; 哥林多前书 15:54"> 祂必永远吞灭死亡。主耶和华必擦去各人脸上的眼泪，从世上除掉祂子民的羞辱。这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 27:14; 创世记 49:18; 弥迦书 7:7"> 到那日，人们必说：“看啊，这是我们的上帝，我们信靠祂，祂拯救了我们。这是耶和华，我们信靠祂，我们要因祂的救恩而欢喜快乐。”</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 25:6; 以赛亚书 18:4; 西番雅书 2:9"> 耶和华必伸手保护这山，但摩押人必在本地被践踏，像干草被践踏在粪池中。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 16:14; 以赛亚书 2:11; 以赛亚书 16:6"> 他们必在里面张开手臂，好像张开手臂游泳的人一样。耶和华必摧毁他们的骄傲，挫败他们手中的诡计。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 26:5; 启示录 18:21; 以赛亚书 14:23"> 祂必拆毁他们高大坚固的城墙，将其夷为平地、化为尘土。</span>

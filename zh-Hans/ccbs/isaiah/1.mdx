## 上帝责备叛逆的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="申命记 32:1; 申命记 30:19; 弥迦书 1:2"> <span className="pl pl-1">诸天啊，请听！</span><br /><span className="pl pl-1">大地啊，要侧耳听！</span><br /><span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“我把孩子抚育成人，</span><br /><span className="pl pl-1">他们竟然背叛我。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 8:7; 耶利米书 4:22; 以赛亚书 44:18"> <span className="pl pl-1">牛认识主人，</span><br /><span className="pl pl-1">驴也认得主人的槽，</span><br /><span className="pl pl-1">以色列却不认识我，</span><br /><span className="pl pl-1">我的子民却不明白。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 5:24; 耶利米书 2:17; 耶利米书 2:13"> <span className="pl pl-1">唉！这罪恶的民族，</span><br /><span className="pl pl-1">恶贯满盈的百姓，</span><br /><span className="pl pl-1">作恶的子孙，</span><br /><span className="pl pl-1">败坏的儿女！</span><br /><span className="pl pl-1">他们背弃耶和华，</span><br /><span className="pl pl-1">藐视以色列的圣者，</span><br /><span className="pl pl-1">与祂疏远。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="但以理书 9:8–11; 以西结书 24:13; 耶利米书 5:3"> <span className="pl pl-1">你们为什么一再叛逆？</span><br /><span className="pl pl-1">你们为什么还要受责打？</span><br /><span className="pl pl-1">你们已经头破血流，</span><br /><span className="pl pl-1">身心疲惫不堪。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 6:14; 耶利米书 33:6; 马太福音 9:12"> <span className="pl pl-1">你们已经体无完肤，</span><br /><span className="pl pl-1">从头到脚伤痕累累，尽是瘀肿和伤口，</span><br /><span className="pl pl-1">没有清洗，没有包扎，</span><br /><span className="pl pl-1">也没有敷药。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米哀歌 5:2; 申命记 28:43; 申命记 28:33"> <span className="pl pl-1">你们的土地荒凉，</span><br /><span className="pl pl-1">城邑化为灰烬。</span><br /><span className="pl pl-1">你们亲眼目睹自己的田园被外族人侵吞、毁坏、变成不毛之地。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亚书 9:9; 约翰福音 12:15; 撒迦利亚书 2:10"> <span className="pl pl-1">仅存的少女锡安也像葡萄园里的草棚，</span><br /><span className="pl pl-1">像瓜田中的茅舍，</span><br /><span className="pl pl-1">像被困无援的孤城。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 9:29; 以赛亚书 37:31–32; 创世记 19:24"> <span className="pl pl-1">若不是万军之耶和华让我们一些人存活，</span><br /><span className="pl pl-1">我们早就像所多玛和蛾摩拉一样灭亡了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="启示录 11:8; 以西结书 16:49; 阿摩司书 9:7"> <span className="pl pl-1">你们这些所多玛的首领啊，</span><br /><span className="pl pl-1">要聆听耶和华的话！</span><br /><span className="pl pl-1">你们这些蛾摩拉的百姓啊，</span><br /><span className="pl pl-1">要侧耳听我们上帝的训诲！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 15:22; 阿摩司书 5:21; 耶利米书 6:20"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“你们献上许多祭物，对我有什么用呢？</span><br /><span className="pl pl-1">我厌烦公绵羊的燔祭和肥畜的脂肪，</span><br /><span className="pl pl-1">我不喜欢公牛、羊羔和公山羊的血。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 34:23; 出埃及记 23:17; 弥迦书 6:8"> <span className="pl pl-1">“你们来朝见我的时候，</span><br /><span className="pl pl-1">谁要求你们带着这些来践踏我的院宇呢？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 66:3; 玛拉基书 1:10; 马太福音 15:9"> <span className="pl pl-1">不要再带毫无意义的祭物了。</span><br /><span className="pl pl-1">我憎恶你们烧的香。</span><br /><span className="pl pl-1">我无法容忍你们又作恶又举行庄严的聚会，</span><br /><span className="pl pl-1">就是你们的朔日</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日”即每月初一。">a</a></sup><br /><span className="pl pl-1">、安息日和大会。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="阿摩司书 5:21; 以赛亚书 43:24; 以赛亚书 7:13"> <span className="pl pl-1">我憎恶你们的朔日及各种节期，</span><br /><span className="pl pl-1">它们成了我的重担，</span><br /><span className="pl pl-1">令我厌倦。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="弥迦书 3:4; 以赛亚书 59:2–3; 箴言 1:28"> <span className="pl pl-1">你们举手祷告，我必掩面不理。</span><br /><span className="pl pl-1">即使你们祷告再多，</span><br /><span className="pl pl-1">我也不会听，</span><br /><span className="pl pl-1">因为你们双手沾满鲜血。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:11; 以赛亚书 55:6–7; 彼得前书 2:1"> <span className="pl pl-1">你们要洗净自己，</span><br /><span className="pl pl-1">不要让我再看见你们的恶行，</span><br /><span className="pl pl-1">要停止作恶。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="弥迦书 6:8; 耶利米书 22:3; 诗篇 82:3–4"> <span className="pl pl-1">你们要学习行善，</span><br /><span className="pl pl-1">追求正义，</span><br /><span className="pl pl-1">帮助受欺压的，</span><br /><span className="pl pl-1">替孤儿辩护，</span><br /><span className="pl pl-1">为寡妇申冤。”</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 44:22; 启示录 7:14; 诗篇 51:7"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“来吧，我们彼此理论！</span><br /><span className="pl pl-1">你们的罪虽如朱红，</span><br /><span className="pl pl-1">也必洁白如雪；</span><br /><span className="pl pl-1">你们的罪虽如绯红，</span><br /><span className="pl pl-1">也必白如羊毛。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 30:15–16; 以赛亚书 3:10; 约珥书 2:26"> <span className="pl pl-1">如果你们愿意听从，</span><br /><span className="pl pl-1">就必享用这地方的美好出产。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:12; 以赛亚书 58:14; 民数记 23:19"> <span className="pl pl-1">如果你们执意叛逆，</span><br /><span className="pl pl-1">就必丧身刀下。”</span><br /><span className="pl pl-1">这是耶和华亲口说的。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 22:1–23; 撒迦利亚书 8:3; 西番雅书 3:1–3"> <span className="pl pl-1">忠信的城竟变成了妓女！</span><br /><span className="pl pl-1">从前充满公平，</span><br /><span className="pl pl-1">是公义之家，</span><br /><span className="pl pl-1">现在却住着凶手。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 6:28–30; 耶利米哀歌 4:1–2; 何西阿书 4:18"> <span className="pl pl-1">你的银子变为渣滓；</span><br /><span className="pl pl-1">你的美酒掺了水分。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="弥迦书 7:3; 出埃及记 23:8; 撒迦利亚书 7:10"> <span className="pl pl-1">你的首领是叛逆之徒，</span><br /><span className="pl pl-1">与盗贼为伍，</span><br /><span className="pl pl-1">个个喜爱贿赂，</span><br /><span className="pl pl-1">贪图好处，</span><br /><span className="pl pl-1">不为孤儿辩护，</span><br /><span className="pl pl-1">不替寡妇申冤。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 60:16; 以赛亚书 35:4; 申命记 28:63"> <span className="pl pl-1">所以，主——万军之耶和华，</span><br /><span className="pl pl-1">以色列的大能者说：</span><br /><span className="pl pl-1">“唉！我要向我的敌人报仇，</span><br /><span className="pl pl-1">向我的仇敌雪恨。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="玛拉基书 3:3; 耶利米书 9:7; 以赛亚书 4:4"> <span className="pl pl-1">我必出手攻击你，</span><br /><span className="pl pl-1">用碱炼净你的渣滓，</span><br /><span className="pl pl-1">除尽你的杂质。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 33:7; 撒迦利亚书 8:3; 以赛亚书 62:1–2"> <span className="pl pl-1">我必像从前一样恢复你的审判官，</span><br /><span className="pl pl-1">像起初一样恢复你的谋士。</span><br /><span className="pl pl-1">之后，你必被称为公义之城，</span><br /><span className="pl pl-1">忠信之邑。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 62:12; 以赛亚书 45:21–25; 以赛亚书 5:16"> <span className="pl pl-1">耶和华必因祂的公正救赎锡安，</span><br /><span className="pl pl-1">必因祂的公义拯救城中悔改的人。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 1:8–9; 诗篇 1:6; 以赛亚书 30:13"> <span className="pl pl-1">但叛逆之辈和犯罪之徒必同遭毁灭，</span><br /><span className="pl pl-1">背弃耶和华的人必灭亡。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 65:3; 以赛亚书 57:5; 以赛亚书 66:17"> <span className="pl pl-1">你们必因所喜爱的圣橡树而抱愧，</span><br /><span className="pl pl-1">必因所选择的偶像园而蒙羞。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 17:5–6; 以西结书 17:9–10; 马太福音 21:19"> <span className="pl pl-1">你们必像叶子枯萎的橡树，</span><br /><span className="pl pl-1">又如无水的园子。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 66:24; 以西结书 32:21; 玛拉基书 4:1"> <span className="pl pl-1">有权势的人像麻绒，他的行为如火花，</span><br /><span className="pl pl-1">两者要一同焚毁，无人能救。</span></span>
</div>

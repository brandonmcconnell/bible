## 圣洁之路

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 36:35; 以赛亚书 51:3; 以赛亚书 55:12–13"> 沙漠和干旱之地必欢喜；<br /><span className="pl pl-1">旷野必快乐，开满鲜花，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 25:9; 以赛亚书 60:13; 阿摩司书 9:13–15"> <span className="pl pl-1">无比繁盛，充满欢声笑语，</span><br /><span className="pl pl-1">享有黎巴嫩的荣耀、</span><br /><span className="pl pl-1">迦密和沙仑的荣美。</span><br /><span className="pl pl-1">人们必看见耶和华的荣耀，</span><br /><span className="pl pl-1">我们上帝的荣美。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:12; 约伯记 4:3–4; 路加福音 22:32"> <span className="pl pl-1">你们要使软弱的人强壮，</span><br /><span className="pl pl-1">使双膝无力的人站稳。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 5:7–9; 以赛亚书 41:10–14; 哈该书 2:4"> <span className="pl pl-1">要对胆怯的人说：</span><br /><span className="pl pl-1">“你们要刚强，不要害怕。</span><br /><span className="pl pl-1">看啊，你们的上帝必来为你们复仇，施行报应，</span><br /><span className="pl pl-1">祂必来拯救你们。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 42:6–7; 路加福音 7:20–23; 以赛亚书 29:18"> <span className="pl pl-1">那时，瞎眼的必看见，</span><br /><span className="pl pl-1">耳聋的必听见，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 5:8–9; 约翰福音 7:37–39; 路加福音 11:14"> <span className="pl pl-1">瘸腿的必跳跃如鹿，</span><br /><span className="pl pl-1">哑巴必欢呼歌唱；</span><br /><span className="pl pl-1">旷野有泉水涌流，</span><br /><span className="pl pl-1">沙漠里河川奔腾；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 26:18; 以赛亚书 49:10; 约翰福音 4:14"> <span className="pl pl-1">炙热的沙漠变成池塘，</span><br /><span className="pl pl-1">旱地涌出甘泉；</span><br /><span className="pl pl-1">豺狼的巢穴长出青草、</span><br /><span className="pl pl-1">芦苇和蒲草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="马太福音 7:13–14; 以赛亚书 42:16; 约翰福音 14:6"> <span className="pl pl-1">那里必有一条大路，</span><br /><span className="pl pl-1">被称为“圣洁之路”，</span><br /><span className="pl pl-1">专供蒙救赎的人行走。</span><br /><span className="pl pl-1">污秽的人都不能走这条路，</span><br /><span className="pl pl-1">愚昧的人也不能信步其上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 62:12; 何西阿书 2:18; 利未记 26:6"> <span className="pl pl-1">那里必没有狮子，</span><br /><span className="pl pl-1">也没有恶兽，</span><br /><span className="pl pl-1">没有它们的踪影，</span><br /><span className="pl pl-1">只有蒙救赎的人行走。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:19; 启示录 21:4; 以赛亚书 25:8"> <span className="pl pl-1">耶和华救赎的子民必归回，</span><br /><span className="pl pl-1">欢唱着回到锡安，</span><br /><span className="pl pl-1">永远的福乐必临到他们头上。</span><br /><span className="pl pl-1">他们必欢喜快乐，</span><br /><span className="pl pl-1">再没有忧愁和叹息。</span></span>
</div>

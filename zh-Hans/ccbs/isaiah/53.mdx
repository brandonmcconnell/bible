## 受苦的仆人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 12:38; 罗马书 10:16–17; 哥林多前书 1:18"> 谁相信我们所传的呢？<br /><span className="pl pl-1">耶和华的臂膀向谁彰显呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:6–7; 以赛亚书 52:14; 约翰福音 1:10–14"> <span className="pl pl-1">祂像嫩芽一样在耶和华面前长大，</span><br /><span className="pl pl-1">像生长在旱地里的根。</span><br /><span className="pl pl-1">祂没有俊美威荣的外表吸引我们，</span><br /><span className="pl pl-1">也没有令我们仰慕的容貌。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 26:67; 约翰福音 1:10–11; 以赛亚书 53:10"> <span className="pl pl-1">祂被藐视，遭人厌弃，</span><br /><span className="pl pl-1">饱受痛苦，历尽忧患。</span><br /><span className="pl pl-1">人们对祂不屑一顾，</span><br /><span className="pl pl-1">我们也不尊重祂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:24; 马太福音 8:17; 加拉太书 3:13"> <span className="pl pl-1">其实祂担当了我们的忧患，</span><br /><span className="pl pl-1">背负了我们的痛苦。</span><br /><span className="pl pl-1">我们却以为是上帝责罚、</span><br /><span className="pl pl-1">击打、苦待祂。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:24–25; 彼得前书 3:18; 马太福音 20:28"> <span className="pl pl-1">谁知祂是因我们的过犯而被刺透，</span><br /><span className="pl pl-1">因我们的罪恶而被压伤。</span><br /><span className="pl pl-1">我们因祂所受的刑罚而得到平安，</span><br /><span className="pl pl-1">因祂所受的鞭伤而得到医治。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:25; 彼得前书 3:18; 诗篇 119:176"> <span className="pl pl-1">我们都像迷路的羊，</span><br /><span className="pl pl-1">各人偏行己路，</span><br /><span className="pl pl-1">但耶和华却让祂承担我们众人的罪恶。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 8:32–33; 马太福音 26:63; 彼得前书 2:23"> <span className="pl pl-1">祂遭欺压、受痛苦，</span><br /><span className="pl pl-1">却默然不语，</span><br /><span className="pl pl-1">像被人牵去宰杀的羔羊，</span><br /><span className="pl pl-1">又如在剪毛人手下一声不吭的绵羊，</span><br /><span className="pl pl-1">祂默然不语。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 3:18; 使徒行传 8:33; 马太福音 26:65–66"> <span className="pl pl-1">祂受到欺压和审判，被押去处死。</span><br /><span className="pl pl-1">祂那个世代的人谁会想到祂受鞭打、</span><br /><span className="pl pl-1">从世上被除去是因为我百姓的过犯呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 27:57–60; 彼得前书 2:22; 约翰一书 3:5"> <span className="pl pl-1">虽然祂没有做过残暴之事，</span><br /><span className="pl pl-1">口中也没有诡诈，</span><br /><span className="pl pl-1">人却将祂与恶人同葬，</span><br /><span className="pl pl-1">与富人同墓。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:32; 哥林多后书 5:21; 加拉太书 3:13"> <span className="pl pl-1">然而，祂被压伤、</span><br /><span className="pl pl-1">受痛苦是耶和华的旨意；</span><br /><span className="pl pl-1">祂的性命作了赎罪祭</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“祂的性命作了赎罪祭”或译“耶和华以祂的性命作赎罪祭”。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">祂必看见自己的后裔，</span><br /><span className="pl pl-1">祂必长久活着。</span><br /><span className="pl pl-1">耶和华的旨意必在祂手中成就。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:18–19; 彼得前书 2:24; 以赛亚书 53:4–6"> <span className="pl pl-1">祂必看见自己劳苦的成果，</span><br /><span className="pl pl-1">并心满意足。</span><br /><span className="pl pl-1">耶和华说：“我公义的仆人必凭祂的知识使许多人被算为义人，</span><br /><span className="pl pl-1">祂要担当他们的罪恶。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 22:37; 希伯来书 9:28; 路加福音 23:32–34"> <span className="pl pl-1">因此，我要使祂与伟人同享尊荣，</span><br /><span className="pl pl-1">跟强者同分战利品，</span><br /><span className="pl pl-1">因为祂献出了自己的生命。</span><br /><span className="pl pl-1">祂被列在罪犯中，</span><br /><span className="pl pl-1">却担当了许多人的罪，</span><br /><span className="pl pl-1">又为罪犯代求。”</span></span>
</div>

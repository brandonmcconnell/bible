## 北国必遭审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿书 7:5; 以赛亚书 28:7; 列王纪下 14:25–27"> 以法莲酒徒引以为荣的华冠有祸了！<br /><span className="pl pl-1">它坐落在醉酒者肥美的山谷顶上，</span><br /><span className="pl pl-1">它的荣美如将残之花。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:30; 那鸿书 1:8; 以西结书 13:11"> <span className="pl pl-1">看啊，主有一位强壮有力的人，</span><br /><span className="pl pl-1">他像冰雹和带来毁灭的暴风，</span><br /><span className="pl pl-1">又像汹涌泛滥的洪水，</span><br /><span className="pl pl-1">他必把华冠摔在地上。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 26:6; 希伯来书 10:29; 启示录 11:2"> <span className="pl pl-1">以法莲酒徒引以为荣的华冠必被践踏在脚下。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="那鸿书 3:12; 弥迦书 7:1; 以赛亚书 28:1"> <span className="pl pl-1">那荣美的将残之花在肥沃的山谷之巅，</span><br /><span className="pl pl-1">它必像夏季到来之前早熟的无花果，</span><br /><span className="pl pl-1">人一看见它就把它摘下吞掉。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 5:4; 以赛亚书 62:3; 以赛亚书 60:19"> <span className="pl pl-1">到那日，万军之耶和华必作祂余民的荣冠和华冕，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 18:32–34; 约翰福音 5:30; 约书亚记 1:9"> <span className="pl pl-1">祂必使审判官公正断案，</span><br /><span className="pl pl-1">赐力量给守城退敌之人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 56:10–12; 路加福音 21:34; 以赛亚书 19:14"> <span className="pl pl-1">但祭司和先知也因醉酒而摇摇晃晃，</span><br /><span className="pl pl-1">因烈酒而东倒西歪。</span><br /><span className="pl pl-1">他们因烈酒而摇摇晃晃、</span><br /><span className="pl pl-1">酩酊大醉，东倒西歪，</span><br /><span className="pl pl-1">他们错解异象，糊涂判案。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 48:26; 箴言 26:11; 哈巴谷书 2:15–16"> <span className="pl pl-1">桌子上到处都是呕吐之物，</span><br /><span className="pl pl-1">一片狼藉。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 131:2; 耶利米书 6:10; 约翰福音 12:38"> <span className="pl pl-1">他们抱怨说：</span><br /><span className="pl pl-1">“祂想教导谁知识呢？</span><br /><span className="pl pl-1">祂想把信息解释给谁呢？</span><br /><span className="pl pl-1">是刚刚断奶、离开母怀的婴孩吗？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 28:13; 提摩太后书 3:7; 耶利米书 11:7"> <span className="pl pl-1">因为祂的教导只是命命令令、命命令令、律律例例、律律例例、这里一点、那里一点。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 14:21; 申命记 28:49; 以赛亚书 33:19"> <span className="pl pl-1">因此，耶和华必用外族人的口和陌生的语言来教训他们。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 11:28–29; 以赛亚书 30:15; 耶利米书 6:16"> <span className="pl pl-1">耶和华曾对他们说：</span><br /><span className="pl pl-1">“这是安歇之地，</span><br /><span className="pl pl-1">让疲乏的人安歇吧。</span><br /><span className="pl pl-1">这是安歇之地。”</span><br /><span className="pl pl-1">他们却不肯听。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 13:14; 以赛亚书 6:9–10; 彼得后书 3:16"> <span className="pl pl-1">所以，对他们来说，</span><br /><span className="pl pl-1">耶和华的话成了命命令令、命命令令、律律例例、律律例例、这里一点、那里一点，</span><br /><span className="pl pl-1">以致他们走路时仰面跌倒，摔伤，落网，被捉。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 28:22; 以赛亚书 29:20; 以赛亚书 1:10"> <span className="pl pl-1">因此，你们这些好讥讽、在耶路撒冷统管百姓的人啊，</span><br /><span className="pl pl-1">要听耶和华的话。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 8:7–8; 以西结书 13:22; 阿摩司书 2:4"> <span className="pl pl-1">你们说：</span><br /><span className="pl pl-1">“我们已经和死亡立约，</span><br /><span className="pl pl-1">与阴间结盟。</span><br /><span className="pl pl-1">势不可挡的灾难席卷而来时，</span><br /><span className="pl pl-1">我们会安然无恙，</span><br /><span className="pl pl-1">因为我们以谎言为庇护所，</span><br /><span className="pl pl-1">以诡诈为藏身处。”</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 118:22; 使徒行传 4:11–12; 彼得前书 2:6–8"> <span className="pl pl-1">所以主耶和华说：</span><br /><span className="pl pl-1">“看啊，我要在锡安放一块基石，</span><br /><span className="pl pl-1">一块经过考验的石头，</span><br /><span className="pl pl-1">一块根基稳固的宝贵房角石，</span><br /><span className="pl pl-1">信靠的人必不会恐慌。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 21:13; 阿摩司书 7:7–9; 启示录 16:21"> <span className="pl pl-1">我必以公平为准绳，</span><br /><span className="pl pl-1">以公义作线锤。</span><br /><span className="pl pl-1">冰雹必砸碎你们虚谎的庇护所，</span><br /><span className="pl pl-1">洪水必淹没你们的藏身处。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 7:7; 以赛亚书 8:10; 以赛亚书 28:15"> <span className="pl pl-1">你们和死亡所立的约必被废弃，</span><br /><span className="pl pl-1">与阴间的结盟必不能长久。</span><br /><span className="pl pl-1">势不可挡的灾难席卷而来时，</span><br /><span className="pl pl-1">你们必遭践踏。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 3:16; 以赛亚书 36:22; 列王纪下 24:2"> <span className="pl pl-1">灾难必不分昼夜、日复一日地袭来，</span><br /><span className="pl pl-1">每次袭来都必掳掠你们。”</span><br /><span className="pl pl-1">明白这信息的人都必惊恐万分。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 64:6; 哥林多前书 1:18–31; 罗马书 9:30–32"> <span className="pl pl-1">你们的床太小，不能舒身；</span><br /><span className="pl pl-1">你们的被子太窄，不足裹身。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此处的床和被子象征他们虚假的安全感。">a</a></sup><br /></span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 14:11; 约书亚记 10:12; 撒母耳记下 5:20"> <span className="pl pl-1">耶和华必像在毗拉心山一样挺身而出，</span><br /><span className="pl pl-1">像在基遍谷一样发怒，</span><br /><span className="pl pl-1">要完成祂奇异的作为，</span><br /><span className="pl pl-1">成就祂不寻常的工作。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 10:22–23; 以赛亚书 24:1–23; 马太福音 27:44"> <span className="pl pl-1">现在你们不要再讥讽了，</span><br /><span className="pl pl-1">以免你们的捆索更沉重，</span><br /><span className="pl pl-1">因为我已从主——万军之耶和华那里听到毁灭全国的谕旨。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 1:2; 耶利米书 22:29; 启示录 2:11"> <span className="pl pl-1">你们要侧耳听我的声音，</span><br /><span className="pl pl-1">留心听我的话语。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 4:3; 何西阿书 10:11–12"> <span className="pl pl-1">难道农夫会一直耕地而不撒种吗？</span><br /><span className="pl pl-1">难道他会一直犁地、耙地吗？</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 4:9; 马太福音 23:23; 出埃及记 9:31–32"> <span className="pl pl-1">他整平土地之后，</span><br /><span className="pl pl-1">难道不种小茴香、大茴香，</span><br /><span className="pl pl-1">按行种小麦，</span><br /><span className="pl pl-1">在合适的地方种大麦，</span><br /><span className="pl pl-1">在田边种粗麦吗？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 31:3–6; 出埃及记 36:2; 约伯记 39:17"> <span className="pl pl-1">因为他的上帝指点他，教导他耕种之道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 41:15; 以赛亚书 27:7–8; 耶利米书 46:28"> <span className="pl pl-1">打小茴香不用大槌，用木棍；</span><br /><span className="pl pl-1">打大茴香不用石磙，用木棒。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 9:9–10; 马太福音 3:12; 约翰福音 12:24"> <span className="pl pl-1">做饼的粮食要磨碎，</span><br /><span className="pl pl-1">没有人会不停地在场上碾压粮食。</span><br /><span className="pl pl-1">马拉着石磙在场上轧过，</span><br /><span className="pl pl-1">也不会把粮食磨碎。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="罗马书 11:33; 耶利米书 32:19; 约伯记 5:9"> <span className="pl pl-1">这些知识都是万军之耶和华所赐的，</span><br /><span className="pl pl-1">祂有奇妙的谋略和伟大的智慧。</span></span>

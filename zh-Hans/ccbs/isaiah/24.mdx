## 主必审判世界

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="那鸿书 2:10; 以赛亚书 2:19; 以赛亚书 42:15"> 看啊，耶和华必摧毁大地，<br /><span className="pl pl-1">使大地荒凉。</span><br /><span className="pl pl-1">祂毁坏地面，驱散万民。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿书 4:9; 耶利米哀歌 5:12–14; 以西结书 7:12–13"> <span className="pl pl-1">那时，祭司和百姓，</span><br /><span className="pl pl-1">主人和仆人，</span><br /><span className="pl pl-1">主母和婢女，</span><br /><span className="pl pl-1">买的和卖的，</span><br /><span className="pl pl-1">贷的和借的，</span><br /><span className="pl pl-1">债主和债户都必遭难。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 24:1; 以赛亚书 6:11; 申命记 29:23"> <span className="pl pl-1">大地必被完全毁坏，洗劫一空。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿书 4:3; 以赛亚书 33:9; 以赛亚书 3:26"> <span className="pl pl-1">大地枯竭凋零，</span><br /><span className="pl pl-1">世界衰败没落，</span><br /><span className="pl pl-1">世上的权贵也败落。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 13:20; 罗马书 8:20–21; 但以理书 7:25"> <span className="pl pl-1">大地被世人玷污，</span><br /><span className="pl pl-1">他们干犯律法，</span><br /><span className="pl pl-1">不守律例，背弃永远的约。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 4:1; 马太福音 7:14; 撒迦利亚书 5:3–4"> <span className="pl pl-1">所以咒诅必吞噬大地，</span><br /><span className="pl pl-1">世人必因罪而受惩罚。</span><br /><span className="pl pl-1">他们必被焚烧，</span><br /><span className="pl pl-1">所剩无几。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 16:10; 约珥书 1:10–12; 以赛亚书 16:8"> <span className="pl pl-1">葡萄树枯萎，新酒枯竭，</span><br /><span className="pl pl-1">欢乐的人都发出悲叹。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="何西阿书 2:11; 启示录 18:22; 以西结书 26:13"> <span className="pl pl-1">愉快的鼓声止息，</span><br /><span className="pl pl-1">悦耳的琴音消失，</span><br /><span className="pl pl-1">宴乐的喧闹不复听闻。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 5:22; 传道书 9:7; 以赛亚书 5:20"> <span className="pl pl-1">再没有人对酒高歌，</span><br /><span className="pl pl-1">浓酒变得苦涩。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:2; 启示录 17:5–6; 以赛亚书 24:12"> <span className="pl pl-1">毁坏的城一片荒凉，</span><br /><span className="pl pl-1">家家房门紧闭，无人能进。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿书 7:14; 以赛亚书 24:7–9; 耶利米书 48:33"> <span className="pl pl-1">人们因无酒而在街上喊叫；</span><br /><span className="pl pl-1">一切欢乐变作哀愁，</span><br /><span className="pl pl-1">地上喜乐不复存在。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 9:11; 弥迦书 1:12; 耶利米哀歌 5:18"> <span className="pl pl-1">城里一片荒凉，</span><br /><span className="pl pl-1">城门被撞成碎片。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:9; 以西结书 6:8–11; 以西结书 11:16–20"> <span className="pl pl-1">世上万民必所剩无几，</span><br /><span className="pl pl-1">像打过的橄榄树，</span><br /><span className="pl pl-1">又如摘过的葡萄树。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 40:9; 耶利米书 31:12; 以赛亚书 54:1"> <span className="pl pl-1">劫后余生的人必高声欢呼，</span><br /><span className="pl pl-1">在西方赞美耶和华的威严。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 48:43–44; 列王纪上 19:17; 利未记 26:21–22"> <span className="pl pl-1">世人啊！</span><br /><span className="pl pl-1">恐怖、陷阱和网罗要临到你们。</span><br /></span>

## 上帝呼召以赛亚

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 12:41; 启示录 15:8; 启示录 7:15–17"> 乌西雅王驾崩那年，我看见主坐在高高的宝座上，祂的衣袍下垂，充满圣殿。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 4:8; 以西结书 1:11; 诗篇 104:4"> 在祂上方侍立着撒拉弗天使，他们各有三对翅膀：一对遮脸，一对遮脚，一对飞翔。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 4:8–9; 诗篇 72:19; 民数记 14:21"> 他们彼此呼喊：<br /><span className="pl pl-1">“圣哉，圣哉，圣哉，</span><br /><span className="pl pl-1">万军之耶和华！</span><br /><span className="pl pl-1">祂的荣耀充满大地。”</span></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 15:8; 出埃及记 40:34; 历代志下 5:13–1"> 他们的呼喊声震动圣殿门槛的基石，圣殿里烟云弥漫。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 5:8–9; 雅各书 3:6–10; 耶利米书 9:3–8"> 那时我说：“我有祸了！我要灭亡了！因为我嘴唇不洁净，又住在嘴唇不洁净的民中，并且亲眼看见了大君王——万军之耶和华。”</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 8:3–5; 希伯来书 9:22–26; 以西结书 10:2"> 有个撒拉弗天使用火钳从祭坛上取了一块燃烧的炭，飞到我面前，</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:9; 约翰一书 1:7; 以赛亚书 43:25"> 用炭碰我的嘴，说：“看啊，这炭碰了你的嘴唇，你的过犯已被除掉，你的罪恶已被赦免。”</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:10–13; 使徒行传 26:16–17; 以弗所书 3:8"> 然后，我听见主说：“我可以差遣谁呢？谁肯为我们去呢？”我说：“我在这里，请差遣我！”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 13:14–15; 路加福音 8:10; 马可福音 4:12"> 祂说：“你去告诉这百姓，<br /><span className="pl pl-1">“‘你们听了又听，却不明白；</span><br /><span className="pl pl-1">看了又看，却不领悟。’</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:15; 使徒行传 28:27; 耶利米书 5:21"> <span className="pl pl-1">你要让这些人心灵麻木，</span><br /><span className="pl pl-1">耳朵发背，</span><br /><span className="pl pl-1">眼睛昏花，</span><br /><span className="pl pl-1">免得他们眼睛看见，</span><br /><span className="pl pl-1">耳朵听见，</span><br /><span className="pl pl-1">心里明白，</span><br /><span className="pl pl-1">回心转意，就得到医治。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 24:1–12; 诗篇 94:3; 利未记 26:31"> 我说：“主啊，这要到什么时候呢？”祂说：<br /><span className="pl pl-1">“直到城邑荒凉，无人居住，房屋空置，</span><br /><span className="pl pl-1">土地荒废的时候。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 4:29; 申命记 28:64; 列王纪下 25:11"> <span className="pl pl-1">那时，我必把他们赶到远方，</span><br /><span className="pl pl-1">他们的土地必大量荒废。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 14:7–9; 罗马书 11:5–6; 创世记 22:18"> <span className="pl pl-1">即使境内只剩下十分之一的人，</span><br /><span className="pl pl-1">也必被消灭。</span><br /><span className="pl pl-1">然而，就像砍掉松树和橡树后必留下树桩，</span><br /><span className="pl pl-1">圣洁的苗裔就是残留的树桩。”</span></span>

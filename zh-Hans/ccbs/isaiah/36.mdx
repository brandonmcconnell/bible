## 亚述王入侵犹大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 32:1; 列王纪下 18:13; 列王纪下 18:17"> 希西迦王执政第十四年，亚述王西拿基立起兵攻取了犹大所有的坚城。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 32:9–23; 以赛亚书 7:3; 列王纪下 18:17–37"> 然后，亚述王从拉吉差遣将军率领大军到耶路撒冷的希西迦王那里。将军站在上池的水沟旁、通往漂布场的路上。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16–17; 以赛亚书 22:15–21; 撒母耳记下 20:24–25"> 希勒迦的儿子宫廷总管以利亚敬、书记舍伯那和亚萨的儿子史官约亚出来见亚述的将军。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:19–37; 犹大书 1:16; 箴言 16:18"> 亚述的将军对他们说：“你们去告诉希西迦，伟大的亚述王说，‘你凭什么这样自信呢？</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 18:7; 耶利米书 52:3; 箴言 21:30–31"> 你所谓的战略和军力不过是空话。你究竟倚靠谁，竟敢背叛我？</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 29:6–7; 耶利米书 37:5–8; 列王纪下 18:21"> 看啊，你所倚靠的埃及不过是一根破裂的芦苇杖，倚靠它的必被刺破手。倚靠埃及王法老的下场都是这样。’</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:4–5; 诗篇 42:10–11; 诗篇 42:5"> 也许你会说，‘我们倚靠我们的上帝耶和华。’希西迦不是拆除了祂的丘坛和祭坛，又吩咐犹大和耶路撒冷的人必须在这座祭坛前敬拜吗？</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:40–43; 列王纪上 20:10; 尼希米记 4:2–5"> 来，跟我主人亚述王打个赌，你若能找到两千骑士，我就给你两千匹马！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 10:8; 以赛亚书 30:16–17; 以赛亚书 36:6"> 你们即使依靠埃及的战车和骑兵，又怎能打败我主人的一个最小的将领呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:25; 以赛亚书 10:5–7; 列王纪上 13:18"> 更何况我来攻打、毁灭这地方不正是耶和华的意思吗？耶和华吩咐我攻打、毁灭这地方。”</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 4:7; 但以理书 2:4; 列王纪下 18:26–27"> 以利亚敬、舍伯那和约亚对亚述的将军说：“求你用亚兰语跟仆人们说话，我们都听得懂。求你不要用犹大话跟我们说，免得城墙上的人听见。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 18:27; 利未记 26:29; 耶利米哀歌 4:9–10"> 亚述的将军却说：“难道我主人派我来只对你们和你们的主人说这些话吗？不也是对坐在城墙上的人说吗？他们和你们一样都要吃自己的粪，喝自己的尿。”</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 32:18; 诗篇 73:8–9; 列王纪下 18:28–32"> 于是，他站着用犹大话大喊：“你们要听伟大的亚述王的话，</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:4; 启示录 13:5–6; 但以理书 6:20"> 王说，‘你们不要被希西迦欺骗，他不能救你们。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 37:23–24; 马太福音 27:43; 诗篇 71:9–11"> 不要听希西迦的话去倚靠耶和华，说什么耶和华必拯救你们，这城必不会落在亚述王手中。’</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:25; 撒迦利亚书 3:10; 弥迦书 4:4"> 不要听希西迦的话。亚述王说，‘你们要跟我讲和，出来归顺我。这样，你们就可以吃自己葡萄树和无花果树的果子，喝自己井里的水。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 18:32; 申命记 8:7–9; 约伯记 20:17"> 以后我会来领你们到一个地方，那里和这里一样有五谷和新酒、饼和葡萄园。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17–18; 以赛亚书 36:15; 以赛亚书 37:10"> 希西迦说耶和华必拯救你们，不要被他哄骗。列国有哪个神明曾从亚述王手中救它的国家呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 10:9–11; 耶利米书 49:23; 撒母耳记下 8:9"> 哈马和亚珥拔的神明在哪里呢？西法瓦音的神明在哪里呢？它们从我手中救撒玛利亚了吗？</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:21; 历代志下 32:19; 以赛亚书 37:23–29"> 这些国家有哪个神明从我手中救了它的国家呢？难道耶和华能从我手中救耶路撒冷吗？’”</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 诗篇 38:13–15; 马太福音 7:6"> 民众默不作声，一言不发，因为希西迦王曾吩咐他们不要答话。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 36:3; 以赛亚书 33:7; 马太福音 26:65"> 这时，宫廷总管希勒家的儿子以利亚敬、书记舍伯那和亚萨的儿子史官约亚都撕裂衣服去见希西迦，把亚述将军的话回禀他。</span>

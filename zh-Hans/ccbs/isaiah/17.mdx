## 关于大马士革的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 25:2; 撒迦利亚书 9:1; 阿摩司书 1:3–5"> 以下是关于大马士革的预言：<br /><span className="pl pl-1">“看啊，大马士革城必不复存在，沦为废墟。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 25:5; 耶利米书 7:33; 民数记 32:34"> <span className="pl pl-1">亚罗珥的众城邑必被废弃，</span><br /><span className="pl pl-1">羊群将在那里栖息，</span><br /><span className="pl pl-1">没有人惊扰它们。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 9:11; 以赛亚书 8:4; 以赛亚书 7:16"> <span className="pl pl-1">以法莲</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="旧约中常用以法莲代表以色列国。">a</a></sup><br /><span className="pl pl-1">的堡垒必被摧毁，</span><br /><span className="pl pl-1">大马士革的王权必丧失。</span><br /><span className="pl pl-1">幸存的亚兰人必像以色列人的荣耀一样消失。”</span><br /><span className="pl pl-1">这是万军之耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 10:16; 申命记 32:15–27; 以赛亚书 24:13"> <span className="pl pl-1">“到那日，雅各的荣耀必消失，</span><br /><span className="pl pl-1">他肥胖的身躯必渐渐消瘦。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 13:30; 约珥书 3:13; 耶利米书 51:33"> <span className="pl pl-1">那时就像人收割庄稼，收集麦穗，</span><br /><span className="pl pl-1">又像人在利乏音谷拾取麦穗。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 24:13; 申命记 4:27; 罗马书 9:27"> <span className="pl pl-1">幸存者寥寥无几，就像打过的橄榄树上剩下的果子，</span><br /><span className="pl pl-1">或两三个挂在树梢，</span><br /><span className="pl pl-1">或四五个残存在枝头。”</span><br /><span className="pl pl-1">这是以色列的上帝耶和华说的。</span></span>
<span className="v" id="v7" data-v="7" data-xref="弥迦书 7:7; 何西阿书 6:1; 何西阿书 3:5"> 到那日，人们必仰望他们的创造主，把目光转向以色列的圣者。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 30:22; 以赛亚书 27:9; 以赛亚书 2:8"> 那时他们不再仰望自己双手所造的祭坛，也不再关注自己指头所造的亚舍拉神像和香坛。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 3:11–15; 以赛亚书 27:10; 以赛亚书 24:1–12"> 到那日，他们因以色列人而离弃的坚城必如长满荆棘和杂草的废地，一片荒凉。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 106:21; 申命记 32:18; 以赛亚书 26:4"> <span className="pl pl-1">你们忘记了拯救你们的上帝，</span><br /><span className="pl pl-1">不记念那保护你们的磐石。</span><br /><span className="pl pl-1">所以，你们虽然栽种佳美的秧子，</span><br /><span className="pl pl-1">插上异国的树苗，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 4:8; 何西阿书 8:7; 加拉太书 6:7–8"> <span className="pl pl-1">使它们在栽种的当天早上就生长开花，</span><br /><span className="pl pl-1">也必一无所获。</span><br /><span className="pl pl-1">那时只有艰难和无尽的痛苦。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 6:23; 路加福音 21:25; 诗篇 18:4"> <span className="pl pl-1">唉！列国喧嚣，如怒海汹涌；</span><br /><span className="pl pl-1">万民骚动，如洪水滔滔。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 9:5; 诗篇 1:4; 以赛亚书 41:15–16"> <span className="pl pl-1">虽然万民喧嚣如汹涌的洪水，</span><br /><span className="pl pl-1">但上帝一斥责，他们便逃往远方，</span><br /><span className="pl pl-1">像山顶上被风卷走的糠秕，</span><br /><span className="pl pl-1">又如狂风卷起的尘埃。</span></span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 19:35; 箴言 22:23; 耶利米书 13:25"> 他们晚上令人恐惧，早晨已无影无踪。这就是掳掠我们之人的下场，抢夺我们之人的报应。</span>
</div>

## 以色列蒙拣选

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 41:8; 罗马书 11:5–6; 耶利米书 30:10"> <span className="pl pl-1">“我的仆人雅各，</span><br /><span className="pl pl-1">我所拣选的以色列啊，</span><br /><span className="pl pl-1">现在你要留心听。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 1:5; 以赛亚书 43:1; 以赛亚书 46:3–4"> <span className="pl pl-1">造你、使你在母胎中成形、</span><br /><span className="pl pl-1">帮助你的耶和华说，</span><br /><span className="pl pl-1">‘我的仆人雅各，</span><br /><span className="pl pl-1">我所拣选的耶书仑</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“耶书仑”是以色列的昵称。">a</a></sup><br /><span className="pl pl-1">啊，</span><br /><span className="pl pl-1">不要害怕。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约珥书 2:28; 使徒行传 2:17; 以赛亚书 59:21"> <span className="pl pl-1">我要用水浇灌干渴之地，</span><br /><span className="pl pl-1">使河流滋润干旱之土。</span><br /><span className="pl pl-1">我要用我的灵浇灌你的后裔，</span><br /><span className="pl pl-1">使我赐的福临到你的子孙。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:11; 诗篇 1:3; 诗篇 92:13–15"> <span className="pl pl-1">他们要滋长如青草，</span><br /><span className="pl pl-1">又如溪旁杨柳。’</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 8:5; 撒迦利亚书 13:9; 彼得前书 2:9"> <span className="pl pl-1">这个说，‘我属于耶和华，’</span><br /><span className="pl pl-1">那个说，‘我是雅各的子孙，’</span><br /><span className="pl pl-1">还有人手上写着，‘耶和华之民，’</span><br /><span className="pl pl-1">把自己归在以色列名下。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 41:4; 以赛亚书 43:10–11; 启示录 1:8"> <span className="pl pl-1">“耶和华，以色列的君王和救赎主——</span><br /><span className="pl pl-1">万军之耶和华说，</span><br /><span className="pl pl-1">‘我是首先的，我是末后的，</span><br /><span className="pl pl-1">除我以外再没有真神。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 41:26; 以赛亚书 41:22; 以赛亚书 46:9–10"> <span className="pl pl-1">谁能与我相比？让他公之于众。</span><br /><span className="pl pl-1">让他细说自从我设立这古老民族以来的往事，</span><br /><span className="pl pl-1">让他宣告未来将要发生的事。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 43:10; 撒母耳记上 2:2; 申命记 4:35"> <span className="pl pl-1">不要恐惧，不要害怕，</span><br /><span className="pl pl-1">我不是从古时告诉过你们吗？</span><br /><span className="pl pl-1">你们是我的证人。</span><br /><span className="pl pl-1">除我以外还有真神吗？</span><br /><span className="pl pl-1">没有，没有别的磐石，</span><br /><span className="pl pl-1">一个也没有。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 41:24; 耶利米书 10:14–15; 诗篇 97:7"> 制造偶像的真是无用，他们珍爱的偶像毫无价值。拜神像的人目盲眼瞎，愚昧无知，自找羞辱。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 10:5; 哈巴谷书 2:18; 使徒行传 19:26"> 制造神像、铸造无益偶像的是谁？</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 42:17; 以赛亚书 45:16; 诗篇 97:7"> 看啊，拜偶像的人必羞愧，制造神像的工匠不过是人。让他们聚在一起来对质吧，他们必恐惧、羞愧。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 41:6–7; 以赛亚书 40:19; 以赛亚书 46:6–7"> 铁匠拿起工具在炭火上工作，用他强壮的臂膀挥动铁锤打造偶像。他饥饿时就会无力，口渴时就会疲乏。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 17:4–5; 诗篇 115:5–7; 使徒行传 17:29"> 木匠拉线测量木料，用笔勾出轮廓，用圆规画出模样，用凿子雕成人的样子，形态逼真，放在庙宇里。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 40:20; 耶利米书 10:3–8; 何西阿书 4:12"> 他砍伐香柏木，或从林中选取柏木和橡木。他栽种松树，雨水使它长大。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 25:14; 启示录 9:20; 士师记 2:19"> 这树可以用来烧柴，他取一些木料生火取暖、烤饼，又制成神像来祭拜，雕成偶像来叩拜。</span>
<span className="v" id="v16" data-v="16"> 他用一半木头生火烤肉，饱餐一顿，并用火取暖，说：“啊！我这里有火，真暖和。”</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 45:20; 列王纪上 18:26; 但以理书 6:27"> 他用另一半木头造了一个神明，作他的偶像，向它俯伏叩拜、祷告说：“你是我的神明，求你拯救我。”</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 6:9–10; 哥林多后书 4:3–4; 约翰福音 12:39–40"> 他们愚昧无知，因为他们的眼睛被封住以致看不见，他们的心窍被塞住以致不明白。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 27:15; 列王纪上 11:7; 列王纪上 11:5"> 他们无人思想，无人明白，无人醒悟说：“我用一半木头生火，在炭上烤饼烤肉吃，我岂能用另一半木头造可憎的神像？我岂能向一块木头叩拜？”</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:28; 约伯记 15:31; 何西阿书 12:1"> 他们以灰为食，心智迷糊，走入歧途，不能自救，也不会说：“我右手拿的神像岂不是假的吗？”</span>
</div>

## 关于耶路撒冷的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 21:13; 诗篇 125:2; 约珥书 3:12"> 以下是关于异象谷<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“异象谷”指耶路撒冷。">a</a></sup>的预言：<br /><span className="pl pl-1">为什么你们全都上到房顶呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 32:13; 以赛亚书 23:7; 耶利米哀歌 2:20"> <span className="pl pl-1">你们这座充满喧闹、骚动和欢乐的城啊，</span><br /><span className="pl pl-1">你们中间被杀的人既非丧身刀下，</span><br /><span className="pl pl-1">也非死于战场。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 25:4–7; 以赛亚书 3:1–8; 耶利米书 39:4–7"> <span className="pl pl-1">你们的官长都一起逃跑，</span><br /><span className="pl pl-1">一箭未发便束手就缚，</span><br /><span className="pl pl-1">逃到远方的也一同被擒。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 9:1; 马太福音 2:18; 诗篇 77:2"> <span className="pl pl-1">所以，我说：“你们不要管我，</span><br /><span className="pl pl-1">让我痛哭吧！</span><br /><span className="pl pl-1">不要安慰我，</span><br /><span className="pl pl-1">我的同胞都被毁灭了。”</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:4; 以赛亚书 37:3; 路加福音 23:30"> <span className="pl pl-1">主——万军之耶和华已经定了日子，</span><br /><span className="pl pl-1">要使异象谷饱受恐慌、</span><br /><span className="pl pl-1">失败和混乱，</span><br /><span className="pl pl-1">城墙被攻破，</span><br /><span className="pl pl-1">哭喊声响彻山间。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 16:9; 以赛亚书 21:2; 阿摩司书 1:5"> <span className="pl pl-1">以拦人带着箭袋，</span><br /><span className="pl pl-1">率领战车和骑兵前来，</span><br /><span className="pl pl-1">吉珥人也亮出盾牌。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 8:7–8; 以赛亚书 10:28–32; 耶利米书 39:1–3"> <span className="pl pl-1">你们佳美的山谷中布满战车，</span><br /><span className="pl pl-1">骑兵在你们的城门前列阵。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 7:2; 列王纪上 10:17; 以赛亚书 36:1–3"> <span className="pl pl-1">主除去了犹大的防卫。</span>那时，你们寄望于藏在林宫里的兵器。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 20:20; 尼希米记 3:16; 历代志下 32:1–6"> 你们看见大卫城破口累累，你们储存下池的水，</span>
<span className="v" id="v10" data-v="10"> 数点耶路撒冷城的房屋，把房屋拆掉修补城墙。</span>
<span className="v" id="v11" data-v="11" data-xref="弥迦书 7:7; 耶利米书 33:2–3; 以赛亚书 31:1"> 你们又在两道城墙之间建造新的蓄水池，用来盛旧池的水。耶和华从古时已定了这一切，要使这一切发生，但你们既不仰望祂，也不理会祂。</span>
<span className="v" id="v12" data-v="12" data-xref="约珥书 2:17; 弥迦书 1:16; 约珥书 1:13"> <span className="pl pl-1">那日，主——万军之耶和华要你们哭泣哀号，</span><br /><span className="pl pl-1">剃光头发，身披麻衣。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 56:12; 哥林多前书 15:32; 路加福音 17:26–29"> <span className="pl pl-1">但你们却欢喜作乐，</span><br /><span className="pl pl-1">宰牛杀羊，喝酒吃肉，说：</span><br /><span className="pl pl-1">“让我们吃喝吧！</span><br /><span className="pl pl-1">因为明天我们就死了。”</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 24:13; 撒母耳记上 3:14; 以赛亚书 5:9"> <span className="pl pl-1">万军之耶和华启示我说：</span><br /><span className="pl pl-1">“你们这罪到死也得不到赦免。</span><br /><span className="pl pl-1">这是主——万军之耶和华说的。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 36:3; 列王纪下 18:18; 列王纪下 19:2"> 主——万军之耶和华吩咐我去见宫廷总管舍伯那，对他说：</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:60; 历代志下 16:14; 撒母耳记下 18:18"> “你在这里做什么？你凭什么在这里为自己挖坟墓，在高处为自己挖坟墓，在磐石上为自己凿安息之所？</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 14:3; 约伯记 9:24; 以斯帖记 7:8"> 看啊，你这有权有势的人，耶和华必紧紧抓住你，把你猛力抛出去。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 17:13; 阿摩司书 7:17"> 祂必把你揉作一团，像球一样扔到宽阔之地。在那里，你必死亡，你华美的战车也必遭毁灭，你是你主人家的羞辱。”</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 17:24; 诗篇 75:6–7; 约伯记 40:11–12"> 耶和华对舍伯那说：“我必解除你的官职，把你从高位上拉下来。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 36:3; 列王纪下 18:18; 以赛亚书 37:2"> “到那日，我必召来希勒迦的儿子——我的仆人以利亚敬，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 45:8; 以赛亚书 9:6–7; 创世记 41:42–43"> 给他穿上你的朝服，系上你的腰带，把你的权柄交给他。他必像父亲一样保护耶路撒冷的居民和犹大人。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:18–19; 启示录 3:7; 约伯记 12:14"> 我必把大卫家的钥匙放在他的肩头。他开启的，没有人能关；他关闭的，没有人能开。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:8; 约伯记 36:7; 撒迦利亚书 10:4"> 我要使他像深嵌在坚固之处的橛子一样稳固，他必给他的家族带来尊荣。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 6:1–3; 约翰福音 20:21–23; 马太福音 28:18"> 他的家族及其子孙后代都靠他得荣耀，如同杯子和酒瓶等小器皿挂在一个橛子上。”</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 46:11; 以斯帖记 9:24–25; 诗篇 146:3"> 万军之耶和华说：“到那日，牢牢钉在坚固之处的橛子必松动，被砍落在地上，挂在上面的东西必被除掉。这是耶和华说的。”</span>

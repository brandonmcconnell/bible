## 依靠埃及徒劳无益

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:2; 以赛亚书 1:2; 何西阿书 7:13"> 耶和华说：<br /><span className="pl pl-1">“我悖逆的儿女有祸了！</span><br /><span className="pl pl-1">他们推行的计划并非我的心意，</span><br /><span className="pl pl-1">他们与人结盟并非出于我的灵，</span><br /><span className="pl pl-1">以致罪上加罪。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 36:6; 民数记 27:21; 申命记 28:68"> <span className="pl pl-1">他们不求问我便去埃及，</span><br /><span className="pl pl-1">要得到法老的保护，</span><br /><span className="pl pl-1">寻求埃及的荫庇。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 20:5; 罗马书 10:11; 耶利米书 17:5–6"> <span className="pl pl-1">然而，法老的保护必成为你们的羞愧，</span><br /><span className="pl pl-1">埃及的荫庇必成为你们的耻辱。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 19:11; 以赛亚书 57:9; 耶利米书 43:7"> <span className="pl pl-1">虽然他们的官长已在琐安，</span><br /><span className="pl pl-1">使臣已到哈内斯，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 2:36; 以赛亚书 30:7; 以赛亚书 30:16"> <span className="pl pl-1">但他们必因无用的埃及人而蒙羞，</span><br /><span className="pl pl-1">那些人带不来任何助益，</span><br /><span className="pl pl-1">只带来羞愧和耻辱。”</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:15; 以赛亚书 46:1–2; 耶利米书 11:4"> <span className="pl pl-1">以下是关于南地动物的预言：</span><br /><span className="pl pl-1">他们用驴驮着财物，</span><br /><span className="pl pl-1">用骆驼驮着珍宝，</span><br /><span className="pl pl-1">穿过公狮、母狮、蝮蛇和飞蛇出没的艰险之地，</span><br /><span className="pl pl-1">前往一个对他们毫无益处的国家。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 2:22; 以赛亚书 7:4; 诗篇 118:8–9"> <span className="pl pl-1">埃及的帮助是徒然的，</span><br /><span className="pl pl-1">所以我称她为“没用的拉哈伯</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拉哈伯”埃及的别名，也有“海怪”之意。">a</a></sup><br /><span className="pl pl-1">”。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 31:22; 哈巴谷书 2:2; 以赛亚书 8:1"> <span className="pl pl-1">现在，你去当着他们的面把这些话刻在版上，</span><br /><span className="pl pl-1">记在书卷上，</span><br /><span className="pl pl-1">永远留给后世作明证。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 30:1; 使徒行传 7:51; 撒迦利亚书 1:4–6"> <span className="pl pl-1">因为他们是悖逆的民族，</span><br /><span className="pl pl-1">是说谎的儿女，</span><br /><span className="pl pl-1">不肯听从耶和华的教导。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 13:7–10; 罗马书 16:18; 阿摩司书 2:12"> <span className="pl pl-1">他们对先见说：</span><br /><span className="pl pl-1">“你们不要再看异象了。”</span><br /><span className="pl pl-1">对先知说：</span><br /><span className="pl pl-1">“不要再教导我们正道。</span><br /><span className="pl pl-1">给我们说些好听的话，</span><br /><span className="pl pl-1">讲些虚幻的事吧。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:7; 罗马书 1:30; 约翰福音 15:23–24"> <span className="pl pl-1">闪开此道！离开此路！</span><br /><span className="pl pl-1">不要再给我们讲以色列圣者的事。”</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 31:1–3; 以赛亚书 5:24; 帖撒罗尼迦前书 4:8"> <span className="pl pl-1">因此，以色列的圣者说：</span><br /><span className="pl pl-1">“因为你们藐视我的话，</span><br /><span className="pl pl-1">依仗欺压之能和诡诈之术，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 29:5; 以西结书 13:10–15; 列王纪上 20:30"> <span className="pl pl-1">你们这罪必像一堵断裂、凸起的高墙，</span><br /><span className="pl pl-1">摇摇欲坠，瞬间倒塌，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 2:9; 耶利米书 19:10–11; 彼得后书 2:4–5"> <span className="pl pl-1">又像瓦器一样被无情地摔碎，</span><br /><span className="pl pl-1">找不到一块可以用来从火炉中取炭或从水池里舀水的碎片。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 26:3–4; 以赛亚书 32:17; 耶利米书 3:22–23"> <span className="pl pl-1">主耶和华——以色列的圣者说：</span><br /><span className="pl pl-1">“你们回转并安息，就必得拯救；</span><br /><span className="pl pl-1">你们安静并信靠，就必得力量。</span><br /><span className="pl pl-1">但你们却不肯。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 31:1; 以赛亚书 31:3; 申命记 28:25"> <span className="pl pl-1">你们说，‘不，我们要骑马奔逃。’</span><br /><span className="pl pl-1">所以你们必奔逃。</span><br /><span className="pl pl-1">你们又说，‘我们要骑快马逃跑。’</span><br /><span className="pl pl-1">所以追赶你们的人必疾驰如飞。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:25; 约书亚记 23:10; 申命记 32:30"> <span className="pl pl-1">他们一人叱喝，</span><br /><span className="pl pl-1">必吓得你们千人逃跑；</span><br /><span className="pl pl-1">他们五人叱喝，</span><br /><span className="pl pl-1">你们必全部逃跑，</span><br /><span className="pl pl-1">剩下的像山顶上的旗杆、高岗上的旗帜。”</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:25–26; 彼得后书 3:9; 箴言 16:20"> <span className="pl pl-1">然而，耶和华正在等候，</span><br /><span className="pl pl-1">准备施恩给你们，</span><br /><span className="pl pl-1">祂必怜悯你们。</span><br /><span className="pl pl-1">因为耶和华是公正的上帝，</span><br /><span className="pl pl-1">等候祂的人有福了！</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 60:20; 诗篇 50:15; 以赛亚书 65:24"> 住在耶路撒冷的锡安百姓啊，你们必不再哭泣。祂听到你们的呼求后，必恩待你们；祂听见后，必应允你们。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:27; 诗篇 80:5; 阿摩司书 8:11–12"> 虽然主让你们吃苦受难、历尽艰辛，但你们的教师必不再隐藏，你们必亲眼看见你们的教师。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 32:8; 箴言 3:5–6; 以赛亚书 58:11"> 不管你们向左还是向右，都会听见背后有声音说：“这是正路，走在上面吧！”</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 17:3–4; 以赛亚书 31:7; 撒迦利亚书 13:2"> 你们必抛弃自己那些镀金和包银的偶像，把它们当作污秽之物丢掉，对它们说：“去吧！”</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 8:11–12; 以赛亚书 32:20; 诗篇 65:9–13"> 你们撒种，主必降雨，并使你们五谷丰登。那时，你们的牲畜必在宽阔的草场上吃草；</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 45:6; 申命记 25:4; 撒母耳记上 8:12"> 耕田的牛和驴必吃用叉子和铲子扬净、拌上盐的饲料。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:19–20; 以赛亚书 35:6–7; 以赛亚书 2:14–15"> 在你们的敌人被杀戮、城楼倒塌的日子，你们的高山冈陵上必有溪水奔流。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 60:19–20; 申命记 32:39; 启示录 22:5"> 耶和华包扎祂子民的创伤，医治他们的伤口时，月亮必发出太阳般的光辉，太阳的光辉必增加七倍，灿烂得好像七个太阳同时发光。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:8; 那鸿书 1:5–6; 诗篇 18:7–9"> <span className="pl pl-1">看啊，耶和华的名从远方来，</span><br /><span className="pl pl-1">伴着滚滚浓烟，</span><br /><span className="pl pl-1">祂的怒气如烈火，</span><br /><span className="pl pl-1">祂口中充满愤怒，舌头好像烈焰。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 37:29; 以赛亚书 11:4; 帖撒罗尼迦后书 2:8"> <span className="pl pl-1">祂的气息像淹到人颈项的洪流。</span><br /><span className="pl pl-1">祂必用毁灭的筛子筛净列国，</span><br /><span className="pl pl-1">并把嚼环放在列邦口中，</span><br /><span className="pl pl-1">引他们走上歧途。</span></span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 42:4; 诗篇 95:1–2; 出埃及记 15:1–21"> 但你们必欢唱，好像晚上庆祝节期；你们必充满喜乐，好像人们吹着笛子登耶和华的山、到以色列的磐石那里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 18:13–14; 约书亚记 10:11; 以赛亚书 29:6"> 耶和华必使人听见祂威严的声音，在愤怒、烈焰、暴雨、狂风和冰雹中让人看见祂降罚的臂膀。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 11:4; 以赛亚书 9:4; 弥迦书 5:5–6"> 亚述人听见耶和华的声音必心惊胆战，祂必用杖击打他们。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 11:15; 以赛亚书 19:16; 以赛亚书 2:19"> 耶和华的刑杖每责打他们一下，必伴随着击鼓弹琴的声音。祂必在战场上挥手击打他们。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 23:10; 创世记 19:24; 耶利米书 19:6"> 焚烧之地陀斐特早预备好了，是为亚述王预备的，又宽又深，堆满了火和木柴，耶和华的气息必如同一股硫磺火点燃那些木柴。</span>

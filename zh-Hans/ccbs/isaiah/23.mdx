## 关于泰尔的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约珥书 3:4–8; 阿摩司书 1:9–10; 创世记 10:4"> 以下是关于泰尔的预言：<br /><span className="pl pl-1">他施的船只哀号吧！</span><br /><span className="pl pl-1">因为从基提</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基提”就是现在的塞浦路斯。">a</a></sup><br /><span className="pl pl-1">传来消息，</span><br /><span className="pl pl-1">说泰尔已被毁灭，</span><br /><span className="pl pl-1">房屋和港口都荡然无存。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 47:5; 以赛亚书 41:1; 以西结书 28:2"> <span className="pl pl-1">海边的居民，西顿</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="先知在本预言中提到西顿，是因为泰尔和西顿都在同一地区，都属于腓尼基人。">b</a></sup><br /><span className="pl pl-1">的商贾啊，</span><br /><span className="pl pl-1">要静默无言。</span><br /><span className="pl pl-1">你们的商人飘洋过海，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 2:18; 历代志上 13:5; 以西结书 27:33"> <span className="pl pl-1">从大水之上把西曷的粮食、尼罗河边的农产都运到泰尔。</span><br /><span className="pl pl-1">泰尔成为列国的商埠。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 18:23; 创世记 10:15; 耶利米书 47:3–4"> <span className="pl pl-1">西顿啊，你要羞愧！</span><br /><span className="pl pl-1">你这海上的堡垒啊，</span><br /><span className="pl pl-1">大海否认你，说：</span><br /><span className="pl pl-1">“我没有经历过产痛，</span><br /><span className="pl pl-1">没有生过孩子，</span><br /><span className="pl pl-1">也未曾养育过儿女。”</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:9–11; 出埃及记 15:14–16; 启示录 18:17–19"> <span className="pl pl-1">埃及人听见泰尔的消息，</span><br /><span className="pl pl-1">都感到伤痛。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 23:12; 以赛亚书 21:15; 以赛亚书 23:10"> <span className="pl pl-1">海边的居民啊，你们要去他施！</span><br /><span className="pl pl-1">你们要哀号！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 22:2; 以赛亚书 32:13; 约书亚记 19:29"> <span className="pl pl-1">这就是你们历史悠久、</span><br /><span className="pl pl-1">充满欢乐的城吗？</span><br /><span className="pl pl-1">她的双脚曾带她到远方居住。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 10:8; 耶利米书 50:44–45; 申命记 29:24–28"> <span className="pl pl-1">泰尔曾是封王之地，</span><br /><span className="pl pl-1">她的商贾是王侯，</span><br /><span className="pl pl-1">她的商人名闻天下。</span><br /><span className="pl pl-1">但她如今的遭遇是谁定的？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 4:6; 以赛亚书 13:11; 约伯记 40:11–12"> <span className="pl pl-1">是万军之耶和华定的，</span><br /><span className="pl pl-1">为要摧毁因荣华而生的骄傲，</span><br /><span className="pl pl-1">羞辱世上的尊贵者。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 12:21; 以赛亚书 23:14; 诗篇 18:32"> <span className="pl pl-1">他施的人民啊，</span><br /><span className="pl pl-1">去你们的田地耕作吧，像在尼罗河沿岸一样，</span><br /><span className="pl pl-1">因为海港已不复存在。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 9:3–4; 出埃及记 14:21; 耶利米书 47:7"> <span className="pl pl-1">耶和华向大海伸手，</span><br /><span className="pl pl-1">祂使列国震动。</span><br /><span className="pl pl-1">祂已下令毁灭迦南的堡垒。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 18:22; 以西结书 26:13–14; 以赛亚书 23:1–2"> <span className="pl pl-1">祂说：“受欺压的处女西顿啊，</span><br /><span className="pl pl-1">你再也不能欢乐了！</span><br /><span className="pl pl-1">起来，逃到基提吧，</span><br /><span className="pl pl-1">只是在那里你也得不到安宁。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 1:6; 以赛亚书 10:5; 列王纪下 17:24"> 看看迦勒底人所居之地，这个民族已不复存在！亚述人使它成为野兽出没之地。他们筑起围城的高台，摧毁它的宫殿，使它沦为废墟。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 23:1; 以赛亚书 23:6; 以西结书 27:25–30"> <span className="pl pl-1">他施的船只都哀号吧！</span><br /><span className="pl pl-1">因为你们的堡垒已被摧毁。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 25:22; 耶利米书 25:9–11; 但以理书 7:14"> 到那日，泰尔必被遗忘七十年，正好一个王的寿数。七十年之后，泰尔必如妓女之歌所描述的：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 30:14; 箴言 7:10–12"> <span className="pl pl-1">“被遗忘的妓女啊，</span><br /><span className="pl pl-1">拿起琴，走遍全城。</span><br /><span className="pl pl-1">要弹得美妙，多多唱歌，</span><br /><span className="pl pl-1">好使人再记起你。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="那鸿书 3:4; 以西结书 27:6–36; 启示录 19:2"> 七十年后，耶和华必眷顾泰尔。她必重操旧业，与天下万国交易。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 72:10; 申命记 26:12–14; 腓立比书 4:17–18"> 但她得到的利润和收入不会被积攒或储存起来，而是要被献给耶和华，用来供应那些事奉耶和华的人，使他们吃得饱足，穿得精美。</span>
</div>

## 关于摩押的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 2:1–3; 耶利米书 48:1–47; 以赛亚书 11:14"> 以下是关于摩押的预言：<br /><span className="pl pl-1">摩押的亚珥城必在一夜之间被摧毁，沦为废墟；</span><br /><span className="pl pl-1">摩押的基珥城必在一夜之间被摧毁，沦为废墟。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 48:1; 利未记 21:5; 以赛亚书 3:24"> <span className="pl pl-1">摩押人上到神庙，</span><br /><span className="pl pl-1">上到底本的丘坛痛哭。</span><br /><span className="pl pl-1">他们都剃光头发，刮掉胡须，</span><br /><span className="pl pl-1">为尼波和米底巴城哀号。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约拿书 3:6–8; 耶利米书 19:13; 申命记 22:8"> <span className="pl pl-1">他们身披麻衣走在街上，</span><br /><span className="pl pl-1">人们在房顶和广场上号啕大哭。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 48:34; 列王纪上 19:4; 约拿书 4:8"> <span className="pl pl-1">希实本人和以利亚利人都在哭喊，</span><br /><span className="pl pl-1">声音一直传到雅杂，</span><br /><span className="pl pl-1">因此摩押的战士大声喊叫，</span><br /><span className="pl pl-1">胆战心惊。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 48:5; 耶利米书 4:20; 路加福音 19:41–44"> <span className="pl pl-1">我的心为摩押哀号。</span><br /><span className="pl pl-1">她的人民逃难到琐珥和伊基拉·施利施亚。</span><br /><span className="pl pl-1">他们上到鲁希斜坡，边走边哭，</span><br /><span className="pl pl-1">在去何罗念的路上因自己的毁灭而哀哭。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 1:10–12; 以赛亚书 19:5–7; 民数记 32:36"> <span className="pl pl-1">宁林的河道干涸，</span><br /><span className="pl pl-1">青草枯萎，植被消失，毫无绿色。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 48:36; 那鸿书 2:12–13; 以赛亚书 10:6"> <span className="pl pl-1">因此，摩押人把自己积存的财物都运过柳树河。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 47:10; 以赛亚书 15:2–5; 耶利米书 48:31–34"> <span className="pl pl-1">摩押境内哀声四起，</span><br /><span className="pl pl-1">号啕声传到以基莲，</span><br /><span className="pl pl-1">传到比珥·以琳。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 17:25; 利未记 26:28; 利未记 26:24"> <span className="pl pl-1">底门的河里流的都是血，</span><br /><span className="pl pl-1">但我还要降更多灾难给底门：</span><br /><span className="pl pl-1">狮子必吞噬逃出摩押的人和那里的余民。</span></span>

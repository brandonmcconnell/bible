## 希西迦患病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 38:1–8; 历代志下 32:24; 列王纪下 20:1–11"> 那些日子，希西迦病危，亚摩斯的儿子以赛亚先知前来对他说：“耶和华说，‘你要交待后事，因为你要死了，你必无法康复。’”</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:6; 诗篇 91:15; 列王纪上 8:30"> 希西迦把脸转向墙，向耶和华祷告，说：</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 5:7; 诗篇 18:20–27; 希伯来书 6:10"> “耶和华啊，求你顾念我怎样全心、忠诚地事奉你，做你视为善的事。”希西迦痛哭起来。</span>
<span className="v" id="v4" data-v="4"> 耶和华对以赛亚说：</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 34:5–6; 约翰一书 5:14–15; 启示录 7:17"> “你去告诉希西迦，‘你祖先大卫的上帝耶和华说，我垂听了你的祷告，也看见了你的眼泪，我要使你的寿命增加十五年。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:35; 以赛亚书 31:4–5; 以赛亚书 12:6"> 我要从亚述王手中拯救你和这城，我要保护这城。’”</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 20:7–8; 马可福音 7:33; 约翰福音 9:6"> 以赛亚说：“拿一块无花果饼贴在王的疮上，他就会痊愈。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 118:18–19; 列王纪下 20:8; 约翰福音 5:14"> 希西迦问：“有什么兆头证明我会上耶和华的殿呢？”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这两节在原文抄本是放在本章末尾，不过这可能是在誊抄过程中放错位置。其实这两节经文放在6节和7节之间最为自然，就如在列王纪下一样，参见列王纪下20:7‑8。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:37–39; 以赛亚书 37:30; 以赛亚书 7:11–14"> 以赛亚说：“耶和华要给你一个预兆，以证明祂言出必行。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 20:9–11; 约书亚记 10:12–14; 马太福音 16:1"> 祂要使亚哈斯日晷上的日影后退十度。”果然，日影后退了十度。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:1; 出埃及记 15:1–21; 约伯记 5:18"> 犹大王希西迦病愈后，<br /><span className="pl pl-1">写了一首诗：</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 102:24; 哥林多后书 1:9; 诗篇 107:18"> <span className="pl pl-1">“我以为自己盛年之际，</span><br /><span className="pl pl-1">就要踏入阴间之门，</span><br /><span className="pl pl-1">不能享受余年。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:13; 诗篇 116:8–9; 诗篇 31:22"> <span className="pl pl-1">我以为再也见不到耶和华，</span><br /><span className="pl pl-1">在世间再不能见到祂，</span><br /><span className="pl pl-1">也不能再见到世人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 73:14; 哥林多后书 5:1; 希伯来书 1:12"> <span className="pl pl-1">我的居所像牧人的帐篷一样被拆走，</span><br /><span className="pl pl-1">我像织布的卷布一样卷起自己的生命，</span><br /><span className="pl pl-1">祂从织布机上把我剪断。</span><br /><span className="pl pl-1">旦夕之间，祂使我的生命戛然而止。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:8; 但以理书 6:24; 诗篇 50:22"> <span className="pl pl-1">我整夜哀号，</span><br /><span className="pl pl-1">祂像狮子一样咬断我全身的骨头。</span><br /><span className="pl pl-1">旦夕之间，祂使我的生命戛然而止。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:11; 诗篇 69:3; 诗篇 123:1–4"> <span className="pl pl-1">“我像燕、鹤一样哀鸣，</span><br /><span className="pl pl-1">像鸽子一样呻吟；</span><br /><span className="pl pl-1">我举目望天，双眼疲倦。</span><br /><span className="pl pl-1">耶和华啊！</span><br /><span className="pl pl-1">我困苦不堪，求你保护我。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 21:27; 约伯记 7:11; 约伯记 10:1"> <span className="pl pl-1">我能说什么呢？</span><br /><span className="pl pl-1">祂对我说的，祂都亲自成就了。</span><br /><span className="pl pl-1">因为心灵的苦痛，我要一生谨慎行事。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:10–11; 哥林多前书 11:32; 诗篇 119:25"> <span className="pl pl-1">“主啊，你的法令使人存活，</span><br /><span className="pl pl-1">使我的心灵存活。</span><br /><span className="pl pl-1">主啊，求你使我身体复原，</span><br /><span className="pl pl-1">让我存活。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 43:25; 弥迦书 7:18–19; 约拿书 2:6"> <span className="pl pl-1">其实我受大苦对我有益。</span><br /><span className="pl pl-1">你施慈爱，从死亡的深坑中拯救我的生命，</span><br /><span className="pl pl-1">将我一切罪恶抛在你背后。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="传道书 9:10; 诗篇 30:9; 诗篇 6:5"> <span className="pl pl-1">诚然，阴间不会称谢你，</span><br /><span className="pl pl-1">死亡不会赞美你，</span><br /><span className="pl pl-1">下坟墓的人不会仰望你的信实。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 诗篇 119:175; 诗篇 78:3–6"> <span className="pl pl-1">只有活着的人会像我今天这样称谢你，</span><br /><span className="pl pl-1">父亲会把你的信实告诉子女。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="诗篇 116:2; 诗篇 150:4; 诗篇 145:2"> <span className="pl pl-1">“耶和华必救我，</span><br /><span className="pl pl-1">我们要一生一世在祂殿中弹琴歌唱。”</span></span>
</div>

## 关于埃及的预言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:12; 启示录 1:7; 约书亚记 2:11"> 以下是关于埃及的预言：<br /><span className="pl pl-1">看啊，耶和华驾着疾驰的云来到埃及。</span><br /><span className="pl pl-1">埃及的偶像在祂面前颤抖，</span><br /><span className="pl pl-1">埃及人胆战心惊。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="士师记 7:22; 撒母耳记上 14:20; 马太福音 10:36"> <span className="pl pl-1">“我必使埃及人彼此为敌——手足相残，</span><br /><span className="pl pl-1">邻居互斗，城邑相争，</span><br /><span className="pl pl-1">邦国互攻。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:19; 但以理书 2:2; 历代志上 10:13"> <span className="pl pl-1">埃及人必灰心丧志，</span><br /><span className="pl pl-1">我必破坏他们的计谋。</span><br /><span className="pl pl-1">他们必求问偶像、巫师、灵媒和术士。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 20:4; 耶利米书 46:26; 以西结书 29:19"> <span className="pl pl-1">我必将埃及人交给一位残忍的主人，</span><br /><span className="pl pl-1">一位暴君必统治他们。”</span><br /><span className="pl pl-1">这是主——万军之耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:36; 以西结书 30:12; 撒迦利亚书 14:18"> <span className="pl pl-1">海水必枯竭，</span><br /><span className="pl pl-1">河床必干涸。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:25; 出埃及记 7:18; 列王纪下 19:24"> <span className="pl pl-1">沟渠必发臭，</span><br /><span className="pl pl-1">埃及的河流逐渐枯竭。</span><br /><span className="pl pl-1">芦苇和灯心草必枯死，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 32:20; 约珥书 1:17–18; 以赛亚书 23:3"> <span className="pl pl-1">尼罗河两岸青草枯黄，</span><br /><span className="pl pl-1">田地龟裂，庄稼被风吹去，</span><br /><span className="pl pl-1">荡然无存。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 47:10; 哈巴谷书 1:15; 民数记 11:5"> <span className="pl pl-1">所有在尼罗河下钩的渔夫都哀哭悲伤，</span><br /><span className="pl pl-1">在河上撒网的人都伤痛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 27:7; 箴言 7:16; 列王纪上 10:28"> <span className="pl pl-1">纺麻织布的人一筹莫展，</span><br /><span className="pl pl-1">陷入绝望。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 11:10; 出埃及记 7:19; 出埃及记 8:5"> <span className="pl pl-1">埃及的显贵萎靡不振</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="死海古卷为“埃及的织布者都崩溃”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">雇工们都忧心忡忡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="民数记 13:22; 使徒行传 7:22; 列王纪上 4:30"> <span className="pl pl-1">琐安的官长愚不可及，</span><br /><span className="pl pl-1">法老聪明的谋士尽出下策。</span><br /><span className="pl pl-1">他们怎敢在法老面前自称是智者之子，古代君王之后？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:20; 以赛亚书 14:24; 士师记 9:38"> <span className="pl pl-1">法老啊，你的智者在哪里呢？</span><br /><span className="pl pl-1">让他们把万军之耶和华对付埃及的计划告诉你吧！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 30:13; 耶利米书 2:16; 耶利米书 46:14"> <span className="pl pl-1">琐安的首领愚昧，</span><br /><span className="pl pl-1">挪弗的首领糊涂。</span><br /><span className="pl pl-1">他们是埃及各支派的房角石，</span><br /><span className="pl pl-1">却把埃及人引入歧途。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:11; 列王纪上 22:20–23; 以西结书 14:7–9"> <span className="pl pl-1">耶和华使错谬的灵进入他们当中，</span><br /><span className="pl pl-1">使他们像又呕又吐、东倒西歪的醉汉，</span><br /><span className="pl pl-1">做什么都错误百出。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 9:14–15; 帖撒罗尼迦前书 4:11–12; 箴言 14:23"> <span className="pl pl-1">埃及从头到尾，</span><br /><span className="pl pl-1">从权贵到草根必一筹莫展。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 51:30; 那鸿书 3:13; 以赛亚书 11:15"> 到那日，当万军之耶和华挥手惩罚的时候，埃及人必恐惧颤抖，如柔弱的女子。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:24; 但以理书 4:35; 以西结书 29:6–7"> 他们必对犹大充满恐惧，一听见犹大的名字就害怕，因为万军之耶和华定下计划要对付他们。</span>
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:9; 撒迦利亚书 2:11; 以赛亚书 19:21"> 到那日，埃及必有五座城的人讲迦南的语言，并起誓效忠万军之耶和华，其中有一座必叫灭亡城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“灭亡城”有些抄本作“太阳城”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 28:18; 约书亚记 22:10; 约书亚记 22:26"> 到那日，埃及境内必有一座为耶和华筑的祭坛，边境必有一根为耶和华立的石柱。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:15; 提多书 2:13; 以赛亚书 45:21–22"> 这是万军之耶和华在埃及的记号和凭据。埃及人因受到欺压就呼求耶和华，祂必差遣一位救主保护、拯救他们。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:9; 玛拉基书 1:11; 约翰福音 17:3"> 耶和华必向埃及人彰显自己。到那日，埃及人必认识祂，带着祭物和供物来敬拜祂，向祂许愿还愿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:39; 希伯来书 12:11; 何西阿书 14:1"> 耶和华必击打他们，也必医治他们。他们必归向耶和华，祂必应允他们的祷告，医治他们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 11:16; 以弗所书 2:18–22; 以赛亚书 35:8–10"> 到那日，必有一条大道连接埃及和亚述，两国人民互相往来，一同敬拜耶和华。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:8; 创世记 12:2; 加拉太书 3:14"> 到那日，以色列必与埃及和亚述一同成为世人的祝福。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 29:23; 何西阿书 2:23; 罗马书 9:24–25"> 万军之耶和华必赐福给他们，说：“我的子民埃及、我的创作亚述、我的产业以色列都有福了！”</span>
</div>
</div>

## 因罪与主隔绝

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 32:17; 以赛亚书 50:2; 民数记 11:23"> 看啊，耶和华的臂膀并非无力拯救，<br /><span className="pl pl-1">祂的耳朵并非聋得听不见。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 5:25; 箴言 15:29; 弥迦书 3:4"> <span className="pl pl-1">而是你们的罪过使你们与上帝隔绝，</span><br /><span className="pl pl-1">你们的罪恶使祂转脸不看你们，</span><br /><span className="pl pl-1">不听你们的祈求。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="罗马书 3:15–17; 箴言 6:17; 马可福音 7:21–22"> <span className="pl pl-1">你们的脚奔向邪恶，</span><br /><span className="pl pl-1">急于滥杀无辜；</span><br /><span className="pl pl-1">你们心怀恶念，</span><br /><span className="pl pl-1">所到之处，大肆毁灭。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 57:20–21; 罗马书 3:17; 路加福音 1:79"> <span className="pl pl-1">你们不知道平安之路，</span><br /><span className="pl pl-1">你们的行径毫无公正；</span><br /><span className="pl pl-1">你们走歪门邪道，</span><br /><span className="pl pl-1">跟从你们的必不知何为平安。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="申命记 28:29; 约伯记 5:14; 耶利米哀歌 3:6"> <span className="pl pl-1">我们像盲人一样沿墙摸索，</span><br /><span className="pl pl-1">像无眼睛的人一样探路。</span><br /><span className="pl pl-1">我们在中午也跌跌撞撞，</span><br /><span className="pl pl-1">如同走在晚上。</span><br /><span className="pl pl-1">我们在强壮人当中如同死人。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="马可福音 7:21–22; 雅各书 3:6; 希伯来书 3:12"> <span className="pl pl-1">我们悖逆，否认耶和华，</span><br /><span className="pl pl-1">离弃我们的上帝，</span><br /><span className="pl pl-1">说欺压、叛逆的话，</span><br /><span className="pl pl-1">吐露心中编织的谎言。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="哈巴谷书 1:4; 传道书 3:16; 耶利米书 5:31"> <span className="pl pl-1">正义被赶逐，</span><br /><span className="pl pl-1">公义远远站立，</span><br /><span className="pl pl-1">真理倒在街上，</span><br /><span className="pl pl-1">正直被拒之门外。</span><br /></span>

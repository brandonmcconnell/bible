## 未来的君王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:15–16; 列王纪下 15:29; 以赛亚书 8:22"> 但那些受过痛苦的人必不再遇见黑暗。从前，耶和华使西布伦人和拿弗他利人住的地方受人藐视，日后必使这些地方，即约旦河东、沿海一带、外族人居住的加利利得到荣耀。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:16; 以弗所书 5:8; 约翰福音 8:12"> <span className="pl pl-1">走在黑暗中的人必看见大光，</span><br /><span className="pl pl-1">活在死荫之地的人必被光照亮。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 35:10; 诗篇 119:162; 以赛亚书 26:15"> <span className="pl pl-1">耶和华啊，你必使以色列成为大国，</span><br /><span className="pl pl-1">使他们喜气洋洋。</span><br /><span className="pl pl-1">他们必在你面前欢喜快乐，</span><br /><span className="pl pl-1">好像丰收时那样欢喜，</span><br /><span className="pl pl-1">如同瓜分战利品时那样快乐。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 30:8; 以赛亚书 14:25; 以赛亚书 10:26–27"> <span className="pl pl-1">因为你必折断他们负的重轭和欺压者的棍棒，</span><br /><span className="pl pl-1">好像昔日你毁灭米甸人一样；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 1:8; 诗篇 46:9; 以赛亚书 30:33"> <span className="pl pl-1">勇士争战穿的靴子和染血的战袍都要被扔进火里烧掉。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 2:11; 马太福音 28:18; 耶利米书 23:5–6"> <span className="pl pl-1">因为必有一个婴儿为我们诞生，</span><br /><span className="pl pl-1">有一个儿子要赐给我们，</span><br /><span className="pl pl-1">祂肩头必担负王权。</span><br /><span className="pl pl-1">祂被称为奇妙的策士、大能的上帝、永存的父、和平的君。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 1:32–33; 但以理书 2:44; 但以理书 7:14"> <span className="pl pl-1">祂的国必长治久安。</span><br /><span className="pl pl-1">祂必坐在大卫的宝座上以公平和公义治国兴邦，</span><br /><span className="pl pl-1">使国家永固。</span><br /><span className="pl pl-1">万军之耶和华必热切地成就此事。</span></span>

## 耶和华要审判以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:4–8; 撒迦利亚书 1:6; 撒迦利亚书 5:1–4"> <span className="pl pl-1">主已出言审判雅各家，</span><br /><span className="pl pl-1">他的审判必临到以色列，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 46:12; 彼得前书 5:5; 以西结书 7:27"> <span className="pl pl-1">以法莲和撒玛利亚的居民都知道。</span><br /><span className="pl pl-1">他们骄傲自大地说：</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 1:4; 列王纪上 10:27; 列王纪上 7:9–12"> <span className="pl pl-1">“砖墙倒塌了，</span><br /><span className="pl pl-1">我们凿石重建；</span><br /><span className="pl pl-1">桑树砍倒了，</span><br /><span className="pl pl-1">我们换种香柏树。”</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 8:4–7; 以赛亚书 17:1–5; 以赛亚书 7:8"> <span className="pl pl-1">因此耶和华必兴起利汛的仇敌，</span><br /><span className="pl pl-1">驱使敌人来攻击他们。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 5:25; 历代志下 28:18; 诗篇 79:7"> <span className="pl pl-1">东有亚兰人，西有非利士人，</span><br /><span className="pl pl-1">他们必吞噬以色列。</span><br /><span className="pl pl-1">虽然如此，耶和华的怒气还没有止息，</span><br /><span className="pl pl-1">祂降罚的手仍没有收回。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿书 7:10; 以赛亚书 31:1; 耶利米书 5:3"> <span className="pl pl-1">但百姓没有归向击打他们的主，</span><br /><span className="pl pl-1">也不寻求万军之耶和华。</span><br /></span>

<span className="v" id="v16" data-v="16" data-xref="马太福音 15:14; 以赛亚书 3:12; 马太福音 23:16–36"> <span className="pl pl-1">这些带领者使百姓步入歧途、</span><br /><span className="pl pl-1">走向灭亡。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 18:21; 以赛亚书 10:6; 以赛亚书 5:25"> <span className="pl pl-1">他们都目无上帝，</span><br /><span className="pl pl-1">行事邪恶，口出妄语。</span><br /><span className="pl pl-1">所以，主不喜欢他们的青年，</span><br /><span className="pl pl-1">也不怜悯他们的孤儿寡妇。</span><br /><span className="pl pl-1">虽然如此，耶和华的怒气还没有止息，</span><br /><span className="pl pl-1">祂降罚的手仍没有收回。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 83:14; 玛拉基书 4:1; 以赛亚书 5:24"> <span className="pl pl-1">邪恶像燃烧的火焰，</span><br /><span className="pl pl-1">焚毁荆棘和蒺藜，点燃密林，</span><br /><span className="pl pl-1">烟柱旋转上腾。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 7:2; 弥迦书 7:6; 约珥书 2:2"> <span className="pl pl-1">万军之耶和华的烈怒必如火烧焦大地，</span><br /><span className="pl pl-1">百姓成为烧火的柴，</span><br /><span className="pl pl-1">弟兄彼此相煎。</span><br /></span>

<span className="v" id="v21" data-v="21" data-xref="以赛亚书 5:25; 加拉太书 5:15; 以赛亚书 9:12"> <span className="pl pl-1">以法莲和玛拿西自相残杀，</span><br /><span className="pl pl-1">又联合起来攻打犹大。</span><br /><span className="pl pl-1">虽然如此，耶和华的怒气还没有止息，</span><br /><span className="pl pl-1">祂降罚的手仍没有收回。</span></span>

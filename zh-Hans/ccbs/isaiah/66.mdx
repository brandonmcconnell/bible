## 耶和华的审判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:48–50; 使徒行传 17:24; 马太福音 5:34–35"> 耶和华说：<br /><span className="pl pl-1">“天是我的宝座，</span><br /><span className="pl pl-1">地是我的脚凳，</span><br /><span className="pl pl-1">你们要为我造怎样的殿宇？</span><br /><span className="pl pl-1">哪里可作我的安歇之处？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 57:15; 诗篇 34:18; 诗篇 51:17"> <span className="pl pl-1">这一切不都是我亲手创造的吗？</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /><span className="pl pl-1">我看顾谦卑、悔过、</span><br /><span className="pl pl-1">对我的话心存敬畏的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="箴言 15:8; 阿摩司书 5:21–22; 以赛亚书 1:11–15"> <span className="pl pl-1">“至于那些任意妄为、</span><br /><span className="pl pl-1">以行可憎之事为乐的人，</span><br /><span className="pl pl-1">他们宰牛就像杀人、</span><br /><span className="pl pl-1">献羊羔就像打断狗颈、</span><br /><span className="pl pl-1">献谷物就像献猪血、</span><br /><span className="pl pl-1">烧香就像颂赞偶像，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 65:12; 耶利米书 7:13; 箴言 10:24"> <span className="pl pl-1">我必重重地惩罚他们，</span><br /><span className="pl pl-1">使他们遭遇自己害怕的事。</span><br /><span className="pl pl-1">因为我呼唤，无人回应；</span><br /><span className="pl pl-1">我讲话，无人聆听。</span><br /><span className="pl pl-1">他们做我视为恶的事，</span><br /><span className="pl pl-1">专行令我不悦的事。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:18–20; 以赛亚书 66:2; 马太福音 5:10–12"> <span className="pl pl-1">对耶和华的话心存敬畏的人啊，要听祂的话：</span><br /><span className="pl pl-1">“你们的弟兄憎恨你们，</span><br /><span className="pl pl-1">因为我的名而弃绝你们，</span><br /><span className="pl pl-1">他们讥讽说，</span><br /><span className="pl pl-1">‘愿耶和华得荣耀，</span><br /><span className="pl pl-1">我们好看看你们的欢乐！’</span><br /><span className="pl pl-1">他们必受羞辱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 3:7–16; 阿摩司书 1:2; 以赛亚书 34:8"> <span className="pl pl-1">城中传出喧闹声，</span><br /><span className="pl pl-1">殿中也传出声音，</span><br /><span className="pl pl-1">这是耶和华报应祂仇敌的声音。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="启示录 12:1–5; 以赛亚书 54:1; 加拉太书 4:26"> <span className="pl pl-1">“锡安还没有阵痛就分娩，</span><br /><span className="pl pl-1">还没有感到产痛就生下男婴。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 64:4; 以赛亚书 49:20–22; 罗马书 15:18–21"> <span className="pl pl-1">谁曾听过看过这样的事？</span><br /><span className="pl pl-1">一个国家能一日而生吗？</span><br /><span className="pl pl-1">一个民族能在刹那间产生吗？</span><br /><span className="pl pl-1">然而锡安刚开始阵痛就生下了儿女。”</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 37:3; 创世记 18:14"> <span className="pl pl-1">耶和华说：“我既使她临产，</span><br /><span className="pl pl-1">难道不让她分娩吗？”</span><br /><span className="pl pl-1">你的上帝说：“我既使她生产，</span><br /><span className="pl pl-1">难道封闭她的胎吗？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="诗篇 26:8; 申命记 32:43; 诗篇 137:6"> <span className="pl pl-1">“所有爱耶路撒冷的人啊，</span><br /><span className="pl pl-1">要与她一同欢喜，为她高兴。</span><br /><span className="pl pl-1">所有为她悲哀的人啊，</span><br /><span className="pl pl-1">要与她尽情欢乐。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 60:16; 约珥书 3:18; 以赛亚书 60:5"> <span className="pl pl-1">你们必在她舒适的怀抱里得到乳养和满足，</span><br /><span className="pl pl-1">欣然畅饮她充足的奶汁。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 48:18; 以赛亚书 60:16; 以赛亚书 45:14"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“看啊，我赐给她的平安如涛涛江河，</span><br /><span className="pl pl-1">使万国的滚滚财富都归给她。</span><br /><span className="pl pl-1">你们必被她抱在怀中乳养，</span><br /><span className="pl pl-1">摇在膝上。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 1:4; 以赛亚书 51:3; 以赛亚书 40:1"> <span className="pl pl-1">母亲怎样抚慰孩子，</span><br /><span className="pl pl-1">我也怎样抚慰你们，</span><br /><span className="pl pl-1">你们必在耶路撒冷得到安慰。”</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亚书 10:7; 以斯拉记 8:31; 以斯拉记 7:9"> <span className="pl pl-1">你们见到这些事，必满心欢喜，</span><br /><span className="pl pl-1">身体如青草一样充满活力。</span><br /><span className="pl pl-1">耶和华必向祂的仆人彰显大能，</span><br /><span className="pl pl-1">向祂的仇敌发怒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:33; 帖撒罗尼迦后书 1:6–9; 彼得后书 3:10–12"> <span className="pl pl-1">看啊，耶和华要在火中降临，</span><br /><span className="pl pl-1">祂的战车好像旋风。</span><br /><span className="pl pl-1">祂要发烈怒，用火焰惩罚。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 38:21–22; 以赛亚书 30:30; 以西结书 39:2–10"> <span className="pl pl-1">因为耶和华要用火和剑审判世人，并杀死许多人。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 65:3–4; 申命记 14:3–8; 以赛亚书 1:28–29"> 耶和华说：“那些人奉献自己、洁净自己，一个接一个进园中祭拜偶像，又吃猪肉、老鼠及其他可憎之物，他们必一同灭亡。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 86:9; 启示录 11:15; 哥林多后书 4:4–6"> 我知道他们的所作所为和所思所想。我要召集万邦万民，他们必来瞻仰我的荣耀。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 52:15; 罗马书 15:21; 以赛亚书 55:5"> 我要在他们中间行神迹，我要派一些生还者到他施、普勒、路德、米设、罗施、土巴、雅完各国，以及那些没有听过我名声，也没有见过我荣耀的遥远海岛。他们必在列国传扬我的荣耀。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 60:3–14; 以赛亚书 65:11; 以赛亚书 11:9"> 他们必骑着马、驾着车、坐着轿、骑着骡子或骆驼，把你们的弟兄从各国带到我的圣山耶路撒冷，作为供物献给耶和华，好像以色列人用洁净的器皿把素祭带到耶和华的殿中。这是耶和华说的。”</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:9; 出埃及记 19:6; 启示录 1:6"> 耶和华说：“我要在他们中间立一些人做祭司和利未人。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 65:17; 彼得后书 3:13; 启示录 21:1"> <span className="pl pl-1">耶和华说：“正如我造的新天新地在我面前长存，</span><br /><span className="pl pl-1">你们的名字和后裔也必长存。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 46:1; 诗篇 86:9; 歌罗西书 2:16–17"> <span className="pl pl-1">每逢朔日和安息日，</span><br /><span className="pl pl-1">世人都必来敬拜我。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="启示录 14:10–11; 以赛亚书 14:11; 帖撒罗尼迦前书 2:15–16"> <span className="pl pl-1">他们必出去观看那些背叛我之人的尸体，</span><br /><span className="pl pl-1">因为咬他们的虫不会死，</span><br /><span className="pl pl-1">烧他们的火不会灭，</span><br /><span className="pl pl-1">世人都必厌恶他们。”</span></span>
</div>

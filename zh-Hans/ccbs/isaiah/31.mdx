## 要倚靠主，而非埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 20:7; 耶利米书 17:5; 申命记 17:16"> 那些下到埃及寻求帮助的人有祸了！<br /><span className="pl pl-1">他们仰赖战马，倚靠众多的战车和强壮的骑兵，</span><br /><span className="pl pl-1">却不仰望以色列的圣者，</span><br /><span className="pl pl-1">不寻求耶和华。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:19; 以赛亚书 45:7; 阿摩司书 3:6"> <span className="pl pl-1">然而，耶和华有智慧，</span><br /><span className="pl pl-1">有能力降灾，</span><br /><span className="pl pl-1">从不食言。</span><br /><span className="pl pl-1">祂必惩罚恶人之家及其帮凶。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 9:17; 以西结书 20:33–34; 以西结书 28:9"> <span className="pl pl-1">埃及人不过是人，并非上帝；</span><br /><span className="pl pl-1">埃及的战马是血肉之躯，</span><br /><span className="pl pl-1">并不是灵。</span><br /><span className="pl pl-1">耶和华一伸手，</span><br /><span className="pl pl-1">那些帮凶必踉跄，</span><br /><span className="pl pl-1">受帮助的必跌倒，</span><br /><span className="pl pl-1">他们必一同灭亡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿书 11:10; 阿摩司书 3:8; 以赛亚书 42:13"> <span className="pl pl-1">耶和华对我说：</span><br /><span className="pl pl-1">“猛狮守护猎物，发出咆哮。</span><br /><span className="pl pl-1">即使叫来许多牧人一起攻击它，</span><br /><span className="pl pl-1">它也不会因他们的呐喊而惧怕，</span><br /><span className="pl pl-1">不会因他们的叫嚷而畏缩。</span><br /><span className="pl pl-1">同样，万军之耶和华必降临在锡安山上争战。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 91:4; 诗篇 37:40; 以赛亚书 37:35"> <span className="pl pl-1">万军之耶和华必保护耶路撒冷，</span><br /><span className="pl pl-1">就像飞鸟展翅保护幼雏一样。</span><br /><span className="pl pl-1">祂必护卫它，搭救它，</span><br /><span className="pl pl-1">祂必越过它，解救它。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 3:22; 耶利米书 3:14; 以赛亚书 55:7"> 以色列人啊，你们已经严重悖逆耶和华，现在归向祂吧！</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 30:22; 以赛亚书 2:20; 以西结书 36:25"> 到那日，你们都要抛弃自己罪恶双手制造的金银偶像。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 14:25; 创世记 49:15; 以赛亚书 37:7"> <span className="pl pl-1">“亚述人必丧身刀下，但并非人的刀；</span><br /><span className="pl pl-1">他们必被刀吞噬，但并非凡人的刀。</span><br /><span className="pl pl-1">他们必逃避这刀，</span><br /><span className="pl pl-1">他们的青年必做苦役。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="玛拉基书 4:1; 以赛亚书 29:6; 利未记 6:13"> <span className="pl pl-1">他们的堡垒必因恐惧而陷落，</span><br /><span className="pl pl-1">他们的将领一看见战旗就惊慌失措。”</span><br /><span className="pl pl-1">这是耶和华说的，</span><br /><span className="pl pl-1">祂的火在锡安，祂的火炉在耶路撒冷。</span></span>
</div>

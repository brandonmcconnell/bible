## 预言灾难降临

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 30:8; 约伯记 19:23–24; 哈巴谷书 2:2–3"> 耶和华对我说：“你去拿块大的写字板，用通用的文字在上面写上‘玛黑珥·沙拉勒·哈施·罢斯’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛黑珥·沙拉勒·哈施·罢斯”意思是“快速掳掠，迅速抢夺”。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 16:10–11; 列王纪下 18:2; 哥林多后书 13:1"> 我会吩咐忠信的祭司乌利亚和耶比利迦的儿子撒迦利亚为这事做见证。”</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 1:3–9; 士师记 4:4; 以赛亚书 7:13–14"> 我以赛亚与女先知同房，她就怀孕生了个儿子。耶和华对我说：“给他取名叫玛黑珥·沙拉勒·哈施·罢斯。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:11; 列王纪下 16:9; 申命记 1:39"> 因为这孩子会叫爸爸妈妈之前，亚述王必把大马士革的财富和撒玛利亚的战利品洗劫一空。”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:10"> 耶和华又对我说：</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 9:7; 尼希米记 3:15; 以赛亚书 7:6"> “因为这些百姓厌弃西罗亚的缓缓流水，反倒因利汛和利玛利的儿子而欢喜。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 17:12–13; 创世记 6:17; 以赛亚书 7:17"> 因此，我要差来亚述王和他的军队，使他们像幼发拉底河的洪流一样汹涌而来，淹没一切水道，漫过河岸，</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 7:14; 以赛亚书 30:28; 马太福音 1:23"> 席卷犹大，使整个犹大几遭灭顶之灾。他必展开双翼横扫你的土地。”愿上帝与我们同在！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 14:5–6; 箴言 11:21; 诗篇 37:14–15"> <span className="pl pl-1">列国啊，你们必被打垮、击溃！</span><br /><span className="pl pl-1">远方的人啊，你们要侧耳听！</span><br /><span className="pl pl-1">整装备战吧，但你们必被击垮！</span><br /><span className="pl pl-1">整装备战吧，但你们必被击垮！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:37; 罗马书 8:31; 约伯记 5:12"> <span className="pl pl-1">你们设计谋吧，但休想得逞！</span><br /><span className="pl pl-1">你们定策略吧，但休想成功！</span><br /><span className="pl pl-1">因为上帝与我们同在。</span></span>

## 当敬畏主

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 3:14; 箴言 1:15; 耶利米书 15:19"> 耶和华大能的手按在我身上，警告我不可效法这些百姓。祂说：</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14–15; 路加福音 21:9; 诗篇 53:5"> “他们认为是阴谋的，你们不要认为是阴谋。他们所怕的，你们不要怕，也不要畏惧。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:5; 以赛亚书 26:3–4; 启示录 15:4"> 你们当尊万军之耶和华为圣，当敬畏祂，惧怕祂。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 2:8; 罗马书 9:32–33; 以赛亚书 28:16"> 祂必作人的圣所，也要作以色列和犹大两家的绊脚石和使他们跌倒的磐石，作耶路撒冷居民的陷阱和网罗。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:44; 路加福音 20:17–18; 以赛亚书 28:13"> 许多人必被绊倒，摔得粉身碎骨；他们必被网罗缠住，捕获。”</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 12:4; 希伯来书 3:5; 马可福音 4:10–11"> 你们要在我的门徒中间把上帝的训诲卷起来，用印封好。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:36–39; 哈巴谷书 2:3; 耶利米哀歌 3:25–26"> 虽然耶和华掩面不顾雅各家，但我仍要等候祂，冀望于祂。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:13–14; 路加福音 2:34; 撒迦利亚书 8:3"> 看啊，我和耶和华赐给我的儿女在以色列是征兆和迹象。这征兆和迹象来自住在锡安山的万军之耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 10:13; 利未记 20:6; 历代志下 33:6"> 有人让你们去求问那些念念有词的巫师和术士。难道你们不该去求问你们的上帝吗？活人的事怎能求问死人呢？</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 1:19; 提摩太后书 3:15–17; 以赛亚书 30:8–11"> 人应该遵循耶和华的训诲和法度。人若不遵循祂的话，必看不到曙光。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 9:20; 箴言 19:3; 耶利米哀歌 4:4–5"> 他们必困苦，饥饿，到处流浪。他们饥饿时，会怒气冲冲地扬天咒骂他们的君王，亵渎上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:30; 马太福音 22:13; 耶利米书 13:16"> 他们低头看地，看到的尽是患难、痛苦和黑暗。他们必被扔进黑暗中。</span>
</div>

## 给亚哈斯王的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:37; 列王纪下 16:1; 以赛亚书 1:1"> 乌西雅的孙子、约坦的儿子亚哈斯做犹大王时，亚兰王利汛和利玛利的儿子以色列王比加来攻打耶路撒冷，却无法攻破。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 8:12; 以赛亚书 7:13; 以赛亚书 9:9"> 亚兰和以色列结盟的消息传到犹大王那里，举国上下都吓得胆战心惊，好像林中被风吹动的树木。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:17; 以赛亚书 36:2; 罗马书 9:27"> 耶和华对以赛亚说：“你带着儿子施亚雅述出去，到上池水沟的尽头、在通往漂布场的路上迎见亚哈斯，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 35:4; 耶利米哀歌 3:26; 申命记 20:3"> 告诉他要谨慎镇定，不要害怕，不要因亚兰王利汛和利玛利的儿子的怒气而胆怯，他们不过是两个冒烟的火把头。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 83:3–4; 撒迦利亚书 1:15; 诗篇 2:2"> 亚兰王和以法莲及利玛利的儿子阴谋毁灭他，</span>
<span className="v" id="v6" data-v="6"> 企图攻打并瓜分犹大，改立他比勒的儿子为王。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 8:10; 耶利米哀歌 3:37; 以赛亚书 46:10–11"> 但主耶和华说，<br /><span className="pl pl-1">“‘这阴谋休想得逞，</span><br /><span className="pl pl-1">休想成功。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 17:1–3; 创世记 14:15; 撒母耳记下 8:6"> <span className="pl pl-1">亚兰的都城是大马士革，</span><br /><span className="pl pl-1">大马士革的首领是利汛。</span><br /><span className="pl pl-1">六十五年之内，</span><br /><span className="pl pl-1">以法莲必亡国灭族。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 11:6; 罗马书 11:20; 历代志下 20:20"> <span className="pl pl-1">以法莲的都城是撒玛利亚，</span><br /><span className="pl pl-1">撒玛利亚的首领是利玛利的儿子。</span><br /><span className="pl pl-1">你们信心若不坚定，</span><br /><span className="pl pl-1">必无法坚立。’”</span></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 8:5; 以赛亚书 1:5; 以赛亚书 10:20"> 耶和华又对亚哈斯说：</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 37:30; 以赛亚书 38:7–8; 以赛亚书 38:22"> “向你的上帝耶和华求个征兆吧，或显在天上，或显在阴间。”</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 33:31; 历代志下 28:22; 玛拉基书 3:15"> 但亚哈斯说：“我不求，我不要试探耶和华。”</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:24; 以赛亚书 63:10; 以西结书 34:18"> 以赛亚说：“大卫家啊，你们听着！你们使人厌烦还不够吗？还要使我的上帝厌烦吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:23; 以赛亚书 9:6; 路加福音 1:31"> 所以，主会亲自给你们一个征兆，必有童贞女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“童贞女”或译“女子”。">a</a></sup>怀孕生子并给他取名叫以马内利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“以马内利”意思是“上帝与我们同在”。">b</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 7:22; 阿摩司书 5:15; 马太福音 3:4"> 他将吃奶酪和蜂蜜，一直到他能弃恶择善之时。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:4; 申命记 1:39; 以赛亚书 9:11"> 因为在他能明辨是非之前，你所惧怕的这二王的国土必荒废。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 8:7–8; 以赛亚书 10:5–6; 历代志下 28:19–21"> “之后，耶和华必让亚述王来攻击你、你的人民和你全家，这是自以法莲与犹大分裂以来从未有过的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 5:26; 约书亚记 24:12; 申命记 1:44"> 那时，耶和华必用哨声从埃及的尼罗河口召来苍蝇，从亚述召来黄蜂。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 2:19; 耶利米书 16:16; 以赛亚书 2:21"> 它们必蜂拥而来，落在险峻的山谷、岩穴、一切荆棘丛和草场。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:7; 以西结书 29:18; 以赛亚书 10:15"> 那时，主必使用从幼发拉底河那边租来的剃刀，就是亚述王，来剃光你们的头发、体毛和胡须。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 5:17; 耶利米书 39:10; 以赛亚书 37:30"> 那时，一个人将养活一头小母牛和两只羊。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 7:15; 马太福音 3:4; 撒母耳记下 17:29"> 因出产的奶丰富，他就有奶酪吃，境内剩下的人都将吃奶酪和蜂蜜。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 5:6; 雅歌 8:11–12; 马太福音 21:33"> 那时，本来有千株葡萄、价值千金的各园子都必长满荆棘和蒺藜，</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 27:3"> 人们必带着弓箭去那里打猎，因为遍地长满了荆棘和蒺藜。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 7:21–22; 以赛亚书 13:20–22; 以赛亚书 5:17"> 你因惧怕荆棘和蒺藜，将不再去从前用锄头开垦的山地，那里将成为牧放牛羊的地方。”</span>
</div>

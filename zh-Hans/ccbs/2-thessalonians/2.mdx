## 主再来的先兆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 4:14–17; 马可福音 13:27; 马太福音 24:31"> 弟兄姊妹，关于主耶稣基督再来和我们到祂那里相聚的事情，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:1–2; 马可福音 13:7; 马太福音 24:4–6"> 我们现在奉劝你们：无论是什么灵，或是传闻，或是冒充我们写的信，说主的日子已经到了，你们都不要轻易动摇，也不要惊慌。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:4–6; 约翰一书 2:18; 以弗所书 5:6"> 不管别人用什么诡计，你们都不要上当。因为那日子来临之前，必有离经叛道的事发生，而那不法之徒，就是那注定灭亡的人也要出现。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 28:2; 但以理书 7:25; 启示录 13:6–7"> 他会抵挡主，高抬自己超过一切所谓的神明和人们崇拜的对象，甚至坐在上帝的殿中以上帝自居！</span>
<span className="v" id="v5" data-v="5" data-xref="彼得后书 1:15; 加拉太书 5:21; 马太福音 16:9"> 我还在你们那里的时候，曾告诉过你们这些事，你们忘记了吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:3; 帖撒罗尼迦后书 2:8"> 现在，你们知道是什么拦阻他，使他到了所定的时间才出现。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:3; 启示录 17:7; 提摩太后书 2:17–18"> 其实那不法之徒的阴谋已经在酝酿中，然而现在有一位在拦阻他。等到拦阻他的那位一离开，</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 2:3; 启示录 19:20–21; 以赛亚书 11:4"> 他就会出现，但主耶稣会用自己口中的气毁灭他，用从天降临的荣光废掉他。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:24; 启示录 19:20; 以弗所书 2:2"> 他来要按照撒旦的伎俩行各种虚假的异能、神迹和奇事，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 1:18; 箴言 1:7; 哥林多后书 4:2–3"> 用尽各种诡计欺骗那些将要灭亡的人，因为他们不喜欢接受那能拯救他们的真理。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 1:28; 约翰福音 12:39–43; 提摩太前书 4:1"> 上帝就让他们是非不辨，去相信那些虚假的谎言，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:32; 罗马书 8:7–8; 马可福音 16:16"> 使一切不相信真理、反喜爱不义的人都被定罪。</span>
</div>
</div>

## 要坚定不移

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 帖撒罗尼迦前书 1:4"> 主所爱的弟兄姊妹，我们应当常常为你们感谢上帝，因为上帝一开始就拣选了你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“一开始就拣选了你们”有古卷作“拣选你们作初熟的果子”。">a</a></sup>，使你们借着圣灵得以圣洁，并且相信真理，从而得救。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:12; 彼得前书 5:10; 帖撒罗尼迦前书 1:5"> 为此，上帝借着我们所传的福音呼召了你们，使你们可以得到我们主耶稣基督的荣耀。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 11:2; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 2:2"> 所以，各位弟兄姊妹，务要坚定不移，无论是我们信上的教导还是口头的教导，你们都要坚守。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:2–5; 约翰福音 3:16; 彼得前书 1:3–8"> 愿主耶稣基督和爱我们、开恩将永远的安慰和美好的盼望赐给我们的父上帝，</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:3; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 3:2"> 安慰你们的心，使你们在一切善行善言上刚强。</span>
</div>
</div>

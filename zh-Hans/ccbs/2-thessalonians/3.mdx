## 请求代祷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:25; 歌罗西书 4:3; 哥林多前书 16:9"> 弟兄姊妹，最后我还要请你们为我们祷告，好使主的道像在你们那里一样迅速传开、受到尊崇，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 4:3–4; 罗马书 15:31; 申命记 32:20"> 并使我们能避开那些邪恶的人，因为不是人人都有信心。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 4:18; 帖撒罗尼迦前书 5:24; 哥林多前书 10:13"> 主是信实的，祂必使你们刚强，保护你们脱离那恶者。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 腓利门书 1:21; 帖撒罗尼迦前书 4:10"> 我们靠着主深信你们正遵行我们的吩咐，而且以后还会继续遵行。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 119:36; 历代志上 29:18; 申命记 30:6"> 愿主引导你们的心领悟上帝的爱和基督的坚忍。</span>
</div>
</div>

## 不可游手好闲

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:10–11; 帖撒罗尼迦后书 3:7; 罗马书 16:17"> 弟兄姊妹，现在我们奉主耶稣基督的名吩咐你们，要远离那些游手好闲、不遵守我们教导的信徒。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 3:9; 哥林多前书 4:16"> 你们自己知道应该怎样效法我们，因为我们在你们那里的时候，并没有懒懒散散，</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:11; 帖撒罗尼迦前书 2:9; 以弗所书 4:28"> 也没有白吃谁的饭，而是昼夜辛勤工作，免得成为你们任何人的负担。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:7; 帖撒罗尼迦前书 2:6; 哥林多前书 9:4–14"> 这并不是因为我们没有权利接受供应，而是要给你们树立学习的榜样。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 3:19; 箴言 13:4; 箴言 20:4"> 我们在你们那里的时候，曾吩咐过你们：不肯工作的人没有资格吃饭。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:13; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦前书 4:11"> 我们听说在你们当中有些人游手好闲，无所事事，专管闲事。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:28; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:8"> 我们奉主耶稣基督的名吩咐并劝诫这些人要安分守己，自食其力。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:9–10; 希伯来书 12:3; 哥林多后书 4:1"> 弟兄姊妹，你们要坚持行善，不要灰心。</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 3:10; 帖撒罗尼迦后书 3:6; 哥林多前书 5:11"> 如果有人不听从这信上的教导，要注意提防他，不要和他来往，好使他羞愧。</span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:10; 帖撒罗尼迦前书 5:14; 哥林多前书 5:5"> 只是不可把他当作仇人，要像对待弟兄姊妹一样劝诫他。</span>
</div>
</div>

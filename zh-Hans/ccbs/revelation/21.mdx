## 新天新地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:17–19; 彼得后书 3:13; 以赛亚书 66:22"> 接着我看见一个新天新地，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书65:17。">a</a></sup>因为以前的天地都消逝了，海洋也不复存在了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:10; 启示录 3:12; 启示录 21:10"> 我又看见圣城新耶路撒冷从天上的上帝那里降下，预备好了，像妆饰整齐等候新郎的新娘。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 37:27; 哥林多后书 6:16; 约翰福音 14:23"> 我听见从宝座中传来响亮的声音说：“看啊！上帝的居所设立在人间，祂要与人同住。他们要成为祂的子民，上帝要亲自与他们同在，做他们的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 25:8; 启示录 7:17; 哥林多前书 15:26"> 上帝要擦干他们所有的眼泪，再没有死亡、忧伤、哭泣和痛苦，因为以前的事都已成过去。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书25:8。">b</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:17; 以赛亚书 42:9; 以赛亚书 43:19"> 坐在宝座上的那位说：“看啊！我已经将一切都更新了。你要将这一切记录下来，因为这些话真实可信。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:37–38; 约翰福音 4:10; 启示录 7:17"> 祂又对我说：“一切都成了！我是阿拉法，我是俄梅加；我是开始，我是终结。我要将生命泉的水白白赐给口渴的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 6:18; 希伯来书 8:10; 启示录 2:11"> 得胜者必承受这一切福分，我要做他的上帝，他要做我的儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 6:9–10; 启示录 2:11; 以弗所书 5:5–6"> 至于那些胆怯的、不信的、行为可憎的、杀人的、淫乱的、行邪术的、拜偶像的和所有说谎的，他们的结局是被扔进硫磺火湖里，这就是第二次的死。”</span>
</div>
</div>

## 新耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 21:2; 启示录 19:7; 启示录 16:1–17"> 七位天使手里拿着盛满最后七灾的七个碗，其中有一位来对我说：“你来，我要将新娘，就是羔羊的妻子指给你看。”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:2; 以西结书 11:24; 以西结书 40:1–49"> 我被圣灵感动，天使带着我到一座高大的山上，将从天上的上帝那里降下的圣城耶路撒冷指给我看。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 4:6; 启示录 22:5; 启示录 22:1"> 城中充满上帝的荣光，璀璨如贵重的宝石，晶莹如碧玉。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 48:31–34; 启示录 7:4–8; 启示录 21:17–21"> 城墙高大，有十二个城门，东、北、南、西每面三个门，每个城门都有一位天使把守，门上写着以色列十二支派的名字。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 11:10; 以弗所书 2:20; 以赛亚书 54:11"> 城墙共有十二块基石，基石上有羔羊的十二位使徒的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 2:1; 启示录 11:1–2; 以西结书 41:1–5"> 那和我说话的天使拿了一根金量杆要丈量圣城、城墙和城门。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 48:35; 以西结书 48:8–20"> 圣城是正方形的，长宽相等。天使用量杆丈量那城，长、宽、高都是两千二百公里<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“两千二百公里”希腊文是“一万二千司他町”。">c</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 7:4; 申命记 3:11; 启示录 13:18"> 他又丈量了城墙，按人的尺寸，也是天使的尺寸来算，是六十五米<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“六十五米”希腊文是“一百四十四肘”。">d</a></sup>厚。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 21:11; 启示录 21:21; 启示录 21:19"> 城墙是用碧玉砌成的，城本身是用纯金造的，跟玻璃一样明净。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:11–12; 出埃及记 28:17–21; 约伯记 28:16–19"> 城墙的基石用各种宝石装饰：第一块基石是碧玉，第二块是蓝宝石，第三块是绿玛瑙，第四块是绿宝石，</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 4:3"> 第五块是红玛瑙，第六块是红宝石，第七块是橄榄石，第八块是水苍玉，第九块是黄宝石，第十块是翡翠，第十一块是紫玛瑙，第十二块是紫晶。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:18; 启示录 17:4; 启示录 22:2"> 十二个城门是用十二颗珍珠造的，每一个城门都是一颗珍珠，城中的街道是纯金的，好像透明的玻璃一样。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:23; 列王纪上 8:27; 历代志下 2:6"> 我看见城中没有圣殿，因为全能的主上帝和羔羊就是圣城的殿。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 60:19–20; 启示录 22:5; 启示录 21:11"> 圣城里不需要太阳和月亮的光照耀，因为有上帝的荣光照耀，羔羊就是圣城的灯。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 21:26; 启示录 22:2; 撒迦利亚书 8:22–23"> 万民要在圣城的光中行走，地上的君王也要将他们的荣耀带进圣城。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 60:11; 撒迦利亚书 14:7; 启示录 22:5"> 城门整天都开着，那里没有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 21:24"> 人们将列国的荣耀和尊贵带进圣城。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 22:14–15; 以赛亚书 52:1; 启示录 20:15"> 所有污秽的、做可憎之事的、撒谎的都不得进入圣城。唯有名字记录在羔羊的生命册上的人才有资格进去。</span>
</div>
</div>

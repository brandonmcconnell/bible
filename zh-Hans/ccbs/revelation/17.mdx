## 大淫妇的下场

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 19:2; 启示录 17:1–17; 耶利米书 51:13"> 拿着七碗的七位天使中有一位前来对我说：“你过来！我要让你看那坐在众水之上的大淫妇将要遭受的刑罚。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:7; 启示录 18:3"> 地上的君王与她行淫，地上的居民因喝了她淫乱的酒而酩酊大醉。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="启示录 12:3; 启示录 13:1–6; 启示录 12:6"> 那时，我被圣灵感动，被天使带到旷野，在那里见到一个妇人骑着一只朱红色怪兽。怪兽有七头十角，浑身写满亵渎上帝的名号。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 18:16; 耶利米书 51:7; 启示录 19:2"> 那妇人身穿紫色和朱红色衣服，用黄金、宝石及珍珠装扮自己。她手中拿着金杯，里面盛满了她淫乱可憎的污秽之物。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 14:8; 启示录 18:2; 启示录 17:7"> 在她额上还写了一个神秘的名号：“大巴比伦——地上淫妇及可憎事物之母”。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 16:6; 启示录 13:15; 启示录 2:13"> 我又见她醉了，因她喝了众圣徒的血，就是为耶稣做见证之人的血。<br />我看见她的时候，感到非常惊奇。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 17:1–6; 启示录 17:8"> 天使对我说：“你为什么惊奇呢？我要将这妇人和她骑的七头十角怪兽的奥秘告诉你。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 17:11; 启示录 11:7; 启示录 3:10"> 你看见的这怪兽以前出现过，现今没有出现，将来要从无底坑上来，然后走向灭亡。凡住在地上、自创世以来名字没有记在生命册上的人，都因见到这只从前出现过、现今没有出现、将来会再出现的怪兽而感到惊奇。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 13:18; 启示录 17:7; 马太福音 13:11"> 这里需要智慧才能明白，它的七个头是指那妇人坐镇的七座山，又指七个王。</span>
<span className="v" id="v10" data-v="10"> 其中五个已经衰亡，一个还在，另外一个还未来到，他来后只能短暂存留。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 17:8"> 那从前出现过、现今没有出现的怪兽是第八个王，他是七个王之一，也要走向灭亡。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 12:3; 启示录 13:1; 但以理书 7:24"> 你看见的那十个角是指另外十个还没有得势的王，他们将取得王权和那怪兽一同统治短暂的一段时期。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 17:17; 以西结书 38:10; 以赛亚书 10:5–7"> 他们一致同意把自己所有的能力和权柄交给那怪兽。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:30; 提摩太前书 6:15; 马太福音 22:14"> 他们将与羔羊交战，但羔羊必胜过他们，因为羔羊是万主之主，万王之王。那些跟随羔羊的是被呼召、蒙拣选、忠心耿耿的人。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 17:1; 耶利米书 51:13; 耶利米书 51:55"> 天使又对我说：“你看见的那淫妇所坐的众水是指来自各民族、各国家、各语言族群的人。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 18:8; 以西结书 16:37–44; 利未记 21:9"> 怪兽和你看见的十角必憎恨那淫妇，使她赤身露体、景况凄凉。它们要吃她的肉，最后用火将她烧尽。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 2:10–12; 箴言 21:1; 启示录 10:7"> 众王同心将政权交给怪兽，直到上帝的话都应验。因为上帝使他们定意这样做，好完成祂的旨意。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 16:19; 启示录 18:2; 但以理书 7:23"> 你看见的那妇人就是那掌管世上众王的大城。”</span>
</div>
</div>

## 天上的赞美

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 7:10–12; 历代志上 29:11; 启示录 11:15"> 此后，我听见天上好像有一大群人在呼喊：“哈利路亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“哈利路亚”意思是“要赞美上帝”。">a</a></sup>！救赎、荣耀和权能都归于我们的上帝！</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:43; 启示录 6:10; 启示录 18:20"> 因为祂的审判真实公义，祂惩罚了那用淫乱败坏世界的大淫妇，为那些被她杀害的奴仆申冤。”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 34:10; 启示录 18:18; 启示录 14:11"> 他们又欢呼说：“哈利路亚！焚烧大淫妇的烟不断上腾，直到永永远远。”</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 5:14; 尼希米记 8:6; 诗篇 106:48"> 那二十四位长老和四个活物也俯伏敬拜坐在宝座上的上帝，说：“阿们！哈利路亚！”</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 134:1; 诗篇 148:11–13; 诗篇 150:6"> 这时从宝座那里发出声音，说：“上帝所有的奴仆和一切敬畏祂的人，无论尊卑，都要赞美我们的上帝！”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 97:1; 启示录 14:2; 诗篇 93:1"> 我听见有声音好像一大群人的呼喊声，又像洪涛，也像雷鸣，说：“哈利路亚！因为我们的主，全能的上帝已经执掌王权了。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 21:9; 启示录 21:2; 启示录 19:9"> 我们要欢喜快乐，归荣耀给祂，因为羔羊的婚期到了，祂的新娘已预备妥当，</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 61:10; 启示录 7:13–14; 诗篇 132:9"> 获准穿上光亮洁白的细麻衣。”这细麻衣代表圣徒的义行。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 22:6; 马太福音 22:2–4; 路加福音 14:15–16"> 天使吩咐我说：“你要写下来，被邀请参加羔羊婚宴的人有福了！”他又说：“这是上帝说的，千真万确。”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 22:8–9; 使徒行传 10:25–26; 约翰福音 5:39"> 我俯伏在他脚前要拜他，他却说：“千万不可！我和你并那些为耶稣做见证的弟兄姊妹同是上帝的奴仆。你要敬拜上帝，因为预言的真谛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“真谛”或译“灵”。">b</a></sup>就是为耶稣做见证。”</span>
</div>
</div>

## 白马骑士

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 96:13; 以赛亚书 11:3–5; 诗篇 98:9"> 我看见天开了，有一匹白马出来，马上的骑士名叫“诚信真实”，祂凭公义审判和争战。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 19:16; 路加福音 10:22; 启示录 2:17–18"> 祂双目如炬，头上戴了许多冠冕，身上写着一个只有祂自己才明白的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:1; 以赛亚书 63:1–6; 约翰福音 1:14"> 祂穿着被血浸透的衣服，祂的名字是“上帝的道”。</span>
<span className="v" id="v14" data-v="14" data-xref="犹大书 1:14; 启示录 7:9; 启示录 19:8"> 众天军穿着洁白的细麻衣，骑着白马跟随祂。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:2–6; 启示录 1:16; 启示录 2:27"> 祂口中吐出一把利剑，可以攻击列国。祂必用铁杖统治他们，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇2:9。">c</a></sup>祂必踩踏盛满全能上帝之烈怒的榨酒池。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:14; 提摩太前书 6:15; 但以理书 2:47"> 祂的衣服和大腿上都写着祂的名号：“万王之王，万主之主。”</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 19:21; 启示录 8:13; 以西结书 39:17–20"> 我又看见一位天使站在太阳里，对空中飞翔的鸟大声呼唤：“来吧！一起来参加上帝的盛宴，</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 39:18–20; 启示录 6:15; 撒母耳记上 17:44"> 一同吃君王、将军、勇士、马匹、骑士和所有人的肉吧，无论他们是自由人还是奴隶，尊贵还是卑贱。”</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 16:16; 启示录 16:14; 启示录 17:12–14"> 我看见那怪兽、地上的众王及其军队聚集起来，与白马骑士和祂的军队作战。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:10; 启示录 21:8; 帖撒罗尼迦后书 2:8–11"> 怪兽被俘虏了，在怪兽面前行奇迹的假先知也一同被擒了。这假先知曾用奇迹迷惑那些盖了兽印、敬拜兽像的人。他和怪兽一同被活活地扔进硫磺火湖里。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 19:11–15; 启示录 1:16; 启示录 19:17–19"> 其余的被白马骑士口中的利剑所杀，飞鸟饱餐了他们的肉。</span>
</div>
</div>

## 羔羊与封印的书卷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 2:9–10; 以赛亚书 29:11; 启示录 5:7"> 接着，我看见坐在宝座上的那位右手拿着一卷内外写着字、用七个印封住的书。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 29:11–12; 启示录 5:5; 启示录 10:1"> 我又看见一位大能天使高声问道：“谁有资格揭开那七个封印，打开书卷？”</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 5:13; 以赛亚书 40:13–14; 罗马书 11:34"> 可是，天上、地上、甚至地底下谁都没有资格开卷阅读。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 12:8–9; 启示录 4:1"> 我见谁都没有资格开卷阅读，便放声大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 11:1; 耶利米书 23:5–6; 启示录 22:16"> 有一位长老对我说：“不要哭！看啊，犹大支派的狮子，大卫的根已经得胜了，祂能揭开那七个封印，打开书卷。”</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亚书 4:10; 约翰福音 1:29; 启示录 5:12"> 我又看到宝座、四个活物和众长老之间站着一只好像是被宰杀过的羔羊。祂有七只角和七只眼睛，这些是指被派往普天下的上帝的七灵。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 5:1; 启示录 4:2–3"> 羔羊走上前去，从坐在宝座上的那位右手中接过书卷。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 141:2; 启示录 8:3–4; 腓立比书 2:9–11"> 祂拿过书卷后，四个活物和二十四位长老就各拿着竖琴和盛满了香的金香炉，俯伏在羔羊面前。那些香就是众圣徒的祈祷。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:18–19; 约翰一书 1:7; 马太福音 26:28"> 他们唱着一首新歌：<br /><span className="pl pl-1">“你配拿书卷并揭开封印，</span><br /><span className="pl pl-1">因你曾被杀，</span><br /><span className="pl pl-1">用你的血从各部落、各语言族群、各民族、各国家，</span><br /><span className="pl pl-1">将人买赎回来归给上帝。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="启示录 1:6; 但以理书 7:27; 启示录 20:6"> <span className="pl pl-1">你又使他们成为上帝的国度和祭司，</span><br /><span className="pl pl-1">他们要在地上执掌王权。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 7:10; 希伯来书 12:22; 启示录 4:4"> 我又看见宝座、四个活物和众长老的周围有千千万万的天使，并听见他们高声呼喊：</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 5:9; 启示录 19:1; 启示录 4:11"> “曾被杀的羔羊配得权柄、财富、智慧、能力、尊贵、荣耀和颂赞！”</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:10; 历代志上 29:11; 诗篇 148:2–13"> 我又听到天上、地上、地底下和海洋中一切被造之物同声说：“愿颂赞、尊贵、荣耀和权柄都归给坐在宝座上的那位和羔羊，直到永永远远！”</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 19:4; 启示录 4:9–11; 启示录 5:8"> 四个活物就说：“阿们！”众长老也俯伏敬拜。</span>

## 为上帝的仆人盖印

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:31; 但以理书 7:2; 耶利米书 49:36"> 此后，我看见四位天使分别站在地的四个角落控制着四面的风，使风不再吹向地面、海洋和树木。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:30; 哥林多后书 1:22; 启示录 7:3–8"> 我又看见一位天使从东方日出之地上来，手里拿着永活上帝的印。他对那领受权柄能伤害地和海的四位天使大声说：</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 9:4; 启示录 22:4; 启示录 9:4"> “我们在上帝的奴仆额上盖印之前，你们不可伤害地、海和树木。”</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 14:1; 启示录 14:3; 马太福音 19:28"> 我听见以色列各支派中盖了印的共有十四万四千人：</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 1:2–4; 民数记 10:14–27; 民数记 13:4–16"> 犹大支派有一万二千，吕便支派有一万二千，迦得支派有一万二千，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 2:36"> 亚设支派有一万二千，拿弗他利支派有一万二千，玛拿西支派有一万二千，</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:23; 民数记 26:14; 民数记 25:14"> 西缅支派有一万二千，利未支派有一万二千，以萨迦支派有一万二千，</span>
<span className="v" id="v8" data-v="8"> 西布伦支派有一万二千，约瑟支派有一万二千，便雅悯支派有一万二千。</span>
</div>
</div>

## 劫后余生的上帝子民

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 5:9; 约翰福音 12:13; 诗篇 117:1–2"> 此后，我观看，见有一大群人，不可胜数，他们来自各国家、各部落、各民族、各语言族群，身穿白袍，手拿棕树枝，站在宝座和羔羊面前，</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 19:1; 诗篇 3:8; 以赛亚书 45:21"> 大声呼喊说：“救恩来自我们坐在宝座上的上帝，也来自羔羊！”</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 5:11–13; 启示录 19:4–6; 启示录 4:10"> 众天使都站在宝座、众长老和四个活物的周围，在宝座前俯伏敬拜上帝，说：</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 5:12–14; 犹大书 1:25; 诗篇 100:4"> “阿们！愿颂赞、荣耀、智慧、感谢、尊贵、权柄、能力都归给我们的上帝，直到永永远远。阿们！”</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 7:9; 启示录 4:10; 启示录 5:5"> 其中一位长老问我：“这些身穿白袍的人是谁？他们从哪里来？”</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 1:7; 启示录 22:14; 希伯来书 13:12"> 我回答说：“先生，你知道答案。” 他便说：“这些都是经过大灾难的人，他们用羔羊的血将衣裳洗得洁白。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 21:3–4; 启示录 22:3; 哥林多后书 6:16"> 因此，他们在上帝的宝座前，在圣殿中不分昼夜地事奉上帝。坐在宝座上的那位要庇护他们。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:10; 诗篇 121:6; 马太福音 5:6"> 他们不会再受饥饿和干渴的折磨，也不会再受太阳和酷热的煎熬，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书25:8。">a</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:37–38; 诗篇 36:8–9; 约翰福音 4:14"> 因为在宝座中央的羔羊要做他们的牧人，引导他们到生命的泉水边，上帝要擦干他们所有的眼泪。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书49:10。">b</a></sup></span>
</div>

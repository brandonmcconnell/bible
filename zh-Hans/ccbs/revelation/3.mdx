## 给撒狄教会的信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 5:6; 雅各书 2:26; 启示录 1:4"> “你要写信告诉撒狄教会的天使，有上帝的七灵又有七颗星的主说，‘我知道你的行为，你名义上活着，实际上是死的。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 5:8; 提摩太后书 4:1–4; 启示录 16:15"> 你要警醒！把所剩无几、奄奄一息的生命振作起来，因为我发现你的行为在我的上帝面前不纯全。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 2:5; 彼得后书 3:10; 帖撒罗尼迦前书 5:2"> 因此，要回想你以前所领受、所听见的教导，遵守这些教导，并且悔改。你若不警醒，我必在你意想不到的时候，像贼一样突然临到。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:5; 启示录 7:9; 传道书 9:8"> 不过在撒狄，你还有几个人未曾玷污自己的衣服，他们要穿白衣与我同行，因为他们配得这样。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 10:32; 路加福音 12:8; 启示录 21:27"> 得胜者必同样穿上白衣，我绝不会从生命册上抹去他的名字，我必在我父和众天使面前承认他的名。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 2:7"> “‘圣灵对各教会所说的话，凡有耳朵的都应当听。’</span>
</div>
</div>

## 给非拉铁非教会的信

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 22:22; 马太福音 16:19; 启示录 1:18"> “你要写信告诉非拉铁非教会的天使，那位圣洁、真实、拿着大卫的钥匙、开了门无人能关、关了门无人能开的主说，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 16:9; 歌罗西书 4:3; 启示录 3:7"> ‘我知道你的行为。你力量微小，却遵守了我的教导，没有否认我的名。看啊！我在你面前开了一扇无人能关的门。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:14; 启示录 2:9; 以赛亚书 49:23"> 看啊！那些撒旦的会众自称是犹太人，其实他们不是，而是说谎的，我要使他们在你面前俯伏下拜，并知道你是我所爱的。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 2:9; 启示录 14:12; 撒迦利亚书 13:9"> 因为你遵守我有关坚忍的教导，所以当将来的试炼临到普天下的人时，我必使你免受磨难。</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 1:12; 启示录 22:12; 启示录 2:10"> 我很快就要来了！你要持守所拥有的，免得有人夺去你的冠冕。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 22:4; 启示录 21:2; 启示录 14:1"> 我要使得胜者在我上帝的殿中作栋梁，永不离开。我要将我上帝的名和我上帝圣城的名，就是从天上我上帝那里降下来的新耶路撒冷和我自己的新名，都写在他上面。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 2:7"> “‘圣灵对各教会所说的话，凡有耳朵的都应当听。’</span>
</div>
</div>

## 给老底嘉教会的信

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:15; 启示录 1:5; 哥林多后书 1:20"> “你要写信告诉老底嘉教会的天使，那位真实<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“真实”希腊文是“阿们”。">a</a></sup>、诚信、无伪的见证人，就是上帝所造万物的元首说，</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:11; 马太福音 6:24; 列王纪上 18:21"> ‘我知道你的行为，你不冷也不热。我情愿你或冷或热！</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 2:5; 撒迦利亚书 11:8–9; 耶利米书 14:19"> 你却像温水一样不冷不热，我必将你从我口中吐出去！</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; 何西阿书 12:8; 罗马书 7:24"> 你说，我很富有，已经发了财，什么都不缺。你却不知道自己困苦、可怜、贫穷、瞎眼、赤身露体。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 16:15; 彼得前书 1:7; 以赛亚书 55:1"> 我劝你向我买精炼的金子，使你真正富有。你还要向我买白衣穿在身上，好遮盖你赤身露体的羞辱。你还要向我买眼药抹眼睛，使你能看见。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前书 11:32; 希伯来书 12:5–11"> 凡我所爱的，我都会责备、管教。因此，你要热心起来，也要悔改。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:36–37; 启示录 19:9; 约翰福音 14:21–23"> 看啊！我站在门外敲门，若有谁闻声开门，我必进去，我与他，他与我，一同坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:12; 马太福音 19:28; 启示录 2:26–27"> 我必让得胜者与我一同坐在我的宝座上，正如我得胜后与我父一同坐在祂的宝座上一样。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 2:7; 启示录 2:11; 启示录 2:17"> “‘圣灵对各教会所说的话，凡有耳朵的都应当听。’”</span>
</div>
</div>

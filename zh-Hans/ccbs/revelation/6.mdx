## 羔羊揭开前六印

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 6:5; 启示录 5:1; 启示录 6:7"> 然后，我看见羔羊揭开七印中的第一印，那时我听见四个活物中的一个用如雷的声音说：“来！”</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 6:3–8; 撒迦利亚书 1:8; 诗篇 45:3–5"> 我便观看，见有一匹白马，马上的骑士拿着弓，他接受了赐给他的冠冕后，便四处征战，战无不胜。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 4:7; 启示录 6:1"> 羔羊揭开第二印时，我听见第二个活物说：“来！”</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 6:2; 马太福音 10:34; 启示录 13:10"> 这次出现了一匹红马，马上的骑士获得权柄，要夺取地上的和平，使人类互相厮杀。他还获得一把大刀。</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 6:2; 以西结书 4:16; 撒迦利亚书 6:6"> 羔羊揭开第三印的时候，我听见第三个活物说：“来！”我便观看，见有一匹黑马，马上的骑士手里拿着天平。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 9:4; 启示录 4:6; 启示录 7:3"> 我又听见四个活物中好像有声音说：“一升小麦值一个银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一个银币相当于一天的工钱。">a</a></sup>，三升大麦也值一个银币，油和酒都不要糟蹋。”</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 4:7; 启示录 6:3; 启示录 6:1"> 羔羊揭开第四印的时候，我听到第四个活物说：“来！”</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿书 13:14; 耶利米书 15:2–3; 启示录 1:18"> 我便观看，见有一匹浅灰色的马，马上骑士的名字叫死亡，阴间紧跟在他后面。他们得到权柄可以用刀剑、饥荒、瘟疫和野兽消灭地上四分之一的人。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 20:4; 约翰福音 16:2; 启示录 1:9"> 羔羊揭开第五印的时候，我看到祭坛下有许多灵魂，都是为传扬上帝的道、为祂做见证而被杀的。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 19:2; 诗篇 9:12; 启示录 16:5–7"> 他们大声喊道：“圣洁真实的主宰啊，你还要等多久才审判地上那些屠杀我们的人，为我们申冤呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 14:13; 启示录 7:9; 启示录 3:4–5"> 这时有白袍赐给他们每个人，有声音告诉他们要再稍候片刻，直到和他们同做奴仆、同被杀害的弟兄姊妹的数目满了为止。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 24:29; 约珥书 2:10; 使徒行传 2:19–20"> 羔羊揭开第六印的时候，我看见大地震发生了，太阳变得像黑毛布一样黑，整个月亮变成血红色，</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 34:4; 马太福音 24:29; 启示录 9:1"> 天上的星辰都坠落到地上，好像未成熟的无花果被狂风从树上吹落一般。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 34:4; 启示录 16:20; 彼得后书 3:10"> 天空也像书卷被卷起来，所有的山岭和海岛都被挪离原位。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 2:19; 以赛亚书 2:21; 以赛亚书 24:21–22"> 地上的君王、显要、将领、富豪、权贵、一切奴隶和自由人都躲藏在山洞里和岩穴间。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:30; 何西阿书 10:8; 启示录 4:2"> 他们哀求群山和岩石，说：“倒下来遮盖我们吧，我们好躲避宝座上的那位和羔羊的烈怒！</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 3:2; 约珥书 2:11; 诗篇 76:7"> 因为祂们发烈怒的大日子到了，谁能站得住呢？”</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="西番雅书 3:8; 耶利米书 10:25; 启示录 15:1"> 我听见殿中有宏亮的声音对七位天使说：“去将那盛满上帝烈怒的七个碗倾倒在地上。”</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 8:7; 启示录 16:11; 启示录 13:15–18"> 第一位天使去将碗倒在了地上，那些有怪兽的印记、敬拜兽像的人身上长出可怕的毒疮。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:17–21; 启示录 8:8–9; 启示录 11:6"> 第二位天使将碗倒在了海洋里，海水变得像死人的血，海中的活物都死光了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 7:17–20; 启示录 8:10–11; 何西阿书 13:15"> 第三位天使将碗倒在了江河与水泉里，水就变成了血。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:8; 启示录 11:17; 启示录 1:4"> 我听见掌管众水的天使说：<br /><span className="pl pl-1">“昔在今在的圣者啊！</span><br /><span className="pl pl-1">你是公义的，</span><br /><span className="pl pl-1">因为你施行了审判。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 49:26; 启示录 11:18; 启示录 6:10–11"> <span className="pl pl-1">他们流了众圣徒和先知们的血，</span><br /><span className="pl pl-1">所以你使他们喝血，</span><br /><span className="pl pl-1">这正是他们应得的报应。”</span></span>
<span className="v" id="v7" data-v="7" data-xref="启示录 19:2; 启示录 6:9; 启示录 15:3–4"> 我又听见从祭坛发出的声音说：<br /><span className="pl pl-1">“是的，全能的主上帝，</span><br /><span className="pl pl-1">你的判决真实公义。”</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:20; 启示录 14:18; 约拿书 4:8"> 第四位天使将碗倒在太阳上，使太阳可以用它的火炙烤世人。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:21; 启示录 16:21; 启示录 11:13"> 世人被高温炙烤，就亵渎掌管这些灾祸的上帝的名，他们毫无悔意，不肯归荣耀给上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 9:2; 马太福音 8:12; 以赛亚书 8:21–22"> 第五位天使将碗倒在怪兽的座位上，它的国便被黑暗笼罩，它的国民痛苦不堪，咬自己的舌头。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:9; 启示录 16:2; 启示录 16:21"> 他们因为痛苦和毒疮就亵渎天上的上帝，不肯为自己的所作所为悔改。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 9:14; 耶利米书 51:36; 以赛亚书 44:27"> 第六位天使将碗倒在幼发拉底大河上，河水就干了，为东方各国的王预备了道路。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 19:20; 帖撒罗尼迦后书 2:9–11; 启示录 20:10"> 我又看见三个像青蛙一样的污鬼分别从巨龙、怪兽和假先知的口里跳出来。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 17:14; 提摩太前书 4:1; 启示录 20:8"> 它们都是鬼魔的灵，能行奇迹。它们到普天下召集各王，预备在全能上帝的大日子争战。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:2–3; 马太福音 24:42–43; 彼得后书 3:10"> “看啊！我来的时候像贼一样。那警醒等候，穿好衣裳的人有福了！他们不会赤身行走，在人前蒙羞。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 12:11; 士师记 5:19; 约珥书 3:9–14"> 三个污鬼把众王召集到一个希伯来话叫哈米吉多顿的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:30; 启示录 21:6; 以弗所书 6:12"> 第七位天使将碗倒在空中时，从殿里的宝座上传出响亮的声音说：“成了！”</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 12:1; 启示录 4:5; 启示录 11:19"> 随后雷电交加，伴随着巨响，还有空前剧烈的大地震。</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:5; 启示录 17:18; 启示录 18:21"> 巴比伦大城裂作三段，其他各国的城邑也都倒塌了。上帝并没有忘记巴比伦大城的罪恶，要把那杯盛满祂烈怒的酒给她喝。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:14; 启示录 20:11; 耶利米书 4:23–25"> 海岛都沉没了，山岭也都不见了，</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 11:19; 约书亚记 10:11; 启示录 16:9"> 又有四十公斤重的巨型冰雹从天而降，打在世人身上。世人因为可怕的雹灾，就亵渎上帝。</span>

## 两位见证人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 21:15; 以西结书 42:15–20; 撒迦利亚书 2:1–2"> 有一根像杖一样的量杆赐给我，并有声音吩咐我说：“起来，量一量上帝的殿和祭坛，并数点在殿里敬拜的人。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 12:6; 但以理书 7:25; 路加福音 21:24"> 你不用量圣殿的外院，因为这部分已经给了外族人，他们要践踏圣城四十二个月。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:6; 启示录 11:2; 申命记 19:15"> 我要赐权柄给我的两个见证人，他们将身穿麻衣，传道一千二百六十天。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 4:11–14; 撒迦利亚书 4:2–3; 耶利米书 11:16"> 这两位见证人就是竖立在世界之主面前的那两棵橄榄树和两座灯台。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亚书4:3、11、14。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 5:14; 列王纪下 1:10–12; 何西阿书 6:5"> 若有人要伤害他们，他们便从口中喷出火焰，烧灭敌人；若有人企图加害他们，必定会这样被杀。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 17:1; 路加福音 4:25; 诗篇 105:26–36"> 他们有权在传道期间使天关闭无雨，又有权变水为血，并随时用各种灾祸击打世界。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 13:7; 但以理书 8:23–24; 但以理书 7:25"> 当他们做完见证以后，从无底坑上来的兽要和他们交战，并战胜他们，把他们杀掉。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:14; 启示录 18:10; 启示录 18:21"> 他们便陈尸在大城的街上，这大城按寓意名叫所多玛，又名埃及，是他们的主被钉在十字架上的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 79:2–3; 启示录 17:15; 启示录 10:11"> 三天半之久，他们的尸体不得埋葬，各民族、各部落、各语言族群、各国家的人都观看他们的尸体。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 18:17; 启示录 3:10; 使徒行传 5:33"> 地上万民都兴高采烈，互送礼物，因为这两位先知曾使地上的人受苦。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 2:7; 罗马书 8:11; 罗马书 8:2"> 三天半过后，从上帝而来的生命之气进入二人里面，他们便站立起来。看见的人都害怕极了。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 4:1; 列王纪下 2:11; 使徒行传 1:9"> 接着他们听见天上有响亮的声音呼唤他们：“上这里来！”他们就在敌人的注视下驾云升上天去。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 14:7; 启示录 6:12; 约书亚记 7:19"> 就在那一刻，发生了强烈的地震，那座城的十分之一倒塌了，因地震死亡的共七千人，生还者都在恐惧中将荣耀归给天上的上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 8:13; 启示录 9:12; 启示录 15:1"> 第二样灾难过去了，第三样灾难又接踵而来！</span>
</div>
</div>

## 第七位天使吹号

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="但以理书 7:14; 启示录 12:10; 但以理书 7:27"> 第七位天使吹响了号角，天上有响亮的声音说：“世上的国度现在已经属于我们的主和祂所立的基督了。祂要做王，直到永永远远。”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 4:4; 启示录 4:10; 启示录 7:11"> 在上帝面前，坐在自己宝座上的二十四位长老都一同俯伏敬拜上帝，说：</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 1:8; 启示录 16:5; 启示录 4:8–9"> <span className="pl pl-1">“主啊！昔在、今在的全能上帝啊！</span><br /><span className="pl pl-1">我们感谢你，</span><br /><span className="pl pl-1">因你已执掌大权做王了。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="启示录 19:5; 启示录 20:12; 启示录 6:10–11"> <span className="pl pl-1">列国曾充满愤怒，</span><br /><span className="pl pl-1">现在你发烈怒的时候到了。</span><br /><span className="pl pl-1">时候已到，你要审判死人，</span><br /><span className="pl pl-1">你要赏赐你的奴仆、先知、圣徒</span><br /><span className="pl pl-1">和一切不论尊卑敬畏你名的人，</span><br /><span className="pl pl-1">你要毁灭那些毁坏世界的人。”</span></span>
<span className="v" id="v19" data-v="19" data-xref="启示录 16:21; 启示录 15:5–8; 以西结书 38:22"> 那时，天上上帝的圣殿敞开了，殿内的约柜清晰可见，又有闪电、巨响、雷鸣、地震和大冰雹。</span>
</div>

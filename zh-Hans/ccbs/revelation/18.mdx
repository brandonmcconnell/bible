## 巴比伦的下场

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 43:2; 路加福音 17:24; 帖撒罗尼迦后书 2:8"> 此后，我看见另一位执掌大权的天使从天而降，他的荣光照亮了大地。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:8; 耶利米书 51:37"> 他用强有力的声音喊道：<br /><span className="pl pl-1">“巴比伦大城倒塌了！倒塌了！</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书21:9。">a</a></sup><br /><span className="pl pl-1">她成了鬼魔的住处，</span><br /><span className="pl pl-1">各样污秽之灵的巢穴，</span><br /><span className="pl pl-1">各样污秽之鸟的老巢，</span><br /><span className="pl pl-1">各样污秽可憎之兽的老窝。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 14:8; 启示录 17:2; 启示录 18:9"> <span className="pl pl-1">因为列国都喝了她淫乱的烈酒。</span><br /><span className="pl pl-1">地上的君王与她通奸，</span><br /><span className="pl pl-1">地上的商人也因她穷奢极侈的生活而发了财。”</span></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 耶利米书 51:6"> 我听见天上又有一个声音说：<br /><span className="pl pl-1">“我的子民啊，离开那城，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶利米书51:45。">b</a></sup><br /><span className="pl pl-1">以免沾染她的罪恶，</span><br /><span className="pl pl-1">受她所受的灾祸。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="创世记 18:20–21; 以斯拉记 9:6; 启示录 16:19"> <span className="pl pl-1">因为她已经罪恶滔天，</span><br /><span className="pl pl-1">上帝没有忘记她的不义。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:29; 诗篇 137:8; 耶利米书 51:24"> <span className="pl pl-1">她怎样待人，</span><br /><span className="pl pl-1">也要怎样待她，</span><br /><span className="pl pl-1">要按她所做的加倍地报应她，</span><br /><span className="pl pl-1">用她调酒的杯加倍地调给她喝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 47:7–9; 西番雅书 2:15; 耶利米哀歌 1:1"> <span className="pl pl-1">她过去怎样自炫自耀、</span><br /><span className="pl pl-1">奢华荒淫，</span><br /><span className="pl pl-1">现在也要让她怎样痛苦哀伤。</span><br /><span className="pl pl-1">因为她心里说，</span><br /><span className="pl pl-1">‘我贵为女王，不是寡妇，</span><br /><span className="pl pl-1">绝不会经历哀伤。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书47:7、8。">c</a></sup><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 50:34; 耶利米书 50:31; 启示录 17:16"> <span className="pl pl-1">所以在一天之内，</span><br /><span className="pl pl-1">她的灾祸，就是死亡、</span><br /><span className="pl pl-1">哀伤和饥荒要同时临到她身上。</span><br /><span className="pl pl-1">她要被火烧尽，</span><br /><span className="pl pl-1">因为审判她的主上帝大有能力。</span></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:3; 启示录 18:3; 启示录 17:2"> “地上曾与她通奸、一同奢华享乐的君王目睹焚烧她的烟，必为她哭泣哀号。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:19; 启示录 18:8; 启示录 18:15–17"> 他们对她所受的灾祸充满恐惧，就远远地站着说，<br /><span className="pl pl-1">“‘雄伟坚固的巴比伦城啊，</span><br /><span className="pl pl-1">有祸了！有祸了！</span><br /><span className="pl pl-1">因为审判顷刻间临到你了。’</span></span>
<span className="v" id="v11" data-v="11" data-xref="启示录 18:3; 启示录 18:23; 以西结书 27:27–36"> “地上的商人也为她痛哭哀伤，因为再也没有人购买他们的货物了。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:4; 以西结书 27:5–25; 箴言 8:10–11"> 他们的金、银、宝石、珍珠、细麻布、紫布、丝绸、朱红色布、各种香木、象牙器具，贵重木材、铜、铁、大理石制品，</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 27:13; 阿摩司书 2:6; 彼得后书 2:3"> 以及肉桂、豆蔻、香料、香膏、乳香、酒、油、细面粉、小麦、牛、羊、马、车、仆婢和人口都没有人购买了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:6; 诗篇 106:14; 路加福音 16:25"> 他们呼喊，‘你贪爱的美物已离你而去了，一切珍馐美味和奢华之物都消失殆尽，无影无踪。’</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 18:3; 使徒行传 19:24–27; 以西结书 27:31"> “靠贩卖这些货物给她而致富的商人对她所受的灾祸充满恐惧，就站在远处为她哀伤哭号，</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:4; 路加福音 16:19–31; 启示录 18:10–11"> 说，‘身穿紫色和朱红色细麻布衣服，并用黄金、宝石、珍珠为装饰的大城啊，有祸了！有祸了！</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 27:27–36; 启示录 17:16; 以赛亚书 23:14"> 因为顷刻间你这一切的繁华都化为乌有了。’所有船主、船客、水手及靠海为生的人都远远地站着，</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 13:4; 以西结书 27:30–32; 启示录 18:9–10"> 看见烧她的烟，就高喊，‘有哪一座城能与这座大城相比呢？’</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:10; 约书亚记 7:6; 以西结书 27:30"> 他们又把尘土撒在头上，哀伤哭泣，高喊，<br /><span className="pl pl-1">“‘这大城啊，有祸了！有祸了！</span><br /><span className="pl pl-1">所有经营航运的都因她的奢华而发了财，</span><br /><span className="pl pl-1">可是顷刻间她却沦为废墟了！’</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:10; 启示录 19:1–3; 路加福音 18:7–8"> <span className="pl pl-1">上天啊，</span><br /><span className="pl pl-1">众圣徒、众使徒和众先知啊，</span><br /><span className="pl pl-1">为她的下场欢喜吧！</span><br /><span className="pl pl-1">因为上帝已经对她下了判决，</span><br /><span className="pl pl-1">为你们申冤了。”</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 51:63–64; 以西结书 26:21; 启示录 5:2"> 这时，有一位大能天使举起一块像大磨石的石头扔进海里，说：<br /><span className="pl pl-1">“巴比伦大城也必这样被用力扔下去，</span><br /><span className="pl pl-1">消失得无影无踪。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 26:13; 耶利米书 25:10; 耶利米书 7:34"> <span className="pl pl-1">在你那里，</span><br /><span className="pl pl-1">再也听不见弹琴作乐、</span><br /><span className="pl pl-1">弄笛吹号的声音了，</span><br /><span className="pl pl-1">再也找不到能工巧匠了，</span><br /><span className="pl pl-1">再也听不到推磨的声音了，</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="启示录 18:3; 以赛亚书 23:8; 那鸿书 3:4"> <span className="pl pl-1">再也看不到闪耀的灯光了，</span><br /><span className="pl pl-1">再也听不见新郎新娘的声音了。</span><br /><span className="pl pl-1">因为你的商人在世上显赫一时，</span><br /><span className="pl pl-1">万国都被你的邪术迷惑，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="启示录 17:6; 启示录 16:6; 耶利米书 51:49"> <span className="pl pl-1">你的城内流了众先知、</span><br /><span className="pl pl-1">众圣徒和地上一切被杀之人的血。”</span></span>

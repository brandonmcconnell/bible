<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:10; 罗马书 10:7; 启示录 9:2"> 第五位天使吹号的时候，我见有一颗星从天上坠落到地上，有无底坑的钥匙赐给它。</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 2:10; 创世记 19:28; 约珥书 2:2"> 它打开无底坑时，浓烟从坑里冒出来，好像大火炉的烟一样，太阳和天空都变得昏暗了。</span>
<span className="v" id="v3" data-v="3" data-xref="约珥书 1:4; 启示录 9:5; 约珥书 2:25"> 有蝗虫从烟里飞出来，落到地上，有地上蝎子的能力赐给它们。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 7:2–4; 以西结书 9:4; 启示录 14:1"> 它们奉命不得毁坏地上的青草、树木和其他植物，只伤害额上没有上帝印记的人，</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 9:10; 约伯记 2:6; 启示录 9:3"> 但不可杀死他们，只折磨他们五个月。他们受的折磨就像被蝎子蛰到一样。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 23:30; 耶利米书 8:3; 启示录 6:16"> 那时候，人求死，却求不到；想死，死却躲避他们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:8; 那鸿书 3:17; 约珥书 2:4–5"> 那些蝗虫好像预备出征的战马一样，头上好像戴了金冠，面孔好像人脸，</span>
<span className="v" id="v8" data-v="8" data-xref="约珥书 1:6; 哥林多前书 11:14–15; 彼得前书 3:3"> 毛发好像女人的头发，牙齿好像狮子的牙，</span>
<span className="v" id="v9" data-v="9" data-xref="约珥书 2:5–8; 那鸿书 2:4–5; 约伯记 39:25"> 胸前有甲，如同铁甲，鼓动翅膀时声音如同许多战马战车奔赴战场。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 9:5; 启示录 9:3; 启示录 9:19"> 它们像蝎子一样有带毒钩的尾巴，能够折磨人五个月。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 26:6; 启示录 9:1–2; 以弗所书 2:2"> 它们的王是无底坑的天使，希伯来文名叫亚巴顿，希腊文名叫亚玻伦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="两个名字的意思都是“毁灭者”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="启示录 11:14; 启示录 8:13–2; 启示录 9:13–21"> 第一样灾祸过去了，另外两样接踵而来。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 8:3–5; 出埃及记 30:2–3; 启示录 9:1"> 第六位天使吹号的时候，我听见从上帝面前的金祭坛的四角传出一个声音，</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 16:12; 启示录 9:15; 撒母耳记下 8:3"> 对刚才吹号的第六位天使说：“释放那捆绑在幼发拉底大河的四位天使！”</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 9:18; 启示录 8:7; 启示录 8:9"> 那四位天使就被释放了，他们为了此年、此月、此日、此刻已经预备好了，要杀掉人类的三分之一。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:4; 诗篇 68:17; 但以理书 7:10"> 我听见他们共有二亿骑兵。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 9:18; 启示录 14:10; 历代志上 12:8"> 我在异象中看见了马和骑士。骑士胸甲的颜色像火焰、紫玛瑙和硫磺。马的头像狮子的头，口中喷出火、烟和硫磺。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 9:17; 启示录 9:15"> 马口中喷出的这三样灾害杀死了世上三分之一的人口。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:15; 启示录 9:10; 以弗所书 4:14"> 这些马的杀伤力不只在口，也在尾巴。它们的尾巴像蛇，有头能咬伤人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理书 5:23; 申命记 31:29; 提摩太前书 4:1"> 其余没有被这些灾害所杀的人仍怙恶不悛，继续拜鬼魔和那些用金、银、铜、石、木所造，不能看、不能听、不能行走的偶像。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:8; 哥林多后书 12:21; 启示录 17:5"> 他们也不肯为自己所犯的凶杀、邪术、淫乱和偷盗悔改。</span>
</div>
</div>

## 两只怪兽

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="启示录 12:3; 启示录 17:3; 但以理书 7:23–25"> 我又看见一只怪兽从海中上来，有七头十角，每只角上都戴着一个冠冕，每个头上都写着亵渎上帝的名号。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 7:4–7; 彼得前书 5:8; 启示录 17:12"> 它看起来像豹，脚像熊的脚，口像狮子的口。巨龙将自己的能力、王位和大权柄都交给了怪兽。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:8; 启示录 13:14; 启示录 17:17"> 我看见怪兽的一个头似乎受了致命伤，这伤却复原了。全世界的人都惊奇地跟从了它。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 13:2; 启示录 18:18; 启示录 13:15"> 他们拜巨龙，因为巨龙将自己的权柄给了怪兽。他们又拜怪兽，说：“谁比得上这兽呢？谁能与它对抗呢？”</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 7:8; 但以理书 7:25; 但以理书 11:36"> 巨龙又赐给怪兽说狂妄、亵渎话的口，并给它权柄可以任意妄为四十二个月。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:34; 希伯来书 9:24; 启示录 12:12"> 怪兽开口亵渎上帝、祂的名、祂的居所和一切居住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:21; 启示录 11:7; 但以理书 7:25"> 它又获准去攻打圣徒，征服他们，并得到权柄制服各部落、各民族、各语言族群、各国家。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 1:19–20; 以弗所书 1:4; 马太福音 25:34"> 凡住在地上、自创世以来名字没有记在被杀羔羊的生命册上的人，都会拜怪兽。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:7; 启示录 2:17; 启示录 2:11"> <span className="pl pl-1">凡有耳朵的都应当听。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 15:2; 以赛亚书 33:1; 启示录 14:12"> <span className="pl pl-1">该被掳的人必被掳，</span><br /><span className="pl pl-1">该被刀杀的必被刀杀。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶利米书15:2。">a</a></sup>因此，圣徒需要坚忍和信心。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 7:8; 哥林多后书 11:13–15; 马太福音 7:15"> 我又看见另一只怪兽从地里上来，它的两只角像羔羊的角，说话却像龙，</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:10–11; 启示录 14:11; 启示录 14:9"> 在头一只怪兽面前行使头一只怪兽的一切权柄。它使世上的人拜曾受了致命伤但已复原的头一只怪兽，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:24; 启示录 19:20; 帖撒罗尼迦后书 2:9–10"> 又行大奇迹，当众叫火从天降到地上。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 12:9; 启示录 19:20; 启示录 13:8"> 它获准在头一只怪兽面前行奇迹，借此迷惑普世的人，并吩咐他们为受了刀伤却仍然活着的头一只怪兽塑像。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 20:4; 启示录 19:20; 但以理书 3:3–6"> 它又获准给怪兽的塑像生命气息，使它不但能说话，还能使所有不拜那像的人遭害。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 20:4; 启示录 19:20; 以西结书 9:4"> 它又强迫所有的人，不论尊卑、贫富、自由人或奴隶，都在右手或额上接受印记。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 15:2; 启示录 13:16; 启示录 14:11"> 凡没有盖上怪兽印记的，就是没有怪兽的名字或代号的，都不能买卖。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 15:2; 启示录 17:9; 启示录 21:17"> 这里需要智慧：明哲可以计算那怪兽的代号，因为那是一个人的代号，是六百六十六。</span>
</div>

## 耶和华命令百姓重建圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 2:2; 以斯拉记 3:8; 以斯拉记 3:2"> 大流士王执政第二年六月一日，耶和华借着先知哈该对撒拉铁的儿子犹大省长所罗巴伯和约撒答的儿子大祭司约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:23–2; 尼希米记 4:10; 传道书 11:4"> “万军之耶和华说，‘这些百姓说，重建耶和华殿的时候还没到。’”</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 5:1; 撒迦利亚书 1:1"> 因此，耶和华借先知哈该说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 7:2; 诗篇 132:3–5; 腓立比书 2:21"> “这殿还荒废时，你们却住在华丽的房子里吗？</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 3:40; 哥林多后书 13:5; 哈该书 1:7"> 万军之耶和华说，你们要认真反省自己的行为。</span>
<span className="v" id="v6" data-v="6" data-xref="哈该书 1:9; 申命记 28:38–40; 何西阿书 4:10"> 你们种多收少，吃不饱，喝不足，穿不暖，挣来的工钱却放在破漏口袋中。”</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 119:59–60; 哈该书 1:5; 腓立比书 3:1"> 万军之耶和华说：“你们要认真反省自己的行为。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 132:13–14; 历代志下 7:16; 哈该书 2:7"> 你们要上山伐木，重建这殿，好让我欢喜并得到尊崇。这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="哈该书 1:4; 哈该书 2:16–17; 哈该书 1:6"> 你们盼望丰收，结果收的很少；你们把收成带回家，我却把它们吹走。这是什么缘故？万军之耶和华告诉你们，‘因为你们都忙于建自家的房子，任由我的殿荒废。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:35; 利未记 26:19; 申命记 28:23–24"> 所以，天不降露，地无出产。</span>
<span className="v" id="v11" data-v="11" data-xref="哈该书 2:17; 申命记 28:22; 列王纪下 8:1"> 我让旱灾临到大地、群山、五谷、葡萄、橄榄等地里的出产和人畜，以及你们所劳碌的一切。’”</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 50:10; 以斯拉记 5:2; 哈该书 1:14"> 撒拉铁的儿子犹大省长所罗巴伯、约撒答的儿子大祭司约书亚和所有的余民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“余民”指“从流亡之地归回的人”。">a</a></sup>，听到他们的上帝耶和华派先知哈该所讲的话，都顺服耶和华的话。百姓都敬畏耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:2; 马太福音 28:20; 玛拉基书 3:1"> 耶和华的使者哈该向百姓传达耶和华的话，说：“耶和华说，‘我与你们同在。’”</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 36:22; 希伯来书 13:21; 哈该书 2:21"> 耶和华感动撒拉铁的儿子犹大省长所罗巴伯、约撒答的儿子大祭司约书亚和所有的余民，他们就动工建造他们的上帝——万军之耶和华的殿，</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 1:1; 哈该书 2:20; 哈该书 2:1"> 时值大流士王执政第二年六月二十四日。</span>
</div>

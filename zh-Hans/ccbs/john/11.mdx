## 拉撒路病死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 10:38–42; 约翰福音 12:17; 列王纪下 20:1–12"> 伯大尼村有个名叫拉撒路的人病倒了。伯大尼是玛丽亚和她姐姐玛大居住的村庄。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 12:3; 马可福音 14:3; 马太福音 26:6–7"> 就是这个玛丽亚后来用香膏抹主，又用自己的头发擦干祂的脚，患病的拉撒路是她的弟弟。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:5; 启示录 3:19; 提摩太后书 4:20"> 她们两姊妹托人去告诉耶稣，说：“主啊，你所爱的人病了！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:40; 约翰福音 9:3; 彼得前书 4:14"> 耶稣听见后，说：“这病不至于死，而是为了上帝的荣耀，使祂的儿子借此得到荣耀。”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:9–13; 约翰福音 16:27; 约翰福音 17:26"> 耶稣一向爱玛大、她妹妹和拉撒路，</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 30:18; 以赛亚书 55:8–9; 创世记 45:1–5"> 可是祂听到拉撒路有病的消息后，仍在原地逗留了两天，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 10:40–42; 路加福音 9:51; 使徒行传 20:22–24"> 然后才对门徒说：“我们回犹太吧！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:31; 约翰福音 8:59; 使徒行传 21:12–13"> 门徒说：“老师，犹太人近来想拿石头打你，你还要去那里吗？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 9:4; 约翰福音 12:35; 耶利米书 31:9"> 耶稣说：“白天不是有十二个小时吗？人在白天走路，不会跌倒，因为他看得见这世上的光。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:10–11; 箴言 4:18–19; 耶利米书 13:16"> 人在夜间走路，才会跌倒，因为没有光。”</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 12:2; 约翰福音 11:13; 约翰福音 11:43–44"> 接着耶稣又说：“我们的朋友拉撒路已经睡了，我去叫醒他。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 门徒说：“主啊，他如果睡了，肯定会好的。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:24"> 其实耶稣是指他已经死了，门徒却以为他真的睡了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 16:25; 约翰福音 16:29; 约翰福音 10:24"> 于是，耶稣清楚地对他们说：“拉撒路死了。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 2:10; 约翰福音 14:10–11; 以赛亚书 54:15"> 为了你们的缘故，我很高兴自己不在那里，好叫你们信我。现在我们可以去了。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 13:37; 马太福音 10:3; 约翰福音 21:2"> 绰号“双胞胎”的多马对其他门徒说：“我们也去跟祂一块儿死吧。”</span>
</div>
</div>

## 拉撒路死而复活

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 11:39; 何西阿书 6:2; 使徒行传 2:27–31"> 耶稣到了伯大尼，得知拉撒路已经在坟墓里四天了。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 14:20; 启示录 21:16; 约翰福音 6:19"> 伯大尼离耶路撒冷不远，大约只有三公里的路，</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:11; 约翰福音 11:31; 帖撒罗尼迦前书 5:11"> 很多犹太人来看望玛大和玛丽亚，为她们兄弟的事来安慰她们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:38–42; 帖撒罗尼迦前书 4:17; 马太福音 25:1"> 玛大听说耶稣来了，就去迎接祂，玛丽亚却仍然坐在家里。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:32; 列王纪上 17:18; 马太福音 9:18"> 玛大对耶稣说：“主啊，你如果早在这里，我弟弟就不会死了。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 9:31; 约翰福音 11:41–42; 马太福音 28:18"> 就是现在我也知道你无论向上帝求什么，上帝必定赐给你。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 11:43–44"> 耶稣说：“你弟弟必定复活。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理书 12:2–3; 使徒行传 24:15; 约翰福音 5:28–29"> 玛大说：“我知道，在末日复活的时候，他必复活。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 4:14; 约翰福音 3:36; 约翰一书 5:11–12"> 耶稣说：“我是复活，我是生命。信我的人虽然死了，也必复活。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 10:28; 约翰福音 5:24; 罗马书 8:13"> 凡活着信我的人必永远不死。你相信吗？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:16; 约翰福音 6:69; 约翰福音 6:14"> 玛大说：“主啊，我信！我相信你是来到世界的基督，是上帝的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 11:20; 约翰福音 13:13; 马可福音 10:49"> 玛大说完了，就回去悄悄地告诉她妹妹玛丽亚：“老师来了，祂叫你去。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 15:23; 诗篇 27:8; 雅歌 3:1–4"> 玛丽亚听了，急忙起来到耶稣那里。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 11:20"> 那时，耶稣还没有进村子，仍在玛大迎接祂的地方。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 11:19; 创世记 37:35; 撒母耳记下 12:16–18"> 那些在家里安慰玛丽亚的犹太人，见她匆匆忙忙地起来出去了，以为她要去坟墓那里哭，就跟着出去。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约翰福音 11:21; 路加福音 17:16; 路加福音 5:8"> 玛丽亚来到耶稣那里，俯伏在祂脚前说：“主啊，你如果早在这里，我弟弟就不会死了。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:38; 约翰福音 12:27; 马可福音 3:5"> 耶稣看见她和陪她来的犹太人都在哭，心中非常激愤和难过，</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 15:47; 马太福音 28:6; 约翰福音 1:39"> 便问：“你们把他葬在哪里了？”<br />他们答道：“主啊，你来看。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 19:41; 希伯来书 4:15; 约翰福音 11:33"> 耶稣哭了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约翰福音 11:3; 约翰一书 3:1; 约翰一书 4:9–10"> 犹太人说：“你看！祂多么爱拉撒路啊！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 9:6–7; 约翰福音 11:32; 路加福音 23:39"> 其中也有人说：“祂既然能医治瞎眼的人，难道不能叫这个人不死吗？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:33; 路加福音 24:2; 马太福音 27:60"> 耶稣又非常激愤地来到坟墓前。那坟墓是个洞，洞口堵着一块大石头。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 11:17; 马可福音 16:3; 诗篇 49:7"> 耶稣说：“把石头挪开。”<br />死者的姐姐玛大对祂说：“主啊，他死了四天了，肯定臭了。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 11:4; 约翰福音 11:23–26; 罗马书 4:17–25"> 耶稣说：“我不是跟你说过，只要你信，就会看见上帝的荣耀吗？”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="马太福音 11:25; 约翰福音 17:1; 诗篇 123:1"> 于是，他们把石头挪开，耶稣望着天说：“父啊，我感谢你，因为你已垂听了我的祷告，</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 3:17; 约翰福音 17:21; 约翰一书 4:14"> 我知道你常常垂听我的祷告。我这样说是为了周围站着的众人，好叫他们相信是你差我来的。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="列王纪下 4:33–36; 使徒行传 9:40; 使徒行传 9:34"> 说完，就大声呼喊：“拉撒路，出来！”</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 5:25; 约翰福音 20:7; 约翰福音 11:25–26"> 那死者就出来了，手脚都缠着布条，脸上也包着布。<br />耶稣对他们说：“给他解开，让他走！”</span>
</div>
</div>

## 谋害耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 2:23; 约翰福音 11:19; 约翰福音 10:41"> 许多来看望玛丽亚的犹太人看见耶稣的作为，就信了祂，</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 9:13; 使徒行传 5:25; 约翰福音 12:37"> 但也有些人去见法利赛人，把耶稣所行的事告诉他们。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 26:3; 约翰福音 12:19; 使徒行传 4:5–6"> 祭司长和法利赛人便召开公会会议，说：“这人行了许多神迹，我们该怎么办呢？</span>
<span className="v" id="v48" data-v="48" data-xref="帖撒罗尼迦前书 2:15–16; 马太福音 23:35–38; 马太福音 27:25"> 如果让祂这样继续下去，所有的人都会信祂，那时罗马人一定会来夺取我们的圣地，掳掠我们的人民。”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马太福音 26:3; 约翰福音 11:51; 约翰福音 18:13–14"> 那年担任大祭司的该亚法对他们说：“你们什么都不懂！</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 18:14; 路加福音 24:46; 罗马书 3:8"> 你们没有认识到，对你们而言，与其整个民族灭亡，不如一人替众人死。”</span>
<span className="v" id="v51" data-v="51" data-xref="但以理书 9:26; 哥林多后书 5:21; 出埃及记 28:30"> 其实这句话不是出于他自己，只因那年他是大祭司，上帝借着他预言耶稣将要替犹太民族死。</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 10:16; 以赛亚书 49:6; 约翰一书 2:2"> 祂不单是要替犹太民族死，也要把散居在各处的上帝的儿女聚集在一起。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="使徒行传 5:33; 使徒行传 9:23; 马可福音 14:1"> 从那天起，他们就计划要杀害耶稣，</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 7:1; 约翰福音 7:4; 历代志下 13:19"> 所以耶稣不再公开地在犹太人中间露面。祂离开那里，前往靠近旷野的地方，到了以法莲城，就和门徒住下来。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="历代志下 30:17–20; 希伯来书 9:13–14; 约翰福音 6:4"> 犹太人的逾越节快到了，有很多人从乡下上耶路撒冷，预备在过节前洁净自己。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 7:11; 约翰福音 11:7–8"> 他们四处寻找耶稣，又彼此在圣殿里谈论：“你们怎么想？祂不会来过节吧？”</span>
<span className="v" id="v57" data-v="57" data-xref="约翰福音 9:22; 约翰福音 8:59; 约翰福音 5:16–18"> 当时祭司长和法利赛人早已下令，任何人知道耶稣在哪里，都要报告，他们好去抓祂。</span>
</div>
</div>

</div>

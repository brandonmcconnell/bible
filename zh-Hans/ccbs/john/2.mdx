## 变水为酒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:46; 箴言 31:10–12; 约翰福音 21:2"> 第三天，有人在加利利的迦拿举办婚宴，耶稣的母亲在场。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:40–49; 马太福音 10:40–42; 哥林多前书 7:39"> 耶稣和门徒也应邀赴宴。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 104:15; 腓立比书 4:6; 以赛亚书 24:11"> 酒喝完了，耶稣的母亲就对祂说：“他们没有酒了。”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:6; 约翰福音 13:1; 约翰福音 7:30"> 耶稣说：“女士，何必把我牵扯进去？我的时候还没有到。”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:14; 创世记 6:22; 希伯来书 11:8"> 祂母亲对仆人说：“祂叫你们做什么，你们就做什么。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:25; 希伯来书 9:10; 以弗所书 5:26"> 那里有六口犹太人用来行洁净礼仪的石缸，每口可以盛约一百升水。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 4:2–6; 约翰福音 2:5; 约翰福音 2:3"> 耶稣对仆人说：“把缸倒满水！”他们就往缸里倒水，一直满到缸口。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 2:9; 箴言 3:5–6; 罗马书 13:7"> 耶稣又说：“现在舀些出来，送给宴席总管。”他们就送了去。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 4:46; 约翰福音 7:17; 诗篇 119:100"> 那些仆人知道酒是怎么来的，宴席总管并不知道。他尝过那水变的酒后，便把新郎叫来，</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 7:16–17; 箴言 9:1–6; 路加福音 16:25"> 对他说：“人们都是先拿好酒款待客人，等客人喝够了，再把次等的拿出来，你却把好酒留到现在！”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:30–31; 约翰福音 1:14; 约翰福音 3:2"> 这是耶稣第一次行神迹，是在加利利的迦拿行的，彰显了祂的荣耀，门徒都信了祂。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:46; 马太福音 13:55–56; 马可福音 6:3"> 这事以后，耶稣和祂的母亲、弟弟及门徒一起去迦百农住了几天。</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:41; 约翰福音 11:55; 约翰福音 2:23"> 犹太人的逾越节快到了，耶稣便上耶路撒冷去。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 19:45–46; 马可福音 11:15; 马可福音 11:17"> 祂看见圣殿外院有人在卖牛羊和鸽子，还有人坐在那里兑换银币，</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:6; 撒迦利亚书 4:6; 哥林多后书 10:4"> 就用绳子做成鞭子把牛羊赶出去，抛散钱商的银币，推翻他们的桌子，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:13; 耶利米书 7:11; 马可福音 11:17"> 又对卖鸽子的说：“把这些东西拿出去！不要把我父的殿当作市场。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:9; 诗篇 119:139"> 祂的门徒想起圣经上说：“我为你的殿心急如焚。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇69:9。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 21:23; 马可福音 8:11; 马可福音 11:27–28"> 当时，犹太人质问祂：“你能显什么神迹向我们证明你有权柄这样做？”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:58; 马可福音 15:29; 马太福音 27:40"> 耶稣回答说：“你们拆毁这座殿，我三天之内就会把它重建起来。”</span>
<span className="v" id="v20" data-v="20"> 他们说：“这座殿用了四十六年才建成，你三天之内就要把它重建起来吗？”</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 以弗所书 2:20–22"> 其实耶稣说的殿是指自己的身体，</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 12:16; 约翰福音 16:4; 路加福音 24:7–8"> 等到祂从死里复活以后，祂的门徒想起这句话，就相信了圣经和耶稣所传的道。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 7:31; 路加福音 8:13; 约翰福音 6:14"> 耶稣在耶路撒冷过逾越节期间，许多人看见祂行的神迹，就信了祂。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:64; 希伯来书 4:13; 使徒行传 1:24"> 耶稣却不信任他们，因为祂洞悉万人。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 13:11; 马太福音 9:4; 约翰福音 6:64"> 不用别人告诉祂，祂也深知人的内心。</span>
</div>

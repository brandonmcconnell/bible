## 真葡萄树

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 2:21; 以赛亚书 27:2–3; 哥林多前书 3:9"> “我是真葡萄树，我父是栽培的人。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 3:10; 希伯来书 12:10–11; 马太福音 15:13"> 属于我的枝子如果不结果子，祂就把它剪掉；如果结果子，祂便修剪它，让它结更多果子。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 17:17; 以弗所书 5:26; 彼得前书 1:22"> 因着我对你们讲的道，你们已经洁净了。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:6; 加拉太书 2:20; 约翰福音 8:31"> 你们要常在我里面，我就常在你们里面。枝子若离开葡萄树，就不能结果子。同样，你们若不常在我里面，也不能结果子。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:13; 歌罗西书 1:10; 约翰福音 15:16"> “我是葡萄树，你们是枝子。常在我里面的，我也常在他里面，他就会多结果子，因为你们离了我什么都不能做。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:19; 希伯来书 6:7–8; 马太福音 13:41"> 不常在我里面的人就像扔在外面枯干的枝子，最后只有被人拾起来扔进火里烧掉。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:4; 约翰一书 5:14; 约翰福音 14:13"> 你们若常在我里面，我的话也常在你们里面，无论你们求什么，都会得到应允。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:31; 马太福音 5:16; 腓立比书 1:11"> 你们多结果子，证明自己是我的门徒，就会给我父带来荣耀。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:23–24; 约翰福音 17:26; 约翰一书 2:28"> 父怎样爱我，我也怎样爱你们。你们要常在我的爱中。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 3:21–24"> 你们若遵守我的命令，就必常在我的爱中，正如我遵守了父的命令，常在父的爱中一样。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 17:13; 罗马书 15:13; 约翰福音 16:24"> “我把这些事告诉你们，是要叫你们心里有我的喜乐，让你们的喜乐满溢。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:21; 彼得前书 4:8; 约翰福音 13:34"> 你们要彼此相爱，像我爱你们一样，这就是我的命令。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 10:11; 以弗所书 5:2; 罗马书 5:6–8"> 为朋友舍命是最伟大的爱了。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 12:50; 约翰一书 5:3; 雅各书 2:23"> 你们如果照我的吩咐去做，就是我的朋友。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 25:14; 哥林多前书 2:9–12; 马太福音 13:11"> 我不再称你们为奴仆，因为奴仆不知道主人的事。我称你们为朋友，因为我把从父那里听见的一切都告诉了你们。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 15:19; 耶利米书 1:5–7; 以弗所书 2:10"> 不是你们拣选了我，而是我拣选了你们，并且派你们出去结长存的果子。这样，你们奉我的名无论向父求什么，祂都会赐给你们。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:12; 约翰一书 3:14–17; 彼得前书 2:17"> 我把这些事吩咐你们，是要叫你们彼此相爱。</span>
</div>
</div>

## 被世人憎恶

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 3:13; 约翰福音 7:7; 马可福音 13:13"> “如果世人恨你们，要知道，他们恨你们以前已经恨我了。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:4–5; 约翰福音 17:14–16; 以弗所书 1:4–11"> 如果你们属于这个世界，世人一定会爱你们。可是你们不属于这世界，我已经把你们从世上拣选出来，因此世人恨你们。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:12; 约翰福音 13:16; 马太福音 10:24"> 你们要记住我说的话，‘奴仆不能大过主人。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约翰福音13:16。">a</a></sup>他们如果迫害我，也必迫害你们；他们如果遵行我的话，也必遵行你们的话。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:22; 约翰福音 16:3; 马太福音 10:18"> 世人将因为我的名而这样对待你们，因为他们不认识差我来的那位。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 9:41; 雅各书 4:17; 使徒行传 17:30"> 我如果没有来教导他们，他们就没有罪了，但现在他们的罪无可推诿。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 8:40–42; 约翰二书 1:9; 约翰一书 2:23"> 恨我的，也恨我的父。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:36; 约翰福音 14:9; 约翰福音 7:31"> 我如果没有在他们当中行过空前的神迹，他们就没有罪了。然而，他们亲眼看见了，却还是恨我和我的父。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 109:3; 诗篇 69:4; 诗篇 35:19"> 这是要应验他们律法书上的话，‘他们无故地恨我。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇35:19；69:4。">b</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 16:13–15"> “我要从父那里为你们差护慰者来，祂就是从父而来的真理之灵。祂来了要为我做见证。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰一书 4:14; 约翰福音 21:24; 使徒行传 10:39–42"> 你们也要为我做见证，因为你们从开始就与我在一起。</span>
</div>

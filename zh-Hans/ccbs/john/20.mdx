## 耶稣复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:9; 马太福音 27:60; 约翰福音 19:25"> 周日清晨，天还未亮，抹大拉的玛丽亚就来到坟墓前，发现墓口的石头已经挪开了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:23; 约翰福音 20:13; 约翰福音 21:24"> 她赶快跑去告诉西门·彼得和耶稣所爱的那个门徒，说：“有人把主从坟墓里搬走了，不知放到哪里去了。”</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 彼得和那个门徒听了就出去，往坟墓那边跑。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:23; 哥林多后书 8:12; 哥林多前书 9:24"> 两个人一起跑，但那个门徒比彼得跑得快，所以先到了坟墓。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:40; 约翰福音 20:11; 约翰福音 11:44"> 他没有进去，只是探头往里看，看见细麻布还在那里。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:17; 约翰福音 21:7; 马太福音 16:15–16"> 西门·彼得随后也来了，他进到里边，看到细麻布放在那里，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 11:44"> 耶稣的裹头巾则卷着放在另一处，没有和细麻布放在一起。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:25; 约翰福音 20:4; 约翰福音 1:50"> 先到的那个门徒也进来了，看见这种情形就信了。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 16:10; 以赛亚书 25:8; 以赛亚书 53:10–12"> 因为他们还不明白圣经上有关耶稣必须从死里复活的话。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 7:53; 约翰福音 16:32"> 然后，他们各自回家去了。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:5"> 玛丽亚却站在坟墓外面哭泣，边哭边往坟墓里面看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 启示录 3:4; 马可福音 16:5–6"> 看见两个穿着白衣的天使，分别坐在原来安放耶稣遗体的头脚两端。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:15; 约翰福音 2:4; 撒母耳记上 1:8"> 天使对她说：“妇人，你为什么哭呢？” 她说：“有人把我的主搬走了，我不知道放在什么地方。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 约翰福音 21:4; 马太福音 28:9"> 说完，她转过身来，看见耶稣站在那里，但她不知道是耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 20:13; 约翰福音 18:7; 约翰福音 1:38"> 耶稣问她：“妇人，你为什么哭？你在找谁？” 玛丽亚还以为祂是园丁，就说：“先生，如果是你把祂搬走了，请告诉我放在哪里了，我好搬回来。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:3; 约翰福音 1:38; 使徒行传 10:3"> 耶稣说：“玛丽亚。” 玛丽亚转向祂用希伯来话说：“拉波尼！”拉波尼的意思是老师。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:28; 以弗所书 4:8–10; 加拉太书 4:6–7"> 耶稣说：“不要拉着我，我还没有升到父那里。你先去找我的众弟兄，告诉他们我要升天去见我的父，也是你们的父；去见我的上帝，也是你们的上帝。”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 马太福音 28:10; 约翰福音 20:1"> 抹大拉的玛丽亚就去向门徒报信，说：“我看见主了！”又把主对她说的话告诉门徒。</span>
</div>
</div>

## 向门徒显现

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 20:26; 约翰福音 14:27; 约翰福音 20:21"> 当晚，即周日晚上，门徒因为害怕犹太人，把房门都关上了。忽然，耶稣来了，站在他们当中，对他们说：“愿你们平安！”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 16:22; 约翰福音 16:20; 约翰福音 20:27"> 说完，祂把手和肋旁给他们看。门徒看见主，十分欢喜。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 17:18–19; 约翰福音 13:20; 约翰福音 3:17"> 耶稣又说：“愿你们平安！父怎样差遣我，我也照样差遣你们。”</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 33:4; 创世记 2:7; 使徒行传 8:15"> 然后祂向他们吹了一口气，说：“你们领受圣灵吧！</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 18:18; 马太福音 16:19; 马可福音 2:5–10"> 你们赦免谁的罪，谁的罪就得到赦免；你们不赦免谁的罪，谁的罪就得不到赦免。”</span>
</div>
</div>

## 向多马显现

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 11:16; 约翰福音 6:66–67; 希伯来书 10:25"> 耶稣显现的时候，十二个门徒中绰号“双胞胎”的多马不在场。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:30; 马可福音 16:11; 希伯来书 3:12"> 其他门徒告诉他：“我们看见主了！”可是多马说：“除非我亲眼看见祂手上的钉痕，用手摸到祂手上的钉痕和祂的肋旁，否则我决不信。”</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 20:19; 以赛亚书 54:10; 约翰福音 20:21"> 过了八天，门徒又聚在一起，多马也在，门都关着。突然耶稣来了，站在他们当中说：“愿你们平安！”</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 20:25; 约翰一书 1:1–2; 约翰福音 20:20"> 然后对多马说：“把你的指头放在我手上摸摸看，伸出手来摸摸我的肋旁。不要怀疑，要相信！”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:1; 以赛亚书 9:6; 以赛亚书 7:14"> 多马回答说：“我的主，我的上帝！”</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 1:8; 哥林多后书 5:7; 希伯来书 11:1"> 耶稣说：“你看见我才信，那些没有看见就信的人有福了。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:25; 提摩太后书 3:15–17; 罗马书 15:4"> 耶稣在门徒面前还行了许多神迹，只是没有记在这本书里。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:43; 约翰福音 3:15–16; 约翰一书 5:1"> 而记载这些事，是为了使你们相信耶稣就是基督，是上帝的儿子，并且使你们这些信祂的人可以靠祂的名得到生命。</span>
</div>

## 圣灵的工作

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:8; 马太福音 13:21; 马太福音 26:31–33"> “我把这些事告诉你们，以免你们背弃信仰。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:22; 使徒行传 26:9–11; 罗马书 10:2–3"> 人们将把你们赶出会堂，时候将到，杀害你们的人还以为是在事奉上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:21; 约翰福音 17:25; 约翰福音 8:55"> 他们这样做，是因为他们根本不认识父，也不认识我。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 14:29; 马可福音 13:23; 约翰福音 17:12–13"> 我把这些事提前告诉你们，是要叫你们到时候可以想起我曾跟你们讲过这些事。我以前没有告诉你们，那是因为我还跟你们在一起。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:36; 约翰福音 7:33; 约翰福音 16:28"> “现在我要去差我来的父那里，你们没有人问我去哪里。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:1; 约翰福音 16:20–22; 路加福音 24:17"> 因为我把这些事告诉了你们，你们心里充满了忧愁。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 15:26"> 然而，我把实情告诉你们，我去对你们是有益的，因为如果我不去，护慰者就不会来，我去了就会派祂到你们这里来。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:37; 犹大书 1:15; 撒迦利亚书 12:10"> 祂来了，必让世人在罪、义和审判方面知罪。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:22–25; 约翰福音 8:23–24; 约翰福音 12:47–48"> 关于罪，是因为他们不信我；</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 3:18; 罗马书 10:3–4"> 关于义，是因为我要去父那里，你们再也看不到我了；</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:31; 约翰一书 3:8; 希伯来书 2:14"> 关于审判，是因为这世界的王受了审判。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:33; 约翰福音 15:15; 哥林多前书 3:1–2"> “我还有许多事情要告诉你们，可是你们现在还不能承受。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:26; 哥林多前书 2:10–13; 约翰福音 14:17"> 等到真理之灵来了，祂会引导你们进入一切真理。祂不凭自己说话，而是把祂所听见的和有关将来的事告诉你们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:13–14; 哥林多后书 3:14–18; 约翰福音 15:26"> 祂也要把从我领受的指示你们，使我得荣耀。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 17:10; 马太福音 11:27; 约翰福音 3:35"> 父的一切都是我的，所以我才说圣灵要把从我领受的指示你们。</span>
</div>
</div>

## 转忧为喜

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:33; 使徒行传 1:3; 约翰福音 14:18–24"> “不久，你们就见不到我了。再过不久，你们还会看见我。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:16; 马可福音 9:32; 约翰福音 16:5"> 几个门徒彼此议论说：“祂说，‘不久，你们就见不到我了，再过不久，你们还会看见我’，又说，‘因为我要去父那里’，这到底是什么意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 马太福音 16:9–11; 希伯来书 5:12"> 祂说‘不久’是什么意思呢？我们真不明白祂在说什么！”</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:30; 约翰福音 16:16; 约翰福音 14:19"> 耶稣知道他们想问祂，就说：“我说，‘不久，你们就见不到我了。再过不久，你们还会看见我。’你们在议论这话是什么意思吗？</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 1:2; 马太福音 5:4; 诗篇 126:5–6"> 我实实在在地告诉你们，你们将痛哭、哀号，世人却要欢喜；你们将忧愁，然而你们的忧愁将变为喜乐。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 113:9; 以赛亚书 13:8; 帖撒罗尼迦前书 5:3"> 妇人分娩时都会痛苦，但孩子生下来后，她就会因为这世界添了一个新生命而欢喜，忘掉了生产的剧痛。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 1:8; 使徒行传 13:52; 约翰福音 16:6"> 同样，现在你们痛苦，但到我再见你们的时候，你们的心必欢喜，而且这份喜乐是谁也夺不去的。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 15:7; 约翰福音 14:13–14; 马太福音 21:22"> “到那一天，你们就什么也不用问我了。我实实在在地告诉你们，你们奉我的名无论向父求什么，祂都会赐给你们。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:7–8; 雅各书 4:2–3; 约翰福音 15:11"> 你们从来没有奉我的名求过什么，你们现在求，就必得到，好使你们的喜乐满溢。</span>
</div>
</div>

## 胜过世界

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:12; 马可福音 4:13; 马太福音 13:34–35"> “我一直用比喻跟你们讲这些事，不久，我就不再用比喻了，而是清楚地把父的事告诉你们。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 8:34; 约翰福音 17:24; 约翰福音 17:19"> 到那天，你们将要奉我的名祈求，我不是说我要为你们向父祈求。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:21; 约翰福音 14:23; 约翰福音 17:23"> 父爱你们，因为你们一直爱我，并且相信我来自上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:1; 约翰福音 13:3; 约翰福音 8:14"> 我从父那里来到这个世界，现在我要离开这个世界回到父那里。”</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 16:25"> 门徒说：“现在你直截了当地告诉我们，不再用比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:17; 约翰福音 17:8; 约翰福音 16:17"> 现在我们知道你无所不知，无需人问你什么，因此我们相信你来自上帝。”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 约翰福音 13:38"> 耶稣说：“你们现在相信吗？</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 13:7; 马太福音 26:31; 约翰福音 8:29"> 看啊！时候快到了，现在就是，你们将要分散，各自回家，只留下我一人。不过，我并非一人，因为父与我在一起。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 14:27; 约翰一书 5:4; 帖撒罗尼迦后书 3:16"> 我把这些事告诉你们，是要叫你们在我里面有平安。你们在世上会有苦难，但你们要放心，我已经胜过这个世界。”</span>
</div>
</div>

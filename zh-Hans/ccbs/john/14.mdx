## 耶稣是道路、真理、生命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 26:3; 约翰福音 16:22–23; 以赛亚书 12:2–3"> “你们心里不要忧愁，你们要信上帝，也要信我。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 5:1; 约翰福音 13:36; 希伯来书 13:14"> 我父的家里有许多住处，不然我就不会说去为你们预备地方了。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 4:16–17; 约翰福音 12:26; 提摩太后书 2:12"> 我预备好了以后，必定回来接你们到我那里。我在哪里，让你们也在哪里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:9; 约翰福音 16:28; 约翰福音 13:3"> 你们知道哪条路通往我去的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 11:16; 马可福音 9:19; 约翰福音 20:25–28"> 多马说：“主啊，你要去哪里，我们还不知道，又怎么会知道路呢？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 4:12; 约翰福音 10:9; 以弗所书 2:18"> 耶稣说：“我就是道路、真理、生命，若不借着我，没有人能去父那里。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 1:15–17; 约翰福音 8:19; 路加福音 10:22"> 你们若认识我，也会认识我的父。从现在起，你们确实认识祂，并且已经看见祂。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 33:18–23; 启示录 22:3–5; 约翰福音 1:43–46"> 腓力说：“主啊！求你让我们看看父，我们就心满意足了。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:15; 约翰福音 12:45; 约翰福音 14:7"> 耶稣说：“腓力，我和你们相处了这么久，你还不认识我吗？人看见了我，就看见了父，你怎么说‘让我们看看父’呢？</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 5:19; 约翰福音 10:38; 约翰福音 10:30"> 难道你不相信我在父里面，父也在我里面吗？我这些话不是凭自己讲的，而是住在我里面的父在做祂自己的工作。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:38; 约翰福音 10:25; 约翰福音 5:36"> 你们要相信我，我在父里面，父也在我里面。你们即使不信，也该因我所做的而信我。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:21; 马可福音 16:17; 路加福音 10:17–19"> 我实实在在地告诉你们，我所做的事，信我的人也要做，而且要做更大的事，因为我要回到父那里。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:7; 马可福音 11:24; 马太福音 7:7"> 你们奉我的名无论求什么，我必应允，好让父在子身上得荣耀。</span>
<span className="v" id="v14" data-v="14"> 你们若奉我的名向我求什么，我必应允。</span>
</div>
</div>

## 应许赐下圣灵

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:3–5; 约翰一书 5:2–3; 约翰福音 14:21–24"> “你们若爱我，就必遵守我的命令。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:26; 约翰福音 15:26; 约翰福音 16:7–15"> 我会求父另外赐一位护慰者给你们，祂要永远和你们同在。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 36:27; 约翰福音 16:13; 约翰一书 2:27"> 祂是真理的灵，世人不能接受祂，因为他们看不见祂，也不认识祂。但你们认识祂，因祂常与你们同在，并且要住在你们里面。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 14:3; 诗篇 23:4; 马太福音 18:20"> 我不会撇下你们为孤儿，我必到你们这里来。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:16; 约翰福音 7:33; 希伯来书 7:25"> 不久，世人就看不见我了，而你们却能看见我，因为我活着，你们也要活着。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 15:5–7; 加拉太书 2:20; 约翰福音 17:21–23"> 到了那一天，你们就知道我在父里面，你们在我里面，我也在你们里面。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 2:5"> 接受我的命令又遵行的，就是爱我的人。爱我的，我父必定爱他，我也要爱他，并且要亲自向他显现。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 1:13; 路加福音 6:16; 马太福音 10:3"> 犹大（不是加略人犹大）问耶稣：“主啊，你为什么只向我们显现而不向世人显现呢？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 14:21; 约翰福音 14:15; 启示录 3:20–21"> 耶稣回答说：“爱我的人必遵行我的道，我父也必爱他，并且我们要到他那里与他同住。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 7:16; 约翰福音 14:10; 约翰福音 8:42"> 不爱我的人不会遵行我的道。你们所听见的道不是出于我自己，而是出于差我来的父。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:6–8; 约翰福音 13:19; 约翰福音 16:12"> 我趁着与你们在一起，将这些事情都告诉了你们。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:26; 约翰福音 14:16; 约翰一书 2:27"> 但护慰者，就是父为我的名而差来的圣灵，将教导你们一切的事，并使你们想起我对你们说的一切话。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:7; 约翰福音 16:33; 以赛亚书 41:10"> 我把平安留给你们，把我的平安赐给你们，我赐给你们的平安不像世人给的平安。你们心里不要忧愁，也不要害怕。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:29–30; 哥林多前书 15:24–28; 哥林多前书 11:3"> “我对你们说过，我去了还要再回到你们这里。你们如果真的爱我，就会为我去父那里而欢喜快乐，因为父比我大。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 13:19; 约翰福音 16:4–31; 马太福音 24:24–25"> 现在事情还没有发生，我便先告诉你们，到了事情发生的时候，你们就会相信。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:19; 约翰一书 4:4; 启示录 12:9"> 我不再跟你们多谈，因为世界的王快要来了。他根本没有力量胜过我，</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 10:18; 腓立比书 2:8; 约翰福音 12:49"> 但为了让世人知道我爱父，父怎么吩咐我，我就怎么做。起来，我们走吧！”</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 53:5; 以赛亚书 50:6; 马太福音 20:19"> 于是彼拉多命人鞭打耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 15:16–20; 路加福音 23:11; 马太福音 27:27–31"> 士兵用荆棘编成冠冕戴在祂头上，又拿紫袍给祂穿上，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 27:29; 马太福音 26:49; 路加福音 1:28"> 来到祂面前说：“犹太人的王万岁！”然后又用手掌打祂。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:38; 约翰福音 19:6; 路加福音 23:4"> 彼拉多又走到外面对众人说：“我把祂带到你们面前，好让你们知道我查不出祂有什么罪。”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:2; 希伯来书 12:2; 以赛亚书 7:14"> 于是，耶稣戴着荆棘冠冕、穿着紫色长袍走出来。彼拉多对众人说：“你们看这个人！”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:31; 约翰福音 19:4; 使徒行传 2:23"> 祭司长和差役一看见耶稣，就喊道：“把祂钉在十字架上！把祂钉在十字架上！” 彼拉多说：“你们自己把祂带去钉十字架吧！因为我查不出祂有什么罪。”</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 24:16; 约翰福音 5:18; 马太福音 26:63–66"> 犹太人回答说：“我们有律法，按照那律法，祂理当被处死，因为祂自称是上帝的儿子。”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 19:13; 使徒行传 14:11–19"> 彼拉多听了这话，更加害怕，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 18:33; 诗篇 38:13–15; 腓立比书 1:28"> 又将耶稣带回总督府，问祂：“你到底是从哪里来的？”但耶稣没有回答。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 5:19; 约翰福音 18:39; 但以理书 3:14–15"> 彼拉多说：“你不回答我吗？难道你不知道我有权释放你，也有权把你钉在十字架上吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:1; 约翰福音 3:27; 使徒行传 2:23"> 耶稣回答说：“若非从天上赐下权柄给你，你根本无权处置我。因此，把我交给你的那人罪更大。”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 17:6–7; 约翰福音 18:33–36; 马可福音 6:16–26"> 从那时起，彼拉多想要释放耶稣，可是犹太人却一直喊叫：“你如果释放这个人，就不是凯撒的忠臣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“忠臣”希腊文是“朋友”。">a</a></sup>。凡自以为王的，就是背叛凯撒。”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 82:5–7; 马太福音 27:19; 阿摩司书 4:7"> 彼拉多听了这话，就带着耶稣来到一个地方，名叫“铺石地”，希伯来话叫厄巴大。彼拉多在那里开庭审判祂。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:62; 约翰福音 19:5; 马可福音 15:25"> 那天正是逾越节的预备日，大约正午，彼拉多对犹太人说：“看，你们的王！”</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 23:18; 使徒行传 21:36; 约翰福音 19:6"> 众人喊道：“除掉祂！除掉祂！把祂钉在十字架上！” 彼拉多说：“我可以把你们的王钉在十字架上吗？” 祭司长答道：“除了凯撒，我们没有别的王！”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:24–25; 马太福音 27:26–31; 马可福音 15:15–20"> 于是，彼拉多将耶稣交给他们去钉十字架，他们就把耶稣带走了。</span>
</div>
</div>

## 钉十字架

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:33; 路加福音 14:27; 路加福音 23:26"> 耶稣背着自己的十字架出来，前往髑髅地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="可能当地的石灰岩地形看起来像一具骷髅头，故此得名。">b</a></sup>，那地方希伯来话叫各各他。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:12; 马可福音 15:24–27; 加拉太书 3:13"> 他们在那里把耶稣钉在十字架上。同时还钉了两个人，一边一个，耶稣在当中。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 27:37; 路加福音 23:38; 马可福音 15:26"> 彼拉多写了一个告示，安在十字架上，上面写着：“犹太人的王，拿撒勒人耶稣。”</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 26:14; 启示录 16:16; 使徒行传 22:2"> 因为耶稣被钉十字架的地方离城不远，告示上面的字是用希伯来、罗马、希腊三种文字写的，所以很多犹太人读了上面的字。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 19:14; 约翰福音 19:19"> 犹太人的祭司长对彼拉多说：“不要写‘犹太人的王’，应该写‘这人自称是犹太人的王’。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 76:10; 诗篇 65:7; 箴言 8:29"> 彼拉多说：“我写了就写了。”</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 23:34; 马可福音 15:24; 马太福音 27:35"> 士兵把耶稣钉在十字架上，又把祂的衣服分成四份，每人一份。剩下的内衣从上到下是一块布，没有缝口。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 22:18; 约翰福音 19:28; 约翰福音 19:36–37"> 他们就商量说：“不要撕破它，让我们抽签决定给谁吧。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="诗篇22:18。">c</a></sup>这件事是要应验圣经上的话：“他们分了我的外衣，又为我的内衣抽签。”士兵果然这样做了。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 23:49; 马太福音 27:55–56; 约翰福音 20:1"> 耶稣的十字架旁边站着祂母亲、祂母亲的姊妹、革罗罢的妻子玛丽亚和抹大拉的玛丽亚。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 21:24; 约翰福音 20:2; 约翰福音 2:4"> 耶稣看见祂的母亲和祂爱的门徒都站在旁边，就对母亲说：“女士，看啊，他是你的儿子。”</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:48–50; 约翰福音 16:32; 提摩太前书 5:2–4"> 然后对那门徒说：“看啊，她是你的母亲。”从那天起，那个门徒就把她接到自己家里去了。</span>
</div>
</div>

## 耶稣之死

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="诗篇 69:21; 诗篇 22:15; 约翰福音 19:30"> 之后，耶稣知道一切都完成了，就说：“我渴了。”这是要应验圣经上的话。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 19:18; 路加福音 23:36; 马可福音 15:36"> 那里有一个器皿盛满了酸酒。有人用海绵蘸满了酸酒，绑在牛膝草上送到祂嘴边，</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 17:4; 腓立比书 2:8; 歌罗西书 2:14–17"> 耶稣喝了那酸酒，然后说：“成了！”就垂下头来，将灵魂交给了上帝。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 19:14; 约翰福音 19:42; 马可福音 15:42"> 因为那天是预备日，第二天的安息日是个大日子，为了避免在安息日有尸首留在十字架上，犹太人便求彼拉多叫人打断他们的腿，把他们搬走。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 19:18; 路加福音 23:39–43"> 于是，士兵上前把与耶稣同钉十字架的两个人的腿都打断了。</span>
<span className="v" id="v33" data-v="33"> 但是他们来到耶稣那里时，发现祂已经死了，就没有打断祂的腿，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰一书 5:6; 撒迦利亚书 12:10; 撒迦利亚书 13:1"> 只是有一个士兵用矛刺了一下祂的肋旁，顿时有血和水流了出来。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 21:24; 希伯来书 2:3–4; 约翰一书 1:1–3"> 看见这事的人为此做见证，他的见证是真实的，他知道自己所说的是事实，好让你们可以相信。</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 34:20; 民数记 9:12; 出埃及记 12:46"> 这些事的发生是为了应验圣经上的话：“祂的骨头一根也不会折断。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="出埃及记12:46；民数记9:12；诗篇34:20。">d</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="撒迦利亚书 12:10; 启示录 1:7; 诗篇 22:16–17"> 还有经文说：“他们必仰望自己所刺的那位。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="撒迦利亚书12:10。">e</a></sup></span>
</div>
</div>

## 安葬耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马可福音 15:42–47; 马太福音 27:57–61; 箴言 29:25"> 事后，有一个名叫约瑟的亚利马太人请求彼拉多让他为耶稣收尸。他因为畏惧犹太人，只是暗中做耶稣的门徒。彼拉多批准后，他就把耶稣的遗体领去。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:50–52; 雅歌 4:14; 约翰福音 3:1–21"> 曾经夜访耶稣的尼哥德慕也来了，他带来了没药和沉香调成的香料，重约三十四公斤。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 11:44; 约翰福音 20:5–7; 使徒行传 5:6"> 他们按照犹太人殡葬的习俗，用细麻布加上香料把耶稣的遗体裹好。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:53; 马太福音 27:60; 约翰福音 20:15"> 在耶稣被钉十字架的地方有一个园子，里边有一座新坟墓，从来没有安葬过人。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 19:31; 约翰福音 19:14; 以赛亚书 53:9"> 因为那天是犹太人的预备日，这座新坟墓也在附近，他们就把耶稣安放在那里。</span>
</div>

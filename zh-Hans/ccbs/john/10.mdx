## 好牧人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 约翰福音 10:8–10; 罗马书 16:18"> “我实实在在地告诉你们，不从门进羊圈而从别处爬进去的人就是贼，是强盗。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:14; 使徒行传 20:28; 彼得前书 5:4"> 从门进去的才是羊的牧人，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 34:11–16; 提摩太后书 2:19; 约翰福音 10:4"> 看门的会给他开门，羊也听他的声音。他按名字叫自己的羊，把它们领出来。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:30; 约翰福音 10:16; 约翰福音 12:26"> 领出来之后，自己便走在前面，羊群也跟着他，因为羊认得他的声音。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:5–6; 歌罗西书 2:6–10; 马可福音 4:24"> 羊从不跟随陌生人，见了陌生人就逃跑，因为它们不认得陌生人的声音。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 56:11; 诗篇 82:5; 箴言 28:5"> 耶稣讲了这个比喻，但听的人都不明白祂的意思。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:1"> 于是祂又说：“我实实在在地告诉你们，我就是羊的门。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 34:2; 耶利米书 23:1; 约翰福音 10:1"> 在我以前来的，都是贼，是强盗，羊不听从他们。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:7"> 我就是门，从我进来的必定得救，并且会安然出入，找到草吃。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 约翰福音 6:51; 约翰福音 12:47"> 盗贼来，无非是要偷窃、杀害、毁坏。但我来是要羊得生命，并且得到丰盛的生命。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:14–15; 诗篇 23:1; 约翰福音 15:13"> “我是好牧人，好牧人为羊舍命。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:29; 撒迦利亚书 11:16–17; 以西结书 34:2–6"> 雇工不是牧人，羊也不是他的，他一见狼来了，必撇下羊逃命。狼就会抓住羊，驱散羊群。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:20; 约翰福音 12:6; 使徒行传 18:17"> 他逃走，因为他是雇工，并不在乎羊。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:27; 约翰福音 10:11; 提摩太后书 2:19"> 我是好牧人，我认识我的羊，我的羊也认识我，</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:4; 约翰福音 10:11; 以赛亚书 53:10"> 正如父认识我，我也认识父，并且我为羊舍命。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 56:8; 约翰福音 11:52; 彼得前书 2:25"> 我还有别的羊不在这羊圈里，我必须领他们回来，他们也必听我的声音。这样，我所有的羊将要合成一群，由一个牧人来带领。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:18; 约翰福音 10:11; 希伯来书 2:9"> 父爱我，因为我舍弃自己的生命，为了再得回生命。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:9; 提多书 2:14; 约翰福音 2:19–21"> 没有人能夺走我的生命，我是甘心舍弃的。我有权舍弃，也有权得回，这是我从父那里得到的命令。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:16; 哥林多前书 3:3; 约翰福音 7:40–43"> 犹太人因这番话又起了纷争。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:20; 马可福音 3:21; 约翰福音 8:47–48"> 他们当中好些人说：“祂被鬼附身了！祂疯了！何必听祂的？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 4:11; 以赛亚书 35:5–6; 诗篇 94:9"> 又有些人说：“被鬼附身的人不会说这种话的，鬼能医治瞎眼的人吗？”</span>
</div>
</div>

## 被犹太人弃绝

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶路撒冷庆祝修殿节的时候到了，是在冬天。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:12; 使徒行传 3:11"> 耶稣正在圣殿的所罗门廊行走，</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 约翰福音 1:19; 约翰福音 8:25"> 一群犹太人围着祂说：“你让我们猜到什么时候呢？如果你是基督，就清楚地告诉我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:38; 约翰福音 8:58; 约翰福音 14:11"> 耶稣回答说：“我已经告诉你们了，你们却不信。我奉我父的名所行的神迹也为我做见证，</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:47; 哥林多后书 4:3–4; 约翰福音 12:37–40"> 只是你们不肯相信，因为你们不是我的羊。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 10:16; 约翰福音 10:14; 启示录 3:20"> 我的羊听我的声音，我也认识他们，他们也跟随我。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:39–40; 约翰福音 6:37; 约翰福音 3:15–16"> 我要赐他们永生，他们永不灭亡。没有人能从我的手里把他们抢走。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:37; 约翰福音 17:2; 约翰福音 17:9"> 我父把羊赐给我，祂比万物都大，没有人能从祂手中把羊抢走。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:1–2; 约翰福音 14:9; 约翰福音 17:21–23"> 我和父本为一。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 5:18; 约翰福音 8:59; 撒母耳记上 30:6"> 于是犹太人又拿起石头要打祂。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰一书 3:12; 约翰福音 5:36; 诗篇 35:12"> 耶稣就问他们：“我将许多从父而来的善行显给你们看，你们为了哪一件事拿石头打我呢？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 5:18; 利未记 24:16; 约翰福音 10:30"> 犹太人回答说：“我们不是因为你做的善事打你，而是因为你说了亵渎的话，你是人，却把自己当作上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 82:6–7; 出埃及记 7:1; 诗篇 82:1"> 耶稣说：“你们的律法书上不是写着‘我曾说你们都是神’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇82:6。">a</a></sup>吗？</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:35; 罗马书 13:1; 路加福音 16:17"> 圣经上的话是不能废的，既然上帝称那些承受祂道的人为神，</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:17–18; 约翰福音 3:17; 耶利米书 1:5"> 而我是父分别出来又差到世上来的，我说自己是上帝的儿子，你们就指控我亵渎吗？</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 15:24; 约翰福音 10:25; 约翰福音 12:37–40"> 如果我不做我父的事，你们不必信我。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 14:20; 约翰福音 10:25; 约翰福音 10:30"> 但如果我做了，你们纵然不信我，也应该相信我所做的事，这样你们就会知道并领会父在我里面，我也在父里面。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:30; 约翰福音 8:59; 约翰福音 7:44"> 他们又要抓耶稣，但祂从他们手中逃脱了。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 1:28; 约翰福音 11:54; 约翰福音 7:1"> 后来，耶稣回到约旦河东岸约翰从前施洗的地方，在那里住下来。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 1:33–34; 约翰福音 1:29–30; 马可福音 1:37"> 许多人来到祂那里。他们说：“虽然约翰没有行过神迹，可是约翰所说关于这人的事全是真的。”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 4:41; 约翰福音 2:23; 约翰福音 7:31"> 那里有许多人信了耶稣。</span>
</div>
</div>

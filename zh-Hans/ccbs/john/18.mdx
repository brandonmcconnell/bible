## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 14:32; 马太福音 26:36; 撒母耳记下 15:23"> 耶稣祷告完毕，就带着门徒穿过汲沦溪，进了那里的一个园子。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:37; 路加福音 22:39; 马可福音 11:11–12"> 因为耶稣时常带着门徒到那里聚会，所以出卖耶稣的犹大也知道那地方。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 18:12; 路加福音 22:47–53; 诗篇 22:12"> 这时，犹大带着一队士兵以及祭司长和法利赛人的差役，拿着灯笼、火把和兵器来了。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 13:1; 约翰福音 18:7; 诗篇 27:3"> 耶稣知道将要发生在自己身上的一切事，于是出来问他们：“你们找谁？”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:11; 约翰福音 19:19; 马太福音 2:23"> 他们回答说：“拿撒勒人耶稣！” 耶稣说：“我就是。”那时出卖耶稣的犹大也站在他们当中。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 27:2; 诗篇 70:2–3; 列王纪下 1:9–15"> 他们听到耶稣说“我就是”，便后退跌倒在地上。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 18:4"> 耶稣又问：“你们找谁？” 他们说：“拿撒勒人耶稣。”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:28; 马太福音 26:56; 哥林多后书 12:9"> 耶稣说：“我已经告诉你们我就是。你们既然找我，就让这些人走吧。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:12"> 这是要应验祂以前说的：“你赐给我的人一个也没有失掉。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约翰福音6:39。">a</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 14:47; 马太福音 26:51–54; 路加福音 22:49–51"> 西门·彼得带着一把刀，他拔刀向大祭司的奴仆马勒古砍去，削掉了他的右耳。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 20:22; 马太福音 26:39; 约翰福音 20:17"> 耶稣对彼得说：“收刀入鞘吧！我父赐给我的杯，我怎能不喝呢？”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:57; 约翰福音 18:3; 使徒行传 21:37"> 千夫长带着士兵和犹太人的差役抓住耶稣，把祂捆绑起来。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 18:24; 约翰福音 11:51; 马太福音 26:3"> 他们押着耶稣先去见亚那，他是那一年的大祭司该亚法的岳父。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:49–52"> 这个该亚法以前曾对犹太人建议说：“不如一人替众人死。”</span>
</div>
</div>

## 彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:54; 马可福音 14:54; 马太福音 26:58–68"> 西门·彼得和另一个门徒跟在耶稣后面。那门徒认识大祭司，就跟着耶稣进了大祭司的院子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:69; 马可福音 14:66–68; 路加福音 22:55–57"> 彼得留在门外。后来，认识大祭司的那个门徒出来对看门的婢女说了一声，便把彼得也带了进去。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 26:69–70; 约翰福音 21:15; 路加福音 22:56–57"> 看门的婢女问彼得：“你不也是这个人的门徒吗？” 他说：“我不是。”</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 14:54; 约翰福音 18:25; 马可福音 14:67"> 天气很冷，奴仆和差役生了一堆炭火，站着烤火取暖，彼得也跟他们站在一起烤火取暖。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:55–65; 路加福音 20:20; 路加福音 22:63–71"> 那时，大祭司正在盘问耶稣有关祂的门徒和祂的教导之事。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:26; 以赛亚书 48:16; 马太福音 4:23"> 耶稣说：“我是公开对世人讲的，我常在犹太人聚集的会堂和圣殿教导人，没有在背地里讲过什么。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:59–60; 使徒行传 24:12–13; 路加福音 22:67"> 你何必问我呢？问那些听过我讲的人吧，他们知道我讲过什么。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 19:3; 马可福音 14:65; 路加福音 22:63–64"> 耶稣话才说完，站在旁边的差役就打祂耳光，说：“你敢这样回答大祭司！”</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:20–23; 哥林多后书 10:1; 马太福音 5:39"> 耶稣说：“如果我说错了，你可以指出我错在哪里。如果我说的对，你为什么打我呢？”</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:13; 马太福音 26:57"> 亚那派人把耶稣捆绑着押到大祭司该亚法那里。</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 14:67–72; 约翰福音 18:17–18; 创世记 18:15"> 那时西门·彼得仍然站在那里烤火，有人问他：“你不也是祂的门徒吗？” 彼得否认说：“我不是！”</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 18:1; 约翰福音 18:10; 马太福音 26:73"> 大祭司有个奴仆，跟被彼得削掉耳朵的那人是亲戚，他说：“我不是看见你和祂一起在园子里吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 13:38; 马可福音 14:71–72; 路加福音 22:60–62"> 彼得再次否认。就在那时，鸡叫了。</span>
</div>
</div>

## 彼拉多审问耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 18:33; 约翰福音 19:9; 马太福音 27:27"> 黎明的时候，众人从该亚法那里把耶稣押往总督府，他们自己却没有进去，因为怕沾染污秽，不能吃逾越节的晚餐。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 27:23; 马可福音 15:2–5; 马太福音 27:11–14"> 彼拉多出来问他们：“你们控告这个人什么罪？”</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 3:13; 路加福音 20:19–26; 马可福音 10:33"> 他们回答说：“如果祂没有为非作歹，我们也不会把祂送到你这里来。”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 19:6–7; 约翰福音 19:15; 使徒行传 25:18–20"> 彼拉多说：“你们把祂带走，按照你们的律法去审理吧。” 犹太人说：“可是我们无权处死人。”</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:14; 马太福音 20:19; 马太福音 26:2"> 这是要应验耶稣预言自己会怎样死的话。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 23:3–4; 约翰福音 18:37; 约翰福音 19:3"> 彼拉多回到总督府提审耶稣，问道：“你是犹太人的王吗？”</span>
<span className="v" id="v34" data-v="34"> 耶稣回答说：“你这样问，是你自己的意思，还是听别人说的？”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 18:14–16; 尼希米记 4:2; 罗马书 3:1–2"> 彼拉多说：“难道我是犹太人吗？是你们犹太人和祭司长把你送来的。你到底做了什么？”</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 17:20–21; 歌罗西书 1:12–14; 罗马书 14:17"> 耶稣答道：“我的国不属于这个世界，如果我的国属于这个世界，我的臣仆早就起来争战了，我也不会被交在犹太人的手里。但现在我的国不属于这个世界。”</span>
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 约翰福音 8:47; 约翰福音 8:14"> 于是彼拉多对祂说：“那么，你是王吗？” 耶稣说：“你说我是王，我正是为此而生，也为此来到世上为真理做见证，属于真理的人都听从我的话。”</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 19:4; 路加福音 23:4; 约翰福音 19:6"> 彼拉多说：“真理是什么？”说完了，又到外面对犹太人说：“我查不出祂有什么罪。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:15–18; 路加福音 23:16–23; 马可福音 15:6–14"> 不过按照惯例，在逾越节我要给你们释放一个人。你们要我为你们释放犹太人的王吗？”</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:25; 马可福音 15:15; 马太福音 27:16"> 众人又高喊：“不要这个人！我们要巴拉巴！”巴拉巴是个强盗。</span>
</div>

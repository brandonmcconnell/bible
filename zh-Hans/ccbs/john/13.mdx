## 耶稣为门徒洗脚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 12:23; 约翰一书 4:19; 约翰福音 13:34"> 逾越节之前，耶稣知道自己快要离开世界回到父那里了。祂一直爱世上属自己的人，并且爱他们到底。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:13–17; 使徒行传 5:3; 约翰福音 13:26–27"> 吃晚饭的时候，魔鬼已经把出卖耶稣的念头放在加略人西门的儿子犹大的心里。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 马太福音 11:27; 希伯来书 1:2"> 耶稣知道父将一切交给了祂，也知道自己从上帝那里来，即将回到上帝那里，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:27; 哥林多后书 8:9; 路加福音 12:37"> 就离席站起来，脱了外衣，拿了一条毛巾束在腰间，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:44; 诗篇 51:2; 创世记 18:4"> 然后倒了一盆水为门徒洗脚，用束在腰间的毛巾擦干。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 3:11–14; 约翰福音 1:27; 路加福音 5:8"> 轮到西门·彼得的时候，他说：“主啊！你要洗我的脚吗？”</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 12:8; 约翰福音 12:16; 约翰福音 14:26"> 耶稣回答说：“我这样做，你现在虽然不明白，将来一定会明白。”</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 36:25; 使徒行传 22:16; 提多书 3:5"> 彼得说：“你绝对不可洗我的脚。” 耶稣说：“如果我不洗你的脚，你就和我没有关系了。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 51:7; 诗篇 51:2; 彼得前书 3:21"> 西门·彼得说：“主啊，不只我的脚，连我的手和头也洗吧。”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:3; 哥林多后书 7:1; 哥林多后书 5:17"> 耶稣说：“洗过澡的人全身是干净的，只要洗洗脚就好了。你们是干净的，但不是每一个都干净。”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 13:26; 约翰福音 13:2; 约翰福音 13:21"> 因为耶稣知道谁要出卖祂，所以说：“你们不是每一个都干净。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 13:7; 约翰福音 13:4; 以西结书 24:24"> 耶稣给门徒洗完了脚，便穿上外衣再次入席，然后问道：“我为你们做的，你们明白吗？</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:46; 哥林多前书 12:3; 约翰福音 11:28"> 你们称呼我‘老师’，也称呼我‘主’，你们称呼得对，因为我是。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 5:5; 使徒行传 20:35; 罗马书 12:16"> 我是你们的老师，又是你们的主，尚且给你们洗脚，你们更应当彼此洗脚。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 3:17–18"> 我给你们立了榜样，好让你们效法我。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:40; 约翰福音 15:20; 马太福音 10:24–25"> 我实实在在地告诉你们，奴仆不能大过主人，受差遣的也不能大过差遣他的人。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 11:28; 雅各书 4:17; 雅各书 1:25"> 你们既然明白这些道理，照着去做就有福了。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 马太福音 26:23; 约翰福音 17:12"> 我这话不是指着你们每一个人说的，我知道我拣选了谁。但这是为了要应验圣经上的话，‘吃我饭的人用脚踢我。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇41:9。">a</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 43:10; 约翰福音 14:29; 约翰福音 16:4"> 我在事情还没有发生之前预先告诉你们，等事情发生以后，你们就会相信我是基督。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:16; 路加福音 9:48; 马太福音 25:40"> 我实实在在地告诉你们，谁接待我所差遣的，就是接待我；谁接待我，就是接待差我来的那位。”</span>
</div>
</div>

## 预言犹大卖主

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:18; 马太福音 26:21; 马可福音 14:18"> 说完这番话，耶稣心里忧伤，便宣布说：“我实实在在地告诉你们，你们中间有一个人要出卖我。”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 22:23; 马太福音 26:22; 马可福音 14:19"> 门徒面面相觑，不知道耶稣指的是谁。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 19:26; 约翰福音 21:7; 约翰福音 21:20"> 西门·彼得向耶稣所爱的那个门徒点头示意，让他问耶稣到底是谁要出卖祂。那门徒挨在耶稣身边，</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 21:20; 创世记 44:4–12; 以斯帖记 7:5"> 便顺势靠过去问耶稣：“主啊，是谁？”</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:23; 约翰福音 13:30; 马可福音 14:19–20"> 耶稣回答说：“我蘸一点饼给谁，就是谁。”耶稣就蘸了一点饼，递给加略人西门的儿子犹大。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:3; 约翰福音 13:2; 传道书 9:3"> 犹大吃了以后，撒旦就进了他的心。耶稣对他说：“你要做的事，赶快去做吧！”</span>
<span className="v" id="v28" data-v="28"> 同桌吃饭的人都不明白耶稣这话的意思。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 12:5–6; 约翰福音 13:1; 以弗所书 4:28"> 因为犹大负责保管钱袋，有人以为耶稣是叫他去买过节的用品，或者去周济穷人。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:7; 约伯记 24:13–15; 箴言 4:16"> 犹大吃过那块饼后，立刻出去了。那时候是晚上。</span>
</div>
</div>

## 新命令

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 14:13; 彼得前书 4:11; 约翰福音 7:39"> 犹大出去以后，耶稣说：“现在人子得到荣耀了，上帝在人子身上也得了荣耀。</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 22:1; 以赛亚书 53:10–12; 约翰福音 17:4–6"> 上帝既然在人子身上得了荣耀，也要让人子在祂身上得荣耀，并且马上要使人子得荣耀。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 7:33–34; 约翰福音 8:21–24; 约翰福音 16:16–22"> 孩子们，我与你们同在的时间不多了，你们会寻找我，但我去的地方，你们不能去。这句话我以前对犹太人说过，现在也照样告诉你们。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所书 5:2; 利未记 19:18; 约翰福音 15:17"> 我赐给你们一条新命令：你们要彼此相爱。我怎样爱你们，你们也要怎样彼此相爱。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 4:20–21; 约翰一书 3:10–14; 约翰一书 2:10"> 你们如果彼此相爱，世人就会认出你们是我的门徒。”</span>
</div>
</div>

## 预言彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="彼得后书 1:14; 约翰福音 13:33; 约翰福音 21:21–22"> 西门·彼得问耶稣：“主啊，你要到哪里去？” 耶稣回答说：“我要去的地方，你现在不能跟我去，但将来必定跟我去。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:13; 使徒行传 20:24; 马可福音 14:27–31"> 彼得说：“主啊！为什么我现在不能跟你去呢？就是为你死，我也愿意！”</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:34; 马太福音 26:34; 马可福音 14:30"> 耶稣说：“你真愿意为我死吗？我实实在在地告诉你，鸡叫以前，你会三次不认我。”</span>
</div>

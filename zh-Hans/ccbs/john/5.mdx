## 耶稣在毕士大池边治病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 16:16; 出埃及记 23:14–17; 出埃及记 34:23"> 这事以后，犹太人的一个节期到了，耶稣便上了耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 12:39; 尼希米记 3:1; 尼希米记 3:32"> 耶路撒冷靠近羊门的地方有一个水池，希伯来话叫毕士大，池边有五条走廊，</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:1–4; 路加福音 7:22; 马太福音 15:30"> 里面躺着许多瞎眼的、瘸腿的、瘫痪的等病人。</span>
<span className="v" id="v4" data-v="4"> 他们都在等候主的天使偶尔来搅动池水。水动时，第一个下去的，无论患了什么病都会痊愈。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无4节。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 3:2; 路加福音 8:43; 马可福音 9:21"> 那里有一个人病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯来书 4:15; 希伯来书 4:13"> 耶稣看他躺着，知道他病了很久，就问他：“你想痊愈吗？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 72:12; 申命记 32:36; 哥林多前书 9:24"> 那人回答说：“先生，水动的时候，没有人把我放进池子里，我要下去的时候，别人总是先我一步。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 马太福音 9:6; 马可福音 2:11"> 耶稣对他说：“起来，拿上你的垫子走吧！”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:7–8; 约翰福音 9:14; 马可福音 3:2–4"> 那人立刻痊愈了，拿起垫子开始行走。那天是安息日，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 17:21; 路加福音 6:2; 约翰福音 9:16"> 犹太人便对那人说：“今天是安息日，你不可拿着垫子走路。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 2:9–11; 约翰福音 9:16"> 他说：“那位医治我的叫我拿起垫子走。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:23; 士师记 6:29; 罗马书 10:2"> 他们问他：“叫你拿起垫子走的人是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 约翰福音 8:59"> 那人不知道是谁，因为那里人多，耶稣已经躲开了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:11; 利未记 26:23–24; 诗篇 118:18"> 后来，耶稣在圣殿里遇见他，对他说：“你已经完全好了，不要再犯罪了，免得你遭遇更不幸的事。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:11–12; 约翰福音 4:29; 约翰福音 9:25"> 那人便去告诉犹太人，医治他的是耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:39; 约翰福音 7:19–20; 马可福音 3:6"> 因为耶稣在安息日给人治病，犹太人便开始迫害祂。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:4; 约翰福音 14:10; 歌罗西书 1:16"> 耶稣对他们说：“我父至今仍在做工，我也在做工。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 10:30; 约翰福音 10:33; 约翰福音 19:7"> 犹太人听了，更想杀祂，因祂不但干犯安息日，还称上帝为父，把自己看作与上帝平等。</span>
</div>
</div>

## 圣子的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:49; 约翰福音 8:28; 约翰福音 14:10"> 耶稣说：“我实实在在地告诉你们，子凭自己什么都不能做，唯有看见父做什么，子才做什么。无论父做什么，子也照样做。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:35; 马太福音 3:17; 约翰福音 17:26"> 父因为爱子，便把自己的一切作为给祂看，而且还要把比这些更大的作为给祂看，叫你们惊奇。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:11; 申命记 32:39; 约翰福音 11:25"> 父如何使死人复活并赐生命给他们，子也照样想赐生命给谁，就赐给谁。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:27; 使徒行传 17:31; 哥林多后书 5:10"> 父不审判人，祂将审判的事全交给子，</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:23; 路加福音 10:16; 马太福音 11:27"> 叫人尊敬子如同尊敬父。不尊敬子的，就是不尊敬差子来的父。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 约翰福音 6:40; 约翰一书 5:11–13"> “我实实在在地告诉你们，谁听从我的话，又信差我来的那位，谁就有永生，不被定罪，已经出死入生了。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:28; 以弗所书 5:14; 以弗所书 2:5"> 我实实在在地告诉你们，时候快到了，现在就是，死人将听见上帝儿子的声音，听见的将活过来。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 11:26; 约翰福音 1:4; 出埃及记 3:14"> 因为正如父自己是生命的源头，祂也同样让子作生命的源头，</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 10:42; 约翰福音 5:22; 使徒行传 17:31"> 又把审判的权柄交给祂，因为祂是人子。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 20:12; 帖撒罗尼迦前书 4:14–17; 以赛亚书 26:19"> 你们不要惊奇，时候将到，一切在坟墓里的死人都要听见上帝儿子的声音，</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 12:2–3; 罗马书 2:6–10; 使徒行传 24:15"> 他们都要从坟墓里出来。行善的人复活后得永生，作恶的人复活后被定罪。</span>
</div>
</div>

## 见证耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 6:38; 约翰福音 5:19; 约翰福音 4:34"> “我凭自己不能做什么，我按从父听到的指示审判，我的审判是公平的；因为我不是按自己的旨意行，而是按差我来者的旨意行。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 约翰福音 8:54; 启示录 3:14"> “如果我为自己做见证，我的见证是无效的。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 1:33; 约翰福音 12:28–30; 约翰福音 5:36–37"> 然而，另有一位给我做见证，我知道他为我做的见证是真实的。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:29–34; 约翰福音 3:26–36; 约翰福音 1:15–27"> 你们曾派人到约翰那里，他为真理做过见证。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 约翰福音 20:31; 约翰一书 5:9"> 其实我并不需要人的见证，我之所以提起这些事是为了使你们得救。</span>
<span className="v" id="v35" data-v="35" data-xref="彼得后书 1:19; 约翰福音 1:7–8; 马太福音 11:11"> 约翰是一盏点亮的明灯，你们情愿在他的光中欢乐一时。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 10:25; 约翰福音 10:37–38; 约翰福音 15:24"> 但是我有比约翰更大的见证，因为父交待我去完成的工作，就是我现在所做的工作，证明我是父差来的。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 8:18; 约翰福音 1:18; 马太福音 3:17"> 差我来的父曾亲自为我做过见证。你们从未听过祂的声音，从未见过祂，</span>
<span className="v" id="v38" data-v="38" data-xref="约翰一书 2:14; 申命记 6:6–9; 约翰福音 12:44–48"> 心里也没有祂的道，因为你们不信祂差来的那位。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得后书 1:19–21"> 你们研读圣经，以为从圣经中可以得到永生。其实为我做见证的正是这圣经，</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 3:19; 约翰福音 1:11; 诗篇 81:11"> 但你们却不肯到我这里来得生命。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:18; 约翰福音 5:34; 帖撒罗尼迦前书 2:6"> “我不接受人给的荣耀，</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:20; 约翰一书 3:17; 约翰福音 2:25"> 我知道你们没有爱上帝的心。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 10:25; 马太福音 24:5; 约翰福音 17:4–6"> 我奉我父的名来，你们不接受我；若有人奉自己的名来，你们却接受他。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:43; 罗马书 2:29; 腓立比书 2:3"> 你们喜欢互相恭维，却不追求从独一上帝来的荣耀，怎能信我呢？</span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 3:19–20; 加拉太书 3:10; 哥林多后书 3:7–11"> 不要以为我会在父面前控告你们，控告你们的是你们所仰赖的摩西。</span>
<span className="v" id="v46" data-v="46" data-xref="申命记 18:15; 申命记 18:18–19; 约翰福音 1:45"> 你们若信摩西，就会信我，因为他的书里也提到我。</span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> 你们如果连他写的都不信，又怎么会信我的话呢？”</span>
</div>
</div>

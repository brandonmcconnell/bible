## 生命之道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 1:1; 约翰福音 17:5; 启示录 19:13"> 太初，道已经存在，道与上帝同在，道就是上帝。</span>
<span className="v" id="v2" data-v="2"> 祂太初就与上帝同在。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 1:16–17; 哥林多前书 8:6; 启示录 4:11"> 万物都是借着祂造的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“造的”或译“存在”。">a</a></sup>，受造之物没有一样不是借着祂造的。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:12; 约翰福音 12:46; 约翰福音 5:26"> 祂里面有生命，这生命是人类的光。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 3:19–20; 约翰福音 12:36–40; 哥林多前书 2:14"> 光照进黑暗里，黑暗不能吞灭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“吞灭”或译“接受”或“明白”。">b</a></sup>光。</span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 3:1; 约翰福音 3:28; 以赛亚书 40:3–5"> 有一个上帝差来的人名叫约翰，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:4; 约翰福音 1:36; 约翰福音 5:33–35"> 他作为见证人来为光做见证，叫世人可以借着他相信。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:20; 约翰福音 3:28; 使徒行传 19:4"> 约翰不是那光，而是那光的见证人。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:46; 约翰福音 1:4; 约翰一书 2:8"> 那照亮世人的真光来到了世上。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 17:25; 约翰一书 3:1; 哥林多前书 2:8"> 祂来到世上，借祂而造的世界却不认识祂。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 以赛亚书 53:2–3; 约翰福音 3:32"> 祂来到自己的地方，自己人却不接受祂。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 3:26; 罗马书 8:14; 约翰一书 3:1"> 但所有接受祂的，就是那些信祂的人，祂就赐给他们权利成为上帝的儿女。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 3:9; 雅各书 1:18; 彼得前书 1:23"> 这些人不是从血缘关系生的，也不是从情欲或人意生的，而是从上帝生的。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:9; 提摩太前书 3:16; 以赛亚书 40:5"> 道成为肉身，住在我们中间，充满了恩典和真理。我们见过祂的荣耀，正是父独一儿子的荣耀。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:11; 歌罗西书 1:17; 路加福音 3:16"> 约翰为祂做见证，高声喊道：“这就是我以前所说的那位，‘祂在我之后来，却比我位分高，因为祂在我之前已经存在了。’”</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:19; 罗马书 5:2; 以弗所书 2:5–10"> 从祂的丰盛里，我们一次又一次地领受了恩典。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:14; 约翰福音 14:6; 罗马书 3:19–26"> 因为律法是借着摩西颁布的，恩典和真理则是借着耶稣基督赐下来的。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:15; 约翰福音 6:46; 马太福音 11:27"> 从来没有人见过上帝，只有父怀中的独一上帝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“独一上帝”有古卷作“独一儿子”。">c</a></sup>把祂显明出来。</span>
</div>
</div>

## 施洗者约翰的见证

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 约翰福音 10:24; 使徒行传 19:4"> 以下是约翰的见证。犹太人从耶路撒冷派祭司和利未人来查问约翰是谁。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:7–8; 马太福音 3:11–12; 约翰福音 3:28–36"> 约翰毫不隐瞒地说：“我不是基督。”</span>
<span className="v" id="v21" data-v="21" data-xref="玛拉基书 4:5; 申命记 18:15–18; 马太福音 11:14"> 他们问：“那么，你是谁？是以利亚吗？” 他说：“不是。” 他们又问：“你是那位先知吗？” 他说：“不是。”</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 24:13"> 他们又追问：“你到底是谁？你自己说出来吧，我们好回复差我们来的人。”</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 40:3–5; 马可福音 1:3; 马太福音 3:3"> 他就用以赛亚先知的话说：“我就是那个在旷野大声呼喊‘修直主的路’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以赛亚书40:3。">d</a></sup>的人。”</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 马太福音 23:13–15; 路加福音 11:39–44"> 法利赛人派来的那些人问他：</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:18; 申命记 18:15; 约翰福音 1:20–22"> “你既然不是基督，不是以利亚，也不是那位先知，那你为什么给人施洗呢？”</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:10–11; 路加福音 3:16; 使徒行传 1:5"> 约翰答道：“我用水施洗，但在你们中间站着一位你们不认识的，</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 1:30; 马可福音 1:7; 马太福音 3:11"> 祂在我之后来，我连给祂解鞋带都不配。”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:40; 约翰福音 3:23; 士师记 7:24"> 这事发生在约旦河东岸的伯大尼，就是约翰给人施洗的地方。</span>
</div>
</div>

## 上帝的羔羊

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 53:7; 约翰一书 2:2; 约翰一书 3:5"> 次日，约翰看见耶稣走过来，就说：“看啊！上帝的羔羊，除去世人罪恶的！</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:27; 约翰福音 1:15; 路加福音 3:16"> 我说过，‘有一个人在我之后来，却比我位分高，因为祂在我之前已经存在了。’这就是我说的那位。</span>
<span className="v" id="v31" data-v="31" data-xref="玛拉基书 3:1; 路加福音 1:17; 玛拉基书 4:2–5"> 我以前并不认识祂，现在我用水给人施洗，是要把祂显明给以色列人。”</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 1:10; 路加福音 3:22; 马太福音 3:16"> 约翰又做见证说：“我看见圣灵好像鸽子一样从天降下，住在祂身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:5; 马太福音 3:11; 路加福音 3:16"> 我本来不认识祂，但那位差我来用水给人施洗的告诉我，‘你看见圣灵降下，住在谁身上，谁就是用圣灵给人施洗的。’</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 2:7; 约翰福音 1:49; 诗篇 89:26–27"> 我看见了，便做见证：祂就是上帝的儿子。”</span>
</div>
</div>

## 第一批门徒

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 3:25–26; 玛拉基书 3:16"> 再次日，约翰和两个门徒站在那里，</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 1:29; 彼得前书 1:19–20; 以赛亚书 65:1–2"> 他看见耶稣经过，就说：“看啊！这是上帝的羔羊！”</span>
<span className="v" id="v37" data-v="37" data-xref="罗马书 10:17; 约翰福音 1:43; 撒迦利亚书 8:21"> 两个门徒听见他的话，便跟从了耶稣。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 18:7; 约翰福音 3:2; 约翰福音 1:49"> 耶稣转过身来，看见他们跟着，便问：“你们想要什么？” 他们说：“老师<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“老师”希腊文是“拉比”，特指犹太教的老师，下同。">e</a></sup>，你住在哪里？”</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 马太福音 11:28–30; 约翰福音 6:37"> 耶稣说：“你们来看吧。”他们便跟着去看耶稣住的地方。那时大约下午四点，他们就住在耶稣那里。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 约翰福音 1:40–42"> 听见约翰的话后跟从耶稣的两个人中，有一个是西门·彼得的弟弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 4:25; 约翰福音 1:45; 诗篇 89:20"> 他首先去找他哥哥西门，说：“我们找到弥赛亚了！”弥赛亚的意思是基督<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="希伯来文的“弥赛亚”和希腊文的“基督”都是“受膏者”的意思。">f</a></sup>。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 21:15–17; 哥林多前书 3:22; 哥林多前书 15:5"> 他带着西门去见耶稣。 耶稣看着西门，对他说：“你是约翰的儿子西门，你要叫矶法。”矶法的意思是彼得<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="“矶法”和“彼得”分别是亚兰语和希腊语，都是“磐石”的意思。">g</a></sup>。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:9; 约翰福音 14:8; 以赛亚书 65:1"> 又过了一天，耶稣决定去加利利。祂找到腓力，就对他说：“跟从我！”</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:21; 马太福音 11:21; 马可福音 8:22"> 腓力是伯赛大人，与彼得、安得烈是同乡。</span>
<span className="v" id="v45" data-v="45" data-xref="申命记 18:18–22; 路加福音 24:27; 弥迦书 5:2"> 腓力去找拿但业，对他说：“我们遇见了摩西律法和先知记载的那位！祂是约瑟的儿子，拿撒勒人耶稣。”</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 7:52; 约翰福音 7:41–42; 约翰福音 4:29"> 拿但业说：“拿撒勒能出什么好的？” 腓力说：“你来看看吧！”</span>
<span className="v" id="v47" data-v="47" data-xref="启示录 14:5; 诗篇 32:2; 诗篇 73:1"> 耶稣看见拿但业走过来，就指着他说：“看啊，这是个真正的以色列人！他心里毫无诡诈。”</span>
<span className="v" id="v48" data-v="48" data-xref="以赛亚书 65:24; 约翰福音 2:25; 诗篇 139:1–2"> 拿但业问耶稣：“你怎么会认识我？” 耶稣答道：“你在无花果树下，腓力叫你之前，我就看见你了。”</span>
<span className="v" id="v49" data-v="49" data-xref="西番雅书 3:15; 撒迦利亚书 9:9; 马太福音 27:42"> 拿但业说：“老师，你是上帝的儿子！你是以色列的王！”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 20:29; 路加福音 1:45"> 耶稣说：“我说看见你在无花果树下，你就信我吗？将来你还要看见比这更大的事。</span>
<span className="v" id="v51" data-v="51" data-xref="创世记 28:12; 使徒行传 7:56; 路加福音 22:43"> 我实实在在地告诉你们，你们会看见天开了，上帝的天使以人子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="“人子”是耶稣的自称，耶稣在这里自比天梯，背景请参见创世记28:12。">h</a></sup>为梯上上下下。”</span>
</div>

## 香膏抹脚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 14:3–8; 约翰福音 11:1; 路加福音 24:50"> 逾越节前六天，耶稣来到伯大尼，就是祂叫拉撒路从死里复活的那个村子。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:27; 路加福音 10:38–42; 启示录 3:20"> 村里有人为耶稣预备了晚饭，拉撒路也与耶稣同席，玛大在旁边伺候。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 14:3–9; 约翰福音 11:2; 路加福音 10:38–39"> 玛丽亚拿出一瓶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“一瓶”希腊文是“一罗马磅”，约325克。">a</a></sup>珍贵的纯哪哒香膏来抹耶稣的脚，又用自己的头发去擦，屋里充满了香气。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:4; 撒母耳记上 17:28–29; 约翰福音 13:2"> 有一个门徒，就是将要出卖耶稣的加略人犹大说：</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:22; 路加福音 12:33; 马可福音 14:4–5"> “为什么不把香膏卖三百个银币<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“三百个银币”相当于当时一个人一年的工钱。">b</a></sup>去周济穷人呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 13:29; 诗篇 50:16–20; 雅各书 2:6"> 他这样说不是因为他真的关心穷人，而是因为他是个贼，负责保管钱袋，常从中偷拿财物。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:12; 马可福音 14:6; 马太福音 27:57–60"> 耶稣说：“由她吧！她这是为我安葬作预备。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:11; 马可福音 14:7; 马太福音 26:11"> 因为你们身边总会有穷人，可是你们身边不会总有我。”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:14; 约翰福音 11:43–45; 使徒行传 3:10–11"> 有许多犹太人知道耶稣在那里，就来看祂，不单是为了看耶稣，也想看看从死里复活的拉撒路。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:31; 马太福音 2:16; 约翰福音 11:47–53"> 于是，祭司长计划连拉撒路也杀掉，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:45; 约翰福音 12:18; 使徒行传 13:45"> 因为有许多犹太人因为拉撒路的缘故离开他们，去信了耶稣。</span>
</div>
</div>

## 光荣进圣城

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:7–10; 马太福音 21:4–9; 路加福音 19:35–38"> 第二天，很多上来过节的人听见耶稣快到耶路撒冷了，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 118:25–26; 启示录 15:3; 马太福音 21:9–11"> 就拿着棕树枝出去迎接祂，高喊道：<br /><span className="pl pl-1">“和散那！”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“和散那”原意是“拯救我们”，此处有“赞美”的意思。">c</a></sup><br /><span className="pl pl-1">“奉主名来的以色列王当受称颂！”</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="诗篇118:25、26。">d</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亚书 9:9; 马可福音 11:1–7; 马太福音 21:1–7"> 那时，耶稣找到一头驴驹，就骑上它，正如圣经记载：</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 9:9; 以赛亚书 62:11; 西番雅书 3:16–17"> <span className="pl pl-1">“少女锡安啊，不要害怕！</span><br /><span className="pl pl-1">看啊，你的君王骑着驴驹来了。”</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="撒迦利亚书9:9。">e</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 2:22; 约翰福音 14:26; 约翰福音 7:39"> 起初门徒不明白这些事，耶稣得了荣耀之后，他们才想起圣经上这些有关耶稣的记载果然在祂身上应验了。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 1:2; 约翰一书 5:9–12; 约翰福音 19:35"> 那些亲眼看见耶稣叫拉撒路复活、走出坟墓的人不断传扬这件事。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 12:11"> 众人因为听说耶稣行了这神迹，都去迎接祂。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 诗篇 22:27; 约翰一书 2:2"> 法利赛人彼此议论说：“我们真是枉费心思！看啊，整个世界都跟着祂跑了。”</span>
</div>
</div>

## 耶稣预言自己的死

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:35; 以赛亚书 11:10; 使徒行传 17:4"> 有几个希腊人也在节期上耶路撒冷敬拜。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 2:2; 路加福音 19:2–4; 约翰福音 6:40"> 他们去见加利利的伯赛大人腓力，请求说：“先生，我们想见见耶稣。”</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 10:13–14; 路加福音 9:49–50; 约翰福音 1:40–41"> 腓力把这件事告诉安得烈，二人去转告耶稣。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:31–32; 约翰福音 17:1–5; 以赛亚书 60:9"> 耶稣说：“人子得荣耀的时候到了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:36–38; 以赛亚书 53:10–12; 希伯来书 2:9–10"> 我实实在在地告诉你们，一粒麦子如果不落在地里死了，仍是一粒，如果死了，就会结出许多麦粒来。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 路加福音 9:23–24; 马可福音 8:35"> 爱惜自己生命的，会失掉生命；憎恶自己今世生命的，必保住生命，直到永生。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:24; 加拉太书 1:10; 撒母耳记上 2:30"> 谁要事奉我，就要跟从我。我在哪里，事奉我的人也要在哪里。我父必尊重事奉我的人。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 12:23; 希伯来书 5:7; 马太福音 26:42"> “我现在心里忧伤，说什么才好呢？求父救我离开这个时刻吗？然而，我原是为这个时刻来的。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:31–32; 马太福音 26:42; 启示录 5:9–14"> 父啊！愿你使自己的名得荣耀！” 当时天上有声音说：“我已使自己的名得了荣耀，并且还要得荣耀。”</span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 37:2–5; 启示录 6:1; 启示录 14:2"> 站在那里的人群中有人听见后，就说：“打雷了！”也有人说：“是天使在跟祂说话。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 11:42; 约翰福音 11:15; 约翰福音 5:34"> 耶稣说：“这声音不是为我发出的，是为你们发出的。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:4; 约翰一书 5:19; 约翰一书 3:8"> 现在是这世界受审判的时候，这世界的王<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“世界的王”指“魔鬼，又名撒旦”，参见路加福音10:18；歌罗西书2:15；约翰一书3:8。">f</a></sup>要被赶出去了。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:14; 约翰福音 8:28; 彼得前书 2:24"> 至于我，当我从地上被举起来时，必吸引万人归向我。”</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 18:32; 约翰福音 21:19"> 耶稣这句话指的是祂会怎样死。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 37:24–25; 以赛亚书 9:7; 但以理书 7:14"> 众人问：“我们从律法书上知道，基督是永远长存的，你怎么说‘人子必须被举起来’呢？这人子是谁呢？”</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 12:46; 约翰福音 16:16; 以弗所书 5:8"> 耶稣对他们说：“光在你们中间照耀的时候不多了，你们要趁着有光的时候走路，免得黑暗临到你们。走在黑暗里的人不知道要往哪里去。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:8; 约翰福音 8:59; 使徒行传 13:47–48"> 所以你们当趁着有光的时候信从光，好成为光明的儿女。” 耶稣说完后，便离开他们，隐藏起来。</span>
</div>
</div>

## 犹太人不信祂

<div className="bt">
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="路加福音 16:31; 约翰福音 1:11; 约翰福音 15:24"> 耶稣虽然在他们面前行了许多神迹，他们还是不信祂。</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 53:1; 罗马书 10:16; 罗马书 10:20"> 这是要应验以赛亚先知的话：<br /><span className="pl pl-1">“主啊，谁相信我们所传的呢？主的臂膀向谁彰显呢？”</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以赛亚书53:1。">g</a></sup><br /></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:38; 约翰福音 5:44; 彼得后书 2:14"> <span className="pl pl-1">接着，以赛亚又说出他们不能信的缘故：</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 6:10; 马太福音 13:13–15; 路加福音 8:10"> <span className="pl pl-1">“主使他们眼瞎、心硬，</span><br /><span className="pl pl-1">免得他们眼睛看见，</span><br /><span className="pl pl-1">心里明白，回心转意，</span><br /><span className="pl pl-1">就被我医治。”</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="以赛亚书6:10。">h</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 6:1–5; 以赛亚书 6:9–10; 约翰福音 1:14"> 以赛亚看见了祂的荣耀，所以才这样说。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 9:22; 约翰福音 7:13; 以赛亚书 51:7"> 虽然这样，仍有很多犹太的官员信了耶稣，只是在法利赛人面前不敢公开承认，因为害怕会被赶出会堂。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 5:44; 马太福音 23:5–7; 约翰福音 5:41"> 因为他们爱从世人而来的荣耀，胜过爱从上帝而来的荣耀。</span>
</div>
</div>

## 耶稣的道要审判人

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 10:40; 约翰福音 13:20; 约翰福音 5:24"> 耶稣高声说：“信我的，不只是信我，而是信差我来的那位。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 14:9–10; 哥林多后书 4:6; 歌罗西书 1:15"> 人看见了我，就是看见了差我来的那位。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 8:12; 诗篇 36:9; 约翰福音 9:5"> 我来是要作世界的光，好叫信我的人脱离黑暗。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:17; 约翰福音 8:15–16; 约翰福音 12:48"> 听了我的话却不遵守的人，我不审判他，因为我来不是要审判世人，而是要拯救世人。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 10:16; 希伯来书 9:27–28; 罗马书 2:16"> 弃绝我、不接受我话的人将受审判，我讲过的道在末日要审判他，</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 14:10; 约翰福音 8:26; 约翰福音 5:30"> 因为我不是凭自己讲的，我说什么、讲什么都是差我来的父吩咐的。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 17:3; 约翰福音 6:68; 约翰一书 5:20"> 我知道祂的命令能带来永生。所以祂怎么告诉我，我就怎么说。”</span>
</div>
</div>

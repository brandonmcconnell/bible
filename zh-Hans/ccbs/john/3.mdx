## 论重生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 19:39; 约翰福音 7:47–50; 约翰福音 3:10"> 有一个法利赛人名叫尼哥德慕，是犹太人的官。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 5:36; 使徒行传 10:38; 使徒行传 2:22"> 一天晚上，他来见耶稣，说：“老师，我们知道你是上帝差来教导人的，因为如果没有上帝的同在，没有人能行你所行的神迹。”</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 5:17; 约翰福音 3:5–6; 彼得前书 1:23–25"> 耶稣说：“我实实在在地告诉你，人若不重生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“重生”或译“生自上面”，7节同。">a</a></sup>，就不能看见上帝的国。”</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 2:14; 哥林多前书 1:18; 约翰福音 3:3"> 尼哥德慕说：“人老了，怎能重生呢？难道要再进母腹生一次吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 36:25–27; 以弗所书 5:26; 使徒行传 2:38"> 耶稣说：“我实实在在地告诉你，人若不是从水和圣灵生的，就不能进上帝的国。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:16–21; 以西结书 36:26–27; 罗马书 8:4–9"> 从肉体生的还是肉体，从灵生的才是灵。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:3; 以弗所书 4:22–24; 罗马书 12:1–2"> 我说你们必须重生，你不要惊奇。</span>
<span className="v" id="v8" data-v="8" data-xref="传道书 11:4–5; 哥林多前书 2:11; 使徒行传 2:2"> 风随意吹动，你听见它的声音，却不知道它从哪里来、往哪里去。凡从灵生的人也是这样。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 6:60; 路加福音 1:34; 以赛亚书 42:16"> 尼哥德慕又问：“这怎么可能呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:29; 耶利米书 8:8–9; 以西结书 11:19"> 耶稣说：“你是以色列人的老师，还不明白这事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:38; 约翰一书 5:6–12; 约翰福音 12:49"> 我实实在在地告诉你，我们所说的是自己知道的，所见证的是自己见过的，可是你们不肯接受我们的见证。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:1–2; 哥林多前书 2:7–9; 希伯来书 5:11"> 我对你们说地上的事，你们尚且不信，要是说天上的事，你们怎么会信呢？</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 约翰福音 6:38; 使徒行传 2:34"> 除了从天上降下来的人子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“从天上降下来的人子”有古卷作：“从天降下、仍旧在天的人子”。">b</a></sup>以外，没有人到过天上。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 21:7–9; 约翰福音 8:28; 约翰福音 12:32–34"> 摩西在旷野怎样举起铜蛇，人子也必照样被举起来，</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 3:16; 约翰福音 6:40; 约翰福音 12:44–46"> 叫一切信祂的人都得到永生。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:8; 约翰一书 4:9–10; 约翰福音 3:15"> “因为上帝爱世人，甚至将祂独一的儿子赐给他们，叫一切信祂的人不致灭亡，反得永生。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:14; 路加福音 19:10; 约翰福音 12:47–48"> 上帝差祂的儿子到世上来，不是要定世人的罪，而是要借着祂的儿子拯救世人。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:16; 约翰一书 5:10; 罗马书 8:1"> 信祂的人不会被定罪，不信的人已经被定罪，因为他们不信上帝独一的儿子。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:12; 帖撒罗尼迦后书 2:12; 约翰福音 9:39–41"> 光来到世上，世人因为自己的行为邪恶而不爱光，反爱黑暗，这就是他们被定罪的原因。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 5:11–13; 约翰福音 7:7; 约伯记 24:13–17"> 作恶的人恨光，不肯接近光，恐怕他们的罪行暴露出来。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 1:6; 诗篇 139:23–24; 约翰三书 1:11"> 但遵行真理的人喜欢接近光，好显明他们所做的是靠上帝做的。”</span>
</div>
</div>

## 施洗者约翰论耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:1–3; 约翰福音 3:26; 约翰福音 2:13"> 这事之后，耶稣和门徒前往犹太地区，在那里住下，给人施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 1:4–5; 以西结书 43:2; 马太福音 3:5–6"> 那时约翰还没有入狱，他在靠近撒冷的哀嫩也给人施洗。那里水多，众人都去受洗。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 2:6; 马太福音 3:11; 希伯来书 6:2"> 约翰的门徒和一个犹太人为了洁净的礼仪争辩起来，</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:7; 约翰福音 1:15; 约翰福音 12:19"> 于是他们来见约翰，说：“老师，你看，以前在约旦河东岸和你在一起、你为祂做见证的那位在给人施洗，众人都去祂那里了！”</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 1:17; 哥林多前书 4:7; 哥林多前书 15:10"> 约翰回答说：“除非是从天上赐的，否则人什么都得不到。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:20; 约翰福音 1:23; 马太福音 3:11–12"> 你们自己可以为我做见证，我说过我不是基督，我只是奉差遣在祂前面预备道路。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 9:15; 何西阿书 2:19; 以赛亚书 54:5"> 娶新娘的是新郎，伴郎听见新郎的声音，就会欢喜快乐。因此，我现在也心满意足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 1:18; 诗篇 72:17–19; 希伯来书 3:2–6"> 祂必兴旺，我必衰微。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:23; 马太福音 28:18; 罗马书 9:5"> “从上面来的超越万物；从地上来的，属于地，他所谈论的也不外乎地上的事。从天上来的超越万物。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:11; 约翰福音 15:15; 约翰福音 1:11"> 祂见证的是自己的所见所闻，只是没有人接受祂的见证。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 6:17; 以弗所书 1:13; 提多书 1:1–2"> 接受祂见证的人印证了上帝是真实的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 10:38; 马太福音 12:18; 约翰福音 15:26"> 上帝所差来的，说的是上帝的话，因为上帝将圣灵无限量地赐给祂。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 28:18; 约翰福音 5:22; 约翰福音 5:20"> 父爱子，已把万物交在祂手里。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:24; 约翰福音 1:12; 帖撒罗尼迦前书 5:9"> 信子的人有永生；不信子的人得不到永生，上帝的烈怒常在他身上。”</span>
</div>
</div>

## 耶稣的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 13:31–32; 约翰福音 17:4–5; 腓立比书 2:9–11"> 耶稣说完后，就举目望着天说：“父啊！时候到了，愿你使你的儿子得荣耀，好让你的儿子也使你得荣耀。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:28–29; 约翰福音 6:39; 但以理书 7:14"> 因为你把管理世人的权柄赐给了祂，使祂可以将永生赐予你赐给祂的人。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:20; 约翰一书 5:11–12; 耶利米书 9:23–24"> 这永生就是，认识你独一的真神，并且认识你差来的耶稣基督。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:34; 使徒行传 20:24; 提摩太后书 4:7"> 我已经完成你交给我的工作，使你在地上得了荣耀。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:1–3; 歌罗西书 1:15–17; 约翰福音 10:30"> 父啊，现在让我和你同享创世以前我们共有的荣耀吧！</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 17:26; 约翰福音 14:21–24; 约翰一书 5:20"> “你从世上赐给我的人，我已将你的名显明给他们。他们本来属于你，你将他们赐给了我，他们遵守了你的道。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:16–17; 约翰福音 16:15; 约翰福音 14:7–10"> 如今他们知道，我所领受的一切都是从你而来的，</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 17:14; 约翰福音 15:15; 约翰福音 16:30"> 因为我已经把你赐给我的道赐给他们，他们也接受了，并且确实知道我是从你那里来的，也相信是你差遣了我。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:24; 约翰福音 17:2; 约翰福音 17:6"> “我不为世人祈求，却为他们祈求，就是为你赐给我的那些人祈求，因为他们属于你。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 10:30; 彼得前书 2:9; 启示录 5:8–14"> 凡属于我的都是你的，凡属于你的也都是我的，并且我从他们身上得了荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:9; 箴言 18:10; 约翰福音 17:12–18"> 现在我要离开这个世界去你那里了，他们却仍然留在世上。圣父啊，求你为了自己的名，就是你赐给我的名而保守他们，使他们像我们一样合而为一。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 109:6–19; 约翰福音 10:27–28; 约翰福音 18:9"> 我和他们在一起的时候，靠着你赐给我的名保守他们，护卫他们。除了那个注定灭亡的人以外，他们一个也没有灭亡，这是为了应验圣经上的话。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 12:2; 加拉太书 5:22; 约翰福音 15:11"> “现在我要去你那里了，我在世上这样说，是要叫他们心里充满我的喜乐。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:16; 约翰福音 15:18–21; 约翰一书 5:19–20"> 我已将你的道赐给他们，世人恨他们，因为他们像我一样不属于这个世界。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 121:7; 约翰一书 5:18; 马太福音 6:13"> 我不求你带他们离开这个世界，但求你保守他们脱离那恶者。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 17:14"> 因为他们像我一样不属于这个世界。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:3; 诗篇 119:160; 以弗所书 5:26"> 求你用真理使他们圣洁。你的道就是真理。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 5:20; 约翰福音 20:21; 约翰福音 17:3"> 你怎样差我到世上来，我也照样差他们到世人中间。</span>
<span className="v" id="v19" data-v="19" data-xref="提多书 2:14; 希伯来书 2:11; 约翰福音 17:17"> 为了他们，我献上自己，使他们借着真理可以圣洁。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 17:6–11; 使徒行传 2:41; 使徒行传 4:4"> “我不但为这些人祈求，也为那些因他们的话而信我的人祈求，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 12:12; 歌罗西书 3:11–14; 约翰福音 17:11"> 使他们都合而为一，正如父你在我里面，我在你里面一样，使他们也在我们里面，好让世人相信是你差我来的。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 3:18; 约翰福音 14:20; 马可福音 16:17–20"> 我又将你赐给我的荣耀赐给他们，使他们像我们一样合而为一。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 17:21; 约翰福音 16:27; 约翰一书 3:1"> 我在他们里面，你在我里面，使他们完完全全地合而为一。这样，世人便知道我是你差来的，而且知道你像爱我一样爱他们。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 17:5; 约翰福音 12:26; 约翰福音 14:3"> “父啊！我在哪里，愿你赐给我的人也在哪里，好让他们看见你赐给我的荣耀，因为在创世以前你已经爱我了。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:11; 约翰福音 7:29; 约翰福音 17:8"> 公义的父啊！尽管世人不认识你，但我认识你，这些人也知道是你差我来的。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 17:23; 约翰福音 17:6; 约翰福音 15:9"> 我使他们认识了你的名，我还要使他们更认识你的名，好让你对我的爱存在他们里面，我也在他们里面。”</span>

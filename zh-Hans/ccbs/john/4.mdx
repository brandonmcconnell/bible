## 井边谈道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:26; 约翰福音 3:22; 哥林多后书 4:5"> 耶稣得知法利赛人听见祂比约翰收徒施洗的人数还多，便离开犹太，返回加利利。其实不是耶稣亲自施洗，而是祂的门徒施洗。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 祂回加利利的路上必须经过撒玛利亚。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 24:32; 创世记 33:19; 创世记 48:22"> 于是，祂来到撒玛利亚的一座城，名叫叙加，靠近雅各留给他儿子约瑟的那块地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 4:15; 希伯来书 2:17; 马太福音 8:24"> 雅各井就在那个地方。耶稣走路疲乏，便坐在井旁休息。那时大约是正午。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:42; 列王纪上 17:10; 创世记 24:43"> 门徒都进城买食物去了。有一个撒玛利亚的妇人来打水，耶稣对她说：“请给我一点水喝。”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 10:28; 马太福音 10:5; 列王纪下 17:24–41"> 撒玛利亚妇人说：“你是个犹太人，怎么向我这撒玛利亚妇人要水喝？”原来犹太人和撒玛利亚人互不往来。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:14; 启示录 7:17; 约翰福音 7:37–39"> 耶稣回答说：“要是你知道上帝的恩赐，又知道向你要水喝的是谁，你早就求祂了，祂也早就把活水给你了。”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:14; 约翰福音 3:4"> 妇人说：“先生，你没有打水的器具，井又深，你从哪里得到活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 4:6; 约翰福音 8:53; 马太福音 12:42"> 我们的祖先雅各把这口井留给我们，他自己和他的儿女、牲畜都喝这井里的水，难道你比他更大吗？”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 6:27; 以赛亚书 65:13–14; 路加福音 16:24"> 耶稣说：“人喝了这井里的水，还会再渴，</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:38–39; 约翰福音 6:35; 以赛亚书 49:10"> 但是喝了我所赐的水，永远不会再渴。我所赐的水要在他里面成为生命的泉源，涌流不息，直到永生。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:34; 罗马书 8:5; 诗篇 4:6"> 妇人说：“先生，请你把这水赐给我，我就不会再渴了，也用不着来打水了。”</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 4:13; 启示录 2:23; 约翰福音 4:18"> 耶稣说：“去叫你的丈夫来。”</span>
<span className="v" id="v17" data-v="17"> 妇人说：“我没有丈夫。”耶稣说：“你说的对，你没有丈夫，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:20; 哥林多前书 7:10–11; 罗马书 7:3"> 因为你有过五个丈夫了，现在和你在一起的也不是你丈夫。你说的是实话。”</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 约翰福音 6:14; 约翰福音 9:17"> 妇人说：“先生，我看你一定是先知。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 12:6–7; 申命记 27:12; 申命记 11:29"> 我们的祖先一向都是在这山上敬拜上帝，你们却说耶路撒冷才是敬拜的地方。”</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 2:8; 玛拉基书 1:11; 约翰福音 4:23"> 耶稣回答说：“妇人，你要信我。时候快到了，你们将不在这山上或耶路撒冷敬拜父。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 17:23; 以赛亚书 2:3; 罗马书 9:4–5"> 你们不知道你们敬拜的是谁，我们知道我们敬拜的是谁，因为救恩是从犹太人出来的。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:3; 约翰福音 5:25; 马太福音 15:7–9"> 时候快到了，现在就是，真正敬拜父的，要用心灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“用心灵”或译“靠圣灵”；24节同。">a</a></sup>、按真理敬拜祂，因为父寻找的正是这样敬拜祂的人。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 3:17; 马太福音 15:8–9; 腓立比书 3:3"> 上帝是灵，所以必须用心灵、按真理敬拜祂。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:49; 但以理书 9:24–26; 约翰福音 1:41–42"> 妇人说：“我知道那被称为基督的弥赛亚要来。祂来了，会把一切都告诉我们。”</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:24; 马可福音 14:61–62; 罗马书 10:20–21"> 耶稣说：“我这位跟你说话的就是。”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 约翰福音 4:8–9"> 这时，门徒回来了，看见耶稣和一个妇人谈话，感到惊奇，可是没有人问：“你想要什么？”或问：“你为什么和她说话？”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:7; 路加福音 24:33; 马可福音 16:8–10"> 那妇人撇下水罐，回到城里，对人们说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 22:17; 哥林多前书 14:24–25; 约翰福音 4:25"> “你们快来看啊！有一个人把我做过的事都说了出来。莫非祂就是基督？”</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 5:20; 使徒行传 8:5–8; 路加福音 17:16–18"> 众人听了就到城外去见耶稣。</span>
</div>
</div>

## 撒种与收割

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:38; 创世记 24:33; 使徒行传 16:30–34"> 其间，门徒对耶稣说：“老师，请吃点东西吧。”</span>
<span className="v" id="v32" data-v="32" data-xref="约伯记 23:12; 诗篇 119:103; 约翰福音 4:34"> 耶稣说：“我有食物吃，是你们不知道的。”</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 16:6–11; 路加福音 9:45"> 门徒彼此议论说：“难道有人给祂吃的了？”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 6:38; 约翰福音 5:30; 约伯记 23:12"> 耶稣说：“我的食物就是遵行差我来者的旨意，完成祂的工作。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 马太福音 9:37–38; 约翰福音 4:30"> 你们不是说还有四个月才到收割的时候吗？举目向田观看吧，庄稼已经熟了，可以收割了。</span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 5:19–20; 罗马书 1:13; 哥林多前书 3:5–9"> 收割的人可以得到报酬并为永生收获果实，叫撒种的和收割的一同快乐。</span>
<span className="v" id="v37" data-v="37" data-xref="弥迦书 6:15; 约伯记 31:8; 路加福音 19:21"> 俗语说得好，‘那人撒种，这人收割。’</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 1:7; 历代志下 36:15; 使徒行传 10:42–43"> 我派你们去收割那些你们没有劳作的庄稼，别人劳苦，你们享受他们劳苦的成果。”</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 4:29; 约翰福音 4:5; 约翰福音 10:41–42"> 那城里有许多撒玛利亚人信了耶稣，因为那妇人做见证说：“祂把我做过的事都说了出来。”</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 3:20; 使徒行传 16:15; 路加福音 24:29"> 撒玛利亚人来见耶稣，恳求祂留下来，祂就在那里住了两天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前书 2:4–5; 使徒行传 1:8; 使徒行传 8:12"> 因为耶稣传的道，信的人更多了。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:14; 约翰福音 1:29; 约翰一书 5:20"> 他们对那妇人说：“现在我们信，不再是因为你的话，而是我们亲耳听见了，知道祂真是世人的救主。”</span>
</div>
</div>

## 耶稣治好大臣的儿子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:13; 罗马书 15:8; 马可福音 7:27–28"> 两天后，耶稣动身前往加利利。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 13:57; 路加福音 4:24; 马可福音 6:4"> 祂以前说过：“先知在本乡不受人尊敬。”</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 2:23; 约翰福音 2:13–16; 申命记 16:16"> 然而，祂回到加利利却受到当地人欢迎，因为他们上耶路撒冷过节时，看见了祂的一切作为。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 2:1–11; 路加福音 7:2; 何西阿书 5:15"> 祂又到了加利利的迦拿，就是祂从前把水变成酒的地方。有一个大臣的儿子在迦百农患了病。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 4:3; 约翰福音 11:21; 约翰福音 11:32"> 大臣听说耶稣从犹太来到加利利，立刻赶来见祂，求祂去医治他病危的儿子。</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 20:29; 希伯来书 2:4; 哥林多前书 1:22"> 耶稣对他说：“你们不看见神迹奇事，总不相信。”</span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:23; 诗篇 88:10–12; 诗篇 40:17"> 大臣说：“先生，趁我的孩子还没死，求你赶快去！”</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 8:13; 马可福音 7:29–30; 罗马书 4:20–21"> 耶稣说：“回去吧，你的儿子好了。”他相信耶稣的话，就回去了。</span>
<span className="v" id="v51" data-v="51" data-xref="列王纪上 17:23; 约翰福音 4:50; 约翰福音 4:53"> 途中遇见奴仆来报信，说他儿子好了，</span>
<span className="v" id="v52" data-v="52"> 他就问什么时候好的。仆人说：“昨天下午一点钟烧就退了。”</span>
<span className="v" id="v53" data-v="53" data-xref="诗篇 107:20; 路加福音 19:9; 使徒行传 16:34"> 他知道正是那时候耶稣对他说：“你的儿子好了。”他和全家都信了。</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 4:45; 约翰福音 2:1–11"> 这是耶稣从犹太回到加利利后行的第二个神迹。</span>

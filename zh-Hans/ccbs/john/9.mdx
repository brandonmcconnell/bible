## 医治生来瞎眼的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶稣在路上看见一个生来瞎眼的人。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 13:2; 约翰福音 9:34; 使徒行传 28:4"> 门徒问耶稣：“老师，这个人生来瞎眼，是因为他犯了罪呢，还是他父母犯了罪呢？”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:4; 约翰福音 11:40; 传道书 9:1–2"> 耶稣说：“不是他犯了罪，也不是他父母犯了罪，而是要在他身上彰显上帝的作为。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:35; 以弗所书 5:16; 约翰福音 4:34"> 趁着白天，我们必须做差我来者的工作，黑夜一到，就没有人能工作了。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:12; 约翰福音 12:46; 使徒行传 13:47"> 我在世上的时候，是世界的光。”</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 8:23; 马可福音 7:33; 启示录 3:18"> 耶稣讲完后，便吐唾沫在地上，用唾沫和泥抹在那人的眼睛上，</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 35:5; 约翰福音 9:11; 约翰福音 11:37"> 对他说：“到西罗亚池去洗洗！”西罗亚是“奉差遣”的意思。那人照着去做，回来的时候已经能看见了。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 2:8; 撒母耳记上 21:11; 路加福音 18:35"> 他的邻居和从前见他乞讨的人说：“他不是那个常坐在这里乞讨的人吗？”</span>
<span className="v" id="v9" data-v="9"> 有人说：“是他。”有人说：“不是他，只是长得像他。” 他不停地说：“我就是那个人。”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 9:26; 约翰福音 9:21; 传道书 11:5"> 他们问：“你的眼睛是怎么好的？”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 9:6–7; 约翰福音 9:27; 耶利米书 36:17"> 他回答说：“有一位叫耶稣的人和泥抹我的眼睛，叫我到西罗亚池子去洗。我照着去做，眼睛就能看见了。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 5:11–13; 出埃及记 2:18–20; 约翰福音 7:11"> 他们问：“那人在哪里？”他说：“我不知道。”</span>
</div>
</div>

## 盘问眼睛得医治的事

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:57; 约翰福音 11:46–47; 约翰福音 12:42"> 他们就把这个从前瞎眼的人带到法利赛人那里。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:9; 路加福音 13:10–17; 马太福音 12:1–14"> 耶稣和泥开他眼睛那天是安息日。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:26–27; 约翰福音 9:10–11"> 法利赛人也查问他的眼睛是怎么看见的。他回复说：“祂把泥抹在我的眼睛上，我去一洗，眼睛就看见了。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:43; 约翰福音 10:19; 马太福音 12:2"> 有些法利赛人说：“这人不是从上帝那里来的，因为祂不守安息日。”有些人却说：“罪人怎能行这样的神迹呢？”他们就争论起来。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:19; 约翰福音 6:14; 使徒行传 3:22–26"> 于是，他们又问那个瞎眼的人：“既然祂开了你的眼睛，你认为祂是什么人？” 他说：“祂是先知。”</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 3:15–19; 约翰福音 5:44; 以赛亚书 26:11"> 犹太人不相信他以前瞎眼，现在看见了，便叫来他的父母，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:8–9; 使徒行传 4:14; 使徒行传 3:10"> 问他们：“这是你们的儿子吗？你们说他生来瞎眼，现在怎么能看见了？”</span>
<span className="v" id="v20" data-v="20"> 他父母回答说：“我们知道他是我们的儿子，生来瞎眼。</span>
<span className="v" id="v21" data-v="21"> 至于他现在怎么能看见了，我们就不知道了。是谁治好了他，我们也不知道。他现在已经长大成人，你们可以去问他，他自己可以回答。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 7:13; 约翰福音 16:2; 路加福音 6:22"> 他父母因为害怕那些犹太人，所以才这样说，因为那些犹太人早就商量好了，谁承认耶稣是基督，就把谁赶出会堂。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 9:21"> 因此他父母才说他已经长大成人，叫他们去问他。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 7:19; 约翰福音 9:16; 约翰福音 8:49"> 法利赛人又把那个从前瞎眼的人叫来，对他说：“你应该把荣耀归给上帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这是古时叫人在上帝面前起誓说实话的惯用语，参见约书亚记7:19。">a</a></sup>！我们知道那个人是罪人。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 5:10; 约翰福音 9:30; 约翰福音 5:11"> 他说：“祂是不是罪人，我不知道；我只知道我本来瞎眼，现在能看见了。”</span>
<span className="v" id="v26" data-v="26"> 他们就问他：“祂向你做了些什么？祂是怎样治好你眼睛的？”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:67; 约翰福音 9:10–15"> 他回答说：“我已经告诉过你们了，你们不听，为什么又想听呢？难道你们也想做祂的门徒吗？”</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 2:17; 约翰福音 7:19; 马太福音 27:39"> 他们就骂他：“你才是祂的门徒！我们是摩西的门徒。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:14; 民数记 12:2–7; 使徒行传 7:35"> 我们知道上帝曾对摩西讲话，至于这个人，我们不知道祂是从哪里来的。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:37; 诗篇 119:18; 以赛亚书 29:18"> 那人说：“祂开了我的眼睛，你们竟不知道祂从哪里来，真是奇怪。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 15:29; 以赛亚书 1:15; 箴言 28:9"> 我们知道上帝不听罪人的祷告，只听那些敬拜祂、遵行祂旨意者的祷告。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 64:4; 启示录 16:18; 约伯记 20:4"> 从创世以来，从未听过有人能把生来瞎眼的人治好。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 9:16; 约翰福音 3:2; 使徒行传 5:38–39"> 这个人如果不是从上帝那里来的，就什么也不能做。”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 9:22; 约翰福音 9:2; 以赛亚书 66:5"> 法利赛人斥责他：“你这生来就深陷罪中的家伙，居然敢教导我们！”于是把他赶了出去。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 20:31; 约翰一书 5:13; 约翰福音 10:36"> 耶稣听说了这事，后来祂找到这个人，对他说：“你信人子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“人子”有古卷作“上帝的儿子”。">b</a></sup>吗？”</span>
<span className="v" id="v36" data-v="36" data-xref="罗马书 10:14; 雅歌 5:9; 约翰福音 1:38"> 他说：“先生，谁是人子？我要信祂。”</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 4:26; 诗篇 25:8–9; 约翰福音 14:21–23"> 耶稣说：“你已经看见祂了，现在跟你说话的就是祂。”</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 14:33; 马太福音 28:9; 路加福音 24:52"> 他说：“主啊！我信！”他就敬拜耶稣。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 3:19; 约翰福音 12:46; 使徒行传 26:18"> 耶稣说：“我为了审判来到这世界，使瞎眼的可以看见，使看得见的反成了瞎眼的。”</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 3:17; 马太福音 15:12–14; 约翰福音 7:47–52"> 有些跟祂在一起的法利赛人听了这句话，就问：“难道我们也瞎了眼吗？”</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 5:21; 约翰福音 15:22–24; 约翰一书 1:8–10"> 耶稣说：“你们如果是瞎眼的，就没有罪了。但现在你们自称看得见，所以仍然有罪。</span>
</div>

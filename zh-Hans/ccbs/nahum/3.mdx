## 尼尼微的灾祸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 3:1–3; 哈巴谷书 2:12; 何西阿书 4:2"> <span className="pl pl-1">充满血腥的尼尼微有祸了！</span><br /><span className="pl pl-1">城中充满诡诈和掠夺，</span><br /><span className="pl pl-1">害人的事从未止息。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 47:3; 那鸿书 2:3–4; 约伯记 39:22–25"> <span className="pl pl-1">鞭声啪啪，车轮隆隆，</span><br /><span className="pl pl-1">战马奔腾，战车疾驰，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="哈巴谷书 3:11; 以西结书 39:4; 以赛亚书 34:3"> <span className="pl pl-1">骑士冲锋，刀光闪闪，矛枪生辉；</span><br /><span className="pl pl-1">被杀者众多，尸骨成堆，</span><br /><span className="pl pl-1">人们被遍地的尸体绊倒。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 47:9; 以赛亚书 47:12–13; 启示录 17:1–5"> <span className="pl pl-1">这全是因为尼尼微像妖媚的妓女大肆淫乱，</span><br /><span className="pl pl-1">惯行邪术，</span><br /><span className="pl pl-1">以淫行诱惑列国，</span><br /><span className="pl pl-1">靠邪术欺骗各族。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 13:26; 以西结书 23:29; 耶利米书 13:22"> <span className="pl pl-1">万军之耶和华说：</span><br /><span className="pl pl-1">“我与你为敌。</span><br /><span className="pl pl-1">我要把你的衣裙掀到你脸上，</span><br /><span className="pl pl-1">使列国看见你的裸体，</span><br /><span className="pl pl-1">使列邦看见你的羞耻。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 2:9; 耶利米书 51:37; 约伯记 9:31"> <span className="pl pl-1">我要把可憎之物抛在你身上，</span><br /><span className="pl pl-1">羞辱你，</span><br /><span className="pl pl-1">让众人观看。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 15:5; 以赛亚书 51:19; 启示录 18:10"> <span className="pl pl-1">凡看见你的都要逃避，说，</span><br /><span className="pl pl-1">‘尼尼微毁灭了！</span><br /><span className="pl pl-1">谁会为她悲伤呢？’</span><br /><span className="pl pl-1">我到哪里去寻找安慰你的人呢？”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="阿摩司书 6:2; 以西结书 30:14–16; 耶利米书 46:25–26"> <span className="pl pl-1">你能强过底比斯</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“底比斯”希伯来文是“挪亚们”。">a</a></sup><br /><span className="pl pl-1">吗？</span><br /><span className="pl pl-1">底比斯位于尼罗河上，</span><br /><span className="pl pl-1">四面环水，</span><br /><span className="pl pl-1">水是她的屏障，</span><br /><span className="pl pl-1">又是她的城墙。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 30:5; 以西结书 27:10; 以赛亚书 20:5"> <span className="pl pl-1">古实和埃及是她无穷的力量，</span><br /><span className="pl pl-1">弗人和利比亚人是她的帮手。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 20:4; 约珥书 3:3; 何西阿书 13:16"> <span className="pl pl-1">可是，她却被掳去，流落他乡，</span><br /><span className="pl pl-1">她的婴孩被摔死在各个街头。</span><br /><span className="pl pl-1">她的官长被抽签瓜分，</span><br /><span className="pl pl-1">她所有的首领都被锁链锁着。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 49:26; 以赛亚书 2:10; 诗篇 75:8"> <span className="pl pl-1">尼尼微啊，</span><br /><span className="pl pl-1">你也必像醉汉一样，</span><br /><span className="pl pl-1">你必寻找藏身之处躲避敌人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 6:13; 以赛亚书 28:4; 哈巴谷书 1:10"> <span className="pl pl-1">你所有的堡垒都像无花果树上的初熟果子，</span><br /><span className="pl pl-1">一摇树，果子就掉进吃者口中。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 51:30; 以赛亚书 19:16; 耶利米书 50:37"> <span className="pl pl-1">看啊，</span><br /><span className="pl pl-1">你的军队就像柔弱的女人，</span><br /><span className="pl pl-1">你境内的关口向敌人敞开，</span><br /><span className="pl pl-1">你的门闩被火烧毁。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="历代志下 32:3–4; 那鸿书 2:1; 历代志下 32:11"> <span className="pl pl-1">你要蓄水以防围困，</span><br /><span className="pl pl-1">要加强防御！</span><br /><span className="pl pl-1">要走进土坑踩泥，</span><br /><span className="pl pl-1">拿起砖模造砖！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约珥书 1:4; 那鸿书 2:13; 那鸿书 3:13"> <span className="pl pl-1">但在那里，火要吞噬你，</span><br /><span className="pl pl-1">刀剑要杀戮你，</span><br /><span className="pl pl-1">要像蝗虫吞没你。</span><br /><span className="pl pl-1">你只管像蝗虫一样繁殖，</span><br /><span className="pl pl-1">如蚱蜢一般增多吧！</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 22:17; 尼希米记 9:23; 耶利米书 33:22"> <span className="pl pl-1">你的商贾多过天上的繁星，</span><br /><span className="pl pl-1">但他们像吃光田地后飞去的蝗虫。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 51:27; 启示录 9:7"> <span className="pl pl-1">你的臣仆像蝗虫，</span><br /><span className="pl pl-1">你的将领像成群的蚱蜢。</span><br /><span className="pl pl-1">它们寒日聚集在墙上，</span><br /><span className="pl pl-1">太阳一出来就飞走了，</span><br /><span className="pl pl-1">无人知道它们的行踪。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 22:17; 诗篇 76:5–6; 耶利米书 50:18"> <span className="pl pl-1">亚述王啊！</span><br /><span className="pl pl-1">你的牧人沉睡，贵族酣眠，</span><br /><span className="pl pl-1">你的百姓分散在群山上，</span><br /><span className="pl pl-1">无人招聚他们。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 1:9; 耶利米哀歌 2:15; 约伯记 27:23"> <span className="pl pl-1">你的创伤无法救治，</span><br /><span className="pl pl-1">你的伤势极其严重。</span><br /><span className="pl pl-1">听见这消息的人必鼓掌欢呼，</span><br /><span className="pl pl-1">因为谁没受过你无休止的暴虐呢？</span></span>
</div>

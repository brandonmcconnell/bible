## 耶和华向尼尼微发怒

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 8:2; 出埃及记 20:5; 诗篇 94:1"> <span className="pl pl-1">耶和华是痛恨不贞、施行报应的上帝。</span><br /><span className="pl pl-1">耶和华施行报应，充满烈怒。</span><br /><span className="pl pl-1">耶和华报应祂的仇敌，向他们发烈怒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 147:5; 出埃及记 34:6–7; 尼希米记 9:17"> <span className="pl pl-1">耶和华不轻易发怒，大有能力。</span><br /><span className="pl pl-1">耶和华断不以有罪的为无罪。</span><br /><span className="pl pl-1">祂行走在旋风和暴风中，</span><br /><span className="pl pl-1">云彩是祂脚下的尘土。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 33:9; 诗篇 106:9; 诗篇 114:5"> <span className="pl pl-1">祂斥责大海，使大海干涸；</span><br /><span className="pl pl-1">祂使一切河流枯竭。</span><br /><span className="pl pl-1">巴珊和迦密的草木凋零，</span><br /><span className="pl pl-1">黎巴嫩的鲜花衰残。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 1:4; 撒母耳记下 22:8; 耶利米书 4:24"> <span className="pl pl-1">在祂面前，群山震动，丘陵消融。</span><br /><span className="pl pl-1">在祂面前，大地隆起，</span><br /><span className="pl pl-1">世界和世上的一切都战栗。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 10:10; 玛拉基书 3:2; 申命记 32:22–23"> <span className="pl pl-1">祂发怒，谁能站立？</span><br /><span className="pl pl-1">祂发烈怒，谁能承受？</span><br /><span className="pl pl-1">祂的愤怒如火焰喷涌而出，</span><br /><span className="pl pl-1">磐石在祂面前崩裂。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 10:27; 提摩太后书 2:19; 耶利米哀歌 3:25"> <span className="pl pl-1">耶和华是良善的，</span><br /><span className="pl pl-1">是人患难时的避难所；</span><br /><span className="pl pl-1">祂看顾那些信靠祂的人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:17; 以赛亚书 8:22; 以西结书 13:13"> <span className="pl pl-1">祂必用滔滔洪水毁灭尼尼微，</span><br /><span className="pl pl-1">把祂的敌人驱逐到黑暗中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 21:11; 箴言 21:30; 诗篇 33:10"> <span className="pl pl-1">尼尼微人啊，</span><br /><span className="pl pl-1">你们为何图谋抵挡耶和华？</span><br /><span className="pl pl-1">祂要彻底毁灭你们，</span><br /><span className="pl pl-1">无需击打两次。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 7:4; 以赛亚书 5:24; 以赛亚书 9:18"> <span className="pl pl-1">你们像纠结的荆棘，</span><br /><span className="pl pl-1">又像酩酊大醉的人，</span><br /><span className="pl pl-1">要如干秸被火烧尽。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="那鸿书 1:9; 历代志下 13:7; 列王纪下 18:13–14"> <span className="pl pl-1">你们中间出来一人，</span><br /><span className="pl pl-1">一个邪恶的阴谋者，</span><br /><span className="pl pl-1">图谋抵挡耶和华。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 30:19; 约珥书 2:19; 以赛亚书 17:14"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">“尽管尼尼微势力强大、人口众多，</span><br /><span className="pl pl-1">但必被铲除，化为乌有。</span><br /><span className="pl pl-1">我的子民啊，我使你们受了苦，</span><br /><span className="pl pl-1">但必不再使你们受苦。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 10:27; 以赛亚书 9:4; 耶利米书 2:20"> <span className="pl pl-1">现在我要打碎他们套在你们颈上的轭，</span><br /><span className="pl pl-1">松开你们身上的锁链。”</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 109:13; 以赛亚书 46:1–2; 弥迦书 5:13"> <span className="pl pl-1">尼尼微啊，</span><br /><span className="pl pl-1">耶和华已发出有关你的命令：</span><br /><span className="pl pl-1">“你的名不会传于后世。</span><br /><span className="pl pl-1">我要摧毁你神庙中雕刻和铸造的偶像。</span><br /><span className="pl pl-1">我要为你掘好坟墓，</span><br /><span className="pl pl-1">因为你毫无用处。”</span></span>
</div>

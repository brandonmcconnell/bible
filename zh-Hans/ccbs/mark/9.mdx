## 登山变象

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; 以赛亚书 33:17; 马太福音 17:1–8"> 六天后，耶稣带着彼得、雅各和约翰单独登上一座高山。耶稣在他们面前改变了形象，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 28:3; 但以理书 7:9; 启示录 7:14"> 衣服洁白放光，世上没有人能把布漂得那么白。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 马太福音 17:3–4; 使徒行传 3:21–24"> 这时，以利亚和摩西向他们显现，他们在跟耶稣谈话。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:23; 约翰福音 14:8–9; 启示录 22:3–4"> 彼得对耶稣说：“老师，我们在这里真好！我们搭三座帐篷吧，一座给你，一座给摩西，一座给以利亚。”</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17; 但以理书 10:15–19; 马可福音 16:5–8"> 其实彼得不知道说什么才好，因为他们都很害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得后书 1:17; 马太福音 3:17; 马可福音 1:11"> 就在这时候，有一朵云彩飘来笼罩他们，云彩中有声音说：“这是我的爱子，你们要听从祂。”</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 10:16; 使徒行传 8:39–40; 路加福音 24:31"> 门徒立刻四处观看，发现没有其他人，只有耶稣和他们在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 12:40; 马太福音 17:9–13; 马可福音 5:43"> 下山的时候，耶稣叮嘱他们在人子从死里复活之前，不要把刚才看见的告诉别人。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 门徒把这话谨记在心，彼此议论“从死里复活”这句话的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="玛拉基书 4:5; 玛拉基书 3:1; 马太福音 11:14"> 他们问耶稣：“律法教师为什么说以利亚必须先来？”</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 53:1–12; 以赛亚书 50:6; 以赛亚书 52:14"> 耶稣回答说：“以利亚固然要先来复兴一切，但为什么圣经上说人子一定会饱受痛苦、遭人蔑视呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 14:3–11; 马太福音 17:12–13; 马太福音 11:14"> 其实我告诉你们，以利亚已经来了，人们却任意对待他，正如圣经的记载。”</span>
</div>
</div>

## 治好污鬼附身的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 马太福音 17:14–20; 路加福音 11:53–54"> 他们与其他门徒会合时，看见一大群人围住门徒，几个律法教师正在跟他们辩论。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:30; 马可福音 9:2–3"> 众人一看到耶稣，都十分惊奇，立刻跑上去问候祂。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 马可福音 8:11"> 耶稣问门徒：“你们跟他们辩论什么？”</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:25; 路加福音 11:14; 约翰福音 4:47"> 人群中有一个人答道：“老师，我带了我的儿子来找你，因为他被哑巴鬼附身。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:19–20; 马可福音 11:23; 马太福音 17:16"> 每次鬼控制他，把他摔在地上，他就口吐白沫，咬牙切齿，全身僵硬。我请你的门徒把鬼赶出去，但他们无能为力。”</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 14:11; 约翰福音 20:27; 民数记 14:27"> 耶稣说：“唉，这不信的世代啊！我要跟你们在一起待多久，容忍你们多久呢？把他带到我这里来吧。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:26; 路加福音 4:35; 约翰福音 8:44"> 他们把那孩子带到耶稣面前。那鬼一见耶稣，就使孩子抽搐，倒在地上打滚，口吐白沫。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:33; 使徒行传 4:22; 马可福音 5:25"> 耶稣问孩子的父亲：“他这样子多久了？”孩子的父亲回答道：“他从小就这样，</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:22–28; 马可福音 5:19; 马太福音 20:34"> 鬼常常将他扔进火里或水里，要害他的命。如果你能，求你怜悯我们，帮助我们吧！”</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 11:40; 希伯来书 11:6; 马可福音 11:23"> 耶稣说：“如果你能？对于相信的人，凡事都有可能！”</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯来书 12:2; 以弗所书 2:8"> 孩子的父亲立刻高喊：“我信！但我信心不足，求你帮助我！”</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:18; 路加福音 9:42; 马可福音 9:15"> 耶稣看见人群都跑了过来，就斥责那污鬼：“你这个聋哑鬼，我命令你从他身上出来，不许再进去！”</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:20; 马可福音 1:26; 马可福音 9:18"> 那鬼发出喊叫，使孩子剧烈地抽搐了一阵，就出来了。孩子躺在地上一动也不动，很多人都说他死了。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 1:31; 使徒行传 3:7; 马可福音 1:41"> 但耶稣拉着他的手扶他起来，他就站了起来。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 17:19–20; 马可福音 7:17; 马太福音 15:15"> 耶稣进屋后，门徒私下问祂：“我们为什么赶不走那鬼呢？”</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 5:15; 但以理书 9:3; 马太福音 17:20"> 耶稣说：“要赶走这类鬼只有靠祷告<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“祷告”有古卷作“祷告和禁食”。">a</a></sup>。”</span>
</div>
</div>

## 再次预言受难

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 17:22–23; 路加福音 9:43–45; 马可福音 6:31–32"> 他们离开那里，途经加利利。耶稣不想任何人知道祂的行踪，</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 16:21; 马可福音 9:12; 路加福音 24:44–46"> 因为祂在教导门徒。祂说：“人子将被交在人手中，被他们杀害，但三天之后，祂必复活。”</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 门徒却不明白这句话的意思，又不敢问祂。</span>
</div>
</div>

## 谁最伟大

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 18:1–5; 希伯来书 4:13; 路加福音 9:46–48"> 他们回到迦百农的住所，耶稣问门徒：“你们一路上争论些什么？”</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 9:50; 马太福音 20:21–24; 马太福音 18:1–5"> 他们都沉默不语，因为刚才他们在争论谁最伟大。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:25–28; 马可福音 10:42–45; 路加福音 22:26"> 耶稣坐下，叫十二个门徒过来，对他们说：“谁想为首，就该在众人中做最小的，做众人的仆人。”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 10:16; 马太福音 19:14–15; 马太福音 18:2"> 祂领了一个小孩子来，叫他站在门徒中间，又抱起他，对他们说：</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 18:3–5; 路加福音 10:16; 马太福音 10:40–42"> “谁为了我的名接待这样一个小孩子，就是接待我；谁接待我，就是接待差我来的那位，而非接待我。”</span>
</div>
</div>

## 警戒犯罪

<div className="bt">
<div className="bp poetry">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; 民数记 11:26–29; 路加福音 11:19"> 约翰对耶稣说：“老师，我们看见有人奉你的名赶鬼，就阻止他，因为他不是跟从我们的。”</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:3; 哥林多前书 13:1–2; 马太福音 13:28–29"> 耶稣说：“不要阻止他，因为没有人奉我的名行过神迹后，会很快毁谤我。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 12:30; 路加福音 11:23"> 不反对我们的，就是支持我们的。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 10:42; 马太福音 25:40; 哥林多前书 15:23"> 我实在告诉你们，有人若因你们属于基督而给你们一杯水喝，也必得到赏赐。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 18:6; 路加福音 17:1–2; 马太福音 18:10"> “不论谁使这样一个小信徒失足犯罪，他的下场比把大磨石拴在他脖子上扔到海里还要惨。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 5:29–30; 马太福音 18:8–9; 马太福音 25:41"> 如果你一只手使你犯罪，就砍掉它！残废着进入永生，胜过双手健全却落入地狱不灭的火中<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="-44 有古卷加“那里虫是不死的，火是不灭的”。">b</a></sup>。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 18:8; 马太福音 5:22; 马可福音 9:43"> 如果你一只脚使你犯罪，就砍掉它！瘸着腿进入永生，胜过双脚健全却被扔进地狱<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="-46 有古卷加“那里虫是不死的，火是不灭的”。">c</a></sup>。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 18:9; 马可福音 9:43; 马太福音 5:22"> 如果你一只眼睛使你犯罪，就剜掉它！独眼进上帝的国，胜过双目健全却被扔进地狱。</span>
<span className="v" id="v48" data-v="48" data-xref="以赛亚书 66:24; 马可福音 9:43–45; 马太福音 25:41"> 在那里，<br /><span className="pl pl-1">“‘虫不会死，</span><br /><span className="pl pl-1">火不会灭。’</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以赛亚书66:24。">d</a></sup></span>
<span className="v" id="v49" data-v="49" data-xref="利未记 2:13; 以西结书 43:24"> “每个人都要被火炼，像被盐腌一样。</span>
<span className="v" id="v50" data-v="50" data-xref="歌罗西书 4:6; 罗马书 12:18; 马太福音 5:13"> 盐本是好的，但如果失去咸味，怎能使它再咸呢？你们里面要有盐，要彼此和睦。”</span>

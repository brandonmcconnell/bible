## 拿撒勒人厌弃耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:16–30; 马太福音 13:54–58; 马太福音 2:23"> 耶稣带着门徒离开那地方，回到自己的家乡。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:15; 约翰福音 6:42; 使徒行传 4:13–14"> 到了安息日，祂开始在会堂里教导人，众人听了都很惊奇，说：“这个人从哪里学来这些本领？祂怎么会有这种智慧？祂怎么会行这样的神迹？</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 马太福音 13:55–57; 约翰福音 6:42"> 这不是那个木匠吗？祂不是玛丽亚的儿子吗？祂不是雅各、约西、犹大、西门的大哥吗？祂的妹妹们不也住在我们这里吗？”他们就对祂很反感。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:44; 路加福音 4:24; 马太福音 13:57"> 耶稣对他们说：“先知到处受人尊敬，只有在本乡、本族、本家例外。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 13:58; 马可福音 9:23; 马可福音 5:23"> 耶稣不能在那里行任何神迹，只把手按在几个病人身上，医治了他们。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:35; 马太福音 8:10; 路加福音 13:22"> 耶稣对他们的不信感到诧异，就去周围的村庄继续教导人。</span>
</div>
</div>

## 差遣十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="传道书 4:9–10; 路加福音 10:17–20; 马太福音 10:1–5"> 耶稣召集了十二个使徒，差遣他们两个两个地出去，赐他们制服污鬼的权柄，</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:3; 马太福音 10:9–10; 路加福音 10:4"> 又吩咐他们路上除了手杖外什么都不要带，不要带食物和背包，腰袋里也不要带钱，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 12:8; 以弗所书 6:15"> 只穿一双鞋和一套衣服就够了。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–8; 路加福音 9:4; 马太福音 10:11–13"> 祂对他们说：“无论什么地方，你们进到哪户人家，就在哪里住下来，一直到离开那地方。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 10:14–15; 使徒行传 18:6; 路加福音 10:10–15"> 如果某地方的人不接待你们，不听你们传的道，你们离开那里时要跺掉脚上的尘土，作为对他们的警告！”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:17; 路加福音 13:3; 使徒行传 20:21"> 使徒便出去传道，劝人悔改，</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:14–15; 马可福音 6:7; 路加福音 10:17"> 赶出许多鬼，为许多病人抹油，治好他们。</span>
</div>
</div>

## 施洗者约翰遇害

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:7–9; 马可福音 6:14–29; 路加福音 23:7–12"> 耶稣声名远扬，希律王也听说了祂的事。有人说：“施洗者约翰从死里复活了，所以能行这些神迹。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 16:14; 玛拉基书 4:5; 马太福音 21:11"> 也有人说：“祂是以利亚。” 还有人说：“祂是个先知，就像古代的一位先知。”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:10–13; 马太福音 27:4; 路加福音 9:9"> 希律听到这些议论，就说：“被我斩首的约翰从死里复活了！”</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 3:19–20; 马太福音 11:2; 路加福音 3:1"> 原来希律娶了他兄弟腓力的妻子希罗底，并为她的缘故而派人逮捕了约翰，把他锁在监牢里。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 20:21; 利未记 18:16; 列王纪上 22:14"> 因为约翰曾对希律说：“你娶弟弟的妻子不合法。”</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 7:9; 以弗所书 4:26–27; 创世记 39:17–20"> 希罗底对约翰怀恨在心，想要杀掉他，只是不能得逞。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 21:26; 马太福音 14:5; 历代志下 24:15–22"> 因为希律知道约翰是个公义圣洁的人，所以敬畏他，并对他加以保护。尽管约翰所讲的道理令他困惑不安，他仍然喜欢听。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 2:18; 创世记 40:20; 彼得前书 4:3"> 机会终于来了。希律在自己的生日那天设宴招待文武百官和加利利的显要。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 1:10–12; 马太福音 14:6; 但以理书 5:2"> 希罗底的女儿进来跳舞，甚得希律和客人的欢心。王对她说：“你想要什么，只管说。”</span>
<span className="v" id="v23" data-v="23" data-xref="以斯帖记 7:2; 以斯帖记 5:3; 以斯帖记 5:6"> 王还对她起誓说：“无论你要什么，哪怕是我的半壁江山，我都会给你。”</span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 31:31; 以西结书 19:2–3; 创世记 27:8–11"> 她便出去问她母亲：“我应该要什么呢？” 她母亲说：“要施洗者约翰的头！”</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:15; 民数记 7:19–89; 民数记 7:13"> 她马上回去向王请求说：“愿王立刻把施洗者约翰的头放在盘子里送给我。”</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:24–25; 马太福音 14:9; 马太福音 27:3–5"> 王听到这个请求，感到十分为难，但因为在众宾客面前起了誓，就不好拒绝。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 14:10–11"> 他立刻命令卫兵进监牢砍了约翰的头，</span>
<span className="v" id="v28" data-v="28"> 放在盘子里送给女孩，她又转送给她母亲。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 14:12; 历代志下 24:16; 马太福音 27:57–60"> 约翰的门徒听到这个消息，就来把约翰的尸体领回去，安葬在坟墓里。</span>
</div>
</div>

## 耶稣使五千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:10; 路加福音 10:17; 马太福音 10:2"> 使徒们聚集在耶稣身边，向祂报告他们一切的工作和教导。</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 3:20; 约翰福音 6:1; 马可福音 1:45"> 耶稣对他们说：“你们单独跟我到荒僻的地方去歇一会儿吧。”因为当时来来往往的人很多，他们连吃饭的时间都没有。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 8:2–9; 马可福音 6:45; 马可福音 4:36"> 他们乘船单独到了一处荒僻的地方。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 6:2; 马太福音 15:29–31; 马可福音 6:54–55"> 可是有许多人看见他们离开，认出了他们，便从各城镇步行赶往那里，比他们先到达。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:36; 路加福音 9:11; 民数记 27:17"> 耶稣一下船，看见这一大群人好像没有牧人的羊，心里怜悯他们，于是教导了他们许多道理。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:5–15; 路加福音 9:12–17; 马太福音 14:15–21"> 天色晚了，门徒过来对耶稣说：“时候已经不早了，这里又是荒郊野外，</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 15:23; 马可福音 3:21; 马可福音 5:31"> 请遣散众人，好让他们到周围的村庄去自己买些吃的。”</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 4:42–44; 马太福音 15:32–33; 马可福音 8:2–3"> 耶稣说：“你们给他们吃的吧。” 门徒说：“难道要我们买二百个银币的饼给他们吃吗？”</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:34; 马可福音 8:5; 约翰福音 6:9"> 耶稣说：“去看看你们有多少饼。” 他们察看后，说：“有五个饼和两条鱼。”</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 14:40; 哥林多前书 14:33; 马太福音 15:35"> 耶稣吩咐门徒叫众人分组坐在草地上。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:14–15"> 于是众人坐下，有的五十人一组，有的一百人一组。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 14:19; 马可福音 7:34; 路加福音 9:16"> 耶稣拿起那五个饼、两条鱼，举目望着天祝谢后，掰开饼递给门徒，让他们分给众人。祂又照样把那两条鱼分给众人。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 9:17; 马可福音 8:8–9; 马太福音 15:37–38"> 大家都吃了，并且吃饱了。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 8:19–20"> 门徒把剩下的碎饼、碎鱼收拾起来，装满了十二个篮子。</span>
<span className="v" id="v44" data-v="44"> 当时吃饼的有五千男人。</span>
</div>
</div>

## 耶稣在湖面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 14:22–33; 约翰福音 6:15–21; 马可福音 6:32"> 耶稣随即催门徒上船，叫他们先渡到湖对岸的伯赛大，祂则遣散众人。</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 1:35; 马太福音 6:6; 路加福音 6:12"> 祂辞别了众人后，就上山去祷告。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 14:23; 约翰福音 6:16–17"> 到了晚上，门徒的船在湖中心，耶稣独自留在岸上。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 24:28; 路加福音 12:38; 约伯记 9:8"> 祂看见门徒在逆风中摇橹，非常吃力。天将破晓的时候，祂从水面上朝门徒走去，想要从他们旁边经过。</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 14:25–26; 路加福音 24:37; 约伯记 9:8"> 门徒看见祂在湖面上走，以为是幽灵，就惊叫起来。</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 14:27; 约翰福音 6:19–20; 以赛亚书 43:2"> 全船的人看见祂，都吓坏了。耶稣立刻对他们说：“放心吧！是我，不要怕。”</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 93:3–4; 马可福音 4:39; 约翰福音 6:21"> 耶稣上船到他们那里，风便停了。门徒心里大为惊奇，</span>
<span className="v" id="v52" data-v="52" data-xref="马可福音 8:17–21; 路加福音 24:25; 以赛亚书 63:17"> 因为他们仍然不明白耶稣分饼的事，心里还是愚顽。</span>
<span className="v" id="v53" data-v="53" data-xref="马太福音 14:34–36; 约翰福音 6:24–25; 路加福音 5:1"> 他们渡到湖对岸，来到革尼撒勒，在那里靠岸，</span>
<span className="v" id="v54" data-v="54" data-xref="诗篇 9:10; 腓立比书 3:10"> 刚一下船，众人立刻认出了耶稣。</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 4:24; 马可福音 2:1–3; 马可福音 3:7–11"> 他们跑遍那一带地方，用垫子把生病的人抬来，听到耶稣在哪里，就把病人抬到哪里。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 9:20; 路加福音 6:19; 民数记 15:38–39"> 耶稣无论到哪一个村庄、城镇或乡下，人们总是把病人抬到街市上，求耶稣让他们摸一摸祂衣服的穗子，所有摸过的病人都好了。</span>
</div>

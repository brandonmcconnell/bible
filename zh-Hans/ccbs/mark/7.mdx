## 传统与诫命

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:1–20; 马可福音 3:22; 路加福音 5:17"> 有法利赛人和一些律法教师从耶路撒冷聚集到耶稣那里。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:28; 马太福音 7:3–5; 罗马书 14:14"> 他们看到祂的一些门徒吃饭前没有照礼仪洗手。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:14; 马可福音 7:13; 歌罗西书 2:8"> 因为法利赛人和所有的犹太人都拘守祖先的传统，总是先照礼仪洗手之后才吃饭；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:10; 马太福音 23:25; 路加福音 11:38–39"> 从市场回来也要先洁净自己，然后才吃饭。他们还拘守许多其他规矩，如洗杯、罐、铜器等。</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 3:6; 使徒行传 21:21; 马太福音 15:2"> 他们质问耶稣：“为什么你的门徒违背祖先的传统，竟用不洁净的手吃饭呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 15:7–9"> 耶稣回答说：“以赛亚针对你们这些伪君子说的预言一点没错，正如圣经上说，<br /><span className="pl pl-1">“‘这些人嘴上尊崇我，</span><br /><span className="pl pl-1">心却远离我。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:13; 马太福音 15:9; 雅各书 1:26"> <span className="pl pl-1">他们的教导无非是人的规条，</span><br /><span className="pl pl-1">他们敬拜我也是枉然。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书29:13。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 7:3–4; 以赛亚书 1:12"> 你们只知拘守人的传统，却无视上帝的诫命。”</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 44:16–17; 加拉太书 2:21; 以赛亚书 29:13"> 耶稣又对他们说：“你们为了拘守传统，竟巧妙地废除了上帝的诫命。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:17; 出埃及记 20:12; 申命记 5:16"> 摩西说，‘要孝敬父母’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及记20:12；申命记5:16。">b</a></sup>，又说，‘咒骂父母的，必被处死。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及记21:17；利未记20:9。">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 23:18; 提摩太前书 5:4–8; 马太福音 15:5"> 你们却认为人若对父母说，‘我把供养你们的钱财已经全部奉献给上帝了’，</span>
<span className="v" id="v12" data-v="12"> 他就可以不再奉养父母。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 7:9; 提多书 1:14; 马太福音 5:17–20"> 你们就是这样为了拘守传统而废除上帝的道，类似的情形还有很多。”</span>
</div>
</div>

## 内心的污秽

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:10; 以赛亚书 6:9; 箴言 8:5"> 耶稣又召集众人，对他们说：“你们都要听我说，也要明白，</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未记 11:42–47; 提多书 1:15"> 从外面进去的不会使人污秽，只有从人里面发出来的才会使人污秽。</span>
<span className="v" id="v16" data-v="16"> 有耳可听的，都应当听！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古卷无16节。">d</a></sup>”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:15; 马太福音 13:36; 马可福音 9:28"> 耶稣离开众人，进了屋子，门徒问祂这比喻的意思。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 15:16–17; 希伯来书 5:11; 以赛亚书 28:9–10"> 耶稣说：“你们也这样糊涂吗？岂不知从外面进去的，不会使人污秽，</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 15:17; 哥林多前书 6:13; 歌罗西书 2:21–22"> 因为不能进入他的心，只能进他的肠胃，最后排进厕所，也就是说所有的食物都是洁净的。”</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 3:6; 雅各书 1:14–15; 雅各书 4:1"> 祂接着说：“从人里面发出来的才使人污秽，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:9; 罗马书 8:7–8; 雅各书 4:1–3"> 因为从里面，就是从人的心里能够生出恶念、苟合、偷盗、谋杀、</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 20:15; 马太福音 6:23; 彼得前书 2:15"> 通奸、贪婪、邪恶、诡诈、放荡、嫉妒、毁谤、骄傲、愚妄。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:15; 提多书 1:15; 哥林多前书 3:17"> 这一切恶事都是从里面生出来的，能使人污秽。”</span>
</div>
</div>

## 外族妇人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 15:21–28; 马太福音 11:21; 以西结书 28:2"> 耶稣从那里启程去泰尔和西顿地区。祂进了一户人家，原本不想让人知道，却无法避开人们的注意。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:22; 马可福音 9:17–23; 使徒行传 10:25–26"> 当时有一个妇人的小女儿被污鬼附身，她听见耶稣的事，就来俯伏在祂脚前，恳求祂赶出她女儿身上的鬼。这妇人是希腊人，来自叙利亚的腓尼基。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:23–28; 马太福音 7:6; 使徒行传 22:21"> 耶稣对她说：“要先让儿女们吃饱，因为把儿女的食物丢给狗吃不合适。”</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 10:12; 罗马书 3:29; 使徒行传 11:17–18"> 妇人说：“主啊，你说的对，但桌子下的狗也吃孩子们掉下来的碎渣呀！”</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 66:2; 马太福音 5:3; 约翰一书 3:8"> 耶稣说：“因为你这句话，你回去吧，鬼已经离开你的女儿了。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 3:8; 约翰福音 4:50–52"> 她回到家里，见女儿躺在床上，鬼已经离开了。</span>
</div>
</div>

## 医治聋哑人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 5:20; 马太福音 15:29–31; 马太福音 4:25"> 耶稣离开泰尔地区，经过西顿，来到低加坡里地区的加利利湖。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 马可福音 5:23; 马太福音 9:32–33"> 有人带着一个又聋又哑的人来见耶稣，恳求祂把手按在这个人身上。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:23; 约翰福音 9:6–7; 马可福音 5:40"> 耶稣就带他离开众人走到一边，用指头伸进他的耳朵，又吐唾沫抹他的舌头，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 11:41; 马可福音 5:41; 马可福音 6:41"> 望天长叹，对他说：“以法大！”意思是“开了吧！”</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 35:5–6; 诗篇 33:9; 马可福音 2:12"> 他的耳朵立刻开了，舌头灵活了，说话也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 8:4; 马可福音 8:26; 马可福音 3:12"> 耶稣吩咐他们不要将这事告诉别人。可是耶稣越是这样吩咐，他们越是极力宣扬，</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 6:51; 马可福音 5:42; 出埃及记 4:10–11"> 听见的人都十分惊奇，说：“祂做的一切都很好，甚至叫耳聋的听见，哑巴说话！”</span>
</div>
</div>

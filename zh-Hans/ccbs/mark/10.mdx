## 论婚姻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马可福音 4:2; 约翰福音 11:7"> 耶稣离开那里，来到犹太地区和约旦河东岸，人群又聚集到祂那里。耶稣照常教导他们。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:10–11; 路加福音 11:53–54; 约翰福音 8:6"> 一些法利赛人想试探耶稣，就来问祂：“男人可以休妻吗？”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:20; 加拉太书 4:21; 路加福音 10:25"> 耶稣反问道：“摩西怎么吩咐你们的？”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 24:1–4; 马太福音 5:31–32; 以赛亚书 50:1"> 他们说：“摩西准许人写休书休妻。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 19:8; 尼希米记 9:26; 使徒行传 7:51"> 耶稣说：“摩西因为你们心里刚硬，才给你们写了这条诫命。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 1:27; 创世记 5:2; 创世记 1:1"> 太初创造时，‘上帝造了男人和女人。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="创世记1:27。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="创世记 2:24; 马太福音 19:5–6; 以弗所书 5:31"> ‘因此，人要离开父母，与妻子结合，</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:28; 创世记 2:24; 哥林多前书 6:16"> 二人成为一体。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="创世记2:24。">b</a></sup>这样，夫妻不再是两个人，而是一体了。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 7:1–3; 历代志上 7:10–13"> 因此，上帝配合的，人不可分开。”</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 9:33; 马可福音 9:28; 马可福音 4:10"> 回到屋里后，门徒追问耶稣这件事。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:31–32; 马太福音 19:9; 哥林多前书 7:10–11"> 耶稣说：“任何人休妻另娶，就是对妻子不忠，是犯通奸罪。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:11; 哥林多前书 7:13"> 同样，妻子若离弃丈夫另嫁，也是犯通奸罪。”</span>
</div>
</div>

## 祝福孩童

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 19:13–15; 路加福音 18:15–17; 出埃及记 10:9–11"> 有人带着小孩子来要让耶稣为他们按手，门徒却责备他们。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 19:14; 马太福音 18:10; 马太福音 18:4"> 耶稣看见后很生气，对门徒说：“让小孩子到我这里来，不要阻止他们，因为上帝的国属于这样的人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:3; 路加福音 18:17; 约翰福音 3:3–6"> 我实在告诉你们，人若不像小孩子一样接受上帝的国，绝不能进去。”</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 9:36; 以赛亚书 40:11; 约翰福音 21:15–17"> 于是，耶稣抱起小孩子，为他们按手祝福。</span>
</div>
</div>

## 永生的代价

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 19:16–30; 路加福音 18:18–30; 罗马书 2:7"> 耶稣正要上路，有一个人跑来跪在祂跟前，问祂：“良善的老师，我该做什么才能承受永生？”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:19; 马太福音 19:17; 罗马书 3:12"> 耶稣说：“你为什么称我是良善的？只有上帝是良善的。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:12–17; 罗马书 13:9; 雅各书 2:11"> 你知道‘不可杀人，不可通奸，不可偷盗，不可作伪证，不可欺诈，要孝敬父母’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及记20:12‑16；申命记5:16‑20。">c</a></sup>这些诫命。”</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 33:31–32; 提摩太后书 3:5; 腓立比书 3:6"> 那人说：“老师，我从小就遵行这些诫命。”</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:19–21; 启示录 2:4; 路加福音 18:22"> 耶稣望着他，心中爱他，便说：“你还差一件事，就是去变卖你所有的产业，送给穷人，你必有财宝存在天上，然后你还要来跟从我。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰一书 2:15–16; 提摩太前书 6:9–10; 路加福音 12:15"> 那人听了，脸色骤变，便沮丧地走了，因为他有许多产业。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:26; 路加福音 18:24; 马可福音 3:5"> 耶稣环顾四周，对门徒说：“有钱人进上帝的国真难啊！”</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 5:1–3; 箴言 11:28; 诗篇 52:7"> 门徒听了感到惊奇，耶稣便再次对他们说：“孩子们，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古卷此处有“依靠钱财的人”。">d</a></sup>进上帝的国真难啊！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 19:24–25; 路加福音 18:25; 马太福音 23:24"> 骆驼穿过针眼比有钱人进上帝的国还容易呢！”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 16:31; 哥林多后书 11:23; 罗马书 10:9–13"> 门徒更加惊奇，便议论说：“这样，谁能得救呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:27; 约伯记 42:2"> 耶稣看着他们说：“对人而言，这不可能，但对上帝而言，凡事都可能。”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 19:27–30; 路加福音 18:28–30; 路加福音 14:33"> 彼得说：“你看，我们已经撇下一切来跟从你了。”</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:23; 马太福音 5:10–11; 马可福音 8:35"> 耶稣说：“我实在告诉你们，任何人为了我和福音而撇下房屋、弟兄、姊妹、父母、儿女或田地，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 18:30; 腓立比书 3:8; 哥林多后书 6:10"> 今世必在房屋、弟兄、姊妹、父母、儿女或田地方面获得百倍的回报，来世必得永生。同时他也会受到迫害。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:30; 路加福音 13:30; 马太福音 20:16"> 然而，许多为首的将要殿后，殿后的将要为首。”</span>
</div>
</div>

## 耶稣第三次预言自己的受难

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 20:17–19; 路加福音 18:31–34; 路加福音 9:51"> 在前往耶路撒冷的路上，耶稣走在众人前面，门徒感到惊奇，其他跟随的人也很害怕。 耶稣又把十二使徒叫到一旁，把自己将要遭遇的事告诉他们，说：</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:2; 马太福音 20:17–19; 马可福音 8:31"> “看啊，我们现在前往耶路撒冷，人子将被交给祭司长和律法教师，他们要判祂死刑，把祂交给外族人。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 26:67; 马太福音 16:21; 马可福音 14:65"> 他们会嘲弄祂，向祂吐唾沫，鞭打祂，杀害祂。但是，三天之后祂必复活！”</span>
</div>
</div>

## 雅各与约翰的请求

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:20–28; 撒母耳记下 14:4–11; 列王纪上 2:20"> 西庇太的两个儿子雅各和约翰上前对耶稣说：“老师，请你答应我们一个要求。”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 15:7; 列王纪上 3:5–15; 马可福音 10:51"> 耶稣问：“什么要求？”</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:28; 马可福音 16:19; 路加福音 24:26"> 他们说：“在你的荣耀中，求你让我们一个坐在你右边，一个坐在你左边。”</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:50; 马太福音 20:21–22; 诗篇 75:8"> 耶稣说：“你们不知道自己在求什么。我要喝的那杯，你们能喝吗？我要受的洗，你们能受吗？”</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 12:2; 启示录 1:9; 约翰福音 17:14"> 他们说：“我们能。” 耶稣说：“我要喝的那杯，你们也要喝；我所受的洗，你们也要受。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:23; 马太福音 25:34; 约翰福音 17:24"> 不过谁坐在我的左右不是我来定，而是为谁预备的，就让谁坐。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 20:24; 箴言 13:10; 罗马书 12:10"> 其他十个门徒听见这事，很生雅各和约翰的气。</span>
<span className="v" id="v42" data-v="42" data-xref="彼得前书 5:3; 路加福音 22:25; 马太福音 20:25"> 于是，耶稣把他们叫来，对他们说：“你们知道，外族人有君王统治他们，有大臣管理他们，</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 23:8–12; 路加福音 14:11; 马可福音 9:35"> 但你们不可这样。你们中间谁想当首领，谁就要做大家的仆人；</span>
<span className="v" id="v44" data-v="44"> 谁想居首位，谁就要做大家的奴仆。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 20:28; 腓立比书 2:5–8; 哥林多后书 8:9"> 因为就连人子也不是来受人服侍，而是来服侍人，并且牺牲性命，作许多人的赎价。”</span>
</div>
</div>

## 治好瞎眼的巴底买

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 18:35–1; 马太福音 20:29–34; 约翰福音 9:8"> 耶稣和门徒来到耶利哥。当耶稣和门徒及一大群人出城的时候，有一个瞎眼的人坐在路旁乞讨，他的名字叫巴底买，是底买的儿子。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 1:24; 马太福音 9:27; 启示录 22:16"> 巴底买一听说是拿撒勒人耶稣，就喊道：“大卫的后裔耶稣啊，可怜我吧！”</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 29:13; 马可福音 7:26–29; 希伯来书 5:7"> 许多人都责备他，叫他不要吵，但他却更加大声喊道：“大卫的后裔啊，可怜我吧！”</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 18:40; 马太福音 20:32–34; 约翰福音 11:28"> 耶稣停下脚步，说：“叫他过来吧。” 他们就对那瞎眼的说：“好了，起来吧，祂叫你呢。”</span>
<span className="v" id="v50" data-v="50" data-xref="腓立比书 3:7–9; 希伯来书 12:1"> 那人丢下外衣，跳了起来，走到耶稣面前。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 18:41–43; 马可福音 10:36; 马太福音 7:7"> 耶稣问他：“你要我为你做什么？” 他说：“老师，我想看见。”</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 9:22; 使徒行传 26:18; 马可福音 8:25"> 耶稣说：“去吧！你的信心救<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“救”或译“医治”。">e</a></sup>了你。”他立刻得见光明，在路上跟从了耶稣。</span>
</div>

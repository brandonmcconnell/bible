## 骑驴进耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1–11; 约翰福音 12:14–19; 路加福音 19:29–40"> 耶稣和门徒将近耶路撒冷，来到橄榄山的伯法其和伯大尼。耶稣派了两个门徒，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 21:2–3; 路加福音 19:30–31"> 并嘱咐说：“你们去前面的村庄，一进村就会看见一头从来没有人骑过的驴驹拴在那里，你们把它解开牵来。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:36; 马可福音 14:15; 诗篇 110:3"> 若有人问你们为什么这样做，就说，‘主要用它，很快会把它送回来。’”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:19; 路加福音 19:32–34; 马太福音 21:6–7"> 他们就去了，果然看见有一头驴驹拴在街道旁一户人家的门外，就解开它。</span>
<span className="v" id="v5" data-v="5"> 旁边站着的几个人就问他们：“你们解开驴驹干什么？”</span>
<span className="v" id="v6" data-v="6"> 门徒依照耶稣的吩咐回答，那些人就让他们牵走了。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 9:9; 路加福音 19:35–36; 马太福音 21:7–8"> 他们把驴驹牵到耶稣那里，把自己的外衣搭在驴背上，耶稣就骑了上去。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 23:40"> 许多人把衣服铺在路上，还有人将田间的树枝砍下来铺在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:25–26; 马太福音 21:9; 马太福音 23:39"> 众人前呼后拥，高喊道：<br /><span className="pl pl-1">“和散那！”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“和散那”原意是“拯救我们”，此处有“赞美”的意思。">a</a></sup><br /><span className="pl pl-1">“奉主名来的当受称颂！”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇118:26。">b</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以西结书 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> <span className="pl pl-1">“那将要来临的我祖大卫的国度当受称颂！”</span><br /><span className="pl pl-1">“和散那归于至高之处的上帝！”</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶稣进了耶路撒冷，来到圣殿，巡视各处。那时天色已晚，耶稣便和十二使徒出城前往伯大尼。</span>
</div>
</div>

## 咒诅无花果树

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:18–22; 马太福音 4:2; 约翰福音 19:28"> 第二天，他们离开伯大尼后，耶稣饿了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 21:19; 路加福音 13:6–9; 以赛亚书 5:7"> 祂远远看见一棵长满叶子的无花果树，就走过去看能否找到果子。到了树下，却什么也找不到，只有叶子，因为当时不是收无花果的季节。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 21:19; 马太福音 7:19; 马太福音 3:10"> 祂对那棵树说：“愿今后无人再吃你的果子！”祂的门徒都听见了这句话。</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 2:13–17; 马太福音 21:12–16; 路加福音 19:45–47"> 他们来到耶路撒冷后，耶稣进入圣殿，赶走里面做买卖的人，推翻兑换钱币之人的桌子和卖鸽子之人的凳子，</span>
<span className="v" id="v16" data-v="16"> 不准人抬着货物穿过圣殿。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 56:7; 耶利米书 7:11; 路加福音 19:46"> 祂教导他们说：“圣经上不是记载‘我的殿必称为万民祷告的殿’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书56:7。">c</a></sup>吗？你们竟把它变成了贼窝。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="耶利米书7:11。">d</a></sup>”</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 7:28; 马可福音 12:12; 马可福音 14:1–2"> 祭司长和律法教师听到这番话后，就策划如何杀害耶稣，只是害怕祂，因为百姓都对祂的教导感到惊奇。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 马可福音 11:11; 约翰福音 12:36"> 到了傍晚，耶稣和门徒去了城外。</span>
</div>
</div>

## 无花果树的教训

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:13; 马可福音 11:14; 约翰福音 15:6"> 早上，他们经过那棵无花果树，看见它连根都枯了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; 马太福音 23:7; 马太福音 25:41"> 彼得想起昨天发生的事，就对耶稣说：“老师，你看！你咒诅的无花果树已经枯了。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 62:8; 约翰福音 14:1; 马可福音 9:23"> 耶稣说：“你们要对上帝有信心。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 17:20; 约翰福音 15:7; 马太福音 21:21"> 我实在告诉你们，不论何人，只要有信心，毫不疑惑，就是对这座山说，‘从这里挪开，投进大海里！’也必定为他成就。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:22; 约翰一书 5:14–15; 约翰一书 3:22"> 所以我告诉你们，你们无论祷告求什么，只要相信已经得到了，就必得到。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:14–15; 歌罗西书 3:13; 以弗所书 4:32"> 你们站着祷告的时候，若想起有人得罪了你们，就要饶恕他。这样，你们天上的父也会饶恕你们的过犯。</span>
<span className="v" id="v26" data-v="26"> 你们如果不饶恕别人，你们天上的父也不会饶恕你们的过犯。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古卷无26节。">e</a></sup>”</span>
</div>
</div>

## 质问耶稣的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 马太福音 21:23–27; 诗篇 2:1–5"> 他们再次回到耶路撒冷。耶稣在圣殿里行走的时候，祭司长、律法教师和长老上前质问祂：</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 2:14; 使徒行传 7:38–39; 民数记 16:3"> “你凭什么权柄做这些事？谁授权给你了？”</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 马太福音 21:24; 以赛亚书 52:13"> 耶稣说：“我要问你们一个问题，你们回答了，我就告诉你们我凭什么权柄做这些事。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 约翰福音 3:25–36; 马可福音 1:1–11"> 约翰的洗礼是从天上来的，还是从人间来的？请回答我！”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:29; 约翰福音 1:34; 马太福音 21:31–32"> 他们彼此议论说：“如果我们说‘是从天上来的’，祂一定会问，‘那你们为什么不信他？’</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 21:46; 马可福音 12:12; 马太福音 14:5"> 但我们如果说‘是从人间来的’，又怕触怒百姓，因为他们都相信约翰真的是先知。”</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 6:9–10; 哥林多后书 4:3–4; 帖撒罗尼迦后书 2:10–12"> 于是，他们回答说：“我们不知道。”耶稣说：“我也不告诉你们我凭什么权柄做这些事。”</span>
</div>
</div>

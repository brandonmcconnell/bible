## 治好被鬼附身的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 马太福音 8:28–34; 马可福音 4:35"> 他们来到湖对岸的格拉森地区。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:23; 以赛亚书 65:4; 马可福音 5:8"> 耶稣刚下船，迎面就遇见一个被污鬼附身的人，是从坟墓里出来的。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 65:4; 路加福音 8:29; 但以理书 4:32–33"> 那人以坟墓为家，没有人能把他捆住，就算用铁链也不行。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 3:7–8"> 因为有人多次用铁链和脚镣锁住他，但他挣断了铁链，砸碎了脚镣。没有人能制服他。</span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 2:7–8; 列王纪上 18:28; 约翰福音 8:44"> 他昼夜在坟场和山野间大喊大叫，又用石头砍自己。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:19; 诗篇 66:3; 路加福音 4:41"> 他远远看见耶稣，就跑过去跪下来拜祂，高声喊道：</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 8:29; 使徒行传 16:17; 马太福音 26:63"> “至高上帝的儿子耶稣啊，我和你有什么关系？看在上帝的份上，求你不要折磨我！”</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 1:25; 马可福音 9:25–26; 使徒行传 16:18"> 原来，耶稣已经对他身上的鬼说：“污鬼，从这人身上出来！”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 马可福音 5:15; 马太福音 26:53"> 耶稣问：“你叫什么名字？” 他说：“我的名字叫‘群’，因为我们是一大群。”</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 3:22; 马可福音 5:13"> 接着污鬼再三哀求耶稣，不要把它们赶出那个地区。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 11:7–8; 以赛亚书 65:4; 以赛亚书 66:3"> 当时有一大群猪在附近山坡上吃食。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:11; 约伯记 1:10–12; 路加福音 22:31–32"> 污鬼就央求耶稣说：“让我们到猪群里去，附在它们身上吧！”</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:22; 彼得前书 3:22; 约伯记 2:6"> 耶稣允许了，污鬼就离开那人，进入猪群。那群猪就一路奔下陡坡，冲进湖里淹死了，约有两千头。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 马太福音 8:33"> 放猪的人逃走了，把这事传遍了城里乡间，人们都跑来看个究竟。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 1:13; 提摩太后书 1:7; 撒母耳记上 6:20–21"> 他们到了耶稣那里，看见那曾被群鬼附身的人神智清醒、衣着整齐地坐在那里，都很害怕。</span>
<span className="v" id="v16" data-v="16"> 目击者把被鬼附身的人和猪群的事告诉了他们，</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 8:34; 马可福音 1:24; 路加福音 8:37"> 他们就请求耶稣离开他们那里。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比书 1:23–24; 马可福音 5:17"> 耶稣上船的时候，那曾被鬼附身的人恳求耶稣让他随行。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 66:16; 约翰福音 4:29; 以赛亚书 38:9–20"> 耶稣没有答应，而是对他说：“回去见你的家人，把主为你所行的奇事和祂怜悯你的经过都告诉他们吧！”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:31; 马太福音 4:25"> 这人就回到低加坡里一带传扬耶稣为他所行的奇事，人们都很惊奇。</span>
</div>
</div>

## 耶稣医治有信心的人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:1; 马可福音 4:1; 路加福音 8:40"> 耶稣再坐船回到对岸，有一大群人在岸边围着祂。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行传 18:8; 马可福音 5:35–36"> 这时来了一个名叫雅鲁的会堂主管，他一见到耶稣便俯伏在祂脚前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 马可福音 16:18"> 迫切恳求说：“我小女儿快要死了，求你去把手按在她身上，医治她，救她一命。”</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 5:31; 马可福音 3:20; 路加福音 7:6"> 耶稣和他同去，一大群人跟着祂，拥挤着祂。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:25–27; 路加福音 8:43–44; 马太福音 9:20–22"> 有一个妇人患血漏病已经十二年，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 30:12–13; 耶利米书 8:22; 诗篇 108:12"> 经过许多医生的诊治，受尽痛苦，耗尽钱财，病情仍没有好转，反而更加严重。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:12; 马太福音 14:36; 使徒行传 5:15"> 她听见耶稣的事，就夹在人群中从耶稣背后摸祂的衣服，</span>
<span className="v" id="v28" data-v="28"> 心想：“我只要摸到祂的衣服，就会痊愈。”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:34; 诗篇 30:2; 马可福音 3:10"> 她的血漏立刻止住了，她感到自己痊愈了。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶稣马上知道有能力从自己身上发出，便在人群中转过身来问：“谁摸了我的衣服？”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 门徒对祂说：“你看，这么多人在你周围挤来挤去，你怎么问谁摸你呢？”</span>
<span className="v" id="v32" data-v="32"> 耶稣环视四周，要找出摸祂的人。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那妇人害怕得发抖，知道在自己身上发生了什么，就上前俯伏在耶稣脚前，将实情说了出来。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 马太福音 9:22; 路加福音 7:50"> 耶稣说：“女儿，你的信心救了你。安心去吧！你的病好了。”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 约翰福音 11:39; 马可福音 5:22"> 耶稣还在说话的时候，有人从雅鲁家赶来，对雅鲁说：“你的女儿已经死了，何必再麻烦老师呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 马太福音 9:28–29; 约翰福音 11:40"> 耶稣听了，就对雅鲁说：“不要怕，只要信。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 9:40; 马可福音 14:33; 哥林多后书 13:1"> 于是，祂带着彼得、雅各和雅各的弟弟约翰去雅鲁家，不准其他人跟着。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:23–24; 路加福音 8:52–53; 马可福音 5:22"> 他们到了会堂主管家，耶稣看见在场的人嚎啕大哭，场面混乱。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 20:10; 帖撒罗尼迦前书 5:10; 帖撒罗尼迦前书 4:13–14"> 耶稣进去问道：“你们为什么乱哄哄地哭叫呢？这孩子没有死，只是睡着了。”</span>
<span className="v" id="v40" data-v="40" data-xref="尼希米记 2:19; 列王纪下 4:33; 马太福音 9:24–25"> 众人都讥笑祂。耶稣让他们全部出去，然后带着女孩的父母和三个门徒进了孩子的房间。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 祂拉着女孩的手说：“大利大，古米！”意思是：“小女孩，我吩咐你起来！”</span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 4:41; 使徒行传 3:10–13; 马可福音 7:37"> 女孩应声而起，开始走动。当时她十二岁。在场的人都惊奇不已。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 8:4; 马太福音 9:30; 马可福音 1:43"> 耶稣郑重叮嘱他们不要把这事张扬出去，又吩咐他们给女孩东西吃。</span>

## 耶稣在彼拉多面前受审

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 清早，祭司长、长老、律法教师和全公会的人商定后，便把耶稣绑起来押送到彼拉多那里。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:2; 马太福音 27:11–14; 提摩太前书 6:13"> 彼拉多问耶稣：“你是犹太人的王吗？”<br />耶稣回答说：“如你所言。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 53:7; 马可福音 15:5; 约翰福音 18:29–31"> 祭司长控告耶稣许多罪。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 19:10; 马太福音 27:13; 马太福音 26:62"> 彼拉多又问道：“你看，他们控告你这么多，你都不回答吗？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 53:7; 撒迦利亚书 3:8; 诗篇 71:7"> 耶稣仍旧一言不发，彼拉多感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:39–40; 使徒行传 25:9; 使徒行传 24:27"> 每逢逾越节，彼拉多都会照惯例按民众的要求释放一个囚犯。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 马太福音 27:16; 路加福音 23:25"> 那时，有一个囚犯名叫巴拉巴，与其他作乱时杀过人的囚犯关在一起。</span>
<span className="v" id="v8" data-v="8"> 百姓聚来，要求彼拉多照惯例释放一个囚犯。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:14–16; 约翰福音 19:4–5; 约翰福音 18:39"> 彼拉多问：“你们要我为你们释放犹太人的王吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多书 3:3; 创世记 4:4–6"> 因为他知道祭司长把耶稣押来是出于嫉妒。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:14; 约翰福音 18:40; 何西阿书 5:1"> 但祭司长却煽动百姓，叫他们要求彼拉多释放巴拉巴。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 23:5–6; 以赛亚书 9:6–7; 撒迦利亚书 9:9"> 彼拉多又问他们：“那么，这位你们称为犹太人之王的，我如何处置呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 他们高喊：“把祂钉在十字架上！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以赛亚书 53:3"> 彼拉多问：“为什么？祂犯了什么罪？”<br />他们却更大声地喊：“把祂钉在十字架上！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 19:1; 马太福音 27:26; 以赛亚书 50:6"> 为了取悦众人，彼拉多释放了巴拉巴，下令将耶稣鞭打后交出去钉十字架。</span>
</div>
</div>

## 耶稣受辱

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 19:9; 马太福音 27:27–31; 约翰福音 18:28"> 于是，士兵把耶稣押进总督府的院子，集合了全营的士兵。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 27:28–30; 约翰福音 19:2–5; 路加福音 23:11"> 他们给祂穿上紫袍，用荆棘编成冠冕戴在祂头上，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:42–43; 马可福音 15:2; 创世记 37:10"> 向祂行礼，并高呼：“犹太人的王万岁！”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:65; 以赛亚书 53:3–5; 路加福音 23:11"> 他们用苇秆打祂的头，向祂吐唾沫，跪拜祂。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 19:16; 马太福音 27:31"> 戏弄完了，就脱去祂的紫袍，给祂穿上原来的衣服，押祂出去钉十字架。</span>
</div>
</div>

## 钉十字架

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:32; 路加福音 23:26; 罗马书 16:13"> 亚历山大和鲁孚的父亲古利奈人西门从乡下来，途经那地方，卫兵就强迫他背耶稣的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 27:33–44; 约翰福音 19:17–27; 路加福音 23:27–38"> 他们把耶稣带到各各他——意思是“髑髅地”，</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:34; 约翰福音 19:28–30; 路加福音 23:36"> 拿没药调和的酒给祂喝，但祂不肯喝。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 约翰福音 19:23–24; 马太福音 27:35–36"> 他们把耶稣钉在十字架上，还抽签分祂的衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 19:14; 马可福音 15:33; 马太福音 27:45"> 他们钉祂十字架的时间是在上午九点钟。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:37; 马太福音 2:2; 约翰福音 19:18–22"> 祂的罪状牌上写着“犹太人的王”。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 马太福音 27:38; 约翰福音 19:18"> 他们还把两个强盗钉在十字架上，一个在祂右边，一个在祂左边，</span>
<span className="v" id="v28" data-v="28"> 这应验了圣经的话：“祂被列在罪犯中。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无28节。">a</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 14:58; 诗篇 109:25; 耶利米哀歌 1:12"> 过路的人都嘲笑祂，摇着头说：“哈，你这要把圣殿拆毁又在三天内重建的人啊，</span>
<span className="v" id="v30" data-v="30"> 救救你自己，从十字架上下来吧！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:23–24; 马太福音 27:41–43; 路加福音 23:35–37"> 祭司长和律法教师也同样嘲讽祂，彼此议论说：“祂救了别人，却救不了自己！</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:44; 路加福音 23:39–43; 撒迦利亚书 9:9"> 以色列的王基督，现在从十字架上下来吧！让我们看看，我们就信了！”与祂同钉十字架的强盗也嘲笑祂。</span>
</div>
</div>

## 耶稣之死

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:45; 路加福音 23:44–45; 阿摩司书 8:9–10"> 正午时分，黑暗笼罩着整个大地，一直到下午三点。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 22:1; 马太福音 27:46; 希伯来书 5:7"> 大约下午三点，耶稣大声呼喊：“以罗伊，以罗伊，拉马撒巴各大尼？”意思是：“我的上帝，我的上帝，你为什么离弃我？”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="诗篇22:1。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:47–49; 马可福音 9:11–13; 马太福音 17:11–13"> 有些站在旁边的人听见了，就说：“听，祂在呼叫以利亚。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马可福音 15:23; 约翰福音 19:28–30"> 有人跑去把一块海绵蘸满酸酒，绑在苇秆上送给祂喝，说：“等着吧，我们看看以利亚会不会救祂下来。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 19:30; 路加福音 23:46; 马太福音 27:50"> 耶稣大叫一声，就断了气。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 10:19–23; 路加福音 23:45; 希伯来书 9:3–12"> 圣殿的幔子从上到下裂成两半。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:54; 路加福音 23:47–48; 马太福音 27:43"> 站在对面的百夫长看见耶稣喊叫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷无“喊叫”二字。">c</a></sup>断气的情形，便说：“这人真是上帝的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 马太福音 27:55–56"> 有些妇女在远处观看，其中有抹大拉的玛丽亚、小雅各和约西的母亲玛丽亚并撒罗米。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 马太福音 27:55–56"> 耶稣在加利利时，她们就跟随祂、服侍祂了。此外还有好些跟着祂上耶路撒冷的妇女。</span>
</div>
</div>

## 安葬耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 约翰福音 19:38–42; 约翰福音 19:31"> 那天是犹太人的预备日，也就是安息日的前一天。傍晚，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 亚利马太人约瑟鼓起勇气去见彼拉多，要求领取耶稣的遗体。他是一位德高望重的公会议员，一直在等候上帝的国。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 19:31–37"> 彼拉多听见耶稣已经死了，十分惊讶，便把百夫长召来问个明白，</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 27:58; 约翰福音 19:38; 马可福音 15:39"> 得知耶稣确实已死，便将耶稣的遗体交给约瑟。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:9; 马太福音 27:59–60; 以赛亚书 22:16"> 约瑟把耶稣的遗体取下来，用买来的细麻布裹好，安放在一个在岩壁上凿出的墓穴里，又滚来一块大石头堵住墓口。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 15:40; 马可福音 16:1; 路加福音 23:55–2"> 抹大拉的玛丽亚和约西的母亲玛丽亚都看到了安葬耶稣的地方。</span>
</div>
</div>

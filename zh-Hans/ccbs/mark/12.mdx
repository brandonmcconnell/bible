## 凶狠的佃户

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:1–4; 马可福音 13:34; 雅歌 8:11–12"> 耶稣用比喻对他们说：“有人开垦了一个葡萄园，在四周围上篱笆，又在园中挖了一个榨酒池，建了一座瞭望台，然后把葡萄园租给佃户，就出远门了。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:1–8; 希伯来书 1:1; 耶利米书 44:4"> “到了收获的季节，园主派奴仆去佃户那里收取他的那份果实。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 2:15; 尼希米记 9:26; 耶利米书 29:26"> 佃户却抓住奴仆，打了他一顿，使他空手而归。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> “园主又派另一个奴仆去。这一次，佃户不但把他打得头破血流，还侮辱他。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:6; 马太福音 23:37; 尼希米记 9:30"> 园主再派一个奴仆前往，他们却把他杀掉了。园主后来派去的人不是挨打，就是被杀。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 1:1–2; 马太福音 3:17; 约翰福音 1:34"> 最后只剩下园主的爱子，园主就派他去，以为那些佃户会尊重他的儿子。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:20; 马太福音 2:16; 使徒行传 2:23"> 可是佃户却彼此商量说，‘这是产业继承人。来吧！我们杀掉他，产业就归我们了。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="马太福音 21:39; 路加福音 20:15; 马太福音 21:33"> “于是他们抓住他，杀了他，把他扔到葡萄园外。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 10:20–12; 马太福音 21:43; 路加福音 19:27"> 那么，园主会怎么做？他必来杀掉这些佃户，把葡萄园租给别人。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 118:22–23; 彼得前书 2:7–8; 以赛亚书 28:16"> 圣经上说，<br /><span className="pl pl-1">“‘工匠丢弃的石头已成了房角石。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:23; 使徒行传 3:12–16; 哈巴谷书 1:5"> <span className="pl pl-1">这是主的作为，</span><br /><span className="pl pl-1">在我们看来奇妙莫测。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="诗篇118:22、23。">a</a></sup><br />你们没有读过这段经文吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:18; 马太福音 22:22; 约翰福音 7:44"> 他们听出这比喻是针对他们说的，就想逮捕耶稣，但又害怕百姓，只好离开了。</span>
</div>
</div>

## 纳税给凯撒的问题

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 马可福音 3:6"> 后来，他们派了几个法利赛人和希律党人到耶稣那里，企图利用祂所说的话设计陷害祂。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:4; 路加福音 20:22; 约翰福音 7:18"> 他们上前对耶稣说：“老师，我们知道你诚实无伪，不徇情面，因为你不以貌取人，而是按真理传上帝的道。那么，向凯撒纳税对不对呢？</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 17:2; 启示录 2:23; 马可福音 10:2"> 我们该不该纳呢？”耶稣看破他们的阴谋，就说：“你们为什么试探我呢？拿一个银币来给我看。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 启示录 3:12; 马太福音 22:19–22"> 他们就拿来一个银币，耶稣问他们：“上面刻的是谁的像和名号？”<br />他们说：“凯撒的。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 彼得前书 2:17; 哥林多后书 5:14–15"> 耶稣说：“属于凯撒的东西应该给凯撒，属于上帝的东西应该给上帝。”<br />他们听了这话，都很惊奇。</span>
</div>
</div>

## 论复活

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 22:23–33; 使徒行传 4:1–2; 使徒行传 23:6–9"> 撒都该人向来不相信有复活的事，他们来问耶稣：</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 25:5–10; 路得记 4:5; 路得记 1:11–13"> “老师，摩西为我们写下律例，如果一个人死了，留下妻子，又没有儿女，他的兄弟就当娶嫂嫂，替哥哥传宗接代。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 22:25–28; 路加福音 20:29–33"> 有弟兄七人，老大结了婚，没有孩子就死了。</span>
<span className="v" id="v21" data-v="21"> 二弟把大嫂娶过来，也没有生孩子就死了，三弟也是一样，</span>
<span className="v" id="v22" data-v="22"> 七个人都没有留下孩子。最后，那女人也死了。</span>
<span className="v" id="v23" data-v="23"> 那么，到复活的时候，她将是谁的妻子呢？因为七个人都娶过她。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 20:9; 提摩太后书 3:15–17; 马太福音 22:29"> 耶稣说：“你们弄错了，因为你们不明白圣经，也不知道上帝的能力。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 马太福音 22:30; 约翰一书 3:2"> 死人复活之后，不娶也不嫁，就像天上的天使一样。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 3:2–6; 路加福音 20:37; 创世记 17:7–8"> 关于死人复活的事，你们没有读过摩西书有关火中荆棘的记载吗？上帝对摩西说，‘我是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及记3:6。">b</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 14:9; 罗马书 4:17; 马可福音 12:24"> 上帝不是死人的上帝，而是活人的上帝。你们大错了！”</span>
</div>
</div>

## 最大的诫命

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 有一位律法教师听到他们的辩论，觉得耶稣的回答很精彩，就走过去问道：“诫命中哪一条最重要呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命记 6:4; 路加福音 10:27; 加拉太书 3:20"> 耶稣回答道：“最重要的诫命是，‘听啊，以色列！主——我们的上帝是独一的主。</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 6:5"> 你要全心、全情、全意、全力爱主你的上帝’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命记6:4、5。">c</a></sup>；</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 13:8–9; 马太福音 22:39; 利未记 19:18"> 其次就是‘要爱邻如己’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="利未记19:18。">d</a></sup>。再也没有任何诫命比这两条更重要了。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命记 4:39; 申命记 4:35; 以赛亚书 46:9"> 那位律法教师说：“老师，你说的对，上帝只有一位，除祂以外，别无他神。</span>
<span className="v" id="v33" data-v="33" data-xref="何西阿书 6:6; 弥迦书 6:6–8; 撒母耳记上 15:22"> 我们要全心、全意、全力爱祂，又要爱邻如己。这比一切燔祭等祭物都好。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 4:6; 路加福音 20:40; 马太福音 22:46"> 耶稣见他答得很有智慧，就告诉他：“你离上帝的国不远了。”此后，再没人敢用问题刁难耶稣。</span>
</div>
</div>

## 基督的身份

<div className="bt">
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="路加福音 20:41–44; 马太福音 22:41–45; 马太福音 26:55"> 耶稣在圣殿里教导的时候，问道：“律法教师怎么说基督是大卫的后裔呢？</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 110:1; 希伯来书 1:13; 马太福音 22:43–45"> 大卫自己曾经受圣灵的感动，说，<br /><span className="pl pl-1">“‘主对我主说，</span><br /><span className="pl pl-1">你坐在我的右边，</span><br /><span className="pl pl-1">等我把你的仇敌放在你脚下。’</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="诗篇110:1。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="罗马书 1:3–4; 马太福音 11:25; 马太福音 1:23"> 既然大卫自己称基督为主，基督又怎么会是大卫的后裔呢？”百姓听得津津有味。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:1–7; 路加福音 20:45–47; 路加福音 11:43"> 耶稣又教导他们，说：“你们要提防律法教师，他们爱穿着长袍招摇过市，喜欢人们在大街上问候他们，</span>
<span className="v" id="v39" data-v="39" data-xref="雅各书 2:2–3"> 又喜欢会堂里的上座和宴席中的首位。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 23:13; 路加福音 20:47; 马太福音 23:33"> 他们侵吞寡妇的家产，还假意做冗长的祷告。这种人必受到更严厉的惩罚。”</span>
</div>
</div>

## 穷寡妇的奉献

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 列王纪下 12:9; 约翰福音 8:20"> 然后，耶稣在圣殿的奉献箱对面坐下，看众人怎样奉献。很多财主奉献了大量的钱。</span>
<span className="v" id="v42" data-v="42"> 后来一个穷寡妇来了，投进了相当于一文钱的两个小铜钱。</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多后书 9:6–8; 哥林多后书 8:2; 使徒行传 11:29"> 耶稣叫门徒来，说：“我实在告诉你们，这位穷寡妇比其他人奉献的都多，</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 8:2–3; 约翰一书 3:17; 以斯拉记 2:68–69"> 因为他们不过奉献了自己富余的，但这穷寡妇奉献了她赖以为生的一切。”</span>
</div>

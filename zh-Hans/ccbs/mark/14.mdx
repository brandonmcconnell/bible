## 耶稣受膏

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 7:37–39; 约翰福音 12:1–8; 约翰福音 11:2"> 耶稣在伯大尼患过麻风病的西门家里吃饭的时候，有个女人带了一瓶极贵重的纯哪哒香膏进来，把玉瓶打破，将香膏倒在耶稣头上。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:4–5; 马太福音 26:8–9; 玛拉基书 1:12–13"> 有些人生气地彼此议论说：“何必这样浪费香膏？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:29; 以弗所书 4:28; 哥林多前书 10:10"> 这瓶香膏能卖三百多个银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“三百多个银币”相当于当时人们一年的工钱。">a</a></sup>来周济穷人。”他们就责备那女人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 3:14; 希伯来书 10:24; 希伯来书 13:21"> 耶稣说：“随她吧！何必为难她呢？她在我身上做的是一件美事。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 15:11; 马太福音 26:11; 雅各书 2:14–16"> 因为你们身边总会有穷人，你们随时都可以帮助他们，可是你们身边不会总有我。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 约翰福音 12:7; 马可福音 15:42–1"> 她做了自己能做的。她是为我的安葬做准备，提前用香膏抹了我的身体。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 26:12–13; 马可福音 16:15; 马太福音 24:14"> 我实在告诉你们，无论福音传到世界哪个角落，人们都会传扬这女人的事迹，记念她。”</span>
</div>
</div>

## 最后的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 12:6; 出埃及记 12:18; 马太福音 26:17–19"> 除酵节的第一天，就是宰杀逾越节羔羊的那天，门徒问耶稣：“你想让我们去哪里为你预备逾越节吃的晚餐呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 22:10–13; 马太福音 26:18–19; 路加福音 19:30–33"> 耶稣就派了两个门徒，并嘱咐他们：“你们进城会看到一个人带着一瓶水迎面而来，你们就跟着他。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 3:20; 马可福音 11:3; 约翰福音 13:13"> 他进哪一家，你们就对哪一家的主人说，‘老师问：祂的客房在哪里？祂要和门徒在里面吃逾越节的晚餐。’</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 1:13; 诗篇 110:3; 箴言 21:1–2"> 主人会带你们看楼上一间布置整齐的大房间，你们就在那里为我们预备吧。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 16:4; 路加福音 22:13; 路加福音 22:35"> 两个门徒出去，进了城，所遇见的果然和耶稣所说的一样。他们就预备了逾越节的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:14; 约翰福音 13:21–26; 马太福音 26:20–24"> 傍晚，耶稣和十二使徒来了。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 约翰福音 6:47; 约翰福音 6:70"> 用餐的时候，耶稣说：“我实在告诉你们，你们中间有一个人要出卖我，他正和我同桌吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:21–23; 马太福音 26:22; 约翰福音 13:22"> 他们感到忧伤，一个一个地问耶稣：“不是我吧？”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 13:26; 马太福音 26:23; 约翰福音 6:71"> 耶稣说：“是你们十二个人中的一个，他现在正和我一起在碗里蘸饼吃。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:24–25; 以赛亚书 53:1–12; 约翰福音 19:28"> 人子要离世了，正如圣经对祂的记载，但那出卖人子的人有祸了，他还不如不生在这世上！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 26:26–29; 马可福音 14:24; 哥林多前书 10:16–17"> 他们吃的时候，耶稣拿起饼来，祝谢后，掰开分给门徒，说：“拿去吃吧！这是我的身体。”</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 14:22; 马太福音 26:27; 哥林多前书 10:16"> 接着祂又拿起杯来，祝谢后，递给他们，他们都喝了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 9:11; 出埃及记 24:8; 启示录 7:9–17"> 耶稣说：“这是我为万人所流的立约之血。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 26:29; 诗篇 104:15; 路加福音 22:16–18"> 我实在告诉你们，从今天起，一直到我在上帝的国喝新酒的那天之前，我不会再喝这葡萄酒。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:30; 路加福音 22:39; 使徒行传 16:25"> 他们唱完圣诗，就出门去了橄榄山。</span>
</div>
</div>

## 客西马尼园的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 14:36; 马可福音 14:39; 诗篇 18:5–6"> 他们到了客西马尼，耶稣对门徒说：“你们坐在这里，我要去祷告。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:44; 希伯来书 5:7; 马可福音 5:37"> 于是耶稣带着彼得、雅各和约翰一起去。祂极其忧伤和难过，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 12:27; 马可福音 13:35–37; 彼得前书 5:8"> 说：“我心里非常忧伤，几乎要死，你们留在这里警醒。”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 14:41; 申命记 9:18; 希伯来书 5:7"> 耶稣往前走了不远，俯伏在地祷告：如果可以的话，不要让那时刻临到祂。</span>

<span className="v" id="v36" data-v="36" data-xref="加拉太书 4:6; 罗马书 8:15–16; 约翰福音 5:30"> 祂说：“阿爸，父啊，你无所不能，求你撤去此杯。然而，愿你的旨意成就，而非我的意愿。”</span>

<span className="v" id="v38" data-v="38" data-xref="马太福音 26:41; 马太福音 24:42; 路加福音 21:36"> 你们要警醒祷告，免得陷入诱惑。你们的心灵虽然愿意，肉体却很软弱。”</span>

<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 26:42–44; 哥林多后书 12:8; 马太福音 6:7"> 耶稣又去祷告，所祈求的跟上次一样。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 9:33–34; 罗马书 3:19; 创世记 44:16"> 祂回来时见他们又睡着了，因为他们困得眼皮发沉，也不知道对祂说什么。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:35; 马可福音 9:31; 约翰福音 17:1"> 祂第三次祷告回来后，对他们说：“你们还在睡觉休息吗？够了，时候到了，看啊，人子要被交在罪人手中了。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:46; 约翰福音 18:1–2"> 起来，我们走吧。看啊，出卖我的人已经来了！”</span>
</div>
</div>

## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约翰福音 18:3–11; 路加福音 22:47–53; 马太福音 26:47–56"> 耶稣还在说话的时候，十二使徒中的犹大来了，同来的还有祭司长、律法教师和长老派来的一群拿着刀棍的人。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 26:48–50; 箴言 27:6; 诗篇 55:20–21"> 出卖耶稣的犹大预先和他们定了暗号，说：“我亲吻谁，谁就是耶稣，你们把祂抓起来，小心押走。”</span>
</div>
<div className="bp">

<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马可福音 14:27; 约翰福音 16:32; 诗篇 88:18"> 那时，所有门徒都丢下祂逃走了。</span>

## 彼得三次不认耶稣

<div className="bt">
<div className="bp">

<span className="v" id="v67" data-v="67" data-xref="马可福音 14:54; 马可福音 10:47; 马太福音 2:23"> 见彼得在烤火，打量了他一番，说：“你也跟拿撒勒人耶稣是一伙的。”</span>

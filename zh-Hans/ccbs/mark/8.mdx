## 耶稣使四千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:32–39; 马可福音 6:34–44"> 那时，又有一大群人聚在一起，他们没有东西吃。耶稣就叫来门徒，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36; 弥迦书 7:19; 诗篇 103:13"> “我怜悯这些人，他们跟我在一起已经三天，没有任何吃的了。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:31; 士师记 8:4–6; 撒母耳记上 30:10–12"> 如果我让他们饿着肚子回家，他们在路上会体力不支，因为有些人是远道而来的。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 4:42–44; 列王纪下 7:2; 马可福音 6:52"> 门徒说：“在这荒郊野外，如何找到足够的食物给这些人吃呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 14:15–17; 马太福音 15:34; 路加福音 9:13"> 耶稣问：“你们有多少饼？”<br />门徒答道：“七个。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:17; 马太福音 15:35–36; 约翰福音 6:10–11"> 耶稣便吩咐众人坐在地上，然后拿着那七个饼祝谢后，掰开，递给门徒，让门徒分给众人，门徒就把饼分给众人。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:19; 约翰福音 21:5; 路加福音 24:41–42"> 他们还有几条小鱼。耶稣祝谢了，叫门徒分给众人。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 4:42–44; 诗篇 145:16; 马太福音 16:10"> 大家都吃了，并且吃饱了，剩下的零碎装满了七个筐子。</span>
<span className="v" id="v9" data-v="9"> 吃的人约有四千。耶稣让众人回家后，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:39"> 随即和门徒上船，来到大玛努他地区。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:9; 马太福音 12:38; 申命记 6:16"> 法利赛人出来盘问耶稣，要求祂从天上显一个神迹，好试探祂。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:39–40; 马可福音 7:34; 马太福音 16:4"> 耶稣深深叹息道：“这世代的人为什么总是要看神迹呢？我实在告诉你们，没有神迹给这世代的人看。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 12:36; 使徒行传 13:45–46; 诗篇 81:12"> 然后，耶稣离开他们，乘船回对岸去了。</span>
</div>
</div>

## 防备法利赛人和希律的酵

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:5"> 门徒忘了带饼，船上只有一个饼。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 5:6–8; 马太福音 16:6; 马太福音 16:11–12"> 耶稣警告他们：“你们要谨慎，要提防法利赛人和希律的酵！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 马太福音 16:7–8"> 他们彼此议论说：“这是因为我们没有带饼吧。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:52; 以赛亚书 63:17; 马可福音 2:8"> 耶稣知道他们的心思，就说：“你们为什么议论没有带饼的事呢？你们还不明白、不领悟吗？你们的心还是愚顽吗？</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 28:26–27; 马太福音 13:14–15; 耶利米书 5:21"> 你们有眼不会看，有耳不会听吗？你们不记得吗？</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 马太福音 14:17–21; 约翰福音 6:5–13"> 我掰开五个饼分给五千人吃的时候，你们捡了多少篮的零碎呢？”<br />门徒答道：“十二篮。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:34–38; 马可福音 8:1–9"> 耶稣又说：“我用七个饼喂饱四千人的时候，你们捡了多少筐零碎呢？”<br />门徒答道：“七筐。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:52; 马太福音 16:11–12; 马可福音 8:12"> 耶稣接着说：“你们还不明白吗？”</span>
</div>
</div>

## 治好伯赛大瞎眼的人

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:21; 马可福音 6:45; 路加福音 10:13"> 他们到了伯赛大，有人带来一个瞎眼的人，求耶稣摸他。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:33; 约翰福音 9:6–7; 马可福音 5:23"> 耶稣拉着他的手带他走到村外，吐唾沫在他的眼睛上，并把手按在他身上，问他：“你看见什么了？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 32:3; 以赛亚书 29:18; 哥林多前书 13:9–12"> 他抬头看了看，说：“我看见人们好像一棵棵的树，走来走去。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前书 2:9; 彼得后书 3:18; 箴言 4:18"> 耶稣又把手按在他的眼睛上，他的眼睛便睁开了，视力也恢复了，什么都看得清清楚楚。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 8:4; 马可福音 8:23; 马可福音 5:43"> 耶稣叫他回家，并对他说：“不要再进这个村子了。”</span>
</div>
</div>

## 彼得宣告耶稣是基督

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:13–20; 路加福音 9:18–20"> 耶稣和门徒前往凯撒利亚·腓立比境内的村庄。在路上，祂问门徒：“人们说我是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:21; 马太福音 14:2; 玛拉基书 4:5"> 他们说：“有人说是施洗者约翰，有人说是以利亚，还有人说是其他某位先知。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰一书 4:15; 马太福音 16:15–16; 约翰一书 5:1"> 耶稣又问他们：“那么，你们说我是谁？”<br />彼得回答说：“你是基督！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 马太福音 16:20; 马可福音 9:9"> 耶稣叮嘱他们不可泄露祂的身份。</span>
</div>
</div>

## 耶稣预言自己的受难和复活

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 10:33–34; 约翰福音 2:19; 路加福音 24:26"> 从此，耶稣开始教导他们，人子必须受许多苦，被长老、祭司长和律法教师弃绝，并且被杀害，但必在三天之后复活。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 16:22; 约翰福音 16:25; 约翰福音 16:29"> 耶稣清楚地把这些事告诉了他们，彼得就把祂拉到一边，开始责怪祂。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 4:10; 腓立比书 3:19; 约翰一书 2:15"> 耶稣转身看了看门徒，斥责彼得说：“撒旦，退到我后面去！因为你不考虑上帝的意思，只考虑人的意思。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:38; 路加福音 14:26–27; 约翰福音 10:27"> 祂叫众人和门徒一起过来，对他们说：“人若想跟从我，就当舍己，背起他的十字架跟从我。</span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 2:11–13; 哥林多前书 9:23; 路加福音 17:33"> 因为想救自己生命的，必失去生命；但为了我和福音失去生命的，必得到生命。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 16:26; 路加福音 9:25; 诗篇 49:17"> 人就算赚得全世界，却丧失自己的生命，又有什么益处呢？</span>
<span className="v" id="v37" data-v="37" data-xref="诗篇 49:7–8; 彼得前书 1:18–19"> 人还能拿什么换回自己的生命呢？</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 罗马书 1:16; 约翰一书 2:23"> “在这淫乱、罪恶的世代，如果有人以我和我的道为耻，人子在祂父的荣耀中与圣天使再来的时候，也要以他为耻。”</span>
</div>
</div>

</div>

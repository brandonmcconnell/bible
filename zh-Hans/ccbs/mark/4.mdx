## 撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 马可福音 2:13; 路加福音 8:4–10"> 耶稣又开始在湖边教导，周围聚集了许多人，耶稣只好上到湖边的船上坐下，众人都站在岸上。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 13:34–35; 马可福音 3:23; 马可福音 4:11"> 耶稣用比喻教导他们许多事，在教导中祂说：</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 2:5; 马太福音 13:26; 马可福音 4:26–29"> “听着！有一个农夫出去撒种。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:19; 马可福音 4:15; 马太福音 13:4"> 撒种的时候，有些种子落在路旁，被飞鸟吃掉了；</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 36:26; 路加福音 8:6; 路加福音 8:13"> 有些落在石头地上，因为泥土不深，种子很快就发芽了，</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:11; 耶利米书 17:5–8; 约拿书 4:8"> 然而因为没有根，被太阳一晒就枯萎了；</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 创世记 3:17–18"> 有些落在荆棘丛中，荆棘长起来便把幼苗挤住了，以致不能结出果实；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:5; 歌罗西书 1:6; 马可福音 4:20"> 有些落在沃土里，就发芽生长，结出果实，收成多达三十倍、六十倍、一百倍！”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:15; 马可福音 4:23–24; 启示录 3:22"> 然后祂说：“有耳可听的，都应当听。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:10–17; 马可福音 4:34; 箴言 13:20"> 当耶稣独自一人的时候，十二使徒和追随祂的人来请教比喻的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:25; 路加福音 8:10; 约翰一书 5:20"> 耶稣说：“上帝国的奥秘只让你们知道，对于外人，我全部用比喻，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 6:9–10; 以赛亚书 44:18; 马太福音 13:14–15"> 使他们‘看了又看，却不领悟；听了又听，却不明白，免得他们回心转意，得到赦免。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以赛亚书6:9、10。">a</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 3:19; 马太福音 13:51–52; 马可福音 7:17–18"> 耶稣又对他们说：“你们不明白这个比喻，又怎能明白其他比喻呢？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 8:4; 马太福音 13:19; 马太福音 13:37"> 农夫撒的是上帝的道。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 13:19; 哥林多后书 2:11"> 种子落在路旁，是指人听了道，撒旦立刻过来夺去了撒在他们心里的道。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 6:20; 路加福音 8:13; 马太福音 13:20–21"> 种子落在石头地上，是指人听了道后，立刻欢喜地接受了，</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:6; 帖撒罗尼迦前书 3:3–5; 马太福音 12:31"> 但他们心里没有根基，不过是暂时接受，一旦为道遭受患难或迫害，就立刻放弃了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; 耶利米书 4:3; 马太福音 13:22"> 种子落在荆棘丛中，是指人虽然听过道，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> 但生活的忧虑、钱财的迷惑和其他欲望纷纷进来把道挤住了，以致不能结出果实。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 1:10; 路加福音 8:15; 约翰福音 15:4–5"> 种子落在沃土里，是指人听了道，领受了，又结出果实，收成多达三十倍、六十倍、甚至一百倍。”</span>
</div>
</div>

## 灯的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶稣继续说：“人会把灯拿来放在斗底下或床底下吗？当然不会，他一定会把它放在灯台上。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; 传道书 12:14; 马太福音 10:26–27"> 因为隐藏的事无不显露出来，掩盖的事终会被人知道。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 4:9; 马太福音 11:15; 启示录 2:29"> 有耳可听的，就应当听。”</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 2:1; 路加福音 8:18; 马太福音 7:2"> 耶稣又说：“要好好思想你们所听到的，你们用什么量器量给人，就用什么量器量给你们，甚至要多给你们。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 13:12; 路加福音 8:18; 马太福音 25:28–29"> 因为凡有的，还要给他更多；凡没有的，连他仅有的也要夺去！”</span>
</div>
</div>

## 种子生长的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 13:24; 哥林多前书 3:6–9; 路加福音 8:11"> 祂又说：“上帝的国就像一个人在地上撒种。</span>
<span className="v" id="v27" data-v="27" data-xref="传道书 11:5; 帖撒罗尼迦后书 1:3; 哥林多前书 15:37–38"> 他日出而作，日落而息。种子就在他不知不觉中渐渐发芽长大。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 4:31–32; 何西阿书 6:3; 腓立比书 1:9–11"> 大地会使种子生长，先发苗后吐穗，最终结出饱满的籽粒。</span>
<span className="v" id="v29" data-v="29" data-xref="约珥书 3:13; 马太福音 13:30; 马太福音 13:40–43"> 庄稼成熟后，他就拿起镰刀来收割，因为收成的时候到了。”</span>
</div>
</div>

## 芥菜种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 13:31–32; 路加福音 13:18–21; 耶利米哀歌 2:13"> 耶稣说：“我们拿什么比作上帝的国呢？用什么比喻来解释呢？</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:20; 路加福音 13:18–19; 但以理书 2:44–45"> 上帝的国就像一粒芥菜种。它是世上种子中最小的，</span>
<span className="v" id="v32" data-v="32" data-xref="但以理书 4:20–22; 但以理书 4:10–14; 以西结书 31:3–10"> 但种在地里，却能长得比各样蔬菜都大，有粗大的枝条，可以让飞鸟在它的树荫中栖息。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 13:34–35; 约翰福音 16:12; 希伯来书 5:11–14"> 耶稣用了许多类似的比喻，按照众人所能领悟的给他们讲道。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 16:25; 马可福音 4:10; 马太福音 15:15–20"> 祂总是用比喻对他们讲论，只有单独和门徒在一起的时候，才把一切解释清楚。</span>
</div>
</div>

## 平息风浪

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 8:18; 路加福音 8:22; 路加福音 8:25"> 那天晚上，耶稣对门徒说：“我们渡到对岸去吧。”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 3:9; 马可福音 4:1; 马可福音 5:2"> 他们就离开众人，上了耶稣乘坐的船，带祂一起渡到湖的对岸，还有其他船只跟着去。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 8:23–24; 约伯记 1:19; 路加福音 8:22–23"> 忽然，湖面上狂风大作，波浪撞击船身，船内几乎灌满了水。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 5:7; 希伯来书 4:15; 以赛亚书 54:6–8"> 耶稣却还在船尾枕着枕头睡觉。门徒叫醒了祂，说：“老师，我们快淹死了，你怎么不管呢？”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="诗篇 107:29; 诗篇 89:9; 诗篇 65:7"> 耶稣起来斥责狂风，对着湖面说：“静下来！停下来！”顿时风平浪静了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 8:25; 马太福音 8:26; 马太福音 14:31"> 祂对门徒说：“你们为什么这样害怕呢？你们还是没有信心吗？”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:25; 约伯记 38:11; 诗篇 89:7"> 他们极其害怕，彼此议论说：“祂到底是谁？连风浪都听祂的！”</span>
</div>
</div>

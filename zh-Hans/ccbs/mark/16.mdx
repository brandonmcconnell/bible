## 耶稣复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:56–12; 约翰福音 20:1–10; 马太福音 28:1–10"> 过了安息日，抹大拉的玛丽亚、雅各的母亲玛丽亚和撒罗米买了香料，要去抹耶稣的遗体。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 20:1; 路加福音 24:1; 马太福音 28:1"> 周日清早，太阳刚刚升起，她们就去坟墓那里。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 15:46–47; 马太福音 27:60–66"> 她们彼此议论说：“谁能替我们滚开墓口那块大石头呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:2–4; 路加福音 24:2; 约翰福音 20:1"> 她们抬头一看，见那块大石头已经滚到一旁。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 20:11–12; 路加福音 24:3–5; 约翰福音 20:8"> 她们进了坟墓，看见一位身穿洁白长袍的青年坐在右边，吓了一跳。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17–18; 哥林多前书 15:3–7; 路加福音 24:46"> 那青年对她们说：“不要害怕，你们要找那位被钉十字架的拿撒勒人耶稣吗？祂已经复活了，不在这里。你们看！这是安放祂的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:28; 马太福音 26:32; 马太福音 28:10"> 你们回去，告诉祂的门徒，特别是彼得，‘祂要先你们一步去加利利，你们将在那里见到祂，正如祂以前所说的一样。’”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:22–24; 路加福音 24:9–11; 马可福音 16:5–6"> 她们从坟墓出来，跑走了，战战兢兢，不知所措，什么也没有对别人说，因为她们很害怕。</span>
</div>
</div>

## 耶稣显现

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 20:14–19; 路加福音 8:2; 约翰福音 20:12"> 耶稣在周日清晨复活后，首先向抹大拉的玛丽亚显现，耶稣曾在她身上赶出七个鬼。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:18; 路加福音 24:17; 约翰福音 16:6"> 玛丽亚去告诉那些向来跟耶稣在一起的人，看见他们仍然在哭泣哀悼，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 24:11; 马可福音 16:13–14; 马可福音 9:19"> 就告诉他们耶稣已经复活了，她还看见了耶稣，但他们不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:13–32; 约翰福音 21:14; 约翰福音 21:1"> 此后，有两个门徒在去乡下的路上，看到耶稣变了形象向他们显现。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:25; 路加福音 24:33–35; 约翰福音 20:8"> 他们回去告诉其他门徒，但门徒还是不相信。</span>
</div>
</div>

## 最后的使命

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:5; 路加福音 24:36–43; 希伯来书 3:7–8"> 后来，当十一位门徒在一起吃饭的时候，耶稣向他们显现，责备他们硬着心不信，因为他们不肯相信那些人在祂复活后见过祂。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 28:19; 马可福音 13:10; 使徒行传 1:8"> 耶稣又对他们说：“你们要到世界各地去，向天下人传扬福音。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 11:25–26; 约翰福音 3:36; 罗马书 10:9–14"> 相信并接受洗礼的人必定得救，不信的人必被定罪。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:16; 哥林多前书 12:28; 使徒行传 8:7"> 必有神迹随着信我的人，他们能奉我的名赶鬼，说新的方言，</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 10:19; 雅各书 5:14–15; 使徒行传 28:3–6"> 又能用手拿蛇，万一喝了什么毒物，也不会受害。他们把手按在病人身上，病人就能痊愈。”</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:22; 希伯来书 1:3; 希伯来书 12:2"> 主耶稣说完这些话，就被接到天上，坐在上帝的右边。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4–5; 使徒行传 14:3; 罗马书 15:19"> 门徒出去到处传扬福音，主和他们一同做工，以神迹相伴来证实他们所传的道。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无9-20节。">a</a></sup></span>
</div>
</div>

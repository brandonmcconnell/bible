## 预言圣殿被毁

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:1–51; 以西结书 11:22–23; 以西结书 10:19"> 耶稣走出圣殿的时候，有一个门徒对祂说：“老师，你看！这是多么大的石头，多么宏伟的建筑啊！”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:6; 马太福音 24:2; 列王纪上 9:7–8"> 耶稣说：“你看见这些宏伟的建筑了吗？将来要被完全拆毁，找不到两块叠在一起的石头。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:1; 马可福音 4:34; 马可福音 14:33"> 耶稣面向圣殿坐在橄榄山上，彼得、雅各、约翰和安得烈私下来问祂：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 1:6–7; 马太福音 24:3; 但以理书 12:6"> “请告诉我们，这些事什么时候会发生？有什么预兆？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 2:8; 以弗所书 5:6; 耶利米书 29:8"> 耶稣回答说：“你们要小心，免得被人迷惑。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:22; 耶利米书 23:21–25; 约翰福音 8:24"> 将来会有许多人冒我的名来，说，‘我是基督’，欺骗许多人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 约翰福音 14:27; 马太福音 24:6–7"> “你们听见战争爆发、战讯频传时，不要惊慌，因为这些事必然发生，只是末日还没有到。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 24:8; 以赛亚书 37:3; 诗篇 48:6"> “民族将攻打民族，国家将攻打国家，各处将有地震和饥荒。这些只是灾难<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“灾难”希腊文是“生产之痛”。">a</a></sup>的开始。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:17–18; 约翰福音 16:2; 腓立比书 1:29"> “你们要小心谨慎，因为你们将被送上法庭，并在会堂里被鞭打，又将为了我的缘故在官长和君王面前做见证。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:14; 歌罗西书 1:23; 罗马书 10:18"> 不过，福音一定要先传遍天下。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 马太福音 10:19–21"> 当你们被拘捕，押去受审时，不要先担心该说什么话，到时候赐给你们什么话，你们就说什么话，因为那时候说话的不是你们自己，而是圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> “那时，人将把自己的弟兄置于死地，父亲将把儿子置于死地，儿女将反叛父母，置他们于死地。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 马太福音 10:22; 马太福音 24:13"> 你们将因我的名而被众人憎恨，但坚忍到底的必定得救。</span>
</div>
</div>

## 大灾难

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 9:27; 但以理书 12:11; 但以理书 11:31"> “当你们看见‘那带来毁灭的可憎者’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="但以理书9:27；11:31；12:11。">b</a></sup>站在不当站的地方时（读者须会意），犹太地区的人要逃到山上去；</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯来书 11:7; 腓立比书 3:7–8"> 在屋顶上的人不要下来，不要进屋拿东西；</span>
<span className="v" id="v16" data-v="16"> 在田间的人不要回家取外衣。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿书 9:14"> 那时，孕妇和哺育婴儿的母亲们可就遭殃了！</span>
<span className="v" id="v18" data-v="18"> 你们要祈求上帝使这些事不要在冬天发生，</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 12:1; 约珥书 2:2; 马太福音 24:21"> 因为那是上帝创造天地以来空前绝后的大灾难。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:22; 撒迦利亚书 13:8–9; 以赛亚书 65:8–9"> 如果主不缩短灾期，恐怕没有人能活命，但为了祂的选民，祂已经缩短灾期。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 马太福音 24:23–25; 马太福音 24:5"> 那时，如果有人对你们说，‘看啊，基督在这里！’或说，‘基督在那里！’你们不要相信。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:24; 帖撒罗尼迦后书 2:8–14; 马可福音 13:6"> 因为假基督和假先知将出现，行各种神迹奇事，如果可能，甚至要迷惑上帝的选民。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 3:17; 马可福音 13:5; 约翰福音 14:29"> 你们要小心，我已经把一切预先告诉你们了。</span>
</div>
</div>

## 人子降临

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 13:10; 使徒行传 2:19–20; 启示录 6:12–14"> <span className="pl pl-1">“大灾难过后，</span><br /><span className="pl pl-1">‘太阳昏暗，</span><br /><span className="pl pl-1">月亮无光，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 34:4; 启示录 6:13"> <span className="pl pl-1">星宿陨落，</span><br /><span className="pl pl-1">天体震动。’</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以赛亚书13:10；34:4。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="启示录 1:7; 马太福音 16:27; 马太福音 24:30"> 那时，世人必看到人子驾着云、带着极大的能力和荣耀降临。</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:6; 马太福音 24:31; 申命记 30:4"> 祂必差遣天使从四面八方、天涯海角招聚祂拣选的人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 马太福音 24:32–33"> “你们可以从无花果树学个道理。当无花果树发芽长叶的时候，你们就知道夏天快来了。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 4:17–18; 雅各书 5:9; 以西结书 12:25–28"> 同样，当你们看见这些事情发生时，就知道人子快来了，就在门口。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 24:34; 路加福音 21:32; 马太福音 16:28"> 我实在告诉你们，这个世代还没有过去，这一切都要发生。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 40:8; 以赛亚书 51:6; 马太福音 24:35"> 天地都要消逝，但我的话永不消逝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 1:7; 马太福音 24:36–42; 马太福音 25:13"> “但没有人知道那日子和时辰何时来到，连天上的天使也不知道，人子也不知道，只有天父知道。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:18; 路加福音 12:40; 罗马书 13:11–12"> 你们要小心，保持警醒，因为你们不知道那日子何时来到。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 25:14–30; 约翰福音 10:3; 路加福音 12:36–40"> “这就好像一个人在出远门之前，把家中的事交给仆人，让他们各做各的工作，又吩咐守门的人要警醒。</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 13:33; 马太福音 24:42; 马太福音 24:44"> 所以你们要警醒，因为你们不知道家主什么时候回来，可能是黄昏，可能是夜半，也可能是黎明或早上。</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦前书 5:6–7; 罗马书 13:11–14; 马太福音 24:48–51"> 别让他突然回来时看到你们在睡觉。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 13:33; 路加福音 12:41–46; 马可福音 13:35"> 我劝你们，也劝所有的人，要警醒！”</span>
</div>
</div>

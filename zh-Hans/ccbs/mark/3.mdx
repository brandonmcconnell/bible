## 治好手枯的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:9–14; 路加福音 6:6–11; 马可福音 1:21"> 耶稣又进了会堂，那里有个人一只手是萎缩的。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 37:32; 路加福音 14:1; 路加福音 6:7"> 当时有好些人监视耶稣，看祂会不会在安息日医治这个人，好控告祂。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:28–30; 以赛亚书 42:4; 路加福音 6:8"> 耶稣对那一只手萎缩的人说：“起来，站在中间。”</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 马太福音 12:10–12; 何西阿书 6:6"> 然后问众人：“在安息日应该行善还是作恶？救人还是害人？”他们都不吭声。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所书 4:18; 罗马书 11:25"> 耶稣生气地看着四周这些人，为他们心里刚硬而深感难过。祂对那人说：“把手伸出来！”那人一伸手，手就复原了。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 22:16; 马可福音 12:13; 马太福音 12:14"> 法利赛人立刻出去，跟希律党的人策划怎样除掉耶稣。</span>
</div>
</div>

## 群众跟随耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 4:25; 路加福音 6:17; 马太福音 12:15"> 耶稣和门徒退到湖边，有一大群人从加利利来跟随祂。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 35:15; 以赛亚书 34:5; 马太福音 11:21"> 还有很多人听见耶稣的一切作为，就从犹太、耶路撒冷、以土买、约旦河东，甚至泰尔和西顿一带来找祂。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 5:30; 约翰福音 6:15"> 耶稣见人多，就吩咐门徒为祂预备一条小船，以免人群拥挤祂。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 14:36; 马可福音 6:56; 马太福音 4:23"> 因为祂医治了很多人，凡有疾病的人都想挤过来摸祂。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 马可福音 1:23–24; 路加福音 8:28"> 污鬼一看见祂，就俯伏在祂面前，大喊：“你是上帝的儿子！”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:16; 马可福音 1:25; 马可福音 1:34"> 耶稣却严厉地警告它们不要泄露祂的身份。</span>
</div>
</div>

## 选立十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 马太福音 10:1–4"> 耶稣上了山，把自己想要的人召来，他们就来到祂面前。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:8; 路加福音 9:1–6; 约翰福音 15:16"> 祂从中选出十二人立为使徒，让他们跟随自己，并且差遣他们出去传道，</span>
<span className="v" id="v15" data-v="15"> 赐他们赶鬼的权柄。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:42; 使徒行传 1:13; 马太福音 16:16–18"> 祂设立的十二位使徒是：西门——耶稣给他取名叫彼得、</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 马可福音 14:33; 耶利米书 23:29"> 西庇太的儿子雅各和雅各的兄弟约翰——耶稣给他们取名叫“半尼其”，就是“雷霆之子”的意思、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 1:13; 马可福音 2:14; 马太福音 9:9"> 安得烈、腓力、巴多罗买、马太、多马、亚勒腓的儿子雅各、达太、激进党人西门、</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 6:71; 约翰福音 13:2; 使徒行传 1:16–25"> 及后来出卖耶稣的加略人犹大。</span>
</div>
</div>

## 耶稣和别西卜

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 6:31; 约翰福音 4:31–34; 马可福音 9:28"> 耶稣刚进家门，人群又聚集起来，以致祂和门徒都无暇吃饭。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 26:24; 约翰福音 10:20; 马可福音 3:31"> 祂的亲属听见这个消息，就出来要制止祂，因为他们说祂疯了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:1; 马太福音 10:25; 马太福音 9:34"> 从耶路撒冷下来的律法教师说：“祂被别西卜附身。”又说：“祂是靠鬼王赶鬼。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 马太福音 12:25–30; 马太福音 13:34"> 耶稣叫他们来，用比喻对他们说：“撒旦怎能驱逐撒旦呢？</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 11:14; 以赛亚书 19:2–3; 撒母耳记下 20:6"> 一个国内部自相纷争，必无法坚立。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 3:16; 诗篇 133:1; 加拉太书 5:15"> 一个家内部自相纷争，必无法坚立。</span>
<span className="v" id="v26" data-v="26"> 同样，撒旦如果与自己为敌，自相纷争，就站立不住，必然灭亡。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 49:24–26; 马太福音 12:29; 路加福音 11:21–23"> 没有人能进入壮汉家里抢夺财物，除非先把那壮汉捆绑起来，才能抢劫他的家。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 马太福音 12:31–32; 约翰一书 5:16"> “我实在告诉你们，世人一切的罪和亵渎的话都可以得到赦免，</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 12:31–32; 路加福音 12:10; 帖撒罗尼迦后书 1:9"> 唯有亵渎圣灵的人永远得不到赦免，他们要永远担罪。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:20; 马可福音 3:22"> 耶稣这样说是因为他们诬蔑祂被污鬼附身。</span>
</div>
</div>

## 谁是耶稣的亲人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 马太福音 12:46–50"> 这时候，耶稣的母亲和兄弟来了，他们站在外面，托人叫耶稣。</span>
<span className="v" id="v32" data-v="32"> 有许多人围坐在耶稣身边，他们告诉祂说：“看啊！你的母亲和兄弟在外面找你。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 3:21; 申命记 33:9; 马可福音 6:3"> 耶稣说：“谁是我的母亲？谁是我的兄弟？”</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 12:49–50; 路加福音 11:27–28; 罗马书 8:29"> 然后祂望着周围坐着的人说：“看啊，我的母亲和我的兄弟！</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:17; 马太福音 7:21; 约翰一书 3:22–23"> 凡遵行上帝旨意的人都是我的弟兄、姊妹和母亲。”</span>
</div>
</div>

</div>

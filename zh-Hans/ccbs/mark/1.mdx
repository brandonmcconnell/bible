## 施洗者约翰预备道路

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 5:11–12; 马太福音 4:3; 马太福音 3:17"> 有关上帝的儿子耶稣基督的福音是这样开始的，</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:1; 马太福音 11:10; 路加福音 1:76"> 正如以赛亚先知书上说：<br /><span className="pl pl-1">“看啊，我要差遣我的使者在你前面为你预备道路。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="玛拉基书3:1。">a</a></sup><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3–5; 马太福音 3:3; 路加福音 3:4–6"> <span className="pl pl-1">他在旷野大声呼喊，</span><br /><span className="pl pl-1">‘预备主的道，</span><br /><span className="pl pl-1">修直祂的路。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以赛亚书40:3。">b</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:3–4; 马太福音 3:6; 使徒行传 13:24–25"> 果然，施洗者约翰出现了，他在旷野宣讲悔改就得赦罪的洗礼。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 26:40–42; 使徒行传 19:18; 马太福音 3:5–6"> 犹太全境和耶路撒冷的居民都到约翰那里，承认他们的罪，在约旦河里接受他的洗礼。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 1:8; 利未记 11:22; 马太福音 3:4"> 约翰身穿骆驼毛的衣服，腰束皮带，吃的是蝗虫和野蜜。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 13:25; 路加福音 3:16; 约翰福音 1:27"> 他传道说：“在我之后，有一位比我更有能力的要来，我连弯腰给祂解鞋带都不配。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:5; 哥林多前书 12:13; 使徒行传 19:4–6"> 我是用水给你们施洗，但祂要用圣灵给你们施洗。”</span>
</div>
</div>

## 耶稣受洗

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:13–17; 马太福音 2:23; 路加福音 3:21–22"> 那时，耶稣从加利利的拿撒勒来，在约旦河受了约翰的洗礼。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:31–34; 路加福音 3:22; 以赛亚书 42:1"> 耶稣从水中一上来，就看见天裂开了，圣灵好像鸽子一样降在祂身上，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 42:1; 马可福音 9:7; 马太福音 3:17"> 有声音从天上传来：“你是我的爱子，我喜悦你。”</span>
</div>
</div>

## 耶稣受试探

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:1–11; 路加福音 4:1–13"> 圣灵随即催促祂到旷野。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17–18; 希伯来书 4:15; 出埃及记 34:28"> 祂在旷野受撒旦的试探四十天。祂与野兽在一起，有天使伺候祂。</span>
</div>
</div>

## 呼召四渔夫

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23; 马太福音 4:12; 路加福音 8:1"> 约翰被捕后，耶稣来到加利利宣讲上帝的福音，说：</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:2; 使徒行传 2:36–38; 马太福音 4:17"> “时候到了，上帝的国临近了，你们要悔改，相信福音。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:18–22; 约翰福音 1:40–42; 约翰福音 6:8"> 耶稣沿着加利利湖边走，看见西门和他弟弟安得烈正在向湖里撒网。他们是渔夫。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 5:10; 马太福音 4:19–20; 使徒行传 2:38–41"> 耶稣对他们说：“来跟从我！我要使你们成为得人的渔夫。”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:28–30; 路加福音 5:11; 马可福音 10:28–31"> 他们立刻撇下渔网，跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 5:37; 使徒行传 1:13; 马可福音 10:35"> 耶稣往前走了不远，又看见西庇太的两个儿子雅各和约翰正在船上补网，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 10:37; 路加福音 14:26; 马可福音 10:29"> 便立刻呼召他们。他们就辞别父亲西庇太和船上的雇工，跟从了耶稣。</span>
</div>
</div>

## 传道赶鬼

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:2; 马可福音 1:39; 马太福音 4:23"> 他们到了迦百农，耶稣在安息日去会堂里教导人。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:28–29; 马太福音 13:54; 路加福音 4:32"> 那里的人都很惊奇，因为祂教导他们时像个有权柄的人，不像律法教师。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 9:25; 马可福音 7:25; 马可福音 1:34"> 当时会堂里有一个被污鬼附身的人喊道：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:29; 雅各书 2:19; 使徒行传 3:14"> “拿撒勒的耶稣啊，我们和你有什么关系？你是来毁灭我们吗？我知道你是谁，你是上帝的圣者！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 1:34; 路加福音 4:41; 使徒行传 16:17"> 耶稣责备它说：“住口，从他身上出来！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:26; 马可福音 9:20; 路加福音 11:22"> 污鬼使那人抽搐了一阵，大叫一声，就从他身上出来了。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:31; 马可福音 7:37; 路加福音 9:1"> 众人都很惊讶，彼此议论说：“这是怎么回事？真是带着权柄的新教导啊！祂一发命令，污鬼都服从祂。”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 9:31; 路加福音 4:37; 马可福音 1:45"> 于是，耶稣的名声立刻传遍了整个加利利一带。</span>
</div>
</div>

## 医病赶鬼

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 4:38–39; 马太福音 8:14–15; 马可福音 1:21"> 耶稣同雅各和约翰离开会堂后，就来到西门和安得烈家。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 9:5; 马可福音 5:23; 约翰福音 11:3"> 当时西门的岳母正发烧，躺在床上，他们立刻把这事告诉耶稣。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:41; 诗篇 116:12; 马可福音 5:41"> 耶稣走到她的床边，拉着她的手扶她起来，她的烧就退了，她便起来服侍他们。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 8:16; 马可福音 3:2; 路加福音 4:40"> 傍晚，日落之后，有人把病人和被鬼附身的人都带来见耶稣。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:5; 使徒行传 13:44"> 全城的人都聚在门前。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 4:41; 马可福音 3:12; 马太福音 4:23"> 耶稣治好了许多患各种疾病的人，又赶出很多鬼。祂不许鬼说话，因为鬼认识祂。</span>
</div>
</div>

## 在加利利传道

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 6:12; 路加福音 5:16; 路加福音 22:39–46"> 第二天清早，天还没亮，耶稣就起来出门去荒僻的地方祷告。</span>
<span className="v" id="v36" data-v="36"> 西门和同伴们四处寻找耶稣，</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:19; 马可福音 1:5; 撒迦利亚书 11:11"> 找到后便对祂说：“大家都在找你呢！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:43; 约翰福音 17:8; 以赛亚书 61:1–3"> 耶稣却回答说：“我们到附近的乡镇去吧，我也好在那里传道，因为我就是为此而来的。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 4:23; 马可福音 1:21; 路加福音 4:43–44"> 于是，耶稣走遍加利利，在各会堂传道，赶鬼。</span>
</div>
</div>

## 治好麻风病人

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 5:12–14; 马太福音 8:2–4; 利未记 13:1–14"> 有一次，一个患麻风病的人来到耶稣面前，跪下央求：“如果你肯，就能使我洁净。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="马太福音 9:36; 希伯来书 2:17; 希伯来书 4:15"> 耶稣动了慈心，就伸手摸他，说：“我肯，你洁净了吧！”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 15:3; 马可福音 5:29; 约翰福音 4:50–53"> 那人的麻风病立即消失了，他就洁净了。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:30; 马可福音 7:36; 路加福音 8:56"> 耶稣随即让他回去并郑重地叮嘱：</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 14:1–32; 路加福音 17:14; 马太福音 8:4"> “切勿把这事告诉别人，要去让祭司察看你的身体，并照摩西的规定献祭，向众人证明你已经洁净了。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马可福音 2:13; 马太福音 9:31; 约翰福音 6:2"> 但那人离开之后，却到处传扬这件事，以致耶稣无法再公开进城。祂只能待在城外的旷野，可是人们仍从各处来找祂。</span>
</div>
</div>

## 义人和恶人的结局

<div className="bt">
<div className="hs">大卫的诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 37:7; 箴言 23:17; 箴言 24:19"> <span className="pl pl-1">不要因为恶人而烦躁，</span><br /><span className="pl pl-1">也不要羡慕不义之人，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 92:7; 诗篇 90:5–6; 雅各书 1:10–11"> <span className="pl pl-1">因为他们如瞬息枯萎的草芥，</span><br /><span className="pl pl-1">又如转眼消逝的青草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 17:7–8; 马太福音 6:31–33; 诗篇 62:8"> <span className="pl pl-1">要信靠耶和华，要行善，</span><br /><span className="pl pl-1">要在这片土地上安然度日。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 15:7; 诗篇 145:19; 约翰福音 15:16"> <span className="pl pl-1">要以耶和华为乐，</span><br /><span className="pl pl-1">祂必成全你的心愿。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前书 5:7; 腓立比书 4:6–7"> <span className="pl pl-1">要把你的路交托给耶和华，</span><br /><span className="pl pl-1">信靠祂，祂必帮助你。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 54:17; 约伯记 11:17; 以赛亚书 58:8"> <span className="pl pl-1">祂使你的公义如晨光照耀，</span><br /><span className="pl pl-1">使你的仁义如日中天。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 5:7–11; 诗篇 27:14; 诗篇 62:5"> <span className="pl pl-1">要在耶和华面前安静，</span><br /><span className="pl pl-1">耐心等候祂，</span><br /><span className="pl pl-1">不要因恶人道路通达、阴谋得逞而烦躁。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各书 1:19–20"> <span className="pl pl-1">你要抑制怒气，除掉愤怒；</span><br /><span className="pl pl-1">不要烦躁不安，</span><br /><span className="pl pl-1">那会导致你作恶。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:21; 诗篇 25:13; 诗篇 37:29"> <span className="pl pl-1">因为作恶的必被消灭，</span><br /><span className="pl pl-1">但等候耶和华的必承受土地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 24:24; 诗篇 103:16; 诗篇 37:35–36"> <span className="pl pl-1">再过片刻，恶人必不复存在，</span><br /><span className="pl pl-1">虽寻遍其住处，也不见踪影。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:5; 加拉太书 5:22–23; 以赛亚书 26:3"> <span className="pl pl-1">但谦卑人必承受土地，</span><br /><span className="pl pl-1">得享太平昌盛。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 2:1; 诗篇 35:16; 诗篇 31:13"> <span className="pl pl-1">恶人谋害义人，</span><br /><span className="pl pl-1">对他们咬牙切齿。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 2:4; 箴言 1:26; 撒母耳记上 26:10"> <span className="pl pl-1">但主嗤笑邪恶人，</span><br /><span className="pl pl-1">因为祂知道他们末日将临。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 诗篇 11:2; 约翰一书 3:12"> <span className="pl pl-1">恶人拔剑张弓要消灭穷苦人，</span><br /><span className="pl pl-1">杀戮正直人，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14–15; 诗篇 35:8; 耶利米书 51:56"> <span className="pl pl-1">但他们的剑必刺穿自己的心，</span><br /><span className="pl pl-1">他们的弓必被折断。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前书 6:6"> <span className="pl pl-1">义人清贫一生强过恶人财富如山。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 41:10; 诗篇 63:8; 诗篇 145:14"> <span className="pl pl-1">因为恶人的势力终必瓦解，</span><br /><span className="pl pl-1">耶和华必扶持义人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 1:6; 罗马书 6:23; 诗篇 103:17"> <span className="pl pl-1">耶和华看顾纯全者的时日，</span><br /><span className="pl pl-1">他们的产业永远长存。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 33:19; 箴言 10:3; 约伯记 5:20–22"> <span className="pl pl-1">他们在灾难中不致蒙羞，</span><br /><span className="pl pl-1">在饥荒时仍得饱足。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 68:2; 诗篇 102:3; 路加福音 13:3"> <span className="pl pl-1">但恶人必灭亡，</span><br /><span className="pl pl-1">耶和华的仇敌必像野地的花一样凋零，</span><br /><span className="pl pl-1">消逝如烟。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 诗篇 112:5; 箴言 22:7"> <span className="pl pl-1">恶人借债不还，</span><br /><span className="pl pl-1">义人慷慨给予。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前书 16:22; 加拉太书 3:13"> <span className="pl pl-1">蒙耶和华赐福的人必承受土地，</span><br /><span className="pl pl-1">被耶和华咒诅的人必遭铲除。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 诗篇 119:133; 箴言 4:26"> <span className="pl pl-1">耶和华巩固义人的脚步，</span><br /><span className="pl pl-1">喜悦他们所走的路。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 诗篇 145:14; 诗篇 94:18"> <span className="pl pl-1">他们即使失脚，也不会跌倒，</span><br /><span className="pl pl-1">因为耶和华的手扶持他们。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:5; 诗篇 37:28; 诗篇 112:2"> <span className="pl pl-1">从幼年到老年，</span><br /><span className="pl pl-1">我从未见过义人遭弃，</span><br /><span className="pl pl-1">也未见其后人讨饭。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 112:5; 马太福音 5:7; 诗篇 37:21"> <span className="pl pl-1">他们总是乐善好施，</span><br /><span className="pl pl-1">他们的后代都蒙祝福。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:14; 箴言 16:6; 约翰一书 2:16–17"> <span className="pl pl-1">你要离恶行善，</span><br /><span className="pl pl-1">就必永远安居。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 11:7; 箴言 2:22; 诗篇 21:10"> <span className="pl pl-1">因为耶和华喜爱公正，</span><br /><span className="pl pl-1">不丢弃信靠祂的人，</span><br /><span className="pl pl-1">永远保护他们。</span><br /><span className="pl pl-1">恶人的后代必被铲除。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:21; 诗篇 37:9; 彼得后书 3:13"> <span className="pl pl-1">义人必承受土地，</span><br /><span className="pl pl-1">在地上永远安居。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:6; 箴言 25:11–13; 以弗所书 4:29"> <span className="pl pl-1">义人口出智慧，诉说正义，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 40:8; 申命记 6:6; 以赛亚书 51:7"> <span className="pl pl-1">铭记上帝的律法，</span><br /><span className="pl pl-1">从不失脚。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 诗篇 10:8–10; 诗篇 37:12"> <span className="pl pl-1">恶人窥探义人，</span><br /><span className="pl pl-1">伺机谋害。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 109:31; 彼得后书 2:9; 罗马书 8:1"> <span className="pl pl-1">但耶和华不会让他们落在恶人手中，</span><br /><span className="pl pl-1">也不会让义人在审判时被定罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="诗篇 27:14; 诗篇 37:9; 箴言 20:22"> <span className="pl pl-1">要等候耶和华，</span><br /><span className="pl pl-1">坚守祂的道，</span><br /><span className="pl pl-1">祂必赐你土地，使你有尊荣。</span><br /><span className="pl pl-1">你必亲眼看见恶人被铲除。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 5:3; 以西结书 31:18; 以赛亚书 14:14–19"> <span className="pl pl-1">我见过邪恶残暴之人，</span><br /><span className="pl pl-1">势如本地青翠的香柏树，</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 37:10; 使徒行传 12:22–23; 以赛亚书 10:16–19"> <span className="pl pl-1">再一看，他已经消失得无影无踪，</span><br /><span className="pl pl-1">我寻找他，却找不到。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 32:17; 以赛亚书 57:1–2; 提摩太后书 4:6–8"> <span className="pl pl-1">你观察那纯全正直的人，</span><br /><span className="pl pl-1">因为和平的人前途美好。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="箴言 14:32; 诗篇 52:5; 诗篇 1:4–6"> <span className="pl pl-1">罪人必同遭毁灭，</span><br /><span className="pl pl-1">恶人必没有前途。</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 9:9; 诗篇 91:15; 以赛亚书 12:2"> <span className="pl pl-1">耶和华拯救义人，</span><br /><span className="pl pl-1">患难时作他们的庇护所。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 31:5; 历代志上 5:20; 但以理书 6:23"> <span className="pl pl-1">耶和华救助他们，</span><br /><span className="pl pl-1">救他们脱离恶人，拯救他们，</span><br /><span className="pl pl-1">因为他们投靠祂。</span></span>
</div>

## 为耶路撒冷祷告

<div className="bt">
<div className="hs">大卫的上圣殿朝圣之诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 84:10; 弥迦书 4:2; 以赛亚书 2:3"> <span className="pl pl-1">人们对我说：</span><br /><span className="pl pl-1">“让我们去耶和华的殿吧！”</span><br /><span className="pl pl-1">我感到欢喜。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 100:4; 诗篇 84:7; 历代志下 6:6"> <span className="pl pl-1">耶路撒冷啊，</span><br /><span className="pl pl-1">我们正站在你的城门里。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 5:9; 以弗所书 2:20–21; 以弗所书 4:4–7"> <span className="pl pl-1">耶路撒冷被建成一座整齐坚固的城。</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="申命记 17:8; 历代志下 19:8; 历代志下 11:22"> <span className="pl pl-1">那里有审判的王座，</span><br /><span className="pl pl-1">就是大卫家的王座。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 51:18; 耶利米书 29:7; 创世记 12:3"> <span className="pl pl-1">要为耶路撒冷的平安祷告，</span><br /><span className="pl pl-1">愿爱这城的人亨通。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:27; 诗篇 48:3; 以赛亚书 54:13"> <span className="pl pl-1">耶路撒冷啊！</span><br /><span className="pl pl-1">愿你城内有平安，</span><br /><span className="pl pl-1">你的宫里有安宁，</span><br /></span>

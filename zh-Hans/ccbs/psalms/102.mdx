## 患难中的祈祷

<div className="bt">
<div className="hs">受苦之人的祷告，在疲惫不堪时向耶和华的倾诉。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 18:6; 诗篇 130:1–2; 诗篇 142:2–3"> <span className="pl pl-1">耶和华啊，求你听我的祷告，</span><br /><span className="pl pl-1">愿我的呼求达到你面前！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 69:17; 诗篇 27:9; 以赛亚书 8:17"> <span className="pl pl-1">我在危难的时候，</span><br /><span className="pl pl-1">求你不要掩面不理我。</span><br /><span className="pl pl-1">我的呼求的时候，求你垂听，</span><br /><span className="pl pl-1">赶快应允我。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 4:14; 诗篇 37:20; 约伯记 30:30"> <span className="pl pl-1">我的年日如烟消散，</span><br /><span className="pl pl-1">我的骨头如火焚烧。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 40:7; 诗篇 37:2; 诗篇 77:3"> <span className="pl pl-1">我的心被摧残，如草枯萎，</span><br /><span className="pl pl-1">以致我不思饮食。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 19:20; 耶利米哀歌 4:8; 诗篇 6:8"> <span className="pl pl-1">我因哀叹而瘦骨嶙峋。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="西番雅书 2:14; 以赛亚书 38:14; 以赛亚书 34:11–15"> <span className="pl pl-1">我就像旷野中的鸮鸟，</span><br /><span className="pl pl-1">又像废墟中的猫头鹰。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 77:4; 诗篇 38:11; 申命记 28:66–67"> <span className="pl pl-1">我无法入睡，</span><br /><span className="pl pl-1">我就像屋顶上一只孤伶伶的麻雀。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:11; 诗篇 69:9–10; 以赛亚书 65:15"> <span className="pl pl-1">我的仇敌终日辱骂我，</span><br /><span className="pl pl-1">嘲笑我的用我的名字咒诅人。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 42:3; 诗篇 80:5; 弥迦书 1:10"> <span className="pl pl-1">我以炉灰为食物，</span><br /><span className="pl pl-1">眼泪拌着水喝，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 38:3; 诗篇 90:7–9; 诗篇 147:6"> <span className="pl pl-1">因为你向我大发烈怒，</span><br /><span className="pl pl-1">把我捡起来扔掉了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 14:2; 诗篇 109:23; 诗篇 144:4"> <span className="pl pl-1">我的年日像黄昏的影子，</span><br /><span className="pl pl-1">又如枯干的草芥。</span></span>
</div>

</div>
<div className="bp poetry">

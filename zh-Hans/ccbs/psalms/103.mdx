## 上帝的慈爱

<div className="bt">
<div className="hs">大卫的诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 146:1–2; 诗篇 57:7–11; 约翰福音 4:24"> <span className="pl pl-1">我的心啊，要称颂耶和华，</span><br /><span className="pl pl-1">我的肺腑心肠啊，要称颂祂的圣名。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 63:7; 诗篇 116:12; 诗篇 105:5"> <span className="pl pl-1">我的心啊，要称颂耶和华，</span><br /><span className="pl pl-1">不要忘记祂的一切恩惠。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:26; 以赛亚书 53:5; 耶利米书 17:14"> <span className="pl pl-1">祂赦免你一切的罪恶，</span><br /><span className="pl pl-1">医治你一切的疾病。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 56:13; 诗篇 71:23; 诗篇 103:12"> <span className="pl pl-1">祂救赎你的生命脱离死亡，</span><br /><span className="pl pl-1">以慈爱和怜悯环绕你。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 40:31; 诗篇 107:9; 提摩太前书 6:17"> <span className="pl pl-1">祂以美物满足你的愿望，</span><br /><span className="pl pl-1">使你如鹰一般恢复青春。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 9:9; 诗篇 12:5; 诗篇 72:12"> <span className="pl pl-1">耶和华为一切受欺压的人伸张正义，主持公道。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 33:13; 诗篇 147:19; 诗篇 78:11"> <span className="pl pl-1">祂让摩西明白自己的旨意，</span><br /><span className="pl pl-1">向以色列人彰显自己的作为。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 86:15; 约珥书 2:13; 出埃及记 34:6–7"> <span className="pl pl-1">耶和华好怜悯，有恩典，</span><br /><span className="pl pl-1">不轻易发怒，充满慈爱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 57:16; 诗篇 30:5; 弥迦书 7:18–19"> <span className="pl pl-1">祂不永久责备人，</span><br /><span className="pl pl-1">也不永远怀怒。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 9:13; 耶利米哀歌 3:22; 尼希米记 9:31"> <span className="pl pl-1">祂没有按我们的罪恶对待我们，</span><br /><span className="pl pl-1">也没有照我们的罪过惩罚我们。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 57:10; 路加福音 1:50; 诗篇 36:5"> <span className="pl pl-1">因为天离地有多高，</span><br /><span className="pl pl-1">祂对敬畏祂之人的爱也多大！</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 43:25; 约翰一书 1:7; 弥迦书 7:18"> <span className="pl pl-1">东离西有多远，</span><br /><span className="pl pl-1">祂叫我们的过犯离我们也多远！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:11–12; 希伯来书 12:5–11; 路加福音 15:21–22"> <span className="pl pl-1">耶和华怜爱敬畏祂的人，</span><br /><span className="pl pl-1">如同慈父怜爱自己的儿女。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="传道书 12:7; 约伯记 10:9; 诗篇 78:38–39"> <span className="pl pl-1">因为祂知道我们的本源，</span><br /><span className="pl pl-1">顾念我们不过是尘土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="彼得前书 1:24; 雅各书 1:10–11; 以赛亚书 51:12"> <span className="pl pl-1">世人的年日如同草芥，</span><br /><span className="pl pl-1">如野地茂盛的花，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:7; 约伯记 20:9; 约伯记 14:10"> <span className="pl pl-1">一经风吹，便无影无踪，</span><br /><span className="pl pl-1">从原处永远消逝。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 100:5; 出埃及记 20:6; 以弗所书 2:4–7"> <span className="pl pl-1">耶和华永永远远爱敬畏祂的人，</span><br /><span className="pl pl-1">以公义待他们的子子孙孙，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="申命记 7:9; 诗篇 132:12; 路加福音 1:6"> <span className="pl pl-1">就是那些守祂的约、</span><br /><span className="pl pl-1">一心遵行祂命令的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="诗篇 47:2; 腓立比书 2:9–10; 诗篇 9:7"> <span className="pl pl-1">耶和华在天上设立了宝座，</span><br /><span className="pl pl-1">祂的王权统管万有。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 1:14; 诗篇 148:2; 路加福音 1:19"> <span className="pl pl-1">听从耶和华的命令、遵行祂吩咐的大能天使啊，</span><br /><span className="pl pl-1">你们要称颂祂！</span><br /></span>

<span className="v" id="v22" data-v="22" data-xref="以赛亚书 49:13; 诗篇 145:10; 以赛亚书 42:10–12"> <span className="pl pl-1">耶和华所造的万物啊，</span><br /><span className="pl pl-1">要在祂掌管的各处称颂祂。</span><br /><span className="pl pl-1">我的心啊，要称颂耶和华！</span></span>

## 上帝是至高的君王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="历代志上 16:23–33; 诗篇 98:1; 诗篇 149:1"> <span className="pl pl-1">你们要向耶和华唱新歌，</span><br /><span className="pl pl-1">普世都要歌颂耶和华。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:15; 诗篇 71:15; 诗篇 103:1–2"> <span className="pl pl-1">要歌颂耶和华，颂赞祂的名，</span><br /><span className="pl pl-1">天天传扬祂的拯救之恩。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 22:27; 但以理书 4:1–3; 路加福音 24:47"> <span className="pl pl-1">要在列国述说祂的荣耀，</span><br /><span className="pl pl-1">在万民中述说祂的奇妙作为。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 145:3; 诗篇 18:3; 启示录 15:4"> <span className="pl pl-1">因为耶和华无比伟大，</span><br /><span className="pl pl-1">当受至高的颂扬；</span><br /><span className="pl pl-1">祂超越一切神明，当受敬畏。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 115:15; 以赛亚书 42:5; 耶利米书 10:11–12"> <span className="pl pl-1">列邦的神明都是假的，</span><br /><span className="pl pl-1">唯独耶和华创造了诸天。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 63:2–3; 诗篇 104:1; 彼得后书 1:16–17"> <span className="pl pl-1">祂带着尊贵和威严，</span><br /><span className="pl pl-1">祂的圣所充满能力和荣美。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="启示录 19:1; 马太福音 6:13; 历代志上 29:11–13"> <span className="pl pl-1">万族万民啊，</span><br /><span className="pl pl-1">要把荣耀和能力归给耶和华，</span><br /><span className="pl pl-1">归给耶和华！</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 100:4; 罗马书 12:1; 出埃及记 34:5–9"> <span className="pl pl-1">要将耶和华之名当得的荣耀归给祂，</span><br /><span className="pl pl-1">要带着祭物到祂的院宇。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 29:2; 诗篇 114:7; 诗篇 110:3"> <span className="pl pl-1">当敬拜圣洁荣耀的耶和华，</span><br /><span className="pl pl-1">大地要在祂面前颤抖。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 93:1; 诗篇 67:4; 诗篇 9:8"> <span className="pl pl-1">要告诉列国：</span><br /><span className="pl pl-1">“耶和华掌权，</span><br /><span className="pl pl-1">世界坚立不摇，</span><br /><span className="pl pl-1">祂必公正地审判万民。”</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 69:34; 以赛亚书 49:13; 诗篇 98:7–9"> <span className="pl pl-1">愿天欢喜，愿地快乐，</span><br /><span className="pl pl-1">愿海洋和其中的一切都欢呼。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 55:12–13; 以赛亚书 35:1; 以赛亚书 42:10–11"> <span className="pl pl-1">愿田野和其中的万物都欢腾，</span><br /><span className="pl pl-1">愿林中的树木都在耶和华面前欢唱。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 19:11; 提摩太后书 4:8; 以赛亚书 25:8–9"> <span className="pl pl-1">因为祂来了，祂来审判天下，</span><br /><span className="pl pl-1">祂要按公义审判世界，</span><br /><span className="pl pl-1">凭祂的信实审判万民。</span></span>

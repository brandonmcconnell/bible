## 受苦者的呼求

<div className="bt">
<div className="hs">大卫的诗，交给乐长耶杜顿。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 21:23; 诗篇 141:3; 雅各书 1:26"> <span className="pl pl-1">我说：“我要谨言慎行，</span><br /><span className="pl pl-1">免犯口舌之罪。</span><br /><span className="pl pl-1">只要身边有恶人，</span><br /><span className="pl pl-1">我就用嚼环勒住自己的口。”</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:20; 诗篇 38:13–14; 约伯记 32:19–20"> <span className="pl pl-1">然而，我默不作声，</span><br /><span className="pl pl-1">连好话也不出口时，</span><br /><span className="pl pl-1">内心就更加痛苦。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:32; 耶利米书 20:9; 以西结书 3:14"> <span className="pl pl-1">我心如火烧，越沉思越烦躁，</span><br /><span className="pl pl-1">便开口呼求：</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 90:12; 诗篇 103:14; 约伯记 14:13"> <span className="pl pl-1">“耶和华啊，求你让我知道我人生的终点和寿数，</span><br /><span className="pl pl-1">明白人生何其短暂。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 90:9–10; 诗篇 144:4; 诗篇 89:47"> <span className="pl pl-1">你使我的生命转瞬即逝，</span><br /><span className="pl pl-1">我的岁月在你眼中不到片刻。</span><br /><span className="pl pl-1">人的生命不过是一丝气息，（细拉）</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:20–21; 雅各书 4:14; 传道书 2:26"> <span className="pl pl-1">人生不过是幻影，</span><br /><span className="pl pl-1">劳碌奔波却一场空，</span><br /><span className="pl pl-1">积蓄财富却不知谁来享用。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 15:13; 诗篇 38:15; 诗篇 119:81"> <span className="pl pl-1">主啊，如今我等候什么呢？</span><br /><span className="pl pl-1">你是我的盼望。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 44:13; 诗篇 65:3; 约珥书 2:17"> <span className="pl pl-1">求你救我脱离一切过犯，</span><br /><span className="pl pl-1">不要让愚昧人嘲笑我。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 2:10; 撒母耳记下 16:10; 利未记 10:3"> <span className="pl pl-1">我默然不语，一言不发，</span><br /><span className="pl pl-1">因为我受的责罚是出于你。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 9:34; 约伯记 13:21; 诗篇 25:16–17"> <span className="pl pl-1">求你不要再惩罚我，</span><br /><span className="pl pl-1">你的责打使我几乎丧命。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 13:28; 哥林多前书 11:30–32; 以赛亚书 50:9"> <span className="pl pl-1">因为人犯罪，你责罚管教他们，</span><br /><span className="pl pl-1">如同蛀虫吞噬他们所爱的。</span><br /><span className="pl pl-1">世人不过是一丝气息。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 2:11; 希伯来书 11:13; 列王纪下 20:5"> <span className="pl pl-1">“耶和华啊，</span><br /><span className="pl pl-1">求你垂听我的祷告，</span><br /><span className="pl pl-1">倾听我的呼求，</span><br /><span className="pl pl-1">别对我的眼泪无动于衷。</span><br /><span className="pl pl-1">因为我在你面前只是客旅，</span><br /><span className="pl pl-1">是寄居的，</span><br /><span className="pl pl-1">正如我的祖先。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 10:20–21; 约伯记 14:10–12; 约伯记 14:5–6"> <span className="pl pl-1">求你宽恕我，</span><br /><span className="pl pl-1">好让我在离世之前能重展笑容。”</span></span>
</div>

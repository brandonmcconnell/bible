## 求上帝眷顾

<div className="bt">
<div className="hs">可拉后裔的诗歌，就是以斯拉人希幔的训诲诗，交给乐长，调用“麻哈拉利暗俄”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“麻哈拉利暗俄”意为“受苦”。">a</a></sup>。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 12:2; 诗篇 22:2; 路加福音 18:7"> <span className="pl pl-1">耶和华，拯救我的上帝啊，</span><br /><span className="pl pl-1">我昼夜不停地呼求你。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 31:2; 诗篇 141:1–2; 耶利米哀歌 3:8"> <span className="pl pl-1">求你垂听我的祷告，</span><br /><span className="pl pl-1">侧耳听我的呼求。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 107:18; 耶利米哀歌 3:15–19; 马可福音 14:33–34"> <span className="pl pl-1">我饱经患难，</span><br /><span className="pl pl-1">生命在阴间的边缘。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 28:1; 哥林多后书 1:9; 诗篇 143:7"> <span className="pl pl-1">我被列在下坟墓的人中，</span><br /><span className="pl pl-1">我的精力耗尽。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 53:8; 诗篇 31:22; 以赛亚书 14:9–12"> <span className="pl pl-1">我被扔在死人中，</span><br /><span className="pl pl-1">如同被杀的人躺在坟墓里，</span><br /><span className="pl pl-1">被你遗忘，不再蒙你眷顾。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 69:15; 诗篇 86:13; 诗篇 143:3"> <span className="pl pl-1">你已经把我扔在极深的坑中，</span><br /><span className="pl pl-1">扔在漆黑的深渊。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 42:7; 约伯记 6:4; 罗马书 2:5–9"> <span className="pl pl-1">你的烈怒重重地压着我，</span><br /><span className="pl pl-1">你用汹涌的波涛把我淹没。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="诗篇 31:11; 以赛亚书 49:7; 耶利米书 32:2"> <span className="pl pl-1">你使我众叛亲离，遭人唾弃。</span><br /><span className="pl pl-1">我陷入困境，无路可逃。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 11:13; 诗篇 38:10; 诗篇 86:3"> <span className="pl pl-1">我因忧伤而眼睛昏花。</span><br /><span className="pl pl-1">耶和华啊，我天天呼求你，</span><br /><span className="pl pl-1">举手向你呼求。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 6:5; 以赛亚书 26:19; 诗篇 30:9"> <span className="pl pl-1">你要行神迹给死人看吗？</span><br /><span className="pl pl-1">死人会起来赞美你吗？（细拉）</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 26:6; 箴言 15:11; 诗篇 73:18"> <span className="pl pl-1">坟墓里的死人怎能述说你的慈爱呢？</span><br /><span className="pl pl-1">灭亡的人怎能传扬你的信实呢？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="传道书 9:5; 传道书 2:16; 以赛亚书 8:22"> <span className="pl pl-1">黑暗之地有谁知道你的神迹呢？</span><br /><span className="pl pl-1">在被遗忘之地有谁知道你的公义作为呢？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 5:3; 诗篇 30:2; 马可福音 1:35"> <span className="pl pl-1">耶和华啊，我向你呼求，</span><br /><span className="pl pl-1">我在清晨向你祷告。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 13:24; 诗篇 13:1; 诗篇 44:24"> <span className="pl pl-1">耶和华啊，你为何弃绝我？</span><br /><span className="pl pl-1">为何掩面不理我？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 6:4; 路加福音 22:44; 约伯记 7:11–16"> <span className="pl pl-1">我从小受苦，几乎丧命。</span><br /><span className="pl pl-1">你使我惊恐不已，陷入绝望。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 90:11; 以赛亚书 53:4–6; 罗马书 8:32"> <span className="pl pl-1">你的烈怒吞噬了我，</span><br /><span className="pl pl-1">你可怕的攻击毁灭了我。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 22:16; 诗篇 116:3; 诗篇 69:1–2"> <span className="pl pl-1">这些灾难如洪涛整天环绕我，</span><br /><span className="pl pl-1">四面围住我。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 88:8; 诗篇 38:11; 约伯记 19:12–15"> <span className="pl pl-1">你使我的亲朋好友离我而去，</span><br /><span className="pl pl-1">只有黑暗与我相伴。</span></span>
</div>

## 求上帝惩治恶人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 22:1; 诗篇 27:9; 诗篇 13:1–3"> <span className="pl pl-1">耶和华啊，你为何远远站着？</span><br /><span className="pl pl-1">为何在我遭难时隐藏起来？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 59:12; 诗篇 36:11; 诗篇 7:16"> <span className="pl pl-1">恶人狂妄地追逼穷苦人，</span><br /><span className="pl pl-1">愿他们落入自己所设的圈套。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 94:4; 路加福音 12:19; 撒迦利亚书 11:5–8"> <span className="pl pl-1">恶人夸耀自己的贪欲，</span><br /><span className="pl pl-1">贪婪的人咒诅和藐视耶和华。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 14:1–2; 使徒行传 8:22; 罗马书 1:28"> <span className="pl pl-1">他们狂傲自大，不寻求耶和华，</span><br /><span className="pl pl-1">他们心中没有上帝。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 92:5–6; 以赛亚书 26:11; 诗篇 12:5"> <span className="pl pl-1">他们凡事顺利，</span><br /><span className="pl pl-1">对你的审判不屑一顾，</span><br /><span className="pl pl-1">对所有的仇敌嗤之以鼻。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="传道书 8:11; 马太福音 24:48; 以赛亚书 56:12"> <span className="pl pl-1">他们自以为可以屹立不倒，</span><br /><span className="pl pl-1">世世代代永不遭殃。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 7:14; 诗篇 140:9; 诗篇 140:3"> <span className="pl pl-1">他们满口咒诅、谎话和恐吓之言，</span><br /><span className="pl pl-1">舌头沾满祸害和邪恶。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哈巴谷书 3:14; 撒母耳记上 22:18; 耶利米书 22:17"> <span className="pl pl-1">他们埋伏在村庄，</span><br /><span className="pl pl-1">杀害无辜，暗中监视受害者。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 17:12; 诗篇 59:3; 弥迦书 7:2"> <span className="pl pl-1">他们像狮子埋伏在暗处，</span><br /><span className="pl pl-1">伺机猎取无助的人，</span><br /><span className="pl pl-1">用网罗拖走他们。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 23:21–22; 撒母耳记上 18:21–26; 撒母耳记下 15:5"> <span className="pl pl-1">无助的人被击垮，</span><br /><span className="pl pl-1">倒在他们的暴力下。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:12; 诗篇 94:7; 诗篇 73:11"> <span className="pl pl-1">他们自言自语：“上帝忘记了，</span><br /><span className="pl pl-1">祂掩面不理，永不察看！”</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="弥迦书 5:9; 诗篇 9:12; 诗篇 94:2"> <span className="pl pl-1">耶和华啊，求你起来！</span><br /><span className="pl pl-1">上帝啊，求你举手施罚，</span><br /><span className="pl pl-1">不要忘记无助的人！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 12:9–10; 诗篇 74:10; 创世记 9:5"> <span className="pl pl-1">恶人为何藐视上帝，</span><br /><span className="pl pl-1">以为上帝不会追究呢？</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 68:5; 诗篇 146:9; 诗篇 55:22"> <span className="pl pl-1">但你已看到世人的疾苦，</span><br /><span className="pl pl-1">随时伸出援手。</span><br /><span className="pl pl-1">困苦无助的人投靠你，</span><br /><span className="pl pl-1">你是孤儿的帮助。</span><br /></span>

<span className="v" id="v16" data-v="16" data-xref="诗篇 29:10; 耶利米书 10:10; 提摩太前书 1:17"> <span className="pl pl-1">耶和华永永远远是君王，</span><br /><span className="pl pl-1">列国必从祂的土地上灭亡。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 145:19; 历代志下 34:27; 诗篇 34:15"> <span className="pl pl-1">耶和华啊，</span><br /><span className="pl pl-1">你知道困苦人的愿望，</span><br /><span className="pl pl-1">你必垂听他们的呼求，</span><br /><span className="pl pl-1">使他们心里刚强。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 9:9; 诗篇 82:3; 以赛亚书 11:4"> <span className="pl pl-1">你为孤儿和受欺压的人申冤，</span><br /><span className="pl pl-1">使区区世人不能再恐吓他们。</span></span>

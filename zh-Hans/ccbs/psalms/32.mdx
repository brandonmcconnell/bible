## 认罪与赦免

<div className="bt">
<div className="hs">大卫的训诲诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="罗马书 4:6–8; 以赛亚书 44:22; 诗篇 85:2"> <span className="pl pl-1">过犯得到赦免、罪恶被遮盖的人有福了！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:47; 哥林多后书 5:19–21; 启示录 14:5"> <span className="pl pl-1">不被耶和华算为有罪、</span><br /><span className="pl pl-1">心里没有诡诈的人有福了！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:13; 诗篇 38:8; 诗篇 38:3"> <span className="pl pl-1">我默然不语、拒绝认罪的时候，</span><br /><span className="pl pl-1">就因整日哀叹而身心疲惫。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 5:11; 诗篇 38:2–8; 诗篇 39:10–11"> <span className="pl pl-1">你的手昼夜重压我，</span><br /><span className="pl pl-1">我的精力如水在盛夏枯竭。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 28:13; 撒母耳记下 12:13; 诗篇 38:18"> <span className="pl pl-1">我向你承认自己的罪，</span><br /><span className="pl pl-1">不再隐瞒自己的恶。</span><br /><span className="pl pl-1">我说：“我要向耶和华承认我的过犯。”</span><br /><span className="pl pl-1">你就赦免了我的罪恶。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 55:6; 以赛亚书 43:2; 哥林多后书 6:2"> <span className="pl pl-1">因此，趁着还能寻求你的时候，</span><br /><span className="pl pl-1">愿所有敬虔的人都当向你祷告；</span><br /><span className="pl pl-1">洪水泛滥时，必不殃及他们。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 91:1; 诗篇 119:114; 诗篇 9:9"> <span className="pl pl-1">你是我的藏身之所，</span><br /><span className="pl pl-1">你保护我免遭危难，</span><br /><span className="pl pl-1">用得救的乐歌环绕我。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="箴言 3:5–6; 诗篇 33:18; 诗篇 25:8–10"> <span className="pl pl-1">耶和华说：“我要指教你走正路；</span><br /><span className="pl pl-1">我要劝导你，看顾你。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 26:3; 耶利米书 4:22; 雅各书 3:3"> <span className="pl pl-1">不要像无知的骡马，</span><br /><span className="pl pl-1">不用嚼环辔头就不驯服。”</span></span>
</div>

</div>

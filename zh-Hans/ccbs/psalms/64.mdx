## 祈求上帝的保护

<div className="bt">
<div className="hs">大卫作的诗，交给乐长。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 34:4; 诗篇 143:1–3; 耶利米哀歌 3:55–56"> <span className="pl pl-1">上帝啊，求你倾听我的苦诉，</span><br /><span className="pl pl-1">求你保护我的性命不受仇敌的威胁。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 143:9; 诗篇 59:2; 诗篇 109:2–3"> <span className="pl pl-1">求你保护我免遭恶人的谋害，</span><br /><span className="pl pl-1">使我脱离作恶之徒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 57:4; 诗篇 58:7; 雅各书 3:6–8"> <span className="pl pl-1">他们舌头锋利如刀，</span><br /><span className="pl pl-1">言语恶毒，犹如利箭。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 55:19; 诗篇 11:2; 彼得前书 2:22–23"> <span className="pl pl-1">他们埋伏起来，</span><br /><span className="pl pl-1">暗箭伤害纯全无过的人。</span><br /><span className="pl pl-1">他们突然袭击，毫无顾忌。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 140:5; 诗篇 10:11; 以西结书 8:12"> <span className="pl pl-1">他们朋比为奸，</span><br /><span className="pl pl-1">商量暗设网罗，</span><br /><span className="pl pl-1">以为谁也看不见。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 17:9–10; 马太福音 26:59; 诗篇 5:9"> <span className="pl pl-1">他们图谋不义之事，</span><br /><span className="pl pl-1">认为策划得无懈可击。</span><br /><span className="pl pl-1">人心真是狡猾。</span><br /></span>

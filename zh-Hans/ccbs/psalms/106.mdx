## 上帝恩待祂的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:18; 诗篇 105:1; 历代志上 16:34"> <span className="pl pl-1">你们要赞美耶和华！</span><br /><span className="pl pl-1">要称谢耶和华，</span><br /><span className="pl pl-1">因为祂是美善的，</span><br /><span className="pl pl-1">祂的慈爱永远长存！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 11:33; 以弗所书 1:19; 诗篇 145:3–12"> <span className="pl pl-1">谁能述说耶和华的大能作为？</span><br /><span className="pl pl-1">谁能道尽祂当受赞美之处？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 15:2; 雅各书 1:25; 约翰福音 15:14"> <span className="pl pl-1">那些行事公正，</span><br /><span className="pl pl-1">持守公义的人有福了。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 119:132; 路加福音 23:42; 尼希米记 13:14"> <span className="pl pl-1">耶和华啊！</span><br /><span className="pl pl-1">你恩待你子民的时候，</span><br /><span className="pl pl-1">求你顾念我；</span><br /><span className="pl pl-1">你拯救他们的时候，</span><br /><span className="pl pl-1">求你帮助我，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:16; 诗篇 105:43; 诗篇 1:3"> <span className="pl pl-1">使我看到你所拣选的人繁荣昌盛，</span><br /><span className="pl pl-1">与他们同乐，</span><br /><span className="pl pl-1">与你的子民一同夸耀。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 9:16; 诗篇 78:8; 列王纪上 8:47"> <span className="pl pl-1">我们跟祖先一样也犯了罪，</span><br /><span className="pl pl-1">行事邪恶。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 14:11–12; 诗篇 78:42; 诗篇 78:11"> <span className="pl pl-1">我们祖先在埃及漠视你奇妙的作为，</span><br /><span className="pl pl-1">忘记你向他们屡施慈爱，</span><br /><span className="pl pl-1">在红海边反叛你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 9:16; 以西结书 20:9; 以西结书 20:14"> <span className="pl pl-1">但祂为了自己的名拯救了他们，</span><br /><span className="pl pl-1">以彰显祂的大能。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:15; 以赛亚书 51:10; 以赛亚书 63:11–14"> <span className="pl pl-1">祂斥责红海，海就干了，</span><br /><span className="pl pl-1">祂带领他们走过深渊，</span><br /><span className="pl pl-1">如履干地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 14:30; 诗篇 107:2; 弥迦书 6:4"> <span className="pl pl-1">祂救他们脱离敌人的权势，</span><br /><span className="pl pl-1">从仇敌的手中救赎了他们。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 15:5; 诗篇 78:53; 出埃及记 14:13"> <span className="pl pl-1">海水淹没了敌军，</span><br /><span className="pl pl-1">没有一人生还。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 14:31–21; 路加福音 8:13; 约翰福音 8:30–31"> <span className="pl pl-1">那时他们才相信祂的话，</span><br /><span className="pl pl-1">歌唱赞美祂。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 78:11; 出埃及记 15:24; 以赛亚书 48:17–18"> <span className="pl pl-1">然而，他们很快忘了祂的作为，</span><br /><span className="pl pl-1">不愿等候祂的引导。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:9; 民数记 11:4; 哥林多前书 10:6"> <span className="pl pl-1">他们在旷野大起贪念，</span><br /><span className="pl pl-1">在荒野试探上帝。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="民数记 11:31–34; 以赛亚书 10:16; 诗篇 78:29–31"> <span className="pl pl-1">祂满足了他们的要求，</span><br /><span className="pl pl-1">但在他们当中降下了瘟疫。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民数记 16:1–50; 利未记 21:10–12; 利未记 21:6–8"> <span className="pl pl-1">他们还在营中嫉妒摩西和耶和华的圣仆亚伦。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命记 11:6; 民数记 16:29–33; 民数记 26:10"> <span className="pl pl-1">大地裂开吞没了大坍，</span><br /><span className="pl pl-1">埋葬了亚比兰一伙人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:29; 民数记 16:35–40; 民数记 16:46"> <span className="pl pl-1">火在他们的党羽中烧起，</span><br /><span className="pl pl-1">烧灭了这些恶人。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 32:4–8; 出埃及记 32:35; 尼希米记 9:18"> <span className="pl pl-1">他们在何烈山铸造牛犊，祭拜金属偶像，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 2:11; 出埃及记 20:4–5; 罗马书 1:22–23"> <span className="pl pl-1">他们用吃草之牛的铸像代替荣耀的上帝。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 2:32; 诗篇 78:42–51; 诗篇 106:13"> <span className="pl pl-1">他们忘记了拯救他们的上帝，</span><br /><span className="pl pl-1">祂曾在埃及行奇事，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 105:23; 诗篇 78:51; 出埃及记 14:25–28"> <span className="pl pl-1">在含地行神迹，</span><br /><span className="pl pl-1">在红海边行可畏的事。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:13–14; 申命记 9:25; 以西结书 22:30"> <span className="pl pl-1">因此祂说要消灭他们。</span><br /><span className="pl pl-1">若不是祂拣选的摩西站在裂口处向祂求情，</span><br /><span className="pl pl-1">祂早已发烈怒毁灭了他们。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="申命记 1:32; 以西结书 20:6; 希伯来书 3:18–19"> <span className="pl pl-1">他们藐视那佳美之地，</span><br /><span className="pl pl-1">不相信祂的应许。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="民数记 14:22; 申命记 1:26–27; 希伯来书 3:15"> <span className="pl pl-1">他们在帐篷里发怨言，</span><br /><span className="pl pl-1">不听从祂的命令。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 20:15; 民数记 14:28–35; 希伯来书 3:11"> <span className="pl pl-1">因此，祂举手起誓要使他们倒毙在旷野，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 44:11; 利未记 26:33; 申命记 28:64–65"> <span className="pl pl-1">使他们的后代倒在列国，分散到各地。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="何西阿书 9:10; 民数记 25:1–3; 民数记 25:5"> <span className="pl pl-1">他们与巴力·毗珥苟合，</span><br /><span className="pl pl-1">吃献给假神的祭物。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:16–21; 哥林多前书 10:8; 罗马书 1:21–24"> <span className="pl pl-1">他们的所作所为触怒耶和华，</span><br /><span className="pl pl-1">以致瘟疫降在他们中间。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="民数记 25:6–8; 约书亚记 7:12; 民数记 25:14–15"> <span className="pl pl-1">那时，非尼哈起来惩罚罪人，</span><br /><span className="pl pl-1">瘟疫才停止。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="民数记 25:11–13; 马可福音 14:3–9; 申命记 24:13"> <span className="pl pl-1">这就是他的义行，世代永存。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="民数记 20:2–13; 民数记 20:23–24; 申命记 4:21"> <span className="pl pl-1">他们在米利巴泉边惹耶和华发怒，</span><br /><span className="pl pl-1">连累了摩西。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="民数记 20:10–11; 诗篇 107:11; 雅各书 3:2"> <span className="pl pl-1">因为他们惹摩西发怒，</span><br /><span className="pl pl-1">以致他说了鲁莽的话。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="申命记 7:2; 申命记 7:16; 士师记 1:21"> <span className="pl pl-1">他们没有照耶和华的命令消灭外族人，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="士师记 3:5–6; 哥林多前书 15:33; 哥林多前书 5:6"> <span className="pl pl-1">反倒与他们混居，</span><br /><span className="pl pl-1">仿效他们的习俗，</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="申命记 7:16; 士师记 2:3; 出埃及记 23:33"> <span className="pl pl-1">拜他们的偶像，陷入网罗。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 17:17; 列王纪下 16:3; 申命记 32:17"> <span className="pl pl-1">他们把自己的儿女当祭物献给鬼魔，</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="民数记 35:33; 申命记 21:9; 以赛亚书 26:21"> <span className="pl pl-1">他们把自己的儿女献给迦南的偶像作祭物，</span><br /><span className="pl pl-1">流他们儿女无辜的血，</span><br /><span className="pl pl-1">玷污了那地方。</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 20:18; 民数记 15:39; 利未记 17:7"> <span className="pl pl-1">他们的行为玷污了自己，</span><br /><span className="pl pl-1">所作所为使自己沦为淫妇。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="士师记 2:14; 申命记 9:29; 士师记 2:20"> <span className="pl pl-1">耶和华因此向祂的子民发怒，</span><br /><span className="pl pl-1">祂厌恶自己的产业，</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="士师记 2:14; 尼希米记 9:27–38; 士师记 3:8"> <span className="pl pl-1">使他们落在列邦的手中，</span><br /><span className="pl pl-1">受敌人的辖制。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="士师记 4:3; 士师记 10:12"> <span className="pl pl-1">他们的敌人压迫他们，</span><br /><span className="pl pl-1">他们被制服在敌人手下。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 81:12; 士师记 2:16–18; 诗篇 1:1"> <span className="pl pl-1">祂多次拯救他们，</span><br /><span className="pl pl-1">他们却执意背叛，</span><br /><span className="pl pl-1">陷入罪中不能自拔。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="士师记 3:9; 士师记 4:3; 撒母耳记上 7:8–12"> <span className="pl pl-1">但祂听见他们在苦难中呼求时，</span><br /><span className="pl pl-1">仍然眷顾他们。</span><br /></span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 105:8; 耶利米哀歌 3:32; 士师记 2:18"> <span className="pl pl-1">祂顾念与他们所立的约，</span><br /><span className="pl pl-1">凭丰盛的慈爱怜悯他们。</span><br /></span>
<span className="v" id="v46" data-v="46" data-xref="以斯拉记 9:9; 耶利米书 42:12; 耶利米书 15:11"> <span className="pl pl-1">祂使掳掠他们的人怜悯他们。</span><br /></span>
<span className="v" id="v47" data-v="47" data-xref="历代志上 16:35–36; 启示录 7:10–12; 哥林多后书 2:14"> <span className="pl pl-1">我们的上帝耶和华啊，</span><br /><span className="pl pl-1">求你拯救我们，</span><br /><span className="pl pl-1">从列国招聚我们，</span><br /><span className="pl pl-1">我们好称谢你的圣名，</span><br /><span className="pl pl-1">以赞美你为荣。</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 41:13; 诗篇 89:52; 诗篇 105:45–1"> <span className="pl pl-1">以色列的上帝耶和华永永远远当受称颂。</span><br /><span className="pl pl-1">愿众民都说：“阿们！”</span><br /><span className="pl pl-1">你们要赞美耶和华！</span></span>

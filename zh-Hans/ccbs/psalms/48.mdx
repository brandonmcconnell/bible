## 上帝的城锡安

<div className="bt">
<div className="hs">可拉后裔的诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="弥迦书 4:1; 撒迦利亚书 8:3; 诗篇 96:4"> <span className="pl pl-1">耶和华何等伟大！</span><br /><span className="pl pl-1">我们的上帝在祂的城中，</span><br /><span className="pl pl-1">在祂的圣山上当大受颂赞。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 50:2; 耶利米哀歌 2:15; 马太福音 5:35"> <span className="pl pl-1">北面的锡安山雄伟壮丽，</span><br /><span className="pl pl-1">令世人欢喜，</span><br /><span className="pl pl-1">是伟大君王的城。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 2:4–5; 诗篇 125:1; 诗篇 46:7"> <span className="pl pl-1">上帝在城内的殿宇中，</span><br /><span className="pl pl-1">祂亲自做这城的庇护。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 10:6–19; 启示录 17:12–14; 启示录 20:8–9"> <span className="pl pl-1">世上的君王一同聚集，齐来攻城。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 14:25; 列王纪下 7:6–7; 列王纪下 19:35–37"> <span className="pl pl-1">他们看见这城后，</span><br /><span className="pl pl-1">大惊失色，慌忙逃跑。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="何西阿书 13:13; 以赛亚书 13:6–8; 以赛亚书 21:3"> <span className="pl pl-1">他们被恐惧笼罩，</span><br /><span className="pl pl-1">痛苦如分娩的妇人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 18:17; 以西结书 27:25–26; 列王纪上 22:48"> <span className="pl pl-1">你毁灭他们，</span><br /><span className="pl pl-1">如同东风摧毁他施的船只。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 87:5; 诗篇 78:3–6; 诗篇 46:5"> <span className="pl pl-1">我们曾经听说，如今在万军之耶和华的城中，</span><br /><span className="pl pl-1">在我们上帝的城中亲眼看见：</span><br /><span className="pl pl-1">上帝要坚立这城，直到永远。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 26:3; 诗篇 40:10; 诗篇 77:10–14"> <span className="pl pl-1">上帝啊，我们在你的殿中默想你的慈爱。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 1:11; 申命记 28:58; 诗篇 113:3"> <span className="pl pl-1">上帝啊，你秉公行义，</span><br /><span className="pl pl-1">你的名普世皆知，</span><br /><span className="pl pl-1">颂赞你的声音响彻地极。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 97:8; 启示录 16:5–7; 启示录 18:20"> <span className="pl pl-1">因你的审判，</span><br /><span className="pl pl-1">锡安山欢喜，</span><br /><span className="pl pl-1">犹大的城邑充满快乐。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 33:18–20; 尼希米记 12:31–40; 马太福音 24:1–2"> <span className="pl pl-1">你们要围绕锡安数点她的城楼，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 71:18; 诗篇 122:7; 申命记 11:19"> <span className="pl pl-1">留意她的城墙，</span><br /><span className="pl pl-1">观看她的殿宇，</span><br /><span className="pl pl-1">好告诉子孙后代。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 58:11; 诗篇 23:3–4; 诗篇 73:24"> <span className="pl pl-1">因为上帝永永远远是我们的上帝，</span><br /><span className="pl pl-1">祂必引领我们，</span><br /><span className="pl pl-1">直到我们离世之日。</span></span>
</div>

## 祈求上帝拯救的祷告

<div className="bt">
<div className="hs">大卫作的诗，交给乐长，调用“百合花”。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 69:14–15; 以赛亚书 43:2; 耶利米哀歌 3:54"> <span className="pl pl-1">上帝啊，求你拯救我，</span><br /><span className="pl pl-1">因为洪水快把我淹没；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 40:2; 耶利米书 38:6; 马太福音 7:25"> <span className="pl pl-1">我深陷泥沼，无法站稳脚；</span><br /><span className="pl pl-1">我落入深渊，被洪流淹没。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 6:6; 诗篇 119:82; 以赛亚书 38:14"> <span className="pl pl-1">我连连呼救，已声嘶力竭；</span><br /><span className="pl pl-1">我期盼上帝的帮助，望眼欲穿。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 15:25; 诗篇 35:19; 诗篇 109:3–5"> <span className="pl pl-1">无故恨我的人不计其数，</span><br /><span className="pl pl-1">无故害我的仇敌势力强大，</span><br /><span className="pl pl-1">逼我偿还我没有偷过的东西。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 38:9; 诗篇 17:3; 耶利米书 16:17"> <span className="pl pl-1">上帝啊，你知道我的愚昧，</span><br /><span className="pl pl-1">我的罪恶也瞒不过你。</span><br /></span>

<span className="v" id="v9" data-v="9" data-xref="罗马书 15:3; 约翰福音 2:14–17; 诗篇 119:139"> <span className="pl pl-1">我为你的殿心急如焚，</span><br /><span className="pl pl-1">辱骂你之人的辱骂都落在我身上。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 35:13; 诗篇 102:8–9; 路加福音 7:33–34"> <span className="pl pl-1">我悲伤禁食，</span><br /><span className="pl pl-1">他们就羞辱我。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:7; 耶利米书 24:9; 约伯记 17:6"> <span className="pl pl-1">我披上麻衣，</span><br /><span className="pl pl-1">他们就讥笑我。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 35:15–16; 马可福音 15:17–19; 但以理书 5:23"> <span className="pl pl-1">我成了街谈巷议的话题，</span><br /><span className="pl pl-1">醉汉作歌取笑我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 6:2; 以赛亚书 49:8; 诗篇 55:16–17"> <span className="pl pl-1">可是，耶和华啊，</span><br /><span className="pl pl-1">在你悦纳人的时候，我向你祷告。</span><br /><span className="pl pl-1">上帝啊，求你以你的大爱和信实的拯救应允我。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:7; 诗篇 109:21; 耶利米书 38:6–13"> <span className="pl pl-1">求你救我脱离泥沼，</span><br /><span className="pl pl-1">不要让我沉下去；</span><br /><span className="pl pl-1">求你救我脱离恨我的人，</span><br /><span className="pl pl-1">使我离开深渊。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="启示录 12:15–16; 使徒行传 2:24; 约拿书 2:2–7"> <span className="pl pl-1">求你不要让洪水淹没我，</span><br /><span className="pl pl-1">不要让深渊吞灭我，</span><br /><span className="pl pl-1">不要让坟墓吞噬我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="诗篇 109:21; 诗篇 25:16; 诗篇 63:3"> <span className="pl pl-1">耶和华啊，求你答应我的祷告，</span><br /><span className="pl pl-1">因为你的慈爱充满良善；</span><br /><span className="pl pl-1">求你以丰盛的怜悯眷顾我。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 27:9; 诗篇 102:2; 诗篇 70:1"> <span className="pl pl-1">求你不要掩面不理你的仆人。</span><br /><span className="pl pl-1">我正身陷困境，</span><br /><span className="pl pl-1">求你快快答应我。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 22:19; 诗篇 22:1; 诗篇 111:9"> <span className="pl pl-1">求你前来拯救我，</span><br /><span className="pl pl-1">因仇敌环伺而救赎我。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 12:2; 以赛亚书 53:3; 彼得前书 2:23"> <span className="pl pl-1">你知道我受的辱骂、欺凌和羞辱，</span><br /><span className="pl pl-1">我的仇敌都在你面前。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 63:5; 诗篇 142:4; 马可福音 14:50"> <span className="pl pl-1">他们的辱骂使我心碎，</span><br /><span className="pl pl-1">令我绝望无助。</span><br /><span className="pl pl-1">我渴望有人同情，却没有一个；</span><br /><span className="pl pl-1">期望有人安慰，却无一人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:34; 路加福音 23:36; 马可福音 15:23"> <span className="pl pl-1">他们给我苦胆当食物，</span><br /><span className="pl pl-1">又拿醋给我解渴。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 5:3; 罗马书 11:8–10; 彼得前书 2:8"> <span className="pl pl-1">愿他们面前的宴席变为网罗，</span><br /><span className="pl pl-1">成为他们的报应和陷阱。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 5:6; 罗马书 11:10; 以赛亚书 6:9–10"> <span className="pl pl-1">愿他们眼目昏暗，无法看见；</span><br /><span className="pl pl-1">愿他们颤颤巍巍，直不起腰来。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 79:6; 何西阿书 5:10; 出埃及记 15:15"> <span className="pl pl-1">求你向他们倾倒烈怒，</span><br /><span className="pl pl-1">愿你的怒火淹没他们。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 1:20; 马太福音 23:38; 耶利米书 7:12–14"> <span className="pl pl-1">愿他们的家园一片荒凉，</span><br /><span className="pl pl-1">愿他们的帐篷无人居住。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:4; 撒迦利亚书 1:15; 历代志下 28:9"> <span className="pl pl-1">因为他们迫害你击打过的人，</span><br /><span className="pl pl-1">嘲笑你所打伤之人的痛苦。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 26:10; 尼希米记 4:5; 提摩太后书 4:14"> <span className="pl pl-1">求你清算他们的种种罪行，</span><br /><span className="pl pl-1">不要让他们得享你的拯救。</span><br /></span>

<span className="v" id="v29" data-v="29" data-xref="诗篇 91:14–16; 诗篇 40:17; 诗篇 20:1"> <span className="pl pl-1">上帝啊，我陷入痛苦和忧伤，</span><br /><span className="pl pl-1">愿你的救恩保护我。</span><br /></span>

<span className="v" id="v32" data-v="32" data-xref="诗篇 22:26; 诗篇 34:2; 约翰福音 16:22"> <span className="pl pl-1">卑微的人看见这一切就欢喜快乐，</span><br /><span className="pl pl-1">愿你们寻求上帝的人心神振奋。</span><br /></span>

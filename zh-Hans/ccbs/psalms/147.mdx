## 赞美上帝复兴耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 135:3; 诗篇 33:1; 诗篇 42:4"> <span className="pl pl-1">你们要赞美耶和华！</span><br /><span className="pl pl-1">歌颂我们的上帝，真是美好！</span><br /><span className="pl pl-1">赞美祂，真是快乐合宜！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="申命记 30:3; 以赛亚书 56:8; 诗篇 51:18"> <span className="pl pl-1">耶和华重建耶路撒冷，</span><br /><span className="pl pl-1">召集流亡的以色列人。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 34:18; 约伯记 5:18; 耶利米书 33:6"> <span className="pl pl-1">祂医治心灵破碎的人，</span><br /><span className="pl pl-1">包扎他们的创伤。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 40:26; 诗篇 8:3; 诗篇 148:3"> <span className="pl pl-1">祂决定众星的数目，</span><br /><span className="pl pl-1">给它们一一命名。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 40:28; 诗篇 139:17–18; 诗篇 96:4"> <span className="pl pl-1">我们的主伟大无比，充满力量，</span><br /><span className="pl pl-1">祂的智慧没有穷尽。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 146:8–9; 诗篇 25:9; 彼得前书 5:6"> <span className="pl pl-1">耶和华扶持谦卑人，</span><br /><span className="pl pl-1">祂使恶人坠入尘埃。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 95:1–2; 诗篇 47:6–7; 诗篇 68:32"> <span className="pl pl-1">你们要以感恩的心歌颂耶和华，</span><br /><span className="pl pl-1">弹琴赞美我们的上帝。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 5:10; 诗篇 65:9–13; 创世记 9:14"> <span className="pl pl-1">祂以云霞遮蔽天空，</span><br /><span className="pl pl-1">降雨水滋润大地，</span><br /><span className="pl pl-1">使山上长出青草。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 104:27–28; 约伯记 38:41; 马太福音 6:26"> <span className="pl pl-1">祂赐食物给走兽，</span><br /><span className="pl pl-1">喂养嗷嗷待哺的小乌鸦。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 16:7; 以赛亚书 31:1; 箴言 21:31"> <span className="pl pl-1">耶和华所喜悦的不是强健的马匹，</span><br /><span className="pl pl-1">也不是矫捷的战士，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 33:18; 玛拉基书 3:16–17; 西番雅书 3:17"> <span className="pl pl-1">而是敬畏祂、仰望祂慈爱的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 12:6; 以赛亚书 52:7; 约珥书 2:23"> <span className="pl pl-1">耶路撒冷啊，要称颂耶和华；</span><br /><span className="pl pl-1">锡安啊，要赞美你的上帝。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 128:3–6; 诗篇 115:14–15; 以赛亚书 44:3–5"> <span className="pl pl-1">因为祂使你的城门坚固，</span><br /><span className="pl pl-1">赐福给你的儿女。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 60:17–18; 诗篇 29:11; 诗篇 81:16"> <span className="pl pl-1">祂使你四境平安，</span><br /><span className="pl pl-1">饱享上好的麦子。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 37:12; 帖撒罗尼迦后书 3:1; 诗篇 107:20"> <span className="pl pl-1">祂向大地发出命令，</span><br /><span className="pl pl-1">祂的话迅速传开。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 38:29; 约伯记 37:6; 诗篇 148:8"> <span className="pl pl-1">祂降下羊毛般的白雪，</span><br /><span className="pl pl-1">撒下炉灰般的寒霜。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 38:29–30; 约伯记 38:22–23; 约伯记 37:9–10"> <span className="pl pl-1">祂抛下碎石般的冰雹，</span><br /><span className="pl pl-1">谁能经得住祂降下的严寒呢？</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 147:15; 诗篇 33:9; 约伯记 37:10"> <span className="pl pl-1">祂一声令下，冰雪便溶化；</span><br /><span className="pl pl-1">祂使微风吹拂，河川奔流。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 4:4; 诗篇 78:5; 申命记 33:2–4"> <span className="pl pl-1">祂将自己的话传于雅各，</span><br /><span className="pl pl-1">将自己的律例和法令指示以色列。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="申命记 4:32–34; 罗马书 3:1–2; 彼得前书 2:9–10"> <span className="pl pl-1">祂未曾这样对待其他国家，</span><br /><span className="pl pl-1">他们不知道祂的法令。</span><br /><span className="pl pl-1">你们要赞美耶和华！</span></span>

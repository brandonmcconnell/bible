## 歌颂上帝的恩惠

<div className="bt">

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 31:7; 诗篇 66:1; 诗篇 100:1–2"> <span className="pl pl-1">要歌颂赐我们力量的上帝，</span><br /><span className="pl pl-1">向雅各的上帝欢呼。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 149:1–3; 诗篇 92:3; 歌罗西书 3:16"> <span className="pl pl-1">要唱诗，击鼓，弹奏悦耳的琴瑟。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="民数记 10:1–10; 民数记 15:3; 历代志下 2:4"> <span className="pl pl-1">要在我们过节的朔日和望日</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“朔日和望日”即每月的初一和十五。">a</a></sup><br /><span className="pl pl-1">吹响号角。</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="诗篇 114:1; 申命记 28:49; 哥林多前书 14:21–22"> <span className="pl pl-1">上帝攻击埃及的时候，</span><br /><span className="pl pl-1">为约瑟立下此法度。</span><br /><span className="pl pl-1">我在那里听见陌生的声音说：</span><br /></span>

## 敬畏上帝者必蒙福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 128:1; 路加福音 1:50; 以赛亚书 50:10"> <span className="pl pl-1">你们要赞美耶和华！</span><br /><span className="pl pl-1">敬畏耶和华、热爱祂命令的人有福了！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:7; 箴言 20:7; 诗篇 37:26"> <span className="pl pl-1">他的子孙在世上必兴盛，</span><br /><span className="pl pl-1">正直人的后代必蒙福。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:6; 箴言 3:16; 马太福音 6:33"> <span className="pl pl-1">他的家财丰厚，</span><br /><span className="pl pl-1">他的公义永远长存。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 11:17; 诗篇 97:11; 歌罗西书 3:12–13"> <span className="pl pl-1">黑暗中必有光照亮正直人，</span><br /><span className="pl pl-1">照亮有恩慈、好怜悯、行公义的人。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:21; 箴言 2:20; 以弗所书 5:15"> <span className="pl pl-1">慷慨借贷，</span><br /><span className="pl pl-1">行事公正的人必亨通。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 10:7; 诗篇 125:1; 诗篇 62:2"> <span className="pl pl-1">义人必永不动摇，</span><br /><span className="pl pl-1">他必永得眷顾。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 26:3–4; 箴言 1:33; 诗篇 57:7"> <span className="pl pl-1">他不怕恶讯，</span><br /><span className="pl pl-1">他一心信靠耶和华。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 59:10; 诗篇 31:24; 诗篇 118:7"> <span className="pl pl-1">他心里笃定，毫不害怕，</span><br /><span className="pl pl-1">他终必战胜仇敌。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 75:10; 希伯来书 13:16; 雅各书 2:15–16"> <span className="pl pl-1">他慷慨施舍，周济穷人；</span><br /><span className="pl pl-1">他的公义永远长存；</span><br /><span className="pl pl-1">他的角被高举，得享尊荣。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 58:7–8; 箴言 11:7; 箴言 10:28"> <span className="pl pl-1">恶人见状恼怒不已，</span><br /><span className="pl pl-1">他咬牙切齿地死去。</span><br /><span className="pl pl-1">恶人的盼望必破灭。</span></span>

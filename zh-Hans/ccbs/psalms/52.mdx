## 上帝的审判和慈爱

<div className="bt">
<div className="hs">以东人多益去告诉扫罗：“大卫到了亚希米勒家。”那时大卫作了这首训诲诗，交给乐长。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 103:17; 诗篇 94:4; 诗篇 107:1"> <span className="pl pl-1">勇士啊，你为何以作恶为荣？</span><br /><span className="pl pl-1">上帝的慈爱永远长存。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 18:21; 诗篇 57:4; 耶利米书 9:3–4"> <span className="pl pl-1">你这诡诈的人啊，</span><br /><span className="pl pl-1">舌头利如剃刀，</span><br /><span className="pl pl-1">尽是害人的奸计。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 9:3–5; 提摩太后书 3:4; 约翰福音 8:44"> <span className="pl pl-1">你喜爱邪恶，不爱良善；</span><br /><span className="pl pl-1">你喜爱虚谎，不爱真理。（细拉）</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 120:3; 雅各书 3:6–9; 撒母耳记上 22:18–19"> <span className="pl pl-1">你有诡诈的舌头，</span><br /><span className="pl pl-1">好说恶言恶语。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 2:22; 诗篇 27:13; 启示录 21:8"> <span className="pl pl-1">上帝必永远毁灭你，</span><br /><span className="pl pl-1">祂必抓住你，</span><br /><span className="pl pl-1">把你从家里拉出来，</span><br /><span className="pl pl-1">从活人之地铲除。（细拉）</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 22:19; 诗篇 40:3; 诗篇 37:34"> <span className="pl pl-1">义人看见必心生敬畏，</span><br /><span className="pl pl-1">他们必嘲笑说：</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 17:5; 诗篇 73:18–20; 传道书 8:8"> <span className="pl pl-1">“看啊，这就是不依靠上帝的人，</span><br /><span className="pl pl-1">他只倚仗自己的财富并靠作恶得势。”</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 92:12–14; 诗篇 1:3; 何西阿书 14:6–8"> <span className="pl pl-1">但我就像上帝殿中的一棵橄榄树，枝繁叶茂，</span><br /><span className="pl pl-1">我永永远远信靠上帝的慈爱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 130:5–6; 耶利米哀歌 3:25–26; 诗篇 54:6"> <span className="pl pl-1">上帝啊，</span><br /><span className="pl pl-1">我要永远赞美你的作为。</span><br /><span className="pl pl-1">我要在你忠心的子民面前仰望你美善的名。</span></span>

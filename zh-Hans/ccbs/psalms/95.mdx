## 赞美上帝之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 10:4; 诗篇 81:1; 撒母耳记下 22:47"> <span className="pl pl-1">来吧，让我们向耶和华歌唱，</span><br /><span className="pl pl-1">向拯救我们的磐石欢呼。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 100:4; 以弗所书 5:19; 诗篇 105:2"> <span className="pl pl-1">让我们怀着感恩的心来到祂面前，</span><br /><span className="pl pl-1">用诗歌颂扬祂。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 96:4; 耶利米书 10:6–7; 诗篇 145:3"> <span className="pl pl-1">因为耶和华是伟大的上帝，</span><br /><span className="pl pl-1">是众神明之上的大君王。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 135:6; 哈巴谷书 3:10; 哈巴谷书 3:6"> <span className="pl pl-1">祂掌管地的深处，</span><br /><span className="pl pl-1">祂拥有山的高峰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="创世记 1:9–10; 诗篇 146:6; 约伯记 38:10–11"> <span className="pl pl-1">海洋属于祂，是祂创造的，</span><br /><span className="pl pl-1">陆地也是祂造的。</span><br /></span>

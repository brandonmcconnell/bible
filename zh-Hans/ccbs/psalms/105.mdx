## 上帝和祂的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 12:4; 诗篇 145:11–12; 罗马书 10:13"> <span className="pl pl-1">你们要称谢耶和华，呼求祂的名，</span><br /><span className="pl pl-1">在列邦传扬祂的作为。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 119:27; 诗篇 98:5; 以赛亚书 12:5–6"> <span className="pl pl-1">要歌颂、赞美祂，</span><br /><span className="pl pl-1">述说祂一切奇妙的作为。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 3:25; 加拉太书 6:14; 哥林多前书 1:29"> <span className="pl pl-1">要以祂的圣名为荣，</span><br /><span className="pl pl-1">愿寻求耶和华的人心中快乐。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 27:8; 西番雅书 2:2–3; 历代志下 6:41"> <span className="pl pl-1">要寻求耶和华和祂的能力，</span><br /><span className="pl pl-1">时常来到祂面前。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 77:11; 诗篇 119:13; 申命记 32:7"> <span className="pl pl-1">祂仆人亚伯拉罕的后裔啊，</span><br /><span className="pl pl-1">祂所拣选的雅各的子孙啊，</span><br /><span className="pl pl-1">要记住祂所行的神迹奇事和祂口中的判词。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 26:9; 申命记 26:17–18; 出埃及记 20:2"> <span className="pl pl-1">祂是我们的上帝耶和华，</span><br /><span className="pl pl-1">祂在普天下施行审判。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 7:9; 诗篇 106:45; 诗篇 111:5"> <span className="pl pl-1">祂永远记得祂的约，</span><br /><span className="pl pl-1">历经千代也不忘祂的应许，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="创世记 17:2; 创世记 22:16–18; 创世记 26:3"> <span className="pl pl-1">就是祂与亚伯拉罕所立的约，</span><br /><span className="pl pl-1">向以撒所起的誓。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:7–8; 撒母耳记下 23:5; 创世记 28:13–15"> <span className="pl pl-1">祂将这约定为律例赐给雅各，</span><br /><span className="pl pl-1">定为永远的约赐给以色列。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="创世记 13:15; 创世记 15:18; 诗篇 78:55"> <span className="pl pl-1">祂说：“我必把迦南赐给你，</span><br /><span className="pl pl-1">作为你的产业。”</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="创世记 34:30; 申命记 7:7; 希伯来书 11:9"> <span className="pl pl-1">那时他们人丁稀少，寥寥可数，</span><br /><span className="pl pl-1">在当地寄居。</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">他们在异国他乡流离飘零。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="创世记 35:5; 出埃及记 7:16–17; 创世记 26:14–33"> <span className="pl pl-1">耶和华不容人压迫他们，</span><br /><span className="pl pl-1">还为他们的缘故责备君王，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 2:8; 创世记 26:11; 创世记 20:7"> <span className="pl pl-1">说：“不可加害我膏立的人，</span><br /><span className="pl pl-1">也不可伤害我的先知。”</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 4:16; 创世记 41:54; 以赛亚书 3:1"> <span className="pl pl-1">祂命饥荒降在那里，</span><br /><span className="pl pl-1">断绝一切食物供应。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 7:9; 创世记 37:36; 创世记 45:4–5"> <span className="pl pl-1">祂派一个人先去，</span><br /><span className="pl pl-1">这人就是被卖为奴隶的约瑟。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 16:24; 创世记 39:20; 创世记 40:15"> <span className="pl pl-1">他被戴上脚镣，套上枷锁，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:10; 箴言 21:1; 创世记 40:20–21"> <span className="pl pl-1">直到后来他的预言应验，</span><br /><span className="pl pl-1">耶和华的话试炼了他。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:14"> <span className="pl pl-1">埃及王派人释放他，</span><br /><span className="pl pl-1">百姓的首领给他自由，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:40–44; 创世记 45:8; 创世记 41:55"> <span className="pl pl-1">派他执掌朝政，</span><br /><span className="pl pl-1">管理国中的一切，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:11; 创世记 41:33; 创世记 41:38"> <span className="pl pl-1">有权柄管束王的大臣，</span><br /><span className="pl pl-1">将智慧传授王的长老。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 7:11–15; 使徒行传 13:17; 诗篇 78:51"> <span className="pl pl-1">以色列来到埃及，</span><br /><span className="pl pl-1">雅各寄居在含地。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 46:3; 出埃及记 1:7–9; 使徒行传 7:17"> <span className="pl pl-1">耶和华使祂的子民生养众多，</span><br /><span className="pl pl-1">比他们的仇敌还要强盛。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 7:19; 创世记 15:13; 出埃及记 9:16"> <span className="pl pl-1">祂使仇敌转念憎恨祂的子民，</span><br /><span className="pl pl-1">用诡计虐待祂的仆人。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 3:10; 出埃及记 29:5–46; 出埃及记 28:12"> <span className="pl pl-1">祂派遣祂的仆人摩西和祂拣选的亚伦，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 78:43–51; 尼希米记 9:10–11; 诗篇 105:23"> <span className="pl pl-1">在埃及行神迹，</span><br /><span className="pl pl-1">在含地行奇事。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 99:7; 约珥书 2:31; 约珥书 2:2"> <span className="pl pl-1">祂使黑暗降下笼罩那里；</span><br /><span className="pl pl-1">他们没有违背祂的话。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 7:20–21; 诗篇 78:44; 以赛亚书 50:2"> <span className="pl pl-1">祂使埃及的水变成血，</span><br /><span className="pl pl-1">鱼都死去；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="启示录 16:13–14; 出埃及记 8:3–14; 诗篇 78:45"> <span className="pl pl-1">又使国中到处是青蛙，</span><br /><span className="pl pl-1">王宫禁院也不能幸免。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 8:16–18; 出埃及记 8:21–24; 以赛亚书 7:18"> <span className="pl pl-1">祂一发命令，</span><br /><span className="pl pl-1">苍蝇蜂拥而至，虱子遍满全境。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 78:47–48; 出埃及记 9:18–28; 启示录 8:7"> <span className="pl pl-1">祂使雨变成冰雹，</span><br /><span className="pl pl-1">遍地电光闪闪。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 78:47; 启示录 9:4"> <span className="pl pl-1">祂击倒他们的葡萄树和无花果树，</span><br /><span className="pl pl-1">摧毁他们境内的树木。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 10:12–15; 诗篇 78:46; 约珥书 1:4–7"> <span className="pl pl-1">祂一发声，</span><br /><span className="pl pl-1">就飞来无数蝗虫和蚂蚱，</span><br /></span>
<span className="v" id="v35" data-v="35"> <span className="pl pl-1">吃尽他们土地上的植物，</span><br /><span className="pl pl-1">吃尽他们田间的出产。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="创世记 49:3; 出埃及记 12:29–30; 诗篇 78:51"> <span className="pl pl-1">祂又击杀他们境内所有的长子，</span><br /><span className="pl pl-1">就是他们年轻力壮时生的长子。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 12:35–36; 出埃及记 3:22; 使徒行传 13:17"> <span className="pl pl-1">祂带领以色列人携金带银地离开埃及，</span><br /><span className="pl pl-1">各支派中无人畏缩。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 12:33; 出埃及记 15:16; 创世记 35:5"> <span className="pl pl-1">埃及人惧怕他们，</span><br /><span className="pl pl-1">乐见他们离去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="尼希米记 9:12; 诗篇 78:14; 以赛亚书 4:5"> <span className="pl pl-1">祂铺展云彩为他们遮荫，</span><br /><span className="pl pl-1">晚上用火给他们照明。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 78:18; 民数记 11:31–33; 约书亚记 5:12"> <span className="pl pl-1">他们祈求，</span><br /><span className="pl pl-1">祂就赐下鹌鹑，降下天粮，</span><br /><span className="pl pl-1">叫他们饱足。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="民数记 20:11; 哥林多前书 10:4; 出埃及记 17:6"> <span className="pl pl-1">祂使磐石裂开、涌出水来，</span><br /><span className="pl pl-1">在干旱之地奔流成河。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 2:24; 路加福音 1:72–73; 创世记 12:7"> <span className="pl pl-1">因为祂顾念祂赐给仆人亚伯拉罕的神圣应许。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="以赛亚书 35:10; 使徒行传 7:36; 耶利米书 31:11–12"> <span className="pl pl-1">祂带领祂的子民欢然离去，</span><br /><span className="pl pl-1">祂所拣选的百姓欢呼前行。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="申命记 6:10–11; 约书亚记 24:13; 诗篇 78:55"> <span className="pl pl-1">祂把列国的土地赐给他们，</span><br /><span className="pl pl-1">使他们获得别人的劳动成果。</span><br /></span>
<span className="v" id="v45" data-v="45" data-xref="申命记 4:40; 提多书 2:14; 以弗所书 2:8–10"> <span className="pl pl-1">祂这样做是要使他们持守祂的命令，</span><br /><span className="pl pl-1">遵行祂的律法。</span><br /><span className="pl pl-1">你们要赞美耶和华！</span></span>
</div>

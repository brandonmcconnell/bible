## 上帝的美善

<div className="bt">
<div className="hs">大卫在亚比米勒面前装疯，被赶出去后，作了此诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:18; 歌罗西书 3:17; 诗篇 145:1–2"> <span className="pl pl-1">我要常常称颂耶和华，</span><br /><span className="pl pl-1">我的口时刻赞美祂。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 9:24; 哥林多前书 1:31; 诗篇 119:74"> <span className="pl pl-1">我因耶和华而夸耀，</span><br /><span className="pl pl-1">困苦人听见必欢欣。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 69:30; 路加福音 1:46; 诗篇 148:1–14"> <span className="pl pl-1">要跟我们一同尊耶和华为大，</span><br /><span className="pl pl-1">让我们一起尊崇祂的名！</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="诗篇 34:17–19; 诗篇 3:4; 诗篇 10:17"> <span className="pl pl-1">我这可怜的人向祂呼求，</span><br /><span className="pl pl-1">祂就垂听，</span><br /><span className="pl pl-1">救我脱离一切困境。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 91:11; 但以理书 6:22; 希伯来书 1:14"> <span className="pl pl-1">祂的天使在敬畏祂的人四围安营，</span><br /><span className="pl pl-1">要搭救他们。</span><br /></span>

<span className="v" id="v9" data-v="9" data-xref="罗马书 8:32; 腓立比书 4:19; 诗篇 23:1"> <span className="pl pl-1">耶和华的圣民啊，</span><br /><span className="pl pl-1">你们要敬畏祂，</span><br /><span className="pl pl-1">因为敬畏祂的人一无所缺。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 84:11; 马太福音 6:32; 诗篇 104:21"> <span className="pl pl-1">猛狮也会忍饥挨饿，</span><br /><span className="pl pl-1">但寻求耶和华的人什么福分都不缺。</span></span>
</div>

<span className="v" id="v14" data-v="14" data-xref="诗篇 37:27; 彼得前书 3:11; 希伯来书 12:14"> <span className="pl pl-1">要弃恶行善，</span><br /><span className="pl pl-1">竭力追求和睦。</span><br /></span>

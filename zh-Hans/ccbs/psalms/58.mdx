## 祈求上帝惩罚恶人

<div className="bt">
<div className="hs">大卫作的诗，交给乐长，调用“休要毁坏”。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 57:1; 申命记 16:18–19; 诗篇 72:1–4"> <span className="pl pl-1">你们做官长的主持公道吗？</span><br /><span className="pl pl-1">你们的审判公正吗？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 94:20; 以赛亚书 10:1; 以西结书 22:27"> <span className="pl pl-1">不，你们心中图谋不义，</span><br /><span className="pl pl-1">你们在地上行凶作恶。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 51:5; 以赛亚书 48:8; 箴言 22:15"> <span className="pl pl-1">恶人生下来就步入歧途，</span><br /><span className="pl pl-1">一出母胎就离开正道，</span><br /><span className="pl pl-1">谎话连篇。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 140:3; 雅各书 3:8; 传道书 10:11"> <span className="pl pl-1">他们恶毒如蛇，</span><br /><span className="pl pl-1">像耳聋的眼镜蛇，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 8:17; 以赛亚书 19:3; 申命记 18:11"> <span className="pl pl-1">任法师的邪术再高超，</span><br /><span className="pl pl-1">也听不见他的咒语。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 3:7; 约伯记 4:10–11; 何西阿书 5:14"> <span className="pl pl-1">上帝啊，求你敲碎他们的牙齿；</span><br /><span className="pl pl-1">耶和华啊，</span><br /><span className="pl pl-1">求你拔掉这些猛狮的利齿。</span><br /></span>

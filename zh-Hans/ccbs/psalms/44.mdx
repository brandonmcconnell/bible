## 祈求上帝保护

<div className="bt">
<div className="hs">可拉后裔作的训诲诗，交给乐长。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 78:3–6; 出埃及记 13:14–15; 申命记 6:20"> <span className="pl pl-1">上帝啊，</span><br /><span className="pl pl-1">我们亲耳听过祖先讲述你在古时，</span><br /><span className="pl pl-1">在我们祖先时代的作为。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 78:55; 出埃及记 15:17; 约书亚记 11:23"> <span className="pl pl-1">你亲手赶出外族，</span><br /><span className="pl pl-1">把我们的祖先安置在那里；</span><br /><span className="pl pl-1">你击溃列邦，</span><br /><span className="pl pl-1">使我们的祖先兴旺发达。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:7–8; 申命记 8:17–18; 约书亚记 24:12"> <span className="pl pl-1">他们不是靠自己的刀剑征服那里，</span><br /><span className="pl pl-1">不是靠自己的臂膀得胜，</span><br /><span className="pl pl-1">而是靠你的右手、你的臂膀和你的容光，</span><br /><span className="pl pl-1">因为你爱他们。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 74:12; 诗篇 42:8; 诗篇 149:2"> <span className="pl pl-1">你是我的君王，我的上帝；</span><br /><span className="pl pl-1">你命定雅各得胜。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 108:13; 诗篇 60:12; 诗篇 118:10–13"> <span className="pl pl-1">我们靠你击退敌人，</span><br /><span className="pl pl-1">靠你的名践踏仇敌。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 20:7; 何西阿书 1:7; 撒母耳记上 17:47"> <span className="pl pl-1">我不倚靠我的弓，</span><br /><span className="pl pl-1">我的剑不能使我得胜。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 1:5; 诗篇 132:18; 诗篇 136:24"> <span className="pl pl-1">只有你救我们脱离敌人，</span><br /><span className="pl pl-1">使我们的仇敌蒙羞。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 34:2; 哥林多前书 1:29–31; 耶利米书 9:24"> <span className="pl pl-1">我们终日凭上帝夸耀，</span><br /><span className="pl pl-1">我们永远赞美你的名。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 74:1; 诗篇 60:10; 诗篇 60:1"> <span className="pl pl-1">现在你却丢弃我们，让我们受辱，</span><br /><span className="pl pl-1">不再同我们的军队出战。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 7:8; 利未记 26:17; 约书亚记 7:12"> <span className="pl pl-1">你使我们在仇敌面前败退，</span><br /><span className="pl pl-1">遭敌人掳掠。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 4:27; 申命记 28:64; 罗马书 8:36"> <span className="pl pl-1">你使我们如被宰杀的羊，</span><br /><span className="pl pl-1">将我们分散在列国。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:13; 申命记 32:30; 以赛亚书 52:3–4"> <span className="pl pl-1">你把我们廉价卖掉，</span><br /><span className="pl pl-1">并未从买卖中获利。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 79:4; 诗篇 80:6; 诗篇 89:41"> <span className="pl pl-1">你使我们遭四邻辱骂，</span><br /><span className="pl pl-1">被周围人讥讽、嘲笑。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 24:9; 列王纪下 19:21; 约伯记 16:4"> <span className="pl pl-1">你使我们成为列国的笑柄，</span><br /><span className="pl pl-1">列邦对我们连连摇头。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 69:7; 耶利米书 3:25; 诗篇 89:45"> <span className="pl pl-1">我终日受辱，满脸尽是耻辱，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:2; 诗篇 74:10; 诗篇 74:18"> <span className="pl pl-1">因为咒骂和毁谤我的人讥笑我，</span><br /><span className="pl pl-1">仇敌报复我。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 9:13; 申命记 8:14; 申命记 6:12"> <span className="pl pl-1">虽然这一切临到我们身上，</span><br /><span className="pl pl-1">我们却没有忘记你，</span><br /><span className="pl pl-1">也没有违背你的约。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:51; 诗篇 119:157; 诗篇 78:57"> <span className="pl pl-1">我们对你没有异心，</span><br /><span className="pl pl-1">也没有偏离你的道路。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 3:5; 诗篇 23:4; 耶利米书 14:17"> <span className="pl pl-1">你在豺狼出没的地方压碎我们，</span><br /><span className="pl pl-1">使死亡的阴影笼罩我们。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 81:9; 约伯记 11:13; 申命记 6:14"> <span className="pl pl-1">倘若我们忘记我们上帝的名，</span><br /><span className="pl pl-1">或举手向外邦的神明祷告，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:10; 耶利米书 23:24; 希伯来书 4:12–13"> <span className="pl pl-1">上帝难道察觉不到吗？</span><br /><span className="pl pl-1">祂洞悉人心中的秘密。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 8:36; 以赛亚书 53:7; 诗篇 44:11"> <span className="pl pl-1">为了你，我们终日出生入死，</span><br /><span className="pl pl-1">被视为待宰的羊。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="约伯记 13:24; 申命记 32:20; 诗篇 42:9"> <span className="pl pl-1">你为何掩面不理我们，</span><br /><span className="pl pl-1">忘记我们所受的苦难和压迫？</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 119:25; 耶利米哀歌 4:5; 以赛亚书 51:23"> <span className="pl pl-1">我们仆倒在地，横卧在尘土中。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 130:7–8; 诗篇 25:22; 诗篇 26:11"> <span className="pl pl-1">求你起来帮助我们，</span><br /><span className="pl pl-1">因你的慈爱而救赎我们。</span></span>

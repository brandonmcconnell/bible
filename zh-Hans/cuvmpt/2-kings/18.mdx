## 希西家做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 28:27–1; 馬太福音 1:9–10; 歷代志上 3:13"> 以色列王以拉的兒子何細亞第三年，猶大王亞哈斯的兒子希西家登基。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 29:1–2"> 他登基的時候年二十五歲，在耶路撒冷做王二十九年。他母親名叫亞比，是撒迦利雅的女兒。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 20:3; 列王紀上 11:4; 歷代志下 31:20–21"> 希西家行耶和華眼中看為正的事，效法他祖大衛一切所行的。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 31:1; 民數記 21:8–9; 列王紀下 18:22"> 他廢去丘壇，毀壞柱像，砍下木偶，打碎摩西所造的銅蛇，因為到那時以色列人仍向銅蛇燒香；希西家叫銅蛇為銅塊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：人稱銅蛇為銅像。">a</a></sup>。</span>
</div>
</div>

## 倚靠耶和華謹守其誡

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:25; 列王紀下 19:10; 馬太福音 27:43"> 希西家倚靠耶和華以色列的神，在他前後的猶大列王中沒有一個及他的。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 23:8; 申命記 10:20; 約翰福音 14:15"> 因為他專靠耶和華，總不離開，謹守耶和華所吩咐摩西的誡命。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:31; 創世記 39:2–3; 列王紀下 16:7"> 耶和華與他同在，他無論往何處去盡都亨通。他背叛，不肯侍奉亞述王。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 14:29; 列王紀下 17:9; 歷代志下 28:18"> 希西家攻擊非利士人，直到加沙並加沙的四境，從瞭望樓到堅固城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿書 10:14; 列王紀下 17:3–23; 列王紀下 18:1"> 希西家王第四年，就是以色列王以拉的兒子何細亞第七年，亞述王撒縵以色上來圍困撒馬利亞。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 6:7; 阿摩司書 9:1–4; 彌迦書 1:6–9"> 過了三年，就攻取了城。希西家第六年，以色列王何細亞第九年，撒馬利亞被攻取了。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 5:26; 列王紀下 17:6; 以賽亞書 37:12"> 亞述王將以色列人擄到亞述，把他們安置在哈臘與歌散的哈博河邊並瑪代人的城邑；</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:17; 彼得前書 2:8; 彌迦書 3:4"> 都因他們不聽從耶和華他們神的話，違背他的約，就是耶和華僕人摩西吩咐他們所當守的。</span>
</div>
</div>

## 西拿基立攻猶大諸邑

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 36:1–22; 歷代志下 32:1–23; 以賽亞書 7:17–25"> 希西家王十四年，亞述王西拿基立上來攻擊猶大的一切堅固城，將城攻取。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 18:7; 路加福音 14:32; 列王紀上 20:4"> 猶大王希西家差人往拉吉去見亞述王，說：「我有罪了，求你離開我。凡你罰我的，我必承當。」於是亞述王罰猶大王希西家銀子三百他連得，金子三十他連得。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 16:8; 列王紀上 15:18–19; 列王紀下 12:18"> 希西家就把耶和華殿裡和王宮府庫裡所有的銀子都給了他。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 29:3; 列王紀上 6:31–35"> 那時猶大王希西家將耶和華殿門上的金子和他自己包在柱上的金子都刮下來，給了亞述王。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 20:1; 列王紀下 20:20; 以賽亞書 7:3"> 亞述王從拉吉差遣他珥探、拉伯撒利和拉伯沙基率領大軍往耶路撒冷，到希西家王那裡去。他們上到耶路撒冷，就站在上池的水溝旁，在漂布地的大路上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 19:2; 以賽亞書 36:3; 撒母耳記下 8:16–17"> 他們呼叫王的時候，就有希勒家的兒子家宰以利亞敬，並書記舍伯那和亞薩的兒子史官約亞，出來見他們。</span>
</div>
</div>

## 拉伯沙基之狂語

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 36:4; 列王紀下 19:10; 以賽亞書 10:8–14"> 拉伯沙基說：「你們去告訴希西家說：『亞述大王如此說：你所倚靠的有什麼可仗賴的呢？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你說有打仗的計謀和能力，我看不過是虛話！你到底倚靠誰才背叛我呢？</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 30:7; 以西結書 29:6–7; 以賽亞書 30:2–3"> 看哪，你所倚靠的埃及是那壓傷的葦杖，人若靠這杖，就必刺透他的手，埃及王法老向一切倚靠他的人也是這樣。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 31:1; 列王紀下 18:4–5; 馬太福音 27:43"> 你們若對我說「我們倚靠耶和華我們的神」，希西家豈不是將神的丘壇和祭壇廢去，且對猶大和耶路撒冷的人說「你們當在耶路撒冷這壇前敬拜」嗎？』</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:42; 列王紀上 20:10; 尼希米記 4:2–5"> 現在，你把當頭給我主亞述王，我給你二千匹馬，看你這一面騎馬的人夠不夠！</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 10:8; 申命記 17:16; 以賽亞書 36:6"> 若不然，怎能打敗我主臣僕中最小的軍長呢？你竟倚靠埃及的戰車馬兵嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 19:6; 以賽亞書 10:5–6; 列王紀下 19:22–37"> 現在我上來攻擊毀滅這地，豈沒有耶和華的意思嗎？耶和華吩咐我說：『你上去攻擊毀滅這地吧！』」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 4:7; 但以理書 2:4; 以賽亞書 36:11–12"> 希勒家的兒子以利亞敬和舍伯那並約亞對拉伯沙基說：「求你用亞蘭言語和僕人說話，因為我們懂得。不要用猶大言語和我們說話，達到城上百姓的耳中。」</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 73:8; 耶利米哀歌 4:5; 以西結書 4:15"> 拉伯沙基說：「我主差遣我來，豈是單對你和你的主說這些話嗎？不也是對這些坐在城上，要與你們一同吃自己糞喝自己尿的人說嗎？」</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 36:13–18; 以賽亞書 10:8–13; 以西結書 29:3"> 於是拉伯沙基站著，用猶大言語大聲喊著說：「你們當聽亞述大王的話！</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 32:15; 帖撒羅尼迦後書 2:8; 歷代志下 32:11"> 王如此說：『你們不要被希西家欺哄了，因他不能救你們脫離我的手。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 125:1–2; 路加福音 23:35; 列王紀下 19:32–34"> 也不要聽希西家使你們倚靠耶和華說：「耶和華必要拯救我們，這城必不交在亞述王的手中。」』</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 4:25; 列王紀上 4:20; 撒迦利亞書 3:10"> 不要聽希西家的話，因亞述王如此說：『你們要與我和好，出來投降我，各人就可以吃自己葡萄樹和無花果樹的果子，喝自己井裡的水。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 8:7–9; 出埃及記 3:8; 申命記 11:12"> 等我來領你們到一個地方，與你們本地一樣，就是有五穀和新酒之地，有糧食和葡萄園之地，有橄欖樹和蜂蜜之地，好使你們存活，不至於死。希西家勸導你們說：「耶和華必拯救我們。」你們不要聽他的話。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 10:10–11; 列王紀下 19:12–13; 歷代志下 32:19"> 列國的神，有哪一個救他本國脫離亞述王的手呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 10:9; 列王紀下 17:23–33; 耶利米書 49:23"> 哈馬、亞珥拔的神在哪裡呢？西法瓦音、希拿、以瓦的神在哪裡呢？他們曾救撒馬利亞脫離我的手嗎？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理書 3:15; 以賽亞書 10:15; 出埃及記 5:2"> 這些國的神有誰曾救自己的國脫離我的手呢？難道耶和華能救耶路撒冷脫離我的手嗎？』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="阿摩司書 5:13; 箴言 9:7; 馬太福音 7:6"> 百姓靜默不言，並不回答一句，因為王曾吩咐說：「不要回答他。」</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 22:11; 創世記 37:29; 列王紀下 5:7"> 當下，希勒家的兒子家宰以利亞敬，和書記舍伯那並亞薩的兒子史官約亞，都撕裂衣服來到希西家那裡，將拉伯沙基的話告訴了他。</span>
</div>
</div>

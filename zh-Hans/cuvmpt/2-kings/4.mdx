## 以利沙為嫠婦行奇事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:25; 列王紀下 2:3; 尼希米記 5:2–5"> 有一個先知門徒的妻哀求以利沙說：「你僕人我丈夫死了，他敬畏耶和華是你所知道的。現在有債主來，要取我兩個兒子做奴僕。」</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 17:12; 雅各書 2:5; 列王紀下 6:26–27"> 以利沙問她說：「我可以為你做什麼呢？你告訴我，你家裡有什麼？」她說：「婢女家中除了一瓶油之外，沒有什麼。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 2:7; 詩篇 81:10; 約翰福音 16:24"> 以利沙說：「你去，向你眾鄰舍借空器皿，不要少借。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 8:5–9; 馬太福音 6:6; 以弗所書 3:20"> 回到家裡，關上門，你和你兒子在裡面將油倒在所有的器皿裡，倒滿了的放在一邊。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 5:11; 希伯來書 11:7–8; 列王紀上 17:15–16"> 於是婦人離開以利沙去了，關上門，自己和兒子在裡面，兒子把器皿拿來，她就倒油。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 14:20; 列王紀下 13:19; 路加福音 6:19"> 器皿都滿了，她對兒子說：「再給我拿器皿來。」兒子說：「再沒有器皿了。」油就止住了。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦後書 3:7–12; 列王紀上 12:22; 羅馬書 12:17"> 婦人去告訴神人，神人說：「你去賣油還債，所剩的，你和你兒子可以靠著度日。」</span>
</div>
</div>

## 書念婦接待以利沙

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 19:18; 創世記 19:3; 列王紀下 4:11–12"> 一日，以利沙走到書念，在那裡有一個大戶的婦人強留他吃飯。此後以利沙每從那裡經過，就進去吃飯。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 17:24; 箴言 31:10–11; 列王紀下 4:7"> 婦人對丈夫說：「我看出那常從我們這裡經過的是聖潔的神人。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:13; 馬太福音 10:41–42; 馬太福音 25:40"> 我們可以為他在牆上蓋一間小樓，在其中安放床榻、桌子、椅子、燈臺，他來到我們這裡，就可以住在其間。」</span>
<span className="v" id="v11" data-v="11"> 一日以利沙來到那裡，就進了那樓躺臥。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 8:4–5; 列王紀下 3:11; 列王紀下 4:29–31"> 以利沙吩咐僕人基哈西說：「你叫這書念婦人來。」他就把婦人叫了來，婦人站在以利沙面前。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 1:16–18; 腓立比書 4:18–19; 希伯來書 6:10"> 以利沙吩咐僕人說：「你對她說：『你既為我們費了許多心思，可以為你做什麼呢？你向王或元帥有所求的沒有？』」她回答說：「我在我本鄉安居無事。」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:7; 創世記 15:2–3; 撒母耳記上 1:8"> 以利沙對僕人說：「究竟當為她做什麼呢？」基哈西說：「她沒有兒子，她丈夫也老了。」</span>
<span className="v" id="v15" data-v="15"> 以利沙說：「再叫她來。」於是叫了她來，她就站在門口。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 18:10; 路加福音 1:13; 列王紀下 4:28"> 以利沙說：「明年到這時候，你必抱一個兒子。」她說：「神人，我主啊，不要那樣欺哄婢女！」</span>
</div>
</div>

## 子死以利沙蘇之

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路得記 2:4"> 孩子漸漸長大，一日到他父親和收割的人那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 14:1–2; 耶利米書 4:19"> 他對父親說：「我的頭啊！我的頭啊！」他父親對僕人說：「把他抱到他母親那裡。」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:12; 約翰福音 11:3; 約翰福音 11:14"> 僕人抱去，交給他母親，孩子坐在母親的膝上，到晌午就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 4:32; 列王紀下 4:10; 列王紀下 4:7"> 他母親抱他上了樓，將他放在神人的床上，關上門出來，</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:38; 列王紀下 4:26; 約翰福音 11:3"> 呼叫她丈夫說：「你叫一個僕人，給我牽一匹驢來，我要快快地去見神人，就回來。」</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 10:10; 民數記 28:11; 歷代志上 23:31"> 丈夫說：「今日不是月朔，也不是安息日，你為何要去見他呢？」婦人說：「平安無事。」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 4:20; 列王紀上 13:13; 撒母耳記上 25:19–20"> 於是備上驢，對僕人說：「你快快趕著走，我若不吩咐你，就不要遲慢。」</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 2:25; 以賽亞書 35:2; 列王紀上 18:19"> 婦人就往迦密山去見神人。<br />神人遠遠地看見她，對僕人基哈西說：「看哪，書念的婦人來了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:36; 列王紀下 4:23; 撒母耳記上 17:18"> 你跑去迎接她，問她說：『你平安嗎？你丈夫平安嗎？孩子平安嗎？』」她說：「平安。」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 7:3; 創世記 18:17; 阿摩司書 3:7"> 婦人上了山，到神人那裡，就抱住神人的腳。基哈西前來要推開她，神人說：「由她吧！因為她心裡愁苦。耶和華向我隱瞞，沒有指示我。」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 30:1; 列王紀下 4:16"> 婦人說：「我何嘗向我主求過兒子呢？我豈沒有說過，不要欺哄我嗎？」</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 2:14; 列王紀上 18:46; 出埃及記 14:16"> 以利沙吩咐基哈西說：「你束上腰，手拿我的杖前去。若遇見人，不要向他問安，人若向你問安，也不要回答。要把我的杖放在孩子臉上。」</span>
<span className="v" id="v30" data-v="30" data-xref="路得記 1:16–18; 列王紀下 2:2; 出埃及記 33:12–16"> 孩子的母親說：「我指著永生的耶和華，又敢在你面前起誓：我必不離開你！」於是以利沙起身，隨著她去了。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 11:11; 馬可福音 5:39; 馬可福音 9:19–29"> 基哈西先去，把杖放在孩子臉上，卻沒有聲音，也沒有動靜。基哈西就迎著以利沙回來，告訴他說：「孩子還沒有醒過來。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 8:52–53; 約翰福音 11:17; 列王紀上 17:17"> 以利沙來到，進了屋子，看見孩子死了，放在自己的床上。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 6:6; 列王紀下 4:4; 使徒行傳 9:40"> 他就關上門，只有自己和孩子在裡面，他便祈禱耶和華。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 17:21; 使徒行傳 20:10"> 上床伏在孩子身上，口對口，眼對眼，手對手。既伏在孩子身上，孩子的身體就漸漸溫和了。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 8:5; 列王紀下 13:21; 列王紀上 17:22"> 然後他下來，在屋裡來往走了一趟，又上去伏在孩子身上。孩子打了七個噴嚏，就睜開眼睛了。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 11:35; 列王紀上 17:23; 路加福音 7:15"> 以利沙叫基哈西說：「你叫這書念婦人來。」於是叫了她來。以利沙說：「將你兒子抱起來。」</span>
<span className="v" id="v37" data-v="37" data-xref="希伯來書 11:35; 列王紀下 2:15; 列王紀上 17:24"> 婦人就進來，在以利沙腳前俯伏於地，抱起她兒子出去了。</span>
</div>
</div>

## 先知徒中毒以利沙解之

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王紀下 8:1; 列王紀下 2:3; 列王紀下 2:1"> 以利沙又來到吉甲，那地正有饑荒。先知門徒坐在他面前，他吩咐僕人說：「你將大鍋放在火上，給先知門徒熬湯。」</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米書 2:21; 以賽亞書 5:4; 馬太福音 15:13"> 有一個人去到田野掐菜，遇見一棵野瓜藤，就摘了一兜野瓜回來，切了擱在熬湯的鍋中，因為他們不知道是什麼東西。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 16:18; 出埃及記 15:23; 出埃及記 10:17"> 倒出來給眾人吃，吃的時候，都喊叫說：「神人哪，鍋中有致死的毒物！」所以眾人不能吃了。</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀下 2:21; 出埃及記 15:25; 哥林多前書 1:25"> 以利沙說：「拿點麵來。」就把麵撒在鍋中，說：「倒出來給眾人吃吧。」鍋中就沒有毒了。</span>
</div>
</div>

## 以二十餅飽百人

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 9:7; 約翰福音 6:9; 馬太福音 14:16–21"> 有一個人從巴力沙利沙來，帶著初熟大麥做的餅二十個並新穗子，裝在口袋裡送給神人。神人說：「把這些給眾人吃。」</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:13; 馬太福音 14:20; 約翰福音 6:9"> 僕人說：「這一點豈可擺給一百人吃呢？」以利沙說：「你只管給眾人吃吧，因為耶和華如此說：『眾人必吃了，還剩下。』」</span>
<span className="v" id="v44" data-v="44"> 僕人就擺在眾人面前。他們吃了，果然還剩下，正如耶和華所說的。</span>
</div>
</div>

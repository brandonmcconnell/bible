## 耶戶遺書耶斯列長老

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:30; 列王紀上 13:32; 列王紀上 21:8–14"> 亞哈有七十個兒子在撒馬利亞。耶戶寫信送到撒馬利亞，通知耶斯列的首領，就是長老和教養亞哈眾子的人，說：</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:6"> 「你們那裡既有你們主人的眾子和車馬、器械、堅固城，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 2:8–9; 列王紀上 12:20–21; 撒母耳記下 2:12–17"> 接了這信，就可以在你們主人的眾子中選擇一個賢能合宜的，使他坐他父親的位，你們也可以為你們主人的家爭戰。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 9:24; 列王紀下 9:27; 以賽亞書 27:4"> 他們卻甚懼怕，彼此說：「二王在他面前尚且站立不住，我們怎能站得住呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 20:32; 列王紀上 20:4; 約書亞記 9:11"> 家宰、邑宰和長老並教養眾子的人打發人去見耶戶，說：「我們是你的僕人，凡你所吩咐我們的都必遵行，我們不立誰做王。你看怎樣好就怎樣行。」</span>
</div>
</div>

## 戮亞哈眾子

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:20–23; 申命記 5:9; 民數記 25:4"> 耶戶又給他們寫信說：「你們若歸順我，聽從我的話，明日這時候要將你們主人眾子的首級帶到耶斯列來見我。」那時王的兒子七十人都住在教養他們那城中的尊貴人家裡。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:21; 列王紀下 11:1; 列王紀下 10:9"> 信一到，他們就把王的七十個兒子殺了，將首級裝在筐裡，送到耶斯列耶戶那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 21:23; 撒母耳記下 11:18–21; 馬可福音 6:28"> 有使者來告訴耶戶說：「他們將王眾子的首級送來了。」耶戶說：「將首級在城門口堆做兩堆，擱到明日。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:14–24; 以賽亞書 5:3; 何西阿書 1:4"> 次日早晨，耶戶出來，站著對眾民說：「你們都是公義的。我背叛我主人，將他殺了，這些人卻是誰殺的呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:29; 列王紀上 21:19; 列王紀下 9:7–10"> 由此可知，耶和華指著亞哈家所說的話一句沒有落空，因為耶和華藉他僕人以利亞所說的話都成就了。」</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 18:19; 列王紀上 18:19; 列王紀上 22:6"> 凡亞哈家在耶斯列所剩下的人和他的大臣、密友、祭司，耶戶盡都殺了，沒有留下一個。</span>
</div>
</div>

## 戮亞哈謝昆弟

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶戶起身往撒馬利亞去。在路上，牧人剪羊毛之處，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 8:29; 列王紀下 8:24; 歷代志下 21:17"> 遇見猶大王亞哈謝的弟兄，問他們說：「你們是誰？」回答說：「我們是亞哈謝的弟兄，現在下去要問王和太后的眾子安。」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 22:10; 列王紀下 10:6; 列王紀下 10:10–11"> 耶戶吩咐說：「活捉他們！」跟從的人就活捉了他們，將他們殺在剪羊毛之處的坑邊，共四十二人，沒有留下一個。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 35:14–19; 以斯拉記 10:19; 以西結書 17:18"> 耶戶從那裡前行，恰遇利甲的兒子約拿達來迎接他。耶戶問他安，對他說：「你誠心待我像我誠心待你嗎？」約拿達回答說：「是。」耶戶說：「若是這樣，你向我伸手。」他就伸手，耶戶拉他上車。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 19:10; 馬太福音 6:5; 列王紀下 10:31"> 耶戶說：「你和我同去，看我為耶和華怎樣熱心。」於是請他坐在車上。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 9:8; 歷代志下 22:8; 瑪拉基書 4:1"> 到了撒馬利亞，就把撒馬利亞亞哈家剩下的人都殺了，直到滅盡，正如耶和華對以利亞所說的。</span>
</div>
</div>

## 計殺拜巴力者

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 16:31–32; 列王紀下 3:2; 羅馬書 3:8"> 耶戶招聚眾民，對他們說：「亞哈侍奉巴力還冷淡，耶戶卻更熱心。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:6; 列王紀上 18:19; 哥林多後書 11:3"> 現在我要給巴力獻大祭，應當叫巴力的眾先知和一切拜巴力的人，並巴力的眾祭司都到我這裡來，不可缺少一個。凡不來的必不得活。」耶戶這樣行，是用詭計要殺盡拜巴力的人。</span>
<span className="v" id="v20" data-v="20" data-xref="約珥書 1:14; 出埃及記 32:5; 列王紀上 18:19–20"> 耶戶說：「要為巴力宣告嚴肅會。」於是宣告了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 16:32; 列王紀下 11:18; 約珥書 3:2"> 耶戶差人走遍以色列地，凡拜巴力的人都來齊了，沒有一個不來的。他們進了巴力廟，巴力廟中從前邊直到後邊都滿了人。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:2; 馬太福音 22:11–12"> 耶戶吩咐掌管禮服的人說：「拿出禮服來，給一切拜巴力的人穿。」他就拿出禮服來給了他們。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:30; 馬太福音 25:32–33; 馬太福音 13:41"> 耶戶和利甲的兒子約拿達進了巴力廟，對拜巴力的人說：「你們察看察看，在你們這裡不可有耶和華的僕人，只可容留拜巴力的人。」</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:30–42"> 耶戶和約拿達進去獻平安祭和燔祭。耶戶先安排八十人在廟外，吩咐說：「我將這些人交在你們手中，若有一人脫逃，誰放的必叫他償命！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="啟示錄 16:6–7; 以西結書 22:21–22; 列王紀上 18:40"> 耶戶獻完了燔祭，就出來吩咐護衛兵和眾軍長說：「你們進去殺他們，不容一人出來！」護衛兵和軍長就用刀殺他們，將屍首拋出去，便到巴力廟的城去了。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:23; 列王紀下 3:2; 列王紀下 19:18"> 將巴力廟中的柱像都拿出來燒了，</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 3:29; 以斯拉記 6:11; 但以理書 2:5"> 毀壞了巴力柱像，拆毀了巴力廟作為廁所，直到今日。</span>
<span className="v" id="v28" data-v="28"> 這樣，耶戶在以色列中滅了巴力。</span>
</div>
</div>

## 耶戶仍拜金犢

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:28–30; 列王紀上 14:16; 列王紀上 13:33–34"> 只是耶戶不離開尼八的兒子耶羅波安使以色列人陷在罪裡的那罪，就是拜伯特利和但的金牛犢。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 10:35; 列王紀下 13:1; 列王紀下 13:10"> 耶和華對耶戶說：「因你辦好我眼中看為正的事，照我的心意待亞哈家，你的子孫必接續你坐以色列的國位，直到四代。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 10:29; 箴言 4:23; 希伯來書 2:1"> 只是耶戶不盡心遵守耶和華以色列神的律法，不離開耶羅波安使以色列人陷在罪裡的那罪。</span>
</div>
</div>

## 哈薛攻以色列地

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀下 8:12; 列王紀上 19:17; 列王紀下 13:22"> 在那些日子，耶和華才割裂以色列國，使哈薛攻擊以色列的境界，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司書 1:3–4; 申命記 2:36; 約書亞記 13:9–12"> 乃是約旦河東，基列全地，從靠近亞嫩谷邊的亞羅珥起，就是基列和巴珊的迦得人、魯本人、瑪拿西人之地。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀上 14:19"> 耶戶其餘的事，凡他所行的和他的勇力，都寫在《以色列諸王記》上。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀上 1:21"> 耶戶與他列祖同睡，葬在撒馬利亞。他兒子約哈斯接續他做王。</span>
<span className="v" id="v36" data-v="36"> 耶戶在撒馬利亞做以色列王二十八年。</span>
</div>
</div>

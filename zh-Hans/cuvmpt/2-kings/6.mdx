<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 2:3; 列王紀下 4:1; 約書亞記 17:14"> 先知門徒對以利沙說：「看哪，我們同你所住的地方過於窄小。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 21:3; 使徒行傳 18:3; 帖撒羅尼迦前書 2:9"> 求你容我們往約旦河去，各人從那裡取一根木料建造房屋居住。」他說：「你們去吧。」</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 6:28; 士師記 19:6; 列王紀下 5:23"> 有一人說：「求你與僕人同去。」回答說：「我可以去。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 19:5; 申命記 29:11"> 於是以利沙與他們同去。到了約旦河，就砍伐樹木。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:21; 傳道書 10:10; 列王紀下 6:15"> 有一人砍樹的時候，斧頭掉在水裡，他就呼叫說：「哀哉！我主啊，這斧子是借的。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 2:21; 馬可福音 8:23–25; 列王紀下 4:41"> 神人問說：「掉在哪裡了？」他將那地方指給以利沙看。以利沙砍了一根木頭，拋在水裡，斧頭就漂上來了。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 4:36; 出埃及記 4:4; 列王紀下 4:7"> 以利沙說：「拿起來吧。」那人就伸手拿起來了。</span>
</div>
</div>

## 亞蘭人圍多坍

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 6:24; 箴言 21:30; 箴言 20:18"> 亞蘭王與以色列人爭戰，和他的臣僕商議說：「我要在某處某處安營。」</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 3:7; 啟示錄 1:1; 列王紀下 6:12"> 神人打發人去見以色列王，說：「你要謹慎，不要從某處經過，因為亞蘭人從那裡下來了。」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 13:14; 列王紀下 5:14; 使徒行傳 27:24"> 以色列王差人去窺探神人所告訴、所警戒他去的地方，就防備未受其害，不止一兩次。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 18:7–11; 以賽亞書 57:20–21; 馬太福音 2:3–12"> 亞蘭王因這事心裡驚疑，召了臣僕來，對他們說：「我們這裡有誰幫助以色列王，你們不指給我嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 2:28–30; 阿摩司書 3:7; 列王紀下 6:9–10"> 有一個臣僕說：「我主我王，無人幫助他，只有以色列中的先知以利沙將王在臥房所說的話告訴以色列王了。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 37:17; 約翰福音 11:47–53; 撒母耳記上 23:22–23"> 王說：「你們去探他在哪裡，我好打發人去捉拿他。」有人告訴王說：「他在多坍。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 18:17; 撒母耳記上 24:2; 撒母耳記上 23:26"> 王就打發車馬和大軍往那裡去，夜間到了，圍困那城。</span>
</div>
</div>

## 以利沙慰安其僕

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="馬太福音 8:26; 歷代志下 20:12; 詩篇 53:5"> 神人的僕人清早起來出去，看見車馬軍兵圍困了城。僕人對神人說：「哀哉！我主啊，我們怎樣行才好呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 41:10–14; 羅馬書 8:31; 約翰一書 4:4"> 神人說：「不要懼怕，與我們同在的比與他們同在的更多。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 68:17; 詩篇 34:7; 撒迦利亞書 6:1–7"> 以利沙禱告說：「耶和華啊，求你開這少年人的眼目，使他能看見。」耶和華開他的眼目，他就看見滿山有火車火馬圍繞以利沙。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 13:11; 約翰福音 12:40; 創世記 19:11"> 敵人下到以利沙那裡，以利沙禱告耶和華說：「求你使這些人的眼目昏迷。」耶和華就照以利沙的話，使他們的眼目昏迷。</span>
</div>
</div>

## 領敵入邑以飲食之

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 24:16; 撒母耳記下 16:18–19; 路加福音 9:23"> 以利沙對他們說：「這不是那道，也不是那城。你們跟我去，我必領你們到所尋找的人那裡。」於是領他們到了撒馬利亞。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 6:17; 路加福音 24:31; 路加福音 16:23"> 他們進了撒馬利亞，以利沙禱告說：「耶和華啊，求你開這些人的眼目，使他們能看見。」耶和華開他們的眼目，他們就看見了，不料，是在撒馬利亞的城中。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 5:13; 列王紀下 8:9; 列王紀下 2:12"> 以色列王見了他們，就問以利沙說：「我父啊，我可以擊殺他們嗎？」</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 12:20–21; 創世記 48:22; 何西阿書 2:18"> 回答說：「不可擊殺他們。就是你用刀用弓擄來的，豈可擊殺他們呢<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：也不可擊殺，何況這些人呢。">a</a></sup>？當在他們面前設擺飲食，使他們吃喝，回到他們的主人那裡。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 5:2; 列王紀下 24:2; 路加福音 6:35"> 王就為他們預備了許多食物。他們吃喝完了，打發他們回到他們主人那裡。從此，亞蘭軍不再犯以色列境了。</span>
</div>
</div>

## 亞蘭王圍撒馬利亞

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:1; 列王紀上 22:31; 傳道書 9:14"> 此後，亞蘭王便哈達聚集他的全軍，上來圍困撒馬利亞。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 6:28–29; 耶利米書 14:18; 耶利米書 14:13–15"> 於是撒馬利亞被圍困，有饑荒，甚至一個驢頭值銀八十舍客勒，二升鴿子糞值銀五舍客勒。</span>
</div>
</div>

## 邑人絕糧易子而食

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:4; 以賽亞書 10:3; 路加福音 18:3"> 一日，以色列王在城上經過，有一個婦人向他呼叫說：「我主我王啊，求你幫助！」</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 118:8–9; 詩篇 124:1–3; 詩篇 60:11"> 王說：「耶和華不幫助你，我從何處幫助你？是從禾場，是從酒榨呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 14:5; 士師記 18:23; 耶利米哀歌 4:10"> 王問婦人說：「你有什麼苦處？」她回答說：「這婦人對我說：『將你的兒子取來，我們今日可以吃，明日可以吃我的兒子。』</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 26:29; 申命記 28:53; 申命記 28:57"> 我們就煮了我的兒子吃了。次日，我對她說：『要將你的兒子取來，我們可以吃。』她卻將她的兒子藏起來了。」</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 21:27; 列王紀下 5:7; 列王紀下 19:1"> 王聽見婦人的話，就撕裂衣服；王在城上經過，百姓看見王貼身穿著麻衣。</span>
<span className="v" id="v31" data-v="31" data-xref="路得記 1:17; 列王紀上 19:2; 約翰福音 11:50"> 王說：「我今日若容沙法的兒子以利沙的頭仍在他項上，願神重重地降罰於我！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西結書 20:1; 列王紀上 18:4; 以西結書 8:1"> 那時，以利沙正坐在家中，長老也與他同坐。王打發一個伺候他的人去，他還沒有到，以利沙對長老說：「你們看這凶手之子，打發人來斬我的頭。你們看著使者來到，就關上門，用門將他推出去。在他後頭不是有他主人腳步的響聲嗎？」</span>
<span className="v" id="v33" data-v="33" data-xref="約伯記 2:9; 以賽亞書 8:21; 創世記 4:13"> 正說話的時候，使者來到，王也到了，說：「這災禍是從耶和華那裡來的，我何必再仰望耶和華呢？」</span>
</div>
</div>

## 摩押王米沙叛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 1:17; 列王紀上 22:51; 列王紀下 8:16"> 猶大王約沙法十八年，亞哈的兒子約蘭在撒馬利亞登基，做了以色列王十二年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 10:18; 列王紀下 10:26–28; 列王紀上 21:25"> 他行耶和華眼中看為惡的事，但不至像他父母所行的，因為除掉他父所造巴力的柱像。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀下 15:18"> 然而，他貼近尼八的兒子耶羅波安使以色列人陷在罪裡的那罪，總不離開。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 8:2; 創世記 26:13–14; 約伯記 1:3"> 摩押王米沙牧養許多羊，每年將十萬羊羔的毛和十萬公綿羊的毛給以色列王進貢。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 1:1; 列王紀下 8:20; 歷代志下 21:8–10"> 亞哈死後，摩押王背叛以色列王。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 24:1–25; 撒母耳記上 11:8; 撒母耳記上 15:4"> 那時約蘭王出撒馬利亞，數點以色列眾人。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 22:4; 歷代志下 22:10–12; 歷代志下 18:3"> 前行的時候，差人去見猶大王約沙法，說：「摩押王背叛我，你肯同我去攻打摩押嗎？」他說：「我肯上去。你我不分彼此，我的民與你的民一樣，我的馬與你的馬一樣。」</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 1:2–3; 民數記 21:4"> 約蘭說：「我們從哪條路上去呢？」回答說：「從以東曠野的路上去。」</span>
</div>
</div>

## 三王合攻摩押

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 22:47; 民數記 20:2; 出埃及記 17:1"> 於是，以色列王和猶大王並以東王都一同去。繞行七日的路程，軍隊和所帶的牲畜沒有水喝。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:34–36; 以賽亞書 51:20; 以賽亞書 8:21"> 以色列王說：「哀哉！耶和華招聚我們這三王，乃要交在摩押人的手裡！」</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 22:7; 列王紀上 19:21; 列王紀下 3:3"> 約沙法說：「這裡不是有耶和華的先知嗎？我們可以託他求問耶和華。」以色列王的一個臣子回答說：「這裡有沙法的兒子以利沙，就是從前服侍以利亞的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：倒水在以利亞手上的。">a</a></sup>。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 5:15; 列王紀下 2:21; 以賽亞書 60:14"> 約沙法說：「他必有耶和華的話。」於是以色列王和約沙法並以東王都下去見他。</span>
</div>
</div>

## 以利沙之訓導與預言

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:6; 列王紀上 18:19; 列王紀上 22:10–11"> 以利沙對以色列王說：「我與你何干？去問你父親的先知和你母親的先知吧！」以色列王對他說：「不要這樣說，耶和華招聚我們這三王，乃要交在摩押人的手裡。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 5:16; 列王紀上 17:1; 歷代志下 19:3–4"> 以利沙說：「我指著所侍奉永生的萬軍耶和華起誓，我若不看猶大王約沙法的情面，必不理你，不顧你。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:23; 以弗所書 5:18–19; 以西結書 1:3"> 現在你們給我找一個彈琴的來。」彈琴的時候，耶和華的靈<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：手。">b</a></sup>就降在以利沙身上。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 2:16–18; 列王紀下 4:3"> 他便說：「耶和華如此說：你們要在這谷中滿處挖溝。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:35; 以賽亞書 41:17–18; 以賽亞書 48:21"> 因為耶和華如此說：你們雖不見風，不見雨，這谷必滿了水，使你們和牲畜有水喝。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 32:27; 路加福音 1:37; 耶利米書 32:17"> 在耶和華眼中這還算為小事，他也必將摩押人交在你們手中。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 13:17; 申命記 20:19–20; 士師記 6:16"> 你們必攻破一切堅城美邑，砍伐各種佳樹，塞住一切水泉，用石頭糟蹋一切美田。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 29:39–40; 但以理書 9:21; 列王紀上 18:36"> 次日早晨，約在獻祭的時候，有水從以東而來，遍地就滿了水。</span>
</div>
</div>

## 摩押人敗遁

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所書 6:14; 列王紀上 20:11"> 摩押眾人聽見這三王上來要與他們爭戰，凡能頂盔貫甲的，無論老少，盡都聚集站在邊界上。</span>
<span className="v" id="v22" data-v="22"> 次日早晨，日光照在水上，摩押人起來，看見對面水紅如血，</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 5:30; 出埃及記 15:9; 以賽亞書 10:14"> 就說：「這是血啊！必是三王互相擊殺，俱都滅亡。摩押人哪，我們現在去搶奪財物吧！」</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:3–4; 約書亞記 8:20–22; 士師記 20:40–46"> 摩押人到了以色列營，以色列人就起來攻打他們，以致他們在以色列人面前逃跑。以色列人往前追殺摩押人，直殺入摩押的境內，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 16:7; 耶利米書 48:36; 耶利米書 48:31"> 拆毀摩押的城邑，各人拋石填滿一切美田，塞住一切水泉，砍伐各種佳樹，只剩下吉珥哈列設的石牆，甩石的兵在四圍攻打那城。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 3:9; 阿摩司書 2:1"> 摩押王見陣勢甚大，難以對敵，就率領七百拿刀的兵，要衝過陣去到以東王那裡，卻是不能。</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 6:7; 申命記 12:31; 士師記 11:31"> 便將那應當接續他做王的長子，在城上獻為燔祭。以色列人遭遇耶和華的大怒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：招人痛恨。">c</a></sup>，於是三王離開摩押王，各回本國去了。</span>
</div>
</div>

## 宣約書於民而立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 34:29–33; 歷代志下 30:2; 申命記 31:28"> 王差遣人招聚猶大和耶路撒冷的眾長老來。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 22:8; 申命記 31:10–13; 啟示錄 20:12"> 王和猶大眾人與耶路撒冷的居民，並祭司、先知和所有的百姓，無論大小，都一同上到耶和華的殿。王就把耶和華殿裡所得的約書念給他們聽。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 11:14; 列王紀下 11:17; 申命記 13:4"> 王站在柱旁，在耶和華面前立約，要盡心、盡性地順從耶和華，遵守他的誡命、法度、律例，成就這書上所記的約言。眾民都服從這約。</span>
</div>
</div>

## 命除偶像及諸惡行

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:3; 列王紀下 21:7; 歷代志下 33:3"> 王吩咐大祭司希勒家和副祭司並把門的，將那為巴力和亞舍拉並天上萬象所造的器皿，都從耶和華殿裡搬出來，在耶路撒冷外汲淪溪旁的田間燒了，把灰拿到伯特利去。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 44:17–19; 列王紀下 21:3–4; 何西阿書 10:5"> 從前猶大列王所立拜偶像的祭司在猶大城邑的丘壇和耶路撒冷的周圍燒香，現在王都廢去，又廢去向巴力和日、月、行星<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「行星」或作「十二宮」。">a</a></sup>並天上萬象燒香的人。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 34:4; 列王紀下 23:15; 列王紀上 14:23"> 又從耶和華殿裡，將亞舍拉搬到耶路撒冷外汲淪溪邊焚燒，打碎成灰，將灰撒在平民的墳上。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 15:12; 以西結書 16:16; 列王紀上 14:24"> 又拆毀耶和華殿裡孌童的屋子，就是婦女為亞舍拉織帳子的屋子。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 15:22; 約書亞記 21:17; 列王紀上 19:3"> 並且從猶大的城邑帶眾祭司來，汙穢祭司燒香的丘壇，從迦巴直到別是巴。又拆毀城門旁的丘壇，這丘壇在邑宰約書亞門前，進城門的左邊。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 44:10–14; 撒母耳記上 2:36; 瑪拉基書 2:8–9"> 但是丘壇的祭司不登耶路撒冷耶和華的壇，只在他們弟兄中間吃無酵餅。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:33; 耶利米書 19:6; 利未記 18:21"> 又汙穢欣嫩子谷的陀斐特，不許人在那裡使兒女經火獻給摩洛。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:16; 申命記 4:19; 歷代志下 14:5"> 又將猶大列王在耶和華殿門旁太監拿單米勒靠近遊廊的屋子向日頭所獻的馬廢去，且用火焚燒日車。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 21:5; 西番雅書 1:5; 耶利米書 19:13"> 猶大列王在亞哈斯樓頂上所築的壇和瑪拿西在耶和華殿兩院中所築的壇，王都拆毀，打碎了，就把灰倒在汲淪溪中。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 11:7; 列王紀上 11:5; 民數記 21:29"> 從前以色列王所羅門在耶路撒冷前、邪僻山右邊，為西頓人可憎的神亞斯她錄、摩押人可憎的神基抹、亞捫人可憎的神米勒公所築的丘壇，王都汙穢了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 7:5; 出埃及記 23:24; 列王紀下 23:16"> 又打碎柱像，砍下木偶，將人的骨頭充滿了那地方。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:6; 列王紀上 14:16; 列王紀上 21:22"> 他將伯特利的壇，就是叫以色列人陷在罪裡尼八的兒子耶羅波安所築的那壇，都拆毀焚燒，打碎成灰，並焚燒了亞舍拉。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 13:1–2; 列王紀上 13:32; 約翰福音 10:35"> 約西亞回頭，看見山上的墳墓，就打發人將墳墓裡的骸骨取出來，燒在壇上，汙穢了壇，正如從前神人宣傳耶和華的話。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 13:1; 列王紀上 13:30–31"> 約西亞問說：「我所看見的是什麼碑？」那城裡的人回答說：「先前有神人從猶大來，預先說王現在向伯特利壇所行的事，這就是他的墓碑。」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:31; 列王紀上 13:1–22"> 約西亞說：「由他吧，不要挪移他的骸骨。」他們就不動他的骸骨，也不動從撒馬利亞來那先知的骸骨。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 34:6–7; 列王紀下 17:9; 以西結書 8:17–18"> 從前以色列諸王在撒馬利亞的城邑建築丘壇的殿，惹動耶和華的怒氣，現在約西亞都廢去了，就如他在伯特利所行的一般。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 11:18; 歷代志下 34:5; 出埃及記 22:20"> 又將丘壇的祭司都殺在壇上，並在壇上燒人的骨頭，就回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 16:1–8; 民數記 9:2–5; 歷代志下 35:1–19"> 王吩咐眾民說：「你們當照這約書上所寫的，向耶和華你們的神守逾越節。」</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 30:1–3; 歷代志下 30:13–20; 歷代志下 35:3–19"> 自從士師治理以色列人和以色列王、猶大王的時候，直到如今，實在沒有守過這樣的逾越節，</span>
<span className="v" id="v23" data-v="23"> 只有約西亞王十八年在耶路撒冷向耶和華守這逾越節。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未記 19:31; 列王紀下 21:6; 創世記 31:19"> 凡猶大國和耶路撒冷所有交鬼的、行巫術的，與家中的神像和偶像，並一切可憎之物，約西亞盡都除掉，成就了祭司希勒家在耶和華殿裡所得律法書上所寫的話。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 18:5; 耶利米書 29:13; 申命記 6:5"> 在約西亞以前沒有王像他盡心、盡性、盡力地歸向耶和華，遵行摩西的一切律法，在他以後也沒有興起一個王像他。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:11–13; 列王紀下 24:4; 耶利米書 3:7–10"> 然而耶和華向猶大所發猛烈的怒氣仍不止息，是因瑪拿西諸事惹動他。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 18:11; 列王紀下 21:13; 列王紀下 21:4"> 耶和華說：「我必將猶大人從我面前趕出，如同趕出以色列人一般，我必棄掉我從前所選擇的這城耶路撒冷和我所說立我名的殿。」</span>
</div>
</div>

## 埃及王殺約西亞

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀下 20:20"> 約西亞其餘的事，凡他所行的，都寫在《猶大列王記》上。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 46:2; 歷代志下 35:20–24; 士師記 5:19"> 約西亞年間，埃及王法老尼哥上到幼發拉底河攻擊亞述王。約西亞王去抵擋他，埃及王遇見約西亞在米吉多，就殺了他。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 9:28; 歷代志下 36:1–4; 列王紀下 21:24"> 他的臣僕用車將他的屍首從米吉多送到耶路撒冷，葬在他自己的墳墓裡。國民膏約西亞的兒子約哈斯接續他父親做王。</span>
</div>
</div>

## 約哈斯做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歷代志上 3:15; 列王紀下 24:18; 耶利米書 22:11"> 約哈斯登基的時候年二十三歲，在耶路撒冷做王三個月。他母親名叫哈慕她，是立拿人耶利米的女兒。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀下 21:2–7; 列王紀下 21:21–22"> 約哈斯行耶和華眼中看為惡的事，效法他列祖一切所行的。</span>
</div>
</div>

## 法老尼哥囚約哈斯立約雅敬

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王紀上 8:65; 列王紀下 25:6; 耶利米書 39:5–6"> 法老尼哥將約哈斯鎖禁在哈馬地的利比拉，不許他在耶路撒冷做王，又罰猶大國銀子一百他連得、金子一他連得。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 19:3–4; 列王紀下 24:17; 歷代志上 3:15"> 法老尼哥立約西亞的兒子以利亞敬接續他父親約西亞做王，給他改名叫約雅敬；卻將約哈斯帶到埃及，他就死在那裡。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 23:33; 列王紀下 15:19–20"> 約雅敬將金銀給法老，遵著法老的命向國民徵取金銀，按著各人的力量派定，索要金銀，好給法老尼哥。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="歷代志下 36:5; 耶利米書 26:1; 歷代志上 3:15"> 約雅敬登基的時候年二十五歲，在耶路撒冷做王十一年。他母親名叫西布大，是魯瑪人毗大雅的女兒。</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志下 33:22–23; 以西結書 19:5–9; 耶利米書 36:31"> 約雅敬行耶和華眼中看為惡的事，效法他列祖一切所行的。</span>
</div>
</div>

## 王聞書念婦事命返其業

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈該書 1:11; 列王紀下 4:31–35; 路得記 1:1"> 以利沙曾對所救活之子的那婦人說：「你和你的全家要起身往你可住的地方去住，因為耶和華命饑荒降在這地七年。」</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 5:8; 士師記 3:3; 撒母耳記上 27:1–3"> 婦人就起身，照神人的話，帶著全家往非利士地去，住了七年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 22:16; 路加福音 18:3–5; 列王紀下 4:13"> 七年完了，那婦人從非利士地回來，就出去為自己的房屋、田地哀告王。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 5:20–27; 列王紀下 2:14; 列王紀下 6:32"> 那時王正與神人的僕人基哈西說：「請你將以利沙所行的一切大事告訴我。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 4:35; 馬太福音 10:29–30; 列王紀下 6:26"> 基哈西告訴王以利沙如何使死人復活，恰巧以利沙所救活她兒子的那婦人為自己的房屋、田地來哀告王。基哈西說：「我主我王，這就是那婦人，這是她的兒子，就是以利沙所救活的。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:7; 箴言 21:1; 撒母耳記下 9:7"> 王問那婦人，她就把那事告訴王。於是王為她派一個太監，說：「凡屬這婦人的都還給她，自從她離開本地直到今日，她田地的出產也都還給她。」</span>
</div>
</div>

## 便哈達遘疾

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 11:24; 列王紀下 6:24; 列王紀上 20:1"> 以利沙來到大馬士革，亞蘭王便哈達正患病。有人告訴王說：「神人來到這裡了。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 19:15; 列王紀下 1:2; 撒母耳記上 9:7"> 王就吩咐哈薛說：「你帶著禮物去見神人，託他求問耶和華，我這病能好不能好。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 5:13; 列王紀下 13:14; 列王紀上 19:15"> 於是哈薛用四十個駱駝，馱著大馬士革的各樣美物為禮物，去見以利沙。到了他那裡，站在他面前，說：「你兒子亞蘭王便哈達打發我來見你，他問說：『我這病能好不能好？』」</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 7:7; 創世記 2:17; 阿摩司書 7:1"> 以利沙對哈薛說：「你回去告訴他說：『這病必能好。』但耶和華指示我，他必要死。」</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:41; 羅馬書 9:2; 耶利米書 9:18"> 神人定睛看著哈薛，甚至他慚愧。神人就哭了。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 13:16; 那鴻書 3:10; 列王紀下 15:16"> 哈薛說：「我主為什麼哭？」回答說：「因為我知道你必苦害以色列人，用火焚燒他們的保障，用刀殺死他們的壯丁，摔死他們的嬰孩，剖開他們的孕婦。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 17:43; 列王紀上 19:15; 撒母耳記下 9:8"> 哈薛說：「你僕人算什麼，不過是一條狗，焉能行這大事呢？」以利沙回答說：「耶和華指示我，你必做亞蘭王。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 8:10; 馬太福音 26:16; 列王紀下 5:25"> 哈薛離開以利沙，回去見他的主人。主人問他說：「以利沙對你說什麼？」回答說：「他告訴我，你必能好。」</span>
</div>
</div>

## 約蘭做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 1:17; 列王紀下 3:1; 歷代志下 21:1–20"> 以色列王亞哈的兒子約蘭第五年，猶大王約沙法還在位的時候，約沙法的兒子約蘭登基做了猶大王。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 21:5–10"> 約蘭登基的時候年三十二歲，在耶路撒冷做王八年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 8:26; 列王紀上 11:1–5; 歷代志下 21:13"> 他行以色列諸王所行的，與亞哈家一樣；因為他娶了亞哈的女兒為妻，行耶和華眼中看為惡的事。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 11:36; 撒母耳記下 7:12–13; 路加福音 1:32–33"> 耶和華卻因他僕人大衛的緣故，仍不肯滅絕猶大，照他所應許大衛的話，永遠賜燈光於他的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:47; 列王紀下 3:9; 列王紀下 8:22"> 約蘭年間，以東人背叛猶大，脫離他的權下，自己立王。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 18:17"> 約蘭率領所有的戰車往撒益去，夜間起來，攻打圍困他的以東人和車兵長。猶大兵就逃跑，各回各家去了。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 19:8; 約書亞記 21:13; 創世記 27:40"> 這樣，以東人背叛猶大，脫離他的權下，直到今日。那時立拿人也背叛了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 15:36; 列王紀上 11:41; 歷代志下 21:11–20"> 約蘭其餘的事，凡他所行的，都寫在《猶大列王記》上。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 22:6; 歷代志下 25:23; 歷代志下 21:1"> 約蘭與他列祖同睡，葬在大衛城他列祖的墳地裡。他兒子亞哈謝接續他做王。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀下 9:29; 列王紀下 8:16–17; 歷代志下 21:20–6"> 以色列王亞哈的兒子約蘭十二年，猶大王約蘭的兒子亞哈謝登基。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 22:2; 列王紀下 9:21–27; 列王紀下 11:1"> 他登基的時候年二十二歲，在耶路撒冷做王一年。他母親名叫亞她利雅，是以色列王暗利的孫女。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 22:3–4; 哥林多後書 6:14–17; 傳道書 7:26"> 亞哈謝效法亞哈家，行耶和華眼中看為惡的事，與亞哈家一樣，因為他是亞哈家的女婿。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 22:5; 列王紀上 4:13; 歷代志下 19:2"> 他與亞哈的兒子約蘭同往基列的拉末去，與亞蘭王哈薛爭戰，亞蘭人打傷了約蘭。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 9:15–16; 列王紀下 8:28; 歷代志下 22:5–7"> 約蘭王回到耶斯列，醫治在拉末與亞蘭王哈薛打仗的時候所受的傷。猶大王約蘭的兒子亞哈謝因為亞哈的兒子約蘭病了，就下到耶斯列望看他。</span>
</div>
</div>

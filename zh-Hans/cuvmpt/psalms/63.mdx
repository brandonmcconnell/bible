## 尋求神者必得飽足

<div className="bt">
<div className="hs">大衛在猶大曠野的時候，作了這詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 143:6; 詩篇 84:2; 詩篇 42:1–2"> <span className="pl pl-1">神啊，你是我的神，</span><br /><span className="pl pl-1">我要切切地尋求你！</span><br /><span className="pl pl-1">在乾旱疲乏無水之地，我渴想你，</span><br /><span className="pl pl-1">我的心切慕你。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 27:4; 詩篇 105:4; 詩篇 84:2–11"> <span className="pl pl-1">我在聖所中曾如此瞻仰你，</span><br /><span className="pl pl-1">為要見你的能力和你的榮耀。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 69:16; 詩篇 51:15; 腓立比書 1:23"> <span className="pl pl-1">因你的慈愛比生命更好，</span><br /><span className="pl pl-1">我的嘴唇要頌讚你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 104:33; 詩篇 134:2; 詩篇 28:2"> <span className="pl pl-1">我還活的時候要這樣稱頌你，</span><br /><span className="pl pl-1">我要奉你的名舉手。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 36:7–9; 以賽亞書 25:6; 以斯拉記 3:11–13"> <span className="pl pl-1">我在床上記念你，</span><br /><span className="pl pl-1">在夜更的時候思想你，</span><br /><span className="pl pl-1">我的心就像飽足了骨髓肥油，</span><br /><span className="pl pl-1">我也要以歡樂的嘴唇讚美你。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 1:10; 詩篇 61:4; 詩篇 27:9"> <span className="pl pl-1">因為你曾幫助我，</span><br /><span className="pl pl-1">我就在你翅膀的蔭下歡呼。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 41:10; 詩篇 18:35; 詩篇 73:23"> <span className="pl pl-1">我心緊緊地跟隨你，</span><br /><span className="pl pl-1">你的右手扶持我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 55:15; 詩篇 9:17; 詩篇 40:14"> <span className="pl pl-1">但那些尋索要滅我命的人，</span><br /><span className="pl pl-1">必往地底下去。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 18:21; 以西結書 35:5; 以西結書 39:4"> <span className="pl pl-1">他們必被刀劍所殺，</span><br /><span className="pl pl-1">被野狗所吃。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 6:13; 詩篇 21:1; 以賽亞書 65:16"> <span className="pl pl-1">但是王必因神歡喜，</span><br /><span className="pl pl-1">凡指著他發誓的，必要誇口，</span><br /><span className="pl pl-1">因為說謊之人的口必被塞住。</span></span>
</div>

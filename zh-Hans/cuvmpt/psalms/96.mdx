<div className="bt">
<div className="bp poetry">

<span className="v" id="v3" data-v="3" data-xref="詩篇 22:27; 但以理書 4:1–3; 路加福音 24:47"> <span className="pl pl-1">在列邦中述說他的榮耀，</span><br /><span className="pl pl-1">在萬民中述說他的奇事。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 145:3; 詩篇 18:3; 啟示錄 15:4"> <span className="pl pl-1">因耶和華為大，當受極大的讚美，</span><br /><span className="pl pl-1">他在萬神之上，當受敬畏。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 115:15; 以賽亞書 42:5; 耶利米書 10:11–12"> <span className="pl pl-1">外邦的神都屬虛無，</span><br /><span className="pl pl-1">唯獨耶和華創造諸天。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 19:1; 馬太福音 6:13; 歷代志上 29:11–13"> <span className="pl pl-1">民中的萬族啊，你們要將榮耀、能力歸給耶和華，</span><br /><span className="pl pl-1">都歸給耶和華！</span><br /></span>

<span className="v" id="v9" data-v="9" data-xref="詩篇 29:2; 詩篇 114:7; 詩篇 110:3"> <span className="pl pl-1">當以聖潔的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「的」或作「為」。">a</a></sup><br /><span className="pl pl-1">裝飾敬拜耶和華，</span><br /><span className="pl pl-1">全地要在他面前戰抖！</span></span>

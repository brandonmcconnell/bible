<div className="bt">
<div className="hs">大衛的詩，交於伶長耶杜頓。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 21:23; 詩篇 141:3; 雅各書 1:26"> <span className="pl pl-1">我曾說：「我要謹慎我的言行，</span><br /><span className="pl pl-1">免得我舌頭犯罪。</span><br /><span className="pl pl-1">惡人在我面前的時候，</span><br /><span className="pl pl-1">我要用嚼環勒住我的口。」</span><br /></span>

<span className="v" id="v3" data-v="3" data-xref="路加福音 24:32; 耶利米書 20:9; 以西結書 3:14"> <span className="pl pl-1">我的心在我裡面發熱，</span><br /><span className="pl pl-1">我默想的時候，火就燒起，</span><br /><span className="pl pl-1">我便用舌頭說話。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="詩篇 90:12; 詩篇 103:14; 約伯記 14:13"> <span className="pl pl-1">耶和華啊，求你叫我曉得我身之終，</span><br /><span className="pl pl-1">我的壽數幾何，</span><br /><span className="pl pl-1">叫我知道我的生命不長。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 90:9–10; 詩篇 144:4; 詩篇 89:47"> <span className="pl pl-1">你使我的年日窄如手掌，</span><br /><span className="pl pl-1">我一生的年數，在你面前如同無有。</span><br /><span className="pl pl-1">各人最穩妥的時候，真是全然虛幻！（細拉）</span><br /></span>

<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 15:13; 詩篇 38:15; 詩篇 119:81"> <span className="pl pl-1">主啊，如今我等什麼呢？</span><br /><span className="pl pl-1">我的指望在乎你。</span><br /></span>

<span className="v" id="v9" data-v="9" data-xref="約伯記 2:10; 撒母耳記下 16:10; 利未記 10:3"> <span className="pl pl-1">因我所遭遇的是出於你，</span><br /><span className="pl pl-1">我就默然不語。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 9:34; 約伯記 13:21; 詩篇 25:16–17"> <span className="pl pl-1">求你把你的責罰從我身上免去，</span><br /><span className="pl pl-1">因你手的責打，我便消滅。</span><br /></span>

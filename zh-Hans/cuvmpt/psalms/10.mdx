## 求耶和華傾惡人救貧苦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 22:1; 詩篇 27:9; 詩篇 13:1–3"> <span className="pl pl-1">耶和華啊，你為什麼站在遠處？</span><br /><span className="pl pl-1">在患難的時候為什麼隱藏？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 59:12; 詩篇 36:11; 詩篇 7:16"> <span className="pl pl-1">惡人在驕橫中把困苦人追得火急，</span><br /><span className="pl pl-1">願他們陷在自己所設的計謀裡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="詩篇 94:4; 路加福音 12:19; 撒迦利亞書 11:5–8"> <span className="pl pl-1">因為惡人以心願自誇，</span><br /><span className="pl pl-1">貪財的背棄耶和華，並且輕慢他</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：他祝福貪財的，卻輕慢耶和華。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 14:1–2; 使徒行傳 8:22; 羅馬書 1:28"> <span className="pl pl-1">惡人面帶驕傲，說：「耶和華必不追究。」</span><br /><span className="pl pl-1">他一切所想的，都以為沒有神。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 92:5–6; 以賽亞書 26:11; 詩篇 12:5"> <span className="pl pl-1">凡他所做的，時常穩固，</span><br /><span className="pl pl-1">你的審判超過他的眼界。</span><br /><span className="pl pl-1">至於他一切的敵人，</span><br /><span className="pl pl-1">他都向他們噴氣。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="傳道書 8:11; 馬太福音 24:48; 以賽亞書 56:12"> <span className="pl pl-1">他心裡說：「我必不動搖，</span><br /><span className="pl pl-1">世世代代不遭災難。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 7:14; 詩篇 140:9; 詩篇 140:3"> <span className="pl pl-1">他滿口是咒罵、詭詐、欺壓，</span><br /><span className="pl pl-1">舌底是毒害、奸惡。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哈巴谷書 3:14; 撒母耳記上 22:18; 耶利米書 22:17"> <span className="pl pl-1">他在村莊埋伏等候，</span><br /><span className="pl pl-1">他在隱密處殺害無辜的人，</span><br /><span className="pl pl-1">他的眼睛窺探無倚無靠的人。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 17:12; 詩篇 59:3; 彌迦書 7:2"> <span className="pl pl-1">他埋伏在暗地，如獅子蹲在洞中。</span><br /><span className="pl pl-1">他埋伏，要擄去困苦人；</span><br /><span className="pl pl-1">他拉網，就把困苦人擄去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 23:21–22; 撒母耳記上 18:21–26; 撒母耳記下 15:5"> <span className="pl pl-1">他屈身蹲伏，</span><br /><span className="pl pl-1">無倚無靠的人就倒在他爪牙</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「爪牙」或作「強暴人」。">b</a></sup><br /><span className="pl pl-1">之下。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:12; 詩篇 94:7; 詩篇 73:11"> <span className="pl pl-1">他心裡說：「神竟忘記了，</span><br /><span className="pl pl-1">他掩面永不觀看。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 5:9; 詩篇 9:12; 詩篇 94:2"> <span className="pl pl-1">耶和華啊，求你起來！</span><br /><span className="pl pl-1">神啊，求你舉手，不要忘記困苦人！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 12:9–10; 詩篇 74:10; 創世記 9:5"> <span className="pl pl-1">惡人為何輕慢神，</span><br /><span className="pl pl-1">心裡說你必不追究？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="詩篇 68:5; 詩篇 146:9; 詩篇 55:22"> <span className="pl pl-1">其實你已經觀看，</span><br /><span className="pl pl-1">因為奸惡毒害你都看見了，</span><br /><span className="pl pl-1">為要以手施行報應。</span><br /><span className="pl pl-1">無倚無靠的人把自己交託你，</span><br /><span className="pl pl-1">你向來是幫助孤兒的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="西番雅書 1:12; 詩篇 37:17; 約伯記 38:15"> <span className="pl pl-1">願你打斷惡人的膀臂，</span><br /><span className="pl pl-1">至於壞人，願你追究他的惡，直到淨盡。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 29:10; 耶利米書 10:10; 提摩太前書 1:17"> <span className="pl pl-1">耶和華永永遠遠為王，</span><br /><span className="pl pl-1">外邦人從他的地已經滅絕了。</span></span>

<span className="v" id="v17" data-v="17" data-xref="詩篇 145:19; 歷代志下 34:27; 詩篇 34:15"> <span className="pl pl-1">耶和華啊，謙卑人的心願</span><br /><span className="pl pl-1">你早已知道</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：聽見。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你必預備他們的心，</span><br /><span className="pl pl-1">也必側耳聽他們的祈求，</span><br /></span>

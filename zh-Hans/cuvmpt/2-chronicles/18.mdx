## 約沙法之豐富

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 17:5; 歷代志下 21:6; 歷代志下 19:2"> 約沙法大有尊榮、資財，就與亞哈結親。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 9:1; 歷代志下 19:2; 列王紀上 1:9"> 過了幾年，他下到撒馬利亞去見亞哈。亞哈為他和跟從他的人宰了許多牛羊，勸他與自己同去攻取基列的拉末。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 22:4; 列王紀下 3:7; 約翰二書 1:10–11"> 以色列王亞哈問猶大王約沙法說：「你肯同我去攻取基列的拉末嗎？」他回答說：「你我不分彼此，我的民與你的民一樣，必與你同去爭戰。」</span>
</div>
</div>

## 約沙法與亞哈求先知諮諏耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 21:2; 撒母耳記下 5:19; 撒母耳記下 2:1"> 約沙法對以色列王說：「請你先求問耶和華。」</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太後書 4:3; 彌迦書 3:11; 耶利米書 28:1–17"> 於是以色列王招聚先知四百人，問他們說：「我們上去攻取基列的拉末可以不可以？」他們說：「可以上去，因為神必將那城交在王的手裡。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 22:7–9; 列王紀下 3:11–13"> 約沙法說：「這裡不是還有耶和華的先知我們可以求問他嗎？」</span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司書 5:10; 彌迦書 2:7; 列王紀上 21:20"> 以色列王對約沙法說：「還有一個人，是音拉的兒子米該雅，我們可以託他求問耶和華。只是我恨他，因為他指著我所說的預言不說吉語，常說凶言。」約沙法說：「王不必這樣說。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 22:9; 以賽亞書 39:7; 歷代志下 18:25–26"> 以色列王就召了一個太監來，說：「你快去將音拉的兒子米該雅召來。」</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 14:9; 但以理書 7:9; 馬太福音 19:28"> 以色列王和猶大王約沙法在撒馬利亞城門前的空場上，各穿朝服，坐在位上，所有的先知都在他們面前說預言。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 23:17; 撒迦利亞書 1:18–21; 耶利米書 28:2–3"> 基拿拿的兒子西底家造了兩個鐵角，說：「耶和華如此說：你要用這角牴觸亞蘭人，直到將他們滅盡。」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 24:24–25; 歷代志下 18:33–34; 猶大書 1:16"> 所有的先知也都這樣預言說：「可以上基列的拉末去，必然得勝，因為耶和華必將那城交在王的手中。」</span>
</div>
</div>

## 米該雅之警戒

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 2:6; 詩篇 10:11; 彌迦書 2:11"> 那去召米該雅的使者對米該雅說：「眾先知一口同音地都向王說吉言，你不如與他們說一樣的話，也說吉言。」</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 22:35; 民數記 24:13; 民數記 22:18–20"> 米該雅說：「我指著永生的耶和華起誓：我的神說什麼，我就說什麼。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 22:15; 耶利米哀歌 4:21; 阿摩司書 4:4–5"> 米該雅到王面前，王問他說：「米該雅啊，我們上去攻取基列的拉末可以不可以？」他說：「可以上去，必然得勝，敵人必交在你們手裡。」</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 26:63; 撒母耳記上 14:24; 列王紀上 22:16"> 王對他說：「我當囑咐你幾次，你才奉耶和華的名向我說實話呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 9:36; 以西結書 34:5–6; 民數記 27:17"> 米該雅說：「我看見以色列眾民散在山上，如同沒有牧人的羊群一般。耶和華說：『這民沒有主人，他們可以平平安安地各歸各家去。』」</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 18:7; 列王紀上 22:18; 箴言 29:1"> 以色列王對約沙法說：「我豈沒有告訴你，這人指著我所說的預言不說吉語，單說凶言嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 7:9; 以賽亞書 6:1–5; 列王紀上 22:19–23"> 米該雅說：「你們要聽耶和華的話！我看見耶和華坐在寶座上，天上的萬軍侍立在他左右。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 14:9; 歷代志下 25:19; 箴言 11:5"> 耶和華說：『誰去引誘以色列王亞哈上基列的拉末去陣亡呢？』這個就這樣說，那個就那樣說。</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:6; 哥林多後書 11:13–15; 哥林多後書 11:3"> 隨後有一個神靈出來，站在耶和華面前，說：『我去引誘他。』耶和華問他說：『你用何法呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 8:44; 列王紀上 22:21–22; 約翰一書 4:6"> 他說：『我去，要在他眾先知口中做謊言的靈。』耶和華說：『這樣，你必能引誘他，你去如此行吧。』</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 19:14; 以西結書 14:9; 約伯記 12:16"> 現在耶和華使謊言的靈入了你這些先知的口，並且耶和華已經命定降禍於你。」</span>
</div>
</div>

## 米該雅受批被執

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬可福音 14:65; 耶利米書 20:2; 歷代志下 18:10"> 基拿拿的兒子西底家前來，打米該雅的臉，說：「耶和華的靈從哪裡離開我與你說話呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 29:21–22; 以賽亞書 26:20; 耶利米書 28:16–17"> 米該雅說：「你進嚴密的屋子藏躲的那日，就必看見了。」</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 18:8; 歷代志下 34:8; 耶利米書 38:6–7"> 以色列王說：「將米該雅帶回，交給邑宰亞們和王的兒子約阿施，說：</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 16:10; 詩篇 80:5; 路加福音 23:2"> 『王如此說：把這個人下在監裡，使他受苦，吃不飽喝不足，等候我平平安安地回來。』」</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:45–46; 阿摩司書 9:10; 彌迦書 1:2"> 米該雅說：「你若能平安回來，那就是耶和華沒有藉我說這話了！」又說：「眾民哪，你們都要聽！」</span>
</div>
</div>

## 二王偕攻基列拉末

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 22:29–33"> 以色列王和猶大王約沙法上基列的拉末去了。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 28:8; 耶利米書 23:24; 箴言 26:25"> 以色列王對約沙法說：「我要改裝上陣，你可以仍穿王服。」於是以色列王改裝，他們就上陣去了。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 19:11; 申命記 1:17; 列王紀上 20:42"> 先是亞蘭王吩咐車兵長說：「他們的兵將，無論大小，你們都不可與他們爭戰，只要與以色列王爭戰。」</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 13:14; 詩篇 118:13; 哥林多後書 1:9–10"> 車兵長看見約沙法，便說：「這必是以色列王。」就轉過去與他爭戰。約沙法一呼喊，耶和華就幫助他，神又感動他們離開他。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 22:33"> 車兵長見不是以色列王，就轉去不追他了。</span>
</div>
</div>

## 以色列王中箭而死

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歷代志下 35:23; 撒母耳記下 15:11; 列王紀上 22:34–35"> 有一人隨便開弓，恰巧射入以色列王的甲縫裡。王對趕車的說：「我受了重傷，你轉過車來，拉我出陣吧。」</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 13:21; 歷代志下 18:27; 箴言 28:17"> 那日陣勢越戰越猛，以色列王勉強站在車上抵擋亞蘭人，直到晚上。約在日落的時候，王就死了。</span>
</div>
</div>

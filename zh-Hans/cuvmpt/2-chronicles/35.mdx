## 守逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:6; 民數記 9:3; 列王紀下 23:21–23"> 約西亞在耶路撒冷向耶和華守逾越節，正月十四日就宰了逾越節的羊羔。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 31:2; 歷代志上 22:19; 歷代志下 29:5–11"> 王分派祭司各盡其職，又勉勵他們辦耶和華殿中的事。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 23:26; 瑪拉基書 2:7; 申命記 33:10"> 又對那歸耶和華為聖、教訓以色列人的利未人說：「你們將聖約櫃安放在以色列王大衛兒子所羅門建造的殿裡，不必再用肩扛抬。現在要侍奉耶和華你們的神，服侍他的民以色列。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 8:14; 歷代志上 23:1–26; 尼希米記 11:10–20"> 你們應當按著宗族，照著班次，遵以色列王大衛和他兒子所羅門所寫的，自己預備。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 135:2; 以斯拉記 6:18"> 要按著你們的弟兄這民宗族的班次，站在聖所，每班中要利未宗族的幾個人。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 29:5; 希伯來書 9:13–14; 歷代志下 29:15"> 要宰逾越節的羊羔，潔淨自己，為你們的弟兄預備了，好遵守耶和華藉摩西所吩咐的話。」</span>
</div>
</div>

## 樂獻祭品

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:63; 歷代志下 30:24; 以賽亞書 32:8"> 約西亞從群畜中賜給在那裡所有的人民綿羊羔和山羊羔三萬隻，牛三千隻，做逾越節的祭物，這都是出自王的產業中。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 29:31–33; 耶利米書 29:25–26; 歷代志上 24:4–5"> 約西亞的眾首領也樂意將犧牲給百姓和祭司、利未人。又有管理神殿的希勒家、撒迦利亞、耶歇，將羊羔二千六百隻、牛三百隻給祭司做逾越節的祭物。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:21–28; 耶利米書 3:10; 以賽亞書 1:10–15"> 利未人的族長歌楠雅和他兩個兄弟示瑪雅、拿坦業，與哈沙比雅、耶利、約撒拔，將羊羔五千隻、牛五百隻給利未人做逾越節的祭物。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 30:16; 以斯拉記 6:18; 歷代志下 35:4–5"> 這樣，供獻的事齊備了。祭司站在自己的地方，利未人按著班次站立，都是照王所吩咐的。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 29:34; 希伯來書 9:21–22; 歷代志下 29:22–24"> 利未人宰了逾越節的羊羔，祭司從他們手裡接過血來灑在壇上，利未人剝皮，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 3:9–11; 利未記 3:3; 利未記 3:5"> 將燔祭搬來，按著宗族的班次分給眾民，好照摩西書上所寫的獻給耶和華。獻牛也是這樣。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 12:8–9; 撒母耳記上 2:13–15; 申命記 16:7"> 他們按著常例，用火烤逾越節的羊羔，別的聖物用鍋、用釜、用罐煮了，速速地送給眾民。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 6:2–4"> 然後為自己和祭司預備祭物，因為祭司亞倫的子孫獻燔祭和脂油直到晚上，所以利未人為自己和祭司亞倫的子孫預備祭物。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 25:1–7; 歷代志上 26:12–19; 歷代志上 9:17–19"> 歌唱的亞薩之子孫照著大衛、亞薩、希幔和王的先見耶杜頓所吩咐的，站在自己的地位上。守門的看守各門，不用離開他們的職事，因為他們的弟兄利未人給他們預備祭物。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 當日，供奉耶和華的事齊備了，就照約西亞王的吩咐守逾越節，獻燔祭在耶和華的壇上。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:15–20; 歷代志下 30:21–23; 出埃及記 23:15"> 當時在耶路撒冷的以色列人守逾越節，又守除酵節七日。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 30:5; 列王紀下 23:21–23; 歷代志下 30:26–27"> 自從先知撒母耳以來，在以色列中沒有守過這樣的逾越節，以色列諸王也沒有守過像約西亞、祭司、利未人，在那裡的猶大人和以色列人，以及耶路撒冷居民所守的逾越節。</span>
<span className="v" id="v19" data-v="19"> 這逾越節是約西亞做王十八年守的。</span>
</div>
</div>

## 約西亞與埃及王尼哥戰重傷而死

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 10:9; 列王紀下 23:29–30; 耶利米書 46:2–12"> 這事以後，約西亞修完了殿，有埃及王尼哥上來，要攻擊靠近幼發拉底河的迦基米施，約西亞出去抵擋他。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 25:19; 列王紀下 18:25; 以賽亞書 36:10"> 他差遣使者來見約西亞，說：「猶大王啊，我與你何干？我今日來不是要攻擊你，乃是要攻擊與我爭戰之家，並且神吩咐我速行。你不要干預神的事，免得他毀滅你，因為神是與我同在。」</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:19; 歷代志下 18:29; 列王紀上 22:30"> 約西亞卻不肯轉去離開他，改裝要與他打仗，不聽從神藉尼哥之口所說的話，便來到米吉多平原爭戰。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:34; 列王紀下 9:24; 創世記 49:23"> 弓箭手射中約西亞王，王對他的臣僕說：「我受了重傷，你拉我出陣吧。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 12:11; 列王紀下 23:30; 詩篇 36:6"> 他的臣僕扶他下了戰車，上了次車，送他到耶路撒冷，他就死了，葬在他列祖的墳墓裡。猶大人和耶路撒冷人都為他悲哀。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米哀歌 4:20; 耶利米書 22:10; 約伯記 3:8"> 耶利米為約西亞作哀歌，所有歌唱的男女也唱哀歌追悼約西亞，直到今日，而且在以色列中成了定例。這歌載在《哀歌書》上。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 31:20; 歷代志下 32:32"> 約西亞其餘的事和他遵著耶和華律法上所記而行的善事，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 26:22; 歷代志下 25:26; 列王紀下 10:34"> 並他自始至終所行的，都寫在《以色列和猶大列王記》上。</span>
</div>
</div>

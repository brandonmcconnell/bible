## 約西亞做王毀除崇邱偶像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 1:1; 耶利米書 1:2; 歷代志下 33:25"> 約西亞登基的時候年八歲，在耶路撒冷做王三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 29:2; 約書亞記 1:7; 列王紀下 22:2"> 他行耶和華眼中看為正的事，效法他祖大衛所行的，不偏左右。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 33:22; 歷代志下 15:2; 箴言 8:17"> 他做王第八年，尚且年幼，就尋求他祖大衛的神。到了十二年，才潔淨猶大和耶路撒冷，除掉丘壇、木偶、雕刻的像和鑄造的像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 32:20; 利未記 26:30; 列王紀下 23:4–6"> 眾人在他面前拆毀巴力的壇，砍斷壇上高高的日像，又把木偶和雕刻的像並鑄造的像打碎成灰，撒在祭偶像人的墳上，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:2; 耶利米書 3:10; 民數記 35:33"> 將他們祭司的骸骨燒在壇上，潔淨了猶大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 13:20–21; 以賽亞書 7:25; 歷代志下 30:1"> 又在瑪拿西、以法蓮、西緬、拿弗他利各城和四圍破壞之處，都這樣行。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:1; 申命記 9:21; 歷代志下 34:1"> 又拆毀祭壇，把木偶和雕刻的像打碎成灰，砍斷以色列遍地所有的日像，就回耶路撒冷去了。</span>
</div>
</div>

## 修葺聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:16; 歷代志上 18:15; 耶利米書 29:25"> 約西亞王十八年，淨地淨殿之後，就差遣亞薩利雅的兒子沙番、邑宰瑪西雅、約哈斯的兒子史官約亞去修理耶和華他神的殿。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 30:18; 歷代志下 30:10; 歷代志下 35:8"> 他們就去見大祭司希勒家，將奉到神殿的銀子交給他，這銀子是看守殿門的利未人從瑪拿西、以法蓮和一切以色列剩下的人，以及猶大、便雅憫眾人，並耶路撒冷的居民收來的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 12:11–12; 以斯拉記 3:7; 列王紀下 22:5–6"> 又將這銀子交給耶和華殿裡督工的，轉交修理耶和華殿的工匠，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 33:4–7; 歷代志下 33:22"> 就是交給木匠、石匠，買鑿成的石頭和架木與棟梁，修猶大王所毀壞的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 12:15; 歷代志上 23:5; 列王紀下 22:7"> 這些人辦事誠實，督工的是利未人米拉利的子孫雅哈、俄巴底，督催的是哥轄的子孫撒迦利亞、米書蘭，還有善於作樂的利未人。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:10; 歷代志下 2:18; 耶利米書 8:8"> 他們又監管扛抬的人，督催一切做工的，利未人中也有做書記、做司事、做守門的。</span>
</div>
</div>

## 希勒家得律書

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 8:36; 詩篇 1:2; 利未記 10:11"> 他們將奉到耶和華殿的銀子運出來的時候，祭司希勒家偶然得了摩西所傳耶和華的律法書。</span>
<span className="v" id="v15" data-v="15"> 希勒家對書記沙番說：「我在耶和華殿裡得了律法書。」遂將書遞給沙番。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 22:9–10; 耶利米書 36:20–21"> 沙番把書拿到王那裡，回覆王說：「凡交給僕人們辦的都辦理了。</span>
<span className="v" id="v17" data-v="17"> 耶和華殿裡的銀子倒出來，交給督工的和匠人的手裡了。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:46; 耶利米書 36:20–21; 申命記 17:19"> 書記沙番又對王說：「祭司希勒家遞給我一卷書。」沙番就在王面前讀那書。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:6; 申命記 28:3–68; 列王紀下 22:19"> 王聽見律法上的話，就撕裂衣服，</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 22:12; 耶利米書 26:24; 耶利米書 40:9"> 吩咐希勒家與沙番的兒子亞希甘、米迦的兒子亞比頓、書記沙番和王的臣僕亞撒雅說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 21:2; 以西結書 14:1–11; 歷代志下 28:6"> 「你們去，為我，為以色列和猶大剩下的人，以這書上的話求問耶和華。因我們列祖沒有遵守耶和華的言語，沒有照這書上所記的去行，耶和華的烈怒就倒在我們身上。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及記 15:20; 列王紀下 22:14"> 於是，希勒家和王所派的眾人都去見女先知戶勒大。戶勒大是掌管禮服沙龍的妻，沙龍是哈斯拉的孫子、特瓦的兒子。戶勒大住在耶路撒冷第二區，他們請問於她。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 37:7–10; 耶利米書 21:3–7; 列王紀下 22:15–20"> 她對他們說：「耶和華以色列的神如此說：你們可以回覆那差遣你們來見我的人說：</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 36:14–20; 約書亞記 23:16; 申命記 28:15–68"> 『耶和華如此說：我必照著在猶大王面前所讀那書上的一切咒詛，降禍於這地和其上的居民。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 7:20; 馬可福音 9:43–48; 那鴻書 1:6"> 因為他們離棄我，向別神燒香，用他們手所做的惹我發怒，所以我的憤怒如火倒在這地上，總不熄滅。』</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 34:23; 歷代志下 34:21"> 然而，差遣你們來求問耶和華的猶大王，你們要這樣回覆他說：『耶和華以色列的神如此說：至於你所聽見的話，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 32:26; 以西結書 9:4; 詩篇 34:18"> 就是聽見我指著這地和其上居民所說的話，你便心裡敬服，在我面前自卑，撕裂衣服，向我哭泣，因此我應允了你。這是我耶和華說的。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 39:8; 詩篇 37:37; 列王紀上 21:29"> 我必使你平平安安地歸到墳墓，到你列祖那裡。我要降於這地和其上居民的一切災禍，你也不致親眼看見。』」他們就回覆王去了。</span>
</div>
</div>

## 王誦約書於民眾

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀下 23:1–3; 歷代志下 30:2; 馬可福音 14:8"> 王差遣人招聚猶大和耶路撒冷的眾長老來。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 24:7; 列王紀下 23:2; 歷代志下 34:15"> 王和猶大眾人與耶路撒冷的居民，並祭司、利未人，以及所有的百姓，無論大小，都一同上到耶和華的殿。王就把殿裡所得的約書念給他們聽。</span>
</div>
</div>

## 立約守誡

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歷代志下 23:16; 列王紀下 23:3; 列王紀下 11:14"> 王站在他的地位上，在耶和華面前立約，要盡心、盡性地順從耶和華，遵守他的誡命、法度、律例，成就這書上所記的約言，</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 30:12; 耶利米書 3:10; 歷代志下 14:4"> 又使住耶路撒冷和便雅憫的人都服從這約。於是耶路撒冷的居民都遵行他們列祖之神的約。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 34:3–7; 約書亞記 24:31; 列王紀下 23:4–20"> 約西亞從以色列各處將一切可憎之物盡都除掉，使以色列境內的人都侍奉耶和華他們的神。約西亞在世的日子，就跟從耶和華他們列祖的神，總不離開。</span>
</div>

## 所羅門為民祝福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 18:8–11; 利未記 16:2; 出埃及記 20:21"> 那時所羅門說：<br /><span className="pl pl-1">「耶和華曾說他必住在幽暗之處。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 2:4–6; 詩篇 135:21; 歷代志上 28:6"> <span className="pl pl-1">但我已經建造殿宇做你的居所，</span><br /><span className="pl pl-1">為你永遠的住處。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:14; 歷代志下 29:29; 列王紀上 8:55–61"> 王轉臉為以色列會眾祝福，以色列會眾就都站立。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 72:18–19; 馬太福音 24:35; 詩篇 68:32–35"> 所羅門說：「耶和華以色列的神是應當稱頌的！因他親口向我父大衛所應許的，也親手成就了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 20:24; 列王紀上 8:16; 撒母耳記上 13:13–14"> 他說：『自從我領我民出埃及地以來，我未曾在以色列眾支派中選擇一城建造殿宇為我名的居所，也未曾揀選一人做我民以色列的君。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 28:4; 詩篇 132:13; 歷代志下 12:13"> 但選擇耶路撒冷為我名的居所，又揀選大衛治理我民以色列。』」</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 17:1; 列王紀上 5:3; 歷代志上 22:7"> 所羅門說：「我父大衛曾立意要為耶和華以色列神的名建殿，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 8:12; 馬可福音 14:8; 列王紀上 8:18–21"> 耶和華卻對我父大衛說：『你立意要為我的名建殿，這意思甚好，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 7:12–13; 歷代志上 17:4; 歷代志上 17:11–12"> 只是你不可建殿，唯你所生的兒子，必為我名建殿。』</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 1:4; 歷代志上 28:5; 歷代志上 17:11"> 現在耶和華成就了他所應許的話，使我接續我父大衛坐以色列的國位，是照耶和華所說的，又為耶和華以色列神的名建造了殿。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 5:10; 歷代志下 5:7; 列王紀上 8:21"> 我將約櫃安置在其中，櫃內有耶和華的約，就是他與以色列人所立的約。」</span>
</div>
</div>

## 大申祈禱

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 63:4; 以賽亞書 50:10; 約伯記 11:13"> 所羅門當著以色列會眾，站在耶和華的壇前，舉起手來。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 8:54; 尼希米記 8:4; 詩篇 95:6"> 所羅門曾造一個銅臺，長五肘，寬五肘，高三肘，放在院中，就站在臺上，當著以色列的會眾跪下，向天舉手，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 15:11; 申命記 7:9; 尼希米記 1:5"> 說：「耶和華以色列的神啊，天上地下，沒有神可比你的。你向那盡心行在你面前的僕人守約施慈愛，</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 22:9–10; 撒母耳記下 7:12; 列王紀上 8:24"> 向你僕人我父大衛所應許的話現在應驗了。你親口應許，親手成就，正如今日一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 2:4; 約翰福音 15:14–15; 歷代志下 7:18"> 耶和華以色列的神啊，你所應許你僕人我父大衛的話說『你的子孫若謹慎自己的行為，遵守我的律法，像你在我面前所行的一樣，就不斷人坐以色列的國位』，現在求你應驗這話。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 11:5; 以賽亞書 41:17; 歷代志下 6:4"> 耶和華以色列的神啊，求你成就向你僕人大衛所應許的話！</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 2:6; 以賽亞書 66:1; 詩篇 139:7–10"> 「神果真與世人同住在地上嗎？看哪，天和天上的天尚且不足你居住的，何況我所建的這殿呢！</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:28; 路加福音 18:1–7; 約翰福音 17:20"> 唯求耶和華我的神垂顧僕人的禱告、祈求，俯聽僕人在你面前的祈禱、呼籲。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 34:15; 但以理書 6:10; 詩篇 121:5"> 願你晝夜看顧這殿，就是你應許立為你名的居所；求你垂聽僕人向此處禱告的話。</span>
<span className="v" id="v21" data-v="21" data-xref="彌迦書 7:18; 但以理書 9:19; 以賽亞書 43:25"> 你僕人和你民以色列向此處祈禱的時候，求你從天上你的居所垂聽，垂聽而赦免。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 22:11; 利未記 5:1; 民數記 5:19–22"> 「人若得罪鄰舍，有人叫他起誓，他來到這殿，在你的壇前起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 3:10–11; 箴言 17:15; 耶利米書 51:56"> 求你從天上垂聽，判斷你的僕人：定惡人有罪，照他所行的報應在他頭上；定義人有理，照他的義賞賜他。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未記 26:17; 列王紀下 17:7–18; 約書亞記 7:8"> 「你的民以色列若得罪你，敗在仇敵面前，又回心轉意，承認你的名，在這殿裡向你祈求、禱告，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 33:6–13; 以斯拉記 1:1–6; 創世記 13:15"> 求你從天上垂聽，赦免你民以色列的罪，使他們歸回你賜給他們和他們列祖之地。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 28:23; 申命記 11:17; 利未記 26:19"> 「你的民因得罪你，你懲罰他們，使天閉塞不下雨，他們若向此處禱告，承認你的名，離開他們的罪，</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 8:35–36; 耶利米書 5:24; 撒迦利亞書 10:1"> 求你在天上垂聽，赦免你僕人和你民以色列的罪，將當行的善道指教他們，且降雨在你的地，就是你賜給你民為業之地。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 9:3–11; 約珥書 2:25; 路得記 1:1"> 「國中若有饑荒、瘟疫、旱風、霉爛、蝗蟲、螞蚱，或有仇敵犯境圍困城邑，無論遭遇什麼災禍疾病，</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 50:15; 詩篇 32:2–6; 歷代志下 6:12–13"> 你的民以色列，或是眾人，或是一人，自覺災禍甚苦，向這殿舉手，無論祈求什麼，禱告什麼，</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 28:9; 撒母耳記上 16:7; 啟示錄 2:23"> 求你從天上你的居所垂聽赦免。你是知道人心的，要照各人所行的待他們——唯有你知道世人的心——</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:31; 約伯記 28:28; 詩篇 128:1"> 使他們在你賜給我們列祖之地上一生一世敬畏你，遵行你的道。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 56:3–7; 列王紀上 8:41–43; 馬太福音 8:10–11"> 「論到不屬你民以色列的外邦人，為你的大名和大能的手並伸出來的膀臂，從遠方而來，向這殿禱告，</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 7:14; 列王紀上 8:16; 啟示錄 11:15"> 求你從天上你的居所垂聽，照著外邦人所祈求的而行，使天下萬民都認識你的名，敬畏你，像你的民以色列一樣，又使他們知道我建造的這殿是稱為你名下的。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歷代志下 20:6–13; 歷代志下 18:31; 歷代志下 20:4"> 「你的民若奉你的差遣，無論往何處去與仇敵爭戰，向你所選擇的城與我為你名所建造的殿禱告，</span>
<span className="v" id="v35" data-v="35" data-xref="但以理書 9:17–19; 詩篇 9:3–4; 耶利米書 5:28"> 求你從天上垂聽他們的禱告、祈求，使他們得勝。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="傳道書 7:20; 雅各書 3:2; 約翰一書 1:8–10"> 「你的民若得罪你——世上沒有不犯罪的人——你向他們發怒，將他們交給仇敵，擄到或遠或近之地，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 31:18–20; 但以理書 9:5–11; 以賽亞書 64:6–12"> 他們若在擄到之地想起罪來，回心轉意，懇求你說『我們有罪了，我們悖逆了，我們作惡了』，</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志下 33:11–13; 但以理書 6:10; 但以理書 9:3–4"> 他們若在擄到之地盡心、盡性歸服你，又向自己的地，就是你賜給他們列祖之地，和你所選擇的城，並我為你名所建造的殿禱告，</span>
<span className="v" id="v39" data-v="39" data-xref="彌迦書 7:18–20; 歷代志下 6:35; 詩篇 25:18"> 求你從天上你的居所垂聽你民的禱告、祈求，為他們申冤，赦免他們的過犯。</span>
</div>
<div className="bp poetry">
<span className="v" id="v40" data-v="40" data-xref="歷代志下 7:15; 詩篇 116:2; 尼希米記 1:6"> 「我的神啊，現在求你睜眼看、側耳聽在此處所獻的禱告。</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 61:10; 歷代志上 28:2; 詩篇 132:8–10"> <span className="pl pl-1">耶和華神啊，求你起來，</span><br /><span className="pl pl-1">和你有能力的約櫃同入安息之所。</span><br /><span className="pl pl-1">耶和華神啊，願你的祭司披上救恩，</span><br /><span className="pl pl-1">願你的聖民蒙福歡樂。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以賽亞書 55:3; 詩篇 132:1; 以賽亞書 61:1"> <span className="pl pl-1">耶和華神啊，求你不要厭棄你的受膏者，</span><br /><span className="pl pl-1">要記念向你僕人大衛所施的慈愛。」</span></span>
</div>
</div>

## 約書亞之遺命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 13:1; 約書亞記 21:44; 約書亞記 11:23"> 耶和華使以色列人安靜，不與四圍的一切仇敵爭戰，已經多日。約書亞年紀老邁，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:1; 申命記 31:28; 歷代志上 28:1"> 就把以色列眾人的長老、族長、審判官並官長都召了來，對他們說：「我年紀已經老邁。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 14:14; 約書亞記 10:42; 約書亞記 10:14"> 耶和華你們的神因你們的緣故向那些國所行的一切事，你們親眼看見了，因那為你們爭戰的是耶和華你們的神。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 13:6–7; 約書亞記 18:10; 約書亞記 13:2"> 我所剪除和所剩下的各國，從約旦河起到日落之處的大海，我已經拈鬮分給你們各支派為業。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 11:23; 約書亞記 13:6; 出埃及記 33:2"> 耶和華你們的神必將他們從你們面前趕出去，使他們離開你們，你們就必得他們的地為業，正如耶和華你們的神所應許的。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 5:32; 申命記 28:14; 箴言 4:26–27"> 所以，你們要大大壯膽，謹守遵行寫在摩西律法書上的一切話，不可偏離左右。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 23:13; 詩篇 16:4; 申命記 7:2–3"> 不可與你們中間所剩下的這些國民摻雜。他們的神，你們不可提他的名，不可指著他起誓，也不可侍奉、叩拜。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 10:20; 約書亞記 22:5; 申命記 13:4"> 只要照著你們到今日所行的，專靠耶和華你們的神。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 1:5; 申命記 11:23; 約書亞記 23:5"> 因為耶和華已經把又大又強的國民從你們面前趕出，直到今日，沒有一人在你們面前站立得住。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:30; 利未記 26:8; 申命記 3:22"> 你們一人必追趕千人，因耶和華你們的神照他所應許的，為你們爭戰。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 22:5; 申命記 6:5–12; 箴言 4:23"> 你們要分外謹慎，愛耶和華你們的神。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:3; 以西結書 18:24; 西番雅書 1:6"> 你們若稍微轉去，與你們中間所剩下的這些國民聯絡，彼此結親，互相往來，</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 7:16; 民數記 33:55; 出埃及記 23:33"> 你們要確實知道：耶和華你們的神必不再將他們從你們眼前趕出，他們卻要成為你們的網羅、機檻，肋上的鞭、眼中的刺，直到你們在耶和華你們神所賜的這美地上滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王紀上 2:2; 利未記 26:3–13"> 「我現在要走世人必走的路。你們是一心一意地知道，耶和華你們神所應許賜福於你們的話沒有一句落空，都應驗在你們身上了。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; 利未記 26:14–46; 士師記 3:8"> 耶和華你們神所應許的一切福氣怎樣臨到你們身上，耶和華也必照樣使各樣禍患臨到你們身上，直到把你們從耶和華你們神所賜的這美地上除滅。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:25–26; 列王紀下 24:20"> 你們若違背耶和華你們神吩咐你們所守的約，去侍奉別神，叩拜他，耶和華的怒氣必向你們發作，使你們在他所賜的美地上速速滅亡。」</span>
</div>

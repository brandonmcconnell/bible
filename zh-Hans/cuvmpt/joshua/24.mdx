## 約書亞於示劍述神之恩惠

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 23:2; 撒母耳記上 10:19; 創世記 33:18–19"> 約書亞將以色列的眾支派聚集在示劍，召了以色列的長老、族長、審判官並官長來。他們就站在神面前，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:15; 以西結書 16:3; 創世記 31:30"> 約書亞對眾民說：「耶和華以色列的神如此說：『古時你們的列祖，就是亞伯拉罕和拿鶴的父親他拉，住在大河那邊侍奉別神，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1–4; 創世記 21:2–3; 使徒行傳 7:2–3"> 我將你們的祖宗亞伯拉罕從大河那邊帶來，領他走遍迦南全地，又使他的子孫眾多，把以撒賜給他。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 36:8; 申命記 2:5; 創世記 25:24–26"> 又把雅各和以掃賜給以撒，將西珥山賜給以掃為業。後來雅各和他的子孫下到埃及去了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:10; 出埃及記 7:1–12; 詩篇 105:26–36"> 我差遣摩西、亞倫，並照我在埃及中所行的降災於埃及，然後把你們領出來。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 7:36; 希伯來書 11:29; 以賽亞書 63:12–13"> 我領你們列祖出埃及，他們就到了紅海，埃及人帶領車輛馬兵追趕你們列祖到紅海。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:34; 出埃及記 14:10; 出埃及記 14:20"> 你們列祖哀求耶和華，他就使你們和埃及人中間黑暗了，又使海水淹沒埃及人。我在埃及所行的事，你們親眼見過。你們在曠野也住了許多年日。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 21:21–35; 詩篇 135:10–11; 尼希米記 9:22"> 我領你們到約旦河東亞摩利人所住之地，他們與你們爭戰，我將他們交在你們手中，你們便得了他們的地為業，我也在你們面前將他們滅絕。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 11:25; 彌迦書 6:5; 民數記 22:2"> 那時，摩押王西撥的兒子巴勒起來攻擊以色列人，打發人召了比珥的兒子巴蘭來咒詛你們。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 23:5; 民數記 24:5–10; 以賽亞書 54:17"> 我不肯聽巴蘭的話，所以他倒為你們連連祝福。這樣，我便救你們脫離巴勒的手。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 4:10–12; 約書亞記 3:14–17; 詩篇 114:5"> 你們過了約旦河，到了耶利哥。耶利哥人、亞摩利人、比利洗人、迦南人、赫人、革迦撒人、希未人、耶布斯人都與你們爭戰，我把他們交在你們手裡。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:20; 出埃及記 23:28; 詩篇 44:3–6"> 我打發黃蜂飛在你們前面，將亞摩利人的二王從你們面前攆出，並不是用你的刀，也不是用你的弓。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 6:10–12; 申命記 8:7; 約書亞記 21:45"> 我賜給你們地土，非你們所修治的；我賜給你們城邑，非你們所建造的。你們就住在其中，又得吃非你們所栽種的葡萄園，橄欖園的果子。』</span>
</div>
</div>

## 勸民侍奉耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 12:24; 申命記 10:12; 創世記 35:2"> 「現在你們要敬畏耶和華，誠心實意地侍奉他，將你們列祖在大河那邊和在埃及所侍奉的神除掉，去侍奉耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:21; 約翰福音 6:67–68; 路得記 1:15–16"> 若是你們以侍奉耶和華為不好，今日就可以選擇所要侍奉的，是你們列祖在大河那邊所侍奉的神呢，是你們所住這地的亞摩利人的神呢？至於我和我家，我們必定侍奉耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 10:38–39; 撒母耳記上 12:23; 羅馬書 6:2"> 百姓回答說：「我們斷不敢離棄耶和華去侍奉別神！</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 19:4; 以賽亞書 63:7–14; 以賽亞書 46:4"> 因耶和華我們的神曾將我們和我們列祖從埃及地的為奴之家領出來，在我們眼前行了那些大神蹟，在我們所行的道上、所經過的諸國，都保護了我們。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 4:2; 出埃及記 10:2; 詩篇 116:16"> 耶和華又把住此地的亞摩利人都從我們面前趕出去。所以，我們必侍奉耶和華，因為他是我們的神。」</span>
</div>
</div>

## 與民立約

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 5:16; 出埃及記 23:21; 詩篇 99:9"> 約書亞對百姓說：「你們不能侍奉耶和華！因為他是聖潔的神，是忌邪的神，必不赦免你們的過犯罪惡。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 10:26–27; 以西結書 18:24; 歷代志上 28:9"> 你們若離棄耶和華去侍奉外邦神，耶和華在降福之後，必轉而降禍於你們，把你們滅絕。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 20:19; 以賽亞書 44:5; 申命記 5:27–28"> 百姓回答約書亞說：「不然，我們定要侍奉耶和華。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 119:173; 詩篇 119:11; 約伯記 15:6"> 約書亞對百姓說：「你們選定耶和華，要侍奉他，你們自己做見證吧！」他們說：「我們願意做見證！」</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:16–18; 約書亞記 24:14; 希伯來書 12:28–29"> 約書亞說：「你們現在要除掉你們中間的外邦神，專心歸向耶和華以色列的神。」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 24:7; 出埃及記 24:3; 申命記 5:27–29"> 百姓回答約書亞說：「我們必侍奉耶和華我們的神，聽從他的話。」</span>
<span className="v" id="v25" data-v="25" data-xref="尼希米記 9:38; 歷代志下 23:16; 出埃及記 15:25"> 當日，約書亞就與百姓立約，在示劍為他們立定律例、典章。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 9:6; 創世記 35:4; 約書亞記 4:20–24"> 約書亞將這些話都寫在神的律法書上，又將一塊大石頭立在橡樹下耶和華的聖所旁邊。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 約書亞記 22:34; 約書亞記 22:27–28"> 約書亞對百姓說：「看哪，這石頭可以向我們做見證，因為是聽見了耶和華所吩咐我們的一切話。倘或你們背棄你們的神，這石頭就可以向你們做見證。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「倘或」云云或作「所以要向你們做見證，免得你們背棄耶和華你們的神。」">a</a></sup>」</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 2:6"> 於是約書亞打發百姓各歸自己的地業去了。</span>
</div>
</div>

## 約書亞卒

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 2:8; 提摩太後書 4:7–8; 申命記 34:5"> 這些事以後，耶和華的僕人嫩的兒子約書亞，正一百一十歲，就死了。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:50; 士師記 2:9; 撒母耳記下 23:30"> 以色列人將他葬在他地業的境內，就是在以法蓮山地的亭拿西拉，在迦實山的北邊。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 2:7; 申命記 31:13; 申命記 11:2"> 約書亞在世和約書亞死後，那些知道耶和華為以色列人所行諸事的長老還在的時候，以色列人侍奉耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 50:25; 創世記 33:19; 出埃及記 13:19"> 以色列人從埃及所帶來約瑟的骸骨，葬埋在示劍，就是在雅各從前用一百塊銀子向示劍的父親哈抹的子孫所買的那塊地裡，這就做了約瑟子孫的產業。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 22:13; 出埃及記 6:25; 以賽亞書 57:1–2"> 亞倫的兒子以利亞撒也死了，就把他葬在他兒子非尼哈以法蓮山地所得的小山上。</span>
</div>
</div>

## 西緬所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 19:9; 創世記 49:5–7; 約書亞記 18:6–11"> 為西緬支派的人，按著宗族，拈出第二鬮。他們所得的地業是在猶大人地業中間。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 4:28–30; 尼希米記 11:26–30; 創世記 21:31"> 他們所得為業之地就是別是巴（或名示巴）、摩拉大、</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 15:28–29"> 哈薩書亞、巴拉、以森、</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 15:30; 士師記 1:17"> 伊利多拉、比土力、何珥瑪、</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 30:1; 歷代志上 4:31; 約書亞記 15:31"> 洗革拉、伯瑪加博、哈薩蘇撒、</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 15:32"> 伯利巴勿、沙魯險，共十三座城，還有屬城的村莊。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:42; 約書亞記 15:32; 民數記 33:19–20"> 又有亞因、利門、以帖、亞珊，共四座城，還有屬城的村莊。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 4:33; 撒母耳記上 30:27"> 並有這些城邑四圍一切的村莊，直到巴拉比珥，就是南地的拉瑪。這是西緬支派按著宗族所得的地業。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 8:14–15; 出埃及記 16:18"> 西緬人的地業是從猶大人地業中得來的，因為猶大人的份過多，所以西緬人在他們的地業中得了地業。</span>
</div>
</div>

## 西布倫所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 18:11; 約書亞記 18:6; 創世記 49:13"> 為西布倫人，按著宗族，拈出第三鬮。他們地業的境界是到撒立。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 12:22; 歷代志上 6:68; 列王紀上 4:12"> 往西上到瑪拉拉，達到大巴設，又達到約念前的河。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 4:6; 歷代志上 6:72; 約書亞記 19:22"> 又從撒立往東轉向日出之地，到吉斯綠他泊的境界，又通到大比拉，上到雅非亞。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 14:25"> 從那裡往東，接連到迦特希弗，至以特加汛，通到臨門，臨門延到尼亞。</span>
<span className="v" id="v14" data-v="14"> 又繞過尼亞的北邊，轉到哈拿頓，通到伊弗他伊勒谷。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 11:1; 路得記 1:19; 撒母耳記下 23:15"> 還有加他、拿哈拉、伸崙、以大拉、伯利恆，共十二座城，還有屬城的村莊。</span>
<span className="v" id="v16" data-v="16"> 這些城並屬城的村莊就是西布倫人按著宗族所得的地業。</span>
</div>
</div>

## 以薩迦所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 為以薩迦人，按著宗族，拈出第四鬮。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 28:4; 列王紀下 4:8; 何西阿書 1:4–5"> 他們的境界是到耶斯列、基蘇律、書念、</span>
<span className="v" id="v19" data-v="19"> 哈弗連、示按、亞拿哈拉、</span>
<span className="v" id="v20" data-v="20"> 拉璧、基善、亞別、</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 21:29"> 利篾、隱干寧、隱哈大、伯帕薛，</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 4:6; 歷代志上 6:77; 約書亞記 19:38"> 又達到他泊、沙哈洗瑪、伯示麥，直通到約旦河為止，共十六座城，還有屬城的村莊。</span>
<span className="v" id="v23" data-v="23"> 這些城並屬城的村莊就是以薩迦支派按著宗族所得的地業。</span>
</div>
</div>

## 亞設所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 2:26–38"> 為亞設支派，按著宗族，拈出第五鬮。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 12:20; 約書亞記 11:1; 撒母耳記下 2:16"> 他們的境界是黑甲、哈利、比田、押煞、</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王紀上 18:42; 以賽亞書 33:9"> 亞拉米勒、亞末、米沙勒。往西達到迦密，又到希曷立納，</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:13; 撒母耳記上 5:2"> 轉向日出之地，到伯大袞，達到細步綸，往北到伊弗他伊勒谷，到伯以墨和尼業，也通到迦步勒的左邊。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:31; 約書亞記 11:8; 以賽亞書 23:12"> 又到義伯崙、利合、哈們、加拿，直到西頓大城。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:31; 撒母耳記下 5:11; 彌迦書 1:14"> 轉到拉瑪和堅固城推羅，又轉到何薩，靠近亞革悉一帶地方，直通到海。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 21:31; 列王紀上 20:30; 撒母耳記上 4:1"> 又有烏瑪、亞弗、利合，共二十二座城，還有屬城的村莊。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 33:24–25; 創世記 49:20"> 這些城並屬城的村莊就是亞設支派按著宗族所得的地業。</span>
</div>
</div>

## 拿弗他利所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32"> 為拿弗他利人，按著宗族，拈出第六鬮。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 4:11"> 他們的境界是從希利弗從撒拿音的橡樹，從亞大米尼吉和雅比聶，直到拉共，通到約旦河。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 33:23; 約書亞記 19:12; 約書亞記 19:22"> 又轉向西到亞斯納他泊，從那裡通到戶割，南邊到西布倫，西邊到亞設，又向日出之地，達到約旦河那裡的猶大。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 11:2; 列王紀上 8:65; 創世記 10:18"> 堅固的城就是西丁、側耳、哈末、拉甲、基尼烈、</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 11:1; 約書亞記 11:20; 約書亞記 12:19"> 亞大瑪、拉瑪、夏瑣、</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 20:7; 約書亞記 12:22"> 基低斯、以得來、隱夏瑣、</span>
<span className="v" id="v38" data-v="38"> 以利穩、密大伊勒、和璉、伯亞納、伯示麥，共十九座城，還有屬城的村莊。</span>
<span className="v" id="v39" data-v="39"> 這些城並屬城的村莊就是拿弗他利支派按著宗族所得的地業。</span>
</div>
</div>

## 但所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40"> 為但支派，按著宗族，拈出第七鬮。</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志上 2:53; 約書亞記 15:33; 士師記 13:25"> 他們地業的境界是瑣拉、以實陶、伊珥示麥、</span>
<span className="v" id="v42" data-v="42" data-xref="士師記 1:35; 約書亞記 10:12; 約書亞記 21:24"> 沙拉賓、亞雅崙、伊提拉、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 38:12; 撒母耳記上 5:10; 士師記 14:1–2"> 以倫、亭拿他、以革倫、</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 15:27; 列王紀上 16:15; 列王紀上 9:18"> 伊利提基、基比頓、巴拉、</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 21:24"> 伊胡得、比尼比拉、迦特臨門、</span>
<span className="v" id="v46" data-v="46" data-xref="約拿書 1:3; 使徒行傳 9:36; 歷代志下 2:16"> 美耶昆、拉昆，並約帕對面的地界。</span>
<span className="v" id="v47" data-v="47" data-xref="士師記 1:34–35; 士師記 18:1–29"> 但人的地界越過原得的地界，因為但人上去攻取利善，用刀擊殺城中的人，得了那城，住在其中，以他們先祖但的名將利善改名為但。</span>
<span className="v" id="v48" data-v="48"> 這些城並屬城的村莊就是但支派按著宗族所得的地業。</span>
</div>
</div>

## 以亭拿西拉邑予約書亞為業

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以西結書 45:7–8"> 以色列人按著境界分完了地業，就在他們中間將地給嫩的兒子約書亞為業，</span>
<span className="v" id="v50" data-v="50" data-xref="約書亞記 24:30; 士師記 2:9; 歷代志上 7:24"> 是照耶和華的吩咐，將約書亞所求的城，就是以法蓮山地的亭拿西拉城，給了他。他就修那城，住在其中。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="約書亞記 18:10; 約書亞記 14:1; 約書亞記 18:1"> 這就是祭司以利亞撒和嫩的兒子約書亞並以色列各支派的族長，在示羅會幕門口，耶和華面前，拈鬮所分的地業。這樣，他們把地分完了。</span>
</div>
</div>

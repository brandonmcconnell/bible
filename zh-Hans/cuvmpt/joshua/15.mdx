## 猶大所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:55–56; 約書亞記 14:2; 民數記 33:36–37"> 猶大支派按著宗族拈鬮所得之地是在儘南邊，到以東的交界，向南直到尋的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:3; 以西結書 47:8; 以賽亞書 11:15"> 他們的南界是從鹽海的儘邊，就是從朝南的海汊起，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 34:4; 士師記 1:36; 民數記 20:1"> 通到亞克拉濱坡的南邊，接連到尋，上到加低斯巴尼亞的南邊，又過希斯崙，上到亞達珥，繞到甲加，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 34:5; 約書亞記 13:3; 出埃及記 23:31"> 接連到押們，通到埃及小河，直通到海為止。這就是他們的南界。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 34:12; 約書亞記 18:15–19; 民數記 34:10"> 東界是從鹽海南邊到約旦河口。北界是從約旦河口的海汊起，</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 18:17; 約書亞記 18:19–21"> 上到伯曷拉，過伯亞拉巴的北邊，上到魯本之子波罕的磐石；</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 1:9; 撒母耳記下 17:17; 約書亞記 7:26"> 從亞割谷往北，上到底璧，直向河南亞都冥坡對面的吉甲；又接連到隱示麥泉，直通到隱羅結，</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 18:16; 約書亞記 15:63; 約書亞記 18:28"> 上到欣嫩子谷，貼近耶布斯的南界（耶布斯就是耶路撒冷）；又上到欣嫩谷西邊的山頂，就是在利乏音谷極北的邊界；</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 13:6; 約書亞記 18:15; 士師記 18:12"> 又從山頂延到尼弗多亞的水源，通到以弗崙山的城邑，又延到巴拉（巴拉就是基列耶琳），</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 14:1; 士師記 14:5; 創世記 38:12–13"> 又從巴拉往西繞到西珥山，接連到耶琳山的北邊（耶琳就是基撒崙）；又下到伯示麥過亭納，</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 15:45; 列王紀下 1:2–3; 撒母耳記上 5:10"> 通到以革倫北邊，延到施基崙，接連到巴拉山，又通到雅比聶，直通到海為止。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 34:6–7; 約書亞記 15:47; 以西結書 47:20"> 西界就是大海和靠近大海之地。這是猶大人按著宗族所得之地四圍的交界。</span>
</div>
</div>

## 俄陀聶攻取基列西弗

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 13:30; 申命記 1:34–36; 民數記 14:23–24"> 約書亞照耶和華所吩咐的，將猶大人中的一段地，就是基列亞巴，分給耶孚尼的兒子迦勒；亞巴是亞衲族的始祖，基列亞巴就是希伯崙。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:20; 士師記 1:10; 民數記 13:22–23"> 迦勒就從那裡趕出亞衲族的三個族長，就是示篩、亞希幔、撻買。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:38; 約書亞記 10:3; 士師記 1:11–13"> 又從那裡上去，攻擊底璧的居民，這底璧從前名叫基列西弗。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 1:12–13; 士師記 1:6"> 迦勒說：「誰能攻打基列西弗將城奪取，我就把我女兒押撒給他為妻。」</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 3:9; 士師記 1:13; 約書亞記 14:6"> 迦勒兄弟基納斯的兒子俄陀聶奪取了那城，迦勒就把女兒押撒給他為妻。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 24:64; 撒母耳記上 25:23"> 押撒過門的時候，勸丈夫向她父親求一塊田。押撒一下驢，迦勒問她說：「你要什麼？」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 1:14–15; 撒母耳記上 25:27; 申命記 33:7"> 她說：「求你賜福給我，你既將我安置在南地，求你也給我水泉。」她父親就把上泉下泉賜給她。</span>
</div>
</div>

## 猶大所得之邑

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:8–12; 申命記 33:7"> 以下是猶大支派按著宗族所得的產業。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 35:21; 尼希米記 11:25"> 猶大支派儘南邊的城邑，與以東交界相近的，就是甲薛、以得、雅姑珥、</span>
<span className="v" id="v22" data-v="22"> 基拿、底摩拿、亞大達、</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 12:22; 民數記 33:37; 申命記 1:19"> 基低斯、夏瑣、以提楠、</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 23:14; 撒母耳記上 23:24; 撒母耳記上 23:19"> 西弗、提鏈、比亞綠、</span>
<span className="v" id="v25" data-v="25"> 夏瑣哈大他、加略希斯崙（加略希斯崙就是夏瑣）、</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 4:28"> 亞曼、示瑪、摩拉大、</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 11:26"> 哈薩迦大、黑實門、伯帕列、</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 26:33; 歷代志上 4:28; 創世記 21:31–33"> 哈薩書亞、別是巴、比斯約他、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 15:9–11; 約書亞記 19:3; 歷代志上 4:29"> 巴拉、以因、以森、</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:4; 民數記 14:45; 申命記 1:44"> 伊勒多臘、基失、何珥瑪、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 27:6; 撒母耳記上 30:1; 歷代志上 12:1"> 洗革拉、麥瑪拿、三撒拿、</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 34:11; 尼希米記 11:29"> 利巴勿、實忻、亞因、臨門，共二十九座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 13:25; 士師記 16:31; 民數記 13:23"> 在高原有以實陶、瑣拉、亞實拿、</span>

<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 17:1; 撒母耳記上 22:1; 約書亞記 10:3"> 耶末、亞杜蘭、梭哥、亞西加、</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 17:52"> 沙拉音、亞底他音、基底拉、基底羅他音，共十四座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 又有洗楠、哈大沙、麥大迦得、</span>

<span className="v" id="v40" data-v="40"> 迦本、拉幔、基提利、</span>
<span className="v" id="v41" data-v="41" data-xref="約書亞記 10:21; 約書亞記 12:16; 約書亞記 10:10"> 基低羅、伯大袞、拿瑪、瑪基大，共十六座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="約書亞記 10:29; 列王紀下 8:22; 約書亞記 19:7"> 又有立拿、以帖、亞珊、</span>
<span className="v" id="v43" data-v="43"> 益弗他、亞實拿、尼悉、</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 38:5; 彌迦書 1:14–15; 撒母耳記上 23:1–14"> 基伊拉、亞革悉、瑪利沙，共九座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約書亞記 13:3; 阿摩司書 1:8; 撒母耳記上 6:17"> 又有以革倫和屬以革倫的鎮市村莊。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 26:6; 阿摩司書 1:8; 撒母耳記上 5:1"> 從以革倫直到海，一切靠近亞實突之地，並屬其地的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="約書亞記 15:4; 出埃及記 23:31; 阿摩司書 1:6–7"> 亞實突和屬亞實突的鎮市村莊，加沙和屬加沙的鎮市村莊，直到埃及小河，並大海和靠近大海之地。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約書亞記 21:14"> 在山地有沙密、雅提珥、梭哥、</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 15:15; 士師記 1:11"> 大拿、基列薩拿（基列薩拿就是底璧）、</span>
<span className="v" id="v50" data-v="50"> 亞拿伯、以實提莫、亞念、</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 11:16; 約書亞記 10:41; 撒母耳記下 15:12"> 歌珊、何倫、基羅，共十一座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="以賽亞書 21:11"> 又有亞拉、度瑪、以珊、</span>
<span className="v" id="v53" data-v="53"> 雅農、伯他普亞、亞非加、</span>
<span className="v" id="v54" data-v="54" data-xref="約書亞記 15:13; 創世記 23:2; 約書亞記 14:15"> 宏他、基列亞巴（基列亞巴就是希伯崙）、洗珥，共九座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳記上 25:2; 約書亞記 15:24; 撒母耳記上 23:25"> 又有瑪雲、迦密、西弗、淤他、</span>
<span className="v" id="v56" data-v="56"> 耶斯列、約甸、撒挪亞、</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 15:10; 創世記 38:12; 耶利米書 14:1"> 該隱、基比亞、亭納，共十座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="歷代志上 4:39"> 又有哈忽、伯夙、基突、</span>
<span className="v" id="v59" data-v="59"> 瑪臘、伯亞諾、伊勒提君，共六座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="約書亞記 18:14; 撒母耳記上 7:1"> 又有基列巴力（基列巴力就是基列耶琳）、拉巴，共兩座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="約書亞記 15:6; 約書亞記 18:18"> 在曠野有伯亞拉巴、密丁、西迦迦、</span>
<span className="v" id="v62" data-v="62" data-xref="撒母耳記上 23:29; 歷代志下 20:2"> 匿珊、鹽城、隱基底，共六座城，還有屬城的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="士師記 1:21; 士師記 1:8; 撒母耳記下 5:6–9"> 至於住耶路撒冷的耶布斯人，猶大人不能把他們趕出去，耶布斯人卻在耶路撒冷與猶大人同住，直到今日。</span>
</div>

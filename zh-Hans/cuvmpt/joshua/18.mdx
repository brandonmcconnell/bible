## 餘地繪圖以備鬮分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 19:51; 撒母耳記上 1:3; 約書亞記 21:2"> 以色列的全會眾都聚集在示羅，把會幕設立在那裡，那地已經被他們制伏了。</span>
<span className="v" id="v2" data-v="2"> 以色列人中其餘的七個支派還沒有分給他們地業。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 18:9; 箴言 13:4; 箴言 10:4"> 約書亞對以色列人說：「耶和華你們列祖的神所賜給你們的地，你們耽延不去得，要到幾時呢？</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 18:6; 約書亞記 4:2; 約書亞記 18:3"> 你們每支派當選舉三個人，我要打發他們去，他們就要起身走遍那地，按著各支派應得的地業寫明<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：畫圖。">a</a></sup>，就回到我這裡來。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 16:1–10; 約書亞記 19:1–9; 約書亞記 15:1–12"> 他們要將地分做七份。猶大仍在南方，住在他的境內。約瑟家仍在北方，住在他的境內。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:2; 約書亞記 18:10; 使徒行傳 13:19"> 你們要將地分做七份，寫明了拿到我這裡來。我要在耶和華我們神面前，為你們拈鬮。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 13:33; 約書亞記 13:8–31; 民數記 18:20"> 利未人在你們中間沒有份，因為供耶和華祭司的職任就是他們的產業。迦得支派、魯本支派和瑪拿西半支派已經在約旦河東得了地業，就是耶和華僕人摩西所給他們的。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 18:10; 羅馬書 14:19; 撒母耳記上 14:41"> 劃地勢的人起身去的時候，約書亞囑咐他們說：「你們去走遍那地，劃明地勢，就回到我這裡來。我要在示羅這裡，耶和華面前，為你們拈鬮。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 13:19"> 他們就去了，走遍那地，按著城邑分做七份，寫在冊子上，回到示羅營中見約書亞。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 1:12; 使徒行傳 13:19; 約書亞記 18:6"> 約書亞就在示羅，耶和華面前，為他們拈鬮。約書亞在那裡，按著以色列人的支派，將地分給他們。</span>
</div>
</div>

## 便雅憫所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 16:1–10; 約書亞記 15:1–8; 申命記 10:1–22"> 便雅憫支派，按著宗族拈鬮所得之地，是在猶大、約瑟子孫中間。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 16:1; 約書亞記 7:2; 約書亞記 2:1"> 他們的北界是從約旦河起，往上貼近耶利哥的北邊，又往西通過山地，直到伯亞文的曠野；</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 28:19; 約書亞記 16:2–3; 約書亞記 10:11"> 從那裡往南接連到路斯，貼近路斯（路斯就是伯特利），又下到亞他綠亞達，靠近下伯和崙南邊的山。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:9; 歷代志上 13:5–6; 撒母耳記上 7:1–2"> 從那裡往西，又轉向南，從伯和崙南對面的山，直達到猶大人的城基列巴力（基列巴力就是基列耶琳），這是西界。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 15:9"> 南界是從基列耶琳的儘邊起，往西達到尼弗多亞的水源；</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:10; 約書亞記 15:7–8; 以賽亞書 30:33"> 又下到欣嫩子谷對面山的儘邊，就是利乏音谷北邊的山；又下到欣嫩谷，貼近耶布斯的南邊。又下到隱羅結；</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 15:6"> 又往北通到隱示麥，達到亞都冥坡對面的基利綠，又下到魯本之子波罕的磐石；</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 15:6; 約書亞記 15:61"> 又接連到亞拉巴對面，往北下到亞拉巴；</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:3; 約書亞記 15:2; 民數記 34:3"> 又接連到伯曷拉的北邊，直通到鹽海的北汊，就是約旦河的南頭。這是南界。</span>
<span className="v" id="v20" data-v="20"> 東界是約旦河。這是便雅憫人按著宗族，照他們四圍的交界所得的地業。</span>
</div>
</div>

## 便雅憫所得之邑

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 18:12; 約書亞記 6:1; 約書亞記 18:19"> 便雅憫支派按著宗族所得的城邑就是耶利哥、伯曷拉、伊麥基悉、</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 15:6; 列王紀上 12:29–32; 約書亞記 18:18"> 伯亞拉巴、洗瑪臉、伯特利、</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 13:17"> 亞文、巴拉、俄弗拉、</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 2:26; 約書亞記 21:17; 以賽亞書 10:29"> 基法阿摩尼、俄弗尼、迦巴，共十二座城，還有屬城的村莊。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 9:17; 列王紀上 3:4–5; 約書亞記 10:2"> 又有基遍、拉瑪、比錄、</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 10:17; 以斯拉記 2:25; 約書亞記 9:17"> 米斯巴、基非拉、摩撒、</span>
<span className="v" id="v27" data-v="27"> 利堅、伊利毗勒、他拉拉、</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 21:14; 約書亞記 15:8; 士師記 20:4–5"> 洗拉、以利弗、耶布斯（耶布斯就是耶路撒冷）、基比亞、基列，共十四座城，還有屬城的村莊。這是便雅憫人按著宗族所得的地業。</span>
</div>

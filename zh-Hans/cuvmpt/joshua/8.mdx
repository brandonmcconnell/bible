## 約書亞再攻艾城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 1:9; 申命記 7:18; 申命記 1:21"> 耶和華對約書亞說：「不要懼怕，也不要驚惶。你起來，率領一切兵丁上艾城去，我已經把艾城的王和他的民、他的城並他的地，都交在你手裡。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 20:14; 約書亞記 6:21; 歷代志下 20:22"> 你怎樣待耶利哥和耶利哥的王，也當照樣待艾城和艾城的王；只是城內所奪的財物和牲畜，你們可以取為自己的掠物。你要在城後設下伏兵。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 24:39; 馬太福音 25:6; 帖撒羅尼迦前書 5:2"> 於是，約書亞和一切兵丁都起來，要上艾城去。約書亞選了三萬大能的勇士，夜間打發他們前往，</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 20:29; 約書亞記 8:16; 士師記 20:36"> 吩咐他們說：「你們要在城後埋伏，不可離城太遠，都要各自準備。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 7:5; 馬太福音 10:16; 士師記 20:31–33"> 我與我所帶領的眾民要向城前往。城裡的人像初次出來攻擊我們的時候，我們就在他們面前逃跑，</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 20:32; 出埃及記 15:9; 傳道書 8:11"> 他們必出來追趕我們，直到我們引誘他們離開城，因為他們必說：『這些人像初次在我們面前逃跑。』所以我們要在他們面前逃跑，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王紀下 5:1; 約書亞記 8:1"> 你們就從埋伏的地方起來，奪取那城，因為耶和華你們的神必把城交在你們手裡。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 13:28; 約書亞記 1:16; 約書亞記 1:9"> 你們奪了城以後，就放火燒城，要照耶和華的話行。這是我吩咐你們的。」</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 7:2; 創世記 12:8; 以斯拉記 2:28"> 約書亞打發他們前往，他們就上埋伏的地方去，住在伯特利和艾城的中間，就是在艾城的西邊。這夜約書亞卻在民中住宿。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 6:12; 詩篇 119:60; 創世記 22:3"> 約書亞清早起來，點齊百姓，他和以色列的長老在百姓前面上艾城去。</span>
<span className="v" id="v11" data-v="11"> 眾民，就是他所帶領的兵丁，都上去，向前直往，來到城前，在艾城北邊安營。在約書亞和艾城中間有一山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 8:2–3"> 他挑了約有五千人，使他們埋伏在伯特利和艾城的中間，就是在艾城的西邊。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 8:12; 約書亞記 8:8"> 於是安置了百姓，就是城北的全軍和城西的伏兵。這夜約書亞進入山谷之中。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 24:39; 士師記 20:34–36; 申命記 1:1"> 艾城的王看見這景況，就和全城的人清早急忙起來，按所定的時候，出到亞拉巴前，要與以色列人交戰。王卻不知道在城後有伏兵。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 18:12; 約書亞記 16:1; 士師記 20:36"> 約書亞和以色列眾人在他們面前裝敗，往那通曠野的路逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 20:31; 士師記 20:36–39; 約書亞記 8:5–6"> 城內的眾民都被招聚，追趕他們。艾城人追趕的時候，就被引誘離開城。</span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 5:13; 約書亞記 8:3; 以賽亞書 19:11–13"> 艾城和伯特利城沒有一人不出來追趕以色列人的，撇了敞開的城門，去追趕以色列人。</span>
</div>
</div>

## 取艾城而焚之

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約書亞記 8:26; 約伯記 15:25; 撒母耳記上 17:41"> 耶和華吩咐約書亞說：「你向艾城伸出手裡的短槍，因為我要將城交在你手裡。」約書亞就向城伸出手裡的短槍。</span>
<span className="v" id="v19" data-v="19"> 他一伸手，伏兵就從埋伏的地方急忙起來，奪了城，跑進城去，放火焚燒。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 76:5; 約伯記 11:20; 創世記 19:28"> 艾城的人回頭一看，不料，城中煙氣沖天，他們就無力向左向右逃跑。那往曠野逃跑的百姓便轉身攻擊追趕他們的人。</span>
<span className="v" id="v21" data-v="21"> 約書亞和以色列眾人見伏兵已經奪了城，城中煙氣飛騰，就轉身回去，擊殺艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:2; 約書亞記 10:28; 約書亞記 6:21"> 伏兵也出城迎擊艾城人。艾城人就困在以色列人中間，前後都是以色列人。於是以色列人擊殺他們，沒有留下一個，也沒有一個逃脫的，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 15:8; 約書亞記 10:17; 啟示錄 19:20"> 生擒了艾城的王，將他解到約書亞那裡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約書亞記 11:10–14; 約書亞記 10:30–41; 民數記 21:24"> 以色列人在田間和曠野殺盡所追趕一切艾城的居民。艾城人倒在刀下，直到滅盡。以色列眾人就回到艾城，用刀殺了城中的人。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 20:16–18"> 當日殺斃的人，連男帶女共有一萬二千，就是艾城所有的人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 17:11–12; 約書亞記 8:18"> 約書亞沒有收回手裡所伸出來的短槍，直到把艾城的一切居民盡行殺滅。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 8:2; 民數記 31:26; 詩篇 50:10"> 唯獨城中的牲畜和財物，以色列人都取為自己的掠物，是照耶和華所吩咐約書亞的話。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 13:16; 耶利米書 49:2; 列王紀下 19:25"> 約書亞將艾城焚燒，使城永為高堆、荒場，直到今日。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 7:26; 撒母耳記下 18:17; 申命記 21:22–23"> 又將艾城王掛在樹上，直到晚上。日落的時候，約書亞吩咐人把屍首從樹上取下來，丟在城門口，在屍首上堆成一大堆石頭，直存到今日。</span>
</div>
</div>

## 約書亞築壇錄法於石

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:4–6; 出埃及記 20:24; 創世記 12:7–8"> 那時，約書亞在以巴路山上為耶和華以色列的神築一座壇，</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 27:5–7; 出埃及記 20:24–25; 約書亞記 8:34–35"> 是用沒有動過鐵器的整石頭築的，照著耶和華僕人摩西所吩咐以色列人的話，正如摩西律法書上所寫的。眾人在這壇上給耶和華奉獻燔祭和平安祭。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 27:2–3; 申命記 27:8"> 約書亞在那裡，當著以色列人面前，將摩西所寫的律法抄寫在石頭上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 11:29; 申命記 31:12; 申命記 31:9"> 以色列眾人，無論是本地人是寄居的，和長老、官長並審判官都站在約櫃兩旁，在抬耶和華約櫃的祭司利未人面前，一半對著基利心山，一半對著以巴路山，為以色列民祝福，正如耶和華僕人摩西先前所吩咐的。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 8:2–3; 尼希米記 13:1; 申命記 31:10–12"> 隨後約書亞將律法上祝福、咒詛的話，照著律法書上一切所寫的，都宣讀了一遍。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 31:12; 尼希米記 8:2; 耶利米書 26:2"> 摩西所吩咐的一切話，約書亞在以色列全會眾和婦女、孩子，並他們中間寄居的外人面前，沒有一句不宣讀的。</span>
</div>
</div>

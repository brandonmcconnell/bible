## 醫好三十八年之病者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:16; 出埃及記 23:14–17; 出埃及記 34:23"> 這事以後，到了猶太人的一個節期，耶穌就上耶路撒冷去。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="尼希米記 12:39; 尼希米記 3:1; 尼希米記 3:32"> 在耶路撒冷，靠近羊門有一個池子，希伯來話叫做畢士大，旁邊有五個廊子，</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 3:1–4; 路加福音 7:22; 馬太福音 15:30"> 裡面躺著瞎眼的、瘸腿的、血氣枯乾的許多病人。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：等候水動，4 因為有天使按時下池子攪動那水，水動之後，誰先下去，無論害什麼病就痊癒了。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 3:2; 路加福音 8:43; 馬可福音 9:21"> 在那裡有一個人，病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯來書 4:15; 希伯來書 4:13"> 耶穌看見他躺著，知道他病了許久，就問他說：<span className="woj">「你要痊癒嗎？」</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 72:12; 申命記 32:36; 哥林多前書 9:24"> 病人回答說：「先生，水動的時候，沒有人把我放在池子裡，我正去的時候，就有別人比我先下去。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 馬太福音 9:6; 馬可福音 2:11"> 耶穌對他說：<span className="woj">「起來，拿你的褥子走吧！」</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 3:7–8; 約翰福音 9:14; 馬可福音 3:2–4"> 那人立刻痊癒，就拿起褥子來走了。</span>
</div>
</div>

## 猶太人責耶穌犯安息日

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 17:21; 路加福音 6:2; 約翰福音 9:16"> 那天是安息日，所以猶太人對那醫好的人說：「今天是安息日，你拿褥子是不可的！」</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 2:9–11; 約翰福音 9:16"> 他卻回答說：「那使我痊癒的對我說『拿你的褥子走吧』。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:23; 士師記 6:29; 羅馬書 10:2"> 他們問他說：「對你說『拿褥子走』的是什麼人？」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 約翰福音 8:59"> 那醫好的人不知道是誰，因為那裡的人多，耶穌已經躲開了。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 8:11; 利未記 26:23–24; 詩篇 118:18"> 後來耶穌在殿裡遇見他，對他說：<span className="woj">「你已經痊癒了，不要再犯罪，恐怕你遭遇的更加厲害。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 9:11–12; 約翰福音 4:29; 約翰福音 9:25"> 那人就去告訴猶太人，使他痊癒的是耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 10:39; 約翰福音 7:19–20; 馬可福音 3:6"> 所以猶太人逼迫耶穌，因為他在安息日做了這事。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 9:4; 約翰福音 14:10; 歌羅西書 1:16"> 耶穌就對他們說：<span className="woj">「我父做事直到如今，我也做事。」</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 10:30; 約翰福音 10:33; 約翰福音 19:7"> 所以猶太人越發想要殺他，因他不但犯了安息日，並且稱神為他的父，將自己和神當做平等。</span>
</div>
</div>

## 尊敬子如尊敬父

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 12:49; 約翰福音 8:28; 約翰福音 14:10"> 耶穌對他們說：<span className="woj">「我實實在在地告訴你們：子憑著自己不能做什麼，唯有看見父所做的，子才能做；父所做的事，子也照樣做。</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 3:35; 馬太福音 3:17; 約翰福音 17:26"> <span className="woj">父愛子，將自己所做的一切事指給他看，還要將比這更大的事指給他看，叫你們稀奇。</span></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:11; 申命記 32:39; 約翰福音 11:25"> <span className="woj">父怎樣叫死人起來，使他們活著，子也照樣隨自己的意思使人活著。</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 5:27; 使徒行傳 17:31; 哥林多後書 5:10"> <span className="woj">父不審判什麼人，乃將審判的事全交於子，</span></span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 2:23; 路加福音 10:16; 馬太福音 11:27"> <span className="woj">叫人都尊敬子如同尊敬父一樣。不尊敬子的，就是不尊敬差子來的父。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 3:36; 約翰福音 6:40; 約翰一書 5:11–13"> <span className="woj">我實實在在地告訴你們：那聽我話又信差我來者的，就有永生，不至於定罪，是已經出死入生了。</span></span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 5:28; 以弗所書 5:14; 以弗所書 2:5"> <span className="woj">我實實在在地告訴你們：時候將到，現在就是了，死人要聽見神兒子的聲音，聽見的人就要活了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 11:26; 約翰福音 1:4; 出埃及記 3:14"> <span className="woj">因為父怎樣在自己有生命，就賜給他兒子也照樣在自己有生命，</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 10:42; 約翰福音 5:22; 使徒行傳 17:31"> <span className="woj">並且因為他是人子，就賜給他行審判的權柄。</span></span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 20:12; 帖撒羅尼迦前書 4:14–17; 以賽亞書 26:19"> <span className="woj">你們不要把這事看做稀奇。時候要到，凡在墳墓裡的，都要聽見他的聲音，就出來，</span></span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 12:2–3; 羅馬書 2:6–10; 使徒行傳 24:15"> <span className="woj">行善的復活得生，作惡的復活定罪。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 6:38; 約翰福音 5:19; 約翰福音 4:34"> <span className="woj">「我憑著自己不能做什麼，我怎麼聽見就怎麼審判。我的審判也是公平的，因為我不求自己的意思，只求那差我來者的意思。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 約翰福音 8:54; 啟示錄 3:14"> <span className="woj">我若為自己作見證，我的見證就不真。</span></span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 1:33; 約翰福音 12:28–30; 約翰福音 5:36–37"> <span className="woj">另有一位給我作見證，我也知道他給我作的見證是真的。</span></span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 1:29–34; 約翰福音 3:26–36; 約翰福音 1:15–27"> <span className="woj">你們曾差人到約翰那裡，他為真理作過見證。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 約翰福音 20:31; 約翰一書 5:9"> <span className="woj">其實我所受的見證不是從人來的，然而我說這些話，為要叫你們得救。</span></span>
<span className="v" id="v35" data-v="35" data-xref="彼得後書 1:19; 約翰福音 1:7–8; 馬太福音 11:11"> <span className="woj">約翰是點著的明燈，你們情願暫時喜歡他的光。</span></span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 10:25; 約翰福音 10:37–38; 約翰福音 15:24"> <span className="woj">但我有比約翰更大的見證，因為父交給我要我成就的事，就是我所做的事，這便見證我是父所差來的。</span></span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 8:18; 約翰福音 1:18; 馬太福音 3:17"> <span className="woj">差我來的父也為我作過見證。你們從來沒有聽見他的聲音，也沒有看見他的形像。</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰一書 2:14; 申命記 6:6–9; 約翰福音 12:44–48"> <span className="woj">你們並沒有他的道存在心裡，因為他所差來的，你們不信。</span></span>
</div>
</div>

## 聖經為耶穌的證據

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得後書 1:19–21"> <span className="woj">「你們查考聖經</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：應當查考聖經。">b</a></sup><span className="woj">，因你們以為內中有永生。給我作見證的就是這經，</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 3:19; 約翰福音 1:11; 詩篇 81:11"> <span className="woj">然而你們不肯到我這裡來得生命。</span></span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 7:18; 約翰福音 5:34; 帖撒羅尼迦前書 2:6"> <span className="woj">我不受從人來的榮耀。</span></span>
<span className="v" id="v42" data-v="42" data-xref="約翰一書 4:20; 約翰一書 3:17; 約翰福音 2:25"> <span className="woj">但我知道，你們心裡沒有神的愛。</span></span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 10:25; 馬太福音 24:5; 約翰福音 17:4–6"> <span className="woj">我奉我父的名來，你們並不接待我；若有別人奉自己的名來，你們倒要接待他。</span></span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 12:43; 羅馬書 2:29; 腓立比書 2:3"> <span className="woj">你們互相受榮耀，卻不求從獨一之神來的榮耀，怎能信我呢？</span></span>
</div>
</div>

## 不信摩西怎能信主

<div className="bp">

<span className="v" id="v46" data-v="46" data-xref="申命記 18:15; 申命記 18:18–19; 約翰福音 1:45"> <span className="woj">你們如果信摩西，也必信我，因為他書上有指著我寫的話。</span></span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> <span className="woj">你們若不信他的書，怎能信我的話呢？」</span></span>

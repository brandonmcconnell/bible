## 耶穌在迦拿變水為酒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 4:46; 箴言 31:10–12; 約翰福音 21:2"> 第三日，在加利利的迦拿有娶親的筵席，耶穌的母親在那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 1:40–49; 馬太福音 10:40–42; 哥林多前書 7:39"> 耶穌和他的門徒也被請去赴席。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 104:15; 腓立比書 4:6; 以賽亞書 24:11"> 酒用盡了，耶穌的母親對他說：「他們沒有酒了。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 7:6; 約翰福音 13:1; 約翰福音 7:30"> 耶穌說：<span className="woj">「母親</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：婦人。">a</a></sup><span className="woj">，我與你有什麼相干？我的時候還沒有到。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 15:14; 創世記 6:22; 希伯來書 11:8"> 他母親對用人說：「他告訴你們什麼，你們就做什麼。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 3:25; 希伯來書 9:10; 以弗所書 5:26"> 照猶太人潔淨的規矩，有六口石缸擺在那裡，每口可以盛兩三桶水。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 4:2–6; 約翰福音 2:5; 約翰福音 2:3"> 耶穌對用人說：<span className="woj">「把缸倒滿了水。」</span>他們就倒滿了，直到缸口。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 2:9; 箴言 3:5–6; 羅馬書 13:7"> 耶穌又說：<span className="woj">「現在可以舀出來，送給管筵席的。」</span>他們就送了去。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 4:46; 約翰福音 7:17; 詩篇 119:100"> 管筵席的嘗了那水變的酒，並不知道是哪裡來的，只有舀水的用人知道。管筵席的便叫新郎來，</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 7:16–17; 箴言 9:1–6; 路加福音 16:25"> 對他說：「人都是先擺上好酒，等客喝足了才擺上次的，你倒把好酒留到如今！」</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 20:30–31; 約翰福音 1:14; 約翰福音 3:2"> 這是耶穌所行的頭一件神蹟，是在加利利的迦拿行的，顯出他的榮耀來，他的門徒就信他了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:46; 馬太福音 13:55–56; 馬可福音 6:3"> 這事以後，耶穌與他的母親、弟兄和門徒都下迦百農去，在那裡住了不多幾日。</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:41; 約翰福音 11:55; 約翰福音 2:23"> 猶太人的逾越節近了，耶穌就上耶路撒冷去。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 19:45–46; 馬可福音 11:15; 馬可福音 11:17"> 看見殿裡有賣牛、羊、鴿子的，並有兌換銀錢的人坐在那裡，</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:6; 撒迦利亞書 4:6; 哥林多後書 10:4"> 耶穌就拿繩子做成鞭子，把牛羊都趕出殿去，倒出兌換銀錢之人的銀錢，推翻他們的桌子，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 21:13; 耶利米書 7:11; 馬可福音 11:17"> 又對賣鴿子的說：<span className="woj">「把這些東西拿去，不要將我父的殿當做買賣的地方！」</span></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:9; 詩篇 119:139"> 他的門徒就想起經上記著說：「我為你的殿心裡焦急，如同火燒。」</span>
</div>
</div>

## 耶穌以殿譬己身

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 21:23; 馬可福音 8:11; 馬可福音 11:27–28"> 因此猶太人問他說：「你既做這些事，還顯什麼神蹟給我們看呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:58; 馬可福音 15:29; 馬太福音 27:40"> 耶穌回答說：<span className="woj">「你們拆毀這殿，我三日內要再建立起來。」</span></span>
<span className="v" id="v20" data-v="20"> 猶太人便說：「這殿是四十六年才造成的，你三日內就再建立起來嗎？」</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 6:19; 哥林多前書 3:16; 以弗所書 2:20–22"> 但耶穌這話是以他的身體為殿。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 12:16; 約翰福音 16:4; 路加福音 24:7–8"> 所以到他從死裡復活以後，門徒就想起他說過這話，便信了聖經和耶穌所說的。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 7:31; 路加福音 8:13; 約翰福音 6:14"> 當耶穌在耶路撒冷過逾越節的時候，有許多人看見他所行的神蹟，就信了他的名。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:64; 希伯來書 4:13; 使徒行傳 1:24"> 耶穌卻不將自己交託他們，因為他知道萬人，</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 13:11; 馬太福音 9:4; 約翰福音 6:64"> 也用不著誰見證人怎樣，因他知道人心裡所存的。</span>
</div>
</div>

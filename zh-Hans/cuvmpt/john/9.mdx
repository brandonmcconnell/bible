## 醫好生來瞎眼的

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶穌過去的時候，看見一個人生來是瞎眼的。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 13:2; 約翰福音 9:34; 使徒行傳 28:4"> 門徒問耶穌說：「拉比，這人生來是瞎眼的，是誰犯了罪？是這人呢，是他父母呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:4; 約翰福音 11:40; 傳道書 9:1–2"> 耶穌回答說：<span className="woj">「也不是這人犯了罪，也不是他父母犯了罪，是要在他身上顯出神的作為來。</span></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 12:35; 以弗所書 5:16; 約翰福音 4:34"> <span className="woj">趁著白日，我們必須做那差我來者的工；黑夜將到，就沒有人能做工了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 8:12; 約翰福音 12:46; 使徒行傳 13:47"> <span className="woj">我在世上的時候，是世上的光。」</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 8:23; 馬可福音 7:33; 啟示錄 3:18"> 耶穌說了這話，就吐唾沫在地上，用唾沫和泥抹在瞎子的眼睛上，</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 35:5; 約翰福音 9:11; 約翰福音 11:37"> 對他說：<span className="woj">「你往西羅亞池子裡去洗。」</span>（「西羅亞」翻出來就是「奉差遣」。）他去一洗，回頭就看見了。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 2:8; 撒母耳記上 21:11; 路加福音 18:35"> 他的鄰舍和那素常見他是討飯的，就說：「這不是那從前坐著討飯的人嗎？」</span>
<span className="v" id="v9" data-v="9"> 有人說：「是他。」又有人說：「不是，卻是像他。」他自己說：「是我。」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 9:26; 約翰福音 9:21; 傳道書 11:5"> 他們對他說：「你的眼睛是怎樣開的呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 9:6–7; 約翰福音 9:27; 耶利米書 36:17"> 他回答說：「有一個人名叫耶穌，他和泥抹我的眼睛，對我說：『你往西羅亞池子去洗。』我去一洗，就看見了。」</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 5:11–13; 出埃及記 2:18–20; 約翰福音 7:11"> 他們說：「那個人在哪裡？」他說：「我不知道。」</span>
</div>
</div>

## 法利賽人盤問醫好的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 11:57; 約翰福音 11:46–47; 約翰福音 12:42"> 他們把從前瞎眼的人帶到法利賽人那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 5:9; 路加福音 13:10–17; 馬太福音 12:1–14"> 耶穌和泥開他眼睛的日子是安息日。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 9:26–27; 約翰福音 9:10–11"> 法利賽人也問他是怎麼得看見的。瞎子對他們說：「他把泥抹在我的眼睛上，我去一洗，就看見了。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:43; 約翰福音 10:19; 馬太福音 12:2"> 法利賽人中有的說：「這個人不是從神來的，因為他不守安息日。」又有人說：「一個罪人怎能行這樣的神蹟呢？」他們就起了紛爭。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:19; 約翰福音 6:14; 使徒行傳 3:22–26"> 他們又對瞎子說：「他既然開了你的眼睛，你說他是怎樣的人呢？」他說：「是個先知。」</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 3:15–19; 約翰福音 5:44; 以賽亞書 26:11"> 猶太人不信他從前是瞎眼、後來能看見的，等到叫了他的父母來，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 9:8–9; 使徒行傳 4:14; 使徒行傳 3:10"> 問他們說：「這是你們的兒子嗎？你們說他生來是瞎眼的，如今怎麼能看見了呢？」</span>
<span className="v" id="v20" data-v="20"> 他父母回答說：「他是我們的兒子，生來就瞎眼，這是我們知道的。</span>
<span className="v" id="v21" data-v="21"> 至於他如今怎麼能看見，我們卻不知道。是誰開了他的眼睛，我們也不知道。他已經成了人，你們問他吧，他自己必能說。」</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 7:13; 約翰福音 16:2; 路加福音 6:22"> 他父母說這話是怕猶太人，因為猶太人已經商議定了，若有認耶穌是基督的，要把他趕出會堂。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 9:21"> 因此他父母說「他已經成了人，你們問他吧」。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 7:19; 約翰福音 9:16; 約翰福音 8:49"> 所以法利賽人第二次叫了那從前瞎眼的人來，對他說：「你該將榮耀歸給神，我們知道這人是個罪人。」</span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 5:10; 約翰福音 9:30; 約翰福音 5:11"> 他說：「他是個罪人不是，我不知道。有一件事我知道：從前我是眼瞎的，如今能看了！」</span>
<span className="v" id="v26" data-v="26"> 他們就問他說：「他向你做什麼？是怎麼開了你的眼睛呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:67; 約翰福音 9:10–15"> 他回答說：「我方才告訴你們，你們不聽，為什麼又要聽呢？莫非你們也要做他的門徒嗎？」</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 2:17; 約翰福音 7:19; 馬太福音 27:39"> 他們就罵他，說：「你是他的門徒！我們是摩西的門徒。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 8:14; 民數記 12:2–7; 使徒行傳 7:35"> 神對摩西說話是我們知道的，只是這個人，我們不知道他從哪裡來！」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:37; 詩篇 119:18; 以賽亞書 29:18"> 那人回答說：「他開了我的眼睛，你們竟不知道他從哪裡來，這真是奇怪！</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 15:29; 以賽亞書 1:15; 箴言 28:9"> 我們知道神不聽罪人，唯有敬奉神、遵行他旨意的，神才聽他。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 64:4; 啟示錄 16:18; 約伯記 20:4"> 從創世以來，未曾聽見有人把生來是瞎子的眼睛開了。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 9:16; 約翰福音 3:2; 使徒行傳 5:38–39"> 這人若不是從神來的，什麼也不能做。」</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 9:22; 約翰福音 9:2; 以賽亞書 66:5"> 他們回答說：「你全然生在罪孽中，還要教訓我們嗎？」於是把他趕出去了。</span>
</div>
</div>

## 耶穌收留被逐的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 20:31; 約翰一書 5:13; 約翰福音 10:36"> 耶穌聽說他們把他趕出去，後來遇見他，就說：<span className="woj">「你信神的兒子嗎？」</span></span>
<span className="v" id="v36" data-v="36" data-xref="羅馬書 10:14; 雅歌 5:9; 約翰福音 1:38"> 他回答說：「主啊，誰是神的兒子，叫我信他呢？」</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 4:26; 詩篇 25:8–9; 約翰福音 14:21–23"> 耶穌說：<span className="woj">「你已經看見他，現在和你說話的就是他。」</span></span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 14:33; 馬太福音 28:9; 路加福音 24:52"> 他說：「主啊，我信！」就拜耶穌。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 3:19; 約翰福音 12:46; 使徒行傳 26:18"> 耶穌說：<span className="woj">「我為審判到這世上來，叫不能看見的可以看見，能看見的反瞎了眼。」</span></span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 3:17; 馬太福音 15:12–14; 約翰福音 7:47–52"> 同他在那裡的法利賽人聽見這話，就說：「難道我們也瞎了眼嗎？」</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 5:21; 約翰福音 15:22–24; 約翰一書 1:8–10"> 耶穌對他們說：<span className="woj">「你們若瞎了眼，就沒有罪了；但如今你們說『我們能看見』，所以你們的罪還在。</span></span>
</div>

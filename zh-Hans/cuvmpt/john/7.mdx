## 眾人為耶穌紛紛議論

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 5:13; 馬太福音 10:16; 以賽亞書 42:2–3"> 但他弟兄上去以後，他也上去過節，不是明去，似乎是暗去的。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:56"> 正在節期，猶太人尋找耶穌，說：「他在哪裡？」</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 7:40–43; 約翰福音 9:16; 約翰福音 7:32"> 眾人為他紛紛議論，有的說：「他是好人。」有的說：「不然，他是迷惑眾人的。」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 9:22; 約翰福音 19:38; 約翰福音 20:19"> 只是沒有人明明地講論他，因為怕猶太人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 7:28; 路加福音 19:47; 約翰福音 7:37"> 到了節期，耶穌上殿裡去教訓人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 馬太福音 7:28–29; 馬太福音 13:54"> 猶太人就稀奇說：「這個人沒有學過，怎麼明白書呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:10; 約翰福音 14:24; 約翰福音 17:8"> 耶穌說：<span className="woj">「我的教訓不是我自己的，乃是那差我來者的。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 8:31–32; 約翰福音 8:43; 耶利米書 31:33–34"> <span className="woj">人若立志遵著他的旨意行，就必曉得這教訓或是出於神，或是我憑著自己說的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 5:41; 哥林多前書 10:31–33; 約翰福音 13:31–32"> <span className="woj">人憑著自己說，是求自己的榮耀；唯有求那差他來者的榮耀，這人是真的，在他心裡沒有不義。</span></span>
</div>
</div>

## 不可按外貌定是非

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 1:17; 約翰福音 11:53; 馬太福音 12:14"> <span className="woj">「摩西豈不是傳律法給你們嗎？你們卻沒有一個人守律法！為什麼想要殺我呢？」</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:20; 約翰福音 8:48; 約翰福音 8:52"> 眾人回答說：「你是被鬼附著了！誰想要殺你？」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 7:23; 約翰福音 5:2–11"> 耶穌說：<span className="woj">「我做了一件事，你們都以為稀奇。</span></span>
<span className="v" id="v22" data-v="22" data-xref="利未記 12:3; 創世記 17:10–14; 羅馬書 4:9–11"> <span className="woj">摩西傳割禮給你們（其實不是從摩西起的，乃是從祖先起的），因此你們也在安息日給人行割禮。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:5; 約翰福音 5:14–16; 馬太福音 12:2"> <span className="woj">人若在安息日受割禮，免得違背摩西的律法，我在安息日叫一個人全然好了，你們就向我生氣嗎？</span></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 11:3–4; 雅各書 2:9; 約翰福音 8:15"> <span className="woj">不可按外貌斷定是非，總要按公平斷定是非。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 7:10–11"> 耶路撒冷人中有的說：「這不是他們想要殺的人嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:7–8; 約翰福音 7:48; 約翰福音 12:42"> 你看，他還明明地講道，他們也不向他說什麼，難道官長真知道這是基督嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 5:2; 約翰福音 7:41–42; 約翰福音 6:42"> 然而我們知道這個人從哪裡來，只是基督來的時候，沒有人知道他從哪裡來。」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 8:42; 約翰福音 8:19; 約翰福音 8:26"> 那時，耶穌在殿裡教訓人，大聲說：<span className="woj">「你們也知道我，也知道我從哪裡來。我來並不是由於自己，但那差我來的是真的，你們不認識他。</span></span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 8:55; 馬太福音 11:27; 約翰福音 17:18"> <span className="woj">我卻認識他，因為我是從他來的，他也是差了我來。」</span></span>
</div>
</div>

## 打發差役捉拿耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 8:20; 約翰福音 10:39; 約翰福音 7:6"> 他們就想要捉拿耶穌，只是沒有人下手，因為他的時候還沒有到。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 12:42; 馬太福音 12:23; 約翰福音 10:41–42"> 但眾人中間有好些信他的，說：「基督來的時候，他所行的神蹟豈能比這人所行的更多嗎？」</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 18:3; 路加福音 22:52–53; 約翰福音 11:47–48"> 法利賽人聽見眾人為耶穌這樣紛紛議論，祭司長和法利賽人就打發差役去捉拿他。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 16:5; 約翰福音 13:33; 馬可福音 16:19"> 於是耶穌說：<span className="woj">「我還有不多的時候和你們同在，以後就回到差我來的那裡去。</span></span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; 約翰福音 13:33–36; 約翰福音 14:6"> <span className="woj">你們要找我，卻找不著，我所在的地方你們不能到。」</span></span>
<span className="v" id="v35" data-v="35" data-xref="雅各書 1:1; 以賽亞書 11:12; 西番雅書 3:10"> 猶太人就彼此對問說：「這人要往哪裡去，叫我們找不著呢？難道他要往散住希臘中的猶太人那裡去教訓希臘人嗎？</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 3:9; 約翰福音 7:34; 約翰福音 12:34"> 他說<span className="woj">『你們要找我，卻找不著，我所在的地方你們不能到』</span>，這話是什麼意思呢？」</span>
</div>
</div>

## 渴者當來就耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 55:1; 約翰福音 4:14; 約翰福音 6:35"> 節期的末日，就是最大之日，耶穌站著高聲說：<span className="woj">「人若渴了，可以到我這裡來喝！</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 4:14; 以賽亞書 44:3; 以賽亞書 58:11"> <span className="woj">信我的人就如經上所說，從他腹中要流出活水的江河來。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 2:17; 約珥書 2:28; 約翰福音 14:16–17"> 耶穌這話是指著信他之人要受聖靈說的。那時還沒有賜下聖靈來，因為耶穌尚未得著榮耀。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 21:11; 約翰福音 1:21; 約翰福音 6:14"> 眾人聽見這話，有的說：「這真是那先知！」</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 7:52; 約翰福音 1:46; 約翰福音 1:49"> 有的說：「這是基督。」但也有的說：「基督豈是從加利利出來的嗎？</span>
<span className="v" id="v42" data-v="42" data-xref="彌迦書 5:2; 馬太福音 2:5; 路加福音 2:4"> 經上豈不是說基督是大衛的後裔，從大衛本鄉伯利恆出來的嗎？」</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 9:16; 約翰福音 10:19; 約翰福音 7:12"> 於是眾人因著耶穌起了紛爭。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 7:30; 使徒行傳 23:11; 約翰福音 8:20"> 其中有人要捉拿他，只是無人下手。</span>
</div>
</div>

## 沒有人像耶穌說話

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 7:32; 使徒行傳 5:21–27"> 差役回到祭司長和法利賽人那裡，他們對差役說：「你們為什麼沒有帶他來呢？」</span>
<span className="v" id="v46" data-v="46" data-xref="馬太福音 7:28–29; 路加福音 4:22; 約翰福音 7:26"> 差役回答說：「從來沒有像他這樣說話的！」</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 7:12; 哥林多後書 6:8; 列王紀下 18:32"> 法利賽人說：「你們也受了迷惑嗎？</span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 12:42; 哥林多前書 1:20; 哥林多前書 2:8"> 官長或是法利賽人豈有信他的呢？</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:20–21; 約翰福音 9:40; 約翰福音 9:34"> 但這些不明白律法的百姓是被咒詛的！」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:39; 約翰福音 3:1–2"> 內中有尼哥迪慕，就是從前去見耶穌的，對他們說：</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命記 1:17; 申命記 19:15–19"> 「不先聽本人的口供，不知道他所做的事，難道我們的律法還定他的罪嗎？」</span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 7:41; 約翰福音 1:46; 以賽亞書 9:1–2"> 他們回答說：「你也是出於加利利嗎？你且去查考，就可知道加利利沒有出過先知。」</span>

## 耶穌在提比哩亞海邊顯現

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 6:1; 約翰福音 6:23; 馬太福音 28:16"> 這些事以後，耶穌在提比哩亞海邊又向門徒顯現。他怎樣顯現記在下面。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:21–22; 約翰福音 1:45–1; 約翰福音 4:46"> 有西門彼得和稱為低土馬的多馬，並加利利的迦拿人拿但業，還有西庇太的兩個兒子，又有兩個門徒，都在一處。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:5; 馬太福音 4:18–20; 帖撒羅尼迦後書 3:7–9"> 西門彼得對他們說：「我打魚去。」他們說：「我們也和你同去。」他們就出去，上了船，那一夜並沒有打著什麼。</span>
</div>
</div>

## 得滿網魚

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 20:14; 路加福音 24:15–16; 路加福音 24:31"> 天將亮的時候，耶穌站在岸上，門徒卻不知道是耶穌。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:19; 腓立比書 4:11–13; 約翰一書 2:13"> 耶穌就對他們說：<span className="woj">「小子，你們有吃的沒有？」</span>他們回答說：「沒有。」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:4–7; 使徒行傳 2:41; 約翰福音 2:5"> 耶穌說：<span className="woj">「你們把網撒在船的右邊，就必得著。」</span>他們便撒下網去，竟拉不上來了，因為魚甚多。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 13:23; 約翰福音 20:2; 馬太福音 14:28–29"> 耶穌所愛的那門徒對彼得說：「是主！」那時西門彼得赤著身子，一聽見是主，就束上一件外衣，跳在海裡。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:11"> 其餘的門徒離岸不遠，約有二百肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="古代以肘為尺，一肘約有今時尺半。">a</a></sup>，就在小船上把那網魚拉過來。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 21:13; 列王紀上 19:5–6; 約翰福音 21:10"> 他們上了岸，就看見那裡有炭火，上面有魚又有餅。</span>
<span className="v" id="v10" data-v="10"> 耶穌對他們說：<span className="woj">「把剛才打的魚拿幾條來。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 5:6–8; 使徒行傳 2:41"> 西門彼得就去<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：上船。">b</a></sup>，把網拉到岸上。那網滿了大魚，共一百五十三條。魚雖這樣多，網卻沒有破。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:41; 路加福音 9:45; 約翰福音 16:19"> 耶穌說：<span className="woj">「你們來吃早飯。」</span>門徒中沒有一個敢問他「你是誰？」，因為知道是主。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 21:9; 使徒行傳 10:41; 路加福音 24:42–43"> 耶穌就來拿餅和魚給他們。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 20:26; 約翰福音 20:19"> 耶穌從死裡復活以後向門徒顯現，這是第三次。</span>
</div>
</div>

## 查彼得愛主之心

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 40:11; 約翰一書 4:19; 羅馬書 15:1"> 他們吃完了早飯，耶穌對西門彼得說：<span className="woj">「約翰</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「約翰」《馬太福音》16章17節稱「約拿」。">c</a></sup><span className="woj">的兒子西門，你愛我比這些更深嗎？」彼得</span>說：「主啊，是的，你知道我愛你。」耶穌對他說：<span className="woj">「你餵養我的小羊。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 20:28; 彼得前書 5:2; 彼得前書 2:25"> 耶穌第二次又對他說：<span className="woj">「約翰的兒子西門，你愛我嗎？」彼得</span>說：「主啊，是的，你知道我愛你。」耶穌說：<span className="woj">「你牧養我的羊。」</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 13:38; 約翰福音 16:30; 馬可福音 14:72"> 第三次對他說：<span className="woj">「約翰的兒子西門，你愛我嗎？」彼得</span>因為耶穌第三次對他說<span className="woj">「你愛我嗎」</span>，就憂愁，對耶穌說：「主啊，你是無所不知的，你知道我愛你。」耶穌說：<span className="woj">「你餵養我的羊。</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 13:36; 使徒行傳 12:3–4; 使徒行傳 21:11"> <span className="woj">我實實在在地告訴你：你年少的時候，自己束上帶子，隨意往來；但年老的時候，你要伸出手來，別人要把你束上，帶你到不願意的地方。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="彼得後書 1:14; 約翰福音 21:22; 馬太福音 10:38"> 耶穌說這話，是指著彼得要怎樣死榮耀神。說了這話，就對他說：<span className="woj">「你跟從我吧！」</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 21:7; 約翰福音 20:2; 約翰福音 21:24"> 彼得轉過來，看見耶穌所愛的那門徒跟著，就是在晚飯的時候靠著耶穌胸膛，說「主啊，賣你的是誰」的那門徒。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 13:23–24; 使徒行傳 1:6–7; 馬太福音 24:3–4"> 彼得看見他，就問耶穌說：「主啊，這人將來如何？」</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:25; 啟示錄 3:11; 馬可福音 9:1"> 耶穌對他說：<span className="woj">「我若要他等到我來的時候，與你何干？你跟從我吧！」</span></span>
<span className="v" id="v23" data-v="23" data-xref="申命記 29:29; 約伯記 33:13; 但以理書 4:35"> 於是這話傳在弟兄中間，說那門徒不死。其實耶穌不是說他不死，乃是說：<span className="woj">「我若要他等到我來的時候，與你何干？」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 19:35; 約翰福音 15:27; 約翰一書 5:6"> 為這些事作見證，並且記載這些事的，就是這門徒。我們也知道他的見證是真的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 40:5; 約翰福音 20:30–31; 詩篇 71:15"> 耶穌所行的事還有許多，若是一一地都寫出來，我想，所寫的書就是世界也容不下了。</span>
</div>

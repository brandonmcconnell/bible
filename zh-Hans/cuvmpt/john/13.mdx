## 耶穌洗門徒的腳做榜樣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 12:23; 約翰一書 4:19; 約翰福音 13:34"> 逾越節以前，耶穌知道自己離世歸父的時候到了。他既然愛世間屬自己的人，就愛他們到底。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:13–17; 使徒行傳 5:3; 約翰福音 13:26–27"> 吃晚飯的時候——魔鬼已將賣耶穌的意思放在西門的兒子加略人猶大心裡——</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 3:35; 馬太福音 11:27; 希伯來書 1:2"> 耶穌知道父已將萬有交在他手裡，且知道自己是從神出來的，又要歸到神那裡去，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:27; 哥林多後書 8:9; 路加福音 12:37"> 就離席站起來，脫了衣服，拿一條手巾束腰。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:44; 詩篇 51:2; 創世記 18:4"> 隨後把水倒在盆裡，就洗門徒的腳，並用自己所束的手巾擦乾。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 3:11–14; 約翰福音 1:27; 路加福音 5:8"> 挨到西門彼得，彼得對他說：「主啊，你洗我的腳嗎？」</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 12:8; 約翰福音 12:16; 約翰福音 14:26"> 耶穌回答說：<span className="woj">「我所做的，你如今不知道，後來必明白。」</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 36:25; 使徒行傳 22:16; 提多書 3:5"> 彼得說：「你永不可洗我的腳！」耶穌說：<span className="woj">「我若不洗你，你就與我無份了。」</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 51:7; 詩篇 51:2; 彼得前書 3:21"> 西門彼得說：「主啊，不但我的腳，連手和頭也要洗！」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 15:3; 哥林多後書 7:1; 哥林多後書 5:17"> 耶穌說：<span className="woj">「凡洗過澡的人，只要把腳一洗，全身就乾淨了。你們是乾淨的，然而不都是乾淨的。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 13:26; 約翰福音 13:2; 約翰福音 13:21"> 耶穌原知道要賣他的是誰，所以說<span className="woj">「你們不都是乾淨的」</span>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 13:7; 約翰福音 13:4; 以西結書 24:24"> 耶穌洗完了他們的腳，就穿上衣服，又坐下，對他們說：<span className="woj">「我向你們所做的，你們明白嗎？</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:46; 哥林多前書 12:3; 約翰福音 11:28"> <span className="woj">你們稱呼我夫子，稱呼我主，你們說的不錯，我本來是。</span></span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 5:5; 使徒行傳 20:35; 羅馬書 12:16"> <span className="woj">我是你們的主、你們的夫子，尚且洗你們的腳，你們也當彼此洗腳。</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 2:6; 馬太福音 11:29; 彼得前書 3:17–18"> <span className="woj">我給你們做了榜樣，叫你們照著我向你們所做的去做。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:40; 約翰福音 15:20; 馬太福音 10:24–25"> <span className="woj">我實實在在地告訴你們：僕人不能大於主人，差人也不能大於差他的人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 11:28; 雅各書 4:17; 雅各書 1:25"> <span className="woj">你們既知道這事，若是去行就有福了。</span></span>
</div>
</div>

## 耶穌預指賣他的人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; 馬太福音 26:23; 約翰福音 17:12"> <span className="woj">「我這話不是指著你們眾人說的，我知道我所揀選的是誰。現在要應驗經上的話說：『同我吃飯的人用腳踢我。』</span></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 43:10; 約翰福音 14:29; 約翰福音 16:4"> <span className="woj">如今事情還沒有成就，我要先告訴你們，叫你們到事情成就的時候，可以信我是基督。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:16; 路加福音 9:48; 馬太福音 25:40"> <span className="woj">我實實在在地告訴你們：有人接待我所差遣的，就是接待我；接待我，就是接待那差遣我的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 13:18; 馬太福音 26:21; 馬可福音 14:18"> 耶穌說了這話，心裡憂愁，就明說：<span className="woj">「我實實在在地告訴你們：你們中間有一個人要賣我了。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 22:23; 馬太福音 26:22; 馬可福音 14:19"> 門徒彼此對看，猜不透所說的是誰。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 19:26; 約翰福音 21:7; 約翰福音 21:20"> 有一個門徒，是耶穌所愛的，側身挨近耶穌的懷裡。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 12:17; 路加福音 1:22; 使徒行傳 13:16"> 西門彼得點頭對他說：「你告訴我們主是指著誰說的。」</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 21:20; 創世記 44:4–12; 以斯帖記 7:5"> 那門徒便就勢靠著耶穌的胸膛，問他說：「主啊，是誰呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 26:23; 約翰福音 13:30; 馬可福音 14:19–20"> 耶穌回答說：<span className="woj">「我蘸一點餅給誰，就是誰。」</span>耶穌就蘸了一點餅，遞給加略人西門的兒子猶大。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:3; 約翰福音 13:2; 傳道書 9:3"> 他吃了以後，撒旦就入了他的心。耶穌便對他說：<span className="woj">「你所做的，快做吧！」</span></span>
<span className="v" id="v28" data-v="28"> 同席的人沒有一個知道為什麼對他說這話。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 12:5–6; 約翰福音 13:1; 以弗所書 4:28"> 有人因猶大帶著錢囊，以為耶穌是對他說「你去買我們過節所應用的東西」，或是叫他拿什麼賙濟窮人。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 59:7; 約伯記 24:13–15; 箴言 4:16"> 猶大受了那點餅，立刻就出去。那時候是夜間了。</span>
</div>
</div>

## 主賜一條新命令

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 14:13; 彼得前書 4:11; 約翰福音 7:39"> 他既出去，耶穌就說：<span className="woj">「如今人子得了榮耀，神在人子身上也得了榮耀。</span></span>
<span className="v" id="v32" data-v="32" data-xref="啟示錄 22:1; 以賽亞書 53:10–12; 約翰福音 17:4–6"> <span className="woj">神要因自己榮耀人子，並且要快快地榮耀他。</span></span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 7:33–34; 約翰福音 8:21–24; 約翰福音 16:16–22"> <span className="woj">小子們，我還有不多的時候與你們同在，後來你們要找我，但我所去的地方你們不能到。這話我曾對猶太人說過，如今也照樣對你們說。</span></span>
<span className="v" id="v34" data-v="34" data-xref="以弗所書 5:2; 利未記 19:18; 約翰福音 15:17"> <span className="woj">我賜給你們一條新命令，乃是叫你們彼此相愛，我怎樣愛你們，你們也要怎樣相愛。</span></span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 4:20–21; 約翰一書 3:10–14; 約翰一書 2:10"> <span className="woj">你們若有彼此相愛的心，眾人因此就認出你們是我的門徒了。」</span></span>
</div>
</div>

## 預言彼得不認主

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="彼得後書 1:14; 約翰福音 13:33; 約翰福音 21:21–22"> 西門彼得問耶穌說：「主往哪裡去？」耶穌回答說：<span className="woj">「我所去的地方，你現在不能跟我去，後來卻要跟我去。」</span></span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 21:13; 使徒行傳 20:24; 馬可福音 14:27–31"> 彼得說：「主啊，我為什麼現在不能跟你去？我願意為你捨命！」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:34; 馬太福音 26:34; 馬可福音 14:30"> 耶穌說：<span className="woj">「你願意為我捨命嗎？我實實在在地告訴你：雞叫以先，你要三次不認我。」</span></span>
</div>

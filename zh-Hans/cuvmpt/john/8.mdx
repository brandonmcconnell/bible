## 拿淫婦來質難主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:1; 馬可福音 11:1; 路加福音 19:37"> 於是各人都回家去了。耶穌卻往橄欖山去。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 26:55; 路加福音 4:20; 路加福音 21:37"> 清早又回到殿裡，眾百姓都到他那裡去，他就坐下教訓他們。</span>
<span className="v" id="v3" data-v="3"> 文士和法利賽人帶著一個行淫時被拿的婦人來，叫她站在當中，</span>
<span className="v" id="v4" data-v="4"> 就對耶穌說：「夫子，這婦人是正行淫之時被拿的。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 20:10; 申命記 22:21–24; 以西結書 16:38–40"> 摩西在律法上吩咐我們把這樣的婦人用石頭打死，你說該把她怎麼樣呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 17:13; 路加福音 10:25; 傳道書 3:7"> 他們說這話乃試探耶穌，要得著告他的把柄。耶穌卻彎著腰，用指頭在地上畫字。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:1–5; 羅馬書 2:21–25; 羅馬書 2:1–3"> 他們還是不住地問他，耶穌就直起腰來，對他們說：<span className="woj">「你們中間誰是沒有罪的，誰就可以先拿石頭打她。」</span></span>
<span className="v" id="v8" data-v="8"> 於是又彎著腰，用指頭在地上畫字。</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 7:22; 羅馬書 2:15; 約翰一書 3:20"> 他們聽見這話，就從老到少，一個一個地都出去了，只剩下耶穌一人，還有那婦人仍然站在當中。</span>
</div>
</div>

## 不要再犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 41:11–12"> 耶穌就直起腰來，對她說：<span className="woj">「婦人，那些人在哪裡呢？沒有人定你的罪嗎？」</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 3:17; 約翰福音 5:14; 以賽亞書 1:16–18"> 她說：「主啊，沒有。」耶穌說：<span className="woj">「我也不定你的罪。去吧，從此不要再犯罪了！」</span></span>
</div>
</div>

## 主是世界的光

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 12:46; 約翰福音 9:5; 約翰福音 12:35"> 耶穌又對眾人說：<span className="woj">「我是世界的光。跟從我的，就不在黑暗裡走，必要得著生命的光。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 5:31–47"> 法利賽人對他說：「你是為自己作見證，你的見證不真。」</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 16:28; 約翰福音 13:3; 約翰福音 8:42"> 耶穌說：<span className="woj">「我雖然為自己作見證，我的見證還是真的；因我知道我從哪裡來，往哪裡去。你們卻不知道我從哪裡來，往哪裡去。</span></span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:7; 約翰福音 7:24; 約翰福音 12:47"> <span className="woj">你們是以外貌</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：憑肉身。">a</a></sup><span className="woj">判斷人，我卻不判斷人。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:31; 約翰福音 8:29; 約翰福音 16:32"> <span className="woj">就是判斷人，我的判斷也是真的，因為不是我獨自在這裡，還有差我來的父與我同在。</span></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 19:15; 申命記 17:6; 希伯來書 10:28"> <span className="woj">你們的律法上也記著說：『兩個人的見證是真的。』</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 8:38; 約翰福音 8:58; 約翰福音 8:25"> <span className="woj">我是為自己作見證，還有差我來的父也是為我作見證。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:3; 約翰福音 8:54–55; 約翰福音 14:6–9"> 他們就問他說：「你的父在哪裡？」耶穌回答說：<span className="woj">「你們不認識我，也不認識我的父；若是認識我，也就認識我的父。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:30; 約翰福音 7:8; 馬可福音 12:41"> 這些話是耶穌在殿裡的庫房教訓人時所說的，也沒有人拿他，因為他的時候還沒有到。</span>
</div>
</div>

## 不信主的必死在罪裡

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 7:34; 約翰福音 8:24; 哥林多前書 15:17–18"> 耶穌又對他們說：<span className="woj">「我要去了，你們要找我，並且你們要死在罪中。我所去的地方你們不能到。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 8:52; 詩篇 22:6; 約翰福音 8:48"> 猶太人說：「他說<span className="woj">『我所去的地方你們不能到』</span>，難道他要自盡嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 3:31; 約翰福音 17:14; 約翰福音 17:16"> 耶穌對他們說：<span className="woj">「你們是從下頭來的，我是從上頭來的；你們是屬這世界的，我不是屬這世界的。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 3:36; 馬可福音 16:16; 約翰福音 3:18"> <span className="woj">所以我對你們說，你們要死在罪中；你們若不信我是基督，必要死在罪中。」</span></span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 5:17–29; 路加福音 22:67; 約翰福音 1:22"> 他們就問他說：「你是誰？」耶穌對他們說：<span className="woj">「就是我從起初所告訴你們的。</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:15; 約翰福音 12:47–50; 約翰福音 8:40"> <span className="woj">我有許多事講論你們，判斷你們；但那差我來的是真的，我在他那裡所聽見的，我就傳給世人。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 6:9; 約翰福音 8:43; 哥林多後書 4:3–4"> 他們不明白耶穌是指著父說的。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 5:19; 約翰福音 5:30; 約翰福音 6:38"> 所以耶穌說：<span className="woj">「你們舉起人子以後，必知道我是基督，並且知道我沒有一件事是憑著自己做的。我說這些話乃是照著父所教訓我的。</span></span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 6:38; 約翰福音 16:32; 約翰福音 4:34"> <span className="woj">那差我來的是與我同在，他沒有撇下我獨自在這裡，因為我常做他所喜悅的事。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 7:31; 約翰福音 2:23; 約翰福音 11:45"> 耶穌說這話的時候，就有許多人信他。</span>
</div>
</div>

## 真理叫人得以自由

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰二書 1:9; 約翰福音 15:4–9; 提摩太後書 3:14"> 耶穌對信他的猶太人說：<span className="woj">「你們若常常遵守我的道，就真是我的門徒，</span></span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 8:2; 約翰福音 8:36; 約翰福音 17:17"> <span className="woj">你們必曉得真理，真理必叫你們得以自由。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 3:9; 約翰福音 8:39; 創世記 15:13"> 他們回答說：「我們是亞伯拉罕的後裔，從來沒有做過誰的奴僕，你怎麼說『你們必得以自由』呢？」</span>
<span className="v" id="v34" data-v="34" data-xref="羅馬書 6:16; 彼得後書 2:19; 箴言 5:22"> 耶穌回答說：<span className="woj">「我實實在在地告訴你們：所有犯罪的就是罪的奴僕。</span></span>
<span className="v" id="v35" data-v="35" data-xref="加拉太書 4:4–7; 路加福音 15:31; 羅馬書 8:15–17"> <span className="woj">奴僕不能永遠住在家裡，兒子是永遠住在家裡。</span></span>
<span className="v" id="v36" data-v="36" data-xref="哥林多後書 3:17; 加拉太書 5:1; 羅馬書 8:2"> <span className="woj">所以天父的兒子若叫你們自由，你們就真自由了。</span></span>
</div>
</div>

## 誰為亞伯拉罕的真子孫

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 2:14; 約翰福音 8:45–47; 約翰福音 7:1"> <span className="woj">「我知道你們是亞伯拉罕的子孫，你們卻想要殺我，因為你們心裡容不下我的道。</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 5:19; 約翰福音 8:44; 約翰福音 8:41"> <span className="woj">我所說的，是在我父那裡看見的；你們所行的，是在你們的父那裡聽見的。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="加拉太書 3:7; 約翰福音 8:37; 羅馬書 9:7"> 他們說：「我們的父就是亞伯拉罕！」耶穌說：<span className="woj">「你們若是亞伯拉罕的兒子，就必行亞伯拉罕所行的事。</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 8:26; 加拉太書 4:29; 加拉太書 4:16"> <span className="woj">我將在神那裡所聽見的真理告訴了你們，現在你們卻想要殺我，這不是亞伯拉罕所行的事。</span></span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 64:8; 約翰福音 8:38; 以賽亞書 63:16"> <span className="woj">你們是行你們父所行的事。」</span>他們說：「我們不是從淫亂生的。我們只有一位父，就是神！」</span>
</div>
</div>

## 出於神的必聽神的話

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:49; 約翰福音 14:10; 約翰福音 17:8"> 耶穌說：<span className="woj">「倘若神是你們的父，你們就必愛我。因為我本是出於神，也是從神而來；並不是由著自己來，乃是他差我來。</span></span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 12:39–40; 羅馬書 8:7–8; 約翰福音 7:17"> <span className="woj">你們為什麼不明白我的話呢？無非是因你們不能聽我的道。</span></span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 13:10; 約翰一書 3:12; 約翰一書 3:8–10"> <span className="woj">你們是出於你們的父魔鬼，你們父的私慾你們偏要行。他從起初是殺人的，不守真理，因他心裡沒有真理。他說謊是出於自己，因他本來是說謊的，也是說謊之人的父。</span></span>
<span className="v" id="v45" data-v="45" data-xref="提摩太後書 4:3–4; 加拉太書 4:16; 約翰福音 18:37"> <span className="woj">我將真理告訴你們，你們就因此不信我。</span></span>
<span className="v" id="v46" data-v="46" data-xref="希伯來書 4:15; 約翰福音 16:8; 彼得前書 2:22"> <span className="woj">你們中間誰能指證我有罪呢？我既然將真理告訴你們，為什麼不信我呢？</span></span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 10:26–27; 約翰二書 1:9; 約翰福音 18:37"> <span className="woj">出於神的必聽神的話，你們不聽，因為你們不是出於神。」</span></span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 7:20; 約翰福音 8:52; 馬太福音 10:5"> 猶太人回答說：「我們說你是撒馬利亞人，並且是鬼附著的，這話豈不正對嗎？」</span>
<span className="v" id="v49" data-v="49" data-xref="彼得前書 2:23; 以賽亞書 49:3; 約翰福音 13:31–32"> 耶穌說：<span className="woj">「我不是鬼附著的。我尊敬我的父，你們倒輕慢我。</span></span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 5:41; 約翰福音 8:54; 約翰福音 7:18"> <span className="woj">我不求自己的榮耀，有一位為我求榮耀、定是非的。</span></span>
<span className="v" id="v51" data-v="51" data-xref="約翰福音 11:25–26; 約翰福音 5:24; 約翰福音 3:15–16"> <span className="woj">我實實在在地告訴你們：人若遵守我的道，就永遠不見死。」</span></span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 9:24; 約翰福音 8:48; 希伯來書 2:9"> 猶太人對他說：「現在我們知道你是鬼附著的。亞伯拉罕死了，眾先知也死了，你還說『人若遵守我的道，就永遠不嘗死味』。</span>
<span className="v" id="v53" data-v="53" data-xref="約翰福音 4:12; 羅馬書 9:5; 希伯來書 7:1–7"> 難道你比我們的祖宗亞伯拉罕還大嗎？他死了，眾先知也死了。你將自己當做什麼人呢？」</span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 8:50; 箴言 25:27; 彼得後書 1:17"> 耶穌回答說：<span className="woj">「我若榮耀自己，我的榮耀就算不得什麼。榮耀我的乃是我的父，就是你們所說是你們的神。</span></span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 8:19; 約翰福音 8:44; 約翰福音 7:28–29"> <span className="woj">你們未曾認識他，我卻認識他。我若說不認識他，我就是說謊的，像你們一樣。但我認識他，也遵守他的道。</span></span>
</div>
</div>

## 耶穌言己在亞伯拉罕之先

<div className="bt">
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="希伯來書 11:13; 創世記 22:18; 加拉太書 3:7–9"> <span className="woj">「你們的祖宗亞伯拉罕歡歡喜喜地仰望我的日子，既看見了，就快樂。」</span></span>

## 戲弄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 53:5; 以賽亞書 50:6; 馬太福音 20:19"> 當下彼拉多將耶穌鞭打了。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 15:16–20; 路加福音 23:11; 馬太福音 27:27–31"> 兵丁用荊棘編做冠冕，戴在他頭上，給他穿上紫袍，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 27:29; 馬太福音 26:49; 路加福音 1:28"> 又挨近他，說：「恭喜，猶太人的王啊！」他們就用手掌打他。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:38; 約翰福音 19:6; 路加福音 23:4"> 彼拉多又出來對眾人說：「我帶他出來見你們，叫你們知道我查不出他有什麼罪來。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:2; 希伯來書 12:2; 以賽亞書 7:14"> 耶穌出來，戴著荊棘冠冕，穿著紫袍。彼拉多對他們說：「你們看，這個人！」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:31; 約翰福音 19:4; 使徒行傳 2:23"> 祭司長和差役看見他，就喊著說：「釘他十字架！釘他十字架！」彼拉多說：「你們自己把他釘十字架吧，我查不出他有什麼罪來。」</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 24:16; 約翰福音 5:18; 馬太福音 26:63–66"> 猶太人回答說：「我們有律法，按那律法，他是該死的！因他以自己為神的兒子。」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 19:13; 使徒行傳 14:11–19"> 彼拉多聽見這話，越發害怕，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 18:33; 詩篇 38:13–15; 腓立比書 1:28"> 又進衙門，對耶穌說：「你是哪裡來的？」耶穌卻不回答。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 5:19; 約翰福音 18:39; 但以理書 3:14–15"> 彼拉多說：「你不對我說話嗎？你豈不知我有權柄釋放你，也有權柄把你釘十字架嗎？」</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 13:1; 約翰福音 3:27; 使徒行傳 2:23"> 耶穌回答說：<span className="woj">「若不是從上頭賜給你的，你就毫無權柄辦我。所以，把我交給你的那人罪更重了。」</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 17:6–7; 約翰福音 18:33–36; 馬可福音 6:16–26"> 從此彼拉多想要釋放耶穌，無奈猶太人喊著說：「你若釋放這個人，就不是凱撒的忠臣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：朋友。">a</a></sup>。凡以自己為王的，就是背叛凱撒了。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:5–7; 馬太福音 27:19; 阿摩司書 4:7"> 彼拉多聽見這話，就帶耶穌出來，到了一個地方，名叫鋪華石處，希伯來話叫厄巴大，就在那裡坐堂。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 27:62; 約翰福音 19:5; 馬可福音 15:25"> 那日是預備逾越節的日子，約有午正。彼拉多對猶太人說：「看哪，這是你們的王！」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 23:18; 使徒行傳 21:36; 約翰福音 19:6"> 他們喊著說：「除掉他！除掉他！釘他在十字架上！」彼拉多說：「我可以把你們的王釘十字架嗎？」祭司長回答說：「除了凱撒，我們沒有王！」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:24–25; 馬太福音 27:26–31; 馬可福音 15:15–20"> 於是，彼拉多將耶穌交給他們去釘十字架。</span>
</div>
</div>

## 耶穌被釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:33; 路加福音 14:27; 路加福音 23:26"> 他們就把耶穌帶了去。耶穌背著自己的十字架出來，到了一個地方，名叫髑髏地，希伯來話叫各各他。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:12; 馬可福音 15:24–27; 加拉太書 3:13"> 他們就在那裡釘他在十字架上，還有兩個人和他一同釘著，一邊一個，耶穌在中間。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 27:37; 路加福音 23:38; 馬可福音 15:26"> 彼拉多又用牌子寫了一個名號，安在十字架上，寫的是：「猶太人的王，拿撒勒人耶穌。」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 26:14; 啟示錄 16:16; 使徒行傳 22:2"> 有許多猶太人念這名號，因為耶穌被釘十字架的地方與城相近，並且是用希伯來、羅馬、希臘三樣文字寫的。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 19:14; 約翰福音 19:19"> 猶太人的祭司長就對彼拉多說：「不要寫『猶太人的王』，要寫『他自己說我是猶太人的王』。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 76:10; 詩篇 65:7; 箴言 8:29"> 彼拉多說：「我所寫的，我已經寫上了。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="路加福音 23:34; 馬可福音 15:24; 馬太福音 27:35"> 兵丁既然將耶穌釘在十字架上，就拿他的衣服分為四份，每兵一份。又拿他的裡衣，這件裡衣原來沒有縫兒，是上下一片織成的。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 22:18; 約翰福音 19:28; 約翰福音 19:36–37"> 他們就彼此說：「我們不要撕開，只要拈鬮，看誰得著。」這要應驗經上的話說：<br /><span className="pl pl-1">「他們分了我的外衣，</span><br /><span className="pl pl-1">為我的裡衣拈鬮。」</span><br />兵丁果然做了這事。</span>
</div>
</div>

## 將母親託付約翰

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 23:49; 馬太福音 27:55–56; 約翰福音 20:1"> 站在耶穌十字架旁邊的，有他母親與他母親的姐妹，並革羅罷的妻子馬利亞和抹大拉的馬利亞。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 21:24; 約翰福音 20:2; 約翰福音 2:4"> 耶穌見母親和他所愛的那門徒站在旁邊，就對他母親說：<span className="woj">「母親</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：婦人。">b</a></sup><span className="woj">，看，你的兒子！」</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 12:48–50; 約翰福音 16:32; 提摩太前書 5:2–4"> 又對那門徒說：<span className="woj">「看，你的母親！」</span>從此，那門徒就接她到自己家裡去了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="詩篇 69:21; 詩篇 22:15; 約翰福音 19:30"> 這事以後，耶穌知道各樣的事已經成了，為要使經上的話應驗，就說：<span className="woj">「我渴了。」</span></span>
<span className="v" id="v29" data-v="29" data-xref="民數記 19:18; 路加福音 23:36; 馬可福音 15:36"> 有一個器皿盛滿了醋，放在那裡。他們就拿海絨蘸滿了醋，綁在牛膝草上，送到他口。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 17:4; 腓立比書 2:8; 歌羅西書 2:14–17"> 耶穌嘗<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：受。">c</a></sup>了那醋，就說：<span className="woj">「成了！」</span>便低下頭，將靈魂交付神了。</span>
</div>
</div>

## 主的骨頭一根也不折斷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 19:14; 約翰福音 19:42; 馬可福音 15:42"> 猶太人因這日是預備日，又因那安息日是個大日，就求彼拉多叫人打斷他們的腿，把他們拿去，免得屍首當安息日留在十字架上。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 19:18; 路加福音 23:39–43"> 於是兵丁來，把頭一個人的腿，並與耶穌同釘第二個人的腿，都打斷了。</span>
<span className="v" id="v33" data-v="33"> 只是來到耶穌那裡，見他已經死了，就不打斷他的腿。</span>
<span className="v" id="v34" data-v="34" data-xref="約翰一書 5:6; 撒迦利亞書 12:10; 撒迦利亞書 13:1"> 唯有一個兵拿槍扎他的肋旁，隨即有血和水流出來。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 21:24; 希伯來書 2:3–4; 約翰一書 1:1–3"> 看見這事的那人就作見證，他的見證也是真的，並且他知道自己所說的是真的，叫你們也可以信。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 34:20; 民數記 9:12; 出埃及記 12:46"> 這些事成了，為要應驗經上的話說：「他的骨頭一根也不可折斷。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒迦利亞書 12:10; 啟示錄 1:7; 詩篇 22:16–17"> 經上又有一句說：「他們要仰望自己所扎的人。」</span>
</div>
</div>

## 安放在新墳墓裡

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬可福音 15:42–47; 馬太福音 27:57–61; 箴言 29:25"> 這些事以後，有亞利馬太人約瑟，是耶穌的門徒，只因怕猶太人，就暗暗地做門徒，他來求彼拉多，要把耶穌的身體領去。彼拉多允准，他就把耶穌的身體領去了。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 7:50–52; 雅歌 4:14; 約翰福音 3:1–21"> 又有尼哥迪慕，就是先前夜裡去見耶穌的，帶著沒藥和沉香約有一百斤前來。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 11:44; 約翰福音 20:5–7; 使徒行傳 5:6"> 他們就照猶太人殯葬的規矩，把耶穌的身體用細麻布加上香料裹好了。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:53; 馬太福音 27:60; 約翰福音 20:15"> 在耶穌釘十字架的地方有一個園子，園子裡有一座新墳墓，是從來沒有葬過人的。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 19:31; 約翰福音 19:14; 以賽亞書 53:9"> 只因是猶太人的預備日，又因那墳墓近，他們就把耶穌安放在那裡。</span>
</div>

## 施洗約翰傳道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 5:11–12; 馬太福音 4:3; 馬太福音 3:17"> 神的兒子，耶穌基督福音的起頭。</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 3:1; 馬太福音 11:10; 路加福音 1:76"> 正如先知以賽亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無「以賽亞」三字。">a</a></sup>書上記著說：<br /><span className="pl pl-1">「看哪！我要差遣我的使者在你前面，</span><br /><span className="pl pl-1">預備道路。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 40:3–5; 馬太福音 3:3; 路加福音 3:4–6"> <span className="pl pl-1">在曠野有人聲喊著說：</span><br /><span className="pl pl-1">『預備主的道，</span><br /><span className="pl pl-1">修直他的路！』」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 19:3–4; 馬太福音 3:6; 使徒行傳 13:24–25"> 照這話，約翰來了，在曠野施洗，傳悔改的洗禮，使罪得赦。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 26:40–42; 使徒行傳 19:18; 馬太福音 3:5–6"> 猶太全地和耶路撒冷的人都出去到約翰那裡，承認他們的罪，在約旦河裡受他的洗。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 1:8; 利未記 11:22; 馬太福音 3:4"> 約翰穿駱駝毛的衣服，腰束皮帶，吃的是蝗蟲、野蜜。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 13:25; 路加福音 3:16; 約翰福音 1:27"> 他傳道說：「有一位在我以後來的，能力比我更大，我就是彎腰給他解鞋帶也是不配的。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:5; 哥林多前書 12:13; 使徒行傳 19:4–6"> 我是用水給你們施洗，他卻要用聖靈給你們施洗。」</span>
</div>
</div>

## 耶穌受洗

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 3:13–17; 馬太福音 2:23; 路加福音 3:21–22"> 那時，耶穌從加利利的拿撒勒來，在約旦河裡受了約翰的洗。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 1:31–34; 路加福音 3:22; 以賽亞書 42:1"> 他從水裡一上來，就看見天裂開了，聖靈彷彿鴿子降在他身上；</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 42:1; 馬可福音 9:7; 馬太福音 3:17"> 又有聲音從天上來說：「你是我的愛子，我喜悅你。」</span>
</div>
</div>

## 耶穌受試探

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 4:1–11; 路加福音 4:1–13"> 聖靈就把耶穌催到曠野裡去。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 2:17–18; 希伯來書 4:15; 出埃及記 34:28"> 他在曠野四十天，受撒旦的試探，並與野獸同在一處，且有天使來伺候他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 4:23; 馬太福音 4:12; 路加福音 8:1"> 約翰下監以後，耶穌來到加利利，宣傳神的福音，</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 3:2; 使徒行傳 2:36–38; 馬太福音 4:17"> 說：<span className="woj">「日期滿了，神的國近了！你們當悔改，信福音！」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 4:18–22; 約翰福音 1:40–42; 約翰福音 6:8"> 耶穌順著加利利的海邊走，看見西門和西門的兄弟安得烈在海裡撒網，他們本是打魚的。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 5:10; 馬太福音 4:19–20; 使徒行傳 2:38–41"> 耶穌對他們說：<span className="woj">「來跟從我，我要叫你們得人如得魚一樣。」</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:28–30; 路加福音 5:11; 馬可福音 10:28–31"> 他們就立刻捨了網，跟從了他。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 5:37; 使徒行傳 1:13; 馬可福音 10:35"> 耶穌稍往前走，又見西庇太的兒子雅各和雅各的兄弟約翰在船上補網，</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 10:37; 路加福音 14:26; 馬可福音 10:29"> 耶穌隨即招呼他們。他們就把父親西庇太和雇工人留在船上，跟從耶穌去了。</span>
</div>
</div>

## 在迦百農趕逐汙鬼

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:2; 馬可福音 1:39; 馬太福音 4:23"> 到了迦百農，耶穌就在安息日進了會堂教訓人。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:28–29; 馬太福音 13:54; 路加福音 4:32"> 眾人很稀奇他的教訓，因為他教訓他們正像有權柄的人，不像文士。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 9:25; 馬可福音 7:25; 馬可福音 1:34"> 在會堂裡有一個人被汙鬼附著，他喊叫說：</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 8:29; 雅各書 2:19; 使徒行傳 3:14"> 「拿撒勒人耶穌，我們與你有什麼相干？你來滅我們嗎？我知道你是誰，乃是神的聖者！」</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 1:34; 路加福音 4:41; 使徒行傳 16:17"> 耶穌責備他說：<span className="woj">「不要作聲！從這人身上出來吧！」</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 9:26; 馬可福音 9:20; 路加福音 11:22"> 汙鬼叫那人抽了一陣風，大聲喊叫，就出來了。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:31; 馬可福音 7:37; 路加福音 9:1"> 眾人都驚訝，以致彼此對問說：「這是什麼事？是個新道理啊！他用權柄吩咐汙鬼，連汙鬼也聽從了他。」</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 9:31; 路加福音 4:37; 馬可福音 1:45"> 耶穌的名聲就傳遍了加利利的四方。</span>
</div>
</div>

## 醫西門岳母

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 4:38–39; 馬太福音 8:14–15; 馬可福音 1:21"> 他們一出會堂，就同著雅各、約翰進了西門和安得烈的家。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 9:5; 馬可福音 5:23; 約翰福音 11:3"> 西門的岳母正害熱病躺著，就有人告訴耶穌。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:41; 詩篇 116:12; 馬可福音 5:41"> 耶穌進前拉著她的手，扶她起來，熱就退了，她就服侍他們。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 8:16; 馬可福音 3:2; 路加福音 4:40"> 天晚日落的時候，有人帶著一切害病的和被鬼附的來到耶穌跟前。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 1:5; 使徒行傳 13:44"> 合城的人都聚集在門前。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 4:41; 馬可福音 3:12; 馬太福音 4:23"> 耶穌治好了許多害各樣病的人，又趕出許多鬼，不許鬼說話，因為鬼認識他。</span>
</div>
</div>

## 到曠野禱告

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 6:12; 路加福音 5:16; 路加福音 22:39–46"> 次日早晨，天未亮的時候，耶穌起來到曠野地方去，在那裡禱告。</span>
<span className="v" id="v36" data-v="36"> 西門和同伴追了他去，</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 12:19; 馬可福音 1:5; 撒迦利亞書 11:11"> 遇見了就對他說：「眾人都找你。」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:43; 約翰福音 17:8; 以賽亞書 61:1–3"> 耶穌對他們說：<span className="woj">「我們可以往別處去，到鄰近的鄉村，我也好在那裡傳道，因為我是為這事出來的。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 4:23; 馬可福音 1:21; 路加福音 4:43–44"> 於是在加利利全地，進了會堂，傳道、趕鬼。</span>
</div>
</div>

## 潔淨長大痲瘋的

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 5:12–14; 馬太福音 8:2–4; 利未記 13:1–14"> 有一個長大痲瘋的來求耶穌，向他跪下，說：「你若肯，必能叫我潔淨了。」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 9:36; 希伯來書 2:17; 希伯來書 4:15"> 耶穌動了慈心，就伸手摸他，說：<span className="woj">「我肯，你潔淨了吧！」</span></span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 15:3; 馬可福音 5:29; 約翰福音 4:50–53"> 大痲瘋即時離開他，他就潔淨了。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 9:30; 馬可福音 7:36; 路加福音 8:56"> 耶穌嚴嚴地囑咐他，就打發他走，</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 14:1–32; 路加福音 17:14; 馬太福音 8:4"> 對他說：<span className="woj">「你要謹慎，什麼話都不可告訴人，只要去把身體給祭司察看，又因為你潔淨了，獻上摩西所吩咐的禮物，對眾人做證據。」</span></span>
<span className="v" id="v45" data-v="45" data-xref="馬可福音 2:13; 馬太福音 9:31; 約翰福音 6:2"> 那人出去，倒說許多的話，把這件事傳揚開了，叫耶穌以後不得再明明地進城，只好在外邊曠野地方。人從各處都就了他來。</span>
</div>
</div>

## 辯論休妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 10:40; 馬可福音 4:2; 約翰福音 11:7"> 耶穌從那裡起身，來到猶太的境界並約旦河外。眾人又聚集到他那裡，他又照常教訓他們。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 7:10–11; 路加福音 11:53–54; 約翰福音 8:6"> 有法利賽人來問他說：「人休妻可以不可以？」意思要試探他。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 8:20; 加拉太書 4:21; 路加福音 10:25"> 耶穌回答說：<span className="woj">「摩西吩咐你們的是什麼？」</span></span>
<span className="v" id="v4" data-v="4" data-xref="申命記 24:1–4; 馬太福音 5:31–32; 以賽亞書 50:1"> 他們說：「摩西許人寫了休書便可以休妻。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 19:8; 尼希米記 9:26; 使徒行傳 7:51"> 耶穌說：<span className="woj">「摩西因為你們的心硬，所以寫這條例給你們。</span></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 1:27; 創世記 5:2; 創世記 1:1"> <span className="woj">但從起初創造的時候，神造人是『造男造女』，</span></span>
<span className="v" id="v7" data-v="7" data-xref="創世記 2:24; 馬太福音 19:5–6; 以弗所書 5:31"> <span className="woj">『因此，人要離開父母，與妻子聯合，二人成為一體。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:28; 創世記 2:24; 哥林多前書 6:16"> <span className="woj">既然如此，夫妻不再是兩個人，乃是一體的了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 7:1–3; 歷代志上 7:10–13"> <span className="woj">所以，神配合的，人不可分開。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 9:33; 馬可福音 9:28; 馬可福音 4:10"> 到了屋裡，門徒就問他這事。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:31–32; 馬太福音 19:9; 哥林多前書 7:10–11"> 耶穌對他們說：<span className="woj">「凡休妻另娶的，就是犯姦淫，辜負他的妻子；</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 7:11; 哥林多前書 7:13"> <span className="woj">妻子若離棄丈夫另嫁，也是犯姦淫了。」</span></span>
</div>
</div>

## 耶穌為小孩祝福

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 19:13–15; 路加福音 18:15–17; 出埃及記 10:9–11"> 有人帶著小孩子來見耶穌，要耶穌摸他們，門徒便責備那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 19:14; 馬太福音 18:10; 馬太福音 18:4"> 耶穌看見就惱怒，對門徒說：<span className="woj">「讓小孩子到我這裡來，不要禁止他們，因為在神國的正是這樣的人。</span></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:3; 路加福音 18:17; 約翰福音 3:3–6"> <span className="woj">我實在告訴你們：凡要承受神國的，若不像小孩子，斷不能進去。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 9:36; 以賽亞書 40:11; 約翰福音 21:15–17"> 於是抱著小孩子，給他們按手，為他們祝福。</span>
</div>
</div>

## 當積財寶在天上

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 19:16–30; 路加福音 18:18–30; 羅馬書 2:7"> 耶穌出來行路的時候，有一個人跑來跪在他面前，問他說：「良善的夫子，我當做什麼事才可以承受永生？」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:19; 馬太福音 19:17; 羅馬書 3:12"> 耶穌對他說：<span className="woj">「你為什麼稱我是良善的？除了神一位之外，再沒有良善的。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:12–17; 羅馬書 13:9; 雅各書 2:11"> <span className="woj">誡命你是曉得的：不可殺人，不可姦淫，不可偷盜，不可作假見證，不可虧負人，當孝敬父母。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 33:31–32; 提摩太後書 3:5; 腓立比書 3:6"> 他對耶穌說：「夫子，這一切我從小都遵守了。」</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:19–21; 啟示錄 2:4; 路加福音 18:22"> 耶穌看著他，就愛他，對他說：<span className="woj">「你還缺少一件：去變賣你所有的，分給窮人，就必有財寶在天上；你還要來跟從我。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰一書 2:15–16; 提摩太前書 6:9–10; 路加福音 12:15"> 他聽見這話，臉上就變了色，憂憂愁愁地走了，因為他的產業很多。</span>
</div>
</div>

## 靠錢財的難進天國

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 1:26; 路加福音 18:24; 馬可福音 3:5"> 耶穌周圍一看，對門徒說：<span className="woj">「有錢財的人進神的國是何等地難哪！」</span></span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 5:1–3; 箴言 11:28; 詩篇 52:7"> 門徒稀奇他的話。耶穌又對他們說：<span className="woj">「小子，倚靠錢財的人進神的國是何等地難哪！</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 19:24–25; 路加福音 18:25; 馬太福音 23:24"> <span className="woj">駱駝穿過針的眼，比財主進神的國還容易呢！」</span></span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 16:31; 哥林多後書 11:23; 羅馬書 10:9–13"> 門徒就分外稀奇，對他說：「這樣誰能得救呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:26; 耶利米書 32:27; 約伯記 42:2"> 耶穌看著他們說：<span className="woj">「在人是不能，在神卻不然，因為神凡事都能。」</span></span>
</div>
</div>

## 跟從主的賞賜

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 19:27–30; 路加福音 18:28–30; 路加福音 14:33"> 彼得就對他說：「看哪，我們已經撇下所有的跟從你了！」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 9:23; 馬太福音 5:10–11; 馬可福音 8:35"> 耶穌說：<span className="woj">「我實在告訴你們：人為我和福音撇下房屋或是弟兄、姐妹、父母、兒女、田地，</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 18:30; 腓立比書 3:8; 哥林多後書 6:10"> <span className="woj">沒有不在今世得百倍的，就是房屋、弟兄、姐妹、母親、兒女、田地，並且要受逼迫；在來世必得永生。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 19:30; 路加福音 13:30; 馬太福音 20:16"> <span className="woj">然而，有許多在前的將要在後，在後的將要在前。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 20:17–19; 路加福音 18:31–34; 路加福音 9:51"> 他們行路上耶路撒冷去。耶穌在前頭走，門徒就稀奇，跟從的人也害怕。耶穌又叫過十二個門徒來，把自己將要遭遇的事告訴他們說：</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:2; 馬太福音 20:17–19; 馬可福音 8:31"> <span className="woj">「看哪，我們上耶路撒冷去，人子將要被交給祭司長和文士，他們要定他死罪，交給外邦人；</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 26:67; 馬太福音 16:21; 馬可福音 14:65"> <span className="woj">他們要戲弄他，吐唾沫在他臉上，鞭打他，殺害他；過了三天，他要復活。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:20–28; 撒母耳記下 14:4–11; 列王紀上 2:20"> 西庇太的兒子雅各、約翰進前來，對耶穌說：「夫子，我們無論求你什麼，願你給我們做。」</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 15:7; 列王紀上 3:5–15; 馬可福音 10:51"> 耶穌說：<span className="woj">「要我給你們做什麼？」</span></span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 19:28; 馬可福音 16:19; 路加福音 24:26"> 他們說：「賜我們在你的榮耀裡，一個坐在你右邊，一個坐在你左邊。」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:50; 馬太福音 20:21–22; 詩篇 75:8"> 耶穌說：<span className="woj">「你們不知道所求的是什麼。我所喝的杯，你們能喝嗎？我所受的洗，你們能受嗎？」</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 12:2; 啟示錄 1:9; 約翰福音 17:14"> 他們說：「我們能。」耶穌說：<span className="woj">「我所喝的杯，你們也要喝；我所受的洗，你們也要受；</span></span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 20:23; 馬太福音 25:34; 約翰福音 17:24"> <span className="woj">只是坐在我的左右，不是我可以賜的，乃是為誰預備的，就賜給誰。」</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 20:24; 箴言 13:10; 羅馬書 12:10"> 那十個門徒聽見，就惱怒雅各、約翰。</span>
</div>
</div>

## 誰願為首必做僕人

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="彼得前書 5:3; 路加福音 22:25; 馬太福音 20:25"> 耶穌叫他們來，對他們說：<span className="woj">「你們知道，外邦人有尊為君王的治理他們，有大臣操權管束他們。</span></span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 23:8–12; 路加福音 14:11; 馬可福音 9:35"> <span className="woj">只是在你們中間不是這樣，你們中間誰願為大，就必做你們的用人；</span></span>
<span className="v" id="v44" data-v="44"> <span className="woj">在你們中間誰願為首，就必做眾人的僕人。</span></span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 20:28; 腓立比書 2:5–8; 哥林多後書 8:9"> <span className="woj">因為人子來並不是要受人的服侍，乃是要服侍人，並且要捨命做多人的贖價。」</span></span>
</div>
</div>

## 瞎子巴底買得醫治

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 18:35–1; 馬太福音 20:29–34; 約翰福音 9:8"> 到了耶利哥，耶穌同門徒並許多人出耶利哥的時候，有一個討飯的瞎子，是底買的兒子巴底買，坐在路旁。</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 1:24; 馬太福音 9:27; 啟示錄 22:16"> 他聽見是拿撒勒的耶穌，就喊著說：「大衛的子孫耶穌啊，可憐我吧！」</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 29:13; 馬可福音 7:26–29; 希伯來書 5:7"> 有許多人責備他，不許他作聲，他卻越發大聲喊著說：「大衛的子孫哪，可憐我吧！」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 18:40; 馬太福音 20:32–34; 約翰福音 11:28"> 耶穌就站住說：<span className="woj">「叫過他來。」</span>他們就叫那瞎子，對他說：「放心，起來，他叫你啦！」</span>
<span className="v" id="v50" data-v="50" data-xref="腓立比書 3:7–9; 希伯來書 12:1"> 瞎子就丟下衣服，跳起來，走到耶穌那裡。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 18:41–43; 馬可福音 10:36; 馬太福音 7:7"> 耶穌說：<span className="woj">「要我為你做什麼？」</span>瞎子說：「拉波尼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拉波尼」就是「夫子」。">a</a></sup>，我要能看見！」</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 9:22; 使徒行傳 26:18; 馬可福音 8:25"> 耶穌說：<span className="woj">「你去吧！你的信救了你了。」</span>瞎子立刻看見了，就在路上跟隨耶穌。</span>

## 醫治癱子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 4:47; 路加福音 5:18; 路加福音 18:35–38"> 過了些日子，耶穌又進了迦百農。人聽見他在房子裡，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 2:13; 馬可福音 1:45; 詩篇 40:9"> 就有許多人聚集，甚至連門前都沒有空地。耶穌就對他們講道。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:18–26; 馬太福音 9:1–8; 馬太福音 4:24"> 有人帶著一個癱子來見耶穌，是用四個人抬來的。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 5:19; 申命記 22:8"> 因為人多，不得近前，就把耶穌所在的房子拆了房頂。既拆通了，就把癱子連所躺臥的褥子都縋下來。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 9:2; 雅各書 5:15; 馬可福音 2:9–10"> 耶穌見他們的信心，就對癱子說：<span className="woj">「小子，你的罪赦了！」</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:21–22; 馬可福音 8:17; 哥林多後書 10:5"> 有幾個文士坐在那裡，心裡議論說：</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 43:25; 路加福音 5:21; 彌迦書 7:18"> 「這個人為什麼這樣說呢？他說僭妄的話了！除了神以外，誰能赦罪呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 139:2; 使徒行傳 8:22; 路加福音 5:22"> 耶穌心中知道他們心裡這樣議論，就說：<span className="woj">「你們心裡為什麼這樣議論呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:22–25; 馬太福音 9:5"> <span className="woj">或對癱子說『你的罪赦了』，或說『起來，拿你的褥子行走』，哪一樣容易呢？</span></span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 7:13–14; 馬太福音 9:6–8; 約翰福音 5:20–27"> <span className="woj">但要叫你們知道，人子在地上有赦罪的權柄。」</span>就對癱子說：</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 1:41; 約翰福音 5:8–10; 約翰福音 6:63"> <span className="woj">「我吩咐你，起來，拿你的褥子回家去吧！」</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 9:33; 馬太福音 9:8; 路加福音 7:16"> 那人就起來，立刻拿著褥子，當眾人面前出去了。以致眾人都驚奇，歸榮耀於神，說：「我們從來沒有見過這樣的事！」</span>
</div>
</div>

## 耶穌召利未

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 4:1; 箴言 1:20–22; 路加福音 19:48"> 耶穌又出到海邊去，眾人都就了他來，他便教訓他們。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:27–32; 路加福音 6:15; 馬太福音 9:9–13"> 耶穌經過的時候，看見亞勒腓的兒子利未坐在稅關上，就對他說：<span className="woj">「你跟從我來！」</span>他就起來跟從了耶穌。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:1; 路加福音 5:29–30; 馬太福音 9:10–11"> 耶穌在利未家裡坐席的時候，有好些稅吏和罪人與耶穌並門徒一同坐席，因為這樣的人多，他們也跟隨耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 路加福音 19:7; 路加福音 18:11"> 法利賽人中的文士<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：文士和法利賽人。">a</a></sup>看見耶穌和罪人並稅吏一同吃飯，就對他門徒說：「他和稅吏並罪人一同吃喝嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 9:12–13; 路加福音 15:7; 路加福音 5:31–32"> 耶穌聽見，就對他們說：<span className="woj">「康健的人用不著醫生，有病的人才用得著。我來本不是召義人，乃是召罪人。」</span></span>
</div>
</div>

## 論禁食

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:12; 馬太福音 6:18; 馬太福音 9:14–17"> 當下，約翰的門徒和法利賽人禁食。他們來問耶穌說：「約翰的門徒和法利賽人的門徒禁食，你的門徒倒不禁食，這是為什麼呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 25:1–10; 創世記 29:22; 士師記 14:10–11"> 耶穌對他們說：<span className="woj">「新郎和陪伴之人同在的時候，陪伴之人豈能禁食呢？新郎還同在，他們不能禁食。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:22; 啟示錄 21:9; 以賽亞書 54:5"> <span className="woj">但日子將到，新郎要離開他們，那日他們就要禁食。</span></span>
</div>
</div>

## 新舊難合的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 9:16; 哥林多前書 10:13; 以賽亞書 57:16"> <span className="woj">「沒有人把新布縫在舊衣服上，恐怕所補上的新布帶壞了舊衣服，破的就更大了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 9:17; 詩篇 119:83; 路加福音 5:37–38"> <span className="woj">也沒有人把新酒裝在舊皮袋裡，恐怕酒把皮袋裂開，酒和皮袋就都壞了。唯把新酒裝在新皮袋裡。」</span></span>
</div>
</div>

## 人子是安息日的主

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:1–8; 申命記 23:24–25; 路加福音 6:1–5"> 耶穌當安息日從麥地經過，他門徒行路的時候掐了麥穗。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:10; 希伯來書 12:3; 馬太福音 12:2"> 法利賽人對耶穌說：「看哪，他們在安息日為什麼做不可做的事呢？」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 21:3–6; 路加福音 10:26; 馬太福音 22:31"> 耶穌對他們說：<span className="woj">「經上記著大衛和跟從他的人缺乏、飢餓之時所做的事，你們沒有念過嗎？</span></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 8:17; 利未記 24:5–9; 撒母耳記上 21:1"> <span className="woj">他當亞比亞他做大祭司的時候，怎麼進了神的殿，吃了陳設餅，又給跟從他的人吃？這餅除了祭司以外，人都不可吃。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 2:16; 路加福音 6:9; 申命記 5:14"> 又對他們說：<span className="woj">「安息日是為人設立的，人不是為安息日設立的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 12:8; 啟示錄 1:10; 約翰福音 5:17"> <span className="woj">所以，人子也是安息日的主。」</span></span>
</div>

## 鬼入豬群

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 馬太福音 8:28–34; 馬可福音 4:35"> 他們來到海那邊格拉森人的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 1:23; 以賽亞書 65:4; 馬可福音 5:8"> 耶穌一下船，就有一個被汙鬼附著的人從墳塋裡出來迎著他。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 65:4; 路加福音 8:29; 但以理書 4:32–33"> 那人常住在墳塋裡，沒有人能捆住他，就是用鐵鏈也不能。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 3:7–8"> 因為人屢次用腳鐐和鐵鏈捆鎖他，鐵鏈竟被他掙斷了，腳鐐也被他弄碎了。總沒有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 2:7–8; 列王紀上 18:28; 約翰福音 8:44"> 他晝夜常在墳塋裡和山中喊叫，又用石頭砍自己。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 2:19; 詩篇 66:3; 路加福音 4:41"> 他遠遠地看見耶穌，就跑過去拜他，</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 8:29; 使徒行傳 16:17; 馬太福音 26:63"> 大聲呼叫說：「至高神的兒子耶穌，我與你有什麼相干？我指著神懇求你，不要叫我受苦！」</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 1:25; 馬可福音 9:25–26; 使徒行傳 16:18"> 是因耶穌曾吩咐他說：<span className="woj">「汙鬼啊，從這人身上出來吧！」</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 馬可福音 5:15; 馬太福音 26:53"> 耶穌問他說：<span className="woj">「你名叫什麼？」</span>回答說：「我名叫『群』，因為我們多的緣故。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 3:22; 馬可福音 5:13"> 就再三地求耶穌，不要叫他們離開那地方。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 11:7–8; 以賽亞書 65:4; 以賽亞書 66:3"> 在那裡山坡上，有一大群豬吃食。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:11; 約伯記 1:10–12; 路加福音 22:31–32"> 鬼就央求耶穌，說：「求你打發我們往豬群裡，附著豬去。」</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:22; 彼得前書 3:22; 約伯記 2:6"> 耶穌准了他們，汙鬼就出來，進入豬裡去。於是那群豬闖下山崖，投在海裡淹死了。豬的數目約有二千。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 馬太福音 8:33"> 放豬的就逃跑了，去告訴城裡和鄉下的人。眾人就來，要看是什麼事。</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 1:13; 提摩太後書 1:7; 撒母耳記上 6:20–21"> 他們來到耶穌那裡，看見那被鬼附著的人，就是從前被群鬼所附的，坐著，穿上衣服，心裡明白過來，他們就害怕。</span>
<span className="v" id="v16" data-v="16"> 看見這事的，便將鬼附之人所遇見的和那群豬的事都告訴了眾人。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 8:34; 馬可福音 1:24; 路加福音 8:37"> 眾人就央求耶穌離開他們的境界。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比書 1:23–24; 馬可福音 5:17"> 耶穌上船的時候，那從前被鬼附著的人懇求和耶穌同在。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 66:16; 約翰福音 4:29; 以賽亞書 38:9–20"> 耶穌不許，卻對他說：<span className="woj">「你回家去到你的親屬那裡，將主為你所做的是何等大的事，是怎樣憐憫你，都告訴他們。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 7:31; 馬太福音 4:25"> 那人就走了，在低加波利傳揚耶穌為他做了何等大的事，眾人就都稀奇。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 9:1; 馬可福音 4:1; 路加福音 8:40"> 耶穌坐船又渡到那邊去，就有許多人到他那裡聚集，他正在海邊上。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行傳 18:8; 馬可福音 5:35–36"> 有一個管會堂的人，名叫睚魯，來見耶穌，就俯伏在他腳前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 馬可福音 16:18"> 再三地求他，說：「我的小女兒快要死了，求你去按手在她身上，使她痊癒，得以活了。」</span>
<span className="v" id="v24" data-v="24" data-xref="馬可福音 5:31; 馬可福音 3:20; 路加福音 7:6"> 耶穌就和他同去。有許多人跟隨，擁擠他。</span>
</div>
</div>

## 醫患血漏的女人

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="利未記 15:25–27; 路加福音 8:43–44; 馬太福音 9:20–22"> 有一個女人患了十二年的血漏，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 30:12–13; 耶利米書 8:22; 詩篇 108:12"> 在好些醫生手裡受了許多的苦，又花盡了她所有的，一點也不見好，病勢反倒更重了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 19:12; 馬太福音 14:36; 使徒行傳 5:15"> 她聽見耶穌的事，就從後頭來，雜在眾人中間，摸耶穌的衣裳，</span>
<span className="v" id="v28" data-v="28"> 意思說：「我只摸他的衣裳，就必痊癒。」</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 5:34; 詩篇 30:2; 馬可福音 3:10"> 於是她血漏的源頭立刻乾了，她便覺得身上的災病好了。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶穌頓時心裡覺得有能力從自己身上出去，就在眾人中間轉過來，說：<span className="woj">「誰摸我的衣裳？」</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 門徒對他說：「你看眾人擁擠你，還說『誰摸我』嗎？」</span>
<span className="v" id="v32" data-v="32"> 耶穌周圍觀看，要見做這事的女人。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那女人知道在自己身上所成的事，就恐懼戰兢，來俯伏在耶穌跟前，將實情全告訴他。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 馬太福音 9:22; 路加福音 7:50"> 耶穌對她說：<span className="woj">「女兒，你的信救了你，平平安安地回去吧！你的災病痊癒了。」</span></span>
</div>
</div>

## 耶穌叫睚魯的女兒復活

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 約翰福音 11:39; 馬可福音 5:22"> 還說話的時候，有人從管會堂的家裡來，說：「你的女兒死了，何必還勞動先生呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 馬太福音 9:28–29; 約翰福音 11:40"> 耶穌聽見所說的話，就對管會堂的說：<span className="woj">「不要怕，只要信！」</span></span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 9:40; 馬可福音 14:33; 哥林多後書 13:1"> 於是帶著彼得、雅各和雅各的兄弟約翰同去，不許別人跟隨他。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 9:23–24; 路加福音 8:52–53; 馬可福音 5:22"> 他們來到管會堂的家裡，耶穌看見那裡亂嚷，並有人大大地哭泣哀號，</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 20:10; 帖撒羅尼迦前書 5:10; 帖撒羅尼迦前書 4:13–14"> 進到裡面就對他們說：<span className="woj">「為什麼亂嚷哭泣呢？孩子不是死了，是睡著了。」</span></span>
<span className="v" id="v40" data-v="40" data-xref="尼希米記 2:19; 列王紀下 4:33; 馬太福音 9:24–25"> 他們就嗤笑耶穌。耶穌把他們都攆出去，就帶著孩子的父母和跟隨的人進了孩子所在的地方，</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 就拉著孩子的手，對她說：<span className="woj">「大利大，古米！」</span>（翻出來就是說：<span className="woj">「閨女，我吩咐你起來！」</span>）</span>
<span className="v" id="v42" data-v="42" data-xref="馬可福音 4:41; 使徒行傳 3:10–13; 馬可福音 7:37"> 那閨女立時起來走，他們就大大地驚奇；閨女已經十二歲了。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 8:4; 馬太福音 9:30; 馬可福音 1:43"> 耶穌切切地囑咐他們，不要叫人知道這事，又吩咐給她東西吃。</span>
</div>

## 給四千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 15:32–39; 馬可福音 6:34–44"> 那時，又有許多人聚集，並沒有什麼吃的。耶穌叫門徒來，說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:36; 彌迦書 7:19; 詩篇 103:13"> <span className="woj">「我憐憫這眾人，因為他們同我在這裡已經三天，也沒有吃的了。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 40:31; 士師記 8:4–6; 撒母耳記上 30:10–12"> <span className="woj">我若打發他們餓著回家，就必在路上困乏，因為其中有從遠處來的。」</span></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 4:42–44; 列王紀下 7:2; 馬可福音 6:52"> 門徒回答說：「在這野地，從哪裡能得餅叫這些人吃飽呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 14:15–17; 馬太福音 15:34; 路加福音 9:13"> 耶穌問他們說：<span className="woj">「你們有多少餅？」</span>他們說：「七個。」</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:17; 馬太福音 15:35–36; 約翰福音 6:10–11"> 他吩咐眾人坐在地上，就拿著這七個餅祝謝了，掰開，遞給門徒，叫他們擺開，門徒就擺在眾人面前。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 14:19; 約翰福音 21:5; 路加福音 24:41–42"> 又有幾條小魚，耶穌祝了福，就吩咐也擺在眾人面前。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 4:42–44; 詩篇 145:16; 馬太福音 16:10"> 眾人都吃，並且吃飽了，收拾剩下的零碎，有七筐子。</span>
<span className="v" id="v9" data-v="9"> 人數約有四千。耶穌打發他們走了，</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 15:39"> 隨即同門徒上船，來到大瑪努他境內。</span>
</div>
</div>

## 求主顯神蹟

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 10:9; 馬太福音 12:38; 申命記 6:16"> 法利賽人出來盤問耶穌，求他從天上顯個神蹟給他們看，想要試探他。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:39–40; 馬可福音 7:34; 馬太福音 16:4"> 耶穌心裡深深地嘆息說：<span className="woj">「這世代為什麼求神蹟呢？我實在告訴你們：沒有神蹟給這世代看！」</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 12:36; 使徒行傳 13:45–46; 詩篇 81:12"> 他就離開他們，又上船往海那邊去了。</span>
</div>
</div>

## 防備法利賽人和希律的酵

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 16:5"> 門徒忘了帶餅，在船上除了一個餅，沒有別的食物。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 5:6–8; 馬太福音 16:6; 馬太福音 16:11–12"> 耶穌囑咐他們說：<span className="woj">「你們要謹慎，防備法利賽人的酵和希律的酵。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 馬太福音 16:7–8"> 他們彼此議論說：「這是因為我們沒有餅吧？」</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 6:52; 以賽亞書 63:17; 馬可福音 2:8"> 耶穌看出來，就說：<span className="woj">「你們為什麼因為沒有餅就議論呢？你們還不醒悟，還不明白嗎？你們的心還是愚頑嗎？</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 28:26–27; 馬太福音 13:14–15; 耶利米書 5:21"> <span className="woj">你們有眼睛看不見嗎？有耳朵聽不見嗎？也不記得嗎？</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 馬太福音 14:17–21; 約翰福音 6:5–13"> <span className="woj">我掰開那五個餅分給五千人，你們收拾的零碎裝滿了多少籃子呢？」</span>他們說：「十二個。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 15:34–38; 馬可福音 8:1–9"> <span className="woj">「又掰開那七個餅分給四千人，你們收拾的零碎裝滿了多少筐子呢？」</span>他們說：「七個。」</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:52; 馬太福音 16:11–12; 馬可福音 8:12"> 耶穌說：<span className="woj">「你們還是不明白嗎？」</span></span>
</div>
</div>

## 吐唾沫治好瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:21; 馬可福音 6:45; 路加福音 10:13"> 他們來到伯賽大，有人帶一個瞎子來，求耶穌摸他。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 7:33; 約翰福音 9:6–7; 馬可福音 5:23"> 耶穌拉著瞎子的手，領他到村外，就吐唾沫在他眼睛上，按手在他身上，問他說：<span className="woj">「你看見什麼了？」</span></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 32:3; 以賽亞書 29:18; 哥林多前書 13:9–12"> 他就抬頭一看，說：「我看見人了，他們好像樹木，並且行走。」</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 2:9; 彼得後書 3:18; 箴言 4:18"> 隨後又按手在他眼睛上，他定睛一看，就復了原，樣樣都看得清楚了。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 8:4; 馬可福音 8:23; 馬可福音 5:43"> 耶穌打發他回家，說：<span className="woj">「連這村子你也不要進去。」</span></span>
</div>
</div>

## 認耶穌為基督

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:13–20; 路加福音 9:18–20"> 耶穌和門徒出去，往凱撒利亞-腓立比的村莊去。在路上問門徒說：<span className="woj">「人說我是誰？」</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:21; 馬太福音 14:2; 瑪拉基書 4:5"> 他們說：「有人說是施洗的約翰，有人說是以利亞，又有人說是先知裡的一位。」</span>
<span className="v" id="v29" data-v="29" data-xref="約翰一書 4:15; 馬太福音 16:15–16; 約翰一書 5:1"> 又問他們說：<span className="woj">「你們說我是誰？」彼得</span>回答說：「你是基督。」</span>
</div>
</div>

## 預言受難復活降臨

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 馬太福音 16:20; 馬可福音 9:9"> 耶穌就禁戒他們，不要告訴人。</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 10:33–34; 約翰福音 2:19; 路加福音 24:26"> 從此，他教訓他們說：<span className="woj">「人子必須受許多的苦，被長老、祭司長和文士棄絕，並且被殺，過三天復活。」</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 16:22; 約翰福音 16:25; 約翰福音 16:29"> 耶穌明明地說這話，彼得就拉著他，勸他。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 4:10; 腓立比書 3:19; 約翰一書 2:15"> 耶穌轉過來，看著門徒，就責備彼得，說：<span className="woj">「撒旦，退我後邊去吧！因為你不體貼神的意思，只體貼人的意思。」</span></span>
</div>
</div>

## 當背十架跟從主

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:38; 路加福音 14:26–27; 約翰福音 10:27"> 於是叫眾人和門徒來，對他們說：<span className="woj">「若有人要跟從我，就當捨己，背起他的十字架來跟從我。</span></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太後書 2:11–13; 哥林多前書 9:23; 路加福音 17:33"> <span className="woj">因為凡要救自己生命</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「生命」或作「靈魂」，下同。">a</a></sup><span className="woj">的，必喪掉生命；凡為我和福音喪掉生命的，必救了生命。</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 16:26; 路加福音 9:25; 詩篇 49:17"> <span className="woj">人就是賺得全世界，賠上自己的生命，有什麼益處呢？</span></span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 49:7–8; 彼得前書 1:18–19"> <span className="woj">人還能拿什麼換生命呢？</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 羅馬書 1:16; 約翰一書 2:23"> <span className="woj">凡在這淫亂罪惡的世代，把我和我的道當做可恥的，人子在他父的榮耀裡同聖天使降臨的時候，也要把那人當做可恥的。」</span></span>
</div>

## 主騎驢進耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:1–11; 約翰福音 12:14–19; 路加福音 19:29–40"> 耶穌和門徒將近耶路撒冷，到了伯法其和伯大尼，在橄欖山那裡，耶穌就打發兩個門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 21:2–3; 路加福音 19:30–31"> 對他們說：<span className="woj">「你們往對面村子裡去，一進去的時候，必看見一匹驢駒拴在那裡，是從來沒有人騎過的，可以解開牽來。</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 10:36; 馬可福音 14:15; 詩篇 110:3"> <span className="woj">若有人對你們說：『為什麼做這事？』你們就說：『主要用牠。』那人必立時讓你們牽來。」</span></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 26:19; 路加福音 19:32–34; 馬太福音 21:6–7"> 他們去了，便看見一匹驢駒拴在門外街道上，就把牠解開。</span>
<span className="v" id="v5" data-v="5"> 在那裡站著的人有幾個說：「你們解驢駒做什麼？」</span>
<span className="v" id="v6" data-v="6"> 門徒照著耶穌所說的回答，那些人就任憑他們牽去了。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 9:9; 路加福音 19:35–36; 馬太福音 21:7–8"> 他們把驢駒牽到耶穌那裡，把自己的衣服搭在上面，耶穌就騎上。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 23:40"> 有許多人把衣服鋪在路上，也有人把田間的樹枝砍下來鋪在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:25–26; 馬太福音 21:9; 馬太福音 23:39"> 前行後隨的人都喊著說：<br /><span className="pl pl-1">「和散那</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「和散那」原有「求救」的意思，在此乃是稱頌的話。">a</a></sup><br /><span className="pl pl-1">！</span><br /><span className="pl pl-1">奉主名來的是應當稱頌的！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> <span className="pl pl-1">那將要來的我祖大衛之國是應當稱頌的！</span><br /><span className="pl pl-1">高高在上和散那！」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶穌進了耶路撒冷，入了聖殿，周圍看了各樣物件。天色已晚，就和十二個門徒出城，往伯大尼去了。</span>
</div>
</div>

## 無花果樹被咒詛

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:18–22; 馬太福音 4:2; 約翰福音 19:28"> 第二天，他們從伯大尼出來，耶穌餓了，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 21:19; 路加福音 13:6–9; 以賽亞書 5:7"> 遠遠地看見一棵無花果樹，樹上有葉子，就往那裡去，或者在樹上可以找著什麼。到了樹下，竟找不著什麼，不過有葉子，因為不是收無花果的時候。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 21:19; 馬太福音 7:19; 馬太福音 3:10"> 耶穌就對樹說：<span className="woj">「從今以後，永沒有人吃你的果子！」</span>他的門徒也聽見了。</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 2:13–17; 馬太福音 21:12–16; 路加福音 19:45–47"> 他們來到耶路撒冷。耶穌進入聖殿，趕出殿裡做買賣的人，推倒兌換銀錢之人的桌子和賣鴿子之人的凳子，</span>
<span className="v" id="v16" data-v="16"> 也不許人拿著器具從殿裡經過。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 56:7; 耶利米書 7:11; 路加福音 19:46"> 便教訓他們，說：<span className="woj">「經上不是記著說</span><br /><span className="pl pl-1 woj">『我的殿必稱為萬國禱告的殿』嗎？</span><br /><span className="pl pl-1 woj">你們倒使它成為賊窩了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 7:28; 馬可福音 12:12; 馬可福音 14:1–2"> 祭司長和文士聽見這話，就想法子要除滅耶穌，卻又怕他，因為眾人都稀奇他的教訓。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 馬可福音 11:11; 約翰福音 12:36"> 每天晚上，耶穌出城去。</span>
</div>
</div>

## 信心的能力

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 15:13; 馬可福音 11:14; 約翰福音 15:6"> 早晨，他們從那裡經過，看見無花果樹連根都枯乾了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; 馬太福音 23:7; 馬太福音 25:41"> 彼得想起耶穌的話來，就對他說：「拉比，請看，你所咒詛的無花果樹已經枯乾了！」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 62:8; 約翰福音 14:1; 馬可福音 9:23"> 耶穌回答說：<span className="woj">「你們當信服神。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 17:20; 約翰福音 15:7; 馬太福音 21:21"> <span className="woj">我實在告訴你們：無論何人對這座山說：『你挪開此地，投在海裡！』，他若心裡不疑惑，只信他所說的必成，就必給他成了。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 21:22; 約翰一書 5:14–15; 約翰一書 3:22"> <span className="woj">所以我告訴你們，凡你們禱告祈求的，無論是什麼，只要信是得著的，就必得著。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 6:14–15; 歌羅西書 3:13; 以弗所書 4:32"> <span className="woj">你們站著禱告的時候，若想起有人得罪你們，就當饒恕他，好叫你們在天上的父也饒恕你們的過犯。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">你們若不饒恕人，你們在天上的父也不饒恕你們的過犯。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷無此節。">b</a></sup><span className="woj">」</span></span>
</div>
</div>

## 辯駁耶穌的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 馬太福音 21:23–27; 詩篇 2:1–5"> 他們又來到耶路撒冷。耶穌在殿裡行走的時候，祭司長和文士並長老進前來，</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 2:14; 使徒行傳 7:38–39; 民數記 16:3"> 問他說：「你仗著什麼權柄做這些事？給你這權柄的是誰呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 馬太福音 21:24; 以賽亞書 52:13"> 耶穌對他們說：<span className="woj">「我要問你們一句話，你們回答我，我就告訴你們我仗著什麼權柄做這些事。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 約翰福音 3:25–36; 馬可福音 1:1–11"> <span className="woj">約翰的洗禮是從天上來的，是從人間來的呢？你們可以回答我。」</span></span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:29; 約翰福音 1:34; 馬太福音 21:31–32"> 他們彼此商議說：「我們若說從天上來，他必說：『這樣，你們為什麼不信他呢？』</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 21:46; 馬可福音 12:12; 馬太福音 14:5"> 若說從人間來，卻又怕百姓，因為眾人真以約翰為先知。」</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 6:9–10; 哥林多後書 4:3–4; 帖撒羅尼迦後書 2:10–12"> 於是回答耶穌說：「我們不知道。」耶穌說：<span className="woj">「我也不告訴你們我仗著什麼權柄做這些事。」</span></span>
</div>

## 改變形像

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; 以賽亞書 33:17; 馬太福音 17:1–8"> 過了六天，耶穌帶著彼得、雅各、約翰暗暗地上了高山，就在他們面前變了形像，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 28:3; 但以理書 7:9; 啟示錄 7:14"> 衣服放光，極其潔白，地上漂布的沒有一個能漂得那樣白。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 馬太福音 17:3–4; 使徒行傳 3:21–24"> 忽然，有以利亞同摩西向他們顯現，並且和耶穌說話。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 1:23; 約翰福音 14:8–9; 啟示錄 22:3–4"> 彼得對耶穌說：「拉比<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拉比」就是「夫子」。">a</a></sup>，我們在這裡真好！可以搭三座棚：一座為你，一座為摩西，一座為以利亞。」</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:17; 但以理書 10:15–19; 馬可福音 16:5–8"> 彼得不知道說什麼才好，因為他們甚是懼怕。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得後書 1:17; 馬太福音 3:17; 馬可福音 1:11"> 有一朵雲彩來遮蓋他們，也有聲音從雲彩裡出來說：「這是我的愛子，你們要聽他！」</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 10:16; 使徒行傳 8:39–40; 路加福音 24:31"> 門徒忽然周圍一看，不再見一人，只見耶穌同他們在那裡。</span>
</div>
</div>

## 以約翰譬以利亞

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 12:40; 馬太福音 17:9–13; 馬可福音 5:43"> 下山的時候，耶穌囑咐他們說：<span className="woj">「人子還沒有從死裡復活，你們不要將所看見的告訴人。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 門徒將這話存記在心，彼此議論從死裡復活是什麼意思。</span>
<span className="v" id="v11" data-v="11" data-xref="瑪拉基書 4:5; 瑪拉基書 3:1; 馬太福音 11:14"> 他們就問耶穌說：「文士為什麼說以利亞必須先來？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 53:1–12; 以賽亞書 50:6; 以賽亞書 52:14"> 耶穌說：<span className="woj">「以利亞固然先來復興萬事。經上不是指著人子說，他要受許多的苦、被人輕慢呢？</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 14:3–11; 馬太福音 17:12–13; 馬太福音 11:14"> <span className="woj">我告訴你們：以利亞已經來了，他們也任意待他，正如經上所指著他的話。」</span></span>
</div>
</div>

## 害癲癇病的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 馬太福音 17:14–20; 路加福音 11:53–54"> 耶穌到了門徒那裡，看見有許多人圍著他們，又有文士和他們辯論。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:30; 馬可福音 9:2–3"> 眾人一見耶穌，都甚稀奇，就跑上去問他的安。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 馬可福音 8:11"> 耶穌問他們說：<span className="woj">「你們和他們辯論的是什麼？」</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 9:25; 路加福音 11:14; 約翰福音 4:47"> 眾人中間有一個人回答說：「夫子，我帶了我的兒子到你這裡來，他被啞巴鬼附著。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 17:19–20; 馬可福音 11:23; 馬太福音 17:16"> 無論在哪裡，鬼捉弄他，把他摔倒，他就口中流沫，咬牙切齒，身體枯乾。我請過你的門徒把鬼趕出去，他們卻是不能。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 14:11; 約翰福音 20:27; 民數記 14:27"> 耶穌說：<span className="woj">「唉！不信的世代啊，我在你們這裡要到幾時呢？我忍耐你們要到幾時呢？把他帶到我這裡來吧！」</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:26; 路加福音 4:35; 約翰福音 8:44"> 他們就帶了他來。他一見耶穌，鬼便叫他重重地抽風，倒在地上翻來覆去，口中流沫。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:33; 使徒行傳 4:22; 馬可福音 5:25"> 耶穌問他父親說：<span className="woj">「他得這病有多少日子呢？」</span>回答說：「從小的時候。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:22–28; 馬可福音 5:19; 馬太福音 20:34"> 鬼屢次把他扔在火裡、水裡，要滅他。你若能做什麼，求你憐憫我們，幫助我們！」</span>
</div>
</div>

## 在信的人凡事都能

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 11:40; 希伯來書 11:6; 馬可福音 11:23"> 耶穌對他說：<span className="woj">「你若能信，在信的人，凡事都能。」</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯來書 12:2; 以弗所書 2:8"> 孩子的父親立時喊著說<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷作：立時流淚地喊著說。">b</a></sup>：「我信！但我信不足，求主幫助！」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:18; 路加福音 9:42; 馬可福音 9:15"> 耶穌看見眾人都跑上來，就斥責那汙鬼，說：<span className="woj">「你這聾啞的鬼，我吩咐你從他裡頭出來，再不要進去！」</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 9:20; 馬可福音 1:26; 馬可福音 9:18"> 那鬼喊叫，使孩子大大地抽了一陣風，就出來了。孩子好像死了一般，以致眾人多半說：「他是死了。」</span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 1:31; 使徒行傳 3:7; 馬可福音 1:41"> 但耶穌拉著他的手，扶他起來，他就站起來了。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 17:19–20; 馬可福音 7:17; 馬太福音 15:15"> 耶穌進了屋子，門徒就暗暗地問他說：「我們為什麼不能趕出他去呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 5:15; 但以理書 9:3; 馬太福音 17:20"> 耶穌說：<span className="woj">「非用禱告</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷在此有「禁食」二字。">c</a></sup><span className="woj">，這一類的鬼總不能出來</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：不能趕他出來。">d</a></sup><span className="woj">。」</span></span>
</div>
</div>

## 預言受難

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 17:22–23; 路加福音 9:43–45; 馬可福音 6:31–32"> 他們離開那地方，經過加利利，耶穌不願意人知道。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 16:21; 馬可福音 9:12; 路加福音 24:44–46"> 於是教訓門徒，說：<span className="woj">「人子將要被交在人手裡，他們要殺害他，被殺以後過三天他要復活。」</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 門徒卻不明白這話，又不敢問他。</span>
</div>
</div>

## 爭論誰為大

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 18:1–5; 希伯來書 4:13; 路加福音 9:46–48"> 他們來到迦百農，耶穌在屋裡問門徒說：<span className="woj">「你們在路上議論的是什麼？」</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 9:50; 馬太福音 20:21–24; 馬太福音 18:1–5"> 門徒不作聲，因為他們在路上彼此爭論誰為大。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:25–28; 馬可福音 10:42–45; 路加福音 22:26"> 耶穌坐下，叫十二個門徒來，說：<span className="woj">「若有人願意做首先的，他必做眾人末後的，做眾人的用人。」</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 10:16; 馬太福音 19:14–15; 馬太福音 18:2"> 於是領過一個小孩子來，叫他站在門徒中間，又抱起他來，對他們說：</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 18:3–5; 路加福音 10:16; 馬太福音 10:40–42"> <span className="woj">「凡為我名接待一個像這小孩子的，就是接待我；凡接待我的，不是接待我，乃是接待那差我來的。」</span></span>
</div>
</div>

## 奉主名的不易謗主

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; 民數記 11:26–29; 路加福音 11:19"> 約翰對耶穌說：「夫子，我們看見一個人奉你的名趕鬼，我們就禁止他，因為他不跟從我們。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 12:3; 哥林多前書 13:1–2; 馬太福音 13:28–29"> 耶穌說：<span className="woj">「不要禁止他，因為沒有人奉我名行異能，反倒輕易毀謗我。</span></span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 12:30; 路加福音 11:23"> <span className="woj">不敵擋我們的，就是幫助我們的。</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 10:42; 馬太福音 25:40; 哥林多前書 15:23"> <span className="woj">凡因你們是屬基督，給你們一杯水喝的，我實在告訴你們：他不能不得賞賜。</span></span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 18:6; 路加福音 17:1–2; 馬太福音 18:10"> <span className="woj">凡使這信我的一個小子跌倒的，倒不如把大磨石拴在這人的頸項上，扔在海裡。</span></span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 5:29–30; 馬太福音 18:8–9; 馬太福音 25:41"> <span className="woj">倘若你一隻手叫你跌倒，就把它砍下來！</span></span>
<span className="v" id="v44" data-v="44"> <span className="woj">你缺了肢體進入永生，強如有兩隻手落到地獄，入那不滅的火裡去。</span></span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 18:8; 馬太福音 5:22; 馬可福音 9:43"> <span className="woj">倘若你一隻腳叫你跌倒，就把它砍下來！</span></span>
<span className="v" id="v46" data-v="46"> <span className="woj">你瘸腿進入永生，強如有兩隻腳被丟在地獄裡。</span></span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 18:9; 馬可福音 9:43; 馬太福音 5:22"> <span className="woj">倘若你一隻眼叫你跌倒，就去掉它！你只有一隻眼進入神的國，強如有兩隻眼被丟在地獄裡。</span></span>
<span className="v" id="v48" data-v="48" data-xref="以賽亞書 66:24; 馬可福音 9:43–45; 馬太福音 25:41"> <span className="woj">在那裡，蟲是不死的，火是不滅的。</span></span>
<span className="v" id="v49" data-v="49" data-xref="利未記 2:13; 以西結書 43:24"> <span className="woj">因為必用火當鹽醃各人。</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古卷在此有：凡祭物必用鹽醃。">e</a></sup></span>
<span className="v" id="v50" data-v="50" data-xref="歌羅西書 4:6; 羅馬書 12:18; 馬太福音 5:13"> <span className="woj">鹽本是好的，若失了味，可用什麼叫它再鹹呢？你們裡頭應當有鹽，彼此和睦。」</span></span>

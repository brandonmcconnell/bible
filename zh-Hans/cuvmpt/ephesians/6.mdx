## 父母和兒女的本分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:20–25; 箴言 23:22; 箴言 6:20"> 你們做兒女的，要在主裡聽從父母，這是理所當然的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 20:12; 申命記 27:16; 馬太福音 15:4–6"> 「要孝敬父母，使你得福，在世長壽。」這是第一條帶應許的誡命。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:21; 箴言 22:6; 箴言 29:15"> 你們做父親的，不要惹兒女的氣，只要照著主的教訓和警戒養育他們。</span>
</div>
</div>

## 主人和僕人的本分

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得前書 2:18–21; 提多書 2:9–10; 歌羅西書 3:17–24"> 你們做僕人的，要懼怕戰兢，用誠實的心聽從你們肉身的主人，好像聽從基督一般。</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:22–23; 帖撒羅尼迦前書 2:4; 加拉太書 1:10"> 不要只在眼前侍奉，像是討人喜歡的，要像基督的僕人，從心裡遵行神的旨意，</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 3:23; 以弗所書 6:5–6; 哥林多前書 10:31"> 甘心侍奉，好像服侍主，不像服侍人。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:24; 路加福音 14:14; 箴言 11:18"> 因為曉得各人所行的善事，不論是為奴的，是自主的，都必按所行的得主的賞賜。</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 3:25–1; 使徒行傳 10:34; 羅馬書 2:11"> 你們做主人的，待僕人也是一理，不要威嚇他們。因為知道，他們和你們同有一位主在天上，他並不偏待人。</span>
</div>
</div>

## 須穿戴神所賜的全副軍裝

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比書 4:13; 以賽亞書 40:31; 約書亞記 1:9"> 我還有末了的話，你們要靠著主，倚賴他的大能大力做剛強的人。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 10:4; 羅馬書 13:12; 以弗所書 6:13"> 要穿戴神所賜的全副軍裝，就能抵擋魔鬼的詭計。</span>
<span className="v" id="v12" data-v="12" data-xref="歌羅西書 1:13; 哥林多後書 4:4; 以弗所書 2:2"> 因我們並不是與屬血氣的爭戰，乃是與那些執政的、掌權的、管轄這幽暗世界的，以及天空屬靈氣的惡魔爭戰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="兩「爭戰」原文都作「摔跤」。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 10:4; 路加福音 21:36; 以弗所書 6:11–17"> 所以，要拿起神所賜的全副軍裝，好在磨難的日子抵擋仇敵；並且成就了一切，還能站立得住。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 59:17; 帖撒羅尼迦前書 5:8; 以賽亞書 11:5"> 所以要站穩了，用真理當做帶子束腰，用公義當做護心鏡遮胸，</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 52:7; 羅馬書 10:15; 哥林多後書 5:18–21"> 又用平安的福音當做預備走路的鞋穿在腳上。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 5:8–9; 約翰一書 5:4–5; 箴言 18:10"> 此外，又拿著信德當做藤牌，可以滅盡那惡者一切的火箭；</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:12; 以賽亞書 59:17; 啟示錄 19:15"> 並戴上救恩的頭盔，拿著聖靈的寶劍，就是神的道。</span>
</div>
</div>

## 當隨時警醒禱告

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:17; 歌羅西書 4:2; 腓立比書 4:6"> 靠著聖靈，隨時多方禱告祈求，並要在此警醒不倦，為眾聖徒祈求；</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 4:3; 使徒行傳 4:29; 帖撒羅尼迦後書 3:1"> 也為我祈求，使我得著口才，能以放膽開口講明福音的奧祕——</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 5:20; 歌羅西書 4:4; 提摩太後書 2:9"> 我為這福音的奧祕做了戴鎖鏈的使者——並使我照著當盡的本分放膽講論。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:4; 提摩太後書 4:12; 提多書 3:12"> 今有所親愛、忠心侍奉主的兄弟推基古，他要把我的事情並我的景況如何全告訴你們，叫你們知道。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 2:25; 歌羅西書 4:7–8; 帖撒羅尼迦後書 2:17"> 我特意打發他到你們那裡去，好叫你們知道我們的光景，又叫他安慰你們的心。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:16; 加拉太書 5:6; 彼得前書 5:14"> 願平安、仁愛、信心從父神和主耶穌基督歸於弟兄們！</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 22:37; 哥林多後書 8:12; 馬太福音 6:13"> 並願所有誠心愛我們主耶穌基督的人都蒙恩惠！</span>
</div>
</div>

## 勸門徒合而為一

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:10; 腓立比書 1:27; 帖撒羅尼迦前書 2:12"> 我為主被囚的勸你們：既然蒙召，行事為人就當與蒙召的恩相稱，</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 3:12–13; 哥林多前書 13:7; 哥林多前書 13:4–5"> 凡事謙虛、溫柔、忍耐，用愛心互相寬容，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:10; 歌羅西書 3:13–15; 哥林多前書 12:12–13"> 用和平彼此聯絡，竭力保守聖靈所賜合而為一的心。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:18; 羅馬書 12:4–5; 哥林多前書 12:4–13"> 身體只有一個，聖靈只有一個，正如你們蒙召同有一個指望；</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 8:6; 哥林多前書 12:13; 彼得前書 3:21"> 一主，一信，一洗，</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 11:36; 瑪拉基書 2:10; 哥林多前書 8:6"> 一神，就是眾人的父，超乎眾人之上，貫乎眾人之中，也住在眾人之內。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:10; 羅馬書 12:3; 哥林多前書 12:7–11"> 我們各人蒙恩，都是照基督所量給各人的恩賜。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:18; 歌羅西書 2:15; 撒母耳記上 30:26"> 所以經上說：<br /><span className="pl pl-1">「他升上高天的時候，擄掠了仇敵，</span><br /><span className="pl pl-1">將各樣的恩賜賞給人。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:13; 馬太福音 12:40; 箴言 30:4"> （既說升上，豈不是先降在地下嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 7:26; 希伯來書 4:14; 以弗所書 1:20–23"> 那降下的，就是遠升諸天之上要充滿萬有的。）</span>
</div>
</div>

## 滿有基督長成的身量

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:15; 哥林多前書 12:28–29; 以弗所書 2:20"> 他所賜的有使徒，有先知，有傳福音的，有牧師和教師，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:11–14; 以弗所書 4:16; 哥林多前書 12:27"> 為要成全聖徒，各盡其職，建立基督的身體，</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:28; 約翰福音 17:21; 以弗所書 4:5"> 直等到我們眾人在真道上同歸於一，認識神的兒子，得以長大成人，滿有基督長成的身量，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:9; 羅馬書 16:17–18; 哥林多前書 14:20"> 使我們不再做小孩子，中了人的詭計和欺騙的法術，被一切異教之風搖動飄來飄去，就隨從各樣的異端，</span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 3:18; 以弗所書 4:25; 撒迦利亞書 8:16"> 唯用愛心說誠實話，凡事長進，連於元首基督。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 2:19; 約翰福音 15:5; 歌羅西書 2:2"> 全身都靠他聯絡得合式，百節各按各職，照著各體的功用彼此相助，便叫身體漸漸增長，在愛中建立自己。</span>
</div>
</div>

## 凡事效法基督

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:21; 彼得前書 4:3–4; 帖撒羅尼迦前書 4:1–2"> 所以我說，且在主裡確實地說：你們行事不要再像外邦人，存虛妄的心行事。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:15; 以弗所書 2:12; 羅馬書 1:21–23"> 他們心地昏昧，與神所賜的生命隔絕了，都因自己無知，心裡剛硬；</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:5; 羅馬書 1:24–26; 提摩太前書 4:2"> 良心既然喪盡，就放縱私慾，貪行種種的汙穢。</span>
</div>
</div>

## 穿上新人

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提多書 2:11–14; 約翰福音 6:45; 馬太福音 11:29"> 你們學了基督，卻不是這樣。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 5:20; 以弗所書 1:13; 希伯來書 3:7–8"> 如果你們聽過他的道，領了他的教，學了他的真理，</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 6:6; 希伯來書 12:1; 雅各書 1:21"> 就要脫去你們從前行為上的舊人，這舊人是因私慾的迷惑漸漸變壞的；</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 12:2; 羅馬書 8:6; 詩篇 51:10"> 又要將你們的心志改換一新，</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:10–14; 哥林多後書 5:17; 以弗所書 2:10"> 並且穿上新人，這新人是照著神的形像造的，有真理的仁義和聖潔。</span>
</div>
</div>

## 不可給魔鬼留地步

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌羅西書 3:9; 撒迦利亞書 8:16; 箴言 12:22"> 所以你們要棄絕謊言，各人與鄰舍說實話，因為我們是互相為肢體。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 1:19; 詩篇 4:4; 詩篇 37:8"> 生氣卻不要犯罪，不可含怒到日落，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 4:7; 彼得前書 5:8; 以弗所書 6:16"> 也不可給魔鬼留地步。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前書 6:18; 帖撒羅尼迦前書 4:11–12; 加拉太書 6:10"> 從前偷竊的，不要再偷，總要勞力，親手做正經事，就可有餘，分給那缺少的人。</span>
</div>
</div>

## 不要叫聖靈擔憂

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 4:6; 帖撒羅尼迦前書 5:11; 傳道書 10:12"> 汙穢的言語一句不可出口，只要隨事說造就人的好話，叫聽見的人得益處。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 5:19; 以賽亞書 63:10; 以弗所書 1:13–14"> 不要叫神的聖靈擔憂，你們原是受了他的印記，等候得贖的日子來到。</span>
<span className="v" id="v31" data-v="31" data-xref="歌羅西書 3:8; 傳道書 7:9; 提多書 3:2–3"> 一切苦毒、惱恨、憤怒、嚷鬧、毀謗，並一切的惡毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：陰毒。">a</a></sup>，都當從你們中間除掉；</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 3:12–13; 馬太福音 6:14–15; 馬可福音 11:25"> 並要以恩慈相待，存憐憫的心，彼此饒恕，正如神在基督裡饒恕了你們一樣。</span>
</div>
</div>

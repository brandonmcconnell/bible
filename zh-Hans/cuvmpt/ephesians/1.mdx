## 蒙救贖的恩

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 1:3; 哥林多後書 1:3; 以弗所書 2:6"> 願頌讚歸於我們主耶穌基督的父神！他在基督裡曾賜給我們天上各樣屬靈的福氣，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 1:9; 羅馬書 8:28–30; 以弗所書 2:10"> 就如神從創立世界以前在基督裡揀選了我們，使我們在他面前成為聖潔，無有瑕疵；</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:29–30; 以弗所書 1:11; 加拉太書 4:5–6"> 又因愛我們，就按著自己意旨所喜悅的，預定我們藉著耶穌基督得兒子的名分，</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 3:22–26; 以弗所書 1:12; 歌羅西書 1:13"> 使他榮耀的恩典得著稱讚。這恩典是他在愛子裡所賜給我們的。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 2:24; 羅馬書 3:24; 約翰一書 1:7–9"> 我們藉這愛子的血得蒙救贖，過犯得以赦免，乃是照他豐富的恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 5:12; 以弗所書 3:10; 羅馬書 5:15"> 這恩典是神用諸般智慧聰明，充充足足賞給我們的，</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:26–28; 羅馬書 16:25–27; 以弗所書 3:3–9"> 都是照他自己所預定的美意，叫我們知道他旨意的奧祕，</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 1:20; 腓立比書 2:9–10; 加拉太書 4:4"> 要照所安排的，在日期滿足的時候，使天上、地上一切所有的，都在基督裡面同歸於一。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:28; 彼得前書 1:4; 以賽亞書 46:10–11"> 我們也在他裡面得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「得」或作「成」。">a</a></sup>了基業，這原是那位隨己意行做萬事的，照著他旨意所預定的，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 1:6; 耶利米書 17:5–7; 以弗所書 1:13–14"> 叫他的榮耀從我們這首先在基督裡有盼望的人，可以得著稱讚。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 1:22; 以弗所書 4:30; 提摩太後書 2:19"> 你們既聽見真理的道，就是那叫你們得救的福音，也信了基督，既然信他，就受了所應許的聖靈為印記。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 1:22; 哥林多後書 5:5; 以弗所書 4:30"> 這聖靈是我們得基業的憑據<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：質。">b</a></sup>，直等到神之民<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「民」原文作「產業」。">c</a></sup>被贖，使他的榮耀得著稱讚。</span>
</div>
</div>

## 指望天上的基業

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="腓利門書 1:5; 歌羅西書 1:3–4; 帖撒羅尼迦後書 1:3"> 因此，我既聽見你們信從主耶穌，親愛眾聖徒，</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 1:8–9; 歌羅西書 1:9; 歌羅西書 1:3"> 就為你們不住地感謝神，禱告的時候常提到你們，</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 11:2; 雅各書 3:17–18; 歌羅西書 1:9–10"> 求我們主耶穌基督的神、榮耀的父，將那賜人智慧和啟示的靈賞給你們，使你們真知道他。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:18; 哥林多後書 4:6; 路加福音 24:45"> 並且照明你們心中的眼睛，使你們知道他的恩召有何等指望，他在聖徒中得的基業有何等豐盛的榮耀；</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 2:13; 以弗所書 3:20; 歌羅西書 2:12"> 並知道他向我們這信的人所顯的能力是何等浩大，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 10:12; 馬可福音 16:19; 詩篇 110:1"> 就是照他在基督身上所運行的大能大力，使他從死裡復活，叫他在天上坐在自己的右邊，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:9–11; 歌羅西書 2:10; 歌羅西書 1:15–16"> 遠超過一切執政的、掌權的、有能的、主治的和一切有名的，不但是今世的，連來世的也都超過了；</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 1:18; 歌羅西書 2:10; 哥林多前書 15:25–27"> 又將萬有服在他的腳下，使他為教會做萬有之首。</span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:18–19; 約翰福音 1:16; 歌羅西書 2:9–10"> 教會是他的身體，是那充滿萬有者所充滿的。</span>
</div>
</div>

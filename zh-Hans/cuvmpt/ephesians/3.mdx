## 奉命傳福音於外邦人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:24; 提摩太後書 1:8; 腓立比書 1:13–16"> 因此，我保羅——為你們外邦人做了基督耶穌被囚的，替你們祈禱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此句是對照14節所加。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 1:25–27; 提摩太前書 1:11; 提摩太後書 1:11"> 諒必你們曾聽見神賜恩給我，將關切你們的職分託付我，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 1:12; 羅馬書 16:25; 以弗所書 1:9–11"> 用啟示使我知道福音的奧祕，正如我以前略略寫過的。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 4:3; 哥林多前書 4:1; 哥林多後書 11:6"> 你們念了，就能曉得我深知基督的奧祕。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:10–12; 彼得後書 3:2; 提多書 1:1–3"> 這奧祕在以前的世代沒有叫人知道，像如今藉著聖靈啟示他的聖使徒和先知一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:26–29; 約翰一書 1:3; 約翰一書 2:25"> 這奧祕就是外邦人在基督耶穌裡，藉著福音，得以同為後嗣，同為一體，同蒙應許。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 1:19; 以弗所書 3:20; 以弗所書 3:2"> 我做了這福音的執事，是照神的恩賜，這恩賜是照他運行的大能賜給我的。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 1:27; 哥林多前書 15:9; 以弗所書 2:7"> 我本來比眾聖徒中最小的還小，然而他還賜我這恩典，叫我把基督那測不透的豐富傳給外邦人，</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:26; 馬太福音 13:35; 提摩太後書 1:9"> 又使眾人都明白，這歷代以來隱藏在創造萬物之神裡的奧祕是如何安排的，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 1:12; 以弗所書 6:12; 哥林多前書 2:7"> 為要藉著教會，使天上執政的、掌權的現在得知神百般的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 1:9; 以弗所書 1:11; 以弗所書 1:4"> 這是照神從萬世以前在我們主基督耶穌裡所定的旨意。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 2:18; 羅馬書 5:2; 希伯來書 4:14–16"> 我們因信耶穌，就在他裡面放膽無懼，篤信不疑地來到神面前。</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:24; 帖撒羅尼迦後書 3:13; 哥林多後書 1:6"> 所以，我求你們不要因我為你們所受的患難喪膽，這原是你們的榮耀。</span>
</div>
</div>

## 基督有莫測之愛

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 95:6; 以弗所書 1:16–19; 腓立比書 2:10"> 因此，我在父面前屈膝——</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 1:10; 啟示錄 5:8–14; 以弗所書 1:21"> 天上地上的各<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：全。">b</a></sup>家，都是從他得名——</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:11; 腓立比書 4:13; 以賽亞書 40:29–31"> 求他按著他豐盛的榮耀，藉著他的靈，叫你們心裡的力量剛強起來，</span>
<span className="v" id="v17" data-v="17" data-xref="歌羅西書 2:7; 約翰一書 4:16; 約翰福音 14:23"> 使基督因你們的信住在你們心裡，叫你們的愛心有根有基，</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 103:11–12; 約伯記 11:7–9; 以弗所書 1:18–23"> 能以和眾聖徒一同明白基督的愛是何等長闊高深，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 1:23; 歌羅西書 2:9–10; 歌羅西書 1:10"> 並知道這愛是過於人所能測度的，便叫神一切所充滿的充滿了你們。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 9:8; 羅馬書 4:21; 耶利米書 32:27"> 神能照著運行在我們心裡的大力，充充足足地成就一切，超過我們所求所想的。</span>
<span className="v" id="v21" data-v="21" data-xref="猶大書 1:25; 羅馬書 11:36; 彼得後書 3:18"> 但願他在教會中，並在基督耶穌裡得著榮耀，直到世世代代，永永遠遠！阿們。</span>
</div>
</div>

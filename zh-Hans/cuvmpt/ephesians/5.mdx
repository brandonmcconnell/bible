## 當憑愛心行事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 4:11; 彼得前書 1:15–16; 以弗所書 4:32"> 所以你們該效法神，好像蒙慈愛的兒女一樣。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 13:34; 加拉太書 2:20; 歌羅西書 3:14"> 也要憑愛心行事，正如基督愛我們，為我們捨了自己，當做馨香的供物和祭物獻於神。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 3:5; 以弗所書 5:5; 加拉太書 5:19–21"> 至於淫亂並一切汙穢，或是貪婪，在你們中間連提都不可，方合聖徒的體統。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:8; 以弗所書 4:29; 帖撒羅尼迦前書 5:18"> 淫詞、妄語和戲笑的話都不相宜，總要說感謝的話。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:21; 哥林多前書 6:9–10; 以弗所書 5:3"> 因為你們確實地知道，無論是淫亂的，是汙穢的，是有貪心的，在基督和神的國裡都是無份的；有貪心的，就與拜偶像的一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 1:18; 歌羅西書 2:8; 馬太福音 24:4"> 不要被人虛浮的話欺哄，因這些事，神的憤怒必臨到那悖逆之子。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 18:4; 以弗所書 5:11; 提摩太前書 5:22"> 所以你們不要與他們同夥。</span>
</div>
</div>

## 當像光明的子女

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 8:12; 約翰一書 1:7; 使徒行傳 26:18"> 從前你們是暗昧的，但如今在主裡面是光明的，行事為人就當像光明的子女——</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 3:9–10; 加拉太書 5:22–23; 約翰三書 1:11"> 光明所結的果子就是一切良善、公義、誠實——</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:1–2; 希伯來書 12:28; 詩篇 19:14"> 總要察驗何為主所喜悅的事。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 13:12; 提摩太前書 5:20; 帖撒羅尼迦後書 3:6"> 那暗昧無益的事不要與人同行，倒要責備行這事的人，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:3; 耶利米書 23:24; 傳道書 12:14"> 因為他們暗中所行的，就是提起來也是可恥的。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 3:20–21; 哥林多前書 4:5; 何西阿書 2:10"> 凡事受了責備，就被光顯明出來，因為一切能顯明的就是光。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 60:1; 羅馬書 13:11–12; 以賽亞書 26:19"> 所以主說：<br /><span className="pl pl-1">「你這睡著的人，當醒過來，</span><br /><span className="pl pl-1">從死裡復活，</span><br /><span className="pl pl-1">基督就要光照你了！」</span></span>
</div>
</div>

## 愛惜光陰

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 4:5; 雅各書 3:13; 腓立比書 1:27"> 你們要謹慎行事，不要像愚昧人，當像智慧人。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 4:5; 阿摩司書 5:13; 約翰福音 12:35"> 要愛惜光陰，因為現今的世代邪惡。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:2; 帖撒羅尼迦前書 5:18; 歌羅西書 1:9"> 不要做糊塗人，要明白主的旨意如何。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 羅馬書 13:13"> 不要醉酒，酒能使人放蕩；乃要被聖靈充滿。</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:16; 哥林多前書 14:26; 詩篇 95:2"> 當用詩章、頌詞、靈歌彼此對說，口唱心和地讚美主。</span>
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 3:17; 帖撒羅尼迦前書 5:18; 希伯來書 13:15"> 凡事要奉我們主耶穌基督的名常常感謝父神。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:3; 以弗所書 5:24; 以弗所書 5:22"> 又當存敬畏基督的心，彼此順服。</span>
</div>
</div>

## 夫妻的本分

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:18–1; 彼得前書 3:1–6; 提多書 2:5"> 你們做妻子的，當順服自己的丈夫，如同順服主；</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 11:3–10; 歌羅西書 1:18; 以弗所書 1:22–23"> 因為丈夫是妻子的頭，如同基督是教會的頭，他又是教會全體的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 5:33; 歌羅西書 3:20; 提多書 2:7"> 教會怎樣順服基督，妻子也要怎樣凡事順服丈夫。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 3:7; 歌羅西書 3:19; 以弗所書 5:28"> 你們做丈夫的，要愛你們的妻子，正如基督愛教會，為教會捨己，</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 10:22; 約翰福音 15:3; 以西結書 36:25"> 要用水藉著道把教會洗淨，成為聖潔，</span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 1:22; 希伯來書 9:14; 彼得前書 1:19"> 可以獻給自己，做個榮耀的教會，毫無玷汙、皺紋等類的病，乃是聖潔沒有瑕疵的。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 5:25; 馬太福音 19:5; 創世記 2:21–24"> 丈夫也當照樣愛妻子，如同愛自己的身子，愛妻子便是愛自己了。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 34:14–15; 以弗所書 5:31; 傳道書 4:5"> 從來沒有人恨惡自己的身子，總是保養顧惜，正像基督待教會一樣，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 6:15; 哥林多前書 12:12–27; 羅馬書 12:5"> 因我們是他身上的肢體<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：就是他的骨，他的肉。">a</a></sup>。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 2:24; 馬太福音 19:5; 馬可福音 10:7–8"> 為這個緣故，人要離開父母，與妻子聯合，二人成為一體。</span>
<span className="v" id="v32" data-v="32" data-xref="啟示錄 21:2; 哥林多後書 11:2; 以賽亞書 54:5"> 這是極大的奧祕，但我是指著基督和教會說的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 3:2–7; 以斯帖記 1:20; 以弗所書 5:25"> 然而你們各人都當愛妻子，如同愛自己一樣；妻子也當敬重她的丈夫。</span>
</div>
</div>

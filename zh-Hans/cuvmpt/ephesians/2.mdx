## 得救是本乎恩也因著信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 2:13; 以弗所書 2:5–6; 歌羅西書 3:1–4"> 你們死在過犯罪惡之中，他叫你們活過來。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:12; 約翰一書 5:19; 以弗所書 2:3"> 那時你們在其中行事為人，隨從今世的風俗，順服空中掌權者的首領，就是現今在悖逆之子心中運行的邪靈。</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 3:3; 以弗所書 4:22; 加拉太書 5:16–24"> 我們從前也都在他們中間，放縱肉體的私慾，隨著肉體和心中所喜好的去行，本為可怒之子，和別人一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 1:3; 以弗所書 1:7; 詩篇 86:15"> 然而，神既有豐富的憐憫，因他愛我們的大愛，</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 3:24; 以弗所書 2:8; 羅馬書 5:10"> 當我們死在過犯中的時候，便叫我們與基督一同活過來。你們得救是本乎恩。</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:1–3; 以弗所書 1:3; 羅馬書 6:4–5"> 他又叫我們與基督耶穌一同復活，一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 1:16–17; 提多書 3:4; 以弗所書 2:4"> 要將他極豐富的恩典，就是他在基督耶穌裡向我們所施的恩慈，顯明給後來的世代看。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:22–26; 以弗所書 2:5; 羅馬書 4:16"> 你們得救是本乎恩，也因著信。這並不是出於自己，乃是神所賜的；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 1:9; 羅馬書 11:6; 提多書 3:3–5"> 也不是出於行為，免得有人自誇。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:13; 歌羅西書 1:10; 希伯來書 13:21"> 我們原是他的工作，在基督耶穌裡造成的，為要叫我們行善，就是神所預備叫我們行的。</span>
</div>
</div>

## 從前門徒不知道神

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌羅西書 2:11; 歌羅西書 2:13; 歌羅西書 3:11"> 所以你們應當記念：你們從前按肉體是外邦人，是稱為沒受割禮的，這名原是那些憑人手在肉身上稱為受割禮之人所起的；</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 4:8; 歌羅西書 1:21; 耶利米書 31:31–34"> 那時你們與基督無關，在以色列國民以外，在所應許的諸約上是局外人，並且活在世上沒有指望，沒有神。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 2:39; 歌羅西書 1:20–22; 歌羅西書 1:13–14"> 你們從前遠離神的人，如今卻在基督耶穌裡，靠著他的血，已經得親近了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:28; 歌羅西書 3:11; 歌羅西書 3:15"> 因他使我們和睦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：因他是我們的和睦。">a</a></sup>，將兩下合而為一，拆毀了中間隔斷的牆，</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 2:14; 加拉太書 3:10; 歌羅西書 1:21–22"> 而且以自己的身體廢掉冤仇，就是那記在律法上的規條，為要將兩下藉著自己造成一個新人，如此便成就了和睦。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:20–22; 羅馬書 5:10; 哥林多後書 5:18–21"> 既在十字架上滅了冤仇，便藉這十字架，使兩下歸為一體，與神和好了。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 57:19–21; 使徒行傳 10:36; 羅馬書 5:1"> 並且來傳和平的福音給你們遠處的人，也給那近處的人；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 12:13; 以弗所書 3:12; 羅馬書 5:2"> 因為我們兩下藉著他被一個聖靈所感，得以進到父面前。</span>
</div>
</div>

## 如今是神家裡的人

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="腓立比書 3:20; 約翰一書 3:1; 加拉太書 6:10"> 這樣，你們不再做外人和客旅，是與聖徒同國，是神家裡的人了。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:4–5; 以賽亞書 28:16; 彼得前書 2:7–8"> 並且被建造在使徒和先知的根基上，有基督耶穌自己為房角石，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 3:16–17; 哥林多前書 3:9; 哥林多後書 6:16"> 各<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：全。">b</a></sup>房靠他聯絡得合式，漸漸成為主的聖殿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:4–5; 哥林多前書 3:16; 約翰一書 4:16"> 你們也靠他同被建造，成為神藉著聖靈居住的所在。</span>
</div>
</div>

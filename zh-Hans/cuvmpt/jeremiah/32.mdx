## 西底家因耶利米預言而囚之

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 39:1–2; 列王紀下 25:1–2; 耶利米書 25:1"> 猶大王西底家第十年，就是尼布甲尼撒十八年，耶和華的話臨到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 37:21; 尼希米記 3:25; 耶利米書 33:1"> 那時巴比倫王的軍隊圍困耶路撒冷，先知耶利米囚在護衛兵的院內，在猶大王的宮中。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 34:2–3; 耶利米書 21:4–7; 耶利米書 26:8–9"> 因為猶大王西底家已將他囚禁，說：「你為什麼預言說『耶和華如此說：我必將這城交在巴比倫王的手中，他必攻取這城。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:4–7; 列王紀下 25:4–7; 耶利米書 37:17"> 猶大王西底家必不能逃脫迦勒底人的手，定要交在巴比倫王的手中，要口對口彼此說話，眼對眼彼此相看。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 39:7; 以西結書 17:9–10; 以西結書 17:15"> 巴比倫王必將西底家帶到巴比倫，西底家必住在那裡，直到我眷顧他的時候。你們雖與迦勒底人爭戰，卻不順利。這是耶和華說的』？」</span>
</div>
</div>

## 耶利米購哈拿篾之田

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶利米說：耶和華的話臨到我說：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 1:1; 耶利米書 11:21; 利未記 25:25"> 「你叔叔沙龍的兒子哈拿篾必來見你，說：『我在亞拿突的那塊地，求你買來，因你買這地是合乎贖回之理。』」</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 32:7; 耶利米書 32:2; 耶利米書 33:1"> 我叔叔的兒子哈拿篾果然照耶和華的話來到護衛兵的院內，對我說：「我在便雅憫境內亞拿突的那塊地，求你買來，因你買來是合乎承受之理，是你當贖的。你為自己買來吧。」我耶利米就知道這是耶和華的話。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 11:12–13; 以斯帖記 3:9; 列王紀上 20:39"> 我便向我叔叔的兒子哈拿篾買了亞拿突的那塊地，平了十七舍客勒銀子給他。</span>
</div>
</div>

## 命付田契於巴錄

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:44; 耶利米書 32:12; 耶利米書 32:25"> 我在契上畫押，將契封緘，又請見證人來，並用天平將銀子平給他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前書 11:16; 使徒行傳 26:3"> 我便將照例按規所立的買契，就是封緘的那一張和敞著的那一張，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 32:16; 耶利米書 51:59; 耶利米書 36:4–5"> 當著我叔叔的兒子哈拿篾和畫押做見證的人，並坐在護衛兵院內的一切猶大人眼前，交給瑪西雅的孫子、尼利亞的兒子巴錄。</span>
<span className="v" id="v13" data-v="13"> 當著他們眾人眼前，我囑咐巴錄說：</span>
<span className="v" id="v14" data-v="14"> 「萬軍之耶和華以色列的神如此說：要將這封緘的和敞著的兩張契放在瓦器裡，可以存留多日。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 3:10; 阿摩司書 9:14–15; 耶利米書 30:18"> 因為萬軍之耶和華以色列的神如此說：將來在這地必有人再買房屋、田地和葡萄園。」</span>
</div>
</div>

## 耶利米祈禱

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 12:1; 創世記 32:9–12; 腓立比書 4:6–7"> 我將買契交給尼利亞的兒子巴錄以後，便禱告耶和華說：</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米書 32:27; 創世記 18:14"> 「主耶和華啊，你曾用大能和伸出來的膀臂創造天地，在你沒有難成的事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 10:16; 申命記 5:9–10; 出埃及記 34:7"> 你施慈愛於千萬人，又將父親的罪孽報應在他後世子孫的懷中，是至大全能的神，萬軍之耶和華是你的名。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 17:10; 馬太福音 16:27; 詩篇 62:12"> 謀事有大略，行事有大能，注目觀看世人一切的舉動，為要照各人所行的和他做事的結果報應他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 9:10; 撒母耳記下 7:23; 出埃及記 10:2"> 在埃及地顯神蹟奇事，直到今日在以色列和別人中間也是如此，使自己得了名聲，正如今日一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 6:6; 申命記 26:8; 詩篇 105:43"> 用神蹟奇事和大能的手，並伸出來的膀臂與大可畏的事，領你的百姓以色列出了埃及，</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 3:8; 出埃及記 13:5; 耶利米書 11:5"> 將這地賜給他們，就是你向他們列祖起誓應許賜給他們流奶與蜜之地。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:7; 詩篇 78:54–55; 但以理書 9:10–14"> 他們進入這地得了為業，卻不聽從你的話，也不遵行你的律法。你一切所吩咐他們行的，他們一無所行。因此，你使這一切的災禍臨到他們。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 32:36; 申命記 4:26; 約書亞記 23:15–16"> 看哪，敵人已經來到，築壘要攻取這城，城也因刀劍、饑荒、瘟疫交在攻城的迦勒底人手中。你所說的話都成就了，你也看見了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 32:24; 詩篇 97:2; 詩篇 77:19"> 主耶和華啊，你對我說『要用銀子為自己買那塊地，又請見證人』，其實這城已交在迦勒底人的手中了。」</span>
</div>
</div>

## 耶和華以民擄城毀示耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:26; 耶利米書 32:17; 以賽亞書 64:8"> 「我是耶和華，是凡有血氣者的神，豈有我難成的事嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 32:3; 耶利米書 32:24; 耶利米書 19:7–12"> 耶和華如此說：我必將這城交付迦勒底人的手和巴比倫王尼布甲尼撒的手，他必攻取這城。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 21:10; 耶利米書 19:13; 耶利米書 52:13"> 攻城的迦勒底人必來放火焚燒這城和其中的房屋，在這房屋上，人曾向巴力燒香，向別神澆奠，惹我發怒。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 7:22–26; 申命記 9:7–12; 耶利米書 25:7"> 以色列人和猶大人自從幼年以來，專行我眼中看為惡的事，以色列人盡以手所做的惹我發怒。這是耶和華說的。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:27; 耶利米書 27:10; 列王紀下 21:4–7"> 這城自從建造的那日直到今日，常惹我的怒氣和憤怒，使我將這城從我面前除掉。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理書 9:8; 耶利米書 2:26; 以賽亞書 1:4–6"> 是因以色列人和猶大人一切的邪惡，就是他們和他們的君王、首領、祭司、先知，並猶大的眾人以及耶路撒冷的居民所行的，惹我發怒。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 7:13; 耶利米書 2:27; 以西結書 8:16"> 他們以背向我，不以面向我。我雖從早起來教訓他們，他們卻不聽從，不受教訓，</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 7:30; 以西結書 8:5–16; 列王紀下 21:4–7"> 竟把可憎之物設立在稱為我名下的殿中，汙穢了這殿。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 7:31; 歷代志下 33:6; 利未記 18:21"> 他們在欣嫩子谷建築巴力的丘壇，好使自己的兒女經火歸摩洛，他們行這可憎的事，使猶大陷在罪裡。這並不是我所吩咐的，也不是我心所起的意。</span>
</div>
</div>

## 後必導民復歸故土

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米書 32:24; 耶利米書 32:3; 耶利米書 32:28"> 「現在論到這城，就是你們所說已經因刀劍、饑荒、瘟疫交在巴比倫王手中的，耶和華以色列的神如此說：</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 23:3; 耶利米書 23:6; 以西結書 34:12–14"> 我在怒氣、憤怒和大惱恨中將以色列人趕到各國，日後我必從那裡將他們招聚出來，領他們回到此地，使他們安然居住。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 24:7; 以西結書 11:19–20; 希伯來書 8:10"> 他們要做我的子民，我要做他們的神。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 11:19–20; 使徒行傳 4:32; 約翰福音 17:21"> 我要使他們彼此同心同道，好叫他們永遠敬畏我，使他們和他們後世的子孫得福樂。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米書 31:31–33; 以西結書 36:26; 耶利米書 24:7"> 又要與他們立永遠的約，必隨著他們施恩，並不離開他們，且使他們有敬畏我的心，不離開我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 24:6; 西番雅書 3:17; 以賽亞書 62:5"> 我必歡喜施恩於他們，要盡心、盡意，誠誠實實將他們栽於此地。</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 31:28; 約書亞記 23:14–15; 耶利米書 33:10–11"> 因為耶和華如此說：我怎樣使這一切大禍臨到這百姓，我也要照樣使我所應許他們的一切福樂都臨到他們。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 37:11–14; 耶利米書 32:15; 耶利米書 32:36"> 你們說『這地是荒涼無人民、無牲畜，是交付迦勒底人手之地』，日後在這境內必有人置買田地。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米書 17:26; 耶利米書 33:26; 耶利米書 33:11"> 在便雅憫地、耶路撒冷四圍的各處、猶大的城邑、山地的城邑、高原的城邑並南地的城邑，人必用銀子買田地，在契上畫押，將契封緘，請出見證人，因為我必使被擄的人歸回。這是耶和華說的。」</span>
</div>

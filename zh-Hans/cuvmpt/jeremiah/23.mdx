## 預言四散之群必復集旋返

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 10:21; 撒迦利亞書 11:15–17; 以西結書 34:2–10"> 耶和華說：「那些殘害、趕散我草場之羊的牧人有禍了！」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 32:34; 耶利米書 21:12; 彌迦書 7:4"> 耶和華以色列的神斥責那些牧養他百姓的牧人，如此說：「你們趕散我的羊群，並沒有看顧他們，我必討你們這行惡的罪。」這是耶和華說的。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 9:14–15; 耶利米書 32:37; 以賽亞書 43:5–6"> 「我要將我羊群中所餘剩的，從我趕他們到的各國內招聚出來，領他們歸回本圈，他們也必生養眾多。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 3:14–15; 彼得前書 1:5; 以西結書 34:23–31"> 我必設立照管他們的牧人牧養他們，他們不再懼怕，不再驚惶，也不缺少一個。」這是耶和華說的。</span>
</div>
</div>

## 大衛後裔中必興起義者為王

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 1:32–33; 以賽亞書 4:2; 以賽亞書 9:7"> 耶和華說：「日子將到，我要給大衛興起一個公義的苗裔。他必掌王權，行事有智慧，在地上施行公平和公義。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 1:30; 耶利米書 33:16; 腓立比書 3:9"> 在他的日子，猶大必得救，以色列也安然居住，他的名必稱為『耶和華我們的義』。」</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 16:14–15; 耶利米書 23:3; 以賽亞書 43:18–19"> 耶和華說：「日子將到，人必不再指著那領以色列人從埃及地上來永生的耶和華起誓，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 43:5–6; 阿摩司書 9:14–15; 以西結書 34:13"> 卻要指著那領以色列家的後裔從北方和趕他們到的各國中上來永生的耶和華起誓。他們必住在本地。」</span>
</div>
</div>

## 論偽先知之惡及所受之報

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="哈巴谷書 3:16; 耶利米哀歌 3:15; 詩篇 60:3"> <span className="pl pl-1">論到那些先知，</span><br /><span className="pl pl-1">我心在我裡面憂傷，</span><br /><span className="pl pl-1">我骨頭都發顫。</span><br /><span className="pl pl-1">因耶和華和他的聖言，</span><br /><span className="pl pl-1">我像醉酒的人，</span><br /><span className="pl pl-1">像被酒所勝的人。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 4:2–3; 詩篇 107:34; 耶利米書 9:2"> <span className="pl pl-1">地滿了行淫的人。</span><br /><span className="pl pl-1">因妄自賭咒，地就悲哀，</span><br /><span className="pl pl-1">曠野的草場都枯乾了。</span><br /><span className="pl pl-1">他們所行的道乃是惡的，</span><br /><span className="pl pl-1">他們的勇力使得不正。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="西番雅書 3:4; 耶利米書 6:13; 馬太福音 21:12–13"> <span className="pl pl-1">「連先知帶祭司都是褻瀆的，</span><br /><span className="pl pl-1">就是在我殿中我也看見他們的惡。」</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 13:16; 耶利米書 11:23; 詩篇 35:6"> <span className="pl pl-1">「因此，他們的道路必像黑暗中的滑地，</span><br /><span className="pl pl-1">他們必被追趕在這路中仆倒。</span><br /><span className="pl pl-1">因為當追討之年，</span><br /><span className="pl pl-1">我必使災禍臨到他們。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:8; 以賽亞書 9:16; 列王紀上 18:18–21"> <span className="pl pl-1">「我在撒馬利亞的先知中曾見愚妄，</span><br /><span className="pl pl-1">他們藉巴力說預言，</span><br /><span className="pl pl-1">使我的百姓以色列走錯了路。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 1:9–10; 耶利米書 29:23; 以西結書 22:25"> <span className="pl pl-1">我在耶路撒冷的先知中曾見可憎惡的事，</span><br /><span className="pl pl-1">他們行姦淫，做事虛妄，</span><br /><span className="pl pl-1">又堅固惡人的手，</span><br /><span className="pl pl-1">甚至無人回頭離開他的惡。</span><br /><span className="pl pl-1">他們在我面前都像所多瑪，</span><br /><span className="pl pl-1">耶路撒冷的居民都像蛾摩拉。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 8:14; 耶利米書 9:15; 耶利米哀歌 3:5"> 所以萬軍之耶和華論到先知如此說：<br /><span className="pl pl-1">「我必將茵陳給他們吃，</span><br /><span className="pl pl-1">又將苦膽水給他們喝，</span><br /><span className="pl pl-1">因為褻瀆的事出於耶路撒冷的先知，流行遍地。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 14:14; 以西結書 13:6; 加拉太書 1:8–9"> 萬軍之耶和華如此說：「這些先知向你們說預言，你們不要聽他們的話。他們以虛空教訓你們，所說的異象是出於自己的心，不是出於耶和華的口。</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 3:11; 耶利米書 13:10; 阿摩司書 9:10"> 他們常對藐視我的人說：『耶和華說，你們必享平安。』又對一切按自己頑梗之心而行的人說：『必沒有災禍臨到你們。』」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:22; 以賽亞書 40:13–14; 阿摩司書 3:7"> <span className="pl pl-1">有誰站在耶和華的會中</span><br /><span className="pl pl-1">得以聽見並會悟他的話呢？</span><br /><span className="pl pl-1">有誰留心聽他的話呢？</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 30:23; 耶利米書 25:32; 阿摩司書 1:14"> <span className="pl pl-1">看哪，耶和華的憤怒</span><br /><span className="pl pl-1">好像暴風，已經發出，</span><br /><span className="pl pl-1">是暴烈的旋風，</span><br /><span className="pl pl-1">必轉到惡人的頭上。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 30:24; 以賽亞書 55:11; 撒迦利亞書 1:6"> <span className="pl pl-1">耶和華的怒氣必不轉消，</span><br /><span className="pl pl-1">直到他心中所擬定的成就了，</span><br /><span className="pl pl-1">末後的日子你們要全然明白。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:14; 耶利米書 27:15; 耶利米書 23:32"> <span className="pl pl-1">「我沒有打發那些先知，</span><br /><span className="pl pl-1">他們竟自奔跑；</span><br /><span className="pl pl-1">我沒有對他們說話，</span><br /><span className="pl pl-1">他們竟自預言。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:18; 撒迦利亞書 1:4; 耶利米書 25:5"> <span className="pl pl-1">他們若是站在我的會中，</span><br /><span className="pl pl-1">就必使我的百姓聽我的話，</span><br /><span className="pl pl-1">又使他們回頭離開惡道和他們所行的惡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 139:1–10; 列王紀上 20:23; 列王紀上 20:28"> 耶和華說：「我豈為近處的神呢？不也為遠處的神嗎？」</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:3; 詩篇 139:7; 詩篇 90:8"> 耶和華說：「人豈能在隱密處藏身，使我看不見他呢？」耶和華說：「我豈不充滿天地嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 23:32; 耶利米書 23:28; 耶利米書 29:8"> 我已聽見那些先知所說的，就是託我名說的假預言，他們說：『我做了夢！我做了夢！』</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 4:1–2; 耶利米書 14:14; 帖撒羅尼迦後書 2:9–11"> 說假預言的先知，就是預言本心詭詐的先知，他們這樣存心要到幾時呢？</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 8:33–34; 士師記 3:7; 使徒行傳 13:8"> 他們各人將所做的夢對鄰舍述說，想要使我的百姓忘記我的名，正如他們列祖因巴力忘記我的名一樣。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多後書 2:17; 提摩太前書 1:12; 哥林多前書 3:12–13"> 得夢的先知可以述說那夢，得我話的人可以誠實講說我的話！糠秕怎能與麥子比較呢？」這是耶和華說的。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 4:12; 耶利米書 5:14; 路加福音 24:32"> 耶和華說：「我的話豈不像火，又像能打碎磐石的大錘嗎？」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 18:20; 以西結書 13:8; 耶利米書 14:14–15"> 耶和華說：「那些先知各從鄰舍偷竊我的言語，因此我必與他們反對。」</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 23:17; 歷代志下 18:10–12; 歷代志下 18:5"> 耶和華說：「那些先知用舌頭說『是耶和華說的』，我必與他們反對。」</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 13:7–18; 西番雅書 3:4; 耶利米哀歌 2:14"> 耶和華說：「那些以幻夢為預言，又述說這夢，以謊言和矜誇使我百姓走錯了路的，我必與他們反對。我沒有打發他們，也沒有吩咐他們，他們與這百姓毫無益處。」這是耶和華說的。</span>
</div>

## 譏真先知者必受罰

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="瑪拉基書 1:1; 耶利米書 12:7; 哈巴谷書 1:1"> 「無論是百姓，是先知，是祭司，問你說：『耶和華有什麼默示呢？』你就對他們說：『什麼默示啊？耶和華說：我要撇棄你們！』</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 13:3; 耶利米哀歌 2:14"> 無論是先知，是祭司，是百姓，說『耶和華的默示』，我必刑罰那人和他的家。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 31:34; 耶利米書 42:4; 耶利米書 33:3"> 你們各人要對鄰舍，各人要對弟兄如此說：『耶和華回答什麼？耶和華說了什麼呢？』</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 10:10; 彼得後書 3:16; 以賽亞書 3:8"> 『耶和華的默示』你們不可再提，各人所說的話必做自己的重擔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「重擔」和「默示」原文同。">a</a></sup>，因為你們謬用永生神萬軍之耶和華我們神的言語。</span>
<span className="v" id="v37" data-v="37"> 你們要對先知如此說：『耶和華回答你什麼？耶和華說了什麼呢？』</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志下 11:13–14"> 你們若說『耶和華的默示』，耶和華就如此說：因你們說『耶和華的默示』這句話，我也打發人到你們那裡去，告訴你們不可說『耶和華的默示』，</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米書 23:33; 以西結書 8:18; 箴言 13:13"> 所以我必全然忘記你們，將你們和我所賜給你們並你們列祖的城撇棄了。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米書 20:11; 以西結書 5:14–15; 耶利米書 42:18"> 又必使永遠的凌辱和長久的羞恥臨到你們，是不能忘記的。」</span>
</div>

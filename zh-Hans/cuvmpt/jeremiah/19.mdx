## 以毀瓶為喻明示猶大國必滅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:11–12; 以賽亞書 30:14; 耶利米哀歌 4:2"> 耶和華如此說：「你去買窯匠的瓦瓶，又帶百姓中的長老和祭司中的長老，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 15:8; 列王紀下 23:10; 耶利米書 7:31–32"> 出去到欣嫩子谷，哈珥西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「哈珥西」就是「瓦片」的意思。">a</a></sup>的門口那裡，宣告我所吩咐你的話，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 3:11; 耶利米書 17:20; 以賽亞書 28:19"> 說：『猶大君王和耶路撒冷的居民哪，當聽耶和華的話！萬軍之耶和華以色列的神如此說：我必使災禍臨到這地方，凡聽見的人都必耳鳴。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 2:34; 申命記 28:20; 列王紀下 21:16"> 因為他們和他們列祖並猶大君王離棄我，將這地方看為平常，在這裡向素不認識的別神燒香，又使這地方滿了無辜人的血。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:35; 申命記 12:31; 利未記 18:21"> 又建築巴力的丘壇，好在火中焚燒自己的兒子，作為燔祭獻給巴力。這不是我所吩咐的，不是我所提說的，也不是我心所起的意。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 15:8; 以賽亞書 30:33; 耶利米書 19:2"> 耶和華說：因此，日子將到，這地方不再稱為陀斐特和欣嫩子谷，反倒稱為殺戮谷。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 26:17; 耶利米書 16:4; 詩篇 33:10–11"> 我必在這地方使猶大和耶路撒冷的計謀落空，也必使他們在仇敵面前倒於刀下，並尋索其命的人手下。他們的屍首，我必給空中的飛鳥和地上的野獸做食物。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 18:16; 耶利米書 49:13; 列王紀上 9:8"> 我必使這城令人驚駭、嗤笑，凡經過的人必因這城所遭的災驚駭、嗤笑。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 9:20; 利未記 26:29; 耶利米哀歌 4:10"> 我必使他們在圍困窘迫之中，就是仇敵和尋索其命的人窘迫他們的時候，各人吃自己兒女的肉和朋友的肉。』</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 51:63–64; 耶利米書 48:12; 耶利米書 19:1"> 「你要在同去的人眼前打碎那瓶，</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:9; 以賽亞書 30:14; 耶利米哀歌 4:2"> 對他們說：『萬軍之耶和華如此說：我要照樣打碎這民和這城，正如人打碎窯匠的瓦器，以致不能再囫圇。並且人要在陀斐特葬埋屍首，甚至無處可葬。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 10:13; 耶利米書 11:5"> 耶和華說：我必向這地方和其中的居民如此行，使這城與陀斐特一樣。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 32:29; 列王紀下 23:12; 西番雅書 1:5"> 耶路撒冷的房屋和猶大君王的宮殿是已經被玷汙的，就是他們在其上向天上的萬象燒香、向別神澆奠祭的宮殿房屋，都必與陀斐特一樣。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 26:2; 歷代志下 20:5; 耶利米書 19:2–3"> 耶利米從陀斐特，就是耶和華差他去說預言的地方回來，站在耶和華殿的院中，對眾人說：</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 7:26; 耶利米書 17:23; 尼希米記 9:29"> 「萬軍之耶和華以色列的神如此說：我必使我所說的一切災禍臨到這城和屬城的一切城邑，因為他們硬著頸項不聽我的話。」</span>
</div>

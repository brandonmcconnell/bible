## 預言摩押必受懲罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 32:3; 民數記 32:37–38; 耶利米書 48:22–23"> 論摩押。萬軍之耶和華以色列的神如此說：<br /><span className="pl pl-1">「尼波有禍了，因變為荒場。</span><br /><span className="pl pl-1">基列亭蒙羞被攻取，</span><br /><span className="pl pl-1">米斯迦蒙羞被毀壞。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民數記 32:37; 耶利米書 31:36; 以賽亞書 16:14"> <span className="pl pl-1">摩押不再被稱讚，</span><br /><span className="pl pl-1">有人在希實本設計謀害她說：</span><br /><span className="pl pl-1">『來吧！我們將她剪除，不再成國。』</span><br /><span className="pl pl-1">瑪得緬哪，你也必默默無聲，</span><br /><span className="pl pl-1">刀劍必追趕你。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 15:5; 耶利米書 48:34; 耶利米書 48:5"> <span className="pl pl-1">從何羅念有喊荒涼大毀滅的哀聲。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 137:9; 民數記 21:27–30; 以斯帖記 8:11"> <span className="pl pl-1">摩押毀滅了，</span><br /><span className="pl pl-1">她的孩童</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：家童。">a</a></sup><br /><span className="pl pl-1">發哀聲，使人聽見。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 15:5"> <span className="pl pl-1">人上魯希坡隨走隨哭，</span><br /><span className="pl pl-1">因為在何羅念的下坡聽見毀滅的哀聲。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 17:6; 耶利米書 51:6; 約伯記 30:3–7"> <span className="pl pl-1">你們要奔逃，自救性命，</span><br /><span className="pl pl-1">獨自居住，好像曠野的杜松。</span></span>
</div>
</div>

## 因自恃財貨

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="民數記 21:29; 耶利米書 9:23; 詩篇 52:7"> <span className="pl pl-1">「你因倚靠自己所做的和自己的財寶，必被攻取，</span><br /><span className="pl pl-1">基抹和屬他的祭司、首領也要一同被擄去。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 6:26; 耶利米書 51:56; 耶利米書 25:9"> <span className="pl pl-1">行毀滅的必來到各城，</span><br /><span className="pl pl-1">並無一城得免。</span><br /><span className="pl pl-1">山谷必致敗落，</span><br /><span className="pl pl-1">平原必被毀壞，</span><br /><span className="pl pl-1">正如耶和華所說的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 11:1; 耶利米書 48:28; 以賽亞書 16:2"> <span className="pl pl-1">要將翅膀給摩押，</span><br /><span className="pl pl-1">使她可以飛去。</span><br /><span className="pl pl-1">她的城邑必致荒涼，</span><br /><span className="pl pl-1">無人居住。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:3; 列王紀上 20:42; 士師記 5:23"> 懶惰為耶和華行事的，必受咒詛；禁止刀劍不經血的，必受咒詛。</span>
</div>

## 因妄賴勇力

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="西番雅書 1:12; 撒迦利亞書 1:15; 耶利米書 48:29"> <span className="pl pl-1">「摩押自幼年以來常享安逸，</span><br /><span className="pl pl-1">如酒在渣滓上澄清，</span><br /><span className="pl pl-1">沒有從這器皿倒在那器皿裡，</span><br /><span className="pl pl-1">也未曾被擄去。</span><br /><span className="pl pl-1">因此她的原味尚存，</span><br /><span className="pl pl-1">香氣未變。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="那鴻書 2:2; 以賽亞書 30:14; 以西結書 25:9–10"> 耶和華說：「日子將到，我必打發倒酒的往她那裡去，將她倒出來，倒空她的器皿，打碎她的罈子。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 45:16; 士師記 11:24; 耶利米書 48:39"> 摩押必因基抹羞愧，像以色列家從前倚靠伯特利的神羞愧一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 33:16; 以賽亞書 10:13; 以賽亞書 10:16"> <span className="pl pl-1">你們怎麼說</span><br /><span className="pl pl-1">『我們是勇士，是有勇力打仗的』呢？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 50:27; 耶利米書 46:18; 耶利米書 51:57"> <span className="pl pl-1">摩押變為荒場，</span><br /><span className="pl pl-1">敵人上去進了她的城邑，</span><br /><span className="pl pl-1">她所特選的少年人下去遭了殺戮。」</span><br /><span className="pl pl-1">這是君王，名為萬軍之耶和華說的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 13:22; 耶利米書 1:12; 以西結書 12:28"> <span className="pl pl-1">「摩押的災殃臨近，</span><br /><span className="pl pl-1">她的苦難速速來到。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 9:4; 以賽亞書 14:4–5; 以西結書 19:11–14"> <span className="pl pl-1">凡在她四圍的和認識她名的，</span><br /><span className="pl pl-1">你們都要為她悲傷，說：</span><br /><span className="pl pl-1">『那結實的杖和那美好的棍</span><br /><span className="pl pl-1">何竟折斷了呢！』</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:30; 以賽亞書 47:1; 以賽亞書 15:2"> <span className="pl pl-1">住在底本的民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「民」原文作「女子」。">b</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">要從你榮耀的位上下來，</span><br /><span className="pl pl-1">坐受乾渴，</span><br /><span className="pl pl-1">因毀滅摩押的上來攻擊你，</span><br /><span className="pl pl-1">毀壞了你的保障。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:36; 撒母耳記上 4:16; 撒母耳記上 4:13–14"> <span className="pl pl-1">住亞羅珥的啊，</span><br /><span className="pl pl-1">要站在道旁觀望，</span><br /><span className="pl pl-1">問逃避的男人和逃脫的女人說：</span><br /><span className="pl pl-1">『是什麼事呢？』</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 16:2; 民數記 21:26–28; 申命記 2:36"> <span className="pl pl-1">摩押因毀壞蒙羞，</span><br /><span className="pl pl-1">你們要哀號呼喊，</span><br /><span className="pl pl-1">要在亞嫩旁報告說：</span><br /><span className="pl pl-1">『摩押變為荒場！』</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 13:18; 以賽亞書 15:4; 耶利米書 48:8"> 刑罰臨到平原之地的何倫、雅雜、米法押、</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 48:18; 民數記 33:46; 民數記 32:34"> 底本、尼波、伯低比拉太音、</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 13:17; 耶利米書 48:1; 民數記 32:38"> 基列亭、伯迦末、伯米恩、</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 2:2; 耶利米書 48:41; 約書亞記 21:36"> 加略、波斯拉，和摩押地遠近所有的城邑。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 75:10; 詩篇 10:15; 撒迦利亞書 1:19–21"> 摩押的角砍斷了，摩押的膀臂折斷了。」這是耶和華說的。</span>
</div>
</div>

## 因悖逆神輕侮主民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="耶利米書 48:42; 以賽亞書 29:9; 耶利米書 51:39"> 「你們要使摩押沉醉，因她向耶和華誇大。她要在自己所吐之中打滾，又要被人嗤笑。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 2:26; 彌迦書 7:8–10; 西番雅書 2:8"> 摩押啊，你不曾嗤笑以色列嗎？她豈是在賊中查出來的呢？你每逢提到她便搖頭。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 55:6–7; 士師記 6:2; 雅歌 2:14"> <span className="pl pl-1">摩押的居民哪，</span><br /><span className="pl pl-1">要離開城邑，住在山崖裡，</span><br /><span className="pl pl-1">像鴿子在深淵口上搭窩。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 16:6; 詩篇 138:6; 以賽亞書 2:11–12"> <span className="pl pl-1">我們聽說摩押人驕傲，</span><br /><span className="pl pl-1">是極其驕傲；</span><br /><span className="pl pl-1">聽說她自高自傲，</span><br /><span className="pl pl-1">並且狂妄，居心自大。」</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 50:36; 以賽亞書 16:6; 以賽亞書 37:28–29"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「我知道她的憤怒是虛空的，</span><br /><span className="pl pl-1">她誇大的話一無所成。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 15:5; 列王紀下 3:25; 耶利米書 48:36"> <span className="pl pl-1">因此我要為摩押哀號，</span><br /><span className="pl pl-1">為摩押全地呼喊，</span><br /><span className="pl pl-1">人必為吉珥哈列設人嘆息。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 16:8–9; 民數記 21:32; 約書亞記 13:19"> <span className="pl pl-1">西比瑪的葡萄樹啊，我為你哀哭，</span><br /><span className="pl pl-1">甚於雅謝人哀哭。</span><br /><span className="pl pl-1">你的枝子蔓延過海，</span><br /><span className="pl pl-1">直長到雅謝海，</span><br /><span className="pl pl-1">那行毀滅的已經臨到你夏天的果子</span><br /><span className="pl pl-1">和你所摘的葡萄。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 5:10; 哈該書 2:16; 耶利米書 25:9–10"> <span className="pl pl-1">肥田和摩押地的歡喜快樂都被奪去，</span><br /><span className="pl pl-1">我使酒榨的酒絕流，</span><br /><span className="pl pl-1">無人踹酒歡呼，</span><br /><span className="pl pl-1">那歡呼卻變為仇敵的呐喊</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：那歡呼卻不是歡呼。">c</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 15:4–6; 民數記 32:3; 申命記 34:3"> 希實本人發的哀聲達到以利亞利，直達到雅雜，從瑣珥達到何羅念，直到伊基拉施利施亞，因為寧林的水必然乾涸。」</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 15:2; 以賽亞書 16:12; 民數記 28:14"> 耶和華說：「我必在摩押地使那在丘壇獻祭的和那向她的神燒香的，都斷絕了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 15:7; 以賽亞書 16:11; 以賽亞書 15:5"> 「我心腹為摩押哀鳴如簫，我心腸為吉珥哈列設人也是如此，因摩押人所得的財物都滅沒了。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 41:5; 創世記 37:34; 耶利米書 47:5"> 各人頭上光禿，鬍鬚剪短，手有劃傷，腰束麻布。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 22:28; 耶利米書 25:34; 以賽亞書 22:1"> 在摩押的各房頂上和街市上處處有人哀哭，因我打碎摩押，好像打碎無人喜悅的器皿。」這是耶和華說的。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 20:4–6; 耶利米哀歌 4:1; 耶利米哀歌 2:1"> 「摩押何等毀壞，何等哀號，何等羞愧轉背！這樣，摩押必令四圍的人嗤笑、驚駭。」</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 8:8; 申命記 28:49; 耶利米書 49:22"> 耶和華如此說：<br /><span className="pl pl-1">「仇敵必如大鷹飛起，</span><br /><span className="pl pl-1">展開翅膀攻擊摩押。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 21:3; 以賽亞書 13:8; 彌迦書 4:9–10"> <span className="pl pl-1">加略被攻取，保障也被占據，</span><br /><span className="pl pl-1">到那日，摩押的勇士心中疼痛如臨產的婦人。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 48:2; 以賽亞書 7:8; 以賽亞書 37:23"> <span className="pl pl-1">摩押必被毀滅，不再成國，</span><br /><span className="pl pl-1">因她向耶和華誇大。」</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="耶利米哀歌 3:47; 以賽亞書 24:17–18; 申命記 32:23–25"> <span className="pl pl-1">耶和華說：「摩押的居民哪，</span><br /><span className="pl pl-1">恐懼、陷坑、網羅都臨近你。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="耶利米書 11:23; 列王紀上 19:17; 耶利米書 46:21"> <span className="pl pl-1">躲避恐懼的必墜入陷坑，</span><br /><span className="pl pl-1">從陷坑上來的必被網羅纏住，</span><br /><span className="pl pl-1">因我必使追討之年臨到摩押。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>

## 後日摩押必復振興

<div className="bt">
<div className="bp poetry">
<span className="v" id="v45" data-v="45" data-xref="民數記 24:17; 民數記 21:28; 撒迦利亞書 10:4"> <span className="pl pl-1">「躲避的人無力站在希實本的影下，</span><br /><span className="pl pl-1">因為有火從希實本發出，</span><br /><span className="pl pl-1">有火焰出於西宏的城，</span><br /><span className="pl pl-1">燒盡摩押的角和鬨嚷人的頭頂。</span><br /></span>
<span className="v" id="v46" data-v="46" data-xref="民數記 21:29; 耶利米書 48:7; 士師記 11:24"> <span className="pl pl-1">摩押啊，你有禍了！</span><br /><span className="pl pl-1">屬基抹的民滅亡了！</span><br /><span className="pl pl-1">因你的眾子都被擄去，</span><br /><span className="pl pl-1">你的眾女也被擄去。」</span><br /></span>

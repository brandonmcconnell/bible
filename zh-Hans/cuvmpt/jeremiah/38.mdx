## 牧伯復陷耶利米下之於阱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 7:9; 以斯拉記 2:3; 使徒行傳 4:6–10"> 瑪坦的兒子示法提雅、巴施戶珥的兒子基大利、示利米雅的兒子猶甲、瑪基雅的兒子巴示戶珥，聽見耶利米對眾人所說的話說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 39:18; 耶利米書 34:17; 耶利米書 45:5"> 「耶和華如此說：住在這城裡的必遭刀劍、饑荒、瘟疫而死，但出去歸降迦勒底人的必得存活，就是以自己命為掠物的，必得存活。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:10; 耶利米書 32:3–5"> 耶和華如此說：這城必要交在巴比倫王軍隊的手中，他必攻取這城。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 26:11; 使徒行傳 16:20; 尼希米記 6:9"> 於是，首領對王說：「求你將這人治死，因他向城裡剩下的兵丁和眾民說這樣的話，使他們的手發軟。這人不是求這百姓得平安，乃是叫他們受災禍。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:12–16; 撒母耳記下 3:39; 撒母耳記下 19:22"> 西底家王說：「他在你們手中，無論何事，王也不能與你們反對。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 37:21; 耶利米書 38:22; 耶利米書 37:16"> 他們就拿住耶利米，下在哈米勒的兒子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：王的兒子。">a</a></sup>瑪基雅的牢獄裡。那牢獄在護衛兵的院中，他們用繩子將耶利米繫下去。牢獄裡沒有水，只有淤泥，耶利米就陷在淤泥中。</span>
</div>
</div>

## 以伯米勒求王救援耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 21:19; 阿摩司書 5:10; 耶利米書 29:2"> 在王宮的太監古實人以伯米勒，聽見他們將耶利米下了牢獄（那時王坐在便雅憫門口），</span>
<span className="v" id="v8" data-v="8"> 以伯米勒就從王宮裡出來，對王說：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 37:21–6; 以斯帖記 7:4–6; 箴言 31:8–9"> 「主我的王啊，這些人向先知耶利米一味地行惡，將他下在牢獄中。他在那裡必因飢餓而死，因為城中再沒有糧食。」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 21:1; 以斯帖記 8:7; 以斯帖記 5:2"> 王就吩咐古實人以伯米勒說：「你從這裡帶領三十人，趁著先知耶利米未死以前，將他從牢獄中提上來。」</span>
<span className="v" id="v11" data-v="11"> 於是以伯米勒帶領這些人同去，進入王宮，到庫房以下，從那裡取了些碎布和破爛的衣服，用繩子縋下牢獄去到耶利米那裡。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 12:10; 以弗所書 4:32; 羅馬書 12:15"> 古實人以伯米勒對耶利米說：「你用這些碎布和破爛的衣服放在繩子上，墊你的胳肢窩。」耶利米就照樣行了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 37:21; 使徒行傳 28:16; 使徒行傳 23:35"> 這樣，他們用繩子將耶利米從牢獄裡拉上來。耶利米仍在護衛兵的院中。</span>
</div>
</div>

## 西底家暗詢耶利米當如何行

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 37:17; 列王紀上 22:16; 耶利米書 21:1–2"> 西底家王打發人帶領先知耶利米，進耶和華殿中第三門裡見王。王就對耶利米說：「我要問你一件事，你絲毫不可向我隱瞞。」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:67–68"> 耶利米對西底家說：「我若告訴你，你豈不定要殺我嗎？我若勸誡你，你必不聽從我。」</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 37:17; 耶利米書 38:1–6; 以賽亞書 57:16"> 西底家王就私下向耶利米說：「我指著那造我們生命之永生的耶和華起誓：我必不殺你，也不將你交在尋索你命的人手中。」</span>
</div>
</div>

## 耶利米勸其投降迦勒底人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 27:12; 耶利米書 27:17; 耶利米書 38:2"> 耶利米對西底家說：「耶和華萬軍之神，以色列的神如此說：你若出去歸降巴比倫王的首領，你的命就必存活，這城也不致被火焚燒，你和你的全家都必存活。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:3; 耶利米書 24:8–10; 列王紀下 25:4–10"> 你若不出去歸降巴比倫王的首領，這城必交在迦勒底人手中。他們必用火焚燒，你也不得脫離他們的手。」</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 12:42; 耶利米書 38:22; 約翰福音 19:12–13"> 西底家王對耶利米說：「我怕那些投降迦勒底人的猶大人，恐怕迦勒底人將我交在他們手中，他們戲弄我。」</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 4:27; 以賽亞書 55:3; 耶利米書 26:13"> 耶利米說：「迦勒底人必不將你交出。求你聽從我對你所說耶和華的話，這樣你必得好處，你的命也必存活。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 2:7; 以西結書 2:4–5; 耶利米書 26:15"> 你若不肯出去，耶和華指示我的話乃是這樣：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 43:6; 耶利米哀歌 1:2; 耶利米哀歌 5:11"> 猶大王宮裡所剩的婦女必都帶到巴比倫王的首領那裡，這些婦女必說：<br /><span className="pl pl-1">『你知己的朋友催逼你，</span><br /><span className="pl pl-1">勝過你，</span><br /><span className="pl pl-1">見你的腳陷入淤泥中，</span><br /><span className="pl pl-1">就轉身退後了。』</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 41:10; 耶利米書 39:6; 耶利米書 38:18"> 人必將你的后妃和你的兒女帶到迦勒底人那裡，你也不得脫離他們的手，必被巴比倫王的手捉住，你也必使這城被火焚燒。」</span>
</div>
</div>

## 王命勿以斯言告牧伯

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24"> 西底家對耶利米說：「不要使人知道這些話，你就不至於死。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 38:27; 耶利米書 38:4–6"> 首領若聽見了我與你說話，就來見你，問你說：『你對王說什麼話，不要向我們隱瞞，我們就不殺你。王向你說什麼話，也要告訴我們。』</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 37:20; 耶利米書 37:15; 以斯帖記 4:8"> 你就對他們說：『我在王面前懇求，不要叫我回到約拿單的房屋，死在那裡。』」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 10:15–16; 列王紀下 6:19; 使徒行傳 23:6"> 隨後眾首領來見耶利米問他，他就照王所吩咐的一切話回答他們。他們不再與他說話，因為事情沒有洩漏。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 37:21; 耶利米書 39:14; 詩篇 23:4"> 於是耶利米仍在護衛兵的院中，直到耶路撒冷被攻取的日子。</span>
</div>

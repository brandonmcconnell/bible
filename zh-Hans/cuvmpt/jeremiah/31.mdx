## 以色列必復建興

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 30:22; 耶利米書 30:24; 撒迦利亞書 13:9"> 耶和華說：「那時，我必做以色列各家的神，他們必做我的子民。」</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 10:33; 詩篇 95:11; 馬太福音 11:28"> 耶和華如此說：<br /><span className="pl pl-1">「脫離刀劍的，就是以色列人，</span><br /><span className="pl pl-1">我使他享安息的時候，</span><br /><span className="pl pl-1">他曾在曠野蒙恩。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 103:17; 以賽亞書 54:8–9; 何西阿書 11:4"> <span className="pl pl-1">古時</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：從遠方。">a</a></sup><br /><span className="pl pl-1">耶和華向以色列</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：我。">b</a></sup><br /><span className="pl pl-1">顯現，說：</span><br /><span className="pl pl-1">『我以永遠的愛愛你，</span><br /><span className="pl pl-1">因此我以慈愛吸引你。』</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 33:7; 耶利米書 31:13; 阿摩司書 5:2"> <span className="pl pl-1">以色列的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「民」原文作「處女」。">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">我要再建立你，你就被建立。</span><br /><span className="pl pl-1">你必再以擊鼓為美，</span><br /><span className="pl pl-1">與歡樂的人一同跳舞而出。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 9:14; 利未記 19:23–25; 申命記 28:30"> <span className="pl pl-1">又必在撒馬利亞的山上栽種葡萄園，</span><br /><span className="pl pl-1">栽種的人要享用所結的果子。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:4–5; 彌迦書 4:1–3; 耶利米書 50:19"> <span className="pl pl-1">日子必到，以法蓮山上守望的人必呼叫說：</span><br /><span className="pl pl-1">『起來吧！我們可以上錫安，</span><br /><span className="pl pl-1">到耶和華我們的神那裡去。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 14:7; 詩篇 28:9; 以賽亞書 37:31"> 耶和華如此說：<br /><span className="pl pl-1">「你們當為雅各歡樂歌唱，</span><br /><span className="pl pl-1">因萬國中為首的歡呼，</span><br /><span className="pl pl-1">當傳揚頌讚說：</span><br /><span className="pl pl-1">『耶和華啊，</span><br /><span className="pl pl-1">求你拯救你的百姓以色列所剩下的人！』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 34:16; 以賽亞書 42:16; 耶利米書 23:8"> <span className="pl pl-1">我必將他們從北方領來，</span><br /><span className="pl pl-1">從地極招聚，</span><br /><span className="pl pl-1">同著他們來的有瞎子、瘸子、孕婦、產婦，</span><br /><span className="pl pl-1">他們必成為大幫回到這裡來。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 5:4; 耶利米書 3:4; 出埃及記 4:22"> <span className="pl pl-1">他們要哭泣而來，</span><br /><span className="pl pl-1">我要照他們懇求的引導他們，</span><br /><span className="pl pl-1">使他們在河水旁走正直的路，</span><br /><span className="pl pl-1">在其上不致絆跌，</span><br /><span className="pl pl-1">因為我是以色列的父，</span><br /><span className="pl pl-1">以法蓮是我的長子。</span></span>
</div>
</div>

## 宣揚雅各之得贖

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:11; 以西結書 34:12; 申命記 30:4"> <span className="pl pl-1">「列國啊，要聽耶和華的話，</span><br /><span className="pl pl-1">傳揚在遠處的海島說：</span><br /><span className="pl pl-1">『趕散以色列的必招聚他，</span><br /><span className="pl pl-1">又看守他，好像牧人看守羊群。』</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 48:20; 提多書 2:14; 以賽亞書 44:23"> <span className="pl pl-1">因耶和華救贖了雅各，</span><br /><span className="pl pl-1">救贖他脫離比他更強之人的手。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 35:10; 以賽亞書 58:11; 約珥書 3:18"> <span className="pl pl-1">他們要來到錫安的高處歌唱，</span><br /><span className="pl pl-1">又流歸耶和華施恩之地，</span><br /><span className="pl pl-1">就是有五穀、新酒和油</span><br /><span className="pl pl-1">並羊羔、牛犢之地。</span><br /><span className="pl pl-1">他們的心必像澆灌的園子，</span><br /><span className="pl pl-1">他們也不再有一點愁煩。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 30:11; 以賽亞書 61:3; 以賽亞書 51:11"> <span className="pl pl-1">那時處女必歡樂跳舞，</span><br /><span className="pl pl-1">年少的、年老的也必一同歡樂，</span><br /><span className="pl pl-1">因為我要使他們的悲哀變為歡喜，</span><br /><span className="pl pl-1">並要安慰他們，使他們的愁煩轉為快樂。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:25; 彼得前書 2:9; 耶利米書 33:9"> <span className="pl pl-1">我必以肥油使祭司的心滿足，</span><br /><span className="pl pl-1">我的百姓也要因我的恩惠知足。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
</div>

## 拉結哭子得主慰藉

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="馬太福音 2:16–18; 耶利米書 40:1; 詩篇 77:2"> 耶和華如此說：<br /><span className="pl pl-1">「在拉瑪聽見號啕痛哭的聲音，</span><br /><span className="pl pl-1">是拉結哭她兒女，不肯受安慰，</span><br /><span className="pl pl-1">因為他們都不在了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="路得記 2:12; 耶利米書 30:3; 希伯來書 6:10"> 耶和華如此說：<br /><span className="pl pl-1">「你禁止聲音不要哀哭，</span><br /><span className="pl pl-1">禁止眼目不要流淚，</span><br /><span className="pl pl-1">因你所做之工必有賞賜，</span><br /><span className="pl pl-1">他們必從敵國歸回。」</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:21; 耶利米書 29:11–16; 耶利米哀歌 3:18"> <span className="pl pl-1">耶和華說：「你末後必有指望，</span><br /><span className="pl pl-1">你的兒女必回到自己的境界。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:9; 詩篇 80:3; 約伯記 5:17"> <span className="pl pl-1">我聽見以法蓮為自己悲嘆說：</span><br /><span className="pl pl-1">『你責罰我，我便受責罰，</span><br /><span className="pl pl-1">像不慣負軛的牛犢一樣。</span><br /><span className="pl pl-1">求你使我回轉，我便回轉，</span><br /><span className="pl pl-1">因為你是耶和華我的神。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:31; 耶利米書 3:25; 以西結書 21:12"> <span className="pl pl-1">我回轉以後就真正懊悔，</span><br /><span className="pl pl-1">受教以後就拍腿嘆息，</span><br /><span className="pl pl-1">我因擔當幼年的凌辱就抱愧蒙羞。』」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 55:7; 彌迦書 7:18–19; 以賽亞書 63:15"> <span className="pl pl-1">耶和華說：「以法蓮是我的愛子嗎？</span><br /><span className="pl pl-1">是可喜悅的孩子嗎？</span><br /><span className="pl pl-1">我每逢責備他，仍深顧念他，</span><br /><span className="pl pl-1">所以我的心腸戀慕他，</span><br /><span className="pl pl-1">我必要憐憫他。」</span></span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 50:5; 以賽亞書 62:10; 詩篇 84:5"> <span className="pl pl-1">「以色列民</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「民」原文作「處女」。">d</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你當為自己設立指路碑，</span><br /><span className="pl pl-1">豎起引路柱，</span><br /><span className="pl pl-1">你要留心向大路，</span><br /><span className="pl pl-1">就是你所去的原路。</span><br /><span className="pl pl-1">你當回轉，回轉到你這些城邑。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 49:4; 耶利米書 7:24; 馬太福音 1:21"> <span className="pl pl-1">背道的民</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「民」原文作「女子」。">e</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你翻來覆去要到幾時呢？</span><br /><span className="pl pl-1">耶和華在地上造了一件新事，</span><br /><span className="pl pl-1">就是女子護衛男子。」</span></span>
</div>
</div>

## 耶和華眷愛己民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 8:3; 以賽亞書 1:26; 耶利米書 50:7"> 萬軍之耶和華以色列的神如此說：「我使被擄之人歸回的時候，他們在猶大地和其中的城邑必再這樣說：<br /><span className="pl pl-1">『公義的居所啊，</span><br /><span className="pl pl-1">聖山哪，願耶和華賜福給你！』</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 8:4–8; 以西結書 36:10; 撒迦利亞書 2:4"> 猶大和屬猶大城邑的人，農夫和放羊的人，要一同住在其中。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 5:6; 馬太福音 11:28; 約翰福音 4:14"> 疲乏的人，我使他飽飫；愁煩的人，我使他知足。」</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 127:2; 撒迦利亞書 4:1–2"> 先知說：我醒了，覺著睡得香甜。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="何西阿書 2:23; 撒迦利亞書 10:9; 以西結書 36:9"> 耶和華說：「日子將到，我要把人的種和牲畜的種播種在以色列家和猶大家。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 24:6; 耶利米書 1:10; 耶利米書 18:7–9"> 我先前怎樣留意將他們拔出、拆毀、毀壞、傾覆、苦害，也必照樣留意將他們建立、栽植。」這是耶和華說的。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 5:7; 以西結書 18:2–3; 耶利米書 31:30"> 「當那些日子，人不再說：<br /><span className="pl pl-1">『父親吃了酸葡萄，</span><br /><span className="pl pl-1">兒子的牙酸倒了。』</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西結書 18:20; 以賽亞書 3:11; 申命記 24:16"> 但各人必因自己的罪死亡，凡吃酸葡萄的，自己的牙必酸倒。」</span>
</div>
</div>

## 與民立新約

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="希伯來書 10:16–17; 以西結書 37:26; 耶利米書 31:31–34"> 耶和華說：「日子將到，我要與以色列家和猶大家另立新約。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 24:6–8; 申命記 5:3; 出埃及記 19:5"> 不像我拉著他們祖宗的手領他們出埃及地的時候，與他們所立的約，我雖做他們的丈夫，他們卻背了我的約。」這是耶和華說的。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 3:3; 希伯來書 10:16; 希伯來書 8:10"> 耶和華說：「那些日子以後，我與以色列家所立的約乃是這樣：我要將我的律法放在他們裡面，寫在他們心上；我要做他們的神，他們要做我的子民。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 43:25; 希伯來書 8:12; 約翰一書 2:27"> 他們各人不再教導自己的鄰舍和自己的弟兄說『你該認識耶和華』，因為他們從最小的到至大的都必認識我。我要赦免他們的罪孽，不再記念他們的罪惡。」這是耶和華說的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="耶利米書 10:16; 以賽亞書 51:15; 詩篇 136:7–9"> <span className="pl pl-1">那使太陽白日發光，</span><br /><span className="pl pl-1">使星月有定例黑夜發亮，</span><br /><span className="pl pl-1">又攪動大海，使海中波浪砰訇的，</span><br /><span className="pl pl-1">萬軍之耶和華是他的名，</span><br />他如此說：</span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 54:9–10; 耶利米書 33:20–26; 詩篇 89:36–37"> <span className="pl pl-1">「這些定例若能在我面前廢掉，</span><br /><span className="pl pl-1">以色列的後裔也就在我面前斷絕，</span><br /><span className="pl pl-1">永遠不再成國。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="耶利米書 33:24–26; 以賽亞書 40:12; 耶利米書 33:22"> 耶和華如此說：<br /><span className="pl pl-1">「若能量度上天，</span><br /><span className="pl pl-1">尋察下地的根基，</span><br /><span className="pl pl-1">我就因以色列後裔一切所行的棄絕他們。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒迦利亞書 14:10; 列王紀下 14:13; 耶利米書 30:18"> 耶和華說：「日子將到，這城必為耶和華建造，從哈楠業樓直到角門。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亞書 2:1–2; 以西結書 40:8"> 準繩要往外量出，直到迦立山，又轉到歌亞。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 15:23; 約珥書 3:17; 列王紀下 11:16"> 拋屍的全谷和倒灰之處，並一切田地，直到汲淪溪，又直到東方馬門的拐角，都要歸耶和華為聖。不再拔出，不再傾覆，直到永遠。」</span>
</div>
</div>

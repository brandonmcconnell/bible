## 耶利米奉召為先知之時

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 6:60; 耶利米書 11:21; 歷代志下 36:21"> 便雅憫地亞拿突城的祭司中，希勒家的兒子耶利米的話記在下面。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 13:20; 約拿書 1:1; 耶利米書 1:11"> 猶大王亞們的兒子約西亞在位十三年，耶和華的話臨到耶利米。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 39:2; 歷代志下 36:5–8; 列王紀下 23:34"> 從猶大王約西亞的兒子約雅敬在位的時候，直到猶大王約西亞的兒子西底家在位的末年，就是十一年五月間耶路撒冷人被擄的時候，耶和華的話也常臨到耶利米。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以西結書 3:16; 以西結書 1:3; 耶利米書 1:2"> 耶利米說：耶和華的話臨到我說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 139:16; 以賽亞書 49:1; 加拉太書 1:15–16"> <span className="pl pl-1">「我未將你造在腹中，我已曉得你；</span><br /><span className="pl pl-1">你未出母胎，我已分別你為聖。</span><br /><span className="pl pl-1">我已派你做列國的先知。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 6:12; 出埃及記 4:10–16; 列王紀上 3:7–9"> 我就說：「主耶和華啊！我不知怎樣說，因為我是年幼的。」</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 16:15–16; 以西結書 3:27; 民數記 22:20"> 耶和華對我說：<br /><span className="pl pl-1">「你不要說『我是年幼的』，</span><br /><span className="pl pl-1">因為我差遣你到誰那裡去，你都要去，</span><br /><span className="pl pl-1">我吩咐你說什麼話，你都要說。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 1:5; 約書亞記 1:9; 以賽亞書 51:7"> <span className="pl pl-1">你不要懼怕他們，</span><br /><span className="pl pl-1">因為我與你同在，</span><br /><span className="pl pl-1">要拯救你。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:15; 出埃及記 4:11–12; 路加福音 12:12"> 於是耶和華伸手按我的口，對我說：<br /><span className="pl pl-1">「我已將當說的話傳給你。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:28; 哥林多後書 10:4–5; 以賽亞書 44:26–28"> <span className="pl pl-1">看哪，我今日立你在列邦列國之上，</span><br /><span className="pl pl-1">為要施行拔出、拆毀、毀壞、傾覆，</span><br /><span className="pl pl-1">又要建立、栽植。」</span></span>
</div>
</div>

## 耶利米見杏枝沸釜

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="阿摩司書 7:8; 阿摩司書 8:2; 撒迦利亞書 5:2"> 耶和華的話又臨到我說：「耶利米，你看見什麼？」我說：「我看見一根杏樹枝。」</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 12:28; 以西結書 12:25; 以西結書 12:22–23"> 耶和華對我說：「你看得不錯，因為我留意保守我的話，使得成就。」</span>
</div>
</div>

## 預言猶大遭災

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 11:3; 以西結書 11:7; 撒迦利亞書 4:2"> 耶和華的話第二次臨到我說：「你看見什麼？」我說：「我看見一個燒開的鍋，從北而傾。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 41:25; 耶利米書 4:6; 耶利米書 10:22"> 耶和華對我說：「必有災禍從北方發出，臨到這地的一切居民。」</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 43:10; 耶利米書 25:9; 耶利米書 9:11"> 耶和華說：「看哪，我要召北方列國的眾族。他們要來，各安座位在耶路撒冷的城門口，周圍攻擊城牆，又要攻擊猶大的一切城邑。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 7:9; 耶利米書 19:4; 使徒行傳 7:41"> 至於這民的一切惡，就是離棄我，向別神燒香，跪拜自己手所造的，我要發出我的判語，攻擊他們。</span>
</div>
</div>

## 耶和華慰勉耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 1:7–8; 列王紀上 18:46; 彼得前書 1:13"> 「所以你當束腰，起來將我所吩咐你的一切話告訴他們。不要因他們驚惶，免得我使你在他們面前驚惶。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 50:7; 以西結書 3:8–9; 耶利米書 15:20"> 看哪，我今日使你成為堅城、鐵柱、銅牆，與全地，和猶大的君王、首領、祭司，並地上的眾民反對。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 1:9; 耶利米書 1:8; 耶利米書 20:11"> 他們要攻擊你，卻不能勝你，因為我與你同在，要拯救你。」這是耶和華說的。</span>
</div>
</div>

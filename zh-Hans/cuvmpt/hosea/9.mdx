## 徇欲棄主必遭懲罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 10:5; 何西阿書 4:12; 耶利米書 44:17"> <span className="pl pl-1">以色列啊，不要像外邦人歡喜快樂，</span><br /><span className="pl pl-1">因為你行邪淫離棄你的神，</span><br /><span className="pl pl-1">在各穀場上如妓女喜愛賞賜。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 2:9; 彌迦書 6:13–16; 約珥書 1:3–7"> <span className="pl pl-1">穀場和酒榨都不夠以色列人使用，</span><br /><span className="pl pl-1">新酒也必缺乏。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 4:13; 何西阿書 8:13; 利未記 25:23"> <span className="pl pl-1">他們必不得住耶和華的地，</span><br /><span className="pl pl-1">以法蓮卻要歸回埃及，</span><br /><span className="pl pl-1">必在亞述吃不潔淨的食物。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 8:13; 申命記 26:14; 耶利米書 6:20"> <span className="pl pl-1">他們必不得向耶和華奠酒，</span><br /><span className="pl pl-1">即便奠酒也不蒙悅納。</span><br /><span className="pl pl-1">他們的祭物必如居喪者的食物，</span><br /><span className="pl pl-1">凡吃的必被玷汙，</span><br /><span className="pl pl-1">因他們的食物只為自己的口腹，</span><br /><span className="pl pl-1">必不奉入耶和華的殿。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 10:3; 耶利米書 5:31; 何西阿書 2:11"> <span className="pl pl-1">在大會的日子，</span><br /><span className="pl pl-1">到耶和華的節期，你們怎樣行呢？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="何西阿書 10:8; 以賽亞書 5:6; 以賽亞書 7:23"> <span className="pl pl-1">看哪，他們逃避災難，</span><br /><span className="pl pl-1">埃及人必收殮他們的屍首，</span><br /><span className="pl pl-1">摩弗人必葬埋他們的骸骨。</span><br /><span className="pl pl-1">他們用銀子做的美物上必長蒺藜，</span><br /><span className="pl pl-1">他們的帳篷中必生荊棘。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 26:24–25; 彌迦書 7:4; 列王紀下 9:11"> <span className="pl pl-1">以色列人必知道降罰的日子臨近，</span><br /><span className="pl pl-1">報應的時候來到。</span><br /><span className="pl pl-1">民說：「做先知的是愚昧，</span><br /><span className="pl pl-1">受靈感的是狂妄。」</span><br /><span className="pl pl-1">皆因他們多多作孽，大懷怨恨。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 5:1; 以西結書 3:17; 以賽亞書 62:6"> <span className="pl pl-1">以法蓮曾做我神守望的，</span><br /><span className="pl pl-1">至於先知，在他一切的道上作為捕鳥人的網羅，</span><br /><span className="pl pl-1">在他神的家中懷怨恨。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 10:9; 士師記 19:16–21; 何西阿書 8:13"> <span className="pl pl-1">以法蓮深深地敗壞，</span><br /><span className="pl pl-1">如在基比亞的日子一樣。</span><br /><span className="pl pl-1">耶和華必記念他們的罪孽，</span><br /><span className="pl pl-1">追討他們的罪惡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 11:13; 何西阿書 4:14; 民數記 25:1–18"> <span className="pl pl-1">主說：「我遇見以色列如葡萄在曠野，</span><br /><span className="pl pl-1">我看見你們的列祖如無花果樹上春季初熟的果子。</span><br /><span className="pl pl-1">他們卻來到巴力毗珥專拜那可羞恥的，</span><br /><span className="pl pl-1">就成為可憎惡的，</span><br /><span className="pl pl-1">與他們所愛的一樣。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 28:18; 何西阿書 9:14; 何西阿書 4:7"> <span className="pl pl-1">至於以法蓮人，他們的榮耀必如鳥飛去，</span><br /><span className="pl pl-1">必不生產，不懷胎，不成孕。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 7:13; 申命記 32:25; 申命記 31:17"> <span className="pl pl-1">縱然養大兒女，</span><br /><span className="pl pl-1">我卻必使他們喪子，甚至不留一個。</span><br /><span className="pl pl-1">我離棄他們，他們就有禍了。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 26:1–21; 以西結書 27:3; 何西阿書 13:8"> <span className="pl pl-1">我看以法蓮如推羅栽於美地，</span><br /><span className="pl pl-1">以法蓮卻要將自己的兒女帶出來，</span><br /><span className="pl pl-1">交於行殺戮的人。」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:29; 哥林多前書 7:26; 馬可福音 13:17"> <span className="pl pl-1">耶和華啊，求你加給他們——</span><br /><span className="pl pl-1">加什麼呢？</span><br /><span className="pl pl-1">要使他們胎墜乳乾！</span><br /></span>

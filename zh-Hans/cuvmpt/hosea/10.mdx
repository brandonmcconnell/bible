## 嚴責以色列崇偽拜像

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 8:11; 利未記 26:1; 腓立比書 2:21"> <span className="pl pl-1">以色列是茂盛的葡萄樹，結果繁多。</span><br /><span className="pl pl-1">果子越多，就越增添祭壇；</span><br /><span className="pl pl-1">地土越肥美，就越造美麗的柱像。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="彌迦書 5:13; 列王紀上 18:21; 西番雅書 1:5"> <span className="pl pl-1">他們心懷二意，</span><br /><span className="pl pl-1">現今要定為有罪。</span><br /><span className="pl pl-1">耶和華必拆毀他們的祭壇，</span><br /><span className="pl pl-1">毀壞他們的柱像。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 10:15; 何西阿書 10:7; 何西阿書 13:11"> <span className="pl pl-1">他們必說：「我們沒有王，</span><br /><span className="pl pl-1">因為我們不敬畏耶和華。</span><br /><span className="pl pl-1">王能為我們做什麼呢？」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="阿摩司書 5:7; 阿摩司書 6:12; 何西阿書 4:2"> <span className="pl pl-1">他們為立約說謊言，起假誓，</span><br /><span className="pl pl-1">因此災罰如苦菜滋生在田間的犁溝中。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 9:11; 何西阿書 5:8; 列王紀下 23:5"> <span className="pl pl-1">撒馬利亞的居民必因伯亞文的牛犢驚恐，</span><br /><span className="pl pl-1">崇拜牛犢的民和喜愛牛犢的祭司</span><br /><span className="pl pl-1">都必因榮耀離開它，為它悲哀。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="何西阿書 5:13; 以賽亞書 30:3; 但以理書 11:8"> <span className="pl pl-1">人必將牛犢帶到亞述當做禮物，</span><br /><span className="pl pl-1">獻給耶雷布王。</span><br /><span className="pl pl-1">以法蓮必蒙羞，</span><br /><span className="pl pl-1">以色列必因自己的計謀慚愧。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 10:3; 猶大書 1:13; 列王紀下 1:3"> <span className="pl pl-1">至於撒馬利亞，她的王必滅沒，</span><br /><span className="pl pl-1">如水面的沫子一樣。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 23:30; 啟示錄 6:16; 以賽亞書 2:19"> <span className="pl pl-1">伯亞文的丘壇，</span><br /><span className="pl pl-1">就是以色列取罪的地方，必被毀滅，</span><br /><span className="pl pl-1">荊棘和蒺藜必長在他們的祭壇上。</span><br /><span className="pl pl-1">他們必對大山說「遮蓋我們！」，</span><br /><span className="pl pl-1">對小山說「倒在我們身上！」。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="何西阿書 9:9; 士師記 20:5; 士師記 19:22–30"> <span className="pl pl-1">「以色列啊，</span><br /><span className="pl pl-1">你從基比亞的日子以來時常犯罪。</span><br /><span className="pl pl-1">你們的先人曾站在那裡，</span><br /><span className="pl pl-1">現今住基比亞的人</span><br /><span className="pl pl-1">以為攻擊罪孽之輩的戰事臨不到自己。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 5:13; 何西阿書 4:9; 耶利米書 16:16"> <span className="pl pl-1">我必隨意懲罰他們！</span><br /><span className="pl pl-1">他們為兩樣的罪所纏，</span><br /><span className="pl pl-1">列邦的民必聚集攻擊他們。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 4:16; 耶利米書 50:11; 申命記 25:4"> <span className="pl pl-1">以法蓮是馴良的母牛犢，喜愛踹穀，</span><br /><span className="pl pl-1">我卻將軛加在牠肥美的頸項上。</span><br /><span className="pl pl-1">我要使以法蓮拉套</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：被騎。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">猶大必耕田，</span><br /><span className="pl pl-1">雅各必耙地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 4:3–4; 雅各書 3:18; 以賽亞書 45:8"> <span className="pl pl-1">「你們要為自己栽種公義，</span><br /><span className="pl pl-1">就能收割慈愛。</span><br /><span className="pl pl-1">現今正是尋求耶和華的時候，</span><br /><span className="pl pl-1">你們要開墾荒地，等他臨到，</span><br /><span className="pl pl-1">使公義如雨降在你們身上。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 4:8; 加拉太書 6:7–8; 箴言 1:31"> <span className="pl pl-1">你們耕種的是奸惡，</span><br /><span className="pl pl-1">收割的是罪孽，</span><br /><span className="pl pl-1">吃的是謊話的果子。</span><br /><span className="pl pl-1">因你倚靠自己的行為，</span><br /><span className="pl pl-1">仰賴勇士眾多，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="何西阿書 13:16; 列王紀下 18:9–10; 阿摩司書 3:8"> <span className="pl pl-1">所以在這民中必有鬨嚷之聲，</span><br /><span className="pl pl-1">你一切的保障必被拆毀，</span><br /><span className="pl pl-1">就如沙勒幔在爭戰的日子拆毀伯亞比勒，</span><br /><span className="pl pl-1">將其中的母子一同摔死。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="何西阿書 10:5; 何西阿書 10:7; 羅馬書 7:13"> <span className="pl pl-1">因他們的大惡，</span><br /><span className="pl pl-1">伯特利必使你們遭遇如此。</span><br /><span className="pl pl-1">到了黎明，以色列的王必全然滅絕。</span></span>
</div>

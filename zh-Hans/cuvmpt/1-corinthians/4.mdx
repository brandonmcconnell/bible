## 使徒是神的管家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:10; 提多書 1:7; 提摩太前書 3:9"> 人應當以我們為基督的執事，為神奧祕事的管家。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 所求於管家的，是要他有忠心。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 7:24; 哥林多前書 2:15; 撒母耳記上 16:7"> 我被你們論斷，或被別人論斷，我都以為極小的事，連我自己也不論斷自己。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 143:2; 約翰一書 3:20–21; 詩篇 130:3"> 我雖不覺得自己有錯，卻也不能因此得以稱義，但判斷我的乃是主。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 5:7; 哥林多後書 5:10; 哥林多前書 3:13"> 所以，時候未到，什麼都不要論斷，只等主來，他要照出暗中的隱情，顯明人心的意念。那時，各人要從神那裡得著稱讚。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 12:6; 哥林多後書 11:4; 哥林多後書 12:19"> 弟兄們，我為你們的緣故，拿這些事轉比自己和亞波羅，叫你們效法我們不可過於聖經所記，免得你們自高自大，貴重這個、輕看那個。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 3:27; 彼得前書 4:10; 雅各書 1:17"> 使你與人不同的是誰呢？你有什麼不是領受的呢？若是領受的，為何自誇，彷彿不是領受的呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; 箴言 13:7; 哥林多前書 5:6"> 你們已經飽足了，已經豐富了！不用我們，自己就做王了！我願意你們果真做王，叫我們也得與你們一同做王！</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:33; 羅馬書 8:36; 哥林多後書 4:8–12"> 我想神把我們使徒明明列在末後，好像定死罪的囚犯；因為我們成了一臺戲，給世人和天使觀看。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 2:3; 使徒行傳 26:24; 哥林多前書 3:18"> 我們為基督的緣故算是愚拙的，你們在基督裡倒是聰明的；我們軟弱，你們倒強壯；你們有榮耀，我們倒被藐視。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:35; 哥林多後書 11:23–27; 腓立比書 4:12"> 直到如今，我們還是又飢又渴，又赤身露體，又挨打，又沒有一定的住處，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:9; 馬太福音 5:11; 彼得前書 4:12–14"> 並且勞苦，親手做工。被人咒罵，我們就祝福；被人逼迫，我們就忍受；</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:45; 使徒行傳 22:22"> 被人毀謗，我們就善勸。直到如今，人還把我們看做世界上的汙穢，萬物中的渣滓。</span>
</div>
</div>

## 當效法保羅

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:11; 哥林多前書 4:15; 約翰三書 1:4"> 我寫這話，不是叫你們羞愧，乃是警戒你們，好像我所親愛的兒女一樣。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:19; 哥林多前書 3:10; 哥林多前書 9:14"> 你們學基督的，師傅雖有一萬，為父的卻是不多，因我在基督耶穌裡用福音生了你們。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 11:1; 帖撒羅尼迦後書 3:9; 腓立比書 3:17"> 所以，我求你們效法我。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前書 1:2; 哥林多前書 16:10; 哥林多前書 7:17"> 因此我已打發提摩太到你們那裡去，他在主裡面是我所親愛、有忠心的兒子，他必提醒你們記念我在基督裡怎樣行事，在各處各教會中怎樣教導人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 4:6–8; 哥林多前書 5:2; 哥林多前書 4:21"> 有些人自高自大，以為我不到你們那裡去。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 13:1–4; 使徒行傳 18:21; 使徒行傳 19:21"> 然而主若許我，我必快到你們那裡去，並且我所要知道的，不是那些自高自大之人的言語，乃是他們的權能。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 2:4; 帖撒羅尼迦前書 1:5; 哥林多後書 10:4–5"> 因為神的國不在乎言語，乃在乎權能。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 13:2; 哥林多後書 13:10; 帖撒羅尼迦前書 2:7"> 你們願意怎麼樣呢？是願意我帶著刑杖到你們那裡去呢，還是要我存慈愛溫柔的心呢？</span>
</div>
</div>

## 述說古事以為鑒戒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 14:29; 尼希米記 9:11–12; 詩篇 78:13–14"> 弟兄們，我不願意你們不曉得：我們的祖宗從前都在雲下，都從海中經過，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 3:2–3; 哥林多前書 1:13–16; 出埃及記 14:31"> 都在雲裡、海裡受洗歸了摩西，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:3; 尼希米記 9:15; 出埃及記 16:35"> 並且都吃了一樣的靈食，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 17:6; 約翰福音 7:37; 以賽亞書 48:21"> 也都喝了一樣的靈水；所喝的是出於隨著他們的靈磐石，那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 3:17; 猶大書 1:5; 民數記 14:37"> 但他們中間多半是神不喜歡的人，所以在曠野倒斃。</span>
<span className="v" id="v6" data-v="6" data-xref="猶大書 1:7; 哥林多前書 10:11; 希伯來書 4:11"> 這些事都是我們的鑒戒，叫我們不要貪戀惡事，像他們那樣貪戀的。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 32:6–8; 詩篇 106:19–20; 哥林多前書 6:9"> 也不要拜偶像，像他們有人拜的，如經上所記：「百姓坐下吃喝，起來玩耍。」</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 25:1–9; 哥林多前書 6:18; 詩篇 106:29"> 我們也不要行姦淫，像他們有人行的，一天就倒斃了二萬三千人。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 21:5–6; 詩篇 78:18; 希伯來書 3:8–11"> 也不要試探主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」有古卷作「基督」。">a</a></sup>，像他們有人試探的，就被蛇所滅。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:2; 民數記 16:41; 民數記 14:37"> 你們也不要發怨言，像他們有發怨言的，就被滅命的所滅。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 15:4; 羅馬書 13:11; 哥林多前書 9:10"> 他們遭遇這些事都要作為鑒戒，並且寫在經上正是警戒我們這末世的人。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:20; 彼得後書 3:17; 箴言 16:18"> 所以，自己以為站得穩的須要謹慎，免得跌倒。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得後書 2:9; 提摩太後書 4:18; 帖撒羅尼迦後書 3:3"> 你們所遇見的試探，無非是人所能受的。神是信實的，必不叫你們受試探過於所能受的，在受試探的時候，總要給你們開一條出路，叫你們能忍受得住。</span>
</div>
</div>

## 當逃避拜偶像的事

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:8; 約翰一書 5:21; 彼得前書 2:11"> 我所親愛的弟兄啊，你們要逃避拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:1; 帖撒羅尼迦前書 5:21; 哥林多前書 11:13"> 我好像對明白人說的，你們要審察我的話。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:26–28; 哥林多前書 11:23–29; 使徒行傳 2:42"> 我們所祝福的杯，豈不是同領基督的血嗎？我們所掰開的餅，豈不是同領基督的身體嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:5; 歌羅西書 3:15; 哥林多前書 12:27"> 我們雖多，仍是一個餅、一個身體，因為我們都是分受這一個餅。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比書 3:3–5; 加拉太書 6:16; 利未記 7:6"> 你們看屬肉體的以色列人，那吃祭物的豈不是在祭壇上有份嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 8:4; 哥林多前書 3:7; 哥林多前書 13:2"> 我是怎麼說呢？豈是說祭偶像之物算得什麼呢？或說偶像算得什麼呢？</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 9:20; 詩篇 106:37–39; 申命記 32:16–17"> 我乃是說：外邦人所獻的祭是祭鬼，不是祭神。我不願意你們與鬼相交。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:24; 列王紀上 18:21; 哥林多後書 6:15–17"> 你們不能喝主的杯，又喝鬼的杯；不能吃主的筵席，又吃鬼的筵席。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:21; 申命記 32:16; 希伯來書 10:31"> 我們可惹主的憤恨嗎？我們比他還有能力嗎？</span>
</div>
</div>

## 不可妄用自由

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 6:12; 哥林多前書 8:9; 以弗所書 4:29"> 凡事都可行，但不都有益處；凡事都可行，但不都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 15:1–2; 哥林多前書 10:33; 腓立比書 2:4–5"> 無論何人，不要求自己的益處，乃要求別人的益處。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前書 4:4; 哥林多前書 8:7; 提多書 1:15"> 凡市上所賣的，你們只管吃，不要為良心的緣故問什麼話，</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 24:1; 出埃及記 19:5; 詩篇 50:12"> 因為地和其中所充滿的都屬乎主。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 10:25; 路加福音 10:7–8; 哥林多前書 5:9–11"> 倘有一個不信的人請你們赴席，你們若願意去，凡擺在你們面前的，只管吃，不要為良心的緣故問什麼話。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 8:10–13; 哥林多前書 8:7; 哥林多前書 10:26"> 若有人對你們說：「這是獻過祭的物」，就要為那告訴你們的人，並為良心的緣故不吃。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 9:19; 羅馬書 14:15–21; 哥林多前書 8:9–13"> 我說的良心不是你的，乃是他的。我這自由為什麼被別人的良心論斷呢？</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 14:6; 提摩太前書 4:3–4"> 我若謝恩而吃，為什麼因我謝恩的物被人毀謗呢？</span>
<span className="v" id="v31" data-v="31" data-xref="歌羅西書 3:17; 歌羅西書 3:23; 彼得前書 4:11"> 所以，你們或吃或喝，無論做什麼，都要為榮耀神而行。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 20:28; 哥林多前書 10:33; 羅馬書 14:13"> 不拘是猶太人，是希臘人，是神的教會，你們都不要使他跌倒；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 10:24; 加拉太書 1:10; 哥林多前書 9:19–23"> 就好像我，凡事都叫眾人喜歡，不求自己的益處，只求眾人的益處，叫他們得救。</span>
</div>
</div>

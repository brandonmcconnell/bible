## 祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 1:1; 以弗所書 1:1; 哥林多後書 1:1"> 奉神旨意、蒙召做耶穌基督使徒的保羅，同兄弟所提尼，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:7; 哥林多前書 6:9–11; 哥林多前書 1:30"> 寫信給在哥林多神的教會，就是在基督耶穌裡成聖、蒙召做聖徒的，以及所有在各處求告我主耶穌基督之名的人。基督是他們的主，也是我們的主。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 1:7; 哥林多後書 1:2; 彼得前書 1:2"> 願恩惠、平安從神我們的父並主耶穌基督歸於你們！</span>
</div>
</div>

## 感謝

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:8; 約翰福音 14:26; 提摩太前書 1:14"> 我常為你們感謝我的神，因神在基督耶穌裡所賜給你們的恩惠，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 9:11; 哥林多後書 8:7; 歌羅西書 2:3"> 又因你們在他裡面凡事富足，口才、知識都全備。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:2; 提摩太後書 1:8; 提摩太前書 2:6"> 正如我為基督作的見證在你們心裡得以堅固，</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 3:20; 彼得後書 3:12; 希伯來書 9:28"> 以致你們在恩賜上沒有一樣不及人的，等候我們的主耶穌基督顯現。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:23–24; 帖撒羅尼迦前書 3:13; 歌羅西書 1:22"> 他也必堅固你們到底，叫你們在我們主耶穌基督的日子無可責備。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:3; 希伯來書 10:23; 申命記 7:9"> 神是信實的，你們原是被他所召，好與他兒子我們的主耶穌基督一同得份。</span>
</div>
</div>

## 勸弟兄相合

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:1–4; 以弗所書 4:1–7; 哥林多前書 12:25"> 弟兄們，我藉我們主耶穌基督的名，勸你們都說一樣的話，你們中間也不可分黨，只要一心一意，彼此相合。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:6; 提摩太前書 6:4; 提摩太後書 2:23–25"> 因為革來氏家裡的人曾對我提起弟兄們來，說你們中間有紛爭。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 3:21–23; 約翰福音 1:42; 馬太福音 23:9–10"> 我的意思就是，你們各人說「我是屬保羅的」、「我是屬亞波羅的」、「我是屬磯法的」、「我是屬基督的」。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:5; 哥林多後書 11:4; 使徒行傳 2:38"> 基督是分開的嗎？保羅為你們釘了十字架嗎？你們是奉保羅的名受了洗嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 18:8; 羅馬書 16:23; 哥林多前書 1:4"> 我感謝神，除了基利司布並該猶以外，我沒有給你們一個人施洗，</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 11:2; 約翰福音 3:28–29; 約翰福音 7:18"> 免得有人說，你們是奉我的名受洗。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:15; 哥林多前書 16:17; 使徒行傳 16:33"> 我也給司提反家施過洗，此外給別人施洗沒有，我卻記不清。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 2:1; 哥林多前書 2:13; 彼得後書 1:16"> 基督差遣我原不是為施洗，乃是為傳福音；並不用智慧的言語，免得基督的十字架落了空。</span>
</div>
</div>

## 基督是神的能力和智慧

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 2:14; 羅馬書 1:16; 帖撒羅尼迦後書 2:10"> 因為十字架的道理，在那滅亡的人為愚拙，在我們得救的人卻為神的大能。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 29:14; 耶利米書 8:9; 哥林多前書 3:19"> 就如經上所記：<br /><span className="pl pl-1">「我要滅絕智慧人的智慧，</span><br /><span className="pl pl-1">廢棄聰明人的聰明。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:22; 約伯記 12:17; 哥林多前書 3:19"> 智慧人在哪裡？文士在哪裡？這世上的辯士在哪裡？神豈不是叫這世上的智慧變成愚拙嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 10:21; 羅馬書 1:20–22; 馬太福音 11:25"> 世人憑自己的智慧既不認識神，神就樂意用人所當做愚拙的道理，拯救那些信的人，這就是神的智慧了。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 16:1–4; 馬太福音 12:38–39; 馬可福音 8:11"> 猶太人是要神蹟，希臘人是求智慧，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 2:14; 哥林多前書 2:2; 彼得前書 2:8"> 我們卻是傳釘十字架的基督——在猶太人為絆腳石，在外邦人為愚拙，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 1:30; 歌羅西書 2:3; 哥林多前書 1:18"> 但在那蒙召的，無論是猶太人、希臘人，基督總為神的能力、神的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 11:33–36; 哥林多前書 1:18; 撒迦利亞書 4:6–7"> 因神的愚拙總比人智慧，神的軟弱總比人強壯。</span>
</div>
</div>

## 世人厭惡的乃神所揀選

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各書 2:5; 哥林多前書 3:18–20; 雅各書 1:9–11"> 弟兄們哪，可見你們蒙召的，按著肉體有智慧的不多，有能力的不多，有尊貴的也不多。</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 2:5; 馬太福音 11:25; 哥林多前書 1:20"> 神卻揀選了世上愚拙的，叫有智慧的羞愧；又揀選了世上軟弱的，叫那強壯的羞愧。</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 34:24; 羅馬書 4:17; 以賽亞書 2:11"> 神也揀選了世上卑賤的、被人厭惡的以及那無有的，為要廢掉那有的，</span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 3:27; 耶利米書 9:23; 以弗所書 2:9"> 使一切有血氣的，在神面前一個也不能自誇。</span>
<span className="v" id="v30" data-v="30" data-xref="以弗所書 1:7; 腓立比書 3:9; 羅馬書 8:1"> 但你們得在基督耶穌裡，是本乎神，神又使他成為我們的智慧、公義、聖潔、救贖。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 9:23–24; 哥林多後書 10:17; 腓立比書 3:3"> 如經上所記：「誇口的，當指著主誇口。」</span>
</div>
</div>

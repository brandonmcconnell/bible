## 勸門徒思念上面的事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 8:6; 馬太福音 6:33; 哥林多後書 4:18"> 所以，你們若真與基督一同復活，就當求在上面的事，那裡有基督坐在神的右邊。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 2:15–17; 歷代志上 22:19; 歌羅西書 3:1"> 你們要思念上面的事，不要思念地上的事，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 2:20; 羅馬書 6:2; 歌羅西書 2:20"> 因為你們已經死了，你們的生命與基督一同藏在神裡面。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 11:25; 約翰一書 3:2; 加拉太書 2:20"> 基督是我們的生命，他顯現的時候，你們也要與他一同顯現在榮耀裡。</span>
</div>
</div>

## 棄舊更新

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:13; 加拉太書 5:19–21; 加拉太書 5:24"> 所以要治死你們在地上的肢體，就如淫亂、汙穢、邪情、惡慾和貪婪，貪婪就與拜偶像一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 5:6; 羅馬書 1:18; 彼得前書 1:14"> 因這些事，神的憤怒必臨到那悖逆之子。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 2:2; 彼得前書 4:3–4; 羅馬書 6:19–20"> 當你們在這些事中活著的時候，也曾這樣行過。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 4:29; 以弗所書 4:22; 雅各書 1:20–21"> 但現在你們要棄絕這一切的事，以及惱恨、憤怒、惡毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：陰毒。">a</a></sup>、毀謗並口中汙穢的言語。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:22; 以弗所書 4:25; 利未記 19:11"> 不要彼此說謊，因你們已經脫去舊人和舊人的行為，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 4:23–24; 羅馬書 12:2; 以弗所書 2:10"> 穿上了新人；這新人在知識上漸漸更新，正如造他主的形像。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:28–29; 哥林多前書 12:13; 羅馬書 10:12"> 在此並不分希臘人、猶太人，受割禮的、未受割禮的，化外人，西古提人，為奴的，自主的，唯有基督是包括一切，又住在各人之內。</span>
</div>
</div>

## 愛心是聯絡全德的

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:32; 以弗所書 4:2; 約翰一書 4:19"> 所以，你們既是神的選民、聖潔蒙愛的人，就要存<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：穿。下同。">b</a></sup>憐憫、恩慈、謙虛、溫柔、忍耐的心。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:32; 馬可福音 11:25; 雅各書 2:13"> 倘若這人與那人有嫌隙，總要彼此包容，彼此饒恕；主怎樣饒恕了你們，你們也要怎樣饒恕人。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 4:8; 以弗所書 5:2; 哥林多前書 13:1–13"> 在這一切之外，要存著愛心，愛心就是聯絡全德的。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 4:6–7; 約翰福音 14:27; 以賽亞書 26:3"> 又要叫基督的平安在你們心裡做主，你們也為此蒙召，歸為一體；且要存感謝的心。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:11; 以弗所書 5:19; 約翰福音 15:7"> 當用各樣的智慧，把基督的道理豐豐富富地存在心裡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：當把基督的道理豐豐富富地存在心裡，以各樣的智慧。">c</a></sup>，用詩章、頌詞、靈歌彼此教導，互相勸誡，心被恩感歌頌神。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 10:31; 歌羅西書 3:23; 箴言 3:6"> 無論做什麼，或說話或行事，都要奉主耶穌的名，藉著他感謝父神。</span>
</div>
</div>

## 勸夫婦父子主僕各盡其分

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所書 5:22–9; 提多書 2:4–5; 哥林多前書 11:3"> 你們做妻子的，當順服自己的丈夫，這在主裡面是相宜的。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 3:7; 創世記 2:23–24; 歌羅西書 3:21"> 你們做丈夫的，要愛你們的妻子，不可苦待她們。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:12; 以弗所書 6:1–3; 箴言 6:20"> 你們做兒女的，要凡事聽從父母，因為這是主所喜悅的。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所書 6:4; 詩篇 103:13"> 你們做父親的，不要惹兒女的氣，恐怕他們失了志氣。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 6:5–7; 提摩太前書 6:1–2; 加拉太書 1:10"> 你們做僕人的，要凡事聽從你們肉身的主人；不要只在眼前侍奉，像是討人喜歡的，總要存心誠實敬畏主。</span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 3:17; 以弗所書 6:6–7; 羅馬書 14:8"> 無論做什麼，都要從心裡做，像是給主做的，不是給人做的。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 6:8; 加拉太書 1:10; 使徒行傳 20:32"> 因你們知道，從主那裡必得著基業為賞賜，你們所侍奉的乃是主基督。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 10:34; 羅馬書 2:11; 哥林多後書 5:10"> 那行不義的必受不義的報應，主並不偏待人。</span>
</div>
</div>

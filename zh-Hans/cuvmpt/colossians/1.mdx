## 為門徒的信與愛與望感謝神

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 1:2; 歌羅西書 1:9; 提摩太後書 1:3"> 我們感謝神我們主耶穌基督的父，常常為你們禱告，</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 1:15; 帖撒羅尼迦後書 1:3; 帖撒羅尼迦前書 1:3"> 因聽見你們在基督耶穌裡的信心並向眾聖徒的愛心——</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:3–4; 以弗所書 1:13; 提摩太後書 4:8"> 是為那給你們存在天上的盼望。這盼望就是你們從前在福音真理的道上所聽見的。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:16; 腓立比書 1:11; 歌羅西書 1:23"> 這福音傳到你們那裡，也傳到普天之下，並且結果、增長，如同在你們中間，自從你們聽見福音真知道神恩惠的日子一樣。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 4:12; 腓利門書 1:23; 歌羅西書 4:7"> 正如你們從我們所親愛、一同做僕人的以巴弗所學的。他為我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：你們。">a</a></sup>做了基督忠心的執事，</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 15:30; 提摩太後書 1:7; 加拉太書 5:22"> 也把你們因聖靈所存的愛心告訴了我們。</span>
</div>
</div>

## 為門徒加增智慧力量忍耐禱告神

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各書 3:17; 腓立比書 1:9–11; 雅各書 1:5"> 因此，我們自從聽見的日子，也就為你們不住地禱告祈求，願你們在一切屬靈的智慧悟性上，滿心知道神的旨意，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 4:1; 希伯來書 13:21; 彼得後書 1:2–3"> 好叫你們行事為人對得起主，凡事蒙他喜悅，在一切善事上結果子，漸漸地多知道神；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:16; 腓立比書 4:13; 以弗所書 4:2"> 照他榮耀的權能，得以在各樣的力上加力，好叫你們凡事歡歡喜喜地忍耐寬容。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 20:32; 以弗所書 1:11; 以弗所書 1:18"> 又感謝父，叫我們能與眾聖徒在光明中同得基業。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 5:8; 使徒行傳 26:18; 彼得前書 2:9"> 他救了我們脫離黑暗的權勢，把我們遷到他愛子的國裡；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 1:7; 羅馬書 3:24–25; 彼得前書 1:19–20"> 我們在愛子裡得蒙救贖，罪過得以赦免。</span>
</div>
</div>

## 愛子是不能看見之神的像

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 1:3; 約翰福音 14:9; 約翰福音 1:1"> 愛子是那不能看見之神的像，是首生的，在一切被造的以先。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:36; 約翰福音 1:3; 哥林多前書 8:6"> 因為萬有都是靠他造的，無論是天上的、地上的，能看見的、不能看見的，或是有位的、主治的、執政的、掌權的，一概都是藉著他造的，又是為他造的。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 1:3; 哥林多前書 8:6; 使徒行傳 17:28"> 他在萬有之先，萬有也靠他而立。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 1:22–23; 啟示錄 1:5; 以弗所書 4:15–16"> 他也是教會全體之首。他是元始，是從死裡首先復生的，使他可以在凡事上居首位，</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 2:9; 約翰福音 1:16; 以弗所書 1:23"> 因為父喜歡叫一切的豐盛在他裡面居住。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 5:18–21; 以弗所書 1:10; 約翰一書 4:9–10"> 既然藉著他在十字架上所流的血成就了和平，便藉著他叫萬有，無論是地上的、天上的，都與自己和好了。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 2:12; 提多書 3:3–7; 以弗所書 2:1–3"> 你們從前與神隔絕，因著惡行，心裡與他為敵；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 5:27; 猶大書 1:24; 以弗所書 1:4"> 但如今他藉著基督的肉身受死，叫你們與自己和好，都成了聖潔，沒有瑕疵，無可責備，把你們引到自己面前。</span>
</div>
</div>

## 應當穩固不離開福音的盼望

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯來書 3:14; 希伯來書 3:6; 馬太福音 24:13–14"> 只要你們在所信的道上恆心，根基穩固，堅定不移，不致被引動失去<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：離開。">b</a></sup>福音的盼望。這福音就是你們所聽過的，也是傳於普天下萬人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「萬人」原文作「凡受造的」。">c</a></sup>聽的。我保羅也做了這福音的執事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="羅馬書 5:3; 提摩太後書 1:8; 哥林多後書 1:5–8"> 現在我為你們受苦，倒覺歡樂，並且為基督的身體，就是為教會，要在我肉身上補滿基督患難的缺欠。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所書 3:2; 歌羅西書 1:23; 加拉太書 2:7–8"> 我照神為你們所賜我的職分做了教會的執事，要把神的道理傳得全備。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 羅馬書 16:25–26; 以弗所書 3:3–10"> 這道理就是歷世歷代所隱藏的奧祕，但如今向他的聖徒顯明了。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:20; 羅馬書 8:10; 以弗所書 3:16–17"> 神願意叫他們知道，這奧祕在外邦人中有何等豐盛的榮耀，就是基督在你們心裡成了有榮耀的盼望。</span>
</div>
</div>

## 使各人在基督裡完全

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以弗所書 5:27; 耶利米書 3:15; 以弗所書 4:11–13"> 我們傳揚他，是用諸般的智慧勸誡各人，教導各人，要把各人在基督裡完完全全地引到神面前。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 15:10; 以弗所書 1:19; 哥林多前書 9:25–27"> 我也為此勞苦，照著他在我裡面運用的大能盡心竭力。</span>
</div>
</div>

## 巴比倫傾倒

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 43:2; 路加福音 17:24; 帖撒羅尼迦後書 2:8"> 此後，我看見另有一位有大權柄的天使從天降下，地就因他的榮耀發光。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 14:8; 耶利米書 51:8; 耶利米書 51:37"> 他大聲喊著說：<br /><span className="pl pl-1">「巴比倫大城傾倒了！傾倒了！</span><br /><span className="pl pl-1">成了鬼魔的住處</span><br /><span className="pl pl-1">和各樣汙穢之靈的巢穴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：牢獄。下同。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">並各樣汙穢可憎之雀鳥的巢穴。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 14:8; 啟示錄 17:2; 啟示錄 18:9"> <span className="pl pl-1">因為列國都被她邪淫大怒的酒傾倒了，</span><br /><span className="pl pl-1">地上的君王與她行淫，</span><br /><span className="pl pl-1">地上的客商因她奢華太過就發了財。」</span></span>
</div>
</div>

## 先有榮耀奢華後受悲哀痛苦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 52:11; 哥林多後書 6:17; 耶利米書 51:6"> 我又聽見從天上有聲音說：<br /><span className="pl pl-1">「我的民哪，你們要從那城出來，</span><br /><span className="pl pl-1">免得與她一同有罪，受她所受的災殃。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="創世記 18:20–21; 以斯拉記 9:6; 啟示錄 16:19"> <span className="pl pl-1">因她的罪惡滔天，</span><br /><span className="pl pl-1">她的不義，神已經想起來了。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:29; 詩篇 137:8; 耶利米書 51:24"> <span className="pl pl-1">她怎樣待人，也要怎樣待她，</span><br /><span className="pl pl-1">按她所行的加倍地報應她，</span><br /><span className="pl pl-1">用她調酒的杯加倍地調給她喝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 47:7–9; 西番雅書 2:15; 耶利米哀歌 1:1"> <span className="pl pl-1">她怎樣榮耀自己，怎樣奢華，</span><br /><span className="pl pl-1">也當叫她照樣痛苦悲哀；</span><br /><span className="pl pl-1">因她心裡說：</span><br /><span className="pl pl-1">『我坐了皇后的位，</span><br /><span className="pl pl-1">並不是寡婦，</span><br /><span className="pl pl-1">決不至於悲哀。』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 50:34; 耶利米書 50:31; 啟示錄 17:16"> <span className="pl pl-1">所以在一天之內，</span><br /><span className="pl pl-1">她的災殃要一齊來到，</span><br /><span className="pl pl-1">就是死亡、悲哀、饑荒。</span><br /><span className="pl pl-1">她又要被火燒盡了，</span><br /><span className="pl pl-1">因為審判她的主神大有能力。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:3; 啟示錄 18:3; 啟示錄 17:2"> 地上的君王，素來與她行淫、一同奢華的，看見燒她的煙，就必為她哭泣哀號。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 18:19; 啟示錄 18:8; 啟示錄 18:15–17"> 因怕她的痛苦，就遠遠地站著說：『哀哉！哀哉！<br /><span className="pl pl-1">巴比倫大城，堅固的城啊，</span><br /><span className="pl pl-1">一時之間你的刑罰就來到了！』</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 18:3; 啟示錄 18:23; 以西結書 27:27–36"> 地上的客商也都為她哭泣悲哀，因為沒有人再買他們的貨物了。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 17:4; 以西結書 27:5–25; 箴言 8:10–11"> 這貨物就是金、銀、寶石、珍珠、細麻布、紫色料、綢子、朱紅色料，各樣香木，各樣象牙的器皿，各樣極寶貴的木頭和銅、鐵、漢白玉的器皿，</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 27:13; 阿摩司書 2:6; 彼得後書 2:3"> 並肉桂、豆蔻、香料、香膏、乳香、酒、油、細麵、麥子、牛、羊、車、馬和奴僕、人口。</span>
</div>
</div>

## 因大城受報應聖徒都歡喜

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 10:6; 詩篇 106:14; 路加福音 16:25"> 「巴比倫哪，你所貪愛的果子離開了你，<br /><span className="pl pl-1">你一切的珍饈美味</span><br /><span className="pl pl-1">和華美的物件也從你中間毀滅，</span><br /><span className="pl pl-1">決不能再見了！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 18:3; 使徒行傳 19:24–27; 以西結書 27:31"> 販賣這些貨物，藉著她發了財的客商，因怕她的痛苦，就遠遠地站著哭泣悲哀，</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:4; 路加福音 16:19–31; 啟示錄 18:10–11"> 說：<br /><span className="pl pl-1">『哀哉，哀哉，這大城啊！</span><br /><span className="pl pl-1">素常穿著細麻、</span><br /><span className="pl pl-1">紫色、朱紅色的衣服，</span><br /><span className="pl pl-1">又用金子、寶石和珍珠為裝飾，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 27:27–36; 啟示錄 17:16; 以賽亞書 23:14"> <span className="pl pl-1">一時之間，這麼大的富厚就歸於無有了！』</span><br />凡船主和坐船往各處去的，並眾水手，連所有靠海為業的，都遠遠地站著，</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 13:4; 以西結書 27:30–32; 啟示錄 18:9–10"> 看見燒她的煙就喊著說：『有何城能比這大城呢？』</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 18:10; 約書亞記 7:6; 以西結書 27:30"> 他們又把塵土撒在頭上，哭泣悲哀，喊著說：<br /><span className="pl pl-1">『哀哉，哀哉，這大城啊！</span><br /><span className="pl pl-1">凡有船在海中的都因她的珍寶成了富足，</span><br /><span className="pl pl-1">她在一時之間就成了荒場！』</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 6:10; 啟示錄 19:1–3; 路加福音 18:7–8"> <span className="pl pl-1">天哪，眾聖徒、眾使徒、眾先知啊！</span><br /><span className="pl pl-1">你們都要因她歡喜，</span><br /><span className="pl pl-1">因為神已經在她身上申了你們的冤。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 51:63–64; 以西結書 26:21; 啟示錄 5:2"> 有一位大力的天使舉起一塊石頭，好像大磨石，扔在海裡說：<br /><span className="pl pl-1">「巴比倫大城也必這樣猛力地被扔下去，</span><br /><span className="pl pl-1">決不能再見了。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 26:13; 耶利米書 25:10; 耶利米書 7:34"> <span className="pl pl-1">彈琴、作樂、吹笛、吹號的聲音</span><br /><span className="pl pl-1">在你中間決不能再聽見。</span><br /><span className="pl pl-1">各行手藝人在你中間決不能再遇見。</span><br /><span className="pl pl-1">推磨的聲音在你中間決不能再聽見。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 18:3; 以賽亞書 23:8; 那鴻書 3:4"> <span className="pl pl-1">燈光在你中間決不能再照耀。</span><br /><span className="pl pl-1">新郎和新婦的聲音在你中間決不能再聽見。</span><br /><span className="pl pl-1">你的客商原來是地上的尊貴人，</span><br /><span className="pl pl-1">萬國也被你的邪術迷惑了。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="啟示錄 17:6; 啟示錄 16:6; 耶利米書 51:49"> 先知和聖徒並地上一切被殺之人的血，都在這城裡看見了。」</span>
</div>
</div>

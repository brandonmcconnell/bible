## 當回想所聽見所領受的

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="啟示錄 2:5; 彼得後書 3:10; 帖撒羅尼迦前書 5:2"> <span className="woj">『所以要回想你是怎樣領受、怎樣聽見的，又要遵守，並要悔改。若不警醒，我必臨到你那裡，如同賊一樣。我幾時臨到，你也決不能知道。</span></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:5; 啟示錄 7:9; 傳道書 9:8"> <span className="woj">然而在撒狄，你還有幾名是未曾汙穢自己衣服的，他們要穿白衣與我同行，因為他們是配得過的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 10:32; 路加福音 12:8; 啟示錄 21:27"> <span className="woj">凡得勝的，必這樣穿白衣，我也必不從生命冊上塗抹他的名，且要在我父面前和我父眾使者面前，認他的名。</span></span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:7"> <span className="woj">聖靈向眾教會所說的話，凡有耳的，就應當聽！』</span></span>
</div>
</div>

## 寄信給非拉鐵非

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:22; 馬太福音 16:19; 啟示錄 1:18"> <span className="woj">「你要寫信給非拉鐵非教會的使者說：『那聖潔、真實，拿著大衛的鑰匙，開了就沒有人能關、關了就沒有人能開的說：</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 16:9; 歌羅西書 4:3; 啟示錄 3:7"> <span className="woj">我知道你的行為，你略有一點力量，也曾遵守我的道，沒有棄絕我的名，看哪，我在你面前給你一個敞開的門，是無人能關的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:14; 啟示錄 2:9; 以賽亞書 49:23"> <span className="woj">那撒旦一會的，自稱是猶太人，其實不是猶太人，乃是說謊話的，我要使他們來在你腳前下拜，也使他們知道我是已經愛你了。</span></span>
</div>
</div>

<span className="v" id="v11" data-v="11" data-xref="雅各書 1:12; 啟示錄 22:12; 啟示錄 2:10"> <span className="woj">我必快來！你要持守你所有的，免得人奪去你的冠冕。</span></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 22:4; 啟示錄 21:2; 啟示錄 14:1"> <span className="woj">得勝的，我要叫他在我神殿中做柱子，他也必不再從那裡出去。我又要將我神的名和我神城的名——這城就是從天上、從我神那裡降下來的新耶路撒冷——並我的新名，都寫在他上面。</span></span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 2:7"> <span className="woj">聖靈向眾教會所說的話，凡有耳的，就應當聽！』</span></span>
</div>
</div>

## 當買火煉金子

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; 何西阿書 12:8; 羅馬書 7:24"> <span className="woj">『你說「我是富足，已經發了財，一樣都不缺」，卻不知道你是那困苦、可憐、貧窮、瞎眼、赤身的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 16:15; 彼得前書 1:7; 以賽亞書 55:1"> <span className="woj">我勸你向我買火煉的金子，叫你富足；又買白衣穿上，叫你赤身的羞恥不露出來；又買眼藥擦你的眼睛，使你能看見。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前書 11:32; 希伯來書 12:5–11"> <span className="woj">凡我所疼愛的，我就責備管教他，所以你要發熱心，也要悔改。</span></span>

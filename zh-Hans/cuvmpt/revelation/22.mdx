## 生命水和生命樹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 7:17; 約翰福音 4:14; 詩篇 36:8–9"> 天使又指示我在城內街道當中一道生命水的河，明亮如水晶，從神和羔羊的寶座流出來。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 22:1; 彼得前書 2:24; 啟示錄 2:7"> 在河這邊與那邊有生命樹，結十二樣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「樣」或作「回」。">a</a></sup>果子，每月都結果子，樹上的葉子乃為醫治萬民。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 25:21; 啟示錄 21:3–4; 約翰福音 12:26"> 以後再沒有咒詛。在城裡有神和羔羊的寶座，他的僕人都要侍奉他，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 5:8; 啟示錄 14:1; 啟示錄 3:12"> 也要見他的面。他的名字必寫在他們的額上。</span>
</div>
</div>

## 不再有黑夜

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 60:19–20; 但以理書 7:18; 啟示錄 20:4"> 不再有黑夜，他們也不用燈光、日光，因為主神要光照他們。他們要做王，直到永永遠遠。</span>
</div>
</div>

## 遵守這書上預言的有福了

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:1; 啟示錄 21:5; 啟示錄 19:9"> 天使又對我說：「這些話是真實可信的。主，就是眾先知被感之靈的神，差遣他的使者，將那必要快成的事指示他僕人。」</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 1:3; 啟示錄 3:11; 啟示錄 22:20"> <span className="woj">「看哪，我必快來！凡遵守這書上預言的有福了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 19:10; 啟示錄 1:1; 啟示錄 19:19"> 這些事是我約翰所聽見、所看見的，我既聽見、看見了，就在指示我的天使腳前俯伏要拜他。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:10; 歌羅西書 2:18–19; 啟示錄 14:7"> 他對我說：「千萬不可！我與你，和你的弟兄眾先知，並那些守這書上言語的人，同是做僕人的。你要敬拜神！」</span>
</div>
</div>

## 賞罰在主主必報應

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 8:26; 啟示錄 1:3; 彼得前書 4:7"> 他又對我說：「不可封了這書上的預言，因為日期近了。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:10; 箴言 4:18; 以西結書 3:27"> 不義的，叫他仍舊不義；汙穢的，叫他仍舊汙穢；為義的，叫他仍舊為義；聖潔的，叫他仍舊聖潔。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 16:27; 以賽亞書 62:11; 以賽亞書 40:10"> <span className="woj">「看哪，我必快來！賞罰在我，要照各人所行的報應他。</span></span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 1:8; 啟示錄 21:6; 以賽亞書 44:6"> <span className="woj">我是阿拉法，我是俄梅戛；我是首先的，我是末後的；我是初，我是終。</span></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:27; 約翰一書 5:3; 啟示錄 22:7"> <span className="woj">那些洗淨自己衣服的有福了！可得權柄能到生命樹那裡，也能從門進城。</span></span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 21:8; 加拉太書 5:19–21; 腓立比書 3:2"> <span className="woj">城外有那些犬類、行邪術的、淫亂的、殺人的、拜偶像的，並一切喜好說謊言、編造虛謊的。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 5:5; 彼得後書 1:19; 以賽亞書 11:1"> <span className="woj">「我耶穌差遣我的使者為眾教會將這些事向你們證明。我是大衛的根，又是他的後裔；我是明亮的晨星。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:14; 啟示錄 21:6; 以賽亞書 55:1–3"> 聖靈和新婦都說：「來！」聽見的人也該說：「來！」口渴的人也當來，願意的都可以白白取生命的水喝。</span>
</div>
</div>

## 警戒增減這書上的預言

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:2; 箴言 30:6"> 我向一切聽見這書上預言的作見證：若有人在這預言上加添什麼，神必將寫在這書上的災禍加在他身上；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:2; 路加福音 11:52; 啟示錄 22:2"> 這書上的預言，若有人刪去什麼，神必從這書上所寫的生命樹和聖城刪去他的份。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="啟示錄 22:7; 希伯來書 9:28; 啟示錄 22:12"> 證明這事的說：<span className="woj">「是了，我必快來！」</span>阿們！主耶穌啊，我願你來！</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦後書 3:18; 羅馬書 16:20; 哥林多後書 13:14"> 願主耶穌的恩惠常與眾聖徒同在！阿們。</span>
</div>
</div>

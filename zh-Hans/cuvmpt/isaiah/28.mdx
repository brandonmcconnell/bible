<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 7:5; 以賽亞書 28:7; 列王紀下 14:25–27"> <span className="pl pl-1">禍哉，以法蓮的酒徒！</span><br /><span className="pl pl-1">住在肥美谷的山上，</span><br /><span className="pl pl-1">他們心裡高傲，</span><br /><span className="pl pl-1">以所誇的為冠冕，</span><br /><span className="pl pl-1">猶如將殘之花。</span><br /></span>

## 耶和華為其民之華冕

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="彼得前書 5:4; 以賽亞書 62:3; 以賽亞書 60:19"> <span className="pl pl-1">到那日，萬軍之耶和華</span><br /><span className="pl pl-1">必做他餘剩之民的榮冠華冕，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 18:32–34; 約翰福音 5:30; 約書亞記 1:9"> <span className="pl pl-1">也做了在位上行審判者公平之靈，</span><br /><span className="pl pl-1">並城門口打退仇敵者的力量。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 56:10–12; 路加福音 21:34; 以賽亞書 19:14"> <span className="pl pl-1">就是這地的人，也因酒搖搖晃晃，</span><br /><span className="pl pl-1">因濃酒東倒西歪。</span><br /><span className="pl pl-1">祭司和先知因濃酒搖搖晃晃，</span><br /><span className="pl pl-1">被酒所困，</span><br /><span className="pl pl-1">因濃酒東倒西歪。</span><br /><span className="pl pl-1">他們錯解默示，</span><br /><span className="pl pl-1">謬行審判。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 48:26; 箴言 26:11; 哈巴谷書 2:15–16"> <span className="pl pl-1">因為各席上滿了嘔吐的汙穢，</span><br /><span className="pl pl-1">無一處乾淨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 131:2; 耶利米書 6:10; 約翰福音 12:38"> <span className="pl pl-1">譏誚先知的說：</span><br /><span className="pl pl-1">「他要將知識指教誰呢？</span><br /><span className="pl pl-1">要使誰明白傳言呢？</span><br /><span className="pl pl-1">是那剛斷奶離懷的嗎？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 28:13; 提摩太後書 3:7; 耶利米書 11:7"> <span className="pl pl-1">他竟命上加命，令上加令，</span><br /><span className="pl pl-1">律上加律，例上加例，</span><br /><span className="pl pl-1">這裡一點，那裡一點！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 14:21; 申命記 28:49; 以賽亞書 33:19"> <span className="pl pl-1">先知說：「不然！主要藉異邦人的嘴唇</span><br /><span className="pl pl-1">和外邦人的舌頭對這百姓說話。」</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 11:28–29; 以賽亞書 30:15; 耶利米書 6:16"> <span className="pl pl-1">他曾對他們說：</span><br /><span className="pl pl-1">「你們要使疲乏人得安息，</span><br /><span className="pl pl-1">這樣才得安息，才得舒暢。」</span><br /><span className="pl pl-1">他們卻不肯聽。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 13:14; 以賽亞書 6:9–10; 彼得後書 3:16"> <span className="pl pl-1">所以耶和華向他們說的話是</span><br /><span className="pl pl-1">「命上加命，令上加令，</span><br /><span className="pl pl-1">律上加律，例上加例，</span><br /><span className="pl pl-1">這裡一點，那裡一點」，</span><br /><span className="pl pl-1">以致他們前行仰面跌倒，</span><br /><span className="pl pl-1">而且跌碎，並陷入網羅，被纏住。</span></span>
</div>
</div>

## 置寶貴隅石於錫安

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 28:22; 以賽亞書 29:20; 以賽亞書 1:10"> <span className="pl pl-1">所以你們這些褻慢的人，</span><br /><span className="pl pl-1">就是轄管住在耶路撒冷這百姓的，</span><br /><span className="pl pl-1">要聽耶和華的話！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 8:7–8; 以西結書 13:22; 阿摩司書 2:4"> <span className="pl pl-1">你們曾說：</span><br /><span className="pl pl-1">「我們與死亡立約，</span><br /><span className="pl pl-1">與陰間結盟。</span><br /><span className="pl pl-1">敵軍</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：鞭子。">a</a></sup><br /><span className="pl pl-1">如水漲漫經過的時候，</span><br /><span className="pl pl-1">必不臨到我們。</span><br /><span className="pl pl-1">因我們以謊言為避所，</span><br /><span className="pl pl-1">在虛假以下藏身。」</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 118:22; 使徒行傳 4:11–12; 彼得前書 2:6–8"> <span className="pl pl-1">所以主耶和華如此說：</span><br /><span className="pl pl-1">「看哪，我在錫安放一塊石頭作為根基，</span><br /><span className="pl pl-1">是試驗過的石頭，</span><br /><span className="pl pl-1">是穩固根基，寶貴的房角石，</span><br /><span className="pl pl-1">信靠的人必不著急。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:13; 阿摩司書 7:7–9; 啟示錄 16:21"> <span className="pl pl-1">我必以公平為準繩，</span><br /><span className="pl pl-1">以公義為線砣，</span><br /><span className="pl pl-1">冰雹必沖去謊言的避所，</span><br /><span className="pl pl-1">大水必漫過藏身之處。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 7:7; 以賽亞書 8:10; 以賽亞書 28:15"> <span className="pl pl-1">你們與死亡所立的約必然廢掉，</span><br /><span className="pl pl-1">與陰間所結的盟必立不住。</span><br /><span className="pl pl-1">敵軍如水漲漫經過的時候，</span><br /><span className="pl pl-1">你們必被他踐踏。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 3:16; 以賽亞書 36:22; 列王紀下 24:2"> <span className="pl pl-1">每逢經過，必將你們擄去，</span><br /><span className="pl pl-1">因為每早晨他必經過，</span><br /><span className="pl pl-1">白晝黑夜都必如此。」</span><br /><span className="pl pl-1">明白傳言的，必受驚恐。</span><br /></span>

<span className="v" id="v21" data-v="21" data-xref="歷代志上 14:11; 約書亞記 10:12; 撒母耳記下 5:20"> <span className="pl pl-1">耶和華必興起像在毗拉心山，</span><br /><span className="pl pl-1">他必發怒像在基遍谷，</span><br /><span className="pl pl-1">好做成他的工，就是非常的工，</span><br /><span className="pl pl-1">成就他的事，就是奇異的事。</span></span>
</div>
</div>

## 戒民褻慢

<div className="bt">
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 10:22–23; 以賽亞書 24:1–23; 馬太福音 27:44"> <span className="pl pl-1">現在你們不可褻慢，</span><br /><span className="pl pl-1">恐怕捆你們的綁索更結實了。</span><br /><span className="pl pl-1">因為我從主萬軍之耶和華那裡聽見，</span><br /><span className="pl pl-1">已經決定在全地上施行滅絕的事。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 1:2; 耶利米書 22:29; 啟示錄 2:11"> <span className="pl pl-1">你們當側耳聽我的聲音，</span><br /><span className="pl pl-1">留心聽我的言語。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 4:3; 何西阿書 10:11–12"> <span className="pl pl-1">那耕地為要撒種的，</span><br /><span className="pl pl-1">豈是常常耕地呢？</span><br /><span className="pl pl-1">豈是常常開墾耙地呢？</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 4:9; 馬太福音 23:23; 出埃及記 9:31–32"> <span className="pl pl-1">他拉平了地面，</span><br /><span className="pl pl-1">豈不就撒種小茴香，</span><br /><span className="pl pl-1">播種大茴香，</span><br /><span className="pl pl-1">按行列種小麥，</span><br /><span className="pl pl-1">在定處種大麥，</span><br /><span className="pl pl-1">在田邊種粗麥呢？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 31:3–6; 出埃及記 36:2; 約伯記 39:17"> <span className="pl pl-1">因為他的神教導他務農相宜，</span><br /><span className="pl pl-1">並且指教他。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 41:15; 以賽亞書 27:7–8; 耶利米書 46:28"> <span className="pl pl-1">原來打小茴香不用尖利的器具，</span><br /><span className="pl pl-1">軋大茴香也不用碌碡</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：車輪。下同。">b</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">但用杖打小茴香，</span><br /><span className="pl pl-1">用棍打大茴香。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 9:9–10; 馬太福音 3:12; 約翰福音 12:24"> <span className="pl pl-1">做餅的糧食是用磨磨碎，</span><br /><span className="pl pl-1">因他不必常打；</span><br /><span className="pl pl-1">雖用碌碡和馬打散，</span><br /><span className="pl pl-1">卻不磨它。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 11:33; 耶利米書 32:19; 約伯記 5:9"> <span className="pl pl-1">這也是出於萬軍之耶和華，</span><br /><span className="pl pl-1">他的謀略奇妙，</span><br /><span className="pl pl-1">他的智慧廣大。</span></span>

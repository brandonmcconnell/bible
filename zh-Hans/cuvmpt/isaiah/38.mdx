## 希西家遘疾祈禱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 38:1–8; 歷代志下 32:24; 列王紀下 20:1–11"> 那時，希西家病得要死。亞摩斯的兒子先知以賽亞去見他，對他說：「耶和華如此說：你當留遺命於你的家，因為你必死，不能活了。」</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:6; 詩篇 91:15; 列王紀上 8:30"> 希西家就轉臉朝牆，禱告耶和華說：</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 5:7; 詩篇 18:20–27; 希伯來書 6:10"> 「耶和華啊，求你記念我在你面前怎樣存完全的心，按誠實行事，又做你眼中所看為善的。」希西家就痛哭了。</span>
</div>
</div>

## 以賽亞奉諭慰藉之

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶和華的話臨到以賽亞說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:5–6; 約翰一書 5:14–15; 啟示錄 7:17"> 「你去告訴希西家說：『耶和華你祖大衛的神如此說：我聽見了你的禱告，看見了你的眼淚。我必加增你十五年的壽數，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:35; 以賽亞書 31:4–5; 以賽亞書 12:6"> 並且我要救你和這城脫離亞述王的手，也要保護這城。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:37–39; 以賽亞書 37:30; 以賽亞書 7:11–14"> 我耶和華必成就我所說的，我先給你一個兆頭，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 20:9–11; 約書亞記 10:12–14; 馬太福音 16:1"> 就是叫亞哈斯的日晷向前進的日影往後退十度。』」於是前進的日影果然在日晷上往後退了十度。</span>
</div>
</div>

## 希西家感恩之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:1; 出埃及記 15:1–21; 約伯記 5:18"> 猶大王希西家患病已經痊癒，就作詩說：</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:24; 哥林多後書 1:9; 詩篇 107:18"> <span className="pl pl-1">「我說，正在我中年</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：晌午。">a</a></sup><br /><span className="pl pl-1">之日，</span><br /><span className="pl pl-1">必進入陰間的門，</span><br /><span className="pl pl-1">我餘剩的年歲不得享受。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:13; 詩篇 116:8–9; 詩篇 31:22"> <span className="pl pl-1">我說，我必不得見耶和華，</span><br /><span className="pl pl-1">就是在活人之地不見耶和華，</span><br /><span className="pl pl-1">我與世上的居民不再見面。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 73:14; 哥林多後書 5:1; 希伯來書 1:12"> <span className="pl pl-1">我的住處被遷去離開我，</span><br /><span className="pl pl-1">好像牧人的帳篷一樣。</span><br /><span className="pl pl-1">我將性命捲起，</span><br /><span className="pl pl-1">像織布的捲布一樣，</span><br /><span className="pl pl-1">耶和華必將我從機頭剪斷；</span><br /><span className="pl pl-1">從早到晚，他要使我完結。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:8; 但以理書 6:24; 詩篇 50:22"> <span className="pl pl-1">我使自己安靜直到天亮，</span><br /><span className="pl pl-1">他像獅子折斷我一切的骨頭；</span><br /><span className="pl pl-1">從早到晚，他要使我完結。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 59:11; 詩篇 69:3; 詩篇 123:1–4"> <span className="pl pl-1">我像燕子呢喃，</span><br /><span className="pl pl-1">像白鶴鳴叫，</span><br /><span className="pl pl-1">又像鴿子哀鳴，</span><br /><span className="pl pl-1">我因仰觀，眼睛困倦。</span><br /><span className="pl pl-1">耶和華啊，我受欺壓，</span><br /><span className="pl pl-1">求你為我作保！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 21:27; 約伯記 7:11; 約伯記 10:1"> <span className="pl pl-1">我可說什麼呢？</span><br /><span className="pl pl-1">他應許我的，也給我成就了。</span><br /><span className="pl pl-1">我因心裡的苦楚，</span><br /><span className="pl pl-1">在一生的年日必悄悄而行。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 12:10–11; 哥林多前書 11:32; 詩篇 119:25"> <span className="pl pl-1">主啊，人得存活乃在乎此，</span><br /><span className="pl pl-1">我靈存活也全在此，</span><br /><span className="pl pl-1">所以求你使我痊癒，仍然存活。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 43:25; 彌迦書 7:18–19; 約拿書 2:6"> <span className="pl pl-1">看哪，我受大苦本為使我得平安，</span><br /><span className="pl pl-1">你因愛我的靈魂</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：生命。">b</a></sup><br /><span className="pl pl-1">，便救我脫離敗壞的坑，</span><br /><span className="pl pl-1">因為你將我一切的罪扔在你的背後。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 9:10; 詩篇 30:9; 詩篇 6:5"> <span className="pl pl-1">原來陰間不能稱謝你，</span><br /><span className="pl pl-1">死亡不能頌揚你，</span><br /><span className="pl pl-1">下坑的人不能盼望你的誠實。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 詩篇 119:175; 詩篇 78:3–6"> <span className="pl pl-1">只有活人，活人必稱謝你，</span><br /><span className="pl pl-1">像我今日稱謝你一樣，</span><br /><span className="pl pl-1">為父的必使兒女知道你的誠實。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 116:2; 詩篇 150:4; 詩篇 145:2"> <span className="pl pl-1">耶和華肯救我，</span><br /><span className="pl pl-1">所以我們要一生一世，</span><br /><span className="pl pl-1">在耶和華殿中</span><br /><span className="pl pl-1">用絲弦的樂器唱我的詩歌。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀下 20:7–8; 馬可福音 7:33; 約翰福音 9:6"> 以賽亞說：「當取一塊無花果餅來，貼在瘡上，王必痊癒。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 118:18–19; 列王紀下 20:8; 約翰福音 5:14"> 希西家問說：「我能上耶和華的殿，有什麼兆頭呢？」</span>
</div>

## 預示埃及之禍亂

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:12; 啟示錄 1:7; 約書亞記 2:11"> 論埃及的默示。<br /><span className="pl pl-1">看哪，耶和華乘駕快雲，</span><br /><span className="pl pl-1">臨到埃及。</span><br /><span className="pl pl-1">埃及的偶像在他面前戰兢，</span><br /><span className="pl pl-1">埃及人的心在裡面消化。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="士師記 7:22; 撒母耳記上 14:20; 馬太福音 10:36"> <span className="pl pl-1">「我必激動埃及人攻擊埃及人，</span><br /><span className="pl pl-1">弟兄攻擊弟兄，</span><br /><span className="pl pl-1">鄰舍攻擊鄰舍，</span><br /><span className="pl pl-1">這城攻擊那城，</span><br /><span className="pl pl-1">這國攻擊那國。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 8:19; 但以理書 2:2; 歷代志上 10:13"> <span className="pl pl-1">埃及人的心神必在裡面耗盡，</span><br /><span className="pl pl-1">我必敗壞他們的謀略，</span><br /><span className="pl pl-1">他們必求問偶像和念咒的、</span><br /><span className="pl pl-1">交鬼的、行巫術的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 20:4; 耶利米書 46:26; 以西結書 29:19"> <span className="pl pl-1">我必將埃及人交在殘忍主的手中，</span><br /><span className="pl pl-1">強暴王必轄制他們。」</span><br /><span className="pl pl-1">這是主萬軍之耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 51:36; 以西結書 30:12; 撒迦利亞書 14:18"> <span className="pl pl-1">海中的水必絕盡，</span><br /><span className="pl pl-1">河也消沒乾涸。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:25; 出埃及記 7:18; 列王紀下 19:24"> <span className="pl pl-1">江河要變臭，</span><br /><span className="pl pl-1">埃及的河水都必減少枯乾，</span><br /><span className="pl pl-1">葦子和蘆荻都必衰殘。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 32:20; 約珥書 1:17–18; 以賽亞書 23:3"> <span className="pl pl-1">靠尼羅河旁的草田，</span><br /><span className="pl pl-1">並沿尼羅河所種的田，都必枯乾，</span><br /><span className="pl pl-1">莊稼被風吹去，歸於無有。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 47:10; 哈巴谷書 1:15; 民數記 11:5"> <span className="pl pl-1">打魚的必哀哭，</span><br /><span className="pl pl-1">在尼羅河一切釣魚的必悲傷，</span><br /><span className="pl pl-1">在水上撒網的必都衰弱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 27:7; 箴言 7:16; 列王紀上 10:28"> <span className="pl pl-1">用梳好的麻造物的，</span><br /><span className="pl pl-1">和織白布的，都必羞愧。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:10; 出埃及記 7:19; 出埃及記 8:5"> <span className="pl pl-1">國柱必被打碎，</span><br /><span className="pl pl-1">所有傭工的心必愁煩。</span></span>
</div>
</div>

## 牧伯謀士盡為愚蒙

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="民數記 13:22; 使徒行傳 7:22; 列王紀上 4:30"> <span className="pl pl-1">瑣安的首領極其愚昧，</span><br /><span className="pl pl-1">法老大有智慧的謀士</span><br /><span className="pl pl-1">所籌劃的成為愚謀。</span><br /><span className="pl pl-1">你們怎敢對法老說</span><br /><span className="pl pl-1">「我是智慧人的子孫，</span><br /><span className="pl pl-1">我是古王的後裔」？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 1:20; 以賽亞書 14:24; 士師記 9:38"> <span className="pl pl-1">你的智慧人在哪裡呢？</span><br /><span className="pl pl-1">萬軍之耶和華向埃及所定的旨意，</span><br /><span className="pl pl-1">他們可以知道，可以告訴你吧！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 30:13; 耶利米書 2:16; 耶利米書 46:14"> <span className="pl pl-1">瑣安的首領都變為愚昧，</span><br /><span className="pl pl-1">挪弗的首領都受了迷惑，</span><br /><span className="pl pl-1">當埃及支派房角石的</span><br /><span className="pl pl-1">使埃及人走錯了路。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦後書 2:11; 列王紀上 22:20–23; 以西結書 14:7–9"> <span className="pl pl-1">耶和華使乖謬的靈摻入埃及中間，</span><br /><span className="pl pl-1">首領使埃及一切所做的都有差錯，</span><br /><span className="pl pl-1">好像醉酒之人嘔吐的時候東倒西歪一樣。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 9:14–15; 帖撒羅尼迦前書 4:11–12; 箴言 14:23"> <span className="pl pl-1">埃及中，無論是頭與尾，</span><br /><span className="pl pl-1">棕枝與蘆葦，所做之工都不成就。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 51:30; 那鴻書 3:13; 以賽亞書 11:15"> 到那日，埃及人必像婦人一樣，他們必因萬軍之耶和華在埃及以上所掄的手戰兢懼怕。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 14:24; 但以理書 4:35; 以西結書 29:6–7"> 猶大地必使埃及驚恐，向誰提起猶大地，誰就懼怕。這是因萬軍之耶和華向埃及所定的旨意。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="西番雅書 3:9; 撒迦利亞書 2:11; 以賽亞書 19:21"> 當那日，埃及地必有五城的人說迦南的方言，又指著萬軍之耶和華起誓，有一城必稱為滅亡城。</span>
</div>
</div>

## 埃及人識主蒙救

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 28:18; 約書亞記 22:10; 約書亞記 22:26"> 當那日，在埃及地中必有為耶和華築的一座壇，在埃及的邊界上必有為耶和華立的一根柱。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:15; 提多書 2:13; 以賽亞書 45:21–22"> 這都要在埃及地為萬軍之耶和華做記號和證據。埃及人因為受人的欺壓哀求耶和華，他就差遣一位救主，做護衛者，拯救他們。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 11:9; 瑪拉基書 1:11; 約翰福音 17:3"> 耶和華必被埃及人所認識，在那日，埃及人必認識耶和華，也要獻祭物和供物敬拜他，並向耶和華許願還願。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; 希伯來書 12:11; 何西阿書 14:1"> 耶和華必擊打埃及，又擊打又醫治，埃及人就歸向耶和華。他必應允他們的禱告，醫治他們。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 11:16; 以弗所書 2:18–22; 以賽亞書 35:8–10"> 當那日，必有從埃及通亞述去的大道，亞述人要進入埃及，埃及人也進入亞述，埃及人要與亞述人一同敬拜耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 65:8; 創世記 12:2; 加拉太書 3:14"> 當那日，以色列必與埃及、亞述三國一律，使地上的人得福。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 29:23; 何西阿書 2:23; 羅馬書 9:24–25"> 因為萬軍之耶和華賜福給他們，說：「埃及我的百姓，亞述我手的工作，以色列我的產業，都有福了！」</span>
</div>
</div>

## 末日萬民必歸耶和華殿之山

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:1; 以賽亞書 13:1; 哈巴谷書 1:1"> 亞摩斯的兒子以賽亞得默示，論到猶大和耶路撒冷。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="彌迦書 4:1–3; 以賽亞書 56:7; 撒迦利亞書 8:3"> <span className="pl pl-1">末後的日子，耶和華殿的山必堅立</span><br /><span className="pl pl-1">超乎諸山，高舉過於萬嶺，</span><br /><span className="pl pl-1">萬民都要流歸這山。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 50:4–5; 路加福音 24:47; 撒迦利亞書 8:20–23"> <span className="pl pl-1">必有許多國的民前往，說：</span><br /><span className="pl pl-1">「來吧！我們登耶和華的山，</span><br /><span className="pl pl-1">奔雅各神的殿。</span><br /><span className="pl pl-1">主必將他的道教訓我們，</span><br /><span className="pl pl-1">我們也要行他的路，</span><br /><span className="pl pl-1">因為訓誨必出於錫安，</span><br /><span className="pl pl-1">耶和華的言語必出於耶路撒冷。」</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 2:18; 彌迦書 4:3; 以賽亞書 11:6–9"> <span className="pl pl-1">他必在列國中施行審判，</span><br /><span className="pl pl-1">為許多國民斷定是非。</span><br /><span className="pl pl-1">他們要將刀打成犁頭，</span><br /><span className="pl pl-1">把槍打成鐮刀。</span><br /><span className="pl pl-1">這國不舉刀攻擊那國，</span><br /><span className="pl pl-1">他們也不再學習戰事。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以弗所書 5:8; 路加福音 1:79; 以賽亞書 60:19–20"> <span className="pl pl-1">雅各家啊，來吧，</span><br /><span className="pl pl-1">我們在耶和華的光明中行走！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 11:20; 列王紀下 1:2; 詩篇 106:35"> <span className="pl pl-1">耶和華，你離棄了你百姓雅各家，</span><br /><span className="pl pl-1">是因他們充滿了東方的風俗，</span><br /><span className="pl pl-1">做觀兆的，像非利士人一樣，</span><br /><span className="pl pl-1">並與外邦人擊掌。</span><br /></span>

<span className="v" id="v8" data-v="8" data-xref="詩篇 115:4–8; 啟示錄 9:20; 耶利米書 2:28"> <span className="pl pl-1">他們的地滿了偶像，</span><br /><span className="pl pl-1">他們跪拜自己手所造的，</span><br /><span className="pl pl-1">就是自己指頭所做的。</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:15–16; 詩篇 18:27; 以賽亞書 2:17"> <span className="pl pl-1">到那日，眼目高傲的必降為卑，</span><br /><span className="pl pl-1">性情狂傲的都必屈膝，</span><br /><span className="pl pl-1">唯獨耶和華被尊崇。</span></span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="瑪拉基書 4:1; 以賽亞書 23:9; 箴言 16:5"> <span className="pl pl-1">必有萬軍耶和華降罰的一個日子，</span><br /><span className="pl pl-1">要臨到驕傲狂妄的，</span><br /><span className="pl pl-1">一切自高的都必降為卑；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 14:8; 撒迦利亞書 11:1–2; 以西結書 31:3–12"> <span className="pl pl-1">又臨到黎巴嫩高大的香柏樹和巴珊的橡樹；</span><br /></span>

## 耶西之根將發枝結實

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 23:5; 啟示錄 22:16; 撒迦利亞書 6:12"> <span className="pl pl-1">從耶西的本</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：𣎴。">a</a></sup><br /><span className="pl pl-1">必發一條，</span><br /><span className="pl pl-1">從他根生的枝子必結果實。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 61:1; 約翰福音 16:13; 以弗所書 1:17–18"> <span className="pl pl-1">耶和華的靈必住在他身上，</span><br /><span className="pl pl-1">就是使他有智慧和聰明的靈，</span><br /><span className="pl pl-1">謀略和能力的靈，</span><br /><span className="pl pl-1">知識和敬畏耶和華的靈。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 7:24; 約翰福音 8:15–16; 路加福音 2:52"> <span className="pl pl-1">他必以敬畏耶和華為樂，</span><br /><span className="pl pl-1">行審判不憑眼見，</span><br /><span className="pl pl-1">斷是非也不憑耳聞；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦後書 2:8; 啟示錄 19:15; 瑪拉基書 4:6"> <span className="pl pl-1">卻要以公義審判貧窮人，</span><br /><span className="pl pl-1">以正直判斷世上的謙卑人，</span><br /><span className="pl pl-1">以口中的杖擊打世界，</span><br /><span className="pl pl-1">以嘴裡的氣殺戮惡人。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 6:14; 約翰一書 1:9; 哥林多後書 6:7"> <span className="pl pl-1">公義必當他的腰帶，</span><br /><span className="pl pl-1">信實必當他脅下的帶子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 65:25; 何西阿書 2:18; 以西結書 34:25"> <span className="pl pl-1">豺狼必與綿羊羔同居，</span><br /><span className="pl pl-1">豹子與山羊羔同臥，</span><br /><span className="pl pl-1">少壯獅子與牛犢並肥畜同群，</span><br /><span className="pl pl-1">小孩子要牽引牠們。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">牛必與熊同食，</span><br /><span className="pl pl-1">牛犢必與小熊同臥，</span><br /><span className="pl pl-1">獅子必吃草與牛一樣。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 59:5; 詩篇 140:3"> <span className="pl pl-1">吃奶的孩子必玩耍在虺蛇的洞口，</span><br /><span className="pl pl-1">斷奶的嬰兒必按手在毒蛇的穴上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="哈巴谷書 2:14; 以賽亞書 52:10; 詩篇 98:2–3"> <span className="pl pl-1">在我聖山的遍處，</span><br /><span className="pl pl-1">這一切都不傷人，不害物，</span><br /><span className="pl pl-1">因為認識耶和華的知識要充滿遍地，</span><br /><span className="pl pl-1">好像水充滿洋海一般。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 15:9–12; 路加福音 2:32; 以賽亞書 11:1"> 到那日，耶西的根立做萬民的大旗，外邦人必尋求他，他安息之所大有榮耀。</span>
</div>
</div>

## 以色列民旋返異邦亦歸附主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="彌迦書 7:12; 以賽亞書 10:20; 撒迦利亞書 10:8–12"> 當那日，主必二次伸手救回自己百姓中所餘剩的，就是在亞述、埃及、巴忒羅、古實、以攔、示拿、哈馬並眾海島所剩下的。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 56:8; 以賽亞書 43:6; 西番雅書 3:10"> <span className="pl pl-1">他必向列國豎立大旗，</span><br /><span className="pl pl-1">招回以色列被趕散的人，</span><br /><span className="pl pl-1">又從地的四方聚集分散的猶大人。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 3:18; 何西阿書 1:11; 以西結書 37:16–24"> <span className="pl pl-1">以法蓮的嫉妒就必消散，</span><br /><span className="pl pl-1">擾害猶大的必被剪除；</span><br /><span className="pl pl-1">以法蓮必不嫉妒猶大，</span><br /><span className="pl pl-1">猶大也不擾害以法蓮。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約珥書 3:19; 以賽亞書 25:10; 耶利米書 49:28"> <span className="pl pl-1">他們要向西飛，</span><br /><span className="pl pl-1">撲在非利士人的肩頭上</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「肩頭上」或作「西界」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">一同擄掠東方人，</span><br /><span className="pl pl-1">伸手按住以東和摩押，</span><br /><span className="pl pl-1">亞捫人也必順服他們。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 10:11; 啟示錄 16:12; 以賽亞書 50:2"> <span className="pl pl-1">耶和華必使埃及海汊枯乾，</span><br /><span className="pl pl-1">掄手用暴熱的風使大河分為七條，</span><br /><span className="pl pl-1">令人過去不致濕腳。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 19:23; 以賽亞書 35:8–10; 以賽亞書 11:11"> <span className="pl pl-1">為主餘剩的百姓，</span><br /><span className="pl pl-1">就是從亞述剩下回來的，</span><br /><span className="pl pl-1">必有一條大道，</span><br /><span className="pl pl-1">如當日以色列從埃及地上來一樣。</span></span>
</div>

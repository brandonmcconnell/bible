## 軟弱者將得助

<div className="bt">
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="希伯來書 12:12; 約伯記 4:3–4; 路加福音 22:32"> <span className="pl pl-1">你們要使軟弱的手堅壯，</span><br /><span className="pl pl-1">無力的膝穩固，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 5:7–9; 以賽亞書 41:10–14; 哈該書 2:4"> <span className="pl pl-1">對膽怯的人說：</span><br /><span className="pl pl-1">「你們要剛強，不要懼怕！</span><br /><span className="pl pl-1">看哪，你們的神必來報仇，</span><br /><span className="pl pl-1">必來施行極大的報應，</span><br /><span className="pl pl-1">他必來拯救你們。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 42:6–7; 路加福音 7:20–23; 以賽亞書 29:18"> <span className="pl pl-1">那時瞎子的眼必睜開，</span><br /><span className="pl pl-1">聾子的耳必開通。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 5:8–9; 約翰福音 7:37–39; 路加福音 11:14"> <span className="pl pl-1">那時瘸子必跳躍像鹿，</span><br /><span className="pl pl-1">啞巴的舌頭必能歌唱。</span><br /><span className="pl pl-1">在曠野必有水發出，</span><br /><span className="pl pl-1">在沙漠必有河湧流。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 26:18; 以賽亞書 49:10; 約翰福音 4:14"> <span className="pl pl-1">發光的沙</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：蜃樓。">a</a></sup><br /><span className="pl pl-1">要變為水池，</span><br /><span className="pl pl-1">乾渴之地要變為泉源。</span><br /><span className="pl pl-1">在野狗躺臥之處，</span><br /><span className="pl pl-1">必有青草、蘆葦和蒲草。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 7:13–14; 以賽亞書 42:16; 約翰福音 14:6"> <span className="pl pl-1">在那裡必有一條大道，</span><br /><span className="pl pl-1">稱為「聖路」。</span><br /><span className="pl pl-1">汙穢人不得經過，</span><br /><span className="pl pl-1">必專為贖民行走，</span><br /><span className="pl pl-1">行路的人雖愚昧</span><br /><span className="pl pl-1">也不致失迷。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 62:12; 何西阿書 2:18; 利未記 26:6"> <span className="pl pl-1">在那裡必沒有獅子，</span><br /><span className="pl pl-1">猛獸也不登這路，</span><br /><span className="pl pl-1">在那裡都遇不見，</span><br /><span className="pl pl-1">只有贖民在那裡行走。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:19; 啟示錄 21:4; 以賽亞書 25:8"> <span className="pl pl-1">並且耶和華救贖的民必歸回，</span><br /><span className="pl pl-1">歌唱來到錫安，</span><br /><span className="pl pl-1">永樂必歸到他們的頭上。</span><br /><span className="pl pl-1">他們必得著歡喜快樂，</span><br /><span className="pl pl-1">憂愁嘆息盡都逃避。</span></span>
</div>

## 稀奇加拉太人速離正道

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 11:4; 加拉太書 5:7–8; 以賽亞書 29:13"> 我稀奇你們這麼快離開那藉著基督之恩召你們的，去從別的福音。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 15:24; 羅馬書 16:17–18; 加拉太書 5:10"> 那並不是福音，不過有些人攪擾你們，要把基督的福音更改了。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 11:13–14; 加拉太書 1:9; 啟示錄 22:18–19"> 但無論是我們，是天上來的使者，若傳福音給你們，與我們所傳給你們的不同，他就應當被咒詛。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 16:17; 箴言 30:6; 申命記 4:2"> 我們已經說了，現在又說：若有人傳福音給你們，與你們所領受的不同，他就應當被咒詛！</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒羅尼迦前書 2:4; 使徒行傳 5:29; 以弗所書 6:6"> 我現在是要得人的心呢，還是要得神的心呢？我豈是討人的喜歡嗎？若仍舊討人的喜歡，我就不是基督的僕人了。</span>
</div>
</div>

## 保羅傳的福音是從神來的

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太書 1:1; 哥林多前書 2:9–10; 哥林多前書 11:23"> 弟兄們，我告訴你們，我素來所傳的福音不是出於人的意思。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 1:16; 哥林多前書 2:10; 加拉太書 1:1"> 因為我不是從人領受的，也不是人教導我的，乃是從耶穌基督啟示來的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:3; 哥林多前書 15:9; 使徒行傳 22:3–5"> 你們聽見我從前在猶太教中所行的事，怎樣極力逼迫、殘害神的教會，</span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 2:8; 使徒行傳 26:5; 腓立比書 3:4–6"> 我又在猶太教中，比我本國許多同歲的人更有長進，為我祖宗的遺傳更加熱心。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:5; 以賽亞書 49:5; 以賽亞書 49:1"> 然而，那把我從母腹裡分別出來，又施恩召我的神，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 16:17; 以弗所書 3:5–10; 以弗所書 6:12"> 既然樂意將他兒子啟示在我心裡，叫我把他傳在外邦人中，我就沒有與屬血氣的人商量，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 9:20–25; 哥林多後書 11:32–33; 加拉太書 1:18"> 也沒有上耶路撒冷去見那些比我先做使徒的，唯獨往阿拉伯去，後又回到大馬士革。</span>
</div>
</div>

## 不是在耶路撒冷學的

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 9:22–23; 使徒行傳 9:26–29; 使徒行傳 22:17–18"> 過了三年才上耶路撒冷去見磯法，和他同住了十五天。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:55; 馬可福音 6:3; 馬太福音 12:46"> 至於別的使徒，除了主的兄弟雅各，我都沒有看見。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:1; 哥林多後書 11:31; 哥林多後書 11:10–11"> 我寫給你們的不是謊話，這是我在神面前說的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 15:41; 使徒行傳 9:30; 使徒行傳 6:9"> 以後我到了敘利亞和基利家境內。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:14; 羅馬書 16:7; 帖撒羅尼迦後書 1:1"> 那時，猶太信基督的各教會都沒有見過我的面，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 15:8–10; 使徒行傳 9:13; 提摩太前書 1:13–16"> 不過聽說「那從前逼迫我們的，現在傳揚他原先所殘害的真道」，</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 9:8; 使徒行傳 11:18; 路加福音 15:10"> 他們就為我的緣故，歸榮耀給神。</span>
</div>
</div>

## 責備加拉太人受了迷惑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 5:7–8; 哥林多後書 11:3; 加拉太書 1:6"> 無知的加拉太人哪！耶穌基督釘十字架，已經活畫在你們眼前，誰又迷惑了你們呢？</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 10:16–17; 加拉太書 3:14; 使徒行傳 15:8"> 我只要問你們這一件：你們受了聖靈，是因行律法呢，是因聽信福音呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 5:4–8; 加拉太書 4:7–10; 希伯來書 7:16–19"> 你們既靠聖靈入門，如今還靠肉身成全嗎？你們是這樣的無知嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="約翰二書 1:8; 哥林多前書 15:2; 希伯來書 10:32–39"> 你們受苦如此之多，都是徒然的嗎？難道果真是徒然的嗎？</span>
</div>
</div>

## 信與律法相比

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太書 3:2; 使徒行傳 14:9–10; 使徒行傳 19:11–12"> 那賜給你們聖靈，又在你們中間行異能的，是因你們行律法呢，是因你們聽信福音呢？</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 15:6; 羅馬書 4:21–22; 雅各書 2:23"> 正如「亞伯拉罕信神，這就算為他的義」。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:7–8; 加拉太書 3:9; 加拉太書 3:26–29"> 所以你們要知道：那以信為本的人，就是亞伯拉罕的子孫。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:3; 創世記 22:18; 創世記 28:14"> 並且聖經既然預先看明神要叫外邦人因信稱義，就早已傳福音給亞伯拉罕，說：「萬國都必因你得福。」</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 4:16; 加拉太書 3:29; 羅馬書 4:24"> 可見那以信為本的人和有信心的亞伯拉罕一同得福。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 27:26; 羅馬書 8:7; 羅馬書 3:19–20"> 凡以行律法為本的，都是被咒詛的，因為經上記著：「凡不常照律法書上所記一切之事去行的，就被咒詛。」</span>
</div>
</div>

## 義人必因信得生

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哈巴谷書 2:4; 羅馬書 1:17; 希伯來書 10:38"> 沒有一個人靠著律法在神面前稱義，這是明顯的，因為經上說：「義人必因信得生。」</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:5; 羅馬書 10:5–6; 尼希米記 9:29"> 律法原不本乎信，只說：「行這些事的，就必因此活著。」</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:24; 申命記 21:23; 希伯來書 9:12"> 基督既為我們受<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「受」原文作「成」。">a</a></sup>了咒詛，就贖出我們脫離律法的咒詛，因為經上記著：「凡掛在木頭上都是被咒詛的。」</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:28–29; 哥林多前書 12:13; 以西結書 36:26–27"> 這便叫亞伯拉罕的福，因基督耶穌可以臨到外邦人，使我們因信得著所應許的聖靈。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 9:17; 羅馬書 6:19; 羅馬書 3:5"> 弟兄們，我且照著人的常話說：雖然是人的文約，若已經立定了，就沒有能廢棄或加增的。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:7–8; 羅馬書 4:13; 路加福音 1:55"> 所應許的原是向亞伯拉罕和他子孫說的，神並不是說「眾子孫」，指著許多人；乃是說「你那一個子孫」，指著一個人，就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 11:39–40; 創世記 15:13; 羅馬書 4:13–14"> 我是這麼說：神預先所立的約，不能被那四百三十年以後的律法廢掉，叫應許歸於虛空。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:12–15; 加拉太書 2:21; 羅馬書 4:13–16"> 因為承受產業，若本乎律法，就不本乎應許；但神是憑著應許，把產業賜給亞伯拉罕。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 7:53; 羅馬書 7:7–13; 希伯來書 2:2"> 這樣說來，律法是為什麼有的呢？原是為過犯添上的，等候那蒙應許的子孫來到；並且是藉天使、經中保之手設立的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前書 2:5; 申命記 6:4; 約伯記 9:33"> 但中保本不是為一面做的，神卻是一位。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 2:21; 羅馬書 9:31; 羅馬書 3:20–22"> 這樣，律法是與神的應許反對嗎？斷乎不是。若曾傳一個能叫人得生的律法，義就誠然本乎律法了。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 11:32; 希伯來書 9:15; 加拉太書 3:23"> 但聖經把眾人都圈在罪裡，使所應許的福因信耶穌基督歸給那信的人。</span>
</div>
</div>

## 律法是福音的先聲

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 5:18; 加拉太書 3:24–25; 加拉太書 3:19"> 但這因信得救的理還未來以先，我們被看守在律法之下，直圈到那將來的真道顯明出來。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 10:4; 使徒行傳 13:38–39; 羅馬書 7:24–25"> 這樣，律法是我們訓蒙的師傅，引我們到基督那裡，使我們因信稱義。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 6:14; 羅馬書 7:4; 希伯來書 10:15–18"> 但這因信得救的理既然來到，我們從此就不在師傅的手下了。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所書 1:5; 哥林多後書 6:18; 約翰福音 1:12–13"> 所以，你們因信基督耶穌，都是神的兒子。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 13:14; 哥林多前書 12:13; 羅馬書 6:3–4"> 你們受洗歸入基督的，都是披戴基督了；</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 12:12–13; 歌羅西書 3:11; 羅馬書 3:29–30"> 並不分猶太人、希臘人，自主的、為奴的，或男或女，因為你們在基督耶穌裡都成為一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 3:6; 羅馬書 9:7–8; 加拉太書 3:7"> 你們既屬乎基督，就是亞伯拉罕的後裔，是照著應許承受產業的了。</span>
</div>
</div>

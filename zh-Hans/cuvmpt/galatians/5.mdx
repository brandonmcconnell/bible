## 基督使人得自由

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 3:17; 加拉太書 5:13; 彼得前書 2:16"> 基督釋放了我們，叫我們得以自由，所以要站立得穩，不要再被奴僕的軛挾制。</span>
</div>
</div>

## 在基督裡割禮無功效

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="加拉太書 5:6; 使徒行傳 15:1; 羅馬書 9:31–32"> 我保羅告訴你們，若受割禮，基督就於你們無益了。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:10; 羅馬書 2:25; 雅各書 2:10–11"> 我再指著凡受割禮的人確實地說：他是欠著行全律法的債。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:31–32; 彼得後書 2:20–22; 羅馬書 11:6"> 你們這要靠律法稱義的，是與基督隔絕，從恩典中墜落了。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 130:5; 帖撒羅尼迦前書 1:10; 詩篇 62:5"> 我們靠著聖靈，憑著信心，等候所盼望的義。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 6:15; 哥林多前書 7:19; 雅各書 2:14–26"> 原來在基督耶穌裡，受割禮不受割禮全無功效，唯獨使人生發仁愛的信心才有功效。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 9:24; 加拉太書 3:1; 希伯來書 12:1"> 你們向來跑得好，有誰攔阻你們，叫你們不順從真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 1:6; 羅馬書 8:28"> 這樣的勸導不是出於那召你們的。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 15:33; 哥林多前書 5:6–7; 馬可福音 8:15"> 一點麵酵能使全團都發起來。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 5:12; 哥林多後書 2:3; 加拉太書 1:7"> 我在主裡很信你們必不懷別樣的心，但攪擾你們的，無論是誰，必擔當他的罪名。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 1:23; 加拉太書 6:12; 加拉太書 4:29"> 弟兄們，我若仍舊傳割禮，為什麼還受逼迫呢？若是這樣，那十字架討厭的地方就沒有了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:10; 哥林多前書 5:13; 提多書 3:10"> 恨不得那攪亂你們的人把自己割絕了！</span>
</div>
</div>

## 愛心乃包括全律法的義

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:16; 哥林多前書 9:19; 哥林多前書 8:9"> 弟兄們，你們蒙召是要得自由，只是不可將你們的自由當做放縱情慾的機會，總要用愛心互相服侍。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 7:12; 利未記 19:18; 加拉太書 6:2"> 因為全律法都包在「愛人如己」這一句話之內了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 3:3; 雅各書 3:14–3; 加拉太書 5:26"> 你們要謹慎，若相咬相吞，只怕要彼此消滅了。</span>
</div>
</div>

## 聖靈和情慾為敵

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太書 5:24–25; 羅馬書 8:12–14; 加拉太書 6:8"> 我說，你們當順著聖靈而行，就不放縱肉體的情慾了。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:13; 約翰福音 3:6; 羅馬書 8:5–8"> 因為情慾和聖靈相爭，聖靈和情慾相爭，這兩個是彼此相敵，使你們不能做所願意做的。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:14; 羅馬書 6:14–15; 加拉太書 5:25"> 但你們若被聖靈引導，就不在律法以下。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 6:9–10; 歌羅西書 3:5–8; 馬太福音 15:18–19"> 情慾的事都是顯而易見的，就如姦淫、汙穢、邪蕩、</span>
<span className="v" id="v20" data-v="20" data-xref="提多書 3:10; 哥林多前書 11:19; 啟示錄 21:8"> 拜偶像、邪術、仇恨、爭競、忌恨、惱怒、結黨、紛爭、異端、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 6:9–10; 羅馬書 8:13; 羅馬書 13:13"> 嫉妒、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有「凶殺」二字。">a</a></sup>醉酒、荒宴等類。我從前告訴你們，現在又告訴你們：行這樣事的人必不能承受神的國。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:12–17; 哥林多前書 13:4–7; 約翰福音 15:5"> 聖靈所結的果子，就是仁愛、喜樂、和平、忍耐、恩慈、良善、信實、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 1:9; 使徒行傳 24:25; 提多書 2:2"> 溫柔、節制；這樣的事沒有律法禁止。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 6:6; 羅馬書 13:14; 羅馬書 8:13"> 凡屬基督耶穌的人，是已經把肉體連肉體的邪情私慾同釘在十字架上了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:16; 羅馬書 8:4–5; 羅馬書 8:2"> 我們若是靠聖靈得生，就當靠聖靈行事。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 3:14–16; 腓立比書 2:1–3; 雅各書 4:16"> 不要貪圖虛名，彼此惹氣，互相嫉妒。</span>
</div>
</div>

## 以色列與猶大崇邪拜像干罪受罰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 26:18; 以賽亞書 1:1; 何西阿書 1:1"> 當猶大王約坦、亞哈斯、希西家在位的時候，摩利沙人彌迦得耶和華的默示，論撒馬利亞和耶路撒冷。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:2; 詩篇 11:4; 啟示錄 3:13"> <span className="pl pl-1">萬民哪，你們都要聽！</span><br /><span className="pl pl-1">地和其上所有的，也都要側耳而聽！</span><br /><span className="pl pl-1">主耶和華從他的聖殿</span><br /><span className="pl pl-1">要見證你們的不是。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 4:13; 以賽亞書 26:21; 申命記 32:13"> <span className="pl pl-1">看哪，耶和華出了他的居所，</span><br /><span className="pl pl-1">降臨步行地的高處。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="那鴻書 1:5; 詩篇 97:5; 士師記 5:4"> <span className="pl pl-1">眾山在他以下必消化，</span><br /><span className="pl pl-1">諸谷必崩裂，</span><br /><span className="pl pl-1">如蠟化在火中，</span><br /><span className="pl pl-1">如水沖下山坡。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 8:14; 耶利米書 2:19; 帖撒羅尼迦前書 2:15–16"> <span className="pl pl-1">這都因雅各的罪過，</span><br /><span className="pl pl-1">以色列家的罪惡。</span><br /><span className="pl pl-1">雅各的罪過在哪裡呢？</span><br /><span className="pl pl-1">豈不是在撒馬利亞嗎？</span><br /><span className="pl pl-1">猶大的丘壇在哪裡呢？</span><br /><span className="pl pl-1">豈不是在耶路撒冷嗎？</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="申命記 23:18; 何西阿書 2:12; 何西阿書 8:6"> <span className="pl pl-1">她一切雕刻的偶像必被打碎，</span><br /><span className="pl pl-1">她所得的財物必被火燒，</span><br /><span className="pl pl-1">所有的偶像我必毀滅，</span><br /><span className="pl pl-1">因為是從妓女雇價所聚來的，</span><br /><span className="pl pl-1">後必歸為妓女的雇價。」</span></span>

<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 22:4; 以賽亞書 20:2–4; 耶利米書 4:19"> <span className="pl pl-1">先知說：因此我必大聲哀號，</span><br /><span className="pl pl-1">赤腳露體而行；</span><br /><span className="pl pl-1">又要呼號如野狗，</span><br /><span className="pl pl-1">哀鳴如鴕鳥。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 30:11–15; 以賽亞書 8:7–8; 歷代志下 32:1–23"> <span className="pl pl-1">因為撒馬利亞的傷痕無法醫治，</span><br /><span className="pl pl-1">延及猶大和耶路撒冷我民的城門。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 1:20; 耶利米書 6:26; 約書亞記 18:23"> <span className="pl pl-1">不要在迦特報告這事，</span><br /><span className="pl pl-1">總不要哭泣；</span><br /><span className="pl pl-1">我在伯亞弗拉滾於灰塵之中。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:17; 歷代志下 32:9; 約書亞記 10:3"> <span className="pl pl-1">拉吉的居民哪，要用快馬套車，</span><br /><span className="pl pl-1">錫安民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「民」原文作「女子」。">a</a></sup><br /><span className="pl pl-1">的罪由你而起，</span><br /><span className="pl pl-1">以色列人的罪過在你那裡顯出。</span><br /></span>

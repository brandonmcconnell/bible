## 耶利米哀嘆耶路撒冷之苦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 28:2; 詩篇 132:7; 馬太福音 11:23"> <span className="pl pl-1">主何竟發怒，使黑雲遮蔽錫安城！</span><br /><span className="pl pl-1">他將以色列的華美從天扔在地上，</span><br /><span className="pl pl-1">在他發怒的日子並不記念自己的腳凳。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米哀歌 2:17; 詩篇 89:39–40; 耶利米哀歌 3:43"> <span className="pl pl-1">主吞滅雅各一切的住處，並不顧惜。</span><br /><span className="pl pl-1">他發怒傾覆猶大民的保障，</span><br /><span className="pl pl-1">使這保障坍倒在地。</span><br /><span className="pl pl-1">他辱沒這國和其中的首領。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 74:11; 詩篇 75:10; 詩篇 75:5"> <span className="pl pl-1">他發烈怒把以色列的角全然砍斷，</span><br /><span className="pl pl-1">在仇敵面前收回右手。</span><br /><span className="pl pl-1">他像火焰四圍吞滅，將雅各燒毀。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 7:20; 耶利米書 21:5; 耶利米哀歌 3:12–13"> <span className="pl pl-1">他張弓好像仇敵，</span><br /><span className="pl pl-1">他站著舉起右手</span><br /><span className="pl pl-1">如同敵人，將悅人眼目的盡行殺戮。</span><br /><span className="pl pl-1">在錫安百姓的帳篷上</span><br /><span className="pl pl-1">倒出他的憤怒，像火一樣。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 2:2; 耶利米書 30:14; 耶利米書 52:13"> <span className="pl pl-1">主如仇敵吞滅以色列和錫安的一切宮殿，</span><br /><span className="pl pl-1">拆毀百姓的保障，</span><br /><span className="pl pl-1">在猶大民中加增悲傷哭號。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 1:4; 西番雅書 3:18; 耶利米哀歌 4:16"> <span className="pl pl-1">他強取自己的帳幕好像是園中的窩棚，</span><br /><span className="pl pl-1">毀壞他的聚會之處。</span><br /><span className="pl pl-1">耶和華使聖節和安息日在錫安都被忘記，</span><br /><span className="pl pl-1">又在怒氣的憤恨中藐視君王和祭司。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:21; 阿摩司書 2:5; 詩篇 74:3–8"> <span className="pl pl-1">耶和華丟棄自己的祭壇，</span><br /><span className="pl pl-1">憎惡自己的聖所，</span><br /><span className="pl pl-1">將宮殿的牆垣交付仇敵。</span><br /><span className="pl pl-1">他們在耶和華的殿中喧嚷，</span><br /><span className="pl pl-1">像在聖會之日一樣。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 21:13; 以賽亞書 34:11; 以賽亞書 3:26"> <span className="pl pl-1">耶和華定意拆毀錫安的城牆，</span><br /><span className="pl pl-1">他拉了準繩，</span><br /><span className="pl pl-1">不將手收回，定要毀滅。</span><br /><span className="pl pl-1">他使外郭和城牆都悲哀，</span><br /><span className="pl pl-1">一同衰敗。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 7:26; 何西阿書 3:4; 歷代志下 15:3"> <span className="pl pl-1">錫安的門都陷入地內，</span><br /><span className="pl pl-1">主將她的門閂毀壞、折斷。</span><br /><span className="pl pl-1">她的君王和首領落在沒有律法的列國中，</span><br /><span className="pl pl-1">她的先知不得見耶和華的異象。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 3:26; 以賽亞書 15:3; 約伯記 2:12–13"> <span className="pl pl-1">錫安城的長老坐在地上默默無聲，</span><br /><span className="pl pl-1">他們揚起塵土落在頭上，腰束麻布。</span><br /><span className="pl pl-1">耶路撒冷的處女垂頭至地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="耶利米哀歌 1:20; 約伯記 16:13; 耶利米哀歌 1:16"> <span className="pl pl-1">我眼中流淚，以致失明，</span><br /><span className="pl pl-1">我的心腸擾亂，肝膽塗地，</span><br /><span className="pl pl-1">都因我眾民遭毀滅，</span><br /><span className="pl pl-1">又因孩童和吃奶的在城內街上發昏。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 1:12; 耶利米書 8:22; 撒母耳記下 5:20"> <span className="pl pl-1">耶路撒冷的民哪，我可用什麼向你證明呢？</span><br /><span className="pl pl-1">我可用什麼與你相比呢？</span><br /><span className="pl pl-1">錫安的民哪，我可拿什麼和你比較，好安慰你呢？</span><br /><span className="pl pl-1">因為你的裂口大如海，</span><br /><span className="pl pl-1">誰能醫治你呢？</span><br /></span>

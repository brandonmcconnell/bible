## 戒民陷於拜像之罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:3; 使徒行傳 13:19; 申命記 4:38"> 「耶和華你神領你進入要得為業之地，從你面前趕出許多國民，就是赫人、革迦撒人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人，共七國的民，都比你強大。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 2:2; 出埃及記 23:32–33; 申命記 20:16–17"> 耶和華你神將他們交給你擊殺，那時你要把他們滅絕淨盡，不可與他們立約，也不可憐恤他們。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:2; 約書亞記 23:12–13; 出埃及記 34:15–16"> 不可與他們結親。不可將你的女兒嫁他們的兒子，也不可叫你的兒子娶他們的女兒，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 6:15; 士師記 2:11; 申命記 4:26"> 因為她必使你兒子轉離不跟從主，去侍奉別神，以致耶和華的怒氣向你們發作，就速速地將你們滅絕。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 23:24; 申命記 12:2–3; 出埃及記 34:13"> 你們卻要這樣待他們：拆毀他們的祭壇，打碎他們的柱像，砍下他們的木偶，用火焚燒他們雕刻的偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:2; 出埃及記 19:5–6; 彼得前書 2:9"> 因為你歸耶和華你神為聖潔的民，耶和華你神從地上的萬民中揀選你，特做自己的子民。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 10:22; 羅馬書 9:11–15; 羅馬書 11:6"> 耶和華專愛你們，揀選你們，並非因你們的人數多於別民，原來你們的人數在萬民中是最少的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 20:2; 出埃及記 32:13; 以弗所書 2:4–5"> 只因耶和華愛你們，又因要守他向你們列祖所起的誓，就用大能的手領你們出來，從為奴之家救贖你們脫離埃及王法老的手。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:23; 提摩太後書 2:13; 帖撒羅尼迦後書 3:3"> 所以，你要知道耶和華你的神，他是神，是信實的神：向愛他守他誡命的人守約施慈愛，直到千代；</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 59:18; 那鴻書 1:2; 羅馬書 12:19"> 向恨他的人當面報應他們，將他們滅絕——凡恨他的人，必報應他們，決不遲延。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 14:15; 申命記 4:1; 申命記 5:32"> 所以，你要謹守遵行我今日所吩咐你的誡命、律例、典章。</span>
</div>
</div>

## 聽從典章必蒙賜福

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 28:1–14; 申命記 7:9; 利未記 26:3–13"> 「你們果然聽從這些典章，謹守遵行，耶和華你神就必照他向你列祖所起的誓守約施慈愛。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:21; 約翰福音 15:10; 申命記 28:3–5"> 他必愛你，賜福於你，使你人數增多；也必在他向你列祖起誓應許給你的地上，賜福於你身所生的，地所產的，並你的五穀、新酒和油，以及牛犢、羊羔。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 23:26–33; 申命記 28:4; 詩篇 127:3"> 你必蒙福勝過萬民。你們的男女沒有不能生養的，牲畜也沒有不能生育的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 15:26; 詩篇 105:36–37; 利未記 26:3–4"> 耶和華必使一切的病症離開你；你所知道埃及各樣的惡疾，他不加在你身上，只加在一切恨你的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:33; 士師記 8:27; 申命記 13:8"> 耶和華你神所要交給你的一切人民，你要將他們除滅，你眼不可顧惜他們。你也不可侍奉他們的神，因這必成為你的網羅。</span>
</div>
</div>

## 勸民勿懼必勝諸敵

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 13:32; 民數記 33:53; 申命記 18:21"> 「你若心裡說：『這些國的民比我更多，我怎能趕出他們呢？』</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 105:5; 申命記 31:6; 申命記 1:29"> 你不要懼怕他們，要牢牢記念耶和華你神向法老和埃及全地所行的事，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:34; 尼希米記 9:10–11; 耶利米書 32:20–21"> 就是你親眼所看見的大試驗、神蹟、奇事和大能的手並伸出來的膀臂，都是耶和華你神領你出來所用的。耶和華你神必照樣待你所懼怕的一切人民，</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 24:12; 出埃及記 23:28–30"> 並且耶和華你神必打發黃蜂飛到他們中間，直到那剩下而藏躲的人從你面前滅亡。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 1:5; 申命記 10:17; 尼希米記 9:32"> 你不要因他們驚恐，因為耶和華你神在你們中間是大而可畏的神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 23:29–30; 約書亞記 15:63"> 耶和華你神必將這些國的民從你面前漸漸趕出；你不可把他們速速滅盡，恐怕野地的獸多起來害你。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 8:20; 申命記 2:15; 耶利米書 17:18"> 耶和華你神必將他們交給你，大大地擾亂他們，直到他們滅絕了。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 10:8; 約書亞記 23:9; 約書亞記 1:5"> 又要將他們的君王交在你手中，你就使他們的名從天下消滅。必無一人能在你面前站立得住，直到你將他們滅絕了。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 32:20; 歷代志上 14:12; 申命記 17:1"> 他們雕刻的神像，你們要用火焚燒，其上的金銀，你不可貪圖，也不可收取，免得你因此陷入網羅。這原是耶和華你神所憎惡的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 13:17; 何西阿書 14:8; 以西結書 11:18"> 可憎的物，你不可帶進家去，不然你就成了當毀滅的，與那物一樣。你要十分厭惡，十分憎嫌，因為這是當毀滅的物。</span>
</div>
</div>

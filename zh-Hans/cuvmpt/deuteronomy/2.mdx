## 自加低斯巴尼亞至撒烈溪之路

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:4; 申命記 1:40; 民數記 14:25"> 「此後，我們轉回，從紅海的路往曠野去，是照耶和華所吩咐我的。我們在西珥山繞行了許多日子。</span>
<span className="v" id="v2" data-v="2"> 耶和華對我說：</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:6; 申命記 2:14; 申命記 2:7"> 『你們繞行這山的日子夠了，要轉向北去。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 20:14–21; 出埃及記 15:15; 申命記 23:7"> 你吩咐百姓說：你們弟兄以掃的子孫住在西珥，你們要經過他們的境界。他們必懼怕你們，所以你們要分外謹慎，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 36:8; 約書亞記 24:4; 耶利米書 27:5"> 不可與他們爭戰。他們的地，連腳掌可踏之處，我都不給你們，因我已將西珥山賜給以掃為業。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:12; 民數記 20:19; 羅馬書 12:17"> 你們要用錢向他們買糧吃，也要用錢向他們買水喝。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米記 9:21; 申命記 8:2–4"> 因為耶和華你的神在你手裡所辦的一切事上已賜福於你。你走這大曠野，他都知道了。這四十年，耶和華你的神常與你同在，故此你一無所缺。』</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 9:26; 士師記 11:18; 列王紀下 16:6"> 於是我們離了我們弟兄以掃子孫所住的西珥，從亞拉巴的路，經過以拉他、以旬迦別，轉向摩押曠野的路去。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 19:36–37; 民數記 21:15; 民數記 21:28"> 耶和華吩咐我說：『不可擾害摩押人，也不可與他們爭戰。他們的地，我不賜給你為業，因我已將亞珥賜給羅得的子孫為業。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 14:5; 申命記 2:11; 民數記 13:22"> （先前有以米人住在那裡，民數眾多，身體高大，像亞衲人一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:28; 民數記 13:28; 創世記 14:5"> 這以米人像亞衲人，也算為利乏音人，摩押人稱他們為以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:22; 創世記 14:6; 申命記 2:32–11"> 先前何利人也住在西珥，但以掃的子孫將他們除滅，得了他們的地，接著居住，就如以色列在耶和華賜給他為業之地所行的一樣。）</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 21:12; 民數記 13:23"> 現在起來，過撒烈溪。』於是我們過了撒烈溪。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 26:64–65; 民數記 14:28–35; 申命記 1:34–35"> 自從離開加低斯巴尼亞，到過了撒烈溪的時候，共有三十八年，等那世代的兵丁都從營中滅盡，正如耶和華向他們所起的誓。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 106:26; 以賽亞書 66:14; 詩篇 32:4"> 耶和華的手也攻擊他們，將他們從營中除滅，直到滅盡。</span>
</div>
</div>

## 經過摩押亞捫之地

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 「兵丁從民中都滅盡死亡以後，</span>
<span className="v" id="v17" data-v="17"> 耶和華吩咐我說：</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:23; 以賽亞書 15:1; 民數記 21:15"> 『你今天要從摩押的境界亞珥經過，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:9; 士師記 11:13–27; 歷代志下 20:10"> 走近亞捫人之地，不可擾害他們，也不可與他們爭戰。亞捫人的地，我不賜給你們為業，因我已將那地賜給羅得的子孫為業。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 14:5"> （那地也算為利乏音人之地，先前利乏音人住在那裡，亞捫人稱他們為散送冥。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 27:7–8; 申命記 1:28; 申命記 2:22"> 那民眾多，身體高大，像亞衲人一樣，但耶和華從亞捫人面前除滅他們，亞捫人就得了他們的地，接著居住。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 36:8; 創世記 36:20–30; 申命記 2:12"> 正如耶和華從前為住西珥的以掃子孫將何利人從他們面前除滅，他們得了何利人的地，接著居住一樣，直到今日。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 10:14; 約書亞記 13:3; 阿摩司書 9:7"> 從迦斐托出來的迦斐托人將先前住在鄉村直到加沙的亞衛人除滅，接著居住。）</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 27:5; 但以理書 4:17; 士師記 11:18–21"> 你們起來前往，過亞嫩谷。我已將亞摩利人希實本王西宏和他的地交在你手中，你要與他爭戰，得他的地為業。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 11:25; 出埃及記 15:14–16; 申命記 28:10"> 從今日起，我要使天下萬民聽見你的名聲都驚恐懼怕，且因你發顫傷慟。』</span>
</div>
</div>

## 戰敗希實本王西宏

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 約書亞記 13:18"> 「我從基底莫的曠野差遣使者去見希實本王西宏，用和睦的話說：</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 11:19; 申命記 2:6; 民數記 21:21–23"> 『求你容我從你的地經過，只走大道，不偏左右。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 20:19"> 你可以賣糧給我吃，也可以賣水給我喝，只要容我步行過去，</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 20:18; 士師記 11:17–18; 申命記 23:3–4"> 就如住西珥的以掃子孫和住亞珥的摩押人待我一樣，等我過了約旦河，好進入耶和華我們神所賜給我們的地。』</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 21:23; 出埃及記 4:21; 約書亞記 11:19–20"> 但希實本王西宏不容我們從他那裡經過，因為耶和華你的神使他心中剛硬，性情頑梗，為要將他交在你手中，像今日一樣。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:8; 申命記 2:24"> 耶和華對我說：『從此起首，我要將西宏和他的地交給你。你要得他的地為業！』</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 21:23–30; 士師記 11:20–23; 詩篇 136:19"> 那時，西宏和他的眾民出來攻擊我們，在雅雜與我們交戰。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 7:2; 約書亞記 21:44; 申命記 3:2–3"> 耶和華我們的神將他交給我們，我們就把他和他的兒子並他的眾民，都擊殺了。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 7:2; 撒母耳記上 15:3; 申命記 3:6"> 我們奪了他的一切城邑，將有人煙的各城，連女人帶孩子，盡都毀滅，沒有留下一個。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 8:27; 申命記 20:14; 民數記 31:9–11"> 唯有牲畜和所奪的各城，並其中的財物，都取為自己的掠物。</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 13:9; 申命記 4:48; 申命記 3:12"> 從亞嫩谷邊的亞羅珥和谷中的城，直到基列，耶和華我們的神都交給我們了，沒有一座城高得使我們不能攻取的。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:24; 申命記 3:16; 創世記 32:22"> 唯有亞捫人之地，凡靠近雅博河的地，並山地的城邑，與耶和華我們神所禁止我們去的地方，都沒有挨近。</span>

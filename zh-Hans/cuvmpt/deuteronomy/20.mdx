## 可免戰者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 32:7–8; 申命記 31:8; 詩篇 20:7"> 「你出去與仇敵爭戰的時候，看見馬匹、車輛，並有比你多的人民，不要怕他們，因為領你出埃及地的耶和華你神與你同在。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 31:6; 歷代志下 13:12; 民數記 10:8–9"> 你們將要上陣的時候，祭司要到百姓面前宣告，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 13:6; 詩篇 3:6; 啟示錄 2:10"> 說：『以色列人哪，你們當聽！你們今日將要與仇敵爭戰，不要膽怯，不要懼怕戰兢，也不要因他們驚恐。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 14:14; 申命記 3:22; 申命記 1:30"> 因為耶和華你們的神與你們同去，要為你們與仇敵爭戰，拯救你們。』</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 12:27; 民數記 31:14; 申命記 16:18"> 官長也要對百姓宣告說：『誰建造房屋，尚未奉獻，他可以回家去，恐怕他陣亡，別人去奉獻。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 19:23–25; 申命記 28:1–30; 耶利米書 31:5"> 誰種葡萄園，尚未用所結的果子，他可以回家去，恐怕他陣亡，別人去用。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 24:5; 申命記 28:30; 路加福音 14:18–20"> 誰聘定了妻，尚未迎娶，他可以回家去，恐怕他陣亡，別人去娶。』</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 7:3; 申命記 1:28; 啟示錄 21:8"> 官長又要對百姓宣告說：『誰懼怕膽怯，他可以回家去，恐怕他弟兄的心消化，和他一樣。』</span>
<span className="v" id="v9" data-v="9"> 官長對百姓宣告完了，就當派軍長率領他們。</span>
</div>
</div>

## 攻城先告以和

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:5–6; 哥林多後書 5:18–1; 以弗所書 2:17"> 「你臨近一座城，要攻打的時候，先要對城裡的民宣告和睦的話。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 約書亞記 11:19–20; 約書亞記 16:10"> 他們若以和睦的話回答你，給你開了城，城裡所有的人都要給你效勞，服侍你。</span>
<span className="v" id="v12" data-v="12"> 若不肯與你和好，反要與你打仗，你就要圍困那城。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:6–12; 列王紀上 11:15–16; 詩篇 110:1"> 耶和華你的神把城交付你手，你就要用刀殺盡這城的男丁。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 8:2; 約書亞記 22:8; 民數記 31:9"> 唯有婦女、孩子、牲畜和城內一切的財物，你可以取為自己的掠物。耶和華你神把你仇敵的財物賜給你，你可以吃用。</span>
<span className="v" id="v15" data-v="15"> 離你甚遠的各城，不是這些國民的城，你都要這樣待他。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 11:14; 民數記 21:2–3; 民數記 33:52"> 但這些國民的城，耶和華你神既賜你為業，其中凡有氣息的，一個不可存留，</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 34:5–6; 耶利米書 50:35–40; 申命記 7:1–2"> 只要照耶和華你神所吩咐的，將這赫人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人都滅絕淨盡，</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:30–31; 出埃及記 23:33; 以弗所書 5:11"> 免得他們教導你們學習一切可憎惡的事，就是他們向自己神所行的，以致你們得罪耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 3:10; 約翰福音 15:2–8; 申命記 26:6"> 「你若許久圍困，攻打所要取的一座城，就不可舉斧子砍壞樹木。因為你可以吃那樹上的果子，不可砍伐。田間的樹木豈是人，叫你糟蹋嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 26:15; 耶利米書 33:4; 傳道書 9:14"> 唯獨你所知道不是結果子的樹木，可以毀壞、砍伐，用以修築營壘，攻擊那與你打仗的城，直到攻塌了。</span>
</div>
</div>

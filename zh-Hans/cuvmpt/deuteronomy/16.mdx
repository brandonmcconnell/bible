## 逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 34:18; 出埃及記 12:2–20; 出埃及記 13:4"> 「你要注意亞筆月，向耶和華你的神守逾越節，因為耶和華你的神在亞筆月夜間領你出埃及。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:5; 申命記 12:26; 路加福音 22:15"> 你當在耶和華所選擇要立為他名的居所，從牛群、羊群中，將逾越節的祭牲獻給耶和華你的神。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 12:39; 出埃及記 34:18; 出埃及記 12:19–20"> 你吃這祭牲，不可吃有酵的餅。七日之內要吃無酵餅，就是困苦餅（你本是急忙出了埃及地），要叫你一生一世記念你從埃及地出來的日子。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 34:25; 出埃及記 12:10; 出埃及記 13:7"> 在你四境之內，七日不可見麵酵，頭一日晚上所獻的肉一點不可留到早晨。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 16:2; 申命記 12:5–6"> 在耶和華你神所賜的各城中，你不可獻逾越節的祭，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:5; 出埃及記 12:6–9; 民數記 9:11"> 只當在耶和華你神所選擇要立為他名的居所，晚上日落的時候，乃是你出埃及的時候，獻逾越節的祭。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 35:13; 出埃及記 12:8–9; 約翰福音 2:23"> 當在耶和華你神所選擇的地方把肉烤<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「烤」或作「煮」。">a</a></sup>了吃，次日早晨就回到你的帳篷去。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 13:6–8; 利未記 23:6–8; 利未記 23:36"> 你要吃無酵餅六日，第七日要向耶和華你的神守嚴肅會，不可做工。</span>
</div>
</div>

## 七七節

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 34:22; 出埃及記 23:16; 使徒行傳 2:1"> 「你要計算七七日，從你開鐮收割禾稼時算起，共計七七日。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 16:2; 利未記 12:8; 瑪拉基書 3:10–11"> 你要照耶和華你神所賜你的福，手裡拿著甘心祭，獻在耶和華你的神面前，守七七節。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:7; 申命記 12:12; 申命記 12:18"> 你和你兒女、僕婢，並住在你城裡的利未人，以及在你們中間寄居的與孤兒寡婦，都要在耶和華你神所選擇立為他名的居所，在耶和華你的神面前歡樂。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:15; 耶利米哀歌 3:19–20; 羅馬書 6:17–18"> 你也要記念你在埃及做過奴僕。你要謹守遵行這些律例。</span>
</div>
</div>

## 住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及記 23:16; 約翰福音 7:2; 歷代志下 5:3"> 「你把禾場的穀、酒榨的酒收藏以後，就要守住棚節七日。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 8:9–12; 申命記 16:11; 以賽亞書 30:29"> 守節的時候，你和你兒女、僕婢，並住在你城裡的利未人，以及寄居的與孤兒寡婦，都要歡樂。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 23:36–42; 申命記 30:16; 申命記 16:10"> 在耶和華所選擇的地方，你當向耶和華你的神守節七日。因為耶和華你神在你一切的土產上和你手裡所辦的事上要賜福於你，你就非常地歡樂。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 詩篇 96:8; 哈該書 1:9"> 你一切的男丁要在除酵節、七七節、住棚節，一年三次，在耶和華你神所選擇的地方朝見他，卻不可空手朝見，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 9:6–7; 哥林多後書 8:12; 申命記 16:10"> 各人要按自己的力量，照耶和華你神所賜的福分，奉獻禮物。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志上 23:4; 出埃及記 18:25–26; 羅馬書 13:1–6"> 「你要在耶和華你神所賜的各城裡，按著各支派設立審判官和官長，他們必按公義的審判判斷百姓。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 19:15; 出埃及記 23:2; 箴言 17:23"> 不可屈枉正直，不可看人的外貌，也不可受賄賂，因為賄賂能叫智慧人的眼變瞎了，又能顛倒義人的話。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比書 4:8; 以西結書 18:9; 以西結書 18:5"> 你要追求至公至義，好叫你存活，承受耶和華你神所賜你的地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 33:3; 列王紀下 17:16; 出埃及記 34:13"> 「你為耶和華你的神築壇，不可在壇旁栽什麼樹木作為木偶。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 26:1; 出埃及記 20:4; 撒迦利亞書 8:17"> 也不可為自己設立柱像，這是耶和華你神所恨惡的。</span>
</div>
</div>

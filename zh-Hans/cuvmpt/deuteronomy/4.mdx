## 勸民遵行耶和華之律例典章

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 10:5; 以西結書 20:11; 利未記 18:5"> 「以色列人哪，現在我所教訓你們的律例、典章，你們要聽從遵行，好叫你們存活，得以進入耶和華你們列祖之神所賜給你們的地，承受為業。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:32; 箴言 30:6; 啟示錄 22:18–19"> 所吩咐你們的話，你們不可加添，也不可刪減，好叫你們遵守我所吩咐的，就是耶和華你們神的命令。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 25:1–9; 詩篇 106:28–29; 約書亞記 22:17"> 耶和華因巴力毗珥的事所行的，你們親眼看見了，凡隨從巴力毗珥的人，耶和華你們的神都從你們中間除滅了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 10:20; 約書亞記 23:8; 約翰福音 6:67–69"> 唯有你們專靠耶和華你們神的人，今日全都存活。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 28:20; 帖撒羅尼迦前書 4:1–2; 希伯來書 3:5"> 我照著耶和華我神所吩咐的，將律例、典章教訓你們，使你們在所要進去得為業的地上遵行。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 28:28; 詩篇 111:10; 提摩太後書 3:15"> 所以你們要謹守遵行，這就是你們在萬民眼前的智慧、聰明。他們聽見這一切律例，必說：『這大國的人真是有智慧，有聰明！』</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:18; 撒母耳記下 7:23; 詩篇 34:18"> 哪一大國的人有神與他們相近，像耶和華我們的神，在我們求告他的時候與我們相近呢？</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 147:19–20; 羅馬書 7:12–14; 詩篇 119:127–128"> 又哪一大國有這樣公義的律例、典章，像我今日在你們面前所陳明的這一切律法呢？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 6:7; 申命記 11:19; 詩篇 78:3–8"> 「你只要謹慎，殷勤保守你的心靈，免得忘記你親眼所看見的事，又免得你一生這事離開你的心，總要傳給你的子子孫孫。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 19:9; 希伯來書 12:18–19; 出埃及記 19:16"> 你在何烈山站在耶和華你神面前的那日，耶和華對我說：『你為我招聚百姓，我要叫他們聽見我的話，使他們存活在世的日子，可以學習敬畏我，又可以教訓兒女這樣行。』</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 5:23; 出埃及記 19:16–18; 希伯來書 12:18–19"> 那時你們近前來，站在山下，山上有火焰沖天，並有昏黑、密雲、幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:15; 申命記 5:4; 申命記 5:22"> 耶和華從火焰中對你們說話，你們只聽見聲音，卻沒有看見形像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:28; 出埃及記 31:18; 申命記 9:9–11"> 他將所吩咐你們當守的約指示你們，就是十條誡，並將這誡寫在兩塊石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 105:44–45; 以西結書 21:1–23"> 那時耶和華又吩咐我將律例、典章教訓你們，使你們在所要過去得為業的地上遵行。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:12; 以賽亞書 40:18; 哥林多後書 4:4–6"> 所以你們要分外謹慎，因為耶和華在何烈山，從火中對你們說話的那日，你們沒有看見什麼形像。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:29; 申命記 5:8; 出埃及記 20:4–5"> 唯恐你們敗壞自己，雕刻偶像，彷彿什麼男像女像，</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:23"> 或地上走獸的像，或空中飛鳥的像，</span>
<span className="v" id="v18" data-v="18"> 或地上爬物的像，或地底下水中魚的像。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 1:25; 申命記 17:3; 列王紀下 21:3"> 又恐怕你向天舉目觀看，見耶和華你的神為天下萬民所擺列的日、月、星，就是天上的萬象，自己便被勾引，敬拜侍奉它。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 8:51; 耶利米書 11:4; 出埃及記 19:5–6"> 耶和華將你們從埃及領出來，脫離鐵爐，要特做自己產業的子民，像今日一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:37; 民數記 20:12; 詩篇 106:32–33"> 耶和華又因你們的緣故向我發怒，起誓必不容我過約旦河，也不容我進入耶和華你神所賜你為業的那美地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 3:25; 申命記 3:27; 彼得後書 1:13–15"> 我只得死在這地，不能過約旦河，但你們必過去得那美地。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:9; 希伯來書 3:12; 約書亞記 23:16"> 你們要謹慎，免得忘記耶和華你們神與你們所立的約，為自己雕刻偶像，就是耶和華你神所禁止你做的偶像，</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 12:29; 那鴻書 1:6; 申命記 9:3"> 因為耶和華你的神乃是烈火，是忌邪的神。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 4:16; 何西阿書 9:9; 哥林多前書 10:22"> 「你們在那地住久了，生子生孫，就雕刻偶像，彷彿什麼形像，敗壞自己，行耶和華你神眼中看為惡的事，惹他發怒。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:1; 彌迦書 6:2; 耶利米書 22:29"> 我今日呼天喚地向你們作見證，你們必在過約旦河得為業的地上速速滅盡。你們不能在那地上長久，必盡行除滅。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 28:62–64; 利未記 26:33; 以西結書 12:15"> 耶和華必使你們分散在萬民中，在他所領你們到的萬國裡，你們剩下的人數稀少。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:64; 耶利米書 16:13; 申命記 28:36"> 在那裡，你們必侍奉人手所造的神，就是用木石造成，不能看、不能聽、不能吃、不能聞的神。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:2; 耶利米書 29:12–14; 歷代志下 15:4"> 但你們在那裡必尋求耶和華你的神。你盡心、盡性尋求他的時候，就必尋見。</span>
<span className="v" id="v30" data-v="30" data-xref="約珥書 2:12–13; 耶利米書 23:20; 何西阿書 3:5"> 日後你遭遇一切患難的時候，你必歸回耶和華你的神，聽從他的話。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 31:8; 詩篇 116:5; 尼希米記 9:31"> 耶和華你神原是有憐憫的神，他總不撇下你，不滅絕你，也不忘記他起誓與你列祖所立的約。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約伯記 8:8; 馬太福音 24:31; 詩篇 44:1"> 「你且考察在你以前的世代，自神造人在世以來，從天這邊到天那邊，曾有何民聽見神在火中說話的聲音，像你聽見還能存活呢？這樣的大事何曾有，何曾聽見呢？</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 26:8; 申命記 5:15; 出埃及記 6:6"> 神何曾從別的國中將一國的人民領出來，用試驗、神蹟、奇事、爭戰、大能的手和伸出來的膀臂並大可畏的事，像耶和華你們的神在埃及在你們眼前為你們所行的一切事呢？</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 45:18; 撒母耳記上 2:2; 以賽亞書 45:5"> 這是顯給你看，要使你知道唯有耶和華他是神，除他以外，再無別神。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 19:9; 出埃及記 19:19; 申命記 4:33"> 他從天上使你聽見他的聲音，為要教訓你，又在地上使你看見他的烈火，並且聽見他從火中所說的話。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 10:15; 以賽亞書 63:9; 出埃及記 13:9"> 因他愛你的列祖，所以揀選他們的後裔，用大能親自領你出了埃及，</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 7:1; 申命記 9:1–5; 出埃及記 23:27–28"> 要將比你強大的國民從你面前趕出，領你進去，將他們的地賜你為業，像今日一樣。</span>
<span className="v" id="v39" data-v="39" data-xref="約書亞記 2:11; 申命記 4:35; 歷代志上 29:11"> 所以，今日你要知道，也要記在心上：天上地下唯有耶和華他是神，除他以外，再無別神。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 6:3; 以弗所書 6:3; 申命記 12:28"> 我今日將他的律例、誡命曉諭你，你要遵守，使你和你的子孫可以得福，並使你的日子在耶和華你神所賜的地上得以長久。」</span>
</div>
</div>

## 設立河東之逃城

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 35:6; 民數記 35:14–15; 約書亞記 20:2–9"> 那時，摩西在約旦河東，向日出之地，分定三座城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 6:18; 申命記 19:1–10; 民數記 35:15–28"> 使那素無仇恨無心殺了人的，可以逃到這三城之中的一座城，就得存活：</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 20:8; 列王紀上 4:13; 約書亞記 21:27"> 為魯本人分定曠野平原的比悉，為迦得人分定基列的拉末，為瑪拿西人分定巴珊的哥蘭。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命記 27:3; 利未記 27:34; 瑪拉基書 4:4"> 摩西在以色列人面前所陳明的律法，</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 2:3; 申命記 4:1; 詩篇 119:7"> 就是摩西在以色列人出埃及後所傳給他們的法度、律例、典章，</span>
<span className="v" id="v46" data-v="46" data-xref="申命記 3:29; 申命記 4:47; 申命記 1:4–5"> 在約旦河東伯毗珥對面的谷中，在住希實本亞摩利王西宏之地。這西宏是摩西和以色列人出埃及後所擊殺的，</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 3:1–14; 民數記 21:33–35; 申命記 29:7–8"> 他們得了他的地，又得了巴珊王噩的地，就是兩個亞摩利王在約旦河東向日出之地，</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 3:9; 申命記 2:36; 申命記 3:12"> 從亞嫩谷邊的亞羅珥直到西雲山，就是黑門山，</span>
<span className="v" id="v49" data-v="49" data-xref="申命記 3:17; 約書亞記 13:20; 申命記 34:1"> 還有約旦河東的全亞拉巴，直到亞拉巴海，靠近毗斯迦山根。</span>
</div>
</div>

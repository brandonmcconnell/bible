## 當記念神之引導

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 申命記 5:32–3; 帖撒羅尼迦前書 4:1–2"> 「我今日所吩咐的一切誡命，你們要謹守遵行，好叫你們存活，人數增多，且進去得耶和華向你們列祖起誓應許的那地。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:3; 彼得前書 1:7; 申命記 8:16"> 你也要記念耶和華你的神在曠野引導你這四十年，是要苦煉你、試驗你，要知道你心內如何，肯守他的誡命不肯。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:4; 路加福音 4:4; 希伯來書 13:5–6"> 他苦煉你，任你飢餓，將你和你列祖所不認識的嗎哪賜給你吃，使你知道人活著不是單靠食物，乃是靠耶和華口裡所出的一切話。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 9:21; 申命記 29:5; 馬太福音 26:25–30"> 這四十年，你的衣服沒有穿破，你的腳也沒有腫。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 3:19; 箴言 3:12; 撒母耳記下 7:14"> 你當心裡思想，耶和華你神管教你，好像人管教兒子一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 6:31; 申命記 5:33; 撒母耳記上 12:24"> 你要謹守耶和華你神的誡命，遵行他的道，敬畏他。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:9–12; 出埃及記 3:8; 以西結書 20:6"> 因為耶和華你神領你進入美地，那地有河，有泉，有源，從山谷中流出水來，</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 6:13; 詩篇 147:14; 申命記 32:14"> 那地有小麥、大麥、葡萄樹、無花果樹、石榴樹、橄欖樹和蜜。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 22:14; 申命記 33:25; 約書亞記 22:8"> 你在那地不缺食物，一無所缺。那地的石頭是鐵，山內可以挖銅。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 103:2; 羅馬書 14:6; 箴言 3:9"> 你吃得飽足，就要稱頌耶和華你的神，因他將那美地賜給你了。</span>
</div>
</div>

## 慎起驕傲致忘耶和華恩

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:21; 何西阿書 2:8–9; 箴言 1:32"> 「你要謹慎，免得忘記耶和華你的神，不守他的誡命、典章、律例，就是我今日所吩咐你的。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命記 28:47; 申命記 32:15"> 恐怕你吃得飽足，建造美好的房屋居住，</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 1:3; 創世記 13:1–5; 路加福音 12:13–21"> 你的牛羊加多，你的金銀增添，並你所有的全都加增，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:21; 哥林多前書 4:7–8; 申命記 8:11"> 你就心高氣傲，忘記耶和華你的神（就是將你從埃及地為奴之家領出來的，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 21:6; 民數記 20:11; 耶利米書 2:6"> 引你經過那大而可怕的曠野，那裡有火蛇、蠍子、乾旱無水之地。他曾為你使水從堅硬的磐石中流出來，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 8:3; 雅各書 1:12; 出埃及記 16:15"> 又在曠野將你列祖所不認識的嗎哪賜給你吃，是要苦煉你、試驗你，叫你終久享福），</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 9:4; 哥林多前書 4:7; 但以理書 4:30"> 恐怕你心裡說：『這貨財是我力量，我能力得來的。』</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿書 2:8; 申命記 7:8"> 你要記念耶和華你的神，因為得貨財的力量是他給你的，為要堅定他向你列祖起誓所立的約，像今日一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:26; 撒母耳記上 12:25; 西番雅書 1:18"> 你若忘記耶和華你的神，隨從別神，侍奉敬拜，你們必定滅亡，這是我今日警戒你們的。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 9:11–12; 歷代志下 36:16–17"> 耶和華在你們面前怎樣使列國的民滅亡，你們也必照樣滅亡，因為你們不聽從耶和華你們神的話。</span>
</div>

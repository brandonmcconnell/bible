## 以色列人為非利士人所制

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 12:9; 士師記 6:1; 羅馬書 2:6"> 以色列人又行耶和華眼中看為惡的事，耶和華將他們交在非利士人手中四十年。</span>
</div>
</div>

## 瑪挪亞與妻見天使

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約書亞記 19:41; 路加福音 1:7; 約書亞記 15:33"> 那時，有一個瑣拉人，是屬但族的，名叫瑪挪亞。他的妻不懷孕，不生育。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:13; 路加福音 1:11; 士師記 6:11–12"> 耶和華的使者向那婦人顯現，對她說：「向來你不懷孕，不生育，如今你必懷孕生一個兒子。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:15; 士師記 13:14; 民數記 6:2–3"> 所以你當謹慎，清酒濃酒都不可喝，一切不潔之物也不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 6:5; 撒母耳記上 1:11; 歷代志上 18:1"> 你必懷孕生一個兒子，不可用剃頭刀剃他的頭，因為這孩子一出胎就歸神做拿細耳人。他必起首拯救以色列人脫離非利士人的手。」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 13:17–18; 撒母耳記上 9:6; 馬太福音 28:3–4"> 婦人就回去對丈夫說：「有一個神人到我面前來，他的相貌如神使者的相貌，甚是可畏。我沒有問他從哪裡來，他也沒有將他的名告訴我，</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 13:4"> 卻對我說：『你要懷孕生一個兒子，所以清酒濃酒都不可喝，一切不潔之物也不可吃。因為這孩子從出胎一直到死，必歸神做拿細耳人。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:6; 約伯記 34:32; 箴言 3:5–6"> 瑪挪亞就祈求耶和華說：「主啊，求你再差遣那神人到我們這裡來，好指教我們怎樣待這將要生的孩子。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 65:2; 馬太福音 7:7–11"> 神應允瑪挪亞的話。婦人正坐在田間的時候，神的使者又到她那裡，她丈夫瑪挪亞卻沒有同她在一處。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:28–29; 約翰福音 1:41–42"> 婦人急忙跑去告訴丈夫說：「那日到我面前來的人，又向我顯現。」</span>
<span className="v" id="v11" data-v="11"> 瑪挪亞起來，跟隨他的妻來到那人面前，對他說：「與這婦人說話的就是你嗎？」他說：「是我。」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; 以弗所書 6:4; 創世記 18:19"> 瑪挪亞說：「願你的話應驗！我們當怎樣待這孩子，他後來當怎樣呢？」</span>
<span className="v" id="v13" data-v="13"> 耶和華的使者對瑪挪亞說：「我告訴婦人的一切事，她都當謹慎。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 2:5; 士師記 13:4; 帖撒羅尼迦後書 3:4"> 葡萄樹所結的都不可吃，清酒濃酒都不可喝，一切不潔之物也不可吃。凡我所吩咐的，她都當遵守。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 6:18–19; 創世記 18:3–5; 士師記 13:3"> 瑪挪亞對耶和華的使者說：「求你容我們款留你，好為你預備一隻山羊羔。」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 13:23; 士師記 6:20; 士師記 6:26"> 耶和華的使者對瑪挪亞說：「你雖然款留我，我卻不吃你的食物；你若預備燔祭，就當獻於耶和華。」原來瑪挪亞不知道他是耶和華的使者。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:29"> 瑪挪亞對耶和華的使者說：「請將你的名告訴我，到你話應驗的時候，我們好尊敬你。」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:29; 以賽亞書 9:6; 士師記 13:6"> 耶和華的使者對他說：「你何必問我的名？我名是奇妙的。」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 6:19–21; 列王紀上 18:30–38"> 瑪挪亞將一隻山羊羔和素祭在磐石上獻於耶和華。使者行奇妙的事，瑪挪亞和他的妻觀看，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 9:24; 歷代志上 21:16; 列王紀下 2:11"> 見火焰從壇上往上升，耶和華的使者在壇上的火焰中也升上去了。瑪挪亞和他的妻看見，就俯伏於地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 6:22; 何西阿書 12:4–5; 士師記 13:16"> 耶和華的使者不再向瑪挪亞和他的妻顯現，瑪挪亞才知道他是耶和華的使者。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 申命記 5:26; 約翰福音 1:18"> 瑪挪亞對他的妻說：「我們必要死，因為看見了神。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 25:14; 哥林多前書 12:21; 約翰福音 15:15"> 他的妻卻對他說：「耶和華若要殺我們，必不從我們手裡收納燔祭和素祭，並不將這一切事指示我們，今日也不將這些話告訴我們。」</span>
</div>
</div>

## 參孫生

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:80; 撒母耳記上 3:19; 希伯來書 11:32"> 後來婦人生了一個兒子，給他起名叫參孫。孩子長大，耶和華賜福於他。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 3:10; 約書亞記 15:33; 約翰福音 3:34"> 在瑪哈尼但，就是瑣拉和以實陶中間，耶和華的靈才感動他。</span>
</div>

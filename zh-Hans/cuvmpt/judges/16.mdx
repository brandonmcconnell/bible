## 大利拉誘詰參孫力何由至

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:47; 以斯拉記 9:1–2; 創世記 38:16–18"> 參孫到了加沙，在那裡看見一個妓女，就與她親近。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:10–12; 撒母耳記上 23:26; 使徒行傳 9:24"> 有人告訴加沙人說：「參孫到這裡來了。」他們就把他團團圍住，終夜在城門悄悄埋伏，說：「等到天亮我們便殺他。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 2:24; 詩篇 107:16; 以賽亞書 63:1–5"> 參孫睡到半夜，起來，將城門的門扇、門框、門閂一齊拆下來，扛在肩上，扛到希伯崙前的山頂上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:6; 箴言 22:14; 尼希米記 13:26"> 後來參孫在梭烈谷喜愛一個婦人，名叫大利拉。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 13:3; 士師記 14:15; 提摩太前書 6:9–10"> 非利士人的首領上去見那婦人，對她說：「求你誆哄參孫，探探他因何有這麼大的力氣，我們用何法能勝他，捆綁剋制他，我們就每人給你一千一百舍客勒銀子。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 7:21; 箴言 6:26; 箴言 22:14"> 大利拉對參孫說：「求你告訴我，你因何有這麼大的力氣，當用何法捆綁剋制你。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 21:2–3; 羅馬書 3:8; 撒母耳記上 27:10"> 參孫回答說：「人若用七條未乾的青繩子捆綁我，我就軟弱像別人一樣。」</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 7:26"> 於是非利士人的首領拿了七條未乾的青繩子來，交給婦人，她就用繩子捆綁參孫。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 58:9"> 有人預先埋伏在婦人的內室裡。婦人說：「參孫哪，非利士人拿你來了！」參孫就掙斷繩子，如掙斷經火的麻線一般。這樣，他力氣的根由人還是不知道。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 16:13; 路加福音 22:48; 士師記 16:7"> 大利拉對參孫說：「你欺哄我，向我說謊言。現在求你告訴我當用何法捆綁你。」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:5; 以弗所書 4:25; 箴言 13:3"> 參孫回答說：「人若用沒有使過的新繩捆綁我，我就軟弱像別人一樣。」</span>
<span className="v" id="v12" data-v="12"> 大利拉就用新繩捆綁他，對他說：「參孫哪，非利士人拿你來了！」有人預先埋伏在內室裡。參孫將臂上的繩掙斷了，如掙斷一條線一樣。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 大利拉對參孫說：「你到如今還是欺哄我，向我說謊言。求你告訴我，當用何法捆綁你。」參孫回答說：「你若將我頭上的七條髮綹，與緯線同織就可以了。」</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:43; 以斯拉記 9:13–14"> 於是大利拉將他的髮綹與緯線同織，用橛子釘住，對他說：「參孫哪，非利士人拿你來了！」參孫從睡中醒來，將機上的橛子和緯線一齊都拔出來了。</span>
</div>
</div>

## 參孫洩其有力之故

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 14:16; 約翰一書 2:15–16; 約翰福音 14:21–24"> 大利拉對參孫說：「你既不與我同心，怎麼說你愛我呢？你這三次欺哄我，沒有告訴我你因何有這麼大的力氣！」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 7:21–23; 路加福音 18:5; 馬可福音 14:24"> 大利拉天天用話催逼他，甚至他心裡煩悶要死。</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 7:5; 士師記 13:5; 箴言 12:23"> 參孫就把心中所藏的都告訴了她，對她說：「向來人沒有用剃頭刀剃我的頭，因為我自出母胎就歸神做拿細耳人。若剃了我的頭髮，我的力氣就離開我，我便軟弱像別人一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 26:15; 士師記 16:5; 提摩太前書 6:10"> 大利拉見他把心中所藏的都告訴了她，就打發人到非利士人的首領那裡，對他們說：「他已經把心中所藏的都告訴了我，請你們再上來一次。」於是非利士人的首領手裡拿著銀子，上到婦人那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 7:26–27; 箴言 7:21–23; 傳道書 7:26"> 大利拉使參孫枕著她的膝睡覺，叫了一個人來剃除他頭上的七條髮綹。於是大利拉剋制他，他的力氣就離開他了。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 14:42–43; 撒母耳記上 16:14; 約書亞記 7:12"> 大利拉說：「參孫哪，非利士人拿你來了！」參孫從睡中醒來，心裡說：「我要像前幾次出去活動身體。」他卻不知道耶和華已經離開他了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 2:19; 箴言 14:14; 以賽亞書 47:2"> 非利士人將他拿住，剜了他的眼睛，帶他下到加沙，用銅鏈拘索他，他就在監裡推磨。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:13–14; 詩篇 106:44–45; 利未記 26:44"> 然而他的頭髮被剃之後，又漸漸長起來了。</span>
</div>
</div>

## 非利士人戲侮參孫

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 5:2–5; 箴言 24:17; 詩篇 35:15–16"> 非利士人的首領聚集，要給他們的神大袞獻大祭，並且歡樂，因為他們說：「我們的神將我們的仇敵參孫交在我們手中了。」</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 5:4; 但以理書 5:23; 士師記 15:16"> 眾人看見參孫，就讚美他們的神說：「我們的神將毀壞我們地，殺害我們許多人的仇敵交在我們手中了！」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 13:28; 士師記 19:6; 士師記 9:27"> 他們正宴樂的時候，就說：「叫參孫來，在我們面前戲耍戲耍。」於是將參孫從監裡提出來，他就在眾人面前戲耍。他們使他站在兩柱中間。</span>
<span className="v" id="v26" data-v="26"> 參孫向拉他手的童子說：「求你讓我摸著托房的柱子，我要靠一靠。」</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 22:8; 撒母耳記下 11:2; 約書亞記 2:8"> 那時房內充滿男女，非利士人的眾首領也都在那裡，房的平頂上約有三千男女，觀看參孫戲耍。</span>
</div>
</div>

## 參孫傾覆神室與敵偕亡

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="耶利米書 15:15; 耶利米哀歌 3:31–32; 詩篇 143:12"> 參孫求告耶和華說：「主耶和華啊，求你眷念我！神啊，求你賜我這一次的力量，使我在非利士人身上報那剜我雙眼的仇！」</span>
<span className="v" id="v29" data-v="29"> 參孫就抱住托房的那兩根柱子，左手抱一根，右手抱一根，</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 2:8; 馬太福音 16:25; 馬太福音 24:38–39"> 說：「我情願與非利士人同死。」就盡力屈身，房子倒塌，壓住首領和房內的眾人。這樣，參孫死時所殺的人，比活著所殺的還多。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 15:20; 士師記 13:25; 士師記 13:2"> 參孫的弟兄和他父的全家都下去取他的屍首，抬上來葬在瑣拉和以實陶中間，在他父瑪挪亞的墳墓裡。參孫做以色列的士師二十年。</span>
</div>
</div>

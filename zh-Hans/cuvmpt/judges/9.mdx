## 亞比米勒殺基甸眾子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:31; 詩篇 83:2–4; 撒母耳記下 15:6"> 耶路巴力的兒子亞比米勒到了示劍見他的眾母舅，對他們和他外祖全家的人說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:14; 士師記 8:30; 希伯來書 2:14"> 「請你們問示劍的眾人說，是耶路巴力的眾子七十人都管理你們好呢，還是一人管理你們好呢？你們又要記念我是你們的骨肉。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 29:15; 詩篇 10:3; 箴言 1:11–14"> 他的眾母舅便將這一切話為他說給示劍人聽，示劍人的心就歸向亞比米勒。他們說：「他原是我們的弟兄。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 8:33; 使徒行傳 17:5; 歷代志下 13:7"> 就從巴力比利土的廟中取了七十舍客勒銀子給亞比米勒。亞比米勒用以雇了些匪徒跟隨他。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 11:1–2; 歷代志下 21:4; 士師記 6:24"> 他往俄弗拉到他父親的家，將他弟兄耶路巴力的眾子七十人都殺在一塊磐石上；只剩下耶路巴力的小兒子約坦，因為他躲藏了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:9; 列王紀上 12:20; 列王紀下 12:20"> 示劍人和米羅人都一同聚集，往示劍橡樹旁的柱子那裡，立亞比米勒為王。</span>
</div>
</div>

## 約坦宣喻責示劍人

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 11:29; 約翰福音 4:20; 申命記 27:12"> 有人將這事告訴約坦，他就去站在基利心山頂上，向眾人大聲喊叫說：「示劍人哪，你們要聽我的話，神也就聽你們的話。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 8:22–23; 但以理書 4:10–18; 列王紀下 14:9"> 有一時樹木要膏一樹為王，管理它們，就去對橄欖樹說：『請你做我們的王。』</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 2:1; 出埃及記 29:7; 使徒行傳 4:27"> 橄欖樹回答說：『我豈肯止住供奉神和尊重人的油，飄搖在眾樹之上呢？』</span>
<span className="v" id="v10" data-v="10"> 樹木對無花果樹說：『請你來做我們的王。』</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> 無花果樹回答說：『我豈肯止住所結甜美的果子，飄搖在眾樹之上呢？』</span>
<span className="v" id="v12" data-v="12"> 樹木對葡萄樹說：『請你來做我們的王。』</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 104:15; 傳道書 10:19; 民數記 15:5"> 葡萄樹回答說：『我豈肯止住使神和人喜樂的新酒，飄搖在眾樹之上呢？』</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 14:9"> 眾樹對荊棘說：『請你來做我們的王。』</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:2; 士師記 9:20; 何西阿書 14:7"> 荊棘回答說：『你們若誠誠實實地膏我為王，就要投在我的蔭下。不然，願火從荊棘裡出來，燒滅黎巴嫩的香柏樹。』</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 8:35"> 現在你們立亞比米勒為王，若按誠實、正直善待耶路巴力和他的全家，這就是酬他的勞。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:4; 羅馬書 5:8; 啟示錄 12:11"> 從前我父冒死為你們爭戰，救了你們脫離米甸人的手。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:5–6; 士師記 8:30–31; 士師記 9:14"> 你們如今起來攻擊我的父家，將他眾子七十人殺在一塊磐石上，又立他婢女所生的兒子亞比米勒為示劍人的王，他原是你們的弟兄。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 8:6; 雅各書 4:16; 腓立比書 3:3"> 你們如今若按誠實、正直待耶路巴力和他的家，就可因亞比米勒得歡樂，他也可因你們得歡樂。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:15; 士師記 9:56–57; 歷代志下 20:22–23"> 不然，願火從亞比米勒發出，燒滅示劍人和米羅眾人；又願火從示劍人和米羅人中出來，燒滅亞比米勒。」</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 21:16; 撒母耳記下 20:14; 約書亞記 19:8"> 約坦因怕他弟兄亞比米勒，就逃跑，來到比珥，住在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 亞比米勒管理以色列人三年。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 33:1; 以賽亞書 19:14; 以賽亞書 19:2"> 神使惡魔降在亞比米勒和示劍人中間，示劍人就以詭詐待亞比米勒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 2:32; 詩篇 7:16; 以斯帖記 9:25"> 這是要叫耶路巴力七十個兒子所受的殘害歸於他們的哥哥亞比米勒，又叫那流他們血的罪歸於幫助他殺弟兄的示劍人。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 8:12–13; 箴言 1:11–12; 約書亞記 8:4"> 示劍人在山頂上設埋伏，等候亞比米勒，凡從他們那裡經過的人，他們就搶奪。有人將這事告訴亞比米勒。</span>
</div>
</div>

## 迦勒謀攻亞比米勒

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 13:8; 創世記 19:7"> 以別的兒子迦勒和他的弟兄來到示劍，示劍人都信靠他。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 9:4; 士師記 9:46; 詩篇 109:17"> 示劍人出城到田間去，摘下葡萄，踹酒，設擺筵宴，進他們神的廟中吃喝，咒詛亞比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 34:2; 創世記 34:6; 撒母耳記上 25:10"> 以別的兒子迦勒說：「亞比米勒是誰，示劍是誰，使我們服侍他呢？他不是耶路巴力的兒子嗎？他的幫手不是西布勒嗎？你們可以服侍示劍的父親哈抹的後裔。我們為何服侍亞比米勒呢？</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 15:4; 撒母耳記下 2:14–17; 以賽亞書 36:8–9"> 唯願這民歸我的手下，我就除掉亞比米勒。」迦勒又對亞比米勒說：「增添你的軍兵出來吧！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 邑宰西布勒聽見以別的兒子迦勒的話，就發怒，</span>
<span className="v" id="v31" data-v="31"> 悄悄地打發人去見亞比米勒，說：「以別的兒子迦勒和他的弟兄到了示劍，煽惑城中的民攻擊你。</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 3:15; 詩篇 36:4; 箴言 1:11–16"> 現在你和跟隨你的人今夜起來，在田間埋伏。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 10:7; 傳道書 9:10; 利未記 25:26"> 到早晨太陽一出，你就起來闖城。迦勒和跟隨他的人出來攻擊你的時候，你便向他們見機而做。」</span>
</div>
</div>

## 亞比米勒擊敗迦勒

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34"> 於是，亞比米勒和跟隨他的眾人夜間起來，分做四隊，埋伏等候示劍人。</span>
<span className="v" id="v35" data-v="35"> 以別的兒子迦勒出去，站在城門口，亞比米勒和跟隨他的人從埋伏之處起來。</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 8:24; 以西結書 7:7"> 迦勒看見那些人，就對西布勒說：「看哪，有人從山頂上下來了。」西布勒說：「你看見山的影子，以為是人。」</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:14"> 迦勒又說：「看哪，有人從高處下來，又有一隊從米惡尼尼橡樹的路上而來。」</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 9:28–29; 列王紀下 14:8–14; 撒母耳記下 2:26–27"> 西布勒對他說：「你曾說：『亞比米勒是誰，叫我們服侍他？』你所誇的口在哪裡呢？這不是你所藐視的民嗎？你現在出去，與他們交戰吧！」</span>
<span className="v" id="v39" data-v="39"> 於是迦勒率領示劍人出去，與亞比米勒交戰。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 20:18–21; 列王紀上 20:30"> 亞比米勒追趕迦勒，迦勒在他面前逃跑，有許多受傷仆倒的，直到城門。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="士師記 9:28; 士師記 9:30"> 亞比米勒住在亞魯瑪。西布勒趕出迦勒和他弟兄，不准他們住在示劍。</span>
<span className="v" id="v42" data-v="42"> 次日，民出到田間，有人告訴亞比米勒。</span>
<span className="v" id="v43" data-v="43"> 他就把他的人分做三隊，埋伏在田間，看見示劍人從城裡出來，就起來擊殺他們。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太書 5:15; 士師記 9:15; 士師記 9:20"> 亞比米勒和跟隨他的一隊向前闖去，站在城門口。那兩隊直闖到田間，擊殺了眾人。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 3:25; 申命記 29:23; 雅各書 2:13"> 亞比米勒整天攻打城，將城奪取，殺了其中的居民，將城拆毀，撒上了鹽。</span>
</div>
</div>

## 焚示劍樓

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士師記 8:33; 士師記 9:4; 列王紀上 8:26"> 示劍樓的人聽見了，就躲入巴力比利土廟的衛所。</span>
<span className="v" id="v47" data-v="47"> 有人告訴亞比米勒說，示劍樓的人都聚在一處，</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 68:14; 箴言 1:11–12; 士師記 7:17–18"> 亞比米勒和跟隨他的人就都上撒們山。亞比米勒手拿斧子，砍下一根樹枝，扛在肩上，對跟隨他的人說：「你們看我所行的，也當趕緊照樣行。」</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太書 5:15; 雅各書 3:16; 士師記 9:20"> 眾人就各砍一枝，跟隨亞比米勒，把樹枝堆在衛所的四圍，放火燒了衛所，以致示劍樓的人都死了，男女約有一千。</span>
</div>
</div>

## 亞比米勒被傷而亡

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50"> 亞比米勒到提備斯，向提備斯安營，就攻取了那城。</span>
<span className="v" id="v51" data-v="51"> 城中有一座堅固的樓，城裡的眾人，無論男女，都逃進樓去，關上門，上了樓頂。</span>
<span className="v" id="v52" data-v="52" data-xref="士師記 9:48–49; 列王紀下 14:10; 列王紀下 15:16"> 亞比米勒到了樓前攻打，挨近樓門，要用火焚燒。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 11:21; 約伯記 31:3; 耶利米書 49:20"> 有一個婦人把一塊上磨石拋在亞比米勒的頭上，打破了他的腦骨。</span>
<span className="v" id="v54" data-v="54" data-xref="撒母耳記上 31:4–5"> 他就急忙喊叫拿他兵器的少年人，對他說：「拔出你的刀來殺了我吧！免得人議論我說：『他為一個婦人所殺。』」於是少年人把他刺透，他就死了。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳記下 18:16; 撒母耳記下 20:21–22; 列王紀上 22:35–36"> 以色列人見亞比米勒死了，便各回自己的地方去了。</span>
<span className="v" id="v56" data-v="56" data-xref="詩篇 94:23; 士師記 9:24; 箴言 5:22"> 這樣，神報應亞比米勒向他父親所行的惡，就是殺了弟兄七十個人的惡。</span>
<span className="v" id="v57" data-v="57" data-xref="士師記 9:20; 約書亞記 6:26; 列王紀上 16:34"> 示劍人的一切惡，神也都報應在他們頭上，耶路巴力的兒子約坦的咒詛歸到他們身上了。</span>
</div>
</div>

## 民立耶弗他做首領

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:32; 士師記 6:12; 列王紀下 5:1"> 基列人耶弗他是個大能的勇士，是妓女的兒子。耶弗他是基列所生的。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:10; 箴言 2:16; 申命記 23:2"> 基列的妻也生了幾個兒子，他妻所生的兒子長大了，就趕逐耶弗他，說：「你不可在我們父家承受產業，因為你是妓女的兒子。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 9:4; 撒母耳記上 22:2; 撒母耳記下 10:8"> 耶弗他就逃避他的弟兄，去住在陀伯地，有些匪徒到他那裡聚集，與他一同出入。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 10:9"> 過了些日子，亞捫人攻打以色列。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:22–23; 使徒行傳 7:35–39; 哥林多前書 1:27–29"> 亞捫人攻打以色列的時候，基列的長老到陀伯地去，要叫耶弗他回來，</span>
<span className="v" id="v6" data-v="6"> 對耶弗他說：「請你來做我們的元帥，我們好與亞捫人爭戰。」</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 3:9; 創世記 45:4–5; 以賽亞書 60:14"> 耶弗他回答基列的長老說：「從前你們不是恨我，趕逐我出離父家嗎？現在你們遭遇急難為何到我這裡來呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 10:18; 列王紀上 13:6; 出埃及記 10:17"> 基列的長老回答耶弗他說：「現在我們到你這裡來，是要你同我們去，與亞捫人爭戰。你可以做基列一切居民的領袖。」</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 32:20–29"> 耶弗他對基列的長老說：「你們叫我回去，與亞捫人爭戰，耶和華把他交給我，我可以做你們的領袖嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 42:5; 創世記 31:50; 耶利米書 29:23"> 基列的長老回答耶弗他說：「有耶和華在你我中間做見證，我們必定照你的話行。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 10:17; 撒母耳記上 10:17; 士師記 20:1"> 於是耶弗他同基列的長老回去，百姓就立耶弗他做領袖，做元帥。耶弗他在米斯巴將自己的一切話陳明在耶和華面前。</span>
</div>
</div>

## 耶弗他與亞捫人辯理

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:26; 馬太福音 18:15–16; 箴言 25:8–9"> 耶弗他打發使者去見亞捫人的王，說：「你與我有什麼相干，竟來到我國中攻打我呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 32:22; 民數記 21:24–26; 申命記 2:37"> 亞捫人的王回答耶弗他的使者說：「因為以色列人從埃及上來的時候占據我的地，從亞嫩河到雅博河，直到約旦河。現在你要好好地將這地歸還吧！」</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:11; 羅馬書 12:18; 希伯來書 12:14"> 耶弗他又打發使者去見亞捫人的王，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 2:19; 申命記 2:9; 民數記 21:27–30"> 對他說：「耶弗他如此說：『以色列人並沒有占據摩押地和亞捫人的地。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 14:25; 申命記 1:40; 民數記 20:1"> 以色列人從埃及上來乃是經過曠野到紅海，來到加低斯，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 20:14–21; 申命記 2:4–9; 民數記 20:1"> 就打發使者去見以東王，說：「求你容我從你的地經過。」以東王卻不應允。又照樣打發使者去見摩押王，他也不允准。以色列人就住在加低斯。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 2:1–8; 民數記 22:36; 民數記 21:4–13"> 他們又經過曠野，繞著以東和摩押地，從摩押地的東邊過來，在亞嫩河邊安營，並沒有入摩押的境內，因為亞嫩河是摩押的邊界。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 21:21–35; 申命記 2:26–36; 申命記 3:1–17"> 以色列人打發使者去見亞摩利王西宏，就是希實本的王，對他說：「求你容我們從你的地經過，往我們自己的地方去。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 13:15–32; 民數記 21:23–25; 詩篇 136:17–21"> 西宏卻不信服以色列人，不容他們經過他的境界，乃招聚他的眾民在雅雜安營，與以色列人爭戰。</span>
<span className="v" id="v21" data-v="21"> 耶和華以色列的神將西宏和他的眾民都交在以色列人手中，以色列人就擊殺他們，得了亞摩利人的全地，</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 2:36"> 從亞嫩河到雅博河，從曠野直到約旦河。</span>
<span className="v" id="v23" data-v="23"> 耶和華以色列的神在他百姓以色列面前趕出亞摩利人，你竟要得他們的地嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 21:29; 詩篇 78:55; 彌迦書 4:5"> 你的神基抹所賜你的地，你不是得為業嗎？耶和華我們的神在我們面前所趕出的人，我們就得他的地。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 6:5; 約書亞記 24:9–10; 申命記 23:3–4"> 難道你比摩押王西撥的兒子巴勒還強嗎？他曾與以色列人爭競，或是與他們爭戰嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 2:36; 約書亞記 12:5; 士師記 10:8"> 以色列人住希實本和屬希實本的鄉村，亞羅珥和屬亞羅珥的鄉村，並沿亞嫩河的一切城邑，已經有三百年了。在這三百年之內，你們為什麼沒有取回這些地方呢？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 24:15; 創世記 16:5; 撒母耳記上 24:12"> 原來我沒有得罪你，你卻攻打我，惡待我。願審判人的耶和華今日在以色列人和亞捫人中間判斷是非！』」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 14:11; 箴言 16:18"> 但亞捫人的王不肯聽耶弗他打發人說的話。</span>
</div>
</div>

## 耶弗他許願

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 11:25; 士師記 3:10; 士師記 13:25"> 耶和華的靈降在耶弗他身上，他就經過基列和瑪拿西，來到基列的米斯巴，又從米斯巴來到亞捫人那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 28:20; 撒母耳記上 1:11; 傳道書 5:1–2"> 耶弗他就向耶和華許願，說：「你若將亞捫人交在我手中，</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 66:13–14; 利未記 27:28–29; 撒母耳記上 1:28"> 我從亞捫人那裡平平安安回來的時候，無論什麼人，先從我家門出來迎接我，就必歸你，我也必將他獻上為燔祭。」</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:4; 士師記 2:18; 士師記 3:10"> 於是耶弗他往亞捫人那裡去，與他們爭戰。耶和華將他們交在他手中，</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 27:17; 申命記 2:36"> 他就大大殺敗他們，從亞羅珥到米匿，直到亞備勒基拉明，攻取了二十座城。這樣，亞捫人就被以色列人制伏了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米書 31:4; 出埃及記 15:20; 士師記 10:17"> 耶弗他回米斯巴到了自己的家，不料，他女兒拿著鼓跳舞出來迎接他，是他獨生的，此外無兒無女。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 14:7–9; 創世記 37:29–30; 創世記 42:36–38"> 耶弗他看見她，就撕裂衣服，說：「哀哉！我的女兒啊，你使我甚是愁苦，叫我作難了！因為我已經向耶和華開口許願，不能挽回。」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 18:19; 腓立比書 2:30; 羅馬書 16:4"> 他女兒回答說：「父啊，你既向耶和華開口，就當照你口中所說的向我行，因耶和華已經在仇敵亞捫人身上為你報仇。」</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 1:25; 撒母耳記上 1:6"> 又對父親說：「有一件事求你允准，容我去兩個月，與同伴在山上，好哀哭我終為處女。」</span>
<span className="v" id="v38" data-v="38"> 耶弗他說：「你去吧！」就容她去兩個月。她便和同伴去了，在山上為她終為處女哀哭。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 66:3; 士師記 11:31; 利未記 27:28–29"> 兩月已滿，她回到父親那裡，父親就照所許的願向她行了。女兒終身沒有親近男子。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 9:25; 士師記 5:11"> 此後以色列中有個規矩，每年以色列的女子去為基列人耶弗他的女兒哀哭四天。</span>
</div>
</div>

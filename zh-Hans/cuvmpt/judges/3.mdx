## 遺留數族以試以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 2:21–22; 申命記 7:22; 箴言 17:3"> 耶和華留下這幾族，為要試驗那不曾知道與迦南爭戰之事的以色列人，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 3:5; 創世記 3:7; 哥林多前書 9:26–27"> 好叫以色列的後代又知道又學習未曾曉得的戰事。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 13:3; 約書亞記 13:5; 士師記 10:7"> 所留下的就是非利士的五個首領和一切迦南人，西頓人，並住黎巴嫩山的希未人（從巴力黑們山直到哈馬口）。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:1; 士師記 2:22; 出埃及記 15:25"> 留下這幾族，為要試驗以色列人，知道他們肯聽從耶和華藉摩西吩咐他們列祖的誡命不肯。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:34–38; 創世記 10:15–18; 出埃及記 3:8"> 以色列人竟住在迦南人、赫人、亞摩利人、比利洗人、希未人、耶布斯人中間，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:3–4; 出埃及記 34:16; 列王紀上 11:1–5"> 娶他們的女兒為妻，將自己的女兒嫁給他們的兒子，並侍奉他們的神。</span>
</div>
</div>

## 俄陀聶興起為救者

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 34:13; 列王紀下 23:6; 列王紀上 18:19"> 以色列人行耶和華眼中看為惡的事，忘記耶和華他們的神，去侍奉諸巴力和亞舍拉，</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 2:14; 哈巴谷書 3:7; 士師記 4:9"> 所以耶和華的怒氣向以色列人發作，就把他們交在美索不達米亞王古珊利薩田的手中。以色列人服侍古珊利薩田八年。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 3:15; 士師記 1:13; 詩篇 22:5"> 以色列人呼求耶和華的時候，耶和華就為他們興起一位拯救者救他們，就是迦勒兄弟基納斯的兒子俄陀聶。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 13:25; 撒母耳記上 11:6; 士師記 14:19"> 耶和華的靈降在他身上，他就做了以色列的士師，出去爭戰。耶和華將美索不達米亞王古珊利薩田交在他手中，他便勝了古珊利薩田。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 5:31; 士師記 8:28; 約書亞記 11:23"> 於是國中太平四十年。基納斯的兒子俄陀聶死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 12:9; 士師記 2:19; 士師記 2:14"> 以色列人又行耶和華眼中看為惡的事，耶和華就使摩押王伊磯倫強盛，攻擊以色列人。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 1:16; 申命記 34:3; 士師記 5:14"> 伊磯倫招聚亞捫人和亞瑪力人，去攻打以色列人，占據棕樹城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:47–48; 申命記 28:40; 利未記 26:23–25"> 於是以色列人服侍摩押王伊磯倫十八年。</span>
</div>
</div>

## 以笏興起

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 3:9; 詩篇 78:34; 以賽亞書 36:16"> 以色列人呼求耶和華的時候，耶和華就為他們興起一位拯救者，就是便雅憫人基拉的兒子以笏。他是左手便利的。以色列人託他送禮物給摩押王伊磯倫。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 啟示錄 2:12; 詩篇 149:6"> 以笏打了一把兩刃的劍，長一肘，帶在右腿上衣服裡面。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:20; 約伯記 15:27; 耶利米書 50:11"> 他將禮物獻給摩押王伊磯倫，原來伊磯倫極其肥胖。</span>
<span className="v" id="v18" data-v="18"> 以笏獻完禮物，便將抬禮物的人打發走了，</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 4:20; 士師記 3:20; 使徒行傳 23:18–19"> 自己卻從靠近吉甲鑿石之地回來，說：「王啊，我有一件機密事奏告你。」王說：「迴避吧！」於是左右侍立的人都退去了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 10:7; 阿摩司書 3:15; 詩篇 29:1"> 以笏來到王面前，王獨自一人坐在涼樓上。以笏說：「我奉神的命報告你一件事。」王就從座位上站起來。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 13:3; 約伯記 20:25; 撒母耳記上 15:33"> 以笏便伸左手，從右腿上拔出劍來，刺入王的肚腹，</span>
<span className="v" id="v22" data-v="22"> 連劍把都刺進去了。劍被肥肉夾住，他沒有從王的肚腹拔出來，且穿通了後身。</span>
<span className="v" id="v23" data-v="23"> 以笏就出到遊廊，將樓門盡都關鎖。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 24:3"> 以笏出來之後，王的僕人到了，看見樓門關鎖，就說：「他必是在樓上大解。」</span>
<span className="v" id="v25" data-v="25"> 他們等煩了，見仍不開樓門，就拿鑰匙開了，不料，他們的主人已死，倒在地上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 他們耽延的時候，以笏就逃跑了，經過鑿石之地，逃到西伊拉。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:34; 撒母耳記上 13:3; 士師記 5:14"> 到了，就在以法蓮山地吹角。以色列人隨著他下了山地，他在前頭引路，</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 12:5; 士師記 7:9; 士師記 7:15"> 對他們說：「你們隨我來，因為耶和華已經把你們的仇敵摩押人交在你們手中。」於是他們跟著他下去，把守約旦河的渡口，不容摩押一人過去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:15; 士師記 3:17; 詩篇 17:10"> 那時擊殺了摩押人約有一萬，都是強壯的勇士，沒有一人逃脫。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 3:11; 士師記 5:31"> 這樣，摩押就被以色列人制伏了。國中太平八十年。</span>
</div>
</div>

## 珊迦擊敗非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 5:6; 哥林多前書 1:17; 撒母耳記上 17:50"> 以笏之後，有亞拿的兒子珊迦，他用趕牛的棍子打死六百非利士人。他也救了以色列人。</span>
</div>

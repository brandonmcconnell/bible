## 預言波斯王將攻希臘

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:1; 但以理書 5:31; 但以理書 10:18"> 又說：「當瑪代王大流士元年，我曾起來扶助米迦勒，使他堅強。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:5–6; 但以理書 8:26; 啟示錄 21:5"> 「現在我將真事指示你，波斯還有三王興起，第四王必富足遠勝諸王。他因富足成為強盛，就必激動大眾攻擊希臘國。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 11:16; 但以理書 11:36; 但以理書 8:21"> 必有一個勇敢的王興起，執掌大權，隨意而行。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 8:22; 但以理書 8:8; 耶利米書 12:17"> 他興起的時候，他的國必破裂，向天的四方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「方」原文作「風」。">a</a></sup>分開，卻不歸他的後裔，治國的權勢也都不及他，因為他的國必被拔出，歸於他後裔之外的人。</span>
</div>
</div>

## 南王北王時爭時和

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 11:14; 但以理書 11:11; 但以理書 11:25"> 「南方的王必強盛，他將帥中必有一個比他更強盛，執掌權柄，他的權柄甚大。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 11:13; 但以理書 11:40; 但以理書 11:7"> 過些年後，他們必互相聯合，南方王的女兒必就了北方王來立約。但這女子幫助之力存立不住，王和他所倚靠之力也不能存立。這女子和引導她來的，並生她的，以及當時扶助她的，都必交於死地。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理書 11:38–39; 但以理書 11:19–20; 以賽亞書 9:14"> 「但這女子的本家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「本家」原文作「根」。">b</a></sup>必另生一子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「子」原文作「枝」。">c</a></sup>繼續王位，他必率領軍隊進入北方王的保障，攻擊他們，而且得勝，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 37:19; 以賽亞書 46:1–2; 耶利米書 43:12–13"> 並將他們的神像和鑄成的偶像，與金銀的寶器掠到埃及去。數年之內，他不去攻擊北方的王。</span>
<span className="v" id="v9" data-v="9"> 北方的王<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文作：他。">d</a></sup>必入南方王的國，卻要仍回本地。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 51:42; 但以理書 11:7; 但以理書 11:26"> 「北方王<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文作：他。">e</a></sup>的二子必動干戈，招聚許多軍兵。這軍兵前去，如洪水氾濫，又必再去爭戰，直到南方王的保障。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 8:7; 但以理書 11:5; 詩篇 33:16–17"> 南方王必發烈怒，出來與北方王爭戰，擺列大軍，北方王的軍兵必交付他手。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 12:22–23; 列王紀下 14:10; 以賽亞書 10:7–12"> 他的眾軍高傲，他的心也必自高，他雖使數萬人仆倒，卻不得常勝。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 4:16; 但以理書 12:7; 但以理書 11:6–7"> 北方王必回來擺列大軍，比先前的更多。滿了所定的年數，他必率領大軍，帶極多的軍裝來。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 17:17; 使徒行傳 4:25–28"> 那時必有許多人起來攻擊南方王，並且你本國的強暴人必興起，要應驗那異象，他們卻要敗亡。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 6:6; 以西結書 17:17; 以西結書 4:2"> 北方王必來築壘攻取堅固城，南方的軍兵必站立不住，就是選擇的精兵<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="「精兵」原文作「民」。">f</a></sup>也無力站住。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 8:9; 但以理書 11:36; 但以理書 11:3"> 來攻擊他的必任意而行，無人在北方王<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原文作：他。">g</a></sup>面前站立得住。他必站在那榮美之地，用手施行毀滅。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 12:17; 以西結書 4:3; 以西結書 4:7"> 他必定意用全國之力而來，立公正的約，照約而行，將自己的女兒給南方王為妻，想要敗壞他<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="或作：埃及。">h</a></sup>，這計卻不得成就，與自己毫無益處。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿書 12:14; 耶利米書 31:10; 西番雅書 2:11"> 其後他必轉回，奪取了許多海島。但有一大帥，除掉他令人受的羞辱，並且使這羞辱歸他本身。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 26:21; 詩篇 37:36; 約伯記 20:8"> 他就必轉向本地的保障，卻要絆跌仆倒，歸於無有。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 60:17; 但以理書 11:7; 申命記 15:2–3"> 「那時，必有一人興起接續他為王，使橫征暴斂的人通行國中的榮美地。這王不多日就必滅亡，卻不因憤怒，也不因爭戰。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 11:34; 但以理書 8:25; 士師記 9:1–20"> 必有一個卑鄙的人興起接續為王，人未曾將國的尊榮給他，他卻趁人坦然無備的時候，用諂媚的話得國。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 8:10–11; 但以理書 11:10; 但以理書 9:26"> 必有無數的軍兵勢如洪水，在他面前沖沒敗壞，同盟的君也必如此。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 8:25; 帖撒羅尼迦後書 2:9; 詩篇 52:2"> 與那君結盟之後，他必行詭詐，因為他必上來以微小的軍<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="原文作：民。">i</a></sup>成為強盛。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:25; 箴言 23:7; 馬太福音 9:4"> 趁人坦然無備的時候，他必來到國中極肥美之地，行他列祖和他列祖之祖所未曾行的，將擄物、掠物和財寶散給眾人，又要設計攻打保障，然而這都是暫時的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; 但以理書 11:2; 箴言 28:25"> 他必奮勇向前，率領大軍攻擊南方王。南方王也必以極大極強的軍兵與他爭戰，卻站立不住，因為有人設計謀害南方王。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 11:10; 但以理書 11:40; 撒母耳記下 4:2–12"> 吃王膳的必敗壞他，他的軍隊必被沖沒，而且被殺的甚多。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 12:2; 耶利米書 9:3–5; 哈巴谷書 2:3"> 至於這二王，他們心懷惡計，同席說謊，計謀卻不成就，因為到了定期，事就了結。</span>
</div>
</div>

## 北王廢棄聖約汙褻聖地

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理書 11:30–32; 但以理書 8:24; 使徒行傳 3:25"> 「北方王<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="原文作：他。">j</a></sup>必帶許多財寶回往本國，他的心反對聖約，任意而行，回到本地。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 17:26; 以賽亞書 14:31; 但以理書 11:25"> 到了定期，他必返回，來到南方，後一次卻不如前一次。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 10:4; 民數記 24:24; 耶利米書 2:10"> 因為基提戰船必來攻擊他，他就喪膽而回，又要惱恨聖約，任意而行。他必回來聯絡背棄聖約的人。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 12:11; 但以理書 9:27; 馬太福音 24:15"> 他必興兵，這兵必褻瀆聖地，就是保障，除掉常獻的燔祭，設立那行毀壞可憎的。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 28:9; 詩篇 9:10; 約翰福音 17:3"> 作惡違背聖約的人，他必用巧言勾引；唯獨認識神的子民，必剛強行事。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 24:9; 約翰福音 16:2; 瑪拉基書 2:7"> 民間的智慧人必訓誨多人，然而他們多日必倒在刀下，或被火燒，或被擄掠搶奪。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 7:15; 羅馬書 16:18; 使徒行傳 20:29–30"> 他們仆倒的時候，稍得扶助，卻有許多人用諂媚的話親近他們。</span>
<span className="v" id="v35" data-v="35" data-xref="撒迦利亞書 13:9; 瑪拉基書 3:2–4; 啟示錄 2:10"> 智慧人中有些仆倒的，為要熬煉其餘的人，使他們清淨潔白，直到末了，因為到了定期，事就了結。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="啟示錄 13:5–6; 帖撒羅尼迦後書 2:4; 申命記 10:17"> 「王必任意而行，自高自大，超過所有的神，又用奇異的話攻擊萬神之神。他必行事亨通，直到主的憤怒完畢，因為所定的事必然成就。</span>
<span className="v" id="v37" data-v="37" data-xref="帖撒羅尼迦後書 2:4; 以賽亞書 14:13; 提摩太前書 4:3"> 他必不顧他列祖的神，也不顧婦女所羨慕的神，無論何神他都不顧，因為他必自大，高過一切。</span>
<span className="v" id="v38" data-v="38" data-xref="啟示錄 17:1–5; 以賽亞書 44:9; 啟示錄 13:12–17"> 他倒要敬拜保障的神，用金銀、寶石和可愛之物敬奉他列祖所不認識的神。</span>
<span className="v" id="v39" data-v="39" data-xref="啟示錄 18:9–13"> 他必靠外邦神的幫助，攻破最堅固的保障。凡承認他的，他必將榮耀加給他們，使他們管轄許多人，又為賄賂分地於他們。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="但以理書 11:35; 但以理書 11:10; 以賽亞書 5:28"> 「到末了，南方王要與他交戰。北方王必用戰車、馬兵和許多戰船，勢如暴風來攻擊他，也必進入列國，如洪水氾濫。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 48:47; 耶利米書 49:6; 以賽亞書 11:13–15"> 又必進入那榮美之地，有許多國就被傾覆，但以東人、摩押人和一大半亞捫人必脫離他的手。</span>
<span className="v" id="v42" data-v="42" data-xref="撒迦利亞書 10:10–11; 以西結書 29:14; 啟示錄 11:8"> 他必伸手攻擊列國，埃及地也不得脫離。</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志下 12:3; 那鴻書 3:9; 以西結書 30:4–5"> 他必把持埃及的金銀財寶和各樣的寶物，呂彼亞人和古實人都必跟從他。</span>
<span className="v" id="v44" data-v="44" data-xref="啟示錄 19:19–21; 啟示錄 16:12; 啟示錄 17:13"> 但從東方和北方必有消息擾亂他，他就大發烈怒出去，要將多人殺滅淨盡。</span>
<span className="v" id="v45" data-v="45" data-xref="帖撒羅尼迦後書 2:4; 但以理書 8:25; 啟示錄 19:19–21"> 他必在海和榮美的聖山中間，設立他如宮殿的帳幕，然而到了他的結局，必無人能幫助他。</span>
</div>
</div>

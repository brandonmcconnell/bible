## 尼布甲尼撒王得夢遺忘迫令術士告之

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 4:5; 以斯帖記 6:1; 約伯記 33:15–17"> 尼布甲尼撒在位第二年，他做了夢，心裡煩亂，不能睡覺。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 1:20; 但以理書 4:6; 創世記 41:8"> 王吩咐人將術士、用法術的、行邪術的和迦勒底人召來，要他們將王的夢告訴王，他們就來站在王前。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 40:8; 創世記 41:15; 但以理書 4:5"> 王對他們說：「我做了一夢，心裡煩亂，要知道這是什麼夢。」</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 3:9; 但以理書 5:10; 以斯拉記 4:7"> 迦勒底人用亞蘭的言語對王說：「願王萬歲！請將那夢告訴僕人，僕人就可以講解。」</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:29; 以斯拉記 6:11; 列王紀下 10:27"> 王回答迦勒底人說：「夢我已經忘了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：我已定命。8節同。">a</a></sup>，你們若不將夢和夢的講解告訴我，就必被凌遲，你們的房屋必成為糞堆。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 5:7; 但以理書 2:48; 但以理書 5:29"> 你們若將夢和夢的講解告訴我，就必從我這裡得贈品和賞賜並大尊榮。現在你們要將夢和夢的講解告訴我。」</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 2:4; 但以理書 2:9; 傳道書 10:4"> 他們第二次對王說：「請王將夢告訴僕人，僕人就可以講解。」</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 4:5; 以弗所書 5:16"> 王回答說：「我準知道你們是故意遲延，因為你們知道那夢我已經忘了。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 41:23; 但以理書 7:25; 以斯帖記 4:11"> 你們若不將夢告訴我，只有一法待你們。因為你們預備了謊言亂語向我說，要等候時勢改變。現在你們要將夢告訴我，因我知道你們能將夢的講解告訴我。」</span>
</div>
</div>

## 術士回奏無人能告

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 2:27"> 迦勒底人在王面前回答說：「世上沒有人能將王所問的事說出來。因為沒有君王、大臣、掌權的向術士，或用法術的，或迦勒底人問過這樣的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 5:11; 以賽亞書 57:15; 創世記 41:39"> 王所問的事甚難，除了不與世人同居的神明，沒有人在王面前能說出來。」</span>
</div>
</div>

## 王怒擬殲滅之

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理書 3:13; 馬太福音 2:16; 但以理書 3:19"> 因此，王氣憤憤地大發烈怒，吩咐滅絕巴比倫所有的哲士。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 1:19–20; 以斯帖記 3:12–15; 以賽亞書 10:1"> 於是命令發出，哲士將要見殺，人就尋找但以理和他的同伴，要殺他們。</span>
</div>
</div>

## 但以理求寬限

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 2:24; 耶利米書 52:12; 撒母耳記下 20:16–22"> 王的護衛長亞略出來，要殺巴比倫的哲士，但以理就用婉言回答他，</span>
<span className="v" id="v15" data-v="15"> 向王的護衛長亞略說：「王的命令為何這樣緊急呢？」亞略就將情節告訴但以理。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:18–19; 但以理書 2:9–11"> 但以理遂進去求王寬限，就可以將夢的講解告訴王。</span>
</div>
</div>

## 與同儕禱主蒙示以王夢與兆

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理書 1:6–7; 但以理書 3:12; 但以理書 1:11"> 但以理回到他的居所，將這事告訴他的同伴哈拿尼雅、米沙利、亞撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 33:3; 馬太福音 18:19; 馬太福音 18:12"> 要他們祈求天上的神施憐憫，將這奧祕的事指明，免得但以理和他的同伴與巴比倫其餘的哲士一同滅亡。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 12:6; 阿摩司書 3:7; 但以理書 7:7"> 這奧祕的事就在夜間異象中給但以理顯明，但以理便稱頌天上的神。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 113:2; 詩篇 145:1–2; 啟示錄 5:12"> 但以理說：「神的名是應當稱頌的，從亙古直到永遠！因為智慧能力都屬乎他。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 75:5–7; 詩篇 31:14–15; 詩篇 113:7–8"> 他改變時候、日期，廢王、立王，將智慧賜予智慧人，將知識賜予聰明人。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 12:22; 約翰一書 1:5; 耶利米書 23:24"> 他顯明深奧隱祕的事，知道暗中所有的，光明也與他同居。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 2:18; 出埃及記 3:15; 但以理書 2:29–30"> 我列祖的神啊，我感謝你，讚美你！因你將智慧、才能賜給我，允准我們所求的，把王的事給我們指明。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 27:24; 但以理書 2:12–14"> 於是但以理進去見亞略，就是王所派滅絕巴比倫哲士的，對他說：「不要滅絕巴比倫的哲士，求你領我到王面前，我要將夢的講解告訴王。」</span>
</div>
</div>

## 但以理覲王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 1:27–28; 但以理書 6:13; 但以理書 5:13"> 亞略就急忙將但以理領到王面前，對王說：「我在被擄的猶大人中遇見一人，他能將夢的講解告訴王。」</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 1:7; 但以理書 5:16; 但以理書 5:12"> 王問稱為伯提沙撒的但以理說：「你能將我所做的夢和夢的講解告訴我嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 47:12–14; 但以理書 2:2; 以賽亞書 44:25"> 但以理在王面前回答說：「王所問的那奧祕事，哲士、用法術的、術士、觀兆的都不能告訴王。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 40:8; 阿摩司書 4:13; 但以理書 10:14"> 只有一位在天上的神能顯明奧祕的事，他已將日後必有的事指示尼布甲尼撒王。你的夢和你在床上腦中的異象是這樣：</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:28; 阿摩司書 4:13; 但以理書 2:47"> 王啊，你在床上想到後來的事，那顯明奧祕事的主把將來必有的事指示你。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 41:16; 使徒行傳 3:12; 但以理書 2:17–18"> 至於那奧祕的事顯明給我，並非因我的智慧勝過一切活人，乃為使王知道夢的講解和心裡的思念。</span>
</div>
</div>

## 述王之夢

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷書 1:7; 以西結書 28:7; 但以理書 7:3–17"> 「王啊，你夢見一個大像，這像甚高，極其光耀，站在你面前，形狀甚是可怕。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 51:7; 但以理書 7:4–6; 啟示錄 17:4"> 這像的頭是精金的，胸膛和膀臂是銀的，肚腹和腰是銅的，</span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 7:19–26; 但以理書 7:7–8; 但以理書 2:40–43"> 腿是鐵的，腳是半鐵半泥的。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理書 2:44–45; 但以理書 8:25; 撒迦利亞書 12:3"> 你觀看，見有一塊非人手鑿出來的石頭打在這像半鐵半泥的腳上，把腳砸碎。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 2:2–3; 詩篇 37:10; 啟示錄 20:11"> 於是金、銀、銅、鐵、泥都一同砸得粉碎，成如夏天禾場上的糠秕，被風吹散，無處可尋。打碎這像的石頭變成一座大山，充滿天下。</span>
</div>
</div>

## 詳解夢兆

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理書 2:23–24"> 「這就是那夢，我們在王面前要講解那夢。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 26:7; 耶利米書 27:6–7; 以斯拉記 7:12"> 王啊，你是諸王之王，天上的神已將國度、權柄、能力、尊榮都賜給你。</span>
<span className="v" id="v38" data-v="38" data-xref="但以理書 4:21–22; 詩篇 50:10–11; 耶利米書 27:5–7"> 凡世人所住之地的走獸，並天空的飛鳥，他都交付你手，使你掌管這一切，你就是那金頭。</span>
<span className="v" id="v39" data-v="39" data-xref="但以理書 5:28–31; 以賽亞書 44:28–5; 但以理書 2:32"> 在你以後必另興一國，不及於你。又有第三國，就是銅的，必掌管天下。</span>
<span className="v" id="v40" data-v="40" data-xref="但以理書 7:7; 但以理書 7:19–26; 但以理書 11:36–45"> 第四國，必堅壯如鐵，鐵能打碎剋制百物，又能壓碎一切，那國也必打碎壓制列國。</span>
<span className="v" id="v41" data-v="41" data-xref="啟示錄 17:12; 但以理書 2:33–35; 啟示錄 12:3"> 你既見像的腳和腳指頭一半是窯匠的泥，一半是鐵，那國將來也必分開。你既見鐵與泥摻雜，那國也必有鐵的力量。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 7:24; 啟示錄 13:1"> 那腳指頭既是半鐵半泥，那國也必半強半弱。</span>
<span className="v" id="v43" data-v="43"> 你既見鐵與泥摻雜，那國民也必與各種人摻雜，卻不能彼此相合，正如鐵與泥不能相合一樣。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 28:18; 路加福音 1:32–33; 但以理書 6:26"> 當那列王在位的時候，天上的神必另立一國，永不敗壞，也不歸別國的人，卻要打碎滅絕那一切國，這國必存到永遠。</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 28:16; 創世記 41:32; 申命記 10:17"> 你既看見非人手鑿出來的一塊石頭從山而出，打碎金、銀、銅、鐵、泥，那就是至大的神把後來必有的事給王指明。這夢準是這樣，這講解也是確實的。」</span>
</div>
</div>

## 王尊崇但以理加以重賚

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 10:25; 使徒行傳 14:13; 以斯拉記 6:10"> 當時尼布甲尼撒王俯伏在地，向但以理下拜，並且吩咐人給他奉上供物和香品。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理書 2:22; 但以理書 2:28; 阿摩司書 3:7"> 王對但以理說：「你既能顯明這奧祕的事，你們的神誠然是萬神之神，萬王之主，又是顯明奧祕事的。」</span>
<span className="v" id="v48" data-v="48" data-xref="但以理書 2:6; 但以理書 4:9; 但以理書 5:11"> 於是王高抬但以理，賞賜他許多上等禮物，派他管理巴比倫全省，又立他為總理，掌管巴比倫的一切哲士。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理書 1:7; 以斯帖記 2:19; 但以理書 3:12–30"> 但以理求王，王就派沙得拉、米煞、亞伯尼歌管理巴比倫省的事務，只是但以理常在朝中侍立。</span>
</div>

## 命焚紅母牛為灰以潔不潔之民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 22:20–25; 申命記 21:3; 撒母耳記上 6:7"> 「耶和華命定律法中的一條律例乃是這樣說：你要吩咐以色列人，把一隻沒有殘疾、未曾負軛、純紅的母牛牽到你這裡來，</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 4:12; 利未記 4:21; 利未記 16:27"> 交給祭司以利亞撒。他必牽到營外，人就把牛宰在他面前。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 4:17; 利未記 4:6; 利未記 16:14"> 祭司以利亞撒要用指頭蘸這牛的血，向會幕前面彈七次。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 29:14; 利未記 4:11–12; 詩篇 22:14"> 人要在他眼前把這母牛焚燒，牛的皮、肉、血、糞都要焚燒。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 14:4; 利未記 14:49; 詩篇 51:7"> 祭司要把香柏木、牛膝草、朱紅色線都丟在燒牛的火中。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 11:25; 利未記 11:40; 民數記 19:8"> 祭司必不潔淨到晚上，要洗衣服，用水洗身，然後可以進營。</span>
<span className="v" id="v8" data-v="8"> 燒牛的人必不潔淨到晚上，也要洗衣服，用水洗身。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 9:13; 民數記 19:13; 民數記 19:20–21"> 必有一個潔淨的人收起母牛的灰，存在營外潔淨的地方，為以色列會眾調做除汙穢的水，這本是除罪的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 12:49; 民數記 19:7–8; 歌羅西書 3:11"> 收起母牛灰的人必不潔淨到晚上，要洗衣服。這要給以色列人和寄居在他們中間的外人作為永遠的定例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 5:2; 民數記 31:19; 利未記 21:1"> 「摸了人死屍的，就必七天不潔淨。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 31:19; 啟示錄 7:14; 利未記 7:17"> 那人到第三天要用這除汙穢的水潔淨自己，第七天就潔淨了。他若在第三天不潔淨自己，第七天就不潔淨了。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 15:31; 利未記 22:3; 利未記 7:20"> 凡摸了人死屍，不潔淨自己的，就玷汙了耶和華的帳幕，這人必從以色列中剪除。因為那除汙穢的水沒有灑在他身上，他就為不潔淨，汙穢還在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 「人死在帳篷裡的條例乃是這樣：凡進那帳篷的和一切在帳篷裡的，都必七天不潔淨。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 14:36; 利未記 11:32; 民數記 31:20"> 凡敞口的器皿，就是沒有紮上蓋的，也是不潔淨。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 31:19; 馬太福音 23:27; 路加福音 11:44"> 無論何人在田野裡摸了被刀殺的，或是屍首，或是人的骨頭，或是墳墓，就要七天不潔淨。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 7:38; 創世記 26:19; 啟示錄 7:17"> 要為這不潔淨的人拿些燒成的除罪灰放在器皿裡，倒上活水。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 36:25–27; 希伯來書 9:14; 民數記 19:9"> 必當有一個潔淨的人拿牛膝草蘸在這水中，把水灑在帳篷上，和一切器皿並帳篷內的眾人身上，又灑在摸了骨頭，或摸了被殺的，或摸了自死的，或摸了墳墓的那人身上。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 1:7; 希伯來書 10:22; 以西結書 36:25"> 第三天和第七天，潔淨的人要灑水在不潔淨的人身上，第七天就使他成為潔淨。那人要洗衣服，用水洗澡，到晚上就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 16:16; 創世記 17:14; 民數記 19:13"> 「但那汙穢而不潔淨自己的，要將他從會中剪除，因為他玷汙了耶和華的聖所。除汙穢的水沒有灑在他身上，他是不潔淨的。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 9:13–14; 希伯來書 10:4; 希伯來書 9:10"> 這要給你們作為永遠的定例。並且那灑除汙穢水的人要洗衣服，凡摸除汙穢水的，必不潔淨到晚上。</span>
<span className="v" id="v22" data-v="22" data-xref="哈該書 2:13; 利未記 7:19; 馬太福音 15:19–20"> 不潔淨人所摸的一切物就不潔淨，摸了這物的人必不潔淨到晚上。」</span>
</div>
</div>

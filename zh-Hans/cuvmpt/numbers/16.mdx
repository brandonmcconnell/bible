## 可拉黨叛亂

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="猶大書 1:11; 申命記 11:6; 出埃及記 6:21"> 利未的曾孫、哥轄的孫子、以斯哈的兒子可拉，和魯本子孫中以利押的兒子大坍、亞比蘭，與比勒的兒子安，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 26:9; 以西結書 23:10; 創世記 6:4"> 並以色列會中的二百五十個首領，就是有名望選入會中的人，在摩西面前一同起來，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 106:16; 民數記 14:14; 出埃及記 19:6"> 聚集攻擊摩西、亞倫，說：「你們擅自專權。全會眾個個既是聖潔，耶和華也在他們中間，你們為什麼自高，超過耶和華的會眾呢？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民數記 14:5; 民數記 20:6; 約書亞記 7:6"> 摩西聽見這話就俯伏在地，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 65:4; 民數記 17:5; 提摩太後書 2:19"> 對可拉和他一黨的人說：「到了早晨，耶和華必指示誰是屬他的，誰是聖潔的，就叫誰親近他。他所揀選的是誰，必叫誰親近他。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 10:1; 民數記 16:46–48; 列王紀上 18:21–23"> 可拉啊，你們要這樣行：你和你的一黨要拿香爐來，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 16:3; 以弗所書 1:4; 列王紀上 18:17–18"> 明日在耶和華面前，把火盛在爐中，把香放在其上。耶和華揀選誰，誰就為聖潔。你們這利未的子孫擅自專權了！」</span>
<span className="v" id="v8" data-v="8"> 摩西又對可拉說：「利未的子孫哪，你們聽我說。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 7:13; 申命記 10:8; 以西結書 44:10–11"> 以色列的神從以色列會中將你們分別出來，使你們親近他，辦耶和華帳幕的事，並站在會眾面前替他們當差。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 約翰三書 1:9; 民數記 18:7"> 耶和華又使你，和你一切弟兄利未的子孫，一同親近他，這豈為小事，你們還要求祭司的職任嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 16:7–8; 出埃及記 17:2; 民數記 16:3"> 你和你一黨的人聚集是要攻擊耶和華，亞倫算什麼，你們竟向他發怨言呢？」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 2:13–14; 猶大書 1:8; 箴言 29:9"> 摩西打發人去召以利押的兒子大坍、亞比蘭。他們說：「我們不上去。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:35; 出埃及記 2:14; 民數記 11:5"> 你將我們從流奶與蜜之地領上來，要在曠野殺我們，這豈為小事，你還要自立為王轄管我們嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:24; 民數記 36:8–10; 民數記 20:5"> 並且你沒有將我們領到流奶與蜜之地，也沒有把田地和葡萄園給我們為業。難道你要剜這些人的眼睛嗎？我們不上去。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 4:4–5; 哥林多後書 7:2; 帖撒羅尼迦前書 2:10"> 摩西就甚發怒，對耶和華說：「求你不要享受他們的供物。我並沒有奪過他們一匹驢，也沒有害過他們一個人。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 12:3; 撒母耳記上 12:7; 提摩太後書 2:14"> 摩西對可拉說：「明天你和你一黨的人，並亞倫，都要站在耶和華面前。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 12:7"> 各人要拿一個香爐，共二百五十個，把香放在上面，到耶和華面前。你和亞倫也各拿自己的香爐。」</span>
<span className="v" id="v18" data-v="18"> 於是他們各人拿一個香爐，盛上火，加上香，同摩西、亞倫站在會幕門前。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 14:10; 民數記 16:42; 出埃及記 16:7"> 可拉招聚全會眾到會幕門前，要攻擊摩西、亞倫。耶和華的榮光就向全會眾顯現。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:45; 出埃及記 32:10; 詩篇 73:19"> 「你們離開這會眾，我好在轉眼之間把他們滅絕。」</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 27:16; 撒迦利亞書 12:1; 約伯記 12:10"> 摩西、亞倫就俯伏在地，說：「神，萬人之靈的神啊！一人犯罪，你就要向全會眾發怒嗎？」</span>
<span className="v" id="v23" data-v="23"> 耶和華曉諭摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 16:21"> 「你吩咐會眾說：你們離開可拉、大坍、亞比蘭帳篷的四圍。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 11:16–17; 民數記 11:25; 民數記 11:30"> 摩西起來，往大坍、亞比蘭那裡去，以色列的長老也隨著他去。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 52:11; 哥林多後書 6:17; 啟示錄 18:4"> 他吩咐會眾說：「你們離開這惡人的帳篷吧，他們的物件，什麼都不可摸，恐怕你們陷在他們的罪中，與他們一同消滅。」</span>
<span className="v" id="v27" data-v="27" data-xref="約伯記 9:4; 以賽亞書 28:14; 約伯記 40:10–11"> 於是眾人離開可拉、大坍、亞比蘭帳篷的四圍。大坍、亞比蘭帶著妻子、兒女、小孩子，都出來，站在自己的帳篷門口。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:38; 出埃及記 3:12; 約翰福音 14:11"> 摩西說：「我行的這一切事本不是憑我自己心意行的，乃是耶和華打發我行的，必有證據使你們知道。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王紀上 22:28; 出埃及記 32:34"> 這些人死若與世人無異，或是他們所遭的與世人相同，就不是耶和華打發我來的。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 55:15; 民數記 16:33; 約伯記 31:3"> 倘若耶和華創作一件新事，使地開口，把他們和一切屬他們的都吞下去，叫他們活活地墜落陰間，你們就明白這些人是藐視耶和華了。」</span>
</div>
</div>

## 可拉黨受刑

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 106:17–18; 民數記 27:3; 申命記 11:6"> 摩西剛說完了這一切話，他們腳下的地就開了口，</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:17; 民數記 26:11; 啟示錄 12:16"> 把他們和他們的家眷，並一切屬可拉的人丁、財物，都吞下去。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 32:18; 以賽亞書 14:9; 詩篇 9:15"> 這樣，他們和一切屬他們的都活活地墜落陰間。地口在他們上頭照舊合閉，他們就從會中滅亡。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 14:5; 以賽亞書 33:3; 啟示錄 6:15–17"> 在他們四圍的以色列眾人聽他們呼號，就都逃跑，說：「恐怕地也把我們吞下去！」</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 26:10; 利未記 10:2; 詩篇 106:18"> 又有火從耶和華那裡出來，燒滅了那獻香的二百五十個人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 耶和華曉諭摩西說：</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 27:28; 民數記 16:18; 民數記 16:7"> 「你吩咐祭司亞倫的兒子以利亞撒從火中撿起那些香爐來，把火撒在別處，因為那些香爐是聖的。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 26:10; 以西結書 14:8; 彼得後書 2:6"> 把那些犯罪自害己命之人的香爐，叫人錘成片子，用以包壇。那些香爐本是他們在耶和華面前獻過的，所以是聖的，並且可以給以色列人做記號。」</span>
<span className="v" id="v39" data-v="39"> 於是祭司以利亞撒將被燒之人所獻的銅香爐拿來，人就錘出來，用以包壇，</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 3:10; 民數記 18:4–7; 歷代志下 26:16–21"> 給以色列人做紀念，使亞倫後裔之外的人不得近前來在耶和華面前燒香，免得他遭可拉和他一黨所遭的。這乃是照耶和華藉著摩西所吩咐的。</span>
</div>
</div>

## 民怨摩西亞倫致遘疫癘

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 16:1–7; 詩篇 106:23; 民數記 14:2"> 第二天，以色列全會眾都向摩西、亞倫發怨言說：「你們殺了耶和華的百姓了！」</span>
<span className="v" id="v42" data-v="42" data-xref="民數記 16:19; 利未記 9:23; 民數記 20:6"> 會眾聚集攻擊摩西、亞倫的時候，向會幕觀看，不料，有雲彩遮蓋了，耶和華的榮光顯現。</span>
<span className="v" id="v43" data-v="43"> 摩西、亞倫就來到會幕前。</span>
<span className="v" id="v44" data-v="44"> 耶和華吩咐摩西說：</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 16:21–22; 民數記 16:24; 民數記 20:6"> 「你們離開這會眾，我好在轉眼之間把他們滅絕。」他們二人就俯伏於地。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 8:19; 歷代志上 27:24; 利未記 10:6"> 摩西對亞倫說：「拿你的香爐，把壇上的火盛在其中，又加上香，快快帶到會眾那裡，為他們贖罪。因為有憤怒從耶和華那裡出來，瘟疫已經發作了。」</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 5:44; 申命記 33:10–11; 詩篇 106:29"> 亞倫照著摩西所說的拿來，跑到會中，不料，瘟疫在百姓中已經發作了。他就加上香，為百姓贖罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳記下 24:25; 希伯來書 7:24–25; 民數記 16:18"> 他站在活人死人中間，瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 25:9; 民數記 16:32–35; 希伯來書 2:1–3"> 除了因可拉事情死的以外，遭瘟疫死的，共有一萬四千七百人。</span>
<span className="v" id="v50" data-v="50" data-xref="歷代志上 21:26–30; 民數記 16:43"> 亞倫回到會幕門口，到摩西那裡，瘟疫已經止住了。</span>
</div>
</div>

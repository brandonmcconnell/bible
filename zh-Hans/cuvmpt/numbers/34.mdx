## 命定迦南地之境界

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:8; 詩篇 105:11; 申命記 1:7–8"> 「你吩咐以色列人說：你們到了迦南地，就是歸你們為業的迦南四境之地：</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:3; 以西結書 47:13; 約書亞記 3:16"> 南角要從尋的曠野，貼著以東的邊界。南界要從鹽海東頭起，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 32:8; 約書亞記 15:3–4; 民數記 13:26"> 繞到亞克拉濱坡的南邊，接連到尋，直通到加低斯巴尼亞的南邊，又通到哈薩亞達，接連到押們，</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 15:4; 創世記 15:18; 列王紀上 8:65"> 從押們轉到埃及小河，直通到海為止。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 1:4; 以西結書 47:20; 以西結書 47:15"> 「西邊要以大海為界。這就是你們的西界。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民數記 33:37; 民數記 34:6; 民數記 34:3"> 「北界要從大海起，劃到何珥山，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 13:21; 列王紀下 14:25; 約書亞記 13:5–6"> 從何珥山劃到哈馬口，通到西達達，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 47:17"> 又通到西斐崙，直到哈薩以難。這要做你們的北界。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 「你們要從哈薩以難劃到示番為東界。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:33; 申命記 3:17; 約書亞記 11:2"> 這界要從示番下到亞延東邊的利比拉，又要達到基尼烈湖的東邊。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 34:3; 創世記 13:10; 創世記 19:24–26"> 這界要下到約旦河，通到鹽海為止。這四圍的邊界以內，要做你們的地。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 34:1; 約書亞記 14:1–5"> 摩西吩咐以色列人說：「這地就是耶和華吩咐拈鬮給九個半支派承受為業的。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 32:33; 民數記 32:23; 約書亞記 14:2–3"> 因為魯本支派和迦得支派按著宗族受了產業，瑪拿西半個支派也受了產業。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 32:32"> 這兩個半支派已經在耶利哥對面，約旦河東，向日出之地受了產業。」</span>
</div>
</div>

## 揀選分地之人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華曉諭摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 14:1; 約書亞記 19:51; 民數記 13:8"> 「要給你們分地為業之人的名字是祭司以利亞撒和嫩的兒子約書亞。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 1:4–16"> 又要從每支派中選一個首領幫助他們。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 26:65; 民數記 13:30; 民數記 14:24"> 這些人的名字：猶大支派有耶孚尼的兒子迦勒；</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 49:5"> 西緬支派有亞米忽的兒子示母利；</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 49:27; 詩篇 68:27"> 便雅憫支派有基斯倫的兒子以利達；</span>
<span className="v" id="v22" data-v="22"> 但支派有一個首領，約利的兒子布基；</span>
<span className="v" id="v23" data-v="23"> 約瑟的子孫瑪拿西支派有一個首領，以弗的兒子漢聶；</span>
<span className="v" id="v24" data-v="24"> 以法蓮支派有一個首領，拾弗但的兒子基母利；</span>
<span className="v" id="v25" data-v="25"> 西布倫支派有一個首領，帕納的兒子以利撒番；</span>
<span className="v" id="v26" data-v="26"> 以薩迦支派有一個首領，阿散的兒子帕鐵；</span>
<span className="v" id="v27" data-v="27"> 亞設支派有一個首領，示羅米的兒子亞希忽；</span>
<span className="v" id="v28" data-v="28"> 拿弗他利支派有一個首領，亞米忽的兒子比大黑。」</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:51; 民數記 34:18"> 這些人就是耶和華所吩咐，在迦南地把產業分給以色列人的。</span>
</div>
</div>

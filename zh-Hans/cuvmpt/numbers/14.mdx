## 以色列眾向摩西亞倫發怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 1:45; 民數記 11:1–4"> 當下全會眾大聲喧嚷，那夜百姓都哭號。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 15:24; 出埃及記 17:3; 民數記 16:41"> 以色列眾人向摩西、亞倫發怨言，全會眾對他們說：「巴不得我們早死在埃及地，或是死在這曠野！</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 14:31–32; 耶利米書 9:3; 詩篇 78:40"> 耶和華為什麼把我們領到那地，使我們倒在刀下呢？我們的妻子和孩子必被擄掠。我們回埃及去豈不好嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 7:39; 尼希米記 9:16–17; 申命記 17:16"> 眾人彼此說：「我們不如立一個首領回埃及去吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 16:4; 民數記 16:22; 民數記 16:45"> 摩西、亞倫就俯伏在以色列全會眾面前。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:30; 民數記 13:30; 民數記 14:38"> 窺探地的人中，嫩的兒子約書亞和耶孚尼的兒子迦勒撕裂衣服，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:27; 申命記 1:25; 申命記 8:7–9"> 對以色列全會眾說：「我們所窺探經過之地是極美之地。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 22:20; 以賽亞書 62:4; 民數記 13:27"> 耶和華若喜悅我們，就必將我們領進那地，把地賜給我們，那地原是流奶與蜜之地。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:18; 羅馬書 8:31; 申命記 31:6"> 但你們不可背叛耶和華，也不要怕那地的居民，因為他們是我們的食物，並且蔭庇他們的已經離開他們。有耶和華與我們同在，不要怕他們。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 17:4; 撒母耳記上 30:6; 利未記 9:23"> 但全會眾說拿石頭打死他們二人。忽然，耶和華的榮光在會幕中向以色列眾人顯現。</span>
</div>
</div>

## 耶和華怒民違逆欲殲滅之

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:32; 詩篇 106:24; 詩篇 78:22"> 耶和華對摩西說：「這百姓藐視我要到幾時呢？我在他們中間行了這一切神蹟，他們還不信我要到幾時呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 32:10; 民數記 25:9; 撒母耳記下 24:12–15"> 我要用瘟疫擊殺他們，使他們不得承受那地，叫你的後裔成為大國，比他們強盛。」</span>
</div>
</div>

## 摩西為民求赦

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:23; 以西結書 20:9; 申命記 32:27"> 摩西對耶和華說：「埃及人必聽見這事，因為你曾施展大能，將這百姓從他們中間領上來。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 15:14; 出埃及記 33:11; 申命記 5:4"> 埃及人要將這事傳給迦南地的居民。那民已經聽見你耶和華是在這百姓中間，因為你面對面被人看見，有你的雲彩停在他們以上，你日間在雲柱中，夜間在火柱中，在他們前面行。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 6:16"> 如今你若把這百姓殺了，如殺一人，那些聽見你名聲的列邦必議論說：</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 9:28; 約書亞記 7:9; 約書亞記 7:7"> 『耶和華因為不能把這百姓領進他向他們起誓應許之地，所以在曠野把他們殺了。』</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 9:6; 馬太福音 9:8; 彌迦書 3:8"> 現在求主大顯能力，照你所說過的話說：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:6–7; 詩篇 145:8; 出埃及記 20:5"> 『耶和華不輕易發怒，並有豐盛的慈愛，赦免罪孽和過犯，萬不以有罪的為無罪，必追討他的罪，自父及子，直到三四代。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 34:9; 詩篇 78:38; 詩篇 106:45"> 求你照你的大慈愛赦免這百姓的罪孽，好像你從埃及到如今常赦免他們一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="彌迦書 7:18–20; 雅各書 5:16; 詩篇 106:23"> 耶和華說：「我照著你的話赦免了他們。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 72:19; 哈巴谷書 2:14; 以賽亞書 6:3"> 然我指著我的永生起誓：遍地要被我的榮耀充滿！</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 19:3; 創世記 31:7; 出埃及記 32:1"> 這些人雖看見我的榮耀和我在埃及與曠野所行的神蹟，仍然試探我這十次，不聽從我的話，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 32:11; 民數記 26:64; 以西結書 20:15"> 他們斷不得看見我向他們的祖宗所起誓應許之地。凡藐視我的，一個也不得看見。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 14:6–9; 約書亞記 14:6–14; 以弗所書 6:6"> 唯獨我的僕人迦勒，因他另有一個心志，專一跟從我，我就把他領進他所去過的那地。他的後裔也必得那地為業。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:40; 民數記 13:29; 詩篇 81:11–13"> 亞瑪力人和迦南人住在谷中，明天你們要轉回，從紅海的路往曠野去。」</span>
</div>
</div>

## 以色列眾發怨言者必死於野

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華對摩西、亞倫說：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 16:12; 哥林多前書 10:10; 出埃及記 16:28"> 「這惡會眾向我發怨言，我忍耐他們要到幾時呢？以色列人向我所發的怨言，我都聽見了。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 14:21; 希伯來書 3:17; 民數記 14:2"> 你們告訴他們：『耶和華說：我指著我的永生起誓：我必要照你們達到我耳中的話待你們。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:45; 哥林多前書 10:5; 希伯來書 3:17"> 你們的屍首必倒在這曠野，並且你們中間凡被數點，從二十歲以外，向我發怨言的，</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 26:65; 民數記 14:38; 申命記 1:36–38"> 必不得進我起誓應許叫你們住的那地。唯有耶孚尼的兒子迦勒和嫩的兒子約書亞才能進去。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:39; 詩篇 106:24; 民數記 26:64"> 但你們的婦人孩子，就是你們所說要被擄掠的，我必把他們領進去，他們就得知你們所厭棄的那地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 10:5; 民數記 14:29; 希伯來書 3:17"> 至於你們，你們的屍首必倒在這曠野。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 23:35; 民數記 32:13; 申命記 2:14"> 你們的兒女必在曠野漂流四十年，擔當你們淫行的罪，直到你們的屍首在曠野消滅。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 4:6; 民數記 13:25; 耶利米書 18:9–10"> 按你們窺探那地的四十日，一年頂一日，你們要擔當罪孽四十年，就知道我與你們疏遠了。』</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 23:19; 哥林多前書 10:5; 希伯來書 3:19"> 我耶和華說過，我總要這樣待這一切聚集敵我的惡會眾。他們必在這曠野消滅，在這裡死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民數記 13:31–33; 民數記 13:4–16"> 摩西所打發窺探那地的人回來，報那地的惡信，叫全會眾向摩西發怨言，</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 10:10; 民數記 16:49; 希伯來書 3:17"> 這些報惡信的人都遭瘟疫，死在耶和華面前。</span>
<span className="v" id="v38" data-v="38" data-xref="約書亞記 14:6–10; 民數記 26:65"> 其中唯有嫩的兒子約書亞和耶孚尼的兒子迦勒仍然存活。</span>
</div>
</div>

## 民至何珥瑪為敵所敗

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 33:4; 馬太福音 8:12; 希伯來書 12:17"> 摩西將這些話告訴以色列眾人，他們就甚悲哀。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 1:41; 馬太福音 7:21–23; 路加福音 13:25"> 清早起來，上山頂去，說：「我們在這裡，我們有罪了。情願上耶和華所應許的地方去！」</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志下 24:20; 約伯記 4:9; 耶利米書 2:37"> 摩西說：「你們為何違背耶和華的命令呢？這事不能順利了！</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 1:42; 約書亞記 7:8; 約書亞記 7:12"> 不要上去，因為耶和華不在你們中間，恐怕你們被仇敵殺敗了。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 13:29; 民數記 14:25; 歷代志下 15:2"> 亞瑪力人和迦南人都在你們面前，你們必倒在刀下。因你們退回不跟從耶和華，所以他必不與你們同在。」</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 1:43; 撒母耳記上 4:3–11; 民數記 31:6"> 他們卻擅敢上山頂去，然而耶和華的約櫃和摩西沒有出營。</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 21:3; 士師記 1:17; 申命記 1:44"> 於是亞瑪力人和住在那山上的迦南人都下來擊打他們，把他們殺退了，直到何珥瑪。</span>
</div>
</div>

<span className="v" id="v2" data-v="2" data-xref="士師記 11:30; 創世記 28:20; 撒母耳記上 1:11"> 以色列人向耶和華發願說：「你若將這民交付我手，我就把他們的城邑盡行毀滅。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 14:45; 申命記 1:44; 詩篇 10:17"> 耶和華應允了以色列人，把迦南人交付他們，他們就把迦南人和迦南人的城邑盡行毀滅。那地方的名便叫何珥瑪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「何珥瑪」就是「毀滅」的意思。">a</a></sup>。</span>

## 火蛇與銅蛇

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 6:9; 士師記 11:18; 民數記 32:7"> 他們從何珥山起行，往紅海那條路走，要繞過以東地。百姓因這路難行，心中甚是煩躁，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 78:19; 民數記 16:13–14; 出埃及記 17:2–3"> 就怨讟神和摩西說：「你們為什麼把我們從埃及領出來，使我們死在曠野呢？這裡沒有糧，沒有水，我們的心厭惡這淡薄的食物！」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:9; 耶利米書 8:17; 申命記 8:15"> 於是耶和華使火蛇進入百姓中間，蛇就咬他們，以色列人中死了許多。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 8:24; 民數記 11:2; 詩篇 78:34"> 百姓到摩西那裡，說：「我們怨讟耶和華和你，有罪了。求你禱告耶和華，叫這些蛇離開我們。」於是摩西為百姓禱告。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:14; 詩篇 106:43–45; 詩篇 145:8"> 耶和華對摩西說：「你製造一條火蛇，掛在杆子上。凡被咬的，一望這蛇，就必得活。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:14–15; 希伯來書 12:2; 約翰福音 6:40"> 摩西便製造一條銅蛇，掛在杆子上。凡被蛇咬的，一望這銅蛇就活了。</span>
</div>
</div>

## 民由阿伯起行至毗斯迦山

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="民數記 33:43–45"> 以色列人起行，安營在阿伯。</span>
<span className="v" id="v11" data-v="11"> 又從阿伯起行，安營在以耶亞巴琳，與摩押相對的曠野，向日出之地。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:13–14"> 從那裡起行，安營在撒烈谷。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 11:18; 民數記 22:36; 以賽亞書 16:2"> 從那裡起行，安營在亞嫩河那邊。這亞嫩河是在曠野，從亞摩利的境界流出來的。原來亞嫩河是摩押的邊界，在摩押和亞摩利人搭界的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 10:13; 撒母耳記下 1:18"> 所以《耶和華的戰記》上說：「蘇法的哇哈伯與亞嫩河的谷，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 21:28; 申命記 2:18; 申命記 2:9"> 並向亞珥城眾谷的下坡，是靠近摩押的境界。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 20:8; 以賽亞書 12:3; 以賽亞書 41:17–18"> 以色列人從那裡起行，到了比珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「比珥」就是「井」的意思。">b</a></sup>。從前耶和華吩咐摩西說：「招聚百姓，我好給他們水喝」，說的就是這井。</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 5:13; 出埃及記 15:1–2; 詩篇 106:12"> 當時，以色列人唱歌說：<br /><span className="pl pl-1">「井啊，湧上水來！</span><br /><span className="pl pl-1">你們要向這井歌唱。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 33:22; 提摩太前書 6:17–18; 雅各書 4:12"> <span className="pl pl-1">這井是首領和民中的尊貴人</span><br /><span className="pl pl-1">用圭用杖所挖所掘的。」</span><br />以色列人從曠野往瑪他拿去，</span>
<span className="v" id="v19" data-v="19"> 從瑪他拿到拿哈列，從拿哈列到巴末，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 23:28; 民數記 23:14; 申命記 1:5"> 從巴末到摩押地的谷，又到那下望曠野之毗斯迦的山頂。</span>
</div>
</div>

## 擊敗亞摩利巴珊二王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命記 2:26–28; 民數記 20:14–19; 士師記 11:19–21"> 以色列人差遣使者去見亞摩利人的王西宏，說：</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 20:17"> 「求你容我們從你的地經過。我們不偏入田間和葡萄園，也不喝井裡的水，只走大道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：王道。">c</a></sup>，直到過了你的境界。」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 11:20; 申命記 29:7–8; 以賽亞書 15:4"> 西宏不容以色列人從他的境界經過，就招聚他的眾民出到曠野，要攻擊以色列人，到了雅雜與以色列人爭戰。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 2:9; 約書亞記 24:8; 創世記 32:22"> 以色列人用刀殺了他，得了他的地，從亞嫩河到雅博河，直到亞捫人的境界，因為亞捫人的境界多有堅壘。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 32:33–42; 以賽亞書 16:8–9; 耶利米書 48:2"> 以色列人奪取這一切的城邑，也住亞摩利人的城邑，就是希實本與希實本的一切鄉村。</span>
<span className="v" id="v26" data-v="26"> 這希實本是亞摩利王西宏的京城，西宏曾與摩押的先王爭戰，從他手中奪取了全地，直到亞嫩河。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 14:4; 民數記 21:14; 哈巴谷書 2:6"> 所以那些作詩歌的說：<br /><span className="pl pl-1">「你們來到希實本，</span><br /><span className="pl pl-1">願西宏的城被修造，被建立！</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民數記 21:15; 耶利米書 48:45–46; 以賽亞書 15:1–2"> <span className="pl pl-1">因為有火從希實本發出，</span><br /><span className="pl pl-1">有火焰出於西宏的城，</span><br /><span className="pl pl-1">燒盡摩押的亞珥和亞嫩河丘壇的祭司</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「祭司」原文作「主」。">d</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="士師記 11:24; 列王紀下 23:13; 耶利米書 48:46"> <span className="pl pl-1">摩押啊，你有禍了！</span><br /><span className="pl pl-1">基抹的民哪，你們滅亡了！</span><br /><span className="pl pl-1">基抹的男子逃奔，女子被擄，</span><br /><span className="pl pl-1">交付亞摩利的王西宏。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 48:18; 以賽亞書 15:2; 耶利米書 48:22"> <span className="pl pl-1">我們射了他們，</span><br /><span className="pl pl-1">希實本直到底本盡皆毀滅。</span><br /><span className="pl pl-1">我們使地變成荒場，直到挪法。</span><br /><span className="pl pl-1">這挪法直延到米底巴。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 13:8–12; 民數記 32:33–42; 申命記 3:16–17"> 這樣，以色列人就住在亞摩利人之地。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 48:32; 民數記 32:1; 民數記 32:35"> 摩西打發人去窺探雅謝，以色列人就占了雅謝的鎮市，趕出那裡的亞摩利人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 13:12; 申命記 1:4; 申命記 29:7"> 以色列人轉回，向巴珊去。巴珊王噩和他的眾民都出來，在以得來與他們交戰。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 135:10–11; 約書亞記 8:7; 申命記 3:2–3"> 耶和華對摩西說：「不要怕他。因我已將他和他的眾民，並他的地，都交在你手中。你要待他像從前待住希實本的亞摩利王西宏一般。」</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 29:7–8; 約書亞記 13:12; 申命記 3:3–17"> 於是他們殺了他和他的眾子，並他的眾民，沒有留下一個，就得了他的地。</span>
</div>
</div>

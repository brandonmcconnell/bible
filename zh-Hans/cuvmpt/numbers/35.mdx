## 命以色列人以邑予利未人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 22:1; 民數記 31:12; 民數記 33:50"> 耶和華在摩押平原約旦河邊，耶利哥對面，曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 14:3–4; 以西結書 48:8; 約書亞記 21:2–42"> 「你吩咐以色列人，要從所得為業的地中把些城給利未人居住，也要把這城四圍的郊野給利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:14; 約書亞記 21:11; 以西結書 45:2"> 這城邑要歸他們居住，城邑的郊野可以牧養他們的牛羊和各樣的牲畜，又可以安置他們的財物。</span>
<span className="v" id="v4" data-v="4"> 你們給利未人的郊野，要從城根起，四圍往外量一千肘。</span>
<span className="v" id="v5" data-v="5"> 另外東量二千肘、南量二千肘、西量二千肘、北量二千肘為邊界，城在當中。這要歸他們做城邑的郊野。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 21:13; 約書亞記 21:3; 詩篇 9:9"> 你們給利未人的城邑，其中當有六座逃城，使誤殺人的可以逃到那裡，此外還要給他們四十二座城。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:3–42; 歷代志上 6:54–81"> 你們要給利未人的城，共有四十八座，連城帶郊野都要給他們。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 26:54; 民數記 33:54; 約書亞記 21:1–42"> 以色列人所得的地業從中要把些城邑給利未人。人多的就多給，人少的就少給。各支派要按所承受為業之地把城邑給利未人。」</span>
</div>
</div>

## 簡邑為逃城

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華曉諭摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 12:9; 申命記 19:1–2; 利未記 14:34"> 「你吩咐以色列人說：你們過約旦河，進了迦南地，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 21:13; 約書亞記 20:2; 民數記 35:6"> 就要分出幾座城，為你們做逃城，使誤殺人的可以逃到那裡。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 20:3–6; 申命記 19:6; 約書亞記 20:9"> 這些城可以做逃避報仇人的城，使誤殺人的不至於死，等他站在會眾面前聽審判。</span>
<span className="v" id="v13" data-v="13"> 你們所分出來的城，要做六座逃城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 19:8–10; 申命記 4:41–43; 約書亞記 20:7–9"> 在約旦河東要分出三座城，在迦南地也要分出三座城，都做逃城。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 15:16; 加拉太書 3:28; 羅馬書 3:29"> 這六座城要給以色列人和他們中間的外人，並寄居的，作為逃城，使誤殺人的都可以逃到那裡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 24:17; 創世記 9:5–6; 申命記 19:11–13"> 「倘若人用鐵器打人，以致打死，他就是故殺人的，故殺人的必被治死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 21:18"> 若用可以打死人的石頭打死了人，他就是故殺人的，故殺人的必被治死。</span>
<span className="v" id="v18" data-v="18"> 若用可以打死人的木器打死了人，他就是故殺人的，故殺人的必被治死。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 20:3; 申命記 19:6; 申命記 19:12"> 報血仇的必親自殺那故殺人的，一遇見就殺他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 21:14; 申命記 19:11; 撒母耳記下 3:27"> 人若因怨恨把人推倒，或是埋伏往人身上扔物，以至於死，</span>
<span className="v" id="v21" data-v="21"> 或是因仇恨用手打人，以至於死，那打人的必被治死。他是故殺人的，報血仇的一遇見就殺他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 35:11; 出埃及記 21:13; 約書亞記 20:3"> 「倘若人沒有仇恨，忽然將人推倒，或是沒有埋伏把物扔在人身上，</span>
<span className="v" id="v23" data-v="23"> 或是沒有看見的時候用可以打死人的石頭扔在人身上，以至於死，本來與他無仇，也無意害他，</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 20:6; 民數記 35:12"> 會眾就要照典章，在打死人的和報血仇的中間審判。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 29:7; 利未記 4:3; 羅馬書 3:24–26"> 會眾要救這誤殺人的脫離報血仇人的手，也要使他歸入逃城。他要住在其中，直等到受聖膏的大祭司死了。</span>
<span className="v" id="v26" data-v="26"> 但誤殺人的，無論什麼時候，若出了逃城的境外，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 22:2; 申命記 19:10; 申命記 19:6"> 報血仇的在逃城境外遇見他，將他殺了，報血仇的就沒有流血之罪。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 3:14; 希伯來書 10:26–30; 希伯來書 6:4–8"> 因為誤殺人的該住在逃城裡，等到大祭司死了。大祭司死了以後，誤殺人的才可以回到他所得為業之地。</span>
</div>
</div>

## 故殺之例

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 27:11; 民數記 27:1"> 「這在你們一切的住處，要做你們世世代代的律例、典章。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 10:28; 申命記 19:15; 馬太福音 18:16"> 無論誰故殺人，要憑幾個見證人的口把那故殺人的殺了，只是不可憑一個見證的口叫人死。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 19:11–13; 創世記 9:5–6; 詩篇 51:14"> 故殺人，犯死罪的，你們不可收贖價代替他的命，他必被治死。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 4:12; 加拉太書 3:10–13; 加拉太書 2:21"> 那逃到逃城的人，你們不可為他收贖價，使他在大祭司未死以先再來住在本地。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 詩篇 106:38; 何西阿書 4:2–3"> 這樣，你們就不汙穢所住之地，因為血是汙穢地的。若有在地上流人血的，非流那殺人者的血，那地就不得潔淨<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「潔淨」原文作「贖」。">a</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 5:3; 詩篇 135:21; 啟示錄 21:27"> 你們不可玷汙所住之地，就是我住在其中之地，因為我耶和華住在以色列人中間。」</span>
</div>
</div>

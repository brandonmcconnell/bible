## 魯本迦得二支派求業於約旦河東

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:32; 民數記 32:3; 創世記 13:10–11"> 魯本子孫和迦得子孫的牲畜極其眾多。他們看見雅謝地和基列地是可牧放牲畜之地，</span>
<span className="v" id="v2" data-v="2"> 就來見摩西和祭司以利亞撒並會眾的首領，說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 48:34; 以賽亞書 16:8–9; 民數記 32:34–38"> 「亞他錄、底本、雅謝、寧拉、希實本、以利亞利、示班、尼波、比穩，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 21:34; 申命記 2:24–35; 民數記 21:24"> 就是耶和華在以色列會眾前面所攻取之地，是可牧放牲畜之地，你僕人也有牲畜。」</span>
<span className="v" id="v5" data-v="5" data-xref="路得記 2:10; 約書亞記 7:7; 耶利米書 31:2"> 又說：「我們若在你眼前蒙恩，求你把這地給我們為業，不要領我們過約旦河。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 13:5; 撒母耳記下 11:11; 腓立比書 2:4"> 摩西對迦得子孫和魯本子孫說：「難道你們的弟兄去打仗，你們竟坐在這裡嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:27–4; 民數記 32:9; 申命記 1:28"> 你們為何使以色列人灰心喪膽，不過去進入耶和華所賜給他們的那地呢？</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 1:19–25; 民數記 14:2; 民數記 13:2–26"> 我先前從加低斯巴尼亞打發你們先祖去窺探那地，他們也是這樣行。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 13:23–10; 申命記 1:24–28"> 他們上以實各谷，去窺探那地回來的時候，使以色列人灰心喪膽，不進入耶和華所賜給他們的地。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:11; 詩篇 95:11; 以西結書 20:15"> 當日，耶和華的怒氣發作，就起誓說：</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 14:28–30; 民數記 14:24; 民數記 26:2"> 『凡從埃及上來，二十歲以外的人斷不得看見我對亞伯拉罕、以撒、雅各起誓應許之地，因為他們沒有專心跟從我。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 1:36; 民數記 14:30; 民數記 14:24"> 唯有基尼洗族耶孚尼的兒子迦勒和嫩的兒子約書亞可以看見，因為他們專心跟從我。』</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:5; 民數記 14:33–35; 希伯來書 3:16–19"> 耶和華的怒氣向以色列人發作，使他們在曠野漂流四十年，等到在耶和華眼前行惡的那一代人都消滅了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 詩篇 78:57; 馬太福音 23:31–33"> 誰知，你們起來接續先祖，增添罪人的數目，使耶和華向以色列大發烈怒。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:11–12; 歷代志下 15:2; 歷代志下 7:19–22"> 你們若退後不跟從他，他還要把以色列人撇在曠野，便是你們使這眾民滅亡。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 33:17; 民數記 34:22"> 兩支派的人挨近摩西，說：「我們要在這裡為牲畜壘圈，為婦人孩子造城。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 4:12–13; 民數記 32:29–32; 申命記 3:18–20"> 我們自己要帶兵器行在以色列人的前頭，好把他們領到他們的地方。但我們的婦人孩子，因這地居民的緣故，要住在堅固的城內。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 22:1–5"> 我們不回家，直等到以色列人各承受自己的產業。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 13:8; 約書亞記 12:1–6; 民數記 34:15"> 我們不和他們在約旦河那邊一帶之地同受產業，因為我們的產業是坐落在約旦河東邊這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約書亞記 4:12–13; 申命記 3:18–20; 約書亞記 1:13–15"> 摩西對他們說：「你們若這樣行，在耶和華面前帶著兵器出去打仗，</span>
<span className="v" id="v21" data-v="21"> 所有帶兵器的人都要在耶和華面前過約旦河，等他趕出他的仇敵，</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 22:9; 約書亞記 22:4; 申命記 3:20"> 那地被耶和華制伏了，然後你們可以回來，向耶和華和以色列才為無罪，這地也必在耶和華面前歸你們為業。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 59:12; 箴言 13:21; 創世記 44:16"> 倘若你們不這樣行，就得罪耶和華，要知道你們的罪必追上你們。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 32:16; 民數記 30:2; 民數記 32:34–42"> 如今你們口中所出的，只管去行，為你們的婦人孩子造城，為你們的羊群壘圈。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 1:13–14"> 迦得子孫和魯本子孫對摩西說：「僕人要照我主所吩咐的去行。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 1:14"> 我們的妻子、孩子、羊群和所有的牲畜都要留在基列的各城。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 4:12; 民數記 32:17; 民數記 12:11"> 但你的僕人，凡帶兵器的，都要照我主所說的話，在耶和華面前過去打仗。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 1:13"> 於是，摩西為他們囑咐祭司以利亞撒和嫩的兒子約書亞並以色列眾支派的族長，說：</span>
<span className="v" id="v29" data-v="29"> 「迦得子孫和魯本子孫，凡帶兵器在耶和華面前去打仗的，若與你們一同過約旦河，那地被你們制伏了，你們就要把基列地給他們為業。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 22:19"> 倘若他們不帶兵器和你們一同過去，就要在迦南地你們中間得產業。」</span>
<span className="v" id="v31" data-v="31"> 迦得子孫和魯本子孫回答說：「耶和華怎樣吩咐僕人，僕人就怎樣行。</span>
<span className="v" id="v32" data-v="32"> 我們要帶兵器，在耶和華面前過去，進入迦南地，只是約旦河這邊，我們所得為業之地仍歸我們。」</span>
</div>
</div>

## 以約旦河東地給魯本迦得二支派及瑪拿西支派之半

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 12:6; 申命記 29:8; 申命記 3:12–17"> 摩西將亞摩利王西宏的國和巴珊王噩的國，連那地和周圍的城邑，都給了迦得子孫和魯本子孫，並約瑟的兒子瑪拿西半個支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 2:36; 民數記 32:3; 以賽亞書 17:2"> 迦得子孫建造底本、亞他錄、亞羅珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 32:1; 民數記 32:3"> 亞他錄朔反、雅謝、約比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 32:3"> 伯寧拉、伯哈蘭，都是堅固城，他們又壘羊圈。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:27; 民數記 32:3; 以賽亞書 15:4"> 魯本子孫建造希實本、以利亞利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 46:1; 民數記 32:3; 約書亞記 23:7"> 尼波、巴力免、西比瑪（尼波、巴力免，名字是改了的），又給他們所建造的城另起別名。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 50:23; 約書亞記 17:1; 民數記 26:29"> 瑪拿西的兒子瑪吉，他的子孫往基列去，占了那地，趕出那裡的亞摩利人。</span>
<span className="v" id="v40" data-v="40" data-xref="約書亞記 17:1; 約書亞記 13:29–31; 申命記 3:13–15"> 摩西將基列賜給瑪拿西的兒子瑪吉，他子孫就住在那裡。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 3:14; 士師記 10:4; 約書亞記 13:30"> 瑪拿西的子孫睚珥去占了基列的村莊，就稱這些村莊為哈倭特睚珥。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 49:11; 撒母耳記下 18:18"> 挪巴去占了基納和基納的鄉村，就按自己的名稱基納為挪巴。</span>
</div>
</div>

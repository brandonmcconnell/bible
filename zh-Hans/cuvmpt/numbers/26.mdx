## 核民數

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 25:9"> 瘟疫之後，耶和華曉諭摩西和祭司亞倫的兒子以利亞撒說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 38:25–26; 民數記 1:2–3; 出埃及記 30:11–16"> 「你們要將以色列全會眾，按他們的宗族，凡以色列中從二十歲以外，能出去打仗的，計算總數。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 22:1; 民數記 33:48; 民數記 35:1"> 摩西和祭司以利亞撒在摩押平原與耶利哥相對的約旦河邊向以色列人說：</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 1:1; 歷代志上 21:1"> 「將你們中間從二十歲以外的計算總數，是照耶和華吩咐出埃及地的摩西和以色列人的話。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 5:3; 創世記 46:8–9; 出埃及記 6:14"> 以色列的長子是魯本。魯本的眾子，屬哈諾的，有哈諾族；屬法路的，有法路族；</span>
<span className="v" id="v6" data-v="6"> 屬希斯崙的，有希斯崙族；屬迦米的，有迦米族。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:9; 民數記 26:21; 民數記 2:11"> 這就是魯本的各族。其中被數的，共有四萬三千七百三十名。</span>
<span className="v" id="v8" data-v="8"> 法路的兒子是以利押。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 1:16; 民數記 16:1–35; 詩篇 106:17"> 以利押的眾子是尼母利、大坍、亞比蘭。這大坍、亞比蘭，就是從會中選召的，與可拉一黨同向耶和華爭鬧的時候也向摩西、亞倫爭鬧。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 16:38; 彼得後書 2:6; 民數記 16:31–35"> 地便開口吞了他們，和可拉、可拉的黨類一同死亡。那時火燒滅了二百五十個人，他們就做了警戒。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 6:24; 詩篇 42:1; 民數記 16:33"> 然而可拉的眾子沒有死亡。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 4:24; 創世記 46:10; 出埃及記 6:15"> 按著家族，西緬的眾子，屬尼母利的，有尼母利族；屬雅憫的，有雅憫族；屬雅斤的，有雅斤族；</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 46:10"> 屬謝拉的，有謝拉族；屬掃羅的，有掃羅族。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:22–23; 民數記 2:12–13"> 這就是西緬的各族，共有二萬二千二百名。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 46:16; 民數記 2:14"> 按著家族，迦得的眾子，屬洗分的，有洗分族；屬哈基的，有哈基族；屬書尼的，有書尼族；</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 46:16"> 屬阿斯尼的，有阿斯尼族；屬以利的，有以利族；</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:16"> 屬亞律的，有亞律族；屬亞列利的，有亞列利族。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 1:24–25; 民數記 2:14–15"> 這就是迦得子孫的各族，照他們中間被數的，共有四萬零五百名。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 46:12; 創世記 38:1–10; 歷代志上 2:3–8"> 猶大的兒子是珥和俄南。這珥和俄南死在迦南地。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 11:24; 創世記 46:12; 路加福音 3:33"> 按著家族，猶大其餘的眾子，屬示拉的，有示拉族；屬法勒斯的，有法勒斯族；屬謝拉的，有謝拉族。</span>
<span className="v" id="v21" data-v="21"> 法勒斯的兒子，屬希斯崙的，有希斯崙族；屬哈母勒的，有哈母勒族。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 1:26–27; 民數記 2:3–4; 創世記 49:8"> 這就是猶大的各族，照他們中間被數的，共有七萬六千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 46:13; 歷代志上 7:1; 創世記 30:17–18"> 按著家族，以薩迦的眾子，屬陀拉的，有陀拉族；屬普瓦的，有普瓦族；</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 46:13"> 屬雅述的，有雅述族；屬伸崙的，有伸崙族。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 2:5–6; 民數記 1:28–29"> 這就是以薩迦的各族，照他們中間被數的，共有六萬四千三百名。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 46:14; 創世記 30:19–20"> 按著家族，西布倫的眾子，屬西烈的，有西烈族；屬以倫的，有以倫族；屬雅利的，有雅利族。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:30–31; 民數記 2:7–8"> 這就是西布倫的各族，照他們中間被數的，共有六萬零五百名。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:20; 創世記 48:5; 創世記 41:51–52"> 按著家族，約瑟的兒子有瑪拿西、以法蓮。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 17:1; 民數記 36:1; 歷代志上 7:14–19"> 瑪拿西的眾子，屬瑪吉的，有瑪吉族。瑪吉生基列，屬基列的，有基列族。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 6:11; 士師記 6:34; 士師記 6:24"> 基列的眾子，屬伊以謝的，有伊以謝族；屬希勒的，有希勒族；</span>
<span className="v" id="v31" data-v="31"> 屬亞斯列的，有亞斯列族；屬示劍的，有示劍族；</span>
<span className="v" id="v32" data-v="32"> 屬示米大的，有示米大族；屬希弗的，有希弗族。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 27:1; 民數記 36:10–12"> 希弗的兒子西羅非哈沒兒子，只有女兒，西羅非哈女兒的名字就是瑪拉、挪阿、曷拉、密迦、得撒。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 1:34–35; 民數記 2:20–21"> 這就是瑪拿西的各族，他們中間被數的，共有五萬二千七百名。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歷代志上 7:20–21"> 按著家族，以法蓮的眾子，屬書提拉的，有書提拉族；屬比結的，有比結族；屬他罕的，有他罕族；</span>
<span className="v" id="v36" data-v="36"> 書提拉的眾子，屬以蘭的，有以蘭族。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 1:32–33; 民數記 2:18–19"> 這就是以法蓮子孫的各族，照他們中間被數的，共有三萬二千五百名。按著家族，這都是約瑟的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志上 8:1; 歷代志上 7:6–12; 創世記 46:2"> 按著家族，便雅憫的眾子，屬比拉的，有比拉族；屬亞實別的，有亞實別族；屬亞希蘭的，有亞希蘭族；</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 46:21"> 屬書反的，有書反族；屬戶反的，有戶反族。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志上 8:3"> 比拉的眾子是亞勒、乃幔；屬亞勒的，有亞勒族；屬乃幔的，有乃幔族。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 2:22–23; 創世記 46:21; 民數記 1:36–37"> 按著家族，這就是便雅憫的子孫，其中被數的，共有四萬五千六百名。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 46:23"> 按著家族，但的眾子，屬書含的，有書含族。按著家族，這就是但的各族。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 1:38–39; 民數記 2:25–26"> 照其中被數的，書含所有的各族，共有六萬四千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="創世記 46:17; 歷代志上 7:30"> 按著家族，亞設的眾子，屬音拿的，有音拿族；屬亦施韋的，有亦施韋族；屬比利亞的，有比利亞族。</span>
<span className="v" id="v45" data-v="45"> 比利亞的眾子，屬希別的，有希別族；屬瑪結的，有瑪結族。</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 46:17"> 亞設的女兒名叫西拉。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 2:27–28; 民數記 1:40–41"> 這就是亞設子孫的各族，照他們中間被數的，共有五萬三千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="創世記 46:24; 歷代志上 7:13"> 按著家族，拿弗他利的眾子，屬雅薛的，有雅薛族；屬沽尼的，有沽尼族；</span>
<span className="v" id="v49" data-v="49" data-xref="歷代志上 7:13"> 屬耶色的，有耶色族；屬示冷的，有示冷族。</span>
<span className="v" id="v50" data-v="50" data-xref="民數記 1:42–43; 民數記 2:29–30"> 按著家族，這就是拿弗他利的各族，他們中間被數的，共有四萬五千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民數記 1:46; 民數記 2:32; 出埃及記 12:37"> 以色列人中被數的，共有六十萬零一千七百三十名。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52"> 耶和華曉諭摩西說：</span>
<span className="v" id="v53" data-v="53" data-xref="約書亞記 11:23; 約書亞記 14:1; 詩篇 105:44"> 「你要按著人名的數目將地分給這些人為業。</span>
<span className="v" id="v54" data-v="54" data-xref="民數記 33:54; 民數記 32:3; 民數記 32:5"> 人多的，你要把產業多分給他們；人少的，你要把產業少分給他們。要照被數的人數，把產業分給各人。</span>
<span className="v" id="v55" data-v="55" data-xref="民數記 34:13; 民數記 33:54; 約書亞記 14:2"> 雖是這樣，還要拈鬮分地。他們要按著祖宗各支派的名字承受為業。</span>
<span className="v" id="v56" data-v="56" data-xref="哥林多前書 12:4; 羅馬書 11:7"> 要按著所拈的鬮，看人數多人數少，把產業分給他們。」</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="創世記 46:11; 歷代志上 6:1; 出埃及記 6:16–19"> 利未人，按著他們的各族被數的，屬革順的，有革順族；屬哥轄的，有哥轄族；屬米拉利的，有米拉利族。</span>
<span className="v" id="v58" data-v="58" data-xref="民數記 16:1; 民數記 3:17–21; 出埃及記 6:20"> 利未的各族有立尼族、希伯倫族、瑪利族、母示族、可拉族。哥轄生暗蘭。</span>
<span className="v" id="v59" data-v="59" data-xref="出埃及記 6:20; 出埃及記 2:1–2; 利未記 18:12"> 暗蘭的妻名叫約基別，是利未女子，生在埃及。她給暗蘭生了亞倫、摩西，並他們的姐姐米利暗。</span>
<span className="v" id="v60" data-v="60" data-xref="民數記 3:2; 民數記 3:8"> 亞倫生拿答、亞比戶、以利亞撒、以他瑪。</span>
<span className="v" id="v61" data-v="61" data-xref="民數記 3:4; 利未記 10:1–2; 歷代志上 24:1–2"> 拿答、亞比戶在耶和華面前獻凡火的時候就死了。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:9; 民數記 35:2–8; 民數記 3:39"> 利未人中，凡一個月以外，被數的男丁，共有二萬三千。他們本來沒有數在以色列人中，因為在以色列人中，沒有分給他們產業。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="民數記 26:3"> 這些就是被摩西和祭司以利亞撒所數的。他們在摩押平原與耶利哥相對的約旦河邊數點以色列人。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 2:14–15; 申命記 4:3–4; 哥林多前書 10:5"> 但被數的人中，沒有一個是摩西和祭司亞倫從前在西奈的曠野所數的以色列人。</span>
<span className="v" id="v65" data-v="65" data-xref="哥林多前書 10:5–6; 民數記 14:38; 羅馬書 11:22"> 因為耶和華論到他們說，他們必要死在曠野，所以除了耶孚尼的兒子迦勒和嫩的兒子約書亞以外，連一個人也沒有存留。</span>
</div>
</div>

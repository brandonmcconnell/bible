## 耶和華以烈怒施諸敵以恩慈待己兵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 2:13; 約拿書 1:2; 撒迦利亞書 9:1"> 論尼尼微的默示，就是伊勒歌斯人那鴻所得的默示。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 8:2; 出埃及記 20:5; 詩篇 94:1"> <span className="pl pl-1">耶和華是忌邪施報的神，</span><br /><span className="pl pl-1">耶和華施報大有憤怒，</span><br /><span className="pl pl-1">向他的敵人施報，</span><br /><span className="pl pl-1">向他的仇敵懷怒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 147:5; 出埃及記 34:6–7; 尼希米記 9:17"> <span className="pl pl-1">耶和華不輕易發怒，大有能力，</span><br /><span className="pl pl-1">萬不以有罪的為無罪。</span><br /><span className="pl pl-1">他乘旋風和暴風而來，</span><br /><span className="pl pl-1">雲彩為他腳下的塵土。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 33:9; 詩篇 106:9; 詩篇 114:5"> <span className="pl pl-1">他斥責海，使海乾了，</span><br /><span className="pl pl-1">使一切江河乾涸。</span><br /><span className="pl pl-1">巴珊和迦密的樹林衰殘，</span><br /><span className="pl pl-1">黎巴嫩的花草也衰殘了。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 1:4; 撒母耳記下 22:8; 耶利米書 4:24"> <span className="pl pl-1">大山因他震動，</span><br /><span className="pl pl-1">小山也都消化。</span><br /><span className="pl pl-1">大地在他面前突起，</span><br /><span className="pl pl-1">世界和住在其間的也都如此。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 10:10; 瑪拉基書 3:2; 申命記 32:22–23"> <span className="pl pl-1">他發憤恨，誰能立得住呢？</span><br /><span className="pl pl-1">他發烈怒，誰能當得起呢？</span><br /><span className="pl pl-1">他的憤怒如火傾倒，</span><br /><span className="pl pl-1">磐石因他崩裂。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 10:27; 提摩太後書 2:19; 耶利米哀歌 3:25"> <span className="pl pl-1">耶和華本為善，</span><br /><span className="pl pl-1">在患難的日子為人的保障，</span><br /><span className="pl pl-1">並且認得那些投靠他的人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:17; 以賽亞書 8:22; 以西結書 13:13"> <span className="pl pl-1">但他必以漲溢的洪水淹沒尼尼微，</span><br /><span className="pl pl-1">又驅逐仇敵進入黑暗。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 21:11; 箴言 21:30; 詩篇 33:10"> <span className="pl pl-1">尼尼微人哪，設何謀攻擊耶和華呢？</span><br /><span className="pl pl-1">他必將你們滅絕淨盡，</span><br /><span className="pl pl-1">災難不再興起。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 7:4; 以賽亞書 5:24; 以賽亞書 9:18"> <span className="pl pl-1">你們像叢雜的荊棘，</span><br /><span className="pl pl-1">像喝醉了的人，</span><br /><span className="pl pl-1">又如枯乾的碎秸全然燒滅。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="那鴻書 1:9; 歷代志下 13:7; 列王紀下 18:13–14"> <span className="pl pl-1">有一人從你那裡出來，</span><br /><span className="pl pl-1">圖謀邪惡，設惡計攻擊耶和華。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 30:19; 約珥書 2:19; 以賽亞書 17:14"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">「尼尼微雖然勢力充足，人數繁多，</span><br /><span className="pl pl-1">也被剪除，歸於無有。</span><br /><span className="pl pl-1">猶大啊，我雖然使你受苦，</span><br /><span className="pl pl-1">卻不再使你受苦。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 10:27; 以賽亞書 9:4; 耶利米書 2:20"> <span className="pl pl-1">現在我必從你頸項上折斷他的軛，</span><br /><span className="pl pl-1">扭開他的繩索。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="詩篇 109:13; 以賽亞書 46:1–2; 彌迦書 5:13"> <span className="pl pl-1">耶和華已經出令，指著尼尼微說：</span><br /><span className="pl pl-1">「你名下的人必不留後。</span><br /><span className="pl pl-1">我必從你神的廟中除滅雕刻的偶像和鑄造的偶像，</span><br /><span className="pl pl-1">我必因你鄙陋使你歸於墳墓。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 52:7; 羅馬書 10:15; 以賽亞書 40:9–10"> <span className="pl pl-1">看哪，有報好信傳平安之人的腳登山，說：</span><br /><span className="pl pl-1">「猶大啊，可以守你的節期，</span><br /><span className="pl pl-1">還你所許的願吧！</span><br /><span className="pl pl-1">因為那惡人不再從你中間經過，</span><br /><span className="pl pl-1">他已滅絕淨盡了。」</span></span>
</div>

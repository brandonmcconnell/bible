## 當做基督的精兵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 12:9–10; 以弗所書 6:10; 提摩太後書 1:7"> 我兒啊，你要在基督耶穌的恩典上剛強起來。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太後書 1:13–14; 提摩太前書 4:6; 提摩太前書 6:12"> 你在許多見證人面前聽見我所教訓的，也要交託那忠心能教導別人的人。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 12:2–3; 雅各書 1:12; 提摩太後書 4:5"> 你要和我同受苦難，好像基督耶穌的精兵。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:4; 路加福音 8:14; 彼得後書 2:20"> 凡在軍中當兵的，不將世務纏身，好叫那招他當兵的人喜悅。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 9:24–27; 啟示錄 3:11; 提摩太後書 4:7–8"> 人若在場上比武，非按規矩，就不能得冠冕。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 10:36; 哥林多前書 9:7–11; 哥林多前書 3:6–9"> 勞力的農夫理當先得糧食。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:5; 約翰一書 5:20; 路加福音 24:45"> 我所說的話你要思想，因為凡事主必給你聰明。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:24; 羅馬書 2:16; 哥林多前書 15:11–20"> 你要記念耶穌基督乃是大衛的後裔，他從死裡復活，正合乎我所傳的福音。</span>
</div>

## 神的道不被捆綁

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="腓立比書 1:7; 使徒行傳 28:31; 提摩太後書 1:8"> 我為這福音受苦難，甚至被捆綁，像犯人一樣；然而，神的道卻不被捆綁。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 5:10; 歌羅西書 1:24; 提摩太後書 2:3"> 所以，我為選民凡事忍耐，叫他們也可以得著那在基督耶穌裡的救恩和永遠的榮耀。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 6:8; 歌羅西書 3:3–4; 羅馬書 6:5"> 有可信的話說：<br /><span className="pl pl-1">我們若與基督同死，也必與他同活；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 8:17; 馬太福音 10:33; 啟示錄 20:4"> <span className="pl pl-1">我們若能忍耐，也必和他一同做王；</span><br /><span className="pl pl-1">我們若不認他，他也必不認我們；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民數記 23:19; 羅馬書 3:3; 帖撒羅尼迦後書 3:3"> <span className="pl pl-1">我們縱然失信，他仍是可信的，</span><br /><span className="pl pl-1">因為他不能背乎自己。</span></span>
</div>
</div>

## 當做無慚愧的工人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提多書 3:9–11; 提摩太後書 2:23; 提摩太後書 4:1"> 你要使眾人回想這些事，在主面前囑咐他們：不可為言語爭辯，這是沒有益處的，只能敗壞聽見的人。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:4; 彼得後書 1:10; 提摩太前書 4:6"> 你當竭力在神面前得蒙喜悅，做無愧的工人，按著正意分解真理的道。</span>
<span className="v" id="v16" data-v="16" data-xref="提多書 3:9; 提摩太前書 6:20; 提摩太後書 2:14"> 但要遠避世俗的虛談，因為這等人必進到更不敬虔的地步。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前書 1:20; 那鴻書 3:15; 雅各書 5:3"> 他們的話如同毒瘡，越爛越大。其中有許米乃和腓理徒，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 15:12; 提摩太前書 1:19; 希伯來書 3:10"> 他們偏離了真道，說復活的事已過，就敗壞好些人的信心。</span>
</div>
</div>

## 稱呼主名的要離開不義

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 10:14; 哥林多前書 8:3; 那鴻書 1:7"> 然而，神堅固的根基立住了，上面有這印記說：「主認識誰是他的人」，又說：「凡稱呼主名的人總要離開不義。」</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:21–23; 彼得前書 2:5; 提摩太前書 3:15"> 在大戶人家，不但有金器銀器，也有木器瓦器，有作為貴重的，有作為卑賤的。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 3:17; 以弗所書 2:10; 哥林多後書 7:1"> 人若自潔，脫離卑賤的事，就必做貴重的器皿，成為聖潔，合乎主用，預備行各樣的善事。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:11; 彼得前書 3:11; 哥林多前書 6:18"> 你要逃避少年的私慾，同那清心禱告主的人追求公義、信德、仁愛、和平。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太後書 2:14; 提多書 3:9; 提摩太前書 4:7"> 唯有那愚拙無學問的辯論，總要棄絕，因為知道這等事是起爭競的。</span>
</div>
</div>

<div className="bp">

<span className="v" id="v25" data-v="25" data-xref="使徒行傳 11:18; 加拉太書 6:1; 提摩太前書 2:4"> 用溫柔勸誡那抵擋的人，或者神給他們悔改的心，可以明白真道，</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 3:7; 以賽亞書 49:25–26; 詩篇 124:7"> 叫他們這已經被魔鬼任意擄去的可以醒悟，脫離他的網羅。</span>

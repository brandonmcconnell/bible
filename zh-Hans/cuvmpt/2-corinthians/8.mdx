## 當效法馬其頓教會樂捐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 16:9; 哥林多後書 9:2; 哥林多後書 9:4"> 弟兄們，我把神賜給馬其頓眾教會的恩告訴你們，</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 2:5; 箴言 11:25; 哥林多後書 6:10"> 就是他們在患難中受大試煉的時候，仍有滿足的快樂，在極窮之間還格外顯出他們樂捐的厚恩。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:29; 出埃及記 35:5; 出埃及記 35:21–22"> 我可以證明他們是按著力量，而且也過了力量，自己甘心樂意地捐助，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 24:17; 加拉太書 6:10; 哥林多後書 9:1"> 再三地求我們，准他們在這供給聖徒的恩情上有份。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 12:1; 羅馬書 14:7–9; 歷代志下 30:12"> 並且他們所做的，不但照我們所想望的，更照神的旨意，先把自己獻給主，又歸附了我們。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 12:18; 哥林多後書 8:19; 哥林多後書 8:4"> 因此我勸提多，既然在你們中間開辦這慈惠的事，就當辦成了。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 9:8; 彼得後書 1:5–8; 帖撒羅尼迦後書 1:3"> 你們既然在信心、口才、知識、熱心和待我們的愛心上，都格外顯出滿足來，就當在這慈惠的事上也格外顯出滿足來。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 7:6; 約翰一書 3:17–19; 雅各書 2:14–16"> 我說這話，不是吩咐你們，乃是藉著別人的熱心試驗你們愛心的實在。</span>
</div>
</div>

## 當效基督捨富為貧

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="羅馬書 8:32; 腓立比書 2:6–8; 馬太福音 20:28"> 你們知道我們主耶穌基督的恩典：他本來富足，卻為你們成了貧窮，叫你們因他的貧窮可以成為富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:18–19; 希伯來書 13:16; 哥林多後書 9:2"> 我在這事上把我的意見告訴你們，是於你們有益；因為你們下手辦這事，而且起此心意已經有一年了，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 9:2"> 如今就當辦成這事。既有願做的心，也當照你們所有的去辦成。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 12:42–44; 哥林多後書 9:7; 路加福音 21:1–4"> 因為人若有願做的心，必蒙悅納，乃是照他所有的，並不是照他所無的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 4:34; 羅馬書 15:26–27"> 我原不是要別人輕省、你們受累，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 9:12; 使徒行傳 4:34"> 乃要均平。就是要你們的富餘現在可以補他們的不足，使他們的富餘將來也可以補你們的不足，這就均平了，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 16:18; 路加福音 22:35"> 如經上所記：<br /><span className="pl pl-1">「多收的也沒有餘，</span><br /><span className="pl pl-1">少收的也沒有缺。」</span></span>
</div>
</div>

## 稱讚提多

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:17; 耶利米書 32:40; 哥林多後書 2:13–14"> 多謝神感動提多的心，叫他待你們殷勤，像我一樣。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 8:6; 希伯來書 13:22; 哥林多後書 8:10"> 他固然是聽了我的勸，但自己更是熱心，情願往你們那裡去。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 12:18; 哥林多後書 8:19; 哥林多前書 7:17"> 我們還打發一位兄弟和他同去，這人在福音上得了眾教會的稱讚。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 16:3–4; 哥林多後書 4:15; 哥林多後書 9:8"> 不但這樣，他也被眾教會挑選，和我們同行，把所託於我們的這捐資送到了，可以榮耀主，又表明我們樂意的心。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒羅尼迦前書 5:22; 羅馬書 14:16; 以弗所書 5:15"> 這就免得有人因我們收的捐銀很多，就挑我們的不是。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 12:17; 彼得前書 2:12; 腓立比書 4:8"> 我們留心行光明的事，不但在主面前，就在人面前也是這樣。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 2:20–22"> 我們又打發一位兄弟同去；這人的熱心，我們在許多事上屢次試驗過，現在他因為深信你們就更加熱心了。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 2:25; 腓利門書 1:17; 哥林多後書 8:6"> 論到提多，他是我的同伴，一同為你們勞碌的；論到那兩位兄弟，他們是眾教會的使者，是基督的榮耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 7:14; 哥林多後書 7:4; 哥林多後書 9:2–4"> 所以，你們務要在眾教會面前顯明你們愛心的憑據，並我所誇獎你們的憑據。</span>
</div>

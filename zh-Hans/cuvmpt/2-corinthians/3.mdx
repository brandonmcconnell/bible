## 門徒為保羅的薦書

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 12:11; 哥林多後書 10:12; 哥林多後書 5:12"> 我們豈是又舉薦自己嗎？豈像別人，用人的薦信給你們或用你們的薦信給人嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 9:1–2; 帖撒羅尼迦前書 1:8; 羅馬書 1:8"> 你們就是我們的薦信，寫在我們的心裡，被眾人所知道所念誦的。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 11:19; 耶利米書 31:33; 希伯來書 8:10"> 你們明顯是基督的信，藉著我們修成的：不是用墨寫的，乃是用永生神的靈寫的；不是寫在石版上，乃是寫在心版上。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 1:6; 以弗所書 3:12; 哥林多後書 2:14"> 我們因基督，所以在神面前才有這樣的信心。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:9; 腓立比書 4:13; 哥林多前書 15:10"> 並不是我們憑自己能承擔什麼事，我們所能承擔的，乃是出於神。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 6:63; 羅馬書 7:6; 耶利米書 31:31"> 他叫我們能承當這新約的執事，不是憑著字句，乃是憑著精意；因為那字句是叫人死，精意<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「精意」或作「聖靈」。">a</a></sup>是叫人活。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 3:9–11; 羅馬書 10:4; 出埃及記 31:18"> 那用字刻在石頭上屬死的職事尚且有榮光，甚至以色列人因摩西面上的榮光，不能定睛看他的臉，這榮光原是漸漸退去的；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 3:16; 以弗所書 2:18; 加拉太書 3:14"> 何況那屬靈的職事，豈不更有榮光嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 3:21–22; 希伯來書 12:18–21; 哥林多後書 5:21"> 若是定罪的職事有榮光，那稱義的職事榮光就越發大了。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 1:17; 哈該書 2:7–9; 使徒行傳 26:13"> 那從前有榮光的，因這極大的榮光就算不得有榮光了。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:20–21; 希伯來書 8:13; 希伯來書 7:21–25"> 若那廢掉的有榮光，這長存的就更有榮光了。</span>
</div>
</div>

## 主的靈在哪裡哪裡就得以自由

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 7:4; 使徒行傳 4:13; 腓立比書 1:20"> 我們既有這樣的盼望，就大膽講說，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:33–35; 希伯來書 10:1–9; 以弗所書 2:14–15"> 不像摩西將帕子蒙在臉上，叫以色列人不能定睛看到那將廢者的結局。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 4:3–4; 使徒行傳 26:18; 羅馬書 11:25"> 但他們的心地剛硬，直到今日誦讀舊約的時候，這帕子還沒有揭去；這帕子在基督裡已經廢去了。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 13:27–29"> 然而直到今日，每逢誦讀摩西書的時候，帕子還在他們心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 34:34; 以賽亞書 29:18; 以賽亞書 25:7"> 但他們的心幾時歸向主，帕子就幾時除去了。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:2; 加拉太書 5:13; 約翰福音 8:32"> 主就是那靈，主的靈在哪裡，哪裡就得以自由。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 4:6; 以弗所書 4:22–24; 羅馬書 12:2"> 我們眾人既然敞著臉得以看見主的榮光，好像從鏡子裡返照，就變成主的形狀，榮上加榮，如同從主的靈變成的。</span>
</div>
</div>

## 律法是將來美事的影兒

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 8:5; 希伯來書 9:11; 歌羅西書 2:17"> 律法既是將來美事的影兒，不是本物的真像，總不能藉著每年常獻一樣的祭物，叫那近前來的人得以完全。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 43:25; 彌迦書 7:19; 詩篇 103:12"> 若不然，獻祭的事豈不早已止住了嗎？因為禮拜的人，良心既被潔淨，就不再覺得有罪了。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 9:7; 出埃及記 30:10; 利未記 23:27–28"> 但這些祭物是叫人每年想起罪來，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 10:11; 以賽亞書 1:11–15; 彌迦書 6:6–8"> 因為公牛和山羊的血斷不能除罪。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 40:6–8; 以賽亞書 1:11; 以賽亞書 7:14"> 所以，基督到世上來的時候就說：<br /><span className="pl pl-1">「神啊，祭物和禮物是你不願意的，</span><br /><span className="pl pl-1">你曾給我預備了身體。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 1:10; 馬太福音 3:17; 詩篇 147:11"> <span className="pl pl-1">燔祭和贖罪祭是你不喜歡的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 40:7–8; 約翰福音 4:34; 約翰福音 6:38"> <span className="pl pl-1">那時我說：『神啊，我來了，</span><br /><span className="pl pl-1">為要照你的旨意行，</span><br /><span className="pl pl-1">我的事在經卷上已經記載了。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:5; 馬可福音 12:33"> 以上說：「祭物和禮物，燔祭和贖罪祭，是你不願意的，也是你不喜歡的。」這都是按著律法獻的。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 7:18–19; 希伯來書 12:27–28; 希伯來書 10:7"> 後又說：「我來了為要照你的旨意行。」可見他是除去在先的，為要立定在後的。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:14; 希伯來書 10:12; 哥林多前書 6:11"> 我們憑這旨意，靠耶穌基督只一次獻上他的身體，就得以成聖。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 5:1; 民數記 28:3; 希伯來書 10:4"> 凡祭司天天站著侍奉神，屢次獻上一樣的祭物，這祭物永不能除罪。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 1:3; 歌羅西書 3:1; 羅馬書 8:34"> 但基督獻了一次永遠的贖罪祭，就在神的右邊坐下了，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 1:13; 詩篇 110:1; 路加福音 20:43"> 從此等候他仇敵成了他的腳凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 7:25; 希伯來書 10:1; 希伯來書 9:14"> 因為他一次獻祭，便叫那得以成聖的人永遠完全。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:7; 啟示錄 2:11; 啟示錄 3:6"> 聖靈也對我們作見證，因為他既已說過：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 31:33–34; 希伯來書 8:8–12; 羅馬書 11:27"> <span className="pl pl-1">「主說：『那些日子以後，</span><br /><span className="pl pl-1">我與他們所立的約乃是這樣：</span><br /><span className="pl pl-1">我要將我的律法寫在他們心上，</span><br /><span className="pl pl-1">又要放在他們的裡面』」，</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 31:34; 希伯來書 8:12"> 以後就說：<br /><span className="pl pl-1">「我不再記念他們的罪愆和他們的過犯。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯來書 10:2; 希伯來書 10:14"> 這些罪過既已赦免，就不用再為罪獻祭了。</span>
</div>
</div>

## 當存誠心和充足的信心來到神面前

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所書 2:18; 希伯來書 9:12; 希伯來書 4:16"> 弟兄們，我們既因耶穌的血得以坦然進入至聖所，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 14:6; 約翰福音 10:9; 希伯來書 9:3"> 是藉著他給我們開了一條又新又活的路，從幔子經過，這幔子就是他的身體；</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 2:17; 希伯來書 4:14–16; 希伯來書 8:1"> 又有一位大祭司治理神的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 36:25; 約翰福音 3:5; 以弗所書 5:26"> 並我們心中天良的虧欠已經灑去，身體用清水洗淨了，就當存著誠心和充足的信心來到神面前。</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒羅尼迦前書 5:24; 哥林多前書 1:9; 帖撒羅尼迦後書 3:3"> 也要堅守我們所承認的指望，不致搖動，因為那應許我們的是信實的。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:11; 約翰一書 3:18; 希伯來書 13:1"> 又要彼此相顧，激發愛心，勉勵行善。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 2:42; 帖撒羅尼迦前書 5:11; 馬太福音 18:20"> 你們不可停止聚會，好像那些停止慣了的人，倒要彼此勸勉；既知道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：看見。">a</a></sup>那日子臨近，就更當如此。</span>
</div>
</div>

## 警戒故意犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得後書 2:20–22; 希伯來書 6:4–6; 約翰福音 9:41"> 因為我們得知真道以後，若故意犯罪，贖罪的祭就再沒有了，</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 26:11; 希伯來書 2:3; 西番雅書 1:18"> 唯有戰懼等候審判和那燒滅眾敵人的烈火。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:2; 申命記 19:15; 申命記 17:2–13"> 人干犯摩西的律法，憑兩三個見證人，尚且不得憐恤而死；</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 6:6; 以弗所書 4:30; 以賽亞書 63:10"> 何況人踐踏神的兒子，將那使他成聖之約的血當做平常，又褻慢施恩的聖靈，你們想，他要受的刑罰該怎樣加重呢！</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 32:35–36; 羅馬書 12:19; 那鴻書 1:2"> 因為我們知道誰說「申冤在我，我必報應」，又說「主要審判他的百姓」。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 10:28; 路加福音 12:5; 希伯來書 12:29"> 落在永生神的手裡，真是可怕的！</span>
</div>
</div>

## 義人必因信得生

<div className="bt">
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="希伯來書 6:4; 希伯來書 12:4; 提摩太後書 2:3–13"> 你們要追念往日蒙了光照以後，所忍受大爭戰的各樣苦難。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 4:9; 腓立比書 4:14; 希伯來書 11:36"> 一面被毀謗，遭患難，成了戲景叫眾人觀看；一面陪伴那些受這樣苦難的人。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前書 1:4; 提摩太後書 1:16; 馬太福音 5:11–12"> 因為你們體恤了那些被捆鎖的人，並且你們的家業被人搶去，也甘心忍受，知道自己有更美、長存的家業。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前書 15:58; 加拉太書 6:8–10; 希伯來書 3:6"> 所以，你們不可丟棄勇敢的心，存這樣的心必得大賞賜。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 12:1; 詩篇 37:7; 雅各書 5:7–11"> 你們必須忍耐，使你們行完了神的旨意，就可以得著所應許的。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 5:7–9; 哈巴谷書 2:3–4; 路加福音 18:8"> <span className="pl pl-1">「因為還有一點點時候，</span><br /><span className="pl pl-1">那要來的就來，並不遲延。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太書 3:11; 哈巴谷書 2:4; 羅馬書 1:17"> <span className="pl pl-1">只是義人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「義人」有古卷作「我的義人」。">b</a></sup><br /><span className="pl pl-1">必因信得生；</span><br /><span className="pl pl-1">他若退後，我心裡就不喜歡他。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰一書 5:5; 彼得前書 1:5; 馬可福音 16:16"> 我們卻不是退後入沉淪的那等人，乃是有信心以致靈魂得救的人。</span>
</div>
</div>

## 當竭力進到完全的地步

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 5:12–14; 哥林多後書 7:1; 希伯來書 9:14"> 所以，我們應當離開基督道理的開端，竭力進到完全的地步，不必再立根基，就如那懊悔死行、信靠神、</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 15:13–57; 使徒行傳 17:31–32; 羅馬書 6:3–5"> 各樣洗禮、按手之禮、死人復活，以及永遠審判各等教訓。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:21; 哥林多前書 16:7; 哥林多前書 4:19"> 神若許我們，我們必如此行。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 10:26–29; 彼得後書 2:20–22; 馬太福音 5:13"> 論到那些已經蒙了光照，嘗過天恩的滋味，又於聖靈有份，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 2:3; 路加福音 8:13; 馬太福音 13:20–21"> 並嘗過神善道的滋味，覺悟來世權能的人，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得後書 2:21; 希伯來書 10:29; 希伯來書 6:4"> 若是離棄道理，就不能叫他們重新懊悔了。因為他們把神的兒子重釘十字架，明明地羞辱他。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 10:12; 以賽亞書 44:3; 詩篇 65:9–13"> 就如一塊田地，吃過屢次下的雨水，生長菜蔬，合乎耕種的人用，就從神得福；</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:17–18; 約翰福音 15:6; 路加福音 13:7–9"> 若長荊棘和蒺藜，必被廢棄，近於咒詛，結局就是焚燒。</span>
</div>
</div>

## 當效法承受應許之人

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:39; 哥林多後書 7:10; 希伯來書 6:4–6"> 親愛的弟兄們，我們雖是這樣說，卻深信你們的行為強過這些，而且近乎得救。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 10:42; 希伯來書 13:16; 加拉太書 6:10"> 因為神並非不公義，竟忘記你們所做的工和你們為他名所顯的愛心，就是：先前伺候聖徒，如今還是伺候。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 1:5–8; 希伯來書 3:6; 羅馬書 5:2–5"> 我們願你們各人都顯出這樣的殷勤，使你們有滿足的指望，一直到底；</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 13:7; 希伯來書 10:36; 約翰一書 2:25"> 並且不懈怠，總要效法那些憑信心和忍耐承受應許的人。</span>
</div>
</div>

## 務要持定面前的指望

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 22:15–18; 路加福音 1:73; 耶利米書 22:5"> 當初神應許亞伯拉罕的時候，因為沒有比自己更大可以指著起誓的，就指著自己起誓，說：</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:17; 申命記 1:10; 尼希米記 9:23"> 「論福，我必賜大福給你；論子孫，我必叫你的子孫多起來。」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 12:2–3; 羅馬書 4:17–25; 出埃及記 1:7"> 這樣，亞伯拉罕既恆久忍耐，就得了所應許的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 22:11; 希伯來書 6:13; 創世記 31:53"> 人都是指著比自己大的起誓，並且以起誓為實據，了結各樣的爭論。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 6:18; 箴言 19:21; 以賽亞書 55:11"> 照樣，神願意為那承受應許的人格外顯明他的旨意是不更改的，就起誓為證。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 23:19; 提多書 1:2; 撒母耳記上 15:29"> 藉這兩件不更改的事——神決不能說謊——好叫我們這逃往避難所、持定擺在我們前頭指望的人可以大得勉勵。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 43:5; 羅馬書 5:5–10; 希伯來書 9:7"> 我們有這指望，如同靈魂的錨，又堅固又牢靠，且通入幔內；</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 4:14; 希伯來書 3:1; 希伯來書 5:6"> 做先鋒的耶穌既照著麥基洗德的等次成了永遠的大祭司，就為我們進入幔內。</span>
</div>
</div>

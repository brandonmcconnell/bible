## 十童女的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:35–36; 腓立比書 2:15–16; 馬太福音 24:42–51"> <span className="woj">「那時，天國好比十個童女拿著燈出去迎接新郎。</span></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 24:2; 哥林多前書 10:1–5; 馬太福音 13:19–23"> <span className="woj">其中有五個是愚拙的，五個是聰明的。</span></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:15–16; 提摩太後書 3:5; 以賽亞書 48:1–2"> <span className="woj">愚拙的拿著燈，卻不預備油；</span></span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 8:9; 約翰一書 2:27; 約翰一書 2:20"> <span className="woj">聰明的拿著燈，又預備油在器皿裡。</span></span>
<span className="v" id="v5" data-v="5" data-xref="哈巴谷書 2:3; 帖撒羅尼迦前書 5:6–8; 彼得後書 3:4–9"> <span className="woj">新郎遲延的時候，她們都打盹睡著了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="彼得後書 3:10; 馬太福音 24:31; 馬太福音 24:44"> <span className="woj">半夜有人喊著說：『新郎來了，你們出來迎接他！』</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 12:35; 啟示錄 3:19–20; 彼得後書 3:14"> <span className="woj">那些童女就都起來收拾燈。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 13:9; 路加福音 12:35; 希伯來書 4:1"> <span className="woj">愚拙的對聰明的說：『請分點油給我們，因為我們的燈要滅了。』</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 49:7–9; 啟示錄 3:17–18; 以賽亞書 55:6–7"> <span className="woj">聰明的回答說：『恐怕不夠你我用的，不如你們自己到賣油的那裡去買吧。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:25; 馬太福音 24:44; 路加福音 12:36–37"> <span className="woj">她們去買的時候，新郎到了，那預備好了的同他進去坐席，門就關了。</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 7:21–23; 希伯來書 12:16–17"> <span className="woj">其餘的童女隨後也來了，說：『主啊，主啊，給我們開門！』</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 8:3; 提摩太後書 2:19; 約翰福音 10:27"> <span className="woj">他卻回答說：『我實在告訴你們：我不認識你們。』</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:42–44; 啟示錄 16:15; 帖撒羅尼迦前書 5:6"> <span className="woj">所以，你們要警醒，因為那日子、那時辰，你們不知道。</span></span>
</div>
</div>

## 按才幹受責任

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬可福音 13:34; 路加福音 19:12–27; 彼得前書 4:9–11"> <span className="woj">「天國又好比一個人要往外國去，就叫了僕人來，把他的家業交給他們，</span></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:24; 路加福音 19:13–14; 路加福音 12:48"> <span className="woj">按著各人的才幹給他們銀子，一個給了五千，一個給了二千，一個給了一千，就往外國去了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="約翰三書 1:5–8; 提摩太前書 6:17–18; 提摩太後書 2:6"> <span className="woj">那領五千的隨即拿去做買賣，另外賺了五千。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 3:9–10; 以弗所書 5:16; 彼得前書 4:10"> <span className="woj">那領二千的也照樣另賺了二千。</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得後書 1:8; 哈該書 1:2–4; 瑪拉基書 1:10"> <span className="woj">但那領一千的去掘開地，把主人的銀子埋藏了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 3:12–15; 哥林多後書 5:10; 羅馬書 14:7–12"> <span className="woj">過了許久，那些僕人的主人來了，和他們算帳。</span></span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 20:24; 路加福音 19:16–17; 歌羅西書 1:29"> <span className="woj">那領五千銀子的又帶著那另外的五千來，說：『主啊，你交給我五千銀子，請看，我又賺了五千。』</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:23; 路加福音 16:10; 約翰福音 12:26"> <span className="woj">主人說：『好，你這又良善又忠心的僕人，你在不多的事上有忠心，我要把許多事派你管理。可以進來享受你主人的快樂！』</span></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 8:12; 哥林多後書 8:7–8; 哥林多後書 8:1–3"> <span className="woj">那領二千的也來，說：『主啊，你交給我二千銀子，請看，我又賺了二千。』</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 25:21; 馬可福音 14:8–9; 馬可福音 12:41–44"> <span className="woj">主人說：『好，你這又良善又忠心的僕人，你在不多的事上有忠心，我要把許多事派你管理。可以進來享受你主人的快樂！』</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 19:20–22; 路加福音 15:29; 瑪拉基書 3:14–15"> <span className="woj">那領一千的也來，說：『主啊，我知道你是忍心的人，沒有種的地方要收割，沒有散的地方要聚斂。</span></span>
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 1:6–7; 羅馬書 8:15; 啟示錄 21:8"> <span className="woj">我就害怕，去把你的一千銀子埋藏在地裡。請看，你的原銀子在這裡。』</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:32; 約伯記 15:5–6"> <span className="woj">主人回答說：『你這又惡又懶的僕人！你既知道我沒有種的地方要收割，沒有散的地方要聚斂，</span></span>
<span className="v" id="v27" data-v="27" data-xref="申命記 23:19–20; 羅馬書 3:19; 猶大書 1:15"> <span className="woj">就當把我的銀子放給兌換銀錢的人，到我來的時候，可以連本帶利收回。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 19:24; 路加福音 10:42"> <span className="woj">奪過他這一千來，給那有一萬的！</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 8:18; 馬可福音 4:25; 馬太福音 13:12"> <span className="woj">因為凡有的，還要加給他，叫他有餘；沒有的，連他所有的也要奪過來。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 8:12; 啟示錄 3:15–16; 馬太福音 13:50"> <span className="woj">把這無用的僕人丟在外面黑暗裡，在那裡必要哀哭切齒了。』</span></span>
</div>

## 論審判的日子

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="啟示錄 1:7; 帖撒羅尼迦後書 1:7–8; 馬太福音 19:28"> <span className="woj">「當人子在他榮耀裡同著眾天使降臨的時候，要坐在他榮耀的寶座上。</span></span>
<span className="v" id="v32" data-v="32" data-xref="瑪拉基書 3:18; 馬太福音 13:49; 哥林多後書 5:10"> <span className="woj">萬民都要聚集在他面前，他要把他們分別出來，好像牧羊的分別綿羊山羊一般：</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 100:3; 約翰福音 10:26–28; 約翰福音 21:15–17"> <span className="woj">把綿羊安置在右邊，山羊在左邊。</span></span>
<span className="v" id="v34" data-v="34" data-xref="彼得前書 1:19–20; 雅各書 2:5; 啟示錄 21:7"> <span className="woj">於是，王要向那右邊的說：『你們這蒙我父賜福的，可來承受那創世以來為你們所預備的國。</span></span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 3:16–19; 雅各書 2:15–16; 申命記 15:7–11"> <span className="woj">因為我餓了，你們給我吃；渴了，你們給我喝；我做客旅，你們留我住；</span></span>
<span className="v" id="v36" data-v="36" data-xref="雅各書 1:27; 提摩太後書 1:16–18; 雅各書 5:14–15"> <span className="woj">我赤身露體，你們給我穿；我病了，你們看顧我；我在監裡，你們來看我。』</span></span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 6:3; 歷代志上 29:14; 彼得前書 5:5–6"> <span className="woj">義人就回答說：『主啊，我們什麼時候見你餓了給你吃，渴了給你喝？</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">什麼時候見你做客旅留你住，或是赤身露體給你穿？</span></span>
<span className="v" id="v39" data-v="39"> <span className="woj">又什麼時候見你病了或是在監裡，來看你呢？』</span></span>
<span className="v" id="v40" data-v="40" data-xref="箴言 19:17; 箴言 14:31; 馬太福音 10:42"> <span className="woj">王要回答說：『我實在告訴你們：這些事你們既做在我這弟兄中一個最小的身上，就是做在我身上了。』</span></span>
<span className="v" id="v41" data-v="41" data-xref="彼得後書 2:4; 猶大書 1:6–7; 帖撒羅尼迦後書 1:9"> <span className="woj">王又要向那左邊的說：『你們這被咒詛的人，離開我，進入那為魔鬼和他的使者所預備的永火裡去！</span></span>
<span className="v" id="v42" data-v="42" data-xref="雅各書 2:15–24; 約翰福音 5:23; 馬太福音 12:30"> <span className="woj">因為我餓了，你們不給我吃；渴了，你們不給我喝；</span></span>
<span className="v" id="v43" data-v="43"> <span className="woj">我做客旅，你們不留我住；我赤身露體，你們不給我穿；我病了，我在監裡，你們不來看顧我。』</span></span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 7:22; 路加福音 10:29; 馬太福音 25:24–27"> <span className="woj">他們也要回答說：『主啊，我們什麼時候見你餓了，或渴了，或做客旅，或赤身露體，或病了，或在監裡，不伺候你呢？』</span></span>
<span className="v" id="v45" data-v="45" data-xref="箴言 21:13; 箴言 17:5; 箴言 14:31"> <span className="woj">王要回答說：『我實在告訴你們：這些事你們既不做在我這弟兄中一個最小的身上，就是不做在我身上了。』</span></span>
<span className="v" id="v46" data-v="46" data-xref="但以理書 12:2; 約翰福音 3:36; 約翰福音 5:29"> <span className="woj">這些人要往永刑裡去，那些義人要往永生裡去。」</span></span>

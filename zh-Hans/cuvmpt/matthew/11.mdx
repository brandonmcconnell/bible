## 施洗約翰差人問主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 61:1–3; 使徒行傳 10:38; 路加福音 8:1"> 耶穌吩咐完了十二個門徒，就離開那裡，往各城去傳道、教訓人。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬可福音 6:17; 馬太福音 14:3; 馬太福音 9:14"> 約翰在監裡聽見基督所做的事，就打發兩個門徒去，</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:27; 瑪拉基書 3:1; 申命記 18:15–18"> 問他說：「那將要來的是你嗎？還是我們等候別人呢？」</span>
<span className="v" id="v4" data-v="4"> 耶穌回答說：<span className="woj">「你們去，把所聽見、所看見的事告訴約翰，</span></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 35:4–6; 以賽亞書 61:1–3; 路加福音 4:18"> <span className="woj">就是：瞎子看見，瘸子行走，長大痲瘋的潔淨，聾子聽見，死人復活，窮人有福音傳給他們。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 8:14–15; 哥林多前書 2:14; 馬太福音 26:31"> <span className="woj">凡不因我跌倒的，就有福了！」</span></span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:6; 約翰福音 5:35; 馬可福音 1:3–5"> 他們走的時候，耶穌就對眾人講論約翰說：<span className="woj">「你們從前出到曠野是要看什麼呢？要看風吹動的蘆葦嗎？</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 3:4; 列王紀下 1:8; 撒迦利亞書 13:4"> <span className="woj">你們出去到底是要看什麼？要看穿細軟衣服的人嗎？那穿細軟衣服的人是在王宮裡。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 馬太福音 14:5; 馬太福音 21:24–26"> <span className="woj">你們出去究竟是為什麼？是要看先知嗎？我告訴你們，是的，他比先知大多了。</span></span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 3:1; 以賽亞書 40:3; 瑪拉基書 4:5"> <span className="woj">經上記著說：『我要差遣我的使者在你前面預備道路』，所說的就是這個人。</span></span>
</div>
</div>

## 耶穌稱讚施洗約翰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所書 3:8; 馬太福音 3:11"> <span className="woj">「我實在告訴你們：凡婦人所生的，沒有一個興起來大過施洗約翰的；然而天國裡最小的比他還大。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所書 6:11–13"> <span className="woj">從施洗約翰的時候到如今，天國是努力進入的，努力的人就得著了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:17–18; 羅馬書 3:21; 使徒行傳 13:27"> <span className="woj">因為眾先知和律法說預言到約翰為止；</span></span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 4:5; 馬太福音 17:10–13; 馬可福音 9:11–13"> <span className="woj">你們若肯領受，這人就是那應當來的以利亞。</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 馬太福音 13:9; 馬可福音 4:23"> <span className="woj">有耳可聽的，就應當聽！</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 馬太福音 12:34; 馬太福音 23:36"> <span className="woj">我可用什麼比這世代呢？好像孩童坐在街市上招呼同伴說：</span></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 28:9–13; 以賽亞書 30:29; 耶利米書 9:17–20"> <span className="pl pl-1 woj">『我們向你們吹笛，</span><br /><span className="pl pl-1 woj">你們不跳舞！</span><br /><span className="pl pl-1 woj">我們向你們舉哀，</span><br /><span className="pl pl-1 woj">你們不捶胸！』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 馬太福音 3:4; 約翰福音 10:20"> <span className="woj">約翰來了，也不吃也不喝，人就說他是被鬼附著的。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> <span className="woj">人子來了，也吃也喝，人又說他是貪食好酒的人，是稅吏和罪人的朋友。但智慧之子總以智慧為是。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：但智慧在行為上就顯為是。">a</a></sup><span className="woj">」</span></span>
</div>
</div>

## 耶穌責備那些城的人

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米書 8:6; 提摩太後書 2:25–26"> 耶穌在諸城中行了許多異能，那些城的人終不悔改，就在那時候責備他們說：</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 3:6–7; 使徒行傳 12:20; 路加福音 9:10"> <span className="woj">「哥拉汛哪，你有禍了！伯賽大啊，你有禍了！因為在你們中間所行的異能，若行在推羅、西頓，他們早已披麻蒙灰悔改了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:24; 馬太福音 10:15; 希伯來書 10:26–31"> <span className="woj">但我告訴你們：當審判的日子，推羅、西頓所受的比你們還容易受呢！</span></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 14:13–15; 約翰福音 4:46–54; 創世記 13:13"> <span className="woj">迦百農啊，你已經升到天上，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：你將要升到天上嗎？">b</a></sup><span className="woj">將來必墜落陰間！因為在你那裡所行的異能，若行在所多瑪，它還可以存到今日。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:15; 馬太福音 11:22; 馬可福音 6:11"> <span className="woj">但我告訴你們：當審判的日子，所多瑪所受的比你還容易受呢！」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 21:16; 詩篇 8:2; 馬太福音 16:17"> 那時，耶穌說：<span className="woj">「父啊，天地的主，我感謝你！因為你將這些事向聰明通達人就藏起來，向嬰孩就顯出來。</span></span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:9; 以弗所書 1:11; 約伯記 33:13"> <span className="woj">父啊，是的，因為你的美意本是如此。</span></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:6–9; 馬太福音 28:18; 路加福音 10:22"> <span className="woj">一切所有的，都是我父交付我的。除了父，沒有人知道子；除了子和子所願意指示的，沒有人知道父。</span></span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 11:29; 約翰福音 7:37; 約翰福音 6:37"> <span className="woj">凡勞苦擔重擔的人，可以到我這裡來，我就使你們得安息。</span></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 6:16; 約翰一書 2:6; 腓立比書 2:7–8"> <span className="woj">我心裡柔和謙卑，你們當負我的軛，學我的樣式，這樣你們心裡就必得享安息。</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 5:3; 約翰福音 16:33; 腓立比書 4:13"> <span className="woj">因為我的軛是容易的，我的擔子是輕省的。」</span></span>
</div>

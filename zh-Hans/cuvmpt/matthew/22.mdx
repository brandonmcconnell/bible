## 娶親的筵席

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 20:1–16; 馬太福音 12:43–45; 路加福音 14:16"> 耶穌又用比喻對他們說：</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 19:7–9; 馬太福音 13:24; 以弗所書 5:24–32"> <span className="woj">「天國好比一個王為他兒子擺設娶親的筵席，</span></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 22:17; 約翰福音 5:40; 路加福音 14:15–17"> <span className="woj">就打發僕人去，請那些被召的人來赴席，他們卻不肯來。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 13:46; 馬太福音 21:36; 約翰福音 6:50–57"> <span className="woj">王又打發別的僕人，說：『你們告訴那被召的人：我的筵席已經預備好了，牛和肥畜已經宰了，各樣都齊備，請你們來赴席。』</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 2:3; 路加福音 14:18–20; 約翰一書 2:15–16"> <span className="woj">那些人不理就走了：一個到自己田裡去，一個做買賣去，</span></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:19–20; 約翰福音 16:2–3; 使徒行傳 7:51–57"> <span className="woj">其餘的拿住僕人，凌辱他們，把他們殺了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前書 4:17–18; 路加福音 21:24"> <span className="woj">王就大怒，發兵除滅那些凶手，燒毀他們的城。</span></span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦後書 1:5; 使徒行傳 13:46; 啟示錄 3:4"> <span className="woj">於是對僕人說：『喜筵已經齊備，只是所召的人不配。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 馬可福音 16:15–16"> <span className="woj">所以你們要往岔路口上去，凡遇見的，都召來赴席。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 6:9–11; 啟示錄 19:6–9; 哥林多後書 12:21"> <span className="woj">那些僕人就出去，到大路上，凡遇見的，不論善惡都召聚了來，筵席上就坐滿了客。</span></span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 3:4–5; 啟示錄 19:8; 希伯來書 4:12–13"> <span className="woj">王進來觀看賓客，見那裡有一個沒有穿禮服的，</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:9; 約伯記 5:16; 馬太福音 20:13"> <span className="woj">就對他說：『朋友，你到這裡來怎麼不穿禮服呢？』那人無言可答。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 8:12; 馬太福音 25:30; 馬太福音 24:51"> <span className="woj">於是王對使喚的人說：『捆起他的手腳來，把他丟在外邊的黑暗裡，在那裡必要哀哭切齒了。』</span></span>
<span className="v" id="v14" data-v="14" data-xref="彼得後書 1:10; 路加福音 13:23–24; 馬太福音 7:13–14"> <span className="woj">因為被召的人多，選上的人少。」</span></span>
</div>
</div>

## 巧言盤問

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 馬可福音 12:13–17; 詩篇 2:2"> 當時，法利賽人出去商議，怎樣就著耶穌的話陷害他，</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 3:6; 馬可福音 8:15; 馬可福音 12:14"> 就打發他們的門徒同希律黨的人去見耶穌，說：「夫子，我們知道你是誠實人，並且誠誠實實傳神的道，什麼人你都不徇情面，因為你不看人的外貌。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 羅馬書 13:6–7; 馬太福音 17:25"> 請告訴我們你的意見如何：納稅給凱撒可以不可以？」</span>
</div>
</div>

## 納稅給凱撒

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 8:6; 路加福音 5:22; 約翰福音 2:25"> 耶穌看出他們的惡意，就說：<span className="woj">「假冒為善的人哪，為什麼試探我？</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 20:2; 啟示錄 6:6; 馬太福音 18:28"> <span className="woj">拿一個上稅的錢給我看。」</span>他們就拿一個銀錢來給他。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶穌說：<span className="woj">「這像和這號是誰的？」</span></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 13:7; 箴言 24:21; 使徒行傳 4:19"> 他們說：「是凱撒的。」耶穌說：<span className="woj">「這樣，凱撒的物當歸給凱撒，神的物當歸給神。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 12:12; 馬太福音 22:46; 路加福音 20:25–26"> 他們聽見就稀奇，離開他走了。</span>
</div>
</div>

## 撒都該人辯駁復活之事

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 4:1; 馬可福音 12:18–27; 使徒行傳 23:6–8"> 撒都該人常說沒有復活的事。那天，他們來問耶穌，說：</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 25:5–10; 路加福音 20:28; 路得記 1:11"> 「夫子，摩西說：『人若死了，沒有孩子，他兄弟當娶他的妻，為哥哥生子立後。』</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 馬可福音 12:19–23; 希伯來書 9:27"> 從前在我們這裡有弟兄七人，第一個娶了妻，死了，沒有孩子，撇下妻子給兄弟。</span>
<span className="v" id="v26" data-v="26"> 第二、第三直到第七個，都是如此。</span>
<span className="v" id="v27" data-v="27"> 末後，婦人也死了。</span>
<span className="v" id="v28" data-v="28"> 這樣，當復活的時候，她是七個人中哪一個的妻子呢？因為他們都娶過她。」</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 20:9; 羅馬書 15:4; 路加福音 1:37"> 耶穌回答說：<span className="woj">「你們錯了，因為不明白聖經，也不曉得神的大能。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 馬可福音 12:24–25; 馬太福音 24:38"> <span className="woj">當復活的時候，人也不娶也不嫁，乃像天上的使者一樣。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 12:3; 馬太福音 21:16; 馬太福音 21:42"> <span className="woj">論到死人復活，神在經上向你們所說的，你們沒有念過嗎？</span></span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 3:6; 馬可福音 12:26–27; 路加福音 20:37–38"> <span className="woj">他說：『我是亞伯拉罕的神、以撒的神、雅各的神。』神不是死人的神，乃是活人的神。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 12:17; 馬可福音 6:2; 約翰福音 7:46"> 眾人聽見這話，就稀奇他的教訓。</span>
</div>
</div>

## 最大的誡命

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 12:28–31; 馬太福音 25:3–5; 馬太福音 12:14"> 法利賽人聽見耶穌堵住了撒都該人的口，他們就聚集。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 內中有一個人是律法師，要試探耶穌，就問他說：</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 12:28–33; 馬太福音 5:19–20; 路加福音 11:42"> 「夫子，律法上的誡命哪一條是最大的呢？」</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 12:29–30; 路加福音 10:27; 申命記 6:5"> 耶穌對他說：<span className="woj">「你要盡心、盡性、盡意愛主你的神。</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">這是誡命中的第一，且是最大的。</span></span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 12:31; 路加福音 10:27–37; 利未記 19:18"> <span className="woj">其次也相仿，就是要愛人如己。</span></span>
<span className="v" id="v40" data-v="40" data-xref="羅馬書 13:9; 馬太福音 7:12; 約翰一書 4:19–21"> <span className="woj">這兩條誡命是律法和先知一切道理的總綱。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 馬可福音 12:35–37; 馬太福音 22:34"> 法利賽人聚集的時候，耶穌問他們說：</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 23:5–6; 約翰福音 6:68–69; 馬太福音 16:13–17"> <span className="woj">「論到基督，你們的意見如何？他是誰的子孫呢？」</span>他們回答說：「是大衛的子孫。」</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 23:2; 啟示錄 4:2; 馬可福音 12:36"> 耶穌說：<span className="woj">「這樣，大衛被聖靈感動，怎麼還稱他為主說：</span></span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:1; 希伯來書 1:13; 使徒行傳 2:34–35"> <span className="pl pl-1 woj">『主對我主說：</span><br /><span className="pl pl-1 woj">你坐在我的右邊，</span><br /><span className="pl pl-1 woj">等我把你仇敵放在你的腳下』？</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="羅馬書 1:3–4; 啟示錄 22:16; 約翰福音 8:58"> <span className="woj">大衛既稱他為主，他怎麼又是大衛的子孫呢？」</span></span>
<span className="v" id="v46" data-v="46" data-xref="馬可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 他們沒有一個人能回答一言。從那日以後，也沒有人敢再問他什麼。</span>
</div>

## 登山訓眾論福

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:13; 馬太福音 15:29; 馬可福音 4:1"> 耶穌看見這許多的人，就上了山，既已坐下，門徒到他跟前來，</span>

## 門徒為鹽為光

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 4:6; 路加福音 14:34–35; 馬可福音 9:49–50"> <span className="woj">「你們是世上的鹽。鹽若失了味，怎能叫它再鹹呢？以後無用，不過丟在外面，被人踐踏了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 2:15; 約翰福音 8:12; 以弗所書 5:8–14"> <span className="woj">你們是世上的光。城造在山上，是不能隱藏的。</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:33; 馬可福音 4:21; 路加福音 8:16"> <span className="woj">人點燈，不放在斗底下，是放在燈臺上，就照亮一家的人。</span></span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 2:12; 提多書 2:7; 約翰福音 15:8"> <span className="woj">你們的光也當這樣照在人前，叫他們看見你們的好行為，便將榮耀歸給你們在天上的父。</span></span>
</div>
</div>

## 耶穌來成全律法和先知的道

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 10:4; 路加福音 16:17; 加拉太書 4:4–5"> <span className="woj">「莫想我來要廢掉律法和先知，我來不是要廢掉，乃是要成全。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 16:17; 以賽亞書 40:8; 彼得前書 1:25"> <span className="woj">我實在告訴你們：就是到天地都廢去了，律法的一點一畫也不能廢去，都要成全。</span></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 12:32; 雅各書 2:10–11; 馬太福音 28:20"> <span className="woj">所以，無論何人廢掉這誡命中最小的一條，又教訓人這樣做，他在天國要稱為最小的；但無論何人遵行這誡命，又教訓人遵行，他在天國要稱為大的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 10:2–3; 腓立比書 3:9; 羅馬書 9:30–32"> <span className="woj">我告訴你們：你們的義若不勝於文士和法利賽人的義，斷不能進天國。</span></span>
</div>
</div>

## 論仇恨

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 5:17; 出埃及記 20:13; 民數記 35:30–34"> <span className="woj">「你們聽見有吩咐古人的話說：『不可殺人』，又說：『凡殺人的難免受審判。』</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰一書 3:14–15; 約翰一書 4:20–21; 約翰一書 2:9"> <span className="woj">只是我告訴你們，凡</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在「凡」字下添「無緣無故地」五字。">a</a></sup><span className="woj">向弟兄動怒的，難免受審判；凡罵弟兄是拉加的，難免公會的審斷；凡罵弟兄是魔利的，難免地獄的火。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 11:25; 利未記 6:2–6; 馬太福音 5:24"> <span className="woj">所以，你在祭壇上獻禮物的時候，若想起弟兄向你懷怨，</span></span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 5:16; 羅馬書 12:17–18; 馬太福音 18:15–17"> <span className="woj">就把禮物留在壇前，先去同弟兄和好，然後來獻禮物。</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 12:58–59; 箴言 25:8; 希伯來書 3:13"> <span className="woj">你同告你的對頭還在路上，就趕緊與他和息，恐怕他把你送給審判官，審判官交付衙役，你就下在監裡了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:34; 路加福音 12:59; 帖撒羅尼迦後書 1:9"> <span className="woj">我實在告訴你：若有一文錢沒有還清，你斷不能從那裡出來。</span></span>
</div>
</div>

## 論姦淫

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 5:18; 箴言 6:32; 出埃及記 20:14"> <span className="woj">「你們聽見有話說：『不可姦淫。』</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰一書 2:16; 雅各書 1:14–15; 箴言 6:25"> <span className="woj">只是我告訴你們，凡看見婦女就動淫念的，這人心裡已經與她犯姦淫了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 8:13; 馬可福音 9:43–48; 歌羅西書 3:5"> <span className="woj">若是你的右眼叫你跌倒，就剜出來丟掉！寧可失去百體中的一體，不叫全身丟在地獄裡。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:43; 馬太福音 5:29; 彼得前書 2:8"> <span className="woj">若是右手叫你跌倒，就砍下來丟掉！寧可失去百體中的一體，不叫全身下入地獄。</span></span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 3:1; 申命記 24:1–4; 馬太福音 19:7"> <span className="woj">又有話說：『人若休妻，就當給她休書。』</span></span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 7:3; 哥林多前書 7:10–11; 路加福音 16:18"> <span className="woj">只是我告訴你們，凡休妻的，若不是為淫亂的緣故，就是叫她做淫婦了；人若娶這被休的婦人，也是犯姦淫了。</span></span>
</div>
</div>

<span className="v" id="v34" data-v="34" data-xref="雅各書 5:12; 以賽亞書 66:1; 申命記 23:21–23"> <span className="woj">只是我告訴你們，什麼誓都不可起。不可指著天起誓，因為天是神的座位；</span></span>

<span className="v" id="v36" data-v="36" data-xref="路加福音 12:25; 馬太福音 6:27; 馬太福音 23:16–21"> <span className="woj">又不可指著你的頭起誓，因為你不能使一根頭髮變黑變白了。</span></span>

## 論愛仇敵

<div className="bt">

<span className="v" id="v39" data-v="39" data-xref="帖撒羅尼迦前書 5:15; 彼得前書 3:9; 羅馬書 12:17–19"> <span className="woj">只是我告訴你們，不要與惡人作對。有人打你的右臉，連左臉也轉過來由他打；</span></span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 6:29; 哥林多前書 6:7"> <span className="woj">有人想要告你，要拿你的裡衣，連外衣也由他拿去；</span></span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:26; 馬太福音 27:32; 馬可福音 15:21"> <span className="woj">有人強逼你走一里路，你就同他走二里。</span></span>

## 求主顯神蹟

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:16; 馬太福音 16:6; 使徒行傳 4:1"> 法利賽人和撒都該人來試探耶穌，請他從天上顯個神蹟給他們看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:54–56"> 耶穌回答說：<span className="woj">「晚上天發紅，你們就說『天必要晴』；</span></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 12:56; 歷代志上 12:32; 馬太福音 11:5"> <span className="woj">早晨天發紅，又發黑，你們就說『今日必有風雨』。你們知道分辨天上的氣色，倒不能分辨這時候的神蹟！</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:29–30; 馬太福音 12:39–40; 約拿書 1:17"> <span className="woj">一個邪惡淫亂的世代求神蹟，除了約拿的神蹟以外，再沒有神蹟給他看。」</span>耶穌就離開他們去了。</span>
</div>
</div>

## 防備法利賽人和撒都該人的酵

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬可福音 8:13–14; 馬太福音 15:39"> 門徒渡到那邊去，忘了帶餅。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:1; 加拉太書 5:9; 馬太福音 16:12"> 耶穌對他們說：<span className="woj">「你們要謹慎，防備法利賽人和撒都該人的酵。」</span></span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 8:16–18; 馬太福音 15:16–18; 使徒行傳 10:14"> 門徒彼此議論說：「這是因為我們沒有帶餅吧！」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:30; 馬太福音 14:31; 馬太福音 8:26"> 耶穌看出來，就說：<span className="woj">「你們這小信的人，為什麼因為沒有餅彼此議論呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 14:17–21; 約翰福音 6:9–13; 路加福音 9:13–17"> <span className="woj">你們還不明白嗎？不記得那五個餅分給五千人，又收拾了多少籃子的零碎嗎？</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 15:34–38; 馬可福音 8:17–21; 馬可福音 8:5–9"> <span className="woj">也不記得那七個餅分給四千人，又收拾了多少筐子的零碎嗎？</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 16:6; 路加福音 12:56; 馬可福音 8:21"> <span className="woj">我對你們說要防備法利賽人和撒都該人的酵，這話不是指著餅說的，你們怎麼不明白呢？」</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 5:20; 使徒行傳 23:8; 馬太福音 15:4–9"> 門徒這才曉得他說的不是叫他們防備餅的酵，乃是防備法利賽人和撒都該人的教訓。</span>
</div>
</div>

## 認耶穌為基督

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:18–20; 馬可福音 8:27–29; 但以理書 7:13"> 耶穌到了凱撒利亞-腓立比的境內，就問門徒說：<span className="woj">「人說我</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無「我」字。">a</a></sup><span className="woj">人子是誰？」</span></span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 6:15; 馬太福音 14:2; 瑪拉基書 4:5"> 他們說：「有人說是施洗的約翰，有人說是以利亞，又有人說是耶利米或是先知裡的一位。」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 9:20; 馬太福音 13:11; 馬可福音 8:29"> 耶穌說：<span className="woj">「你們說我是誰？」</span></span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 14:33; 約翰福音 11:27; 約翰一書 4:15"> 西門彼得回答說：「你是基督，是永生神的兒子。」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 6:45; 以弗所書 1:17–18; 馬太福音 11:25–27"> 耶穌對他說：<span className="woj">「西門·巴約拿，你是有福的，因為這不是屬血肉的指示你的，乃是我在天上的父指示的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 2:19–22; 哥林多前書 3:9–11; 以賽亞書 28:16"> <span className="woj">我還告訴你：你是彼得，我要把我的教會建造在這磐石上，陰間的權柄</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「權柄」原文作「門」。">b</a></sup><span className="woj">不能勝過他。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 18:18; 以賽亞書 22:22; 啟示錄 1:18"> <span className="woj">我要把天國的鑰匙給你，凡你在地上所捆綁的，在天上也要捆綁；凡你在地上所釋放的，在天上也要釋放。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 8:30; 路加福音 9:21; 約翰福音 1:41"> 當下，耶穌囑咐門徒，不可對人說他是基督。</span>
</div>
</div>

## 預言受難復活降臨

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 24:6–7; 馬太福音 20:17–19; 馬太福音 17:22–23"> 從此，耶穌才指示門徒，他必須上耶路撒冷去，受長老、祭司長、文士許多的苦，並且被殺，第三日復活。</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 8:32; 約翰福音 13:6–8; 馬太福音 16:16–17"> 彼得就拉著他，勸他說：「主啊，萬不可如此！這事必不臨到你身上。」</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 8:5–8; 歌羅西書 3:2; 腓立比書 3:19"> 耶穌轉過來，對彼得說：<span className="woj">「撒旦，退我後邊去吧！你是絆我腳的，因為你不體貼神的意思，只體貼人的意思。」</span></span>
</div>
</div>

## 當背起自己的十字架跟從主

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:38; 路加福音 14:27; 彼得前書 4:1–2"> 於是，耶穌對門徒說：<span className="woj">「若有人要跟從我，就當捨己，背起他的十字架來跟從我。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 10:39; 馬可福音 8:35; 啟示錄 12:11"> <span className="woj">因為凡要救自己生命</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「生命」或作「靈魂」，下同。">c</a></sup><span className="woj">的，必喪掉生命；凡為我喪掉生命的，必得著生命。</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 8:36–37; 約伯記 27:8; 路加福音 9:25"> <span className="woj">人若賺得全世界，賠上自己的生命，有什麼益處呢？人還能拿什麼換生命呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 5:10; 詩篇 62:12; 羅馬書 2:6"> <span className="woj">人子要在他父的榮耀裡同著眾使者降臨，那時候他要照各人的行為報應各人。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:27; 馬可福音 9:1; 約翰福音 8:52"> <span className="woj">我實在告訴你們：站在這裡的，有人在沒嘗死味以前，必看見人子降臨在他的國裡。」</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 13:1–37; 路加福音 21:5–36; 以西結書 8:6"> 耶穌出了聖殿，正走的時候，門徒進前來，把殿宇指給他看。</span>

## 耶穌降臨的預兆

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬可福音 13:3–4; 使徒行傳 1:7; 帖撒羅尼迦前書 5:1–11"> 耶穌在橄欖山上坐著，門徒暗暗地來，說：「請告訴我們，什麼時候有這些事？你降臨和世界的末了有什麼預兆呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 4:1; 耶利米書 29:8; 帖撒羅尼迦後書 2:3"> 耶穌回答說：<span className="woj">「你們要謹慎，免得有人迷惑你們。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 24:11; 馬太福音 24:24; 耶利米書 14:14"> <span className="woj">因為將來有好些人冒我的名來，說：『我是基督』，並且要迷惑許多人。</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:7–8; 路加福音 21:9; 彼得前書 3:14–15"> <span className="woj">你們也要聽見打仗和打仗的風聲，總不要驚慌，因為這些事是必須有的，只是末期還沒有到。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 啟示錄 6:8; 以賽亞書 19:2"> <span className="woj">民要攻打民，國要攻打國，多處必有饑荒、地震，</span></span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:3; 彼得前書 4:17–18; 申命記 28:59"> <span className="woj">這都是災難</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「災難」原文作「生產之難」。">a</a></sup><span className="woj">的起頭。</span></span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 16:2; 約翰福音 15:19–20; 路加福音 21:16–17"> <span className="woj">那時，人要把你們陷在患難裡，也要殺害你們；你們又要為我的名被萬民恨惡。</span></span>
</div>
</div>

## 忍耐到底必要得救

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彌迦書 7:5–6; 路加福音 21:16; 馬太福音 11:6"> <span className="woj">「那時，必有許多人跌倒，也要彼此陷害、彼此恨惡，</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 24:24; 馬太福音 7:15; 馬太福音 24:5"> <span className="woj">且有好些假先知起來，迷惑多人。</span></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 2:4–5; 雅各書 4:1–4; 啟示錄 3:15"> <span className="woj">只因不法的事增多，許多人的愛心才漸漸冷淡了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 10:22; 馬可福音 13:13; 啟示錄 2:10"> <span className="woj">唯有忍耐到底的，必然得救。</span></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 14:6; 羅馬書 10:18; 羅馬書 16:25–26"> <span className="woj">這天國的福音要傳遍天下，對萬民作見證，然後末期才來到。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 9:27; 但以理書 12:11; 馬可福音 13:14"> <span className="woj">「你們看見先知但以理所說的『那行毀壞可憎的』站在聖地</span>——讀這經的人須要會意——</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:15–17; 路加福音 21:21–22; 希伯來書 11:7"> <span className="woj">那時，在猶太的，應當逃到山上；</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 馬可福音 13:15–16; 馬太福音 10:27"> <span className="woj">在房上的，不要下來拿家裡的東西；</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">在田裡的，也不要回去取衣裳。</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命記 28:53–56; 路加福音 21:23"> <span className="woj">當那些日子，懷孕的和奶孩子的有禍了！</span></span>
</div>
</div>

## 為選民要減少災難的日子

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:29; 使徒行傳 1:12"> <span className="woj">「你們應當祈求，叫你們逃走的時候，不遇見冬天或是安息日。</span></span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 12:1; 約珥書 2:2; 瑪拉基書 4:1"> <span className="woj">因為那時必有大災難，從世界的起頭直到如今沒有這樣的災難，後來也必沒有。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 13:20; 提摩太後書 2:10; 馬太福音 24:31"> <span className="woj">若不減少那日子，凡有血氣的總沒有一個得救的；只是為選民，那日子必減少了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命記 13:1–3"> <span className="woj">那時，若有人對你們說『基督在這裡』，或說『基督在那裡』，你們不要信。</span></span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦後書 2:9–11; 馬可福音 13:22; 啟示錄 13:13–14"> <span className="woj">因為假基督、假先知將要起來，顯大神蹟、大奇事，倘若能行，連選民也就迷惑了。</span></span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:1; 路加福音 21:13; 以賽亞書 48:5–6"> <span className="woj">看哪，我預先告訴你們了！</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以賽亞書 40:3; 馬太福音 3:1"> <span className="woj">若有人對你們說『看哪，基督在曠野裡』，你們不要出去；或說『看哪，基督在內屋中』，你們不要信。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亞書 9:14; 約伯記 37:3"> <span className="woj">閃電從東邊發出，直照到西邊，人子降臨也要這樣。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 約伯記 39:27–30; 申命記 28:49"> <span className="woj">屍首在哪裡，鷹也必聚在那裡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="阿摩司書 8:9; 約珥書 3:15; 以賽亞書 13:10"> <span className="woj">「那些日子的災難一過去，</span><br /><span className="pl pl-1 woj">『日頭就變黑了，</span><br /><span className="pl pl-1 woj">月亮也不放光，</span><br /><span className="pl pl-1 woj">眾星要從天上墜落，</span><br /><span className="pl pl-1 woj">天勢都要震動。』</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="啟示錄 1:7; 但以理書 7:13; 路加福音 21:27"> <span className="woj">那時，人子的兆頭要顯在天上，地上的萬族都要哀哭。他們要看見人子有能力、有大榮耀駕著天上的雲降臨。</span></span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦前書 4:16; 馬可福音 13:27; 以賽亞書 27:13"> <span className="woj">他要差遣使者，用號筒的大聲，將他的選民從四方</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「方」原文作「風」。">b</a></sup><span className="woj">，從天這邊到天那邊，都招聚了來。</span></span>
</div>
</div>

## 從無花果樹學比方

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 13:28–29; 路加福音 21:29–30"> <span className="woj">「你們可以從無花果樹學個比方。當樹枝發嫰長葉的時候，你們就知道夏天近了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 5:9; 希伯來書 10:37; 以西結書 7:2–14"> <span className="woj">這樣，你們看見這一切的事，也該知道人子近了，正在門口了。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 13:30–31; 路加福音 21:32–33; 馬太福音 16:28"> <span className="woj">我實在告訴你們：這世代還沒有過去，這些事都要成就。</span></span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 40:8; 彼得前書 1:25; 民數記 23:19"> <span className="woj">天地要廢去，我的話卻不能廢去。</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 13:32; 使徒行傳 1:7; 馬太福音 24:44"> <span className="woj">但那日子、那時辰，沒有人知道，連天上的使者也不知道，子也不知道，唯獨父知道。</span></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 創世記 6:1–7; 彼得後書 2:5"> <span className="woj">挪亞的日子怎樣，人子降臨也要怎樣。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 羅馬書 13:13–14; 路加福音 14:18–20"> <span className="woj">當洪水以前的日子，人照常吃喝嫁娶</span>，<span className="woj">直到挪亞進方舟的那日，</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 3:20; 馬太福音 24:37; 使徒行傳 13:41"> <span className="woj">不知不覺洪水來了，把他們全都沖去。人子降臨也要這樣。</span></span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得後書 2:7–9; 彼得後書 2:5"> <span className="woj">那時，兩個人在田裡，取去一個，撇下一個；</span></span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 11:5; 以賽亞書 47:2; 路加福音 17:35"> <span className="woj">兩個女人推磨，取去一個，撇下一個。</span></span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒羅尼迦前書 5:6; 馬太福音 25:13"> <span className="woj">所以，你們要警醒，因為不知道你們的主是哪一天來到。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 馬太福音 24:44; 帖撒羅尼迦前書 5:2–6"> <span className="woj">家主若知道幾更天有賊來，就必警醒，不容人挖透房屋，這是你們所知道的。</span></span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 25:10; 馬太福音 24:42; 馬太福音 25:13"> <span className="woj">所以，你們也要預備，因為你們想不到的時候，人子就來了。</span></span>
</div>
</div>

## 善僕與惡僕的報應

<div className="bt">
<div className="bp">

<span className="v" id="v46" data-v="46" data-xref="啟示錄 16:15; 路加福音 12:43; 路加福音 12:37"> <span className="woj">主人來到</span>，<span className="woj">看見他這樣行，那僕人就有福了。</span></span>

## 毋論斷人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 羅馬書 2:1–2; 雅各書 4:11–12"> <span className="woj">「你們不要論斷人，免得你們被論斷。</span></span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 2:13; 馬可福音 4:24; 路加福音 6:38"> <span className="woj">因為你們怎樣論斷人，也必怎樣被論斷；你們用什麼量器量給人，也必用什麼量器量給你們。</span></span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 8:7–9; 加拉太書 6:1; 路加福音 6:41–42"> <span className="woj">為什麼看見你弟兄眼中有刺，卻不想自己眼中有梁木呢？</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">你自己眼中有梁木，怎能對你弟兄說『容我去掉你眼中的刺』呢？</span></span>

</div>

## 求則得之

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 21:22; 約翰一書 3:22; 約翰福音 15:7"> <span className="woj">「你們祈求，就給你們；尋找，就尋見；叩門，就給你們開門。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 81:10; 詩篇 81:16; 路加福音 23:42–43"> <span className="woj">因為凡祈求的，就得著；尋找的，就尋見；叩門的，就給他開門。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:11–13"> <span className="woj">你們中間誰有兒子求餅，反給他石頭呢？</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">求魚，反給他蛇呢？</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 11:11–13; 雅各書 1:17; 羅馬書 8:32"> <span className="woj">你們雖然不好，尚且知道拿好東西給兒女，何況你們在天上的父，豈不更把好東西給求他的人嗎？</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:31; 羅馬書 13:8–10; 加拉太書 5:13–14"> <span className="woj">所以，無論何事，你們願意人怎樣待你們，你們也要怎樣待人，因為這就是律法和先知的道理。</span></span>
</div>
</div>

## 兩種果樹

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰一書 4:1; 彼得後書 2:1–3; 馬太福音 24:11"> <span className="woj">「你們要防備假先知。他們到你們這裡來，外面披著羊皮，裡面卻是殘暴的狼。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:43–45; 馬太福音 12:33; 雅各書 3:12"> <span className="woj">憑著他們的果子就可以認出他們來。荊棘上豈能摘葡萄呢？蒺藜裡豈能摘無花果呢？</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 12:33–35; 加拉太書 5:22–24; 以弗所書 5:9"> <span className="woj">這樣，凡好樹都結好果子，唯獨壞樹結壞果子。</span></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 5:17; 約翰一書 3:9–10"> <span className="woj">好樹不能結壞果子，壞樹不能結好果子。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 3:10; 希伯來書 6:8; 約翰福音 15:2–6"> <span className="woj">凡不結好果子的樹就砍下來，丟在火裡。</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:16; 使徒行傳 5:38"> <span className="woj">所以，憑著他們的果子就可以認出他們來。</span></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 2:13; 路加福音 6:46; 雅各書 1:22"> <span className="woj">凡稱呼我『主啊，主啊』的人不能都進天國，唯獨遵行我天父旨意的人才能進去。</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:25–27; 哥林多前書 13:1–2; 瑪拉基書 3:17–18"> <span className="woj">當那日，必有許多人對我說：『主啊，主啊</span>，<span className="woj">我們不是奉你的名傳道，奉你的名趕鬼，奉你的名行許多異能嗎？』</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 25:41; 詩篇 6:8; 路加福音 13:25"> <span className="woj">我就明明地告訴他們說：『我從來不認識你們。你們這些作惡的人，離開我去吧！』</span></span>
</div>
</div>

## 兩等根基

<div className="bt">
<div className="bp">

<span className="v" id="v25" data-v="25" data-xref="雅各書 1:12; 詩篇 125:1–2; 彼得前書 1:7"> <span className="woj">雨淋，水沖，風吹，撞著那房子，房子總不倒塌，因為根基立在磐石上。</span></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 8:9; 路加福音 6:49; 雅各書 2:20"> <span className="woj">凡聽見我這話不去行的，好比一個無知的人，把房子蓋在沙土上。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 13:19–22; 彼得後書 2:20–22; 哥林多前書 3:13"> <span className="woj">雨淋，水沖，風吹，撞著那房子，房子就倒塌了，並且倒塌得很大。」</span></span>

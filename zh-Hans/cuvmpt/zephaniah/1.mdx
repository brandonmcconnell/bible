## 猶大作惡主必嚴懲

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 1:2; 歷代志下 34:1–33; 彼得後書 1:19"> 當猶大王亞們的兒子約西亞在位的時候，耶和華的話臨到希西家的玄孫、亞瑪利雅的曾孫、基大利的孫子、古示的兒子西番雅。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="彌迦書 7:13; 列王紀下 22:16–17; 以西結書 33:27–29"> 耶和華說：<br /><span className="pl pl-1">「我必從地上除滅萬類。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 4:3; 以西結書 7:19; 耶利米書 12:4"> <span className="pl pl-1">我必除滅人和牲畜，</span><br /><span className="pl pl-1">與空中的鳥、海裡的魚，</span><br /><span className="pl pl-1">以及絆腳石和惡人。</span><br /><span className="pl pl-1">我必將人從地上剪除。」</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 10:5; 彌迦書 5:13; 列王紀下 23:4–5"> <span className="pl pl-1">「我必伸手攻擊猶大</span><br /><span className="pl pl-1">和耶路撒冷的一切居民，</span><br /><span className="pl pl-1">也必從這地方剪除所剩下的巴力，</span><br /><span className="pl pl-1">並基瑪林的名和祭司，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 19:13; 列王紀上 11:33; 列王紀下 17:33"> <span className="pl pl-1">與那些在房頂上敬拜天上萬象的，</span><br /><span className="pl pl-1">並那些敬拜耶和華指著他起誓，</span><br /><span className="pl pl-1">又指著瑪勒堪起誓的，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 1:4; 耶利米書 2:13; 耶利米書 15:6"> <span className="pl pl-1">與那些轉去不跟從耶和華的，</span><br /><span className="pl pl-1">和不尋求耶和華也不訪問他的。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷書 2:20; 撒迦利亞書 2:13; 西番雅書 1:14"> <span className="pl pl-1">你要在主耶和華面前靜默無聲，</span><br /><span className="pl pl-1">因為耶和華的日子快到。</span><br /><span className="pl pl-1">耶和華已經預備祭物，</span><br /><span className="pl pl-1">將他的客分別為聖。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 24:21; 以賽亞書 3:18–24; 耶利米書 22:24–30"> <span className="pl pl-1">「到了我耶和華獻祭的日子，</span><br /><span className="pl pl-1">必懲罰首領和王子，</span><br /><span className="pl pl-1">並一切穿外邦衣服的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 5:5; 阿摩司書 3:10; 撒母耳記上 2:15–16"> <span className="pl pl-1">到那日，我必懲罰一切跳過門檻，</span><br /><span className="pl pl-1">將強暴和詭詐得來之物充滿主人房屋的。」</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 33:14; 阿摩司書 8:3; 列王紀下 22:14"> <span className="pl pl-1">耶和華說：「當那日，</span><br /><span className="pl pl-1">從魚門必發出悲哀的聲音，</span><br /><span className="pl pl-1">從二城發出哀號的聲音，</span><br /><span className="pl pl-1">從山間發出大破裂的響聲。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 5:1; 耶利米書 25:34; 何西阿書 12:7–8"> <span className="pl pl-1">瑪革提施的居民哪，你們要哀號！</span><br /><span className="pl pl-1">因為迦南的商民都滅亡了，</span><br /><span className="pl pl-1">凡搬運銀子的都被剪除。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司書 6:1; 耶利米書 48:11; 以西結書 8:12"> <span className="pl pl-1">那時，我必用燈巡查耶路撒冷，</span><br /><span className="pl pl-1">我必懲罰那些如酒在渣滓上澄清的，</span><br /><span className="pl pl-1">他們心裡說：</span><br /><span className="pl pl-1">『耶和華必不降福，也不降禍。』</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 5:11; 彌迦書 6:15; 申命記 28:30"> <span className="pl pl-1">他們的財寶必成為掠物，</span><br /><span className="pl pl-1">他們的房屋必變為荒場。</span><br /><span className="pl pl-1">他們必建造房屋卻不得住在其內，</span><br /><span className="pl pl-1">栽種葡萄園卻不得喝所出的酒。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 4:5; 以西結書 30:3; 西番雅書 1:7"> <span className="pl pl-1">耶和華的大日臨近，</span><br /><span className="pl pl-1">臨近而且甚快。</span><br /><span className="pl pl-1">乃是耶和華日子的風聲，</span><br /><span className="pl pl-1">勇士必痛痛的哭號。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約珥書 2:2; 以賽亞書 22:5; 啟示錄 6:17"> <span className="pl pl-1">那日是憤怒的日子，</span><br /><span className="pl pl-1">是急難困苦的日子，</span><br /><span className="pl pl-1">是荒廢淒涼的日子，</span><br /><span className="pl pl-1">是黑暗、幽冥、密雲、烏黑的日子，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="何西阿書 8:1; 阿摩司書 3:6; 以賽亞書 32:14"> <span className="pl pl-1">是吹角呐喊的日子，</span><br /><span className="pl pl-1">要攻擊堅固城和高大的城樓。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 3:17; 詩篇 83:10; 耶利米書 2:17"> <span className="pl pl-1">「我必使災禍臨到人身上，</span><br /><span className="pl pl-1">使他們行走如同瞎眼的，</span><br /><span className="pl pl-1">因為得罪了我。</span><br /><span className="pl pl-1">他們的血必倒出如灰塵，</span><br /><span className="pl pl-1">他們的肉必拋棄如糞土。」</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="西番雅書 3:8; 以西結書 7:19; 箴言 11:4"> <span className="pl pl-1">當耶和華發怒的日子，</span><br /><span className="pl pl-1">他們的金銀不能救他們。</span><br /><span className="pl pl-1">他的憤怒如火，必燒滅全地，</span><br /><span className="pl pl-1">毀滅這地的一切居民，而且大大毀滅。</span></span>
</div>

## 論監督當如何為人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多書 1:7; 使徒行傳 20:28; 彼得前書 5:2"> 「人若想要得監督的職分，就是羨慕善工。」這話是可信的。</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 1:6–9; 提摩太後書 2:24; 羅馬書 12:13"> 做監督的，必須無可指責，只做一個婦人的丈夫，有節制，自守，端正，樂意接待遠人，善於教導；</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 1:7; 以弗所書 5:18; 提多書 3:2"> 不因酒滋事，不打人，只要溫和，不爭競，不貪財；</span>
<span className="v" id="v4" data-v="4" data-xref="提多書 1:6; 創世記 18:19; 提摩太前書 3:12"> 好好管理自己的家，使兒女凡事端莊、順服<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：端端莊莊地使兒女順服。">a</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 3:13; 以弗所書 5:24; 使徒行傳 20:28"> 人若不知道管理自己的家，焉能照管神的教會呢？</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 6:4; 希伯來書 5:12–13; 彼得前書 2:2"> 初入教的不可做監督，恐怕他自高自大，就落在魔鬼所受的刑罰裡。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 8:21; 提摩太後書 2:26; 歌羅西書 4:5"> 監督也必須在教外有好名聲，恐怕被人毀謗，落在魔鬼的網羅裡。</span>
</div>
</div>

## 論執事當如何為人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="腓立比書 1:1; 提摩太前書 5:23; 使徒行傳 6:3–6"> 做執事的也是如此，必須端莊，不一口兩舌，不好喝酒，不貪不義之財；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 1:19; 約翰二書 1:9–10; 提摩太前書 1:5"> 要存清潔的良心，固守真道的奧祕。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 5:22; 提摩太前書 3:13; 提多書 1:6–7"> 這等人也要先受試驗，若沒有可責之處，然後叫他們做執事。</span>
<span className="v" id="v11" data-v="11" data-xref="提多書 2:3; 提多書 3:2; 提摩太前書 3:2"> 女執事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：女人。">b</a></sup>也是如此，必須端莊，不說讒言，有節制，凡事忠心。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 3:2; 提摩太前書 3:4–5; 腓立比書 1:1"> 執事只要做一個婦人的丈夫，好好管理兒女和自己的家。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 25:21; 希伯來書 6:10; 使徒行傳 21:35"> 因為善做執事的，自己就得到美好的地步，並且在基督耶穌裡的真道上大有膽量。</span>
</div>
</div>

## 教會是真理的柱石和根基

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 11:34; 腓利門書 1:22; 哥林多後書 1:15–17"> 我指望快到你那裡去，所以先將這些事寫給你；</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 2:5; 以弗所書 2:21–22; 帖撒羅尼迦前書 1:9"> 倘若我耽延日久，你也可以知道在神的家中當怎樣行。這家就是永生神的教會，真理的柱石和根基。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 1:14; 希伯來書 1:3; 馬可福音 16:19"> <span className="pl pl-1">大哉，敬虔的奧祕！</span><br /><span className="pl pl-1">無人不以為然，</span><br /><span className="pl pl-1">就是：神在肉身顯現，</span><br /><span className="pl pl-1">被聖靈稱義</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：在靈性稱義。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">被天使看見，</span><br /><span className="pl pl-1">被傳於外邦，</span><br /><span className="pl pl-1">被世人信服，</span><br /><span className="pl pl-1">被接在榮耀裡。</span></span>
</div>

## 稱為神的兒女是蒙父何等慈愛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 1:12; 加拉太書 3:26; 哥林多後書 6:18"> 你看父賜給我們是何等的慈愛，使我們得稱為神的兒女，我們也真是他的兒女！世人所以不認識我們，是因未曾認識他。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 3:21; 歌羅西書 3:4; 哥林多前書 13:12"> 親愛的弟兄啊，我們現在是神的兒女，將來如何，還未顯明。但我們知道，主若顯現，我們必要像他，因為必得見他的真體。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 7:1; 約翰一書 2:6; 彼得後書 3:14"> 凡向他有這指望的，就潔淨自己，像他潔淨一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 5:17; 羅馬書 3:20; 羅馬書 4:15"> 凡犯罪的，就是違背律法，違背律法就是罪。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:21; 希伯來書 9:28; 彼得前書 3:18"> 你們知道，主曾顯現是要除掉人的罪，在他並沒有罪。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰三書 1:11; 約翰一書 2:4; 約翰一書 3:9"> 凡住在他裡面的，就不犯罪；凡犯罪的，是未曾看見他，也未曾認識他。</span>
</div>
</div>

## 神的兒子要除滅魔鬼所行的事

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 2:29; 彼得前書 1:15–16; 羅馬書 2:13"> 小子們哪，不要被人誘惑。行義的才是義人，正如主是義的一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 2:14; 約翰福音 8:44; 歌羅西書 2:15"> 犯罪的是屬魔鬼，因為魔鬼從起初就犯罪。神的兒子顯現出來，為要除滅魔鬼的作為。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 5:18; 彼得前書 1:23; 約翰福音 1:13"> 凡從神生的，就不犯罪，因神的道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：種。">a</a></sup>存在他心裡；他也不能犯罪，因為他是由神生的。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 4:8; 約翰三書 1:11; 路加福音 6:35"> 從此，就顯出誰是神的兒女，誰是魔鬼的兒女。凡不行義的就不屬神，不愛弟兄的也是如此。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 15:12; 約翰二書 1:5; 約翰一書 4:7"> 我們應當彼此相愛，這就是你們從起初所聽見的命令。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:4; 創世記 4:4–15; 箴言 29:27"> 不可像該隱，他是屬那惡者，殺了他的兄弟。為什麼殺了他呢？因自己的行為是惡的，兄弟的行為是善的。</span>
</div>
</div>

## 沒有愛心的就住在死中

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:18–19; 約翰福音 17:14; 路加福音 21:17"> 弟兄們，世人若恨你們，不要以為稀奇。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 13:35; 約翰一書 5:2; 約翰一書 4:20–21"> 我們因為愛弟兄，就曉得是已經出死入生了。沒有愛心的，仍住在死中。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:21–22; 箴言 26:24–26; 啟示錄 21:8"> 凡恨他弟兄的，就是殺人的；你們曉得，凡殺人的，沒有永生存在他裡面。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰一書 4:9–11; 以弗所書 5:2; 約翰福音 13:34"> 主為我們捨命，我們從此就知道何為愛，我們也當為弟兄捨命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 13:16; 以賽亞書 58:7–10; 申命記 15:7–11"> 凡有世上財物的，看見弟兄窮乏，卻塞住憐恤的心，愛神的心怎能存在他裡面呢？</span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 2:15–16; 羅馬書 12:9; 彼得前書 1:22"> 小子們哪，我們相愛，不要只在言語和舌頭上，總要在行為和誠實上。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 10:22; 約翰一書 3:21; 希伯來書 6:10–11"> 從此，就知道我們是屬真理的，並且我們的心在神面前可以安穩。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 139:1–4; 耶利米書 17:10; 希伯來書 4:13"> 我們的心若責備我們，神比我們的心大，一切事沒有不知道的。</span>
</div>
</div>

## 心若不自責就可以向神坦然無懼

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰一書 2:28; 希伯來書 4:16; 哥林多後書 1:12"> 親愛的弟兄啊，我們的心若不責備我們，就可以向神坦然無懼了。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 15:7; 約翰福音 9:31; 約翰一書 5:14"> 並且我們一切所求的就從他得著，因為我們遵守他的命令，行他所喜悅的事。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 6:29; 約翰福音 13:34; 彼得前書 1:22"> 神的命令就是叫我們信他兒子耶穌基督的名，且照他所賜給我們的命令彼此相愛。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 3:16; 約翰一書 4:15–16; 約翰一書 4:12–13"> 遵守神命令的，就住在神裡面，神也住在他裡面。我們所以知道神住在我們裡面，是因他所賜給我們的聖靈。</span>
</div>
</div>

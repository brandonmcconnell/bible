## 阿摩司預示亞蘭必受主罰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亞書 14:5; 歷代志下 26:1–23; 列王紀上 19:19"> 當猶大王烏西雅、以色列王約阿施的兒子耶羅波安在位的時候，大地震前二年，提哥亞牧人中的阿摩司得默示論以色列。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="約珥書 3:16; 耶利米書 25:30; 阿摩司書 9:3"> 他說：<br /><span className="pl pl-1">耶和華必從錫安吼叫，</span><br /><span className="pl pl-1">從耶路撒冷發聲，</span><br /><span className="pl pl-1">牧人的草場要悲哀，</span><br /><span className="pl pl-1">迦密的山頂要枯乾。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="列王紀下 8:12; 阿摩司書 1:9; 以賽亞書 8:4"> 耶和華如此說：<br /><span className="pl pl-1">「大馬士革三番四次地犯罪，</span><br /><span className="pl pl-1">我必不免去他的刑罰，</span><br /><span className="pl pl-1">因為他以打糧食的鐵器打過基列。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 49:27; 列王紀下 6:24; 列王紀下 13:25"> <span className="pl pl-1">我卻要降火在哈薛的家中，</span><br /><span className="pl pl-1">燒滅便哈達的宮殿。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 16:9; 阿摩司書 9:7; 耶利米書 51:30"> <span className="pl pl-1">我必折斷大馬士革的門閂，</span><br /><span className="pl pl-1">剪除亞文平原的居民和伯伊甸掌權的，</span><br /><span className="pl pl-1">亞蘭人必被擄到吉珥。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
</div>

## 非利士受罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 1:11; 歷代志下 28:18; 俄巴底亞書 1:11"> 耶和華如此說：<br /><span className="pl pl-1">「加沙三番四次地犯罪，</span><br /><span className="pl pl-1">我必不免去他的刑罰，</span><br /><span className="pl pl-1">因為他擄掠眾民交給以東。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 18:8; 耶利米書 47:1; 西番雅書 2:4"> <span className="pl pl-1">我卻要降火在加沙的城內，</span><br /><span className="pl pl-1">燒滅其中的宮殿。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 25:16; 以賽亞書 14:29–31; 耶利米書 47:4–5"> <span className="pl pl-1">我必剪除亞實突的居民和亞實基倫掌權的，</span><br /><span className="pl pl-1">也必反手攻擊以革倫，</span><br /><span className="pl pl-1">非利士人所餘剩的必都滅亡。」</span><br /><span className="pl pl-1">這是主耶和華說的。</span></span>
</div>
</div>

## 推羅受罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:11–14; 以賽亞書 23:1–18; 約珥書 3:4–8"> 耶和華如此說：<br /><span className="pl pl-1">「推羅三番四次地犯罪，</span><br /><span className="pl pl-1">我必不免去他的刑罰，</span><br /><span className="pl pl-1">因為他將眾民交給以東，</span><br /><span className="pl pl-1">並不記念弟兄的盟約。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 9:4; 阿摩司書 1:7; 阿摩司書 1:4"> <span className="pl pl-1">我卻要降火在推羅的城內，</span><br /><span className="pl pl-1">燒滅其中的宮殿。」</span></span>
</div>
</div>

## 以東受罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西結書 25:12–14; 歷代志下 28:17; 瑪拉基書 1:4"> 耶和華如此說：<br /><span className="pl pl-1">「以東三番四次地犯罪，</span><br /><span className="pl pl-1">我必不免去他的刑罰，</span><br /><span className="pl pl-1">因為他拿刀追趕兄弟，毫無憐憫，</span><br /><span className="pl pl-1">發怒撕裂，永懷憤怒。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 49:7; 俄巴底亞書 1:9–10; 耶利米書 49:20"> <span className="pl pl-1">我卻要降火在提幔，</span><br /><span className="pl pl-1">燒滅波斯拉的宮殿。」</span></span>
</div>
</div>

## 亞捫受罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿書 13:16; 以西結書 25:2–7; 耶利米書 49:1–6"> 耶和華如此說：<br /><span className="pl pl-1">「亞捫人三番四次的犯罪，</span><br /><span className="pl pl-1">我必不免去他們的刑罰，</span><br /><span className="pl pl-1">因為他們剖開基列的孕婦，</span><br /><span className="pl pl-1">擴張自己的境界。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 49:2; 阿摩司書 2:2; 申命記 3:11"> <span className="pl pl-1">我卻要在爭戰呐喊的日子，</span><br /><span className="pl pl-1">旋風狂暴的時候，</span><br /><span className="pl pl-1">點火在拉巴的城內，</span><br /><span className="pl pl-1">燒滅其中的宮殿。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 49:3"> <span className="pl pl-1">他們的王和首領必一同被擄去。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
</div>

## 造法櫃

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 25:10–20; 出埃及記 26:33; 民數記 10:33–36"> 比撒列用皂莢木做櫃，長二肘半，寬一肘半，高一肘半，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 30:3"> 裡外包上精金，四圍鑲上金牙邊。</span>
<span className="v" id="v3" data-v="3"> 又鑄四個金環，安在櫃的四腳上，這邊兩環，那邊兩環。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 9:15; 彼得前書 1:7; 民數記 4:14–15"> 用皂莢木做兩根槓，用金包裹。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 4:15; 撒母耳記下 6:3–7; 民數記 1:50"> 把槓穿在櫃旁的環內，以便抬櫃。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 9:5; 提多書 2:14; 羅馬書 3:25"> 用精金做施恩座，長二肘半，寬一肘半。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 10:2; 詩篇 104:4; 詩篇 80:1"> 用金子錘出兩個基路伯來，安在施恩座的兩頭，</span>
<span className="v" id="v8" data-v="8"> 這頭做一個基路伯，那頭做一個基路伯，二基路伯接連一塊，在施恩座的兩頭。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 1:51; 希伯來書 1:14; 創世記 28:12"> 二基路伯高張翅膀，遮掩施恩座，基路伯是臉對臉，朝著施恩座。</span>
</div>
</div>

## 造桌

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 1:14; 以西結書 40:39–42; 瑪拉基書 1:12"> 他用皂莢木做一張桌子，長二肘，寬一肘，高一肘半，</span>
<span className="v" id="v11" data-v="11"> 又包上精金，四圍鑲上金牙邊。</span>
<span className="v" id="v12" data-v="12"> 桌子的四圍各做一掌寬的橫梁，橫梁上鑲著金牙邊。</span>
<span className="v" id="v13" data-v="13"> 又鑄了四個金環，安在桌子四腳的四角上。</span>
<span className="v" id="v14" data-v="14"> 安環子的地方是挨近橫梁，可以穿槓抬桌子。</span>
<span className="v" id="v15" data-v="15"> 他用皂莢木做兩根槓，用金包裹，以便抬桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:29; 列王紀上 7:50; 列王紀下 12:13"> 又用精金做桌子上的器皿，就是盤子，調羹，並奠酒的瓶和爵。</span>
</div>
</div>

## 造燈臺

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 25:31–39; 希伯來書 9:2; 歷代志下 13:11"> 他用精金做一個燈臺，這燈臺的座和幹與杯、球、花，都是接連一塊錘出來的。</span>
<span className="v" id="v18" data-v="18"> 燈臺兩旁杈出六個枝子，這旁三個，那旁三個。</span>
<span className="v" id="v19" data-v="19"> 這旁每枝上有三個杯，形狀像杏花，有球有花；那旁每枝上也有三個杯，形狀像杏花，有球有花。從燈臺杈出來的六個枝子都是如此。</span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 12:5; 耶利米書 1:11; 出埃及記 25:33"> 燈臺上有四個杯，形狀像杏花，有球有花。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 25:35"> 燈臺每兩個枝子以下有球，與枝子接連一塊，燈臺杈出的六個枝子都是如此。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:5; 出埃及記 25:31; 詩篇 51:17"> 球和枝子是接連一塊，都是一塊精金錘出來的。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 1:12; 出埃及記 25:37; 啟示錄 1:20–1"> 用精金做燈臺的七個燈盞，並燈臺的蠟剪和蠟花盤。</span>
<span className="v" id="v24" data-v="24"> 他用精金一他連得做燈臺和燈臺的一切器具。</span>
</div>
</div>

## 造香壇

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:1–5; 希伯來書 7:25; 啟示錄 8:3–4"> 他用皂莢木做香壇，是四方的，長一肘，寬一肘，高二肘，壇的四角與壇接連一塊。</span>
<span className="v" id="v26" data-v="26"> 又用精金把壇的上面與壇的四面並壇的四角包裹，又在壇的四圍鑲上金牙邊。</span>
<span className="v" id="v27" data-v="27"> 做兩個金環，安在牙子邊以下，在壇的兩旁兩根橫撐上，作為穿槓的用處，以便抬壇。</span>
<span className="v" id="v28" data-v="28"> 用皂莢木做槓，用金包裹。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 141:2; 希伯來書 7:25; 約翰一書 2:20"> 又按做香之法做聖膏油和馨香料的淨香。</span>
</div>
</div>

## 杖變蛇為證

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 3:18; 出埃及記 2:14; 耶利米書 1:6"> 摩西回答說：「他們必不信我，也不聽我的話，必說：『耶和華並沒有向你顯現。』」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 4:17; 出埃及記 4:20; 以賽亞書 11:4"> 耶和華對摩西說：「你手裡是什麼？」他說：「是杖。」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:10–15; 阿摩司書 5:19; 出埃及記 4:17"> 耶和華說：「丟在地上。」他一丟下去，就變做蛇，摩西便跑開。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 28:3–6; 創世記 22:1–2; 詩篇 91:13"> 耶和華對摩西說：「伸出手來，拿住牠的尾巴，牠必在你手中仍變為杖。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 19:9; 創世記 48:3; 出埃及記 3:15"> 如此好叫他們信耶和華他們祖宗的神，就是亞伯拉罕的神、以撒的神、雅各的神，是向你顯現了。」</span>
</div>
</div>

## 手生大痲瘋為證

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 5:27; 民數記 12:10"> 耶和華又對他說：「把手放在懷裡。」他就把手放在懷裡，及至抽出來，不料，手長了大痲瘋，有雪那樣白。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 申命記 32:39; 馬太福音 8:3"> 耶和華說：「再把手放在懷裡。」他就再把手放在懷裡，及至從懷裡抽出來，不料，手已經復原，與周身的肉一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:10; 申命記 32:39; 出埃及記 4:30–31"> 又說：「倘或他們不聽你的話，也不信頭一個神蹟，他們必信第二個神蹟。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 7:19–25; 出埃及記 1:22; 馬太福音 7:2"> 這兩個神蹟若都不信，也不聽你的話，你就從河裡取些水，倒在旱地上，你從河裡取的水必在旱地上變做血。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 1:6; 出埃及記 6:12; 使徒行傳 7:22"> 摩西對耶和華說：「主啊，我素日不是能言的人，就是從你對僕人說話以後，也是這樣。我本是拙口笨舌的。」</span>
<span className="v" id="v11" data-v="11" data-xref="阿摩司書 3:6; 詩篇 146:8; 以西結書 3:26–27"> 耶和華對他說：「誰造人的口呢？誰使人口啞、耳聾、目明、眼瞎呢？豈不是我耶和華嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 1:9; 路加福音 12:11–12; 馬太福音 10:19–20"> 現在去吧，我必賜你口才，指教你所當說的話。」</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 1:3; 出埃及記 4:1; 馬太福音 13:41"> 摩西說：「主啊，你願意打發誰，就打發誰去吧！」</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 14:13–15; 出埃及記 4:27; 歷代志上 21:7"> 耶和華向摩西發怒說：「不是有你的哥哥利未人亞倫嗎？我知道他是能言的，現在他出來迎接你，他一見你，心裡就歡喜。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 51:16; 申命記 18:18; 路加福音 21:15"> 你要將當說的話傳給他，我也要賜你和他口才，又要指教你們所當行的事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 7:1–2; 詩篇 82:6; 約翰福音 10:34–35"> 他要替你對百姓說話，你要以他當做口，他要以你當做神。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 4:2; 哥林多前書 1:27; 出埃及記 7:9–20"> 你手裡要拿這杖，好行神蹟。」</span>
</div>
</div>

## 耶和華命摩西行奇事於法老前

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 3:1; 撒母耳記上 1:17; 提摩太前書 6:1"> 於是，摩西回到他岳父葉忒羅那裡，對他說：「求你容我回去見我在埃及的弟兄，看他們還在不在。」葉忒羅對摩西說：「你可以平平安安地去吧。」</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 2:20; 出埃及記 2:23; 出埃及記 2:15"> 耶和華在米甸對摩西說：「你要回埃及去，因為尋索你命的人都死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 17:9; 民數記 20:8–9; 出埃及記 18:3–4"> 摩西就帶著妻子和兩個兒子，叫他們騎上驢，回埃及地去。摩西手裡拿著神的杖。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 9:18; 以賽亞書 63:17; 出埃及記 14:8"> 耶和華對摩西說：「你回到埃及的時候，要留意將我指示你的一切奇事行在法老面前。但我要使<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：任憑。下同。">a</a></sup>他的心剛硬，他必不容百姓去。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 11:1; 羅馬書 9:4; 耶利米書 31:9"> 你要對法老說：『耶和華這樣說：以色列是我的兒子，我的長子。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 11:5; 出埃及記 12:29; 詩篇 135:8"> 我對你說過容我的兒子去，好侍奉我，你還是不肯容他去。看哪，我要殺你的長子。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 17:14; 民數記 22:22–23; 何西阿書 13:8"> 摩西在路上住宿的地方，耶和華遇見他，想要殺他。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 5:2–3; 創世記 17:14; 撒母耳記下 16:7"> 西坡拉就拿一塊火石，割下他兒子的陽皮，丟在摩西腳前，說：「你真是我的血郎了！」</span>
<span className="v" id="v26" data-v="26"> 這樣，耶和華才放了他。西坡拉說：「你因割禮就是血郎了。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:1; 出埃及記 4:14–16; 列王紀上 19:8"> 耶和華對亞倫說：「你往曠野去迎接摩西。」他就去，在神的山遇見摩西，和他親嘴。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 4:8–9; 出埃及記 4:15–16; 馬太福音 21:29"> 摩西將耶和華打發他所說的言語和囑咐他所行的神蹟都告訴了亞倫。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 3:16; 出埃及記 24:11; 出埃及記 24:1"> 摩西、亞倫就去招聚以色列的眾長老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 4:16"> 亞倫將耶和華對摩西所說的一切話述說了一遍，又在百姓眼前行了那些神蹟。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:18; 出埃及記 2:25; 詩篇 106:12–13"> 百姓就信了。以色列人聽見耶和華眷顧他們，鑒察他們的困苦，就低頭下拜。</span>
</div>
</div>

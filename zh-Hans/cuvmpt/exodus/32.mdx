## 亞倫造犢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:40; 申命記 9:9; 出埃及記 24:18"> 百姓見摩西遲延不下山，就大家聚集到亞倫那裡，對他說：「起來，為我們做神像，可以在我們前面引路，因為領我們出埃及地的那個摩西，我們不知道他遭了什麼事。」</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:24–27; 出埃及記 12:35–36; 以西結書 16:17"> 亞倫對他們說：「你們去摘下你們妻子、兒女耳上的金環，拿來給我。」</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 46:6; 以賽亞書 40:19–20; 耶利米書 10:9"> 百姓就都摘下他們耳上的金環，拿來給亞倫。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 9:18; 申命記 9:16; 列王紀上 12:28"> 亞倫從他們手裡接過來，鑄了一隻牛犢，用雕刻的器具做成。他們就說：「以色列啊，這是領你出埃及地的神！」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 10:20; 利未記 23:2; 利未記 23:37"> 亞倫看見，就在牛犢面前築壇，且宣告說：「明日要向耶和華守節。」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:7; 民數記 25:2; 使徒行傳 7:41–42"> 次日清早，百姓起來獻燔祭和平安祭，就坐下吃喝，起來玩耍。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 32:11; 何西阿書 9:9; 士師記 2:19"> 耶和華吩咐摩西說：「下去吧，因為你的百姓，就是你從埃及地領出來的，已經敗壞了。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 12:28; 出埃及記 20:23; 出埃及記 20:3–4"> 他們快快偏離了我所吩咐的道，為自己鑄了一隻牛犢，向它下拜獻祭，說：『以色列啊，這就是領你出埃及地的神！』」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:51; 申命記 9:13; 以賽亞書 48:4"> 耶和華對摩西說：「我看這百姓真是硬著頸項的百姓。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 9:14; 民數記 14:12; 申命記 9:19"> 你且由著我，我要向他們發烈怒，將他們滅絕，使你的後裔成為大國。」</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:18–20; 申命記 9:26–29; 詩篇 106:23"> 摩西便懇求耶和華他的神說：「耶和華啊，你為什麼向你的百姓發烈怒呢？這百姓是你用大力和大能的手從埃及地領出來的。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 14:13–16; 申命記 9:28; 約書亞記 7:9"> 為什麼使埃及人議論說『他領他們出去，是要降禍於他們，把他們殺在山中，將他們從地上除滅』？求你轉意，不發你的烈怒；後悔，不降禍與你的百姓。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 6:13; 創世記 12:7; 創世記 22:16"> 求你記念你的僕人亞伯拉罕、以撒、以色列，你曾指著自己起誓說：『我必使你們的後裔像天上的星那樣多，並且我所應許的這全地，必給你們的後裔，他們要永遠承受為業。』」</span>
<span className="v" id="v14" data-v="14" data-xref="約拿書 3:10; 詩篇 106:45; 耶利米書 26:13"> 於是耶和華後悔，不把所說的禍降於他的百姓。</span>
</div>
</div>

## 摩西怒碎法版

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 9:15; 出埃及記 40:20; 申命記 5:22"> 摩西轉身下山，手裡拿著兩塊法版。這版是兩面寫的，這面那面都有字，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 31:18; 希伯來書 8:10; 申命記 10:1"> 是神的工作，字是神寫的，刻在版上。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 24:13; 出埃及記 17:9; 約書亞記 6:20"> 約書亞一聽見百姓呼喊的聲音，就對摩西說：「在營裡有爭戰的聲音。」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 15:1–18; 但以理書 5:4; 但以理書 5:23"> 摩西說：「這不是人打勝仗的聲音，也不是人打敗仗的聲音，我所聽見的乃是人歌唱的聲音。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 9:16–17; 耶利米書 31:32; 耶利米哀歌 5:15"> 摩西挨近營前，就看見牛犢，又看見人跳舞，便發烈怒，把兩塊版扔在山下摔碎了，</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 9:21; 列王紀下 23:6; 列王紀下 23:15"> 又將他們所鑄的牛犢用火焚燒，磨得粉碎，撒在水面上，叫以色列人喝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 20:9; 約書亞記 7:19–26; 列王紀上 21:22"> 摩西對亞倫說：「這百姓向你做了什麼？你竟使他們陷在大罪裡！」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 9:24; 出埃及記 15:24; 出埃及記 16:20"> 亞倫說：「求我主不要發烈怒。這百姓專於作惡，是你知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 32:1–4; 出埃及記 32:8"> 他們對我說：『你為我們做神像，可以在我們前面引路，因為領我們出埃及地的那個摩西，我們不知道他遭了什麼事。』</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 32:4; 路加福音 10:29; 羅馬書 3:10"> 我對他們說：『凡有金環的，可以摘下來。』他們就給了我，我把金環扔在火中，這牛犢便出來了。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 47:3; 彌迦書 1:11; 啟示錄 16:15"> 摩西見百姓放肆（亞倫縱容他們，使他們在仇敵中間被譏刺），</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 9:32; 馬太福音 12:30; 撒母耳記下 20:11"> 就站在營門中，說：「凡屬耶和華的，都要到我這裡來！」於是利未的子孫都到他那裡聚集。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 25:5; 路加福音 14:26; 申命記 33:8–9"> 他對他們說：「耶和華以色列的神這樣說：『你們各人把刀跨在腰間，在營中往來，從這門到那門，各人殺他的弟兄與同伴並鄰舍。』」</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:9; 瑪拉基書 2:4–6; 哥林多前書 10:8"> 利未的子孫照摩西的話行了。那一天百姓中被殺的約有三千。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 25:11–13; 馬太福音 10:37; 撒迦利亞書 13:3"> 摩西說：「今天你們要自潔，歸耶和華為聖，各人攻擊他的兒子和弟兄，使耶和華賜福於你們。」</span>
</div>
</div>

## 耶和華討民之罪

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 12:20; 民數記 25:13; 列王紀下 17:21"> 到了第二天，摩西對百姓說：「你們犯了大罪，我如今要上耶和華那裡去，或者可以為你們贖罪。」</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 20:23; 但以理書 9:11; 但以理書 9:8"> 摩西回到耶和華那裡，說：「唉！這百姓犯了大罪，為自己做了金像。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 69:28; 羅馬書 9:3; 啟示錄 21:27"> 倘或你肯赦免他們的罪——不然，求你從你所寫的冊上塗抹我的名。」</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 29:20; 以西結書 18:4; 啟示錄 20:12"> 耶和華對摩西說：「誰得罪我，我就從我的冊上塗抹誰的名。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 23:20; 申命記 32:35; 馬太福音 23:35"> 現在你去領這百姓，往我所告訴你的地方去，我的使者必在你前面引路，只是到我追討的日子，我必追討他們的罪。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 7:41; 出埃及記 32:25; 撒母耳記下 12:9–10"> 耶和華殺百姓的緣故是因他們同亞倫做了牛犢。</span>
</div>
</div>

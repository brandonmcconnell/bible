## 造祭壇之法則

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 38:1–7; 出埃及記 20:24–26; 出埃及記 40:10"> 「你要用皂莢木做壇。這壇要四方的，長五肘，寬五肘，高三肘。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:27; 出埃及記 29:12; 利未記 4:7"> 要在壇的四拐角上做四個角，與壇接連一塊，用銅把壇包裹。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 7:45; 民數記 4:14; 歷代志上 28:17"> 要做盆，收去壇上的灰，又做鏟子、盤子、肉叉子、火鼎，壇上一切的器具都用銅做。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 35:16; 出埃及記 25:12; 出埃及記 38:4–5"> 要為壇做一個銅網，在網的四角上做四個銅環，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 38:4"> 把網安在壇四面的圍腰板以下，使網從下達到壇的半腰。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 35:13–15; 民數記 4:44; 出埃及記 30:4"> 又要用皂莢木為壇做槓，用銅包裹。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 25:28; 出埃及記 30:4; 民數記 4:13–14"> 這槓要穿在壇兩旁的環子內，用以抬壇。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 25:40; 出埃及記 25:9; 希伯來書 8:5"> 要用板做壇，壇是空的，都照著在山上指示你的樣式做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 38:9–20; 以西結書 40:32; 以西結書 42:3"> 「你要做帳幕的院子。院子的南面要用撚的細麻做帷子，長一百肘。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 26:19–21; 耶利米書 52:21; 出埃及記 36:38"> 帷子的柱子要二十根，帶卯的銅座二十個，柱子上的鉤子和杆子都要用銀子做。</span>
<span className="v" id="v11" data-v="11"> 北面也當有帷子，長一百肘，帷子的柱子二十根，帶卯的銅座二十個，柱子上的鉤子和杆子都要用銀子做。</span>
<span className="v" id="v12" data-v="12"> 院子的西面當有帷子，寬五十肘，帷子的柱子十根，帶卯的座十個。</span>
<span className="v" id="v13" data-v="13"> 院子的東面要寬五十肘。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:9; 出埃及記 26:36"> 門這邊的帷子要十五肘，帷子的柱子三根，帶卯的座三個。</span>
<span className="v" id="v15" data-v="15"> 門那邊的帷子也要十五肘，帷子的柱子三根，帶卯的座三個。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 26:36; 士師記 5:30; 出埃及記 28:39"> 院子的門當有簾子，長二十肘，要拿藍色、紫色、朱紅色線和撚的細麻，用繡花的手工織成，柱子四根，帶卯的座四個。</span>
<span className="v" id="v17" data-v="17"> 院子四圍一切的柱子都要用銀杆連絡，柱子上的鉤子要用銀做，帶卯的座要用銅做。</span>
<span className="v" id="v18" data-v="18"> 院子要長一百肘，寬五十肘，高五肘，帷子要用撚的細麻做，帶卯的座要用銅做。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 35:18; 以賽亞書 22:23–25; 民數記 4:32"> 帳幕各樣用處的器具，並帳幕一切的橛子，和院子裡一切的橛子，都要用銅做。</span>
</div>
</div>

## 燃燈之例

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未記 24:1–4; 撒迦利亞書 4:11–14; 詩篇 23:5"> 「你要吩咐以色列人，把那為點燈搗成的清橄欖油拿來給你，使燈常常點著。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 19:21; 民數記 18:23; 撒母耳記上 3:3"> 在會幕中法櫃前的幔外，亞倫和他的兒子，從晚上到早晨，要在耶和華面前經理這燈。這要做以色列人世世代代永遠的定例。</span>

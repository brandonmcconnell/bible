## 法老追襲以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:1; 出埃及記 13:1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 33:7–8; 耶利米書 44:1; 出埃及記 13:17–18"> 「你吩咐以色列人轉回，安營在比哈希錄前、密奪和海的中間，對著巴力洗分，靠近海邊安營。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 4:28; 撒母耳記上 23:23; 詩篇 71:11"> 法老必說：『以色列人在地中繞迷了，曠野把他們困住了。』</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:22–23; 出埃及記 7:5; 羅馬書 9:17"> 我要使法老的心剛硬，他要追趕他們，我便在法老和他全軍身上得榮耀，埃及人就知道我是耶和華。」於是以色列人這樣行了。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 105:25; 出埃及記 12:33; 路加福音 11:24–26"> 有人告訴埃及王說：「百姓逃跑！」法老和他的臣僕就向百姓變心，說：「我們容以色列人去，不再服侍我們，這做的是什麼事呢？」</span>
<span className="v" id="v6" data-v="6"> 法老就預備他的車輛，帶領軍兵同去，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 15:4; 士師記 4:3; 詩篇 68:17"> 並帶著六百輛特選的車和埃及所有的車，每輛都有車兵長。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:17; 民數記 33:3; 申命記 26:8"> 耶和華使埃及王法老的心剛硬，他就追趕以色列人，因為以色列人是昂然無懼地出埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 15:9; 約書亞記 24:6; 出埃及記 14:2"> 埃及人追趕他們，法老一切的馬匹、車輛、馬兵與軍兵就在海邊上，靠近比哈希錄，對著巴力洗分，在他們安營的地方追上了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:7; 詩篇 34:17; 尼希米記 9:9"> 法老臨近的時候，以色列人舉目看見埃及人趕來，就甚懼怕，向耶和華哀求。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:7–8; 民數記 14:1–4; 出埃及記 15:23–24"> 他們對摩西說：「難道在埃及沒有墳地，你把我們帶來死在曠野嗎？你為什麼這樣待我們，將我們從埃及領出來呢？</span>
<span className="v" id="v12" data-v="12" data-xref="約拿書 4:3; 出埃及記 6:9; 約拿書 4:8"> 我們在埃及豈沒有對你說過，不要攪擾我們，容我們服侍埃及人嗎？因為服侍埃及人比死在曠野還好。」</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 20:17; 歷代志下 20:15; 出埃及記 14:30"> 摩西對百姓說：「不要懼怕，只管站住，看耶和華今天向你們所要施行的救恩。因為你們今天所看見的埃及人，必永遠不再看見了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 3:22; 申命記 20:4; 歷代志下 20:17"> 耶和華必為你們爭戰，你們只管靜默，不要作聲。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 7:10; 以斯拉記 10:4–5; 尼希米記 9:9"> 耶和華對摩西說：「你為什麼向我哀求呢？你吩咐以色列人往前走。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 7:19; 出埃及記 4:20; 出埃及記 4:2"> 你舉手向海伸杖，把水分開，以色列人要下海中走乾地。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:8; 出埃及記 14:4; 以西結書 34:11"> 我要使埃及人的心剛硬，他們就跟著下去，我要在法老和他的全軍、車輛、馬兵上得榮耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:5; 出埃及記 14:4; 出埃及記 7:17"> 我在法老和他的車輛、馬兵上得榮耀的時候，埃及人就知道我是耶和華了。」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 63:9; 出埃及記 32:34; 出埃及記 23:20–21"> 在以色列營前行走神的使者，轉到他們後邊去，雲柱也從他們前邊轉到他們後邊立住。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:14; 哥林多後書 2:15–16; 箴言 4:18–19"> 在埃及營和以色列營中間有雲柱，一邊黑暗，一邊發光，終夜兩下不得相近。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 63:12; 出埃及記 15:8; 詩篇 66:6"> 摩西向海伸杖，耶和華便用大東風使海水一夜退去，水便分開，海就成了乾地。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:29; 詩篇 66:6; 出埃及記 15:19"> 以色列人下海中走乾地，水在他們的左右做了牆垣。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 15:19; 出埃及記 14:17; 出埃及記 15:9"> 埃及人追趕他們，法老一切的馬匹、車輛和馬兵都跟著下到海中。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 13:21; 詩篇 77:16–19; 出埃及記 14:25"> 到了晨更的時候，耶和華從雲火柱中向埃及的軍兵觀看，使埃及的軍兵混亂了，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 14:14; 申命記 3:22; 約伯記 20:24"> 又使他們的車輪脫落，難以行走，以致埃及人說：「我們從以色列人面前逃跑吧！因耶和華為他們攻擊我們了。」</span>
</div>
</div>

## 投埃及人於海

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 14:16; 出埃及記 8:5; 雅各書 2:13"> 耶和華對摩西說：「你向海伸杖，叫水仍合在埃及人並他們的車輛、馬兵身上。」</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 4:18; 詩篇 78:53; 希伯來書 11:29"> 摩西就向海伸杖，到了天一亮，海水仍舊復原。埃及人避水逃跑的時候，耶和華把他們推翻在海中，</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:53; 詩篇 106:9–11; 哈巴谷書 3:13"> 水就回流，淹沒了車輛和馬兵。那些跟著以色列人下海法老的全軍，連一個也沒有剩下。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 14:22; 詩篇 77:19–20; 以賽亞書 43:2"> 以色列人卻在海中走乾地，水在他們的左右做了牆垣。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 106:8; 詩篇 106:10; 詩篇 92:9–11"> 當日，耶和華這樣拯救以色列人脫離埃及人的手，以色列人看見埃及人的死屍都在海邊了。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 2:11; 約翰福音 11:45; 約翰福音 2:23–25"> 以色列人看見耶和華向埃及人所行的大事，就敬畏耶和華，又信服他和他的僕人摩西。</span>
</div>
</div>

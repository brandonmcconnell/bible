<span className="v" id="v4" data-v="4"> 但、拿弗他利、迦得、亞設。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:22; 創世記 46:26–27; 士師記 8:30"> 凡從雅各而生的，共有七十人。約瑟已經在埃及。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 50:26; 創世記 50:24; 使徒行傳 7:14–16"> 約瑟和他的弟兄，並那一代的人都死了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:3; 創世記 1:28; 申命記 26:5"> 以色列人生養眾多，並且繁茂，極其強盛，滿了那地。</span>

## 埃及新王虐待以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 7:18; 傳道書 2:18–19; 傳道書 9:15"> 有不認識約瑟的新王起來，治理埃及，</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 105:24–25; 傳道書 4:4; 雅各書 3:14–16"> 對他的百姓說：「看哪，這以色列民比我們還多，又比我們強盛。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 7:19; 詩篇 83:3–4; 箴言 1:11"> 來吧，我們不如用巧計待他們，恐怕他們多起來，日後若遇什麼爭戰的事，就聯合我們的仇敵攻擊我們，離開這地去了。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 15:13; 創世記 47:11; 出埃及記 3:7"> 於是埃及人派督工的轄制他們，加重擔苦害他們。他們為法老建造兩座積貨城，就是比東和蘭塞。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 105:24; 出埃及記 1:9; 羅馬書 8:28"> 只是越發苦害他們，他們越發多起來，越發蔓延，埃及人就因以色列人愁煩。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:20"> 埃及人嚴嚴地使以色列人做工，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 7:19; 民數記 20:15; 出埃及記 2:23"> 使他們因做苦工覺得命苦。無論是和泥，是做磚，是做田間各樣的工，在一切的工上都嚴嚴地待他們。</span>
</div>
</div>

## 收生者敬畏神存留男子

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 有希伯來的兩個收生婆，一名施弗拉，一名普阿。埃及王對她們說：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 1:22; 馬太福音 21:38; 啟示錄 12:4"> 「你們為希伯來婦人收生，看她們臨盆的時候，若是男孩，就把他殺了，若是女孩，就留她存活。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:29; 出埃及記 1:21; 馬太福音 10:28"> 但是收生婆敬畏神，不照埃及王的吩咐行，竟存留男孩的性命。</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 8:4; 撒母耳記下 13:28"> 埃及王召了收生婆來，說：「你們為什麼做這事，存留男孩的性命呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 2:4–24; 撒母耳記下 17:19–20; 撒母耳記上 21:2"> 收生婆對法老說：「因為希伯來婦人與埃及婦人不同，希伯來婦人本是健壯的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：活潑的。">a</a></sup>，收生婆還沒有到，她們已經生產了。」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 3:10; 傳道書 8:12; 箴言 11:18"> 神厚待收生婆。以色列人多起來，極其強盛。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 11:38; 撒母耳記上 2:35; 詩篇 37:3"> 收生婆因為敬畏神，神便叫她們成立家室。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 7:19; 箴言 1:16; 出埃及記 1:16"> 法老吩咐他的眾民說：「以色列人所生的男孩，你們都要丟在河裡；一切的女孩，你們要存留她的性命。」</span>
</div>
</div>

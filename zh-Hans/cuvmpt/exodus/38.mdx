## 造祭壇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 27:1–8; 以西結書 43:13–17; 出埃及記 40:6"> 他用皂莢木做燔祭壇，是四方的，長五肘，寬五肘，高三肘。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 27:2; 約伯記 6:12"> 在壇的四拐角上做四個角，與壇接連一塊，用銅把壇包裹。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 27:3; 撒母耳記上 2:13"> 他做壇上的盆、鏟子、盤子、肉叉子、火鼎，這一切器具都是用銅做的。</span>
<span className="v" id="v4" data-v="4"> 又為壇做一個銅網，安在壇四面的圍腰板以下，從下達到壇的半腰。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 27:4"> 為銅網的四角鑄四個環子，作為穿槓的用處。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:3; 出埃及記 25:6"> 用皂莢木做槓，用銅包裹，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 9:15; 哥林多前書 2:2; 哥林多前書 1:24"> 把槓穿在壇兩旁的環子內，用以抬壇；並用板做壇，壇是空的。</span>
</div>
</div>

## 立幕院

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 27:9–19; 詩篇 89:7; 列王紀上 6:36"> 他做帳幕的院子。院子的南面用撚的細麻做帷子，寬一百肘。</span>
<span className="v" id="v10" data-v="10"> 帷子的柱子二十根，帶卯的銅座二十個，柱子上的鉤子和杆子都是用銀子做的。</span>
<span className="v" id="v11" data-v="11"> 北面也有帷子，寬一百肘。帷子的柱子二十根，帶卯的銅座二十個，柱子上的鉤子和杆子都是用銀子做的。</span>
<span className="v" id="v12" data-v="12"> 院子的西面有帷子，寬五十肘。帷子的柱子十根，帶卯的座十個，柱子的鉤子和杆子都是用銀子做的。</span>
<span className="v" id="v13" data-v="13"> 院子的東面，寬五十肘。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:14"> 門這邊的帷子十五肘，那邊也是一樣。帷子的柱子三根，帶卯的座三個。在門的左右各有帷子十五肘，帷子的柱子三根，帶卯的座三個。</span>
<span className="v" id="v16" data-v="16"> 院子四面的帷子都是用撚的細麻做的。</span>
<span className="v" id="v17" data-v="17"> 柱子帶卯的座是銅的，柱子上的鉤子和杆子是銀的，柱頂是用銀子包的。院子一切的柱子都是用銀杆連絡的。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 3:14"> 院子的門簾是以繡花的手工，用藍色、紫色、朱紅色線和撚的細麻織的，寬二十肘，高五肘，與院子的帷子相配。</span>
<span className="v" id="v19" data-v="19"> 帷子的柱子四根，帶卯的銅座四個，柱子上的鉤子和杆子是銀的，柱頂是用銀子包的。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 3:9; 出埃及記 27:19; 以弗所書 2:21–22"> 帳幕一切的橛子和院子四圍的橛子都是銅的。</span>
</div>
</div>

## 核記民獻金銀銅之數

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 7:44; 民數記 9:15; 歷代志下 24:6"> 這是法櫃的帳幕中利未人所用物件的總數，是照摩西的吩咐，經祭司亞倫的兒子以他瑪的手數點的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 35:30–3; 出埃及記 31:1–5; 詩篇 119:6"> 凡耶和華所吩咐摩西的，都是猶大支派戶珥的孫子、烏利的兒子比撒列做的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 35:34; 出埃及記 31:6"> 與他同工的有但支派中亞希撒抹的兒子亞何利亞伯，他是雕刻匠，又是巧匠，又能用藍色、紫色、朱紅色線和細麻繡花。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 18:16; 民數記 3:47; 利未記 27:25"> 為聖所一切工作使用所獻的金子，按聖所的平，有二十九他連得並七百三十舍客勒。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:12"> 會中被數的人所出的銀子，按聖所的平，有一百他連得並一千七百七十五舍客勒。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:46; 出埃及記 30:13; 出埃及記 12:37"> 凡過去歸那些被數之人的，從二十歲以外，有六十萬零三千五百五十人，按聖所的平，每人出銀半舍客勒，就是一比加。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 26:19; 出埃及記 26:25; 出埃及記 26:21"> 用那一百他連得銀子鑄造聖所帶卯的座和幔子柱子帶卯的座，一百他連得共一百帶卯的座，每帶卯的座用一他連得。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 27:17"> 用那一千七百七十五舍客勒銀子做柱子上的鉤子，包裹柱頂並柱子上的杆子。</span>
<span className="v" id="v29" data-v="29"> 所獻的銅有七十他連得並二千四百舍客勒。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 26:37; 出埃及記 27:17; 出埃及記 27:10"> 用這銅做會幕門帶卯的座和銅壇，並壇上的銅網和壇的一切器具，</span>
<span className="v" id="v31" data-v="31"> 並院子四圍帶卯的座和院門帶卯的座，與帳幕一切的橛子和院子四圍所有的橛子。</span>
</div>
</div>

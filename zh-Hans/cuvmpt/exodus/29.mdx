## 示以立亞倫及其子為祭司當獻之物當行之禮

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 4:3; 瑪拉基書 1:13–14; 出埃及記 12:5"> 「你使亞倫和他兒子成聖，給我供祭司的職分，要如此行。取一隻公牛犢，兩隻無殘疾的公綿羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 6:15; 利未記 2:15; 利未記 7:12"> 無酵餅和調油的無酵餅，與抹油的無酵薄餅，這都要用細麥麵做成。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 6:17; 利未記 8:26; 利未記 8:2"> 這餅要裝在一個筐子裡，連筐子帶來，又把公牛和兩隻公綿羊牽來。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 40:12; 希伯來書 10:22; 出埃及記 26:36"> 要使亞倫和他兒子到會幕門口來，用水洗身。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 28:2–8; 利未記 8:7–8"> 要給亞倫穿上內袍和以弗得的外袍並以弗得，又戴上胸牌，束上以弗得巧工織的帶子。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 8:9; 出埃及記 28:36–39"> 把冠冕戴在他頭上，將聖冠加在冠冕上，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 35:25; 利未記 21:10; 約翰福音 3:34"> 就把膏油倒在他頭上膏他。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 8:13; 出埃及記 28:40"> 要叫他的兒子來，給他們穿上內袍。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 18:7; 利未記 8:22–28; 申命記 18:5"> 給亞倫和他兒子束上腰帶，包上裹頭巾，他們就憑永遠的定例得了祭司的職任。又要將亞倫和他兒子分別為聖。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 1:4; 利未記 8:14; 出埃及記 29:15"> 「你要把公牛牽到會幕前，亞倫和他兒子要按手在公牛的頭上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 9:8; 利未記 9:12; 出埃及記 29:4"> 你要在耶和華面前，在會幕門口，宰這公牛。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 27:2; 利未記 9:9; 利未記 8:15"> 要取些公牛的血，用指頭抹在壇的四角上，把血都倒在壇腳那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 3:3–4; 撒母耳記上 2:16; 利未記 9:10"> 要把一切蓋臟的脂油與肝上的網子，並兩個腰子和腰子上的脂油，都燒在壇上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 4:11–12; 利未記 4:21; 出埃及記 30:10"> 只是公牛的皮、肉、糞都要用火燒在營外。這牛是贖罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 29:19; 出埃及記 29:3; 利未記 8:18–21"> 「你要牽一隻公綿羊來，亞倫和他兒子要按手在這羊的頭上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 29:11–12"> 要宰這羊，把血灑在壇的周圍。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 4:14; 利未記 1:13; 利未記 1:9"> 要把羊切成塊子，洗淨五臟和腿，連塊子帶頭，都放在一處。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 8:21; 腓立比書 4:18; 創世記 22:7"> 要把全羊燒在壇上，是給耶和華獻的燔祭，是獻給耶和華為馨香的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 29:3; 利未記 8:22–29"> 「你要將那一隻公綿羊牽來，亞倫和他兒子要按手在羊的頭上。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 50:5; 希伯來書 10:22; 利未記 14:16"> 你要宰這羊，取點血抹在亞倫的右耳垂上和他兒子的右耳垂上，又抹在他們右手的大拇指上和右腳的大拇指上，並要把血灑在壇的四圍。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 9:22; 出埃及記 29:7; 出埃及記 29:1"> 你要取點膏油和壇上的血，彈在亞倫和他的衣服上，並他兒子和他兒子的衣服上，他們和他們的衣服就一同成聖。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:13; 利未記 9:21; 利未記 9:19"> 你要取這羊的脂油和肥尾巴，並蓋臟的脂油與肝上的網子，兩個腰子和腰子上的脂油並右腿，這是承接聖職所獻的羊。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:2–3; 利未記 8:26"> 再從耶和華面前裝無酵餅的筐子中取一個餅，一個調油的餅和一個薄餅，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 7:30; 利未記 8:27; 利未記 9:21"> 都放在亞倫的手上和他兒子的手上，作為搖祭，在耶和華面前搖一搖。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:28; 出埃及記 29:41; 利未記 3:16"> 要從他們手中接過來，燒在耶和華面前壇上的燔祭上，是獻給耶和華為馨香的火祭。</span>
</div>
</div>

## 祭司當得之份

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未記 8:29; 利未記 7:31; 利未記 7:34"> 「你要取亞倫承接聖職所獻公羊的胸，作為搖祭，在耶和華面前搖一搖，這就可以做你的份。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 10:15; 民數記 18:11; 申命記 18:3"> 那搖祭的胸和舉祭的腿，就是承接聖職所搖的、所舉的，是歸亞倫和他兒子的。這些你都要成為聖，</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 15:19–20; 利未記 7:11–38; 利未記 10:14–15"> 做亞倫和他子孫從以色列人中永遠所得的份，因為是舉祭。這要從以色列人的平安祭中，作為獻給耶和華的舉祭。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 18:8; 出埃及記 28:3–4; 出埃及記 30:30"> 「亞倫的聖衣要留給他的子孫，可以穿著受膏，又穿著承接聖職。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 20:28; 利未記 13:5; 使徒行傳 20:6–7"> 他的子孫接續他當祭司的，每逢進會幕在聖所供職的時候，要穿七天。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 8:31; 撒母耳記上 2:13; 以西結書 46:20–24"> 「你要將承接聖職所獻公羊的肉煮在聖處。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 12:4; 出埃及記 29:23; 出埃及記 29:2–3"> 亞倫和他兒子要在會幕門口吃這羊的肉和筐內的餅。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 18:4; 利未記 10:13–18; 詩篇 22:26"> 他們吃那些贖罪之物，好承接聖職，使他們成聖；只是外人不可吃，因為這是聖物。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 12:10; 利未記 8:32; 出埃及記 29:22"> 那承接聖職所獻的肉或餅，若有一點留到早晨，就要用火燒了，不可吃這物，因為是聖物。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及記 29:30; 利未記 14:8–11; 利未記 8:4–36"> 「你要這樣照我一切所吩咐的，向亞倫和他兒子行承接聖職的禮七天。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 10:11; 希伯來書 9:22–23; 出埃及記 30:28–29"> 每天要獻公牛一隻為贖罪祭。你潔淨壇的時候，壇就潔淨了，且要用膏抹壇，使壇成聖。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 40:10; 馬太福音 23:19; 出埃及記 30:28–29"> 要潔淨壇七天，使壇成聖，壇就成為至聖。凡挨著壇的都成為聖。</span>
</div>
</div>

## 每日當獻之祭

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志下 2:4; 歷代志上 16:40; 民數記 28:3–8"> 「你每天所要獻在壇上的就是兩隻一歲的羊羔，</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 46:13–15; 列王紀下 16:15; 詩篇 5:3"> 早晨要獻這一隻，黃昏的時候要獻那一隻。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 2:17; 以西結書 46:14; 約珥書 2:14"> 和這一隻羊羔同獻的，要用細麵伊法十分之一與搗成的油一欣四分之一調和，又用酒一欣四分之一作為奠祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 46:13–15; 列王紀上 18:29; 詩篇 141:2"> 那一隻羊羔要在黃昏的時候獻上，照著早晨的素祭和奠祭的禮辦理，作為獻給耶和華馨香的火祭。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及記 25:22"> 這要在耶和華面前，會幕門口，做你們世世代代常獻的燔祭。我要在那裡與你們相會，和你們說話。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 8:11; 歷代志下 7:1–3; 瑪拉基書 3:1"> 我要在那裡與以色列人相會，會幕就要因我的榮耀成為聖。</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 21:15; 利未記 22:9; 利未記 22:16"> 我要使會幕和壇成聖，也要使亞倫和他的兒子成聖，給我供祭司的職分。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 26:12; 哥林多後書 6:16; 出埃及記 25:8"> 我要住在以色列人中間，做他們的神。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 20:2; 耶利米書 31:33; 以西結書 20:5"> 他們必知道我是耶和華他們的神，是將他們從埃及地領出來的，為要住在他們中間。我是耶和華他們的神。</span>
</div>
</div>

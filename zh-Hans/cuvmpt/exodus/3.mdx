## 耶和華顯現於荊棘火中

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 19:8; 出埃及記 17:6; 詩篇 78:70–72"> 摩西牧養他岳父米甸祭司葉忒羅的羊群，一日領羊群往野外去，到了神的山，就是何烈山。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:30–35; 以賽亞書 43:2; 馬可福音 12:26"> 耶和華的使者從荊棘裡火焰中向摩西顯現。摩西觀看，不料，荊棘被火燒著，卻沒有燒毀。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 7:31; 詩篇 107:8; 約伯記 37:14"> 摩西說：「我要過去看這大異象，這荊棘為何沒有燒壞呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 33:16; 撒母耳記上 3:6; 使徒行傳 9:4"> 耶和華神見他過去要看，就從荊棘裡呼叫說：「摩西！摩西！」他說：「我在這裡。」</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:15; 使徒行傳 7:33; 出埃及記 19:12"> 神說：「不要近前來。當把你腳上的鞋脫下來，因為你所站之地是聖地。」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:37; 馬太福音 22:32; 出埃及記 4:5"> 又說：「我是你父親的神，是亞伯拉罕的神、以撒的神、雅各的神。」摩西蒙上臉，因為怕看神。</span>
</div>
</div>

## 遣摩西領以色列人出埃及

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:19; 詩篇 106:44; 出埃及記 2:23–25"> 耶和華說：「我的百姓在埃及所受的困苦，我實在看見了；他們因受督工的轄制所發的哀聲，我也聽見了。我原知道他們的痛苦。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 50:24; 創世記 15:18–21; 出埃及記 3:17"> 我下來是要救他們脫離埃及人的手，領他們出了那地，到美好寬闊、流奶與蜜之地，就是到迦南人、赫人、亞摩利人、比利洗人、希未人、耶布斯人之地。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 22:22–23; 出埃及記 2:23; 出埃及記 1:13–14"> 現在以色列人的哀聲達到我耳中，我也看見埃及人怎樣欺壓他們。</span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 6:4; 撒母耳記上 12:6; 詩篇 105:26"> 故此，我要打發你去見法老，使你可以將我的百姓以色列人從埃及領出來。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 18:18; 哥林多後書 3:5; 出埃及記 6:12"> 摩西對神說：「我是什麼人？竟能去見法老，將以色列人從埃及領出來呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 1:5; 羅馬書 8:31; 以賽亞書 41:10"> 神說：「我必與你同在。你將百姓從埃及領出來之後，你們必在這山上侍奉我，這就是我打發你去的證據。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 以賽亞書 9:6; 耶利米書 23:6"> 摩西對神說：「我到以色列人那裡，對他們說：『你們祖宗的神打發我到你們這裡來。』他們若問我說：『他叫什麼名字？』我要對他們說什麼呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 8:58; 希伯來書 13:8; 啟示錄 1:8"> 神對摩西說：「我是自有永有的。」又說：「你要對以色列人這樣說：『那自有的打發我到你們這裡來。』」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:7–8; 希伯來書 13:8; 瑪拉基書 3:6"> 神又對摩西說：「你要對以色列人這樣說：『耶和華你們祖宗的神，就是亞伯拉罕的神、以撒的神、雅各的神，打發我到你們這裡來。』耶和華是我的名，直到永遠；這也是我的紀念，直到萬代。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:4; 出埃及記 4:31; 出埃及記 4:29"> 你去招聚以色列的長老，對他們說：『耶和華你們祖宗的神，就是亞伯拉罕的神、以撒的神、雅各的神，向我顯現，說：我實在眷顧了你們，我也看見埃及人怎樣待你們。』</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:13–21; 創世記 50:24; 創世記 46:4"> 我也說：『要將你們從埃及的困苦中領出來，往迦南人、赫人、亞摩利人、比利洗人、希未人、耶布斯人的地去，就是到流奶與蜜之地。』</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 9:1; 出埃及記 7:16; 出埃及記 10:24–26"> 他們必聽你的話。你和以色列的長老要去見埃及王，對他說：『耶和華希伯來人的神遇見了我們，現在求你容我們往曠野去，走三天的路程，為要祭祀耶和華我們的神。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 5:2; 出埃及記 6:1; 出埃及記 7:1–14"> 我知道雖用大能的手，埃及王也不容你們去。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 7:36; 尼希米記 9:10; 出埃及記 9:15"> 我必伸手在埃及中間施行我一切的奇事，攻擊那地，然後他才容你們去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:36; 詩篇 105:37; 出埃及記 11:3"> 我必叫你們在埃及人眼前蒙恩，你們去的時候就不至於空手而去。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 39:10; 出埃及記 11:2; 出埃及記 12:35–36"> 但各婦女必向她的鄰舍並居住在她家裡的女人要金器銀器和衣裳，好給你們的兒女穿戴，這樣你們就把埃及人的財物奪去了。」</span>
</div>
</div>

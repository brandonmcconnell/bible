## 敵黨謀阻建殿之工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 22:9–10; 以斯拉記 1:11; 以斯拉記 10:16"> 猶大和便雅憫的敵人，聽說被擄歸回的人為耶和華以色列的神建造殿宇，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 19:37; 列王紀下 17:24; 加拉太書 2:4"> 就去見所羅巴伯和以色列的族長，對他們說：「請容我們與你們一同建造，因為我們尋求你們的神，與你們一樣。自從亞述王以撒哈頓帶我們上這地以來，我們常祭祀神。」</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 2:20; 馬太福音 10:16; 歷代志下 36:22–3"> 但所羅巴伯、耶書亞和其餘以色列的族長對他們說：「我們建造神的殿與你們無干，我們自己為耶和華以色列的神協力建造，是照波斯王居魯士所吩咐的。」</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 3:3; 尼希米記 6:9; 耶利米書 38:4"> 那地的民就在猶大人建造的時候，使他們的手發軟，擾亂他們。</span>
<span className="v" id="v5" data-v="5" data-xref="那鴻書 1:11; 以斯拉記 5:5–18; 詩篇 2:1–2"> 從波斯王居魯士年間直到波斯王大流士登基的時候，賄買謀士，要敗壞他們的謀算。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 1:1; 但以理書 9:1; 使徒行傳 24:5–9"> 在亞哈隨魯才登基的時候，上本控告猶大和耶路撒冷的居民。</span>
</div>
</div>

## 上告於亞達薛西

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 18:26; 但以理書 2:4; 以賽亞書 36:11"> 亞達薛西年間，比施蘭、米特利達、他別和他們的同黨上本奏告波斯王亞達薛西，本章是用亞蘭文字亞蘭方言。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:9; 撒母耳記下 8:17; 撒母耳記下 20:25"> 省長利宏、書記伸帥要控告耶路撒冷人，也上本奏告亞達薛西王：</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 5:6; 以斯拉記 6:6; 列王紀下 17:24"> 「省長利宏、書記伸帥和同黨的底拿人、亞法薩提迦人、他毗拉人、亞法撒人、亞基衛人、巴比倫人、書珊迦人、底亥人、以攔人，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 4:17; 以斯拉記 4:11; 以斯拉記 7:12"> 和尊大的亞斯那巴所遷移，安置在撒馬利亞城並大河西一帶地方的人等，</span>
<span className="v" id="v11" data-v="11"> 上奏亞達薛西王說：河西的臣民云云。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 5:9; 歷代志下 36:13; 以斯拉記 5:3"> 王該知道，從王那裡上到我們這裡的猶大人已經到耶路撒冷，重建這反叛惡劣的城，築立根基，建造城牆。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 7:24; 羅馬書 13:6–7; 尼希米記 5:4"> 如今王該知道，他們若建造這城，城牆完畢就不再與王進貢、交課、納稅，終久王必受虧損。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 19:12–15; 以西結書 33:31; 約翰福音 12:5–6"> 我們既食御鹽，不忍見王吃虧，因此奏告於王。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 4:12; 以斯帖記 3:5–8; 列王紀下 24:20–1"> 請王考察先王的實錄，必在其上查知這城是反叛的城，於列王和各省有害，自古以來其中常有悖逆的事，因此這城曾被拆毀。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 4:20; 列王紀上 4:24; 撒母耳記下 8:3"> 我們謹奏王知，這城若再建造，城牆完畢，河西之地王就無份了。」</span>
</div>
</div>

## 王令止工

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:7; 以斯拉記 5:7; 以斯拉記 4:9–11"> 那時王諭復省長利宏、書記伸帥，和他們的同黨，就是住撒馬利亞並河西一帶地方的人，說：「願你們平安云云。</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 8:8"> 你們所上的本，已經明讀在我面前。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 18:7; 箴言 25:2; 申命記 13:14"> 我已命人考查，得知此城古來果然背叛列王，其中常有反叛悖逆的事。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 15:18; 列王紀上 4:21; 歷代志上 18:3"> 從前耶路撒冷也有大君王統管河西全地，人就給他們進貢、交課、納稅。</span>
<span className="v" id="v21" data-v="21"> 現在你們要出告示命這些人停工，使這城不得建造，等我降旨。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 7:3–4; 以斯帖記 3:8–9; 以斯拉記 4:13"> 你們當謹慎，不可遲延，為何容害加重使王受虧損呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="羅馬書 3:15; 彌迦書 2:1; 以斯拉記 4:17"> 亞達薛西王的上諭讀在利宏和書記伸帥並他們的同黨面前，他們就急忙往耶路撒冷去見猶大人，用勢力強迫他們停工。</span>
<span className="v" id="v24" data-v="24" data-xref="哈該書 1:15; 尼希米記 6:9; 以斯拉記 5:5"> 於是，在耶路撒冷神殿的工程就停止了，直停到波斯王大流士第二年。</span>
</div>
</div>

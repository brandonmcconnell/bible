## 再興聖殿之工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亞書 4:6–10; 哈該書 1:1; 撒迦利亞書 1:1–21"> 那時，先知哈該和易多的孫子撒迦利亞奉以色列神的名，向猶大和耶路撒冷的猶大人說勸勉的話。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 3:2; 以斯拉記 6:14; 撒迦利亞書 3:1–4"> 於是，撒拉鐵的兒子所羅巴伯和約薩達的兒子耶書亞都起來，動手建造耶路撒冷神的殿，有神的先知在那裡幫助他們。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 6:6; 以斯拉記 6:13; 以斯拉記 5:9"> 當時河西的總督達乃和示他波斯乃並他們的同黨來問說：「誰降旨讓你們建造這殿，修成這牆呢？」</span>
<span className="v" id="v4" data-v="4"> 我們便告訴他們建造這殿的人叫什麼名字。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 33:18; 以斯拉記 7:6; 以斯拉記 7:28"> 神的眼目看顧猶大的長老，以致總督等沒有叫他們停工，直到這事奏告大流士得著他的回諭。</span>
</div>
</div>

## 達乃黨上本大流士王

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 4:9; 以斯拉記 4:11; 以斯拉記 6:6"> 河西的總督達乃和示他波斯乃，並他們的同黨，就是住河西的亞法薩迦人，上本奏告大流士王。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 4:17; 但以理書 6:21; 帖撒羅尼迦後書 3:16"> 本上寫著說：「願大流士王諸事平安！</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 7:6; 馬可福音 13:1–2; 但以理書 3:26"> 王該知道，我們往猶大省去，到了至大神的殿，這殿是用大石建造的，梁木插入牆內，工作甚速，他們手下亨通。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 5:3–4"> 我們就問那些長老說：『誰降旨讓你們建造這殿，修成這牆呢？』</span>
<span className="v" id="v10" data-v="10"> 又問他們的名字，要記錄他們首領的名字，奏告於王。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 6:16; 約拿書 1:9; 使徒行傳 27:23"> 他們回答說：『我們是天地之神的僕人，重建前多年所建造的殿，就是以色列的一位大君王建造修成的。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 36:16–17; 但以理書 9:5; 列王紀下 24:2"> 只因我們列祖惹天上的神發怒，神把他們交在迦勒底人巴比倫王尼布甲尼撒的手中，他就拆毀這殿，又將百姓擄到巴比倫。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 6:3–5; 以賽亞書 44:28–1; 以斯拉記 1:1–8"> 然而巴比倫王居魯士元年，他降旨允准建造神的這殿。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯拉記 6:5; 但以理書 5:2–3; 以斯拉記 5:16"> 神殿中的金銀器皿，就是尼布甲尼撒從耶路撒冷的殿中掠去帶到巴比倫廟裡的，居魯士王從巴比倫廟裡取出來，交給派為省長的，名叫設巴薩，</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 6:3; 以斯拉記 1:2; 以斯拉記 3:3"> 對他說：「可以將這些器皿帶去，放在耶路撒冷的殿中，在原處建造神的殿。」</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 3:10; 以斯拉記 6:15; 以斯拉記 3:8"> 於是，這設巴薩來建立耶路撒冷神殿的根基。這殿從那時直到如今，尚未造成。』</span>
</div>
</div>

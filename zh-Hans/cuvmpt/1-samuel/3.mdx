## 撒母耳初得啟示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 8:11–12; 詩篇 74:9; 撒母耳記上 3:21"> 童子撒母耳在以利面前侍奉耶和華。當那些日子，耶和華的言語稀少，不常有默示。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:15; 詩篇 90:10; 創世記 27:1"> 一日，以利睡臥在自己的地方。他眼目昏花，看不分明。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:4; 利未記 24:2–4; 出埃及記 27:20–21"> 神的燈在神耶和華殿內約櫃那裡，還沒有熄滅，撒母耳已經睡了。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 6:8; 哥林多前書 12:6–11; 出埃及記 3:4"> 耶和華呼喚撒母耳，撒母耳說：「我在這裡。」</span>
<span className="v" id="v5" data-v="5"> 就跑到以利那裡，說：「你呼喚我？我在這裡。」以利回答說：「我沒有呼喚你，你去睡吧。」他就去睡了。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 9:2; 撒母耳記上 4:16; 撒母耳記下 18:22"> 耶和華又呼喚撒母耳，撒母耳起來，到以利那裡，說：「你呼喚我？我在這裡。」以利回答說：「我的兒，我沒有呼喚你，你去睡吧。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:2; 耶利米書 9:24"> 那時撒母耳還未認識耶和華，也未得耶和華的默示。</span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 33:14–15; 哥林多前書 13:11–12"> 耶和華第三次呼喚撒母耳，撒母耳起來，到以利那裡，說：「你又呼喚我，我在這裡。」以利才明白是耶和華呼喚童子。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 20:19; 以賽亞書 6:8; 詩篇 85:8"> 因此以利對撒母耳說：「你仍去睡吧。若再呼喚你，你就說：『耶和華啊，請說，僕人敬聽。』」撒母耳就去，仍睡在原處。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 3:8; 撒母耳記上 3:4–6"> 耶和華又來站著，像前三次呼喚說：「撒母耳啊！撒母耳啊！」撒母耳回答說：「請說，僕人敬聽。」</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷書 1:5; 耶利米書 19:3; 列王紀下 21:12"> 耶和華對撒母耳說：「我在以色列中必行一件事，叫聽見的人都必耳鳴。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:27–36; 撒迦利亞書 1:6; 約書亞記 23:15"> 我指著以利家所說的話，到了時候，我必始終應驗在以利身上。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; 馬太福音 10:37; 撒母耳記上 2:12"> 我曾告訴他必永遠降罰於他的家，因他知道兒子作孽，自招咒詛，卻不禁止他們。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 22:14; 撒母耳記上 2:25; 耶利米書 15:1"> 所以我向以利家起誓說：以利家的罪孽，雖獻祭奉禮物，永不能得贖去。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:6–8; 瑪拉基書 1:10; 撒母耳記上 1:9"> 撒母耳睡到天亮，就開了耶和華的殿門，不敢將默示告訴以利。</span>
<span className="v" id="v16" data-v="16"> 以利呼喚撒母耳說：「我兒撒母耳啊！」撒母耳回答說：「我在這裡。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:35; 路得記 1:17; 詩篇 141:5"> 以利說：「耶和華對你說什麼，你不要向我隱瞞。你若將神對你所說的隱瞞一句，願他重重地降罰於你！」</span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 2:10; 以賽亞書 39:8; 士師記 10:15"> 撒母耳就把一切話都告訴了以利，並沒有隱瞞。以利說：「這是出於耶和華，願他憑自己的意旨而行。」</span>
</div>
</div>

## 立撒母耳為先知

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 39:2; 撒母耳記上 9:6; 列王紀上 8:56"> 撒母耳長大了，耶和華與他同在，使他所說的話一句都不落空。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 20:1; 撒母耳記下 3:10; 提摩太前書 1:12"> 從但到別是巴所有的以色列人，都知道耶和華立撒母耳為先知。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 3:1; 創世記 12:7; 撒母耳記上 3:4"> 耶和華又在示羅顯現，因為耶和華將自己的話默示撒母耳，撒母耳就把這話傳遍以色列地。</span>
</div>
</div>

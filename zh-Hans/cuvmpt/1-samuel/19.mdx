## 約拿單褒揚大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 18:1; 撒母耳記上 18:9"> 掃羅對他兒子約拿單和眾臣僕說要殺大衛，掃羅的兒子約拿單卻甚喜愛大衛。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 17:17; 使徒行傳 9:24; 撒母耳記上 18:1–3"> 約拿單告訴大衛說：「我父掃羅想要殺你，所以明日早晨你要小心，到一個僻靜地方藏身。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 20:9; 撒母耳記上 20:13"> 我就出到你所藏的田裡，站在我父親旁邊與他談論。我看他情形怎樣，我必告訴你。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 18:20; 箴言 31:8–9; 創世記 42:22"> 約拿單向他父親掃羅替大衛說好話，說：「王不可得罪王的僕人大衛，因為他未曾得罪你，他所行的都於你大有益處。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 11:13; 歷代志上 11:14; 士師記 9:17"> 他拼命殺那非利士人，耶和華為以色列眾人大行拯救。那時你看見，甚是歡喜，現在為何無故要殺大衛，流無辜人的血，自己取罪呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 26:24–25; 耶利米書 5:2; 詩篇 15:4"> 掃羅聽了約拿單的話，就指著永生的耶和華起誓說：「我必不殺他。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 18:2; 撒母耳記上 16:21; 撒母耳記上 18:13"> 約拿單叫大衛來，把這一切事告訴他，帶他去見掃羅，他就仍然侍立在掃羅面前。</span>
</div>
</div>

## 米甲釋大衛

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 27:3; 詩篇 18:32–50"> 此後又有爭戰的事。大衛出去與非利士人打仗，大大殺敗他們，他們就在他面前逃跑。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 16:14; 撒母耳記上 18:10–11; 撒母耳記上 16:16"> 從耶和華那裡來的惡魔又降在掃羅身上（掃羅手裡拿槍坐在屋裡），大衛就用手彈琴。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 20:33; 撒母耳記上 18:11; 箴言 21:30"> 掃羅用槍想要刺透大衛，釘在牆上。他卻躲開，掃羅的槍刺入牆內。當夜大衛逃走，躲避了。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–17; 士師記 16:2"> 掃羅打發人到大衛的房屋那裡窺探他，要等到天亮殺他。大衛的妻米甲對他說：「你今夜若不逃命，明日你要被殺。」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 2:15; 使徒行傳 9:24–25; 詩篇 34:19"> 於是米甲將大衛從窗戶裡縋下去，大衛就逃走，躲避了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:19; 士師記 18:17; 士師記 18:14"> 米甲把家中的神像放在床上，頭枕在山羊毛裝的枕頭上，用被遮蓋。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 2:5; 撒母耳記下 16:17–19; 撒母耳記下 17:20"> 掃羅打發人去捉拿大衛，米甲說：「他病了。」</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 27:3–4; 詩篇 37:12; 約伯記 31:31"> 掃羅又打發人去看大衛，說：「當連床將他抬來，我好殺他。」</span>
<span className="v" id="v16" data-v="16"> 使者進去，看見床上有神像，頭枕在山羊毛裝的枕頭上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 2:22; 撒母耳記上 22:17; 出埃及記 1:17–19"> 掃羅對米甲說：「你為什麼這樣欺哄我，放我仇敵逃走呢？」米甲回答說：「他對我說：『你放我走，不然我要殺你。』」</span>
</div>
</div>

## 掃羅及其使感靈而言

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 7:17; 詩篇 116:11; 撒母耳記上 15:34"> 大衛逃避，來到拉瑪見撒母耳，將掃羅向他所行的事述說了一遍。他和撒母耳就往拿約去居住。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 23:19; 撒母耳記上 22:9–10; 撒母耳記上 26:1"> 有人告訴掃羅，說大衛在拉瑪的拿約。</span>
<span className="v" id="v20" data-v="20" data-xref="約珥書 2:28; 約翰福音 7:32; 撒母耳記上 10:5–6"> 掃羅打發人去捉拿大衛。去的人見有一班先知都受感說話，撒母耳站在其中監管他們。打發去的人也受神的靈感動說話。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 27:22; 耶利米書 13:23; 約珥書 2:28"> 有人將這事告訴掃羅，他又打發人去，他們也受感說話。掃羅第三次打發人去，他們也受感說話。</span>
<span className="v" id="v22" data-v="22"> 然後掃羅自己往拉瑪去，到了西沽的大井，問人說：「撒母耳和大衛在哪裡呢？」有人說：「在拉瑪的拿約。」</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 撒母耳記上 10:10; 撒母耳記上 19:20"> 他就往拉瑪的拿約去。神的靈也感動他，一面走一面說話，直到拉瑪的拿約。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 6:20; 以賽亞書 20:2; 彌迦書 1:8"> 他就脫了衣服，在撒母耳面前受感說話，一晝一夜露體躺臥。因此有句俗語說：「掃羅也列在先知中嗎？」</span>
</div>
</div>

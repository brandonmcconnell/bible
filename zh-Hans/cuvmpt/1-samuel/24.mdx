## 大衛在隱基底不害掃羅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 23:28–29; 以西結書 22:9; 撒母耳記上 23:19"> 掃羅追趕非利士人回來，有人告訴他說，大衛在隱基底的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 26:2; 詩篇 104:18; 詩篇 37:32"> 掃羅就從以色列人中挑選三千精兵，率領他們往野羊的磐石去，尋索大衛和跟隨他的人。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:24; 詩篇 57:1–11; 詩篇 142:1–7"> 到了路旁的羊圈，在那裡有洞，掃羅進去大解。大衛和跟隨他的人正藏在洞裡的深處。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 26:8–11; 撒母耳記上 24:10; 撒母耳記上 26:23"> 跟隨的人對大衛說：「耶和華曾應許你說：『我要將你的仇敵交在你手裡，你可以任意待他。』如今時候到了！」大衛就起來，悄悄地割下掃羅外袍的衣襟。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 24:10; 列王紀下 22:19; 約翰一書 3:20–21"> 隨後大衛心中自責，因為割下掃羅的衣襟，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 1:14; 約伯記 31:29–30; 撒母耳記上 26:9–11"> 對跟隨他的人說：「我的主乃是耶和華的受膏者，我在耶和華面前萬不敢伸手害他，因他是耶和華的受膏者。」</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 5:44; 詩篇 7:4; 羅馬書 12:17–21"> 大衛用這話攔住跟隨他的人，不容他們起來害掃羅。掃羅起來，從洞裡出去行路。</span>
</div>
</div>

## 大衛向掃羅自白

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 25:23–24; 羅馬書 13:7; 出埃及記 20:12"> 隨後大衛也起來，從洞裡出去，呼叫掃羅說：「我主！我王！」掃羅回頭觀看，大衛就屈身，臉伏於地下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 7:21–22; 箴言 29:12; 箴言 16:28"> 大衛對掃羅說：「你為何聽信人的讒言，說大衛想要害你呢？</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 105:15; 撒母耳記上 24:4; 撒母耳記上 26:8–9"> 今日你親眼看見在洞中，耶和華將你交在我手裡。有人叫我殺你，我卻愛惜你，說：『我不敢伸手害我的主，因為他是耶和華的受膏者。』</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 26:20; 撒母耳記上 23:14; 撒母耳記上 23:23"> 我父啊，看看你外袍的衣襟在我手中。我割下你的衣襟，沒有殺你。你由此可以知道我沒有惡意叛逆你。你雖然獵取我的命，我卻沒有得罪你。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 43:1; 士師記 11:27; 詩篇 35:1"> 願耶和華在你我中間判斷是非，在你身上為我申冤，我卻不親手加害於你。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 7:20; 馬太福音 7:16–18; 馬太福音 12:33–34"> 古人有句俗語說：『惡事出於惡人』，我卻不親手加害於你。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 26:20; 撒母耳記上 17:43; 撒母耳記下 9:8"> 以色列王出來要尋找誰呢？追趕誰呢？不過追趕一條死狗，一個虼蚤就是了。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 43:1; 詩篇 35:1; 詩篇 119:154"> 願耶和華在你我中間施行審判，斷定是非，並且鑒察，為我申冤，救我脫離你的手。」</span>
</div>
</div>

## 掃羅自承其過

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:17; 創世記 33:4; 路加福音 21:15"> 大衛向掃羅說完這話，掃羅說：「我兒大衛，這是你的聲音嗎？」就放聲大哭，</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:44; 撒母耳記上 26:21; 創世記 38:26"> 對大衛說：「你比我公義。因為你以善待我，我卻以惡待你。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 26:23; 詩篇 31:8; 撒母耳記上 23:12"> 你今日顯明是以善待我，因為耶和華將我交在你手裡，你卻沒有殺我。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:20; 撒母耳記上 23:21; 箴言 25:21–22"> 人若遇見仇敵，豈肯放他平安無事地去呢？願耶和華因你今日向我所行的，以善報你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:17; 馬太福音 2:3–6; 撒母耳記下 3:17–18"> 我也知道你必要做王，以色列的國必堅立在你手裡。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:23; 撒母耳記下 21:6–8; 撒母耳記上 20:14–17"> 現在你要指著耶和華向我起誓，不剪除我的後裔，在我父家不滅沒我的名。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 23:29; 約翰福音 2:24; 馬太福音 10:16–17"> 於是大衛向掃羅起誓。掃羅就回家去，大衛和跟隨他的人上山寨去了。</span>
</div>
</div>

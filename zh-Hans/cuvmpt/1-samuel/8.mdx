## 以色列人求立王撒母耳不悅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:18–19; 提摩太前書 5:21; 尼希米記 7:2"> 撒母耳年紀老邁，就立他兒子做以色列的士師。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 6:38; 創世記 22:19; 歷代志上 6:28"> 長子名叫約珥，次子名叫亞比亞，他們在別是巴做士師。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:19; 詩篇 15:5; 提摩太前書 6:10"> 他兒子不行他的道，貪圖財利，收受賄賂，屈枉正直。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 7:17; 撒母耳記下 5:3; 出埃及記 3:16"> 以色列的長老都聚集，來到拉瑪見撒母耳，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 17:14–15; 何西阿書 13:10–11; 撒母耳記上 8:6–8"> 對他說：「你年紀老邁了，你兒子不行你的道。現在求你為我們立一個王治理我們，像列國一樣。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 15:11; 雅各書 1:5; 撒母耳記上 12:17"> 撒母耳不喜悅他們說立一個王治理我們，他就禱告耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 撒母耳記上 10:19; 出埃及記 16:8"> 耶和華對撒母耳說：「百姓向你說的一切話，你只管依從，因為他們不是厭棄你，乃是厭棄我，不要我做他們的王。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:34–40; 出埃及記 32:1; 士師記 13:1"> 自從我領他們出埃及到如今，他們常常離棄我，侍奉別神。現在他們向你所行的，是照他們素來所行的。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 10:25; 撒母耳記上 8:11–18; 以西結書 46:18"> 故此你要依從他們的話，只是當警戒他們，告訴他們將來那王怎樣管轄他們。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 撒母耳將耶和華的話都傳給求他立王的百姓，說：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 14:52; 申命記 17:14–20; 撒母耳記上 10:25"> 「管轄你們的王必這樣行，他必派你們的兒子為他趕車，跟馬，奔走在車前；</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 22:7; 列王紀上 4:7; 歷代志上 27:1–22"> 又派他們做千夫長、五十夫長，為他耕種田地，收割莊稼，打造軍器和車上的器械。</span>
<span className="v" id="v13" data-v="13"> 必取你們的女兒為他製造香膏，做飯烤餅。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 46:18; 列王紀上 21:7; 列王紀上 21:19"> 也必取你們最好的田地、葡萄園、橄欖園賜給他的臣僕。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 1:3; 以賽亞書 39:7; 創世記 37:36"> 你們的糧食和葡萄園所出的，他必取十分之一給他的太監和臣僕。</span>
<span className="v" id="v16" data-v="16"> 又必取你們的僕人婢女，健壯的少年人和你們的驢，供他的差役。</span>
<span className="v" id="v17" data-v="17"> 你們的羊群他必取十分之一，你們也必做他的僕人。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 3:4; 以賽亞書 1:15; 箴言 1:25–28"> 那時你們必因所選的王哀求耶和華，耶和華卻不應允你們。」</span>
</div>
</div>

## 耶和華命撒母耳從民言立王

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 44:16; 耶利米書 7:13; 以賽亞書 66:4"> 百姓竟不肯聽撒母耳的話，說：「不然，我們定要一個王治理我們，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 8:5; 詩篇 106:35; 申命記 7:6"> 使我們像列國一樣，有王治理我們，統領我們，為我們爭戰。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:11"> 撒母耳聽見百姓這一切話，就將這話陳明在耶和華面前。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 8:7; 何西阿書 13:11"> 耶和華對撒母耳說：「你只管依從他們的話，為他們立王。」撒母耳對以色列人說：「你們各歸各城去吧。」</span>
</div>
</div>

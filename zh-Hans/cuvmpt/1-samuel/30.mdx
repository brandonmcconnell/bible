## 亞瑪力人焚掠洗革拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 15:7; 撒母耳記上 29:11; 撒母耳記上 27:8–10"> 第三日，大衛和跟隨他的人到了洗革拉。亞瑪力人已經侵奪南地，攻破洗革拉，用火焚燒，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 27:11; 約伯記 38:11; 詩篇 76:10"> 擄了城內的婦女和其中的大小人口，卻沒有殺一個，都帶著走了。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 34:19; 彼得前書 1:6–7; 啟示錄 3:9"> 大衛和跟隨他的人到了那城，不料，城已燒毀，他們的妻子、兒女都被擄去了。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 11:4; 民數記 14:1; 士師記 21:2"> 大衛和跟隨他的人就放聲大哭，直哭得沒有氣力。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 25:42–43; 撒母耳記下 2:2; 撒母耳記上 1:2"> 大衛的兩個妻耶斯列人亞希暖和做過拿八妻的迦密人亞比該，也被擄去了。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 56:3–4; 詩篇 56:11; 詩篇 62:5"> 大衛甚是焦急，因眾人為自己的兒女苦惱，說要用石頭打死他。大衛卻倚靠耶和華他的神，心裡堅固。</span>
</div>
</div>

## 大衛追亞瑪力人

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 2:26; 撒母耳記上 22:20–21; 撒母耳記上 23:2–9"> 大衛對亞希米勒的兒子祭司亞比亞他說：「請你將以弗得拿過來。」亞比亞他就將以弗得拿到大衛面前。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:18; 箴言 3:5–6; 撒母耳記上 23:2"> 大衛求問耶和華說：「我追趕敵軍，追得上追不上呢？」耶和華說：「你可以追，必追得上，都救得回來。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 27:2"> 於是，大衛和跟隨他的六百人來到比梭溪，有不能前去的就留在那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 30:9; 撒母耳記上 30:21; 撒母耳記上 14:31"> 大衛卻帶著四百人往前追趕，有二百人疲乏，不能過比梭溪，所以留在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 12:20–21; 申命記 23:7; 馬太福音 25:35"> 這四百人在田野遇見一個埃及人，就帶他到大衛面前，給他餅吃，給他水喝，</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 15:19; 撒母耳記上 14:27; 撒母耳記上 30:13"> 又給他一塊無花果餅，兩個葡萄餅。他吃了，就精神復原，因為他三日三夜沒有吃餅，沒有喝水。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 2:13; 箴言 12:10; 約伯記 31:13–15"> 大衛問他說：「你是屬誰的？你是哪裡的人？」他回答說：「我是埃及的少年人，是亞瑪力人的奴僕。因我三日前患病，我主人就把我撇棄了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 1:38; 撒母耳記下 8:18; 列王紀上 1:44"> 我們侵奪了基利提的南方和屬猶大的地，並迦勒地的南方，又用火燒了洗革拉。」</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 2:12; 約書亞記 9:19–20; 以西結書 17:16"> 大衛問他說：「你肯領我們到敵軍那裡不肯？」他回答說：「你要向我指著神起誓，不殺我，也不將我交在我主人手裡，我就領你下到敵軍那裡。」</span>
</div>
</div>

## 盡返掠物

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:10–13; 撒母耳記下 13:28; 士師記 16:23–30"> 那人領大衛下去，見他們散在地上，吃喝跳舞，因為從非利士地和猶大地所擄來的財物甚多。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 11:11; 詩篇 18:42; 撒母耳記上 15:3"> 大衛從黎明直到次日晚上，擊殺他們，除了四百騎駱駝的少年人之外，沒有一個逃脫的。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 14:16"> 亞瑪力人所擄去的財物，大衛全都奪回，並救回他的兩個妻來。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:9–10; 撒母耳記上 30:8; 約伯記 1:10"> 凡亞瑪力人所擄去的，無論大小、兒女、財物，大衛都奪回來，沒有失落一個。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 30:26; 民數記 31:9–12; 歷代志下 20:25"> 大衛所奪來的牛群羊群，跟隨他的人趕在原有的群畜前邊，說：「這是大衛的掠物。」</span>
</div>
</div>

## 定分擄物之例

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:1; 撒母耳記上 30:10; 士師記 8:15"> 大衛到了那疲乏不能跟隨，留在比梭溪的二百人那裡。他們出來迎接大衛並跟隨的人，大衛前來問他們安。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:12; 申命記 13:13; 列王紀上 21:10"> 跟隨大衛人中的惡人和匪類說：「這些人既然沒有和我們同去，我們所奪的財物就不分給他們，只將他們各人的妻子、兒女給他們，使他們帶去就是了。」</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 8:18; 詩篇 44:2–7; 使徒行傳 7:2"> 大衛說：「弟兄們，耶和華所賜給我們的，不可不分給他們，因為他保佑我們，將那攻擊我們的敵軍交在我們手裡。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 22:8; 民數記 31:27; 詩篇 68:12"> 這事誰肯依從你們呢？上陣的得多少，看守器具的也得多少，應當大家平分。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 16:13"> 大衛定此為以色列的律例、典章，從那日直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 25:27; 創世記 33:11; 以賽亞書 32:8"> 大衛到了洗革拉，從掠物中取些送給他朋友猶大的長老，說：「這是從耶和華仇敵那裡奪來的，送你們為禮物。」</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 15:48; 約書亞記 19:8; 士師記 1:22–23"> 他送禮物給住伯特利的，南地拉末的，雅提珥的，</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 13:16; 約書亞記 15:50; 約書亞記 21:14"> 住亞羅珥的，息末的，以實提莫的，</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:16; 撒母耳記上 27:10; 撒母耳記上 15:6"> 住拉哈勒的，耶拉篾各城的，基尼各城的，</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 1:17; 約書亞記 19:4; 約書亞記 15:42"> 住何珥瑪的，歌拉珊的，亞撻的，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 2:1; 撒母耳記下 15:10; 撒母耳記下 4:1"> 住希伯崙的，並大衛和跟隨他的人素來所到之處的人。</span>
</div>
</div>

## 撒母耳自白於民眾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 10:24; 撒母耳記上 11:14–15; 撒母耳記上 10:1"> 撒母耳對以色列眾人說：「你們向我所求的，我已應允了，為你們立了一個王。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 8:5; 撒母耳記上 8:1; 撒母耳記上 8:20"> 現在有這王在你們前面行。我已年老髮白，我的兒子都在你們這裡。我從幼年直到今日都在你們前面行。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 20:33; 民數記 16:15; 彼得前書 5:2"> 我在這裡，你們要在耶和華和他的受膏者面前給我作見證：我奪過誰的牛，搶過誰的驢，欺負過誰，虐待過誰，從誰手裡受過賄賂因而眼瞎呢？若有，我必償還。」</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 6:4; 詩篇 37:5–6; 約翰三書 1:12"> 眾人說：「你未曾欺負我們，虐待我們，也未曾從誰手裡受過什麼。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:4; 使徒行傳 24:20; 使徒行傳 23:9"> 撒母耳對他們說：「你們在我手裡沒有找著什麼，有耶和華和他的受膏者今日為證。」他們說：「願他為證。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="彌迦書 6:4; 出埃及記 6:26; 詩篇 99:6"> 撒母耳對百姓說：「從前立摩西、亞倫，又領你們列祖出埃及地的是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:18; 彌迦書 6:1–5; 使徒行傳 17:3"> 現在你們要站住，等我在耶和華面前對你們講論耶和華向你們和你們列祖所行一切公義的事。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:14–16; 出埃及記 2:23–24; 詩篇 78:54–55"> 從前雅各到了埃及，後來你們列祖呼求耶和華，耶和華就差遣摩西、亞倫領你們列祖出埃及，使他們在這地方居住。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:1; 士師記 10:7; 士師記 3:12"> 他們卻忘記耶和華他們的神，他就把他們付於夏瑣將軍西西拉的手裡，和非利士人並摩押王的手裡，於是這些人常來攻擊他們。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 10:10; 士師記 2:13; 士師記 3:7"> 他們就呼求耶和華說：『我們離棄耶和華，侍奉巴力和亞斯她錄，是有罪了。現在求你救我們脫離仇敵的手，我們必侍奉你。』</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 6:32; 士師記 4:6; 士師記 8:35"> 耶和華就差遣耶路巴力、比但、耶弗他、撒母耳救你們脫離四圍仇敵的手，你們才安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 8:23; 撒母耳記上 8:5–7; 創世記 17:7"> 你們見亞捫人的王拿轄來攻擊你們，就對我說：『我們定要一個王治理我們。』其實耶和華你們的神是你們的王。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 13:11; 撒母耳記上 10:24; 撒母耳記上 8:5"> 現在，你們所求所選的王在這裡。看哪，耶和華已經為你們立王了！</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 24:14; 申命記 28:1–14; 詩篇 81:12–15"> 你們若敬畏耶和華，侍奉他，聽從他的話，不違背他的命令，你們和治理你們的王也都順從耶和華你們的神，就好了。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 24:20; 以賽亞書 1:20; 以賽亞書 3:11"> 倘若不聽從耶和華的話，違背他的命令，耶和華的手必攻擊你們，像從前攻擊你們列祖一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 14:13; 出埃及記 14:31; 撒母耳記上 12:7"> 現在你們要站住，看耶和華在你們眼前要行一件大事。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 8:7; 箴言 26:1; 撒母耳記上 7:9–10"> 這不是割麥子的時候嗎？我求告耶和華，他必打雷降雨，使你們又知道又看出，你們求立王的事是在耶和華面前犯大罪了。」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:31; 以斯拉記 10:9; 詩篇 106:12–13"> 於是撒母耳求告耶和華，耶和華就在這日打雷降雨，眾民便甚懼怕耶和華和撒母耳。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 9:28; 約翰一書 5:16; 撒母耳記上 12:23"> 眾民對撒母耳說：「求你為僕人們禱告耶和華你的神，免得我們死亡，因為我們求立王的事正是罪上加罪了。」</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 11:16; 約書亞記 23:6; 彼得前書 3:16"> 撒母耳對百姓說：「不要懼怕！你們雖然行了這惡，卻不要偏離耶和華，只要盡心侍奉他。</span>
<span className="v" id="v21" data-v="21" data-xref="哈巴谷書 2:18; 耶利米書 10:15; 耶利米書 16:19"> 若偏離耶和華，去順從那不能救人的虛神，是無益的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:7–8; 申命記 14:2; 詩篇 106:8"> 耶和華既喜悅選你們做他的子民，就必因他的大名不撇棄你們。</span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:9; 羅馬書 1:9; 提摩太後書 1:3"> 至於我，斷不停止為你們禱告，以致得罪耶和華。我必以善道正路指教你們。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 10:21; 箴言 1:7; 以賽亞書 5:12"> 只要你們敬畏耶和華，誠誠實實地盡心侍奉他，想念他向你們所行的事何等大。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 24:20; 何西阿書 10:3; 撒母耳記上 31:1–5"> 你們若仍然作惡，你們和你們的王必一同滅亡。」</span>
</div>

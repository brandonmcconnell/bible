## 彼得醫治瘸腿的

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 55:17; 使徒行傳 10:3; 使徒行傳 4:13"> 申初禱告的時候，彼得、約翰上聖殿去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 14:8; 約翰福音 9:8; 路加福音 16:20"> 有一個人，生來是瘸腿的，天天被人抬來，放在殿的一個門口——那門名叫美門——要求進殿的人賙濟。</span>
<span className="v" id="v3" data-v="3"> 他看見彼得、約翰將要進殿，就求他們賙濟。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:9–10; 約翰福音 11:40; 路加福音 4:20"> 彼得、約翰定睛看他，彼得說：「你看我們！」</span>
<span className="v" id="v5" data-v="5"> 那人就留意看他們，指望得著什麼。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 3:16; 使徒行傳 10:38; 使徒行傳 4:10"> 彼得說：「金銀我都沒有，只把我所有的給你：我奉拿撒勒人耶穌基督的名，叫你起來行走！」</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 1:31; 馬可福音 9:27; 使徒行傳 9:41"> 於是拉著他的右手，扶他起來。他的腳和踝子骨立刻健壯了，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 14:10; 以賽亞書 35:6; 詩篇 107:20–22"> 就跳起來站著，又行走，同他們進了殿，走著跳著，讚美神。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:21; 使徒行傳 4:16; 路加福音 13:17"> 百姓都看見他行走、讚美神，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 3:2; 約翰福音 5:20; 約翰福音 9:3"> 認得他是那素常坐在殿的美門口求賙濟的，就因他所遇著的事滿心稀奇、驚訝。</span>
</div>
</div>

## 彼得對眾講論醫治瘸腿的因由

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:12; 約翰福音 10:23; 路加福音 8:38"> 那人正在稱為所羅門的廊下拉著彼得、約翰，眾百姓一齊跑到他們那裡，很覺稀奇。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:5; 約翰福音 3:27–28; 但以理書 2:28–30"> 彼得看見，就對百姓說：「以色列人哪，為什麼把這事當做稀奇呢？為什麼定睛看我們，以為我們憑自己的能力和虔誠使這人行走呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 22:32; 使徒行傳 7:32; 馬太福音 27:17–25"> 亞伯拉罕、以撒、雅各的神，就是我們列祖的神，已經榮耀了他的僕人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「僕人」或作「兒子」。">a</a></sup>耶穌，你們卻把他交付彼拉多，彼拉多定意要釋放他，你們竟在彼拉多面前棄絕了他。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 1:24; 使徒行傳 7:52; 彼得前書 3:18"> 你們棄絕了那聖潔公義者，反求著釋放一個凶手給你們。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:24; 啟示錄 21:6; 使徒行傳 2:32"> 你們殺了那生命的主，神卻叫他從死裡復活了。我們都是為這事作見證。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 21:21–22; 使徒行傳 4:10; 使徒行傳 14:9"> 我們因信他的名，他的名便叫你們所看見、所認識的這人健壯了。正是他所賜的信心，叫這人在你們眾人面前全然好了。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行傳 13:27; 約翰福音 16:3"> 弟兄們，我曉得你們做這事是出於不知，你們的官長也是如此。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:1–12; 使徒行傳 26:22–23; 使徒行傳 2:23"> 但神曾藉眾先知的口預言基督將要受害，就這樣應驗了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 2:38; 以賽亞書 44:22; 以賽亞書 43:25"> 所以，你們當悔改歸正，使你們的罪得以塗抹，這樣那安舒的日子就必從主面前來到，</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:30–36; 啟示錄 19:11–16; 帖撒羅尼迦後書 2:2"> 主也必差遣所預定給你們的基督——耶穌降臨。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:21; 以賽亞書 1:26; 使徒行傳 1:11"> 天必留他，等到萬物復興的時候，就是神從創世以來藉著聖先知的口所說的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:15–19; 使徒行傳 7:37; 加拉太書 4:4"> 摩西曾說：『主神要從你們弟兄中間給你們興起一位先知像我，凡他向你們所說的，你們都要聽從。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 18:19; 約翰福音 12:48; 希伯來書 10:28–30"> 凡不聽從那先知的，必要從民中全然滅絕。』</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 3:21; 路加福音 24:27; 撒母耳記上 3:20"> 從撒母耳以來的眾先知，凡說預言的，也都說到這些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 22:18; 加拉太書 3:8; 使徒行傳 2:39"> 你們是先知的子孫，也承受神與你們祖宗所立的約，就是對亞伯拉罕說：『地上萬族都要因你的後裔得福。』</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 1:21; 使徒行傳 3:22; 猶大書 1:24"> 神既興起他的僕人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：兒子。">b</a></sup>，就先差他到你們這裡來，賜福給你們，叫你們各人回轉，離開罪惡。」</span>
</div>
</div>

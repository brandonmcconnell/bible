## 彼得約翰被拿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行傳 6:12; 使徒行傳 23:6–9"> 使徒對百姓說話的時候，祭司們和守殿官並撒都該人忽然來了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 17:18; 帖撒羅尼迦前書 4:13–14; 使徒行傳 24:14–15"> 因他們教訓百姓，本著耶穌傳說死人復活，就很煩惱，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 5:18; 馬太福音 10:16–17; 使徒行傳 16:19–24"> 於是下手拿住他們。因為天已經晚了，就把他們押到第二天。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 2:41; 哥林多後書 2:14–17; 提摩太後書 2:9–10"> 但聽道之人有許多信的，男丁數目約到五千。</span>
</div>
</div>

## 到公會前被審

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 4:8; 馬太福音 27:1–2; 路加福音 20:1"> 第二天，官府、長老和文士在耶路撒冷聚會，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 約翰福音 18:24; 馬太福音 26:3"> 又有大祭司亞那和該亞法、約翰、亞歷山大，並大祭司的親族都在那裡，</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 21:23; 馬可福音 11:28; 使徒行傳 5:40"> 叫使徒站在當中，就問他們說：「你們用什麼能力，奉誰的名做這事呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 馬太福音 10:19–20; 使徒行傳 2:4"> 那時彼得被聖靈充滿，對他們說：</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 3:15–17; 使徒行傳 3:7; 約翰福音 10:32"> 「治民的官府和長老啊，倘若今日因為在殘疾人身上所行的善事，查問我們他是怎麼得了痊癒，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:29–32; 使徒行傳 3:6; 使徒行傳 2:36"> 你們眾人和以色列百姓都當知道：站在你們面前的這人得痊癒，是因你們所釘十字架、神叫他從死裡復活的拿撒勒人耶穌基督的名。</span>
</div>
</div>

## 除了耶穌別無拯救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:22–23; 以賽亞書 28:16; 馬可福音 12:10–12"> 「他是<br /><span className="pl pl-1">『你們匠人所棄的石頭，</span><br /><span className="pl pl-1">已成了房角的頭塊石頭』。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 14:6; 哥林多前書 3:11; 約翰福音 3:36"> 除他以外，別無拯救，因為在天下人間，沒有賜下別的名我們可以靠著得救。」</span>
</div>
</div>

## 恐嚇而放

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 1:27; 約翰福音 7:15; 馬太福音 11:25"> 他們見彼得、約翰的膽量，又看出他們原是沒有學問的小民，就稀奇，認明他們是跟過耶穌的。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 19:36; 使徒行傳 3:8–12; 使徒行傳 4:21"> 又看見那治好了的人和他們一同站著，就無話可駁。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 26:30–32; 使徒行傳 5:34–42; 馬太福音 5:22"> 於是吩咐他們從公會出去，就彼此商議說：</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行傳 6:10; 約翰福音 12:18"> 「我們當怎樣辦這兩個人呢？因為他們誠然行了一件明顯的神蹟，凡住耶路撒冷的人都知道，我們也不能說沒有。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:28; 羅馬書 15:18–22; 使徒行傳 5:24"> 唯恐這事越發傳揚在民間，我們必須恐嚇他們，叫他們不再奉這名對人講論。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:40; 路加福音 24:46–48; 使徒行傳 5:20"> 於是叫了他們來，禁止他們總不可奉耶穌的名講論、教訓人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 5:29; 出埃及記 1:17; 哥林多前書 10:15"> 彼得、約翰說：「聽從你們不聽從神，這在神面前合理不合理，你們自己酌量吧！</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 22:15; 耶利米書 20:9; 哥林多前書 9:16–17"> 我們所看見、所聽見的，不能不說。」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 5:26; 馬太福音 21:46; 路加福音 22:2"> 官長為百姓的緣故，想不出法子刑罰他們，又恐嚇一番，把他們釋放了。這是因眾人為所行的奇事都歸榮耀於神。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 5:5; 使徒行傳 9:33; 路加福音 13:11"> 原來藉著神蹟醫好的那人有四十多歲了。</span>
</div>
</div>

## 門徒同心禱告讚美

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:14–17; 使徒行傳 12:11–12; 詩篇 119:63"> 二人既被釋放，就到會友那裡去，把祭司長和長老所說的話都告訴他們。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:11; 耶利米書 32:17; 尼希米記 9:6"> 他們聽見了，就同心合意地高聲向神說：「主啊，你是造天、地、海和其中萬物的！</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–6; 使徒行傳 1:16; 使徒行傳 2:30"> 你曾藉著聖靈，託你僕人——我們祖宗大衛的口說：<br /><span className="pl pl-1">『外邦為什麼爭鬧？</span><br /><span className="pl pl-1">萬民為什麼謀算虛妄的事？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:2; 啟示錄 17:12–14; 但以理書 9:24"> <span className="pl pl-1">世上的君王一齊起來，</span><br /><span className="pl pl-1">臣宰也聚集，</span><br /><span className="pl pl-1">要抵擋主</span><br /><span className="pl pl-1">並主的受膏者</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：基督。">a</a></sup><br /><span className="pl pl-1">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 27:2; 使徒行傳 4:30; 路加福音 9:22"> 希律和本丟·彼拉多，外邦人和以色列民，果然在這城裡聚集，要攻打你所膏的聖僕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「僕」或作「子」。">b</a></sup>耶穌，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 2:23; 以賽亞書 46:10; 創世記 50:20"> 成就你手和你意旨所預定必有的事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:13; 使徒行傳 14:3; 腓立比書 1:14"> 他們恐嚇我們，現在求主鑒察，一面叫你僕人大放膽量講你的道，一面伸出你的手來醫治疾病，並且使神蹟奇事因著你聖僕<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="-30 「僕」或作「子」。">c</a></sup>耶穌的名行出來。」</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 21:22; 使徒行傳 2:2; 使徒行傳 2:4"> 禱告完了，聚會的地方震動，他們就都被聖靈充滿，放膽講論神的道。</span>
</div>
</div>

## 信徒財物不分彼此

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 1:10; 以弗所書 4:2–6; 彼得前書 3:8"> 那許多信的人都是一心一意的，沒有一人說他的東西有一樣是自己的，都是大家公用。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 1:16; 使徒行傳 1:22; 使徒行傳 1:8"> 使徒大有能力，見證主耶穌復活，眾人也都蒙大恩。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 2:45; 路加福音 12:33; 路加福音 16:9"> 內中也沒有一個缺乏的，因為人人將田產房屋都賣了，把所賣的價銀拿來，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 5:2; 使徒行傳 2:45; 哥林多後書 8:20–21"> 放在使徒腳前，照各人所需用的分給各人。</span>
</div>
</div>

## 巴拿巴賣產捐銀

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="加拉太書 2:9; 加拉太書 2:13; 加拉太書 2:1"> 有一個利未人，生在塞浦路斯，名叫約瑟，使徒稱他為巴拿巴（「巴拿巴」翻出來就是「勸慰子」）。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 5:1–2; 使徒行傳 4:34–35; 馬太福音 19:29"> 他有田地，也賣了，把價銀拿來放在使徒腳前。</span>
</div>
</div>

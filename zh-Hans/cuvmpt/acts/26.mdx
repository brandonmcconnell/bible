## 保羅在亞基帕前為自己分訴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:15; 箴言 1:24; 使徒行傳 26:2"> 亞基帕對保羅說：「准你為自己辯明。」於是保羅伸手分訴說：</span>
<span className="v" id="v2" data-v="2"> 「亞基帕王啊，猶太人所告我的一切事，今日得在你面前分訴，實為萬幸。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 6:14; 使徒行傳 26:26; 使徒行傳 26:7"> 更可幸的是，你熟悉猶太人的規矩和他們的辯論。所以，求你耐心聽我。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:13; 提摩太後書 3:10; 腓立比書 3:5"> 我從起初在本國的民中，並在耶路撒冷，自幼為人如何，猶太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 23:6; 使徒行傳 22:3; 使徒行傳 24:5"> 他們若肯作見證，就曉得我從起初是按著我們教中最嚴緊的教門做了法利賽人。</span>
<span className="v" id="v6" data-v="6" data-xref="提多書 2:13; 使徒行傳 24:15; 使徒行傳 28:20"> 現在我站在這裡受審，是因為指望神向我們祖宗所應許的。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:1; 腓立比書 3:11; 提摩太前書 5:5"> 這應許，我們十二個支派晝夜切切地侍奉神，都指望得著。王啊，我被猶太人控告，就是因這指望。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 15:12–20; 使徒行傳 4:2; 使徒行傳 17:31–32"> 神叫死人復活，你們為什麼看做不可信的呢？</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 1:13; 使徒行傳 22:8; 腓立比書 3:6"> 從前我自己以為應當多方攻擊拿撒勒人耶穌的名，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 8:3; 使徒行傳 9:13–14; 使徒行傳 9:21"> 我在耶路撒冷也曾這樣行了。既從祭司長得了權柄，我就把許多聖徒囚在監裡；他們被殺，我也出名定案。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 22:19; 馬太福音 10:17; 使徒行傳 13:45"> 在各會堂，我屢次用刑強逼他們說褻瀆的話，又分外惱恨他們，甚至追逼他們，直到外邦的城邑。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 26:10; 使徒行傳 22:5–11; 使徒行傳 9:1–8"> 那時，我領了祭司長的權柄和命令，往大馬士革去。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 17:2; 啟示錄 21:23; 啟示錄 1:16"> 王啊，我在路上，晌午的時候，看見從天發光，比日頭還亮，四面照著我並與我同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 21:40; 使徒行傳 22:2; 使徒行傳 9:7"> 我們都仆倒在地，我就聽見有聲音用希伯來話向我說：<span className="woj">『掃羅，掃羅，為什麼逼迫我？你用腳踢刺是難的。』</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 15:20–21; 馬太福音 25:45; 出埃及記 16:8"> 我說：『主啊，你是誰？』主說：<span className="woj">『我就是你所逼迫的耶穌。</span></span>
</div>
</div>

## 蒙派到外邦傳道

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 22:14–15; 以西結書 2:1; 但以理書 10:11"> <span className="woj">「你起來站著！我特意向你顯現，要派你做執事，作見證，將你所看見的事和我將要指示你的事證明出來。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 耶利米書 1:19"> <span className="woj">我也要救你脫離百姓和外邦人的手。</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前書 2:9; 以弗所書 1:18; 以弗所書 5:8"> <span className="woj">我差你到他們那裡去，要叫他們的眼睛得開，從黑暗中歸向光明，從撒旦權下歸向神；又因信我，得蒙赦罪，和一切成聖的人同得基業。』</span></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 50:5; 加拉太書 1:16; 以西結書 2:7–8"> 亞基帕王啊，我故此沒有違背那從天上來的異象，</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 3:8; 使徒行傳 3:19; 使徒行傳 2:38"> 先在大馬士革，後在耶路撒冷和猶太全地，以及外邦，勸勉他們應當悔改歸向神，行事與悔改的心相稱。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 21:30–31; 使徒行傳 21:27; 使徒行傳 25:3"> 因此猶太人在殿裡拿住我，想要殺我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 24:14; 約翰福音 5:46; 羅馬書 3:21"> 然而我蒙神的幫助，直到今日還站得住，對著尊貴、卑賤、老幼作見證。所講的並不外乎眾先知和摩西所說將來必成的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 53:1–12; 路加福音 24:26; 歌羅西書 1:18"> 就是基督必須受害，並且因從死裡復活，要首先把光明的道傳給百姓和外邦人。」</span>
</div>
</div>

## 非斯都說保羅癲狂

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 2:13–14; 哥林多前書 1:23; 哥林多前書 4:10"> 保羅這樣分訴，非斯都大聲說：「保羅，你癲狂了吧！你的學問太大，反叫你癲狂了！」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 23:26; 提多書 1:9; 提多書 2:7–8"> 保羅說：「非斯都大人，我不是癲狂，我說的乃是真實明白話。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:2–3; 使徒行傳 2:1–12; 以賽亞書 30:20"> 王也曉得這些事，所以我向王放膽直言；我深信這些事沒有一件向王隱藏的，因都不是在背地裡做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 26:22–23"> 亞基帕王啊，你信先知嗎？我知道你是信的。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 11:26; 馬太福音 10:18; 使徒行傳 26:29"> 亞基帕對保羅說：「你想稍微一勸，便叫我做基督徒啊？<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：你這樣勸我，幾乎叫我做基督徒了！">a</a></sup>」</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 6:20; 歌羅西書 1:28; 羅馬書 10:1"> 保羅說：「無論是少勸是多勸，我向神所求的，不但你一個人，就是今天一切聽我的，都要像我一樣，只是不要像我有這些鎖鏈。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 18:15; 使徒行傳 28:22; 使徒行傳 25:23"> 於是，王和巡撫並百妮基與同坐的人都起來，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 23:29; 使徒行傳 23:9; 使徒行傳 28:18"> 退到裡面，彼此談論說：「這人並沒有犯什麼該死、該綁的罪。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 28:18; 使徒行傳 25:11–12; 使徒行傳 25:25"> 亞基帕又對非斯都說：「這人若沒有上告於凱撒，就可以釋放了。」</span>
</div>
</div>

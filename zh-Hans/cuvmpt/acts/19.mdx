## 保羅遇見施洗約翰的門徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:23–28; 哥林多前書 16:12; 哥林多前書 1:12"> 亞波羅在哥林多的時候，保羅經過了上邊一帶地方，就來到以弗所。在那裡遇見幾個門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 7:39; 使徒行傳 11:15–17; 加拉太書 3:5"> 問他們說：「你們信的時候受了聖靈沒有？」他們回答說：「沒有，也未曾聽見有聖靈賜下來。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:25; 哥林多前書 12:13; 使徒行傳 8:16"> 保羅說：「這樣，你們受的是什麼洗呢？」他們說：「是約翰的洗。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 1:29–34; 使徒行傳 11:16; 使徒行傳 1:5"> 保羅說：「約翰所行的是悔改的洗，告訴百姓當信那在他以後要來的，就是耶穌。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 8:12; 使徒行傳 8:16; 羅馬書 6:3–4"> 他們聽見這話，就奉主耶穌的名受洗。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 6:6; 使徒行傳 2:4; 馬可福音 16:17"> 保羅按手在他們頭上，聖靈便降在他們身上，他們就說方言，又說預言<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：又講道。">a</a></sup>。</span>
<span className="v" id="v7" data-v="7"> 一共約有十二個人。</span>
</div>
</div>

## 保羅在推喇奴的學房辯論

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 28:23; 使徒行傳 1:3; 使徒行傳 9:20–22"> 保羅進會堂放膽講道，一連三個月，辯論神國的事，勸化眾人。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 19:23; 使徒行傳 9:2; 使徒行傳 18:6–8"> 後來，有些人心裡剛硬不信，在眾人面前毀謗這道，保羅就離開他們，也叫門徒與他們分離，便在推喇奴的學房天天辯論。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 20:31; 提摩太後書 1:15; 使徒行傳 16:6"> 這樣有兩年之久，叫一切住在亞細亞的，無論是猶太人是希臘人，都聽見主的道。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 16:17–20; 使徒行傳 5:12; 羅馬書 15:18–19"> 神藉保羅的手行了些非常的奇事，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:15; 列王紀下 13:20–21; 馬可福音 16:17"> 甚至有人從保羅身上拿手巾或圍裙放在病人身上，病就退了，惡鬼也出去了。</span>
</div>
</div>

## 被鬼附的勝了趕鬼的

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 12:27; 馬可福音 9:38; 路加福音 11:19"> 那時，有幾個遊行各處、念咒趕鬼的猶太人，向那被惡鬼附的人擅自稱主耶穌的名，說：「我奉保羅所傳的耶穌，敕令你們出來！」</span>
<span className="v" id="v14" data-v="14"> 做這事的，有猶太祭司長士基瓦的七個兒子。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 16:17–18; 路加福音 4:33–35; 馬可福音 1:34"> 惡鬼回答他們說：「耶穌我認識，保羅我也知道，你們卻是誰呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 馬可福音 5:3–4; 馬可福音 5:15"> 惡鬼所附的人就跳在他們身上，勝了其中二人，制伏他們，叫他們赤著身子受了傷，從那房子裡逃出去了。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 1:12; 使徒行傳 5:5; 腓立比書 2:9–11"> 凡住在以弗所的，無論是猶太人是希臘人，都知道這事，也都懼怕，主耶穌的名從此就尊大了。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 10:10; 詩篇 32:5; 馬太福音 3:6"> 那已經信的，多有人來承認訴說自己所行的事。</span>
</div>
</div>

## 行邪術的燒自己的書

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 13:8; 出埃及記 32:20; 創世記 35:4"> 平素行邪術的，也有許多人把書拿來，堆積在眾人面前焚燒。他們算計書價，便知道共合五萬塊錢。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 12:24; 使徒行傳 6:7; 以賽亞書 55:11"> 主的道大大興旺，而且得勝，就是這樣。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:22; 使徒行傳 20:16; 使徒行傳 23:11"> 這些事完了，保羅心裡定意經過了馬其頓、亞該亞，就往耶路撒冷去，又說：「我到了那裡以後，也必須往羅馬去看看。」</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 16:23; 提摩太後書 4:20; 使徒行傳 16:3"> 於是從幫助他的人中打發提摩太、以拉都二人往馬其頓去，自己暫時等在亞細亞。</span>
</div>
</div>

## 底米丟和銀匠鼓噪鬧事

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 19:9; 使徒行傳 24:22; 哥林多後書 1:8–10"> 那時，因為這道起的擾亂不小。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前書 6:9–10; 使徒行傳 16:16; 使徒行傳 16:19"> 有一個銀匠名叫底米丟，是製造亞底米神銀龕的，他使這樣手藝人生意發達。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:19; 何西阿書 12:7–8; 啟示錄 18:11–19"> 他聚集他們和同行的工人，說：「眾位，你們知道我們是倚靠這生意發財。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 17:29; 哥林多前書 8:4; 以賽亞書 44:10–20"> 這保羅不但在以弗所，也幾乎在亞細亞全地引誘迷惑許多人，說人手所做的不是神。這是你們所看見、所聽見的。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅書 2:11; 提摩太前書 6:5; 馬太福音 23:13"> 這樣，不獨我們這事業被人藐視，就是大女神亞底米的廟也要被人輕忽，連亞細亞全地和普天下所敬拜的大女神之威榮也要消滅了！」</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 13:4; 啟示錄 17:13; 使徒行傳 16:19–24"> 眾人聽見，就怒氣填胸，喊著說：「大哉，以弗所人的亞底米啊！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 20:4; 歌羅西書 4:10; 使徒行傳 27:2"> 滿城都轟動起來。眾人拿住與保羅同行的馬其頓人該猶和亞里達古，齊心擁進戲園裡去。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 21:39; 撒母耳記下 18:2–3; 使徒行傳 17:22–31"> 保羅想要進去到百姓那裡，門徒卻不許他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:10; 使徒行傳 21:12; 使徒行傳 16:6"> 還有亞細亞幾位首領，是保羅的朋友，打發人來勸他，不要冒險到戲園裡去。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 21:34; 使徒行傳 19:40; 馬太福音 11:7–9"> 聚集的人紛紛亂亂，有喊叫這個的，有喊叫那個的，大半不知道是為什麼聚集。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 12:17; 提摩太後書 4:14; 提摩太前書 1:20"> 有人把亞歷山大從眾人中帶出來，猶太人推他往前，亞歷山大就擺手，要向百姓分訴。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 19:28; 馬太福音 6:7; 啟示錄 13:4"> 只因他們認出他是猶太人，就大家同聲喊著說：「大哉，以弗所人的亞底米啊！」如此約有兩小時。</span>
</div>
</div>

## 以弗所的書記使眾人安靜

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 2:10–11; 提摩太前書 4:2; 以弗所書 2:12"> 那城裡的書記安撫了眾人，就說：「以弗所人哪，誰不知道以弗所人的城是看守大亞底米的廟和從宙斯那裡落下來的像呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行傳 5:35–39; 箴言 25:8"> 這事既是駁不倒的，你們就當安靜，不可造次。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多後書 6:3; 羅馬書 2:22; 使徒行傳 25:8"> 你們把這些人帶來，他們並沒有偷竊廟中之物，也沒有謗讟我們的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 13:7; 哥林多前書 6:1; 使徒行傳 18:14"> 若是底米丟和他同行的人有控告人的事，自有放告的日子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：自有公堂。">b</a></sup>，也有方伯可以彼此對告。</span>
<span className="v" id="v39" data-v="39"> 你們若問別的事，就可以照常例聚集斷定。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 17:5–8; 馬太福音 26:5; 使徒行傳 20:1"> 今日的擾亂本是無緣無故，我們難免被查問；論到這樣聚眾，我們也說不出所以然來。」</span>
<span className="v" id="v41" data-v="41" data-xref="傳道書 9:17; 詩篇 65:7; 哥林多後書 1:8–10"> 說了這話，便叫眾人散去。</span>
</div>
</div>

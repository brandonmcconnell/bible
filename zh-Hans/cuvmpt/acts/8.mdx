## 教會被害門徒分散

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 22:20; 但以理書 3:16–18; 使徒行傳 5:40"> 從這日起，耶路撒冷的教會大遭逼迫。除了使徒以外，門徒都分散在猶太和撒馬利亞各處。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:10–11; 創世記 23:2; 耶利米書 22:18"> 有虔誠的人把司提反埋葬了，為他捶胸大哭。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 1:13; 加拉太書 1:13; 哥林多前書 15:9"> 掃羅卻殘害教會，進各人的家，拉著男女下在監裡。</span>
</div>
</div>

## 腓利往撒馬利亞傳道

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:23; 使徒行傳 11:19; 使徒行傳 8:1"> 那些分散的人往各處去傳道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 6:5; 使徒行傳 21:8; 使徒行傳 8:35–36"> 腓利下撒馬利亞城去宣講基督。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 4:41–42; 歷代志下 30:12; 馬太福音 20:15–16"> 眾人聽見了，又看見腓利所行的神蹟，就同心合意地聽從他的話。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:1; 使徒行傳 14:8–10; 馬可福音 16:17–18"> 因為有許多人被汙鬼附著，那些鬼大聲呼叫，從他們身上出來；還有許多癱瘓的、瘸腿的，都得了醫治。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:52; 使徒行傳 13:48; 使徒行傳 8:39"> 在那城裡就大有歡喜。</span>
</div>
</div>

## 行邪術的西門

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 13:6; 使徒行傳 5:36; 約翰福音 7:18"> 有一個人名叫西門，向來在那城裡行邪術，妄自尊大，使撒馬利亞的百姓驚奇。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:34; 彼得後書 2:2; 啟示錄 13:3"> 無論大小都聽從他，說：「這人就是那稱為神的大能者。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 8:9; 加拉太書 3:1; 以賽亞書 44:25"> 他們聽從他，因他久用邪術使他們驚奇。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 2:38; 使徒行傳 1:3; 馬太福音 28:19"> 及至他們信了腓利所傳神國的福音和耶穌基督的名，連男帶女就受了洗。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:6–7; 約翰福音 5:20; 使徒行傳 19:11"> 西門自己也信了，既受了洗，就常與腓利在一處，看見他所行的神蹟和大異能，就甚驚奇。</span>
</div>
</div>

## 彼得約翰傳教於撒馬利亞

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:13; 帖撒羅尼迦前書 3:2; 加拉太書 2:9"> 使徒在耶路撒冷聽見撒馬利亞人領受了神的道，就打發彼得、約翰往他們那裡去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:38; 約翰福音 16:23–24; 約翰福音 14:13–14"> 兩個人到了，就為他們禱告，要叫他們受聖靈，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:38; 使徒行傳 19:2; 馬太福音 28:19"> 因為聖靈還沒有降在他們一個人身上，他們只奉主耶穌的名受了洗。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 19:6; 使徒行傳 6:6; 提摩太後書 1:6"> 於是使徒按手在他們頭上，他們就受了聖靈。</span>
</div>
</div>

## 西門貪心受責

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 6:5; 馬太福音 10:8; 列王紀下 8:9"> 西門看見使徒按手便有聖靈賜下，就拿錢給使徒，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 約翰三書 1:9; 約翰福音 5:44"> 說：「把這權柄也給我，叫我手按著誰，誰就可以受聖靈。」</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 5:17; 馬太福音 10:8; 使徒行傳 2:38"> 彼得說：「你的銀子和你一同滅亡吧！因你想神的恩賜是可以用錢買的。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 4:13; 詩篇 36:1; 馬太福音 6:22–24"> 你在這道上無份無關，因為在神面前你的心不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太後書 2:25–26; 但以理書 4:27; 希伯來書 4:12"> 你當懊悔你這罪惡，祈求主，或者你心裡的意念可得赦免。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 58:6; 箴言 5:22; 約翰福音 8:34"> 我看出你正在苦膽之中，被罪惡捆綁。」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 8:8; 民數記 21:7; 約伯記 42:8"> 西門說：「願你們為我求主，叫你們所說的，沒有一樣臨到我身上！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 20:21; 使徒行傳 26:22–23; 使徒行傳 1:8"> 使徒既證明主道而且傳講，就回耶路撒冷去，一路在撒馬利亞好些村莊傳揚福音。</span>
</div>
</div>

## 腓利傳道於埃塞俄比亞的太監

<div className="bt">
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:19; 希伯來書 1:14; 列王紀下 1:3"> 有主的一個使者對腓利說：「起來，向南走，往那從耶路撒冷下加沙的路上去！」那路是曠野。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅書 3:10; 詩篇 68:31; 以賽亞書 56:3–8"> 腓利就起身去了。不料，有一個埃塞俄比亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即古實，見《以賽亞書》18章1節。">a</a></sup>人，是個有大權的太監，在埃塞俄比亞女王干大基的手下總管銀庫。他上耶路撒冷禮拜去了，</span>
<span className="v" id="v28" data-v="28" data-xref="歌羅西書 3:16; 以賽亞書 1:1; 使徒行傳 28:25"> 現在回來，在車上坐著，念先知以賽亞的書。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 10:19; 使徒行傳 11:12; 使徒行傳 20:22–23"> 聖靈對腓利說：「你去，貼近那車走！」</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 約翰福音 5:39; 以弗所書 5:17"> 腓利就跑到太監那裡，聽見他念先知以賽亞的書，便問他說：「你所念的你明白嗎？」</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 10:14; 詩篇 73:16–17; 以賽亞書 29:18–19"> 他說：「沒有人指教我，怎能明白呢？」於是請腓利上車與他同坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 53:7–8; 彼得前書 2:21–24; 耶利米書 51:40"> 他所念的那段經說：<br /><span className="pl pl-1">「他像羊被牽到宰殺之地，</span><br /><span className="pl pl-1">又像羊羔在剪毛的人手下無聲，</span><br /><span className="pl pl-1">他也是這樣不開口。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 53:12; 以賽亞書 53:8; 撒迦利亞書 13:7"> <span className="pl pl-1">他卑微的時候，</span><br /><span className="pl pl-1">人不按公義審判他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：他的審判被奪去。">b</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">誰能述說他的世代？</span><br /><span className="pl pl-1">因為他的生命從地上奪去。』</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 15:15; 馬太福音 13:36; 馬太福音 2:2–4"> 太監對腓利說：「請問，先知說這話是指著誰？是指著自己呢，是指著別人呢？」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行傳 18:28; 使徒行傳 28:23"> 腓利就開口從這經上起，對他傳講耶穌。</span>
</div>
</div>

## 太監信而受洗

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 10:47; 約翰福音 3:5; 提多書 3:5–6"> 二人正往前走，到了有水的地方，太監說：「看哪，這裡有水！我受洗有什麼妨礙呢？」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷在此有：37 腓利說：「你若是一心相信，就可以。」他回答說：「我信耶穌基督是神的兒子。」">c</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 4:1; 約翰福音 3:22–23"> 於是吩咐車站住，腓利和太監二人同下水裡去，腓利就給他施洗。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:12; 列王紀下 2:16; 以西結書 8:3"> 從水裡上來，主的靈把腓利提了去。太監也不再見他了，就歡歡喜喜地走路。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 21:8; 使徒行傳 23:23; 使徒行傳 23:33"> 後來有人在亞鎖都遇見腓利；他走遍那地方，在各城宣傳福音，直到凱撒利亞。</span>
</div>

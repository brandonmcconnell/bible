## 保羅坐船往意大利去

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 25:25; 使徒行傳 25:12; 使徒行傳 10:1"> 非斯都既然定規了叫我們坐船往意大利去，便將保羅和別的囚犯交給御營裡的一個百夫長，名叫猶流。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 19:29; 腓利門書 1:24; 歌羅西書 4:10"> 有一隻亞大米田的船要沿著亞細亞一帶地方的海邊走，我們就上了那船開行，有馬其頓的帖撒羅尼迦人亞里達古和我們同去。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 24:23; 使徒行傳 28:16; 使徒行傳 27:43"> 第二天，到了西頓，猶流寬待保羅，准他往朋友那裡去，受他們的照應。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:36; 使徒行傳 15:39; 使徒行傳 13:4"> 從那裡又開船，因為風不順，就貼著塞浦路斯背風岸行去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 6:9; 使徒行傳 13:13; 使徒行傳 15:41"> 過了基利家、旁非利亞前面的海，就到了呂家的每拉。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 28:11; 使徒行傳 27:1; 使徒行傳 6:9"> 在那裡，百夫長遇見一隻亞歷山大的船要往意大利去，便叫我們上了那船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 27:21; 提多書 1:5; 提多書 1:12"> 一連多日，船行得慢，僅僅來到革尼土的對面。因為被風攔阻，就貼著克里特背風岸，從撒摩尼對面行過。</span>
<span className="v" id="v8" data-v="8"> 我們沿岸行走，僅僅來到一個地方，名叫佳澳，離那裡不遠有拉西亞城。</span>
</div>
</div>

## 保羅勸眾

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 29:7; 利未記 23:27–29; 利未記 16:29–31"> 走的日子多了，已經過了禁食的節期，行船又危險，保羅就勸眾人說：</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 2:30; 使徒行傳 27:20–26; 使徒行傳 27:41–44"> 「眾位，我看這次行船，不但貨物和船要受傷損，大遭破壞，連我們的性命也難保。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 33:4; 希伯來書 11:7; 以西結書 3:17–18"> 但百夫長信從掌船的和船主，不信從保羅所說的。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:30; 使徒行傳 27:8"> 且因在這海口過冬不便，船上的人就多半說，不如開船離開這地方，或者能到非尼基過冬。非尼基是克里特的一個海口，一面朝東北，一面朝東南。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 約伯記 37:17"> 這時微微起了南風，他們以為得意，就起了錨，貼近克里特行去。</span>
</div>
</div>

## 水路的危險

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬可福音 4:37; 詩篇 107:25–27; 出埃及記 14:21–27"> 不多幾時，狂風從島上撲下來，那風名叫友拉革羅。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:4; 使徒行傳 27:27"> 船被風抓住，敵不住風，我們就任風颳去。</span>
<span className="v" id="v16" data-v="16"> 貼著一個小島的背風岸奔行，那島名叫高大，在那裡僅僅收住了小船。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 27:29; 使徒行傳 27:26; 使徒行傳 27:41"> 既然把小船拉上來，就用纜索捆綁船底，又恐怕在賽耳底沙灘上擱了淺，就落下篷來，任船飄去。</span>
<span className="v" id="v18" data-v="18" data-xref="約拿書 1:5; 使徒行傳 27:38; 馬太福音 16:26"> 我們被風浪逼得甚急，第二天眾人就把貨物拋在海裡。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:4; 路加福音 9:24–25; 馬可福音 8:35–37"> 到第三天，他們又親手把船上的器具拋棄了。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:29; 馬太福音 8:24–25; 耶利米書 2:25"> 太陽和星辰多日不顯露，又有狂風大浪催逼，我們得救的指望就都絕了。</span>
</div>
</div>

## 安慰眾人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 詩篇 107:5–6; 使徒行傳 27:7"> 眾人多日沒有吃什麼，保羅就出來站在他們中間，說：「眾位，你們本該聽我的話不離開克里特，免得遭這樣的傷損破壞。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 27:25; 使徒行傳 27:36; 哥林多後書 4:8–9"> 現在我還勸你們放心，你們的性命一個也不失喪，唯獨失喪這船。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 23:11; 羅馬書 1:9; 提摩太後書 4:17"> 因我所屬、所侍奉的神，他的使者昨夜站在我旁邊說：</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 23:11; 提摩太後書 4:16–17; 馬太福音 10:28"> 『保羅，不要害怕！你必定站在凱撒面前；並且與你同船的人，神都賜給你了。』</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 4:20–21; 路加福音 1:45; 民數記 23:19"> 所以眾位可以放心，我信神他怎樣對我說，事情也要怎樣成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 28:1; 使徒行傳 27:17; 使徒行傳 27:29"> 只是我們必要撞在一個島上。」</span>
</div>
</div>

## 水手想逃

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約拿書 1:6; 使徒行傳 27:30; 啟示錄 18:17"> 到了第十四天夜間，船在亞得里亞海飄來飄去，約到半夜，水手以為漸近旱地，</span>
<span className="v" id="v28" data-v="28"> 就探深淺，探得有十二丈；稍往前行，又探深淺，探得有九丈。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 27:17; 希伯來書 6:19; 申命記 28:67"> 恐怕撞在石頭上，就從船尾拋下四個錨，盼望天亮。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 27:16; 使徒行傳 27:32"> 水手想要逃出船去，把小船放在海裡，假作要從船頭拋錨的樣子。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦後書 2:13–14; 詩篇 91:11–12; 耶利米書 29:11–13"> 保羅對百夫長和兵丁說：「這些人若不等在船上，你們必不能得救。」</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比書 3:7–9; 路加福音 16:8"> 於是兵丁砍斷小船的繩子，由它飄去。</span>
<span className="v" id="v33" data-v="33"> 天漸亮的時候，保羅勸眾人都吃飯，說：「你們懸望忍餓不吃什麼，已經十四天了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:30; 列王紀上 1:52; 路加福音 21:18"> 所以我勸你們吃飯，這是關乎你們救命的事，因為你們各人連一根頭髮也不至於損壞。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 15:36; 哥林多前書 10:30–31; 提摩太前書 4:3–4"> 保羅說了這話，就拿著餅，在眾人面前祝謝了神，掰開吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多後書 1:4–6; 使徒行傳 27:22; 詩篇 27:14"> 於是他們都放下心，也就吃了。</span>
</div>
</div>

## 船被大浪損壞

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 2:41; 羅馬書 13:1; 彼得前書 3:20"> 我們在船上的共有二百七十六個人。</span>
<span className="v" id="v38" data-v="38" data-xref="約拿書 1:5; 馬太福音 6:25; 使徒行傳 27:18–19"> 他們吃飽了，就把船上的麥子拋在海裡，為要叫船輕一點。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 28:1"> 到了天亮，他們不認識那地方，但見一個海灣有岸可登，就商議能把船攏進去不能。</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 33:23; 使徒行傳 27:29–30"> 於是砍斷纜索，棄錨在海裡，同時也鬆開舵繩，拉起頭篷，順著風向岸行去。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多後書 11:25–26; 以西結書 27:26; 使徒行傳 27:26–29"> 但遇著兩水夾流的地方，就把船擱了淺，船頭膠住不動，船尾被浪的猛力衝壞。</span>
</div>
</div>

## 眾人得救

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬可福音 15:15–20; 傳道書 9:3; 詩篇 74:20"> 兵丁的意思要把囚犯殺了，恐怕有洑水脫逃的。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 27:3; 箴言 16:7; 使徒行傳 27:11"> 但百夫長要救保羅，不准他們任意而行，就吩咐會洑水的跳下水去先上岸，</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 27:22; 詩篇 107:28–30; 約翰福音 6:39–40"> 其餘的人可以用板子或船上的零碎東西上岸。這樣，眾人都得了救，上了岸。</span>
</div>
</div>

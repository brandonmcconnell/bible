## 哥尼流蒙主指示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 27:1; 馬太福音 8:5–13; 馬太福音 27:27"> 在凱撒利亞有一個人名叫哥尼流，是「意大利營」的百夫長。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 7:7–8; 使徒行傳 10:4; 使徒行傳 10:22"> 他是個虔誠人，他和全家都敬畏神，多多賙濟百姓，常常禱告神。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 9:20–21; 使徒行傳 3:1; 使徒行傳 5:19"> 有一天，約在申初，他在異象中明明看見神的一個使者進去，到他那裡，說：「哥尼流！」</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 4:6; 希伯來書 6:10; 使徒行傳 10:31"> 哥尼流定睛看他，驚怕說：「主啊，什麼事呢？」天使說：「你的禱告和你的賙濟達到神面前，已蒙記念了。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 16:9; 使徒行傳 9:38; 使徒行傳 15:7"> 現在你當打發人往約帕去，請那稱呼彼得的西門來。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 9:43; 使徒行傳 11:13–14; 羅馬書 10:14–17"> 他住在海邊一個硝皮匠西門的家裡，房子在海邊上。」</span>
<span className="v" id="v7" data-v="7" data-xref="腓利門書 1:16; 撒母耳記上 14:6–7; 馬太福音 8:9–10"> 向他說話的天使去後，哥尼流叫了兩個家人和常伺候他的一個虔誠兵來，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:36; 詩篇 119:59–60; 使徒行傳 10:33"> 把這事都述說給他們聽，就打發他們往約帕去。</span>
</div>
</div>

## 彼得見異象

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="西番雅書 1:5; 詩篇 55:17; 撒母耳記上 9:25"> 第二天，他們行路將近那城，彼得約在午正上房頂去禱告。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 22:17; 啟示錄 4:2–3; 哥林多後書 12:2–4"> 覺得餓了，想要吃。那家的人正預備飯的時候，彼得魂遊象外，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:6; 約翰福音 1:51; 羅馬書 16:25–26"> 看見天開了，有一物降下，好像一塊大布，繫著四角，縋在地上，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:8–9; 約翰福音 7:37; 哥林多前書 6:9–11"> 裡面有地上各樣四足的走獸和昆蟲，並天上的飛鳥。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 4:31–34; 耶利米書 35:2–5; 使徒行傳 10:10"> 又有聲音向他說：<span className="woj">「彼得，起來，宰了吃！」</span></span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:25; 以西結書 4:14; 但以理書 1:8"> 彼得卻說：「主啊，這是不可的！凡俗物和不潔淨的物，我從來沒有吃過。」</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 10:25; 馬太福音 15:11; 提多書 1:15"> 第二次有聲音向他說：<span className="woj">「神所潔淨的，你不可當做俗物。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 41:32; 約翰福音 21:17; 哥林多後書 13:1"> 這樣一連三次，那物隨即收回天上去了。</span>
</div>
</div>

## 哥尼流所差的人來尋彼得

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 13:12; 使徒行傳 10:7–19; 使徒行傳 5:24"> 彼得心裡正在猜疑之間，不知所看見的異象是什麼意思，哥尼流所差來的人已經訪問到西門的家，站在門外，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 10:5–6; 使徒行傳 11:11"> 喊著問：「有稱呼彼得的西門住在這裡沒有？」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 8:29; 使徒行傳 11:12; 使徒行傳 21:4"> 彼得還思想那異象的時候，聖靈向他說：「有三個人來找你。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 15:7–9; 撒迦利亞書 2:9–11; 以賽亞書 48:16"> 起來，下去，和他們同往，不要疑惑，因為是我差他們來的。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 1:38–39; 馬可福音 10:51; 使徒行傳 10:29"> 於是彼得下去見那些人，說：「我就是你們所找的人。你們來是為什麼緣故？」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 11:14; 使徒行傳 10:2; 使徒行傳 22:12"> 他們說：「百夫長哥尼流是個義人，敬畏神，為猶太通國所稱讚。他蒙一位聖天使指示，叫他請你到他家裡去，聽你的話。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 10:45; 使徒行傳 11:12; 彼得前書 4:9"> 彼得就請他們進去，住了一宿。 彼得往哥尼流家傳道<br />次日起身和他們同去，還有約帕的幾個弟兄同著他去。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 8:40; 撒迦利亞書 8:20–23; 撒迦利亞書 3:10"> 又次日，他們進入凱撒利亞。哥尼流已經請了他的親屬密友等候他們。</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 19:10; 啟示錄 22:8–9; 但以理書 2:46"> 彼得一進去，哥尼流就迎接他，俯伏在他腳前拜他。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 19:10; 啟示錄 22:8–9; 使徒行傳 14:14–15"> 彼得卻拉他，說：「你起來，我也是人。」</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 2:12; 約翰福音 4:35; 使徒行傳 10:24"> 彼得和他說著話進去，見有好些人在那裡聚集，</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 4:9; 以弗所書 3:6–7; 加拉太書 2:12–14"> 就對他們說：「你們知道，猶太人和別國的人親近來往本是不合例的，但神已經指示我，無論什麼人都不可看做俗而不潔淨的。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:60; 彼得前書 3:15; 使徒行傳 10:19–20"> 所以我被請的時候，就不推辭而來。現在請問：你們叫我來有什麼意思呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 10:3; 但以理書 9:20–21; 尼希米記 9:1–3"> 哥尼流說：「前四天這個時候，我在家中守著申初的禱告，忽然有一個人穿著光明的衣裳，站在我面前，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 10:4; 但以理書 9:23; 路加福音 1:13"> 說：『哥尼流，你的禱告已蒙垂聽，你的賙濟達到神面前已蒙記念了。</span>
<span className="v" id="v32" data-v="32"> 你當打發人往約帕去，請那稱呼彼得的西門來，他住在海邊一個硝皮匠西門的家裡。』</span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 1:19; 加拉太書 4:14; 歷代志下 30:12"> 所以我立時打發人去請你。你來了很好！現今我們都在神面前，要聽主所吩咐你的一切話。」</span>
</div>
</div>

## 彼得宣傳耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="羅馬書 2:11; 歷代志下 19:7; 申命記 10:17"> 彼得就開口說：「我真看出神是不偏待人，</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:29; 使徒行傳 10:2; 羅馬書 10:12–13"> 原來各國中那敬畏主、行義的人都為主所悅納。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 28:18; 使徒行傳 2:36; 啟示錄 17:14"> 神藉著耶穌基督——他是萬有的主——傳和平的福音，將這道賜給以色列人。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 4:14; 使徒行傳 2:22; 使徒行傳 28:22"> 這話在約翰宣傳洗禮以後，從加利利起，傳遍了猶太。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:18; 使徒行傳 2:22; 以賽亞書 61:1–3"> 神怎樣以聖靈和能力膏拿撒勒人耶穌，這都是你們知道的。他周流四方，行善事，醫好凡被魔鬼壓制的人，因為神與他同在。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:48; 使徒行傳 1:8; 使徒行傳 10:41"> 他在猶太人之地並耶路撒冷所行的一切事，有我們作見證。他們竟把他掛在木頭上殺了！</span>
<span className="v" id="v40" data-v="40" data-xref="彼得前書 1:21; 使徒行傳 13:30–31; 哥林多前書 15:3–4"> 第三日，神叫他復活，顯現出來，</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 14:22; 使徒行傳 10:39; 約翰福音 21:13"> 不是顯現給眾人看，乃是顯現給神預先所揀選為他作見證的人看，就是我們這些在他從死裡復活以後和他同吃同喝的人。</span>
<span className="v" id="v42" data-v="42" data-xref="哥林多後書 5:10; 提摩太後書 4:1; 彼得前書 4:5"> 他吩咐我們傳道給眾人，證明他是神所立定的，要做審判活人、死人的主。</span>
<span className="v" id="v43" data-v="43" data-xref="撒迦利亞書 13:1; 使徒行傳 2:38; 以賽亞書 53:11"> 眾先知也為他作見證說：『凡信他的人，必因他的名得蒙赦罪。』」</span>
</div>
</div>

## 聖靈降在眾人身上

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 11:15; 使徒行傳 19:6; 使徒行傳 15:8"> 彼得還說這話的時候，聖靈降在一切聽道的人身上。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行傳 10:23; 使徒行傳 2:38; 加拉太書 3:13–14"> 那些奉割禮、和彼得同來的信徒，見聖靈的恩賜也澆在外邦人身上，就都稀奇，</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 19:6; 使徒行傳 2:4; 馬可福音 16:17"> 因聽見他們說方言，稱讚神為大。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 8:36; 羅馬書 10:12; 使徒行傳 11:15–17"> 於是彼得說：「這些人既受了聖靈，與我們一樣，誰能禁止用水給他們施洗呢？」</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 2:38; 使徒行傳 8:16; 加拉太書 3:27"> 就吩咐奉耶穌基督的名給他們施洗。他們又請彼得住了幾天。</span>
</div>

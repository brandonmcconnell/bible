## 土人的接待

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 27:26; 使徒行傳 27:44; 使徒行傳 27:39"> 我們既已得救，才知道那島名叫馬耳他。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:14; 希伯來書 13:2; 歌羅西書 3:11"> 土人看待我們有非常的情分，因為當時下雨，天氣又冷，就生火接待我們眾人。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 23:33; 馬太福音 12:34; 使徒行傳 28:4"> 那時，保羅拾起一捆柴，放在火上，有一條毒蛇因為熱了出來，咬住他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 約翰福音 7:24"> 土人看見那毒蛇懸在他手上，就彼此說：「這人必是個凶手，雖然從海裡救上來，天理還不容他活著。」</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 馬可福音 16:18; 詩篇 91:13"> 保羅竟把那毒蛇甩在火裡，並沒有受傷。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 12:22; 使徒行傳 14:11–13; 馬太福音 21:9"> 土人想他必要腫起來，或是忽然仆倒死了。看了多時，見他無害，就轉念說：「他是個神！」</span>
</div>
</div>

## 部百流款待保羅

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:40–41; 路加福音 19:6–9; 使徒行傳 28:2"> 離那地方不遠，有田產是島長部百流的。他接納我們，盡情款待三日。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:40; 馬可福音 6:5; 雅各書 5:14–16"> 當時，部百流的父親患熱病和痢疾躺著。保羅進去為他禱告，按手在他身上，治好了他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 5:12; 馬可福音 6:54–56; 使徒行傳 5:15"> 從此，島上其餘的病人也來，得了醫治。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒羅尼迦前書 2:6; 腓立比書 4:11–12; 馬太福音 6:31–34"> 他們又多方地尊敬我們，到了開船的時候，也把我們所需用的送到船上。</span>
</div>
</div>

## 再行水程

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 27:6; 哥林多前書 8:4; 以賽亞書 45:20"> 過了三個月，我們上了亞歷山大的船往前行。這船以「宙斯雙子」為記，是在那海島過了冬的。</span>
<span className="v" id="v12" data-v="12"> 到了敘拉古，我們停泊三日，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 27:13"> 又從那裡繞行，來到利基翁。過了一天，起了南風，第二天就來到部丟利。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 21:4; 使徒行傳 20:6; 使徒行傳 19:1"> 在那裡遇見弟兄們，請我們與他們同住了七天。這樣，我們來到羅馬。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:3; 羅馬書 15:24; 出埃及記 4:14"> 那裡的弟兄們一聽見我們的信息，就出來到亞比烏市和三館地方迎接我們。保羅見了他們，就感謝神，放心壯膽。</span>
</div>
</div>

## 進了羅馬城

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 27:3; 使徒行傳 24:23; 使徒行傳 28:30–31"> 進了羅馬城，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：百夫長把眾囚犯交給御營的統領，唯有。">a</a></sup>保羅蒙准和一個看守他的兵另住在一處。</span>
</div>
</div>

## 保羅請猶太的首領來聲明上控的緣由

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 25:8; 使徒行傳 6:14; 使徒行傳 25:10"> 過了三天，保羅請猶太人的首領來。他們來了，就對他們說：「弟兄們，我雖沒有做什麼事干犯本國的百姓和我們祖宗的規條，卻被鎖綁，從耶路撒冷解在羅馬人的手裡。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:31–32; 使徒行傳 23:29; 使徒行傳 22:24–25"> 他們審問了我，就願意釋放我，因為在我身上並沒有該死的罪。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 26:32; 使徒行傳 25:21; 使徒行傳 25:10–12"> 無奈猶太人不服，我不得已，只好上告於凱撒，並非有什麼事要控告我本國的百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:20; 提摩太後書 2:9; 使徒行傳 26:6–7"> 因此，我請你們來見面說話。我原為以色列人所指望的，被這鏈子捆鎖。」</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 54:17; 以賽亞書 41:11; 以賽亞書 50:8"> 他們說：「我們並沒有接著從猶太來論你的信，也沒有弟兄到這裡來報給我們說你有什麼不好處。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:12; 使徒行傳 24:14; 彼得前書 3:16"> 但我們願意聽你的意見如何，因為這教門我們曉得是到處被毀謗的。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 17:2–3; 使徒行傳 19:8; 使徒行傳 18:28"> 他們和保羅約定了日子，就有許多人到他的寓處來。保羅從早到晚，對他們講論這事，證明神國的道，引摩西的律法和先知的書，以耶穌的事勸勉他們。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 14:4; 使徒行傳 17:4–5; 使徒行傳 19:8–9"> 他所說的話，有信的，有不信的。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 15:7; 彼得後書 1:21; 馬可福音 7:6"> 他們彼此不合，就散了。未散以先，保羅說了一句話，說：「聖靈藉先知以賽亞向你們祖宗所說的話是不錯的。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 6:9–10; 以西結書 12:2; 以賽亞書 42:19–20"> 他說：<br /><span className="pl pl-1">『你去告訴這百姓說：</span><br /><span className="pl pl-1">你們聽是要聽見，卻不明白；</span><br /><span className="pl pl-1">看是要看見，卻不曉得。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 6:10"> <span className="pl pl-1">因為這百姓油蒙了心，</span><br /><span className="pl pl-1">耳朵發沉，</span><br /><span className="pl pl-1">眼睛閉著，</span><br /><span className="pl pl-1">恐怕眼睛看見，</span><br /><span className="pl pl-1">耳朵聽見，</span><br /><span className="pl pl-1">心裡明白，回轉過來，</span><br /><span className="pl pl-1">我就醫治他們。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行傳 26:17–18; 羅馬書 3:29–30"> 所以你們當知道，神這救恩如今傳給外邦人，他們也必聽受。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷在此有：29 保羅說了這話，猶太人議論紛紛地就走了。">b</a></sup></span>
</div>
</div>

## 保羅在羅馬傳道足足兩年

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30"> 保羅在自己所租的房子裡住了足足兩年。凡來見他的人，他全都接待，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 4:29; 以弗所書 6:19–20; 馬太福音 4:23"> 放膽傳講神國的道，將主耶穌基督的事教導人，並沒有人禁止。</span>
</div>
</div>

<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 2:3; 帖撒羅尼迦前書 4:1; 歌羅西書 1:28"> 走遍了那一帶地方，用許多話勸勉門徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：眾人。">a</a></sup>，然後來到希臘。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 20:19; 哥林多後書 11:26; 使徒行傳 9:23–24"> 在那裡住了三個月，將要坐船往敘利亞去，猶太人設計要害他，他就定意從馬其頓回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 19:29; 以弗所書 6:21; 提摩太後書 4:20"> 同他到亞細亞去的，有庇哩亞人畢羅斯的兒子所巴特，帖撒羅尼迦人亞里達古和西公都，還有特庇人該猶並提摩太，又有亞細亞人推基古和特羅非摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 16:8; 使徒行傳 16:10–11; 提摩太後書 4:13"> 這些人先走，在特羅亞等候我們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 12:3; 使徒行傳 16:12; 出埃及記 23:15"> 過了除酵的日子，我們從腓立比開船，五天到了特羅亞，和他們相會，在那裡住了七天。</span>
</div>
</div>

## 保羅在特羅亞使猶推古復活

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 16:2; 使徒行傳 2:42; 約翰福音 20:19"> 七日的第一日，我們聚會掰餅的時候，保羅因為要次日起行，就與他們講論，直講到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:13; 路加福音 22:12"> 我們聚會的那座樓上，有好些燈燭。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 13:36; 馬太福音 26:40–41; 約拿書 1:5–6"> 有一個少年人名叫猶推古，坐在窗臺上，困倦沉睡。保羅講了多時，少年人睡熟了，就從三層樓上掉下去。扶起他來，已經死了。</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 5:39; 馬太福音 9:23–24; 列王紀上 17:21–22"> 保羅下去，伏在他身上，抱著他說：「你們不要發慌，他的靈魂還在身上。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 20:7; 使徒行傳 20:9"> 保羅又上去，掰餅吃了，談論許久，直到天亮，這才走了。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦後書 2:16; 帖撒羅尼迦前書 5:14; 哥林多後書 1:4"> 有人把那童子活活地領來，得的安慰不小。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 6:46; 馬可福音 1:35; 馬可福音 6:31–33"> 我們先上船開往亞朔去，意思要在那裡接保羅；因為他是這樣安排的，他自己打算要步行。</span>
<span className="v" id="v14" data-v="14"> 他既在亞朔與我們相會，我們就接他上船，來到米推利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 4:20; 使徒行傳 20:17"> 從那裡開船，次日到了基阿的對面；又次日，在撒摩靠岸；又次日，來到米利都。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:8; 使徒行傳 2:1; 使徒行傳 19:21"> 乃因保羅早已定意越過以弗所，免得在亞細亞耽延；他急忙前走，巴不得趕五旬節能到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多書 1:5; 使徒行傳 11:30; 提摩太前書 5:17"> 保羅從米利都打發人往以弗所去，請教會的長老來。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 1:5–6; 使徒行傳 18:19; 使徒行傳 19:1"> 他們來了，保羅就說：「你們知道自從我到亞細亞的日子以來，在你們中間始終為人如何，</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:24; 哥林多後書 2:4; 羅馬書 12:11"> 服侍主凡事謙卑，眼中流淚，又因猶太人的謀害經歷試煉。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 20:27; 提摩太後書 4:2; 使徒行傳 5:42"> 你們也知道，凡於你們有益的，我沒有一樣避諱不說的，或在眾人面前，或在各人家裡，我都教導你們。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 2:38; 使徒行傳 11:18; 約翰一書 5:11–13"> 又對猶太人和希臘人證明當向神悔改，信靠我主耶穌基督。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 4:14; 哥林多後書 5:14; 彼得後書 1:14"> 現在我往耶路撒冷去，心甚迫切<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：心被捆綁。">b</a></sup>，不知道在那裡要遇見什麼事。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 9:16; 帖撒羅尼迦前書 3:3; 使徒行傳 21:4"> 但知道聖靈在各城裡向我指證，說有捆鎖與患難等待我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:6–8; 哥林多後書 4:1; 哥林多後書 12:10"> 我卻不以性命為念，也不看為寶貴，只要行完我的路程，成就我從主耶穌所領受的職事，證明神恩惠的福音。</span>
</div>
</div>

## 謹慎勸勉

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 28:31; 使徒行傳 20:38; 馬太福音 4:23"> 「我素常在你們中間來往，傳講神國的道，如今我曉得，你們以後都不得再見我的面了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 18:6; 以西結書 3:18–21; 以西結書 33:2–9"> 所以我今日向你們證明，你們中間無論何人死亡，罪不在我身上<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：我於眾人的血是潔淨的。">c</a></sup>，</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 20:20; 帖撒羅尼迦前書 2:4; 加拉太書 1:7–10"> 因為神的旨意我並沒有一樣避諱不傳給你們的。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 5:2–3; 提摩太前書 4:16; 以賽亞書 40:11"> 聖靈立你們做全群的監督，你們就當為自己謹慎，也為全群謹慎，牧養神的教會，就是他用自己血所買來的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：救贖的。">d</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 7:15; 彼得後書 2:1; 約翰福音 10:12"> 我知道我去之後，必有凶暴的豺狼進入你們中間，不愛惜羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前書 1:19–20; 提摩太後書 4:3–4; 箴言 23:33"> 就是你們中間也必有人起來，說悖謬的話，要引誘門徒跟從他們。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:8; 使徒行傳 20:19; 使徒行傳 19:10"> 所以你們應當警醒，記念我三年之久晝夜不住地流淚勸誡你們各人。</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 1:12; 以弗所書 1:14; 歌羅西書 3:24"> 如今我把你們交託神和他恩惠的道，這道能建立你們，叫你們和一切成聖的人同得基業。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 11:9; 哥林多前書 9:12; 哥林多前書 9:18"> 我未曾貪圖一個人的金、銀、衣服。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 18:3; 哥林多前書 4:12; 帖撒羅尼迦後書 3:8–9"> 我這兩隻手常供給我和同人的需用，這是你們自己知道的。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 13:16; 箴言 19:17; 哥林多後書 9:6–12"> 我凡事給你們做榜樣，叫你們知道應當這樣勞苦扶助軟弱的人，又當記念主耶穌的話說：<span className="woj">『施比受更為有福。』</span>」</span>
</div>
</div>

## 保羅同眾人禱告辭別他們

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 21:5; 路加福音 22:41; 腓立比書 4:6"> 保羅說完了這話，就跪下同眾人禱告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太後書 1:4; 哥林多前書 16:20; 帖撒羅尼迦前書 5:26"> 眾人痛哭，抱著保羅的頸項，和他親嘴。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 15:3; 哥林多前書 16:11; 使徒行傳 20:25"> 叫他們最傷心的，就是他說「以後不能再見我的面」那句話。於是送他上船去了。</span>
</div>

## 保羅向百姓聲明

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:2; 使徒行傳 28:17; 使徒行傳 13:26"> 「諸位父兄，請聽我現在對你們分訴！」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 21:40"> 眾人聽他說的是希伯來話，就更加安靜了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:5; 腓立比書 3:5–6; 使徒行傳 9:11"> 保羅說：「我原是猶太人，生在基利家的大數，長在這城裡；在迦瑪列門下，按著我們祖宗嚴緊的律法受教；熱心侍奉神，像你們眾人今日一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 22:19–20; 提摩太前書 1:13–15; 使徒行傳 26:9–11"> 我也曾逼迫奉這道的人，直到死地，無論男女都鎖拿下監。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:1–2; 路加福音 22:66; 使徒行傳 5:21"> 這是大祭司和眾長老都可以給我作見證的。我又領了他們達於弟兄的書信，往大馬士革去，要把在那裡奉這道的人鎖拿，帶到耶路撒冷受刑。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 9:3–8; 使徒行傳 26:12–18; 啟示錄 1:16"> 我將到大馬士革，正走的時候，約在晌午，忽然從天上發大光，四面照著我。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 2:9; 馬太福音 25:45; 創世記 22:11"> 我就仆倒在地，聽見有聲音對我說：<span className="woj">『掃羅，掃羅，你為什麼逼迫我？』</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 26:9; 撒母耳記上 8:7; 出埃及記 16:7–8"> 我回答說：『主啊，你是誰？』他說：<span className="woj">『我就是你所逼迫的拿撒勒人耶穌。』</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 9:7; 但以理書 10:7; 使徒行傳 26:13"> 與我同行的人看見了那光，卻沒有聽明那位對我說話的聲音。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 16:30; 使徒行傳 22:12–16; 使徒行傳 2:37"> 我說：『主啊，我當做什麼？』主說：<span className="woj">『起來！進大馬士革去，在那裡要將所派你做的一切事告訴你。』</span></span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 9:8–9; 使徒行傳 13:11; 以賽亞書 42:16"> 我因那光的榮耀不能看見，同行的人就拉著我手進了大馬士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:22; 使徒行傳 6:3; 約翰三書 1:12"> 那裡有一個人名叫亞拿尼亞，按著律法是虔誠人，為一切住在那裡的猶太人所稱讚。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 9:17–18; 腓利門書 1:16"> 他來見我，站在旁邊對我說：『兄弟掃羅，你可以看見！』我當時往上一看，就看見了他。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 1:12; 哥林多前書 15:8; 哥林多前書 9:1"> 他又說：『我們祖宗的神揀選了你，叫你明白他的旨意，又得見那義者，聽他口中所出的聲音。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 23:11; 使徒行傳 4:20; 約翰福音 15:27"> 因為你要將所看見的、所聽見的，對著萬人為他作見證。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:38; 使徒行傳 2:21; 提多書 3:5"> 現在你為什麼耽延呢？起來，求告他的名受洗，洗去你的罪！』</span>
</div>
</div>

## 述說奉主名往外邦

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 12:1–4; 使徒行傳 10:9–10; 使徒行傳 9:26–28"> 「後來我回到耶路撒冷，在殿裡禱告的時候魂遊象外，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 9:29; 路加福音 21:21; 以西結書 3:6–7"> 看見主向我說：<span className="woj">『你趕緊地離開耶路撒冷，不可遲延。因你為我作的見證，這裡的人必不領受。』</span></span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 22:4; 馬太福音 10:17; 使徒行傳 8:3"> 我就說：『主啊，他們知道我從前把信你的人收在監裡，又在各會堂裡鞭打他們。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 7:58; 使徒行傳 8:1; 羅馬書 1:32"> 並且你的見證人司提反被害流血的時候，我也站在旁邊歡喜，又看守害死他之人的衣裳。』</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 以弗所書 3:6–8"> 主向我說：<span className="woj">『你去吧！我要差你遠遠地往外邦人那裡去。』」</span></span>
</div>
</div>

## 眾人就喧嚷要除滅他

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 25:24; 使徒行傳 21:36; 約翰福音 19:15"> 眾人聽他說到這句話，就高聲說：「這樣的人，從世上除掉他吧！他是不當活著的！」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 16:13; 使徒行傳 26:11; 傳道書 10:3"> 眾人喧嚷，摔掉衣裳，把塵土向空中揚起來。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 21:31–32; 使徒行傳 21:34; 約翰福音 19:1"> 千夫長就吩咐將保羅帶進營樓去，叫人用鞭子拷問他，要知道他們向他這樣喧嚷是為什麼緣故。</span>
</div>
</div>

## 因羅馬民籍免受鞭打

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:37; 使徒行傳 25:16; 使徒行傳 27:43"> 剛用皮條捆上，保羅對旁邊站著的百夫長說：「人是羅馬人，又沒有定罪，你們就鞭打他，有這個例嗎？」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 23:27; 使徒行傳 22:29"> 百夫長聽見這話，就去見千夫長，告訴他說：「你要做什麼？這人是羅馬人！」</span>
<span className="v" id="v27" data-v="27"> 千夫長就來問保羅說：「你告訴我：你是羅馬人嗎？」保羅說：「是。」</span>
<span className="v" id="v28" data-v="28"> 千夫長說：「我用許多銀子才入了羅馬的民籍。」保羅說：「我生來就是。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 21:33; 使徒行傳 22:24–26; 使徒行傳 16:38–39"> 於是那些要拷問保羅的人就離開他去了。千夫長既知道他是羅馬人，又因為捆綁了他，也害怕了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 23:28; 使徒行傳 21:33; 使徒行傳 21:11"> 第二天，千夫長為要知道猶太人控告保羅的實情，便解開他，吩咐祭司長和全公會的人都聚集，將保羅帶下來，叫他站在他們面前。</span>
</div>
</div>

</div>

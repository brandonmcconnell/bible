## 保羅治好生來瘸腿的

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:4; 使徒行傳 13:51; 使徒行傳 13:46"> 二人在以哥念同進猶太人的會堂，在那裡講的叫猶太人和希臘人信的很多。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 13:50; 使徒行傳 21:27–30; 使徒行傳 14:19"> 但那不順從的猶太人聳動外邦人，叫他們心裡惱恨弟兄。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 2:4; 以弗所書 6:18–20; 使徒行傳 20:32"> 二人在那裡住了多日，倚靠主放膽講道，主藉他們的手施行神蹟奇事，證明他的恩道。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 28:24; 使徒行傳 14:14; 路加福音 11:21–23"> 城裡的眾人就分了黨，有附從猶太人的，有附從使徒的。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 14:19; 提摩太後書 3:11; 使徒行傳 17:5"> 那時，外邦人和猶太人並他們的官長一齊擁上來，要凌辱使徒，用石頭打他們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 14:20–21; 馬太福音 10:23; 提摩太後書 3:11"> 使徒知道了，就逃往呂高尼的路司得、特庇兩個城和周圍地方去，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 14:21; 使徒行傳 16:10; 帖撒羅尼迦前書 2:2"> 在那裡傳福音。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 3:2; 約翰福音 9:1–2; 約翰福音 5:3–5"> 路司得城裡坐著一個兩腳無力的人，生來是瘸腿的，從來沒有走過。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 3:4; 馬太福音 15:28; 馬太福音 9:28–29"> 他聽保羅講道，保羅定睛看他，見他有信心，可得痊癒，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 35:6; 約翰福音 5:8–9; 約翰福音 14:12"> 就大聲說：「你起來，兩腳站直！」那人就跳起來，而且行走。</span>
</div>
</div>

## 眾人要向二使徒獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:6; 使徒行傳 8:10; 使徒行傳 12:22"> 眾人看見保羅所做的事，就用呂高尼的話大聲說：「有神藉著人形降臨在我們中間了！」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:35"> 於是稱巴拿巴為宙斯，稱保羅為希耳米，因為他說話領首。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 2:46; 使徒行傳 10:25"> 有城外宙斯廟的祭司牽著牛、拿著花圈，來到門前，要同眾人向使徒獻祭。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:65; 哥林多前書 9:5–6; 列王紀下 5:7"> 巴拿巴、保羅二使徒聽見，就撕開衣裳，跳進眾人中間，喊著說：</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 10:26; 哥林多前書 8:4; 雅各書 5:17"> 「諸君，為什麼做這事呢？我們也是人，性情和你們一樣。我們傳福音給你們，是叫你們離棄這些虛妄，歸向那創造天、地、海和其中萬物的永生神。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:30; 詩篇 81:12; 羅馬書 1:28"> 他在從前的世代，任憑萬國各行其道，</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:19–20; 約珥書 2:23; 約伯記 5:10"> 然而為自己未嘗不顯出證據來，就如常施恩惠，從天降雨賞賜豐年，叫你們飲食飽足、滿心喜樂。」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 44:16–17; 創世記 19:9; 創世記 11:6"> 二人說了這些話，僅僅地攔住眾人不獻祭於他們。</span>
</div>
</div>

## 猶太人唆眾用石頭打保羅

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 11:25; 提摩太後書 3:11; 使徒行傳 13:50–51"> 但有些猶太人從安提阿和以哥念來，挑唆眾人，就用石頭打保羅，以為他是死了，便拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 1:9–10; 哥林多後書 6:9; 使徒行傳 14:6"> 門徒正圍著他，他就起來，走進城去。第二天，同巴拿巴往特庇去。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 14:19; 使徒行傳 14:1; 使徒行傳 13:51"> 對那城裡的人傳了福音，使好些人做門徒，就回路司得、以哥念、安提阿去，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 5:10; 提摩太後書 3:12; 約翰福音 16:33"> 堅固門徒的心，勸他們恆守所信的道，又說：「我們進入神的國，必須經歷許多艱難。」</span>
<span className="v" id="v23" data-v="23" data-xref="提多書 1:5; 使徒行傳 11:30; 雅各書 5:14"> 二人在各教會中選立了長老，又禁食禱告，就把他們交託所信的主。</span>
</div>
</div>

## 述說給外邦人開信道的門

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 13:13–14; 使徒行傳 15:38"> 二人經過彼西底，來到旁非利亞。</span>
<span className="v" id="v25" data-v="25"> 在別加講了道，就下亞大利去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:40; 使徒行傳 11:19; 哥林多後書 1:12"> 從那裡坐船，往安提阿去。當初他們被眾人所託、蒙神之恩要辦現在所做之工，就是在這地方。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 16:9; 使徒行傳 15:12; 歌羅西書 4:3"> 到了那裡，聚集了會眾，就述說神藉他們所行的一切事，並神怎樣為外邦人開了信道的門。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 11:26; 使徒行傳 15:35"> 二人就在那裡同門徒住了多日。</span>
</div>
</div>

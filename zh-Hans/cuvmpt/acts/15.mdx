## 爭論外邦門徒該守摩西的律法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 5:6; 使徒行傳 15:5; 利未記 12:3"> 有幾個人從猶太下來，教訓弟兄們說：「你們若不按摩西的規條受割禮，不能得救。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 15:22–23; 使徒行傳 15:6–7; 加拉太書 2:1–2"> 保羅、巴拿巴與他們大大地紛爭辯論，眾門徒就定規，叫保羅、巴拿巴和本會中幾個人為所辯論的，上耶路撒冷去見使徒和長老。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 14:27; 使徒行傳 21:5; 哥林多前書 16:11"> 於是教會送他們起行。他們經過腓尼基、撒馬利亞，隨處傳說外邦人歸主的事，叫眾弟兄都甚歡喜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:27; 使徒行傳 15:12; 使徒行傳 15:3"> 到了耶路撒冷，教會和使徒並長老都接待他們，他們就述說神同他們所行的一切事。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:1–3; 腓立比書 3:5–8; 使徒行傳 15:1"> 唯有幾個信徒是法利賽教門的人起來，說：「必須給外邦人行割禮，吩咐他們遵守摩西的律法。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯來書 13:7; 希伯來書 13:17"> 使徒和長老聚會商議這事。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 10:17–18; 加拉太書 2:7–9; 歷代志上 28:4–5"> 辯論已經多了，彼得就起來說：「諸位弟兄，你們知道神早已在你們中間揀選了我，叫外邦人從我口中得聽福音之道，而且相信。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:24; 使徒行傳 10:47; 使徒行傳 14:3"> 知道人心的神也為他們作了見證，賜聖靈給他們，正如給我們一樣；</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 3:6; 加拉太書 5:6; 使徒行傳 10:28"> 又藉著信潔淨了他們的心，並不分他們我們。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 5:1; 馬太福音 23:4; 加拉太書 4:9"> 現在為什麼試探神，要把我們祖宗和我們所不能負的軛放在門徒的頸項上呢？</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:24; 提多書 3:4–7; 提多書 2:11"> 我們得救乃是因主耶穌的恩，和他們一樣，這是我們所信的。」</span>
</div>
</div>

## 巴拿巴和保羅述說在外邦人中所行之事

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 14:27; 使徒行傳 15:4; 使徒行傳 21:19"> 眾人都默默無聲，聽巴拿巴和保羅述說神藉他們在外邦人中所行的神蹟奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 12:17; 加拉太書 2:12; 雅各書 1:1"> 他們住了聲，雅各就說：「諸位弟兄，請聽我的話！</span>
<span className="v" id="v14" data-v="14" data-xref="彼得後書 1:1; 使徒行傳 15:7–9; 路加福音 2:31–32"> 方才西門述說神當初怎樣眷顧外邦人，從他們中間選取百姓歸於自己的名下。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 15:8–12; 使徒行傳 13:47"> 眾先知的話也與這意思相合，</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 9:11–12; 詩篇 89:35–49; 路加福音 1:31–33"> 正如經上所寫的：<br /><span className="pl pl-1">『此後我要回來，</span><br /><span className="pl pl-1">重新修造大衛倒塌的帳幕，</span><br /><span className="pl pl-1">把那破壞的重新修造建立起來，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亞書 2:11; 撒迦利亞書 8:20–23; 以賽亞書 65:1"> <span className="pl pl-1">叫餘剩的人，</span><br /><span className="pl pl-1">就是凡稱為我名下的外邦人，</span><br /><span className="pl pl-1">都尋求主。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 1:4; 以弗所書 3:9; 以賽亞書 46:9–10"> <span className="pl pl-1">這話是從創世以來顯明這事的主說的。』</span></span>
</div>
</div>

## 雅各定斷此事

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 15:28; 加拉太書 1:7–10; 使徒行傳 15:24"> 「所以據我的意見，不可難為那歸服神的外邦人，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 15:29; 啟示錄 2:20; 利未記 3:17"> 只要寫信吩咐他們禁戒偶像的汙穢和姦淫，並勒死的牲畜和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:15; 使徒行傳 13:27; 哥林多後書 3:14–15"> 因為從古以來，摩西的書在各城有人傳講，每逢安息日在會堂裡誦讀。」</span>
</div>
</div>

## 差人送信到安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 15:27; 使徒行傳 15:40; 帖撒羅尼迦前書 1:1"> 那時，使徒和長老並全教會定意從他們中間揀選人，差他們和保羅、巴拿巴同往安提阿去。所揀選的就是稱呼巴撒巴的猶大和西拉，這兩個人在弟兄中是做首領的。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 23:26; 雅各書 1:1; 加拉太書 1:21"> 於是寫信交付他們，內中說：「使徒和做長老的弟兄們問安提阿、敘利亞、基利家外邦眾弟兄的安！</span>
<span className="v" id="v24" data-v="24" data-xref="加拉太書 5:12; 加拉太書 5:10; 使徒行傳 15:1"> 我們聽說有幾個人從我們這裡出去，用言語攪擾你們，惑亂你們的心。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：你們必須受割禮，守摩西的律法。">a</a></sup>其實我們並沒有吩咐他們。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得後書 3:15; 使徒行傳 1:14; 使徒行傳 15:2"> 所以，我們同心定意揀選幾個人，差他們同我們所親愛的巴拿巴和保羅往你們那裡去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 14:19; 使徒行傳 9:23–25; 腓立比書 2:29–30"> 這二人是為我主耶穌基督的名不顧性命的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 15:22; 使徒行傳 15:32; 約翰三書 1:13"> 我們就差了猶大和西拉，他們也要親口訴說這些事。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 16:13; 啟示錄 2:24; 馬太福音 11:30"> 因為聖靈和我們定意不將別的重擔放在你們身上，唯有幾件事是不可少的，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 15:20; 使徒行傳 21:25; 啟示錄 2:14"> 就是禁戒祭偶像的物和血，並勒死的牲畜和姦淫。這幾件你們若能自己禁戒不犯就好了。願你們平安！」</span>
</div>
</div>

## 眾人接信便得安慰

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 16:4; 使徒行傳 6:2; 使徒行傳 23:33"> 他們既奉了差遣，就下安提阿去，聚集眾人，交付書信。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 2:4–5; 腓立比書 3:3; 加拉太書 5:1"> 眾人念了，因為信上安慰的話就歡喜了。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 11:23; 使徒行傳 14:22; 使徒行傳 13:1"> 猶大和西拉也是先知，就用許多話勸勉弟兄，堅固他們。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 16:11; 使徒行傳 16:36; 希伯來書 11:31"> 住了些日子，弟兄們打發他們平平安安地回到差遣他們的人那裡去。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷在此有：34 唯有西拉定意仍住在那裡。">b</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太後書 4:2; 歌羅西書 1:28; 使徒行傳 13:1"> 但保羅和巴拿巴仍住在安提阿，和許多別人一同教訓人，傳主的道。</span>
</div>
</div>

## 保羅巴拿巴為馬可分開

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 14:6; 使徒行傳 13:4; 使徒行傳 13:51"> 過了些日子，保羅對巴拿巴說：「我們可以回到從前宣傳主道的各城，看望弟兄們景況如何。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 12:12; 腓利門書 1:24; 使徒行傳 13:5"> 巴拿巴有意要帶稱呼馬可的約翰同去，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 13:13; 箴言 25:19; 路加福音 14:27–34"> 但保羅因為馬可從前在旁非利亞離開他們，不和他們同去做工，就以為不可帶他去。</span>
<span className="v" id="v39" data-v="39" data-xref="歌羅西書 4:10; 傳道書 7:20; 使徒行傳 4:36"> 於是二人起了爭論，甚至彼此分開。巴拿巴帶著馬可，坐船往塞浦路斯去；</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 15:22; 使徒行傳 14:26; 使徒行傳 11:23"> 保羅揀選了西拉，也出去，蒙弟兄們把他交於主的恩中。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 15:23; 加拉太書 1:21; 使徒行傳 15:32"> 他就走遍敘利亞、基利家，堅固眾教會。</span>
</div>

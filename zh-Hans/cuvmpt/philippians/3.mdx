## 保羅只在基督裡誇口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 5:11; 腓立比書 4:4; 雅各書 1:2"> 弟兄們，我還有話說，你們要靠主喜樂！我把這話再寫給你們，於我並不為難，於你們卻是妥當。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 11:13; 提多書 1:16; 啟示錄 22:15"> 應當防備犬類，防備作惡的，防備妄自行割的。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:11; 申命記 30:6; 羅馬書 7:6"> 因為真受割禮的，乃是我們這以神的靈敬拜，在基督耶穌裡誇口，不靠著肉體的。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 11:18–22"> 其實我也可以靠肉體，若是別人想他可以靠肉體，我更可以靠著了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 11:22; 羅馬書 11:1; 使徒行傳 23:6"> 我第八天受割禮，我是以色列族便雅憫支派的人，是希伯來人所生的希伯來人。就律法說，我是法利賽人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 1:13–14; 使徒行傳 8:3; 使徒行傳 26:9–10"> 就熱心說，我是逼迫教會的；就律法上的義說，我是無可指摘的。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 馬太福音 16:26; 馬太福音 13:44–46"> 只是我先前以為於我有益的，我現在因基督都當做有損的。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 9:23–24; 羅馬書 8:18; 腓立比書 3:7"> 不但如此，我也將萬事當做有損的，因我以認識我主基督耶穌為至寶。 為基督丟棄萬事<br />我為他已經丟棄萬事，看做糞土，為要得著基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 5:21; 哥林多前書 1:30; 加拉太書 2:16"> 並且得以在他裡面，不是有自己因律法而得的義，乃是有信基督的義，就是因信神而來的義；</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 2:20; 羅馬書 8:17; 彼得前書 4:1–2"> 使我認識基督，曉得他復活的大能，並且曉得和他一同受苦，效法他的死，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 啟示錄 20:5; 使徒行傳 23:6"> 或者我也得以從死裡復活。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 6:11–12; 彼得後書 1:5–8; 詩篇 138:8"> 這不是說我已經得著了，已經完全了，我乃是竭力追求，或者可以得著基督耶穌所以得著我的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「所以得著我的」或作「所要我得的」。">a</a></sup>。</span>
</div>
</div>

## 忘記背後努力面前的

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯來書 12:1–2; 腓立比書 3:12"> 弟兄們，我不是以為自己已經得著了，我只有一件事，就是忘記背後，努力面前的，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 9:24; 彼得前書 5:10; 啟示錄 3:21"> 向著標竿直跑，要得神在基督耶穌裡從上面召我來得的獎賞。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 7:17; 雅各書 1:4–5; 箴言 2:3–6"> 所以我們中間凡是完全人，總要存這樣的心；若在什麼事上存別樣的心，神也必以此指示你們。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 2:6; 啟示錄 3:3; 啟示錄 2:4–5"> 然而我們到了什麼地步，就當照著什麼地步行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="腓立比書 4:9; 哥林多前書 4:16; 彼得前書 5:3"> 弟兄們，你們要一同效法我，也當留意看那些照我們榜樣行的人。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 4:17; 以賽亞書 8:11; 加拉太書 6:12"> 因為有許多人行事是基督十字架的仇敵，我屢次告訴你們，現在又流淚地告訴你們。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 16:18; 羅馬書 8:5–7; 彼得後書 2:3"> 他們的結局就是沉淪，他們的神就是自己的肚腹！他們以自己的羞辱為榮耀，專以地上的事為念。</span>
</div>
</div>

## 門徒是天上的國民

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以弗所書 2:19; 歌羅西書 3:1–3; 哥林多後書 4:18–1"> 我們卻是天上的國民，並且等候救主，就是主耶穌基督，從天上降臨。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 3:2; 歌羅西書 3:4; 哥林多前書 15:42–56"> 他要按著那能叫萬有歸服自己的大能，將我們這卑賤的身體改變形狀，和他自己榮耀的身體相似。</span>
</div>
</div>

## 當以基督的心為心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:12; 約翰一書 4:12; 約翰一書 4:7–8"> 所以，在基督裡若有什麼勸勉，愛心有什麼安慰，聖靈有什麼交通，心中有什麼慈悲憐憫，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 12:16; 彼得前書 3:8–9; 哥林多前書 1:10"> 你們就要意念相同，愛心相同，有一樣的心思，有一樣的意念，使我的喜樂可以滿足。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 12:10; 加拉太書 5:26; 以弗所書 5:21"> 凡事不可結黨，不可貪圖虛浮的榮耀，只要存心謙卑，各人看別人比自己強。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:24; 羅馬書 15:1; 雅各書 2:8"> 各人不要單顧自己的事，也要顧別人的事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="約翰一書 2:6; 馬太福音 11:29; 彼得前書 2:21"> 你們當以基督耶穌的心為心。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 5:18; 哥林多後書 4:4; 希伯來書 1:3"> <span className="pl pl-1">他本有神的形像，</span><br /><span className="pl pl-1">不以自己與神同等為強奪的，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 8:9; 馬太福音 20:28; 約翰福音 1:14"> <span className="pl pl-1">反倒虛己，</span><br /><span className="pl pl-1">取了奴僕的形像，</span><br /><span className="pl pl-1">成為人的樣式；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:18; 希伯來書 12:2; 羅馬書 5:19"> <span className="pl pl-1">既有人的樣子，就自己卑微，</span><br /><span className="pl pl-1">存心順服以至於死，</span><br /><span className="pl pl-1">且死在十字架上。</span></span>
</div>
</div>

## 無不口稱耶穌為主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:16; 馬太福音 28:18; 彼得前書 3:22"> <span className="pl pl-1">所以神將他升為至高，</span><br /><span className="pl pl-1">又賜給他那超乎萬名之上的名，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 45:23–25; 馬太福音 28:18; 啟示錄 5:13–14"> <span className="pl pl-1">叫一切在天上的、地上的和地底下的，</span><br /><span className="pl pl-1">因耶穌的名無不屈膝，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約翰一書 4:15; 羅馬書 14:11; 約翰福音 13:13"> <span className="pl pl-1">無不口稱耶穌基督為主，</span><br /><span className="pl pl-1">使榮耀歸於父神。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得後書 1:5–10; 路加福音 13:23–24; 哥林多前書 15:58"> 這樣看來，我親愛的弟兄，你們既是常順服的，不但我在你們那裡，就是我如今不在你們那裡，更是順服的，就當恐懼戰兢，做成你們得救的工夫。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:21; 哥林多後書 3:5; 提摩太後書 1:9"> 因為你們立志行事，都是神在你們心裡運行，為要成就他的美意。</span>
</div>
</div>

## 門徒如明光照耀

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前書 4:9; 哥林多前書 10:10; 腓立比書 2:3"> 凡所行的，都不要發怨言、起爭論，</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:14–16; 彼得前書 2:12; 馬太福音 5:45"> 使你們無可指摘，誠實無偽，在這彎曲悖謬的世代做神無瑕疵的兒女。你們顯在這世代中，好像明光照耀，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 9:26; 加拉太書 2:2; 約翰一書 1:1"> 將生命的道表明出來，叫我在基督的日子好誇我沒有空跑，也沒有徒勞。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 4:6; 羅馬書 15:16; 希伯來書 13:15–16"> 我以你們的信心為供獻的祭物，我若被澆奠在其上，也是喜樂，並且與你們眾人一同喜樂。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 1:2–4; 腓立比書 4:4; 腓立比書 3:1"> 你們也要照樣喜樂，並且與我一同喜樂。</span>
</div>
</div>

## 保羅稱讚提摩太

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 4:17; 帖撒羅尼迦前書 3:6–8; 帖撒羅尼迦前書 3:2"> 我靠主耶穌指望快打發提摩太去見你們，叫我知道你們的事，心裡就得著安慰。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比書 2:2; 哥林多前書 16:10; 腓立比書 2:22"> 因為我沒有別人與我同心，實在掛念你們的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 10:24; 馬太福音 16:24; 腓立比書 2:4"> 別人都求自己的事，並不求耶穌基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 4:17; 哥林多後書 2:9; 提摩太後書 1:2"> 但你們知道提摩太的明證，他興旺福音與我同勞，待我像兒子待父親一樣。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 22:3; 腓立比書 2:19"> 所以，我一看出我的事要怎樣了結，就盼望立刻打發他去；</span>
<span className="v" id="v24" data-v="24" data-xref="約翰三書 1:14; 腓利門書 1:22; 腓立比書 1:25–26"> 但我靠著主，自信我也必快去。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比書 4:18; 腓利門書 1:1–2; 腓立比書 4:3"> 然而，我想必須打發以巴弗提到你們那裡去，他是我的兄弟，與我一同做工一同當兵，是你們所差遣的，也是供給我需用的。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 12:15; 箴言 12:25; 以弗所書 3:13"> 他很想念你們眾人，並且極其難過，因為你們聽見他病了。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:19; 腓立比書 2:30; 詩篇 103:3–4"> 他實在是病了，幾乎要死，然而神憐恤他，不但憐恤他，也憐恤我，免得我憂上加憂。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 16:22; 提摩太後書 1:4; 腓立比書 2:26–27"> 所以我越發急速打發他去，叫你們再見他就可以喜樂，我也可以少些憂愁。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒羅尼迦前書 5:12; 哥林多前書 16:18; 提摩太前書 5:17"> 故此，你們要在主裡歡歡樂樂地接待他，而且要尊重這樣的人，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 16:17; 使徒行傳 20:24; 腓立比書 4:10"> 因他為做基督的工夫幾乎至死，不顧性命，要補足你們供給我的不及之處。</span>
</div>
</div>

## 亞希雅預言耶羅波安家遘災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 20:5; 列王紀上 13:33–34; 撒母耳記上 31:2"> 那時，耶羅波安的兒子亞比雅病了。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 28:8; 列王紀上 11:29–38; 撒母耳記下 14:2"> 耶羅波安對他的妻說：「你可以起來改裝，使人不知道你是耶羅波安的妻，往示羅去，在那裡有先知亞希雅，他曾告訴我說：『你必做這民的王。』</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 9:7–8; 列王紀上 13:7; 列王紀下 4:42"> 現在你要帶十個餅，與幾個薄餅，和一瓶蜜去見他，他必告訴你兒子將要怎樣。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:29; 撒母耳記上 3:2; 撒母耳記上 4:15"> 耶羅波安的妻就這樣行，起身往示羅去，到了亞希雅的家。亞希雅因年紀老邁，眼目發直，不能看見。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 6:8–12; 箴言 21:30; 列王紀下 4:27"> 耶和華先曉諭亞希雅說：「耶羅波安的妻要來問你，因她兒子病了，你當如此如此告訴她。她進來的時候必裝作別的婦人。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理書 5:17–28; 使徒行傳 5:9–10; 路加福音 20:20–23"> 她剛進門，亞希雅聽見她腳步的響聲，就說：「耶羅波安的妻，進來吧！你為何裝作別的婦人呢？我奉差遣將凶事告訴你。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 16:2; 撒母耳記下 12:7–8; 撒母耳記上 15:16"> 你回去告訴耶羅波安說，耶和華以色列的神如此說：『我從民中將你高舉，立你做我民以色列的君，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 15:5; 列王紀上 11:33–38; 歷代志下 28:1"> 將國從大衛家奪回賜給你。你卻不效法我僕人大衛，遵守我的誡命，一心順從我，行我眼中看為正的事。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 23:35; 尼希米記 9:26; 詩篇 50:17"> 你竟行惡，比那在你以先的更甚，為自己立了別神，鑄了偶像，惹我發怒，將我丟在背後。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:36; 列王紀上 21:21; 列王紀下 14:26"> 因此，我必使災禍臨到耶羅波安的家，將屬耶羅波安的男丁，無論困住的、自由的，都從以色列中剪除，必除盡耶羅波安的家，如人除盡糞土一般。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 16:4; 耶利米書 15:3; 列王紀上 21:23–24"> 凡屬耶羅波安的人，死在城中的必被狗吃，死在田野的必被空中的鳥吃。這是耶和華說的。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 14:3; 列王紀上 14:16–17; 列王紀下 1:6"> 所以你起身回家去吧，你的腳一進城，你兒子就必死了。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 19:3; 歷代志下 12:12; 約伯記 19:28"> 以色列眾人必為他哀哭，將他葬埋。凡屬耶羅波安的人，唯有他得入墳墓，因為在耶羅波安的家中，只有他向耶和華以色列的神顯出善行。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 15:27–29; 以西結書 7:2–7; 以西結書 12:22–28"> 耶和華必另立一王治理以色列，到了日期，他必剪除耶羅波安的家。那日期已經到了！</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 23:15–16; 詩篇 52:5; 列王紀下 15:29"> 耶和華必擊打以色列人，使他們搖動，像水中的蘆葦一般。又將他們從耶和華賜給他們列祖的美地上拔出來，分散在大河那邊，因為他們做木偶，惹耶和華發怒。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:34; 列王紀上 16:2; 列王紀上 13:34"> 因耶羅波安所犯的罪，又使以色列人陷在罪裡，耶和華必將以色列人交給仇敵。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 15:33; 列王紀上 16:15; 列王紀上 16:23"> 耶羅波安的妻起身回去，到了得撒，剛到門檻，兒子就死了。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:13"> 以色列眾人將他葬埋，為他哀哭，正如耶和華藉他僕人先知亞希雅所說的話。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 13:2–20; 歷代志上 27:24; 列王紀上 16:20"> 耶羅波安其餘的事，他怎樣爭戰，怎樣做王，都寫在《以色列諸王記》上。</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 14:12; 詩篇 3:5; 列王紀上 11:43"> 耶羅波安做王二十二年，就與他列祖同睡。他兒子拿答接續他做王。</span>
</div>
</div>

## 羅波安做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 12:13; 列王紀上 11:36; 列王紀上 14:31"> 所羅門的兒子羅波安做猶大王。他登基的時候年四十一歲，在耶路撒冷，就是耶和華從以色列眾支派中所選擇立他名的城，做王十七年。羅波安的母親名叫拿瑪，是亞捫人。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 12:1; 哥林多前書 10:22; 詩篇 78:58"> 猶大人行耶和華眼中看為惡的事，犯罪觸動他的憤恨，比他們列祖更甚。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:2; 以賽亞書 57:5; 列王紀下 17:9–10"> 因為他們在各高岡上、各青翠樹下築壇，立柱像和木偶。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 23:17; 哥林多前書 6:9; 列王紀上 15:12"> 國中也有孌童，猶大人效法耶和華在以色列人面前所趕出的外邦人，行一切可憎惡的事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:40; 歷代志下 12:2–4; 歷代志下 12:9"> 羅波安王第五年，埃及王示撒上來攻取耶路撒冷，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 15:18; 歷代志下 9:15–16; 列王紀上 7:51"> 奪了耶和華殿和王宮裡的寶物，盡都帶走，又奪去所羅門製造的金盾牌。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 8:11; 撒母耳記上 22:17; 列王紀上 18:46"> 羅波安王製造銅盾牌代替那金盾牌，交給守王宮門的護衛長看守。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 12:11"> 王每逢進耶和華的殿，護衛兵就拿這盾牌，隨後仍將盾牌送回，放在護衛房。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 22:45; 列王紀上 15:23; 列王紀上 14:19"> 羅波安其餘的事，凡他所行的，都寫在《猶大列王記》上。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 12:24; 列王紀上 12:21; 列王紀上 15:6–7"> 羅波安與耶羅波安時常爭戰。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 12:16; 馬太福音 1:7; 列王紀上 15:3"> 羅波安與他列祖同睡，葬在大衛城他列祖的墳地裡。他母親名叫拿瑪，是亞捫人。他兒子亞比央<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又名亞比雅。">a</a></sup>接續他做王。</span>
</div>
</div>

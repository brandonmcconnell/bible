## 記所羅門諸臣之名

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="傳道書 1:12; 歷代志下 9:30; 列王紀上 12:19–20"> 所羅門做以色列眾人的王。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 18:21; 哥林多前書 12:28; 撒母耳記下 8:15–18"> 他的臣子記在下面：撒督的兒子亞撒利雅做祭司，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:16; 以賽亞書 62:6; 歷代志上 18:15"> 示沙的兩個兒子以利何烈、亞希亞做書記，亞希律的兒子約沙法做史官，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:35; 列王紀上 2:26–27"> 耶何耶大的兒子比拿雅做元帥，撒督和亞比亞他做祭司長，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 27:33; 撒母耳記下 15:37; 撒母耳記下 16:16"> 拿單的兒子亞撒利雅做眾吏長，王的朋友拿單的兒子撒布得做領袖，</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:15; 撒母耳記下 20:24; 列王紀上 12:18"> 亞希煞做家宰，亞比大的兒子亞多尼蘭掌管服苦的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 27:1–15"> 所羅門在以色列全地立了十二個官吏，使他們供給王和王家的食物，每年各人供給一月。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 24:33; 士師記 19:1; 士師記 17:1"> 他們的名字記在下面：在以法蓮山地有便戶珥；</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 21:16; 撒母耳記上 6:20; 撒母耳記上 6:12"> 在瑪迦斯、沙賓、伯示麥、以倫伯哈南有便底甲；</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 15:35; 約書亞記 12:17; 約書亞記 17:2"> 在亞魯泊有便希悉，他管理梭哥和希弗全地；</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 11:2; 約書亞記 12:23; 約書亞記 17:11"> 在多珥山岡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：全境。">a</a></sup>有便亞比拿達，他娶了所羅門的女兒她法為妻；</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 17:11; 士師記 5:19; 約書亞記 3:16"> 在他納和米吉多，並靠近撒拉他拿，耶斯列下邊的伯善全地，從伯善到亞伯米何拉直到約念之外，有亞希律的兒子巴拿；</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 3:4; 民數記 32:41; 列王紀上 22:3"> 在基列的拉末有便基別，他管理在基列的瑪拿西子孫睚珥的城邑，巴珊的亞珥歌伯地的大城六十座，都有城牆和銅閂；</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 13:26; 撒母耳記下 17:24; 撒母耳記下 2:8"> 在瑪哈念有易多的兒子亞希拿達；</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 19:32–39; 撒母耳記下 15:27; 撒母耳記上 18:18"> 在拿弗他利有亞希瑪斯，他也娶了所羅門的一個女兒巴實抹為妻；</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 19:24–31; 撒母耳記下 15:32"> 在亞設和亞祿有戶篩的兒子巴拿；</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 19:17–23"> 在以薩迦有帕路亞的兒子約沙法；</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:8; 約書亞記 18:20–28; 撒迦利亞書 12:13"> 在便雅憫有以拉的兒子示每；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:26–17; 約書亞記 13:9–12; 民數記 21:21–35"> 在基列地，就是從前屬亞摩利王西宏和巴珊王噩之地，有烏利的兒子基別一人管理。</span>
</div>
</div>

## 所羅門之富強

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 22:17; 列王紀上 3:8; 創世記 32:12"> 猶大人和以色列人如同海邊的沙那樣多，都吃喝快樂。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:18; 約書亞記 1:4; 詩篇 68:29"> 所羅門統管諸國，從大河到非利士地，直到埃及的邊界。所羅門在世的日子，這些國都進貢服侍他。</span>
<span className="v" id="v22" data-v="22"> 所羅門每日所用的食物，細麵三十歌珥，粗麵六十歌珥，</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 5:17–18"> 肥牛十隻，草場的牛二十隻，羊一百隻，還有鹿、羚羊、麃子並肥禽。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 22:9; 詩篇 72:11; 詩篇 72:3"> 所羅門管理大河西邊的諸王，以及從提弗薩直到加沙的全地，四境盡都平安。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 4:4; 撒迦利亞書 3:10; 士師記 20:1"> 所羅門在世的日子，從但到別是巴的猶大人和以色列人，都在自己的葡萄樹下和無花果樹下安然居住。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 1:14; 歷代志下 9:25; 撒母耳記下 8:4"> 所羅門有套車的馬四萬，還有馬兵一萬二千。</span>
<span className="v" id="v27" data-v="27"> 那十二個官吏各按各月供給所羅門王，並一切與他同席之人的食物，一無所缺。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖記 8:10; 以斯帖記 8:14; 彌迦書 1:13"> 眾人各按各分，將養馬與快馬的大麥和乾草送到官吏那裡。</span>
</div>
</div>

## 所羅門之智能

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 3:12; 雅各書 3:17; 列王紀上 4:20"> 神賜給所羅門極大的智慧、聰明和廣大的心，如同海沙不可測量。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 5:11–12; 創世記 25:6; 但以理書 1:20"> 所羅門的智慧超過東方人和埃及人的一切智慧。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 2:6; 歷代志上 15:19; 列王紀上 3:12"> 他的智慧勝過萬人，勝過以斯拉人以探並瑪曷的兒子希幔、甲各、達大的智慧。他的名聲傳揚在四圍的列國。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 馬太福音 13:35; 箴言 1:1–31"> 他作箴言三千句，詩歌一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 19:23; 詩篇 51:7; 詩篇 92:12"> 他講論草木，自黎巴嫩的香柏樹直到牆上長的牛膝草，又講論飛禽走獸、昆蟲水族。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 9:23; 列王紀上 10:1; 歷代志下 9:1"> 天下列王聽見所羅門的智慧，就都差人來聽他的智慧話。</span>
</div>
</div>

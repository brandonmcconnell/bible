## 始建聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 3:1–2; 使徒行傳 7:47; 歷代志上 29:19"> 以色列人出埃及地後四百八十年，所羅門做以色列王第四年西弗月，就是二月，開工建造耶和華的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 40:1–41; 以西結書 41:1–15; 啟示錄 21:16–17"> 所羅門王為耶和華所建的殿，長六十肘，寬二十肘，高三十肘。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 28:11; 歷代志下 3:3–4; 以西結書 41:15"> 殿前的廊子長二十肘，與殿的寬窄一樣，闊十肘。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 40:16; 以西結書 41:26; 以西結書 41:16"> 又為殿做了嚴緊的窗櫺。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:16; 列王紀上 6:19–21; 列王紀上 6:31"> 靠著殿牆，圍著外殿、內殿，造了三層旁屋，</span>
<span className="v" id="v6" data-v="6"> 下層寬五肘，中層寬六肘，上層寬七肘。殿外旁屋的梁木擱在殿牆坎上，免得插入殿牆。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:5–6; 彼得前書 2:5; 出埃及記 20:25"> 建殿是用山中鑿成的石頭，建殿的時候，錘子、斧子和別樣鐵器的響聲都沒有聽見。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 41:6–7"> 在殿右邊當中的旁屋有門，門內有旋螺的樓梯，可以上到第二層，從第二層可以上到第三層。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:14; 列王紀上 6:38"> 所羅門建殿，安置香柏木的棟梁，又用香柏木板遮蓋。</span>
<span className="v" id="v10" data-v="10"> 靠著殿所造的旁屋，每層高五肘，香柏木的棟梁擱在殿牆坎上。</span>
</div>
</div>

## 耶和華之約

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華的話臨到所羅門說：</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 22:10; 歌羅西書 1:23; 列王紀上 3:14"> 「論到你所建的這殿，你若遵行我的律例，謹守我的典章，遵從我的一切誡命，我必向你應驗我所應許你父親大衛的話。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 31:6; 出埃及記 25:8; 利未記 26:11"> 我必住在以色列人中間，並不丟棄我民以色列。」</span>
</div>
</div>

## 造內殿

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 6:9; 列王紀上 6:38; 使徒行傳 7:47–48"> 所羅門建造殿宇。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:7"> 殿裡面用香柏木板貼牆，從地到篷頂都用木板遮蔽，又用松木板鋪地。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 3:8; 列王紀上 8:6; 希伯來書 9:3"> 內殿，就是至聖所，長二十肘，從地到篷頂用香柏木板遮蔽<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：隔斷。">a</a></sup>。</span>
<span className="v" id="v17" data-v="17"> 內殿前的外殿，長四十肘。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:24"> 殿裡一點石頭都不顯露，一概用香柏木遮蔽，上面刻著野瓜和初開的花。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:6–10; 詩篇 28:2; 列王紀上 6:5"> 殿裡預備了內殿，好安放耶和華的約櫃。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 6:2–3; 列王紀上 6:22; 列王紀上 7:48"> 內殿長二十肘，寬二十肘，高二十肘，牆面都貼上精金。又用香柏木做壇，包上精金。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 3:7–9; 歷代志下 3:14–16; 列王紀上 6:5"> 所羅門用精金貼了殿內的牆，又用金鏈子掛在內殿前門扇，用金包裹。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 30:1; 出埃及記 30:3; 歷代志下 3:7–14"> 全殿都貼上金子，直到貼完。內殿前的壇，也都用金包裹。</span>
</div>
</div>

## 造二基路伯

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 37:7–9; 創世記 3:24; 彼得前書 1:12"> 他用橄欖木做兩個基路伯，各高十肘，安在內殿。</span>
<span className="v" id="v24" data-v="24"> 這一個基路伯有兩個翅膀，各長五肘，從這翅膀尖到那翅膀尖共有十肘。</span>
<span className="v" id="v25" data-v="25"> 那一個基路伯的兩個翅膀也是十肘，兩個基路伯的尺寸、形像都是一樣。</span>
<span className="v" id="v26" data-v="26"> 這基路伯高十肘，那基路伯也是如此。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 37:9; 出埃及記 25:20; 歷代志下 5:8"> 他將兩個基路伯安在內殿裡，基路伯的翅膀是張開的，這基路伯的一個翅膀挨著這邊的牆，那基路伯的一個翅膀挨著那邊的牆，裡邊的兩個翅膀在殿中間彼此相接。</span>
<span className="v" id="v28" data-v="28"> 又用金子包裹二基路伯。</span>
</div>
</div>

## 殿之裝飾

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 6:32; 詩篇 92:12–15; 歷代志下 4:2–5"> 內殿、外殿周圍的牆上都刻著基路伯、棕樹和初開的花。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 21:18–21; 以賽亞書 60:17; 以賽亞書 54:11–12"> 內殿、外殿的地板都貼上金子。</span>
<span className="v" id="v31" data-v="31" data-xref="希伯來書 10:19–20; 以弗所書 3:18; 約翰福音 14:6"> 又用橄欖木製造內殿的門扇、門楣、門框，門口有牆的五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 6:18; 列王紀上 6:29"> 在橄欖木做的兩門扇上刻著基路伯、棕樹和初開的花，都貼上金子。</span>
<span className="v" id="v33" data-v="33"> 又用橄欖木製造外殿的門框，門口有牆的四分之一。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 41:23–25; 列王紀上 5:8"> 用松木做門兩扇，這扇分兩扇，是摺疊的，那扇分兩扇，也是摺疊的。</span>
<span className="v" id="v35" data-v="35"> 上面刻著基路伯、棕樹和初開的花，都用金子貼了。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:12; 歷代志下 7:7; 出埃及記 27:9–19"> 他又用鑿成的石頭三層，香柏木一層建築內院。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王紀上 6:1; 歷代志下 3:2"> 所羅門在位第四年西弗月，立了耶和華殿的根基。</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉記 6:14–15; 列王紀上 7:1; 撒迦利亞書 4:9"> 到十一年布勒月，就是八月，殿和一切屬殿的都按著樣式造成。他建殿的工夫共有七年。</span>
</div>
</div>

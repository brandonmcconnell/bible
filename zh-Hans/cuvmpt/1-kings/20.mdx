## 便哈達攻亞哈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 15:18; 列王紀上 15:20; 列王紀上 22:31"> 亞蘭王便哈達聚集他的全軍，率領三十二個王，帶著車馬上來圍攻撒馬利亞。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 36:2–22; 列王紀下 19:9; 以賽亞書 37:9–10"> 又差遣使者進城見以色列王亞哈，對他說：「便哈達如此說：</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:9; 以賽亞書 10:13–14"> 『你的金銀都要歸我，你妻子、兒女中最美的也要歸我。』」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 15:11–13; 申命記 28:48; 撒母耳記上 13:6–7"> 以色列王回答說：「我主我王啊，可以依著你的話，我與我所有的都歸你。」</span>
<span className="v" id="v5" data-v="5"> 使者又來說：「便哈達如此說：『我已差遣人去見你，要你將你的金銀、妻子、兒女都給我。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 25:34; 約珥書 3:5; 列王紀下 18:31–32"> 但明日約在這時候，我還要差遣臣僕到你那裡，搜查你的家和你僕人的家，將你眼中一切所喜愛的都拿了去。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:7; 箴言 6:14; 列王紀上 8:1"> 以色列王召了國中的長老來，對他們說：「請你們看看，這人是怎樣地謀害我！他先差遣人到我這裡來，要我的妻子、兒女和金銀，我並沒有推辭他。」</span>
<span className="v" id="v8" data-v="8"> 長老和百姓對王說：「不要聽從他，也不要應允他。」</span>
<span className="v" id="v9" data-v="9"> 故此，以色列王對便哈達的使者說：「你們告訴我主我王說：『王頭一次差遣人向僕人所要的，僕人都依從。但這次所要的，我不能依從。』」使者就去回覆便哈達。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 19:2; 出埃及記 11:8; 列王紀下 19:23–24"> 便哈達又差遣人去見亞哈說：「撒馬利亞的塵土若夠跟從我的人每人捧一捧的，願神明重重地降罰於我！」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 27:1; 以賽亞書 10:15–16; 撒母耳記上 17:44–47"> 以色列王說：「你告訴他說：『才頂盔貫甲的，休要像摘盔卸甲的誇口。』」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 16:9; 列王紀上 20:16; 箴言 31:4–5"> 便哈達和諸王正在帳幕裡喝酒，聽見這話，就對他臣僕說：「擺隊吧！」他們就擺隊攻城。</span>
</div>
</div>

## 先知預言便哈達之敗

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 20:28; 以西結書 20:22; 以賽亞書 7:1–9"> 有一個先知來見以色列王亞哈，說：「耶和華如此說：『這一大群人你看見了嗎？今日我必將他們交在你手裡，你就知道我是耶和華。』」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 17:50; 創世記 14:14–16; 列王紀上 18:44"> 亞哈說：「藉著誰呢？」他回答說：「耶和華說：『藉著跟從省長的少年人。』」亞哈說：「要誰率領呢？」他說：「要你親自率領。」</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 7:16; 撒母耳記上 14:2; 士師記 7:7"> 於是亞哈數點跟從省長的少年人，共有二百三十二名，後又數點以色列的眾兵，共有七千名。</span>
</div>
</div>

## 亞蘭人遁

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="傳道書 10:16–17; 何西阿書 4:11; 列王紀上 16:9"> 午間，他們就出城。便哈達和幫助他的三十二個王正在帳幕裡痛飲。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:14–15; 列王紀上 20:19"> 跟從省長的少年人先出城。便哈達差遣人去探望，他們回報說：「有人從撒馬利亞出來了。」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 14:8–12; 撒母耳記上 14:11–12; 箴言 18:12"> 他說：「他們若為講和出來，要活捉他們；若為打仗出來，也要活捉他們。」</span>
<span className="v" id="v19" data-v="19"> 跟從省長的少年人出城，軍兵跟隨他們。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 30:16–17; 列王紀下 19:36; 傳道書 9:11"> 各人遇見敵人就殺。亞蘭人逃跑，以色列人追趕他們。亞蘭王便哈達騎著馬和馬兵一同逃跑。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 3:18; 士師記 3:28; 列王紀下 3:24"> 以色列王出城攻打車馬，大大擊殺亞蘭人。</span>
</div>
</div>

## 先知警教亞哈

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 11:1; 列王紀上 20:26; 列王紀上 20:13"> 那先知來見以色列王，對他說：「你當自強，留心怎樣防備，因為到明年這時候，亞蘭王必上來攻擊你。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 14:23; 撒母耳記上 4:8; 詩篇 50:21–22"> 亞蘭王的臣僕對亞蘭王說：「以色列人的神是山神，所以他們勝過我們。但在平原與他們打仗，我們必定得勝。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 22:31; 箴言 21:30; 列王紀上 20:16"> 王當這樣行：把諸王革去，派軍長代替他們，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 10:3"> 又照著王喪失軍兵之數，再招募一軍，馬補馬，車補車，我們在平原與他們打仗，必定得勝。」王便聽臣僕的話去行。</span>
</div>
</div>

## 便哈達復與以色列人戰

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀下 13:17; 列王紀上 20:22; 撒母耳記上 4:1"> 次年，便哈達果然點齊亞蘭人上亞弗去，要與以色列人打仗。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:5; 撒母耳記上 13:5–8; 撒母耳記上 14:2"> 以色列人也點齊軍兵，預備食物，迎著亞蘭人出去，對著他們安營，好像兩小群山羊羔，亞蘭人卻滿了地面。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 20:13; 列王紀上 17:18; 以西結書 12:16"> 有神人來見以色列王，說：「耶和華如此說：『亞蘭人既說我耶和華是山神，不是平原的神，所以我必將這一大群人都交在你手中，你們就知道我是耶和華。』」</span>
</div>
</div>

## 便哈達復敗

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志下 13:17; 歷代志下 28:6; 詩篇 10:16"> 以色列人與亞蘭人相對安營七日，到第七日兩軍交戰。那一日以色列人殺了亞蘭人步兵十萬，</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 22:25; 歷代志下 18:24; 列王紀上 20:26"> 其餘的逃入亞弗城。城牆塌倒，壓死剩下的二萬七千人。便哈達也逃入城，藏在嚴密的屋子裡。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:31; 創世記 37:34; 列王紀上 20:23"> 他的臣僕對他說：「我們聽說以色列王都是仁慈的王，現在我們不如腰束麻布，頭套繩索，出去投降以色列王，或者他存留王的性命。」</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 20:3–6; 約伯記 12:17–18; 但以理書 5:20–23"> 於是他們腰束麻布，頭套繩索，去見以色列王，說：「王的僕人便哈達說：『求王存留我的性命！』」亞哈說：「他還活著嗎？他是我的兄弟。」</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 16:8; 列王紀下 10:15; 箴言 25:13"> 這些人留心探出他的口氣來，便急忙就著他的話說：「便哈達是王的兄弟。」王說：「你們去請他來。」便哈達出來見王，王就請他上車。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 15:20; 以賽亞書 26:10; 列王紀上 20:42"> 便哈達對王說：「我父從你父那裡所奪的城邑，我必歸還。你可以在大馬士革立街市，像我父在撒馬利亞所立的一樣。」亞哈說：「我照此立約，放你回去。」就與他立約，放他去了。</span>
</div>
</div>

## 先知責亞哈縱敵

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王紀下 2:15; 列王紀上 13:17–18; 列王紀下 4:1"> 有先知的一個門徒奉耶和華的命對他的同伴說：「你打我吧！」那人不肯打他。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 13:21–24; 列王紀上 13:26; 撒母耳記上 15:22–23"> 他就對那人說：「你既不聽從耶和華的話，你一離開我，必有獅子咬死你。」那人一離開他，果然遇見獅子，把他咬死了。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 21:12; 列王紀上 20:35"> 先知的門徒又遇見一個人，對他說：「你打我吧！」那人就打他，將他打傷。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 14:2; 馬太福音 6:16; 列王紀上 22:30"> 他就去了，用頭巾蒙眼，改換面目，在路旁等候王。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀下 10:24; 約伯記 36:18; 彼得前書 1:18–19"> 王從那裡經過，他向王呼叫說：「僕人在陣上的時候，有人帶了一個人來，對我說：『你看守這人，若把他失了，你的性命必代替他的性命，不然你必交出一他連得銀子來。』</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 12:5–7; 馬太福音 25:24–27; 約伯記 15:6"> 僕人正在忙亂之間，那人就不見了。」以色列王對他說：「你自己定妥了，必照樣判斷你。」</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 6:26; 撒母耳記下 13:19; 約伯記 2:8"> 他急忙除掉蒙眼的頭巾，以色列王就認出他是一個先知。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 22:31–37; 歷代志下 18:33–34; 列王紀上 20:39"> 他對王說：「耶和華如此說：『因你將我定要滅絕的人放去，你的命就必代替他的命，你的民也必代替他的民。』」</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 21:4; 以斯帖記 5:13; 以斯帖記 6:12–13"> 於是以色列王悶悶不樂地回到撒馬利亞，進了他的宮。</span>
</div>
</div>

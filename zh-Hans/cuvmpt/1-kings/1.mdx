## 大衛王年邁之景況

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 23:1–2; 歷代志上 29:27–28; 歷代志上 23:1"> 大衛王年紀老邁，雖用被遮蓋，仍不覺暖。</span>
<span className="v" id="v2" data-v="2" data-xref="傳道書 4:11; 創世記 16:5; 彌迦書 7:5"> 所以臣僕對他說：「不如為我主我王尋找一個處女，使她伺候王，奉養王，睡在王的懷中，好叫我主我王得暖。」</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 19:18; 以斯帖記 2:4; 以斯帖記 2:2"> 於是在以色列全境尋找美貌的童女，尋得書念的一個童女亞比煞，就帶到王那裡。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:25"> 這童女極其美貌，她奉養王，伺候王，王卻沒有與她親近。</span>
</div>
</div>

## 亞多尼雅謀竊王位

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 15:1; 撒母耳記下 3:4; 申命記 17:15–16"> 那時，哈及的兒子亞多尼雅自尊，說：「我必做王。」就為自己預備車輛、馬兵，又派五十人在他前頭奔走。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 3:3–4; 撒母耳記上 3:13; 希伯來書 12:5–6"> 他父親素來沒有使他憂悶，說：「你是做什麼呢？」他甚俊美，生在押沙龍之後。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 20:25; 列王紀上 2:22; 撒母耳記上 22:20–23"> 亞多尼雅與洗魯雅的兒子約押和祭司亞比亞他商議，二人就順從他，幫助他。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 4:18; 撒母耳記下 23:8–39; 撒母耳記下 20:25"> 但祭司撒督、耶何耶大的兒子比拿雅、先知拿單、示每、利以並大衛的勇士都不順從亞多尼雅。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 17:17; 撒母耳記下 13:23–27; 撒母耳記下 15:11–12"> 一日，亞多尼雅在隱羅結旁瑣希列磐石那裡宰了牛羊、肥犢，請他的諸弟兄，就是王的眾子，並所有做王臣僕的猶大人；</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 12:24; 列王紀上 1:19; 撒母耳記下 12:1–15"> 唯獨先知拿單和比拿雅並勇士，與他的兄弟所羅門，他都沒有請。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 3:4; 撒母耳記下 7:12–17; 撒母耳記下 12:24–25"> 拿單對所羅門的母親拔示巴說：「哈及的兒子亞多尼雅做王了，你沒有聽見嗎？我們的主大衛卻不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行傳 27:31; 創世記 19:17"> 現在我可以給你出個主意，好保全你和你兒子所羅門的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 1:30; 列王紀上 1:17; 詩篇 132:11–12"> 你進去見大衛王，對他說：『我主我王啊，你不曾向婢女起誓說「你兒子所羅門必接續我做王，坐在我的位上」嗎？現在亞多尼雅怎麼做了王呢？』</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 13:1; 列王紀上 1:17–27"> 你還與王說話的時候，我也隨後進去，證實你的話。」</span>
</div>
</div>

## 撥示巴覲王陳訴

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 1:1"> 拔示巴進入內室見王，王甚老邁，書念的童女亞比煞正伺候王。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 25:23; 撒母耳記上 24:8; 撒母耳記上 20:41"> 拔示巴向王屈身下拜。王說：「你要什麼？」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 1:13; 列王紀上 1:30; 彼得前書 3:6"> 她說：「我主啊，你曾向婢女指著耶和華你的神起誓說：『你兒子所羅門必接續我做王，坐在我的位上。』</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:24; 列王紀上 1:11; 使徒行傳 3:17"> 現在亞多尼雅做王了，我主我王卻不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 1:25; 列王紀上 1:7–10"> 他宰了許多牛羊、肥犢，請了王的眾子和祭司亞比亞他並元帥約押，唯獨王的僕人所羅門他沒有請。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 29:1; 詩篇 123:2; 歷代志上 22:8–10"> 我主我王啊，以色列眾人的眼目都仰望你，等你曉諭他們，在我主我王之後誰坐你的位。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 申命記 31:16; 創世記 15:15"> 若不然，到我主我王與列祖同睡以後，我和我兒子所羅門必算為罪人了。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約伯記 1:16–18; 創世記 24:15; 但以理書 9:20"> 拔示巴還與王說話的時候，先知拿單也進來了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 1:16; 彼得前書 2:17; 羅馬書 13:7"> 有人奏告王說：「先知拿單來了。」拿單進到王前，臉伏於地。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:17–18; 列王紀上 1:5; 列王紀上 1:13–14"> 拿單說：「我主我王果然應許亞多尼雅說『你必接續我做王，坐在我的位上』嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 10:24; 列王紀上 1:19; 列王紀上 1:9"> 他今日下去，宰了許多牛羊、肥犢，請了王的眾子和軍長並祭司亞比亞他。他們正在亞多尼雅面前吃喝，說：『願亞多尼雅王萬歲！』</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 1:8; 列王紀上 1:10; 撒母耳記下 7:2"> 唯獨我，就是你的僕人，和祭司撒督、耶何耶大的兒子比拿雅，並王的僕人所羅門，他都沒有請。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 15:15; 列王紀上 1:24; 列王紀下 4:27"> 這事果然出乎我主我王嗎？王卻沒有告訴僕人們，在我主我王之後誰坐你的位。」</span>
</div>
</div>

## 大衛誓許所羅門為王

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28"> 大衛王吩咐說：「叫拔示巴來。」拔示巴就進來，站在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 4:9; 詩篇 136:24; 撒母耳記上 14:45"> 王起誓說：「我指著救我性命脫離一切苦難，永生的耶和華起誓：</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:13; 列王紀上 1:17"> 我既然指著耶和華以色列的神向你起誓說『你兒子所羅門必接續我做王，坐在我的位上』，我今日就必照這話而行。」</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 2:4; 但以理書 5:10; 但以理書 3:9"> 於是，拔示巴臉伏於地，向王下拜，說：「願我主大衛王萬歲！」</span>
</div>
</div>

## 所羅門在基訓受膏

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀上 1:8; 列王紀上 1:38; 列王紀上 1:26"> 大衛王又吩咐說：「將祭司撒督、先知拿單、耶何耶大的兒子比拿雅召來。」他們就都來到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 32:30; 列王紀上 1:38; 歷代志下 33:14"> 王對他們說：「要帶領你們主的僕人，使我兒子所羅門騎我的騾子，送他下到基訓。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 1:25; 撒母耳記下 15:10; 撒母耳記上 10:1"> 在那裡，祭司撒督和先知拿單要膏他做以色列的王。你們也要吹角，說：『願所羅門王萬歲！』</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 1:17; 詩篇 72:1–2; 列王紀上 1:13"> 然後要跟隨他上來，使他坐在我的位上，接續我做王。我已立他做以色列和猶大的君。」</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 28:6; 哥林多前書 14:16; 詩篇 72:19"> 耶何耶大的兒子比拿雅對王說：「阿們！願耶和華我主我王的神也這樣命定。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 20:13; 列王紀上 1:47; 約書亞記 1:17"> 耶和華怎樣與我主我王同在，願他照樣與所羅門同在，使他的國位比我主大衛王的國位更大。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 8:18; 列王紀上 1:8; 列王紀上 1:33"> 於是，祭司撒督、先知拿單、耶何耶大的兒子比拿雅和基利提人、比利提人都下去，使所羅門騎大衛王的騾子，將他送到基訓。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 89:20; 列王紀上 1:34; 歷代志上 29:22"> 祭司撒督就從帳幕中取了盛膏油的角來，用膏膏所羅門。人就吹角，眾民都說：「願所羅門王萬歲！」</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 11:14; 撒迦利亞書 9:9; 列王紀下 11:20"> 眾民跟隨他上來，且吹笛，大大歡呼，聲音震地。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約伯記 15:21–22; 路加福音 17:26–29; 使徒行傳 21:31"> 亞多尼雅和所請的眾客筵宴方畢，聽見這聲音。約押聽見角聲就說：「城中為何有這響聲呢？」</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記下 15:36; 撒母耳記下 17:17; 撒母耳記下 18:27"> 他正說話的時候，祭司亞比亞他的兒子約拿單來了。亞多尼雅對他說：「進來吧！你是個忠義的人，必是報好信息。」</span>
<span className="v" id="v43" data-v="43"> 約拿單對亞多尼雅說：「我們的主大衛王誠然立所羅門為王了！</span>
<span className="v" id="v44" data-v="44"> 王差遣祭司撒督、先知拿單、耶何耶大的兒子比拿雅和基利提人、比利提人都去，使所羅門騎王的騾子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 1:40; 但以理書 5:26–28; 撒母耳記上 4:5"> 祭司撒督和先知拿單在基訓已經膏他做王。眾人都從那裡歡呼著上來，聲音使城震動，這就是你們所聽見的聲音。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志上 29:23; 詩篇 132:11; 列王紀上 1:13"> 並且，所羅門登了國位。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 47:31; 列王紀上 1:37; 以斯拉記 6:10"> 王的臣僕也來為我們的主大衛王祝福，說：『願王的神使所羅門的名比王的名更尊榮，使他的國位比王的國位更大。』王就在床上屈身下拜。</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 3:6; 詩篇 132:11–12; 詩篇 145:2"> 王又說：『耶和華以色列的神是應當稱頌的！因他賜我一人今日坐在我的位上，我也親眼看見了。』」</span>
</div>
</div>

## 亞多尼雅聞信驚懼

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以賽亞書 21:4–5; 箴言 28:1; 但以理書 5:4–6"> 亞多尼雅的眾客聽見這話就都驚懼，起來四散。</span>
<span className="v" id="v50" data-v="50" data-xref="列王紀上 2:28; 出埃及記 21:14; 出埃及記 27:2"> 亞多尼雅懼怕所羅門，就起來，去抓住祭壇的角。</span>
<span className="v" id="v51" data-v="51"> 有人告訴所羅門說：「亞多尼雅懼怕所羅門王，現在抓住祭壇的角，說：『願所羅門王今日向我起誓，必不用刀殺僕人。』」</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳記上 14:45; 撒母耳記下 14:11; 箴言 13:6"> 所羅門說：「他若做忠義的人，連一根頭髮也不至落在地上；他若行惡，必要死亡。」</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 1:16; 撒母耳記下 14:24; 撒母耳記下 1:2"> 於是所羅門王差遣人，使亞多尼雅從壇上下來，他就來，向所羅門王下拜。所羅門對他說：「你回家去吧！」</span>
</div>
</div>

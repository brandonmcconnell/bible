## 運約櫃入殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 5:2–10; 歷代志上 15:25; 撒母耳記下 6:12–17"> 那時，所羅門將以色列的長老和各支派的首領並以色列的族長，招聚到耶路撒冷，要把耶和華的約櫃從大衛城就是錫安運上來。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:34; 歷代志下 7:8–10; 撒迦利亞書 14:16–19"> 以他念月，就是七月，在節前，以色列人都聚集到所羅門王那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; 約書亞記 3:6; 民數記 4:15"> 以色列長老來到，祭司便抬起約櫃，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:4; 歷代志下 1:3; 出埃及記 40:2–33"> 祭司和利未人將耶和華的約櫃運上來，又將會幕和會幕的一切聖器具都帶上來。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 6:13; 歷代志上 16:1; 列王紀上 8:62–63"> 所羅門王和聚集到他那裡的以色列全會眾，一同在約櫃前獻牛羊為祭，多得不可勝數。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:19; 撒母耳記下 6:17; 列王紀上 6:27"> 祭司將耶和華的約櫃抬進內殿，就是至聖所，放在兩個基路伯的翅膀底下。</span>
<span className="v" id="v7" data-v="7"> 基路伯張著翅膀在約櫃之上，遮掩約櫃和抬櫃的槓。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 25:13–15; 出埃及記 37:4–5; 約書亞記 4:9"> 這槓甚長，槓頭在內殿前的聖所可以看見，在殿外卻不能看見，直到如今還在那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:21; 希伯來書 9:4; 出埃及記 40:20"> 約櫃裡唯有兩塊石版，就是以色列人出埃及地後，耶和華與他們立約的時候，摩西在何烈山所放的，除此以外，並無別物。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:34–35; 歷代志下 7:1–2"> 祭司從聖所出來的時候，有雲充滿耶和華的殿，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 43:4–5; 以西結書 44:4; 哥林多後書 3:18"> 甚至祭司不能站立供職，因為耶和華的榮光充滿了殿。</span>
</div>
</div>

## 所羅門宣述建殿之來由

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="詩篇 97:2; 歷代志下 6:1–11; 利未記 16:2"> 那時所羅門說：<br /><span className="pl pl-1">「耶和華曾說</span><br /><span className="pl pl-1">他必住在幽暗之處。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 7:13; 詩篇 132:13–14; 希伯來書 9:24"> <span className="pl pl-1">我已經建造殿宇做你的居所，</span><br /><span className="pl pl-1">為你永遠的住處。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 6:18; 列王紀上 8:55–56; 歷代志下 30:18–20"> 王轉臉為以色列會眾祝福，以色列會眾就都站立。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:68; 歷代志上 29:20; 歷代志上 29:10"> 所羅門說：「耶和華以色列的神是應當稱頌的！因他親口向我父大衛所應許的，也親手成就了。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 16:1; 列王紀上 8:29; 撒母耳記下 7:4–8"> 他說：『自從我領我民以色列出埃及以來，我未曾在以色列各支派中選擇一城建造殿宇為我名的居所，但揀選大衛治理我民以色列。』」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 7:2–3; 歷代志上 22:7; 歷代志上 28:2"> 所羅門說：「我父大衛曾立意要為耶和華以色列神的名建殿，</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 6:7–9; 哥林多後書 8:12"> 耶和華卻對我父大衛說：『你立意為我的名建殿，這意思甚好，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 7:5; 歷代志上 22:8–10; 歷代志上 28:6"> 只是你不可建殿，唯你所生的兒子，必為我名建殿。』</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 28:5–6; 腓立比書 1:6; 列王紀上 8:15"> 現在耶和華成就了他所應許的話，使我接續我父大衛坐以色列的國位，又為耶和華以色列神的名建造了殿。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 8:9; 申命記 31:26; 列王紀上 8:5–6"> 我也在其中為約櫃預備一處，約櫃內有耶和華的約，就是他領我們列祖出埃及地的時候，與他們所立的約。」</span>
</div>
</div>

## 大申祈禱

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以斯拉記 9:5; 列王紀上 8:54; 出埃及記 9:33"> 所羅門當著以色列會眾，站在耶和華的壇前，向天舉手說：</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 7:22; 申命記 7:9; 但以理書 9:4"> 「耶和華以色列的神啊，天上地下，沒有神可比你的。你向那盡心行在你面前的僕人守約施慈愛，</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 7:16; 列王紀上 8:15; 撒母耳記下 7:12"> 向你僕人我父大衛所應許的話現在應驗了。你親口應許，親手成就，正如今日一樣。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 2:4; 列王紀上 9:4–6; 耶利米書 33:17–26"> 耶和華以色列的神啊，你所應許你僕人我父大衛的話說『你的子孫若謹慎自己的行為，在我面前行事像你所行的一樣，就不斷人坐以色列的國位』，現在求你應驗這話。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 7:25–29; 以賽亞書 41:17; 撒母耳記上 1:17"> 以色列的神啊，求你成就向你僕人我父大衛所應許的話！</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志下 2:6; 以賽亞書 66:1; 耶利米書 23:24"> 「神果真住在地上嗎？看哪，天和天上的天尚且不足你居住的，何況我所建的這殿呢！</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 88:1–2; 詩篇 5:1; 路加福音 18:1"> 唯求耶和華我的神垂顧僕人的禱告、祈求，俯聽僕人今日在你面前的祈禱、呼籲。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 6:20; 列王紀上 8:16; 歷代志下 7:15–16"> 願你晝夜看顧這殿，就是你應許立為你名的居所；求你垂聽僕人向此處禱告的話。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 8:39; 列王紀上 8:34; 列王紀上 8:36"> 你僕人和你民以色列向此處祈禱的時候，求你在天上你的居所垂聽，垂聽而赦免。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 22:8–11; 歷代志下 6:22–23; 利未記 5:1"> 「人若得罪鄰舍，有人叫他起誓，他來到這殿，在你的壇前起誓，</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 25:1; 以賽亞書 3:10–11; 羅馬書 2:6–10"> 求你在天上垂聽，判斷你的僕人：定惡人有罪，照他所行的報應在他頭上；定義人有理，照他的義賞賜他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="利未記 26:17; 申命記 28:25; 約拿書 3:10"> 「你的民以色列若得罪你，敗在仇敵面前，又歸向你，承認你的名，在這殿裡祈求、禱告，</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 31:4–9; 但以理書 9:12; 創世記 13:15"> 求你在天上垂聽，赦免你民以色列的罪，使他們歸回你賜給他們列祖之地。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="利未記 26:19; 申命記 11:17; 列王紀上 8:33"> 「你的民因得罪你，你懲罰他們，使天閉塞不下雨，他們若向此處禱告，承認你的名，離開他們的罪，</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 27:11; 撒母耳記上 12:23; 耶利米書 6:16"> 求你在天上垂聽，赦免你僕人以色列民的罪，將當行的善道指教他們，且降雨在你的地，就是你賜給你民為業之地。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命記 28:21–22; 利未記 26:16; 歷代志下 20:9"> 「國中若有饑荒、瘟疫、旱風、霉爛、蝗蟲、螞蚱，或有仇敵犯境圍困城邑，無論遭遇什麼災禍疾病，</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 73:21–22; 列王紀上 8:22; 腓立比書 4:6"> 你的民以色列，或是眾人，或是一人，自覺有罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：災。">a</a></sup>，向這殿舉手，無論祈求什麼，禱告什麼，</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志上 28:9; 耶利米書 17:10; 使徒行傳 1:24"> 求你在天上你的居所垂聽赦免。你是知道人心的，要照各人所行的待他們——唯有你知道世人的心——</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 130:4; 啟示錄 19:5; 申命記 6:2"> 使他們在你賜給我們列祖之地上一生一世敬畏你。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王紀上 10:1–2; 使徒行傳 8:27–40; 出埃及記 18:8–12"> 「論到不屬你民以色列的外邦人，為你名從遠方而來——</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 3:24; 列王紀下 17:36; 出埃及記 3:13–16"> 他們聽人論說你的大名和大能的手並伸出來的膀臂——向這殿禱告，</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 102:15; 撒母耳記上 17:46; 詩篇 22:27"> 求你在天上你的居所垂聽，照著外邦人所祈求的而行，使天下萬民都認識你的名，敬畏你，像你的民以色列一樣，又使他們知道我建造的這殿是稱為你名下的。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歷代志下 6:34; 詩篇 78:67–69; 列王紀上 8:16"> 「你的民若奉你的差遣，無論往何處去與仇敵爭戰，向耶和華所選擇的城與我為你名所建造的殿禱告，</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 18:25; 詩篇 9:4; 耶利米書 5:28"> 求你在天上垂聽他們的禱告、祈求，使他們得勝。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="傳道書 7:20; 箴言 20:9; 約翰一書 1:8–10"> 「你的民若得罪你——世上沒有不犯罪的人——你向他們發怒，將他們交給仇敵擄到仇敵之地，或遠或近，</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 106:6; 尼希米記 1:6–11; 尼希米記 9:26–30"> 他們若在擄到之地想起罪來，回心轉意，懇求你說『我們有罪了，我們悖逆了，我們作惡了』，</span>
<span className="v" id="v48" data-v="48" data-xref="但以理書 6:10; 耶利米書 29:12–14; 申命記 4:29"> 他們若在擄到之地盡心、盡性歸服你，又向自己的地，就是你賜給他們列祖之地，和你所選擇的城，並我為你名所建造的殿禱告，</span>
<span className="v" id="v49" data-v="49" data-xref="列王紀下 19:19; 列王紀上 8:45; 撒迦利亞書 1:15–16"> 求你在天上你的居所垂聽他們的禱告、祈求，為他們申冤，</span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 106:46; 歷代志下 30:9; 使徒行傳 7:10"> 饒恕得罪你的民，赦免他們的一切過犯，使他們在擄他們的人面前蒙憐恤，</span>
<span className="v" id="v51" data-v="51" data-xref="尼希米記 1:10; 耶利米書 11:4; 申命記 4:20"> 因為他們是你的子民，你的產業，是你從埃及領出來脫離鐵爐的。</span>
<span className="v" id="v52" data-v="52" data-xref="詩篇 145:18; 列王紀上 8:29; 詩篇 86:5"> 願你的眼目看顧僕人，聽你民以色列的祈求，無論何時向你祈求，願你垂聽。</span>
<span className="v" id="v53" data-v="53" data-xref="出埃及記 19:5–6; 申命記 14:2; 申命記 32:9"> 主耶和華啊，你將他們從地上的萬民中分別出來做你的產業，是照你領我們列祖出埃及的時候，藉你僕人摩西所應許的話。」</span>

## 為民祝福

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="歷代志下 7:1; 歷代志下 6:12–13; 路加福音 22:45"> 所羅門在耶和華的壇前屈膝跪著，向天舉手，在耶和華面前禱告祈求已畢，就起來，</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀上 8:14; 撒母耳記下 6:18; 民數記 6:23–26"> 站著，大聲為以色列全會眾祝福，說：</span>
<span className="v" id="v56" data-v="56" data-xref="約書亞記 23:14–15; 約書亞記 21:44–45; 路加福音 21:33"> 「耶和華是應當稱頌的！因為他照著一切所應許的賜平安給他的民以色列人，凡藉他僕人摩西應許賜福的話，一句都沒有落空。</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 1:5; 申命記 31:6; 申命記 31:8"> 願耶和華我們的神與我們同在，像與我們列祖同在一樣，不撇下我們，不丟棄我們，</span>
<span className="v" id="v58" data-v="58" data-xref="詩篇 119:36; 以西結書 36:26–27; 耶利米書 31:33"> 使我們的心歸向他，遵行他的道，謹守他吩咐我們列祖的誡命、律例、典章。</span>
<span className="v" id="v59" data-v="59" data-xref="詩篇 141:2; 約翰福音 17:9; 約翰福音 17:20–24"> 我在耶和華面前祈求的這些話，願耶和華我們的神晝夜垂念，每日為他僕人與他民以色列申冤，</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 4:35; 耶利米書 10:10–12; 列王紀上 18:39"> 使地上的萬民都知道唯獨耶和華是神，並無別神。</span>
<span className="v" id="v61" data-v="61" data-xref="列王紀上 11:4; 列王紀下 20:3; 哥林多後書 7:1"> 所以你們當向耶和華我們的神存誠實的心，遵行他的律例，謹守他的誡命，至終如今日一樣。」</span>
</div>
</div>

## 獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="撒母耳記下 6:17–19; 以斯拉記 6:16–17; 歷代志下 7:4–10"> 王和以色列眾民一同在耶和華面前獻祭。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉記 6:16–17; 歷代志下 15:11; 尼希米記 12:27"> 所羅門向耶和華獻平安祭，用牛二萬二千，羊十二萬。這樣，王和以色列眾民為耶和華的殿行奉獻之禮。</span>
<span className="v" id="v64" data-v="64" data-xref="歷代志下 4:1; 歷代志下 7:7"> 當日，王因耶和華殿前的銅壇太小，容不下燔祭、素祭和平安祭牲的脂油，便將耶和華殿前院子當中分別為聖，在那裡獻燔祭、素祭和平安祭牲的脂油。</span>
<span className="v" id="v65" data-v="65" data-xref="民數記 34:5; 民數記 34:8; 列王紀上 8:2"> 那時所羅門和以色列眾人，就是從哈馬口直到埃及小河所有的以色列人，都聚集成為大會，在耶和華我們的神面前守節七日又七日，共十四日。</span>
<span className="v" id="v66" data-v="66" data-xref="腓立比書 4:4; 使徒行傳 2:46; 撒迦利亞書 9:17"> 第八日，王遣散眾民，他們都為王祝福。因見耶和華向他僕人大衛和他民以色列所施的一切恩惠，就都心中喜樂，各歸各家去了。</span>

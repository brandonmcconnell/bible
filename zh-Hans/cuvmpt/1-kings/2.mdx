## 大衛遺命所羅門

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 47:29; 申命記 31:14; 提摩太前書 1:18"> 大衛的死期臨近了，就囑咐他兒子所羅門說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:6–7; 約書亞記 23:14; 以弗所書 6:10"> 「我現在要走世人必走的路，所以你當剛強，做大丈夫，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:9; 申命記 17:18–20; 箴言 3:1–4"> 遵守耶和華你神所吩咐的，照著摩西律法上所寫的行主的道，謹守他的律例、誡命、典章、法度。這樣，你無論做什麼事，不拘往何處去，盡都亨通。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 20:3; 撒母耳記下 7:25; 列王紀上 8:25"> 耶和華必成就向我所應許的話說：『你的子孫若謹慎自己的行為，盡心、盡意，誠誠實實地行在我面前，就不斷人坐以色列的國位。』</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 3:27; 撒母耳記下 20:10; 撒母耳記下 18:5"> 你知道洗魯雅的兒子約押向我所行的，就是殺了以色列的兩個元帥——尼珥的兒子押尼珥和益帖的兒子亞瑪撒。他在太平之時流這二人的血，如在爭戰之時一樣，將這血染了腰間束的帶和腳上穿的鞋。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 2:9; 以賽亞書 57:21; 詩篇 37:37"> 所以你要照你的智慧行，不容他白頭安然下陰間。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 17:27–29; 撒母耳記下 9:7; 撒母耳記下 19:31–40"> 你當恩待基列人巴西萊的眾子，使他們常與你同席吃飯，因為我躲避你哥哥押沙龍的時候，他們拿食物來迎接我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 16:5–8; 列王紀上 2:36–46; 撒母耳記下 19:16–23"> 在你這裡有巴戶琳的便雅憫人基拉的兒子示每。我往瑪哈念去的那日，他用狠毒的言語咒罵我，後來卻下約旦河迎接我，我就指著耶和華向他起誓說：『我必不用刀殺你。』</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:6; 創世記 42:38; 創世記 44:31"> 現在你不要以他為無罪。你是聰明人，必知道怎樣待他，使他白頭見殺，流血下到陰間。」</span>
</div>
</div>

## 大衛壽終

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:29; 使徒行傳 13:36; 列王紀上 1:21"> 大衛與他列祖同睡，葬在大衛城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 5:4–5; 歷代志上 29:26–27"> 大衛做以色列王四十年，在希伯崙做王七年，在耶路撒冷做王三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 1:1; 歷代志上 29:23–25; 詩篇 132:12"> 所羅門坐他父親大衛的位，他的國甚是堅固。</span>
</div>
</div>

## 亞多尼雅求亞比煞為妻

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 16:4–5; 列王紀上 1:5–10; 路加福音 10:5–6"> 哈及的兒子亞多尼雅去見所羅門的母親拔示巴，拔示巴問他說：「你來是為平安嗎？」回答說：「是為平安。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 14:12; 路加福音 7:40"> 又說：「我有話對你說。」拔示巴說：「你說吧。」</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 22:9–10; 歷代志上 28:5–7; 列王紀上 1:25"> 亞多尼雅說：「你知道國原是歸我的，以色列眾人也都仰望我做王，不料，國反歸了我兄弟，因他得國是出乎耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 詩篇 132:10"> 現在我有一件事求你，望你不要推辭。」拔示巴說：「你說吧。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 12:8; 列王紀上 1:2–4; 撒母耳記下 3:7"> 他說：「求你請所羅門王將書念的女子亞比煞賜我為妻，因他必不推辭你。」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 拔示巴說：「好，我必為你對王提說。」</span>
</div>
</div>

## 亞多尼雅見殺

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="詩篇 45:9; 列王紀上 15:13; 利未記 19:32"> 於是，拔示巴去見所羅門王，要為亞多尼雅提說。王起來迎接，向她下拜，就坐在位上，吩咐人為王母設一座位，她便坐在王的右邊。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:7–11; 馬太福音 11:24; 約翰福音 2:3–4"> 拔示巴說：「我有一件小事求你，望你不要推辭。」王說：「請母親說，我必不推辭。」</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 1:3; 撒母耳記下 16:21–22"> 拔示巴說：「求你將書念的女子亞比煞賜給你哥哥亞多尼雅為妻。」</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 3:2; 歷代志上 3:5; 馬太福音 20:22"> 所羅門王對他母親說：「為何單替他求書念的女子亞比煞呢？也可以為他求國吧！他是我的哥哥，他有祭司亞比亞他和洗魯雅的兒子約押為輔佐。」</span>
<span className="v" id="v23" data-v="23" data-xref="路得記 1:17; 詩篇 140:9; 詩篇 64:8"> 所羅門王就指著耶和華起誓說：「亞多尼雅這話是自己送命，不然，願神重重地降罰於我！</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 22:10; 歷代志上 17:10; 歷代志上 17:17"> 耶和華堅立我，使我坐在父親大衛的位上，照著所應許的話為我建立家室。現在我指著永生的耶和華起誓：亞多尼雅今日必被治死！」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 8:18; 列王紀上 2:46; 士師記 8:20–21"> 於是所羅門王差遣耶何耶大的兒子比拿雅，將亞多尼雅殺死。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約書亞記 21:18; 撒母耳記上 22:20–23; 耶利米書 1:1"> 王對祭司亞比亞他說：「你回亞拿突歸自己的田地去吧！你本是該死的，但因你在我父親大衛面前抬過主耶和華的約櫃，又與我父親同受一切苦難，所以我今日不將你殺死。」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 2:27–36; 撒母耳記上 3:12–14; 耶利米書 7:12–14"> 所羅門就革除亞比亞他，不許他做耶和華的祭司。這樣，便應驗耶和華在示羅論以利家所說的話。</span>
</div>
</div>

## 約押見殺

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 1:50; 列王紀上 1:7; 撒母耳記下 18:2"> 約押雖然沒有歸從押沙龍，卻歸從了亞多尼雅。他聽見這風聲，就逃到耶和華的帳幕，抓住祭壇的角。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 2:25; 出埃及記 21:14; 列王紀上 2:46"> 有人告訴所羅門王說：「約押逃到耶和華的帳幕，現今在祭壇的旁邊。」所羅門就差遣耶何耶大的兒子比拿雅，說：「你去將他殺死。」</span>
<span className="v" id="v30" data-v="30"> 比拿雅來到耶和華的帳幕，對約押說：「王吩咐說，你出來吧！」他說：「我不出去，我要死在這裡！」比拿雅就去回覆王說：「約押如此如此回答我。」</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 21:8–9; 民數記 35:33; 出埃及記 21:14"> 王說：「你可以照著他的話行，殺死他，將他葬埋，好叫約押流無辜人血的罪不歸我和我的父家了。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 9:24; 士師記 9:57; 詩篇 7:16"> 耶和華必使約押流人血的罪歸到他自己的頭上，因為他用刀殺了兩個比他又義又好的人，就是以色列元帥尼珥的兒子押尼珥和猶大元帥益帖的兒子亞瑪撒，我父親大衛卻不知道。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:25; 列王紀上 2:32; 路加福音 2:14"> 故此，流這二人血的罪必歸到約押和他後裔的頭上，直到永遠。唯有大衛和他的後裔，並他的家與國，必從耶和華那裡得平安，直到永遠。」</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 3:1; 約書亞記 15:61; 列王紀上 2:25"> 於是耶何耶大的兒子比拿雅上去，將約押殺死，葬在曠野約押自己的墳墓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「墳墓」原文作「房屋」。">a</a></sup>裡。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 2:27; 歷代志上 24:3; 歷代志上 29:22"> 王就立耶何耶大的兒子比拿雅做元帥，代替約押，又使祭司撒督代替亞比亞他。</span>
</div>
</div>

## 戒示每勿出耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 16:5–9; 列王紀上 2:8–9; 箴言 20:26"> 王差遣人將示每召來，對他說：「你要在耶路撒冷建造房屋居住，不可出來往別處去。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 1:16; 撒母耳記下 15:23; 約書亞記 2:19"> 你當確實地知道：你何日出來過汲淪溪，何日必死，你的罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：血。">b</a></sup>必歸到自己的頭上。」</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 20:4; 列王紀下 20:19"> 示每對王說：「這話甚好。我主我王怎樣說，僕人必怎樣行。」於是示每多日住在耶路撒冷。</span>
</div>
</div>

## 示每見殺

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 21:10; 撒母耳記上 27:2–3"> 過了三年，示每的兩個僕人逃到迦特王瑪迦的兒子亞吉那裡去。有人告訴示每說：「你的僕人在迦特。」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前書 6:10"> 示每起來，備上驢，往迦特到亞吉那裡去找他的僕人，就從迦特帶他僕人回來。</span>
<span className="v" id="v41" data-v="41"> 有人告訴所羅門說：「示每出耶路撒冷往迦特去，回來了。」</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 15:4; 列王紀上 2:36–38; 路加福音 15:22"> 王就差遣人將示每召了來，對他說：「我豈不是叫你指著耶和華起誓，並且警戒你說『你當確實地知道，你哪日出來往別處去，哪日必死』嗎？你也對我說『這話甚好，我必聽從』。</span>
<span className="v" id="v43" data-v="43" data-xref="羅馬書 13:5; 歷代志下 30:12; 傳道書 8:2"> 現在你為何不遵守你指著耶和華起的誓和我所吩咐你的命令呢？」</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記下 16:5–13; 詩篇 7:16; 以西結書 17:19"> 王又對示每說：「你向我父親大衛所行的一切惡事，你自己心裡也知道，所以耶和華必使你的罪惡歸到自己的頭上。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王紀上 2:24; 以賽亞書 9:6–7"> 唯有所羅門王必得福，並且大衛的國位必在耶和華面前堅定，直到永遠。」</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 1:1; 列王紀上 2:12; 列王紀上 2:45"> 於是王吩咐耶何耶大的兒子比拿雅，他就去殺死示每。這樣，便堅定了所羅門的國位。</span>
</div>

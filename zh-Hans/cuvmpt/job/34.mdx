## 以利戶責約伯自義向神煩言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 以利戶又說：</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:5; 哥林多前書 14:20; 哥林多前書 10:15"> <span className="pl pl-1">「你們智慧人，要聽我的話；</span><br /><span className="pl pl-1">有知識的人，要留心聽我說。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 12:11; 哥林多前書 2:15; 約伯記 33:2"> <span className="pl pl-1">因為耳朵試驗話語，</span><br /><span className="pl pl-1">好像上膛嘗食物。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:21; 士師記 19:30; 羅馬書 12:2"> <span className="pl pl-1">我們當選擇何為是，</span><br /><span className="pl pl-1">彼此知道何為善。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 27:2; 約伯記 33:9; 約伯記 16:17"> <span className="pl pl-1">約伯曾說：『我是公義，</span><br /><span className="pl pl-1">神奪去我的理。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 6:4; 約伯記 27:4–6; 約伯記 16:13"> <span className="pl pl-1">我雖有理，還算為說謊言的；</span><br /><span className="pl pl-1">我雖無過，受的傷還不能醫治。』</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 15:16; 申命記 29:19; 箴言 1:22"> <span className="pl pl-1">誰像約伯，</span><br /><span className="pl pl-1">喝譏誚如同喝水呢？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 1:1; 哥林多前書 15:33; 箴言 13:20"> <span className="pl pl-1">他與作孽的結伴，</span><br /><span className="pl pl-1">和惡人同行。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 21:14–16; 約伯記 35:3; 瑪拉基書 3:14"> <span className="pl pl-1">他說，人以神為樂</span><br /><span className="pl pl-1">總是無益。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 9:14; 申命記 32:4; 約伯記 8:3"> <span className="pl pl-1">「所以你們明理的人，要聽我的話：</span><br /><span className="pl pl-1">神斷不至行惡，</span><br /><span className="pl pl-1">全能者斷不至作孽。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 5:10; 羅馬書 2:6; 啟示錄 22:12"> <span className="pl pl-1">他必按人所做的報應人，</span><br /><span className="pl pl-1">使各人照所行的得報。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 8:3; 詩篇 11:7; 詩篇 145:17"> <span className="pl pl-1">神必不作惡，</span><br /><span className="pl pl-1">全能者也不偏離公平。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 29:11; 以賽亞書 40:13–14; 羅馬書 11:34–36"> <span className="pl pl-1">誰派他治理地，</span><br /><span className="pl pl-1">安定全世界呢？</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:29; 約伯記 7:17; 約伯記 9:4"> <span className="pl pl-1">他若專心為己，</span><br /><span className="pl pl-1">將靈和氣收歸自己，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="創世記 3:19; 傳道書 12:7; 以賽亞書 57:16"> <span className="pl pl-1">凡有血氣的就必一同死亡，</span><br /><span className="pl pl-1">世人必仍歸塵土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="約伯記 13:2–6; 約伯記 12:3"> <span className="pl pl-1">「你若明理，就當聽我的話，</span><br /><span className="pl pl-1">留心聽我言語的聲音。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 40:8; 創世記 18:25; 撒母耳記下 23:3"> <span className="pl pl-1">難道恨惡公平的可以掌權嗎？</span><br /><span className="pl pl-1">那有公義的，有大能的，豈可定他有罪嗎？</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 22:28; 箴言 17:26; 羅馬書 13:7"> <span className="pl pl-1">他對君王說：『你是鄙陋的！』</span><br /><span className="pl pl-1">對貴臣說：『你是邪惡的！』</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:17; 使徒行傳 10:34; 雅各書 2:5"> <span className="pl pl-1">他待王子不徇情面，</span><br /><span className="pl pl-1">也不看重富足的過於貧窮的，</span><br /><span className="pl pl-1">因為都是他手所造。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 73:19; 撒母耳記上 25:37–39; 撒母耳記上 26:10"> <span className="pl pl-1">在轉眼之間，半夜之中，</span><br /><span className="pl pl-1">他們就死亡，</span><br /><span className="pl pl-1">百姓被震動而去世，</span><br /><span className="pl pl-1">有權力的被奪去非藉人手。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="箴言 15:3; 約伯記 31:4; 耶利米書 16:17"> <span className="pl pl-1">「神注目觀看人的道路，</span><br /><span className="pl pl-1">看明人的腳步。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 4:13; 阿摩司書 9:2–3; 箴言 10:29"> <span className="pl pl-1">沒有黑暗、陰翳能給作孽的藏身。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:13; 詩篇 119:137; 羅馬書 9:20"> <span className="pl pl-1">神審判人，不必使人到他面前再三鑒察。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 113:7–8; 詩篇 94:5; 但以理書 2:21"> <span className="pl pl-1">他用難測之法打破有能力的人，</span><br /><span className="pl pl-1">設立別人代替他們。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 7:2; 約伯記 34:20; 阿摩司書 8:7"> <span className="pl pl-1">他原知道他們的行為，</span><br /><span className="pl pl-1">使他們在夜間傾倒滅亡。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 58:10–11; 申命記 21:21; 以賽亞書 66:24"> <span className="pl pl-1">他在眾人眼前擊打他們，</span><br /><span className="pl pl-1">如同擊打惡人一樣。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 28:5; 撒母耳記上 15:11; 以賽亞書 5:12"> <span className="pl pl-1">因為他們偏行不跟從他，</span><br /><span className="pl pl-1">也不留心他的道，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="雅各書 5:4; 出埃及記 3:7; 約伯記 35:9"> <span className="pl pl-1">甚至使貧窮人的哀聲達到他那裡，</span><br /><span className="pl pl-1">他也聽了困苦人的哀聲。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 23:13; 約翰福音 14:27; 詩篇 27:9"> <span className="pl pl-1">他使人安靜，誰能擾亂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：定罪。">a</a></sup><br /><span className="pl pl-1">呢？</span><br /><span className="pl pl-1">他掩面，誰能見他呢？</span><br /><span className="pl pl-1">無論待一國或一人，都是如此，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:2–12; 約伯記 34:21; 列王紀下 21:9"> <span className="pl pl-1">使不虔敬的人不得做王，</span><br /><span className="pl pl-1">免得有人牢籠百姓。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="彌迦書 7:9; 約伯記 33:27; 約伯記 42:6"> <span className="pl pl-1">「有誰對神說</span><br /><span className="pl pl-1">『我受了責罰，不再犯罪。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 32:8; 詩篇 25:4–5; 詩篇 139:23–24"> <span className="pl pl-1">我所看不明的，求你指教我。</span><br /><span className="pl pl-1">我若作了孽，必不再做』？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="約伯記 33:32; 以賽亞書 45:9; 詩篇 135:6"> <span className="pl pl-1">他施行報應，</span><br /><span className="pl pl-1">豈要隨你的心願，叫你推辭不受嗎？</span><br /><span className="pl pl-1">選定的是你，不是我，</span><br /><span className="pl pl-1">你所知道的只管說吧！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 10:15; 約伯記 34:4; 約伯記 34:16"> <span className="pl pl-1">明理的人和聽我話的智慧人，必對我說：</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 35:16; 約伯記 38:2; 約伯記 15:2"> <span className="pl pl-1">『約伯說話沒有知識，</span><br /><span className="pl pl-1">言語中毫無智慧。』</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="約伯記 21:7; 約伯記 23:16; 約伯記 12:6"> <span className="pl pl-1">願約伯被試驗到底，</span><br /><span className="pl pl-1">因他回答像惡人一樣。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="約伯記 27:23; 以賽亞書 1:19–20; 撒母耳記上 15:23"> <span className="pl pl-1">他在罪上又加悖逆，</span><br /><span className="pl pl-1">在我們中間拍手，</span><br /><span className="pl pl-1">用許多言語輕慢神。」</span></span>
</div>

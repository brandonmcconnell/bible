## 言人干罪為義於神無所損益

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 以利戶又說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:36–37; 約伯記 19:6–7; 約伯記 16:17"> <span className="pl pl-1">「你以為有理，</span><br /><span className="pl pl-1">或以為你的公義勝於神的公義，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 34:9; 瑪拉基書 3:14; 約伯記 9:30–31"> <span className="pl pl-1">才說：『這與我有什麼益處？</span><br /><span className="pl pl-1">我不犯罪比犯罪有什麼好處呢？』</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 13:20; 約伯記 34:8"> <span className="pl pl-1">我要回答你和在你這裡的朋友。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 22:12; 以賽亞書 55:9; 那鴻書 1:3"> <span className="pl pl-1">你要向天觀看，</span><br /><span className="pl pl-1">瞻望那高於你的穹蒼。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:19; 箴言 8:36; 箴言 9:12"> <span className="pl pl-1">你若犯罪，能使神受何害呢？</span><br /><span className="pl pl-1">你的過犯加增，能使神受何損呢？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 22:2–3; 詩篇 16:2; 路加福音 17:10"> <span className="pl pl-1">你若是公義，還能加增他什麼呢？</span><br /><span className="pl pl-1">他從你手裡還接受什麼呢？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 22:30; 約伯記 42:8; 使徒行傳 27:24"> <span className="pl pl-1">你的過惡，或能害你這類的人；</span><br /><span className="pl pl-1">你的公義，或能叫世人得益處。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:23; 約伯記 34:28; 出埃及記 3:7"> <span className="pl pl-1">「人因多受欺壓就哀求，</span><br /><span className="pl pl-1">因受能者的轄制</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「轄制」原文作「膀臂」。">a</a></sup><br /><span className="pl pl-1">便求救，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 42:8; 使徒行傳 16:25; 詩篇 149:5"> <span className="pl pl-1">卻無人說：『造我的神在哪裡？</span><br /><span className="pl pl-1">他使人夜間歌唱，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 94:12; 約伯記 36:22; 約伯記 32:8"> <span className="pl pl-1">教訓我們勝於地上的走獸，</span><br /><span className="pl pl-1">使我們有聰明勝於空中的飛鳥。』</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 1:28; 約翰福音 9:31; 詩篇 123:3–4"> <span className="pl pl-1">他們在那裡</span><br /><span className="pl pl-1">因惡人的驕傲呼求，卻無人答應。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 15:29; 以賽亞書 1:15; 雅各書 4:3"> <span className="pl pl-1">虛妄的呼求，神必不垂聽，</span><br /><span className="pl pl-1">全能者也必不眷顧。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 9:11; 彌迦書 7:7–9; 詩篇 37:5–6"> <span className="pl pl-1">何況你說，你不得見他，</span><br /><span className="pl pl-1">你的案件在他面前，你等候他吧！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 89:32; 約伯記 9:14; 約伯記 13:15"> <span className="pl pl-1">但如今因他未曾發怒降罰，</span><br /><span className="pl pl-1">也不甚理會狂傲，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 38:2; 約伯記 33:8–12; 約伯記 34:35–37"> <span className="pl pl-1">所以約伯開口說虛妄的話，</span><br /><span className="pl pl-1">多發無知識的言語。」</span></span>

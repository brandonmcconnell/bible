<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 1:7; 傳道書 3:17; 彼得後書 3:7–8"> <span className="pl pl-1">「全能者既定期罰惡，</span><br /><span className="pl pl-1">為何不使認識他的人看見那日子呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="申命記 19:14; 申命記 27:17; 箴言 23:10"> <span className="pl pl-1">有人挪移地界，</span><br /><span className="pl pl-1">搶奪群畜而牧養。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 24:6; 申命記 24:10–13; 撒母耳記上 12:3"> <span className="pl pl-1">他們拉去孤兒的驢，</span><br /><span className="pl pl-1">強取寡婦的牛為當頭。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 28:28; 約伯記 24:14; 以西結書 22:29"> <span className="pl pl-1">他們使窮人離開正道，</span><br /><span className="pl pl-1">世上的貧民盡都隱藏。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 2:1; 約伯記 39:5–7; 詩篇 104:23"> <span className="pl pl-1">這些貧窮人，如同野驢出到曠野，殷勤尋找食物。</span><br /><span className="pl pl-1">他們靠著野地給兒女糊口，</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="出埃及記 22:26–27; 約伯記 22:6; 申命記 24:11–13"> <span className="pl pl-1">終夜赤身無衣，</span><br /><span className="pl pl-1">天氣寒冷毫無遮蓋，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:5; 雅歌 5:2; 希伯來書 11:38"> <span className="pl pl-1">在山上被大雨淋濕，</span><br /><span className="pl pl-1">因沒有避身之處就挨近磐石。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 5:5; 列王紀下 4:1"> <span className="pl pl-1">又有人從母懷中搶奪孤兒，</span><br /><span className="pl pl-1">強取窮人的衣服為當頭，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 2:7–8; 申命記 24:19; 阿摩司書 5:11–12"> <span className="pl pl-1">使人赤身無衣到處流行，</span><br /><span className="pl pl-1">且因飢餓扛抬禾捆，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 5:4; 耶利米書 22:13; 申命記 25:4"> <span className="pl pl-1">在那些人的圍牆內造油，榨酒</span><br /><span className="pl pl-1">自己還口渴。</span><br /></span>

</div>
<div className="bp poetry">

<span className="v" id="v19" data-v="19" data-xref="詩篇 49:14; 路加福音 16:22; 箴言 14:32"> <span className="pl pl-1">乾旱炎熱消沒雪水，</span><br /><span className="pl pl-1">陰間也如此消沒犯罪之輩。</span><br /></span>

<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 1:6–7; 約伯記 22:9; 約伯記 29:13"> <span className="pl pl-1">他惡待</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：他吞滅。">b</a></sup><br /><span className="pl pl-1">不懷孕不生養的婦人，</span><br /><span className="pl pl-1">不善待寡婦。</span><br /></span>

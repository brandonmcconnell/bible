## 惡人之禍患

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 13:9; 箴言 24:20; 箴言 20:20"> <span className="pl pl-1">「惡人的亮光必要熄滅，</span><br /><span className="pl pl-1">他的火焰必不照耀。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 18:23; 約伯記 21:17; 詩篇 18:28"> <span className="pl pl-1">他帳篷中的亮光要變為黑暗，</span><br /><span className="pl pl-1">他以上的燈也必熄滅。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 4:12; 詩篇 33:10; 詩篇 18:36"> <span className="pl pl-1">他堅強的腳步必見狹窄，</span><br /><span className="pl pl-1">自己的計謀必將他絆倒。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 9:15; 約伯記 22:10; 詩篇 35:8"> <span className="pl pl-1">因為他被自己的腳陷入網中，</span><br /><span className="pl pl-1">走在纏人的網羅上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 8:14–15; 約伯記 1:15; 約伯記 1:17"> <span className="pl pl-1">圈套必抓住他的腳跟，</span><br /><span className="pl pl-1">機關必擒獲他。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 12:13; 羅馬書 11:9; 詩篇 11:6"> <span className="pl pl-1">活扣為他藏在土內，</span><br /><span className="pl pl-1">羈絆為他藏在路上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 15:21; 耶利米書 6:25; 利未記 26:36"> <span className="pl pl-1">四面的驚嚇要使他害怕，</span><br /><span className="pl pl-1">並且追趕他的腳跟。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:36; 帖撒羅尼迦前書 5:3; 詩篇 34:10"> <span className="pl pl-1">他的力量必因飢餓衰敗，</span><br /><span className="pl pl-1">禍患要在他旁邊等候。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 2:6; 撒迦利亞書 14:12; 啟示錄 6:8"> <span className="pl pl-1">他本身的肢體要被吞吃，</span><br /><span className="pl pl-1">死亡的長子要吞吃他的肢體。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 10:28; 詩篇 55:4; 約伯記 11:20"> <span className="pl pl-1">他要從所倚靠的帳篷被拔出來，</span><br /><span className="pl pl-1">帶到驚嚇的王那裡。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 11:6; 申命記 29:23; 以賽亞書 34:9–10"> <span className="pl pl-1">不屬他的必住在他的帳篷裡，</span><br /><span className="pl pl-1">硫磺必撒在他所住之處。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="何西阿書 9:16; 以賽亞書 5:24; 約伯記 15:30"> <span className="pl pl-1">下邊，他的根本要枯乾；</span><br /><span className="pl pl-1">上邊，他的枝子要剪除。</span><br /></span>

## 約伯自詛其誕辰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 20:14–15; 詩篇 106:33; 詩篇 39:2–3"> 此後，約伯開口咒詛自己的生日，</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 18:14"> 說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 20:14–18; 耶利米書 15:10; 約伯記 10:18–19"> <span className="pl pl-1">「願我生的那日</span><br /><span className="pl pl-1">和說懷了男胎的那夜都滅沒。</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="約伯記 10:21–22; 詩篇 23:4; 約伯記 28:3"> <span className="pl pl-1">願黑暗和死蔭索取那日，</span><br /><span className="pl pl-1">願密雲停在其上，</span><br /><span className="pl pl-1">願日食恐嚇它。</span><br /></span>
<span className="v" id="v6" data-v="6"> <span className="pl pl-1">願那夜被幽暗奪取，</span><br /><span className="pl pl-1">不在年中的日子同樂，</span><br /><span className="pl pl-1">也不入月中的數目。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 24:8; 耶利米書 7:34; 啟示錄 18:22–23"> <span className="pl pl-1">願那夜沒有生育，</span><br /><span className="pl pl-1">其間也沒有歡樂的聲音。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 41:1; 約伯記 41:10; 馬可福音 5:38"> <span className="pl pl-1">願那咒詛日子且能惹動鱷魚的，</span><br /><span className="pl pl-1">咒詛那夜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 41:18; 耶利米書 13:16; 約伯記 30:26"> <span className="pl pl-1">願那夜黎明的星宿變為黑暗，</span><br /><span className="pl pl-1">盼亮卻不亮，</span><br /><span className="pl pl-1">也不見早晨的光線</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「光線」原文作「眼皮」。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 20:17; 傳道書 6:3–5; 創世記 20:18"> <span className="pl pl-1">因沒有把懷我胎的門關閉，</span><br /><span className="pl pl-1">也沒有將患難對我的眼隱藏。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 10:18–19; 以賽亞書 46:3; 詩篇 71:6"> <span className="pl pl-1">我為何不出母胎而死？</span><br /><span className="pl pl-1">為何不出母腹絕氣？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 66:12; 創世記 30:3; 創世記 50:23"> <span className="pl pl-1">為何有膝接收我？</span><br /><span className="pl pl-1">為何有奶哺養我？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 9:10; 約伯記 21:13; 約伯記 14:10–12"> <span className="pl pl-1">不然，我就早已躺臥安睡，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 15:28; 詩篇 89:48; 詩篇 49:14"> <span className="pl pl-1">和地上為自己重造荒丘的君王、謀士，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 10:27; 約伯記 22:25; 西番雅書 1:18"> <span className="pl pl-1">或與有金子、將銀子裝滿了房屋的王子</span><br /><span className="pl pl-1">一同安息；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 58:8; 傳道書 6:3; 哥林多前書 15:8"> <span className="pl pl-1">或像隱而未現、不到期而落的胎，</span><br /><span className="pl pl-1">歸於無有，如同未見光的嬰孩。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 14:13; 約伯記 17:16; 希伯來書 4:11"> <span className="pl pl-1">在那裡，惡人止息攪擾，</span><br /><span className="pl pl-1">困乏人得享安息；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 39:7; 以賽亞書 14:3–4; 出埃及記 5:6–8"> <span className="pl pl-1">被囚的人同得安逸，</span><br /><span className="pl pl-1">不聽見督工的聲音。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 8:8; 約伯記 30:23; 傳道書 12:7"> <span className="pl pl-1">大小都在那裡，</span><br /><span className="pl pl-1">奴僕脫離主人的轄制。</span></span>

## 萬物可尋唯智非主莫賜

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 1:7; 瑪拉基書 3:2–3; 以賽亞書 48:10"> <span className="pl pl-1">「銀子有礦，</span><br /><span className="pl pl-1">煉金有方。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:9; 民數記 31:22; 創世記 4:22"> <span className="pl pl-1">鐵從地裡挖出，</span><br /><span className="pl pl-1">銅從石中熔化。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 1:13; 哈巴谷書 2:13; 馬太福音 6:33"> <span className="pl pl-1">人為黑暗定界限，</span><br /><span className="pl pl-1">查究幽暗陰翳的石頭，直到極處。</span><br /></span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">在無人居住之處刨開礦穴，</span><br /><span className="pl pl-1">過路的人也想不到他們，</span><br /><span className="pl pl-1">又與人遠離，懸在空中搖來搖去。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 28:25–29; 詩篇 104:14–15; 創世記 1:11–12"> <span className="pl pl-1">至於地，能出糧食，</span><br /><span className="pl pl-1">地內好像被火翻起來。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 28:16; 出埃及記 24:10; 以賽亞書 54:11"> <span className="pl pl-1">地中的石頭有藍寶石，</span><br /><span className="pl pl-1">並有金沙。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 11:6; 約伯記 28:21–23; 約伯記 38:24"> <span className="pl pl-1">礦中的路，鷙鳥不得知道，</span><br /><span className="pl pl-1">鷹眼也未見過；</span><br /></span>
<span className="v" id="v8" data-v="8"> <span className="pl pl-1">狂傲的野獸未曾行過，</span><br /><span className="pl pl-1">猛烈的獅子也未曾經過。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="那鴻書 1:4–6"> <span className="pl pl-1">人伸手鑿開堅石，</span><br /><span className="pl pl-1">傾倒山根。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哈巴谷書 3:9; 箴言 14:23; 箴言 24:4"> <span className="pl pl-1">在磐石中鑿出水道，</span><br /><span className="pl pl-1">親眼看見各樣寶物。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 4:5; 以賽亞書 45:2–3; 以賽亞書 44:27"> <span className="pl pl-1">他封閉水，不得滴流，</span><br /><span className="pl pl-1">使隱藏的物顯露出來。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="箴言 2:4–6; 約伯記 28:20; 雅各書 1:5"> <span className="pl pl-1">「然而，智慧有何處可尋？</span><br /><span className="pl pl-1">聰明之處在哪裡呢？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 8:11; 箴言 8:18–19; 箴言 3:14–15"> <span className="pl pl-1">智慧的價值無人能知，</span><br /><span className="pl pl-1">在活人之地也無處可尋。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 11:33–34"> <span className="pl pl-1">深淵說：『不在我內』，</span><br /><span className="pl pl-1">滄海說：『不在我中』。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 16:16; 箴言 8:10–11; 箴言 8:19"> <span className="pl pl-1">智慧非用黃金可得，</span><br /><span className="pl pl-1">也不能平白銀為它的價值。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 13:12; 以西結書 28:13; 詩篇 45:9"> <span className="pl pl-1">俄斐金和貴重的紅瑪瑙，</span><br /><span className="pl pl-1">並藍寶石，不足與較量。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 22:1; 啟示錄 4:6; 啟示錄 21:11"> <span className="pl pl-1">黃金和玻璃，不足與比較；</span><br /><span className="pl pl-1">精金的器皿，不足與兌換。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 3:15; 箴言 31:10; 耶利米哀歌 4:7"> <span className="pl pl-1">珊瑚、水晶都不足論，</span><br /><span className="pl pl-1">智慧的價值勝過珍珠</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：紅寶石。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 8:19; 出埃及記 39:10; 以西結書 28:13"> <span className="pl pl-1">古實的紅璧璽，不足與比較；</span><br /><span className="pl pl-1">精金，也不足與較量。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 28:12; 雅各書 1:5; 雅各書 1:17"> <span className="pl pl-1">智慧從何處來呢？</span><br /><span className="pl pl-1">聰明之處在哪裡呢？</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 49:3–4; 哥林多前書 2:7–10; 馬太福音 11:25"> <span className="pl pl-1">是向一切有生命的眼目隱藏，</span><br /><span className="pl pl-1">向空中的飛鳥掩蔽。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 83:10–12; 約伯記 26:6; 約伯記 28:14"> <span className="pl pl-1">滅沒和死亡說：</span><br /><span className="pl pl-1">『我們風聞其名。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="箴言 8:22–31; 哥林多前書 1:30; 猶大書 1:25"> <span className="pl pl-1">「神明白智慧的道路，</span><br /><span className="pl pl-1">曉得智慧的所在。</span><br /></span>

<span className="v" id="v25" data-v="25" data-xref="詩篇 135:7; 以賽亞書 40:12; 約伯記 12:15"> <span className="pl pl-1">要為風定輕重，</span><br /><span className="pl pl-1">又度量諸水。</span><br /></span>

<span className="v" id="v27" data-v="27" data-xref="詩篇 19:1; 箴言 8:22–29"> <span className="pl pl-1">那時他看見智慧，而且述說；</span><br /><span className="pl pl-1">他堅定，並且查究。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 111:10; 箴言 1:7; 箴言 9:10"> <span className="pl pl-1">他對人說：『敬畏主就是智慧，</span><br /><span className="pl pl-1">遠離惡便是聰明。』」</span></span>
</div>

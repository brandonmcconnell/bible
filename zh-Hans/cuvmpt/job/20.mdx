## 瑣法言惡者暫興終必滅亡

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約伯記 2:11; 約伯記 42:9; 約伯記 11:1"> 拿瑪人瑣法回答說：</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:29; 詩篇 31:22; 約伯記 20:3"> <span className="pl pl-1">「我心中急躁，</span><br /><span className="pl pl-1">所以我的思念叫我回答。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 33:3; 約伯記 20:2; 詩篇 78:2–5"> <span className="pl pl-1">我已聽見那羞辱我責備我的話，</span><br /><span className="pl pl-1">我的悟性叫我回答。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 9:1–3; 約伯記 15:10; 約伯記 32:7"> <span className="pl pl-1">你豈不知亙古以來，</span><br /><span className="pl pl-1">自從人生在地，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:35–36; 約伯記 18:5–6; 使徒行傳 12:22–23"> <span className="pl pl-1">惡人誇勝是暫時的，</span><br /><span className="pl pl-1">不敬虔人的喜樂不過轉眼之間嗎？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 14:13–14; 俄巴底亞書 1:3–4; 創世記 11:4"> <span className="pl pl-1">他的尊榮雖達到天上，</span><br /><span className="pl pl-1">頭雖頂到雲中，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 7:10; 列王紀上 14:10; 約伯記 4:20"> <span className="pl pl-1">他終必滅亡，像自己的糞一樣。</span><br /><span className="pl pl-1">素來見他的人要說：『他在哪裡呢？』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 90:5; 詩篇 73:20; 以賽亞書 29:7–8"> <span className="pl pl-1">他必飛去如夢，不再尋見；</span><br /><span className="pl pl-1">速被趕去，如夜間的異象。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 7:8; 約伯記 7:10; 約伯記 8:18"> <span className="pl pl-1">親眼見過他的，必不再見他；</span><br /><span className="pl pl-1">他的本處，也再見不著他。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 20:18; 路加福音 19:8; 約伯記 27:16–17"> <span className="pl pl-1">他的兒女要求窮人的恩，</span><br /><span className="pl pl-1">他的手要賠還不義之財。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 13:26; 詩篇 25:7; 約伯記 21:26"> <span className="pl pl-1">他的骨頭雖然有青年之力，</span><br /><span className="pl pl-1">卻要和他一同躺臥在塵土中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="約伯記 15:16; 詩篇 10:7; 傳道書 11:9"> <span className="pl pl-1">「他口內雖以惡為甘甜，</span><br /><span className="pl pl-1">藏在舌頭底下，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 9:43–49; 羅馬書 8:13; 馬太福音 5:29–30"> <span className="pl pl-1">愛戀不捨，含在口中；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 3:13; 詩篇 51:8–9; 詩篇 32:3–4"> <span className="pl pl-1">他的食物在肚裡卻要化為酸，</span><br /><span className="pl pl-1">在他裡面成為虺蛇的惡毒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 23:8; 馬太福音 27:3–4"> <span className="pl pl-1">他吞了財寶，還要吐出，</span><br /><span className="pl pl-1">神要從他腹中掏出來。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 28:3–6; 羅馬書 3:13; 申命記 32:24"> <span className="pl pl-1">他必吸飲虺蛇的毒氣，</span><br /><span className="pl pl-1">蝮蛇的舌頭也必殺他。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 32:13–14; 約伯記 29:6; 路加福音 16:24"> <span className="pl pl-1">流奶與蜜之河，</span><br /><span className="pl pl-1">他不得再見。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 20:10; 約伯記 20:15; 耶利米書 51:44"> <span className="pl pl-1">他勞碌得來的要賠還，不得享用</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：吞下。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">不能照所得的財貨歡樂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 35:9; 箴言 14:31; 雅各書 5:4"> <span className="pl pl-1">他欺壓窮人，且又離棄，</span><br /><span className="pl pl-1">強取非自己所蓋的房屋</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：強取房屋不得再建造。">b</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="傳道書 5:13–14; 以賽亞書 57:20–21"> <span className="pl pl-1">「他因貪而無厭，</span><br /><span className="pl pl-1">所喜悅的連一樣也不能保守。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 17:11; 約伯記 15:29; 路加福音 16:24–25"> <span className="pl pl-1">其餘的沒有一樣他不吞滅，</span><br /><span className="pl pl-1">所以他的福樂不能長久。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 15:29; 啟示錄 18:7; 列王紀下 24:2"> <span className="pl pl-1">他在滿足有餘的時候，必到狹窄的地步；</span><br /><span className="pl pl-1">凡受苦楚的人，都必加手在他身上。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 78:30–31; 民數記 11:33; 詩篇 11:6"> <span className="pl pl-1">他正要充滿肚腹的時候，</span><br /><span className="pl pl-1">神必將猛烈的憤怒降在他身上；</span><br /><span className="pl pl-1">正在他吃飯的時候，</span><br /><span className="pl pl-1">要將這憤怒像雨降在他身上。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 24:18; 阿摩司書 5:19; 撒母耳記下 22:35"> <span className="pl pl-1">他要躲避鐵器，</span><br /><span className="pl pl-1">銅弓的箭要將他射透。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 16:13; 約伯記 18:11; 申命記 32:41"> <span className="pl pl-1">他把箭一抽，就從他身上出來，</span><br /><span className="pl pl-1">發光的箭頭從他膽中出來，</span><br /><span className="pl pl-1">有驚惶臨在他身上。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 21:9; 詩篇 120:4; 以賽亞書 30:33"> <span className="pl pl-1">他的財寶歸於黑暗，</span><br /><span className="pl pl-1">人所不吹的火要把他燒滅，</span><br /><span className="pl pl-1">要把他帳篷中所剩下的燒毀。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 26:21; 路加福音 12:2–3; 約伯記 16:18"> <span className="pl pl-1">天要顯明他的罪孽，</span><br /><span className="pl pl-1">地要興起攻擊他。</span><br /></span>

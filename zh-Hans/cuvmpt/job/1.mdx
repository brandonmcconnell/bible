## 約伯之善行

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各書 5:11; 以西結書 14:14; 以西結書 14:20"> 烏斯地有一個人名叫約伯。那人完全、正直，敬畏神，遠離惡事。</span>
</div>
</div>

## 約伯之富有

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="詩篇 127:3–5; 約伯記 42:13; 詩篇 128:3"> 他生了七個兒子，三個女兒。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 29:25; 約伯記 42:12; 士師記 6:3"> 他的家產有七千羊，三千駱駝，五百對牛，五百母驢，並有許多僕婢。這人在東方人中就為至大。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 13:1; 詩篇 133:1"> 他的兒子按著日子各在自己家裡設擺筵宴，就打發人去，請了他們的三個姐妹來，與他們一同吃喝。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 42:8; 創世記 8:20; 撒母耳記上 16:5"> 筵宴的日子過了，約伯打發人去叫他們自潔。他清早起來，按著他們眾人的數目獻燔祭，因為他說：「恐怕我兒子犯了罪，心中棄掉神。」約伯常常這樣行。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約伯記 2:1; 約伯記 38:7; 撒迦利亞書 3:1"> 有一天，神的眾子來侍立在耶和華面前，撒旦也來在其中。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 5:8; 啟示錄 12:12–17; 馬太福音 12:43"> 耶和華問撒旦說：「你從哪裡來？」撒旦回答說：「我從地上走來走去，往返而來。」</span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 2:3; 約伯記 1:1; 民數記 12:7–8"> 耶和華問撒旦說：「你曾用心察看我的僕人約伯沒有？地上再沒有人像他完全、正直，敬畏神，遠離惡事。」</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 16:26; 提摩太前書 4:8; 約伯記 2:10"> 撒旦回答耶和華說：「約伯敬畏神，豈是無故呢？</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:7; 撒迦利亞書 2:5; 彼得前書 1:5"> 你豈不是四面圈上籬笆，圍護他和他的家並他一切所有的嗎？他手所做的都蒙你賜福，他的家產也在地上增多。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 2:5; 約伯記 19:21; 啟示錄 16:11"> 你且伸手毀他一切所有的，他必當面棄掉你。」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 22:31–32; 約翰福音 3:35–36; 哥林多後書 12:7"> 耶和華對撒旦說：「凡他所有的都在你手中，只是不可伸手加害於他。」於是撒旦從耶和華面前退去。</span>
</div>
</div>

## 約伯受試煉

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:34; 箴言 27:1; 約伯記 1:4"> 有一天，約伯的兒女正在他們長兄的家裡吃飯喝酒，</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 15:13; 耶利米書 51:31; 撒母耳記上 4:17"> 有報信的來見約伯說：「牛正耕地，驢在旁邊吃草，</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 10:7; 約伯記 6:19; 以賽亞書 45:14"> 示巴人忽然闖來，把牲畜擄去，並用刀殺了僕人，唯有我一人逃脫，來報信給你。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 1:12; 創世記 19:24; 列王紀上 18:38"> 他還說話的時候，又有人來說：「神從天上降下火來，將群羊和僕人都燒滅了，唯有我一人逃脫，來報信給你。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 11:28; 哈巴谷書 1:6; 創世記 11:31"> 他還說話的時候，又有人來說：「迦勒底人分做三隊忽然闖來，把駱駝擄去，並用刀殺了僕人，唯有我一人逃脫，來報信給你。」</span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 1:4; 約伯記 1:13; 約伯記 27:14"> 他還說話的時候，又有人來說：「你的兒女正在他們長兄的家裡吃飯喝酒，</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 42:36; 路加福音 13:1–5; 士師記 16:30"> 不料有狂風從曠野颳來，擊打房屋的四角，房屋倒塌在少年人身上，他們就都死了，唯有我一人逃脫，來報信給你。」</span>
</div>
</div>

## 約伯之忍耐

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="彼得前書 5:6; 撒母耳記下 12:16–20; 創世記 37:34"> 約伯便起來，撕裂外袍，剃了頭，伏在地上下拜，</span>
<span className="v" id="v21" data-v="21" data-xref="傳道書 5:15; 提摩太前書 6:7; 帖撒羅尼迦前書 5:18"> 說：「我赤身出於母胎，也必赤身歸回；賞賜的是耶和華，收取的也是耶和華。耶和華的名是應當稱頌的！」</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 1:12; 約伯記 2:10; 彼得前書 1:7"> 在這一切的事上約伯並不犯罪，也不以神為愚妄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：也不妄評神。">a</a></sup>。</span>
</div>

## 以利戶怒約伯自義並怒其三友

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約伯記 10:7; 約伯記 33:9; 約伯記 10:2"> 於是這三個人，因約伯自以為義就不再回答他。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 22:21; 約伯記 40:8; 約伯記 27:2"> 那時有布西人蘭族巴拉迦的兒子以利戶向約伯發怒，因約伯自以為義，不以神為義。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 8:6; 約伯記 24:25; 約伯記 22:5–30"> 他又向約伯的三個朋友發怒，因為他們想不出回答的話來，仍以約伯為有罪。</span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 32:11–12; 箴言 18:13"> 以利戶要與約伯說話，就等候他們，因為他們比自己年老。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 32:2; 出埃及記 32:19"> 以利戶見這三個人口中無話回答，就怒氣發作。</span>
</div>
</div>

## 以利戶陳述己意

<div className="bt">
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="約伯記 15:10; 提摩太前書 5:1; 提多書 2:6"> 布西人巴拉迦的兒子以利戶回答說：<br /><span className="pl pl-1">「我年輕，你們老邁，</span><br /><span className="pl pl-1">因此我退讓，不敢向你們陳說我的意見。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 16:31; 約伯記 12:12; 希伯來書 5:12"> <span className="pl pl-1">我說，年老的當先說話，</span><br /><span className="pl pl-1">壽高的當以智慧教訓人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 38:36; 約伯記 33:4; 提摩太後書 3:16"> <span className="pl pl-1">但在人裡面有靈，</span><br /><span className="pl pl-1">全能者的氣使人有聰明。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:25; 約伯記 12:20; 傳道書 4:13"> <span className="pl pl-1">尊貴的不都有智慧，</span><br /><span className="pl pl-1">壽高的不都能明白公平。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:25; 哥林多前書 7:40"> <span className="pl pl-1">因此我說，你們要聽我言，</span><br /><span className="pl pl-1">我也要陳說我的意見。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="約伯記 29:21; 約伯記 5:27; 箴言 28:11"> <span className="pl pl-1">「你們查究所要說的話，</span><br /><span className="pl pl-1">那時我等候你們的話，</span><br /><span className="pl pl-1">側耳聽你們的辯論，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 32:3; 提摩太前書 1:7"> <span className="pl pl-1">留心聽你們。</span><br /><span className="pl pl-1">誰知你們中間無一人折服約伯，</span><br /><span className="pl pl-1">駁倒他的話。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 9:23; 哥林多前書 1:27–29; 哥林多前書 3:18"> <span className="pl pl-1">你們切不可說：『我們尋得智慧，</span><br /><span className="pl pl-1">神能勝他，人卻不能。』</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">約伯沒有向我爭辯，</span><br /><span className="pl pl-1">我也不用你們的話回答他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="約伯記 6:24–25; 馬太福音 22:46; 約伯記 29:22"> <span className="pl pl-1">「他們驚奇，不再回答，</span><br /><span className="pl pl-1">一言不發。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 1:19; 約伯記 13:5; 阿摩司書 5:13"> <span className="pl pl-1">我豈因他們不說話，</span><br /><span className="pl pl-1">站住不再回答，仍舊等候呢？</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 35:3–4; 約伯記 33:12; 約伯記 32:10"> <span className="pl pl-1">我也要回答我的一份話，</span><br /><span className="pl pl-1">陳說我的意見。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:3; 使徒行傳 4:20; 哥林多後書 5:13–14"> <span className="pl pl-1">因為我的言語滿懷，</span><br /><span className="pl pl-1">我裡面的靈激動我。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 9:17"> <span className="pl pl-1">我的胸懷如盛酒之囊，沒有出氣之縫，</span><br /><span className="pl pl-1">又如新皮袋快要破裂。</span><br /></span>

<span className="v" id="v21" data-v="21" data-xref="利未記 19:15; 約伯記 13:8; 馬太福音 22:16"> <span className="pl pl-1">我必不看人的情面，</span><br /><span className="pl pl-1">也不奉承人。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 12:2–3; 帖撒羅尼迦前書 2:5; 箴言 29:5"> <span className="pl pl-1">我不曉得奉承，</span><br /><span className="pl pl-1">若奉承，造我的主必快快除滅我。</span></span>
</div>

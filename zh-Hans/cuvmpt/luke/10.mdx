## 主差遣七十人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 6:7–13; 路加福音 9:52; 民數記 11:24–26"> 這事以後，主又設立七十個人，差遣他們兩個兩個地在他前面，往自己所要到的各城各地方去。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:36–38; 約翰福音 4:35–38; 哥林多前書 3:6–9"> 就對他們說：<span className="woj">「要收的莊稼多，做工的人少。所以，你們當求莊稼的主，打發工人出去收他的莊稼。</span></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 10:16; 使徒行傳 20:29; 以西結書 2:3–6"> <span className="woj">你們去吧！我差你們出去，如同羊羔進入狼群。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:35; 列王紀下 4:29; 路加福音 10:4–12"> <span className="woj">不要帶錢囊，不要帶口袋，不要帶鞋，在路上也不要問人的安。</span></span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 25:6; 馬太福音 10:12–13; 以賽亞書 57:19"> <span className="woj">無論進哪一家，先要說：『願這一家平安！』</span></span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:16; 哥林多後書 2:15–16; 以弗所書 5:6"> <span className="woj">那裡若有當得平安的人</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「當得平安的人」原文作「平安之子」。">a</a></sup><span className="woj">，你們所求的平安就必臨到那家；不然，就歸於你們了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 5:17–18; 馬太福音 10:10–11; 加拉太書 6:6"> <span className="woj">你們要住在那家，吃喝他們所供給的，因為工人得工價是應當的。不要從這家搬到那家。</span></span>
</div>
</div>

## 傳神的國臨近

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:27; 馬太福音 10:40; 路加福音 10:10"> <span className="woj">「無論進哪一城，人若接待你們，給你們擺上什麼，你們就吃什麼。</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 3:2; 約翰福音 3:5; 路加福音 10:11"> <span className="woj">要醫治那城裡的病人，對他們說：『神的國臨近你們了。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 18:6; 馬太福音 10:14; 使徒行傳 13:51"> <span className="woj">無論進哪一城，人若不接待你們，你們就到街上去，</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:9; 使徒行傳 13:51; 使徒行傳 13:26"> <span className="woj">說：『就是你們城裡的塵土粘在我們的腳上，我們也當著你們擦去。雖然如此，你們該知道神的國臨近了。』</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 10:15; 馬太福音 11:24; 耶利米哀歌 4:6"> <span className="woj">我告訴你們：當審判的日子，所多瑪所受的比那城還容易受呢！</span></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 23:1–18; 約珥書 3:4–8; 以西結書 26:1–26"> <span className="woj">哥拉汛哪，你有禍了！伯賽大啊，你有禍了！因為在你們中間所行的異能，若行在推羅、西頓，他們早已披麻蒙灰、坐在地上悔改了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 15:22–25; 羅馬書 2:1; 路加福音 12:47–48"> <span className="woj">當審判的日子，推羅、西頓所受的比你們還容易受呢！</span></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 14:13–15; 馬太福音 4:13; 路加福音 13:28"> <span className="woj">迦百農啊，你已經升到天上，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：你將要升到天上嗎？">b</a></sup><span className="woj">將來必推下陰間！」</span></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 13:20; 馬太福音 10:40; 帖撒羅尼迦前書 4:8"> 又對門徒說：<span className="woj">「聽從你們的，就是聽從我；棄絕你們的，就是棄絕我；棄絕我的，就是棄絕那差我來的。」</span></span>
</div>
</div>

## 七十人回來

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:20; 馬可福音 16:17; 路加福音 9:1"> 那七十個人歡歡喜喜地回來，說：「主啊，因你的名，就是鬼也服了我們！」</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 12:7–9; 以賽亞書 14:12; 啟示錄 9:1"> 耶穌對他們說：<span className="woj">「我曾看見撒旦從天上墜落，像閃電一樣。</span></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:13; 馬可福音 16:18; 羅馬書 16:20"> <span className="woj">我已經給你們權柄可以踐踏蛇和蠍子，又勝過仇敵一切的能力，斷沒有什麼能害你們。</span></span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 20:15; 啟示錄 20:12; 希伯來書 12:23"> <span className="woj">然而，不要因鬼服了你們就歡喜，要因你們的名記錄在天上歡喜。」</span></span>
</div>
</div>

## 耶穌歡樂

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 4:3; 馬太福音 13:11–16; 馬太福音 11:25–27"> 正當那時，耶穌被聖靈感動就歡樂，說：<span className="woj">「父啊，天地的主，我感謝你！因為你將這些事向聰明通達人就藏起來，向嬰孩就顯出來。父啊，是的，因為你的美意本是如此。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:27; 約翰福音 1:18; 約翰福音 6:44–46"> <span className="woj">一切所有的，都是我父交付我的。除了父，沒有人知道子是誰；除了子和子所願意指示的，沒有人知道父是誰。」</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:16–17"> 耶穌轉身暗暗地對門徒說：<span className="woj">「看見你們所看見的，那眼睛就有福了！</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 8:56; 希伯來書 11:13; 彼得前書 1:10–12"> <span className="woj">我告訴你們：從前有許多先知和君王要看你們所看的，卻沒有看見；要聽你們所聽的，卻沒有聽見。」</span></span>
</div>
</div>

## 撒馬利亞人憐愛受傷的

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 22:34–39; 路加福音 18:18; 馬太福音 19:16–19"> 有一個律法師起來試探耶穌，說：「夫子，我該做什麼才可以承受永生？」</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 10:5; 以賽亞書 8:20; 加拉太書 3:21–22"> 耶穌對他說：<span className="woj">「律法上寫的是什麼？你念的是怎樣呢？」</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 12:30–31; 馬太福音 22:37–40; 申命記 6:5"> 他回答說：「你要盡心、盡性、盡力、盡意愛主你的神，又要愛鄰舍如同自己。」</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 20:11; 利未記 18:5; 馬太福音 19:17"> 耶穌說：<span className="woj">「你回答的是。你這樣行，就必得永生。」</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 16:15; 羅馬書 4:2; 利未記 19:34"> 那人要顯明自己有理，就對耶穌說：「誰是我的鄰舍呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 88:4; 路加福音 18:31; 耶利米哀歌 2:12"> 耶穌回答說：<span className="woj">「有一個人從耶路撒冷下耶利哥去，落在強盜手中。他們剝去他的衣裳，把他打個半死，就丟下他走了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 3:16–18; 詩篇 69:20; 耶利米書 5:31"> <span className="woj">偶然有一個祭司從這條路下來，看見他，就從那邊過去了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行傳 18:17; 詩篇 109:25"> <span className="woj">又有一個利未人來到這地方，看見他，也照樣從那邊過去了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 8:50; 耶利米書 38:7–13; 路加福音 7:13"> <span className="woj">唯有一個撒馬利亞人行路來到那裡，看見他，就動了慈心，</span></span>
<span className="v" id="v34" data-v="34" data-xref="羅馬書 12:20; 詩篇 147:3; 帖撒羅尼迦前書 5:15"> <span className="woj">上前用油和酒倒在他的傷處，包裹好了，扶他騎上自己的牲口，帶到店裡去照應他。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; 路加福音 14:13; 羅馬書 16:23"> <span className="woj">第二天拿出二錢銀子來，交給店主說：『你且照應他，此外所費用的，我回來必還你。』</span></span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 7:42; 馬太福音 21:28–31; 馬太福音 17:25"> <span className="woj">你想，這三個人哪一個是落在強盜手中的鄰舍呢？」</span></span>
<span className="v" id="v37" data-v="37" data-xref="約翰一書 3:16–18; 彌迦書 6:8; 彼得前書 2:21"> 他說：「是憐憫他的。」耶穌說：<span className="woj">「你去照樣行吧。」</span></span>
</div>
</div>

## 馬大為事忙亂

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:19–20; 約翰福音 11:1–5; 約翰福音 12:1–3"> 他們走路的時候，耶穌進了一個村莊。有一個女人名叫馬大，接他到自己家裡。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; 路加福音 8:35; 約翰福音 12:3"> 她有一個妹子名叫馬利亞，在耶穌腳前坐著聽他的道。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 6:27; 路加福音 12:29; 馬太福音 14:15"> 馬大伺候的事多，心裡忙亂，就進前來說：「主啊，我的妹子留下我一個人伺候，你不在意嗎？請吩咐她來幫助我。」</span>
<span className="v" id="v41" data-v="41" data-xref="腓立比書 4:6; 路加福音 21:34; 馬太福音 6:25–34"> 耶穌回答說：<span className="woj">「馬大，馬大，你為許多的事思慮煩擾，</span></span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 27:4; 詩篇 16:5–6; 約翰福音 10:27–28"> <span className="woj">但是不可少的只有一件。馬利亞已經選擇那上好的福分，是不能奪去的。」</span></span>
</div>

## 施洗約翰在曠野傳道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:24; 創世記 49:10; 路加福音 9:7"> 凱撒提庇留在位第十五年，本丟·彼拉多做猶太巡撫，希律做加利利分封的王，他的兄弟腓力做以土利亞和特拉可尼地方分封的王，呂撒聶做亞比利尼分封的王，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:6; 約翰福音 18:24; 路加福音 1:80"> 亞那和該亞法做大祭司。那時，撒迦利亞的兒子約翰在曠野裡，神的話臨到他。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:77; 馬太福音 3:5–6; 使徒行傳 13:24"> 他就來到約旦河一帶地方，宣講悔改的洗禮，使罪得赦。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 40:3–5; 約翰福音 1:23; 路加福音 1:76–79"> 正如先知以賽亞書上所記的話說：<br /><span className="pl pl-1">「在曠野有人聲喊著說：</span><br /><span className="pl pl-1">『預備主的道，</span><br /><span className="pl pl-1">修直他的路！</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 40:4; 以賽亞書 42:16; 以賽亞書 45:2"> <span className="pl pl-1">一切山窪都要填滿，</span><br /><span className="pl pl-1">大小山岡都要削平，</span><br /><span className="pl pl-1">彎彎曲曲的地方要改為正直，</span><br /><span className="pl pl-1">高高低低的道路要改為平坦。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 52:10; 以賽亞書 40:5; 詩篇 98:2–3"> <span className="pl pl-1">凡有血氣的，都要見神的救恩。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 23:33; 馬太福音 12:34; 帖撒羅尼迦前書 1:10"> 約翰對那出來要受他洗的眾人說：「毒蛇的種類！誰指示你們逃避將來的憤怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 18:27–31; 使徒行傳 26:20; 以賽亞書 1:16–18"> 你們要結出果子來，與悔改的心相稱！不要自己心裡說：『有亞伯拉罕為我們的祖宗。』我告訴你們，神能從這些石頭中給亞伯拉罕興起子孫來。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 7:19; 約翰福音 15:6; 路加福音 13:9"> 現在斧子已經放在樹根上，凡不結好果子的樹就砍下來，丟在火裡。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:37; 路加福音 3:14; 使徒行傳 16:30"> 眾人問他說：「這樣，我們當做什麼呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 58:7–11; 約翰一書 3:17; 提摩太前書 6:18"> 約翰回答說：「有兩件衣裳的，就分給那沒有的，有食物的也當這樣行。」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 7:29; 路加福音 15:1–2; 路加福音 18:13"> 又有稅吏來要受洗，問他說：「夫子，我們當做什麼呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:8; 以弗所書 4:28; 哥林多前書 6:10"> 約翰說：「除了例定的數目，不要多取。」</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:5–6; 出埃及記 20:16; 出埃及記 23:1"> 又有兵丁問他說：「我們當做什麼呢？」約翰說：「不要以強暴待人，也不要訛詐人，自己有錢糧就當知足。」</span>
</div>
</div>

## 必有聖靈與火的洗

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 10:24; 約翰福音 3:28–29; 約翰福音 1:19–28"> 百姓指望基督來的時候，人都心裡猜疑或者約翰是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 3:11; 使徒行傳 1:5; 使徒行傳 11:15–16"> 約翰說：「我是用水給你們施洗。但有一位能力比我更大的要來，我就是給他解鞋帶也不配，他要用聖靈與火給你們施洗。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 15:7; 馬太福音 13:30; 彌迦書 4:12"> 他手裡拿著簸箕，要揚淨他的場，把麥子收在倉裡，把糠用不滅的火燒盡了。」</span>
</div>
</div>

## 約翰責備希律被囚

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:29–36; 約翰福音 1:34; 約翰福音 1:29"> 約翰又用許多別的話勸百姓，向他們傳福音。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:1; 馬太福音 11:2; 馬可福音 6:17–18"> 只是分封的王希律因他兄弟之妻希羅底的緣故，並因他所行的一切惡事，受了約翰的責備，</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 24:17–22; 約翰福音 3:24; 帖撒羅尼迦前書 2:15–16"> 又另外添了一件，就是把約翰收在監裡。</span>
</div>

## 耶穌受洗

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 1:32–34; 馬太福音 3:13–17; 約翰福音 12:27–28"> 眾百姓都受了洗，耶穌也受了洗，正禱告的時候天就開了，</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 2:7; 彼得後書 1:17–18; 約翰福音 1:32"> 聖靈降臨在他身上，形狀彷彿鴿子；又有聲音從天上來說：「你是我的愛子，我喜悅你。」</span>
</div>

## 耶穌的家譜

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 4:22; 馬太福音 13:55; 民數記 4:3"> 耶穌開頭傳道，年紀約有三十歲。依人看來，他是約瑟的兒子，約瑟是希里的兒子，</span>
<span className="v" id="v24" data-v="24"> 希里是瑪塔的兒子，瑪塔是利未的兒子，利未是麥基的兒子，麥基是雅拿的兒子，雅拿是約瑟的兒子，</span>
<span className="v" id="v25" data-v="25"> 約瑟是瑪他提亞的兒子，瑪他提亞是亞摩斯的兒子，亞摩斯是拿鴻的兒子，拿鴻是以斯利的兒子，以斯利是拿該的兒子，</span>
<span className="v" id="v26" data-v="26"> 拿該是瑪押的兒子，瑪押是瑪他提亞的兒子，瑪他提亞是西美的兒子，西美是約瑟的兒子，約瑟是猶大的兒子，猶大是約亞拿的兒子，</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 1:12"> 約亞拿是利撒的兒子，利撒是所羅巴伯的兒子，所羅巴伯是撒拉鐵的兒子，撒拉鐵是尼利的兒子，尼利是麥基的兒子，</span>
<span className="v" id="v28" data-v="28"> 麥基是亞底的兒子，亞底是哥桑的兒子，哥桑是以摩當的兒子，以摩當是珥的兒子，珥是約細的兒子，</span>
<span className="v" id="v29" data-v="29"> 約細是以利以謝的兒子，以利以謝是約令的兒子，約令是瑪塔的兒子，瑪塔是利未的兒子，</span>
<span className="v" id="v30" data-v="30"> 利未是西緬的兒子，西緬是猶大的兒子，猶大是約瑟的兒子，約瑟是約南的兒子，約南是以利亞敬的兒子，</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 3:5; 撒母耳記下 5:14; 撒迦利亞書 12:12"> 以利亞敬是米利亞的兒子，米利亞是買南的兒子，買南是瑪達他的兒子，瑪達他是拿單的兒子，拿單是大衛的兒子，</span>
<span className="v" id="v32" data-v="32" data-xref="路得記 4:18–22; 馬太福音 1:3–6; 以賽亞書 11:1–2"> 大衛是耶西的兒子，耶西是俄備得的兒子，俄備得是波阿斯的兒子，波阿斯是撒門的兒子，撒門是拿順的兒子，</span>
<span className="v" id="v33" data-v="33" data-xref="路得記 4:19–20; 創世記 49:8; 創世記 38:29"> 拿順是亞米拿達的兒子，亞米拿達是亞蘭的兒子，亞蘭是希斯崙的兒子，希斯崙是法勒斯的兒子，法勒斯是猶大的兒子，</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 21:3; 約書亞記 24:2; 歷代志上 1:24–28"> 猶大是雅各的兒子，雅各是以撒的兒子，以撒是亞伯拉罕的兒子，亞伯拉罕是他拉的兒子，他拉是拿鶴的兒子，</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 11:12–21; 創世記 10:24–25"> 拿鶴是西鹿的兒子，西鹿是拉吳的兒子，拉吳是法勒的兒子，法勒是希伯的兒子，希伯是沙拉的兒子，</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 5:28–32; 創世記 10:21–22; 創世記 9:1"> 沙拉是該南的兒子，該南是亞法撒的兒子，亞法撒是閃的兒子，閃是挪亞的兒子，挪亞是拉麥的兒子，</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 1:1–3; 創世記 5:6–28"> 拉麥是瑪土撒拉的兒子，瑪土撒拉是以諾的兒子，以諾是雅列的兒子，雅列是瑪勒列的兒子，瑪勒列是該南的兒子，該南是以挪士的兒子，</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 2:7; 以賽亞書 64:8; 哥林多前書 15:45"> 以挪士是塞特的兒子，塞特是亞當的兒子，亞當是神的兒子。</span>

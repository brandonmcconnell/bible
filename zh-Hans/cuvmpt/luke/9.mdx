## 差遣十二門徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 14:12; 路加福音 10:19; 馬太福音 16:19"> 耶穌叫齊了十二個門徒，給他們能力、權柄制伏一切的鬼，醫治各樣的病，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 10:7–8; 路加福音 10:9; 馬太福音 3:2"> 又差遣他們去宣傳神國的道、醫治病人，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 22:35; 詩篇 37:3; 路加福音 10:4–12"> 對他們說：<span className="woj">「行路的時候不要帶拐杖和口袋，不要帶食物和銀子，也不要帶兩件褂子。</span></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:11; 馬可福音 6:10; 路加福音 10:5–8"> <span className="woj">無論進哪一家，就住在那裡，也從那裡起行。</span></span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 13:51; 使徒行傳 18:6; 馬可福音 6:11"> <span className="woj">凡不接待你們的，你們離開那城的時候，要把腳上的塵土跺下去，見證他們的不是。」</span></span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 4:30; 馬可福音 16:20; 使徒行傳 5:15"> 門徒就出去，走遍各鄉宣傳福音，到處治病。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬可福音 6:14–28; 馬太福音 14:1–12; 路加福音 3:1"> 分封的王希律聽見耶穌所做的一切事，就游移不定，因為有人說是約翰從死裡復活，</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:21; 路加福音 9:19; 馬可福音 6:15"> 又有人說是以利亞顯現，還有人說是古時的一個先知又活了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 23:8; 路加福音 13:31–32"> 希律說：「約翰我已經斬了，這卻是什麼人，我竟聽見他這樣的事呢？」就想要見他。</span>
</div>
</div>

## 給五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 11:21; 希伯來書 13:17; 馬太福音 14:13–21"> 使徒回來，將所做的事告訴耶穌。耶穌就帶他們暗暗地離開那裡，往一座城去，那城名叫伯賽大。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:2; 路加福音 5:31; 希伯來書 4:16"> 但眾人知道了，就跟著他去。耶穌便接待他們，對他們講論神國的道，醫治那些需醫的人。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 6:1; 約翰福音 6:5–15; 何西阿書 13:5"> 日頭快要平西，十二個門徒來對他說：「請叫眾人散開，他們好往四面鄉村裡去借宿找吃的，因為我們這裡是野地。」</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 約翰福音 6:5–9; 列王紀下 4:42–43"> 耶穌說：<span className="woj">「你們給他們吃吧！」</span>門徒說：「我們不過有五個餅、兩條魚，若不去為這許多人買食物就不夠。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 8:6; 哥林多前書 14:40; 馬可福音 6:39–40"> 那時人數約有五千。耶穌對門徒說：<span className="woj">「叫他們一排一排地坐下，每排大約五十個人。」</span></span>
<span className="v" id="v15" data-v="15"> 門徒就如此行，叫眾人都坐下。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 14:19; 提摩太前書 4:4–5; 馬太福音 15:36"> 耶穌拿著這五個餅、兩條魚，望著天祝福，掰開，遞給門徒，擺在眾人面前。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 4:44; 馬太福音 15:37–38; 約翰福音 6:11–13"> 他們就吃，並且都吃飽了。把剩下的零碎收拾起來，裝滿了十二籃子。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 16:13–16; 路加福音 11:1; 馬太福音 26:36"> 耶穌自己禱告的時候，門徒也同他在那裡。耶穌問他們說：<span className="woj">「眾人說我是誰？」</span></span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 4:5; 路加福音 9:7–8; 馬太福音 14:2"> 他們說：「有人說是施洗的約翰，有人說是以利亞，還有人說是古時的一個先知又活了。」</span>

</div>

## 當背十架跟從主

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 10:38–39; 路加福音 14:26–27; 羅馬書 8:13"> 耶穌又對眾人說：<span className="woj">「若有人要跟從我，就當捨己，天天背起他的十字架來跟從我。</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:33; 約翰福音 12:25; 使徒行傳 20:23–24"> <span className="woj">因為凡要救自己生命</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「生命」或作「靈魂」，下同。">a</a></sup><span className="woj">的，必喪掉生命；凡為我喪掉生命的，必救了生命。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 8:36; 馬太福音 16:26; 詩篇 49:6–8"> <span className="woj">人若賺得全世界，卻喪了自己、賠上自己，有什麼益處呢？</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:32–33; 提摩太後書 2:12; 路加福音 12:8–9"> <span className="woj">凡把我和我的道當做可恥的，人子在自己的榮耀裡，並天父與聖天使的榮耀裡降臨的時候，也要把那人當做可恥的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:28; 馬可福音 9:1; 約翰福音 21:22–23"> <span className="woj">我實在告訴你們：站在這裡的，有人在沒嘗死味以前，必看見神的國。」</span></span>
</div>

## 改變相貌

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 17:1–13; 馬太福音 26:37–39; 馬可福音 14:33–36"> 說了這話以後約有八天，耶穌帶著彼得、約翰、雅各上山去禱告。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 17:2; 馬可福音 9:2–3; 出埃及記 34:29–35"> 正禱告的時候，他的面貌就改變了，衣服潔白放光。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 3:3–6; 哥林多後書 3:7–11; 路加福音 1:17"> 忽然，有摩西、以利亞兩個人同耶穌說話，</span>
<span className="v" id="v31" data-v="31" data-xref="腓立比書 3:21; 彼得前書 1:11–12; 彼得前書 5:10"> 他們在榮光裡顯現，談論耶穌去世的事，就是他在耶路撒冷將要成的事。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理書 8:18; 約翰福音 1:14; 但以理書 10:9"> 彼得和他的同伴都打盹，既清醒了，就看見耶穌的榮光，並同他站著的那兩個人。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 9:5–6; 馬可福音 10:38; 詩篇 4:6–7"> 二人正要和耶穌分離的時候，彼得對耶穌說：「夫子，我們在這裡真好！可以搭三座棚：一座為你，一座為摩西，一座為以利亞。」他卻不知道所說的是什麼。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 40:34–38; 馬太福音 17:5–7; 士師記 13:22"> 說這話的時候，有一朵雲彩來遮蓋他們。他們進入雲彩裡就懼怕。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 3:22; 使徒行傳 3:22–23; 馬太福音 3:17"> 有聲音從雲彩裡出來，說：「這是我的兒子，我所揀選的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷作：這是我的愛子。">b</a></sup>，你們要聽他！」</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 17:9; 馬可福音 9:9–10; 馬可福音 9:6"> 聲音住了，只見耶穌一人在那裡。當那些日子，門徒不提所看見的事，一樣也不告訴人。</span>
</div>
</div>

## 害癲癇病的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬太福音 17:14–20; 馬可福音 9:14–29"> 第二天，他們下了山，就有許多人迎見耶穌。</span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亞書 12:10; 約翰福音 4:47; 路加福音 7:12"> 其中有一人喊叫說：「夫子！求你看顧我的兒子，因為他是我的獨生子。</span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 9:20; 路加福音 8:29; 路加福音 4:35"> 他被鬼抓住就忽然喊叫，鬼又叫他抽風，口中流沫，並且重重地傷害他，難以離開他。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:1; 使徒行傳 19:13–16; 路加福音 10:17–19"> 我求過你的門徒把鬼趕出去，他們卻是不能。」</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 32:5; 羅馬書 2:4; 約翰福音 20:27"> 耶穌說：<span className="woj">「唉！這又不信又悖謬的世代啊，我在你們這裡，忍耐你們要到幾時呢？將你的兒子帶到這裡來吧！」</span></span>
<span className="v" id="v42" data-v="42" data-xref="馬可福音 9:26–27; 路加福音 7:15; 啟示錄 12:12"> 正來的時候，鬼把他摔倒，叫他重重地抽風。耶穌就斥責那汙鬼，把孩子治好了，交給他父親。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:43–45; 路加福音 5:26; 馬太福音 17:22"> 眾人都詫異神的大能<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「大能」或作「威榮」。">c</a></sup>。 人子將要被交<br />耶穌所做的一切事，眾人正稀奇的時候，耶穌對門徒說：</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 9:22; 使徒行傳 2:23; 路加福音 2:19"> <span className="woj">「你們要把這些話存在耳中，因為人子將要被交在人手裡。」</span></span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 18:34; 路加福音 2:50; 約翰福音 12:16"> 他們不明白這話，意思乃是隱藏的，叫他們不能明白，他們也不敢問這話的意思。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="馬太福音 18:1–5; 馬可福音 9:33–37; 馬太福音 20:20–22"> 門徒中間起了議論：誰將為大。</span>

## 撒馬利亞人不接待主

<div className="bp">

<span className="v" id="v52" data-v="52" data-xref="馬太福音 10:5; 路加福音 17:16; 路加福音 10:1"> 便打發使者在他前頭走。他們到了撒馬利亞的一個村莊，要為他預備。</span>
<span className="v" id="v53" data-v="53" data-xref="約翰福音 4:9; 約翰福音 4:40–42; 路加福音 9:48"> 那裡的人不接待他，因他面向耶路撒冷去。</span>
<span className="v" id="v54" data-v="54" data-xref="列王紀下 1:10–14; 雅各書 3:14–18; 雅各書 1:19–20"> 他的門徒雅各、約翰看見了，就說：「主啊，你要我們吩咐火從天上降下來燒滅他們，像以利亞所做的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古卷無「像以利亞所做的」數字。">d</a></sup>嗎？」</span>
<span className="v" id="v55" data-v="55" data-xref="啟示錄 3:19; 彼得前書 3:9; 耶利米書 17:9"> 耶穌轉身責備兩個門徒，說：<span className="woj">「你們的心如何，你們並不知道。</span></span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 20:28; 羅馬書 12:21; 約翰福音 3:17"> <span className="woj">人子來不是要滅人的性命</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「性命」或作「靈魂」，下同。">e</a></sup><span className="woj">，是要救人的性命。」說著就往別的村莊去了。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古卷只有55節首句，56節末句。">f</a></sup></span>

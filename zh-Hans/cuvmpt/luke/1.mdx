<span className="v" id="v3" data-v="3" data-xref="使徒行傳 1:1; 使徒行傳 26:25; 使徒行傳 11:4"> 這些事我既從起頭都詳細考察了，就定意要按著次序寫給你，</span>

## 預言施洗約翰的生

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:14; 歷代志上 24:19; 歷代志下 31:2"> 撒迦利亞按班次在神面前供祭司的職分，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 29:11; 出埃及記 30:7–8; 歷代志上 23:13"> 照祭司的規矩掣籤，得進主殿燒香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 16:17; 啟示錄 8:3; 希伯來書 4:14"> 燒香的時候，眾百姓在外面禱告。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:26–27; 使徒行傳 10:3–4; 士師記 13:3"> 有主的使者站在香壇的右邊向他顯現。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:22; 士師記 6:22; 路加福音 2:9–10"> 撒迦利亞看見，就驚慌害怕。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 2:21; 使徒行傳 10:31; 創世記 25:21"> 天使對他說：「撒迦利亞，不要害怕，因為你的祈禱已經被聽見了。你的妻子伊利莎白要給你生一個兒子，你要給他起名叫約翰。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 創世記 21:6"> 你必歡喜快樂，有許多人因他出世也必喜樂。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:5; 民數記 6:2–4; 路加福音 7:33"> 他在主面前將要為大，淡酒濃酒都不喝，從母腹裡就被聖靈充滿了。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 40:3–5; 馬太福音 21:32; 瑪拉基書 3:1"> 他要使許多以色列人回轉，歸於主他們的神。</span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 4:5–6; 馬太福音 11:14; 路加福音 1:76"> 他必有以利亞的心志能力，行在主的前面，叫為父的心轉向兒女，叫悖逆的人轉從義人的智慧，又為主預備合用的百姓。」</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 38:22; 創世記 17:17; 路加福音 1:7"> 撒迦利亞對天使說：「我憑著什麼可知道這事呢？我已經老了，我的妻子也年紀老邁了。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 馬太福音 18:10; 但以理書 9:21–23"> 天使回答說：「我是站在神面前的加百列，奉差而來對你說話，將這好信息報給你。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 3:26; 以西結書 24:27; 路加福音 1:22"> 到了時候，這話必然應驗。只因你不信，你必啞巴，不能說話，直到這事成就的日子。」</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 6:23–27"> 百姓等候撒迦利亞，詫異他許久在殿裡。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 約翰福音 13:24; 使徒行傳 21:40"> 及至他出來，不能和他們說話，他們就知道他在殿裡見了異象，因為他直向他們打手勢，竟成了啞巴。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 9:25; 列王紀下 11:5–7"> 他供職的日子已滿，就回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 這些日子以後，他的妻子伊利莎白懷了孕，就隱藏了五個月，</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 30:22–23; 以賽亞書 54:1–4; 創世記 21:1–2"> 說：「主在眷顧我的日子這樣看待我，要把我在人間的羞恥除掉。」</span>
</div>
</div>

## 加百列預言耶穌的生

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 2:23; 路加福音 1:19; 約翰福音 7:41"> 到了第六個月，天使加百列奉神的差遣往加利利的一座城去，這城名叫拿撒勒；</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 1:18; 以賽亞書 7:14; 馬太福音 1:16"> 到一個童女那裡，是已經許配大衛家的一個人，名叫約瑟，童女的名字叫馬利亞。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 6:12; 但以理書 10:19; 路加福音 1:30"> 天使進去，對她說：「蒙大恩的女子，我問你安，主和你同在了！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 10:17; 路加福音 1:12; 使徒行傳 10:4"> 馬利亞因這話就很驚慌，又反覆思想這樣問安是什麼意思。</span>

<span className="v" id="v34" data-v="34" data-xref="士師記 13:8–12; 使徒行傳 9:6"> 馬利亞對天使說：「我沒有出嫁，怎麼有這事呢？」</span>

<span className="v" id="v36" data-v="36"> 況且你的親戚伊利莎白，在年老的時候也懷了男胎，就是那素來稱為不生育的，現在有孕六個月了。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 19:26; 耶利米書 32:27; 馬可福音 10:27"> 因為出於神的話，沒有一句不帶能力的。」</span>
<span className="v" id="v38" data-v="38" data-xref="羅馬書 4:20–21; 詩篇 119:38; 詩篇 116:16"> 馬利亞說：「我是主的使女，情願照你的話成就在我身上！」天使就離開她去了。</span>
</div>
</div>

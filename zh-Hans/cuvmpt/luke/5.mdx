## 在革尼撒勒湖邊教訓人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 1:16–20; 馬太福音 4:18–22; 馬可福音 3:9"> 耶穌站在革尼撒勒湖邊，眾人擁擠他，要聽神的道。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 1:19; 馬太福音 4:21"> 他見有兩隻船灣在湖邊，打魚的人卻離開船洗網去了。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:18; 馬太福音 13:1–2; 約翰福音 1:41–42"> 有一隻船是西門的，耶穌就上去，請他把船撐開，稍微離岸，就坐下，從船上教訓眾人。</span>
</div>
</div>

## 打魚的將來得人

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 21:6; 馬太福音 17:27"> 講完了，對西門說：<span className="woj">「把船開到水深之處，下網打魚。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 2:5; 約翰福音 15:14; 路加福音 6:46–48"> 西門說：「夫子，我們整夜勞力，並沒有打著什麼，但依從你的話，我就下網。」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 15:58; 約翰福音 21:6–11; 傳道書 11:6"> 他們下了網，就圈住許多魚，網險些裂開，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 6:2; 腓立比書 4:3; 使徒行傳 11:25"> 便招呼那隻船上的同伴來幫助。他們就來，把魚裝滿了兩隻船，甚至船要沉下去。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 6:5; 約伯記 42:5–6; 啟示錄 1:17"> 西門彼得看見，就俯伏在耶穌膝前，說：「主啊！離開我，我是個罪人！」</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; 詩篇 8:8; 馬可福音 9:6"> 他和一切同在的人都驚訝這一網所打的魚。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:19; 馬太福音 13:47; 以西結書 47:9–10"> 他的夥伴西庇太的兒子雅各、約翰也是這樣。耶穌對西門說：<span className="woj">「不要怕，從今以後你要得人了。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 4:20; 路加福音 5:28; 馬太福音 19:27"> 他們把兩隻船攏了岸，就撇下所有的，跟從了耶穌。</span>
</div>
</div>

## 耶穌潔淨長大痲瘋的

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 50:15; 路加福音 17:16; 馬太福音 8:2–4"> 有一回，耶穌在一個城裡，有人滿身長了大痲瘋，看見他，就俯伏在地，求他說：「主若肯，必能叫我潔淨了。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 9:29–30; 約翰福音 4:50–53; 何西阿書 14:4"> 耶穌伸手摸他，說：<span className="woj">「我肯，你潔淨了吧！」</span>大痲瘋立刻就離了他的身。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 14:2–32; 路加福音 17:14; 馬可福音 1:44"> 耶穌囑咐他：<span className="woj">「你切不可告訴人，只要去把身體給祭司察看，又要為你得了潔淨，照摩西所吩咐的獻上禮物，對眾人做證據。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 15:30–31; 路加福音 12:1; 馬可福音 1:45–2"> 但耶穌的名聲越發傳揚出去，有極多的人聚集來聽道，也指望醫治他們的病。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 馬可福音 1:35–36; 馬太福音 14:23"> 耶穌卻退到曠野去禱告。</span>
</div>
</div>

## 醫治癱子

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 馬太福音 11:5"> 有一天，耶穌教訓人，有法利賽人和教法師在旁邊坐著，他們是從加利利各鄉村和猶太並耶路撒冷來的。主的能力與耶穌同在，使他能醫治病人。</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 2:3–12; 馬太福音 9:2–8; 約翰福音 5:5–6"> 有人用褥子抬著一個癱子，要抬進去放在耶穌面前，</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 2:4; 馬太福音 10:27; 馬太福音 24:17"> 卻因人多，尋不出法子抬進去，就上了房頂，從瓦間把他連褥子縋到當中，正在耶穌面前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 14:9; 馬太福音 9:2; 馬可福音 2:5"> 耶穌見他們的信心，就對癱子說：<span className="woj">「你的罪赦了！」</span></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 43:25; 馬可福音 2:6–7; 路加福音 7:49"> 文士和法利賽人就議論說：「這說僭妄話的是誰？除了神以外，誰能赦罪呢？」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; 以賽亞書 66:18; 詩篇 139:2"> 耶穌知道他們所議論的，就說：<span className="woj">「你們心裡議論的是什麼呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 2:9; 馬太福音 9:5"> <span className="woj">或說『你的罪赦了』，或說『你起來行走』，哪一樣容易呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 1:13; 以賽亞書 53:11; 路加福音 8:54"> <span className="woj">但要叫你們知道，人子在地上有赦罪的權柄。」</span>就對癱子說：<span className="woj">「我吩咐你，起來，拿你的褥子回家去吧！」</span></span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 9:24; 路加福音 5:13; 詩篇 107:20–22"> 那人當眾人面前立刻起來，拿著他所躺臥的褥子回家去，歸榮耀於神。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 9:8; 馬太福音 12:23; 路加福音 7:16"> 眾人都驚奇，也歸榮耀於神，並且滿心懼怕，說：「我們今日看見非常的事了！」</span>
</div>
</div>

## 利未被召

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬可福音 2:13–22; 馬太福音 9:9–17; 約翰福音 1:43"> 這事以後，耶穌出去，看見一個稅吏，名叫利未，坐在稅關上，就對他說：<span className="woj">「你跟從我來！」</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 馬太福音 19:22–27; 列王紀上 19:19–21"> 他就撇下所有的，起來跟從了耶穌。</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 2:15; 路加福音 15:1; 哥林多前書 10:27"> 利未在自己家裡為耶穌大擺筵席，有許多稅吏和別人與他們一同坐席。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 21:28–32; 路加福音 5:17; 馬可福音 7:3"> 法利賽人和文士就向耶穌的門徒發怨言說：「你們為什麼和稅吏並罪人一同吃喝呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 2:17; 馬太福音 9:12–13; 耶利米書 8:22"> 耶穌對他們說：<span className="woj">「無病的人用不著醫生，有病的人才用得著。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前書 1:15–16"> <span className="woj">我來本不是召義人悔改，乃是召罪人悔改。」</span></span>
</div>
</div>

## 論禁食

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 9:14–17; 馬可福音 2:18–22; 約翰福音 3:25"> 他們說：「約翰的門徒屢次禁食、祈禱，法利賽人的門徒也是這樣，唯獨你的門徒又吃又喝。」</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 3:29; 哥林多後書 11:2; 以賽亞書 54:5"> 耶穌對他們說：<span className="woj">「新郎和陪伴之人同在的時候，豈能叫陪伴之人禁食呢？</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行傳 14:23; 使徒行傳 3:21"> <span className="woj">但日子將到，新郎要離開他們，那日他們就要禁食了。」</span></span>
</div>
</div>

## 新舊難合的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬太福音 9:16–17; 馬可福音 2:21–22; 哥林多後書 6:16"> 耶穌又設一個比喻，對他們說：<span className="woj">「沒有人把新衣服撕下一塊來補在舊衣服上，若是這樣，就把新的撕破了，並且所撕下來的那塊新的和舊的也不相稱。</span></span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 9:13; 詩篇 119:83; 約書亞記 9:4"> <span className="woj">也沒有人把新酒裝在舊皮袋裡，若是這樣，新酒必將皮袋裂開，酒便漏出來，皮袋也就壞了。</span></span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 8:8–13; 哥林多後書 5:17; 以西結書 36:26"> <span className="woj">但新酒必須裝在新皮袋裡。</span></span>
<span className="v" id="v39" data-v="39" data-xref="希伯來書 11:39; 馬可福音 7:7–13; 耶利米書 6:16"> <span className="woj">沒有人喝了陳酒又想喝新的，他總說陳的好。」</span></span>
</div>
</div>

## 主稱讚寡婦的捐資

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 12:41–44; 約翰福音 8:20; 馬太福音 27:6"> 耶穌抬頭觀看，見財主把捐項投在庫裡，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 12:42"> 又見一個窮寡婦投了兩個小錢，</span>

## 預言聖殿被毀

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 2:20; 馬太福音 24:1–51; 馬可福音 13:1–37"> 有人談論聖殿是用美石和供物裝飾的，</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 24:2; 馬可福音 13:2; 耶利米哀歌 5:18"> 耶穌就說：<span className="woj">「論到你們所看見的這一切，將來日子到了，在這裡沒有一塊石頭留在石頭上不被拆毀了。」</span></span>
</div>
</div>

## 這些事的預兆

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 1:6–7; 馬可福音 13:14; 馬可福音 13:3–4"> 他們問他說：「夫子，什麼時候有這事呢？這事將到的時候有什麼預兆呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰一書 4:1; 馬可福音 13:5–6; 以弗所書 5:6"> 耶穌說：<span className="woj">「你們要謹慎，不要受迷惑。因為將來有好些人冒我的名來，說『我是基督』，又說『時候近了』。你們不要跟從他們！</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 馬太福音 24:6–8; 馬可福音 13:7–8"> <span className="woj">你們聽見打仗和擾亂的事，不要驚惶，因為這些事必須先有，只是末期不能立時就到。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:19–20; 馬可福音 13:8; 歷代志下 15:5–6"> 當時，耶穌對他們說：<span className="woj">「民要攻打民，國要攻打國，</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 24:29–30; 路加福音 21:25–27"> <span className="woj">地要大大震動，多處必有饑荒、瘟疫，又有可怕的異象和大神蹟從天上顯現。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:12–14; 使徒行傳 5:40; 使徒行傳 22:30"> <span className="woj">但這一切的事以先，人要下手拿住你們，逼迫你們，把你們交給會堂，並且收在監裡，又為我的名拉你們到君王諸侯面前。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 1:12; 腓立比書 1:28; 帖撒羅尼迦後書 1:5"> <span className="woj">但這些事終必為你們的見證。</span></span>
</div>
</div>

## 忍受艱難的必要得救

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 馬可福音 13:11; 馬太福音 10:19–20"> <span className="woj">「所以，你們當立定心意，不要預先思想怎樣分訴；</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:9; 以弗所書 6:19; 路加福音 12:12"> <span className="woj">因為我必賜你們口才、智慧，是你們一切敵人所敵不住、駁不倒的。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 啟示錄 6:9; 彌迦書 7:5–6"> <span className="woj">連你們的父母、弟兄、親族、朋友也要把你們交官，你們也有被他們害死的。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:19; 路加福音 6:22; 約翰福音 15:21"> <span className="woj">你們要為我的名被眾人恨惡，</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 10:30; 撒母耳記上 14:45; 路加福音 12:7"> <span className="woj">然而，你們連一根頭髮也必不損壞。</span></span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 10:36; 馬太福音 10:22; 雅各書 1:3"> <span className="woj">你們常存忍耐，就必保全靈魂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：必得生命。">a</a></sup><span className="woj">。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理書 9:27; 馬可福音 13:14"> <span className="woj">「你們看見耶路撒冷被兵圍困，就可知道它成荒場的日子近了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 6:1; 創世記 19:17; 路加福音 17:31–33"> <span className="woj">那時，在猶太的，應當逃到山上；在城裡的，應當出來；在鄉下的，不要進城。</span></span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 9:7; 以賽亞書 65:12–16; 以賽亞書 63:4"> <span className="woj">因為這是報應的日子，使經上所寫的都得應驗。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 13:17; 馬太福音 24:19; 路加福音 23:29"> <span className="woj">當那些日子，懷孕的和奶孩子的有禍了！因為將有大災難降在這地方，也有震怒臨到這百姓。</span></span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:25; 啟示錄 11:2; 以賽亞書 63:18"> <span className="woj">他們要倒在刀下，又被擄到各國去。耶路撒冷要被外邦人踐踏，直到外邦人的日期滿了。</span></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 13:10; 約珥書 2:30–31; 啟示錄 6:12–14"> <span className="woj">日、月、星辰要顯出異兆，地上的邦國也有困苦，因海中波浪的響聲就慌慌不定。</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 24:29; 申命記 28:65–67; 彼得後書 3:10–12"> <span className="woj">天勢都要震動，人想起那將要臨到世界的事，就都嚇得魂不附體。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 24:30; 啟示錄 1:7; 馬可福音 13:26"> <span className="woj">那時，他們要看見人子有能力、有大榮耀駕雲降臨。</span></span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 8:23; 以賽亞書 60:1–2; 以弗所書 4:30"> <span className="woj">一有這些事，你們就當挺身昂首，因為你們得贖的日子近了。」</span></span>
</div>
</div>

## 從無花果樹學比方

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 24:32–35; 馬可福音 13:28–30"> 耶穌又設比喻對他們說：<span className="woj">「你們看無花果樹和各樣的樹，它發芽的時候，你們一看見，自然曉得夏天近了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 5:9; 希伯來書 10:37; 彼得前書 4:7"> <span className="woj">這樣，你們看見這些事漸漸地成就，也該曉得神的國近了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 13:30; 馬太福音 24:34; 馬太福音 23:36"> <span className="woj">我實在告訴你們：這世代還沒有過去，這些事都要成就。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 40:8; 馬可福音 13:31; 馬太福音 24:35"> <span className="woj">天地要廢去，我的話卻不能廢去。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> <span className="woj">「你們要謹慎，恐怕因貪食、醉酒並今生的思慮累住你們的心，那日子就如同網羅忽然臨到你們，</span></span>
<span className="v" id="v35" data-v="35" data-xref="啟示錄 16:15; 詩篇 11:6; 耶利米書 48:43–44"> <span className="woj">因為那日子要這樣臨到全地上一切居住的人。</span></span>
<span className="v" id="v36" data-v="36" data-xref="約翰一書 2:28; 馬太福音 25:13; 彼得前書 5:8"> <span className="woj">你們要時時警醒，常常祈求，使你們能逃避這一切要來的事，得以站立在人子面前。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 馬可福音 11:19; 馬太福音 21:17"> 耶穌每日在殿裡教訓人，每夜出城在一座山——名叫橄欖山——住宿。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 8:1–2"> 眾百姓清早上聖殿，到耶穌那裡，要聽他講道。</span>
</div>

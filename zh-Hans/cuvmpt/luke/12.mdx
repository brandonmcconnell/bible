## 主警戒門徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:1; 哥林多前書 5:7–8; 雅各書 3:17"> 這時，有幾萬人聚集，甚至彼此踐踏。耶穌開講，先對門徒說：<span className="woj">「你們要防備法利賽人的酵，就是假冒為善。</span></span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 4:22; 路加福音 8:17; 哥林多後書 5:10"> <span className="woj">掩蓋的事沒有不露出來的，隱藏的事沒有不被人知道的。</span></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 10:27; 馬太福音 12:36; 傳道書 10:20"> <span className="woj">因此，你們在暗中所說的，將要在明處被人聽見；在內室附耳所說的，將要在房上被人宣揚。</span></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:28; 耶利米書 1:8; 啟示錄 2:10"> <span className="woj">我的朋友，我對你們說，那殺身體以後不能再做什麼的，不要怕他們。</span></span>
<span className="v" id="v5" data-v="5" data-xref="彼得後書 2:4; 馬太福音 10:28; 啟示錄 14:7"> <span className="woj">我要指示你們當怕的是誰，當怕那殺了以後又有權柄丟在地獄裡的。我實在告訴你們：正要怕他！</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:24; 詩篇 145:15–16; 詩篇 147:9"> <span className="woj">五個麻雀不是賣二分銀子嗎？但在神面前，一個也不忘記。</span></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:30–31; 馬太福音 6:26; 以賽亞書 43:3–4"> <span className="woj">就是你們的頭髮，也都被數過了。不要懼怕，你們比許多麻雀還貴重。</span></span>
</div>
</div>

## 褻瀆聖靈不得赦免

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="馬太福音 10:32–33; 約翰一書 2:23; 羅馬書 10:9–10"> <span className="woj">「我又告訴你們：凡在人面前認我的，人子在神的使者面前也必認他；</span></span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 2:12; 路加福音 9:26; 馬可福音 8:38"> <span className="woj">在人面前不認我的，人子在神的使者面前也必不認他。</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 12:31–32; 約翰一書 5:16; 提摩太前書 1:13"> <span className="woj">凡說話干犯人子的，還可得赦免；唯獨褻瀆聖靈的，總不得赦免。</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 10:17–20; 路加福音 21:12–14; 使徒行傳 4:5–7"> <span className="woj">人帶你們到會堂，並官府和有權柄的人面前，不要思慮怎麼分訴，說什麼話，</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 21:15; 馬太福音 10:20; 使徒行傳 4:8"> <span className="woj">因為正在那時候，聖靈要指教你們當說的話。」</span></span>
</div>
</div>

## 警戒貪心

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:45; 提摩太前書 6:5; 以西結書 33:31"> 眾人中有一個人對耶穌說：「夫子，請你吩咐我的兄長和我分開家業。」</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:3; 羅馬書 2:1; 羅馬書 9:20"> 耶穌說：<span className="woj">「你這個人！誰立我做你們斷事的官，給你們分家業呢？」</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:5; 提摩太前書 6:6–10; 詩篇 119:36–37"> 於是對眾人說：<span className="woj">「你們要謹慎自守，免去一切的貪心，因為人的生命不在乎家道豐富。」</span></span>
</div>
</div>

## 無知的財主

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 26:12–14; 何西阿書 2:8; 創世記 41:47–49"> 就用比喻對他們說：<span className="woj">「有一個財主田產豐盛，</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:42; 以賽亞書 58:7; 羅馬書 12:13"> <span className="woj">自己心裡思想說：『我的出產沒有地方收藏，怎麼辦呢？』</span></span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 3:15; 雅各書 4:15; 路加福音 12:21"> <span className="woj">又說：『我要這麼辦：要把我的倉房拆了，另蓋更大的，在那裡好收藏我一切的糧食和財物，</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 27:1; 雅各書 4:13–15; 哥林多前書 15:32"> <span className="woj">然後要對我的靈魂說：「靈魂哪，你有許多財物積存，可做多年的費用，只管安安逸逸地吃喝快樂吧！」』</span></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 27:8; 耶利米書 17:11; 提摩太前書 6:7"> <span className="woj">神卻對他說：『無知的人哪，今夜必要你的靈魂，你所預備的要歸誰呢？』</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:19–20; 路加福音 12:33; 雅各書 2:5"> <span className="woj">凡為自己積財，在神面前卻不富足的，也是這樣。」</span></span>
</div>
</div>

## 勿慮衣食

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 6:25–34; 腓立比書 4:6; 希伯來書 13:5"> 耶穌又對門徒說：<span className="woj">「所以我告訴你們，不要為生命憂慮吃什麼，為身體憂慮穿什麼。</span></span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 2:6; 箴言 13:8; 約伯記 2:4"> <span className="woj">因為生命勝於飲食，身體勝於衣裳。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:31; 詩篇 147:9; 路加福音 12:7"> <span className="woj">你想烏鴉，也不種也不收，又沒有倉又沒有庫，神尚且養活牠，你們比飛鳥是何等地貴重呢！</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 6:27; 馬太福音 5:36; 路加福音 19:3"> <span className="woj">你們哪一個能用思慮使壽數多加一刻呢</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：使身量多加一肘呢。">a</a></sup><span className="woj">？</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 5:7; 詩篇 39:6; 傳道書 7:13"> <span className="woj">這最小的事你們尚且不能做，為什麼還憂慮其餘的事呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 6:28–30; 路加福音 12:24; 列王紀上 10:1–13"> <span className="woj">你想百合花怎麼長起來，它也不勞苦，也不紡線，然而我告訴你們：就是所羅門極榮華的時候，他所穿戴的還不如這花一朵呢！</span></span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 14:31; 以賽亞書 40:6; 馬太福音 6:30"> <span className="woj">你們這小信的人哪！野地裡的草今天還在，明天就丟在爐裡，神還給它這樣的裝飾，何況你們呢！</span></span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 6:31; 路加福音 12:22; 路加福音 22:35"> <span className="woj">你們不要求吃什麼、喝什麼，也不要掛心。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 6:32; 馬太福音 6:8; 以弗所書 4:17"> <span className="woj">這都是外邦人所求的。你們必須用這些東西，你們的父是知道的。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 6:33; 希伯來書 13:5; 詩篇 34:9"> <span className="woj">你們只要求他的國，這些東西就必加給你們了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 12:28; 彼得前書 1:3–5; 啟示錄 1:6"> <span className="woj">你們這小群，不要懼怕，因為你們的父樂意把國賜給你們。</span></span>
</div>
</div>

## 論真財寶

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 19:21; 使徒行傳 4:34–35; 使徒行傳 2:45"> <span className="woj">「你們要變賣所有的賙濟人，為自己預備永不壞的錢囊、用不盡的財寶在天上，就是賊不能近、蟲不能蛀的地方。</span></span>
<span className="v" id="v34" data-v="34" data-xref="歌羅西書 3:1–3; 馬太福音 6:21; 腓立比書 3:20"> <span className="woj">因為你們的財寶在哪裡，你們的心也在哪裡。</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="彼得前書 1:13; 以弗所書 6:14; 馬太福音 25:4–10"> <span className="woj">「你們腰裡要束上帶，燈也要點著，</span></span>
<span className="v" id="v36" data-v="36" data-xref="猶大書 1:20–21; 雅各書 5:7–8; 啟示錄 3:20"> <span className="woj">自己好像僕人等候主人從婚姻的筵席上回來。他來到叩門，就立刻給他開門。</span></span>
<span className="v" id="v37" data-v="37" data-xref="彼得後書 3:14; 馬太福音 24:42; 約翰福音 13:4–5"> <span className="woj">主人來了，看見僕人警醒，那僕人就有福了。我實在告訴你們：主人必叫他們坐席，自己束上帶進前伺候他們。</span></span>
<span className="v" id="v38" data-v="38" data-xref="帖撒羅尼迦前書 5:4–5; 馬太福音 25:6"> <span className="woj">或是二更天來，或是三更天來，看見僕人這樣，那僕人就有福了。</span></span>

<span className="v" id="v40" data-v="40" data-xref="帖撒羅尼迦前書 5:6; 馬太福音 25:13; 羅馬書 13:11"> <span className="woj">你們也要預備，因為你們想不到的時候，人子就來了。」</span></span>
</div>
</div>

## 善僕與惡僕的報應

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="馬可福音 13:37; 彼得前書 4:7; 彼得前書 5:8"> 彼得說：「主啊，這比喻是為我們說的呢，還是為眾人呢？」</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 24:45–46; 彼得前書 5:1–4; 希伯來書 13:17"> 主說：<span className="woj">「誰是那忠心有見識的管家，主人派他管理家裡的人，按時分糧給他們呢？</span></span>
<span className="v" id="v43" data-v="43"> <span className="woj">主人來到，看見僕人這樣行，那僕人就有福了。</span></span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 22:29–30; 馬太福音 24:47; 路加福音 19:17–19"> <span className="woj">我實在告訴你們：主人要派他管理一切所有的。</span></span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 24:48–50; 啟示錄 18:7–8; 腓立比書 3:18–19"> <span className="woj">那僕人若心裡說『我的主人必來得遲』，就動手打僕人和使女，並且吃喝醉酒，</span></span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 12:40; 馬太福音 24:51; 詩篇 11:5"> <span className="woj">在他想不到的日子，不知道的時辰，那僕人的主人要來，重重地處治他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：把他腰斬了。">b</a></sup><span className="woj">，定他和不忠心的人同罪。</span></span>
<span className="v" id="v47" data-v="47" data-xref="雅各書 4:17; 約翰福音 9:41; 約翰福音 12:48"> <span className="woj">僕人知道主人的意思，卻不預備，又不順他的意思行，那僕人必多受責打。</span></span>
<span className="v" id="v48" data-v="48" data-xref="雅各書 3:1; 利未記 5:17; 路加福音 16:10–12"> <span className="woj">唯有那不知道的，做了當受責打的事，必少受責打</span>。<span className="woj">因為多給誰，就向誰多取；多託誰，就向誰多要。</span></span>
</div>
</div>

## 人子是安息日的主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; 馬可福音 2:23–28; 馬太福音 12:1–8"> 有一個安息日，耶穌從麥地經過。他的門徒掐了麥穗，用手搓著吃。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:2; 約翰福音 5:16; 約翰福音 5:9–11"> 有幾個法利賽人說：「你們為什麼做安息日不可做的事呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 21:3–6; 馬可福音 2:25–26; 馬太福音 12:3–5"> 耶穌對他們說：<span className="woj">「經上記著大衛和跟從他的人飢餓之時所做的事，連這個你們也沒有念過嗎？</span></span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:5–9"> <span className="woj">他怎麼進了神的殿，拿陳設餅吃，又給跟從的人吃？這餅除了祭司以外，別人都不可吃。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 2:27; 啟示錄 1:10; 馬可福音 9:7"> 又對他們說：<span className="woj">「人子是安息日的主。」</span></span>
</div>
</div>

## 在安息日治病

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 3:1–6; 馬太福音 12:9–14; 路加福音 4:31"> 又有一個安息日，耶穌進了會堂教訓人。在那裡有一個人右手枯乾了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; 詩篇 38:12; 路加福音 13:14"> 文士和法利賽人窺探耶穌在安息日治病不治病，要得把柄去告他。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 42:4; 馬太福音 9:4; 路加福音 5:22"> 耶穌卻知道他們的意念，就對那枯乾一隻手的人說：<span className="woj">「起來，站在當中！」</span>那人就起來站著。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 3:4; 馬太福音 12:12–13; 路加福音 14:3"> 耶穌對他們說：<span className="woj">「我問你們，在安息日行善、行惡，救命、害命，哪樣是可以的呢？」</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:6–7; 馬可福音 3:5; 約翰福音 5:8"> 他就周圍看著他們眾人，對那人說：<span className="woj">「伸出手來！」</span>他把手一伸，手就復了原。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:1–2; 使徒行傳 5:33; 傳道書 9:3"> 他們就滿心大怒，彼此商議怎樣處治耶穌。</span>
</div>
</div>

## 挑選十二門徒

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯來書 5:7; 馬可福音 6:46; 馬可福音 1:35"> 那時，耶穌出去上山禱告，整夜禱告神。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 3:13–19; 馬太福音 9:36–4; 啟示錄 21:14"> 到了天亮，叫他的門徒來，就從他們中間挑選十二個人，稱他們為使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 1:13; 馬太福音 4:21; 馬太福音 4:18"> 這十二個人有西門，耶穌又給他起名叫彼得，還有他兄弟安得烈，又有雅各和約翰，腓力和巴多羅買，</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 9:9; 馬可福音 3:18; 使徒行傳 1:13"> 馬太和多馬，亞勒腓的兒子雅各和奮銳黨的西門，</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:22; 約翰福音 6:70–71; 馬可福音 3:18"> 雅各的兒子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「兒子」或作「兄弟」。">a</a></sup>猶大和賣主的加略人猶大。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:21; 馬太福音 4:23–25; 詩篇 107:17–20"> 耶穌和他們下了山，站在一塊平地上。同站的有許多門徒，又有許多百姓，從猶太全地和耶路撒冷，並推羅、西頓的海邊來，都要聽他講道，又指望醫治他們的病。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 17:15; 馬太福音 15:22; 使徒行傳 5:16"> 還有被汙鬼纏磨的，也得了醫治。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 14:36; 馬可福音 3:10; 使徒行傳 5:15–16"> 眾人都想要摸他，因為有能力從他身上發出來，醫好了他們。</span>
</div>
</div>

## 論福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="雅各書 2:5; 路加福音 6:20–24; 哥林多後書 8:9"> 耶穌舉目看著門徒，說：<br /><span className="pl pl-1 woj">「你們貧窮的人有福了！</span><br /><span className="pl pl-1 woj">因為神的國是你們的。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 6:35; 馬太福音 5:6; 雅各書 1:12"> <span className="pl pl-1 woj">你們飢餓的人有福了！</span><br /><span className="pl pl-1 woj">因為你們將要飽足。</span><br /><span className="pl pl-1 woj">你們哀哭的人有福了！</span><br /><span className="pl pl-1 woj">因為你們將要喜笑。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 5:10–12; 馬太福音 10:22; 彼得前書 4:12–16"> <span className="woj">人為人子恨惡你們，拒絕你們，辱罵你們，棄掉你們的名以為是惡，你們就有福了！</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 5:41; 啟示錄 21:7; 啟示錄 3:12"> <span className="woj">當那日，你們要歡喜跳躍，因為你們在天上的賞賜是大的。他們的祖宗待先知也是這樣。</span></span>
</div>
</div>

## 論愛仇敵

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦前書 5:15; 路加福音 6:35; 羅馬書 12:17–21"> <span className="woj">「只是我告訴你們這聽道的人：你們的仇敵，要愛他；恨你們的，要待他好。</span></span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 3:9; 哥林多前書 4:12; 羅馬書 12:14"> <span className="woj">咒詛你們的，要為他祝福；凌辱你們的，要為他禱告。</span></span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 10:34; 馬太福音 5:39–42; 哥林多後書 11:20"> <span className="woj">有人打你這邊的臉，連那邊的臉也由他打；有人奪你的外衣，連裡衣也由他拿去。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 15:7–10; 哥林多後書 9:6–14; 馬太福音 6:12"> <span className="woj">凡求你的，就給他；有人奪你的東西去，不用再要回來。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 7:12; 加拉太書 5:14; 馬太福音 22:39"> <span className="woj">你們願意人怎樣待你們，你們也要怎樣待人。</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 5:46–47; 彼得前書 2:19–20"> <span className="woj">你們若單愛那愛你們的人，有什麼可酬謝的呢？就是罪人也愛那愛他們的人。</span></span>
<span className="v" id="v33" data-v="33"> <span className="woj">你們若善待那善待你們的人，有什麼可酬謝的呢？就是罪人也是這樣行。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> <span className="woj">你們若借給人，指望從他收回，有什麼可酬謝的呢？就是罪人也借給罪人，要如數收回。</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 5:44–45; 約翰福音 13:35; 箴言 19:17"> <span className="woj">你們倒要愛仇敵，也要善待他們，並要借給人不指望償還。你們的賞賜就必大了，你們也必做至高者的兒子，因為他恩待那忘恩的和作惡的。</span></span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 5:1–2; 馬太福音 5:48; 彼得前書 1:15–16"> <span className="woj">你們要慈悲，像你們的父慈悲一樣。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以弗所書 4:32; 雅各書 5:9; 馬太福音 7:1–5"> <span className="woj">你們不要論斷人，就不被論斷。你們不要定人的罪，就不被定罪。你們要饒恕人，就必蒙饒恕</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「饒恕」原文作「釋放」。">b</a></sup><span className="woj">。</span></span>
<span className="v" id="v38" data-v="38" data-xref="哥林多後書 9:6–8; 申命記 15:10; 馬可福音 4:24"> <span className="woj">你們要給人，就必有給你們的，並且用十足的升斗，連搖帶按、上尖下流地倒在你們懷裡。因為你們用什麼量器量給人，也必用什麼量器量給你們。」</span></span>
</div>
</div>

## 責人之心責己

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="馬太福音 15:14; 提摩太後書 3:13; 提摩太前書 6:3–5"> 耶穌又用比喻對他們說：<span className="woj">「瞎子豈能領瞎子？兩個人不是都要掉在坑裡嗎？</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 13:16; 馬太福音 10:24–25; 約翰福音 15:20"> <span className="woj">學生不能高過先生，凡學成了的不過和先生一樣。</span></span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 8:7; 雅各書 1:24; 羅馬書 2:1"> <span className="woj">為什麼看見你弟兄眼中有刺，卻不想自己眼中有梁木呢？</span></span>
<span className="v" id="v42" data-v="42" data-xref="羅馬書 2:21–29; 帖撒羅尼迦前書 2:10–12; 詩篇 51:9–13"> <span className="woj">你不見自己眼中有梁木，怎能對你弟兄說『容我去掉你眼中的刺』呢？你這假冒為善的人！先去掉自己眼中的梁木，然後才能看得清楚，去掉你弟兄眼中的刺。</span></span>
</div>
</div>

## 兩種果樹

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米書 2:21; 馬太福音 12:33; 馬太福音 7:16–20"> <span className="woj">「因為沒有好樹結壞果子，也沒有壞樹結好果子。</span></span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 12:33; 雅各書 3:12; 加拉太書 5:19–23"> <span className="woj">凡樹木看果子就可以認出它來。人不是從荊棘上摘無花果，也不是從蒺藜裡摘葡萄。</span></span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; 馬太福音 12:34–37; 以弗所書 4:29"> <span className="woj">善人從他心裡所存的善就發出善來，惡人從他心裡所存的惡就發出惡來；因為心裡所充滿的，口裡就說出來。</span></span>
</div>

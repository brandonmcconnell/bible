## 稅吏撒該

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 6:1–27; 路加福音 18:35; 列王紀下 2:18–22"> 耶穌進了耶利哥，正經過的時候，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 18:24–27; 歷代志下 17:5–6"> 有一個人名叫撒該，做稅吏長，是個財主，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:8; 路加福音 9:7–9; 約翰福音 12:21"> 他要看看耶穌是怎樣的人。只因人多，他的身量又矮，所以不得看見。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 9:10; 路加福音 5:19; 列王紀上 10:27"> 就跑到前頭，爬上桑樹，要看耶穌，因為耶穌必從那裡經過。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 3:20; 約翰福音 14:23; 希伯來書 13:2"> 耶穌到了那裡，抬頭一看，對他說：<span className="woj">「撒該，快下來！今天我必住在你家裡。」</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:29; 使徒行傳 16:34; 使徒行傳 16:15"> 他就急忙下來，歡歡喜喜地接待耶穌。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:2; 路加福音 7:39; 路加福音 7:34"> 眾人看見，都私下議論說：「他竟到罪人家裡去住宿！」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 12:6; 民數記 5:7; 路加福音 18:22–23"> 撒該站著對主說：「主啊，我把所有的一半給窮人，我若訛詐了誰，就還他四倍。」</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:7; 路加福音 13:16; 羅馬書 4:16"> 耶穌說：<span className="woj">「今天救恩到了這家，因為他也是亞伯拉罕的子孫。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 34:16; 馬太福音 1:21; 提摩太前書 1:13–16"> <span className="woj">人子來，為要尋找、拯救失喪的人。」</span></span>
</div>
</div>

## 交銀於十僕的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 17:20; 使徒行傳 1:6; 帖撒羅尼迦後書 2:1–3"> 眾人正在聽見這些話的時候，耶穌因為將近耶路撒冷，又因他們以為神的國快要顯出來，就另設一個比喻，說：</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:14–30; 路加福音 19:12–27; 路加福音 20:9"> <span className="woj">「有一個貴胄往遠方去，要得國回來。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 25:14–15; 約翰福音 12:26; 哥林多前書 12:7–11"> <span className="woj">便叫了他的十個僕人來，交給他們十錠</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「錠」原文作「彌拿」，一彌拿約銀十兩。">a</a></sup><span className="woj">銀子，說：『你們去做生意，直等我回來。』</span></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 8:7; 使徒行傳 7:51–52; 使徒行傳 3:14–15"> <span className="woj">他本國的人卻恨他，打發使者隨後去說：『我們不願意這個人做我們的王。』</span></span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 4:1–5; 羅馬書 14:10–12; 詩篇 2:4–6"> <span className="woj">他既得國回來，就吩咐叫那領銀子的僕人來，要知道他們做生意賺了多少。</span></span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 2:18–26; 提摩太後書 4:7–8; 哥林多前書 15:10"> <span className="woj">頭一個上來，說：『主啊，你的一錠銀子已經賺了十錠。』</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 16:10; 馬太福音 25:21; 啟示錄 2:26–29"> <span className="woj">主人說：『好，良善的僕人！你既在最小的事上有忠心，可以有權柄管十座城。』</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 4:20; 馬太福音 13:23; 哥林多後書 8:12"> <span className="woj">第二個來，說：『主啊，你的一錠銀子已經賺了五錠。』</span></span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 15:58; 哥林多前書 15:41–42; 哥林多前書 3:8"> <span className="woj">主人說：『你也可以管五座城。』</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 25:24; 箴言 26:13–16; 雅各書 4:17"> <span className="woj">又有一個來，說：『主啊，看哪，你的一錠銀子在這裡，我把它包在手巾裡存著。</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:24–25; 羅馬書 8:7; 約翰一書 4:18"> <span className="woj">我原是怕你，因為你是嚴厲的人，沒有放下的還要去拿，沒有種下的還要去收。』</span></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 1:16; 馬太福音 12:37; 約伯記 15:5–6"> <span className="woj">主人對他說：『你這惡僕！我要憑你的口定你的罪。你既知道我是嚴厲的人，沒有放下的還要去拿，沒有種下的還要去收，</span></span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 22:25–27; 羅馬書 2:4–5; 申命記 23:19–20"> <span className="woj">為什麼不把我的銀子交給銀行，等我來的時候，連本帶利都可以要回來呢？』</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 16:2; 路加福音 12:20"> <span className="woj">就對旁邊站著的人說：『奪過他這一錠來，給那有十錠的！』</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 16:2; 撒母耳記下 7:19; 以賽亞書 55:8–9"> <span className="woj">他們說：『主啊，他已經有十錠了。』</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰二書 1:8; 路加福音 8:18; 馬太福音 21:43"> <span className="woj">主人說：『我告訴你們：凡有的，還要加給他；沒有的，連他所有的也要奪過來。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:14; 詩篇 21:8–9; 馬太福音 22:7"> <span className="woj">至於我那些仇敵，不要我做他們王的，把他們拉來，在我面前殺了吧！』」</span></span>
</div>
</div>

## 主騎驢進耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:51; 希伯來書 12:2; 彼得前書 4:1"> 耶穌說完了這話，就在前面走，上耶路撒冷去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 1:12; 馬太福音 21:17; 馬太福音 21:1–11"> 將近伯法其和伯大尼，在一座山名叫橄欖山那裡，就打發兩個門徒，說：</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 22:8–13; 路加福音 19:32; 撒母耳記上 10:2–9"> <span className="woj">「你們往對面村子裡去，進去的時候，必看見一匹驢駒拴在那裡，是從來沒有人騎過的，可以解開牽來。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 24:1; 詩篇 50:10–12; 馬可福音 11:3–6"> <span className="woj">若有人問為什麼解牠，你們就說：『主要用牠。』」</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 22:13"> 打發的人去了，所遇見的正如耶穌所說的。</span>
<span className="v" id="v33" data-v="33"> 他們解驢駒的時候，主人問他們說：「解驢駒做什麼？」</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 9:9; 約翰福音 10:35; 哥林多後書 8:9"> 他們說：「主要用牠。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 11:7–8; 馬太福音 21:7; 約翰福音 12:14"> 他們牽到耶穌那裡，把自己的衣服搭在上面，扶著耶穌騎上。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 9:13; 馬太福音 21:8"> 走的時候，眾人把衣服鋪在路上。</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 12:12–13; 以斯拉記 3:10–13; 馬太福音 21:1"> 將近耶路撒冷，正下橄欖山的時候，眾門徒因所見過的一切異能都歡樂起來，大聲讚美神，</span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亞書 9:9; 路加福音 13:35; 詩篇 118:22–26"> 說：<br /><span className="pl pl-1">「奉主名來的王是應當稱頌的！</span><br /><span className="pl pl-1">在天上有和平，</span><br /><span className="pl pl-1">在至高之處有榮光！」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 4:1–2; 馬太福音 23:13; 使徒行傳 4:16–18"> 眾人中有幾個法利賽人對耶穌說：「夫子，責備你的門徒吧！」</span>
<span className="v" id="v40" data-v="40" data-xref="哈巴谷書 2:11; 以賽亞書 55:12; 馬太福音 3:9"> 耶穌說：<span className="woj">「我告訴你們，若是他們閉口不說，這些石頭必要呼叫起來！」</span></span>
</div>
</div>

## 為耶路撒冷哀哭

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 13:34–35; 約翰福音 11:35; 詩篇 119:136"> 耶穌快到耶路撒冷，看見城，就為它哀哭，</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 32:29; 希伯來書 10:26–29; 以賽亞書 48:18"> 說：<span className="woj">「巴不得你在這日子知道關係你平安的事，無奈這事現在是隱藏的，叫你的眼看不出來。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 21:20–24; 以賽亞書 29:1–4; 以西結書 4:2"> <span className="woj">因為日子將到，你的仇敵必築起土壘，周圍環繞你，四面困住你，</span></span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 21:6; 路加福音 13:34–35; 約翰福音 3:18–21"> <span className="woj">並要掃滅你和你裡頭的兒女，連一塊石頭也不留在石頭上，因你不知道眷顧你的時候。」</span></span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 21:12–13; 馬可福音 11:15–17; 約翰福音 2:13–17"> 耶穌進了殿，趕出裡頭做買賣的人，</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 56:7; 耶利米書 7:11; 詩篇 93:5"> 對他們說：<span className="woj">「經上說：</span><br /><span className="pl pl-1 woj">『我的殿必做禱告的殿』，</span><br /><span className="pl pl-1 woj">你們倒使它成為賊窩了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="馬可福音 11:18; 馬太福音 26:55; 馬可福音 11:27–33"> 耶穌天天在殿裡教訓人。祭司長和文士與百姓的尊長都想要殺他，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米記 8:3; 使徒行傳 16:14; 約翰福音 7:46–49"> 但尋不出法子來，因為百姓都側耳聽他。</span>

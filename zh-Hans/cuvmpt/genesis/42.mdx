## 雅各遣子往埃及糴糧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:12; 約書亞記 7:10; 列王紀下 8:3–4"> 雅各見埃及有糧，就對兒子們說：「你們為什麼彼此觀望呢？</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 43:8; 創世記 45:9; 創世記 43:2"> 我聽見埃及有糧，你們可以下去，從那裡為我們糴些來，使我們可以存活，不至於死。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 42:5; 創世記 42:13"> 於是，約瑟的十個哥哥都下埃及糴糧去了。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 42:38; 創世記 43:29; 創世記 11:4"> 但約瑟的兄弟便雅憫，雅各沒有打發他和哥哥們同去，因為雅各說：「恐怕他遭害。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:57; 使徒行傳 7:11; 創世記 12:10"> 來糴糧的人中有以色列的兒子們，因為迦南地也有饑荒。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 3:9; 創世記 37:7–10; 創世記 41:40–41"> 當時治理埃及地的是約瑟，糶糧給那地眾民的就是他。約瑟的哥哥們來了，臉伏於地，向他下拜。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 42:30; 創世記 42:14–17; 馬太福音 15:23–26"> 約瑟看見他哥哥們，就認得他們，卻裝作生人，向他們說些嚴厲話，問他們說：「你們從哪裡來？」他們說：「我們從迦南地來糴糧。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 37:2; 約翰福音 20:14; 路加福音 24:16"> 約瑟認得他哥哥們，他們卻不認得他。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 37:5–9; 出埃及記 32:35; 約書亞記 2:1"> 約瑟想起從前所做的那兩個夢，就對他們說：「你們是奸細，來窺探這地的虛實。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 37:8; 撒母耳記上 26:17; 創世記 27:37"> 他們對他說：「我主啊，不是的，僕人們是糴糧來的。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 42:19; 哥林多後書 6:4; 約翰福音 7:18"> 我們都是一個人的兒子，是誠實人，僕人們並不是奸細。」</span>
<span className="v" id="v12" data-v="12"> 約瑟說：「不然！你們必是窺探這地的虛實來的。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 37:30; 創世記 42:32; 創世記 44:20"> 他們說：「僕人們本是弟兄十二人，是迦南地一個人的兒子，頂小的現今在我們的父親那裡，有一個沒有了。」</span>
</div>
</div>

## 約瑟囚兄令攜弟至

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:21–28; 約伯記 13:24; 創世記 42:9–11"> 約瑟說：「我才說你們是奸細，這話實在不錯！</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 17:55; 耶利米書 5:7; 創世記 42:16"> 我指著法老的性命起誓，若是你們的小兄弟不到這裡來，你們就不得出這地方，從此就可以把你們證驗出來了。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 42:11"> 須要打發你們中間一個人去，把你們的兄弟帶來。至於你們，都要囚在這裡，好證驗你們的話真不真。若不真，我指著法老的性命起誓，你們一定是奸細。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 40:4; 希伯來書 12:10; 創世記 40:7"> 於是約瑟把他們都下在監裡三天。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 25:43; 尼希米記 5:15; 路加福音 18:2"> 到了第三天，約瑟對他們說：「我是敬畏神的，你們照我的話行就可以存活。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 45:23; 以賽亞書 42:7; 創世記 40:3"> 你們如果是誠實人，可以留你們中間的一個人囚在監裡；但你們可以帶著糧食回去，救你們家裡的饑荒。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 44:23; 創世記 43:5; 創世記 42:34"> 把你們的小兄弟帶到我這裡來，如此你們的話便有證據，你們也不至於死。」他們就照樣而行。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 5:15; 馬可福音 9:43–45; 創世記 37:23–28"> 他們彼此說：「我們在兄弟身上實在有罪。他哀求我們的時候，我們見他心裡的愁苦，卻不肯聽，所以這場苦難臨到我們身上。」</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 24:22; 詩篇 9:12; 列王紀上 2:32"> 魯本說：「我豈不是對你們說過不可傷害那孩子嗎？只是你們不肯聽，所以流他血的罪向我們追討。」</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 5:20; 約翰福音 16:13–14"> 他們不知道約瑟聽得出來，因為在他們中間用通事傳話。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 43:30; 猶大書 1:22–23; 希伯來書 4:15"> 約瑟轉身退去，哭了一場，又回來對他們說話，就從他們中間挑出西緬來，在他們眼前把他捆綁。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 3:9; 羅馬書 12:17–21; 創世記 45:21"> 約瑟吩咐人把糧食裝滿他們的器具，把各人的銀子歸還在各人的口袋裡，又給他們路上用的食物。人就照他的話辦了。</span>
</div>
</div>

## 見金在囊則懼

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 他們就把糧食馱在驢上，離開那裡去了。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 4:24; 路加福音 2:7; 路加福音 10:34"> 到了住宿的地方，他們中間有一個人打開口袋，要拿料餵驢，才看見自己的銀子仍在口袋裡，</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 45:7; 耶利米哀歌 3:37; 創世記 42:36"> 就對弟兄們說：「我的銀子歸還了，看哪，仍在我口袋裡！」他們就提心吊膽，戰戰兢兢地彼此說：「這是神向我們做什麼呢？」</span>
<span className="v" id="v29" data-v="29"> 他們來到迦南地他們的父親雅各那裡，將所遭遇的事都告訴他，說：</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:7"> 「那地的主對我們說嚴厲的話，把我們當做窺探那地的奸細。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 42:11"> 我們對他說：『我們是誠實人，並不是奸細。</span>
<span className="v" id="v32" data-v="32"> 我們本是弟兄十二人，都是一個父親的兒子，有一個沒有了，頂小的如今同我們的父親在迦南地。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 42:19–20; 創世記 42:15"> 那地的主對我們說：『若要我知道你們是誠實人，可以留下你們中間的一個人在我這裡，你們可以帶著糧食回去，救你們家裡的饑荒。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 34:10; 創世記 34:21; 列王紀上 10:15"> 把你們的小兄弟帶到我這裡來，我便知道你們不是奸細，乃是誠實人。這樣，我就把你們的弟兄交給你們，你們也可以在這地做買賣。』」</span>
</div>
</div>

## 雅各不容攜幼子去

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="創世記 43:21; 創世記 43:12; 創世記 43:15"> 後來他們倒口袋，不料，各人的銀包都在口袋裡。他們和父親看見銀包就都害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 43:14; 羅馬書 8:31; 以賽亞書 27:9"> 他們的父親雅各對他們說：「你們使我喪失我的兒子，約瑟沒有了，西緬也沒有了，你們又要將便雅憫帶去，這些事都歸到我身上了！」</span>
<span className="v" id="v37" data-v="37" data-xref="創世記 46:9; 彌迦書 6:7; 創世記 43:9"> 魯本對他父親說：「我若不帶他回來交給你，你可以殺我的兩個兒子。只管把他交在我手裡，我必帶他回來交給你。」</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 37:35; 創世記 42:4; 創世記 37:33"> 雅各說：「我的兒子不可與你們一同下去。他哥哥死了，只剩下他，他若在你們所行的路上遭害，那便是你們使我白髮蒼蒼、悲悲慘慘地下陰間去了。」</span>
</div>

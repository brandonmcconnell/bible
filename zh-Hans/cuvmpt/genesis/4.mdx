## 生該隱亞伯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 3:12; 創世記 3:15; 創世記 4:25"> 有一日，那人和他妻子夏娃同房，夏娃就懷孕，生了該隱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是「得」的意思。">a</a></sup>，便說：「耶和華使我得了一個男子。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 3:15; 約翰一書 3:12; 路加福音 11:51"> 又生了該隱的兄弟亞伯。亞伯是牧羊的，該隱是種地的。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 18:12; 利未記 2:1–11; 列王紀上 17:7"> 有一日，該隱拿地裡的出產為供物獻給耶和華，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:4; 箴言 3:9; 出埃及記 13:12"> 亞伯也將他羊群中頭生的和羊的脂油獻上。耶和華看中了亞伯和他的供物，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:4; 約伯記 5:2; 路加福音 15:28–30"> 只是看不中該隱和他的供物。該隱就大大地發怒，變了臉色。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 1:18; 約伯記 5:2; 路加福音 15:31–32"> 耶和華對該隱說：「你為什麼發怒呢？你為什麼變了臉色呢？</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:15; 羅馬書 2:6–10; 以賽亞書 3:10–11"> 你若行得好，豈不蒙悅納？你若行得不好，罪就伏在門前。它必戀慕你，你卻要制伏它。」</span>
</div>
</div>

## 該隱殺其弟

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="馬太福音 23:35; 約翰一書 3:12–15; 猶大書 1:11"> 該隱與他兄弟亞伯說話，二人正在田間，該隱起來打他兄弟亞伯，把他殺了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; 約翰福音 8:44; 詩篇 9:12"> 耶和華對該隱說：「你兄弟亞伯在哪裡？」他說：「我不知道。我豈是看守我兄弟的嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 12:24; 詩篇 72:14; 希伯來書 11:4"> 耶和華說：「你做了什麼事呢？你兄弟的血有聲音從地裡向我哀告。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:10; 約伯記 16:18; 創世記 3:14"> 地開了口，從你手裡接受你兄弟的血，現在你必從這地受咒詛。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 9:17; 利未記 26:36; 利未記 26:20"> 你種地，地不再給你效力；你必流離飄蕩在地上。」</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 15:22; 啟示錄 16:9; 啟示錄 16:11"> 該隱對耶和華說：「我的刑罰太重，過於我所能當的。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 35:19; 詩篇 143:7; 約伯記 15:20–24"> 你如今趕逐我離開這地，以致不見你面，我必流離飄蕩在地上，凡遇見我的必殺我。」</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 9:4; 詩篇 79:12; 創世記 4:24"> 耶和華對他說：「凡殺該隱的，必遭報七倍。」耶和華就給該隱立一個記號，免得人遇見他就殺他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:39; 約伯記 2:7; 創世記 4:14"> 於是，該隱離開耶和華的面，去住在伊甸東邊挪得之地。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 49:11; 傳道書 2:4–11; 但以理書 4:30"> 該隱與妻子同房，他妻子就懷孕，生了以諾。該隱建造了一座城，就按著他兒子的名，將那城叫做以諾。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:2; 創世記 5:21"> 以諾生以拿，以拿生米戶雅利，米戶雅利生瑪土撒利，瑪土撒利生拉麥。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 2:24; 馬太福音 19:8; 創世記 2:18"> 拉麥娶了兩個妻，一個名叫亞大，一個名叫洗拉。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 4:2; 耶利米書 35:9–10; 約翰福音 8:44"> 亞大生雅八。雅八就是住帳篷、牧養牲畜之人的祖師。</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 21:12; 以賽亞書 5:12; 創世記 31:27"> 雅八的兄弟名叫猶八，他是一切彈琴吹簫之人的祖師。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 33:25; 申命記 8:9; 歷代志下 2:7"> 洗拉又生了土八該隱，他是打造各樣銅鐵利器的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：是銅匠鐵匠的祖師。">b</a></sup>。土八該隱的妹子是拿瑪。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 23:18; 出埃及記 20:13; 利未記 19:18"> 拉麥對他兩個妻子說：<br /><span className="pl pl-1">「亞大、洗拉，聽我的聲音，</span><br /><span className="pl pl-1">拉麥的妻子，細聽我的話語：</span><br /><span className="pl pl-1">壯年人傷我，我把他殺了；</span><br /><span className="pl pl-1">少年人損我，我把他害了</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：我殺壯士卻傷自己，我害幼童卻損本身。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 18:22; 創世記 4:15"> <span className="pl pl-1">若殺該隱遭報七倍，</span><br /><span className="pl pl-1">殺拉麥必遭報七十七倍。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 4:8; 創世記 4:10–11; 歷代志上 1:1"> 亞當又與妻子同房，她就生了一個兒子，起名叫塞特，意思說：「神另給我立了一個兒子代替亞伯，因為該隱殺了他。」</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 116:17; 列王紀上 18:24; 約珥書 2:32"> 塞特也生了一個兒子，起名叫以挪士。那時候，人才求告耶和華的名。</span>
</div>
</div>

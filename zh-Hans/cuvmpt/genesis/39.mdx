<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 18:14; 詩篇 91:15; 耶利米書 15:20"> 約瑟住在他主人埃及人的家中，耶和華與他同在，他就百事順利。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 1:3; 創世記 30:27; 馬太福音 5:16"> 他主人見耶和華與他同在，又見耶和華使他手裡所辦的盡都順利，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:21–22; 箴言 27:18; 創世記 19:19"> 約瑟就在主人眼前蒙恩，伺候他主人，並且主人派他管理家務，把一切所有的都交在他手裡。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; 撒母耳記下 6:11–12; 使徒行傳 27:24"> 自從主人派約瑟管理家務和他一切所有的，耶和華就因約瑟的緣故賜福於那埃及人的家；凡家裡和田間一切所有的，都蒙耶和華賜福。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 16:12; 路加福音 19:17; 箴言 31:11"> 波提乏將一切所有的都交在約瑟的手中，除了自己所吃的飯，別的事一概不知。約瑟原來秀雅俊美。</span>
</div>

## 主母誣約瑟

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 13:11; 以西結書 16:34; 彼得後書 2:14"> 這事以後，約瑟主人的妻以目送情給約瑟，說：「你與我同寢吧！」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 約瑟不從，對他主人的妻說：「看哪，一切家務我主人都不知道，他把所有的都交在我手裡。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 12:13; 創世記 20:6; 創世記 42:18"> 在這家裡沒有比我大的，並且他沒有留下一樣不交給我，只留下了你，因為你是他的妻子。我怎能做這大惡得罪神呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 2:11; 創世記 39:8; 帖撒羅尼迦前書 5:22"> 後來她天天和約瑟說，約瑟卻不聽從她，不與她同寢，也不和她在一處。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 5:12; 以弗所書 5:3; 瑪拉基書 3:5"> 有一天，約瑟進屋裡去辦事，家中人沒有一個在那屋裡。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 2:22; 箴言 7:13–27; 傳道書 7:26"> 婦人就拉住他的衣裳，說：「你與我同寢吧！」約瑟把衣裳丟在婦人手裡，跑到外邊去了。</span>
<span className="v" id="v13" data-v="13"> 婦人看見約瑟把衣裳丟在她手裡跑出去了，</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:21; 彼得前書 2:20; 詩篇 35:11"> 就叫了家裡的人來，對他們說：「你們看！他帶了一個希伯來人進入我們家裡，要戲弄我們。他到我這裡來，要與我同寢，我就大聲喊叫。</span>
<span className="v" id="v15" data-v="15"> 他聽見我放聲喊起來，就把衣裳丟在我這裡，跑到外邊去了。」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:32; 耶利米書 4:22; 耶利米書 9:3–5"> 婦人把約瑟的衣裳放在自己那裡，等著他主人回家，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 23:1; 列王紀上 18:17; 詩篇 37:14"> 就對他如此如此說：「你所帶到我們這裡的那希伯來僕人進來要戲弄我，</span>
<span className="v" id="v18" data-v="18"> 我放聲喊起來，他就把衣裳丟在我這裡跑出去了。」</span>
</div>
</div>

## 波提乏囚約瑟於監

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 4:5–6; 箴言 18:17; 箴言 6:34–35"> 約瑟的主人聽見他妻子對他所說的話，說「你的僕人如此如此待我」，他就生氣，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 40:15; 提摩太後書 2:9; 詩篇 105:18–19"> 把約瑟下在監裡，就是王的囚犯被囚的地方。於是約瑟在那裡坐監。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 3:21; 以賽亞書 41:10; 彼得前書 3:17"> 但耶和華與約瑟同在，向他施恩，使他在司獄的眼前蒙恩。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:3–4; 創世記 39:4; 撒母耳記上 2:30"> 司獄就把監裡所有的囚犯都交在約瑟手下，他們在那裡所辦的事都是經他的手。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 43:2; 創世記 39:2–3; 詩篇 1:3"> 凡在約瑟手下的事，司獄一概不察，因為耶和華與約瑟同在，耶和華使他所做的盡都順利。</span>
</div>
</div>

## 雅各往伯特利築壇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 31:13; 何西阿書 12:4; 詩篇 91:15"> 神對雅各說：「起來，上伯特利去，住在那裡。要在那裡築一座壇給神，就是你逃避你哥哥以掃的時候向你顯現的那位。」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:14; 出埃及記 19:10; 以西結書 18:31"> 雅各就對他家中的人並一切與他同在的人說：「你們要除掉你們中間的外邦神，也要自潔，更換衣裳。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 43:2; 創世記 32:7; 創世記 31:3"> 我們要起來，上伯特利去，在那裡我要築一座壇給神，就是在我遭難的日子應允我的禱告，在我行的路上保佑我的那位。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:6; 申命記 7:25; 出埃及記 32:20"> 他們就把外邦人的神像和他們耳朵上的環子交給雅各，雅各都藏在示劍那裡的橡樹底下。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 23:27; 歷代志下 17:10; 約書亞記 5:1"> 他們便起行前往，神使那周圍城邑的人都甚驚懼，就不追趕雅各的眾子了。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 28:19; 創世記 28:22; 創世記 12:8"> 於是雅各和一切與他同在的人到了迦南地的路斯，就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:13"> 他在那裡築了一座壇，就給那地方起名叫伊勒伯特利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是「伯特利之神」的意思。">a</a></sup>，因為他逃避他哥哥的時候，神在那裡向他顯現。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 24:59; 撒母耳記上 31:13; 士師記 2:5"> 利百加的奶母底波拉死了，就葬在伯特利下邊橡樹底下，那棵樹名叫亞倫巴古。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 35:1; 創世記 18:1; 創世記 26:2"> 雅各從巴旦亞蘭回來，神又向他顯現，賜福於他，</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:5; 創世記 32:27–28; 創世記 17:15"> 且對他說：「你的名原是雅各，從今以後不要再叫雅各，要叫以色列。」這樣，他就改名叫以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:1; 創世記 9:1; 創世記 22:17"> 神又對他說：「我是全能的神。你要生養眾多，將來有一族和多國的民從你而生，又有君王從你而出。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:7; 創世記 28:13; 創世記 26:3–4"> 我所賜給亞伯拉罕和以撒的地，我要賜給你與你的後裔。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 17:22; 創世記 18:33; 士師記 6:21"> 神就從那與雅各說話的地方升上去了。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 28:18–19; 撒母耳記上 7:12; 出埃及記 17:15"> 雅各便在那裡立了一根石柱，在柱子上奠酒，澆油。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 28:19"> 雅各就給那地方起名叫伯特利。</span>
</div>
</div>

## 拉結生子而死

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="彌迦書 5:2; 創世記 48:7; 列王紀下 5:19"> 他們從伯特利起行，離以法他還有一段路程，拉結臨產甚是艱難。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:24; 撒母耳記上 4:19–21"> 正在艱難的時候，收生婆對她說：「不要怕，你又要得一個兒子了。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行傳 7:59; 路加福音 23:46"> 她將近於死，靈魂要走的時候，就給她兒子起名叫便俄尼，他父親卻給他起名叫便雅憫。</span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 5:2; 創世記 48:7; 路得記 4:11"> 拉結死了，葬在以法他的路旁。以法他就是伯利恆。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 10:2; 創世記 35:14; 撒母耳記下 18:17–18"> 雅各在她的墳上立了一統碑，就是拉結的墓碑，到今日還在。</span>
<span className="v" id="v21" data-v="21" data-xref="彌迦書 4:8; 路加福音 2:8"> 以色列起行前往，在以得臺那邊支搭帳篷。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 5:1; 利未記 18:8; 撒母耳記下 20:3"> 以色列住在那地的時候，魯本去與他父親的妾辟拉同寢，以色列也聽見了。<br />雅各共有十二個兒子。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 30:18–20; 創世記 46:8–15; 創世記 29:32–35"> 利亞所生的是雅各的長子魯本，還有西緬、利未、猶大、以薩迦、西布倫。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 30:22–24; 創世記 46:19–22; 創世記 35:16–18"> 拉結所生的是約瑟、便雅憫。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 46:23–25; 創世記 37:2; 創世記 30:4–8"> 拉結的使女辟拉所生的是但、拿弗他利。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 30:9–13; 創世記 46:16–18; 創世記 25:20"> 利亞的使女悉帕所生的是迦得、亞設。這是雅各在巴旦亞蘭所生的兒子。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 13:18; 創世記 23:19; 創世記 18:1"> 雅各來到他父親以撒那裡，到了基列亞巴的幔利，乃是亞伯拉罕和以撒寄居的地方。基列亞巴就是希伯崙。</span>
</div>
</div>

## 以撒壽終

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 25:7; 創世記 50:26; 創世記 47:28"> 以撒共活了一百八十歲。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 15:15; 創世記 49:33; 創世記 49:31"> 以撒年紀老邁，日子滿足，氣絕而死，歸到他列祖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：本民。">b</a></sup>那裡。他兩個兒子以掃、雅各把他埋葬了。</span>
</div>

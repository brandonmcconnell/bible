<span className="v" id="v1" data-v="1" data-xref="創世記 28:13; 創世記 26:22–25; 創世記 28:10"> 以色列帶著一切所有的，起身來到別是巴，就獻祭給他父親以撒的神。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 15:1; 約伯記 33:14–15; 約伯記 4:13"> 夜間，神在異象中對以色列說：「雅各！雅各！」他說：「我在這裡。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:2; 申命記 26:5; 以賽亞書 43:1–2"> 神說：「我是神，就是你父親的神。你下埃及去不要害怕，因為我必使你在那裡成為大族。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 3:8; 創世記 28:15; 創世記 48:21"> 我要和你同下埃及去，也必定帶你上來。約瑟必給你送終<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：將手按在你的眼睛上。">a</a></sup>。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 45:21; 創世記 45:19; 創世記 45:27"> 雅各就從別是巴起行。以色列的兒子們使他們的父親雅各和他們的妻子、兒女都坐在法老為雅各送來的車上。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 24:4; 以賽亞書 52:4; 使徒行傳 7:15"> 他們又帶著迦南地所得的牲畜、貨財來到埃及。雅各和他的一切子孫都一同來了。</span>
<span className="v" id="v7" data-v="7"> 雅各把他的兒子、孫子、女兒、孫女，並他的子子孫孫，一同帶到埃及。</span>
</div>

## 記雅各家下埃及者之名

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 1:1–5; 申命記 33:6; 歷代志上 2:1–55"> 來到埃及的以色列人名字記在下面。雅各和他的兒孫：雅各的長子是魯本，</span>
<span className="v" id="v9" data-v="9"> 魯本的兒子是哈諾、法路、希斯崙、迦米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 6:15; 創世記 29:33; 創世記 28:1"> 西緬的兒子是耶母利、雅憫、阿轄、雅斤、瑣轄，還有迦南女子所生的掃羅。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 29:34; 歷代志上 6:16; 民數記 8:1–26"> 利未的兒子是革順、哥轄、米拉利。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 4:21; 創世記 38:10; 創世記 29:35"> 猶大的兒子是珥、俄南、示拉、法勒斯、謝拉，唯有珥與俄南死在迦南地；法勒斯的兒子是希斯崙、哈母勒。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 12:32; 創世記 35:23; 創世記 30:14–18"> 以薩迦的兒子是陀拉、普瓦、約伯、伸崙。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:18–19; 民數記 26:26–27; 民數記 1:30–31"> 西布倫的兒子是西烈、以倫、雅利。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:32–35; 創世記 30:17–21; 創世記 34:1–31"> 這是利亞在巴旦亞蘭給雅各所生的兒子，還有女兒底拿，兒孫共三十三人。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 26:15–17; 創世記 30:11; 民數記 1:24–25"> 迦得的兒子是洗非芸、哈基、書尼、以斯本、以利、亞羅底、亞列利。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 創世記 30:13; 民數記 1:13"> 亞設的兒子是音拿、亦施瓦、亦施韋、比利亞，還有他們的妹子西拉；比利亞的兒子是希別、瑪結。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 29:24; 創世記 35:26; 創世記 30:9–13"> 這是拉班給他女兒利亞的婢女悉帕從雅各所生的兒孫，共有十六人。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 44:27; 創世記 29:18; 創世記 35:24"> 雅各之妻拉結的兒子是約瑟和便雅憫。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:50–52; 創世記 41:45; 申命記 33:13–17"> 約瑟在埃及地生了瑪拿西和以法蓮，就是安城的祭司波提非拉的女兒亞西納給約瑟生的。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 7:6–12; 歷代志上 8:1–7; 民數記 26:38–40"> 便雅憫的兒子是比拉、比結、亞實別、基拉、乃幔、以希、羅實、母平、戶平、亞勒。</span>
<span className="v" id="v22" data-v="22"> 這是拉結給雅各所生的兒孫，共有十四人。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:38–39; 創世記 49:16–17; 民數記 1:12"> 但的兒子是戶伸。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 7:13; 民數記 1:42–43; 創世記 35:25"> 拿弗他利的兒子是雅薛、沽尼、耶色、示冷。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 29:29; 創世記 35:25; 創世記 30:3–8"> 這是拉班給他女兒拉結的婢女辟拉從雅各所生的兒孫，共有七人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 1:5; 創世記 35:11; 士師記 8:30"> 那與雅各同到埃及的，除了他兒婦之外，凡從他所生的，共有六十六人。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 10:22; 使徒行傳 7:14; 出埃及記 1:5"> 還有約瑟在埃及所生的兩個兒子。雅各家來到埃及的共有七十人。</span>
</div>
</div>

## 約瑟往歌珊迎父

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 45:10; 創世記 44:16–34; 創世記 49:8"> 雅各打發猶大先去見約瑟，請派人引路往歌珊去。於是他們來到歌珊地。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 創世記 45:14–15; 創世記 33:4"> 約瑟套車往歌珊去，迎接他父親以色列，及至見了面，就伏在父親的頸項上哭了許久。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 創世記 45:28"> 以色列對約瑟說：「我既得見你的面，知道你還在，就是死我也甘心。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 47:1–3; 希伯來書 2:11; 使徒行傳 18:3"> 約瑟對他的弟兄和他父的全家說：「我要上去告訴法老，對他說：『我的弟兄和我父的全家從前在迦南地，現今都到我這裡來了。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 47:3; 列王紀上 9:27; 列王紀上 18:5–6"> 他們本是牧羊的人，以養牲畜為業。他們把羊群牛群和一切所有的都帶來了。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 46:32; 創世記 47:2–4; 約拿書 1:8"> 等法老召你們的時候，問你們說：『你們以何事為業？』</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 8:26; 創世記 43:32; 創世記 46:32"> 你們要說：『你的僕人，從幼年直到如今，都以養牲畜為業，連我們的祖宗也都以此為業。』這樣，你們可以住在歌珊地，因為凡牧羊的都被埃及人所厭惡。」</span>
</div>

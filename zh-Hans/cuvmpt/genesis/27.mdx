<span className="v" id="v2" data-v="2" data-xref="雅各書 4:14; 傳道書 9:10; 箴言 27:1"> 他說：「我如今老了，不知道哪一天死。</span>

<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:20; 創世記 48:9; 創世記 49:28"> 照我所愛的做成美味，拿來給我吃，使我在未死之先給你祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 以撒對他兒子以掃說話，利百加也聽見了。以掃往田野去打獵，要得野味帶來。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 25:28"> 利百加就對她兒子雅各說：「我聽見你父親對你哥哥以掃說：</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 6:26; 撒母耳記上 24:19; 申命記 33:1"> 『你去把野獸帶來，做成美味給我吃，我好在未死之先，在耶和華面前給你祝福。』</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:1; 創世記 27:13; 使徒行傳 5:29"> 現在，我兒，你要照著我所吩咐你的，聽從我的話。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:15; 撒母耳記上 16:20"> 你到羊群裡去，給我拿兩隻肥山羊羔來，我便照你父親所愛的給他做成美味。</span>
<span className="v" id="v10" data-v="10"> 你拿到你父親那裡給他吃，使他在未死之先給你祝福。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 25:25"> 雅各對他母親利百加說：「我哥哥以掃渾身是有毛的，我身上是光滑的。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:18; 創世記 25:27; 瑪拉基書 1:14"> 倘若我父親摸著我，必以我為欺哄人的，我就招咒詛，不得祝福。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 27:25; 撒母耳記上 25:24; 撒母耳記下 14:9"> 他母親對他說：「我兒，你招的咒詛歸到我身上，你只管聽我的話，去把羊羔給我拿來。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 27:9; 箴言 23:2–3; 創世記 25:28"> 他便去拿來交給他母親，他母親就照他父親所愛的做成美味。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 27:27; 路加福音 20:46; 路加福音 15:22"> 利百加又把家裡所存大兒子以掃上好的衣服給她小兒子雅各穿上，</span>
<span className="v" id="v16" data-v="16"> 又用山羊羔皮包在雅各的手上和頸項的光滑處，</span>
<span className="v" id="v17" data-v="17"> 就把所做的美味和餅交在他兒子雅各的手裡。</span>

## 雅各欺父

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18"> 雅各到他父親那裡說：「我父親！」他說：「我在這裡，我兒，你是誰？」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 28:15; 馬太福音 26:70–74; 撒迦利亞書 13:3–4"> 雅各對他父親說：「我是你的長子以掃。我已照你所吩咐我的行了。請起來坐著，吃我的野味，好給我祝福。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:7; 約伯記 13:7; 創世記 24:12"> 以撒對他兒子說：「我兒，你如何找得這麼快呢？」他說：「因為耶和華你的神使我遇見好機會得著的。」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 4:8; 以賽亞書 57:19; 創世記 27:12"> 以撒對雅各說：「我兒，你近前來，我摸摸你，知道你真是我的兒子以掃不是。」</span>
<span className="v" id="v22" data-v="22"> 雅各就挨近他父親以撒，以撒摸著他，說：「聲音是雅各的聲音，手卻是以掃的手。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 27:16; 希伯來書 11:20; 羅馬書 9:11–12"> 以撒就辨不出他來，因為他手上有毛，像他哥哥以掃的手一樣，就給他祝福。</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:9; 以弗所書 4:25; 箴言 12:22"> 又說：「你真是我兒子以掃嗎？」他說：「我是。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:4"> 以撒說：「你遞給我，我好吃我兒子的野味，給你祝福。」雅各就遞給他，他便吃了，又拿酒給他，他也喝了。</span>
<span className="v" id="v26" data-v="26"> 他父親以撒對他說：「我兒，你上前來與我親嘴。」</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 6:7; 詩篇 65:10; 希伯來書 11:20"> 他就上前與父親親嘴，他父親一聞他衣服上的香氣，就給他祝福，說：<br /><span className="pl pl-1">「我兒的香氣</span><br /><span className="pl pl-1">如同耶和華賜福之田地的香氣一樣。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:28; 申命記 33:13; 詩篇 133:3"> <span className="pl pl-1">願神賜你天上的甘露、</span><br /><span className="pl pl-1">地上的肥土，</span><br /><span className="pl pl-1">並許多五穀、新酒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="創世記 12:3; 民數記 24:9; 以賽亞書 49:23"> <span className="pl pl-1">願多民侍奉你，</span><br /><span className="pl pl-1">多國跪拜你；</span><br /><span className="pl pl-1">願你做你弟兄的主，</span><br /><span className="pl pl-1">你母親的兒子向你跪拜。</span><br /><span className="pl pl-1">凡咒詛你的，願他受咒詛；</span><br /><span className="pl pl-1">為你祝福的，願他蒙福。」</span></span>
</div>
</div>

## 以掃痛哭求父祝福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30"> 以撒為雅各祝福已畢，雅各從他父親那裡才出來，他哥哥以掃正打獵回來，</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 27:4"> 也做了美味，拿來給他父親，說：「請父親起來，吃你兒子的野味，好給我祝福。」</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 27:18"> 他父親以撒對他說：「你是誰？」他說：「我是你的長子以掃。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 28:3–4; 羅馬書 11:29; 以弗所書 1:3"> 以撒就大大地戰兢，說：「你未來之先，是誰得了野味拿來給我呢？我已經吃了，為他祝福，他將來也必蒙福。」</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 12:17; 箴言 1:31; 撒母耳記上 30:4"> 以掃聽了他父親的話，就放聲痛哭，說：「我父啊，求你也為我祝福！」</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦前書 4:6; 約伯記 13:7; 瑪拉基書 2:10"> 以撒說：「你兄弟已經用詭計來將你的福分奪去了。」</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 25:26; 約翰福音 1:47; 創世記 32:28"> 以掃說：「他名雅各，豈不是正對嗎？因為他欺騙了我兩次。他從前奪了我長子的名分，你看，他現在又奪了我的福分。」以掃又說：「你沒有留下為我可祝的福嗎？」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 8:14; 創世記 27:28–29; 創世記 25:23"> 以撒回答以掃說：「我已立他為你的主，使他的弟兄都給他做僕人，並賜他五穀、新酒可以養生。我兒，現在我還能為你做什麼呢？」</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 12:17; 創世記 27:34; 以賽亞書 65:14"> 以掃對他父親說：「父啊，你只有一樣可祝的福嗎？我父啊，求你也為我祝福！」以掃就放聲而哭。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 27:28; 希伯來書 11:20; 約書亞記 24:4"> 他父親以撒說：<br /><span className="pl pl-1">「地上的肥土必為你所住，</span><br /><span className="pl pl-1">天上的甘露必為你所得。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 8:20–22; 創世記 25:23; 歷代志下 25:11–12"> <span className="pl pl-1">你必倚靠刀劍度日，</span><br /><span className="pl pl-1">又必侍奉你的兄弟。</span><br /><span className="pl pl-1">到你強盛的時候，</span><br /><span className="pl pl-1">必從你頸項上掙開他的軛。」</span></span>
</div>
</div>

## 以掃怨恨雅各欲殺之

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰一書 3:12–15; 創世記 37:4; 創世記 50:3–4"> 以掃因他父親給雅各祝的福，就怨恨雅各，心裡說：「為我父親居喪的日子近了，到那時候，我要殺我的兄弟雅各。」</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 37:18–20; 撒母耳記上 30:5; 創世記 42:21–22"> 有人把利百加大兒子以掃的話告訴利百加，她就打發人去，叫了她小兒子雅各來，對他說：「你哥哥以掃想要殺你，報仇雪恨。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 27:8; 創世記 11:31; 創世記 27:13"> 現在，我兒，你要聽我的話，起來逃往哈蘭我哥哥拉班那裡去，</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:38; 創世記 31:41"> 同他住些日子，直等你哥哥的怒氣消了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 創世記 4:8–16; 創世記 9:5–6"> 你哥哥向你消了怒氣，忘了你向他所做的事，我便打發人去把你從那裡帶回來。為什麼一日喪你們二人呢？」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="創世記 24:3; 創世記 26:34–35; 創世記 28:8"> 利百加對以撒說：「我因這赫人的女子連性命都厭煩了。倘若雅各也娶赫人的女子為妻像這些一樣，我活著還有什麼益處呢？」</span>
</div>

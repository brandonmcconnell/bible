## 以撒生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 12:6; 創世記 18:10; 創世記 18:14"> 耶和華按著先前的話眷顧撒拉，便照他所說的給撒拉成就。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 4:22; 希伯來書 11:11; 創世記 18:10"> 當亞伯拉罕年老的時候，撒拉懷了孕，到神所說的日期就給亞伯拉罕生了一個兒子。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 17:19; 羅馬書 9:7; 創世記 21:6"> 亞伯拉罕給撒拉所生的兒子起名叫以撒。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 7:8; 申命記 12:32; 約翰福音 7:22–23"> 以撒生下來第八日，亞伯拉罕照著神所吩咐的給以撒行了割禮。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:17; 羅馬書 4:19; 創世記 17:1"> 他兒子以撒生的時候，亞伯拉罕年一百歲。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 126:2; 以賽亞書 54:1; 創世記 17:17"> 撒拉說：「神使我喜笑，凡聽見的必與我一同喜笑。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 18:11–12; 以賽亞書 66:8; 帖撒羅尼迦後書 1:10"> 又說：「誰能預先對亞伯拉罕說撒拉要乳養嬰孩呢？因為在他年老的時候，我給他生了一個兒子。」</span>
</div>
</div>

## 夏甲與其子被逐

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 1:22; 何西阿書 1:8; 創世記 40:20"> 孩子漸長，就斷了奶。以撒斷奶的日子，亞伯拉罕設擺豐盛的筵席。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 4:29; 創世記 16:15; 加拉太書 4:22"> 當時，撒拉看見埃及人夏甲給亞伯拉罕所生的兒子戲笑，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:35; 約翰一書 2:19; 加拉太書 4:22–31"> 就對亞伯拉罕說：「你把這使女和她兒子趕出去，因為這使女的兒子不可與我的兒子以撒一同承受產業。」</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 12:11; 創世記 17:18; 馬太福音 10:37"> 亞伯拉罕因他兒子的緣故很憂愁。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:18; 羅馬書 9:7–8; 創世記 17:19"> 神對亞伯拉罕說：「你不必為這童子和你的使女憂愁，凡撒拉對你說的話，你都該聽從，因為從以撒生的才要稱為你的後裔。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 16:10; 創世記 17:20; 創世記 21:18"> 至於使女的兒子，我也必使他的後裔成立一國，因為他是你所生的。」</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 9:10; 詩篇 119:60; 創世記 16:7"> 亞伯拉罕清早起來，拿餅和一皮袋水，給了夏甲，搭在她的肩上，又把孩子交給她，打發她走。夏甲就走了，在別是巴的曠野走迷了路。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 3:9; 詩篇 63:1; 耶利米書 14:3"> 皮袋的水用盡了，夏甲就把孩子撇在小樹底下，</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 49:15; 創世記 29:11; 撒母耳記上 24:16"> 自己走開約有一箭之遠，相對而坐，說：「我不忍見孩子死！」就相對而坐，放聲大哭。</span>
</div>
</div>

## 天使安慰夏甲

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 16:11; 詩篇 50:15; 出埃及記 3:7"> 神聽見童子的聲音，神的使者從天上呼叫夏甲說：「夏甲，你為何這樣呢？不要害怕，神已經聽見童子的聲音了。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:13; 創世記 16:10; 創世記 17:20"> 起來，把童子抱在懷<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「懷」原文作「手」。">a</a></sup>中，我必使他的後裔成為大國。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 22:31; 列王紀下 6:17–20; 以賽亞書 35:5–6"> 神使夏甲的眼睛明亮，她就看見一口水井，便去將皮袋盛滿了水，給童子喝。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:15; 創世記 39:21; 創世記 16:12"> 神保佑童子，他就漸長，住在曠野，成了弓箭手。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 26:34–35; 創世記 24:3–4; 民數記 12:16"> 他住在巴蘭的曠野。他母親從埃及地給他娶了一個妻子。</span>
</div>
</div>

## 亞伯拉罕與亞比米勒立約

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約書亞記 3:7; 創世記 26:26; 創世記 26:28"> 當那時候，亞比米勒同他軍長非各對亞伯拉罕說：「凡你所行的事都有神的保佑。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 2:12; 創世記 20:14; 希伯來書 6:16"> 我願你如今在這裡指著神對我起誓，不要欺負我與我的兒子，並我的子孫。我怎樣厚待了你，你也要照樣厚待我與你所寄居這地的民。」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 6:16; 創世記 14:13; 羅馬書 12:18"> 亞伯拉罕說：「我情願起誓。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 26:15–22; 創世記 29:8; 箴言 25:9"> 從前亞比米勒的僕人霸占了一口水井，亞伯拉罕為這事指責亞比米勒。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 13:7; 列王紀下 5:20–24"> 亞比米勒說：「誰做這事，我不知道，你也沒有告訴我，今日我才聽見了。」</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 14:22–23; 以賽亞書 32:8; 羅馬書 1:31"> 亞伯拉罕把羊和牛給了亞比米勒，二人就彼此立約。</span>
<span className="v" id="v28" data-v="28"> 亞伯拉罕把七隻母羊羔另放在一處。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 15:14; 創世記 33:8; 出埃及記 12:26"> 亞比米勒問亞伯拉罕說：「你把這七隻母羊羔另放在一處，是什麼意思呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:52; 約書亞記 24:27; 約書亞記 22:27–28"> 他說：「你要從我手裡受這七隻母羊羔，做我挖這口井的證據。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 26:33; 創世記 21:14; 列王紀上 4:25"> 所以他給那地方起名叫別是巴<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「別是巴」就是「盟誓的井」。">b</a></sup>，因為他們二人在那裡起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 13:17; 創世記 21:27; 士師記 13:1"> 他們在別是巴立了約，亞比米勒就同他軍長非各起身回非利士地去了。</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太前書 1:17; 以賽亞書 40:28; 詩篇 90:2"> 亞伯拉罕在別是巴栽上一棵垂絲柳樹，又在那裡求告耶和華永生神的名。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 29:15; 彼得前書 2:11; 希伯來書 11:9"> 亞伯拉罕在非利士人的地寄居了多日。</span>
</div>
</div>

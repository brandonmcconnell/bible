## 亞伯拉罕接待天使

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:13; 創世記 48:3; 創世記 13:18"> 耶和華在幔利橡樹那裡，向亞伯拉罕顯現出來。那時正熱，亞伯拉罕坐在帳篷門口，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 13:2; 創世記 18:22; 創世記 19:1"> 舉目觀看，見有三個人在對面站著。他一見，就從帳篷門口跑去迎接他們，俯伏在地，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 32:5"> 說：「我主，我若在你眼前蒙恩，求你不要離開僕人往前去。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 24:32; 創世記 19:2; 創世記 43:24"> 容我拿點水來，你們洗洗腳，在樹下歇息歇息。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:15; 士師記 13:15; 士師記 6:18"> 我再拿一點餅來，你們可以加添心力，然後往前去。你們既到僕人這裡來，理當如此。」他們說：「就照你說的行吧。」</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:33; 希伯來書 13:2; 使徒行傳 16:15"> 亞伯拉罕急忙進帳篷見撒拉，說：「你速速拿三細亞細麵調和做餅。」</span>
<span className="v" id="v7" data-v="7" data-xref="瑪拉基書 1:14; 路加福音 15:27; 路加福音 15:30"> 亞伯拉罕又跑到牛群裡，牽了一隻又嫩又好的牛犢來，交給僕人，僕人急忙預備好了。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:3; 士師記 13:15; 啟示錄 3:20"> 亞伯拉罕又取了奶油和奶，並預備好的牛犢來，擺在他們面前，自己在樹下站在旁邊，他們就吃了。</span>
</div>
</div>

## 應許撒拉生子

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提多書 2:5; 創世記 24:67; 創世記 4:9"> 他們問亞伯拉罕說：「你妻子撒拉在哪裡？」他說：「在帳篷裡。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 21:2; 創世記 17:21; 羅馬書 9:8–9"> 三人中有一位說：「到明年這時候，我必要回到你這裡，你的妻子撒拉必生一個兒子。」撒拉在那人後邊的帳篷門口也聽見了這話。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:17; 希伯來書 11:11–12; 路加福音 1:36"> 亞伯拉罕和撒拉年紀老邁，撒拉的月經已斷絕了。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:6; 創世記 17:17; 路加福音 1:18–20"> 撒拉心裡暗笑，說：「我既已衰敗，我主也老邁，豈能有這喜事呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 2:25"> 耶和華對亞伯拉罕說：「撒拉為什麼暗笑，說：『我既已年老，果真能生養嗎？』</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:37; 馬太福音 19:26; 馬可福音 10:27"> 耶和華豈有難成的事嗎？到了日期，明年這時候，我必回到你這裡，撒拉必生一個兒子。」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 1:8; 箴言 28:13; 以弗所書 4:23"> 撒拉就害怕，不承認，說：「我沒有笑。」那位說：「不然，你實在笑了。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 15:3; 使徒行傳 21:5; 使徒行傳 20:38"> 三人就從那裡起行，向所多瑪觀看，亞伯拉罕也與他們同行，要送他們一程。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司書 3:7; 詩篇 25:14; 約翰福音 15:15"> 耶和華說：「我所要做的事，豈可瞞著亞伯拉罕呢？</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 3:8; 創世記 26:4; 加拉太書 3:14"> 亞伯拉罕必要成為強大的國，地上的萬國都必因他得福。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:6–7; 申命記 4:9–10; 提摩太前書 3:4–5"> 我眷顧他，為要叫他吩咐他的眾子和他的眷屬，遵守我的道，秉公行義，使我所應許亞伯拉罕的話都成就了。」</span>
</div>
</div>

## 神將滅所多瑪蛾摩拉

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 19:13; 以西結書 16:49–50; 以賽亞書 3:9"> 耶和華說：「所多瑪和蛾摩拉的罪惡甚重，聲聞於我。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 3:8; 創世記 11:5; 西番雅書 1:12"> 我現在要下去，察看他們所行的，果然盡像那達到我耳中的聲音一樣嗎？若是不然，我也必知道。」</span>
</div>
</div>

## 亞伯拉罕為所多瑪祈求

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 19:1; 使徒行傳 7:55; 以西結書 22:30"> 二人轉身離開那裡，向所多瑪去，但亞伯拉罕仍舊站在耶和華面前。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 16:22; 撒母耳記下 24:17; 創世記 20:4"> 亞伯拉罕近前來，說：「無論善惡，你都要剿滅嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 5:1; 以賽亞書 1:9; 馬太福音 7:13–14"> 假若那城裡有五十個義人，你還剿滅那地方嗎？不為城裡這五十個義人饒恕其中的人嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 8:3; 以賽亞書 3:10–11; 約伯記 8:20"> 將義人與惡人同殺，將義人與惡人一樣看待，這斷不是你所行的！審判全地的主，豈不行公義嗎？」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 5:1; 馬太福音 24:22; 以賽亞書 65:8"> 耶和華說：「我若在所多瑪城裡見有五十個義人，我就為他們的緣故饒恕那地方的眾人。」</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 3:19; 以賽亞書 6:5; 哥林多前書 15:47–48"> 亞伯拉罕說：「我雖然是灰塵，還敢對主說話。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 18:29; 列王紀上 20:32–33; 創世記 18:26"> 假若這五十個義人短了五個，你就因為短了五個毀滅全城嗎？」他說：「我在那裡若見有四十五個，也不毀滅那城。」</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 6:18; 希伯來書 4:16"> 亞伯拉罕又對他說：「假若在那裡見有四十個怎麼樣呢？」他說：「為這四十個的緣故，我也不做這事。」</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 89:7; 詩篇 9:12; 以斯帖記 4:11–16"> 亞伯拉罕說：「求主不要動怒，容我說，假若在那裡見有三十個怎麼樣呢？」他說：「我在那裡若見有三十個，我也不做這事。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 11:8; 創世記 18:27; 路加福音 18:1"> 亞伯拉罕說：「我還敢對主說話，假若在那裡見有二十個怎麼樣呢？」他說：「為這二十個的緣故，我也不毀滅那城。」</span>
<span className="v" id="v32" data-v="32" data-xref="雅各書 5:15–17; 士師記 6:39; 馬太福音 7:7"> 亞伯拉罕說：「求主不要動怒，我再說這一次，假若在那裡見有十個呢？」他說：「為這十個的緣故，我也不毀滅那城。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 18:22; 創世記 32:26; 創世記 31:55"> 耶和華與亞伯拉罕說完了話就走了，亞伯拉罕也回到自己的地方去了。</span>
</div>

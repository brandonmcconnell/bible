## 變亂口音

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="詩篇 2:1–4; 創世記 3:22; 創世記 11:1"> 耶和華說：「看哪，他們成為一樣的人民，都是一樣的言語，如今既做起這事來，以後他們所要做的事就沒有不成就的了。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 33:10; 詩篇 55:9; 約伯記 5:12–13"> 我們下去，在那裡變亂他們的口音，使他們的言語彼此不通。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命記 32:8; 創世記 10:25"> 於是，耶和華使他們從那裡分散在全地上，他們就停工不造那城了。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 10:10; 創世記 10:5; 創世記 10:20"> 因為耶和華在那裡變亂天下人的言語，使眾人分散在全地上，所以那城名叫巴別<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是「變亂」的意思。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 1:17–27; 創世記 10:21–22; 路加福音 3:34–36"> 閃的後代記在下面。洪水以後二年，閃一百歲生了亞法撒。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 9:7; 詩篇 144:12; 創世記 1:28"> 閃生亞法撒之後，又活了五百年，並且生兒養女。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亞法撒活到三十五歲，生了沙拉。</span>
<span className="v" id="v13" data-v="13"> 亞法撒生沙拉之後，又活了四百零三年，並且生兒養女。</span>
<span className="v" id="v14" data-v="14"> 沙拉活到三十歲，生了希伯。</span>
<span className="v" id="v15" data-v="15"> 沙拉生希伯之後，又活了四百零三年，並且生兒養女。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 10:21; 歷代志上 1:19; 民數記 24:24"> 希伯活到三十四歲，生了法勒。</span>
<span className="v" id="v17" data-v="17"> 希伯生法勒之後，又活了四百三十年，並且生兒養女。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒活到三十歲，生了拉吳。</span>
<span className="v" id="v19" data-v="19"> 法勒生拉吳之後，又活了二百零九年，並且生兒養女。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吳活到三十二歲，生了西鹿。</span>
<span className="v" id="v21" data-v="21"> 拉吳生西鹿之後，又活了二百零七年，並且生兒養女。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 24:2"> 西鹿活到三十歲，生了拿鶴。</span>
<span className="v" id="v23" data-v="23"> 西鹿生拿鶴之後，又活了二百年，並且生兒養女。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 約書亞記 24:2"> 拿鶴活到二十九歲，生了他拉。</span>
<span className="v" id="v25" data-v="25"> 拿鶴生他拉之後，又活了一百一十九年，並且生兒養女。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 24:2; 歷代志上 1:26–27; 創世記 22:20–24"> 他拉活到七十歲，生了亞伯蘭、拿鶴、哈蘭。</span>
</div>

## 亞伯蘭離吾珥往迦南

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 12:4; 創世記 14:12; 創世記 11:31"> 他拉的後代記在下面。他拉生亞伯蘭、拿鶴、哈蘭。哈蘭生羅得。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:7; 尼希米記 9:7; 使徒行傳 7:2–4"> 哈蘭死在他的本地迦勒底的吾珥，在他父親他拉之先。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:15; 創世記 22:20; 創世記 24:15"> 亞伯蘭、拿鶴各娶了妻：亞伯蘭的妻子名叫撒萊；拿鶴的妻子名叫密迦，是哈蘭的女兒，哈蘭是密迦和亦迦的父親。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 29:31; 創世記 21:1–2; 路加福音 1:7"> 撒萊不生育，沒有孩子。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 9:7; 使徒行傳 7:2–4; 創世記 24:10"> 他拉帶著他兒子亞伯蘭和他孫子哈蘭的兒子羅得，並他兒婦亞伯蘭的妻子撒萊，出了迦勒底的吾珥，要往迦南地去。他們走到哈蘭，就住在那裡。</span>
<span className="v" id="v32" data-v="32"> 他拉共活了二百零五歲，就死在哈蘭。</span>
</div>

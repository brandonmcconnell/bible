## 亞伯拉罕繼娶基土拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 1:32–33; 創世記 23:1–2; 創世記 28:1"> 亞伯拉罕又娶了一妻，名叫基土拉。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 1:32–33; 民數記 25:17–18; 約伯記 2:11"> 基土拉給他生了心蘭、約珊、米但、米甸、伊施巴和書亞。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 25:13; 耶利米書 49:8; 以西結書 27:20"> 約珊生了示巴和底但，底但的子孫是亞書利族、利都是族和利烏米族。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 60:6"> 米甸的兒子是以法、以弗、哈諾、亞比大和以勒大。這都是基土拉的子孫。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:36; 希伯來書 1:2; 加拉太書 3:29"> 亞伯拉罕將一切所有的都給了以撒。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 21:14; 士師記 6:3; 使徒行傳 14:17"> 亞伯拉罕把財物分給他庶出的眾子，趁著自己還在世的時候，打發他們離開他的兒子以撒往東方去。</span>
</div>
</div>

## 亞伯拉罕壽終

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 12:4"> 亞伯拉罕一生的年日是一百七十五歲。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:28–29; 創世記 15:15; 歷代志上 29:28"> 亞伯拉罕壽高年邁，氣絕而死，歸到他列祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：本民。">a</a></sup>那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 50:13; 創世記 35:29; 創世記 49:29–30"> 他兩個兒子以撒、以實瑪利把他埋葬在麥比拉洞裡。這洞在幔利前，赫人瑣轄的兒子以弗崙的田中，</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 23:16; 創世記 49:31"> 就是亞伯拉罕向赫人買的那塊田。亞伯拉罕和他妻子撒拉都葬在那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 創世記 16:14; 創世記 24:62"> 亞伯拉罕死了以後，神賜福給他的兒子以撒。以撒靠近庇耳拉海萊居住。</span>
</div>
</div>

## 以實瑪利之後裔

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:6; 創世記 17:20; 創世記 21:13"> 撒拉的使女埃及人夏甲給亞伯拉罕所生的兒子是以實瑪利。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 1:29–31; 以賽亞書 60:7; 雅歌 1:5"> 以實瑪利兒子們的名字，按著他們的家譜記在下面。以實瑪利的長子是尼拜約，又有基達、亞德別、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 21:11; 以賽亞書 21:16"> 米施瑪、度瑪、瑪撒、</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 5:19; 約伯記 2:11"> 哈大、提瑪、伊突、拿非施、基底瑪。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:20; 創世記 17:23"> 這是以實瑪利眾子的名字，照著他們的村莊、營寨，做了十二族的族長。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:15; 創世記 25:7–8"> 以實瑪利享壽一百三十七歲，氣絕而死，歸到他列祖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：本民。">b</a></sup>那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 16:12; 創世記 20:1; 列王紀下 23:29"> 他子孫的住處在他眾弟兄東邊，從哈腓拉直到埃及前的書珥，正在亞述的道上。</span>
</div>
</div>

## 以掃雅各生

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 1:2; 路加福音 3:34; 使徒行傳 7:8"> 亞伯拉罕的兒子以撒的後代記在下面。亞伯拉罕生以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:29; 創世記 24:67; 創世記 22:23"> 以撒娶利百加為妻的時候正四十歲，利百加是巴旦亞蘭地的亞蘭人彼土利的女兒，是亞蘭人拉班的妹子。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以賽亞書 58:9; 以斯拉記 8:23"> 以撒因他妻子不生育，就為她祈求耶和華。耶和華應允他的祈求，他的妻子利百加就懷了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 9:9; 撒母耳記上 28:6; 撒母耳記上 30:8"> 孩子們在她腹中彼此相爭，她就說：「若是這樣，我為什麼活著呢<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：我為什麼如此呢。">c</a></sup>？」她就去求問耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 9:10–13; 創世記 27:40; 創世記 27:29"> 耶和華對她說：<br /><span className="pl pl-1">「兩國在你腹內，</span><br /><span className="pl pl-1">兩族要從你身上出來，</span><br /><span className="pl pl-1">這族必強於那族，</span><br /><span className="pl pl-1">將來大的要服侍小的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 生產的日子到了，腹中果然是雙子。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:11; 創世記 27:16; 創世記 27:23"> 先產的身體發紅，渾身有毛，如同皮衣，他們就給他起名叫以掃<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「以掃」就是「有毛」的意思。">d</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:36; 何西阿書 12:3; 創世記 38:28–30"> 隨後又生了以掃的兄弟，手抓住以掃的腳跟，因此給他起名叫雅各<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「雅各」就是「抓住」的意思。">e</a></sup>。利百加生下兩個兒子的時候，以撒年正六十歲。</span>
</div>
</div>

## 以掃賣長子之分

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯來書 11:9; 創世記 21:20; 創世記 10:9"> 兩個孩子漸漸長大，以掃善於打獵，常在田野，雅各為人安靜，常住在帳篷裡。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 27:19; 創世記 27:31; 創世記 27:4"> 以撒愛以掃，因為常吃他的野味，利百加卻愛雅各。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以賽亞書 40:30–31; 撒母耳記上 14:28"> 有一天，雅各熬湯，以掃從田野回來累昏了。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 36:1; 出埃及記 15:15; 創世記 36:9"> 以掃對雅各說：「我累昏了，求你把這紅湯給我喝。」因此以掃又叫以東<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="「以東」就是「紅」的意思。">f</a></sup>。</span>
<span className="v" id="v31" data-v="31"> 雅各說：「你今日把長子的名分賣給我吧。」</span>
<span className="v" id="v32" data-v="32" data-xref="瑪拉基書 3:14; 約伯記 21:15; 約伯記 22:17"> 以掃說：「我將要死，這長子的名分於我有什麼益處呢？」</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 12:16; 創世記 27:36; 希伯來書 6:16"> 雅各說：「你今日對我起誓吧。」以掃就對他起了誓，把長子的名分賣給雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比書 3:18–19; 希伯來書 12:16–17; 哥林多前書 15:32"> 於是雅各將餅和紅豆湯給了以掃，以掃吃了喝了，便起來走了。這就是以掃輕看了他長子的名分。</span>
</div>
</div>

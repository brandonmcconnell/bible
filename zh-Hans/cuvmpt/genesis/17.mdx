## 神易亞伯蘭名為亞伯拉罕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比書 4:13; 以弗所書 3:20; 路加福音 1:6"> 亞伯蘭年九十九歲的時候，耶和華向他顯現，對他說：「我是全能的神，你當在我面前做完全人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:4–6; 創世記 12:2; 詩篇 105:8–11"> 我就與你立約，使你的後裔極其繁多。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 13:20; 創世記 17:17; 民數記 16:45"> 亞伯蘭俯伏在地，神又對他說：</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:11; 加拉太書 3:28–29; 創世記 12:2"> 「我與你立約：你要做多國的父。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 1:21–23; 尼希米記 9:7; 創世記 17:15"> 從此以後，你的名不再叫亞伯蘭，要叫亞伯拉罕，因為我已立你做多國的父。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 17:4; 馬太福音 1:6–17; 創世記 35:11"> 我必使你的後裔極其繁多，國度從你而立，君王從你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:7–9; 使徒行傳 2:39; 創世記 26:24"> 我要與你並你世世代代的後裔堅立我的約，做永遠的約，是要做你和你後裔的神。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 26:12; 詩篇 105:11; 出埃及記 6:7"> 我要將你現在寄居的地，就是迦南全地，賜給你和你的後裔永遠為業，我也必做他們的神。」</span>
</div>
</div>

## 始定割禮

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 56:4–5; 詩篇 25:10; 詩篇 103:18"> 神又對亞伯拉罕說：「你和你的後裔，必世世代代遵守我的約。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 2:11–12; 羅馬書 4:9–11; 使徒行傳 7:8"> 你們所有的男子都要受割禮，這就是我與你並你的後裔所立的約，是你們所當遵守的。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 4:11; 使徒行傳 7:8; 申命記 10:16"> 你們都要受割禮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「受割禮」原文作「割陽皮」 ，14、23、24、25節同。">a</a></sup>，這是我與你們立約的證據。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 12:3; 路加福音 2:21; 出埃及記 12:48–49"> 你們世世代代的男子，無論是家裡生的，是在你後裔之外用銀子從外人買的，生下來第八日，都要受割禮。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 12:44; 創世記 37:36; 尼希米記 5:8"> 你家裡生的和你用銀子買的，都必須受割禮。這樣，我的約就立在你們肉體上做永遠的約。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 4:24–26; 民數記 15:30–31; 出埃及記 12:19"> 但不受割禮的男子，必從民中剪除，因他背了我的約。」</span>
</div>
</div>

## 易撒萊名為撒拉

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 12:25; 創世記 32:28; 創世記 17:5"> 神又對亞伯拉罕說：「你的妻子撒萊，不可再叫撒萊，她的名要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:11; 創世記 17:6; 以賽亞書 49:23"> 我必賜福給她，也要使你從她得一個兒子。我要賜福給她，她也要做多國之母，必有百姓的君王從她而出。」</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 11:16; 創世記 21:6; 創世記 18:12"> 亞伯拉罕就俯伏在地喜笑，心裡說：「一百歲的人還能得孩子嗎？撒拉已經九十歲了，還能生養嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 2:39; 詩篇 41:12; 詩篇 4:6"> 亞伯拉罕對神說：「但願以實瑪利活在你面前。」</span>
</div>
</div>

## 應許生以撒

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 創世記 21:2–3; 列王紀下 4:16–17"> 神說：「不然，你妻子撒拉要給你生一個兒子，你要給他起名叫以撒。我要與他堅定所立的約，做他後裔永遠的約。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:18; 創世記 21:13; 創世記 25:12–18"> 至於以實瑪利，我也應允你，我必賜福給他，使他昌盛，極其繁多。他必生十二個族長，我也要使他成為大國。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:2–3; 創世記 26:2–5; 加拉太書 3:29"> 到明年這時節，撒拉必給你生以撒，我要與他堅定所立的約。」</span>
</div>
</div>

## 始受割禮

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 18:33; 創世記 35:9–15; 士師記 6:21"> 神和亞伯拉罕說完了話，就離開他上升去了。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:60; 創世記 18:19; 創世記 17:10–14"> 正當那日，亞伯拉罕遵著神的命，給他的兒子以實瑪利和家裡的一切男子，無論是在家裡生的，是用銀子買的，都行了割禮。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 4:11; 創世記 17:17; 羅馬書 4:19–20"> 亞伯拉罕受割禮的時候，年九十九歲。</span>
<span className="v" id="v25" data-v="25"> 他兒子以實瑪利受割禮的時候，年十三歲。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:60; 創世記 22:3–4; 創世記 12:4"> 正當那日，亞伯拉罕和他兒子以實瑪利，一同受了割禮。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 18:19"> 家裡所有的人，無論是在家裡生的，是用銀子從外人買的，也都一同受了割禮。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="創世記 26:1; 創世記 26:6; 創世記 18:1"> 亞伯拉罕從那裡向南地遷去，寄居在加低斯和書珥中間的基拉耳。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:15; 創世記 26:7; 創世記 12:11–13"> 亞伯拉罕稱他的妻撒拉為妹子，基拉耳王亞比米勒差人把撒拉取了去。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 20:7; 馬太福音 27:19; 詩篇 105:14"> 但夜間神來在夢中對亞比米勒說：「你是個死人哪！因為你取了那女人來，她原是別人的妻子。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 18:23–25; 歷代志上 21:17; 撒母耳記下 4:11"> 亞比米勒卻還沒有親近撒拉，他說：「主啊，連有義的國，你也要毀滅嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 7:8; 列王紀上 9:4; 但以理書 6:22"> 那人豈不是自己對我說『她是我的妹子』嗎？就是女人也自己說『他是我的哥哥』。我做這事是心正手潔的。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 25:34; 箴言 21:1; 撒母耳記上 25:26"> 神在夢中對他說：「我知道你做這事是心中正直，我也攔阻了你，免得你得罪我。所以我不容你沾著她。</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 42:8; 撒母耳記上 7:5; 撒母耳記下 24:17"> 現在你把這人的妻子歸還他，因為他是先知，他要為你禱告，使你存活。你若不歸還他，你當知道，你和你所有的人都必要死。」</span>

## 亞比米勒責亞伯拉罕

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 亞比米勒清早起來，召了眾臣僕來，將這些事都說給他們聽，他們都甚懼怕。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:18; 創世記 26:10; 創世記 39:9"> 亞比米勒召了亞伯拉罕來，對他說：「你怎麼向我這樣行呢？我在什麼事上得罪了你，你竟使我和我國裡的人陷在大罪裡？你向我行不當行的事了。」</span>
<span className="v" id="v10" data-v="10"> 亞比米勒又對亞伯拉罕說：「你見了什麼才做這事呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 26:7; 創世記 12:12; 約伯記 28:28"> 亞伯拉罕說：「我以為這地方的人總不懼怕神，必為我妻子的緣故殺我。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:29; 創世記 12:13; 帖撒羅尼迦前書 5:22"> 況且她也實在是我的妹子，她與我是同父異母，後來做了我的妻子。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 12:1; 創世記 12:9; 使徒行傳 7:3–5"> 當神叫我離開父家，漂流在外的時候，我對她說：『我們無論走到什麼地方，你可以對人說「他是我的哥哥」，這就是你待我的恩典了。』」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 12:16; 創世記 20:2; 創世記 20:7"> 亞比米勒把牛、羊、僕婢賜給亞伯拉罕，又把他的妻子撒拉歸還他。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 34:10; 創世記 13:9; 創世記 47:6"> 亞比米勒又說：「看哪，我的地都在你面前，你可以隨意居住。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:5; 創世記 20:5; 創世記 24:65"> 又對撒拉說：「我給你哥哥一千銀子，作為你在合家人面前遮羞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「羞」原文作「眼」。">a</a></sup>的，你就在眾人面前沒有不是了。」</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 5:16; 馬太福音 21:22; 約伯記 42:9–10"> 亞伯拉罕禱告神，神就醫好了亞比米勒和他的妻子，並他的眾女僕，她們便能生育。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 12:17; 創世記 30:2; 創世記 16:2"> 因耶和華為亞伯拉罕的妻子撒拉的緣故，已經使亞比米勒家中的婦人不能生育。</span>
</div>

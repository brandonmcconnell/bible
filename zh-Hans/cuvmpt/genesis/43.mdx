## 雅各遣子再往糴糧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 使徒行傳 7:11–13; 耶利米哀歌 5:10"> 那地的饑荒甚大。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 6:6–8; 箴言 16:18; 箴言 15:16"> 他們從埃及帶來的糧食吃盡了，他們的父親就對他們說：「你們再去給我糴些糧來。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 44:23; 創世記 43:5; 撒母耳記下 3:13"> 猶大對他說：「那人諄諄地告誡我們說：『你們的兄弟若不與你們同來，你們就不得見我的面。』</span>
<span className="v" id="v4" data-v="4"> 你若打發我們的兄弟與我們同去，我們就下去給你糴糧。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 20:12; 創世記 44:26; 創世記 42:38"> 你若不打發他去，我們就不下去，因為那人對我們說：『你們的兄弟若不與你們同來，你們就不得見我的面。』」</span>
<span className="v" id="v6" data-v="6"> 以色列說：「你們為什麼這樣害我，告訴那人你們還有兄弟呢？」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 43:3; 創世記 42:13; 創世記 43:27"> 他們回答說：「那人詳細問到我們和我們的親屬，說：『你們的父親還在嗎？你們還有兄弟嗎？』我們就按著他所問的告訴他，焉能知道他要說，必須把你們的兄弟帶下來呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 42:2; 申命記 33:6; 創世記 45:19"> 猶大又對他父親以色列說：「你打發童子與我同去，我們就起身下去，好叫我們和你，並我們的婦人孩子，都得存活，不至於死。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 42:37; 腓利門書 1:18–19; 希伯來書 7:22"> 我為他作保，你可以從我手中追討。我若不帶他回來交在你面前，我情願永遠擔罪。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:16"> 我們若沒有耽擱，如今第二次都回來了。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 37:25; 耶利米書 8:22; 以西結書 27:17"> 他們的父親以色列說：「若必須如此，你們就當這樣行：可以將這地土產中最好的乳香、蜂蜜、香料、沒藥、榧子、杏仁都取一點，收在器具裡，帶下去送給那人做禮物。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:25; 創世記 42:35; 帖撒羅尼迦前書 4:6"> 又要手裡加倍地帶銀子，並將歸還在你們口袋內的銀子仍帶在手裡，那或者是錯了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 42:38"> 也帶著你們的兄弟，起身去見那人。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 4:16; 創世記 17:1; 使徒行傳 21:14"> 但願全能的神使你們在那人面前蒙憐憫，釋放你們的那弟兄和便雅憫回來。我若喪了兒子，就喪了吧！」</span>
<span className="v" id="v15" data-v="15"> 於是，他們拿著那禮物，又手裡加倍地帶銀子，並且帶著便雅憫，起身下到埃及，站在約瑟面前。</span>
</div>
</div>

## 約瑟為弟兄設席

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 44:1; 創世記 43:19; 創世記 24:2–10"> 約瑟見便雅憫和他們同來，就對家宰說：「將這些人領到屋裡，要宰殺牲畜，預備筵席，因為晌午這些人同我吃飯。」</span>
<span className="v" id="v17" data-v="17"> 家宰就遵著約瑟的命去行，領他們進約瑟的屋裡。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 42:35; 羅馬書 7:8; 創世記 42:21"> 他們因為被領到約瑟的屋裡，就害怕，說：「領我們到這裡來，必是因為頭次歸還在我們口袋裡的銀子，找我們的錯縫，下手害我們，強取我們為奴僕，搶奪我們的驢。」</span>
<span className="v" id="v19" data-v="19"> 他們就挨近約瑟的家宰，在屋門口和他說話，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 42:3; 創世記 42:10; 創世記 42:27"> 說：「我主啊，我們頭次下來實在是要糴糧。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:12; 創世記 42:27–35; 羅馬書 13:8"> 後來到了住宿的地方，我們打開口袋，不料，各人的銀子分量足數，仍在各人的口袋內，現在我們手裡又帶回來了。</span>
<span className="v" id="v22" data-v="22"> 另外又帶下銀子來糴糧。不知道先前誰把銀子放在我們的口袋裡。」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 20:26; 創世記 42:24; 約翰福音 14:27"> 家宰說：「你們可以放心，不要害怕，是你們的神和你們父親的神賜給你們財寶在你們的口袋裡。你們的銀子我早已收了。」他就把西緬帶出來，交給他們。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 18:4; 創世記 24:32; 路加福音 7:44"> 家宰就領他們進約瑟的屋裡，給他們水洗腳，又給他們草料餵驢。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:11; 創世記 43:16"> 他們就預備那禮物，等候約瑟晌午來，因為他們聽見要在那裡吃飯。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="腓立比書 2:10–11; 創世記 27:29; 創世記 42:6"> 約瑟來到家裡，他們就把手中的禮物拿進屋去給他，又俯伏在地向他下拜。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 42:13; 撒母耳記上 25:5; 撒母耳記上 17:22"> 約瑟問他們好，又問：「你們的父親，就是你們所說的那老人家，平安嗎？他還在嗎？」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:7; 創世記 43:26; 撒母耳記下 14:4"> 他們回答說：「你僕人我們的父親平安，他還在。」於是他們低頭下拜。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:13; 民數記 6:25; 創世記 30:22–24"> 約瑟舉目看見他同母的兄弟便雅憫，就說：「你們向我所說那頂小的兄弟就是這位嗎？」又說：「小兒啊，願神賜恩給你！」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:24; 耶利米書 31:20; 列王紀上 3:26"> 約瑟愛弟之情發動，就急忙尋找可哭之地，進入自己的屋裡，哭了一場。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 45:1; 彼得前書 3:10; 以賽亞書 42:14"> 他洗了臉出來，勉強隱忍，吩咐人擺飯。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 46:34; 出埃及記 8:26; 創世記 43:16"> 他們就為約瑟單擺了一席，為那些人又擺了一席，也為和約瑟同吃飯的埃及人另擺了一席，因為埃及人不可和希伯來人一同吃飯，那原是埃及人所厭惡的。</span>
<span className="v" id="v33" data-v="33"> 約瑟使眾弟兄在他面前排列坐席，都按著長幼的次序，眾弟兄就彼此詫異。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 45:22; 撒母耳記下 11:8; 撒母耳記上 1:5"> 約瑟把他面前的食物分出來，送給他們，但便雅憫所得的比別人多五倍。他們就飲酒，和約瑟一同宴樂。</span>
</div>
</div>

## 約瑟用策留弟以試諸兄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 42:25; 創世記 43:16; 創世記 24:2"> 約瑟吩咐家宰說：「把糧食裝滿這些人的口袋，儘著他們的驢所能馱的，又把各人的銀子放在各人的口袋裡，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 8:8; 創世記 42:20; 申命記 8:16"> 並將我的銀杯和那少年人糴糧的銀子一同裝在他的口袋裡。」家宰就照約瑟所說的話行了。</span>
<span className="v" id="v3" data-v="3"> 天一亮就打發那些人帶著驢走了。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:32; 詩篇 35:12; 箴言 17:13"> 他們出城走了不遠，約瑟對家宰說：「起來，追那些人去，追上了就對他們說：『你們為什麼以惡報善呢？</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; 利未記 19:26; 列王紀下 21:6"> 這不是我主人飲酒的杯嗎？豈不是他占卜用的嗎？你們這樣行是作惡了。』」</span>
<span className="v" id="v6" data-v="6"> 家宰追上他們，將這些話對他們說了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 38:16–18; 創世記 37:18–32; 列王紀下 8:13"> 他們回答說：「我主為什麼說這樣的話呢？你僕人斷不能做這樣的事。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 43:12; 創世記 42:35; 羅馬書 13:9"> 你看，我們從前在口袋裡所見的銀子，尚且從迦南地帶來還你，我們怎能從你主人家裡偷竊金銀呢？</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:32; 詩篇 7:3–5; 約伯記 31:38–40"> 你僕人中無論在誰那裡搜出來，就叫他死，我們也做我主的奴僕。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 22:3; 創世記 44:17; 創世記 44:33"> 家宰說：「現在就照你們的話行吧！在誰那裡搜出來，誰就做我的奴僕，其餘的都沒有罪。」</span>
<span className="v" id="v11" data-v="11"> 於是他們各人急忙把口袋卸在地下，各人打開口袋。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 44:26–32; 創世記 42:36–38; 創世記 43:14"> 家宰就搜查，從年長的起，到年幼的為止，那杯竟在便雅憫的口袋裡搜出來。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 1:11; 創世記 37:29–34; 撒母耳記下 1:2"> 他們就撕裂衣服，各人把馱子抬在驢上，回城去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 50:18; 創世記 43:25; 創世記 43:16"> 猶大和他弟兄們來到約瑟的屋中，約瑟還在那裡，他們就在他面前俯伏於地。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 4:10; 創世記 21:26; 創世記 3:13"> 約瑟對他們說：「你們做的是什麼事呢？你們豈不知像我這樣的人必能占卜嗎？」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 44:9; 但以理書 9:7; 民數記 32:23"> 猶大說：「我們對我主說什麼呢？還有什麼話可說呢？我們怎能自己表白出來呢？神已經查出僕人的罪孽了，我們與那在他手中搜出杯來的都是我主的奴僕。」</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳記下 23:3; 創世記 18:25"> 約瑟說：「我斷不能這樣行。在誰的手中搜出杯來，誰就做我的奴僕。至於你們，可以平平安安地上你們父親那裡去。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 32:22; 創世記 41:40; 創世記 18:30"> 猶大挨近他，說：「我主啊，求你容僕人說一句話給我主聽，不要向僕人發烈怒，因為你如同法老一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 43:7; 創世記 43:29; 創世記 42:7–10"> 我主曾問僕人們說：『你們有父親有兄弟沒有？』</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 37:3; 創世記 42:38; 路加福音 7:12"> 我們對我主說：『我們有父親，已經年老，還有他老年所生的一個小孩子。他哥哥死了，他母親只撇下他一人，他父親疼愛他。』</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:15; 創世記 42:20; 阿摩司書 9:4"> 你對僕人說：『把他帶到我這裡來，叫我親眼看看他。』</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 44:30; 創世記 42:38"> 我們對我主說：『童子不能離開他父親，若是離開，他父親必死。』</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 43:5; 創世記 43:3; 創世記 42:15–20"> 你對僕人說：『你們的小兄弟若不與你們一同下來，你們就不得再見我的面。』</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 42:29–34"> 我們上到你僕人我們父親那裡，就把我主的話告訴了他。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:2; 創世記 43:5"> 我們的父親說：『你們再去給我糴些糧來。』</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 創世記 43:4–5"> 我們就說：『我們不能下去。我們的小兄弟若和我們同往，我們就可以下去，因為小兄弟若不與我們同往，我們必不得見那人的面。』</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 46:19; 創世記 35:16–18; 創世記 30:22–25"> 你僕人我父親對我們說：『你們知道我的妻子給我生了兩個兒子，</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:33; 創世記 37:13–14; 創世記 42:36"> 一個離開我出去了，我說他必是被撕碎了，直到如今我也沒有見他。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:38; 創世記 43:14; 申命記 31:17"> 現在你們又要把這個帶去離開我。倘若他遭害，那便是你們使我白髮蒼蒼、悲悲慘慘地下陰間去了。』</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 18:1; 撒母耳記下 18:33; 創世記 44:31"> 我父親的命與這童子的命相連，如今我回到你僕人我父親那裡，若沒有童子與我們同在，</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 44:29; 創世記 37:35; 哥林多後書 7:10"> 我們的父親見沒有童子，他就必死。這便是我們使你僕人我們的父親白髮蒼蒼、悲悲慘慘地下陰間去了。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 43:8–9; 創世記 43:16"> 因為僕人曾向我父親為這童子作保，說：『我若不帶他回來交給父親，我便在父親面前永遠擔罪。』</span>
<span className="v" id="v33" data-v="33" data-xref="約翰一書 3:16; 出埃及記 32:32; 希伯來書 7:22"> 現在求你容僕人住下，替這童子做我主的奴僕，叫童子和他哥哥們一同上去。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖記 8:6; 詩篇 116:3; 詩篇 119:143"> 若童子不和我同去，我怎能上去見我父親呢？恐怕我看見災禍臨到我父親身上。」</span>
</div>

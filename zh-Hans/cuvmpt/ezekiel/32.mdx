## 哀嘆埃及之災

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 30:20; 以西結書 32:17; 以西結書 31:1"> 十二年十二月初一日，耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 29:3; 那鴻書 2:11–13; 以西結書 27:2"> 「人子啊，你要為埃及王法老作哀歌，說：<br /><span className="pl pl-1">『從前你在列國中如同少壯獅子，</span><br /><span className="pl pl-1">現在你卻像海中的大魚。</span><br /><span className="pl pl-1">你衝出江河，</span><br /><span className="pl pl-1">用爪攪動諸水，</span><br /><span className="pl pl-1">使江河渾濁。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西結書 12:13; 耶利米書 16:16; 傳道書 9:12"> 主耶和華如此說：<br /><span className="pl pl-1">我必用多國的人民，</span><br /><span className="pl pl-1">將我的網撒在你身上，</span><br /><span className="pl pl-1">把你拉上來。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 18:6; 以西結書 29:5; 以西結書 31:12–13"> <span className="pl pl-1">我必將你丟在地上，</span><br /><span className="pl pl-1">拋在田野，</span><br /><span className="pl pl-1">使空中的飛鳥都落在你身上，</span><br /><span className="pl pl-1">使遍地的野獸吃你得飽。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 31:12"> <span className="pl pl-1">我必將你的肉丟在山間，</span><br /><span className="pl pl-1">用你高大的屍首填滿山谷。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 34:3; 以賽亞書 34:7; 啟示錄 14:20"> <span className="pl pl-1">我又必用你的血澆灌你所游泳之地，</span><br /><span className="pl pl-1">漫過山頂，</span><br /><span className="pl pl-1">河道都必充滿。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 24:29; 約珥書 2:31; 以賽亞書 13:10"> <span className="pl pl-1">我將你撲滅的時候，</span><br /><span className="pl pl-1">要把天遮蔽，</span><br /><span className="pl pl-1">使眾星昏暗，</span><br /><span className="pl pl-1">以密雲遮掩太陽，</span><br /><span className="pl pl-1">月亮也不放光。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:14; 箴言 20:20"> <span className="pl pl-1">我必使天上的亮光都在你以上變為昏暗，</span><br /><span className="pl pl-1">使你的地上黑暗。</span><br /><span className="pl pl-1">這是主耶和華說的。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 18:10–15; 以西結書 30:26; 耶利米書 25:15–25"> 我使你敗亡的風聲傳到你所不認識的各國，那時，我必使多民的心因你愁煩。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 26:16; 以西結書 27:35; 列王紀上 9:8"> 我在許多國民和君王面前向你掄我的刀，國民就必因你驚奇，君王也必因你極其恐慌。在你仆倒的日子，他們各人為自己的性命時刻戰兢。</span>
</div>
</div>

## 必為巴比倫王殲滅

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 43:10; 以西結書 26:7; 以西結書 30:22–25"> 『主耶和華如此說：巴比倫王的刀必臨到你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 28:7; 以西結書 29:19; 以西結書 31:11"> 我必藉勇士的刀使你的眾民仆倒，這勇士都是列國中強暴的。<br /><span className="pl pl-1">他們必使埃及的驕傲歸於無有，</span><br /><span className="pl pl-1">埃及的眾民必被滅絕。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 29:11; 以西結書 29:8; 以西結書 30:12"> <span className="pl pl-1">我必從埃及多水旁除滅所有的走獸，</span><br /><span className="pl pl-1">人腳、獸蹄必不再攪渾這水。</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">那時，我必使埃及河澄清，</span><br /><span className="pl pl-1">江河像油緩流。</span><br /><span className="pl pl-1">這是主耶和華說的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 6:7; 出埃及記 7:5; 出埃及記 14:4"> <span className="pl pl-1">我使埃及地變為荒廢淒涼，</span><br /><span className="pl pl-1">這地缺少從前所充滿的，</span><br /><span className="pl pl-1">又擊殺其中一切的居民，</span><br /><span className="pl pl-1">那時他們就知道我是耶和華。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 1:17; 歷代志下 35:25; 以西結書 26:17"> 人必用這哀歌去哀哭，列國的女子為埃及和他的群眾也必以此悲哀。這是主耶和華說的。』」</span>
</div>
</div>

## 埃及之淪亡

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 32:1; 以西結書 33:21; 以西結書 1:2"> 十二年十二月十五日，耶和華的話臨到我說：</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 31:14; 以西結書 32:2; 耶利米書 1:10"> 「人子啊，你要為埃及群眾哀號，又要將埃及和有名之國的女子，並下坑的人一同扔到陰府去。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 31:18; 以西結書 32:29–30; 耶利米書 9:25–26"> 你埃及的美麗勝過誰呢？你下去，與未受割禮的人一同躺臥吧！</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 28:3; 以西結書 32:23–26; 以西結書 32:29–30"> 他們必在被殺的人中仆倒，她被交給刀劍，要把她和她的群眾拉去。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 14:9–10; 以西結書 32:27; 以西結書 32:19"> 強盛的勇士要在陰間對埃及王和幫助他的說話：『他們是未受割禮被殺的人，已經下去，躺臥不動。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 32:26; 以西結書 32:29–30; 以西結書 32:24"> 「亞述和她的眾民都在那裡，她民的墳墓在她四圍，他們都是被殺倒在刀下的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 26:20; 以西結書 32:24–27; 詩篇 27:13"> 他們的墳墓在坑中極深之處，她的眾民在他墳墓的四圍，都是被殺倒在刀下的。他們曾在活人之地使人驚恐。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西結書 32:18; 以西結書 26:20; 耶利米書 49:34–39"> 「以攔也在那裡，她的群眾在她墳墓的四圍，都是被殺倒在刀下，未受割禮而下陰府的。他們曾在活人之地使人驚恐，並且與下坑的人一同擔當羞辱。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 139:8; 歷代志上 10:4; 撒母耳記下 1:20"> 人給她和她的群眾在被殺的人中設立床榻，她民的墳墓在她四圍，他們都是未受割禮被刀殺的。他們曾在活人之地使人驚恐，並且與下坑的人一同擔當羞辱。以攔已經放在被殺的人中。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西結書 27:13; 創世記 10:2; 以西結書 38:2–3"> 「米設、土巴和她們的群眾都在那裡，她民的墳墓在她四圍，他們都是未受割禮被刀殺的。他們曾在活人之地使人驚恐。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 14:18–19; 約伯記 3:13–15; 以西結書 32:21"> 他們不得與那未受割禮仆倒的勇士一同躺臥，這些勇士帶著兵器下陰間，頭枕刀劍，骨頭上有本身的罪孽。他們曾在活人之地使勇士驚恐。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:34–35"> 法老啊，你必在未受割禮的人中敗壞，與那些被殺的人一同躺臥。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米書 49:7–22; 瑪拉基書 1:3–4; 俄巴底亞書 1:1–9"> 「以東也在那裡，她君王和一切首領雖然仗著勢力，還是放在被殺的人中。他們必與未受割禮的和下坑的人一同躺臥。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 38:6; 以西結書 39:2; 以西結書 28:21"> 在那裡有北方的眾王子和一切西頓人，都與被殺的人下去。他們雖然仗著勢力使人驚恐，還是蒙羞。他們未受割禮，和被刀殺的一同躺臥，與下坑的人一同擔當羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西結書 31:16; 以西結書 14:22; 耶利米哀歌 2:13"> 「法老看見他們，便為他被殺的軍隊受安慰。這是主耶和華說的。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 32:27; 創世記 35:5; 哥林多後書 5:11"> 我任憑法老在活人之地使人驚恐，法老和他的群眾必放在未受割禮和被殺的人中。這是主耶和華說的。」</span>
</div>
</div>

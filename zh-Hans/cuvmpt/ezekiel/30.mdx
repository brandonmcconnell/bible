## 埃及與其同盟必偕敗亡

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 13:6; 以西結書 21:12; 約珥書 1:11"> 「人子啊，你要發預言說：『主耶和華如此說：<br /><span className="pl pl-1">哀哉這日！你們應當哭號。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="俄巴底亞書 1:15; 約珥書 2:1–2; 約珥書 1:15"> <span className="pl pl-1">因為耶和華的日子臨近，</span><br /><span className="pl pl-1">就是密雲之日，</span><br /><span className="pl pl-1">列國受罰之期。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 29:19; 以西結書 29:8; 以賽亞書 16:7"> <span className="pl pl-1">必有刀劍臨到埃及，</span><br /><span className="pl pl-1">在埃及被殺之人仆倒的時候，</span><br /><span className="pl pl-1">古實人就有痛苦；</span><br /><span className="pl pl-1">人民必被擄掠，</span><br /><span className="pl pl-1">基址必被拆毀。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 25:20; 以西結書 27:10; 耶利米書 25:24"> 古實人、弗人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：呂彼亞人。">a</a></sup>、路德人、雜族的人民並古巴人，以及同盟之地的人，都要與埃及人一同倒在刀下。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西結書 29:10; 以賽亞書 20:3–6; 以賽亞書 31:3"> 『耶和華如此說：<br /><span className="pl pl-1">扶助埃及的也必傾倒，</span><br /><span className="pl pl-1">埃及因勢力而有的驕傲必降低微，</span><br /><span className="pl pl-1">其中的人民從色弗尼塔起</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="見29章10節。">b</a></sup><br /><span className="pl pl-1">必倒在刀下。</span><br /><span className="pl pl-1">這是主耶和華說的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 29:12; 耶利米書 25:18–26; 以西結書 32:18–32"> <span className="pl pl-1">埃及地在荒涼的國中必成為荒涼，</span><br /><span className="pl pl-1">埃及城在荒廢的城中也變為荒廢。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 29:6; 以西結書 29:16; 阿摩司書 1:7"> <span className="pl pl-1">我在埃及中使火著起，</span><br /><span className="pl pl-1">幫助埃及的都被滅絕，</span><br /><span className="pl pl-1">那時他們就知道我是耶和華。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 18:1–2; 以賽亞書 23:5; 以西結書 32:9–10"> 到那日，必有使者坐船從我面前出去，使安逸無慮的古實人驚懼；必有痛苦臨到他們，好像埃及遭災的日子一樣。看哪，這事臨近了！</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以西結書 29:19; 以西結書 32:11–16; 以西結書 29:4–5"> 『主耶和華如此說：<br /><span className="pl pl-1">我必藉巴比倫王尼布甲尼撒的手</span><br /><span className="pl pl-1">除滅埃及眾人。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 28:7; 以西結書 32:12; 以西結書 39:11–20"> <span className="pl pl-1">他和隨從他的人，</span><br /><span className="pl pl-1">就是列國中強暴的，</span><br /><span className="pl pl-1">必進來毀滅這地。</span><br /><span className="pl pl-1">他們必拔刀攻擊埃及，</span><br /><span className="pl pl-1">使遍地有被殺的人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 29:3; 那鴻書 1:4; 啟示錄 16:12"> <span className="pl pl-1">我必使江河乾涸，</span><br /><span className="pl pl-1">將地賣在惡人的手中。</span><br /><span className="pl pl-1">我必藉外邦人的手，</span><br /><span className="pl pl-1">使這地和其中所有的變為淒涼。</span><br /><span className="pl pl-1">這是我耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 10:11; 耶利米書 46:14; 耶利米書 2:16"> 『主耶和華如此說：<br /><span className="pl pl-1">我必毀滅偶像，</span><br /><span className="pl pl-1">從挪弗除滅神像。</span><br /><span className="pl pl-1">必不再有君王出自埃及地，</span><br /><span className="pl pl-1">我要使埃及地的人懼怕。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 29:14; 耶利米書 46:25; 詩篇 78:43"> <span className="pl pl-1">我必使巴忒羅荒涼，</span><br /><span className="pl pl-1">在瑣安中使火著起，</span><br /><span className="pl pl-1">向挪施行審判。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 16:1; 那鴻書 1:6; 詩篇 11:6"> <span className="pl pl-1">我必將我的憤怒倒在埃及的保障上，</span><br /><span className="pl pl-1">就是訓上，</span><br /><span className="pl pl-1">並要剪除挪的眾人。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 30:8–9; 以西結書 28:18"> <span className="pl pl-1">我必在埃及中使火著起，</span><br /><span className="pl pl-1">訓必大大痛苦，</span><br /><span className="pl pl-1">挪必被攻破，</span><br /><span className="pl pl-1">挪弗白日</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「白日」或作「終日」。">c</a></sup><br /><span className="pl pl-1">見仇敵。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 41:45"> <span className="pl pl-1">亞文和比伯實的少年人必倒在刀下，</span><br /><span className="pl pl-1">這些城的人必被擄掠。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 30:3; 以西結書 29:15; 以賽亞書 10:27"> <span className="pl pl-1">我在答比匿折斷埃及的諸軛，</span><br /><span className="pl pl-1">使她因勢力而有的驕傲在其中止息，</span><br /><span className="pl pl-1">那時日光必退去。</span><br /><span className="pl pl-1">至於這城，必有密雲遮蔽，</span><br /><span className="pl pl-1">其中的女子必被擄掠。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 30:14; 啟示錄 17:1; 以西結書 5:8"> <span className="pl pl-1">我必這樣向埃及施行審判，</span><br /><span className="pl pl-1">他們就知道我是耶和華。』」</span></span>
</div>
</div>

## 耶和華折法老之臂

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 29:17; 以西結書 26:1; 以西結書 29:1"> 十一年正月初七日，耶和華的話臨到我說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 30:13; 耶利米書 46:11; 詩篇 37:17"> 「人子啊，我已打折埃及王法老的膀臂，沒有敷藥，也沒有用布纏好，使他有力持刀。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 37:17; 耶利米書 37:7; 列王紀下 24:7"> 所以主耶和華如此說：看哪，我與埃及王法老為敵，必將他有力的膀臂和已打折的膀臂全行打斷，使刀從他手中墜落。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 30:26; 以西結書 30:17–18; 以西結書 29:12–13"> 我必將埃及人分散在列國，四散在列邦。</span>
</div>
</div>

## 堅強巴比倫王之臂

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西結書 30:25; 西番雅書 2:12; 以賽亞書 45:5"> 「我必使巴比倫王的膀臂有力，將我的刀交在他手中；卻要打斷法老的膀臂，他就在巴比倫王面前唉哼，如同受死傷的人一樣。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 29:21; 以西結書 32:15; 以西結書 29:16"> 我必扶持巴比倫王的膀臂，法老的膀臂卻要下垂。我將我的刀交在巴比倫王手中，他必舉刀攻擊埃及地，他們就知道我是耶和華。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 11:42; 以西結書 29:12; 以西結書 30:23"> 我必將埃及人分散在列國，四散在列邦，他們就知道我是耶和華。」</span>
</div>

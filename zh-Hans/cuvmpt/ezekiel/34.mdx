## 譴責牧者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 23:1; 耶利米書 3:15; 以賽亞書 40:11"> 「人子啊，你要向以色列的牧人發預言攻擊他們，說：『主耶和華如此說：禍哉，以色列的牧人！只知牧養自己。牧人豈不當牧養群羊嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 11:16; 耶利米書 2:30; 以西結書 33:25–26"> 你們吃脂油，穿羊毛，宰肥壯的，卻不牧養群羊。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 18:12–13; 馬太福音 9:36; 以西結書 34:16"> 瘦弱的你們沒有養壯，有病的你們沒有醫治，受傷的你們沒有纏裹，被逐的你們沒有領回，失喪的你們沒有尋找，但用強暴嚴嚴地轄制。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 9:36; 歷代志下 18:16; 耶利米書 23:2"> 因無牧人，羊就分散，既分散，便做了一切野獸的食物。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 142:4; 彼得前書 2:25; 約翰福音 10:16"> 我的羊在諸山間、在各高岡上流離，在全地上分散，無人去尋，無人去找。</span>
</div>
</div>

## 必加懲罰

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 22:2–3; 彌迦書 3:8–9; 詩篇 82:1–7"> 『所以你們這些牧人，要聽耶和華的話。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得後書 2:13; 使徒行傳 20:33; 以西結書 34:5–6"> 主耶和華說：我指著我的永生起誓，我的羊因無牧人就成為掠物，也做了一切野獸的食物。我的牧人不尋找我的羊，這些牧人只知牧養自己，並不牧養我的羊。</span>
<span className="v" id="v9" data-v="9"> 所以你們這些牧人，要聽耶和華的話。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 34:2; 撒迦利亞書 10:3; 以西結書 13:8"> 主耶和華如此說：我必與牧人為敵，必向他們的手追討我的羊，使他們不再牧放群羊，牧人也不再牧養自己。我必救我的羊脫離他們的口，不再做他們的食物。』</span>
</div>
</div>

## 耶和華躬自做牧

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:16; 路加福音 19:10; 耶利米書 23:3"> 「主耶和華如此說：看哪，我必親自尋找我的羊，將他們尋見。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 40:11; 約翰福音 10:11–12; 路加福音 19:10"> 牧人在羊群四散的日子怎樣尋找他的羊，我必照樣尋找我的羊。這些羊在密雲黑暗的日子散到各處，我必從那裡救回他們來。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:25–26; 以西結書 11:17; 以賽亞書 11:11–16"> 我必從萬民中領出他們，從各國內聚集他們，引導他們歸回故土。也必在以色列山上一切溪水旁邊，境內一切可居之處牧養他們。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 10:9; 耶利米書 31:25; 詩篇 31:8–10"> 我必在美好的草場牧養他們，他們的圈必在以色列高處的山上。他們必在佳美之圈中躺臥，也在以色列山肥美的草場吃草。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 3:15; 詩篇 23:1–2; 約翰福音 21:15"> 主耶和華說：我必親自做我羊的牧人，使他們得以躺臥。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西結書 34:4; 以西結書 34:11"> 失喪的我必尋找，被逐的我必領回，受傷的我必纏裹，有病的我必醫治，只是肥的壯的我必除滅，也要秉公牧養他們。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:20–22; 馬太福音 25:32–33; 撒迦利亞書 10:3"> 「我的羊群哪，論到你們，主耶和華如此說：我必在羊與羊中間，公綿羊與公山羊中間施行判斷。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 23:13; 路加福音 11:52; 民數記 16:13"> 你們這些肥壯的羊，在美好的草場吃草還以為小事嗎？剩下的草你們竟用蹄踐踏了！你們喝清水，剩下的水你們竟用蹄攪渾了！</span>
<span className="v" id="v19" data-v="19"> 至於我的羊，只得吃你們所踐踏的，喝你們所攪渾的。</span>
</div>
</div>

## 預言其僕必牧群羊

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 25:31–46; 以西結書 34:10; 詩篇 22:12–16"> 「所以主耶和華如此說：我必在肥羊和瘦羊中間施行判斷。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 11:5; 申命記 33:17; 路加福音 13:14–16"> 因為你們用脅用肩擁擠一切瘦弱的，又用角牴觸，以致使他們四散，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:2–3; 詩篇 72:12–14; 以西結書 34:10"> 所以我必拯救我的群羊不再做掠物，我也必在羊和羊中間施行判斷。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 37:24–25; 耶利米書 30:9; 以賽亞書 40:11"> 我必立一牧人照管他們，牧養他們，就是我的僕人大衛。他必牧養他們，做他們的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 31:33; 以西結書 36:28; 耶利米書 23:5–6"> 我耶和華必做他們的神，我的僕人大衛必在他們中間做王。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:6–9; 以西結書 37:26; 利未記 26:6"> 「我必與他們立平安的約，使惡獸從境內斷絕，他們就必安居在曠野，躺臥在林中。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:12; 以賽亞書 44:3; 利未記 26:4"> 我必使他們與我山的四圍成為福源，我也必叫時雨落下，必有福如甘霖而降。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 30:8; 利未記 26:4; 利未記 26:13"> 田野的樹必結果，地也必有出產，他們必在故土安然居住。我折斷他們所負的軛，救他們脫離那以他們為奴之人的手，那時他們就知道我是耶和華。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 46:27; 耶利米書 30:10; 以西結書 39:26"> 他們必不再做外邦人的掠物，地上的野獸也不再吞吃他們，卻要安然居住，無人驚嚇。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 36:29; 以賽亞書 4:2; 以西結書 34:26–27"> 我必給他們興起有名的植物，他們在境內不再為饑荒所滅，也不再受外邦人的羞辱，</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 37:27; 以西結書 34:24; 詩篇 46:11"> 必知道我耶和華他們的神是與他們同在，並知道他們以色列家是我的民。這是主耶和華說的。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 100:3; 約翰福音 10:16; 詩篇 78:52"> 你們做我的羊，我草場上的羊，乃是以色列人，我也是你們的神。這是主耶和華說的。」</span>
</div>
</div>

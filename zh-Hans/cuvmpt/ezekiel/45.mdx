## 歸聖所之地份

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 48:29; 撒迦利亞書 14:20–21; 民數記 34:13"> 『你們拈鬮分地為業，要獻上一份給耶和華為聖供地，長二萬五千肘，寬一萬肘。這份以內，四圍都為聖地。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 42:16–20; 以西結書 27:28"> 其中有作為聖所之地，長五百肘，寬五百肘，四面見方。四圍再有五十肘，為郊野之地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 48:10"> 要以肘為度量地，長二萬五千肘，寬一萬肘。其中有聖所，是至聖的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 43:19; 民數記 16:5; 以西結書 40:45"> 這是全地的一份聖地，要歸於供聖所職事的祭司，就是親近侍奉耶和華的，作為他們房屋之地與聖所之聖地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 48:13; 尼希米記 10:38–39; 以西結書 48:20"> 又有一份，長二萬五千肘，寬一萬肘，要歸於在殿中供職的利未人，作為二十間房屋之業。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 48:15–18; 以西結書 48:30–35"> 『也要分定屬城的地業，寬五千肘，長二萬五千肘，挨著那份聖供地，要歸以色列全家。</span>
</div>
</div>

## 歸王之地份

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 48:21; 以西結書 34:24; 以西結書 46:16–18"> 『歸王之地要在聖供地和屬城之地的兩旁，就是聖供地和屬城之地的旁邊，西至西頭，東至東頭，從西到東，其長與每支派的份一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 11:3–5; 以西結書 46:18; 以西結書 22:27"> 這地在以色列中必歸王為業。我所立的王必不再欺壓我的民，卻要按支派將地分給以色列家。</span>
</div>
</div>

## 為王定例

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 8:16; 耶利米書 22:3; 以西結書 44:6"> 『主耶和華如此說：以色列的王啊，你們應當知足，要除掉強暴和搶奪的事，施行公平和公義，不再勒索我的民。這是主耶和華說的。</span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 6:10–11; 阿摩司書 8:4–6; 箴言 16:11"> 你們要用公道天平，公道伊法，公道罷特。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:10"> 伊法與罷特大小要一樣，罷特可盛賀梅珥十分之一，伊法也可盛賀梅珥十分之一，都以賀梅珥的大小為準。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 30:13; 民數記 3:47; 利未記 27:25"> 舍客勒是二十季拉；二十舍客勒，二十五舍客勒，十五舍客勒，為你們的彌那。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 『你們當獻的供物乃是這樣：一賀梅珥麥子要獻伊法六分之一，一賀梅珥大麥要獻伊法六分之一。</span>
<span className="v" id="v14" data-v="14"> 你們獻所分定的油，按油的罷特，一柯珥油要獻罷特十分之一。原來十罷特就是一賀梅珥。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 1:4; 利未記 6:30; 歌羅西書 1:21"> 從以色列滋潤的草場上，每二百羊中要獻一隻羊羔。這都可做素祭、燔祭、平安祭，為民贖罪。這是主耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 30:14–15; 以賽亞書 16:1"> 此地的民都要奉上這供物給以色列中的王。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 46:4–12; 歷代志下 31:3; 以賽亞書 66:23"> 王的本分是在節期、月朔、安息日，就是以色列家一切的節期，奉上燔祭、素祭、奠祭。他要預備贖罪祭、素祭、燔祭和平安祭，為以色列家贖罪。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 16:16; 出埃及記 12:2; 以西結書 43:22"> 『主耶和華如此說：正月初一日，你要取無殘疾的公牛犢，潔淨聖所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 43:20; 以西結書 43:14; 利未記 16:18–20"> 祭司要取些贖罪祭牲的血，抹在殿的門柱上和壇磴臺的四角上，並內院的門框上。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 19:12; 利未記 4:27–35; 以西結書 45:15"> 本月初七日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十經作：七月初一日。">a</a></sup>，也要為誤犯罪的和愚蒙犯罪的如此行，為殿贖罪。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 23:5–8; 哥林多前書 5:7–8; 民數記 9:2–14"> 『正月十四日，你們要守逾越節，守節七日，要吃無酵餅。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:14; 哥林多後書 5:21; 馬太福音 20:28"> 當日，王要為自己和國內的眾民預備一隻公牛做贖罪祭。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 42:8; 利未記 23:8; 民數記 23:1–2"> 這節的七日，每日他要為耶和華預備無殘疾的公牛七隻、公綿羊七隻為燔祭，每日又要預備公山羊一隻為贖罪祭。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:5–7; 民數記 28:12–15"> 他也要預備素祭，就是為一隻公牛同獻一伊法細麵，為一隻公綿羊同獻一伊法細麵，每一伊法細麵加油一欣。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:33–43; 民數記 29:12–38; 歷代志下 5:3"> 七月十五日守節的時候，七日他都要如此行，照逾越節的贖罪祭、燔祭、素祭和油的條例一樣。</span>
</div>
</div>

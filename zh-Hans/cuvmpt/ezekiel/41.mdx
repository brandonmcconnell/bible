## 殿之尺度

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 40:2–3; 以西結書 40:17; 以西結書 41:23"> 他帶我到殿那裡量牆柱，這面厚六肘，那面厚六肘，寬窄與會幕相同。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 6:17; 歷代志下 3:3; 列王紀上 6:2"> 門口寬十肘，門兩旁，這邊五肘，那邊五肘。他量殿，長四十肘，寬二十肘。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 40:16"> 他到內殿量牆柱，各厚二肘。門口寬六肘，門兩旁各寬七肘。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 6:20; 希伯來書 9:3–8; 出埃及記 26:33–34"> 他量內殿，長二十肘，寬二十肘。他對我說：「這是至聖所。」</span>
</div>

## 旁屋之式度

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:5–6; 以西結書 42:3–14; 以西結書 41:6–9"> 他又量殿牆，厚六肘。圍著殿有旁屋，各寬四肘。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:10; 列王紀上 6:5–6; 以西結書 40:17"> 旁屋有三層，層疊而上，每層排列三十間。旁屋的梁木擱在殿牆坎上，免得插入殿牆。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 6:8; 希伯來書 6:1; 馬太福音 13:32"> 這圍殿的旁屋越高越寬。因旁屋圍殿懸疊而上，所以越上越寬，從下一層，由中一層，到上一層。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 40:5; 啟示錄 21:16"> 我又見圍著殿有高月臺。旁屋的根基，高足一竿，就是六大肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 41:11; 以西結書 42:4; 以西結書 42:1"> 旁屋的外牆厚五肘。旁屋之外還有餘地。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 40:17"> 在旁屋與對面的房屋中間有空地，寬二十肘。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 41:9; 以西結書 42:4"> 旁屋的門都向餘地，一門向北，一門向南，周圍的餘地寬五肘。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 42:1; 以西結書 42:13; 以西結書 41:13–15"> 在西面空地之後有房子，寬七十肘，長九十肘，牆四圍厚五肘。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 40:47"> 這樣，他量殿，長一百肘。又量空地和那房子並牆，共長一百肘。</span>
<span className="v" id="v14" data-v="14"> 殿的前面和兩旁的空地，寬一百肘。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西結書 42:3; 以西結書 42:1; 以西結書 41:12"> 他量空地後面的那房子並兩旁的樓廊，共長一百肘。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 6:4; 以西結書 40:25; 以西結書 40:16"> 內殿、院廊、門檻、嚴緊的窗櫺，並對著門檻的三層樓廊，從地到窗櫺（窗櫺都有蔽子），</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 42:15"> 直到門以上，就是到內殿和外殿內外四圍牆壁，都按尺寸用木板遮蔽。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:36; 以西結書 40:16; 以西結書 40:22"> 牆上雕刻基路伯和棕樹，每二基路伯中間有一棵棕樹，每基路伯有二臉。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 10:14; 以西結書 1:10"> 這邊有人臉向著棕樹，那邊有獅子臉向著棕樹，殿內周圍都是如此。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 41:18"> 從地至門以上，都有基路伯和棕樹，殿牆就是這樣。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 41:1; 列王紀上 6:33; 以西結書 40:14"> 殿的門柱是方的。至聖所的前面，形狀和殿的形狀一樣。</span>
<span className="v" id="v22" data-v="22" data-xref="瑪拉基書 1:12; 以西結書 23:41; 瑪拉基書 1:7"> 壇是木頭做的，高三肘，長二肘。壇角和壇面並四旁，都是木頭做的。他對我說：「這是耶和華面前的桌子。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 6:31–35; 歷代志下 4:22; 以西結書 41:1"> 殿和至聖所的門各有兩扇。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:34; 以西結書 40:48"> 每扇分兩扇，這兩扇是摺疊的，這邊門分兩扇，那邊門也分兩扇。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 41:18"> 殿的門扇上雕刻基路伯和棕樹，與刻在牆上的一般。在外頭廊前有木檻。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 41:16; 以西結書 40:16; 以西結書 41:5"> 廊這邊那邊都有嚴緊的窗櫺和棕樹。殿的旁屋和檻就是這樣。</span>
</div>
</div>

## 預言歌革受罰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 38:2–3; 以西結書 35:3; 那鴻書 3:5"> 「人子啊，你要向歌革發預言攻擊他，說：『主耶和華如此說：羅施、米設、土巴的王歌革啊，我與你為敵。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 40:14; 以西結書 38:15; 以賽亞書 37:29"> 我必調轉你，領你前往，使你從北方的極處上來，帶你到以色列的山上。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 76:3; 何西阿書 1:5; 耶利米書 21:4–5"> 我必從你左手打落你的弓，從你右手打掉你的箭。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 39:17–20; 以西結書 33:27; 以西結書 38:21"> 你和你的軍隊並同著你的列國人，都必倒在以色列的山上，我必將你給各類的鷙鳥和田野的走獸做食物。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 22:19; 以西結書 32:4; 耶利米書 8:2"> 你必倒在田野，因為我曾說過。這是主耶和華說的。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 30:16; 阿摩司書 1:4; 以西結書 30:8"> 我要降火在瑪各和海島安然居住的人身上，他們就知道我是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 38:16; 以西結書 38:23; 出埃及記 20:7"> 我要在我民以色列中顯出我的聖名，也不容我的聖名再被褻瀆，列國人就知道我是耶和華，以色列中的聖者。</span>
</div>
</div>

## 以色列人取其器械為薪

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 38:17; 啟示錄 16:17; 以西結書 7:2–10"> 『主耶和華說：這日事情臨近，也必成就，乃是我所說的日子。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:9; 以賽亞書 66:24; 瑪拉基書 1:5"> 住以色列城邑的人必出去撿器械，就是大小盾牌、弓箭、梃杖、槍矛，都當柴燒火，直燒七年，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 33:1; 以賽亞書 14:2; 彌迦書 5:8"> 甚至他們不必從田野撿柴，也不必從樹林伐木。因為他們要用器械燒火，並且搶奪那搶奪他們的人，擄掠那擄掠他們的人。這是主耶和華說的。</span>
</div>
</div>

## 葬其屍於以色列地

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西結書 47:18; 民數記 34:11; 以西結書 38:2"> 『當那日，我必將以色列地的谷，就是海東人所經過的谷，賜給歌革為墳地，使經過的人到此停步。在那裡，人必葬埋歌革和他的群眾，就稱那地為哈們歌革谷。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:23; 以西結書 39:14; 以西結書 39:16"> 以色列家的人必用七個月葬埋他們，為要潔淨全地。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:22; 西番雅書 3:19–20; 耶利米書 33:9"> 全地的居民都必葬埋他們。當我得榮耀的日子，這事必叫他們得名聲。這是主耶和華說的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 39:12; 民數記 19:11–19"> 他們必分派人時常巡查遍地，與過路的人一同葬埋那剩在地面上的屍首，好潔淨全地。過了七個月，他們還要巡查。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:44"> 巡查遍地的人要經過全地，見有人的骸骨，就在旁邊立一標記，等葬埋的人來將骸骨葬在哈們歌革谷。</span>
<span className="v" id="v16" data-v="16"> 他們必這樣潔淨那地，並有一城名叫哈摩那。』</span>
</div>
</div>

## 飛鳥食其肉飲其血

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="西番雅書 1:7; 啟示錄 19:17–18; 以賽亞書 34:6"> 「人子啊，主耶和華如此說：你要對各類的飛鳥和田野的走獸說：『你們聚集來吧！要從四方聚到我為你們獻祭之地，就是在以色列山上獻大祭之地，好叫你們吃肉喝血。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 22:12; 耶利米書 51:40; 啟示錄 19:17–18"> 你們必吃勇士的肉，喝地上首領的血，就如吃公綿羊、羊羔、公山羊、公牛，都是巴珊的肥畜。</span>
<span className="v" id="v19" data-v="19"> 你們吃我為你們所獻的祭，必吃飽了脂油，喝醉了血。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 19:18; 哈該書 2:22; 詩篇 76:5–6"> 你們必在我席上飽吃馬匹和坐車的人，並勇士和一切的戰士。』這是主耶和華說的。</span>
</div>
</div>

## 以色列家因罪被棄

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 38:16; 以西結書 38:23; 以賽亞書 37:20"> 「我必顯我的榮耀在列國中，萬民就必看見我所行的審判與我在他們身上所加的手。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 24:7; 以西結書 28:26; 以西結書 39:28"> 這樣，從那日以後，以色列家必知道我是耶和華他們的神。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 22:8–9; 以賽亞書 1:15; 以賽亞書 59:2"> 列國人也必知道以色列家被擄掠，是因他們的罪孽。他們得罪我，我就掩面不顧，將他們交在敵人手中，他們便都倒在刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 36:19; 耶利米書 2:17; 耶利米書 4:18"> 我是照他們的汙穢和罪過待他們，並且我掩面不顧他們。</span>
</div>
</div>

## 後必蒙恩復歸故土

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 34:13; 以賽亞書 27:12–13; 何西阿書 1:11"> 「主耶和華如此說：我要使雅各被擄的人歸回，要憐憫以色列全家，又為我的聖名發熱心。</span>
<span className="v" id="v26" data-v="26" data-xref="彌迦書 4:4; 列王紀上 4:25; 以西結書 16:63"> 他們在本地安然居住，無人驚嚇，是我將他們從萬民中領回，從仇敵之地召來。我在許多國的民眼前，在他們身上顯為聖的時候，他們要擔當自己的羞辱和干犯我的一切罪。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 39:22; 阿摩司書 9:9; 以賽亞書 27:12"> 因我使他們被擄到外邦人中，後又聚集他們歸回本地，他們就知道我是耶和華他們的神。我必不再留他們一人在外邦。</span>
<span className="v" id="v29" data-v="29" data-xref="約珥書 2:28; 約翰一書 3:24; 以賽亞書 32:15"> 我也不再掩面不顧他們，因我已將我的靈澆灌以色列家。這是主耶和華說的。」</span>
</div>
</div>

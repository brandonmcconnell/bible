## 耶和華之榮光充盈聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 44:1; 以西結書 42:15; 以西結書 46:1"> 以後，他帶我到一座門，就是朝東的門。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 18:1; 以西結書 11:23; 以賽亞書 6:3"> 以色列神的榮光從東而來，他的聲音如同多水的聲音，地就因他的榮耀發光。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 9:5; 以西結書 9:1; 耶利米書 1:10"> 其狀如從前他來滅城的時候我所見的異象，那異象如我在迦巴魯河邊所見的異象，我就俯伏在地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 10:18–19; 以西結書 44:2; 以西結書 43:2"> 耶和華的榮光從朝東的門照入殿中。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:2–4; 列王紀上 8:10–11; 以西結書 8:3"> 靈將我舉起，帶入內院，不料，耶和華的榮光充滿了殿。</span>
</div>
</div>

## 以色列族棄邪行耶和華永居其中

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 40:3; 以賽亞書 66:6; 啟示錄 16:1"> 我聽見有一位從殿中對我說話，有一人站在我旁邊。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 43:9; 詩篇 47:8; 利未記 26:30"> 他對我說：「人子啊，這是我寶座之地，是我腳掌所踏之地。我要在這裡住，在以色列人中，直到永遠。以色列家和他們的君王必不再玷汙我的聖名，就是行邪淫，在錫安的高處葬埋他們君王的屍首。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 5:11; 以西結書 8:3–16; 歷代志下 33:7"> 使他們的門檻挨近我的門檻，他們的門框挨近我的門框，他們與我中間僅隔一牆，並且行可憎的事，玷汙了我的聖名，所以我發怒滅絕他們。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 43:7; 以西結書 37:26–28; 以西結書 18:30–31"> 現在他們當從我面前遠除邪淫和他們君王的屍首，我就住在他們中間直到永遠。</span>
</div>
</div>

## 勸以色列人自愧其罪

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 40:4; 以西結書 16:61; 以西結書 16:63"> 「人子啊，你要將這殿指示以色列家，使他們因自己的罪孽慚愧，也要他們量殿的尺寸。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 36:27; 以西結書 11:20; 馬太福音 28:20"> 他們若因自己所行的一切事慚愧，你就將殿的規模、樣式、出入之處和一切形狀、典章、禮儀、法則指示他們，在他們眼前寫上，使他們遵照殿的一切規模、典章去做。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 40:2; 啟示錄 21:27; 詩篇 93:5"> 殿的法則乃是如此：殿在山頂上，四圍的全界要稱為至聖。這就是殿的法則。</span>
</div>
</div>

## 祭壇之尺度

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 40:5; 出埃及記 27:1–8; 以西結書 41:8"> 「以下量祭壇，是以肘為度（這肘是一肘零一掌）。底座高一肘，邊寬一肘，四圍起邊高一掌，這是壇的座。</span>
<span className="v" id="v14" data-v="14"> 從底座到下層磴臺，高二肘，邊寬一肘。從小磴臺到大磴臺，高四肘，邊寬一肘。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 27:2; 詩篇 118:27; 利未記 9:9"> 壇上的供臺高四肘，供臺的四拐角上都有角。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 27:1; 歷代志下 4:1; 出埃及記 38:1–2"> 供臺長十二肘，寬十二肘，四面見方。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 20:26; 以西結書 40:6; 出埃及記 25:25"> 磴臺長十四肘，寬十四肘，四面見方。四圍起邊高半肘，底座四圍的邊寬一肘。臺階朝東。」</span>
</div>
</div>

## 獻祭之禮儀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 40:29; 希伯來書 10:4–12; 以西結書 2:1"> 他對我說：「人子啊，主耶和華如此說：建造祭壇，為要在其上獻燔祭灑血，造成的時候典章如下。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 40:46; 以西結書 44:15; 民數記 16:40"> 主耶和華說：你要將一隻公牛犢作為贖罪祭，給祭司利未人撒督的後裔，就是那親近我侍奉我的。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 16:19; 利未記 8:15; 出埃及記 29:12"> 你要取些公牛的血，抹在壇的四角和磴臺的四拐角，並四圍所起的邊上。你這樣潔淨壇，壇就潔淨了。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 29:14; 利未記 4:12; 利未記 8:17"> 你又要將那做贖罪祭的公牛犢燒在殿外，聖地之外預定之處。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 43:25–26; 以西結書 43:20; 彼得前書 1:19"> 次日，要將無殘疾的公山羊獻為贖罪祭，要潔淨壇，像用公牛犢潔淨的一樣。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:1"> 潔淨了壇，就要將一隻無殘疾的公牛犢和羊群中一隻無殘疾的公綿羊，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 2:13; 馬可福音 9:49–50; 民數記 18:19"> 奉到耶和華前。祭司要撒鹽在其上，獻於耶和華為燔祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:33; 出埃及記 29:35–37; 利未記 8:35"> 七日內，每日要預備一隻公山羊為贖罪祭，也要預備一隻公牛犢和羊群中的一隻公綿羊，都要沒有殘疾的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 29:24; 利未記 8:34; 出埃及記 32:29"> 七日祭司潔淨壇，壇就潔淨了，要這樣把壇分別為聖。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 9:1; 以西結書 20:40–41; 彼得前書 2:5"> 滿了七日，自八日以後，祭司要在壇上獻你們的燔祭和平安祭，我必悅納你們。這是主耶和華說的。」</span>
</div>
</div>

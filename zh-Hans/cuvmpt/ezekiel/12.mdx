## 命以西結遷徙以兆猶大君被擄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 4:12; 耶利米書 5:21; 詩篇 78:40"> 「人子啊，你住在悖逆的家中，他們有眼睛看不見，有耳朵聽不見，因為他們是悖逆之家。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 36:3; 提摩太後書 2:25; 耶利米書 26:3"> 所以，人子啊，你要預備擄去使用的物件，在白日當他們眼前，從你所住的地方移到別處去。他們雖是悖逆之家，或者可以揣摩思想。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:4; 以西結書 12:12; 列王紀下 25:4"> 你要在白日當他們眼前帶出你的物件去，好像預備擄去使用的物件。到了晚上，你要在他們眼前親自出去，像被擄的人出去一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 25:4; 耶利米書 39:2–4"> 你要在他們眼前挖通了牆，從其中將物件帶出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 4:3; 以賽亞書 8:18; 以西結書 24:24"> 到天黑時，你要當他們眼前搭在肩頭上帶出去，並要蒙住臉看不見地，因為我立你做以色列家的預兆。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:18; 以西結書 37:10; 以西結書 37:7"> 我就照著所吩咐的去行。白日帶出我的物件，好像預備擄去使用的物件。到了晚上，我用手挖通了牆。天黑的時候，就當他們眼前搭在肩頭上帶出去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 次日早晨，耶和華的話臨到我說：</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 24:19; 以西結書 17:12; 以西結書 20:49"> 「人子啊，以色列家，就是那悖逆之家，豈不是問你說：『你做什麼呢？』</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 9:25; 以賽亞書 13:1; 耶利米書 24:8"> 你要對他們說：『主耶和華如此說：這是關乎耶路撒冷的君王和他周圍以色列全家的預表<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：擔子。">a</a></sup>。』</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 52:15; 耶利米書 15:2; 耶利米書 52:28–30"> 你要說：『我做你們的預兆。我怎樣行，他們所遭遇的也必怎樣，他們必被擄去。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:4; 耶利米書 39:4; 以西結書 12:6"> 他們中間的君王也必在天黑的時候將物件搭在肩頭上帶出去。他們要挖通了牆，從其中帶出去。他必蒙住臉，眼看不見地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 39:7; 何西阿書 7:12; 以西結書 17:20"> 我必將我的網撒在他身上，他必在我的網羅中纏住。我必帶他到迦勒底人之地的巴比倫，他雖死在那裡，卻看不見那地。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 5:2; 列王紀下 25:4–5; 以西結書 17:21"> 周圍一切幫助他的和他所有的軍隊，我必分散四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「方」原文作「風」。">b</a></sup>，也要拔刀追趕他們。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 6:7; 以西結書 12:16; 以西結書 12:20"> 我將他們四散在列國、分散在列邦的時候，他們就知道我是耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 22:8–9; 以西結書 14:22–23; 以西結書 6:8–10"> 我卻要留下他們幾個人得免刀劍、饑荒、瘟疫，使他們在所到的各國中述說他們一切可憎的事，人就知道我是耶和華。」</span>
</div>
</div>

## 以西結戰懼以兆猶大人驚惶

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華的話又臨到我說：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 詩篇 80:5; 約伯記 3:24"> 「人子啊，你吃飯必膽戰，喝水必惶惶憂慮。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 7:14; 以西結書 6:6–7; 以西結書 6:14"> 你要對這地的百姓說：『主耶和華論耶路撒冷和以色列地的居民如此說：他們吃飯必憂慮，喝水必驚惶。因其中居住的眾人所行強暴的事，這地必然荒廢，一無所存。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:7; 以賽亞書 7:23–24; 耶利米書 25:9"> 有居民的城邑必變為荒場，地也必變為荒廢，你們就知道我是耶和華。』」</span>
</div>
</div>

## 斥以色列俗諺之非

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和華的話臨到我說：</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 18:2–3; 以西結書 11:3; 以西結書 12:27"> 「人子啊，在你們以色列地怎麼有這俗語說『日子遲延，一切異象都落了空』呢？</span>
<span className="v" id="v23" data-v="23" data-xref="約珥書 2:1; 以西結書 7:5–7; 西番雅書 1:14"> 你要告訴他們說：『主耶和華如此說：我必使這俗語止息，以色列中不再用這俗語。』你卻要對他們說：『日子臨近，一切的異象必都應驗。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 14:13–16; 以西結書 13:23; 撒迦利亞書 13:2–4"> 從此，在以色列家中必不再有虛假的異象和奉承的占卜。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷書 1:5; 以西結書 12:28; 以賽亞書 55:11"> 我耶和華說話，所說的必定成就，不再耽延。你們這悖逆之家，我所說的話必趁你們在世的日子成就。』這是主耶和華說的。」</span>
</div>
</div>

## 啟示預言應驗伊邇

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華的話又臨到我說：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 10:14; 以西結書 12:22; 彼得後書 3:4"> 「人子啊，以色列家的人說：『他所見的異象是關乎後來許多的日子，所說的預言是指著極遠的時候。』</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 12:23–25; 馬可福音 13:32–37; 帖撒羅尼迦前書 5:2–3"> 所以你要對他們說：『主耶和華如此說：我的話沒有一句再耽延的，我所說的必定成就。』這是主耶和華說的。」</span>
</div>
</div>

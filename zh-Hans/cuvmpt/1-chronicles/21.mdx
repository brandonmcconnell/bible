## 大衛核數以色列民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 24:1–25; 撒迦利亞書 3:1; 約伯記 2:4–6"> 撒旦起來攻擊以色列人，激動大衛數點他們。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 27:23–24; 撒母耳記下 3:10; 撒母耳記下 24:15"> 大衛就吩咐約押和民中的首領說：「你們去數點以色列人，從別是巴直到但，回來告訴我，我好知道他們的數目。」</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; 以賽亞書 26:15; 歷代志上 19:13"> 約押說：「願耶和華使他的百姓比現在加增百倍。我主我王啊，他們不都是你的僕人嗎？我主為何吩咐行這事？為何使以色列人陷在罪裡呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:29; 出埃及記 1:17; 但以理書 3:18"> 但王的命令勝過約押。約押就出去，走遍以色列地，回到耶路撒冷，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 24:9; 歷代志上 27:23"> 將百姓的總數奏告大衛。以色列人拿刀的有一百一十萬，猶大人拿刀的有四十七萬。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 27:24; 民數記 1:47–49; 撒母耳記下 20:9–10"> 唯有利未人和便雅憫人沒有數在其中，因為約押厭惡王的這命令。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 15:5; 約書亞記 7:5; 撒母耳記下 21:14"> 神不喜悅這數點百姓的事，便降災給以色列人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 12:13; 約翰一書 1:9; 創世記 34:7"> 大衛禱告神說：「我行這事大有罪了！現在求你除掉僕人的罪孽，因我所行的甚是愚昧。」</span>
</div>
</div>

## 耶和華怒降疫癘

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 9:9; 撒母耳記下 24:11; 歷代志上 29:29"> 耶和華吩咐大衛的先見迦得說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 13:21–22; 啟示錄 3:19; 箴言 1:29–31"> 「你去告訴大衛說：『耶和華如此說：我有三樣災，隨你選擇一樣，我好降於你。』」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> 於是迦得來見大衛，對他說：「耶和華如此說：『你可以隨意選擇：</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 28:27; 使徒行傳 12:23; 以西結書 14:19–21"> 或三年的饑荒；或敗在你敵人面前，被敵人的刀追殺三個月；或在你國中有耶和華的刀，就是三日的瘟疫，耶和華的使者在以色列的四境施行毀滅。』現在你要想一想，我好回覆那差我來的。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 130:7; 以賽亞書 55:7; 腓立比書 1:23"> 大衛對迦得說：「我甚為難。我願落在耶和華的手裡，因為他有豐盛的憐憫，我不願落在人的手裡。」</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 12:30; 歷代志上 27:24; 列王紀下 19:35"> 於是，耶和華降瘟疫於以色列人，以色列人就死了七萬。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:6; 出埃及記 32:14; 耶利米書 26:18"> 神差遣使者去滅耶路撒冷，剛要滅的時候，耶和華看見後悔，就不降這災了，吩咐滅城的天使說：「夠了，住手吧！」那時，耶和華的使者站在耶布斯人阿珥楠的禾場那裡。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 14:5; 列王紀上 21:27; 列王紀下 6:17"> 大衛舉目，看見耶和華的使者站在天地間，手裡有拔出來的刀，伸在耶路撒冷以上。大衛和長老都身穿麻衣，面伏於地。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 16:63; 撒母耳記下 24:17; 約翰福音 10:11–12"> 大衛禱告神說：「吩咐數點百姓的不是我嗎？我犯了罪行了惡，但這群羊做了什麼呢？願耶和華我神的手攻擊我和我的父家，不要攻擊你的民，降瘟疫於他們。」</span>
</div>
</div>

## 大衛築壇獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 3:1; 撒母耳記下 24:18; 歷代志上 21:11"> 耶和華的使者吩咐迦得去告訴大衛，叫他上去，在耶布斯人阿珥楠的禾場上為耶和華築一座壇。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 9:6; 約翰福音 2:5; 列王紀下 5:10–14"> 大衛就照著迦得奉耶和華名所說的話上去了。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 6:11"> 那時阿珥楠正打麥子，回頭看見天使，就和他四個兒子都藏起來了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 25:23; 撒母耳記下 24:18–20"> 大衛到了阿珥楠那裡，阿珥楠看見大衛，就從禾場上出去，臉伏於地，向他下拜。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 24:21; 列王紀上 21:2; 民數記 25:8"> 大衛對阿珥楠說：「你將這禾場與相連之地賣給我，我必給你足價，我好在其上為耶和華築一座壇，使民間的瘟疫止住。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 24:22–23; 撒母耳記上 6:14; 創世記 23:4–6"> 阿珥楠對大衛說：「你可以用這禾場，願我主我王照你所喜悅的去行。我也將牛給你做燔祭，把打糧的器具當柴燒，拿麥子做素祭，這些我都送給你。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 16:16–17; 創世記 14:23; 創世記 23:13"> 大衛王對阿珥楠說：「不然，我必要用足價向你買。我不用你的物獻給耶和華，也不用白得之物獻為燔祭。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 24:24–25"> 於是大衛為那塊地平了六百舍客勒金子給阿珥楠。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 9:24; 士師記 6:21; 箴言 15:8"> 大衛在那裡為耶和華築了一座壇，獻燔祭和平安祭，求告耶和華。耶和華就應允他，使火從天降在燔祭壇上。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 18:11; 詩篇 103:20; 歷代志上 21:15–16"> 耶和華吩咐使者，他就收刀入鞘。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 那時，大衛見耶和華在耶布斯人阿珥楠的禾場上應允了他，就在那裡獻祭。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 16:39; 歷代志下 1:3; 歷代志下 1:13"> 摩西在曠野所造之耶和華的帳幕和燔祭壇都在基遍的高處，</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 1:17; 希伯來書 12:28–29; 啟示錄 15:4"> 只是大衛不敢前去求問神，因為懼怕耶和華使者的刀。</span>
<span className="v" id="v31" data-v="31"> 大衛說：「這就是耶和華神的殿，為以色列人獻燔祭的壇。」</span>
</div>
</div>

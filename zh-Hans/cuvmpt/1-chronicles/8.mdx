## 便雅憫之後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:21; 歷代志上 7:6–12; 民數記 26:38"> 便雅憫的長子比拉，次子亞實別，三子亞哈拉，</span>
<span className="v" id="v2" data-v="2"> 四子挪哈，五子拉法。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:21; 民數記 26:40"> 比拉的兒子是亞大、基拉、亞比忽、</span>
<span className="v" id="v4" data-v="4"> 亞比書、乃幔、亞何亞、</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 7:12; 民數記 26:39; 士師記 3:15"> 基拉、示孚汛、戶蘭。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 2:54; 士師記 3:20–30; 歷代志上 7:10"> 以忽的兒子做迦巴居民的族長，被擄到瑪拿轄，</span>
<span className="v" id="v7" data-v="7"> 以忽的兒子乃幔、亞希亞、基拉也被擄去。基拉生烏撒、亞希忽。</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 1:1; 創世記 25:6"> 沙哈連休他二妻戶伸和巴拉之後，在摩押地生了兒子。</span>
<span className="v" id="v9" data-v="9"> 他與妻賀得同房，生了約巴、洗比雅、米沙、瑪拉干、</span>
<span className="v" id="v10" data-v="10"> 耶烏斯、沙迦、米瑪，他這些兒子都是族長。</span>
<span className="v" id="v11" data-v="11"> 他的妻戶伸給他生的兒子有亞比突、以利巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 2:33; 尼希米記 7:37; 尼希米記 6:2"> 以利巴力的兒子是希伯、米珊、沙麥，沙麥建立阿挪和羅德二城與其村莊。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 2:52; 約書亞記 19:42; 歷代志上 4:4"> 又有比利亞和示瑪，是亞雅崙居民的族長，是驅逐迦特人的。</span>
<span className="v" id="v14" data-v="14"> 亞希約、沙煞、耶利末、</span>
<span className="v" id="v15" data-v="15"> 西巴第雅、亞拉得、亞得、</span>
<span className="v" id="v16" data-v="16"> 米迦勒、伊施巴、約哈，都是比利亞的兒子。</span>
<span className="v" id="v17" data-v="17"> 西巴第雅、米書蘭、希西基、希伯、</span>
<span className="v" id="v18" data-v="18"> 伊施米萊、伊斯利亞、約巴，都是以利巴力的兒子。</span>
<span className="v" id="v19" data-v="19"> 雅金、細基利、撒底、</span>
<span className="v" id="v20" data-v="20"> 以利乃、洗勒太、以列、</span>
<span className="v" id="v21" data-v="21"> 亞大雅、比拉雅、申拉，都是示每的兒子。</span>
<span className="v" id="v22" data-v="22"> 伊施班、希伯、以列、</span>
<span className="v" id="v23" data-v="23"> 亞伯頓、細基利、哈難、</span>
<span className="v" id="v24" data-v="24"> 哈拿尼雅、以攔、安陀提雅、</span>
<span className="v" id="v25" data-v="25"> 伊弗底雅、毗努伊勒，都是沙煞的兒子。</span>
<span className="v" id="v26" data-v="26"> 珊示萊、示哈利、亞他利雅、</span>
<span className="v" id="v27" data-v="27"> 雅利西、以利亞、細基利，都是耶羅罕的兒子。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:21; 約書亞記 15:63; 尼希米記 11:1"> 這些人都是著名的族長，住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志上 9:35–38"> 在基遍住的有基遍的父親耶利，他的妻名叫瑪迦。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 9:36–37"> 他長子是亞伯頓，他又生蘇珥、基士、巴力、拿答、</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 9:37"> 基多、亞希約、撒迦、米基羅。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 9:38"> 米基羅生示米暗。這些人和他們的弟兄在耶路撒冷對面居住。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 9:1; 撒母耳記下 2:8; 撒母耳記上 31:2"> 尼珥生基士，基士生掃羅，掃羅生約拿單、麥基舒亞、亞比拿達、伊施巴力。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 4:4; 撒母耳記下 9:12; 撒母耳記下 9:10"> 約拿單的兒子是米力巴力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「米力巴力」《撒母耳記下》4章4節作「米非波設」。">a</a></sup>，米力巴力生米迦。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 9:41"> 米迦的兒子是毗敦、米勒、他利亞、亞哈斯。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 9:42"> 亞哈斯生耶何阿達，耶何阿達生亞拉篾、亞斯瑪威、心利，心利生摩撒，</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 9:43"> 摩撒生比尼亞。比尼亞的兒子是拉法，拉法的兒子是以利亞薩，以利亞薩的兒子是亞悉。</span>
<span className="v" id="v38" data-v="38"> 亞悉有六個兒子，他們的名字是亞斯利干、波基路、以實瑪利、示亞利雅、俄巴底雅、哈難，這都是亞悉的兒子。</span>
<span className="v" id="v39" data-v="39"> 亞悉兄弟以設的長子是烏蘭，次子耶烏施，三子是以利法列。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 128:3–6; 歷代志下 14:8; 歷代志上 12:2"> 烏蘭的兒子都是大能的勇士，是弓箭手，他們有許多的子孫，共一百五十名，都是便雅憫人。</span>
</div>

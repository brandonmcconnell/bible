## 亞當之譜系

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:38; 創世記 4:25–32"> 亞當生塞特，塞特生以挪士，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:37; 創世記 5:12–20; 創世記 5:9"> 以挪士生該南，該南生瑪勒列，瑪勒列生雅列，</span>
<span className="v" id="v3" data-v="3" data-xref="猶大書 1:14; 創世記 5:21–31; 路加福音 3:36–37"> 雅列生以諾，以諾生瑪土撒拉，瑪土撒拉生拉麥，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 5:32; 創世記 9:18; 路加福音 17:26"> 拉麥生挪亞，挪亞生閃、含、雅弗。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 10:1–5; 以西結書 38:6; 以西結書 27:13"> 雅弗的兒子是歌篾、瑪各、瑪代、雅完、土巴、米設、提拉。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:3"> 歌篾的兒子是亞實基拿、低法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「低法」《創世記》10章3節作「利法」。">a</a></sup>、陀迦瑪。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 2:10; 民數記 24:24; 以賽亞書 66:19"> 雅完的兒子是以利沙、他施、基提、多單<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「多單」有作「羅單」的。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 10:6–7"> 含的兒子是古實、麥西、弗、迦南。</span>
<span className="v" id="v9" data-v="9"> 古實的兒子是西巴、哈腓拉、撒弗他、拉瑪、撒弗提迦。拉瑪的兒子是示巴、底但。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 10:8–12; 彌迦書 5:6"> 古實生寧錄，他為世上英雄之首。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:13–18"> 麥西生路低人、亞拿米人、利哈比人、拿弗土希人、</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:23; 耶利米書 47:4; 阿摩司書 9:7"> 帕斯魯細人、迦斯路希人、迦斐托人，從迦斐托出來的有非利士人。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 9:22; 創世記 23:20; 創世記 10:15–19"> 迦南生長子西頓，又生赫，</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 15:21; 約書亞記 3:10; 出埃及記 33:2"> 和耶布斯人、亞摩利人、革迦撒人、</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 3:8; 列王紀上 9:20; 出埃及記 13:5"> 希未人、亞基人、西尼人、</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 34:8; 列王紀上 8:65"> 亞瓦底人、洗瑪利人並哈馬人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 10:22–32; 以斯拉記 4:2; 以西結書 32:24"> 閃的兒子是以攔、亞述、亞法撒、路德、亞蘭、烏斯、戶勒、基帖、米設<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「米設」《創世記》10章23節作「瑪施」。">c</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 11:12–15; 創世記 10:24"> 亞法撒生沙拉，沙拉生希伯。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 10:21; 創世記 11:16–17; 創世記 10:25"> 希伯生了兩個兒子，一個名叫法勒<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「法勒」就是「分」的意思。">d</a></sup>，因為那時人就分地居住；法勒的兄弟名叫約坍。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 10:26–27"> 約坍生亞摩答、沙列、哈薩瑪非、耶拉、</span>
<span className="v" id="v21" data-v="21"> 哈多蘭、烏薩、德拉、</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:28"> 以巴錄、亞比瑪利、示巴、</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 10:11; 創世記 25:18; 撒母耳記上 15:7"> 阿斐、哈腓拉、約巴，這都是約坍的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 11:10–26; 路加福音 3:34–36"> 閃生亞法撒，亞法撒生沙拉，</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 3:35"> 沙拉生希伯，希伯生法勒，法勒生拉吳，</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:34–35"> 拉吳生西鹿，西鹿生拿鶴，拿鶴生他拉，</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 11:27–32; 尼希米記 9:7; 約書亞記 24:2"> 他拉生亞伯蘭，亞伯蘭就是亞伯拉罕。</span>
</div>
</div>

## 亞伯拉罕之後裔

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 17:19–21; 創世記 21:2–5; 創世記 21:9–10"> 亞伯拉罕的兒子是以撒、以實瑪利。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 60:7; 創世記 25:12–16; 雅歌 1:5"> 以實瑪利的兒子記在下面：以實瑪利的長子是尼拜約，其次是基達、亞德別、米比衫、</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 21:11; 創世記 25:15"> 米施瑪、度瑪、瑪撒、哈達、提瑪、</span>
<span className="v" id="v31" data-v="31"> 伊突、拿非施、基底瑪。這都是以實瑪利的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 25:1–4; 耶利米書 25:23; 士師記 6:1–6"> 亞伯拉罕的妾基土拉所生的兒子就是心蘭、約珊、米但、米甸、伊施巴、書亞。約珊的兒子是示巴、底但。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 60:6"> 米甸的兒子是以法、以弗、哈諾、亞比大、以勒大。這都是基土拉的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 使徒行傳 7:8; 馬太福音 1:2"> 亞伯拉罕生以撒，以撒的兒子是以掃和以色列。</span>
</div>
</div>

## 以掃之後裔

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="創世記 36:9–10; 創世記 36:4–5"> 以掃的兒子是以利法、流珥、耶烏施、雅蘭、可拉。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 49:20; 阿摩司書 1:12; 俄巴底亞書 1:9"> 以利法的兒子是提幔、阿抹、洗玻、迦坦、基納斯、亭納、亞瑪力。</span>
<span className="v" id="v37" data-v="37"> 流珥的兒子是拿哈、謝拉、沙瑪、米撒。</span>
</div>
</div>

## 西珥之後裔

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 36:20–30"> 西珥的兒子是羅坍、朔巴、祭便、亞拿、底順、以察、底珊。</span>
<span className="v" id="v39" data-v="39" data-xref="申命記 2:12; 創世記 36:22; 申命記 2:22"> 羅坍的兒子是何利、荷幔，羅坍的妹子是亭納。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 36:23–24"> 朔巴的兒子是亞勒文、瑪拿轄、以巴錄、示非、阿南。祭便的兒子是亞雅、亞拿。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 36:25–26"> 亞拿的兒子是底順。底順的兒子是哈默蘭、伊是班、益蘭、基蘭。</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米哀歌 4:21; 創世記 36:27–28"> 以察的兒子是辟罕、撒番、亞干。底珊的兒子是烏斯、亞蘭。</span>
</div>
</div>

## 以東諸王

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 36:31–43; 民數記 24:17–19; 創世記 49:10"> 以色列人未有君王治理之先，在以東地做王的記在下面。有比珥的兒子比拉，他的京城名叫亭哈巴。</span>
<span className="v" id="v44" data-v="44" data-xref="以賽亞書 34:6; 以賽亞書 63:1; 阿摩司書 1:12"> 比拉死了，波斯拉人謝拉的兒子約巴接續他做王。</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 36:11; 約伯記 2:11"> 約巴死了，提幔地的人戶珊接續他做王。</span>
<span className="v" id="v46" data-v="46"> 戶珊死了，比達的兒子哈達接續他做王，這哈達就是在摩押地殺敗米甸人的，他的京城名叫亞未得。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 36:36"> 哈達死了，瑪士利加人桑拉接續他做王。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 36:37"> 桑拉死了，大河邊的利河伯人掃羅接續他做王。</span>
<span className="v" id="v49" data-v="49"> 掃羅死了，亞革波的兒子巴勒哈南接續他做王。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 36:39"> 巴勒哈南死了，哈達接續他做王，他的京城名叫巴伊，他的妻子名叫米希她別，是米薩合的孫女、瑪特列的女兒。</span>
</div>
</div>

## 以東諸族長

<div className="bt">
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="創世記 36:40"> 哈達死了，以東人的族長有亭納族長、亞勒瓦族長、耶帖族長、</span>
<span className="v" id="v52" data-v="52"> 阿何利巴瑪族長、以拉族長、比嫩族長、</span>
<span className="v" id="v53" data-v="53"> 基納斯族長、提幔族長、米比薩族長、</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 36:41–43"> 瑪基疊族長、以蘭族長。這都是以東人的族長。</span>
</div>
</div>

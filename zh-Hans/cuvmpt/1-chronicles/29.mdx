## 大衛王備金銀銅鐵木石建殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 22:5; 列王紀上 3:7; 歷代志下 13:7"> 大衛王對會眾說：「我兒子所羅門是神特選的，還年幼嬌嫩。這工程甚大，因這殿不是為人，乃是為耶和華神建造的。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 22:3–5; 哥林多後書 8:3; 以賽亞書 54:11–12"> 我為我神的殿已經盡力預備金子做金器，銀子做銀器，銅做銅器，鐵做鐵器，木做木器，還有紅瑪瑙、可鑲嵌的寶石、彩石和一切的寶石，並許多漢白玉。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 21:24; 詩篇 27:4; 詩篇 26:8"> 且因我心中愛慕我神的殿，就在預備建造聖殿的材料之外，又將我自己積蓄的金銀獻上，建造我神的殿，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:28; 歷代志上 22:14; 約伯記 28:16"> 就是俄斐金三千他連得，精煉的銀子七千他連得，以貼殿牆，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 7:2–3; 出埃及記 35:5–9; 以斯拉記 7:15–16"> 金子做金器，銀子做銀器，並藉匠人的手製造一切。今日有誰樂意將自己獻給耶和華呢？」</span>
</div>
</div>

## 會眾盡心樂輸

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 9:7; 歷代志上 27:25–1; 以賽亞書 60:3–10"> 於是，眾族長和以色列各支派的首領、千夫長、百夫長，並監管王工的官長，都樂意獻上。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 7:70–71; 以斯拉記 2:69"> 他們為神殿的使用，獻上金子五千他連得零一萬達利克，銀子一萬他連得，銅一萬八千他連得，鐵十萬他連得。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 23:8; 歷代志上 26:21–22"> 凡有寶石的都交給革順人耶歇，送入耶和華殿的府庫。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 9:7–8; 哥林多後書 8:3; 列王紀上 8:61"> 因這些人誠心樂意獻給耶和華，百姓就歡喜，大衛王也大大歡喜。</span>
</div>
</div>

## 大衛稱頌耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以弗所書 1:3; 彼得前書 1:3; 羅馬書 1:7"> 所以，大衛在會眾面前稱頌耶和華說：「耶和華，我們的父以色列的神，是應當稱頌直到永永遠遠的！</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 1:3; 但以理書 4:34–35; 提摩太前書 1:17"> 耶和華啊，尊大、能力、榮耀、強盛、威嚴都是你的，凡天上地下的都是你的，國度也是你的，並且你為至高，為萬有之首。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 3:16; 歷代志下 20:6; 申命記 8:18"> 豐富、尊榮都從你而來，你也治理萬物。在你手裡有大能大力，使人尊大、強盛都出於你。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:1; 哥林多後書 9:15; 哥林多後書 8:16"> 我們的神啊，現在我們稱謝你，讚美你榮耀之名。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:17; 哥林多後書 3:5; 羅馬書 11:36"> 我算什麼，我的民算什麼，竟能如此樂意奉獻？因為萬物都從你而來，我們把從你而得的獻給你。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 144:4; 利未記 25:23; 詩篇 102:11"> 我們在你面前是客旅，是寄居的，與我們列祖一樣。我們在世的日子如影兒，不能長存<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：沒有長存的指望。">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 29:14; 詩篇 24:1; 歷代志下 31:10"> 耶和華我們的神啊，我們預備這許多材料要為你的聖名建造殿宇，都是從你而來，都是屬你的。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 17:10; 箴言 11:20; 歷代志上 28:9"> 我的神啊，我知道你察驗人心，喜悅正直。我以正直的心樂意獻上這一切物，現在我喜歡見你的民在這裡都樂意奉獻於你。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 32:39; 耶利米書 10:23; 希伯來書 13:21"> 耶和華我們列祖亞伯拉罕、以撒、以色列的神啊，求你使你的民常存這樣的心思意念，堅定他們的心歸向你。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 72:1; 歷代志上 28:9; 雅各書 1:17"> 又求你賜我兒子所羅門誠實的心，遵守你的命令、法度、律例，成就這一切的事，用我所預備的建造殿宇。」</span>
</div>
</div>

## 會眾稱頌耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 95:6; 出埃及記 4:31; 詩篇 135:19–21"> 大衛對全會眾說：「你們應當稱頌耶和華你們的神！」於是會眾稱頌耶和華他們列祖的神，低頭拜耶和華與王。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 7:4–9; 民數記 15:7; 以斯拉記 6:17"> 次日，他們向耶和華獻平安祭和燔祭，就是獻公牛一千隻、公綿羊一千隻、羊羔一千隻，並同獻的奠祭，又為以色列眾人獻許多的祭。那日他們在耶和華面前吃喝，大大歡樂。</span>
</div>
</div>

## 復膏所羅門立之為王

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王紀上 2:35; 歷代志上 23:1; 出埃及記 24:11"> 他們奉耶和華的命再膏大衛的兒子所羅門做王，又膏撒督做祭司。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 2:12; 歷代志上 28:5; 羅馬書 13:1"> 於是所羅門坐在耶和華所賜的位上，接續他父親大衛做王，萬事亨通。以色列眾人也都聽從他。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 2:3–9; 以西結書 17:18; 創世記 24:2"> 眾首領和勇士，並大衛王的眾子，都順服所羅門王。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 1:12; 歷代志下 1:1; 傳道書 2:9"> 耶和華使所羅門在以色列眾人眼前甚為尊大，極其威嚴，勝過在他以前的以色列王。</span>
</div>
</div>

## 大衛壽終

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 18:14; 詩篇 78:71–72"> 耶西的兒子大衛做以色列眾人的王。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:11; 撒母耳記下 5:4–5; 歷代志上 3:4"> 做王共四十年，在希伯崙做王七年，在耶路撒冷做王三十三年。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:15; 使徒行傳 13:36; 歷代志上 23:1"> 他年紀老邁，日子滿足，享受豐富、尊榮，就死了，他兒子所羅門接續他做王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 9:9; 撒母耳記下 12:1–7; 歷代志上 21:9–11"> 大衛王始終的事，都寫在先見撒母耳的書上和先知拿單並先見迦得的書上。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 4:25; 但以理書 4:23; 但以理書 2:21"> 他的國事和他的勇力，以及他和以色列並列國所經過的事，都寫在這書上。</span>
</div>
</div>

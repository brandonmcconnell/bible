## 居耶路撒冷之以色列後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 7:64; 歷代志上 5:25–26; 耶利米書 52:14–15"> 以色列人都按家譜計算，寫在《以色列諸王記》上。猶大人因犯罪就被擄到巴比倫。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 7:73; 以斯拉記 2:58; 以斯拉記 2:70"> 先從巴比倫回來住在自己地業城邑中的有以色列人、祭司、利未人、尼提寧的首領。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 11:1; 歷代志下 11:16; 尼希米記 11:4–9"> 住在耶路撒冷的有猶大人、便雅憫人、以法蓮人、瑪拿西人。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 2:5; 創世記 46:12; 民數記 26:20"> 猶大兒子法勒斯的子孫中有烏太，烏太是亞米忽的兒子，亞米忽是暗利的兒子，暗利是音利的兒子，音利是巴尼的兒子。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 26:20; 尼希米記 11:5"> 示羅的子孫中有長子亞帥雅和他的眾子。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:20; 歷代志上 2:6; 創世記 38:30"> 謝拉的子孫中有耶烏利和他的弟兄，共六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 10:20; 尼希米記 11:7; 尼希米記 8:4"> 便雅憫人中有哈西努的曾孫、何達威雅的孫子、米書蘭的兒子撒路，</span>
<span className="v" id="v8" data-v="8"> 又有耶羅罕的兒子伊比尼雅，米基立的孫子、烏西的兒子以拉，伊比尼雅的曾孫、流珥的孫子、示法提雅的兒子米書蘭，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 11:8"> 和他們的族弟兄，按著家譜計算，共有九百五十六名。這些人都是他們的族長。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="尼希米記 12:19; 尼希米記 11:10–24"> 祭司中，有耶大雅、耶何雅立、雅斤；</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 11:11; 列王紀下 25:18; 民數記 4:33"> 還有管理神殿希勒家的兒子亞薩利雅，希勒家是米書蘭的兒子，米書蘭是撒督的兒子，撒督是米拉約的兒子，米拉約是亞希突的兒子；</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 7:40; 以斯拉記 2:37; 尼希米記 11:12–13"> 有瑪基雅的曾孫、巴施戶珥的孫子、耶羅罕的兒子亞大雅；又有亞第業的兒子瑪賽，亞第業是雅希細拉的兒子，雅希細拉是米書蘭的兒子，米書蘭是米實利密的兒子，米實利密是音麥的兒子。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 11:14; 歷代志上 26:30; 歷代志上 26:32"> 他們和眾弟兄都是族長，共有一千七百六十人，是善於做神殿使用之工的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 26:57; 尼希米記 10:11; 歷代志上 6:29"> 利未人米拉利的子孫中，有哈沙比雅的曾孫、押利甘的孫子、哈述的兒子示瑪雅，</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 11:22; 尼希米記 11:17; 歷代志上 11:17"> 有拔巴甲，黑勒施，迦拉，並亞薩的曾孫、細基利的孫子、米迦的兒子瑪探雅，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 25:1; 歷代志下 35:15; 歷代志上 12:25"> 又有耶杜頓的曾孫、迦拉的孫子、示瑪雅的兒子俄巴底，還有以利加拿的孫子、亞撒的兒子比利家（他們都住在尼陀法人的村莊）。</span>
</div>
</div>

## 利未人之職任

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:1–32; 歷代志上 23:5; 尼希米記 11:19"> 守門的是沙龍、亞谷、達們、亞希幔和他們的弟兄，沙龍為長。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 46:1–2; 以西結書 44:2–3; 列王紀上 10:5"> 從前這些人看守朝東的王門，如今是利未營中守門的。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 26:9–11; 詩篇 44:1; 列王紀下 11:15"> 可拉的曾孫、以比雅撒的孫子、可利的兒子沙龍和他的族弟兄可拉人都管理使用之工，並守會幕的門。他們的祖宗曾管理耶和華的營盤，又把守營門，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 31:6; 民數記 3:32; 民數記 4:33"> 從前以利亞撒的兒子非尼哈管理他們，耶和華也與他同在。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 26:14; 歷代志上 26:2"> 米施利米雅的兒子撒迦利雅是看守會幕之門的。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 9:9; 歷代志上 28:13; 歷代志上 23:1–32"> 被選守門的人共有二百一十二名，他們在自己的村莊，按著家譜計算，是大衛和先見撒母耳所派當這緊要職任的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 44:14; 歷代志下 23:19; 以西結書 44:10–11"> 他們和他們的子孫按著班次看守耶和華殿的門，就是會幕的門。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 26:14–18"> 在東、西、南、北，四方都有守門的。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 11:5; 歷代志下 23:8; 列王紀下 11:7"> 他們的族弟兄住在村莊，每七日來與他們換班。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米記 13:5; 尼希米記 10:38–39; 歷代志上 26:20–27"> 這四個門領都是利未人，各有緊要的職任，看守神殿的倉庫。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 23:30–32; 瑪拉基書 1:10; 撒母耳記上 3:15"> 他們住在神殿的四圍，是因委託他們守殿，要每日早晨開門。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米記 13:4–5; 尼希米記 12:44; 歷代志上 26:22–26"> 利未人中有管理使用器皿的，按著數目拿出拿入。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 23:29; 出埃及記 30:23–38; 出埃及記 27:20"> 又有人管理器具和聖所的器皿，並細麵、酒、油、乳香、香料。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 30:23–25; 出埃及記 37:29; 出埃及記 30:35–38"> 祭司中有人用香料做膏油。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 9:19; 歷代志上 9:22; 利未記 6:21"> 利未人瑪他提雅是可拉族沙龍的長子，他緊要的職任是管理盤中烤的物。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 24:5–8; 歷代志上 6:33–48; 出埃及記 25:30"> 他們族弟兄哥轄子孫中有管理陳設餅的，每安息日預備擺列。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歷代志上 6:31–33; 詩篇 134:1–2; 歷代志上 16:4–6"> 歌唱的有利未人的族長，住在屬殿的房屋，晝夜供職，不做別樣的工。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 11:1–15; 歷代志上 9:13"> 以上都是利未人著名的族長，住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歷代志上 2:23–24; 歷代志上 2:50–52; 歷代志上 8:29–40"> 在基遍住的有基遍的父親耶利，他的妻名叫瑪迦。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 9:39; 歷代志上 8:33"> 他長子是亞伯頓，他又生蘇珥、基士、巴力、尼珥、拿答、</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 8:31"> 基多、亞希約、撒迦利雅、米基羅。</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 8:32"> 米基羅生示米暗。這些人和他們的弟兄在耶路撒冷對面居住。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 13:22; 歷代志上 8:33–38; 歷代志上 10:2"> 尼珥生基士，基士生掃羅，掃羅生約拿單、麥基舒亞、亞比拿達、伊施巴力。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 4:4; 歷代志上 8:34–36"> 約拿單的兒子是米力巴力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米力巴力即米非波設。">a</a></sup>，米力巴力生米迦。</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志上 8:35"> 米迦的兒子是毗敦、米勒、他利亞、亞哈斯。</span>
<span className="v" id="v42" data-v="42" data-xref="歷代志上 8:36"> 亞哈斯生雅拉，雅拉生亞拉篾、亞斯瑪威、心利，心利生摩撒，</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志上 8:37"> 摩撒生比尼亞，比尼亞生利法雅。利法雅的兒子是以利亞薩，以利亞薩的兒子是亞悉。</span>
<span className="v" id="v44" data-v="44"> 亞悉有六個兒子，他們的名字是亞斯利干、波基路、以實瑪利、示亞利雅、俄巴底雅、哈難，這都是亞悉的兒子。</span>
</div>

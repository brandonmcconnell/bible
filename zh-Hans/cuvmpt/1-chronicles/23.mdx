## 利未人之職任

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:1; 歷代志下 34:29–30; 歷代志上 13:1"> 大衛招聚以色列的眾首領和祭司、利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 23:24; 民數記 4:2–49"> 利未人從三十歲以外的都被數點，他們男丁的數目共有三萬八千。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 19:8; 申命記 16:18; 歷代志上 26:29–31"> 其中有二萬四千人管理耶和華殿的事，有六千人做官長和士師，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:25–26; 歷代志下 8:14; 詩篇 87:7"> 有四千人做守門的，又有四千人用大衛所做的樂器頌讚耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 8:14; 歷代志上 6:1; 歷代志上 6:16"> 大衛將利未人革順、哥轄、米拉利的子孫分了班次。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 26:21; 出埃及記 6:17; 歷代志上 6:17–20"> 革順的子孫有拉但和示每。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 6:33–34; 歷代志上 15:20–21; 歷代志上 15:7"> 拉但的長子是耶歇，還有細坦和約珥，共三人。</span>
<span className="v" id="v9" data-v="9"> 示每的兒子是示羅密、哈薛、哈蘭三人。這是拉但族的族長。</span>
<span className="v" id="v10" data-v="10"> 示每的兒子是雅哈、細拿、耶烏施、比利亞，共四人。</span>
<span className="v" id="v11" data-v="11"> 雅哈是長子，細撒是次子，但耶烏施和比利亞的子孫不多，所以算為一族。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 6:18; 民數記 3:27; 民數記 26:58"> 哥轄的兒子是暗蘭、以斯哈、希伯倫、烏薛，共四人。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 21:5; 出埃及記 6:20; 撒母耳記上 2:28"> 暗蘭的兒子是亞倫、摩西。亞倫和他的子孫分出來，好分別至聖的物，在耶和華面前燒香，侍奉他，奉他的名祝福，直到永遠。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:1; 詩篇 90:1; 歷代志上 26:23–25"> 至於神人摩西，他的子孫名字記在利未支派的冊上。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 18:3–4; 出埃及記 2:22; 出埃及記 4:20"> 摩西的兒子是革舜和以利以謝。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 26:24; 歷代志上 25:20; 歷代志上 24:20"> 革舜的長子是細布業。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:25"> 以利以謝的兒子是利哈比雅。以利以謝沒有別的兒子，但利哈比雅的子孫甚多。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 26:26; 歷代志上 24:22"> 以斯哈的長子是示羅密。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 24:23; 歷代志上 15:9; 歷代志上 23:12"> 希伯倫的長子是耶利雅，次子是亞瑪利亞，三子是雅哈悉，四子是耶加面。</span>
<span className="v" id="v20" data-v="20"> 烏薛的長子是米迦，次子是耶西雅。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 6:19; 歷代志上 6:20; 歷代志上 24:26–30"> 米拉利的兒子是抹利、母示。抹利的兒子是以利亞撒、基士。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 24:28; 民數記 36:6–8"> 以利亞撒死了，沒有兒子，只有女兒，他們本族基士的兒子娶了她們為妻。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 24:30"> 母示的兒子是末力、以得、耶利摩，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 10:17; 民數記 10:21; 歷代志上 23:3"> 以上利未子孫做族長的，照著男丁的數目，從二十歲以外，都辦耶和華殿的事務。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 132:13–14; 歷代志上 22:18; 撒母耳記下 7:11"> 大衛說：「耶和華以色列的神已經使他的百姓平安，他永遠住在耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 4:5; 民數記 7:9; 民數記 4:15"> 利未人不必再抬帳幕和其中所用的一切器皿了。」</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 23:24; 詩篇 72:20; 撒母耳記下 23:1"> 照著大衛臨終所吩咐的，利未人從二十歲以外的都被數點。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 35:3–6; 歷代志下 31:11; 歷代志下 35:11–14"> 他們的職任是：服侍亞倫的子孫，在耶和華的殿和院子並屋中辦事，潔淨一切聖物，就是辦神殿的事務；</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 19:35–36; 出埃及記 25:30; 利未記 6:20–23"> 並管理陳設餅，素祭的細麵，或無酵薄餅，或用盤烤或用油調和的物，又管理各樣的升斗尺度；</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 92:1–3; 以斯拉記 3:10–11; 歷代志上 9:33"> 每日早晚，站立稱謝讚美耶和華；</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 1:13–14; 民數記 28:1–29; 民數記 10:10"> 又在安息日、月朔並節期，按數照例，將燔祭常常獻給耶和華；</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 1:53; 民數記 3:38; 民數記 3:6–9"> 又看守會幕和聖所，並守耶和華吩咐他們弟兄亞倫子孫的，辦耶和華殿的事。</span>
</div>
</div>

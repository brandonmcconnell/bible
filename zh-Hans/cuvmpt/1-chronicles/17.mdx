## 大衛有意為耶和華建殿神不許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 6:7–9; 歷代志上 15:1; 歷代志上 17:5"> 大衛住在自己宮中，對先知拿單說：「看哪，我住在香柏木的宮中，耶和華的約櫃反在幔子裡！」</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 28:2; 哥林多前書 13:9; 撒迦利亞書 8:23"> 拿單對大衛說：「你可以照你的心意而行，因為神與你同在。」</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 3:7; 民數記 12:6; 以賽亞書 30:21"> 當夜，神的話臨到拿單說：</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:2–3; 以賽亞書 55:8–9; 歷代志下 6:8–9"> 「你去告訴我僕人大衛說：『耶和華如此說：你不可建造殿宇給我居住。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 7:6; 出埃及記 40:2–3; 列王紀上 8:16"> 自從我領以色列人出埃及直到今日，我未曾住過殿宇，乃從這會幕到那會幕，從這帳幕到那帳幕。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 7:7; 民數記 10:33–36; 哥林多後書 6:16"> 凡我同以色列人所走的地方，我何曾向以色列的一個士師，就是我吩咐牧養我民的，說：「你為何不給我建造香柏木的殿宇呢？」』</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 6:21; 出埃及記 3:1–10; 撒母耳記上 17:15"> 現在你要告訴我僕人大衛說：『萬軍之耶和華如此說：我從羊圈中將你召來，叫你不再跟從羊群，立你做我民以色列的君。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 18:14; 歷代志上 17:2; 詩篇 113:7–8"> 你無論往哪裡去，我常與你同在，剪除你的一切仇敵。我必使你得大名，好像世上大大有名的人一樣。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:23; 以西結書 28:4; 以弗所書 5:6"> 我必為我民以色列選定一個地方，栽培他們，使他們住自己的地方，不再遷移。凶惡之子也不像從前擾害他們，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 7:11; 士師記 2:14–18; 出埃及記 1:21"> 並不像我命士師治理我民以色列的時候一樣。我必制伏你的一切仇敵，並且我耶和華應許你，必為你建立家室。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 132:11; 列王紀上 1:21; 歷代志上 28:5"> 你壽數滿足歸你列祖的時候，我必使你的後裔接續你的位，我也必堅定他的國。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 5:5; 但以理書 2:44; 以賽亞書 9:7"> 他必為我建造殿宇，我必堅定他的國位直到永遠。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 1:5; 以賽亞書 55:3; 歷代志上 17:12"> 我要做他的父，他要做我的子；並不使我的慈愛離開他，像離開在你以前的掃羅一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 89:36; 路加福音 1:32–33; 詩篇 72:17"> 我卻要將他永遠堅立在我家裡和我國裡，他的國位也必堅定直到永遠。』」</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 23:28; 使徒行傳 20:27; 撒母耳記下 7:17"> 拿單就按這一切話，照這默示，告訴大衛。</span>
</div>
</div>

## 大衛之祈禱

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 7:18; 創世記 32:10; 以弗所書 3:8"> 於是大衛王進去，坐在耶和華面前，說：「耶和華神啊，我是誰，我的家算什麼，你竟使我到這地步呢？</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 17:11–15; 腓立比書 2:8–11; 以賽亞書 49:6"> 神啊，這在你眼中還看為小，又應許你僕人的家至於久遠。耶和華神啊，你看顧我好像看顧高貴的人！</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 21:17; 撒母耳記上 2:30; 撒母耳記下 7:20–24"> 你加於僕人的尊榮，我還有何言可說呢？因為你知道你的僕人。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 37:35; 撒母耳記下 7:21; 但以理書 9:17"> 耶和華啊，你行了這大事，並且顯明出來，是因你僕人的緣故，也是照你的心意。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 44:6; 耶利米書 10:6–7; 以弗所書 3:20"> 耶和華啊，照我們耳中聽見，沒有可比你的，除你以外再無神。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 20:9–10; 以賽亞書 63:9; 以賽亞書 48:9"> 世上有何民能比你的民以色列呢？你神從埃及救贖他們做自己的子民，又在你贖出來的民面前行大而可畏的事，驅逐列邦人，顯出你的大名。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 19:5–6; 彼得前書 2:9; 羅馬書 11:1–12"> 你使以色列人做你的子民直到永遠，你耶和華也做他們的神。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:49; 耶利米書 11:5; 路加福音 1:38"> 耶和華啊，你所應許僕人和僕人家的話，求你堅定直到永遠，照你所說的而行。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 6:13; 耶利米書 31:1; 啟示錄 21:3"> 願你的名永遠堅立，被尊為大，說：『萬軍之耶和華是以色列的神，是治理以色列的神！』這樣，你僕人大衛的家必在你面前堅立。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 9:15; 以西結書 36:37; 詩篇 10:17"> 我的神啊，因你啟示僕人說『我必為你建立家室』，所以僕人大膽在你面前祈禱。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 34:6–7; 希伯來書 6:18; 提多書 1:2"> 耶和華啊，唯有你是神，你也應許將這福氣賜給僕人。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所書 1:3; 羅馬書 11:29; 詩篇 72:17"> 現在你喜悅賜福於僕人的家，可以永存在你面前。耶和華啊，你已經賜福，還要賜福到永遠。」</span>
</div>

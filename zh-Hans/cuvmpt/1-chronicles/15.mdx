## 為神櫃備所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 16:1; 歷代志上 17:1–5; 詩篇 132:5"> 大衛在大衛城為自己建造宮殿，又為神的約櫃預備地方，支搭帳幕。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 10:8; 申命記 31:9; 民數記 18:1–8"> 那時大衛說：「除了利未人之外，無人可抬神的約櫃，因為耶和華揀選他們抬神的約櫃，且永遠侍奉他。」</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:1; 歷代志上 13:5; 歷代志上 15:1"> 大衛招聚以色列眾人到耶路撒冷，要將耶和華的約櫃抬到他所預備的地方。</span>
</div>
</div>

## 任利未人舁約櫃

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 6:16–22; 歷代志上 12:26–28; 歷代志上 6:16–30"> 大衛又聚集亞倫的子孫和利未人：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 6:22–24"> 哥轄子孫中，有族長烏列和他的弟兄一百二十人；</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 6:29–30"> 米拉利子孫中，有族長亞帥雅和他的弟兄二百二十人；</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 15:11; 歷代志上 23:8"> 革順子孫中，有族長約珥和他的弟兄一百三十人；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 6:22"> 以利撒反子孫中，有族長示瑪雅和他的弟兄二百人；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 6:18; 歷代志上 23:19; 歷代志上 26:30–31"> 希伯崙子孫中，有族長以列和他的弟兄八十人；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 6:18; 歷代志上 6:18; 歷代志上 23:12"> 烏薛子孫中，有族長亞米拿達和他的弟兄一百一十二人。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 12:28; 列王紀上 2:35; 撒母耳記上 22:20–23"> 大衛將祭司撒督和亞比亞他，並利未人烏列、亞帥雅、約珥、示瑪雅、以列、亞米拿達召來，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:6; 出埃及記 19:14–15; 歷代志上 15:14"> 對他們說：「你們是利未人的族長，你們和你們的弟兄應當自潔，好將耶和華以色列神的約櫃抬到我所預備的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 6:3; 哥林多前書 14:40; 約翰一書 1:8–10"> 因你們先前沒有抬這約櫃，按定例求問耶和華我們的神，所以他刑罰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：闖殺。">a</a></sup>我們。」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 29:15; 約珥書 2:16–17; 歷代志下 29:34"> 於是祭司、利未人自潔，好將耶和華以色列神的約櫃抬上來。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 4:15; 民數記 7:9; 歷代志下 5:9"> 利未子孫就用槓，肩抬神的約櫃，是照耶和華藉摩西所吩咐的。</span>
</div>
</div>

## 命利未族長立謳歌者作樂

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志上 13:8; 歷代志下 5:13; 歷代志上 16:42"> 大衛吩咐利未人的族長，派他們歌唱的弟兄用琴、瑟和鈸作樂，歡歡喜喜地大聲歌頌。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:39; 歷代志上 6:44; 歷代志上 6:33"> 於是利未人派約珥的兒子希幔和他弟兄中比利家的兒子亞薩，並他們族弟兄米拉利子孫、裡古沙雅的兒子以探，</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 26:4; 歷代志上 26:8; 歷代志上 13:14"> 其次還有他們的弟兄撒迦利雅、便雅薛、示米拉末、耶歇、烏尼、以利押、比拿雅、瑪西雅、瑪他提雅、以利斐利戶、彌克尼雅，並守門的俄別以東和耶利。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 25:6; 歷代志上 16:5; 歷代志上 13:8"> 這樣，派歌唱的希幔、亞薩、以探敲銅鈸，大發響聲；</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:1–11"> 派撒迦利雅、雅薛、示米拉末、耶歇、烏尼、以利押、瑪西雅、比拿雅鼓瑟，調用女音；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 10:5; 歷代志上 25:6–7; 詩篇 81:1–2"> 又派瑪他提雅、以利斐利戶、彌克尼雅、俄別以東、耶利、亞撒西雅領首彈琴，調用第八。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 15:27; 歷代志上 15:16; 歷代志上 25:7–8"> 利未人的族長基拿尼雅是歌唱人的首領，又教訓人歌唱，因為他精通此事。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 84:10; 列王紀下 22:4; 歷代志上 9:21–23"> 比利家、以利加拿是約櫃前守門的。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 16:6; 民數記 10:8; 歷代志上 15:28"> 祭司示巴尼、約沙法、拿坦業、亞瑪賽、撒迦利雅、比拿亞、以利以謝在神的約櫃前吹號。俄別以東和耶希亞也是約櫃前守門的。</span>
</div>
</div>

## 舁約櫃入大衛城

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 6:12–23; 彌迦書 5:2; 腓立比書 3:3"> 於是大衛和以色列的長老並千夫長，都去從俄別以東的家歡歡喜喜地將耶和華的約櫃抬上來。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 23:29; 歷代志上 29:14; 詩篇 66:13–15"> 神賜恩於抬耶和華約櫃的利未人，他們就獻上七隻公牛、七隻公羊。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 2:18; 撒母耳記下 6:14"> 大衛和抬約櫃的利未人，並歌唱人的首領基拿尼雅，以及歌唱的人，都穿著細麻布的外袍，大衛另外穿著細麻布的以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 13:8; 歷代志上 15:16; 歷代志下 5:12–13"> 這樣，以色列眾人歡呼、吹角、吹號、敲鈸、鼓瑟、彈琴，大發響聲，將耶和華的約櫃抬上來。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 6:20–23; 撒母耳記下 6:16; 申命記 31:26"> 耶和華的約櫃進了大衛城的時候，掃羅的女兒米甲從窗戶裡觀看，見大衛王踴躍跳舞，心裡就輕視他。</span>
</div>
</div>

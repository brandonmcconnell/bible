## 以色列族之班長

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 4:27; 歷代志下 26:11–13; 申命記 1:15"> 以色列人的族長、千夫長、百夫長和官長都分定班次，每班是二萬四千人，週年按月輪流，替換出入服侍王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 11:11; 撒母耳記下 23:8"> 正月第一班的班長是撒巴第業的兒子雅朔班，他班內有二萬四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 26:20; 民數記 10:14; 創世記 49:8–10"> 他是法勒斯的子孫，統管正月班的一切軍長。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 23:9; 歷代志上 11:12"> 二月的班長是亞合人朵代，還有副官密基羅，他班內有二萬四千人。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 18:17; 列王紀上 4:4–5"> 三月第三班的班長<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：軍長。下同。">a</a></sup>是祭司耶何耶大的兒子比拿雅，他班內有二萬四千人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 23:20–23; 歷代志上 11:22–25; 撒母耳記下 22:20–23"> 這比拿雅是那三十人中的勇士，管理那三十人，他班內又有他兒子暗米薩拔。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 11:26; 撒母耳記下 23:24; 撒母耳記下 2:18–23"> 四月第四班的班長是約押的兄弟亞撒黑，接續他的是他兒子西巴第雅，他班內有二萬四千人。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 11:27; 撒母耳記下 23:25; 歷代志上 26:29"> 五月第五班的班長是伊斯拉人珊合，他班內有二萬四千人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 11:28; 撒母耳記下 23:26"> 六月第六班的班長是提哥亞人益吉的兒子以拉，他班內有二萬四千人。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 11:27; 撒母耳記下 23:26"> 七月第七班的班長是以法蓮族比倫人希利斯，他班內有二萬四千人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 21:18; 歷代志上 11:29; 民數記 26:20"> 八月第八班的班長是謝拉族戶沙人西比該，他班內有二萬四千人。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 11:28; 撒母耳記下 23:27"> 九月第九班的班長是便雅憫族亞拿突人亞比以謝，他班內有二萬四千人。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 11:30; 撒母耳記下 23:28"> 十月第十班的班長是謝拉族尼陀法人瑪哈萊，他班內有二萬四千人。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 11:31; 撒母耳記下 23:30"> 十一月第十一班的班長是以法蓮族比拉頓人比拿雅，他班內有二萬四千人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 23:29; 歷代志上 4:13; 士師記 3:9"> 十二月第十二班的班長是俄陀聶族尼陀法人黑玳，他班內有二萬四千人。</span>
</div>
</div>

## 記各支派之長

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 管理以色列眾支派的記在下面：管魯本人的，是細基利的兒子以利以謝；管西緬人的，是瑪迦的兒子示法提雅；</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:30; 歷代志上 24:31; 歷代志上 12:27–28"> 管利未人的，是基母利的兒子哈沙比雅；管亞倫子孫的，是撒督；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:6; 撒母耳記上 17:29; 撒母耳記上 17:13"> 管猶大人的，是大衛的一個哥哥以利戶；管以薩迦人的，是米迦勒的兒子暗利；</span>
<span className="v" id="v19" data-v="19"> 管西布倫人的，是俄巴第雅的兒子伊施瑪雅；管拿弗他利人的，是亞斯列的兒子耶利摩；</span>
<span className="v" id="v20" data-v="20"> 管以法蓮人的，是阿撒細雅的兒子何細亞；管瑪拿西半支派的，是毗大雅的兒子約珥；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 3:27; 撒母耳記上 14:50–51; 撒母耳記下 3:37"> 管基列地瑪拿西那半支派的，是撒迦利亞的兒子易多；管便雅憫人的，是押尼珥的兒子雅西業；</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 28:1"> 管但人的，是耶羅罕的兒子亞薩列。以上是以色列眾支派的首領。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:5; 歷代志上 21:2–5; 希伯來書 11:12"> 以色列人二十歲以內的，大衛沒有記其數目，因耶和華曾應許說必加增以色列人如天上的星那樣多。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 21:1–17; 撒母耳記下 24:1–15"> 洗魯雅的兒子約押動手數點，當時耶和華的烈怒臨到以色列人，因此沒有點完，數目也沒有寫在《大衛王記》上。</span>
</div>
</div>

## 記大衛諸臣及其職守

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歷代志下 16:2; 出埃及記 1:11; 歷代志下 26:10"> 掌管王府庫的，是亞疊的兒子押斯馬威；掌管田野城邑村莊保障之倉庫的，是烏西雅的兒子約拿單；</span>
<span className="v" id="v26" data-v="26"> 掌管耕田種地的，是基綠的兒子以斯利；</span>
<span className="v" id="v27" data-v="27"> 掌管葡萄園的，是拉瑪人示每；掌管葡萄園酒窖的，是實弗米人撒巴底；</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 10:27; 歷代志下 1:15; 列王紀上 4:7"> 掌管高原橄欖樹和桑樹的，是基第利人巴勒哈南；掌管油庫的，是約阿施；</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 5:16; 以賽亞書 65:10"> 掌管沙崙牧放牛群的，是沙崙人施提賚；掌管山谷牧養牛群的，是亞第賚的兒子沙法；</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:6; 約伯記 1:3"> 掌管駝群的，是以實瑪利人阿比勒；掌管驢群的，是米崙人耶希底亞；掌管羊群的，是夏甲人雅悉。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 5:10"> 這都是給大衛王掌管產業的。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳記下 21:21; 撒母耳記下 13:3; 歷代志上 11:11"> 大衛的叔叔約拿單做謀士，這人有智慧，又做書記。哈摩尼的兒子耶歇做王眾子的師傅。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 15:12; 撒母耳記下 15:37; 撒母耳記下 15:32"> 亞希多弗也做王的謀士。亞基人戶篩做王的陪伴。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 11:6; 列王紀上 1:7; 歷代志上 27:5"> 亞希多弗之後，有比拿雅的兒子耶何耶大和亞比亞他接續他做謀士。約押做王的元帥。</span>
</div>

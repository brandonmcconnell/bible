## 可以得著不朽壞不衰殘的基業

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 1:23; 約翰一書 5:4; 羅馬書 15:13"> 願頌讚歸於我們主耶穌基督的父神！他曾照自己的大憐憫，藉著耶穌基督從死裡復活，重生了我們，叫我們有活潑的盼望，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 21:27; 希伯來書 9:15; 彼得前書 5:4"> 可以得著不能朽壞、不能玷汙、不能衰殘、為你們存留在天上的基業。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 1:6; 以弗所書 2:8; 帖撒羅尼迦後書 2:13–14"> 你們這因信蒙神能力保守的人，必能得著所預備、到末世要顯現的救恩。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:2; 彼得前書 5:10; 羅馬書 12:12"> 因此，你們是大有喜樂；但如今在百般的試煉中暫時憂愁，</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 23:10; 以賽亞書 48:10; 彼得前書 4:12"> 叫你們的信心既被試驗，就比那被火試驗仍然能壞的金子更顯寶貴，可以在耶穌基督顯現的時候得著稱讚、榮耀、尊貴。</span>
</div>
</div>

## 未見基督卻是愛他

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 20:29; 哥林多後書 5:7; 羅馬書 15:13"> 你們雖然沒有見過他，卻是愛他；如今雖不得看見，卻因信他就有說不出來、滿有榮光的大喜樂，</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 6:22; 雅各書 1:21; 希伯來書 11:13"> 並且得著你們信心的果效，就是靈魂的救恩。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 論到這救恩，那預先說你們要得恩典的眾先知早已詳細地尋求考察，</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 52:13–14; 彼得後書 1:21; 路加福音 24:25–27"> 就是考察在他們心裡基督的靈，預先證明基督受苦難、後來得榮耀是指著什麼時候，並怎樣的時候。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 15:26; 哥林多前書 2:10; 以弗所書 3:10"> 他們得了啟示，知道他們所傳講<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「傳講」原文作「服侍」。">a</a></sup>的一切事，不是為自己，乃是為你們。那靠著從天上差來的聖靈傳福音給你們的人，現在將這些事報給你們；天使也願意詳細察看這些事。</span>
</div>
</div>

## 應當聖潔因主是聖潔的

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前書 5:8; 路加福音 12:35; 彼得前書 4:7"> 所以要約束你們的心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：束上你們心中的腰。">b</a></sup>，謹慎自守，專心盼望耶穌基督顯現的時候所帶來給你們的恩。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 12:2; 提多書 3:3–5; 彼得前書 4:2–3"> 你們既做順命的兒女，就不要效法從前蒙昧無知的時候那放縱私慾的樣子。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:48; 哥林多後書 7:1; 希伯來書 12:14"> 那召你們的既是聖潔，你們在一切所行的事上也要聖潔。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 11:44; 利未記 19:2; 利未記 20:7"> 因為經上記著說：「你們要聖潔，因為我是聖潔的。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 10:34–35; 歷代志下 19:7; 馬太福音 6:9"> 你們既稱那不偏待人、按各人行為審判人的主為父，就當存敬畏的心度你們在世寄居的日子，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 6:20; 提多書 2:14; 詩篇 49:7–8"> 知道你們得贖，脫去你們祖宗所傳流虛妄的行為，不是憑著能壞的金銀等物，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 1:7; 彼得前書 2:22–24; 約翰福音 1:29"> 乃是憑著基督的寶血，如同無瑕疵、無玷汙的羔羊之血。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 1:4; 提摩太後書 1:9–10; 希伯來書 9:26"> 基督在創世以前是預先被神知道的，卻在這末世才為你們顯現。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 2:24; 希伯來書 2:9; 約翰福音 12:44"> 你們也因著他，信那叫他從死裡復活，又給他榮耀的神，叫你們的信心和盼望都在於神。</span>
</div>
</div>

## 藉著神的道得重生

<div className="bt">
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="提摩太前書 1:5; 希伯來書 13:1; 羅馬書 12:9–10"> 你們既因順從真理潔淨了自己的心，以致愛弟兄沒有虛假，就當從心裡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「從心裡」有古卷作「從清潔的心」。">c</a></sup>彼此切實相愛。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前書 1:3; 希伯來書 4:12; 約翰福音 1:13"> 你們蒙了重生，不是由於能壞的種子，乃是由於不能壞的種子，是藉著神活潑常存的道。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 40:6–8; 詩篇 103:15; 雅各書 4:14"> 因為，<br /><span className="pl pl-1">「凡有血氣的盡都如草，</span><br /><span className="pl pl-1">他的美榮都像草上的花。</span><br /><span className="pl pl-1">草必枯乾，花必凋謝，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 40:8; 馬太福音 5:18; 詩篇 119:89"> <span className="pl pl-1">唯有主的道是永存的。」</span><br />所傳給你們的福音就是這道。</span>
</div>

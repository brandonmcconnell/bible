## 示以後建之殿較前建者榮美尤大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈該書 1:1; 哈該書 2:20; 哈該書 2:10"> 七月二十一日，耶和華的話臨到先知哈該說：</span>
<span className="v" id="v2" data-v="2" data-xref="哈該書 1:1; 尼希米記 8:9; 以斯拉記 2:63"> 「你要曉諭猶大省長撒拉鐵的兒子所羅巴伯和約薩答的兒子大祭司約書亞，並剩下的百姓，說：</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 3:12; 哈該書 2:9; 以西結書 7:20"> 『你們中間存留的，有誰見過這殿從前的榮耀呢？現在你們看著如何？豈不在眼中看如無有嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:20; 約書亞記 1:9; 撒迦利亞書 8:9"> 耶和華說：所羅巴伯啊，雖然如此，你當剛強！約薩答的兒子大祭司約書亞啊，你也當剛強！這地的百姓，你們都當剛強做工！因為我與你們同在。這是萬軍之耶和華說的。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 34:10; 出埃及記 29:45–46; 以賽亞書 41:13"> 這是照著你們出埃及我與你們立約的話，那時我的靈住在你們中間。你們不要懼怕！</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 12:26–28; 以賽亞書 10:25; 馬可福音 13:24–26"> 萬軍之耶和華如此說：過不多時，我必再一次震動天地、滄海與旱地。</span>
<span className="v" id="v7" data-v="7" data-xref="瑪拉基書 3:1; 列王紀上 8:11; 約翰福音 7:37–39"> 我必震動萬國，萬國的珍寶必都運來<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：萬國所羨慕的必來到。">a</a></sup>，我就使這殿滿了榮耀。這是萬軍之耶和華說的。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 50:10–12; 詩篇 24:1; 以賽亞書 60:17"> 萬軍之耶和華說：銀子是我的，金子也是我的。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 85:8–9; 哥林多後書 3:9–10; 歌羅西書 1:19–21"> 這殿後來的榮耀必大過先前的榮耀，在這地方我必賜平安。這是萬軍之耶和華說的。』」</span>
</div>
</div>

## 未建殿以前民所獻者不潔故諸事不利

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哈該書 2:20; 哈該書 1:1; 哈該書 1:15–1"> 大流士王第二年九月二十四日，耶和華的話臨到先知哈該說：</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 10:10–11; 瑪拉基書 2:7; 申命記 33:10"> 「萬軍之耶和華如此說：你要向祭司問律法，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 6:27; 馬太福音 23:19; 利未記 7:6"> 若有人用衣襟兜聖肉，這衣襟挨著餅或湯，或酒，或油，或別的食物，便算為聖嗎？」祭司說：「不算為聖。」</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 5:2–3; 民數記 19:11–22; 利未記 22:4–6"> 哈該又說：「若有人因摸死屍染了汙穢，然後挨著這些物的哪一樣，這物算汙穢嗎？」祭司說：「必算汙穢。」</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; 提多書 1:15; 以賽亞書 1:11–15"> 於是哈該說：「耶和華說：這民這國在我面前也是如此，他們手下的各樣工作都是如此，他們在壇上所獻的也是如此。</span>
<span className="v" id="v15" data-v="15" data-xref="哈該書 1:5; 以斯拉記 3:10; 以斯拉記 4:24"> 現在你們要追想，此日以前，耶和華的殿沒有一塊石頭壘在石頭上的光景。</span>
<span className="v" id="v16" data-v="16" data-xref="哈該書 1:6; 瑪拉基書 2:2; 箴言 3:9–10"> 在那一切日子，有人來到穀堆，想得二十斗只得了十斗；有人來到酒池，想得五十桶只得了二十桶。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:22; 哈該書 1:11; 哈該書 1:9"> 在你們手下的各樣工作上，我以旱風、霉爛、冰雹攻擊你們，你們仍不歸向我。這是耶和華說的。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 8:9; 哈該書 2:15; 以斯拉記 5:1–2"> 你們要追想此日以前，就是從這九月二十四日起，追想到立耶和華殿根基的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 3:10; 哈巴谷書 3:17–18; 箴言 3:9–10"> 倉裡有穀種嗎？葡萄樹、無花果樹、石榴樹、橄欖樹都沒有結果子。從今日起，我必賜福於你們。」</span>
</div>
</div>

## 主許簡所羅巴伯

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20"> 這月二十四日，耶和華的話二次臨到哈該說：</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 4:6–10; 哈該書 2:6–7; 哈該書 1:1"> 「你要告訴猶大省長所羅巴伯說，我必震動天地。</span>
<span className="v" id="v22" data-v="22" data-xref="彌迦書 5:10; 士師記 7:22; 西番雅書 3:8"> 我必傾覆列國的寶座，除滅列邦的勢力，並傾覆戰車和坐在其上的。馬必跌倒，騎馬的敗落，各人被弟兄的刀所殺。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 43:10; 以賽亞書 42:1; 雅歌 8:6"> 萬軍之耶和華說：我僕人撒拉鐵的兒子所羅巴伯啊，到那日，我必以你為印，因我揀選了你。這是萬軍之耶和華說的。」</span>
</div>
</div>

<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="詩篇 10:7; 詩篇 7:14; 詩篇 28:3"> <span className="pl pl-1">因為他們的心圖謀強暴，</span><br /><span className="pl pl-1">他們的口談論奸惡。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 哥林多前書 3:9; 箴言 9:1"> <span className="pl pl-1">房屋因智慧建造，</span><br /><span className="pl pl-1">又因聰明立穩，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 15:6; 箴言 21:20; 箴言 20:15"> <span className="pl pl-1">其中因知識充滿各樣美好寶貴的財物。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 7:19; 歌羅西書 1:11; 箴言 21:22"> <span className="pl pl-1">智慧人大有能力，</span><br /><span className="pl pl-1">有知識的人力上加力。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 11:14; 箴言 20:18; 箴言 15:22"> <span className="pl pl-1">你去打仗，要憑智謀，</span><br /><span className="pl pl-1">謀士眾多，人便得勝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 14:6; 詩篇 10:5; 哥林多前書 2:14"> <span className="pl pl-1">智慧極高，非愚昧人所能及，</span><br /><span className="pl pl-1">所以在城門內不敢開口。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 21:11; 以西結書 38:10–11; 箴言 14:22"> <span className="pl pl-1">設計作惡的，</span><br /><span className="pl pl-1">必稱為奸人。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 15:19; 哥林多後書 10:5; 以賽亞書 55:7"> <span className="pl pl-1">愚妄人的思念乃是罪惡，</span><br /><span className="pl pl-1">褻慢者為人所憎惡。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:28–31; 以弗所書 3:13; 耶利米書 51:46"> <span className="pl pl-1">你在患難之日若膽怯，</span><br /><span className="pl pl-1">你的力量就微小。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 82:4; 以賽亞書 58:6–7; 約翰一書 3:16–17"> <span className="pl pl-1">人被拉到死地，你要解救；</span><br /><span className="pl pl-1">人將被殺，你須攔阻。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 34:11; 啟示錄 2:23; 耶利米書 17:10"> <span className="pl pl-1">你若說「這事我未曾知道」，</span><br /><span className="pl pl-1">那衡量人心的豈不明白嗎？</span><br /><span className="pl pl-1">保守你命的豈不知道嗎？</span><br /><span className="pl pl-1">他豈不按各人所行的報應各人嗎？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 7:15; 雅歌 5:1; 箴言 25:16"> <span className="pl pl-1">我兒，你要吃蜜，因為是好的。</span><br /><span className="pl pl-1">吃蜂房下滴的蜜，便覺甘甜。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:25; 耶利米書 15:16; 箴言 2:10"> <span className="pl pl-1">你心得了智慧，也必覺得如此。</span><br /><span className="pl pl-1">你若找著，至終必有善報，</span><br /><span className="pl pl-1">你的指望也不致斷絕。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:24; 以賽亞書 32:18; 撒母耳記上 23:20–23"> <span className="pl pl-1">你這惡人，不要埋伏攻擊義人的家，</span><br /><span className="pl pl-1">不要毀壞他安居之所。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 34:19; 詩篇 37:24; 彌迦書 7:8–10"> <span className="pl pl-1">因為義人雖七次跌倒，仍必興起，</span><br /><span className="pl pl-1">惡人卻被禍患傾倒。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="俄巴底亞書 1:12; 約伯記 31:29; 箴言 17:5"> <span className="pl pl-1">你仇敵跌倒，你不要歡喜；</span><br /><span className="pl pl-1">他傾倒，你心不要快樂。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 1:15–16; 耶利米哀歌 4:21–22"> <span className="pl pl-1">恐怕耶和華看見就不喜悅，</span><br /><span className="pl pl-1">將怒氣從仇敵身上轉過來。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 119:115; 詩篇 37:1; 箴言 23:17"> <span className="pl pl-1">不要為作惡的心懷不平，</span><br /><span className="pl pl-1">也不要嫉妒惡人。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:9; 約伯記 18:5–6; 詩篇 11:6"> <span className="pl pl-1">因為惡人終不得善報，</span><br /><span className="pl pl-1">惡人的燈也必熄滅。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 13:1–7; 彼得前書 2:13–17; 提多書 3:1"> <span className="pl pl-1">我兒，你要敬畏耶和華與君王，</span><br /><span className="pl pl-1">不要與反覆無常的人結交。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 90:11; 何西阿書 5:11; 民數記 16:31–35"> <span className="pl pl-1">因為他們的災難必忽然而起，</span><br /><span className="pl pl-1">耶和華與君王所施行的毀滅，</span><br /><span className="pl pl-1">誰能知道呢？</span></span>
</div>

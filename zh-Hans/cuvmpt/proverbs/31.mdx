## 利慕伊勒母戒子之箴言

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 6:20; 箴言 1:8; 提摩太後書 1:5"> 利慕伊勒王的言語，是他母親教訓他的真言。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 49:15; 撒母耳記上 1:11; 撒母耳記上 1:28"> <span className="pl pl-1">我的兒啊，我腹中生的兒啊，</span><br /><span className="pl pl-1">我許願得的兒啊，我當怎樣教訓你呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 17:17; 尼希米記 13:26; 箴言 7:26–27"> <span className="pl pl-1">不要將你的精力給婦女，</span><br /><span className="pl pl-1">也不要有敗壞君王的行為。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 20:1; 傳道書 10:17; 以賽亞書 5:22"> <span className="pl pl-1">利慕伊勒啊，君王喝酒，君王喝酒不相宜，</span><br /><span className="pl pl-1">王子說「濃酒在哪裡」也不相宜。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="以弗所書 5:18"> <span className="pl pl-1">讓他喝了，就忘記他的貧窮，</span><br /><span className="pl pl-1">不再記念他的苦楚。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 82:3–4; 箴言 24:11–12; 以斯帖記 4:13–16"> <span className="pl pl-1">你當為啞巴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：不能自辯的。">a</a></sup><br /><span className="pl pl-1">開口，</span><br /><span className="pl pl-1">為一切孤獨的申冤。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 1:17; 利未記 19:15; 阿摩司書 5:11–12"> <span className="pl pl-1">你當開口按公義判斷，</span><br /><span className="pl pl-1">為困苦和窮乏的辨屈。</span></span>

## 論賢婦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="箴言 19:14; 箴言 12:4; 箴言 18:22"> <span className="pl pl-1">才德的婦人誰能得著呢？</span><br /><span className="pl pl-1">她的價值勝過珍珠。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前書 3:1–7; 列王紀下 4:22–23; 列王紀下 4:9–10"> <span className="pl pl-1">她丈夫心裡倚靠她，</span><br /><span className="pl pl-1">必不缺少利益。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 25:18–22; 撒母耳記上 25:26–27"> <span className="pl pl-1">她一生使丈夫有益無損。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提多書 2:5; 提摩太前書 5:10; 帖撒羅尼迦後書 3:10–12"> <span className="pl pl-1">她尋找羊絨和麻，</span><br /><span className="pl pl-1">甘心用手做工。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 31:24; 列王紀上 9:26–28; 以西結書 27:3–36"> <span className="pl pl-1">她好像商船，從遠方運糧來。</span><br /></span>

<span className="v" id="v16" data-v="16" data-xref="馬太福音 13:44; 雅歌 8:12; 約書亞記 15:18"> <span className="pl pl-1">她想得田地就買來，</span><br /><span className="pl pl-1">用手所得之利栽種葡萄園。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 38:3; 彼得前書 1:13; 以弗所書 6:10"> <span className="pl pl-1">她以能力束腰，</span><br /><span className="pl pl-1">使膀臂有力。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 2:9; 馬太福音 25:3–10; 詩篇 127:2"> <span className="pl pl-1">她覺得所經營的有利，</span><br /><span className="pl pl-1">她的燈終夜不滅。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 35:25–26"> <span className="pl pl-1">她手拿撚線竿，</span><br /><span className="pl pl-1">手把紡線車。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 4:28; 希伯來書 13:16; 箴言 22:9"> <span className="pl pl-1">她張手賙濟困苦人，</span><br /><span className="pl pl-1">伸手幫補窮乏人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:22; 撒母耳記下 1:24; 箴言 25:20"> <span className="pl pl-1">她不因下雪為家裡的人擔心，</span><br /><span className="pl pl-1">因為全家都穿著朱紅衣服。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 19:8; 箴言 7:16; 創世記 41:42"> <span className="pl pl-1">她為自己製作繡花毯子，</span><br /><span className="pl pl-1">她的衣服是細麻和紫色布做的。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 12:4; 路得記 4:1; 申命記 16:18"> <span className="pl pl-1">她丈夫在城門口與本地的長老同坐，</span><br /><span className="pl pl-1">為眾人所認識。</span><br /></span>

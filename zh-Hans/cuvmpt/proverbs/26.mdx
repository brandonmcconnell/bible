## 箴言雜記

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 19:10; 箴言 28:16; 以斯帖記 4:6"> <span className="pl pl-1">夏天落雪，收割時下雨，都不相宜，</span><br /><span className="pl pl-1">愚昧人得尊榮，也是如此。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民數記 23:8; 尼希米記 13:2; 詩篇 109:28"> <span className="pl pl-1">麻雀往來，燕子翻飛，</span><br /><span className="pl pl-1">這樣，無故的咒詛也必不臨到。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 10:13; 詩篇 32:9; 哥林多前書 4:21"> <span className="pl pl-1">鞭子是為打馬，轡頭是為勒驢，</span><br /><span className="pl pl-1">刑杖是為打愚昧人的背。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 26:5; 彼得前書 3:9; 猶大書 1:9"> <span className="pl pl-1">不要照愚昧人的愚妄話回答他，</span><br /><span className="pl pl-1">恐怕你與他一樣。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 12:16; 馬太福音 16:1–4; 箴言 28:11"> <span className="pl pl-1">要照愚昧人的愚妄話回答他，</span><br /><span className="pl pl-1">免得他自以為有智慧。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 10:26; 箴言 25:13; 箴言 13:17"> <span className="pl pl-1">藉愚昧人手寄信的，</span><br /><span className="pl pl-1">是砍斷自己的腳，自受</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「自受」原文作「喝」。">a</a></sup><br /><span className="pl pl-1">損害。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:9; 詩篇 64:8; 箴言 17:7"> <span className="pl pl-1">瘸子的腳空存無用，</span><br /><span className="pl pl-1">箴言在愚昧人的口中也是如此。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:1; 箴言 30:22; 箴言 19:10"> <span className="pl pl-1">將尊榮給愚昧人的，</span><br /><span className="pl pl-1">好像人把石子包在機弦裡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 23:35"> <span className="pl pl-1">箴言在愚昧人的口中，</span><br /><span className="pl pl-1">好像荊棘刺入醉漢的手。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 2:6; 箴言 11:31"> <span className="pl pl-1">雇愚昧人的與雇過路人的，</span><br /><span className="pl pl-1">就像射傷眾人的弓箭手。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 2:22; 馬太福音 12:45; 出埃及記 8:15"> <span className="pl pl-1">愚昧人行愚妄事，行了又行，</span><br /><span className="pl pl-1">就如狗轉過來吃他所吐的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:20; 哥林多前書 3:18–19; 箴言 26:5"> <span className="pl pl-1">你見自以為有智慧的人嗎？</span><br /><span className="pl pl-1">愚昧人比他更有指望。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 22:13; 箴言 19:15; 箴言 15:19"> <span className="pl pl-1">懶惰人說：「道上有猛獅！</span><br /><span className="pl pl-1">街上有壯獅！」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 6:12; 箴言 12:27; 箴言 12:24"> <span className="pl pl-1">門在樞紐轉動，</span><br /><span className="pl pl-1">懶惰人在床上也是如此。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:24"> <span className="pl pl-1">懶惰人放手在盤子裡，</span><br /><span className="pl pl-1">就是向口撤回，也以為勞乏。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 26:12; 彼得前書 3:15; 箴言 12:15"> <span className="pl pl-1">懶惰人看自己比七個善於應對的人更有智慧。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:3; 提摩太後書 2:23–24; 路加福音 12:14"> <span className="pl pl-1">過路被事激動，管理不干己的爭競，</span><br /><span className="pl pl-1">好像人揪住狗耳。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 25:18; 以賽亞書 50:11; 箴言 7:23"> <span className="pl pl-1">人欺凌鄰舍，卻說：</span><br /><span className="pl pl-1">「我豈不是戲耍嗎？」</span><br /><span className="pl pl-1">他就像瘋狂的人拋擲火把、利箭</span><br /><span className="pl pl-1">與殺人的兵器</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="-19 「殺人的兵器」原文作「死亡」。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 22:10; 雅各書 3:6; 箴言 16:28"> <span className="pl pl-1">火缺了柴就必熄滅，</span><br /><span className="pl pl-1">無人傳舌，爭競便止息。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 15:18; 箴言 29:22; 撒母耳記下 20:1"> <span className="pl pl-1">好爭競的人煽惑爭端，</span><br /><span className="pl pl-1">就如餘火加炭，火上加柴一樣。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 18:8; 箴言 20:19; 以西結書 22:9"> <span className="pl pl-1">傳舌人的言語如同美食，</span><br /><span className="pl pl-1">深入人的心腹。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:47–48; 路加福音 11:39; 箴言 10:18"> <span className="pl pl-1">火熱的嘴奸惡的心，</span><br /><span className="pl pl-1">好像銀渣包的瓦器。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:20; 箴言 10:18; 詩篇 41:6"> <span className="pl pl-1">怨恨人的用嘴粉飾，</span><br /><span className="pl pl-1">心裡卻藏著詭詐。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:16–19; 耶利米書 12:6; 詩篇 28:3"> <span className="pl pl-1">他用甜言蜜語，你不可信他，</span><br /><span className="pl pl-1">因為他心中有七樣可憎惡的。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 55:21–23; 撒母耳記上 18:17; 撒母耳記上 18:21"> <span className="pl pl-1">他雖用詭詐遮掩自己的怨恨，</span><br /><span className="pl pl-1">他的邪惡必在會中顯露。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 28:10; 詩篇 9:15; 詩篇 7:15–16"> <span className="pl pl-1">挖陷坑的，自己必掉在其中；</span><br /><span className="pl pl-1">滾石頭的，石頭必反滾在他身上。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 8:44–49; 路加福音 20:20–21; 約翰福音 10:32–33"> <span className="pl pl-1">虛謊的舌恨他所壓傷的人，</span><br /><span className="pl pl-1">諂媚的口敗壞人的事。</span></span>

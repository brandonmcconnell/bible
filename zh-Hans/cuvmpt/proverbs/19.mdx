## 善惡互論垂為箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 28:6; 馬太福音 16:26; 箴言 16:8"> <span className="pl pl-1">行為純正的貧窮人，</span><br /><span className="pl pl-1">勝過乖謬愚妄的富足人。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 21:5; 腓立比書 1:9; 箴言 29:20"> <span className="pl pl-1">心無知識的乃為不善，</span><br /><span className="pl pl-1">腳步急快的難免犯罪。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 16:9–11; 詩篇 37:7; 民數記 16:19–41"> <span className="pl pl-1">人的愚昧傾敗他的道，</span><br /><span className="pl pl-1">他的心也抱怨耶和華。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 14:20; 箴言 19:6–7; 路加福音 15:13–15"> <span className="pl pl-1">財物使朋友增多，</span><br /><span className="pl pl-1">但窮人，朋友遠離。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 21:28; 箴言 19:9; 箴言 6:19"> <span className="pl pl-1">作假見證的必不免受罰，</span><br /><span className="pl pl-1">吐出謊言的終不能逃脫。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 29:26; 箴言 18:16; 箴言 17:8"> <span className="pl pl-1">好施散的，有多人求他的恩情；</span><br /><span className="pl pl-1">愛送禮的，人都為他的朋友。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 19:4; 約翰一書 3:17–18; 雅各書 2:15–16"> <span className="pl pl-1">貧窮人，弟兄都恨他，</span><br /><span className="pl pl-1">何況他的朋友，更遠離他。</span><br /><span className="pl pl-1">他用言語追隨，他們卻走了。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 16:20; 箴言 8:35–36; 箴言 3:18"> <span className="pl pl-1">得著智慧的愛惜生命，</span><br /><span className="pl pl-1">保守聰明的必得好處。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 22:15; 箴言 19:5; 啟示錄 19:20"> <span className="pl pl-1">作假見證的不免受罰，</span><br /><span className="pl pl-1">吐出謊言的也必滅亡。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 30:21–22; 箴言 26:1; 路加福音 16:19"> <span className="pl pl-1">愚昧人宴樂度日是不合宜的，</span><br /><span className="pl pl-1">何況僕人管轄王子呢？</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 16:32; 箴言 14:29; 雅各書 1:19"> <span className="pl pl-1">人有見識就不輕易發怒，</span><br /><span className="pl pl-1">寬恕人的過失便是自己的榮耀。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 14:5; 箴言 20:2; 箴言 16:14–15"> <span className="pl pl-1">王的憤怒好像獅子吼叫，</span><br /><span className="pl pl-1">他的恩典卻如草上的甘露。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 27:15; 箴言 21:9; 箴言 10:1"> <span className="pl pl-1">愚昧的兒子是父親的禍患，</span><br /><span className="pl pl-1">妻子的爭吵如雨連連滴漏。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:22; 箴言 31:10–31; 箴言 13:22"> <span className="pl pl-1">房屋錢財是祖宗所遺留的，</span><br /><span className="pl pl-1">唯有賢惠的妻是耶和華所賜的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 23:21; 箴言 20:13; 帖撒羅尼迦後書 3:10"> <span className="pl pl-1">懶惰使人沉睡，</span><br /><span className="pl pl-1">懈怠的人必受飢餓。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:28; 箴言 13:13; 路加福音 11:28"> <span className="pl pl-1">謹守誡命的保全生命，</span><br /><span className="pl pl-1">輕忽己路的必致死亡。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 28:27; 希伯來書 6:10; 路加福音 6:38"> <span className="pl pl-1">憐憫貧窮的就是借給耶和華，</span><br /><span className="pl pl-1">他的善行耶和華必償還。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 13:24; 箴言 29:15; 箴言 22:15"> <span className="pl pl-1">趁有指望管教你的兒子，</span><br /><span className="pl pl-1">你的心不可任他死亡。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 25:28; 撒母耳記下 16:5–6; 撒母耳記上 24:17–22"> <span className="pl pl-1">暴怒的人必受刑罰，</span><br /><span className="pl pl-1">你若救他，必須再救。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 12:15; 箴言 8:34–35; 箴言 2:1–9"> <span className="pl pl-1">你要聽勸教，受訓誨，</span><br /><span className="pl pl-1">使你終久有智慧。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 16:9; 以賽亞書 14:24; 箴言 16:1"> <span className="pl pl-1">人心多有計謀，</span><br /><span className="pl pl-1">唯有耶和華的籌算才能立定。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 14:6–8; 哥林多後書 8:12; 歷代志下 6:8"> <span className="pl pl-1">施行仁慈的令人愛慕，</span><br /><span className="pl pl-1">窮人強如說謊言的。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 5:6; 箴言 14:26–27; 箴言 12:21"> <span className="pl pl-1">敬畏耶和華的得著生命，</span><br /><span className="pl pl-1">他必恆久知足，不遭禍患。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:19; 箴言 6:9–10; 箴言 24:30–34"> <span className="pl pl-1">懶惰人放手在盤子裡，</span><br /><span className="pl pl-1">就是向口撤回他也不肯。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 21:11; 箴言 17:10; 箴言 15:5"> <span className="pl pl-1">鞭打褻慢人，愚蒙人必長見識；</span><br /><span className="pl pl-1">責備明哲人，他就明白知識。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 10:5; 箴言 17:2; 箴言 28:24"> <span className="pl pl-1">虐待父親、攆出母親的，</span><br /><span className="pl pl-1">是貽羞致辱之子。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 4:24; 提摩太前書 6:3–5; 馬太福音 7:15"> <span className="pl pl-1">我兒，不可聽了教訓</span><br /><span className="pl pl-1">而又偏離知識的言語。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 15:16; 約伯記 34:7; 路加福音 18:2–4"> <span className="pl pl-1">匪徒做見證戲笑公平，</span><br /><span className="pl pl-1">惡人的口吞下罪孽。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 26:3; 箴言 10:13; 箴言 9:12"> <span className="pl pl-1">刑罰是為褻慢人預備的，</span><br /><span className="pl pl-1">鞭打是為愚昧人的背預備的。</span></span>

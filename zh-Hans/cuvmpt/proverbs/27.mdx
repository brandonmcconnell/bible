## 箴言雜記

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="雅各書 4:13–16; 路加福音 12:19–20; 哥林多後書 6:2"> <span className="pl pl-1">不要為明日自誇，</span><br /><span className="pl pl-1">因為一日要生何事，你尚且不能知道。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 10:18; 箴言 25:27; 哥林多後書 10:12"> <span className="pl pl-1">要別人誇獎你，不可用口自誇；</span><br /><span className="pl pl-1">等外人稱讚你，不可用嘴自稱。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 3:19; 約翰一書 3:12; 創世記 49:7"> <span className="pl pl-1">石頭重，沙土沉，</span><br /><span className="pl pl-1">愚妄人的惱怒比這兩樣更重。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 6:34; 箴言 14:30; 雅各書 3:14–16"> <span className="pl pl-1">憤怒為殘忍，怒氣為狂瀾，</span><br /><span className="pl pl-1">唯有嫉妒，誰能敵得住呢？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 28:23; 提摩太前書 5:20; 加拉太書 2:14"> <span className="pl pl-1">當面的責備，強如背地的愛情。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 141:5; 啟示錄 3:19; 約伯記 5:17–18"> <span className="pl pl-1">朋友加的傷痕出於忠誠，</span><br /><span className="pl pl-1">仇敵連連親嘴卻是多餘。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:16–17; 民數記 11:18–20; 民數記 21:5"> <span className="pl pl-1">人吃飽了，厭惡蜂房的蜜；</span><br /><span className="pl pl-1">人飢餓了，一切苦物都覺甘甜。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 21:16; 以賽亞書 16:2; 約拿書 1:10–17"> <span className="pl pl-1">人離本處漂流，</span><br /><span className="pl pl-1">好像雀鳥離窩遊飛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:23–24; 箴言 16:21; 詩篇 23:5"> <span className="pl pl-1">膏油與香料使人心喜悅，</span><br /><span className="pl pl-1">朋友誠實的勸教也是如此甘美。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 18:24; 箴言 17:17; 列王紀上 12:6–8"> <span className="pl pl-1">你的朋友和父親的朋友，</span><br /><span className="pl pl-1">你都不可離棄。</span><br /><span className="pl pl-1">你遭難的日子，不要上弟兄的家去，</span><br /><span className="pl pl-1">相近的鄰舍強如遠方的弟兄。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 10:1; 詩篇 119:42; 箴言 23:15–16"> <span className="pl pl-1">我兒，你要做智慧人，好叫我的心歡喜，</span><br /><span className="pl pl-1">使我可以回答那譏誚我的人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 22:3; 箴言 18:10; 希伯來書 11:7"> <span className="pl pl-1">通達人見禍藏躲，</span><br /><span className="pl pl-1">愚蒙人前往受害。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:16; 箴言 6:1–4; 箴言 22:26–27"> <span className="pl pl-1">誰為生人作保，就拿誰的衣服；</span><br /><span className="pl pl-1">誰為外女作保，誰就承當。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 16:16–19; 使徒行傳 12:22–23; 耶利米書 28:2–4"> <span className="pl pl-1">清晨起來大聲給朋友祝福的，</span><br /><span className="pl pl-1">就算是咒詛他。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 21:9; 箴言 19:13; 箴言 21:19"> <span className="pl pl-1">大雨之日連連滴漏</span><br /><span className="pl pl-1">和爭吵的婦人一樣，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 12:3"> <span className="pl pl-1">想攔阻她的便是攔阻風，</span><br /><span className="pl pl-1">也是右手抓油。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:24; 箴言 27:9; 約伯記 4:3–4"> <span className="pl pl-1">鐵磨鐵，磨出刃來，</span><br /><span className="pl pl-1">朋友相感</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：磨朋友的臉。">a</a></sup><br /><span className="pl pl-1">也是如此。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 9:7; 提摩太後書 2:6; 雅歌 8:12"> <span className="pl pl-1">看守無花果樹的必吃樹上的果子，</span><br /><span className="pl pl-1">敬奉主人的必得尊榮。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="雅各書 1:22–25; 詩篇 33:15; 馬可福音 7:21"> <span className="pl pl-1">水中照臉，彼此相符；</span><br /><span className="pl pl-1">人與人，心也相對。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 1:8; 約翰一書 2:16; 箴言 30:15–16"> <span className="pl pl-1">陰間和滅亡永不滿足，</span><br /><span className="pl pl-1">人的眼目也是如此。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:3; 撒迦利亞書 13:9; 詩篇 66:10"> <span className="pl pl-1">鼎為煉銀，爐為煉金，</span><br /><span className="pl pl-1">人的稱讚也試煉人。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 5:3; 箴言 23:35; 以賽亞書 1:5"> <span className="pl pl-1">你雖用杵將愚妄人與打碎的麥子一同搗在臼中，</span><br /><span className="pl pl-1">他的愚妄還是離不了他。</span></span>
</div>

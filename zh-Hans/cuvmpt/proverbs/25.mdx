## 箴言雜記

<div className="bt">
<div className="bp">

</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="申命記 29:29; 羅馬書 11:33–34; 約伯記 11:7–8"> <span className="pl pl-1">將事隱祕乃神的榮耀，</span><br /><span className="pl pl-1">將事察清乃君王的榮耀。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 55:9; 詩篇 103:11; 列王紀上 4:29"> <span className="pl pl-1">天之高，地之厚，</span><br /><span className="pl pl-1">君王之心也測不透。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 2:20–21; 以西結書 22:18; 箴言 17:3"> <span className="pl pl-1">除去銀子的渣滓就有銀子出來，</span><br /><span className="pl pl-1">銀匠能以做器皿；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:12; 箴言 20:8; 詩篇 101:7–8"> <span className="pl pl-1">除去王面前的惡人，</span><br /><span className="pl pl-1">國位就靠公義堅立。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 27:2; 箴言 25:27; 箴言 16:19"> <span className="pl pl-1">不要在王面前妄自尊大，</span><br /><span className="pl pl-1">不要在大人的位上站立。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:7–11; 路加福音 18:14; 彼得前書 5:5"> <span className="pl pl-1">寧可有人說「請你上來」，</span><br /><span className="pl pl-1">強如在你覲見的王子面前叫你退下。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 5:25; 箴言 17:14; 箴言 18:6"> <span className="pl pl-1">不要冒失出去與人爭競，</span><br /><span className="pl pl-1">免得至終被他羞辱，</span><br /><span className="pl pl-1">你就不知道怎樣行了。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 18:5–17; 箴言 11:13; 箴言 20:19"> <span className="pl pl-1">你與鄰舍爭訟，</span><br /><span className="pl pl-1">要與他一人辯論，</span><br /><span className="pl pl-1">不可洩漏人的密事，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:39"> <span className="pl pl-1">恐怕聽見的人罵你，</span><br /><span className="pl pl-1">你的臭名就難以脫離。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 15:23; 以賽亞書 50:4; 傳道書 12:10"> <span className="pl pl-1">一句話說得合宜，</span><br /><span className="pl pl-1">就如金蘋果在銀網子裡。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 141:5; 箴言 15:31–32; 箴言 15:5"> <span className="pl pl-1">智慧人的勸誡在順從的人耳中，</span><br /><span className="pl pl-1">好像金耳環和精金的裝飾。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:17; 箴言 25:25; 腓立比書 2:25–30"> <span className="pl pl-1">忠信的使者叫差他的人心裡舒暢，</span><br /><span className="pl pl-1">就如在收割時有冰雪的涼氣。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:6; 路加福音 14:11; 彼得後書 2:15–19"> <span className="pl pl-1">空誇贈送禮物的，</span><br /><span className="pl pl-1">好像無雨的風雲。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 15:1; 傳道書 10:4; 箴言 16:14"> <span className="pl pl-1">恆常忍耐可以勸動君王，</span><br /><span className="pl pl-1">柔和的舌頭能折斷骨頭。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 25:27; 以弗所書 5:18; 箴言 24:13–14"> <span className="pl pl-1">你得了蜜嗎？只可吃夠而已，</span><br /><span className="pl pl-1">恐怕你過飽就嘔吐出來。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 19:2–3; 士師記 19:18–21; 羅馬書 15:24"> <span className="pl pl-1">你的腳要少進鄰舍的家，</span><br /><span className="pl pl-1">恐怕他厭煩你，恨惡你。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 57:4; 箴言 12:18; 雅各書 3:6"> <span className="pl pl-1">作假見證陷害鄰舍的，</span><br /><span className="pl pl-1">就是大槌，是利刀，是快箭。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 36:6; 以西結書 29:6–7; 約伯記 6:14–20"> <span className="pl pl-1">患難時倚靠不忠誠的人，</span><br /><span className="pl pl-1">好像破壞的牙，錯骨縫的腳。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:15; 傳道書 3:4; 以賽亞書 58:7"> <span className="pl pl-1">對傷心的人唱歌，</span><br /><span className="pl pl-1">就如冷天脫衣服，</span><br /><span className="pl pl-1">又如鹼上倒醋。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 12:20–21; 馬太福音 5:44; 出埃及記 23:4–5"> <span className="pl pl-1">你的仇敵若餓了，就給他飯吃；</span><br /><span className="pl pl-1">若渴了，就給他水喝。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 16:12; 馬太福音 10:13; 哥林多前書 15:18"> <span className="pl pl-1">因為你這樣行，就是把炭火堆在他的頭上，</span><br /><span className="pl pl-1">耶和華也必賞賜你。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 37:22; 詩篇 15:3; 羅馬書 1:30"> <span className="pl pl-1">北風生雨，</span><br /><span className="pl pl-1">讒謗人的舌頭也生怒容。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 21:19; 箴言 21:9; 箴言 27:15–16"> <span className="pl pl-1">寧可住在房頂的角上，</span><br /><span className="pl pl-1">不在寬闊的房屋與爭吵的婦人同住。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:30; 羅馬書 10:15; 詩篇 63:1"> <span className="pl pl-1">有好消息從遠方來，</span><br /><span className="pl pl-1">就如拿涼水給口渴的人喝。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 34:18–19; 撒母耳記上 22:14–18; 帖撒羅尼迦前書 2:15"> <span className="pl pl-1">義人在惡人面前退縮，</span><br /><span className="pl pl-1">好像趟渾之泉，弄濁之井。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 5:44; 箴言 27:2; 腓立比書 2:3"> <span className="pl pl-1">吃蜜過多是不好的，</span><br /><span className="pl pl-1">考究自己的榮耀也是可厭的。</span><br /></span>

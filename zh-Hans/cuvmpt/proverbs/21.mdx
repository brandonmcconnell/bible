## 善惡互論垂為箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:9; 箴言 20:24; 以斯拉記 6:22"> <span className="pl pl-1">王的心在耶和華手中</span><br /><span className="pl pl-1">好像壟溝的水，隨意流轉。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:2; 箴言 16:25; 路加福音 16:15"> <span className="pl pl-1">人所行的在自己眼中都看為正，</span><br /><span className="pl pl-1">唯有耶和華衡量人心。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 15:22; 何西阿書 6:6; 彌迦書 6:6–8"> <span className="pl pl-1">行仁義、公平</span><br /><span className="pl pl-1">比獻祭更蒙耶和華悅納。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 6:17; 彼得前書 5:5; 以賽亞書 2:17"> <span className="pl pl-1">惡人發達</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「發達」原文作「燈」。">a</a></sup><br /><span className="pl pl-1">，眼高心傲，</span><br /><span className="pl pl-1">這乃是罪。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 10:4; 箴言 13:4; 以弗所書 4:28"> <span className="pl pl-1">殷勤籌劃的足致豐裕，</span><br /><span className="pl pl-1">行事急躁的都必缺乏。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 13:11; 箴言 10:2; 箴言 20:21"> <span className="pl pl-1">用詭詐之舌求財的，就是自己取死，</span><br /><span className="pl pl-1">所得之財乃是吹來吹去的浮雲。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:21; 以弗所書 5:6; 箴言 1:18–19"> <span className="pl pl-1">惡人的強暴必將自己掃除，</span><br /><span className="pl pl-1">因他們不肯按公平行事。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:15; 約翰一書 2:29; 詩篇 14:2–3"> <span className="pl pl-1">負罪之人的路甚是彎曲，</span><br /><span className="pl pl-1">至於清潔的人，他所行的乃是正直。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 19:13; 箴言 21:19; 箴言 27:15–16"> <span className="pl pl-1">寧可住在房頂的角上，</span><br /><span className="pl pl-1">不在寬闊的房屋與爭吵的婦人同住。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 3:2–3; 箴言 3:29; 詩篇 36:4"> <span className="pl pl-1">惡人的心樂人受禍，</span><br /><span className="pl pl-1">他眼並不憐恤鄰舍。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:25; 箴言 18:15; 箴言 9:9"> <span className="pl pl-1">褻慢的人受刑罰，愚蒙的人就得智慧；</span><br /><span className="pl pl-1">智慧人受訓誨，便得知識。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 14:11; 詩篇 37:35–36; 彼得後書 3:6–7"> <span className="pl pl-1">義人思想惡人的家，</span><br /><span className="pl pl-1">知道惡人傾倒，必致滅亡。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 28:27; 馬太福音 6:14; 箴言 1:28"> <span className="pl pl-1">塞耳不聽窮人哀求的，</span><br /><span className="pl pl-1">他將來呼籲也不蒙應允。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:16; 箴言 19:6; 箴言 17:8"> <span className="pl pl-1">暗中送的禮物挽回怒氣，</span><br /><span className="pl pl-1">懷中揣的賄賂止息暴怒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 10:29; 馬太福音 7:23; 馬太福音 13:41–42"> <span className="pl pl-1">秉公行義使義人喜樂，</span><br /><span className="pl pl-1">使作孽的人敗壞。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 10:38; 詩篇 125:5; 詩篇 49:14"> <span className="pl pl-1">迷離通達道路的，</span><br /><span className="pl pl-1">必住在陰魂的會中。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 23:21; 提摩太前書 5:6; 提摩太後書 3:4"> <span className="pl pl-1">愛宴樂的必致窮乏，</span><br /><span className="pl pl-1">好酒愛膏油的必不富足。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:8; 以賽亞書 43:3–4; 以賽亞書 53:4–5"> <span className="pl pl-1">惡人做了義人的贖價，</span><br /><span className="pl pl-1">奸詐人代替正直人。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:9; 詩篇 120:5–6; 詩篇 55:6–7"> <span className="pl pl-1">寧可住在曠野，</span><br /><span className="pl pl-1">不與爭吵使氣的婦人同住。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 25:3–4; 詩篇 112:3; 傳道書 7:11"> <span className="pl pl-1">智慧人家中積蓄寶物、膏油，</span><br /><span className="pl pl-1">愚昧人隨得來隨吞下。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 5:6; 哥林多前書 15:58; 箴言 22:4"> <span className="pl pl-1">追求公義仁慈的，</span><br /><span className="pl pl-1">就尋得生命、公義和尊榮。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="傳道書 7:19; 箴言 24:5; 傳道書 9:13–18"> <span className="pl pl-1">智慧人爬上勇士的城牆，</span><br /><span className="pl pl-1">傾覆他所倚靠的堅壘。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 13:3; 箴言 18:21; 雅各書 1:26"> <span className="pl pl-1">謹守口與舌的，</span><br /><span className="pl pl-1">就保守自己免受災難。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 1:1; 箴言 18:12; 箴言 1:22"> <span className="pl pl-1">心驕氣傲的人，名叫褻慢，</span><br /><span className="pl pl-1">他行事狂妄，都出於驕傲。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 13:4; 箴言 12:24; 馬太福音 25:26"> <span className="pl pl-1">懶惰人的心願將他殺害，</span><br /><span className="pl pl-1">因為他手不肯做工。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 37:26; 使徒行傳 20:33–35; 以弗所書 4:28"> <span className="pl pl-1">有終日貪得無厭的，</span><br /><span className="pl pl-1">義人施捨而不吝惜。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 66:3; 箴言 15:8; 耶利米書 6:20"> <span className="pl pl-1">惡人的祭物是可憎的，</span><br /><span className="pl pl-1">何況他存惡意來獻呢？</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多後書 4:13; 箴言 19:5; 箴言 19:9"> <span className="pl pl-1">作假見證的必滅亡，</span><br /><span className="pl pl-1">唯有聽真情而言的，其言長存。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="帖撒羅尼迦前書 3:11; 箴言 11:5; 哈該書 2:18–19"> <span className="pl pl-1">惡人臉無羞恥，</span><br /><span className="pl pl-1">正直人行事堅定。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 19:21; 使徒行傳 5:39; 耶利米書 9:23"> <span className="pl pl-1">沒有人能以智慧、聰明、</span><br /><span className="pl pl-1">謀略抵擋耶和華。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 20:7; 以賽亞書 31:1; 詩篇 33:17–18"> <span className="pl pl-1">馬是為打仗之日預備的，</span><br /><span className="pl pl-1">得勝乃在乎耶和華。</span></span>

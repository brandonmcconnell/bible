## 善惡互論垂為箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 31:10–31; 箴言 24:3–4; 箴言 21:9"> <span className="pl pl-1">智慧婦人建立家室，</span><br /><span className="pl pl-1">愚妄婦人親手拆毀。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="提摩太後書 3:2–3; 使徒行傳 10:35; 箴言 28:6"> <span className="pl pl-1">行動正直的敬畏耶和華，</span><br /><span className="pl pl-1">行事乖僻的卻藐視他。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 12:6; 雅各書 3:5–6; 啟示錄 12:11"> <span className="pl pl-1">愚妄人口中驕傲，如杖責打己身，</span><br /><span className="pl pl-1">智慧人的嘴必保守自己。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 9:9–11; 箴言 13:23; 阿摩司書 4:6"> <span className="pl pl-1">家裡無牛，槽頭乾淨；</span><br /><span className="pl pl-1">土產加多，乃憑牛力。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:19; 箴言 19:5; 出埃及記 23:1"> <span className="pl pl-1">誠實見證人不說謊話，</span><br /><span className="pl pl-1">假見證人吐出謊言。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:5; 馬太福音 13:11–12; 馬太福音 11:25–27"> <span className="pl pl-1">褻慢人尋智慧卻尋不著，</span><br /><span className="pl pl-1">聰明人易得知識。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 13:20; 以弗所書 5:11; 哥林多前書 5:11"> <span className="pl pl-1">到愚昧人面前，</span><br /><span className="pl pl-1">不見他嘴中有知識。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:17; 提摩太後書 3:13; 雅各書 3:13"> <span className="pl pl-1">通達人的智慧在乎明白己道，</span><br /><span className="pl pl-1">愚昧人的愚妄乃是詭詐</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：自嘆。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 26:18–19; 箴言 10:23; 羅馬書 14:17–18"> <span className="pl pl-1">愚妄人犯罪以為戲耍</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：贖愆祭愚弄愚妄人。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">正直人互相喜悅。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 4:7; 箴言 18:14; 箴言 15:13"> <span className="pl pl-1">心中的苦楚自己知道，</span><br /><span className="pl pl-1">心裡的喜樂外人無干。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 3:33; 箴言 12:7; 馬太福音 7:26–27"> <span className="pl pl-1">奸惡人的房屋必傾倒，</span><br /><span className="pl pl-1">正直人的帳篷必興盛。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:25; 馬太福音 7:13–14; 箴言 12:15"> <span className="pl pl-1">有一條路人以為正，</span><br /><span className="pl pl-1">至終成為死亡之路。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 2:2; 雅各書 4:9; 傳道書 2:10–11"> <span className="pl pl-1">人在喜笑中心也憂愁，</span><br /><span className="pl pl-1">快樂至極就生愁苦。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 6:8; 箴言 12:14; 希伯來書 3:12"> <span className="pl pl-1">心中背道的必滿得自己的結果，</span><br /><span className="pl pl-1">善人必從自己的行為得以知足。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 5:17; 箴言 14:8; 約翰一書 4:1"> <span className="pl pl-1">愚蒙人是話都信，</span><br /><span className="pl pl-1">通達人步步謹慎。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 22:3; 箴言 3:7; 帖撒羅尼迦前書 5:22"> <span className="pl pl-1">智慧人懼怕，就遠離惡事，</span><br /><span className="pl pl-1">愚妄人卻狂傲自恃。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 14:29; 雅各書 1:19; 傳道書 7:9"> <span className="pl pl-1">輕易發怒的行事愚妄，</span><br /><span className="pl pl-1">設立詭計的被人恨惡。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前書 1:18; 彼得前書 5:4; 耶利米書 44:17"> <span className="pl pl-1">愚蒙人得愚昧為產業，</span><br /><span className="pl pl-1">通達人得知識為冠冕。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 42:6; 瑪拉基書 4:3; 出埃及記 8:8"> <span className="pl pl-1">壞人俯伏在善人面前，</span><br /><span className="pl pl-1">惡人俯伏在義人門口。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 19:4; 箴言 10:15; 箴言 19:6–7"> <span className="pl pl-1">貧窮人連鄰舍也恨他，</span><br /><span className="pl pl-1">富足人朋友最多。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 19:17; 箴言 28:27; 箴言 11:12"> <span className="pl pl-1">藐視鄰舍的，這人有罪；</span><br /><span className="pl pl-1">憐憫貧窮的，這人有福。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 12:2; 約翰福音 1:17; 詩篇 61:7"> <span className="pl pl-1">謀惡的，豈非走入迷途嗎？</span><br /><span className="pl pl-1">謀善的，必得慈愛和誠實。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 28:19; 箴言 12:24; 帖撒羅尼迦後書 3:10–12"> <span className="pl pl-1">諸般勤勞都有益處，</span><br /><span className="pl pl-1">嘴上多言乃致窮乏。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="傳道書 7:11–12; 路加福音 12:19–20; 路加福音 16:19–25"> <span className="pl pl-1">智慧人的財為自己的冠冕，</span><br /><span className="pl pl-1">愚妄人的愚昧終是愚昧。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 14:5; 使徒行傳 26:16–20; 彼得後書 3:3"> <span className="pl pl-1">作真見證的救人性命，</span><br /><span className="pl pl-1">吐出謊言的施行詭詐。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 19:23; 耶利米書 32:39–40; 詩篇 115:13–14"> <span className="pl pl-1">敬畏耶和華的大有倚靠，</span><br /><span className="pl pl-1">他的兒女也有避難所。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 21:6; 箴言 13:14; 箴言 2:10–18"> <span className="pl pl-1">敬畏耶和華就是生命的泉源，</span><br /><span className="pl pl-1">可以使人離開死亡的網羅。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 4:20–21; 列王紀下 13:7; 出埃及記 1:22"> <span className="pl pl-1">帝王榮耀在乎民多，</span><br /><span className="pl pl-1">君王衰敗在乎民少。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 1:19; 傳道書 7:9; 箴言 14:17"> <span className="pl pl-1">不輕易發怒的大有聰明，</span><br /><span className="pl pl-1">性情暴躁的大顯愚妄。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 17:22; 箴言 4:23; 箴言 3:8"> <span className="pl pl-1">心中安靜是肉體的生命，</span><br /><span className="pl pl-1">嫉妒是骨中的朽爛。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 22:2; 箴言 17:5; 箴言 22:16"> <span className="pl pl-1">欺壓貧寒的是辱沒造他的主，</span><br /><span className="pl pl-1">憐憫窮乏的乃是尊敬主。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="提摩太後書 4:18; 哥林多後書 5:8; 詩篇 23:4"> <span className="pl pl-1">惡人在所行的惡上必被推倒，</span><br /><span className="pl pl-1">義人臨死有所投靠。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 12:16; 箴言 13:16; 箴言 12:23"> <span className="pl pl-1">智慧存在聰明人心中，</span><br /><span className="pl pl-1">愚昧人心裡所存的顯而易見。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 107:34; 申命記 28:1–68; 申命記 29:18–28"> <span className="pl pl-1">公義使邦國高舉，</span><br /><span className="pl pl-1">罪惡是人民的羞辱。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:45–51; 路加福音 12:42–48; 馬太福音 25:23"> <span className="pl pl-1">智慧的臣子蒙王恩惠，</span><br /><span className="pl pl-1">貽羞的僕人遭其震怒。</span></span>

## 善惡互論垂為箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 15:10; 箴言 9:7–8; 詩篇 119:97–100"> <span className="pl pl-1">喜愛管教的就是喜愛知識，</span><br /><span className="pl pl-1">恨惡責備的卻是畜類。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 8:35; 使徒行傳 11:24; 詩篇 112:5"> <span className="pl pl-1">善人必蒙耶和華的恩惠，</span><br /><span className="pl pl-1">設詭計的人，耶和華必定他的罪。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 10:25; 以弗所書 3:17; 箴言 12:12"> <span className="pl pl-1">人靠惡行不能堅立，</span><br /><span className="pl pl-1">義人的根必不動搖。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 14:30; 箴言 31:10–25; 箴言 14:1"> <span className="pl pl-1">才德的婦人是丈夫的冠冕，</span><br /><span className="pl pl-1">貽羞的婦人如同朽爛，在他丈夫的骨中。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 139:23; 以賽亞書 55:7; 詩篇 140:1–3"> <span className="pl pl-1">義人的思念是公平，</span><br /><span className="pl pl-1">惡人的計謀是詭詐。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:3; 耶利米書 5:26; 箴言 1:11–19"> <span className="pl pl-1">惡人的言論是埋伏流人的血，</span><br /><span className="pl pl-1">正直人的口必拯救人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:24–27; 箴言 11:21; 箴言 10:25"> <span className="pl pl-1">惡人傾覆歸於無有，</span><br /><span className="pl pl-1">義人的家必站得住。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 10:18; 哥林多前書 4:5; 哥林多前書 3:10–15"> <span className="pl pl-1">人必按自己的智慧被稱讚，</span><br /><span className="pl pl-1">心中乖謬的必被藐視。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:11; 箴言 13:7"> <span className="pl pl-1">被人輕賤卻有僕人，</span><br /><span className="pl pl-1">強如自尊缺少食物。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 25:4; 創世記 33:13–14; 民數記 22:28–32"> <span className="pl pl-1">義人顧惜他牲畜的命，</span><br /><span className="pl pl-1">惡人的憐憫也是殘忍。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 28:19; 箴言 14:23; 帖撒羅尼迦前書 4:11–12"> <span className="pl pl-1">耕種自己田地的必得飽食，</span><br /><span className="pl pl-1">追隨虛浮的卻是無知。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 17:7–8; 約翰福音 15:5; 路加福音 8:13–15"> <span className="pl pl-1">惡人想得壞人的網羅，</span><br /><span className="pl pl-1">義人的根得以結實。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 21:23; 箴言 11:8; 詩篇 64:8"> <span className="pl pl-1">惡人嘴中的過錯是自己的網羅，</span><br /><span className="pl pl-1">但義人必脫離患難。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:20–21; 以賽亞書 3:10–11; 箴言 13:2"> <span className="pl pl-1">人因口所結的果子必飽得美福，</span><br /><span className="pl pl-1">人手所做的必為自己的報應。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 3:7; 箴言 26:12; 箴言 14:16"> <span className="pl pl-1">愚妄人所行的在自己眼中看為正直，</span><br /><span className="pl pl-1">唯智慧人肯聽人的勸教。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 雅各書 1:19; 箴言 10:12"> <span className="pl pl-1">愚妄人的惱怒立時顯露，</span><br /><span className="pl pl-1">通達人能忍辱藏羞。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 14:5; 箴言 14:25; 箴言 24:28"> <span className="pl pl-1">說出真話的顯明公義，</span><br /><span className="pl pl-1">作假見證的顯出詭詐。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 16:24; 箴言 15:4; 詩篇 57:4"> <span className="pl pl-1">說話浮躁的如刀刺人，</span><br /><span className="pl pl-1">智慧人的舌頭卻為醫人的良藥。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:9; 詩篇 52:4–5; 約伯記 20:5"> <span className="pl pl-1">口吐真言，永遠堅立；</span><br /><span className="pl pl-1">舌說謊話，只存片時。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 5:9; 彼得前書 3:8–13; 箴言 12:12"> <span className="pl pl-1">圖謀惡事的心存詭詐，</span><br /><span className="pl pl-1">勸人和睦的便得喜樂。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 3:13; 詩篇 91:10; 羅馬書 8:28"> <span className="pl pl-1">義人不遭災害，惡人滿受禍患。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 5:6; 箴言 11:20; 啟示錄 22:15"> <span className="pl pl-1">說謊言的嘴為耶和華所憎惡，</span><br /><span className="pl pl-1">行事誠實的為他所喜悅。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 13:16; 箴言 11:13; 箴言 10:19"> <span className="pl pl-1">通達人隱藏知識，</span><br /><span className="pl pl-1">愚昧人的心彰顯愚昧。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:27; 箴言 10:4; 箴言 21:25–26"> <span className="pl pl-1">殷勤人的手必掌權，</span><br /><span className="pl pl-1">懶惰的人必服苦。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 16:24; 箴言 15:13; 箴言 17:22"> <span className="pl pl-1">人心憂慮屈而不伸，</span><br /><span className="pl pl-1">一句良言使心歡樂。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="約翰一書 2:26; 馬太福音 5:46–48; 箴言 17:27"> <span className="pl pl-1">義人引導他的鄰舍，</span><br /><span className="pl pl-1">惡人的道叫人失迷。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 13:4; 箴言 26:15; 箴言 15:16"> <span className="pl pl-1">懶惰的人不烤打獵所得的，</span><br /><span className="pl pl-1">殷勤的人卻得寶貴的財物。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="約翰三書 1:11; 羅馬書 5:21; 以西結書 18:20–24"> <span className="pl pl-1">在公義的道上有生命，</span><br /><span className="pl pl-1">其路之中並無死亡。</span></span>

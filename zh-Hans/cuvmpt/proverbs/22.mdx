<div className="bt">
<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="約伯記 31:15; 箴言 14:31; 撒母耳記上 2:7"> <span className="pl pl-1">富戶窮人在世相遇，</span><br /><span className="pl pl-1">都為耶和華所造。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 27:12; 箴言 14:16; 箴言 29:1"> <span className="pl pl-1">通達人見禍藏躲，</span><br /><span className="pl pl-1">愚蒙人前往受害。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="列王紀下 4:1; 箴言 22:16; 馬太福音 18:25"> <span className="pl pl-1">富戶管轄窮人，</span><br /><span className="pl pl-1">欠債的是債主的僕人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 6:7–8; 約伯記 4:8; 以賽亞書 30:31"> <span className="pl pl-1">撒罪孽的必收災禍，</span><br /><span className="pl pl-1">他逞怒的杖也必廢掉。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="箴言 15:19; 箴言 26:13–16; 民數記 13:32–33"> <span className="pl pl-1">懶惰人說：「外頭有獅子，</span><br /><span className="pl pl-1">我在街上就必被殺！」</span><br /></span>

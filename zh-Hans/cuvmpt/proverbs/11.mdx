## 善惡互論垂為箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="申命記 25:13–16; 箴言 16:11; 箴言 20:23"> <span className="pl pl-1">詭詐的天平為耶和華所憎惡，</span><br /><span className="pl pl-1">公平的法碼為他所喜悅。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:23; 箴言 15:33; 箴言 16:18–19"> <span className="pl pl-1">驕傲來，羞恥也來，</span><br /><span className="pl pl-1">謙遜人卻有智慧。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:6; 箴言 28:18; 詩篇 26:1"> <span className="pl pl-1">正直人的純正必引導自己，</span><br /><span className="pl pl-1">奸詐人的乖僻必毀滅自己。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="西番雅書 1:18; 箴言 10:2; 創世記 7:1"> <span className="pl pl-1">發怒的日子，資財無益，</span><br /><span className="pl pl-1">唯有公義能救人脫離死亡。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 5:22; 詩篇 9:15–16; 箴言 1:31–32"> <span className="pl pl-1">完全人的義必指引他的路，</span><br /><span className="pl pl-1">但惡人必因自己的惡跌倒。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="傳道書 10:8; 列王紀上 2:44; 詩篇 7:15–16"> <span className="pl pl-1">正直人的義必拯救自己，</span><br /><span className="pl pl-1">奸詐人必陷在自己的罪孽中。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 10:28; 約伯記 8:13–14; 約伯記 11:20"> <span className="pl pl-1">惡人一死，他的指望必滅絕，</span><br /><span className="pl pl-1">罪人的盼望也必滅沒。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 6:23–24; 箴言 21:18; 以斯帖記 7:9–10"> <span className="pl pl-1">義人得脫離患難，</span><br /><span className="pl pl-1">有惡人來代替他。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 2:10–16; 箴言 4:5–6; 約翰一書 2:27"> <span className="pl pl-1">不虔敬的人用口敗壞鄰舍，</span><br /><span className="pl pl-1">義人卻因知識得救。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:12; 以斯帖記 8:15–16; 詩篇 58:10–11"> <span className="pl pl-1">義人享福，合城喜樂；</span><br /><span className="pl pl-1">惡人滅亡，人都歡呼。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 14:34; 箴言 29:8; 雅各書 3:6"> <span className="pl pl-1">城因正直人祝福便高舉，</span><br /><span className="pl pl-1">卻因邪惡人的口就傾覆。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 10:19; 彼得前書 2:23; 路加福音 18:9"> <span className="pl pl-1">藐視鄰舍的毫無智慧，</span><br /><span className="pl pl-1">明哲人卻靜默不言。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 箴言 25:9; 利未記 19:16"> <span className="pl pl-1">往來傳舌的洩漏密事，</span><br /><span className="pl pl-1">心中誠實的遮隱事情。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 24:6; 箴言 15:22; 箴言 20:18"> <span className="pl pl-1">無智謀，民就敗落；</span><br /><span className="pl pl-1">謀士多，人便安居。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 17:18; 箴言 6:1–5; 箴言 22:26–27"> <span className="pl pl-1">為外人作保的必受虧損，</span><br /><span className="pl pl-1">恨惡擊掌的卻得安穩。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 31:30–31; 路加福音 10:42; 使徒行傳 16:14–15"> <span className="pl pl-1">恩德的婦女得尊榮，</span><br /><span className="pl pl-1">強暴的男子得資財。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:7; 馬太福音 25:34–40; 雅各書 2:13"> <span className="pl pl-1">仁慈的人善待自己，</span><br /><span className="pl pl-1">殘忍的人擾害己身。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 6:8–9; 傳道書 10:8; 何西阿書 10:12–13"> <span className="pl pl-1">惡人經營，得虛浮的工價；</span><br /><span className="pl pl-1">撒義種的，得實在的果效。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 10:16; 羅馬書 2:8–9; 箴言 12:28"> <span className="pl pl-1">恆心為義的必得生命，</span><br /><span className="pl pl-1">追求邪惡的必致死亡。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 119:1; 箴言 21:29; 歷代志上 29:17"> <span className="pl pl-1">心中乖僻的，為耶和華所憎惡；</span><br /><span className="pl pl-1">行事完全的，為他所喜悅。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 112:1–2; 使徒行傳 2:39; 耶利米書 32:39"> <span className="pl pl-1">惡人雖然連手，必不免受罰，</span><br /><span className="pl pl-1">義人的後裔必得拯救。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 3:3–4; 箴言 31:30; 那鴻書 3:4–6"> <span className="pl pl-1">婦女美貌而無見識，</span><br /><span className="pl pl-1">如同金環戴在豬鼻上。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 37:4; 羅馬書 2:8–9; 馬太福音 5:6"> <span className="pl pl-1">義人的心願盡得好處，</span><br /><span className="pl pl-1">惡人的指望致干憤怒。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 19:17; 路加福音 6:38; 申命記 15:10"> <span className="pl pl-1">有施散的卻更增添，</span><br /><span className="pl pl-1">有吝惜過度的反致窮乏。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 5:7; 哥林多後書 9:6–9; 以賽亞書 58:7–11"> <span className="pl pl-1">好施捨的必得豐裕，</span><br /><span className="pl pl-1">滋潤人的必得滋潤。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="約伯記 29:13; 創世記 42:6; 阿摩司書 8:4–6"> <span className="pl pl-1">屯糧不賣的，民必咒詛他；</span><br /><span className="pl pl-1">情願出賣的，人必為他祝福。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 7:15–16; 箴言 17:11; 詩篇 9:15–16"> <span className="pl pl-1">懇切求善的，就求得恩惠；</span><br /><span className="pl pl-1">唯獨求惡的，惡必臨到他身。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前書 6:17; 耶利米書 17:8; 詩篇 52:7–8"> <span className="pl pl-1">倚仗自己財物的必跌倒，</span><br /><span className="pl pl-1">義人必發旺如青葉。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="傳道書 5:16; 箴言 14:19; 箴言 15:27"> <span className="pl pl-1">擾害己家的必承受清風，</span><br /><span className="pl pl-1">愚昧人必做慧心人的僕人。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 12:3; 雅各書 5:20; 哥林多前書 9:19–23"> <span className="pl pl-1">義人所結的果子就是生命樹，</span><br /><span className="pl pl-1">有智慧的必能得人。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="彼得前書 4:17–18; 耶利米書 25:29; 哥林多前書 11:30–32"> <span className="pl pl-1">看哪，義人在世尚且受報，</span><br /><span className="pl pl-1">何況惡人和罪人呢？</span></span>

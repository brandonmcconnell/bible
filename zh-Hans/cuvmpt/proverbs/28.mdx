## 箴言雜記

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="申命記 28:7; 詩篇 53:5; 以賽亞書 26:3–4"> <span className="pl pl-1">惡人雖無人追趕也逃跑，</span><br /><span className="pl pl-1">義人卻膽壯像獅子。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:28; 列王紀上 16:8–29; 列王紀下 15:8–31"> <span className="pl pl-1">邦國因有罪過，君王就多更換。</span><br /><span className="pl pl-1">因有聰明、知識的人，國必長存。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 18:28–30"> <span className="pl pl-1">窮人欺壓貧民，</span><br /><span className="pl pl-1">好像暴雨沖沒糧食。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:32; 以弗所書 5:11; 馬太福音 14:4"> <span className="pl pl-1">違棄律法的誇獎惡人，</span><br /><span className="pl pl-1">遵守律法的卻與惡人相爭。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 92:6; 雅各書 1:5; 約翰一書 2:27"> <span className="pl pl-1">壞人不明白公義，</span><br /><span className="pl pl-1">唯有尋求耶和華的無不明白。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; 路加福音 16:19–23"> <span className="pl pl-1">行為純正的窮乏人，</span><br /><span className="pl pl-1">勝過行事乖僻的富足人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:3–4; 箴言 29:3; 箴言 3:1–35"> <span className="pl pl-1">謹守律法的是智慧之子，</span><br /><span className="pl pl-1">與貪食人做伴的卻羞辱其父。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 27:16–17; 箴言 13:22; 傳道書 2:26"> <span className="pl pl-1">人以厚利加增財物，</span><br /><span className="pl pl-1">是給那憐憫窮人者積蓄的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 66:18; 提摩太後書 4:3–4; 撒迦利亞書 7:11–13"> <span className="pl pl-1">轉耳不聽律法的，</span><br /><span className="pl pl-1">他的祈禱也為可憎。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 26:27; 詩篇 37:25–26; 加拉太書 2:4"> <span className="pl pl-1">誘惑正直人行惡道的，必掉在自己的坑裡；</span><br /><span className="pl pl-1">唯有完全人，必承受福分。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 傳道書 9:15–17; 箴言 26:16"> <span className="pl pl-1">富足人自以為有智慧，</span><br /><span className="pl pl-1">但聰明的貧窮人能將他查透。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">義人得志，有大榮耀；</span><br /><span className="pl pl-1">惡人興起，人就躲藏。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 1:8–10; 詩篇 32:3–5; 約伯記 31:33"> <span className="pl pl-1">遮掩自己罪過的必不亨通，</span><br /><span className="pl pl-1">承認、離棄罪過的必蒙憐恤。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 詩篇 2:11; 以賽亞書 66:2"> <span className="pl pl-1">常存敬畏的便為有福，</span><br /><span className="pl pl-1">心存剛硬的必陷在禍患裡。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 5:8; 馬太福音 2:16; 箴言 19:12"> <span className="pl pl-1">暴虐的君王轄制貧民，</span><br /><span className="pl pl-1">好像吼叫的獅子、覓食的熊。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 18:21; 耶利米書 22:15–17; 傳道書 4:1"> <span className="pl pl-1">無知的君多行暴虐，</span><br /><span className="pl pl-1">以貪財為可恨的必年長日久。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:6; 列王紀上 21:19; 出埃及記 21:14"> <span className="pl pl-1">背負流人血之罪的必往坑裡奔跑，</span><br /><span className="pl pl-1">誰也不可攔阻他。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; 啟示錄 3:3"> <span className="pl pl-1">行動正直的必蒙拯救，</span><br /><span className="pl pl-1">行事彎曲的立時跌倒。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士師記 9:4; 箴言 27:23–27"> <span className="pl pl-1">耕種自己田地的必得飽食，</span><br /><span className="pl pl-1">追隨虛浮的足受窮乏。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 16:10–12; 箴言 13:11; 啟示錄 2:10"> <span className="pl pl-1">誠實人必多得福，</span><br /><span className="pl pl-1">想要急速發財的不免受罰。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 24:23; 箴言 18:5; 以西結書 13:19"> <span className="pl pl-1">看人的情面乃為不好，</span><br /><span className="pl pl-1">人因一塊餅枉法也為不好。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 23:6; 提摩太前書 6:9; 箴言 28:20"> <span className="pl pl-1">人有惡眼想要急速發財，</span><br /><span className="pl pl-1">卻不知窮乏必臨到他身。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 27:5–6; 馬太福音 18:15; 詩篇 141:5"> <span className="pl pl-1">責備人的後來蒙人喜悅，</span><br /><span className="pl pl-1">多於那用舌頭諂媚人的。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 15:4–6; 箴言 18:9; 箴言 19:26"> <span className="pl pl-1">偷竊父母的說「這不是罪」，</span><br /><span className="pl pl-1">此人就是與強盜同類。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 11:25; 提摩太前書 6:6; 箴言 13:10"> <span className="pl pl-1">心中貪婪的挑起爭端，</span><br /><span className="pl pl-1">倚靠耶和華的必得豐裕。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 3:5; 耶利米書 17:9; 約伯記 28:28"> <span className="pl pl-1">心中自是的便是愚昧人，</span><br /><span className="pl pl-1">憑智慧行事的必蒙拯救。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 19:17; 申命記 15:7; 詩篇 41:1–3"> <span className="pl pl-1">賙濟貧窮的不致缺乏，</span><br /><span className="pl pl-1">佯為不見的必多受咒詛。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 29:2; 約伯記 24:4; 使徒行傳 12:23–24"> <span className="pl pl-1">惡人興起，人就躲藏；</span><br /><span className="pl pl-1">惡人敗亡，義人增多。</span></span>

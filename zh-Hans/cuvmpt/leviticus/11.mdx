## 示潔與不潔之生物

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 15:11; 利未記 11:11; 希伯來書 9:10"> 「你們曉諭以色列人說，在地上一切走獸中可吃的乃是這些：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多後書 6:17; 申命記 6:6–7"> 凡蹄分兩瓣、倒嚼的走獸，你們都可以吃。</span>
<span className="v" id="v4" data-v="4"> 但那倒嚼或分蹄之中不可吃的乃是：駱駝，因為倒嚼不分蹄，就於你們不潔淨；</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:18; 箴言 30:26; 馬太福音 7:26"> 沙番，因為倒嚼不分蹄，就於你們不潔淨；</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:7"> 兔子，因為倒嚼不分蹄，就於你們不潔淨；</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 66:17; 以賽亞書 65:4; 以賽亞書 66:3"> 豬，因為蹄分兩瓣，卻不倒嚼，就於你們不潔淨。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 52:11; 歌羅西書 2:16; 希伯來書 9:10"> 這些獸的肉你們不可吃，死的你們不可摸，都於你們不潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 5:6; 雅各書 2:18; 使徒行傳 20:21"> 「水中可吃的乃是這些：凡在水裡、海裡、河裡，有翅有鱗的，都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未記 7:18; 詩篇 139:21–22"> 凡在海裡、河裡並一切水裡游動的活物，無翅無鱗的，你們都當以為可憎。</span>
<span className="v" id="v11" data-v="11"> 這些無翅無鱗、以為可憎的，你們不可吃牠的肉，死的也當以為可憎。</span>
<span className="v" id="v12" data-v="12"> 凡水裡無翅無鱗的，你們都當以為可憎。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約伯記 39:27–30; 耶利米書 4:22; 提多書 3:3"> 「雀鳥中你們當以為可憎，不可吃的乃是：鵰，狗頭鵰，紅頭鵰，</span>
<span className="v" id="v14" data-v="14"> 鷂鷹，小鷹與其類，</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王紀上 17:6; 箴言 30:17"> 烏鴉與其類，</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 34:11–15; 以弗所書 5:7–11; 以弗所書 2:2–3"> 鴕鳥，夜鷹，魚鷹，鷹與其類，</span>
<span className="v" id="v17" data-v="17"> 鸮鳥，鸕鶿，貓頭鷹，</span>
<span className="v" id="v18" data-v="18"> 角鴟，鵜鶘，禿鵰，</span>
<span className="v" id="v19" data-v="19"> 鸛，鷺鷥與其類，戴鵀與蝙蝠。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 4:10; 腓立比書 3:18–19; 利未記 11:23"> 「凡有翅膀用四足爬行的物，你們都當以為可憎。</span>
<span className="v" id="v21" data-v="21"> 只是有翅膀、用四足爬行的物中，有足有腿，在地上蹦跳的，你們還可以吃。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 3:4; 馬可福音 1:6; 出埃及記 10:4–5"> 其中有蝗蟲，螞蚱，蟋蟀與其類，蚱蜢與其類，這些你們都可以吃。</span>
<span className="v" id="v23" data-v="23"> 但是有翅膀有四足的爬物，你們都當以為可憎。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:33; 以弗所書 2:1–3; 哥林多後書 6:17"> 這些都能使你們不潔淨：凡摸了死的，必不潔淨到晚上；</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 15:5; 利未記 14:8; 民數記 31:24"> 凡拿了死的，必不潔淨到晚上，並要洗衣服。</span>
<span className="v" id="v26" data-v="26"> 凡走獸分蹄不成兩瓣，也不倒嚼的，是於你們不潔淨，凡摸了的，就不潔淨。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 11:23; 利未記 11:20"> 凡四足的走獸，用掌行走的，是於你們不潔淨。摸其屍的，必不潔淨到晚上；</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 11:24–25"> 拿其屍的，必不潔淨到晚上，並要洗衣服。這些是於你們不潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="利未記 11:41–42; 提摩太後書 3:2–5; 詩篇 10:3"> 「地上爬物於你們不潔淨的乃是這些：鼬鼠，鼫鼠，蜥蜴與其類，</span>
<span className="v" id="v30" data-v="30"> 壁虎，龍子，守宮，蛇醫，蝘蜓。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 11:24–25; 利未記 11:8"> 這些爬物都是於你們不潔淨的。在牠死了以後，凡摸了的，必不潔淨到晚上。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 15:12; 提多書 3:5; 提多書 2:14"> 其中死了的，掉在什麼東西上，這東西就不潔淨，無論是木器、衣服、皮子、口袋，不拘是做什麼工用的器皿，須要放在水中，必不潔淨到晚上，到晚上才潔淨了。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 6:28; 利未記 15:12; 利未記 14:45"> 若有死了掉在瓦器裡的，其中不拘有什麼，就不潔淨，你們要把這瓦器打破了，</span>
<span className="v" id="v34" data-v="34" data-xref="提多書 1:15; 箴言 21:4; 箴言 21:27"> 其中一切可吃的食物，沾水的就不潔淨，並且那樣器皿中一切可喝的也必不潔淨。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 15:12; 利未記 6:28; 利未記 11:33"> 其中已死的，若有一點掉在什麼物件上，那物件就不潔淨，不拘是爐子，是鍋臺，就要打碎，都不潔淨，也必於你們不潔淨。</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亞書 13:1; 約翰福音 4:14"> 但是泉源或是聚水的池子仍是潔淨，唯挨了那死的，就不潔淨。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 15:37; 彼得前書 1:23; 約翰一書 5:18"> 若是死的，有一點掉在要種的子粒上，子粒仍是潔淨；</span>
<span className="v" id="v38" data-v="38"> 若水已經澆在子粒上，那死的有一點掉在上頭，這子粒就於你們不潔淨。</span>
</div>
</div>

## 捫自斃之物必蒙不潔

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="利未記 11:40; 利未記 11:24; 利未記 15:7"> 「你們可吃的走獸若是死了，有人摸牠，必不潔淨到晚上。</span>
<span className="v" id="v40" data-v="40" data-xref="利未記 22:8; 以西結書 44:31; 申命記 14:21"> 有人吃那死了的走獸，必不潔淨到晚上，並要洗衣服。拿了死走獸的，必不潔淨到晚上，並要洗衣服。</span>
</div>
</div>

## 禁食地上爬行之物

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="利未記 11:29; 利未記 11:20; 利未記 11:23"> 「凡地上的爬物是可憎的，都不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多書 1:12; 以賽亞書 65:25; 哥林多後書 11:3"> 凡用肚子行走的和用四足行走的，或是有許多足的，就是一切爬在地上的，你們都不可吃，因為是可憎的。</span>
<span className="v" id="v43" data-v="43" data-xref="利未記 20:25; 利未記 11:41–42"> 你們不可因什麼爬物使自己成為可憎的，也不可因這些使自己不潔淨，以致染了汙穢。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 20:2; 彼得前書 1:15–16; 利未記 19:2"> 我是耶和華你們的神，所以你們要成為聖潔，因為我是聖潔的。你們也不可在地上的爬物汙穢自己。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 11:44; 出埃及記 20:2; 出埃及記 6:7"> 我是把你們從埃及地領出來的耶和華，要做你們的神，所以你們要聖潔，因為我是聖潔的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未記 14:54; 利未記 15:32; 以西結書 43:12"> 「這是走獸、飛鳥和水中游動的活物，並地上爬物的條例，</span>
<span className="v" id="v47" data-v="47" data-xref="利未記 10:10; 以西結書 44:23; 羅馬書 14:13–23"> 要把潔淨的和不潔淨的、可吃的與不可吃的活物，都分別出來。」</span>
</div>
</div>

</div>

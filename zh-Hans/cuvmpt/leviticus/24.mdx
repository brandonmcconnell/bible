## 燃燈之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 4:6; 以弗所書 5:8–14; 出埃及記 27:20–21"> 「要吩咐以色列人，把那為點燈搗成的清橄欖油拿來給你，使燈常常點著。</span>
<span className="v" id="v3" data-v="3"> 在會幕中法櫃的幔子外，亞倫從晚上到早晨必在耶和華面前經理這燈。這要做你們世世代代永遠的定例。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 31:8; 出埃及記 37:17–24; 出埃及記 39:37"> 他要在耶和華面前常收拾精金燈臺上的燈。</span>
</div>
</div>

## 陳設餅

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:30; 列王紀上 18:31; 出埃及記 40:23"> 「你要取細麵，烤成十二個餅，每餅用麵伊法十分之二。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:48; 出埃及記 25:23–24; 歷代志下 4:19"> 要把餅擺列兩行<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「行」或作「摞」，下同。">a</a></sup>，每行六個，在耶和華面前精金的桌子上。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 2:2; 啟示錄 8:3–4; 創世記 9:16"> 又要把淨乳香放在每行餅上，作為紀念，就是作為火祭獻給耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 2:4; 民數記 4:7; 歷代志上 9:32"> 每安息日要常擺在耶和華面前，這為以色列人做永遠的約。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 8:31; 路加福音 6:4; 馬可福音 2:26"> 這餅是要給亞倫和他子孫的，他們要在聖處吃，為永遠的定例，因為在獻給耶和華的火祭中是至聖的。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民數記 11:4; 出埃及記 12:38"> 有一個以色列婦人的兒子，他父親是埃及人，一日閒遊在以色列人中，這以色列婦人的兒子和一個以色列人在營裡爭鬥。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:7; 利未記 24:15–16; 出埃及記 3:15"> 這以色列婦人的兒子褻瀆了聖名，並且咒詛，就有人把他送到摩西那裡。（他母親名叫示羅密，是但支派底伯利的女兒。）</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 18:15–16; 民數記 15:34; 民數記 27:5"> 他們把那人收在監裡，要得耶和華所指示的話。</span>
</div>
</div>

## 詛聖名者殺勿赦

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13"> 耶和華曉諭摩西說：</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:7; 利未記 20:27; 申命記 21:21"> 「把那咒詛聖名的人帶到營外，叫聽見的人都放手在他頭上，全會眾就要用石頭打死他。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 9:13; 出埃及記 22:28; 利未記 5:1"> 你要曉諭以色列人說：凡咒詛神的，必擔當他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 12:31; 雅各書 2:7; 約翰福音 10:33–36"> 那褻瀆耶和華名的，必被治死，全會眾總要用石頭打死他。不管是寄居的，是本地人，他褻瀆耶和華名的時候，必被治死。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:5–6; 申命記 19:11–12; 申命記 27:24"> 打死人的必被治死，</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 24:21; 出埃及記 21:34–36"> 打死牲畜的必賠上牲畜，以命償命。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 5:38; 馬太福音 7:2; 申命記 19:21"> 人若使他鄰舍的身體有殘疾，他怎樣行，也要照樣向他行。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 19:21; 馬太福音 5:38; 出埃及記 21:23–25"> 以傷還傷，以眼還眼，以牙還牙，他怎樣叫人的身體有殘疾，也要照樣向他行。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 24:17–18; 出埃及記 21:33"> 打死牲畜的，必賠上牲畜；打死人的，必被治死。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 12:49; 民數記 15:15–16; 民數記 9:14"> 不管是寄居的，是本地人，同歸一例。我是耶和華你們的神。」</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 10:28–29; 希伯來書 2:2–3; 民數記 15:35–36"> 於是摩西曉諭以色列人，他們就把那咒詛聖名的人帶到營外，用石頭打死。以色列人就照耶和華所吩咐摩西的行了。</span>
</div>
</div>

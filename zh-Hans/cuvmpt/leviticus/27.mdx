## 許願之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 6:2; 撒母耳記上 1:28; 士師記 11:30–31"> 「你曉諭以色列人說：人還特許的願，被許的人要按你所估的價值歸給耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 30:13; 利未記 27:25; 民數記 18:16"> 你估定的，從二十歲到六十歲的男人，要按聖所的平，估定價銀五十舍客勒，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 27:9–10; 撒迦利亞書 11:12–13; 馬太福音 26:15"> 若是女人，你要估定三十舍客勒。</span>
<span className="v" id="v5" data-v="5"> 若是從五歲到二十歲，男子你要估定二十舍客勒，女子估定十舍客勒。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 3:40–43; 民數記 18:14–16"> 若是從一月到五歲，男子你要估定五舍客勒，女子估定三舍客勒。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 90:10"> 若是從六十歲以上，男人你要估定十五舍客勒，女人估定十舍客勒。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 14:7; 利未記 14:21–22; 路加福音 21:1–4"> 他若貧窮，不能照你所估定的價，就要把他帶到祭司面前，祭司要按許願人的力量估定他的價。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「所許的若是牲畜，就是人獻給耶和華為供物的，凡這一類獻給耶和華的，都要成為聖。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 27:15–33; 雅各書 1:8"> 人不可改換，也不可更換，或是好的換壞的，或是壞的換好的。若以牲畜更換牲畜，所許的與所換的都要成為聖。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 23:18; 瑪拉基書 1:14"> 若牲畜不潔淨，是不可獻給耶和華為供物的，就要把牲畜安置在祭司面前。</span>
<span className="v" id="v12" data-v="12"> 祭司就要估定價值，牲畜是好是壞，祭司怎樣估定，就要以怎樣為是。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:19; 利未記 27:15; 利未記 22:14"> 他若一定要贖回，就要在你所估定的價值以外加上五分之一。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 18:14; 利未記 25:29–31; 利未記 27:21"> 「人將房屋分別為聖，歸給耶和華，祭司就要估定價值。房屋是好是壞，祭司怎樣估定，就要以怎樣為定。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 27:13"> 將房屋分別為聖的人，若要贖回房屋，就必在你所估定的價值以外加上五分之一，房屋仍舊歸他。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西結書 45:11–14; 何西阿書 3:2; 使徒行傳 4:34–37"> 「人若將承受為業的幾分地分別為聖，歸給耶和華，你要按這地撒種多少估定價值，若撒大麥一賀梅珥，要估價五十舍客勒。</span>
<span className="v" id="v17" data-v="17"> 他若從禧年將地分別為聖，就要以你所估定的價為定。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 25:15–16; 利未記 25:51–52; 利未記 25:27"> 倘若他在禧年以後將地分別為聖，祭司就要按著未到禧年所剩的年數推算價值，也要從你所估的減去價值。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 27:13"> 將地分別為聖的人若定要把地贖回，他便要在你所估的價值以外加上五分之一，地就准定歸他。</span>
<span className="v" id="v20" data-v="20"> 他若不贖回那地，或是將地賣給別人，就再不能贖了。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 44:29; 民數記 18:14; 利未記 25:31"> 但到了禧年，那地從買主手下出來的時候，就要歸耶和華為聖，和永獻的地一樣，要歸祭司為業。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 25:10; 利未記 25:25"> 他若將所買的一塊地，不是承受為業的，分別為聖歸給耶和華，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 27:18; 利未記 27:12"> 祭司就要將你所估的價值給他推算到禧年，當日他要以你所估的價銀為聖，歸給耶和華。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 25:28; 利未記 27:20"> 到了禧年，那地要歸賣主，就是那承受為業的原主。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:13; 民數記 18:16; 民數記 3:47"> 凡你所估定的價銀都要按著聖所的平，二十季拉為一舍客勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 13:2; 出埃及記 13:12–13; 民數記 18:17"> 「唯獨牲畜中頭生的，無論是牛是羊，既歸耶和華，誰也不可再分別為聖，因為這是耶和華的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 27:11"> 若是不潔淨的牲畜生的，就要按你所估定的價值加上五分之一贖回；若不贖回，就要按你所估定的價值賣了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 6:17–19; 利未記 27:21; 出埃及記 22:20"> 「但一切永獻的，就是人從他所有永獻給耶和華的，無論是人，是牲畜，是他承受為業的地，都不可賣，也不可贖。凡永獻的，是歸給耶和華為至聖。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 15:18–23; 民數記 21:2–3"> 凡從人中當滅的都不可贖，必被治死。</span>
</div>
</div>

## 十輸其一

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 23:23; 尼希米記 13:12; 創世記 28:22"> 「地上所有的，無論是地上的種子是樹上的果子，十分之一是耶和華的，是歸給耶和華為聖的。</span>
<span className="v" id="v31" data-v="31"> 人若要贖這十分之一的什麼物，就要加上五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 33:13; 以西結書 20:37; 彌迦書 7:14"> 凡牛群羊群中，一切從杖下經過的，每第十隻要歸給耶和華為聖。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 27:10"> 不可問是好是壞，也不可更換；若定要更換，所更換的與本來的牲畜都要成為聖，不可贖回。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="利未記 26:46; 民數記 1:1; 希伯來書 12:18–25"> 這就是耶和華在西奈山為以色列人所吩咐摩西的命令。</span>
</div>
</div>

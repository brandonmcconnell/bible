## 祭司獻贖愆祭之任

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 6:17; 利未記 5:14–7; 利未記 6:25"> 「贖愆祭的條例乃是如此：這祭是至聖的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 1:5; 利未記 6:25; 利未記 1:11"> 人在那裡宰燔祭牲，也要在那裡宰贖愆祭牲，其血，祭司要灑在壇的周圍。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:13; 利未記 3:15–16; 詩篇 51:6"> 又要將肥尾巴和蓋臟的脂油，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 3:4"> 兩個腰子和腰子上的脂油，就是靠腰兩旁的脂油，並肝上的網子和腰子，一概取下。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 1:13; 加拉太書 5:24; 彼得前書 4:1–2"> 祭司要在壇上焚燒，為獻給耶和華的火祭，是贖愆祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 6:29; 民數記 18:9–10; 利未記 2:3"> 祭司中的男丁都可以吃這祭物，要在聖處吃，是至聖的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 6:25–26; 利未記 14:13; 哥林多前書 9:13"> 贖罪祭怎樣，贖愆祭也是怎樣，兩個祭是一個條例。獻贖愆祭贖罪的祭司要得這祭物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 4:11; 出埃及記 29:14; 羅馬書 13:14"> 獻燔祭的祭司，無論為誰奉獻，要親自得他所獻那燔祭牲的皮。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 18:9; 以西結書 44:29; 利未記 2:10"> 凡在爐中烤的素祭和煎盤中做的，並鐵鏊上做的，都要歸那獻祭的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 8:14; 出埃及記 16:18"> 凡素祭，無論是油調和的是乾的，都要歸亞倫的子孫，大家均分。</span>
</div>
</div>

## 祭司獻平安祭之任

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 22:18–21; 以西結書 45:15; 利未記 3:1–17"> 「人獻於耶和華平安祭的條例乃是這樣：</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 2:4; 民數記 6:15; 彼得前書 2:5"> 他若為感謝獻上，就要用調油的無酵餅和抹油的無酵薄餅，並用油調勻細麵做的餅，與感謝祭一同獻上。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 4:5; 利未記 23:17; 馬太福音 13:33"> 要用有酵的餅和為感謝獻的平安祭，與供物一同獻上。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 18:19; 出埃及記 29:27–28; 民數記 18:24–32"> 從各樣的供物中，他要把一個餅獻給耶和華為舉祭，是要歸給灑平安祭牲血的祭司。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 22:29–30"> 「為感謝獻平安祭牲的肉，要在獻的日子吃，一點不可留到早晨。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 19:5–8; 申命記 12:6; 詩篇 116:14"> 若所獻的是為還願，或是甘心獻的，必在獻祭的日子吃，所剩下的第二天也可以吃。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:10; 何西阿書 6:2; 哥林多前書 15:4"> 但所剩下的祭肉，到第三天要用火焚燒。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 19:7–8; 利未記 11:41; 民數記 18:27"> 第三天若吃了平安祭的肉，這祭必不蒙悅納，人所獻的也不算為祭，反為可憎嫌的，吃這祭肉的，就必擔當他的罪孽。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多書 1:15; 使徒行傳 10:15–16"> 「挨了汙穢物的肉就不可吃，要用火焚燒。至於平安祭的肉，凡潔淨的人都要吃。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 15:2–33; 創世記 17:14; 利未記 22:3–7"> 只是獻於耶和華平安祭的肉，人若不潔淨而吃了，這人必從民中剪除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 12:1–59; 利未記 11:20; 以西結書 4:14"> 有人摸了什麼不潔淨的物，或是人的不潔淨，或是不潔淨的牲畜，或是不潔可憎之物，吃了獻於耶和華平安祭的肉，這人必從民中剪除。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華對摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 3:16–17; 利未記 17:6; 撒母耳記上 2:15–17"> 「你曉諭以色列人說：牛的脂油，綿羊的脂油，山羊的脂油，你們都不可吃。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 22:31; 利未記 17:15; 利未記 22:8"> 自死的和被野獸撕裂的，那脂油可以做別的使用，只是你們萬不可吃。</span>
<span className="v" id="v25" data-v="25"> 無論何人吃了獻給耶和華當火祭牲畜的脂油，那人必從民中剪除。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 9:4; 利未記 3:17; 使徒行傳 15:20"> 在你們一切的住處，無論是雀鳥的血是野獸的血，你們都不可吃。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 10:29; 利未記 7:20–21; 利未記 7:25"> 無論是誰吃血，那人必從民中剪除。」</span>
</div>
</div>

## 祭司當得之份

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和華對摩西說：</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 1:20; 約翰一書 1:7; 利未記 3:1–17"> 「你曉諭以色列人說：獻平安祭給耶和華的，要從平安祭中取些來奉給耶和華。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 6:20; 利未記 3:9; 利未記 3:14"> 他親手獻給耶和華的火祭，就是脂油和胸，要帶來，好把胸在耶和華面前做搖祭，搖一搖。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 3:5; 利未記 3:11; 利未記 3:16"> 祭司要把脂油在壇上焚燒，但胸要歸亞倫和他的子孫。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 6:20; 利未記 7:34; 利未記 9:21"> 你們要從平安祭中把右腿做舉祭，奉給祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 26:1–46; 利未記 6:1–30; 利未記 7:3"> 亞倫子孫中，獻平安祭牲血和脂油的，要得這右腿為份。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 18:18–19; 利未記 10:14–15; 出埃及記 29:9"> 因為我從以色列人的平安祭中，取了這搖的胸和舉的腿給祭司亞倫和他子孫，做他們從以色列人中所永得的份。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:20; 約翰一書 2:27; 民數記 18:7–19"> 這是從耶和華火祭中，做亞倫受膏的份和他子孫受膏的份，正在摩西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：他。">a</a></sup>叫他們前來給耶和華供祭司職分的日子，</span>
<span className="v" id="v36" data-v="36" data-xref="利未記 8:12; 利未記 8:30; 出埃及記 40:13–15"> 就是在摩西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：他。">b</a></sup>膏他們的日子，耶和華吩咐以色列人給他們的。這是他們世世代代永得的份。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及記 29:1; 利未記 1:1–6; 利未記 6:9–18"> 這就是燔祭、素祭、贖罪祭、贖愆祭和平安祭的條例，並承接聖職的禮，</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 1:1–2"> 都是耶和華在西奈山所吩咐摩西的，就是他在西奈曠野吩咐以色列人獻供物給耶和華之日所說的。</span>
</div>
</div>

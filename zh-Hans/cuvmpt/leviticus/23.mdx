<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:4; 利未記 23:37; 民數記 29:39"> 「你曉諭以色列人說：耶和華的節期，你們要宣告為聖會的節期。</span>

## 安息日

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 19:3; 出埃及記 23:12; 出埃及記 35:2–3"> 「六日要做工，第七日是聖安息日，當有聖會，你們什麼工都不可做。這是在你們一切的住處向耶和華守的安息日。</span>
</div>
</div>

## 無酵節

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未記 23:2; 出埃及記 23:14; 利未記 23:37"> 「耶和華的節期，就是你們到了日期要宣告為聖會的，乃是這些：</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:10; 申命記 16:1–8; 民數記 28:16–17"> 正月十四日黃昏的時候，是耶和華的逾越節。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 34:18; 申命記 16:8; 出埃及記 12:15–16"> 這月十五日是向耶和華守的無酵節，你們要吃無酵餅七日。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 28:18–25; 利未記 23:8; 利未記 23:21"> 第一日當有聖會，什麼勞碌的工都不可做。</span>
<span className="v" id="v8" data-v="8"> 要將火祭獻給耶和華七日。第七日是聖會，什麼勞碌的工都不可做。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華對摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 34:26; 出埃及記 23:19; 申命記 16:9"> 「你曉諭以色列人說：你們到了我賜給你們的地，收割莊稼的時候，要將初熟的莊稼一捆帶給祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 29:24; 利未記 10:14; 利未記 9:21"> 他要把這一捆在耶和華面前搖一搖，使你們得蒙悅納。祭司要在安息日的次日把這捆搖一搖。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:10–12; 彼得前書 1:19; 利未記 1:10"> 搖這捆的日子，你們要把一歲、沒有殘疾的公綿羊羔獻給耶和華為燔祭；</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 2:14–16; 約珥書 1:9; 民數記 28:10"> 同獻的素祭，就是調油的細麵伊法十分之二，作為馨香的火祭獻給耶和華；同獻的奠祭，要酒一欣四分之一。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 34:26; 創世記 4:4–5; 利未記 3:17"> 無論是餅，是烘的子粒，是新穗子，你們都不可吃，直等到把你們獻給神的供物帶來的那一天才可以吃。這在你們一切的住處作為世世代代永遠的定例。</span>
</div>
</div>

## 五旬節

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 23:10–11; 利未記 25:8; 申命記 16:9–10"> 「你們要從安息日的次日，獻禾捆為搖祭的那日算起，要滿了七個安息日，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:1; 民數記 28:26"> 到第七個安息日的次日，共計五十天，又要將新素祭獻給耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 23:10; 出埃及記 34:26; 出埃及記 34:22"> 要從你們的住處取出細麵伊法十分之二，加酵，烤成兩個搖祭的餅，當做初熟之物獻給耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 28:27–31; 利未記 23:12–13; 瑪拉基書 1:13–14"> 又要將一歲、沒有殘疾的羊羔七隻，公牛犢一隻，公綿羊兩隻，和餅一同奉上。這些與同獻的素祭和奠祭要作為燔祭獻給耶和華，就是做馨香的火祭獻給耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 28:30; 利未記 4:23–28; 利未記 7:11–18"> 你們要獻一隻公山羊為贖罪祭，兩隻一歲的公綿羊羔為平安祭。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 18:4; 以弗所書 2:14; 民數記 18:8–12"> 祭司要把這些和初熟麥子做的餅一同做搖祭，在耶和華面前搖一搖，這是獻於耶和華為聖物，歸給祭司的。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 23:2; 利未記 23:4; 民數記 18:23"> 當這日，你們要宣告聖會，什麼勞碌的工都不可做。這在你們一切的住處作為世世代代永遠的定例。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 24:19–21; 利未記 19:9–10; 以賽亞書 58:10"> 「在你們的地收割莊稼，不可割盡田角，也不可拾取所遺落的，要留給窮人和寄居的。我是耶和華你們的神。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華對摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:52; 帖撒羅尼迦前書 4:16; 利未記 25:9"> 「你曉諭以色列人說：七月初一，你們要守為聖安息日，要吹角做紀念，當有聖會。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:21"> 什麼勞碌的工都不可做，要將火祭獻給耶和華。」</span>
</div>
</div>

## 贖罪日

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華曉諭摩西說：</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 16:29–31; 出埃及記 30:10; 利未記 16:24"> 「七月初十是贖罪日，你們要守為聖會，並要刻苦己心，也要將火祭獻給耶和華。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亞書 3:9; 利未記 16:34; 希伯來書 10:10"> 當這日，什麼工都不可做，因為是贖罪日，要在耶和華你們的神面前贖罪。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:14; 民數記 5:2; 利未記 23:27"> 當這日，凡不刻苦己心的，必從民中剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 20:3; 西番雅書 2:5; 耶利米書 15:7"> 凡這日做什麼工的，我必將他從民中除滅。</span>
<span className="v" id="v31" data-v="31"> 你們什麼工都不可做。這在你們一切的住處作為世世代代永遠的定例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 16:31; 馬太福音 11:28–30; 詩篇 69:10–11"> 你們要守這日為聖安息日，並要刻苦己心，從這月初九日晚上到次日晚上，要守為安息日。」</span>
</div>
</div>

## 住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和華對摩西說：</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 7:2; 尼希米記 8:14; 以斯拉記 3:4"> 「你曉諭以色列人說：這七月十五日是住棚節，要在耶和華面前守這節七日。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 23:24–25; 利未記 23:7–8"> 第一日當有聖會，什麼勞碌的工都不可做。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 8:18; 約翰福音 7:37; 歷代志下 7:8–11"> 七日內要將火祭獻給耶和華。第八日當守聖會，要將火祭獻給耶和華。這是嚴肅會，什麼勞碌的工都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="利未記 23:2; 利未記 23:4; 傳道書 3:1"> 「這是耶和華的節期，就是你們要宣告為聖會的節期，要將火祭、燔祭、素祭、祭物並奠祭，各歸各日，獻給耶和華。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 29:39; 利未記 19:3; 以斯拉記 2:68–69"> 這是在耶和華的安息日以外，又在你們的供物和所許的願，並甘心獻給耶和華的以外。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 23:16; 申命記 16:13; 利未記 23:34"> 「你們收藏了地的出產，就從七月十五日起，要守耶和華的節七日。第一日為聖安息，第八日也為聖安息。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 4:4; 啟示錄 7:9; 申命記 16:14–15"> 第一日要拿美好樹上的果子和棕樹上的枝子，與茂密樹的枝條並河旁的柳枝，在耶和華你們的神面前歡樂七日。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 29:12; 尼希米記 8:18"> 每年七月間，要向耶和華守這節七日。這為你們世世代代永遠的定例。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米記 8:14–17; 創世記 33:17; 民數記 24:5"> 你們要住在棚裡七日，凡以色列家的人都要住在棚裡，</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 31:10–13; 詩篇 78:5–6; 出埃及記 13:14"> 好叫你們世世代代知道，我領以色列人出埃及地的時候曾使他們住在棚裡。我是耶和華你們的神。」</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 23:1–2; 馬太福音 18:20; 利未記 21:24"> 於是摩西將耶和華的節期傳給以色列人。</span>
</div>
</div>

</div>

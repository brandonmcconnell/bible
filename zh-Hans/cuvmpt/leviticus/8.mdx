<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 28:2–4; 出埃及記 39:41; 希伯來書 7:27"> 「你將亞倫和他兒子一同帶來，並將聖衣，膏油，與贖罪祭的一隻公牛，兩隻公綿羊，一筐無酵餅都帶來，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 30:13; 使徒行傳 2:1; 尼希米記 8:1"> 又招聚會眾到會幕門口。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 39:26; 出埃及記 39:7; 出埃及記 39:5"> 摩西就照耶和華所吩咐的行了，於是會眾聚集在會幕門口。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 29:4–37"> 摩西告訴會眾說：「這就是耶和華所吩咐當行的事。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 6:11; 以弗所書 5:26; 出埃及記 29:4"> 摩西帶了亞倫和他兒子來，用水洗了他們，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 28:4; 以賽亞書 61:10; 加拉太書 3:27"> 給亞倫穿上內袍，束上腰帶，穿上外袍，又加上以弗得，用其上巧工織的帶子把以弗得繫在他身上，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 2:63; 帖撒羅尼迦前書 5:8; 以賽亞書 59:17"> 又給他戴上胸牌，把烏陵和土明放在胸牌內，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 2:9–11; 撒迦利亞書 6:11–14; 出埃及記 28:36–38"> 把冠冕戴在他頭上，在冠冕的前面釘上金牌，就是聖冠，都是照耶和華所吩咐摩西的。</span>
</div>
</div>

## 膏亞倫使之成聖

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:9–11; 利未記 8:2; 出埃及記 30:23–29"> 摩西用膏油抹帳幕和其中所有的，使它成聖，</span>
<span className="v" id="v11" data-v="11" data-xref="提多書 3:6; 出埃及記 30:29; 出埃及記 16:19"> 又用膏油在壇上彈了七次，又抹了壇和壇的一切器皿，並洗濯盆和盆座，使它成聖，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 30:30; 詩篇 133:2; 出埃及記 29:7"> 又把膏油倒在亞倫的頭上膏他，使他成聖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 29:8–9; 啟示錄 5:10; 啟示錄 1:6"> 摩西帶了亞倫的兒子來，給他們穿上內袍，束上腰帶，包上裹頭巾，都是照耶和華所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 43:19; 詩篇 66:15; 彼得前書 3:18"> 他牽了贖罪祭的公牛來，亞倫和他兒子按手在贖罪祭公牛的頭上，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 4:7; 希伯來書 9:18–23; 以西結書 43:19–27"> 就宰了公牛。摩西用指頭蘸血，抹在壇上四角的周圍，使壇潔淨，把血倒在壇的腳那裡，使壇成聖，壇就潔淨了，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 29:13; 利未記 3:3–5; 利未記 4:8–9"> 又取臟上所有的脂油和肝上的網子，並兩個腰子與腰子上的脂油，都燒在壇上，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:11–12; 出埃及記 29:14; 利未記 6:30"> 唯有公牛，連皮帶肉並糞，用火燒在營外，都是照耶和華所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 8:2; 利未記 1:4–13; 出埃及記 29:15–18"> 他奉上燔祭的公綿羊，亞倫和他兒子按手在羊的頭上，</span>
<span className="v" id="v19" data-v="19"> 就宰了公羊。摩西把血灑在壇的周圍，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 1:8"> 把羊切成塊子，把頭和肉塊並脂油都燒了，</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 5:2; 出埃及記 29:18; 利未記 1:17"> 用水洗了臟腑和腿，就把全羊燒在壇上為馨香的燔祭，是獻給耶和華的火祭，都是照耶和華所吩咐摩西的。</span>
</div>
</div>

## 亞倫與其子任聖職

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 8:2; 利未記 8:29; 出埃及記 29:19–31"> 他又奉上第二隻公綿羊，就是承接聖職之禮的羊，亞倫和他兒子按手在羊的頭上，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:20; 利未記 14:14; 羅馬書 12:1"> 就宰了羊。摩西把些血抹在亞倫的右耳垂上和右手的大拇指上，並右腳的大拇指上；</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:18–22"> 又帶了亞倫的兒子來，把些血抹在他們的右耳垂上和右手的大拇指上，並右腳的大拇指上；又把血灑在壇的周圍。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 3:9; 利未記 3:3–5; 以賽亞書 53:10"> 取脂油和肥尾巴，並臟上一切的脂油與肝上的網子，兩個腰子和腰子上的脂油，並右腿；</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 29:23; 提摩太前書 2:5; 使徒行傳 5:12"> 再從耶和華面前盛無酵餅的筐子裡取出一個無酵餅、一個油餅、一個薄餅，都放在脂油和右腿上；</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 30:21; 希伯來書 9:14; 出埃及記 29:24–37"> 把這一切放在亞倫的手上和他兒子的手上做搖祭，在耶和華面前搖一搖。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 29:25; 詩篇 22:13–14; 希伯來書 10:14–22"> 摩西從他們的手上拿下來，燒在壇上的燔祭上，都是為承接聖職獻給耶和華馨香的火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 10:31; 彼得前書 4:11; 利未記 7:30–34"> 摩西拿羊的胸作為搖祭，在耶和華面前搖一搖，是承接聖職之禮，歸摩西的份，都是照耶和華所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 29:21; 民數記 3:3; 出埃及記 30:30"> 摩西取點膏油和壇上的血，彈在亞倫和他的衣服上，並他兒子和他兒子的衣服上，使他和他們的衣服一同成聖。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 29:31–32; 加拉太書 2:20; 撒母耳記上 2:13–17"> 摩西對亞倫和他兒子說：「把肉煮在會幕門口，在那裡吃，又吃承接聖職筐子裡的餅；按我所吩咐的說<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：按所吩咐我的說。">a</a></sup>，這是亞倫和他兒子要吃的。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 29:34; 出埃及記 12:10; 希伯來書 3:13–14"> 剩下的肉和餅，你們要用火焚燒。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 29:35; 民數記 19:12; 以西結書 43:25–27"> 你們七天不可出會幕的門，等到你們承接聖職的日子滿了，因為主叫你們七天承接聖職。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 7:27; 希伯來書 7:16; 希伯來書 10:11–12"> 像今天所行的，都是耶和華吩咐行的，為你們贖罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 3:7; 申命記 11:1; 列王紀上 2:3"> 七天你們要晝夜住在會幕門口，遵守耶和華的吩咐，免得你們死亡，因為所吩咐我的就是這樣。」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 12:32; 申命記 4:2; 出埃及記 40:16"> 於是亞倫和他兒子行了耶和華藉著摩西所吩咐的一切事。</span>
</div>
</div>

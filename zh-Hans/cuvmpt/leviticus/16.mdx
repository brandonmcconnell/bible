<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 10:1–2"> 亞倫的兩個兒子近到耶和華面前死了。死了之後，耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 30:10; 列王紀上 8:10–12; 希伯來書 10:19–20"> 「要告訴你哥哥亞倫，不可隨時進聖所的幔子內，到櫃上的施恩座前，免得他死亡，因為我要從雲中顯現在施恩座上。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 4:3; 希伯來書 9:24–25; 希伯來書 9:7"> 亞倫進聖所，要帶一隻公牛犢為贖罪祭，一隻公綿羊為燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 28:39–43; 以西結書 44:17–18; 出埃及記 30:20"> 要穿上細麻布聖內袍，把細麻布褲子穿在身上，腰束細麻布帶子，頭戴細麻布冠冕。這都是聖服，他要用水洗身，然後穿戴。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:21; 利未記 8:2; 以斯拉記 6:17"> 要從以色列會眾取兩隻公山羊為贖罪祭，一隻公綿羊為燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 9:7; 希伯來書 9:7; 希伯來書 7:27"> 「亞倫要把贖罪祭的公牛奉上，為自己和本家贖罪。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 12:1; 利未記 4:4; 馬太福音 16:21"> 也要把兩隻公山羊安置在會幕門口，耶和華面前，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:23–26; 約拿書 1:7; 箴言 16:33"> 為那兩隻羊拈鬮，一鬮歸於耶和華，一鬮歸於阿撒瀉勒。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:27–28; 使徒行傳 2:23"> 亞倫要把那拈鬮歸於耶和華的羊獻為贖罪祭，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 2:2; 利未記 16:21–22; 希伯來書 9:23–24"> 但那拈鬮歸於阿撒瀉勒的羊，要活著安置在耶和華面前，用以贖罪，打發人送到曠野去，歸於阿撒瀉勒。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 16:6; 希伯來書 7:27; 希伯來書 9:7"> 「亞倫要把贖罪祭的公牛牽來宰了，為自己和本家贖罪。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 10:1; 出埃及記 30:34–38; 啟示錄 8:3–4"> 拿香爐，從耶和華面前的壇上盛滿火炭，又拿一捧搗細的香料，都帶入幔子內，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 25:21; 出埃及記 30:1; 出埃及記 30:7–8"> 在耶和華面前，把香放在火上，使香的煙雲遮掩法櫃上的施恩座，免得他死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:25; 利未記 4:5–6; 希伯來書 9:13"> 也要取些公牛的血，用指頭彈在施恩座的東面，又在施恩座的前面彈血七次。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 9:7; 希伯來書 2:17; 希伯來書 9:3"> 「隨後他要宰那為百姓做贖罪祭的公山羊，把羊的血帶入幔子內，彈在施恩座的上面和前面，好像彈公牛的血一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 9:22–23; 利未記 16:18; 以西結書 45:18–19"> 他因以色列人諸般的汙穢、過犯，就是他們一切的罪愆，當這樣在聖所行贖罪之禮，並因會幕在他們汙穢之中，也要照樣而行。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 53:6; 路加福音 1:10; 出埃及記 34:3"> 他進聖所贖罪的時候，會幕裡不可有人，直等到他為自己和本家並以色列全會眾贖了罪出來。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:7; 希伯來書 5:7–8; 利未記 16:16"> 他出來，要到耶和華面前的壇那裡，在壇上行贖罪之禮。又要取些公牛的血和公山羊的血，抹在壇上四角的周圍，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 13:1; 以西結書 43:18–22"> 也要用指頭把血彈在壇上七次，潔淨了壇，從壇上除掉以色列人諸般的汙穢，使壇成聖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未記 16:16; 以西結書 45:20; 歌羅西書 1:20"> 「亞倫為聖所和會幕並壇獻完了贖罪祭，就要把那隻活著的公山羊奉上。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 53:6; 哥林多後書 5:21; 以斯拉記 10:1"> 兩手按在羊頭上，承認以色列人諸般的罪孽過犯，就是他們一切的罪愆，把這罪都歸在羊的頭上，藉著所派之人的手，送到曠野去。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 9:28; 以賽亞書 53:11–12; 約翰福音 1:29"> 要把這羊放在曠野，這羊要擔當他們一切的罪孽，帶到無人之地。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西結書 44:19; 以西結書 42:14; 利未記 16:4"> 「亞倫要進會幕，把他進聖所時所穿的細麻布衣服脫下，放在那裡，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 16:3–5; 希伯來書 10:19–22; 出埃及記 28:4–14"> 又要在聖處用水洗身，穿上衣服，出來把自己的燔祭和百姓的燔祭獻上，為自己和百姓贖罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 29:13; 利未記 4:8–10; 利未記 16:6"> 贖罪祭牲的脂油要在壇上焚燒。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 16:10; 希伯來書 7:19; 民數記 19:21"> 那放羊歸於阿撒瀉勒的人要洗衣服，用水洗身，然後進營。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 4:21; 利未記 6:30; 利未記 4:11–12"> 做贖罪祭的公牛和公山羊的血既帶入聖所贖罪，這牛羊就要搬到營外，將皮、肉、糞用火焚燒。</span>
<span className="v" id="v28" data-v="28"> 焚燒的人要洗衣服，用水洗身，然後進營。</span>
</div>
</div>

## 每歲當守贖罪日一次

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 58:3; 民數記 29:7; 出埃及記 20:10"> 「每逢七月初十日，你們要刻苦己心，無論是本地人，是寄居在你們中間的外人，什麼工都不可做，這要做你們永遠的定例。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 33:8; 詩篇 51:2; 以弗所書 5:26"> 因在這日要為你們贖罪，使你們潔淨。你們要在耶和華面前得以潔淨，脫盡一切的罪愆。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 23:32; 以賽亞書 58:5; 利未記 25:4"> 這日你們要守為聖安息日，要刻苦己心，這為永遠的定例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 16:4; 出埃及記 29:29–30; 利未記 4:5"> 那受膏接續他父親承接聖職的祭司，要穿上細麻布的聖衣，行贖罪之禮。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 16:16; 利未記 16:24; 利未記 16:6"> 他要在至聖所和會幕與壇行贖罪之禮，並要為眾祭司和會眾的百姓贖罪。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 9:7; 希伯來書 9:25; 出埃及記 30:10"> 這要做你們永遠的定例，就是因以色列人一切的罪，要一年一次為他們贖罪。」於是亞倫照耶和華所吩咐摩西的行了。</span>
</div>

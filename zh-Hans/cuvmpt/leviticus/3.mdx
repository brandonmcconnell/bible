## 平安祭之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 6:14; 利未記 1:3; 羅馬書 5:1–2"> 「人獻供物為平安祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「平安」或作「酬恩」，下同。">a</a></sup>，若是從牛群中獻，無論是公的是母的，必用沒有殘疾的獻在耶和華面前。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 29:10; 利未記 1:4–5; 使徒行傳 2:36–38"> 他要按手在供物的頭上，宰於會幕門口。亞倫子孫做祭司的，要把血灑在壇的周圍。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:13; 利未記 4:8–9; 出埃及記 29:22"> 從平安祭中，將火祭獻給耶和華，也要把蓋臟的脂油和臟上所有的脂油，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 3:10; 利未記 8:25; 出埃及記 29:22"> 並兩個腰子和腰子上的脂油，就是靠腰兩旁的脂油，與肝上的網子和腰子，一概取下。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 6:12; 出埃及記 29:13; 彼得前書 2:5"> 亞倫的子孫要把這些燒在壇的燔祭上，就是在火的柴上，是獻於耶和華為馨香的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多書 2:11–12; 加拉太書 3:28; 利未記 1:2"> 「人向耶和華獻供物為平安祭，若是從羊群中獻，無論是公的是母的，必用沒有殘疾的。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:62; 以弗所書 5:12; 利未記 17:8–9"> 若獻一隻羊羔為供物，必在耶和華面前獻上，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 1:5; 以弗所書 3:12; 利未記 3:13"> 並要按手在供物的頭上，宰於會幕前。亞倫的子孫要把血灑在壇的周圍。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 29:22; 利未記 9:19; 利未記 8:25"> 從平安祭中，將火祭獻給耶和華，其中的脂油和整肥尾巴都要在靠近脊骨處取下，並要把蓋臟的脂油和臟上所有的脂油，</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 3:4"> 兩個腰子和腰子上的脂油，就是靠腰兩旁的脂油，並肝上的網子和腰子，一概取下。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 21:17; 利未記 21:6; 利未記 3:16"> 祭司要在壇上焚燒，是獻給耶和華為食物的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未記 9:15; 以賽亞書 53:2; 哥林多後書 5:21"> 「人的供物若是山羊，必在耶和華面前獻上，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 3:8; 羅馬書 5:15–21; 哥林多後書 5:21"> 要按手在山羊頭上，宰於會幕前。亞倫的子孫要把血灑在壇的周圍。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:38; 馬太福音 22:37; 利未記 3:9–11"> 又把蓋臟的脂油和臟上所有的脂油，兩個腰子和腰子上的脂油，就是靠腰兩旁的脂油，並肝上的網子和腰子，一概取下，獻給耶和華為火祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:23–25; 馬太福音 22:37; 以賽亞書 53:10"> 祭司要在壇上焚燒，作為馨香火祭的食物。脂油都是耶和華的，</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:4; 馬太福音 26:28; 申命記 15:23"> 在你們一切的住處，脂油和血都不可吃，這要成為你們世世代代永遠的定例。」</span>
</div>
</div>

## 以色列人不全被棄

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:22; 撒母耳記上 12:22; 腓立比書 3:5"> 我且說，神棄絕了他的百姓嗎？斷乎沒有。因為我也是以色列人，亞伯拉罕的後裔，屬便雅憫支派的。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 94:14; 羅馬書 8:29–30; 出埃及記 32:1"> 神並沒有棄絕他預先所知道的百姓。你們豈不曉得經上論到以利亞是怎麼說的呢？他在神面前怎樣控告以色列人說：</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:10–18; 列王紀上 18:13; 尼希米記 9:26"> 「主啊，他們殺了你的先知，拆了你的祭壇，只剩下我一個人，他們還要尋索我的命。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 19:18; 民數記 25:3; 西番雅書 1:4"> 神的回話是怎麼說的呢？他說：「我為自己留下七千人，是未曾向巴力屈膝的。」</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 9:27; 以弗所書 1:5–6; 羅馬書 9:11"> 如今也是這樣，照著揀選的恩典，還有所留的餘數。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:21; 羅馬書 4:4–5; 提摩太後書 1:9"> 既是出於恩典，就不在乎行為；不然，恩典就不是恩典了。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:18; 羅馬書 11:5; 哥林多後書 4:4"> 這是怎麼樣呢？以色列人所求的，他們沒有得著，唯有蒙揀選的人得著了，其餘的就成了頑梗不化的。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:4; 以賽亞書 29:10; 以西結書 12:2"> 如經上所記：<br /><span className="pl pl-1">「神給他們昏迷的心，</span><br /><span className="pl pl-1">眼睛不能看見，</span><br /><span className="pl pl-1">耳朵不能聽見，</span><br /><span className="pl pl-1">直到今日。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 69:22–23; 路加福音 12:20; 詩篇 28:4"> 大衛也說：<br /><span className="pl pl-1">「願他們的筵席變為網羅，變為機檻，</span><br /><span className="pl pl-1">變為絆腳石，做他們的報應。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 69:23; 申命記 28:64–68; 彼得後書 2:4"> <span className="pl pl-1">願他們的眼睛昏矇，不得看見，</span><br /><span className="pl pl-1">願你時常彎下他們的腰。」</span></span>
</div>
</div>

## 猶太人所失為外邦人所得

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 13:46–48; 羅馬書 11:31; 羅馬書 10:19"> 我且說，他們失腳是要他們跌倒嗎？斷乎不是。反倒因他們的過失，救恩便臨到外邦人，要激動他們發憤。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:25; 歌羅西書 1:27; 羅馬書 11:15"> 若他們的過失為天下的富足，他們的缺乏為外邦人的富足，何況他們的豐滿呢？</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 9:15; 提摩太後書 1:11–12; 以弗所書 3:8"> 我對你們外邦人說這話：因我是外邦人的使徒，所以敬重<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「敬重」原文作「榮耀」。">a</a></sup>我的職分，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 7:16; 提摩太前書 4:16; 羅馬書 9:3"> 或者可以激動我骨肉之親發憤，好救他們一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 1:10; 羅馬書 5:10–11; 歌羅西書 1:20–21"> 若他們被丟棄，天下就得與神和好，他們被收納，豈不是死而復生嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 44:30; 雅各書 1:18; 箴言 3:9"> 所獻的新麵若是聖潔，全團也就聖潔了；樹根若是聖潔，樹枝也就聖潔了。</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所書 2:11–13; 以弗所書 3:6; 馬太福音 21:43"> 若有幾根枝子被折下來，你這野橄欖得接在其中，一同得著橄欖根的肥汁，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:12; 羅馬書 11:20; 以弗所書 2:19–20"> 你就不可向舊枝子誇口。若是誇口，當知道不是你托著根，乃是根托著你。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 11:17; 羅馬書 11:11–12; 羅馬書 11:23–24"> 你若說，那枝子被折下來是特為叫我接上。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:16; 哥林多後書 1:24; 哥林多前書 10:12"> 不錯，他們因為不信所以被折下來，你因為信所以立得住。你不可自高，反要懼怕。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:4–9; 耶利米書 25:29; 耶利米書 49:12"> 神既不愛惜原來的枝子，也必不愛惜你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 3:14; 希伯來書 3:6; 哥林多前書 15:2"> 可見神的恩慈和嚴厲：向那跌倒的人是嚴厲的；向你是有恩慈的，只要你長久在他的恩慈裡；不然，你也要被砍下來。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 3:16; 撒迦利亞書 12:10; 馬太福音 23:39"> 而且他們若不是長久不信，仍要被接上，因為神能夠把他們重新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:17–18; 羅馬書 11:30"> 你是從那天生的野橄欖上砍下來的，尚且逆著性得接在好橄欖上，何況這本樹的枝子要接在本樹上呢？</span>
</div>
</div>

## 猶太人暫時被棄終必得救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多後書 3:14–16; 羅馬書 16:25"> 弟兄們，我不願意你們不知道這奧祕，恐怕你們自以為聰明，就是：以色列人有幾分是硬心的，等到外邦人的數目添滿了，</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 59:20; 耶利米書 31:31–37; 詩篇 14:7"> 於是以色列全家都要得救。如經上所記：<br /><span className="pl pl-1">「必有一位救主從錫安出來，</span><br /><span className="pl pl-1">要消除雅各家的一切罪惡。」</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 31:31–34; 以賽亞書 59:21; 以西結書 36:25–29"> <span className="pl pl-1">又說：「我除去他們罪的時候，</span><br /><span className="pl pl-1">這就是我與他們所立的約。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 10:15; 申命記 7:7–8; 馬太福音 21:43"> 就著福音說，他們為你們的緣故是仇敵；就著揀選說，他們為列祖的緣故是蒙愛的。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 7:21; 民數記 23:19; 瑪拉基書 3:6"> 因為神的恩賜和選召是沒有後悔的。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 3:7; 以弗所書 2:1–2; 哥林多前書 7:25"> 你們從前不順服神，如今因他們的不順服，你們倒蒙了憐恤。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 11:15; 羅馬書 10:16; 羅馬書 11:25"> 這樣，他們也是不順服，叫他們因著施給你們的憐恤，現在也就蒙憐恤。</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太書 3:22; 羅馬書 3:9; 提摩太前書 2:4–6"> 因為神將眾人都圈在不順服之中，特意要憐恤眾人。</span>
</div>
</div>

## 主智無窮主道難尋

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="約伯記 5:9; 約伯記 11:7–9; 詩篇 92:5"> <span className="pl pl-1">深哉，神豐富的智慧和知識！</span><br /><span className="pl pl-1">他的判斷何其難測，</span><br /><span className="pl pl-1">他的蹤跡何其難尋！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 40:13; 哥林多前書 2:16; 約伯記 15:8"> <span className="pl pl-1">「誰知道主的心，</span><br /><span className="pl pl-1">誰做過他的謀士呢？</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 41:11; 約伯記 35:7; 哥林多前書 4:7"> <span className="pl pl-1">誰是先給了他，</span><br /><span className="pl pl-1">使他後來償還呢？」</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歌羅西書 1:15–17; 哥林多前書 8:6; 希伯來書 2:10"> <span className="pl pl-1">因為萬有都是本於他，</span><br /><span className="pl pl-1">倚靠他，歸於他。</span><br /><span className="pl pl-1">願榮耀歸給他，直到永遠！阿們。</span></span>

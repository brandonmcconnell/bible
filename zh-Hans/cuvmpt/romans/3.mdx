## 猶太人的長處

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 2:25–29; 創世記 25:32; 傳道書 6:11"> 這樣說來，猶太人有什麼長處，割禮有什麼益處呢？</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 9:4; 使徒行傳 7:38; 哥林多前書 9:17"> 凡事大有好處，第一是神的聖言交託他們。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 2:13; 希伯來書 4:2; 羅馬書 9:6"> 即便有不信的，這有何妨呢？難道他們的不信就廢掉神的信嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 51:4; 詩篇 116:11; 加拉太書 2:17"> 斷乎不能！不如說，神是真實的，人都是虛謊的。如經上所記：<br /><span className="pl pl-1">「你責備人的時候顯為公義，</span><br /><span className="pl pl-1">被人議論的時候可以得勝。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 6:19; 加拉太書 3:15; 羅馬書 9:18–20"> 我且照著人的常話說，我們的不義若顯出神的義來，我們可以怎麼說呢？神降怒是他不義嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:25; 使徒行傳 17:31; 約伯記 8:3"> 斷乎不是！若是這樣，神怎能審判世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:4; 羅馬書 9:19–20; 使徒行傳 13:27–29"> 若神的真實因我的虛謊越發顯出他的榮耀，為什麼我還受審判，好像罪人呢？</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 6:1; 羅馬書 6:15; 羅馬書 5:20"> 為什麼不說「我們可以作惡以成善」呢？這是毀謗我們的人說我們有這話。這等人定罪是該當的。</span>
</div>
</div>

## 引證猶太和外邦都在罪惡之下

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:22; 羅馬書 6:15; 以賽亞書 65:5"> 這卻怎麼樣呢？我們比他們強嗎？決不是的！因我們已經證明：猶太人和希臘人都在罪惡之下。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 53:1–3; 詩篇 14:1–3; 羅馬書 3:23"> 就如經上所記：<br /><span className="pl pl-1">「沒有義人，連一個也沒有。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 14:2–4; 詩篇 53:2; 提多書 3:3"> <span className="pl pl-1">沒有明白的，</span><br /><span className="pl pl-1">沒有尋求神的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 14:3; 傳道書 7:20; 以賽亞書 64:6"> <span className="pl pl-1">都是偏離正路，</span><br /><span className="pl pl-1">一同變為無用；</span><br /><span className="pl pl-1">沒有行善的，連一個也沒有。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 5:9; 詩篇 140:3; 馬太福音 23:27–28"> <span className="pl pl-1">他們的喉嚨是敞開的墳墓，</span><br /><span className="pl pl-1">他們用舌頭弄詭詐，</span><br /><span className="pl pl-1">嘴唇裡有虺蛇的毒氣，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 10:7; 詩篇 109:17–18; 詩篇 59:12"> <span className="pl pl-1">滿口是咒罵苦毒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">殺人流血，</span><br /><span className="pl pl-1">他們的腳飛跑；</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">所經過的路，便行殘害暴虐的事；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 59:8; 羅馬書 5:1; 路加福音 1:79"> <span className="pl pl-1">平安的路，他們未曾知道。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">他們眼中不怕神。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太書 3:10; 加拉太書 3:22–23; 羅馬書 2:12–18"> 我們曉得律法上的話都是對律法以下之人說的，好塞住各人的口，叫普世的人都伏在神審判之下。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 2:16; 使徒行傳 13:39; 羅馬書 3:28"> 所以凡有血氣的，沒有一個因行律法能在神面前稱義，因為律法本是叫人知罪。</span>
</div>
</div>

## 信靠耶穌乃得稱義

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 10:43; 耶利米書 33:16; 腓立比書 3:9"> 但如今，神的義在律法以外已經顯明出來，有律法和先知為證，</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 10:12; 加拉太書 3:28; 羅馬書 8:1"> 就是神的義因信耶穌基督加給一切相信的人，並沒有分別。</span>
<span className="v" id="v23" data-v="23" data-xref="傳道書 7:20; 約翰一書 1:8–10; 羅馬書 3:9"> 因為世人都犯了罪，虧缺了神的榮耀，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 1:18–19; 提多書 3:5–7; 歌羅西書 1:14"> 如今卻蒙神的恩典，因基督耶穌的救贖，就白白地稱義。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 3:23–24; 彼得前書 1:18–20; 約翰一書 4:10"> 神設立耶穌做挽回祭，是憑著耶穌的血，藉著人的信，要顯明神的義。因為他用忍耐的心寬容人先時所犯的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:4; 羅馬書 4:5; 羅馬書 3:30"> 好在今時顯明他的義，使人知道他自己為義，也稱信耶穌的人為義。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 4:2; 羅馬書 2:23; 哥林多前書 1:29–31"> 既是這樣，哪裡能誇口呢？沒有可誇的了。用何法沒有的呢？是用立功之法嗎？不是，乃用信主之法。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 2:16; 加拉太書 3:8; 提多書 3:7"> 所以<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：因為。">a</a></sup>我們看定了，人稱義是因著信，不在乎遵行律法。</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 3:11; 以弗所書 3:6; 撒迦利亞書 2:11"> 難道神只做猶太人的神嗎？不也是做外邦人的神嗎？是的，也做外邦人的神。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太書 3:8; 加拉太書 3:20; 腓立比書 3:3"> 神既是一位，他就要因信稱那受割禮的為義，也要因信稱那未受割禮的為義。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 2:21; 馬太福音 5:17; 羅馬書 13:8–10"> 這樣，我們因信廢了律法嗎？斷乎不是，更是堅固律法。</span>
</div>
</div>

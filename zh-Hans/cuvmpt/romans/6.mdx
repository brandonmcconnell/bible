## 信徒向罪而死向神活著

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:16; 加拉太書 5:13; 羅馬書 6:15"> 這樣，怎麼說呢？我們可以仍在罪中，叫恩典顯多嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 3:9; 歌羅西書 3:3; 羅馬書 7:4"> 斷乎不可！我們在罪上死了的人，豈可仍在罪中活著呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:27; 加拉太書 2:20–21; 羅馬書 6:8"> 豈不知我們這受洗歸入基督耶穌的人，是受洗歸入他的死嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 5:17; 歌羅西書 3:10; 以弗所書 4:22–24"> 所以，我們藉著洗禮歸入死，和他一同埋葬，原是叫我們一舉一動有新生的樣式，像基督藉著父的榮耀從死裡復活一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 3:10–11; 哥林多後書 4:10; 歌羅西書 2:12"> 我們若在他死的形狀上與他聯合，也要在他復活的形狀上與他聯合。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:20; 以弗所書 4:22; 加拉太書 5:24"> 因為知道，我們的舊人和他同釘十字架，使罪身滅絕，叫我們不再做罪的奴僕，</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:1; 歌羅西書 3:1–3; 羅馬書 7:4"> 因為已死的人是脫離了罪。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太後書 2:11–12; 歌羅西書 3:3–4; 哥林多後書 4:10–14"> 我們若是與基督同死，就信必與他同活。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 6:14; 啟示錄 1:18; 使徒行傳 2:24–28"> 因為知道，基督既從死裡復活，就不再死，死也不再做他的主了。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:21; 彼得前書 4:6; 彼得前書 3:18"> 他死是向罪死了，只有一次；他活是向神活著。</span>
<span className="v" id="v11" data-v="11" data-xref="歌羅西書 3:3–5; 哥林多前書 6:20; 羅馬書 6:2"> 這樣，你們向罪也當看自己是死的；向神，在基督耶穌裡，卻當看自己是活的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:16; 羅馬書 6:16; 羅馬書 8:13"> 所以，不要容罪在你們必死的身上做王，使你們順從身子的私慾。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 12:1; 羅馬書 6:16; 歌羅西書 3:5"> 也不要將你們的肢體獻給罪做不義的器具，倒要像從死裡復活的人，將自己獻給神，並將肢體做義的器具獻給神。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 5:18; 羅馬書 8:2; 羅馬書 7:4–11"> 罪必不能做你們的主，因你們不在律法之下，乃在恩典之下。</span>
</div>
</div>

## 罪與恩的結局

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多書 2:11–14; 以弗所書 2:8–10; 羅馬書 6:1–2"> 這卻怎麼樣呢？我們在恩典之下，不在律法之下，就可以犯罪嗎？斷乎不可！</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 8:34; 馬太福音 6:24; 約書亞記 24:15"> 豈不曉得你們獻上自己做奴僕，順從誰，就做誰的奴僕嗎？或做罪的奴僕，以至於死；或做順命的奴僕，以致成義。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 2:9; 提摩太後書 1:13; 羅馬書 1:8"> 感謝神！因為你們從前雖然做罪的奴僕，現今卻從心裡順服了所傳給你們道理的模範。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 6:22; 羅馬書 8:2; 加拉太書 5:1"> 你們既從罪裡得了釋放，就做了義的奴僕。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 6:13; 彼得前書 4:2–4; 歌羅西書 3:5–7"> 我因你們肉體的軟弱，就照人的常話對你們說：你們從前怎樣將肢體獻給不潔、不法做奴僕，以至於不法；現今也要照樣將肢體獻給義做奴僕，以至於成聖。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 6:16–17; 約翰福音 8:34"> 因為你們做罪之奴僕的時候，就不被義約束了。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 1:32; 羅馬書 7:5; 羅馬書 6:23"> 你們現今所看為羞恥的事，當日有什麼果子呢？那些事的結局就是死。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:16; 羅馬書 6:18; 羅馬書 8:2"> 但現今，你們既從罪裡得了釋放，做了神的奴僕，就有成聖的果子，那結局就是永生。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 3:36; 羅馬書 5:12; 雅各書 1:15"> 因為罪的工價乃是死，唯有神的恩賜，在我們的主基督耶穌裡乃是永生。</span>
</div>
</div>

## 保羅憂愁以色列人不信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 2:7; 羅馬書 1:9; 加拉太書 1:20"> 我在基督裡說真話，並不謊言，有我良心被聖靈感動給我作見證。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 3:18; 詩篇 119:136; 耶利米書 13:17"> 我是大有憂愁，心裡時常傷痛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 32:32; 以斯帖記 8:6; 羅馬書 11:14"> 為我弟兄，我骨肉之親，就是自己被咒詛，與基督分離，我也願意。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:12; 詩篇 147:19; 羅馬書 9:6"> 他們是以色列人，那兒子的名分、榮耀、諸約、律法、禮儀、應許都是他們的；</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 10:30; 約翰福音 1:1–3; 歌羅西書 1:16–19"> 列祖就是他們的祖宗；按肉體說，基督也是從他們出來的——他是在萬有之上永遠可稱頌的神！阿們。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 2:28–29; 加拉太書 6:16; 羅馬書 11:1–2"> 這不是說神的話落了空。因為從以色列生的，不都是以色列人；</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 21:12; 希伯來書 11:18; 約翰福音 8:37–39"> 也不因為是亞伯拉罕的後裔，就都做他的兒女，唯獨「從以撒生的，才要稱為你的後裔」。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:13; 羅馬書 4:11–16; 加拉太書 3:26–29"> 這就是說，肉身所生的兒女不是神的兒女，唯獨那應許的兒女才算是後裔。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 18:10; 創世記 18:14; 創世記 17:21"> 因為所應許的話是這樣說：「到明年這時候我要來，撒拉必生一個兒子。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 25:21–23; 路加福音 16:26; 羅馬書 5:11"> 不但如此，還有利百加，既從一個人，就是從我們的祖宗以撒懷了孕，</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 1:9; 以弗所書 1:4–5; 彼得後書 1:10"> 雙子還沒有生下來，善惡還沒有做出來——只因要顯明神揀選人的旨意，不在乎人的行為，乃在乎召人的主——</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:22–23; 撒母耳記下 8:14; 列王紀上 22:47"> 神就對利百加說：「將來大的要服侍小的。」</span>
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 1:2–3; 申命記 21:15; 創世記 29:33"> 正如經上所記：「雅各是我所愛的，以掃是我所惡的。」</span>
</div>
</div>

## 隨意憐憫慈悲

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 19:7; 詩篇 145:17; 申命記 32:4"> 這樣，我們可說什麼呢？難道神有什麼不公平嗎？斷乎沒有！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 33:19; 羅馬書 9:16; 彌迦書 7:18"> 因他對摩西說：<br /><span className="pl pl-1">「我要憐憫誰就憐憫誰，</span><br /><span className="pl pl-1">要恩待誰就恩待誰。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以弗所書 2:8; 馬太福音 11:25–26; 彼得前書 2:9–10"> 據此看來，這不在乎那定意的，也不在乎那奔跑的，只在乎發憐憫的神。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 9:16; 箴言 16:4; 出埃及記 14:17–18"> 因為經上有話向法老說：「我將你興起來，特要在你身上彰顯我的權能，並要使我的名傳遍天下。」</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 11:20; 出埃及記 4:21; 羅馬書 9:15–16"> 如此看來，神要憐憫誰就憐憫誰，要叫誰剛硬就叫誰剛硬。</span>
</div>
</div>

## 預言外邦人蒙愛

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="但以理書 4:35; 歷代志下 20:6; 哥林多前書 15:12"> 這樣，你必對我說：「他為什麼還指責人呢？有誰抗拒他的旨意呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 29:16; 以賽亞書 45:9–11; 以賽亞書 64:8"> 你這個人哪，你是誰，竟敢向神強嘴呢？受造之物豈能對造他的說：「你為什麼這樣造我呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 64:8; 箴言 16:4; 提摩太後書 2:20–21"> 窯匠難道沒有權柄從一團泥裡拿一塊做成貴重的器皿，又拿一塊做成卑賤的器皿嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 猶大書 1:4; 羅馬書 9:21"> 倘若神要顯明他的憤怒，彰顯他的權能，就多多忍耐寬容那可怒、預備遭毀滅的器皿，</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 2:4; 彼得前書 1:2–5; 歌羅西書 1:27"> 又要將他豐盛的榮耀彰顯在那蒙憐憫、早預備得榮耀的器皿上——</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:11; 使徒行傳 13:47–48; 以弗所書 3:6–8"> 這器皿就是我們被神所召的，不但是從猶太人中，也是從外邦人中——這有什麼不可呢？</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 2:23; 彼得前書 2:10; 約翰福音 16:27"> 就像神在何西阿書上說：<br /><span className="pl pl-1">「那本來不是我子民的，</span><br /><span className="pl pl-1">我要稱為我的子民；</span><br /><span className="pl pl-1">本來不是蒙愛的，</span><br /><span className="pl pl-1">我要稱為蒙愛的。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 1:9–10; 約翰一書 3:1–3; 加拉太書 3:26"> <span className="pl pl-1">從前在什麼地方對他們說『</span><br /><span className="pl pl-1">你們不是我的子民』，</span><br /><span className="pl pl-1">將來就在那裡稱他們為『永生神的兒子』。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 10:20–23; 羅馬書 11:4–6; 以賽亞書 1:9"> 以賽亞指著以色列人喊著說：「以色列人雖多如海沙，得救的不過是剩下的餘數。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 10:23; 啟示錄 19:11; 使徒行傳 17:31"> 因為主要在世上施行他的話，叫他的話都成全，速速地完結。」</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 1:9; 以賽亞書 13:19; 阿摩司書 4:11"> 又如以賽亞先前說過：<br /><span className="pl pl-1">「若不是萬軍之主給我們存留餘種，</span><br /><span className="pl pl-1">我們早已像所多瑪、蛾摩拉的樣子了。」</span></span>
</div>
</div>

## 律法的義和信心的義相比

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比書 3:9; 希伯來書 11:7; 加拉太書 2:16"> 這樣，我們可說什麼呢？那本來不追求義的外邦人反得了義，就是因信而得的義；</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 11:7; 羅馬書 3:20; 雅各書 2:10–11"> 但以色列人追求律法的義，反得不著律法的義。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 1:23; 彼得前書 2:8; 路加福音 7:23"> 這是什麼緣故呢？是因為他們不憑著信心求，只憑著行為求，他們正跌在那絆腳石上。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 28:16; 以賽亞書 8:14–15; 羅馬書 10:11"> 就如經上所記：<br /><span className="pl pl-1">「我在錫安放一塊絆腳的石頭、跌人的磐石，</span><br /><span className="pl pl-1">信靠他的人必不至於羞愧。」</span></span>
</div>

## 大衛末終之言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 16:12–13; 撒母耳記下 7:8–9; 詩篇 89:20"> 以下是大衛末了的話。耶西的兒子大衛得居高位，是雅各神所膏的，做以色列的美歌者，說：</span>
<span className="v" id="v2" data-v="2" data-xref="彼得後書 1:21; 馬太福音 22:43; 馬可福音 12:36"> <span className="pl pl-1">「耶和華的靈藉著我說，</span><br /><span className="pl pl-1">他的話在我口中。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 22:32; 申命記 32:4; 出埃及記 18:21"> <span className="pl pl-1">以色列的神，</span><br /><span className="pl pl-1">以色列的磐石曉諭我說：</span><br /><span className="pl pl-1">『那以公義治理人民的，</span><br /><span className="pl pl-1">敬畏神執掌權柄，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="士師記 5:31; 詩篇 72:6; 何西阿書 6:5"> <span className="pl pl-1">他必像日出的晨光，</span><br /><span className="pl pl-1">如無雲的清晨，</span><br /><span className="pl pl-1">雨後的晴光，</span><br /><span className="pl pl-1">使地發生嫩草。』</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 55:3; 撒母耳記下 7:14–16; 以賽亞書 9:6–7"> <span className="pl pl-1">我家在神面前並非如此，</span><br /><span className="pl pl-1">神卻與我立永遠的約。</span><br /><span className="pl pl-1">這約凡事堅穩，</span><br /><span className="pl pl-1">關乎我的一切救恩和我一切所想望的，</span><br /><span className="pl pl-1">他豈不為我成就嗎？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 2:6; 以賽亞書 33:12; 申命記 13:13"> <span className="pl pl-1">但匪類都必像荊棘被丟棄，</span><br /><span className="pl pl-1">人不敢用手拿它。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 6:8; 帖撒羅尼迦後書 2:8; 以賽亞書 27:4"> <span className="pl pl-1">拿它的人必帶鐵器和槍桿，</span><br /><span className="pl pl-1">終久它必被火焚燒。」</span></span>
</div>

## 記大衛之勇士

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志上 27:2; 歷代志上 11:11–47; 歷代志上 27:32"> 大衛勇士的名字記在下面。他革捫人約設巴設，又稱伊斯尼人亞底挪，他是軍長的統領，一時擊殺了八百人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志上 27:4; 歷代志上 11:12–14; 撒母耳記上 17:26"> 其次是亞合人朵多的兒子以利亞撒。從前非利士人聚集要打仗，以色列人迎著上去，有跟隨大衛的三個勇士向非利士人罵陣，其中有以利亞撒。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 19:5; 撒母耳記上 11:13; 士師記 15:14"> 他起來擊殺非利士人，直到手臂疲乏，手粘住刀把。那日耶和華使以色列人大獲全勝，眾民在以利亞撒後頭專奪財物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 11:13–14; 歷代志上 11:27; 撒母耳記下 23:33"> 其次是哈拉人亞基的兒子沙瑪。一日，非利士人聚集成群，在一塊長滿紅豆的田裡，眾民就在非利士人面前逃跑。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳記下 23:10; 詩篇 3:8"> 沙瑪卻站在那田間擊殺非利士人，救護了那田。耶和華使以色列人大獲全勝。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:1; 撒母耳記下 5:18; 約書亞記 12:15"> 收割的時候，有三十個勇士中的三個人下到亞杜蘭洞見大衛。非利士的軍兵在利乏音谷安營。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 22:4–5; 撒母耳記上 13:4; 撒母耳記上 10:5"> 那時大衛在山寨，非利士人的防營在伯利恆。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 4:14; 詩篇 42:1–2; 以賽亞書 41:17"> 大衛渴想，說：「甚願有人將伯利恆城門旁井裡的水打來給我喝！」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:14; 哥林多後書 5:14; 腓立比書 2:17"> 這三個勇士就闖過非利士人的營盤，從伯利恆城門旁的井裡打水，拿來奉給大衛。他卻不肯喝，將水奠在耶和華面前，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 17:10; 馬可福音 14:24; 哥林多前書 15:30"> 說：「耶和華啊，這三個人冒死去打水，這水好像他們的血一般，我斷不敢喝！」如此，大衛不肯喝。這是三個勇士所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 10:10; 撒母耳記下 10:14; 歷代志上 11:20–21"> 洗魯雅的兒子約押的兄弟亞比篩是這三個勇士的首領。他舉槍殺了三百人，就在三個勇士裡得了名。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:8; 馬太福音 13:23; 哥林多前書 15:41"> 他在這三個勇士裡是最尊貴的，所以做他們的首領，只是不及前三個勇士。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 8:18; 約書亞記 15:21; 撒母耳記下 20:23"> 有甲薛勇士耶何耶大的兒子比拿雅行過大能的事。他殺了摩押人亞利伊勒的兩個兒子。又在下雪的時候下坑裡去，殺了一個獅子。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 17:51; 歷代志上 11:23; 歌羅西書 2:15"> 又殺了一個強壯的埃及人，埃及人手裡拿著槍，比拿雅只拿著棍子下去，從埃及人手裡奪過槍來，用那槍將他殺死。</span>
<span className="v" id="v22" data-v="22"> 這是耶何耶大的兒子比拿雅所行的事，就在三個勇士裡得了名。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 20:23; 歷代志上 27:6; 撒母耳記上 22:14"> 他比那三十個勇士都尊貴，只是不及前三個勇士。大衛立他做護衛長。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 2:18; 歷代志上 27:7; 歷代志上 11:26"> 三十個勇士裡有約押的兄弟亞撒黑，伯利恆人朵多的兒子伊勒哈難，</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 7:1; 歷代志上 11:27–28"> 哈律人沙瑪，哈律人以利加，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:2; 歷代志上 11:27–28; 歷代志上 27:9–10"> 帕勒提人希利斯，提哥亞人益吉的兒子以拉，</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 21:18; 歷代志上 11:19; 歷代志上 11:28"> 亞拿突人亞比以謝，戶沙人米本乃，</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 27:13; 列王紀下 25:23; 歷代志上 11:30"> 亞合人撒們，尼陀法人瑪哈萊，</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 11:30–31; 約書亞記 18:28; 歷代志上 27:15"> 尼陀法人巴拿的兒子希立，便雅憫族基比亞人利拜的兒子以太，</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 12:15; 歷代志上 27:14; 士師記 12:13"> 比拉頓人比拿雅，迦實溪人希太，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:16; 歷代志上 11:32–33"> 伯亞拉巴人亞比亞本，巴魯米人押斯瑪弗，</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 11:34"> 沙本人以利雅哈巴，雅善兒子中的約拿單，</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 11:27; 撒母耳記下 23:11; 歷代志上 11:35"> 哈拉人沙瑪，哈拉人沙拉的兒子亞希暗，</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 11:3; 撒母耳記下 15:12; 撒母耳記下 10:6"> 瑪迦人亞哈拜的兒子以利法列，基羅人亞希多弗的兒子以連，</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 11:37; 約書亞記 15:55"> 迦密人希斯萊，亞巴人帕萊，</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 8:3; 歷代志上 11:38"> 瑣巴人拿單的兒子以甲，迦得人巴尼，</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 11:37; 歷代志上 11:39; 撒母耳記下 4:2"> 亞捫人洗勒，比錄人拿哈萊（是給洗魯雅的兒子約押拿兵器的），</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 2:53; 撒母耳記下 20:26; 歷代志上 11:40"> 以帖人以拉，以帖人迦立，</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記下 11:3; 馬太福音 1:6; 列王紀上 15:5"> 赫人烏利亞，共有三十七人。</span>
</div>
</div>

## 押沙龍敗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 8:10; 撒母耳記上 8:12; 出埃及記 17:9"> 大衛數點跟隨他的人，立千夫長、百夫長率領他們。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 7:16; 撒母耳記下 15:19–22; 撒母耳記下 10:7–10"> 大衛打發軍兵出戰，分為三隊，一隊在約押手下，一隊在洗魯雅的兒子約押兄弟亞比篩手下，一隊在迦特人以太手下。大衛對軍兵說：「我必與你們一同出戰。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 21:17; 出埃及記 17:10–12; 列王紀上 22:31"> 軍兵卻說：「你不可出戰。若是我們逃跑，敵人必不介意，我們陣亡一半，敵人也不介意，因為你一人強似我們萬人。你不如在城裡預備幫助我們。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 18:24; 撒母耳記下 18:1; 撒母耳記上 29:2"> 王向他們說：「你們以為怎樣好，我就怎樣行。」於是王站在城門旁，軍兵或百或千地挨次出去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 21:18–21; 撒母耳記下 16:11; 詩篇 103:13"> 王囑咐約押、亞比篩、以太說：「你們要為我的緣故寬待那少年人押沙龍。」王為押沙龍囑咐眾將的話，兵都聽見了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 17:18; 約書亞記 17:15; 士師記 12:4–6"> 兵就出到田野迎著以色列人，在以法蓮樹林裡交戰。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 24:21; 撒母耳記下 2:31; 撒母耳記下 2:26"> 以色列人敗在大衛的僕人面前，那日陣亡的甚多，共有二萬人。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 15:10; 約書亞記 10:11; 詩篇 43:1"> 因為在那裡四面打仗，死於樹林的比死於刀劍的更多。</span>
</div>
</div>

## 押沙龍死

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 14:26; 箴言 30:17; 約伯記 31:3"> 押沙龍偶然遇見大衛的僕人。押沙龍騎著騾子，從大橡樹密枝底下經過，他的頭髮被樹枝繞住，就懸掛起來，所騎的騾子便離他去了。</span>
<span className="v" id="v10" data-v="10"> 有個人看見，就告訴約押說：「我看見押沙龍掛在橡樹上了！」</span>
<span className="v" id="v11" data-v="11"> 約押對報信的人說：「你既看見他，為什麼不將他打死落在地上呢？你若打死他，我就賞你十舍客勒銀子，一條帶子。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 18:5"> 那人對約押說：「我就是得你一千舍客勒銀子，我也不敢伸手害王的兒子，因為我們聽見王囑咐你和亞比篩並以太說：『你們要謹慎，不可害那少年人押沙龍。』</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 14:19–20; 希伯來書 4:13; 撒母耳記下 4:10–12"> 我若妄為害了他的性命，就是你自己也必與我為敵。原來無論何事都瞞不過王。」</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 45:5; 馬太福音 12:40; 撒母耳記下 14:30"> 約押說：「我不能與你流連。」約押手拿三杆短槍，趁押沙龍在橡樹上還活著，就刺透他的心。</span>
<span className="v" id="v15" data-v="15"> 給約押拿兵器的十個少年人圍繞押沙龍，將他殺死。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 2:28; 撒母耳記下 20:22; 哥林多前書 14:8"> 約押吹角，攔阻眾人，他們就回來，不再追趕以色列人。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 7:26; 約書亞記 8:29; 撒母耳記下 19:8"> 他們將押沙龍丟在林中一個大坑裡，上頭堆起一大堆石頭。以色列眾人都逃跑，各回各家去了。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 14:17; 撒母耳記下 14:27; 撒母耳記上 15:12"> 押沙龍活著的時候，在王谷立了一根石柱，因他說：「我沒有兒子為我留名。」他就以自己的名稱那石柱叫押沙龍柱，直到今日。</span>
</div>
</div>

## 二人報信

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 15:36; 撒母耳記下 18:31; 詩篇 9:4"> 撒督的兒子亞希瑪斯說：「容我跑去，將耶和華向仇敵給王報仇的信息報於王知。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 18:5; 撒母耳記下 18:33; 撒母耳記下 17:16–21"> 約押對他說：「你今日不可去報信，改日可以報信。因為今日王的兒子死了，所以你不可去報信。」</span>
<span className="v" id="v21" data-v="21"> 約押對古示人說：「你去將你所看見的告訴王。」古示人在約押面前下拜，就跑去了。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 1:28; 以弗所書 5:4"> 撒督的兒子亞希瑪斯又對約押說：「無論怎樣，求你容我隨著古示人跑去！」約押說：「我兒，你報這信息，既不得賞賜，何必要跑去呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 20:4"> 他又說：「無論怎樣，我要跑去！」約押說：「你跑去吧！」亞希瑪斯就從平原往前跑，跑過古示人去了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 19:8; 撒母耳記下 13:34; 以西結書 33:2–7"> 大衛正坐在城甕裡。守望的人上城門樓的頂上，舉目觀看，見有一個人獨自跑來。</span>
<span className="v" id="v25" data-v="25"> 守望的人就大聲告訴王。王說：「他若獨自來，必是報口信的。」那人跑得漸漸近了。</span>
<span className="v" id="v26" data-v="26"> 守望的人又見一人跑來，就對守城門的人說：「又有一人獨自跑來。」王說：「這也必是報信的。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 9:20; 列王紀上 1:42; 羅馬書 10:15"> 守望的人說：「我看前頭人的跑法，好像撒督的兒子亞希瑪斯的跑法一樣。」王說：「他是個好人，必是報好信息。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 14:4; 創世記 14:20; 創世記 24:27"> 亞希瑪斯向王呼叫說：「平安了！」就在王面前臉伏於地叩拜，說：「耶和華你的神是應當稱頌的！因他已將那舉手攻擊我主我王的人交給王了。」</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 18:22; 撒母耳記下 20:9; 撒母耳記下 18:19–20"> 王問說：「少年人押沙龍平安不平安？」亞希瑪斯回答說：「約押打發王的僕人，那時僕人聽見眾民大聲喧嘩，卻不知道是什麼事。」</span>
<span className="v" id="v30" data-v="30"> 王說：「你退去，站在旁邊。」他就退去，站在旁邊。</span>
</div>
</div>

## 大衛聞信慟哭

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 18:19; 撒母耳記下 18:28; 路加福音 18:7–8"> 古示人也來到，說：「有信息報給我主我王，耶和華今日向一切興起攻擊你的人給你報仇了！」</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 5:31; 撒母耳記上 25:26; 但以理書 4:19"> 王問古示人說：「少年人押沙龍平安不平安？」古示人回答說：「願我主我王的仇敵和一切興起要殺害你的人，都與那少年人一樣。」</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 19:4; 撒母耳記下 12:10–23; 箴言 17:25"> 王就心裡傷慟，上城門樓去哀哭，一面走一面說：「我兒押沙龍啊！我兒，我兒押沙龍啊！我恨不得替你死！押沙龍啊！我兒，我兒！」</span>
</div>
</div>

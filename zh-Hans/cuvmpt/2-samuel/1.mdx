## 大衛聞報基利波山之噩耗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 27:6; 撒母耳記上 31:6; 撒母耳記上 30:17–26"> 掃羅死後，大衛擊殺亞瑪力人回來，在洗革拉住了兩天。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:12; 撒母耳記下 4:10; 約書亞記 7:6"> 第三天，有一人從掃羅的營裡出來，衣服撕裂，頭蒙灰塵，到大衛面前伏地叩拜。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 1:15–19; 列王紀下 5:25"> 大衛問他說：「你從哪裡來？」他說：「我從以色列的營裡逃來。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 4:16; 撒母耳記上 31:1–6; 歷代志上 10:1–6"> 大衛又問他說：「事情怎樣？請你告訴我。」他回答說：「百姓從陣上逃跑，也有許多人仆倒死亡，掃羅和他兒子約拿單也死了。」</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 25:2; 箴言 14:15"> 大衛問報信的少年人說：「你怎麼知道掃羅和他兒子約拿單死了呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 28:4; 撒母耳記下 1:21; 歷代志上 10:4–6"> 報信的少年人說：「我偶然到基利波山，看見掃羅伏在自己槍上，有戰車、馬兵緊緊地追他。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 22:12; 撒母耳記下 9:6; 士師記 9:54"> 他回頭看見我，就呼叫我。我說：『我在這裡。』</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:17; 撒母耳記上 30:13; 撒母耳記上 30:1"> 他問我說：『你是什麼人？』我說：『我是亞瑪力人。』</span>
<span className="v" id="v9" data-v="9"> 他說：『請你來將我殺死，因為痛苦抓住我，我的生命尚存。』</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:2; 士師記 9:54; 列王紀下 11:12"> 我準知他仆倒必不能活，就去將他殺死，把他頭上的冠冕、臂上的鐲子拿到我主這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 13:31; 創世記 37:29; 撒母耳記下 3:31"> 大衛就撕裂衣服，跟隨他的人也是如此，</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:17; 詩篇 35:13–14; 馬太福音 5:44"> 而且悲哀哭號，禁食到晚上，是因掃羅和他兒子約拿單，並耶和華的民以色列家的人倒在刀下。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 1:8"> 大衛問報信的少年人說：「你是哪裡的人？」他說：「我是亞瑪力客人的兒子。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 26:9; 撒母耳記上 31:4; 彼得後書 2:10"> 大衛說：「你伸手殺害耶和華的受膏者，怎麼不畏懼呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 2:34; 士師記 8:20; 撒母耳記下 4:10–12"> 大衛叫了一個少年人來，說：「你去殺他吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:25; 路加福音 19:22; 利未記 20:9"> 大衛對他說：「你流人血的罪歸到自己的頭上，因為你親口作見證說『我殺了耶和華的受膏者』。」少年人就把他殺了。</span>
</div>
</div>

## 為掃羅及約拿單作哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="歷代志下 35:25; 撒母耳記下 1:19; 創世記 50:11"> 大衛作哀歌，弔掃羅和他兒子約拿單，</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 10:13; 創世記 49:8; 申命記 4:10"> 且吩咐將這歌教導猶大人。這歌名叫弓歌，寫在《雅煞珥書》上。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 1:27; 撒母耳記下 1:25; 申命記 4:7–8"> 歌中說：<br /><span className="pl pl-1">「以色列啊，你尊榮者在山上被殺，</span><br /><span className="pl pl-1">大英雄何竟死亡！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彌迦書 1:10; 撒母耳記上 18:6; 士師記 11:34"> <span className="pl pl-1">不要在迦特報告，</span><br /><span className="pl pl-1">不要在亞實基倫街上傳揚，</span><br /><span className="pl pl-1">免得非利士的女子歡樂，</span><br /><span className="pl pl-1">免得未受割禮之人的女子矜誇。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 31:1; 以賽亞書 21:5; 撒母耳記上 10:1"> <span className="pl pl-1">基利波山哪，願你那裡沒有雨露，</span><br /><span className="pl pl-1">願你田地無土產可做供物！</span><br /><span className="pl pl-1">因為英雄的盾牌在那裡被汙丟棄，</span><br /><span className="pl pl-1">掃羅的盾牌彷彿未曾抹油。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 18:4; 以賽亞書 34:6–7; 撒母耳記上 14:6–14"> <span className="pl pl-1">約拿單的弓箭非流敵人的血不退縮，</span><br /><span className="pl pl-1">掃羅的刀劍非剖勇士的油不收回。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 4:13; 士師記 14:18; 耶利米哀歌 4:19"> <span className="pl pl-1">掃羅和約拿單，</span><br /><span className="pl pl-1">活時相悅相愛，死時也不分離；</span><br /><span className="pl pl-1">他們比鷹更快，比獅子還強。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 3:3–5; 耶利米書 2:32; 士師記 5:30"> <span className="pl pl-1">以色列的女子啊，當為掃羅哭號！</span><br /><span className="pl pl-1">他曾使你們穿朱紅色的美衣，</span><br /><span className="pl pl-1">使你們衣服有黃金的裝飾。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 1:19; 撒母耳記下 1:27; 士師記 5:18"> <span className="pl pl-1">英雄何竟在陣上仆倒，</span><br /><span className="pl pl-1">約拿單何竟在山上被殺！</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 20:17; 撒母耳記上 23:16; 撒母耳記上 20:41"> <span className="pl pl-1">我兄約拿單哪，我為你悲傷！</span><br /><span className="pl pl-1">我甚喜悅你，</span><br /><span className="pl pl-1">你向我發的愛情奇妙非常，</span><br /><span className="pl pl-1">過於婦女的愛情。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 1:25; 撒母耳記下 1:19; 以西結書 39:9–10"> <span className="pl pl-1">英雄何竟仆倒！</span><br /><span className="pl pl-1">戰具何竟滅沒！」</span></span>
</div>

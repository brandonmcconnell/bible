## 大衛受膏做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 30:31; 撒母耳記上 23:4; 創世記 32:2"> 此後，大衛問耶和華說：「我上猶大的一個城去可以嗎？」耶和華說：「可以。」大衛說：「我上哪一個城去呢？」耶和華說：「上希伯崙去。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 25:42–43; 撒母耳記上 30:5; 路加福音 22:28–29"> 於是大衛和他的兩個妻，一個是耶斯列人亞希暖，一個是做過迦密人拿八妻的亞比該，都上那裡去了。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 30:1; 歷代志上 12:1–7; 撒母耳記上 27:2–3"> 大衛也將跟隨他的人和他們各人的眷屬一同帶上去，住在希伯崙的城邑中。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 5:5; 撒母耳記上 31:11–13; 撒母耳記下 5:3"> 猶大人來到希伯崙，在那裡膏大衛做猶大家的王。<br />有人告訴大衛說，葬埋掃羅的是基列雅比人。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 23:21; 詩篇 115:15; 路得記 2:20"> 大衛就差人去見基列雅比人，對他們說：「你們厚待你們的主掃羅，將他葬埋，願耶和華賜福於你們。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及記 34:6; 馬太福音 5:44"> 你們既行了這事，願耶和華以慈愛、誠實待你們，我也要為此厚待你們。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 6:10; 撒母耳記下 10:12; 創世記 15:1"> 現在你們的主掃羅死了，猶大家已經膏我做他們的王，所以你們要剛強奮勇。」</span>
</div>
</div>

## 伊施波設做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 14:50; 創世記 32:2; 撒母耳記下 3:7–8"> 掃羅的元帥，尼珥的兒子押尼珥，曾將掃羅的兒子伊施波設帶過河，到瑪哈念，</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 19:18; 約書亞記 13:8–11; 民數記 1:40"> 立他做王，治理基列、亞書利、耶斯列、以法蓮、便雅憫和以色列眾人。</span>
<span className="v" id="v10" data-v="10"> 掃羅的兒子伊施波設登基的時候年四十歲，做以色列王二年。唯獨猶大家歸從大衛。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 2:11; 撒母耳記下 5:4–5; 歷代志上 3:4"> 大衛在希伯崙做猶大家的王，共七年零六個月。</span>
</div>
</div>

## 押尼珥與以色列人敗遁

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:25; 約書亞記 10:2; 約書亞記 9:3"> 尼珥的兒子押尼珥和掃羅的兒子伊施波設的僕人從瑪哈念出來，往基遍去。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 8:16; 歷代志上 2:16; 撒母耳記下 20:23"> 洗魯雅的兒子約押和大衛的僕人也出來，在基遍池旁與他們相遇。一班坐在池這邊，一班坐在池那邊。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥對約押說：「讓少年人起來，在我們面前戲耍吧！」約押說：「可以。」</span>
<span className="v" id="v15" data-v="15"> 就按著定數起來，屬掃羅兒子伊施波設的便雅憫人過去十二名，大衛的僕人也過去十二名，</span>
<span className="v" id="v16" data-v="16"> 彼此揪頭，用刀刺肋，一同仆倒。所以，那地叫做希利甲哈素林，就在基遍。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:1"> 那日的戰事凶猛，押尼珥和以色列人敗在大衛的僕人面前。</span>
</div>
</div>

## 亞撒黑追趕押尼珥被殺

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志上 12:8; 哈巴谷書 3:19; 雅歌 8:14"> 在那裡有洗魯雅的三個兒子約押、亞比篩、亞撒黑，亞撒黑腳快如野鹿一般。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 2:21; 約書亞記 1:7; 箴言 4:27"> 亞撒黑追趕押尼珥，直追趕他不偏左右。</span>
<span className="v" id="v20" data-v="20"> 押尼珥回頭說：「你是亞撒黑嗎？」回答說：「是。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 14:19"> 押尼珥對他說：「你或轉向左轉向右，拿住一個少年人，剝去他的戰衣。」亞撒黑卻不肯轉開不追趕他。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 3:27; 箴言 29:1; 列王紀下 14:10–12"> 押尼珥又對亞撒黑說：「你轉開不追趕我吧！我何必殺你呢？若殺你，有什麼臉見你哥哥約押呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 3:27; 撒母耳記下 4:6; 撒母耳記下 5:6"> 亞撒黑仍不肯轉開，故此押尼珥就用槍鐏刺入他的肚腹，甚至槍從背後透出。亞撒黑就在那裡仆倒而死。眾人趕到亞撒黑仆倒而死的地方，就都站住。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 約押和亞比篩追趕押尼珥，日落的時候，到了通基遍曠野的路旁，基亞對面的亞瑪山。</span>
<span className="v" id="v25" data-v="25"> 便雅憫人聚集，跟隨押尼珥站在一個山頂上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 46:14; 耶利米書 46:10; 使徒行傳 7:26"> 押尼珥呼叫約押說：「刀劍豈可永遠殺人嗎？你豈不知終久必有苦楚嗎？你要等何時才叫百姓回去，不追趕弟兄呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳記下 2:14; 箴言 15:1"> 約押說：「我指著永生的神起誓，你若不說戲耍的那句話，今日早晨百姓就回去，不追趕弟兄了。」</span>
<span className="v" id="v28" data-v="28"> 於是約押吹角，眾民就站住，不再追趕以色列人，也不再打仗了。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 2:8; 雅歌 2:17"> 押尼珥和跟隨他的人整夜經過亞拉巴，過約旦河，走過畢倫，到了瑪哈念。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 約押追趕押尼珥回來，聚集眾民，見大衛的僕人中缺少了十九個人和亞撒黑。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:1; 列王紀上 20:11"> 但大衛的僕人殺了便雅憫人和跟隨押尼珥的人，共三百六十名。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 2:13–16; 撒母耳記上 17:58; 歷代志下 21:1"> 眾人將亞撒黑送到伯利恆，葬在他父親的墳墓裡。約押和跟隨他的人走了一夜，天亮的時候到了希伯崙。</span>
</div>
</div>

## 大衛立意為耶和華建殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王紀上 5:4"> 王住在自己宮中，耶和華使他安靖，不被四圍的仇敵擾亂。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 16:1; 撒母耳記下 5:11; 哈該書 1:4"> 那時，王對先知拿單說：「看哪，我住在香柏木的宮中，神的約櫃反在幔子裡！」</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:7; 列王紀上 8:17–18; 列王紀下 4:27"> 拿單對王說：「你可以照你的心意而行，因為耶和華與你同在。」</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 17:3; 民數記 12:6; 阿摩司書 3:7"> 當夜，耶和華的話臨到拿單說：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 23:3–32; 列王紀上 5:3–4; 列王紀上 8:16–19"> 「你去告訴我僕人大衛說：『耶和華如此說：你豈可建造殿宇給我居住呢？</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:16; 約書亞記 18:1; 出埃及記 40:18–19"> 自從我領以色列人出埃及直到今日，我未曾住過殿宇，常在會幕和帳幕中行走。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 17:6; 撒母耳記下 5:2; 利未記 26:11–12"> 凡我同以色列人所走的地方，我何曾向以色列一支派的士師，就是我吩咐牧養我民以色列的，說：「你們為何不給我建造香柏木的殿宇呢？」』</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 78:70–71; 撒母耳記下 6:21; 撒母耳記下 12:7"> 現在你要告訴我僕人大衛說：『萬軍之耶和華如此說：我從羊圈中將你召來，叫你不再跟從羊群，立你做我民以色列的君。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 5:10; 歷代志上 17:8; 撒母耳記上 18:14"> 你無論往哪裡去，我常與你同在，剪除你的一切仇敵。我必使你得大名，好像世上大大有名的人一樣。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 9:15; 歷代志上 17:9; 耶利米書 24:6"> 我必為我民以色列選定一個地方，栽培他們，使他們住自己的地方，不再遷移。凶惡之子也不像從前擾害他們，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 7:27; 撒母耳記下 7:1; 歷代志上 17:10"> 並不像我命士師治理我民以色列的時候一樣。我必使你安靖，不被一切仇敵擾亂。並且我耶和華應許你，必為你建立家室。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 8:20; 使徒行傳 2:30; 使徒行傳 13:36"> 你壽數滿足與你列祖同睡的時候，我必使你的後裔接續你的位，我也必堅定他的國。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王紀上 8:19; 撒母耳記下 7:16"> 他必為我的名建造殿宇，我必堅定他的國位直到永遠。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 1:5; 啟示錄 3:19; 歷代志上 17:13"> 我要做他的父，他要做我的子。他若犯了罪，我必用人的杖責打他，用人的鞭責罰他。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:23; 撒母耳記上 15:28; 詩篇 89:28"> 但我的慈愛仍不離開他，像離開在你面前所廢棄的掃羅一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 詩篇 89:36–37; 撒母耳記下 7:13"> 你的家和你的國必在我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：你。">a</a></sup>面前永遠堅立，你的國位也必堅定直到永遠。』」</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 17:15; 使徒行傳 20:27; 哥林多前書 15:3"> 拿單就按這一切話，照這默示，告訴大衛。</span>
</div>
</div>

## 大衛之祈禱與頌感

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 8:4; 歷代志上 17:16; 撒母耳記上 18:18"> 於是大衛王進去，坐在耶和華面前，說：「主耶和華啊，我是誰，我的家算什麼，你竟使我到這地步呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 55:8–9; 歷代志上 17:17; 詩篇 36:7"> 主耶和華啊，這在你眼中還看為小，又應許你僕人的家至於久遠。主耶和華啊，這豈是人所常遇的事嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 21:17; 撒母耳記上 16:7; 詩篇 139:1"> 主耶和華啊，我還有何言可以對你說呢？因為你知道你的僕人。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 115:1; 詩篇 138:2; 以弗所書 1:9"> 你行這大事使僕人知道，是因你所應許的話，也是照你的心意。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 86:10; 出埃及記 15:11; 詩篇 86:8"> 主耶和華啊，你本為大，照我們耳中聽見，沒有可比你的，除你以外再無神。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:26; 申命記 10:21; 申命記 15:15"> 世上有何民能比你的民以色列呢？你從埃及救贖他們做自己的子民，又在你贖出來的民面前行大而可畏的事，驅逐列邦人和他們的神，顯出你的大名。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 26:18; 彼得前書 2:10; 創世記 17:7"> 你曾堅立你的民以色列做你的子民直到永遠，你耶和華也做了他們的神。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 119:49; 以西結書 36:37; 創世記 32:12"> 耶和華神啊，你所應許僕人和僕人家的話，求你堅定直到永遠，照你所說的而行。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 17:23–24; 詩篇 72:18–19; 馬太福音 6:9"> 願人永遠尊你的名為大，說：『萬軍之耶和華是治理以色列的神！』這樣，你僕人大衛的家必在你面前堅立。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 17:25–26; 詩篇 10:17; 路得記 4:4"> 萬軍之耶和華以色列的神啊，因你啟示你的僕人說『我必為你建立家室』，所以僕人大膽向你如此祈禱。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 17:17; 出埃及記 34:6; 民數記 23:19"> 主耶和華啊，唯有你是神，你的話是真實的，你也應許將這福氣賜給僕人。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 6:24–26; 歷代志上 17:27; 詩篇 115:12–15"> 現在求你賜福於僕人的家，可以永存在你面前。主耶和華啊，這是你所應許的，願你永遠賜福於僕人的家。」</span>
</div>

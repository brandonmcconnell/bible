## 洗巴誑言欺大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 25:18; 撒母耳記下 15:32; 撒母耳記下 9:2–13"> 大衛剛過山頂，見米非波設的僕人洗巴拉著備好了的兩匹驢，驢上馱著二百麵餅，一百葡萄餅，一百個夏天的果餅，一皮袋酒來迎接他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 17:29; 士師記 10:4; 士師記 5:10"> 王問洗巴說：「你帶這些來是什麼意思呢？」洗巴說：「驢是給王的家眷騎的，麵餅和夏天的果餅是給少年人吃的，酒是給在曠野疲乏人喝的。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 9:9–10; 詩篇 15:3; 撒母耳記下 19:24–30"> 王問說：「你主人的兒子在哪裡呢？」洗巴回答王說：「他仍在耶路撒冷，因他說：『以色列人今日必將我父的國歸還我。』」</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 18:13; 箴言 18:17; 箴言 19:2"> 王對洗巴說：「凡屬米非波設的都歸你了。」洗巴說：「我叩拜我主我王，願我在你眼前蒙恩！」</span>
</div>
</div>

## 大衛容忍示每

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 3:16; 撒母耳記上 17:43; 出埃及記 22:28"> 大衛王到了巴戶琳，見有一個人出來，是掃羅族基拉的兒子，名叫示每。他一面走一面咒罵，</span>
<span className="v" id="v6" data-v="6"> 又拿石頭砍大衛王和王的臣僕。眾民和勇士都在王的左右。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 13:13; 撒母耳記上 25:17; 列王紀上 21:10"> 示每咒罵說：「你這流人血的壞人哪，去吧，去吧！</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 1:16; 撒母耳記下 3:28–29; 列王紀上 2:32–33"> 你流掃羅全家的血，接續他做王。耶和華把這罪歸在你身上，將這國交給你兒子押沙龍。現在你自取其禍，因為你是流人血的人！」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 22:28; 撒母耳記下 9:8; 撒母耳記上 24:14"> 洗魯雅的兒子亞比篩對王說：「這死狗豈可咒罵我主我王呢？求你容我過去，割下他的頭來！」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 19:22; 羅馬書 9:20; 約翰福音 18:11"> 王說：「洗魯雅的兒子，我與你們有何關涉呢？他咒罵是因耶和華吩咐他說：『你要咒罵大衛。』如此，誰敢說你為什麼這樣行呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 17:1–4; 創世記 45:5; 撒母耳記下 12:11–12"> 大衛又對亞比篩和眾臣僕說：「我親生的兒子尚且尋索我的性命，何況這便雅憫人呢？由他咒罵吧！因為這是耶和華吩咐他的。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; 希伯來書 12:10; 詩篇 25:18"> 或者耶和華見我遭難，為我今日被這人咒罵，就施恩於我。」</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 23:23; 撒母耳記下 16:5–6"> 於是大衛和跟隨他的人往前行走。示每在大衛對面山坡，一面行走一面咒罵，又拿石頭砍他，拿土揚他。</span>
<span className="v" id="v14" data-v="14"> 王和跟隨他的眾人疲疲乏乏地到了一個地方，就在那裡歇息歇息。</span>
</div>
</div>

## 戶篩詐歸押沙龍

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 15:37; 撒母耳記下 15:12"> 押沙龍和以色列眾人來到耶路撒冷，亞希多弗也與他同來。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 11:12; 撒母耳記上 10:24; 列王紀上 1:25"> 大衛的朋友亞基人戶篩去見押沙龍，對他說：「願王萬歲！願王萬歲！」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 19:25; 撒母耳記下 15:32–37; 申命記 32:6"> 押沙龍問戶篩說：「這是你恩待朋友嗎？為什麼不與你的朋友同去呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:13; 撒母耳記下 5:1–3"> 戶篩對押沙龍說：「不然，耶和華和這民並以色列眾人所揀選的，我必歸順他，與他同住。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 15:34; 詩篇 55:21; 撒母耳記上 28:2"> 再者，我當服侍誰呢？豈不是前王的兒子嗎？我怎樣服侍你父親，也必照樣服侍你。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:10; 詩篇 37:12–13; 以賽亞書 29:15"> 押沙龍對亞希多弗說：「你們出個主意，我們怎樣行才好。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 20:3; 撒母耳記下 15:16; 撒迦利亞書 8:13"> 亞希多弗對押沙龍說：「你父所留下看守宮殿的妃嬪，你可以與她們親近。以色列眾人聽見你父親憎惡你，凡歸順你人的手就更堅強。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 12:11–12; 撒母耳記下 15:16; 撒母耳記下 20:3"> 於是人為押沙龍在宮殿的平頂上支搭帳篷。押沙龍在以色列眾人眼前，與他父的妃嬪親近。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 15:12; 撒母耳記下 17:14; 撒母耳記下 17:23"> 那時，亞希多弗所出的主意好像人問神的話一樣。他昔日給大衛，今日給押沙龍所出的主意，都是這樣。</span>
</div>
</div>

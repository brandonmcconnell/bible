## 門徒當以試煉為喜樂

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 12:15; 彼得前書 1:1; 約翰福音 7:35"> 做神和主耶穌基督僕人的雅各，請散住十二個支派之人的安！</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前書 1:6–8; 雅各書 1:12; 哥林多後書 12:9–10"> 我的弟兄們，你們落在百般試煉中，都要以為大喜樂，</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 5:3–4; 希伯來書 10:36; 歌羅西書 1:11"> 因為知道，你們的信心經過試驗就生忍耐。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前書 5:10; 馬太福音 5:48"> 但忍耐也當成功，使你們成全、完備，毫無缺欠。</span>
</div>
</div>

## 要憑著信心求

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 約翰福音 15:7; 箴言 3:5–7"> 你們中間若有缺少智慧的，應當求那厚賜於眾人也不斥責人的神，主就必賜給他。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:21–22; 希伯來書 11:6; 馬可福音 11:22–24"> 只要憑著信心求，一點不疑惑；因為那疑惑的人就像海中的波浪，被風吹動翻騰。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 4:3; 以賽亞書 58:3–4; 箴言 21:27"> 這樣的人不要想從主那裡得什麼，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 18:21; 馬太福音 6:24; 雅各書 4:8"> 心懷二意的人在他一切所行的路上都沒有定見。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 9:23–24; 雅各書 2:5–6; 箴言 19:1"> 卑微的弟兄升高，就該喜樂；</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 1:24; 約翰一書 2:17; 約伯記 14:2"> 富足的降卑也該如此，因為他必要過去，如同草上的花一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 40:7–8; 詩篇 37:35–36; 詩篇 49:6–14"> 太陽出來，熱風颳起，草就枯乾，花也凋謝，美容就消沒了；那富足的人在他所行的事上，也要這樣衰殘。</span>
</div>
</div>

## 忍受試探的人是有福的

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:10; 彼得前書 1:6–8; 啟示錄 2:10"> 忍受試探的人是有福的！因為他經過試驗以後，必得生命的冠冕，這是主應許給那些愛他之人的。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 2:12–13; 雅各書 1:12; 羅馬書 9:19–20"> 人被試探，不可說「我是被神試探」，因為神不能被惡試探，他也不試探人。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 7:21–22; 以弗所書 4:22; 馬太福音 15:18"> 但各人被試探，乃是被自己的私慾牽引、誘惑的。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14; 約伯記 15:35; 羅馬書 5:12–21"> 私慾既懷了胎，就生出罪來；罪既長成，就生出死來。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 6:7; 雅各書 1:19; 腓立比書 2:12"> 我親愛的弟兄們，不要看錯了。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 3:27; 馬太福音 7:11; 希伯來書 13:8"> 各樣美善的恩賜和各樣全備的賞賜都是從上頭來的，從眾光之父那裡降下來的，在他並沒有改變，也沒有轉動的影兒。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:29–31; 彼得前書 1:23; 約翰福音 3:3–5"> 他按自己的旨意，用真道生了我們，叫我們在他所造的萬物中好像初熟的果子。</span>
</div>
</div>

## 要行道不要單聽道

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 我親愛的弟兄們，這是你們所知道的，但你們各人要快快地聽，慢慢地說，慢慢地動怒，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 2:24–25; 以弗所書 4:26; 雅各書 3:17–18"> 因為人的怒氣並不成就神的義。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 4:22; 以弗所書 1:13; 彼得前書 2:11"> 所以，你們要脫去一切的汙穢和盈餘的邪惡，存溫柔的心領受那所栽種的道，就是能救你們靈魂的道。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 2:13; 路加福音 6:46–48; 約翰福音 13:17"> 只是你們要行道，不要單單聽道，自己欺哄自己。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 7:26–27; 以西結書 33:31–32; 雅各書 2:14–26"> 因為聽道而不行道的，就像人對著鏡子看自己本來的面目，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得後書 3:11; 路加福音 1:66; 路加福音 7:39"> 看見，走後，隨即忘了他的相貌如何。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 約翰福音 13:17; 哥林多後書 3:17–18"> 唯有詳細察看那全備、使人自由之律法的，並且時常如此，這人既不是聽了就忘，乃是實在行出來，就在他所行的事上必然得福。</span>
</div>
</div>

## 何為真實的虔誠

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所書 4:29; 詩篇 141:3; 彼得前書 3:10"> 若有人自以為虔誠，卻不勒住他的舌頭，反欺哄自己的心，這人的虔誠是虛的。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 1:16–17; 約翰一書 3:17–19; 加拉太書 6:9–10"> 在神我們的父面前，那清潔沒有玷汙的虔誠就是看顧在患難中的孤兒寡婦，並且保守自己不沾染世俗。</span>
</div>
</div>

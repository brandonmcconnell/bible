## 當為真道竭力爭辯

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 6:12; 腓立比書 1:27; 猶大書 1:20"> 親愛的弟兄啊，我想盡心寫信給你們，論我們同得救恩的時候，就不得不寫信勸你們，要為從前一次交付聖徒的真道竭力地爭辯。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得後書 2:1–3; 加拉太書 2:4; 彼得後書 2:10"> 因為有些人偷著進來，就是自古被定受刑罰的，是不虔誠的，將我們神的恩變做放縱情慾的機會，並且不認獨一的主宰——我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我們」或作「和我們」。">a</a></sup>主耶穌基督。</span>
</div>
</div>

## 以古時不虔誠的為鑒戒

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 26:64–65; 希伯來書 3:16–2; 哥林多前書 10:1–12"> 從前主救了他的百姓出埃及地，後來就把那些不信的滅絕了。這一切的事你們雖然都知道，我卻仍要提醒你們。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得後書 2:4; 馬太福音 25:41; 以弗所書 6:12"> 又有不守本位、離開自己住處的天使，主用鎖鏈把他們永遠拘留在黑暗裡，等候大日的審判。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 29:23; 彼得後書 2:6; 羅馬書 1:26–27"> 又如所多瑪、蛾摩拉和周圍城邑的人，也照他們一味地行淫，隨從逆性的情慾，就受永火的刑罰，作為鑒戒。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 13:17; 彼得前書 2:17; 彼得後書 2:10–12"> 這些做夢的人也像他們汙穢身體，輕慢主治的，毀謗在尊位的。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 3:2; 彼得後書 2:11; 申命記 34:6"> 天使長米迦勒為摩西的屍首與魔鬼爭辯的時候，尚且不敢用毀謗的話罪責他，只說：「主責備你吧！」</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 2:12; 羅馬書 1:21–22"> 但這些人毀謗他們所不知道的。他們本性所知道的事與那沒有靈性的畜類一樣，在這事上竟敗壞了自己。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 2:15; 約翰一書 3:12; 啟示錄 2:14"> 他們有禍了！因為走了該隱的道路，又為利往巴蘭的錯謬裡直奔，並在可拉的背叛中滅亡了。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得後書 2:17–20; 馬太福音 15:13; 以西結書 34:8"> 這樣的人在你們的愛席上與你們同吃的時候，正是礁石<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：玷汙。">b</a></sup>；他們做牧人，只知餵養自己，無所懼怕；是沒有雨的雲彩，被風飄蕩；是秋天沒有果子的樹，死而又死，連根被拔出來；</span>
<span className="v" id="v13" data-v="13" data-xref="彼得後書 2:17; 腓立比書 3:19; 以賽亞書 57:20"> 是海裡的狂浪，湧出自己可恥的沫子來；是流蕩的星，有墨黑的幽暗為他們永遠存留。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:2; 詩篇 50:3–5; 希伯來書 11:5–6"> 亞當的七世孫以諾曾預言這些人說：「看哪，主帶著他的千萬聖者降臨，</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 2:16; 傳道書 11:9; 哥林多前書 4:5"> 要在眾人身上行審判，證實那一切不敬虔的人所妄行一切不敬虔的事，又證實不敬虔之罪人所說頂撞他的剛愎話。」</span>
<span className="v" id="v16" data-v="16" data-xref="彼得後書 2:18; 彼得後書 2:10; 腓立比書 2:14"> 這些人是私下議論，常發怨言的，隨從自己的情慾而行，口中說誇大的話，為得便宜諂媚人。</span>
</div>
</div>

## 要常在神的愛中

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得後書 3:2; 約翰一書 4:6; 以弗所書 4:11"> 親愛的弟兄啊，你們要記念我們主耶穌基督之使徒從前所說的話。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得後書 3:3; 提摩太後書 4:3; 提摩太後書 3:1–5"> 他們曾對你們說過：末世必有好譏誚的人隨從自己不敬虔的私慾而行。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 2:14; 箴言 18:1; 羅馬書 8:9"> 這就是那些引人結黨、屬乎血氣、沒有聖靈的人。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:18; 羅馬書 8:26–27; 哥林多前書 14:15"> 親愛的弟兄啊，你們卻要在至聖的真道上造就自己，在聖靈裡禱告，</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 4:16; 耶利米哀歌 3:25–26; 希伯來書 9:28"> 保守自己常在神的愛中，仰望我們主耶穌基督的憐憫，直到永生。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 5:19–20; 加拉太書 6:1; 約翰一書 5:16–18"> 有些人存疑心，你們要憐憫他們；</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 4:16; 哥林多前書 15:33; 啟示錄 3:4"> 有些人你們要從火中搶出來，搭救他們；有些人你們要存懼怕的心憐憫他們，連那被情慾沾染的衣服也當厭惡。</span>
</div>
</div>

## 祝福

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:18; 以弗所書 3:20; 歌羅西書 1:22"> 那能保守你們不失腳，叫你們無瑕無疵、歡歡喜喜站在他榮耀之前的我們的救主獨一的神，</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前書 1:17; 啟示錄 5:13–14; 彼得前書 5:10–11"> 願榮耀、威嚴、能力、權柄因我們的主耶穌基督歸於他，從萬古以前並現今，直到永永遠遠！阿們。</span>
</div>

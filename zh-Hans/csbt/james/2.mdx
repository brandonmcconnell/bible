<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各書 2:9; 利未記 19:15"> 我的弟兄們，你們應當持守對我們榮耀的主耶穌基督的信仰，不要懷著偏待人的心。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖記 3:10; 以斯帖記 8:2"> 如果有一個戴著金戒指、穿著華麗衣服的人進了你們的會堂，又有一個穿著骯髒衣服的窮人也進來了，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:9; 雅各書 2:6; 路加福音 7:44–46"> 你們卻看重那穿華麗衣服的人，對他說「請你坐在這好位子上」，而對那窮人說「你站在那裡」，或說「坐在我的腳凳下邊」；</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 7:24; 約伯記 34:19; 馬太福音 7:1–5"> 難道你們中間不就有了歧視，而你們也成了心懷惡念的審判官嗎？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 5:3; 路加福音 6:20; 啟示錄 2:9"> 我親愛的弟兄們，請聽！神難道不是揀選了世上的那些貧窮人，使他們在信仰上富有，並且做他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——輔助詞語。">a</a></sup>國度的繼承人嗎？這國度是他應許給愛他之人的。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前書 11:22; 箴言 14:31"> 但你們卻侮辱了這貧窮人！那欺壓你們、把你們拉上法庭的，難道不是那些富有的人嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:9–11; 啟示錄 13:5–6; 提摩太前書 1:13"> 那褻瀆你們所敬奉的美好之名的，難道不是他們嗎？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 19:18; 加拉太書 5:14; 馬太福音 22:39"> 不過，你們如果照著經上那條至尊的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="至尊的——或譯作「王的」。">b</a></sup>律法「要愛鄰如己」完全實行，你們就做得很好了。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 19:15; 雅各書 2:1–4; 約翰一書 3:4"> 但如果你們偏待人，就是犯罪，並被律法指證是違犯律法的人。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 3:10; 馬太福音 5:18–19; 申命記 27:26"> 因為那遵守整個律法的人，只在一條上跌倒，就成了干犯所有律法的了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:13–14; 馬太福音 5:21–28; 申命記 5:17–18"> 原來那位說過「不可通姦」的，也說過「不可殺人」。你即使不通姦，卻殺人，你還是成了違犯律法的人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="雅各書 1:25; 雅各書 2:8; 彼得後書 1:4–8"> 既然你們將要照著那使人得自由的律法受審判，就應當照此說話、行事。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:7; 馬太福音 6:15; 箴言 21:13"> 要知道，那不施憐憫的人，要受毫無憐憫的審判；憐憫勝過審判。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 7:26–27; 馬太福音 7:21–23; 雅各書 1:22–25"> 我的弟兄們，如果有人說自己有信仰，但卻沒有行為，這有什麼好處呢？難道這種信仰能救他嗎？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 馬太福音 25:35–40; 以賽亞書 58:7"> 如果有弟兄或姐妹衣不蔽體，又缺乏日用的食物，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 約翰一書 3:16–18; 馬太福音 25:42–45"> 而你們當中有人對他們說：「平平安安地去吧！願你們穿得暖、吃得飽！」，卻不給他們身體所需要的，這有什麼好處呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 2:26; 彼得後書 1:5–9; 雅各書 2:19–20"> 信仰也是這樣：如果沒有行為，這信仰就是死的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各書 3:13; 雅各書 2:14; 加拉太書 5:6"> 不過有人會說：「你有信仰；我有行為。」請給我看看你沒有行為的信仰，我也本於自己的行為給你看看我的信仰。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 馬可福音 1:24; 馬太福音 8:29"> 你相信神只有一位，你就做得很好！連鬼魔也相信，並且恐懼戰兢。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各書 2:17; 雅各書 2:26; 箴言 12:11"> 唉，你這虛空的人哪！你想知道沒有行為的信仰是無用的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="無用的——有古抄本作「死的」。">c</a></sup>嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 22:16–18; 創世記 22:9–12; 約翰福音 8:39"> 我們的先祖亞伯拉罕把他的兒子以撒獻在祭壇上，難道不是本於行為被稱為義嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 1:3; 希伯來書 11:17–19; 加拉太書 5:6"> 你看，信仰和他的行為相輔相成，而且信仰是本於行為得以完全的。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:6; 以賽亞書 41:8; 歷代志下 20:7"> 這就應驗了經上所說的：「亞伯拉罕信神，這就被算為他的義。」他又被稱為「神的朋友」。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 2:21–22; 雅各書 2:15–18; 詩篇 60:12"> 可見人被稱為義是本於行為，不僅是本於信仰。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 11:31; 約書亞記 6:22–25; 約書亞記 2:19–21"> 同樣，妓女拉合接待了那些使者，又從另一條路把他們送走，難道不也是本於行為被稱為義嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 2:20; 雅各書 2:17; 雅各書 2:14"> 要知道，就像身體沒有靈魂是死的，照樣，信仰沒有行為也是死的。</span>
</div>
</div>

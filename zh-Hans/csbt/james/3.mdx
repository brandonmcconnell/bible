<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前書 1:7; 彼得前書 5:3"> 我的弟兄們，你們不應該有很多人做教師，因為你們知道，我們做教師的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="做教師的——輔助詞語。">a</a></sup>將受更嚴厲的審判。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:26; 箴言 13:3; 彼得前書 3:10"> 實際上，我們每一個人在很多事上都會跌倒。如果有人在言語上不跌倒，這個人就是一個成熟的人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="成熟的人——或譯作「完全的人」。">b</a></sup>，也能夠克制全身。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="詩篇 32:9; 詩篇 39:1; 雅各書 1:26"> 我們如果<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我們如果——有古抄本作「看，我們」。">c</a></sup>把嚼子放在馬嘴裡，使牠們服從<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使牠們服從——原文直譯「使牠們服從我們」。">d</a></sup>，就可以駕馭牠們的全身。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 107:25–27; 馬太福音 8:24; 使徒行傳 27:14–38"> 再看船隻，雖然它那麼大，又被狂風吹逐，但是無論舵手的意圖想去哪裡，它都能被小小的舵來駕馭。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米書 9:3–8; 箴言 12:18"> 照樣，舌頭雖然是身體上一個小小的部分，卻能大大地自誇。看哪，那麼小的火，能點燃那麼大的森林！</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 120:2–3; 箴言 16:27; 馬可福音 7:15"> 舌頭是火，它在我們身體的各部分中，是個不公義的世界；它玷汙全身，焚燒人生的路程，而且自己卻被地獄焚燒。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬可福音 5:4"> 原來，各類野獸、飛禽、爬行動物和水族都能被制伏，也已經被人類制伏了，</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:13; 詩篇 140:3; 詩篇 55:21"> 可是沒有人能制伏舌頭；它是不止息的邪惡，充滿著致死的毒。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 10:7; 創世記 1:26–27; 詩篇 62:4"> 我們用這舌頭頌讚我們的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="我們的——輔助詞語。">e</a></sup>主<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="主——有古抄本作「神」。">f</a></sup>——我們的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="我們的——輔助詞語。">g</a></sup>父，又用這舌頭來詛咒照著神的形像被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:14; 彼得前書 3:9; 哥林多前書 3:3"> 頌讚和詛咒從同一張嘴裡出來！我的弟兄們，這些事不應該如此！</span>
<span className="v" id="v11" data-v="11"> 難道從同一個洞裡湧出來的泉源，能又甜又苦嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 馬太福音 12:33; 馬太福音 7:16–20"> 我的弟兄們，難道無花果樹能結出橄欖，葡萄樹能結出無花果嗎？鹹水也不能產生甜水<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="鹹水也不能產生甜水——有古抄本作「照樣，沒有泉源能產生鹹水又產生甜水」。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 5:23; 雅各書 3:17; 馬太福音 5:5"> 到底你們中間誰是有智慧、有見識的呢？他就應當藉著良好的品行，以智慧的溫柔，使自己的行為顯明出來；</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 3:16; 哥林多前書 13:4; 腓立比書 2:3"> 但如果你們心裡懷著苦毒的嫉妒和爭競<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="爭競——或譯作「結黨」。">i</a></sup>，就不要自誇、說謊而抵擋真理。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:17; 雅各書 1:17; 哥林多前書 3:19"> 這種智慧不是從上面下來的，而是屬地的，屬血氣的，屬鬼魔的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 3:14; 哥林多前書 3:3; 哥林多前書 14:33"> 要知道，哪裡有嫉妒和爭競<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="爭競——或譯作「結黨」。">j</a></sup>，哪裡就有混亂和各樣的惡事。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 5:22–23; 箴言 2:6; 哥林多前書 13:4–7"> 至於從上面來的智慧，首先是純潔的，然後是和平的、謙和的、溫順的，滿有憐憫和美好的果子的，是不偏私、不虛假的；</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 5:9; 何西阿書 10:12; 腓立比書 1:11"> 並且義行的果子，是由那些締造和平的人，在和平中種下的。</span>
</div>

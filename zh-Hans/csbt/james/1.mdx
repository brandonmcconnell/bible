<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 12:15; 彼得前書 1:1; 約翰福音 7:35"> 神和主耶穌基督的奴僕雅各，<br />問候散居在各地的十二個支派。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前書 1:6–8; 雅各書 1:12; 哥林多後書 12:9–10"> 我的弟兄們，你們遇到各種試煉的時候，應當看做是極大的喜樂，</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 5:3–4; 希伯來書 10:36; 歌羅西書 1:11"> 因為你們知道，你們的信仰經過考驗就生出忍耐；</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前書 5:10; 馬太福音 5:48"> 但要讓忍耐發揮完全的功效，好使你們成熟、完備，在任何事上都沒有缺欠。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 約翰福音 15:7; 箴言 3:5–7"> 如果你們中間有人缺乏智慧，他就應當向那慷慨賜予萬人又不責罵人的神祈求；神就會賜予他。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:21–22; 希伯來書 11:6; 馬可福音 11:22–24"> 不過他要憑著信仰祈求，不要有任何疑惑，因為疑惑的人就像海中的波浪，被風吹動翻騰。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 4:3; 以賽亞書 58:3–4; 箴言 21:27"> 這樣的人不要想從主那裡得到什麼，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 18:21; 馬太福音 6:24; 雅各書 4:8"> 他是心懷二意的人，在他所有的道路上都搖擺不定。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 9:23–24; 雅各書 2:5–6; 箴言 19:1"> 卑微<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="卑微——或譯作「謙卑」。">a</a></sup>的弟兄應當以自己被高舉而誇耀；</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 1:24; 約翰一書 2:17; 約伯記 14:2"> 富有的應當以自己被降卑而誇耀，因為他將要像草上的花那樣消逝。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 40:7–8; 詩篇 37:35–36; 詩篇 49:6–14"> 太陽帶著熱氣升起，草地枯萎，草上的花也凋謝，它表面的美麗也就消逝了；照樣，富有的人在他的追求中，也將衰殘。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:10; 彼得前書 1:6–8; 啟示錄 2:10"> 忍受試煉的人是蒙福的；因為他經過考驗以後，就要得到生命的冠冕，就是主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="主——有古抄本作「他」。">b</a></sup>應許給那些愛他之人的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 2:12–13; 雅各書 1:12; 羅馬書 9:19–20"> 人受誘惑的時候，不可說：「我被神誘惑」，因為神是不能被邪惡誘惑的，神也不誘惑任何人。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 7:21–22; 以弗所書 4:22; 馬太福音 15:18"> 而每個人受誘惑，都是被自己的欲望所牽扯、所引誘的；</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14; 約伯記 15:35; 羅馬書 5:12–21"> 一旦欲望懷了胎，就生下罪來；罪長成了，就生出死亡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太書 6:7; 雅各書 1:19; 腓立比書 2:12"> 我親愛的弟兄們，你們不要被迷惑了！</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 3:27; 馬太福音 7:11; 希伯來書 13:8"> 一切美好的賞賜和各樣完美的恩賜，都是從上面、從眾光之父降下來的；在他沒有改變，也沒有轉動的影子。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:29–31; 彼得前書 1:23; 約翰福音 3:3–5"> 他照著自己的旨意，藉著真理的話語生了我們，要使我們在他所造的萬物中成為一種初熟的果子。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 我親愛的弟兄們，你們應當知道：<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你們應當知道：——有古抄本作「因此，」。">c</a></sup>每個人都該快快地聽，不急於發言、不急於動怒，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 2:24–25; 以弗所書 4:26; 雅各書 3:17–18"> 因為人的憤怒不能成就神的義。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 4:22; 以弗所書 1:13; 彼得前書 2:11"> 因此，你們要脫去一切的汙穢和滿盈的惡毒，要以溫柔的心接受那栽種在你們裡面的話語，就是能拯救你們靈魂<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="靈魂——或譯作「生命」。">d</a></sup>的話語。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="羅馬書 2:13; 路加福音 6:46–48; 約翰福音 13:17"> 你們要成為這話語的實行者，不要只成為聽者而欺騙自己。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 7:26–27; 以西結書 33:31–32; 雅各書 2:14–26"> 因為，如果有人是這話語的聽者，而不是實行者，這個人就像人對著鏡子觀看自己生來的面貌，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得後書 3:11; 路加福音 1:66; 路加福音 7:39"> 看了就走開，立刻忘了自己是什麼樣子；</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 約翰福音 13:17; 哥林多後書 3:17–18"> 但是詳細察看那使人得自由的完美律法，並且繼續持守的人，因他不是健忘的聽者，而是行為的實行者，這個人就將要在他所行的事上蒙祝福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所書 4:29; 詩篇 141:3; 彼得前書 3:10"> 如果<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「你們中間」。">e</a></sup>有人自以為是虔誠的，卻不克制自己的舌頭，反而欺騙自己的心，這個人的虔誠<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="虔誠——或譯作「宗教」。">f</a></sup>就是虛妄的。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 1:16–17; 約翰一書 3:17–19; 加拉太書 6:9–10"> 在父神看來，純潔而沒有玷汙的虔誠<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="虔誠——或譯作「宗教」。">g</a></sup>是這樣的：照顧患難中的孤兒寡婦，並且保守自己不受世界的玷汙。</span>
</div>
</div>

</div>

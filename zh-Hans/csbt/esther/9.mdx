<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="EST" data-book-slug="esther" data-book-name="以斯帖記" data-chapter="9" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 3:13; 以斯帖記 8:12; 詩篇 30:11"> 十二月（亞達月）十三日，王令和他的法令要執行的那一天，就是猶太人的仇敵期待轄制他們的日子，卻成為猶太人轄制那些恨他們之人的日子。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 8:17; 以斯帖記 8:11; 詩篇 71:13"> 猶太人在亞哈隨魯王各省的城市中聚集起來，下手對付那些要謀害他們的人。沒有人能在他們面前站立得住，因為各民族都懼怕他們。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 8:36; 以斯帖記 8:5; 但以理書 6:1–2"> 各省所有的首領，以及行政官、省長和辦理王事務的人，都支持猶太人，因為他們懼怕末迪凱。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 3:1; 歷代志上 11:9; 撒母耳記上 2:30"> 末迪凱在王宮裡為大，他的名聲傳遍各省；末迪凱這人日漸強大。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:34–40; 詩篇 20:7–8; 詩篇 149:6–9"> 猶太人用刀劍擊殺了他們一切的仇敵，殺戮毀滅，任意對待那些恨他們的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 3:15"> 猶太人在蘇薩城堡中擊殺、消滅了五百人。</span>
<span className="v" id="v7" data-v="7"> 他們也擊殺了巴珊達他、達樂分、阿斯帕他、</span>
<span className="v" id="v8" data-v="8"> 坡拉地、阿達利雅、阿利達他、</span>
<span className="v" id="v9" data-v="9"> 帕瑪示他、阿利賽、阿利代、瓦業撒他，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 5:11; 以斯帖記 8:11; 創世記 14:23"> 就是哈米達他的兒子猶太人的敵人哈曼的十個兒子，但沒有下手掠奪財物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 當天在蘇薩城堡中被擊殺的人數，呈到王的面前。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖記 7:2; 以斯帖記 5:6"> 王對王后以斯帖說：「猶太人在蘇薩城堡中擊殺、消滅了五百人，又殺了哈曼的十個兒子；他們在王的其餘各省中，又做了什麼呢？現在無論你請求什麼，都會賜予你；無論你還求什麼，也會被成全。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯帖記 8:11; 申命記 21:23; 以斯帖記 9:15"> 以斯帖就說：「如果王認為好，就請王允許蘇薩的猶太人明天也照著今天的法令去做，並且把哈曼的十個兒子掛在木架上。」</span>
<span className="v" id="v14" data-v="14"> 王就下令這樣做了。於是這法令在蘇薩頒布，人們把哈曼的十個兒子掛了起來。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖記 8:11; 以斯帖記 9:10; 以斯帖記 9:16"> 亞達月十四日，蘇薩的猶太人又聚集起來，在蘇薩擊殺了三百人，但沒有下手掠奪財物。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以斯帖記 8:11; 以斯帖記 9:2; 利未記 26:7–8"> 至於王各省中的其餘猶太人，他們也都聚集起來，保護自己的性命，擺脫他們的仇敵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="擺脫他們的仇敵——原文直譯「從他們的仇敵得到解脫」。">a</a></sup>，擊殺了七萬五千個恨他們的人，但沒有下手掠奪財物；</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖記 9:21; 以斯帖記 9:1; 以斯帖記 8:9"> 這是亞達月十三日的事，而在十四日，他們得享安寧，並且守這日為宴席和喜樂的日子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯帖記 9:21; 以斯帖記 9:1; 以斯帖記 9:15"> 不過，蘇薩的猶太人在十三日和十四日聚集殺敵<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="殺敵——輔助詞語。">b</a></sup>，而在十五日得享安寧，並且守這日為宴席和喜樂的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 8:17; 啟示錄 11:10; 尼希米記 8:10–12"> 因這緣故，住在鄉下村鎮的猶太人，守亞達月十四日為喜樂、宴席、慶祝的日子，彼此送食物。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 31:19–22; 哥林多後書 1:10–11; 詩篇 145:4–12"> 末迪凱記下了這些事，並且把詔書傳送給亞哈隨魯王各省遠近所有的猶太人，</span>
<span className="v" id="v21" data-v="21"> 吩咐他們：每年都要守亞達月十四日和十五日，</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 30:11; 以賽亞書 14:3; 以斯帖記 9:19"> 因為本月的這兩日，是猶太人擺脫他們的仇敵<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="擺脫他們的仇敵——原文直譯「從他們的仇敵得到解脫」。">c</a></sup>，從悲哀轉為喜樂、從哀慟轉為慶祝的日子；他們要守這兩日為宴席和喜樂的日子，彼此送食物，也送禮物給窮人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 於是，猶太人承諾要守他們已經開始守的，也承諾要遵守<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="遵守——輔助詞語。">d</a></sup>末迪凱寫給他們的。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖記 3:5–13; 以斯帖記 9:10"> 事實上，亞甲人哈米達他的兒子哈曼——全體猶太人的敵人，謀劃對付猶太人，要消滅他們；他抽了普珥，就是抽籤，為要攪亂他們、消滅他們。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 7:16; 詩篇 140:9; 詩篇 141:10"> 然而，這事呈到了王的面前，王就用詔書下令，使哈曼的計策，就是他針對猶太人所謀劃的惡事歸到他自己頭上，王又讓人把他和他的兒子們掛在木架上。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯帖記 9:20; 民數記 16:40; 以西結書 39:11"> 因這緣故，猶太人就以普珥的名字，稱呼這兩日為「普珥」；因這書信中的一切話，又因他們在這事上所看到的，以及在他們身上所發生的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 2:11; 以賽亞書 56:6; 以斯帖記 8:17"> 猶太人就為自己和自己的後裔，以及所有歸附於他們的人，確立並承諾如下：每年都一定照著文書、照著所定的日期守這兩日；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 13:8–9; 約書亞記 4:7; 詩篇 103:2"> 各省各城、家家戶戶、世世代代都記念並守這兩日，使這些普珥日在猶太人當中絕不廢去，使這些事在他們的後裔當中絕不被遺忘。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以斯帖記 9:20; 以斯帖記 2:15; 以斯帖記 8:10"> 於是，亞比亥的女兒王后以斯帖全權給猶太人末迪凱下旨<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以斯帖全權給猶太人末迪凱下旨——原文直譯「以斯帖和猶太人末迪凱全權下旨」。">e</a></sup>，為要確定這第二封有關普珥的書信。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖記 1:1; 以斯帖記 8:9; 撒迦利亞書 8:19"> 末迪凱把詔書，就是平安和真誠的話語，傳送給亞哈隨魯國中一百二十七個行省的所有猶太人，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖記 4:3; 以斯帖記 4:16; 約拿書 3:2–9"> 為要確立所定的日期守這些普珥日，就是照著猶太人末迪凱和王后以斯帖為他們所確立的，也是照著他們為自己和自己的後裔，在禁食、哀哭中所確立的日子。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖記 9:26"> 以斯帖的命令確定了這些有關普珥的事，並且被記在史書上。</span>
</div>
</div>

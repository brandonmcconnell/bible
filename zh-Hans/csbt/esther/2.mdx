<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 6:14–18; 以斯帖記 7:10; 以斯帖記 1:12–21"> 這些事以後，亞哈隨魯王的怒火平息了，他就想起瓦實提和她所行的，以及有關懲罰她的決定。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 1:2; 創世記 12:14; 以斯帖記 6:14"> 於是事奉王的僕人們說：「讓人為王尋找一些容貌美麗的年輕處女吧！</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖記 2:12–15; 以斯帖記 2:8–9; 以斯帖記 1:1–2"> 請王在全國各省中指派監督，讓他們把所有容貌美麗的年輕處女都招聚到蘇薩城堡的妃嬪宮，歸在掌管女人的王室太監希該手下，給她們潔身的香品。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 14:6; 馬太福音 20:16; 以斯帖記 1:21"> 然後，哪個年輕女子在王眼中看為好，就讓她作王后代替瓦實提。」這事在王眼中看為好，他就這樣做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 16:5; 撒母耳記上 9:1; 以斯帖記 10:3"> 蘇薩城堡中有一個猶太人名叫末迪凱；他是睚珥的兒子、示每的孫子、便雅憫人基士的曾孫。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 24:14–15; 歷代志下 36:20; 耶利米書 24:1"> 當擄民與猶大王耶哥尼雅一同被巴比倫王尼布甲尼撒擄走的時候，這家族也從耶路撒冷一起被擄走。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 2:15; 以斯帖記 1:11; 哥林多後書 6:18"> 末迪凱撫養著他叔叔的女兒哈達莎，就是以斯帖，因為她沒有父母。這年輕女子身材秀美、容貌美麗。在她父母死的時候，末迪凱就把她收作自己的女兒。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 2:3; 以斯帖記 2:15"> 當王令和他的法令傳開的時候，許多年輕女子被招聚到蘇薩城堡，歸在希該手下；以斯帖也被帶到王宮，歸在掌管女人的希該手下。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 以斯帖記 2:12"> 這年輕女子在希該眼中看為好，就在他面前蒙了恩慈；希該立刻把潔身的香品和她應得的食物分配給她，又把王宮裡選出來的七個使女分配給她，讓她和她的使女們搬進妃嬪宮裡最好的地方。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 2:20; 馬太福音 10:16; 以斯帖記 3:8"> 以斯帖沒有把自己的民族和宗族告訴人，因為末迪凱吩咐她不可告訴人。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 37:14; 撒母耳記上 17:18; 使徒行傳 15:36"> 末迪凱天天都在妃嬪宮的院子前面往來行走，想知道以斯帖是否平安，以及她的情況如何。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 4:4–5; 箴言 7:17; 以賽亞書 57:9"> 每個年輕女子輪流去見亞哈隨魯王的時候，都要在女人規例所定的十二個月之後——因為要滿足美容潤身期：六個月用沒藥油、六個月用香料和女人潔身的香品。</span>
<span className="v" id="v13" data-v="13"> 年輕女子是這樣去見王的：從妃嬪宮到王宮的時候，凡她所要的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所要的——原文直譯「所說的」。">a</a></sup>都給她，讓她隨身帶著；</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 4:11; 創世記 34:19; 以賽亞書 62:4–5"> 她晚上進去，次日早晨回到另一個妃嬪宮，歸在掌管妃嬪的王室太監沙士甲手下；除非王喜悅她，提名召喚，否則她就不能再去見王。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅歌 6:9; 以斯帖記 2:3; 以斯帖記 9:29"> 以斯帖是末迪凱的叔叔亞比亥的女兒，後來被末迪凱收作自己的女兒；輪到她去見王的時候，除了掌管女人的王室太監希該所安排的以外，她別無所求。以斯帖在所有看見她的人眼前蒙恩。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以斯帖記 8:9; 以斯帖記 2:3; 以斯帖記 2:1"> 亞哈隨魯在位第七年的十月，就是提別月，以斯帖被帶到王宮去見亞哈隨魯王。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:7–8; 路加福音 1:48–52; 以西結書 17:24"> 王愛以斯帖勝過所有其他的女人；她在王面前蒙恩寵、蒙恩慈勝過所有其他的處女。王就把王后的冠冕戴在她的頭上，立她為王后代替瓦實提。</span>
<span className="v" id="v18" data-v="18" data-xref="雅歌 3:11; 路加福音 14:8; 士師記 14:10–17"> 王為所有的首領和臣僕擺設了盛大的宴席，就是以斯帖之宴；又在各省大行豁免<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在各省大行豁免——或譯作「豁免各省的稅賦、兵役、勞役」。">b</a></sup>，並照著王的慷慨賜予禮物。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 2:21; 以斯帖記 2:3–4; 以斯帖記 5:13"> 當第二次招聚處女們的時候，末迪凱坐在御門那裡。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:1–3; 以斯帖記 2:10; 以斯帖記 2:7"> 以斯帖照著末迪凱所吩咐她的，沒有把自己的宗族和她的民族告訴人；以斯帖遵行末迪凱的話，就像被末迪凱撫養時那樣。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 6:2; 列王紀上 16:9; 列王紀下 21:23"> 在那些日子，末迪凱坐在御門那裡。當時有兩個守門的王室太監彼革坦和提列心懷怒氣，圖謀對亞哈隨魯王下手。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 6:1–2; 羅馬書 11:33; 傳道書 10:20"> 末迪凱知道了這陰謀，就告訴王后以斯帖；以斯帖以末迪凱的名義告訴了王。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 40:22; 創世記 40:19; 以斯帖記 10:2"> 經過調查，發現這陰謀是真的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="是真的——輔助詞語。">c</a></sup>；於是那兩個太監就被掛在木架上。這事在王面前被記在《年代志》上。</span>
</div>
</div>

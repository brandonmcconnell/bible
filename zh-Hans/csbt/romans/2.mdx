<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 羅馬書 2:3; 約翰福音 8:7–9"> 哦，人哪，所以你是無法推諉的！一切評斷人的啊，你在什麼事上評斷別人，就在什麼事上定自己的罪；因為你這評斷人的，你自己也在做同樣的事。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 9:7–8; 西番雅書 3:5; 詩篇 145:17"> 況且我們知道，對做這樣事的人，神是按照真理來審判他們的。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 羅馬書 1:32–1"> 哦，人哪！你評斷做這樣事的人，而自己也做同樣的事，你以為你能逃脫神的審判嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得後書 3:9; 以賽亞書 30:18; 出埃及記 34:6"> 難道你輕視神豐富的仁慈、寬容、耐心，不明白他的仁慈是引領你來悔改的嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 12:14; 羅馬書 1:18; 羅馬書 2:2–3"> 可是你照著頑固和不悔改的心，為那震怒的日子，就是神公義審判顯現的日子，給自己積蓄了震怒。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 62:12; 耶利米書 32:19; 馬太福音 16:27"> 神將照著各人的行為回報各人：</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太後書 4:7–8; 路加福音 8:15; 提摩太後書 1:10"> 對那些恆心行善，尋求榮耀、尊貴、不朽的，就以永恆的生命回報他們；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:18–21; 帖撒羅尼迦後書 1:8; 提摩太前書 6:3–4"> 而對那些營私爭競<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="營私爭競——或譯作「結黨」。">a</a></sup>、不肯信從真理、反信從不義的，就以震怒和憤恨回報他們。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 4:17; 以西結書 18:4; 羅馬書 1:16"> 神要把患難和困苦加給一切作惡之人的靈魂，先是猶太人的，後是外邦人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="外邦人——原文直譯「希臘人」；指「希臘文化區的非猶太人」。">b</a></sup>的；</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 32:17; 以賽亞書 26:12; 民數記 6:26"> 而把榮耀、尊貴、平安賜給所有做美善事的人，先是猶太人，後是外邦人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="外邦人——原文直譯「希臘人」；指「希臘文化區的非猶太人」。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:17; 使徒行傳 10:34; 歷代志下 19:7"> 要知道，神是不偏待人的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:21; 加拉太書 3:10; 加拉太書 2:16–19"> 凡是在律法之外犯過罪的，也將要在律法之外滅亡；凡是在律法之下犯過罪的，將要照著律法受審判。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 1:22–25; 約翰一書 3:7; 雅各書 2:21–25"> 因為在神面前，不是律法的聽者為義，而是律法的實行者被稱為義。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:12; 羅馬書 1:19–20; 羅馬書 2:27"> 其實沒有律法的外邦人，一旦按照本性去行律法上的事，他們雖然沒有律法，但自己就是自己的律法了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 5:11; 哥林多後書 1:12; 羅馬書 1:18–19"> 這就顯出律法的要求<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="律法的要求——原文直譯「律法的行為」或「律法所要求的行為」。">d</a></sup>刻在他們的心裡，他們的良心也一同作證，而且自己的心思之間，互相控告或辯解。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 12:14; 哥林多前書 4:5; 使徒行傳 17:31"> 正如我的福音，這些事要在那日，神藉著基督耶穌審判各人隱祕事的時候，顯明出來。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 2:23; 彌迦書 3:11; 以賽亞書 48:1–2"> 你既然<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你既然——有古抄本作「看哪，你」。">e</a></sup>稱為猶太人，依靠律法，以神誇耀；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:21; 申命記 4:8; 雅各書 4:17"> 又從律法中受教，明白神的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神的——輔助詞語。">f</a></sup>旨意，也能分辨是非<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="分辨是非——或譯作「分辨那些更重要的事」。">g</a></sup>；</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 3:17–18; 馬太福音 15:14; 以賽亞書 49:6"> 又深信自己是瞎子的領路人，是在黑暗中人的光，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 3:5; 提多書 1:16; 提摩太後書 1:13"> 是愚妄人的導師，是小孩子的教師，擁有著律法上知識和真理的規範，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 9:27; 馬太福音 23:3–28; 路加福音 12:47"> 那麼，你這教導別人的，難道不教導自己嗎？你這宣講不可偷竊的，難道自己還偷竊嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="瑪拉基書 3:8; 馬太福音 12:39; 馬可福音 11:17"> 你這說不可通姦的，難道自己還通姦嗎？你這憎惡偶像的，難道自己還偷取廟裡的東西嗎？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 4:16–17; 羅馬書 2:17; 羅馬書 3:2"> 你這以律法誇耀的，難道自己還違犯律法侮辱神嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 36:20–23; 以賽亞書 52:5; 彼得後書 2:2"> 事實上，正如經上所記：「因你們的緣故，神的名在外邦人中受到褻瀆。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米書 4:4; 加拉太書 5:3–6; 使徒行傳 7:51"> 你如果是遵行律法的，割禮才有益處；但你如果是違犯律法的人，你的割禮就不是割禮了。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 2:11; 哥林多前書 7:18–19; 羅馬書 8:4"> 因此，那沒有受割禮的人，如果遵守律法的公義規定，他雖然沒有受割禮，難道不是算是受了割禮嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 12:41–42; 羅馬書 2:29; 哥林多後書 3:6"> 並且，那生來沒有受割禮卻完全實行律法的人，對你這雖有律法條文和割禮卻違犯律法的人，難道不是要施行審判嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 6:15; 馬太福音 3:9; 羅馬書 9:6–8"> 其實外表上做猶太人的，並不是猶太人；外表上、肉身上的割禮，也不是割禮。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 30:6; 腓立比書 3:3; 申命記 10:16"> 然而，在內心做猶太人的才是猶太人；同樣，內心的割禮才是割禮——不是靠著律法條文而是靠著聖靈；這樣的人得到的稱讚不是從人來的，而是從神來的。</span>
</div>

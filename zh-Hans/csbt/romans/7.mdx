<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 6:14; 羅馬書 7:6; 羅馬書 6:3"> 弟兄們，我現在對明白律法的人說：難道你們不明白，律法只是在一個人活著的時候轄制這個人嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 2:23–24; 哥林多前書 7:39; 哥林多前書 7:4"> 要知道，已婚的女人，在丈夫活著的時候，是被律法約束的；但如果丈夫死了，她就脫離了那關於丈夫的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:14; 馬太福音 5:32; 馬可福音 10:6–12"> 由此可見，丈夫還活著的時候，她如果歸向別的男人，就被稱為淫婦；但如果丈夫死了，她就脫離那律法得了自由，即使歸向別的男人，也不是淫婦。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彼得前書 2:24; 加拉太書 5:22–23; 以賽亞書 54:5"> 因此，我的弟兄們，你們藉著基督的身體，在律法上也被處死了，使你們歸向另一位，就是從死人中復活的那一位，好讓我們能為神結出果子來。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:3; 加拉太書 5:16–17; 加拉太書 5:24"> 原來，當我們還在肉體中的時候，罪的欲望藉著律法在我們身體的各部分<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="身體的各部分——或譯作「肢體」。">a</a></sup>做工，以致為死亡結了果子。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:23–25; 哥林多後書 3:6; 羅馬書 7:4"> 但如今，我們既然在那捆綁我們的律法上死了，就脫離了律法，結果我們得以按照聖靈的新樣式來服事，而不按照律法條文的舊樣式。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:20; 羅馬書 4:15; 哥林多前書 15:56"> 那麼，我們要怎麼說呢？難道律法是罪嗎？絕對不是！然而，要不是藉著律法，我就不知道什麼是罪。如果律法沒有說「不可貪心」，我就不知道什麼是貪心；</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 7:11; 哥林多前書 15:56; 羅馬書 4:15"> 但是，罪藉著誡命，趁機在我裡面生出種種貪念。原來在律法之外，罪是死的。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:10; 羅馬書 8:7; 雅各書 2:10–11"> 我從前活在律法之外，但是誡命一來，罪就活起來了，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 3:7; 羅馬書 10:5; 利未記 18:5"> 我卻死了。於是我發現，那本該帶來生命的誡命，它卻導致了死亡。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 3:13; 羅馬書 7:8; 希伯來書 3:13"> 事實上，罪藉著誡命趁機欺騙了我，並藉著誡命殺了我。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 1:8; 詩篇 119:137; 詩篇 19:7–12"> 因此，律法是神聖的，誡命也是神聖、公義、美善的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各書 1:13–15; 加拉太書 3:21; 羅馬書 8:3"> 那麼，是那美善的導致了我的死嗎？<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="導致了我的死嗎？——原文直譯「成了我的死嗎？」">b</a></sup>絕對不是！而是罪。罪為要顯出是罪，就藉著那美善的帶來了我的死，使罪藉著誡命變得極其邪惡。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 21:25; 列王紀下 17:17; 羅馬書 7:18"> 我們知道律法是屬靈的；而我是屬肉體的，已經賣給罪了。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 5:17; 羅馬書 7:19–20; 傳道書 7:20"> 實際上，我所做的，我不明白，因為我所願意的，我沒有去做；我所恨惡的，我反而去做。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 7:12; 羅馬書 7:14; 提摩太前書 1:8"> 那麼，如果我做我不願意做的事，我就贊同了律法是好的。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 7:20; 腓立比書 3:8–9; 羅馬書 7:18"> 所以現在這事就不再是我所做的，而是住在我裡面的罪所做的。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:6; 詩篇 51:5; 加拉太書 5:17"> 事實上，我知道在我裡面，就是在我肉體中，沒有良善；因為行善的意願在我裡面，卻行不出來。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:15"> 這樣，我願意行的善，我沒有去行；我不願意做的惡，我反而去做。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 7:17"> 那麼，如果我做我不願意做的事，這事就不再是我所做的，而是住在我裡面的罪所做的。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 6:14; 羅馬書 7:23; 詩篇 119:133"> 因此我發現一個法則：當我願意行善的時候，惡就在我裡面。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 1:2; 詩篇 40:8; 詩篇 119:35"> 就是說，按著內在的人，我喜愛神的法則，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 5:17; 雅各書 4:1; 羅馬書 8:2"> 然而我發現在我身體<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="身體——或譯作「身體的各部分」或「肢體」。">c</a></sup>中另有一個法則，與我理性的法則交戰，把我擄到我身體中罪的法則裡。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 6:6; 提摩太後書 4:18; 提多書 2:14"> 我這個人真是可悲呀！誰能救我脫離這屬於死亡的身體呢？</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:17–24; 歌羅西書 3:17; 哥林多後書 12:9–10"> 藉著我們的主耶穌基督，感謝歸於神！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="藉著我們的主耶穌基督，感謝歸於神！——或譯作「感謝神！藉著我們的主耶穌基督（，就能脫離了）。」">d</a></sup>由此可見，我自己一方面在理性上服從神的法則，另一方面在肉體中卻服從罪的法則。</span>
</div>
</div>

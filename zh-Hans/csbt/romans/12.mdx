<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:5; 羅馬書 6:13; 希伯來書 13:15–16"> 所以弟兄們，我藉著神的各樣憐憫勸你們，要把自己的身體獻上，做為聖潔、蒙神喜悅的活祭；這是你們理所當然的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="理所當然的——或譯作「靈裡的」。">a</a></sup>事奉。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 1:14; 以弗所書 4:22–24; 哥林多後書 5:17"> 不要效法這世代，要藉著理性的更新而改變，使你們可以分辨什麼是神的旨意——那美善、可喜悅、完美的旨意。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="加拉太書 6:3; 腓立比書 2:3–8; 箴言 26:12"> 我藉著所賜給我的恩典，對你們中間的每個人說：不要自視過高，過於所當看的，而要照著神所分給每個人信心的尺度，清醒地看自己。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 12:27; 哥林多前書 12:12–14; 以弗所書 4:15–16"> 正如我們一個身體有很多部分<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="部分——或譯作「肢體」。">b</a></sup>，而且各部分都有不同的功用；</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:20; 哥林多前書 10:17; 哥林多前書 12:27–28"> 照樣，我們這許多人，在基督裡是一個身體，而且各個部分都彼此相屬。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 4:10–11; 哥林多前書 7:7; 哥林多前書 12:28–31"> 照著所賜給我們的恩典，我們各有不同的恩賜：<br /><span className="pl pl-1">如果是做先知傳道</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知傳道——原文直譯「說預言」。">c</a></sup><br /><span className="pl pl-1">的恩賜</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="恩賜——輔助詞語。">d</a></sup><br /><span className="pl pl-1">，就按照信心的程度用它</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="用它——輔助詞語。">e</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:11; 提摩太後書 4:2; 使徒行傳 13:1"> <span className="pl pl-1">如果是服事的，就用在服事上；</span><br /><span className="pl pl-1">如果是教導的，就用在教導上；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 9:7; 提摩太前書 5:17; 哥林多前書 12:28"> <span className="pl pl-1">如果是勸勉的，就用在勸勉上；</span><br /><span className="pl pl-1">分享的，要慷慨；</span><br /><span className="pl pl-1">帶領</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="帶領——或譯作「管理」。">f</a></sup><br /><span className="pl pl-1">的，要殷勤；</span><br /><span className="pl pl-1">憐憫人的，要甘心樂意。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 34:14; 彼得前書 4:8; 提摩太前書 1:5"> 愛，不要虛假；要厭棄惡、持守善；</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:3; 約翰福音 13:34–35; 希伯來書 13:1"> 要以弟兄之情彼此相愛，以尊敬之心彼此謙讓，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:10–11; 使徒行傳 18:25; 啟示錄 3:15–16"> 殷勤而不懶惰，靈裡時時火熱，常常服事主。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:13; 希伯來書 10:36; 詩篇 62:8"> 在盼望中要歡喜，在患難裡要忍耐，在禱告上要恆切。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:16; 哥林多後書 9:12; 約翰一書 3:17"> 要分擔聖徒的缺乏；盡力款待客旅。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:9; 馬太福音 5:44; 帖撒羅尼迦前書 5:15"> 要祝福那些逼迫你們的人；要祝福，不要詛咒。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 12:26; 希伯來書 13:3; 詩篇 35:13–14"> 要與快樂的人一同快樂；與哀哭的人一同哀哭。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:8; 箴言 3:7; 雅各書 3:13–17"> 要彼此同心；不要心高氣傲，而要俯就卑微<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="卑微——或譯作「謙卑」。">g</a></sup>的人；不要自以為聰明。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; 帖撒羅尼迦前書 5:15; 馬太福音 5:39"> 不要對任何人以惡報惡；要顧念眾人看為美善的事；</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:14; 馬太福音 5:9; 羅馬書 14:19"> 如果有可能，盡量在你們的事上與所有的人和睦。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 32:35; 希伯來書 10:30; 箴言 24:29"> 各位蒙愛的人哪，不要自己報復，寧可給神的震怒留地步，因為經上記著：「主說：報應在我，我將回報。」</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; 馬太福音 5:44; 路加福音 6:27"> 不但如此，<br /><span className="pl pl-1">「如果你的敵人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="敵人——或譯作「反對者」。">h</a></sup><br /><span className="pl pl-1">餓了，就給他吃；</span><br /><span className="pl pl-1">如果他渴了，就給他喝；</span><br /><span className="pl pl-1">因為你這樣做，就是把炭火堆在他的頭上。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="彼得前書 3:9; 路加福音 6:27–30; 箴言 16:32"> 不要被惡所勝，反要以善勝惡。</span>
</div>

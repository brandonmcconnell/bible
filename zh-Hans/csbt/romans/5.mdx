<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 32:17; 羅馬書 15:13; 約翰福音 16:33"> 這樣，我們既然因信稱義，就藉著我們的主耶穌基督與神和好了；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 2:18; 以弗所書 3:12; 羅馬書 12:12"> 我們也藉著他，因信<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「因信」。">a</a></sup>進入了現在所站的這恩典中，並且以盼望神的榮耀而誇耀。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 1:2–3; 雅各書 1:12; 彼得前書 3:14"> 不僅如此，我們也以患難誇耀，因為我們知道患難生出忍耐，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 5:10; 雅各書 1:12; 哥林多後書 4:8–12"> 忍耐生出品德<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="品德——或譯作「老練」。">b</a></sup>，品德生出盼望，</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 4:6; 以弗所書 3:16–19; 腓立比書 1:20"> 而這盼望不使人羞愧，因為神的愛藉著所賜給我們的聖靈，已經傾注在我們的心裡。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所書 2:1–5; 羅馬書 5:8; 歌羅西書 2:13"> 原來，當我們還軟弱的時候，基督就按照所定的時候為不敬虔的人死了。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:13; 約翰一書 3:16; 羅馬書 16:4"> 為義人死，是少有的；為好人死，或許有敢做的；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:13; 約翰福音 3:16; 羅馬書 5:6"> 但是，當我們還是罪人的時候，基督就替我們死了。神的愛就在此向我們顯明了。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 1:10; 羅馬書 8:1; 以弗所書 2:13"> 所以，我們現在既然藉著基督的血被稱為義，難道不更要藉著他，從神的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神的——輔助詞語。">c</a></sup>震怒中被拯救出來嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:18–19; 哥林多後書 4:10–11; 羅馬書 8:32"> 這樣，我們做神敵人的時候，尚且能藉著神兒子的死與神和好，何況和好以後，難道不更要藉著神兒子的生命得救嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 5:18–19; 羅馬書 5:10; 以賽亞書 61:10"> 不僅如此，我們現在藉著主耶穌基督與神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="與神——輔助詞語。">d</a></sup>和好了，就更要藉著他以神誇耀。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 15:21–22; 羅馬書 5:19; 羅馬書 6:23"> 所以，正如罪是藉著一個人進入了世界，並且死是藉著罪進入的；這樣，因為人人都犯了罪，死也就臨到了所有的人。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 4:15; 哥林多前書 15:56; 約翰一書 3:4"> 就是說，沒有律法以前，罪已經在世上了；不過沒有律法，罪就不算為罪。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 15:45; 羅馬書 5:17; 希伯來書 9:27"> 然而，從亞當到摩西，死亡掌了權，甚至那些沒有按亞當過犯的樣式犯罪的人，也在死的權下。這亞當是以後要來的那一位的象徵。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="羅馬書 6:23; 以弗所書 2:8; 羅馬書 5:12"> 但是恩賜不同於過犯。原來，一個人的過犯尚且使眾人都死了，何況神的恩典和耶穌基督一個人恩典裡的賞賜，難道不更要豐豐富富地臨到眾人嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 13:38–39; 以賽亞書 1:18; 以賽亞書 44:22"> 而且，恩賜不同於由一個人犯罪而來的後果<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="後果——輔助詞語。">e</a></sup>。因為，由一次過犯而來的審判雖然導致了定罪，但由很多過犯而來的恩賜卻導致了稱義。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 15:21–22; 哥林多前書 15:49; 羅馬書 5:12"> 實際上，一個人的過犯尚且使死亡藉著這一個人掌了權，何況那些領受豐富之恩典和稱義之賞賜的人，難道不更要藉著耶穌基督一個人，在生命裡掌權嗎？</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 15:22; 羅馬書 5:12; 羅馬書 5:15"> 由此可見，藉著一次的過犯導致了所有人的定罪；照樣，藉著一次的義行給所有的人帶來永生的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="永生的——原文直譯「生命的」。">f</a></sup>稱義。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 5:18; 哥林多後書 5:21; 腓立比書 2:8"> 就是說，藉著一個人的悖逆，眾人怎樣都成了罪人；藉著一個人的順從，眾人將怎樣成為義人。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 6:1; 提多書 3:3–7; 羅馬書 6:14"> 律法出現，為要使過犯增多；可是，罪在哪裡增多，恩典就在哪裡格外增多。</span>
<span className="v" id="v21" data-v="21" data-xref="提多書 2:11; 羅馬書 5:14; 羅馬書 8:10"> 這樣，就像罪藉著死亡掌權，恩典也照樣藉著義掌權，使人藉著我們的主耶穌基督進入永恆的生命。</span>
</div>
</div>

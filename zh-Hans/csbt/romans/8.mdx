<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 3:18–19; 哥林多後書 5:17; 加拉太書 3:13"> 所以現在，那些在基督耶穌裡的人，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「就是那些不順著肉體卻順著聖靈而行走的人，」。">a</a></sup>就不被定罪了，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 6:14; 哥林多後書 3:17; 羅馬書 6:18"> 因為聖靈的生命法則，在基督耶穌裡把你<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你——有古抄本作「我」。">b</a></sup>從罪和死的法則中釋放了出來。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 13:39; 加拉太書 4:4–5; 希伯來書 7:18–19"> 因肉體軟弱的緣故，律法所做不到的，神卻做到了<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神卻做到了——輔助詞語。">c</a></sup>——神派遣了自己的兒子成為罪的肉身樣式，並且為了贖罪，用肉身判決了罪，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 5:16; 加拉太書 5:22–25; 歌羅西書 1:22"> 使律法的公義規定，成全在我們這些不順著肉體卻順著聖靈行走的人身上。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 2:14; 加拉太書 5:19–25; 約翰福音 3:6"> 要知道，順著肉體的人，思想屬肉體的事；順著聖靈的人，思想屬聖靈的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 6:8; 羅馬書 8:7; 羅馬書 8:13"> 屬肉體的思想帶來死亡；屬聖靈的思想帶來生命和平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 2:14; 約翰一書 2:15–16; 雅各書 4:4"> 原來屬肉體的思想是敵對神的，因為它不服從神的律法，其實也不能服從；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:5–6; 希伯來書 11:5–6; 羅馬書 8:9"> 並且，屬肉體的人無法得到神的喜悅。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 4:6; 哥林多前書 3:16; 提摩太後書 1:14"> 但既然神的靈真是住在你們裡面，你們就不屬於肉體，而屬於聖靈了。不過如果有人沒有基督的靈，這個人就不屬於基督了。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 3:17; 加拉太書 2:20; 哥林多後書 5:21"> 但如果基督在你們裡面，那麼，你們的身體雖然因罪是死的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="是死的——或譯作「要死」。">d</a></sup>，靈卻因義是活的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="靈卻因義是活的——或譯作「聖靈卻因義賜生命」。">e</a></sup>；</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 4:14; 羅馬書 6:4–5; 哥林多後書 4:11"> 不但如此，使耶穌從死人中復活的那一位——他的靈如果住在你們裡面，那麼，使基督從死人中復活的那一位，也將藉著<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="藉著——有古抄本作「因為」。">f</a></sup>住在你們裡面的聖靈，使你們會死的身體得著生命。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 6:2–15; 哥林多前書 6:19–20; 彼得前書 4:2–3"> 弟兄們，由此可見，我們都是有責任<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有責任——原文直譯「欠債」。">g</a></sup>的，但不是對肉體有責任去順著肉體而活；</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:8; 彼得前書 2:11; 哥林多前書 9:27"> 因為你們如果順著肉體而活，就將死去；但如果順著聖靈治死身體的所作所為，就將活著。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 5:18; 約翰福音 1:12; 加拉太書 3:26"> 原來，凡是蒙神的靈帶領的人，他們才是神的兒女。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:5–7; 提摩太後書 1:7; 哥林多前書 2:12"> 就是說，你們所領受的不是一個奴役的靈，使你們再有懼怕；相反，你們所領受的是使你們有兒子名份的聖靈——藉著他，我們呼叫：「阿爸！父啊！」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰一書 4:13; 哥林多後書 1:22; 哥林多後書 5:5"> 聖靈親自與我們的靈一同作證：我們是神的兒女。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 4:7; 加拉太書 3:29; 以弗所書 3:6"> 既然是兒女，也就是繼承人；如果我們真是為了與他一同得榮耀而與他一同受苦，我們就是神的繼承人，而且與基督同做繼承人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 4:17–18; 彼得前書 4:13; 彼得前書 1:5–7"> 事實上，我認為現今時刻的苦難，與將來要顯明給我們的榮耀，是無法相比的。</span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 3:17–18; 羅馬書 8:23; 約翰一書 3:2"> 被造之物都熱切盼望、熱切等待著神的兒女顯現出來，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:17–19; 創世記 5:29; 羅馬書 8:22"> 因為被造之物屈從在虛妄之下，並不是出於自願，而是出於使它屈從的那一位；</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 22:3–5; 使徒行傳 3:21; 彼得後書 3:13"> 被造之物自己也盼望著從使之衰朽<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="衰朽——或譯作「敗壞」。">h</a></sup>的奴役中得到釋放，歸入神兒女榮耀的自由。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 12:4; 耶利米書 12:11; 約翰福音 16:21"> 我們知道，所有被造之物都一同呻吟、同受陣痛，直到如今。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 3:20–21; 哥林多後書 5:2–5; 希伯來書 9:28"> 不僅如此，連我們這些有聖靈為初熟果子的人，也在自己裡面呻吟嘆息，熱切等待得到兒子的名份<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有「得到兒子的名份」。">i</a></sup>，就是等待我們的身體得蒙救贖。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 5:7; 希伯來書 11:1; 哥林多後書 4:18"> 因為我們得救在於這盼望。然而，看得見的盼望，就不是盼望了；誰會盼望自己所看得見的呢？</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 12:12; 希伯來書 10:36; 詩篇 27:14"> 但如果我們盼望那看不見的，就要藉著忍耐來熱切等待。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:20; 以弗所書 6:18; 加拉太書 4:6"> 況且，聖靈也照樣扶助我們的軟弱。事實上，我們不知道該禱告什麼、如何禱告，但聖靈卻親自用說不出的嘆息，為我們<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「為我們」。">j</a></sup>代求。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 17:10; 約翰一書 5:14–15; 以弗所書 2:18"> 而且，洞察人心的那一位，知道聖靈的意念是什麼，因為聖靈是按神的意思<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="的意思——輔助詞語。">k</a></sup>為聖徒代求的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得前書 5:10; 雅各書 1:12; 創世記 50:20"> 我們也知道，神使萬事相輔相成<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="神使萬事相輔相成——或譯作「萬事相輔相成」。">l</a></sup>，是為了愛神之人的益處，就是那些按照他的心意蒙召之人的益處。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 1:4–5; 耶利米書 1:5; 以弗所書 1:11"> 因為神預先所知道的人，神也預先定下他們和他兒子的形像相似，使他兒子在眾多弟兄中做長子<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="長子——原文直譯「首生者」。">m</a></sup>；</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 17:14; 羅馬書 8:28; 以弗所書 1:11"> 而且，神預先所定下的人，神又召他們來；所召來的人，又稱他們為義；所稱為義的人，又使他們得榮耀。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="詩篇 118:6; 耶利米書 1:19; 詩篇 56:11"> <span className="pl pl-1">那麼，對這些事我們要怎麼說呢？</span><br /><span className="pl pl-1">神如果支持我們，誰還能反對我們呢？</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:16; 羅馬書 8:28; 詩篇 84:11"> <span className="pl pl-1">神既然沒有顧惜自己的兒子，</span><br /><span className="pl pl-1">為我們所有的人捨棄了他，</span><br /><span className="pl pl-1">難道不會把萬有也連同他一起賜給我們嗎？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="啟示錄 12:10–11; 以賽亞書 50:8–9; 以賽亞書 54:17"> <span className="pl pl-1">到底誰能控告那些蒙神揀選的人呢？</span><br /><span className="pl pl-1">神是稱人為義的那一位！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 7:25; 羅馬書 8:27; 希伯來書 9:24"> <span className="pl pl-1">到底誰能定我們的罪呢？</span><br /><span className="pl pl-1">基督耶穌是已經死了的那一位——</span><br /><span className="pl pl-1">但更要說，他已經復活了，</span><br /><span className="pl pl-1">而且現今在神的右邊，還為我們代求！</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 10:28; 詩篇 103:17; 約翰福音 16:33"> <span className="pl pl-1">到底誰能使我們與基督</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="基督——有古抄本作「神」。">n</a></sup><br /><span className="pl pl-1">的愛分開呢？</span><br /><span className="pl pl-1">難道是患難嗎？是困苦嗎？是逼迫嗎？</span><br /><span className="pl pl-1">是飢餓嗎？是赤身嗎？是危險嗎？是刀劍嗎？</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 44:22; 以賽亞書 53:7; 哥林多前書 15:30"> <span className="pl pl-1">正如經上所記：</span><br /><span className="pl pl-1">「為你的緣故，我們終日被置於死地，</span><br /><span className="pl pl-1">被看為要宰殺的羊。」</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 15:57; 約翰一書 4:4; 哥林多後書 2:14"> <span className="pl pl-1">然而，靠著愛我們的那一位，</span><br /><span className="pl pl-1">我們在這一切事上已經得勝有餘了。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 10:28; 羅馬書 14:8; 提摩太後書 1:12"> <span className="pl pl-1">事實上，我深信：</span><br /><span className="pl pl-1">無論是死、是生、</span><br /><span className="pl pl-1">是天使、是統治者、</span><br /><span className="pl pl-1">是現在的事、是將來的事、是有勢力的、</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 10:28–30; 羅馬書 8:35; 羅馬書 5:8"> <span className="pl pl-1">是高處的、是深處的，或是任何別的被造之物，</span><br /><span className="pl pl-1">都不能使我們與神的愛分開，</span><br /><span className="pl pl-1">這愛是在我們主基督耶穌裡的。</span></span>
</div>
</div>

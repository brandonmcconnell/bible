<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:15; 羅馬書 15:16; 哥林多前書 1:1"> 我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——輔助詞語。">a</a></sup>保羅做基督耶穌的奴僕、蒙召的使徒，是為了神的福音被分別出來的。</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 1:2; 路加福音 1:70; 羅馬書 3:21"> 這福音是神先前藉著他的先知們，在聖經上所應許的，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 1:1; 加拉太書 4:4; 耶利米書 23:5–6"> 是關於他的兒子——我們的主耶穌基督的。照著肉身說，他出自大衛的後裔；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 9:14; 希伯來書 5:5–6; 以弗所書 1:19–23"> 照著聖潔的靈<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="聖潔的靈——或譯作「聖靈」。">b</a></sup>說，藉著從死人中復活，他被顯明是神大能的兒子。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:15; 羅馬書 16:26; 使徒行傳 6:7"> 我們從他領受了恩典和使徒的職份，為了他名的緣故，要在萬民中帶來信仰上的順從；</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 2:9; 啟示錄 17:14; 彼得後書 1:10"> 其中也有你們這些蒙召喚、屬耶穌基督的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 1:2; 猶大書 1:1–2; 以弗所書 1:2"> 致所有在羅馬、蒙神所愛、蒙召成為聖徒的人：<br />願恩典與平安從神我們的父和主耶穌基督臨到你們！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 16:19; 哥林多前書 1:4; 帖撒羅尼迦前書 1:8–9"> 首先，我藉著耶穌基督，為你們各位感謝我的神，因為你們的忠信被傳遍全世界。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 6:18; 提摩太後書 1:3; 以弗所書 1:16–19"> 事實上，神——就是我在他兒子的福音工作上用心靈所事奉的那一位，可以為我見證：我怎樣不住地提到你們，</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 15:30–32; 使徒行傳 18:21; 腓利門書 1:22"> 在我的禱告中總是祈求，或許可以照著神的旨意，終有一天能順利地到你們那裡去；</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 1:12; 羅馬書 16:25; 羅馬書 15:29"> 因為我切切地想見到你們，好把一些屬靈的恩賜分給你們，使你們得以堅固。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 3:7–10; 約翰三書 1:3–4; 哥林多後書 7:13"> 這就是說，在你們那裡，藉著你們和我裡面彼此的信仰，大家可以同得鼓勵。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 19:21; 腓立比書 4:17; 提摩太後書 4:17"> 弟兄們，我不願意你們不明白：我多次計劃到你們那裡去，為要在你們那裡也得一些果實，就像我在其他外邦人中那樣，可是直到如今還受到攔阻。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 9:16–23; 使徒行傳 9:15; 歌羅西書 3:11"> 無論是希臘人或是外族人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="外族人——或譯作「非希臘人」。">c</a></sup>，有智慧的或是無知的，我都對他們有責任<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有責任——原文直譯「欠債」。">d</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 15:20; 以賽亞書 6:8; 哥林多前書 9:17"> 因此，我願意盡我所能，把福音也傳給你們在羅馬的人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬可福音 8:38; 提摩太後書 1:8; 彼得前書 4:16"> 的確，我不以<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「基督的」。">e</a></sup>福音為恥，因為這福音是神的大能，把救恩帶給一切相信的人，先是猶太人、後是外邦人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="外邦人——原文直譯「希臘人」；指「希臘文化區的非猶太人」。">f</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="哈巴谷書 2:4; 加拉太書 3:11; 希伯來書 10:38"> 原來，神的義就在這福音上顯明出來——本於信，以至於信，正如經上所記：「義人將因信而活。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所書 5:6; 提摩太前書 4:1–2; 羅馬書 1:32"> 要知道，人用不公義抵擋真理，神的震怒就從天上顯明在人的一切不敬虔和不公義上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 14:16–17; 詩篇 19:1–6; 羅馬書 1:20"> 實際上，有關神的事，人所能知道的，在他們裡面是清清楚楚的，因為神已經向他們顯明了。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:19; 以賽亞書 40:26; 詩篇 19:1–6"> 原來，自從創世以來，神那不可見的本性，就是他永恆的大能和神性，都藉著所造之物，被人明白、被人看見，以致使人無法推諉。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 4:17–18; 列王紀下 17:15; 耶利米書 2:5"> 所以人是已經知道神的，但是卻不把他當做神來榮耀他，也不感謝他；相反，他們在思想上變得虛妄，他們無知的心就昏暗了。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 1:19–21; 羅馬書 11:25; 箴言 26:12"> 他們自稱是有智慧的，卻成了愚拙，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:20; 耶利米書 2:11; 使徒行傳 17:29"> 甚至用偶像，就是會朽壞的人、飛禽、走獸、爬行動物的形像，來取代那不朽之神的榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 使徒行傳 7:42; 使徒行傳 14:16"> 因此，神任憑他們順著心中的情慾去做汙穢的事，以致彼此玷汙自己的身體。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷書 2:18; 耶利米書 13:25; 約翰一書 2:15–16"> 他們用虛假取代神的真理，去崇拜、事奉被造之物，而不事奉造物之主——主是當受頌讚的，直到永遠！阿們。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="猶大書 1:7; 提摩太前書 1:10; 羅馬書 1:24"> 為此，神任憑他們陷入可恥的情慾，連他們的女人也把天性的功用變為違反天性的；</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 20:13; 利未記 18:22; 羅馬書 1:23–24"> 同樣，男人也放棄了女人天性的功用，彼此之間慾火中燒，男人與男人做出羞恥的事，就在自己身上<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在自己身上——原文直譯「在自己裡面」。">g</a></sup>受到他們的妄為<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="妄為——或譯作「迷途行為」。">h</a></sup>所應得的報應。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦後書 2:10–12; 羅馬書 1:21; 提多書 1:16"> 既然人不願意真正認識神，神就任憑他們存敗壞的理性，去做那些不該做的事。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 12:20; 箴言 16:28; 詩篇 41:7"> 他們充滿了各種不義、<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「淫亂、」。">i</a></sup>邪惡、貪心、惡毒；滿心是嫉妒、凶殺、紛爭、欺詐、狠毒；他們搬弄是非、</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太後書 3:2; 猶大書 1:16; 彼得後書 2:18"> 誹謗人、憎恨神、侮慢人、驕傲、自誇、製造惡行、悖逆父母、</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太後書 3:3; 箴言 18:2; 羅馬書 3:11"> 愚昧無知、不守信用、沒有親情、<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「不肯和解、」。">j</a></sup>毫無憐憫。</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 2:1–5; 羅馬書 1:21; 羅馬書 6:21"> 人雖然知道神的公義規定是：行這樣事的人是該死的；然而他們不僅自己去做，還贊同做這些事的人。</span>
</div>
</div>

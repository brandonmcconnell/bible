<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 51:2; 羅馬書 4:16; 哥林多後書 11:22"> 那麼，我們說我們肉體上的先祖亞伯拉罕得到了什麼呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 1:31; 哥林多後書 11:30; 腓立比書 3:9"> 事實上，如果亞伯拉罕本於行為被稱為義，他就有可誇耀的；然而在神面前他並沒有可誇耀的。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 15:6; 雅各書 2:23; 加拉太書 3:6–8"> 經上到底是怎麼說的呢？<br /><span className="pl pl-1">「亞伯拉罕信神，</span><br /><span className="pl pl-1">這就被算為他的義。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 11:6; 羅馬書 9:32; 羅馬書 11:35"> 做工的人得工錢，不算是恩典，而是應得的；</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 3:9; 羅馬書 3:22; 提多書 3:3–7"> 但是，一個人雖沒有做工，卻信靠那稱不敬虔之人為義的神，這人的信就被算為義。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="提摩太後書 1:9; 腓立比書 3:9; 哥林多前書 1:30"> 正如大衛也論到神所算為義之人的福份，這義與行為無關；他說：</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 32:1–2; 詩篇 130:3–4; 路加福音 7:47–50"> <span className="pl pl-1">「罪惡</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罪惡——原文直譯「不法」。">a</a></sup><br /><span className="pl pl-1">被赦免、</span><br /><span className="pl pl-1">罪孽被遮蓋的人，</span><br /><span className="pl pl-1">這人是蒙福的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 32:2; 彼得前書 2:24; 哥林多後書 5:19–20"> <span className="pl pl-1">主絕不算為有罪的，</span><br /><span className="pl pl-1">這人是蒙福的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:14; 歌羅西書 3:11; 加拉太書 3:26–28"> 既然如此，這福份到底是只賜給那些受割禮的人，還是也賜給那些沒有受割禮的人呢？我們說：「亞伯拉罕因著信，就被算為義了。」</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 6:15; 加拉太書 5:6; 創世記 17:10"> 那麼，是怎麼被算為義的呢？到底是在他受割禮之後，還是在他沒有受割禮的時候呢？不是在受割禮之後，而是在沒有受割禮的時候。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:22; 路加福音 19:9; 哥林多後書 1:22"> 並且他領受了割禮的標記，做為他沒有受割禮時因信稱義的印證，使他成為所有不憑著割禮而信之人的父，也使他們被算為義；</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 約翰福音 8:39–40; 箴言 2:20"> 而且他也成為受割禮之人的父，不僅為那些受了割禮的人，還為那些順著我們的先祖亞伯拉罕信心之腳蹤行走的人；亞伯拉罕的信心在他沒有受割禮的時候就已經有了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 3:29; 創世記 22:17–18; 創世記 28:14"> 原來，賜給亞伯拉罕和他後裔繼承世界的應許，不是藉著律法，而是藉著因信而得的義。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:18–24; 腓立比書 3:9; 羅馬書 4:16"> 這是因為，如果本於律法的才是繼承人，信就落了空，應許也就無效了。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 5:13; 加拉太書 3:10; 羅馬書 3:19–20"> 事實上，律法帶來了震怒，所以哪裡沒有律法，哪裡也就沒有過犯。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="羅馬書 3:24–26; 以弗所書 2:8; 加拉太書 3:22"> 為此，這應許是本於信，好使這應許照著恩典，能確保給所有的後裔——不僅是給屬律法的，也是給屬亞伯拉罕信心的。亞伯拉罕在神面前是我們每個人的父，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 1:28; 創世記 17:4–5; 約翰福音 5:21"> 正如經上所記：「我已經指派你為眾多民族的父。」亞伯拉罕所信的那一位，就是叫死人得生命、使無變為有的神。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:24; 創世記 15:5–6; 使徒行傳 27:25"> 亞伯拉罕在沒有盼望的時候，仍然懷著盼望去相信，因而成為眾多民族的父，正如先前所說：「你的後裔將要如此眾多<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="眾多——輔助詞語。">b</a></sup>。」</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 11:11–19; 羅馬書 4:20–21; 創世記 17:17"> 他快到一百歲的時候，想到自己的身體如同<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="如同——輔助詞語。">c</a></sup>已經死了，又想到撒拉也已經不能生育，但是他的信仰卻沒有軟弱。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前書 16:13; 但以理書 10:19"> 他也沒有因著不信去懷疑神的應許，反而因著信得以剛強，把榮耀歸給神，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米書 32:27; 創世記 18:14"> 並且確信不疑：神所應許的，神也能成就。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 4:6; 羅馬書 4:3"> 因此，這就被算為他的義了。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 10:11; 羅馬書 15:4; 哥林多前書 10:6"> 不但如此，「被算為他的義」這句話不僅是為亞伯拉罕寫的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 2:24; 彼得前書 1:21; 使徒行傳 13:30"> 也是為我們寫的；我們信靠使我們的主耶穌從死人中復活的那一位，就將被算為義。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 4:9–10; 以賽亞書 53:5–6; 哥林多後書 5:21"> 主耶穌被交出去，是為了我們的過犯；復活，是為了我們稱義。</span>
</div>

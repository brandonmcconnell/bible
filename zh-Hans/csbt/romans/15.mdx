<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 5:14; 羅馬書 14:1; 加拉太書 6:1–2"> 我們堅強的人，應該擔當不堅強人的軟弱，不求自己的喜悅。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 14:19; 哥林多前書 10:24; 腓立比書 2:4–5"> 我們每個人當為了鄰人的益處讓他喜悅，使他得造就。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 69:9; 腓立比書 2:8; 約翰福音 4:34"> 因為基督不但不求自己的喜悅，反而像經上所記的：「那些責罵你之人的責罵，都落在我身上了。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:11; 提摩太後書 3:16–17; 羅馬書 4:23–24"> 實際上，凡是先前被記載的，都是為了教導我們而寫的，好讓我們藉著忍耐和經上的安慰，懷有盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 2:4–5; 彼得前書 3:8; 羅馬書 12:16"> 願賜忍耐和安慰的神，使你們藉著基督耶穌，彼此同心合意，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 10:29–30; 啟示錄 1:6; 以弗所書 1:3"> 好使你們同心同聲榮耀神——我們主耶穌基督的父。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:40; 約翰福音 13:34; 羅馬書 5:2"> 因此，你們當彼此接納，就像基督也接納了你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——有古抄本作「我們」。">a</a></sup>歸於神的榮耀。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 4:4–5; 馬太福音 15:24; 約翰福音 1:11"> 我是說：基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督——有古抄本作「耶穌基督」。">b</a></sup>為了神的真理，已成為受割禮之人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受割禮之人——指「猶太人」。">c</a></sup>的僕人，為要證實對祖先的各樣應許，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 22:50; 詩篇 18:49; 羅馬書 3:29"> 並且使外邦人因著所蒙的憐憫而榮耀神，正如經上所記：<br /><span className="pl pl-1">「為此，我要在外邦人中承認你，</span><br /><span className="pl pl-1">歌頌你的名。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 67:3–4; 申命記 32:43; 以賽亞書 42:10–12"> 經上又說：「外邦人哪，你們要與他的子民一同慶祝！」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 117:1"> 又說：<br /><span className="pl pl-1">「萬國啊，你們要讚美主！</span><br /><span className="pl pl-1">萬民哪，你們要頌讚他！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 11:10; 以賽亞書 11:1; 馬太福音 12:21"> 又有以賽亞說：<br /><span className="pl pl-1">「將有耶西的根，</span><br /><span className="pl pl-1">就是興起來統治外邦人的那一位；</span><br /><span className="pl pl-1">外邦人要仰望他。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦後書 2:16–17; 羅馬書 12:12; 哥林多後書 9:8"> 願賜盼望的神，因著你們的信，將一切喜樂和平安充滿你們，使你們藉著聖靈的能力滿懷盼望。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 3:16; 彼得後書 1:12; 約翰一書 2:21"> 我的弟兄們，至於你們，我自己同樣深信：你們也滿有良善，充滿一切知識，又能彼此勸誡。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 12:3; 哥林多前書 15:10; 羅馬書 1:5"> 不過<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「弟兄們，」。">d</a></sup>我要提醒你們，藉著神所賜給我的恩典，我在部分地方寫得比較大膽。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:13; 羅馬書 1:1; 使徒行傳 9:15"> 這恩典使我為外邦人成了基督耶穌的僕役、做了神福音的祭司，好讓外邦人藉著聖靈被分別為聖，成為蒙悅納的供物。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 2:14–16; 哥林多後書 12:11–21; 希伯來書 5:1"> 所以，我在基督耶穌裡，在屬神的事上有可誇耀的。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 15:12; 羅馬書 1:5; 使徒行傳 21:19"> 我什麼都不敢說，只說基督藉著我所完成的事，就是為了外邦人的順從，他藉著我所說的和所做的事，</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 12:12; 希伯來書 2:4; 使徒行傳 19:11–12"> 藉著神蹟、奇事的能力和聖靈<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="聖靈——有古抄本作「神的靈」。">e</a></sup>的能力所完成的事。結果我從耶路撒冷及其周圍一帶直到伊利里亞，把基督的福音都傳遍了。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 10:13–16; 哥林多前書 3:9–15; 以弗所書 2:20–22"> 這樣，我立定心志要在基督的名沒有被傳過的地方傳福音，免得建造在別人的根基上，</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 52:15; 以賽亞書 65:1"> 正如經上所記：<br /><span className="pl pl-1">「沒有聽說過他的人，將要看見；</span><br /><span className="pl pl-1">沒有聽見過的人，將要領悟。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="羅馬書 1:13; 帖撒羅尼迦前書 2:17–18"> 所以，我也多次受到攔阻，不能到你們那裡去。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 15:32; 羅馬書 1:10–12; 羅馬書 15:29"> 但如今，這些地區再沒有可傳的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="可傳的——輔助詞語。">f</a></sup>地方了，況且多年來我一直渴望見到你們。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 15:28; 羅馬書 1:12; 使徒行傳 15:3"> 就是說，當我去西班牙的時候，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「我會到你們那裡去。」">g</a></sup>我希望能順路看你們；先與你們相聚<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="相聚——輔助詞語。">h</a></sup>，使我稍得滿足；然後由你們在那裡送我上路。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 24:17; 使徒行傳 19:21; 使徒行傳 20:22"> 但如今，我要到耶路撒冷去服事聖徒，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 8:1–9; 使徒行傳 11:27–30; 哥林多後書 9:2"> 因為馬其頓省和亞該亞省的信徒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="的信徒——輔助詞語。">i</a></sup>，樂意與耶路撒冷聖徒中的窮人有一些分享<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="分享——或譯作「捐獻」。">j</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 9:11; 加拉太書 6:6; 腓利門書 1:19"> 確實，他們是樂意的，不過這也是他們的責任<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="這也是他們的責任——原文直譯「他們是他們的欠債人」。">k</a></sup>，因為外邦人如果分享了猶太人屬靈的事，也就應該在物質的事<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="物質的事——原文直譯「屬肉體的事」。">l</a></sup>上服事猶太人。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 15:24; 腓立比書 4:17; 歌羅西書 1:6"> 所以，當我完成了這件事，向他們印證了這事的成果<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="成果——原文直譯「果子」。">m</a></sup>，我就要經過你們那裡，往西班牙去。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 4:13; 羅馬書 1:10–12; 詩篇 16:11"> 我知道，我到你們那裡去的時候，一定帶著基督豐盛完美的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本附「福音的」。">n</a></sup>祝福而去。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 4:12; 哥林多後書 1:11; 哥林多後書 4:11"> 弟兄們，藉著我們的主耶穌基督、藉著聖靈的愛，我懇求你們與我一同竭力為我向神禱告：</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦後書 3:2; 哥林多後書 8:4; 哥林多後書 9:1"> 願神<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="神——輔助詞語。">o</a></sup>救我脫離猶太地區不肯信從的人，也使我為耶路撒冷的這服事<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="服事——或譯作「捐款」。">p</a></sup>可以蒙聖徒們的悅納，</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 16:18; 腓利門書 1:20; 腓利門書 1:7"> 好讓我能照著神的旨意，快快樂樂地到你們那裡去，和你們同得安息。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 13:11; 腓立比書 4:9; 帖撒羅尼迦前書 5:23"> 願賜平安的神，與你們大家同在！阿們。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 2:7; 羅馬書 1:9; 加拉太書 1:20"> 我在基督裡說真話，不是在說謊；我的良心藉著聖靈與我一同作證：</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 3:18; 詩篇 119:136; 耶利米書 13:17"> 我極其憂傷，心裡時常苦痛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 32:32; 以斯帖記 8:6; 羅馬書 11:14"> 為了我的同胞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同胞——原文直譯「兄弟」。">a</a></sup>，我的骨肉之親，就算我自己被詛咒、與基督分離，我也願意。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:12; 詩篇 147:19; 羅馬書 9:6"> 他們是以色列人：兒子的名份、榮耀、諸約、所賜的律法、禮儀、各樣應許，都是他們的；</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 10:30; 約翰福音 1:1–3; 歌羅西書 1:16–19"> 祖先也是他們的；照著肉身說，基督也是出自他們的——他是那在萬有之上當受頌讚的神，直到永遠！阿們。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="羅馬書 2:28–29; 加拉太書 6:16; 羅馬書 11:1–2"> 但這並不是說神的話語<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="神的話語——或譯作「神的道」。">b</a></sup>落了空，因為由以色列所生的，並不都是以色列人；</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 21:12; 希伯來書 11:18; 約翰福音 8:37–39"> 也不因為是亞伯拉罕的後裔，就都是他的兒女；只有「從以撒生的，才會被稱為你的後裔。」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:13; 羅馬書 4:11–16; 加拉太書 3:26–29"> 這就是說，肉身的兒女並不是神的兒女，只有應許的兒女才算是後裔。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 18:10; 創世記 18:14; 創世記 17:21"> 原來所應許的話是這樣的：「到明年<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="明年——輔助詞語。">c</a></sup>這時候我要來，撒拉會生一個兒子。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 25:21–23; 路加福音 16:26; 羅馬書 5:11"> 不僅如此，莉百加也是這樣。她由一個人，就是由我們的先祖以撒懷了孕。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 1:9; 以弗所書 1:4–5; 彼得後書 1:10"> 實際上，雙子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="雙子——輔助詞語。">d</a></sup>還沒有出生，也沒有行善或作惡以前——為了要顯明神的揀選心意不是本於人的行為，而是出於召喚人的那一位——</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:22–23; 撒母耳記下 8:14; 列王紀上 22:47"> 神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神——輔助詞語。">e</a></sup>就對莉百加說：「大的將要服事小的。」</span>
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 1:2–3; 申命記 21:15; 創世記 29:33"> 正如經上所記：「我愛雅各，卻恨以掃。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 19:7; 詩篇 145:17; 申命記 32:4"> 那麼，我們要怎麼說呢？難道神不公義嗎？絕對不是！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 33:19; 羅馬書 9:16; 彌迦書 7:18"> 因為神對摩西說：<br /><span className="pl pl-1">「我要憐憫誰，就憐憫誰；</span><br /><span className="pl pl-1">我要同情誰，就同情誰。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以弗所書 2:8; 馬太福音 11:25–26; 彼得前書 2:9–10"> 由此可見，這不在於人的意願，也不在於人的努力<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="努力——原文直譯「奔跑」。">f</a></sup>，而在於施憐憫的神。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 9:16; 箴言 16:4; 出埃及記 14:17–18"> 原來經上有話對法老說：<br /><span className="pl pl-1">「我興起你，正是為此：</span><br /><span className="pl pl-1">好讓我藉著你來顯出我的大能，</span><br /><span className="pl pl-1">使我的名傳遍天下。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約書亞記 11:20; 出埃及記 4:21; 羅馬書 9:15–16"> 這樣看來，神要憐憫誰，就憐憫誰；要使誰頑固，就使誰頑固。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="但以理書 4:35; 歷代志下 20:6; 哥林多前書 15:12"> 那麼，你會對我說：「既然如此，神為什麼還要指責人呢？到底誰能抵擋他的旨意呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 29:16; 以賽亞書 45:9–11; 以賽亞書 64:8"> 哦，人哪！你到底是誰，竟然向神頂嘴呢？被造的難道可以對造它的說：「你為什麼把我造成這樣呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 64:8; 箴言 16:4; 提摩太後書 2:20–21"> 難道陶匠沒有權柄從同一團泥中，既造出貴重的器皿，又造出卑賤的器皿嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 猶大書 1:4; 羅馬書 9:21"> 但如果神想要顯出他的震怒，顯明他的能力，就以極大的耐心容忍那些承受震怒的器皿，就是他早已預備要歸於滅亡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="滅亡——或譯作「沉淪」。">g</a></sup>的器皿，那又怎麼樣呢？</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 2:4; 彼得前書 1:2–5; 歌羅西書 1:27"> 再者，如果這是為要將他那榮耀的豐盛顯明在這些得蒙憐憫的器皿，就是他早已預備要歸於榮耀的器皿上，那又怎麼樣呢？</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:11; 使徒行傳 13:47–48; 以弗所書 3:6–8"> 這些器皿就是我們這些蒙召的人：不僅是從猶太人中，也是從外邦人中蒙召的人。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 2:23; 彼得前書 2:10; 約翰福音 16:27"> 正如神在何西阿書上也說：<br /><span className="pl pl-1">「我將要稱那不是我子民的為『我的子民』，</span><br /><span className="pl pl-1">那不蒙愛的為『蒙愛的』。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 1:9–10; 約翰一書 3:1–3; 加拉太書 3:26"> <span className="pl pl-1">從前在什麼地方對他們說</span><br /><span className="pl pl-1">『你們不是我的子民』，</span><br /><span className="pl pl-1">就在那裡，他們將被稱為『永生神的兒女。』 」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 10:20–23; 羅馬書 11:4–6; 以賽亞書 1:9"> 以賽亞論到以色列人，呼喊說：<br /><span className="pl pl-1">「以色列子民的人數雖然多如海沙，</span><br /><span className="pl pl-1">將要得救的卻是剩餘的少數。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 10:23; 啟示錄 19:11; 使徒行傳 17:31"> <span className="pl pl-1">主就是要在地上</span><br /><span className="pl pl-1">徹底、迅速地成就他的話。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 1:9; 以賽亞書 13:19; 阿摩司書 4:11"> 又如以賽亞預先說過：<br /><span className="pl pl-1">「要不是萬軍之主給我們留下後裔，</span><br /><span className="pl pl-1">我們早就變得像所多瑪、格摩拉那樣了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比書 3:9; 希伯來書 11:7; 加拉太書 2:16"> 那麼，我們要怎麼說呢？那原來沒有追求義的外邦人，卻得到了義，就是因信而得的義；</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 11:7; 羅馬書 3:20; 雅各書 2:10–11"> 而以色列人追求律法的義，卻沒有達到律法的義<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="律法的義——有古抄本作「律法」。">h</a></sup>。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 1:23; 彼得前書 2:8; 路加福音 7:23"> 這是為什麼呢？因為他們不是本於信，倒像是本於<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「律法上的」。">i</a></sup>行為去追求的，所以他們就絆倒在那「絆腳的石頭」上。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 28:16; 以賽亞書 8:14–15; 羅馬書 10:11"> 正如經上所記：<br /><span className="pl pl-1">「看哪，我在錫安放一塊絆腳的石頭，</span><br /><span className="pl pl-1">是使人絆倒的磐石；</span><br /><span className="pl pl-1">可是信靠他的人將不至於蒙羞。」</span></span>
</div>
</div>

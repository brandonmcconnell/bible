<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 15:1; 哥林多前書 8:7–13; 哥林多前書 9:22"> 你們要接納在信仰上軟弱的人，避免在有爭議<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="爭議——或譯作「疑惑」。">a</a></sup>的事上辯論。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 4:4; 羅馬書 14:22–23; 羅馬書 14:14"> 雖然有的人相信什麼都可以吃，但那軟弱的人卻只吃蔬菜。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 14:10; 歌羅西書 2:16–17; 路加福音 18:9"> 吃的人不要藐視不吃的人，不吃的人也不要評斷吃的人，因為神已經接納他了。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 4:11–12; 羅馬書 9:20; 羅馬書 8:31–39"> 你到底是誰，竟然評斷別人的僕人？他或站穩或跌倒，是他自己主人的事；而且他會站得住，因為主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="主——有古抄本作「神」。">b</a></sup>能使他站得住。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 2:16–17; 羅馬書 14:23; 加拉太書 4:9–10"> 雖然有的人判定這一天比那一天重要，但有的人卻判定每一天都一樣。每個人當在自己理性上確信不疑。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:30–31; 提摩太前書 4:3–5; 馬太福音 14:19"> 注重某一天的人，是為主而注重的；<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「不注重那一天的人，也是為主而不注重的。」">c</a></sup>吃的人，是為主而吃的，因為他感謝神；不吃的人，也是為主不吃的，他也感謝神。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:2; 哥林多後書 5:15; 哥林多前書 6:19–20"> 我們沒有一個人是為自己而活，也沒有一個人是為自己而死。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 1:20; 帖撒羅尼迦前書 5:10; 哥林多前書 15:23"> 就是說，我們如果活著，是為主而活；如果死了，是為主而死。所以，我們無論是活著，還是死了，總是屬於主。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 1:18; 路加福音 24:26; 希伯來書 12:2"> 正是為此，基督死了，而且復活了，要做死人和活人的主。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:10; 哥林多前書 4:5; 傳道書 12:14"> 至於你，為什麼評斷你的弟兄呢？又為什麼藐視你的弟兄呢？要知道，我們都要站在神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——有古抄本作「基督」。">d</a></sup>的審判臺前，</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 45:22–25; 腓立比書 2:10–11; 詩篇 72:11"> 因為經上記著：<br /><span className="pl pl-1">「主說：我指著我的永生起誓，</span><br /><span className="pl pl-1">萬膝將向我跪下，</span><br /><span className="pl pl-1">萬口將承認神。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:5; 馬太福音 12:36; 馬太福音 16:27"> 由此可見，我們每個人都要把自己的事向神做出交代。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 6:3; 雅各書 4:11; 哥林多前書 8:9–13"> 所以，我們不要再彼此評斷，倒要下定決心，不給弟兄放下絆跌物或絆腳石。</span>
<span className="v" id="v14" data-v="14" data-xref="提多書 1:15; 羅馬書 14:2; 提摩太前書 4:4"> 我知道，並且在主耶穌裡深信：沒有一樣東西本身是不潔淨的。只是，如果有人認為什麼是不潔淨的，對他來說，那就是不潔淨的。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:11–12; 腓立比書 2:2–4; 加拉太書 5:13"> 如果因食物的緣故使你的弟兄憂傷，你就不再是憑著愛行事了。基督已經替他死了，不可因你的食物毀了他。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:17; 帖撒羅尼迦前書 5:22; 哥林多前書 10:29–30"> 所以，不要讓你們看為好的事受到毀謗，</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 6:33; 羅馬書 15:13; 哥林多前書 4:20"> 因為神的國不在於吃喝，而在於聖靈裡的公義、和睦<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="和睦——或譯作「平安」。">e</a></sup>、喜樂。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:21; 哥林多後書 5:11; 彼得前書 2:20"> 要知道，如此服事基督的人，是蒙神喜悅的，也是受人讚許的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所書 4:29; 羅馬書 12:18; 詩篇 34:14"> 這樣看來，我們要追求和睦<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="和睦——或譯作「平安」。">f</a></sup>的事和彼此造就的事。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 14:14–15; 馬太福音 18:6; 提多書 1:15"> 不要因食物的緣故破壞神的工作。一切固然都是潔淨的，但如果有人因吃東西使人絆腳，這就是惡事了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 8:13; 羅馬書 14:13; 羅馬書 15:1–2"> 不在吃肉、喝酒、或其他事上使你的弟兄絆倒，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「或犯罪、或軟弱；」。">g</a></sup>這才是好的。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰一書 3:21; 羅馬書 14:5; 雅各書 3:13"> 你所持有的信念，自己要在神面前持有；在自己認為對的事上不自責的人是蒙福的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 11:6; 提多書 1:15; 哥林多前書 11:29–31"> 但那疑惑的人如果吃了，就被定罪了，因為不是本於信；而一切不是本於信的，就是罪。</span>
</div>
</div>

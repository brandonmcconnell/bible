<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:16; 加拉太書 5:13; 羅馬書 6:15"> 那麼，我們要怎麼說呢？難道我們可以留在罪中，好讓恩典增多嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 3:9; 歌羅西書 3:3; 羅馬書 7:4"> 絕對不可！我們這些向罪已經死了的人，怎麼還能活在罪中呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:27; 加拉太書 2:20–21; 羅馬書 6:8"> 難道你們不明白，所有受洗歸入基督耶穌的人，就是受洗歸入了他的死嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 5:17; 歌羅西書 3:10; 以弗所書 4:22–24"> 所以，我們藉著洗禮歸入死，和他一同埋葬，好使我們也能以生命的新樣式行事為人，就像基督藉著父的榮耀從死人中復活那樣。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 3:10–11; 哥林多後書 4:10; 歌羅西書 2:12"> 就是說，如果我們在基督死的樣式上與他聯合，也將要在他復活的形式上與他聯合。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:20; 以弗所書 4:22; 加拉太書 5:24"> 我們知道，我們的舊我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——原文直譯「人」。">a</a></sup>已經和基督一起被釘十字架，好讓罪的身體被廢除，使我們不再做罪的奴僕，</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:1; 歌羅西書 3:1–3; 羅馬書 7:4"> 因為一個死了的人，已經脫離了罪。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太後書 2:11–12; 歌羅西書 3:3–4; 哥林多後書 4:10–14"> 那麼，如果我們與基督一同死了，就相信也要與他一同活著。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 6:14; 啟示錄 1:18; 使徒行傳 2:24–28"> 我們知道，基督既從死人中復活，就不會再死，死亡再也轄制不了他。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:21; 彼得前書 4:6; 彼得前書 3:18"> 原來他死，是一次性地向罪而死；他活，是向神而活。</span>
<span className="v" id="v11" data-v="11" data-xref="歌羅西書 3:3–5; 哥林多前書 6:20; 羅馬書 6:2"> 照樣，你們就當看自己向罪是死的，但在<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「我們的主」。">b</a></sup>基督耶穌裡向神卻是活的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:16; 羅馬書 6:16; 羅馬書 8:13"> 所以，不要讓罪在你們會死的身體上掌權，使你們順從身體的私慾；</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 12:1; 羅馬書 6:16; 歌羅西書 3:5"> 也不要把你們身體的任何部分<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="身體的任何部分——或譯做「肢體」。">c</a></sup>獻給罪，做不義的器具；相反，要像從死人中復活的人，把自己獻給神，並把身體的各部分做義的器具獻給神。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 5:18; 羅馬書 8:2; 羅馬書 7:4–11"> 這樣，罪就不能轄制你們了，因為你們不在律法之下，而在恩典之下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多書 2:11–14; 以弗所書 2:8–10; 羅馬書 6:1–2"> 那又怎麼樣呢？難道因為我們不在律法之下而在恩典之下，就可以犯罪嗎？絕對不可！</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 8:34; 馬太福音 6:24; 約書亞記 24:15"> 你們難道不知道嗎？你們把自己獻上做奴僕去順從誰，那麼，順從誰就是誰的奴僕：或做罪的奴僕，以至於死；或做順從的奴僕，以致稱義。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 2:9; 提摩太後書 1:13; 羅馬書 1:8"> 感謝神！雖然你們過去是罪的奴僕，但現在卻從心裡順從了所傳給你們的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="傳給你們的——或譯作「交託給你們的」。">d</a></sup>教導內容，</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 6:22; 羅馬書 8:2; 加拉太書 5:1"> 從罪中得了釋放，成為義的奴僕。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 6:13; 彼得前書 4:2–4; 歌羅西書 3:5–7"> 因著你們肉體的軟弱，我就按照人的說法來講，那就是，你們從前怎樣把身體的各部分<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="身體的各部分——或譯作「肢體」。">e</a></sup>獻給汙穢和罪惡<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="罪惡——原文直譯「不法」。">f</a></sup>做奴僕，以致罪惡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="罪惡——原文直譯「不法」。">g</a></sup>；現在也要照樣把你們身體的各部分獻給義做奴僕，以致分別為聖。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 6:16–17; 約翰福音 8:34"> 原來，你們做罪的奴僕時，不受義的管束；</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 1:32; 羅馬書 7:5; 羅馬書 6:23"> 那麼，在你們現在看為羞恥的那些事上，你們當時到底得了什麼果子呢？那些事的結局就是死。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:16; 羅馬書 6:18; 羅馬書 8:2"> 但如今，你們既從罪中得了釋放，成為神的奴僕，就得了果子，以致分別為聖，那結局就是永恆的生命。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 3:36; 羅馬書 5:12; 雅各書 1:15"> 因為罪的工價就是死；但神的恩賜，在我們的主基督耶穌裡，卻是永恆的生命。</span>
</div>

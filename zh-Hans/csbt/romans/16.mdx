<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 16:19; 提摩太後書 4:19; 使徒行傳 18:26"> <span className="pl pl-1">請問候普茜拉和阿奎拉；他們是我在基督耶穌裡的同工。</span></span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 2:30; 約翰一書 3:16; 哥林多前書 16:1"> <span className="pl pl-1">為我的生命，他們將自己的生死置之度外</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="將自己的生死置之度外——原文直譯「冒險自己的脖子」。">b</a></sup><br /><span className="pl pl-1">。不單我感激他們，就是外邦的各教會也都感激他們。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 4:15; 腓利門書 1:2; 哥林多前書 16:19"> <span className="pl pl-1">請問候在他們家裡的教會。</span><br /><span className="pl pl-1">請問候我親愛的以佩尼托，他是亞細亞省歸入基督的初熟果子。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 16:12; 馬太福音 27:55; 提摩太前書 5:10"> <span className="pl pl-1">請問候瑪麗亞，她為你們</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你們——有古抄本作「我們」。">c</a></sup><br /><span className="pl pl-1">多多勞苦。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 16:11; 羅馬書 16:21; 腓利門書 1:23"> <span className="pl pl-1">請問候與我一起坐過牢的同胞安德羅尼克和猶尼亞，他們在使徒中有名望，也比我先成為在基督裡的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:1; 約翰一書 3:14; 羅馬書 16:5"> <span className="pl pl-1">請問候在主裡我親愛的安普利亞托。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 16:2–3; 羅馬書 16:21"> <span className="pl pl-1">請問候歐巴諾，他是我們在基督裡的同工，也問候我親愛的斯塔庫斯。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 14:18; 彼得前書 1:7; 申命記 8:2"> <span className="pl pl-1">請問候阿比利斯，他在基督裡經過了考驗。</span><br /><span className="pl pl-1">請問候亞利多布家裡的人。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 16:21; 羅馬書 16:7"> <span className="pl pl-1">請問候我的同胞希羅迪恩。</span><br /><span className="pl pl-1">請問候納吉蘇家中在主裡的人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:12–13; 希伯來書 6:10–11; 哥林多前書 15:58"> <span className="pl pl-1">請問候在主裡勞苦的特魯菲娜和特魯弗薩。</span><br /><span className="pl pl-1">請問候親愛的佩西絲，她在主裡多多勞苦。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 15:21; 提摩太前書 5:2; 約翰二書 1:1"> <span className="pl pl-1">請問候在主裡蒙揀選的魯弗斯和他的母親，對我來說他的母親就是我的母親。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:2; 羅馬書 8:29; 希伯來書 3:1"> <span className="pl pl-1">請問候阿森克里托、弗勒貢、赫米斯、帕特羅巴、赫馬斯，以及與他們在一起的弟兄們。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:2; 羅馬書 1:7; 羅馬書 16:14"> <span className="pl pl-1">請問候非羅羅古和猶莉婭，尼利亞和他的妹妹</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="妹妹——原文直譯「姐妹」。">d</a></sup><br /><span className="pl pl-1">，以及奧林帕斯，還有與他們在一起的所有聖徒。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 5:26; 哥林多前書 16:20; 哥林多後書 13:12"> <span className="pl pl-1">你們要用聖潔的親吻禮彼此問候。</span><br /><span className="pl pl-1">基督的各教會都問候你們。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="猶大書 1:19; 帖撒羅尼迦後書 3:6; 提摩太前書 6:3–5"> 弟兄們，我勸你們，要留心那些針對你們所受的教導而製造分裂和絆腳石的人。你們要遠離他們。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 2:4; 馬太福音 7:15; 提摩太前書 6:5"> 因為這樣的人不是服事我們的主基督<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="基督——有古抄本作「耶穌基督」。">e</a></sup>，而是服事自己的私慾<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="私欲——原文直譯「肚腹」。">f</a></sup>。他們用花言巧語，欺騙單純人的心。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 10:16; 哥林多前書 14:20; 腓立比書 2:15"> 你們的順從，大家都知道了，所以我為你們而歡喜。但我希望你們在善事上有智慧，在惡事上無知<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="無知——或譯作「天真」或「純潔」。">g</a></sup>。</span>

</div>

<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:4; 使徒行傳 17:5; 使徒行傳 13:1"> 我的同工提摩太和我的同胞盧吉斯、耶森、索西巴特都問候你們。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="加拉太書 6:11; 哥林多前書 16:21; 羅馬書 16:8"> 代筆寫這書信的我——特提烏斯，在主裡問候你們。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 1:14; 使徒行傳 19:22; 提摩太後書 4:20"> 那接待我，也接待全教會的蓋尤斯問候你們。本城的財務官以拉斯托和弟兄庫爾托斯問候你們。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 願我們主耶穌基督的恩典與你們大家同在！阿們。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有此節。">i</a></sup></span>
</div>

<span className="v" id="v26" data-v="26" data-xref="羅馬書 1:5; 加拉太書 3:8; 羅馬書 15:18"> 然而如今已經得以顯現；並且按照永恆神的命令，藉著先知們的經文顯明了出來。這是為要在萬民中帶來信仰上的順從——</span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前書 1:17; 羅馬書 11:36; 啟示錄 7:10–12"> 願榮耀，藉著耶穌基督，歸於這位獨一全智的神，直到永遠！阿們。<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="-27 有些古抄本在此節和在本書14:23之後附本章25-27節的經文；有些只在14:23之後附25-27節的經文；有些只在15:33之後附25-27節的經文；有些則沒有25-27節的經文。">j</a></sup></span>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:22; 撒母耳記上 12:22; 腓立比書 3:5"> 那麼，我要問，難道神棄絕了他的子民嗎？絕對沒有！其實我也是以色列人，亞伯拉罕的後裔，屬於便雅憫支派。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 94:14; 羅馬書 8:29–30; 出埃及記 32:1"> 神並沒有棄絕自己預先所知道的子民。難道你們不知道那有關以利亞的經文怎麼說嗎？他怎樣向神抱怨以色列人呢？</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:10–18; 列王紀上 18:13; 尼希米記 9:26"> <span className="pl pl-1">「主啊，他們殺了你的先知們，拆毀了你的祭壇，</span><br /><span className="pl pl-1">只剩下我一個人，他們還要追索我的命。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 19:18; 民數記 25:3; 西番雅書 1:4"> 但神對他的答覆是怎麼說的呢？「我為自己保留了七千人，他們是沒有向巴力屈膝的。」</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 9:27; 以弗所書 1:5–6; 羅馬書 9:11"> 照樣，在現今的時刻也有剩餘的少數，就是藉著恩典蒙揀選的人。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:21; 羅馬書 4:4–5; 提摩太後書 1:9"> 既然藉著恩典，就不再本於行為了；否則，恩典就不再是恩典了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「但如果是本於行為，就不再是恩典了；否則，行為就不再是行為了。」">a</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:18; 羅馬書 11:5; 哥林多後書 4:4"> 所以怎麼樣呢？以色列人並沒有獲得他們所尋求的，蒙揀選的人卻獲得了，而其餘的人都成了剛硬的，</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:4; 以賽亞書 29:10; 以西結書 12:2"> 正如經上所記：<br /><span className="pl pl-1">「神給了他們昏迷的心靈、</span><br /><span className="pl pl-1">看不見的眼睛、聽不見的耳朵，</span><br /><span className="pl pl-1">直到今天。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 69:22–23; 路加福音 12:20; 詩篇 28:4"> 大衛也說：<br /><span className="pl pl-1">「讓他們的筵席成為網羅、陷阱、絆腳石，</span><br /><span className="pl pl-1">又成為他們的報應。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 69:23; 申命記 28:64–68; 彼得後書 2:4"> <span className="pl pl-1">讓他們的眼睛昏暗不能看。</span><br /><span className="pl pl-1">讓他們的腰背永遠彎曲。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 13:46–48; 羅馬書 11:31; 羅馬書 10:19"> 所以我要問，難道以色列人跌倒了，是要他們敗落嗎？絕對不是！相反，因他們的過犯，救恩就臨到了外邦人，為要激起以色列人的嫉妒之心。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:25; 歌羅西書 1:27; 羅馬書 11:15"> 既然他們的過犯能使世人富足，他們的失敗能使外邦人富足，更何況他們的全數滿足呢！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 9:15; 提摩太後書 1:11–12; 以弗所書 3:8"> 現在我向你們外邦人說話：既然我確實是外邦人的使徒，我就以我的服事工作為榮耀，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 7:16; 提摩太前書 4:16; 羅馬書 9:3"> 或許激起我同胞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同胞——原文直譯「肉體」。">b</a></sup>的嫉妒之心，好拯救他們中的一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 1:10; 羅馬書 5:10–11; 歌羅西書 1:20–21"> 實際上，如果他們被丟棄，使世人與神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="與神——輔助詞語。">c</a></sup>和好了，那麼他們蒙接納，如果不是從死人中復生，又是什麼呢？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 44:30; 雅各書 1:18; 箴言 3:9"> 如果初熟的麥子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="初熟的麥子——原文直譯「初熟的果子」。">d</a></sup>是聖潔的，那麵團也就聖潔了；如果樹根是聖潔的，那樹枝也就聖潔了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以弗所書 2:11–13; 以弗所書 3:6; 馬太福音 21:43"> 但如果有些樹枝被折下來，而你這野橄欖枝被接在其上，並且一同有份於那橄欖樹根的豐富養分，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:12; 羅馬書 11:20; 以弗所書 2:19–20"> 那麼你就不應該向那些樹枝自誇了。而就算你自誇，也不是你托著樹根，而是樹根托著你。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 11:17; 羅馬書 11:11–12; 羅馬書 11:23–24"> 這樣，你會說：「那些樹枝被折下來，就是要我能被接上去。」</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:16; 哥林多後書 1:24; 哥林多前書 10:12"> 不錯！他們因不信被折了下來，而你因信已經站立得住；你不可心高氣傲，反要懼怕；</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:4–9; 耶利米書 25:29; 耶利米書 49:12"> 因為神如果沒有顧惜原生的樹枝，恐怕也不會顧惜你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 3:14; 希伯來書 3:6; 哥林多前書 15:2"> 所以看哪！神的仁慈和嚴厲——對墮落的人，神一定是嚴厲的，但是對你，如果你留在他的仁慈中，神就是仁慈的；否則，你也將被砍下來。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 3:16; 撒迦利亞書 12:10; 馬太福音 23:39"> 而且，那些被折下來的樹枝<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="那些被折下來的樹枝——原文直譯「他們」。">e</a></sup>如果不再堅持不信，也將被接上，因為神能夠把他們重新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:17–18; 羅馬書 11:30"> 要知道，如果你從天然的野橄欖樹上被砍下來，尚且能違反自然、被接在栽培的橄欖樹上，何況那些原生的樹枝<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="樹枝——輔助詞語。">f</a></sup>，難道不更能接在自己的橄欖樹上嗎？</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多後書 3:14–16; 羅馬書 16:25"> 弟兄們，我不願意你們不明白這奧祕，免得你們自以為聰明。這奧祕就是：以色列人中的部分人變得剛硬，直到外邦人的全數滿足了，</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 59:20; 耶利米書 31:31–37; 詩篇 14:7"> 以色列全家才會得救，正如經上所記：<br /><span className="pl pl-1">「一位拯救者將從錫安而來，</span><br /><span className="pl pl-1">他要從雅各除去不敬神的心，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 31:31–34; 以賽亞書 59:21; 以西結書 36:25–29"> <span className="pl pl-1">這就是我的約——</span><br /><span className="pl pl-1">當我除去他們罪孽的時候，所給他們的約。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 10:15; 申命記 7:7–8; 馬太福音 21:43"> 就福音而言，他們因你們的緣故，固然是神的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="神的——輔助詞語。">g</a></sup>敵人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="敵人——或譯作「反對者」。">h</a></sup>；但就揀選而言，他們因祖先的緣故，卻是蒙愛的，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 7:21; 民數記 23:19; 瑪拉基書 3:6"> 因為神的恩賜和召喚是不撤回的<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="不撤回的——或譯作「不反悔的」。">i</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 3:7; 以弗所書 2:1–2; 哥林多前書 7:25"> 正如你們以前不肯信從神而現在卻因他們的不信從反而蒙了憐憫；</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 11:15; 羅馬書 10:16; 羅馬書 11:25"> 照樣，他們如今也不肯信從，為要藉著你們所蒙的憐憫，讓他們現在<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「現在」。">j</a></sup>也可以蒙憐憫，</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太書 3:22; 羅馬書 3:9; 提摩太前書 2:4–6"> 因為神把所有的人都圈在不信從之中，是為了要憐憫所有的人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="約伯記 5:9; 約伯記 11:7–9; 詩篇 92:5"> <span className="pl pl-1">哦，深奧啊！神的智慧和知識的財富！</span><br /><span className="pl pl-1">他的判斷是多麼地無法探究，</span><br /><span className="pl pl-1">他的道</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="道——或譯作「路」。">k</a></sup><br /><span className="pl pl-1">是多麼地無法測度！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 40:13; 哥林多前書 2:16; 約伯記 15:8"> <span className="pl pl-1">「到底是誰知道主的心意？</span><br /><span className="pl pl-1">是誰做過他的謀士？</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 41:11; 約伯記 35:7; 哥林多前書 4:7"> <span className="pl pl-1">又是誰首先給了主，</span><br /><span className="pl pl-1">使自己將來得到回報呢？ 」</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歌羅西書 1:15–17; 哥林多前書 8:6; 希伯來書 2:10"> <span className="pl pl-1">因為萬有都是出於他、藉著他、歸於他。</span><br /><span className="pl pl-1">願榮耀歸於他，直到永遠！阿們。</span></span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 2:25–29; 創世記 25:32; 傳道書 6:11"> 這樣說來，猶太人有什麼優越呢？割禮有什麼益處呢？</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 9:4; 使徒行傳 7:38; 哥林多前書 9:17"> 在各方面都有很多。首要的，是神的話語確實委託給他們了。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 2:13; 希伯來書 4:2; 羅馬書 9:6"> 即使他們中有些人不信，到底又怎麼樣呢？難道他們的不信會使神的信實無效嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 51:4; 詩篇 116:11; 加拉太書 2:17"> 絕對不會！即使每個人都是說謊者，神還是真實的。正如經上所記：<br /><span className="pl pl-1">「這樣，你說話的時候，顯為公義；</span><br /><span className="pl pl-1">被評斷的時候，必然得勝。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 6:19; 加拉太書 3:15; 羅馬書 9:18–20"> 但是，如果我按人的意思來說，我們的不義可以顯明神的義，那我們要怎麼說呢？難道降震怒的神是不公正的嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:25; 使徒行傳 17:31; 約伯記 8:3"> 絕對不是！否則，神怎麼能審判世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:4; 羅馬書 9:19–20; 使徒行傳 13:27–29"> 那麼，如果神的真實因我的虛謊使他的榮耀更加豐盛，為什麼我還要像罪人一樣被定罪呢？</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 6:1; 羅馬書 6:15; 羅馬書 5:20"> 這樣，為什麼不說「讓我們作惡好帶來善」呢？——我們正是如此受到毀謗，也有些人說過我們講了這話——這些人被定罪倒是應該的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:22; 羅馬書 6:15; 以賽亞書 65:5"> 那麼怎麼樣呢？我們猶太人比別人好嗎？當然不是！我們已經指出：猶太人和外邦人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="外邦人——原文直譯「希臘人」；指「希臘文化區的非猶太人」。">a</a></sup>都在罪孽之下。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 53:1–3; 詩篇 14:1–3; 羅馬書 3:23"> 正如經上所記：<br /><span className="pl pl-1">「沒有義人，連一個也沒有；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 14:2–4; 詩篇 53:2; 提多書 3:3"> <span className="pl pl-1">沒有領悟的，</span><br /><span className="pl pl-1">沒有尋求神的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 14:3; 傳道書 7:20; 以賽亞書 64:6"> <span className="pl pl-1">人人都遠離了正道，</span><br /><span className="pl pl-1">一同成了無用的；</span><br /><span className="pl pl-1">沒有仁慈的，</span><br /><span className="pl pl-1">連一個也沒有。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 5:9; 詩篇 140:3; 馬太福音 23:27–28"> <span className="pl pl-1">他們的喉嚨是敞開的墳墓，</span><br /><span className="pl pl-1">他們用舌頭玩弄詭詐，</span><br /><span className="pl pl-1">他們的嘴唇含有蛇毒，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 10:7; 詩篇 109:17–18; 詩篇 59:12"> <span className="pl pl-1">他們滿口是咒罵和苦毒，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">他們的腳步為殺人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="殺人——輔助詞語。">b</a></sup><br /><span className="pl pl-1">流血而飛快，</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">他們的路上只有毀滅和慘禍；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 59:8; 羅馬書 5:1; 路加福音 1:79"> <span className="pl pl-1">和平之路</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="和平之路——或譯作「平安之路」。">c</a></sup><br /><span className="pl pl-1">，他們從來不知道。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">他們的眼目中沒有對神的敬畏。 」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太書 3:10; 加拉太書 3:22–23; 羅馬書 2:12–18"> 我們知道，律法上的一切話都是對律法之下的人講的，好堵住每個人的口，使全世界的人都在神的審判之下有罪，</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 2:16; 使徒行傳 13:39; 羅馬書 3:28"> 因為沒有一個人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="人——原文直譯「肉體」。">d</a></sup>本於律法上的行為在神面前被稱為義；原來，藉著律法，只能對罪有真正的認識。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 10:43; 耶利米書 33:16; 腓立比書 3:9"> 但如今，神的義已經在律法之外顯明出來，被律法和先知們所見證，</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 10:12; 加拉太書 3:28; 羅馬書 8:1"> 那就是：神的義藉著對耶穌基督的信仰<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="藉著對耶穌基督的信仰——或譯作「由於耶穌基督的信實」。">e</a></sup>，臨到所有信的人，並沒有分別。</span>
<span className="v" id="v23" data-v="23" data-xref="傳道書 7:20; 約翰一書 1:8–10; 羅馬書 3:9"> 要知道，每個人都犯了罪，虧缺了神的榮耀；</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 1:18–19; 提多書 3:5–7; 歌羅西書 1:14"> 但藉著神的恩典，藉著在基督耶穌裡的救贖，卻無償地被稱為義。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 3:23–24; 彼得前書 1:18–20; 約翰一書 4:10"> 神預先定下耶穌為平息祭<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="平息祭——或譯作「挽回祭」。">f</a></sup>，是用耶穌的血、藉著人的信，為要顯明神自己的義；因為他用忍耐的心，寬容人過去所犯的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:4; 羅馬書 4:5; 羅馬書 3:30"> 為了在現今的時刻顯明他的義，好表明他自己為義，也稱信耶穌的人為義。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="羅馬書 4:2; 羅馬書 2:23; 哥林多前書 1:29–31"> 既然如此，還有什麼可誇耀的呢？根本沒有。憑著什麼法則呢？憑著行為的法則嗎？不是！而是憑著信的法則。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 2:16; 加拉太書 3:8; 提多書 3:7"> 就是說，我們認為：人被稱為義，是藉著信，與律法上的行為無關。</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 3:11; 以弗所書 3:6; 撒迦利亞書 2:11"> 難道神只是猶太人的神嗎？不也是外邦人的神嗎？是的，他也是外邦人的神，</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太書 3:8; 加拉太書 3:20; 腓立比書 3:3"> 既然神真是一位；他要使受割禮的人因信稱義，也要使沒有受割禮的人因信稱義。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 2:21; 馬太福音 5:17; 羅馬書 13:8–10"> 那麼，我們是藉著信廢掉律法嗎？絕對不是！反而確立了律法。</span>
</div>
</div>

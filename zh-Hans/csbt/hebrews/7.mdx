<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:18–20; 詩篇 57:2; 希伯來書 6:20"> 原來這麥基洗德——<br /><span className="pl pl-1">撒冷之王，至高神的祭司，</span><br /><span className="pl pl-1">在亞伯拉罕殺敗眾王回來的時候，去迎接他、祝福他，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民數記 18:21; 詩篇 85:10–11; 撒母耳記上 8:17"> <span className="pl pl-1">亞伯拉罕就從所得來的一切中，把十分之一獻給</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="獻給——原文直譯「分給」。">a</a></sup><br /><span className="pl pl-1">他。</span><br /><span className="pl pl-1">「麥基洗德」翻譯出來，首先是「公義之王」，</span><br /><span className="pl pl-1">然後又是「撒冷之王」——這意思是「和平之王」。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 7:17; 希伯來書 7:23–28; 出埃及記 6:20–27"> <span className="pl pl-1">他沒有父親，沒有母親，沒有族譜，</span><br /><span className="pl pl-1">沒有年歲的開始，也沒有生命的終結，</span><br /><span className="pl pl-1">與神的兒子相似，持久做祭司，直到永遠。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 14:20; 使徒行傳 2:29; 使徒行傳 7:8–9"> 你們當想一想，這個人多麼偉大！連先祖亞伯拉罕也從最好的戰利品中把十分之一獻給他。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 27:30–33; 歷代志下 31:4–6; 民數記 18:21–32"> 雖然利未子孫中那些領受祭司職務的，從亞伯拉罕的後裔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="後裔——原文直譯「腰」。">b</a></sup>中出來，他們還是奉命按照律法向子民，就是自己的同胞<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="同胞——原文直譯「兄弟」。">c</a></sup>，收取十分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 4:13; 希伯來書 7:3–4; 創世記 13:14–17"> 可是，不出於利未世系的那一位，卻從亞伯拉罕收取了十分之一，並且祝福了那擁有各樣應許的亞伯拉罕。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 30:27; 創世記 48:15–20; 提摩太前書 3:16"> 原來，位分小的從位分大的接受祝福，是毫無爭議的事。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 6:20; 希伯來書 5:6; 啟示錄 1:18"> 在這裡，收取十分之一的人們固然都會死去；但在那裡，他卻被見證說是永生的。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 5:12; 創世記 14:20; 希伯來書 7:4"> 甚至從某種意義上可以說：連那收取十分之一的利未，也藉著亞伯拉罕交納了十分之一，</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 35:11; 希伯來書 7:5; 創世記 46:26"> 因為麥基洗德迎接亞伯拉罕的時候，利未還在他先祖的身體<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="身體——原文直譯「腰」。">d</a></sup>裡面。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯來書 8:7; 加拉太書 2:21; 加拉太書 4:9"> 既然如此，如果藉著利未人的祭司職份能達到完全——子民本來在這職份下領受了律法——那麼，為什麼還需要照著麥基洗德的等級<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="等級——或譯作「體系」。">e</a></sup>，而不照著所謂「亞倫的等級」興起另一位祭司呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 31:31–34; 以賽亞書 66:21; 以西結書 16:61"> 祭司職份被更換，律法也必須有所更換。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 7:11; 希伯來書 7:14; 民數記 17:5"> 其實這些話所論到的那一位是屬於別的支派，這支派中從來沒有人在祭壇供過職；</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 5:2; 以賽亞書 11:1; 路加福音 3:33"> 就是說，我們的主明顯是從猶大支派<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="支派——輔助詞語。">f</a></sup>興起的，而對於這個支派，摩西從來沒有提到有關祭司<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="祭司——有古抄本作「祭司職份」。">g</a></sup>的事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="詩篇 110:4; 希伯來書 7:17–21; 希伯來書 7:3"> 如果照著麥基洗德的相同樣式另有一位祭司興起來，那麼，這件事就更加明顯了。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 1:18; 歌羅西書 2:20; 希伯來書 7:28"> 他成為祭司，不是照著有關肉體條例的法則，而是照著那不能毀滅的生命大能，</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 110:4; 希伯來書 5:6; 希伯來書 7:21"> 因為他被見證說：<br /><span className="pl pl-1">「你是照著麥基洗德的等級</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="等級——或譯作「體系」。">h</a></sup><br /><span className="pl pl-1">做祭司，直到永遠。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:3; 使徒行傳 13:39; 加拉太書 4:9"> 原來，一方面，先前的條例因著本身的軟弱和無用，就被廢棄了，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 13:39; 希伯來書 4:16; 希伯來書 9:9"> 因為律法沒有使任何事物完全；另一方面，一個更美好的盼望卻被帶來了；藉著這個盼望，我們可以親近神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="民數記 18:7; 希伯來書 5:6; 詩篇 110:4"> 再者，所發生的事並不是沒有神的<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的——輔助詞語。">i</a></sup>誓言保證。就是說，其他人成為祭司是沒有誓言保證的，</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 110:4; 希伯來書 7:17; 希伯來書 6:16–18"> 可是耶穌<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶穌——原文直譯「他」。">j</a></sup>藉著對他說話的那一位是有誓言保證的：<br /><span className="pl pl-1">「主起了誓，不會後悔：</span><br /><span className="pl pl-1">『你是</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附「照著麥基洗德的等級做」。">k</a></sup><br /><span className="pl pl-1">祭司，直到永遠。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 11:25; 創世記 44:32; 希伯來書 8:6–12"> 既然如此，耶穌也就成了更美好之約的保證人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米記 12:10–11; 歷代志上 6:3–14; 希伯來書 7:8"> 那些以前成為祭司的固然人數眾多，因為死亡阻止了他們繼續留任，</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 12:34; 希伯來書 7:28; 以賽亞書 9:6–7"> 但由於耶穌永遠長存，就擁有永恆不變的祭司職份；</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 8:34; 約翰一書 2:1–2; 提摩太前書 2:5"> 故此，他也能徹底<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="徹底——或譯作「永遠」。">l</a></sup>拯救那些藉著他來到神面前的人；因為他一直活著，為他們代求。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 5:21; 希伯來書 4:14–15; 彼得前書 2:22"> 這樣一位聖潔、沒有邪惡、毫無玷汙、與罪人分開、高過諸天的大祭司，對我們實在是合宜的。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 9:28; 希伯來書 9:12; 希伯來書 9:14"> 他不需要像其他大祭司那樣天天獻祭：先為自己的罪孽，然後為子民；因為當他把自己獻上的時候，就一次性地把這事完成了。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:10; 希伯來書 7:21; 希伯來書 1:2"> 律法委任的大祭司都有軟弱，但在律法以後，誓言保證的話語所委任的兒子，卻永遠完全。</span>
</div>
</div>

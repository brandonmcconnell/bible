<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 1:20–21; 約珥書 2:28; 民數記 12:6–8"> 過去，神在不同的時代，用不同的方式，藉著先知們對祖先說話，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 1:3; 哥林多前書 8:6; 歌羅西書 1:16–18"> 但在末後的這些日子裡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在末後的這些日子裡——或譯作「在這些日子的末後」。">a</a></sup>，神藉著他的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他的——輔助詞語。">b</a></sup>兒子向我們說話。神預定了他為萬有的繼承人，也藉著他造了宇宙<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="宇宙——或譯作「各世代」。">c</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 1:15–17; 啟示錄 4:11; 約翰福音 14:9–10"> 他是神榮耀的光輝，是神本體的真像，以自己大能的話語托住萬有。他成就了潔淨罪孽的事<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他成就了潔淨罪孽的事——有古抄本作「他藉著自己成就了潔淨我們罪孽的事」。">d</a></sup>，就坐在高天至尊者的右邊。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 1:21; 腓立比書 2:9–11; 彼得前書 3:22"> 他遠比天使更美好，就像他所繼承的名比天使的名更尊貴。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 2:7; 使徒行傳 13:33; 希伯來書 5:5"> 從前神到底對哪一位天使說過「你是我的兒子，我今天生了你」，又說「我將成為他的父親，他成為我的兒子」呢？</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:7; 歌羅西書 1:18; 申命記 32:43"> 不過當神再次帶領長子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="長子——原文直譯「首生者」。">e</a></sup>進入世界的時候卻說：「神所有的天使都當敬拜他。」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 104:4; 希伯來書 1:14; 列王紀下 6:17"> 關於天使，他確實說：<br /><span className="pl pl-1">「神使他的天使為風，</span><br /><span className="pl pl-1">使他的僕役為烈火。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:6–7; 以賽亞書 9:6–7; 耶利米書 23:5–6"> 但是關於兒子，他卻說：<br /><span className="pl pl-1">「神哪，你的寶座是永永遠遠的；</span><br /><span className="pl pl-1">你國度的權杖是正義的權杖。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 45:7; 詩篇 23:5; 以賽亞書 61:3"> <span className="pl pl-1">你愛公義，恨罪惡</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="罪惡——原文直譯「不法」。">f</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">為此，神——你的神用喜樂的油來膏立你，</span><br /><span className="pl pl-1">而不膏立你的同伴。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:25–27; 創世記 1:1; 約翰福音 1:1–3"> 他又說：<br /><span className="pl pl-1">「主啊，你在起初立定了大地的根基，</span><br /><span className="pl pl-1">諸天也是你手所造的。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 51:6; 馬可福音 13:31; 路加福音 21:33"> <span className="pl pl-1">天地</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="天地——原文直譯「它們」。">g</a></sup><br /><span className="pl pl-1">將要毀滅，你卻繼續存留；</span><br /><span className="pl pl-1">天地都要像衣服那樣漸漸破舊。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 102:26–27; 希伯來書 13:8; 約翰福音 8:58"> <span className="pl pl-1">你將要把天地像外衣那樣捲起來，</span><br /><span className="pl pl-1">天地也要像衣服那樣</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「像衣服那樣」。">h</a></sup><br /><span className="pl pl-1">被更換；</span><br /><span className="pl pl-1">你卻永不改變，</span><br /><span className="pl pl-1">你的歲月沒有窮盡。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:1; 馬可福音 12:36; 馬太福音 22:44"> 從前神到底對哪一位天使說過：<br /><span className="pl pl-1">「你坐在我的右邊，</span><br /><span className="pl pl-1">等我把你的敵人放在你的腳下做腳凳」 呢？</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 34:7; 詩篇 103:20–21; 詩篇 91:11–12"> 難道所有的天使不都是服事的靈、奉差派服事那些將要繼承救恩的人嗎？</span>
</div>

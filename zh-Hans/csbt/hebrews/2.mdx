<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:15; 彼得後書 1:12–13; 箴言 7:1–2"> 因此，我們必須更加留心所聽過的事，免得隨流漂去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:53; 加拉太書 3:19; 希伯來書 10:28"> 要知道，那藉著天使所說的話既然是確定的，連一切過犯和悖逆都受到了應得的報應，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 10:28–29; 希伯來書 12:25; 希伯來書 5:9"> 那麼，如果我們忽視了如此偉大的救恩，又怎麼能逃脫報應呢？這救恩起初由主傳講，後來由那些聽見的人向我們證實。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:3; 以弗所書 1:5; 馬可福音 16:20"> 神又照著自己的旨意，用神蹟、奇事和各種大能，以及聖靈的各種恩賜，與他們一同見證。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="啟示錄 11:15; 彼得後書 3:13; 希伯來書 6:5"> 事實上，我們所說的那「將要來的世界」，神並沒有使它服從天使，</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 8:4–8; 詩篇 144:3; 約伯記 7:17–18"> 但是有人在經上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在經上——輔助詞語。">a</a></sup>某處鄭重地見證說：<br /><span className="pl pl-1">「人算什麼，你竟然顧念他？</span><br /><span className="pl pl-1">人之子算什麼，你竟然照顧他？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 8:5; 腓立比書 2:6–7"> <span className="pl pl-1">你使他暫時比天使低微</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="暫時比天使低微——或譯作「比天使低微一點」。">b</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">你賜他榮耀和尊貴為冠冕；</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「你也委任他統管你手所造的；」。">c</a></sup><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 13:3; 哥林多前書 15:27; 詩篇 8:6"> <span className="pl pl-1">你使萬有都服從在他的腳下。」</span><br />既然神使萬有都服從他，就沒有留下一樣不服從他；但如今，我們還沒有看見萬有都服從他。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 2:7–9; 啟示錄 5:9; 約翰一書 4:9–10"> 不過我們看見的是：那暫時比天使低微的耶穌，因著死亡的痛苦被賜予榮耀和尊貴為冠冕，好使他藉著神的恩典，替所有的人嘗了死的滋味。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 11:36; 使徒行傳 5:31; 路加福音 24:46"> 萬有因他而有、萬有藉他而成的那一位，既然要帶領許多兒女歸於榮耀，就藉著苦難使他們救恩的元首<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="元首——或譯作「創始者」。">d</a></sup>得以成全，這是合宜的，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 10:10; 希伯來書 13:12; 希伯來書 10:14"> 因為那使人分別為聖的，和那些被分別為聖的，都是出於同一位。因這理由，他稱他們為弟兄，並不以為恥。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 22:22; 詩篇 40:10; 約翰福音 18:20"> 他說：<br /><span className="pl pl-1">「我要向我的弟兄們宣揚你的名，</span><br /><span className="pl pl-1">我要在會眾面前歌頌你。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 8:17–18; 以賽亞書 12:2; 詩篇 91:2"> 他又說：「我要依靠他。」還說：「看哪，我和神所賜給我的孩子們都在這裡<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="都在這裡——輔助詞語。">e</a></sup>！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提摩太後書 1:10; 羅馬書 8:3; 歌羅西書 2:15"> 所以，孩子們既然同屬血肉之體，他也照樣同有一樣的血肉之體，為要藉著死亡來廢除那掌握死亡權勢的——就是魔鬼，</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 8:15; 提摩太後書 1:7; 路加福音 1:74–75"> 並且釋放那些因怕死而終生被束縛為奴役的人。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 3:29; 加拉太書 3:16; 羅馬書 4:16–25"> 顯然，他並不是要救拔天使，而是救拔亞伯拉罕的後裔。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:14–2; 腓立比書 2:7–8; 希伯來書 2:14"> 故此，他必須在各方面都像他的弟兄們那樣，為要在屬神的事上成為憐憫人的、忠心<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="忠心——或譯作「信實」。">f</a></sup>的大祭司，好為子民的罪孽獻上平息祭<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="平息祭——或譯作「挽回祭」。">g</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:13; 希伯來書 4:15–16; 猶大書 1:24"> 既然他自己在被試探的時候受了苦，他就能幫助那些受試探的人。</span>
</div>

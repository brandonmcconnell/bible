<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 4:7; 哥林多前書 9:24–27; 腓立比書 2:16"> 因此，我們既然有這麼一大群見證人，如同雲彩圍繞著我們，就讓我們脫去各樣的重擔和容易纏累我們的罪，藉著忍耐去跑那擺在我們前面的賽程，</span>
<span className="v" id="v2" data-v="2" data-xref="彌迦書 7:7; 彼得前書 3:18; 彼得前書 2:23–24"> 仰望信仰的創始者和成終者耶穌。他為了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="為了——或譯作「替換」。">a</a></sup>那擺在他前面的喜樂，就輕看羞辱，忍受了十字架，如今坐在神寶座的右邊。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="加拉太書 6:9; 哥林多後書 4:16; 啟示錄 2:3"> 其實，你們應當仔細地思想耶穌如何忍受了罪人的頂撞，這樣你們心裡<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="心裡——或譯作「靈魂」。">b</a></sup>就不會因喪氣而疲倦。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:13; 啟示錄 2:13; 希伯來書 10:32–34"> 你們與罪爭戰，還沒有抵抗到流血的地步。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; 約伯記 5:17–18; 啟示錄 3:19"> 難道你們已經忘記那安慰的話嗎？就是他對你們如同對兒女那樣講論的話：<br /><span className="pl pl-1">「我兒，你不可輕看主的管教；</span><br /><span className="pl pl-1">被他責備的時候，也不可喪氣。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 3:19; 箴言 3:12; 詩篇 119:75"> <span className="pl pl-1">因為主所愛的人，主都管教；</span><br /><span className="pl pl-1">他所接納的每一個兒子，他都鞭打。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命記 8:5; 箴言 13:24"> 對管教的事，你們要忍受；神對待你們，就像對待兒女那樣。到底哪一個兒子不受父親的管教呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 12:6; 彼得前書 5:9–10; 詩篇 73:1"> 大家都有份受管教；你們如果沒有受管教，那麼，你們就是私生子，不是兒子了。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 16:22; 民數記 27:16; 以賽亞書 42:5"> 再者，我們有肉身的父親來管教我們，我們尚且敬重他們，何況對這位萬靈之父，我們難道不更要服從他而活著嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 1:4; 利未記 11:44–45; 提多書 2:14"> 肉身的父親在短暫的日子裡，固然照著自己的意思來管教我們；但萬靈之父是為了我們的益處管教我們，好使我們在他的聖潔上有份。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:3–5; 哥林多後書 4:17; 希伯來書 12:5–6"> 不過所有的管教，當時雖然不覺得是愉快的事，反覺得是憂傷的事，而後來卻為那些由此受到操練的人，結出平安和義行的果子。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 35:3; 希伯來書 12:3; 帖撒羅尼迦前書 5:14"> 因此，你們要把發軟的手、發痠的腿伸直吧！</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; 以賽亞書 35:3; 加拉太書 6:1"> 也要為你們的腳把道路修直<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="修直——或譯作「修平」。">c</a></sup>，好使瘸腿的不至扭腳<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="扭腳——或譯作「偏離」或「被人避開」。">d</a></sup>，反得痊癒。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 7:1; 彼得前書 1:15–16; 帖撒羅尼迦前書 4:7"> 你們要追求與眾人和睦，要追求聖潔。任何不聖潔的人，都不能見到主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:12; 申命記 29:18; 加拉太書 5:4"> 你們要謹慎，免得有人虧缺了神的恩典；免得有苦毒的根長起來攪擾你們，使許多人因此被汙穢了；</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 25:31–34; 哥林多前書 6:15–20; 啟示錄 22:15"> 又免得有淫亂的，或像以掃那樣不敬神的。以掃為了<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="為了——或譯作「替換」。">e</a></sup>一點食物，就把自己長子的名份賣了；</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; 馬太福音 25:11–12; 馬太福音 7:23"> 你們知道，後來他想繼承祝福，卻被棄絕了，雖然他流著淚水尋求，還是找不到悔改的機會。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 4:11; 出埃及記 24:17; 出埃及記 20:18"> 你們並不是來到了摸得著的山<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「山」。">f</a></sup>、燃燒著的火、陰雲、幽暗、風暴、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; 哥林多前書 15:52; 申命記 4:12"> 號角的響聲和說話的聲音面前——那些聽見這聲音的人，都懇求不要再向他們說話了，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 19:12–13; 出埃及記 19:16; 加拉太書 3:10"> 因為他們擔當不了那吩咐他們的話：「即使是野獸觸摸這山，也要用石頭砸死<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「或被標槍刺穿」。">g</a></sup>。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 19:16; 申命記 9:19; 以賽亞書 6:3–5"> 那景象實在可怕，連摩西也說：「我非常害怕戰兢。」</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太書 4:26; 腓立比書 3:20; 啟示錄 14:1"> 相反，你們卻是來到了錫安山、永生神的城、天上的耶路撒冷面前；來到了千萬天使的盛會面前；</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 1:18; 希伯來書 11:40; 路加福音 10:20"> 來到了長子們<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="長子們——原文直譯「首生者們」。">h</a></sup>的教會面前——他們的名字<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="名字——輔助詞語。">i</a></sup>已經登記在天上；來到了神面前——他是萬人的審判者；來到了義人的靈魂面前——他們得以完全；</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:15; 希伯來書 11:28; 希伯來書 11:4"> 來到了耶穌面前——他是新約的中保；來到了所灑的血面前——這血比亞伯的血所述說的更美好。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯來書 8:5; 申命記 30:17; 希伯來書 2:1–3"> 你們要當心，不要拒絕向你們<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="向你們——輔助詞語。">j</a></sup>說話的那一位。要知道，那些拒絕了在地上警告他們的，尚且無法逃脫懲罰<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="懲罰——輔助詞語。">k</a></sup>，更何況我們背棄從天上警告我們的那一位呢！</span>
<span className="v" id="v26" data-v="26" data-xref="哈該書 2:6–7; 以賽亞書 13:13; 出埃及記 19:18"> 那時候，他的聲音震動了大地，但如今他應許說：「我不僅要再一次震動地，而且還要震動天。」</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 7:31; 馬太福音 24:35; 彼得後書 3:10–11"> 「再一次」這句話表明了那些能夠被震動的，就如被造之物，都要被挪去，好使那些不能被震動的可以存留。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 12:1–2; 希伯來書 13:15; 但以理書 2:44"> 因此，我們既然在領受一個不能被震動的國度，就讓我們懷有感恩的心<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="懷有感恩的心——或譯作「持守恩典」。">l</a></sup>，藉此以虔誠和敬畏，照著神所喜悅的<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="照著神所喜悅的——或譯作「按蒙喜悅的方式」。">m</a></sup>來事奉他。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 4:24; 申命記 9:3; 希伯來書 10:27"> 要知道，我們的神實在是吞噬的烈火。</span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 4:20–1; 彼得前書 3:8; 彼得前書 1:22"> 你們當常存弟兄之愛。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 25:35; 創世記 18:1–3; 彼得前書 4:9"> 不要忘記款待客旅，因為曾經有些人這樣做，在無意中就招待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 25:36; 希伯來書 10:34; 羅馬書 12:15"> 你們要顧念那些被囚禁的人，好像與他們一同被囚禁；要記念那些受虐待的人，好像你們自己也是在肉體中受虐待。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 2:24; 箴言 5:15–23; 加拉太書 5:19"> 婚姻當受所有人尊重，床也不可玷汙，因為神將要審判淫亂和通姦的人。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 31:8; 約書亞記 1:5; 申命記 31:6"> 你們行事為人不要愛錢財，要以現有的為滿足，因為神自己說過：「我絕不撇下你，也絕不離棄你。」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 118:6–9; 以賽亞書 41:10; 羅馬書 8:31"> 所以，我們可以滿懷勇氣地說：<br /><span className="pl pl-1">「主是我的幫助，</span><br /><span className="pl pl-1">我就不懼怕，</span><br /><span className="pl pl-1">人能把我怎麼樣呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦前書 5:12–13; 希伯來書 13:17; 腓立比書 3:17"> 你們當記住那些帶領你們、把神的話語<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的話語——或譯作「神的道」。">a</a></sup>傳給你們的人；要仔細觀察他們行事為人的結果，效法他們的信仰。</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 3:6; 雅各書 1:17; 啟示錄 1:8"> 耶穌基督昨天、今天、直到永遠，都是一樣的。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:14; 提摩太前書 6:3–5; 以弗所書 5:6"> 你們不要被各種怪異的教導引入歧途<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引入歧途——有古抄本作「被帶走」或「被搖動」。">b</a></sup>，因為人的心靠恩典，不靠食物規定得以確立才是好的；那靠食物規定<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="規定——輔助詞語。">c</a></sup>而行事的人，從來沒有得到什麼益處。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 5:7–8; 哥林多前書 10:20; 哥林多前書 9:13"> 我們有一個祭壇，這壇上的祭物<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="祭物——輔助詞語。">d</a></sup>，是那些在會幕中事奉的人沒有權利吃的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 16:27; 出埃及記 29:14; 利未記 9:11"> 原來動物的血由大祭司帶進聖所，是為了贖罪，而動物的身體卻在營地外面被燒掉；</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 9:12–14; 約翰福音 19:17–18; 使徒行傳 7:58"> 所以耶穌為了藉著自己的血使子民分別為聖，也在城門外受難。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 11:26; 彼得前書 4:14–16; 使徒行傳 5:41"> 因此，讓我們到營地外面他那裡去，擔當他所受的責罵。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 3:20; 歌羅西書 3:1–3; 希伯來書 11:12–16"> 因為在這裡，我們沒有長存的城；相反，我們是在尋求那將要來臨的城。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 107:21–22; 詩篇 50:14; 羅馬書 12:1"> 這樣，讓我們藉著耶穌，常常以頌讚為祭物獻給神，這祭物就是承認他名的嘴唇所結的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="所結的——輔助詞語。">e</a></sup>果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦後書 3:13; 加拉太書 6:10; 羅馬書 12:13"> 你們不可忘記行善和分享<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="分享——或譯作「相契合」。">f</a></sup>，因為這樣的祭物是蒙神喜悅的。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦前書 5:12–13; 提摩太前書 5:17; 希伯來書 13:7"> 你們要信任那些帶領你們的人，要服從他們，因為他們做為要交帳的人，要為你們的靈魂時刻警醒。你們要讓他們能懷著喜樂的心做這事，而不至嘆息，因為讓他們嘆息，對你們並沒有益處。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:25; 帖撒羅尼迦後書 3:1; 歌羅西書 4:3"> 請為我們禱告；因為我們深信自己有無愧的良心，願意在一切事上行事正直。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利門書 1:22; 羅馬書 1:10–12; 羅馬書 15:31–32"> 我特別請求你們禱告，好讓我能快一點回到你們那裡。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:11; 希伯來書 10:22; 詩篇 23:1"> 願賜平安的神，就是藉著永恆之約的血，把群羊的大牧人我們的主耶穌從死人中領上來的那一位，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:13; 帖撒羅尼迦後書 2:17; 腓立比書 4:13"> 在一切美善之事上使你們完備，好遵行他的旨意。願神藉著耶穌基督，在我們裡面行他看為喜悅的事。願榮耀歸於他，直到永永遠遠！阿們。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="希伯來書 3:1; 彼得前書 5:12; 哥林多後書 6:1"> 弟兄們，我懇求你們容忍我這勸勉的話，因為我只是簡略地寫信給你們。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利門書 1:1; 帖撒羅尼迦前書 3:2; 提摩太後書 1:8"> 你們要知道，我們的弟兄提摩太已經被釋放了。如果他能快一點來，我就與他一起去看你們。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 13:7; 希伯來書 13:17; 使徒行傳 18:2"> 請問候所有帶領你們的人和所有的聖徒。從意大利來的那些人也問候你們。</span>
<span className="v" id="v25" data-v="25" data-xref="歌羅西書 4:18; 提摩太後書 4:22; 提多書 3:15"> 願恩典與你們大家同在！<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「阿們。」">g</a></sup></span>
</div>
</div>

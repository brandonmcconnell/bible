<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯來書" data-chapter="10" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 8:5; 希伯來書 9:11; 歌羅西書 2:17"> 既然律法帶有那將要來的美好事物的影子，它不是那些事物的本像，就絕不能藉著年年不斷地獻上同樣的祭物，使近前來的人得以完全。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 43:25; 彌迦書 7:19; 詩篇 103:12"> 否則，事奉的人因為一次性地被潔淨，不再覺得有罪孽，難道不早就停止獻祭了嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 9:7; 出埃及記 30:10; 利未記 23:27–28"> 然而這些祭物使人年年都想起罪孽來，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 10:11; 以賽亞書 1:11–15; 彌迦書 6:6–8"> 因為公牛和山羊的血，不可能把罪孽除去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 40:6–8; 以賽亞書 1:11; 以賽亞書 7:14"> 所以，基督進入世界的時候，他說：<br /><span className="pl pl-1">「神哪</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神哪——輔助詞語。">a</a></sup><br /><span className="pl pl-1">，祭物和供物不是你所希望的；</span><br /><span className="pl pl-1">你為我預備了一個身體。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 1:10; 馬太福音 3:17; 詩篇 147:11"> <span className="pl pl-1">燔祭和贖罪祭不是你所喜悅的；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 40:7–8; 約翰福音 4:34; 約翰福音 6:38"> <span className="pl pl-1">於是我說：『看哪，我來了！</span><br /><span className="pl pl-1">關於我的事，</span><br /><span className="pl pl-1">經卷上已經記載了。</span><br /><span className="pl pl-1">神哪，我來是要遵行你的旨意！』」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:5; 馬可福音 12:33"> 上文說：祭物、供物、燔祭和贖罪祭不是你所希望的，也不是你所喜悅的，儘管這些都是照著律法獻上的；</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 7:18–19; 希伯來書 12:27–28; 希伯來書 10:7"> 接著又說：「看哪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="看哪——有古抄本作「看，神哪」。">b</a></sup>，我來了！是要遵行你的旨意！」神廢除前者，是為了確立後者。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:14; 希伯來書 10:12; 哥林多前書 6:11"> 我們憑著這旨意，藉著耶穌基督身體做供物，就已經一次性地被分別為聖了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="希伯來書 5:1; 民數記 28:3; 希伯來書 10:4"> 所有的祭司天天都站著服事，再三地獻上同樣的祭物，但這些祭物絕不能把罪孽除掉，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 1:3; 歌羅西書 3:1; 羅馬書 8:34"> 而這一位為贖罪孽獻上了一個永遠的祭物，就在神的右邊坐下了，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 1:13; 詩篇 110:1; 路加福音 20:43"> 此後一直等候他的敵人被放在他的腳下做腳凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 7:25; 希伯來書 10:1; 希伯來書 9:14"> 事實上，他藉著一個供物，使那些被分別為聖的人永遠得以完全。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:7; 啟示錄 2:11; 啟示錄 3:6"> 聖靈也向我們做見證，因為他說過<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="說過——有古抄本作「預先說過」。">c</a></sup>：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 31:33–34; 希伯來書 8:8–12; 羅馬書 11:27"> <span className="pl pl-1">「主說：『在那些日子以後，</span><br /><span className="pl pl-1">我要與他們訂立這樣的約：</span><br /><span className="pl pl-1">我要把我的法則放在他們的心上，</span><br /><span className="pl pl-1">刻在他們的意念中。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 31:34; 希伯來書 8:12"> 然後又說：<br /><span className="pl pl-1">「我絕不再想起他們的罪孽和他們的罪惡</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="罪惡——原文直譯「不法」。">d</a></sup><br /><span className="pl pl-1">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯來書 10:2; 希伯來書 10:14"> 所以在哪裡這些罪得了赦免，在哪裡就不再有贖罪的供物了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所書 2:18; 希伯來書 9:12; 希伯來書 4:16"> 因此，弟兄們，我們藉著耶穌的血，可以坦然無懼地進入至聖所。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 14:6; 約翰福音 10:9; 希伯來書 9:3"> 他為我們開闢了一條又新又活的道路，從幔子經過；這幔子就是他的身體。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 2:17; 希伯來書 4:14–16; 希伯來書 8:1"> 既然我們有一位偉大的祭司管理神的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 36:25; 約翰福音 3:5; 以弗所書 5:26"> 既然我們的心被血<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="血——輔助詞語。">e</a></sup>灑過，脫離了罪惡感，身體也被清水洗淨了，就讓我們懷著真誠的心，以確信不移的信仰近前來；</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒羅尼迦前書 5:24; 哥林多前書 1:9; 帖撒羅尼迦後書 3:3"> 讓我們毫不動搖地持守所告白的盼望，因為向我們應許的那一位是信實的；</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:11; 約翰一書 3:18; 希伯來書 13:1"> 讓我們彼此看顧，好激勵愛心和美好的工作。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 2:42; 帖撒羅尼迦前書 5:11; 馬太福音 18:20"> 你們不要放棄自己的聚會，像某些人所習慣的那樣，而要彼此鼓勵；你們既然看見那日子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="日子——指「基督再來的日子」。">f</a></sup>臨近，就更應該這樣。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得後書 2:20–22; 希伯來書 6:4–6; 約翰福音 9:41"> 要知道，我們領受了真理的知識以後，如果還故意犯罪，就不再有贖罪的祭物被保留下來；</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 26:11; 希伯來書 2:3; 西番雅書 1:18"> 只保留了對審判的可怕等待，和那將要吞滅敵對者的嫉恨之火。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:2; 申命記 19:15; 申命記 17:2–13"> 任何拒絕摩西律法的人，憑兩個或三個見證人的見證，就得不到憐憫而死，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 6:6; 以弗所書 4:30; 以賽亞書 63:10"> 何況一個人踐踏了神的兒子，把那使自己成聖的立約之血看做是俗物，又侮辱了恩典的聖靈，你們想想，這個人難道不該受更厲害的懲罰嗎？</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 32:35–36; 羅馬書 12:19; 那鴻書 1:2"> 因為我們認識曾說過「報應在我，我將回報<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「——這是主說的」。">g</a></sup>」的那一位，他又說過「主要審判自己的子民。」</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 10:28; 路加福音 12:5; 希伯來書 12:29"> 落在永生神的手中實在可怕。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="希伯來書 6:4; 希伯來書 12:4; 提摩太後書 2:3–13"> 你們要回想原先的日子：當你們蒙了光照以後，忍受了許多痛苦掙扎；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 4:9; 腓立比書 4:14; 希伯來書 11:36"> 有時候當眾受責罵、受患難；有時候陪伴那些受到同樣遭遇的人。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前書 1:4; 提摩太後書 1:16; 馬太福音 5:11–12"> 的確，你們不但同情了那些被囚禁的人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="那些被囚禁的人——有古抄本作「被囚禁的我」。">h</a></sup>，而且當自己所擁有的被奪去時，你們也甘心接受了，因為知道你們在天上<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有「在天上」。">i</a></sup>有更好的、長存的產業。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前書 15:58; 加拉太書 6:8–10; 希伯來書 3:6"> 所以，不要丟棄你們的確信，這確信帶來極大的報償。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 12:1; 詩篇 37:7; 雅各書 5:7–11"> 其實，你們需要忍耐，好在你們行完神的旨意以後，可以領受所應許的。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 5:7–9; 哈巴谷書 2:3–4; 路加福音 18:8"> <span className="pl pl-1">要知道，還有一點點時候，</span><br /><span className="pl pl-1">「要來的那一位就要來臨，他不會遲延。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太書 3:11; 哈巴谷書 2:4; 羅馬書 1:17"> <span className="pl pl-1">我的義人將因信而活；</span><br /><span className="pl pl-1">如果他退縮，</span><br /><span className="pl pl-1">我的心就不喜悅他。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰一書 5:5; 彼得前書 1:5; 馬可福音 16:16"> 然而，我們不是退縮以致滅亡<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="滅亡——或譯作「沉淪」。">j</a></sup>的人，而是有信仰以致保全靈魂<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="靈魂——或譯作「生命」。">k</a></sup>的人。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:9; 腓立比書 3:14; 希伯來書 4:14–15"> 故此，蒙了屬天召喚的同伴們，聖潔的弟兄們！你們應該思想我們信仰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="信仰——輔助詞語。">a</a></sup>告白中的使者和大祭司——耶穌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶穌——有古抄本作「基督耶穌」。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 12:7; 提摩太前書 3:15; 以弗所書 2:22"> 他對委任他的那一位是忠心的，正如摩西在神的全家也是忠心的。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 3:9; 彼得前書 2:5–7; 撒迦利亞書 6:12–13"> 事實上，這個人被看為比摩西配得更大的榮耀，就像建造房屋的人比房屋本身更有尊榮那樣，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 3:3; 希伯來書 1:2; 以斯帖記 2:10"> 因為每一座房屋都是由人建造的，而建造萬有的就是神。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 12:7; 希伯來書 3:2; 出埃及記 14:31"> 摩西是做為僕人，對神的全家忠心，為將被述說的事做見證；</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 6:16; 哥林多前書 3:16; 希伯來書 10:35"> 但基督是做為兒子，忠心管理神的家。如果我們持守所確信的和所誇耀的盼望，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「堅定地持守到底，」。">c</a></sup>我們就是神的家。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7–11; 希伯來書 3:15; 以賽亞書 55:3"> 因此，就像聖靈所說的：<br /><span className="pl pl-1">「今天，你們如果聽見他的聲音，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及記 17:7; 撒迦利亞書 7:11–12"> <span className="pl pl-1">就不可硬著你們的心，</span><br /><span className="pl pl-1">如同在那悖逆的時候，也像在那曠野試探的日子。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:36; 申命記 4:9; 出埃及記 19:4"> <span className="pl pl-1">在那裡，你們的祖先考驗我、試探我，</span><br /><span className="pl pl-1">並且看了我的作為四十年之久。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 95:10; 帖撒羅尼迦後書 2:10–12; 詩篇 67:2"> <span className="pl pl-1">所以，我向那世代發怒，說：</span><br /><span className="pl pl-1">『他們的心總是被迷惑，</span><br /><span className="pl pl-1">他們不認識我的道路』，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:34–35; 希伯來書 4:3; 民數記 32:10–13"> <span className="pl pl-1">所以，我在自己的震怒中起誓說：</span><br /><span className="pl pl-1">『他們絕不能進入我的安息。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 17:5; 耶利米書 7:24; 耶利米書 17:9"> 弟兄們，你們要當心，免得你們中間有人存著不信的邪惡之心，以致離開永生的神。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 5:11; 希伯來書 10:24–25; 提摩太後書 4:2"> 只要日子還被稱為「今天」，你們就要天天互相鼓勵，免得你們當中有人被罪迷惑，心裡剛硬。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 3:6; 希伯來書 6:11; 希伯來書 12:10"> 因為我們如果把那起初的確信，堅定地持守到底，我們就成為基督的同伴了。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:7–8; 詩篇 95:7; 希伯來書 10:38"> 經上說：<br /><span className="pl pl-1">「今天，你們如果聽見他的聲音，</span><br /><span className="pl pl-1">就不可硬著你們的心，如同在那悖逆的時候。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 14:2; 民數記 14:30; 民數記 26:65"> 到底是誰聽見卻悖逆了呢？難道不是被摩西從埃及帶領<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="帶領——輔助詞語。">d</a></sup>出來的那一切人嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 14:29; 民數記 26:64–65; 民數記 14:32–33"> 神又向誰發怒了四十年之久呢？難道不是那些犯了罪、屍首倒在曠野的人嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 14:30; 希伯來書 4:6; 申命記 1:34–35"> 他又向誰起誓說，他們絕不能進入他的安息呢？難道不是向那些不肯信從的人嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="猶大書 1:5; 約翰福音 3:36; 馬可福音 16:16"> 這樣我們就看出來：他們不能進入，是因不信的緣故。</span>
</div>

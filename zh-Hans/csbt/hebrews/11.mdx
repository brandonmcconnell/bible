<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯來書" data-chapter="11" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 5:7; 哥林多後書 4:18; 羅馬書 8:24–25"> 信，是對所盼望的事有把握，對看不見的事有確據。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:39; 希伯來書 11:4"> 古人因著這信曾受到了讚許。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="詩篇 33:6; 彼得後書 3:5; 約翰福音 1:3"> 因著信，我們明白宇宙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="宇宙——或譯作「各世代」。">a</a></sup>是藉著神的話語形成的，從而明白那看得見的事是從看不見的事造出來的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯來書 12:24; 創世記 4:3–5; 約翰一書 3:11–12"> 因著信，亞伯向神獻上的祭物比該隱所獻的更好，就藉著信受到了讚許成為義人，因為神讚許他的禮物。他雖然死了，但藉著信仍然說話。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 5:21–24; 猶大書 1:14; 希伯來書 11:6"> 因著信，以諾被接去而沒有經歷死亡，人也找不到他，因為神把他接去了。原來他被接去以前，已經蒙神喜悅而受到讚許。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米書 29:13–14; 馬太福音 6:33"> 沒有信，就不可能蒙神喜悅，因為來到神面前的人，必須相信神存在，並且相信他報償那些尋求他的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 6:13–1; 彼得前書 3:20; 以西結書 14:14"> 因著信，挪亞在那還看不見的事上得了神的指示，就動了敬畏的心，建造了一隻方舟，以至於他的家人獲救。藉著信，他定了世界的罪，自己也繼承了從信而來的義。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 12:1–4; 使徒行傳 7:2–4; 馬太福音 7:24–25"> 因著信，亞伯拉罕蒙召的時候，就順從出發，往他將要得為繼業的地方去。他出發的時候，還不知道往哪裡去。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:8; 創世記 13:18; 創世記 13:3"> 因著信，他做為外人客居在應許之地，住在帳幕裡，與同一個應許的共同繼承人以撒、雅各一樣，</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 13:14; 腓立比書 3:20; 希伯來書 12:22"> 因為他等待著那座有根基的城；那城是神所設計、所建造的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 4:20–21; 希伯來書 10:23; 創世記 18:11–14"> 同樣因著信，不能生育的撒拉，自己雖然過了年齡，還是領受了懷孕生子的能力，原來她認為向她應許的那一位<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="因著信，不能生育的撒拉……原來她認為向她應許的那一位——或譯作「因著信，亞伯拉罕雖然過了年歲——撒拉又不能生育——但是仍然得著了生育的能力，原來亞伯拉罕認為向他應許的那一位」。">b</a></sup>是信實的。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 22:17; 創世記 32:12; 創世記 15:5"> 所以從一個如同已經死了的人，就生出了許多人，像天空的星那樣眾多，像海邊的沙那樣無法數算。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 23:4; 詩篇 39:12; 希伯來書 11:27"> 這些人都懷著信仰死去，沒有得到那些所應許的，卻遠遠地看見<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「深信它們」。">c</a></sup>並且歡迎它們，又承認自己在地上是異鄉人，是寄居的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 4:18–7; 希伯來書 11:16; 希伯來書 13:14"> 實際上，說這樣話的人，是表明他們在尋求一個家鄉。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 24:6–8; 創世記 12:10; 創世記 32:9–11"> 如果他們真是想念自己所離開的地方，他們還有機會回去；</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 13:14; 希伯來書 11:10; 腓立比書 3:20"> 但如今，他們所嚮往的是一個更美好的，就是在天上的家鄉。因此，神被稱為「他們的神」並不以為恥；原來他已經為他們預備了一座城。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 22:16; 創世記 22:1–12; 雅各書 2:21–24"> 因著信，亞伯拉罕在受考驗的時候，獻上了以撒；這位領受了各樣應許的人，獻上了自己的獨生兒子——</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:12; 羅馬書 9:7; 創世記 17:19"> 關於這兒子，神曾經說過：「從以撒生的，將被稱為你的後裔。」</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 4:17–21; 馬太福音 9:28; 以弗所書 3:20"> 亞伯拉罕認為，神真的能使人從死人中復活。故此，用比喻來說，他真的從死人中得回了以撒。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 27:27–40; 創世記 28:2–3"> 同樣因著信，以撒指著將來的事祝福了雅各和以掃。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:31–1; 創世記 48:5–22"> 因著信，雅各臨死的時候，祝福了約瑟的每個兒子，又倚著自己的杖頭敬拜神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 13:19; 創世記 50:24–25; 約書亞記 24:32"> 因著信，約瑟臨終的時候，提到以色列子民出埃及的事，也為自己的骸骨留下了遺言。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 1:22; 出埃及記 1:16; 希伯來書 13:6"> 因著信，摩西出生以後，被父母藏了三個月，原來他們看見孩子俊美；他們不怕王的命令。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 2:10–11; 使徒行傳 7:21–24"> 因著信，摩西長大以後，拒絕被稱為法老女兒的兒子。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 84:10; 提摩太後書 2:3–10; 約伯記 36:21"> 他寧願選擇與神的子民同受虐待，也不願享受暫時的罪中之樂。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 10:35; 希伯來書 11:6; 彼得前書 4:14"> 他把為基督受的責罵看做是比埃及的財寶更大的財富，因為他注目那將來的報償。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 4:18; 希伯來書 11:13; 希伯來書 11:1"> 因著信，他不怕王的憤怒，離開了埃及，因為他恆心忍耐，如同看見了不可見的那一位。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 12:21–30; 希伯來書 9:19; 希伯來書 12:24"> 因著信，他立<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="立——或譯作「守」。">d</a></sup>了逾越節和灑血的禮，免得那毀滅長子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="長子——原文直譯「首生者」。">e</a></sup>的碰以色列人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以色列人——原文直譯「他們」。">f</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 14:13–21; 詩篇 106:9–11; 詩篇 78:13"> 因著信，他們走過了紅海，像走過乾地那樣；埃及人試著這樣做，就被吞滅了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約書亞記 6:3–20; 哥林多後書 10:4–5"> 因著信，他們圍繞耶利哥城七天，城牆就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 2:25; 約書亞記 6:22–25; 馬太福音 1:5"> 因著信，妓女拉合在平安中接納了偵察的人，沒有和那些不肯信從的人一同滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:1; 撒母耳記上 1:20; 撒母耳記上 16:13"> 我還要再說什麼呢？如果我一一述說基甸、巴拉克、叄孫、耶弗塔、大衛、撒母耳和先知們的事，時間就不夠了。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 144:1–2; 希伯來書 6:12–15; 希伯來書 10:36"> 他們藉著信，征服了列國，行了公義，獲得了那些應許；他們堵住了獅子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀下 6:16–18; 哥林多後書 12:9–10; 撒母耳記上 17:51–52"> 滅了烈火的威力，逃脫了刀劍的鋒刃，從軟弱中得以剛強，在戰爭中得以強大，擊敗了外國的軍隊。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 4:27–37; 列王紀上 17:22–24; 腓立比書 3:11"> 有些婦女得回了那些從死人中復活的親人；有些人受酷刑至死也不肯接受釋放，為要得到更美好的復活；</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 20:2; 創世記 39:20; 耶利米書 37:15–21"> 另有些人經受了戲弄、鞭打的試煉；還有些人受了捆鎖、監禁的試煉；</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志下 24:21; 耶利米書 26:23; 列王紀上 19:10"> 他們被石頭砸死，被鋸成兩截，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「受到考驗，」。">g</a></sup>被刀劍殺死，披著綿羊、山羊的皮四處漂泊，遭受窮困、患難和虐待。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 18:4; 撒母耳記上 22:1; 列王紀上 19:9"> 他們是這世界不配有的。他們在曠野、山嶺、岩穴、地洞中漂流無定。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯來書 11:13; 希伯來書 11:2"> 這些人雖然都藉著信受到了讚許，還是沒有領受到所應許的，</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 6:11; 希伯來書 8:6; 希伯來書 10:11–14"> 因為神為我們預備了更美好的事，使他們沒有我們，就不能得以完全。</span>
</div>
</div>

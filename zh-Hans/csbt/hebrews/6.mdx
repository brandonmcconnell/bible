<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 5:12–14; 哥林多後書 7:1; 希伯來書 9:14"> 所以，讓我們從基督話語的基本原則出發<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出發——原文直譯「離開」。">a</a></sup>，被神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="神——輔助詞語。">b</a></sup>帶到那成熟的境界；而不用重新打基礎，就如悔改那些致死的行為、對神的信仰、</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 15:13–57; 使徒行傳 17:31–32; 羅馬書 6:3–5"> 各樣的洗淨禮、按手禮、死人復活、永遠的懲罰等教導上。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:21; 哥林多前書 16:7; 哥林多前書 4:19"> 神如果准許，我們就這麼做。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯來書 10:26–29; 彼得後書 2:20–22; 馬太福音 5:13"> 原來，如果有人蒙過一次光照、嘗過屬天恩賜的滋味、曾經與聖靈有份、</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 2:3; 路加福音 8:13; 馬太福音 13:20–21"> 嘗過神美善的話語和將要來臨之世代的權能，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得後書 2:21; 希伯來書 10:29; 希伯來書 6:4"> 卻背棄了真理，就不可能再次更新以至於悔改了。因為他們親自把神的兒子再次釘上十字架，公然羞辱他。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 10:12; 以賽亞書 44:3; 詩篇 65:9–13"> 要知道，當一塊田地吸收了常常降在它上面的雨水，並且為種地的人長出有用菜蔬時，它就享受從神而來的祝福；</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:17–18; 約翰福音 15:6; 路加福音 13:7–9"> 但如果它長出荊棘和蒺藜，就沒有用處了，很快就要被詛咒，它的結局就是被焚燒。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:39; 哥林多後書 7:10; 希伯來書 6:4–6"> 各位蒙愛的人哪，我們即使這樣說，還是深信那關於你們的更好之事，並且是有關救恩的，</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 10:42; 希伯來書 13:16; 加拉太書 6:10"> 因為神不是不公正的，以致忘記你們的工作和你們為他的名所顯出的愛，就是你們先前和如今服事聖徒時所顯出的愛<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="愛——有古抄本作「愛心的勞苦」。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 1:5–8; 希伯來書 3:6; 羅馬書 5:2–5"> 我們渴望你們每個人都顯出同樣的殷勤，使你們對所盼望的有完全的確信，一直到底；</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 13:7; 希伯來書 10:36; 約翰一書 2:25"> 這樣，你們就不會變得懈怠，反而會效法那些藉著信仰和耐心去繼承各樣應許的人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="創世記 22:15–18; 路加福音 1:73; 耶利米書 22:5"> 神向亞伯拉罕應許的時候，因為沒有比自己<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="比自己——輔助詞語。">d</a></sup>更大的可以指著起誓，就指著自己起誓，</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:17; 申命記 1:10; 尼希米記 9:23"> 說：<br /><span className="pl pl-1">「我必定大大賜福給你，</span><br /><span className="pl pl-1">多多地增加你的子孫</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="的子孫——輔助詞語。">e</a></sup><br /><span className="pl pl-1">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 12:2–3; 羅馬書 4:17–25; 出埃及記 1:7"> 這樣，亞伯拉罕恆久忍耐，就獲得了神所應許的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 22:11; 希伯來書 6:13; 創世記 31:53"> 人本來指著比自己<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="比自己——輔助詞語。">f</a></sup>更大的起誓；對他們，所起的誓就是了結一切爭執的確據；</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 6:18; 箴言 19:21; 以賽亞書 55:11"> 為此，神想要對那些繼承應許的人格外表明他的計劃是不能更改的，就用所起的誓來保證。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 23:19; 提多書 1:2; 撒母耳記上 15:29"> 藉著這兩件不能更改的事——在這些事上，神不可能說謊——使我們這些逃往避難所、抓住那擺在前面盼望的人，可以得到極大的鼓勵。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 43:5; 羅馬書 5:5–10; 希伯來書 9:7"> 我們所擁有的這盼望，像靈魂<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="靈魂——或譯作「生命」。">g</a></sup>的錨，又可靠又堅固，並且進到幔子最裡層的那至聖所<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="那至聖所——輔助詞語。">h</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 4:14; 希伯來書 3:1; 希伯來書 5:6"> 耶穌已經為我們做先鋒進入了那裡，照著麥基洗德的等級<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="等級——或譯作「體系」。">i</a></sup>做大祭司，直到永遠。</span>
</div>
</div>

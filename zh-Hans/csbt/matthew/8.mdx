<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="MAT" data-book-slug="matthew" data-book-name="馬太福音" data-chapter="8" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 8:18; 馬太福音 4:25–1; 路加福音 5:15"> 耶穌從山上下來，有一大群人跟隨他。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 15:25; 路加福音 17:12–19; 馬太福音 18:26"> 這時候，忽然有一個痲瘋病人前來拜他，說：「主啊，如果你願意，你就能潔淨我。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:13; 詩篇 33:9; 列王紀下 5:14"> 耶穌伸出手來摸他，說：<span className="woj">「我願意，你潔淨了吧！」</span>那人的痲瘋病立刻就被潔淨了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 14:2–32; 路加福音 5:14; 路加福音 17:14"> 耶穌對他說：<span className="woj">「你要注意，不可告訴任何人，只要去把自己給祭司看，並且獻上摩西所吩咐的祭物，好對他們做見證。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:1–10; 使徒行傳 27:43; 使徒行傳 10:1–33"> 耶穌進了迦百農，有個百夫長前來懇求他，</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 4:1; 馬太福音 4:24; 使徒行傳 9:33"> 說：「主啊，我的僕人癱瘓了，躺在家裡，受劇烈的折磨。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 9:18–19; 路加福音 7:6; 馬可福音 5:23–24"> 耶穌對他說：<span className="woj">「我去使他痊癒。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 107:20; 路加福音 7:6–7; 詩篇 33:9"> 百夫長回答說：「主啊，我實在不配請你進我家。其實只要你說一句話，我的僕人就會痊癒的。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:35–36; 提多書 2:9; 歌羅西書 3:22"> 事實上，我也在人的權下，也有士兵在我之下。我對這個說『去』，他就去；對那個說『來』，他就來；對我的奴僕說『做這事』，他就去做。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 15:28; 路加福音 7:9; 馬可福音 6:6"> 耶穌聽了，十分感慨，對跟隨他的人說：<span className="woj">「我確實地告訴你們：在以色列我沒有見過有這麼大信心</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="信心——指「對耶穌的信心」。">a</a></sup><span className="woj">的人。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:28–29; 以弗所書 3:6; 加拉太書 3:28–29"> <span className="woj">我告訴你們：將有許多人從東從西而來，在天國裡與亞伯拉罕、以撒、雅各一同坐席。</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:30; 路加福音 13:28; 馬太福音 21:43"> <span className="woj">但那些『天國的兒女』，卻將被丟在外面的黑暗裡。在那裡將有哀哭和切齒。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 9:29–30; 馬可福音 9:23; 約翰福音 4:50"> 於是耶穌對那百夫長說：<span className="woj">「回去吧，照著你所信的，給你成全吧！」</span>他的僕人就在那一刻痊癒了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="路加福音 4:38–41; 馬可福音 1:29–34; 哥林多前書 9:5"> 耶穌來到彼得家，看見彼得的岳母正發燒躺著。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; 路加福音 4:38–39; 路加福音 8:54"> 耶穌一摸她的手，燒就退了。於是她就起來服事耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 15:26; 馬太福音 14:14; 馬可福音 1:32–34"> 到了傍晚，人們把許多有鬼魔附身的人帶到耶穌那裡。耶穌話語一出就把那些邪靈都趕了出去，並且使所有患病的人痊癒了。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 53:4; 彼得前書 2:24; 馬太福音 1:22"> 這樣，那藉著先知以賽亞所說的話就應驗了：<br /><span className="pl pl-1">「他親自代替了我們的軟弱，</span><br /><span className="pl pl-1">擔當了我們的疾病。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 4:42–43; 路加福音 8:22; 馬可福音 4:35"> 耶穌看見一群人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一群人——有古抄本作「一大群人」。">b</a></sup>圍著他，就吩咐渡到對岸去。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:33–34; 約翰福音 13:36–38; 路加福音 14:25–27"> 有一個經文士前來對他說：「老師，無論你到哪裡去，我都要跟從你。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 84:3; 路加福音 2:7; 以賽亞書 53:2–3"> 耶穌對他說：<span className="woj">「狐狸有洞，天空的飛鳥有窩，人子卻沒有枕頭的地方。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 9:59–62; 利未記 21:11–12; 民數記 6:6–7"> 耶穌的另一個門徒對他說：「主啊，請准許我先去埋葬我的父親。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 2:13; 路加福音 15:32; 以弗所書 5:14"> 但是耶穌對他說：<span className="woj">「你跟從我，讓死人去埋葬他們的死人吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 8:22–25; 馬可福音 4:36–41; 馬太福音 9:1"> 耶穌上了船，他的門徒們跟著他。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 8:23; 詩篇 107:23–27; 馬可福音 4:37–38"> 這時候，忽然湖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="湖——原文直譯「海」；指「加利利湖（海）」。">c</a></sup>上起了大風暴，以致波浪蓋過了船，耶穌卻睡著了。</span>
<span className="v" id="v25" data-v="25" data-xref="約拿書 1:6; 歷代志下 14:11; 馬可福音 4:38–39"> 門徒們上前來叫醒他，說：「主啊，救救我們，我們沒命了！」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 41:10–14; 詩篇 65:7; 詩篇 107:28–30"> 耶穌對他們說：<span className="woj">「為什麼膽怯呢？你們這些小信的人哪！」</span>耶穌就起來，斥責風和浪<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="浪——或譯作「湖」；原文直譯「海」。">d</a></sup>，湖面就變得一片平靜。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬可福音 7:37; 馬可福音 6:51; 馬太福音 14:33"> 他們都感到驚奇，說：「這個人究竟是什麼人？連風和浪<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="浪——或譯作「湖」；原文直譯「海」。">e</a></sup>也聽從他！」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 8:26–39; 馬可福音 5:1–20; 使徒行傳 10:38"> 耶穌來到對岸格達拉<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="格達拉——有古抄本作「格拉森」。">f</a></sup>人的地方，兩個有鬼魔附身的人，從墓地迎著他出來。他們非常凶猛，以致沒有人能從那條路經過。</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 1:24; 路加福音 4:34; 雅各書 2:19"> 忽然，他們喊叫說：「神的兒子<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「耶穌」。">g</a></sup>啊，我們與你有什麼關係？時候來到之前，你就來這裡折磨我們嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 14:8; 利未記 11:7; 馬可福音 5:11"> 當時，離他們很遠的地方，有一大群豬正在吃食。</span>
<span className="v" id="v31" data-v="31" data-xref="啟示錄 20:1–2; 路加福音 8:30–33; 馬可福音 5:12"> 那些鬼魔就央求耶穌，說：「如果你要把我們趕出去，就叫我們進入這群豬裡面去吧。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 5:13; 使徒行傳 2:23; 啟示錄 20:7"> 耶穌對它們說：<span className="woj">「去吧！」</span>它們就出來，進入豬<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「群」。">h</a></sup>裡面去了。忽然，那整群豬<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有「豬」。">i</a></sup>從山崖衝到湖裡，在水裡淹<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="淹——輔助詞語。">j</a></sup>死了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:34–36; 馬可福音 5:14–16; 使徒行傳 19:15–17"> 那些放豬的人就逃跑，進城去傳報了這一切事，包括鬼魔附身之人的事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 16:39; 路加福音 8:37–39; 路加福音 5:8"> 看哪，全城的人都出來看耶穌，見了耶穌以後，就央求他離開他們的地區。</span>
</div>
</div>

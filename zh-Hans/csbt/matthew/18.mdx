</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 19:13–14; 馬可福音 9:36–37; 列王紀上 3:7"> 耶穌叫來一個小孩子，讓他站在他們當中，</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 10:14–15; 彼得前書 2:2; 馬太福音 19:14"> 說：<span className="woj">「我確實地告訴你們：你們如果不回轉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="回轉——或譯作「悔改」。">a</a></sup><span className="woj">，變得像小孩子一樣，絕不能進入天國。</span></span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 4:10; 路加福音 14:11; 馬可福音 10:43"> <span className="woj">所以，誰像這小孩子自我降卑，誰在天國裡就更大。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 25:40; 馬可福音 9:37; 約翰福音 13:20"> <span className="woj">無論誰奉我的名接受這樣一個小孩子，就是接受我。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 9:42; 路加福音 17:1–2; 馬太福音 18:10"> <span className="woj">「但無論誰使信我的這些卑微人中的一個絆倒，對那人來說，倒不如脖子上被拴上大磨石</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大磨石——原文直譯「驢拉的磨石」。">b</a></sup><span className="woj">，沉到深海裡。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前書 11:19; 馬太福音 26:24"> <span className="woj">這世界有禍了，因為有使人絆腳的事；要知道，那些使人絆腳的事必然出現，不過使它出現的人有禍了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 5:29–30; 腓立比書 3:8–9; 羅馬書 13:12"> <span className="woj">如果你的一隻手或一隻腳使你絆倒，就把它砍下來丟掉！對你來說，缺一隻手或缺一隻腳進入永生</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="永生——原文直譯「生命」。">c</a></sup><span className="woj">，要比手腳雙全被丟進永遠的火裡好多了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 14:22; 馬太福音 18:8; 馬太福音 5:29"> <span className="woj">如果你的一隻眼使你絆倒，就把它剜出來丟掉！對你來說，缺一隻眼進入永生</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="永生——原文直譯「生命」。">d</a></sup><span className="woj">，要比雙眼齊全被丟進烈火的地獄裡好多了。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11; 詩篇 34:7; 希伯來書 1:14"> <span className="woj">「你們要注意，不可輕視這些卑微人中的一個。我告訴你們：他們的天使在天上常常看見我天父的面。</span></span>
<span className="v" id="v11" data-v="11"> <span className="woj">要知道人子來，是為了拯救迷失的人。</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有此節。">e</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 34:12; 路加福音 15:4–7; 以西結書 34:16"> <span className="woj">你們怎麼看以下的事？如果一個人有一百隻羊，其中一隻迷失了，難道他不把九十九隻留在山上，去尋找那一隻迷失的嗎？</span></span>
<span className="v" id="v13" data-v="13" data-xref="西番雅書 3:17; 路加福音 15:5–10; 雅各書 2:13"> <span className="woj">如果找到了，我確實地告訴你們：他為這一隻羊歡喜，會比為那九十九隻沒有迷失的羊更歡喜。</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:12; 約翰福音 6:39–40; 彼得後書 3:9"> <span className="woj">照樣，你們</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你們——有古抄本作「我」。">f</a></sup><span className="woj">在天上的父也不願意失去這些卑微人中的一個。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 19:17; 路加福音 17:3–4; 加拉太書 6:1"> <span className="woj">「如果你的弟兄對你</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「對你」。">g</a></sup><span className="woj">犯了罪，你就要去，只在你和他之間責備他。如果他聽你的，你就贏得了你的弟兄；</span></span>
<span className="v" id="v16" data-v="16" data-xref="申命記 19:15; 哥林多後書 13:1; 約翰福音 8:17"> <span className="woj">如果他不聽，你就另外帶一個或兩個人一起去，為要使「任何事，憑兩個或三個見證人的口，才能成立。」</span></span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 3:6; 哥林多前書 5:9–7; 帖撒羅尼迦後書 3:14–15"> <span className="woj">如果他不聽他們的，就告訴教會；如果他連教會也不聽，就應當把他看做像外邦人或稅吏一樣。</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 16:19; 哥林多後書 2:10; 約翰福音 20:23"> <span className="woj">我確實地告訴你們：你們在地上所捆綁的，在天上將是已經被捆綁了的；你們在地上所釋放的，在天上將是被釋放了的。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 7:7; 約翰一書 5:14–16; 馬可福音 11:24"> <span className="woj">我再確實地告訴你們：如果你們當中有兩個人，在地上同心地為任何事祈求，我在天上的父就會為你們成全；</span></span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 5:4; 啟示錄 21:3; 馬太福音 28:20"> <span className="woj">因為哪裡有兩三個人奉我的名聚集，我就在哪裡，在他們當中。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 馬太福音 18:15"> 那時，彼得前來問耶穌：「主啊，如果弟兄對我犯罪，我該饒恕多少次呢？到七次可以嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:13; 馬可福音 11:25; 馬太福音 6:14–15"> 耶穌對他說：<span className="woj">「我告訴你：不是七次，而是七十個七次</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="七十個七次——或譯作「七十七次」。">h</a></sup><span className="woj">。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:24; 羅馬書 14:12; 馬太福音 3:2"> <span className="woj">為此，天國就好比一個君王，要與他的奴僕們清算帳目。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 38:4; 詩篇 130:3–4; 路加福音 16:5"> <span className="woj">他開始算的時候，一個欠了一千萬兩銀子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一千萬兩銀子——原文為「10,000他連得」。1他連得=約6,000日工資。">i</a></sup><span className="woj">的奴僕被帶到他面前。</span></span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:1; 尼希米記 5:5; 路加福音 7:42"> <span className="woj">因為那奴僕沒有可償還的，主人就下令把他和他的妻子兒女，以及他所擁有的一切都賣掉來償還。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:29; 路加福音 7:43; 馬太福音 8:2"> <span className="woj">「那奴僕就俯伏拜他，說：『</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「主啊！」">j</a></sup><span className="woj">請寬容我吧，將來我會把一切償還給你。』</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 145:8; 尼希米記 9:17; 詩篇 86:15"> <span className="woj">那奴僕的主人動了憐憫之心，把他釋放了，並且免了他的債。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 20:2; 以西結書 45:9; 申命記 15:2"> <span className="woj">「但那奴僕出去以後，遇見一個與他同做奴僕的；這人欠他一百個銀幣</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一百個銀幣——原文為「100得拿利」。1得拿利=約1日工資的羅馬銀幣。">k</a></sup><span className="woj">。他就抓住這人，掐住這人的喉嚨，說：『把欠我的還給我。』</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 18:26; 馬太福音 6:12; 腓利門書 1:18–19"> <span className="woj">「這人就俯伏在地</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="俯伏在地——有古抄本作「俯伏在他的腳前」。">l</a></sup><span className="woj">央求他，說：『請寬容我吧，我會還給你的。』</span></span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 22:27; 列王紀上 21:27–29"> <span className="woj">可是他不肯，反而把這人投進監獄，直到這人能還清所欠的債。</span></span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 12:15; 希伯來書 13:3; 馬可福音 3:5"> <span className="woj">那些與他同做奴僕的看見所發生的事，就極其憂傷，去把一切都告訴他們的主人。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 馬太福音 25:26; 羅馬書 3:19"> <span className="woj">「於是主人把那奴僕叫來，對他說：『你這惡奴！因為你求我，我就免了你所有的債。</span></span>
<span className="v" id="v33" data-v="33" data-xref="歌羅西書 3:13; 馬太福音 6:12; 以弗所書 4:32–2"> <span className="woj">難道你不也該憐憫與你同做奴僕的，像我憐憫了你一樣嗎？』</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:25–26; 雅各書 2:13; 路加福音 12:58–59"> <span className="woj">主人就發怒，把他交給掌刑官，直到他能還清所欠的一切債。</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 6:14–15; 雅各書 2:13; 路加福音 6:37–38"> <span className="woj">如果你們每個人不從心裡饒恕自己的弟兄</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="弟兄——有古抄本作「弟兄的過犯」。">m</a></sup><span className="woj">，我的天父也會照樣對待你們。」</span></span>

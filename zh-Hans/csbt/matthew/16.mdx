<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:16; 馬太福音 16:6; 使徒行傳 4:1"> 有些法利賽人和撒都該人前來試探耶穌，要求他把一個從天上來的神蹟顯給他們看。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:54–56"> 耶穌回答他們，說：<span className="woj">「黃昏的時候你們說：『天要晴了，因為天色通紅』；</span></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 12:56; 歷代志上 12:32; 馬太福音 11:5"> <span className="woj">清晨的時候你們說：『今天會有風雨，因為天色通紅又變得陰沉。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「你們這些偽善的人！」">a</a></sup><span className="woj">你們能分辨天象，卻不能分辨時代的徵兆。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="-3 有古抄本沒有「黃昏……徵兆。」">b</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:29–30; 馬太福音 12:39–40; 約拿書 1:17"> <span className="woj">一個邪惡、淫亂的世代會尋求神蹟，可是除了</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「先知」。">c</a></sup><span className="woj">約拿的神蹟以外，不會有神蹟賜給它了。」</span>然後耶穌就離開他們走了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬可福音 8:13–14; 馬太福音 15:39"> 門徒們到了對岸，忘了帶餅。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:1; 加拉太書 5:9; 馬太福音 16:12"> 耶穌對他們說：<span className="woj">「你們要注意，要提防法利賽人和撒都該人的酵母。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬可福音 8:16–18; 馬太福音 15:16–18; 使徒行傳 10:14"> 門徒們就彼此討論說：「這是因為我們沒有帶餅吧。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:30; 馬太福音 14:31; 馬太福音 8:26"> 耶穌知道了，就說：<span className="woj">「小信的人哪，你們為什麼彼此討論沒有帶</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本沒有「帶」。">d</a></sup><span className="woj">餅的事呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 14:17–21; 約翰福音 6:9–13; 路加福音 9:13–17"> <span className="woj">你們還不明白嗎？難道不記得那五個餅給五千人，你們收拾了幾個籃子的碎塊</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="的碎塊——輔助詞語。">e</a></sup><span className="woj">嗎？</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 15:34–38; 馬可福音 8:17–21; 馬可福音 8:5–9"> <span className="woj">也不記得那七個餅給四千人，你們收拾了幾個筐子的碎塊</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的碎塊——輔助詞語。">f</a></sup><span className="woj">嗎？</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 16:6; 路加福音 12:56; 馬可福音 8:21"> <span className="woj">你們怎麼不明白，我對你們說的不是餅的事，而是要你們提防法利賽人和撒都該人的酵母呢？」</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 5:20; 使徒行傳 23:8; 馬太福音 15:4–9"> 門徒們這才領悟耶穌所說的不是要他們提防餅的酵母，而是要他們提防法利賽人和撒都該人的教導。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:18–20; 馬可福音 8:27–29; 但以理書 7:13"> 耶穌來到凱撒里亞菲利彼地區，就問他的門徒們，說：<span className="woj">「人們說</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「我」。">g</a></sup><span className="woj">人子是誰？」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬可福音 6:15; 馬太福音 14:2; 瑪拉基書 4:5"> 他們回答說：「有的說是施洗者<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗者——或譯作「施浸者」。">h</a></sup>約翰，有的說是以利亞，另有的說是耶利米或是先知中的一位。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 9:20; 馬太福音 13:11; 馬可福音 8:29"> 耶穌問他們：<span className="woj">「那麼你們呢？你們說我是誰？」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 14:33; 約翰福音 11:27; 約翰一書 4:15"> 西門彼得回答說：「你是基督，是永生神的兒子！」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 6:45; 以弗所書 1:17–18; 馬太福音 11:25–27"> 耶穌對他說：<span className="woj">「約拿的兒子西門，你是蒙福的，因為這不是任何人</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="任何人——原文直譯「血和肉」。">i</a></sup><span className="woj">啟示你的，而是我在天上的父啟示你的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 2:19–22; 哥林多前書 3:9–11; 以賽亞書 28:16"> <span className="woj">我還告訴你：你是彼得，我要在這磐石上建立我的教會，陰間的門</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="門——或譯作「勢力」。">j</a></sup><span className="woj">不能勝過它。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 18:18; 以賽亞書 22:22; 啟示錄 1:18"> <span className="woj">我要把天國的鑰匙賜給你，你在地上所捆綁的，在天上將是已經被捆綁了的；你在地上所釋放的，在天上將是被釋放了的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 8:30; 路加福音 9:21; 約翰福音 1:41"> 接著耶穌吩咐門徒們，不要對任何人說他就是基督。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 24:6–7; 馬太福音 20:17–19; 馬太福音 17:22–23"> 從那時候起，耶穌開始向他的門徒們指示他必須到耶路撒冷去，經受長老們、祭司長們和經文士們的很多苦害，並且被殺，然後在第三天要復活。</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 8:32; 約翰福音 13:6–8; 馬太福音 16:16–17"> 彼得把耶穌拉到一邊，開始勸阻他，說：「主啊，千萬不可，這事絕不能臨到你身上。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="羅馬書 8:5–8; 歌羅西書 3:2; 腓立比書 3:19"> 但耶穌轉身對彼得說：<span className="woj">「撒旦，退到我後面去！你是我的絆腳石，因為你不是思想神的事，而是思想人的事。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:38; 路加福音 14:27; 彼得前書 4:1–2"> 於是，耶穌對他的門徒們說：<span className="woj">「如果有人想要來跟從我，他就當捨棄自己，背起自己的十字架，然後跟從我。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 10:39; 馬可福音 8:35; 啟示錄 12:11"> <span className="woj">因為凡想要保全</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="保全——原文直譯「救」。">k</a></sup><span className="woj">自己生命的，將失去生命；凡為我的緣故失去自己生命的，將尋得生命。</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 8:36–37; 約伯記 27:8; 路加福音 9:25"> <span className="woj">一個人就是賺得了全世界，卻賠上了自己的生命</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="生命——或譯作「靈魂」。">l</a></sup><span className="woj">，到底有什麼益處呢？人還能拿什麼來換回自己的生命呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 5:10; 詩篇 62:12; 羅馬書 2:6"> <span className="woj">人子將要在他父的榮耀中，與他的天使們一起來臨。那時候，他要按照各人的所作所為回報每個人。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:27; 馬可福音 9:1; 約翰福音 8:52"> <span className="woj">我確實地告訴你們：站在這裡的有些人，在還沒有嘗到死的滋味之前，必定見到人子在他的國度中來臨。」</span></span>
</div>
</div>

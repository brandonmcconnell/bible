<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 7:28; 馬太福音 19:1"> 當耶穌講完了這一切話，就對自己的門徒們說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:1–2; 馬可福音 14:1–2; 約翰福音 13:1–2"> <span className="woj">「你們知道，過兩天就是逾越節，人子要被交出去釘上十字架。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:47–53; 約翰福音 18:24; 馬可福音 14:54"> 那時，祭司長們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「經文士們」。">a</a></sup>和民間的長老們聚集在叫該亞法的大祭司的宅院裡，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 12:14; 詩篇 2:2; 使徒行傳 13:10"> 商議要用詭計拘捕耶穌，把他殺掉。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 27:24; 馬太福音 21:26; 馬太福音 14:5"> 不過他們說：「不可在節日期間，免得民中發生騷亂。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 14:3–9; 路加福音 7:37–39; 約翰福音 12:1–8"> 耶穌在伯大尼，在痲瘋病人西門家裡的時候，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 12:2–3; 路加福音 7:46; 路加福音 7:37–38"> 有一個女人拿著一個盛了極其貴重香液的玉瓶上前來，在耶穌坐席的時候，把香液澆在他的頭上。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 12:4–6; 馬可福音 14:4; 出埃及記 5:17"> 門徒們看見了就很不滿，說：「為什麼這樣浪費？</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 12:5–6; 馬可福音 14:5; 約書亞記 7:20–21"> 這香液<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有「香液」。">b</a></sup>本來可以賣很多錢，分給窮人。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提多書 3:8; 希伯來書 13:21; 提摩太前書 5:10"> 耶穌知道了，就對他們說：<span className="woj">「你們為什麼為難這婦人呢？她為我做了一件美好的事。</span></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 15:11; 馬可福音 14:7; 約翰福音 12:8"> <span className="woj">要知道，你們總是有窮人與你們在一起，但你們不總是有我。</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 14:8; 約翰福音 12:7; 馬可福音 16:1"> <span className="woj">她把這香液澆在我身上，是為了預備安葬我而做的。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 14:9; 馬太福音 24:14; 詩篇 112:6"> <span className="woj">我確實地告訴你們：在全世界，福音無論傳到什麼地方，這女人所做的事也將被述說，做為對她的記念。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:3–6; 馬太福音 10:4; 馬可福音 14:10–11"> 那時候，十二使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使徒——輔助詞語。">c</a></sup>中的一個，就是那稱為加略人猶大的，到祭司長們那裡去，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 11:12–13; 創世記 37:26–28; 出埃及記 21:32"> 說：「如果我把他交給你們，你們願意給我什麼？」他們就約定給他三十個銀錢。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 14:11; 路加福音 22:6"> 從那時候起，猶大就開始找機會要把耶穌交出去。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:7–13; 馬可福音 14:12–16; 出埃及記 12:18–20"> 除酵節的第一日，門徒們前來問耶穌：「你要我們到哪裡去預備，好讓你吃逾越節的晚餐呢？」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 14:13–16; 約翰福音 7:6; 約翰福音 17:1"> 耶穌說：<span className="woj">「你們進城去，到某人那裡，告訴他：『老師說，我的時候快到了。我要在你那裡與我的門徒們一起守逾越節。』」</span></span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 2:5; 約翰福音 15:14; 馬太福音 21:6"> 門徒們就依照耶穌所吩咐的去做，預備了逾越節的晚餐。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 14:17–21; 約翰福音 13:21; 路加福音 22:14–16"> 到了晚上，耶穌與十二使徒一同坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 13:21; 希伯來書 4:13; 約翰福音 6:70–71"> 在他們吃的時候，耶穌說：<span className="woj">「我確實地告訴你們：你們當中有一個人要出賣我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 13:22–25; 路加福音 22:23; 馬可福音 14:19–20"> 他們極其憂傷，就一個一個地開始問耶穌：「主啊，不會是我吧？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:18; 詩篇 41:9; 約翰福音 13:26–28"> 耶穌回答說：<span className="woj">「那與我一同把手蘸在盤子裡的，就是要出賣我的人。</span></span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 26:22–23; 路加福音 24:46; 馬太福音 18:7"> <span className="woj">人子確實要離去，正如經上指著他所寫的，但是出賣人子的那個人有禍了。對他來說，沒有出生倒好。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 26:64; 馬太福音 27:11; 路加福音 22:70"> 那出賣耶穌的猶大應聲說：「拉比，不會是我吧？」<br />耶穌對他說：<span className="woj">「你已經說了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多前書 11:23–29; 路加福音 22:18–20; 哥林多前書 10:16–17"> 在他們吃的時候，耶穌拿起餅來，祝福了，就掰開，遞給門徒們，說：<span className="woj">「你們領受吃吧，這是我的身體。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 25:6; 哥林多前書 10:16; 詩篇 116:13"> 接著，他拿起杯來，祝謝了，遞給他們，說：<span className="woj">「你們都來喝，</span></span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 10:4–14; 希伯來書 9:14–22; 利未記 17:11"> <span className="woj">因為這是我的血，是為立約</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="約——有古抄本作「新約」。">d</a></sup><span className="woj">的，為許多人所流的，使罪得赦免。</span></span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 12:2; 啟示錄 7:17; 馬可福音 14:25"> <span className="woj">我告訴你們：從今以後我絕不喝這葡萄汁</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="葡萄汁——或譯作「葡萄酒」；原文直譯「葡萄樹的產品」。">e</a></sup><span className="woj">，直到我在我父的國裡與你們一起喝新的那一天。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 21:1; 以弗所書 5:19–20; 路加福音 22:39"> 他們唱了讚美詩<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="讚美詩——那時代的逾越節晚餐時、晚餐後，所唱的讚美詩是《詩篇》113-118篇。">f</a></sup>，就出來，往橄欖山去了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="撒迦利亞書 13:7; 馬可福音 14:27–28; 約翰福音 16:32"> 那時，耶穌對他們說：<span className="woj">「今天晚上，你們都將因我被絆倒，因為經上記著：</span><br /><span className="pl pl-1 woj">『我將擊打牧人，</span><br /><span className="pl pl-1 woj">群羊就被分散。』</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 28:10; 路加福音 18:33–34; 馬太福音 28:16"> <span className="woj">但是我復活以後，要在你們之前到加利利去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:33; 約翰福音 13:36–38; 箴言 28:25–26"> 彼得對耶穌說：「即使所有的人因你被絆倒，我也絕不會被絆倒。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 13:38; 路加福音 22:34; 馬太福音 26:75"> 耶穌對他說：<span className="woj">「我確實地告訴你：今天晚上雞叫以前，你會三次不認我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="羅馬書 11:20; 約翰福音 13:37; 箴言 29:23"> 彼得對耶穌說：「即使我必須與你同死，我也絕不會不認你。」所有的門徒也都如此說。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 14:32–42; 馬太福音 26:42; 路加福音 22:39–46"> 隨後，耶穌與他們來到一個叫客西馬尼的地方。耶穌對門徒們說：<span className="woj">「我走開在那裡禱告的時候，你們坐在這裡。」</span></span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 4:21; 馬太福音 17:1; 馬可福音 5:37"> 他帶了彼得和西庇太的兩個兒子一起去，開始感到憂慮，極其難過，</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 12:27; 彼得前書 3:18; 彼得前書 2:24"> 就對他們說：<span className="woj">「我的靈魂很憂傷，幾乎要死。你們留在這裡，與我一同警醒。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 6:38; 腓立比書 2:8; 路加福音 22:41–42"> 耶穌稍往前走，把臉伏在地上禱告說：<span className="woj">「我父啊，如果有可能，讓這杯離開我吧！但不要照我的意願，而要照你的意願。」</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬可福音 14:37; 路加福音 22:45; 馬太福音 26:43"> 耶穌回到門徒們那裡，看見他們睡著了，就對彼得說：<span className="woj">「你們怎麼就不能與我一同警醒一個小時呢？</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 14:38; 路加福音 22:46; 以弗所書 6:18"> <span className="woj">要警醒禱告，免得陷入試探。你們心靈雖然願意，肉體卻是軟弱的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬太福音 26:39; 馬可福音 14:39–40; 希伯來書 4:15"> 耶穌第二次又去禱告說：<span className="woj">「我父啊，如果這杯不能離開我</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「我」。">g</a></sup><span className="woj">，一定要我喝下，那就願你的旨意成就！」</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:32; 羅馬書 13:1; 箴言 23:34"> 他又回來，看見他們在睡覺，因為他們的眼皮發沉。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="哥林多後書 12:8; 路加福音 18:1; 馬太福音 6:7"> 耶穌又離開他們，第三次去禱告，又說了同樣的話。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 13:1; 約翰福音 12:27; 馬可福音 14:41–42"> 然後，他回到門徒們那裡，對他們說：<span className="woj">「你們還在睡覺、休息嗎？看哪，時候快到了！人子被交在</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="被交在——或譯作「被出賣到」。">h</a></sup><span className="woj">罪人的手裡了。</span></span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 9:51; 約翰福音 14:31; 撒母耳記上 17:48"> <span className="woj">起來，我們走吧！看，那出賣我的人快到了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 1:16; 馬太福音 26:55; 馬可福音 14:43–50"> 耶穌還在說話的時候，忽然十二使徒之一的猶大來了。有一大群人拿著刀劍和棍棒與他一起來，他們是祭司長們和民間的長老們所派來的。</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 55:20–21; 詩篇 28:3; 撒母耳記下 3:27"> 那出賣耶穌的人已經和他們定了一個暗號，說：「我如果親吻誰，誰就是那個人。你們把他抓住。」</span>
<span className="v" id="v49" data-v="49" data-xref="馬太福音 26:25; 帖撒羅尼迦前書 5:26; 箴言 27:6"> 猶大立刻上前來對耶穌說：「拉比，願你歡喜！」然後親吻了他。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬太福音 20:13; 馬太福音 22:12; 詩篇 41:9"> 耶穌對他說：<span className="woj">「朋友，你為什麼來到這裡？」</span><br />於是，那些人上前來，下手拘捕了耶穌。</span>
<span className="v" id="v51" data-v="51" data-xref="約翰福音 18:36; 馬可福音 14:47; 哥林多後書 10:4"> 這時候，忽然有一個與耶穌在一起的人伸手拔出刀來，向大祭司的奴僕砍去，削掉了他的一個耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="啟示錄 13:10; 創世記 9:6; 羅馬書 12:19"> 耶穌就對他說：<span className="woj">「把你的刀收回原處！因為凡動刀的，必死在刀下。</span></span>
<span className="v" id="v53" data-v="53" data-xref="列王紀下 6:17; 馬太福音 4:11; 但以理書 7:10"> <span className="woj">難道你想我不能求我父，現在就為我派來十二個軍團以上的天使嗎？</span></span>
<span className="v" id="v54" data-v="54" data-xref="撒迦利亞書 13:7; 馬太福音 26:24; 使徒行傳 1:16"> <span className="woj">如果這樣，『事情必須如此發生』的經文怎麼應驗呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="馬可福音 12:35; 約翰福音 8:2; 路加福音 22:52–53"> 這時候，耶穌對那群人說：<span className="woj">「你們帶著刀劍和棍棒出來抓我，就像對付強盜那樣嗎？我天天坐在聖殿裡教導人，你們並沒有抓我。</span></span>
<span className="v" id="v56" data-v="56" data-xref="撒迦利亞書 13:7; 約翰福音 16:32; 馬可福音 14:50–52"> <span className="woj">不過這整個事的發生，是為要應驗先知書的那些經文。」</span>這時候，所有的門徒都離開他，逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="馬太福音 26:3; 馬可福音 14:53–65; 詩篇 56:5–6"> 拘捕耶穌的人把他帶到大祭司該亞法那裡。經文士們和長老們已經聚集在那裡了。</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 7:32; 約翰福音 18:15–16; 約翰福音 18:25"> 彼得遠遠地跟著耶穌，一直到大祭司的院子。他進到裡面，與差役們坐在一起，想看看結果如何。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="使徒行傳 6:11–13; 申命記 19:16–21; 馬可福音 14:55–56"> 當時，祭司長們<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「長老們」。">i</a></sup>和全議會的人為了要處死耶穌，都在尋找偽證來控告他。</span>

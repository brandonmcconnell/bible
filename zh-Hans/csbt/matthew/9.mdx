<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:13; 路加福音 8:37; 馬太福音 8:18"> 耶穌上了船，渡過去，來到自己的城裡。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 2:1–12; 路加福音 5:18–26; 耶利米書 31:33–34"> 這時候，有幾個人把一個躺在床榻上癱瘓的人抬到他面前。耶穌看見他們的信心，就對癱瘓的人說：<span className="woj">「孩子，鼓起勇氣吧！你的罪孽被赦免了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 26:65; 路加福音 5:21; 利未記 24:16"> 但這時候，有些經文士心裡說：「這個人說褻瀆的話！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:8; 馬太福音 12:25; 啟示錄 2:23"> 耶穌知道他們的想法，就說：<span className="woj">「你們心裡為什麼懷著惡念呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 5:8–14; 馬可福音 2:9–12; 使徒行傳 3:16"> <span className="woj">或說『你的罪孽被赦免了』，或說『你起來走路』，到底哪一樣更容易呢？</span></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 43:25; 馬太福音 9:5; 約翰福音 20:21–23"> <span className="woj">不過為要使你們知道人子在地上有赦免罪的權柄——」</span>於是他對癱瘓的人說：<span className="woj">「起來，拿起你的床榻，回家去吧！」</span></span>
<span className="v" id="v7" data-v="7"> 那個人就起來，回家去了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 7:16; 馬太福音 15:31; 使徒行傳 4:21"> 眾人看見就起了敬畏之心<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="起了敬畏之心——有古抄本作「十分驚奇」。">a</a></sup>，就榮耀神，因為他賜給人這樣的權柄。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:27–38; 馬可福音 2:14–22; 路加福音 19:2–10"> 耶穌從那裡往前走，看見一個叫馬太的人在稅關坐著。耶穌對他說：<span className="woj">「你跟從我！」</span>馬太就站起來，跟從了耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 1:13–16; 路加福音 5:29–32; 馬可福音 2:15–17"> 耶穌在屋子裡坐席，這時候來了許多稅吏和罪人，與耶穌和他的門徒們一同坐席。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 11:19; 路加福音 5:30; 馬可福音 2:16"> 有些法利賽人看見了，就對耶穌的門徒們說：「你們的老師為什麼與那些稅吏和罪人一起吃飯呢？」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 5:31; 啟示錄 3:17–18; 馬可福音 2:17"> 耶穌聽見了就說：<span className="woj">「健康的人不需要醫生，有病的人才需要。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 2:17; 路加福音 19:10; 何西阿書 6:6"> <span className="woj">你們去學『我要的是憐憫，而不是祭祀』這話是什麼意思吧！我來不是要召喚義人，而是要召喚罪人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「來悔改」。">b</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:33–39; 馬可福音 2:18–22; 馬太福音 6:16"> 隨後，約翰的門徒們前來問耶穌：「為什麼我們和法利賽人經常<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「經常」。">c</a></sup>禁食，而你的門徒們卻不禁食呢？」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:9; 約翰福音 3:29; 啟示錄 21:2"> 耶穌對他們說：<span className="woj">「新郎與賓客</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="賓客——或譯作「伴郎」；原文直譯「新房之子」。">d</a></sup><span className="woj">在一起的時候，難道賓客能悲傷嗎？可是日子將要來到：當新郎從他們中間被帶走的時候，他們那時就要禁食了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 3:1–2; 約翰福音 16:12; 詩篇 125:3"> <span className="woj">沒有人把沒縮過水的布塊補在舊衣服上，因為所補上的布塊會扯壞衣服，造成更大的裂口。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 9:4; 約伯記 32:19; 詩篇 119:83"> <span className="woj">也沒有人把新酒裝在舊皮袋裡，否則皮袋會脹破，酒會流出來，皮袋也被糟蹋了；相反，他們是把新酒裝在新皮袋裡，這樣兩者都保全了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:41–56; 馬可福音 5:22–43; 馬太福音 8:2"> 耶穌正對他們講這些事的時候，忽然有一個會堂<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="會堂——輔助詞語。">e</a></sup>主管來拜他，說：「我的女兒剛才死了，求你來按手在她身上，她就會活了。」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 10:38; 加拉太書 6:9–10; 馬太福音 8:7"> 於是耶穌起身跟著他去，他的門徒們也跟著去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 8:43–56; 馬太福音 14:36; 馬可福音 6:56"> 這時候，忽然有一個患血漏十二年的女人，從耶穌後面過來，摸了一下耶穌的衣服穗子，</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 5:26–33; 路加福音 8:45–47; 使徒行傳 19:12"> 原來她心裡想：「只要我摸到他的衣服，就會得救治。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 7:50; 馬太福音 15:28; 馬太福音 9:2"> 耶穌轉過身來看著她，說：<span className="woj">「女兒，鼓起勇氣吧！你的信救了你。」</span>從那一刻起，那個女人就得了救治。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歷代志下 35:25; 馬可福音 5:35–40; 路加福音 8:49–51"> 耶穌來到那會堂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="會堂——輔助詞語。">f</a></sup>主管的家，看見吹笛的人和慌亂的人群，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 20:10; 約翰福音 11:11–13; 馬太福音 27:39–43"> 就說：<span className="woj">「你們退去吧！這女孩不是死了，而是睡了。」</span>他們就譏笑他。</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 9:27; 馬可福音 5:41; 路加福音 8:54"> 那群人被趕出去以後，耶穌進去，握著女孩的手，那女孩就起來了。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 4:24; 馬太福音 14:1–2; 馬可福音 1:45"> 於是，這消息傳遍了那整個地區。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:22; 馬太福音 20:30–31; 馬可福音 10:46–48"> 耶穌從那裡往前走，有兩個瞎眼的跟著他，呼叫說：「大衛的後裔，可憐我們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:23–24; 馬太福音 13:58; 馬太福音 8:2"> 耶穌進了屋子，那兩個瞎眼的來到他面前。耶穌問他們：<span className="woj">「你們相信我能做這件事嗎？」</span><br />他們回答說：「主啊，是的，我們信<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="我們信——輔助詞語。">g</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 15:28; 馬可福音 10:52; 馬太福音 8:13"> 於是耶穌摸他們的眼睛，說：<span className="woj">「照著你們所信的，給你們成全吧。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 8:4; 路加福音 5:14; 馬太福音 17:9"> 他們的眼睛就開了。耶穌嚴厲地告誡他們：<span className="woj">「你們要注意，不可讓任何人知道。」</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 7:36; 馬太福音 9:26; 馬可福音 1:44–45"> 但他們一出去，就把耶穌的消息傳遍了那整個地區。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 4:24; 馬太福音 12:22–24; 路加福音 11:14"> 兩個人離去了。這時候有幾個人把一個有鬼魔附身的啞巴帶到耶穌那裡。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 35:6; 馬可福音 7:32–37; 出埃及記 4:11–12"> 鬼魔一被趕出去，啞巴就說出話來。眾人都感到驚奇，他們說：「這樣的事，在以色列從來沒有見過。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 11:15; 馬可福音 3:22; 馬太福音 12:23–24"> 但法利賽人卻說：「他是靠鬼魔的王驅趕鬼魔的。」<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有此節。">h</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 4:23–24; 使徒行傳 10:38; 馬可福音 6:56"> 耶穌走遍各個城鎮鄉村，在他們的會堂裡教導人，傳天國的福音，並且使<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「民中」。">i</a></sup>各樣的疾病和各樣的症狀痊癒。</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 6:34; 民數記 27:17; 耶利米書 50:6"> 耶穌看見眾人，就對他們動了憐憫之心，因為他們困苦流離，像羊沒有牧人那樣。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 10:2; 馬可福音 16:15; 哥林多前書 3:9"> 於是他對自己的門徒們說：<span className="woj">「收割的工作</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="收割的工作——或譯作「莊稼」。">j</a></sup><span className="woj">多，而工人少。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 10:1–2; 耶利米書 3:15; 帖撒羅尼迦後書 3:1"> <span className="woj">所以你們要祈求收割</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="收割——或譯作「莊稼」。">k</a></sup><span className="woj">的主催促工人參與他的收割工作</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="參與他的收割工作——或譯作「收他的莊稼」。">l</a></sup><span className="woj">。」</span></span>
</div>
</div>

</div>

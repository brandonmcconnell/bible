<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; 馬可福音 2:23–28; 路加福音 6:1–5"> 在安息日那天，耶穌從麥田經過。他的門徒們餓了，就開始摘麥穗吃。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:10; 約翰福音 7:21–24; 路加福音 14:3"> 有些法利賽人看見了，就對耶穌說：「你看，你的門徒們做了在安息日不可以做的事。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 21:3–6; 路加福音 6:3; 馬可福音 2:25–26"> 耶穌對他們說：<span className="woj">「大衛和那些與他在一起的人飢餓時所做的事，你們難道沒有讀過嗎？</span></span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:5–9; 出埃及記 25:30; 利未記 8:31"> <span className="woj">他不是進了神的殿</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="殿——原文直譯「家」。">a</a></sup><span className="woj">，和他們吃了</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="和他們吃了——有古抄本作「吃了」。">b</a></sup><span className="woj">陳設餅嗎？這餅是他和那些與他在一起的人不可以吃的，唯有祭司才可以吃。</span></span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:9–10; 約翰福音 7:22–23; 尼希米記 13:17"> <span className="woj">再者，你們難道沒有在律法書上讀過：當安息日，祭司們在聖殿裡觸犯了安息日，也是無罪的嗎？</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 12:41–42; 歷代志下 6:18; 彼得前書 2:4–5"> <span className="woj">但是我告訴你們：比聖殿更大的就在這裡！</span></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 6:6; 馬太福音 9:13; 彌迦書 6:6–8"> <span className="woj">你們如果明白『我要的是憐憫，而不是祭祀』這話是什麼意思，就不會把無罪的定為有罪了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 2:28; 路加福音 6:5; 約翰福音 5:17–23"> <span className="woj">因為人子是安息日的主。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬可福音 3:1–6; 路加福音 6:6–11"> 耶穌離開那地方，進了他們的會堂。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 約翰福音 9:16; 約翰福音 8:6"> 看哪，有個一隻手枯萎的人。有些人就問耶穌，說：「在安息日使人痊癒，是否可以呢？」這是為要控告耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶穌對他們說：<span className="woj">「你們當中有哪一個人，如果他有一隻羊在安息日掉進坑裡，他不會抓住羊，把牠拉上來呢？</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 6:26; 路加福音 6:9; 馬可福音 3:4"> <span className="woj">人比羊重要多了！所以，在安息日做好事是可以的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行傳 3:7–8"> 於是耶穌對那個人說：<span className="woj">「伸出你的手！」</span>他一伸出來，手就復原了，和另一隻一樣健全。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 11:53; 約翰福音 10:39; 馬可福音 3:6"> 那些法利賽人就出去，商議怎樣對付耶穌，好除滅他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="馬可福音 3:7–12; 馬太福音 10:23; 馬太福音 19:2"> 耶穌知道了，就離開那裡。有一大群人跟隨他，耶穌使他們都痊癒了，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 8:4; 馬太福音 9:30; 馬太福音 17:9"> 並且告誡他們不要把他傳揚出去。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 42:1–4; 以賽亞書 42:9; 馬太福音 13:35"> 這是為要應驗那藉著先知以賽亞所說的話：</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 42:1; 路加福音 4:18; 使徒行傳 10:38"> <span className="pl pl-1">「看哪，我所揀選的僕人，</span><br /><span className="pl pl-1">我所愛的，心所喜悅的。</span><br /><span className="pl pl-1">我要把我的靈賜給他，</span><br /><span className="pl pl-1">他要向外邦人宣揚審判的事。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 11:29; 約翰福音 18:36–38; 提摩太後書 2:24–25"> <span className="pl pl-1">他不爭競、不喧嚷，</span><br /><span className="pl pl-1">大街</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大街——或譯作「廣場」。">c</a></sup><br /><span className="pl pl-1">上也沒有人聽見他的聲音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 42:3–4; 以西結書 34:16; 以賽亞書 61:1–3"> <span className="pl pl-1">壓傷的蘆葦，他不折斷；</span><br /><span className="pl pl-1">將熄的燈火，他不吹滅，</span><br /><span className="pl pl-1">直到他使公義得勝，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 11:10; 羅馬書 15:12–13; 以賽亞書 42:4"> <span className="pl pl-1">外邦人將要仰望他的名。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 馬可福音 7:35–37; 以賽亞書 29:18"> 那時，一個有鬼魔附身、又瞎又啞的人被帶到耶穌那裡。耶穌使他痊癒，那啞巴就能說話，也能看見了。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 9:27; 約翰福音 4:29; 馬太福音 22:42–43"> 眾人都十分驚訝，說：「難道這個人就是『大衛的後裔』？」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬可福音 3:22; 馬太福音 9:34; 路加福音 11:15"> 但法利賽人聽見了卻說：「這個人如果不是靠著鬼魔的王別西卜，就不能驅趕鬼魔！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:15; 耶利米書 17:10; 馬太福音 9:4"> 耶穌知道他們的想法，就對他們說：<span className="woj">「任何一個國家，如果自相紛爭就成為荒蕪；任何一個城或家庭，如果自相紛爭就站立不住。</span></span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 1:13; 啟示錄 20:2–3; 約翰一書 5:19"> <span className="woj">如果撒旦驅趕撒旦，就是自相紛爭，它的國怎麼能站立得住呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 19:13–16; 馬可福音 9:38–39; 路加福音 9:49–50"> <span className="woj">如果我是靠別西卜驅趕鬼魔，那麼，你們的子弟是靠誰驅趕鬼魔呢？為此，你們的子弟就將要成為你們的審判者了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理書 7:14; 馬太福音 6:33"> <span className="woj">然而，如果我藉著神的靈驅趕鬼魔，那麼，神的國就已經臨到你們了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 49:24; 馬可福音 3:27; 路加福音 11:21–22"> <span className="woj">人怎麼能進入一個壯士的家搶奪他的東西呢？如果不先把那壯士捆住，就不能搶奪他的家。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:40; 路加福音 11:23; 約書亞記 24:15"> <span className="woj">不與我在一起的，就是在反對我；不與我一起收集的，就是在拆散。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 馬可福音 3:28–30; 希伯來書 10:29"> <span className="woj">為此，我告訴你們：人一切的罪和褻瀆的話都能被赦免，但褻瀆聖靈卻不能被赦免。</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 3:29; 希伯來書 10:26–29; 希伯來書 6:4–6"> <span className="woj">凡是說話抵擋人子的，還能被赦免；但如果有人說話抵擋聖靈，無論在這世代，或在將要來的世代，都不能被赦免。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 馬太福音 7:16–20; 雅各書 4:8"> <span className="woj">「你們讓一棵樹好，它的果子就好；你們讓一棵樹壞，它的果子就壞；這樣，一棵樹是憑著果子被認出來。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 馬太福音 15:18; 以弗所書 4:29"> <span className="woj">你們這些毒蛇的子孫！你們做為惡人，怎麼能說出善的來呢？因為心裡所充滿的，口裡就說出來。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌羅西書 4:6; 箴言 15:28"> <span className="woj">好人從他心裡</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本沒有「他心裡」。">d</a></sup><span className="woj">所存的善，發出善來；壞人從他心裡所存的惡，發出惡來。</span></span>
<span className="v" id="v36" data-v="36" data-xref="傳道書 12:14; 羅馬書 2:16; 啟示錄 20:12"> <span className="woj">我告訴你們：人所說的每一句無益的話，在那審判的日子，句句都要做出交代，</span></span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各書 2:21–25"> <span className="woj">因為憑你的話，你將被稱為義；也憑你的話，你將被定有罪。」</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前書 1:22; 馬可福音 8:11–12; 路加福音 11:16"> 當時，有一些經文士和法利賽人對耶穌說：「老師，我們希望你顯個神蹟給我們看。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="馬太福音 16:4; 路加福音 11:29–32; 馬可福音 8:38"> 耶穌回答他們，說：<span className="woj">「一個邪惡、淫亂的世代會尋求神蹟；可是除了先知約拿的神蹟以外，不會有神蹟賜給它了。</span></span>
<span className="v" id="v40" data-v="40" data-xref="約拿書 1:17; 馬太福音 27:63–64; 馬太福音 16:21"> <span className="woj">就是說，正如約拿在大魚的肚子裡三天三夜，人子也照樣將要在地心三天三夜。</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 12:42; 希伯來書 11:7; 馬太福音 12:6"> <span className="woj">在審判的時候，尼尼微人將要與這世代一起復活</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="復活——或譯作「起來」。">e</a></sup><span className="woj">，並且要定這世代的罪，因為尼尼微人因著約拿的傳道就悔改了。看，比約拿更大的就在這裡！</span></span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 10:1–13; 歷代志下 9:1–12; 希伯來書 1:2–4"> <span className="woj">在審判的時候，南方的女王</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="南方的女王——指「示巴女王」。">f</a></sup><span className="woj">將要與這世代一起復活</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="復活——或譯作「起來」。">g</a></sup><span className="woj">，並且要定這世代的罪，因為她從極遠的地方來，要聽所羅門智慧的話語。看，比所羅門更大的就在這裡！</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 馬太福音 8:29"> <span className="woj">「有個汙靈從一個人身上出來以後，走遍無水之地，尋找安歇的地方，卻找不到，</span></span>
<span className="v" id="v44" data-v="44" data-xref="約翰一書 4:4; 啟示錄 13:8–9; 猶大書 1:4–5"> <span className="woj">就說：『我要回到我離開的那屋裡去。』於是它回去，發現那裡空著，已被打掃乾淨，擺設整齊，</span></span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 馬可福音 5:9; 希伯來書 6:4–8"> <span className="woj">就去帶了另外七個比自己更邪惡的靈，進去住在那裡。那個人最後的情況就比先前更壞了。這邪惡的世代也將是這樣。」</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="馬太福音 13:55; 約翰福音 2:12; 約翰福音 7:3"> 耶穌正在向人群講話，這時候他的母親和弟弟們<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="弟弟們——原文直譯「兄弟們」。">h</a></sup>站在外面，想要和他說話。</span>
<span className="v" id="v47" data-v="47"> 有人告訴他：「看，你母親和弟弟們站在外面，想和你說話。」<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有此節。">i</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="馬可福音 3:32–33; 馬太福音 10:37; 路加福音 2:52"> 耶穌回答那對他說話的人，說：<span className="woj">「我的母親是誰呢？我的弟兄是誰呢？」</span></span>
<span className="v" id="v49" data-v="49" data-xref="馬可福音 3:34; 約翰福音 17:8–9; 約翰福音 20:17–20"> 他就伸手指著他的門徒們，說：<span className="woj">「看，我的母親、我的弟兄！</span></span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 8:21; 馬可福音 3:35; 約翰福音 15:14"> <span className="woj">因為凡是遵行我天父旨意的人，他才是我的弟兄、姐妹和母親。」</span></span>
</div>

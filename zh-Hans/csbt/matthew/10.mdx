<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 馬可福音 3:13–15; 馬可福音 6:7–13"> 耶穌召來他的十二個門徒，賜給他們權柄，能驅趕汙靈，也能使各樣的疾病和各樣的症狀痊癒。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:21; 使徒行傳 1:13; 路加福音 5:10"> 以下是十二使徒的名字：<br /><span className="pl pl-1">首先是西門——也叫彼得，</span><br /><span className="pl pl-1">然後是他的弟弟</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="弟弟——原文直譯「兄弟」。">a</a></sup><br /><span className="pl pl-1">安得烈，</span><br /><span className="pl pl-1">西庇太的兒子雅各，</span><br /><span className="pl pl-1">雅各的弟弟約翰，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 3:18; 使徒行傳 1:13; 馬可福音 2:14"> <span className="pl pl-1">腓力和巴多羅邁，</span><br /><span className="pl pl-1">多馬和稅吏馬太，</span><br /><span className="pl pl-1">亞勒腓的兒子雅各，還有達太，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 26:14; 馬太福音 26:47; 約翰福音 13:2"> <span className="pl pl-1">激進派</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="激進派——或譯作「奮銳黨」。">b</a></sup><br /><span className="pl pl-1">的西門，</span><br /><span className="pl pl-1">還有那出賣耶穌的加略人猶大。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 4:9; 使徒行傳 22:21–23; 列王紀下 17:24–41"> 耶穌差派這十二使徒出去，吩咐他們說：<span className="woj">「外邦人的路，你們不要走；撒瑪利亞人的城，你們不要進；</span></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:6; 以西結書 34:6; 以賽亞書 53:6"> <span className="woj">寧願到以色列家迷失的羊那裡去。</span></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 28:31; 馬太福音 3:2; 路加福音 9:60"> <span className="woj">你們去的時候，要傳講說『天國近了。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 3:6; 路加福音 10:9; 使徒行傳 4:30"> <span className="woj">要使病人痊癒，使死人復活，使痲瘋病人潔淨，把鬼魔趕出去。你們無償地得來，也要無償地給與。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> <span className="woj">腰包裡不要帶金銀或銅錢。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前書 5:17–18; 哥林多前書 9:4–14"> <span className="woj">在路上不要帶行囊，不要帶兩件衣服</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="衣服——或譯作「襯袍」。">c</a></sup><span className="woj">，也不要帶鞋子和手杖，因為工人配得自己的食物。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 約伯記 31:32; 士師記 19:16–21"> <span className="woj">「你們無論進哪個城鎮或鄉村，要查問其中配得的人，就住在他那裡，直到你們離去。</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 25:6; 路加福音 10:5–6; 使徒行傳 10:36"> <span className="woj">你們進了他家，要祝那家平安。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 詩篇 35:13; 哥林多後書 2:16"> <span className="woj">如果那一家是配得的，你們的平安就臨到那一家；如果那家是不配得的，你們的平安就歸回你們。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行傳 18:6; 尼希米記 5:13"> <span className="woj">如果有人不接受你們，也不聽你們的話語，你們離開那家那城的時候，要把腳上的塵土跺掉。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:6; 約翰一書 4:17; 約翰福音 15:22–24"> <span className="woj">我確實地告訴你們：在那審判的日子，所多瑪和格摩拉之地所受的，將要比那城還容易受呢！</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比書 2:15; 哥林多前書 14:20"> <span className="woj">「看哪，我差派你們出去，就像把羊送進狼群中，所以你們要像蛇那樣聰明，像鴿子那樣純潔。</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 13:9; 馬太福音 23:34; 使徒行傳 26:11"> <span className="woj">你們要提防人們，因為他們將要把你們送交議會，並且在他們的會堂裡鞭打你們。</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:25–27; 馬太福音 8:4; 詩篇 2:1–6"> <span className="woj">為我的緣故，你們將被帶到總督和君王面前，好對他們和外邦人做見證。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 4:12; 馬可福音 13:11–13; 提摩太後書 4:17"> <span className="woj">當他們把你們交出去的時候，不要憂慮怎樣說或說什麼。到時候，你們就會被賜予該說的話，</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行傳 6:10; 路加福音 12:12"> <span className="woj">因為說話的不是你們自己，而是你們父的靈在你們裡面說話。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 彌迦書 7:5–6; 馬可福音 13:12–13"> <span className="woj">「兄弟將要把兄弟出賣，置於死地；父親對孩子也會這樣。兒女會起來與父母作對，並且害死他們。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 24:13; 雅各書 1:12; 啟示錄 2:10"> <span className="woj">為了我的名，你們將被所有的人憎恨，但是忍耐到底的，這個人將會得救。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 16:28; 使徒行傳 8:1; 馬可福音 13:26"> <span className="woj">他們在這城逼迫你們，你們就逃到別的城去。我確實地告訴你們：在你們走遍以色列的城鎮之前，人子必定來臨。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 15:20; 路加福音 6:40; 約翰福音 13:16"> <span className="woj">學生不高於他的老師，奴僕也不高於他的主人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 馬太福音 12:24; 馬太福音 9:34"> <span className="woj">學生能像他的老師一樣，奴僕能像他的主人一樣，就已經夠了。如果人們稱一家的主人為『別西卜』，更何況他的家人呢！</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 馬可福音 4:22; 耶利米書 1:8"> <span className="woj">「所以不要怕他們，因為被遮蓋的事沒有將不被顯露出來的，隱祕的事也沒有將不被知道的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 5:20; 約翰福音 16:13; 約翰福音 16:1"> <span className="woj">我在暗中告訴你們的，你們要在明處說出來；你們在耳邊聽到的，要在屋頂上宣揚出去。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以賽亞書 8:12–13; 啟示錄 2:10"> <span className="woj">你們不要怕那些能殺死身體卻不能殺死靈魂的；反而倒要懼怕那位能把靈魂和身體都毀滅在地獄裡的。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 詩篇 104:27–30"> <span className="woj">兩隻麻雀不是賣一個小錢</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="小錢——原文為「阿撒利」。1阿撒利=約1/16日工資的羅馬銅幣。">d</a></sup><span className="woj">嗎？但如果沒有你們父的允許</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="允許——輔助詞語。">e</a></sup><span className="woj">，一隻也不會掉在地上。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳記上 14:45; 使徒行傳 27:34"> <span className="woj">至於你們，就是每一根頭髮也都被數過了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 詩篇 8:5; 馬太福音 6:26"> <span className="woj">所以不要怕！你們比一大群麻雀還重要。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="啟示錄 3:5; 羅馬書 10:9–10; 路加福音 12:8–9"> <span className="woj">「凡是在人面前承認我的，我在我天上的父面前也將承認他；</span></span>
<span className="v" id="v33" data-v="33" data-xref="提摩太後書 2:12; 路加福音 9:26; 路加福音 12:9"> <span className="woj">但無論誰在人面前不認我，我在我天上的父面前也將不認他。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行傳 14:4; 使徒行傳 13:45–50"> <span className="woj">不要以為我來了，是給地上帶來和平。我來並不是帶來和平，而是刀劍，</span></span>
<span className="v" id="v35" data-v="35" data-xref="彌迦書 7:5–6; 馬太福音 10:21; 路加福音 21:16"> <span className="woj">因為我來就是為了：</span><br /><span className="pl pl-1 woj">使『人與父親對立，</span><br /><span className="pl pl-1 woj">女兒與母親對立，</span><br /><span className="pl pl-1 woj">媳婦與婆婆對立，</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="彌迦書 7:6; 耶利米書 12:6; 詩篇 41:9"> <span className="pl pl-1 woj">這樣，一個人的敵人</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="敵人——或譯作「反對者」。">f</a></sup><br /><span className="pl pl-1 woj">，</span><br /><span className="pl pl-1 woj">就是自己家裡的人。』</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 馬太福音 22:37; 腓立比書 3:7–9"> <span className="woj">「那愛父親或母親過於愛我的，不配屬於我；那愛兒子或女兒過於愛我的，不配屬於我；</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 馬可福音 8:34; 馬太福音 16:24"> <span className="woj">不背起自己的十字架來跟從我的，也不配屬於我。</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 12:25; 馬可福音 8:35–36; 路加福音 17:33"> <span className="woj">尋得自己生命的，將失去生命；為我的緣故失去自己生命的，將尋得生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> <span className="woj">「接受你們的，就是接受我；接受我的，就是接受差派我來的那一位。</span></span>
<span className="v" id="v41" data-v="41" data-xref="約翰三書 1:5–8; 希伯來書 6:10; 列王紀下 4:16–17"> <span className="woj">因著先知的名份接受先知的，將得到先知的報償；因著義人的名份接受義人的，將得到義人的報償。</span></span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 6:10; 馬太福音 25:40; 馬可福音 9:41–42"> <span className="woj">無論誰，因著門徒的名份，就是拿一杯涼水給這些卑微人中的一個喝，我確實地告訴你們：他絕不會失去他的報償。」</span></span>

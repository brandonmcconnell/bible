<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:4–10; 馬太福音 13:1–15; 馬可福音 4:1–12"> 那一天，耶穌從屋子裡出來，在湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直譯「海」；指「加利利湖（海）」。">a</a></sup>邊坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 5:3; 馬太福音 4:25; 馬可福音 4:1"> 有一大群人聚集到他那裡，所以他上了一條船坐下來。眾人都站在岸邊。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬可福音 4:2–9; 馬可福音 4:13; 詩篇 78:2"> 耶穌用比喻對他們講了很多事。他說：<span className="woj">「看哪，有一個撒種的出去撒種。</span></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 13:18–19"> <span className="woj">他撒的時候，有些種子落在路邊，飛鳥來把它們吃掉了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 11:19; 以西結書 36:26; 撒迦利亞書 7:12"> <span className="woj">有些落在岩石地上，那裡沒有多少泥土，它們立刻就發芽了，因為土不深；</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:21; 雅各書 1:11–12; 歌羅西書 1:23"> <span className="woj">當太陽升起，它們被暴曬，就枯萎了，因為沒有根。</span></span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 4:18–19; 耶利米書 4:3–4; 創世記 3:18"> <span className="woj">有些落進荊棘叢裡，荊棘長起來，就把它們擠住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 13:23; 路加福音 8:15; 創世記 26:12"> <span className="woj">但是另有落在好土壤上的，就不斷地結出果實來，有一百倍的，有六十倍的，有三十倍的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:11; 馬太福音 11:15; 啟示錄 2:7"> <span className="woj">凡是有耳的</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有耳的——有古抄本作「有耳可聽的」。">b</a></sup><span className="woj">，就應當聽！」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬可福音 4:33–34; 馬可福音 4:10"> 門徒們上前來，問耶穌：「你對他們講話，為什麼用比喻呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 2:9–10; 哥林多前書 2:14; 馬太福音 19:11"> 耶穌回答他們，說：<span className="woj">「天國的奧祕已經賜下來讓你們知道，而沒有賜給那些人；</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:29; 馬可福音 4:24–25; 路加福音 8:18"> <span className="woj">因為凡是有的，還要賜給他，使他豐足有餘；凡是沒有的，連他有的也將從他那裡被拿走。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 12:2; 耶利米書 5:21; 以賽亞書 42:18–20"> <span className="woj">我之所以用比喻對他們說，是因為他們雖然看了，卻看不見；聽了，卻聽不進，也不領悟。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 6:9–10; 以西結書 12:2; 哥林多後書 3:14"> <span className="woj">在他們身上，正應驗了以賽亞的預言，他說：</span><br /><span className="pl pl-1 woj">『你們將聽了又聽，但絕不會領悟；</span><br /><span className="pl pl-1 woj">你們將看了又看，但絕不會明白；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 6:10; 馬可福音 4:12; 撒迦利亞書 7:11"> <span className="pl pl-1 woj">因為這子民的心麻木了，</span><br /><span className="pl pl-1 woj">他們充耳不聞，眼睛閉著；</span><br /><span className="pl pl-1 woj">免得他們眼睛看見，耳朵聽見，心裡領悟，</span><br /><span className="pl pl-1 woj">回轉過來，我就使他們痊癒。』</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:23–24; 以弗所書 1:17–18; 馬太福音 16:17"> <span className="woj">「但你們的眼睛是蒙福的，因為看見了；你們的耳朵是蒙福的，因為聽見了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 8:56; 希伯來書 11:13; 彼得前書 1:10–12"> <span className="woj">我確實地告訴你們：曾經有許多先知和義人渴望看你們所看見的，卻沒有看到；渴望聽你們所聽見的，卻沒有聽到。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:11–12; 路加福音 8:11–15; 馬可福音 4:13–20"> <span className="woj">「所以，你們應當聽這撒種的比喻：</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 8:11–15; 馬太福音 13:38; 希伯來書 2:1"> <span className="woj">無論誰聽了天國的話語而不領悟，那惡者就來，把那撒在他心裡的奪走；這就是那被撒上種子的『路邊之地』。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 33:31–32; 詩篇 106:12–13; 約翰福音 5:35"> <span className="woj">那被撒上種子的『岩石地』是這樣的人：他聽了這話語，立刻懷著喜樂的心接受了它；</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 11:6; 彼得後書 1:8–9; 以弗所書 3:17"> <span className="woj">只是他裡面沒有根而不能持久，一旦為這話語受患難或逼迫，他立刻就放棄</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="放棄——原文直譯「絆倒」。">c</a></sup><span className="woj">了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前書 6:17; 路加福音 8:14; 提摩太前書 6:9–10"> <span className="woj">那被撒進種子的『荊棘叢』是這樣的人：他聽了這話語，但今世的憂慮和財富的迷惑把話語擠住了，他就成了不結果實的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 1:11; 馬太福音 12:33; 約翰福音 15:16"> <span className="woj">那被撒上種子的『好土壤』是這樣的人：他聽了這話語，就領悟了，必然結出果實來，結出的有一百倍的、有六十倍的、有三十倍的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 25:1; 馬太福音 13:47; 馬太福音 20:1"> 耶穌對他們講了另一個比喻說：<span className="woj">「天國好比一個人把好種子撒在自己的田裡。</span></span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 5:8; 彼得後書 2:1; 使徒行傳 20:30–31"> <span className="woj">但是當人們睡覺的時候，他的仇敵來把稗子撒在麥子中間，然後離開了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 4:26–29"> <span className="woj">到了麥苗長大結穗的時候，稗子也顯出來了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 16:17; 哥林多後書 6:1; 哥林多後書 5:18–20"> <span className="woj">奴僕前來問那家的主人，說：『主人，你不是把好種子撒在你的田裡嗎？從哪裡來的這些稗子呢？』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 5:3–7; 帖撒羅尼迦前書 5:14; 路加福音 9:49–54"> <span className="woj">「主人告訴他們：『這是仇敵做的。』</span><br /><span className="woj">「奴僕問：『那麼，你要我們去把稗子拔掉嗎？』</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> <span className="woj">「主人說：『不，免得你們把稗子拔掉的時候，也把麥子一同連根拔出來。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 3:12; 提摩太前書 5:24; 哥林多前書 4:5"> <span className="woj">讓兩樣一起長吧，直到收割的季節。在收割的時候，我要吩咐收割的人先把稗子拔掉，把它們綁成一捆一捆的好去燒掉，然後把麥子收進我的倉庫裡。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 13:18–19; 馬太福音 17:20; 馬可福音 4:30–32"> 耶穌對他們講了另一個比喻說：<span className="woj">「天國好比一粒芥菜種子，有人拿去種在他的田裡。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 31:6; 但以理書 4:12; 以西結書 17:23–24"> <span className="woj">它雖然比所有的種子更小，長大以後，卻比各種蔬菜更大，成了一棵樹，結果天空的飛鳥來了，在它的枝子上搭窩。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="加拉太書 5:9; 哥林多前書 5:6–7; 路加福音 13:21"> 耶穌又對他們講了另一個比喻：<span className="woj">「天國好比酵母，一個婦人拿去拌在</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="拌在——原文直譯「藏在」。">d</a></sup><span className="woj">三斗</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三斗——原文為「3撒頓」；容量約為22公升。1撒頓=7.3公升。">e</a></sup><span className="woj">麵裡，直到整團麵都發了酵。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 4:33–34; 約翰福音 16:25; 馬太福音 13:13"> 耶穌用比喻向人群講了這一切；他向他們講話，沒有不用比喻的。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 78:2; 以弗所書 3:9; 彼得前書 1:20–21"> 這是為要應驗那藉著先知所說的話：<br /><span className="pl pl-1">「我要開口，</span><br /><span className="pl pl-1">用比喻說出創世以來被隱藏的事。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約翰福音 16:17–20; 馬太福音 13:11; 馬太福音 9:28"> 然後，耶穌離開了人群，進了屋子。他的門徒們上前來，說：「請給我們解釋一下田裡稗子的比喻。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 3:5–7; 馬太福音 13:41; 路加福音 10:16"> 耶穌回答說：<span className="woj">「那撒好種子的是人子。</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 8:44; 腓立比書 3:18–19; 使徒行傳 13:10"> <span className="woj">田地是這世界，這些好種子就是天國的兒女，稗子是那惡者的兒女，</span></span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 13:49; 啟示錄 14:15–19; 馬太福音 25:31"> <span className="woj">撒稗子的仇敵是魔鬼，收割的季節是世代的終結，收割的人是天使。</span></span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 13:39"> <span className="woj">就像稗子被拔出來用火燒掉，在這世代的終結也將是這樣。</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 24:31; 馬太福音 18:7; 彼得後書 2:1–2"> <span className="woj">人子要差派他的天使們，從他的國度裡挑出來所有絆腳的和作惡</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="惡——原文直譯「不法」。">f</a></sup><span className="woj">的，</span></span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 13:50; 路加福音 16:23–24; 馬太福音 8:12"> <span className="woj">把他們丟進火爐裡。在那裡將有哀哭和切齒。</span></span>
<span className="v" id="v43" data-v="43" data-xref="但以理書 12:3; 馬太福音 11:15; 路加福音 12:32"> <span className="woj">那時，義人會在他們父的國度裡像太陽一樣發光。凡是有耳的</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有耳的——有古抄本作「有耳可聽的」。">g</a></sup><span className="woj">，就應當聽！</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; 歌羅西書 2:3; 腓立比書 3:7–9"> <span className="woj">「天國好比被藏在田裡的財寶。有人發現了，就把它再藏起來，然後高高興興地去賣掉他所擁有的一切，買下了那塊地。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; 馬太福音 16:26; 馬太福音 13:24"> <span className="woj">「天國又好比一個商人尋找精美的珍珠。</span></span>
<span className="v" id="v46" data-v="46" data-xref="以弗所書 3:8; 路加福音 18:28–30; 箴言 2:4"> <span className="woj">當他發現了一顆極其貴重的珍珠，就去賣掉他所擁有的一切，買下了那顆珍珠。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="約翰福音 15:6; 提摩太後書 3:2–5; 馬太福音 22:9–10"> <span className="woj">「天國又好比一張漁網撒在海裡，網到了各種魚類。</span></span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 13:30; 馬太福音 13:40–43; 馬太福音 3:12"> <span className="woj">網一滿了，漁夫們就把它拉上岸來，然後坐下，把好的收進筐裡，把壞的丟在外面。</span></span>
<span className="v" id="v49" data-v="49" data-xref="啟示錄 20:12–15; 馬太福音 24:31; 馬太福音 13:39"> <span className="woj">在這世代的終結也將是這樣。天使們要出去，把惡人從義人中分別出來，</span></span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 13:42; 馬太福音 8:12; 啟示錄 14:10–11"> <span className="woj">丟進火爐裡。在那裡將有哀哭和切齒。」</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="馬太福音 13:19; 馬太福音 13:11; 馬可福音 4:34"> 耶穌問他們<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「耶穌問他們」。">h</a></sup>：<span className="woj">「這一切你們都領悟了嗎？」</span><br />他們說：「是的，領悟了<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="領悟了——輔助詞語。">i</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="約翰一書 2:7–8; 提摩太後書 3:16–17; 提多書 1:9"> 耶穌對他們說：<span className="woj">「為此，凡是成為天國門徒的經文士，就好比一家的主人，從他的寶庫裡拿出新的和舊的東西來。」</span></span>
<span className="v" id="v53" data-v="53" data-xref="馬太福音 7:28; 馬可福音 4:33–35"> 當耶穌講完了這些比喻，就離開了那地方。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="馬太福音 7:28; 約翰福音 7:15–16; 馬可福音 6:1–6"> 他來到自己的家鄉，在他們的會堂裡教導人，以致他們驚嘆不已，說：「這個人的這種智慧和能力是從哪裡來的呢？</span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 6:42; 馬可福音 6:3; 路加福音 3:23"> 這不就是那木匠的兒子嗎？他的母親不是叫瑪麗亞嗎？他的弟弟們<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="弟弟們——原文直譯「兄弟們」。">j</a></sup>不是雅各、約西<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="約西——有古抄本作「約瑟」。">k</a></sup>、西門和猶大嗎？</span>

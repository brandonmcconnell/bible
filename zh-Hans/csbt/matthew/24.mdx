<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 13:1–37; 路加福音 21:5–36; 以西結書 8:6"> 耶穌從聖殿出來，往前走的時候，他的門徒們上前來，把聖殿的建築指給他看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:44; 耶利米書 26:18; 彌迦書 3:12"> 耶穌回應說：<span className="woj">「你們不是看見了這一切嗎？我確實地告訴你們：這裡將絕不會有一塊石頭留在另一塊石頭上而不被拆下。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬可福音 13:3–4; 使徒行傳 1:7; 帖撒羅尼迦前書 5:1–11"> 耶穌在橄欖山上坐著，門徒們悄悄地前來問他：「請告訴我們，這些事什麼時候會發生呢？你的來臨和這世代的終結會有什麼預兆呢？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰一書 4:1; 耶利米書 29:8; 帖撒羅尼迦後書 2:3"> 耶穌回答他們，說：<span className="woj">「你們要當心，免得有人迷惑你們。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 24:11; 馬太福音 24:24; 耶利米書 14:14"> <span className="woj">因為許多人會以我的名而來，聲稱『我是基督』，並且會迷惑許多人。</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:7–8; 路加福音 21:9; 彼得前書 3:14–15"> <span className="woj">你們也將會聽見戰爭和戰爭的消息。要注意，不可驚慌，因為這些事必須發生，不過結局還沒有到。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 啟示錄 6:8; 以賽亞書 19:2"> <span className="woj">一個民族要起來反對另一個民族，一個國家要起來反對另一個國家；到處都會有饑荒</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「瘟疫」。">a</a></sup><span className="woj">和地震。</span></span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:3; 彼得前書 4:17–18; 申命記 28:59"> <span className="woj">這些都像臨產陣痛的開始。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 16:2; 約翰福音 15:19–20; 路加福音 21:16–17"> <span className="woj">「那時，他們將要出賣你們，使你們受患難，甚至殺害你們。為了我的名，你們將被萬民憎恨。</span></span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 7:5–6; 路加福音 21:16; 馬太福音 11:6"> <span className="woj">那時，許多人將被絆倒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="被絆倒——或譯作「放棄信仰」。">b</a></sup><span className="woj">，彼此出賣，彼此憎恨；</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 24:24; 馬太福音 7:15; 馬太福音 24:5"> <span className="woj">並且會有許多假先知起來，迷惑許多人；</span></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 2:4–5; 雅各書 4:1–4; 啟示錄 3:15"> <span className="woj">由於罪惡</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="罪惡——原文直譯「不法」。">c</a></sup><span className="woj">增多，許多人的愛心就會冷淡。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 10:22; 馬可福音 13:13; 啟示錄 2:10"> <span className="woj">但是忍耐到底的，這個人將會得救。</span></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 14:6; 羅馬書 10:18; 羅馬書 16:25–26"> <span className="woj">這天國的福音將被傳遍天下，好對萬國做見證，然後結局才會到來。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 9:27; 但以理書 12:11; 馬可福音 13:14"> <span className="woj">「當你們看見藉著先知但以理所說的『那帶來毀滅的褻瀆者</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="褻瀆者——或譯作「褻瀆之物」。">d</a></sup><span className="woj">』</span><span className="woj">站在聖地的時候</span>——讀者應當思考——</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:15–17; 路加福音 21:21–22; 希伯來書 11:7"> <span className="woj">那時，在猶太的人應當逃到山裡；</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 馬可福音 13:15–16; 馬太福音 10:27"> <span className="woj">在屋頂上的人，不要下來拿屋子裡的東西；</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">在田裡的人，不要返回去拿自己的衣服。</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命記 28:53–56; 路加福音 21:23"> <span className="woj">在那些日子裡，孕婦和哺乳的女人有禍了！</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:29; 使徒行傳 1:12"> <span className="woj">你們要禱告，好讓你們逃難的時候不在冬天，也不在安息日。</span></span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 12:1; 約珥書 2:2; 瑪拉基書 4:1"> <span className="woj">因為那時將有大患難。這樣的患難從世界開始直到如今，從來沒有發生過，也絕不再發生。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 13:20; 提摩太後書 2:10; 馬太福音 24:31"> <span className="woj">如果那些日子不被減少，就沒有一個人</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="人——原文直譯「肉體」。">e</a></sup><span className="woj">能得救。可是為了那些蒙揀選的人，那些日子將被減少。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命記 13:1–3"> <span className="woj">「那時候，如果有人對你們說『看哪，基督在這裡！』或『他在那裡！』你們不要相信。</span></span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦後書 2:9–11; 馬可福音 13:22; 啟示錄 13:13–14"> <span className="woj">因為假基督們和假先知們會出現，行大神蹟和奇事，如果有可能，甚至迷惑那些蒙揀選的人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:1; 路加福音 21:13; 以賽亞書 48:5–6"> <span className="woj">看哪，我已經預先告訴你們了！</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以賽亞書 40:3; 馬太福音 3:1"> <span className="woj">所以，如果有人對你們說『看哪，基督在曠野裡！』你們不要出去；有人說：『看哪，他在內室裡！』你們也不要相信；</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亞書 9:14; 約伯記 37:3"> <span className="woj">因為就像閃電從東邊發出，直照到西邊，人子的來臨也將要這樣。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 約伯記 39:27–30; 申命記 28:49"> <span className="woj">屍體在哪裡，禿鷹就聚集在哪裡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="阿摩司書 8:9; 約珥書 3:15; 以賽亞書 13:10"> <span className="woj">「那些日子的患難一過去，</span><br /><span className="pl pl-1 woj">『太陽就要變黑，</span><br /><span className="pl pl-1 woj">月亮也不發光，</span><br /><span className="pl pl-1 woj">星辰要從天上墜落，</span><br /><span className="pl pl-1 woj">諸天的各勢力也將被震動。』</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="啟示錄 1:7; 但以理書 7:13; 路加福音 21:27"> <span className="woj">「那時候，人子的徵兆將要顯現在天上，地上的萬族都要捶胸哀哭。他們將要看見人子帶著極大的權能和榮耀，在天上的雲彩中來臨。</span></span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦前書 4:16; 馬可福音 13:27; 以賽亞書 27:13"> <span className="woj">在嘹亮的號角聲中，他要差派他的天使們從四方，從天這邊到天那邊，召集他所揀選的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 13:28–29; 路加福音 21:29–30"> <span className="woj">「你們要從無花果樹那裡學個比喻：當無花果樹的枝子發嫩長出葉子的時候，你們就知道夏天快到了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 5:9; 希伯來書 10:37; 以西結書 7:2–14"> <span className="woj">照樣，當你們看見這一切的時候，你們就知道人子</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="人子——原文直譯「他」或「它」；可指「人子」，也可指「那時刻」。">f</a></sup><span className="woj">快到了，就在門口了。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 13:30–31; 路加福音 21:32–33; 馬太福音 16:28"> <span className="woj">我確實地告訴你們：在這一切事發生之前，這世代絕不會過去。</span></span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 40:8; 彼得前書 1:25; 民數記 23:19"> <span className="woj">天和地將要消逝，但是我的話絕不會消逝。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 13:32; 使徒行傳 1:7; 馬太福音 24:44"> <span className="woj">「至於那日子和那時刻，沒有人知道，連諸天之上的天使們也不知道，子也不知道，</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「子也不知道，」。">g</a></sup><span className="woj">唯有父知道。</span></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 創世記 6:1–7; 彼得後書 2:5"> <span className="woj">挪亞的那些日子怎樣，人子的來臨也將要怎樣。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 羅馬書 13:13–14; 路加福音 14:18–20"> <span className="woj">在洪水以前的那些日子裡，人們繼續吃、喝、嫁、娶，直到挪亞進方舟的那一天。</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 3:20; 馬太福音 24:37; 使徒行傳 13:41"> <span className="woj">他們毫不察覺，直到洪水到來，把一切沖走。人子的來臨，也將是這樣。</span></span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得後書 2:7–9; 彼得後書 2:5"> <span className="woj">那時，兩個人在田裡，一個被接去，一個被留下。</span></span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 11:5; 以賽亞書 47:2; 路加福音 17:35"> <span className="woj">兩個女人在磨石那裡推磨，一個被接去，一個被留下。</span></span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒羅尼迦前書 5:6; 馬太福音 25:13"> <span className="woj">所以你們要警醒，因為你們不知道你們的主哪一天</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="哪一天——有古抄本作「什麼時候」。">h</a></sup><span className="woj">回來。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 馬太福音 24:44; 帖撒羅尼迦前書 5:2–6"> <span className="woj">不過你們應當知道這一點：一家的主人如果知道賊什麼時刻</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="時刻——原文直譯「更次」。">i</a></sup><span className="woj">來，他就會警醒，不讓他的房子被人鑽進。</span></span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 25:10; 馬太福音 24:42; 馬太福音 25:13"> <span className="woj">你們為了這緣故也應當做好準備，因為在你們意想不到的時候，人子就來了。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 25:21; 馬太福音 25:23; 哥林多前書 4:1–2"> <span className="woj">「究竟誰是那又忠心又聰明的奴僕——受主人委任統管他家裡的人、按時給他們分糧的人呢？</span></span>
<span className="v" id="v46" data-v="46" data-xref="啟示錄 16:15; 路加福音 12:43; 路加福音 12:37"> <span className="woj">主人回來的時候，看見哪個奴僕這樣做，那個奴僕就蒙福了。</span></span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 25:23; 馬太福音 25:21; 路加福音 12:37"> <span className="woj">我確實地告訴你們：主人會委任他統管自己所擁有的一切。</span></span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 18:32; 以賽亞書 32:6; 路加福音 12:45"> <span className="woj">但如果這惡奴心裡說『我的主人會遲延回來</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「回來」。">j</a></sup><span className="woj">』，</span></span>
<span className="v" id="v49" data-v="49" data-xref="啟示錄 17:6; 啟示錄 16:6; 彌迦書 3:5"> <span className="woj">就動手毆打與他同做奴僕的，並且與醉酒的人一起吃喝，</span></span>
<span className="v" id="v50" data-v="50" data-xref="帖撒羅尼迦前書 5:2–3; 啟示錄 3:3; 馬太福音 24:42–44"> <span className="woj">那麼，這奴僕的主人就要在意想不到的日子、在他不知道的時刻回來，</span></span>
<span className="v" id="v51" data-v="51" data-xref="馬太福音 8:12; 馬太福音 22:13; 路加福音 12:46"> <span className="woj">並且會嚴厲懲罰他</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="嚴厲懲罰他——原文直譯「把他砍成兩段」。">k</a></sup><span className="woj">，使他與那些偽善的人有同樣的下場。在那裡將有哀哭和切齒。</span></span>

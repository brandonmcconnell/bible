<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亞書 14:4; 馬可福音 11:1–10; 路加福音 21:37"> 當耶穌和門徒們臨近耶路撒冷，來到橄欖山附近的伯法其的時候，耶穌派了兩個門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 馬可福音 11:2–3; 約翰福音 2:5–8"> 對他們說：<span className="woj">「你們到對面的村子裡去，會立刻發現一頭驢拴在那裡，還有一頭驢駒與牠在一起。把牠們解開，牽來給我。</span></span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:1–2; 使徒行傳 17:25; 哥林多後書 8:9"> <span className="woj">如果有人對你們說什麼，你們就說『主需要牠們，會很快把牠們送來的。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 9:9; 約翰福音 12:15; 馬太福音 1:22"> 這件事發生，是為要應驗那藉著先知所說的話：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 9:9–10; 以賽亞書 62:11; 以賽亞書 12:6"> <span className="pl pl-1">「要對錫安的女兒說</span><br /><span className="pl pl-1">『看哪，你的王來到你這裡，</span><br /><span className="pl pl-1">是謙和的，騎著驢——</span><br /><span className="pl pl-1">一頭小驢，就是驢的駒子。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 39:43; 約翰福音 15:14; 出埃及記 40:16"> 兩個門徒就去，照著耶穌所吩咐的做了。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 9:13; 馬可福音 11:4–8; 路加福音 19:32–35"> 他們牽來了驢和驢駒，把外衣搭在牠們背上，耶穌就坐在上面。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 9:13; 約翰福音 12:13; 利未記 23:40"> 有一大群人把自己的外衣鋪在路上，也有人從樹上砍下枝子鋪在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:24–26; 路加福音 2:14; 約翰福音 12:13–15"> 前行後隨的人群呼喊說：<br /><span className="pl pl-1">「和散那歸於大衛的後裔！</span><br /><span className="pl pl-1">奉主名而來的那一位——</span><br /><span className="pl pl-1">是蒙祝福的！</span><br /><span className="pl pl-1">在至高之處——和散那！」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 9:5; 路得記 1:19; 約翰福音 12:16–19"> 耶穌進了耶路撒冷，全城都轟動了，人們問：「這個人是誰？」</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 6:14; 路加福音 7:16; 約翰福音 7:40"> 眾人說：「這就是從加利利的拿撒勒來的先知耶穌。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 2:14–17; 路加福音 19:45–47; 馬可福音 11:15–18"> 耶穌進了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「神的」。">a</a></sup>聖殿，把所有在聖殿裡做買賣的人都趕了出去。他推翻了兌換銀幣之人的桌子和賣鴿子之人的凳子，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 7:11; 以賽亞書 56:7; 路加福音 19:46"> 對他們說：<span className="woj">「經上記著：『我的殿將被稱為禱告的殿』，而你們卻使它成為賊窩了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 3:1–9; 使徒行傳 10:38; 馬太福音 11:4–5"> 耶穌在聖殿裡，一些瞎眼的和瘸腿的來到他面前，耶穌就使他們痊癒了。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 21:9; 路加福音 19:39–40; 以賽亞書 26:11"> 祭司長們和經文士們看見耶穌所行的神蹟，又見孩子們在聖殿裡呼喊說：「和散那歸於大衛的後裔」，就很生氣。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:2; 馬太福音 11:25; 路加福音 19:39–40"> 他們問耶穌：「你聽見這些小孩在說什麼嗎？」<br />耶穌回答他們，說：<span className="woj">「是的，聽見了</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="聽見了——輔助詞語。">b</a></sup><span className="woj">。難道你們從來沒有讀過『從孩子和吃奶嬰兒的口中，你預備了讚美』這話嗎？」</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 11:18; 馬可福音 11:11; 路加福音 24:50"> 然後，耶穌離開他們，出城到伯大尼去，在那裡過夜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 4:2; 希伯來書 4:15; 馬太福音 12:1"> 清晨，回城的時候，耶穌餓了。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 15:6; 馬可福音 11:14; 提多書 1:16"> 他看見路邊有一棵無花果樹，就上前去，可是樹上除了葉子，什麼也找不到。於是他對那棵樹說：<span className="woj">「你永遠不會再結果子了！」</span>那棵無花果樹立刻就枯萎了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 40:6–8; 馬可福音 11:20–21; 雅各書 1:10–11"> 門徒們看見了，感到驚奇，說：「這棵無花果樹怎麼立刻枯萎了呢？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:6; 馬太福音 17:20; 馬可福音 11:22–23"> 耶穌回答他們，說：<span className="woj">「我確實地告訴你們：你們如果存著信而不疑惑，不僅能做我對這無花果樹所做的，即使對這座山說『願你被挪開，被丟進海裡去！』事情也將成就。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:7; 約翰一書 5:14–15; 馬可福音 11:24"> <span className="woj">你們在禱告中無論求什麼，只要信，就必得著。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 4:7; 馬可福音 11:27–33; 歷代志上 24:1–19"> 耶穌進了聖殿，正教導人的時候，祭司長們和民間的長老們前來問他：「你憑什麼權柄做這些事？是誰給你這權柄的？」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌羅西書 4:6; 馬太福音 10:16"> 耶穌回答他們，說：<span className="woj">「我也要問你們一個問題，如果你們回答我，我就告訴你們我憑什麼權柄做這些事。</span></span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 3:20; 馬可福音 1:1–11; 約翰福音 3:18"> <span className="woj">約翰的洗禮是從哪裡來的？是來自天上，還是來自人間呢？」</span><br />他們就彼此討論，說：「如果我們說『是來自天上』，他就會問我們『那麼你們為什麼不相信他呢？』</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 6:20; 馬太福音 14:5; 約翰福音 5:35"> 但如果說『是來自人間』——我們又怕民眾，因為大家都認為約翰是先知。」</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 1:18–22; 帖撒羅尼迦後書 2:9–10; 路加福音 20:7–8"> 於是他們回答耶穌，說：「我們不知道。」<br />耶穌就對他們說：<span className="woj">「我也不告訴你們我憑什麼權柄做這些事。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 15:58; 馬太福音 20:1; 哥林多前書 10:15"> <span className="woj">「這件事你們怎麼看？一個人有兩個兒子，他前來對大兒子說：『孩子，你今天到葡萄園去做工吧。』</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以西結書 18:28–32; 馬太福音 3:2–8; 以賽亞書 55:6–7"> <span className="woj">「大兒子回答說：『我不願意去。』可是後來他悔改，就去了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="提多書 1:16; 以西結書 33:31; 馬太福音 23:3"> <span className="woj">父親前來對小兒子也說同樣的話。</span><br /><span className="woj">「小兒子回答說：『主啊，我去。』可是他沒有去。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 馬太福音 7:21"> <span className="woj">「這兩個兒子中，哪一個遵行父親的意願呢？」</span><br />他們回答說：「大兒子。」<br />耶穌說：<span className="woj">「我確實地告訴你們：稅吏和妓女要在你們的前面進神的國，</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; 撒迦利亞書 7:11–12; 路加福音 7:29–30"> <span className="woj">因為約翰來到你們這裡指明義的道路，你們不相信他，而那些稅吏和妓女們卻相信了他。你們雖然看見了，後來還是沒有悔改去相信他。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 5:1–4; 馬可福音 12:1–12; 路加福音 20:9–19"> <span className="woj">「你們當聽另一個比喻：有一個人，是一家的主人，他栽種了一個葡萄園，四面圍上籬笆，裡面挖了一個榨酒池，蓋了一座守望樓，然後把葡萄園租給一些農夫，就出外旅行。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; 以賽亞書 5:4; 撒迦利亞書 1:3–6"> <span className="woj">當收果子的季節近了，主人就派了奴僕們到那些農夫那裡去收取他的果子。</span></span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 36:15–16; 馬太福音 5:12; 希伯來書 11:36–37"> <span className="woj">但那些農夫抓住他的奴僕，打了一個，殺了一個，還用石頭砸死一個。</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 22:4"> <span className="woj">主人又派別的奴僕去，比先前的更多，那些農夫也照樣對待他們。</span></span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 3:16; 約翰福音 3:35–36; 西番雅書 3:7"> <span className="woj">後來他差派自己的兒子到他們那裡，說：『他們一定會尊重我的兒子。』</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; 創世記 37:18–20; 馬可福音 12:7–8"> <span className="woj">「可是那些農夫看見他的兒子，就彼此說：『這是繼承人。來，我們把他殺了，占有他的繼業！』</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 2:23; 雅各書 5:6; 路加福音 22:52–54"> <span className="woj">於是他們抓住他，把他扔出葡萄園外，殺了。</span></span>
<span className="v" id="v40" data-v="40" data-xref="希伯來書 10:29; 馬可福音 12:9; 路加福音 20:15–16"> <span className="woj">那麼，葡萄園的主人回來的時候，會怎麼對待那些農夫呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 18:6; 馬太福音 21:43; 使徒行傳 28:28"> 他們回答說：「他會狠狠地除滅那些惡人，把葡萄園另租給按時交果子的農夫們。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v42" data-v="42" data-xref="詩篇 118:22–23; 以賽亞書 28:16; 使徒行傳 4:11"> 耶穌對他們說：<span className="woj">「難道你們從來沒有讀過這段經文嗎？</span><br /><span className="pl pl-1 woj">『工匠所棄絕的石頭，</span><br /><span className="pl pl-1 woj">它已經成了房角的頭塊石頭；</span><br /><span className="pl pl-1 woj">這是主所成就的，</span><br /><span className="pl pl-1 woj">在我們眼中實在奇妙！』</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 21:41; 馬太福音 8:11–12; 彼得前書 2:9"> <span className="woj">為此，我告訴你們：神的國要從你們中間被奪走，賜給那結神國果子的人。</span></span>
<span className="v" id="v44" data-v="44" data-xref="以賽亞書 8:14–15; 彼得前書 2:8; 但以理書 2:34–35"> <span className="woj">那跌落在這石頭上的人，就將被破碎；這石頭落在誰的身上，就會把誰砸得稀爛。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有此節。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 馬太福音 12:12"> 祭司長們和法利賽人聽了耶穌的這些比喻，知道他是針對他們而說的，</span>
<span className="v" id="v46" data-v="46" data-xref="馬太福音 21:11; 馬太福音 21:26; 路加福音 7:16"> 就想拘捕他，可是怕民眾，因為他們都認為耶穌是先知。</span>
</div>

<span className="v" id="v3" data-v="3" data-xref="以賽亞書 66:2; 箴言 29:23; 詩篇 34:18"> <span className="pl pl-1 woj">「靈裡貧乏的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為天國是他們的。</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="詩篇 37:11; 以賽亞書 29:19; 雅各書 3:13"> <span className="pl pl-1 woj">謙和的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為他們將繼承那地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 4:14; 詩篇 107:9; 約翰福音 6:27"> <span className="pl pl-1 woj">飢渴慕義的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為他們將得飽足。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="雅各書 1:12; 彼得前書 3:13–14; 哥林多後書 4:17"> <span className="pl pl-1 woj">為義受逼迫的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為天國是他們的。</span></span>
</div>

<span className="v" id="v12" data-v="12" data-xref="路加福音 6:23; 雅各書 1:2; 歌羅西書 3:24"> <span className="woj">你們當歡喜，當快樂，因為你們在天上的報償是大的。要知道，那些人也這樣逼迫了在你們以前的先知們。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 4:6; 路加福音 14:34–35; 馬可福音 9:49–50"> <span className="woj">「你們是地上的鹽。鹽如果失去了味道，還能用什麼來把它醃成鹹的呢？它再也沒有用處，只好被丟在外面，任人踐踏。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="腓立比書 2:15; 約翰福音 8:12; 以弗所書 5:8–14"> <span className="woj">「你們是世界的光。建在山上的城是不能隱藏的；</span></span>

<span className="v" id="v16" data-v="16" data-xref="彼得前書 2:12; 提多書 2:7; 約翰福音 15:8"> <span className="woj">同樣，你們的光也應當照耀在人前，使他們看見你們的美好工作，就榮耀你們在天上的父。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 10:4; 路加福音 16:17; 加拉太書 4:4–5"> <span className="woj">「你們不要以為我來是要廢除律法和先知</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="先知——或譯作「先知書」。">b</a></sup><span className="woj">，我來不是要廢除，而是要成全。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 16:17; 以賽亞書 40:8; 彼得前書 1:25"> <span className="woj">我確實地告訴你們：即使天和地都消逝了，律法的一點一畫也絕不會消逝，直到一切都成就。</span></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 12:32; 雅各書 2:10–11; 馬太福音 28:20"> <span className="woj">所以，如果有人違犯了這些誡命中最小的一條，又教導人也這樣做，他在天國裡將被稱為最小的；但無論誰遵行這些誡命，又教導人也這樣做，這個人在天國裡將被稱為大的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 10:2–3; 腓立比書 3:9; 羅馬書 9:30–32"> <span className="woj">我告訴你們：你們的義如果不勝過經文士們和法利賽人的義，就絕不能進入天國。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 5:17; 出埃及記 20:13; 民數記 35:30–34"> <span className="woj">「你們聽過那吩咐古人的話：『不可殺人。</span><span className="woj">殺人的，當遭受審判。』</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰一書 3:14–15; 約翰一書 4:20–21; 約翰一書 2:9"> <span className="woj">但是我告訴你們：所有向他弟兄</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「毫無理由地」。">c</a></sup><span className="woj">發怒的，當遭受審判；罵他弟兄『廢物』的，當遭受議會的審判；罵『蠢貨』的，當遭受烈火的地獄。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 11:25; 利未記 6:2–6; 馬太福音 5:24"> <span className="woj">所以，如果你在祭壇獻上祭物的時候，在那裡想起弟兄向你懷著怨，</span></span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 5:16; 羅馬書 12:17–18; 馬太福音 18:15–17"> <span className="woj">就要把祭物留在祭壇前，先去與弟兄和好，然後再回來獻上你的祭物。</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 12:58–59; 箴言 25:8; 希伯來書 3:13"> <span className="woj">你要趁著與你的對頭還在路上的時候，趕快與他和解，免得他把你交給審判官，審判官把你交給差役，你就會被投進監獄了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:34; 路加福音 12:59; 帖撒羅尼迦後書 1:9"> <span className="woj">我確實地告訴你：除非你還清了最後的一個銅幣</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="銅幣——原文為「柯錐特」。1柯錐特=約1/64日工資的羅馬銅幣。">d</a></sup><span className="woj">，否則你絕不能從那裡出來。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 5:18; 箴言 6:32; 出埃及記 20:14"> <span className="woj">「你們聽過那吩咐</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="那吩咐——有古抄本作「那吩咐古人的話」。">e</a></sup><span className="woj">：『不可通姦。』</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰一書 2:16; 雅各書 1:14–15; 箴言 6:25"> <span className="woj">但是我告訴你們：所有懷著慾念看女人的，就已經在心裡和她通姦了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 8:13; 馬可福音 9:43–48; 歌羅西書 3:5"> <span className="woj">如果你的右眼使你絆倒，就把它剜出來丟掉！因為對你來說，失去你身體的一部分</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="身體的一部分——或譯作「一個肢體」。">f</a></sup><span className="woj">，總比你全身被丟進地獄要好。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:43; 馬太福音 5:29; 彼得前書 2:8"> <span className="woj">如果你的右手使你絆倒，就把它砍下來丟掉！因為對你來說，失去你身體的一部分，總比你全身下地獄要好。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="耶利米書 3:1; 申命記 24:1–4; 馬太福音 19:7"> <span className="woj">「又有吩咐：『如果有人休妻，要給妻子一份休書。』</span></span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 7:3; 哥林多前書 7:10–11; 路加福音 16:18"> <span className="woj">但是我告訴你們：凡是休妻的，除非為了淫亂的緣故，否則就是讓她犯通姦罪了；凡是娶了被休的女人的，也是犯通姦罪。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 23:21; 利未記 19:12; 傳道書 5:4–6"> <span className="woj">「另外，你們聽過那吩咐古人的話：『不可起假誓。你所起的誓，總要向主償還。』</span></span>
<span className="v" id="v34" data-v="34" data-xref="雅各書 5:12; 以賽亞書 66:1; 申命記 23:21–23"> <span className="woj">但是我告訴你們：根本不可起誓。不可指著天起誓，因為天是神的寶座；</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 48:2; 瑪拉基書 1:14; 歷代志下 6:6"> <span className="woj">不可指著地起誓，因為地是神的腳凳；不可用耶路撒冷起誓，因為耶路撒冷是那大君王的城；</span></span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 12:25; 馬太福音 6:27; 馬太福音 23:16–21"> <span className="woj">也不可指著自己的頭起誓，因為你不能使一根頭髮變白或變黑。</span></span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 5:12; 歌羅西書 4:6; 歌羅西書 3:9"> <span className="woj">你們的話語應該如此：是，就說是；不是，就說不是。再多說，就是出於那惡者。</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="利未記 24:19–20; 申命記 19:21; 出埃及記 21:22–27"> <span className="woj">「你們聽過這吩咐：『以眼還眼，以牙還牙。』</span></span>
<span className="v" id="v39" data-v="39" data-xref="帖撒羅尼迦前書 5:15; 彼得前書 3:9; 羅馬書 12:17–19"> <span className="woj">但是我告訴你們：不要與惡人作對。有人打你的右臉，把左臉</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="左臉——原文直譯「另一邊」。">g</a></sup><span className="woj">也轉給他；</span></span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 6:29; 哥林多前書 6:7"> <span className="woj">有人想要控告你，並要拿走你的裡衣</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="裡衣——或譯作「襯袍」。">h</a></sup><span className="woj">，你就連外衣也由他拿去；</span></span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:26; 馬太福音 27:32; 馬可福音 15:21"> <span className="woj">有人強迫你走一里</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一里——原文為「1米利翁」。1米利翁=1500公尺。">i</a></sup><span className="woj">路，你就與他一起走兩里；</span></span>
<span className="v" id="v42" data-v="42" data-xref="箴言 19:17; 希伯來書 13:16; 路加福音 6:30–36"> <span className="woj">有人求你，你要給他；有人要向你借什麼，你不要拒絕。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="利未記 19:18; 詩篇 139:21–22; 加拉太書 5:13–14"> <span className="woj">「你們聽過這吩咐：『要愛你的鄰人</span><span className="woj">，恨你的敵人</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="敵人——或譯作「反對者」。">j</a></sup><span className="woj">。』</span></span>

<span className="v" id="v45" data-v="45" data-xref="詩篇 145:9; 路加福音 6:35; 使徒行傳 14:17"> <span className="woj">好讓你們成為你們天父的兒女。因為他使太陽升起，對著惡人，也對著好人；降雨給義人，也給不義的人。</span></span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:32–35; 彼得前書 2:20–23; 馬太福音 9:10–11"> <span className="woj">其實你們如果只愛那些愛你們的人，會有什麼報償呢？連稅吏不也這樣做嗎？</span></span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 5:20; 路加福音 6:32; 彼得前書 2:20"> <span className="woj">你們如果只問候自己的兄弟，這樣做有什麼特別呢？連外邦人</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="外邦人——有古抄本作「稅吏」。">n</a></sup><span className="woj">不也這樣做嗎？</span></span>
<span className="v" id="v48" data-v="48" data-xref="彼得前書 1:15–16; 雅各書 1:4; 利未記 19:2"> <span className="woj">所以，你們當成為完全的，就像你們的天父是完全的。</span></span>

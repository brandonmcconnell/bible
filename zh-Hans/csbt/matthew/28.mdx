<span className="v" id="v1" data-v="1" data-xref="馬可福音 16:1–8; 約翰福音 20:1–10; 馬太福音 27:56"> 過了安息日，在一週的頭一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一週的頭一天——指「星期日」。">a</a></sup>，黎明的時候，茉大拉的瑪麗亞和另一個瑪麗亞來看墳墓。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 16:26; 約翰福音 20:12–13; 馬可福音 16:3–5"> 忽然發生了強烈的地震，主的一位天使從天上降下來，上前把那石頭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「從門口」。">b</a></sup>滾開，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 9:3; 使徒行傳 1:10; 馬可福音 16:5"> 他的容貌像閃電，衣服潔白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 1:17; 但以理書 10:7; 馬太福音 27:65–66"> 看守的衛兵們因怕天使就渾身發抖，變得像死人那樣。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:17–18; 希伯來書 1:14; 以賽亞書 41:10"> 天使對婦女們說：「你們不要怕！我知道你們是在尋找被釘十字架的耶穌。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 16:6; 馬太福音 12:40; 路加福音 24:6–8"> 他不在這裡，因為他已經復活<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="復活——原文直譯「被復活」；指「神使耶穌復活」。">c</a></sup>了，正如他所說過的。你們來看安放他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——有古抄本作「主」。">d</a></sup>的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 26:32; 路加福音 24:22–24; 馬太福音 28:10"> 趕快去告訴他的門徒們：『他從死人中復活了。看哪，他要在你們之前到加利利去。在那裡，你們將見到他。』看哪，我已經告訴你們了！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 2:11; 馬可福音 16:8; 路加福音 24:36–41"> 她們立即離開墓穴，又懼怕，又大大歡喜，跑去告訴耶穌的門徒們。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 28:17; 約翰福音 20:14–17; 馬太福音 14:33"> 這時候<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="這時候——有古抄本作「正當她們要去告訴門徒們的時候」。">e</a></sup>，忽然耶穌迎面而來，說：<span className="woj">「願你們歡喜！」</span>她們就上前來抱住他的腳拜他。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:29; 約翰福音 20:17; 馬太福音 28:7"> 耶穌對她們說：<span className="woj">「不要怕！去告訴我的弟兄們，要他們到加利利去。在那裡，他們將見到我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 27:65–66; 馬太福音 28:4"> 她們離去的時候，正好有一些衛兵進了城，把所發生的事都報告給祭司長們。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:3–4; 使徒行傳 4:5–22; 馬太福音 27:1–2"> 祭司長們就與長老們一起聚集商議，給了士兵們許多銀錢，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:64"> 說：「你們要說：『他的門徒們夜裡來，趁我們睡著的時候，把他偷走了。』</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 27:2; 使徒行傳 12:19"> 如果這事被總督聽見了，我們會說服他，保證你們無事。」</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前書 6:10; 馬太福音 27:8; 馬太福音 26:15"> 士兵們收了銀錢，就照所指示的去做。於是這說法就流傳在猶太人當中，直到今天。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:32; 馬太福音 28:10; 馬太福音 28:7"> 十一個門徒往加利利去，到了耶穌給他們指定的那座山上。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 45:11; 詩篇 2:12; 約翰福音 5:23"> 他們看見耶穌，就拜他，不過還有人疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:35; 彼得前書 3:22; 馬太福音 11:27"> 耶穌前來，對他們說：<span className="woj">「天上和地上所有的權柄都賜給我了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 16:15–16; 使徒行傳 2:38–39; 使徒行傳 1:8"> <span className="woj">所以你們要去，使萬民成為我的門徒；奉父、子、聖靈的名給他們施洗</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="奉父、子、聖靈的名給他們施洗——或譯作「給他們施洗歸入父、子、聖靈的名」。">f</a></sup><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="施洗——或譯作「施浸」。">g</a></sup><span className="woj">；</span></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 41:10; 約書亞記 1:5; 使徒行傳 18:9–10"> <span className="woj">凡我所吩咐你們的，都教導他們遵守。看哪，我就天天都與你們同在，直到這世代的終結。」</span></span>
</div>

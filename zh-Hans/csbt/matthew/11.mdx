<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 61:1–3; 使徒行傳 10:38; 路加福音 8:1"> 當耶穌吩咐完了他的十二個門徒，就離開了那裡，到各城鎮去傳道、教導人。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 6:17; 馬太福音 14:3; 馬太福音 9:14"> 約翰在監獄裡聽說了基督所做的事，就派自己的幾個<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="幾個——有古抄本作「兩個」。">a</a></sup>門徒去</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:27; 瑪拉基書 3:1; 申命記 18:15–18"> 問耶穌：「將要來的那一位就是你嗎？還是我們應該等候別人呢？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶穌回答他們，說：<span className="woj">「你們去把所聽見、所看見的告訴約翰，</span></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 35:4–6; 以賽亞書 61:1–3; 路加福音 4:18"> <span className="woj">就是：瞎眼的得以看見，瘸腿的行走，痲瘋病人被潔淨，耳聾的聽見，死人得以復活，窮人得以聽到福音。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 8:14–15; 哥林多前書 2:14; 馬太福音 26:31"> <span className="woj">凡不因我被絆倒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="被絆倒——或譯作「放棄信仰」。">b</a></sup><span className="woj">的人，就蒙福了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:6; 約翰福音 5:35; 馬可福音 1:3–5"> 約翰的門徒們走了，耶穌就開始對眾人談論約翰，說：<span className="woj">「你們曾經到曠野去，是要觀看什麼呢？一根被風吹動的蘆葦嗎？</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 3:4; 列王紀下 1:8; 撒迦利亞書 13:4"> <span className="woj">你們出去，究竟是要看什麼呢？一個身穿細軟衣服的人嗎？看哪，那些穿細軟衣服的人在王宮裡。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 馬太福音 14:5; 馬太福音 21:24–26"> <span className="woj">你們出去，究竟是要看什麼呢？一位先知嗎？是的，我告訴你們：他比先知還大。</span></span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 3:1; 以賽亞書 40:3; 瑪拉基書 4:5"> <span className="woj">他就是經上記載的那個人：</span><br /><span className="pl pl-1 woj">『看哪，我要差派我的使者在你前頭，</span><br /><span className="pl pl-1 woj">他要在你之前預備你的道</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="道——或譯作「路」。">c</a></sup><br /><span className="pl pl-1 woj">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所書 3:8; 馬太福音 3:11"> <span className="woj">「我確實地告訴你們：在女人所生的人中，沒有出現過一個比施洗者</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="施洗者——或譯作「施浸者」。">d</a></sup><span className="woj">約翰更大的；然而在天國裡，再小的也比約翰更大。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所書 6:11–13"> <span className="woj">從施洗者</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="施洗者——或譯作「施浸者」。">e</a></sup><span className="woj">約翰的日子到現在，天國是努力爭取的，努力爭取的人就得著它。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="天國是努力爭取的，努力爭取的人就得著它。——或譯作「天國受到強烈的攻擊，強者奪取它。」">f</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:17–18; 羅馬書 3:21; 使徒行傳 13:27"> <span className="woj">在約翰之前，所有的先知和律法都說預言。</span></span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 4:5; 馬太福音 17:10–13; 馬可福音 9:11–13"> <span className="woj">如果你們願意接受，約翰就是那位要來的以利亞。</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 馬太福音 13:9; 馬可福音 4:23"> <span className="woj">凡是有耳的</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有耳的——有古抄本作「有耳可聽的」。">g</a></sup><span className="woj">，就應當聽！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 馬太福音 12:34; 馬太福音 23:36"> <span className="woj">「我要把這世代比做什麼呢？它就好比孩子們坐在街市上呼叫別的孩子，</span></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 28:9–13; 以賽亞書 30:29; 耶利米書 9:17–20"> <span className="woj">說：</span><br /><span className="pl pl-1 woj">『我們為你們吹笛，</span><br /><span className="pl pl-1 woj">你們卻不跳舞；</span><br /><span className="pl pl-1 woj">我們唱哀歌，</span><br /><span className="pl pl-1 woj">你們也不捶胸。』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 馬太福音 3:4; 約翰福音 10:20"> <span className="woj">「因為約翰來了，不吃也不喝，他們就說：『他有鬼魔附身！』</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> <span className="woj">人子來了，也吃也喝，他們就說：『看，這個貪食好酒的人！稅吏和罪人的朋友！』然而，智慧是憑著智慧的行為</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="行為——有古抄本作「兒女」。">h</a></sup><span className="woj">被證明為義的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米書 8:6; 提摩太後書 2:25–26"> 接著，耶穌開始斥責那些他曾經在其中行了許多神蹟的城市，因為那裡的人不肯悔改：</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 3:6–7; 使徒行傳 12:20; 路加福音 9:10"> <span className="woj">「哥拉汛哪，你有禍了！伯賽達呀，你有禍了！因為在你們當中行過的神蹟，如果行在提爾和西頓，那裡的人早就會披麻蒙灰悔改了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:24; 馬太福音 10:15; 希伯來書 10:26–31"> <span className="woj">不過我告訴你們：在那審判的日子，提爾和西頓所受的，將要比你們還容易受呢！</span></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 14:13–15; 約翰福音 4:46–54; 創世記 13:13"> <span className="woj">而你——迦百農啊，你將被高舉到天上嗎？不，你將下到陰間。因為在你中間行過的神蹟，如果行在所多瑪，它就會存留到今天。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:15; 馬太福音 11:22; 馬可福音 6:11"> <span className="woj">不過我告訴你們：在那審判的日子，所多瑪之地所受的，將要比你還容易受呢！」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 21:16; 詩篇 8:2; 馬太福音 16:17"> 那時候，耶穌說：<span className="woj">「父啊，天地的主，我讚美</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="讚美——或譯作「感謝」。">i</a></sup><span className="woj">你，因為你把這些事向有智慧的和有學問的人隱藏起來，而向小孩子們顯明出來。</span></span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:9; 以弗所書 1:11; 約伯記 33:13"> <span className="woj">是的，父啊！因為這正是你的美意。</span></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:6–9; 馬太福音 28:18; 路加福音 10:22"> <span className="woj">我父把一切都交給了我。除了父，沒有人認識子；除了子和子所願意啟示的人，也沒有人認識父。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 11:29; 約翰福音 7:37; 約翰福音 6:37"> <span className="woj">「所有勞苦和背負重擔的人哪，到我這裡來吧！我將使你們得到安息。</span></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 6:16; 約翰一書 2:6; 腓立比書 2:7–8"> <span className="woj">你們當負起我的軛，向我學，因為我心地柔和、謙卑。這樣，你們就將尋得靈魂的安息。</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 5:3; 約翰福音 16:33; 腓立比書 4:13"> <span className="woj">要知道，我的軛是容易負的，我的擔子是輕省的。」</span></span>
</div>

<span className="v" id="v1" data-v="1" data-xref="馬太福音 20:1–16; 馬太福音 12:43–45; 路加福音 14:16"> 耶穌又用比喻對他們說：</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 19:7–9; 馬太福音 13:24; 以弗所書 5:24–32"> <span className="woj">「天國好比一個君王，為自己的兒子預備婚宴。</span></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 22:17; 約翰福音 5:40; 路加福音 14:15–17"> <span className="woj">他派了奴僕們去叫那些被邀請的人前來赴宴，可是他們不肯來。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 13:46; 馬太福音 21:36; 約翰福音 6:50–57"> <span className="woj">王又派了別的奴僕，說：『你們去對那些被邀請的人說，看哪，我的午餐我已經預備好了，公牛和肥畜已經宰殺了，一切都預備好了，請你們來赴婚宴。』</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="希伯來書 2:3; 路加福音 14:18–20; 約翰一書 2:15–16"> <span className="woj">「但那些人不理，就走開了，有的到自己的田裡去，有的做自己的生意去。</span></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:19–20; 約翰福音 16:2–3; 使徒行傳 7:51–57"> <span className="woj">其餘的竟抓住王的奴僕們，凌辱他們，並且把他們殺了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前書 4:17–18; 路加福音 21:24"> <span className="woj">王</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「聽了」。">a</a></sup><span className="woj">就發怒，派軍兵除滅那些凶手，燒毀了他們的城。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦後書 1:5; 使徒行傳 13:46; 啟示錄 3:4"> <span className="woj">「然後對奴僕們說：『婚宴預備好了，但那些被邀請的人不配。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 馬可福音 16:15–16"> <span className="woj">所以你們要到大街小巷去，把所見到的人都請來赴宴。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 6:9–11; 啟示錄 19:6–9; 哥林多後書 12:21"> <span className="woj">那些奴僕就出去，到大街上，把所見到的，無論好人壞人都召集起來，婚宴上就坐滿了賓客。</span></span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 3:4–5; 啟示錄 19:8; 希伯來書 4:12–13"> <span className="woj">王進來會見賓客，發現有一個人沒有穿婚宴的禮服，</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:9; 約伯記 5:16; 馬太福音 20:13"> <span className="woj">就對他說：『朋友，你進到這裡來怎麼沒有穿婚宴的禮服呢？』那個人啞口無言。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 8:12; 馬太福音 25:30; 馬太福音 24:51"> <span className="woj">「於是王吩咐僕人們：『把他的手腳捆起來，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「帶去」。">b</a></sup><span className="woj">丟到外面的黑暗裡去！在那裡將有哀哭和切齒。』</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得後書 1:10; 路加福音 13:23–24; 馬太福音 7:13–14"> <span className="woj">「要知道，蒙召喚的人多，而蒙揀選的人少。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 馬可福音 12:13–17; 詩篇 2:2"> 法利賽人就去商議，怎樣找耶穌的話柄來陷害他。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 3:6; 馬可福音 8:15; 馬可福音 12:14"> 他們派了自己的門徒們與希律黨的人一同去見耶穌，說：「老師，我們知道你是真誠的，並且按真理教導神的道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="道——或譯作「路」。">c</a></sup>。你不顧忌任何人，因為你不看人的情面。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 羅馬書 13:6–7; 馬太福音 17:25"> 請告訴我們，你認為向凱撒納稅，可以不可以呢？」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 8:6; 路加福音 5:22; 約翰福音 2:25"> 耶穌看出他們的惡意，就說：<span className="woj">「你們這些偽善的人！為什麼試探我呢？</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 20:2; 啟示錄 6:6; 馬太福音 18:28"> <span className="woj">拿一個納稅的錢幣給我看。」</span>他們就拿來了一個銀幣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="銀幣——原文為「得拿利」。1得拿利=約1日工資的羅馬銀幣。">d</a></sup>給他。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶穌問他們：<span className="woj">「這是誰的像和名號？」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="羅馬書 13:7; 箴言 24:21; 使徒行傳 4:19"> 他們回答說：「是凱撒的。」<br />耶穌對他們說：<span className="woj">「那麼，凱撒的歸給凱撒；神的歸給神。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 12:12; 馬太福音 22:46; 路加福音 20:25–26"> 他們聽了，感到驚奇，就離開耶穌走了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 4:1; 馬可福音 12:18–27; 使徒行傳 23:6–8"> 在那一天，撒都該人來到耶穌那裡，他們一向說沒有復活的事。他們問耶穌，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 25:5–10; 路加福音 20:28; 路得記 1:11"> 說：「老師，摩西說：如果一個人死了，沒有兒女，他的一個兄弟就要娶他的妻子，為他兄弟留後裔。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 馬可福音 12:19–23; 希伯來書 9:27"> 我們這裡曾經有兄弟七人，第一個結了婚，死了，沒有後裔，留下妻子給他的一個兄弟。</span>
<span className="v" id="v26" data-v="26"> 第二個、第三個、一直到第七個，都是如此。</span>
<span className="v" id="v27" data-v="27"> 到了最後，這婦人也死了。</span>
<span className="v" id="v28" data-v="28"> 既然他們都娶過她，那麼，在復活的時候，她將是這七個人中哪一個的妻子呢？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰福音 20:9; 羅馬書 15:4; 路加福音 1:37"> 耶穌回答說：<span className="woj">「你們錯了，因為你們不明白經上的話，也不明白神的大能。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 馬可福音 12:24–25; 馬太福音 24:38"> <span className="woj">復活的時候，人既不娶也不嫁，而是像天上的</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「神的」。">e</a></sup><span className="woj">天使一樣。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 12:3; 馬太福音 21:16; 馬太福音 21:42"> <span className="woj">關於死人復活的事，你們難道沒有讀過神對你們所說的話嗎？神說</span></span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 3:6; 馬可福音 12:26–27; 路加福音 20:37–38"> <span className="woj">『我是亞伯拉罕的神、以撒的神、雅各的神。』神不是死人的神，而是活人的神。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬可福音 12:17; 馬可福音 6:2; 約翰福音 7:46"> 眾人聽了這話，對他的教導驚嘆不已。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 12:28–31; 馬太福音 25:3–5; 馬太福音 12:14"> 法利賽人聽說耶穌使撒都該人啞口無言，就聚集在一起。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 他們當中有一個是律法師，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「是律法師，」。">f</a></sup>來試探耶穌，問他：</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 12:28–33; 馬太福音 5:19–20; 路加福音 11:42"> 「老師，律法中最大的誡命是哪一條呢？」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬可福音 12:29–30; 路加福音 10:27; 申命記 6:5"> 耶穌對他說：<span className="woj">「『你要以全心、全靈、全意愛主——你的神』，</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">這是最大的，也是最重要的誡命。</span></span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 12:31; 路加福音 10:27–37; 利未記 19:18"> <span className="woj">其次的也和它類似，『要愛鄰如己。』</span></span>
<span className="v" id="v40" data-v="40" data-xref="羅馬書 13:9; 馬太福音 7:12; 約翰一書 4:19–21"> <span className="woj">全部律法和先知書都是以這兩條誡命為依據的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 馬可福音 12:35–37; 馬太福音 22:34"> 法利賽人聚集在一起的時候，耶穌問他們</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 23:5–6; 約翰福音 6:68–69; 馬太福音 16:13–17"> 說：<span className="woj">「關於基督，你們怎麼看？他是誰的後裔呢？」</span><br />他們說：「是大衛的後裔。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 23:2; 啟示錄 4:2; 馬可福音 12:36"> 耶穌問他們：<span className="woj">「那麼，大衛藉著聖靈，怎麼還稱他為『主』呢？大衛說：</span></span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:1; 希伯來書 1:13; 使徒行傳 2:34–35"> <span className="pl pl-1 woj">『主對我主說：</span><br /><span className="pl pl-1 woj">你坐在我的右邊，</span><br /><span className="pl pl-1 woj">等我把你的敵人放在你的腳下</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「做腳凳」。">g</a></sup><br /><span className="pl pl-1 woj">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="羅馬書 1:3–4; 啟示錄 22:16; 約翰福音 8:58"> <span className="woj">「因此，大衛如果稱基督為『主』，基督怎麼會是大衛的後裔呢？」</span></span>
<span className="v" id="v46" data-v="46" data-xref="馬可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 沒有人能回答他一句話。從那天起，再也沒有人敢質問耶穌了。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 馬可福音 8:15; 路加福音 9:7–9"> 那時候，分封王希律聽到耶穌的消息，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 16:14; 約翰福音 10:41; 馬可福音 8:28"> 就對他的臣僕說：「這個人是施洗者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="施洗者——或譯作「施浸者」。">a</a></sup>約翰從死人中復活了！所以這些能力在他裡面做工。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬可福音 6:17; 路加福音 3:19–20; 馬太福音 4:12"> 原來，希律為了他弟弟<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="弟弟——原文直譯「兄弟」。">b</a></sup>菲利普的妻子希羅迪婭的緣故，拘捕了約翰，把他捆起來關進監獄。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:21; 利未記 18:16; 馬可福音 6:18"> 這是因為約翰一直對他說：「你占有這婦人是不可以的。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 21:26; 馬太福音 11:9; 馬可福音 6:19–20"> 希律想要殺約翰，可是怕民眾，因為他們認為約翰是先知。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 6:21–23; 創世記 40:20; 何西阿書 1:5–6"> 到了希律生日的時候，希羅迪婭的女兒在眾人面前跳舞，使希律非常喜悅，</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 5:3; 以斯帖記 5:6; 以斯帖記 7:2"> 故此王就起誓承諾，無論她求什麼都給她。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 6:24; 箴言 29:10; 箴言 1:16"> 女兒受母親的指使，就說：「請把施洗者<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="施洗者——或譯作「施浸者」。">c</a></sup>約翰的頭放在盤子裡給我。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 19:12–16; 撒母耳記上 14:28; 馬可福音 6:26"> 王就憂憂愁愁，但因所起的誓，又因一同坐席的人，就下令給她。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 17:12; 馬太福音 21:35–36; 路加福音 9:9"> 於是派人去，在監獄裡砍下了約翰的頭，</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 16:6; 創世記 49:7; 以西結書 16:3–4"> 把他的頭放在盤子上，端給女孩，女孩就拿去給她母親。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 8:2; 馬太福音 27:58–61"> 後來，約翰的門徒們前來把遺體領去埋葬了，又去告訴耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 馬太福音 14:1–2; 馬可福音 6:30–44"> 耶穌聽了這事，就上船離開那裡，獨自到一個荒僻的地方去。眾人聽到了，就從各城鎮徒步來跟隨他。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 4:15; 馬太福音 9:36; 希伯來書 2:17"> 耶穌下了船，看見一大群人，就對他們動了憐憫之心，使其中的病人痊癒。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="馬太福音 15:23; 馬可福音 8:3; 馬可福音 6:35–36"> 黃昏的時候，門徒們來到耶穌面前，說：「這是個荒僻的地方，而且天已經晚了。請遣散人群，好讓他們到村莊去為自己買些食物。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 4:42–44; 哥林多後書 8:2–3; 傳道書 11:2"> 但耶穌說：<span className="woj">「他們不需要離開，你們給他們吃的吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 15:33–34; 馬可福音 6:37–38; 路加福音 9:13"> 門徒們對耶穌說：「我們這裡除了五個餅和兩條魚，就沒有什麼了。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶穌說：<span className="woj">「拿到我這裡來。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 8:6–7; 路加福音 24:30; 撒母耳記上 9:13"> 於是耶穌吩咐眾人坐在草地上，就拿起這五個餅和兩條魚，抬頭望天，祝福了，然後掰開餅，遞給門徒們，他們又分給眾人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:12; 馬可福音 6:42–44; 馬太福音 16:8–10"> 大家都吃了，並且吃飽了。他們把剩下的碎塊收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 4:19; 哥林多後書 9:8–11; 使徒行傳 4:4"> 吃的人，不算婦女和孩子，約有五千。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 6:45–51; 約翰福音 6:15–21; 馬太福音 15:39"> 耶穌立刻催促門徒們上船，要他們先往對岸去；這期間，他自己遣散了人群。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 馬可福音 6:46; 馬太福音 26:36"> 他遣散了人群以後，就獨自上山去禱告。到了晚上，只有他一個人在那裡。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:18; 馬可福音 6:48; 馬太福音 8:24"> 那時，船已經離岸有幾百公尺<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="幾百公尺——原文為「幾視距」。1視距=185公尺。">d</a></sup><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="離岸有幾百公尺——有古抄本作「在湖中」。">e</a></sup>，由於逆風，被波浪沖擊。</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 9:8; 約翰福音 6:19; 馬可福音 6:48"> 天快亮的時候<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="天快亮的時候——原文直譯「夜裡四更天」；指「早晨三點至六點之間」。">f</a></sup>，耶穌在湖<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="湖——原文直譯「海」；指「加利利湖（海）」。">g</a></sup>面上行走，向他們而去。</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 6:49–50; 啟示錄 1:17; 路加福音 1:11–12"> 門徒們看見耶穌在湖面上行走，就驚慌不安，說：「是幽靈！」他們害怕得喊叫起來。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 23:11; 啟示錄 1:17–18; 約翰福音 16:33"> 耶穌立刻對他們說：<span className="woj">「鼓起勇氣吧！是我，不要怕。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:68; 羅馬書 12:3; 馬太福音 26:33–35"> 彼得對他說：「主啊，如果是你，請吩咐我，從水面上走到你那裡去。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="腓立比書 4:13; 馬可福音 9:23; 使徒行傳 3:16"> 耶穌說：<span className="woj">「你來吧！」</span><br />彼得就從船上下去，在水面上行走向耶穌那裡去。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太後書 4:16–17; 馬可福音 14:38"> 但是，他一看到風極大<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「極大」。">h</a></sup>，就懼怕起來，開始往下沉，於是呼叫說：「主啊，救救我！」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅各書 1:6–8; 詩篇 138:7; 創世記 22:14"> 耶穌立刻伸手拉住他，說：<span className="woj">「小信的人哪，你為什麼疑惑呢？」</span></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 107:29–30; 馬可福音 4:41; 約翰福音 6:21"> 他們一上船，風就停了。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 11:27; 詩篇 2:7; 羅馬書 1:4"> 船上的人都<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「來」。">i</a></sup>拜耶穌，說：「你真是神的兒子！」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 6:53–56; 路加福音 5:1; 約翰福音 6:24–25"> 他們渡過去，到革尼撒勒上岸。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 4:24–25; 馬可福音 6:55; 馬可福音 1:28–34"> 那裡的人一認出是耶穌，就派人到周圍整個地區，把所有患病的都帶到耶穌那裡，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 馬可福音 3:10; 出埃及記 28:33–43"> 懇求耶穌只要讓他們摸一下他的衣服穗子。凡是摸著的人，都得了救治。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彌迦書 5:2; 約翰福音 7:42; 路加福音 2:4–7"> 在希律王的那些日子裡，耶穌誕生在猶太的伯利恆。當時，有幾個博士從東方來到耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 24:17; 耶利米書 23:5; 啟示錄 22:16"> 他們問：「生下來做猶太人之王的那一位在哪裡？我們在東方看見了他的星，就來了要朝拜他。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 17:6–7; 約翰福音 11:47–48; 馬太福音 23:37"> 希律王聽說了，就驚慌不安，全耶路撒冷的人也與他一起不安。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 21:23; 馬太福音 7:29; 使徒行傳 6:12"> 希律就召集了所有的祭司長和民間的經文士，向他們詢問基督誕生在哪裡。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 7:42; 路得記 1:1; 撒母耳記上 16:1"> 他們對希律說：「在猶太的伯利恆，因為藉著先知有這樣的記載：</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 34:23–25; 彌迦書 5:2; 以賽亞書 9:6–7"> <span className="pl pl-1">『猶大之地伯利恆啊！</span><br /><span className="pl pl-1">你在猶大的首要城鄉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="首要城鄉——原文直譯「總督」。">a</a></sup><br /><span className="pl pl-1">中，絕不是最小的，</span><br /><span className="pl pl-1">因為將來有一位領袖要從你那裡出來，</span><br /><span className="pl pl-1">他要牧養我的子民以色列。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 1:10; 撒母耳記上 18:21; 詩篇 55:21"> 於是，希律暗暗地召見了那幾個博士，向他們仔細詢問那顆星出現的時間，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 3:19–20; 耶利米書 41:5–7; 路加福音 20:20–21"> 然後打發他們前往伯利恆，說：「你們去仔細查問有關那孩子的事，一旦查出來了就向我報告，好讓我也去拜他。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 2:2; 箴言 8:17; 詩篇 25:12"> 他們聽了王的話就去了。看哪，他們在東方看見的那顆星在前面引導他們，直到那孩子所在的地方，就在上頭停住了。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 105:3; 路加福音 2:20; 路加福音 2:10"> 他們看見那顆星，極其歡喜快樂。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 60:6; 詩篇 72:10; 路加福音 2:16"> 他們進了屋子，看見那孩子與他的母親瑪麗亞在一起，就俯伏拜那孩子，然後打開他們的寶盒，把黃金、乳香和沒藥做為禮物獻給他。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 2:22; 馬太福音 2:19; 馬太福音 2:13"> 他們在夢中得了神的指示不要回到希律那裡去，就從另一條路回到自己的家鄉去了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 10:7; 使徒行傳 5:19; 馬太福音 1:20"> 那些博士離開以後，忽然主的一位天使在約瑟夢中顯現，說：「起來，帶著孩子和他的母親逃往埃及，留在那裡，直到我再指示你，因為希律要搜尋這孩子並殺害他。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 2:20–21; 使徒行傳 26:21; 馬太福音 1:24"> 約瑟就起來，連夜帶著孩子和他的母親逃往埃及，</span>
<span className="v" id="v15" data-v="15" data-xref="何西阿書 11:1; 出埃及記 4:22; 民數記 24:8"> 住在那裡，直到希律死了。這是為要應驗主藉著先知所說的話：「我從埃及召我的兒子出來。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 59:7; 箴言 28:15; 士師記 16:10"> 希律發現自己受了博士們的愚弄，就十分惱怒。於是，他按照從博士們那裡所詢問到的時間，派人把伯利恆城裡和周圍各個地區內兩歲以下的男孩，全都殺了。</span>
<span className="v" id="v17" data-v="17"> 這就應驗了藉著先知耶利米所說的話：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:15; 耶利米書 9:17–21; 耶利米書 4:31"> <span className="pl pl-1">「從拉瑪聽見了聲音，</span><br /><span className="pl pl-1">是哀哭</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哀哭——有古抄本作「悲嘆和哀哭」。">b</a></sup><br /><span className="pl pl-1">和極其傷痛的聲音，</span><br /><span className="pl pl-1">是拉結為她的兒女哀哭，</span><br /><span className="pl pl-1">不肯接受安慰，</span><br /><span className="pl pl-1">因為他們不在了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 1:20; 但以理書 8:25; 馬太福音 2:12–13"> 希律死了以後，在埃及，忽然主的一位天使在約瑟夢中顯現，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 4:19; 列王紀上 12:1–3; 馬太福音 2:13"> 說：「起來，帶著孩子和他的母親回以色列地去，因為那些追索這孩子性命的人已經死了。」</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 11:8; 創世記 6:22"> 約瑟就起來，帶著孩子和他的母親進了以色列地。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 48:17–18; 路加福音 2:39; 約翰福音 7:52"> 但是，聽說亞基勞接續他父親希律做了猶太王，約瑟就怕往那裡去，而且他在夢中得了神的指示，就退到加利利地區，</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 13:5; 約翰福音 1:45–46; 馬可福音 1:24"> 來到一個叫拿撒勒的鎮，住了下來。這是為要應驗那藉著先知們所說的話：「他將被稱為拿撒勒人。」</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:22; 馬太福音 23:2; 路加福音 5:21"> 那時，有些法利賽人和經文士從耶路撒冷來到耶穌那裡，說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 馬可福音 7:2; 歌羅西書 2:20–23"> 「你的門徒們為什麼違犯古人的傳統呢？他們吃飯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="飯——原文直譯「餅」。">a</a></sup>的時候不洗手！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:23; 提多書 1:14; 歌羅西書 2:8"> 耶穌回答他們，說：<span className="woj">「你們為什麼為了你們的傳統而違犯神的命令呢？</span></span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 20:12; 利未記 20:9; 出埃及記 21:17"> <span className="woj">神吩咐過</span><br /><span className="pl pl-1 woj">『你要孝敬你的父母』</span><br /><span className="pl pl-1 woj">，又說</span><br /><span className="pl pl-1 woj">『咒罵父親或母親的人，必須處死。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="馬可福音 7:10–13; 使徒行傳 5:29; 馬太福音 23:16–18"> <span className="woj">你們卻說『如果有人對父親或母親說：我本該給你的已經做了聖殿奉獻，</span></span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 5:8; 耶利米書 8:8; 馬可福音 7:13"> <span className="woj">他就可以完全不孝敬父母</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="父母——有古抄本作「父親」。">b</a></sup><span className="woj">。』這樣，為了你們的傳統，你們就廢棄了神的話語</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神的話語——或譯作「神的道」。">c</a></sup><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="話語——有古抄本作「命令」。">d</a></sup><span className="woj">。</span></span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 7:6; 馬太福音 23:23–29; 使徒行傳 28:25–27"> <span className="woj">你們這些偽善的人哪！以賽亞指著你們所說的預言是對的，他說：</span></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 29:13; 以西結書 33:31; 使徒行傳 8:21"> <span className="pl pl-1 woj">『這子民</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「用口親近我，」。">e</a></sup><br /><span className="pl pl-1 woj">用嘴唇尊重我，</span><br /><span className="pl pl-1 woj">他們的心卻遠離我。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 29:13; 馬可福音 7:7; 提摩太前書 1:4"> <span className="pl pl-1 woj">他們敬拜我也是徒然的，</span><br /><span className="pl pl-1 woj">因為他們把人的規條當做教義教導人</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他們把人的規條當做教義教導人——或譯作「他們教導的教義是人的規條」。">f</a></sup><br /><span className="pl pl-1 woj">。』</span><br /><span className="pl pl-1 woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶穌召來眾人，對他們說：<span className="woj">「你們當聽，也當領悟：</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 7:15; 馬太福音 15:18–20; 雅各書 3:5–8"> <span className="woj">不是進到口裡的使人汙穢；而是從口裡出來的，這才使人汙穢。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:13–14; 哥林多前書 10:32–33; 加拉太書 2:5"> 那時，門徒們前來對他說：「法利賽人聽了這話很反感<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="很反感——原文直譯「被絆倒了」。">g</a></sup>，你知道嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:2; 以賽亞書 60:21; 約翰福音 15:6"> 耶穌回答說：<span className="woj">「凡不是我天父所栽種的，都將被連根拔起。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; 以賽亞書 56:10; 馬太福音 23:16–24"> <span className="woj">隨他們吧！他們是給瞎子領路的瞎子</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="給瞎子領路的瞎子——有古抄本作「瞎子的領路人」。">h</a></sup><span className="woj">。如果瞎子給瞎子領路，兩個人都會掉進坑裡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="馬太福音 13:36; 馬可福音 4:34; 約翰福音 16:29"> 彼得對耶穌說：「請把這個比喻解釋給我們聽。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 16:9; 馬可福音 7:18; 馬可福音 9:32"> 耶穌說：<span className="woj">「到如今，你們也無知嗎？</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前書 6:13; 馬太福音 7:19–20"> <span className="woj">你們難道不明白：一切進入口裡的，要進到肚子，然後被排到廁所；</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 馬太福音 12:34; 雅各書 3:6–10"> <span className="woj">而從口裡出來的，是由心裡發出的，這些才使人汙穢。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 7:21–23; 加拉太書 5:19–21; 耶利米書 17:9"> <span className="woj">因為從心裡發出種種惡念：殺人、通姦、淫亂、偷竊、做偽證、毀謗，</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 7:3–4; 以弗所書 5:3–6; 哥林多前書 6:18–20"> <span className="woj">這些才會使人汙穢；而不洗手就吃飯，不會使人汙穢。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 7:24–30; 馬太福音 11:21–23; 士師記 1:31"> 耶穌離開那地方，退到提爾和西頓地區。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 9:27; 馬可福音 7:25–26; 馬太福音 17:15"> 這時候，忽然來了一個住在那地區的迦南婦人，她呼叫說：「主啊，大衛的後裔<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="大衛的後裔——或譯作「大衛之子」。">i</a></sup>，可憐我吧！我的女兒有鬼魔附身，痛苦萬分。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 14:15; 馬可福音 10:47–48; 耶利米哀歌 3:8"> 耶穌一句話也不回應，他的門徒們上前來求他，說：「這婦人一直跟在我們後面喊叫，請讓她走吧。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:5–6; 羅馬書 15:8; 耶利米書 50:6–7"> 耶穌回答說：<span className="woj">「我奉差派，只到以色列家迷失的羊那裡去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 32:26; 馬太福音 20:31; 馬太福音 14:33"> 那婦人來拜他，說：「主啊，求你幫助我！」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬可福音 7:27–28; 馬太福音 7:6; 腓立比書 3:2"> 耶穌回答說：<span className="woj">「拿兒女的餅扔給小狗，是不合宜的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所書 3:8; 路加福音 16:21; 約伯記 40:4–5"> 婦人說：「是的，主啊！不過連小狗也吃得到主人桌子上掉下來的碎渣！」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:23–24; 馬太福音 8:13; 詩篇 145:19"> 於是耶穌回答她，說：<span className="woj">「哦，婦人哪，你這信心</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="信心——指「對耶穌基督的信心」。">j</a></sup><span className="woj">是大的！照你所願的，給你成全吧。」</span>從那一刻起，她的女兒就痊癒了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 4:18; 約翰福音 6:1; 馬太福音 5:1"> 耶穌離開那地方，來到加利利湖<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="湖——原文直譯「海」。">k</a></sup>邊，上了山坐在那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行傳 5:15–16; 馬太福音 14:35–36"> 有一大群人來到他面前，帶著瘸腿的、瞎眼的、殘疾的、聾啞的還有許多其他人，把他們放在耶穌腳前；耶穌就使他們痊癒了。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 結果眾人看見聾啞的說話，殘疾的康復，瘸腿的行走，瞎眼的看見，都感到驚奇，就榮耀以色列的神。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 27:33; 路加福音 12:29–30; 馬太福音 9:36"> 耶穌召來他的門徒們，說：<span className="woj">「我憐憫這群人，因為他們與我在一起已經三天了，也沒有什麼東西吃。我不願意讓他們餓著肚子回去，恐怕他們在路上暈倒。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬可福音 6:37; 馬太福音 14:15; 馬可福音 8:4–5"> 門徒們說：「我們在曠野，從哪裡得這麼多的食物讓這麼大一群人吃飽呢？」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 16:9–10; 路加福音 24:41–42; 約翰福音 21:9–10"> 耶穌問他們：<span className="woj">「你們有多少餅？」</span><br />他們回答說：「七個，還有幾條小魚。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 馬可福音 6:39–40; 約翰福音 6:10"> 耶穌就吩咐眾人坐在地上，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 羅馬書 14:6; 約翰福音 6:11"> 於是拿起這七個餅和幾條小魚，祝謝以後，掰開，不斷遞給門徒們，他們又分給眾人。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 8:19–21; 馬太福音 16:9–10; 馬太福音 15:33"> 大家都吃了，並且吃飽了。然後，他們把剩下的碎塊收拾起來，裝滿了七個筐子。</span>
<span className="v" id="v38" data-v="38"> 吃的人，不算婦女和孩子，就有四千。</span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 8:10; 馬太福音 14:22"> 耶穌遣散了人群以後，就上了船，來到茉加丹<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="茉加丹——有古抄本作「茉大拉」。">l</a></sup>地區。</span>
</div>

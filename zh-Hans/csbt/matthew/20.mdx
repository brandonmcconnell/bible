<span className="v" id="v3" data-v="3" data-xref="提摩太前書 5:13; 使徒行傳 2:15; 馬太福音 20:6–7"> <span className="woj">大約上午九點</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="上午九點——原文為「第三時刻」。">b</a></sup><span className="woj">，他又出去，看見還有人閒站在街市上，</span></span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 6:11; 彼得前書 4:2–3; 路加福音 19:7–10"> <span className="woj">就對他們說：『你們也進葡萄園去吧，理當給的，我會給你們。』</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:24–26; 使徒行傳 10:3; 馬可福音 15:33–34"> <span className="woj">他們就去了。大約中午十二點</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="中午十二點——原文為「第六時刻」。">c</a></sup><span className="woj">和下午三點</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="下午三點——原文為「第九時刻」。">d</a></sup><span className="woj">，主人又出去，也是這麼做。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 6:12; 約翰福音 9:4; 使徒行傳 17:21"> <span className="woj">下午五點</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="下午五點——原文為「第十一時刻」。">e</a></sup><span className="woj">左右，他出去看見還有人站著，就問他們：『你們為什麼整天閒站在這裡呢？』</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所書 2:11–12; 希伯來書 6:10; 約翰福音 9:4"> <span className="woj">「他們回答說：『因為沒有人雇用我們。』</span><br /><span className="woj">「他就說：『你們也進葡萄園去吧。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「我會給你們正當的回報。」">f</a></sup><span className="woj">』</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命記 24:15; 彼得前書 4:10; 羅馬書 2:6–10"> <span className="woj">到了傍晚，葡萄園的主人對管事的說：『把工人叫來，發給他們工錢，從最後來的開始，到最先來的為止。』</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 20:6–7; 路加福音 23:40–43; 馬太福音 20:2"> <span className="woj">「那些下午五點</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="下午五點——原文為「第十一時刻」。">g</a></sup><span className="woj">左右被雇</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="被雇——輔助詞語。">h</a></sup><span className="woj">的人來了，每人領了一個銀幣。</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">那些最先被雇</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="被雇——輔助詞語。">i</a></sup><span className="woj">的人也來了，以為會得到更多，可是他們每人也只領到一個銀幣。</span></span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 2:16; 路加福音 19:7; 使徒行傳 22:21–22"> <span className="woj">他們拿到錢以後，就對那家的主人抱怨，</span></span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:5–6; 哥林多後書 11:23–28; 路加福音 12:55"> <span className="woj">說：『這些最後來的人只工作了一個小時，而我們經受了一天的勞累和炎熱，你卻把他們和我們同等看待！』</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:50; 馬太福音 22:12; 羅馬書 9:14–15"> <span className="woj">「主人回答他們其中的一個人，說：『朋友，我並沒有虧負你。我們不是彼此說好了一個銀幣嗎？</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:2; 路加福音 15:31; 馬太福音 6:6"> <span className="woj">你拿自己的走吧！我願意給那最後來的，就像我也給你一樣。</span></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 9:15–24; 申命記 15:9; 約拿書 4:1–4"> <span className="woj">難道我不可以用我的東西，做我願意做的事嗎？還是因為我好心，你就嫉妒了嗎</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="你就嫉妒了嗎——原文直譯「你的眼睛就邪惡嗎」。">j</a></sup><span className="woj">？』</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 19:30; 馬可福音 10:31; 馬太福音 22:14"> <span className="woj">「這樣，那些在後的，將要在前；那些在前的，將要在後。</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附「要知道，蒙召喚的人多，而蒙揀選的人少。」">k</a></sup><span className="woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬可福音 10:32–34; 路加福音 18:31–34; 馬太福音 16:13"> 耶穌上耶路撒冷去的時候，在路上單獨把十二個門徒帶到一邊，對他們說：</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 16:21; 使徒行傳 2:23; 馬太福音 27:1"> <span className="woj">「看，我們現在上耶路撒冷去，人子將被出賣給祭司長們和經文士們。他們要定他死罪，</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 16:21; 馬可福音 15:16–20; 馬太福音 27:27–31"> <span className="woj">並且要把他交給外邦人去戲弄、鞭打、釘上十字架；然後在第三天，他要復活。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 4:21; 馬可福音 10:35–45; 馬太福音 8:2"> 那時，西庇太兒子的母親帶著她的兩個兒子上前來拜耶穌，向他求一件事。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 19:28; 馬可福音 10:36–37; 以斯帖記 5:3"> 耶穌問她：<span className="woj">「你要什麼呢？」</span><br />她說：「請准許我這兩個兒子，在你的國裡，一個坐在你的右邊，一個坐在你的左邊。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 26:42; 路加福音 22:42; 馬太福音 26:39"> 耶穌就回答說：<span className="woj">「你們不知道自己在求什麼。我將要喝的杯，你們能喝嗎？</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附「我所受的洗禮，你們能受嗎？」">l</a></sup><span className="woj">」</span><br />他們說：「我們能。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="啟示錄 1:9; 馬太福音 25:34; 使徒行傳 12:2"> 耶穌對他們說：<span className="woj">「我的杯你們固然要喝</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附「我所受的洗禮你們將要受」。">m</a></sup><span className="woj">，但坐在我的右邊或左邊，不是我所賜的，而是我父已經預備給誰，就賜給誰。」</span></span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 5:5; 腓立比書 2:3; 馬可福音 10:41"> 其他十個使徒聽了，就對這兄弟兩個人很不滿。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:25–27; 馬太福音 20:25–28; 約翰福音 13:12–17"> 於是耶穌把他們召來，說：<span className="woj">「你們知道，外邦人有首領壓制他們，也有為大的管轄他們。</span></span>

<span className="v" id="v27" data-v="27" data-xref="路加福音 22:26; 馬可福音 9:33–35; 馬太福音 18:4"> <span className="woj">無論誰想在你們當中為首，誰就該做你們的奴僕，</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:27; 希伯來書 9:28; 提多書 2:14"> <span className="woj">就像人子來不是為了受人的服事，而是為了服事人，並且獻上自己的生命，替許多人做救贖的代價。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬可福音 10:46–52; 路加福音 18:35–43; 馬太福音 9:27–31"> 他們離開耶利哥的時候，有一大群人跟隨耶穌。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 10:46; 以賽亞書 42:16; 馬太福音 21:9"> 這時候有兩個瞎眼的坐在路邊，他們聽說是耶穌經過那裡，就呼叫說：「主啊，大衛的後裔<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="大衛的後裔——或譯作「大衛之子」。">n</a></sup>，可憐我們吧！」</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 19:13; 歌羅西書 4:2; 馬太福音 7:7–8"> 眾人責備他們，叫他們不要做聲。可是他們越發呼叫說：「主啊，大衛的後裔<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="大衛的後裔——或譯作「大衛之子」。">o</a></sup>，可憐我們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西結書 36:37; 腓立比書 4:6; 馬太福音 20:21"> 耶穌就停住，叫他們過來，說：<span className="woj">「你們要我為你們做什麼呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="詩篇 119:18; 以弗所書 1:17–19"> 他們說：「主啊，願你開我們的眼睛。」</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 4:15–16; 馬太福音 9:29; 使徒行傳 26:18"> 耶穌動了憐憫之心，摸了他們的眼睛。他們立刻重見光明，於是跟隨了耶穌。</span>

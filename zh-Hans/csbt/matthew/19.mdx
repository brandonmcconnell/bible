<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 10:40; 馬太福音 19:1–9; 馬太福音 7:28"> 當耶穌講完了這些話，就離開加利利，來到約旦河對岸的猶太地區。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:15; 馬可福音 6:55–56; 馬太福音 15:30–31"> 有一大群人跟隨他，他就在那裡使他們痊癒。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 10:2; 希伯來書 3:9; 馬太福音 16:1"> 有些法利賽人前來試探耶穌，說：「無論出於什麼緣故，人是否可以休妻呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="創世記 2:23; 創世記 1:27; 創世記 5:2"> 耶穌回答說：<span className="woj">「你們難道沒有讀過嗎？造物主從起初就把人造成男的和女的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="創世記 2:21–24; 哥林多前書 7:4; 哥林多前書 7:2"> <span className="woj">並且說：</span><br /><span className="pl pl-1 woj">『為這緣故，人將離開父母，</span><br /><span className="pl pl-1 woj">與妻子結合，</span><br /><span className="pl pl-1 woj">兩個人就成為一體。』</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯來書 13:4; 馬可福音 10:9; 哥林多前書 7:10–14"> <span className="woj">這樣，夫妻不再是兩個人，而是一體了。因此，神所配合的，人不可分開。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 24:1–4; 馬太福音 5:31; 馬可福音 10:4"> 他們問耶穌：「那麼，為什麼摩西吩咐說，給一份休書，就可以休妻呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 2:13–14; 創世記 2:24; 馬可福音 10:5"> 耶穌對他們說：<span className="woj">「摩西因著你們的心裡剛硬，才准許你們休妻，但並不是從起初就這樣的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 5:32; 路加福音 16:18; 哥林多前書 7:39"> <span className="woj">我告訴你們：如果有人不是由於淫亂的緣故而休妻，另娶別人，就是犯通姦罪。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「此外，凡是娶了被休的女人的，也是犯通姦罪。」">a</a></sup><span className="woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:32–35; 箴言 19:13–14; 箴言 21:19"> 他的門徒們對耶穌說：「如果丈夫與妻子的關係是這樣，結婚就沒有益處了。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 7:17; 哥林多前書 7:35; 哥林多前書 7:7–9"> 耶穌就對他們說：<span className="woj">「這話不是所有人都能接受的，只有誰被賜予了</span>，<span className="woj">誰才能接受：</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 7:32–38; 哥林多前書 9:5; 以賽亞書 56:3–4"> <span className="woj">就是說，有些獨身者</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="獨身者——原文直譯「閹人」。">b</a></sup><span className="woj">是生來</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="生來——原文直譯「從母腹中生下來」。">c</a></sup><span className="woj">如此的；有些獨身者是別人使他們成為獨身的</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="成為獨身的——原文直譯「閹割」。">d</a></sup><span className="woj">；還有些獨身者是為了天國的緣故自己成為獨身的。誰能接受，就接受吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 10:13–16; 路加福音 18:15–17; 馬太福音 18:2–5"> 那時，有一些小孩子被帶到耶穌那裡，好讓耶穌按手在他們身上，給他們禱告。門徒們卻責備那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 18:3; 路加福音 18:16–17; 哥林多前書 14:20"> 耶穌就說：<span className="woj">「讓小孩子到我這裡來，不要阻止他們，因為天國正屬於這樣的人。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="馬可福音 10:16; 提摩太後書 3:15; 哥林多前書 7:14"> 於是，耶穌按手在他們身上，然後離開那地方。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬可福音 10:17–30; 約翰福音 3:15; 猶大書 1:21"> 看哪，有一個人上前來對耶穌說：「老師<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="老師——有古抄本作「良善的老師」。">e</a></sup>，我該做什麼良善的事，才能得到永恆的生命呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="利未記 18:5; 路加福音 10:26–28; 加拉太書 3:11–13"> 耶穌對他說：<span className="woj">「你為什麼問我有關良善的事呢？只有一位是良善的</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你為什麼問我有關良善的事呢？只有一位是良善的——有古抄本作「你為什麼稱我是良善的呢？除了神一位之外，沒有一個是良善的」。">f</a></sup><span className="woj">。如果你想進入永生</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="永生——原文直譯「生命」。">g</a></sup><span className="woj">，就應該遵守誡命。」</span></span>
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16–21; 出埃及記 20:12–17; 馬可福音 10:19"> 那個人就問：「哪些誡命呢？」<br />耶穌回答說：<br /><span className="pl pl-1 woj">「不可殺人、</span><br /><span className="pl pl-1 woj">不可通姦、</span><br /><span className="pl pl-1 woj">不可偷竊、</span><br /><span className="pl pl-1 woj">不可做偽證、</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="利未記 19:18; 出埃及記 20:12; 馬太福音 22:39"> <span className="pl pl-1 woj">要孝敬父母、</span><br /><span className="pl pl-1 woj">要愛鄰如己。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="加拉太書 3:24; 馬可福音 10:20–21; 腓立比書 3:6"> 那年輕人對耶穌說：「這一切<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「我從小」。">h</a></sup>我都遵守了，我還缺少什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 10:21; 路加福音 18:22; 路加福音 12:33"> 耶穌對他說：<span className="woj">「如果你想要成為完全的，就當去賣掉你所擁有的，分給窮人，這樣你將有財寶在天上；然後你來跟從我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 6:24; 以西結書 33:31; 馬太福音 13:22"> 那年輕人聽了這話，就憂憂愁愁地走開了，因為他有很多財產。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 6:9–10; 馬太福音 13:22; 馬可福音 10:23"> 耶穌對他的門徒們說：<span className="woj">「我確實地告訴你們：富有的人進入天國會很困難。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 5:44; 路加福音 18:25; 馬可福音 10:24–25"> <span className="woj">我再告訴你們：駱駝穿過針眼，比富有的人進入神的國更容易呢！」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="羅馬書 10:13; 馬太福音 24:22; 羅馬書 11:5–7"> 門徒們聽了這話，極其驚訝，就說：「究竟誰能得救呢？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米書 32:27; 路加福音 1:37; 約伯記 42:2"> 耶穌注視著他們，說：<span className="woj">「在人，這是不可能的；但是在神，凡事都可能。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="腓立比書 3:8; 路加福音 18:28; 路加福音 5:11"> 這時候，彼得對耶穌說：「看，我們捨棄一切跟從了你，我們將來究竟會怎麼樣呢？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:28–30; 哥林多前書 6:2–3; 馬太福音 25:31"> 耶穌對他們說：<span className="woj">「我確實地告訴你們：在新的世界裡，當人子坐在他榮耀寶座上的時候，你們這些跟從我的人也要坐在十二個寶座上，審判以色列的十二個支派。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:29–30; 馬可福音 10:29–30; 腓立比書 3:8"> <span className="woj">凡是為我名的緣故而捨棄房屋，或兄弟，或姐妹，或父親，或母親，</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「或妻子，」。">i</a></sup><span className="woj">或兒女，或田產的人，都將得到百倍，並且繼承永恆的生命。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 20:16; 路加福音 13:30; 馬可福音 10:31"> <span className="woj">不過許多在前的，將要在後；許多在後的，將要在前。</span></span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 羅馬書 2:1–2; 雅各書 4:11–12"> <span className="woj">「不要評斷人，免得你們被評斷。</span></span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 2:13; 馬可福音 4:24; 路加福音 6:38"> <span className="woj">因為，你們用什麼標準來評斷，也會同樣地被評斷；你們用什麼量器</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="量器——或譯作「尺度」或「標準」。">a</a></sup><span className="woj">來衡量，也會同樣地被衡量。</span></span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 8:7–9; 加拉太書 6:1; 路加福音 6:41–42"> <span className="woj">你為什麼看見你弟兄眼裡的木屑，卻不想自己眼裡的梁木呢？</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">又怎麼能對你弟兄說『讓我除掉你眼裡的木屑』呢？看哪，你自己眼裡還有梁木呢！</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:42; 詩篇 51:9–13; 馬太福音 23:13–28"> <span className="woj">你這偽善的人！先除掉你自己眼裡的梁木，然後你才能看得清楚，好除掉你弟兄眼裡的木屑。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 9:7–8; 箴言 23:9; 馬太福音 10:14–15"> <span className="woj">不要把神聖之物丟給狗，也不要把你們的珍珠丟在豬面前，免得牠們用腳把這些踐踏了，然後轉身撕咬你們。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 21:22; 約翰一書 3:22; 約翰福音 15:7"> <span className="woj">「不斷祈求吧，就會給你們；不斷尋找吧，就會找到；不斷敲門吧，就會為你們開門。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 81:10; 詩篇 81:16; 路加福音 23:42–43"> <span className="woj">因為凡祈求的，就得到；尋找的，就找到；敲門的，就為他開門。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:11–13"> <span className="woj">你們當中有哪個人，兒子要餅，卻給他石頭呢？</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">兒子要魚，卻給他蛇呢？</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 11:11–13; 雅各書 1:17; 羅馬書 8:32"> <span className="woj">所以，如果你們做為惡人也知道把好的東西給自己的兒女，更何況你們在天上的父要把美好的賜給求他的人呢！</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:31; 羅馬書 13:8–10; 加拉太書 5:13–14"> <span className="woj">因此在任何事上，你們希望別人怎樣對待你們，你們也應當怎樣對待別人。要知道，這就是律法和先知</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="先知——或譯作「先知書」。">b</a></sup><span className="woj">的教導</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的教導——輔助詞語。">c</a></sup><span className="woj">。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:24–25; 箴言 16:25; 約翰福音 14:6"> <span className="woj">「你們要從窄門進去；因為那通向滅亡</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="滅亡——或譯作「沉淪」。">d</a></sup><span className="woj">的門是大的，那條路是寬的，從那裡進去的人也多；</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 13:23–30; 馬太福音 22:14; 馬太福音 16:24–25"> <span className="woj">然而，那通向永生</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="永生——原文直譯「生命」。">e</a></sup><span className="woj">的門是多麼小，路是多麼窄，找到它的人是多麼少。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰一書 4:1; 彼得後書 2:1–3; 馬太福音 24:11"> <span className="woj">「你們要提防假先知。他們披著羊皮來到你們這裡，裡面卻是凶殘的狼。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:43–45; 馬太福音 12:33; 雅各書 3:12"> <span className="woj">憑著他們的果子，你們就能認出他們來。難道從荊棘上能收葡萄，從蒺藜中能收無花果嗎？</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 12:33–35; 加拉太書 5:22–24; 以弗所書 5:9"> <span className="woj">同樣，好樹都結好果子，壞樹就結壞果子；</span></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 5:17; 約翰一書 3:9–10"> <span className="woj">好樹不能結壞果子，壞樹也不能結好果子。</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 3:10; 希伯來書 6:8; 約翰福音 15:2–6"> <span className="woj">所有不結好果子的樹都要被砍下來，被丟進火裡。</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:16; 使徒行傳 5:38"> <span className="woj">因此憑著他們的果子，你們就能認出他們來。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="羅馬書 2:13; 路加福音 6:46; 雅各書 1:22"> <span className="woj">「不是每一個稱呼我『主啊，主啊』的人，都能進入天國；只有遵行我天父旨意的人，才能進去。</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:25–27; 哥林多前書 13:1–2; 瑪拉基書 3:17–18"> <span className="woj">在那一天，有許多人會對我說：『主啊，主啊，我們不是奉你的名做先知傳道</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="做先知傳道——原文直譯「說預言」。">f</a></sup><span className="woj">，奉你的名驅趕鬼魔，奉你的名行了很多神蹟嗎？』</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 25:41; 詩篇 6:8; 路加福音 13:25"> <span className="woj">那時候，我要向他們宣告：『我從來不認識你們。離開我，你們這些作惡</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="惡——原文直譯「不法」。">g</a></sup><span className="woj">的人！』</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:47–49; 約翰福音 13:17; 哥林多前書 3:10–11"> <span className="woj">「因此，凡是聽了我這些話而實行的人，就好比一個聰明的人把自己的房子建在磐石上。</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 1:12; 詩篇 125:1–2; 彼得前書 1:7"> <span className="woj">大雨降下，急流沖來，狂風颳起，撞擊那房子，房子卻沒有倒塌，因為它在磐石上立定根基。</span></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 8:9; 路加福音 6:49; 雅各書 2:20"> <span className="woj">可是，凡是聽了我這些話而不實行的人，就好比一個愚拙的人把自己的房子建在沙灘上。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 13:19–22; 彼得後書 2:20–22; 哥林多前書 3:13"> <span className="woj">大雨降下，急流沖來，狂風颳起，撞擊那房子，房子就倒塌了，並且倒塌得非常厲害。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 4:32; 馬可福音 1:22; 約翰福音 7:46"> 當耶穌講完了這些話，眾人都對他的教導驚嘆不已，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 4:12–13; 路加福音 20:8; 申命記 18:18–19"> 因為耶穌教導他們，就像有權柄的人，不像他們的經文士們。</span>
</div>

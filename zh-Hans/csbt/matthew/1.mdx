</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:8; 希伯來書 11:17–18; 創世記 46:8–27"> <span className="pl pl-1">亞伯拉罕生以撒，</span><br /><span className="pl pl-1">以撒生雅各，</span><br /><span className="pl pl-1">雅各生猶大和他的兄弟們，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 創世記 38:29–30; 歷代志上 4:1"> <span className="pl pl-1">猶大與塔瑪爾生法勒斯和謝拉，</span><br /><span className="pl pl-1">法勒斯生希斯倫，</span><br /><span className="pl pl-1">希斯倫生亞蘭，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 2:10–12; 民數記 7:12; 民數記 2:3"> <span className="pl pl-1">亞蘭生亞米拿達，</span><br /><span className="pl pl-1">亞米拿達生拿順，</span><br /><span className="pl pl-1">拿順生撒門，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:31; 路得記 1:16–17; 雅各書 2:25"> <span className="pl pl-1">撒門與拉合生波阿斯，</span><br /><span className="pl pl-1">波阿斯與路得生俄備得，</span><br /><span className="pl pl-1">俄備得生耶西，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 15:5; 撒母耳記上 17:12; 撒母耳記下 12:24–25"> <span className="pl pl-1">耶西生大衛王。</span><br />從大衛到遷徙巴比倫<br /><span className="pl pl-1">大衛</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大衛——有古抄本作「大衛王」。">a</a></sup><br /><span className="pl pl-1">與烏利亞的妻子生所羅門，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 14:1–15; 列王紀上 14:31; 列王紀上 11:43–24"> <span className="pl pl-1">所羅門生羅波安，</span><br /><span className="pl pl-1">羅波安生亞比雅，</span><br /><span className="pl pl-1">亞比雅生亞撒，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 3:11; 歷代志下 26:1–23; 列王紀下 8:16"> <span className="pl pl-1">亞撒生約沙法，</span><br /><span className="pl pl-1">約沙法生約蘭，</span><br /><span className="pl pl-1">約蘭生烏西雅，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 7:1–13; 歷代志下 26:21; 歷代志下 27:1–32"> <span className="pl pl-1">烏西雅生約坦，</span><br /><span className="pl pl-1">約坦生亞哈斯，</span><br /><span className="pl pl-1">亞哈斯生希西加，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 32:33–27; 列王紀上 13:2; 歷代志上 3:13–15"> <span className="pl pl-1">希西加生瑪拿西，</span><br /><span className="pl pl-1">瑪拿西生亞門，</span><br /><span className="pl pl-1">亞門生約西亞，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 27:20; 耶利米書 52:28–30; 但以理書 1:2"> <span className="pl pl-1">在被迫遷徙巴比倫的時候，</span><br /><span className="pl pl-1">約西亞生耶哥尼雅和他的兄弟們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 3:17; 以斯拉記 3:2; 路加福音 3:27"> <span className="pl pl-1">被迫遷徙巴比倫以後，</span><br /><span className="pl pl-1">耶哥尼雅生撒拉鐵，</span><br /><span className="pl pl-1">撒拉鐵生所羅巴伯，</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">所羅巴伯生亞比玉，</span><br /><span className="pl pl-1">亞比玉生以利亞敬，</span><br /><span className="pl pl-1">以利亞敬生亞所，</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">亞所生撒督，</span><br /><span className="pl pl-1">撒督生亞金，</span><br /><span className="pl pl-1">亞金生以律，</span><br /></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">以律生以利亞撒，</span><br /><span className="pl pl-1">以利亞撒生瑪坦，</span><br /><span className="pl pl-1">瑪坦生雅各，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:17; 約翰福音 4:25; 路加福音 3:23"> <span className="pl pl-1">雅各生約瑟，就是瑪麗亞的丈夫，</span><br /><span className="pl pl-1">那稱為基督的耶穌是由瑪麗亞所生的。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 1:11–12; 列王紀下 24:14; 馬太福音 11:2"> 這樣，從亞伯拉罕到大衛的各世代，一共有十四代；從大衛到被迫遷徙巴比倫的時候，也有十四代；從被迫遷徙巴比倫的時候到基督，又有十四代。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="加拉太書 4:4–5; 路加福音 1:27–38; 約伯記 14:4"> 耶穌基督的誕生是這樣的：耶穌的母親瑪麗亞已經許配給約瑟，在他們成婚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="成婚——或譯作「同居」；原文直譯「聚在一起」。">b</a></sup>以前，瑪麗亞就由聖靈懷了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:21–24; 申命記 24:1–4; 約翰福音 8:4–5"> 她的丈夫約瑟是個義人，不願意公開羞辱她，想要暗中把她休了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; 路加福音 1:19; 馬太福音 1:18"> 約瑟思考這些事以後，忽然主的一位天使在約瑟夢中顯現，說：「大衛的後裔約瑟，不要怕迎娶瑪麗亞做你的妻子，因為她裡面所懷的是由聖靈而來的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:23; 使徒行傳 4:12; 約翰福音 1:29"> 瑪麗亞將要生一個兒子，你要給他起名叫耶穌，因為他將要把自己的子民從他們的罪孽中拯救出來。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:44; 馬太福音 2:23; 列王紀上 8:15"> 不過這整個事的發生，是為要應驗主藉著先知所說的話：</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 7:14; 以賽亞書 9:6–7; 詩篇 46:11"> <span className="pl pl-1">「看哪，那童貞女要懷孕，她要生一個兒子，</span><br /><span className="pl pl-1">人們將稱他的名為以馬內利。」 ——</span><br />「以馬內利」翻譯出來就是「神與我們同在」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 15:14; 雅各書 2:21–26; 約翰福音 2:5–8"> 約瑟從夢中醒過來，就依照主的天使所吩咐他的去做，把他的妻子迎娶過來，</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 2:21; 出埃及記 13:2; 馬太福音 1:21"> 只是在她生兒子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="兒子——有古抄本作「頭胎兒子」。">c</a></sup>以前，一直沒有與她同房。約瑟給孩子起名叫耶穌。</span>
</div>

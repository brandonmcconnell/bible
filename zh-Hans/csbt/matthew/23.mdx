<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 馬太福音 15:10–20"> 那時，耶穌對眾人和自己的門徒們說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 20:46; 馬可福音 12:38; 瑪拉基書 2:7"> <span className="woj">「經文士和法利賽人坐在摩西的位子上，</span></span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 3:5; 提多書 1:16; 羅馬書 2:19–24"> <span className="woj">所以，他們所吩咐你們的，你們都要去做，也要遵守；但是不要效法他們的行為，因為他們說而不做。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行傳 15:10; 加拉太書 6:13"> <span className="woj">他們把沉重難挑的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「難挑的」。">a</a></sup><span className="woj">擔子捆起來，放在人們肩上，但自己卻連一根指頭也不肯動它們一下。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 6:1–16; 約翰福音 12:43; 腓立比書 2:3"> <span className="woj">他們所做的一切事，都是為了給人看：他們把自己的經文盒加寬，把衣服的</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有「衣服的」。">b</a></sup><span className="woj">穗子加長；</span></span>
<span className="v" id="v6" data-v="6" data-xref="約翰三書 1:9; 路加福音 11:43–54; 馬可福音 12:38–39"> <span className="woj">他們喜愛宴席中的上座和會堂裡的首位，</span></span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 1:38; 約翰福音 1:49; 約翰福音 3:26"> <span className="woj">喜愛街市上的致敬問候，又喜愛被人們稱為『老師</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="老師——或譯作「拉比」。">c</a></sup><span className="woj">』。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="雅各書 3:1; 哥林多前書 1:12–13; 彼得前書 5:3"> <span className="woj">「但你們不可被稱為『老師</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="老師——或譯作「拉比」。">d</a></sup><span className="woj">』，因為你們的老師只有一位，</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「就是基督，」。">e</a></sup><span className="woj">而你們都是弟兄。</span></span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 3:1; 希伯來書 12:9; 瑪拉基書 1:6"> <span className="woj">不要稱地上的任何人為『父』，因為你們的父只有一位，就是天父。</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">你們也不要被人稱為『主人』，因為你們的主人只有一位，就是基督。</span></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 9:19; 加拉太書 5:13; 約翰福音 13:14–15"> <span className="woj">你們當中誰更大，誰就該做你們的僕人，</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:5; 雅各書 4:6; 箴言 29:23"> <span className="woj">因為凡是自我高舉的都會被降卑，而自我降卑的都會被高舉。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 馬太福音 23:29; 馬太福音 23:23"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們在人的面前封閉了天國。你們自己不進去，也不讓正要進的人進去。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們侵吞寡婦的家產，又假意做很長的禱告。因此，你們將受到更重的懲罰。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有此節。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以弗所書 2:3; 使徒行傳 13:10; 使徒行傳 13:43"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們為了使一個人入教，走遍海洋和陸地，一旦那人成了教徒</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="教徒——輔助詞語。">g</a></sup><span className="woj">，你們就使他成為比你們加倍壞的地獄之子。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:14; 馬太福音 5:33–35; 雅各書 5:12"> <span className="woj">「你們這些瞎眼的領路人有禍了！你們說：『如果有人指著聖所起誓，算不得什麼；但如果有人指著聖所裡的金子起誓，就必須遵守。』</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 23:19; 民數記 16:38–39; 詩篇 94:8"> <span className="woj">你們這些又愚拙又瞎眼的人哪，到底哪一樣更重要呢？是金子，還是使金子成聖的聖所呢？</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">你們還說：『如果有人指著祭壇起誓，算不得什麼；但如果有人指著祭壇上的祭物起誓，就必須遵守。』</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 29:37; 出埃及記 30:29"> <span className="woj">你們這些</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「愚拙又」。">h</a></sup><span className="woj">瞎眼的人哪，到底哪一樣更重要呢？是祭物，還是使祭物成聖的祭壇呢？</span></span>
<span className="v" id="v20" data-v="20"> <span className="woj">所以，指著祭壇起誓的，就是指著祭壇和祭壇上的一切起誓；</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 26:8; 列王紀上 8:13; 歷代志下 6:2"> <span className="woj">指著聖所起誓的，就是指著聖所和住在裡面的那一位起誓；</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 5:34; 詩篇 11:4; 以賽亞書 66:1"> <span className="woj">指著天起誓的，就是指著神的寶座和坐在寶座上的那一位起誓。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; 彌迦書 6:8; 何西阿書 6:6"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們奉獻薄荷、蒔蘿、香芹的十分之一，卻放棄了律法上更重要的：就是公義、憐憫、信實。這些才是你們應該做的，至於前者也不可放棄。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 19:24; 馬太福音 27:6–8; 馬太福音 15:2–6"> <span className="woj">你們這些瞎眼的領路人哪，你們濾掉蠓蟲，卻吞下駱駝！</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 馬太福音 15:19–20; 馬可福音 7:4–13"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們洗淨杯子、盤子的外面，裡面卻盛滿了貪心和放縱。</span></span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 7:1; 雅各書 4:8; 希伯來書 10:22"> <span className="woj">你這瞎眼的法利賽人哪！當先洗淨杯子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「盤子」。">i</a></sup><span className="woj">的裡面，好使外面也潔淨。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行傳 23:3; 民數記 19:16"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們好像粉飾的墳墓，外面固然顯得美麗，裡面卻裝滿了死人骨頭和一切汙穢。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; 詩篇 51:6; 馬太福音 23:5"> <span className="woj">你們也是這樣，你們外面對人顯出公義，裡面卻充滿了偽善和罪惡</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="罪惡——原文直譯「不法」。">j</a></sup><span className="woj">。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行傳 2:29"> <span className="woj">「經文士和法利賽人哪，你們這些偽善的人有禍了！因為你們建造先知的墳墓，裝飾義人的墓碑，</span></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 2:30; 馬太福音 23:34–35; 馬太福音 21:35–36"> <span className="woj">說：『如果我們活在我們祖先的時代，我們就不會與他們合夥流先知們的血。』</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 7:51–52; 帖撒羅尼迦前書 2:15–16; 約書亞記 24:22"> <span className="woj">這樣，你們就見證了自己是殺害先知們的那些人的後代。</span></span>
<span className="v" id="v32" data-v="32" data-xref="創世記 15:16; 民數記 32:14; 帖撒羅尼迦前書 2:16"> <span className="woj">你們去充滿你們祖先的惡貫吧！</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 3:7; 馬太福音 12:34; 馬太福音 5:22"> <span className="woj">「你們這些蛇類，這些毒蛇的子孫！你們怎麼能逃避地獄的懲罰呢？</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:16–17; 馬太福音 13:52; 歌羅西書 1:28"> <span className="woj">看，我為此差派先知、智者、經師到你們這裡來；有些你們要殺害、要釘上十字架，有些要在會堂裡鞭打，從一個城追逼到另一個城。</span></span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 24:20–22; 撒迦利亞書 1:1; 希伯來書 11:4"> <span className="woj">所以，從義人亞伯的血起，直到你們在聖所和祭壇之間所殺的巴拉加的兒子撒迦利亞的血為止，在地上所流的義人的血都要歸在你們身上。</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 10:23; 馬太福音 24:34; 馬可福音 13:30–31"> <span className="woj">我確實地告訴你們：這一切都要臨到這世代。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; 路得記 2:12; 詩篇 91:4"> <span className="woj">「耶路撒冷啊，耶路撒冷！這城殺害先知們，又用石頭砸死被差到她這裡的人！我多次想聚集你的兒女，像母雞把自己的小雞聚集在翅膀下，可是你們不願意！</span></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 22:5; 路加福音 13:35; 路加福音 21:24"> <span className="woj">看哪，你們的家</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="家——或譯作「殿」；指「聖殿」。參《耶利米書》12:7；22:5。">k</a></sup><span className="woj">要被廢棄成為荒場。</span></span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 118:26; 馬太福音 21:9; 羅馬書 11:25"> <span className="woj">我告訴你們：今後你們絕不會再見到我了，直到你們說：『奉主名而來的那一位，是蒙祝福的。』」</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 11:4; 但以理書 9:2; 但以理書 7:28"> 伯沙撒王在位第三年，又有一個異象向我但以理顯現，是在先前向我顯現的異象之後。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 1:2; 尼希米記 1:1; 創世記 10:22"> 我在異象中觀看，看見自己在以攔省的蘇薩城堡中；我在異象中繼續觀看，又看見自己在烏萊運河邊。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 8:20; 但以理書 10:5; 撒迦利亞書 6:1"> 我舉目觀看，看哪，有一隻公綿羊站在運河邊！牠有兩隻犄角，兩隻犄角都很高，其中一隻高過另一隻，那較高的是後來長起來的。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 11:16; 但以理書 11:36; 但以理書 8:7"> 我看見那公綿羊向西、向北、向南衝撞，沒有野獸能在牠面前站立得住，也沒有誰能解救牠們脫離牠的權勢；牠任意而行，並高抬自己。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 8:21; 但以理書 11:3; 但以理書 8:8"> 我正在領悟這事，看哪，有一隻公山羊從西邊而來，穿越整個地面，腳<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="腳——輔助詞語。">a</a></sup>不沾地！這公山羊的雙眼之間有一隻顯眼的犄角。</span>
<span className="v" id="v6" data-v="6"> 牠來到我所看見的站在運河邊、有兩隻犄角的公綿羊那裡，在猛烈的怒火中衝向公綿羊。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:7; 但以理書 11:11; 約書亞記 8:20"> 我看見公山羊接近公綿羊，怒氣衝衝地撞擊牠，折斷了牠的兩隻犄角，公綿羊就沒有力量在公山羊面前站立得住。公山羊把牠撞倒在地，踩踏牠，沒有誰能解救公綿羊脫離公山羊的權勢。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 7:2; 啟示錄 7:1; 但以理書 5:20"> 於是公山羊極度高抬自己，但正在牠強盛的時候，大犄角卻被折斷了；在其原處有四隻顯眼的犄角向著天上四方的風長了起來。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 11:16; 以西結書 20:6; 以西結書 20:15"> 從其中的一隻又長出一隻小犄角，向南、向東、向那榮美之地長得極其強大。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 14:13; 啟示錄 12:4; 但以理書 8:7"> 它變得強大，高達天軍<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="天軍——或譯作「天上的萬象」。">b</a></sup>，把一部分天軍、一部分星辰摔落在地，並踩踏它們。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:11; 啟示錄 13:5–7; 但以理書 8:25"> 它還高抬自己到天軍元帥的地位，廢除天軍元帥的常獻祭，拆毀他的聖所。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 12:1; 以賽亞書 59:14; 但以理書 11:31–36"> 因罪過的緣故，天軍與常獻的祭一同被交出去；這小犄角把真理拋棄在地，它所做的都順利。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 11:2; 啟示錄 6:10; 路加福音 21:24"> 然後我聽見一位聖者在說話，又有一位聖者問那說話的：「這異象，就是有關常獻的祭、帶來荒涼的罪過、聖所和天軍被踐踏之事，要到什麼時候呢？」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 12:7; 但以理書 7:25; 啟示錄 11:2–3"> 他就回答我：「要經過兩千三百個晚上和早晨，那時聖所就必重歸為聖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="聖——或譯作「義」。">c</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 10:16; 啟示錄 1:13; 彼得前書 1:10–11"> 我但以理正在觀看這異象，想要領悟它，看哪，有一位樣貌像人的站在我面前！</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:19; 路加福音 1:26; 但以理書 8:2"> 我又聽見在烏萊運河中間有人的聲音呼喊說：「加百列啊，你當使這人領悟這異象！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="但以理書 8:19; 但以理書 12:4; 哈巴谷書 2:3"> 於是加百列來到我所站的地方。他一來，我就驚慌失措，臉伏於地。他對我說：「人子啊，你當領悟，這異象是關於末後的時期！」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 10:18; 以西結書 2:2; 但以理書 10:16"> 他與我說話的時候，我臉伏於地沉睡了。他碰了我一下，使我站立起來。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 2:3; 但以理書 11:27; 啟示錄 17:17"> 他說：「看哪，我要使你明白在那憤怒的末期將要發生的事，因為這是關於所定的末後時期。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 8:3; 但以理書 11:1–2"> 你所看見的那有兩隻犄角的公綿羊，就是米底亞王和波斯王。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 10:20; 但以理書 11:3; 但以理書 8:5–8"> 那多毛的公山羊就是希臘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希臘——原文作「雅完」。">d</a></sup>王，牠雙眼之間的大犄角是第一個王。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 11:4; 但以理書 8:3; 但以理書 8:8"> 這犄角被折斷，在它的原處興起的四隻犄角，就是從希臘王的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="希臘王的——輔助詞語。">e</a></sup>國中將要興起的四個王權，只是他們都沒有他的力量。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 13:11–14; 帖撒羅尼迦後書 2:9–11; 啟示錄 19:20"> <span className="pl pl-1">在這些王權的末期，</span><br /><span className="pl pl-1">當悖逆者們的悖逆達到極點</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的悖逆達到極點——傳統譯作「惡貫滿盈」。">f</a></sup><br /><span className="pl pl-1">的時候，</span><br /><span className="pl pl-1">將要興起一個王，</span><br /><span className="pl pl-1">他傲慢殘暴</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="傲慢殘暴——原文直譯「面貌凶猛」。">g</a></sup><br /><span className="pl pl-1">，詭計多端</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="詭計多端——或譯作「能領悟謎題」。">h</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 8:12; 但以理書 11:31–36; 但以理書 7:25"> <span className="pl pl-1">他的力量必強盛，</span><br /><span className="pl pl-1">卻不是出於自己的力量；</span><br /><span className="pl pl-1">他必帶來極不尋常的毀滅，</span><br /><span className="pl pl-1">他所做的都順利；</span><br /><span className="pl pl-1">他必毀滅強者和聖民；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 8:11; 啟示錄 17:14; 約伯記 34:20"> <span className="pl pl-1">他憑著自己的狡猾，藉著自己的手腕，</span><br /><span className="pl pl-1">使詭詐得逞，</span><br /><span className="pl pl-1">又在心中高抬自己；</span><br /><span className="pl pl-1">他在人安穩無備的時候毀滅許多人，</span><br /><span className="pl pl-1">甚至起來與萬君之君作對，</span><br /><span className="pl pl-1">但他必被摧毀，卻不是出於人的</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="人的——輔助詞語。">i</a></sup><br /><span className="pl pl-1">手。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 10:1; 但以理書 12:9; 但以理書 12:4"> <span className="pl pl-1">至於所提到的有關兩千三百個晚上和早晨的異象是真實的</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="真實的——或譯作「真理」。">j</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">但你要封住這異象，</span><br /><span className="pl pl-1">因為這是關於將來許多的日子。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="但以理書 7:28; 哈巴谷書 3:16; 但以理書 8:7"> 我但以理為此精疲力竭，病了幾天；然後起來辦理王的事務。我因這異象而驚恐，無法領悟它。</span>
</div>
</div>

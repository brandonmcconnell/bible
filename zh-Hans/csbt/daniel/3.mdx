<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="DAN" data-book-slug="daniel" data-book-name="但以理書" data-chapter="3" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷書 2:19; 耶利米書 16:20; 以賽亞書 46:6"> 尼布甲尼撒王造了一座金像，高六十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六十肘——相當於27.4公尺。1肘=45.7公分。">a</a></sup>，寬六肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="六肘——相當於2.7公尺。">b</a></sup>；他把這像立在巴比倫省的杜拉平原上。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:27; 箴言 29:12; 列王紀上 12:32"> 尼布甲尼撒王派遣人招聚行政官、總長、省長、參謀、司庫官、司法官、審判官和各省所有的官員，來參加尼布甲尼撒王所立之像的奉獻禮。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:17; 啟示錄 17:13; 啟示錄 13:13–16"> 於是，行政官、總長、省長、參謀、司庫官、司法官、審判官和各省所有的官員，都被招聚來參加尼布甲尼撒王所立之像的奉獻禮；他們站在尼布甲尼撒所立之像的前面。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理書 4:1; 但以理書 6:25; 彌迦書 6:16"> 那時，傳令官大聲宣告：「各民族、各國家、各語言群體，以下是給你們的命令：</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:15; 但以理書 3:10; 但以理書 3:7"> 你們一聽見號角、豎笛、里拉琴、弦琴、豎琴、風笛和各種樂器的聲音，就要向尼布甲尼撒王所立的金像俯伏膜拜；</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:50; 馬太福音 13:42; 耶利米書 29:22"> 誰不俯伏膜拜，誰就立刻被扔進烈火燃燒的窯中。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 17:8; 啟示錄 13:3; 啟示錄 13:8"> 因此那時候，所有的民族、國家、語言群體一聽見號角、豎笛、里拉琴、弦琴、豎琴和各種樂器的聲音，就都向尼布甲尼撒王所立的金像俯伏膜拜。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:12–16; 但以理書 6:12–13; 以斯帖記 3:8–9"> 當時，有些迦勒底人前來惡意控告猶太人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:10; 但以理書 6:6; 但以理書 6:21"> 他們開口對尼布甲尼撒王說：「願王萬歲！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 3:4–7; 但以理書 6:12; 以斯帖記 3:12–14"> 王啊，你曾下令：所有聽見號角、豎笛、里拉琴、弦琴、豎琴、風笛和各種樂器聲音的人，都要向這金像俯伏膜拜；</span>
<span className="v" id="v11" data-v="11"> 誰不俯伏膜拜，誰就必被扔進烈火燃燒的窯中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 6:13; 但以理書 2:49; 使徒行傳 17:7"> 有幾個你所指派管理巴比倫省事務的猶太人，就是沙德拉克、米沙克、亞伯尼哥；王啊，這些人卻不理會你的命令，既不事奉你的神，也不向你所立的金像膜拜！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理書 3:19; 但以理書 2:12; 以斯帖記 3:5–6"> 尼布甲尼撒就勃然大怒，下令把沙德拉克、米沙克、亞伯尼哥帶來；於是這些人被帶到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 50:2; 但以理書 3:1; 以賽亞書 46:1"> 尼布甲尼撒開口對他們說：「沙德拉克、米沙克、亞伯尼哥，你們不事奉我的神，也不向我所立的金像膜拜，是真的嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 5:29; 歷代志下 32:15–17; 出埃及記 5:2"> 現在，你們一聽見號角、豎笛、里拉琴、弦琴、豎琴、風笛和各種樂器的聲音，如果準備向我所造的像俯伏膜拜，那就沒有事了<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那就沒有事了——輔助詞語。">c</a></sup>；如果不膜拜，你們就立刻被扔進烈火燃燒的窯中。有什麼神能從我的手中拯救你們呢？」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:7; 但以理書 3:12"> 沙德拉克、米沙克、亞伯尼哥回答尼布甲尼撒王，說：「對於這事，我們不需要回應你。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:31; 路加福音 1:37; 希伯來書 7:25"> 如果真被扔進火窯中，我們所事奉的神也能從烈火燃燒的窯中拯救我們；王啊，他必從你的手中拯救我們！</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:29–32; 馬太福音 10:39; 啟示錄 2:10–11"> 即或不然，王啊，你要知道，我們也絕不會事奉你的神明，不會向你所立的金像膜拜！」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 3:13; 利未記 26:24; 箴言 21:24"> 尼布甲尼撒就怒火填膺，對沙德拉克、米沙克、亞伯尼哥變了臉色。他下令把窯燒熱，比平常更熱七倍；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 16:23; 使徒行傳 16:25; 但以理書 3:15"> 又命令他軍隊中幾個最強壯的人，把沙德拉克、米沙克、亞伯尼哥綁起來，扔進烈火燃燒的窯中。</span>
<span className="v" id="v21" data-v="21"> 於是這三個人穿著長袍、長褲和其他的衣服，戴著頭巾，被綁起來扔進了烈火燃燒的窯中。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 12:33; 箴言 21:18; 箴言 11:8"> 由於從王發出的命令急迫，窯又燒得非常熱，烈火的火焰燒死了那些抬沙德拉克、米沙克、亞伯尼哥的人。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 6:16–17; 耶利米書 38:6; 詩篇 34:19"> 就這樣，沙德拉克、米沙克、亞伯尼哥這三個人，被綁著落入了烈火燃燒的窯中。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理書 6:7; 但以理書 6:22; 但以理書 3:9–10"> 那時，尼布甲尼撒王感到驚奇，急忙站起來，開口問他的謀士們：「我們綁起來扔進烈火中的，難道不是三個人嗎？」<br />他們回答王，說：「王啊，是的！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 43:2; 使徒行傳 28:5; 馬可福音 16:18"> 王回應說：「看哪，我看到有四個人，並沒有被綁著，在烈火中行走，身上也沒有損傷，而那第四個人，他的樣貌彷彿神子。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理書 3:17; 以賽亞書 52:12; 啟示錄 19:5"> 於是，尼布甲尼撒靠近烈火燃燒的窯門，開口說：「至高神的僕人沙德拉克、米沙克、亞伯尼哥，你們出來，到這裡來吧！」沙德拉克、米沙克、亞伯尼哥就從烈火中出來了。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 43:2; 希伯來書 11:34; 以賽亞書 26:11"> 那些行政官、總長、省長和王的謀士們都聚集過來，看到這三個人——烈火無力傷他們的身體，他們的頭髮沒有燒焦，他們的長袍沒有變化，他們身上也沒有火燒的氣味。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 14:7–8; 詩篇 34:7–8; 詩篇 84:11–12"> 尼布甲尼撒就開口說：「沙德拉克、米沙克、亞伯尼哥的神是當受頌讚的！他派遣他的使者拯救了他的僕人們；他們信靠神，違抗王的命令，甚至捨棄己身，除了自己的神以外，不事奉、不膜拜任何其他神明。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:5; 詩篇 76:10; 申命記 32:31"> 因此我下令：所有的民族、國家、語言群體中，誰說話冒犯了沙德拉克、米沙克、亞伯尼哥的神，誰就必被千刀萬剮，他的家必成為廢堆，因為沒有別的神能這樣解救人。」</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 2:49; 撒母耳記上 2:30; 但以理書 3:12"> 隨後，王使沙德拉克、米沙克、亞伯尼哥在巴比倫省高升。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 1:17; 阿摩司書 3:7; 但以理書 5:1"> 巴比倫王伯沙撒元年，但以理在床上做了一個夢，看見腦海中的異象。於是他寫下了這夢，又述說這夢<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="這夢——原文直譯「事情」或「話語」。">a</a></sup>的概要。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 7:1; 啟示錄 17:15"> 但以理開口說：「我在夜間的異象中正在觀看，看哪，天上四方的風攪動大海！</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 13:1; 但以理書 7:17; 但以理書 2:32–33"> 有四隻巨獸從海裡上來，各個都不相同。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 4:7; 以賽亞書 14:13–17; 以西結書 17:3"> 「第一隻獸好像獅子，卻有鷹的翅膀。我繼續觀看，牠的翅膀被拔掉，牠從地上被舉起，像人那樣用雙腳站立，又被賜予了一顆人的心。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 2:39; 以賽亞書 13:17–18; 箴言 17:12"> 「看哪，有另一隻獸，就是第二隻，彷彿一隻熊！牠用一側站立，口齒間有三根肋骨<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="肋骨——或譯作「獠牙」。">b</a></sup>；有話對牠這樣說：『起來，吞吃大量的肉！』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 13:2; 但以理書 8:20–22; 但以理書 8:5–8"> 「此後我繼續觀看，看哪，又有另一隻獸好像豹子！牠的背上有鳥的四個翅膀；這獸有四個頭，並且被賜予了權柄。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 13:1; 啟示錄 12:3; 啟示錄 17:12"> 「此後在夜間的異象中我繼續觀看，看哪，第四隻獸非常恐怖、十分可怕、極其強壯！牠有大鐵牙，吞吃咬碎，又把剩餘的用腳踩踏；牠與之前的各獸都不相同，牠有十隻犄角。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 13:5–6; 啟示錄 13:1; 詩篇 12:3"> 「我正在注視這些犄角，看哪，有另一隻小犄角在它們中間長出來，先前的那些犄角中有三隻從它面前被連根拔出！看哪，這犄角上有眼睛，好像人的眼睛，又有說大話的口！</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 1:14; 馬可福音 9:3; 但以理書 7:13"> 「我繼續觀看，<br /><span className="pl pl-1">寶座已經安放好，</span><br /><span className="pl pl-1">亙古永存者入座了；</span><br /><span className="pl pl-1">他的衣服潔白如雪，</span><br /><span className="pl pl-1">他的頭髮純淨如羊毛；</span><br /><span className="pl pl-1">他的寶座是烈火的火焰，</span><br /><span className="pl pl-1">寶座的輪子是燃燒的烈火。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:27; 申命記 33:2; 啟示錄 20:11–15"> <span className="pl pl-1">從他面前有一條火河湧流而出；</span><br /><span className="pl pl-1">事奉他的有千千，</span><br /><span className="pl pl-1">侍立在他面前的有萬萬；</span><br /><span className="pl pl-1">庭審已經開始</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="庭審已經開始——或譯作「審判者入座了」。">c</a></sup><br /><span className="pl pl-1">，書卷都打開了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 19:20; 啟示錄 20:10; 帖撒羅尼迦後書 2:8"> 「那時，我繼續觀看——因那犄角說大話的聲音，我繼續觀看，那獸被殺掉，身體被毀壞，交於焚燒的烈火。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 8:7; 但以理書 7:4–6"> 至於其餘的獸，牠們的權柄被奪去，牠們的壽命卻得以延長到所定的時候和時期。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:64; 啟示錄 1:7; 路加福音 21:27"> 我在夜間的異象中繼續觀看，<br /><span className="pl pl-1">看哪，有一位像人子的，</span><br /><span className="pl pl-1">在天上的雲彩中來臨，</span><br /><span className="pl pl-1">被引領來到亙古永存者面前！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 11:15; 但以理書 7:27; 約翰福音 3:35"> <span className="pl pl-1">他被賜予了權柄、尊榮和國度，</span><br /><span className="pl pl-1">所有的民族、國家、語言群體都事奉他；</span><br /><span className="pl pl-1">他的權柄是永遠的權柄，不會廢去，</span><br /><span className="pl pl-1">他的國度不會毀滅。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 7:28; 耶利米書 17:16; 創世記 40:7–8"> 「至於我但以理，我的靈在我裡面<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="在我裡面——原文直譯「在鞘裡」；或譯作「在軀體裡」。">d</a></sup>憂傷，我腦海中的異象使我惶恐。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 7:13–14; 撒迦利亞書 2:3; 啟示錄 5:5"> 我靠近其中一位侍立者，向他尋問有關這一切事情的真義。他就告訴我，把事情的釋義顯明給我：</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 8:19–22; 但以理書 2:37–40; 約翰福音 18:36"> 『這四隻巨獸就是從地上將要興起的四個王；</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 7:27; 以賽亞書 60:12–14; 啟示錄 5:10"> 但至高者的聖徒們必領受國度，擁有國度直到永遠，永永遠遠。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 7:7; 但以理書 2:40–43"> 「那時我很想知道有關那第四隻獸的真義；那獸與其他各獸都不相同，牠極其恐怖，有鐵牙和銅爪，吞吃咬碎，又把剩餘的用腳踩踏。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 7:23; 但以理書 7:8; 但以理書 7:11"> 我也很想知道有關牠頭上的十隻犄角和那另長出的犄角的真義——在這犄角面前有三隻犄角倒下了；這犄角有眼睛，有說大話的口，牠的樣子比牠的同類更大。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 12:7; 啟示錄 17:14; 但以理書 8:24"> 我繼續觀看，這犄角與聖徒們作戰，並勝過了他們，</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 7:18; 啟示錄 20:4; 啟示錄 5:10"> 直到亙古永存者來臨，為至高者的聖徒們伸張公正，聖徒們擁有國度的所定時候就來到了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理書 2:40; 但以理書 7:7; 路加福音 2:1"> 「那位侍立者這樣說：『那第四隻獸是地上將有的第四個國，與其他各國都不相同，必吞吃全地，把它踐踏咬碎。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:20; 但以理書 11:36; 啟示錄 13:1"> 至於那十隻犄角，是從這國中將要興起的十個王；在他們之後將有另一個王興起，與先前的那些都不相同，必使三個王屈服。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 12:7; 啟示錄 12:14; 帖撒羅尼迦後書 2:4"> 他必說話敵對至高者，折磨至高者的聖徒們，又企圖更改所定的時候和法令；聖徒們將被交在他的手中一期、二期、半期。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 20:10–11; 帖撒羅尼迦後書 2:8; 啟示錄 11:13"> 然而庭審將要開始<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="庭審將要開始——或譯作「審判者要入座」。">e</a></sup>，那王<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="那王——原文直譯「他」。">f</a></sup>的權柄必被奪去，除滅消亡，直到永遠。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 72:11; 路加福音 1:33; 啟示錄 11:15"> 國度、權柄和普天之下萬國的權勢，都必賜給至高者的眾聖民；至高者的國度是永遠的國度，所有掌權的都必事奉、順從至高者。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理書 10:8"> 「這事到此結束。至於我但以理，我的意念使我極其惶恐，臉色也變了，但我卻把這事存在心裡。」</span>
</div>
</div>

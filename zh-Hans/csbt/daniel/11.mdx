<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:1; 但以理書 5:31; 但以理書 10:18"> 至於我，我在米底亞人大流士元年，曾起來作米迦勒的扶持者和保障。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:5–6; 但以理書 8:26; 啟示錄 21:5"> 現在我就把關乎真理的事告訴你。 關於波斯和希臘的預言<br />「看哪，在波斯又會有三個王興起！之後第四個王會擁有極大的財富，超過所有的王。他藉著自己的財富變得強盛，就挑動全國與希臘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希臘——原文作「雅完」。">a</a></sup>國對立。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 11:16; 但以理書 11:36; 但以理書 8:21"> 後來，會有一個勇猛的王興起，他必執掌大權，任意而行；</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 8:22; 但以理書 8:8; 耶利米書 12:17"> 但他興起以後，他的王權必被打碎，向著天上四方的風分開，不會歸於他的後代，也不會像他曾經執掌的權勢那樣；因為他的王權必被拔出，歸於他後代<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他後代——原文直譯「這些」。">b</a></sup>以外的人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 11:14; 但以理書 11:11; 但以理書 11:25"> 「南方王會強盛，但他的首領中會有一個比他更強盛；這人必另外<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="另外——輔助詞語。">c</a></sup>執掌權柄，他的權柄極大。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 11:13; 但以理書 11:40; 但以理書 11:7"> 過了幾年，南北結盟。南方王的女兒必嫁給北方王<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="嫁給北方王——原文直譯「到北方王那裡」。">d</a></sup>，為了實現合約；但她不能維持自己的勢力<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="勢力——原文直譯「膀臂的力量」。">e</a></sup>，南方王的勢力<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="勢力——原文直譯「膀臂」。">f</a></sup>也不能存留；這女子和那些帶她來的，還有生她的，以及在那些時候扶持她的，都必被交出去。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 11:38–39; 但以理書 11:19–20; 以賽亞書 9:14"> 不過，從她的本家中會有一個人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="她的本家中會有一個人——原文直譯「她的根會有一個枝子」。">g</a></sup>興起坐上王位；他必來攻擊北方王的軍隊，進入北方王的堡壘，對他們採取行動，並取得勝利。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 37:19; 以賽亞書 46:1–2; 耶利米書 43:12–13"> 他還把他們的神像、鑄造的偶像，與他們寶貴的金銀器具一同擄掠到埃及。此後數年，他不再攻擊北方王。</span>
<span className="v" id="v9" data-v="9"> 後來，北方王必侵入南方王的國，然後返回本國。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 51:42; 但以理書 11:7; 但以理書 11:26"> 「北方王的兒子們將發動戰爭，他們必招聚極大的軍隊，洶湧而來，如洪水<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="如洪水——輔助詞語。">h</a></sup>漫溢，縱橫穿越，一次次爭戰，直到南方王的堡壘。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 8:7; 但以理書 11:5; 詩篇 33:16–17"> 南方王必怒氣衝衝，出來與北方王爭戰；北方王調集極大的軍隊，但這大軍必被交在南方王的手中。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 12:22–23; 列王紀下 14:10; 以賽亞書 10:7–12"> 這大軍被除去之後，南方王會心裡高傲；雖然他使數萬人仆倒，但他必不得勝。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 4:16; 但以理書 12:7; 但以理書 11:6–7"> 北方王會再次調集比先前更大的軍隊；過了幾年的時間，他必率領大軍，帶著大量的裝備洶湧而來。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 17:17; 使徒行傳 4:25–28"> 「那些時候，將有許多人起來與南方王作對；你的民中一些凶惡的人也必起來，為要應驗那異象，但他們卻必敗亡。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 6:6; 以西結書 17:17; 以西結書 4:2"> 北方王將前來，築起土壘攻取那堡壘城。南方的軍隊<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="軍隊——原文直譯「膀臂」。">i</a></sup>必站立不住，連南方王最精銳的軍兵也沒有力量站立得住。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 8:9; 但以理書 11:36; 但以理書 11:3"> 那來攻擊南方王的必任意而行，沒有人在他面前站立得住；他必立足在那榮美之地，手上擁有滅絕之權。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 12:17; 以西結書 4:3; 以西結書 4:7"> 他決意舉全國之力而來，與南方王實現合約，又把自己的女兒嫁給他，為要毀滅他的國；但北方王的女兒卻不站在北方王的立場上，也不支持他<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="但北方王的女兒卻不站在北方王的立場上，也不支持他——或譯作「但這計謀卻不會成功，也不會帶給他益處」。">j</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿書 12:14; 耶利米書 31:10; 西番雅書 2:11"> 於是他就轉向眾海島，並攻取許多海島；但必有一個統領止息北方王對他的辱罵，並使王的辱罵歸回到王的身上；</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 26:21; 詩篇 37:36; 約伯記 20:8"> 王就轉身回本土的堡壘，卻必絆跌、仆倒、不復存在<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="不復存在——或譯作「找不到」。">k</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 60:17; 但以理書 11:7; 申命記 15:2–3"> 「然後會有一個人興起坐上王位，為了國家的榮華，派出一個橫徵暴斂的人；但在幾天之內，這王必被摧毀，既不是由於怒氣，也不是由於戰爭。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理書 11:34; 但以理書 8:25; 士師記 9:1–20"> 「此後必有一個卑鄙的人興起坐上王位；他沒有被賜予王權的尊榮，卻在人安穩無備的時候來到，以奸猾的手段抓取了王權。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 8:10–11; 但以理書 11:10; 但以理書 9:26"> 洪流般的軍隊<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="軍隊——原文直譯「膀臂」。">l</a></sup>在他面前必被沖沒、摧毀，立約的領袖也必如此。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 8:25; 帖撒羅尼迦後書 2:9; 詩篇 52:2"> 他與立約的領袖結盟之後，就行詭詐；他必從少數的國民漸漸強盛起來，</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:25; 箴言 23:7; 馬太福音 9:4"> 在人安穩無備的時候侵入南方國<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="南方國——輔助詞語。">m</a></sup>省中那些肥美之地，行他祖先和他祖先的祖先都未行過的事；他把掠物、戰利品和財物分給自己的人，謀劃計策攻擊多個堡壘，但這只是短暫的時間。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; 但以理書 11:2; 箴言 28:25"> 「他必激起力量和勇氣，率領大軍攻擊南方王。南方王也調動極其強大的軍隊迎戰，卻站立不住，因為有些人謀劃計策與他作對，</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 11:10; 但以理書 11:40; 撒母耳記下 4:2–12"> 那些吃他美食的人把他摧毀；他的軍隊必被沖沒，許多人被殺倒下。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 12:2; 耶利米書 9:3–5; 哈巴谷書 2:3"> 這兩個王，他們的心都傾向作惡，他們同席卻彼此說謊，但他們的計謀不會成功，因為結局在所定的時期才會來到。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 11:30–32; 但以理書 8:24; 使徒行傳 3:25"> 北方王必帶著大量的財物向本土返回；他的心反對神聖的約，並付諸行動，然後才回到本土。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 17:26; 以賽亞書 14:31; 但以理書 11:25"> 「到了所定的時期，他將再次侵入南方國，不過這後一次就不像前一次了。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 10:4; 民數記 24:24; 耶利米書 2:10"> 基提<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="基提——就是塞浦路斯。">n</a></sup>的戰船來攻擊他，他就喪膽而回。他惱恨神聖的約，並付諸行動；在回程中，他顧念那些離棄神聖之約的人。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 12:11; 但以理書 9:27; 馬太福音 24:15"> 他派出的軍隊<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="軍隊——原文直譯「膀臂」。">o</a></sup>會起來褻瀆那作為堡壘的聖所，並廢除常獻的祭，設立那帶來荒涼的可憎者<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="可憎者——或譯作「可憎之物」。">p</a></sup>。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 28:9; 詩篇 9:10; 約翰福音 17:3"> 他必用圓滑的話語使那些違背聖約的人墮落，但那些認識神的子民必堅強，並付諸行動。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 24:9; 約翰福音 16:2; 瑪拉基書 2:7"> 子民中那些明達的人會使許多人有悟性，但在一段日子裡，他們會倒在刀劍或火焰之下，倒在被擄或擄掠中。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 7:15; 羅馬書 16:18; 使徒行傳 20:29–30"> 在他們倒下的時候，將得到一點幫助；必有許多人奸猾地歸附於他們。</span>
<span className="v" id="v35" data-v="35" data-xref="撒迦利亞書 13:9; 瑪拉基書 3:2–4; 啟示錄 2:10"> 那些明達的人中有一些倒下，是為了熬煉、潔淨明達的人，使他們變得潔白，直到末後的時期，因為所定的時期還沒來到。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="啟示錄 13:5–6; 帖撒羅尼迦後書 2:4; 申命記 10:17"> 「這王任意而行，自高自大，高抬自己超過一切神明，並說荒謬<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="荒謬——或譯作「驚人」或「放肆」。">q</a></sup>的話來敵對萬神之神；他事事順利，直到憤怒的時期<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="的時期——輔助詞語。">r</a></sup>終結，因為那被註定的事必成就。</span>
<span className="v" id="v37" data-v="37" data-xref="帖撒羅尼迦後書 2:4; 以賽亞書 14:13; 提摩太前書 4:3"> 他不顧祖先的神明，不顧女人們所愛慕的神明，也不顧任何其他的神明，因為他高抬自己超過一切。</span>
<span className="v" id="v38" data-v="38" data-xref="啟示錄 17:1–5; 以賽亞書 44:9; 啟示錄 13:12–17"> 他反而會榮耀一個堡壘之神，用金子、銀子、寶石和珍寶榮耀他祖先所不認識的神明。</span>
<span className="v" id="v39" data-v="39" data-xref="啟示錄 18:9–13"> 他必靠著外邦神明的幫助<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="的幫助——輔助詞語。">s</a></sup>對堅固的堡壘採取行動，而對那些承認他的人，他把榮耀大大加給他們，使他們管轄許多人，又把土地分給他們作為報償。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="但以理書 11:35; 但以理書 11:10; 以賽亞書 5:28"> 「末後的時期，南方王會與他衝撞。北方王必帶著戰車、馬兵和許多戰船，暴風般地攻擊他，並侵入列國，如洪水漫溢，縱橫穿越。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 48:47; 耶利米書 49:6; 以賽亞書 11:13–15"> 他必侵入那榮美之地，許多國家<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="國家——輔助詞語。">t</a></sup>將被傾倒，但是以東人和摩押人，亞捫子孫的首要人物<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="首要人物——或譯作「大部分人」。">u</a></sup>必從他的手中被救出。</span>
<span className="v" id="v42" data-v="42" data-xref="撒迦利亞書 10:10–11; 以西結書 29:14; 啟示錄 11:8"> 他必伸手攻擊列國，連埃及地也不會逃脫。</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志下 12:3; 那鴻書 3:9; 以西結書 30:4–5"> 他將管轄埃及金銀寶藏和一切珍寶；利比亞人和庫實人都將跟隨他的腳步。</span>
<span className="v" id="v44" data-v="44" data-xref="啟示錄 19:19–21; 啟示錄 16:12; 啟示錄 17:13"> 然而，從東方、從北方必有消息使他惶恐，他就在極大的怒火中出兵，為要把許多人滅絕淨盡。</span>
<span className="v" id="v45" data-v="45" data-xref="帖撒羅尼迦後書 2:4; 但以理書 8:25; 啟示錄 19:19–21"> 他必在兩海之間的榮美聖山上搭起他的王宮帳幕，但他的結局將要來到，沒有人幫助他。</span>
</div>
</div>

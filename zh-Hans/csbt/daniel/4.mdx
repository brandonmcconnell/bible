<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 6:25; 彼得前書 1:2; 但以理書 3:4"> 尼布甲尼撒王，<br />致住在全地的所有民族、國家、語言群體：<br />願你們大有平安！</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:26; 詩篇 66:16; 詩篇 71:18"> 我很高興能把至高神向我所行的神蹟奇事講明出來——</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 145:13; 以賽亞書 25:1; 但以理書 2:44"> <span className="pl pl-1">他的神蹟多麼偉大，</span><br /><span className="pl pl-1">他的奇事多麼有能力！</span><br /><span className="pl pl-1">他的國度是永遠的國度，</span><br /><span className="pl pl-1">他的權柄世世代代長存！</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 47:7–8; 帖撒羅尼迦前書 5:2–3; 詩篇 30:6–7"> 我尼布甲尼撒在殿裡安居，在宮中興盛。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 2:1; 約伯記 7:13–14; 但以理書 2:28–29"> 我做了一個夢，這夢使我恐懼；我在床上時的夢境和我腦海中的異象使我惶恐。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 2:2; 創世記 41:7–8; 以賽亞書 8:19"> 因此我下令，要把巴比倫的所有智慧人帶到我面前，好讓他們把夢的釋義顯明給我。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 44:25; 但以理書 2:7; 創世記 41:8"> 於是術士、占卜者、迦勒底人和算命者都來了；我就向他們說了這夢，他們卻不能把這夢的釋義顯明給我。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="但以理書 1:7; 但以理書 5:14; 但以理書 4:18"> 最後，那照著我神的名稱為伯提沙撒的但以理，來到我面前，他裡面有聖神之靈；我就向他說了這夢：</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 2:48; 但以理書 5:11; 但以理書 4:8"> 「術士的領袖伯提沙撒啊，我知道你裡面有聖神之靈，任何奧祕都難不倒你！你就講說我所看到的夢中異象和夢的釋義吧！</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 12:2; 但以理書 4:5; 詩篇 37:35–36"> 我在床上時，我腦海中的異象是這樣的：<br /><span className="pl pl-1">我正在觀看，看哪，</span><br /><span className="pl pl-1">在大地中間有一棵樹，極其高大！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 4:21–22; 申命記 9:1; 馬太福音 11:23"> <span className="pl pl-1">這樹繼續長大，變得茁壯，</span><br /><span className="pl pl-1">高達於天，全地極都能看到；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西結書 31:6–7"> <span className="pl pl-1">它的葉子美麗，果實繁多，</span><br /><span className="pl pl-1">足以給眾生作食物；</span><br /><span className="pl pl-1">田野的走獸在它之下得蔭庇，</span><br /><span className="pl pl-1">天空的飛鳥在它枝子上棲息，</span><br /><span className="pl pl-1">一切有血肉的都從它得供養。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="申命記 33:2; 但以理書 8:13; 但以理書 7:1"> 「我在床上時，我在腦海中的異象裡繼續觀看，看哪，有一位守望者，就是一位聖者，從天上降下！</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 3:10; 但以理書 4:23; 以西結書 31:12–13"> 他大聲高呼，這樣說：<br /><span className="pl pl-1">『你們當砍倒這樹，砍掉它的枝子，</span><br /><span className="pl pl-1">打落它的葉子，拋散它的果實；</span><br /><span className="pl pl-1">使走獸從樹下逃離，</span><br /><span className="pl pl-1">使飛鳥從樹枝逃離！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 14:7–9; 但以理書 4:25–27; 以西結書 29:14–15"> <span className="pl pl-1">然而你們當把帶根的樹樁留在地裡，</span><br /><span className="pl pl-1">在田野的青草中用鐵圈和銅圈套住——</span><br /><span className="pl pl-1">讓他被天上的露水濕透，</span><br /><span className="pl pl-1">在地上的牧草中與走獸一同有份；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 4:23; 啟示錄 12:14; 但以理書 4:25"> <span className="pl pl-1">讓他的心從人的心改變，</span><br /><span className="pl pl-1">並給他一個獸的心，</span><br /><span className="pl pl-1">讓七個時期從他流過。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 4:25; 但以理書 2:21; 詩篇 75:6–7"> <span className="pl pl-1">這是守望者們所宣告的裁決，</span><br /><span className="pl pl-1">是聖者們所宣布的決定，</span><br /><span className="pl pl-1">為要使活人明白：</span><br /><span className="pl pl-1">至高者在人的國中掌權，</span><br /><span className="pl pl-1">他願意把國賜給誰就賜給誰，</span><br /><span className="pl pl-1">甚至把最卑微的人立在一國之上。』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理書 5:15; 創世記 41:8; 但以理書 5:8"> 「以上就是我尼布甲尼撒王所做的夢。伯提沙撒啊，你講說夢的釋義吧！因為我國中的所有智慧人都不能把夢的釋義顯明給我；只有你能，因為你裡面有聖神之靈。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 8:27; 但以理書 7:28; 但以理書 4:24"> 那時，稱為伯提沙撒的但以理一陣驚恐，他的意念使他惶恐。王就開口說：「伯提沙撒啊，不要讓這夢和夢的釋義使你惶恐！」<br />伯提沙撒回應說：「我主啊，願這夢歸於那些恨惡你的人，願夢的釋義歸於你的敵人！</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 4:10–12; 以西結書 31:3; 以西結書 31:16"> 你所看到的那樹繼續長大，變得茁壯，高達於天，全地都能看到；</span>
<span className="v" id="v21" data-v="21"> 它的葉子美麗，果實繁多，足以給眾生作食物；田野的走獸在它之下安居，天空的飛鳥在它枝子上棲息。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 2:37–38; 撒母耳記下 12:7; 耶利米書 27:6–8"> 王啊，這樹就是你！你繼續強大，變得堅壯，你的權勢繼續強大，高達於天，你的權柄直到地極。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理書 5:21; 但以理書 4:13–16"> 「王又看到有一位守望者，就是一位聖者，從天上降下，說：『你們當砍倒毀壞這樹！然而你們當把帶根的樹樁留在地裡，在田野的青草中用鐵圈和銅圈套住——讓他被天上的露水濕透，與田野的走獸一同有份，讓七個時期從他流過。』</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:40; 約伯記 40:11–12; 以賽亞書 46:10–11"> 王啊，夢的釋義是這樣的，它是至高者的裁決臨到了我主我王：</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 4:17; 耶利米書 27:5; 詩篇 83:18"> 你必從人間被趕出，你的住處必與田野的走獸在一起；你必像牛那樣吃牧草，被天上的露水濕透，讓七個時期從你流過，直到你明白：至高者在人的國中掌權，他願意把國賜給誰就賜給誰。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 4:15; 馬太福音 5:34; 馬太福音 21:20"> 既然守望者們吩咐要留下帶根的樹樁，那麼當你明白了上天掌權時，你的國必定再歸於你。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 55:6–7; 約拿書 3:9; 使徒行傳 8:22"> 因此，王啊，願我的勸告蒙你悅納：請你藉著施行公義斷絕你的罪惡，藉著恩待受苦人斷絕你的罪孽，或許你的安穩可以延長。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民數記 23:19; 撒迦利亞書 1:6; 箴言 10:24"> 這一切事果然都臨到了尼布甲尼撒王：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 2:21; 傳道書 8:11; 彼得前書 3:20"> 過了十二個月，王在巴比倫王宮的宮頂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的宮頂——輔助詞語。">a</a></sup>上行走時，</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 啟示錄 18:10; 路加福音 14:11"> 開口說：「這大巴比倫，難道不是我以自己的權能力量建為國都，為要顯出<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="顯出——輔助詞語。">b</a></sup>我威嚴的尊榮嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:3–5; 啟示錄 16:7; 路加福音 12:20"> 這話還在王的口中，就有聲音從天上降下，說：「尼布甲尼撒王啊，這是對你的宣告：你的國權從你那裡被移除了！</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 27:5; 但以理書 5:21; 箴言 8:15–16"> 你必從人間被趕出，你的住處必與田野的走獸在一起；你必像牛那樣吃牧草，讓七個時期從你流過，直到你明白：至高者在人的國中掌權，他願意把國賜給誰就賜給誰。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="但以理書 4:32; 但以理書 4:25; 但以理書 5:5"> 這話立刻就應驗在尼布甲尼撒身上；他從人間被趕出，像牛那樣吃牧草，身體被天上的露水濕透，直到他的頭髮長得像鷹的羽毛<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="羽毛——輔助詞語。">c</a></sup>，指甲長得像鳥的爪子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="爪子——輔助詞語。">d</a></sup>。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="啟示錄 4:10; 耶利米書 10:10; 但以理書 12:7"> 那些日子結束了，我尼布甲尼撒舉目望天，我的理智回到我身上。我就頌讚至高者，稱讚、尊崇永遠活著的那一位——<br /><span className="pl pl-1">他的權柄是永遠的權柄，</span><br /><span className="pl pl-1">他的國度世世代代長存！</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 42:2; 詩篇 135:6; 詩篇 115:3"> <span className="pl pl-1">地上所有的居民都算為無有，</span><br /><span className="pl pl-1">他照著自己的旨意對待天上的眾軍和地上的居民。</span><br /><span className="pl pl-1">沒有人能攔住他的手，</span><br /><span className="pl pl-1">或對他說：「你做什麼？」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理書 4:34; 箴言 22:4; 但以理書 4:15–16"> ——當時，我的理智回到我身上；為了我國家的尊榮，我的威嚴、我的光輝也回到我身上。我的謀士們、我的大臣們又來尋求我，我的國權重新堅立，超卓的權勢也加增給我。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 4:6–7; 詩篇 33:4–5; 彼得前書 5:5–6"> 如今我尼布甲尼撒稱讚、高舉、尊崇天上的王，因為他一切的作為都是確實的，一切的道路都是公正的，他能使行事驕傲的人降卑。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 11:1; 但以理書 1:21; 但以理書 5:31–1"> 米底亞人的後裔，亞哈隨魯的兒子大流士被立為王統治迦勒底國的第一年，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 29:10; 耶利米書 25:11–12; 歷代志下 36:21"> 就是他作王的第一年，我但以理從書卷中領悟到：照著耶和華給先知耶利米的話，耶路撒冷荒廢期滿的年數是七十年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 33:3; 耶利米書 29:10–13; 雅各書 5:16–18"> 於是我轉向主耶和華，以禱告、懇求、禁食、披麻蒙灰來尋求他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 8:28; 出埃及記 20:6; 申命記 5:10"> 我向我的神耶和華禱告、認罪，說：「哦，主啊，大而可畏的神，你向那些愛你並遵守你誡命的人持守你的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你的——輔助詞語。">a</a></sup>約和慈愛！</span>
<span className="v" id="v5" data-v="5" data-xref="瑪拉基書 3:7; 但以理書 9:11; 但以理書 9:15"> 我們犯了罪，行事扭曲，作惡背叛，偏離了你的誡命和法規，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 9:10; 歷代志下 36:15–16; 路加福音 20:10–12"> 沒有聽從你的僕人眾先知——他們奉你的名向我們的君王們、首領們、祖先們和這地所有的子民說話。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:15; 耶利米書 3:25; 耶利米書 2:26–27"> 「主啊，公義在於你；至於我們猶大人、耶路撒冷的居民，以及你驅散到遠近各地的全體以色列人，因為對你行事不忠，都滿面羞恥，就像今日這樣！</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 耶和華啊，我們和我們的君王們、首領們、祖先們都滿面羞恥，因為我們對你犯了罪！</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 1:6–8; 但以理書 9:7; 但以理書 9:5"> 憐憫和赦免在於主我們的神；我們卻背叛了他，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 9:6; 列王紀下 18:12; 尼希米記 9:13–17"> 沒有聽從我們的神耶和華的話，沒有遵行他藉著他的僕人眾先知在我們面前設立的律法。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:5–10; 以賽亞書 1:4–6; 申命記 28:15–68"> 「全體以色列人都違背、偏離了你的律法，不聽從你的話；因此神的僕人摩西的律法上所記的詛咒和審判<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="審判——原文直譯「起的誓」。">b</a></sup>都傾瀉在我們身上，因為我們對神犯了罪。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 5:9; 耶利米哀歌 1:12; 約伯記 12:17"> 神實現了他的話語，就是他針對我們、針對那些審判我們的審判官所說的，為要使極大的禍患臨到我們身上；像這樣在耶路撒冷所發生的禍患，在普天之下從來沒有發生過。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:15–68; 以賽亞書 9:13; 但以理書 9:11"> 照著摩西的律法上所記的，這一切禍患都臨到我們身上；然而我們卻沒有懇求我們神耶和華的恩寵，好使我們轉離自己的罪孽，留心你的真理。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:7; 尼希米記 9:33; 詩篇 51:14"> 於是耶和華有意使這禍患臨到我們身上，因為我們的神耶和華所做的一切都是公義的，但我們卻沒有聽從他的話。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米記 9:10; 出埃及記 32:11; 尼希米記 1:10"> 「主我們的神哪，你曾用大能的手把你的子民從埃及地領出來，為自己成就了名聲，就像今日這樣；我們犯了罪，作了惡！</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 8:3; 約珥書 3:17; 詩篇 87:1–3"> 主啊，現在求你照著你一切的公義，從你的城耶路撒冷和你的聖山收回你的怒氣和你的怒火！因我們的罪過和我們祖先的罪孽，耶路撒冷和你的子民被四圍所有的人羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 80:19; 耶利米哀歌 5:18; 哥林多後書 1:20"> 「我們的神哪，現在求你垂聽你僕人的禱告和懇求；主啊，為你自己的緣故，求你使你的臉照亮你荒涼的聖所！</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 37:17; 耶利米書 36:7; 列王紀下 19:16"> 我的神哪，求你側耳聽，求你垂聽！求你睜眼看我們的荒涼和這被稱為你名下的城，因為我們在你面前呈上的懇求不是因著我們的義，而是因著你豐盛的憐憫。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 9:18; 以弗所書 1:12; 阿摩司書 7:2"> 主啊，求你垂聽！主啊，求你赦免！主啊，求你留心聽並且行動！我的神哪，為你自己的緣故，求你不要遲延，因為你的城和你的子民都是被稱為你名下的。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 145:18; 但以理書 9:3–4; 羅馬書 3:23"> 我還在說話、禱告，承認我的罪和我民以色列的罪，並為我神的聖山在我的神耶和華面前呈上懇求——</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理書 8:16; 列王紀上 18:36"> 我還在禱告中說話的時候，先前的異象中見過的那位樣貌像人的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那位樣貌像人的——原文直譯「那人」。">c</a></sup>加百列快速地飛<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="快速地飛——或譯作「在我精疲力竭時」。">d</a></sup>到我這裡來；那時大約是獻晚祭的時候。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 9:24–27; 但以理書 10:21; 但以理書 8:16"> 他指示我，對我說：「但以理啊，現在我出來，為要使你明達、有悟性！</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 10:19; 馬太福音 24:15; 但以理書 10:11–12"> 在你開始懇求的時候，就有命令發出，於是我來告訴你，因為你是蒙愛的；你當領悟這話語，要領悟這異象！</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:11–14; 羅馬書 5:10; 耶利米書 23:5–6"> 「為了你的民，為了你的聖城，有七十個『七』被定下了，為要結束罪過，終止罪惡，贖清罪孽，帶來永遠的公義，封住異象和預言，膏抹至聖所<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="至聖所——或譯作「至聖者」。">e</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 4:24; 以賽亞書 9:6; 以賽亞書 55:4"> 因此你當知道，你要明白：從發出命令恢復<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="恢復——或譯作「回歸」。">f</a></sup>、重建耶路撒冷，直到受膏之君的時候，有七個『七』和六十二個『七』；那時耶路撒冷連同她的廣場和溝渠都必被恢復、重建，但那將是一個困苦的時期。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 53:8; 那鴻書 1:8; 馬可福音 13:2"> 那六十二個『七』之後，受膏者必被剪除，他將一無所有。將要來一位領袖，他的民眾必毀滅這城和聖所，其結局必伴隨著洪流，必有戰爭直到末了；荒涼的事已經被註定了。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 24:15; 路加福音 21:20; 但以理書 12:11"> 他將與許多人訂立一個『七』之久的堅固盟約；而在半個『七』的時候，他將使祭物和供物止息。在那些可憎者<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="可憎者——或譯作「可憎之物」。">g</a></sup>的羽翼上，必出現一個帶來荒涼的人，直到那被註定的滅絕傾瀉在這帶來荒涼的人身上。」</span>
</div>
</div>

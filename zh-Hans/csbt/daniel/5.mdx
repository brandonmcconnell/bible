<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="DAN" data-book-slug="daniel" data-book-name="但以理書" data-chapter="5" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 1:3; 馬可福音 6:21–22; 以賽亞書 21:4–5"> 伯沙撒王為他的一千名大臣擺設了盛大的宴席，當著這一千人的面喝酒。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 1:2; 列王紀下 24:13; 耶利米書 27:16–22"> 伯沙撒酒酣之時，吩咐人把他先王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="先王——原文直譯「父親」或「先祖」。">a</a></sup>尼布甲尼撒從耶路撒冷的聖殿中取走的金銀器皿帶來，好讓王和他的大臣們、妻子們、妃嬪們都用這些來喝酒。</span>
<span className="v" id="v3" data-v="3"> 於是人把聖殿——耶路撒冷神的殿中所取走的金器帶來，王和他的大臣們、妻子們、妃嬪們就用這些來喝酒。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 5:23; 哈巴谷書 2:19; 詩篇 135:15–18"> 他們一邊喝酒，一邊稱讚那些用金、銀、銅、鐵、木、石所做的神明。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 4:31; 但以理書 5:24–28; 約伯記 20:5"> 那時，忽然有人的手指出現，在燈臺對面王宮的粉牆上寫字。王看到那正在寫字的手<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="手——原文直譯「手掌」。">b</a></sup>，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 7:17; 但以理書 7:28; 那鴻書 2:10"> 王的臉色就變了，他的意念使他惶恐，他的腰骨鬆脫，雙膝彼此相碰。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 5:29; 但以理書 5:16; 但以理書 2:48"> 王大聲高呼，要人把占卜者、迦勒底人和算命者帶來。王開口對巴比倫的智慧人說：「任何人讀出這文字，並把它的釋義講明給我，他就必身穿紫袍，項戴金鏈，在國中掌權，位居第三。」</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 2:27; 但以理書 4:7; 創世記 41:8"> 那時，王所有的智慧人都來了，卻不能讀出這文字，也不能把它的釋義顯明給王。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:6; 但以理書 2:1; 耶利米書 6:24"> 於是伯沙撒王極其惶恐，臉色大變，他的大臣們也都驚愕困惑。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 3:9; 但以理書 6:6; 但以理書 2:4"> 太后因王和他大臣們所說的話，就來到宴會大廳。太后開口說：「願王萬歲！不要讓你的意念使你惶恐，臉色也不要變。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 4:8–9; 但以理書 2:47–48; 但以理書 4:18"> 在你的國中有一個人，他裡面有聖神之靈；你先王年間就發現這人裡面有亮光、有悟性、有智慧如同神的智慧；你先王尼布甲尼撒親自任命他為術士、占卜者、迦勒底人和算命者的領袖。你先王這樣做<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="這樣做——輔助詞語。">c</a></sup>，</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 5:14; 但以理書 6:3; 但以理書 1:7"> 是因為發現但以理裡面有超卓的靈性、有理智、有悟性，還能解夢、講解謎語、解答難題；先王給他起名為伯提沙撒。現在讓人把但以理召來，他必講明那文字的釋義。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理書 6:13; 但以理書 5:11; 但以理書 2:25"> 於是但以理被帶到王面前，王就開口對但以理說：「你就是我先王從猶大帶來的猶大擄民中的但以理吧！</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 5:11–12"> 我聽說過你裡面有神的靈，也發現你裡面有亮光、悟性、超卓的智慧。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:7–8; 以賽亞書 47:12; 以賽亞書 29:10–12"> 現在智慧人和占卜者都被帶到我面前，為要他們讀出這文字，並把它的釋義顯明給我，但他們卻不能講明這句話的釋義；</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 5:7; 創世記 40:8; 但以理書 5:29"> 而我聽說過你能講解釋義，解答難題。現在如果你能讀出這文字，並把它的釋義顯明給我，你就必身穿紫袍，項戴金鏈，在國中掌權，位居第三。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀下 5:16; 創世記 14:23; 列王紀下 5:26"> 那時，但以理在王面前回應說：「願你的禮物歸自己，願你的賞賜給別人；然而我要為王讀出這文字，並把那釋義顯明給王。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 2:37–38; 但以理書 4:17; 但以理書 4:22–25"> 王啊，至高神把國度、權勢、尊榮和威嚴賜給了你先王尼布甲尼撒！</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 3:6; 但以理書 2:12–13; 但以理書 3:4"> 因著神所賜給他的權勢，所有的民族、國家、語言群體都在他面前戰兢恐懼；他想要殺誰就殺誰，想要讓誰活就讓誰活，想要高舉誰就高舉誰，想要降卑誰就降卑誰。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 9:17; 耶利米書 13:18; 希伯來書 3:13"> 然而，他心裡高舉自己，靈裡變得剛硬，以致行事狂傲，就從王權的寶座上被廢黜，他的尊榮也被奪去了。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 4:25; 以西結書 17:24; 但以理書 4:35"> 他從世人中被趕出，他的心變得像獸的心一樣，他的住處與野驢在一起，他像牛那樣吃牧草，身體被天上的露水濕透，直到他明白：至高神在人的國中掌權，願意立誰就立誰治理國家。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歷代志下 33:23; 出埃及記 10:3; 雅各書 4:17"> 「至於你，他的繼位人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="繼位人——原文直譯「兒子」或「子孫」。">d</a></sup>伯沙撒啊！你雖然知道這一切，自己的心卻不降卑，</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 12:10; 但以理書 4:37; 耶利米書 10:23"> 反而對天上的主高舉自己，讓人把他殿中的器皿帶到你面前來，你和你的大臣們、妻子們、妃嬪們都用這些來喝酒；你稱讚那些不能看、不能聽、不能知——用金、銀、銅、鐵、木、石所做的神明，卻不尊崇那位掌握你的氣息、掌握你一切道路的神。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 5:5"> 於是，有一隻手<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="手——原文直譯「手掌」。">e</a></sup>從神那裡被派來，寫下了這文字。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 「所寫下的文字是：彌尼，彌尼，提客勒，賠珥新。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 25:11–12; 以賽亞書 47:1–15; 耶利米書 27:7"> 這句話的釋義是這樣的：『彌尼』就是神已經數算了你國的年日<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的年日——輔助詞語。">f</a></sup>，使它終結了；</span>
<span className="v" id="v27" data-v="27" data-xref="約伯記 31:6; 哥林多前書 3:13; 詩篇 62:9"> 『提客勒』就是在天平上你已經被稱量了，發現了虧缺；</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 13:17; 但以理書 6:28; 但以理書 5:31"> 『賠珥新』就是你的國已經被分割，賜給了米底亞和波斯。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理書 5:16; 但以理書 5:7"> 伯沙撒下令，人就給但以理穿上紫袍，把金鏈戴在他的頸項上，並宣布他是國中位居第三的掌權者。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 51:31; 耶利米書 51:57; 耶利米書 51:39"> 當夜，迦勒底人的王伯沙撒被殺了。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 9:1; 但以理書 6:1"> 米底亞人大流士接取這國；當時他六十二歲。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 36:5–7; 列王紀下 24:1–2; 列王紀下 24:13"> 猶大王約雅敬在位第三年，巴比倫王尼布甲尼撒來到耶路撒冷，圍困了它。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 36:7; 撒迦利亞書 5:11; 耶利米書 27:19–20"> 主把猶大王約雅敬以及神殿中的一部分器具，交在尼布甲尼撒的手中；他就都帶到示拿地他神明的廟宇，把器具放入他神明的寶庫。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 39:7; 列王紀下 20:17–18; 列王紀下 24:15"> 尼布甲尼撒王吩咐他的太監長亞施培納，從以色列子孫中，帶來一些王室後裔和貴族中的年輕人——</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 5:11; 使徒行傳 7:22; 箴言 22:29"> 他們沒有任何殘疾，樣貌美好，在各樣的學問上明達，富有學識，在知識上有悟性，有能力在王宮中侍立；王又吩咐太監長教導他們迦勒底人的典籍和語言。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 1:19; 列王紀上 10:8; 但以理書 1:8"> 王從自己的美食和所飲用的酒中，給他們指定了每天的份額，要他們受教養三年；三年結束後，他們將在王面前侍立。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 14:14; 馬太福音 24:15; 但以理書 2:17"> 他們中有猶大子孫的但以理、哈納尼雅、米沙利和亞撒利雅。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 5:12; 但以理書 4:8; 但以理書 2:49"> 太監總管給了他們新的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="新的——輔助詞語。">a</a></sup>名字，稱但以理為伯提沙撒，哈納尼雅為沙德拉克，米沙利為米沙克，亞撒利雅為亞伯尼哥。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 141:4; 以西結書 4:13–14; 利未記 11:45–47"> 但以理決心不讓王的美食和王所飲用的酒玷汙自己；於是請求太監總管允許他不因這些玷汙自己。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 詩篇 106:46"> 神使但以理在太監總管面前蒙恩慈和憐憫。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 6:16–18; 約翰福音 12:42–43; 箴言 29:25"> 太監總管對但以理說：「我懼怕我主我王，他已經指定了你們的食物和飲物。為什麼要讓他看到你們的臉色與你們同齡的年輕人相比顯得憔悴呢？你們會使我的頭在王面前保不住！」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 但以理對太監總管所指定負責但以理、哈納尼雅、米沙利、亞撒利雅的管事者說：</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 14:2; 但以理書 1:16; 創世記 1:29–30"> 「請你試驗你的僕人們十天，給我們吃素菜、喝清水；</span>
<span className="v" id="v13" data-v="13"> 之後，請你察看我們的樣貌以及那些吃王美食的年輕人的樣貌，然後照著你所察看的對待你的僕人們吧！」</span>
<span className="v" id="v14" data-v="14"> 管事者就聽允了他們這請求，試驗了他們十天。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 23:25; 箴言 10:22; 列王紀下 4:42–44"> 十天結束後，他們的樣貌看起來比所有吃王美食的年輕人更加美好肥壯。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:12"> 於是，管事者就繼續撤掉他們的美食和飲用酒，給他們素菜。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 3:12; 雅各書 1:5; 但以理書 2:21"> 至於這四個年輕人，神賜給他們在各種典籍和學問上的知識和明達；但以理甚至能領悟各樣的異象和異夢。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 1:5"> 王所吩咐的那些日子結束時，就是要把他們帶進宮中<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="宮中——輔助詞語。">b</a></sup>的時候，太監總管就把他們帶到尼布甲尼撒面前。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 創世記 41:46; 但以理書 1:5"> 王與他們談論，在那些年輕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那些年輕人——原文直譯「他們所有人」。">c</a></sup>中找不到一個像但以理、哈納尼雅、米沙利、亞撒利雅那樣的。於是這四個人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="這四個人——原文直譯「他們」。">d</a></sup>就在王面前侍立。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 8:19; 以賽亞書 47:12–14; 列王紀上 4:29–34"> 王向他們尋問各樣有關學問和悟性的事，發現他們勝過全國所有的術士和占卜者十倍。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 6:28; 但以理書 10:1"> 但以理在王面前<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="王面前——輔助詞語。">e</a></sup>，一直到居魯士王元年。</span>
</div>
</div>

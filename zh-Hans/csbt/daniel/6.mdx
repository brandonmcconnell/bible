<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="DAN" data-book-slug="daniel" data-book-name="但以理書" data-chapter="6" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 18:21–22; 但以理書 5:31; 以斯帖記 1:1"> 大流士認為最好任命一百二十個行政官來管理國家，分治全國，</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 2:48–49; 但以理書 5:29; 以斯帖記 7:4"> 又在他們之上任命三位總督察，但以理是其中之一；這些行政官要向他們三位負責交代，好使王不受損失。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 5:14; 箴言 22:29; 創世記 41:38–41"> 這但以理在總督察和行政官中出類拔萃，因為在他裡面有超卓的靈性；王就打算任命他治理全國。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 3:16; 腓立比書 2:15; 彼得前書 2:12"> 於是其他總督察和行政官就試圖在他處理<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="處理——輔助詞語。">a</a></sup>國事上找出把柄控告但以理，卻找不出他的任何把柄或過失；因為他忠心可靠，在他身上找不出任何疏忽或過失。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 24:13–16; 以斯帖記 3:8; 使徒行傳 24:20–21"> 這些人就說：「我們如果不在他的神的法令上找出把柄攻擊他，就找不出任何把柄控告這但以理。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理書 2:4; 尼希米記 2:3; 但以理書 6:21"> 於是這些總督察和行政官合謀來到王那裡，對王這樣說：「願大流士王萬歲！</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 59:3; 詩篇 62:4; 但以理書 3:27"> 國中所有的總督察、總長、行政官、謀士和省長一同商議，要請王設立一條法規，強制執行一條禁令：王啊，三十天之內，無論何人，如果向你以外的任何神明或任何人祈禱，就必被扔進獅子坑！</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 6:15; 以斯帖記 1:19; 但以理書 6:12"> 王啊，現在請你照著不能廢除的米底亞和波斯的法令，設立這禁令並簽署這文告，使它不能更改！」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 146:3; 詩篇 118:9; 詩篇 62:9–10"> 於是，大流士王簽署了這禁令文告。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:29; 詩篇 55:17; 帖撒羅尼迦前書 5:17–18"> 但以理知道這文書已經簽署了，回到自己的家裡——他閣樓上的窗戶朝耶路撒冷開著——仍然一天三次雙膝跪下，在他的神面前禱告、感謝，就像以前那樣做。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 37:32–33; 詩篇 10:9; 但以理書 6:6"> 那時，這些人合謀而來，發現但以理正在他的神面前祈禱、懇求。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 6:8; 但以理書 3:8–12; 以斯帖記 1:19"> 於是他們來到王面前，提起有關王的禁令：「王啊，難道你不是簽署了以下的禁令嗎？三十天之內，無論何人，如果向你以外的任何神明或任何人祈禱，就必被扔進獅子坑！」<br />王開口說：「照著不能廢除的米底亞和波斯的法令，確實如此。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理書 3:12; 使徒行傳 5:29; 但以理書 2:25"> 他們就在王面前回應說：「王啊，猶大擄民中的但以理，不理會你的命令，也不理會你所簽署的禁令，他仍然一天三次祈禱。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 6:26; 馬太福音 27:17–24; 撒母耳記下 3:28–29"> 王聽見了這話，就極其煩惱，定意要拯救但以理；直到日落的時候，他還在盡一切努力要解救但以理。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 6:12; 詩篇 94:20–21; 但以理書 6:8"> 這些人又合謀來到王那裡，對王說：「王啊，你要知道，照著米底亞和波斯的法令，王所設立的任何禁令和法規都不能更改！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:39–40; 約伯記 5:19; 詩篇 91:14–16"> 王下令，人就把但以理帶來，扔進獅子坑中。王開口對但以理說：「願你的神，你一直事奉的那一位，親自拯救你！」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:53; 使徒行傳 12:4; 馬太福音 27:60–66"> 人又把一塊石頭搬來，放在坑口上，王就用自己的印和大臣們的印封上石頭；這樣，有關但以理的事就不能更改了。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖記 6:1; 但以理書 2:1; 撒母耳記下 12:16–17"> 然後，王回到宮中，整夜禁食，不讓人給他帶來任何娛樂享受，他也睡不著覺。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="帖撒羅尼迦前書 3:5; 馬可福音 16:2; 馬太福音 28:1"> 清晨天一亮，王就起來，急忙前往獅子坑。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 16:11; 希伯來書 7:25; 但以理書 6:27"> 他靠近那坑的時候，用憂傷的聲音呼叫但以理，開口對但以理說：「永生神的僕人但以理啊！你的神，你一直事奉的那一位，有沒有拯救你脫離那些獅子呢？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理書 2:4; 但以理書 6:6; 尼希米記 2:3"> 那時但以理對王說：「願王萬歲！</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太後書 4:17; 希伯來書 11:33; 使徒行傳 12:11"> 我的神派遣他的使者封住了獅子的口，使牠們沒有傷害我，因為我在神面前是清白的；王啊，我在你面前也沒有做過任何害人的事。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歷代志上 5:20; 馬可福音 9:23; 但以理書 3:27–28"> 王因此極其高興，下令把但以理從坑裡拉上來；但以理就被人從坑裡拉上來，在他身上找不到任何損傷，因為他信靠他的神。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 38:13; 以斯帖記 7:10; 申命記 24:16"> 王又下令，人就把那些惡意控告但以理的人帶來，把他們連同他們的兒女、妻子都扔進獅子坑。他們還沒有落到坑底，那些獅子就撲住他們，把他們全身的骨頭都咬碎了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="但以理書 4:1; 以斯拉記 1:1–2; 以斯帖記 3:12"> 隨後，大流士王寫詔書給住在全地的所有民族、國家、語言群體，說：「願你們大有平安！</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 4:34; 路加福音 1:33; 但以理書 3:29"> 現在我下令，在我國的一切權柄之下，人人都要在但以理的神面前恐懼戰兢——<br /><span className="pl pl-1">因為他是永生的神，</span><br /><span className="pl pl-1">他永遠長存，</span><br /><span className="pl pl-1">他的國度不會毀滅，</span><br /><span className="pl pl-1">他的權柄沒有窮盡！</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 4:2–3; 詩篇 18:50; 使徒行傳 4:30"> <span className="pl pl-1">他拯救人、解救人，</span><br /><span className="pl pl-1">在天上地上施行神蹟奇事，</span><br /><span className="pl pl-1">他拯救了但以理脫離獅子的爪。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理書 1:21; 歷代志下 36:22–2; 以賽亞書 44:28–1"> 這樣，大流士在位的時候和波斯人居魯士在位的時候，這但以理都事事通達。</span>
</div>
</div>

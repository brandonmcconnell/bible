<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="DAN" data-book-slug="daniel" data-book-name="但以理書" data-chapter="2" data-verses="49">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 4:5; 以斯帖記 6:1; 約伯記 33:15–17"> 尼布甲尼撒在位第二年，尼布甲尼撒做夢，靈裡煩亂，睡不著覺。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 1:20; 但以理書 4:6; 創世記 41:8"> 於是王吩咐人召來術士、占卜者、行巫術的和迦勒底人，要他們把王的夢告訴王。他們就來了，站在王面前。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 40:8; 創世記 41:15; 但以理書 4:5"> 王對他們說：「我做了一個夢，靈裡煩亂，想要明白這夢。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理書 3:9; 但以理書 5:10; 以斯拉記 4:7"> 那些迦勒底人用亞蘭語對王說：「願王萬歲！請把夢告訴你的僕人們，我們就會講明夢的釋義。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:29; 以斯拉記 6:11; 列王紀下 10:27"> 王回應那些迦勒底人，說：「我所發出的命令是確定的：如果你們不把這夢和夢的釋義顯明給我，你們就必被千刀萬剮，你們的家必成為廢堆；</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 5:7; 但以理書 2:48; 但以理書 5:29"> 但如果你們講明這夢和夢的釋義，你們就必從我得到禮物、賞賜和極大的尊榮；因此你們要把這夢和夢的釋義講明給我！」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理書 2:4; 但以理書 2:9; 傳道書 10:4"> 他們第二次回應說：「請王把那夢告訴你的僕人們，我們就會講明那夢的釋義。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 4:5; 以弗所書 5:16"> 王回應說：「我清楚地知道你們是在拖延<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拖延——原文直譯「贏得」。">a</a></sup>時間，因為你們看到我所發出的命令是確定的：</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 41:23; 但以理書 7:25; 以斯帖記 4:11"> 如果你們不把這夢顯明給我，給你們的就只有一條法令。你們互相串通好了，要在我面前說謊言和亂語，直到時勢有所改變。現在你們要把這夢告訴我，好讓我知道你們能把夢的釋義講明給我。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 2:27"> 那些迦勒底人在王面前回應說：「地上沒有人能講明王所要求的事；事實上，沒有任何一個偉大、有權勢的君王，向任何一個術士、占卜者或迦勒底人問過這樣的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 5:11; 以賽亞書 57:15; 創世記 41:39"> 王所問的事，是件難事，除了不與屬肉體的人住在一起的神明，沒有誰能在王面前講明它。」</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 3:13; 馬太福音 2:16; 但以理書 3:19"> 王因此發怒，極其震怒，下令消滅巴比倫的所有智慧人。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 1:19–20; 以斯帖記 3:12–15; 以賽亞書 10:1"> 法令發出，要殺掉智慧人；人就尋找但以理和他的同伴，要殺掉他們。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 2:24; 耶利米書 52:12; 撒母耳記下 20:16–22"> 那時，但以理謹慎機智地回應阿約克——他是王的護衛長，出來要殺掉巴比倫的智慧人。</span>
<span className="v" id="v15" data-v="15"> 但以理開口對王的官長阿約克說：「從王而來的法令為什麼這樣急迫呢？」阿約克就把以上的事告訴了但以理。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:18–19; 但以理書 2:9–11"> 但以理就進去，請求王給他一些時間，好使他可以把那夢的釋義講明給王。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="但以理書 1:6–7; 但以理書 3:12; 但以理書 1:11"> 但以理回到自己的家裡，把這事告訴了他的同伴哈納尼雅、米沙利和亞撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 33:3; 馬太福音 18:19; 馬太福音 18:12"> 讓他們在這奧祕的事上，向天上的神祈求憐憫，免得但以理和他的同伴與巴比倫其餘的智慧人一同滅亡。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 12:6; 阿摩司書 3:7; 但以理書 7:7"> 於是這奧祕的事在夜間的異象中顯明給了但以理；但以理就頌讚天上的神。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 113:2; 詩篇 145:1–2; 啟示錄 5:12"> 但以理開口說：<br /><span className="pl pl-1">「願神的名受頌讚，從永遠到永遠</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="永遠到永遠——或譯作「亙古到永遠」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">因智慧和大能都屬於他；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 75:5–7; 詩篇 31:14–15; 詩篇 113:7–8"> <span className="pl pl-1">是他改變時勢和時期；</span><br /><span className="pl pl-1">是他廢王、立王；</span><br /><span className="pl pl-1">是他賜智慧給智慧人，</span><br /><span className="pl pl-1">賜知識給有悟性的人；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 12:22; 約翰一書 1:5; 耶利米書 23:24"> <span className="pl pl-1">是他顯明深奧和隱祕的事；</span><br /><span className="pl pl-1">他知道黑暗中有什麼，</span><br /><span className="pl pl-1">光明也與他同在。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 2:18; 出埃及記 3:15; 但以理書 2:29–30"> <span className="pl pl-1">我祖先的神哪，</span><br /><span className="pl pl-1">我感謝、稱讚你！</span><br /><span className="pl pl-1">因為你賜給我智慧和大能；</span><br /><span className="pl pl-1">我們向你祈求的，</span><br /><span className="pl pl-1">如今你已顯明給我，</span><br /><span className="pl pl-1">又把王的事顯明給了我們。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 27:24; 但以理書 2:12–14"> 於是，但以理進去見阿約克——他是王所指派要消滅巴比倫智慧人的。但以理對他這樣說：「不要消滅巴比倫的智慧人；請把我帶到王面前，我要把那夢的釋義講明給王。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 1:27–28; 但以理書 6:13; 但以理書 5:13"> 阿約克就急忙把但以理帶到王面前，對王這樣說：「我在猶大的擄民中找到一個人，他能把那夢的釋義顯明給王。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理書 1:7; 但以理書 5:16; 但以理書 5:12"> 王問那稱為伯提沙撒的但以理說：「難道你能把我做的夢和夢的釋義顯明給我嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 47:12–14; 但以理書 2:2; 以賽亞書 44:25"> 但以理在王面前回答說：「王所問的那奧祕的事，沒有智慧人、占卜者、術士或算命者能講明給王。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 40:8; 阿摩司書 4:13; 但以理書 10:14"> 然而天上有一位神，就是顯明奧祕的那一位，他已經使尼布甲尼撒王明白了末後的日子將要發生的事——這就是你在床上所做的夢和腦海中的異象。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:28; 阿摩司書 4:13; 但以理書 2:47"> 王啊，你在床上所懷的意念是此後將要發生的事，而顯明奧祕的那一位已經使你明白了將要發生的事！</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 41:16; 使徒行傳 3:12; 但以理書 2:17–18"> 至於那奧祕的事顯明給我，不是因為我比所有的活人更有智慧，而是要使王明白那夢的釋義和王心裡的意念。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷書 1:7; 以西結書 28:7; 但以理書 7:3–17"> 「王啊，你正在觀看，看哪，有一座巨大的像！這像極大，非常光耀，立在你前面，它的樣貌令人恐懼。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 51:7; 但以理書 7:4–6; 啟示錄 17:4"> 這像的頭是純金的，它的胸膛和膀臂是銀的，它的腹部和大腿是銅的，</span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 7:19–26; 但以理書 7:7–8; 但以理書 2:40–43"> 它的小腿是鐵的，它的腳有部分是鐵的，有部分是泥的。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理書 2:44–45; 但以理書 8:25; 撒迦利亞書 12:3"> 你繼續觀看，有一塊非人手鑿出的石頭，砸在這像的鐵和泥的腳上，把腳砸碎了。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 2:2–3; 詩篇 37:10; 啟示錄 20:11"> 這樣，鐵、泥、銅、銀、金都一同被砸得粉碎了，就像夏天打穀場上的糠秕，被風吹散，無蹤跡可尋；但砸這像的石頭卻變成一座大山，充滿全地。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理書 2:23–24"> 「以上就是那夢；現在我們要在王面前講說夢的釋義。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 26:7; 耶利米書 27:6–7; 以斯拉記 7:12"> 王啊，你是王中之王！天上的神把國度、權能、力量和尊榮都賜給了你，</span>
<span className="v" id="v38" data-v="38" data-xref="但以理書 4:21–22; 詩篇 50:10–11; 耶利米書 27:5–7"> 也把世人、田野的走獸、天空的飛鳥，無論住在哪裡，都交在你的手中，讓你統轄這一切；你就是那金的頭。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="但以理書 5:28–31; 以賽亞書 44:28–5; 但以理書 2:32"> 「在你之後，會有另一個國興起，卻不如你；接下來會再有一個國，就是那銅的第三個國，要統轄全地；</span>
<span className="v" id="v40" data-v="40" data-xref="但以理書 7:7; 但以理書 7:19–26; 但以理書 11:36–45"> 然後會有第四個國，它必強硬如鐵。鐵怎樣砸碎、擊破一切，怎樣壓碎一切，這國也照樣砸碎、壓碎一切。</span>
<span className="v" id="v41" data-v="41" data-xref="啟示錄 17:12; 但以理書 2:33–35; 啟示錄 12:3"> 正如你看到那像的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那像的——輔助詞語。">c</a></sup>腳和腳趾有部分是陶匠的泥，有部分是鐵，這國也必是一個分裂的國；但這國裡面會有鐵的堅硬，就像你看到有鐵與濕泥混合那樣。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 7:24; 啟示錄 13:1"> 腳趾怎樣有部分是鐵，有部分是泥，這國也怎樣有部分強硬，有部分脆弱。</span>
<span className="v" id="v43" data-v="43"> 正如你看到有鐵與濕泥混合，他們也必與各人種混合；但他們彼此卻不會粘合，就像鐵不與泥混合那樣。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 28:18; 路加福音 1:32–33; 但以理書 6:26"> 「這些君王年間，天上的神必立起一個永不毀滅的國度，這國度不會交給別的民族，卻會砸碎、終結所有這些國，而它會存到永遠，</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 28:16; 創世記 41:32; 申命記 10:17"> 就像你看到那塊從山而出、非人手鑿出的石頭，砸碎了鐵、銅、泥、銀、金那樣。偉大的神已經給王顯明了此後將要發生的事。這夢是確實的，夢的釋義也是可靠的。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 10:25; 使徒行傳 14:13; 以斯拉記 6:10"> 於是尼布甲尼撒王就臉伏於地，向但以理下拜，並且吩咐人向他獻上祭物和香品。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理書 2:22; 但以理書 2:28; 阿摩司書 3:7"> 王開口對但以理說：「你既然能顯明這奧祕，那麼你們的神真是萬神之神、萬王之主，是顯明奧祕的那一位！」</span>
<span className="v" id="v48" data-v="48" data-xref="但以理書 2:6; 但以理書 4:9; 但以理書 5:11"> 王就提拔了但以理，賜給他許多貴重的禮物，使他統轄巴比倫全省，並且立他為總長之首管理巴比倫的所有智慧人。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理書 1:7; 以斯帖記 2:19; 但以理書 3:12–30"> 但以理向王提出請求，王就指派沙德拉克、米沙克、亞伯尼哥管理巴比倫省的事務；但以理卻留在王的宮廷中。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:11–12; 哥林多前書 1:1; 羅馬書 1:1"> 我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——輔助詞語。">a</a></sup>保羅做使徒，既不是出於人，也不是藉著人，而是藉著耶穌基督和使他從死人中復活的父神；</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 16:1; 腓立比書 4:21; 使徒行傳 16:5–6"> 我和所有與我在一起的弟兄致加拉太的各教會：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約翰二書 1:3; 哥林多後書 13:14; 羅馬書 1:7–15"> 願恩典與平安從神我們的父和主耶穌基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="神我們的父和主耶穌基督——有古抄本作「父神和我們的主耶穌基督」。">b</a></sup>臨到你們！</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 20:28; 羅馬書 4:25; 加拉太書 2:20"> 基督照著神我們父的旨意，已經為我們的罪孽獻上了自己，為要把我們從現今這邪惡的世代救出來。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 11:36; 猶大書 1:25; 詩篇 72:19"> 願榮耀歸於他，直到永永遠遠！阿們。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 11:4; 加拉太書 5:7–8; 以賽亞書 29:13"> 我感到驚奇，你們這麼輕易地離棄了藉著基督的恩典召喚你們的那一位，轉向了別的福音。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 15:24; 羅馬書 16:17–18; 加拉太書 5:10"> 其實那並不是另一個福音，而是有些人在攪擾你們，想要篡改基督的福音。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 11:13–14; 加拉太書 1:9; 啟示錄 22:18–19"> 然而，就算是我們，或是天上來的使者，如果向你們傳講的福音，與我們先前所傳給你們的不同，他就該受詛咒。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 16:17; 箴言 30:6; 申命記 4:2"> 我們先前說過，現在我再說：如果有人向你們傳講的福音，與你們先前所領受的不同，他就該受詛咒。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="帖撒羅尼迦前書 2:4; 使徒行傳 5:29; 以弗所書 6:6"> 我現在到底是要得人的信任，還是要得神的信任呢？難道我是想討人的喜悅嗎？如果我仍然討人的喜悅，我就不是基督的奴僕了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太書 1:1; 哥林多前書 2:9–10; 哥林多前書 11:23"> 弟兄們，我要你們明白，我所傳的福音不是按人的意思，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 1:16; 哥林多前書 2:10; 加拉太書 1:1"> 因為我既不是從人領受的，也不是受人教導的，而是藉著耶穌基督的啟示領受的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:3; 哥林多前書 15:9; 使徒行傳 22:3–5"> 你們聽說過我以前在猶太教中的行事為人：我曾極力地逼迫神的教會，殘害她。</span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 2:8; 使徒行傳 26:5; 腓立比書 3:4–6"> 我在猶太教中，比我本族的許多同輩更進一步，是一個對我祖先的傳統格外熱心的人。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:5; 以賽亞書 49:5; 以賽亞書 49:1"> 然而神，就是當我在母腹裡時就把我分別出來、又藉著他的恩典召喚我的那一位，樂意</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 16:17; 以弗所書 3:5–10; 以弗所書 6:12"> 將他的兒子啟示在我裡面，好使我在外邦人中傳揚他。我沒有立刻與人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="人——原文直譯「血和肉」。">c</a></sup>商量，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 9:20–25; 哥林多後書 11:32–33; 加拉太書 1:18"> 也沒有上耶路撒冷去見那些比我先做使徒的，而是往阿拉伯去，然後再回到大馬士革。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 9:22–23; 使徒行傳 9:26–29; 使徒行傳 22:17–18"> 三年以後，我才上耶路撒冷去見磯法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="磯法——有古抄本作「彼得」。">d</a></sup>，在他那裡住了十五天。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:55; 馬可福音 6:3; 馬太福音 12:46"> 至於其他的使徒，除了主的弟弟<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="弟弟——原文直譯「兄弟」。">e</a></sup>雅各，我都沒有見過。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:1; 哥林多後書 11:31; 哥林多後書 11:10–11"> 我現在所寫給你們的，看哪，是在神面前寫的，我不是在說謊。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 15:41; 使徒行傳 9:30; 使徒行傳 6:9"> 後來，我到了敘利亞和奇里乞亞地區。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:14; 羅馬書 16:7; 帖撒羅尼迦後書 1:1"> 那時，在基督裡的猶太各教會，還沒有見過我的面。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 15:8–10; 使徒行傳 9:13; 提摩太前書 1:13–16"> 他們只是聽說：「以前逼迫我們的那個人，現在卻在傳揚他曾經殘害過的信仰。」</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 9:8; 使徒行傳 11:18; 路加福音 15:10"> 他們就因我的緣故不住地榮耀神。</span>
</div>
</div>

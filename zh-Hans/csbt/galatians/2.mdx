<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 2:3; 使徒行傳 14:12; 哥林多後書 8:23"> 過了十四年，我與巴拿巴一起再次上耶路撒冷，並且帶著提多一起去。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 2:6; 腓立比書 2:16; 帖撒羅尼迦前書 3:5"> 我是照著啟示上去的，向他們陳述了我在外邦人中所傳的福音，不過是單獨地向那些公認是人物的做了陳述，免得我過去或是現在所奔跑的都落了空<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="免得我過去或是現在所奔跑的都落了空——或譯作「這樣，我過去或是現在就不會白白奔跑了」。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 5:2–6; 使徒行傳 16:3; 哥林多前書 9:20–21"> 與我在一起的提多，雖然是希臘人，也沒有被迫受割禮。</span>
<span className="v" id="v4" data-v="4" data-xref="猶大書 1:4; 加拉太書 5:1; 加拉太書 4:3"> 其實提到這件事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="提到這件事——輔助詞語。">b</a></sup>，是因著一些偷偷進來的假弟兄的緣故；他們混進來窺視我們在基督耶穌裡所擁有的自由，為了要奴役我們。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 2:14; 加拉太書 4:16; 歌羅西書 1:5"> 我們對這些人，一刻也沒有屈服妥協，好使福音的真理在你們中間繼續存留。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:2; 使徒行傳 10:34; 哥林多後書 12:11"> 至於那些公認是人物的——無論他們從前什麼樣，都對我沒有區別；神不以外貌取人。那些公認是人物的並沒有給我增添什麼；</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 加拉太書 1:16"> 不過他們反而看出來：我受了委託去傳福音給沒有受割禮的人，正如彼得受了委託去傳福音給受割禮的人，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:15; 使徒行傳 22:21; 使徒行傳 2:14–41"> 因為在彼得裡面做工、使他做受割禮之人使徒的那一位，也在我裡面做工、使我做外邦人的使徒。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 12:3; 啟示錄 3:12; 加拉太書 2:2"> 公認是柱石的雅各、磯法和約翰，既然明白了神所賜給我的恩典，就向巴拿巴和我伸出右手行契合之禮<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="伸出右手行契合之禮——原文直譯「伸出右手的契合」。">c</a></sup>，要我們往外邦人那裡去，而他們往受割禮的人那裡去；</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 24:17; 約翰一書 3:17; 希伯來書 13:16"> 只是要我們記得窮人，而這一點也正是我一向努力做的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:20; 哥林多後書 5:16; 使徒行傳 15:1"> 不過磯法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="磯法——有古抄本作「彼得」。">d</a></sup>來到安提阿的時候，我曾當面抵擋他，因為他有該責備的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:28; 路加福音 15:2; 使徒行傳 11:2–3"> 原來，從雅各那裡來的一些人到達之前，磯法與外邦人一起吃飯；可是那些人一到，他因為怕那些割禮派的人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="割禮派的人——指「那些主張外邦人也必須受割禮的人」；或譯作「受割禮的人」。">e</a></sup>，就退縮，與外邦人分開了。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 15:33; 以弗所書 4:14; 希伯來書 13:9"> 其餘的猶太人也跟著他裝假，以致連巴拿巴也被他們的偽善引入歧途。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 2:5; 使徒行傳 10:28; 使徒行傳 15:10–11"> 但我一看見他們的行為不符合福音的真理，就在大家面前對磯法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="磯法——有古抄本作「彼得」。">f</a></sup>說：「你身為猶太人，如果像外邦人而不像猶太人那樣生活，怎麼還要強求外邦人像猶太人一樣呢？」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多書 3:3; 以弗所書 2:3; 以弗所書 2:11–12"> 我們生來是猶太人，不是「外邦中的罪人」，</span>
<span className="v" id="v16" data-v="16" data-xref="腓立比書 3:9; 詩篇 143:2; 羅馬書 9:30"> 不過我們知道：人被稱為義不是本於律法上的行為，而是藉著信耶穌基督。於是我們信了基督耶穌，為要因信基督稱義，而不是本於律法上的行為，因為沒有一個人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="人——原文直譯「肉體」。">g</a></sup>本於律法上的行為會被稱為義。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 6:1–2; 約翰一書 3:8–10; 約翰一書 3:5"> 但如果我們自己尋求在基督裡被稱為義，卻被發現還是罪人，那麼，難道基督就成了罪的僕人嗎？絕對不是！</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 4:9–12; 加拉太書 2:4–5; 加拉太書 2:12–16"> 因為我如果重建自己以前所拆毀的，就證明我是違犯律法的人。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:4; 羅馬書 6:2; 帖撒羅尼迦前書 5:10"> 原來藉著律法，我已經向律法死了，使我能向神活著。我已經和基督一起被釘十字架，</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 5:24; 哥林多後書 5:15; 羅馬書 6:4–6"> 所以現在活著的不再是我，而是基督在我裡面活著；並且如今我在肉體中活著，是因信神的兒子而活；他愛我，甚至為我捨棄了自己。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 11:6; 加拉太書 3:21; 希伯來書 7:11"> 我不棄絕神的恩典，因為義如果是藉著律法而來的，那麼，基督就白白地死了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 5:7–8; 哥林多後書 11:3; 加拉太書 1:6"> 唉，無知的加拉太人哪！是誰迷惑了你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「使你們不信從真理」。">a</a></sup>呢？被釘十字架的耶穌基督，難道不是先前被描繪在你們眼前的嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 10:16–17; 加拉太書 3:14; 使徒行傳 15:8"> 我只想請教你們這一點：你們領受了聖靈，是本於律法上的行為，還是本於信而聽從呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 5:4–8; 加拉太書 4:7–10; 希伯來書 7:16–19"> 你們是這樣的無知嗎？你們以聖靈開始，現在卻要以肉體完成嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="約翰二書 1:8; 哥林多前書 15:2; 希伯來書 10:32–39"> 你們受了這麼多的苦，都沒有意義嗎？會不會真的沒有意義呢！</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 3:2; 使徒行傳 14:9–10; 使徒行傳 19:11–12"> 那麼，神賜給你們聖靈，又在你們中間行神蹟，是本於你們在律法上的行為，還是本於你們信而聽從呢？</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 15:6; 羅馬書 4:21–22; 雅各書 2:23"> 正如「亞伯拉罕信神，這就被算為他的義」，</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:7–8; 加拉太書 3:9; 加拉太書 3:26–29"> 因此你們應當知道：那些本於信的，他們才是亞伯拉罕的子孫。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:3; 創世記 22:18; 創世記 28:14"> 既然經文預先看見神要使外邦人因信稱義，就預先把福音傳給了亞伯拉罕，說：「萬國都要藉著你蒙祝福。」</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 4:16; 加拉太書 3:29; 羅馬書 4:24"> 這樣，那些有信仰的人，與有信仰的亞伯拉罕一同蒙祝福。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 27:26; 羅馬書 8:7; 羅馬書 3:19–20"> 凡是本於律法上行為的人，都在詛咒之下，因為經上記著：「任何人不持守、不遵行律法書上所記載的一切，都是被詛咒的。」</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷書 2:4; 羅馬書 1:17; 希伯來書 10:38"> 所以，明顯地沒有人能藉著律法在神面前被稱為義，因為經上說：「義人將因信而活。」</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:5; 羅馬書 10:5–6; 尼希米記 9:29"> 律法不是本於信，但是「遵行這些事的人，將因此而活。」</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:24; 申命記 21:23; 希伯來書 9:12"> 基督替我們成了詛咒，從律法的詛咒中救贖了我們，因為經上記著：「凡是被掛在木頭上的，都是被詛咒的。」</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:28–29; 哥林多前書 12:13; 以西結書 36:26–27"> 這是為了讓亞伯拉罕所蒙的祝福，能在基督耶穌裡臨到外邦人，好使我們能藉著信領受所應許的聖靈。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 9:17; 羅馬書 6:19; 羅馬書 3:5"> 弟兄們，我按人的意思說話：甚至是人的約，一旦證實了，也沒有人能廢棄或加添。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:7–8; 羅馬書 4:13; 路加福音 1:55"> 神的各樣應許，原是對亞伯拉罕和他的一個後裔說的。神並沒有說「後裔們」，像是指著許多人；而是說「你的一個後裔」，像是指著一個人，這一位就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 11:39–40; 創世記 15:13; 羅馬書 4:13–14"> 我說的這話是：四百三十年以後出現的律法，不能廢棄神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「為基督」。">b</a></sup>預先立好的約，使那應許無效。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:12–15; 加拉太書 2:21; 羅馬書 4:13–16"> 如果繼業是本於律法，就不再是本於應許了；但是神把繼業<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="繼業——輔助詞語。">c</a></sup>賜給亞伯拉罕是藉著應許。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 7:53; 羅馬書 7:7–13; 希伯來書 2:2"> 那麼，為什麼要有律法呢？律法是為了過犯的緣故被加上的，直到那蒙應許的後裔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="那蒙應許的後裔——指「耶穌基督」。">d</a></sup>來臨；律法是藉著天使，通過中保的手所規定的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前書 2:5; 申命記 6:4; 約伯記 9:33"> 不過中保沒有為一方的，神卻是一位。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 2:21; 羅馬書 9:31; 羅馬書 3:20–22"> 那麼，律法和神的各樣應許是對立的嗎？絕對不是！如果一個能使人得生命的律法被賜下，義就真是本於律法了。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 11:32; 希伯來書 9:15; 加拉太書 3:23"> 然而，經上的話把萬物<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="萬物——或譯作「萬人」。">e</a></sup>都圈在罪孽之下，為要使這因信耶穌基督而來的應許，賜給那些相信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 5:18; 加拉太書 3:24–25; 加拉太書 3:19"> 只是在這信仰臨到之前，我們都被圈在律法之下受看守，直到這將要來臨的信仰被啟示出來。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 10:4; 使徒行傳 13:38–39; 羅馬書 7:24–25"> 這樣，律法一向是我們的導師<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="導師——或譯作「監護人」。">f</a></sup>，直到基督，好使我們能因信稱義。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 6:14; 羅馬書 7:4; 希伯來書 10:15–18"> 不過，這信仰既然已經臨到，我們就不在導師<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="導師——或譯作「監護人」。">g</a></sup>之下了，</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所書 1:5; 哥林多後書 6:18; 約翰福音 1:12–13"> 因為你們藉著信，在基督耶穌裡，都是神的兒女。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="羅馬書 13:14; 哥林多前書 12:13; 羅馬書 6:3–4"> 實際上，你們所有受洗<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="受洗——或譯作「受浸」。">h</a></sup>歸入基督的，就穿上了基督，</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 12:12–13; 歌羅西書 3:11; 羅馬書 3:29–30"> 其中沒有猶太人或希臘人，沒有為奴的或自由的，沒有男的或女的，因為你們在基督耶穌裡都合而為一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 3:6; 羅馬書 9:7–8; 加拉太書 3:7"> 而且，如果你們屬於基督，你們就是亞伯拉罕的後裔，是照著應許的繼承人。</span>
</div>
</div>

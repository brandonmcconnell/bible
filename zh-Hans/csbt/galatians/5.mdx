<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 3:17; 加拉太書 5:13; 彼得前書 2:16"> 基督釋放了我們，使我們得自由。所以你們當站立得穩，不要再被奴役的軛所束縛。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 5:6; 使徒行傳 15:1; 羅馬書 9:31–32"> 看，我保羅告訴你們：如果你們要受割禮，基督就對你們毫無益處了。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:10; 羅馬書 2:25; 雅各書 2:10–11"> 我再次忠告每一個受割禮的人：他有責任遵行全部律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他有責任遵行全部律法——原文直譯「他欠下這筆遵行全部律法的債」。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:31–32; 彼得後書 2:20–22; 羅馬書 11:6"> 你們這些藉著律法被稱為義的人，你們是與基督隔絕，從恩典中墮落了。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 130:5; 帖撒羅尼迦前書 1:10; 詩篇 62:5"> 要知道，我們藉著聖靈，本於信，滿懷著<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="滿懷著——原文直譯「熱切等待」。">b</a></sup>稱義的盼望；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 6:15; 哥林多前書 7:19; 雅各書 2:14–26"> 因為在基督耶穌裡，受割禮或不受割禮都沒有用處，只有藉著愛行出來的信仰才有用處。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 9:24; 加拉太書 3:1; 希伯來書 12:1"> 你們一向跑得很好，到底是誰攔阻了你們，使你們不信從真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 1:6; 羅馬書 8:28"> 這種勸誘不是出於召喚你們的那一位。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 15:33; 哥林多前書 5:6–7; 馬可福音 8:15"> 一點點酵母能使整個麵團發酵。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 5:12; 哥林多後書 2:3; 加拉太書 1:7"> 我在主裡深信你們不會有別的思想；不過那攪擾你們的，無論他是誰，都將受到懲罰。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 1:23; 加拉太書 6:12; 加拉太書 4:29"> 弟兄們，如果我仍然傳講割禮，我為什麼還受逼迫呢？如果我這樣做，十字架使人絆腳的地方早就沒有了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:10; 哥林多前書 5:13; 提多書 3:10"> 我真希望那些攪亂你們的人把自己閹割了！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:16; 哥林多前書 9:19; 哥林多前書 8:9"> 弟兄們，你們蒙召是為了得自由，只是不可用這自由給肉體一個機會，而是要藉著愛彼此服事，</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 7:12; 利未記 19:18; 加拉太書 6:2"> 因為全部律法都在「要愛鄰如己」這一句話裡得以滿足了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 3:3; 雅各書 3:14–3; 加拉太書 5:26"> 你們要當心！如果你們繼續相咬相吞，恐怕就要彼此毀滅了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太書 5:24–25; 羅馬書 8:12–14; 加拉太書 6:8"> 所以我說：你們應當順著聖靈行走，這樣就絕不會去滿足肉體的欲望了；</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:13; 約翰福音 3:6; 羅馬書 8:5–8"> 因為肉體的欲望與聖靈對立，聖靈也與肉體對立。這兩者彼此反對，使你們不能做自己所願意做的。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:14; 羅馬書 6:14–15; 加拉太書 5:25"> 但如果你們被聖靈帶領，就不在律法之下了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 6:9–10; 歌羅西書 3:5–8; 馬太福音 15:18–19"> 肉體的行為是清清楚楚的，它們就是：通姦<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「通姦」。">c</a></sup>、淫亂、汙穢、好色、</span>
<span className="v" id="v20" data-v="20" data-xref="提多書 3:10; 哥林多前書 11:19; 啟示錄 21:8"> 拜偶像、行邪術<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="邪術——或譯作「巫術」或「毒品」。">d</a></sup>、仇恨、紛爭、嫉恨、暴怒、爭競<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="爭競——或譯作「結黨」。">e</a></sup>、分裂、結派、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 6:9–10; 羅馬書 8:13; 羅馬書 13:13"> 嫉妒、凶殺<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「凶殺」。">f</a></sup>、醉酒、荒宴以及類似這樣的事。對這些事，我現在要預先告訴你們，就像我以前告訴過你們的那樣：行這些事的人不會繼承神的國。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:12–17; 哥林多前書 13:4–7; 約翰福音 15:5"> 然而，聖靈的果子是：愛心、喜樂、和平、忍耐、仁慈、良善、忠信、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 1:9; 使徒行傳 24:25; 提多書 2:2"> 溫柔、自制。這樣的事，沒有律法反對。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 6:6; 羅馬書 13:14; 羅馬書 8:13"> 那些屬於基督耶穌的人，已經把肉體與肉體的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="肉體的——輔助詞語。">g</a></sup>渴望和情慾一同釘上十字架了。</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:16; 羅馬書 8:4–5; 羅馬書 8:2"> 我們既然藉著聖靈而活，就讓我們靠著聖靈行走。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 3:14–16; 腓立比書 2:1–3; 雅各書 4:16"> 我們不可貪圖虛榮，彼此惹氣，互相嫉妒。</span>
</div>

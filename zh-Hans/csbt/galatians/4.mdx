<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 4:23; 加拉太書 4:29; 創世記 24:2–3"> 我說：繼承人雖然是一切的主人，但是當他還是小孩子的時候，與奴僕沒有區別；</span>
<span className="v" id="v2" data-v="2"> 他是在監護人和管家之下，直到父親所預定的時候來到。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:20; 歌羅西書 2:8; 加拉太書 4:9"> 我們也是這樣：我們還是小孩子的時候，在世界的原則下受奴役。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 7:14; 約翰福音 1:14; 羅馬書 1:3"> 但是等到時候一滿足，神就派遣他的兒子，由女人所生，生在律法之下，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 9:15; 以弗所書 1:5; 彼得前書 1:18–20"> 為要救贖律法之下的人，好使我們得到兒子的名份。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 8:15–17; 羅馬書 5:5; 羅馬書 8:9"> 而且因你們是兒子，神就派遣他兒子的靈進入你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——有古抄本作「我們」。">a</a></sup>的心，呼叫：「阿爸！父啊！」</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:16–17; 加拉太書 3:29–2; 加拉太書 3:26"> 這樣，你不再是奴僕，卻是兒子了；既然是兒子，就藉著神，也是繼承人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="藉著神，也是繼承人——有古抄本作「藉著基督，也是神的繼承人」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 8:4; 以弗所書 2:11–12; 帖撒羅尼迦後書 1:8"> 從前，你們不認識神的時候，固然給那些本性上不是神的做了奴僕，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 8:3; 加拉太書 3:3; 羅馬書 8:3"> 但如今，你們認識了神——不過更要說，被神所認識——怎麼能再回到那無能、無用的原則裡去呢？你們願意再重新做它們的奴僕嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 2:16–17; 羅馬書 14:5; 利未記 23:1–44"> 你們竟嚴守著某些日子、月份、節期、年份！</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 3:5; 腓立比書 2:16; 加拉太書 2:2"> 我替你們擔心，恐怕我為你們的勞苦毫無意義了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:5; 列王紀上 22:4; 創世記 34:15"> 弟兄們，我請求你們要像我一樣，因為我也像你們一樣。你們一點也沒有虧負過我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 2:3; 哥林多後書 12:7–10; 哥林多後書 11:30"> 你們知道，我原先傳福音給你們，是身體有病的時候。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:40; 帖撒羅尼迦前書 2:13; 希伯來書 13:2"> 雖然我的身體對你們<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你們——有古抄本作「我」。">c</a></sup>是個試煉，但你們並沒有藐視我，也沒有唾棄我，反而接受我如同接受神的使者、如同接受基督耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="羅馬書 5:2; 約翰一書 3:16–18; 歌羅西書 4:13"> 你們當時的福份到哪裡去了<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="到哪裡去了——有古抄本作「成了什麼」。">d</a></sup>呢？我可以給你們做見證：那時如果有可能，你們連自己的眼睛都會挖出來給我！</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 5:10; 箴言 9:8; 約翰福音 8:45"> 我對你們說真話<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="對你們說真話 ——或譯作「對你們真誠」。">e</a></sup>，結果就成了你們的敵人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="敵人——或譯作「反對者」。">f</a></sup>嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:18; 哥林多後書 11:13–15; 彼得後書 2:3"> 那些人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="那些人——指「假教師」。">g</a></sup>對你們熱心，並不是出於好意，而是想要離間你們，好讓你們對他們熱心。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比書 2:12; 啟示錄 3:19; 腓立比書 1:27"> 不過在善事上常有熱心，卻是好的，但不要僅僅是我與你們在一起的時候才這樣。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 4:13; 羅馬書 8:29; 羅馬書 13:14"> 我的孩子們哪，為了你們，我再次經受臨產的陣痛，直到基督在你們裡面成形！</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒羅尼迦前書 2:17–18; 哥林多前書 4:19–21; 帖撒羅尼迦前書 3:9"> 我現在想要與你們在一起，也要改變我的語氣，因為我為你們的緣故心裡困惑。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 3:10; 加拉太書 3:23–24; 羅馬書 7:5–6"> 你們這些願意在律法之下的人哪，請告訴我，難道你們沒有聽過律法嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 16:15; 創世記 21:10; 創世記 21:1–2"> 因為經上記著：亞伯拉罕有兩個兒子，一個出於女僕<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="女僕——指「夏甲」。參《創世記》16:15。">h</a></sup>，一個出於自由女人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="自由女人——指「撒拉」。參《創世記》21:2。">i</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 11:11; 羅馬書 9:7–8; 加拉太書 4:28–29"> 那出於女僕的是由肉體生的，那出於自由女人的是藉著應許生的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 21:9–13; 希伯來書 10:15–18; 創世記 16:8"> 這些都是有寓意的。就是說，這兩個女人是兩個約。一個出於西奈山，生子為奴，她就是夏甲。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行傳 1:11; 加拉太書 1:17"> 這夏甲是指著阿拉伯的西奈山，相當於現在的耶路撒冷，因為耶路撒冷<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶路撒冷——原文直譯「她」。">j</a></sup>和她的兒女都是為奴的。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 12:22; 腓立比書 3:20; 彌迦書 4:1–2"> 但那在上面的耶路撒冷是自由女人；她是我們<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="我們——有古抄本作「我們所有人」。">k</a></sup>的母親。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 54:1–5; 詩篇 113:9; 路得記 4:14–16"> 因為經上記著：<br /><span className="pl pl-1">「不能生育、沒有生產的女子啊，</span><br /><span className="pl pl-1">你要歡喜！</span><br /><span className="pl pl-1">沒有經歷臨產陣痛的女子啊，</span><br /><span className="pl pl-1">你要放聲呼喊！</span><br /><span className="pl pl-1">因為沒有丈夫的女子，</span><br /><span className="pl pl-1">比有丈夫的女子有更多的兒女。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="加拉太書 4:23; 羅馬書 9:8–9; 羅馬書 4:13–18"> 不過弟兄們，你們<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="你們——有古抄本作「我們」。">l</a></sup>就像以撒一樣，是應許的兒女。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 21:9; 羅馬書 8:13; 加拉太書 5:11"> 但正如那由肉體生的<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="那由肉體生的——指「夏甲的兒子以實瑪利」。">m</a></sup>當時逼迫了那由聖靈生的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="那由聖靈生的——指「撒拉的兒子以撒」。">n</a></sup>，現在也是這樣。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 21:10–12; 約翰福音 8:35; 羅馬書 8:15–17"> 然而經上是怎麼說的呢？<br />「把女僕和她的兒子趕出去！因為女僕的兒子，絕不可以與自由女人的兒子一同做繼承人。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 8:36; 約翰福音 1:12–13; 加拉太書 5:1"> 因此，弟兄們，我們不是女僕的兒女，而是自由女人的兒女。</span>
</div>
</div>

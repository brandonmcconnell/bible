<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 22:20–25; 申命記 21:3; 撒母耳記上 6:7"> 「以下是耶和華所吩咐的律法條例：你要告訴以色列子民，把一頭沒有殘疾、沒有負過軛的無瑕疵紅母牛帶到你這裡。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 4:12; 利未記 4:21; 利未記 16:27"> 你們要把這牛交給祭司以利亞撒，然後領到營地外，在他面前宰殺了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 4:17; 利未記 4:6; 利未記 16:14"> 祭司以利亞撒要用手指蘸一些母牛的血，向著會幕前面彈灑七次。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 29:14; 利未記 4:11–12; 詩篇 22:14"> 然後這母牛要在他眼前被焚燒，皮、肉、血，連同糞便都要燒掉。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 14:4; 利未記 14:49; 詩篇 51:7"> 祭司要拿來香柏木、牛膝草和朱紅色線，扔進焚燒母牛的火中。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 11:25; 利未記 11:40; 民數記 19:8"> 祭司要洗衣服，用水洗身，之後才可以進入營地；祭司會不潔淨直到傍晚。</span>
<span className="v" id="v8" data-v="8"> 那焚燒母牛的人，也要用水洗衣服，用水洗身；他會不潔淨直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯來書 9:13; 民數記 19:13; 民數記 19:20–21"> 「要有一個潔淨的人收取那母牛的灰燼，放置在營地外潔淨的地方，為以色列會眾保存下來，用於調制除汙穢的水；這是除罪用的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 12:49; 民數記 19:7–8; 歌羅西書 3:11"> 那收取母牛灰燼的人要洗衣服，他會不潔淨直到傍晚。這要作為以色列子孫和寄居在他們中間的外人永遠的律例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 5:2; 民數記 31:19; 利未記 21:1"> 「凡是觸碰死屍的人，無論那是誰的屍體，他都會不潔淨七天。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 31:19; 啟示錄 7:14; 利未記 7:17"> 他要在第三天和第七天用那除汙穢的水潔淨自己，他就得潔淨了；如果他在第三天和第七天不潔淨自己，他就不得潔淨。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 15:31; 利未記 22:3; 利未記 7:20"> 凡是觸碰死人屍體的，如果不潔淨自己，他就玷汙了耶和華的帳幕，這人必須從以色列中被剪除。因為那除汙穢的水沒有灑在他身上，他仍是不潔淨的，他的汙穢還在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 「以下是有人死在帳篷裡時的條例：所有進入那帳篷的人或已經在那帳篷裡的人，都會不潔淨七天。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 14:36; 利未記 11:32; 民數記 31:20"> 帳篷裡所有敞口的器皿，就是沒有扣上蓋子的，都會不潔淨。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 31:19; 馬太福音 23:27; 路加福音 11:44"> 另外，任何人在田野上觸碰被刀劍所殺的，或自然<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自然——輔助詞語。">a</a></sup>死去的，或人的骨頭，或墳墓，他也會不潔淨七天。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 7:38; 創世記 26:19; 啟示錄 7:17"> 他們要為不潔淨的人取來那贖罪祭牲燒成的灰，放在器皿裡，加上活水。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 36:25–27; 希伯來書 9:14; 民數記 19:9"> 要有一個潔淨的人拿牛膝草蘸那水，灑在帳篷上、所有器具上以及帳篷裡的人身上，也灑在那觸碰了人骨頭的，或觸碰被殺的、自然<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="自然——輔助詞語。">b</a></sup>死的，或觸碰墳墓的人身上。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰一書 1:7; 希伯來書 10:22; 以西結書 36:25"> 「潔淨的人要在第三天和第七天把那水灑在不潔淨的人身上，這樣就使他在第七天得潔淨；他要洗衣服，用水洗身，到傍晚就潔淨了。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 16:16; 創世記 17:14; 民數記 19:13"> 凡是不潔淨的人，如果沒有潔淨自己，這人就要從會眾當中被剪除，因為他玷汙了耶和華的聖所；那除汙穢的水沒有灑在他身上，他就是不潔淨的。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 9:13–14; 希伯來書 10:4; 希伯來書 9:10"> 這要作為他們永遠的律例。灑這除汙穢之水的人，要洗自己的衣服；凡是觸碰除汙穢之水的人，都會不潔淨直到傍晚。</span>
<span className="v" id="v22" data-v="22" data-xref="哈該書 2:13; 利未記 7:19; 馬太福音 15:19–20"> 那不潔淨的人碰過的任何東西都不潔淨，觸碰那些東西的人也會不潔淨直到傍晚。」</span>
</div>

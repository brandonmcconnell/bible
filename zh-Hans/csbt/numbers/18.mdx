<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 28:38; 希伯來書 13:17; 彼得前書 2:24"> 於是，耶和華對亞倫說：「你和你的兒子們以及你的父家，要一同承擔與聖所相關的罪責；你和你的兒子們，要一同承擔與你們祭司職份相關的罪責。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:34; 民數記 18:4; 以西結書 44:15"> 你還要帶你利未支派的弟兄，就是你父系支派的人，與你一同上前事奉。他們要從屬你，輔助你。當你和你的兒子們一同在見證會幕前面時，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 4:15; 民數記 16:40; 民數記 4:19–20"> 他們要為你和整個會幕謹守職責，只是他們不可靠近聖所的器具和祭壇，以免他們和你們都死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 6:19; 民數記 1:51; 民數記 3:10"> 他們要從屬你，為帳幕的一切服事謹守會幕的職責；外人不可靠近你們。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 27:21; 利未記 24:3; 民數記 16:46"> 「你們要謹守聖所的職責和祭壇的職責，以免震怒再臨到以色列子孫。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 3:9; 民數記 3:12; 民數記 3:45"> 看哪，我已經從以色列子孫中揀選了你的弟兄利未人，賞賜給你們，獻於耶和華做會幕的服事工作。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 15:15–16; 約翰福音 3:27; 民數記 3:10"> 你和你的兒子們要為祭壇和幔子內的一切事務，謹守祭司的職份，做好服事。我把祭司職份作為服事工作賞賜給你們，凡是接近的外人，都要被處死。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 6:16; 利未記 7:6; 出埃及記 29:29"> 耶和華又對亞倫說：「看哪，我已經把奉獻供物的職責交給了你。至於以色列子孫所有的聖物，我把它們賜給你作受膏的份，也給你的兒子們作永遠的份例。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 7:7; 利未記 14:13; 利未記 6:25–26"> 人們帶來獻給我的至聖物，就是所有的祭物，包括所有的素祭、所有的贖罪祭、所有的贖愆祭，其中沒有燒獻的要歸屬你；這些是至聖的，歸於你和你的子孫。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 7:6; 利未記 6:29; 利未記 6:16"> 你要把它作為至聖物吃，只有男的才可以吃；你要把它當作神聖的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 18:3; 出埃及記 29:27–28; 利未記 10:14"> 「以色列子孫奉獻的供物，就是他們所有的搖獻祭物，也歸於你；我把它們賜給你和與你一起的兒女們，作永遠的份例，你家裡所有潔淨的人都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 18:4; 出埃及記 23:19; 出埃及記 34:26"> 所有最好的新油、最好的新酒，以及人們獻給耶和華的初熟五穀，我也賜給你。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 22:29; 出埃及記 23:19; 彌迦書 7:1"> 他們地裡的一切初熟之物，就是他們帶來獻給耶和華的，都歸屬你。你家裡所有潔淨的人都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 27:28; 以西結書 44:29"> 「以色列中一切永獻之物都歸屬你。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:20; 出埃及記 13:2; 出埃及記 13:12–13"> 他們向耶和華獻上的所有頭胎的活物，無論是人還是牲畜，都歸屬你。只是你必須讓他們把頭生的人贖回，還有頭生的不潔淨牲畜，也要贖回。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 30:13; 民數記 3:47; 利未記 27:2–7"> 出生一個月以後要贖回的，要照你所估的價，用五謝克爾銀子贖回；按聖所的謝克爾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="謝克爾——重量單位；後來成為貨幣單位。1謝克爾=11.4公克。">a</a></sup>標準，一謝克爾是二十季拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十季拉——相當於11.4公克。1季拉=0.57公克。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 29:16; 申命記 15:19–22; 利未記 3:2–5"> 「但是頭生的公牛，或頭生的綿羊，或頭生的山羊，不可贖回；牠們是聖物。你要把牠們的血灑在祭壇上，把牠們的脂肪燒獻為火祭，作馨香之氣獻給耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 7:31–34; 出埃及記 29:26–28"> 牠們的肉要歸屬你，就像搖獻祭物的胸肉和右腿一樣歸屬你。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 13:5; 利未記 2:13; 民數記 18:11"> 「以色列子孫向耶和華奉上的一切神聖供物，我都賜給你和與你一起的兒女們，作永遠的份例。這是你和與你一起的後裔在耶和華面前永遠的鹽約。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 44:28; 申命記 10:9; 約書亞記 13:33"> 耶和華對亞倫說：「你不可在以色列子孫的土地中分得繼業，你在他們中間沒有繼業的份。在以色列子孫中，我就是你的份，你的產業。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="尼希米記 12:44; 申命記 14:22–29; 尼希米記 10:37"> 「至於利未的子孫，看哪，我把以色列中所有出產的十分之一賜給了他們為產業，回報他們所做的會幕服事工作。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 22:9; 民數記 1:51–52; 民數記 3:38"> 以色列子孫不可再靠近會幕，以免他們承擔罪過而死。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 3:7; 民數記 18:20; 民數記 18:1"> 利未人要做會幕的服事工作，他們要承擔與聖所相關的罪責。這是你們世世代代永遠的律例：他們不可在以色列子孫中分得繼業。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 18:26; 瑪拉基書 3:8–10"> 因為我已經把以色列子孫的十分之一出產，就是他們向耶和華奉上的供物，賜給了利未人作產業。因此我對他們說，他們不可在以色列子孫中分得繼業。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和華指示摩西說：</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米記 10:38; 民數記 18:21"> 「你要吩咐利未人，對他們說：當你們從以色列子孫獲得了我所賜給你們的那十分之一出產為產業，你們要再從那十分之一中奉上十分之一，作為獻給耶和華的供物。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 18:30; 申命記 15:14; 列王紀下 6:27"> 這算為你們奉獻的供物，就像你們打穀場上的五穀，酒榨中滿盈的酒一樣。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 6:20–10; 創世記 14:18"> 這樣，你們從以色列子孫獲得的全部十分之一出產，也要從中奉上耶和華的供物，把這份獻給耶和華的供物交給祭司亞倫。</span>
<span className="v" id="v29" data-v="29"> 你們要從你們的一切禮物中，從一切最好的、至聖的部分中，奉上耶和華的各樣供物。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 3:9–10; 創世記 43:11; 馬太福音 6:33"> 「你要對利未人說：『當你們從其中把最好的奉獻之後，其餘的就算為利未人的，就像打穀場的收成和酒榨的收成。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前書 9:10–14; 提摩太前書 5:17–18; 路加福音 10:7"> 你們和你們的家人可以在任何地方吃它，因為這是你們的酬報，以回報你們在會幕裡的服事。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 19:8; 利未記 22:2; 瑪拉基書 1:7"> 當你們把其中最好的奉獻之後，你們就不會因它而承擔罪過了；你們不可褻瀆以色列子孫的聖物，免得你們死亡。」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 23:29; 猶大書 1:11; 出埃及記 27:1–8"> 巴蘭對巴勒說：「請在這裡為我築七座祭壇，並在這裡為我預備七頭公牛、七隻公綿羊。」</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 23:14; 民數記 23:30"> 巴勒就照著巴蘭所說的做了。巴勒和巴蘭在每座祭壇上獻一頭公牛、一隻公綿羊。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 23:15; 創世記 8:20; 創世記 22:2"> 巴蘭對巴勒說：「你站在你的燔祭旁邊，我要往前去，或許耶和華會臨到，接見我。他指示我什麼信息，我都會告訴你。」然後，巴蘭走到一片光禿的高地。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民數記 23:16; 以弗所書 2:9; 路加福音 18:12"> 神臨到巴蘭，巴蘭對神說：「我預備了七座祭壇，在每座祭壇上獻了一頭公牛、一隻公綿羊。」</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 18:18; 耶利米書 1:9; 以賽亞書 59:21"> 耶和華就把話放在巴蘭的口中，說：「你回巴勒那裡去，要如此如此說。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 他回到巴勒那裡，看哪，巴勒和摩押全體首領都站在燔祭旁邊。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="申命記 23:4; 民數記 24:3; 民數記 22:5–6"> 巴蘭發佈諭示，說：<br /><span className="pl pl-1">「巴勒請我從亞蘭來，</span><br /><span className="pl pl-1">摩押王請我出東山，他說：</span><br /><span className="pl pl-1">『來吧，為我詛咒雅各；</span><br /><span className="pl pl-1">來吧，向以色列宣判！』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:23; 以賽亞書 44:25; 民數記 23:20"> <span className="pl pl-1">神沒有詛咒的，我怎麼能詛咒？</span><br /><span className="pl pl-1">耶和華沒有宣判，我怎麼能宣判？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 33:28; 申命記 32:8; 出埃及記 33:16"> <span className="pl pl-1">我從岩壁的頂峰觀望他，</span><br /><span className="pl pl-1">從山崗上注視他</span><br /><span className="pl pl-1">——看，這獨居的民族，</span><br /><span className="pl pl-1">不把自己算在列國之中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 37:37; 創世記 13:16; 詩篇 116:15"> <span className="pl pl-1">誰能數點雅各的塵沙，</span><br /><span className="pl pl-1">誰能數算以色列的煙塵</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="煙塵——或譯作「四分之一」。">a</a></sup><br /><span className="pl pl-1">？</span><br /><span className="pl pl-1">願我死如正直人的死，</span><br /><span className="pl pl-1">願我的結局像他一樣。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米記 13:2; 民數記 24:10; 民數記 22:17"> 巴勒對巴蘭說：「你對我做了什麼事！我帶你來詛咒我的仇敵，看哪，你卻大大祝福他們。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 22:38; 民數記 23:20; 民數記 23:26"> 巴蘭回答說：「耶和華放在我口中的話，我怎麼能不忠實傳講呢？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 109:17; 雅各書 3:9–10; 民數記 22:41"> 巴勒對巴蘭說：「來吧，請與我一起到另外一個地方，你可以從那裡看到那民族；只會看到他們營地的邊緣，不能看見全部。請在那裡為我詛咒他們。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 46:6; 民數記 23:29; 以賽亞書 1:10–11"> 於是巴勒帶巴蘭到瑣腓野外，毗斯迦山頂上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="瑣腓野外，毗斯迦山頂上——或譯作「毗斯迦山頂的守望臺」。">b</a></sup>。巴勒築了七座祭壇，在每座祭壇上獻一頭公牛、一隻公綿羊。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 23:3; 民數記 22:8"> 巴蘭對巴勒說：「你站在你的燔祭旁邊，我要到那邊受接見。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 23:5; 民數記 24:1; 民數記 22:35"> 耶和華接見巴蘭，把話語放在他口中，說：「你回巴勒那裡去，要如此如此說。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 23:26; 撒母耳記上 3:17; 耶利米書 37:17"> 巴蘭回到巴勒那裡，看哪，巴勒站在燔祭旁邊，摩押的首領們也與他在一起。巴勒問他：「耶和華說了什麼？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="士師記 3:20"> 巴蘭發佈諭示，說：<br /><span className="pl pl-1">「巴勒啊，你起來聽著；</span><br /><span className="pl pl-1">西撥的兒子啊，聽我說！</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 15:29; 雅各書 1:17; 瑪拉基書 3:6"> <span className="pl pl-1">神不是會說謊的人，</span><br /><span className="pl pl-1">也不是會後悔的人類。</span><br /><span className="pl pl-1">難道他說了會不做嗎？</span><br /><span className="pl pl-1">他發話了，會不成就嗎？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:27–29; 民數記 22:12; 創世記 12:2"> <span className="pl pl-1">看哪，我奉命祝福；</span><br /><span className="pl pl-1">神已經祝福了，</span><br /><span className="pl pl-1">我不能翻轉。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 23:4; 馬太福音 1:23; 耶利米書 50:20"> <span className="pl pl-1">神使雅各中看不到禍患，</span><br /><span className="pl pl-1">使以色列中看不見苦難。</span><br /><span className="pl pl-1">他的神耶和華與他同在，</span><br /><span className="pl pl-1">歡呼君王的聲音在他們中間。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="民數記 24:8; 申命記 33:17; 約伯記 39:9–11"> <span className="pl pl-1">神把他們從埃及領出來，</span><br /><span className="pl pl-1">像野牛的角為他們爭戰</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="爭戰——輔助詞語。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 10:18–19; 約書亞記 13:22; 加拉太書 1:23–24"> <span className="pl pl-1">實在沒有法術對付雅各，</span><br /><span className="pl pl-1">也沒有占卜對付以色列，</span><br /><span className="pl pl-1">每當論到雅各，</span><br /><span className="pl pl-1">論到以色列，人都會說：</span><br /><span className="pl pl-1">『神成就了何等的事啊！』</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:27; 創世記 49:9; 民數記 24:17"> <span className="pl pl-1">看，這民族起來如母獅，</span><br /><span className="pl pl-1">挺身像公獅。</span><br /><span className="pl pl-1">它不吞吃獵物，不喝被殺之人的血，</span><br /><span className="pl pl-1">就絕不躺下。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–3"> 巴勒對巴蘭說：「既然你一點也不詛咒他們，那就一點也不要祝福他們。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:29; 民數記 22:18; 使徒行傳 4:19–20"> 巴蘭回答巴勒說：「我不是告訴過你，耶和華所說的一切我必須遵行嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="羅馬書 11:29; 箴言 21:30; 民數記 23:19–20"> 於是巴勒對巴蘭說：「來，請讓我帶你到另外一個地方。或許在神的眼中，你從那裡為我詛咒他們是合宜的。」</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 21:20; 詩篇 106:28"> 巴勒就帶巴蘭到毗珥山頂，在那裡可以俯看荒漠。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 23:1–2"> 巴蘭對巴勒說：「請在這裡為我築七座祭壇，並在這裡為我預備七頭公牛、七隻公綿羊。」</span>
<span className="v" id="v30" data-v="30"> 巴勒就照著巴蘭所說的做了，在每座祭壇上獻一頭公牛、一隻公綿羊。</span>
</div>
</div>

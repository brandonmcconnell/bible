<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 23:24–25; 歷代志上 15:28; 以賽亞書 27:13"> 「七月的第一日，你們要有神聖的聚會，任何日常工作都不可做，這是你們長鳴號角的日子。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 28:27; 民數記 28:19; 民數記 29:36"> 你們要獻一頭公牛、一隻公綿羊、七隻無瑕疵的一歲公羊羔為燔祭，作馨香之氣獻給耶和華。</span>
<span className="v" id="v3" data-v="3"> 還有同獻的素祭，就是調了油的細麵粉：為每頭公牛，要獻十分之三伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之三伊法——相當於6.6公升；本章下同。1伊法=22公升。">a</a></sup>麵粉；為每隻公綿羊，要獻十分之二伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十分之二伊法——相當於4.4公升；本章下同。1伊法=22公升。">b</a></sup>麵粉；</span>
<span className="v" id="v4" data-v="4"> 至於那七隻公羊羔，要為每隻羊羔獻十分之一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之一伊法——相當於2.2公升；本章下同。1伊法＝22公升。">c</a></sup>麵粉。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:30; 民數記 28:15; 民數記 28:22"> 還要獻一隻公山羊作贖罪祭，為你們贖罪。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 28:3–8; 民數記 28:11–15; 民數記 29:18"> 你們要在新月燔祭和同獻的素祭、常獻的燔祭和同獻的素祭，以及照著法規同獻的酒祭以外，把這些作為馨香的火祭獻給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 5:4; 利未記 16:29–31; 撒迦利亞書 12:10"> 「七月十日，你們要有神聖的聚會，要刻苦己心，任何工作都不可做。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 28:19; 民數記 29:13; 民數記 29:2"> 你們要獻上一頭公牛、一隻公綿羊、七隻一歲的公羊羔，都必須是無瑕疵的，作為馨香的燔祭獻給耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 15:3–12"> 還有同獻的素祭，就是調了油的細麵粉：為每頭公牛，要獻十分之三伊法麵粉；為每隻公綿羊，要獻十分之二伊法麵粉；</span>
<span className="v" id="v10" data-v="10"> 至於那七隻公羊羔，要為每隻羊羔獻十分之一伊法麵粉。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 16:3; 利未記 16:5; 民數記 28:3–8"> 還要獻一隻公山羊作贖罪祭。這是在贖罪祭、常獻的燔祭和同獻的素祭，以及同獻的酒祭以外的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 16:13–14; 撒迦利亞書 14:16–19; 出埃及記 34:22"> 「七月十五日，你們要有神聖的聚會，任何日常工作都不可做，你們要向耶和華守節期七天。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 28:11; 以斯拉記 3:4; 民數記 29:2"> 你們要獻上十三頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都必須是無瑕疵的，作為燔祭，作為馨香的火祭獻給耶和華。</span>
<span className="v" id="v14" data-v="14"> 還有同獻的素祭，就是調了油的細麵粉：十三頭公牛，為每頭公牛要獻十分之三伊法麵粉；兩隻公綿羊，為每一隻公綿羊要獻十分之二伊法麵粉；</span>
<span className="v" id="v15" data-v="15"> 十四隻公羊羔，為每一隻羊羔要獻十分之一伊法麵粉。</span>
<span className="v" id="v16" data-v="16"> 還要獻一隻公山羊作贖罪祭。這是在常獻的燔祭和同獻的素祭，以及同獻的酒祭以外的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 8:13; 詩篇 50:8–9; 詩篇 69:31"> 「第二天，要獻十二頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都是無瑕疵的。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 28:7; 民數記 15:4–12; 民數記 28:14"> 還有為公牛、公綿羊和羊羔同獻的素祭和酒祭，都要按數目、照法規獻上。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 29:11; 民數記 29:25; 民數記 29:22"> 還要獻一隻公山羊作贖罪祭。這是在常獻的燔祭和同獻的素祭，以及同獻的酒祭以外的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 「第三天，要獻十一頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都是無瑕疵的。</span>
<span className="v" id="v21" data-v="21"> 還有為公牛、公綿羊和公羊羔同獻的素祭和酒祭，都要按數目、照法規獻上。</span>
<span className="v" id="v22" data-v="22" data-xref="約珥書 1:13; 詩篇 16:4; 約珥書 2:14"> 還要獻一隻公山羊作贖罪祭。這是在常獻的燔祭和同獻的素祭，以及同獻的酒祭以外的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 「第四天，要獻十頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都是無瑕疵的。</span>
<span className="v" id="v24" data-v="24"> 還有為公牛、公綿羊和公羊羔同獻的素祭和酒祭，都要按數目、照法規獻上。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 13:43; 加拉太書 2:5; 加拉太書 6:9"> 還要獻一隻公山羊作贖罪祭。這是在常獻的燔祭和同獻的素祭，以及同獻的酒祭以外的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 「第五天，要獻九頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都是無瑕疵的。</span>
<span className="v" id="v27" data-v="27"> 還有為公牛、公綿羊和公羊羔同獻的素祭和酒祭，都要按數目、照法規獻上。</span>
<span className="v" id="v28" data-v="28"> 還要獻一隻公山羊作贖罪祭。這是在常獻的燔祭和同獻的素祭，以及同獻的酒祭以外的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 「第六天，要獻八頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都是無瑕疵的。</span>
<span className="v" id="v30" data-v="30"> 還有為公牛、公綿羊和公羊羔同獻的素祭和酒祭，都要按數目、照法規獻上。</span>

</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 「第七天，要獻七頭公牛、兩隻公綿羊、十四隻一歲的公羊羔，都是無瑕疵的。</span>
<span className="v" id="v33" data-v="33"> 還有為公牛、公綿羊和公羊羔同獻的素祭和酒祭，都要按數目、照法規獻上。</span>

</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="利未記 23:36; 約翰福音 7:37–39; 啟示錄 7:9–17"> 「第八天，你們要有嚴肅集會，任何日常工作都不可做。</span>
<span className="v" id="v36" data-v="36"> 你們要獻上一頭公牛、一隻公綿羊、七隻一歲的公羊羔，都是無瑕疵的，作為燔祭，作為馨香的火祭獻給耶和華。</span>

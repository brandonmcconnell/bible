<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="NUM" data-book-slug="numbers" data-book-name="民數記" data-chapter="22" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:1; 申命記 3:8; 民數記 21:20"> 以色列子民起行，在耶利哥東邊約旦河對面的摩押平原紮營。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:25; 民數記 21:20–35; 民數記 21:3"> 以色列對亞摩利人所做的一切，西撥的兒子巴勒都看到了。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:15; 以賽亞書 23:5; 約書亞記 9:24"> 摩押就非常懼怕這民，因為他們人數眾多。摩押因以色列人的緣故而憂心，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 25:15–18; 民數記 31:8; 民數記 24:17"> 對米甸的長老們說：「恐怕這部族要吃光我們周圍的一切，就像牛吃光田野的青草一樣。」<br />那時，西撥的兒子巴勒是摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 23:4; 約書亞記 24:9; 彌迦書 6:5"> 他就派遣使者到他本族人之地大河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼發拉底河。">a</a></sup>邊的佩托爾，去見比珥的兒子巴蘭，要召他來，說：「你看，有一個民族從埃及出來，他們遮滿了地面，在我對面駐紮。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 24:9; 民數記 23:7–8; 使徒行傳 16:16"> 現在請你來，為我詛咒這民族，因為他們比我強大。這樣，或許我能夠擊敗他們，把他們從這地驅逐出去。因為我知道，你祝福的人必受祝福，你詛咒的人必受詛咒。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 9:7–8; 彌迦書 3:11; 羅馬書 16:18"> 摩押的長老們和米甸的長老們，手裡帶著占卜的酬金就去了。他們來見巴蘭，將巴勒的話告訴了他。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:12; 民數記 22:19–20; 耶利米書 12:2"> 巴蘭對他們說：「你們今晚在這裡過夜吧。我將照著耶和華吩咐我的，回覆你們。」於是摩押的首領們就住在巴蘭那裡。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 20:3; 民數記 22:20; 創世記 16:8"> 神臨到巴蘭，說：「那些在你這裡的人是誰？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 巴蘭對神說：「西撥的兒子摩押王巴勒派了人到我這裡來，說：</span>
<span className="v" id="v11" data-v="11"> 『你看，有一個民族從埃及出來，遮滿了地面。現在請你來，為我詛咒他們，或許我能擊敗他們，驅逐他們。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; 以弗所書 1:3; 創世記 12:2"> 神對巴蘭說：「你不可跟著他們去，不可詛咒那民族，因為他們是蒙祝福的。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 23:5; 民數記 22:14"> 巴蘭清晨起來，對巴勒的首領們說：「你們回本地去吧，因為耶和華不允許我跟著你們去。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 22:37; 民數記 22:13"> 摩押的首領們就起身，回到巴勒那裡，說：「巴蘭不願跟著我們來。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 10:7–8; 民數記 22:7–8"> 於是，巴勒再次派遣一批首領，比先前的更多更尊貴。</span>
<span className="v" id="v16" data-v="16"> 他們來到巴蘭那裡，對他說：「西撥的兒子巴勒如此說：請不要推辭來我這裡，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 24:11; 以斯帖記 5:11; 馬太福音 4:8–9"> 我一定使你大得尊榮。無論你告訴我什麼，我都會照辦。來吧，請為我詛咒這民族。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 24:13; 列王紀上 22:14; 歷代志下 18:13"> 巴蘭回答巴勒的臣僕，說：「即使巴勒把他滿屋的金銀都給我，我也不能違背我的神耶和華的吩咐，無論做小事還是大事。</span>
<span className="v" id="v19" data-v="19" data-xref="猶大書 1:11; 彼得後書 2:3; 提摩太前書 6:9–10"> 所以，請你們今晚也住在這裡吧，我要知道耶和華還會對我說什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 23:12; 民數記 24:13; 民數記 23:26"> 夜間，神臨到巴蘭對他說：「既然這些人來邀請你，你就起來跟著他們去吧，只是你要做我吩咐你的事。」</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 於是巴蘭清晨起來，備好驢，跟著摩押的首領們去了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 4:24; 耶利米哀歌 2:4; 民數記 22:32"> 因巴蘭前往，神就怒氣發作。耶和華的一位使者站在路上敵對他。當時，巴蘭騎在驢上，他的兩個僕人跟隨著他。</span>
<span className="v" id="v23" data-v="23" data-xref="猶大書 1:11; 彼得後書 2:16; 哥林多前書 1:27–29"> 驢看見耶和華的使者站在路上，手裡有拔出的刀，驢就轉離那條路，走到田野中。巴蘭打驢，要使牠轉回那條路。</span>
<span className="v" id="v24" data-v="24"> 於是，耶和華的使者站在葡萄園之間的窄路上，這邊有圍牆，那邊也有圍牆。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 47:12; 約伯記 5:13–15"> 驢看見耶和華的使者，就擠到牆邊，把巴蘭的腳也擠到牆邊上，巴蘭就又打牠。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 2:6; 以賽亞書 26:11"> 耶和華的使者再上前去，站到左右都無路可轉的狹窄地方。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各書 1:19; 箴言 27:3–4"> 驢看見耶和華的使者，就趴在巴蘭身下。巴蘭怒氣發作，用杖打驢。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得後書 2:16; 路加福音 1:37; 出埃及記 4:11"> 於是耶和華開了驢的口，驢對巴蘭說：「我對你做了什麼，你竟打我這三次？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 馬太福音 15:19; 箴言 12:16"> 巴蘭對驢說：「因為你捉弄我！要是我手裡有刀，我現在就宰了你。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="彼得後書 2:16; 哥林多前書 1:27–28"> 驢對巴蘭說：「我不就是你至今一直在騎的那頭驢嗎？我往常對你這樣做過嗎？」<br />巴蘭說：「沒有。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 21:19; 路加福音 24:31; 使徒行傳 26:18"> 耶和華打開巴蘭的眼睛，他看見耶和華的使者站在路上，手裡拿著拔出的刀，他就俯身，臉伏於地。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行傳 13:10; 民數記 22:22"> 耶和華的使者對他說：「你為什麼這三次打你的驢呢？看哪，我出來敵對你，因為這條路在我面前是邪僻的。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 16:33–35; 民數記 14:37; 列王紀上 13:24–28"> 驢看見我，所以從我面前轉開了這三次。如果牠不從我面前轉開，我早已經把你殺了，只讓牠存活。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約伯記 34:31–32; 撒母耳記下 12:13; 撒母耳記上 15:24"> 巴蘭對耶和華的使者說：「我有罪了！我實在不知道你站在路上阻擋我。現在如果你不喜悅，我就回去吧。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 2:9–12; 以賽亞書 37:26–29; 民數記 22:20–21"> 耶和華的使者對巴蘭說：「你跟著這些人去吧，但只可以說我吩咐你的話。」於是巴蘭就跟著巴勒的首領們去了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 16:2; 使徒行傳 28:15; 耶利米書 48:20"> 巴勒聽見巴蘭來了就出去，到摩押的都城迎接他，這城在亞嫩河的邊界，在邊界線上。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 24:11; 約翰福音 5:44; 馬太福音 4:8–9"> 巴勒對巴蘭說：「我不是迫切派人去召你來嗎？你為什麼不來我這裡呢？難道我不會真的使你得尊榮嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民數記 22:18; 箴言 19:21; 民數記 23:16"> 巴蘭對巴勒說：「看，我已經來到你這裡了。難道現在我就能擅自說什麼嗎？神把什麼話放在我口中，我就說什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 於是巴蘭跟著巴勒去，來到了基列-胡作。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 23:14; 箴言 1:16; 民數記 23:2"> 巴勒祭獻了牛羊，然後把肉送給巴蘭以及與他一起的首領們。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 23:13; 民數記 25:2–3; 歷代志下 11:15"> 到了清晨，巴勒帶巴蘭登上巴力高原，從那裡可以看到以色列民營地的邊緣。</span>
</div>
</div>

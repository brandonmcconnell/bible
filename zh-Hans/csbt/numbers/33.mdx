<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 77:20; 彌迦書 6:4; 出埃及記 12:51"> 以下是以色列子民在摩西和亞倫的指揮下，按隊伍出埃及地的行程。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 9:17–23; 申命記 10:11; 民數記 10:6"> 摩西照著耶和華的指示，記下他們每段行程的起點，以下是他們行程的各起點：</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 14:8; 出埃及記 12:37; 出埃及記 13:4"> 一月十五日，就是逾越節的第二天，以色列子孫從拉美西斯起程，在全體埃及人眼前昂然無懼地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="昂然無懼地——原文直譯「高舉著手」。">a</a></sup>出來了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 12:12; 以賽亞書 19:1; 出埃及記 18:11"> 那時埃及人正在埋葬他們的長子，就是耶和華在他們中間所擊殺的；耶和華也對他們的神明施行了審判。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 12:37"> 以色列子孫從拉美西斯起程，在疏割紮營。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 13:20"> <span className="pl pl-1">然後從疏割起行，在曠野邊緣的伊坦紮營。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 14:2; 出埃及記 14:9; 民數記 33:8"> 又從伊坦起行，然後轉回到巴力洗分前面的比哈希錄，在密奪附近紮營。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 15:22–26; 出埃及記 14:21–31"> 然後從比哈希錄前面起行，從海裡走過，到了曠野；又在伊坦曠野走了三天的路程，在瑪拉紮營。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 15:27"> 再從瑪拉起行，來到伊利姆，伊利姆有十二股水泉和七十棵棕櫚樹；他們在那裡紮營。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 16:1; 出埃及記 17:1"> <span className="pl pl-1">然後從伊利姆起行，在紅海邊紮營。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 16:1"> <span className="pl pl-1">又從紅海起行，在汛的曠野紮營。</span><br /></span>
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">然後從汛的曠野起行，在多夫卡紮營。</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">又從多夫卡起行，在阿盧什紮營。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 17:1–8; 出埃及記 19:2"> 再從阿盧什起行，在利菲迪姆紮營；<br /><span className="pl pl-1">在那裡，百姓沒有水喝。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:1–2; 出埃及記 16:1"> <span className="pl pl-1">從利菲迪姆起行，在西奈曠野紮營。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民數記 11:34; 民數記 10:11–13; 民數記 10:33"> <span className="pl pl-1">從西奈曠野起行，在基布羅-哈特瓦紮營。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="民數記 11:35"> <span className="pl pl-1">從基布羅-哈特瓦起行，在哈洗錄紮營。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="民數記 12:16"> <span className="pl pl-1">從哈洗錄起行，在利提瑪紮營。</span><br /></span>
<span className="v" id="v19" data-v="19"> <span className="pl pl-1">從利提瑪起行，在臨門-法勒斯紮營。</span><br /></span>
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">從臨門-法勒斯起行，在立拿紮營。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:1"> <span className="pl pl-1">從立拿起行，在利撒紮營。</span><br /></span>
<span className="v" id="v22" data-v="22"> <span className="pl pl-1">從利撒起行，在克希拉塔紮營。</span><br /></span>
<span className="v" id="v23" data-v="23"> <span className="pl pl-1">從克希拉塔起行，在沙斐山紮營。</span><br /></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">從沙斐山起行，在哈拉達紮營。</span><br /></span>
<span className="v" id="v25" data-v="25"> <span className="pl pl-1">從哈拉達起行，在瑪克希錄紮營。</span><br /></span>
<span className="v" id="v26" data-v="26"> <span className="pl pl-1">從瑪克希錄起行，在塔哈特紮營。</span><br /></span>
<span className="v" id="v27" data-v="27"> <span className="pl pl-1">從塔哈特起行，在塔拉紮營。</span><br /></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">從塔拉起行，在米特卡紮營。</span><br /></span>
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">從米特卡起行，在哈什莫納紮營。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 10:5–6"> <span className="pl pl-1">從哈什莫納起行，在莫西洛紮營。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="申命記 10:6; 創世記 36:27; 歷代志上 1:43"> <span className="pl pl-1">從莫西洛起行，在比尼-亞干紮營。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="申命記 10:7"> <span className="pl pl-1">從比尼-亞干起行，在霍-哈吉加德紮營。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="申命記 10:7"> <span className="pl pl-1">從霍-哈吉加德起行，在約特瓦塔紮營。</span><br /></span>
<span className="v" id="v34" data-v="34"> <span className="pl pl-1">從約特瓦塔起行，在阿博拿紮營。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="申命記 2:8; 列王紀上 9:26; 列王紀上 22:48"> <span className="pl pl-1">從阿博拿起行，在以旬迦別紮營。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="民數記 20:1; 民數記 27:14; 申命記 32:51"> <span className="pl pl-1">從以旬迦別起行，在尋的曠野，就是加低斯紮營。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="民數記 21:4; 民數記 20:22–23; 民數記 20:16"> 然後從加低斯起行，在以東地邊界的何珥山紮營。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 10:6; 申命記 32:50; 民數記 20:24–28"> 以色列子孫出埃及地之後，第四十年的五月一日，祭司亞倫按照耶和華的指示上何珥山，然後死在那裡。</span>
<span className="v" id="v39" data-v="39"> 亞倫死在何珥山上的時候，一百二十三歲。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 21:1–9"> 那時，住在迦南地南方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南方——音譯作「尼革夫」。">b</a></sup>的迦南王阿拉德，聽說以色列人來了。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 21:4"> <span className="pl pl-1">以色列子孫又從何珥山起行，在撒摩拿紮營。</span><br /></span>
<span className="v" id="v42" data-v="42"> <span className="pl pl-1">然後從撒摩拿起行，在普嫩紮營。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="民數記 21:10"> <span className="pl pl-1">從普嫩起行，在奧伯特紮營。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="民數記 21:11"> <span className="pl pl-1">從奧伯特起行，在摩押邊界上的伊耶-亞巴琳紮營。</span><br /></span>
<span className="v" id="v45" data-v="45"> <span className="pl pl-1">從伊音</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="伊音——指伊耶-亞巴琳。">c</a></sup><br /><span className="pl pl-1">起行，在迪本-迦得紮營。</span><br /></span>
<span className="v" id="v46" data-v="46" data-xref="耶利米書 48:18; 以西結書 6:14; 以賽亞書 15:2"> <span className="pl pl-1">從迪本-迦得起行，在阿勒蒙-迪布拉泰姆紮營。</span><br /></span>
<span className="v" id="v47" data-v="47" data-xref="申命記 32:49; 申命記 34:1; 民數記 27:12"> <span className="pl pl-1">從阿勒蒙-迪布拉泰姆起行，在尼波對面的亞巴琳山紮營。</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="民數記 22:1"> 從亞巴琳山起行，在耶利哥東邊約旦河對面的摩押平原紮營。</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 2:1; 約書亞記 13:20; 民數記 25:1–9"> 他們在摩押平原沿著約旦河紮營，從伯耶西莫直到阿貝勒什亭。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民數記 33:48–49"> 那時，耶和華在耶利哥東邊約旦河對面的摩押平原指示摩西說：</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 3:17; 申命記 9:1; 申命記 7:1"> 「你要吩咐以色列子民，對他們說：當你們過了約旦河，到迦南地時，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及記 23:24; 利未記 26:1; 申命記 20:16–18"> 要把那地的居民全都從你們面前趕出去，並且毀掉他們所有的雕像，毀掉他們所鑄造的一切偶像，拆毀他們所有的高壇。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 11:31; 詩篇 115:16; 申命記 32:8"> 你們要占有那地，住在其中，因為我已經把那地賜給你們，讓你們繼承它。</span>
<span className="v" id="v54" data-v="54" data-xref="民數記 26:53–56; 約書亞記 18:11–48; 約書亞記 15:1–12"> 你們要按家族，以抽籤的方式分得那地為繼業。人多的，多給他們繼業；人少的，少給他們繼業；籤抽到哪裡，哪裡就歸屬那人。你們要按你們的父系支派分得繼業。</span>
<span className="v" id="v55" data-v="55" data-xref="士師記 2:3; 詩篇 106:34–36; 申命記 7:16"> 但如果你們不把那地的居民從你們面前趕出去，你所留下的那些人必成為你們眼中的刺、肋旁的荊棘，他們會在你們所住的地上擾害你們；</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命記 28:63; 利未記 20:23"> 而且，我曾怎樣計劃對待他們，也將怎樣對待你們。」</span>
</div>
</div>

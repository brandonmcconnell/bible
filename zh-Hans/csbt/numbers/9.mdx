<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 1:1; 出埃及記 40:2"> 他們出埃及地之後，第二年一月，耶和華在西奈曠野指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 16:1–2; 哥林多前書 5:7–8; 歷代志下 35:1"> 「以色列子民要在所定的日期守逾越節。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 12:6–11; 利未記 23:5; 歷代志下 30:2"> 你們要在這個月的十四日，黃昏的時候，按所定的日期守這節。你們要照著所有的律例和法規來守逾越節。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 於是摩西吩咐以色列子民要守逾越節。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:10; 馬太福音 28:20; 出埃及記 12:1–13"> 他們就在一月十四日，黃昏的時候，在西奈曠野守逾越節。耶和華所指示摩西的一切，以色列子民都照著做了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民數記 27:2; 出埃及記 18:15; 民數記 5:2"> 但有一些人因接觸人的屍體而不潔淨了，不能在那一天守逾越節，所以當天來到摩西和亞倫面前。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 16:2; 哥林多前書 5:7–8; 出埃及記 12:27"> 那些人對摩西說：「我們確實因接觸人的屍體而不潔淨，但為什麼被限制，不能在這節期與以色列子民一起獻上耶和華的祭物呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 85:8; 民數記 27:5; 哥林多前書 4:4"> 摩西回答他們：「你們在這裡等候，我要聆聽耶和華對你們有什麼指示。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 隨後耶和華指示摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 2:1–2; 以弗所書 2:12–13; 哥林多前書 11:28"> 「你要吩咐以色列子民：無論是你們還是你們的後代，如果有人因接觸屍體而不潔淨了，或者在遠方旅行，他還是可以向耶和華守逾越節。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 30:2–15; 出埃及記 12:43–49; 約翰福音 19:36"> 他們要在下一個月的十四日，黃昏的時候守這節。羔羊的肉要與無酵餅和苦菜一起吃，</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 19:36; 出埃及記 12:46; 出埃及記 12:10"> 一點也不可留到早晨，羔羊的骨頭一根也不可折斷；他們要照著逾越節的所有律例守這節。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 17:14; 出埃及記 12:15; 民數記 9:7"> 「但那潔淨的、當時也不在旅行的人，如果沒有守逾越節，那人就要從民中被剪除。那人沒有在這節期獻上耶和華的祭物，所以要承擔自己的罪過。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 12:48–49; 利未記 24:22; 以賽亞書 56:3–7"> 「如果寄居在你們中間的外人，也想守耶和華的逾越節，他就要照著逾越節的律例和法規去做。無論是對外人還是對本族人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本族人——原文直譯「本地人」。">a</a></sup>，你們要有同一個律例。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 13:21; 出埃及記 40:34; 尼希米記 9:19"> 在立起帳幕那一天，有雲彩遮蓋帳幕，就是見證會幕；到了晚上，雲彩停留在帳幕上方，像火的形狀，直到清晨。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 9:12; 出埃及記 40:38; 哥林多前書 10:1"> 此後一直如此，白天有雲彩遮蓋帳幕，夜間有火的形狀。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 40:36–38; 詩篇 32:8; 約翰福音 10:9"> 每當雲彩從會幕上方收上去，隨後以色列子民就起行；雲彩在哪個地方停留，以色列子民就在哪裡紮營。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:1; 約翰二書 1:6; 出埃及記 17:1"> 以色列子民照著耶和華的指示起行，也照著耶和華的指示紮營；雲彩在帳幕上方停留多久，他們就紮營多久。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 3:7; 民數記 1:52–53; 民數記 3:8"> 即使雲彩停留在帳幕上方許多天，以色列子民也謹守耶和華的吩咐不起行。</span>
<span className="v" id="v20" data-v="20"> 有時雲彩只停留在帳幕上方幾天，他們就照著耶和華的指示紮營，然後照著耶和華的指示起行。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 9:19; 尼希米記 9:12"> 有時雲彩從晚上停留到早晨，當雲彩在早晨收上去的時候，他們就起行。無論是白天還是夜間，只要雲彩收上去，他們就起行。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 32:8; 出埃及記 40:36–37; 出埃及記 40:16"> 無論是兩天，還是一個月，或是一年<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一年——或譯作「許多日子」。">b</a></sup>，只要雲彩停留在帳幕上方，在那裡停住，以色列子民就紮營不起行；當雲彩收上去的時候，他們才起行。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約書亞記 22:3; 民數記 9:19; 創世記 26:5"> 他們按照耶和華的指示紮營，也按照耶和華的指示起行。他們遵照耶和華藉著摩西所指示的，謹守耶和華的吩咐。</span>
</div>
</div>

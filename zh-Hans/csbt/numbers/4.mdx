<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 3:27; 民數記 3:19"> 「你們要按家族和父家，統計利未子孫中哥轄子孫的人數，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 4:23; 歷代志上 23:3–5; 列王紀下 11:4–12"> 就是三十歲以上到五十歲，所有前來供職、在會幕中工作的人數。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民數記 4:19; 馬可福音 13:34; 民數記 4:30"> 「哥轄子孫在會幕中有關至聖物的服事工作如下：</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 27:51; 希伯來書 9:3; 出埃及記 40:3"> 當營隊起行時，亞倫和他的兒子們要進去，取下簾幕的幔子，用它遮蓋見證櫃。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 25:13–15; 出埃及記 35:19; 民數記 4:7–8"> 又放上海獅皮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="海獅皮——原文語義不確定，基本意思是一種精細的皮革；本章下同。">a</a></sup>的頂罩，再鋪上純藍色的布，然後穿進杠子。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未記 24:5–8; 出埃及記 37:10–16; 出埃及記 25:23–30"> 「亞倫和他的兒子們要在陳設餅的桌子上鋪藍色的布，其上擺放盤子、勺子、碗和酒祭用的壺，常獻的餅也必須在桌上。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:6–7; 民數記 4:11–13; 民數記 4:9"> 又在它們上面鋪朱紅色的布，再用海獅皮的頂罩遮蓋，然後穿進杠子。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:31–39; 出埃及記 37:17–24; 啟示錄 1:20–1"> 「他們要取來藍色的布，遮蓋燈臺和燈臺的燈盞、燈剪、燈盤，以及所有的油罐，就是用來盛油的器皿。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 4:12; 民數記 4:6"> 然後把燈臺和燈臺的所有器具放進海獅皮的頂罩內，放在臺架上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:5; 出埃及記 30:1–19; 出埃及記 40:26–27"> 「他們要在金祭壇上鋪藍色的布，再用海獅皮的頂罩遮蓋，然後穿進杠子。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 9:29; 出埃及記 25:9; 歷代志下 4:22"> 他們要把聖所中事奉用的所有器具取來，包在藍色的布裡，再用海獅皮的頂罩遮蓋它們，然後放在臺架上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 6:12–13; 出埃及記 39:1; 出埃及記 39:41"> 「他們要收去祭壇的灰，然後在祭壇上鋪紫色的布。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 4:19; 出埃及記 38:1–7"> 又把祭壇上事奉用的所有器具，就是火盆、叉子、鏟子、碗，以及一切祭壇用具，都放在祭壇上；再鋪上海獅皮的頂罩，然後穿進杠子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 6:6–7; 民數記 7:9; 申命記 31:9"> 「營隊起行的時候，亞倫和他的兒子們把聖物和聖所的所有器具都遮蓋完畢，之後哥轄的子孫要進來抬；他們不可觸碰聖物，免得死亡。這些就是會幕中哥轄子孫負責扛抬的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:6; 利未記 24:2; 出埃及記 30:23–38"> 「祭司亞倫的兒子以利亞撒所負責的，是燈油、芬芳香、常獻的素祭和膏油，並負責整個帳幕和帳幕裡的一切，聖所和聖所內的器具。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 6:6–7; 民數記 17:10; 民數記 18:5"> 「不要讓哥轄家族的支系從利未人中被除滅。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 4:15"> 要為他們這樣做：當他們接近至聖物的時候，亞倫和他的兒子們要進去，安排他們每個人的服事工作和各人要負責扛抬的；這樣他們就可以存活，不致死亡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 6:19; 出埃及記 19:21; 民數記 4:15"> 他們片刻都不可進去看聖物，免得他們死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和華指示摩西說：</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 3:18; 民數記 3:21; 民數記 3:24"> 「你也要按父家和家族，統計革順子孫的人數，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 4:3; 提摩太前書 1:18; 哥林多前書 9:7"> 數點三十歲以上到五十歲，所有前來供職、在會幕中做服事的人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 4:19; 民數記 4:31–32; 民數記 4:47"> 「革順家族的服事、扛抬工作如下：</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 3:25–26; 出埃及記 26:14; 民數記 7:5–7"> 他們要抬帳幕的幔帳、會幕和它的頂罩以及覆蓋其上的海獅皮頂罩，還有會幕入口的簾幕，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:18; 出埃及記 27:9"> 院子的帷幔，在帳幕和祭壇四圍的院子入口的簾幕，它們的繩子，以及服事用的一切器具；所有相關的工作，他們都要去做。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前書 11:2"> 「革順子孫所有的服事，所有的扛抬和服事工作，都要遵照亞倫和他兒子們的吩咐；他們所有的扛抬工作，你們都要為他們指派相關的職責。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 4:33; 哥林多前書 12:5–6"> 這是革順子孫各家族在會幕中的服事，是在祭司亞倫的兒子以塔瑪爾手下履行的職責。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 3:33–35"> 「米拉利的子孫，你也要按家族和父家數點他們，</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 4:3; 民數記 4:23; 提摩太後書 2:4"> 數點三十歲以上到五十歲，所有前來供職、做會幕服事工作的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民數記 3:36–37; 出埃及記 26:15; 民數記 7:8–9"> 「他們在會幕中的一切服事，要負責的扛抬工作如下：帳幕的木板，門閂，柱子和底座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 38:21; 歷代志上 9:29; 民數記 3:8"> 院子四圍的柱子和它們的底座、橛子、繩子，以及相關的一切器具，相關的一切工作。你們要按名字指派他們負責扛抬的器具。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 4:28; 約書亞記 3:6; 以賽亞書 3:6"> 這是米拉利子孫各家族的服事，是他們在會幕中的各樣服事，在祭司亞倫的兒子以塔瑪爾手下履行。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 於是，摩西和亞倫以及會眾領袖們按家族和父家，數點哥轄的子孫。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 23:24; 民數記 4:23; 歷代志上 23:3"> 三十歲以上到五十歲，所有前來供職、在會幕中服事的人，</span>
<span className="v" id="v36" data-v="36"> 按著家族被數點，有兩千七百五十人。</span>
<span className="v" id="v37" data-v="37"> 這些就是哥轄家族所有在會幕中服事、被數點的人，摩西和亞倫按照耶和華藉著摩西所指示的，數點了他們。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 革順子孫被數點的，是按家族和父家，</span>
<span className="v" id="v39" data-v="39"> 三十歲以上到五十歲，所有前來供職、在會幕中服事的人；</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 3:32"> 他們按家族和父家被數點的，有兩千六百三十人。</span>
<span className="v" id="v41" data-v="41"> 這些就是革順子孫各家族所有在會幕中服事、被數點的人，是摩西和亞倫按照耶和華的指示數點的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 米拉利子孫各家族被數點的，是按家族和父家，</span>
<span className="v" id="v43" data-v="43"> 三十歲以上到五十歲，所有前來供職、在會幕中服事的人；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前書 10:13; 哥林多後書 12:9–10; 哥林多前書 12:8–12"> 他們按家族被數點的，有三千兩百人。</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 4:29"> 這些就是米拉利子孫各家族被數點的人，摩西和亞倫按照耶和華藉著摩西所指示的，數點了他們。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> 摩西和亞倫以及以色列眾領袖數點利未人，所有被數點的，是按家族和父家，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前書 12:4–31; 羅馬書 12:6–8; 民數記 4:3"> 三十歲以上到五十歲，所有前來在會幕中做服事工作和扛抬工作的人。</span>
<span className="v" id="v48" data-v="48" data-xref="民數記 3:39; 馬太福音 20:16; 馬太福音 22:15"> 他們被數點的，總共是八千五百八十人，</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 1:54; 民數記 4:31; 民數記 4:15"> 都是按照耶和華的吩咐，藉著摩西數點的，各人負責自己的服事工作和扛抬工作。摩西照著耶和華所指示他的，數點了他們。</span>
</div>
</div>

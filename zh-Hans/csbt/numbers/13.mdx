<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 1:22–25; 民數記 32:8; 民數記 34:18"> 「你要派人去探察我賜給以色列子孫的迦南地，按父系支派，每支派差遣一人，都是他們當中的首領。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 12:16; 民數記 32:8; 申命記 1:19"> 摩西就按照耶和華的指示，從帕蘭曠野派出他們，全都是作以色列子民首領的人。</span>
<span className="v" id="v4" data-v="4"> 以下是他們的名字：<br /><span className="pl pl-1">屬魯本支派的，是扎克爾的兒子沙慕亞；</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">屬西緬支派的，是何利的兒子沙法；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="民數記 34:19; 民數記 14:6; 民數記 13:30"> <span className="pl pl-1">屬猶大支派的，是耶弗尼的兒子迦勒；</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">屬以薩迦支派的，是約瑟的兒子以甲；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 24:13; 民數記 11:28; 民數記 13:16"> <span className="pl pl-1">屬以法蓮支派的，是嫩的兒子何西阿；</span><br /></span>
<span className="v" id="v9" data-v="9"> <span className="pl pl-1">屬便雅憫支派的，是拉弗的兒子帕爾提；</span><br /></span>
<span className="v" id="v10" data-v="10"> <span className="pl pl-1">屬西布倫支派的，是索迪的兒子伽迪列；</span><br /></span>
<span className="v" id="v11" data-v="11"> <span className="pl pl-1">屬約瑟支派，就是瑪拿西支派的，是蘇希的兒子迦底；</span><br /></span>
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">屬但支派的，是基瑪利的兒子亞米利；</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">屬亞設支派的，是米迦勒的兒子西帖；</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">屬拿弗他利支派的，是沃夫西的兒子拿比；</span><br /></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">屬迦得支派的，是瑪基的兒子格烏列。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 13:8; 出埃及記 17:9; 民數記 14:6"> 以上就是摩西派去探察那地的人的名字；摩西稱嫩的兒子何西阿為約書亞。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 1:9; 創世記 12:9; 士師記 1:19"> 摩西派他們去探察迦南地，對他們說：「你們前往南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音譯作「內蓋夫」；本章下同。">a</a></sup>那裡，然後上到山地去。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 34:14; 出埃及記 3:8"> 你們要察看那地是怎樣的：住在那裡的民是強是弱、是少是多，</span>
<span className="v" id="v19" data-v="19"> 他們所住的地方是好是壞，他們所住的城是營地是堡壘，</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 31:23; 申命記 31:6–8; 以西結書 34:14"> 那地是肥沃還是貧瘠，那裡有樹木沒有。你們要盡力帶一些當地的果實回來。」那時正是葡萄初熟的季節。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 20:1; 民數記 33:36; 民數記 27:14"> 於是他們上去探察那地，從尋的曠野直到哈馬隘口那裡的利合。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:12; 詩篇 78:43; 以賽亞書 19:11"> 他們上到南地，來到希伯崙；那裡有亞衲人的後裔亞希幔、示篩和塔爾邁，希伯崙比埃及的瑣安早建造七年。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 13:24; 民數記 32:9; 申命記 1:24–25"> 他們來到以實格溪谷，從那裡砍下一根葡萄枝，上面帶著一掛葡萄，由兩個人用杠子抬著，還帶了一些石榴和無花果。</span>
<span className="v" id="v24" data-v="24"> 以色列人給那地方起名為「以實格溪谷」，因為他們從那裡砍下了一掛葡萄。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 34:28; 出埃及記 24:18; 民數記 14:33–34"> 四十天後，他們探察完那地回來了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民數記 32:8; 民數記 20:1; 申命記 1:19"> 他們回到帕蘭曠野的加低斯，來到摩西和亞倫以及全體以色列會眾那裡，向他們和全體會眾報告，又給他們看那地的果實。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:8; 出埃及記 3:17; 出埃及記 13:5"> 他們向摩西講述，說：「我們到了你派我們去的那地，果然是流奶與蜜之地，這就是那裡的果實。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 9:1–2; 申命記 1:28; 民數記 13:33"> 不過住在那地的民強悍，城市極其堅固高大，我們在那裡還看見了亞衲人的後裔。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 14:43; 士師記 6:3; 創世記 15:19–21"> 亞瑪力人住在南地，赫提人、耶布斯人和亞摩利人住在山地，迦南人住在海邊和約旦河沿岸。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民數記 14:24; 羅馬書 8:31; 腓立比書 4:13"> 迦勒讓民眾在摩西面前安靜下來，說：「我們儘管上去，占有那地！我們一定能征服它。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 1:28; 約書亞記 14:8; 希伯來書 3:19"> 但那些與他一起上去探察<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="探察——輔助詞語。">b</a></sup>的人說：「我們不能上去攻打那民，他們實在比我們強大。」</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司書 2:9; 民數記 14:36–37; 以西結書 36:13–14"> 那些人還向以色列子民散布有關所探察之地的謠言，說：「我們過去探察的那地，是吞沒居民之地，而且我們在那裡看見的民都是身材高大的人。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 1:28; 以賽亞書 40:22; 創世記 6:4"> 我們在那裡也看見了巨人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="巨人——或譯作「偉人」。">c</a></sup>，就是巨人的後裔亞衲子孫。在我們眼中，我們就像是蚱蜢；在他們眼中，我們也是如此。」</span>
</div>
</div>

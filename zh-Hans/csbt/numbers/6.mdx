<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:5; 阿摩司書 2:11–12; 羅馬書 1:1"> 「你要吩咐以色列子民，對他們說：如果有男人或女人許了特殊的願，就是拿細耳人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拿細耳人——意思是「分別出來的人」；本章下同。">a</a></sup>的願，為要離俗歸於耶和華，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前書 5:23; 阿摩司書 2:12"> 他就要遠離淡酒烈酒，也不可喝淡酒烈酒做的醋。任何葡萄汁，他都不可喝；鮮的或乾的葡萄，他也不可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 6:5; 民數記 6:21; 民數記 6:8–9"> 在他離俗的所有日子，凡是葡萄樹所出產的，甚至是葡萄籽或葡萄皮的產物，他都不可吃。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 1:11; 士師記 16:17; 士師記 13:5"> 「在他許願離俗的所有日子，他都不可用剃刀剃他的頭。他要分別為聖，任由頭髮變長，直到他離俗歸於耶和華的日子滿了。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 21:11; 利未記 19:28; 利未記 21:1–3"> 他在離俗歸於耶和華的所有日子，都不可接近死人的屍體。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 9:6; 利未記 21:1–2; 利未記 21:10–12"> 即使那是他的父母、兄弟或姐妹，當他們死的時候，他也不可為他們玷汙自己，因為離俗歸神的標記在他頭上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 6:17–18"> 在他離俗的所有日子，他都是歸耶和華為聖的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 6:18; 使徒行傳 18:18; 利未記 14:9"> 「如果有人突然死在他旁邊，以致玷汙了他離俗的頭，他就要在第七天，在得潔淨的日子剃頭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 15:29; 利未記 1:14; 利未記 15:14"> 在第八天，他要把兩隻斑鳩或兩隻雛鴿帶到會幕入口給祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 14:30–31; 利未記 5:8–10"> 祭司要獻一隻作贖罪祭，一隻作燔祭，為他贖那因屍體而帶來的罪污。當天，他要使他的頭重新分別為聖，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 5:6; 馬太福音 24:13; 利未記 14:24"> 重新把離俗的日子獻給耶和華，並且帶來一隻一歲的公羊羔作贖愆祭；先前的那些日子失效了，因為他的離俗已經被玷汙。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 21:26"> 「拿細耳人有以下條例：在他離俗的日子滿了那天，要讓他來到會幕入口。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 3:6; 利未記 4:32; 利未記 4:2–3"> 他要向耶和華獻上他的祭物，一隻無瑕疵的一歲公羊羔作燔祭，一隻無瑕疵的一歲母羊羔作贖罪祭，一隻無瑕疵的公綿羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 2:4; 出埃及記 29:2; 民數記 15:10"> 還有一籃子調了油的無酵細麵餅和抹了油的無酵薄餅，以及同獻的素祭和酒祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 「祭司要把這些祭物帶到耶和華面前，獻上那人的贖罪祭和燔祭，</span>
<span className="v" id="v17" data-v="17"> 並將那隻公綿羊連同那一籃子無酵餅獻給耶和華作平安祭，還要獻上同獻的素祭和酒祭。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:24; 民數記 6:9; 使徒行傳 18:18"> 「拿細耳人要在會幕入口剃自己離俗的頭，把他的離俗頭髮拿去，放在平安祭下的火中。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 2:15; 利未記 7:30; 出埃及記 29:23–28"> 他剃了自己離俗的頭之後，祭司要取出煮過的公綿羊前腿，並從籃子裡取出一個無酵餅和一個無酵薄餅，放在這拿細耳人手掌上。</span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 9:7; 出埃及記 29:27–28; 民數記 5:25"> 然後祭司要把它們作為搖獻祭物，在耶和華面前搖一搖；這些連同搖獻祭物的胸肉以及供物的大腿，都是歸於祭司的聖物。之後拿細耳人就可以喝酒了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:16; 以斯拉記 2:69; 民數記 5:29"> 「這是拿細耳人的條例。如果他在離俗許願之外，還向耶和華許願獻上他所能負擔的祭物，他就要在離俗條例之外，也按照所許的願去做。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22"> 耶和華指示摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 21:5; 歷代志上 23:13; 創世記 48:20"> 「你要吩咐亞倫和他的兒子們，要這樣祝福以色列子民，對他們說：</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:23; 詩篇 121:4–7; 腓立比書 4:7"> <span className="pl pl-1">願耶和華祝福你，保守你；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 80:19; 詩篇 119:135; 詩篇 31:16"> <span className="pl pl-1">願耶和華使他的臉光照你，恩待你；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 4:6; 詩篇 29:11; 帖撒羅尼迦後書 3:16"> <span className="pl pl-1">願耶和華向你顯出笑容，賜你平安。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志下 7:14; 但以理書 9:18–19; 申命記 28:10"> 他們要這樣把我的名安置在以色列子民身上，我就祝福他們。」</span>
</div>

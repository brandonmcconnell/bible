<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 25:22; 出埃及記 19:1; 民數記 10:11–12"> 以色列人出埃及地之後，第二年二月一日，耶和華在西奈曠野、在會幕中指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 38:26; 出埃及記 30:12; 民數記 1:18"> 「你們要統計全體以色列會眾的人數；按著家族、父家，按名單<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="名單——原文直譯「人名的數目」；下同。">a</a></sup>，按著他們的人頭統計所有的男子。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 30:14; 民數記 14:29; 民數記 33:1"> 你和亞倫要按著隊伍，數點以色列二十歲以上所有能出戰的。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 1:16; 出埃及記 18:25; 民數記 13:2–15"> 每個支派要有一個人協助你們，都要是父家的首領。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 7:30; 創世記 30:5–20; 創世記 49:1–33"> 這些協助你們的人，名字如下：<br /><span className="pl pl-1">屬魯本支派的，是謝德珥的兒子以利佐。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="民數記 7:36; 民數記 2:12"> <span className="pl pl-1">屬西緬支派的，是蘇利沙代的兒子謝路米業。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民數記 10:14; 馬太福音 1:2–5"> <span className="pl pl-1">屬猶大支派的，是亞米拿達的兒子拿順。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民數記 7:18; 民數記 10:15; 民數記 2:5"> <span className="pl pl-1">屬以薩迦支派的，是蘇押的兒子拿旦業。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="民數記 7:24; 民數記 10:16; 民數記 2:7"> <span className="pl pl-1">屬西布倫支派的，是希倫的兒子以利押。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="民數記 7:54; 民數記 7:48; 歷代志上 7:26–27"> <span className="pl pl-1">約瑟的子孫中，</span><br /><span className="pl pl-1">屬以法蓮支派的，是亞米忽的兒子以利沙瑪；</span><br /><span className="pl pl-1">屬瑪拿西支派的，是佩達佐的兒子迦瑪列。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="民數記 7:60; 民數記 10:24; 民數記 2:22"> <span className="pl pl-1">屬便雅憫支派的，是基多尼的兒子亞比但。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="民數記 7:66; 民數記 2:25; 民數記 10:25"> <span className="pl pl-1">屬但支派的，是亞米沙代的兒子亞希以謝。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民數記 7:72; 民數記 10:26; 民數記 2:27"> <span className="pl pl-1">屬亞設支派的，是俄蘭的兒子帕結。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="民數記 2:14; 民數記 7:42; 民數記 10:20"> <span className="pl pl-1">屬迦得支派的，是德珥的兒子以利雅薩。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="民數記 7:78; 民數記 10:27; 民數記 2:29"> <span className="pl pl-1">屬拿弗他利支派的，是恩南的兒子亞希拉。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 7:2; 出埃及記 18:21; 出埃及記 18:25"> 以上是會眾裡選召出來的人，都是他們父系支派的領袖，是以色列千軍的首領。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 10:3; 啟示錄 7:4–17; 民數記 1:5–15"> 於是，摩西和亞倫帶著這些被指名的人，</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 2:59; 尼希米記 7:61; 希伯來書 7:3"> 在二月一日招聚全體會眾，按著家族、父家，按名單，按著他們的人頭，登記二十歲以上的男子。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:2; 民數記 26:1–2; 撒母耳記下 24:1–10"> 摩西照著耶和華所指示的，在西奈曠野數點了他們。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 26:5–7; 民數記 2:10–11; 創世記 46:9"> 以色列的長子魯本的子孫，他們的譜系：按著家族、父家，按名單，按著他們的人頭，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 26:7; 民數記 2:10–11"> 魯本支派被數點的，共四萬六千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 26:12–14; 創世記 34:25–30; 民數記 2:12–13"> 西緬子孫的譜系：按著家族、父家，按名單數點，按著他們的人頭，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 26:14; 民數記 2:13; 民數記 25:8–9"> 西緬支派被數點的，共五萬九千三百人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 26:15–18; 創世記 46:16; 民數記 2:14–15"> 迦得子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 26:18; 民數記 2:15"> 迦得支派被數點的，共四萬五千六百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 29:35; 民數記 26:19–22; 撒母耳記下 24:9"> 猶大子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 24:9; 民數記 26:22; 歷代志下 17:14–16"> 猶大支派被數點的，共七萬四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:13; 創世記 49:14–15; 創世記 30:18"> 以薩迦子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 26:25; 民數記 2:6"> 以薩迦支派被數點的，共五萬四千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民數記 26:26–27; 創世記 49:13; 創世記 30:20"> 西布倫子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 26:27; 民數記 2:8"> 西布倫支派被數點的，共五萬七千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民數記 26:35–37; 申命記 33:17; 創世記 46:20"> 約瑟的子孫中，<br />以法蓮子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 26:37; 申命記 33:17; 民數記 2:19"> 以法蓮支派被數點的，共四萬零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民數記 26:28–34"> 瑪拿西子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 26:34; 創世記 48:19–20; 民數記 2:21"> 瑪拿西支派被數點的，共三萬兩千兩百人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 49:27; 創世記 44:20; 啟示錄 7:8"> 便雅憫子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 26:41; 士師記 20:44–46; 歷代志下 17:17"> 便雅憫支派被數點的，共三萬五千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 46:23; 創世記 30:5–6; 創世記 49:16–17"> 但子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v39" data-v="39" data-xref="民數記 26:43; 民數記 2:26"> 但支派被數點的，共六萬兩千七百人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 30:12–13; 創世記 46:27; 創世記 49:20"> 亞設子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 26:47; 民數記 2:28"> 亞設支派被數點的，共四萬一千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 49:21; 民數記 26:48–50; 創世記 46:24"> 拿弗他利子孫的譜系：按著家族、父家，按名單，二十歲以上所有能出戰的男子，</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 26:50; 民數記 2:30"> 拿弗他利支派被數點的，共五萬三千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民數記 26:64; 民數記 1:2–16"> 以上是被數點的人，是摩西和亞倫以及以色列的眾領袖所數點的，領袖有十二人，各人代表自己的父家。</span>
<span className="v" id="v45" data-v="45"> 這些按父家被數點的以色列子孫，都是以色列中二十歲以上所有能出戰的男子；</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 12:37; 民數記 26:51; 出埃及記 38:26"> 被數點的總共有六十萬三千五百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民數記 2:33; 民數記 3:1–49; 民數記 26:57–62"> 利未人沒有按著他們的父系支派與以色列子孫一起被數點，</span>
<span className="v" id="v48" data-v="48"> 因為耶和華指示摩西說：</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 26:62; 民數記 2:33"> 「唯獨不可數點利未支派，不可將他們的人數與以色列子孫一起統計。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 38:21; 出埃及記 31:18; 民數記 4:15"> 你要指派利未人管理見證帳幕和其中的所有器具，以及屬於帳幕的一切。他們要抬帳幕和帳幕的所有器具，做帳幕的事奉，在帳幕的四圍紮營。</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 3:38; 民數記 3:10; 撒母耳記上 6:19"> 起行的時候，利未人要拆卸帳幕；紮營的時候，利未人要立起帳幕。接近帳幕的外人，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="民數記 2:2; 民數記 2:34; 民數記 10:1–36"> 「以色列子孫紮營時，要各按自己的隊伍，各歸自己的營地，各歸自己的旗幟。</span>
<span className="v" id="v53" data-v="53" data-xref="民數記 16:46; 歷代志上 23:32; 利未記 10:6"> 至於利未人，要紮營在見證帳幕的四圍，以免震怒臨到以色列會眾；利未人要謹守見證帳幕的職責。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="申命記 12:32; 出埃及記 40:16; 出埃及記 39:32"> 以色列子孫就這樣做了；耶和華所指示摩西的一切，他們都照著做了。</span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 23:3; 民數記 23:23; 民數記 23:28"> 巴蘭看到祝福以色列能取悅耶和華，就沒有像前幾次那樣嘗試用法術，而是把臉轉向曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 19:20; 歷代志下 15:1; 撒母耳記上 19:23"> 巴蘭舉目，看見以色列按各自的支派安居，神的靈就臨到他身上。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 22:31; 民數記 24:16; 民數記 23:7"> 他發佈諭示，說：<br /><span className="pl pl-1">「這是比珥的兒子巴蘭的宣告，</span><br /><span className="pl pl-1">眼睛開啟之人的宣告；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 1:17; 啟示錄 1:10; 民數記 12:6"> <span className="pl pl-1">這聽到神的話語之人，</span><br /><span className="pl pl-1">看到全能者的異象，</span><br /><span className="pl pl-1">俯伏著，雙眼被開啟，</span><br /><span className="pl pl-1">他的宣告如下：</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">雅各啊，你的帳篷多麼美好；</span><br /><span className="pl pl-1">以色列啊，你的帳幕何等華美！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 1:3; 以賽亞書 58:11; 詩篇 104:16"> <span className="pl pl-1">它們像綿延的溪谷，</span><br /><span className="pl pl-1">像河邊的園林；</span><br /><span className="pl pl-1">像耶和華栽種的沉香樹，</span><br /><span className="pl pl-1">像水邊的香柏樹。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 5:12; 歷代志上 14:2; 啟示錄 17:1"> <span className="pl pl-1">露水從他的枝幹滴落</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="露水從他的枝幹滴落——或譯作「水從他的桶裡流出」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他的根</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="根——或譯作「種子」。">b</a></sup><br /><span className="pl pl-1">在水源豐富之地；</span><br /><span className="pl pl-1">他的君王必高過亞甲，</span><br /><span className="pl pl-1">他的王權必被高舉。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:5; 詩篇 2:9; 民數記 14:9"> <span className="pl pl-1">神把他從埃及領出來，</span><br /><span className="pl pl-1">像野牛的角為他爭戰</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="爭戰——輔助詞語。">c</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">他必吞噬那些敵對他的國家，</span><br /><span className="pl pl-1">壓碎他們的骨頭，</span><br /><span className="pl pl-1">用箭射透他們。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:3; 創世記 27:29; 創世記 49:9"> <span className="pl pl-1">他屈身躺臥如公獅和母獅，</span><br /><span className="pl pl-1">誰敢招惹他？</span><br /><span className="pl pl-1">凡祝福你的，必受祝福；</span><br /><span className="pl pl-1">凡詛咒你的，必受詛咒！」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民數記 23:11; 以西結書 21:14; 以西結書 21:17"> 巴勒就對巴蘭發怒，拍掌對巴蘭說：「我召你來是為了詛咒我的仇敵，看哪，你竟然祝福了他們這三次！</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 22:17; 民數記 22:37; 希伯來書 11:24–26"> 現在趕緊回你本地去吧！我曾說要使你大得尊榮，看哪，耶和華卻阻擋你得尊榮。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 22:18; 民數記 22:38"> 巴蘭回答巴勒：「我不是告訴過你派來見我的那些使者嗎？我說：</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 16:28; 民數記 22:18; 民數記 22:20"> 即使巴勒把他滿屋的金銀給我，我也不能違背耶和華的吩咐，憑自己的心意做好做歹。耶和華說什麼，我就說什麼。</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 6:5; 啟示錄 2:14; 創世記 49:1"> 現在，看哪，我將要回我的族人那裡去了。請讓我告訴你，日後那民族會怎樣對待你的子民。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="民數記 24:3–4; 民數記 23:7; 馬太福音 13:35"> 於是巴蘭發佈諭示，說：<br /><span className="pl pl-1">「這是比珥的兒子巴蘭的宣告，</span><br /><span className="pl pl-1">眼睛開啟之人的宣告；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民數記 24:4; 哥林多前書 8:1; 撒母耳記下 23:1–2"> <span className="pl pl-1">這聽到神的話語之人，</span><br /><span className="pl pl-1">明白至高者的知識，</span><br /><span className="pl pl-1">看到全能者的異象，</span><br /><span className="pl pl-1">俯伏著，雙眼被開啟，</span><br /><span className="pl pl-1">他的宣告如下：</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 22:16; 路加福音 1:32–33; 創世記 49:10"> <span className="pl pl-1">我看見他，卻不是現在；</span><br /><span className="pl pl-1">我望見他，卻不在近處。</span><br /><span className="pl pl-1">有一顆星從雅各發出，</span><br /><span className="pl pl-1">有一根杖從以色列興起；</span><br /><span className="pl pl-1">他將擊碎摩押的額角，</span><br /><span className="pl pl-1">擊潰所有的謝特人</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="擊潰所有的謝特人——有古卷作「打破所有謝特人的頭顱」；參《耶利米書》48:45。">d</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司書 9:12; 創世記 27:29; 撒母耳記下 8:14"> <span className="pl pl-1">以東將成為他的領地，</span><br /><span className="pl pl-1">他的仇敵西珥將被他占領，</span><br /><span className="pl pl-1">以色列必做大能的事。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 49:10; 彌迦書 5:2; 詩篇 2:1–12"> <span className="pl pl-1">有一位出自雅各的必執掌大權，</span><br /><span className="pl pl-1">他將滅絕城裡的倖存者。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 17:14; 士師記 6:3; 歷代志上 4:43"> 然後他觀看亞瑪力，發佈諭示說：<br /><span className="pl pl-1">「亞瑪力是列國之首，</span><br /><span className="pl pl-1">但他最終歸向滅亡。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="創世記 15:19; 士師記 1:16; 約伯記 29:18"> 巴蘭又觀看基尼人，發佈諭示說：<br /><span className="pl pl-1">「你的住處穩固，</span><br /><span className="pl pl-1">你在岩石中築巢。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 83:8; 創世記 10:22; 以斯拉記 4:2"> <span className="pl pl-1">然而基尼必被燒毀，</span><br /><span className="pl pl-1">最終亞述要把你擄去。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="民數記 23:23; 瑪拉基書 3:2; 列王紀下 5:1"> 巴蘭又發佈諭示，說：<br /><span className="pl pl-1">「有禍了！</span><br /><span className="pl pl-1">神定意如此，誰能存活呢？</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 10:4; 民數記 24:20; 但以理書 10:20"> <span className="pl pl-1">有船隊從基提海岸而來，</span><br /><span className="pl pl-1">要制伏亞述、制伏希伯，</span><br /><span className="pl pl-1">但它也歸向滅亡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 31:8; 約書亞記 13:22; 民數記 24:11"> 然後，巴蘭起身離開，回本地去，巴勒也上路回去了。</span>
</div>

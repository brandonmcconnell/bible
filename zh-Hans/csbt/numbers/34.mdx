<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:8; 詩篇 105:11; 申命記 1:7–8"> 「你要吩咐以色列子民，對他們說：你們進入迦南地之後分得為繼業的迦南之地，其邊界如下：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 14:3; 以西結書 47:13; 約書亞記 3:16"> 你們的南端是從尋的曠野起，沿著以東的邊境延伸；南面的邊界是從鹽海的東邊開始。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 32:8; 約書亞記 15:3–4; 民數記 13:26"> 邊界從阿克拉賓斜坡的南邊轉過去，經過尋的曠野，抵達加低斯-巴尼亞南邊的盡頭，然後延伸到哈薩-阿達爾，再經過阿茲蒙。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 15:4; 創世記 15:18; 列王紀上 8:65"> 邊界接著從阿茲蒙轉到埃及河，終點是大海<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大海——指地中海；下同。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 1:4; 以西結書 47:20; 以西結書 47:15"> 至於你們西面的邊界，是大海和海岸線；這就是你們西面的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民數記 33:37; 民數記 34:6; 民數記 34:3"> 你們北面的邊界如下：從大海開始，劃界到何珥山。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 13:21; 列王紀下 14:25; 約書亞記 13:5–6"> 又從何珥山劃界到哈馬隘口，終點是澤達德。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 47:17"> 邊界又延伸到基弗侖，終點是哈薩耶楠。這就是你們北面的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 你們東面的邊界，要從哈薩耶楠劃界到謝法姆。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:33; 申命記 3:17; 約書亞記 11:2"> 邊界從謝法姆下到阿音東邊的利比拉，然後往下，伸展到革尼勒湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="革尼勒湖——指加利利海；又稱「革尼撒勒湖、太巴列湖」。">b</a></sup>的東側。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 34:3; 創世記 13:10; 創世記 19:24–26"> 又下到約旦河，終點是鹽海。<br />以上就是你們土地四圍的邊界。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 34:1; 約書亞記 14:1–5"> 於是，摩西吩咐以色列子民說：「這是你們要以抽籤的方式來繼承的土地，是耶和華指示要分給九個半支派的。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 32:33; 民數記 32:23; 約書亞記 14:2–3"> 因為魯本支派按父家取得了他們的繼業，迦得支派按父家取得了他們的繼業，瑪拿西半支派也取得了他們的繼業，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 32:32"> 這兩個半支派已經在耶利哥對面，約旦河東邊日出的方向，取得了他們的繼業。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16"> 耶和華指示摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 14:1; 約書亞記 19:51; 民數記 13:8"> 「以下是要為你們分配地業之人的名字：祭司以利亞撒，嫩的兒子約書亞。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 1:4–16"> 還要從每支派選出一位領袖，來協助分配土地為繼業，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 26:65; 民數記 13:30; 民數記 14:24"> 這些人的名字是：<br /><span className="pl pl-1">耶弗尼的兒子迦勒，</span><br /><span className="pl pl-1">屬猶大支派；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 49:5"> <span className="pl pl-1">亞米忽的兒子撒母耳，</span><br /><span className="pl pl-1">屬西緬支派；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 49:27; 詩篇 68:27"> <span className="pl pl-1">基斯倫的兒子伊利達德，</span><br /><span className="pl pl-1">屬便雅憫支派；</span><br /></span>
<span className="v" id="v22" data-v="22"> <span className="pl pl-1">約格力的兒子布其，</span><br /><span className="pl pl-1">是但支派的領袖；</span><br /></span>
<span className="v" id="v23" data-v="23"> <span className="pl pl-1">約瑟子孫以弗的兒子哈尼業，</span><br /><span className="pl pl-1">是瑪拿西支派的領袖；</span><br /></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">示弗坦的兒子基姆利，</span><br /><span className="pl pl-1">是以法蓮支派的領袖；</span><br /></span>
<span className="v" id="v25" data-v="25"> <span className="pl pl-1">帕爾納克的兒子以利撒番，</span><br /><span className="pl pl-1">是西布倫支派的領袖；</span><br /></span>
<span className="v" id="v26" data-v="26"> <span className="pl pl-1">阿贊的兒子帕爾提業，</span><br /><span className="pl pl-1">是以薩迦支派的領袖；</span><br /></span>
<span className="v" id="v27" data-v="27"> <span className="pl pl-1">示羅米的兒子亞希忽，</span><br /><span className="pl pl-1">是亞設支派的領袖；</span><br /></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">亞米忽的兒子佩達業，</span><br /><span className="pl pl-1">是拿弗他利支派的領袖。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:51; 民數記 34:18"> 以上就是耶和華所吩咐，要在迦南地給以色列子孫分配繼業的人。」</span>
</div>

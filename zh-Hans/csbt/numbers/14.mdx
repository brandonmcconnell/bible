<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 1:45; 民數記 11:1–4"> 全體會眾就起來，大聲喧嚷，那天夜裡，民眾都哭泣。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 15:24; 出埃及記 17:3; 民數記 16:41"> 以色列子民都向摩西和亞倫發怨言，全體會眾對他們說：「我們還不如死在埃及地，或者死在這曠野！</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 14:31–32; 耶利米書 9:3; 詩篇 78:40"> 耶和華為什麼要把我們領到這地，使我們倒在刀下呢？我們的妻子和孩童要成為掠物了！我們回埃及不是更好嗎？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 7:39; 尼希米記 9:16–17; 申命記 17:16"> 他們又彼此說：「讓我們立一個首領，回埃及去吧！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 16:4; 民數記 16:22; 民數記 16:45"> 摩西和亞倫就在以色列子孫全體會眾面前臉伏於地。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:30; 民數記 13:30; 民數記 14:38"> 那時，探察那地的人當中，嫩的兒子約書亞和耶弗尼的兒子迦勒撕裂衣服，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:27; 申命記 1:25; 申命記 8:7–9"> 對全體以色列會眾說：「我們過去探察的那地，是極其美好的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 22:20; 以賽亞書 62:4; 民數記 13:27"> 如果耶和華喜悅我們，他必把我們帶進那地，把那流奶與蜜之地賜給我們；</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:18; 羅馬書 8:31; 申命記 31:6"> 至於你們，不要背叛耶和華！不要怕那地的民，他們是我們的獵物；他們的保障已經離開他們了，但耶和華與我們同在。你們不要怕他們！」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 17:4; 撒母耳記上 30:6; 利未記 9:23"> 但全體會眾說要用石頭砸死這二人。這時，耶和華的榮耀在會幕中向全體以色列子民顯現。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:32; 詩篇 106:24; 詩篇 78:22"> 耶和華對摩西說：「這子民藐視我，要到什麼時候呢？我在他們當中行了這一切神蹟，他們還不相信我，要到什麼時候呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 32:10; 民數記 25:9; 撒母耳記下 24:12–15"> 我要用瘟疫打擊他們，不讓他們繼承那地，卻使你成為一個比他們強大的民族。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:23; 以西結書 20:9; 申命記 32:27"> 但摩西對耶和華說：「埃及人必聽見這事。要知道，你用你的大能將這子民從他們當中帶上來，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 15:14; 出埃及記 33:11; 申命記 5:4"> 他們會告訴這地的居民；這些居民也聽說了：你耶和華與這子民同在，你耶和華曾被人親眼看見，你的雲彩停留在子民上面，你白天在雲柱中、黑夜在火柱中，行走在他們前頭。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 6:16"> 你如果把這子民全都<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="全都——原文直譯「如同一人」。">a</a></sup>殺掉，那些聽過你名聲的民族就會議論說：</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 9:28; 約書亞記 7:9; 約書亞記 7:7"> 『耶和華因為不能領這子民進入他起誓要給他們的那地，所以在曠野把他們宰殺了。』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 9:6; 馬太福音 9:8; 彌迦書 3:8"> 「現在，願我主彰顯大能！正如你曾宣告說：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:6–7; 詩篇 145:8; 出埃及記 20:5"> 『耶和華不輕易發怒，並有豐盛的慈愛；他赦免罪孽和過犯，但絕不會讓有罪的免於罪責，而會追究罪責，從父親到兒子，直到第三代、第四代』，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 34:9; 詩篇 78:38; 詩篇 106:45"> 求你照著你的大慈愛赦免這子民的罪孽，就像從埃及到如今你一直赦免這子民一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="彌迦書 7:18–20; 雅各書 5:16; 詩篇 106:23"> 耶和華說：「我已經照你的祈求赦免了他們。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 72:19; 哈巴谷書 2:14; 以賽亞書 6:3"> 然而我指著我的永生起誓，指著那充滿全地的耶和華的榮耀起誓：</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 19:3; 創世記 31:7; 出埃及記 32:1"> 雖然這些人全都看見過我的榮耀，以及我在埃及、在曠野所行的神蹟，他們卻試探了我這十次，並沒有聽從我的話，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 32:11; 民數記 26:64; 以西結書 20:15"> 所以，他們絕不會見到我所起誓賜給他們先祖的那地，所有藐視我的人都不會見到。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 14:6–9; 約書亞記 14:6–14; 以弗所書 6:6"> 但我的僕人迦勒，因他有與他們不同的靈<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="與他們不同的靈——或譯作「不同的心志」。">b</a></sup>，全心跟從我，我要把他帶進他曾進去的那地，他的後裔也必繼承那地。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:40; 民數記 13:29; 詩篇 81:11–13"> 亞瑪力人和迦南人住在山間平地，明天你們要轉回，沿著通往紅海的路往曠野前行。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華又指示摩西和亞倫說：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 16:12; 哥林多前書 10:10; 出埃及記 16:28"> 「這邪惡的會眾，他們向我發怨言要到什麼時候呢？以色列子民向我所發的怨言，我都聽見了。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 14:21; 希伯來書 3:17; 民數記 14:2"> 你要對他們說，這是耶和華的宣告：我指著我的永生起誓，我必定照著你們在我耳中所說的話對待你們。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:45; 哥林多前書 10:5; 希伯來書 3:17"> 你們這些被數點過的，就是二十歲以上所有在名單中的，都將橫尸在這曠野中，因為你們向我發怨言。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 26:65; 民數記 14:38; 申命記 1:36–38"> 除了耶弗尼的兒子迦勒和嫩的兒子約書亞以外，你們絕不會進入我舉手起誓要讓你們安居其中的那地；</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:39; 詩篇 106:24; 民數記 26:64"> 但你們的孩童，就是你們說將成為掠物的，我要帶他們進去，他們將得見你們所厭棄的那地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 10:5; 民數記 14:29; 希伯來書 3:17"> 至於你們，你們將橫尸在這曠野中，</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 23:35; 民數記 32:13; 申命記 2:14"> 你們的子孫將在曠野遊牧四十年，承擔你們不忠貞的罪，直到你們全都橫尸在曠野中。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 4:6; 民數記 13:25; 耶利米書 18:9–10"> 按你們探察那地的天數，共四十天，一天算一年，你們要承擔你們的罪責四十年。這樣你們就知道敵對我的後果<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="敵對我的後果——或譯作「我疏遠你們了」。">c</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 23:19; 哥林多前書 10:5; 希伯來書 3:19"> 我耶和華發了話，就必如此對待這一切聚集起來敵對我的邪惡會眾，他們必在這曠野中滅盡，死在這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民數記 13:31–33; 民數記 13:4–16"> 摩西派去探察那地的人回來後，散布有關那地的謠言，以致全體會眾向摩西發怨言，</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 10:10; 民數記 16:49; 希伯來書 3:17"> 這些散布那地可怕謠言的人就遭受瘟疫，死在耶和華面前。</span>
<span className="v" id="v38" data-v="38" data-xref="約書亞記 14:6–10; 民數記 26:65"> 這些去探察那地的人當中，只有嫩的兒子約書亞和耶弗尼的兒子迦勒活了下來。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 33:4; 馬太福音 8:12; 希伯來書 12:17"> 摩西將這些話告訴了全體以色列子民，人們就極其悲慟。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 1:41; 馬太福音 7:21–23; 路加福音 13:25"> 他們清早起來，上到山地高處，說：「我們來了，我們要上耶和華應許的那地方去！我們實在犯了罪。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志下 24:20; 約伯記 4:9; 耶利米書 2:37"> 摩西說：「你們為什麼又要違背耶和華的吩咐呢？這不會成功的。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 1:42; 約書亞記 7:8; 約書亞記 7:12"> 你們不要上去，以免敗在你們仇敵面前，因為耶和華不在你們當中。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 13:29; 民數記 14:25; 歷代志下 15:2"> 亞瑪力人和迦南人就在那裡，在你們前頭，你們必倒在刀下。因為你們既然轉離不跟從耶和華，耶和華也必不與你們同在。」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命記 1:43; 撒母耳記上 4:3–11; 民數記 31:6"> 他們卻擅自上山地高處去，儘管耶和華的約櫃和摩西都沒有從營地中出來。</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 21:3; 士師記 1:17; 申命記 1:44"> 於是住在那山地的亞瑪力人和迦南人下來擊殺他們，擊潰他們，直到霍爾瑪。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 25:37; 出埃及記 40:25; 利未記 24:1–2"> 「你要吩咐亞倫，對他說：點燈的時候，要讓七盞燈照亮燈臺的前面。」</span>
<span className="v" id="v3" data-v="3"> 亞倫就這樣做了。他照著耶和華所指示摩西的，點燃了燈照亮燈臺的前面。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:31–40; 出埃及記 25:9; 出埃及記 25:18"> 燈臺的工藝是用金子錘擛，從底座到花朵都錘擛成形；摩西照著耶和華所顯示給他的樣式，做了燈臺。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華指示摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 7:1; 雅各書 4:8; 出埃及記 19:15"> 「你要從以色列子孫中揀選利未人，為他們舉行潔淨禮。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 19:13; 民數記 19:7–10; 利未記 8:6"> 你要對他們這樣做，使他們得潔淨：要把贖罪的水彈灑在他們身上，又讓他們用剃刀剃全身，並且洗自己的衣服，這樣他們就得潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 2:1; 出埃及記 29:1; 利未記 16:3"> 「然後他們要取來一頭公牛，還有同獻的素祭，就是調了油的細麵粉；你也要另外取來一頭公牛，作贖罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 40:12; 利未記 8:3; 出埃及記 29:4–37"> 你要把利未人帶到會幕前面，並且招聚全體以色列會眾。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 1:4; 使徒行傳 6:6; 提摩太前書 4:14"> 當你把利未人帶到了耶和華面前，以色列子孫就要按手在利未人身上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 7:30; 利未記 8:29; 民數記 1:49–53"> 亞倫要從以色列子孫中把利未人作為搖獻祭，奉獻在耶和華面前，使他們可以做服事耶和華的工作。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:4–10; 出埃及記 29:10; 利未記 1:4"> 利未人要按手在兩頭公牛的頭上，一頭作贖罪祭，另一頭作燔祭，獻給耶和華，為利未人贖罪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 8:21; 民數記 8:11; 羅馬書 15:16"> 「你要讓利未人站在亞倫和他的兒子們面前，把他們作為搖獻祭，奉獻給耶和華。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 3:45; 瑪拉基書 3:17; 民數記 18:6"> 這樣，你把利未人從以色列子孫中分別出來，利未人就歸屬我了。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 8:11; 民數記 8:13; 民數記 3:23–37"> 此後，利未人要進入會幕服事。你要潔淨他們，把他們作為搖獻祭獻上。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:12; 民數記 3:45; 民數記 3:9"> 因為他們是從以色列子孫中特定獻給我的，我已經揀選了他們，代替以色列子孫中所有的頭胎、所有的長子歸屬我。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 13:2; 路加福音 2:23; 出埃及記 13:12–15"> 以色列子孫中所有頭生的，無論是人還是牲畜，都屬於我；我在擊殺埃及地所有頭生的那一天，已經把他們分別為聖歸於我。</span>
<span className="v" id="v18" data-v="18"> 但我揀選利未人代替以色列子孫中所有頭生的；</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:53; 民數記 16:46; 歷代志下 26:16–20"> 我從以色列子孫中把利未人作為奉獻，賜給亞倫和他的兒子們，在會幕中為以色列子民做服事，並為以色列子民贖罪，免得以色列子民接近聖所時，災殃臨到以色列子民。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 摩西和亞倫以及全體以色列會眾就對利未人這樣做了；耶和華所指示摩西有關利未人的一切，以色列子民都照樣對他們做了。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 8:7; 民數記 19:19; 民數記 8:15"> 利未人潔淨了自己，洗了自己的衣服，亞倫就把他們作為搖獻祭，奉獻在耶和華面前；亞倫又為他們贖罪，使他們得潔淨。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 31:2; 歷代志下 35:8–15; 民數記 8:15"> 之後，利未人進去，在亞倫和他的兒子們面前，在會幕中做服事。耶和華所指示摩西有關利未人的一切，他們都照樣對利未人做了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華指示摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 4:3; 歷代志上 23:3; 民數記 4:23"> 「以下是關於利未人的安排：二十五歲以上的要前來，在會幕的服事上供職。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 4:23; 提摩太後書 4:7"> 到了五十歲，他要退出服事工作，不再服事。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:53; 民數記 3:32; 提摩太前書 4:15"> 他可以在會幕中值守，輔助他的弟兄們，但不能做自己的服事。你要這樣安排利未人的職責。」</span>
</div>

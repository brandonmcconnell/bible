<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 14:40; 民數記 10:22; 民數記 1:50"> 「以色列子孫要各歸自己的旗幟，照著父家的標幟紮營，要對著會幕在四圍紮營。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志上 2:10; 路得記 4:20; 路加福音 3:32–33"> 「在東邊日出的方向按隊伍紮營的，是猶大營的旗幟；猶大子孫的領袖是亞米拿達的兒子拿順，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 26:22; 民數記 1:27"> 他的隊伍，那些被數點的共七萬四千六百人。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 1:8; 民數記 7:18; 民數記 7:23"> 挨著他紮營的是以薩迦支派；以薩迦子孫的領袖是蘇押的兒子拿旦業，</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:25; 民數記 1:29"> 他的隊伍，那些被數點的共五萬四千四百人。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 1:9; 民數記 7:24; 民數記 10:16"> 然後是西布倫支派；西布倫子孫的領袖是希倫的兒子以利押，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 26:26–27; 民數記 1:31"> 他的隊伍，那些被數點的共五萬七千四百人。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 10:14"> 所有屬猶大營、按隊伍被數點的，共十八萬六千四百人；他們要首先起行。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民數記 1:5; 創世記 49:3–4; 民數記 7:35"> 「在南邊，按隊伍是魯本營的旗幟；魯本子孫的領袖是謝德珥的兒子以利佐，</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 26:7; 民數記 1:21"> 他的隊伍，那些被數點的共四萬六千五百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 1:6; 民數記 10:19; 民數記 7:41"> 挨著他紮營的是西緬支派；西緬子孫的領袖是蘇利沙代的兒子謝路米業，</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 26:14; 民數記 1:23"> 他的隊伍，那些被數點的共五萬九千三百人。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:14; 民數記 7:42; 民數記 7:47"> 然後是迦得支派；迦得子孫的領袖是德珥的兒子以利雅薩，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:18; 民數記 1:25"> 他的隊伍，那些被數點的共四萬五千六百五十人。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 10:18; 民數記 2:9; 民數記 2:24"> 所有屬魯本營、按隊伍被數點的，共十五萬一千四百五十人；他們作為第二隊起行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 10:21; 民數記 10:17; 民數記 3:38"> 「隨後，會幕和利未營要在眾營中間起行。他們怎樣紮營，也怎樣起行；各照自己的位置，各按自己的旗幟。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 1:10; 民數記 10:22; 創世記 48:14–20"> 「在西邊，按隊伍是以法蓮營的旗幟；以法蓮子孫的領袖是亞米忽的兒子以利沙瑪，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:33; 民數記 26:37"> 他的隊伍，那些被數點的共四萬零五百人。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:10; 民數記 7:54; 民數記 10:23"> 挨著他是瑪拿西支派；瑪拿西子孫的領袖是佩達佐的兒子迦瑪列，</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 26:34; 民數記 1:35"> 他的隊伍，那些被數點的共三萬兩千兩百人。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 1:11; 民數記 7:60; 民數記 10:24"> 然後是便雅憫支派；便雅憫子孫的領袖是基多尼的兒子亞比但，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:37; 民數記 26:41"> 他的隊伍，那些被數點的共三萬五千四百人。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 10:22; 民數記 2:31; 詩篇 80:2"> 所有屬以法蓮營、按隊伍被數點的，共十萬八千一百人；他們作為第三隊起行。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 1:12; 民數記 7:66; 民數記 10:25"> 「在北邊，按隊伍是但營的旗幟；但子孫的領袖是亞米沙代的兒子亞希以謝，</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 26:43; 民數記 1:39"> 他的隊伍，那些被數點的共六萬兩千七百人。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:13; 民數記 7:77; 民數記 7:72"> 挨著他紮營的是亞設支派；亞設子孫的領袖是俄蘭的兒子帕結，</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 1:41; 民數記 26:47"> 他的隊伍，那些被數點的共四萬一千五百人。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:15; 民數記 10:27; 民數記 26:48–50"> 然後是拿弗他利支派；拿弗他利子孫的領袖是恩南的兒子亞希拉，</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 1:42–43; 民數記 26:50"> 他的隊伍，那些被數點的共五萬三千四百人。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 10:25; 民數記 2:16; 民數記 2:9"> 所有屬但營被數點的，共十五萬七千六百人；他們要隨自己的旗幟最後起行。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民數記 1:46; 出埃及記 38:26; 民數記 2:9"> 以上是按父家被數點的以色列子孫；眾營按隊伍被數點的，總共六十萬三千五百五十人。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 26:57–62; 民數記 1:47–49"> 照著耶和華指示摩西的，利未人沒有與以色列子孫一起被數點。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 119:6; 民數記 24:2; 民數記 24:5–6"> 以色列子孫就這樣做，他們照著耶和華所指示摩西的一切，按著自己的旗幟紮營，各按家族和父家起行。</span>
</div>
</div>

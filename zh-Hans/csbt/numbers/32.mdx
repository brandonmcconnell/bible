<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:32; 民數記 32:3; 創世記 13:10–11"> 魯本子孫和迦得子孫有許多牲畜，極其興旺。他們觀看雅謝地和基列地，發現那地方很適合放牧牲畜。</span>
<span className="v" id="v2" data-v="2"> 於是迦得子孫和魯本子孫前來，對摩西和祭司以利亞撒，以及會眾領袖們說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 48:34; 以賽亞書 16:8–9; 民數記 32:34–38"> 「亞塔羅、迪本、雅謝、寧拉、希實本、以利亞利、謝巴姆、尼波、比穩，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 21:34; 申命記 2:24–35; 民數記 21:24"> 就是耶和華在以色列會眾面前所征服的土地，很適合放牧牲畜，而你的僕人們有許多牲畜。」</span>
<span className="v" id="v5" data-v="5" data-xref="路得記 2:10; 約書亞記 7:7; 耶利米書 31:2"> 他們接著說：「如果我們在你眼前蒙恩，就請把這地分給你的僕人作產業，不要領我們過約旦河。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 13:5; 撒母耳記下 11:11; 腓立比書 2:4"> 摩西對迦得子孫和魯本子孫說：「難道你們的弟兄去作戰，你們卻要坐在這裡嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:27–4; 民數記 32:9; 申命記 1:28"> 你們為什麼不過河前往耶和華賜給以色列子孫的土地，以致他們灰心喪膽呢？</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 1:19–25; 民數記 14:2; 民數記 13:2–26"> 我從加低斯-巴尼亞派你們的父輩去察看那地時，他們也這樣做過。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 13:23–10; 申命記 1:24–28"> 他們上到以實格溪谷，察看了那地後，卻使以色列子民灰心喪膽，不願進入耶和華賜給他們的土地。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:11; 詩篇 95:11; 以西結書 20:15"> 所以在那天，耶和華怒氣發作，起誓說：</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 14:28–30; 民數記 14:24; 民數記 26:2"> 『從埃及上來的二十歲以上的男子，絕不會見到我起誓給亞伯拉罕、以撒、雅各的那地，因為他們沒有全心跟從我。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 1:36; 民數記 14:30; 民數記 14:24"> 只有基尼洗人耶弗尼的兒子迦勒和嫩的兒子約書亞例外，因為他們全心跟隨耶和華。』</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:5; 民數記 14:33–35; 希伯來書 3:16–19"> 耶和華的怒氣向以色列發作，使他們在曠野漂泊四十年，直到在耶和華眼前作惡的那整個世代都滅盡了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 詩篇 78:57; 馬太福音 23:31–33"> 看哪，你們這罪人的族類，你們起來接續你們的父輩，再次增添耶和華對以色列的猛烈怒氣。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:11–12; 歷代志下 15:2; 歷代志下 7:19–22"> 如果你們轉離不跟從他，他必再次把以色列撇棄在曠野，那樣你們就毀了這整個民族。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 33:17; 民數記 34:22"> 於是，他們近前來說：「我們是要在這裡為我們的牲畜建造圍欄，為我們的家屬建造城鎮。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 4:12–13; 民數記 32:29–32; 申命記 3:18–20"> 然後我們必武裝起來，在以色列子孫前面領先前行，直到把他們帶到他們的地方；我們的家屬要留在堅固的城裡，躲避這地的居民。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 22:1–5"> 在以色列子孫各自繼承他們的產業之前，我們絕不回自己的家；</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 13:8; 約書亞記 12:1–6; 民數記 34:15"> 我們也不會在約旦河對岸那一帶與大家同分產業，因為我們已經在約旦河東邊分得了自己的產業。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約書亞記 4:12–13; 申命記 3:18–20; 約書亞記 1:13–15"> 摩西就對他們說：「如果你們是要這樣做，如果你們在耶和華面前武裝起來去作戰，</span>
<span className="v" id="v21" data-v="21"> 你們所有武裝起來的人就要在耶和華面前渡過約旦河，直到耶和華將仇敵從他面前趕出去。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 22:9; 約書亞記 22:4; 申命記 3:20"> 當那地在耶和華面前被征服之後，你們才可以回來。這樣你們就對耶和華和以色列盡責了，這地就在耶和華面前成為你們的產業。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 59:12; 箴言 13:21; 創世記 44:16"> 但如果你們不這樣做，看哪，你們就對耶和華犯罪了！要知道，你們的罪必找上你們。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 32:16; 民數記 30:2; 民數記 32:34–42"> 你們就為家屬建造城鎮、為羊群建造圍欄吧！但你們口裡說出的，一定要實行。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 1:13–14"> 迦得子孫和魯本子孫回答摩西說：「你的僕人們必照著我主所吩咐的去做。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 1:14"> 我們的孩童、妻子，以及我們的牛羊和所有的牲畜，都會留在基列各城。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 4:12; 民數記 32:17; 民數記 12:11"> 但你的僕人們，凡是武裝起來的軍兵，都會照著我主所吩咐的，在耶和華面前過河去作戰。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 1:13"> 於是，摩西就為了他們吩咐祭司以利亞撒和嫩的兒子約書亞，以及以色列子孫各支派父系的首領。</span>
<span className="v" id="v29" data-v="29"> 摩西說：「迦得子孫和魯本子孫，凡是武裝起來在耶和華面前去作戰的人，如果與你們一同過約旦河，並且那地在你們面前被征服了，你們就要把基列地分給他們作產業。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 22:19"> 但如果他們不願武裝起來與你們一同過河，他們就要在迦南地與你們同分產業。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 迦得子孫和魯本子孫回應說：「耶和華所吩咐你僕人們的，我們都必照樣遵行。</span>
<span className="v" id="v32" data-v="32"> 我們會武裝起來，在耶和華面前過河到迦南地，而我們繼承的地業是在約旦河這邊。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 12:6; 申命記 29:8; 申命記 3:12–17"> 於是，摩西把亞摩利王西宏的王國和巴珊王歐革的王國，就是他們境內的土地連同城鎮，以及周圍的土地和城鎮，都分給了迦得子孫和魯本子孫，以及約瑟的兒子瑪拿西半支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 2:36; 民數記 32:3; 以賽亞書 17:2"> 迦得子孫就建造了迪本、亞塔羅、亞羅珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 32:1; 民數記 32:3"> 亞他錄-朔反、雅謝、約比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 32:3"> 伯寧拉、伯哈蘭，都是堅固的城，並建造了牲畜圍欄。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:27; 民數記 32:3; 以賽亞書 15:4"> 魯本子孫建造了希實本、以利亞利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 46:1; 民數記 32:3; 約書亞記 23:7"> 尼波、巴力梅翁（這些名字是被改的）、西比瑪。他們給所建造的城都起了別的名字。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="創世記 50:23; 約書亞記 17:1; 民數記 26:29"> 瑪拿西的兒子瑪吉的子孫往基列去，攻取那地，把那裡的亞摩利人趕了出去。</span>
<span className="v" id="v40" data-v="40" data-xref="約書亞記 17:1; 約書亞記 13:29–31; 申命記 3:13–15"> 於是摩西把基列分給瑪拿西的兒子瑪吉，他就住在那裡。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 3:14; 士師記 10:4; 約書亞記 13:30"> 瑪拿西的兒子睚珥也前去，攻取了亞摩利人的一些村鎮，就稱它們為睚珥鎮。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 49:11; 撒母耳記下 18:18"> 挪巴也前去，攻取了基納和附屬的村鎮，就以自己的名字稱基納為挪巴。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 22:1; 民數記 31:12; 民數記 33:50"> 耶和華在耶利哥東邊約旦河對面的摩押平原，指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 14:3–4; 以西結書 48:8; 約書亞記 21:2–42"> 「你要吩咐以色列子民，讓他們從所得的繼業中，分給利未人一些城居住，也把這些城周圍的牧野給利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:14; 約書亞記 21:11; 以西結書 45:2"> 這些城要用來給他們居住，而牧野用來安置他們所擁有的牛羊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他們所擁有的牛羊——或譯作「他們的牛羊、他們的財物」。">a</a></sup>和一切牲畜。</span>
<span className="v" id="v4" data-v="4"> 你們給利未人的那些城郊牧野，要從城牆算起，四圍向外一千肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一千肘——相當於457公尺。1肘=45.7公分。">b</a></sup>；</span>
<span className="v" id="v5" data-v="5"> 然後從城外那裡測量，向東邊兩千肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="兩千肘——相當於914公尺；下同。">c</a></sup>，向南邊兩千肘，向西邊兩千肘，向北邊兩千肘，城要在中間。這是給他們的城郊牧野。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 21:13; 約書亞記 21:3; 詩篇 9:9"> 「你們給利未人的城，其中要有六座逃城，讓過失殺人者可以逃到那裡；在六座之外，還要給他們四十二座城。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:3–42; 歷代志上 6:54–81"> 你們要給利未人的城一共是四十八座城，還包括城郊的牧野。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 26:54; 民數記 33:54; 約書亞記 21:1–42"> 你們從以色列子孫的產業中分給利未人那些城，多的要多給，少的要少給。各支派要根據所得的繼業，把一些城分給利未人。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華指示摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 12:9; 申命記 19:1–2; 利未記 14:34"> 「你要吩咐以色列子民，對他們說：當你們過了約旦河，到迦南地時，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 21:13; 約書亞記 20:2; 民數記 35:6"> 要為自己選定幾座城作逃城，使無意中殺了人的凶手可以逃到那裡。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 20:3–6; 申命記 19:6; 約書亞記 20:9"> 這些城要作你們逃避報血仇者的避難所，這樣過失殺人者就不至於死，等候站在會眾面前受審判。</span>
<span className="v" id="v13" data-v="13"> 你們分給利未人的城，有六座要為你們作逃城：</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 19:8–10; 申命記 4:41–43; 約書亞記 20:7–9"> 在約旦河對岸指定三座城，在迦南地也指定三座城，作為逃城。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 15:16; 加拉太書 3:28; 羅馬書 3:29"> 這六座城要給以色列子孫，以及那些外人和寄居在他們中間的人作避難所，好讓任何無意中殺了人的可以逃到那裡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 24:17; 創世記 9:5–6; 申命記 19:11–13"> 「但如果有人用鐵器打人致死，他就是故意殺人的，這凶手必須被處死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 21:18"> 如果有人手裡拿著可打死人的石頭打人致死，他就是故意殺人的，這凶手必須被處死。</span>
<span className="v" id="v18" data-v="18"> 或者有人手裡拿著可打死人的木器打人致死，他就是故意殺人的，這凶手必須被處死。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 20:3; 申命記 19:6; 申命記 19:12"> 報血仇的人要親自把凶手處死，遇見他時，就要處死他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 21:14; 申命記 19:11; 撒母耳記下 3:27"> 如果有人因仇恨推倒人或故意向人扔東西，致其死亡，</span>
<span className="v" id="v21" data-v="21"> 或者因仇恨動手打人致死，這打死人的必須被處死，他是故意殺人的。報血仇的人遇見凶手時，就要把他處死。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 35:11; 出埃及記 21:13; 約書亞記 20:3"> 「如果有人毫無仇恨而突然推倒了人，或者並非故意把任何器具扔在人身上，</span>
<span className="v" id="v23" data-v="23"> 或者因沒看見而把任何可打死人的石頭砸在人身上，致其死亡，他本不是那人的仇敵，也不是謀害那人，</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 20:6; 民數記 35:12"> 會眾就要在這凶手和報血仇的人之間，按照這些法規審判。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 29:7; 利未記 4:3; 羅馬書 3:24–26"> 會眾要從報血仇的人手中救出這過失殺人者，讓他回到他曾逃入的逃城。他要住在城中，直到以聖油膏立的大祭司去世。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 「但如果那過失殺人者擅自出了他所逃入的逃城的地界，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 22:2; 申命記 19:10; 申命記 19:6"> 報血仇的人在逃城地界外遇見那殺人者，把他殺了，報血仇的人並不負血債。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 3:14; 希伯來書 10:26–30; 希伯來書 6:4–8"> 因為那過失殺人者應該留在逃城，直到大祭司去世；大祭司去世以後，他才可以回到他產業之地。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 27:11; 民數記 27:1"> 這要在你們居住的任何地方，作你們世世代代的律例法規。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯來書 10:28; 申命記 19:15; 馬太福音 18:16"> 「無論誰殺了人，都要憑幾個見證人的口來處決凶手；不可只憑一個見證人的指證來處死人。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 19:11–13; 創世記 9:5–6; 詩篇 51:14"> 你們不可接受贖金來保全殺人者的性命，他犯了死罪，必須被處死。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 4:12; 加拉太書 3:10–13; 加拉太書 2:21"> 你們也不可接受那逃入逃城之人的贖金，讓他在大祭司去世之前回本地居住。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 詩篇 106:38; 何西阿書 4:2–3"> 「這樣，你們就不會玷汙你們所在之地，因為血會使地玷汙；如果有血流在地上，除非藉著那流人血之人的血，地就無法贖清罪污。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 5:3; 詩篇 135:21; 啟示錄 21:27"> 你們不可玷汙所住之地，因為我也住在那裡，我耶和華就住在以色列子民中間。」</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="NUM" data-book-slug="numbers" data-book-name="民數記" data-chapter="31" data-verses="54">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 27:13; 民數記 25:14–18; 啟示錄 6:10"> 「你要向米甸人報以色列人的仇，然後你將歸到你的先人那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 26:25; 民數記 25:11; 列王紀下 10:30"> 摩西就吩咐民眾：「你們當中要有一些人武裝起來去作戰，攻打米甸人，向米甸人施行耶和華的報復。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:8; 撒母耳記上 14:6; 士師記 7:2"> 以色列所有支派中，每支派要派遣一千人去作戰。」</span>
<span className="v" id="v5" data-v="5"> 於是，從以色列千軍中選出了一萬兩千武裝起來作戰的人，每支派有一千人。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:44; 民數記 10:8–9; 歷代志下 13:12–15"> 摩西派他們去作戰，每支派有一千人。他們和祭司以利亞撒的兒子非尼哈一起去作戰，非尼哈手裡帶著聖所的器具和發令的號角。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士師記 21:11; 列王紀上 11:15–16; 撒母耳記上 27:9"> 他們就照著耶和華指示摩西的，與米甸人作戰，殺死了米甸所有的男子。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:21–22; 民數記 25:15; 啟示錄 2:14"> 在這些被殺的人以外，他們還殺了米甸的王，就是埃維、利肯、蘇珥、戶珥、利巴五個米甸王，並且用刀殺了比珥的兒子巴蘭。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:14; 歷代志下 28:8–10; 歷代志下 28:5"> 以色列人擄走了米甸人的婦女和孩童，還掠奪了他們所有的牛羊牲畜和財物，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 1:7; 撒母耳記上 30:1; 約書亞記 6:24"> 又用火燒了他們所住的一切城鎮，以及他們所有的營寨。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 20:14; 約書亞記 8:2"> 他們把所有的掠物和所有的擄物，連人和牲畜都帶走了。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:1"> 他們把俘虜、擄物和掠物都帶到營地，就在耶利哥東邊約旦河對面的摩押平原那裡，帶給摩西和祭司以利亞撒以及以色列會眾。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 5:2; 撒母耳記上 30:21; 民數記 31:12"> 摩西和祭司以利亞撒，以及所有的會眾領袖都出去，到營地外面迎接他們。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 13:19; 撒母耳記上 15:13–14; 民數記 31:48"> 然而，摩西對那些從戰陣上回來的軍官千夫長和百夫長發怒。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:3; 耶利米書 48:10; 申命記 2:34"> 摩西對他們說：「你們怎麼讓所有的女人都存活呢？</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 25:1–9; 彼得後書 2:15; 啟示錄 2:14"> 看哪，正是她們按照巴蘭的計謀，使以色列子民在毗珥的事情上背叛耶和華，以致瘟疫臨到了耶和華的會眾！</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 21:11–12; 申命記 20:16–18; 申命記 7:2"> 現在，你們要把米甸所有的男孩殺死，也要把所有與男人同床共寢過的女人殺死；</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 21:10–14; 歷代志下 28:8–10; 申命記 20:14"> 只有那些不曾與男人同寢過的女孩，可以讓她們存活，歸於你們。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民數記 19:11–22; 民數記 5:2; 歷代志上 22:8"> 「至於你們，要在營地外停留七天。你們和你們的俘虜，所有殺了人的、所有觸碰了被殺之人的，都要在第三天和第七天潔淨自己。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 19:22; 創世記 35:2; 出埃及記 19:10"> 你們還要潔淨每件衣服、每件皮具、每件羊毛織品和每件木器。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 30:16"> 祭司以利亞撒對那些作戰回來的軍人說：「這是耶和華指示摩西的律法條例：</span>
<span className="v" id="v22" data-v="22"> 唯獨金、銀、銅、鐵、錫、鉛，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 19:9; 民數記 19:17; 哥林多前書 3:13"> 這些經得起火燒的東西，你們要使它們經火潔淨，但還要用除汙穢的水使它們得潔淨；至於那些經不起火燒的，要使它們經水潔淨。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 11:25; 利未記 15:13; 利未記 14:9"> 第七天，你們洗衣服，就潔淨了，然後可以回營地。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和華指示摩西說：</span>
<span className="v" id="v26" data-v="26"> 「你和祭司以利亞撒，以及會眾各父系的首領，要統計所擄來的擄物——連人帶牲畜的數目。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 22:8; 詩篇 68:12; 撒母耳記上 30:24–25"> 你要在那些出征的戰士和全體會眾之間，同分擄物。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 18:26; 民數記 31:30; 民數記 31:47"> 你還要從出征的戰士所得的人、牛、驢和羊中，每五百個取一個，作為貢物獻給耶和華。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 29:27; 申命記 12:19; 申命記 12:12"> 你們要從他們那一半中取出這些，作為獻給耶和華的供物交給祭司以利亞撒；</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 3:31; 民數記 3:7–8; 民數記 3:25"> 也要從以色列子孫的這一半中，就是從人、牛、驢、羊以及各樣牲畜中，每五十個取一個，交給謹守耶和華帳幕職責的利未人。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31"> 摩西和祭司以利亞撒就照耶和華指示摩西的去做。</span>
<span className="v" id="v32" data-v="32"> 那些擄物，就是軍兵所掠奪存留下來的掠物有：<br /><span className="pl pl-1">羊六十七萬五千隻；</span><br /></span>
<span className="v" id="v33" data-v="33"> <span className="pl pl-1">牛七萬兩千頭；</span><br /></span>
<span className="v" id="v34" data-v="34"> <span className="pl pl-1">驢六萬一千匹；</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 人口總共三萬兩千，都是沒有與男人同寢過的女人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36"> 出征的人分得的那一半：<br /><span className="pl pl-1">羊的數目是三十三萬七千五百隻，</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37"> 這些羊中歸於耶和華的貢物有六百七十五隻；</span>
<span className="v" id="v38" data-v="38"> <span className="pl pl-1">牛三萬六千頭，</span><br /><span className="pl pl-1">其中歸於耶和華的貢物有七十二頭；</span><br /></span>
<span className="v" id="v39" data-v="39"> <span className="pl pl-1">驢三萬零五百匹，</span><br /><span className="pl pl-1">其中歸於耶和華的貢物有六十一匹；</span><br /></span>
<span className="v" id="v40" data-v="40"> <span className="pl pl-1">人口一萬六千，</span><br /><span className="pl pl-1">其中歸於耶和華的貢物有三十二人。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 18:8; 民數記 18:19; 希伯來書 7:9–12"> 摩西把貢物，就是獻給耶和華的供物，交給了祭司以利亞撒，正如耶和華所指示摩西的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v42" data-v="42"> 以色列子孫的那一半，是摩西從作戰的人取來分給他們的，</span>
<span className="v" id="v43" data-v="43"> 會眾的一半有：<br /><span className="pl pl-1">羊三十三萬七千五百隻，</span><br /></span>
<span className="v" id="v44" data-v="44"> <span className="pl pl-1">牛三萬六千頭，</span><br /></span>
<span className="v" id="v45" data-v="45"> <span className="pl pl-1">驢三萬零五百匹，</span><br /></span>
<span className="v" id="v46" data-v="46"> <span className="pl pl-1">人口一萬六千。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民數記 31:30; 路加福音 10:1–8; 以賽亞書 56:10–11"> 摩西從以色列子孫的那一半中，無論是人還是牲畜，每五十個抽出一個，交給了謹守耶和華帳幕職責的利未人，正如耶和華所指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 那些率領千軍的軍官，就是千夫長、百夫長，來到摩西那裡，</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 18:9; 撒母耳記上 30:18–19; 詩篇 72:14"> 對摩西說：「你的僕人已經統計了我們手下戰士的人數，我們沒有少一個人。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 30:12; 出埃及記 30:15–16; 詩篇 116:12"> 我們帶來了耶和華的祭物，就是各人所獲得的金器——臂環、鐲子、戒指、耳環、項鏈，要在耶和華面前為我們贖罪。」</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民數記 7:2–6"> 摩西和祭司以利亞撒接受了他們的金器，全都是精工的首飾。</span>
<span className="v" id="v52" data-v="52"> 他們獻給耶和華為供物的金子，就是千夫長和百夫長獻出的，共有一萬六千七百五十謝克爾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一萬六千七百五十謝克爾——相當於191公斤。1謝克爾=11.4公克。">a</a></sup>；</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 20:14; 民數記 31:32"> 軍人們掠奪的，各歸自己。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 30:16; 撒迦利亞書 6:14; 使徒行傳 10:4"> 摩西和祭司以利亞撒接受了千夫長和百夫長的金子，帶進會幕，為以色列子孫在耶和華面前作記念。</span>
</div>
</div>

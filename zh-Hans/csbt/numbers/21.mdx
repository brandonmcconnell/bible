<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 1:16; 民數記 33:40; 約書亞記 12:14"> 迦南的阿拉德王住在南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音譯作「內蓋夫」。">a</a></sup>，聽說以色列沿著通往阿塔林的路來了，就攻打以色列，俘虜了他們一些人。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:30; 創世記 28:20; 撒母耳記上 1:11"> 以色列向耶和華許願說：「如果你把這民確實交在我手中，我就把他們的城鎮都毀滅淨盡。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 14:45; 申命記 1:44; 詩篇 10:17"> 耶和華垂聽了以色列的祈求，交出迦南人。以色列人把他們和他們的城鎮都毀滅淨盡，那地方就被起名為「霍爾瑪」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 6:9; 士師記 11:18; 民數記 32:7"> 他們離開何珥山，沿著通往紅海的路前行，要繞過以東地，民眾在路上失去耐心。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 78:19; 民數記 16:13–14; 出埃及記 17:2–3"> 民眾攻擊神和摩西說：「你們為什麼把我們從埃及帶上來，使我們死在曠野呢？這裡既沒有食物，也沒有水，我們的心也厭煩了這淡而無味的食物！」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:9; 耶利米書 8:17; 申命記 8:15"> 於是耶和華派出毒蛇<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="毒蛇——或譯作「火蛇」；本章下同。">b</a></sup>到民眾當中咬他們，以色列死了許多人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 8:24; 民數記 11:2; 詩篇 78:34"> 民眾來見摩西，說：「我們犯罪了，我們攻擊了耶和華和你。求你向耶和華禱告，讓蛇離開我們。」於是摩西就為民眾禱告。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:14; 詩篇 106:43–45; 詩篇 145:8"> 耶和華對摩西說：「你要鑄造一條毒蛇，掛在旗杆上。凡是被咬的人，一看見它就能存活。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:14–15; 希伯來書 12:2; 約翰福音 6:40"> 摩西就鑄造了一條銅蛇，掛在旗杆上。凡是被蛇咬了的人，只要仰望那銅蛇，就得以存活。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="民數記 33:43–45"> 以色列子民起行，紮營在奧伯特。</span>
<span className="v" id="v11" data-v="11"> 又從奧伯特起行，紮營在伊耶-亞巴琳，就在摩押東面的曠野。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:13–14"> 又從那裡起行，紮營在撒烈溪谷。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 11:18; 民數記 22:36; 以賽亞書 16:2"> 又從那裡起行，紮營在亞嫩河對岸。這條河在曠野中，從亞摩利人的邊界流出來；亞嫩河就是摩押的邊界，位於摩押和亞摩利之間。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 10:13; 撒母耳記下 1:18"> 因此在《耶和華戰記》上說：<br /><span className="pl pl-1">「蘇法的哇哈伯，亞嫩河的溪谷，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="民數記 21:28; 申命記 2:18; 申命記 2:9"> <span className="pl pl-1">以及往亞珥居住地延伸的溪谷斜坡，</span><br /><span className="pl pl-1">都緊靠摩押的邊界。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="民數記 20:8; 以賽亞書 12:3; 以賽亞書 41:17–18"> 他們從那裡來到比爾，就是在這井旁，耶和華曾對摩西說：「招聚民眾來，我要賜給他們水。」</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 5:13; 出埃及記 15:1–2; 詩篇 106:12"> 那時以色列唱了這首歌：<br /><span className="pl pl-1">「井啊，湧上水來！</span><br /><span className="pl pl-1">你們要為這井歌唱。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 33:22; 提摩太前書 6:17–18; 雅各書 4:12"> <span className="pl pl-1">這井是首領們所挖的，</span><br /><span className="pl pl-1">是民中的貴族用權杖、用手杖開鑿的。」</span><br />然後，他們從曠野來到瑪塔納。</span>
<span className="v" id="v19" data-v="19"> 又從瑪塔納到拿哈列，從拿哈列到巴末，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 23:28; 民數記 23:14; 申命記 1:5"> 從巴末到摩押境內的山谷，在那裡的毗斯迦山頂可以俯看荒漠。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 2:26–28; 民數記 20:14–19; 士師記 11:19–21"> 以色列派使者去見亞摩利王西宏，說：</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 20:17"> 「請讓我們從你境內經過，我們不進入田間和葡萄園，也不喝井裡的水。我們只走大道，直到過了你的地界。」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 11:20; 申命記 29:7–8; 以賽亞書 15:4"> 但西宏不允許以色列經過他的境內。西宏招聚他的全軍，出來在曠野迎擊以色列。他來到雅哈茲，與以色列交戰。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 2:9; 約書亞記 24:8; 創世記 32:22"> 以色列用刀擊殺他，占有了他的領土，從亞嫩河到雅博河，直到亞捫人那裡，因為亞捫人的邊防穩固。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="民數記 32:33–42; 以賽亞書 16:8–9; 耶利米書 48:2"> 以色列奪取了那些城，就住在亞摩利人的所有城鎮，包括希實本和它的所有村鎮。</span>
<span className="v" id="v26" data-v="26"> 希實本是亞摩利王西宏的都城，西宏曾與摩押先前的王交戰，從他手中奪取了他的全地，直到亞嫩河，</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 14:4; 民數記 21:14; 哈巴谷書 2:6"> 因此那些唱歌謠的人說：<br /><span className="pl pl-1">「來希實本吧！</span><br /><span className="pl pl-1">願西宏的城被建造，得堅立！</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民數記 21:15; 耶利米書 48:45–46; 以賽亞書 15:1–2"> <span className="pl pl-1">有火從希實本出來，</span><br /><span className="pl pl-1">有火焰從西宏的城發出，</span><br /><span className="pl pl-1">吞噬了摩押的亞珥，</span><br /><span className="pl pl-1">以及亞嫩河的高壇之主。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="士師記 11:24; 列王紀下 23:13; 耶利米書 48:46"> <span className="pl pl-1">摩押啊，你有禍了！</span><br /><span className="pl pl-1">基抹的民哪，你們滅亡了！</span><br /><span className="pl pl-1">基抹任憑自己的兒子逃亡，</span><br /><span className="pl pl-1">任憑女兒被亞摩利王西宏擄去。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 48:18; 以賽亞書 15:2; 耶利米書 48:22"> <span className="pl pl-1">我們射殺了他們，</span><br /><span className="pl pl-1">希實本滅亡了，直到迪本；</span><br /><span className="pl pl-1">我們使它荒涼，</span><br /><span className="pl pl-1">直到挪法，直到米底巴。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 13:8–12; 民數記 32:33–42; 申命記 3:16–17"> 這樣，以色列就住在亞摩利人之地。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 48:32; 民數記 32:1; 民數記 32:35"> 摩西又派人去窺探雅謝，隨後攻取雅謝的村鎮，趕出了那裡的亞摩利人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 13:12; 申命記 1:4; 申命記 29:7"> 然後他們轉身，沿著通往巴珊的路上去。巴珊王歐革帶著他的全軍出來迎戰他們，在伊德賴作戰。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 135:10–11; 約書亞記 8:7; 申命記 3:2–3"> 耶和華對摩西說：「不要怕他，我已經把他和他的全軍以及他的領土，都交在你手中了。你要像對待住希實本的亞摩利王西宏那樣對待他。」</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 29:7–8; 約書亞記 13:12; 申命記 3:3–17"> 於是他們擊殺了歐革和他的兒子們以及他的全軍，沒有給他留下一人存活，並且占有了他的領土。</span>
</div>
</div>

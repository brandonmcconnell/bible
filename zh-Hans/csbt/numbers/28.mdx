<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 3:11; 創世記 8:21; 民數記 9:2–3"> 「你要吩咐以色列子民，對他們說：你們務必在所定的日期向我獻上祭物作馨香之氣，作為獻給我的火祭食物。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 6:9; 但以理書 11:31; 約翰福音 1:29"> 你要對他們說，獻給耶和華的火祭如下： 每日常獻的燔祭<br />「兩隻無瑕疵的一歲公羊羔，作為每天常獻的燔祭，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 9:21; 列王紀上 18:36; 出埃及記 12:6"> 早晨獻一隻羊羔，黃昏的時候獻另一隻羊羔；</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 2:1; 出埃及記 16:36; 出埃及記 29:38–42"> 還有十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相當於2.2公升；本章下同。1伊法＝22公升。">a</a></sup>細麵粉，用四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相當於0.9公升；本章下同。1欣=3.7公升。">b</a></sup>壓榨的油調和作素祭。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 5:25; 利未記 6:9; 詩篇 50:8"> 這常獻的燔祭是在西奈山規定的，是獻給耶和華的馨香火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 29:42; 民數記 28:14; 以賽亞書 57:6"> 還要為每一隻公羊羔同獻四分之一欣的酒祭，在聖所中將醇酒的酒祭澆奠給耶和華。</span>
<span className="v" id="v8" data-v="8"> 你要在黃昏的時候獻第二隻羊羔，像早晨的素祭和酒祭一樣獻上，作馨香的火祭獻給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 58:13; 詩篇 92:1–4; 啟示錄 1:10"> 「在安息日，要獻兩隻無瑕疵的一歲公羊羔，還有十分之二伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之二伊法——相當於4.4公升；本章下同。1伊法=22公升。">c</a></sup>調了油的細麵粉為素祭，以及同獻的酒祭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 46:4–5; 民數記 29:22; 民數記 29:31"> 這是在常獻的燔祭和同獻的酒祭以外，每個安息日都要獻的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 10:10; 以西結書 46:6; 以斯拉記 3:5"> 「在每個月的第一天，你們要向耶和華獻上燔祭：兩頭公牛、一隻公綿羊、七隻無瑕疵的一歲公羊羔。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 15:4–12; 以西結書 46:5–7; 民數記 29:10"> 為每一頭公牛，獻上十分之三伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="十分之三伊法——相當於6.6公升；本章下同。1伊法=22公升。">d</a></sup>調了油的細麵粉作素祭；為每一隻公綿羊，獻上十分之二伊法調了油的細麵粉作素祭；</span>
<span className="v" id="v13" data-v="13"> 為每一隻羊羔，獻上十分之一伊法調了油的細麵粉作素祭。這是燔祭，作馨香的火祭獻給耶和華。</span>
<span className="v" id="v14" data-v="14"> 還有同獻的酒祭，每頭公牛要二分之一欣<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="二分之一欣——相當於1.9公升。1欣=3.7公升。">e</a></sup>酒，每隻公綿羊要三分之一欣<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三分之一欣——相當於1.2公升。">f</a></sup>酒，每隻羊羔要四分之一欣<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="四分之一欣——相當於0.9公升。">g</a></sup>酒。這是一年之中每個月都要獻上的新月燔祭。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 28:3; 民數記 28:22; 民數記 15:24"> 除了常獻的燔祭和同獻的酒祭以外，還要獻給耶和華一隻公山羊作贖罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 16:1–8; 出埃及記 12:18; 利未記 23:5–8"> 「一月十四日是耶和華的逾越節，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 23:6; 出埃及記 23:15; 出埃及記 13:6"> 這個月的十五日是節期，要吃無酵餅七天。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 12:16; 利未記 23:7–8"> 第一天要有神聖的聚會，任何日常工作都不可做。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 15:21; 以西結書 45:21–25; 民數記 29:8"> 你們要獻上兩頭公牛、一隻公綿羊、七隻一歲的公羊羔，都必須是無瑕疵的，作為火祭，作為燔祭獻給耶和華。</span>
<span className="v" id="v20" data-v="20"> 還有同獻的素祭，就是調了油的細麵粉：為每頭公牛，要獻十分之三伊法麵粉；為每隻公綿羊，要獻十分之二伊法麵粉；</span>
<span className="v" id="v21" data-v="21"> 至於那七隻公羊羔，要為每一隻羊羔獻十分之一伊法麵粉。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 8:3"> 還要獻一隻贖罪祭公山羊，為你們贖罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 28:3; 民數記 28:10"> 除了清晨的燔祭，就是常獻的燔祭以外，你們還要獻以上這些祭物。</span>
<span className="v" id="v24" data-v="24"> 在常獻的燔祭和同獻的酒祭以外，一連七天，每天都要這樣獻上火祭的食物，作馨香之氣獻給耶和華。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:8; 民數記 28:18; 出埃及記 13:6"> 第七天要有神聖的聚會，任何日常工作都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 23:16; 出埃及記 34:22; 利未記 23:10"> 「在初熟之日，當你們在七七節向耶和華獻上新的素祭時，要有神聖的聚會，任何日常工作都不可做。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 23:18–19; 民數記 28:11; 民數記 28:19"> 你們要獻上兩頭公牛、一隻公綿羊、七隻一歲的公羊羔為燔祭，作馨香之氣獻給耶和華。</span>
<span className="v" id="v28" data-v="28"> 還有同獻的素祭，就是調了油的細麵粉：為每頭公牛，要獻十分之三伊法麵粉；為每一隻公綿羊，要獻十分之二伊法麵粉；</span>
<span className="v" id="v29" data-v="29"> 至於那七隻公羊羔，要為每一隻羊羔獻十分之一伊法麵粉。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 28:15; 民數記 28:22; 彼得前書 2:24"> 還要獻一隻公山羊，為你們贖罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 28:19; 民數記 28:3; 瑪拉基書 1:13–14"> 你們要在常獻的燔祭和同獻的素祭以外，獻上這些無瑕疵的燔祭和同獻的酒祭。</span>
</div>

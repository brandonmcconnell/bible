<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 21:1; 利未記 13:46; 民數記 12:14"> 「你要吩咐以色列子民：把所有患痲瘋病的、所有患漏症的、所有因接觸屍體而不潔淨的，都從營裡送出去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:14; 利未記 26:11–12; 詩篇 68:18"> 無論男女，都要送出去。你們要把他們送到營地外面，以免玷汙了他們的營地，因為我居住在他們中間。」</span>
<span className="v" id="v4" data-v="4"> 以色列子民就這樣做，把他們送到營地外面。耶和華所指示摩西的，以色列子民都照著做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華指示摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 5:1–4; 利未記 5:14–7"> 「你要吩咐以色列子民：如果有男人或女人犯了人常犯的任何罪，以致不忠於耶和華，那人就要承擔罪責。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 5:5; 利未記 26:40; 約書亞記 7:19"> 他要承認自己所犯的罪，按全數對他的虧負作出賠償，並且加上五分之一，交給他所虧負的人。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 6:6–7; 利未記 7:7; 利未記 25:25–26"> 但如果被虧負的人沒有近親為他接受損害賠償，那麼，這損害賠償以及犯罪之人的贖罪祭公綿羊，都歸於耶和華，歸給祭司。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 18:3–4; 利未記 7:6–14; 利未記 6:17–18"> 以色列子民帶到祭司那裡的所有聖物中，凡是供物，都要歸給祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 10:13"> 各人的聖物原屬於自己，各人獻到祭司那裡的，要歸給祭司。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華指示摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 5:19–20; 箴言 2:16–17"> 「你要吩咐以色列子民，對他們說：如果一個人的妻子行為不軌，對丈夫不忠，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 18:20; 利未記 20:10; 箴言 7:18–19"> 有男人與她同寢交合，但她瞞過了丈夫，隱藏了這事，她使自己受玷汙卻沒有見證人，也沒有被捉住——</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; 西番雅書 3:8"> 無論是丈夫起了猜忌的心，猜忌妻子，而她確實玷汙了自己，或者是丈夫起了猜忌的心，猜忌妻子，而她並沒有玷汙自己——</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 29:16; 列王紀上 17:18; 利未記 5:11"> 這個人就要把自己的妻子帶到祭司那裡，並且為她帶來祭物，就是十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相當於2.2公升。1伊法＝22公升。">a</a></sup>大麥粉。不可澆上油，也不可加上乳香，因為這是猜忌的素祭，是想起罪孽的反思素祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 2:22–23; 耶利米書 17:10; 希伯來書 13:4"> 「祭司要讓她上前來，站在耶和華面前。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 30:18; 約翰福音 8:6; 民數記 19:2–9"> 祭司要用瓦器取聖水，還要取一些在帳幕地面上的塵土，放在水中。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民數記 5:22; 啟示錄 10:9–10"> 祭司要讓那女人站在耶和華面前，散開那女人的頭髮，然後把反思素祭，就是猜忌的素祭，放在她手掌上。祭司要手裡端著會帶來詛咒的苦水，</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:2; 民數記 5:12; 馬太福音 26:63"> 讓那女人起誓，對她說：『如果沒有別的男人與你同寢，如果你在丈夫權下沒有行為不軌受玷汙，你就免於這詛咒苦水的罪罰。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 5:12"> 但如果你在丈夫權下行為不軌，與丈夫以外的男人交合，玷汙了自己——』</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 6:26; 尼希米記 10:29; 撒母耳記上 14:24"> 這時祭司要讓那女人以詛咒的誓言起誓，然後對那女人說：『當耶和華使你大腿萎縮、肚子腫脹的時候，願耶和華使你在族人中間成為詛咒和誓語。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 109:18; 詩篇 89:52; 約伯記 31:39–40"> 願這帶來詛咒的水進入你的肚腹，使肚子腫脹、大腿萎縮。』那女人就要說：『阿們，阿們。』</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 3:19; 詩篇 51:1; 詩篇 51:9"> 「祭司要將這些詛咒寫在書卷上，把這些字擦抹到苦水裡。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 5:3–4; 瑪拉基書 3:5"> 之後要讓那女人喝這帶來詛咒的苦水，這詛咒的水就會進入她體内產生痛苦。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:27; 民數記 5:18; 民數記 5:15"> 祭司要從那女人手中接過猜忌的素祭，在耶和華面前把這素祭搖一搖，然後帶到祭壇那裡。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 2:2; 利未記 2:9; 利未記 5:12"> 祭司要從素祭中捧出一把，作為記念部分，在祭壇上燒獻為煙，然後讓女人喝那水。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 42:18; 撒迦利亞書 8:13; 耶利米書 29:18"> 「祭司讓她喝那水以後：如果她玷汙了自己，對她丈夫不忠，這帶來詛咒的水就會進到她體内，產生痛苦。她的肚子會腫脹，她的大腿會萎縮，那女人就在族人中間成為詛咒。</span>
<span className="v" id="v28" data-v="28" data-xref="彌迦書 7:7–10; 哥林多後書 4:17; 詩篇 113:9"> 但如果那女人沒有使自己受玷汙，她是清白的，她就免於罪罰，仍然能懷孕生子。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 5:19; 民數記 5:12; 民數記 5:15"> 「這就是關於猜忌的條例：如果妻子在丈夫權下行為不軌，玷汙了自己，</span>
<span className="v" id="v30" data-v="30"> 或者丈夫起了猜忌的心，猜忌自己的妻子，就要讓那女人站在耶和華面前，祭司要對她執行這一切條例。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 20:10; 羅馬書 2:8–9; 以西結書 18:4"> 這樣丈夫就免於罪責，那女人卻要承擔自己的罪責。」</span>
</div>
</div>

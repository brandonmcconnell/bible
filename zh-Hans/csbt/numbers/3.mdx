<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 6:20; 創世記 10:1; 出埃及記 6:16"> 以下是亞倫和摩西的家系記事，那時耶和華在西奈山向摩西說話。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:23; 民數記 26:60; 出埃及記 28:1"> 亞倫兒子們的名字是：長子納達布，還有亞比戶、以利亞撒、以塔瑪爾。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 28:41; 利未記 8:30; 利未記 8:12"> 這些是亞倫兒子們的名字，他們是受膏的祭司，摩西使他們承接聖職作祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 10:1–2; 民數記 26:61"> 納達布和亞比戶在西奈曠野向耶和華獻上違規的火，就死在耶和華面前；他們沒有兒子。以利亞撒和以塔瑪爾在父親亞倫面前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="面前——或譯作「活著時」。">a</a></sup>作祭司。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華指示摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:8; 民數記 2:33; 民數記 1:49–53"> 「你要讓利未支派上前來，侍立在祭司亞倫面前，輔助他。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 1:50; 民數記 8:15; 民數記 8:11"> 他們要在會幕前為亞倫和全體會眾謹守職責，做帳幕的服事工作。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:33; 民數記 10:17; 以賽亞書 52:11"> 他們也要看管會幕的所有器具，並且為以色列子民謹守職責，做帳幕的服事工作。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 8:19; 民數記 18:6–7; 以弗所書 4:8"> 你要把利未人指派給亞倫和他的兒子們，這是從以色列子孫中特別指派給他們的。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 1:51; 民數記 3:38; 羅馬書 12:7"> 你要指派亞倫和他的兒子們謹守他們祭司的職份；接近帳幕的外人，必須被處死。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華又指示摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 3:41; 民數記 8:16; 民數記 18:6"> 「看哪，我已經從以色列子孫中揀選了利未人，代替以色列子孫中所有頭生的長子，所以利未人要歸屬我。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及記 13:12; 出埃及記 13:2"> 因為所有頭生的都屬於我；埃及地所有頭生的被我擊殺那天，我已經使以色列所有頭生的，無論是人還是牲畜，都分別為聖歸於我了，他們是屬於我的。我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華在西奈曠野指示摩西說：</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:62; 馬可福音 10:14; 提摩太後書 3:15"> 「你要按父家和家族數點利未子孫；所有一個月以上的男性，你都要數點。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:39; 民數記 4:37; 民數記 4:49"> 摩西就按照耶和華的命令，照著所受的指示數點他們。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 46:11; 出埃及記 6:16–19; 民數記 15:5–23"> 以下是利未兒子們的名字：革順，哥轄，米拉利。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 6:17; 歷代志上 26:1–32; 出埃及記 6:17–19"> 革順兒子的名字，按家族是立尼、示每。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 6:18; 歷代志上 6:18; 歷代志上 15:17–21"> 哥轄的兒子，按家族是阿姆蘭、以斯哈、希伯倫、烏基業。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 6:19; 歷代志上 6:19; 民數記 3:33"> 米拉利的兒子，按家族是瑪赫利、穆希。這些是利未人的家族，各按他們的父家。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 屬革順的，有立尼家族和示每家族；這些是革順的家族。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 4:38–40"> 他們被數點的，是所有一個月以上男性的數目，被數點的共七千五百人。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:53; 民數記 2:17"> 革順家族要在帳幕後面靠西邊紮營，</span>
<span className="v" id="v24" data-v="24"> 革順人的父家領袖是拉伊勒的兒子以利雅薩。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 25:9; 歷代志上 23:32; 歷代志上 9:14–33"> 革順子孫在會幕中負責：帳幕，罩篷，罩篷的頂罩，會幕入口的簾幕，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:18; 出埃及記 38:9–16; 出埃及記 27:9–16"> 院子的帷幔，在帳幕和祭壇四圍的院子入口的簾幕，它們的繩子，以及相關的一切工作。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 26:23; 民數記 3:19; 歷代志上 23:12"> 屬哥轄的，有阿姆蘭家族、以斯哈家族、希伯倫家族、烏基業家族；這些是哥轄的家族。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 3:31; 民數記 4:35–36; 民數記 3:7"> 所有一個月以上男性的數目，共八千六百<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="八千六百——或譯作「八千三百」。">b</a></sup>人；他們要謹守聖所的職責。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:53; 民數記 3:23; 民數記 2:10"> 哥轄子孫的家族要在帳幕南邊紮營，</span>
<span className="v" id="v30" data-v="30"> 哥轄家族的父家領袖是烏基業的兒子以利撒番。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 36:35–36; 出埃及記 27:1–8; 出埃及記 26:31–33"> 他們負責：約櫃，桌子，燈臺，祭壇和香壇，事奉用的聖所器具，簾幕，以及相關的一切工作。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 4:27; 民數記 4:16; 民數記 20:25–28"> 利未人眾領袖的主管是祭司亞倫的兒子以利亞撒，他是那些謹守聖所職責之人的監督。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民數記 3:20; 歷代志上 6:19; 歷代志上 23:21"> 屬米拉利的，有瑪賀利家族和穆希家族；這些是米拉利的家族。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 2:9; 民數記 2:11; 民數記 1:21"> 他們被數點的，所有一個月以上男性的數目，共六千兩百人。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 1:53; 民數記 2:25; 民數記 3:28–29"> 米拉利家族的父家領袖是亞比亥的兒子蘇列，他們要在帳幕北邊紮營。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 26:32; 出埃及記 26:37; 出埃及記 26:15–29"> 米拉利子孫所負責的是：帳幕的木板，門閂，柱子，底座，帳幕的所有器具，以及相關的一切工作，</span>
<span className="v" id="v37" data-v="37"> 還有院子四圍的柱子和它們的底座、橛子、繩子。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民數記 3:10; 民數記 1:53; 民數記 2:3"> 在帳幕前面朝東，就是在會幕前面日出方向紮營的，是摩西和亞倫以及亞倫的兒子們。他們為聖所和以色列子民謹守職責<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="為聖所和以色列子民謹守職責——或譯作「代表以色列子民謹守聖所的職責」。">c</a></sup>。接近帳幕的外人，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="民數記 26:62; 馬太福音 7:14; 民數記 4:47–48"> 所有被數點的利未人，就是摩西和亞倫按照耶和華的指示、按家族數點的，所有一個月以上的男性，總共兩萬兩千人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民數記 3:15; 路加福音 10:20; 詩篇 87:6"> 耶和華對摩西說：「你要數點以色列子孫中所有一個月以上的頭生男性，按名單統計他們。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 3:12; 民數記 3:45; 民數記 8:16"> 我是耶和華，你要揀選利未人歸於我，代替以色列子孫所有頭生的；並要用利未人的牲畜，代替以色列子孫所有頭生的牲畜。」</span>
<span className="v" id="v42" data-v="42"> 摩西就照著耶和華所指示的，數點以色列子孫中所有頭生的。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 3:39"> 按名單，所有一個月以上的頭生男性，被數點的有兩萬兩千兩百七十三人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 耶和華指示摩西說：</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 3:12; 民數記 3:40–41"> 「你要揀選利未人，代替以色列子孫中所有頭生的；並要用利未人的牲畜，代替以色列子孫的牲畜。利未人要歸於我，我是耶和華。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 13:13; 民數記 18:15–16"> 以色列子孫頭生的男子比利未人多出了兩百七十三人，他們的贖價，</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及記 30:13; 利未記 27:6; 民數記 18:16"> 你要每人收取五謝克爾，按聖所的謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="謝克爾——重量單位；後來成為貨幣單位。1謝克爾=11.4公克。本章下同。">d</a></sup>標準收取，一謝克爾是二十季拉<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="二十季拉——相當於11.4公克。1季拉=0.57公克。">e</a></sup>。</span>
<span className="v" id="v48" data-v="48"> 你要把銀子，就是多出來之人的贖價，交給亞倫和他的兒子們。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49"> 摩西就在利未人所贖的人以外，向多出來的人收取贖價的銀子。</span>
<span className="v" id="v50" data-v="50" data-xref="民數記 3:46–47; 彼得前書 3:18; 馬太福音 20:28"> 他從這些以色列子孫的頭生子那裡收取了銀子，按聖所的謝克爾標準，共一千三百七十五謝克爾<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一千三百七十五謝克爾——相當於15.7公斤。1謝克爾=11.4公克。">f</a></sup>。</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 3:48; 民數記 16:15; 撒母耳記上 12:3–4"> 摩西按照耶和華的吩咐，把贖價銀子交給了亞倫和他的兒子們，正如耶和華所指示摩西的。</span>
</div>
</div>

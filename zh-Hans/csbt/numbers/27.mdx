<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:33; 加拉太書 3:28; 歷代志上 7:15"> 那時，西羅非哈的女兒們上前來——西羅非哈是希弗的兒子、基列的孫子、瑪吉的曾孫、瑪拿西的玄孫，屬於約瑟兒子瑪拿西的家族；他女兒的名字是：瑪拉、挪阿、霍格拉、米爾卡、提爾撒——</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 15:33–34; 申命記 17:8–10; 出埃及記 18:19–26"> 她們站在會幕的入口，在摩西、祭司以利亞撒和領袖們，以及全體會眾面前說：</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 26:64–65; 以西結書 18:4; 民數記 14:35"> 「我們的父親死在曠野，他不在那些聚衆反對耶和華的一夥人當中，不屬於可拉同黨，而是因自己的罪過死了；他沒有兒子。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 17:4; 詩篇 109:13; 出埃及記 32:11"> 為什麼因我們的父親沒有兒子，就要把他的名字從他家族中除去呢？求你在我們父親的兄弟中分給我們一份地業。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未記 24:12–13; 約伯記 23:4; 箴言 3:5–6"> 摩西就把她們的案件呈到耶和華面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:28; 詩篇 68:5–6"> 耶和華告訴摩西說：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 3:28; 耶利米書 49:11; 約書亞記 17:4"> 「西羅非哈的女兒們說得對，你一定要在她們父親的兄弟中分給她們一份可繼承的地業，把她們父親的繼業轉給她們。</span>
<span className="v" id="v8" data-v="8"> 你還要吩咐以色列子民說：如果一個人死了，並且沒有兒子，就要把他的繼業轉給他的女兒。</span>
<span className="v" id="v9" data-v="9"> 如果他沒有女兒，就要把他的繼業轉給他的兄弟。</span>
<span className="v" id="v10" data-v="10"> 如果他沒有兄弟，就要把他的繼業轉給他父親的兄弟。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 35:29; 路得記 4:3–6; 耶利米書 32:8"> 如果他父親也沒有兄弟，就要把他的繼業給他家族中與他最近的親屬，那人可以擁有這繼業。」這要成為以色列子孫的律例法規，正如耶和華所指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 33:47–48; 申命記 34:1–4; 申命記 3:23–27"> 耶和華對摩西說：「你到這亞巴琳山上去，觀看我賜給以色列子孫的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:6; 民數記 31:2; 民數記 20:24–28"> 你觀看了那地之後，你也要歸到你的先人那裡，像你的哥哥亞倫歸到先人那裡一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:37; 民數記 20:8–13; 出埃及記 17:7"> 因為在尋的曠野，當會眾爭鬧時，你們違背了我的命令，沒有在那水邊在他們眼前尊我為聖。」那水就是尋的曠野中的米利巴-加低斯水。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 於是，摩西請求耶和華說：</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 16:22; 耶利米書 3:15; 希伯來書 12:9"> 「願耶和華——那使一切肉體有氣息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使一切肉體有氣息——或譯作「賜予全人類氣息」。">a</a></sup>的神，指派一個人管理會眾，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:5; 馬可福音 6:34; 列王紀上 22:17"> 這人要在他們前面出入。他要帶領他們出入，以免耶和華的會眾像沒有牧人的羊群那樣。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 34:9; 民數記 27:23; 創世記 41:38"> 耶和華就對摩西說：「你把嫩的兒子約書亞帶來，他是一個心中有聖靈的人。你要按手在他頭上，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 3:28; 申命記 31:7–8; 申命記 31:23"> 讓他站在祭司以利亞撒和全體會眾面前，在他們眼前任命他；</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 1:16–18; 撒母耳記上 10:9; 列王紀下 2:9–10"> 並將你的一些尊榮加給他，好讓全體以色列會眾都聽從他。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 9:14; 撒母耳記上 28:6; 出埃及記 28:30"> 他要站在祭司以利亞撒面前；以利亞撒要在耶和華面前憑藉烏陵的裁決為他求問。約書亞和所有與他一起的以色列子民，就是全體會眾，都要照著以利亞撒的命令出入。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 摩西就照著耶和華所指示的去做。他把約書亞帶來，讓他站在祭司以利亞撒和全體會眾面前，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 3:28; 民數記 27:19; 申命記 31:7–8"> 按手在他頭上，任命他，正如耶和華藉著摩西所說的。</span>
</div>
</div>

</div>

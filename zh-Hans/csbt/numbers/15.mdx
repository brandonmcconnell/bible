<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:10; 民數記 15:18; 利未記 25:2"> 「你要吩咐以色列子民，對他們說：你們進入了我賜給你們的安居之地後，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:18; 創世記 8:21; 腓立比書 4:18"> 向耶和華獻上火祭時，無論是燔祭或是別的祭物，無論是為了還特殊的願，或是作甘心祭，或是作各節期的祭，都要從牛群或羊群中取來，燒獻為馨香之氣給耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:40; 利未記 23:13; 利未記 6:14"> 那向耶和華獻上祭物的人，還要獻上十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相當於2.2公升。1伊法=22公升。">a</a></sup>細麵粉為素祭，用四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相當於0.9公升。1欣=3.7公升。">b</a></sup>油調和。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:7; 民數記 28:14; 士師記 9:13"> 在燔祭或別的祭物之外，你還要為每隻綿羊羔預備四分之一欣的酒作酒祭。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 28:12–14; 民數記 15:4"> 或是為每隻公綿羊預備十分之二伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之二伊法——相當於4.4公升。1伊法=22公升。">c</a></sup>細麵粉為素祭，用三分之一欣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三分之一欣——相當於1.2公升。1欣=3.7公升。">d</a></sup>油調和；</span>
<span className="v" id="v7" data-v="7"> 還要獻上三分之一欣的酒作酒祭，燒獻為馨香之氣給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 3:1; 利未記 7:11–18; 利未記 1:3"> 「當你預備一頭公牛作燔祭或別的祭物獻給耶和華，無論是為了還特殊的願或是作平安祭，</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 28:14; 民數記 28:12; 利未記 6:14"> 都要與公牛一起獻上十分之三伊法<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="十分之三伊法——相當於6.6公升。1伊法=22公升。">e</a></sup>細麵粉為素祭，用半欣<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="半欣——相當於1.9公升。1欣=3.7公升。">f</a></sup>油調和。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 15:5; 民數記 6:15"> 還要獻上半欣的酒為酒祭，作為馨香的火祭獻給耶和華。</span>
<span className="v" id="v11" data-v="11"> 為每頭公牛、每隻公綿羊、每隻綿羊羔或山羊羔，都要這樣預備；</span>
<span className="v" id="v12" data-v="12"> 無論為多少牛羊，都要照著牠們的數量，這樣為每一隻祭牲預備。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 「任何本族人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="本族人——原文直譯「本地人」；本章下同。">g</a></sup>向耶和華獻上馨香的火祭，都要這樣預備。</span>
<span className="v" id="v14" data-v="14"> 如果寄居在你們中間的外人，或世世代代在你們中間的外人，想要向耶和華獻上馨香的火祭，那麼，你們怎樣做，他也要怎樣做。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 9:14; 民數記 15:29; 出埃及記 12:49"> 無論是對你們還是對寄居的外人，會眾要有同一個律例。這是你們世世代代永遠的律例。在耶和華面前，你們怎樣，外人也要怎樣。</span>
<span className="v" id="v16" data-v="16"> 你們和寄居在你們中間的外人，是同一個條例、同一個規定。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華指示摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 15:2; 申命記 26:1–15"> 「你要吩咐以色列子民，對他們說：當你們進入我要帶你們去的那地，</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 5:11–12"> 享用那地的出產時，你們要奉上一份供物給耶和華。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 2:14; 出埃及記 34:26; 申命記 26:2–10"> 你們要用初熟五穀的麵團做餅，作為供物奉上，就像打穀場的供物一樣把它奉上。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 29:28; 民數記 18:26"> 你們世世代代都要從你們初熟五穀的麵團中，把一份供物獻給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 4:2; 利未記 4:27; 利未記 5:15–17"> 「如果你們無意中有了過失，沒有遵行耶和華吩咐摩西的這一切誡命，</span>
<span className="v" id="v23" data-v="23"> 就是耶和華藉著摩西所指示你們的一切——從耶和華指示你們的那天起，之後世世代代，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 4:23; 利未記 4:13–21; 利未記 5:15"> 如果是會眾沒有察覺而無意中有了過失，全體會眾就要獻上一頭公牛為燔祭，作馨香之氣獻給耶和華，並按照規定獻上同獻的素祭和酒祭；還有一隻公山羊為贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:20; 羅馬書 3:25; 希伯來書 2:17"> 祭司要為全體以色列會眾贖罪，他們就得赦免，因為這是無意的過失。他們要為自己無意的過失帶來祭物，就是獻給耶和華的火祭和贖罪祭，帶到耶和華面前。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 15:24"> 全體以色列會眾和寄居在他們中間的外人，都必得赦免，因為這是全體民眾無意的過失。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未記 4:27–28; 使徒行傳 17:30; 使徒行傳 3:17"> 「如果是一個人無意中犯了罪，他就要獻上一隻一歲的母山羊作贖罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 4:35"> 祭司要為那無意中過失犯罪的人贖罪；祭司在耶和華面前為他贖罪，他就必得赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 15:15; 利未記 16:29; 利未記 17:15"> 無論是以色列子孫中的本族人，還是寄居在他們中間的外人，你們無意中有過失的人都是同一個條例。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯來書 10:26; 詩篇 19:13; 申命記 1:43"> 「但狂妄行事的人，無論是本族人或是外人，那人是在褻瀆耶和華，必須從民中被剪除。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 12:9; 箴言 13:13; 以西結書 18:20"> 那人既然藐視耶和華的話語，違背他的誡命，就必須被剪除，他的罪責要歸在自己身上。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及記 35:2–3; 出埃及記 31:14–15; 出埃及記 20:8–10"> 以色列子孫在曠野的時候，人們發現有一個人在安息日撿木柴。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 8:3–20"> 那些發現他在撿木柴的人，就把他帶到摩西和亞倫以及全體會眾那裡。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 24:12; 民數記 9:8"> 他們把他拘押起來，因為還不明確該怎樣處置他。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 7:58; 出埃及記 31:14–15; 列王紀上 21:13"> 耶和華對摩西說：「那人必須被處死，全體會眾要在營地外用石頭砸死他。」</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 7:25"> 於是全體會眾把那人帶到營地外，用石頭砸死了他，正如耶和華所指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和華指示摩西說：</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 23:5; 申命記 22:12; 馬太福音 9:20"> 「你要吩咐以色列子民，告訴他們要世世代代在外衣的衣擺上做繸子，並給衣擺的繸子加上一根藍色的細帶子。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 106:39; 箴言 28:26; 詩篇 73:27"> 你們要這樣做繸子，使你們看見就想起並遵行耶和華的一切誡命，而不隨從自己慣於行淫的欲念和眼目；</span>
<span className="v" id="v40" data-v="40" data-xref="羅馬書 12:1; 帖撒羅尼迦前書 4:7; 利未記 11:44–45"> 也使你們牢記並遵行我的一切誡命，成為聖潔的，歸於你們的神。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得前書 2:9–10; 以西結書 36:25–27; 希伯來書 11:16"> 我是耶和華你們的神，是我把你們從埃及地領了出來，為要作你們的神。我是耶和華你們的神。」</span>
</div>
</div>

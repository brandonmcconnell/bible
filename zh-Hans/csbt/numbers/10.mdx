<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:13; 約珥書 1:14; 詩篇 81:3"> 「你要製作兩支銀號筒，用錘擛工藝製作，用來聚集會眾，也用來拔營起行。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 4:5; 約珥書 2:15–16"> 當兩支號筒吹響時，全體會眾要到你那裡，在會幕入口集合；</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 7:2; 出埃及記 18:21; 民數記 1:4–16"> 如果只吹響一支，領袖們，就是以色列千軍的首領，要到你那裡集合。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 2:3–9; 民數記 10:14; 以賽亞書 58:1"> 「當你們吹響警號時，紮營在東面的營隊要起行。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 10:18; 民數記 2:10–16"> 當你們第二次吹響警號時，紮營在南面的營隊要起行。讓會眾起程時，要吹響警號，</span>
<span className="v" id="v7" data-v="7" data-xref="約珥書 2:1; 民數記 10:3–4"> 招聚會眾時也要吹號，但不要吹警號。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 6:4–16; 民數記 31:6; 歷代志上 15:24"> 那些作祭司的亞倫子孫要吹響號筒。這要作為你們世世代代永遠的律例。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 10:18; 士師記 2:18; 創世記 8:1"> 「當你們在自己的土地上，與擾害你們的敵人作戰時，你們要用號筒吹警號。這樣，你們就能在你們的神耶和華面前蒙記念，得拯救，脫離你們的仇敵。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 81:3; 帖撒羅尼迦前書 4:16; 哥林多前書 11:24–26"> 在你們喜樂的日子和所定的節期，以及月初，你們要為你們的燔祭和平安祭吹響號筒。這樣，它們就使你們在你們的神面前蒙記念。我是耶和華你們的神。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:17; 民數記 1:1; 民數記 9:11"> 到了第二年的二月二十日，雲彩從見證帳幕上方收上去了；</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 21:21; 民數記 12:16; 民數記 9:5"> 以色列子民從西奈曠野起行，一程一程地前行，雲彩到帕蘭曠野就停住了。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 1:6; 民數記 9:23"> 這是他們第一次按照耶和華藉著摩西所指示的起行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 2:3–9; 民數記 1:7; 民數記 7:12"> 首先按隊伍起行的，是猶大子孫營隊的旗幟。統領猶大隊伍的，是亞米拿達的兒子拿順；</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 7:18; 民數記 1:8"> 統領以薩迦支派隊伍的，是蘇押的兒子拿旦業。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 7:24; 民數記 1:9"> 統領西布倫支派隊伍的，是希倫的兒子以利押。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 7:6–8; 民數記 1:51; 希伯來書 12:28"> 然後，帳幕被拆下來，革順的子孫和米拉利的子孫抬著帳幕起行。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 2:10–16; 民數記 1:5; 民數記 26:5–18"> 接著按隊伍起行的，是魯本營隊的旗幟。統領魯本隊伍的，是謝德珥的兒子以利佐；</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:6; 民數記 7:36"> 統領西緬支派隊伍的，是蘇利沙代的兒子謝路米業；</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:14; 民數記 2:14; 民數記 7:42"> 統領迦得支派隊伍的，是德珥的兒子以利雅薩。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 10:17; 民數記 7:9; 民數記 4:4–16"> 然後，哥轄人抬著聖物起行，帳幕要在他們到達之前立起來。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 2:18–24; 民數記 1:10; 民數記 26:23–41"> 接著按隊伍起行的，是以法蓮子孫營隊的旗幟。統領以法蓮隊伍的，是亞米忽的兒子以利沙瑪；</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:10; 民數記 7:54"> 統領瑪拿西支派隊伍的，是佩達佐的兒子迦瑪列；</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 1:11; 民數記 7:60"> 統領便雅憫支派隊伍的，是基多尼的兒子亞比但。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:9; 民數記 1:12; 創世記 49:16–17"> 最後按隊伍起行的，是但子孫營隊的旗幟，他們作全營的後衛隊。統領他們隊伍的，是亞米沙代的兒子亞希以謝；</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:13; 民數記 7:72"> 統領亞設支派隊伍的，是俄蘭的兒子帕結；</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:15; 民數記 7:78"> 統領拿弗他利支派隊伍的，是恩南的兒子亞希拉。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 2:34; 民數記 24:4–5; 哥林多前書 14:33"> 以上是以色列子孫按著隊伍的起程次序，他們就這樣起行。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 12:7; 士師記 4:11; 出埃及記 3:1"> 那時，摩西對他岳父米甸人流珥的兒子何巴說：「我們要起行，去耶和華所說『我要將它賜給你們』的那個地方，請你與我們一起去，我們會厚待你，耶和華已經向以色列應許了福份。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路得記 1:15–17; 詩篇 45:10; 馬太福音 21:29"> 何巴回答說：「我不去，我寧願回我本地本族去。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約伯記 29:15; 加拉太書 6:2; 哥林多前書 12:14–21"> 摩西說：「請不要離開我們，因為你了解曠野紮營的地方，可以作我們的嚮導<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="嚮導——原文直譯「眼睛」。">a</a></sup>；</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:16; 申命記 10:18; 約翰一書 1:3"> 而且如果你與我們一起去，將來耶和華賜下福份，使我們蒙福，我們也必使你一同蒙福。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 1:33; 出埃及記 3:1; 詩篇 95:11"> 於是，他們離開耶和華的山，前行了三天的路程。這三天的路程中，耶和華的約櫃一直在他們前頭前行，為他們尋找安歇的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 9:12; 尼希米記 9:19; 詩篇 105:39"> 他們從營地起行，白天總有耶和華的雲彩在他們上方。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="詩篇 68:1–2; 以賽亞書 17:12–14; 詩篇 132:8"> 每當約櫃起行時，摩西就說：<br /><span className="pl pl-1">「耶和華啊，求你起來！</span><br /><span className="pl pl-1">願你的仇敵四散，</span><br /><span className="pl pl-1">願那些恨你的人從你面前奔逃！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36" data-xref="申命記 1:10; 詩篇 90:13–17; 以賽亞書 63:17"> 每當約櫃停下來，他就說：<br /><span className="pl pl-1">「耶和華啊，</span><br /><span className="pl pl-1">求你回到千千萬萬以色列人當中</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶和華啊，求你回到千千萬萬以色列人當中——或譯作「耶和華，以色列的萬軍啊，求你回來」。">b</a></sup><br /><span className="pl pl-1">！」</span></span>
</div>
</div>

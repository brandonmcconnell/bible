<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="猶大書 1:11; 申命記 11:6; 出埃及記 6:21"> 以斯哈的兒子可拉，是利未之子哥轄的孫子，他帶著魯本子孫以利押的兒子大坍和亞比蘭，以及比勒的兒子奧恩，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 26:9; 以西結書 23:10; 創世記 6:4"> 起來對抗摩西，隨同他們的還有以色列子孫中的兩百五十人，都是議會選召出來的會眾領袖，是有名望的人。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 106:16; 民數記 14:14; 出埃及記 19:6"> 他們聚集起來對抗摩西和亞倫，說：「你們僭越了！其實全體會眾每一個都是聖潔的，耶和華也與他們同在，你們為何高抬自己，站在耶和華的會眾之上呢？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民數記 14:5; 民數記 20:6; 約書亞記 7:6"> 摩西聽見了，就臉伏於地。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 65:4; 民數記 17:5; 提摩太後書 2:19"> 他對可拉和可拉的所有同黨說：「明天早晨，耶和華會顯明誰是屬於他的，誰是分別為聖的，他會讓那人親近他，讓他所揀選的人親近他。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 10:1; 民數記 16:46–48; 列王紀上 18:21–23"> 你們要這樣做：可拉和可拉的所有同黨，你們拿來香爐，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 16:3; 以弗所書 1:4; 列王紀上 18:17–18"> 明天在耶和華面前，給香爐裡盛上火，加上香。那時，耶和華揀選了誰，誰就是分別為聖的。利未的子孫哪，是你們僭越了！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 摩西又對可拉說：「利未的子孫哪，你們聽著！</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 7:13; 申命記 10:8; 以西結書 44:10–11"> 以色列的神將你們從以色列會眾當中分別出來，讓你們親近他，做耶和華帳幕的服事工作，並站在會眾面前事奉他們，這對你們是小事嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 約翰三書 1:9; 民數記 18:7"> 耶和華讓你和你所有的弟兄，就是與你一起的利未子孫，都親近他，現在你們還想謀求祭司的職份嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 16:7–8; 出埃及記 17:2; 民數記 16:3"> 其實，你和你所有的同黨聚集起來是在敵對耶和華！亞倫算什麼，你們竟然向他發怨言？」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 2:13–14; 猶大書 1:8; 箴言 29:9"> 摩西派人去把以利押的兒子大坍和亞比蘭召來，他們卻說：「我們不過去。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:35; 出埃及記 2:14; 民數記 11:5"> 你把我們從流奶與蜜之地帶上來，讓我們死在曠野，這算小事嗎？你還想自立為王統治我們！</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:24; 民數記 36:8–10; 民數記 20:5"> 況且，你並沒有把我們領到流奶與蜜之地，也沒有賜給我們田地和葡萄園為繼業。難道你想剜出我們這些人的眼睛嗎？我們不過去！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 4:4–5; 哥林多後書 7:2; 帖撒羅尼迦前書 2:10"> 摩西就非常惱火，他對耶和華說：「求你不要悅納他們的供物。我並沒有奪走過他們一頭驢子，也沒有傷害過他們任何一人。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 12:3; 撒母耳記上 12:7; 提摩太後書 2:14"> 摩西對可拉說：「明天你和你的所有同黨都要到耶和華面前，你和他們，還有亞倫都要在場。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 12:7"> 你們各自拿來香爐，放上香。他們各人要在耶和華面前呈上自己的香爐，共兩百五十個香爐，你和亞倫也要呈上自己的香爐。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 於是他們各自拿來香爐，給香爐裡盛上火，加上香，與摩西和亞倫一起站在會幕入口。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 14:10; 民數記 16:42; 出埃及記 16:7"> 可拉把全體會眾都招聚到會幕入口，對抗摩西和亞倫。那時，耶和華的榮耀向全體會眾顯現，</span>
<span className="v" id="v20" data-v="20"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:45; 出埃及記 32:10; 詩篇 73:19"> 「你們從這會眾當中分離出來，我要一瞬間消滅他們！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 27:16; 撒迦利亞書 12:1; 約伯記 12:10"> 摩西和亞倫就臉伏於地，說：「神哪，使一切肉體有氣息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使一切肉體有氣息——或譯作「賜予全人類氣息」。">a</a></sup>的神！一個人犯罪，你就對全體會眾發怒嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 於是，耶和華指示摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 16:21"> 「你要吩咐會眾說：你們都從可拉、大坍和亞比蘭的帳幕周圍離開！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 11:16–17; 民數記 11:25; 民數記 11:30"> 於是摩西起來，到大坍和亞比蘭那裡去，以色列的長老們跟隨著他。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 52:11; 哥林多後書 6:17; 啟示錄 18:4"> 他告訴會眾說：「你們要遠離這些惡人的帳篷，不要碰任何屬於他們的東西，免得你們因他們的一切罪惡而被除滅。」</span>
<span className="v" id="v27" data-v="27" data-xref="約伯記 9:4; 以賽亞書 28:14; 約伯記 40:10–11"> 會眾就從可拉、大坍、亞比蘭的帳篷四圍離開了。大坍和亞比蘭，還有他們的妻子、兒女和孩童都出來，站在他們的帳篷入口。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:38; 出埃及記 3:12; 約翰福音 14:11"> 摩西說：「藉著這事，你們必知道，是耶和華派遣了我來做這一切工作，而不是我隨從自己的心意做事。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王紀上 22:28; 出埃及記 32:34"> 如果這些人的死如世人的死，他們的遭遇如世人的遭遇，耶和華就沒有派遣我。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 55:15; 民數記 16:33; 約伯記 31:3"> 但如果耶和華行一件新事，使地張口吞掉他們和屬於他們的一切，使他們活活地下到陰間，你們就明白：這些人確實藐視了耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 106:17–18; 民數記 27:3; 申命記 11:6"> 他剛說完這一切話，那些人脚下的土地就裂開了。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:17; 民數記 26:11; 啟示錄 12:16"> 地張口吞掉他們和他們的家人，以及所有屬於可拉的人和財物。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 32:18; 以賽亞書 14:9; 詩篇 9:15"> 他們和所有屬於他們的，都活活地下到陰間，地掩埋了他們，他們就從會眾當中消失了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 14:5; 以賽亞書 33:3; 啟示錄 6:15–17"> 因他們的叫聲周圍所有的以色列人都逃跑了，他們說：「恐怕地要把我們也吞掉了！」</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 26:10; 利未記 10:2; 詩篇 106:18"> 還有火從耶和華那裡出來，吞滅了那兩百五十個呈上香的人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此節至17:13在馬索拉文本為17:1至17:28。">b</a></sup>耶和華指示摩西說：</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 27:28; 民數記 16:18; 民數記 16:7"> 「你要吩咐祭司亞倫的兒子以利亞撒，讓他從燃燒的火中拿起那些香爐，將火撒在遠處，因為那些香爐都分別為聖了。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 26:10; 以西結書 14:8; 彼得後書 2:6"> 至於那些犯罪喪命之人的香爐，要錘成薄片，用來包祭壇，因為這些香爐已經被獻在耶和華面前，分別為聖了；它們要給以色列子孫作鑒戒。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 於是，祭司以利亞撒取來那些被燒死的人所獻的銅香爐，人們把香爐錘成薄片，用來包祭壇，</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 3:10; 民數記 18:4–7; 歷代志下 26:16–21"> 為以色列子孫作記念，免得那不屬於亞倫後裔的外人靠近耶和華面前燒香，以致有可拉和他的同黨一樣的遭遇。這都是照耶和華藉著摩西所吩咐以利亞撒的。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 16:1–7; 詩篇 106:23; 民數記 14:2"> 但第二天，全體以色列會眾向摩西和亞倫發怨言，說：「你們殺了耶和華的子民！」</span>
<span className="v" id="v42" data-v="42" data-xref="民數記 16:19; 利未記 9:23; 民數記 20:6"> 正當會眾聚集起來對抗摩西和亞倫的時候，他們轉向會幕，看哪，雲彩遮蓋會幕，耶和華的榮耀顯現了。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 摩西和亞倫來到會幕前面，</span>
<span className="v" id="v44" data-v="44"> 耶和華指示摩西說：</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 16:21–22; 民數記 16:24; 民數記 20:6"> 「你們從這會眾當中離開，我要一瞬間消滅他們！」摩西和亞倫就臉伏於地。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="民數記 8:19; 歷代志上 27:24; 利未記 10:6"> 摩西對亞倫說：「你拿來香爐，香爐裡盛上祭壇的火，加上香，趕快到會眾那裡去，為他們贖罪，因為有震怒從耶和華面前發出，瘟疫已經開始了。」</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="馬太福音 5:44; 申命記 33:10–11; 詩篇 106:29"> 亞倫照著摩西所說的拿來香爐，跑到會眾當中。看哪，瘟疫已經在子民中開始了！他就呈上香<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="呈上香——或譯作「給香爐放上香」。">c</a></sup>，為子民贖罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳記下 24:25; 希伯來書 7:24–25; 民數記 16:18"> 他站在死人和活人之間，瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 25:9; 民數記 16:32–35; 希伯來書 2:1–3"> 除了因可拉事件而死的人以外，死於瘟疫的有一萬四千七百人。</span>
<span className="v" id="v50" data-v="50" data-xref="歷代志上 21:26–30; 民數記 16:43"> 亞倫回到會幕入口摩西那裡，瘟疫已經止住了。</span>
</div>
</div>

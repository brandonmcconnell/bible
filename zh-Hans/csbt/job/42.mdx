<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 約伯回答耶和華，說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 19:26; 馬可福音 10:27; 創世記 18:14"> <span className="pl pl-1">「我知道你凡事都能做，</span><br /><span className="pl pl-1">你的計劃無可攔阻。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 131:1; 詩篇 139:6; 約伯記 38:2"> <span className="pl pl-1">你問</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你問——輔助詞語。">a</a></sup><br /><span className="pl pl-1">是誰用無知隱藏你的旨意，</span><br /><span className="pl pl-1">確實，我述說了我不明白的事，</span><br /><span className="pl pl-1">這些對我太過奇妙，我無法領悟。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 40:7; 約伯記 38:3; 創世記 18:30–32"> <span className="pl pl-1">你說</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你說——輔助詞語。">b</a></sup><br /><span className="pl pl-1">『請聽我說話，</span><br /><span className="pl pl-1">我問你，你來指示我！』</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 1:17–18; 羅馬書 10:17; 約翰福音 12:45"> <span className="pl pl-1">我從前風聞有你，</span><br /><span className="pl pl-1">現在卻親眼看見你。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 9:6; 提摩太前書 1:13–16; 雅各書 4:7–10"> <span className="pl pl-1">因此我厭棄自己，</span><br /><span className="pl pl-1">在塵土和灰燼中懊悔！」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約伯記 11:5–6; 約伯記 32:2–3; 約伯記 32:5"> 耶和華對約伯說了這些話以後，又對提幔人以利法說：「我向你和你的兩個朋友發怒，因為你們沒有正確地講論我，不像我的僕人約伯說的那樣。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:1; 雅各書 5:16; 詩篇 103:10"> 現在，你們要帶七頭公牛、七隻公綿羊，到我僕人約伯那裡去，為自己獻上燔祭。我的僕人約伯會為你們禱告，我必悅納他，不按你們的愚頑對待你們。因為你們沒有正確地講論我，不像我的僕人約伯說的那樣。」</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 11:8; 使徒行傳 9:6; 使徒行傳 10:33"> 於是提幔人以利法、書亞人比勒達和拿瑪人佐法爾就去，照著耶和華吩咐他們的做了。耶和華就悅納約伯。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 30:3; 約伯記 8:6–7; 箴言 22:4"> 約伯為他的朋友禱告後，耶和華恢復了約伯的家業，並且耶和華使約伯所擁有的一切加倍增添。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 2:11; 約伯記 19:13–14; 箴言 16:7"> 約伯所有的兄弟姐妹以及所有以前認識他的人，都來看他，並在他家裡與他一同吃飯。他們勸慰他，因耶和華降給他的一切災禍而安慰他。每人還送給他一份銀錢和一個金環。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約伯記 8:7; 傳道書 7:8; 箴言 10:22"> 這樣，耶和華後來賜福給約伯的比先前更多：他有一萬四千隻羊，六千匹駱駝，一千對牛和一千頭母驢。</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 1:2; 詩篇 107:41; 詩篇 127:3"> 他又有了七個兒子，三個女兒。</span>
<span className="v" id="v14" data-v="14"> 他給第一個女兒起名為耶美瑪，第二個女兒起名為克希婭，第三個女兒起名為卡蓮哈樸。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 27:7; 詩篇 144:12; 使徒行傳 7:20"> 全地都找不到像約伯的女兒那樣美貌的女子，而且她們的父親使她們與兄弟們同分繼業。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 17:6; 詩篇 128:6; 創世記 50:23"> 這事以後，約伯又活了一百四十年，得見他的兒孫，直到四代。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 25:8; 創世記 15:15; 約伯記 5:26"> 約伯年邁，壽數滿足而死。</span>
</div>
</div>

</div>

<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="約伯記 30:1; 約伯記 17:6; 詩篇 91:15"> <span className="pl pl-1">我這呼求神、蒙神回應的人，</span><br /><span className="pl pl-1">竟然成了朋友的笑柄；</span><br /><span className="pl pl-1">公義、純全的人，竟然成了笑柄！</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 25:8; 箴言 13:9; 詩篇 17:5"> <span className="pl pl-1">安逸的人心裡藐視災禍，</span><br /><span className="pl pl-1">以為那是失腳滑倒之人的命運。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 9:24; 詩篇 73:11–12; 詩篇 17:14"> <span className="pl pl-1">行毀滅之人的帳篷安穩，</span><br /><span className="pl pl-1">惹怒神的人也安全——</span><br /><span className="pl pl-1">神把他們捧在自己手中</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神把他們捧在自己手中——或譯作「他們手中捧著神明」。">a</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:3; 箴言 6:6; 耶利米書 8:7"> <span className="pl pl-1">請問問走獸，牠們必指示你；</span><br /><span className="pl pl-1">問問天空的飛鳥，牠們必告訴你。</span><br /></span>
<span className="v" id="v8" data-v="8"> <span className="pl pl-1">或與大地談論，它必指教你；</span><br /><span className="pl pl-1">海裡的魚也必向你陳明。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 41:20; 耶利米書 27:5–6; 羅馬書 11:36"> <span className="pl pl-1">牠們當中，</span><br /><span className="pl pl-1">誰不知道這是耶和華的手所做的？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:28; 約伯記 33:4; 使徒行傳 17:25"> <span className="pl pl-1">一切活物的生命，</span><br /><span className="pl pl-1">一切血肉之人的氣息都在他手中。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 34:3; 希伯來書 5:14; 約伯記 6:30"> <span className="pl pl-1">耳朵怎能不察驗言詞，</span><br /><span className="pl pl-1">唇齒怎能不品嘗食物？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 32:7; 約伯記 15:10; 約伯記 8:8"> <span className="pl pl-1">難道年老的就有智慧，</span><br /><span className="pl pl-1">長壽的就有見識嗎？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="約伯記 9:4; 約伯記 36:5; 箴言 2:6–7"> <span className="pl pl-1">智慧和大能全在於他，</span><br /><span className="pl pl-1">謀略和見識也屬於他。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 3:7; 以賽亞書 22:22; 瑪拉基書 1:4"> <span className="pl pl-1">看哪，他拆毀，就不得重建；</span><br /><span className="pl pl-1">他拘禁人，就不得釋放。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 17:1; 阿摩司書 5:8; 創世記 6:13"> <span className="pl pl-1">看哪，他止住水，水就枯竭；</span><br /><span className="pl pl-1">他放出水，水就淹沒大地。</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="以賽亞書 29:14; 哥林多前書 1:19–20; 撒母耳記下 17:23"> <span className="pl pl-1">他使謀士赤身被擄，</span><br /><span className="pl pl-1">使審判官變得愚妄。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 2:21; 詩篇 116:16; 歷代志下 33:11–14"> <span className="pl pl-1">他解開君王們的玉帶</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="解開君王們的玉帶——或譯作「解除君王們的轄制」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">用束帶捆住他們的腰。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 45:1; 以賽亞書 37:36–38; 啟示錄 17:14"> <span className="pl pl-1">他使祭司赤身被帶走，</span><br /><span className="pl pl-1">推翻有權勢的人。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 32:9; 約伯記 17:4; 約伯記 12:24"> <span className="pl pl-1">他廢除忠臣的言語，</span><br /><span className="pl pl-1">奪去長老的見識。</span><br /></span>

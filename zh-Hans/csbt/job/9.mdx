<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 約伯回答說：</span>
<span className="v" id="v2" data-v="2" data-xref="約伯記 4:17; 羅馬書 3:20; 約伯記 25:4"> <span className="pl pl-1">「我知道事情確實如此，</span><br /><span className="pl pl-1">世人怎能在神面前顯為義呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 10:2; 約伯記 40:2; 以賽亞書 57:15–16"> <span className="pl pl-1">人如果想與神爭論，</span><br /><span className="pl pl-1">千次回答不了一次。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 36:5; 羅馬書 11:33; 以弗所書 3:20"> <span className="pl pl-1">神心裡有智慧，能力強大，</span><br /><span className="pl pl-1">誰能對抗他還平安無事呢？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 27:51; 路加福音 21:11; 哈巴谷書 3:10"> <span className="pl pl-1">他使群山移開，山卻不知道：</span><br /><span className="pl pl-1">他在怒氣中把它們傾覆。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="哈該書 2:6; 希伯來書 12:26; 詩篇 75:3"> <span className="pl pl-1">他使大地顫抖離開原處，</span><br /><span className="pl pl-1">地的基柱就搖撼。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 13:10; 阿摩司書 8:9; 路加福音 21:25–26"> <span className="pl pl-1">他一下令，太陽就不顯現，</span><br /><span className="pl pl-1">他還封印星辰；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 44:24; 以賽亞書 40:22; 詩篇 104:2–3"> <span className="pl pl-1">他獨自鋪展諸天，</span><br /><span className="pl pl-1">踏行海浪之上；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 5:8; 創世記 1:16; 約伯記 38:31–41"> <span className="pl pl-1">他造北斗、參星和昴星，</span><br /><span className="pl pl-1">以及南方的星宿；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 5:9; 詩篇 72:18; 以弗所書 3:20"> <span className="pl pl-1">他行大事無法測度，</span><br /><span className="pl pl-1">行奇事無法數算。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 23:8–9; 約伯記 35:14; 詩篇 77:19"> <span className="pl pl-1">看哪，他從我旁邊經過，我卻看不見；</span><br /><span className="pl pl-1">他掠過，我也不察覺。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 45:9; 約伯記 11:10; 約伯記 23:13"> <span className="pl pl-1">他奪去時，誰能阻攔他？</span><br /><span className="pl pl-1">誰能對他說：『你在做什麼？』</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 89:10; 約伯記 26:12; 以賽亞書 30:7"> <span className="pl pl-1">神必不收回他的怒氣，</span><br /><span className="pl pl-1">拉哈伯的幫助者們必屈身在他腳下。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 8:27; 約伯記 9:3; 約伯記 4:19"> <span className="pl pl-1">所以，我怎麼敢反駁他呢？</span><br /><span className="pl pl-1">我怎麼敢挑選言詞與他辯論？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 10:15; 約伯記 8:5; 約伯記 10:2"> <span className="pl pl-1">即使我是對的，也不敢反駁，</span><br /><span className="pl pl-1">只能向我的審判者懇求。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 29:24; 出埃及記 6:9; 詩篇 66:18–20"> <span className="pl pl-1">即使我呼喊了，並且他回應我，</span><br /><span className="pl pl-1">我也不相信他會傾聽我的聲音。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 16:14; 約伯記 2:3; 約伯記 34:6"> <span className="pl pl-1">他用暴風摧殘我，</span><br /><span className="pl pl-1">無故增多我的創傷。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 7:19; 耶利米哀歌 3:15; 詩篇 88:15–18"> <span className="pl pl-1">他不允許我喘一口氣，</span><br /><span className="pl pl-1">而是讓我吃盡苦頭。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 9:32–33; 約伯記 9:4; 哥林多前書 1:25"> <span className="pl pl-1">如果論能力，看，他多麼強大！</span><br /><span className="pl pl-1">如果論審判，他說</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他說——輔助詞語。">a</a></sup><br /><span className="pl pl-1">：『誰能傳喚我？』</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 15:5–6; 腓立比書 3:12–15; 詩篇 143:2"> <span className="pl pl-1">即使我是對的，</span><br /><span className="pl pl-1">我開口就使我被定為有罪；</span><br /><span className="pl pl-1">即使我是純全的，</span><br /><span className="pl pl-1">我開口就使我成為悖謬的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="約伯記 1:1; 詩篇 139:23–24; 箴言 28:26"> <span className="pl pl-1">我是純全的，</span><br /><span className="pl pl-1">但我不顧</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="顧——或譯作「認識」。">b</a></sup><br /><span className="pl pl-1">我自己了，</span><br /><span className="pl pl-1">我厭棄我的性命。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="傳道書 9:1–3; 路加福音 13:2–4; 約伯記 10:8"> <span className="pl pl-1">反正都一樣！因此我說：</span><br /><span className="pl pl-1">『純全人和惡人，他都要滅絕。』</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 24:12; 約伯記 1:13–19; 約伯記 4:7"> <span className="pl pl-1">如果突來橫禍使人死亡，</span><br /><span className="pl pl-1">他就嘲笑清正的人的遭遇。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 10:3; 耶利米書 12:1–2; 詩篇 73:3–7"> <span className="pl pl-1">世界被交在惡人手中，</span><br /><span className="pl pl-1">他遮蔽了審判官們的臉——</span><br /><span className="pl pl-1">如果不是他，還能是誰呢？</span></span>

<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="約伯記 7:6–7; 雅各書 4:14; 詩篇 90:9–10"> <span className="pl pl-1">我的年日比信使更快，</span><br /><span className="pl pl-1">飛逝而去，不見福樂。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="哈巴谷書 1:8; 以賽亞書 18:2; 約伯記 39:27–30"> <span className="pl pl-1">我的年日如蘆葦舟掠過，</span><br /><span className="pl pl-1">如鷹向獵物疾飛。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="約伯記 7:13; 耶利米書 8:18; 約伯記 7:11"> <span className="pl pl-1">如果我說『我要忘記我的苦情，</span><br /><span className="pl pl-1">除去我的愁容，得以歡愉』，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 119:120; 詩篇 88:15–16; 約伯記 21:6"> <span className="pl pl-1">我就因我所有的愁苦而懼怕，</span><br /><span className="pl pl-1">我知道你不會讓我免於罪罰。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 10:7; 約伯記 21:27; 約伯記 10:14–17"> <span className="pl pl-1">既然我被定為有罪，</span><br /><span className="pl pl-1">我何必這樣徒勞呢？</span><br /></span>

<div className="bp poetry">

<span className="v" id="v8" data-v="8"> <span className="pl pl-1">狂傲的野獸未曾踏過，</span><br /><span className="pl pl-1">凶猛的獅子未曾經過。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="那鴻書 1:4–6"> <span className="pl pl-1">人下手開鑿堅石，</span><br /><span className="pl pl-1">把群山從山根翻轉，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哈巴谷書 3:9; 箴言 14:23; 箴言 24:4"> <span className="pl pl-1">在磐石中鑿出水道</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="水道——或譯作「坑道」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他的眼就看見各樣寶物。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 4:5; 以賽亞書 45:2–3; 以賽亞書 44:27"> <span className="pl pl-1">他封住滲漏的河水，</span><br /><span className="pl pl-1">隱祕之物就顯露出來。</span></span>

<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="箴言 2:4–6; 約伯記 28:20; 雅各書 1:5"> <span className="pl pl-1">然而，智慧何處可尋，</span><br /><span className="pl pl-1">哪裡才是悟性的所在呢？</span><br /></span>

<span className="v" id="v18" data-v="18" data-xref="箴言 3:15; 箴言 31:10; 耶利米哀歌 4:7"> <span className="pl pl-1">珊瑚和水晶不值一提，</span><br /><span className="pl pl-1">智慧的價值超過紅寶石。</span><br /></span>

</div>
<div className="bp poetry">

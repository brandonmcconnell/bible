<span className="v" id="v1" data-v="1" data-xref="約伯記 10:7; 約伯記 33:9; 約伯記 10:2"> 於是這三個人停止回應約伯，因為他自視為義。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 22:21; 約伯記 40:8; 約伯記 27:2"> 布西人蘭家族巴拉迦的兒子以利戶就怒氣發作，向約伯發怒，因約伯自以為義，不以神為義；</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 8:6; 約伯記 24:25; 約伯記 22:5–30"> 他的怒氣也向約伯的三個朋友發作，因為他們雖然定約伯有罪，卻無話回答約伯。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約伯記 32:11–12; 箴言 18:13"> 以利戶一直等候要向約伯說話，因為他們都比他年老。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 32:2; 出埃及記 32:19"> 當他看到三人都口中無話可說，他就怒氣發作。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="約伯記 15:10; 提摩太前書 5:1; 提多書 2:6"> 布西人巴拉迦的兒子以利戶回應說：<br /><span className="pl pl-1">「我年輕，你們年老，</span><br /><span className="pl pl-1">因此我膽怯害怕，</span><br /><span className="pl pl-1">不敢向你們陳述我的意見。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 16:31; 約伯記 12:12; 希伯來書 5:12"> <span className="pl pl-1">我原本想，</span><br /><span className="pl pl-1">應當讓年長者說話，</span><br /><span className="pl pl-1">讓年歲大的教導人智慧。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 38:36; 約伯記 33:4; 提摩太後書 3:16"> <span className="pl pl-1">然而，是人裡面的靈，</span><br /><span className="pl pl-1">是全能者的氣息使人有悟性；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:25; 約伯記 12:20; 傳道書 4:13"> <span className="pl pl-1">而不是年紀大就有智慧，</span><br /><span className="pl pl-1">也不是年老就明辨是非。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:25; 哥林多前書 7:40"> <span className="pl pl-1">因此我說：請你們聽我，</span><br /><span className="pl pl-1">我也要陳述我的意見。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 29:21; 約伯記 5:27; 箴言 28:11"> <span className="pl pl-1">看哪，我等候你們的話語；</span><br /><span className="pl pl-1">我要傾聽你們的智慧，</span><br /><span className="pl pl-1">直到你們找到合適的言詞。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 32:3; 提摩太前書 1:7"> <span className="pl pl-1">我留心聽你們，</span><br /><span className="pl pl-1">看哪，你們竟無人能駁倒約伯，</span><br /><span className="pl pl-1">回答他的話。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 9:23; 哥林多前書 1:27–29; 哥林多前書 3:18"> <span className="pl pl-1">切不可說：『我們已經找到智慧，</span><br /><span className="pl pl-1">只有神能折服約伯，人是不能的！』</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">約伯並沒有與我爭辯，</span><br /><span className="pl pl-1">我也不用你們的話回答他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="約伯記 6:24–25; 馬太福音 22:46; 約伯記 29:22"> <span className="pl pl-1">他們驚惶，不再回答，</span><br /><span className="pl pl-1">他們無話可說。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 1:19; 約伯記 13:5; 阿摩司書 5:13"> <span className="pl pl-1">然而，因他們不說話，</span><br /><span className="pl pl-1">已經停住不再回答，</span><br /><span className="pl pl-1">我就要一直等候嗎？</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 35:3–4; 約伯記 33:12; 約伯記 32:10"> <span className="pl pl-1">我也要給出我的一份回答，</span><br /><span className="pl pl-1">我也要陳述我的意見。</span><br /></span>

<span className="v" id="v22" data-v="22" data-xref="詩篇 12:2–3; 帖撒羅尼迦前書 2:5; 箴言 29:5"> <span className="pl pl-1">因為我不明白如何奉承，</span><br /><span className="pl pl-1">不然，我的創造主</span><br /><span className="pl pl-1">必片刻間把我取走。</span></span>

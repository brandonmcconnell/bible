<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 24:1–51; 以西結書 11:22–23; 以西結書 10:19"> 耶穌走出聖殿的時候，他的一個門徒對他說：「老師，你看！多好的石頭，多好的建築啊！」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:6; 馬太福音 24:2; 列王紀上 9:7–8"> 耶穌對他說：<span className="woj">「你在看這些雄偉的建築嗎？這裡將絕不會有一塊石頭留在另一塊石頭上而不被拆下。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 21:1; 馬可福音 4:34; 馬可福音 14:33"> 耶穌在橄欖山上，面對聖殿坐著。彼得、雅各、約翰和安得烈悄悄地問他：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 1:6–7; 馬太福音 24:3; 但以理書 12:6"> 「請告訴我們，這些事什麼時候會發生呢？這一切將要成就的時候，會有什麼預兆呢？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 2:8; 以弗所書 5:6; 耶利米書 29:8"> 耶穌就開始對他們說：<span className="woj">「你們要當心，免得有人迷惑你們。</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:22; 耶利米書 23:21–25; 約翰福音 8:24"> <span className="woj">許多人會以我的名而來，聲稱『我就是那一位</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我就是那一位——原文直譯「我就是」或「我永在」。">a</a></sup><span className="woj">』，並且會迷惑許多人。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 約翰福音 14:27; 馬太福音 24:6–7"> <span className="woj">當你們聽見戰爭和戰爭消息的時候，不可驚慌。這些事必須發生，不過結局還沒有到。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 24:8; 以賽亞書 37:3; 詩篇 48:6"> <span className="woj">一個民族要起來反對另一個民族，一個國家要起來反對另一個國家；到處都會有地震和饑荒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「和動亂」。">b</a></sup><span className="woj">。這些都像臨產陣痛的開始。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 10:17–18; 約翰福音 16:2; 腓立比書 1:29"> <span className="woj">「你們自己要當心。他們將要把你們送交議會；你們會在會堂裡受鞭打。為我的緣故，你們將站在總督和君王面前，好對他們做見證。</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 24:14; 歌羅西書 1:23; 羅馬書 10:18"> <span className="woj">然而，福音必須先傳給萬國。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 馬太福音 10:19–21"> <span className="woj">當他們把你們交出去、帶走的時候，不要預先憂慮</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「或考慮」。">c</a></sup><span className="woj">說什麼。到時候，你們被賜予什麼話，就說什麼話，因為說話的不是你們自己，而是聖靈。</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> <span className="woj">兄弟將要把兄弟出賣，置於死地；父親對孩子也會這樣。兒女會起來與父母作對，並且害死他們。</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:18–19; 馬太福音 10:22; 馬太福音 24:13"> <span className="woj">為了我的名，你們將被所有的人憎恨，但是忍耐到底的，這個人將會得救。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:27; 但以理書 12:11; 但以理書 11:31"> <span className="woj">「當你們看見</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「先知但以理所說的」。">d</a></sup><span className="woj">『那帶來毀滅的褻瀆者</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="褻瀆者——或譯作「褻瀆之物」。">e</a></sup><span className="woj">』</span><span className="woj">站在不該站的地方時</span>——讀者應當思考——<span className="woj">那時，在猶太的人應當逃到山裡；</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯來書 11:7; 腓立比書 3:7–8"> <span className="woj">在屋頂上的人，不要下來</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「到屋子裡去」。">f</a></sup><span className="woj">，也不要進屋子裡去拿什麼東西；</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">在田裡的人，不要轉回到背後的事上，去拿自己的衣服。</span></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿書 9:14"> <span className="woj">在那些日子裡，孕婦和哺乳的女人有禍了！</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">你們要禱告，好讓這事</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="這事——有古抄本作「你們逃難的時候」。">g</a></sup><span className="woj">不在冬天發生，</span></span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 12:1; 約珥書 2:2; 馬太福音 24:21"> <span className="woj">因為在那些日子裡將有患難。這樣的患難從神創世之初直到如今，從來沒有發生過，也絕不再發生。</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:22; 撒迦利亞書 13:8–9; 以賽亞書 65:8–9"> <span className="woj">如果不是主減少了那些日子，就沒有一個人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="人——原文直譯「肉體」。">h</a></sup><span className="woj">能得救。然而，為了那些蒙揀選的人，就是他所揀選的，他減少了那些日子。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 馬太福音 24:23–25; 馬太福音 24:5"> <span className="woj">「那時候，如果有人對你們說『看哪，基督在這裡！』『看哪，他在那裡！』你們不要相信。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 24:24; 帖撒羅尼迦後書 2:8–14; 馬可福音 13:6"> <span className="woj">因為假基督們和假先知們會出現，行神蹟和奇事，如果有可能，甚至迷惑那些蒙揀選的人。</span></span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 3:17; 馬可福音 13:5; 約翰福音 14:29"> <span className="woj">所以你們要當心。我已經預先把一切都告訴你們了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 13:10; 使徒行傳 2:19–20; 啟示錄 6:12–14"> <span className="woj">「在那些日子裡，隨著那患難，</span><br /><span className="pl pl-1 woj">『太陽就要變黑，</span><br /><span className="pl pl-1 woj">月亮也不發光，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 34:4; 啟示錄 6:13"> <span className="pl pl-1 woj">星辰要從天上墜落，</span><br /><span className="pl pl-1 woj">諸天之上的各勢力也將被震動。』</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="啟示錄 1:7; 馬太福音 16:27; 馬太福音 24:30"> <span className="woj">那時候，人們將要看見人子帶著極大的權能和榮耀，在雲彩中來臨。</span></span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 2:6; 馬太福音 24:31; 申命記 30:4"> <span className="woj">他要差派天使們，並且從四方，從地極到天邊，召集他所揀選的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 馬太福音 24:32–33"> <span className="woj">「你們要從無花果樹那裡學個比喻：當無花果樹的枝子發嫩長出葉子的時候，你們就知道夏天快到了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 4:17–18; 雅各書 5:9; 以西結書 12:25–28"> <span className="woj">照樣，當你們看見這些事發生的時候，你們應當知道：人子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="人子——原文直譯「他」或「它」；可指「人子」，也可指「那時刻」。">i</a></sup><span className="woj">快到了，就在門口了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 24:34; 路加福音 21:32; 馬太福音 16:28"> <span className="woj">我確實地告訴你們：在這一切事發生之前，這世代絕不會過去。</span></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 40:8; 以賽亞書 51:6; 馬太福音 24:35"> <span className="woj">天和地將要消逝，但是我的話絕不會消逝。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 1:7; 馬太福音 24:36–42; 馬太福音 25:13"> <span className="woj">「至於那日子或那時刻，沒有人知道，連天上的天使們也不知道，子也不知道，唯有父知道。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以弗所書 6:18; 路加福音 12:40; 羅馬書 13:11–12"> <span className="woj">你們要當心，要警醒</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「要禱告」。">j</a></sup><span className="woj">；因為你們不知道那時刻是什麼時候。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 25:14–30; 約翰福音 10:3; 路加福音 12:36–40"> <span className="woj">這就像一個人出外旅行，離開了家，把權柄交給了他的奴僕們，又把工作分給了每個人，他吩咐看門的人要警醒。</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 13:33; 馬太福音 24:42; 馬太福音 24:44"> <span className="woj">所以你們要警醒，因為你們不知道這家的主人什麼時候回來，或傍晚，或半夜，或雞叫時，或凌晨；</span></span>
<span className="v" id="v36" data-v="36" data-xref="帖撒羅尼迦前書 5:6–7; 羅馬書 13:11–14; 馬太福音 24:48–51"> <span className="woj">免得他忽然回來，看見你們在睡覺。</span></span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 13:33; 路加福音 12:41–46; 馬可福音 13:35"> <span className="woj">我對你們說的，也對所有的人說：你們要警醒！」</span></span>
</div>

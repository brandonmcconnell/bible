<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 一到清晨，祭司長們就與長老們、經文士們以及全議會的人商議對策，然後把耶穌捆起來帶走，交給彼拉多。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 2:2; 馬太福音 27:11–14; 提摩太前書 6:13"> 彼拉多問他：「你是猶太人的王嗎？」<br />耶穌回答他，說：<span className="woj">「是你說的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 53:7; 馬可福音 15:5; 約翰福音 18:29–31"> 祭司長們控告了耶穌很多事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「但是他什麼都不回答」。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 19:10; 馬太福音 27:13; 馬太福音 26:62"> 所以彼拉多又問他，說：「你什麼都不回應嗎？你看，他們控告你這麼多的事。」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 53:7; 撒迦利亞書 3:8; 詩篇 71:7"> 可是，耶穌仍然什麼也不回答，以致彼拉多感到驚奇。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:39–40; 使徒行傳 25:9; 使徒行傳 24:27"> 每逢這節日<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="節日——指「逾越節」。">b</a></sup>，彼拉多都會給民眾釋放一個他們所要求的囚犯。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 馬太福音 27:16; 路加福音 23:25"> 那時，有一個叫巴拉巴的，和一同叛亂的人被關在牢裡，他們在暴亂中殺過人。</span>
<span className="v" id="v8" data-v="8"> 眾人就上前去<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="上前去——有古抄本作「高喊」。">c</a></sup>，開始要求彼拉多按照他的慣例給他們辦。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 19:14–16; 約翰福音 19:4–5; 約翰福音 18:39"> 彼拉多問他們，說：「你們要我給你們釋放這猶太人的王嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多書 3:3; 創世記 4:4–6"> 其實彼拉多知道祭司長們是出於嫉妒才把耶穌交給他的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 3:14; 約翰福音 18:40; 何西阿書 5:1"> 但是，祭司長們煽動眾人，寧願要彼拉多給他們釋放巴拉巴。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 23:5–6; 以賽亞書 9:6–7; 撒迦利亞書 9:9"> 彼拉多又問他們，說：「那麼，你們要我怎麼處理你們稱為猶太人之王的那一位呢？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 他們再次喊叫：「把他釘上十字架！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以賽亞書 53:3"> 彼拉多對他們說：「他到底做了什麼惡事呢？」<br />但他們卻越發喊叫：「把他釘上十字架！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 19:1; 馬太福音 27:26; 以賽亞書 50:6"> 彼拉多想要討好眾人，就給他們釋放了巴拉巴，然後將耶穌鞭打<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="鞭打——羅馬式鞭打使用的鞭子是帶有碎骨頭或金屬尖鉤的皮條，抽打時使人皮開肉綻，非常殘酷。">d</a></sup>了，把他交出去釘上十字架。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 19:9; 馬太福音 27:27–31; 約翰福音 18:28"> 士兵們把耶穌帶進大院，那裡就是總督府，並召集了全隊士兵。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 27:28–30; 約翰福音 19:2–5; 路加福音 23:11"> 他們給他穿上紫色袍子，套上用荊棘編的冠冕，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:42–43; 馬可福音 15:2; 創世記 37:10"> 然後開始向他致敬說：「萬歲，猶太人的王！」</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:65; 以賽亞書 53:3–5; 路加福音 23:11"> 他們用蘆葦打他的頭，向他吐唾沫，又跪下來拜他。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 19:16; 馬太福音 27:31"> 他們戲弄完了，就脫下他紫色袍子，給他穿上他自己的衣服，然後帶他出去，要把他釘上十字架。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 27:32; 路加福音 23:26; 羅馬書 16:13"> 有一個古利奈人西門，是亞歷山大和魯弗斯的父親，正從鄉下來，經過那裡。他們就強迫他來背耶穌的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 27:33–44; 約翰福音 19:17–27; 路加福音 23:27–38"> 他們把耶穌帶到一個叫各各他的地方——「各各他」翻譯出來就是「骷髏地」；</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 27:34; 約翰福音 19:28–30; 路加福音 23:36"> 然後把調了沒藥的酒給耶穌，但他不接受。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 約翰福音 19:23–24; 馬太福音 27:35–36"> 於是，他們把耶穌釘上十字架，又分他的衣服，抽籤看誰得什麼。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 19:14; 馬可福音 15:33; 馬太福音 27:45"> 在上午九點<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="上午九點——原文為「第三時刻」。">e</a></sup>，他們把耶穌釘上了十字架。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:37; 馬太福音 2:2; 約翰福音 19:18–22"> 他的罪狀牌上寫的是：「猶太人的王。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 馬太福音 27:38; 約翰福音 19:18"> 同時，他們把兩個強盜與耶穌一起釘上十字架，一個在右邊，一個在左邊。</span>
<span className="v" id="v28" data-v="28"> 這就應驗了經上所說的：「他被列在不法之徒當中。」<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有此節。">f</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 14:58; 詩篇 109:25; 耶利米哀歌 1:12"> 那些路過的人辱罵耶穌，搖著頭，說：「咳！你這個要拆毀聖所、三天內又建起來的人哪，</span>
<span className="v" id="v30" data-v="30"> 從十字架上下來，救救你自己吧！」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 12:23–24; 馬太福音 27:41–43; 路加福音 23:35–37"> 同樣，祭司長們也與經文士們一起嘲笑，相互說：「他救了別人，卻不能救自己！</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 27:44; 路加福音 23:39–43; 撒迦利亞書 9:9"> 這個基督，以色列的王，現在讓他從十字架上下來吧，好讓我們看了就相信！」與耶穌一起被釘十字架的人也責罵他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:45; 路加福音 23:44–45; 阿摩司書 8:9–10"> 到了中午十二點<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="中午十二點——原文為「第六時刻」。">g</a></sup>，黑暗籠罩了整個大地，一直到下午三點<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="下午三點——原文為「第九時刻」。">h</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 22:1; 馬太福音 27:46; 希伯來書 5:7"> 下午三點，耶穌大聲呼喊：<span className="woj">「以羅伊，以羅伊！拉瑪撒巴克達尼？</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="以羅伊，以羅伊！拉瑪撒巴克達尼？——亞蘭文詞語的音譯。">i</a></sup><span className="woj">」</span>——這翻譯出來就是<span className="woj">「我的神，我的神！你為什麼離棄我？」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 27:47–49; 馬可福音 9:11–13; 馬太福音 17:11–13"> 站在旁邊的一些人聽見了，就說：「看，他在呼喚以利亞呢！」</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; 馬可福音 15:23; 約翰福音 19:28–30"> 有一個人跑過去，用海綿蘸滿了酸酒，套在蘆葦上，要給他喝，然後說：「等著吧，我們看以利亞會不會來把他放下來。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰福音 19:30; 路加福音 23:46; 馬太福音 27:50"> 耶穌大叫一聲，就斷了氣。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 10:19–23; 路加福音 23:45; 希伯來書 9:3–12"> 同時，聖所裡的幔子從上到下裂成兩半。</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:54; 路加福音 23:47–48; 馬太福音 27:43"> 站在耶穌對面的百夫長，看見他這樣<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「喊叫著」。">j</a></sup>斷了氣，就說：「這個人真是神的兒子！」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 馬太福音 27:55–56"> 還有一些婦女從遠處觀看，其中有茉大拉的瑪麗亞、小雅各和約西的母親瑪麗亞，以及莎羅美。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 馬太福音 27:55–56"> 她們就是耶穌在加利利的時候，跟隨他並服事他的人；還有許多別的跟耶穌一同上耶路撒冷的婦女。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 約翰福音 19:38–42; 約翰福音 19:31"> 因為那天是預備日，也就是安息日的前一天，所以到了傍晚，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 亞利馬太的約瑟來了，鼓起勇氣去向彼拉多請求要耶穌的遺體。約瑟是猶太議會中一位受人尊敬的議員，他也期待著神的國。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 19:31–37"> 彼拉多聽見耶穌已經死了就感到驚奇，於是叫來了百夫長，問他耶穌是否已經死了<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="已經死了——有古抄本作「死了很久了」。">k</a></sup>。</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 27:58; 約翰福音 19:38; 馬可福音 15:39"> 他向百夫長了解情況<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="情況——輔助詞語。">l</a></sup>後，就把遺體<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="遺體——有古抄本作「身體」。">m</a></sup>給了約瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 53:9; 馬太福音 27:59–60; 以賽亞書 22:16"> 於是，約瑟買了細麻布，把遺體取下來，用細麻布包好，安放在一座岩石鑿成的墓穴裡，又滾來一塊石頭，堵住墓穴口。</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 15:40; 馬可福音 16:1; 路加福音 23:55–2"> 茉大拉的瑪麗亞和約西的母親<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="母親——輔助詞語。">n</a></sup>瑪麗亞，都看到了安放耶穌的地方。</span>
</div>

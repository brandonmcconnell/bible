<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 4:47; 路加福音 5:18; 路加福音 18:35–38"> 過了些日子，耶穌又進了迦百農。人們聽說他在房子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="房子——或譯作「家」。">a</a></sup>裡，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 2:13; 馬可福音 1:45; 詩篇 40:9"> 許多人就聚集，甚至連門前都沒有空處了。於是耶穌就向他們講道。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:18–26; 馬太福音 9:1–8; 馬太福音 4:24"> 這時候，一些人帶了一個癱瘓的人來到耶穌那裡，是被四個人抬來的；</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 5:19; 申命記 22:8"> 但由於人多，無法抬到耶穌面前<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="抬到耶穌面前——有古抄本作「靠近他（耶穌）」。">b</a></sup>，他們就把耶穌上方的屋頂拆了。拆通之後，就把躺在墊子上那癱瘓的人縋了下去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 9:2; 雅各書 5:15; 馬可福音 2:9–10"> 耶穌看見他們的信心，就對癱瘓的人說：<span className="woj">「孩子，你的罪孽被赦免了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:21–22; 馬可福音 8:17; 哥林多後書 10:5"> 可是，有一些經文士坐在那裡，心裡想：</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 43:25; 路加福音 5:21; 彌迦書 7:18"> 「這個人怎麼這樣說話呢？他說褻瀆的話！除了神一位之外，誰能赦免罪呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 139:2; 使徒行傳 8:22; 路加福音 5:22"> 耶穌靈裡立刻知道他們心裡這樣想，就對他們說：<span className="woj">「你們心裡為什麼想這些事呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:22–25; 馬太福音 9:5"> <span className="woj">對這癱瘓的人說『你的罪孽被赦免了』，或說『你起來，拿起墊子走路』，哪一樣更容易呢？</span></span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 7:13–14; 馬太福音 9:6–8; 約翰福音 5:20–27"> <span className="woj">不過為要使你們知道人子在地上有赦免罪的權柄——」</span>耶穌就對癱瘓的人說：</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 1:41; 約翰福音 5:8–10; 約翰福音 6:63"> <span className="woj">「我吩咐你：起來，拿起你的墊子，回家去吧！」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 9:33; 馬太福音 9:8; 路加福音 7:16"> 那個人就立刻起來，拿起墊子在大家面前出去了。結果大家都驚訝，就榮耀神，說：「我們從來沒有見過這樣的事。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 4:1; 箴言 1:20–22; 路加福音 19:48"> 後來，耶穌又出去，到了加利利湖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="湖——原文直譯「海」。">c</a></sup>邊。眾人都來到他那裡，他就教導他們。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:27–32; 路加福音 6:15; 馬太福音 9:9–13"> 耶穌往前走，看見亞勒腓的兒子利未<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="利未——就是「馬太」。">d</a></sup>在稅關坐著。耶穌對他說：<span className="woj">「你跟從我！」</span>利未就站起來，跟從了耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:1; 路加福音 5:29–30; 馬太福音 9:10–11"> 耶穌在利未家裡坐席的時候，許多稅吏和罪人與耶穌及他的門徒們一同坐席，因為有許多這樣的人也跟隨了耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 路加福音 19:7; 路加福音 18:11"> 有些法利賽派的經文士<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有些法利賽派的經文士——有古抄本作「有些經文士和法利賽人」。">e</a></sup>見耶穌與罪人和稅吏一起吃飯，就對耶穌的門徒們說：「他怎麼與那些稅吏和罪人一起吃飯<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="吃飯——有古抄本作「吃喝」。">f</a></sup>呢？」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 9:12–13; 路加福音 15:7; 路加福音 5:31–32"> 耶穌聽見了，就對他們說：<span className="woj">「健康的人不需要醫生，有病的人才需要。我來不是要召喚義人，而是要召喚罪人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「來悔改」。">g</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:12; 馬太福音 6:18; 馬太福音 9:14–17"> 約翰的門徒們和法利賽人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="法利賽人——有古抄本作「法利賽人的門徒們」。">h</a></sup>正禁食的時候，有些人來問耶穌：「為什麼約翰的門徒們和法利賽人的門徒們都禁食，而你的門徒們卻不禁食呢？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 25:1–10; 創世記 29:22; 士師記 14:10–11"> 耶穌對他們說：<span className="woj">「新郎與賓客</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="賓客——或譯作「伴郎」；原文直譯「新房之子」。">i</a></sup><span className="woj">在一起的時候，難道賓客能禁食嗎？只要他們與新郎在一起，他們就不能禁食。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:22; 啟示錄 21:9; 以賽亞書 54:5"> <span className="woj">可是日子將要來到：當新郎從他們中間被帶走的時候，他們那時——在那一天就要禁食了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 9:16; 哥林多前書 10:13; 以賽亞書 57:16"> <span className="woj">沒有人把沒縮過水的布塊補在舊衣服上。否則所補上的新布會扯壞舊衣服，造成更大的裂口。</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 9:17; 詩篇 119:83; 路加福音 5:37–38"> <span className="woj">同樣，也沒有人把新酒裝在舊皮袋裡，否則酒</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="酒——有古抄本作「新酒」。">j</a></sup><span className="woj">會脹破皮袋，酒和皮袋都糟蹋了</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="酒和皮袋都糟蹋了——有古抄本作「酒會流出來，皮袋也會糟蹋了」。">k</a></sup><span className="woj">。因此，新酒必須裝</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有「必須裝」。">l</a></sup><span className="woj">在新皮袋裡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:1–8; 申命記 23:24–25; 路加福音 6:1–5"> 有一次在安息日，耶穌從麥田經過，他的門徒們開始邊走邊摘麥穗。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:10; 希伯來書 12:3; 馬太福音 12:2"> 有些法利賽人對耶穌說：「你看，他們為什麼做安息日不可以做的事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 21:3–6; 路加福音 10:26; 馬太福音 22:31"> 耶穌對他們說：<span className="woj">「大衛和那些與他在一起的人飢餓缺乏時所做的事，難道你們從來沒有讀過嗎？</span></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 8:17; 利未記 24:5–9; 撒母耳記上 21:1"> <span className="woj">在亞比亞特任大祭司的時候，他難道不是進了神的殿</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="殿——原文直譯「家」。">m</a></sup><span className="woj">，吃了陳設餅，還分給與他在一起的人嗎？這餅除了祭司，誰都不可以吃。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 2:16; 路加福音 6:9; 申命記 5:14"> 接著，耶穌對他們說：<span className="woj">「安息日是為人而存在的，人不是為安息日而存在的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 12:8; 啟示錄 1:10; 約翰福音 5:17"> <span className="woj">所以，人子是主，也是安息日的主。」</span></span>
</div>
</div>

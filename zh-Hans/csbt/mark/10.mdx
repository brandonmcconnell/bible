<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 10:40; 馬可福音 4:2; 約翰福音 11:7"> 後來，耶穌從那裡起身，來到猶太地區和約旦河對岸。人群又聚集到他那裡，他又照常教導他們。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 7:10–11; 路加福音 11:53–54; 約翰福音 8:6"> 有些法利賽人前來試探耶穌，問他：「人是否可以休妻呢？」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 8:20; 加拉太書 4:21; 路加福音 10:25"> 耶穌回答他們，說：<span className="woj">「摩西是怎麼吩咐你們的？」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 24:1–4; 馬太福音 5:31–32; 以賽亞書 50:1"> 他們說：「摩西准許人寫一份休書就可以休妻。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 19:8; 尼希米記 9:26; 使徒行傳 7:51"> 耶穌對他們說：<span className="woj">「摩西因著你們的心裡剛硬，才給你們定下這條誡命。</span></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 1:27; 創世記 5:2; 創世記 1:1"> <span className="woj">從創世之初，『神</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神——有古抄本作「他」。">a</a></sup><span className="woj">把人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人——原文直譯「他們」。">b</a></sup><span className="woj">造成男的和女的』，</span></span>
<span className="v" id="v7" data-v="7" data-xref="創世記 2:24; 馬太福音 19:5–6; 以弗所書 5:31"> <span className="pl pl-1 woj">『為這緣故，</span><br /><span className="pl pl-1 woj">人將離開他的父母，</span><br /><span className="pl pl-1 woj">與妻子結合</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「與妻子結合」。">c</a></sup><br /><span className="pl pl-1 woj">，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:28; 創世記 2:24; 哥林多前書 6:16"> <span className="pl pl-1 woj">兩個人就成為一體。』</span><br /><span className="woj">這樣，夫妻不再是兩個人，而是一體了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 7:1–3; 歷代志上 7:10–13"> <span className="woj">因此，神所配合的，人不可分開。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬可福音 9:33; 馬可福音 9:28; 馬可福音 4:10"> 進了屋子，門徒們又向耶穌問起這件事。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:31–32; 馬太福音 19:9; 哥林多前書 7:10–11"> 耶穌就說：<span className="woj">「如果有人休妻，另娶別人，就是犯通姦罪觸犯妻子。</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 7:11; 哥林多前書 7:13"> <span className="woj">女人如果離棄丈夫，另嫁別人，也是犯通姦罪。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 19:13–15; 路加福音 18:15–17; 出埃及記 10:9–11"> 有些人把小孩子帶到耶穌那裡，好讓耶穌摸他們一下。門徒們卻責備那些人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="那些人——有古抄本作「那些帶他們來的人」。">d</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 19:14; 馬太福音 18:10; 馬太福音 18:4"> 耶穌看見了就很不滿，對門徒們說：<span className="woj">「讓小孩子到我這裡來，不要阻止他們，因為神的國正屬於這樣的人。</span></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:3; 路加福音 18:17; 約翰福音 3:3–6"> <span className="woj">我確實地告訴你們：無論誰不像小孩子一樣接受神的國，就絕不能進去。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 9:36; 以賽亞書 40:11; 約翰福音 21:15–17"> 於是，他把孩子們摟在懷中，按手在他們身上，祝福了他們。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 19:16–30; 路加福音 18:18–30; 羅馬書 2:7"> 耶穌剛出門上路，有一個人跑過去向他跪下，問他：「良善的老師，我該做什麼才能繼承永恆的生命呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:19; 馬太福音 19:17; 羅馬書 3:12"> 耶穌對他說：<span className="woj">「你為什麼稱我是良善的呢？除了神一位之外，沒有一個是良善的。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:12–17; 羅馬書 13:9; 雅各書 2:11"> <span className="woj">你是知道這些誡命的：</span><br /><span className="pl pl-1 woj">『不可殺人、</span><br /><span className="pl pl-1 woj">不可通姦、</span><br /><span className="pl pl-1 woj">不可偷竊、</span><br /><span className="pl pl-1 woj">不可做偽證、</span><br /><span className="pl pl-1 woj">不可虧負人、</span><br /><span className="pl pl-1 woj">要孝敬父母。』</span><br /><span className="pl pl-1 woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 33:31–32; 提摩太後書 3:5; 腓立比書 3:6"> 那個人對耶穌說：「老師，這一切我從年少就遵守了。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:19–21; 啟示錄 2:4; 路加福音 18:22"> 耶穌注視著他，就愛他，對他說：<span className="woj">「你還缺少一件：去賣掉你所擁有的，分給窮人，這樣你將有財寶在天上；然後你</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「背起十字架」。">e</a></sup><span className="woj">來跟從我。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰一書 2:15–16; 提摩太前書 6:9–10; 路加福音 12:15"> 那個人因這話，臉色就變得陰沉，憂憂愁愁地走開了，因為他有很多財產。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 1:26; 路加福音 18:24; 馬可福音 3:5"> 耶穌環視周圍，對他的門徒們說：<span className="woj">「有錢財的人進入神的國，是多麼困難！」</span></span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 5:1–3; 箴言 11:28; 詩篇 52:7"> 門徒們因這些話，就驚訝不已。耶穌又對他們說：<span className="woj">「孩子們，</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「依靠錢財的人」。">f</a></sup><span className="woj">進入神的國是多麼困難！</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 19:24–25; 路加福音 18:25; 馬太福音 23:24"> <span className="woj">駱駝穿過針眼，比富有的人進入神的國更容易呢！」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 16:31; 哥林多後書 11:23; 羅馬書 10:9–13"> 門徒們越發驚訝，彼此說：「那麼，誰能得救呢？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:26; 耶利米書 32:27; 約伯記 42:2"> 耶穌注視著他們，說：<span className="woj">「在人不可能，但在神卻不然；因為在神，凡事都可能。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 19:27–30; 路加福音 18:28–30; 路加福音 14:33"> 彼得就對耶穌說：「看，我們捨棄一切跟從了你！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 9:23; 馬太福音 5:10–11; 馬可福音 8:35"> 耶穌說：<span className="woj">「我確實地告訴你們：無論誰為我的緣故、為福音的緣故而捨棄房屋，或兄弟，或姐妹，或母親，或父親，</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「或妻子，」。">g</a></sup><span className="woj">或兒女，或田產，</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 18:30; 腓立比書 3:8; 哥林多後書 6:10"> <span className="woj">都必定在今世得到百倍，就是房屋、兄弟、姐妹、母親、兒女和田產，也會有逼迫；但在來世得到永恆的生命。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 19:30; 路加福音 13:30; 馬太福音 20:16"> <span className="woj">不過許多在前的，將要在後；許多在後的，將要在前。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 20:17–19; 路加福音 18:31–34; 路加福音 9:51"> 在上耶路撒冷的路途中，耶穌一直走在前頭，門徒們驚訝不已，跟著的人也懼怕了。耶穌又把十二使徒<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="使徒——輔助詞語。">h</a></sup>帶到一邊，開始告訴他們將要發生在他身上的事，</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:2; 馬太福音 20:17–19; 馬可福音 8:31"> 說：<span className="woj">「看，我們現在上耶路撒冷去，人子將被出賣給祭司長們和經文士們。他們要定他死罪，並且要把他交給外邦人。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 26:67; 馬太福音 16:21; 馬可福音 14:65"> <span className="woj">他們要戲弄他、向他吐唾沫、鞭打他，並殺害他；然後在第三天</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="在第三天——有古抄本作「三天后」。">i</a></sup><span className="woj">，他要復活。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:20–28; 撒母耳記下 14:4–11; 列王紀上 2:20"> 這時候，西庇太的兒子雅各和約翰來到耶穌面前，說：「老師，如果我們向你求什麼，希望你為我們成全。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約翰福音 15:7; 列王紀上 3:5–15; 馬可福音 10:51"> 耶穌問他們：<span className="woj">「要我為你們做什麼呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬太福音 19:28; 馬可福音 16:19; 路加福音 24:26"> 他們說：「請准許我們在你的榮耀裡，一個坐在你的右邊，一個坐在你的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「你的」。">j</a></sup>左邊。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:50; 馬太福音 20:21–22; 詩篇 75:8"> 耶穌就說：<span className="woj">「你們不知道自己在求什麼。我所喝的杯，你們能喝嗎？我所受的洗禮，你們能受嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 12:2; 啟示錄 1:9; 約翰福音 17:14"> 他們回答說：「我們能。」<br />耶穌就說：<span className="woj">「我所喝的杯你們將要喝，我所受的洗禮你們將要受。</span></span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 20:23; 馬太福音 25:34; 約翰福音 17:24"> <span className="woj">但是坐在我的右邊或左邊，不是我所賜的，而是已經預備給誰，就賜給誰。」</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 20:24; 箴言 13:10; 羅馬書 12:10"> 其他十個使徒聽了，就開始對雅各和約翰很不滿。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="彼得前書 5:3; 路加福音 22:25; 馬太福音 20:25"> 於是耶穌把他們召來，對他們說：<span className="woj">「你們知道，外邦人有所謂為首的壓制他們，也有為大的管轄他們。</span></span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 23:8–12; 路加福音 14:11; 馬可福音 9:35"> <span className="woj">但你們當中卻不是這樣；相反，無論誰想在你們當中為大，誰就該做你們的僕人；</span></span>
<span className="v" id="v44" data-v="44"> <span className="woj">無論誰想在你們當中為首，誰就該做大家的奴僕。</span></span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 20:28; 腓立比書 2:5–8; 哥林多後書 8:9"> <span className="woj">要知道，就是人子來，也不是為了受人的服事，而是為了服事人，並且獻上自己的生命，替許多人做救贖的代價。」</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 18:35–1; 馬太福音 20:29–34; 約翰福音 9:8"> 他們來到了耶利哥。當耶穌與他的門徒們和一大群人要離開那裡的時候，有一個瞎眼的乞丐坐在路邊，他是提邁的兒子巴提邁。</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 1:24; 馬太福音 9:27; 啟示錄 22:16"> 他一聽說是拿撒勒人耶穌，就開始呼叫說：「大衛的後裔<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="大衛的後裔——或譯作「大衛之子」。">k</a></sup>——耶穌，可憐我吧！」</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 29:13; 馬可福音 7:26–29; 希伯來書 5:7"> 許多人責備他，叫他不要做聲。可是他更加大聲呼叫：「大衛的後裔<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="大衛的後裔——或譯作「大衛之子」。">l</a></sup>，可憐我吧！」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 18:40; 馬太福音 20:32–34; 約翰福音 11:28"> 耶穌就停住，說：<span className="woj">「叫他過來吧。」</span><br />他們就叫那瞎眼的說：「鼓起勇氣吧！起來，他叫你呢。」</span>
<span className="v" id="v50" data-v="50" data-xref="腓立比書 3:7–9; 希伯來書 12:1"> 他就丟下外衣跳起來，來到耶穌面前。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="路加福音 18:41–43; 馬可福音 10:36; 馬太福音 7:7"> 耶穌問他說：<span className="woj">「你要我為你做什麼呢？」</span><br />那瞎眼的說：「拉波尼<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="拉波尼——希伯來文詞語；意思為「我的老師」。">m</a></sup>，我要重見光明！」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="馬太福音 9:22; 使徒行傳 26:18; 馬可福音 8:25"> 耶穌對他說：<span className="woj">「你去吧！你的信救了你。」</span>他立刻重見光明，於是一路跟隨了耶穌。</span>
</div>

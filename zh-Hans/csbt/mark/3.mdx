<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:9–14; 路加福音 6:6–11; 馬可福音 1:21"> 耶穌又進了會堂。那裡有個人，他的一隻手枯萎了。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:32; 路加福音 14:1; 路加福音 6:7"> 有些人就密切注意耶穌會不會在安息日使那個人痊癒，這是為要控告耶穌。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比書 1:28–30; 以賽亞書 42:4; 路加福音 6:8"> 耶穌對那手枯萎的人說：<span className="woj">「起來，站到中間來！」</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 馬太福音 12:10–12; 何西阿書 6:6"> 耶穌問他們：<span className="woj">「在安息日可以行善還是作惡，救命還是害命？」</span>他們卻不做聲。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所書 4:18; 羅馬書 11:25"> 耶穌憤怒地環視他們，又為他們心裡剛硬而憂傷，就對那個人說：<span className="woj">「伸出手來！」</span>他一伸出來，手就復原了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「和另一隻一樣健全」。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 22:16; 馬可福音 12:13; 馬太福音 12:14"> 那些法利賽人就出去，立刻與希律黨的人一起商議怎樣對付耶穌，好除滅他。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 4:25; 路加福音 6:17; 馬太福音 12:15"> 耶穌與他的門徒們退到湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="湖——原文直譯「海」；指「加利利湖（海）」。">b</a></sup>邊，有一大群從加利利來的人跟隨他；還有來自猶太、</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 35:15; 以賽亞書 34:5; 馬太福音 11:21"> 耶路撒冷、以杜邁亞、約旦河對岸，以及提爾和西頓周圍的一大群人來到他那裡，因為他們聽說了耶穌所做的事。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 5:30; 約翰福音 6:15"> 由於人多，耶穌就吩咐他的門徒為他預備一條小船，免得眾人擁擠他。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 14:36; 馬可福音 6:56; 馬太福音 4:23"> 因為他使許多人痊癒，所以有病痛的人都向他擠過來，想要摸到他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 馬可福音 1:23–24; 路加福音 8:28"> 汙靈每當見到耶穌，就俯伏在他面前，喊叫說：「你是神的兒子！」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:16; 馬可福音 1:25; 馬可福音 1:34"> 可是，耶穌嚴厲地斥責它們不要把他傳揚出去。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 馬太福音 10:1–4"> 耶穌上了山，召來那些他想要的人，他們就來到他那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 1:8; 路加福音 9:1–6; 約翰福音 15:16"> 於是，耶穌委任了十二個人，稱他們為使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「稱他們為使徒」。">c</a></sup>，是要他們常與他在一起，並要差派他們出去傳道，</span>
<span className="v" id="v15" data-v="15"> 又使他們有權柄<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「使疾病痊癒、」。">d</a></sup>驅趕鬼魔。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 1:42; 使徒行傳 1:13; 馬太福音 16:16–18"> 這樣，他委任了十二使徒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「這樣，他委任了十二使徒」。">e</a></sup>：<br /><span className="pl pl-1">西門——耶穌給他起名叫彼得；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:12; 馬可福音 14:33; 耶利米書 23:29"> <span className="pl pl-1">西庇太的兒子雅各，</span><br /><span className="pl pl-1">雅各的弟弟</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="弟弟——原文直譯「兄弟」。">f</a></sup><br /><span className="pl pl-1">約翰</span><br /><span className="pl pl-1">——耶穌給他們起名叫「波阿內格」——</span><br /><span className="pl pl-1">這意思是「雷霆之子」；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 1:13; 馬可福音 2:14; 馬太福音 9:9"> <span className="pl pl-1">又有安得烈，</span><br /><span className="pl pl-1">腓力和巴多羅邁，</span><br /><span className="pl pl-1">馬太和多馬，</span><br /><span className="pl pl-1">亞勒腓的兒子雅各和達太，</span><br /><span className="pl pl-1">激進派</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="激進派——或譯作「奮銳黨」。">g</a></sup><br /><span className="pl pl-1">的西門，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 6:71; 約翰福音 13:2; 使徒行傳 1:16–25"> <span className="pl pl-1">還有那出賣耶穌的加略人猶大。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 6:31; 約翰福音 4:31–34; 馬可福音 9:28"> 耶穌進了房子，人群又聚集而來，以致他和門徒們連飯<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="飯——原文直譯「餅」。">h</a></sup>都不能吃。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 26:24; 約翰福音 10:20; 馬可福音 3:31"> 耶穌的親屬聽說了，就來制止他，因為有人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有人——原文直譯「他們」。">i</a></sup>說他發瘋了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:1; 馬太福音 10:25; 馬太福音 9:34"> 從耶路撒冷下來的一些經文士說：「他有別西卜附身，他是靠鬼魔的王驅趕鬼魔的。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 馬太福音 12:25–30; 馬太福音 13:34"> 耶穌把他們召來，用比喻對他們說：<span className="woj">「撒旦怎麼能夠驅趕撒旦呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 11:14; 以賽亞書 19:2–3; 撒母耳記下 20:6"> <span className="woj">一個國家如果自相紛爭，這個國家就站立不住；</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 3:16; 詩篇 133:1; 加拉太書 5:15"> <span className="woj">一個家庭如果自相紛爭，這個家庭就站立不住；</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">撒旦如果起來反對自己而紛爭，他不但站立不住，而且要完了。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 49:24–26; 馬太福音 12:29; 路加福音 11:21–23"> <span className="woj">「沒有人能進入一個壯士的家搶奪他的東西，如果不先把那壯士捆住，就不能搶奪他的家。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 馬太福音 12:31–32; 約翰一書 5:16"> <span className="woj">我確實地告訴你們：人類</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="人類——原文直譯「人的子孫」。">j</a></sup><span className="woj">的一切罪和褻瀆的話，無論怎樣褻瀆，都能被赦免。</span></span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 12:31–32; 路加福音 12:10; 帖撒羅尼迦後書 1:9"> <span className="woj">但如果有人褻瀆聖靈，他永遠得不到赦免，而且必擔當永遠的罪</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="擔當永遠的罪——有古抄本作「遭受永遠的審判」。">k</a></sup><span className="woj">。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 10:20; 馬可福音 3:22"> 這話是因為他們說：「他有汙靈附身。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 馬太福音 12:46–50"> 後來，耶穌的母親和弟弟們來了，站在外面，派人去叫耶穌。</span>
<span className="v" id="v32" data-v="32"> 有一群人正圍著耶穌坐著，他們對他說：「看，你母親和弟弟妹妹們<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="妹妹們——原文直譯「姐妹們」。">l</a></sup><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本沒有「妹妹們」。">m</a></sup>在外面找你。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬可福音 3:21; 申命記 33:9; 馬可福音 6:3"> 耶穌回答他們，說：<span className="woj">「我的母親、我的弟兄是誰呢？」</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 12:49–50; 路加福音 11:27–28; 羅馬書 8:29"> 他環視坐在他周圍的人，說：<span className="woj">「看，我的母親、我的弟兄！</span></span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:17; 馬太福音 7:21; 約翰一書 3:22–23"> <span className="woj">因為凡是遵行神旨意的人，他才是我的弟兄、姐妹和母親。」</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:1–11; 約翰福音 12:14–19; 路加福音 19:29–40"> 當耶穌和門徒們臨近耶路撒冷，到橄欖山附近的伯法其和伯大尼的時候，耶穌派了他的兩個門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 21:2–3; 路加福音 19:30–31"> 對他們說：<span className="woj">「你們到對面的村子裡去。你們一進村，就會發現一頭驢駒拴在那裡，是從來沒有人騎過的。你們把牠解開牽過來。</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 10:36; 馬可福音 14:15; 詩篇 110:3"> <span className="woj">如果有人問你們為什麼這麼做，你們就說『主需要牠</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主需要牠——或譯作「牠的主人有需要」。">a</a></sup><span className="woj">，會很快把牠送回這裡來的。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 26:19; 路加福音 19:32–34; 馬太福音 21:6–7"> 兩個門徒去了，果然發現一頭驢駒拴在岔路口一個門外，他們就解開驢駒。</span>
<span className="v" id="v5" data-v="5"> 站在那裡的一些人問：「你們解開驢駒做什麼呢？」</span>
<span className="v" id="v6" data-v="6"> 他們就照著耶穌所吩咐的回答，那些人就讓他們牽走<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="牽走——輔助詞語。">b</a></sup>了。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 9:9; 路加福音 19:35–36; 馬太福音 21:7–8"> 他們牽著驢駒到耶穌那裡，把自己的外衣墊在驢駒上，耶穌就騎了上去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="利未記 23:40"> 許多人把自己的外衣鋪在路上，也有人從田野裡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="從田野裡——有古抄本作「從樹上」。">c</a></sup>砍來樹枝鋪在路上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本沒有「鋪在路上」。">d</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:25–26; 馬太福音 21:9; 馬太福音 23:39"> 前行後隨的人都呼喊：<br /><span className="pl pl-1">「和散那！</span><br /><span className="pl pl-1">奉主名而來的那一位——是蒙祝福的！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> <span className="pl pl-1">那</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「奉主名」。">e</a></sup><br /><span className="pl pl-1">將要來的，我們先祖大衛的國度——是蒙祝福的！</span><br /><span className="pl pl-1">在至高之處——和散那！」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶穌進了耶路撒冷，來到聖殿，環視周圍的一切。天已經晚了，他就與十二使徒<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="使徒——輔助詞語。">f</a></sup>一同離開，往伯大尼去了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:18–22; 馬太福音 4:2; 約翰福音 19:28"> 第二天，當他們離開伯大尼的時候，耶穌餓了。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 21:19; 路加福音 13:6–9; 以賽亞書 5:7"> 他遠遠地看見一棵長滿葉子的無花果樹，就上前去，要看看樹上是否有什麼。他來到樹下，除了葉子什麼也找不到，因為不是結無花果的季節。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 21:19; 馬太福音 7:19; 馬太福音 3:10"> 於是他對那棵樹說：<span className="woj">「永遠不再有任何人吃到你的果子了！」</span>他的門徒都聽見了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 2:13–17; 馬太福音 21:12–16; 路加福音 19:45–47"> 他們來到耶路撒冷。耶穌進了聖殿，開始把那些在聖殿裡做買賣的人趕出去。他推翻了兌換銀幣之人的桌子和賣鴿子之人的凳子，</span>
<span className="v" id="v16" data-v="16"> 也不准任何人搬運東西穿過聖殿。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 56:7; 耶利米書 7:11; 路加福音 19:46"> 耶穌教導他們說：<span className="woj">「經上不是記著『我的殿將被稱為萬國禱告的殿』嗎？而你們卻使它成為賊窩了！」</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 7:28; 馬可福音 12:12; 馬可福音 14:1–2"> 祭司長們和經文士們聽了，就圖謀怎樣來除滅耶穌。原來他們怕耶穌，因為眾人都對他的教導驚嘆不已。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 馬可福音 11:11; 約翰福音 12:36"> 到了傍晚的時候，耶穌和門徒們就到城外去。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 15:13; 馬可福音 11:14; 約翰福音 15:6"> 清晨，他們路過那棵無花果樹的時候，看見它連根都枯萎了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; 馬太福音 23:7; 馬太福音 25:41"> 彼得想起來就對耶穌說：「拉比，你看！你所詛咒的無花果樹枯萎了！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 62:8; 約翰福音 14:1; 馬可福音 9:23"> 耶穌對他們說：<span className="woj">「你們當對神有信心。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 17:20; 約翰福音 15:7; 馬太福音 21:21"> <span className="woj">我確實地告訴你們：無論誰對這座山說『願你被挪開，被丟進海裡去！』只要他心裡不疑惑，相信自己所說的會成就，事情</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="事情——有古抄本作「凡是他所說的事情」。">g</a></sup><span className="woj">就將為他成就。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 21:22; 約翰一書 5:14–15; 約翰一書 3:22"> <span className="woj">所以，我告訴你們：凡是你們所禱告和祈求的，當相信已經得著了</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="已經得著了——有古抄本作「將得到」。">h</a></sup><span className="woj">。這樣，事情就將為你們成就。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 6:14–15; 歌羅西書 3:13; 以弗所書 4:32"> <span className="woj">當你們站著禱告的時候，如果向什麼人懷怨，就要饒恕他。這樣，你們在天上的父也會饒恕你們的過犯。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">你們如果不饒恕別人，你們在天上的父也不會饒恕你們的過犯。</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有此節。">i</a></sup><span className="woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 馬太福音 21:23–27; 詩篇 2:1–5"> 他們又來到耶路撒冷。當耶穌在聖殿裡行走的時候，祭司長們、經文士們和長老們來到他那裡。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 2:14; 使徒行傳 7:38–39; 民數記 16:3"> 他們問：「你憑什麼權柄做這些事？誰給你這權柄，讓你做這些事？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 馬太福音 21:24; 以賽亞書 52:13"> 耶穌對他們說：<span className="woj">「我要問你們一個問題，你們回答我，我就告訴你們我憑什麼權柄做這些事。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 約翰福音 3:25–36; 馬可福音 1:1–11"> <span className="woj">約翰的洗禮是來自天上，還是來自人間呢？你們回答我！」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:29; 約翰福音 1:34; 馬太福音 21:31–32"> 他們就彼此討論，說：「如果我們說『是來自天上』，他就會問『那麼你們為什麼不相信他呢？』</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 21:46; 馬可福音 12:12; 馬太福音 14:5"> 可是我們能說『是來自人間』嗎？」原來他們怕民眾，因為大家都認為約翰的確是先知。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 6:9–10; 哥林多後書 4:3–4; 帖撒羅尼迦後書 2:10–12"> 於是他們回答耶穌，說：「我們不知道。」<br />耶穌就對他們說：<span className="woj">「我也不告訴你們我憑什麼權柄做這些事。」</span></span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="MRK" data-book-slug="mark" data-book-name="馬可福音" data-chapter="7" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 15:1–20; 馬可福音 3:22; 路加福音 5:17"> 有些法利賽人和一些從耶路撒冷來的經文士聚集到耶穌那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:28; 馬太福音 7:3–5; 羅馬書 14:14"> 他們看見耶穌的一些門徒用不潔淨的手，就是沒有洗過的手吃飯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="飯——原文直譯「餅」。">a</a></sup><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「就指責他們」。">b</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 1:14; 馬可福音 7:13; 歌羅西書 2:8"> 原來，法利賽人和所有的猶太人都拘守古人的傳統：如果不按規矩<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="按規矩——或譯作「仔細地」。">c</a></sup>洗手就不吃飯；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 9:10; 馬太福音 23:25; 路加福音 11:38–39"> 他們從街市上回來，如果不行洗淨禮，也就不吃飯；他們還有很多其他的傳統要拘守，例如洗杯子、瓶子、銅器，甚至床<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本沒有「甚至床」。">d</a></sup>等。</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒羅尼迦後書 3:6; 使徒行傳 21:21; 馬太福音 15:2"> 於是，法利賽人和經文士就問耶穌：「你的門徒們為什麼不照著古人的傳統行事，用不潔淨的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="不潔淨的——有古抄本作「沒有洗過的」。">e</a></sup>手吃飯<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="飯——原文直譯「餅」。">f</a></sup>呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 29:13; 提多書 1:16; 馬太福音 15:7–9"> 耶穌對他們說：<span className="woj">「以賽亞指著你們這些偽善的人所說的預言是對的，正如經上所記：</span><br /><span className="pl pl-1 woj">『這子民用嘴唇尊重我，</span><br /><span className="pl pl-1 woj">他們的心卻遠離我。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 29:13; 馬太福音 15:9; 雅各書 1:26"> <span className="pl pl-1 woj">他們敬拜我也是徒然的，</span><br /><span className="pl pl-1 woj">因為他們把人的規條當做教義教導人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="他們把人的規條當做教義教導人——或譯作「他們教導的教義是人的規條」。">g</a></sup><br /><span className="pl pl-1 woj">。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="馬可福音 7:3–4; 以賽亞書 1:12"> <span className="woj">你們離棄了神的命令，而拘守人的傳統</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「例如洗瓶子、杯子，還做很多其他類似這樣的事」。">h</a></sup><span className="woj">。」</span></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 44:16–17; 加拉太書 2:21; 以賽亞書 29:13"> 耶穌又對他們說：<span className="woj">「你們為了要守住你們的傳統，竟然棄絕了神的命令！</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 21:17; 出埃及記 20:12; 申命記 5:16"> <span className="woj">摩西吩咐過</span><br /><span className="pl pl-1 woj">『你要孝敬你的父母』</span><br /><span className="pl pl-1 woj">，又說</span><br /><span className="pl pl-1 woj">『咒罵父親或母親的人，必須處死。』</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 23:18; 提摩太前書 5:4–8; 馬太福音 15:5"> <span className="woj">你們卻說『如果一個人對父親或母親說：我本該給你的，已經做了「各爾板」</span>——這意思是「聖殿奉獻」，</span>
<span className="v" id="v12" data-v="12"> <span className="woj">就准許這個人可以不再為父母做什麼了。』</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 7:9; 提多書 1:14; 馬太福音 5:17–20"> <span className="woj">這樣，你們就藉著所繼承的傳統，廢棄了神的話語</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的話語——或譯作「神的道」。">i</a></sup><span className="woj">。你們還做很多類似這樣的事。」</span></span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:10; 以賽亞書 6:9; 箴言 8:5"> 耶穌又<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「又」。">j</a></sup>召來眾人，對他們說：<span className="woj">「你們每個人都當聽我說，也當領悟：</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未記 11:42–47; 提多書 1:15"> <span className="woj">從人外面進到他裡面的，沒有一樣能使人</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="人——原文直譯「他」。">k</a></sup><span className="woj">汙穢；相反，從人裡面出來的，才會使人汙穢。</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">凡是有耳可聽的，就應當聽！</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有此節。">l</a></sup><span className="woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 15:15; 馬太福音 13:36; 馬可福音 9:28"> 耶穌離開人群，一進了房子，他的門徒們就問他這比喻的意思。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 15:16–17; 希伯來書 5:11; 以賽亞書 28:9–10"> 耶穌說：<span className="woj">「你們也是這樣無知嗎？你們難道不明白一切從外面進到人裡面的，不能使人汙穢嗎？</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 15:17; 哥林多前書 6:13; 歌羅西書 2:21–22"> <span className="woj">因為這些東西不是進到人的心裡，而是進入肚子，然後排到廁所裡去。」</span>耶穌這樣就使一切食物都潔淨。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 3:6; 雅各書 1:14–15; 雅各書 4:1"> 他接著說：<span className="woj">「從人裡面出來的，那才使人汙穢。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 17:9; 羅馬書 8:7–8; 雅各書 4:1–3"> <span className="woj">因為從裡面，就是從人心裡發出種種惡念：淫亂、偷竊、殺人、</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 20:15; 馬太福音 6:23; 彼得前書 2:15"> <span className="woj">通姦、貪心、惡意、欺詐、好色、嫉妒、毀謗、驕傲、愚妄，</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 7:15; 提多書 1:15; 哥林多前書 3:17"> <span className="woj">這一切邪惡都是從人裡面出來的，而且使人汙穢。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 15:21–28; 馬太福音 11:21; 以西結書 28:2"> 耶穌起身離開那地方到提爾和西頓<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本沒有「和西頓」。">m</a></sup>地區。他進了一戶人家，本來不願意任何人知道，卻還是不能避開眾人。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 15:22; 馬可福音 9:17–23; 使徒行傳 10:25–26"> 有一個婦人，她的女兒有汙靈附著。這婦人一聽說耶穌的事，就趕來俯伏在他的腳前。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 15:22; 以賽亞書 49:12; 加拉太書 3:28"> 這婦人是希臘人，出生在敘利亞的腓尼基。她請求耶穌把鬼魔從她女兒身上趕出去。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:23–28; 馬太福音 7:6; 使徒行傳 22:21"> 耶穌對她說：<span className="woj">「應該先讓兒女吃飽，因為拿兒女的餅扔給小狗，是不合宜的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="羅馬書 10:12; 羅馬書 3:29; 使徒行傳 11:17–18"> 婦人回答說：「主啊<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="主啊——有古抄本作「是的，主啊」。">n</a></sup>！連桌子底下的小狗，也吃得到孩子們的碎渣！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 66:2; 馬太福音 5:3; 約翰一書 3:8"> 耶穌對她說：<span className="woj">「憑你這句話，你可以回去了。鬼魔已經離開了你的女兒。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 3:8; 約翰福音 4:50–52"> 婦人回到家，發現孩子<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="孩子——有古抄本作「女兒」。">o</a></sup>躺在床上，鬼魔已經離去了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 5:20; 馬太福音 15:29–31; 馬太福音 4:25"> 耶穌離開提爾地區，經過西頓，從德卡波利斯境內又來到加利利湖<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="湖——原文直譯「海」。">p</a></sup>邊。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 馬可福音 5:23; 馬太福音 9:32–33"> 有人把一個又聾又啞的人帶到耶穌面前，懇求耶穌按手在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 8:23; 約翰福音 9:6–7; 馬可福音 5:40"> 耶穌把他從人群中單獨帶到一邊去，用指頭伸進他的耳朵，吐唾沫來抹他的舌頭，</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 11:41; 馬可福音 5:41; 馬可福音 6:41"> 然後望天噓了一口氣，對他說：<span className="woj">「以法達</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="以法達——亞蘭文詞語的音譯。">q</a></sup><span className="woj">！」</span>——這意思是<span className="woj">「開了吧」。</span></span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 35:5–6; 詩篇 33:9; 馬可福音 2:12"> 他的耳朵立刻開了，舌結也解了，說話也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 8:4; 馬可福音 8:26; 馬可福音 3:12"> 耶穌吩咐他們不要告訴任何人。但是，他越是吩咐，他們越是大大傳揚。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬可福音 6:51; 馬可福音 5:42; 出埃及記 4:10–11"> 人們極其驚訝，說：「他所做的一切都好！他甚至使聾子聽見，使啞巴說話。」</span>
</div>
</div>

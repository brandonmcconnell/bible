<span className="v" id="v1" data-v="1" data-xref="路加福音 23:56–12; 約翰福音 20:1–10; 馬太福音 28:1–10"> 安息日一過，茉大拉的瑪麗亞、雅各的母親<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="母親——輔助詞語。">a</a></sup>瑪麗亞和莎羅美就買了香料，要去膏抹耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 20:1; 路加福音 24:1; 馬太福音 28:1"> 在一週的頭一天<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一週的頭一天——指「星期日」。">b</a></sup>，一大清早，太陽剛出來，她們就來到墓穴那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 15:46–47; 馬太福音 27:60–66"> 她們互相說：「誰能替我們滾開墓穴口的石頭呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 28:2–4; 路加福音 24:2; 約翰福音 20:1"> 原來那塊石頭非常大。可是她們抬頭一看，見石頭已經被滾開了。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 20:11–12; 路加福音 24:3–5; 約翰福音 20:8"> 她們進了墓穴，看見一個年輕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一個年輕人——在《馬太福音》28:2，這個年輕人是一位天使。">c</a></sup>身穿白袍坐在右邊，就大吃一驚。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:17–18; 哥林多前書 15:3–7; 路加福音 24:46"> 那年輕人對她們說：「不要驚慌！你們是在尋找被釘十字架的拿撒勒人耶穌，他已經復活<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="復活——原文直譯「被復活」；指「神使耶穌復活」。">d</a></sup>了，不在這裡。看，這就是他們安放他的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 14:28; 馬太福音 26:32; 馬太福音 28:10"> 你們去，告訴他的門徒們和彼得：『他要在你們之前到加利利去。在那裡，你們將見到他，正如他告訴過你們的。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:22–24; 路加福音 24:9–11; 馬可福音 16:5–6"> 她們渾身顫抖、驚慌失措，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「趕快」。">e</a></sup>從墓穴出來就逃跑了。她們因為感到懼怕，什麼也沒有對任何人說。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 20:14–19; 路加福音 8:2; 約翰福音 20:12"> 在一週頭一天<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一週頭一天——指「星期日」。">f</a></sup>的清晨，耶穌復活以後，首先向茉大拉的瑪麗亞顯現。耶穌曾經從她身上趕出了七個鬼魔。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 20:18; 路加福音 24:17; 約翰福音 16:6"> 她去告訴那些向來與耶穌在一起的人，他們正在悲傷、哀哭。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 24:11; 馬可福音 16:13–14; 馬可福音 9:19"> 他們聽見耶穌活了，又被瑪麗亞看到了，卻是不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:13–32; 約翰福音 21:14; 約翰福音 21:1"> 這些事以後，門徒中有兩個人往鄉下去。在路上，耶穌以另一種形像向他們顯現。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 20:25; 路加福音 24:33–35; 約翰福音 20:8"> 他們去告訴其他的門徒，那些門徒也不相信他們。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 15:5; 路加福音 24:36–43; 希伯來書 3:7–8"> 後來那十一個使徒吃飯的時候，耶穌向他們顯現，並斥責他們的不信和心裡剛硬，因為他們不相信那些在他復活後看到他的人。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 28:19; 馬可福音 13:10; 使徒行傳 1:8"> 耶穌對他們說：<span className="woj">「你們要到全世界去，向萬人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="萬人——原文直譯「一切被造之物」。">g</a></sup><span className="woj">傳福音。</span></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 11:25–26; 約翰福音 3:36; 羅馬書 10:9–14"> <span className="woj">信而受洗</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="受洗——或譯作「受浸」。">h</a></sup><span className="woj">的人，將會得救；不信的人，將被定罪。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:16; 哥林多前書 12:28; 使徒行傳 8:7"> <span className="woj">這些神蹟將伴隨著信的人：他們將奉我的名驅趕鬼魔；說各種新的語言</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="語言——原文直譯「舌頭」；傳統譯法作「方言」；或譯作「殊言」。">i</a></sup><span className="woj">；</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 10:19; 雅各書 5:14–15; 使徒行傳 28:3–6"> <sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「用手」。">j</a></sup><span className="woj">對付</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="對付——或譯作「拿走」。">k</a></sup><span className="woj">蛇類；即使喝了致命的東西也絕不受害；按手在病人身上，病人就將痊癒。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前書 3:22; 希伯來書 1:3; 希伯來書 12:2"> 這樣，主耶穌<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="主耶穌——有古抄本作「主」。">l</a></sup>對他們說完話以後，就被接到天上，坐在神的右邊。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 2:4–5; 使徒行傳 14:3; 羅馬書 15:19"> 門徒們就出去，到處傳道。主與他們一同工作，並且藉著伴隨的神蹟證實這話語。<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本沒有9-20節。">m</a></sup><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本附「阿們。」">n</a></sup></span>
</div>

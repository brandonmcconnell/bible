<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 馬可福音 2:13; 路加福音 8:4–10"> 又一次，耶穌開始在湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直譯「海」；指「加利利湖（海）」。">a</a></sup>邊教導人。有一大群人聚集到他那裡，所以他上了湖中的一條船坐下來。眾人都在岸邊，面對湖站著。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 13:34–35; 馬可福音 3:23; 馬可福音 4:11"> 耶穌用比喻教導他們很多事，在教導時對他們說：</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 2:5; 馬太福音 13:26; 馬可福音 4:26–29"> <span className="woj">「你們當聽好：看哪，有一個撒種的出去撒種。</span></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 13:19; 馬可福音 4:15; 馬太福音 13:4"> <span className="woj">他撒的時候，有的種子落在路邊，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「天空的」。">b</a></sup><span className="woj">飛鳥來了，就把它吃掉了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 36:26; 路加福音 8:6; 路加福音 8:13"> <span className="woj">另有落在岩石地上的，那裡沒有多少泥土，它立刻就發芽了，因為土不深；</span></span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:11; 耶利米書 17:5–8; 約拿書 4:8"> <span className="woj">當太陽升起，它被暴曬，就枯萎了，因為沒有根。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 4:3; 路加福音 8:14; 創世記 3:17–18"> <span className="woj">另有落進荊棘叢裡的，荊棘長起來把它擠住，它就結不出果實了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:5; 歌羅西書 1:6; 馬可福音 4:20"> <span className="woj">可是另有落進好土壤裡的，就發芽、生長，不斷地結出果實，結出的有三十倍的、有六十倍的、有一百倍的。」</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:15; 馬可福音 4:23–24; 啟示錄 3:22"> 耶穌說：<span className="woj">「凡是有耳可聽的，就應當聽！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 13:10–17; 馬可福音 4:34; 箴言 13:20"> 耶穌獨自一人的時候，跟隨他的人與十二使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使徒——輔助詞語。">c</a></sup>一起問他這些比喻的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 11:25; 路加福音 8:10; 約翰一書 5:20"> 耶穌對他們說：<span className="woj">「神國的奧祕已經賜給你們了</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="賜給你們了——有古抄本作「賜下來讓你們知道」。">d</a></sup><span className="woj">，但是對外人，一切都是用比喻的。</span></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 6:9–10; 以賽亞書 44:18; 馬太福音 13:14–15"> <span className="woj">這是為要使</span><br /><span className="pl pl-1 woj">『他們看了又看，卻不明白，</span><br /><span className="pl pl-1 woj">聽了又聽，卻不領悟，</span><br /><span className="pl pl-1 woj">免得他們回轉過來，</span><br /><span className="pl pl-1 woj">就</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「罪」。">e</a></sup><br /><span className="pl pl-1 woj">被赦免。』</span><br /><span className="pl pl-1 woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 3:19; 馬太福音 13:51–52; 馬可福音 7:17–18"> 耶穌對他們說：<span className="woj">「你們不明白這個比喻，又怎麼能領會所有的比喻呢？</span></span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 8:4; 馬太福音 13:19; 馬太福音 13:37"> <span className="woj">撒種的人所撒的是話語。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 5:8; 馬太福音 13:19; 哥林多後書 2:11"> <span className="woj">那被撒上話語的『路邊之地』是這樣一些人：他們聽了話語以後，撒旦就立刻來把那撒在他們心裡</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="在他們心裡——有古抄本作「在他們裡面」。">f</a></sup><span className="woj">的話語奪走。</span></span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 6:20; 路加福音 8:13; 馬太福音 13:20–21"> <sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「同樣，」。">g</a></sup><span className="woj">那被撒上話語的『岩石地』是這樣一些人：他們一旦聽了這話語，就立刻懷著喜樂的心接受了它；</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:6; 帖撒羅尼迦前書 3:3–5; 馬太福音 12:31"> <span className="woj">可是他們裡面沒有根而不能持久，一旦為這話語受患難或逼迫，他們立刻就放棄</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="放棄——原文直譯「絆倒」。">h</a></sup><span className="woj">了。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; 耶利米書 4:3; 馬太福音 13:22"> <span className="woj">那被撒進話語的『荊棘叢』是另外一些人，那些人是這樣的：他們聽了這話語，</span></span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 2:15–17; 提摩太前書 6:9–10; 提摩太前書 6:17"> <span className="woj">但今世的各種憂慮、財富的迷惑，以及其他各種欲望紛紛進來把這話語擠住了，他就成了不結果實的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 1:10; 路加福音 8:15; 約翰福音 15:4–5"> <span className="woj">而那被撒上話語的『好土壤』是這樣的人：他們聽了這話語就接受，並且結出果實來，有三十倍的，有六十倍的，也有一百倍的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶穌又對他們說：<span className="woj">「油燈拿進來，難道是為了放在斗</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="斗——指「一種度量穀物的量器」；容量約為9升。">i</a></sup><span className="woj">底下，或床底下嗎？不是為了放在燈臺上嗎？</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; 傳道書 12:14; 馬太福音 10:26–27"> <span className="woj">這樣，就算是隱祕的事，也沒有不顯明出來的；即使是隱藏的事，也沒有不顯露出來的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 4:9; 馬太福音 11:15; 啟示錄 2:29"> <span className="woj">凡是有耳可聽的，就應當聽！」</span></span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 2:1; 路加福音 8:18; 馬太福音 7:2"> 耶穌又說：<span className="woj">「你們要留心所聽到的。你們用什麼量器</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="量器——或譯作「尺度」或「標準」。">j</a></sup><span className="woj">來衡量，也會同樣地被衡量，而且還將加添給你們</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你們——有古抄本作「你們這些正在聽的人」。">k</a></sup><span className="woj">；</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 13:12; 路加福音 8:18; 馬太福音 25:28–29"> <span className="woj">因為凡是有的，還要賜給他；凡是沒有的，連他有的也將從他那裡被拿走。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 13:24; 哥林多前書 3:6–9; 路加福音 8:11"> 耶穌又說：<span className="woj">「神的國就像這樣：有人在地上撒了種子，</span></span>
<span className="v" id="v27" data-v="27" data-xref="傳道書 11:5; 帖撒羅尼迦後書 1:3; 哥林多前書 15:37–38"> <span className="woj">黑夜白晝，或睡或起，他卻不知道那種子怎樣發芽和長大。</span></span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 4:31–32; 何西阿書 6:3; 腓立比書 1:9–11"> <span className="woj">大地自然長出五穀</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="長出五穀——原文直譯「結出果實」。">l</a></sup><span className="woj">——先長苗，再吐穗，然後穗上結出飽滿的子粒。</span></span>
<span className="v" id="v29" data-v="29" data-xref="約珥書 3:13; 馬太福音 13:30; 馬太福音 13:40–43"> <span className="woj">當果實成熟的時候，他立刻伸出鐮刀，因為收割的季節到了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 13:31–32; 路加福音 13:18–21; 耶利米哀歌 2:13"> 耶穌又說：<span className="woj">「我們把神的國比做什麼呢？用什麼比喻來表明</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="表明——或譯作「描述」；有古抄本作「比做」。">m</a></sup><span className="woj">它呢？</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:20; 路加福音 13:18–19; 但以理書 2:44–45"> <span className="woj">它好像一粒芥菜種子，被種入地裡的時候，比地上所有的種子更小，</span></span>
<span className="v" id="v32" data-v="32" data-xref="但以理書 4:20–22; 但以理書 4:10–14; 以西結書 31:3–10"> <span className="woj">可是被種下去以後，它就長起來，長得比所有蔬菜更大，並且長出大枝子，以致天空的飛鳥能在它的蔭下搭窩。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 13:34–35; 約翰福音 16:12; 希伯來書 5:11–14"> 耶穌照著他們所能聽的，用許多這樣的比喻，向他們講道。</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 16:25; 馬可福音 4:10; 馬太福音 15:15–20"> 他向眾人講話，沒有不用比喻的。可是，他卻單獨給自己的門徒們解釋一切。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 8:18; 路加福音 8:22; 路加福音 8:25"> 那天晚上，耶穌對門徒們說：<span className="woj">「我們渡到對岸去吧。」</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 3:9; 馬可福音 4:1; 馬可福音 5:2"> 門徒離開眾人，耶穌仍然在船上，他們就把他一同帶去；也有別的船<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="船——有古抄本作「小船」。">n</a></sup>與他同行。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 8:23–24; 約伯記 1:19; 路加福音 8:22–23"> 這時候，起了大風暴，以致波浪打進船裡，船幾乎灌滿了水。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前書 5:7; 希伯來書 4:15; 以賽亞書 54:6–8"> 耶穌卻在船尾靠著枕頭睡著了。門徒們叫醒他，說：「老師！我們沒命了，你不管嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="詩篇 107:29; 詩篇 89:9; 詩篇 65:7"> 耶穌就起來，斥責了風，對浪<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="浪——或譯作「湖」；原文直譯「海」。">o</a></sup>說：<span className="woj">「不許做聲！平靜下來！」</span>於是風就停了，湖面就變得一片平靜。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 8:25; 馬太福音 8:26; 馬太福音 14:31"> 耶穌對門徒們說：<span className="woj">「為什麼膽怯呢？你們還沒有信嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:25; 約伯記 38:11; 詩篇 89:7"> 門徒們就大為驚恐，彼此說：「這個人究竟是誰？連風和浪也聽從他！」</span>
</div>

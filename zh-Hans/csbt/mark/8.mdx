<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="MRK" data-book-slug="mark" data-book-name="馬可福音" data-chapter="8" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 15:32–39; 馬可福音 6:34–44"> 在那些日子裡，又一次，有一大群人，他們沒有什麼東西吃。耶穌召來門徒們，對他們說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:36; 彌迦書 7:19; 詩篇 103:13"> <span className="woj">「我憐憫這群人，因為他們與我在一起已經三天了，也沒有什麼東西吃。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 40:31; 士師記 8:4–6; 撒母耳記上 30:10–12"> <span className="woj">如果我讓他們餓著肚子回家，他們會在路上暈倒，因為有些人從遠處而來。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 4:42–44; 列王紀下 7:2; 馬可福音 6:52"> 他的門徒們回答：「在這曠野，從哪裡能得食物讓這些人吃飽呢？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 14:15–17; 馬太福音 15:34; 路加福音 9:13"> 耶穌問他們：<span className="woj">「你們有多少餅呢？」</span><br />他們回答說：「七個。」</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:17; 馬太福音 15:35–36; 約翰福音 6:10–11"> 耶穌就吩咐眾人坐在地上，於是拿起這七個餅，祝謝以後，掰開，不斷遞給他的門徒們，讓他們分發。門徒們就分給眾人；</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 14:19; 約翰福音 21:5; 路加福音 24:41–42"> 他們還有幾條小魚，耶穌祝福了，就吩咐把牠們也分給眾人。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 4:42–44; 詩篇 145:16; 馬太福音 16:10"> 他們吃了，並且吃飽了。然後，他們把剩下的碎塊收拾起來，裝滿了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="裝滿了——輔助詞語。">a</a></sup>七個筐子。</span>
<span className="v" id="v9" data-v="9"> 當時約有四千人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="約有四千人——有古抄本作「吃的人約有四千」。">b</a></sup>。耶穌遣散了他們，</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 15:39"> 隨即與他的門徒們一起上船，來到達瑪努達<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="達瑪努達——有古抄本作「茉加丹」或「茉大拉」。">c</a></sup>地區。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 10:9; 馬太福音 12:38; 申命記 6:16"> 有些法利賽人出來，開始和耶穌辯論。他們試探耶穌，向他要求一個從天上來的神蹟。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:39–40; 馬可福音 7:34; 馬太福音 16:4"> 耶穌靈裡深深地嘆息，就說：<span className="woj">「這世代為什麼在尋求神蹟呢？我確實地告訴你們：絕不會有神蹟賜給這世代。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 12:36; 使徒行傳 13:45–46; 詩篇 81:12"> 於是他就離開他們，又上船往對岸去。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 16:5"> 門徒們忘了帶餅，船上除了一個餅，再沒有別的了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 5:6–8; 馬太福音 16:6; 馬太福音 16:11–12"> 耶穌吩咐他們說：<span className="woj">「你們要注意，要當心法利賽人的酵母和希律的酵母。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 馬太福音 16:7–8"> 門徒們因為沒有餅，就彼此討論。</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 6:52; 以賽亞書 63:17; 馬可福音 2:8"> 耶穌知道了，就問他們：<span className="woj">「你們為什麼討論沒有餅的事呢？你們還不明白，還不領悟，還是硬著心嗎？</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 28:26–27; 馬太福音 13:14–15; 耶利米書 5:21"> <span className="woj">你們有眼睛卻看不見，有耳朵卻聽不見嗎？難道不記得嗎？</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 馬太福音 14:17–21; 約翰福音 6:5–13"> <span className="woj">當我掰開那五個餅給五千人的時候，你們收拾的碎塊裝滿了幾個籃子呢？」</span><br />門徒們回答說：「十二個。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 15:34–38; 馬可福音 8:1–9"> <span className="woj">「那七個餅給四千人的時候，你們收拾的碎塊裝滿了幾個筐子呢？」</span><br />門徒們回答說：「七個。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:52; 馬太福音 16:11–12; 馬可福音 8:12"> 耶穌對他們說：<span className="woj">「你們還不領悟嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:21; 馬可福音 6:45; 路加福音 10:13"> 他們來到伯賽達，有人帶來一個瞎眼的，懇求耶穌摸他。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 7:33; 約翰福音 9:6–7; 馬可福音 5:23"> 耶穌牽著瞎眼之人的手，領他到村子外面，吐唾沫在他的眼睛上，按手在他身上，問他：<span className="woj">「你是否看見什麼？」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 32:3; 以賽亞書 29:18; 哥林多前書 13:9–12"> 他抬頭一看，說：「我看見一些人！看起來好像樹在走路！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前書 2:9; 彼得後書 3:18; 箴言 4:18"> 然後耶穌又按手在他的眼睛上，他就看得清清楚楚了。他痊癒了，就清楚地看見了一切。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 8:4; 馬可福音 8:23; 馬可福音 5:43"> 耶穌叫他回家，並說：<span className="woj">「不要進這村子</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「也不要告訴村子裡的任何人」。">d</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:13–20; 路加福音 9:18–20"> 耶穌和他的門徒們往凱撒里亞菲利彼的那些村莊去。在路上，耶穌問他的門徒們，說：<span className="woj">「人們說我是誰？」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:21; 馬太福音 14:2; 瑪拉基書 4:5"> 他們回答他，說：「是施洗者<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="施洗者——或譯作「施浸者」。">e</a></sup>約翰，有的說是以利亞，也有的說是先知中的一位。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰一書 4:15; 馬太福音 16:15–16; 約翰一書 5:1"> 耶穌又問他們：<span className="woj">「那麼你們呢？你們說我是誰？」</span><br />彼得回答說：「你是基督！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 馬太福音 16:20; 馬可福音 9:9"> 耶穌就告誡他們不要把有關他的事告訴任何人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 10:33–34; 約翰福音 2:19; 路加福音 24:26"> 耶穌開始教導他們說：<span className="woj">「人子必須受很多苦害，被長老們、祭司長們和經文士們棄絕，並且被殺，然後在第三天要復活。」</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 16:22; 約翰福音 16:25; 約翰福音 16:29"> 耶穌公開地講這些事，彼得把耶穌拉到一邊，開始勸阻他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 4:10; 腓立比書 3:19; 約翰一書 2:15"> 但耶穌轉過身，看了看他的門徒們，就斥責彼得，說：<span className="woj">「撒旦，退到我後面去！因為你不是思想神的事，而是思想人的事。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:38; 路加福音 14:26–27; 約翰福音 10:27"> 於是，耶穌把眾人和他的門徒們一起召來，對他們說：<span className="woj">「如果有人想要跟從我，他就當捨棄自己，背起自己的十字架，然後跟從我。</span></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太後書 2:11–13; 哥林多前書 9:23; 路加福音 17:33"> <span className="woj">因為凡想要保全</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="保全——原文直譯「救」。">f</a></sup><span className="woj">自己生命的，將失去生命；凡為我和福音的緣故失去自己生命的，將保全</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="保全——原文直譯「救」。">g</a></sup><span className="woj">生命。</span></span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 16:26; 路加福音 9:25; 詩篇 49:17"> <span className="woj">一個人就是賺得了全世界，卻賠上了自己的生命</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="生命——或譯作「靈魂」。">h</a></sup><span className="woj">，到底有什麼益處呢？</span></span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 49:7–8; 彼得前書 1:18–19"> <span className="woj">人到底能拿什麼來換回自己的生命</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="生命——或譯作「靈魂」。">i</a></sup><span className="woj">呢？</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 羅馬書 1:16; 約翰一書 2:23"> <span className="woj">在這淫亂、罪惡的世代，一個人如果以我和我的話為恥，當人子在他父的榮耀中，與聖天使們一起來臨的時候，也要以這個人為恥。」</span></span>
</div>
</div>

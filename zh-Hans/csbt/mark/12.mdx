<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 5:1–4; 馬可福音 13:34; 雅歌 8:11–12"> 耶穌開始用比喻對他們說：<span className="woj">「有一個人栽種了一個葡萄園，四面圍上籬笆，挖了一個榨酒池，蓋了一座守望樓，然後把葡萄園租給一些農夫，就出外旅行。</span></span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 15:1–8; 希伯來書 1:1; 耶利米書 44:4"> <span className="woj">到了收獲的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="收穫的——輔助詞語。">a</a></sup><span className="woj">季節，他就派了一個奴僕到那些農夫那裡去，好從他們收取葡萄園的果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 2:15; 尼希米記 9:26; 耶利米書 29:26"> <span className="woj">但他們抓住那奴僕，打了他，叫他空手回去。</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">園主又派另一個奴僕到他們那裡去。那些農夫</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「用石頭砸他，」。">b</a></sup><span className="woj">打傷了他的頭，並且侮辱他</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「把他趕了回去」。">c</a></sup><span className="woj">。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 22:6; 馬太福音 23:37; 尼希米記 9:30"> <span className="woj">園主再派另一個去，他們把他殺了。另派了許多去，有的被打，有的被殺。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯來書 1:1–2; 馬太福音 3:17; 約翰福音 1:34"> <span className="woj">「那園主還有一位——是他的愛子。最後他差派兒子到他們那裡，說：『他們一定會尊重我的兒子。』</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 37:20; 馬太福音 2:16; 使徒行傳 2:23"> <span className="woj">「可是那些農夫彼此說：『這是繼承人。來，我們把他殺了，那繼業就歸我們了。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 21:39; 路加福音 20:15; 馬太福音 21:33"> <span className="woj">於是他們抓住他，把他殺了，並扔出葡萄園外。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="羅馬書 10:20–12; 馬太福音 21:43; 路加福音 19:27"> <span className="woj">「那麼，葡萄園的主人會做什麼呢？他會來除滅那些農夫，把葡萄園交給別人。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 118:22–23; 彼得前書 2:7–8; 以賽亞書 28:16"> <span className="woj">你們難道也沒有讀過這段經文嗎？</span><br /><span className="pl pl-1 woj">『工匠所棄絕的石頭，</span><br /><span className="pl pl-1 woj">它已經成了房角的頭塊石頭；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:23; 使徒行傳 3:12–16; 哈巴谷書 1:5"> <span className="pl pl-1 woj">這是主所成就的，</span><br /><span className="pl pl-1 woj">在我們眼中實在奇妙！』</span><br /><span className="pl pl-1 woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 11:18; 馬太福音 22:22; 約翰福音 7:44"> 祭司長們、律法師們和長老們知道這比喻是針對他們而說的，就想拘捕耶穌。可是他們怕民眾，於是離開耶穌走了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 馬可福音 3:6"> 後來，他們派了一些法利賽人和希律黨的人到耶穌那裡，要找話柄來陷害他。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:4; 路加福音 20:22; 約翰福音 7:18"> 那些人來對耶穌說：「老師，我們知道你是真誠的。你不顧忌任何人，因為你不看人的情面，而是按真理教導神的道<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="道——或譯作「路」。">d</a></sup>。請問，向凱撒納稅，可以不可以呢？我們該交還是不該交呢？」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西結書 17:2; 啟示錄 2:23; 馬可福音 10:2"> 耶穌看出他們的假意，就對他們說：<span className="woj">「你們為什麼試探我呢？拿一個銀幣</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="銀幣——原文為「得拿利」。1得拿利=約1日工資的羅馬銀幣。">e</a></sup><span className="woj">來給我看。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 啟示錄 3:12; 馬太福音 22:19–22"> 他們就拿來了。耶穌問他們：<span className="woj">「這是誰的像和名號？」</span><br />他們回答說：「是凱撒的。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:7; 彼得前書 2:17; 哥林多後書 5:14–15"> 耶穌對他們說：<span className="woj">「凱撒的歸給凱撒；神的歸給神。」</span>這使他們感到驚奇。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 22:23–33; 使徒行傳 4:1–2; 使徒行傳 23:6–9"> 接著，撒都該人來到耶穌那裡，他們一向說沒有復活的事。他們問耶穌，說：</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 25:5–10; 路得記 4:5; 路得記 1:11–13"> 「老師，摩西為我們寫道：如果一個人的兄弟死了，撇下妻子而沒有留下孩子，他就應該娶這婦人，為兄弟留後裔。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 22:25–28; 路加福音 20:29–33"> 曾經有兄弟七人，第一個娶了妻子，死去了，沒有留下後裔。</span>
<span className="v" id="v21" data-v="21"> 第二個娶了這寡婦，也死了，沒有留下後裔。第三個也一樣。</span>
<span className="v" id="v22" data-v="22"> 結果，兄弟七個都<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「娶過她，而」。">f</a></sup>沒有留下後裔。到了最後，這婦人也死了。</span>
<span className="v" id="v23" data-v="23"> 既然這七個人都娶過她為妻，在復活的時候，當他們復活了<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「當他們復活以後」。">g</a></sup>，她將是誰的妻子呢？」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 20:9; 提摩太後書 3:15–17; 馬太福音 22:29"> 耶穌說：<span className="woj">「你們之所以錯了，不就是因為你們不明白經上的話，也不明白神的大能嗎？</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 馬太福音 22:30; 約翰一書 3:2"> <span className="woj">當人從死人中復活以後，他們既不娶也不嫁，而是像諸天之上的天使一樣。</span></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 3:2–6; 路加福音 20:37; 創世記 17:7–8"> <span className="woj">關於死人復活的事，你們難道沒有讀過摩西書『荊棘篇』上，神怎樣對摩西說的嗎？神說『我是亞伯拉罕的神、以撒的神、雅各的神。』</span></span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 14:9; 羅馬書 4:17; 馬可福音 12:24"> <span className="woj">神不是死人的神，而是活人的神</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「神」。">h</a></sup><span className="woj">。你們完全錯了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 有一個經文士前來，聽見他們辯論，見耶穌回答得好，就問耶穌：「所有的誡命中，哪一條是最重要的呢？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 6:4; 路加福音 10:27; 加拉太書 3:20"> 耶穌回答：<span className="woj">「</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「所有誡命中」。">i</a></sup><span className="woj">最重要的是：</span><br /><span className="woj">『以色列啊，你當聽好！主——我們的神，是獨一的主。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 6:5"> <span className="woj">你要以全心、全靈、全意、全力愛主——你的神。』</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「這是最重要的誡命。」">j</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="羅馬書 13:8–9; 馬太福音 22:39; 利未記 19:18"> <span className="woj">「其次就是『要愛鄰如己。』</span><span className="woj">沒有別的誡命比這兩條更大的了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 4:39; 申命記 4:35; 以賽亞書 46:9"> 那經文士就對耶穌說：「不錯，老師，你真的講了：神只有一位，除他以外沒有別的神。</span>
<span className="v" id="v33" data-v="33" data-xref="何西阿書 6:6; 彌迦書 6:6–8; 撒母耳記上 15:22"> 以全心、全智、<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附「全靈、」。">k</a></sup>全力來愛神，並且要愛鄰如己，這是比所有的燔祭和各種祭祀都重要的。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歌羅西書 4:6; 路加福音 20:40; 馬太福音 22:46"> 耶穌見他回答得有智慧，就對他說：<span className="woj">「你離神的國不遠了。」</span>於是，沒有人敢再質問耶穌了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="路加福音 20:41–44; 馬太福音 22:41–45; 馬太福音 26:55"> 耶穌在聖殿裡教導人的時候問：<span className="woj">「經文士們怎麼說基督是大衛的後裔呢？</span></span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 110:1; 希伯來書 1:13; 馬太福音 22:43–45"> <span className="woj">大衛藉著聖靈，自己說過：</span><br /><span className="pl pl-1 woj">『主對我主說：</span><br /><span className="pl pl-1 woj">你坐在我的右邊，</span><br /><span className="pl pl-1 woj">等我把你的敵人放在你的腳下</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附「做腳凳」。">l</a></sup><br /><span className="pl pl-1 woj">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="羅馬書 1:3–4; 馬太福音 11:25; 馬太福音 1:23"> <span className="woj">大衛自己稱基督為『主』，基督又怎麼會是大衛的後裔呢？」</span>那一大群人都樂意聽耶穌講說。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬太福音 23:1–7; 路加福音 20:45–47; 路加福音 11:43"> 耶穌在他的教導中說：<span className="woj">「你們要當心經文士們。他們喜歡穿著長袍走來走去，喜歡街市上的致敬問候，</span></span>
<span className="v" id="v39" data-v="39" data-xref="雅各書 2:2–3"> <span className="woj">又喜歡會堂裡的首位、宴席中的上座。</span></span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 23:13; 路加福音 20:47; 馬太福音 23:33"> <span className="woj">他們侵吞寡婦的家產，又假意做很長的禱告。這些人將受到更重的懲罰</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="懲罰——或譯作「審判」。">m</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 列王紀下 12:9; 約翰福音 8:20"> 耶穌面對奉獻箱坐著，看眾人怎樣把錢投入奉獻箱裡。許多富有的人投進了很多錢。</span>
<span className="v" id="v42" data-v="42"> 有一個窮寡婦來，投進兩個小錢<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="兩個小錢——原文為「2雷普頓」。1雷普頓=約1/128日工資的希臘小銅幣。">n</a></sup>，值一個銅幣<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="銅幣——原文為「柯錐特」。1柯錐特=約1/64日工資的羅馬銅幣。">o</a></sup>。</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多後書 9:6–8; 哥林多後書 8:2; 使徒行傳 11:29"> 耶穌把他的門徒們召來，對他們說：<span className="woj">「我確實地告訴你們：這窮寡婦所投入奉獻箱的，比所有的人投的更多。</span></span>
<span className="v" id="v44" data-v="44" data-xref="哥林多後書 8:2–3; 約翰一書 3:17; 以斯拉記 2:68–69"> <span className="woj">因為大家是從自己的富餘中拿出來投進去；而這寡婦是從自己的缺乏中，把她所擁有的一切，就是她全部的養生費用都投進去了。」</span></span>
</div>

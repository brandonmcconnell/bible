<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 馬太福音 8:28–34; 馬可福音 4:35"> 他們來到湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直譯「海」；指「加利利湖（海）」。">a</a></sup>的對岸，進了格拉森<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="格拉森——有古抄本作「格達拉」。">b</a></sup>人的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 1:23; 以賽亞書 65:4; 馬可福音 5:8"> 耶穌剛下船，就有一個被汙靈附身的人，從墓地迎著他來。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 65:4; 路加福音 8:29; 但以理書 4:32–33"> 這個人住在墓地裡，沒有人能捆住他，就是用鐵鏈也不行。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 3:7–8"> 他經常被腳鐐和鐵鏈捆起來，然而他總是掙斷鐵鏈、打碎腳鐐。沒有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 2:7–8; 列王紀上 18:28; 約翰福音 8:44"> 不管黑夜白晝，他常常在墓地和山上喊叫，又用石頭砍自己。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各書 2:19; 詩篇 66:3; 路加福音 4:41"> 他遠遠地看見耶穌，就跑過去，向他下拜，</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 8:29; 使徒行傳 16:17; 馬太福音 26:63"> 大聲喊叫說：「至高神的兒子耶穌，我與你有什麼關係？我藉著神懇求你，不要折磨我！」</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 1:25; 馬可福音 9:25–26; 使徒行傳 16:18"> 這是因為耶穌對他說：<span className="woj">「你出來，汙靈！離開這個人！」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 馬可福音 5:15; 馬太福音 26:53"> 耶穌問他：<span className="woj">「你叫什麼名字？」</span><br />他回答說：「我名叫『軍團』，因為我們眾多。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 3:22; 馬可福音 5:13"> 他一再央求耶穌不要把它們趕出那個地方。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 11:7–8; 以賽亞書 65:4; 以賽亞書 66:3"> 當時，那裡有一大群豬正在附近的山上吃食。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:11; 約伯記 1:10–12; 路加福音 22:31–32"> 那些汙靈<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那些汙靈——原文直譯「它們」；有古抄本作「所有的鬼魔」。">c</a></sup>就央求耶穌，說：「求你打發我們到豬群裡，好讓我們進入豬裡面去吧！」</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:22; 彼得前書 3:22; 約伯記 2:6"> 耶穌<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「立刻」。">d</a></sup>准許了它們，汙靈就出來，進入豬裡面。那群豬約有兩千頭，牠們從山崖衝到湖裡，在湖裡淹死了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 馬太福音 8:33"> 那些放豬的人就逃跑了，去把這事傳到城裡城外。於是人們就來<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="來——有古抄本作「出來」。">e</a></sup>看發生了什麼事。</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 1:13; 提摩太後書 1:7; 撒母耳記上 6:20–21"> 他們來到耶穌那裡，看見那曾經有鬼魔附身的，就是被『軍團』所附的那個人，穿著衣服，神志清醒地坐著，他們就懼怕起來。</span>
<span className="v" id="v16" data-v="16"> 那些看見的人，把發生在有鬼魔附身的人身上和有關豬群的事，都告訴了大家。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 8:34; 馬可福音 1:24; 路加福音 8:37"> 他們就開始央求耶穌離開他們的地區。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比書 1:23–24; 馬可福音 5:17"> 耶穌上船的時候，那曾被鬼魔附身的人懇求他，要與他在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 66:16; 約翰福音 4:29; 以賽亞書 38:9–20"> 耶穌沒有答應，卻對他說：<span className="woj">「你回家去吧，到你的親友那裡，告訴他們主為你做了什麼，以及他怎樣憐憫你。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 7:31; 馬太福音 4:25"> 於是那個人離開了，開始在德卡波利斯地區傳揚耶穌為他做了什麼樣的事。眾人都感到驚奇。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 9:1; 馬可福音 4:1; 路加福音 8:40"> 耶穌又上船渡到對岸。有一大群人聚集到他那裡，他就留在湖邊。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行傳 18:8; 馬可福音 5:35–36"> 這時候，來了一個名叫睚魯的會堂主管。他一見到耶穌，就俯伏在耶穌腳前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 馬可福音 16:18"> 迫切地懇求他，說：「我的小女兒快要死了。求你來按手在她身上，好讓她得救治，能活下去。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬可福音 5:31; 馬可福音 3:20; 路加福音 7:6"> 耶穌就與他一起去，有一大群人跟隨耶穌，並擁擠他。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 15:25–27; 路加福音 8:43–44; 馬太福音 9:20–22"> 有一個婦人，患了十二年的血漏病。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 30:12–13; 耶利米書 8:22; 詩篇 108:12"> 她在許多醫生手裡受了很多苦，花盡了她所有的一切，沒有任何效果，反而倒變得更嚴重了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 19:12; 馬太福音 14:36; 使徒行傳 5:15"> 她聽說了耶穌的事，就夾在人群中，從後面摸了一下耶穌的衣服，</span>
<span className="v" id="v28" data-v="28"> 原來她想：「只要我摸到他的衣服，就會得救治。」</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 5:34; 詩篇 30:2; 馬可福音 3:10"> 立刻，她的血漏就止住了，她也感覺到身體從病痛中痊癒了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶穌自己裡面立刻知道有能力從他而出，就在人群中轉過身來，問：<span className="woj">「誰摸了我的衣服？」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 他的門徒們對他說：「你看這群人擁擠著你，你還問『誰摸了我』嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 可是耶穌環視周圍，要知道是誰做了這事。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那婦人知道發生在自己身上的事，就懼怕起來，戰戰兢兢地上前俯伏在耶穌面前，把真實情況全告訴了他。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 馬太福音 9:22; 路加福音 7:50"> 耶穌對她說：<span className="woj">「女兒，你的信救了你，平平安安地去吧。你從病痛中痊癒了吧！」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 約翰福音 11:39; 馬可福音 5:22"> 耶穌還在說話的時候，有些人從會堂主管的家裡來，對睚魯<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="對睚魯——輔助詞語。">f</a></sup>說：「你的女兒已經死了，何必再麻煩老師呢？」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 馬太福音 9:28–29; 約翰福音 11:40"> 耶穌卻當做沒聽見他們所說的話，對會堂主管說<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶穌卻當做沒聽見他們所說的話，對……說——有古抄本作「耶穌聽見他們所說的話，就立刻對……說」。">g</a></sup>：<span className="woj">「不要怕，只要信！」</span></span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 9:40; 馬可福音 14:33; 哥林多後書 13:1"> 然後他除了彼得、雅各和雅各的弟弟<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="弟弟——原文直譯「兄弟」。">h</a></sup>約翰以外，不准別的人跟著。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 9:23–24; 路加福音 8:52–53; 馬可福音 5:22"> 他們來到會堂主管的家裡，耶穌看見一片混亂，有人哭泣，有人哀號。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 20:10; 帖撒羅尼迦前書 5:10; 帖撒羅尼迦前書 4:13–14"> 耶穌進去對他們說：<span className="woj">「為什麼慌亂哭泣呢？孩子不是死了，而是睡了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="尼希米記 2:19; 列王紀下 4:33; 馬太福音 9:24–25"> 他們就譏笑耶穌。耶穌把他們都趕出去，只帶著孩子的父母和一起來的人，進入孩子所在的地方<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="孩子所在的地方——有古抄本作「孩子躺著的地方」。">i</a></sup>。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 他握著孩子的手，對她說：<span className="woj">「塔利達，庫莫！</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="塔利達，庫莫！——亞蘭文詞語的音譯。">j</a></sup><span className="woj">」</span>——這翻譯出來就是<span className="woj">「小女孩，我吩咐你起來！」</span></span>
<span className="v" id="v42" data-v="42" data-xref="馬可福音 4:41; 使徒行傳 3:10–13; 馬可福音 7:37"> 那女孩隨即起來，開始走動。她那時十二歲。大家立刻目瞪口呆，大為驚訝。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 8:4; 馬太福音 9:30; 馬可福音 1:43"> 耶穌鄭重地吩咐他們，不要讓任何人知道這事，又吩咐給孩子吃東西。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:1–2; 出埃及記 12:6–20; 約翰福音 13:1"> 過兩天就是逾越節和除酵節了。祭司長們和經文士們在圖謀怎樣用詭計拘捕耶穌，把他殺掉。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 7:40; 箴言 21:30; 約翰福音 12:19"> 不過他們說：「不可在節日期間，免得民眾發生騷亂。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 7:37–39; 約翰福音 12:1–8; 約翰福音 11:2"> 耶穌在伯大尼，在痲瘋病人西門家裡坐席的時候，有一個女人拿著一個玉瓶進來。瓶裡盛著<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瓶裡盛著——輔助詞語。">a</a></sup>極其貴重的純哪噠香液。她打破玉瓶，把香液澆在耶穌的頭上。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 12:4–5; 馬太福音 26:8–9; 瑪拉基書 1:12–13"> 有些人心裡很不滿，說：「為什麼要這樣浪費香液呢？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 13:29; 以弗所書 4:28; 哥林多前書 10:10"> 這香液本來可以賣三百多個銀幣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三百多個銀幣——原文為「300多得拿利」。1得拿利=約1日工資的羅馬銀幣。">b</a></sup>，分給窮人。」他們就責備那女人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多書 3:14; 希伯來書 10:24; 希伯來書 13:21"> 耶穌說：<span className="woj">「由她吧！你們為什麼為難她呢？她為我做了一件美好的事。</span></span>
<span className="v" id="v7" data-v="7" data-xref="申命記 15:11; 馬太福音 26:11; 雅各書 2:14–16"> <span className="woj">要知道，你們總是有窮人與你們在一起，只要你們願意，隨時可以為他們做好事。但你們不總是有我。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 8:12; 約翰福音 12:7; 馬可福音 15:42–1"> <span className="woj">她盡她所能的做了。她是為我的安葬，預先膏抹了我的身體。</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 26:12–13; 馬可福音 16:15; 馬太福音 24:14"> <span className="woj">我確實地告訴你們：在全世界，福音無論傳到什麼地方，這女人所做的事也將被述說，做為對她的記念。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 22:3–6; 馬太福音 26:14–16; 約翰福音 13:2"> 那時候，加略人猶大，就是十二使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使徒——輔助詞語。">c</a></sup>中的一個，到祭司長們那裡去，要把耶穌交給他們。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 6:10; 何西阿書 7:3; 猶大書 1:11"> 他們聽了就歡喜，並且許諾給他銀錢。於是猶大就圖謀怎樣找機會把耶穌交出去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 12:6; 出埃及記 12:18; 馬太福音 26:17–19"> 除酵節的第一日，就是人們宰殺逾越節羔羊的那一天，耶穌的門徒們問他：「你要我們到哪裡去預備，好讓你吃逾越節的晚餐呢？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 22:10–13; 馬太福音 26:18–19; 路加福音 19:30–33"> 於是耶穌差派了他的兩個門徒，對他們說：<span className="woj">「你們進城去，會有一個人提著一罐水迎面而來，你們就跟著他。</span></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 3:20; 馬可福音 11:3; 約翰福音 13:13"> <span className="woj">他進哪一家，你們就對那家的主人說：『老師問：我的客房，就是我與我的門徒們一起吃逾越節晚餐的客房在哪裡呢？』</span></span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 1:13; 詩篇 110:3; 箴言 21:1–2"> <span className="woj">他會給你們看樓上一間預備好的大房間。你們就在那裡為我們預備吧。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 16:4; 路加福音 22:13; 路加福音 22:35"> 兩個門徒出去，進了城，所看到的正如耶穌對他們所說的。他們就預備了逾越節的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:14; 約翰福音 13:21–26; 馬太福音 26:20–24"> 到了晚上，耶穌與十二使徒一起來了。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; 約翰福音 6:47; 約翰福音 6:70"> 他們坐著吃飯的時候，耶穌說：<span className="woj">「我確實地告訴你們：你們當中有一個人要出賣我，他正與我一起吃飯。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:21–23; 馬太福音 26:22; 約翰福音 13:22"> 他們開始感到憂傷，就一個接一個地問耶穌：「不會是我吧？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 13:26; 馬太福音 26:23; 約翰福音 6:71"> 耶穌對他們說：<span className="woj">「是你們十二使徒中的一個。他正與我一同在盤子裡蘸餅。</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 26:24–25; 以賽亞書 53:1–12; 約翰福音 19:28"> <span className="woj">人子確實要離去，正如經上指著他所寫的，但是出賣人子的那個人有禍了。對他來說，沒有出生倒好。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 26:26–29; 馬可福音 14:24; 哥林多前書 10:16–17"> 在他們吃的時候，耶穌拿起餅來，祝福了，就掰開，遞給門徒們，說：<span className="woj">「你們領受</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「吃」。">d</a></sup><span className="woj">吧，這是我的身體。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬可福音 14:22; 馬太福音 26:27; 哥林多前書 10:16"> 接著，他拿起杯來，祝謝了，遞給門徒們。他們都喝了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 9:11; 出埃及記 24:8; 啟示錄 7:9–17"> 耶穌對他們說：<span className="woj">「這是我的血，是為立約</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="約——有古抄本作「新約」。">e</a></sup><span className="woj">的，為許多人所流的。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 26:29; 詩篇 104:15; 路加福音 22:16–18"> <span className="woj">我確實地告訴你們：我絕不再喝這葡萄汁</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="葡萄汁——或譯作「葡萄酒」；原文直譯「葡萄樹的產品」。">f</a></sup><span className="woj">，直到我在神的國裡喝新的那一天。」</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 26:30; 路加福音 22:39; 使徒行傳 16:25"> 他們唱了讚美詩<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="讚美詩——那時代的逾越節晚餐時、晚餐後，所唱的讚美詩是《詩篇》113-118篇。">g</a></sup>，就出來，往橄欖山去了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 13:7; 約翰福音 16:32; 馬太福音 26:31"> 耶穌對他們說：<span className="woj">「你們都將被絆倒</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="你們都將被絆倒——有古抄本作「今天晚上，你們都將因我被絆倒」。">h</a></sup><span className="woj">，因為經上記著：</span><br /><span className="pl pl-1 woj">『我將擊打牧人，</span><br /><span className="pl pl-1 woj">羊群就被分散。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 28:16; 馬可福音 16:7; 馬太福音 28:7"> <span className="woj">但是我復活以後，要在你們之前到加利利去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 26:33–35; 路加福音 22:33–34; 約翰福音 13:36–38"> 彼得對耶穌說：「即使所有的人被絆倒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="被絆倒——或譯作「放棄信仰」。">i</a></sup>，我還是不會。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 13:38; 馬可福音 14:66–72; 創世記 1:5"> 可是耶穌對他說：<span className="woj">「我確實地告訴你：今天，就在今夜，雞叫兩遍以前，你會三次不認我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 19:8; 約翰福音 13:37; 箴言 16:18"> 彼得卻堅決<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="堅決——有古抄本作「更加堅決」。">j</a></sup>地說：「就算我必須與你同死，我也絕不會不認你。」所有的門徒也都這麼說。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 14:36; 馬可福音 14:39; 詩篇 18:5–6"> 他們來到一個名叫客西馬尼的地方。耶穌對他的門徒們說：<span className="woj">「我禱告的時候，你們坐在這裡。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:44; 希伯來書 5:7; 馬可福音 5:37"> 他帶了彼得、雅各和約翰一起去。這時候，他開始憂懼起來，極其難過，</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 12:27; 馬可福音 13:35–37; 彼得前書 5:8"> 對他們說：<span className="woj">「我的靈魂很憂傷，幾乎要死。你們留在這裡，要警醒。」</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 14:41; 申命記 9:18; 希伯來書 5:7"> 耶穌稍往前走，俯伏在地，禱告說，如果有可能，讓那時刻離開他。</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太書 4:6; 羅馬書 8:15–16; 約翰福音 5:30"> 他說：<span className="woj">「阿爸！父啊！在你，沒有不可能的事，請把這杯從我這裡拿走吧！但不要照我的意願，而要照你的意願。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬太福音 26:40; 馬可福音 14:29–31; 希伯來書 12:3"> 耶穌回來，看見他們睡著了，就對彼得說：<span className="woj">「西門，你睡著了？難道你不能警醒一個小時嗎？</span></span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 26:41; 馬太福音 24:42; 路加福音 21:36"> <span className="woj">要警醒禱告，免得陷入試探。你們心靈雖然願意，肉體卻是軟弱的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="馬太福音 26:42–44; 哥林多後書 12:8; 馬太福音 6:7"> 耶穌又去禱告，說了同樣的話。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 9:33–34; 羅馬書 3:19; 創世記 44:16"> 他又回來，看見他們在睡覺，因為他們的眼皮發沉，也不知道要回答耶穌什麼。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 14:35; 馬可福音 9:31; 約翰福音 17:1"> 耶穌第三次回來，對他們說：<span className="woj">「你們還在睡覺、休息嗎？已經夠了，時候到了！看哪，人子被交在</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="被交在——或譯作「被出賣到」。">k</a></sup><span className="woj">罪人的手裡了。</span></span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 26:46; 約翰福音 18:1–2"> <span className="woj">起來，我們走吧！看，那出賣我的人快到了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="約翰福音 18:3–11; 路加福音 22:47–53; 馬太福音 26:47–56"> 耶穌還在說話的時候，忽然十二使徒之一的猶大來了。有一群人拿著刀劍和棍棒與他一起來，他們是祭司長們、經文士們和長老們所派來的。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 26:48–50; 箴言 27:6; 詩篇 55:20–21"> 那出賣耶穌的人已經和他們定了一個暗號，說：「我如果親吻誰，誰就是那個人。你們把他抓住，小心地帶走。」</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 23:7–10; 瑪拉基書 1:6; 馬可福音 12:14"> 猶大一到，就上前對耶穌說：「拉比！」然後親吻了他。</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 18:12; 耶利米哀歌 4:20; 使徒行傳 2:23"> 他們就下手拘捕了耶穌。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 18:10–11; 馬太福音 26:51–54; 路加福音 22:49–51"> 站在旁邊的一個門徒拔出刀來，向大祭司的奴僕砍去，削掉了他的一個耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="路加福音 22:52–53; 撒母耳記上 26:18; 撒母耳記上 24:14–15"> 耶穌對他們說：<span className="woj">「你們帶著刀劍和棍棒出來抓我，就像對付強盜那樣嗎？</span></span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 18:20; 約翰福音 8:2; 路加福音 22:37"> <span className="woj">我天天在聖殿裡教導人，和你們在一起，而你們不抓我。不過這是為要應驗那些經文。」</span></span>
<span className="v" id="v50" data-v="50" data-xref="馬可福音 14:27; 約翰福音 16:32; 詩篇 88:18"> 這時候，所有的門徒都離開他逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> 有一個年輕人，赤身披上一塊細麻布，跟在耶穌後面。那些人<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="那些人——有古抄本作「一些年輕人」。">l</a></sup>就抓住他，</span>
<span className="v" id="v52" data-v="52" data-xref="馬可福音 13:14–16; 創世記 39:12; 約伯記 2:4"> 可是他卻丟下麻布，赤著身子逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="馬太福音 26:57–68; 約翰福音 18:12–14; 路加福音 22:54–62"> 他們把耶穌帶到大祭司那裡。所有的祭司長、長老和經文士都聚在一起。</span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 18:18; 馬太福音 26:3; 約翰福音 18:25"> 彼得遠遠地跟著耶穌，直到進了大祭司的院子裡。他與差役們一起坐在火邊取暖。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="彼得前書 3:16–18; 馬太福音 26:59–60; 馬太福音 5:22"> 當時，祭司長們和全議會的人為了要處死耶穌，都在尋找證據來控告他。可是他們找不出什麼。</span>
<span className="v" id="v56" data-v="56"> 許多人做偽證誣告他，可是這些證詞互相矛盾。</span>
<span className="v" id="v57" data-v="57" data-xref="使徒行傳 6:13–14; 馬太福音 26:60–61; 約翰福音 2:18–21"> 有一些人站起來做偽證控告他，說：</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 2:19; 希伯來書 9:11; 哥林多後書 5:1"> 「我們聽他說過『我要拆毀這座人手所造的聖所，三天內另建一座不是人手所造的。』」</span>
<span className="v" id="v59" data-v="59"> 可是他們這個證詞也是互相矛盾的。</span>

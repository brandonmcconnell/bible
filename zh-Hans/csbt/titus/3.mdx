<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 13:1–7; 彼得前書 2:13–17; 傳道書 10:4"> 你提醒他們要服從統治者和掌權者，要順從，並要為一切美善的工作做好準備；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 4:31; 提摩太後書 2:24–25; 以弗所書 4:2"> 不要毀謗人、不要爭吵；要謙和，在一切事上對所有的人都要顯出溫柔。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 2:1–3; 羅馬書 6:17; 歌羅西書 1:21"> 其實，我們從前也是無知、悖逆、被迷惑的，做各種欲望和享樂的奴僕，活在惡毒和嫉妒中，是可憎惡的，又彼此相恨。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:4–10; 提多書 2:10–11; 提摩太前書 4:10"> <span className="pl pl-1">但是，當神我們救主的仁慈和他對人的愛顯明的時候，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:8–9; 提摩太後書 1:9; 哥林多前書 6:11"> <span className="pl pl-1">他拯救了我們；</span><br /><span className="pl pl-1">這不是本於我們所做的義行，</span><br /><span className="pl pl-1">而是照著他的憐憫，</span><br /><span className="pl pl-1">藉著重生的洗滌和聖靈的更新。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:28; 羅馬書 5:5; 使徒行傳 10:45"> <span className="pl pl-1">神藉著我們的救主耶穌基督，</span><br /><span className="pl pl-1">將聖靈豐豐富富地傾注在我們身上，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:17; 提多書 2:11; 哥林多前書 6:11"> <span className="pl pl-1">使我們藉著他的恩典被稱為義，</span><br /><span className="pl pl-1">可以照著永恆生命的盼望成為繼承人。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="提多書 3:14; 提多書 1:9; 詩篇 16:2–3"> 這話是信實的。我希望你強調這些事，好讓那些信了神的人專心投入美好的工作；這些事對人是好事，是有益處的。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 2:14; 提摩太後書 2:23; 提摩太前書 4:7"> 至於愚拙的辯論、家譜、紛爭和律法上的爭執，你都要避免；因為這些都是無用的，是虛妄的。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 16:17; 約翰二書 1:10; 馬太福音 18:15–17"> 對那製造分裂的人，在第一次、第二次的警戒以後，就要棄絕他，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 10:26; 路加福音 19:22; 馬太福音 25:26–28"> 因為你知道，這樣的人已經背道，一直犯罪，定了自己的罪。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 4:9; 提摩太後書 4:12; 哥林多前書 16:8–9"> 我派阿特馬斯或特其庫斯到你那裡以後，你要盡快到尼科波利斯來見我，因為我已經決定在那裡過冬。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 18:24; 馬太福音 22:35; 約翰三書 1:6–8"> 你要盡快送齊納斯律師和阿波羅上路，好讓他們一無所缺。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:10; 提多書 3:8; 馬太福音 7:19"> 我們自己的人，為了緊要的需用也應該學會投入美好的工作，免得成為不結果子的人。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前書 1:5; 以弗所書 6:23–24; 約翰二書 1:1–2"> 所有與我在一起的人都問候你。請問候那些在信仰上愛我們的人。願恩典與你們大家同在！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「阿們。」">a</a></sup></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:1; 以弗所書 3:1; 腓利門書 1:9"> 基督耶穌的囚犯保羅，以及弟兄提摩太，<br />致我們親愛的弟兄和同工腓利門，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 2:25; 歌羅西書 4:17; 羅馬書 16:5"> 還有姐妹<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="姐妹——有古抄本作「蒙愛的」。">a</a></sup>阿菲婭和我們的戰友阿其波斯，以及在你家裡的教會：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="羅馬書 1:7; 以弗所書 1:2; 哥林多後書 13:14"> 願恩典與平安從神我們的父和主耶穌基督臨到你們！</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:8; 以弗所書 1:16; 帖撒羅尼迦後書 1:3"> 我在禱告中提到你的時候，總是感謝我的神，</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 1:4; 以弗所書 1:15; 哥林多前書 16:1"> 因為我聽說了你對主耶穌和所有聖徒所懷的愛心和信仰。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 1:9–11; 彼得後書 1:8; 歌羅西書 1:9"> 藉著認識在我們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我們——有古抄本作「你們」。">b</a></sup>中間為基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——有古抄本作「基督耶穌」。">c</a></sup>所做的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="所做的——輔助詞語。">d</a></sup>一切美善之事，願你在信仰上的契合<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="契合——或譯作「溝通」或「分享」。">e</a></sup>能發揮功效。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 7:13; 帖撒羅尼迦前書 3:9; 哥林多後書 7:4"> 實際上，我由於你的愛得了極大的喜樂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="喜樂——有古抄本作「恩典」或「感謝」。">f</a></sup>和鼓勵，因為弟兄啊，聖徒們的情感藉著你得了安寧。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 2:6; 哥林多後書 10:8; 哥林多後書 3:12"> 所以，雖然我在基督裡大有膽量，可以吩咐你去做<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="去做——輔助詞語。">g</a></sup>合宜的事，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 5:20; 以弗所書 4:1; 羅馬書 12:1"> 但為了愛的緣故，我寧願懇求你。我<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="我——輔助詞語。">h</a></sup>保羅——像我這樣一個老人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="老人——或譯作「年長的」或「年老的」。">i</a></sup>，而現在又是基督耶穌的囚犯——</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 4:9; 哥林多前書 4:15; 提摩太前書 1:2"> 為我在捆鎖中所生的孩子<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="我……所生的孩子——指「保羅帶他信耶穌」。參《哥林多前書》4:15。">j</a></sup>奧尼斯莫<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="奧尼斯莫——意思為「有益處的」。">k</a></sup>，懇求你。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 4:11; 約伯記 30:1–2; 彼得前書 2:10"> 他從前對你沒有益處，但如今對你、對我都有益處了。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 6:14–15; 耶利米書 31:20; 馬可福音 11:25"> 我把他本人送回你那裡，就是說，把我的情感送回你那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 1:7; 以弗所書 3:1; 哥林多前書 16:17"> 我本來想把他留在自己身邊，好讓他在我為福音被捆鎖的期間，能替你服事我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 9:7; 歷代志上 29:17; 彼得前書 5:2–3"> 但是沒有你的同意，我就不願意做什麼，好讓你的美善之事不是出於勉強，而是出於自願。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 50:20; 創世記 45:5–8; 以賽亞書 20:6"> 其實，他暫時離開你，或許正是為了使你可以永遠得著他——</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 3:22; 馬太福音 23:8; 哥林多前書 7:22"> 不再像一個奴僕，而是高於奴僕，是一位蒙愛的弟兄。他對我尤其是這樣，更何況對你呢！無論是在肉體上或在主裡面都是這樣。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 8:23; 馬太福音 10:40; 腓利門書 1:12"> 因此，你如果把我當做同伴，就請接納他，像接納我一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:4–7"> 如果他虧負過你什麼，或現在欠了你什麼，請把它算在我的帳上。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 6:11; 加拉太書 5:2; 哥林多前書 4:15"> 我保羅親手寫下：我必償還——免得我對你說，連你自己也是欠我的呢！</span>
<span className="v" id="v20" data-v="20" data-xref="約翰三書 1:4; 腓利門書 1:7; 腓利門書 1:12"> 是的，弟兄！願我在主裡從你得到喜樂<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="喜樂——或譯作「益處」。">l</a></sup>，請你使我的情感在基督<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="基督——有古抄本作「主」。">m</a></sup>裡得到安寧。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦後書 3:4; 哥林多後書 2:3; 哥林多後書 7:16"> 我深信你會順從，就寫了信給你，因為我知道你所做的甚至會超過我所求的。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 1:11; 腓立比書 2:24; 約翰二書 1:12"> 同時還請你為我預備住處，因為我希望藉著你們的禱告，能回到你們那裡去。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:7; 羅馬書 16:7; 歌羅西書 4:12"> 在基督耶穌裡與我一起坐牢的以帕弗拉問候你。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:10–11; 歌羅西書 4:14; 歌羅西書 4:10"> 我的同工馬可、亞里達古、迪馬斯、路加也都問候你。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 4:22; 羅馬書 16:23; 羅馬書 16:20"> 願我們主耶穌基督的恩典與你們的靈同在！<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本附「阿們。」">n</a></sup></span>
</div>
</div>

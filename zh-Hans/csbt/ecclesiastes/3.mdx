<span className="v" id="v9" data-v="9" data-xref="傳道書 1:3; 傳道書 5:16; 箴言 14:23"> 做事的人如此勞苦，有什麼益處呢？</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 1:13–14; 創世記 3:19; 傳道書 2:26"> 我看到神加給世人擔子，讓他們在其中操勞。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 11:33; 羅馬書 1:19–20; 約伯記 11:7"> 神使萬物各按其時成為美好，又把永恆放在人的心裡。雖然如此，神從始至終所做的事，人卻無法查明。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 37:3; 傳道書 3:22; 提摩太前書 6:18"> 我知道：人一生中沒有什麼比喜樂和行善更好的；</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 128:2; 傳道書 9:7; 傳道書 2:24"> 並且，人人吃喝，在一切的勞苦中享受好處——這也是神的恩賜。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:17; 詩篇 33:11; 羅馬書 11:36"> 我知道：神所做的一切，都必永存，無可增添，無可減少；神這樣做，是要人在他面前心存敬畏。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 1:9–10; 傳道書 6:10"> 現在有的，早已經有過；將要有的，也早已經有過；因為神使已過的事重複再現<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神使已過的事重複再現——原文直譯「神尋回已過的事」。">a</a></sup>。</span>

<span className="v" id="v17" data-v="17" data-xref="哥林多後書 5:10; 傳道書 12:14; 馬太福音 16:27"> 我心裡說：「義人和惡人，神都會審判；因為在他那裡，萬事萬務都有定時。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 73:22; 詩篇 49:12; 希伯來書 9:27"> 至於世人，我心裡說：「神在考驗他們，要讓他們看見自己像獸類一樣」；</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 49:12; 詩篇 49:20; 詩篇 89:47–48"> 因為世人的命運和獸的命運都一樣：這個會死，那個也一樣會死，他們都有一樣的氣息，人不比獸優越。這全是虛空！</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:19; 約伯記 34:15; 傳道書 12:7"> 他們都同歸一處，都出於塵土，也都歸於塵土。</span>

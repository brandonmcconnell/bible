<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各書 1:19; 希伯來書 12:28–29; 箴言 15:8"> 你去神的殿時，要謹慎腳步；近前聽，勝過像愚昧人那樣獻上祭物，因為愚昧人不知道自己在作惡。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:7; 箴言 10:19; 以賽亞書 55:9"> 在神面前不要冒失開口，也不要心急發言，因為神在天上，你在地上，所以你要少言寡語。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 傳道書 10:12–14"> 要知道，夢來自事務繁多，愚昧的聲音來自多言多語。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 30:2; 申命記 23:21–23; 詩篇 76:11"> 你向神許了願，償還不可遲延，因為神不喜歡愚昧人；你所許的願應當償還。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 5:4; 申命記 23:22; 箴言 20:25"> 不許願，好過許了願卻不償還。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:26; 約翰二書 1:8; 雅各書 3:2"> 不要任你的口使自己犯罪，也不要在使者面前說所許的願是個失誤。為什麼要使神因你的話而發怒，摧毀你手中的工作呢？</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 12:13; 馬太福音 12:36; 傳道書 8:12"> 多夢多語帶來更多的虛空<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="多夢多語帶來更多的虛空——原文直譯 「多夢帶來更多的虛空和話語」。">a</a></sup>；因此你當敬畏神。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 12:5; 傳道書 4:1; 傳道書 3:16"> 如果你在某一省中看到窮人受欺壓，公正和公義被奪去，不要因此感到驚奇，因為高位者之上有更高的在保護<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保護——或譯作「鑒察」；本節下同。">b</a></sup>他，在他們之上還有更高的保護他們。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 4:7–23; 詩篇 115:16; 創世記 1:29–30"> 各人都從這塊地得好處，甚至君王也藉著這塊地得益處。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:10; 馬太福音 6:24; 路加福音 12:15"> 貪愛銀子的不會因銀子滿足，貪愛財富的也不會因利益滿足。這也是虛空！</span>
<span className="v" id="v11" data-v="11" data-xref="約翰一書 2:16; 哈巴谷書 2:13; 詩篇 119:36–37"> 財物增加，吃用的人也增加，而主人除了眼看以外，還有什麼益處呢？</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 詩篇 4:8; 耶利米書 31:26"> 勞力的人無論吃多吃少，都睡得甜美；富有人的豐足，卻不容他安睡。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="傳道書 6:1–2; 路加福音 18:22–23; 創世記 19:14"> 我看到在日光之下有一件令人痛心的悲苦之事：財主所積存的財富導致了他的悲苦，</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 6:19–20; 哈該書 2:16–17; 箴言 23:5"> 那財富也在悲苦的事中消亡了；所以當他生兒子的時候，自己的手中卻一無所有。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 49:17; 約伯記 1:21; 提摩太前書 6:7"> 他從母腹中怎樣赤身而來，也必怎樣赤身而去，就像他來的那樣；至於他的勞苦所得，他的手分毫不能帶走——</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 傳道書 1:3; 約翰福音 6:27"> 這也是一件令人痛心的悲苦之事，就是他來的時候怎樣，去的時候也怎樣；他為風勞苦，對他有什麼益處呢？</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 127:2; 以西結書 4:16–17; 詩篇 90:7–11"> 並且他一生的日子都在黑暗中吃喝，多有煩惱、疾病和怒氣。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="傳道書 2:24; 傳道書 3:12–13; 傳道書 3:22"> 看哪，我所見為善為美的，就是人在神所賜給他一生可數的日子裡吃喝，享受他在日光之下勞苦所得的一切好處，因為這是他的份。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 8:18; 傳道書 3:13; 傳道書 6:2"> 而且，對每個蒙神賜予富貴資產的人，神也使他能享用，並領受他的份，在自己的勞苦中歡喜——這就是神的恩賜。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 65:21–24; 以賽亞書 65:13–14; 詩篇 37:16"> 他並不多思考自己一生的日子，因為神以喜樂充滿他的心。</span>
</div>

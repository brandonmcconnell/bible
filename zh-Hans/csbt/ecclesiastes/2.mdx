<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 傳道書 8:15; 雅各書 5:5"> 我對自己說：「來吧，我要用享樂試驗你，讓你看看有什麼好處！」看哪，這也是虛空！</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 傳道書 7:2–6; 彼得前書 4:2–4"> 論到歡笑，我說：「這是發狂」；論到享樂，我說：「這有什麼用呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 傳道書 1:17; 箴言 31:4–5"> 我的心以智慧引領我的同時，我心裡探察如何用酒使我的肉體暢快並保持愚昧狀，直到我看清世人一生可數的日子裡，在天下做什麼才有益處。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 7:1–12; 歷代志下 8:11; 歷代志下 26:10"> 我擴建工程，為自己建造房屋，種植葡萄園；</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米書 39:4"> 我為自己造了庭園和園林，在其中栽種各樣的果樹；</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 2:14; 詩篇 1:3; 耶利米書 17:8"> 我為自己造了蓄水池，用以澆灌長滿樹木的林子；</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:4; 創世記 15:3; 列王紀上 4:23"> 我買下了男僕和婢女，我也有生在我家裡的奴僕；我還擁有大量的牛群和羊群，超過我之前在耶路撒冷的所有人；</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 10:10; 列王紀上 9:28; 撒母耳記下 19:35"> 我又為自己積聚金銀，還有來自君王們和各省的珍寶。我也為自己招納了男女歌手，以及許多的妃嬪，都是世人引以為樂的。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 29:25; 傳道書 1:16; 列王紀上 10:23"> 於是我日漸昌大，超越了我之前在耶路撒冷的所有人，而我的智慧仍然與我同在。</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 9:9; 傳道書 5:18; 傳道書 3:22"> 我的眼目所追求的一切，我都不禁止；我的心所歡喜的一切，我都不拒絕；因為我的心在我一切的勞苦中歡喜——這就是我在一切勞苦中所得的份。</span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 1:14; 約翰一書 2:16–17; 傳道書 1:3"> 但當我回顧我手所做的一切事，以及我勞苦所做的工，看哪，全是虛空，全是捕風！在日光之下毫無益處。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="傳道書 1:17; 傳道書 7:25; 傳道書 1:9–10"> 我轉眼去看智慧、狂妄和愚昧。那在王之後來的人，到底能做什麼呢？不過是先前所做過的而已。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 5:8; 傳道書 7:11–12; 馬太福音 6:23"> 這樣我就看到：智慧勝過愚昧，就像光明勝過黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 49:10; 箴言 17:24; 傳道書 9:11"> <span className="pl pl-1">智慧人看得見他的道路</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="智慧人看得見他的道路——原文直譯「智慧人的眼睛在頭上」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">愚昧人卻在黑暗中行走。</span><br />不過我也明白，同樣的命運會臨到他們這兩種人。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 6:8; 傳道書 1:14; 傳道書 1:2"> 於是我心裡說：「既然愚昧人的命運也照樣會臨到我，那麼我為什麼要更有智慧呢？」我心裡就說：「這也是虛空！」</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 1:11; 傳道書 9:5; 詩篇 88:12"> 因為智慧人與愚昧人一樣，不會被永遠記念；在將要來的日子，一切都會被忘掉。智慧人怎麼像愚昧人一樣死亡呢？</span>
<span className="v" id="v17" data-v="17" data-xref="傳道書 2:11; 約拿書 4:8; 傳道書 4:2"> 於是我恨惡生命，因為在日光之下所做的事，對我都是悲苦。是的，全是虛空，全是捕風！</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:6; 詩篇 49:10; 路加福音 16:27–28"> 我恨惡自己一切的勞苦，就是我在日光之下的勞碌所為，因為我必把勞苦所得留給在我之後來的人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各書 3:17; 傳道書 3:22; 傳道書 9:13"> 那人是智慧是愚笨，誰知道呢？他卻要掌管我勞苦所得的一切，就是我在日光之下用智慧得來的。這也是虛空！</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 43:14; 約伯記 17:11–15; 哥林多後書 1:8–10"> 於是我回顧我在日光之下勞苦所做的一切工，就心感絕望；</span>
<span className="v" id="v21" data-v="21" data-xref="傳道書 2:17–18; 歷代志下 31:20–21; 歷代志下 34:2"> 因為一個人用智慧、知識和技能勞苦工作，卻把自己所得的份給了那未曾勞苦的人。這也是虛空，也是極大的悲苦！</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 127:2; 傳道書 1:3; 腓立比書 4:6"> 人一切的勞苦和他心裡的追求，就是他在日光之下的勞碌所為，到底能為自己成就什麼呢？</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 14:1; 約伯記 5:7; 詩篇 6:6–7"> 其實他一生的日子都是痛苦，他的事務都是煩惱，他的心甚至在夜間也不得安息。這也是虛空！</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="傳道書 3:22; 傳道書 8:15; 提摩太前書 6:17"> 對人而言，沒有什麼比吃喝並在勞苦中找到快樂更好的了！在我看，這也是出於神的手；</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 2:1–12; 列王紀上 4:21–24"> 因為離了他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他——馬索拉文本作「我」。">b</a></sup>，誰能吃喝，誰能享受呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 約伯記 27:16–17; 箴言 28:8"> 原來神把智慧、知識和喜樂賜給他所喜悅的人；至於罪人，神加給他們擔子，讓他們去收取、積聚，好給神所喜悅的人。這也是虛空，也是捕風！</span>
</div>

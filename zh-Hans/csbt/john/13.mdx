<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JHN" data-book-slug="john" data-book-name="約翰福音" data-chapter="13" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 12:23; 約翰一書 4:19; 約翰福音 13:34"> 逾越節前，耶穌知道他離開這世界回到父那裡去的時候到了。他一直愛世界上那些屬自己的人，並且愛他們到底。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:13–17; 使徒行傳 5:3; 約翰福音 13:26–27"> 晚餐的時候，魔鬼已經把出賣耶穌的念頭放在加略人西門的兒子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="兒子——輔助詞語。">a</a></sup>猶大的心裡。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 3:35; 馬太福音 11:27; 希伯來書 1:2"> 耶穌知道父把一切交在自己手裡，並且知道自己是從神那裡來，又要回到神那裡去。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:27; 哥林多後書 8:9; 路加福音 12:37"> 他從席位上起身，脫了外衣，拿起一條布巾束在自己腰上，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:44; 詩篇 51:2; 創世記 18:4"> 然後把水倒進盆裡，開始洗門徒們的腳，又用束在腰上的布巾擦乾。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬太福音 3:11–14; 約翰福音 1:27; 路加福音 5:8"> 他來到西門彼得面前，彼得對他說：「主啊，你洗我的腳嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理書 12:8; 約翰福音 12:16; 約翰福音 14:26"> 耶穌回答說：<span className="woj">「我所做的，你現在不理解，不過事後就會明白。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 36:25; 使徒行傳 22:16; 提多書 3:5"> 彼得說：「你絕不可洗我的腳，永遠不可！」<br />耶穌說：<span className="woj">「如果我不洗你，你就與我沒有份了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 51:7; 詩篇 51:2; 彼得前書 3:21"> 西門彼得說：「主啊！不單我的腳，連我的手、我的頭也要洗！」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 15:3; 哥林多後書 7:1; 哥林多後書 5:17"> 耶穌說：<span className="woj">「洗過澡的人，除了腳以外，沒有需要洗的；他是完全乾淨的。你們是乾淨的，但不是每個人都乾淨。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 13:26; 約翰福音 13:2; 約翰福音 13:21"> 原來，耶穌知道要出賣他的是誰，所以說<span className="woj">「你們不是每個人都乾淨。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 13:7; 約翰福音 13:4; 以西結書 24:24"> 耶穌洗完了他們的腳以後，穿上外衣，又坐下來，對他們說：<span className="woj">「你們明白我為你們做的事嗎？</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:46; 哥林多前書 12:3; 約翰福音 11:28"> <span className="woj">你們叫我『老師』，稱呼我『主』。你們說得對，因為我就是那一位。</span></span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 5:5; 使徒行傳 20:35; 羅馬書 12:16"> <span className="woj">因此，如果我——你們的主、你們的老師，還洗你們的腳，那麼你們也應該彼此洗腳。</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 2:6; 馬太福音 11:29; 彼得前書 3:17–18"> <span className="woj">事實上，我給你們做了榜樣，好讓你們也照著我為你們所做的去做。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:40; 約翰福音 15:20; 馬太福音 10:24–25"> <span className="woj">「我確確實實地告訴你們：沒有一個奴僕大過他的主人，也沒有一個被派的大過派他的人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 11:28; 雅各書 4:17; 雅各書 1:25"> <span className="woj">你們既然明白這些事，如果去做，就蒙福了。</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; 馬太福音 26:23; 約翰福音 17:12"> <span className="woj">我不是針對你們每個人而說的。我了解我所揀選的每個人，但這是為要應驗經上的話：『那吃我餅的人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那吃我餅的人——有古抄本作「與我一同吃餅的人」。">b</a></sup><span className="woj">，竟抬腳踢</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="踢——原文直譯「對付」。">c</a></sup><span className="woj">我。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 43:10; 約翰福音 14:29; 約翰福音 16:4"> <span className="woj">「如今，在事情發生以前，我先告訴你們，好讓你們在事情發生的時候，能相信我就是那一位。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:16; 路加福音 9:48; 馬太福音 25:40"> <span className="woj">我確確實實地告訴你們：那接受我所派的人，就是接受我；接受我的，就是接受派我來的那一位。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 13:18; 馬太福音 26:21; 馬可福音 14:18"> 說完這些話，耶穌靈裡煩擾，就指名說：<span className="woj">「我確確實實地告訴你們：你們當中有一個人要出賣我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 22:23; 馬太福音 26:22; 馬可福音 14:19"> 門徒彼此相看，不知道耶穌說的是誰。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 19:26; 約翰福音 21:7; 約翰福音 21:20"> 他的門徒當中，有一個挨著耶穌坐著<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="挨著耶穌坐著——原文直譯「坐在耶穌胸前」。">d</a></sup>，是耶穌所愛的。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 12:17; 路加福音 1:22; 使徒行傳 13:16"> 西門彼得就向他點頭示意，要他問耶穌所講的人到底是誰。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 21:20; 創世記 44:4–12; 以斯帖記 7:5"> 於是那門徒貼近耶穌<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="貼近耶穌——原文直譯「貼近耶穌的胸膛」。">e</a></sup>，問他：「主啊，是誰呢？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 26:23; 約翰福音 13:30; 馬可福音 14:19–20"> 耶穌回答：<span className="woj">「我蘸一塊餅給誰，就是誰。」</span>接著，他蘸了一塊餅拿給加略人西門的兒子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="兒子——輔助詞語。">f</a></sup>猶大。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:3; 約翰福音 13:2; 傳道書 9:3"> 猶大一接那塊餅，撒旦就進了他裡面。於是耶穌對他說：<span className="woj">「你要做的，就快一點做吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 在座的人，沒有一個明白耶穌為什麼對他說這話。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 12:5–6; 約翰福音 13:1; 以弗所書 4:28"> 因為猶大管錢包，有些人以為耶穌對他說，去買我們過節需要的東西，或是要他給窮人什麼東西。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 59:7; 約伯記 24:13–15; 箴言 4:16"> 猶大接了那塊餅，就立刻出去。那時候是夜間了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 14:13; 彼得前書 4:11; 約翰福音 7:39"> 猶大出去以後，耶穌就說：<span className="woj">「現在人子得了榮耀，神藉著人子也得了榮耀。</span></span>
<span className="v" id="v32" data-v="32" data-xref="啟示錄 22:1; 以賽亞書 53:10–12; 約翰福音 17:4–6"> <span className="woj">神既然藉著人子得了榮耀，</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「神既然藉著人子得了榮耀，」。">g</a></sup><span className="woj">神也將藉著自己榮耀人子，而且立刻就要榮耀他。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約翰福音 7:33–34; 約翰福音 8:21–24; 約翰福音 16:16–22"> <span className="woj">「孩子們哪，我與你們在一起的時候不多了。你們將尋找我，而且就像我曾經告訴過那些猶太人一樣，現在我也告訴你們：我去的地方，你們不能去。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以弗所書 5:2; 利未記 19:18; 約翰福音 15:17"> <span className="woj">「我給你們一條新的命令：就是要你們彼此相愛，就如我愛你們，為要使你們也彼此相愛。</span></span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 4:20–21; 約翰一書 3:10–14; 約翰一書 2:10"> <span className="woj">如果你們彼此之間有了愛，眾人從這一點就會知道你們是我的門徒了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="彼得後書 1:14; 約翰福音 13:33; 約翰福音 21:21–22"> 西門彼得問：「主啊，你要到哪裡去呢？」<br />耶穌回答：<span className="woj">「我去的地方，你現在不能跟著去，但以後會跟著去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 21:13; 使徒行傳 20:24; 馬可福音 14:27–31"> 彼得說：「主啊，為什麼我現在就不能跟隨你呢？為了你，我願意捨棄自己的生命！」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:34; 馬太福音 26:34; 馬可福音 14:30"> 耶穌回答：<span className="woj">「你願意為我捨命嗎？我確確實實地告訴你：雞叫以前，你必定三次不認我。</span></span>
</div>
</div>

</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JHN" data-book-slug="john" data-book-name="約翰福音" data-chapter="19" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 53:5; 以賽亞書 50:6; 馬太福音 20:19"> 於是彼拉多吩咐<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="吩咐——輔助詞語。">a</a></sup>把耶穌帶走，鞭打了。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 15:16–20; 路加福音 23:11; 馬太福音 27:27–31"> 士兵們用荊棘編了冠冕，戴在耶穌的頭上，又給他披上紫色袍子。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 27:29; 馬太福音 26:49; 路加福音 1:28"> 他們不斷地來到他面前說：「萬歲，猶太人的王！」又不住地用手掌打他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:38; 約翰福音 19:6; 路加福音 23:4"> 彼拉多再次出來對猶太人說：「看！我把他帶出來給你們，是要你們知道，我查不出他有什麼罪。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:2; 希伯來書 12:2; 以賽亞書 7:14"> 這時候，耶穌出來了，他戴著荊棘冠冕，披著紫色袍子。彼拉多對他們說：「看，這個人！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:31; 約翰福音 19:4; 使徒行傳 2:23"> 祭司長們和差役們一看見耶穌，就喊叫說：「釘上十字架！釘上十字架！」<br />彼拉多對他們說：「你們自己把他帶走釘上十字架！要知道，我查不出他有罪。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未記 24:16; 約翰福音 5:18; 馬太福音 26:63–66"> 那些猶太人回答：「我們有律法，按照這律法，他是應該死的，因為他把自己當做神的兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 19:13; 使徒行傳 14:11–19"> 彼拉多一聽這話，就更加懼怕了，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 18:33; 詩篇 38:13–15; 腓立比書 1:28"> 又進了總督府，問耶穌：「你到底是從哪裡來的？」耶穌卻沒有回答他。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 5:19; 約翰福音 18:39; 但以理書 3:14–15"> 彼拉多就說：「你不與我說話嗎？難道你不知道我有權釋放你，也有權把你釘上十字架嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 13:1; 約翰福音 3:27; 使徒行傳 2:23"> 耶穌回答：<span className="woj">「如果權柄不是從上面賜給你的，你就對我沒有任何權柄。所以，把我交給你的人有更大的罪。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 17:6–7; 約翰福音 18:33–36; 馬可福音 6:16–26"> 由此，彼拉多就想要釋放耶穌。可是猶太人喊叫說：「你如果釋放這個人，就不是凱撒的朋友了。所有把自己當做王的，就是反對凱撒的！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:5–7; 馬太福音 27:19; 阿摩司書 4:7"> 彼拉多聽了這話，就把耶穌帶到外面，並在一個叫「鋪石臺」的地方坐上了審判席。「鋪石臺」希伯來語<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希伯來語——或譯作「亞蘭語」。">b</a></sup>叫做「伽巴達」。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 27:62; 約翰福音 19:5; 馬可福音 15:25"> 那天是逾越節的預備日，大約在中午十二點<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="中午十二點——原文為「第六時刻」。">c</a></sup>，彼拉多對猶太人說：「看，你們的王！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 23:18; 使徒行傳 21:36; 約翰福音 19:6"> 他們就大聲喊叫：「除掉他！除掉他！把他釘上十字架！」<br />彼拉多問：「我可以把你們的王釘上十字架嗎？」<br />祭司長們回答：「除了凱撒，我們沒有王！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:24–25; 馬太福音 27:26–31; 馬可福音 15:15–20"> 於是彼拉多把耶穌交給他們去釘上十字架。 耶穌被釘十字架<br />他們就把耶穌帶走了。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:33; 路加福音 14:27; 路加福音 23:26"> 耶穌自己背著十字架出來，前往一個叫「骷髏地」的地方，希伯來語<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希伯來語——或譯作「亞蘭語」。">d</a></sup>叫做「各各他」。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:12; 馬可福音 15:24–27; 加拉太書 3:13"> 在那裡，他們把耶穌釘上十字架，還把另外兩個人與耶穌一起釘上十字架，這邊一個，那邊一個，耶穌在中間。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 27:37; 路加福音 23:38; 馬可福音 15:26"> 彼拉多還寫了一個牌子，掛在十字架上，寫的是：「拿撒勒人耶穌，猶太人的王。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 26:14; 啟示錄 16:16; 使徒行傳 22:2"> 許多猶太人都讀了這牌子，因為耶穌被釘十字架的地方離城不遠，而且牌子是用希伯來文<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="希伯來文——或譯作「亞蘭文」。">e</a></sup>、拉丁文、希臘文寫的。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 19:14; 約翰福音 19:19"> 猶太人的祭司長們對彼拉多說：「請不要寫『猶太人的王』，而要寫『這個人說：我是猶太人的王。』」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 76:10; 詩篇 65:7; 箴言 8:29"> 彼拉多回答：「我所寫的，我已經寫了。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 23:34; 馬可福音 15:24; 馬太福音 27:35"> 士兵們將耶穌釘上十字架以後，把他的衣服拿來分成四份，每人一份。他們又拿了裡衣，這件裡衣沒有接縫，從上到下由整片織成。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 22:18; 約翰福音 19:28; 約翰福音 19:36–37"> 他們彼此說：「不要把它撕開，讓我們抽籤，看它是誰的。」這是為要應驗經上的話：「他們分了我的衣服，又為我的衣裳抽籤。」士兵們果然做了這些事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 23:49; 馬太福音 27:55–56; 約翰福音 20:1"> 在耶穌的十字架旁邊，站著他的母親、他母親的妹妹、克羅帕的妻子瑪麗亞，以及茉大拉的瑪麗亞。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 21:24; 約翰福音 20:2; 約翰福音 2:4"> 耶穌看到母親和他所愛的那門徒站在旁邊，就對母親說：<span className="woj">「母親</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="母親——原文直譯「婦人」。">f</a></sup><span className="woj">，看哪，你的兒子！」</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 12:48–50; 約翰福音 16:32; 提摩太前書 5:2–4"> 然後對那門徒說：<span className="woj">「看哪，你的母親！」</span>從那時候起，那門徒就把耶穌的母親接到自己的家裡。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="詩篇 69:21; 詩篇 22:15; 約翰福音 19:30"> 這事以後，耶穌知道一切都已經完成了，為要應驗經上的話，就說：<span className="woj">「我渴了。」</span></span>
<span className="v" id="v29" data-v="29" data-xref="民數記 19:18; 路加福音 23:36; 馬可福音 15:36"> 那裡放著一個裝滿酸酒的容器。他們就把蘸滿了酸酒的海綿套在牛膝草上，送到他的嘴邊。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 17:4; 腓立比書 2:8; 歌羅西書 2:14–17"> 耶穌嘗了酸酒後，就說：<span className="woj">「成了！」</span>然後垂下頭，交出了靈魂。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 19:14; 約翰福音 19:42; 馬可福音 15:42"> 因為那天是預備日，又因為那個安息日是個大節日，那些猶太人為了不讓屍體在安息日留在十字架上，就向彼拉多請求，好把他們的腿打斷，把屍體拿走。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 19:18; 路加福音 23:39–43"> 士兵們就來，把與耶穌一起被釘十字架的頭一個人的腿打斷，又把另一個人的也打斷了。</span>
<span className="v" id="v33" data-v="33"> 可是，當他們來到耶穌那裡，看見他已經死了，就沒有打斷他的腿。</span>
<span className="v" id="v34" data-v="34" data-xref="約翰一書 5:6; 撒迦利亞書 12:10; 撒迦利亞書 13:1"> 不過有一個士兵用長矛刺入耶穌的肋旁，立刻有血和水流了出來。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 21:24; 希伯來書 2:3–4; 約翰一書 1:1–3"> 看見這事的那人做了見證——他的見證是真實的，並且他知道他所說的是真實的——這是為了要你們也信。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 34:20; 民數記 9:12; 出埃及記 12:46"> 事實上，這些事發生，是為要應驗經上的話：「他的骨頭，一根也不被折斷。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒迦利亞書 12:10; 啟示錄 1:7; 詩篇 22:16–17"> 另有一段經文也說：「他們將看見自己所刺的那一位。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬可福音 15:42–47; 馬太福音 27:57–61; 箴言 29:25"> 這些事以後，亞利馬太的約瑟請求彼拉多，要領取耶穌的遺體。約瑟也是耶穌的門徒，不過是暗暗地做門徒，因為他怕那些猶太人。彼拉多准許了，他就來把耶穌的遺體領去。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 7:50–52; 雅歌 4:14; 約翰福音 3:1–21"> 當初在夜裡來到耶穌那裡的尼克迪莫也來了。他帶著沒藥和沉香的混合香料，大約三十公斤<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="三十公斤——原文為「100力揣」；或譯作「100磅」。力揣=羅馬磅；1力揣=0.34公斤。">g</a></sup>。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 11:44; 約翰福音 20:5–7; 使徒行傳 5:6"> 他們領了耶穌的遺體，按猶太人預備葬禮的規矩，用細麻布條和香料把遺體纏裹起來。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:53; 馬太福音 27:60; 約翰福音 20:15"> 耶穌被釘十字架的地方有一個園子，園子裡有一座新墓穴，從來沒有安放過人。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 19:31; 約翰福音 19:14; 以賽亞書 53:9"> 因為那天是猶太人的預備日，那墓穴又在附近，他們就把耶穌安放在那裡。</span>
</div>
</div>

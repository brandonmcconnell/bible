<span className="v" id="v2" data-v="2" data-xref="哥林多後書 5:1; 約翰福音 13:36; 希伯來書 13:14"> <span className="woj">在我父家裡有很多住處。如果沒有，我怎麼會告訴你們說，我去是要為你們預備地方呢？</span></span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 4:16–17; 約翰福音 12:26; 提摩太後書 2:12"> <span className="woj">我如果去為你們預備了地方，就會再來，接你們到我那裡，好使我在哪裡，你們也能在哪裡。</span></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:9; 約翰福音 16:28; 約翰福音 13:3"> <span className="woj">我往哪裡去，你們知道；那條路，你們也知道。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 11:16; 馬可福音 9:19; 約翰福音 20:25–28"> 多馬說：「主啊，我們不知道你要到哪裡去，怎麼能知道那條路呢？」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 4:12; 約翰福音 10:9; 以弗所書 2:18"> 耶穌說：<span className="woj">「我就是道路、真理、生命。要不是藉著我，沒有人能到父那裡去。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 1:15–17; 約翰福音 8:19; 路加福音 10:22"> <span className="woj">「如果你們認識我，也就會認識我的父。從今以後，你們就認識他，並且已經看到他了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 33:18–23; 啟示錄 22:3–5; 約翰福音 1:43–46"> 腓力說：「主啊，請給我們看看父，我們就滿足了。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:15; 約翰福音 12:45; 約翰福音 14:7"> 耶穌回答說：<span className="woj">「腓力，我與你們在一起這麼久了，你還不認識我嗎？一個人看到了我，就是看到了父。你怎麼還說『請給我們看看父』呢？</span></span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 5:19; 約翰福音 10:38; 約翰福音 10:30"> <span className="woj">難道你不相信我就在父裡面，父也在我裡面嗎？我對你們說的話，不是憑自己說的，而是住在我裡面的父，在做他的工作。</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:38; 約翰福音 10:25; 約翰福音 5:36"> <span className="woj">你們當相信我：我在父裡面，父也在我裡面。即使不信，也當因我所做的事而相信</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「我」。">a</a></sup><span className="woj">。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:21; 馬可福音 16:17; 路加福音 10:17–19"> <span className="woj">「我確確實實地告訴你們：我所做的事，信我的人也要做，而且要做比這些更大的事。這是因為我就要到父那裡去了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:7; 馬可福音 11:24; 馬太福音 7:7"> <span className="woj">你們奉我的名無論求什麼，我將行這事，好使父藉著子得榮耀。</span></span>
<span className="v" id="v14" data-v="14"> <span className="woj">如果你們奉我的名向我</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有「向我」。">b</a></sup><span className="woj">求什麼，我將成就。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有此節。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰一書 2:3–5; 約翰一書 5:2–3; 約翰福音 14:21–24"> <span className="woj">「你們如果愛我，就會遵守我的命令。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就會遵守我的命令。——有古抄本作「就應當遵守我的命令。」">d</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:26; 約翰福音 15:26; 約翰福音 16:7–15"> <span className="woj">我也要向父祈求，他就將賜給你們另一位慰助者，讓他與你們在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在——有古抄本作「住在」。">e</a></sup><span className="woj">一起，直到永遠。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 36:27; 約翰福音 16:13; 約翰一書 2:27"> <span className="woj">他就是真理的靈，是世界不能接受的，因為世界看不到他，也不認識他。而你們認識他，因為他與你們同在，並且要在你們裡面。</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 14:3; 詩篇 23:4; 馬太福音 18:20"> <span className="woj">我不會撇下你們為孤兒，我要回到你們這裡來。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:16; 約翰福音 7:33; 希伯來書 7:25"> <span className="woj">「再過一會兒，世人不再看到我了，而你們將看到我。因為我活著，你們也將活著。</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 15:5–7; 加拉太書 2:20; 約翰福音 17:21–23"> <span className="woj">在那一天，你們就會明白：我在我父裡面，你們在我裡面，我也在你們裡面。</span></span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 14:15; 約翰一書 5:3; 約翰一書 2:5"> <span className="woj">那領受我命令並遵守的人，就是愛我的。愛我的會蒙我父所愛，我也會愛他，並且會向他顯明我自己。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 1:13; 路加福音 6:16; 馬太福音 10:3"> 不是加略人的那個猶大問耶穌：「主啊，怎麼會這樣呢？你為什麼要向我們顯明自己，而不向世人顯明呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 14:21; 約翰福音 14:15; 啟示錄 3:20–21"> 耶穌回答說：<span className="woj">「如果有人愛我，他就會遵守我的話語，我父也會愛他，而且我們將要來到他那裡，並且在他那裡安置我們的住處。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 7:16; 約翰福音 14:10; 約翰福音 8:42"> <span className="woj">不愛我的人，就不遵守我的話語。事實上，你們所聽見的話語，不是我的，而是那派我來的父的話語。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 17:6–8; 約翰福音 13:19; 約翰福音 16:12"> <span className="woj">「我還與你們在一起的時候，已經把這些事告訴了你們。</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:26; 約翰福音 14:16; 約翰一書 2:27"> <span className="woj">但那位慰助者，就是父以我的名所要派遣的聖靈，將要把一切的事教導你們，並且讓你們想起我對你們說過的一切。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="腓立比書 4:7; 約翰福音 16:33; 以賽亞書 41:10"> <span className="woj">「我把平安留給你們，我把我的平安賜給你們。我給你們的，不像世界所給的。你們心裡不要愁煩，也不要膽怯。</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 10:29–30; 哥林多前書 15:24–28; 哥林多前書 11:3"> <span className="woj">你們聽過我對你們說：『我去了，還要回到你們這裡來。』如果你們愛我，就會為了我到父那裡去而感到歡喜。這是因為父比我更大。</span></span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 13:19; 約翰福音 16:4–31; 馬太福音 24:24–25"> <span className="woj">如今，在事情發生以前我已經告訴你們了，好讓你們在事情發生的時候能相信。</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 5:19; 約翰一書 4:4; 啟示錄 12:9"> <span className="woj">我不再對你們多說了。要知道，世界的那掌權者就要來了，而他對我毫無作用。</span></span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 10:18; 腓立比書 2:8; 約翰福音 12:49"> <span className="woj">不過我照著父的吩咐如此去做，是為要世界知道我愛父。</span><br /><span className="woj">「起來，我們走吧！</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 14:3–8; 約翰福音 11:1; 路加福音 24:50"> 逾越節前六天，耶穌來到<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「曾經死過的」。">a</a></sup>拉撒路所在的伯大尼，就是他使拉撒路從死人中復活的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:27; 路加福音 10:38–42; 啟示錄 3:20"> 有些人在那裡為耶穌預備晚餐，瑪妲正伺候著。拉撒路也在與耶穌坐席的人當中。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 14:3–9; 約翰福音 11:2; 路加福音 10:38–39"> 這時候，瑪麗亞拿了一斤<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一斤——原文為「1力揣」；或譯作「1磅」。力揣=羅馬磅；1力揣=0.34公斤。">b</a></sup>極其貴重的純哪噠香液，膏抹耶穌的腳，又用自己的頭髮擦乾，屋子裡就充滿了香液的氣味。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:4; 撒母耳記上 17:28–29; 約翰福音 13:2"> 他的一個門徒，就是後來要出賣耶穌的那個加略人猶大卻說：</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:22; 路加福音 12:33; 馬可福音 14:4–5"> 「為什麼不把這香液賣三百個銀幣<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三百個銀幣——原文為「300得拿利」。1得拿利=約1日工資的羅馬銀幣。">c</a></sup>去分給窮人呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 13:29; 詩篇 50:16–20; 雅各書 2:6"> 他說這話，並不是因為顧念窮人，而是因為他是個賊。他管錢包，常常拿走其中所存的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 26:12; 馬可福音 14:6; 馬太福音 27:57–60"> 耶穌說：<span className="woj">「由她吧！她是為我安葬的日子而保存的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:11; 馬可福音 14:7; 馬太福音 26:11"> <span className="woj">要知道，你們總是有窮人與你們在一起，但你們不總是有我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:14; 約翰福音 11:43–45; 使徒行傳 3:10–11"> 有一大群猶太人知道耶穌在那裡，就來了。他們不僅是為了耶穌的緣故，也是為了看拉撒路，就是耶穌使他從死人中復活的那個人。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:31; 馬太福音 2:16; 約翰福音 11:47–53"> 於是祭司長們就商議，連拉撒路也要殺掉，</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:45; 約翰福音 12:18; 使徒行傳 13:45"> 因為有許多猶太人為了拉撒路的緣故，離開他們，信了耶穌。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 11:7–10; 馬太福音 21:4–9; 路加福音 19:35–38"> 第二天，一大群上來過節的人聽說耶穌要來到耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 118:25–26; 啟示錄 15:3; 馬太福音 21:9–11"> 就拿著棕櫚樹枝出去迎接他，歡呼說：<br /><span className="pl pl-1">「和散那！</span><br /><span className="pl pl-1">奉主名而來的那一位，</span><br /><span className="pl pl-1">以色列的王啊，</span><br /><span className="pl pl-1">是蒙祝福的！」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 9:9; 馬可福音 11:1–7; 馬太福音 21:1–7"> 耶穌找來一頭驢駒，騎在上面，正如經上所記：</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 9:9; 以賽亞書 62:11; 西番雅書 3:16–17"> 「錫安的女兒啊，不要怕！看哪，你的王騎著驢駒來了！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 2:22; 約翰福音 14:26; 約翰福音 7:39"> 耶穌的門徒們當初不明白這些事，等到耶穌得了榮耀以後，才想起這些話是指著他寫的，人們果然向他做了這些事。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 1:2; 約翰一書 5:9–12; 約翰福音 19:35"> 當耶穌呼喚拉撒路從墳墓中出來，使他從死人中復活的時候，那些與耶穌在一起的眾人就見證了這件事。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 12:11"> 眾人之所以也去迎接他，是因為他們聽說他行了這神蹟。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:6; 詩篇 22:27; 約翰一書 2:2"> 於是法利賽人互相說：「可見你們真沒用！看，這世界都跟隨他去了。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:35; 以賽亞書 11:10; 使徒行傳 17:4"> 當時，上來過節敬拜的人中，有一些希臘人。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 2:2; 路加福音 19:2–4; 約翰福音 6:40"> 這些人來到加利利的伯賽達人腓力那裡，求他說：「先生，我們想見耶穌。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 10:13–14; 路加福音 9:49–50; 約翰福音 1:40–41"> 腓力去告訴安得烈，安得烈和腓力就去告訴耶穌。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:31–32; 約翰福音 17:1–5; 以賽亞書 60:9"> 耶穌回答他們，說：<span className="woj">「人子得榮耀的時候到了！</span></span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:36–38; 以賽亞書 53:10–12; 希伯來書 2:9–10"> <span className="woj">我確確實實地告訴你們：一粒麥子如果不落在地裡死去，它仍然是一粒；如果死了，就結出很多子粒</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="子粒——或譯作「果實」。">d</a></sup><span className="woj">來。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 10:39; 路加福音 9:23–24; 馬可福音 8:35"> <span className="woj">愛惜自己生命的，就失去生命；在這世上恨惡自己生命的，將保全生命到永生。</span></span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 3:24; 加拉太書 1:10; 撒母耳記上 2:30"> <span className="woj">一個人如果要服事我，就當跟從我；我在哪裡，我的僕人也將要在哪裡。如果有人服事我，父將尊重他。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 12:23; 希伯來書 5:7; 馬太福音 26:42"> <span className="woj">「現在我的靈魂煩擾。我該說什麼呢？說『父啊，救我脫離這時刻』嗎？但我正是為了這時刻而來的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 13:31–32; 馬太福音 26:42; 啟示錄 5:9–14"> <span className="woj">父啊，願你榮耀你的名</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="名——有古抄本作「兒子」。">e</a></sup><span className="woj">！」</span><br />這時候，有聲音從天上傳來：「我已經榮耀了我的名，還要再榮耀！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約伯記 37:2–5; 啟示錄 6:1; 啟示錄 14:2"> 站在那裡的眾人聽見了，就說：「打雷了。」另有人說：「是天使在對他說話。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 11:42; 約翰福音 11:15; 約翰福音 5:34"> 耶穌就回答說：<span className="woj">「這聲音不是為我，而是為你們來的。</span></span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:4; 約翰一書 5:19; 約翰一書 3:8"> <span className="woj">現在，是這世界受審判的時候了；現在，世界的那掌權者要被趕出去了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:14; 約翰福音 8:28; 彼得前書 2:24"> <span className="woj">至於我，當我從地上被舉起來的時候，就會吸引所有的人歸向我。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 18:32; 約翰福音 21:19"> 耶穌說這話是指自己將要怎樣死。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以西結書 37:24–25; 以賽亞書 9:7; 但以理書 7:14"> 眾人回答他：「我們從律法中聽到，基督是永遠長存的。你怎麼說『人子必須被舉起來』呢？這『人子』到底是誰？」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 12:46; 約翰福音 16:16; 以弗所書 5:8"> 耶穌說：<span className="woj">「光在你們當中的時候不多了。要趁著有光的時候行走，免得黑暗抓住你們！因為在黑暗裡行走的人，不知道自己往哪裡去。</span></span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 5:8; 約翰福音 8:59; 使徒行傳 13:47–48"> <span className="woj">你們要趁著有光的時候信這光，好使你們成為光明的兒女。」</span>耶穌說了這些話，就離開他們被隱藏了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="路加福音 16:31; 約翰福音 1:11; 約翰福音 15:24"> 耶穌雖然在他們面前行了這麼多神蹟，他們仍然不信他。</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 53:1; 羅馬書 10:16; 羅馬書 10:20"> 這是為要應驗先知以賽亞所說的話：<br /><span className="pl pl-1">「主啊，我們所傳的，有誰相信了？</span><br /><span className="pl pl-1">主的膀臂</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="膀臂——意義為「大能」。">f</a></sup><br /><span className="pl pl-1">，向誰顯示了？」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 10:38; 約翰福音 5:44; 彼得後書 2:14"> 他們之所以不能相信，是因為以賽亞又說過：</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 6:10; 馬太福音 13:13–15; 路加福音 8:10"> <span className="pl pl-1">「神使他們瞎了眼，</span><br /><span className="pl pl-1">硬了心，</span><br /><span className="pl pl-1">免得他們眼睛看見，</span><br /><span className="pl pl-1">心裡明白，</span><br /><span className="pl pl-1">回轉過來，</span><br /><span className="pl pl-1">我就使他們痊癒。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 6:1–5; 以賽亞書 6:9–10; 約翰福音 1:14"> 以賽亞說了這些話，是因為看見了耶穌的榮耀<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="是因為看見了耶穌的榮耀——有古抄本作「是在他看見了耶穌的榮耀的時候」。">g</a></sup>，就講論他的事。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="約翰福音 9:22; 約翰福音 7:13; 以賽亞書 51:7"> 不過甚至是首領當中也有許多信耶穌的。但是為了法利賽人的緣故，他們不敢承認，免得被趕出會堂，</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 5:44; 馬太福音 23:5–7; 約翰福音 5:41"> 這是因為他們喜愛人的榮耀，勝過喜愛神的榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 10:40; 約翰福音 13:20; 約翰福音 5:24"> 耶穌喊著說：<span className="woj">「信我的人，不是信我，而是信派我來的那一位。</span></span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 14:9–10; 哥林多後書 4:6; 歌羅西書 1:15"> <span className="woj">誰看見我，就是看見派我來的那一位。</span></span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 8:12; 詩篇 36:9; 約翰福音 9:5"> <span className="woj">我就是光。我來到世上，好讓所有信我的人不住在黑暗裡。</span></span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:17; 約翰福音 8:15–16; 約翰福音 12:48"> <span className="woj">如果有人聽了我的話卻不遵守</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="遵守——有古抄本作「相信」。">h</a></sup><span className="woj">，我不定他的罪；因為我來，不是為了定世人的罪，而是為了拯救世人。</span></span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 10:16; 希伯來書 9:27–28; 羅馬書 2:16"> <span className="woj">拒絕我，又不接受我話的人，自有定他罪的：我所講的話語，在末日要定他的罪。</span></span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 14:10; 約翰福音 8:26; 約翰福音 5:30"> <span className="woj">這是因為我沒有憑自己講話，而是派我來的父給了我命令，要我說什麼和講什麼。</span></span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 17:3; 約翰福音 6:68; 約翰一書 5:20"> <span className="woj">我知道他的命令就是永恆的生命。所以我所講的，正是照著父所告訴我的來講的。」</span></span>
</div>

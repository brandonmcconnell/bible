<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:16; 出埃及記 23:14–17; 出埃及記 34:23"> 這些事以後，猶太人的一個節日到了，耶穌就上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 12:39; 尼希米記 3:1; 尼希米記 3:32"> 在耶路撒冷的羊門附近有一個池子，希伯來語<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯來語——或譯作「亞蘭語」。">a</a></sup>叫做「貝示達<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="貝示達——有古抄本作「貝特扎塔」；或譯作「貝特斯達」或「畢士大」。">b</a></sup>」，那裡有五道柱廊。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 3:1–4; 路加福音 7:22; 馬太福音 15:30"> 柱廊裡躺著一群患病的，有瞎眼的、瘸腿的、癱瘓的。他們正等著池水動起來，</span>
<span className="v" id="v4" data-v="4"> 因為主的天使按時下到池子裡攪動池水。每次水動起來時，第一個下到池子裡的人，無論患什麼病都會痊癒。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="-4 有古抄本沒有「他們正等著……痊癒。」">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 3:2; 路加福音 8:43; 馬可福音 9:21"> 那裡有一個人，病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯來書 4:15; 希伯來書 4:13"> 耶穌見這個人躺在那裡，知道他已經病了很久，就問他：<span className="woj">「你想痊癒嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 72:12; 申命記 32:36; 哥林多前書 9:24"> 那個病人回答：「先生，池水被攪動的時候，沒有人把我放進池子裡；而正當我要下去的時候，別人總比我先下去。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 馬太福音 9:6; 馬可福音 2:11"> 耶穌對他說：<span className="woj">「起來，拿起你的墊子走路吧！」</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 3:7–8; 約翰福音 9:14; 馬可福音 3:2–4"> 那個人立刻痊癒了，就拿起他的墊子開始走路。<br />那天是安息日，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 17:21; 路加福音 6:2; 約翰福音 9:16"> 所以那些猶太人對那得了痊癒的人說：「今天是安息日，你拿著墊子是不可以的！」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬可福音 2:9–11; 約翰福音 9:16"> 他就回答：「是那個使我痊癒的人對我說『拿起你的墊子走路吧。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:23; 士師記 6:29; 羅馬書 10:2"> 他們問：「對你說『拿起<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「你的」。">d</a></sup>墊子走路』的那個人是誰？」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 約翰福音 8:59"> 那得了痊癒的人並不知道他是誰，因為那裡有一群人，而耶穌已經抽身離去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 8:11; 利未記 26:23–24; 詩篇 118:18"> 這些事以後，耶穌在聖殿裡找到他，對他說：<span className="woj">「看，你已經痊癒了。不要再犯罪，免得更嚴重的事臨到你。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 9:11–12; 約翰福音 4:29; 約翰福音 9:25"> 那個人就去向那些猶太人報告說，使他痊癒的是耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 10:39; 約翰福音 7:19–20; 馬可福音 3:6"> 那些猶太人之所以逼迫耶穌，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「想要殺他，」。">e</a></sup>是因為他在安息日做這些事。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 9:4; 約翰福音 14:10; 歌羅西書 1:16"> 耶穌卻對他們說：<span className="woj">「直到如今，我父在做工，我也在做工。」</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 10:30; 約翰福音 10:33; 約翰福音 19:7"> 為此，那些猶太人更想要殺他，因為他不僅干犯了安息日，還稱神是他的父，把自己當做與神同等的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 12:49; 約翰福音 8:28; 約翰福音 14:10"> 耶穌對他們說：<span className="woj">「我確確實實地告訴你們：子憑著自己什麼也不能做，只有看見父所做的，子才能做，因為父所做的事，子也同樣地做。</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 3:35; 馬太福音 3:17; 約翰福音 17:26"> <span className="woj">原來，父喜愛子，把自己所做的一切都給他看，還要把比這些更大的事給他看，使你們感到驚奇。</span></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:11; 申命記 32:39; 約翰福音 11:25"> <span className="woj">因為父怎樣使死人復活，賜他們生命，子也照樣按自己的意願賜人生命。</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 5:27; 使徒行傳 17:31; 哥林多後書 5:10"> <span className="woj">事實上，父並不審判任何人，而把一切審判的事都交給了子，</span></span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 2:23; 路加福音 10:16; 馬太福音 11:27"> <span className="woj">好使所有的人都尊重子，就像尊重父那樣。不尊重子的，就是不尊重派他來的父。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 3:36; 約翰福音 6:40; 約翰一書 5:11–13"> <span className="woj">「我確確實實地告訴你們：誰聽我的話，又相信派我來的那一位，誰就有永恆的生命。他不但不被定罪，而且已經出死入生了。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 5:28; 以弗所書 5:14; 以弗所書 2:5"> <span className="woj">「我確確實實地告訴你們：時候就要到了，現在就是了！當死人聽見神兒子的聲音時，聽到的人就將活了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 11:26; 約翰福音 1:4; 出埃及記 3:14"> <span className="woj">原來，父怎樣在自己裡面有生命，也照樣使子在自己裡面有生命；</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 10:42; 約翰福音 5:22; 使徒行傳 17:31"> <span className="woj">並且把審判的權柄交給了他，因為他是人子。</span></span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 20:12; 帖撒羅尼迦前書 4:14–17; 以賽亞書 26:19"> <span className="woj">你們不要為此感到驚奇：時候就要到了！那時所有在墳墓裡的人，都會聽到他的聲音，</span></span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 12:2–3; 羅馬書 2:6–10; 使徒行傳 24:15"> <span className="woj">並且要出來——行善的人復活得生命，作惡的人復活被定罪。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 6:38; 約翰福音 5:19; 約翰福音 4:34"> <span className="woj">「我憑自己什麼也不能做。我怎麼聽見，就怎麼審判，而且我的審判是公義的，因為我不求自己的意思，而求那派我來者</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「——父」。">f</a></sup><span className="woj">的意思。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 約翰福音 8:54; 啟示錄 3:14"> <span className="woj">「如果我為自己做見證，我的見證就無效</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="無效——原文直譯「不真實」。">g</a></sup><span className="woj">。</span></span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 1:33; 約翰福音 12:28–30; 約翰福音 5:36–37"> <span className="woj">為我做見證的另有一位，並且我知道，他為我做的見證是有效</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有效——原文直譯「真實」。">h</a></sup><span className="woj">的。</span></span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 1:29–34; 約翰福音 3:26–36; 約翰福音 1:15–27"> <span className="woj">你們曾經派人到約翰那裡，他為真理做了見證。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 約翰福音 20:31; 約翰一書 5:9"> <span className="woj">其實我所接受的見證不是從人來的。不過我說這些話，是為了要你們得救。</span></span>
<span className="v" id="v35" data-v="35" data-xref="彼得後書 1:19; 約翰福音 1:7–8; 馬太福音 11:11"> <span className="woj">約翰是一盞燃燒發光的燈，你們情願在他的光裡快樂一時。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約翰福音 10:25; 約翰福音 10:37–38; 約翰福音 15:24"> <span className="woj">「我有比約翰更大的見證，因為父交給我工作要我去完成。我現在做的這些工作正為我見證：就是父差派了我。</span></span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 8:18; 約翰福音 1:18; 馬太福音 3:17"> <span className="woj">派我來的父也親自為我做了見證。你們從來沒有聽到他的聲音，也沒有看到他的相貌，</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰一書 2:14; 申命記 6:6–9; 約翰福音 12:44–48"> <span className="woj">更沒有把他的話語</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="話語——或譯作「道」。">i</a></sup><span className="woj">存在你們裡面，因為你們不信他所派來的那一位。</span></span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得後書 1:19–21"> <span className="woj">你們查考經文，因你們以為從中可以得到永恆的生命。其實這經文就是為我做見證的。</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 3:19; 約翰福音 1:11; 詩篇 81:11"> <span className="woj">可是你們不肯到我這裡來得生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 7:18; 約翰福音 5:34; 帖撒羅尼迦前書 2:6"> <span className="woj">「我不接受從人而來的榮耀。</span></span>
<span className="v" id="v42" data-v="42" data-xref="約翰一書 4:20; 約翰一書 3:17; 約翰福音 2:25"> <span className="woj">不過我了解你們，你們裡面沒有屬神的愛。</span></span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 10:25; 馬太福音 24:5; 約翰福音 17:4–6"> <span className="woj">我奉我父的名來了，你們卻不接受我；如果有別人奉自己的名而來，你們倒會接受他。</span></span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 12:43; 羅馬書 2:29; 腓立比書 2:3"> <span className="woj">你們彼此接受榮耀，卻不尋求從獨一的神而來的榮耀，那怎麼能信呢？</span></span>
<span className="v" id="v45" data-v="45" data-xref="羅馬書 3:19–20; 加拉太書 3:10; 哥林多後書 3:7–11"> <span className="woj">不要以為我將要在父面前控告你們，有一位控告你們的，就是你們所仰賴的摩西。</span></span>
<span className="v" id="v46" data-v="46" data-xref="申命記 18:15; 申命記 18:18–19; 約翰福音 1:45"> <span className="woj">事實上，如果你們信摩西，就會信我，因為他寫了關於我的事；</span></span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> <span className="woj">如果你們不相信他所寫的，又怎麼會相信我的話呢？」</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 7:15; 約翰福音 10:8–10; 羅馬書 16:18"> <span className="woj">「我確確實實地告訴你們：那不從門進入羊圈，卻從別處爬進去的人，是賊、是強盜。</span></span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 10:14; 使徒行傳 20:28; 彼得前書 5:4"> <span className="woj">那從門進去的，才是羊的牧人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 34:11–16; 提摩太後書 2:19; 約翰福音 10:4"> <span className="woj">看門的就給他開門，羊也聽他的聲音。他一一提名呼喚自己的羊，帶領牠們出去。</span></span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:30; 約翰福音 10:16; 約翰福音 12:26"> <span className="woj">他把自己所有</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「所有」。">a</a></sup><span className="woj">的羊</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有「羊」。">b</a></sup><span className="woj">帶出去的時候，走在牠們的前面。羊因為認得他的聲音，就跟著他去。</span></span>
<span className="v" id="v5" data-v="5" data-xref="約翰一書 4:5–6; 歌羅西書 2:6–10; 馬可福音 4:24"> <span className="woj">羊絕不會跟著陌生人，反而會逃避，因為不認得他的聲音。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 56:11; 詩篇 82:5; 箴言 28:5"> 耶穌對他們說了這個比喻，他們卻不明白他說的是什麼。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:6; 以弗所書 2:18; 約翰福音 10:1"> 因此耶穌又說：<span className="woj">「我確確實實地告訴你們：我就是羊的門。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 34:2; 耶利米書 23:1; 約翰福音 10:1"> <span className="woj">所有在我以前來的，是賊、是強盜，因此羊沒有聽從他們。</span></span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 14:6; 以弗所書 2:18; 約翰福音 10:7"> <span className="woj">我就是門。人如果通過我進來，就將得救，而且進進出出，將找到牧草。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 約翰福音 6:51; 約翰福音 12:47"> <span className="woj">盜賊來，無非是要偷竊、宰殺、毀滅；而我來是要他們得生命，並且得的更豐盛。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:14–15; 詩篇 23:1; 約翰福音 15:13"> <span className="woj">「我就是好牧人。好牧人為羊捨棄自己的生命；</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 20:29; 撒迦利亞書 11:16–17; 以西結書 34:2–6"> <span className="woj">那雇來的不是牧人，羊也不是自己的，他看見狼來了，撇下羊就逃。這樣，狼就搶奪羊，把牠們驅散了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 2:20; 約翰福音 12:6; 使徒行傳 18:17"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「那雇來的會逃跑，」。">c</a></sup><span className="woj">這是因為那人是雇來的，並不顧念羊的事。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 10:27; 約翰福音 10:11; 提摩太後書 2:19"> <span className="woj">「我就是好牧人。我認識那屬於我的，那屬於我的也認識我，</span></span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 1:4; 約翰福音 10:11; 以賽亞書 53:10"> <span className="woj">就像父認識我，我也認識父那樣，而且我為羊捨棄自己的生命。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 56:8; 約翰福音 11:52; 彼得前書 2:25"> <span className="woj">我另外有羊，不是這圈裡的。我必須把他們帶來，他們會聽我的聲音，並且合成一群，同歸一個牧人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 10:18; 約翰福音 10:11; 希伯來書 2:9"> <span className="woj">父之所以愛我，是因為我捨棄自己的生命，好把它再取回來。</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 2:9; 提多書 2:14; 約翰福音 2:19–21"> <span className="woj">沒有人奪去我的生命，是我自願捨棄的。我有權柄捨棄生命，也有權柄再把它取回來。這命令，我已經從我父領受了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 9:16; 哥林多前書 3:3; 約翰福音 7:40–43"> 因這些話，猶太人中又產生了分裂。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:20; 馬可福音 3:21; 約翰福音 8:47–48"> 其中有許多人說：「他有鬼魔附身，發瘋了！何必聽他的呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 4:11; 以賽亞書 35:5–6; 詩篇 94:9"> 另有些人說：「這些話不是有鬼魔附身的人說的！鬼魔難道能開瞎子的眼睛嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 在耶路撒冷，當時正是獻殿節。那時候是冬天。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 5:12; 使徒行傳 3:11"> 耶穌正在聖殿的所羅門柱廊上走著，</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 約翰福音 1:19; 約翰福音 8:25"> 猶太人圍住了他，說：「你還讓我們猜疑多久呢？如果你是基督，就明確地告訴我們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 10:38; 約翰福音 8:58; 約翰福音 14:11"> 耶穌回答：<span className="woj">「我告訴過你們，你們卻不相信。我奉我父的名所行的這些事為我做見證；</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:47; 哥林多後書 4:3–4; 約翰福音 12:37–40"> <span className="woj">可是你們不信，因為</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「就像我告訴過你們那樣，」。">d</a></sup><span className="woj">你們不是我的羊。</span></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 10:16; 約翰福音 10:14; 啟示錄 3:20"> <span className="woj">我的羊聽我的聲音，我也認識他們，他們也跟著我；</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:39–40; 約翰福音 6:37; 約翰福音 3:15–16"> <span className="woj">並且我賜給他們永恆的生命，他們絕不會滅亡，直到永遠。誰也不能把他們從我手中奪走。</span></span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 6:37; 約翰福音 17:2; 約翰福音 17:9"> <span className="woj">我父，就是把他們</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="把他們——輔助詞語。">e</a></sup><span className="woj">賜給我的那一位，他比一切更大。誰也不能把他們從我</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「我」。">f</a></sup><span className="woj">父的手中奪走。</span></span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 1:1–2; 約翰福音 14:9; 約翰福音 17:21–23"> <span className="woj">我與父是一體的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 5:18; 約翰福音 8:59; 撒母耳記上 30:6"> 猶太人又拿起石頭要砸死他。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰一書 3:12; 約翰福音 5:36; 詩篇 35:12"> 耶穌對他們說：<span className="woj">「我把很多從父而來的美好之事顯給你們看了，你們是為哪一件要用石頭砸死我呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約翰福音 5:18; 利未記 24:16; 約翰福音 10:30"> 他們回答：「我們不會為了什麼美好之事用石頭砸死你，而是為了你說褻瀆的話！因為你不過是人，竟然把自己當做神！」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 82:6–7; 出埃及記 7:1; 詩篇 82:1"> 耶穌對他們說：<span className="woj">「你們的</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「你們的」。">g</a></sup><span className="woj">律法上不是寫道『我說你們是神』嗎？</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:35; 羅馬書 13:1; 路加福音 16:17"> <span className="woj">而經上的話是不能廢除的。神既然稱那些承受他話語</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="話語——或譯作「道」。">h</a></sup><span className="woj">的人為神，</span></span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 5:17–18; 約翰福音 3:17; 耶利米書 1:5"> <span className="woj">那麼，難道因為我說了『我是神的兒子』，你們就對父所分別為聖、並差派到世上來的那一位說『你說了褻瀆的話』嗎？</span></span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 15:24; 約翰福音 10:25; 約翰福音 12:37–40"> <span className="woj">如果我沒有做我父的事，你們就不該相信我；</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 14:20; 約翰福音 10:25; 約翰福音 10:30"> <span className="woj">但如果我做了，你們即使不相信我，也該相信這些事。這樣，你們就會知道並體會</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="體會——有古抄本作「相信」。">i</a></sup><span className="woj">父在我裡面，我也在父</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="父——有古抄本作「他」。">j</a></sup><span className="woj">裡面。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 7:30; 約翰福音 8:59; 約翰福音 7:44"> 於是他們又試圖抓耶穌，他卻從他們的手中脫離出來。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 1:28; 約翰福音 11:54; 約翰福音 7:1"> 耶穌又前往約旦河對岸，到約翰當初施洗的地方，住在那裡。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 1:33–34; 約翰福音 1:29–30; 馬可福音 1:37"> 有許多人來到他那裡，說：「雖然約翰沒有行過神蹟，但約翰所說的有關這個人的事，都是真的。」</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 4:41; 約翰福音 2:23; 約翰福音 7:31"> 於是有許多人在那裡信了耶穌。</span>
</div>
</div>

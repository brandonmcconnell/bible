<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 16:9; 馬太福音 27:60; 約翰福音 19:25"> 在一週頭一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一週頭一天——指「星期日」。">a</a></sup>的清晨，天還黑的時候，茉大拉的瑪麗亞就來到墓穴那裡，看見那石頭已經從墓穴被挪開了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 13:23; 約翰福音 20:13; 約翰福音 21:24"> 她就跑到西門彼得和耶穌所愛的那另一個門徒那裡去，對他們說：「他們從墓穴裡把主挪走了，我們不知道他們把他放在哪裡！」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 於是彼得和那另一個門徒就出來，往墓穴去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 18:23; 哥林多後書 8:12; 哥林多前書 9:24"> 兩個人一起跑，那另一個門徒跑得比彼得快一點，先到了墓穴。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:40; 約翰福音 20:11; 約翰福音 11:44"> 他彎腰去看，見那細麻布條放在那裡，不過他沒有進去。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:17; 約翰福音 21:7; 馬太福音 16:15–16"> 西門彼得跟著他，也到了，並且進了墓穴，看見那細麻布條放在那裡，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 11:44"> 也看見原來在耶穌頭上的那塊頭巾，沒有與那細麻布條放在一起，被捲了起來，分開放在一邊。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 20:25; 約翰福音 20:4; 約翰福音 1:50"> 這時候，先來到墓穴的那另一個門徒也進去了。他看見了，就信了。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 16:10; 以賽亞書 25:8; 以賽亞書 53:10–12"> 原來，他們從來沒有明白過經上所說「他必須從死人中復活」的那句話。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 7:53; 約翰福音 16:32"> 於是那些門徒就離開，回到他們的住處去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 20:5"> 瑪麗亞卻站在墓穴外面哭。她哭著，彎腰往墓穴裡看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 啟示錄 3:4; 馬可福音 16:5–6"> 看見兩位身穿白衣的天使，坐在原來安放耶穌遺體的地方，一位在頭的地方，一位在腳的地方。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 20:15; 約翰福音 2:4; 撒母耳記上 1:8"> 天使們問她：「婦人，你為什麼哭？」<br />她說：「因為他們把我的主挪走了，我不知道他們把他放在哪裡。」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 約翰福音 21:4; 馬太福音 28:9"> 說了這些話，她轉過身來，看見耶穌站在那裡，卻沒有認出他就是耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 20:13; 約翰福音 18:7; 約翰福音 1:38"> 耶穌說：<span className="woj">「婦人，你為什麼哭呢？你在找誰？」</span><br />瑪麗亞以為他是園丁，就對他說：「先生，如果是你把他抬走的，就請告訴我，你把他放在哪裡了，我好把他取回來。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 10:3; 約翰福音 1:38; 使徒行傳 10:3"> 耶穌對她說：<span className="woj">「瑪麗亞！」</span><br />她轉過身，用希伯來語<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希伯來語——或譯作「亞蘭語」。">b</a></sup>對耶穌說：「拉波尼<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="拉波尼——《馬可福音》10:51。">c</a></sup>！」——這意思是「老師」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:28; 以弗所書 4:8–10; 加拉太書 4:6–7"> 耶穌說：<span className="woj">「不要碰我，因為我還沒有上到父那裡。你到我弟兄們那裡去告訴他們：我要上到我的父那裡，他也是你們的父；我要上到我的神那裡，他也是你們的神。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 馬太福音 28:10; 約翰福音 20:1"> 茉大拉的瑪麗亞就去告訴門徒們：「我看到主了！」她又把耶穌對她說的這些話告訴他們。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 20:26; 約翰福音 14:27; 約翰福音 20:21"> 那日，也就是一週的頭一天<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一週的頭一天——指「星期日」。">d</a></sup>，傍晚的時候，門徒們所在地方的門戶已經關上了，因為他們怕那些猶太人。耶穌出現了，站在他們當中，對他們說：<span className="woj">「願你們平安！」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 16:22; 約翰福音 16:20; 約翰福音 20:27"> 說了這話，他把手和肋旁給他們看。門徒們看見了主，就歡喜。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 17:18–19; 約翰福音 13:20; 約翰福音 3:17"> 耶穌又對他們說：<span className="woj">「願你們平安！正如父差派了我，我也要派遣你們。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 33:4; 創世記 2:7; 使徒行傳 8:15"> 說了這話，耶穌向他們吹了一口氣，說：<span className="woj">「領受聖靈吧！</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 18:18; 馬太福音 16:19; 馬可福音 2:5–10"> <span className="woj">你們赦免誰的罪，誰的罪就已經被赦免了；你們留下誰的罪，誰的罪就已經被留下了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 11:16; 約翰福音 6:66–67; 希伯來書 10:25"> 當耶穌出現的時候，十二使徒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="使徒——輔助詞語。">e</a></sup>中那叫迪杜馬<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="迪杜馬——意思為「雙胞胎」。">f</a></sup>的多馬沒有與他們在一起。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 6:30; 馬可福音 16:11; 希伯來書 3:12"> 後來，其他的門徒就告訴他：「我們看到主了！」<br />他卻說：「我如果不看到他手上的釘痕，把指頭放進那釘痕，再把手放進他的肋旁，我就絕不相信！」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約翰福音 20:19; 以賽亞書 54:10; 約翰福音 20:21"> 八天後，耶穌的門徒們又在屋裡，多馬也與他們在一起。門戶已經關上了，耶穌卻出現，站在他們當中說：<span className="woj">「願你們平安！」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 20:25; 約翰一書 1:1–2; 約翰福音 20:20"> 然後他對多馬說：<span className="woj">「把你的指頭伸到這裡來，看看我的手吧。伸出你的手來，放進我的肋旁吧。不要不信，而要信！」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:1; 以賽亞書 9:6; 以賽亞書 7:14"> 多馬回答耶穌，說：「我的主，我的神！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="彼得前書 1:8; 哥林多後書 5:7; 希伯來書 11:1"> 耶穌對他說：<span className="woj">「你因為看到了我才信嗎？那沒有看到就信的人，是蒙福的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 21:25; 提摩太後書 3:15–17; 羅馬書 15:4"> 事實上，耶穌在他的門徒們面前還行了很多別的神蹟，沒有記在這部書裡。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 10:43; 約翰福音 3:15–16; 約翰一書 5:1"> 但這些事被記下來，是要你們相信耶穌就是基督、是神的兒子；並且使你們因著信，就奉他的名有生命。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 3:26; 約翰福音 3:22; 哥林多後書 4:5"> 耶穌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶穌——有古抄本作「主」。">a</a></sup>知道，法利賽人聽說他收門徒和施洗比約翰更多。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:48; 哥林多前書 1:13–17"> 其實不是耶穌親自施洗，而是他的門徒們施洗。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 10:23; 約翰福音 10:40; 約翰福音 2:11"> 於是耶穌離開猶太地區，又前往加利利地區。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 但他定要經過撒瑪利亞，</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 24:32; 創世記 33:19; 創世記 48:22"> 這樣就來到了撒瑪利亞的一個城，叫敘加。這城靠近雅各給他兒子約瑟的那塊地，</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 4:15; 希伯來書 2:17; 馬太福音 8:24"> 雅各井就在那裡。耶穌因旅途勞累，就坐在井邊。那時大約是中午十二點<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="中午十二點——原文為「第六時刻」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:42; 列王紀上 17:10; 創世記 24:43"> 有一個撒瑪利亞婦人來打水。耶穌對她說：<span className="woj">「請給我一點水喝。」</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:13; 約翰福音 4:39; 約翰福音 4:5"> 那時，他的門徒們進城買食物去了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 10:28; 馬太福音 10:5; 列王紀下 17:24–41"> 撒瑪利亞婦人對他說：「你是猶太人，怎麼向我一個撒瑪利亞婦人要水喝呢？」原來猶太人不和撒瑪利亞人來往。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「原來猶太人不和撒馬利亞人來往。」">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:14; 啟示錄 7:17; 約翰福音 7:37–39"> 耶穌回答她，說：<span className="woj">「如果你明白神的恩賜，也知道是誰對你說『給我一點水喝』，你早就求他了，他也把活水給你了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 2:14; 約翰福音 3:4"> 婦人問：「先生，你沒有打水的器具，井又深，你從哪裡得來那活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 4:6; 約翰福音 8:53; 馬太福音 12:42"> 難道你比我們的先祖雅各更大嗎？他給我們留下了這口井。他自己、他的子孫、他的牲畜都喝這井裡的水！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 6:27; 以賽亞書 65:13–14; 路加福音 16:24"> 耶穌回答說：<span className="woj">「所有喝這水的人，還會再渴。</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 7:38–39; 約翰福音 6:35; 以賽亞書 49:10"> <span className="woj">但如果有人喝了我給他的水，就絕不乾渴，直到永遠。不但如此，我給他的水將要在他裡面成為泉源，一直湧流到永恆的生命。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 6:34; 羅馬書 8:5; 詩篇 4:6"> 婦人說：「先生，請給我那水，使我不渴，我也不用到這裡來打水了。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 4:13; 啟示錄 2:23; 約翰福音 4:18"> 耶穌說：<span className="woj">「去叫你的丈夫，再回到這裡來。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 婦人回答說：「我沒有丈夫。」<br />耶穌說：<span className="woj">「你說你沒有丈夫，這話沒錯。</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 3:20; 哥林多前書 7:10–11; 羅馬書 7:3"> <span className="woj">其實你已經有過五個丈夫，你現在有的，不是你的丈夫。你說的是真的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 約翰福音 6:14; 約翰福音 9:17"> 婦人對他說：「先生，我看出你是先知！</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 12:6–7; 申命記 27:12; 申命記 11:29"> 我們的祖先在這山上敬拜，而你們卻說敬拜的地方必須在耶路撒冷。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="提摩太前書 2:8; 瑪拉基書 1:11; 約翰福音 4:23"> 耶穌說：<span className="woj">「婦人，你當相信我，時候就要到了！那時你們敬拜父，既不在這山上，也不在耶路撒冷。</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 17:23; 以賽亞書 2:3; 羅馬書 9:4–5"> <span className="woj">你們敬拜你們所不認識的；我們卻敬拜我們所認識的，因為救恩是出自猶太人的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 3:3; 約翰福音 5:25; 馬太福音 15:7–9"> <span className="woj">然而，時候就要到了，現在就是了！那時真正敬拜的人，要在靈裡和真理中敬拜父，因為父就是想要這樣的人來敬拜他。</span></span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 3:17; 馬太福音 15:8–9; 腓立比書 3:3"> <span className="woj">神是靈，敬拜他的人必須在靈裡和真理中敬拜。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 1:49; 但以理書 9:24–26; 約翰福音 1:41–42"> 婦人說：「我知道那稱為基督的彌賽亞要來。他來的時候，就會把一切都傳講給我們。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:24; 馬可福音 14:61–62; 羅馬書 10:20–21"> 耶穌說：<span className="woj">「這和你說話的我，就是那一位。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 約翰福音 4:8–9"> 正在這時，他的門徒們回來了。他們見耶穌與一個婦人一同說話，就感到驚奇。只是沒有人問「你想要什麼？」或「你為什麼與她說話？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 4:7; 路加福音 24:33; 馬可福音 16:8–10"> 那婦人放下她的水罐，回到城裡告訴人們說：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 22:17; 哥林多前書 14:24–25; 約翰福音 4:25"> 「你們來看！有個人把我過去所做的一切都說了出來，這個人會不會就是基督呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 5:20; 使徒行傳 8:5–8; 路加福音 17:16–18"> 大家就出城，來到耶穌那裡。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:38; 創世記 24:33; 使徒行傳 16:30–34"> 這其間，門徒們勸耶穌說：「拉比，請吃。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約伯記 23:12; 詩篇 119:103; 約翰福音 4:34"> 但耶穌說：<span className="woj">「我有食物吃，是你們所不知道的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 16:6–11; 路加福音 9:45"> 門徒彼此問：「難道有人拿東西來給他吃了嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 6:38; 約翰福音 5:30; 約伯記 23:12"> 耶穌對他們說：<span className="woj">「我的食物就是遵行那派我來者的旨意，並且完成他的工作。</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 馬太福音 9:37–38; 約翰福音 4:30"> <span className="woj">你們不是說『收割的季節還有四個月才到』嗎？看哪，我告訴你們：舉目向田裡觀望，莊稼已經成熟</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="成熟——原文直譯「白了」。">d</a></sup><span className="woj">，可以收割了！</span></span>
<span className="v" id="v36" data-v="36" data-xref="雅各書 5:19–20; 羅馬書 1:13; 哥林多前書 3:5–9"> <span className="woj">收割的人得酬報，收集果實歸入永恆的生命，好使撒種的和收割的一同快樂。</span></span>
<span className="v" id="v37" data-v="37" data-xref="彌迦書 6:15; 約伯記 31:8; 路加福音 19:21"> <span className="woj">實際上，這樣的說法是真實的：『一人撒種，另一個人收割。』</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 1:7; 歷代志下 36:15; 使徒行傳 10:42–43"> <span className="woj">我派你們去收你們未曾勞苦的；別人勞苦了，你們也進入了他們的勞苦中。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 4:29; 約翰福音 4:5; 約翰福音 10:41–42"> 當時，那城裡有許多撒瑪利亞人信了耶穌。這是因為那婦人見證說：「他把我過去所做的一切都說了出來。」</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 3:20; 使徒行傳 16:15; 路加福音 24:29"> 這樣，撒瑪利亞人來到耶穌那裡的時候，請求他住在他們那裡。於是耶穌在那裡住了兩天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前書 2:4–5; 使徒行傳 1:8; 使徒行傳 8:12"> 後來，因著耶穌的話，信的人就更多了。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰一書 4:14; 約翰福音 1:29; 約翰一書 5:20"> 他們告訴那婦人說：「現在我們信，不再是因為你的話，而是因為我們親耳聽到了，並且知道這一位真是世界的救主<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「——基督」。">e</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 4:13; 羅馬書 15:8; 馬可福音 7:27–28"> 兩天後，耶穌離開了那裡，前往加利利地區。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 13:57; 路加福音 4:24; 馬可福音 6:4"> 他曾親自見證說，先知在自己的家鄉得不到尊敬。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 2:23; 約翰福音 2:13–16; 申命記 16:16"> 當耶穌來到加利利地區，加利利人就接受他，因為他們也曾經上耶路撒冷去過節，看到耶穌節日期間在那裡所行的一切事。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="約翰福音 2:1–11; 路加福音 7:2; 何西阿書 5:15"> 耶穌又來到加利利的迦拿，就是他把水變成酒的地方。有一個大臣，他的兒子在迦百農患了病。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 4:3; 約翰福音 11:21; 約翰福音 11:32"> 這個人聽說耶穌從猶太來到加利利，就到耶穌那裡去，請求他下去治癒他的兒子，因為他的兒子快要死了。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約翰福音 20:29; 希伯來書 2:4; 哥林多前書 1:22"> 耶穌對他說：<span className="woj">「你們如果沒有看見神蹟和奇事，你們就絕不會信！」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="馬可福音 5:23; 詩篇 88:10–12; 詩篇 40:17"> 那大臣對耶穌說：「先生，求你在我的孩子還沒有死之前下來吧！」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬太福音 8:13; 馬可福音 7:29–30; 羅馬書 4:20–21"> 耶穌對他說：<span className="woj">「你回去吧，你的兒子活了！」</span>那人相信耶穌的話，就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王紀上 17:23; 約翰福音 4:50; 約翰福音 4:53"> 他正下去的時候，他的奴僕們迎著他來<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「報告」。">f</a></sup>，告訴他孩子活了。</span>
<span className="v" id="v52" data-v="52"> 他就問孩子好轉的時間，他們說：「昨天下午一點<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="下午一點——原文為「第七時刻」。">g</a></sup>，燒就退了。」</span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:20; 路加福音 19:9; 使徒行傳 16:34"> 這位父親就知道，那正是耶穌說<span className="woj">「你的兒子活了」</span>的時間。於是他自己和全家人都信了。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="約翰福音 4:45; 約翰福音 2:1–11"> 這是耶穌從猶太回到加利利以後所行的第二件神蹟。</span>
</div>
</div>

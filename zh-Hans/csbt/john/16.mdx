</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 13:36; 約翰福音 7:33; 約翰福音 16:28"> <span className="woj">「現在我要回到派我來的那一位面前，你們當中卻沒有人問我：『你要到哪裡去？』</span></span>

<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:26; 約翰福音 14:16–17; 約翰福音 15:26"> <span className="woj">但我把真相告訴你們：我離去對你們是有益處的，因為我如果不去，慰助者就不會到你們這裡來；如果我去了，我就會派遣他到你們這裡來。</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:37; 猶大書 1:15; 撒迦利亞書 12:10"> <span className="woj">他來了，要在關於罪、關於義、關於審判的事上，使世界知罪。</span></span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 15:22–25; 約翰福音 8:23–24; 約翰福音 12:47–48"> <span className="woj">關於罪，是因為世界不信我；</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:21; 彼得前書 3:18; 羅馬書 10:3–4"> <span className="woj">關於義，是因為我到父那裡去，而你們不再看到我了；</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 12:31; 約翰一書 3:8; 希伯來書 2:14"> <span className="woj">關於審判，是因為世界的那掌權者已經被定罪了。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:33; 約翰福音 15:15; 哥林多前書 3:1–2"> <span className="woj">「我還有很多事要告訴你們，可是你們現在擔當不了，</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:26; 哥林多前書 2:10–13; 約翰福音 14:17"> <span className="woj">不過當那位真理的靈來了，他就會引導你們進入一切真理</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引導你們進入一切真理——有古抄本作「在一切真理中引導你們」。">c</a></sup><span className="woj">。那時，他不會憑著自己說話，只把所聽到的說出來，並且把那些就要來的事傳講給你們。</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:13–14; 哥林多後書 3:14–18; 約翰福音 15:26"> <span className="woj">他將榮耀我，因為他將從我領受，並傳講給你們。</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 17:10; 馬太福音 11:27; 約翰福音 3:35"> <span className="woj">父所擁有的一切，都是我的。所以我說，聖靈將從我領受，並傳講給你們。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:33; 使徒行傳 1:3; 約翰福音 14:18–24"> <span className="woj">「過一會兒，你們就不再看到我了；再過一會兒，你們又將見到我</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「因為我要到父那裡去」。">d</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:16; 馬可福音 9:32; 約翰福音 16:5"> 於是他的門徒當中有的彼此問：「他對我們說<span className="woj">『過一會兒，你們就看不到我了；再過一會兒，你們又將見到我』</span>，還說<span className="woj">『是因為我要到父那裡去』</span>，這是什麼意思呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 馬太福音 16:9–11; 希伯來書 5:12"> 他們又說：「他說的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「他說的」。">e</a></sup><span className="woj">『過一會兒』</span>是什麼意思呢？我們不明白他在說什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:30; 約翰福音 16:16; 約翰福音 14:19"> 耶穌知道他們想要問他，就對他們說：<span className="woj">「我剛才說『過一會兒，你們就看不到我了；再過一會兒，你們又將見到我』，你們就為了這話彼此議論嗎？</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各書 1:2; 馬太福音 5:4; 詩篇 126:5–6"> <span className="woj">「我確確實實地告訴你們：你們將會痛哭、哀號，這世界反而會喜樂；你們將會憂傷，然而你們的憂傷要變成喜樂。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 113:9; 以賽亞書 13:8; 帖撒羅尼迦前書 5:3"> <span className="woj">婦人生產的時候會有憂慮，因為她的時候到了；但是生了孩子以後，她就因著有人出生到世上的喜樂，而不再記住那痛苦了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 1:8; 使徒行傳 13:52; 約翰福音 16:6"> <span className="woj">這樣，你們現在雖然也有憂慮，但是我會再見到你們，你們心裡將喜樂，並且沒有人能奪去你們的喜樂。</span></span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 15:7; 約翰福音 14:13–14; 馬太福音 21:22"> <span className="woj">在那一天，你們什麼也不會問我了。</span><br /><span className="woj">「我確確實實地告訴你們：你們奉我的名無論向父求什麼，他都將賜給你們。</span></span>

</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:12; 馬可福音 4:13; 馬太福音 13:34–35"> <span className="woj">「我用比喻對你們說了這些話。但是時候就要到了！那時我不再用比喻對你們說話，而是要明確地告訴你們有關父的事。</span></span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 8:34; 約翰福音 17:24; 約翰福音 17:19"> <span className="woj">在那一天，你們會奉我的名祈求，而且我並不是說我要替你們向父祈求。</span></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:21; 約翰福音 14:23; 約翰福音 17:23"> <span className="woj">要知道，父自己愛你們，因為你們已經愛我，並且相信我是從神</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神——有古抄本作「父」。">f</a></sup><span className="woj">而來的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 13:1; 約翰福音 13:3; 約翰福音 8:14"> <span className="woj">我從父而出，來到這世界；又要離開這世界，到父那裡去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰福音 16:25"> 他的門徒們說：「看，如今你說得明明白白，而不說比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 21:17; 約翰福音 17:8; 約翰福音 16:17"> 現在我們已經明白你知道一切，也不需要任何人問你，從這一點我們就相信你是從神而來的。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 約翰福音 13:38"> 耶穌對他們說：<span className="woj">「你們現在相信嗎？</span></span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亞書 13:7; 馬太福音 26:31; 約翰福音 8:29"> <span className="woj">看哪，時候就要到了，而且已經到了！你們要被驅散，每個人到自己的地方，留下我一個人。其實我不是獨自一人，因為父與我同在。</span></span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 14:27; 約翰一書 5:4; 帖撒羅尼迦後書 3:16"> <span className="woj">我把這些事告訴了你們，好讓你們在我裡面有平安。在世上你們有患難，然而你們要鼓起勇氣！我已經勝過了這世界。」</span></span>
</div>

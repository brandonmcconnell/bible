<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 2:21; 以賽亞書 27:2–3; 哥林多前書 3:9"> <span className="woj">「我就是真葡萄樹，我父是園丁。</span></span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 3:10; 希伯來書 12:10–11; 馬太福音 15:13"> <span className="woj">所有屬於我</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="屬於我——原文直譯「在我裡面」。">a</a></sup><span className="woj">而不結果子的枝條，他就除掉；而所有結果子的，他就修剪乾淨，好讓它結出更多的果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 17:17; 以弗所書 5:26; 彼得前書 1:22"> <span className="woj">藉著我給你們講的話語，你們已經乾淨了。</span></span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 2:6; 加拉太書 2:20; 約翰福音 8:31"> <span className="woj">你們當住在我裡面，我就住在你們裡面。枝條如果不留在葡萄樹上，就不能由自己結出果子；照樣，你們如果不住在我裡面，你們也是如此。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:13; 歌羅西書 1:10; 約翰福音 15:16"> <span className="woj">「我就是葡萄樹，你們是枝條。那住在我裡面、我也在他裡面的，他才結出很多果子，因為沒有我，你們什麼也不能做。</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:19; 希伯來書 6:7–8; 馬太福音 13:41"> <span className="woj">一個人如果不住在我裡面，就像枝條被丟在外面枯乾了，然後被收集扔進火裡焚燒。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:4; 約翰一書 5:14; 約翰福音 14:13"> <span className="woj">你們如果住在我裡面，而我的話也住在你們裡面，那麼，凡是你們所願的，當祈求，就將為你們成就。</span></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 8:31; 馬太福音 5:16; 腓立比書 1:11"> <span className="woj">你們結出很多果子，就表明是我的門徒了；從這一點我父也就得榮耀。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 17:23–24; 約翰福音 17:26; 約翰一書 2:28"> <span className="woj">「正如父愛我，我也愛你們。你們當住在我的愛裡。</span></span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 14:15; 約翰一書 5:3; 約翰一書 3:21–24"> <span className="woj">如果你們遵守我的命令，就會住在我的愛裡；就像我遵守了我父的命令，住在他的愛裡那樣。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 17:13; 羅馬書 15:13; 約翰福音 16:24"> <span className="woj">「我把這些事告訴了你們，是要我的喜樂在</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在——有古抄本作「住在」。">b</a></sup><span className="woj">你們裡面，並且使你們的喜樂得以滿足。</span></span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 4:21; 彼得前書 4:8; 約翰福音 13:34"> <span className="woj">這是我的命令：你們要彼此相愛，就像我愛了你們那樣。</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 10:11; 以弗所書 5:2; 羅馬書 5:6–8"> <span className="woj">一個人為他的朋友捨棄自己的生命，人的愛沒有比這更大的了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 12:50; 約翰一書 5:3; 雅各書 2:23"> <span className="woj">你們如果遵行我所吩咐的事，你們就是我的朋友了。</span></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 25:14; 哥林多前書 2:9–12; 馬太福音 13:11"> <span className="woj">我不再稱你們為奴僕，因為奴僕不知道主人所做的事。我卻稱你們為朋友，因為我把從我父所聽到的一切，都讓你們明白了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 15:19; 耶利米書 1:5–7; 以弗所書 2:10"> <span className="woj">不是你們揀選了我，而是我揀選了你們，並指派了你們，好使你們去，讓你們結出果子，而且使你們的果子長存。這樣，你們奉我的名無論向父求什麼，他就會賜給你們。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:12; 約翰一書 3:14–17; 彼得前書 2:17"> <span className="woj">我將這些事吩咐你們，是要讓你們彼此相愛。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 3:13; 約翰福音 7:7; 馬可福音 13:13"> <span className="woj">「這世界如果恨你們，你們應當知道，世界在恨你們之前已經恨我了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 4:4–5; 約翰福音 17:14–16; 以弗所書 1:4–11"> <span className="woj">如果你們屬於這世界，世界會把你們做為屬自己的來愛；但是，因為你們不屬於這世界，而是我從世界中揀選了你們，所以世界就恨你們。</span></span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 3:12; 約翰福音 13:16; 馬太福音 10:24"> <span className="woj">你們當記住我對你們說過的話：「沒有一個奴僕大過他的主人。」他們既然逼迫了我，也會逼迫你們；如果他們遵守了我的話，也就會遵守你們的話。</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 10:22; 約翰福音 16:3; 馬太福音 10:18"> <span className="woj">但是，因我名的緣故，他們會對你們做這一切事，因為他們不認識派我來的那一位。</span></span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 9:41; 雅各書 4:17; 使徒行傳 17:30"> <span className="woj">如果我沒有來，也沒有教導他們，他們就沒有罪；但如今，他們的罪無可推諉了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 8:40–42; 約翰二書 1:9; 約翰一書 2:23"> <span className="woj">恨我的，也恨我的父。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 5:36; 約翰福音 14:9; 約翰福音 7:31"> <span className="woj">如果我沒有在他們當中做別人從未做過的事，他們就沒有罪；但如今他們雖然看到了，還是恨我和我的父。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 109:3; 詩篇 69:4; 詩篇 35:19"> <span className="woj">不過這是為要應驗他們律法上所記載的話：『他們無緣無故地恨我。』</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約翰福音 14:26; 約翰福音 14:16–17; 約翰福音 16:13–15"> <span className="woj">「我將從父那裡派遣慰助者來，他就是從父而來的真理的靈。他來的時候，將為我做見證。</span></span>
<span className="v" id="v27" data-v="27" data-xref="約翰一書 4:14; 約翰福音 21:24; 使徒行傳 10:39–42"> <span className="woj">並且你們也要做見證，因為你們從一開始就與我在一起。</span></span>
</div>

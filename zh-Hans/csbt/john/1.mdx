<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="創世記 1:1; 約翰福音 17:5; 啟示錄 19:13"> <span className="pl pl-1">太初有道，</span><br /><span className="pl pl-1">道與神同在，</span><br /><span className="pl pl-1">道就是神。</span><br /></span>
<span className="v" id="v2" data-v="2"> <span className="pl pl-1">這道太初與神同在。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 1:16–17; 哥林多前書 8:6; 啟示錄 4:11"> <span className="pl pl-1">萬有是藉著他而成的；</span><br /><span className="pl pl-1">凡所成的，</span><br /><span className="pl pl-1">沒有一樣不是藉著他而成的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 8:12; 約翰福音 12:46; 約翰福音 5:26"> <span className="pl pl-1">生命在他裡面，</span><br /><span className="pl pl-1">這生命就是人的光。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 3:19–20; 約翰福音 12:36–40; 哥林多前書 2:14"> <span className="pl pl-1">這光在黑暗中照耀，</span><br /><span className="pl pl-1">黑暗卻沒有勝過</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="勝過——或譯作「領會」或「掌握」或「接受」。">a</a></sup><br /><span className="pl pl-1">這光。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 3:1; 約翰福音 3:28; 以賽亞書 40:3–5"> <span className="pl pl-1">有一個人受神的差派而來，</span><br /><span className="pl pl-1">他名叫約翰。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:4; 約翰福音 1:36; 約翰福音 5:33–35"> <span className="pl pl-1">他為見證而來，</span><br /><span className="pl pl-1">是要為這光做見證，</span><br /><span className="pl pl-1">好讓人都藉著他相信。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:20; 約翰福音 3:28; 使徒行傳 19:4"> <span className="pl pl-1">他不是這光，</span><br /><span className="pl pl-1">而是要為這光做見證。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 12:46; 約翰福音 1:4; 約翰一書 2:8"> <span className="pl pl-1">這光是真光，</span><br /><span className="pl pl-1">來到這世界照亮每個人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 17:25; 約翰一書 3:1; 哥林多前書 2:8"> <span className="pl pl-1">他在這世界，</span><br /><span className="pl pl-1">世界也是藉著他而成的，</span><br /><span className="pl pl-1">世界卻不認識他。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 以賽亞書 53:2–3; 約翰福音 3:32"> <span className="pl pl-1">他來到自己的地方，</span><br /><span className="pl pl-1">自己的人卻不接受他。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 3:26; 羅馬書 8:14; 約翰一書 3:1"> <span className="pl pl-1">但是所有接受他的，</span><br /><span className="pl pl-1">就是信他名的人，</span><br /><span className="pl pl-1">他就賜給他們權柄成為神的兒女。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 3:9; 雅各書 1:18; 彼得前書 1:23"> <span className="pl pl-1">他們不是由血緣、</span><br /><span className="pl pl-1">或肉體的意願、</span><br /><span className="pl pl-1">或人的意志所生的，</span><br /><span className="pl pl-1">而是由神所生的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:9; 提摩太前書 3:16; 以賽亞書 40:5"> <span className="pl pl-1">道成了肉身，</span><br /><span className="pl pl-1">居住在我們中間。</span><br /><span className="pl pl-1">我們看到了他的榮耀，</span><br /><span className="pl pl-1">正是從父而來的獨生子的榮耀，</span><br /><span className="pl pl-1">充滿了恩典和真理。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 3:11; 歌羅西書 1:17; 路加福音 3:16"> <span className="pl pl-1">約翰為他做見證，呼喊說：</span><br /><span className="pl pl-1">「這一位就是我曾說過的，</span><br /><span className="pl pl-1">『那在我之後來的，已成為在我前面的，</span><br /><span className="pl pl-1">因為他在我之前就已經存在。』」</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:19; 羅馬書 5:2; 以弗所書 2:5–10"> <span className="pl pl-1">原來從他的豐盛完美中，</span><br /><span className="pl pl-1">我們都領受了恩典，而且恩上加恩。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 6:14; 約翰福音 14:6; 羅馬書 3:19–26"> <span className="pl pl-1">因為律法是藉著摩西賜下的，</span><br /><span className="pl pl-1">恩典和真理是藉著耶穌基督而來的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:15; 約翰福音 6:46; 馬太福音 11:27"> <span className="pl pl-1">從來沒有人看見神，</span><br /><span className="pl pl-1">只有在父懷裡的那位獨生子——神，</span><br /><span className="pl pl-1">他將神表明了出來。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 約翰福音 10:24; 使徒行傳 19:4"> 以下是約翰的見證。那時候，耶路撒冷的那些猶太人派了一些祭司和利未人到約翰那裡去問他：「你是誰？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:7–8; 馬太福音 3:11–12; 約翰福音 3:28–36"> 他就承認，並毫不否認地告白：「我不是基督。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="瑪拉基書 4:5; 申命記 18:15–18; 馬太福音 11:14"> 他們又問：「那麼你是誰呢？是以利亞嗎？」<br />他說：「我不是。」<br />「是那位先知<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那位先知——《申命記》18:15。">b</a></sup>嗎？」<br />他回答：「不是。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 24:13"> 於是他們問：「你到底是誰？好讓我們給那些派我們來的人一個答覆。你自己說，你是什麼人？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 40:3–5; 馬可福音 1:3; 馬太福音 3:3"> 約翰說：「正如先知以賽亞所說的，我就是在曠野裡呼喊的聲音：『你們當修直<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="修直——或譯作「修平」。">c</a></sup>主的道<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="道——或譯作「路」。">d</a></sup>。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 馬太福音 23:13–15; 路加福音 11:39–44"> 那些被派來的人屬於法利賽人，</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:18; 申命記 18:15; 約翰福音 1:20–22"> 他們又問約翰：「你既不是基督，又不是以利亞，也不是那位先知，那麼，你為什麼施洗呢？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約翰福音 1:10–11; 路加福音 3:16; 使徒行傳 1:5"> 約翰回答說：「我用水<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="用水——或譯作「在水裡」。">e</a></sup>施洗，但有一位站在你們中間，是你們不認識的，</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 1:30; 馬可福音 1:7; 馬太福音 3:11"> 他是那在我之後來的，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「已成為在我前面的，」。">f</a></sup>我就是為他解鞋帶也不配。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 10:40; 約翰福音 3:23; 士師記 7:24"> 這些事發生在約旦河對岸的伯大尼<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="伯大尼——有古抄本作「伯達巴拉」。">g</a></sup>，就是約翰施洗的地方。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 53:7; 約翰一書 2:2; 約翰一書 3:5"> 第二天，約翰看見耶穌向他走來，就說：「看哪，神的羔羊，除去世人罪孽的！</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 1:27; 約翰福音 1:15; 路加福音 3:16"> 這一位就是我所說的『那在我之後來的人，已成為在我前面的，因為在我之前他就存在了。』</span>
<span className="v" id="v31" data-v="31" data-xref="瑪拉基書 3:1; 路加福音 1:17; 瑪拉基書 4:2–5"> 我以前也不認識他，但為了讓他向以色列顯明，所以我來用水施洗。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 1:10; 路加福音 3:22; 馬太福音 3:16"> 約翰又見證說：「我看到聖靈好像鴿子從天上降臨，停留在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 1:5; 馬太福音 3:11; 路加福音 3:16"> 我以前也不認識他，可是那派我用水施洗的對我說：『如果你看見聖靈降臨在誰身上，又停留在誰身上，誰就是用聖靈施洗的那一位。』</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 2:7; 約翰福音 1:49; 詩篇 89:26–27"> 我看到了，就見證：這一位就是神的兒子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神的兒子——有古抄本作「神所揀選的」。">h</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 3:25–26; 瑪拉基書 3:16"> 過了一天，約翰和他的兩個門徒又站在那裡。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 1:29; 彼得前書 1:19–20; 以賽亞書 65:1–2"> 約翰看著耶穌走過，就說：「看哪，神的羔羊！」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="羅馬書 10:17; 約翰福音 1:43; 撒迦利亞書 8:21"> 那兩個門徒聽他說話，就跟從了耶穌。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 18:7; 約翰福音 3:2; 約翰福音 1:49"> 耶穌轉過身來，看到他們跟著走，就問：<span className="woj">「你們尋找什麼呢？」</span><br />他們對耶穌說：「拉比，你住在哪裡呢？」——「拉比」翻譯出來意思是「老師」。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 馬太福音 11:28–30; 約翰福音 6:37"> 耶穌說：<span className="woj">「你們來看吧！」</span>他們去了，看見耶穌住的地方，那天就住在他那裡。那時大約是下午四點<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="下午四點——原文為「第十時刻」。">i</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬可福音 1:16–20; 馬太福音 4:18–22; 約翰福音 1:40–42"> 聽見了約翰的話而跟從耶穌的兩個人中，有一個是西門彼得的弟弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 4:25; 約翰福音 1:45; 詩篇 89:20"> 安得烈先去找自己的哥哥<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="哥哥——原文直譯「兄弟」。">j</a></sup>西門，對他說：「我們找到了彌賽亞。」——「彌賽亞」翻譯出來就是「基督」。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 21:15–17; 哥林多前書 3:22; 哥林多前書 15:5"> 他就帶西門到耶穌那裡。<br />耶穌注視著他，說：<span className="woj">「你是約翰</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="約翰——有古抄本作「約拿」。">k</a></sup><span className="woj">的兒子西門，你將被稱為磯法。」</span>——「磯法」翻譯出來就是「彼得<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="彼得——意思為「石頭」。">l</a></sup>」。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 9:9; 約翰福音 14:8; 以賽亞書 65:1"> 又過了一天，耶穌決定前往加利利地區。他找到腓力，對他說：<span className="woj">「你跟從我！」</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="約翰福音 12:21; 馬太福音 11:21; 馬可福音 8:22"> 腓力來自伯賽達，與安得烈和彼得同鄉。</span>
<span className="v" id="v45" data-v="45" data-xref="申命記 18:18–22; 路加福音 24:27; 彌迦書 5:2"> 腓力找到拿旦業<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="拿旦業——一般認為，此人與其他福音書和《使徒行傳》中的巴多羅邁是同一個人。">m</a></sup>，對他說：「我們發現了摩西在律法上所寫的，和先知們所記的那一位。他就是約瑟的兒子，拿撒勒人耶穌。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="約翰福音 7:52; 約翰福音 7:41–42; 約翰福音 4:29"> 拿旦業對他說：「拿撒勒還能出什麼好的嗎？」<br />腓力說：「你來看吧！」</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="啟示錄 14:5; 詩篇 32:2; 詩篇 73:1"> 耶穌看見拿旦業向他走來，就指著他說：<span className="woj">「看，一個真正的以色列人！他裡面沒有詭詐。」</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="以賽亞書 65:24; 約翰福音 2:25; 詩篇 139:1–2"> 拿旦業對耶穌說：「你怎麼知道我呢？」<br />耶穌回答說：<span className="woj">「腓力叫你以前，你還在無花果樹下，我就看見你了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="西番雅書 3:15; 撒迦利亞書 9:9; 馬太福音 27:42"> 拿旦業說：「拉比，你是神的兒子，你是以色列的王！」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="約翰福音 11:40; 約翰福音 20:29; 路加福音 1:45"> 耶穌對他說：<span className="woj">「因為我說『我看見你在無花果樹下』，你就信嗎？你將會看到比這更大的事。」</span></span>
<span className="v" id="v51" data-v="51" data-xref="創世記 28:12; 使徒行傳 7:56; 路加福音 22:43"> 耶穌又對他說：<span className="woj">「我確確實實地告訴你們：你們將會看見天敞開了，神的天使們在人子上頭，上去下來。」</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:1; 馬可福音 11:1; 路加福音 19:37"> 耶穌卻往橄欖山去。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 26:55; 路加福音 4:20; 路加福音 21:37"> 清晨，耶穌又來到聖殿，全體民眾到他那裡，他就坐下，開始教導他們。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 這時，經文士們和法利賽人帶來一個在通姦時被抓住的婦人，叫她站在中間。</span>
<span className="v" id="v4" data-v="4"> 他們對耶穌說：「老師，這婦人是正在通姦的時候被抓住的。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 20:10; 申命記 22:21–24; 以西結書 16:38–40"> 摩西在律法上吩咐我們用石頭砸死這樣的女人，既然如此，你怎麼說呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 17:13; 路加福音 10:25; 傳道書 3:7"> 他們說這話是要試探耶穌，為要找把柄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="把柄——輔助詞語。">a</a></sup>來控告他。<br />耶穌卻彎下腰，開始用指頭在地上寫字。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:1–5; 羅馬書 2:21–25; 羅馬書 2:1–3"> 可是當他們不停地追問耶穌的時候，耶穌就直起身來，對他們說：<span className="woj">「你們當中誰沒有罪，誰就先用石頭砸她吧！」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 然後他又彎下腰去，繼續在地上寫字。</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 7:22; 羅馬書 2:15; 約翰一書 3:20"> 他們聽了這話，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「受到良心的責備，」。">b</a></sup>從年長的開始<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「到年幼的」。">c</a></sup>，一個接一個地走開了。最後，只剩下耶穌和那站在中間的婦人。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 41:11–12"> 耶穌直起身來<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「除了那婦人以外沒有見到任何人」。">d</a></sup>問她：<span className="woj">「婦人，他們</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他們——有古抄本作「那些控告你的人」。">e</a></sup><span className="woj">在哪裡？沒有人定你的罪嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 3:17; 約翰福音 5:14; 以賽亞書 1:16–18"> 她說：「主啊，沒有。」<br />耶穌說：<span className="woj">「我也不定你的罪。你回去吧！從今以後不要再犯罪了。」</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有7:53-8:11。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 12:46; 約翰福音 9:5; 約翰福音 12:35"> 耶穌又對眾人說：<span className="woj">「我就是世界的光。跟從我的人，絕不會在黑暗裡行走，卻要得到生命的光。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 5:31–47"> 法利賽人對他說：「你為自己做見證，你的見證是無效<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="無效——原文直譯「不真實」。">g</a></sup>的。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 16:28; 約翰福音 13:3; 約翰福音 8:42"> 耶穌回答：<span className="woj">「即使我為自己做見證，我的見證也是有效</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有效——原文直譯「真實」。">h</a></sup><span className="woj">的，因為我知道我從哪裡來，往哪裡去；而你們卻不知道我從哪裡來，往哪裡去。</span></span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:7; 約翰福音 7:24; 約翰福音 12:47"> <span className="woj">你們是按人</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="人——原文直譯「肉體」。">i</a></sup><span className="woj">的標準來評斷，我卻不評斷任何人。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:31; 約翰福音 8:29; 約翰福音 16:32"> <span className="woj">不過，就算我評斷，我的評斷也是真實的，因為我不是獨自一人，而是有那派我來的父與我同在。</span></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 19:15; 申命記 17:6; 希伯來書 10:28"> <span className="woj">連你們的律法上也記載著：兩個人的見證才是有效的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 8:38; 約翰福音 8:58; 約翰福音 8:25"> <span className="woj">我為自己做見證，派我來的父也為我做見證。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:3; 約翰福音 8:54–55; 約翰福音 14:6–9"> 他們就問耶穌：「你的『父』在哪裡？」<br />耶穌回答：<span className="woj">「你們既不認識我，也不認識我的父；如果你們認識我，也就認識我的父。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:30; 約翰福音 7:8; 馬可福音 12:41"> 這些話是耶穌在聖殿的奉獻箱附近教導人的時候說的。可是沒有人抓他，因為他的時候還沒有到。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 7:34; 約翰福音 8:24; 哥林多前書 15:17–18"> 後來，耶穌又對他們說：<span className="woj">「我要去了，你們將要尋找我，並且將死在自己的罪中。我去的地方，你們不能去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 8:52; 詩篇 22:6; 約翰福音 8:48"> 那些猶太人就說：「他說<span className="woj">『我去的地方，你們不能去』</span>，難道他要自殺嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 3:31; 約翰福音 17:14; 約翰福音 17:16"> 耶穌對他們說：<span className="woj">「你們從下面來，我從上面來；你們屬於這世界，我不屬於這世界。</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 3:36; 馬可福音 16:16; 約翰福音 3:18"> <span className="woj">所以我對你們說過『你們將死在自己的罪孽中。』事實上，你們如果不信我就是那一位，就將死在自己的罪孽中。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 5:17–29; 路加福音 22:67; 約翰福音 1:22"> 他們問：「你到底是誰？」<br />耶穌說：<span className="woj">「我從一開始就告訴你們了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:15; 約翰福音 12:47–50; 約翰福音 8:40"> <span className="woj">關於你們，我有很多事要說、要評斷；不過派我來的那一位是真實的，我從他那裡聽了這些事，就向世人說出來。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 6:9; 約翰福音 8:43; 哥林多後書 4:3–4"> 他們不明白耶穌對他們說的是有關父的事。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 5:19; 約翰福音 5:30; 約翰福音 6:38"> 所以耶穌說：<span className="woj">「你們舉起人子的時候，你們那時就會明白我就是那一位，也會明白我不憑自己做什麼，而且我說這些話，也是照著父所教導我的。</span></span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 6:38; 約翰福音 16:32; 約翰福音 4:34"> <span className="woj">派我來的那一位與我同在；他</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="他——有古抄本作「父」。">j</a></sup><span className="woj">沒有撇下我，使我獨自一人，因為我一直做他所喜悅的事。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 7:31; 約翰福音 2:23; 約翰福音 11:45"> 耶穌說這些話的時候，許多人就信了他。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰二書 1:9; 約翰福音 15:4–9; 提摩太後書 3:14"> 於是耶穌對信他的猶太人說：<span className="woj">「你們如果住在我的話語中，就真是我的門徒了，</span></span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 8:2; 約翰福音 8:36; 約翰福音 17:17"> <span className="woj">並且你們將明白真理，而真理將使你們自由。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 3:9; 約翰福音 8:39; 創世記 15:13"> 他們回答：「我們是亞伯拉罕的後裔，從來沒有做過誰的奴僕。你怎麼說『你們將要得自由』呢？」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="羅馬書 6:16; 彼得後書 2:19; 箴言 5:22"> 耶穌回答：<span className="woj">「我確確實實地告訴你們：所有犯罪的，就是罪的奴隸。</span></span>
<span className="v" id="v35" data-v="35" data-xref="加拉太書 4:4–7; 路加福音 15:31; 羅馬書 8:15–17"> <span className="woj">奴隸不會永遠住在家裡，兒子卻會永遠住在家裡。</span></span>
<span className="v" id="v36" data-v="36" data-xref="哥林多後書 3:17; 加拉太書 5:1; 羅馬書 8:2"> <span className="woj">所以，如果子使你們自由，你們就真正自由了。</span></span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 2:14; 約翰福音 8:45–47; 約翰福音 7:1"> <span className="woj">我知道你們是亞伯拉罕的後裔。可是你們想要殺我，因為你們裡面容不下我的話語。</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 5:19; 約翰福音 8:44; 約翰福音 8:41"> <span className="woj">我所說的，是我從我</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本沒有「我」。">k</a></sup><span className="woj">父那裡所看到的；而實際上，你們所做的，是從你們的</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有「你們的」。">l</a></sup><span className="woj">父那裡所聽到</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="聽到——有古抄本作「看到」。">m</a></sup><span className="woj">的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="加拉太書 3:7; 約翰福音 8:37; 羅馬書 9:7"> 他們回答說：「亞伯拉罕是我們的父！」<br />耶穌說：<span className="woj">「如果你們是亞伯拉罕的兒女，就會做亞伯拉罕所做的事。</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 8:26; 加拉太書 4:29; 加拉太書 4:16"> <span className="woj">但如今，我把從神那裡所聽到的真理告訴了你們，你們就想殺我。亞伯拉罕沒有做過這種事。</span></span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 64:8; 約翰福音 8:38; 以賽亞書 63:16"> <span className="woj">你們在做你們的父所做的事。」</span><br />他們回答說：「我們不是由淫亂所生的，我們只有一位父，就是神。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:49; 約翰福音 14:10; 約翰福音 17:8"> 耶穌說：<span className="woj">「如果神是你們的父，你們就會愛我，因為我是出於神，並且從神那裡來。要知道，我並不是憑自己而來的，而是那一位差派了我。</span></span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 12:39–40; 羅馬書 8:7–8; 約翰福音 7:17"> <span className="woj">你們為什麼不明白我的話呢？這是因為你們聽不進我的話語。</span></span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 13:10; 約翰一書 3:12; 約翰一書 3:8–10"> <span className="woj">你們屬於你們的父——魔鬼，並且想要隨你們父的欲望去做。他從起初就是殺人的，不站在真理之中，因為他裡面沒有真理。他說虛假之事是出於自己的本性，因為他本來就是個說謊者，並且是說謊者之父。</span></span>
<span className="v" id="v45" data-v="45" data-xref="提摩太後書 4:3–4; 加拉太書 4:16; 約翰福音 18:37"> <span className="woj">可是因為我講真理，你們就不相信我！</span></span>
<span className="v" id="v46" data-v="46" data-xref="希伯來書 4:15; 約翰福音 16:8; 彼得前書 2:22"> <span className="woj">你們當中誰能指證我有罪呢？既然我講的是真理，你們為什麼不相信我呢？</span></span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 10:26–27; 約翰二書 1:9; 約翰福音 18:37"> <span className="woj">屬神的人，就聽神的話語；你們之所以不聽，是因為你們不屬於神。」</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約翰福音 7:20; 約翰福音 8:52; 馬太福音 10:5"> 那些猶太人回答說：「我們說你是個撒瑪利亞人，並且有鬼魔附身，難道說得不對嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="彼得前書 2:23; 以賽亞書 49:3; 約翰福音 13:31–32"> 耶穌回答：<span className="woj">「我沒有鬼魔附身。我尊重我的父，你們卻侮辱我。</span></span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 5:41; 約翰福音 8:54; 約翰福音 7:18"> <span className="woj">我不尋求自己的榮耀，但有尋求和判斷的那一位。</span></span>
<span className="v" id="v51" data-v="51" data-xref="約翰福音 11:25–26; 約翰福音 5:24; 約翰福音 3:15–16"> <span className="woj">我確確實實地告訴你們：人如果遵守我的話語，就絕不見死亡，直到永遠。」</span></span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="約翰福音 9:24; 約翰福音 8:48; 希伯來書 2:9"> 猶太人說：「現在我們知道你是有鬼魔附身的。亞伯拉罕死了，先知們也死了，你還說<span className="woj">『人如果遵守我的話語，就絕不會嘗到死的滋味，直到永遠。』</span></span>
<span className="v" id="v53" data-v="53" data-xref="約翰福音 4:12; 羅馬書 9:5; 希伯來書 7:1–7"> 難道你比我們的先祖亞伯拉罕更大嗎？他死了，先知們也死了。你把自己當做什麼人？」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="約翰福音 8:50; 箴言 25:27; 彼得後書 1:17"> 耶穌回答：<span className="woj">「如果我榮耀自己，我的榮耀就算不得什麼。榮耀我的是我的父，就是你們說『他是我們的神』的那一位。</span></span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 8:19; 約翰福音 8:44; 約翰福音 7:28–29"> <span className="woj">你們不認識他，我卻認識他。如果我說我不認識他，我就成了像你們那樣的說謊者。但我認識他，也遵守他的話語。</span></span>
<span className="v" id="v56" data-v="56" data-xref="希伯來書 11:13; 創世記 22:18; 加拉太書 3:7–9"> <span className="woj">你們的先祖亞伯拉罕因為將要看到我的日子就快樂。他看到了，就歡喜。」</span></span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57"> 猶太人就對他說：「你還不到五十歲，怎麼會見過亞伯拉罕？<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="怎麼會見過亞伯拉罕？——有古抄本作「亞伯拉罕怎麼會見過你？」">n</a></sup>」</span>

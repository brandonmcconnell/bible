<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 5:16–18; 約翰福音 4:3; 馬太福音 21:38"> 這些事以後，耶穌走遍加利利。原來他不願意在猶太地區往來，因為那些猶太人想要殺害他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 14:16–19; 申命記 16:13–16; 出埃及記 23:16–17"> 猶太人的住棚節快到了，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:46; 約翰福音 7:5; 路加福音 8:19"> 耶穌的弟弟們對他說：「你離開這裡到猶太去吧，好讓你的門徒們也能看到你所做的事。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:20; 箴言 18:1–2; 馬太福音 23:5"> 因為人不會又想要出名，又在隱祕中做事。你既然要做這些事，就把自己顯明給世人看吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 3:21; 約翰福音 1:11–13; 彌迦書 7:5–6"> 原來連他的弟弟們也不信他。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 7:8; 約翰福音 2:4; 約翰福音 7:30"> 耶穌對他們說：<span className="woj">「我的時候還沒有來到，而你們的時候隨時都方便。</span></span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:18–19; 約翰福音 3:19; 加拉太書 4:16"> <span className="woj">世界不能恨你們，卻是恨我，因為我見證世界的行為是邪惡的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 7:6; 約翰福音 8:20; 約翰福音 7:30"> <span className="woj">你們上去過節吧，我現在不</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="現在不——有古抄本作「不」。">a</a></sup><span className="woj">上去，因為我的時候還沒有到。」</span></span>
<span className="v" id="v9" data-v="9"> 說了這些話，耶穌仍然留在加利利地區。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 5:13; 馬太福音 10:16; 以賽亞書 42:2–3"> 不過當他的弟弟們上去過節以後，他也上去了，但沒有公開，像是悄悄去的。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:56"> 節日期間，那些猶太人搜尋耶穌，說：「那個人在哪裡？」</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 7:40–43; 約翰福音 9:16; 約翰福音 7:32"> 人群中有許多人對他議論紛紛；有的說：「他是好人。」也有的說：「不，他是迷惑民眾的。」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 9:22; 約翰福音 19:38; 約翰福音 20:19"> 只是沒有人公開地講論他的事，因為怕那些猶太人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 7:28; 路加福音 19:47; 約翰福音 7:37"> 可是住棚節已經過了一半，耶穌上聖殿去，開始教導人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 馬太福音 7:28–29; 馬太福音 13:54"> 那些猶太人感到驚奇，說：「這個人沒學過，怎麼懂得經文呢？」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:10; 約翰福音 14:24; 約翰福音 17:8"> 耶穌回答他們，說：<span className="woj">「我的教導不是我自己的，而是那派我來者的。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 8:31–32; 約翰福音 8:43; 耶利米書 31:33–34"> <span className="woj">人如果願意遵行神的旨意，就會明白這教導究竟是從神而來的，還是我憑自己而講的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 5:41; 哥林多前書 10:31–33; 約翰福音 13:31–32"> <span className="woj">憑自己講話的人，是尋求自己的榮耀；但是，尋求那派他來者之榮耀的，他才是真實的，在他裡面沒有不義。</span></span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 1:17; 約翰福音 11:53; 馬太福音 12:14"> <span className="woj">摩西不是把律法傳給你們了嗎？你們當中卻沒有一個人遵行這律法。你們為什麼想要殺我呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:20; 約翰福音 8:48; 約翰福音 8:52"> 眾人回答：「你有鬼魔附身！誰想要殺你？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 7:23; 約翰福音 5:2–11"> 耶穌對他們說：<span className="woj">「我做了一件事，你們都感到驚奇。</span></span>
<span className="v" id="v22" data-v="22" data-xref="利未記 12:3; 創世記 17:10–14; 羅馬書 4:9–11"> <span className="woj">摩西把割禮傳給你們，你們就在安息日給人施行割禮——其實割禮不是從摩西開始的，而是從祖先開始的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:5; 約翰福音 5:14–16; 馬太福音 12:2"> <span className="woj">既然人在安息日受割禮，是為了不違犯摩西的律法；那麼，因為我在安息日使一個人完全康復，你們就對我生氣嗎？</span></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 11:3–4; 雅各書 2:9; 約翰福音 8:15"> <span className="woj">不要按著外表做判斷，而要按著公義做判斷。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 7:10–11"> 有些耶路撒冷的人說：「這不是他們想要殺的那個人嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:7–8; 約翰福音 7:48; 約翰福音 12:42"> 看，他還在公開講話，他們也沒有對他說什麼。難道首領們真的認為這個人就是<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是——有古抄本作「真是」。">b</a></sup>基督嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 5:2; 約翰福音 7:41–42; 約翰福音 6:42"> 可是，基督出現的時候，沒有人會知道他從哪裡來；而這個人，我們卻很清楚他是從哪裡來的。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 8:42; 約翰福音 8:19; 約翰福音 8:26"> 耶穌在聖殿裡教導人，呼喊說：<span className="woj">「你們認識我，也知道我是從哪裡來的。其實我不是憑自己而來的；派我來的那一位是真實的，你們卻不認識他；</span></span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 8:55; 馬太福音 11:27; 約翰福音 17:18"> <span className="woj">而我認識他，因為我是從他而來，也是他差派了我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 8:20; 約翰福音 10:39; 約翰福音 7:6"> 因此他們想要抓耶穌，只是沒有人下手，因為他的時候還沒有到。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 12:42; 馬太福音 12:23; 約翰福音 10:41–42"> 但是人群中有許多人信了耶穌，他們說：「基督來的時候，難道會比這個人行更多的神蹟嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約翰福音 18:3; 路加福音 22:52–53; 約翰福音 11:47–48"> 法利賽人聽到了眾人私下議論耶穌的這些事。於是祭司長們和法利賽人就派差役們去抓他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約翰福音 16:5; 約翰福音 13:33; 馬可福音 16:19"> 耶穌說：<span className="woj">「我與你們在一起的時候不多了，我要回到派我來的那一位面前。</span></span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; 約翰福音 13:33–36; 約翰福音 14:6"> <span className="woj">你們將要尋找我，卻找不到；我所在的地方，你們不能去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="雅各書 1:1; 以賽亞書 11:12; 西番雅書 3:10"> 那些猶太人彼此問：「這個人要到哪裡去，讓我們找不到他呢？難道他要往散居在希臘人中的猶太僑民那裡，去教導希臘人嗎？</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 3:9; 約翰福音 7:34; 約翰福音 12:34"> 他所說的<span className="woj">『你們將要尋找我，卻找不到；我所在的地方，你們不能去』</span>，這話是什麼意思呢？」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 55:1; 約翰福音 4:14; 約翰福音 6:35"> 節期的最後一天，也是最盛大的日子，耶穌站起來呼喊說：<span className="woj">「如果有人渴了，就到我這裡</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「到我這裡」。">c</a></sup><span className="woj">來喝吧！</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 4:14; 以賽亞書 44:3; 以賽亞書 58:11"> <span className="woj">信我的人，就如經上所說的，從他的腹中將要湧流出活水的江河。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 2:17; 約珥書 2:28; 約翰福音 14:16–17"> 耶穌這話是指著信他的人所要領受的聖靈而說的。當時，聖靈<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="聖靈——有古抄本作「靈」。">d</a></sup>還沒有臨到<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="臨到——有古抄本作「賜下來」。">e</a></sup>，因為耶穌還沒有得榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 21:11; 約翰福音 1:21; 約翰福音 6:14"> 眾人聽了這話，有些<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有些——有古抄本作「許多」。">f</a></sup>人說：「這個人確實是那位先知！」</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 7:52; 約翰福音 1:46; 約翰福音 1:49"> 另有的說：「這個人就是基督。」還有的卻說：「難道基督會出自加利利嗎？</span>
<span className="v" id="v42" data-v="42" data-xref="彌迦書 5:2; 馬太福音 2:5; 路加福音 2:4"> 經上不是說，基督是大衛的後裔，是出自大衛的故鄉伯利恆嗎？」</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 9:16; 約翰福音 10:19; 約翰福音 7:12"> 於是眾人因耶穌就產生了分裂；</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 7:30; 使徒行傳 23:11; 約翰福音 8:20"> 其中有些人想要抓他，可是沒有人下手。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 7:32; 使徒行傳 5:21–27"> 差役們回到祭司長們和法利賽人那裡。那些人問：「為什麼沒有把他帶來？」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="馬太福音 7:28–29; 路加福音 4:22; 約翰福音 7:26"> 差役們回答：「從來沒有人像這個人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「像這個人」。">g</a></sup>那樣講話！」</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="約翰福音 7:12; 哥林多後書 6:8; 列王紀下 18:32"> 法利賽人說：「難道你們也被迷惑了嗎？</span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 12:42; 哥林多前書 1:20; 哥林多前書 2:8"> 難道首領或法利賽人中有信他的嗎？</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:20–21; 約翰福音 9:40; 約翰福音 9:34"> 這不懂律法的民眾是被詛咒的！」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:39; 約翰福音 3:1–2"> 他們當中有一個人，就是原先<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原先——有古抄本作「夜裡」。">h</a></sup>來到耶穌那裡的尼克迪莫，對他們說：</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命記 1:17; 申命記 19:15–19"> 「如果不先聽本人的口供，並且了解他做了什麼，我們的律法就定不了他的罪，難道不是嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="約翰福音 7:41; 約翰福音 1:46; 以賽亞書 9:1–2"> 他們回答說：「你也不會是加利利人吧？你去查一查看，先知是不會從加利利興起的！」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="詩篇 33:10; 約伯記 5:12–13; 詩篇 76:10"> 然後他們每個人都回家去了。</span>
</div>
</div>

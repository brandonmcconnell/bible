<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 6:31–44; 約翰福音 6:23; 路加福音 5:1"> 這些事以後，耶穌渡過加利利湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直譯「海」。">a</a></sup>，也就是太巴列湖，到對岸去。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:24–25; 馬太福音 12:15; 馬太福音 15:30–31"> 有一大群人，因為看到他在病人身上所行的神蹟，就跟隨他。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約翰福音 6:15; 路加福音 9:28; 路加福音 6:12–13"> 耶穌上了山，與他的門徒們在那裡坐下。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 2:13; 約翰福音 11:55; 約翰福音 5:1"> 那時猶太人的逾越節快到了。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 15:33; 路加福音 9:12–13; 馬太福音 14:14–15"> 耶穌舉目觀看，見一大群人向他走來，就對腓力說：<span className="woj">「我們從哪裡買餅給這些人吃呢？」</span></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 22:1; 申命記 13:3; 歷代志下 32:31"> 他說這話是要試試腓力，其實他自己已經知道要做什麼了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民數記 11:21–22; 馬可福音 6:37; 約翰福音 12:5"> 腓力回答：「就是兩百個銀幣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="兩百個銀幣——原文為「200得拿利」。1得拿利=約1日工資的羅馬銀幣。">b</a></sup>的餅，也不夠每個人吃一小塊！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:40–44; 馬太福音 4:18"> 他的一個門徒，就是西門彼得的弟弟安得烈，對耶穌說：</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 4:42–44; 馬太福音 14:17; 馬可福音 6:38"> 「這裡有個孩子，帶了五個大麥餅和兩條魚。可是對這麼多人，這些算什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:14–16; 馬太福音 15:35–36; 馬可福音 6:39–41"> 耶穌說：<span className="woj">「讓他們坐下來。」</span><br />那地方草多，他們坐了下來；男人的數目約有五千。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 6:23; 帖撒羅尼迦前書 5:18; 馬太福音 15:36"> 耶穌就拿起餅來，祝謝以後，分給那些坐著的人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="分給那些坐著的人——有古抄本作「分給門徒們，門徒們又分給那些坐著的人」。">c</a></sup>，把魚也如此分了，他們要多少就給多少。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:53; 尼希米記 9:25; 尼希米記 8:10"> 大家吃飽了以後，耶穌就對他的門徒們說：<span className="woj">「把剩下的碎塊收拾起來，免得浪費。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 列王紀下 4:2–7; 哥林多後書 9:8–9"> 他們就把大家吃剩的那五個大麥餅的碎塊收拾起來，裝滿了十二個籃子。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 18:15–18; 馬太福音 21:11; 使徒行傳 7:37"> 眾人看見耶穌所行的神蹟，就說：「這個人確實是那位要來到世上的先知！」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:36; 約翰福音 6:15–21; 約翰福音 7:3–4"> 耶穌看出他們要來強迫他做王，就又獨自退到山上去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了晚上，他的門徒們下到湖邊。</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 6:45; 約翰福音 6:24–25; 約翰福音 2:12"> 他們上了船，開始渡過湖往迦百農去。原來天色已經黑了，而耶穌還沒有來到他們那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 107:25; 詩篇 135:7; 馬太福音 14:24"> 當時，大風吹起，湖水翻騰。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 6:47–49; 馬太福音 14:25–26; 約伯記 9:8"> 他們已經划了約有四、五公里<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="四、五公里——原文為「25-30視距」。1視距=185公尺。">d</a></sup>，看到耶穌在湖面上行走，逐漸向船靠近，他們就感到懼怕。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 14:27–31; 以賽亞書 43:1–2; 以賽亞書 44:8"> 耶穌對他們說：<span className="woj">「是我，不要怕！」</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:51; 馬太福音 14:32–33; 啟示錄 3:20"> 門徒們這才願意接他上船。船立刻就到了他們所要去的地方。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 6:45; 馬太福音 14:22; 約翰福音 6:2"> 第二天，留在湖對岸的眾人，知道在那裡除了一條小船之外<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="除了一條小船之外——有古抄本作「除了耶穌的門徒們上的那一條小船之外」。">e</a></sup>，沒有別的船；而且知道耶穌沒有和他的門徒們一起上船，是門徒們自己去的。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 6:1; 約翰福音 6:11–12"> 有幾條別的小船從太巴列城來，靠近主祝謝後眾人吃餅的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:17; 路加福音 8:40; 馬可福音 6:53"> 這樣，眾人一發現耶穌已經不在那裡，連他的門徒們也不在那裡，就上了船，往迦百農去找耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 1:38–39; 馬太福音 23:7"> 他們在湖的對岸找到了耶穌，就問他：「拉比，你是什麼時候到這裡來的？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各書 4:3–4; 腓立比書 3:19; 腓立比書 2:21"> 耶穌回答說：<span className="woj">「我確確實實地告訴你們：你們找我，並不是因為看見了神蹟，而是因為你們吃餅吃飽了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 3:2; 以賽亞書 55:2; 約翰福音 6:54"> <span className="woj">不要為那會腐敗的食物做工，而要為那存留到永生的食物做工。這食物就是人子要給你們的，因為人子是父神所印證的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 16:30; 使徒行傳 9:6; 馬太福音 19:16"> 他們問：「我們應該做什麼，才算做神的工作呢？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰一書 3:23; 使徒行傳 16:31; 約翰福音 3:36"> 耶穌回答說：<span className="woj">「信神所派來的那一位，就是做神的工作。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:37; 約翰福音 10:38; 哥林多前書 1:22"> 他們就問：「那麼，你行個什麼神蹟，好讓我們看了就可以信你呢？你可以做什麼呢？</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 9:15; 詩篇 105:40; 詩篇 78:24–25"> 我們的祖先在曠野吃了嗎哪，正如經上所記：『他把從天上來的糧賜給他們吃。』」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約翰福音 15:1; 約翰福音 6:58; 出埃及記 16:4"> 耶穌對他們說：<span className="woj">「我確確實實地告訴你們：那從天上來的糧不是摩西賜給你們的，而是我父把從天上來的真糧賜給了你們。</span></span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 8:42; 約翰福音 17:8; 約翰福音 3:13"> <span className="woj">要知道，神的糧就是從天上降下來、賜生命給世人的那一位。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 4:15; 約翰福音 6:26; 詩篇 4:6"> 他們就對耶穌說：「主啊，請你時常把這糧賜給我們！」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 6:48–58; 啟示錄 22:17; 約翰福音 6:41"> 耶穌對他們說：<span className="woj">「我就是生命的糧。到我這裡來的人，絕不飢餓；信我的人，永不乾渴。</span></span>
<span className="v" id="v36" data-v="36" data-xref="彼得前書 1:8–9; 路加福音 16:31; 約翰福音 12:37"> <span className="woj">但是我告訴過你們，你們雖然看到了我</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「我」。">f</a></sup><span className="woj">，還是不信。</span></span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 11:28; 約翰福音 6:39; 約翰福音 17:24"> <span className="woj">凡是父賜給我的人，都會到我這裡來，而到我這裡來的人，我絕不丟棄</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="丟棄——原文直譯「趕出去」。">g</a></sup><span className="woj">，</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 5:30; 約翰福音 4:34; 約翰福音 3:31"> <span className="woj">因為我從天上降下來，不是要行自己的意思，而是要行那派我來者的意思。</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 17:12; 約翰福音 6:40; 約翰福音 18:9"> <span className="woj">那派我來者</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「——父」。">h</a></sup><span className="woj">的旨意，就是要我不失去他賜給我的任何人，而且要我在末日使他復活。</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 6:54; 約翰福音 5:24; 羅馬書 6:23"> <span className="woj">要知道，我父</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="我父——有古抄本作「那派我來者」。">i</a></sup><span className="woj">的旨意正是：所有看見子而信他的人都得到永恆的生命，並且在末日，我將要使他復活。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 6:51–52; 約翰福音 6:48; 約翰福音 6:33"> 這時候，一些猶太人因為耶穌說<span className="woj">『我是從天上降下來的糧』</span>，就私下議論他，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 4:22; 馬可福音 6:3; 馬太福音 13:55–56"> 並說：「這不就是約瑟的兒子耶穌嗎？我們不都認識他的父母嗎？現在他怎麼說<span className="woj">『我是從天上降下來的』</span>呢？」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="希伯來書 4:13; 約翰福音 6:64; 馬可福音 9:33"> 耶穌就對他們說：<span className="woj">「你們不要彼此議論了。</span></span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 6:65; 約翰福音 6:39–40; 馬太福音 11:25–27"> <span className="woj">如果不是派我來的父引領他，沒有人能到我這裡來；到我這裡來的，在末日我還要使他復活。</span></span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 54:13; 耶利米書 31:33–34; 希伯來書 10:16"> <span className="woj">先知書上記著：『他們都將成為神所教導的人。』任何人聽了並領會了從父而來的教導，就會到我這裡來。</span></span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 1:18; 約翰福音 7:29; 馬太福音 11:27"> <span className="woj">這並不是說，有誰看到父；只有從神而來的那一位，他才看到父。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:36; 歌羅西書 3:3–4; 羅馬書 5:9–10"> <span className="woj">「我確確實實地告訴你們：信我</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「我」。">j</a></sup><span className="woj">的人，就有永恆的生命。</span></span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 6:51; 哥林多前書 11:24–25; 哥林多前書 10:16–17"> <span className="woj">我就是生命的糧。</span></span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 10:3–5; 猶大書 1:5; 撒迦利亞書 1:5"> <span className="woj">你們的祖先在曠野吃了嗎哪，還是死了。</span></span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 6:33; 約翰福音 6:51; 羅馬書 8:10"> <span className="woj">那從天上降下來、讓人吃了而不死的糧，就在這裡。</span></span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 22:19; 約翰福音 6:33; 希伯來書 10:5–12"> <span className="woj">我就是從天上降下來的生命的糧。人如果吃了這糧，就將活著，直到永遠。我要賜的糧就是我的肉身，是為了世人的生命所賜的</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本沒有「所賜的」。">k</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="約翰福音 9:16; 約翰福音 10:19; 約翰福音 6:41"> 於是那些猶太人彼此爭論，說：「這個人怎麼能把自己的肉身給我們吃呢？」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="約翰一書 5:12; 馬太福音 26:26–28; 約翰福音 6:55"> 耶穌說：<span className="woj">「我確確實實地告訴你們：如果你們不吃人子的肉，不喝人子的血，你們裡面就沒有生命。</span></span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 6:39–40; 約翰福音 6:27; 腓立比書 3:7–10"> <span className="woj">吃我肉、喝我血的人，就有永恆的生命，在末日我還要使他復活；</span></span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 15:1; 約翰福音 8:31; 約翰福音 6:32"> <span className="woj">因為我的肉是真食物，我的血是真飲物。</span></span>
<span className="v" id="v56" data-v="56" data-xref="約翰一書 3:24; 約翰福音 15:4–5; 約翰福音 14:20"> <span className="woj">吃我肉、喝我血的人，住在我裡面，我也住在他裡面。</span></span>
<span className="v" id="v57" data-v="57" data-xref="加拉太書 2:20; 約翰福音 5:26; 約翰福音 17:21"> <span className="woj">永生的父怎樣差派了我，我又因父而活，照樣，以我為食的人也將因我而活。</span></span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 3:36; 約翰福音 6:47–51; 約翰福音 6:41"> <span className="woj">這才是從天上降下來的糧，不像嗎哪。你們的</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有「嗎哪。你們的」。">l</a></sup><span className="woj">祖先吃過嗎哪還是死了，而吃這糧的人就將活著，直到永遠。」</span></span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="約翰福音 6:24; 箴言 8:1–3; 路加福音 4:31"> 這些話是耶穌在迦百農教導人的時候，在會堂裡說的。</span>

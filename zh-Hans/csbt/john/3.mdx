<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 19:39; 約翰福音 7:47–50; 約翰福音 3:10"> 有一個人，屬於法利賽人，名叫尼克迪莫，是猶太人的一位首領。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 5:36; 使徒行傳 10:38; 使徒行傳 2:22"> 他夜裡來到耶穌那裡，說：「拉比，我們知道你是從神那裡來的老師，因為你所行的這些神蹟，如果沒有神的同在，沒有人能做得到。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 5:17; 約翰福音 3:5–6; 彼得前書 1:23–25"> 耶穌回答說：<span className="woj">「我確確實實地告訴你：一個人如果不重生</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="重生——或譯作「由上天而生」。">a</a></sup><span className="woj">，就不能見神的國。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 2:14; 哥林多前書 1:18; 約翰福音 3:3"> 尼克迪莫問：「人老了，怎麼能出生呢？他難道能再進母腹又出生嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 36:25–27; 以弗所書 5:26; 使徒行傳 2:38"> 耶穌回答：<span className="woj">「我確確實實地告訴你：一個人如果不是由水和聖靈所生的，就不能進入神的國。</span></span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 5:16–21; 以西結書 36:26–27; 羅馬書 8:4–9"> <span className="woj">由肉體所生的，就是肉體；由聖靈所生的，就是靈。</span></span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 3:3; 以弗所書 4:22–24; 羅馬書 12:1–2"> <span className="woj">我說『你們必須重生</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="重生——或譯作「由上天而生」。">b</a></sup><span className="woj">』，你不要感到驚奇。</span></span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 11:4–5; 哥林多前書 2:11; 使徒行傳 2:2"> <span className="woj">風</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="風——或譯作「靈」或「聖靈」。">c</a></sup><span className="woj">隨意而吹，你聽見風聲，卻不知道它從哪裡來，往哪裡去。所有由聖靈所生的，也是這樣。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 6:60; 路加福音 1:34; 以賽亞書 42:16"> 尼克迪莫又問：「怎麼能有這些事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 22:29; 耶利米書 8:8–9; 以西結書 11:19"> 耶穌回答說：<span className="woj">「你是以色列的老師，還不明白這些事嗎？</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 8:38; 約翰一書 5:6–12; 約翰福音 12:49"> <span className="woj">我確確實實地告訴你：我們講論我們所知道的，我們見證我們所看到的，而你們卻不接受我們的見證。</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 3:1–2; 哥林多前書 2:7–9; 希伯來書 5:11"> <span className="woj">我告訴你們地上的事，你們尚且不信，如果我告訴你們天上的事，你們怎麼會信呢？</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 約翰福音 6:38; 使徒行傳 2:34"> <span className="woj">除了從天上降下來的人子，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「就是在天上的那一位，」。">d</a></sup><span className="woj">沒有人升過天。</span></span>
<span className="v" id="v14" data-v="14" data-xref="民數記 21:7–9; 約翰福音 8:28; 約翰福音 12:32–34"> <span className="woj">摩西在曠野怎樣把銅蛇舉起，人子也必須照樣被舉起來，</span></span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 3:16; 約翰福音 6:40; 約翰福音 12:44–46"> <span className="woj">好使所有相信他的人</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「不至於滅亡，反而」。">e</a></sup><span className="woj">，都得到永恆的生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="羅馬書 5:8; 約翰一書 4:9–10; 約翰福音 3:15"> <span className="woj">「神愛世人，甚至賜下他的獨生子，好讓所有信他的人不至於滅亡，反得永恆的生命，</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰一書 4:14; 路加福音 19:10; 約翰福音 12:47–48"> <span className="woj">因為神差派他的</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「他的」。">f</a></sup><span className="woj">兒子來到世上，不是為了定世人的罪，而是為了世人藉著他得救。</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 16:16; 約翰一書 5:10; 羅馬書 8:1"> <span className="woj">信他的人，不被定罪；不信的人，已經被定罪了，因為他不信神獨生子的名。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 8:12; 帖撒羅尼迦後書 2:12; 約翰福音 9:39–41"> <span className="woj">「所定的罪是這樣的：光來到了世界，人們卻因自己的行為邪惡，不喜愛光，反喜愛黑暗。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 5:11–13; 約翰福音 7:7; 約伯記 24:13–17"> <span className="woj">事實上，所有作惡的人，都憎恨光，不來到光那裡，免得自己的行為被揭露出來；</span></span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 1:6; 詩篇 139:23–24; 約翰三書 1:11"> <span className="woj">但行真理的人，卻來到光那裡，為了顯明自己所做的是在神裡面被做成的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:1–3; 約翰福音 3:26; 約翰福音 2:13"> 這些事以後，耶穌和他的門徒們來到猶太地區，住在那裡，並且給人施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 1:4–5; 以西結書 43:2; 馬太福音 3:5–6"> 約翰也在撒令附近的艾嫩施洗，因為那裡水多。眾人紛紛而來受洗。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 4:12; 馬太福音 14:3; 馬可福音 6:17"> 原來，約翰那時候還沒有被投進監獄。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 2:6; 馬太福音 3:11; 希伯來書 6:2"> 約翰的門徒們與一個<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一個——有古抄本作「一些」。">g</a></sup>猶太人，為了潔淨禮起了辯論。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 1:7; 約翰福音 1:15; 約翰福音 12:19"> 他們就到約翰那裡，對他說：「拉比，你看，以前與你在約旦河對岸的，就是你所見證的那一位，他也在施洗，而且大家都到他那裡去了。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="雅各書 1:17; 哥林多前書 4:7; 哥林多前書 15:10"> 約翰回答說：「如果不是從天上賜下的，人就不能得到什麼。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:20; 約翰福音 1:23; 馬太福音 3:11–12"> 你們自己可以為我見證：我曾經說過『我不是基督，而是奉差派在他前面的。』</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 9:15; 何西阿書 2:19; 以賽亞書 54:5"> 迎娶新娘的是新郎。新郎的朋友站在那裡，聽到新郎的聲音，就歡喜快樂。這樣，我這喜樂得以滿足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 1:18; 詩篇 72:17–19; 希伯來書 3:2–6"> 他必興旺，我必衰微。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 8:23; 馬太福音 28:18; 羅馬書 9:5"> 那從上面來的，是在萬有之上；那從地而出的，屬於地，而且所說的也屬於地。那從天上來的，是在萬有之上，</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:11; 約翰福音 15:15; 約翰福音 1:11"> 他見證他所看到的、他所聽到的，可是沒有人接受他的見證。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 6:17; 以弗所書 1:13; 提多書 1:1–2"> 那接受他見證的人，就印證了神是真實的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 10:38; 馬太福音 12:18; 約翰福音 15:26"> 神所差派的那一位，就說神的話語，因為神不靠著量度賜下聖靈。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 28:18; 約翰福音 5:22; 約翰福音 5:20"> 父愛子，把一切都交在他手裡了。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 5:24; 約翰福音 1:12; 帖撒羅尼迦前書 5:9"> 信從子的人，就有永恆的生命；但是不肯信從子的人，見不到生命，而且神的震怒也停留在他身上。</span>
</div>
</div>

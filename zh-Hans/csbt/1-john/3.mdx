<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 1:12; 加拉太書 3:26; 哥林多後書 6:18"> 你們看，父所賜給我們的是何等的愛，為要使我們被稱為「神的兒女」，而我們就是神的兒女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「而我們就是神的兒女」。">a</a></sup>。世人之所以不認識我們，是因為不認識父<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="父——原文直譯「他」。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 3:21; 歌羅西書 3:4; 哥林多前書 13:12"> 各位蒙愛的人哪，現在我們是神的兒女，將來會怎樣，尚未顯明。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「但」。">c</a></sup>我們已經知道的是：基督<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="基督——原文直譯「他」。">d</a></sup>顯現的時候，我們就會像他，因為我們將看見他的本相。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 7:1; 約翰一書 2:6; 彼得後書 3:14"> 每一個對基督<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="基督——原文直譯「他」。">e</a></sup>懷有這盼望的，都會使自己純潔，正如基督<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="基督——原文直譯「那一位」。">f</a></sup>是純潔的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰一書 5:17; 羅馬書 3:20; 羅馬書 4:15"> 凡是犯罪的，也是行惡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="惡——原文直譯「不法」。">g</a></sup>的；罪就是惡<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="惡——原文直譯「不法」。">h</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:21; 希伯來書 9:28; 彼得前書 3:18"> 你們知道，基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——原文直譯「那一位」。">i</a></sup>曾經顯現，是為了除去罪孽<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="罪孽——有古抄本作「我們的罪孽」。">j</a></sup>；在他裡面並沒有罪。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰三書 1:11; 約翰一書 2:4; 約翰一書 3:9"> 凡是住在基督<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="基督——原文直譯「他」。">k</a></sup>裡面的，就不繼續犯罪；凡是繼續犯罪的，就未曾看到他，也未曾認識他。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 2:29; 彼得前書 1:15–16; 羅馬書 2:13"> 孩子們哪，不要讓任何人迷惑你們。行義的人是公義的，正如基督<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="基督——原文直譯「那一位」。">l</a></sup>是公義的。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 2:14; 約翰福音 8:44; 歌羅西書 2:15"> 繼續犯罪的人屬於魔鬼，因為魔鬼從起初就一直犯罪。為此，神的兒子顯現了，是為了廢除魔鬼的作為。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 5:18; 彼得前書 1:23; 約翰福音 1:13"> 凡是由神所生的，不繼續犯罪，因為神的種子住在他裡面；他也不能繼續犯罪，因為他是由神所生的。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 4:8; 約翰三書 1:11; 路加福音 6:35"> 從這一點，誰是神的兒女，誰是魔鬼的兒女就清清楚楚了。 愛的命令<br />凡是不行公義的，就不屬於神；不愛自己弟兄的，也不屬於神。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 15:12; 約翰二書 1:5; 約翰一書 4:7"> 因為你們從起初所聽見的信息是這樣的：我們要彼此相愛。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:4; 創世記 4:4–15; 箴言 29:27"> 不要像該隱，他屬於那惡者，殺了自己的弟弟<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="弟弟——原文直譯「兄弟」。">m</a></sup>。他為什麼殺弟弟呢？因為他自己的行為是惡的，而他弟弟的行為是義的。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:18–19; 約翰福音 17:14; 路加福音 21:17"> 弟兄們，如果世界恨你們，不要感到驚奇。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 13:35; 約翰一書 5:2; 約翰一書 4:20–21"> 我們知道，因為我們愛弟兄，我們就已經出死入生了；那不愛弟兄的，就住在死亡中。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:21–22; 箴言 26:24–26; 啟示錄 21:8"> 凡是恨自己弟兄的，就是殺人的，而你們知道：凡是殺人的，就沒有永恆的生命住在他裡面。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰一書 4:9–11; 以弗所書 5:2; 約翰福音 13:34"> 我們從這一點就知道了愛：基督<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="基督——原文直譯「那一位」。">n</a></sup>為我們捨棄了自己的生命，我們也應該為弟兄捨棄生命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 13:16; 以賽亞書 58:7–10; 申命記 15:7–11"> 但如果有人擁有世界的財產，看見自己的弟兄有需要，卻封閉情感，那麼，屬神的愛怎麼能住在他裡面呢？</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各書 2:15–16; 羅馬書 12:9; 彼得前書 1:22"> 孩子們哪，讓我們不在語言或口頭上相愛，而在行為和真理中相愛，</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 10:22; 約翰一書 3:21; 希伯來書 6:10–11"> 從這一點我們就會知道我們屬於真理。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 139:1–4; 耶利米書 17:10; 希伯來書 4:13"> 就算我們的心責備自己，我們在神面前也可以安心，因為神比我們的心更大，並且他知道一切。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰一書 2:28; 希伯來書 4:16; 哥林多後書 1:12"> 各位蒙愛的人哪，如果我們的心不責備我們，我們在神面前就可以坦然無懼，</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 15:7; 約翰福音 9:31; 約翰一書 5:14"> 這樣，凡是我們所求的，就會從他得著；因為我們遵守他的命令，行他看為可喜悅的事。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 6:29; 約翰福音 13:34; 彼得前書 1:22"> 而神的命令是這樣的：我們要信他兒子耶穌基督的名，並且照著他所賜給我們的命令彼此相愛。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 3:16; 約翰一書 4:15–16; 約翰一書 4:12–13"> 遵守神<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="神——原文直譯「他」。">o</a></sup>命令的，就住在神<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="神——原文直譯「他」。">p</a></sup>裡面，神<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="神——原文直譯「他」。">q</a></sup>也住在他裡面；而且我們從這一點就知道神<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="神——原文直譯「他」。">r</a></sup>住在我們裡面，是藉著他所賜給我們的聖靈。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 2:5; 羅馬書 8:34; 約翰福音 14:6"> 我的孩子們哪，我把這些事寫給你們，免得你們犯罪。但如果有人犯了罪，在父那裡我們有一位辯護者，就是那義者耶穌基督。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 4:14; 彼得前書 3:18; 約翰一書 4:10"> 他自己為我們的罪孽做了平息祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="平息祭——或譯作「挽回祭」。">a</a></sup>，不僅是為我們的罪，也是為全世界的罪。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約翰福音 14:15; 約翰福音 15:10; 路加福音 6:46"> 如果我們遵守基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督——原文直譯「他」。">b</a></sup>的命令，從這一點我們就知道我們已經認識他。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 1:6; 提多書 1:16; 雅各書 2:14–16"> 那說「我已經認識他」，卻不遵守他命令的，就是說謊者，真理也不在這個人裡面；</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 14:23; 約翰福音 14:21; 約翰一書 4:12–13"> 但如果有人遵守他的話語，屬神的愛就確實在這個人裡面得以完全了；從這一點我們就知道我們是在他裡面。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 2:21; 約翰福音 13:15; 哥林多前書 11:1"> 那說自己住在他裡面的，自己也應該按基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——原文直譯「他」。">c</a></sup>所行的照樣去行。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 3:11; 利未記 19:18; 馬可福音 12:29–34"> 各位蒙愛的人哪<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="各位蒙愛的人哪——有古抄本作「弟兄們」。">d</a></sup>，我寫給你們的不是一條新命令，而是你們從起初就有的舊命令；這條舊命令就是你們<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「從起初」。">e</a></sup>所聽過的那話<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="話——或譯作「道」。">f</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:8; 羅馬書 13:12; 約翰福音 13:34"> 另一方面，我寫給你們的也是一條新命令；這命令在他、在你們，都是真實的，因為黑暗正在消逝，真光已經在照耀。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰一書 4:20; 約翰一書 2:11; 約翰一書 3:13–17"> 那說自己在光裡卻恨自己弟兄的，至今還在黑暗裡；</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 3:14; 羅馬書 9:32–33; 羅馬書 14:13"> 那愛自己弟兄的，就住在光裡，而且在他裡面<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在他裡面——或譯作「在光裡面」。">g</a></sup>沒有什麼絆腳的事；</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 12:35; 提多書 3:3; 約翰一書 1:6"> 但那恨自己弟兄的，就是在黑暗裡，並且在黑暗裡行走，也不知道自己往哪裡去，因為黑暗使他的眼睛瞎了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:43; 使徒行傳 13:38; 以弗所書 1:7"> <span className="pl pl-1">孩子們哪，我寫信給你們，</span><br /><span className="pl pl-1">因為你們的罪孽藉著基督</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="基督——原文直譯「他」。">h</a></sup><br /><span className="pl pl-1">的名已經被赦免了；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:7; 約翰一書 2:14; 路加福音 10:22"> <span className="pl pl-1">父老們哪，我寫信給你們，</span><br /><span className="pl pl-1">因為你們已經認識了從太初就有的那一位；</span><br /><span className="pl pl-1">年輕人哪，我寫信給你們，</span><br /><span className="pl pl-1">因為你們已經勝過了那惡者。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 119:11; 約翰一書 2:13; 歌羅西書 3:16"> <span className="pl pl-1">孩子們哪，我寫了信給你們，</span><br /><span className="pl pl-1">因為你們已經認識了父；</span><br /><span className="pl pl-1">父老們哪，我寫了信給你們，</span><br /><span className="pl pl-1">因為你們已經認識了從太初就有的那一位；</span><br /><span className="pl pl-1">年輕人哪，我寫了信給你們，</span><br /><span className="pl pl-1">因為你們是強壯的，</span><br /><span className="pl pl-1">神的話語</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的話語——或譯作「神的道」。">i</a></sup><br /><span className="pl pl-1">住在你們裡面，</span><br /><span className="pl pl-1">你們也已經勝過了那惡者。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅各書 4:4; 羅馬書 12:2; 馬太福音 6:24"> 你們不要愛世界，也不要愛世界上的事物。如果有人愛世界，父的愛<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="父的愛——或譯作「對父的愛」或「屬父的愛」。">j</a></sup>就不在他裡面了。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 13:14; 加拉太書 5:17; 詩篇 119:36–37"> 原來世界上一切肉體的欲望、眼目的欲望、今生的驕傲，都不是出於父，而是出於世界的。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 24:35; 羅馬書 12:2; 哥林多前書 7:31"> 世界和屬世的欲望正在消逝；但那遵行神旨意的，卻永遠長存。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 4:3; 約翰二書 1:7; 馬太福音 24:24"> 孩子們哪，現在是末後的時期了。正如你們聽說過敵基督的要來，現在確實已經有許多敵基督的出現了；故此我們知道，現在是末後的時期了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 20:30; 哥林多前書 11:19; 路加福音 8:13"> 他們從我們中間出去，但他們本來就不屬於我們，因為他們如果屬於我們，就會留下與我們在一起；不過這樣就顯明出，他們都不屬於我們。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 14:26; 約翰一書 2:27; 哥林多後書 1:21–22"> 至於你們，你們從那位聖者領受了恩膏，並且你們大家都已經知道了這事<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="大家都已經知道了這事——有古抄本作「已經知道了這一切事」。">k</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 1:12; 猶大書 1:5; 箴言 1:5"> 我寫了信給你們，不是因為你們不認識真理，而是因為你們已經認識了真理，又因為一切虛假都不是出於真理。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰二書 1:7; 約翰一書 4:3; 約翰一書 2:18"> 誰是說謊者呢？難道不是那否認耶穌是基督的嗎？那否認父和子的，這個人就是敵基督的。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 4:15; 約翰福音 8:19; 約翰福音 5:23"> 所有否認子的，就沒有父；那承認子的，連父也有了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 14:23; 約翰福音 15:9–10; 約翰一書 4:13"> 你們應當使那從起初所聽到的，住在你們裡面。如果那從起初所聽到的住在你們裡面，你們就會住在子裡面，也住在父裡面。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 10:28; 提多書 3:7; 猶大書 1:21"> 這就是那應許，是他所應許我們的，就是永恆的生命。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得後書 2:1–3; 約翰二書 1:7; 使徒行傳 20:29–30"> 我寫給你們的這些，是關於迷惑你們之人的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:26; 約翰一書 2:20–21; 哥林多前書 2:13"> 至於你們，你們從那一位所領受的恩膏住在你們裡面，這樣你們就不需要人來教導你們。其實，就像他的恩膏在一切事上所教導你們的——是真實的，不是虛假的——又像他曾經所教導的，你們要住在他裡面。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰一書 4:17; 馬可福音 8:38; 約翰一書 3:2"> 如今，孩子們哪，你們當住在他裡面，好使他顯現的時候，我們可以坦然無懼，他來臨的時候，我們可以在他面前不至於蒙羞。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 3:3–5; 約翰一書 3:7; 約翰一書 5:1"> 你們如果知道他是公義的，也就知道所有行義的人，都是由他所生的。</span>
</div>
</div>

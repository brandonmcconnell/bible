<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="創世記 9:7; 創世記 1:28; 創世記 8:17"> 神祝福挪亞和他的兒子們，對他們說：「你們要繁衍增多，充滿大地。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 8:4–8; 創世記 1:28; 雅各書 3:7"> 地上的一切走獸、天空的一切飛鳥、地上的一切爬蟲、海裡的一切魚類，都會畏懼你們、害怕你們；這一切都交在你們手中了。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 14:14; 歌羅西書 2:21–22; 哥林多前書 10:31"> 凡是有生命的動物，都可以作你們的食物；我把這一切賜給了你們，就像我把綠色植物賜給你們一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:23; 申命記 15:23; 申命記 12:16"> 只是帶著生命之血的肉，你們不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 21:28–29; 出埃及記 21:12; 創世記 4:9–10"> 至於你們的生命之血，我必為你們追討：我要向走獸追討；我也要向人，甚至向各人的兄弟追討人命。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 24:17; 馬太福音 26:52; 啟示錄 13:10"> <span className="pl pl-1">那殺人流血的，</span><br /><span className="pl pl-1">他必被殺流血，</span><br /><span className="pl pl-1">因為神是按照自己的形象造人的。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 1:28; 創世記 9:1; 創世記 9:19"> 你們要繁衍增多，充滿大地，在其上增多。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 接著神告訴挪亞以及與他一起的兒子們說：</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 6:18; 以賽亞書 54:9–10; 羅馬書 1:3"> 「看哪，我要與你們以及你們的後裔確立我的約；</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 8:1; 創世記 9:15–16; 詩篇 36:5–6"> 並與所有和你們在一起的活物，包括飛鳥、牲畜和地上的一切走獸，就是與所有從方舟裡出來的地上活物立約。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 54:9; 創世記 8:21–22; 創世記 7:21–23"> 我要與你們確立我的約：一切有血肉的，都不再被洪水滅絕；洪水不再毀滅全地。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 17:11; 馬太福音 26:26–28; 出埃及記 12:13"> 神又說：「以下是我與你們以及同你們在一起的各樣活物所立之約的標記——直到未來所有的世代：</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 1:28; 啟示錄 4:3; 啟示錄 10:1"> 我把我的彩虹放在雲中，它就是我與大地立約的標記。</span>
<span className="v" id="v14" data-v="14"> 當我聚起雲遮蓋大地時，彩虹會出現在雲中，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 7:9; 以西結書 16:60; 以賽亞書 54:8–10"> 我就會記念我與你們以及一切有血肉的活物所立的約，水就不再成為洪水，來毀滅一切有血肉的。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 54:8–10; 耶利米書 32:40; 撒母耳記下 23:5"> 當彩虹出現在雲中，我就會看到，就會記念我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——原文直譯「神」。">a</a></sup>與地上一切有血肉的活物所立的永遠之約。」</span>
<span className="v" id="v17" data-v="17"> 神對挪亞說：「這就是我與地上一切有血肉的所立之約的標記。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 10:1; 創世記 10:6; 創世記 9:25–27"> 挪亞的兒子，從方舟出來的，就是閃、含、雅弗；含是迦南的父親。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 1:4–28; 創世記 8:17; 創世記 5:32"> 這三人是挪亞的兒子，全地的人都是從他們分散出來的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 20:6; 箴言 10:11; 以賽亞書 28:24–26"> 挪亞開始作農夫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="農夫——原文直譯「土地的人」。">b</a></sup>，種植了一個葡萄園。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; 哈巴谷書 2:15–16; 箴言 23:31–32"> 他喝了葡萄酒，就醉了，在自己的帳篷中赤身露體。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 加拉太書 6:1; 馬太福音 18:15"> 迦南的父親含，看見自己父親的下體，就去告訴他在外面的兩個兄弟。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:1; 出埃及記 20:12; 提摩太前書 5:17"> 於是閃和雅弗拿了一件外衣，搭在他們兩人的肩膀上，倒退著進去遮蓋他們父親的下體；他們背著臉，就沒有看見他們父親的下體。</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24"> 挪亞酒醒以後，知道了小兒子向他所做的事，</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 9:23; 申命記 27:16; 士師記 1:28–30"> 就說：<br /><span className="pl pl-1">「迦南是受詛咒的！</span><br /><span className="pl pl-1">他必作自己兄弟們奴僕的奴僕。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="詩篇 144:15; 創世記 12:1–3; 路加福音 3:23–36"> 又說：<br /><span className="pl pl-1">「耶和華——閃的神是當受頌讚的！</span><br /><span className="pl pl-1">願迦南作閃的奴僕。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 11:12; 羅馬書 15:12; 希伯來書 11:9–10"> <span className="pl pl-1">願神使雅弗擴張，</span><br /><span className="pl pl-1">使他住在閃的帳篷中；</span><br /><span className="pl pl-1">願迦南作雅弗的奴僕。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 洪水之後，挪亞又活了三百五十年。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 5:27; 詩篇 90:10; 創世記 5:32"> 這樣挪亞一生活了九百五十年，然後他死了。</span>
</div>
</div>

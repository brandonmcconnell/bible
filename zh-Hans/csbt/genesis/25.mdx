<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 1:32–33; 創世記 23:1–2; 創世記 28:1"> 亞伯拉罕又娶了一個妻子，名叫基土拉。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 1:32–33; 民數記 25:17–18; 約伯記 2:11"> 基土拉為他生了新蘭、約珊、米但、米甸、伊施巴和書亞。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 25:13; 耶利米書 49:8; 以西結書 27:20"> 約珊生了示巴和底但。底但的子孫就是亞書利人、利杜史人和利烏米人。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 60:6"> 米甸的兒子是以法、以弗、哈諾、亞比大和以勒大。以上全都是基土拉的子孫。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:36; 希伯來書 1:2; 加拉太書 3:29"> 亞伯拉罕把自己所擁有的一切都給了以撒。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 21:14; 士師記 6:3; 使徒行傳 14:17"> 至於亞伯拉罕眾妾的兒子，亞伯拉罕也給了他們禮物，在自己還活著的時候，就打發他們離開他的兒子以撒往東，到東方之地去。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 12:4"> 亞伯拉罕一生所活的年日有一百七十五年。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:28–29; 創世記 15:15; 歷代志上 29:28"> 亞伯拉罕盡享天年，壽高年邁，氣絕而死，歸到他的先人那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 50:13; 創世記 35:29; 創世記 49:29–30"> 他的兒子以撒和以實瑪利把他葬在幔利對面、赫提人瑣哈爾的兒子以弗崙田中的麥比拉洞穴裡；</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 23:16; 創世記 49:31"> 那塊地是亞伯拉罕從赫提的子孫那裡買來的。亞伯拉罕和他的妻子撒拉都葬在那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 創世記 16:14; 創世記 24:62"> 亞伯拉罕死了以後，神祝福他的兒子以撒；以撒在比珥-拉海-羅伊附近住下。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:6; 創世記 17:20; 創世記 21:13"> 以下是亞伯拉罕的兒子以實瑪利的家系記事：以實瑪利是撒拉的婢女埃及人夏甲為亞伯拉罕所生的。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 1:29–31; 以賽亞書 60:7; 雅歌 1:5"> 以實瑪利的兒子，按著他們的家系，名字如下：以實瑪利的長子是尼拜約，然後是基達、亞德別、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 21:11; 以賽亞書 21:16"> 米施瑪、度瑪、瑪撒、</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 5:19; 約伯記 2:11"> 哈達、提瑪、伊突、拿非施和基底瑪。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:20; 創世記 17:23"> 這些是以實瑪利的兒子，他們的名字就成了自己村莊和營寨的名字，他們也成了十二個部族的族長。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:15; 創世記 25:7–8"> 以實瑪利一生的年歲是一百三十七歲。他氣絕而死，歸到他的先人那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 16:12; 創世記 20:1; 列王紀下 23:29"> 他子孫的居住之地從哈腓拉到書珥，書珥在埃及對面、通往亞述方向的路上；以實瑪利與他所有兄弟對立而居。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 1:2; 路加福音 3:34; 使徒行傳 7:8"> 以下是亞伯拉罕的兒子以撒的家系記事：亞伯拉罕生以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:29; 創世記 24:67; 創世記 22:23"> 以撒娶莉百加為妻的時候正四十歲；莉百加是帕旦-亞蘭地的亞蘭人彼土利的女兒，是亞蘭人拉班的妹妹。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以賽亞書 58:9; 以斯拉記 8:23"> 以撒因妻子不能生育就為她向耶和華祈求。耶和華應允了他的祈求，他的妻子莉百加就懷了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 9:9; 撒母耳記上 28:6; 撒母耳記上 30:8"> 兩個胎兒在她裡面彼此擠壓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="擠壓——或譯作「相爭」。">a</a></sup>，她就說：「這樣的話，為什麼這事發生在我身上呢？」於是她去求問耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 9:10–13; 創世記 27:40; 創世記 27:29"> 耶和華對她說：<br /><span className="pl pl-1">「兩國在你的腹中，</span><br /><span className="pl pl-1">兩族將從你裡面分出來；</span><br /><span className="pl pl-1">一族要比另一族強，</span><br /><span className="pl pl-1">將來大的要服事小的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 到了生產的日子，看哪，莉百加腹中果然是雙胞胎！</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:11; 創世記 27:16; 創世記 27:23"> 第一個出來的身體通紅，遍體是毛，如同毛皮衣；於是給他起名為以掃。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:36; 何西阿書 12:3; 創世記 38:28–30"> 隨後，弟弟也出來了，他的一隻手抓住以掃的腳跟；於是給他起名為雅各。莉百加生他們的時候，以撒正六十歲。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯來書 11:9; 創世記 21:20; 創世記 10:9"> 兩個孩子漸漸長大，以掃成為一個打獵能手，常在田野；而雅各是一個安靜的人，常在帳篷裡。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 27:19; 創世記 27:31; 創世記 27:4"> 以撒愛以掃，因為愛吃野味，而莉百加卻愛雅各。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以賽亞書 40:30–31; 撒母耳記上 14:28"> 有一天，雅各熬好了湯；這時以掃從田野回來，筋疲力盡。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 36:1; 出埃及記 15:15; 創世記 36:9"> 以掃就對雅各說：「請你讓我喝一些紅湯，就這紅湯；我已筋疲力盡了！」因此他的名字又稱為以東。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 雅各就說：「你現在就把長子的名份賣給我！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="瑪拉基書 3:14; 約伯記 21:15; 約伯記 22:17"> 以掃說：「看哪，我都快死了，這長子的名份對我還有什麼用呢？」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="希伯來書 12:16; 創世記 27:36; 希伯來書 6:16"> 雅各說：「你現在就向我起誓！」以掃就向他起誓，把自己長子的名份賣給了雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比書 3:18–19; 希伯來書 12:16–17; 哥林多前書 15:32"> 於是雅各把餅和豆湯給了以掃；以掃吃喝完，就起來走了。以掃就這樣輕視了長子的名份。</span>
</div>
</div>

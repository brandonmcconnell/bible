<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="50" data-verses="26">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:4; 申命記 6:7–8; 使徒行傳 8:2"> 約瑟伏在他父親的臉上哀哭、親吻。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:26; 歷代志下 16:14; 約翰福音 19:39–40"> 約瑟吩咐僕人中那些作醫生的，用香料包殮他的父親。醫生就用香料包殮了以色列。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 20:29; 申命記 34:8; 創世記 50:10"> 這需要四十天，因為這是用香料包殮屍體所需要的時間。埃及人為以色列哀哭了七十天。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 18:3; 以斯帖記 4:2"> 為他哀哭的日子過了，約瑟對法老家中的人說：「如果我在你們眼前蒙恩，請你們上報法老說：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 16:14; 以賽亞書 22:16; 馬太福音 27:60"> 『我父親曾經要我起誓，說：「看哪，我就要死了；你要把我葬在迦南地，葬在我為自己開鑿的墳墓裡。」現在求你讓我上去，安葬我的父親，然後我就回來。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 48:21"> 法老說：「你上去吧，照著你父親讓你起的誓，安葬你的父親。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 14:16"> 於是約瑟上去安葬他的父親。與他一同上去的，包括法老所有的臣僕，法老家中的長老，埃及地所有的長老，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 32:24–27; 出埃及記 10:26; 出埃及記 10:8–9"> 還有約瑟的全家，他的兄弟們，以及他父親的家屬；只有他們的孩童和羊群、牛群留在歌珊地；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 14:28; 列王紀下 18:24; 雅歌 1:9"> 與他一同上去的，還有車輛和馬兵。那是非常龐大的一隊。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 2:13; 使徒行傳 8:2; 撒母耳記下 1:17"> 他們來到約旦河對岸的亞達禾場，就在那裡大大哀哭，哭得極其沉痛。約瑟為他父親舉哀七天。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:15–19; 創世記 24:6; 申命記 11:30"> 那地的居民迦南人看見亞達禾場上的哀悼，就說：「這是埃及人的一場沉痛的哀悼。」因此約旦河對岸那地方名叫亞伯-麥西。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 7:16; 創世記 49:29–32; 以弗所書 6:1"> 這樣，雅各的兒子們就照著父親吩咐他們的為他去做：</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 49:29–31; 創世記 23:16–18; 使徒行傳 7:16"> 他們把他運到迦南地，葬在幔利對面的麥比拉田間的洞穴裡。那田是亞伯拉罕向赫提人以弗崙買來的，作為他擁有的墳地。</span>
<span className="v" id="v14" data-v="14"> 約瑟安葬了他的父親之後，就和他的兄弟們以及所有與他一同上來安葬他父親的人，回埃及去了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 創世記 42:21–22; 詩篇 53:5"> 約瑟的哥哥們見父親死了，就說：「也許約瑟仍然記恨我們，會因著我們從前對他所做的一切惡，十足地報復我們。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 他們就打發人去約瑟那裡，說：「在你父親死之前，他曾吩咐說：</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所書 4:32; 馬太福音 6:14–15; 創世記 45:8"> 『你們要對約瑟這樣說：從前你哥哥們惡待你，求你饒恕他們的過犯和罪惡。』現在求你饒恕你父親之神的僕人們的過犯。」他們對約瑟說這話時，約瑟就哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:7–11; 創世記 42:6; 創世記 45:3"> 隨後他的哥哥們也來，俯伏在他面前，說：「看哪，我們是你的奴僕！」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="羅馬書 12:19; 創世記 45:5; 創世記 30:2"> 約瑟對他們說：「你們不要害怕，難道我能代替神嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 8:28; 詩篇 119:71; 創世記 45:5–8"> 從前你們有意要害我，但神在其中有他的美意，為要成就今日這樣的結果，使許多人得以存活。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:12; 彼得前書 3:9; 創世記 45:10–11"> 現在，你們不要害怕，我必供應你們和你們的孩童。」於是約瑟安慰他們，對他們說寬心的話。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 約瑟和他的父家都住在埃及。約瑟活了一百一十歲。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 32:39; 創世記 30:3; 約伯記 42:16"> 約瑟得見以法蓮的第三代子孫。瑪拿西的兒子瑪吉的眾子，生下來就歸於約瑟膝下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="生下來就歸於約瑟膝下——原文直譯「也生在約瑟的膝上」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 3:16–17; 創世記 35:12; 創世記 26:3"> 約瑟對他的兄弟們說：「我就要死了，但神必定眷顧你們，也必領你們從這地上去，進入他起誓給亞伯拉罕、以撒、雅各的那地。」</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 13:19; 約書亞記 24:32; 創世記 47:29–31"> 約瑟就讓以色列的子孫起誓，對他們說：「神必定眷顧你們，而你們要把我的骸骨從這裡帶上去。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 50:2–3; 創世記 47:9; 約書亞記 24:29"> 約瑟死了，享年一百一十歲。人們用香料把他包殮了，安放在棺材裡，安置在埃及。</span>
</div>
</div>

</div>

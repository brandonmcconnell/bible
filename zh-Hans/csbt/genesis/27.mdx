<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 3:2; 創世記 48:10; 創世記 25:23–25"> 以撒年老的時候，眼睛衰弱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="衰弱——或譯作「暗淡」。">a</a></sup>，以致不能看見，就把他的大兒子以掃叫來，說：「我兒啊！」<br />以掃說：「我在這裡！」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="雅各書 4:14; 傳道書 9:10; 箴言 27:1"> 他說：「看哪，我已經老了，不知道哪一天會死。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:27–28; 創世記 10:9; 哥林多前書 6:12"> 現在拿上你的獵具，箭囊和弓，到田野去為我打些野味。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:20; 創世記 48:9; 創世記 49:28"> 你要照我所喜愛的，為我做成美食，拿來給我吃，好讓我在死之前祝福你。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 以撒對他兒子以掃說話時，莉百加也在聽。在以掃去田野獵取野味的時候，</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 25:28"> 莉百加對她兒子雅各說：「看哪，我聽到你父親對你哥哥以掃說：</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 6:26; 撒母耳記上 24:19; 申命記 33:1"> 『你把野味帶回來，做成美食給我吃，好讓我在死之前，在耶和華面前祝福你。』</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:1; 創世記 27:13; 使徒行傳 5:29"> 我兒啊，你現在當按著我吩咐你的，聽我的話——</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:15; 撒母耳記上 16:20"> 到羊群中去，從那裡給我牽兩隻上好的小山羊來，讓我照你父親所喜愛的，為他做成美食；</span>
<span className="v" id="v10" data-v="10"> 然後你拿去給你父親吃，好讓他在死之前祝福你。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 25:25"> 雅各對他母親莉百加說：「看哪，我哥哥以掃多毛，而我皮膚光滑。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:18; 創世記 25:27; 瑪拉基書 1:14"> 要是我父親摸我，那我在他眼中看起來就像騙子，我也就給自己帶來詛咒，而不是祝福了。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 27:25; 撒母耳記上 25:24; 撒母耳記下 14:9"> 但他母親對他說：「我兒啊，願你的詛咒歸於我！你只管聽我的話；去吧，把小山羊牽給我。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 27:9; 箴言 23:2–3; 創世記 25:28"> 他就去，把小山羊牽來，帶給他母親。他母親就照他父親所喜愛的做成美食。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 27:27; 路加福音 20:46; 路加福音 15:22"> 莉百加拿了大兒子以掃在家裡最好的衣服，給小兒子雅各穿上；</span>
<span className="v" id="v16" data-v="16"> 又用小山羊的皮，包在雅各手上和他脖子上的光滑處；</span>
<span className="v" id="v17" data-v="17"> 然後把自己做好的美食和餅，交在她兒子雅各的手中。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 雅各來到他父親那裡，說：「我父啊！」<br />以撒說：「我在這裡！我兒啊，你是誰呢？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 28:15; 馬太福音 26:70–74; 撒迦利亞書 13:3–4"> 雅各對他父親說：「我是你的長子以掃，我已照著你吩咐我的去做了。請坐起來，吃我的野味，好為我祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:7; 約伯記 13:7; 創世記 24:12"> 以撒對他兒子說：「我兒啊，你怎麼這樣快就打到了呢？」雅各回答：「因為耶和華你的神成全了我。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 4:8; 以賽亞書 57:19; 創世記 27:12"> 以撒對雅各說：「我兒啊，靠近我，讓我摸摸你，你真是我兒子以掃嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 雅各就靠近他父親以撒。以撒摸著他，說：「聲音是雅各的聲音，手卻是以掃的手。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 27:16; 希伯來書 11:20; 羅馬書 9:11–12"> 以撒沒有認出他來，因為他的手像他哥哥以掃的手那樣多毛。於是以撒就要祝福他，</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:9; 以弗所書 4:25; 箴言 12:22"> 又問：「你真是我兒子以掃嗎？」<br />他說：「我是。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 27:4"> 以撒說：「把野味拿近一點，讓我吃我兒子的野味，好為你祝福。」雅各就拿給他，他就吃了；又遞酒給他，他也喝了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26"> 他父親以撒對他說：「我兒啊，靠近一點親吻我。」</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 6:7; 詩篇 65:10; 希伯來書 11:20"> 雅各就靠近親吻了父親；以撒聞到雅各衣服的氣味，就祝福他，說：<br /><span className="pl pl-1">「啊，我兒子的氣味就像耶和華所祝福的田野的氣味！</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:28; 申命記 33:13; 詩篇 133:3"> <span className="pl pl-1">願神賜給你天上的甘露，</span><br /><span className="pl pl-1">地上的豐饒，</span><br /><span className="pl pl-1">以及豐盛的五穀和新酒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="創世記 12:3; 民數記 24:9; 以賽亞書 49:23"> <span className="pl pl-1">願萬民服事你，</span><br /><span className="pl pl-1">萬族向你下拜；</span><br /><span className="pl pl-1">願你成為你兄弟們的主人，</span><br /><span className="pl pl-1">你母親的兒子們向你下拜。</span><br /><span className="pl pl-1">詛咒你的人，願他受詛咒；</span><br /><span className="pl pl-1">祝福你的人，願他蒙祝福。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 以撒祝福完雅各，雅各剛從父親以撒面前離去，他哥哥以掃就打獵回來了。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 27:4"> 以掃也做了美食，拿給他父親，對父親說：「我父啊，請起來，吃你兒子的野味，好為我祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 27:18"> 他父親以撒對他說：「你是誰呢？」<br />他說：「我是你的兒子，你的長子以掃。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 28:3–4; 羅馬書 11:29; 以弗所書 1:3"> 以撒就大大戰兢，說：「是誰打了野味，剛剛拿給我呢？在你來之前，我已經全吃了；我也祝福了那人，他將來必蒙祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="希伯來書 12:17; 箴言 1:31; 撒母耳記上 30:4"> 以掃聽了他父親的話，就極其痛苦地號啕大哭，對父親說：「我父啊，祝福我，也祝福我吧！」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦前書 4:6; 約伯記 13:7; 瑪拉基書 2:10"> 以撒說：「你弟弟心懷詭計地前來，已經奪取了你的祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 25:26; 約翰福音 1:47; 創世記 32:28"> 以掃說：「他名叫雅各不是名副其實嗎？他兩次都欺騙了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="欺騙了——或譯作「抓取了」。">b</a></sup>我：他先奪取了我長子的名份，看哪，他現在又奪取了我的祝福！」以掃又說：「難道你沒有留下什麼祝福給我嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 8:14; 創世記 27:28–29; 創世記 25:23"> 以撒就回答以掃，說：「看哪，我已經立他為你的主人，又把他所有的兄弟給他為僕人，並把五穀和新酒供給了他。我兒啊，現在我還能為你做什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="希伯來書 12:17; 創世記 27:34; 以賽亞書 65:14"> 以掃對他父親說：「我父啊，難道你只有這一個祝福嗎？我父啊，求你也祝福我！」以掃就放聲大哭。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="創世記 27:28; 希伯來書 11:20; 約書亞記 24:4"> 他父親以撒回答他，說：<br /><span className="pl pl-1">「看哪，你居住之處必遠離地上的豐饒，</span><br /><span className="pl pl-1">遠離天上的甘露。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 8:20–22; 創世記 25:23; 歷代志下 25:11–12"> <span className="pl pl-1">你必靠著你的刀劍生存，</span><br /><span className="pl pl-1">也必服事你的弟弟；</span><br /><span className="pl pl-1">到了你奮起反抗的時候，</span><br /><span className="pl pl-1">你必從頸項上掙脫他的軛。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰一書 3:12–15; 創世記 37:4; 創世記 50:3–4"> 以掃因父親祝福了雅各，就記恨雅各。以掃對自己說：「為父親舉哀的日子臨近了，之後我就要殺死弟弟雅各。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 37:18–20; 撒母耳記上 30:5; 創世記 42:21–22"> 當大兒子以掃的話傳到莉百加那裡，她就派人把小兒子雅各叫來，說：「看哪，你哥哥以掃想要殺你洩恨！</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 27:8; 創世記 11:31; 創世記 27:13"> 我兒啊，現在你當聽我的話；起來！逃往哈蘭，到我哥哥拉班那裡去，</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:38; 創世記 31:41"> 與他一同住些日子，直到你哥哥的怒火消退了——</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 創世記 4:8–16; 創世記 9:5–6"> 等到你哥哥對你的怒氣轉消了，忘記你對他所做的事，那時我就會派人把你從那裡接回來。我為什麼在一天之內要喪失你們兩個呢？」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="創世記 24:3; 創世記 26:34–35; 創世記 28:8"> 莉百加對以撒說：「因這些赫提的女子，我連活著都厭煩了。如果雅各也從這地的女子中，娶了像這樣的赫提女子為妻，我活著還有什麼意義呢？」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 24:37–39; 彼得後書 2:5–9; 創世記 6:9"> 耶和華對挪亞說：「你和你的全家都要進入方舟，因為在這世代中，我看到唯有你在我面前是義人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 8:20; 利未記 10:10; 利未記 11:1–47"> 你要從所有潔淨的走獸中各帶七公七母，從不潔淨的走獸中各帶一公一母，</span>
<span className="v" id="v3" data-v="3"> 從天空的飛鳥中各帶七公七母，好使牠們的種類在全地上存留；</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 6:13; 創世記 7:12; 創世記 7:17"> 因為再過七天，我就要降雨在地上四十晝夜，把我所造的一切活物都從地面上抹掉。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 6:22; 路加福音 8:21; 出埃及記 39:32"> 挪亞就照著耶和華吩咐他的一切做了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 5:32; 創世記 8:13"> 大洪水臨到地上的時候，挪亞正六百歲。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 創世記 6:18; 馬太福音 24:38"> 挪亞與他的兒子們、他的妻子和兒媳們一起進入方舟，躲避大洪水。</span>
<span className="v" id="v8" data-v="8"> 潔淨的走獸和不潔淨的走獸，飛鳥和地上的一切爬蟲，</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 7:16; 創世記 2:19; 耶利米書 8:7"> 都公母成雙，一對一對來到挪亞那裡，也進入方舟，正如神所吩咐挪亞的話。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 6:17; 創世記 7:4; 路加福音 17:27"> 那七天一過，大洪水就臨到地上了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 8:2; 瑪拉基書 3:10; 箴言 8:28–29"> 挪亞六百歲那年的二月十七日，就在那一天，巨大深淵的泉源都裂開了，天上的窗戶也敞開了——</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:4; 馬太福音 4:2; 創世記 7:17"> 大雨降在地上四十晝夜——</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 6:18; 創世記 7:1; 創世記 6:10"> 就在那一天，挪亞與他的兒子閃、含、雅弗，以及他的妻子和三個兒媳一起進入方舟；</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:8–9; 創世記 7:2–3"> 與他們一起的，還有一切走獸，各從其類；一切牲畜，各從其類；地上活動的一切爬蟲，各從其類；一切飛禽，就是一切有翅膀的鳥，各從其類。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:19–20; 以賽亞書 11:6"> 這樣，一切有生命氣息的，就是有血肉的，都一對一對到挪亞那裡，進入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 25:10; 路加福音 13:25; 詩篇 91:1–10"> 各樣有血肉的，都是公母成雙進去的，是照著神所吩咐挪亞的話進去的。然後耶和華在挪亞後面關上了門。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 創世記 7:12"> 洪水在地上持續了四十天，水不斷上漲，把方舟托起，方舟就從地上浮了起來。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:28; 詩篇 69:15; 約伯記 22:16"> 水勢強盛，在地上大大上漲，方舟在水面上漂行。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:6–9; 詩篇 46:2–3; 彼得後書 3:6"> 水勢在地上極其強盛，普天下所有的高山都被淹沒了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 3:23; 詩篇 104:6"> 水勢繼續強盛，高出群山十五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十五肘——相當於6.9公尺。1肘=45.7公分。">a</a></sup>，群山都被淹沒了。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 6:13; 創世記 7:4; 創世記 6:17"> 一切有血肉、在地上活動的，就是飛鳥、牲畜、走獸和地上的各樣群居爬物，以及所有的人都斷了氣。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 2:7; 創世記 6:17"> 在陸地上一切鼻孔裡有生命氣息的都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 2:5; 彼得前書 3:20; 希伯來書 11:7"> 這樣，神抹掉了地面上的一切活物——無論是人，還是走獸、爬蟲和天空的飛鳥，都從地上抹掉了；只留下挪亞和那些與他一起在方舟裡的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 8:3–4"> 水勢強盛，在地上共一百五十天。</span>
</div>
</div>

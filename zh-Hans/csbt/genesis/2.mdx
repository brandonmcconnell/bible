<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 31:17; 出埃及記 20:11; 詩篇 33:6"> 諸天、大地及其萬象就這樣造成了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 4:4; 出埃及記 31:17; 申命記 5:14"> 到第七日，神已經完成了他所做的工，就在第七日安息了，歇了他所做的一切工。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 20:12; 馬可福音 2:27; 利未記 23:3"> 神就祝福第七日，把它分別為聖，因為在這日，神安息了，歇了他所做的一切創造之工。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 5:1; 啟示錄 1:8; 創世記 1:4"> 諸天和大地被造的來歷是這樣的：在耶和華神造大地和諸天的日子，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 3:23; 希伯來書 6:7; 約伯記 5:10"> 田野的灌木還沒有出現在地上，田間的蔬草也還沒有長出，因為耶和華神沒有降雨在地上，也沒有人耕耘土地；</span>
<span className="v" id="v6" data-v="6"> 但有霧氣從大地升騰，滋潤整個地面。</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 12:7; 約伯記 33:4; 哥林多前書 15:45"> 耶和華神用地上的塵土塑造人，把生命的氣息吹入他的鼻孔，那人就成了有生命的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有生命的人——傳統譯法作「有靈的活人」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 28:13; 創世記 3:24; 創世記 13:10"> 耶和華神在東方的伊甸栽種了一個園子，把所塑造的那人安置在那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 3:22; 啟示錄 2:7; 啟示錄 22:14"> 耶和華神使各樣的樹從地裡長出來，令人眼目喜愛，果實<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="果實——輔助詞語。">b</a></sup>好作食物；在園子的中間有生命樹和分辨善惡樹。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="啟示錄 22:1; 詩篇 46:4"> 有一條河從伊甸流出來，澆灌那園子；又從那裡分開，成為四條河<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="河——輔助詞語。">c</a></sup>的源頭。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 25:18; 創世記 10:29; 撒母耳記上 15:7"> 第一條名叫比遜，它圍繞著哈腓拉全地，在那裡有金子，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 28:20; 民數記 11:7; 以西結書 28:13"> 那地的金子是上好的，在那裡還有珍珠<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="珍珠——或譯作「紅玉」或「稀罕的香料」。">d</a></sup>和紅瑪瑙石。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:6; 以賽亞書 11:11"> 第二條河名叫基訓，它圍繞著庫實全地。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 10:4; 創世記 15:18; 申命記 1:7"> 第三條河名叫底格里斯，它流過亞述東邊。第四條河是幼發拉底。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="詩篇 128:2; 創世記 2:8; 以弗所書 4:28"> 耶和華神把那人帶來，安置在伊甸園中，讓他耕耘和看守那園子。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 15:22; 提摩太前書 4:4; 提摩太前書 6:17"> 耶和華神吩咐那人說：「園子中各樣樹上的果實，你都可以隨意吃；</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 6:23; 雅各書 1:15; 創世記 3:19"> 只是分辨善惡樹上的果實，你不可吃，因為在吃的日子，你必定死。」</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 4:9–12; 哥林多前書 11:7–12; 箴言 18:22"> 耶和華神又說：「那人孤身不好，我要為他造一個合適的幫助者。」</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 8:4–8; 創世記 1:28; 創世記 9:2"> 耶和華神用土塑造了田野各樣走獸和天空各樣飛鳥，把牠們帶到那人面前，看他怎麼稱呼牠們。他怎麼稱呼每樣活物，那就成了牠的名字。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:18"> 那人給各樣的牲畜、天空的飛鳥和田野的各樣走獸都起了名。至於給亞當的那合適的幫助者，卻沒有找到。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:12; 約伯記 4:13; 撒母耳記上 26:12"> 耶和華神使那人陷入沉睡，那人就睡著了；神取出他的一根肋骨，又在原處把肉合起來。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 11:8–9; 提摩太前書 2:13; 希伯來書 13:4"> 然後耶和華神用那人身上所取的肋骨，造出一個女人，並把她帶到那人面前。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所書 5:28–30; 哥林多前書 11:8–9; 撒母耳記下 5:1"> 那人說：<br /><span className="pl pl-1">「這才是我骨中的骨、</span><br /><span className="pl pl-1">肉中的肉！</span><br /><span className="pl pl-1">她當被稱為『女人』，</span><br /><span className="pl pl-1">因為她是從男人身上取出來的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 19:3–9; 以弗所書 5:28–31; 馬可福音 10:6–12"> 因此人將離開父母，與妻子結合，二人就成為一體。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 3:7; 創世記 3:10–11; 羅馬書 10:11"> 當時那人和他的妻子都是赤身的，彼此也不覺得羞恥。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 25:11; 創世記 21:22–32"> 在亞伯拉罕日子裡的那次饑荒以外，那地又有了饑荒。於是以撒就往基拉耳去，到了非利士人的王亞比米勒那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:7; 詩篇 37:3; 創世記 17:1"> 耶和華向以撒顯現，說：「你不要繼續下埃及去，要住在我指示你的地方。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 詩篇 105:9; 創世記 17:8"> 你要寄居在這地，我必與你同在，並祝福你，因為我必把所有這些地都賜給你和你的後裔；我必確立我向你父親亞伯拉罕所起的誓。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 3:25; 創世記 15:5; 創世記 22:17–18"> 我必使你的後裔增多，如同天上的星辰，我必把所有這些地都賜給你的後裔；地上萬國都必因你的後裔而蒙福，</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 7:24; 創世記 22:18; 創世記 22:16"> 因為亞伯拉罕聽從我的話，遵守我的吩咐、誡命、律例和訓誨。」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 20:1"> 這樣，以撒就在基拉耳住下了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 創世記 12:13; 創世記 20:2"> 每當那地方的人問起他的妻子，他就說：「她是我的妹妹。」原來他害怕說「她是我的妻子」；他想：「恐怕這地方的人會因莉百加的緣故殺我」，因為莉百加容貌美麗。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 62:5; 箴言 5:18–19; 箴言 7:6"> 他在那裡住了很長的一段日子。有一天，非利士人的王亞比米勒透過窗戶觀望，看哪，以撒正在與他的妻子莉百加親熱！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 亞比米勒就召來了以撒，說：「看哪，她確實是你的妻子！你怎麼說『她是我的妹妹』呢？」<br />以撒對他說：「因為我想『恐怕我會因她的緣故而死。』」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 20:9–10; 創世記 12:18–19"> 亞比米勒說：「你對我們做的這是什麼呢？民中有人差一點就與你的妻子同睡了，而你也差一點使罪責臨到我們了。」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 105:15; 創世記 20:6; 箴言 6:29"> 於是亞比米勒吩咐全體民眾說：「凡碰這人或他妻子的，必須被處死。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:8; 創世記 24:1; 創世記 26:3"> 以撒在那地耕種，那一年收穫百倍；耶和華祝福了他，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 112:3; 箴言 10:22; 創世記 24:35"> 他就昌大起來，日漸強大，變得非常昌盛。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 37:11; 創世記 13:2; 箴言 27:4"> 他擁有羊群、牛群和許多僕婢，非利士人就嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 21:30; 創世記 21:25"> 他父親亞伯拉罕在世的時候，他父親的僕人們所挖的井，全被非利士人堵上了，填滿了土。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 1:9"> 亞比米勒對以撒說：「從我們這裡離開吧！因為你比我們強盛得多。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 以撒就離開那裡，在基拉耳溪谷紮營，住了下來。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 13:2; 何西阿書 2:17; 民數記 32:38"> 以撒重新挖開了他父親亞伯拉罕在世的時候所挖的水井——它們在亞伯拉罕死後都被非利士人堵上了。以撒仍照著他父親為井所起的名字稱呼它們。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 4:10–11; 約翰福音 7:38; 雅歌 4:15"> 以撒的僕人們又在溪谷中挖井，在那裡發現一口活水井。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:25"> 基拉耳的牧人們與以撒的牧人們爭論，說：「這水是我們的。」以撒就給這口井起名為埃色，因為他們與他相爭。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 4:6"> 後來以撒的僕人們挖了另一口井，他們又為那口井爭論；以撒就給那口井起名為西提拿。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 17:6; 出埃及記 1:7; 詩篇 118:5"> 於是以撒從那裡遷移，又挖了一口井。這次，他們沒有為井爭論；以撒就給它起名為利河伯，因為他說：「如今耶和華給了我們寬闊的地方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="地方——輔助詞語。">a</a></sup>，我們必在此地繁盛。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:1; 創世記 21:31; 創世記 46:1"> 以撒從那裡上比爾-謝巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 15:1; 出埃及記 3:6; 以賽亞書 43:1–2"> 那天夜裡，耶和華向他顯現，說：「我是你父親亞伯拉罕的神；你不要害怕，因為我與你同在。我要因我僕人亞伯拉罕的緣故祝福你，並使你的後裔增多。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 13:18; 詩篇 116:17; 創世記 12:7–8"> 以撒就在那裡築了一座祭壇，呼求耶和華的名，並且在那裡支搭帳篷。以撒的僕人們也在那裡挖了一口井。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 21:22–32; 創世記 20:3"> 亞比米勒和他的謀士<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="謀士——或譯作「朋友」。">b</a></sup>亞戶撒，以及他軍隊的首領非革，從基拉耳來到以撒那裡。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:16; 士師記 11:7; 使徒行傳 7:14"> 以撒對他們說：「你們既然恨我，從你們中間趕我走，為什麼還來到我這裡呢？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 21:22–23; 以賽亞書 45:14; 以賽亞書 61:9"> 他們說：「我們確實看見耶和華與你同在，就想我們之間應該有一個誓約，就在你和我們之間。讓我們與你立約：</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 24:31; 創世記 21:22; 創世記 22:17"> 你不可加害我們，正如我們沒有碰過你，只是善待你，並且送你平平安安地走。你現在是蒙耶和華祝福的。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:3; 羅馬書 12:18; 希伯來書 12:14"> 於是以撒為他們擺設宴席，他們就一起吃喝。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 20:16–17; 希伯來書 6:16; 創世記 25:33"> 他們清早起來，彼此起誓；然後以撒送他們走，他們就平平安安地離開他去了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 那一天，以撒的僕人們來，把挖井的情況告訴他說：「我們找到水了。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 21:31; 創世記 26:28"> 他就稱呼那口井為謝巴；因此那城名叫比爾-謝巴，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 36:2; 創世記 36:13; 出埃及記 34:16"> 以掃四十歲的時候，娶了赫提人貝爾里的女兒猶迪斯與赫提人埃隆的女兒巴絲瑪為妻。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 27:46–2; 創世記 28:8; 創世記 6:2"> 她們使以撒和莉百加靈裡痛楚。</span>
</div>
</div>

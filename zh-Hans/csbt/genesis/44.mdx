<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 42:25; 創世記 43:16; 創世記 24:2"> 約瑟吩咐管家說：「給他們的袋子裝滿糧食，他們能帶多少就裝多少，並且把各人的銀子放在各自的袋子口。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 8:8; 創世記 42:20; 申命記 8:16"> 然後把我的杯子——那隻銀杯，放在最小兄弟的袋子口，連同他買糧的銀子都放進去。」管家就照著約瑟所說的話去做了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 早晨天一亮，那些人和他們的驢子都被打發走了。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:32; 詩篇 35:12; 箴言 17:13"> 他們剛出城，走了不遠，約瑟就對管家說：「起來，追趕那些人！追上後就對他們說：『你們為什麼以惡報善呢？</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; 利未記 19:26; 列王紀下 21:6"> 這不是我主人喝酒的杯子嗎？要知道，我主人必定會用它來占卜。你們這樣做就是作惡了！』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 管家就追上了他們，向他們說了這些話。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 38:16–18; 創世記 37:18–32; 列王紀下 8:13"> 他們對他說：「我主為什麼說這樣的話呢？你的僕人們絕不會做這樣的事。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 43:12; 創世記 42:35; 羅馬書 13:9"> 看哪，我們先前在袋子口發現的銀子，尚且從迦南地帶回來給你，我們又怎麼會從你主人的家偷竊金銀呢？</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:32; 詩篇 7:3–5; 約伯記 31:38–40"> 從你哪個僕人那裡找到杯子，他就要死，而且我們其餘的人就都作我主的奴僕。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 22:3; 創世記 44:17; 創世記 44:33"> 管家說：「那麼就照著你們的話做吧！只是從誰那裡找到杯子，誰就作我的奴僕，而你們其餘的人都沒有罪。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 於是他們急忙把自己的袋子卸在地上，各人都打開自己的袋子。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 44:26–32; 創世記 42:36–38; 創世記 43:14"> 管家就搜查，從年長的開始，到最小的為止；結果，那杯子在便雅憫的袋子裡找到了。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 1:11; 創世記 37:29–34; 撒母耳記下 1:2"> 他們就撕裂衣服，各人把東西馱在驢上，又回到城裡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 50:18; 創世記 43:25; 創世記 43:16"> 當猶大和他的兄弟們來到約瑟家時，約瑟還在那裡，他們就在他面前俯伏於地。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 4:10; 創世記 21:26; 創世記 3:13"> 約瑟對他們說：「你們做的這是什麼事呢？難道你們不知道像我這樣的人必定會占卜嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 44:9; 但以理書 9:7; 民數記 32:23"> 猶大說：「我們能對我主說什麼呢？我們還能說什麼呢？我們怎能證明自己無辜呢？神找出了你僕人們的罪孽。看哪，無論是我們還是從他手中找到杯子的那個人，現在都是我主的奴僕了！」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳記下 23:3; 創世記 18:25"> 可是約瑟說：「我絕不能這樣做！在誰手中找到杯子，誰就必作我的奴僕。至於你們其餘的人，平平安安地上到你們父親那裡去吧！」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 32:22; 創世記 41:40; 創世記 18:30"> 猶大靠近約瑟，說：「哦，我主啊，你就像法老一樣，求你讓僕人說句話給我主聽，不要讓你的怒氣向僕人發作。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 43:7; 創世記 43:29; 創世記 42:7–10"> 我主曾問僕人們說：『你們還有父親或其他兄弟嗎？』</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 37:3; 創世記 42:38; 路加福音 7:12"> 我們回答我主：『我們還有年老的父親和最小的弟弟，他是父親年老時生的孩子，他的哥哥死了，他是他母親留下來唯一的孩子，所以父親很疼愛他。』</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:15; 創世記 42:20; 阿摩司書 9:4"> 你就對僕人們說：『把他帶下來到我這裡，我要親眼看看他。』</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 44:30; 創世記 42:38"> 我們對我主說：『那少年不能離開他父親；如果離開了，他父親就會死。』</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 43:5; 創世記 43:3; 創世記 42:15–20"> 但你對僕人們說：『要是你們最小的弟弟不與你們一起下來，你們就再也不得見我的面。』</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 42:29–34"> 「我們上到你僕人我父親那裡去的時候，就把我主的話告訴了他。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:2; 創世記 43:5"> 後來，我們的父親說：『你們再回去為我們買些糧食來。』</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 創世記 43:4–5"> 我們就說：『我們不能下去。要是我們最小的弟弟與我們同去，我們才下去；因為要是最小的弟弟不與我們同去的話，我們就不能見那人的面。』</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 46:19; 創世記 35:16–18; 創世記 30:22–25"> 你僕人我父親對我們說：『你們知道我的妻子為我生了兩個兒子。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:33; 創世記 37:13–14; 創世記 42:36"> 一個已經離我而去了，我想他必定是被野獸撕碎了；直到現在，我再也沒有見過他。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:38; 創世記 43:14; 申命記 31:17"> 如果你們再把這個從我面前帶走，要是有災禍臨到他，你們就使白髮蒼蒼的我悲悲慘慘地下陰間去了。』</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 18:1; 撒母耳記下 18:33; 創世記 44:31"> 「現在如果我回到你僕人我父親那裡，而那少年沒有與我們在一起，既然我父親的命與那少年的命相連，</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 44:29; 創世記 37:35; 哥林多後書 7:10"> 我父親見那少年不在了，就必會死。這樣，你僕人們就使你僕人我們的父親，一個白髮蒼蒼的老人，悲悲慘慘地下陰間去了。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 43:8–9; 創世記 43:16"> 你的僕人曾經為了那少年的緣故向父親擔保，說：『如果我不把他帶回來給你，我就在父親面前終身擔罪。』</span>
<span className="v" id="v33" data-v="33" data-xref="約翰一書 3:16; 出埃及記 32:32; 希伯來書 7:22"> 現在，請你把僕人留下，代替那少年作我主的奴僕，讓那少年與他的哥哥們一同上去。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖記 8:6; 詩篇 116:3; 詩篇 119:143"> 因為如果那少年沒有與我在一起，我怎能上到我父親那裡去呢？恐怕我看見禍患臨到我父親。」</span>
</div>
</div>

</div>

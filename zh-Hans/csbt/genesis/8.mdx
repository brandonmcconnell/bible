<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:22; 創世記 19:29; 詩篇 136:23"> 神記念挪亞以及與他一起在方舟裡的所有活物和牲畜。神使風吹過大地，水就開始退落。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 7:11; 馬太福音 8:26–27; 箴言 8:28"> 深淵的泉源和天上的窗戶都關閉了，從天而降的大雨也止住了。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 7:24; 創世記 7:11"> 水從地上漸漸回落；過了一百五十天，水就大大減退了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:37; 耶利米書 51:27; 以賽亞書 37:38"> 七月十七日，方舟停留在亞拉臘山上。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 7:11"> 水繼續減退，直到十月。十月一日，眾山頂都顯露出來了。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 6:16; 但以理書 6:10"> 過了四十天，挪亞打開他所造方舟的窗戶，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 147:9; 列王紀上 17:6; 列王紀上 17:4"> 放出了一隻烏鴉。烏鴉不斷地飛去飛回，直到地上的水都乾了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 馬太福音 10:16"> 他又從他那裡放出一隻鴿子，要看看水是否從地面上消退了。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:28; 詩篇 116:7; 申命記 28:65"> 但鴿子找不到可以落腳的歇息之處，又回到方舟挪亞那裡，因為整個地面上都是水。挪亞伸出手，把鴿子接過來，帶進方舟自己那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 7:4; 創世記 7:10; 創世記 8:12"> 他又等了七天，再次把鴿子從方舟放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 8:15; 撒迦利亞書 4:12–14; 羅馬書 10:15"> 傍晚時分，鴿子回到他那裡；看哪，鴿子嘴裡有一片新擰下的橄欖葉子！挪亞就知道水已經從地上消退了。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 25:9; 以賽亞書 30:18; 創世記 8:10"> 他另外又等了七天，又把鴿子放出去，鴿子就再也沒有回到他那裡了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 7:11"> 挪亞六百零一歲那年的一月一日，水從地上退乾。挪亞移開方舟的頂蓋觀看，看哪，地面乾了！</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:13–14; 創世記 7:11"> 到了二月二十七日，大地完全乾了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 於是神吩咐挪亞說：</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 7:13; 詩篇 121:8; 詩篇 91:11"> 「你與你的妻子、兒子們和兒媳們，一起從方舟出來吧！</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:22; 創世記 9:1; 耶利米書 31:27–28"> 你要帶出所有與你在一起的活物，就是一切有血肉的，包括飛鳥、走獸和地上活動的一切爬蟲，好讓牠們充滿大地，繁衍增多。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:8"> 於是挪亞與他的兒子們、他的妻子和兒媳們一起出來了；</span>
<span className="v" id="v19" data-v="19"> 一切走獸、爬蟲和飛鳥，地上活動的一切，都按著牠們的族類，也從方舟出來了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="希伯來書 13:15–16; 羅馬書 12:1; 創世記 22:9"> 挪亞為耶和華築了一座祭壇，並拿各樣潔淨的牲畜和各樣潔淨的飛鳥，在祭壇上獻為燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 2:15; 以弗所書 5:2; 以賽亞書 54:9–10"> 耶和華聞到了那馨香之氣，就心裡說：「我絕不再因人的緣故詛咒這地，儘管人從年幼時就心懷邪惡；我也絕不再像我曾做的，毀滅所有的活物。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 5:7; 詩篇 74:16–17; 耶利米書 5:24"> <span className="pl pl-1">只要大地還存留，</span><br /><span className="pl pl-1">稼穡、寒暑、冬夏、晝夜</span><br /><span className="pl pl-1">就不會停息。」</span></span>
</div>

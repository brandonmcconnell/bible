<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 37:28; 詩篇 105:17; 創世記 37:36"> 約瑟被帶下埃及。有一個埃及人，是法老的內臣、護衛長波提乏，從那些帶約瑟下來的以實瑪利人手中買了他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 18:14; 詩篇 91:15; 耶利米書 15:20"> 耶和華與約瑟同在，他就成為事事順利的人。他住在他埃及主人的家中。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 1:3; 創世記 30:27; 馬太福音 5:16"> 他主人見耶和華與他同在，又見耶和華使他手上所做的一切都順利；</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:21–22; 箴言 27:18; 創世記 19:19"> 約瑟就在他主人的眼前蒙恩，事奉他的主人。他主人指派他管理自己的家，把自己所擁有的一切都交在他的手中。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; 撒母耳記下 6:11–12; 使徒行傳 27:24"> 自從波提乏指派約瑟管理家和所擁有的一切，耶和華就因約瑟的緣故祝福了那埃及人的家；無論在家裡或在田間，他所擁有的一切都蒙耶和華的祝福。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 16:12; 路加福音 19:17; 箴言 31:11"> 他把自己所擁有的一切都交託在約瑟的手中；有約瑟在，他除了自己吃的飯以外，什麼事都不理會。<br />約瑟有著健美的身材、俊美的容貌。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 13:11; 以西結書 16:34; 彼得後書 2:14"> 這些事以後，約瑟主人的妻子看上了約瑟<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="看上了約瑟——原文直譯「向約瑟抬起她的眼睛」。">a</a></sup>，對他說：「與我同睡吧！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 但約瑟拒絕了，對他主人的妻子說：「看哪，有我在，我主人對家中的什麼事都不理會，他把自己所擁有的一切都交在我的手中。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 12:13; 創世記 20:6; 創世記 42:18"> 在這家裡沒有比我大的；除你以外，他沒有留下一樣不給我，因你是他的妻子。我怎能行此大惡對神犯罪呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前書 2:11; 創世記 39:8; 帖撒羅尼迦前書 5:22"> 她天天對約瑟這樣說，約瑟卻不聽從她，不與她同睡，也不與她在一起。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 5:12; 以弗所書 5:3; 瑪拉基書 3:5"> 有一天，約瑟進屋去做事，沒有一個家僕在屋裡；</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 2:22; 箴言 7:13–27; 傳道書 7:26"> 主人的妻子就抓住約瑟的衣服，說：「與我同睡吧！」但約瑟把自己的衣服撇在她手中，逃到外面去了。</span>
<span className="v" id="v13" data-v="13"> 她見約瑟把衣服撇在她手中逃到了外面，</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:21; 彼得前書 2:20; 詩篇 35:11"> 就把家裡的人叫來，對他們說：「你們看，我丈夫帶給我們的希伯來人要戲弄我們。他到我這裡來，要與我同睡，我就大聲呼喊。</span>
<span className="v" id="v15" data-v="15"> 他聽見我放聲呼喊，就把自己的衣服撇在我身邊，逃到外面去了。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:32; 耶利米書 4:22; 耶利米書 9:3–5"> 她把約瑟的衣服放在自己身邊，等到約瑟的主人回家，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 23:1; 列王紀上 18:17; 詩篇 37:14"> 也用這些話<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這些話——或譯作「類似的話」。">b</a></sup>對他說：「你帶給我們的那個希伯來奴僕，到我這裡來要戲弄我。</span>
<span className="v" id="v18" data-v="18"> 當我放聲呼喊時，他就把自己的衣服撇在我身邊，逃到外面去了。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 4:5–6; 箴言 18:17; 箴言 6:34–35"> 約瑟的主人聽了妻子對他說的話「你的奴僕對我做了這樣的事」，他就怒氣發作。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 40:15; 提摩太後書 2:9; 詩篇 105:18–19"> 於是約瑟的主人把約瑟拿下，關進監獄，就是王的囚犯被囚的地方。約瑟就在那裡坐牢。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 3:21; 以賽亞書 41:10; 彼得前書 3:17"> 然而，耶和華與約瑟同在，向他施慈愛，使他在監獄長的眼前蒙恩。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:3–4; 創世記 39:4; 撒母耳記上 2:30"> 監獄長就把監獄裡所有的囚犯都交在約瑟手下；獄中要辦的一切事，都由約瑟處理。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 43:2; 創世記 39:2–3; 詩篇 1:3"> 監獄長對約瑟手中的一切事都不查看，因耶和華與他同在，耶和華使他所做的都順利。</span>
</div>
</div>

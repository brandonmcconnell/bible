<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 12:6; 創世記 18:10; 創世記 18:14"> 耶和華照著他所說的眷顧了撒拉，照著他所應許的為撒拉成就了。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 4:22; 希伯來書 11:11; 創世記 18:10"> 撒拉懷了孕，到了神對亞伯拉罕說的那個所定的日期，在亞伯拉罕年老的時候，為他生了一個兒子。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 17:19; 羅馬書 9:7; 創世記 21:6"> 亞伯拉罕給撒拉為他所生的兒子，起名為以撒。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 7:8; 申命記 12:32; 約翰福音 7:22–23"> 亞伯拉罕在兒子以撒生下來的第八天，照著神所吩咐的，給他行了割禮。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:17; 羅馬書 4:19; 創世記 17:1"> 他兒子以撒出生的時候，亞伯拉罕正一百歲。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="詩篇 126:2; 以賽亞書 54:1; 創世記 17:17"> 撒拉說：「神使我歡笑，所有聽見的人也必與我一同歡笑。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 18:11–12; 以賽亞書 66:8; 帖撒羅尼迦後書 1:10"> 她又說：「當年會有人對亞伯拉罕說『撒拉將乳養孩子』嗎？我竟然在他年老的時候，為他生了一個兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 1:22; 何西阿書 1:8; 創世記 40:20"> 孩子長大了，斷了奶。在以撒斷奶的那一天，亞伯拉罕擺設了盛大的宴席。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 4:29; 創世記 16:15; 加拉太書 4:22"> 撒拉看見埃及人夏甲為亞伯拉罕所生的兒子在一邊嘲笑<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在一邊嘲笑——七十士譯本作「與自己的兒子以撒一起玩耍」。">a</a></sup>，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:35; 約翰一書 2:19; 加拉太書 4:22–31"> 就對亞伯拉罕說：「你要把這女僕和她的兒子趕出去，因為這女僕的兒子不可與我的兒子以撒一同作繼承人。」</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 12:11; 創世記 17:18; 馬太福音 10:37"> 由於這事關乎他的兒子，亞伯拉罕就極其愁煩。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:18; 羅馬書 9:7–8; 創世記 17:19"> 神對亞伯拉罕說：「不要因這少年和你的女僕而愁煩。撒拉對你說的一切，你都要聽從，因為從以撒而出的，才被稱為你的後裔。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 16:10; 創世記 17:20; 創世記 21:18"> 至於這女僕的兒子，我也會使他成為一國，因為他是你的後裔。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="傳道書 9:10; 詩篇 119:60; 創世記 16:7"> 於是亞伯拉罕清早起來，拿了餅和一皮袋水，交給夏甲，放在她的肩膀上，又把孩子交給了她，然後送她走。她就走了，在比爾-謝巴曠野中漂流。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 3:9; 詩篇 63:1; 耶利米書 14:3"> 皮袋裡的水喝完了，夏甲就把孩子撇在一叢灌木底下，</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 49:15; 創世記 29:11; 撒母耳記上 24:16"> 然後走開，坐在對面大約一箭遠的地方，因為她想：「我不忍心看這孩子死去。」她坐在對面，放聲大哭。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 16:11; 詩篇 50:15; 出埃及記 3:7"> 神聽見那少年的哭聲，神的使者就從天上向夏甲呼喚，對她說：「夏甲，你怎麼了？不要害怕，因為神已經聽見了那少年在那裡的哭聲。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:13; 創世記 16:10; 創世記 17:20"> 起來！扶起這少年，用手扶持他，因為我要使他成為一個強大的民族。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 22:31; 列王紀下 6:17–20; 以賽亞書 35:5–6"> 神打開了夏甲的眼睛，她就看見一口水井，於是走過去把皮袋倒滿了水，給那少年喝。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:15; 創世記 39:21; 創世記 16:12"> 神與那少年同在；他漸漸長大，住在曠野中，成了射箭能手。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 26:34–35; 創世記 24:3–4; 民數記 12:16"> 他住在帕蘭曠野，他母親從埃及地為他娶了妻子。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約書亞記 3:7; 創世記 26:26; 創世記 26:28"> 在那段時期，亞比米勒和他軍隊的首領非革對亞伯拉罕說：「在你所做的一切事上，神都與你同在。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 2:12; 創世記 20:14; 希伯來書 6:16"> 現在，請你在這裡指著神向我起誓，你絕不以詭詐對待我，以及我的子孫後裔；我怎樣以恩慈對待你，你也要怎樣對待我和你所寄居的這地。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯來書 6:16; 創世記 14:13; 羅馬書 12:18"> 亞伯拉罕說：「我願意起誓。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 26:15–22; 創世記 29:8; 箴言 25:9"> 同時，亞伯拉罕因亞比米勒的僕人們搶占了一口水井，指責了亞比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 13:7; 列王紀下 5:20–24"> 亞比米勒說：「我不知道誰做了這事，你也沒有告訴過我，我今天才聽到。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 14:22–23; 以賽亞書 32:8; 羅馬書 1:31"> 於是亞伯拉罕牽來牛羊，送給亞比米勒，他們兩人就立了約。</span>
<span className="v" id="v28" data-v="28"> 亞伯拉罕又從羊群中分出七隻母羊羔另放一處。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 15:14; 創世記 33:8; 出埃及記 12:26"> 亞比米勒問亞伯拉罕：「你分出來另放一處的這七隻母羊羔，是作什麼的呢？」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 31:52; 約書亞記 24:27; 約書亞記 22:27–28"> 亞伯拉罕說：「你要從我手中接受這七隻母羊羔，作我挖這口井的見證。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 26:33; 創世記 21:14; 列王紀上 4:25"> 因此那地方被稱為比爾-謝巴，因為他們兩人在那裡起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 13:17; 創世記 21:27; 士師記 13:1"> 這樣他們在比爾-謝巴立了約，然後亞比米勒和他軍隊的首領非革就起身，回到非利士人之地。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="提摩太前書 1:17; 以賽亞書 40:28; 詩篇 90:2"> 亞伯拉罕在比爾-謝巴栽種了一棵檉柳樹，在那裡呼求永恆之神耶和華的名。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 29:15; 彼得前書 2:11; 希伯來書 11:9"> 亞伯拉罕在非利士人之地寄居了許多日子。</span>
</div>
</div>

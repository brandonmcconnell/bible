<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所書 4:24; 歌羅西書 3:10; 創世記 1:26–27"> 以下是亞當譜系的記錄：<br />在神創造人的日子，神按著自己的樣式造人；</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 19:4; 馬可福音 10:6; 創世記 2:23"> 神創造了男人和女人；在他們被創造的日子，神祝福他們，給他們起名為「人」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 4:25; 約伯記 25:4; 詩篇 51:5"> 亞當活到一百三十歲時，生了一個兒子，樣式和形象與自己相似；給他起名為塞特。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 1:1–3; 路加福音 3:36–38; 創世記 5:26"> 亞當生了塞特之後，他的年日又有八百年，並且生了其他的兒女。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 5:8; 創世記 5:11; 創世記 3:19"> 這樣亞當一生活了九百三十年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 4:26"> 塞特活到一百零五歲時，生了以挪士。</span>
<span className="v" id="v7" data-v="7"> 塞特生了以挪士之後，又活了八百零七年，並且生了其他的兒女。</span>
<span className="v" id="v8" data-v="8"> 這樣塞特一生活了九百一十二年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:37; 歷代志上 1:2"> 以挪士活到九十歲時，生了該南。</span>
<span className="v" id="v10" data-v="10"> 以挪士生了該南之後，又活了八百一十五年，並且生了其他的兒女。</span>
<span className="v" id="v11" data-v="11"> 這樣以挪士一生活了九百零五年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:37"> 該南活到七十歲時，生了瑪勒列。</span>
<span className="v" id="v13" data-v="13"> 該南生了瑪勒列之後，又活了八百四十年，並且生了其他的兒女。</span>
<span className="v" id="v14" data-v="14"> 這樣該南一生活了九百一十年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 1:2"> 瑪勒列活到六十五歲時，生了雅列。</span>
<span className="v" id="v16" data-v="16"> 瑪勒列生了雅列之後，又活了八百三十年，並且生了其他的兒女。</span>
<span className="v" id="v17" data-v="17"> 這樣瑪勒列一生活了八百九十五年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 4:17; 歷代志上 1:3; 猶大書 1:14–15"> 雅列活到一百六十二歲時，生了以諾。</span>
<span className="v" id="v19" data-v="19"> 雅列生了以諾之後，又活了八百年，並且生了其他的兒女。</span>
<span className="v" id="v20" data-v="20"> 這樣雅列一生活了九百六十二年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:37"> 以諾活到六十五歲時，生了瑪土撒拉。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:12; 創世記 17:1; 創世記 6:9"> 以諾生了瑪土撒拉之後，與神同行三百年，並且生了其他的兒女。</span>
<span className="v" id="v23" data-v="23"> 這樣以諾一生活了三百六十五年。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 11:5–6; 約翰一書 1:7; 創世記 5:22"> 以諾與神同行；後來他不在地上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="地上——輔助詞語。">a</a></sup>了，因為神把他接去。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 4:18"> 瑪土撒拉活到一百八十七歲時，生了拉麥。</span>
<span className="v" id="v26" data-v="26"> 瑪土撒拉生了拉麥之後，又活了七百八十二年，並且生了其他的兒女。</span>
<span className="v" id="v27" data-v="27"> 這樣瑪土撒拉一生活了九百六十九年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 拉麥活到一百八十二歲時，生了一個兒子，</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 2:5; 希伯來書 11:7; 馬太福音 24:37"> 給他起名為挪亞，說：「這兒子將安慰我們，使我們脫離我們的苦工和手中的辛苦——這是因為耶和華詛咒了這地。」</span>
<span className="v" id="v30" data-v="30"> 拉麥生了挪亞之後，又活了五百九十五年，並且生了其他的兒女。</span>
<span className="v" id="v31" data-v="31"> 這樣拉麥一生活了七百七十七年，然後他死了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 6:10; 創世記 10:21; 創世記 9:18–19"> 挪亞五百歲時，生了閃、含、雅弗。</span>
</div>
</div>

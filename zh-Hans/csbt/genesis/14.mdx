<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 10:10; 創世記 10:22; 以賽亞書 37:12"> 在暗拉非作示拿王、阿約克作以拉撒王、基大勞瑪作以攔王、提達作戈印王的日子裡，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 13:10; 申命記 29:23; 創世記 10:19"> 他們與所多瑪王比拉、格摩拉王比沙、押瑪王示納、洗扁王善以別、比拉王作戰；比拉就是瑣珥。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 3:16; 申命記 3:17; 民數記 34:12"> 這五王都在西訂谷會合；西訂谷就是鹽海。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 9:25–26; 以西結書 17:15"> 這五王曾經服事了基大勞瑪十二年，但在第十三年背叛了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:11; 創世記 15:20; 申命記 1:4"> 第十四年，基大勞瑪和同盟的王都來了，在亞特律-加寧擊敗了利乏音人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利乏音人——或譯作「巨人」。">a</a></sup>，在哈麥擊敗了蘇西人，在沙微-基列亭擊敗了以米人，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:22; 申命記 2:12; 創世記 21:21"> 在何利人的西珥山擊敗了何利人，一直打到靠近曠野的伊勒-帕蘭。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 20:2; 創世記 16:14; 創世記 20:1"> 然後他們返回，來到恩米示帕，就是加低斯，征服了亞瑪力人的全境，擊敗了住在哈洗遜-塔瑪爾的亞摩利人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 19:22; 創世記 13:10; 創世記 19:20"> 於是所多瑪王、格摩拉王、押瑪王、洗扁王和比拉王，就是瑣珥王都出來，在西訂谷擺陣與他們作戰，</span>
<span className="v" id="v9" data-v="9"> 就是與以攔王基大勞瑪、戈印王提達、示拿王暗拉非、以拉撒王阿約克作戰；這就是四王對五王。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:17; 創世記 19:30; 以賽亞書 24:18"> 西訂谷有許多瀝青坑；所多瑪王和格摩拉王逃跑時，掉進坑裡，其餘的人都往山裡逃跑。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:21; 創世記 14:16; 申命記 28:31"> 那四王把所多瑪和格摩拉一切的財物以及他們所有的糧食都擄掠而去。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:5; 創世記 11:27; 啟示錄 3:19"> 他們也把亞伯蘭兄弟的兒子羅得和他的財物擄掠而去。當時羅得正住在所多瑪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 13:18; 創世記 14:24; 創世記 40:15"> 有一個逃脫的人來告訴希伯來人亞伯蘭，那時他正居住在亞摩利人幔利的橡樹那裡；幔利是以實格和阿內爾的兄弟，他們是亞伯蘭的盟友。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 18:29; 創世記 15:3; 創世記 17:27"> 亞伯蘭聽說他的侄子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="侄子——原文直譯「兄弟」。">b</a></sup>被擄走了，就出動家裡生養的、訓練有素的家丁三百一十八人，一直追到但。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:2; 詩篇 112:5; 列王紀上 15:18"> 他和他的僕人們在夜間兵分幾路，擊敗敵人，又追趕他們，直到大馬士革北面的赫巴。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 30:18–19; 撒母耳記上 30:8; 創世記 12:2"> 他把一切的財物都奪了回來，也把他的侄子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="侄子——原文直譯「兄弟」。">c</a></sup>羅得和羅得的財物，以及婦女和民眾都奪了回來。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 18:18; 箴言 19:4; 希伯來書 7:1"> 亞伯蘭擊敗基大勞瑪及其同盟的王回來之後，所多瑪王就出來，在沙微谷迎接他；沙微谷就是帝王谷。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:20–3; 詩篇 110:4; 希伯來書 5:6"> 又有撒冷王麥基洗德帶著餅和酒出來；他是至高神的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 7:6–7; 創世記 14:22; 詩篇 24:1"> 他祝福亞伯蘭，說：<br /><span className="pl pl-1">「願至高神、天地的主宰祝福亞伯蘭！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:22; 希伯來書 7:4–9; 瑪拉基書 3:10"> <span className="pl pl-1">至高神是當受頌讚的！</span><br /><span className="pl pl-1">他把你的敵人交在你的手中。」</span><br />亞伯蘭就把所有的十分之一獻給他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 所多瑪王對亞伯蘭說：「人，你交給我；財物，你自己拿去吧。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="但以理書 12:7; 但以理書 4:34; 申命記 32:40"> 但亞伯蘭對所多瑪王說：「我曾經向耶和華至高神、天地的主宰舉手起誓<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="起誓——輔助詞語。">d</a></sup>：</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 5:16; 哥林多後書 11:9–12; 以斯帖記 9:15–16"> 任何屬於你的東西，就是一根線、一根鞋帶，我也絕不會拿，以免你說：『是我使亞伯蘭富有。』</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 14:13; 箴言 3:27; 馬太福音 7:12"> 除了我僕人們所吃的以及同行的阿內爾、以實格和幔利所應得的份，我什麼都不要；讓他們拿去所應得的份吧。」</span>
</div>
</div>

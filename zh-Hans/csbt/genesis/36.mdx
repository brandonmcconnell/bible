<span className="v" id="v1" data-v="1" data-xref="創世記 22:17; 歷代志上 1:35; 申命記 23:7"> 以下是以掃的家系記事，以掃就是以東：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 36:25; 創世記 28:9; 創世記 9:25"> 以掃從迦南的女子中娶了婭達和阿何利巴瑪為妻；婭達是赫提人埃隆的女兒，阿何利巴瑪是希未人基比文的孫女、亞拿的女兒。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:9; 創世記 25:13"> 以掃還娶了以實瑪利的女兒、尼拜約的妹妹巴絲瑪。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 1:35; 出埃及記 2:18; 約伯記 2:11"> 婭達為以掃生了以利法；巴絲瑪生了流珥；</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 35:29"> 阿何利巴瑪生了耶烏施、雅蘭、可拉。以上是以掃的眾子，是他在迦南地生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 32:3; 創世記 12:5; 創世記 17:8"> 後來以掃帶著他的妻子兒女和家中所有的人，以及他的牲畜和各樣動物，還有他在迦南地所積蓄的一切財產，離開他的弟弟雅各到別的地方去了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 13:6; 創世記 17:8; 創世記 28:4"> 因為兩人擁有的很多，不能住在一起；他們的牲畜眾多，寄居之地容不下他們。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:3; 瑪拉基書 1:3; 以西結書 35:2–7"> 於是以掃住在西珥山裡；以掃就是以東。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="創世記 19:37"> 以下是西珥山以東人始祖以掃的家系。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 36:3–4; 歷代志上 1:35–54"> <span className="pl pl-1">以掃子孫的名字：</span><br /><span className="pl pl-1">以利法是以掃的妻子婭達的兒子，</span><br /><span className="pl pl-1">流珥是以掃的妻子巴絲瑪的兒子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="創世記 36:15–16; 歷代志上 1:35–36"> <span className="pl pl-1">以利法的兒子是提幔、阿抹、洗玻、迦坦、基納斯。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 17:8–16; 申命記 25:17–19; 撒母耳記上 15:2–9"> <span className="pl pl-1">以掃的兒子以利法的妾是亭娜，</span><br /><span className="pl pl-1">她為以利法生了亞瑪力。</span><br /><span className="pl pl-1">這些是以掃的妻子婭達的子孫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="歷代志上 1:37; 創世記 36:17"> <span className="pl pl-1">流珥的兒子是拿哈、謝拉、沙瑪、米撒。</span><br /><span className="pl pl-1">這些是以掃的妻子巴絲瑪的子孫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="創世記 36:2; 創世記 36:18; 歷代志上 1:35"> <span className="pl pl-1">以掃的妻子阿何利巴瑪為以掃所生的兒子如下：耶烏施、雅蘭、可拉。</span><br /><span className="pl pl-1">阿何利巴瑪是基比文的孫女、亞拿的女兒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="俄巴底亞書 1:9; 約伯記 2:11; 創世記 36:11–12"> <span className="pl pl-1">以下是以掃子孫中的族長。</span><br /><span className="pl pl-1">以掃的長子以利法的子孫中有：</span><br /><span className="pl pl-1">提幔族長、阿抹族長、洗玻族長、基納斯族長、</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 15:15"> <span className="pl pl-1">可拉族長、迦坦族長、亞瑪力族長。</span><br /><span className="pl pl-1">這些是以東地以利法的族長，</span><br /><span className="pl pl-1">他們都是婭達的子孫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="創世記 36:13; 歷代志上 1:37; 創世記 36:4"> <span className="pl pl-1">以掃的兒子流珥的子孫中有：</span><br /><span className="pl pl-1">拿哈族長、謝拉族長、沙瑪族長、米撒族長。</span><br /><span className="pl pl-1">這些是以東地流珥的族長，</span><br /><span className="pl pl-1">他們都是以掃的妻子巴絲瑪的子孫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="創世記 36:14; 歷代志上 1:35; 創世記 36:5"> <span className="pl pl-1">以掃的妻子阿何利巴瑪的子孫中有：</span><br /><span className="pl pl-1">耶烏施族長、雅蘭族長、可拉族長。</span><br /><span className="pl pl-1">他們是從以掃的妻子，亞拿的女兒阿何利巴瑪而出的族長。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19"> <span className="pl pl-1">以上是以掃的子孫和他們中的族長；</span><br /><span className="pl pl-1">以掃就是以東。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命記 2:12; 申命記 2:22; 創世記 14:6"> <span className="pl pl-1">以下是當地的居民，何利人西珥的子孫：</span><br /><span className="pl pl-1">羅坍、朔巴、基比文、亞拿、</span><br /></span>
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">底順、以察、底珊。</span><br /><span className="pl pl-1">這些是以東地何利人西珥子孫中的族長。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 1:39"> <span className="pl pl-1">羅坍的兒子是何利和希幔；</span><br /><span className="pl pl-1">羅坍的妹妹是亭娜。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 1:40"> <span className="pl pl-1">朔巴的兒子如下：亞勒文、瑪拿哈、以巴錄、示玻、阿南。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="申命記 2:10; 撒母耳記下 18:9; 列王紀上 4:28"> <span className="pl pl-1">基比文的兒子如下：阿亞、亞拿。</span><br /><span className="pl pl-1">這亞拿為他父親基比文放牧驢子時，</span><br /><span className="pl pl-1">在曠野發現了溫泉。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 36:2; 創世記 36:18; 歷代志上 1:41"> <span className="pl pl-1">亞拿的兒女如下：兒子底順、女兒阿何利巴瑪。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 1:41"> <span className="pl pl-1">底順的兒子如下：欣但、伊示班、益蘭、基蘭。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 1:42; 創世記 36:21; 歷代志上 1:38"> <span className="pl pl-1">以察的兒子如下：比勒罕、撒番、亞干。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="耶利米哀歌 4:21; 約伯記 1:1; 耶利米書 25:20"> <span className="pl pl-1">底珊的兒子如下：烏斯、亞蘭。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="創世記 36:20; 創世記 36:28; 歷代志上 1:41–42"> <span className="pl pl-1">以下是何利人的族長：</span><br /><span className="pl pl-1">羅坍族長、朔巴族長、基比文族長、亞拿族長、</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 7:23; 以賽亞書 23:15; 列王紀下 11:19"> <span className="pl pl-1">底順族長、以察族長、底珊族長。</span><br /><span className="pl pl-1">這些是何利人的族長，在西珥地按著他們的宗族作族長。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="創世記 17:6; 歷代志上 1:43–50; 創世記 17:16"> <span className="pl pl-1">以色列子孫還沒有君王統治的時候，</span><br /><span className="pl pl-1">統治以東地的君王如下：</span><br /></span>
<span className="v" id="v32" data-v="32"> <span className="pl pl-1">比珥的兒子比拉在以東作王，</span><br /><span className="pl pl-1">他的城名叫亭哈巴。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 49:13; 耶利米書 49:22; 阿摩司書 1:12"> <span className="pl pl-1">比拉死後，波斯拉人謝拉的兒子約巴接替他作王。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="創世記 36:11; 約伯記 2:11; 創世記 36:15"> <span className="pl pl-1">約巴死後，從提幔地來的戶珊接替他作王。</span><br /></span>
<span className="v" id="v35" data-v="35"> <span className="pl pl-1">戶珊死後，比達的兒子哈達接替他作王；</span><br /><span className="pl pl-1">哈達曾在摩押地擊敗米甸人，</span><br /><span className="pl pl-1">他的城名叫亞未得。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 1:47"> <span className="pl pl-1">哈達死後，瑪士利加人桑拉接替他作王。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 1:48; 創世記 10:11"> <span className="pl pl-1">桑拉死後，大河</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼發拉底河。">a</a></sup><br /><span className="pl pl-1">邊的利河伯人掃羅接替他作王。</span><br /></span>
<span className="v" id="v38" data-v="38"> <span className="pl pl-1">掃羅死後，亞革波的兒子巴勒·哈南接替他作王。</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 15:15; 歷代志上 1:50"> <span className="pl pl-1">亞革波的兒子巴勒·哈南死後，哈達爾接替他作王，</span><br /><span className="pl pl-1">他的城名叫巴烏；</span><br /><span className="pl pl-1">他的妻子名叫米赫塔別，</span><br /><span className="pl pl-1">是米·薩合的孫女、瑪特列的女兒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v40" data-v="40" data-xref="歷代志上 1:51–54; 出埃及記 15:15; 創世記 36:31"> <span className="pl pl-1">以下是從以掃而出的族長的名字，</span><br /><span className="pl pl-1">分別按照他們的家族名和住地名：</span><br /><span className="pl pl-1">亭納族長、亞勒瓦族長、耶帖族長、</span><br /></span>
<span className="v" id="v41" data-v="41"> <span className="pl pl-1">阿何利巴瑪族長、以拉族長、比嫩族長、</span><br /></span>
<span className="v" id="v42" data-v="42"> <span className="pl pl-1">基納斯族長、提幔族長、米比薩族長、</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="創世記 45:8; 歷代志上 4:14; 創世記 25:30"> <span className="pl pl-1">瑪基疊族長、以蘭族長。</span><br /><span className="pl pl-1">以上是以東的各族長，在他們得為業的居住之地作族長；</span><br /><span className="pl pl-1">以東人的始祖就是這以掃。</span></span>

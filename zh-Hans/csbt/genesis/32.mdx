<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="32" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 91:11; 詩篇 34:7; 希伯來書 1:4"> 雅各繼續他的行程。神的使者們與他相遇。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 2:8; 約書亞記 5:14; 約書亞記 21:38"> 雅各看見他們就說：「這是神的營地。」於是給那地方起名為瑪哈念。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 25:30; 約書亞記 24:4; 申命記 2:5"> 雅各派遣使者們在他前面，到以東境內的西珥地，去他哥哥以掃那裡。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 3:6; 路加福音 14:11; 創世記 33:8"> 雅各吩咐他們說：「你們要對我主以掃這樣說：『你的僕人雅各如此說：我在拉班那裡寄居，滯留到現在。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:8; 創世記 33:15; 創世記 33:11"> 我有牛、驢、羊群、男僕和婢女；我派人來告訴我主，為要在你眼前蒙恩。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 33:1; 創世記 32:8; 創世記 32:11"> 使者們回到雅各那裡，說：「我們到了你哥哥以掃那裡，他正迎著你來，與他一起的還有四百人。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 哥林多後書 1:8–10; 出埃及記 14:10"> 於是雅各極其害怕而且焦慮，就把與他一起的人，羊群、牛群和駱駝，分成兩隊。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 10:16; 創世記 33:1–3"> 他想：「如果以掃來擊殺一隊，剩下的一隊還可以逃脫。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 31:42; 詩篇 34:4–6; 創世記 31:3"> 雅各說：「我祖父亞伯拉罕的神，我父親以撒的神耶和華啊，你曾對我說：『回到你的本土本族，我必厚待你。』</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:35; 創世記 24:27; 撒母耳記下 7:18"> 你向你僕人所施的一切慈愛和信實，我一點也不配。我先前只帶著一根杖過這約旦河，如今我卻擁有這兩隊了。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–2; 箴言 18:19; 馬太福音 6:13"> 求你救我脫離我哥哥以掃的手，因為我懼怕他，恐怕他來擊殺我，連母親和孩子也一同擊殺。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 28:13–15; 希伯來書 6:17; 提多書 1:2"> 但你說過：『我必定厚待你，使你的後裔如海沙那樣，多得無法數清。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 創世記 43:11; 箴言 19:6"> 那天晚上，雅各就在那裡過夜。他從自己所擁有的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自己所擁有的——原文直譯「手上帶來的」。">a</a></sup>東西中，選出給哥哥以掃的禮物：</span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 1:3; 申命記 8:18; 約伯記 42:12"> 母山羊兩百隻，公山羊二十隻，母綿羊兩百隻，公綿羊二十隻，</span>
<span className="v" id="v15" data-v="15"> 哺乳的駱駝三十頭和牠們的幼仔，母牛四十頭，公牛十頭，母驢二十頭，公驢十頭；</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 33:8–9; 創世記 32:20; 箴言 2:11"> 分成一群一群的，交在僕人們手中，對他們說：「你們要在我前面先過去，使群和群之間保持一段距離。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 33:3"> 他吩咐領頭的僕人說：「我哥哥以掃遇見你的時候，如果問你：『你的主人是誰？你要到哪裡去？在你前面的這些牲畜是誰的？』</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:4–5"> 你就回答：『是你僕人雅各的，是送給我主以掃的禮物。看哪，他自己也在我們後面。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 他又吩咐第二個、第三個和所有跟在各群後面的僕人，說：「你們遇見以掃的時候，也要這樣對他說，</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 42:8–9; 箴言 21:14; 創世記 43:11"> 並強調說：『看哪，你的僕人雅各在我們後面。』」因為雅各想：「我先藉著在我前面先送去的禮物與他和解，然後再與他見面，或許他會接納我。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 於是那些禮物在雅各前面先送了過去；而他那天晚上卻在營中留宿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 3:16; 申命記 2:37; 提摩太前書 5:8"> 他夜間起來，帶著他的兩個妻子、兩個婢女和十一個孩子，過了雅博渡口。</span>
<span className="v" id="v23" data-v="23"> 他帶著他們，先送他們過河，又把所擁有的一切也都送了過去。</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿書 12:3–5; 以弗所書 6:12; 路加福音 13:24"> 最後雅各獨自留下。 雅各與神較力<br />那夜，有一個人與雅各摔跤，直到天亮。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 12:7–9; 何西阿書 12:3–4; 馬太福音 26:41"> 那人見自己勝不過他，就碰了他的大腿窩；於是雅各與那人摔跤的時候，大腿窩就脫臼了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 12:4; 詩篇 115:12–13; 哥林多後書 12:8–9"> 那人說：「天亮了，讓我走吧！」<br />雅各說：「你不祝福我，我就不讓你走。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 那人問他：「你叫什麼名字？」<br />他回答：「雅各。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 2:17; 創世記 35:10; 以賽亞書 62:2–4"> 那人說：「你的名字不要再叫雅各，而要叫以色列，因為你已經與神與人較力，並且得勝了。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 9:6; 士師記 13:16–18; 約伯記 11:7"> 雅各問他說：「請把你的名字告訴我。」<br />那人說：「為什麼要問我的名字呢？」他就在那裡祝福了雅各。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 24:10–11; 民數記 12:8; 以賽亞書 6:5"> 雅各就給那地方起名為毗努伊勒，因為他說：「我面對面看見了神，但我的性命得以保全。」</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 12:7; 創世記 19:15; 士師記 8:8"> 雅各過毗努伊勒的時候，太陽初升，照在他身上。他因大腿的傷就一瘸一拐。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 5:5"> 因此直到今日，以色列子孫不吃大腿窩上的腱子筋，因為那人碰了雅各大腿窩上的腱子筋。</span>
</div>
</div>

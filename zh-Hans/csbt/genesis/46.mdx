<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 28:13; 創世記 26:22–25; 創世記 28:10"> 以色列帶著一切屬於他的起程了。他來到比爾-謝巴，向他父親以撒的神獻上祭物。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 15:1; 約伯記 33:14–15; 約伯記 4:13"> 神藉著夜間的異象對以色列說：「雅各！雅各！」<br />他說：「我在這裡！」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 12:2; 申命記 26:5; 以賽亞書 43:1–2"> 神說：「我是神，是你父親的神。你不要害怕下埃及去，因為我必使你在那裡成為強大的民族。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 3:8; 創世記 28:15; 創世記 48:21"> 我要親自與你一同下埃及去，也必定把你帶上來。約瑟要親手合上你的眼。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 45:21; 創世記 45:19; 創世記 45:27"> 雅各就從比爾-謝巴起程。以色列的兒子們讓他們的父親雅各，以及他們的孩童和妻子坐上了法老送來的車輛。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 24:4; 以賽亞書 52:4; 使徒行傳 7:15"> 他們還帶上牲畜和在迦南地所積蓄的財物。於是雅各和他所有的子孫都一同來到埃及。</span>
<span className="v" id="v7" data-v="7"> 這樣，雅各帶著他的兒子、孫子、女兒、孫女，他所有的子孫，一同來到了埃及。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 1:1–5; 申命記 33:6; 歷代志上 2:1–55"> 雅各和他的子孫——來到埃及的以色列人——他們的名字如下：<br /><span className="pl pl-1">雅各的長子魯本，</span><br /></span>
<span className="v" id="v9" data-v="9"> <span className="pl pl-1">魯本的兒子哈諾、法路、希斯倫、迦米；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 6:15; 創世記 29:33; 創世記 28:1"> <span className="pl pl-1">西緬的兒子耶姆利、雅憫、阿轄、雅斤、瑣哈爾，以及掃羅——迦南女子的兒子；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="創世記 29:34; 歷代志上 6:16; 民數記 8:1–26"> <span className="pl pl-1">利未的兒子革順、哥轄、米拉利；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 4:21; 創世記 38:10; 創世記 29:35"> <span className="pl pl-1">猶大的兒子珥、俄南、示拉、法勒斯、謝拉，其中珥和俄南在迦南地死了，而法勒斯的兒子是希斯倫、哈姆勒；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 12:32; 創世記 35:23; 創世記 30:14–18"> <span className="pl pl-1">以薩迦的兒子陀拉、普瓦、約伯、希姆崙；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:18–19; 民數記 26:26–27; 民數記 1:30–31"> <span className="pl pl-1">西布倫的兒子西列德、埃隆、雅赫列</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:32–35; 創世記 30:17–21; 創世記 34:1–31"> <span className="pl pl-1">——以上是莉亞在帕旦-亞蘭為雅各所生的兒孫，不包括女兒狄娜，子孫共有三十三人——</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民數記 26:15–17; 創世記 30:11; 民數記 1:24–25"> <span className="pl pl-1">迦得的兒子濟非雲、哈基、書尼、伊茲本、伊利、阿羅迪、阿爾耶利；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 創世記 30:13; 民數記 1:13"> <span className="pl pl-1">亞設的兒子伊姆納、伊施瓦、伊施韋、比利亞，還有他們的妹妹西拉，其中比利亞的兒子是希伯、瑪結</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 29:24; 創世記 35:26; 創世記 30:9–13"> <span className="pl pl-1">——以上是悉帕的子孫，悉帕是拉班給他女兒莉亞的婢女</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="婢女——輔助詞語。">a</a></sup><br /><span className="pl pl-1">，悉帕為雅各生了這些人，共有十六人——</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 44:27; 創世記 29:18; 創世記 35:24"> <span className="pl pl-1">雅各的妻子拉結的兒子約瑟、便雅憫；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:50–52; 創世記 41:45; 申命記 33:13–17"> <span className="pl pl-1">瑪拿西和以法蓮是安城的祭司波提·非拉的女兒婭希納在埃及地為約瑟所生的；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 7:6–12; 歷代志上 8:1–7; 民數記 26:38–40"> <span className="pl pl-1">便雅憫的兒子比拉、比結、阿實別、基拉、奈曼、伊希、羅實、慕皮姆、戶皮姆、阿爾德</span><br /></span>
<span className="v" id="v22" data-v="22"> <span className="pl pl-1">——以上是拉結為雅各所生的兒孫，共有十四人——</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:38–39; 創世記 49:16–17; 民數記 1:12"> <span className="pl pl-1">但的兒子戶西姆；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 7:13; 民數記 1:42–43; 創世記 35:25"> <span className="pl pl-1">拿弗他利的兒子雅赫茲列、古尼、耶則爾、謝勒姆</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 29:29; 創世記 35:25; 創世記 30:3–8"> <span className="pl pl-1">——以上是碧拉的兒孫，碧拉是拉班給他女兒拉結的婢女</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="婢女——輔助詞語。">b</a></sup><br /><span className="pl pl-1">，碧拉為雅各生了這些人，共有七人。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 1:5; 創世記 35:11; 士師記 8:30"> 所有雅各的直系子孫，不包括他的兒媳們，來到埃及的共有六十六人；</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 10:22; 使徒行傳 7:14; 出埃及記 1:5"> 另有約瑟在埃及所生的兩個兒子，雅各家先後來到埃及的總共有七十人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 45:10; 創世記 44:16–34; 創世記 49:8"> 雅各打發猶大先到約瑟那裡，請約瑟指示前往歌珊的路<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的路——輔助詞語。">c</a></sup>。他們就這樣來到了歌珊地。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 創世記 45:14–15; 創世記 33:4"> 約瑟備好座車，上到歌珊去迎接他的父親以色列。他一到父親的面前，就伏在父親的脖子上，在父親的脖子上哭了很久。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 創世記 45:28"> 以色列對約瑟說：「既然我看見你的面，知道你還活著，現在我就是死也甘心。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 47:1–3; 希伯來書 2:11; 使徒行傳 18:3"> 約瑟對他的兄弟們和他的父家說：「我要上到法老那裡稟告說：『我在迦南地的兄弟們和我的父家都來到了我這裡。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 47:3; 列王紀上 9:27; 列王紀上 18:5–6"> 這些人是牧羊的，是牧養牲畜的人；他們把羊群、牛群和一切屬於他們的都帶來了。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 46:32; 創世記 47:2–4; 約拿書 1:8"> 當法老召見你們並問你們：『你們以什麼為業呢？』</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 8:26; 創世記 43:32; 創世記 46:32"> 你們就要回答：『你僕人們從年幼時直到現在，都是牧養牲畜的人，我們祖祖輩輩都一樣。』這樣你們就可以住在歌珊地，因為所有牧羊的都是埃及人所憎惡的。」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 41:50–52; 創世記 46:20; 詩篇 128:6"> 這些事以後，有人告訴約瑟：「看哪，你的父親病了！」他就帶著兩個兒子瑪拿西和以法蓮一同去探望<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="探望——輔助詞語。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:10; 撒母耳記上 23:16; 申命記 3:28"> 又有人告訴雅各說：「看哪，你的兒子約瑟到你這裡來了！」以色列就竭盡全力，在床榻上坐起。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 35:9–12; 出埃及記 6:3; 創世記 28:3"> 雅各對約瑟說：「全能的神曾在迦南地的路斯向我顯現，並祝福了我，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 17:8; 創世記 35:11; 創世記 26:4"> 對我說：『看哪，我要使你繁衍增多，成為萬族之族；又要把這地賜給你的後裔作永遠的產業。』</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:50–52; 約書亞記 14:4; 創世記 46:20"> 我來到埃及你這裡之前，你在埃及地所生的以法蓮和瑪拿西這兩個兒子，現在是我的了，就像魯本和西緬是我的一樣；</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:4"> 而你在他們以後所生的孩子就是你的，在他們繼業的事上，被算在這兩個哥哥的名下。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:16–19; 馬太福音 2:18; 創世記 35:9"> 至於我，從帕旦回來的時候，我很不幸，拉結死在迦南地的路上，離以法他還有一段路程；我把她就地埋葬在通往以法他的路旁。」以法他就是伯利恆。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 以色列看見約瑟的兒子們，就說：「他們是誰呢？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 27:4; 創世記 33:5; 希伯來書 11:21"> 約瑟對他父親說：「他們是我的兒子，是神在這裡賜給我的。」<br />以色列說：「把他們帶到我這裡，好讓我祝福他們。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 27:1; 創世記 27:27; 撒母耳記上 3:2"> 以色列的眼睛因年老昏花，不能看見。約瑟就讓他們靠近他；他就親吻他們，擁抱他們。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:20; 創世記 45:26; 創世記 42:36"> 以色列對約瑟說：「我沒有想到能見你的面，看哪，連你的後裔，神都讓我見到了！」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:6; 利未記 19:32; 創世記 19:1"> 約瑟把他們從以色列的膝蓋挪開，自己臉伏於地下拜。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13"> 然後約瑟領著他們兩個靠近以色列：以法蓮在他的右手，對著以色列的左手；瑪拿西在他的左手，對著以色列的右手。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 41:51; 詩篇 118:16; 馬太福音 19:15"> 以色列卻伸出右手，按在次子以法蓮的頭上；又交叉著伸出左手，按在瑪拿西的頭上；實際上瑪拿西才是長子。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:1; 歌羅西書 2:6; 以賽亞書 33:16"> 以色列祝福約瑟說：<br /><span className="pl pl-1">「願我祖父亞伯拉罕和我父以撒所跟隨的神，</span><br /><span className="pl pl-1">就是牧養我一生直到今日的神，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 34:22; 創世記 49:22; 創世記 48:5"> <span className="pl pl-1">也是救贖我脫離一切禍患的那一位</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那一位——原文直譯「使者」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">祝福這兩個孩子！</span><br /><span className="pl pl-1">願我的名，我祖父亞伯拉罕和我父以撒的名，藉著他們得以流傳；</span><br /><span className="pl pl-1">願他們在地上生養眾多。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 48:14; 羅馬書 9:7–8; 歷代志上 21:7"> 約瑟見父親把右手按在以法蓮的頭上，就覺得不對，於是抓著父親的手，要從以法蓮的頭上移到瑪拿西的頭上。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 19:18; 創世記 29:26; 創世記 43:33"> 約瑟對他父親說：「我的父親哪，這樣不對！這一個才是長子，你要把右手放在他的頭上。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="申命記 33:17; 民數記 1:33–35; 創世記 25:28"> 他父親卻拒絕他，說：「我知道，我兒，我知道！他也要成為一族，也必昌大；只是他的弟弟將來比他還要昌大，他弟弟的後裔必成為多國。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:60; 路得記 4:11–12; 創世記 28:3"> 以色列當天就祝福他們，說：<br /><span className="pl pl-1">「以色列人要用你們的名</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的名——輔助詞語。">c</a></sup><br /><span className="pl pl-1">說祝福的話：</span><br /><span className="pl pl-1">『願神使你像以法蓮和瑪拿西一樣。』」</span><br />這樣他把以法蓮立在瑪拿西之先。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 50:24; 創世記 46:4; 創世記 28:15"> 以色列對約瑟說：「看哪，我就要死了！但神必與你們同在，把你們帶回到你們祖先之地。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:5; 約書亞記 24:32; 歷代志上 5:2"> 我還要使你比眾兄弟多得一塊山地，就是我曾經用刀用弓從亞摩利人手中奪過來的。」</span>
</div>
</div>

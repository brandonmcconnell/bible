<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:3; 哥林多後書 11:14; 啟示錄 12:9"> 在耶和華神所造的田野各樣活物中，蛇是最狡猾的。牠對女人說：「難道神真說過，你們不可吃這園子中任何樹上的果實嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="詩篇 58:4"> 女人對蛇說：「園子中樹上的果實，我們可以吃，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 2:16–17; 哥林多後書 6:17; 出埃及記 19:12–13"> 只有園子中間那棵樹上的果實，神說過『你們不可吃，也不可碰，免得你們死。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 8:44; 哥林多後書 11:3; 提摩太前書 2:14"> 蛇卻對女人說：「你們不一定死，</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 28:2; 帖撒羅尼迦後書 2:4; 哥林多後書 11:13–15"> 因為神知道：你們吃那果實的日子，眼睛就開了，你們就會像神一樣知道善惡。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰一書 2:16; 雅各書 1:14–15; 提摩太前書 2:14"> 女人見那棵樹的果實<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的果實——輔助詞語。">a</a></sup>好作食物，又悅人眼目，並且因使人有智慧而令人喜愛，就摘下果實吃了，又給了與她在一起的丈夫，她丈夫也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 59:6; 創世記 2:25; 創世記 3:5"> 於是他們兩人的眼睛開了，知道自己是赤身的，就把無花果樹的葉子縫合起來，為自己做了腰上的遮蓋。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米書 23:24; 箴言 15:3; 希伯來書 4:13"> 天起涼風的時候，那人和他的妻子聽見耶和華神在園子裡行走的聲音，就躲藏在園子的樹木中，避開耶和華神的面。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 4:9; 創世記 16:8; 創世記 18:20–21"> 耶和華神呼喚那人，對他說：「你在哪裡？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 2:25; 詩篇 119:120; 以賽亞書 47:3"> 那人說：「我在園子裡聽見你的聲音就害怕，因為我是赤身的；於是我躲藏了。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:20; 創世記 4:10; 詩篇 50:21"> 耶和華說：「誰告訴你，你是赤身的呢？難道你吃了我吩咐你『不可吃』的那棵樹的果實<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的果實——輔助詞語。">b</a></sup>嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各書 1:13–15; 約伯記 31:33"> 那人說：「你賜給我那與我在一起的女人——她把那棵樹上的果實給了我，我就吃了。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 11:3; 提摩太前書 2:14; 創世記 4:10–12"> 耶和華神對女人說：「你做的這是什麼呢？」女人說：「那蛇引誘了我，我就吃了。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="彌迦書 7:17; 以賽亞書 65:25; 詩篇 72:9"> 耶和華神就對蛇說：<br /><span className="pl pl-1">「因為你做了這事，</span><br /><span className="pl pl-1">你必受詛咒，比一切的牲畜和田野一切的走獸更甚。</span><br /><span className="pl pl-1">你必用肚腹行走，</span><br /><span className="pl pl-1">你一生所有的日子都必吃土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:20; 約翰一書 3:8; 啟示錄 12:17"> <span className="pl pl-1">我要把仇恨放在你和女人之間，</span><br /><span className="pl pl-1">放在你的後裔和女人的後裔之間；</span><br /><span className="pl pl-1">女人的後裔要重創你的頭，</span><br /><span className="pl pl-1">而你要重創他的腳跟。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="提多書 2:5; 歌羅西書 3:18; 哥林多前書 11:3"> 神對女人說：<br /><span className="pl pl-1">「我要大大增加你懷胎的辛苦，</span><br /><span className="pl pl-1">你必在痛苦中生孩子。</span><br /><span className="pl pl-1">你必戀慕你的丈夫，</span><br /><span className="pl pl-1">而他必管轄你。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:20–22; 創世記 5:29; 以賽亞書 24:5–6"> 神又對亞當說：<br /><span className="pl pl-1">「因為你聽從了你妻子的話，</span><br /><span className="pl pl-1">吃了我吩咐你『不可吃』的那棵樹的果實</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的果實——輔助詞語。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">土地就因你的緣故受詛咒；</span><br /><span className="pl pl-1">你一生所有的日子都必辛苦，</span><br /><span className="pl pl-1">才能從土地得吃的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:7; 約伯記 5:5; 以賽亞書 7:23"> <span className="pl pl-1">土地將給你長出荊棘和蒺藜；</span><br /><span className="pl pl-1">你也必吃田間的蔬草。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 12:7; 約伯記 34:15; 詩篇 104:29"> <span className="pl pl-1">你必汗流滿面才有飯吃，</span><br /><span className="pl pl-1">直到你歸回土地，</span><br /><span className="pl pl-1">因為你是從那裡取出來的。</span><br /><span className="pl pl-1">你本是塵土，</span><br /><span className="pl pl-1">就要歸回塵土。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 2:23; 馬太福音 1:23; 創世記 5:29"> 那人給他妻子起名為夏娃，因為她是眾生之母。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 61:10; 哥林多後書 5:21; 哥林多後書 5:2–3"> 耶和華神為亞當和他的妻子做了皮子衣服，給他們穿上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:7; 啟示錄 22:14; 箴言 3:18"> 耶和華神說：「看哪，那人已經與我們相似<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="與我們相似——原文直譯「像我們中的一個」。">d</a></sup>，知道善惡；現在恐怕他又伸出手，取生命樹的果實來吃，那樣他就會永遠活著。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 4:2; 創世記 3:19; 創世記 4:12"> 於是耶和華神就把他趕出伊甸園，去耕耘土地——他本是從那裡取出來的。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 1:7; 詩篇 104:4; 出埃及記 25:18–22"> 耶和華神驅逐了那人，又在伊甸園的東邊安置了基路伯和四周旋轉的火焰之劍，來看守通往<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="通往——輔助詞語。">e</a></sup>生命樹的道路。</span>
</div>
</div>

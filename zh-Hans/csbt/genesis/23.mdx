<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:17"> 撒拉活了一百二十七歲，這是撒拉一生的年歲。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 23:19; 創世記 13:18; 歷代志上 6:57"> 撒拉死在迦南地的基列-阿爾巴，就是希伯崙；亞伯拉罕前來為撒拉哀慟哭泣。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 10:15; 創世記 23:7; 撒母耳記上 26:6"> 然後亞伯拉罕從死者身旁起來，對赫提的子孫說：</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 29:15; 希伯來書 11:9; 創世記 17:8"> 「我在你們中間是外人，是寄居的；請把你們中間的一塊地產給我作墳地，好讓我把死者從我身旁移去安葬。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 赫提的子孫回應亞伯拉罕，說：</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:35; 創世記 14:14; 出埃及記 32:22"> 「我主啊，請聽我們說！你在我們中間是尊貴的領袖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="尊貴的領袖——或譯作「神的寵臣」。">a</a></sup>，請在我們最好的墳地安葬你的死者吧！我們中沒有一個人會阻止你在他的墳地安葬你的死者。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯來書 12:14; 創世記 19:1; 箴言 18:24"> 亞伯拉罕就起來，向那地的民眾赫提的子孫下拜，</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 25:9; 約翰一書 2:1–2; 列王紀上 2:17"> 對他們說：「如果你們有心讓我把死者從我身旁移去安葬，就聽我說，為我請求瑣哈爾的兒子以弗崙，</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 13:8; 羅馬書 12:17"> 把他田邊的麥比拉洞穴賣給我，並按足價在你們面前賣給我，作為我擁有的墳地。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 34:20; 創世記 34:24; 創世記 23:18"> 當時以弗崙正坐在赫提的子孫中間。赫提人以弗崙就回應亞伯拉罕，當著所有來到城門口的赫提子孫的面<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="面——原文直譯「耳朵」。">b</a></sup>，說：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以賽亞書 32:8; 申命記 19:15"> 「不，我主啊，請聽我說！我把這塊田地送給你，其中的洞穴也送給你。我在我族人眼前把它送給你；你安葬你的死者吧！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 23:7; 創世記 18:2; 創世記 19:1"> 亞伯拉罕就在那地的民眾面前下拜，</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 13:8; 撒母耳記下 24:24; 創世記 14:22–23"> 然後當著那地民眾的面<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="面——原文直譯「耳朵」。">c</a></sup>，對以弗崙說：「如果你願意，就請聽我說！我要把這塊田地的價銀付給你，請你收下，好讓我在那裡安葬我的死者。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 以弗崙回應亞伯拉罕，說：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 45:12; 出埃及記 30:13; 出埃及記 30:15"> 「我主啊，請聽我說！四百謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="四百謝克爾——相當於4.6公斤；下同。1謝克爾=11.4公克。">d</a></sup>銀子的這塊地，在你我之間算什麼呢？你安葬你的死者吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 11:12; 耶利米書 32:9; 出埃及記 30:13"> 亞伯拉罕聽了，就照以弗崙在赫提子孫面前<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="面前——原文直譯「耳朵」。">e</a></sup>所說的價銀，給他稱了四百謝克爾商用的銀子。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 25:9; 創世記 50:13; 創世記 23:20"> 這樣，以弗崙的那塊田地，就是幔利對面在麥比拉的田地，包括其中的洞穴和地界內所有的樹木，</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 4:1; 耶利米書 32:12; 創世記 34:20"> 在所有來到城門口的赫提子孫眼前，轉給亞伯拉罕作他的財產。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:13; 傳道書 12:7; 傳道書 12:5"> 此後亞伯拉罕把他的妻子撒拉葬在迦南地，幔利對面、麥比拉田中的洞穴裡；幔利就是希伯崙。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 32:10–14; 路得記 4:7–10; 創世記 49:31–32"> 於是那塊田地和其中的洞穴，由赫提的子孫轉給了亞伯拉罕，作為他擁有的墳地。</span>
</div>
</div>

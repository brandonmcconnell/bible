<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 使徒行傳 7:11–13; 耶利米哀歌 5:10"> 那地的饑荒仍然很嚴重。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 6:6–8; 箴言 16:18; 箴言 15:16"> 他們從埃及帶回來的糧食吃完後，他們的父親就對他們說：「你們再去為我們買些糧食來。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 44:23; 創世記 43:5; 撒母耳記下 3:13"> 猶大對他說：「那人嚴厲地告誡我們，『要是你們的弟弟不與你們一起來，你們就不得見我的面。』</span>
<span className="v" id="v4" data-v="4"> 如果你打發我們的弟弟與我們一起去，我們就下去為你買糧食；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 20:12; 創世記 44:26; 創世記 42:38"> 但如果你不打發他去，我們就不下去，因為那人對我們說：『要是你們的弟弟不與你們一起來，你們就不得見我的面。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 以色列說：「你們為什麼這樣害我，要告訴那人你們還有一個弟弟呢？」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 43:3; 創世記 42:13; 創世記 43:27"> 他們說：「那人詳細問到我們和我們的親屬，說：『你們的父親還活著嗎？你們還有兄弟嗎？』我們就照著他所問的告訴他。我們怎麼知道他會說『把你們的弟弟帶下來』呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 42:2; 申命記 33:6; 創世記 45:19"> 猶大對他父親以色列說：「請打發那少年與我同去，我們就立刻起身前往，好使我們和你，以及我們的孩童都得以存活，不至於死。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 42:37; 腓利門書 1:18–19; 希伯來書 7:22"> 我親自為此擔保，你可以從我手中追討責任。如果我不把他帶回來，讓他站在你面前，我就在你面前終身擔罪。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:16"> 其實要不是我們耽延，現在已經來回兩次了。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 37:25; 耶利米書 8:22; 以西結書 27:17"> 他們的父親以色列對他們說：「如果必須如此，你們就這樣做：把本地土產中最好的乳香、蜂蜜、香料、沒藥、開心果、杏仁各取一點，放在容器裡，帶下去給那人作禮物。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:25; 創世記 42:35; 帖撒羅尼迦前書 4:6"> 你們手中要拿上雙倍的銀子，親手帶回那歸還在你們袋子口的銀子，那或許是個失誤。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 42:38"> 現在帶上你們的弟弟，立刻起身，回到他那裡吧！</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 4:16; 創世記 17:1; 使徒行傳 21:14"> 願全能的神使你們在那人面前蒙憐憫，好讓他可以把你們那個兄弟和便雅憫都交還給你們。至於我，如果要喪失兒子，就喪失吧！」</span>
<span className="v" id="v15" data-v="15"> 於是他們帶著這些禮物，手中拿上雙倍的銀子，並帶上便雅憫，起身下到埃及，站在了約瑟面前。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 44:1; 創世記 43:19; 創世記 24:2–10"> 約瑟看見便雅憫與他們在一起，就對自己的管家說：「把這些人帶到家裡。宰殺牲畜，預備宴席<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="宴席——輔助詞語。">a</a></sup>，因為這些人中午將與我一起吃飯。」</span>
<span className="v" id="v17" data-v="17"> 那人就照著約瑟所說的做，把這些人帶到約瑟家裡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 42:35; 羅馬書 7:8; 創世記 42:21"> 這些人因為被帶到約瑟家裡就害怕，說：「頭一次銀子歸還在我們的袋子裡，我們現在被帶進來必定是為了這個緣故；他想向我們下手，襲擊我們，抓我們作奴僕，奪我們的驢子。」</span>
<span className="v" id="v19" data-v="19"> 他們就靠近約瑟的管家，在屋門口與他說話。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 42:3; 創世記 42:10; 創世記 42:27"> 他們說：「哦，我主啊，頭一次我們真是下來買糧的。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:12; 創世記 42:27–35; 羅馬書 13:8"> 當我們來到一處住宿的地方，打開自己的袋子，看哪，各人的銀子都在自己的袋子口，重量分文不少。現在我們手上帶著這些銀子回來了。</span>
<span className="v" id="v22" data-v="22"> 我們手上又帶了另外的銀子下來買糧。我們不知道頭一次是誰把銀子放在我們的袋子裡。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 20:26; 創世記 42:24; 約翰福音 14:27"> 管家說：「你們請放心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你們請放心——原文直譯「平安歸你們」。">b</a></sup>，不要害怕。是你們的神，你們父親的神賜你們財寶，放在你們的袋子裡。你們的銀子我早已收到了。」然後他把西緬帶出來交給他們。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 18:4; 創世記 24:32; 路加福音 7:44"> 那人就把這些人帶到約瑟家裡，給他們水洗腳；又給他們的驢子飼料。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:11; 創世記 43:16"> 他們聽說他們要在那裡吃飯，就預備好禮物，等候約瑟中午到來。</span>
<span className="v" id="v26" data-v="26" data-xref="腓立比書 2:10–11; 創世記 27:29; 創世記 42:6"> 約瑟到了家，他們就把手中的禮物帶進屋裡給他，並俯伏於地，向他下拜。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 42:13; 撒母耳記上 25:5; 撒母耳記上 17:22"> 約瑟向他們問安，又說：「你們的父親，就是你們說的那位老人家平安嗎？他還健在嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 37:7; 創世記 43:26; 撒母耳記下 14:4"> 他們說：「你的僕人、我們的父親平安，他還健在。」然後他們又俯身下拜。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 42:13; 民數記 6:25; 創世記 30:22–24"> 約瑟舉目看見他同母的弟弟便雅憫，就問：「這就是你們向我說的那個最小的弟弟嗎？」然後他說：「我兒啊，願神恩待你。」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:24; 耶利米書 31:20; 列王紀上 3:26"> 約瑟的愛弟之情升騰，他就急忙找個地方去哭。於是他進到自己的內室，在那裡哭了一場。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 45:1; 彼得前書 3:10; 以賽亞書 42:14"> 他洗了臉出來，克制住自己，說：「擺飯吧！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 46:34; 出埃及記 8:26; 創世記 43:16"> 他們就為約瑟單獨擺了飯，為那些人另擺了一席，也為那些與約瑟一起吃飯的埃及人又擺了一席，因為埃及人不能與希伯來人同席吃飯；那是埃及人所憎惡的。</span>
<span className="v" id="v33" data-v="33"> 他們被領到各自的座位上，從長子到幼子，照著長幼次序坐在約瑟面前。他們彼此對望<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="對望——輔助詞語。">c</a></sup>，感到驚奇。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 45:22; 撒母耳記下 11:8; 撒母耳記上 1:5"> 約瑟把自己面前的食物分給他們，但便雅憫分到的是其他人的五倍<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="是其他人的五倍——或譯作「比其他人多五倍」。">d</a></sup>。他們與約瑟一同宴樂暢飲。</span>
</div>
</div>

</div>

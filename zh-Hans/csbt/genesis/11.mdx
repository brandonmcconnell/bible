<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 2:6; 西番雅書 3:9; 以賽亞書 19:18"> 當初全地只有一種語言、一種話語。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 10:10; 但以理書 1:2; 創世記 14:1"> 人們向東方遷移<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="向東方遷移——或譯作「從東方出發」。">a</a></sup>，在示拿地發現了一塊平原，就在那裡住下。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:10; 出埃及記 1:14; 出埃及記 2:3"> 他們彼此說：「來吧！讓我們做磚，用火燒透。」於是他們就用磚代替石頭，用瀝青代替灰泥。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:28; 約翰福音 5:44; 路加福音 1:51"> 他們又說：「來吧！讓我們為自己建造一座城和一座塔，塔頂通天，好為自己立名，免得我們分散在整個地面上。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 18:21; 詩篇 33:13–14; 約翰福音 3:13"> 耶和華降臨，要看世人建造的城和塔。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 2:1–4; 創世記 3:22; 創世記 11:1"> 耶和華說：「看哪，他們是一族，又說一樣的語言，而且一開始就做這樣的事，此後他們決意做任何事，就沒有做不成的！</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 33:10; 詩篇 55:9; 約伯記 5:12–13"> 來吧！讓我們下去，在那裡把他們的語言變亂，使他們彼此聽不懂對方的語言。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命記 32:8; 創世記 10:25"> 於是耶和華把他們從那裡分散到整個地面上，他們就停止建造那城。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 10:10; 創世記 10:5; 創世記 10:20"> 因此那城名叫巴別<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巴別——就是巴比倫。">b</a></sup>，因為在那裡耶和華變亂了全地人的語言，又從那裡把他們分散到整個地面上。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 1:17–27; 創世記 10:21–22; 路加福音 3:34–36"> 以下是閃的譜系：洪水之後兩年，閃一百歲時，生了亞法撒。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 9:7; 詩篇 144:12; 創世記 1:28"> 閃生了亞法撒之後，又活了五百年，並且生了其他的兒女。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亞法撒活到三十五歲時，生了沙拉。</span>
<span className="v" id="v13" data-v="13"> 亞法撒生了沙拉之後，又活了四百零三年，並且生了其他的兒女。</span>
<span className="v" id="v14" data-v="14"> 沙拉活到三十歲時，生了希伯。</span>
<span className="v" id="v15" data-v="15"> 沙拉生了希伯之後，又活了四百零三年，並且生了其他的兒女。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 10:21; 歷代志上 1:19; 民數記 24:24"> 希伯活到三十四歲時，生了法勒。</span>
<span className="v" id="v17" data-v="17"> 希伯生了法勒之後，又活了四百三十年，並且生了其他的兒女。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒活到三十歲時，生了拉吳。</span>
<span className="v" id="v19" data-v="19"> 法勒生了拉吳之後，又活了兩百零九年，並且生了其他的兒女。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吳活到三十二歲時，生了西鹿。</span>
<span className="v" id="v21" data-v="21"> 拉吳生了西鹿之後，又活了兩百零七年，並且生了其他的兒女。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 24:2"> 西鹿活到三十歲時，生了拿鶴。</span>
<span className="v" id="v23" data-v="23"> 西鹿生了拿鶴之後，又活了兩百年，並且生了其他的兒女。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 約書亞記 24:2"> 拿鶴活到二十九歲時，生了塔拉。</span>
<span className="v" id="v25" data-v="25"> 拿鶴生了塔拉之後，又活了一百一十九年，並且生了其他的兒女。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 24:2; 歷代志上 1:26–27; 創世記 22:20–24"> 塔拉活到七十歲時，生了亞伯蘭、拿鶴和哈蘭。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 12:4; 創世記 14:12; 創世記 11:31"> 以下是塔拉的譜系：塔拉生了亞伯蘭、拿鶴、哈蘭；哈蘭生了羅得。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:7; 尼希米記 9:7; 使徒行傳 7:2–4"> 哈蘭在他父親塔拉之前，死在他本族之地，就是迦勒底的吾珥。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:15; 創世記 22:20; 創世記 24:15"> 亞伯蘭和拿鶴各為自己娶了妻子。亞伯蘭的妻子名叫撒萊，拿鶴的妻子名叫米爾卡，她是哈蘭的女兒；哈蘭是米爾卡的父親，也是伊斯卡的父親。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 29:31; 創世記 21:1–2; 路加福音 1:7"> 撒萊不能生育，沒有孩子。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 9:7; 使徒行傳 7:2–4; 創世記 24:10"> 塔拉帶著他的兒子亞伯蘭和他的孫子，就是哈蘭的兒子羅得，也帶著他的兒媳婦——他兒子亞伯蘭的妻子撒萊，一同從迦勒底的吾珥出來，要往迦南地去。他們來到哈蘭的時候，就在那裡住下了。</span>
<span className="v" id="v32" data-v="32"> 塔拉的年日有兩百零五年，然後死在哈蘭。</span>
</div>
</div>

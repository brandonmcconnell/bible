<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比書 4:13; 以弗所書 3:20; 路加福音 1:6"> 亞伯蘭九十九歲時，耶和華向亞伯蘭顯現，對他說：「我是全能的神，你當行在我面前，作純全人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:4–6; 創世記 12:2; 詩篇 105:8–11"> 我要在你我之間立約，我要使你的後裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的後裔——輔助詞語。">a</a></sup>大大增多。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士師記 13:20; 創世記 17:17; 民數記 16:45"> 亞伯蘭臉伏於地；神又對他說：</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:11; 加拉太書 3:28–29; 創世記 12:2"> 「看哪，我的約是與你立的，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我的約是與你立的，——或譯作「以下是我與你所立的約：」。">b</a></sup>你將成為多國之父！</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 1:21–23; 尼希米記 9:7; 創世記 17:15"> 你的名字不再叫亞伯蘭，而要叫亞伯拉罕，因為我已立你為多國之父。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 17:4; 馬太福音 1:6–17; 創世記 35:11"> 我要使你大大繁衍，多國因你而立，多王從你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:7–9; 使徒行傳 2:39; 創世記 26:24"> 我要與你以及你世世代代的後裔確立我的約，作為永遠的約，我要成為你和你後裔的神。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 26:12; 詩篇 105:11; 出埃及記 6:7"> 我必把你現在的寄居之地，就是迦南全地，賜給你和你的後裔作永遠的產業；我也必作他們的神。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 56:4–5; 詩篇 25:10; 詩篇 103:18"> 神接著對亞伯拉罕說：「至於你，你要遵守我的約，你和你的後裔世世代代都要如此。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 2:11–12; 羅馬書 4:9–11; 使徒行傳 7:8"> 你們中所有的男子都要受割禮，這就是我與你以及你的後裔所立的約，是你們當遵守的。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 4:11; 使徒行傳 7:8; 申命記 10:16"> 你們要割去肉體上的包皮，這就是我與你們立約的標記。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 12:3; 路加福音 2:21; 出埃及記 12:48–49"> 你們世世代代所有的男子，無論是家裡出生的，還是用銀子從不屬於你後裔的外邦人那裡買來的，在八天大的時候都要受割禮。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 12:44; 創世記 37:36; 尼希米記 5:8"> 你家裡出生的和你用銀子買來的，都必須受割禮；這樣我的約就在你們肉體上成為永遠的約。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 4:24–26; 民數記 15:30–31; 出埃及記 12:19"> 至於不受割禮的男子，就是肉體上的包皮沒有被割去的，那人要從民中被剪除，因他違背了我的約。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 12:25; 創世記 32:28; 創世記 17:5"> 神對亞伯拉罕說：「至於你的妻子撒萊，你不要再叫她撒萊，她的名字要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:11; 創世記 17:6; 以賽亞書 49:23"> 我要祝福她，也要藉著她賜給你一個兒子。我要祝福她，她將成為多國之母<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="之母——輔助詞語。">c</a></sup>，萬族的君王要從她而出。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="啟示錄 11:16; 創世記 21:6; 創世記 18:12"> 亞伯拉罕就臉伏於地笑了，心裡說：「難道一百歲的人還能生孩子嗎？就是撒拉也已經九十歲了，還能生育嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 2:39; 詩篇 41:12; 詩篇 4:6"> 亞伯拉罕對神說：「但願以實瑪利活在你面前。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 創世記 21:2–3; 列王紀下 4:16–17"> 神說：「不，你的妻子撒拉將為你生一個兒子，你要給他起名為以撒。我要與他確立我的約，作為他後裔永遠的約。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:18; 創世記 21:13; 創世記 25:12–18"> 至於以實瑪利，我也聽允你了，看哪，我也要祝福他！我要使他繁衍，大大增多。他將生十二個族長，我必使他成為一個大國。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:2–3; 創世記 26:2–5; 加拉太書 3:29"> 而我的約，我要與以撒確立。這以撒，就是撒拉要在明年所定的日期為你生的兒子。」</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 18:33; 創世記 35:9–15; 士師記 6:21"> 神與亞伯拉罕說完了話，就從亞伯拉罕面前上升而去。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:60; 創世記 18:19; 創世記 17:10–14"> 於是就在那一天，亞伯拉罕照著神向他所說的，叫來他的兒子以實瑪利和家中所有的男子，無論是在他家裡出生的，還是用銀子買來的，都割去了他們肉體上的包皮。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 4:11; 創世記 17:17; 羅馬書 4:19–20"> 亞伯拉罕割去肉體上的包皮時年九十九歲；</span>
<span className="v" id="v25" data-v="25"> 他的兒子以實瑪利割去肉體上的包皮時年十三歲。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:60; 創世記 22:3–4; 創世記 12:4"> 就在那一天，亞伯拉罕和他兒子以實瑪利都受了割禮。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 18:19"> 他家裡所有的男人，無論是家裡出生的，還是用銀子從外邦人那裡買來的，都與他一起受了割禮。</span>
</div>
</div>

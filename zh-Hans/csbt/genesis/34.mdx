<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:21; 耶利米書 2:36; 創世記 30:13"> 莉亞為雅各所生的女兒狄娜出去，要見那地的女子。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 5:28; 約伯記 31:1; 約伯記 31:9"> 那地的族長希未人哈莫爾的兒子示劍看見她，就抓住她，與她同睡，玷辱了她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 2:14; 以賽亞書 40:2; 歷代志下 30:22"> 示劍的心迷戀雅各的女兒狄娜，他愛那少女，對她說寬心的話。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 14:2; 撒母耳記下 13:13; 創世記 21:21"> 示劍告訴他父親哈莫爾說：「求你給我聘娶這個女孩為妻。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 13:22; 利未記 10:3; 撒母耳記上 10:27"> 雅各聽到示劍玷汙了他的女兒狄娜，那時他的兒子們還在田野與他的牲畜在一起，雅各就閉口不言，等他們回來。</span>
<span className="v" id="v6" data-v="6"> 示劍的父親哈莫爾出來，到雅各那裡，要與他商議。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 7:15; 士師記 20:6; 申命記 22:21"> 雅各的兒子們一聽到妹妹的事，就從田野回來，個個痛心，非常惱火，因為示劍對以色列家做了醜惡的事，與雅各的女兒同睡——這樣的事本就不應該做。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 11:2; 詩篇 119:20; 詩篇 84:2"> 哈莫爾與他們商議，說：「我兒子示劍的心愛慕你們家的女兒。請你們把她給我的兒子為妻吧。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:3; 創世記 26:34–35; 創世記 19:14"> 你們與我們通婚吧：你們的女兒，嫁給我們；我們的女兒，你們也可以娶。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:15; 創世記 47:27; 創世記 42:34"> 這樣，你們可以與我們一起居住；這地就在你們面前，住在這裡做買賣，置產業吧！」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 33:15; 創世記 18:3"> 接著示劍對狄娜的父親和她的兄弟們說：「願我在你們眼前蒙恩，無論你們向我索要什麼，我都會給。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 22:16–17; 申命記 22:28–29; 撒母耳記上 18:25–27"> 你們儘管向我多多索要聘金和禮物，我都會照著你們所說的給，只求你們把這少女給我為妻。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 25:27–34; 以賽亞書 59:13; 約伯記 13:4"> 雅各的兒子們因示劍玷汙了他們的妹妹狄娜，就用欺詐的話回答示劍和他父親哈莫爾，</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 23:1–39; 撒母耳記下 15:7; 創世記 17:11"> 對他們說：「把我們的妹妹交給一個未受割禮的人，我們不能做這樣的事，因為這對我們是一種羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:12"> 只有在一個條件下，我們才答應你們，就是你們當中所有的男子都要像我們一樣受割禮。</span>
<span className="v" id="v16" data-v="16"> 這樣，我們就把女兒們嫁給你們，也娶你們的女兒們，並與你們一起居住，成為一族。</span>
<span className="v" id="v17" data-v="17"> 如果你們不肯聽從我們受割禮，我們就要把我們家的女兒帶走。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 他們的說法在哈莫爾和哈莫爾的兒子示劍的眼中都看為好。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:12; 使徒行傳 13:50; 撒母耳記上 22:14"> 那年輕人毫不遲延地去做這事，因為他很喜歡雅各的女兒。他在他父親的全家中最受人尊重。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路得記 4:1; 箴言 31:23; 阿摩司書 5:12"> 於是哈莫爾和他兒子示劍來到城門口，告訴城裡的人說：</span>
<span className="v" id="v21" data-v="21"> 「這些人與我們和平相處，就讓他們在這地居住，在這裡做買賣吧。看哪，這地足夠寬廣，可以容下他們。我們可以娶他們的女兒為妻，也可以把我們的女兒嫁給他們。</span>
<span className="v" id="v22" data-v="22"> 但是只有在一個條件下，這些人才會答應與我們一起居住，成為一族，就是我們當中所有的男子都要受割禮，像他們一樣受割禮。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 約翰福音 6:26–27; 約翰福音 2:16"> 這樣，他們的牲畜、財產和各樣動物，難道不就都成為我們的嗎？只要我們答應他們，他們就與我們一起居住。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 23:10; 哥林多前書 7:19; 以賽亞書 1:10–16"> 所有從城門口出入的人，都聽了哈莫爾和他兒子示劍的話；於是所有從城門口出入的男子，都受了割禮。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 49:5–7; 創世記 29:33–34; 民數記 31:7"> 到了第三天，當他們正疼痛的時候，雅各的兩個兒子，就是狄娜的哥哥西緬和利未，各拿刀劍，在全城毫無戒備的時候進去，把所有的男子都殺了。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 2:26; 申命記 32:42; 以賽亞書 31:8"> 又用刀劍殺了哈莫爾和他的兒子示劍，然後把狄娜從示劍家裡帶走了。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 7:13; 約書亞記 7:21; 出埃及記 2:14"> 雅各的兒子們因那城的人玷汙了他們的妹妹，就來到被殺的人那裡，掠奪那城，</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 1:15–16; 申命記 8:17–18; 約伯記 20:5"> 奪取了他們的羊群、牛群和驢子，以及城中和田間的一切；</span>
<span className="v" id="v29" data-v="29"> 又擄走、掠奪了他們所有的財富、孩童、婦女，以及房屋裡的一切。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 105:12; 約書亞記 7:25; 出埃及記 5:21"> 雅各對西緬和利未說：「你們給我帶來了禍患，使我在這地的居民，就是在迦南人和比利洗人中間，有了臭名。我的人數稀少，如果他們聚集起來對付我、攻擊我，我和我家就會被除滅。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 創世記 34:13; 創世記 49:7"> 他們卻說：「難道他可以把我們的妹妹像妓女一樣對待嗎？」</span>
</div>
</div>

</div>

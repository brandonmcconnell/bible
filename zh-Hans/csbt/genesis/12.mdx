<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:8; 尼希米記 9:7; 使徒行傳 7:2–6"> 耶和華對亞伯蘭說：<br /><span className="pl pl-1">「你當離開你的本土、本族、父家，</span><br /><span className="pl pl-1">往我將要指明你的地去。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 7:9; 創世記 18:18; 加拉太書 3:14"> <span className="pl pl-1">我要使你成為一個大國，</span><br /><span className="pl pl-1">我要祝福你，</span><br /><span className="pl pl-1">使你的名為大；</span><br /><span className="pl pl-1">你也必成為別人的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="別人的——輔助詞語。">a</a></sup><br /><span className="pl pl-1">祝福！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:8; 創世記 22:18; 創世記 27:29"> <span className="pl pl-1">祝福你的，我要祝福他；</span><br /><span className="pl pl-1">詛咒你的，我要詛咒他。</span><br /><span className="pl pl-1">地上萬族都必因你而蒙福。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:8; 創世記 11:31; 創世記 11:27"> 亞伯蘭就照著耶和華吩咐他的去了，羅得也與他同去。亞伯蘭從哈蘭出來的時候年七十五歲。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 14:14; 創世記 11:31; 希伯來書 11:8–9"> 亞伯蘭帶著他的妻子撒萊和他兄弟的兒子羅得，以及他們積蓄的一切財物和他們在哈蘭所得的人，一同出來，往迦南地去。最後他們來到了迦南地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 11:9; 申命記 11:30; 創世記 35:4"> 亞伯蘭在那地穿行，直到示劍地區，到摩利的橡樹那裡。當時迦南人就在那地。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 17:8; 創世記 18:1; 創世記 13:15"> 耶和華向亞伯蘭顯現，說：「我必把這地賜給你的後裔。」亞伯蘭就在那裡為向他顯現的耶和華築了一座祭壇。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:31; 創世記 4:26; 創世記 21:33"> 他又從那裡遷移到伯特利東邊的山地，並支搭帳篷；帳篷的西邊是伯特利，東邊是艾城。他在那裡也為耶和華築了一座祭壇，呼求耶和華的名。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 13:3; 創世記 24:62; 創世記 13:1"> 後來亞伯蘭又起程，繼續往南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音譯作「內蓋夫」。">b</a></sup>去。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 43:1; 創世記 26:1–3; 列王紀上 17:1–18"> 當時那地有饑荒。因為那地的饑荒嚴重，亞伯蘭就下埃及去，要在那裡寄居。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 26:7; 創世記 29:17; 創世記 12:14"> 快要進入埃及時，他對妻子撒萊說：「看哪，我知道你是一個容貌美麗的女人。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 20:11; 創世記 26:7; 約翰一書 1:8–10"> 埃及人看見你的時候，就會說『這是他的妻子』，然後殺了我，卻讓你存活。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 26:7; 創世記 20:12–13; 創世記 20:2"> 請你說你是我的妹妹，好讓我因你的緣故受到善待，我的性命也因你的緣故得以存活。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 6:2; 馬太福音 5:28; 創世記 39:7"> 果然，當亞伯蘭進入埃及時，埃及人看到那女人極其美麗。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 20:2; 創世記 41:1; 列王紀下 18:21"> 法老的群臣看見了，就在法老面前稱讚她；那女人就被帶進法老的宮殿。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 20:14; 創世記 13:2; 創世記 24:35"> 法老因她的緣故善待亞伯蘭；亞伯蘭得了許多羊、牛、公驢、男僕、婢女、母驢和駱駝。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 16:21; 創世記 20:18; 詩篇 105:14–15"> 耶和華因亞伯蘭妻子撒萊的緣故，用嚴重的疾患打擊法老和他的家。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 20:9–10; 創世記 26:9–11; 撒母耳記上 14:43"> 於是法老召來亞伯蘭，說：「你對我做的這是什麼呢？你為什麼不告訴我，她是你的妻子呢？</span>
<span className="v" id="v19" data-v="19"> 你為什麼說『她是我的妹妹』，以致我要娶她為妻呢？現在，你的妻子在這裡，帶她走吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 105:14–15; 箴言 21:1; 出埃及記 18:27"> 於是法老吩咐人，他們就把亞伯蘭和他的妻子以及一切屬於他的都送走了。</span>
</div>
</div>

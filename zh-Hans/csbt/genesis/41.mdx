<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 20:3; 創世記 29:14; 出埃及記 4:9"> 過了整整兩年，法老做了一個夢，夢見自己正站在尼羅河邊。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 19:6"> 看哪！有七頭健美肥壯的母牛從尼羅河裡上來，在蘆葦中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 41:20–21; 創世記 41:4"> 看哪！隨後又有七頭醜陋瘦弱的母牛從尼羅河裡上來，站在河岸上那些母牛旁邊。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:15"> 這些醜陋瘦弱的母牛竟吃掉了那七頭健美肥壯的母牛。法老就醒過來了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:14"> 然後他又睡著，做了第二個夢。看哪！有七個豐碩美好的穗子在一根稈上長起來。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:10; 何西阿書 13:15; 以西結書 19:12"> 看哪！隨後又長出七個被東風吹焦的細弱穗子。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:5; 創世記 20:3"> 這些細弱的穗子竟吞掉了那七個豐碩飽滿的穗子。法老就醒過來了。看哪，原來又是一個夢！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理書 4:7; 出埃及記 7:22; 馬太福音 2:1"> 到了早晨，法老靈裡煩亂，就派人召來了埃及所有的術士和智慧人。法老向他們講述了他的夢，但沒有人能為法老解夢。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 40:14; 創世記 40:23; 創世記 40:1–3"> 那時司酒長對法老說：「我今天想起了我的罪過。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 39:20; 創世記 40:2–3; 創世記 37:36"> 法老曾對臣僕發怒，把我和司膳長關在護衛長府中的牢裡。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 40:5–8"> 在同一夜，我和他都做了夢，各夢各有其解。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 40:12–19; 創世記 37:36; 創世記 39:1"> 在那裡有一個希伯來少年與我們在一起，是護衛長的奴僕。我們把夢向他講述，他就照著我們各自的夢分別為我們解夢。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 43:3; 創世記 40:20–22; 創世記 40:12"> 後來，事情正是像他給我們解釋的那樣發生了：法老使我官復原位，卻把司膳長掛了起來。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 2:25; 詩篇 113:7–8; 詩篇 105:19–22"> 於是法老派人去召約瑟，他們就急忙把他從地牢裡帶出來。他剃頭刮臉，更換衣服，來到法老面前。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:16; 但以理書 5:12; 詩篇 25:14"> 法老對約瑟說：「我做了一個夢，但無人能解。我聽人說，你聽了夢就能解。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 3:5; 創世記 40:8; 但以理書 2:47"> 約瑟就回答法老，說：「不是我，是神要回應法老，關乎法老的平安。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 法老對約瑟說：「在夢裡，看哪！我正站在尼羅河岸。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 24:8; 耶利米書 24:1–3; 耶利米書 24:5"> 看哪！有七頭肥壯健美的母牛從尼羅河裡上來，在蘆葦中吃草。</span>
<span className="v" id="v19" data-v="19"> 看哪！隨後又有七頭衰弱、乾瘦、甚醜的母牛上來；我在埃及全地沒有見過像牠們那樣醜的。</span>
<span className="v" id="v20" data-v="20"> 這些乾瘦醜陋的母牛竟吃掉了先前那七頭肥壯的母牛；</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 3:3; 詩篇 37:19; 啟示錄 10:9–10"> 雖然吃進了肚子，卻看不出已經吃進去了，因為牠們醜陋的樣子仍與先前一樣。我就醒了。</span>
<span className="v" id="v22" data-v="22"> 在夢裡我又觀看，看哪！有七個飽滿美好的穗子在一根稈上長起來。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 129:6–7; 何西阿書 13:15; 列王紀下 19:26"> 看哪！隨後又長出七個被東風吹焦的細弱枯槁的穗子。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 4:7; 創世記 41:8; 出埃及記 8:19"> 這些細弱的穗子竟吞掉了那七個美好的穗子。我告訴了術士們，但無人能給我解釋。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="但以理書 2:45; 啟示錄 4:1; 以弗所書 1:17"> 約瑟就對法老說：「法老的兩個夢原是一個，神已經把所要做的事告訴法老了。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 41:47; 創世記 41:2; 創世記 41:53"> 七頭美好的母牛是七年，而七個美好的穗子也是七年。兩個夢原是一個。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 8:1; 撒母耳記下 24:19"> 那隨後上來的七頭乾瘦醜陋的母牛是七年，那七個被東風吹焦的空癟穗子也是七年，都是七個荒年。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 41:25; 創世記 41:16"> 「這就是我對法老說的：神已經把所要做的事向法老顯明了。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 41:26; 創世記 41:46–47; 創世記 41:49"> 看哪！七個大豐年必臨到埃及全地；</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:13; 創世記 41:54; 雅各書 5:17"> 隨後七個荒年就來臨，埃及地先前一切的豐收將被遺忘，饑荒必毀滅這地。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 24:20; 撒母耳記上 5:6"> 那地先前的豐收一點也看不出來，因為隨後而來的饑荒極其嚴重。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 23:19; 以賽亞書 46:10–11; 以賽亞書 14:24–27"> 至於同一個夢向法老重複了兩次，是因為這事已被神命定，神必快速實施。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 41:39; 使徒行傳 6:3; 申命記 1:13"> 「現在，請法老選一個有悟性有智慧的人，委任他管理埃及地。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 請法老付諸實施，指派監督們管理這地，在七個豐年中，徵收埃及地收成的五分之一。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 45:6–7; 創世記 41:56; 出埃及記 4:13"> 讓他們收集將來豐年中的一切餘量，把穀物積蓄在法老手下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="把穀物積蓄在法老手下——或譯作「由法老授權積蓄穀物」。">a</a></sup>，作為各城的糧食，妥善保管。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 47:13–25"> 這些糧食是為了將臨到埃及地的七個荒年而儲備的，免得這地被饑荒所滅。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 7:10; 列王紀上 21:2; 撒母耳記下 3:36"> 這提議在法老和他所有臣僕的眼中都看為好。</span>
<span className="v" id="v38" data-v="38" data-xref="約伯記 32:8; 但以理書 5:14; 民數記 27:18"> 法老對他的臣僕說：「像他這樣的人，有神的靈在他裡面，我們還能找得到嗎？」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 41:33; 創世記 41:28; 創世記 41:25"> 於是法老對約瑟說：「既然神把這一切都向你顯明了，就沒有像你這樣有悟性有智慧的人了。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行傳 7:10; 詩篇 105:21–22"> 你要管理我的家；我所有的子民都要順從你的話；只有在寶座上的我比你大。」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 28:18; 腓立比書 2:9–11; 創世記 42:6"> 法老又對約瑟說：「你看，我已經委派你管理埃及全地。」</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 5:29; 但以理書 5:7; 以斯帖記 3:10"> 然後法老從自己手上取下印戒，戴在約瑟手上，給他穿上細麻衣，把金鏈戴在他的脖子上；</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 7:10; 創世記 45:8; 創世記 45:26"> 又讓約瑟乘自己的副車，喝道的在約瑟前面向人呼喊：「跪下！」這樣，法老委派他管理埃及全地。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 105:22; 出埃及記 11:7"> 法老對約瑟說：「我是法老，但在埃及全地，沒有你的許可<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的許可——輔助詞語。">b</a></sup>，誰也不能擅自行事<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="擅自行事——原文直譯「抬手抬腳」。">c</a></sup>。」</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 46:20; 以西結書 30:17; 出埃及記 2:16"> 法老給約瑟起名為撒發那特·巴內亞，又把安城祭司波提·非拉的女兒婭希納給他為妻。約瑟就出去管理埃及地。</span>
<span className="v" id="v46" data-v="46" data-xref="但以理書 1:19; 列王紀上 12:6; 撒母耳記上 16:21"> 約瑟侍立在埃及王法老面前的時候，年三十歲。約瑟從法老面前出去，遍行埃及全地。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="創世記 26:12; 詩篇 72:16"> 在那七個豐年中，地的出產極其豐盛，</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 41:34–36; 創世記 47:21"> 約瑟把臨到埃及地那七年的一切餘量都收集起來，把它們存放在各城中；各城周圍田地的餘量，他都存放在該城中。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 78:27; 士師記 6:5; 創世記 22:17"> 約瑟積蓄的穀物極其多，如海沙那樣，實在無法數算，以致他停止了計量。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="創世記 46:20; 創世記 48:5; 撒母耳記下 8:18"> 荒年未到以前，安城的祭司波提·非拉的女兒婭希納為約瑟生了兩個兒子。</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 30:5; 箴言 31:7; 申命記 33:17"> 約瑟給長子起名為瑪拿西，因為他說<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他說——輔助詞語。">d</a></sup>：「神使我忘了我一切的苦難和我父的全家。」</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 49:22; 創世記 50:23; 創世記 17:6"> 他給第二個兒子起名為以法蓮，因為他說<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他說——輔助詞語。">e</a></sup>：「神使我在受苦之地繁盛。」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="創世記 41:29–31; 詩篇 73:20; 路加福音 16:25"> 埃及地的七個豐年一結束，</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 45:11; 使徒行傳 7:11; 詩篇 105:16"> 七個荒年就隨著來了，正如約瑟所說的。各地都有饑荒，但埃及全地還有糧食。</span>
<span className="v" id="v55" data-v="55" data-xref="馬太福音 17:5; 馬太福音 3:17; 耶利米書 14:1–6"> 當埃及全地也有饑荒時，百姓就向法老哀求糧食。法老對所有的埃及人說：「你們到約瑟那裡去，他對你們怎麼說，你們就怎麼做。」</span>
<span className="v" id="v56" data-v="56" data-xref="創世記 42:6; 撒迦利亞書 5:3; 路加福音 21:35"> 那時饑荒遍及了整個地面。約瑟打開了各處的糧倉，售糧給埃及人，因為埃及地的饑荒非常嚴重。</span>
<span className="v" id="v57" data-v="57" data-xref="創世記 41:54; 創世記 42:5; 創世記 41:56"> 各地的人都來到埃及，向約瑟買糧，因為各地的饑荒都非常嚴重。</span>
</div>
</div>

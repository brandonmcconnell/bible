<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:15; 使徒行傳 10:41; 創世記 43:30–31"> 約瑟在所有侍立左右的人面前，再也克制不住自己，大聲喊：「所有人都離開我出去！」當約瑟向兄弟們表明自己是誰時，沒有人站在他身邊。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 46:29; 使徒行傳 20:37; 民數記 14:1"> 他就放聲大哭；埃及人聽到了，法老一家也聽到了這事。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 7:13; 使徒行傳 9:5; 撒迦利亞書 12:10"> 約瑟對他的兄弟們說：「我是約瑟！我的父親還活著嗎？」他的兄弟們卻不能回答他，因為他們在他面前都很惶恐。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 37:28; 馬太福音 14:27; 創世記 50:18"> 約瑟對他的兄弟們說：「請你們靠近我一些！」他們就靠近一些。他說：「我是你們的兄弟約瑟，就是被你們賣到埃及的約瑟。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 50:20; 使徒行傳 7:9–15; 創世記 45:7–8"> 現在，不要因你們把我賣到這裡而自憂自恨；要知道，是神在你們之前派遣了我，為要拯救生命。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 47:23; 創世記 41:54; 創世記 41:56"> 如今，這地已經有兩年的饑荒，還會有五年既沒有耕種，也沒有收成。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:4; 使徒行傳 7:35; 詩篇 18:50"> 神在你們之前派遣了我，為要在地上給你們存留餘種，並要大施解救，使你們得以存活<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="並要大施解救，使你們得以存活——或譯作「使你們有眾多的倖存者活下來」。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:16; 羅馬書 9:16; 約翰福音 19:11"> 這樣看來，派遣我到這裡來的，不是你們，而是神。他立我作法老之父，作他全家之主，又作埃及全地的管轄者。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 45:19–20; 創世記 45:13"> 「你們趕快上到我父親那裡去，對他說：『你的兒子約瑟這樣說：「神立我作了全埃及的主；請你下到我這裡來，不要耽延。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 9:26; 出埃及記 8:22; 創世記 46:34–6"> 你和你的眾兒孫、你的羊群、牛群，以及一切屬於你的，都可以住在歌珊地，在我的附近。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:12; 創世記 47:6; 馬太福音 15:5–6"> 我要在那裡供應你，免得你和你的家人，以及一切屬於你的，都陷入窮困，因為還會有五年的饑荒。」』</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:23; 路加福音 24:39; 約翰福音 20:27"> 看哪，你們的眼睛和我弟弟便雅憫的眼睛都看見了，是我在親口對你們說話。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:14; 啟示錄 21:23; 彼得前書 1:10–12"> 你們要把我在埃及的一切尊榮，以及你們所看見的一切，都告訴我的父親；趕快請我父親下到這裡來。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 33:4; 創世記 29:11; 創世記 46:29"> 然後約瑟就伏在他弟弟便雅憫的脖子上哭泣，便雅憫也在約瑟的脖子上哭泣。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳記上 10:1; 詩篇 77:4"> 約瑟又親吻了所有的兄弟，在他們身上哭泣。此後，他的兄弟們就與他交談。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 41:33; 以斯帖記 1:21; 創世記 20:15"> 約瑟的兄弟們到來的消息傳到法老的宮殿裡；這在法老和他的臣僕眼中都看為好。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 42:25–26; 創世記 44:1–2"> 法老對約瑟說：「你要對你的兄弟們說，『當這樣做：把牲畜馱好，回到迦南地去；</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:28; 民數記 18:12; 創世記 47:6"> 帶上你們的父親和你們的家人，到我這裡來；我要把埃及地的美物賜給你們，你們也要吃這地上最好的。』</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 46:5; 創世記 45:27; 創世記 31:17–18"> 現在你要受命去說：『當這樣做：從埃及地帶上車輛，給你們的孩童和妻子坐，並且帶著你們的父親一起來。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 1:19; 路加福音 17:31; 申命記 7:16"> 你們的眼目不要顧惜你們的家什，因為埃及全地的美物都是你們的。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 45:19; 以西結書 23:24; 耶利米哀歌 1:18"> 以色列的兒子們就這樣做了。約瑟照著法老的吩咐，給了他們車輛和路上用的食物，</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 43:34; 列王紀下 5:5; 士師記 14:12"> 又給了每個哥哥一人一套更換的衣服，卻給了便雅憫三百錠銀子和五套服裝；</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:10; 出埃及記 16:3; 創世記 43:11"> 約瑟送給他父親公驢十頭，馱著埃及的美物；母驢十頭，馱著穀物、餅，以及他父親路上用的食物。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:13; 詩篇 133:1–3; 創世記 42:21–22"> 於是，約瑟打發他的兄弟們走；他們離開的時候，約瑟對他們說：「你們在路上不要爭吵。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他們就從埃及上去，來到迦南地他們的父親雅各那裡。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 44:28; 創世記 37:35; 路加福音 24:34"> 他們告訴他說：「約瑟還活著，而且作了埃及全地的管轄者。」雅各的心驚呆了，因為他簡直不能相信他們。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 85:6; 以賽亞書 57:15; 創世記 45:19"> 他們就把約瑟對他們所說的一切話都告訴了他。當他們的父親雅各看見約瑟派來接他的車輛時，他的靈就甦醒了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 約翰福音 16:21–22; 創世記 46:30"> 以色列說：「好，我的兒子約瑟還活著！在我死之前，我要去見他。」</span>
</div>
</div>

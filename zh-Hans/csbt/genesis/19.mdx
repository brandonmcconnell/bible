<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:22; 創世記 18:1–5; 希伯來書 13:2"> 那兩位天使在傍晚來到所多瑪；當時羅得正坐在所多瑪城門口。羅得一見他們，就起身迎接，臉伏於地下拜，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 18:4; 路加福音 24:28–29; 希伯來書 13:2"> 說：「我主啊，請轉往你們的僕人家裡過夜，洗洗你們的腳，清早起來再上路。」<br />他們卻說：「不，我們就在廣場上過夜。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 18:6–8; 士師記 6:19; 撒母耳記上 28:24"> 但羅得極力勸說他們，他們才轉往他那裡，進了他的家。羅得為他們預備宴席，烤了無酵餅，他們就吃了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 13:13; 箴言 4:16; 出埃及記 23:2"> 他們還沒有躺下睡覺，那城裡的人，就是所多瑪的男人，無論老少，所有人都從各處來圍住了羅得的屋子。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 以賽亞書 3:9; 猶大書 1:7"> 他們向羅得呼叫，說：「今夜到你這裡來的那些男人在哪裡呢？把他們給我們帶出來，好讓我們與他們同寢！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 19:23"> 羅得就出去，到門口眾人那裡，並把身後的門關上，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 6:9–11; 士師記 19:23; 利未記 20:13"> 說：「我的兄弟們，請你們不要這樣作惡。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 19:24; 創世記 19:31–38; 士師記 9:15"> 看哪，我有兩個女兒，還沒有與男人同寢，容我把她們帶出來給你們，你們看怎樣好，就怎樣對待她們吧。只是不要對這兩個人做什麼，因為他們來到了我屋簷的蔭庇下。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:14; 彼得後書 2:7–8; 創世記 13:12"> 但他們說：「滾開！」又說：「這人來寄居，竟然把自己當成審判官了！我們要惡待你，比惡待他們更厲害。」於是他們極力推擠羅得，上前要破門而入。</span>
<span className="v" id="v10" data-v="10"> 那兩個人就伸出手，把羅得拉進屋內他們那裡，並把門關上。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:18; 使徒行傳 13:11; 申命記 28:28–29"> 他們又打擊屋門口的那些人，使他們無論老少都眼目失明，以致他們找不到門<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="找不到門——原文直譯「找門找得疲憊不堪」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 7:1; 彼得後書 2:7; 啟示錄 18:4"> 那兩個人對羅得說：「你在這裡還有什麼人嗎？比如你的女婿、兒女，或是城中任何屬於你的人，你都要從這地方帶出去，</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 18:20; 馬太福音 13:49–50; 猶大書 1:7"> 因為我們就要毀滅這地方了；要知道，控告他們的呼聲在耶和華面前極大，耶和華就派我們來毀滅這城。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 16:21; 耶利米書 51:6; 民數記 16:45"> 羅得就出去，告訴將要娶他女兒的女婿們說：「起來！離開這地方，因為耶和華就要毀滅這城了！」但在他們的眼中，他像是在開玩笑。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 16:24–27; 啟示錄 18:4; 創世記 19:22"> 天亮的時候，天使們催促羅得說：「起來！帶著你的妻子和你在這裡的兩個女兒離開，免得你因這城的罪孽被一同除滅。」</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:15–16; 提多書 3:5; 約翰福音 6:44"> 羅得還在猶豫，那兩個人因耶和華憐恤羅得就抓住他的手，以及他妻子和兩個女兒的手，把他們領出來，安置在城外面。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 24:16–18; 路加福音 9:62; 腓立比書 3:13–14"> 那兩個人把他們領到外面以後，其中一位說：「逃命吧！不要向後看，也不要在周邊地區的任何一處停留；要逃到山上，免得你被除滅。」</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 13:6–8; 使徒行傳 10:14; 創世記 32:26"> 羅得對他們說：「我主啊，請不要這樣。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 27:1; 詩篇 103:1–22; 提摩太前書 1:14–16"> 看哪，你的僕人在你眼前已經蒙了恩，你向我大施慈愛，使我的性命得以存活。不過，我不能逃到山上；恐怕這災禍追上我，我就死了。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 119:175; 箴言 3:5–7; 創世記 19:30"> 看哪，這城足夠近，我能逃到那裡，而且它只是個小地方——它不是一個小地方嗎？請讓我逃到那裡去，使我的性命得以存活。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="詩篇 145:19; 詩篇 34:15; 詩篇 102:17"> 天使對他說：「看哪，這事我也答應你，不會傾覆你所說的這城。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 13:10; 創世記 14:2; 創世記 32:25–28"> 你趕快逃到那裡，因為你到達那裡之前，我什麼也不能做。」因此那城名叫瑣珥。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 羅得到達瑣珥的時候，太陽已經升出地面。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 29:23; 以賽亞書 13:19; 阿摩司書 4:11"> 那時，耶和華就使硫磺與火從天而降，從耶和華那裡降在所多瑪和格摩拉，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 107:34; 創世記 14:3; 創世記 13:10"> 使那些城和整個周邊地區，連同各城所有的居民和地上生長的都遭覆滅。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 創世記 19:17; 箴言 14:14"> 羅得的妻子在後面回頭一望，就變成了一根鹽柱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哈巴谷書 2:1; 詩篇 5:3; 希伯來書 2:1"> 亞伯拉罕清早起來，到了他曾在耶和華面前站立的地方。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 18:9; 啟示錄 9:2; 啟示錄 21:8"> 他俯看所多瑪和格摩拉，以及周邊地區的整個地面；看哪，只見那地有煙上騰，像窯爐的煙那樣！</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 8:1; 申命記 9:5; 創世記 18:23–33"> 當神毀滅周邊地區的眾城、傾覆羅得住過的各城時，神記念亞伯拉罕，將羅得從覆滅中帶出來。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:19; 以賽亞書 15:5; 雅各書 1:8"> 羅得因為怕住在瑣珥，就與兩個女兒離開瑣珥上了山，住在山上。他和兩個女兒住在一個洞穴裡。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 25:5; 以賽亞書 4:1; 創世記 16:2"> 大女兒對小女兒說：「我們的父親老了，這地又沒有男人照著世上的常理與我們同房。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 18:6–7; 創世記 11:3; 創世記 9:21"> 來吧！讓我們給父親喝酒，然後與他同睡，好藉著我們的父親存留後裔！」</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷書 2:15–16; 箴言 23:29–35; 箴言 20:1"> 於是那天夜裡她們給父親喝酒，然後大女兒進去，與父親同睡。她什麼時候躺下，什麼時候起來，父親都不知道。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米書 8:12; 耶利米書 6:15; 以賽亞書 3:9"> 第二天，大女兒對小女兒說：「看哪，昨夜我與父親同睡了！今夜我們再給他喝酒，然後你進去與他同睡，好藉著我們的父親存留後裔！」</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 詩篇 8:4; 彼得前書 4:7"> 那天夜裡她們又給父親喝酒，然後小女兒起來，與他同睡。她什麼時候躺下，什麼時候起來，父親都不知道。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哈巴谷書 2:15; 士師記 1:7; 馬太福音 7:2"> 這樣，羅得的兩個女兒都藉著她們的父親懷了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 2:9; 列王紀下 3:1–27; 民數記 21:29"> 大女兒生了一個兒子，給他起名為摩押，他就是今天摩押人的始祖。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 2:19; 士師記 10:6–40; 詩篇 83:4–8"> 至於小女兒，她也生了一個兒子，給他起名為便亞米，他就是今天亞捫子孫的始祖。</span>
</div>
</div>

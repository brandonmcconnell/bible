<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="30" data-verses="43">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約伯記 5:2; 創世記 29:31; 創世記 37:11"> 拉結見自己沒有為雅各生孩子，就嫉妒她的姐姐，對雅各說：「你給我孩子！不然我就死了。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="創世記 16:2; 詩篇 127:3; 列王紀下 5:7"> 雅各的怒氣就向拉結發作，說：「我難道能代替神嗎？是他不讓你腹中有胎兒。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 50:23; 約伯記 3:12; 路得記 4:11"> 拉結就說：「我的女僕碧拉在這裡，你與她同房，使她生孩子歸於我膝下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="生孩子歸於我膝下——原文直譯「生在我的膝上」。">a</a></sup>，好讓我藉著她立後<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="立後——原文直譯「被建立」。">b</a></sup>。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 創世記 21:10; 撒母耳記下 12:11"> 於是拉結把她的婢女碧拉給雅各作妾，雅各就與她同房。</span>
<span className="v" id="v5" data-v="5"> 碧拉懷孕，為雅各生了一個兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 詩篇 35:24; 詩篇 43:1"> 拉結說：「神為我伸了冤，他確實垂聽我的聲音，賜給了我一個兒子。」因此給孩子起名為但。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 拉結的婢女碧拉又懷孕，為雅各生了第二個兒子。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:24–25; 創世記 23:6; 創世記 49:21"> 拉結就說：「我與姐姐大大地相爭，並且得勝了。」於是給孩子起名為拿弗他利。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 30:4; 創世記 30:17; 創世記 29:35"> 莉亞見自己停止了生育，就把自己的婢女悉帕帶來給雅各作妾。</span>
<span className="v" id="v10" data-v="10"> 莉亞的婢女悉帕也為雅各生了一個兒子。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 49:19; 以賽亞書 65:11; 創世記 35:26"> 莉亞就說：「幸運來臨！」於是給孩子起名為迦得。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 後來莉亞的婢女悉帕又為雅各生了第二個兒子。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 莉亞說：「我真有福啊！眾女子都會稱我有福。」於是給孩子起名為亞設。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 創世記 25:30"> 在收割小麥的日子裡，魯本出去，在田野中找到一些風茄，就把它們帶回來給他母親莉亞。拉結對莉亞說：「請把你兒子的風茄給我一些。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 16:13; 哥林多前書 4:3; 民數記 16:9–10"> 莉亞對她說：「難道你奪取了我丈夫還不夠，又要奪取我兒子的風茄嗎？」<br />拉結說：「那好，為了換取你兒子的風茄，今夜他可以與你同睡。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了傍晚，雅各從田野回來的時候，莉亞就出來迎接他，說：「你要與我同房，因為我用我兒子的風茄著著實實雇下了你。」那一夜，雅各就與她同睡。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 30:6; 創世記 30:22; 出埃及記 3:7"> 神聽允了莉亞，她就懷孕，為雅各生了第五個兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 49:14–15; 申命記 33:18; 創世記 46:13"> 莉亞說：「神給了我賞報，因為我把自己的婢女給了我的丈夫。」於是給孩子起名為以薩迦。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 莉亞又懷孕，為雅各生了第六個兒子。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 35:23; 馬太福音 4:13; 創世記 49:13"> 莉亞說：「神賜給了我美好的禮物，這次我丈夫必重視我<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="必重視我——或譯作「必與我同住」。">c</a></sup>，因為我為他生了六個兒子。」於是給孩子起名為西布倫。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:1–3; 創世記 34:26; 創世記 46:15"> 後來莉亞生了一個女兒，給她起名為狄娜。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 29:31; 詩篇 113:9; 詩篇 127:3"> 神也記念拉結，聽允了她，使她能生育<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使她能生育——原文直譯「開了她的胎」。">d</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 創世記 29:31; 路加福音 1:27"> 拉結懷孕，生了一個兒子，就說：「神除去了我的羞辱。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:22–26; 創世記 35:24; 創世記 37:2"> 於是給孩子起名為約瑟，說：「願耶和華再給我增添一個兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 24:54; 創世記 24:56; 創世記 28:15"> 拉結生了約瑟以後，雅各就對拉班說：「請打發我走吧，讓我回到自己的地方、自己的故土！</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 29:30; 何西阿書 12:12; 創世記 31:26"> 請把我的妻子們和孩子們給我——為了他們，我服事了你；讓我走吧！我怎樣服事你，你是知道的。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路得記 2:13; 使徒行傳 7:10; 以賽亞書 61:9"> 拉班對他說：「如果我在你眼前蒙恩，就請留下<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就請留下——輔助詞語。">e</a></sup>；我占卜得知，耶和華是因你的緣故才祝福我的。」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 29:15; 創世記 29:19"> 又說：「請你定你的工酬吧，我必給你。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 31:6; 創世記 31:38–40; 彼得前書 2:18"> 雅各就對他說：「我怎樣服事你，你的牲畜在我這裡怎樣，你是知道的。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前書 5:8; 哥林多後書 12:14; 申命記 11:10"> 其實在我來之前，你擁有的很少，後來卻大大增多了；耶和華隨著我的腳蹤祝福了你；而如今，我什麼時候才能為自己的家做點事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 21:4–6; 希伯來書 13:5; 詩篇 118:8"> 拉班說：「我該給你什麼呢？」<br />雅各說：「你什麼也不必給我；只要你答應我一件事<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="答應我一件事——原文直譯「為我做一件事」。">f</a></sup>，我就繼續放牧、看守你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 31:8; 創世記 31:10; 創世記 30:35"> 請讓我今天走遍你的羊群，從中挑出全部有點、有斑的羊，綿羊羔中全部黑色的，山羊中有斑、有點的，作為我的工酬。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 13:14; 撒母耳記下 22:21; 撒母耳記上 26:23"> 日後你來查看我所得的工酬時，要是我這裡的山羊中有任何一隻不是有點、有斑的，綿羊羔中有任何一隻不是黑色的，就算是我偷來的。這樣我的公義就為我辯護了。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 7:7; 民數記 22:29; 哥林多前書 14:5"> 拉班說：「好，就照著你說的！」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="創世記 31:9"> 然而就在那一天，拉班挑出了有紋、有斑的公山羊，以及全部有點、有斑和摻雜白色的母山羊，還有全部黑色的綿羊羔，都交在自己兒子們的手中；</span>
<span className="v" id="v36" data-v="36"> 又使自己和雅各之間相距三天的路程。雅各就放牧拉班其餘的羊群。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="創世記 31:9–13; 以西結書 31:8"> 雅各拿楊樹、杏樹和楓樹的嫩枝，剝出白色條紋，使枝子露出白色部分。</span>
<span className="v" id="v38" data-v="38"> 然後他把剝好的枝子插在水槽——羊群來喝水的槽裡，對著羊群。羊來喝水的時候，彼此交配。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 12:35–36; 創世記 31:9–12; 創世記 31:40"> 羊在枝子前面交配，就生下有紋、有點、有斑的。</span>
<span className="v" id="v40" data-v="40"> 雅各就把綿羊羔分出來，又使羊群面向拉班羊群中有紋的和全部黑色的；他把自己的羊群另放一處，不放在拉班的羊群中。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41"> 每當比較肥壯的羊交配時，雅各就把枝子插在水槽裡，就在羊的眼前，使牠們在枝子那裡交配。</span>
<span className="v" id="v42" data-v="42"> 而當瘦弱的羊交配的時候，他就不插枝子。這樣，瘦弱的就歸拉班，肥壯的就歸雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:35; 創世記 30:30; 創世記 26:13–14"> 於是雅各變得極其昌盛，擁有許多羊群、婢女、男僕、駱駝和驢子。</span>
</div>
</div>

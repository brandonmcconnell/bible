<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:17; 雅各書 2:21; 申命記 8:2"> 這些事以後，神試驗亞伯拉罕，對他說：「亞伯拉罕！」<br />他說：「我在這裡！」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約翰福音 3:16; 羅馬書 8:32; 希伯來書 11:17"> 神說：「帶上你的兒子，就是你所愛的獨生子以撒，往摩利亞地去；在我將要指示你的山上，把他獻為燔祭。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="詩篇 119:60; 馬太福音 10:37; 路加福音 14:26"> 亞伯拉罕清早起來，給自己的驢子備好鞍，帶上他的兩個僕人和他的兒子以撒。他劈好了燔祭用的木柴，就起身往神指示他的地方去。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 馬太福音 17:23; 何西阿書 6:2"> 到了第三天，亞伯拉罕舉目，從遠處看見了那地方。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:19; 希伯來書 12:1"> 亞伯拉罕對他的僕人們說：「你們和驢子留在這裡吧，我和這少年要到那裡去敬拜<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="敬拜——原文直譯「下拜」。">a</a></sup>，然後再回到你們這裡來。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:17; 彼得前書 2:24; 以賽亞書 53:6"> 亞伯拉罕拿起燔祭用的木柴，放在他兒子以撒身上，自己手中拿著火和刀；他們兩人就一同前行。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:15; 馬太福音 26:39; 創世記 8:20"> 以撒對父親亞伯拉罕說：「父親哪！」<br />亞伯拉罕說：「我兒啊，我在這裡！」<br />以撒說：「看哪，火和木柴都有了，但燔祭用的羔羊在哪裡呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:36; 約翰福音 1:29; 啟示錄 5:12"> 亞伯拉罕說：「我兒啊，神必親自預備燔祭用的羔羊！」他們兩人就一同前行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各書 2:21; 希伯來書 11:17–19; 腓立比書 2:7–8"> 他們來到神所指示他的地方，亞伯拉罕在那裡築了一座祭壇，擺好木柴，然後捆綁了他的兒子以撒，把他放在祭壇的木柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 2:21–23; 希伯來書 11:17–19; 以賽亞書 53:6–12"> 亞伯拉罕就伸手拿刀，要宰殺自己的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 21:17; 出埃及記 3:4; 創世記 16:9–10"> 這時耶和華的使者從天上向他呼喚，說：「亞伯拉罕！亞伯拉罕！」<br />他說：「我在這裡！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="雅各書 2:21–22; 雅各書 2:18; 撒母耳記上 15:22"> 使者說：「不可向這少年下手，什麼也不可對他做！現在我知道你是敬畏神的，因為你沒有把你的兒子，就是你的獨生子，留下不給我。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:13; 詩篇 40:6–8; 哥林多後書 1:9–10"> 亞伯拉罕舉目觀看，看哪，身後有一隻公綿羊，犄角被灌木叢纏住了！亞伯拉罕就走過去，取了那隻公綿羊，代替自己的兒子獻為燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:13; 出埃及記 17:15; 創世記 22:8"> 亞伯拉罕給那地方起名為「耶和華以勒」；因此直到今日，人們還說：「在耶和華的山上必有預備<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="必有預備——或譯作「他會顯現」。">b</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的使者第二次從天上向亞伯拉罕呼喚，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 6:13–14; 路加福音 1:73; 詩篇 105:9"> 說：「耶和華宣告：我指著自己起誓，你既然做了這事，沒有留下你的兒子，就是你的獨生子，</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:5; 創世記 24:60; 耶利米書 33:22"> 我必定大大祝福你，使你的後裔大大增多，如同天上的星、海邊的沙；你的後裔必占有仇敵的城門。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 3:25; 創世記 12:3; 加拉太書 3:16"> 地上萬國都必因你的後裔而蒙福，因為你聽從了我的話。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 21:31; 士師記 20:1; 約書亞記 15:28"> 然後亞伯拉罕回到他的僕人們那裡，他們就起身一同往比爾-謝巴去。亞伯拉罕住在比爾-謝巴。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 11:29; 創世記 24:24; 箴言 25:25"> 這些事以後，有人告訴亞伯拉罕說：「看哪，米爾卡為你兄弟拿鶴生了兒子：</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 1:1; 約伯記 32:2; 詩篇 60:1–12"> 長子是烏斯，他的弟弟是布斯和亞蘭的父親基姆利，</span>
<span className="v" id="v22" data-v="22"> 還有基瑟德、哈瑣、皮珥達、益拉和彼土利。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:15; 創世記 28:5; 創世記 24:51"> 彼土利生了莉百加。米爾卡為亞伯拉罕的兄弟拿鶴生了這八個兒子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="兒子——輔助詞語。">c</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:3; 創世記 25:6; 箴言 15:25"> 拿鶴的妾名叫琉瑪，她生了特巴、迦含、塔哈斯和瑪迦。</span>
</div>
</div>

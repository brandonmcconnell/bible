<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 31:13; 何西阿書 12:4; 詩篇 91:15"> 神對雅各說：「起來，上伯特利去，住在那裡；你要在那裡造一座祭壇給神——他是你逃避你哥哥以掃的時候曾向你顯現的那一位。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:14; 出埃及記 19:10; 以西結書 18:31"> 雅各就對他的家人以及所有與他在一起的人說：「你們要除掉你們中間的外邦神像，並要潔淨自己，更換你們的衣服。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 43:2; 創世記 32:7; 創世記 31:3"> 讓我們起來，上伯特利去，在那裡我要造一座祭壇給神；他就是在我患難的日子回應我，在我所行的路上與我同行的那一位。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 9:6; 申命記 7:25; 出埃及記 32:20"> 於是他們把自己手中所有的外邦神像和自己耳朵上的環子都交給雅各；雅各把它們埋藏在示劍附近的橡樹底下。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 23:27; 歷代志下 17:10; 約書亞記 5:1"> 然後他們起程了。神使周圍城邑的人都感到恐懼，因此他們就不追趕雅各的兒子們。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 28:19; 創世記 28:22; 創世記 12:8"> 這樣，雅各和所有與他一起的人都來到迦南地的路斯，就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:13"> 他在那裡築了一座祭壇，稱那地方為伊利-伯特利，因為他逃避他哥哥的時候，神曾在那裡向他顯現。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 24:59; 撒母耳記上 31:13; 士師記 2:5"> 莉百加的乳母底波拉死了，埋葬在伯特利下邊的橡樹底下，所以雅各給那棵樹起名為亞倫-巴古。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="創世記 35:1; 創世記 18:1; 創世記 26:2"> 自雅各從帕旦-亞蘭回來後，神再次向他顯現，祝福了他。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:5; 創世記 32:27–28; 創世記 17:15"> 神對他說：<br /><span className="pl pl-1">「你的名字是雅各，</span><br /><span className="pl pl-1">但今後不要再叫雅各了，</span><br /><span className="pl pl-1">你的名字要叫以色列。」</span><br />這樣，神就給他起名為以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:1; 創世記 9:1; 創世記 22:17"> 神又對他說：<br /><span className="pl pl-1">「我是全能的神；</span><br /><span className="pl pl-1">你要繁衍增多；</span><br /><span className="pl pl-1">必有一國和眾邦之國從你而來，</span><br /><span className="pl pl-1">眾君王也必從你生出。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:7; 創世記 28:13; 創世記 26:3–4"> <span className="pl pl-1">我所賜給亞伯拉罕和以撒的土地，我必賜給你；</span><br /><span className="pl pl-1">我也要把這地賜給你的後裔。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 17:22; 創世記 18:33; 士師記 6:21"> 然後神就從那與雅各說話的地方上升而去，離開了他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 28:18–19; 撒母耳記上 7:12; 出埃及記 17:15"> 雅各在神與他說話的地方立了一根柱子作為石碑，在上面澆奠了酒祭，又澆了油。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 28:19"> 雅各給神與他說話的那地方起名為伯特利。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="彌迦書 5:2; 創世記 48:7; 列王紀下 5:19"> 他們從伯特利起程，離以法他還有一段路程的時候，拉結臨產了，而且是難產。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:24; 撒母耳記上 4:19–21"> 在她難產的時候，接生婆對她說：「不要害怕，你這次又要有一個兒子了！」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行傳 7:59; 路加福音 23:46"> 她的靈魂快要出竅，她快死的時候，給兒子起名為便俄尼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="便俄尼——意思是「在我患難中的兒子」。">a</a></sup>，他父親卻稱他為便雅憫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="便雅憫——意思是「右手的兒子」。">b</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 5:2; 創世記 48:7; 路得記 4:11"> 拉結死了，埋葬在通往以法他的路上；以法他就是伯利恆。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 10:2; 創世記 35:14; 撒母耳記下 18:17–18"> 雅各在她的墳墓上立了一根石柱，這就是拉結的墓碑，直到今日。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="彌迦書 4:8; 路加福音 2:8"> 以色列又起程前行，在伊德高臺的那一邊支搭帳篷。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 5:1; 利未記 18:8; 撒母耳記下 20:3"> 以色列在那地居住的時候，魯本去與他父親的小妾碧拉同睡；以色列也聽到了這事。<br />雅各有十二個兒子：</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 30:18–20; 創世記 46:8–15; 創世記 29:32–35"> <span className="pl pl-1">莉亞的兒子是雅各的長子魯本，</span><br /><span className="pl pl-1">還有西緬、利未、猶大、</span><br /><span className="pl pl-1">以薩迦和西布倫。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 30:22–24; 創世記 46:19–22; 創世記 35:16–18"> <span className="pl pl-1">拉結的兒子是約瑟和便雅憫。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 46:23–25; 創世記 37:2; 創世記 30:4–8"> <span className="pl pl-1">拉結的婢女碧拉的兒子是但和拿弗他利。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="創世記 30:9–13; 創世記 46:16–18; 創世記 25:20"> <span className="pl pl-1">莉亞的婢女悉帕的兒子是迦得和亞設。</span><br />以上是雅各的兒子，是他在帕旦-亞蘭生的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 13:18; 創世記 23:19; 創世記 18:1"> 雅各來到他父親以撒那裡，到了基列-阿爾巴的幔利，就是亞伯拉罕和以撒寄居的地方；基列-阿爾巴就是希伯崙。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 25:7; 創世記 50:26; 創世記 47:28"> 以撒的年日有一百八十年。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 15:15; 創世記 49:33; 創世記 49:31"> 以撒年邁，壽數滿足，氣絕而死，歸到他的先人那裡。他的兒子以掃和雅各把他安葬了。</span>
</div>
</div>

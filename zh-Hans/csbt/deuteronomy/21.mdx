<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 26:21; 詩篇 5:6; 箴言 28:17"> 在你神耶和華所賜給你去擁有的那地上，如果發現有人被殺，倒在田野上，卻不知道是誰殺的，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 13:3–4; 申命記 16:18–19"> 你的長老和審判官就要出去，測量從被殺之人的位置<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的位置——輔助詞語。">a</a></sup>到周圍城鎮的距離。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 19:2; 馬太福音 11:28–30; 耶利米書 31:18"> 那距離被殺之人最近的城，城裡的長老要取來一頭沒有耕耘過、沒有負過軛的小母牛。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 2:21–24; 彼得前書 3:18"> 城裡的長老們要把小母牛牽到有水常流、從未耕耘播種過的溪谷裡，在溪谷裡打斷小母牛的脖子。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 23:13; 瑪拉基書 2:7; 申命記 10:8"> 然後那些利未人祭司要上前來，因為你的神耶和華揀選了他們來事奉他，奉耶和華的名祝福，要由他們來判決所有的爭訟和一切打鬥的案件。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 73:13; 詩篇 26:6; 詩篇 51:7"> 那距離被殺之人最近的城中所有的長老，要在那溪谷裡，在打斷了脖子的小母牛上方洗手，</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 21:21–23; 約伯記 21:31–34; 撒母耳記下 16:8"> 然後聲明說：「我們的手沒有流這人的血，我們的眼睛也沒有看見這事。</span>
<span className="v" id="v8" data-v="8" data-xref="約拿書 1:14; 列王紀下 24:4; 以西結書 23:24–25"> 耶和華啊，求你為你所救贖的子民以色列免除罪責，不要把無辜人的血債歸在你子民以色列中間。」這樣，他們就被贖清了殺人流血的罪責。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 19:12–13; 列王紀下 10:30–31; 申命記 13:18"> 你就從你們中間除盡了無辜人的血債，你是做了耶和華眼中看為正的事。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 20:10–16; 約書亞記 21:44"> 當你出去與仇敵作戰，你的神耶和華把他們交在你手中，你擄走他們為俘虜時，</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 創世記 34:3; 創世記 12:14–15"> 如果你在俘虜中看見一個俊美的女子，愛慕她，要娶她為妻，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 14:9; 民數記 6:9; 以弗所書 4:22"> 你就可以把她帶回你家裡。她要剃頭髮，剪指甲，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 45:10–11; 路加福音 14:26–27"> 從身上脫去被擄時的衣服，住在你家裡為她父母哀哭一整個月。此後你可以與她同房，作她的丈夫，她就成為你的妻子了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:29; 創世記 34:2; 申命記 22:19"> 但如果你不喜歡她了，那時你要按著她的意願讓她走，絕對不可拿她賣錢，也不可奴役她，因為你已經玷辱了她。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 29:33; 創世記 29:20; 創世記 29:18"> 如果某人有兩個妻子，一個被寵愛，一個被嫌棄，那被寵愛的和被嫌棄的都為他生了兒子，而長子是那被嫌棄的所生，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 26:10; 歷代志上 5:2; 歷代志下 21:3"> 那麼，到了讓兒子們繼承他產業的時候，他不可偏心，把長子的權利給被愛之妻的兒子，不給被嫌之妻的兒子——他頭生的兒子。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:3; 創世記 25:31–34; 詩篇 105:36"> 他必須承認那被嫌之妻的兒子為長子，從自己的全部產業中給他雙倍，因為他是自己強壯時頭生的，長子的權利屬於他。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 19:3; 出埃及記 20:12; 阿摩司書 4:11–12"> 如果某人有一個兒子頑梗悖逆，不聽從父母的話，父母管教他，他還是不聽從，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 13:3; 申命記 21:2; 申命記 16:18"> 他的父母就要拉住他，帶到本地的城門口，本城的長老們那裡。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> 他們要對本城的長老說：「我們這兒子頑梗悖逆，不聽從我們的話，貪吃酗酒。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 19:19–20; 申命記 13:10–11; 利未記 24:16"> 全城的人就要用石頭砸死他。你要把這邪惡從你們中間除盡。這樣，全以色列聽見了就會害怕。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 19:31–38; 使徒行傳 26:31; 路加福音 23:33"> 如果某人犯了該判死刑的罪，被處死了，你把他掛在木頭上，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 3:13; 約翰福音 19:31; 哥林多後書 5:21"> 你不可讓他的屍體在那木頭上過夜，必須當天把他埋葬，因為被掛之人是神所詛咒的，你不可玷汙你神耶和華所賜給你為繼業的土地。</span>
</div>

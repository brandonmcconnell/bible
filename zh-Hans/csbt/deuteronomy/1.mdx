<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 25:1; 約書亞記 22:7; 民數記 33:17–18"> 這是摩西在約旦河對岸的曠野向全體以色列人宣講的話語，是在帕蘭與陀弗、拉班、哈洗錄、底撒哈之間，在疏弗對面的亞拉巴宣講的。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 32:8; 民數記 13:26; 申命記 9:23"> 從何烈山沿著通往西珥山的路，到加低斯-巴尼亞，有十一天的路程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的路程——輔助詞語。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 33:38; 申命記 4:1–2; 民數記 20:1"> 在第四十年的十一月，當月的第一日，摩西把耶和華指示他要向以色列子孫宣告的一切，都向他們宣告了；</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 21:21–35; 約書亞記 12:2–6; 約書亞記 13:10–12"> 那時他已經擊敗了住希實本的亞摩利王西宏，以及住亞斯他錄和伊德賴的巴珊王歐革。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 4:8; 申命記 32:46; 申命記 31:9"> 在約旦河對岸的摩押地，摩西開始講說這律法：</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 3:1; 民數記 10:11–13; 出埃及記 19:1–2"> 耶和華我們的神在何烈山吩咐我們說：「你們在這山地已經停留很久了，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:24; 約書亞記 10:40; 阿摩司書 2:9"> 你們要起身出發，往亞摩利人的山地去，前往它鄰近的各地，就是亞拉巴、山地、丘陵、南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音譯作「內蓋夫」。">b</a></sup>和沿海一帶迦南人之地，以及黎巴嫩，直到那大河——幼發拉底河。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:18; 創世記 12:7; 創世記 26:3–4"> 看，我已經把那地擺在你們面前了，你們進去占有吧，耶和華曾向你們先祖亞伯拉罕、以撒、雅各起誓，要把那地賜給他們和他們的後裔。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 18:18; 民數記 11:17; 民數記 11:11–14"> 那時我告訴你們說：「我不能獨自擔當你們的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 10:22; 出埃及記 32:13; 創世記 22:17"> 你們的神耶和華使你們增多，看哪，你們今天多如天上的星辰。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 115:14; 創世記 22:17; 民數記 6:27"> 願你們祖先的神耶和華使你們增添到現有的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="現有的——輔助詞語。">c</a></sup>千倍，照著他所應許你們的，祝福你們！</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:5; 列王紀上 3:7–9; 哥林多後書 2:16"> 但我怎能獨自擔當你們的瑣事、你們的重擔和你們的爭訟呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 18:21; 使徒行傳 1:21–23; 民數記 11:16–17"> 你們要按著你們的支派推薦一些有智慧、有悟性、有見識<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有見識——或譯作「被認可」；下同。">d</a></sup>的人，我要立他們作你們的首領。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 當時你們回答我說：「你提出要做的事很好。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 16:18; 出埃及記 18:25–26; 以弗所書 4:11"> 於是我選出你們各支派的首領，就是那些有智慧、有見識的人，我立他們作你們的首領，作千夫長、百夫長、五十夫長、十夫長以及各支派的官長。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:24; 出埃及記 22:21; 歷代志下 19:6–10"> 那時我吩咐你們的審判官說：「你們在你們的弟兄之間聽訟，無論是人與他的弟兄之間，還是與寄居者之間，都要公正地施行審判。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:19; 出埃及記 18:26; 雅各書 2:9"> 裁決的時候，不可顧及情面；無論是對卑微的還是尊貴的，都要一樣聽訟。不可懼怕任何人，因為裁決屬於神。至於對你們太難的案件，可以帶來給我，我會聽訟。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:5; 使徒行傳 20:20"> 那時，我把你們應當做的一切事都吩咐你們了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 1:2; 申命記 8:15; 耶利米書 2:6"> 於是，我們照著耶和華我們神所指示的，從何烈山起行，沿著通往亞摩利人山地的路，走過你們所看到那大而可怕的整個曠野，來到了加低斯-巴尼亞。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 1:7–8"> 我對你們說：「你們來到了我們神耶和華賜給我們的亞摩利人的山地。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 1:9; 詩篇 46:1; 民數記 14:8–9"> 看，耶和華你的神把這地擺在你面前了。照著你祖先的神耶和華所吩咐你的，上去占有吧！不要害怕，不要喪膽。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 13:1–20"> 你們都前來見我，說：「讓我們先派人去，為我們窺探那地，把我們要上去的路和要進入之城的信息帶回來給我們。」</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 13:3–33"> 我看這建議好，就從你們中間選出了十二個人，每支派一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 13:21–27; 約書亞記 2:1–2"> 他們起身上山地去，來到以實格溪谷，窺探那地。</span>
<span className="v" id="v25" data-v="25"> 然後他們手裡拿著那地的一些果實，帶下來給我們，並且帶回來信息，說：「我們的神耶和華賜給我們的這地是美好的。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民數記 14:1–4; 使徒行傳 7:51; 詩篇 106:24–25"> 你們卻不願意上去，竟然違背了你們的神耶和華的命令。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 9:28; 詩篇 106:25; 民數記 14:3"> 你們在自己的帳篷裡抱怨說：「耶和華恨我們，所以把我們從埃及地領了出來，為要把我們交在亞摩利人手中，好除滅我們。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 13:28–33; 申命記 9:1–2; 約書亞記 15:14"> 我們能上哪裡去呢？我們的弟兄使我們的心消融，說：『那民比我們雄偉高大，那些城也雄偉堅固，高得<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="高得——輔助詞語。">e</a></sup>頂天。我們在那裡還看見了亞衲子孫！』」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 我就對你們說：「不要恐懼，不要怕他們。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 14:14; 尼希米記 4:20; 羅馬書 8:31"> 耶和華你們的神，就是走在你們前面的那一位，他會親自為你們爭戰，正如他在埃及，在你們眼前為你們所做的一切那樣；</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 46:3–4; 使徒行傳 13:18; 何西阿書 11:3–4"> 而且你也看見了，在曠野，在你們走過的整個路途中，直到你們來到這地方，你的神耶和華怎樣背負了你，就像人背負自己的兒子那樣。」</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:24; 猶大書 1:5; 希伯來書 3:18–19"> 儘管我說了這些，你們還是不相信耶和華你們的神——</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 10:33; 詩篇 78:14; 尼希米記 9:12"> 是他，一路上走在你們前面，為你們尋找紮營的地方，夜間用火柱、白天用雲柱指明你們當走的路。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民數記 14:22–30; 詩篇 95:11; 以西結書 20:15"> 耶和華聽見你們的怨言，就發怒，起誓說：</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 95:11"> 「這邪惡的世代，絕不會有人看到我起誓要賜給你們先祖的美地！</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 14:24; 約書亞記 14:6–14; 民數記 32:12"> 只有耶弗尼的兒子迦勒，他將看到那地，並且我要把他所踏之地賜給他和他的子孫，因為他全心跟從了耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民數記 20:12; 申命記 4:21; 申命記 34:4"> 因你們的緣故，耶和華也對我發怒，說：「連你也不能進入那地。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 3:28; 民數記 14:30; 申命記 31:7–8"> 在你面前侍立的嫩的兒子約書亞，他將進入那地。你要鼓勵他，因為他將使以色列繼承那地。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 7:15–16; 民數記 14:3; 民數記 14:31"> 還有你們所說將成為掠物的孩童，就是你們那些現在還不知道善惡的兒女，他們將進入那地。我要把那地賜給他們，他們將繼承它。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 14:25"> 至於你們，轉回吧，沿著通往紅海的路前行往曠野去。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 14:39–45; 箴言 19:3; 民數記 22:34"> 那時你們回答我說：「我們對耶和華犯了罪！我們要照著耶和華我們神所吩咐的一切，上去爭戰！」然後你們各人佩帶兵器，輕率地要上那山地去。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="民數記 14:41–43; 約書亞記 7:8–13; 以賽亞書 59:1–2"> 耶和華對我說：「你告訴他們：不要上去，也不要爭戰，因為我不與你們同在。不然，你們必敗在仇敵面前。」</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 14:44; 以賽亞書 63:10; 使徒行傳 7:51"> 我就吩咐了你們，你們卻不聽從，反而違背耶和華的命令，擅自行動上山地去。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 118:12; 民數記 14:45; 民數記 21:3"> 於是住在那山地的亞摩利人出來迎戰，像蜂群一樣追趕你們，在西珥擊潰你們，直到霍爾瑪。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯來書 12:17; 詩篇 78:34"> 你們回來，在耶和華面前大哭，但耶和華不垂聽你們的聲音，不傾聽你們。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 20:1; 民數記 20:22; 士師記 11:16–17"> 你們就在加低斯滯留了許多日子，一直停留在那裡。</span>
</div>
</div>

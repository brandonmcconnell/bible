<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:10; 出埃及記 23:10–11; 利未記 25:2–4"> 每七年的最後一年，你要施行豁免。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各書 2:13; 路加福音 6:34–38"> 豁免的條例是這樣的：所有的債主都要豁免他手中借給鄰人的債，不可向他的鄰人、他的弟兄追討，因為耶和華的豁免已經宣告了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:20; 馬太福音 17:25–26; 哥林多前書 6:6–7"> 你可以向外邦人追討，但你弟兄所欠你的，你要放手豁免。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 58:10–11; 箴言 28:27; 箴言 11:24–25"> 不過在你們中間本不會有貧窮人，因為在你的神耶和華所賜給你為繼業，讓你去繼承的那地上，耶和華必定祝福你——</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 28:1–15; 以賽亞書 1:19–20; 約書亞記 1:7"> 你務必留心聽從你神耶和華的話，謹守遵行我今天所吩咐你的這一切誡命。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:12–13; 路加福音 6:35; 尼希米記 9:27"> 是的，你的神耶和華必照著他所應許你的祝福你，你將借貸給許多民族，自己卻不向人借貸，你將管轄許多民族，他們卻不會管轄你。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 3:16–17; 申命記 15:9; 箴言 21:13"> 但如果在你的神耶和華所賜給你的土地上，在你的某城中，你們中間有一個弟兄是貧窮的，你不可硬著你的心，對你貧窮的弟兄攥著手。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 馬太福音 5:42"> 你一定要向他大大敞開你的手，他缺什麼，就把他所缺的慷慨借給他。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 24:15; 馬太福音 20:15; 耶利米書 17:10"> 你要謹慎，免得你心中起了卑劣的念頭，說「第七年豁免年臨近了」，就惡眼看待你貧窮的弟兄不借給他，以致他因你而向耶和華呼求，你身上就有罪過了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯來書 13:16; 以賽亞書 58:10"> 你要慷慨地借給他；你借給他的時候不要心疼，因為你的神耶和華會因這事的緣故，在你一切工作上以及你手所勞作的一切事上祝福你。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 14:7; 馬太福音 26:11; 約翰福音 12:8"> 地上總不會斷絕窮人，所以我吩咐你說：在你們的地方，你要向你的弟兄，向你那裡的困苦人、貧窮人大大敞開你的手。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 34:14; 利未記 25:39–41; 出埃及記 21:2–6"> 如果你的同胞——無論希伯來男人還是女人——被賣給你，服事了你六年，到第七年你要讓他自由離去。</span>
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 3:5; 耶利米書 22:13; 箴言 3:27–28"> 當你讓他自由離去時，不可讓他空手離去。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 16:2; 箴言 10:22; 詩篇 68:10"> 你要從你的羊群中、打穀場中、榨酒池中慷慨地給他，要照著你的神耶和華所祝福你的給他。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 16:12; 馬太福音 18:32–33; 申命記 5:14–15"> 要記住，你曾在埃及地作過奴隸，而你的神耶和華救贖了你，所以我今天這樣吩咐你。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 21:5–6; 詩篇 40:8; 詩篇 40:6"> 但如果那僕人對你說「我不願離開你」，因為他喜愛你和你的家，他在你那裡很好；那時，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 1:22; 利未記 25:39–42"> 你就拿錐子，把他的耳朵在門上刺透，他就永遠成為你的僕人了。對你的女僕，你也要這樣做。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以賽亞書 16:14; 以賽亞書 21:16"> 但如果你讓那僕人自由離去，你不要看著捨不得，因為他已經服事了你六年，應得雇工雙倍的工酬。這樣，你的神耶和華就會在你所做的一切事上祝福你。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 13:2; 出埃及記 13:12; 利未記 27:26"> 你牛群羊群中所有頭生的，公的要分別為聖歸於耶和華你的神；你不可用你頭生的公牛耕耘，也不可給你頭生的公羊剪毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 12:17; 申命記 14:23; 申命記 12:5–7"> 這些祭物，你和你的家人每年都要在你的神耶和華面前，在耶和華所選擇的地方享用。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 17:1; 瑪拉基書 1:7–8; 利未記 22:19–25"> 但如果牠身上有殘疾，是瘸腿的或瞎眼的，有任何嚴重的殘疾，你不可把牠獻給耶和華你的神。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:21–22; 申命記 12:15–16"> 你可以在自己城中吃，不潔淨的人和潔淨的人都可以吃，就像吃羚羊和鹿那樣。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:16; 利未記 7:26; 申命記 12:23"> 只是不可吃牠的血，要倒在地上，像倒水一樣。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 申命記 5:32–3; 帖撒羅尼迦前書 4:1–2"> 我今天所吩咐你的一切誡命，你們都要謹守遵行，好使你們存活，人數增多，並且進去占有耶和華起誓要給你們先祖的那地。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:3; 彼得前書 1:7; 申命記 8:16"> 你要回想，這四十年你的神耶和華在曠野中帶你走過的整個路程，他是要磨煉你、試驗你，要知道你心裡想什麼，你是否會遵守他的誡命。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:4; 路加福音 4:4; 希伯來書 13:5–6"> 他磨煉你，讓你挨餓，然後把你和你祖先都不認識的嗎哪賜給你吃，是要你明白：人活著不是單靠食物，而是靠耶和華口裡所出的每一句話。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 9:21; 申命記 29:5; 馬太福音 26:25–30"> 這四十年你身上的衣服沒有破，腳也沒有腫。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 3:19; 箴言 3:12; 撒母耳記下 7:14"> 你心裡要明白：你的神耶和華管教你，就像人管教自己的兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 6:31; 申命記 5:33; 撒母耳記上 12:24"> 你要遵守你的神耶和華的誡命，走在他的道路上，敬畏他。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:9–12; 出埃及記 3:8; 以西結書 20:6"> 因為你的神耶和華將要把你帶進一個美好之地：那地有溪水，有泉眼和深淵的水，流淌在平原和山地；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 6:13; 詩篇 147:14; 申命記 32:14"> 那地有小麥、大麥、葡萄樹、無花果樹和石榴樹；那地有橄欖油和蜂蜜；</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 22:14; 申命記 33:25; 約書亞記 22:8"> 你在那地不會缺少食物吃，不會缺乏任何東西；那地的石頭是鐵，山中可以採銅。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 103:2; 羅馬書 14:6; 箴言 3:9"> 當你吃得飽足，你要頌讚耶和華你的神，因為他將那美地賜給了你。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:21; 何西阿書 2:8–9; 箴言 1:32"> 你要謹慎，免得忘記耶和華你的神，不遵守他的誡命、法規和律例，就是我今天所吩咐你的。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命記 28:47; 申命記 32:15"> 恐怕你吃得飽足，建造了上好的房屋居住，</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 1:3; 創世記 13:1–5; 路加福音 12:13–21"> 你的牛羊增多，你的金銀增多，屬於你的一切都增多，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:21; 哥林多前書 4:7–8; 申命記 8:11"> 你就心裡高傲，忘記耶和華你的神——是他把你從埃及地為奴之家領了出來；</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 21:6; 民數記 20:11; 耶利米書 2:6"> 是他帶你走過那大而可怕，有毒蛇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="毒蛇——或譯作「火蛇」。">a</a></sup>和蠍子的曠野，走過沒有水的乾涸之地；是他讓泉水從堅硬的磐石中為你流出來；</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 8:3; 雅各書 1:12; 出埃及記 16:15"> 是他在曠野裡把你祖先不認識的嗎哪賜給你吃，為要磨煉你、試驗你，使你最終蒙福。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 9:4; 哥林多前書 4:7; 但以理書 4:30"> 你或許心裡想：「是我的力量、我手的能力為自己獲取了這財富。」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿書 2:8; 申命記 7:8"> 但你要記得耶和華你的神，是他賜給你能力獲取財富，好成就他與你先祖起誓立下的約，就像今日這樣。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:26; 撒母耳記上 12:25; 西番雅書 1:18"> 如果你真忘記了耶和華你的神，而跟從別的神，服事它們，向它們下拜，我今天警誡你們：你們必定滅亡。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 9:11–12; 歷代志下 36:16–17"> 正如耶和華從你們面前消滅的那些民族，照樣，你們也必滅亡，因為你們不聽從你們的神耶和華的話。</span>
</div>

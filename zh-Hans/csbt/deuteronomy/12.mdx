<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:40; 約伯記 7:1; 申命記 4:19"> 你們在你祖先的神耶和華所賜給你去繼承的地上，要一生一世謹守遵行以下的律例和法規：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:5; 列王紀下 16:4; 民數記 33:51–52"> 你們將趕出的那些民族，他們服事他們神明的任何場所，無論是在高山上、丘陵上，還是在各青翠樹下，你們都要徹底毀掉。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 2:2; 撒迦利亞書 13:2; 民數記 33:52"> 你們要拆毀他們的祭壇，打碎他們的神柱，放火燒毀他們的亞舍拉柱，砍倒他們神明的雕像，使那些神明的名號從那地方消亡。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:23; 申命記 20:18; 申命記 16:21–22"> 你們不可像他們那樣敬拜耶和華你們的神，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 12:11; 申命記 26:2; 歷代志下 7:12"> 而要到你們的神耶和華從各支派中選擇的地方去求問，那是他將安置他的名居住的地方。你們要到那裡去，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:19–20; 瑪拉基書 3:10; 利未記 27:32–33"> 把你們的燔祭、祭物、十一奉獻和你們手中的供物，你們的還願祭和甘心祭，以及你們的牛群羊群中頭生的，都帶到那裡。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 12:18; 利未記 23:40; 申命記 14:26"> 你們和你們的家人也要在那裡，在你們的神耶和華面前享用這些，為你們手所勞作的一切而歡樂，因為你的神耶和華祝福了你。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士師記 21:25; 士師記 17:6; 箴言 21:2"> 你們不可像今天在這裡所做的，各人做自己眼中看為正的一切。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 8:56; 詩篇 95:11; 申命記 25:19"> 你們那樣做<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那樣做——輔助詞語。">a</a></sup>，因為現在還沒有進入安息之地，就是耶和華你的神所賜給你的繼業之地；</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 33:11; 以西結書 34:28; 申命記 3:27"> 但你們即將過約旦河，住在你們的神耶和華使你們繼承的那地，他將使你們得享安息，脫離四圍一切仇敵，安然居住，</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:5; 申命記 15:20; 申命記 17:8"> 那時你們的神耶和華將選擇一個讓他的名安居的地方。你們要把我所吩咐你們的一切，就是你們的燔祭、祭物、十一奉獻和你們手中的供物，以及你們向耶和華所許的一切上好的還願祭，都帶到那裡。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:7; 申命記 10:9; 申命記 26:12"> 你們要在你們的神耶和華面前，與你們的兒女、僕婢，以及你們城裡的利未人一起歡樂，因為利未人在你們中間沒有份，沒有繼業。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:28–32; 列王紀上 15:34; 歷代志下 15:17"> 你要謹慎，不可在你自己看中的任何地方獻上燔祭，</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 12:11; 哥林多後書 5:19; 申命記 12:5"> 只可在耶和華從你一個支派中選擇的地方，在那裡獻上燔祭，遵行我所吩咐你的一切。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 14:5; 申命記 15:22–23; 申命記 14:26"> 不過，你可以照著你的神耶和華所賜的祝福，在你各城中隨心所願地宰殺、吃肉；不潔淨的人和潔淨的人都可以吃，就像吃羚羊和鹿那樣。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 9:4; 申命記 15:23; 申命記 12:23–24"> 只是你們不可吃血，要把血倒在地上，像倒水一樣。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 26:14; 申命記 12:6; 申命記 14:22–29"> 你五穀、新酒和新油的十一奉獻，還有你牛群羊群中頭生的，你所許的任何還願祭，你的甘心祭以及你手中的供物，都不可在自己的城裡吃。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:7; 申命記 14:23; 申命記 12:5"> 你只可在你的神耶和華面前，在你的神耶和華所選擇的地方吃，並且要與你的兒女、僕婢，以及你城裡的利未人一起享用，在你的神耶和華面前為你手所勞作的一切歡樂。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 31:4–21; 尼希米記 10:34–39; 申命記 14:27–29"> 你要謹慎，在你所住的地方永不可撇棄利未人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 19:8; 申命記 11:24; 出埃及記 34:24"> 當你的神耶和華照著他向你所應許的，擴張你的邊界時，你心裡渴望吃肉說「我要吃肉」，你就可以隨心所願地吃肉。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:5; 列王紀上 14:21; 申命記 16:11"> 如果你的神耶和華所選擇安置他名的地方離你很遠，你可以照著我所指示你的，從耶和華賜給你的牛羊中宰殺一些，隨心所願在你的城中吃；</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:15–16"> 就像吃羚羊和鹿那樣，你也照樣可以吃牠；不潔淨的人和潔淨的人全都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 17:11; 創世記 9:4; 利未記 17:13–14"> 只是你絕不可吃血，因為血就是生命，你不可把生命與肉一起吃下。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:16; 申命記 15:23"> 你不可吃血，要倒在地上，像倒水一樣。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:38; 申命記 4:40; 以賽亞書 3:10"> 你不可吃血，好讓你和你的後代子孫蒙福，你是做耶和華眼中看為正的事。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民數記 18:19; 民數記 5:9–10; 申命記 12:11"> 但你的那些聖物和你的還願祭，你要帶上，到耶和華所選擇的地方去。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 1:13; 利未記 17:11; 利未記 1:9"> 你要把你的燔祭，連肉帶血，獻在你的神耶和華的祭壇上；祭物的血你要倒在你的神耶和華的祭壇上，祭物的肉你可以吃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 4:40; 約翰福音 15:14; 約翰福音 15:10"> 你要謹守聽從我所吩咐你的這一切話，好讓你和你的後代子孫永遠蒙福，你是做你神耶和華眼中看為好、看為正的事。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 23:4; 申命記 19:1; 申命記 9:3"> 你的神耶和華必從你面前，剪除你要去趕出的那些民族。當你趕出他們，住在他們的土地上時，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 10:2; 以西結書 20:32; 申命記 7:16"> 你要謹慎，不可在他們從你面前被除滅之後，效法他們而陷入圈套；也不可尋求他們的神明，說：「這些民族怎樣服事他們的神明，我也要照樣做。」</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 32:35; 申命記 18:9–10; 列王紀下 17:15–17"> 你不可那樣敬拜耶和華你的神，因為他們敬拜他們神明的那一切可憎行為是耶和華所恨惡的，他們甚至把自己的兒女用火燒獻給他們的神明。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 4:2; 啟示錄 22:18–19; 約書亞記 1:7"> 我所吩咐你們的一切話，你們都要謹守遵行，不可添加，也不可刪減。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此節在馬索拉文本為13:1。">b</a></sup></span>
</div>
</div>

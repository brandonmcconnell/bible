<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 11:31; 申命記 4:38; 申命記 1:28"> 以色列啊，你要聽：你今天即將過約旦河，進去趕出那些比你強大的民族，他們的城雄偉堅固，高得頂天，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 13:22; 那鴻書 1:6; 申命記 7:24"> 這民雄偉高大，是你所知道的亞衲子孫，而且你也聽說過：「誰能站在亞衲子孫面前？」</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:24; 希伯來書 12:29; 羅馬書 8:31"> 你今天要知道：你的神耶和華將要如吞噬的烈火在你前面過去，他將親自除滅他們，親自在你面前制伏他們。你必趕出他們，很快消滅他們，正如耶和華向你所應許的。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:17; 申命記 9:5; 申命記 18:9–14"> 當你的神耶和華把他們從你面前驅逐出去時，你不要心裡想：「耶和華把我帶進來占有這地，是因著我的義。」其實耶和華把他們從你面前趕出去，是因這些民族的邪惡。</span>
<span className="v" id="v5" data-v="5" data-xref="提多書 3:5; 創世記 17:8; 創世記 26:4"> 你進去占有他們的土地，不是因為你有義，也不是因為你心裡正直；而是因為這些民族邪惡，你的神耶和華才把他們從你面前趕出去，為要成就耶和華向你先祖亞伯拉罕、以撒、雅各所起的誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:16; 使徒行傳 7:51; 申命記 31:27"> 所以你要知道：你的神耶和華把這美地賜給你去占有，並不是因為你的義，其實你是硬著頸項的子民。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 16:2; 出埃及記 14:11; 民數記 21:5"> 你要記住，不要忘記你曾在曠野怎樣惹怒耶和華你的神。從你們出埃及地的那天起，直到你們來到這地方，你們一直悖逆耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:19–22; 出埃及記 32:16; 出埃及記 32:7–10"> 你們在何烈山惹怒了耶和華，耶和華就對你們發怒，要把你們除滅了。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 34:28; 出埃及記 24:18; 列王紀上 19:8"> 當時我上了山，去領受石版，就是耶和華與你們立約的石版。我留在山上四十晝夜，不吃飯不喝水。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 31:18; 希伯來書 8:10; 申命記 10:4"> 耶和華把兩塊石版交給了我，是神用手指寫成的，上面是耶和華在集會那天，在山上從火焰中對你們所說的一切話。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:9; 民數記 10:33; 希伯來書 8:6–10"> 過了四十晝夜，耶和華把那兩塊石版，就是約版，交給了我。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 32:7–8; 申命記 31:29; 士師記 2:17"> 然後耶和華對我說：「起來，趕快從這裡下去，因為你從埃及領出來的子民已經敗壞了。他們很快就偏離了我所指示他們的道路，為自己鑄造偶像。」</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 9:6; 列王紀下 17:14; 申命記 10:16"> 耶和華又告訴我說：「我看見這子民，看哪，他們是硬著頸項的子民！</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 出埃及記 32:10–13; 詩篇 9:5"> 任憑我吧，我要除滅他們，從天下抹掉他們的名號！我卻要使你成為一個比他們強盛的民族。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:18; 申命記 5:23; 申命記 4:11"> 我轉身從山上下來，山在火焰中燃燒，兩塊約版在我的兩手中。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 32:19; 使徒行傳 7:40–41"> 我觀看，看哪，你們已經對你們的神耶和華犯罪，為自己造了一個牛犢鑄像。你們很快就偏離了耶和華所指示你們的道路！</span>
<span className="v" id="v17" data-v="17"> 於是我舉起那兩塊石版，從兩手中甩出去，在你們眼前摔碎了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:28; 申命記 9:9; 詩篇 106:23"> 因著你們犯這一切罪，做耶和華眼中看為惡的事，惹他惱怒，我就像先前那樣，俯伏在耶和華面前四十晝夜，不吃飯不喝水。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:10; 出埃及記 32:14; 雅各書 5:16–17"> 我實在因耶和華的怒氣和怒火而害怕，因為他對你們發怒，要除滅你們；但那一次耶和華又垂聽了我。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 32:35; 出埃及記 32:21; 希伯來書 7:26–28"> 耶和華也對亞倫大大發怒，要除滅他，那時我也為亞倫代禱。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 32:20; 以賽亞書 31:7; 以賽亞書 2:18–21"> 我把你們的罪惡之物，就是你們造的牛犢拿過來，用火焚燒，然後打碎徹底碾磨，磨成粉末，把這粉末扔進了山上流下來的溪水裡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 11:34; 出埃及記 17:7; 民數記 11:1–5"> 在塔備拉、瑪撒、基布羅-哈特瓦，你們繼續惹怒耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:24–25; 希伯來書 4:2; 詩篇 78:22"> 耶和華從加低斯-巴尼亞派遣你們，說：「上去占有我所賜給你們的那地」，那時你們也違背了你們的神耶和華的命令，不相信他，不聽從他的話。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 31:27; 使徒行傳 7:51; 申命記 9:6–7"> 從我認識你們那天起，你們就一直悖逆耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 9:18; 申命記 9:16"> 那時，我俯伏在耶和華面前四十晝夜；我這樣伏下，是因為耶和華說要把你們除滅。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 32:11–13; 提多書 2:14; 詩篇 107:2"> 我向耶和華禱告說：<br />「主耶和華啊，求你不要毀滅你的子民、你的繼業，就是憑你的大能所救贖、用大能的手從埃及領出來的。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 14:21; 彌迦書 7:18–19; 撒母耳記上 25:25"> 求你記念你的僕人亞伯拉罕、以撒和雅各；不要追究這子民的頑固，以及他們的邪惡和罪過，</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 14:16; 出埃及記 32:12"> 免得你領我們出來的那地方的人說：『耶和華因為不能領他們進入所應許之地，又因為他恨惡他們，所以把他們領出來，要在曠野害死他們。』</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 1:10; 列王紀上 8:51; 申命記 9:26"> 畢竟他們是你的子民、你的繼業，是你以偉大的能力和伸出的膀臂領出來的。」</span>
</div>

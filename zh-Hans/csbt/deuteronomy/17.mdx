<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 15:21; 瑪拉基書 1:8; 申命記 23:18"> 你不可把身上有殘疾，有任何缺陷的牛羊，獻給耶和華你的神，因為那是你神耶和華所憎惡的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士師記 2:20; 何西阿書 8:1; 約書亞記 7:11"> 如果在你們中間，在你神耶和華所賜給你的某城中，發現有男人或女人做了你神耶和華眼中看為惡的事，違背他的約，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 7:31; 申命記 4:19; 約伯記 31:26–27"> 去服事別的神，向它們下拜，向太陽、月亮或天上的萬象下拜，都是我禁止<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="禁止——原文直譯「沒有指示過」。">a</a></sup>的，</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 7:51; 申命記 13:12–14; 申命記 19:18"> 有人告訴了你，你聽說了，就要好好調查。如果確定這事是真的，這可憎之事發生在以色列了，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 24:14; 約書亞記 7:25; 利未記 24:16"> 你就要把做這惡事的男人或女人帶到城門口，用石頭砸死那男人或女人。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 35:30; 希伯來書 10:28; 提摩太前書 5:19"> 那判處死刑的人，要憑著兩個見證人或三個見證人的口供被處死，不可憑著一個見證人的口供被處死。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 13:9; 哥林多前書 5:13; 申命記 17:12"> 見證人要先動手處死他，然後全體民眾要動手。你要把這邪惡從你們中間除盡。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 12:5; 哈該書 2:11; 申命記 1:17"> 你城中如果有難以裁決的案件，如殺人流血的案件、爭訟的案件或打鬥的案件，你要起身，上你神耶和華所選擇的地方去，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 44:24; 哈該書 2:11; 瑪拉基書 2:7"> 來到利未祭司們和那時在任的審判官那裡求問，他們就會把案件的判決告訴你。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 22:2–3"> 你要執行他們在耶和華選擇的那地方告訴你的判語，謹守遵行他們所指示你的一切。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 1:7; 申命記 5:32; 羅馬書 13:1–6"> 你要執行他們所指示你的條例、他們所告訴你的判決；他們向你宣告的判語，你不可偏離左右。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 15:30; 申命記 13:5; 申命記 18:5"> 如果有人擅自行事，不聽從侍立在那裡事奉耶和華你神的祭司，或是不聽從審判官，那人就要被處死。你要把這邪惡從以色列除盡。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 13:11; 申命記 19:20; 民數記 15:30–31"> 這樣，全體民眾聽見了就會害怕，不再擅自行事了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 8:19–20; 撒母耳記上 12:19; 約書亞記 1:13"> 當你進入你神耶和華所賜給你的那地，占有並住在其中時，如果你說：「我要為自己立一個王，就像周圍那些民族一樣」，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 30:21; 歷代志上 22:10; 歷代志上 12:23"> 你必須立你神耶和華所揀選的人作你的王。你要從你弟兄當中立一個人作你的王，不可讓不是你弟兄的外邦人統治你。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 31:1–3; 以西結書 17:15; 申命記 28:68"> 此外，他不可為自己大量增添馬匹，更不可為了增添馬匹而讓子民回埃及去，因為耶和華對你們說過：你們不可再回到那條路上。</span>
<span className="v" id="v17" data-v="17" data-xref="尼希米記 13:26; 馬太福音 19:5; 箴言 30:8–9"> 他不可為自己增添很多妃嬪，以免他的心偏離；他也不可為自己大量增添金銀。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 31:9; 列王紀下 22:8; 歷代志下 34:15"> 當他坐上王位的時候，他要在利未祭司面前，在卷冊上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在利未祭司面前，在卷冊上——或譯作「照著利未祭司面前的書卷」。">b</a></sup>為自己抄寫一份這律法書的副本。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 1:8; 詩篇 119:97–100; 詩篇 1:2"> 這副本要留在他身邊，他一生的日子都要誦讀它，好讓他學習敬畏耶和華他的神，謹守這律法的一切話語，遵行這些律例。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:32; 列王紀上 15:5; 詩篇 131:1–2"> 這樣，免得他心裡向他的弟兄高傲，免得他或左或右偏離這些誡命，好使他和他子孫在以色列統治王國的日子長久。</span>
</div>

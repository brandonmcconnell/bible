<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 21:5; 羅馬書 9:8; 加拉太書 3:26"> 你們是你們的神耶和華的兒女，不可為死人割傷自己或剃光你們的額頂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="額頂——原文直譯「雙眼之間」。">a</a></sup>，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:6; 利未記 20:26; 出埃及記 19:5–6"> 因為你是歸屬你的神耶和華的聖潔之民；耶和華從地上萬民中揀選了你，成為他寶貴的子民。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西結書 4:14; 羅馬書 14:14; 利未記 20:25"> 你不可吃任何可憎之物。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 11:2–45; 使徒行傳 10:14; 列王紀上 4:23"> 可以吃的動物是這些：<br /><span className="pl pl-1">牛、綿羊、山羊、</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">鹿、羚羊、麃子、</span><br /><span className="pl pl-1">野山羊、羱羊、瞪羚、</span><br /><span className="pl pl-1">巖羊。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多後書 6:17; 詩篇 1:1–2"> 動物中，凡是分蹄、裂趾為兩瓣蹄並且反芻的動物，都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:22–23; 提多書 1:16; 提摩太後書 3:5"> 然而反芻的或分蹄、裂趾的動物當中，這些不可以吃：<br /><span className="pl pl-1">駱駝、兔子、巖貍，</span><br /><span className="pl pl-1">雖然反芻，卻不分蹄，</span><br /><span className="pl pl-1">所以牠們對於你們是不潔淨的；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="利未記 11:26–27; 以賽亞書 66:3; 彼得後書 2:22"> <span className="pl pl-1">豬，雖然分蹄，卻不反芻，</span><br /><span className="pl pl-1">所以牠對於你們是不潔淨的。</span><br />不可吃牠們的肉，也不可觸碰牠們的屍體。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未記 11:9–12"> 水中的一切，可以吃的是這些：凡是有鰭有鱗的，都可以吃；</span>
<span className="v" id="v10" data-v="10"> 而凡是無鰭無鱗的，都不可吃，牠們對於你們是不潔淨的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11"> 任何潔淨的鳥類，你們都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 11:13–19"> 不可吃的是這些：<br /><span className="pl pl-1">老鷹、禿鷲、紅頭鵰、</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">鳶鷹、小隼、鷹隼與其類，</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">各種烏鴉與其類，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 30:29"> <span className="pl pl-1">鴕鳥、夜鷹、海鷗、蒼鷹與其類，</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">小鴞、貓頭鷹、白鴞、</span><br /></span>
<span className="v" id="v17" data-v="17"> <span className="pl pl-1">鵜鶘、鶚、鸕鶿、</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">白鸛、鷺鷥與其類，</span><br /><span className="pl pl-1">戴勝和蝙蝠。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="腓立比書 3:19; 利未記 11:20–23"> 任何有翅膀的昆蟲，對於你們都是不潔淨的，你們不可吃。</span>
<span className="v" id="v20" data-v="20"> 任何潔淨的飛鳥，都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:19; 出埃及記 34:26; 利未記 22:8"> 你們不可吃任何自然死去的動物，只可以給你城裡的寄居者吃，或者賣給外邦人，因為你是歸屬你的神耶和華的聖潔之民。你不可用母羊的奶煮小羊羔。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 10:37; 申命記 12:17; 申命記 26:12–15"> 每一年，你都必須把種子的全部收成，就是田地所出產的，獻上十分之一。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:5–7; 申命記 4:10; 申命記 12:17–18"> 你要在你的神耶和華面前，在他所選擇使他的名安居的地方，吃你的五穀、新酒和新油的十一奉獻，以及你牛群羊群中頭生的，好讓你終生學習敬畏耶和華你的神。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:21; 申命記 12:5; 申命記 11:24"> 你的神耶和華祝福你的時候，如果你的神耶和華所選擇安置他名的地方離你遙遠，路程太長，以致你不能把奉獻運過去，</span>
<span className="v" id="v25" data-v="25"> 你可以把奉獻換成銀子，然後裝好銀子帶在手裡，到你的神耶和華所選擇的地方去。</span>
<span className="v" id="v26" data-v="26" data-xref="傳道書 9:7; 申命記 12:7; 馬太福音 21:12"> 然後你可以隨心所願用那銀子購買牛羊、淡酒烈酒，或者你想要的各樣物品。你和你的家人要在那裡，在你的神耶和華面前吃喝、歡樂。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 18:20; 申命記 14:29; 申命記 12:12"> 至於你城裡的利未人，你不可撇棄他，因為他在你們中間沒有份，沒有繼業。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 14:22; 阿摩司書 4:4; 申命記 26:12–15"> 每三年的最後一年，你要把當年全部收成的十分之一都拿出來，存放在你城裡。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 15:10; 申命記 14:27; 箴言 19:17"> 這樣，在你們中間沒有份和繼業的利未人，以及你城裡的寄居者、孤兒和寡婦，都可以來吃得飽足，好使耶和華你的神在你手中所做的一切工作上祝福你。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 12:29; 申命記 6:10; 申命記 7:1–2"> 耶和華你的神必剪除那些民族，耶和華你的神把他們的土地賜給你，而你趕出他們，住在他們的城鎮和房屋裡，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 21:13; 約書亞記 20:2–7; 申命記 4:41–43"> 那時，你要在你的神耶和華賜給你去擁有的那地境內，為自己劃分出三座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 57:14; 希伯來書 12:13; 以賽亞書 35:8"> 你要為自己測定距離，把你神耶和華使你繼承的領地分為三部分，讓任何過失殺人的都可以逃到那裡。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民數記 35:15–24; 申命記 4:42; 以賽亞書 30:33"> 過失殺人者逃到那裡得以存活的條例是這樣：他不是故意殺他的鄰人，從前也沒有恨惡過他的鄰人，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 35:25; 箴言 27:12; 列王紀下 6:5–7"> 就比如有人與他的鄰人一起進入樹林砍柴，他掄起手中的斧頭去砍樹，結果斧頭從斧柄上脫落，擊中他的鄰人，以致鄰人死了。他可以逃到其中一座逃城，得以存活。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 35:12; 撒母耳記下 14:7; 申命記 21:22"> 這樣免得報血仇者因為心裡的怒火而追趕那凶手，由於距離逃城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="逃城——輔助詞語。">a</a></sup>遠，就追上了他，奪取他的性命；其實他不該被判處死刑，畢竟他從前沒有恨惡過那人。</span>
<span className="v" id="v7" data-v="7"> 所以我吩咐你說：要為自己劃分出三座城。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 12:20; 出埃及記 34:24; 出埃及記 23:31"> 耶和華你的神必照著他向你祖先所起的誓，擴張你的邊界，把他所應許要賜給你祖先的土地都賜給你——</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 20:7–8; 申命記 11:22–25; 申命記 12:32"> 我今天吩咐你的這一切誡命，你務必謹守遵行，要愛耶和華你的神，一直走在他的道路上——那時，你要在這三座城以外，再增添三座城，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 59:7; 箴言 6:17; 馬太福音 27:4–5"> 以免無辜人的血流在你神耶和華所賜給你的繼業之地上，血債就歸在你身上了。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 35:16–21; 申命記 27:24; 創世記 9:6"> 但如果有人恨惡他的鄰人，對他設下埋伏，起來攻擊他，奪取他的性命，鄰人死了，之後這人逃到其中的一座城，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 2:28–34; 列王紀上 2:5–6"> 他本城的長老們就要派人去，把他從那裡帶回來，交在報血仇者手中，處死他。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 2:31; 申命記 21:9; 申命記 7:16"> 你眼中不可顧惜他，你要從以色列清除無辜人的血債，使你安好。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 27:17; 箴言 22:28; 箴言 23:10"> 你在你神耶和華所賜給你去擁有的那地上，在你所繼承的產業上，不可挪移你鄰人的地界，那是前人所劃定的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 35:30; 申命記 17:6; 哥林多後書 13:1"> 人無論犯了什麼罪，都不能只憑一個見證人就定他有過犯或罪惡；要憑著兩個見證人的口或者三個見證人的口，才能定案。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 27:12; 詩篇 35:11; 出埃及記 23:1–7"> 如果有惡意的見證人起來，指證某人犯法，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 17:9; 申命記 21:5; 瑪拉基書 2:7"> 這兩個爭訟的人就要站在耶和華面前，站在那時在任的祭司和審判官面前。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 13:14; 申命記 17:4; 歷代志下 19:6–7"> 審判官要好好調查，如果那見證人是作假見證，以虛謊指證他的弟兄，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 19:9; 但以理書 6:24"> 那麼，他圖謀怎樣對待自己的弟兄，你們就怎樣對待他。你要把這邪惡從你們中間除盡。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 21:21; 申命記 17:13; 申命記 13:11"> 這樣，其餘的人聽見了就會害怕，再也不會在你們中間做這樣的惡事了。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 5:38–39; 出埃及記 21:23–25; 申命記 19:13"> 你眼中不可顧惜他，要讓他以命償命，以眼還眼，以牙還牙，以手還手，以腳還腳。</span>
</div>

<span className="v" id="v5" data-v="5" data-xref="申命記 32:15; 士師記 17:6; 民數記 23:21"> <span className="pl pl-1">這樣，百姓的首領和以色列眾支派一同聚集時，</span><br /><span className="pl pl-1">耶和華作了耶書崙的王。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="創世記 49:8; 民數記 32:31–32; 約書亞記 22:1–9"> <span className="pl pl-1">「願魯本存活，不致滅亡，</span><br /><span className="pl pl-1">他的人數也不致稀少！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="創世記 49:8–12; 詩篇 20:2; 撒母耳記下 7:9–12"> 關於猶大，他這樣說：<br /><span className="pl pl-1">「耶和華啊，求你垂聽猶大的呼求，</span><br /><span className="pl pl-1">領他歸回本族。</span><br /><span className="pl pl-1">他動手為自己爭鬥，</span><br /><span className="pl pl-1">願你幫助他對付敵人！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 17:7; 出埃及記 28:30; 民數記 20:13"> 關於利未，他說：<br /><span className="pl pl-1">「你的土明和烏陵屬於你的忠信者——</span><br /><span className="pl pl-1">你曾在瑪撒試驗他，</span><br /><span className="pl pl-1">在米利巴水邊與他相爭。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="利未記 10:11; 詩篇 51:19; 申命記 17:9–11"> <span className="pl pl-1">他們將把你的法規教給雅各，</span><br /><span className="pl pl-1">把你的律法教給以色列；</span><br /><span className="pl pl-1">他們要把香擺在你面前，</span><br /><span className="pl pl-1">把全燒祭擺在你的祭壇上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 24:23; 以西結書 43:27; 以西結書 20:40–41"> <span className="pl pl-1">耶和華啊，求你祝福他的才能，</span><br /><span className="pl pl-1">悅納他手中的工作！</span><br /><span className="pl pl-1">求你擊碎那些敵對他、恨惡他之人的腰，</span><br /><span className="pl pl-1">使他們不能起來！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 15:2; 詩篇 91:4; 馬太福音 23:37"> 關於便雅憫，他說：<br /><span className="pl pl-1">「耶和華所愛的人</span><br /><span className="pl pl-1">安居在耶和華身旁；</span><br /><span className="pl pl-1">耶和華終日保護他，</span><br /><span className="pl pl-1">他安居在耶和華的懷中</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="懷中——原文直譯「兩肩之間」。">a</a></sup><br /><span className="pl pl-1">。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="創世記 49:22–26; 彌迦書 5:7; 以賽亞書 18:4"> 關於約瑟，他說：<br /><span className="pl pl-1">「願耶和華祝福約瑟的土地，</span><br /><span className="pl pl-1">賜下天上美好的甘露，</span><br /><span className="pl pl-1">地下蘊藏的深淵之水；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19; 馬太福音 5:45; 詩篇 8:3"> <span className="pl pl-1">還有太陽產出的佳果，</span><br /><span className="pl pl-1">月亮產出的美物，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="哈巴谷書 3:6; 創世記 49:26; 雅各書 5:7"> <span className="pl pl-1">亙古山嶺的精華，</span><br /><span className="pl pl-1">綿延丘陵的寶物；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 7:35; 詩篇 24:1; 出埃及記 3:2–4"> <span className="pl pl-1">還有大地的美物和其上充滿的一切，</span><br /><span className="pl pl-1">以及在荊棘叢中那一位的恩典。</span><br /><span className="pl pl-1">願這祝福臨到約瑟的頭上，</span><br /><span className="pl pl-1">臨到兄弟中領袖</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="領袖——或譯作「分別出來的那位」。">b</a></sup><br /><span className="pl pl-1">的頭頂。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 22:11; 民數記 23:22; 詩篇 44:5"> <span className="pl pl-1">他像頭生的公牛，有威嚴，</span><br /><span className="pl pl-1">他的犄角是野牛的犄角——</span><br /><span className="pl pl-1">他用它們徹底衝垮列邦直到地極，</span><br /><span className="pl pl-1">它們是以法蓮的萬軍，</span><br /><span className="pl pl-1">它們是瑪拿西的千軍！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="創世記 49:13–15; 約書亞記 19:11; 士師記 5:14"> 關於西布倫，他說：<br /><span className="pl pl-1">「西布倫哪，你出門在外要歡喜；</span><br /><span className="pl pl-1">以薩迦啊，你在帳篷裡要歡喜！</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 60:5; 以賽亞書 2:3; 詩篇 4:5"> <span className="pl pl-1">他們要召喚民眾到山上，</span><br /><span className="pl pl-1">在那裡獻上公義的祭物；</span><br /><span className="pl pl-1">因為他們將吸出海洋中的財富，</span><br /><span className="pl pl-1">取出沙土裡的寶藏。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:19; 創世記 9:26–27; 歷代志上 5:18–21"> 關於迦得，他說：<br /><span className="pl pl-1">「使迦得擴張的那一位是當受頌讚的！</span><br /><span className="pl pl-1">迦得臥伏如母獅，</span><br /><span className="pl pl-1">撕咬膀臂連同頭顱。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="士師記 18:27; 約書亞記 19:47; 士師記 15:8"> 關於但，他說：<br /><span className="pl pl-1">「但是一隻小獅子，從巴珊撲出來。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="創世記 49:21; 詩篇 36:8; 馬太福音 4:16"> 關於拿弗他利，他說：<br /><span className="pl pl-1">「拿弗他利啊，</span><br /><span className="pl pl-1">你這飽享恩典、滿得耶和華祝福的，</span><br /><span className="pl pl-1">願你擁有西邊</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="西邊——或譯作「海」，指加利利海。">c</a></sup><br /><span className="pl pl-1">和南邊為業！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="創世記 49:20; 約伯記 29:6; 羅馬書 14:18"> 關於亞設，他說：<br /><span className="pl pl-1">「亞設比眾子更有福；</span><br /><span className="pl pl-1">願他蒙兄弟們的悅納，</span><br /><span className="pl pl-1">願他的腳浸在油中！</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 41:10; 詩篇 138:3; 腓立比書 4:13"> <span className="pl pl-1">你的門閂是鐵的，是銅的；</span><br /><span className="pl pl-1">你的力量如你的日子那樣長久</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="長久——輔助詞語。">d</a></sup><br /><span className="pl pl-1">。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 15:11; 以賽亞書 43:11–13; 耶利米書 10:6"> <span className="pl pl-1">「耶書崙哪，沒有誰能與神相比</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="耶書崙哪，沒有誰能與神相比——或譯作「沒有誰能與耶書崙的神相比」。">e</a></sup><br /><span className="pl pl-1">！</span><br /><span className="pl pl-1">他乘駕高天來幫助你，</span><br /><span className="pl pl-1">乘駕雲霄顯出威榮。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 18:2; 詩篇 90:1–2; 詩篇 46:1"> <span className="pl pl-1">亙古的神是你安穩的住處，</span><br /><span className="pl pl-1">他永恆的膀臂托著你。</span><br /><span className="pl pl-1">他從你面前驅逐仇敵，說：</span><br /><span className="pl pl-1">『除滅他們！』</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民數記 23:9; 創世記 27:28; 出埃及記 33:16"> <span className="pl pl-1">因此以色列獨自安然居住，</span><br /><span className="pl pl-1">雅各的泉源流淌</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="泉源流淌——或譯作「後裔扎根」。">f</a></sup><br /><span className="pl pl-1">在五穀新酒之地，</span><br /><span className="pl pl-1">諸天也為他降下露水。</span><br /></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 10:5; 以西結書 20:11; 利未記 18:5"> 現在，以色列啊，我所教導你們的律例和法規，你們要聽從遵行，好使你們存活，進去繼承你們祖先的神耶和華賜給你們的那地。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:32; 箴言 30:6; 啟示錄 22:18–19"> 我所吩咐你們的話語，不可在其上添加，也不可從其中刪減，好使你們遵守我所吩咐你們的、你們神耶和華的誡命。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 25:1–9; 詩篇 106:28–29; 約書亞記 22:17"> 你們親眼看見了耶和華在巴力-毗珥所做的事：凡是跟從毗珥的巴力的人，你們的神耶和華都從你們當中除滅了；</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 10:20; 約書亞記 23:8; 約翰福音 6:67–69"> 只有你們這些緊緊跟隨耶和華你們神的，今天全都活著。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 28:20; 帖撒羅尼迦前書 4:1–2; 希伯來書 3:5"> 看，我已經按著我的神耶和華指示我的，把律例和法規教導給你們了，好使你們在將要進去占有之地照著遵行。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 28:28; 詩篇 111:10; 提摩太後書 3:15"> 你們要謹守遵行，因為這在各民族眼中是你們的智慧和悟性。他們聽到這一切律例，就會說：「這大國的民實在是有智慧、有悟性！」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:18; 撒母耳記下 7:23; 詩篇 34:18"> 確實，哪一個大國有神與他們親近，像我們的神耶和華，在我們每次呼求他時就與我們親近呢？</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 147:19–20; 羅馬書 7:12–14; 詩篇 119:127–128"> 哪一個大國有公義的律例和法規，像我今天在你們面前所立的這一切律法呢？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 6:7; 申命記 11:19; 詩篇 78:3–8"> 你務必謹慎，極力保守你的靈魂，免得忘記你親眼看到的事，免得那些事在你一生的日子離開你的心。你也要把它們教導給你的子子孫孫。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 19:9; 希伯來書 12:18–19; 出埃及記 19:16"> 那一天你在何烈山，站在你的神耶和華面前，耶和華對我說：「把民眾招聚到我這裡來，我要讓他們聽到我的話，好使他們在地上一生一世都學習敬畏我，也教導他們的兒女。」</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 5:23; 出埃及記 19:16–18; 希伯來書 12:18–19"> 於是你們上前來，站在山腳下，山在燃燒，火焰直達天頂，籠罩著黑暗、密雲和幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:15; 申命記 5:4; 申命記 5:22"> 耶和華從火焰中對你們說話，你們聽到了說話的聲音，沒有看到形象，只有聲音。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:28; 出埃及記 31:18; 申命記 9:9–11"> 他向你們宣告了他的約，就是他吩咐你們要遵行的十誡，然後寫在兩塊石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 105:44–45; 以西結書 21:1–23"> 那時耶和華吩咐我，要把律例和法規教導給你們，好使你們在即將過去占有的那地上遵行。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 4:12; 以賽亞書 40:18; 哥林多後書 4:4–6"> 所以你們要極力保守自己的靈魂，因為耶和華在何烈山從火焰中對你們說話那天，你們沒有看到任何形象。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:29; 申命記 5:8; 出埃及記 20:4–5"> 這樣就免得你們敗壞，為自己製造雕像——任何形象的偶像，男人或女人的樣子，</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:23"> 地上任何動物的樣子，空中任何飛鳥的樣子，</span>
<span className="v" id="v18" data-v="18"> 地上任何爬蟲的樣子，地面之下水中任何魚類的樣子；</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 1:25; 申命記 17:3; 列王紀下 21:3"> 也免得你舉目望天，觀望日月星辰天上的萬象，你就被引誘，向它們下拜，服事它們——你的神耶和華把它們劃分給了普天下的萬民，</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 8:51; 耶利米書 11:4; 出埃及記 19:5–6"> 耶和華卻揀選你們，把你們從埃及從鐵熔爐中領出來，作他的繼業、他的子民，就像今日這樣。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 1:37; 民數記 20:12; 詩篇 106:32–33"> 因你們的緣故，耶和華對我發怒，起誓不許我過約旦河，不讓我進入你的神耶和華賜給你為繼業的那美地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 3:25; 申命記 3:27; 彼得後書 1:13–15"> 因此我將死在這地，不能過約旦河了，而你們即將過去，占有那美地。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:9; 希伯來書 3:12; 約書亞記 23:16"> 你們要謹慎，免得忘記你們的神耶和華與你們所立的約，而為自己製造任何形象的雕像，這是你的神耶和華所禁止<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="禁止——原文直譯「指示」。">a</a></sup>你的。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 12:29; 那鴻書 1:6; 申命記 9:3"> 因為你的神耶和華是吞噬的烈火，是嫉憤的神。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 4:16; 何西阿書 9:9; 哥林多前書 10:22"> 當你們生了孩子，有了孫子，在那地住久了，如果你們敗壞，製造任何形象的雕像，做你們神耶和華眼中看為惡的事，惹他惱怒，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:1; 彌迦書 6:2; 耶利米書 22:29"> 我今天請諸天和大地對你們作見證：在你們即將過約旦河去占有的那地上，你們必定很快滅亡！你們在那地上日子不會長久，必定被除滅。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 28:62–64; 利未記 26:33; 以西結書 12:15"> 耶和華會把你們驅散到萬民中；在耶和華把你們遷往的列國中，你們將存留下來，人數稀少。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:64; 耶利米書 16:13; 申命記 28:36"> 你們將在那裡服事人手所造的神明——那些不能看、不能聽、不能吃、不能聞的木頭和石頭。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:2; 耶利米書 29:12–14; 歷代志下 15:4"> 然而，你們會在那裡尋求耶和華你們的神；只要你全心、全靈尋求他，你就會尋見。</span>
<span className="v" id="v30" data-v="30" data-xref="約珥書 2:12–13; 耶利米書 23:20; 何西阿書 3:5"> 日後，當你遭遇危難，這一切事臨到你時，你就會回轉歸向耶和華你的神，聽從他的話。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 31:8; 詩篇 116:5; 尼希米記 9:31"> 因為你的神耶和華是有憐憫的神，他必不撇下你，也不毀掉你，不會忘記他與你先祖起誓立下的約。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約伯記 8:8; 馬太福音 24:31; 詩篇 44:1"> 你儘管去問，在你之前，起初的那些日子裡，自從神在地上創造了人那天起，從天這邊到天那邊，是否有過這樣的大事，或者聽說過這樣的事？</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 6:22; 申命記 5:24; 出埃及記 33:20"> 是否有哪個民族，聽到神從火焰中說話的聲音，像你那樣聽到了還能存活？</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 26:8; 申命記 5:15; 出埃及記 6:6"> 或者有哪位神，曾試圖用試煉、神蹟、奇事、戰爭、大能的手、伸出的膀臂和極其可畏的事，去為自己把一個民族從另一個民族中帶出來，像你們的神耶和華在埃及、在你眼前為你們所做的那一切呢？</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 45:18; 撒母耳記上 2:2; 以賽亞書 45:5"> 這些事向你顯明，是要你知道：唯獨耶和華是神，在他以外，沒有另一位。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 19:9; 出埃及記 19:19; 申命記 4:33"> 他從天上讓你聽到他的聲音，為要教導你；他在地上也讓你看見他猛烈的火，讓你從火焰中聽到他的話。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 10:15; 以賽亞書 63:9; 出埃及記 13:9"> 他因為愛你的列祖，所以揀選他們的後裔，用偉大的能力親自把你從埃及領了出來，</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 7:1; 申命記 9:1–5; 出埃及記 23:27–28"> 為要從你面前趕出那些比你強大的民族，而把你帶進去，把他們的土地賜給你為繼業，就像今日這樣。</span>
<span className="v" id="v39" data-v="39" data-xref="約書亞記 2:11; 申命記 4:35; 歷代志上 29:11"> 所以你今天要知道，要銘記在心：天上地上唯獨耶和華是神，沒有另一位。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 6:3; 以弗所書 6:3; 申命記 12:28"> 你要遵守他的律例和誡命，就是我今日所吩咐你的，使你和你的後代子孫蒙福，也使你在你的神耶和華永遠賜給你的土地上日子長久。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 35:6; 民數記 35:14–15; 約書亞記 20:2–9"> 那時摩西在約旦河東岸劃分出三座城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 6:18; 申命記 19:1–10; 民數記 35:15–28"> 好讓那從前沒有仇恨、不是故意殺害鄰人的凶手，可以逃往那裡。他逃到其中的一座城，就可以存活：</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 20:8; 列王紀上 4:13; 約書亞記 21:27"> 屬於魯本人的，有平原之地曠野中的比冊爾；屬於迦得人的，有基列的拉末；屬於瑪拿西人的，有巴珊的戈蘭。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命記 27:3; 利未記 27:34; 瑪拉基書 4:4"> 這是摩西在以色列子孫面前設立的律法，</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 2:3; 申命記 4:1; 詩篇 119:7"> 就是摩西在他們出埃及之後，向以色列子孫宣告的法度、律例和法規。</span>
<span className="v" id="v46" data-v="46" data-xref="申命記 3:29; 申命記 4:47; 申命記 1:4–5"> 那時他們在約旦河對岸，在伯毗珥對面的山谷，那裡原是住希實本的亞摩利王西宏的領土，摩西和以色列子孫出埃及之後擊殺西宏，</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 3:1–14; 民數記 21:33–35; 申命記 29:7–8"> 占有了他和巴珊王歐革——約旦河東岸兩個亞摩利王的領土：</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 3:9; 申命記 2:36; 申命記 3:12"> 從亞嫩溪谷邊的亞羅珥，直到西翁山，就是黑門山；</span>
<span className="v" id="v49" data-v="49" data-xref="申命記 3:17; 約書亞記 13:20; 申命記 34:1"> 還有約旦河東岸整個亞拉巴流域，直到毗斯迦山坡下的亞拉巴海。</span>
</div>

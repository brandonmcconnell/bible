<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 申命記 12:1; 申命記 4:45"> 這是耶和華你們的神所吩咐要教導你們的誡命、律例和法規，好讓你們在即將過去占有的那地上遵行，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:40; 申命記 13:4; 出埃及記 20:20"> 好使你和你的子子孫孫一生一世都敬畏耶和華你的神，遵守我所吩咐你的一切律例和誡命，好使你的日子長久。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 22:17; 出埃及記 3:8; 創世記 26:4"> 以色列啊，你要聽，要謹守遵行，使你蒙福，使你們在流奶與蜜之地大大增多，正如你祖先的神耶和華向你所應許的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬可福音 12:29–32; 以賽亞書 44:6; 提摩太前書 2:5"> 以色列啊，你要聽：耶和華是我們的神，耶和華是唯一的！</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 12:30; 馬太福音 22:37; 路加福音 10:27"> 你要全心、全靈、全力愛耶和華你的神。</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:16; 箴言 7:3; 耶利米書 31:33"> 我今天吩咐你的這些話，你要銘記在心；</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:19; 以弗所書 6:4; 詩篇 78:4–6"> 也要勤勉教導給你的兒女，你坐在家裡、走在路上，你躺下、起來，都要談論這些話。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命記 11:18"> 你要把它們繫在手上作為標記，綁在額上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="額上——原文直譯「雙眼之間」。">a</a></sup>作為標誌。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 11:20; 以賽亞書 30:8; 以賽亞書 57:8"> 你也要把它們寫在你家的門框上、你的城門上。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:13; 詩篇 105:44; 尼希米記 9:25"> 你的神耶和華將領你進入他向你先祖亞伯拉罕、以撒、雅各起誓賜給你的那地：有雄偉美好的城邑，不是你建造的；</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 7:12–18; 申命記 8:10–20; 以西結書 16:10–20"> 有充滿各樣美物的房屋，不是你裝滿的；有開鑿好的水窖，不是你開鑿的；有葡萄園和橄欖園，不是你栽種的。那時你吃得飽足，</span>
<span className="v" id="v12" data-v="12"> 就要謹慎，免得忘記把你從埃及地為奴之家領出來的耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:8; 申命記 10:20; 馬太福音 4:10"> 你要敬畏耶和華你的神，唯獨服事他，指著他的名起誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 25:6; 約翰一書 5:21; 申命記 13:7"> 不可跟從別的神，就是你們周圍那些民族的神明，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:24; 出埃及記 20:5; 申命記 7:4"> 因為在你們中間的耶和華你的神是嫉憤的神，恐怕耶和華你的神對你發怒，就把你從這地面上除滅了。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 17:7; 路加福音 4:12; 馬太福音 4:7"> 不可試探耶和華你們的神，就像你們曾經在瑪撒試探他那樣。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 11:22; 詩篇 119:4; 哥林多前書 15:58"> 你們要切實謹守耶和華你們神所吩咐你的誡命、法度和律例。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 4:40; 申命記 12:25; 羅馬書 12:2"> 要做耶和華眼中看為正、看為好的事，好讓你蒙福，並且進去繼承耶和華起誓要給你先祖的那美地，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 33:52–53; 出埃及記 23:28–30; 士師記 3:1–4"> 把你一切仇敵都從你面前驅逐出去，正如耶和華所應許的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 13:14; 出埃及記 12:26; 約書亞記 4:6–7"> 日後當你的兒子問你說：「我們的神耶和華吩咐你們的這些法度、律例和法規，是什麼意思呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 6:17–18; 以弗所書 2:11–12; 申命記 15:15"> 你要對你的兒子說：「我們曾在埃及給法老作奴隸，耶和華用大能的手把我們從埃及領了出來。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 4:34; 詩篇 58:10–11; 申命記 7:19"> 耶和華在我們眼前施行了大而可怕的神蹟奇事，對付埃及，對付法老和他的全家。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 6:18; 申命記 6:10; 出埃及記 13:5"> 他從那裡領我們出來，為要把我們帶進他起誓要給我們先祖的土地，把那地賜給我們。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 32:39; 詩篇 41:2; 申命記 10:12–13"> 那時耶和華吩咐我們要遵行這一切律例，敬畏耶和華我們的神，使我們終生得福，讓我們得以存活，就像今日這樣。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 24:13; 羅馬書 10:3; 利未記 18:5"> 如果我們照著耶和華我們神所指示的，在他面前謹守遵行這一切誡命，這就是我們的義了。」</span>
</div>

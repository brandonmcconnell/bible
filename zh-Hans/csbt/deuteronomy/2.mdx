<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:4; 申命記 1:40; 民數記 14:25"> 然後我們轉回，照著耶和華所吩咐我的，沿著通往紅海的路前行往曠野去。我們繞行了西珥山許多日子。</span>
<span className="v" id="v2" data-v="2"> 耶和華吩咐我說：</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:6; 申命記 2:14; 申命記 2:7"> 「你們繞行這山地已經很久了，你們要轉向北去。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 20:14–21; 出埃及記 15:15; 申命記 23:7"> 你要吩咐百姓說：『你們的兄弟以掃子孫住在西珥，你們即將從他們境內經過，他們會懼怕你們，所以你們要特別謹慎。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 36:8; 約書亞記 24:4; 耶利米書 27:5"> 你們不要挑戰他們，他們的土地連一腳掌之地，我都不會給你們，因為我已經把西珥山賜給了以掃為產業。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:12; 民數記 20:19; 羅馬書 12:17"> 你們要用銀子向他們買食物吃，也要用銀子向他們買水喝，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米記 9:21; 申命記 8:2–4"> 因為耶和華你的神在你手中一切工作上祝福了你。他知道你走這大曠野，這四十年你的神耶和華一直與你同在，你什麼都不缺。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 9:26; 士師記 11:18; 列王紀下 16:6"> 於是我們繞過我們的兄弟——住在西珥的以掃子孫，繞過亞拉巴的路，繞過埃拉特和以旬迦別，然後轉向，沿著通往摩押曠野的路前行。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 19:36–37; 民數記 21:15; 民數記 21:28"> 耶和華對我說：「不要騷擾摩押，也不要向他們挑起戰爭，我不會把他們的土地給你為產業，因為我已經把亞珥賜給了羅得的子孫為產業。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 14:5; 申命記 2:11; 民數記 13:22"> 從前以米人住在那裡，這民雄偉眾多，並且像亞衲人那樣高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:28; 民數記 13:28; 創世記 14:5"> 他們像亞衲人一樣，也算是利乏音人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利乏音人——或譯作「巨人」。">a</a></sup>，而摩押人稱他們為以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:22; 創世記 14:6; 申命記 2:32–11"> 從前何利人也住在西珥，但以掃的子孫趕出他們，把他們從自己面前除滅了，然後取代他們住下來，就像以色列在耶和華賜給他們的產業之地上所做的那樣。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 21:12; 民數記 13:23"> 「現在你們起身，越過撒烈溪谷。」我們就越過了撒烈溪谷；</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 26:64–65; 民數記 14:28–35; 申命記 1:34–35"> 從離開加低斯-巴尼亞，到我們越過撒烈溪谷，有三十八年的時間，直到那整個世代的戰士都從營中滅盡了，正如耶和華向他們所起的誓。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 106:26; 以賽亞書 66:14; 詩篇 32:4"> 確實是耶和華出手對付了他們，使他們在營中潰亂，直到滅盡他們。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 民中的所有戰士全都死了之後，</span>
<span className="v" id="v17" data-v="17"> 耶和華吩咐我說：</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:23; 以賽亞書 15:1; 民數記 21:15"> 「你今天即將經過摩押的邊界亞珥，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:9; 士師記 11:13–27; 歷代志下 20:10"> 接近亞捫人。你不要騷擾他們，也不要挑戰他們，我不會把亞捫人之地給你為產業，因為我已經把它賜給了羅得的子孫為產業。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 14:5"> 那地也算是利乏音人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="利乏音人——或譯作「巨人」。">b</a></sup>之地。利乏音人從前住在那裡，亞捫人稱他們為扎慕祖姆人，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 27:7–8; 申命記 1:28; 申命記 2:22"> 這民雄偉眾多，並且像亞衲人那樣高大。但耶和華把他們從亞捫人面前除滅了，亞捫人趕出他們，然後取代他們住下來，</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 36:8; 創世記 36:20–30; 申命記 2:12"> 就像耶和華為住在西珥的以掃子孫所做的那樣——他把何利人從以掃子孫面前除滅了，以掃子孫趕出他們，然後取代他們住下來，直到今天。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 10:14; 約書亞記 13:3; 阿摩司書 9:7"> 至於住在各村莊直到加沙的亞瓦人，那些從迦斐托出來的迦斐托人把他們除滅了，然後取代他們住下來。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 27:5; 但以理書 4:17; 士師記 11:18–21"> 耶和華說<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶和華說——輔助詞語。">c</a></sup>：「你們要起身出發，越過亞嫩溪谷。看，我已經把亞摩利人希實本王西宏和他的領土交在你手中了。起來占領吧，向他發動戰爭！</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 11:25; 出埃及記 15:14–16; 申命記 28:10"> 從今天開始，我要使普天下的萬民對你恐懼害怕，他們將聽到你的消息就發抖，因你的緣故而震顫。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 約書亞記 13:18"> 於是我從基底莫曠野派遣使者到希實本王西宏那裡，傳達和平的話說：</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 11:19; 申命記 2:6; 民數記 21:21–23"> 「請讓我從你境內經過，我只沿著大道走，不偏離左右。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 20:19"> 你可以按價銀賣食物給我吃，也按價銀給我水喝，只要讓我徒步經過——</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 20:18; 士師記 11:17–18; 申命記 23:3–4"> 就像住在西珥的以掃子孫和住在亞珥的摩押人對待我的那樣——直到我過了約旦河，進入我們神耶和華所賜給我們的那地。」</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 21:23; 出埃及記 4:21; 約書亞記 11:19–20"> 但是希實本王西宏不肯讓我們從他那裡經過，因為你的神耶和華使他靈裡剛硬、內心頑固，為要把他交在你手中，就像今日這樣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 1:8; 申命記 2:24"> 耶和華對我說：「看，我已經把西宏和他的領土交給你了。起來占領吧，去占有他的領土！」</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 21:23–30; 士師記 11:20–23; 詩篇 136:19"> 那時西宏出來，他和他的全軍在雅哈茲迎戰我們。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 7:2; 約書亞記 21:44; 申命記 3:2–3"> 耶和華我們的神把他交給我們，我們擊殺了他和他的兒子們，以及他的全軍。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 7:2; 撒母耳記上 15:3; 申命記 3:6"> 那時我們攻取了他所有的城鎮，把所有城鎮的人，包括女人和孩童，全都滅絕了，沒有留下一人存活。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 8:27; 申命記 20:14; 民數記 31:9–11"> 只掠奪了牲畜和我們所攻取城鎮的財物，歸於自己。</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 13:9; 申命記 4:48; 申命記 3:12"> 從亞嫩溪谷邊的亞羅珥和溪谷中的城，直到基列，沒有一座城邑對我們是高不可破的，耶和華我們的神把這一切都交給我們了。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:24; 申命記 3:16; 創世記 32:22"> 只有亞捫人之地，就是雅博河全流域和那山地的城鎮，以及耶和華我們神所禁止<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="禁止——原文直譯「指示」。">d</a></sup>的一切地方，你沒有靠近。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 30:15; 列王紀上 8:47–48; 申命記 30:19"> 這一切話語，就是我所擺在你面前的祝福和詛咒，將應驗在你身上。如果你在你神耶和華驅散你到的萬國中回心轉意，</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 2:12–13; 尼希米記 1:9; 申命記 4:28–31"> 歸回耶和華你的神，如果你和你的兒女照著我今天所吩咐你的一切，全心、全靈聽從他的話，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:14; 以西結書 36:24; 詩篇 147:2"> 那時你的神耶和華必使你們的擄民回歸<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使你們的擄民回歸——或譯作「復興你們的家業」。">a</a></sup>，他必憐憫你，從他驅散你到的萬民那裡招聚你回來。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 1:9; 以西結書 39:25–29; 申命記 28:64"> 你就算是被驅散到天邊，你的神耶和華也必從那裡招聚你，把你從那裡帶回來。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 29:14"> 你的神耶和華會把你帶回你祖先曾經繼承的那地，你將繼承它；他必使你蒙福，使你人數增多超過你的祖先。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:16; 以西結書 36:26–27; 耶利米書 32:39"> 你的神耶和華會給你和你後裔的心行割禮，使你全心、全靈愛耶和華你的神，好讓你存活。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:15; 耶利米哀歌 4:21–22; 耶利米書 51:24–26"> 你的神耶和華會使這一切詛咒臨到你的仇敵，臨到那些恨你、追逼你的人。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 2:16; 以西結書 36:27; 以西結書 11:19–20"> 至於你，你會再次聽從耶和華的話，遵行他的一切誡命，就是我今天所吩咐你的。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 28:11–14; 耶利米書 32:41; 耶利米書 33:9"> 你的神耶和華會使你興旺，祝福你手中的一切工作，祝福你腹中的胎兒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="胎兒——原文直譯「果實」。">b</a></sup>、牲畜的幼仔<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="幼仔——原文直譯「果實」。">c</a></sup>和土地的出產<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="出產——原文直譯「果實」。">d</a></sup>。耶和華必再次樂意祝福你，像他曾經樂意祝福你的祖先那樣，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:40–41; 申命記 4:29; 尼希米記 1:9"> 因為你聽從你的神耶和華的話，遵守他寫在這律法書上的誡命和律例，全心、全靈回轉歸向耶和華你的神。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 45:19; 詩篇 147:19–20; 羅馬書 16:25–26"> 其實，我今天所吩咐你的這誡命，對你並不太難，也不遙遠。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 10:6–8; 箴言 30:4; 約翰福音 3:13"> 它不是在天上，以致你說：「誰能為我們升到天上去，把它取來，讓我們聽了可以遵行？」</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 10:33; 馬太福音 12:42; 箴言 2:1–5"> 也不是在大海的彼岸，以致你說：「誰能為我們過到大海的彼岸，把它取來，讓我們聽了可以遵行？」</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 10:8–10; 耶利米書 12:2; 馬太福音 7:21"> 相反，這話語離你很近，就在你口中，在你心裡，使你可以遵行。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 11:26; 申命記 30:19; 約翰一書 5:11–12"> 看，我今天把生命和福份、死亡和禍患都擺在你面前了：</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 30:6; 馬太福音 22:37–38; 約翰一書 5:2–3"> 我今天吩咐你要愛耶和華你的神，走在他的道路上，遵守他的誡命、律例和法規，這樣你就得以存活，人數增多，你的神耶和華必在你將進去擁有的那地上祝福你。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 4:4; 希伯來書 3:12; 箴言 1:32"> 但如果你的心背離，你不肯聽從，反而被引誘向別的神下拜，服事它們，</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 8:19–20; 以賽亞書 63:17–18; 申命記 4:26"> 我今天向你們宣告：你們必定滅亡；你們在即將過約旦河去擁有的那地上，日子不會長久。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 30:15; 申命記 11:26; 詩篇 119:30"> 我今天請諸天和大地對你們作見證：我把生命和死亡、祝福和詛咒擺在你面前了。你要選擇生命，好使你和你的後裔得以存活；</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 11:25–26; 申命記 10:20; 約翰福音 17:3"> 要愛耶和華你的神，聽從他的話，緊緊跟隨他，因為他是你的生命，使你日子長久，可以居住在耶和華向你先祖亞伯拉罕、以撒、雅各起誓要賜給他們的土地上。</span>
</div>

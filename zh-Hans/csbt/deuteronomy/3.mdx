<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:33–35; 申命記 1:4; 申命記 29:7"> 然後我們起身，沿著通往巴珊的路上去。那時巴珊王歐革出來，他和他的全軍在伊德賴迎戰我們。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 2:10; 歷代志下 20:17; 民數記 21:23–25"> 耶和華對我說：「你不要怕他，因為我已經把他和他的全軍以及他的領土，都交在你手中了。你要像對付住希實本的亞摩利王西宏一樣對付他。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 21:35; 約書亞記 13:12; 約書亞記 13:30"> 於是，耶和華我們的神把巴珊王歐革和他的全軍也交在我們手中了，我們擊殺他，沒有給他留下一人存活。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 4:13; 約書亞記 12:4; 約書亞記 13:30–31"> 那時我們攻取了他所有的城鎮；在巴珊的歐革王國，就是亞珥歌伯整個地區六十座城，沒有一座不被我們奪取的。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 1:28; 民數記 13:28; 希伯來書 11:30"> 這些全都是堅固的城，有高大的城牆，有門有閂；此外還有很多無城牆的村鎮。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:34; 詩篇 135:10–12; 申命記 2:24"> 我們把所有城鎮的人，包括女人和孩童，全都滅絕了，就像對付希實本王西宏那樣，把他們滅絕淨盡。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:35; 約書亞記 8:27; 約書亞記 11:11–14"> 只掠奪了城裡所有的牲畜和財物，歸於自己。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:9–12; 約書亞記 12:2–6; 民數記 32:33–42"> 那時，我們奪取了約旦河對岸兩個亞摩利王手中的領土，從亞嫩溪谷直到黑門山——</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 5:23; 詩篇 29:6; 以西結書 27:5"> 西頓人稱黑門為「西連」，而亞摩利人稱它為「示尼珥」。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 13:31; 約書亞記 13:11–12; 申命記 4:49"> 我們奪取了平原所有的城鎮，整個基列和整個巴珊，直到撒迦和伊德賴，都是巴珊的歐革王國的城鎮。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:5; 耶利米書 49:2; 撒母耳記下 12:26"> 利乏音人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利乏音人——或譯作「巨人」。">a</a></sup>的遺民中，只有巴珊王歐革殘留下來了。看哪，他的床是鐵床，按人肘算，長九肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="九肘——相當於4.1公尺。1肘=45.7公分。">b</a></sup>，寬四肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="四肘——相當於1.8公尺。">c</a></sup>，如今不是還在亞捫人的拉巴嗎？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:36; 民數記 32:32–38; 約書亞記 13:8–28"> 那時我們占有了這地：從亞嫩溪谷邊的亞羅珥起，我把基列山地的一半和其中的城鎮給了魯本人和迦得人；</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 32:39–42; 約書亞記 13:29–32; 歷代志上 5:23–26"> 基列其餘的土地，以及歐革王國整個巴珊，我給了瑪拿西半支派。亞珥歌伯整個地區，包括整個巴珊，都稱為利乏音人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="利乏音人——或譯作「巨人」。">d</a></sup>之地；</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 32:41; 約書亞記 13:13; 撒母耳記下 3:3"> 瑪拿西的子孫睚珥奪取了亞珥歌伯整個地區，直到基述人和瑪迦人的邊界，他就照著自己的名字稱呼這些地方，稱巴珊為睚珥鎮，直到今天。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 32:39–40; 約書亞記 17:1–3; 約書亞記 22:7"> 我把基列給了瑪吉；</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 21:24; 申命記 2:37; 撒母耳記下 24:5"> 至於給魯本人和迦得人的，是從基列直到亞嫩溪谷，以溪谷中間為邊界，直到亞捫人的邊界雅博河，</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 12:3; 創世記 14:3; 約書亞記 3:16"> 還有亞拉巴流域，以約旦河為邊界，從革尼勒湖<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="革尼勒湖——指加利利海；又稱「革尼撒勒湖、太巴列湖」。">e</a></sup>直到亞拉巴海，就是東邊毗斯迦山坡下的鹽海。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 32:20–24; 約書亞記 4:12–13; 約書亞記 1:12–15"> 那時我吩咐你們說：「你們的神耶和華已經把這地賜給你們了，讓你們去繼承。你們所有的勇士都要武裝起來，在你們弟兄以色列子孫的前面過去；</span>
<span className="v" id="v19" data-v="19"> 只有你們的妻子、孩子以及牲畜——我知道你們有很多牲畜——他們可以留在我所賜給你們的城鎮中。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 22:4; 約書亞記 22:8"> 等到耶和華使你們的弟兄像你們一樣得享安息，等他們也占有了耶和華你們神在約旦河對岸賜給他們的土地，那時候你們各人才可以回到我所賜給你們的產業去。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 27:18–23; 哥林多後書 12:10; 詩篇 9:10"> 那時我吩咐約書亞說：「你親眼看到了你們的神耶和華對這兩個王所做的一切，耶和華也會同樣對付你即將前往之處的所有王國。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 14:14; 申命記 20:4; 申命記 1:30"> 不要怕他們，因為你們的神耶和華是為你們爭戰的那一位。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 12:8–9"> 那時我向耶和華懇求說：</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 15:11; 申命記 11:2; 詩篇 71:19"> 「主耶和華啊，你已經開始向你的僕人顯明你的偉大和你大能的手。天上地上有哪個神行事，能像你的作為和大能呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 4:21–22; 以西結書 20:6; 出埃及記 3:8"> 求你讓我過去，看看約旦河對岸的那美地，那美好的山地和黎巴嫩。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 1:37; 申命記 31:2; 歷代志上 22:7–9"> 但耶和華因你們的緣故對我動怒，不願聽我。耶和華對我說：「夠了，不要再對我說這事了。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 27:12; 申命記 34:1–4; 創世記 13:14–15"> 你上毗斯迦山頂去吧，向西、向北、向南、向東舉目，用你的眼睛觀望，因為你不能過這約旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 31:3; 申命記 31:7; 申命記 1:38"> 不過你要指派約書亞，要使他堅強、勇敢，因為他要帶領這子民過去，他要使他們繼承你所觀望的那地。」</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 34:6; 申命記 4:46; 民數記 25:3"> 於是我們停留在伯毗珥對面的山谷中。</span>
</div>
</div>

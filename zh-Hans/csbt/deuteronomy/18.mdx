<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 18:8–9; 申命記 10:9; 哥林多前書 9:13–14"> 利未祭司、利未整個支派在以色列人當中沒有份，沒有繼業，他們要吃耶和華的火祭，那就是他們的繼業。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 1:5–6; 詩篇 84:11; 彼得前書 2:5"> 利未人在自己的弟兄當中沒有繼業；照著耶和華向他所應許的，耶和華就是他的繼業。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 7:30–34; 申命記 12:27"> 祭司從民眾應得的份是這些：那些祭獻牛或羊的人，要把祭物的前腿、腮頰和胃腸給祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 12:44–47; 民數記 18:12–24; 歷代志下 31:4–10"> 你也要把初熟的五穀、新酒和新油，以及初剪的羊毛給祭司。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:8; 民數記 3:10; 出埃及記 28:1–14"> 因為你的神耶和華從你各支派中揀選了利未，要讓他和他的子孫終生奉耶和華的名侍立事奉。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 35:2–3; 申命記 12:5; 申命記 16:2"> 如果有利未人從你的某一座城，從他所寄居的以色列任何地方離開，隨心所願來到耶和華所選擇的地方，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:2–4"> 他可以像在那裡侍立於耶和華面前的利未弟兄們那樣，奉他的神耶和華的名事奉。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 12:44; 尼希米記 12:47; 歷代志下 31:4"> 在他變賣家產的所得以外，他還可以享用與他們同等的份額。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 12:29–31; 利未記 18:26–27; 利未記 18:30"> 你進入你神耶和華所賜給你的那地以後，不可效法那些民族的可憎行為。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 19:31; 出埃及記 22:18; 利未記 19:26"> 你們中間不可有人讓自己的兒女經火，不可有占卜的、算命的、行法術的、行巫術的、</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 19:31; 撒母耳記上 28:11–14"> 念咒的、招魂的、通靈的、求問死人的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:24; 申命記 9:4; 利未記 18:27"> 因為凡是做這些事的人，都是耶和華所憎惡的；正是因為這些可憎之事，你的神耶和華才要把那些民族從你面前趕出去。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:48; 創世記 17:1; 創世記 6:9"> 你要在你的神耶和華面前作純全人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 14:16; 申命記 18:10; 創世記 20:6"> 你將要趕出的那些民族是聽從算命的和占卜的；至於你，你的神耶和華不允許你這樣做。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 3:22–23; 使徒行傳 7:37; 約翰福音 1:45"> 你的神耶和華將從你們中間，從你的弟兄中為你興起一位像我一樣的先知，你們要聽從他。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 20:19; 申命記 5:23–28; 申命記 9:10"> 正如在何烈山集會的日子，你向你的神耶和華所說的一切，那時你請求說：「不要讓我再聽到我的神耶和華的聲音，也不要讓我再看到這猛烈的火，免得我死亡。」</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 5:28"> 耶和華就對我說：「他們說的好。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 18:15; 約翰福音 8:28; 約翰福音 12:49–50"> 我將從他們的弟兄當中，為他們興起一位像你一樣的先知。我要把我的話放在他口中，他必把我所吩咐的一切都告訴他們。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 3:22–23; 希伯來書 2:3; 希伯來書 10:26"> 那時，如果有人不聽從我的話，就是他奉我名所說的話，我必向這人追討罪責<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罪責——輔助詞語。">a</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 13:1–5; 耶利米書 27:15; 耶利米書 23:13–15"> 但如果有先知擅自奉我的名，說我沒有吩咐他說的話，或者奉別神的名說話，那先知必須被處死。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 4:1–3; 帖撒羅尼迦前書 5:24; 啟示錄 2:2"> 如果你心裡想：『我們怎麼知道那不是耶和華說的話？』</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:20; 列王紀下 20:1; 耶利米書 28:1–17"> 那麼，當先知奉耶和華的名說話，而這話沒有成就，沒有應驗，這話就不是耶和華說的，是那先知擅自說的，你不必怕他。」</span>
</div>
</div>

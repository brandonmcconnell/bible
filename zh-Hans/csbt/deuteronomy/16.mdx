<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 34:18; 出埃及記 12:2–20; 出埃及記 13:4"> 你要謹守亞筆月，向你的神耶和華守逾越節，因為是在亞筆月，你的神耶和華夜間把你從埃及領了出來。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:5; 申命記 12:26; 路加福音 22:15"> 你要在耶和華所選擇使他的名安居的地方，從羊群牛群中獻上逾越節的祭牲給耶和華你的神。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 12:39; 出埃及記 34:18; 出埃及記 12:19–20"> 你不可把這祭牲與有酵之物同吃，七天都要與無酵餅——苦難的餅同吃，因為你是急匆匆出埃及地的；這樣你一生一世就能記住你出埃及地的日子。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 34:25; 出埃及記 12:10; 出埃及記 13:7"> 這七天中，在你的全境內不可看到酵；前一天傍晚獻祭的肉，一點也不可留到早晨。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 16:2; 申命記 12:5–6"> 你不能在你的神耶和華所賜給你的任意一座城中獻上逾越節的祭牲，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:5; 出埃及記 12:6–9; 民數記 9:11"> 只能在你的神耶和華所選擇使他的名安居的地方，在傍晚日落的時候，就是你出埃及的時刻，獻上逾越節的祭牲。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 35:13; 出埃及記 12:8–9; 約翰福音 2:23"> 你要在你的神耶和華所選擇的地方，把祭牲煮了吃。第二天早晨，你可以起身回家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——或譯作「自己的帳篷」。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 13:6–8; 利未記 23:6–8; 利未記 23:36"> 你要六天吃無酵餅；到了第七天，要為你的神耶和華舉行嚴肅集會，什麼工作都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 34:22; 出埃及記 23:16; 使徒行傳 2:1"> 你要為自己數算七個七日；從莊稼開鐮起，數算七個七日。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 16:2; 利未記 12:8; 瑪拉基書 3:10–11"> 然後照著你的神耶和華所祝福你的，獻上你手中足量的甘心祭物，向你的神耶和華守七七節。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:7; 申命記 12:12; 申命記 12:18"> 你和你的兒女、僕婢，以及你城裡的利未人，還有你們中間的寄居者、孤兒和寡婦，都要在你的神耶和華所選擇使他的名安居的地方，在你的神耶和華面前歡樂。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:15; 耶利米哀歌 3:19–20; 羅馬書 6:17–18"> 你要記住，你曾在埃及作過奴隸；你要謹守遵行這些律例。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及記 23:16; 約翰福音 7:2; 歷代志下 5:3"> 當你從打穀場和榨酒池收取了出產以後，你要守七天住棚節。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 8:9–12; 申命記 16:11; 以賽亞書 30:29"> 節期中，你和你的兒女、僕婢，以及你城裡的利未人、寄居者、孤兒和寡婦，要一同歡樂。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 23:36–42; 申命記 30:16; 申命記 16:10"> 你要在耶和華所選擇的地方，向你的神耶和華守七天節期；因為你的神耶和華會在你一切收成和你手中的一切工作上祝福你，你要盡情歡樂。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 詩篇 96:8; 哈該書 1:9"> 一年三次，就是除酵節、七七節和住棚節，你所有的男子都要在耶和華所選擇的地方，朝見耶和華你的神。他們不可空手朝見耶和華，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 9:6–7; 哥林多後書 8:12; 申命記 16:10"> 各人要照著你的神耶和華所賜的祝福，帶上力所能及的禮物。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志上 23:4; 出埃及記 18:25–26; 羅馬書 13:1–6"> 你要在你的神耶和華所賜給你的各城中，按著你的支派，設立審判官和官長。他們要以公義的裁決為百姓施行審判。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 19:15; 出埃及記 23:2; 箴言 17:23"> 你不可屈枉公正，不可顧及情面，也不可收取賄賂，因為賄賂能使智慧人眼瞎，又能曲解義人的證詞。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比書 4:8; 以西結書 18:9; 以西結書 18:5"> 公義，你一定要追求公義，好使你存活，繼承你的神耶和華賜給你的那地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 33:3; 列王紀下 17:16; 出埃及記 34:13"> 你為你的神耶和華修築的祭壇，旁邊不可栽下任何樹幹作為亞舍拉柱。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 26:1; 出埃及記 20:4; 撒迦利亞書 8:17"> 你也不可豎立你的神耶和華所憎惡的神柱。</span>
</div>

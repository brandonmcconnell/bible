<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 32:7–8; 申命記 31:8; 詩篇 20:7"> 當你出去與你的仇敵作戰時，看見戰車馬匹和軍兵比你多，你不要怕他們，因為帶你出埃及地的耶和華你的神與你同在。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 31:6; 歷代志下 13:12; 民數記 10:8–9"> 你們臨戰的時候，祭司要前來向軍兵講話，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 13:6; 詩篇 3:6; 啟示錄 2:10"> 對他們說：「以色列啊，你要聽：現在你們就要與你們的仇敵作戰了。你們不要膽怯，不要害怕，不要慌亂，不要因他們而恐懼，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 14:14; 申命記 3:22; 申命記 1:30"> 因為是你們的神耶和華與你們同去，為你們攻打你們的仇敵，拯救你們。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米記 12:27; 民數記 31:14; 申命記 16:18"> 然後官長也要向軍兵講話，說：「有誰建造了新房屋，還沒有舉行奉獻禮，這人可以離開，回自己的家去，免得他死在戰場上，而別人為那房屋舉行奉獻禮。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 19:23–25; 申命記 28:1–30; 耶利米書 31:5"> 有誰栽種了葡萄園，還沒有享用它，這人可以離開，回自己的家去，免得他死在戰場上，而別人享用那葡萄園。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 24:5; 申命記 28:30; 路加福音 14:18–20"> 有誰與一個女子訂了婚，還沒有迎娶，這人可以離開，回自己的家去，免得他死在戰場上，而別人娶那女子。」</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 7:3; 申命記 1:28; 啟示錄 21:8"> 官長還要吩咐軍兵說：「有誰懼怕或心裡軟弱，這人可以離開，回自己的家去，以免他弟兄們的心像他的心一樣消融。」</span>
<span className="v" id="v9" data-v="9"> 官長向軍兵講完了話，就要指派將領率領軍兵。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:5–6; 哥林多後書 5:18–1; 以弗所書 2:17"> 當你臨近一座城，要攻打它的時候，你先要向它呼籲和平。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 約書亞記 11:19–20; 約書亞記 16:10"> 如果那城以和平回應你，給你開門，那城裡的居民都要為你服苦役，服事你。</span>
<span className="v" id="v12" data-v="12"> 但如果那城不接受和平，而是與你作戰，你就要圍攻它。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:6–12; 列王紀上 11:15–16; 詩篇 110:1"> 當你的神耶和華把它交在你手中時，你要用刀擊殺那城所有的男子。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 8:2; 約書亞記 22:8; 民數記 31:9"> 只有婦女、孩童、牲畜，以及那城裡的一切——它所有的財物，你可以掠奪歸於自己。你可以享用從你仇敵得來的戰利品，這是你神耶和華所賜給你的。</span>
<span className="v" id="v15" data-v="15"> 所有離你很遠的城，不屬於周圍那些民族的城，你都要這樣處置。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 11:14; 民數記 21:2–3; 民數記 33:52"> 唯有以下民族的城，它們是你神耶和華所賜給你為繼業的，你不可讓任何有氣息的存活。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 34:5–6; 耶利米書 50:35–40; 申命記 7:1–2"> 你必須把這些赫提人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人滅絕淨盡，正如你神耶和華所指示你的；</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:30–31; 出埃及記 23:33; 以弗所書 5:11"> 免得他們教導你們去效法他們的一切可憎行為，就是他們為自己神明所做的，以致你們對你們的神耶和華犯罪。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 3:10; 約翰福音 15:2–8; 申命記 26:6"> 當你圍困一座城，需要攻打多日來攻取它，你不要掄起斧頭毀壞它的樹木；你可以從樹上得吃的，所以不要把樹砍掉。難道田野的樹木是人，要被你圍攻<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="要被你圍攻——或譯作「逃避你進入你的圍困」。">a</a></sup>嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 26:15; 耶利米書 33:4; 傳道書 9:14"> 只有那些你知道不是果樹的樹木，你可以砍伐它，用來修築圍城設施攻擊與你交戰的城，直到城陷落。</span>
</div>
</div>

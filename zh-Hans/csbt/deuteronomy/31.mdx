<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西前來對全體以色列人說了以下的話，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 34:7; 民數記 27:17; 列王紀上 3:7"> 他對他們說：「我現在已經一百二十歲，不能再出入了，耶和華也對我說：『你不能過這約旦河。』</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:3; 申命記 31:23; 申命記 3:28"> 你的神耶和華會親自在你前面過去，他將從你面前除滅這些民族，你必趕出他們。約書亞會帶領你過去，正如耶和華所說的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 23:28–31; 申命記 2:33; 申命記 3:3–11"> 耶和華將處置他們，像對待他所除滅的亞摩利王西宏和歐革，以及他們的領土那樣。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:2; 申命記 20:16–17; 出埃及記 23:32–33"> 耶和華會把他們交給你們，你們要照著我所吩咐的一切誡命處置他們。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 1:9; 以弗所書 6:10; 詩篇 27:14"> 你們要堅強、勇敢！不要害怕，不要因他們而恐懼，因為耶和華你的神，他是與你同去的那一位。他必不撇下你，也不離棄你。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 3:28; 申命記 31:6; 申命記 1:38"> 然後摩西把約書亞召來，在全體以色列人面前對他說：「你要堅強、勇敢！你必定帶領這子民進入耶和華向他們先祖起誓要賜給他們的那地，你必定使他們繼承那地。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 33:14; 申命記 31:6; 約書亞記 1:9"> 耶和華是走在你前面的那一位，他將與你同在；他必不撇下你，也不離棄你。你不要害怕，不要喪膽。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 4:15; 約書亞記 3:3; 申命記 17:18"> 摩西把這律法寫下來，交給抬耶和華約櫃的利未人祭司，以及以色列所有的長老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 23:34–43; 申命記 15:1–2"> 摩西吩咐他們說：「每七年的最後一年，就是所定的豁免年住棚節的時候，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:2; 約書亞記 8:34–35; 申命記 16:16–17"> 當全體以色列人前來，在耶和華所選擇的地方朝見你的神耶和華時，你要在全體以色列人面前宣讀這律法給他們聽。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:10; 詩篇 34:11–14; 申命記 6:6–7"> 你要招聚民眾，男人、女人、孩童，以及你城裡的寄居者，使他們都能聽到，使他們學習敬畏耶和華你們的神，謹守遵行這律法的一切話語。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 11:2; 申命記 6:7; 箴言 22:6"> 這樣他們那些不知道這律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="這律法——輔助詞語。">a</a></sup>的兒女也能聽到，並在你們即將過約旦河去擁有的那地上，一生一世都學習敬畏耶和華你的神。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 27:13; 申命記 31:23; 約伯記 2:1"> 耶和華對摩西說：「看哪，你死的日子臨近了。你把約書亞召來，一起站在會幕裡，我好指派他。」於是摩西和約書亞前來，站在會幕裡。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 40:38; 詩篇 99:7; 出埃及記 33:9–10"> 耶和華在會幕裡、在雲柱中顯現，雲柱立在會幕入口的上方。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 士師記 10:13; 士師記 2:12"> 耶和華對摩西說：「看哪，你就要與你的列祖一同長眠了。這子民會起來行淫追隨外邦神明，就是他們將要進入之地的神明；他們將會離棄我，違背我與他們所立的約。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 14:42; 以賽亞書 8:17; 詩篇 104:29"> 到那日，我的怒氣必向他們發作，我會離棄他們，向他們隱藏我的臉。他們將被吞滅，會有許多災禍和患難臨到他們。那時他們會說：『這些禍患臨到我們，難道不是因為我們的神不在我們中間了嗎？』</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 31:16–17"> 到那日，我必定因他所做的一切惡事隱藏我的臉，因為他轉向了別的神。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 申命記 31:21–22; 申命記 31:26"> 現在，你們要寫下這首歌，把它教給以色列子孫，把它放到他們口中，好讓這首歌成為我對以色列子孫的警誡<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="警誡——或譯作「見證」。">b</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿書 13:6; 申命記 6:10–12; 尼希米記 9:25–26"> 因為我領他們進入我起誓要給他們先祖的那地——流奶與蜜之地，他們吃得飽足，發胖了，就轉向別的神去服事它們，而藐視我，違背我的約。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 5:3; 詩篇 139:2; 約翰福音 2:24–25"> 當許多災禍和患難臨到他們時，這首歌必在他們面前作見證，這首歌絕不會從他們後裔的口中被忘掉。是的，在我領他們進入我起誓要給他們的那地以前，我就知道他們今天所懷的意念。」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 31:19; 申命記 31:9"> 摩西就在那天寫下這首歌，教給了以色列子孫。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 31:7–8; 申命記 31:14; 使徒行傳 7:45"> 然後，耶和華指派嫩的兒子約書亞，說：「你要堅強、勇敢！你必定把以色列子孫帶進我起誓要給他們的那地，我會親自與你同在。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 31:9; 申命記 17:18"> 那時，摩西把這律法的話語從頭到尾寫在書卷上，寫完了，</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 31:9"> 摩西就委派那些抬耶和華約櫃的利未人，說：</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 31:19; 列王紀下 22:8–11; 加拉太書 2:19"> 「你們把這律法書拿去，放在你們神耶和華的約櫃旁邊，要留在那裡作為對你們的警誡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="警誡——或譯作「見證」。">c</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 32:20; 申命記 9:24; 使徒行傳 7:51"> 因為我知道你們是悖逆的，是硬著頸項的。看哪，我今天還活著，與你們在一起，你們尚且悖逆耶和華，更何況我死了以後呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:1; 申命記 4:26; 申命記 30:19"> 你們把各支派的長老和官長全都招聚到我這裡來，我要把這些話說給他們聽，並且請諸天和大地對他們作見證。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 2:19; 申命記 32:5; 路加福音 21:24"> 我知道，我死了以後，你們必定敗壞，偏離我所指示你們的道路。日後必有禍患臨到你們，因為你們將做耶和華眼中看為惡的事，以你們手所造的去惹怒他。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯來書 3:2; 申命記 4:5; 約翰福音 12:49"> 然後，摩西把這首歌的歌詞從頭到尾宣讀給以色列全體會眾聽：</span>
</div>
</div>

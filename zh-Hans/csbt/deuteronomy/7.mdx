<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:3; 使徒行傳 13:19; 申命記 4:38"> 當耶和華你的神把你帶到你將進去占有的那地，並從你面前趕出許多民族，就是七個比你強盛的民族——赫提人、革迦撒人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人，</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 2:2; 出埃及記 23:32–33; 申命記 20:16–17"> 當耶和華你的神把他們交給你，你擊敗他們的時候，必須把他們滅絕淨盡，不可與他們立約，不可恩待他們。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:2; 約書亞記 23:12–13; 出埃及記 34:15–16"> 你不可與他們通婚，不可把你的女兒嫁給他們的兒子，也不可為你的兒子娶他們的女兒。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 6:15; 士師記 2:11; 申命記 4:26"> 因為他們會使你的兒女偏離耶和華<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和華——原文直譯「我」。">a</a></sup>不跟隨他，而去服事別的神，以致耶和華對你們發怒，很快把你們除滅。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 23:24; 申命記 12:2–3; 出埃及記 34:13"> 相反，你們要這樣對待他們：拆毀他們的祭壇，打碎他們的神柱，砍倒他們的亞舍拉柱，用火燒掉他們的雕像，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:2; 出埃及記 19:5–6; 彼得前書 2:9"> 因為你是你的神耶和華的聖潔之民；你的神耶和華從地上萬民中揀選了你，成為他寶貴的子民。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 10:22; 羅馬書 9:11–15; 羅馬書 11:6"> 耶和華鐘愛你們，揀選你們，不是因為你們比其他民族眾多——其實你們在萬民中是最少的——</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 20:2; 出埃及記 32:13; 以弗所書 2:4–5"> 而是因為耶和華對你們的愛，因他信守向你們祖先所起的誓。因此耶和華用大能的手把你們領了出來，救贖你們脫離那為奴之家，脫離埃及王法老的手。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:23; 提摩太後書 2:13; 帖撒羅尼迦後書 3:3"> 你要知道：唯獨你的神耶和華是神，是信實的神，他向那些愛他遵守他誡命的人守約施慈愛，直到千代；</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 59:18; 那鴻書 1:2; 羅馬書 12:19"> 而向那些恨他的人，他當面報應他們、消滅他們——他必當面報應那恨他的人，毫不遲延。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 14:15; 申命記 4:1; 申命記 5:32"> 所以我今天吩咐你的誡命、律例和法規，你都要謹守遵行。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 28:1–14; 申命記 7:9; 利未記 26:3–13"> 那時，因為你們聽從這些法規，謹守遵行，你的神耶和華就向你持守他與你先祖起誓立下的約和他的慈愛。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:21; 約翰福音 15:10; 申命記 28:3–5"> 他會愛你，祝福你，使你人數增多。在他向你先祖起誓要賜給你的土地上，他會祝福你腹中的胎兒和你土地的出產——你的五穀、新酒和新油，以及你的新生牛犢和羊羔。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 23:26–33; 申命記 28:4; 詩篇 127:3"> 你必蒙福超過萬民；在你們中間不會有不育的男人或不孕的女人，在你的牲畜中也是如此。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 15:26; 詩篇 105:36–37; 利未記 26:3–4"> 耶和華會使一切疾病都遠離你；你所知道的埃及各樣惡疾，他都不加在你身上，而是會降在所有恨你的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:33; 士師記 8:27; 申命記 13:8"> 你要吞滅你神耶和華交給你的所有民族，你眼中不可顧惜他們；你也不可服事他們的神明，因為這會成為你的陷阱。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 13:32; 民數記 33:53; 申命記 18:21"> 也許你心裡想：「這些民族比我眾多，我怎能趕出他們？」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 105:5; 申命記 31:6; 申命記 1:29"> 你不要懼怕他們，要好好回想你的神耶和華對法老和全埃及所做的事，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:34; 尼希米記 9:10–11; 耶利米書 32:20–21"> 你親眼所見的大試煉，神蹟和奇事，以及你的神耶和華領你出來時所用大能的手和伸出的膀臂。你的神耶和華必同樣對付你所懼怕面對的各民族。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 24:12; 出埃及記 23:28–30"> 你的神耶和華還會派出黃蜂到他們中間，直到那些殘留的和躲藏起來的都從你面前消滅。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 1:5; 申命記 10:17; 尼希米記 9:32"> 你不要因他們而恐懼，因為你的神耶和華在你們中間，他是大而可畏的神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 23:29–30; 約書亞記 15:63"> 你的神耶和華會把這些民族從你面前一點一點地趕出去；你不能一下子消滅他們，免得田野的走獸增多而危害你。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 8:20; 申命記 2:15; 耶利米書 17:18"> 你的神耶和華會把他們交給你，使他們陷入大騷亂，直到他們被除滅。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 10:8; 約書亞記 23:9; 約書亞記 1:5"> 他會把他們的王交在你手中，你要使他們的名從天下消亡；沒有人能在你面前站立得住，直到你把他們除滅了。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 32:20; 歷代志上 14:12; 申命記 17:1"> 他們神明的雕像要用火燒掉，不可貪圖其上的金銀，收取歸自己，免得你因此陷入圈套，因為它是你神耶和華所憎惡的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 13:17; 何西阿書 14:8; 以西結書 11:18"> 你不可把可憎之物帶進你家裡，免得你像它那樣成為當滅之物。你要徹底厭惡它，徹底憎惡它，因為那是當滅之物。</span>
</div>

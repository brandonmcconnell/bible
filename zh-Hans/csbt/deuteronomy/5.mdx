<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 馬太福音 23:3; 申命記 29:10"> 摩西召來全體以色列人，對他們說：<br />以色列啊，要聽我今天向你們宣告的律例和法規，要學習，要謹守遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:23; 出埃及記 19:5–8; 出埃及記 24:8"> 耶和華我們的神在何烈山與我們立了約；</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:10–15; 創世記 17:21; 創世記 17:7"> 耶和華不是與我們的祖先立這約，而是與我們這些今天在這裡還活著的每一個人立約。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 19:18–19; 申命記 34:10; 出埃及記 19:9"> 耶和華在山上，從火焰中面對面與你們說話。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 3:19; 出埃及記 19:16; 出埃及記 20:18–21"> 那時我站在耶和華和你們之間，向你們傳達耶和華的話語，因為你們懼怕那火焰，沒有上山去。耶和華說：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 20:2–17; 詩篇 81:5–10; 利未記 26:1–2"> <span className="pl pl-1">「我是耶和華你的神，是把你從埃及地為奴之家領出來的那一位。</span></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 20:3; 馬太福音 4:10; 約翰一書 5:21"> <span className="pl pl-1">除我以外，你不可有別的神。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 20:4; 申命記 4:15–19"> <span className="pl pl-1">不可為自己造偶像</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="偶像——或譯作「雕像」。">a</a></sup><br /><span className="pl pl-1">，不可造上天、下地和地底下水中之物的任何形象。</span></span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 20:4–6; 出埃及記 34:7; 但以理書 9:4–9"> <br /><span className="pl pl-1">不可向它們下拜，也不可服事它們，因為我耶和華你的神是嫉憤的神。恨我的人，我必懲罰他們的罪孽，從父到子，甚至到三代、四代；</span></span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:28; 約翰一書 1:7; 耶利米書 32:18"> <br /><span className="pl pl-1">愛我並遵守我誡命的人，我必向他們施慈愛，直到千代。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:7; 利未記 19:12; 申命記 6:13"> <span className="pl pl-1">不可妄稱你神耶和華的名，因為妄稱耶和華名的人，耶和華必不讓他免於罪罰。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:8–11; 以賽亞書 58:13; 以賽亞書 56:6"> <span className="pl pl-1">要謹守安息日，把它分別為聖，正如你神耶和華所指示你的。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 20:12; 路加福音 13:14–16; 出埃及記 23:12"> <br /><span className="pl pl-1">六天你要勞碌，做你一切工作；</span></span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 4:4; 創世記 2:2; 出埃及記 23:12"> <br /><span className="pl pl-1">但第七日是你神耶和華的安息日，你和你的兒女、僕婢，你的牛驢和一切牲畜，以及你城裡的寄居者，都不可做任何工作，好讓你的僕婢可以像你一樣休息。</span></span>
<span className="v" id="v15" data-v="15" data-xref="申命記 5:6; 申命記 15:15; 申命記 16:12"> <br /><span className="pl pl-1">要記住，你曾在埃及地作奴隸，而耶和華你的神用大能的手和伸出的膀臂，把你從那裡領了出來，因此耶和華你的神吩咐你要守安息日。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 20:12; 以弗所書 6:1–3; 歌羅西書 3:20"> <span className="pl pl-1">要孝敬父母，正如你神耶和華所指示你的，好讓你的日子長久，在你神耶和華所賜給你的地上蒙福。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 20:13; 羅馬書 13:9; 馬太福音 5:21–22"> <span className="pl pl-1">不可殺人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 20:14; 路加福音 18:20; 利未記 20:10"> <span className="pl pl-1">不可通姦。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:15; 羅馬書 13:9; 以弗所書 4:28"> <span className="pl pl-1">不可偷竊。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:16; 出埃及記 23:1; 箴言 19:9"> <span className="pl pl-1">不可作假見證指證你的鄰人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 20:17; 羅馬書 13:9; 路加福音 12:15"> <span className="pl pl-1">不可貪愛你鄰人的妻子，不可貪圖你鄰人的房屋、田地、僕婢、牛驢，以及任何屬於你鄰人的東西。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 24:12; 出埃及記 31:18; 申命記 4:12–15"> 耶和華在山上，從火焰、密雲和幽暗中，向你們全體會眾大聲宣告了這些話，沒有增添別的；然後把這些話語寫在兩塊石版上，交給了我。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 20:18–19; 希伯來書 12:18–21"> 當時你們聽到黑暗中發出的聲音，並且山在火焰中燃燒，你們所有支派的首領和長老就都靠近我，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 4:33; 出埃及記 19:19; 出埃及記 33:20"> 說：「看哪，我們的神耶和華向我們顯示了他的榮耀和偉大，我們也聽到他從火焰中發出的聲音。今天我們看見了神與人說話，而人竟然能存活。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:16; 加拉太書 3:10; 哥林多後書 3:7–9"> 但現在，我們何必要死呢？這猛烈的火就要吞噬我們了。如果我們繼續聽我們的神耶和華的聲音，我們必定死。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 4:33; 羅馬書 3:20; 馬太福音 26:63"> 凡有血肉的，有誰像我們這樣，聽見永生神從火焰中說話的聲音，還能存活呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 20:19; 希伯來書 12:19"> 請你上前去，聽我們神耶和華所說的一切，然後把我們神耶和華所告訴你的，全都傳達給我們，我們會聽從並遵行。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 18:17; 民數記 36:5; 民數記 27:7"> 你們對我說話時，耶和華聽見了你們說的話。耶和華就對我說：「我聽見了這子民對你說的話，他們說的都很好。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 48:18; 以西結書 33:31–32; 申命記 11:1"> 但願他們終生都有這樣的心敬畏我，遵守我的一切誡命，好讓他們和他們的子孫永遠蒙福。</span>
<span className="v" id="v30" data-v="30"> 你去告訴他們，回自己的帳篷去。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 3:19; 以西結書 20:11; 申命記 5:1"> 至於你，要留在我這裡，我會把你當教導他們的誡命、律例和法規都告訴你，好使他們在我所賜給他們去繼承的那地上遵行。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約書亞記 23:6; 箴言 4:27; 約書亞記 1:7"> 所以，你們要照著耶和華你們神所指示你們的，謹守遵行，不可偏離左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 7:23; 申命記 4:40; 路加福音 1:6"> 你們要走在耶和華你們神所指示你們的一切道路上，好使你們存活，並且蒙福，在你們將繼承的那地上日子長久。</span>
</div>

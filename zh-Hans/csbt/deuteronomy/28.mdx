<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:19; 出埃及記 23:22; 利未記 26:3–13"> 如果你留心聽從你的神耶和華的吩咐，謹守遵行我今天指示你的一切誡命，你的神耶和華就會使你遠超過地上萬國。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 1:6; 申命記 28:15; 提摩太前書 4:8"> 如果你聽從你的神耶和華的吩咐，這一切祝福就會臨到你、追隨你：</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 144:12–15; 創世記 39:5; 哈該書 2:19"> <span className="pl pl-1">你在城中蒙福，在田間也蒙福。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 創世記 49:25; 申命記 7:13"> <span className="pl pl-1">你腹中的胎兒</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="胎兒——原文直譯「果實」；本章下同。">a</a></sup><br /><span className="pl pl-1">、土地的出產</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出產——原文直譯「果實」；本章下同。">b</a></sup><br /><span className="pl pl-1">、牲畜的幼仔</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="幼仔——原文直譯「果實」；本章下同。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你的牛犢和羊羔，都蒙福。</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">你的籃子和揉麵盆都蒙福。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 121:8; 民數記 27:17; 歷代志下 1:10"> <span className="pl pl-1">你出也蒙福，入也蒙福。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 22:38–41; 利未記 26:7–8; 詩篇 89:23"> 耶和華會使那些起來攻擊你的仇敵敗在你面前；他們從一條路出來攻擊你，卻將在你面前從七條路逃跑。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:10; 利未記 26:10; 箴言 3:9–10"> 在你的倉庫裡，以及你手所勞作的一切事上，耶和華都會賜福給你；你的神耶和華必在他賜給你的那地上祝福你。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 19:5–6; 申命記 7:6; 申命記 26:18–19"> 如果你遵守你的神耶和華的誡命，走在他的道路上，耶和華就會照著他向你所起的誓，堅立你作他聖潔的子民。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 7:14; 申命記 11:25; 耶利米書 33:9"> 那時，地上的萬民看見你被稱為耶和華名下的人，就會懼怕你。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 30:9; 箴言 10:22; 利未記 26:9"> 在耶和華向你先祖起誓要賜給你的土地上，耶和華會使你興旺，祝福你腹中的胎兒、牲畜的幼仔和土地的出產。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:6; 約珥書 2:23–24; 申命記 15:10"> 耶和華會為你敞開諸天他福份的寶庫，按時給你的土地賜下雨水，祝福你手中的一切工作。你將借貸給許多民族，自己卻不用借。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:1; 申命記 4:6–9; 腓立比書 1:27"> 耶和華會使你作頭不作尾，居上不居下——只要你聽從我今天所吩咐你的話語，謹守遵行你的神耶和華的誡命；</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 30:21; 申命記 5:32; 申命記 11:16"> 我今天所吩咐你們的一切話語，你不可偏離左右，不可去跟從別的神，服事它們。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 2:2; 申命記 28:2; 申命記 29:20"> 那時，如果你不聽從你的神耶和華的吩咐，不謹守遵行我今天所指示你的一切誡命和律例，這一切詛咒就會臨到你、追隨你：</span>
<span className="v" id="v16" data-v="16" data-xref="瑪拉基書 3:9–12; 箴言 3:33; 約珥書 1:4"> <span className="pl pl-1">你在城中受詛咒，在田間也受詛咒。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="哈該書 1:6; 申命記 28:5; 詩篇 69:22"> <span className="pl pl-1">你的籃子和揉麵盆受詛咒。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="利未記 26:26; 利未記 26:19–20; 約伯記 18:16–19"> <span className="pl pl-1">你腹中的胎兒、土地的出產，</span><br /><span className="pl pl-1">你的牛犢和羊羔，都受詛咒。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:6; 士師記 5:6–7; 歷代志下 15:5"> <span className="pl pl-1">你出也受詛咒，入也受詛咒。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 66:15; 瑪拉基書 2:2; 申命記 4:26"> 因為你行惡離棄了耶和華，耶和華必在你所做的，就是你手所勞作的一切事上，給你降下詛咒、騷亂和責罰，直到你被除滅，很快滅亡。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 26:25; 耶利米書 24:10; 耶利米書 16:4"> 耶和華會使瘟疫緊跟著你，直到他把你從你將要進去擁有的那地上滅絕。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司書 4:9; 利未記 26:16; 哈該書 2:17"> 耶和華會用癆病、熱病、炎症、酷熱、刀劍、枯焦和霉爛打擊你，它們將追趕你，直到你滅亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 26:19; 耶利米書 14:1–6; 列王紀上 18:2"> 你頭上的天將成為銅，你脚下的地將成為鐵。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 28:12; 以賽亞書 5:24; 阿摩司書 4:11"> 耶和華會使你地上的雨水成為灰塵和塵土，從天上降在你身上，直到你被除滅。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 30:17; 以西結書 23:46; 耶利米書 24:9"> 耶和華會使你敗在你的仇敵面前，你從一條路出來攻擊他，卻將在他面前從七條路逃跑；你的遭遇<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="遭遇——輔助詞語。">d</a></sup>將令地上的萬國戰兢。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 34:20; 耶利米書 16:4; 耶利米書 7:33"> 你的屍體將給天空的一切飛鳥和地上的走獸作食物，無人嚇走牠們。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 5:6; 申命記 28:35; 利未記 21:20"> 耶和華會用埃及的瘡，用腫瘤、癬和疥瘡打擊你，都是你不能治癒的。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦後書 2:9–11; 以賽亞書 19:11–17; 以賽亞書 6:9–10"> 耶和華會用瘋狂、瞎眼和心裡昏亂打擊你；</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 59:10; 約伯記 5:14; 士師記 6:1–6"> 你即使在正午也要摸索，就像瞎眼的在幽暗中摸索一樣。你的道路不會順利，你終生只會受欺壓、被搶奪，沒有人拯救。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司書 5:11; 耶利米書 8:10; 約伯記 31:10"> 你與一個女人訂了婚，卻會有別的男人與她同睡；你建造了房屋，卻不能住在其中；你栽種了葡萄園，卻不能享用。</span>
<span className="v" id="v31" data-v="31" data-xref="約伯記 1:14–15; 士師記 6:1"> 你的牛在你眼前被宰殺，你卻吃不到牠；你的驢從你面前被搶奪，不會歸還給你；你的羊被交給你的仇敵，沒有人救助你。</span>
<span className="v" id="v32" data-v="32" data-xref="約珥書 3:6; 申命記 28:41; 約伯記 17:5"> 你的兒女會被交給外邦人，你的眼睛終日張望甚至失明，你的手卻無能為力。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 5:17; 申命記 28:29–30; 以賽亞書 1:7"> 你土地的出產和你的一切辛苦所得，會被你所不認識的民族吃掉，你終生只會受欺壓，被壓迫；</span>
<span className="v" id="v34" data-v="34" data-xref="啟示錄 16:10–11; 申命記 28:68; 以賽亞書 33:14"> 你必因你眼見的景象而發瘋。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:27; 以賽亞書 3:24; 以賽亞書 3:17"> 耶和華會打擊你，使不能治癒的惡瘡臨到你膝蓋上、大腿上，從腳掌直到頭頂。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米書 16:13; 申命記 4:28; 列王紀下 25:11"> 耶和華會把你和你所立的王帶到你和你祖先不認識的國家去，你將要在那裡服事別的神——那些木頭和石頭。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 25:9; 列王紀上 9:7–8; 耶利米書 24:9"> 你將在耶和華引領你去的萬民中，令人驚駭、成為笑柄、被人諷刺。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哈該書 1:6; 彌迦書 6:15; 約珥書 1:4"> 你在田裡撒出去很多種子，收回來的卻很少，因為蝗蟲會吃掉它。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 17:10–11; 約珥書 2:2–4; 約拿書 4:7"> 你栽種、耕耘葡萄園，卻喝不到葡萄酒，收不到葡萄，因為蟲子會吃掉它。</span>
<span className="v" id="v40" data-v="40" data-xref="彌迦書 6:15; 詩篇 23:5; 詩篇 104:15"> 你全境都有橄欖樹，卻不能用油抹身，因為你的橄欖會未熟而落。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 28:32; 耶利米哀歌 1:5; 列王紀下 24:14"> 你生了兒女，卻不屬於你，因為他們將被擄去。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司書 7:1–2; 申命記 28:38–39"> 蝗蟲會吃光<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="吃光——原文直譯「占有」。">e</a></sup>你的一切樹木和你土地的出產。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 28:13; 撒母耳記上 13:19–23; 列王紀下 17:20"> 你們中間的寄居者會升高到你之上，越升越高；你卻會降卑，越降越卑微。</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 28:12–13; 耶利米哀歌 1:5"> 他借給你，你卻不能借給他；他作頭，你卻會作尾。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="申命記 28:15; 以賽亞書 1:20; 耶利米書 24:9–10"> 這一切詛咒都會臨到你，它們將追趕你，趕上你，直到你被除滅，因為你不聽從你的神耶和華的吩咐，不遵守他所指示你的誡命和律例。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 8:18; 申命記 28:37; 以西結書 14:8"> 這些詛咒會臨到你和你的後裔，成為標記和奇蹟，直到永遠。</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 16:11; 申命記 12:7–12; 尼希米記 9:35–37"> 因為你在一切豐盛中，沒有歡心樂意地服事耶和華你的神，</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 28:13–14; 耶利米哀歌 5:2–6; 以西結書 4:16–17"> 所以你必在飢餓、乾渴、赤身以及一切缺乏中，服事耶和華所派遣攻擊你的那些仇敵。耶和華會把鐵軛放在你的脖子上，直到把你除滅。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米書 49:22; 耶利米書 48:40"> 耶和華會從遠方，從地極帶來一個民族，像老鷹那樣疾飛攻擊你。那民族你聽不懂他們的語言，</span>
<span className="v" id="v50" data-v="50" data-xref="以賽亞書 47:6; 歷代志下 36:17; 路加福音 21:23–24"> 那民族面貌凶猛，不眷顧老年人，也不恩待少年人。</span>
<span className="v" id="v51" data-v="51" data-xref="申命記 28:33; 以賽亞書 62:8; 利未記 26:26"> 它會吞噬你牲畜的幼仔和土地的出產，直到你被除滅。它不會給你留下五穀、新酒和新油，以及你的牛犢和羊羔，直到把你消滅。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米書 52:4–7; 以西結書 4:1–8; 馬太福音 24:15–16"> 它會把你圍困在你的各城裡，直到你在全地所依靠的那些高大、堅固的城牆倒塌了；它必在你的神耶和華賜給你的全地上，在你的各城圍困你。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米書 19:9; 利未記 26:29"> 你會在仇敵對你的摧殘中，在圍困和壓迫中，吃你親生兒女<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="親生兒女——原文直譯「腹中的出產」。">f</a></sup>的肉——你神耶和華賜給你的兒女的肉。</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 15:9; 馬太福音 20:15; 申命記 13:6"> 你們中間最溫柔嬌貴的男人，也會惡眼看待他的兄弟、他懷中的妻子、他剩下的兒女，</span>
<span className="v" id="v55" data-v="55" data-xref="耶利米書 34:2; 耶利米書 52:6; 耶利米書 5:10"> 甚至不把他所吃兒女的肉，分一些給他們中的一個；因為在你的各城裡，在仇敵對你的摧殘中，在圍困和壓迫中，他沒有剩下任何東西。</span>
<span className="v" id="v56" data-v="56" data-xref="申命記 28:54; 以賽亞書 3:16; 耶利米哀歌 4:3–6"> 你們中間溫柔嬌貴的女人，就是那因嬌氣、嬌弱而不肯嘗試把腳掌放在地上的，也會惡眼看待她懷中的丈夫、她的兒子和女兒。</span>
<span className="v" id="v57" data-v="57" data-xref="以賽亞書 49:15; 創世記 49:10"> 甚至她兩腿間出來的胎胞和生下的兒女，她也會在你城裡，在仇敵對你的摧殘中，在圍困和壓迫中，因缺乏一切而暗中吃掉他們。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="以賽亞書 42:8; 耶利米書 7:9–10; 瑪拉基書 1:14"> 如果你不謹守遵行寫在這律法書上的一切話語，不敬畏「你的神耶和華」這榮耀可畏的名，</span>
<span className="v" id="v59" data-v="59" data-xref="馬可福音 13:19; 申命記 28:46; 但以理書 9:12"> 耶和華就會用奇特的災害責打你和你的後裔，那是持久嚴重的災害和持久惡性的疾病。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 7:15; 出埃及記 15:26; 申命記 28:27"> 他也會使你所懼怕的埃及一切疫病回到你身上，緊貼著你；</span>
<span className="v" id="v61" data-v="61" data-xref="申命記 4:25–26"> 甚至沒有寫在這律法書上的各種疾病、各種災害，耶和華也會使它們降在你身上，直到你被除滅。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:22; 尼希米記 9:23; 申命記 4:27"> 儘管你們多如天上的星辰，剩下的人也會很少，因為你不聽從你的神耶和華的吩咐。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米書 32:41; 申命記 30:9"> 耶和華曾經怎樣樂意使你們蒙福，使你們增多，那時，耶和華也會怎樣樂意使你們消亡，使你們滅盡；你們必從你進去擁有的土地上被拔出。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 4:27–28; 利未記 26:33; 耶利米書 16:13"> 耶和華會把你驅散到萬民中，從地這邊直到地那邊；你將在那裡服事你和你祖先不認識的別神——那些木頭和石頭。</span>
<span className="v" id="v65" data-v="65" data-xref="利未記 26:36; 羅馬書 11:10; 阿摩司書 9:4"> 在那些民族中，你得不到安寧，沒有可以落腳的歇息之處。耶和華會使你在那裡心中顫抖、眼睛失明、心靈絕望。</span>
<span className="v" id="v66" data-v="66" data-xref="耶利米哀歌 1:13; 希伯來書 10:27; 啟示錄 6:15–17"> 你的性命在你面前懸蕩不定，你日夜懼怕，不確定自己能否存活。</span>

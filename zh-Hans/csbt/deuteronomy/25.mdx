<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 17:15; 申命記 1:16–17; 申命記 17:8–9"> 如果人們中間有了爭訟，前來受審，審判官就要審斷他們，定義人為義，定惡人有罪。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:47–48; 馬太福音 10:17; 使徒行傳 5:40"> 那時，如果那惡人該受鞭打，審判官就要讓他趴下，照著他的罪行、以相應的數目在審判官面前鞭打他。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 18:3; 雅各書 2:2–3; 路加福音 15:30"> 可以鞭打他四十下，但不能再多，恐怕再多鞭打他，責打超過這數目，你的弟兄就在你眼中受辱了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="提摩太前書 5:17–18; 哥林多前書 9:9–10; 箴言 12:10"> 牛踹穀的時候，不可籠住牠的嘴。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 22:24; 路加福音 20:28; 馬可福音 12:19"> 如果兄弟同住，其中一個死了，而他沒有兒子，死者的妻子不可嫁到外面歸屬別人。她丈夫的兄弟要到她那裡去，娶她為妻，對她盡丈夫兄弟的責任。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 21:19; 詩篇 9:5; 詩篇 109:13"> 這妻子所生的頭生子要立在那死去兄弟的名下，以免兄弟的名從以色列中抹掉。</span>
<span className="v" id="v7" data-v="7" data-xref="路得記 4:5–6; 路得記 4:1–2"> 但如果那人不願娶他兄弟的妻子，他兄弟的妻子就要上城門口長老們那裡，說：「我丈夫的兄弟不肯為他兄弟在以色列中立名，不願對我盡丈夫兄弟的責任。」</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 4:6"> 本城的長老們要把那人召來，與他談話。如果他堅持說不願意娶她，</span>
<span className="v" id="v9" data-v="9" data-xref="路得記 4:7–8; 民數記 12:14; 以賽亞書 50:6"> 那人兄弟的妻子就要從長老們眼前過去，到他那裡脫掉他腳上的鞋子，然後往他臉上吐唾沫，聲明說：「不給自己兄弟家立後的人，就要被如此對待！」</span>
<span className="v" id="v10" data-v="10"> 從此，他家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——輔助詞語。">a</a></sup>的名就在以色列被稱為「脫鞋者之家」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 2:9; 羅馬書 3:8"> 如果有人和他弟兄彼此打架，其中一個人的妻子前來要從攻撃者手中解救她丈夫，就伸手抓住對方的私處，</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 19:13; 申命記 19:21; 申命記 7:2"> 你要砍掉她的手，你眼中不可顧惜她。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 11:1; 箴言 16:11; 利未記 19:35–37"> 你袋子裡不可有一大一小兩樣的砝碼。</span>
<span className="v" id="v14" data-v="14"> 你家裡不可有一大一小雙重標準的量斗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="雙重標準的量斗——原文直譯「兩種伊法」；伊法相當於22公升的穀物量器。">b</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 20:12; 申命記 4:40; 以弗所書 6:3"> 你要有誠實公平的砝碼，你要有誠實公平的量斗<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="量斗——原文直譯「伊法」；相當於22公升的穀物量器。">c</a></sup>，好讓你在你神耶和華所賜給你的土地上日子長久。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:1; 啟示錄 21:27; 申命記 22:5"> 因為凡是做那些事的，凡是行不義的，都是你神耶和華所憎惡的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 17:8–16; 民數記 25:17–18; 民數記 24:20"> 要記得你們出埃及時，亞瑪力人在路上是怎樣對待你的：</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 3:18; 詩篇 36:1; 箴言 16:6"> 當你疲乏困倦時，他在路上遇到你，從後面擊殺所有掉隊的人，毫不敬畏神。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 17:14; 撒母耳記上 14:48; 出埃及記 17:16"> 因此，當你的神耶和華使你脫離了四圍一切仇敵，你在你的神耶和華賜給你為繼業，讓你去繼承的那地上得享安息時，你必須把亞瑪力人的名號從天下抹掉；你不可忘記！</span>
</div>
</div>

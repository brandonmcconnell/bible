<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 23:4–5; 以西結書 34:16; 以賽亞書 58:7"> 你看見弟兄的牛或羊走散，不可掩面不顧，必須把牠們帶回來給你的弟兄。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 7:12; 帖撒羅尼迦前書 4:6"> 如果你弟兄不在你附近，或者你不認識他，你就要把牲畜帶回你家中，留在你那裡，等到你弟兄來尋找牠時，你就還給弟兄。</span>
<span className="v" id="v3" data-v="3"> 你也要同樣對待他的驢子、他的衣服，同樣對待你弟兄遺失而被你發現的任何東西；你不可掩面不顧。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 6:1–2; 希伯來書 12:12–13; 馬太福音 5:44"> 你看見弟兄的驢或牛倒在路上，也不可掩面不顧，必須幫他扶起來。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 11:4–15; 申命記 18:12"> 女人不可穿著男人的服裝，男人也不可穿上女人的衣服，因為凡是做這些事的人都是你神耶和華所憎惡的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 22:28; 箴言 12:10; 創世記 8:17"> 如果你在路上，在哪棵樹上或在地上發現一個鳥窩，裡面有幼雛或蛋，而母鳥臥在幼雛或蛋上，你不可把母鳥與雛鳥一起帶走。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; 箴言 22:4"> 你必須放了母鳥，只可把雛鳥或蛋帶走，好讓你蒙福，日子長久。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 11:2; 以賽亞書 22:1; 出埃及記 21:28–36"> 當你建造新房屋時，要在屋頂上安裝圍欄，以免有人從上面掉下來，血債就歸在你的家。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 19:19; 哥林多後書 11:3; 馬太福音 9:16"> 不可在你的葡萄園混類播種，否則你播種的收穫和葡萄園的收成都要歸於聖所<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="歸於聖所——或譯作「被沒收充公」。">a</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 6:14–16"> 不可使用牛和驢一同耕作。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 19:19"> 不可穿戴羊毛和細麻混紡的衣料。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 23:5; 民數記 15:37–41"> 你所穿的外衣四角要縫上穗子。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 29:21; 創世記 29:31; 以弗所書 5:28–29"> 如果某人娶了妻子，與她同房後卻嫌棄她，</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:19; 箴言 18:21; 箴言 18:8"> 指責她行為不端，給她帶來壞名聲，說：「我娶了這女子，親近了她，卻沒看到她的處女憑據。」</span>
<span className="v" id="v15" data-v="15"> 那女子的父母就要帶上女子的處女憑據，來到城門口本城的長老們那裡。</span>
<span className="v" id="v16" data-v="16"> 那女子的父親要對長老說：「我把女兒嫁給了這人為妻，他竟然嫌棄她。</span>
<span className="v" id="v17" data-v="17"> 看哪，他指責她行為不端，說：『我沒看到你女兒的處女憑據。』然而，這就是我女兒的處女憑據。」然後他們要在本城的長老們面前展開那塊布。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 18:21"> 本城的長老們就要把這人帶下去管教他，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:29; 馬太福音 19:8–9; 申命記 24:1–4"> 並且罰他一百謝克爾<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一百謝克爾——相當於1,140公克。1謝克爾=11.4公克。">b</a></sup>銀子，交給女子的父親，因為他給以色列的處女帶來了壞名聲。那女子仍然是他的妻子，他終生不能休棄她。</span>
<span className="v" id="v20" data-v="20"> 但如果這控告是真的，那女子沒有處女的憑據，</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 13:5; 創世記 34:7; 士師記 20:6"> 他們就要把那女子帶到她父家門口，本城的人要用石頭砸死她，因為她在父家行淫，在以色列做了醜惡的事。你要把這邪惡從你們中間除盡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 20:10; 以西結書 23:45–47; 約翰福音 8:4–5"> 如果一個男人被發現與有丈夫的女人同寢，他們兩個——那與女人同寢的男人和那女人都要被處死。你要把這邪惡從以色列除盡。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 1:18–19; 申命記 20:7"> 如果一個女子，是處女，已經與人訂了婚，有個男人在城中遇見她，與她同寢，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 22:21–22; 申命記 21:14; 哥林多前書 5:13"> 你們就要把他們兩個帶到本城的城門口，用石頭砸死——砸死那女子，是因為她在城中沒有呼救；砸死那男人，是因為他玷辱了鄰人的妻子。你要把這邪惡從你們中間除盡。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 13:14"> 但如果是一個男人在野外遇見已經訂了婚的女子，而那男人強行與她同寢，那麼，只要處死那與她同寢的男人，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 21:22"> 不可對那女子做什麼，那女子沒有犯該死的罪。正如有人起來攻擊鄰人，把他殺了那樣，這案件也是如此，</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 13:7"> 因為是那男人在野外遇見她，並且這已經訂婚的女子呼救了，卻沒有人拯救她。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 22:16–17"> 如果有一個男人遇見一個女子——是沒有訂婚的處女，強行與她同寢，被發現了，</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 22:19; 申命記 22:24; 申命記 21:14"> 那與她同寢的男人就要交給那女子的父親五十謝克爾銀子，然後那女子要歸他為妻，因為那男人玷辱了她；他終生不能休棄她。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:20; 哥林多前書 5:1; 利未記 18:8"> 人不可娶他父親的妻妾，不可揭開他父親的衣襟。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 6:5; 申命記 10:12; 路加福音 1:74–75"> 因此，你要愛耶和華你的神，終生謹守他的吩咐、律例、法規和誡命。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:2–5; 申命記 29:10; 使徒行傳 26:22"> 你們今天要知道：這不是對你們的兒女說的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="說的——輔助詞語。">a</a></sup>——<br />他們不知道，也沒有經歷過你們的神耶和華的管教，沒有經歷過他的偉大，他大能的手和伸出的膀臂；</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:27–45"> 他在埃及人當中向埃及王法老和他的全地所行的神蹟奇事，</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 106:11; 出埃及記 14:23–31; 出埃及記 15:19"> 以及他對埃及的軍隊、馬匹和戰車所做的，就是當他們追趕你們時，耶和華使紅海的水淹沒他們，永遠<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="永遠——原文直譯「直到今日」。">b</a></sup>消滅了他們；</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 77:20; 詩篇 106:12–48; 詩篇 78:14–72"> 還有他在曠野中怎樣對待你們，直到你們來到這地方；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:9–10; 詩篇 106:17; 民數記 16:1–35"> 還有他怎樣處置魯本人以利押的兒子大坍和亞比蘭，那時大地張開口，在全體以色列人中吞滅了他們和他們的家人、他們的帳篷，以及他們身邊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="身邊——原文直譯「腳前」。">c</a></sup>的一切活物。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:4–6; 詩篇 145:12; 詩篇 150:2"> 只有你們，親眼看到了耶和華所做的一切偉大作為。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:10; 約書亞記 1:6–7; 以弗所書 3:16"> 所以你們要遵守我今天吩咐你們的一切誡命，好使你們堅強，去占有你們將要過去占有的那地，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 3:8; 申命記 4:40; 申命記 6:2"> 並且在耶和華向你們先祖起誓要賜給他們和他們後裔的土地——流奶與蜜之地上日子長久。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 14:18"> 因為你將要進去占有的那地不像你們出來的埃及地，在埃及你播種後還要用腳來澆灌，像在菜園裡那樣；</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:7; 申命記 8:7–9; 詩篇 65:12–13"> 你們即將過去占有的那地，是有山有谷、有天上雨水滋潤之地，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 24:6; 詩篇 33:18; 列王紀上 9:3"> 是你的神耶和華眷顧之地，你的神耶和華的眼目從歲首到年終一直看顧它。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 10:12; 申命記 4:29; 申命記 6:17"> 到那時，如果你們留心聽從我今天吩咐你們的誡命，愛耶和華你們的神，全心、全靈服事他，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 5:7; 利未記 26:4; 以西結書 34:26"> 他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——依據七十士譯本；馬索拉文本作「我」。">d</a></sup>就按時給你們的土地賜下雨水，秋雨和春雨，使你可以收取你的五穀、新酒和新油，</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 104:14; 申命記 6:11; 約珥書 2:19"> 他<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他——依據七十士譯本；馬索拉文本作「我」。">e</a></sup>也在田野為你的牲畜供應牧草；你必吃得飽足。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 31:27; 希伯來書 3:12; 希伯來書 2:1"> 你們要謹慎，免得你們的心被引誘而偏離，去服事別的神，向它們下拜。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 8:35; 申命記 6:15; 歷代志下 6:26"> 那樣，耶和華的怒氣就會向你們發作，他會使天閉塞，不降雨水，以致土地不供應出產，你們就從耶和華賜給你們的美地上迅速滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 3:16; 申命記 6:6–9; 箴言 3:1"> 你們要把我這些話銘記在心，銘刻在靈魂中；要把它們繫在手上作為標記，綁在額上<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="額上——原文直譯「雙眼之間」。">f</a></sup>作為標誌。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 以賽亞書 38:19; 申命記 4:9–10"> 你們也要把這些話教導給你們的兒女，你坐在家裡、走在路上，你躺下、起來，都要談論這些話。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:9"> 你也要把它們寫在你家的門框上、你的城門上。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 這樣你們的日子，你們子孫的日子，就在耶和華向你們先祖起誓要賜給他們的土地上增多，如天地之久。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 6:17; 申命記 11:13; 申命記 10:20"> 如果你們切實謹守我所吩咐你們遵行的這一切誡命，愛耶和華你們的神，走在他的一切道路上，緊緊跟隨他，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:38; 申命記 9:1; 申命記 7:1–2"> 耶和華就會從你們面前趕出這些民族，你們必趕出比你們強大的民族。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 14:9; 出埃及記 23:31; 創世記 15:18–21"> 你們腳掌踏上的每一個地方，都將成為你們的；從曠野到黎巴嫩，從幼發拉底大河到西邊的海<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="西邊的海——指地中海。">g</a></sup>，將成為你們的地界。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:24; 出埃及記 23:27; 約書亞記 1:5"> 沒有人能在你們面前站立得住，你們的神耶和華會使你們所踏的全地都對你們恐懼害怕，正如他向你們所應許的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 30:1; 申命記 30:15–20; 加拉太書 3:10"> 看，我今天把祝福和詛咒擺在你們面前：</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 1:19; 申命記 28:1–14; 以賽亞書 3:10"> 你們如果聽從我今天所吩咐的、你們神耶和華的誡命，就必蒙福；</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:15–68; 羅馬書 2:8–9; 加拉太書 3:10"> 你們如果不聽從你們的神耶和華的誡命，偏離我今天所指示你們的道路，去跟從你們不認識的別神，就必受詛咒。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 27:12–26; 約書亞記 8:30–35"> 當你的神耶和華帶你來到你將要進去占有的那地時，你要在基利心山上宣告祝福，在以巴錄山上宣告詛咒。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 12:6; 士師記 7:1; 約書亞記 4:19"> 這兩座山不是在約旦河對岸嗎？就在西邊日落的方向，亞拉巴的居民迦南人之地上，在吉甲對面、摩利的橡樹林附近。</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 1:11; 申命記 9:1; 約書亞記 3:13–17"> 你們即將過約旦河，進去占有耶和華你們神所賜給你們的那地，你們占有了它，住在其中以後，</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 28:20; 申命記 12:32; 帖撒羅尼迦前書 4:1–2"> 要謹守遵行我今天在你們面前設立的一切律例和法規。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 5:2–3; 希伯來書 8:9; 出埃及記 24:2–8"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在馬索拉文本為28:69至29:28。">a</a></sup>耶和華在何烈山與以色列子孫立約之外，也在摩押地指示摩西與他們立約，以下是立約的話語。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:4; 出埃及記 8:12; 約書亞記 24:5–6"> 摩西召來全體以色列人，對他們說：<br />耶和華在你們眼前，在埃及地對法老和他所有臣僕以及在他全地所做的一切，你們都已經看到了，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:32–35; 尼希米記 9:9–11; 申命記 7:18–19"> 就是你們親眼看到的大試煉，那些極大的神蹟和奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 4:18; 以賽亞書 6:9–10; 箴言 20:12"> 但耶和華至今沒有賜給你們能明白的心、能看見的眼睛、能聽見的耳朵。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 8:4; 尼希米記 9:21; 申命記 8:2"> 四十年之久，我帶你們走在曠野，你們身上的衣服沒有破，腳上的鞋也沒有爛，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:3; 以弗所書 5:18; 哥林多前書 9:25"> 你們沒有吃餅，也沒有喝淡酒烈酒，這是讓你們知道「我耶和華是你們的神」。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:24–17; 民數記 32:33–42; 詩篇 135:10–12"> 你們來到這地方的時候，希實本王西宏和巴珊王歐革出來迎戰我們，但我們擊敗了他們，</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:12–13; 民數記 32:33"> 並奪取他們的領土，分給了魯本人、迦得人、瑪拿西半支派的人為繼業。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:3; 申命記 4:6; 路加福音 11:28"> 所以你們要謹守遵行這約上的話語，好讓你們所做的一切都通達。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約珥書 2:16–17; 啟示錄 20:12; 申命記 31:12–13"> 今天你們全都站在你們的神耶和華面前——包括你們眾支派的首領，你們的長老和官長，以色列的所有男子，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 12:38; 約書亞記 9:21–27; 出埃及記 12:48–49"> 你們的孩子、妻子，以及在你營中為你砍柴打水的寄居者——</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 15:12–15; 列王紀下 11:17; 申命記 5:2–3"> 為要進入你的神耶和華的約，進入你的神耶和華今天與你所立的誓言，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 6:7; 創世記 17:7; 申命記 28:9"> 好讓他今天確立你作他的子民，而他作你的神，正如他向你所應許的，向你先祖亞伯拉罕、以撒、雅各所起的誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:31–34; 希伯來書 8:7–12"> 他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他——原文直譯「我」。">b</a></sup>不僅僅與你們立這約和這誓言；</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:39; 哥林多前書 7:14; 耶利米書 50:5"> 他是與今天一同站在我們神耶和華面前的人立約，也與今天沒有一同站在這裡的人立約。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 2:19; 申命記 2:9; 申命記 2:4"> 你們都知道，我們怎樣住在埃及地，又怎樣從那些民族中間經過；</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:36"> 也看見了他們的可憎之物，以及他們中間那些木、石、金、銀的偶像。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:15; 申命記 11:16–17; 申命記 13:1–15"> 現在恐怕你們中間有人——或男或女，或家族或支派，心思轉離耶和華我們的神，去服事那些民族的神明。恐怕你們中間有惡根長出苦毒，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 7:24; 民數記 15:30; 民數記 15:39"> 有人聽見這誓言，心中卻暗自慶幸說：「即使我隨著頑固的心行事，還是會有平安！」這樣濕地和旱地就會一起被摧毀。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 74:1; 詩篇 79:5; 申命記 9:14"> 耶和華絕不願赦免他，那時耶和華的怒氣和妒火必向這人燃起，寫在這書卷上的一切詛咒會降在他身上，耶和華必從天下抹掉他的名。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:41; 約書亞記 7:1–26; 以西結書 13:9"> 耶和華必照著這律法書上所寫聖約的一切詛咒，把他從以色列所有支派中分別出來，使他遭受禍患。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 19:8"> 這樣，在你們之後興起的後代子孫，以及從遙遠之地而來的外邦人將會議論，因為他們將看到這地的災害和耶和華降在這地上的疾病——</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅書 2:9; 耶利米書 17:6; 以賽亞書 34:9"> 遍地都是硫磺、鹽鹼，是燒毀之地，沒有耕種，沒有出產，地上不能長出任何植物，就像耶和華在怒氣和怒火中覆滅的所多瑪、格摩拉、押瑪和洗扁那樣——</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 22:8–9; 列王紀上 9:8–9; 羅馬書 2:5"> 列國都會說：「耶和華為什麼如此對待這地呢？這樣大發烈怒是為了什麼呢？」</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 8:9; 以賽亞書 47:6; 耶利米書 50:7"> 人們會說：「是因為他們離棄了祖先的神耶和華的約，就是他從埃及地把他們領出來時，與他們所立的約；</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:64; 士師記 2:12–13; 士師記 5:8"> 而去服事別的神，向他們不認識的、耶和華沒有指定給他們的神明下拜。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 9:11–14; 申命記 28:15–68; 申命記 27:15–26"> 所以耶和華的怒氣向這地發作，使寫在這書卷上的一切詛咒都臨到這地。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 7:20; 列王紀上 14:15; 詩篇 52:5"> 耶和華在怒氣、怒火和極大的震怒中，把他們從自己的土地上拔出來，扔到異國，就像今日這樣。」</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:22; 使徒行傳 1:7; 羅馬書 11:33–34"> 隱祕的事屬於耶和華我們的神，顯明的事永遠屬於我們和我們的子孫，好讓我們遵行這律法的一切話語。</span>
</div>

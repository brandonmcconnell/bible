<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="15" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 5:6; 使徒行傳 15:5; 利未記 12:3"> 有一些人從猶太下來，教導弟兄們說：「你們如果不按摩西的規矩受割禮，就不能得救。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 15:22–23; 使徒行傳 15:6–7; 加拉太書 2:1–2"> 保羅、巴拿巴與他們發生了不小的爭執和辯論，他們就指定保羅、巴拿巴和其中的另一些人為這爭議的問題，上耶路撒冷到使徒們和長老們那裡去。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 14:27; 使徒行傳 21:5; 哥林多前書 16:11"> 於是教會送他們上路；他們就走遍腓尼基和撒瑪利亞地區，詳細說明外邦人悔改的事，給所有弟兄們帶來了極大的喜樂。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:27; 使徒行傳 15:12; 使徒行傳 15:3"> 來到耶路撒冷，他們受到教會、使徒們和長老們的歡迎，就向大家傳講了神與他們一起做的事。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:1–3; 腓立比書 3:5–8; 使徒行傳 15:1"> 但法利賽教派中的一些信徒站起來，說：「必須給外邦人行割禮，並吩咐他們遵守摩西的律法。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯來書 13:7; 希伯來書 13:17"> 使徒們和長老們就聚集探討這件事。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 10:17–18; 加拉太書 2:7–9; 歷代志上 28:4–5"> 經過了許多辯論，彼得站起來對他們說：「各位弟兄，你們知道前些時候神在你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——有古抄本作「我們」。">a</a></sup>中間施行揀選，要外邦人藉著我的口聽到福音之道，得以相信。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:24; 使徒行傳 10:47; 使徒行傳 14:3"> 於是那洞察人心的神，賜聖靈給他們做了見證，就像為我們做的那樣；</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 3:6; 加拉太書 5:6; 使徒行傳 10:28"> 又藉著信潔淨了他們的心，在我們和他們之間不做什麼區別。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 5:1; 馬太福音 23:4; 加拉太書 4:9"> 既然如此，你們現在為什麼試探神，把我們的祖先和我們都擔當不了的軛，放在那些門徒的脖子上呢？</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:24; 提多書 3:4–7; 提多書 2:11"> 相反，我們相信：我們得救是藉著主耶穌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶穌——有古抄本作「耶穌基督」。">b</a></sup>的恩典，外邦人也是一樣。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 14:27; 使徒行傳 15:4; 使徒行傳 21:19"> 這時，全體會眾都靜默無聲，聽巴拿巴和保羅述說神藉著他們在外邦人中所行的神蹟和奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 12:17; 加拉太書 2:12; 雅各書 1:1"> 他們講完以後，雅各就回應說：「各位弟兄，請聽我說。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得後書 1:1; 使徒行傳 15:7–9; 路加福音 2:31–32"> 西門已經述說了神當初怎樣臨到<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="臨到——或譯作「照顧」。">c</a></sup>外邦人，從他們中間選出子民，歸入自己的名。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 15:8–12; 使徒行傳 13:47"> 連先知們的話也與此相符，正如經上所記：</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 9:11–12; 詩篇 89:35–49; 路加福音 1:31–33"> <span className="pl pl-1">『此後我將要回來，</span><br /><span className="pl pl-1">重建大衛倒塌的居所</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="居所——原文直譯「帳幕」。">d</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">我要重建它的破損之處，把它重新豎立起來。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亞書 2:11; 撒迦利亞書 8:20–23; 以賽亞書 65:1"> <span className="pl pl-1">這樣，其餘的人，</span><br /><span className="pl pl-1">就是所有被稱為我名下的外邦人，</span><br /><span className="pl pl-1">都會尋求主。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 1:4; 以弗所書 3:9; 以賽亞書 46:9–10"> <span className="pl pl-1">這是自古以來，讓人知道這些事的主說的。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 15:28; 加拉太書 1:7–10; 使徒行傳 15:24"> 因此，我判定不可為難那些歸向神的外邦人，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 15:29; 啟示錄 2:20; 利未記 3:17"> 不過要寫信給他們：要遠避偶像的汙穢，遠避淫亂、勒死的動物和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:15; 使徒行傳 13:27; 哥林多後書 3:14–15"> 因為自古以來，在各城裡都有人宣講摩西，每逢安息日在各會堂裡都有人誦讀他的書<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他的書——輔助詞語。">e</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 15:27; 使徒行傳 15:40; 帖撒羅尼迦前書 1:1"> 當時，使徒們、長老們和全教會都認為應該從他們當中揀選幾個人，派他們與保羅和巴拿巴一起到安提阿去。被選的是<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="被選的是——輔助詞語。">f</a></sup>那稱為巴撒巴的猶大和西拉斯，這兩個人在弟兄中是領頭的。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 23:26; 雅各書 1:1; 加拉太書 1:21"> 他們帶去的信這樣寫著：<br />「做使徒的和年長的弟兄們，問候安提阿、敘利亞省和奇里乞亞省的外邦弟兄們。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="加拉太書 5:12; 加拉太書 5:10; 使徒行傳 15:1"> 我們聽說從我們這裡出去<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「出去」。">g</a></sup>的一些人，用一些話使你們不安，攪擾你們的心靈。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「說你們必須受割禮並遵守律法。」">h</a></sup>其實我們沒有吩咐他們。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得後書 3:15; 使徒行傳 1:14; 使徒行傳 15:2"> 我們已達成了一致，認為應該揀選幾個人，派他們與我們親愛的巴拿巴和保羅一起到你們那裡去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 14:19; 使徒行傳 9:23–25; 腓立比書 2:29–30"> 這兩個人都為我們主耶穌基督的名，已經把自己的生命置之度外。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 15:22; 使徒行傳 15:32; 約翰三書 1:13"> 所以我們派了猶大和西拉斯去，他們會親口報告同樣的事，</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 16:13; 啟示錄 2:24; 馬太福音 11:30"> 因為聖靈和我們都認為，除了以下幾件必須遵守的事以外，不該把更多的重擔加給你們：</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 15:20; 使徒行傳 21:25; 啟示錄 2:14"> 就是要遠避祭過偶像的食物，遠避血和勒死的動物，遠避淫亂。你們如果保守自己遠離這些，就做得很好了。<br />祝你們安康！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 16:4; 使徒行傳 6:2; 使徒行傳 23:33"> 於是這些人被派遣，下<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="下——有古抄本作「去」。">i</a></sup>到安提阿，召集了會眾，把信函交給他們。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 2:4–5; 腓立比書 3:3; 加拉太書 5:1"> 讀完了信，會眾因著那鼓勵的話而感到歡喜。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 11:23; 使徒行傳 14:22; 使徒行傳 13:1"> 猶大和西拉斯自己也是做先知傳道的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="做先知傳道的——原文直譯「先知」。">j</a></sup>。他們用很多話鼓勵弟兄們，堅固他們。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 16:11; 使徒行傳 16:36; 希伯來書 11:31"> 兩個人住了一段時間，弟兄們就打發他們平平安安地回到差派他們的人<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="差派他們的人——有古抄本作「使徒們」。">k</a></sup>那裡去。</span>
<span className="v" id="v34" data-v="34"> 可是西拉斯認為應該留在那裡。<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有此節。">l</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太後書 4:2; 歌羅西書 1:28; 使徒行傳 13:1"> 保羅和巴拿巴也住在安提阿，與其他許多人一起教導、傳揚主的福音<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="福音——原文直譯「話語」或「道」。">m</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 14:6; 使徒行傳 13:4; 使徒行傳 13:51"> 過了幾天，保羅對巴拿巴說：「來，讓我們回到我們傳過主福音<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="福音——原文直譯「話語」或「道」。">n</a></sup>的每一個城，探望<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="探望——或譯作「照顧」。">o</a></sup>弟兄們，看看他們的情況怎麼樣<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="看看他們的情況怎麼樣——原文直譯「看看他們現在怎麼樣」。">p</a></sup>。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 12:12; 腓利門書 1:24; 使徒行傳 13:5"> 巴拿巴一直想要帶那稱為馬可的約翰一起去。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 13:13; 箴言 25:19; 路加福音 14:27–34"> 但是保羅覺得不該帶他一起去，因為他曾在潘菲利亞省離開他們，沒有陪他們一起去工作。</span>
<span className="v" id="v39" data-v="39" data-xref="歌羅西書 4:10; 傳道書 7:20; 使徒行傳 4:36"> 兩個人起了激烈的爭執，以致彼此分手。巴拿巴帶著馬可，坐船到塞浦路斯島去；</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 15:22; 使徒行傳 14:26; 使徒行傳 11:23"> 保羅卻選了西拉斯。弟兄們把保羅交託於主<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="主——有古抄本作「神」。">q</a></sup>的恩典之後，他就出發了。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 15:23; 加拉太書 1:21; 使徒行傳 15:32"> 保羅走遍敘利亞省和奇里乞亞省，堅固各教會。</span>
</div>
</div>

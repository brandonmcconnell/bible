<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="16" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:5; 提摩太後書 1:2; 哥林多前書 4:17"> 保羅到達代爾貝城，又到了路司得城。當時，那裡有一個名叫提摩太的門徒，是一個信主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主——輔助詞語。">a</a></sup>的猶太婦人的兒子，他父親是希臘人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 5:10; 提摩太後書 3:15; 使徒行傳 14:21"> 路司得和以哥念的弟兄們都讚許他。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 2:3; 哥林多前書 9:20; 加拉太書 5:6"> 保羅想要帶他一起去，但為了那些地方的猶太人的緣故，就給他行了割禮，因為大家都知道他父親是希臘人。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 15:28–29; 使徒行傳 15:2; 使徒行傳 11:30"> 當他們經過那些城鎮的時候，就把耶路撒冷的使徒們和長老們所定的規條，傳達給大家遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:31; 使徒行傳 2:47; 使徒行傳 6:7"> 這樣，各教會在信仰上得了堅固，人數也天天增加。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 18:23; 使徒行傳 16:7; 使徒行傳 13:2–4"> 聖靈既然阻止他們在亞細亞省傳講福音<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="福音——原文直譯「話語」或「道」。">b</a></sup>，他們就走遍弗里吉亞和加拉太地區。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:9; 腓立比書 1:19; 加拉太書 4:6"> 他們來到密細亞地區的邊界，試著要往比提尼亞省去，可是耶穌的靈<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶穌的靈——有古抄本作「聖靈」。">c</a></sup>不允許。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 2:12; 提摩太後書 4:13; 使徒行傳 16:11"> 他們就經過密細亞地區，下到特羅阿斯港。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 9:10–12; 使徒行傳 19:21; 使徒行傳 18:5"> 夜裡，保羅看見了一個異象：一個馬其頓人站著懇求他，說：「請你過來，到馬其頓來幫助我們。」</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 2:12–13; 使徒行傳 14:7; 使徒行傳 16:10–17"> 當保羅看見這異象之後，我們就認定是神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——有古抄本作「主」。">d</a></sup>召喚我們去傳福音給他們，於是立刻設法前往馬其頓省。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:1; 使徒行傳 16:8"> 我們從特羅阿斯港開船直航，到薩莫特拉島，第二天到了奈阿波利斯港，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 2:2; 腓立比書 1:1; 使徒行傳 20:6"> 從那裡來到腓立比。那是馬其頓省的首要城市，是羅馬的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="羅馬的——輔助詞語。">e</a></sup>殖民地。我們在這城裡住了幾天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 13:14; 歌羅西書 1:23; 使徒行傳 17:2"> 安息日那天，我們出了城門，來到河邊，想到那裡有一個禱告的地方。我們就坐下來，對聚集在那裡的婦女們講道。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 1:17–18; 路加福音 24:45; 以賽亞書 50:5"> 有一個敬拜神的婦人，名叫莉迪婭，是錫亞蒂拉城賣紫色布的商人。她一直在聽，主開啟她的心竅，使她留心保羅所講的話。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 11:14; 希伯來書 13:2; 使徒行傳 16:33"> 當她和她的家人受了洗之後，她請求我們說：「如果你們判斷我是主的信徒<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="信徒——或譯作「忠心的人」。">f</a></sup>，請到我家裡來住。」於是她極力挽留我們。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 19:31; 申命記 18:9–11; 以賽亞書 8:19"> 有一次，我們往禱告的地方去，迎面來了一個有占卜邪靈附身的女僕。她用算命為她的主人們帶來大量的生意。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 14:6; 彼得前書 2:16; 馬可福音 5:7"> 她跟著保羅和我們，喊叫說：「這些人是至高神的奴僕，向你們<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="你們——有古抄本作「我們」。">g</a></sup>傳講救恩的道<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="道——或譯作「路」。">h</a></sup>。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 16:17; 路加福音 10:17–19; 使徒行傳 3:6"> 她一連幾天都這樣做。<br />保羅厭煩了，就轉過身對那邪靈說：「我奉耶穌基督的名，吩咐你從她身上出來！」那邪靈立刻就出來了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:6; 使徒行傳 21:30; 使徒行傳 8:3"> 女僕的主人們看見他們的生意沒有希望了，就揪住保羅和西拉斯，把他們拖到街市<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="街市——或譯作「市場」或「大會場」或「公民大會」。">i</a></sup>上去見首領們。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 4:4; 約翰福音 15:18–20; 使徒行傳 28:22"> 把兩個人帶到官長們面前，說：「這些人是猶太人，在擾亂我們的城市，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 3:8; 使徒行傳 26:3; 耶利米書 10:3"> 傳講我們羅馬人不可以接受、也不能遵守的規矩。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:2; 哥林多後書 6:5; 哥林多後書 11:23–25"> 那群人就一同起來反對保羅和西拉斯。官長們就剝了他們的衣服，下令用棍子打，</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 2:10; 提摩太後書 2:9; 撒母耳記上 23:22–23"> 打了很多棍以後，把他們投進監獄，吩咐獄卒好好地看守。</span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 13:27; 約伯記 33:11; 耶利米書 29:26"> 獄卒領了這樣的吩咐，就把他們投進了監獄裡的最裡層，把他們的兩腳銬在木枷上。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦前書 5:16–18; 詩篇 119:62; 雅各書 1:2"> 約在半夜，保羅和西拉斯禱告、唱詩讚美神，其他的囚犯們都側耳聽著。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 4:31; 使徒行傳 5:19; 使徒行傳 12:10"> 突然發生了強烈的地震，結果監獄的地基都被搖動，所有的監門立刻打開了，每個囚犯的鎖鏈也都鬆開了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 12:19; 馬太福音 27:5; 士師記 9:54"> 獄卒醒來，看見監獄的門都開了，以為囚犯們已經逃跑了，就拔出刀來要自殺。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦前書 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保羅卻大聲呼喚說：「不要傷害自己，因為我們都在這裡！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="啟示錄 3:9; 使徒行傳 24:25; 以賽亞書 60:14"> 獄卒叫人拿了燈來，就衝進去，戰戰兢兢地俯伏在保羅和西拉斯面前，</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 2:37; 約翰福音 6:27–29; 以賽亞書 58:9"> 然後領他們出來，說：「先生們，我應該做什麼才能得救呢？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:12; 使徒行傳 2:38–39; 約翰福音 3:36"> 他們說：「要信靠主耶穌<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶穌——有古抄本作「耶穌基督」。">j</a></sup>，你和你一家人就將得救。」</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 1:16; 歌羅西書 1:27–28; 提摩太前書 1:13–16"> 於是他們把主的福音<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="福音——原文直譯「話語」或「道」。">k</a></sup>講給獄卒和他家裡所有的人聽。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 1:16; 使徒行傳 16:15; 使徒行傳 16:25"> 當夜，就在那時刻，獄卒帶他們去清洗傷口，然後他和所有的家人立刻受了洗。</span>
<span className="v" id="v34" data-v="34" data-xref="羅馬書 15:13; 使徒行傳 2:46; 羅馬書 5:11"> 他把保羅和西拉斯領到家裡，擺上飯食。他和全家人因為信了神，都歡欣跳躍。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="耶利米書 5:22; 詩篇 76:10; 使徒行傳 5:40"> 天亮的時候，官長們派刑杖官來說：「把那兩個人放了吧！」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 15:33; 約翰福音 14:27; 撒母耳記上 1:17"> 獄卒就把這話告訴保羅，說：「官長們派人來，要釋放你們。所以現在請你們出來，平平安安地去吧！」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 22:25–29; 詩篇 58:1–2; 馬太福音 10:16"> 可是保羅對他們說：「我們是羅馬公民，並沒有被定罪，他們卻當眾打我們，把我們投進監獄。現在他們還要悄悄地把我們趕出去嗎？當然不行！讓他們親自來領我們出去！」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 22:29; 馬太福音 21:46; 馬太福音 14:5"> 那些刑杖官把這些話報告給官長們，官長們一聽他們是羅馬公民，就懼怕了，</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 8:34; 馬可福音 5:17; 但以理書 6:23"> 於是來安撫他們，並且把他們領出來，請求他們離開那城。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒羅尼迦前書 3:2–3; 使徒行傳 16:14; 使徒行傳 14:22"> 保羅和西拉斯出了監獄，就到莉迪婭家裡去，見了弟兄們，鼓勵他們一番，然後離開了。</span>
</div>
</div>

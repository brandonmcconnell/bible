<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="26" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:15; 箴言 1:24; 使徒行傳 26:2"> 阿格里帕對保羅說：「你獲准為自己說話。」<br />於是保羅伸手開始申辯：</span>
<span className="v" id="v2" data-v="2"> 「阿格里帕王啊，關於猶太人控告我的一切事，今天要在您面前申辯，我認為自己是蒙福的，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 6:14; 使徒行傳 26:26; 使徒行傳 26:7"> 尤其因為您熟悉猶太人一切的規矩和爭議的問題，所以我請求您耐心聽我說。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:13; 提摩太後書 3:10; 腓立比書 3:5"> 「事實上，我自幼的為人，從起初在自己的同胞中間，以及在耶路撒冷，所有的猶太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 23:6; 使徒行傳 22:3; 使徒行傳 24:5"> 他們從一開始就已經認識我，如果他們願意就可以見證：我是按著我們宗教中最嚴格的教派，過著法利賽人的生活。</span>
<span className="v" id="v6" data-v="6" data-xref="提多書 2:13; 使徒行傳 24:15; 使徒行傳 28:20"> 現在我站在這裡受審，是因為盼望神已經賜給我們祖先的那應許。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:1; 腓立比書 3:11; 提摩太前書 5:5"> 為了那應許，我們十二個支派日夜熱切地事奉神，盼望得到它。王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王——有古抄本作「阿格里帕王」。">a</a></sup>啊，我被猶太人控告，就是為了這盼望。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 15:12–20; 使徒行傳 4:2; 使徒行傳 17:31–32"> 你們為什麼判斷神使死人復活的事為不可信的呢？</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 1:13; 使徒行傳 22:8; 腓立比書 3:6"> 事實上，我自己曾經認為必須多做反對拿撒勒人耶穌之名的事，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 8:3; 使徒行傳 9:13–14; 使徒行傳 9:21"> 我在耶路撒冷也是這樣做的。我不但從祭司長們得了權柄把許多聖徒關進監獄，而且當他們被殺的時候，我也投了一票。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 22:19; 馬太福音 10:17; 使徒行傳 13:45"> 我在各會堂裡，經常用刑逼他們說褻瀆的話，又越發惱恨他們，甚至到國外的城市去逼迫他們。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 26:10; 使徒行傳 22:5–11; 使徒行傳 9:1–8"> 「那時我得到祭司長們的授權和委任往大馬士革去。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 17:2; 啟示錄 21:23; 啟示錄 1:16"> 王啊，約在正午，我在路上的時候，看見一道光，比太陽更明亮，從天上四面照射我和與我同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 21:40; 使徒行傳 22:2; 使徒行傳 9:7"> 我們都仆倒在地。我聽見有聲音用希伯來語對我說<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有聲音用希伯來語對我說——有古抄本作「有聲音對我說話，用希伯來語說」。">b</a></sup>：<span className="woj">『掃羅，掃羅！你為什麼逼迫我？你腳踢刺棒，是狂妄的。』</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 15:20–21; 馬太福音 25:45; 出埃及記 16:8"> 「我問：『主啊，你到底是誰？』<br />「主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主——有古抄本作「那一位」。">c</a></sup>說：<span className="woj">『我就是你所逼迫的耶穌。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 22:14–15; 以西結書 2:1; 但以理書 10:11"> <span className="woj">你起來，用你的兩腳站好！要知道，我向你顯現是為這樣一個目的</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一個目的——輔助詞語。">d</a></sup><span className="woj">：預先指定你做僕人和見證人，就是為你所看見的事，以及我將要顯明給你的事做見證人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 耶利米書 1:19"> <span className="woj">我要從以色列</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以色列——輔助詞語。">e</a></sup><span className="woj">子民和外邦人當中把你救出來。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「現在」。">f</a></sup><span className="woj">我差派你到他們那裡去，</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前書 2:9; 以弗所書 1:18; 以弗所書 5:8"> <span className="woj">為了開啟他們的眼睛，使他們從黑暗歸向光明，從撒旦的權勢下歸向神，使他們因著信我，罪得赦免，並且與那些被分別為聖的人同得繼業。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 50:5; 加拉太書 1:16; 以西結書 2:7–8"> 「故此，阿格里帕王啊，我沒有悖逆那從天上來的異象。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 3:8; 使徒行傳 3:19; 使徒行傳 2:38"> 我首先在大馬士革，然後在耶路撒冷、猶太全地以及外邦人中，告誡人們要悔改，歸向神，行事與悔改的心相稱。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 21:30–31; 使徒行傳 21:27; 使徒行傳 25:3"> 猶太人就是因這緣故，在聖殿裡抓住我，想要殺害我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 24:14; 約翰福音 5:46; 羅馬書 3:21"> 然而我蒙了從神而來的幫助，直到今天仍能站立得住，不但向卑微的，還向尊貴的做見證。我所講的，不外乎先知們和摩西所說的那些將要成就的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 53:1–12; 路加福音 24:26; 歌羅西書 1:18"> 就是基督要受難，要成為第一個從死人中復活的人，要把光傳給這子民和外邦人。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 2:13–14; 哥林多前書 1:23; 哥林多前書 4:10"> 保羅這樣申辯的時候，菲斯特斯大聲說：「保羅，你瘋了！你學問太大，使你癲狂了。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 23:26; 提多書 1:9; 提多書 2:7–8"> 保羅<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="保羅——有古抄本作「這位」。">g</a></sup>說：「菲斯特斯大人，我沒有瘋。我說的都是真實、合理的話。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:2–3; 使徒行傳 2:1–12; 以賽亞書 30:20"> 其實王知道這些事，我才對王放膽直言。我深信這些事沒有一件瞞得過王，因為這不是在角落裡做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 26:22–23"> 阿格里帕王啊，您相信先知嗎？我知道您是相信的。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 11:26; 馬太福音 10:18; 使徒行傳 26:29"> 阿格里帕對保羅說：「你用幾句話就要說服我成為<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="成為——有古抄本作「做」。">h</a></sup>基督徒嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以弗所書 6:20; 歌羅西書 1:28; 羅馬書 10:1"> 保羅說：「無論話多話少，我向神祈求的，不僅是您，還有今天所有聽我講話的人都能成為像我這樣的人，只是不要有這些鎖鏈！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 18:15; 使徒行傳 28:22; 使徒行傳 25:23"> 於是<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「他說完這些事，」。">i</a></sup>王和總督，還有百妮基以及與他們坐在一起的人，都站起來了。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 23:29; 使徒行傳 23:9; 使徒行傳 28:18"> 當離開的時候，彼此談論說：「這個人沒有做任何該死或該被捆鎖的事。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 28:18; 使徒行傳 25:11–12; 使徒行傳 25:25"> 阿格里帕對菲斯特斯說：「這個人如果沒有向凱撒上訴，早就可以釋放了。」</span>
</div>
</div>

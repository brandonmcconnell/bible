<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="28" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 27:26; 使徒行傳 27:44; 使徒行傳 27:39"> 我們獲救以後才知道那島叫做馬耳他，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:14; 希伯來書 13:2; 歌羅西書 3:11"> 那裡的土人對我們非常友善。因為當時下著雨，又因為天氣冷，他們就生了火接待我們大家。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 23:33; 馬太福音 12:34; 使徒行傳 28:4"> 保羅收集了一捆柴火，放在火堆上的時候，有一條毒蛇因熱鑽了出來，咬住<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="咬住——或譯作「纏住」。">a</a></sup>他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 約翰福音 7:24"> 那些土人一看見那毒蛇懸在他的手上，就彼此說：「這個人一定是個殺人犯！雖然從海裡獲救了，但天理還是不讓他活著。」</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 馬可福音 16:18; 詩篇 91:13"> 可是保羅把那毒蛇甩在火裡，沒有受任何傷害。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 12:22; 使徒行傳 14:11–13; 馬太福音 21:9"> 他們本來以為他快要腫起來，或是突然倒下死去，然而等了很久，看見他沒有任何異常，就改變了想法，說他是個神。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:40–41; 路加福音 19:6–9; 使徒行傳 28:2"> 在那個地方附近，有些田產是島上首領普布利烏的。他歡迎我們，熱情地招待了我們三天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:40; 馬可福音 6:5; 雅各書 5:14–16"> 當時，普布利烏的父親患熱病和痢疾，躺在床上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在床上——輔助詞語。">b</a></sup>。保羅就進去為他禱告，按手在他身上，使他痊癒了。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 5:12; 馬可福音 6:54–56; 使徒行傳 5:15"> 這麼一來，島上其他有病的人也都來了，並且都得了痊癒。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒羅尼迦前書 2:6; 腓立比書 4:11–12; 馬太福音 6:31–34"> 他們十分尊重我們；開船的時候，還送上所需要的東西。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 27:6; 哥林多前書 8:4; 以賽亞書 45:20"> 過了三個月，我們上了一條亞歷山大的船起航。這船是在那海島過冬的，以「宙斯雙子神」為船頭雕像。</span>
<span className="v" id="v12" data-v="12"> 我們在敘拉古靠岸，停留了三天，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 27:13"> 又從那裡繞道航行，到達利基翁。過了一天，颳起了南風，第二天我們就到了普特奧利，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 21:4; 使徒行傳 20:6; 使徒行傳 19:1"> 在那裡找到一些弟兄，受邀請與他們同住了七天。<br />這樣，我們來到了羅馬。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:3; 羅馬書 15:24; 出埃及記 4:14"> 那裡的弟兄們聽說了有關我們的事，趕到阿比烏市場和三館來迎接我們。保羅見到他們，就感謝神，得了勇氣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 27:3; 使徒行傳 24:23; 使徒行傳 28:30–31"> 我們進了羅馬以後，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「百夫長把囚犯交給軍隊司令官。但」。">c</a></sup>保羅獲准在一個士兵的看守之下，獨自居住。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 25:8; 使徒行傳 6:14; 使徒行傳 25:10"> 第三天，保羅<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="保羅——有古抄本作「他」。">d</a></sup>請猶太人的首領們來。他們聚集了，保羅就對他們說：「各位兄弟，我沒有做過任何反對我們民族或先祖規矩的事，卻做為囚犯從耶路撒冷被交到羅馬人手中。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:31–32; 使徒行傳 23:29; 使徒行傳 22:24–25"> 他們審問我以後，因為沒有處死我的任何理由，本來想要釋放我。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 26:32; 使徒行傳 25:21; 使徒行傳 25:10–12"> 但是由於猶太人反對，我被迫向凱撒上訴，並不是有什麼事要控告自己的同胞。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:20; 提摩太後書 2:9; 使徒行傳 26:6–7"> 因這理由，我請你們來見面談話。其實我是為了以色列所盼望的事，才被這鎖鏈捆鎖的。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 54:17; 以賽亞書 41:11; 以賽亞書 50:8"> 他們對保羅說：「我們沒有收到從猶太來的有關你的文件。來到這裡的同胞<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="同胞——原文直譯「兄弟」。">e</a></sup>中，也沒有人報告過或說過任何有關你的壞事。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:12; 使徒行傳 24:14; 彼得前書 3:16"> 不過我們覺得應該聽聽你的想法，因為我們確實知道有關這教派的事，它到處遭人反對。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 17:2–3; 使徒行傳 19:8; 使徒行傳 18:28"> 於是他們和保羅定好了日子，就有更多的人來到他的住所。保羅從早到晚對他們講解，為神的國鄭重地做見證，並且引用摩西的律法和先知書上有關耶穌的事來勸導他們。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 14:4; 使徒行傳 17:4–5; 使徒行傳 19:8–9"> 對他所說的話，有些人信從了，有些人卻不相信。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 15:7; 彼得後書 1:21; 馬可福音 7:6"> 他們彼此不一致，開始散去，保羅就說了一句話：「聖靈藉著先知以賽亞對你們<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你們——有古抄本作「我們」。">f</a></sup>祖先所說的是對的。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 6:9–10; 以西結書 12:2; 以賽亞書 42:19–20"> 他說：<br /><span className="pl pl-1">『你去告訴這子民：</span><br /><span className="pl pl-1">你們將聽了又聽，但絕不會領悟；</span><br /><span className="pl pl-1">你們將看了又看，但絕不會明白；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 6:10"> <span className="pl pl-1">因為這子民的心麻木了，</span><br /><span className="pl pl-1">他們充耳不聞，眼睛閉著；</span><br /><span className="pl pl-1">免得他們眼睛看見，耳朵聽見，心裡領悟，</span><br /><span className="pl pl-1">回轉過來，我就使他們痊癒。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行傳 26:17–18; 羅馬書 3:29–30"> 所以你們應當知道：神的這救恩已經傳給了外邦人，他們反倒會聽！」</span>
<span className="v" id="v29" data-v="29"> 保羅說完這些話，猶太人就走了，彼此議論紛紛。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有此節。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 保羅在自己租的房子裡住了整整兩年，所有來到他那裡的人，他都歡迎。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 4:29; 以弗所書 6:19–20; 馬太福音 4:23"> 他宣講神的國、教導有關主耶穌基督的事，滿有膽量、沒有攔阻。</span>
</div>
</div>

</div>

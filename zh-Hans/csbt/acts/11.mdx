<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="11" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 22:27; 瑪拉基書 1:11; 以賽亞書 32:15"> 後來，使徒們和在猶太各地的弟兄們聽說外邦人也接受了神的話語<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的話語——或譯作「神的道」。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:45; 使徒行傳 10:9; 使徒行傳 15:1"> 可是當彼得上到耶路撒冷的時候，那些割禮派的人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="割禮派的人——或譯作「受割禮的人」。">b</a></sup>卻批評他，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 10:28; 加拉太書 2:12; 路加福音 15:2"> 說：「你竟然進到沒有受割禮之人的家裡，又與他們一起吃飯。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行傳 14:27; 約書亞記 22:21–31"> 彼得就開始按著次序向他們講解，說：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 10:9–32; 使徒行傳 9:10; 使徒行傳 22:17"> 「我在約帕城裡禱告的時候，魂遊象外，看見一個異象：有一樣東西<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="東西——原文直譯「容器」。">c</a></sup>從天上降下，好像一塊大布，四角捆住<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="捆住——輔助詞語。">d</a></sup>，縋到我面前來。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行傳 3:4"> 我注目觀看它，看見裡面有<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="裡面有——輔助詞語。">e</a></sup>地上的四足動物、野獸、爬行動物和天空的飛鳥；</span>
<span className="v" id="v7" data-v="7"> 那時我也聽見有聲音對我說：<span className="woj">『彼得，起來，宰了吃！』</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 14:14; 何西阿書 9:3; 哥林多前書 7:14"> 我說：『主啊，千萬不可！因為俗物或不潔淨的東西，從來沒有入過我的口。』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 15:9; 希伯來書 9:13–14; 使徒行傳 10:34–35"> 那聲音第二次從天上傳來，說：<span className="woj">『神所潔淨的，你不可當做汙穢的。』</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 21:17; 民數記 24:10; 哥林多後書 12:8"> 這樣一連有三次，然後所有的東西又被收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 4:27; 使徒行傳 9:10–12; 出埃及記 4:14"> 正在這時，忽然有三個人站在我們所住的房子面前，他們是從凱撒里亞被派到我這裡的。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 8:29; 羅馬書 3:22; 帖撒羅尼迦後書 2:2"> 聖靈吩咐我：要陪他們一起去，不要有任何疑惑。當時與我一起去的，還有這六位弟兄。後來我們就進了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 10:30–32; 使徒行傳 10:3–6; 使徒行傳 9:43"> 他告訴我們，他怎樣看見一位天使站在他家裡說：『你要派人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「人」。">f</a></sup>到約帕去，請那稱為彼得的西門來；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 16:15; 使徒行傳 10:22; 使徒行傳 16:31–34"> 他有話要對你說，藉這話你和你全家將要得救。』</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 19:6; 使徒行傳 10:34–46; 使徒行傳 2:2–12"> 我一開始講話，聖靈就降臨在他們身上，就像當初降臨在我們身上一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 1:5; 馬可福音 1:8; 箴言 1:23"> 我就想起了主如此說的話，<span className="woj">『約翰用水</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="用水——或譯作「在水裡」。">g</a></sup><span className="woj">施洗</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗——或譯作「施浸」。">h</a></sup><span className="woj">，但你們將要受聖靈的洗。』</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 10:47; 羅馬書 9:20–26; 但以理書 4:35"> 因此，神如果給了他們這相同的恩賜，就像在我們信靠主耶穌基督的時候也給了我們一樣，那麼，我是誰呢？難道能攔阻神嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="羅馬書 10:12–13; 哥林多後書 7:10; 以西結書 36:26"> 他們聽了這些話就安靜下來，然後就榮耀神，說：「這樣，神把悔改的心也賜給外邦人，使他們得生命。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 4:36; 使徒行傳 21:2; 使徒行傳 15:3"> 於是那些因司提反的事受患難而四散的信徒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="信徒——輔助詞語。">i</a></sup>，就一直走到腓尼基地區、塞浦路斯島和安提阿。他們只向猶太人，而不向任何人傳講福音<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="福音——原文直譯「話語」或「道」。">j</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 27:32; 使徒行傳 13:1; 哥林多前書 1:23–24"> 但其中有一些塞浦路斯人和古利奈人，來到安提阿，也向希臘人講道，傳主耶穌的福音。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行傳 2:47; 使徒行傳 5:14"> 主的手與他們同在，有許許多多的人就相信、歸向了主。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:27; 使徒行傳 8:14; 使徒行傳 13:1–3"> 這消息傳到在耶路撒冷的教會<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="教會——原文直譯「教會耳中」。">k</a></sup>，他們就派巴拿巴到安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 15:58; 使徒行傳 14:22; 使徒行傳 13:43"> 巴拿巴到了，看見神的恩典就感到歡喜，鼓勵大家要立定心志，繼續靠<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="繼續靠——或譯作「恆久靠」。">l</a></sup>主，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 11:21; 使徒行傳 5:14; 使徒行傳 9:31"> ——這是因為巴拿巴是個好人，充滿聖靈和信仰。於是有一大群人歸向<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="歸向——原文直譯「加添」。">m</a></sup>了主。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 9:11; 使徒行傳 9:27; 使徒行傳 9:30"> 後來巴拿巴到塔爾蘇去找掃羅，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 4:16; 使徒行傳 26:28; 彼得前書 4:14"> 找到了，就帶他到安提阿來。然後有整整一年，兩個人與會眾聚在一起，教導了一大群人。門徒們第一次被稱為「基督徒」是在安提阿。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 13:1; 哥林多前書 12:28; 以弗所書 4:11"> 在那些日子裡，有幾個做先知傳道的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="做先知傳道的——原文直譯「先知」。">n</a></sup>從耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 21:10; 使徒行傳 18:2; 路加福音 3:1"> 其中有一個名叫阿伽布斯的站起來，藉著聖靈指明普天下將有大饑荒。這事在凱撒<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本沒有「凱撒」。">o</a></sup>克勞迪時期果然發生了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 8:12–14; 加拉太書 2:10; 哥林多後書 8:2–4"> 於是門徒們決定，每個人照著自己的能力來捐獻<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="捐獻——或譯作「供應」。">p</a></sup>，好送到住在猶太的弟兄們那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 14:23; 使徒行傳 12:25; 使徒行傳 15:4"> 他們就這麼做了，由巴拿巴和掃羅經手，把所捐獻的送到長老們那裡。</span>
</div>
</div>

</div>

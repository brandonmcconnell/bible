<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="8" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 22:20; 但以理書 3:16–18; 使徒行傳 5:40"> 掃羅也贊同殺害司提反。<br />從那一天開始，有大逼迫臨到耶路撒冷的教會。除了使徒以外，他們都分散到猶太和撒瑪利亞地區。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:10–11; 創世記 23:2; 耶利米書 22:18"> 有些虔誠的人把司提反埋葬了，為他大大地悲傷。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 1:13; 加拉太書 1:13; 哥林多前書 15:9"> 掃羅卻摧殘教會，闖進各家各戶，無論男女都拉去關進監獄。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:23; 使徒行傳 11:19; 使徒行傳 8:1"> 於是那些分散的人就走遍各地傳講福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直譯「話語」或「道」。">a</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 6:5; 使徒行傳 21:8; 使徒行傳 8:35–36"> 腓利下到撒瑪利亞的一個城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="撒馬利亞的一個城——有古抄本作「撒馬利亞城」。">b</a></sup>，向那裡的人傳講基督。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 4:41–42; 歷代志下 30:12; 馬太福音 20:15–16"> 當眾人聽見又看見腓利所行的神蹟，就同心合意，專心聽他所說的話。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:1; 使徒行傳 14:8–10; 馬可福音 16:17–18"> 那時，有許多人被汙靈附身，那些汙靈大聲喊叫著從他們身上出來了；許多癱瘓的和瘸腿的，也得了痊癒。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:52; 使徒行傳 13:48; 使徒行傳 8:39"> 所以那城裡，有極大的喜樂。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 13:6; 使徒行傳 5:36; 約翰福音 7:18"> 有一個名叫西門的人，自稱是個大人物，一向在那城裡行邪術，使撒瑪利亞的居民十分驚訝。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:34; 彼得後書 2:2; 啟示錄 13:3"> 所有的人，從卑微的到尊貴的，都聽從他。他們說：「這個人就是那被稱為『神的大能者』的。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 8:9; 加拉太書 3:1; 以賽亞書 44:25"> 他們聽從<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="聽從——原文直譯「注重」。">c</a></sup>他，因為他長期以來用邪術使他們十分驚訝。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 2:38; 使徒行傳 1:3; 馬太福音 28:19"> 可是腓利傳講有關神國的福音和耶穌基督之名的時候，他們就相信了，無論男女都受了洗，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:6–7; 約翰福音 5:20; 使徒行傳 19:11"> 連西門自己也信了。他受洗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="受洗——或譯作「受浸」。">d</a></sup>以後，常常跟著腓利，看見所行出來的神蹟和大能，就十分驚訝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:13; 帖撒羅尼迦前書 3:2; 加拉太書 2:9"> 在耶路撒冷的使徒們聽說撒瑪利亞人接受了神的話語<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神的話語——或譯作「神的道」。">e</a></sup>，就派彼得和約翰到他們那裡去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:38; 約翰福音 16:23–24; 約翰福音 14:13–14"> 兩個人下去，就為他們禱告，好使他們領受聖靈，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:38; 使徒行傳 19:2; 馬太福音 28:19"> 因為聖靈還沒有降臨到他們任何人身上。他們只是受洗歸入了主耶穌的名<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="受洗歸入了主耶穌的名——或譯作「奉主耶穌的名受了洗」。">f</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 19:6; 使徒行傳 6:6; 提摩太後書 1:6"> 於是彼得和約翰按手在他們身上，他們就領受了聖靈。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 6:5; 馬太福音 10:8; 列王紀下 8:9"> 西門看見因著使徒們的按手，有聖靈<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="聖靈——有古抄本作「靈」。">g</a></sup>賜下，就拿了錢給他們，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 約翰三書 1:9; 約翰福音 5:44"> 說：「請把這權柄也給我，使我按手在誰身上，誰就可以領受聖靈。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理書 5:17; 馬太福音 10:8; 使徒行傳 2:38"> 彼得對他說：「你的銀子和你一起滅亡<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="滅亡——或譯作「沉淪」。">h</a></sup>吧！因為你以為神的恩賜可以用錢買到！</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 4:13; 詩篇 36:1; 馬太福音 6:22–24"> 你在這件事上無份無關，因為在神面前你的心不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太後書 2:25–26; 但以理書 4:27; 希伯來書 4:12"> 所以你應當為這惡事悔改，向主<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主——有古抄本作「神」。">i</a></sup>祈求，或許你心中的意念因此被赦免。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 58:6; 箴言 5:22; 約翰福音 8:34"> 因我看出你在苦毒的膽汁中，被不義所捆綁。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 8:8; 民數記 21:7; 約伯記 42:8"> 西門回答說：「請你們為我向主祈求，使你們所說的，沒有一樣臨到我。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 20:21; 使徒行傳 26:22–23; 使徒行傳 1:8"> 於是彼得和約翰在那裡鄭重地做見證，傳講了主的福音<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="福音——原文直譯「話語」或「道」。">j</a></sup>，又在撒瑪利亞人的許多村莊傳福音，就回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:19; 希伯來書 1:14; 列王紀下 1:3"> 有主的一位天使對腓利說：「你起來，順著那條從耶路撒冷下到加沙的路，往南走。」那裡是曠野。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅書 3:10; 詩篇 68:31; 以賽亞書 56:3–8"> 腓利就起身去了。看哪，有一個埃塞俄比亞人，是個太監，是埃塞俄比亞坎蒂絲女王的大臣，統管她整個國庫。他到耶路撒冷去敬拜後，</span>
<span className="v" id="v28" data-v="28" data-xref="歌羅西書 3:16; 以賽亞書 1:1; 使徒行傳 28:25"> 在回去的時候，坐在他的馬車裡誦讀先知以賽亞的書。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 10:19; 使徒行傳 11:12; 使徒行傳 20:22–23"> 聖靈對腓利說：「你上前去，貼近那馬車走。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 約翰福音 5:39; 以弗所書 5:17"> 腓利跑過去，聽見他正在誦讀先知以賽亞的書，就問：「難道你真的明白你所讀的嗎？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="羅馬書 10:14; 詩篇 73:16–17; 以賽亞書 29:18–19"> 太監回答說：「如果沒有人指教我，我怎麼能明白呢？」他就請腓利上來和他同坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 53:7–8; 彼得前書 2:21–24; 耶利米書 51:40"> 太監誦讀的那段經文是這樣的：<br /><span className="pl pl-1">「他像羊被牽去宰殺，</span><br /><span className="pl pl-1">又像羊羔在剪毛的人面前默默無聲，</span><br /><span className="pl pl-1">他也這樣不開口。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 53:12; 以賽亞書 53:8; 撒迦利亞書 13:7"> <span className="pl pl-1">他在屈辱中，公義被奪走了，</span><br /><span className="pl pl-1">誰能述說他的世代呢</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="誰能述說他的世代呢——或譯作「誰來述說他的家世呢」。">k</a></sup><br /><span className="pl pl-1">？</span><br /><span className="pl pl-1">因為他的生命從地上被奪走了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 15:15; 馬太福音 13:36; 馬太福音 2:2–4"> 太監對腓利說：「請問，先知說的這話是關於誰呢？是關於自己，還是關於別人呢？」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行傳 18:28; 使徒行傳 28:23"> 腓利就開口，從這一段經文開始，向他傳講耶穌的福音。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 10:47; 約翰福音 3:5; 提多書 3:5–6"> 當他們沿路前行的時候，來到一個有水的地方。太監說：「看哪，有水！有什麼能阻止我受洗呢？」</span>
<span className="v" id="v37" data-v="37"> 腓利說：「如果你全心相信就可以受洗。」太監回答說：「我相信耶穌基督是神的兒子。」<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有此節。">l</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 4:1; 約翰福音 3:22–23"> 於是他吩咐停下馬車，腓利和太監，兩個人下到水裡，腓利就給他施洗<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="施洗——或譯作「施浸」。">m</a></sup>。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:12; 列王紀下 2:16; 以西結書 8:3"> 他們從水裡上來的時候，主的靈把腓利提走，太監再也看不見他了。太監繼續趕路，滿心快樂。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 21:8; 使徒行傳 23:23; 使徒行傳 23:33"> 後來，腓利出現在阿佐托。他走遍各個城鎮傳揚福音，直到他來到凱撒里亞。</span>
</div>
</div>

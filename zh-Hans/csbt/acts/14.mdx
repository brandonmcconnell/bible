<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="14" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:4; 使徒行傳 13:51; 使徒行傳 13:46"> 有一次在以哥念，保羅和巴拿巴同樣進了猶太人的會堂講道，結果有一大群猶太人和希臘人信了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 13:50; 使徒行傳 21:27–30; 使徒行傳 14:19"> 但那些不肯信從的猶太人慫恿外邦人，使他們心裡敵視弟兄們。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 2:4; 以弗所書 6:18–20; 使徒行傳 20:32"> 於是保羅和巴拿巴就住了很久，靠著主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="靠著主——或譯作「為主」。">a</a></sup>放膽傳道。主藉著他們的手行了神蹟和奇事，見證了他恩典的話語。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 28:24; 使徒行傳 14:14; 路加福音 11:21–23"> 以哥念城的民眾就分裂了，有的贊同猶太人，有的贊同使徒們。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 14:19; 提摩太後書 3:11; 使徒行傳 17:5"> 那時，外邦人和猶太人，與他們的首領們一同企圖凌辱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="凌辱——或譯作「攻擊」。">b</a></sup>使徒們，要用石頭砸死他們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 14:20–21; 馬太福音 10:23; 提摩太後書 3:11"> 兩個人知道了，就逃往利考尼亞地區的路司得和代爾貝兩個城以及周圍地區，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 14:21; 使徒行傳 16:10; 帖撒羅尼迦前書 2:2"> 在那裡繼續傳福音。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 3:2; 約翰福音 9:1–2; 約翰福音 5:3–5"> 在路司得城裡坐著一個雙腳殘廢的人，他生來<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="生來——原文直譯「從母腹中」。">c</a></sup>就瘸腿，從來沒有走過路；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 3:4; 馬太福音 15:28; 馬太福音 9:28–29"> 這個人聽保羅講道。保羅注視著他，見他存著信可得救治，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 35:6; 約翰福音 5:8–9; 約翰福音 14:12"> 就大聲說：「你起來，用你的兩腳站直！」那個人就跳起來，開始走路了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:6; 使徒行傳 8:10; 使徒行傳 12:22"> 眾人看見保羅所做的，就用利考尼亞話高聲說：「神明像人那樣降臨在我們中間了！」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:35"> 他們稱巴拿巴為宙斯神，稱保羅為赫爾墨斯神，因為保羅是領頭說話的人。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 2:46; 使徒行傳 10:25"> 於是城外宙斯神廟的祭司，牽著幾頭公牛，帶著一些花環，到了城門口，要與眾人一起來獻祭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:65; 哥林多前書 9:5–6; 列王紀下 5:7"> 巴拿巴和保羅兩位使徒聽見這事，就撕裂自己的衣服，衝進人群裡面，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 10:26; 哥林多前書 8:4; 雅各書 5:17"> 喊著說：「各位，你們為什麼做這些事呢？我們和你們同樣是人！我們向你們傳福音，是要你們離棄這些虛妄的事，歸向永生的神，就是造了天、地、海和其中萬有的神。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:30; 詩篇 81:12; 羅馬書 1:28"> 在過去的各世代，神容忍萬民各行其道。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:19–20; 約珥書 2:23; 約伯記 5:10"> 其實神並不是沒有為自己留下證據，因為他常行美善：從天上賜給你們<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你們——有古抄本作「我們」。">d</a></sup>雨水和豐收的季節，使你們<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你們——有古抄本作「我們」。">e</a></sup>食物充足，滿心喜樂。」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 44:16–17; 創世記 19:9; 創世記 11:6"> 兩個人說了這些話，好不容易才阻止眾人向他們獻祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 11:25; 提摩太後書 3:11; 使徒行傳 13:50–51"> 但有些猶太人從安提阿和以哥念來到，挑唆眾人，用石頭砸了保羅。他們以為他已經死了，就把他拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 1:9–10; 哥林多後書 6:9; 使徒行傳 14:6"> 但門徒們圍繞他的時候，他站了起來，進到城裡。第二天，他與巴拿巴一起離開，前往代爾貝去。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 14:19; 使徒行傳 14:1; 使徒行傳 13:51"> 保羅和巴拿巴在代爾貝城傳了福音，使許多人成為門徒以後，回到路司得、以哥念、安提阿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 5:10; 提摩太後書 3:12; 約翰福音 16:33"> 堅固門徒們的心，鼓勵他們持守信仰，說：「我們進入神的國，必須經過很多患難。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提多書 1:5; 使徒行傳 11:30; 雅各書 5:14"> 保羅和巴拿巴在各教會為他們選出了長老，禱告和禁食以後，把他們交託給他們所信靠的主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 13:13–14; 使徒行傳 15:38"> 兩個人經過皮西迪亞地區，來到潘菲利亞省，</span>
<span className="v" id="v25" data-v="25"> 在佩爾格傳了道，就下到阿塔利亞，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:40; 使徒行傳 11:19; 哥林多後書 1:12"> 從那裡坐船回安提阿。當初，就是在這裡，他們被交託在神的恩典中，去從事如今那已完成的工作。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 16:9; 使徒行傳 15:12; 歌羅西書 4:3"> 他們到了，就召集教會，傳講了神與他們所做的一切事，以及神怎樣為外邦人打開了信仰之門。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 11:26; 使徒行傳 15:35"> 兩個人在那裡與門徒們一起住了不少時候。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:23–28; 哥林多前書 16:12; 哥林多前書 1:12"> 阿波羅在哥林多的時候，保羅經過內陸地區，來到以弗所城，在那裡他遇見一些門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 7:39; 使徒行傳 11:15–17; 加拉太書 3:5"> 問他們：「你們信的時候，是否領受了聖靈？」<br />他們告訴他：「其實我們也沒有聽說過是否有聖靈。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:25; 哥林多前書 12:13; 使徒行傳 8:16"> 保羅又問：「那麼，你們受的是什麼洗呢？」<br />他們說：「是約翰的洗禮。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 1:29–34; 使徒行傳 11:16; 使徒行傳 1:5"> 保羅說：「約翰所施的是悔改的洗禮，他告訴民眾當相信在他以後來的那一位，就是相信耶穌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶穌——有古抄本作「耶穌基督」。">a</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 8:12; 使徒行傳 8:16; 羅馬書 6:3–4"> 他們聽了，就受洗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="受洗——或譯作「受浸」。">b</a></sup>歸入了主耶穌的名<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受洗歸入了主耶穌的名——或譯作「奉主耶穌的名受了洗」。">c</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 6:6; 使徒行傳 2:4; 馬可福音 16:17"> 接著，保羅按手在他們身上，聖靈就臨到了他們。他們就說起殊言<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="殊言——原文直譯「舌頭」；傳統譯法作「方言」。">d</a></sup>，又說預言。</span>
<span className="v" id="v7" data-v="7"> 他們一共約有十二個人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 28:23; 使徒行傳 1:3; 使徒行傳 9:20–22"> 保羅進了會堂，放膽傳道，一連三個月講論並勸導人相信那些有關神國的事。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 19:23; 使徒行傳 9:2; 使徒行傳 18:6–8"> 後來，當有些人心裡剛硬、不肯信從，在會眾面前誹謗這道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="道——或譯作「路」。">e</a></sup>的時候，保羅就離開他們，把門徒們分別出來，天天在特拉諾斯講堂裡講論。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 20:31; 提摩太後書 1:15; 使徒行傳 16:6"> 這樣持續了兩年，結果所有住在亞細亞省的人，無論是猶太人或希臘人，都聽到了主<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="主——有古抄本作「主耶穌」。">f</a></sup>的福音<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="福音——原文直譯「話語」或「道」。">g</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬可福音 16:17–20; 使徒行傳 5:12; 羅馬書 15:18–19"> 神藉著保羅的手，行了一些不尋常的神蹟，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:15; 列王紀下 13:20–21; 馬可福音 16:17"> 甚至有人把保羅身上的手巾和圍裙拿去，放在病人身上，疾病就從他們身上消退了，邪靈也<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「從他們身上」。">h</a></sup>出去了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 12:27; 馬可福音 9:38; 路加福音 11:19"> 可是有一些四處遊歷的猶太驅魔師，向那些有邪靈附身的人，擅自稱呼主耶穌的名，說：「我藉著保羅所傳的耶穌，吩咐你們出來<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="出來——輔助詞語。">i</a></sup>。」</span>
<span className="v" id="v14" data-v="14"> 有一個名叫斯克瓦的猶太祭司長，他的七個兒子都在做這種事。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 16:17–18; 路加福音 4:33–35; 馬可福音 1:34"> 邪靈回答他們，說：「耶穌我認識，保羅我也知道！但你們呢？你們是誰？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 馬可福音 5:3–4; 馬可福音 5:15"> 有邪靈附身的那個人就跳到他們身上，壓制了所有的人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="所有的人——或譯作「兩個人」 。">j</a></sup>，勝過了他們，以致他們赤著身帶著傷，從那房子逃了出去。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 1:12; 使徒行傳 5:5; 腓立比書 2:9–11"> 所有住在以弗所的猶太人和希臘人，都知道了這件事，恐懼就臨到了他們每個人，主耶穌的名因此被尊為大。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 10:10; 詩篇 32:5; 馬太福音 3:6"> 而且許多信徒都來，承認並述說自己的所作所為。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 13:8; 出埃及記 32:20; 創世記 35:4"> 又有許多行邪術的人，把他們的書籍拿到一處，當眾燒掉。他們估算了那些書的價值，發現共值<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="共值——輔助詞語。">k</a></sup>五萬個銀幣<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="五萬個銀幣——原文為「50,000銀子」或「50,000銀錢」；價值相當於50,000錐克瑪。1錐克瑪=約1日工資的希臘銀幣。">l</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 12:24; 使徒行傳 6:7; 以賽亞書 55:11"> 這樣，主的福音<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="福音——原文直譯「話語」或「道」。">m</a></sup>就大有能力地不斷擴展<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="擴展——原文直譯「生長」。">n</a></sup>，不斷得勝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:22; 使徒行傳 20:16; 使徒行傳 23:11"> 這些事過了以後，保羅受了聖靈的感動決定要經過馬其頓省和亞該亞省，到耶路撒冷去。他說：「我到那裡以後，也必須去羅馬看看。」</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 16:23; 提摩太後書 4:20; 使徒行傳 16:3"> 於是他派了提摩太和以拉斯托兩個服事他的人到馬其頓省去，自己暫時留在亞細亞省。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 19:9; 使徒行傳 24:22; 哥林多後書 1:8–10"> 就在這時候，為了這道發生了不小的騷動。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前書 6:9–10; 使徒行傳 16:16; 使徒行傳 16:19"> 原來，有一個名叫迪米特斯的銀匠，是製造阿蒂米絲女神<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="女神——輔助詞語。">o</a></sup>銀龕<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="阿蒂米絲女神銀龕——原文直譯「阿蒂米絲的銀龕」。">p</a></sup>的，給工匠們帶來不少的生意。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:19; 何西阿書 12:7–8; 啟示錄 18:11–19"> 迪米特斯召集了他們，以及周圍同行的工人，說：「各位，你們知道，我們是由這生意發財的。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 17:29; 哥林多前書 8:4; 以賽亞書 44:10–20"> 可是你們看見了也聽見了，這個保羅不僅在以弗所也幾乎在全亞細亞省，說服、引誘了一大群人，說『人手所造的不是神』。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅書 2:11; 提摩太前書 6:5; 馬太福音 23:13"> 這樣，不僅我們這行業有被輕蔑的危險，連偉大女神阿蒂米絲的廟也要被看為什麼都不是，並且這受全亞細亞省和普天下敬拜的女神的威榮，也要被毀滅了。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 13:4; 啟示錄 17:13; 使徒行傳 16:19–24"> 眾人聽了，就滿腔怒火，喊叫說：「以弗所人偉大的阿蒂米絲！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 20:4; 歌羅西書 4:10; 使徒行傳 27:2"> 於是滿城一片混亂。他們抓住與保羅同來的馬其頓人蓋尤斯和亞里達古，一齊衝進劇場。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 21:39; 撒母耳記下 18:2–3; 使徒行傳 17:22–31"> 保羅雖然想要進到民眾當中，但門徒們不讓他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:10; 使徒行傳 21:12; 使徒行傳 16:6"> 還有一些亞細亞省的官員，是保羅的朋友，也派人勸他不要自己冒險到劇場去。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 21:34; 使徒行傳 19:40; 馬太福音 11:7–9"> 這時候，有人喊這個、有人喊那個，因為集會的人一片混亂，大多數人不知道為了什麼緣故聚集。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 12:17; 提摩太後書 4:14; 提摩太前書 1:20"> 猶太人把亞歷山大推到前面的時候，人群中有些人要他說話。亞歷山大就揮一下手，想要對民眾申辯。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 19:28; 馬太福音 6:7; 啟示錄 13:4"> 可是大家一認出他是猶太人，就同聲呼喊：「以弗所人偉大的阿蒂米絲！」大約喊了兩個小時。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 2:10–11; 提摩太前書 4:2; 以弗所書 2:12"> 後來，城裡的書記官安撫了民眾，說：「各位以弗所人哪，到底有什麼人不知道以弗所城是偉大<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="有古抄本附「女神」。">q</a></sup>阿蒂米絲廟和那從天落下的神像的<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="神像的——輔助詞語。">r</a></sup>看守者呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行傳 5:35–39; 箴言 25:8"> 所以這些事既然是不能否認的，你們就必須冷靜下來，不要做任何妄為的事。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多後書 6:3; 羅馬書 2:22; 使徒行傳 25:8"> 你們帶來的這些人，既沒有偷取廟裡的東西，也沒有褻瀆我們<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="我們——有古抄本作「你們」。">s</a></sup>的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 13:7; 哥林多前書 6:1; 使徒行傳 18:14"> 既然如此，如果迪米特斯和與他一起的工匠們要控告誰，法庭是開著的，省長也在，讓他們彼此控告吧！</span>
<span className="v" id="v39" data-v="39"> 但如果你們有什麼別的要求，要在合法的集會中解決。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 17:5–8; 馬太福音 26:5; 使徒行傳 20:1"> 關於今天的事，本來沒有正當的理由，我們實際上就有被控告為暴亂的危險。我們無法對這次騷動做出交代。」</span>
<span className="v" id="v41" data-v="41" data-xref="傳道書 9:17; 詩篇 65:7; 哥林多後書 1:8–10"> 說了這些話，他就遣散了集會的人。</span>
</div>
</div>

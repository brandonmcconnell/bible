<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 7:5; 使徒行傳 19:21; 提摩太前書 1:3"> 騷亂平息以後，保羅請門徒們來，鼓勵一番，然後與他們告別，就出發往馬其頓省去了。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 2:3; 帖撒羅尼迦前書 4:1; 歌羅西書 1:28"> 他走遍了那些地區，用很多的話鼓勵門徒們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="門徒們——原文直譯「他們」。">a</a></sup>，就來到希臘，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 20:19; 哥林多後書 11:26; 使徒行傳 9:23–24"> 在那裡住了三個月。他正要起航往敘利亞省去的時候，猶太人設計了一個針對他的陰謀，他就決定從馬其頓省回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 19:29; 以弗所書 6:21; 提摩太後書 4:20"> 與他同行<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同行——有古抄本作「一直同行到亞細亞」。">b</a></sup>的，有庇里亞人普羅斯的兒子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="兒子——輔助詞語。">c</a></sup><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本沒有「普羅斯的兒子」。">d</a></sup>索巴特，帖撒羅尼迦人亞里達古和西肯多，也有代爾貝人蓋尤斯和提摩太，還有亞細亞省人特其庫斯和特羅費摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 16:8; 使徒行傳 16:10–11; 提摩太後書 4:13"> 這些人先走，在特羅阿斯港等我們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 12:3; 使徒行傳 16:12; 出埃及記 23:15"> 過了除酵節的日子，我們從腓立比起航，五天後到了特羅阿斯港見他們，在那裡住了七天。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 16:2; 使徒行傳 2:42; 約翰福音 20:19"> 在一週的頭一天<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一週的頭一天——指「星期日」。">e</a></sup>，門徒們<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="門徒們——有古抄本作「我們」。">f</a></sup>聚集掰餅的時候，保羅向他們講論，因第二天就要離開，於是一直講到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:13; 路加福音 22:12"> 我們聚集的樓上房間，有許多燈火。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 13:36; 馬太福音 26:40–41; 約拿書 1:5–6"> 有一個名叫猶圖克斯的年輕人坐在窗臺上，陷入了沉睡。保羅又講論了很久，猶圖克斯在沉睡中從三樓掉了下去，被扶起來的時候，已經死了。</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 5:39; 馬太福音 9:23–24; 列王紀上 17:21–22"> 保羅下去，伏在他身上，抱著他說：「不要慌亂，他的靈魂還在身上！」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 20:7; 使徒行傳 20:9"> 保羅再上去，掰餅吃了，又交談了許久，直到天亮才出發。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦後書 2:16; 帖撒羅尼迦前書 5:14; 哥林多後書 1:4"> 他們把那活生生的年輕人帶走，並且受到了不少的安慰。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 6:46; 馬可福音 1:35; 馬可福音 6:31–33"> 我們先上船開往阿索，要在那裡接保羅；原來他這樣安排，是因為自己要走陸路。</span>
<span className="v" id="v14" data-v="14"> 當他在阿索與我們會合的時候，我們接他上船，來到了米蒂利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 4:20; 使徒行傳 20:17"> 我們從那裡開船，第二天到達了希俄斯島的海域，過了一天在薩莫斯島靠岸，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「在特羅古林停留，」。">g</a></sup>再過一天來到米利都。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:8; 使徒行傳 2:1; 使徒行傳 19:21"> 原來保羅已經決定駛過以弗所城，免得在亞細亞省耽延時間，因為他急著趕路，如果有可能，但願五旬節那一天已經在耶路撒冷了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多書 1:5; 使徒行傳 11:30; 提摩太前書 5:17"> 保羅從米利都派人到以弗所去，請教會的長老們來。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 1:5–6; 使徒行傳 18:19; 使徒行傳 19:1"> 他們來了以後，保羅對他們說：「你們知道，自從我踏進亞細亞省的第一天起，我一直怎樣與你們共處——</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:24; 哥林多後書 2:4; 羅馬書 12:11"> 我在完全的謙卑中、淚水中、以及因猶太人的陰謀而帶來的許多試煉中服事主；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 20:27; 提摩太後書 4:2; 使徒行傳 5:42"> 對你們有益的事，在公眾場所和各家各戶，沒有一件我因畏縮而不傳講、不教導給你們；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 2:38; 使徒行傳 11:18; 約翰一書 5:11–13"> 無論對猶太人或希臘人，我都鄭重地勸誡他們要向神悔改，相信我們的主耶穌<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="耶穌——有古抄本作「耶穌基督」。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="雅各書 4:14; 哥林多後書 5:14; 彼得後書 1:14"> 「看，現在我靈裡受到催逼<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="受到催逼——原文直譯「被捆綁」。">i</a></sup>，要去耶路撒冷。我不知道在那裡將會遇到什麼事，</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 9:16; 帖撒羅尼迦前書 3:3; 使徒行傳 21:4"> 只知道在各城裡聖靈向我鄭重地做見證說，有捆鎖和患難等著我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:6–8; 哥林多後書 4:1; 哥林多後書 12:10"> 但是我不把自己的生命看為寶貴，為要<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「懷著喜樂的心」。">j</a></sup>跑盡我該跑的路程<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="跑盡我該跑的路程——原文直譯「完成我的賽程」。">k</a></sup>，完成從主耶穌所領受的服事工作，為神恩典的福音鄭重地做見證。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 28:31; 使徒行傳 20:38; 馬太福音 4:23"> 「我曾在你們中間走遍各地，宣講神的<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有「神的」。">l</a></sup>國，但現在，看哪，我知道你們都不會再見到我的面了！</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 18:6; 以西結書 3:18–21; 以西結書 33:2–9"> 所以我今天向你們見證：對於任何人的滅亡<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="任何人的滅亡——原文直譯「任何人的血」。">m</a></sup>，我都是清白的！</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 20:20; 帖撒羅尼迦前書 2:4; 加拉太書 1:7–10"> 因為神的整個計劃，我沒有一樣因畏縮而不傳講給你們。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 5:2–3; 提摩太前書 4:16; 以賽亞書 40:11"> 你們當為自己謹慎，也當為全體羊群謹慎。聖靈把你們放在這羊群裡做監督，為要牧養神的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="神的——有古抄本作「主的」。">n</a></sup>教會，就是他用自己的血所贖來的。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 7:15; 彼得後書 2:1; 約翰福音 10:12"> 我知道在我離開以後，凶惡的豺狼將進入你們中間，不會顧惜羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前書 1:19–20; 提摩太後書 4:3–4; 箴言 23:33"> 你們自己當中也會有人起來，講說一些歪曲的道理，要拉攏門徒跟隨他們。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:8; 使徒行傳 20:19; 使徒行傳 19:10"> 所以你們要警醒，記住這三年來，我日夜不住地流著淚水勸誡你們每一個人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 1:12; 以弗所書 1:14; 歌羅西書 3:24"> 「<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本附「弟兄們，」。">o</a></sup>現在我把你們交託給神和他恩典的話語。這話語能造就你們，並且在所有被分別為聖的人中間賜給你們那繼業。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 11:9; 哥林多前書 9:12; 哥林多前書 9:18"> 我沒有渴望過任何人的金子、銀子或衣服。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 18:3; 哥林多前書 4:12; 帖撒羅尼迦後書 3:8–9"> 你們自己也知道，我這雙手供應了我和與我在一起之人的需要。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 13:16; 箴言 19:17; 哥林多後書 9:6–12"> 在一切事上，我都給你們做了榜樣：必須這樣地勞苦做工來扶助軟弱的人，並且要記住主耶穌自己說過的話：<span className="woj">『施比受更加蒙福。』</span>」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 21:5; 路加福音 22:41; 腓立比書 4:6"> 保羅說了這些話，就跪下來與大家一起禱告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太後書 1:4; 哥林多前書 16:20; 帖撒羅尼迦前書 5:26"> 大家都痛哭起來，摟住保羅的脖子親吻他。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 15:3; 哥林多前書 16:11; 使徒行傳 20:25"> 尤其使他們傷心的，就是他說他們不會再看到他面的那句話。然後他們送他上了船。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="22" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:2; 使徒行傳 28:17; 使徒行傳 13:26"> 「各位父老兄弟，現在請聽我的申辯。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 21:40"> 眾人聽見他用希伯來語向他們呼籲，就更加安靜了。保羅說：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:5; 腓立比書 3:5–6; 使徒行傳 9:11"> 「我是猶太人，出生在奇里乞亞省的塔爾蘇，在這城裡長大；在迦瑪列門下，按照我們先祖的律法受了嚴格的教育；我對神是熱心的人，就像今天你們大家一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 22:19–20; 提摩太前書 1:13–15; 使徒行傳 26:9–11"> 我曾經逼迫這道的信徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的信徒——輔助詞語。">a</a></sup>置於死地，無論男女都捆綁起來，關進監獄。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:1–2; 路加福音 22:66; 使徒行傳 5:21"> 這是大祭司和全長老議會的人都可以為我做見證的。我還從他們那裡拿到了給同胞們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同胞們——原文直譯「兄弟們」。">b</a></sup>的一些信函往大馬士革去，要把那裡被捆綁的信徒們<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信徒們——原文直譯「人們」。">c</a></sup>，帶到耶路撒冷來受刑。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 9:3–8; 使徒行傳 26:12–18; 啟示錄 1:16"> 「當我趕路快到大馬士革的時候，大約中午，忽然有強烈的光從天上下來，在我周圍四面照射。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 2:9; 馬太福音 25:45; 創世記 22:11"> 我就仆倒在地上，聽見有聲音對我說：<span className="woj">『掃羅，掃羅！你為什麼逼迫我？』</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 26:9; 撒母耳記上 8:7; 出埃及記 16:7–8"> 「我回答：『主啊！你到底是誰？』<br />「他說：<span className="woj">『我就是你所逼迫的拿撒勒人耶穌。』</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 9:7; 但以理書 10:7; 使徒行傳 26:13"> 與我在一起的人雖然看到了那光，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「感到害怕，」。">d</a></sup>卻聽不懂那對我說話的聲音。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 16:30; 使徒行傳 22:12–16; 使徒行傳 2:37"> 「我說：『主啊！我該做什麼呢？』<br />「主對我說：<span className="woj">『起來，進大馬士革城去，在那裡你將被告知所指定你做的一切事。』</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 9:8–9; 使徒行傳 13:11; 以賽亞書 42:16"> 「我因那光的榮耀，什麼都看不見了，就被同行的人牽著手，進了大馬士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:22; 使徒行傳 6:3; 約翰三書 1:12"> 有一個名叫阿納尼亞的人，按照律法，是一個虔誠的人，受到所有住在那裡的猶太人讚許。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 9:17–18; 腓利門書 1:16"> 他來到我那裡，站在旁邊對我說：『掃羅弟兄，你重見光明吧！』就在那一刻，我抬頭看見他了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 1:12; 哥林多前書 15:8; 哥林多前書 9:1"> 他又說：『我們祖先的神預先指定了你，使你明白他的旨意，看見那位義者，聽見他口中傳來的聲音，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 23:11; 使徒行傳 4:20; 約翰福音 15:27"> 因為你將要做他的見證人，向所有的人見證你所看到的、你所聽到的。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:38; 使徒行傳 2:21; 提多書 3:5"> 現在你還等什麼呢？起來，當受洗<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="受洗——或譯作「受浸」。">e</a></sup>！求告他<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他——有古抄本作「主」。">f</a></sup>的名，當洗去你的罪孽！』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 12:1–4; 使徒行傳 10:9–10; 使徒行傳 9:26–28"> 「後來，我回到耶路撒冷，在聖殿裡禱告的時候，魂遊象外，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 9:29; 路加福音 21:21; 以西結書 3:6–7"> 看見主對我說：<span className="woj">『快！趕快離開耶路撒冷，因為他們不會接受你為我做的見證。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 22:4; 馬太福音 10:17; 使徒行傳 8:3"> 「我就說：『主啊，他們知道我曾經到各會堂，把信靠你的人關進監獄，還鞭打他們。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 7:58; 使徒行傳 8:1; 羅馬書 1:32"> 並且當你的見證人司提反受害<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="受害——輔助詞語。">g</a></sup>流血的時候，我自己也站在旁邊贊同<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「對他的處決」。">h</a></sup>，還為那些殺害他的人看守衣服。』</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 以弗所書 3:6–8"> 「主對我說：<span className="woj">『去吧！我要派你到遙遠的外邦人那裡去。』</span>」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 25:24; 使徒行傳 21:36; 約翰福音 19:15"> 眾人聽保羅講到這句話，就高聲說：「這樣的人，把他從地上除掉，因為他不該活著！」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 16:13; 使徒行傳 26:11; 傳道書 10:3"> 他們喊叫，拋著衣服，向空中揚起塵土。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 21:31–32; 使徒行傳 21:34; 約翰福音 19:1"> 千夫長下令把保羅押進營樓，吩咐鞭打拷問他，要了解民眾是因什麼理由向他這樣一直喊叫。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:37; 使徒行傳 25:16; 使徒行傳 27:43"> 當士兵們用皮條捆上保羅的時候，他對站在旁邊的百夫長說：「你們鞭打一個沒有被定罪的羅馬公民，可以嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 23:27; 使徒行傳 22:29"> 百夫長聽了，就來到千夫長面前，報告說：「你要做什麼呢？<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="你要做什麼呢？——有古抄本作「要注意你所做的事。」">i</a></sup>要知道，這個人是羅馬公民。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 千夫長就前來問保羅：「告訴我，你是羅馬公民嗎？」<br />保羅說：「是的。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 千夫長說：「我花了一大筆錢，才買到了羅馬公民權。」<br />保羅說：「我生下來就是。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 21:33; 使徒行傳 22:24–26; 使徒行傳 16:38–39"> 於是那些要拷問他的人，立刻退下了。千夫長既知道他是羅馬公民，又因為捆綁了他，就懼怕起來。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 23:28; 使徒行傳 21:33; 使徒行傳 21:11"> 第二天，千夫長想確切知道保羅為什麼被猶太人控告，就<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「從捆鎖中」。">j</a></sup>解開他，下令召集祭司長們和全議會的人<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="下令召集祭司長們和全議會的人——有古抄本作「下令要祭司長們和他們全議會的人來」。">k</a></sup>，然後把保羅帶來，叫他站在他們面前。</span>
</div>
</div>

</div>

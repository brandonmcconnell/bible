<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 23:34; 使徒行傳 25:5; 使徒行傳 8:40"> 菲斯特斯到省裡上任第三天，就從凱撒里亞上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 25:15; 箴言 4:16; 使徒行傳 24:1"> 祭司長們和猶太人的首領們向菲斯特斯指控保羅，並且懇求菲斯特斯，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 9:24; 使徒行傳 23:12–15; 撒母耳記上 23:19–21"> 請他恩准，把保羅叫到耶路撒冷來。他們策劃要在路上埋伏殺了保羅。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 24:23"> 於是菲斯特斯說：「保羅正被拘留在凱撒里亞，我自己也很快就要回去。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 25:25; 約翰福音 18:29–30; 使徒行傳 25:18–19"> 他又說：「所以你們中間有權的人都與我一起下去；如果這個人有什麼過錯，就當控告他。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 25:17; 使徒行傳 25:10; 馬太福音 27:19"> 菲斯特斯在他們那裡住了不超過十天八天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不超過十天八天——有古抄本作「十多天」。">a</a></sup>，就下到凱撒里亞去了。第二天，他坐在審判席上，下令把保羅帶上來。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 24:13; 路加福音 23:10; 使徒行傳 25:24"> 保羅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保羅——原文直譯「他」。">b</a></sup>一到，從耶路撒冷下來的那些猶太人就站在他周圍，用很多嚴重的罪狀來控告他，可是都不能證實。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 24:12; 使徒行傳 28:17; 哥林多後書 1:12"> 保羅申辯說：「無論是對猶太人的律法，或是對聖殿，或是對凱撒，我都沒有犯過罪。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 24:27; 使徒行傳 12:3; 使徒行傳 25:20"> 但菲斯特斯想要討好猶太人，就問保羅說：「你願意上耶路撒冷，讓我在那裡審判這些事嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 27:18; 哥林多後書 4:2; 使徒行傳 28:18"> 保羅就說：「我已經站在凱撒的審判臺前，這裡就是我應該受審的地方。我沒有虧負過猶太人，就像您也很清楚地了解那樣。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:19; 使徒行傳 26:32; 使徒行傳 25:25"> 既然如此，如果我行了什麼不義的事，犯了什麼該死的罪，就是死我也不拒絕；但如果這些人對我的控告不是真的，那麼誰也不能把我交給他們。我向凱撒上訴！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:21; 腓立比書 1:12–14; 腓立比書 1:20"> 菲斯特斯與參議會商量以後，就回答：「你已經向凱撒上訴了，你就將到凱撒那裡去！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:40; 使徒行傳 26:1; 使徒行傳 26:27–28"> 過了幾天，阿格里帕王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="阿格里帕王——指「希律阿格里帕二世」。">c</a></sup>和百妮基到達凱撒里亞，問候菲斯特斯。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 24:27"> 他們在那裡住了好幾天，菲斯特斯就向阿格里帕王陳述了有關保羅的事，說：「這裡有一個人，是菲利克斯留下的囚犯。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 25:1–3; 以斯帖記 3:9; 路加福音 18:3–5"> 我到耶路撒冷去的時候，猶太人的祭司長們和長老們指控他，要求我定他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:51; 申命記 19:17–18; 使徒行傳 23:30"> 我回答他們：在被告還沒有與原告當面對質，並且對被控罪名還沒有獲得申辯機會以前，就把被告<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="被告——原文直譯「任何人」。">d</a></sup>交出去，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「以至於死」。">e</a></sup>這不符合羅馬人的規矩。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 25:6; 使徒行傳 25:10"> 因此，當他們聚集在這裡的時候，我沒有耽擱，第二天就坐在審判席上，下令把那個人帶來。</span>
<span className="v" id="v18" data-v="18"> 那些原告站起來圍著他提出來的罪狀，並不是我所認為的惡事<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「惡事」。">f</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 23:29; 使徒行傳 18:15; 哥林多前書 15:3–4"> 不過他們與他有一些爭議的問題，是關於自己宗教的事，以及關於一個叫耶穌的人——這個人已經死了，保羅卻聲稱他還活著。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 25:9"> 我對這些辯論也心裡困惑，就問保羅是否願意上耶路撒冷去，在那裡為這些事受審。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 4:16; 路加福音 2:1; 使徒行傳 25:10–11"> 可是保羅請求把他留給皇帝審斷，我就下令把他留下，等著我送他到凱撒那裡去。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:15; 馬太福音 10:18; 以賽亞書 52:15"> 阿格里帕對菲斯特斯說：「我本來也想親自聽這個人講說。」<br />菲斯特斯說：「明天你就可以聽他講說。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 26:30; 使徒行傳 25:13; 約翰一書 2:16"> 第二天，阿格里帕和百妮基大張聲勢而來，當他們與幾個軍官和城裡的顯要人物一起進了大廳，菲斯特斯一聲下令，保羅就被帶上來。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 22:22; 使徒行傳 25:7; 使徒行傳 25:2–3"> 菲斯特斯說：「阿格里帕王和所有在場的各位，你們所看見的這個人，猶太的全體民眾為了他，在耶路撒冷和這裡向我陳情，喊著說他不應該再活下去。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 23:29; 使徒行傳 25:11–12; 路加福音 23:4"> 但是我了解他並沒有犯過什麼該死的罪，不過他自己既然向皇帝上訴了，我就決定把他解送去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:2–3"> 關於這個人，我沒有任何確切的事可以陳奏皇帝。因此我把他帶到你們面前，尤其在您阿格里帕王面前，好使審查結束時，我可以有所陳奏，</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 7:51; 箴言 18:13"> 因為我認為，解送囚犯而不指明對他的罪狀，是沒有道理的。」</span>
</div>
</div>

</div>

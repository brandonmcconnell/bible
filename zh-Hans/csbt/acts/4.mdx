<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行傳 6:12; 使徒行傳 23:6–9"> 彼得和約翰正向民眾講話的時候，祭司們、聖殿守衛長<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="守衛長——原文直譯「指揮官」或「司令官」或「將軍」。">a</a></sup>和撒都該人忽然來了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 17:18; 帖撒羅尼迦前書 4:13–14; 使徒行傳 24:14–15"> 這些人非常惱怒，因為使徒們教導民眾，藉著耶穌傳講從死人中復活的事。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 5:18; 馬太福音 10:16–17; 使徒行傳 16:19–24"> 於是他們下手捉拿了彼得和約翰。因為天已經晚了，就把他們關在監裡，直到第二天。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 2:41; 哥林多後書 2:14–17; 提摩太後書 2:9–10"> 然而聽了這話語的人中，有許多人相信了；男人的數目約有五千。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 4:8; 馬太福音 27:1–2; 路加福音 20:1"> 到了第二天，猶太人的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="猶太人的——原文直譯「他們的」。">b</a></sup>首領、長老和經文士們都聚集在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 約翰福音 18:24; 馬太福音 26:3"> 大祭司亞納、該亞法、約翰、亞歷山大，以及大祭司家族的人都在那裡。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 21:23; 馬可福音 11:28; 使徒行傳 5:40"> 他們叫彼得和約翰站在中間，質問他們，說：「你們憑著什麼能力，以誰的名做這事？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 馬太福音 10:19–20; 使徒行傳 2:4"> 那時，彼得被聖靈充滿，對他們說：「民眾的首領和<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「以色列的」。">c</a></sup>長老們，</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 3:15–17; 使徒行傳 3:7; 約翰福音 10:32"> 如果我們今天因在一個殘疾人身上所行的善事，被查問這個人怎樣得到救治，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:29–32; 使徒行傳 3:6; 使徒行傳 2:36"> 那麼，你們大家和所有以色列子民應當知道：這個人健全地站在你們面前，是藉著拿撒勒人耶穌基督的名。這位耶穌基督，你們把他釘上十字架，但是神使他從死人中復活了！</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:22–23; 以賽亞書 28:16; 馬可福音 12:10–12"> 這一位就是<br /><span className="pl pl-1">『被你們工匠所藐視的石頭，</span><br /><span className="pl pl-1">它已經成了房角的頭塊石頭。』</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 14:6; 哥林多前書 3:11; 約翰福音 3:36"> 除他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——輔助詞語。">d</a></sup>以外，沒有救恩<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="救恩——或譯作「拯救」。">e</a></sup>；因為在天下人間，沒有賜下別的名，我們必須靠著得救。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 1:27; 約翰福音 7:15; 馬太福音 11:25"> 他們看見彼得和約翰的膽量，又了解他們是沒有學問的普通人，就感到驚奇，並且了解他們是曾經與耶穌在一起的；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 19:36; 使徒行傳 3:8–12; 使徒行傳 4:21"> 又看見那得了痊癒的人和他們一同站著，就無話可說了，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 26:30–32; 使徒行傳 5:34–42; 馬太福音 5:22"> 於是命令他們到議會外面去，就彼此商議，</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行傳 6:10; 約翰福音 12:18"> 說：「我們該怎麼處理這些人呢？藉著他們，確實發生了一個明顯的神蹟，所有住在耶路撒冷的人都清清楚楚；我們也不能否認。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:28; 羅馬書 15:18–22; 使徒行傳 5:24"> 不過為了避免這事在民間傳揚更廣，讓我們威嚇他們<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="讓我們威嚇他們——有古抄本作「讓我們用恐嚇的手段來恐嚇他們」。">f</a></sup>，不可再奉耶穌的名<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶穌的名——原文直譯「這個名」。">g</a></sup>對任何人講話。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:40; 路加福音 24:46–48; 使徒行傳 5:20"> 於是把他們叫來，吩咐他們絕對不可奉耶穌的名講說或教導人。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 5:29; 出埃及記 1:17; 哥林多前書 10:15"> 可是彼得和約翰回答說：「聽從你們過於聽從神，在神面前是理所當然的嗎？你們自己判斷吧！</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 22:15; 耶利米書 20:9; 哥林多前書 9:16–17"> 要知道，我們所看見所聽見的，我們不能不說。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 5:26; 馬太福音 21:46; 路加福音 22:2"> 官長們又威嚇他們一番，為了民眾的緣故把他們釋放了。官長們找不出任何理由來懲罰他們，因為眾人都為所發生的事不住地榮耀神。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 5:5; 使徒行傳 9:33; 路加福音 13:11"> 實際上，因神蹟而痊癒的那個人已經四十多歲了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:14–17; 使徒行傳 12:11–12; 詩篇 119:63"> 彼得和約翰被釋放了，就回到自己的人那裡，把祭司長們和長老們所說的話都告訴他們。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:11; 耶利米書 32:17; 尼希米記 9:6"> 他們聽了，就同心合意地高聲向神說：「主啊，你是造了天、地、海和其中萬有的那一位<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="那一位——有古抄本作「神」。">h</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–6; 使徒行傳 1:16; 使徒行傳 2:30"> 你曾經藉著聖靈<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有「藉著聖靈」。">i</a></sup>，用你的僕人——我們先祖<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「我們先祖」。">j</a></sup>大衛的口說：<br /><span className="pl pl-1">『列國為什麼狂怒騷亂，</span><br /><span className="pl pl-1">眾民為什麼圖謀虛空？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:2; 啟示錄 17:12–14; 但以理書 9:24"> <span className="pl pl-1">地上的眾君王都起來，</span><br /><span className="pl pl-1">首領們也聚集在一起，</span><br /><span className="pl pl-1">抵擋主和他的基督。』</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 27:2; 使徒行傳 4:30; 路加福音 9:22"> 「事實上，希律和本丟彼拉多，與外邦人和以色列子民果然在這城裡<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本沒有「在這城裡」。">k</a></sup>一同聚集，對付你所膏立的聖僕耶穌，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 2:23; 以賽亞書 46:10; 創世記 50:20"> 做成了你手和你計劃所預定要成就的一切事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:13; 使徒行傳 14:3; 腓立比書 1:14"> 主啊，現在求你鑒察<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="鑒察——或譯作「注意」。">l</a></sup>他們的威嚇，使<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="使……能——原文直譯「賜給」。">m</a></sup>你的奴僕們能滿有膽量地傳講你的話語。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 4:27; 使徒行傳 3:6; 使徒行傳 5:12"> 求你伸出你的手，藉著你聖僕耶穌的名，使疾病痊癒，施行神蹟和奇事。」</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 21:22; 使徒行傳 2:2; 使徒行傳 2:4"> 他們禱告完了，聚集的地方就被震動，大家都被聖靈充滿，就坦然無懼地傳講神的話語<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="神的話語——或譯作「神的道」。">n</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 1:10; 以弗所書 4:2–6; 彼得前書 3:8"> 於是那一群信徒都同心合意，沒有一個人說他所擁有的哪樣東西是自己的；相反，他們凡物共有。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 1:16; 使徒行傳 1:22; 使徒行傳 1:8"> 使徒們大有能力地為主耶穌的復活做見證，並且在他們每個人身上都有極大的恩典。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 2:45; 路加福音 12:33; 路加福音 16:9"> 他們當中沒有一個缺乏的人，因為凡是擁有田產或房屋的人，都賣掉了那些東西，把所賣得的錢拿來，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 5:2; 使徒行傳 2:45; 哥林多後書 8:20–21"> 放在使徒們的腳前，按照各人的需要分給每個人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="加拉太書 2:9; 加拉太書 2:13; 加拉太書 2:1"> 有一個出生在塞浦路斯的利未人約瑟，使徒們稱他為巴拿巴——「巴拿巴」翻譯出來就是「安慰之子」；</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 5:1–2; 使徒行傳 4:34–35; 馬太福音 19:29"> 他有一塊田地，也賣掉了，把錢拿來放在使徒們的腳前。</span>
</div>
</div>

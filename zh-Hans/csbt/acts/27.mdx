<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="27" data-verses="44">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 25:25; 使徒行傳 25:12; 使徒行傳 10:1"> 既然決定了我們要坐船往意大利去，他們就把保羅和其他一些囚犯交給皇家軍團的一個名叫猶利烏斯的百夫長。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 19:29; 腓利門書 1:24; 歌羅西書 4:10"> 有一條阿德米提的船，要開往亞細亞省沿岸各地，我們就上那船出發了。有一個從帖撒羅尼迦來的馬其頓人亞里達古，與我們在一起。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 24:23; 使徒行傳 28:16; 使徒行傳 27:43"> 第二天，我們在西頓靠岸。猶利烏斯寬待保羅，准許他到朋友那裡去接受照顧。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:36; 使徒行傳 15:39; 使徒行傳 13:4"> 我們從那裡起航，因為逆風，就沿著塞浦路斯島的背風岸航行。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 6:9; 使徒行傳 13:13; 使徒行傳 15:41"> 度過了奇里乞亞省和潘菲利亞省一帶的海域，在呂基亞省的每拉登陸。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 28:11; 使徒行傳 27:1; 使徒行傳 6:9"> 百夫長在那裡找到了一條亞歷山大的船，要開往意大利去，就安排我們上了那船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 27:21; 提多書 1:5; 提多書 1:12"> 一連好幾天，船航行得很慢，好不容易才到了尼多斯港附近。因為風攔阻我們往前，我們就從撒摩尼岬附近經過，沿著克里特島的背風岸航行。</span>
<span className="v" id="v8" data-v="8"> 我們沿著它航行，好不容易來到一個叫做「美麗港」的地方；離那裡不遠，有個城叫做拉塞亞。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 29:7; 利未記 23:27–29; 利未記 16:29–31"> 又過了很久，這次航程已經很危險，又因為已經過了禁食日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="禁食日——指「（猶太人的）贖罪日」。">a</a></sup>，保羅就勸大家，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 2:30; 使徒行傳 27:20–26; 使徒行傳 27:41–44"> 說：「各位，我看這次航程，不僅是貨物和船，就是我們的生命財產也將會受到傷害和嚴重的損失。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 33:4; 希伯來書 11:7; 以西結書 3:17–18"> 可是百夫長信任了船長和船主，不信任保羅所說的，</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:30; 使徒行傳 27:8"> 而且這港口不適合過冬，大多數人就主張從那裡開船，或許能夠到達菲尼斯過冬。菲尼斯是克里特島上的一個港口，一面朝西南，一面朝西北。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 約伯記 37:17"> 這時，南風微微吹起，他們以為正合所願，就起了錨，沿著克里特島航行。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 4:37; 詩篇 107:25–27; 出埃及記 14:21–27"> 但是過了不久，一股叫做「東北風」的颶風，從島上襲來。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:4; 使徒行傳 27:27"> 船被困住，頂不住風，我們只好任憑船被颳走。</span>
<span className="v" id="v16" data-v="16"> 我們沿著一個叫做克勞達小島的背風岸行駛的時候，好不容易才控制住救生艇。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 27:29; 使徒行傳 27:26; 使徒行傳 27:41"> 水手們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="水手們——原文直譯「他們」。">b</a></sup>把救生艇拖上來以後，就用纜繩繞過大船底綁好；又怕在敘爾提斯淺灘上會擱淺，就把錨放低，任船漂流。</span>
<span className="v" id="v18" data-v="18" data-xref="約拿書 1:5; 使徒行傳 27:38; 馬太福音 16:26"> 我們被暴風猛烈地襲擊。第二天，他們開始把貨物拋在海裡。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:4; 路加福音 9:24–25; 馬可福音 8:35–37"> 第三天，他們又親手把船上的用具拋出去。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:29; 馬太福音 8:24–25; 耶利米書 2:25"> 一連好幾天見不到太陽和星星，又有暴風雨催逼著，最後我們連獲救的希望都斷絕了。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 詩篇 107:5–6; 使徒行傳 27:7"> 那時，大家已經很久沒有吃東西了，保羅站在他們當中說：「哦，各位啊！你們當初應該聽我的，不從克里特開船，省得有這樣的傷害和損失。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 27:25; 使徒行傳 27:36; 哥林多後書 4:8–9"> 只是現在我勸你們振作起來，因為你們當中不會有人失去性命，不過會失去這條船。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 23:11; 羅馬書 1:9; 提摩太後書 4:17"> 要知道，我所歸屬、所事奉的神，他的一位天使昨天晚上站在我身邊，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 23:11; 提摩太後書 4:16–17; 馬太福音 10:28"> 說：『保羅，不要怕！你必須站在凱撒面前。看哪，所有與你同船的人，神都賜給你了。』</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 4:20–21; 路加福音 1:45; 民數記 23:19"> 所以請各位振作起來，因為我相信神怎樣對我說，事情也會怎樣成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 28:1; 使徒行傳 27:17; 使徒行傳 27:29"> 不過我們必須擱淺在一個島上。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約拿書 1:6; 使徒行傳 27:30; 啟示錄 18:17"> 到了第十四天的晚上，我們在亞得里亞海上飄來飄去。約在半夜，水手們認為已經靠近陸地了，</span>
<span className="v" id="v28" data-v="28"> 就測了水深，發現有三十七公尺<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十七公尺——原文為「20歐貴亞」。1歐貴亞=185公分。">c</a></sup>；稍往前行，再測一測，發現有二十七公尺<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="二十七公尺——原文為「15歐貴亞」。1歐貴亞=185公分。">d</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 27:17; 希伯來書 6:19; 申命記 28:67"> 他們擔心會撞到礁石，就從船尾拋下四個錨，祈盼著天亮。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 27:16; 使徒行傳 27:32"> 水手們想離船逃生，就把救生艇放到海裡，卻假裝要從船頭拋錨。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦後書 2:13–14; 詩篇 91:11–12; 耶利米書 29:11–13"> 保羅對百夫長和士兵們說：「這些人如果不留在船上，你們就不能獲救。」</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比書 3:7–9; 路加福音 16:8"> 於是士兵們就把救生艇的繩索砍斷，由它漂去。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 天快亮的時候<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="天快亮的時候——原文直譯「白晝就要來臨了」。">e</a></sup>，保羅勸大家用飯，說：「你們一直挨餓等候，什麼都不吃，今天是第十四天了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:30; 列王紀上 1:52; 路加福音 21:18"> 所以我勸你們用飯，因為這是關於你們得救的事。要知道，你們中間，沒有一個人會失去<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="失去——有古抄本作「掉」。">f</a></sup>一根頭髮。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 15:36; 哥林多前書 10:30–31; 提摩太前書 4:3–4"> 說完這些話，保羅就拿起餅，在大家面前感謝神，然後掰開來，開始吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多後書 1:4–6; 使徒行傳 27:22; 詩篇 27:14"> 於是大家受到鼓勵，也吃了飯。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 2:41; 羅馬書 13:1; 彼得前書 3:20"> 我們在船上的，共有兩百七十六個人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="人——原文直譯「靈魂」。">g</a></sup>。</span>
<span className="v" id="v38" data-v="38" data-xref="約拿書 1:5; 馬太福音 6:25; 使徒行傳 27:18–19"> 大家吃飽了飯，就把麥子扔到海裡，減輕船的負荷。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 28:1"> 天亮的時候，他們雖然不認識那地方，卻看見一個有沙灘的海灣，就決定盡可能地把船攏進去。</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 33:23; 使徒行傳 27:29–30"> 於是他們砍斷了錨，把它們丟棄在海裡，同時鬆開舵繩，拉起了前帆，順著風向岸前進。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多後書 11:25–26; 以西結書 27:26; 使徒行傳 27:26–29"> 但遇到海水夾流的地方，船就擱了淺，船頭被卡住，動彈不得，而船尾也開始被波浪的猛力衝散了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬可福音 15:15–20; 傳道書 9:3; 詩篇 74:20"> 士兵們的計劃是要把囚犯殺了，免得有人游泳逃脫。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 27:3; 箴言 16:7; 使徒行傳 27:11"> 可是百夫長想救保羅，就攔阻了他們的計劃，命令會游泳的人跳下船，先到岸上去，</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 27:22; 詩篇 107:28–30; 約翰福音 6:39–40"> 其餘的人，有的用木板，有的用船上的東西跟著<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="跟著——輔助詞語。">h</a></sup>；這樣，大家就都獲救上岸了。</span>
</div>
</div>

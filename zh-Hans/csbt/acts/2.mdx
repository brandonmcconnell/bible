<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 15:6; 腓立比書 2:2; 使徒行傳 1:13–15"> 到了五旬節那天，他們都聚集<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="聚集——有古抄本作「同心合意地」。">a</a></sup>在一起<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="聚集在一起——原文直譯「同在一個地方」。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:31; 列王紀上 19:11; 詩篇 18:10"> 突然，有響聲從天上下來，好像狂風吹過，充滿了他們所坐的整個房子，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 3:11; 約翰福音 1:32–33; 耶利米書 23:29"> 有舌頭像火焰那樣，向他們顯現，分開留<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="留——原文直譯「坐落」。">c</a></sup>在他們每一個人身上。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 16:17; 使徒行傳 13:52; 使徒行傳 4:31"> 於是他們都被聖靈充滿，就照著聖靈賜給他們的話，開始說出別種語言<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="語言——原文直譯「舌頭」；傳統譯法作「方言」；或譯作「殊言」。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行傳 8:2; 歌羅西書 1:23"> 當時，有從天下各國來的虔誠的猶太人，住在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 2:3; 哥林多前書 16:9; 使徒行傳 2:2"> 這聲音一響，有一群人就聚集而來，非常慌亂，因為各個人都聽見使徒們<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="使徒們——原文直譯「他們」。">e</a></sup>用各個人本地的語言說話。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 2:12; 使徒行傳 1:11; 約翰福音 7:52"> 他們又驚訝又詫異，說<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="說——有古抄本作「彼此說」。">f</a></sup>：「看，這些說話的不都是加利利人嗎？</span>
<span className="v" id="v8" data-v="8"> 我們怎麼會聽到我們各自出生地的語言呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 1:1; 使徒行傳 18:2; 啟示錄 1:4"> 我們當中有帕提亞人、米底亞人、埃攔人；也有住在美索不達米亞、猶太和卡帕多細亞、本都和亞細亞、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 16:6; 撒迦利亞書 8:23; 撒迦利亞書 8:20"> 弗里吉亞和潘菲利亞、埃及和靠近古利奈的利比亞地區的人；還有從羅馬來的旅客，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 12:10; 出埃及記 15:11; 詩篇 78:4"> 包括猶太人和入猶太教的人；克里特人和阿拉伯人。我們都聽見他們用我們的語言述說神偉大的作為！」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行傳 17:20; 路加福音 18:36"> 眾人又驚訝又困惑，彼此問：「這是什麼意思呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 14:23; 使徒行傳 2:15; 撒母耳記上 1:14"> 可是另有些人嘲笑說：「他們被新酒灌醉了！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 51:7; 以賽亞書 51:1; 申命記 27:9"> 這時，彼得和其他十一個使徒一同站起來，高聲對眾人說：「各位猶太人和所有住在耶路撒冷的人哪，你們應當知道這件事，也應當仔細聽我的話，</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 5:5–8; 撒母耳記上 1:15; 馬太福音 20:3"> 因為這些人不是像你們所想的那樣喝醉了，要知道，現在不過是早上九點<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="九點——原文為「第三時刻」。">g</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="約珥書 2:28–32"> 其實這是先知約珥所說的：</span>
<span className="v" id="v17" data-v="17" data-xref="約珥書 2:28–32; 以賽亞書 44:3; 提多書 3:4–6"> <span className="pl pl-1">『神說，在末後的那些日子裡將是這樣：</span><br /><span className="pl pl-1">我要把我的靈傾注在所有人身</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="人身——原文直譯「肉體」。">h</a></sup><br /><span className="pl pl-1">上，</span><br /><span className="pl pl-1">你們的兒女要說預言</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="說預言——或譯作「做先知傳道」。">i</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你們的年輕人要見異象，</span><br /><span className="pl pl-1">你們的老年人要做異夢。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 3:28; 歌羅西書 3:11; 哥林多前書 7:21–22"> <span className="pl pl-1">是的，在那些日子裡，</span><br /><span className="pl pl-1">我也要將我的靈傾注</span><br /><span className="pl pl-1">在我的奴僕和婢女們身上，</span><br /><span className="pl pl-1">他們就要說預言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:30–31; 西番雅書 1:14–18; 瑪拉基書 4:1–6"> <span className="pl pl-1">在天上我要顯奇事；</span><br /><span className="pl pl-1">在地上我要行神蹟——</span><br /><span className="pl pl-1">有血、有火、有煙霧。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彼得後書 3:10; 阿摩司書 8:9; 馬太福音 24:29"> <span className="pl pl-1">在主那大而顯赫的日子來到之前，</span><br /><span className="pl pl-1">太陽要變為黑暗，</span><br /><span className="pl pl-1">月亮要變為血。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 10:12–13; 約珥書 2:32; 詩篇 86:5"> <span className="pl pl-1">那時候，無論誰求告主名，都將得救。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 3:2; 約翰福音 14:10–11; 馬太福音 12:28"> 「各位以色列人哪，請聽這些話：拿撒勒人耶穌是神向你們所證實的人；神藉著他在你們中間行了大能、神蹟和奇事，正如你們自己所知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行傳 4:28; 使徒行傳 3:18"> 這一位照著神設定的計劃和先見被交出去；你們就藉著外邦人的手<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「帶走」。">j</a></sup>，把他釘上十字架殺了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 6:14; 彼得前書 1:21; 使徒行傳 2:32"> 神卻解除了死亡的痛苦，使他復活，因為他本來就不能被死亡轄制。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 16:8–11; 以賽亞書 41:13; 詩篇 62:6"> 事實上，大衛指著他說：<br /><span className="pl pl-1">『我常常看見主在我面前；</span><br /><span className="pl pl-1">因他在我的右邊，</span><br /><span className="pl pl-1">我就不至於搖動。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 16:9; 詩篇 63:5; 詩篇 71:23"> <span className="pl pl-1">為此我內心歡喜，</span><br /><span className="pl pl-1">口舌快樂，</span><br /><span className="pl pl-1">並且我的肉身也要安居在盼望中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:10; 使徒行傳 2:31; 啟示錄 1:18"> <span className="pl pl-1">因為你不會把我的靈魂撇棄在陰間，</span><br /><span className="pl pl-1">也不會讓你的聖者經歷腐朽。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 16:11; 詩篇 25:4; 詩篇 21:6"> <span className="pl pl-1">你讓我明白了生命之道</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="道——或譯作「路」。">k</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">使我在你面前充滿喜樂。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 13:36; 列王紀上 2:10; 使徒行傳 7:8–9"> 「各位兄弟，關於先祖大衛，我可以明確地告訴你們：他不但死了，也被埋葬了，而且他的墳墓到今天還在我們這裡。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 132:11–18; 詩篇 89:3–4; 耶利米書 33:14–15"> 既然大衛是先知，也知道神曾向他起誓說，要從他的後裔中興起一位<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="要從他的後裔中興起一位——有古抄本作「要按肉身從他的後裔中興起基督」。">l</a></sup>坐在他的寶座上，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 2:27; 詩篇 16:10; 使徒行傳 13:35"> 大衛又預先看見了，就講論基督復活的事，說：<br /><span className="pl pl-1">『他</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="他——有古抄本作「他的靈魂」。">m</a></sup><br /><span className="pl pl-1">既沒有被撇棄在陰間，</span><br /><span className="pl pl-1">他的肉身也沒有經歷腐朽。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 3:15; 使徒行傳 1:8; 使徒行傳 1:22"> 「這位耶穌，神已經使他復活了。我們都是這事的見證人。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 1:4; 使徒行傳 5:31; 使徒行傳 2:17"> 他被高舉在神的右邊，從父領受了所應許的聖靈，就將聖靈傾注了下來。這正是你們現在所看見所聽見的。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 110:1; 馬太福音 22:42–45; 希伯來書 1:13"> 大衛並沒有升到諸天之上去，可是他說，<br /><span className="pl pl-1">『主對我主說：</span><br /><span className="pl pl-1">你坐在我的右邊，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="啟示錄 19:19–3; 羅馬書 16:20; 以賽亞書 60:14"> <span className="pl pl-1">等我把你的敵人放在你的腳下做腳凳。』</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 5:30–31; 羅馬書 14:8–12; 哥林多後書 5:10"> 「因此，以色列全家都當確實知道：被你們釘上十字架的這位耶穌，神已經委任他為主、為基督了。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行傳 22:10; 希伯來書 4:12–13"> 眾人聽了這話，覺得扎心，就對彼得和其他的使徒說：「各位兄弟，我們該做什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 22:16; 馬可福音 16:16; 使徒行傳 8:12"> 彼得對他們說：「你們應當悔改，每個人都當奉耶穌基督的名受洗<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="受洗——或譯作「受浸」。">n</a></sup>，使你們的罪得赦免，就會領受所賜的聖靈。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 44:3; 創世記 17:7–8; 羅馬書 8:30"> 因為這應許是給你們和你們的兒女，以及所有在遠處的人，就是主我們的神所召來的人。」</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 2:15; 申命記 32:5; 馬太福音 17:17"> 彼得還說許多別的話鄭重地做見證，又勸告他們說：「你們從這扭曲的<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="扭曲的——或譯作「彎曲的」或「不正直的」。">o</a></sup>世代中得救吧！」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 4:4; 使徒行傳 2:47; 使徒行傳 16:31–34"> 於是<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本附「高興地」。">p</a></sup>領受他話的人就受了洗；那一天大約增加了三千人<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="人——原文直譯「靈魂」。">q</a></sup>。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 10:25; 使徒行傳 1:14; 約翰一書 1:3"> 他們在使徒們的教導上，在契合<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="契合——或譯作「溝通」或「分享」。">r</a></sup>、掰餅、禱告之事上恆切專心。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 約翰福音 14:12; 路加福音 8:37"> 每個人<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="人——原文直譯「靈魂」。">s</a></sup>都起了敬畏之心。使徒們又行了很多奇事和神蹟<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="使徒們又行了很多奇事和神蹟——原文直譯「有很多奇事和神蹟藉著使徒們發生了」。">t</a></sup>。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 4:32; 約翰一書 3:16–18; 哥林多後書 8:14–15"> 所有信了的人都在一起，凡物共有，</span>
<span className="v" id="v45" data-v="45" data-xref="約翰一書 3:17; 提摩太前書 6:18–19; 雅各書 2:14–16"> 他們變賣財產和產業，按照各人的需要分給大家。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 5:42; 使徒行傳 20:7; 使徒行傳 2:42"> 他們同心合意，不但天天恆切地在聖殿聚集<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="聚集——輔助詞語。">u</a></sup>，還在各家各戶掰餅。他們懷著喜樂和誠懇的心用飯，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 16:5; 使徒行傳 5:13–14; 使徒行傳 2:41"> 讚美神，並且得到全體民眾的喜愛。主就在那裡<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="有古抄本沒有「在那裡」。">v</a></sup>使得救的人與日俱增<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="有古抄本附「給教會」。">w</a></sup>。</span>
</div>

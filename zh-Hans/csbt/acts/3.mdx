<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 55:17; 使徒行傳 10:3; 使徒行傳 4:13"> 有一次，在下午三點<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="下午三點——原文為「第九時刻」。">a</a></sup>禱告的時候，彼得和約翰上聖殿去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 14:8; 約翰福音 9:8; 路加福音 16:20"> 一個生來<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="生來——原文直譯「從母腹中」。">b</a></sup>瘸腿的被人抬來。他天天被放在那叫「美門」的聖殿門口，為要向進聖殿的人乞討。</span>
<span className="v" id="v3" data-v="3"> 他看見彼得和約翰正要進入聖殿，就求他們施捨。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:9–10; 約翰福音 11:40; 路加福音 4:20"> 彼得和約翰注視著他，彼得說：「你看我們！」</span>
<span className="v" id="v5" data-v="5"> 那人就留意看他們，期待著從他們那裡得些什麼。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 3:16; 使徒行傳 10:38; 使徒行傳 4:10"> 彼得卻說：「金子銀子我都沒有，只把我有的給你：奉拿撒勒人耶穌基督的名，起來<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「起來」。">c</a></sup>走路吧！」</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 1:31; 馬可福音 9:27; 使徒行傳 9:41"> 彼得抓著他的右手，扶他起來。他的腳和踝骨立刻就健壯了。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 14:10; 以賽亞書 35:6; 詩篇 107:20–22"> 他一跳，站了起來，並且行走，與他們一起進入聖殿，邊走邊跳，讚美神。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:21; 使徒行傳 4:16; 路加福音 13:17"> 全體民眾都看見他邊走邊讚美神，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 3:2; 約翰福音 5:20; 約翰福音 9:3"> 認出他是坐在聖殿的美門口乞討的那個人，就對發生在他身上的事滿心希奇、驚訝。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:12; 約翰福音 10:23; 路加福音 8:38"> 那個人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="那個人——有古抄本作「那得了痊癒的瘸腿之人」。">d</a></sup>緊拉著彼得和約翰的時候，全體民眾都一起跑向他們，到叫做「所羅門」的柱廊那裡，滿心驚奇。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:5; 約翰福音 3:27–28; 但以理書 2:28–30"> 彼得看見，就對民眾說：「各位以色列人哪！你們為什麼對這事感到驚奇？為什麼注視我們，以為我們是憑著自己的能力或虔誠使這個人走路的呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 22:32; 使徒行傳 7:32; 馬太福音 27:17–25"> 亞伯拉罕、以撒、雅各的神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="亞伯拉罕、以撒、雅各的神——原文直譯「亞伯拉罕的神、以撒的神、雅各的神」。">e</a></sup>，也就是我們祖先的神，已經榮耀了他的僕人耶穌。你們竟然把他交出去，並且在彼拉多判定要釋放他的時候，在彼拉多面前拒絕了他。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 1:24; 使徒行傳 7:52; 彼得前書 3:18"> 你們拒絕了神聖、公義的那一位，而要求釋放一個殺人犯給你們。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:24; 啟示錄 21:6; 使徒行傳 2:32"> 你們殺害了生命的創始者<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="創始者——或譯作「本源」或「元首」。">f</a></sup>，神卻使他從死人中復活了！我們就是這事的見證人。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 21:21–22; 使徒行傳 4:10; 使徒行傳 14:9"> 現在，基於對他名的信心，他的名就使你們所看見所認識的這個人健壯了；這由耶穌而來的信心，使他在你們眾人面前完全康復了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行傳 13:27; 約翰福音 16:3"> 「同胞們<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="同胞們——原文直譯「兄弟們」。">g</a></sup>，現在我知道，你們所做的是出於愚昧無知，就像你們的首領那樣。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:1–12; 使徒行傳 26:22–23; 使徒行傳 2:23"> 但神藉著眾先知的口所預言的，就是基督要受難的事，就這樣應驗了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 2:38; 以賽亞書 44:22; 以賽亞書 43:25"> 所以，你們應當悔改，應當回轉，使你們的罪孽被抹去，</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:30–36; 啟示錄 19:11–16; 帖撒羅尼迦後書 2:2"> 這樣，更新的日子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="更新的日子——或譯作「安舒的日子」。">h</a></sup>就會從主面前來到；並且他要將耶穌，就是預先指定給你們的那位基督差來。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:21; 以賽亞書 1:26; 使徒行傳 1:11"> 不過天必須留他，直到萬有復興的時候，就是神自古以來藉著聖先知們的口所說的那時候。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:15–19; 使徒行傳 7:37; 加拉太書 4:4"> 摩西確實<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「對祖先」。">i</a></sup>說過：<br />『主——你們的神，將要從你們兄弟中給你們興起一位先知，像興起我一樣。他對你們所說的一切，你們都要聽從。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 18:19; 約翰福音 12:48; 希伯來書 10:28–30"> 所有不聽從那位先知的人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="人——原文直譯「靈魂」。">j</a></sup>，都要從民中被全然滅絕。』</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 3:21; 路加福音 24:27; 撒母耳記上 3:20"> 「其實從撒母耳以來所有的先知，只要說預言<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="說預言——原文直譯「說話」。">k</a></sup>，都同樣地預告了這些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 22:18; 加拉太書 3:8; 使徒行傳 2:39"> 你們是先知們的子孫，也是神與你們<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="你們——有古抄本作「我們」。">l</a></sup>祖先所訂立之約的子孫。那時神對亞伯拉罕說：『藉著你的那位後裔，地上萬族都要蒙祝福。』</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 1:21; 使徒行傳 3:22; 猶大書 1:24"> 神興起了他的僕人<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附「耶穌」。">m</a></sup>，差派他先到你們這裡來，要你們每個人轉離自己的罪行，好祝福你們。」</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="17" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 1:1; 腓立比書 4:16; 使徒行傳 20:4"> 保羅和西拉斯經過安菲波利斯和阿波羅尼亞，來到帖撒羅尼迦。那裡有一個猶太人的會堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 9:20; 使徒行傳 17:17; 使徒行傳 18:4"> 保羅照習慣進了會堂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="會堂——原文直譯「他們那裡」。">a</a></sup>，一連三個安息日，引用經文向他們講論，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:28; 使徒行傳 9:22; 路加福音 24:32"> 講解並說明基督必須受難，然後從死人中復活，並且說：「我傳給你們的這位耶穌，就是基督。」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 17:12; 使徒行傳 13:43; 使徒行傳 14:4"> 他們當中有些人被說服了，就跟從了保羅和西拉斯；不但有一大群敬神的希臘人，還有不少顯要的婦女。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:26; 使徒行傳 17:13; 羅馬書 16:21"> 但那些不肯信從的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有「不肯信從的」。">b</a></sup>猶太人嫉妒了，就招聚一些市井無賴，成群結夥，擾亂城市。他們闖進耶森的家，搜尋保羅和西拉斯，要把他們帶到民眾那裡。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:5; 使徒行傳 16:19–21; 使徒行傳 28:22"> 可是找不到他們，就把耶森和幾位弟兄拉到地方官們那裡，喊叫說：「這些攪亂天下的，也來到這裡，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行傳 16:21; 約翰福音 19:12"> 耶森竟接待了他們！這些人都違背了凱撒的諭令，說另外有一個王，就是耶穌。」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 2:3; 約翰福音 11:48"> 民眾和地方官們聽了這些話就驚慌不安，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 17:5"> 後來，拿了耶森和其他人的保釋金，就把他們釋放了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:2; 帖撒羅尼迦前書 2:2; 使徒行傳 17:13–14"> 弟兄們立刻連夜送保羅和西拉斯往庇里亞城去。兩個人一到，就進了猶太人的會堂。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 34:16; 箴言 2:1–5; 約翰福音 5:39"> 這裡的人比帖撒羅尼迦的人開明。他們滿心樂意地接受這福音<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="福音——原文直譯「話語」或「道」。">c</a></sup>，天天查考經文，要看這些事是否如此。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:14; 使徒行傳 14:1; 使徒行傳 13:50"> 這樣，他們當中有許多人相信了，包括尊貴的希臘婦女，以及不少男人。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 2:14–16; 箴言 28:25; 使徒行傳 6:12"> 可是當帖撒羅尼迦的猶太人知道保羅又在庇里亞城傳揚神的話語<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的話語——或譯作「神的道」。">d</a></sup>時，就來到那裡煽動、攪擾<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「攪擾」。">e</a></sup>民眾。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 17:10; 馬太福音 10:23; 使徒行傳 9:25"> 於是弟兄們立刻送保羅往海<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="海——指「愛琴海」。">f</a></sup>邊去，西拉斯和提摩太仍然留在庇里亞。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 18:5; 帖撒羅尼迦前書 3:1; 使徒行傳 18:1"> 護送保羅的人一直帶他到了雅典，然後領受了要西拉斯和提摩太盡快到他這裡來的指示，就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:158; 彼得後書 2:7; 詩篇 119:136"> 保羅在雅典等候西拉斯和提摩太的時候，看見滿城都是偶像，他靈裡被激怒。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 13:16; 使徒行傳 14:1–4; 使徒行傳 17:2–4"> 於是他在會堂裡向猶太人以及那些敬神的人講論，每天又向在街市上遇見的人講論。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:20–21; 歌羅西書 2:8; 路加福音 11:53"> 有些伊壁鳩魯派和斯多亞派的哲學家們也與他辯論。<br />有的說：「這胡言亂語的人，究竟想說什麼呢？」也有的說：「他看起來是個宣傳外國鬼神的人。」這是因為保羅傳講耶穌和復活的福音。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬可福音 1:27; 使徒行傳 17:22; 使徒行傳 24:24"> 他們就拉住保羅，帶他到亞略巴古，問他：「你所講論的這新教導，我們可以知道嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 1:23; 何西阿書 8:12; 哥林多前書 2:14"> 既然你帶來了一些奇怪的事，傳到我們耳中，那麼我們想知道這些事到底是什麼意思。」</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:16–17; 歌羅西書 4:5; 以弗所書 5:16"> 原來，所有的雅典人以及在那裡作客的外國人，不做別的，只花時間說說聽聽某個較為新奇的事。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 25:19; 使徒行傳 19:35; 使徒行傳 17:16"> 於是保羅站在亞略巴古當中說：「各位雅典人哪，我看你們在各方面都非常敬畏鬼神，</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 4:22; 加拉太書 4:8–9; 約翰福音 17:3"> 因為我邊走邊觀察你們所敬拜的，發現一座祭壇上刻著『獻給不認識的神』；那麼，我把你們所不認識而敬拜的這一位，現在傳講給你們。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 8:27; 申命記 10:14; 使徒行傳 7:48"> 造了宇宙和其中萬有的神，這一位既然是天地的主，就不住在人手所造的殿宇裡，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 50:8–13; 創世記 2:7; 以賽亞書 42:5"> 也不受人手的服事，好像缺少什麼似的，因為他自己把生命、氣息和萬有賜給萬人。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:7–8; 創世記 3:20; 羅馬書 5:12–19"> 他從一個人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一個人——有古抄本作「一支血脈」。">g</a></sup>造出人類萬族，使他們住在整個地面上，預先設定了他們的年限和所住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 23:23–24; 申命記 4:7; 使徒行傳 14:17"> 好讓他們尋求神<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神——有古抄本作「主」。">h</a></sup>，或許因此真能摸索而找到他。其實他離我們每一個人並不遠，</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 12:10; 歌羅西書 1:17; 希伯來書 1:3"> 因為我們活著、行動、生存，都在於他，正如你們中間的一些詩人也曾經說過，『原來我們也是他的後裔。』</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 40:25; 出埃及記 20:4; 詩篇 115:4–8"> 所以我們既然是神的後裔，就不應該認為神性是彷彿用人的手藝和心思所雕刻的金、銀、石像。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 14:16; 提多書 2:11–12; 路加福音 24:47"> 「雖然神並不鑒察那愚昧無知的時代，但如今卻吩咐各處所有的人都要悔改，</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 25:31–46; 彼得後書 3:7; 羅馬書 2:16"> 因為他已經確立了日子，將要藉著他所設定的一個人，以公義來審判天下的人，並且藉著使他從死人中復活，給萬人帶來了確據。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 17:18; 使徒行傳 26:8; 使徒行傳 25:19"> 他們聽到死人復活的事，雖然有些人嘲笑他，但有些人卻說：「關於此事，我們還要再聽你說！」</span>
<span className="v" id="v33" data-v="33"> 這樣，保羅就從他們中間出去了。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 17:19; 羅馬書 11:5–6; 使徒行傳 13:48"> 有一些人就跟從了保羅，信了主<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主——輔助詞語。">i</a></sup>。其中包括亞略巴古的議員迪奧尼修、一個名叫達瑪麗斯的婦人，以及其他與他們在一起的人。</span>
</div>
</div>

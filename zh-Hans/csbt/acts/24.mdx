<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 24:11; 使徒行傳 23:2; 使徒行傳 25:2"> 過了五天，大祭司阿納尼亞帶著一些長老和一個名叫特圖羅斯的律師下來，向總督指控保羅。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行傳 24:26–27"> 保羅被叫進來，特圖羅斯就開始控告，說：「菲利克斯大人！因著您，我們大享和平；因著您的遠見，本國也進行了許多改革；</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 23:26; 使徒行傳 26:25; 路加福音 1:3"> 我們事事處處滿懷感謝地領受。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:32"> 但為了不過多地煩擾您，我懇求您，以您的仁慈聽我們簡短地說。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 28:22; 使徒行傳 24:14; 使徒行傳 26:5"> 我們發現這個人像瘟疫一樣，煽動普天下猶太人暴亂；他又是拿撒勒人教派的一個頭目。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:12; 使徒行傳 21:27–32; 約翰福音 18:31"> 他甚至試圖玷汙聖殿，我們就把他拘捕了。我們本來想按照我們的律法審判他，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「我們本來想按照我們的律法審判他，」。">a</a></sup></span>
<span className="v" id="v7" data-v="7"> 可是千夫長呂西亞過來，把他從我們手中強行帶走，又吩咐原告到您這裡來。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有此節。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 23:35; 使徒行傳 25:15–16; 使徒行傳 25:5"> 您親自審問他，就能了解我們控告他的這一切事了。」</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 2:16; 彌迦書 7:2–3; 詩篇 4:2"> 猶太人也都附和，聲稱這些事就是如此。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前書 3:15; 撒母耳記上 2:25; 路加福音 18:2"> 總督點頭示意要保羅講話，保羅就說：「我知道您在本國多年做審判官，所以我樂意為自己申辯。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 24:1; 使徒行傳 21:18; 使徒行傳 23:11"> 您可以了解，自從我上耶路撒冷去敬拜，到現在不超過十二天。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 25:8; 使徒行傳 28:17; 使徒行傳 24:18"> 無論在聖殿裡，或在會堂裡，或在城裡，他們都沒有看見我和任何人爭論，或煽動民眾。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 25:7; 彼得前書 3:16"> 他們現在也不能向您證實所控告我的事。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 9:2; 羅馬書 3:21; 使徒行傳 3:13"> 不過這一點我向您承認：我是按照他們稱為『異端<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="異端——或譯作「教派」。">c</a></sup>』的這道<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="道——或譯作「路」。">d</a></sup>，如此事奉我先祖的神，因為我相信一切合乎律法書和先知書上所記載的事；</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 12:2; 約翰福音 5:28–29; 帖撒羅尼迦前書 4:14–16"> 我對神所懷有的盼望也是這些人自己所期望的，就是義人和不義的人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="義人和不義的人——有古抄本作「死人——無論是義人還是不義的人」。">e</a></sup>將來都要復活。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 23:1; 提摩太前書 1:5; 哥林多後書 4:2"> 因此，在神和人面前，我總是盡力存著無愧的良心。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 2:10; 羅馬書 15:25–28; 哥林多前書 16:1–4"> 過了好幾年，我回來了，帶著給我同胞的施捨，以及供物；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:21; 使徒行傳 21:26–30; 使徒行傳 24:12"> 正獻上供物的時候，他們在聖殿裡發現了我，那時我已經行完了潔淨禮，既沒有人群，也沒有騷亂，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 23:30; 使徒行傳 25:16"> 只有一些從亞細亞省來的猶太人——如果對我有什麼控告，應該是他們到您面前來控告。</span>
<span className="v" id="v20" data-v="20"> 還是讓這些人自己說說，我站在議會前的時候，他們到底查出了我有什麼罪行——</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 23:6; 使徒行傳 4:2; 使徒行傳 26:6–8"> 或者，是為了我站在他們中間喊過這樣一句話：『我今天在你們面前受審，是因為死人復活的事！』」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 24:6; 使徒行傳 24:24; 使徒行傳 25:26"> 因為菲利克斯比較詳盡地了解這道，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「聽了這些事後」。">f</a></sup>就推託他們，說：「等千夫長呂西亞下來，我再審斷有關你們的事。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 28:16; 使徒行傳 27:3; 箴言 16:7"> 他吩咐百夫長看守保羅<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="保羅——有古抄本作「他」。">g</a></sup>，要寬待他，不要阻止他自己的人來供應他<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「或到他這裡來」。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 20:21; 加拉太書 2:16; 馬可福音 6:20"> 過了幾天，菲利克斯與他的猶太人妻子杜茜拉一起來了。他把保羅叫來，聽他講說對基督耶穌<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督耶穌——有古抄本作「基督」。">i</a></sup>的信仰。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:8; 彼得前書 3:15; 使徒行傳 10:42"> 當保羅講論關於公義、自制和將來的審判時，菲利克斯感到害怕，就說：「你現在可以回去，我有了時間，就會叫你。」</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 6:9–10; 箴言 17:23; 以賽亞書 56:11"> 同時他也希望保羅送他錢，<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附「這樣他就會釋放他，」。">j</a></sup>所以經常把他叫來，和他交談。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 25:9; 使徒行傳 25:14; 使徒行傳 12:3"> 過了兩年，波奇烏菲斯特斯接替菲利克斯。菲利克斯想要討好猶太人，就把保羅留在監獄裡。</span>
</div>
</div>

</div>

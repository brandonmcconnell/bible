<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 2:17; 路加福音 5:4; 撒母耳記上 20:41–42"> 我們與他們惜別以後就開船直航，來到科斯島。第二天到了羅得島，又從那裡到帕塔拉，</span>
<span className="v" id="v2" data-v="2" data-xref="約拿書 1:3; 使徒行傳 11:19; 使徒行傳 15:3"> 找到了一條開往腓尼基的船，就上船起航。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 21:16; 使徒行傳 4:36; 馬太福音 4:24"> 我們望見塞浦路斯島，駛過的時候它在左邊。我們繼續向敘利亞省航行，在提爾登陸，因為船要在那裡卸貨。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 20:22–23; 使徒行傳 21:10–12; 使徒行傳 20:6–7"> 我們找到了一些門徒，就在那裡住了七天。他們藉著聖靈，一直告訴保羅不要上耶路撒冷去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 20:36; 使徒行傳 9:40; 詩篇 95:6"> 那些日子過了以後，我們出發前行，大家與妻子和兒女一起送我們到城外。我們都跪在岸上禱告，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:27; 約翰福音 1:11; 哥林多後書 2:13"> 彼此告別。我們上了船，他們就回自己的家去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯來書 13:24; 撒母耳記上 10:4; 使徒行傳 28:12"> 我們結束了從提爾開始的航程，到達托勒密，就去問候弟兄們，在他們那裡住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 6:5; 使徒行傳 8:26–40; 以弗所書 4:11"> 第二天我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我們——有古抄本作「跟隨保羅的人」。">a</a></sup>離開那裡，來到凱撒里亞，進了傳福音者腓利的家，住在他那裡，他是那七位執事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="執事——輔助詞語。">b</a></sup>中的一位。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 2:17; 啟示錄 2:20; 約珥書 2:28"> 他有四個女兒，都是童貞女，是做先知傳道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知傳道——原文直譯「說預言」。">c</a></sup>的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 11:28; 使徒行傳 21:4; 使徒行傳 20:16"> 我們住了好幾天，有一個名叫阿伽布斯的先知從猶太下來了。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:33; 耶利米書 13:1–11; 撒母耳記上 15:27–28"> 他來到我們這裡，拿起保羅的腰帶，把自己的手腳捆起來，說：「聖靈這樣說，猶太人在耶路撒冷要如此捆綁這腰帶的主人，把他交在外邦人的手中。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 16:21–23; 使徒行傳 20:22; 使徒行傳 21:4"> 我們一聽這些話，就和當地的人懇求保羅不要上耶路撒冷去。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 20:24; 腓立比書 2:17; 腓立比書 1:20–21"> 這時候保羅說：「你們為什麼哭，使我心碎呢？我為了主耶穌的名，不僅被捆綁，即使死在耶路撒冷，也都預備好了。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 馬太福音 26:42; 馬太福音 26:39"> 我們既然不能說服保羅，就都安靜下來，只說：「願主的旨意成就。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 25:1; 使徒行傳 25:6; 使徒行傳 25:9"> 過了幾天，我們收拾行李，上耶路撒冷去。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行傳 21:8; 詩篇 92:14"> 凱撒里亞的一些門徒也陪我們一起去，帶我們到一個塞浦路斯人納森家裡去作客住宿。他做門徒已經很久了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 15:4; 羅馬書 15:7; 希伯來書 13:1–2"> 我們到了耶路撒冷，弟兄們很高興地歡迎我們。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 1:19; 加拉太書 2:9; 使徒行傳 15:13"> 第二天，保羅與我們一起去探望雅各，所有的長老也都來了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 14:27; 使徒行傳 1:17; 羅馬書 15:18–19"> 保羅問候他們後，一一述說神藉著他的服事，在外邦人中所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 10:2; 加拉太書 1:14; 使徒行傳 22:3"> 他們聽了就不住地榮耀神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——有古抄本作「主」。">d</a></sup>，又對保羅說：「弟兄，你看猶太人中信主<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="主——輔助詞語。">e</a></sup>的人有多少萬，而且他們都是對律法熱心的人。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 6:12–15; 哥林多前書 9:19–21; 加拉太書 5:1–6"> 他們聽到有關你的事，說你教導所有在外邦人中的猶太人離道反教、背棄摩西，叫他們不要給孩子行割禮，也不要按規矩行事。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 15:12; 使徒行傳 15:22; 使徒行傳 19:32"> 他們一定會聽到你來這裡了<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他們一定會聽到你來這裡了——有古抄本作「他們聽到你來了，民眾必定會聚集」。">f</a></sup>。那麼該怎麼辦呢？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 18:18; 民數記 6:2–7"> 你就照我們告訴你的去做吧。我們這裡有四個人，他們都許過願。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 21:26; 使徒行傳 24:18; 使徒行傳 18:18"> 你帶他們去，與他們一起行潔淨禮，並且替他們付錢，好讓他們剃掉頭髮。這樣，大家就會知道有關你的傳聞不是真的，而且你自己也是照著規矩行事、遵守律法的。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 15:29; 使徒行傳 15:19–20"> 至於已經相信的外邦人，我們照著決定寫了信，要他們遠避祭過偶像的食物，遠避血和勒死的動物，遠避淫亂。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「除了這些以外，不要遵守任何這樣的事」。">g</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 24:18; 使徒行傳 21:24; 民數記 6:13–20"> 於是，第二天保羅帶了那四個人，與他們一起行了潔淨禮，進了聖殿，宣告潔淨期滿的日子，直到為他們每一個人的供物都被獻上為止。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 26:21; 使徒行傳 24:18; 使徒行傳 13:50"> 那七天快要結束的時候，從亞細亞省來的一些猶太人看到保羅在聖殿裡，就煽動整個人群，下手捉拿他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 24:5–6; 使徒行傳 21:21; 使徒行傳 26:20–21"> 喊叫：「各位以色列人哪，請幫忙！這個人就是那到處教導大家反對我們的民族、律法，反對這地方的！他甚至把希臘人帶進聖殿，玷汙了這聖地。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 20:4; 提摩太後書 4:20; 使徒行傳 18:19"> 原來他們曾經看見以弗所人特羅費摩與保羅一起在城裡，就以為保羅帶他進了聖殿。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 26:21; 哥林多後書 11:26; 使徒行傳 16:19–22"> 於是全城的人都被煽動了，民眾一起跑來，抓住保羅，把他拖出聖殿，殿門立刻關上了。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 11:23–33; 使徒行傳 17:5; 使徒行傳 26:9–10"> 在他們想殺保羅的時候，有消息上報到軍團的千夫長，說全耶路撒冷都混亂了。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 23:27; 以賽亞書 3:15; 使徒行傳 5:40"> 千夫長立即帶著士兵和幾個百夫長跑下去，到了他們那裡。他們一看見千夫長和士兵們，就停止毆打保羅。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所書 6:20; 使徒行傳 21:11; 使徒行傳 20:23"> 於是千夫長上前抓住保羅，下令用兩條鐵鏈把他捆起來，然後查問他到底是什麼人，做了什麼事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 19:32; 使徒行傳 23:10; 使徒行傳 22:24"> 人群當中，有的喊這個，有的喊那個；千夫長因為騷亂，無法知道真相，就下令把保羅帶到營樓裡去。</span>
<span className="v" id="v35" data-v="35" data-xref="哈巴谷書 1:2–3; 詩篇 55:9; 詩篇 58:2"> 保羅到了臺階上的時候，由於人群凶猛，士兵們只好把他抬起來走。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 19:15; 使徒行傳 22:22; 路加福音 23:18"> 那一群人跟在後面，喊叫：「除掉他！」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 21:34; 路加福音 21:15; 使徒行傳 19:30"> 保羅快要被押進營樓的時候，就對千夫長說：「我是否可以對你說句話？」<br />千夫長說：「你懂希臘語嗎？</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 24:26; 使徒行傳 5:36–37; 馬太福音 5:11"> 你究竟是不是那個前些日子作亂、帶領四千個凶徒進入曠野的埃及人呢？」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 22:3; 使徒行傳 9:11; 使徒行傳 23:27"> 保羅回答說：「我是猶太人，是奇里乞亞省的塔爾蘇人，並不是無名之城的公民，請求你准許我向民眾說話。」</span>
</div>

<span className="v" id="v40" data-v="40" data-xref="使徒行傳 12:17; 使徒行傳 22:2; 約翰福音 5:2"> 千夫長准許了，保羅就站在臺階上，向民眾揮一下手，大家都寂靜無聲，保羅就用希伯來語呼籲，說：</span>

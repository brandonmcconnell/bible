<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 8:3; 提摩太前書 1:13; 加拉太書 1:13"> 掃羅仍然向主的門徒們口吐凶殺威嚇的話。他來到大祭司面前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 19:9; 使徒行傳 19:23; 使徒行傳 24:14"> 求他發一些信函給大馬士革各會堂，准許掃羅如果發現什麼人屬於這道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="道——或譯作「路」。">a</a></sup>，無論男女，都捆綁起來，帶到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:12–13; 哥林多前書 15:8; 使徒行傳 22:6"> 當掃羅趕路，快到大馬士革的時候，忽然有光從天上下來，四面照射他。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 2:8; 創世記 22:11; 羅馬書 11:22"> 他仆倒在地上，聽見有聲音對他說：<span className="woj">「掃羅，掃羅！你為什麼逼迫我？」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 1:13; 撒母耳記上 3:4–10; 約伯記 9:4"> 他問：「主啊，你到底是誰？」<br />主說：<span className="woj">「我就是你所逼迫的耶穌。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「你腳踢刺棒，是狂妄的。」">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 22:10; 使徒行傳 26:16; 提摩太前書 1:14–16"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「他又驚恐，又戰抖，說：『主啊！你要我做什麼呢？』主對他說：『……』」">c</a></sup><span className="woj">你起來，進城去！有人會告訴你應該做什麼。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 22:9; 但以理書 10:7; 使徒行傳 26:13–14"> 與掃羅同行的人都站著，啞口無言，他們雖然聽見聲音，卻看不見任何人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 22:11; 使徒行傳 9:18; 列王紀下 6:17–20"> 掃羅從地上爬起來，睜開眼睛，卻什麼也看不見。他們牽著他的手，把他帶進大馬士革。</span>
<span className="v" id="v9" data-v="9" data-xref="約拿書 3:6–8; 以斯帖記 4:16; 歷代志下 33:12–13"> 他三天不能看見，不吃也不喝。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 22:1; 使徒行傳 10:3; 使徒行傳 22:12"> 在大馬士革有一個名叫阿納尼亞的門徒。主在異象中對他說：<span className="woj">「阿納尼亞！」</span><br />他回答說：「主啊！看哪，我在這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:39; 使徒行傳 22:3; 使徒行傳 9:30"> 主就對他說：<span className="woj">「起來，往那叫做『直』的街上去，在猶大家裡找一個名叫掃羅的塔爾蘇人。看哪，原來他正在禱告。</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 5:23; 使徒行傳 9:10; 使徒行傳 9:17–18"> <span className="woj">他在異象中</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本沒有「在異象中」。">d</a></sup><span className="woj">看見了一個名叫阿納尼亞的人，進來按手在他身上，使他重見光明。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 1:13–15; 使徒行傳 8:3; 使徒行傳 22:19–20"> 阿納尼亞卻回答：「主啊，我聽許多人說過有關這個人在耶路撒冷對你的聖徒們所做的種種惡事。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 9:21; 使徒行傳 7:59; 提摩太後書 2:22"> 並且，他得到祭司長們的授權來到這裡，要捆綁所有求告你名的人。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="加拉太書 1:15–16; 以弗所書 3:7–8; 提摩太後書 4:16–17"> 但是主對他說：<span className="woj">「你去吧！因為這個人是我所揀選的器皿，不但要在外邦人和君王面前，還要在以色列子民面前宣揚</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="宣揚——原文直譯「擔當」。">e</a></sup><span className="woj">我的名。</span></span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 3:3; 使徒行傳 21:11; 哥林多後書 6:4"> <span className="woj">我要指示他，為了我的名他必須受多大的苦害。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 8:17; 使徒行傳 6:6; 使徒行傳 2:4"> 阿納尼亞就去了。他進了那家，按手在掃羅身上，說：「掃羅弟兄，在你來的路上向你顯現的主耶穌差派我來，使你重見光明，並且被聖靈充滿。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 3:14; 使徒行傳 22:16; 使徒行傳 2:38"> 立刻有像鱗片一樣的東西從掃羅的眼睛上掉了下來，他就重見光明了。於是他起來受了洗；</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 26:20; 撒母耳記上 30:12; 加拉太書 1:17"> 吃過飯，體力就恢復了。 掃羅傳講基督<br />掃羅與在大馬士革的門徒們住了幾天，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 20:28; 加拉太書 2:20; 約翰一書 4:14–15"> 就立刻在各會堂裡傳講耶穌<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="耶穌——有古抄本作「基督」。">f</a></sup>，說這一位就是神的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:13–14; 使徒行傳 8:3; 帖撒羅尼迦後書 1:10"> 所有聽見的人都十分驚訝，說：「這不就是那個在耶路撒冷殘害了那些求告這名的人嗎？而且他來到這裡，不就是為要捆綁他們，帶到祭司長們那裡嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 18:5; 以賽亞書 40:29; 路加福音 21:15"> 掃羅反而更加得以剛強，證明這一位就是基督，使住在大馬士革的猶太人很狼狽。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 1:17–18; 帖撒羅尼迦前書 2:15–16; 使徒行傳 14:19"> 過了許多日子以後，猶太人商議要殺了掃羅，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 11:32; 使徒行傳 25:3; 使徒行傳 20:3"> 但他們的陰謀卻被掃羅知道了。於是他們就日夜嚴守著各城門，要殺掉他。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 2:15; 哥林多後書 11:33; 撒母耳記上 19:11–12"> 然而他的門徒們趁夜把他帶去，用筐子把他從城牆上縋了下去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:20; 加拉太書 1:17–19; 使徒行傳 9:19"> 掃羅來到耶路撒冷，想要和門徒們交往，可是大家都怕他，不相信他成了門徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 4:36; 使徒行傳 4:29; 使徒行傳 4:13"> 但是巴拿巴接納他，把他帶到使徒們那裡，並且告訴他們掃羅怎樣在路上見到主，主怎樣對他說了話，以及他怎樣在大馬士革奉耶穌的名放膽傳道。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 1:21; 民數記 27:16–17; 詩篇 121:8"> 於是掃羅在耶路撒冷與他們一起出入，奉主<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="主——有古抄本作「主耶穌」。">g</a></sup>的名放膽傳道。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 6:1; 猶大書 1:9; 使徒行傳 11:20"> 他對那些說希臘語的猶太人講道，與他們辯論；他們卻圖謀要殺了他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 11:25; 使徒行傳 8:40; 使徒行傳 9:11"> 弟兄們知道了這事，就帶他下到凱撒里亞，然後送他往塔爾蘇去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 111:10; 約翰福音 14:16–18; 以賽亞書 33:6"> 這樣，教會在猶太、加利利、撒瑪利亞全地得平安、得造就，並且懷著對主的敬畏之心不斷地前行，在聖靈的安慰<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="安慰——或譯作「鼓勵」。">h</a></sup>中不斷地增長。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 9:13; 使徒行傳 8:25; 箴言 2:8"> 有一次，彼得走遍各地的時候，也下到住在利達的聖徒們那裡。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 約翰福音 5:5; 馬可福音 2:3–11"> 在那裡，他遇見了一個名叫艾尼亞的人。他是個癱瘓的人，躺在墊子上八年了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 9:6; 使徒行傳 3:12; 使徒行傳 3:6"> 彼得對他說：「艾尼亞，耶穌基督使你痊癒。站起來，為你自己整理墊子吧！」艾尼亞立刻就站起來了。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 11:21; 使徒行傳 9:42; 歷代志上 5:16"> 於是所有住在利達和沙崙的人看到他，就歸向了主。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多書 3:8; 提多書 2:7; 歷代志下 2:16"> 在約帕有一個女門徒，名叫塔比莎——「塔比莎」翻譯出來意思是「羚羊<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="羚羊——音譯為「多卡絲」。">i</a></sup>」。她盡做美善工作，常行施捨。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 1:13; 使徒行傳 20:8; 約翰福音 11:36–37"> 就在那些日子裡，她患病死了。人們清洗了遺體，就放在樓上的房間。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 9:36; 使徒行傳 11:26; 使徒行傳 9:32"> 利達離約帕不遠，門徒們聽說彼得在利達，就派了兩個人到他那裡，懇求他說：「請你來到我們這裡，不要耽延！」</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒羅尼迦前書 1:3"> 彼得就起身陪他們一起去。到了以後，他們把他領到樓上的房間。所有的寡婦都站在彼得旁邊哭，把多卡絲與她們在一起的時候所縫製的衣服和袍子拿給他看。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 9:25; 馬可福音 5:40–42; 路加福音 8:54"> 彼得叫大家都出去，然後跪下禱告，接著轉過身對著遺體，說：「塔比莎，你起來！」那婦人就睜開眼睛，看見彼得，而且坐了起來。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:31; 使徒行傳 6:1; 創世記 45:26"> 彼得伸手扶她站起來，又叫聖徒們和寡婦們進來，把活過來的多卡絲交給他們。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:44; 約翰福音 12:11; 約翰福音 11:45"> 這事傳遍了整個約帕，許多人就信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 10:6; 使徒行傳 10:32"> 後來，彼得在約帕的一個硝皮匠西門家裡住了許多日子。</span>
</div>
</div>

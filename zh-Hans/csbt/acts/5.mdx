<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="5" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 10:1–3; 提摩太後書 2:20; 馬太福音 13:47–48"> 有一個名叫阿納尼亞的人，和他的妻子薩菲拉賣掉了財產。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:37; 彼得後書 2:14–15; 馬太福音 23:5"> 但他從價款中私自留下了一部分，把一部分拿來放在使徒們的腳前；他的妻子也知道這事。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 23:24; 以賽亞書 29:15; 約翰福音 13:2"> 彼得就說：「阿納尼亞，為什麼撒旦充滿了你的心，使你對聖靈說謊，從田產的價款中私自留下一些呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:3; 約書亞記 7:25–26; 列王紀下 5:25–27"> 田產留著沒賣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="沒賣——輔助詞語。">a</a></sup>的時候，難道不屬於你的嗎？賣了以後，價款難道不也是由你做主嗎？你心裡為什麼存有這種念頭呢？你不是對人說謊，而是對神說謊了。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 5:10–11; 使徒行傳 2:43; 使徒行傳 5:13"> 阿納尼亞聽見這話，就仆倒斷了氣；所有聽到這事的人都大為恐懼。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:40; 撒母耳記下 18:17; 申命記 21:23"> 有幾個年輕人站起來，把他的屍體<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的屍體——輔助詞語。">b</a></sup>裹好，抬出去埋葬了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 隔了大約三個小時，阿納尼亞的妻子進來，還不知道所發生的事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 5:2"> 彼得問她：「告訴我，你們賣田產的錢，是不是這麼多？」<br />她說：「是的，就這麼多。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 10:9; 使徒行傳 5:3–4; 詩篇 95:8–11"> 彼得就對她說：「你們為什麼同心試探主的靈呢？看，埋葬你丈夫之人的腳，已經到門口了，他們也要把你抬出去。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:5"> 她立刻仆倒在彼得腳前，斷了氣。那些年輕人進來，看見她死了，也把她抬了出去，埋葬在她丈夫的旁邊。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:5; 哥林多前書 10:11–12; 使徒行傳 19:17"> 全教會和所有聽到這些事的人都大為恐懼。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:11; 哥林多後書 12:12; 希伯來書 2:4"> 主藉著使徒們的手，在民間行了很多神蹟和奇事。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主藉著使徒們的手，在民間行了很多神蹟和奇事。——原文直譯「有許多神蹟和奇事，藉著使徒們的手，發生在人民中間。」">c</a></sup>信徒們<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="信徒們——原文直譯「他們」。">d</a></sup>都同心合意地聚集<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="聚集——輔助詞語。">e</a></sup>在所羅門柱廊裡。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 2:47; 使徒行傳 4:21; 約翰福音 12:42"> 雖然其他的人沒有一個敢與他們交往<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="與他們交往——或譯作「加入他們」。">f</a></sup>，但民眾都尊敬他們。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 2:47; 使徒行傳 4:4; 以賽亞書 55:11–13"> 信主的人越發增加，連男帶女成群結隊。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 14:36; 使徒行傳 19:11–12; 約翰福音 14:12"> 人們甚至把病人抬到大街<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大街——或譯作「廣場」。">g</a></sup>上來，放在床榻上或墊子上，為要在彼得走過來的時候，至少他的影子可以落在一些人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 16:17–18; 馬可福音 2:3–4; 馬太福音 15:30–31"> 還有一群人帶著病人和被汙靈折磨的人，從耶路撒冷周圍的城鎮聚集而來，這些人都得了痊癒。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 13:45; 使徒行傳 7:9; 使徒行傳 17:5"> 於是大祭司就採取行動。他和所有與他在一起的人，就是撒都該教派的人，都滿腔嫉妒，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 4:3; 路加福音 21:12; 哥林多後書 11:23"> 下手捉拿使徒們，把他們關在公眾拘留所裡。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 16:26; 詩篇 34:7; 使徒行傳 12:7–11"> 但在夜裡，主的一位天使打開了監門，領他們出來，說：</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 6:63; 約翰福音 6:68; 約翰一書 5:11–12"> 「你們去站在聖殿裡，把這生命的話語，都講給民眾聽。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 8:2; 使徒行傳 22:15; 使徒行傳 12:18–19"> 他們聽從這話，在清晨的時候就進入聖殿教導人。 使徒們再次受審<br />這時，大祭司和與他在一起的人來了，他們召集了議會，就是以色列子民長老的全體議會，然後派人到監獄裡，要把使徒們帶來。</span>
<span className="v" id="v22" data-v="22"> 但差役們到了監獄裡，卻找不到他們，就回去報告，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 2:4; 詩篇 33:10; 但以理書 6:22–24"> 說：「我們看見監獄被關得極其穩妥，衛兵都站在各個門口，可是打開那些門，裡面卻找不到任何人。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 4:1; 使徒行傳 5:26; 約翰福音 12:19"> 當<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「祭司、」。">h</a></sup>聖殿的守衛長<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="守衛長——原文直譯「指揮官」或「司令官」或「將軍」。">i</a></sup>和祭司長們聽到這些話的時候，就對使徒們的事感到困惑，不知道這事會如何發展。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 這時，有人來向他們報告說：「看，你們關在監獄裡的那些人，正站在聖殿裡教導民眾呢！」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:13; 使徒行傳 4:21; 馬太福音 26:5"> 於是守衛長與差役們一起去把使徒們帶來，並沒有用暴力，因為怕民眾用石頭砸他們。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 5:22; 使徒行傳 4:7; 路加福音 22:66"> 他們把使徒們帶來後，叫他們站在議會當中。大祭司質問他們，</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 27:25; 使徒行傳 7:52; 使徒行傳 4:10–11"> 說：「我們不是嚴厲地吩咐你們，不可奉這個人的名教導人嗎？可是看哪，你們把你們的教導傳遍了耶路撒冷，又想把這個人的血歸到我們身上。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:19; 撒母耳記上 15:24; 馬可福音 7:7–9"> 彼得和使徒們回答說：「我們必須順從神過於順從人。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太書 3:13; 彼得前書 2:24; 使徒行傳 10:39"> 你們掛在木頭上殺害的耶穌，我們祖先的神已經使他復活了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行傳 2:33; 希伯來書 2:10"> 神把這一位高舉在自己右邊做元首、做救主，為了將悔改的心賜給以色列，使罪得赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 15:26–27; 希伯來書 2:3–4; 使徒行傳 1:8"> 我們就是這些事的見證人。神所賜給那些順從他之人的聖靈也一同做見證。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 7:54; 使徒行傳 2:37; 路加福音 4:28–29"> 議會的人聽了，勃然大怒<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="勃然大怒——或譯作「心如被刀割」。">j</a></sup>，就想要殺了他們。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 22:3; 路加福音 2:46; 路加福音 5:17"> 但有一個名叫迦瑪列的法利賽人，是全體民眾所尊敬的律法教師，在議會中站了起來，下令把使徒們<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="使徒們——有古抄本作「這些人」。">k</a></sup>暫時帶到外面去，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 22:26; 耶利米書 26:19; 馬太福音 27:19"> 就對大家說：「各位以色列人哪，如何處置這些人，你們應當謹慎。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 8:9; 彼得後書 2:2; 加拉太書 6:3"> 因為這些日子之前，提烏達起來說自己是某某人物，跟從他的人數約有四百。這人被殺了以後，所有信從他的人都四散了，歸於無有。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 詩篇 7:14–15; 馬太福音 26:52"> 這人以後，在戶口登記期間又有個加利利人猶大起來，拉攏民眾<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="民眾——有古抄本作「許多民眾」。">l</a></sup>跟隨他。他也死了，所有信從他的人也都四散了。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:13; 耶利米哀歌 3:37; 以賽亞書 8:9–10"> 現在我告訴你們：不要管這些人，由他們去吧！因為這計劃或這行為，如果是出於人，就會被拆毀；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以賽亞書 46:10; 馬太福音 16:18"> 但如果是出於神，你們就不能拆毀他們，恐怕你們反而被看做是與神作對了。」於是議會的人被迦瑪列說服了，</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 10:17; 使徒行傳 5:28; 使徒行傳 4:17–21"> 就叫來使徒們，鞭打了以後，吩咐他們不可再奉耶穌的名講說，然後把他們釋放了。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各書 1:2; 彼得前書 4:13–16; 路加福音 6:22"> 這樣使徒們就快快樂樂地離開了議會，因為算是配得上為這名受凌辱。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行傳 2:46; 使徒行傳 20:20; 路加福音 21:37"> 他們每天在聖殿和各家各戶不住地教導人，傳福音說耶穌是基督。</span>
</div>
</div>

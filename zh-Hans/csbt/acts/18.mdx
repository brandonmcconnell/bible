<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 1:2; 提摩太後書 4:20; 哥林多後書 1:1"> 這些事以後，保羅離開雅典，來到哥林多。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 16:3–4; 哥林多前書 16:19; 提摩太後書 4:19"> 他遇見一個出生在本都省的猶太人，名叫阿奎拉，最近與他的妻子普茜拉從意大利來，因為克勞迪命令所有的猶太人都要離開羅馬。保羅來到他們那裡，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 4:12; 帖撒羅尼迦前書 2:9; 哥林多後書 11:9"> 因為與他們同業，就住在他們那裡做工。原來他們是以製帳篷為業的。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 5:11; 使徒行傳 17:17; 使徒行傳 28:23"> 每逢安息日，保羅就在會堂裡講論，勸導猶太人和希臘人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:14; 使徒行傳 18:28; 使徒行傳 20:21"> 西拉斯和提摩太從馬其頓省下來的時候，保羅被這福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直譯「話語」或「道」。">a</a></sup><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這福音——有古抄本作「聖靈」。">b</a></sup>所催逼，向猶太人鄭重地見證耶穌是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 33:4; 撒母耳記下 1:16; 以西結書 33:8–9"> 當他們抗拒、說褻瀆話的時候，保羅就抖著衣服對他們說：「你們的血，歸在你們自己的頭上；我是清白的。從今以後，我要到外邦人那裡去。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 16:14; 歌羅西書 4:11; 使徒行傳 10:2"> 於是他離開那裡，進到一個名叫提多猶斯托的人家裡。這個人敬拜神，他的家就在會堂隔壁。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 1:13–17; 羅馬書 10:14–17; 馬可福音 16:15–16"> 會堂主管克里斯普和他全家都信了主，還有許多哥林多人聽了以後就信了，並且受了洗。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 23:11; 以弗所書 6:19–20; 使徒行傳 27:23–25"> 在夜裡，主藉著異象對保羅說：<span className="woj">「不要怕，只管講！不要沉默不語，</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 12:9; 出埃及記 4:12; 以賽亞書 41:10"> <span className="woj">因為我與你同在，而且沒有人會下手傷害你；原來在這城裡有許多我的子民。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 14:3; 使徒行傳 19:10; 使徒行傳 20:31"> 保羅在那裡住了一年零六個月，在他們當中教導神的話語<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神的話語——或譯作「神的道」。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 13:50; 使徒行傳 18:27; 使徒行傳 13:7"> 伽利奧任亞該亞省長的時候，猶太人一致起來攻擊保羅，把他帶到審判臺前，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 25:8; 使徒行傳 24:5–6; 使徒行傳 6:13"> 說：「他煽動人不按律法敬拜神。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:14–15; 使徒行傳 25:11; 馬可福音 9:19"> 保羅剛要開口，伽利奧就對猶太人說：「哦，各位猶太人哪！如果這真是什麼罪行或邪惡的案情，我理當容忍你們。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 23:29; 使徒行傳 25:19; 提摩太前書 6:4"> 但爭議的問題，如果是關於字句、名稱，和有關你們的律法，你們自己看著辦吧！我不願意做這些事的審判者。」</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 12:16; 詩篇 76:10; 羅馬書 13:3–4"> 於是把他們從審判臺前趕了出去。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 1:1; 阿摩司書 6:6; 使徒行傳 17:32"> 大家<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="大家——有古抄本作「希臘人」。">d</a></sup>都抓住會堂主管索提尼，在審判臺前毆打他。但伽利奧一概不管這些事。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:24; 民數記 6:18; 民數記 6:5–9"> 保羅在哥林多<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在哥林多——輔助詞語。">e</a></sup>繼續留了許多日子，然後向弟兄們告別，坐船往敘利亞省去；普茜拉和阿奎拉也與他同去。他因為許過願，就在堅革里港剃了頭髮。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 1:1; 提摩太前書 1:3; 提摩太後書 1:18"> 他們到達以弗所城，保羅把他們兩個人留在那裡，自己就進了會堂向猶太人講論。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:37–38; 哥林多前書 16:12; 使徒行傳 20:16"> 他們請求保羅再多住些時候，他沒有答應，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 4:19; 雅各書 4:15; 羅馬書 15:32"> 向他們告別，說：「<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「我必須盡量在耶路撒冷守那即將來臨的節日。」">f</a></sup>如果神願意，我會再回到你們這裡來。」就從以弗所起航了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 8:40; 使徒行傳 15:4; 使徒行傳 23:23"> 保羅在凱撒里亞登陸，上耶路撒冷<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶路撒冷——輔助詞語。">g</a></sup>去問候教會，然後下安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 14:22; 使徒行傳 16:6; 使徒行傳 15:41"> 住了一段時間，他又離開那裡，按著次序走遍加拉太和弗里吉亞地區，堅固所有的門徒。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 4:6; 提多書 3:13; 哥林多前書 3:5–6"> 有一個出生在亞歷山大的猶太人，名叫阿波羅，到達了以弗所。他是個有學問的人，在經文方面很強。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 19:3; 羅馬書 12:11; 何西阿書 14:9"> 這個人已經在主的道<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="道——或譯作「路」。">h</a></sup>上受了教導，靈裡火熱，並仔細地講論和教導有關耶穌<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="耶穌——有古抄本作「主」。">i</a></sup>的事，可是他只知道約翰的洗禮。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 18:25; 使徒行傳 14:3; 哥林多前書 12:21"> 阿波羅開始在會堂裡放膽傳道。普茜拉和阿奎拉聽了，就接他來，把神的道更詳盡地講解給他聽。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦後書 2:13–14; 雅各書 1:16–18; 彼得前書 1:2–3"> 後來阿波羅想到亞該亞省去，弟兄們就鼓勵他，寫信請門徒們歡迎他。他到了以後，對那些蒙恩的信徒大有幫助，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 18:5; 哥林多前書 15:3–4; 使徒行傳 9:22"> 因為他當眾強有力地駁倒猶太人，用經文證明耶穌是基督。</span>
</div>
</div>

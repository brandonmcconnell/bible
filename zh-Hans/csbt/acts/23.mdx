<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="23" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 24:16; 提摩太後書 1:3; 哥林多後書 1:12"> 保羅注視著議會的人，說：「各位兄弟，直到今天，我在神面前，行事為人一向都憑著無愧的良心。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 18:22; 使徒行傳 24:1; 彌迦書 5:1"> 大祭司阿納尼亞就命令站在保羅旁邊的人，打他的嘴巴。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 25:1–2; 約翰福音 7:51; 馬太福音 23:27–28"> 保羅就對他說：「你這粉飾的牆啊，神將要打你！你坐在那裡應按照律法審判我，而你卻違背律法，下令打我嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 站在旁邊的人說：「你竟敢辱罵神的大祭司？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:28; 傳道書 10:20; 猶大書 1:8–9"> 保羅就說：「同胞們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同胞們——原文直譯「兄弟們」。">a</a></sup>，我不知道他是大祭司。的確，經上記著：不可說你民中掌權者的壞話。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:15; 使徒行傳 24:21; 使徒行傳 26:5–8"> 保羅知道有一部分人是撒都該人，另一部分是法利賽人，就在議會中喊著：「各位兄弟，我是法利賽人，也是法利賽人的兒子。我現在受審，是與死人復活的盼望有關。」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 55:9; 約翰福音 7:40–43; 馬太福音 10:34"> 他說了這話，法利賽人和撒都該人就起了爭執，會眾也分裂了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 馬太福音 22:23; 馬可福音 12:18"> 原來撒都該人說沒有復活，沒有天使，也沒有靈，但法利賽人卻承認這一切<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這一切——或譯作「這兩樣」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 22:7; 使徒行傳 22:17–18; 約翰福音 12:29"> 於是他們大大地喧嚷起來。有些法利賽派的經文士們站起來激烈地爭辯，說：「我們查不出這個人有什麼錯<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="錯——原文直譯「惡」。">c</a></sup>。也許有靈或天使對他說過話呢！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「我們不要對抗神。」">d</a></sup>」</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 1:19; 雅各書 3:14–2; 使徒行傳 22:24"> 爭執越來越激烈，千夫長擔心保羅會被他們撕碎，就命令軍隊下去，把保羅從他們當中搶出來，帶回營樓裡。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 18:9; 使徒行傳 19:21; 提摩太後書 4:17"> 當夜，主站在保羅旁邊，說：<span className="woj">「</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「保羅，」。">e</a></sup><span className="woj">你要鼓起勇氣！你怎樣在耶路撒冷鄭重地見證有關我的事，也必須照樣在羅馬做見證。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 23:30; 以賽亞書 8:9–10; 使徒行傳 23:21"> 天亮了，猶太人就策劃了一起陰謀，並且賭咒起誓說，殺掉保羅以前，就不吃不喝。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 16:2; 撒母耳記下 15:31; 撒母耳記下 15:12"> 策劃這同謀起誓的有四十多人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 23:12; 耶利米書 8:12; 以賽亞書 3:9"> 他們來到祭司長們和長老們那裡，說：「我們已經賭咒起誓，殺掉保羅以前，就什麼都不吃。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 59:7; 詩篇 37:32–33; 箴言 1:16"> 所以你們和議會現在就要告訴千夫長，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「明天」。">f</a></sup>把保羅帶到你們這裡來，假裝要更詳盡地審查他的事；我們預備好了，要在他到達以前就殺了他。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 23:10; 哥林多前書 3:19; 使徒行傳 23:32"> 保羅的外甥聽見了這埋伏的事，就過來進了營樓告訴保羅。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 馬太福音 8:8–9; 馬太福音 10:16"> 保羅請來了一個百夫長，說：「請帶這年輕人到千夫長那裡，因為他有事要向他報告。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所書 3:1; 以弗所書 4:1; 使徒行傳 28:17"> 於是百夫長就帶保羅的外甥到千夫長那裡去，說：「囚犯保羅請了我去，求我把這個年輕人帶到你這裡來，他有事要告訴你。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 31:32; 以斯帖記 9:12; 以斯帖記 7:2"> 千夫長拉著年輕人的手，退到一邊，悄悄地問他：「你有什麼事要告訴我？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 23:14–15; 使徒行傳 23:1; 詩篇 12:2"> 他說：「猶太人已經說好，要請求你明天把保羅帶到議會去，假裝要更詳盡地查問他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 23:12–14; 使徒行傳 14:5–6; 哥林多後書 11:26"> 所以請你不要被他們說服，因為他們中的四十多人正埋伏等著他。他們已經賭咒起誓說，殺掉保羅以前，就不吃不喝。現在他們預備好了，正期望你答應。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 1:44; 約書亞記 2:14"> 千夫長吩咐那年輕人說：「不要對任何人說，你把這些事告訴了我。」於是，就讓他走了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 14:25; 使徒行傳 23:33; 路加福音 12:38"> 然後千夫長叫來兩個百夫長，說：「預備兩百名步兵、七十名騎兵、兩百名長槍手，晚上九點<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="九點——原文為「第三時刻」。">g</a></sup>出發往凱撒里亞去。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 25:14; 使徒行傳 23:26; 使徒行傳 24:10"> 也要預備牲口，讓保羅騎上，護送到總督菲利克斯那裡去。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他寫了一封信函，有這樣的內容：</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:23; 使徒行傳 26:25; 路加福音 1:3"> 「克勞迪呂西亞問候總督菲利克斯大人。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 22:25–29; 使徒行傳 21:31–33; 使徒行傳 24:6"> 這個人被猶太人抓住，正要被他們殺害的時候，我帶軍隊到場，得知他是羅馬公民，就把他救了出來。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 22:30"> 我想了解猶太人控告他的理由，就帶他到他們的議會去。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 26:31; 使徒行傳 25:25; 使徒行傳 18:15"> 我發現他被控告，與他們律法上的爭議問題有關，並沒有任何該死或該被捆鎖的罪行。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 23:35; 使徒行傳 25:16; 使徒行傳 25:5–6"> 後來我被告知<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「藉著猶太人」。">h</a></sup>將有一個針對這個人的陰謀，就立即把他解送到您那裡去，又吩咐原告們到您面前去告他。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「祝您安康！」">i</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太後書 2:3–4; 路加福音 7:8; 使徒行傳 23:23–24"> 於是士兵們按照命令，把保羅接走，連夜送到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 23:23; 使徒行傳 23:10"> 第二天，他們讓騎兵帶著保羅前行，就回到營樓。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 23:26; 使徒行傳 23:23–24; 使徒行傳 28:16"> 騎兵進了凱撒里亞，把信函呈給總督，又把保羅帶到他面前。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 21:39; 使徒行傳 25:1; 但以理書 2:49"> 總督<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「總督」。">j</a></sup>讀了信，問保羅是哪一個省的人，知道他是奇里乞亞省的人，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 23:30; 使徒行傳 25:16; 馬太福音 27:27"> 就說：「等你的原告們也到了，我會詳細地聽你的事。」他下令把保羅看守在希律的王府裡。</span>
</div>
</div>

</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:12; 約翰一書 4:12; 約翰一書 4:7–8"> 所以，你們如果在基督裡有任何鼓勵、任何愛的安慰、任何聖靈裡的契合<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="契合——或譯作「溝通」或「分享」。">a</a></sup>、任何情感和憐憫，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 12:16; 彼得前書 3:8–9; 哥林多前書 1:10"> 你們就要同心合意——愛心一致、靈裡一致、意念一致，好使我的喜樂得以滿足。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 12:10; 加拉太書 5:26; 以弗所書 5:21"> 做任何事都不要出於爭競<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="爭競——或譯作「結黨」。">b</a></sup>，也不可出於虛榮，而要以謙卑的心，各人看別人比自己強；</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:24; 羅馬書 15:1; 雅各書 2:8"> 每個人不要只注重自己的事，也要注重別人的事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="約翰一書 2:6; 馬太福音 11:29; 彼得前書 2:21"> 你們應當有這樣的意念，這也是基督耶穌的意念。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 5:18; 哥林多後書 4:4; 希伯來書 1:3"> <span className="pl pl-1">雖然他就是神本體的存在，</span><br /><span className="pl pl-1">卻不把與神同等看做是一件要強抓不放的事，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 8:9; 馬太福音 20:28; 約翰福音 1:14"> <span className="pl pl-1">反而倒空自己，</span><br /><span className="pl pl-1">取了奴僕的形像，成為人的樣式，</span><br /><span className="pl pl-1">以人的形態出現，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:18; 希伯來書 12:2; 羅馬書 5:19"> <span className="pl pl-1">降卑自己，順從至死，</span><br /><span className="pl pl-1">甚至死在十字架上！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:16; 馬太福音 28:18; 彼得前書 3:22"> <span className="pl pl-1">因此神使他升為至高，</span><br /><span className="pl pl-1">賜給他那超越萬名之上的名，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 45:23–25; 馬太福音 28:18; 啟示錄 5:13–14"> <span className="pl pl-1">好使天上、地上和地底下的一切，</span><br /><span className="pl pl-1">因耶穌的名都屈膝，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約翰一書 4:15; 羅馬書 14:11; 約翰福音 13:13"> <span className="pl pl-1">萬口為了父神的榮耀</span><br /><span className="pl pl-1">要承認耶穌基督是主。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得後書 1:5–10; 路加福音 13:23–24; 哥林多前書 15:58"> 因此，我親愛的各位，既然你們一直是順從的——不僅我在的時候如此，現今我不在的時候更加順從——就當懷著敬畏和戰兢的心，把你們的救恩行出來，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:21; 哥林多後書 3:5; 提摩太後書 1:9"> 因為是神在你們裡面運作，使你們願意並且能行出他的美意。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 4:9; 哥林多前書 10:10; 腓立比書 2:3"> 做任何事都不要抱怨或爭論<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="爭論——或譯作「算計」。">c</a></sup>，</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:14–16; 彼得前書 2:12; 馬太福音 5:45"> 好使你們成為無可指責、純潔無偽的人，在這扭曲、敗壞的世代中，做神毫無瑕疵的兒女；在這世代中，要像星星的光輝一樣照耀在世上。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 9:26; 加拉太書 2:2; 約翰一書 1:1"> 你們要持守生命的話語，好讓我在基督的日子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="日子——指「基督再來的日子」。">d</a></sup>裡可以誇耀我所奔跑的沒有落空，我所勞苦的也沒有落空。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 4:6; 羅馬書 15:16; 希伯來書 13:15–16"> 然而，即使我被做為奠祭，澆在你們信仰的祭物和服事上，我也歡喜，並且和你們大家一同歡喜；</span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 1:2–4; 腓立比書 4:4; 腓立比書 3:1"> 你們也應該照樣歡喜，並且與我一同歡喜。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 4:17; 帖撒羅尼迦前書 3:6–8; 帖撒羅尼迦前書 3:2"> 我在主耶穌裡，希望不久能派提摩太到你們那裡去，好讓我也知道有關你們的事，可以心情愉快。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比書 2:2; 哥林多前書 16:10; 腓立比書 2:22"> 實際上，我沒有別的人與我同心，真正地掛慮你們的事；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 10:24; 馬太福音 16:24; 腓立比書 2:4"> 因為大家都尋求自己的事，不尋求耶穌基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 4:17; 哥林多後書 2:9; 提摩太後書 1:2"> 但是，你們是知道提摩太那經過考驗的品德。因為他在福音工作上與我一起服事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="服事——原文直譯「做奴僕」。">e</a></sup>，就像兒子與父親那樣。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 22:3; 腓立比書 2:19"> 所以我希望，一旦知道我的事有什麼結局<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有什麼結局——輔助詞語。">f</a></sup>，就立即派他去。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰三書 1:14; 腓利門書 1:22; 腓立比書 1:25–26"> 不過我在主裡深信，我自己不久也會去的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比書 4:18; 腓利門書 1:1–2; 腓立比書 4:3"> 然而，我認為必須派以帕弗迪托到你們那裡去；他是我的弟兄、同工、戰友，也是你們的使者，是為我的需要而來的服事者，</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 12:15; 箴言 12:25; 以弗所書 3:13"> 因為他一直切切地想念你們大家，並且因你們聽說他患了病，他就極其難過。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:19; 腓立比書 2:30; 詩篇 103:3–4"> 事實上，他雖然患了病幾乎死去，可是神憐憫了他；不僅憐憫他，也憐憫了我，免得我憂上加憂。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 16:22; 提摩太後書 1:4; 腓立比書 2:26–27"> 所以，我就更迫切地派他去，好讓你們見到他，能夠再次歡喜，而我也可以少些掛慮。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒羅尼迦前書 5:12; 哥林多前書 16:18; 提摩太前書 5:17"> 因此，你們要在主裡滿懷喜樂地歡迎他，也要敬重這樣的人，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 16:17; 使徒行傳 20:24; 腓立比書 4:10"> 因為他為了基督的工作，幾乎至死，冒了生命的危險，為要彌補你們服事我的缺乏。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比書 1:27; 哥林多前書 16:13; 詩篇 27:14"> 因此，我所愛的、所想念的弟兄們，我的喜樂、我的冠冕哪！各位蒙愛的人，你們當如此在主裡站立得穩！</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 12:14; 哥林多前書 1:10; 馬可福音 9:50"> 我懇求猶迪婭，也懇求辛圖柯，要在主裡同心合意。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:5; 啟示錄 13:8; 路加福音 10:20"> 是的，我真誠的同伴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同伴——原文直譯「同負一軛的」。">a</a></sup>哪！我也請求你幫助她們兩位<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="兩位——輔助詞語。">b</a></sup>。她們在福音工作上曾經與我、克萊門斯，和我的其他同工們一起奮戰，這些人的名字都在生命冊上。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:16–18; 羅馬書 12:12; 雅各書 1:2–4"> 你們要在主裡常常歡喜。我再說，你們要歡喜！</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 5:8–9; 馬太福音 6:25; 提多書 3:2"> 要讓所有人知道你們的謙和。主快到了！</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 3:5–6; 彼得前書 5:7; 馬太福音 6:25–33"> 在任何事上都不要憂慮；然而要在一切事上，藉著禱告和祈求，以感謝的心把你們所求的告訴神。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:27; 以賽亞書 26:3; 帖撒羅尼迦後書 3:16"> 這樣，神的平安——那高過一切理性的平安，就會在基督耶穌裡保守你們的心、你們的意念。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="雅各書 3:17; 提多書 2:7; 羅馬書 12:9–21"> 最後，弟兄們，凡是真實的、莊重的、公義的、純潔的、可羨慕的、高尚的，如果有什麼美德，如果有什麼可稱讚的，這些事你們就當思想；</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 1:22; 腓立比書 3:17; 帖撒羅尼迦前書 4:1–8"> 凡是你們在我身上所學到的、所領受的、所聽到的、所看到的，這些事你們就當實行。這樣，賜平安的神就會與你們同在。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 11:9; 加拉太書 6:6; 哥林多後書 7:6–7"> 我在主裡極其歡喜，因為現在你們終於又萌發了思念我的心。其實你們一直在思念我，只是沒有機會表達<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="表達——輔助詞語。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 6:6–9; 希伯來書 13:5–6; 馬太福音 6:31–34"> 我這樣說，並不是因為我缺少什麼；事實上，我已經學會了在任何情況下都知足。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 11:29; 哥林多後書 12:7–10; 哥林多後書 11:27"> 我知道怎樣處卑賤，也知道怎樣處豐富；在一切事上，在一切情況下，或飽足、或飢餓，或豐富、或缺乏，我都得了祕訣。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 41:10; 哥林多後書 12:9–10; 歌羅西書 1:11"> 藉著使我剛強的那一位<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「——基督」。">d</a></sup>，我一切都能。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:16; 腓立比書 1:7; 希伯來書 10:34"> 不過你們分擔了我的患難，做得很好。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="腓立比書 1:5; 哥林多後書 11:8–12; 使徒行傳 16:40–5"> 腓立比人哪，你們也知道，在福音工作的開始，我離開馬其頓省的時候，在供給和領受的事上，除了你們以外，沒有別的教會與我分享。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 2:9; 使徒行傳 17:1; 帖撒羅尼迦前書 2:18"> 就是我在帖撒羅尼迦的時候，你們甚至也一再地把我所需要的送來。</span>
<span className="v" id="v17" data-v="17" data-xref="提多書 3:14; 希伯來書 6:10; 哥林多後書 9:9–13"> 我並不是求什麼供應，而是求你們的果子增多，歸在你們的帳上。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 13:16; 腓立比書 4:12; 哥林多後書 9:12"> 如今我一切都得到了，並且豐足有餘。我已經得以滿足了，因為我從以帕弗迪托接受了來自你們的東西；那是馨香的氣味，是神所悅納、所喜悅的祭物。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 9:8–11; 詩篇 84:11; 彼得前書 5:10"> 我的神將按照他榮耀的豐盛，在基督耶穌裡滿足你們一切的需要。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 11:36; 詩篇 115:1; 啟示錄 14:7"> 願榮耀歸於神我們的父，直到永永遠遠！阿們。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 1:2; 腓利門書 1:23–24; 歌羅西書 4:10–14"> 請問候在基督耶穌裡的每一位聖徒。與我在一起的弟兄們都問候你們；</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 1:13; 哥林多後書 13:13; 羅馬書 16:16"> 所有的聖徒，尤其是來自凱撒宮裡的人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="凱撒宮裡的人——或譯作「凱撒家族的人」。">e</a></sup>，也都問候你們。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 13:14; 羅馬書 16:20; 羅馬書 16:23"> 願主耶穌基督的恩典與你們的靈<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你們的靈——有古抄本作「你們大家」。">f</a></sup>同在！<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「阿們。」">g</a></sup></span>
</div>

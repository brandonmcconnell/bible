<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 1:1; 使徒行傳 16:12–15; 羅馬書 1:1"> 基督耶穌的奴僕保羅和提摩太，<br />致住在腓立比，在基督耶穌裡的所有聖徒，包括各位監督和執事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="執事——或譯作「僕人」。">a</a></sup>：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:7; 哥林多後書 1:2; 彼得前書 1:2"> 願恩典與平安從神我們的父和主耶穌基督臨到你們！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:4; 帖撒羅尼迦前書 1:2–3; 腓利門書 1:4–5"> 每當想到你們，我就感謝我的神；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 1:2; 羅馬書 1:9; 約翰二書 1:4"> 每次為你們大家祈禱的時候，我總是懷著喜樂的心祈禱，</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:14–15; 腓立比書 1:7; 希伯來書 3:14"> 因你們從第一天到如今，一直在福音工作上相契合<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="相契合——或譯作「溝通」或「分享」。">b</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦前書 5:23–24; 腓立比書 2:13; 以弗所書 4:12"> 我正是深信這一點：就是在你們裡面開始了美善工作的那一位，將會完成這工作，直到基督耶穌的日子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="日子——指「基督再來的日子」。">c</a></sup>。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 7:3; 腓立比書 1:5; 歌羅西書 4:18"> 我理當這樣思念你們大家，因為你們常把我放在心上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你們常把我放在心上——或譯作「我常把你們放在心上」。">d</a></sup>；無論我是在捆鎖當中，還是在為福音辯護或做見證的時候，你們都是在恩典上與我一同有份。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:1; 羅馬書 1:9; 提摩太後書 1:4"> 實際上，神可以為我見證：我是怎樣以基督耶穌的情感，切切地想念你們大家的。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 3:12; 歌羅西書 1:9; 彼得後書 1:5–6"> 我是這樣禱告的：願你們的愛心能在真正的知識和一切分辨力上，越來越豐足有餘，</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:2; 帖撒羅尼迦前書 3:13; 帖撒羅尼迦前書 5:23"> 使你們能分辨是非<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="是非——或譯作「那些更重要的事」。">e</a></sup>，好在基督的日子裡是純潔、無可指責的，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 12:11; 約翰福音 15:8; 約翰福音 15:4–5"> 並且充滿了那藉著耶穌基督而來的義行果子，歸於神的榮耀和稱讚。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 2:9; 羅馬書 8:28; 使徒行傳 11:19–21"> 弟兄們，我願你們知道，我的遭遇反而促進了福音的進展，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 2:9; 以弗所書 3:1; 腓立比書 1:7"> 以致整個王宮衛隊<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="王宮衛隊——原文直譯「總督府」。">f</a></sup>和所有其餘的人，都清楚我是為基督的緣故被捆鎖的；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 6:19–20; 帖撒羅尼迦前書 2:2; 路加福音 1:74"> 並且大多數的弟兄因著我所受的捆鎖，就在主裡深信不疑、無所懼怕，更加大膽地傳講這話語<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="這話語——有古抄本作「神的話語」。">g</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:17–18; 腓立比書 2:3; 哥林多後書 11:13"> 有些人傳揚基督固然是出於嫉妒和紛爭，但也有些人是出於好意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 2:17; 哥林多後書 4:1–2; 詩篇 69:26"> 後者是出於愛，知道我是為辯護福音而受委派的；<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本作第17節。">h</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 1:11–12; 腓立比書 2:3; 腓立比書 1:7"> 前者傳講基督是出於爭競<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="爭競——或譯作「結黨」。">i</a></sup>，不是出於真誠，想要在我的捆鎖中，增加<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="增加——有古抄本作「喚起」。">j</a></sup>我的患難。<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本作第16節。">k</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 馬可福音 9:38–40; 哥林多前書 15:11"> 這到底有什麼關係呢？只是在各種方法中，無論是假意還是真心，基督都被傳開了；我為此就歡喜，並且還要歡喜，</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 8:28; 使徒行傳 16:7; 哥林多後書 1:11"> 因為我知道，藉著你們的祈禱和耶穌基督之靈的幫助，事情將為我轉變以致我獲救。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 4:16; 哥林多前書 6:20; 以賽亞書 54:4"> 我的熱切盼望和期待是：我在任何事上都將不至於蒙羞；而現在也能像往常一樣，無論藉著生，還是藉著死，總要滿有膽量地讓基督在我身上被尊為大。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 2:20; 哥林多後書 5:8; 哥林多後書 5:1"> 因為對我來說，活著就是基督，死去就有益處。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 4:2; 加拉太書 2:20; 腓立比書 1:24"> 但如果我繼續活在世上<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="在世上——原文直譯「在肉身中」。">l</a></sup>，這就使我有工作的成果<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="成果——原文直譯「果子」。">m</a></sup>，於是我不明白該怎樣選擇了。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 5:8; 詩篇 17:15; 啟示錄 14:13"> 我正處在兩難之間：我渴望離世與基督在一起，因為這是好得無比的；</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 16:7; 腓立比書 1:22; 腓立比書 1:25–26"> 可是為了你們的緣故，我更需要留在世上<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="在世上——原文直譯「在肉身中」。">n</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比書 2:24; 哥林多後書 1:24; 以弗所書 4:11–13"> 既然我深信這一點，就知道我會活下去<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="活下去——原文直譯「留下來」。">o</a></sup>，並且將繼續和你們大家在一起，好使你們在信仰上有長進、有喜樂。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 1:14; 哥林多後書 5:12; 腓立比書 3:3"> 以致因著我再次到你們那裡去，你們在基督耶穌裡，對我的誇耀能充實滿溢。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所書 4:1; 哥林多前書 16:13–14; 哥林多前書 1:10"> 只是你們行事為人<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="行事為人——原文直譯「像好公民那樣生活」。">p</a></sup>要配得上基督的福音，好讓我無論是來見你們，還是不在你們那裡的時候，都可以聽到有關你們的事，就是你們懷有一個心志站立得穩，同心合意地為福音的信仰一起奮戰；</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 1:7–8; 帖撒羅尼迦後書 1:5–6; 馬太福音 10:28"> 在任何事上都不被反對你們的人嚇倒——這對他們是滅亡<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="滅亡——或譯作「沉淪」。">q</a></sup>的證明，而對你們卻是得救的證明，並且這是出於神。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 1:2; 彼得前書 4:13; 使徒行傳 5:41"> 原來你們為基督所蒙的恩是：不僅要信基督，而且還要為他受苦，</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 2:2; 使徒行傳 16:19–40; 提摩太後書 4:7"> 去經歷你們在我身上所看到、現在又聽到的那同樣的爭戰。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 5:11; 腓立比書 4:4; 雅各書 1:2"> 此外，我的弟兄們，你們要在主裡歡喜。<br />我把同樣的話寫給你們，一方面對我不是麻煩，另一方面對你們是一種保護。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 11:13; 提多書 1:16; 啟示錄 22:15"> 你們要當心那些犬類，當心那些作惡的工人，當心那些妄割身體的人。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:11; 申命記 30:6; 羅馬書 7:6"> 實際上，我們才是受過割禮的人，就是藉著神的靈事奉，在基督耶穌裡誇耀，不依靠肉體的人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 11:18–22"> 其實我也可以依靠肉體；如果另外有人自以為可以依靠肉體，我就更可以了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 11:22; 羅馬書 11:1; 使徒行傳 23:6"> 我出生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我出生——輔助詞語。">a</a></sup>第八天受了割禮；我屬於以色列族、便雅憫支派，是希伯來人所生的希伯來人；按照律法說，我是法利賽人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 1:13–14; 使徒行傳 8:3; 使徒行傳 26:9–10"> 按照熱心說，我曾經逼迫教會；按照律法上的義說，我是無可指責的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 馬太福音 16:26; 馬太福音 13:44–46"> 然而，以前對我有益的事，現在因基督的緣故，我已經把這些事看做是損失。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 9:23–24; 羅馬書 8:18; 腓立比書 3:7"> 不但如此，我甚至把一切都看做是損失，因為我把認識我主基督耶穌看為是至高無上的。我為基督耶穌損失了一切，而且把一切都看做是糞土，為要贏得基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 5:21; 哥林多前書 1:30; 加拉太書 2:16"> 並且要被認定在他裡面——不是擁有那本於律法的自己的義，而是擁有那藉著信基督而來的義，就是來自神、基於信的義；</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 2:20; 羅馬書 8:17; 彼得前書 4:1–2"> 並且為要認識基督和他復活的大能，要在他的苦難裡相契合<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="相契合——或譯作「溝通」或「分享」。">b</a></sup>，效法他的死，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 啟示錄 20:5; 使徒行傳 23:6"> 或許我能得以從死人中復活。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 6:11–12; 彼得後書 1:5–8; 詩篇 138:8"> 這並不是說我已經得到了，或已經得以完全了，而是說我在竭力追求，或許我真的可以得著<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="得著——原文直譯「抓住」。">c</a></sup>；為此我也被基督耶穌得著<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="得著——原文直譯「抓住」。">d</a></sup>了。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯來書 12:1–2; 腓立比書 3:12"> 弟兄們，我不認為自己已經得著<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="得著——原文直譯「抓住」。">e</a></sup>了；但是我有一件事：就是忘記背後，爭取前面的，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 9:24; 彼得前書 5:10; 啟示錄 3:21"> 向著目標竭力追求，為了得到<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="得到——輔助詞語。">f</a></sup>那在基督耶穌裡、神至高召喚的獎賞。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 7:17; 雅各書 1:4–5; 箴言 2:3–6"> 因此，讓我們所有成熟的人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="成熟的人——或譯作「完全的人」。">g</a></sup>都這樣思想。如果你們有什麼不同的思想，神也會把這事啟示給你們。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 2:6; 啟示錄 3:3; 啟示錄 2:4–5"> 不過我們達到了什麼標準<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「標準」。">h</a></sup>，就讓我們照著什麼標準行走<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「照著什麼思想行走」。">i</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="腓立比書 4:9; 哥林多前書 4:16; 彼得前書 5:3"> 弟兄們，你們要一同效法我，也要留心看那些像你們一樣，以我們為榜樣行事的人。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 4:17; 以賽亞書 8:11; 加拉太書 6:12"> 其實我過去再三地告訴你們，而現在又流著眼淚告訴你們：有許多人的行事為人，是基督十字架的仇敵。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 16:18; 羅馬書 8:5–7; 彼得後書 2:3"> 他們的結局就是滅亡<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="滅亡——或譯作「沉淪」。">j</a></sup>；他們的神就是自己的私慾<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="私欲——原文直譯「肚腹」。">k</a></sup>；他們的榮耀在自己的羞恥之中；他們所思想的都是地上的事。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 2:19; 歌羅西書 3:1–3; 哥林多後書 4:18–1"> 然而，我們的國籍在天上；我們也熱切等待著救主——主耶穌基督從那裡降臨。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 3:2; 歌羅西書 3:4; 哥林多前書 15:42–56"> 他將照著那能使萬有都服從他的力量，改變我們這卑賤的身體，要<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附「使它成為」。">l</a></sup>與他那榮耀的身體相似。</span>
</div>
</div>

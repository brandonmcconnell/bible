<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 48:2; 以賽亞書 52:1; 尼希米記 11:18"> 那時，民眾的首領們在耶路撒冷住下來，其餘的民眾抽籤，要從每十人中抽出一人住在聖城耶路撒冷，餘下的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="餘下的——原文直譯「手中的」。">a</a></sup>九人住在各城鎮。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 5:9; 哥林多後書 8:16–17; 約伯記 29:13"> 凡是甘願奉獻自己住在耶路撒冷的人，民眾都為他們祝福。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 2:1; 以斯拉記 2:43; 歷代志上 9:1–34"> 以色列人、祭司、利未人、聖殿僕役和所羅門臣僕的子孫，住在猶大的各城鎮，各人住在本城自己的地業中。以下是住在耶路撒冷的猶大<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="猶大——輔助詞語。">b</a></sup>省眾首領，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 38:29; 馬太福音 1:3; 路加福音 3:33"> 以及住在耶路撒冷的一些猶大子孫和便雅憫子孫。<br /><span className="pl pl-1">猶大的子孫有：</span><br />法勒斯的子孫亞塔雅，他是烏西雅的兒子，烏西雅是撒迦利亞的兒子，撒迦利亞是亞瑪利雅的兒子，亞瑪利雅是示法提雅的兒子，示法提雅是瑪勒列的兒子；</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 9:5; 尼希米記 3:15; 民數記 26:20"> 還有瑪西雅，他是巴錄克的兒子，巴錄克是科爾霍澤的兒子，科爾霍澤是哈扎雅的兒子，哈扎雅是亞達雅的兒子，亞達雅是約雅立的兒子，約雅立是撒迦利亞的兒子，撒迦利亞是示拉<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="示拉——或譯作「示羅人」。">c</a></sup>的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 住在耶路撒冷的法勒斯子孫，總共四百六十八人，都是勇士。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 9:7–9"> <span className="pl pl-1">便雅憫的子孫有：</span><br />薩魯，他是米書蘭的兒子，米書蘭是約耶的兒子，約耶是皮達雅的兒子，皮達雅是科賴雅的兒子，科賴雅是瑪西雅的兒子，瑪西雅是伊鐵勒的兒子，伊鐵勒是耶賽亞的兒子；</span>
<span className="v" id="v8" data-v="8"> 在他之後，有迦拜、薩雷。<br />他們共有九百二十八人，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 9:7"> 澤克利的兒子約珥是他們的督軍，哈西努亞的兒子猶大是那城的副長官。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 9:10; 尼希米記 12:6; 尼希米記 12:19"> <span className="pl pl-1">祭司有：</span><br />約雅立的兒子耶達亞；又有雅斤；</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 9:11; 歷代志上 6:7–14; 民數記 3:32"> 還有神殿總管西萊雅，他是希勒加的兒子，希勒加是米書蘭的兒子，米書蘭是撒督的兒子，撒督是米拉約的兒子，米拉約是亞希突的兒子；</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 9:12–13"> 還有他們那些為聖殿做工的兄弟，八百二十二人；<br />還有亞達雅，他是耶羅罕的兒子，耶羅罕是佩拉利雅的兒子，佩拉利雅是阿姆基的兒子，阿姆基是撒迦利亞的兒子，撒迦利亞是帕示戶珥的兒子，帕示戶珥是瑪基雅的兒子；</span>
<span className="v" id="v13" data-v="13"> 還有亞達雅那些作父系首領的兄弟們，兩百四十二人；<br />還有亞瑪沙伊，他是阿扎列的兒子，阿扎列是阿赫扎伊的兒子，阿赫扎伊是米實列莫的兒子，米實列莫是伊梅爾的兒子；</span>
<span className="v" id="v14" data-v="14"> 還有他們的兄弟們，都是英勇的戰士，有一百二十八人，哈基多琳的兒子撒巴迪業是他們的督軍。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 9:14; 歷代志上 9:19"> <span className="pl pl-1">利未人有：</span><br />示瑪雅，他是哈述的兒子，哈述是亞斯利甘的兒子，亞斯利甘是哈沙比雅的兒子，哈沙比雅是布尼的兒子；</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 6:2–3; 尼希米記 8:7; 以斯拉記 8:33"> 還有管理神殿外部事務的利未首領沙比泰和約撒巴；</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 9:15; 歷代志上 25:1–6; 尼希米記 12:8–9"> 還有禱告時首先獻上感謝的領隊瑪塔尼亞，他是米迦的兒子，米迦是扎布迪的兒子，扎布迪是亞薩的兒子；還有巴克布迦，他是兄弟中的副領隊；還有阿布達，他是沙慕亞的兒子，沙慕亞是迦拉的兒子，迦拉是耶杜頓的兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 11:1; 啟示錄 21:2; 但以理書 9:24"> 在聖城的利未人，總共兩百八十四人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="尼希米記 7:45; 歷代志上 9:17–22; 詩篇 84:10"> <span className="pl pl-1">門衛有：</span><br />阿庫布、達門，以及他們那些看守城門的兄弟，一百七十二人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米記 11:3"> 其餘的以色列人、祭司和利未人，都在猶大的各城鎮，各在自己的繼業之地。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 3:26; 歷代志下 27:3; 尼希米記 3:31"> 聖殿僕役住在俄斐勒，由西哈和基斯帕管理這些聖殿僕役。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:42; 歷代志上 25:1–6; 以斯拉記 8:19"> 在耶路撒冷的利未人的監督是烏基，他是巴尼的兒子，巴尼是哈沙比雅的兒子，哈沙比雅是瑪塔尼亞的兒子，瑪塔尼亞是米迦的兒子，是亞薩的子孫。亞薩子孫是歌手，也負責神殿的事務；</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 7:20–24; 尼希米記 12:47; 以斯拉記 6:8–9"> 因為王對他們有規定，歌手每天的事務都有確定的條例。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 38:30; 歷代志上 18:17; 歷代志上 23:28"> 佩塔希雅代表王管理民眾的一切事務，他是米示薩別的兒子，是猶大兒子謝拉的子孫。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 14:15; 約書亞記 15:21–22"> 至於他們的村莊和郊野：<br /><span className="pl pl-1">猶大子孫中，有些人住在</span><br /><span className="pl pl-1">基列-阿爾巴和附屬的村鎮、</span><br /><span className="pl pl-1">迪本和附屬的村鎮，</span><br /><span className="pl pl-1">耶克策勒和附屬的村莊，</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 15:26–27; 約書亞記 19:2"> <span className="pl pl-1">耶書亞，漠拉達，伯帕列，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:33; 約書亞記 15:28; 士師記 20:1"> <span className="pl pl-1">哈薩書爾，比爾-謝巴和附屬的村鎮，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 27:6; 約書亞記 15:31"> <span className="pl pl-1">洗革拉，米克納和附屬的村鎮，</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:41; 約書亞記 15:32–33; 約書亞記 15:35"> <span className="pl pl-1">恩臨門，佐拉，雅爾慕，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 10:3; 約書亞記 15:8; 約書亞記 18:16"> <span className="pl pl-1">撒挪亞、亞杜蘭和牠們附屬的村莊，</span><br /><span className="pl pl-1">拉吉和附屬的郊野，亞西加和附屬的村鎮。</span><br /><span className="pl pl-1">他們支搭帳篷，從比爾-謝巴直到欣嫩子谷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="創世記 12:8; 約書亞記 8:9; 約書亞記 18:13"> <span className="pl pl-1">便雅憫的子孫所住之地</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="所住之地——輔助詞語。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">是從迦巴起，到米克瑪，艾雅，</span><br /><span className="pl pl-1">伯特利和附屬的村鎮，</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 21:18; 以賽亞書 10:30; 撒母耳記上 21:1"> <span className="pl pl-1">亞納圖，挪伯，亞納尼亞，</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 4:3; 撒母耳記上 7:17; 約書亞記 18:25"> <span className="pl pl-1">哈佐，拉瑪，吉塔伊姆，</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 13:18"> <span className="pl pl-1">哈迪，策伯伊姆，尼巴拉特，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 8:12; 尼希米記 7:37; 歷代志上 4:14"> <span className="pl pl-1">羅德，阿挪，以及匠人谷。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 21:1–45; 創世記 49:7; 歷代志上 6:54–81"> <span className="pl pl-1">猶大地區各班組的一些利未人</span><br /><span className="pl pl-1">住在便雅憫人中間。</span></span>
</div>

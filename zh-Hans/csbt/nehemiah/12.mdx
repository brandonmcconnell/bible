<span className="v" id="v3" data-v="3"> <span className="pl pl-1">謝喀尼亞、利戶姆、米利莫、</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:5"> <span className="pl pl-1">易多、格尼桐、亞比雅、</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:17; 尼希米記 12:24; 尼希米記 11:22"> <span className="pl pl-1">利未人有：</span><br /><span className="pl pl-1">耶書亞、賓努伊、卡米爾、</span><br /><span className="pl pl-1">示利比、猶大、瑪塔尼亞；</span><br /><span className="pl pl-1">瑪塔尼亞和他的兄弟們負責頌讚的事，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 12:24; 詩篇 134:1–3"> <span className="pl pl-1">他們的兄弟巴克布迦和烏尼站在對面履行職責。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 6:3–15; 尼希米記 13:28; 尼希米記 13:4"> <span className="pl pl-1">耶書亞生約雅金，約雅金生以利亞實，</span><br /><span className="pl pl-1">以利亞實生耶赫亞達，</span><br /></span>
<span className="v" id="v11" data-v="11"> <span className="pl pl-1">耶赫亞達生約拿單，約拿單生雅杜亞。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="尼希米記 12:22; 歷代志上 9:33–34; 歷代志上 24:6–31"> <span className="pl pl-1">在約雅金時期，作父系首領的祭司有：</span><br /><span className="pl pl-1">西萊雅家族的米拉雅，耶利米家族的哈納尼雅，</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">以斯拉家族的米書蘭，亞瑪利雅家族的約哈南，</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">瑪盧克家族的約拿單，示巴尼家族的約瑟，</span><br /></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">哈琳家族的阿德納，米拉約家族的希勒凱，</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">易多家族的撒迦利亞，格尼桐家族的米書蘭，</span><br /></span>
<span className="v" id="v17" data-v="17"> <span className="pl pl-1">亞比雅家族的澤克利，珉雅憫家族的人，</span><br /><span className="pl pl-1">莫阿迪亞家族的比勒泰，</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">比勒伽家族的沙慕亞，示瑪雅家族的約拿單，</span><br /></span>
<span className="v" id="v19" data-v="19"> <span className="pl pl-1">約雅立家族的瑪特奈，耶達亞家族的烏基，</span><br /></span>
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">薩雷家族的卡拉伊，阿莫克家族的希伯，</span><br /></span>
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">希勒加家族的哈沙比雅，耶達亞家族的拿旦業。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:10–13"> 這些利未人，在以利亞實、耶赫亞達、約哈南和雅杜亞時期，作為各父系的首領被記了下來；祭司們是波斯人大流士在位時被記下來的。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 9:14–44"> 利未子孫各父系的首領都被記在年代志上，直到以利亞實的兒子約哈南時期。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 25:1–26; 尼希米記 11:17; 以斯拉記 3:10–11"> 利未人的首領哈沙比雅、示利比、卡米爾的兒子耶書亞，站在他們兄弟對面，按照神人大衛的規定，輪班讚美稱謝。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 26:15; 尼希米記 12:8–9; 歷代志上 26:12"> 瑪塔尼亞、巴克布迦、俄巴底亞、米書蘭、達門、阿庫布是門衛，是看守各城門旁倉庫的守衛。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="尼希米記 8:9; 以斯拉記 7:6; 以斯拉記 7:11"> 以上的人，在約薩達的孫子、耶書亞的兒子約雅金時期，以及省長尼希米和祭司經文士以斯拉時期供職。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 15:16; 歷代志上 15:28; 歷代志下 29:30"> 在舉行耶路撒冷城牆奉獻禮的時候，他們從各地尋找利未人，要把利未人帶到耶路撒冷，以感謝和詩歌，用大鈸、里拉琴和豎琴，歡歡喜喜地舉行奉獻禮。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 9:16; 歷代志上 2:54; 尼希米記 6:2"> 歌手們就從耶路撒冷周邊地區，從尼托法人的村莊，</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 10:43; 歷代志上 6:60; 以斯拉記 2:24"> 從伯吉甲，從迦巴和阿茲瑪維的田野被招聚起來，因為歌手們在耶路撒冷四圍建造了自己的村莊。</span>
<span className="v" id="v30" data-v="30" data-xref="約伯記 1:5; 出埃及記 19:10; 歷代志下 29:5"> 於是祭司和利未人潔淨了自己，又潔淨民眾，以及城門和城牆。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 2:13; 尼希米記 12:38; 歷代志上 13:1"> 我把猶大的首領們帶到城牆上面，又安排了兩大隊頌讚隊伍。一隊在城牆的上面向右邊，往糞場門行進。</span>
<span className="v" id="v32" data-v="32"> 走在隊伍後面的有何沙雅和一半的猶大首領，</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米記 10:2–7"> <span className="pl pl-1">以及亞撒利雅、以斯拉、米書蘭、</span><br /></span>
<span className="v" id="v34" data-v="34"> <span className="pl pl-1">猶大、便雅憫、示瑪雅、耶利米。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 6:4; 民數記 10:2–10; 歷代志下 5:12"> <span className="pl pl-1">還有一些祭司子弟拿著號筒，其中有：</span><br />撒迦利亞，他是約拿單的兒子，約拿單是示瑪雅的兒子，示瑪雅是瑪塔尼亞的兒子，瑪塔尼亞是米該亞的兒子，米該亞是扎克爾的兒子，扎克爾是亞薩的兒子；</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 12:24; 歷代志下 8:14; 歷代志上 23:5"> <span className="pl pl-1">還有撒迦利亞的兄弟們</span><br /><span className="pl pl-1">示瑪雅、阿扎列、米拉萊、</span><br /><span className="pl pl-1">基拉萊、瑪艾、拿旦業、</span><br /><span className="pl pl-1">猶大、哈納尼，</span><br /><span className="pl pl-1">都拿著神人大衛的樂器。</span><br /><span className="pl pl-1">經文士以斯拉走在他們前頭。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="尼希米記 3:26; 尼希米記 2:14; 尼希米記 8:3"> 他們到達泉門，往前登上大衛城的臺階，沿著城牆的斜坡，從大衛宮殿的上方，走到東邊的水門。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="尼希米記 3:8; 尼希米記 3:11; 尼希米記 12:31"> 第二隊頌讚隊伍往相反的方向走，我和一半的民眾在隊伍的後面，從城牆上方、從爐樓的上方，直到寬牆；</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米記 3:1; 尼希米記 3:3; 尼希米記 8:16"> 然後經過以法蓮門、古門、魚門、哈楠業樓和百樓，直到羊門，然後在護衛門那裡站住。</span>
</div>
<div className="bp poetry">
<span className="v" id="v40" data-v="40" data-xref="詩篇 42:4; 詩篇 134:1–3; 尼希米記 12:31–32"> 於是這兩隊頌讚隊伍站在神的殿中，我和與我一起的一半官長也在那裡；</span>
<span className="v" id="v41" data-v="41"> <span className="pl pl-1">還有眾祭司以利亞敬、瑪西雅、珉雅憫、米該亞、以利約奈、撒迦利亞、哈納尼雅，都拿著號筒；</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 81:1; 尼希米記 11:14; 詩篇 100:1–2"> <span className="pl pl-1">還有瑪西雅、示瑪雅、以利亞撒、</span><br /><span className="pl pl-1">烏基、約哈南、瑪基雅、以攔、以謝爾；</span><br /><span className="pl pl-1">歌手們歌唱，伊斯拉希雅作指揮。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="以斯拉記 3:13; 詩篇 92:4; 耶利米書 31:13"> 那一天，他們獻上大量的祭物，並且歡喜快樂，因為神使他們極其歡樂；連女人和孩子也歡樂，耶路撒冷歡樂的聲音從遠處都能聽見。</span>
<span className="v" id="v44" data-v="44" data-xref="尼希米記 13:12–13; 尼希米記 10:37–39; 歷代志下 31:11–13"> 當天，一些人受指派管理那些存放供物、初熟果實和十一奉獻的庫房，要把律法所定祭司和利未人的份從各城的田野收存在其中。猶大人都因這些祭司和侍立的利未人而喜樂，</span>
<span className="v" id="v45" data-v="45" data-xref="歷代志上 25:1–26; 歷代志下 23:6; 歷代志上 23:28"> 祭司和利未人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="祭司和利未人——原文直譯「他們」。">a</a></sup>謹守他們的神所賜的職責和潔淨的職責；歌手和門衛也謹守大衛和他兒子所羅門的規定，</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 29:30; 詩篇 73:1; 歷代志上 25:1–31"> 早在大衛和亞薩時期就有了歌手的領隊，並有讚美稱謝神的詩歌。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 18:21–29; 尼希米記 12:26; 尼希米記 13:10–12"> 這樣，在所羅巴伯時期和尼希米時期，全體以色列人一直供應歌手和門衛的份，就是他們每天需用的份額；並且把分別為聖的奉獻物給利未人，利未人也把分別為聖的奉獻物給亞倫的子孫。</span>
</div>

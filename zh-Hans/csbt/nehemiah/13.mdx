<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:3–5; 尼希米記 9:3; 尼希米記 13:23"> 那一天，他們宣讀摩西的書給民眾聽，發現其中記著：亞捫人和摩押人永不可加入神的會眾，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:5; 約書亞記 24:9–10; 民數記 23:8–11"> 因為這些人沒有帶著食物和水迎接以色列子孫，反而雇用巴蘭對付他們，詛咒他們——但我們的神使詛咒變成了祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 9:2; 出埃及記 12:38; 民數記 11:4"> 那時，民眾聽見了這律法，就把所有混雜的族群從以色列中分離出去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="尼希米記 12:44; 尼希米記 6:17–18; 尼希米記 13:28"> 在這之前，托比亞的親戚，就是受指派管理我們神殿庫房的祭司以利亞實，</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 12:44; 歷代志下 34:11; 民數記 18:21–24"> 給托比亞準備了一個大房間，那裡從前用來存放供物、乳香、器皿，以及按照誡命給利未人、歌手和門衛的五穀、新酒和新油的十一奉獻，還有歸給祭司的供物。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米記 5:14; 尼希米記 2:5–6; 馬太福音 13:25"> 這一切發生的時候，我不在耶路撒冷，因為巴比倫王亞達薛西三十二年，我回到了王那裡。過了一些日子，我向王請假，</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 13:5; 馬太福音 21:12–13; 耶利米哀歌 1:10"> 又來到耶路撒冷，才知道以利亞實為托比亞所做的惡事，他在神殿的庭院裡為托比亞準備了一個房間。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 11:15–17; 以斯拉記 10:1; 詩篇 69:9"> 這使我非常生氣，我就把托比亞的家具全都從房間裡扔到外面去了。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 29:5; 歷代志下 29:15–19; 尼希米記 12:45"> 我吩咐人潔淨了那些房間，又讓人把神殿的器皿與供物和乳香都搬回那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 10:37; 瑪拉基書 3:8; 瑪拉基書 1:6–14"> 我還得知利未人的份沒有得到供應，以致事奉的利未人和歌手各自離開，到自己的田地去了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 10:39; 尼希米記 13:17; 尼希米記 13:25"> 我就譴責官長們，說：「為什麼神的殿被撇棄呢？」然後我招聚利未人和歌手，讓他們回到自己的服事崗位上；</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 10:37–39; 瑪拉基書 3:10; 尼希米記 12:44"> 全體猶大人也把五穀、新酒和新油的十一奉獻帶到了庫房。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 22:7; 尼希米記 7:2; 尼希米記 12:44"> 我委派祭司示勒米雅、經文士撒督和利未人皮達雅管理庫房，他們的助手是哈南，哈南是扎克爾的兒子，扎克爾是瑪塔尼亞的兒子；他們被公認是忠實的人，所以讓他們來負責給兄弟們分配當得的份。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 122:6–9; 尼希米記 13:22; 尼希米記 13:31"> 我的神哪，求你為此記念我，不要抹掉我為神的殿、為神殿的職守所盡的忠誠！</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米記 10:31; 尼希米記 13:21; 出埃及記 34:21"> 在那些日子裡，我在猶大看到安息日有人踹榨酒池，有人搬運穀堆，有人用驢子馱東西，還有人在安息日把酒、葡萄、無花果和各樣的貨物運到耶路撒冷。我就在他們賣食物的那天警誡他們。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:12; 申命記 5:14"> 有些住在那裡的提爾人也把魚和各樣的商品運來，在安息日賣給猶大人，而且是在耶路撒冷城內賣的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="尼希米記 13:11; 尼希米記 13:25; 以賽亞書 1:10"> 於是我譴責猶大的貴族，對他們說：「你們怎麼做出這樣的惡事，褻瀆安息日呢？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 17:21–23; 耶利米書 44:9; 民數記 32:14"> 從前你們的祖先難道不是如此行事，以致我們的神使這一切禍患臨到我們和這城嗎？現在你們竟然褻瀆安息日，要使烈怒再次臨到以色列！」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 23:32; 出埃及記 31:14–17; 耶利米書 17:19–22"> 於是，在安息日之前，黃昏籠罩耶路撒冷城門時，我吩咐把各城門關上，並且吩咐安息日結束之前不可打開城門。我還派我的一些下屬在各城門站崗，不讓人在安息日把貨物運進來。</span>
<span className="v" id="v20" data-v="20"> 於是，客商和賣各樣東西的人有幾次留宿在耶路撒冷城外。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 13:3–4; 彼得前書 2:14; 以斯拉記 7:26"> 我就警誡他們，對他們說：「你們為什麼留宿在城牆那裡呢？如果你們再這樣，我就出手對付你們了。」從那時起，他們在安息日就不來了。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:30; 尼希米記 13:14; 尼希米記 13:31"> 我吩咐利未人要潔淨自己，然後來看守各城門，尊安息日為聖。<br />我的神哪，求你也為此記念我，照著你豐盛的慈愛顧惜我！</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:1–2; 以斯拉記 10:10; 尼希米記 10:30"> 在那些日子裡，我還看到猶太人娶了阿實突、亞捫和摩押的女子，</span>
<span className="v" id="v24" data-v="24" data-xref="西番雅書 3:9"> 他們的兒女有一半說阿實突話，或說各民族的語言，沒有人會說猶太話。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:3; 尼希米記 13:17; 尼希米記 10:29–30"> 我就譴責他們，詛咒他們，責打他們中的一些人，拔掉他們的鬍鬚，然後讓他們指著神起誓，對他們說<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="對他們說——輔助詞語。">a</a></sup>：「你們絕不可把你們的女兒嫁給外邦人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="外邦人——原文作「他們」。">b</a></sup>的兒子，也絕不可為你們的兒子、為自己娶他們的女兒。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 11:1–8; 列王紀上 3:13; 傳道書 7:26"> 以色列王所羅門難道不是在這樣的事上犯罪了嗎？在許多國家中沒有一個王像他那樣，蒙他的神所愛，神也使他作全以色列的王，然而他還是受外邦女子引誘而犯罪了！</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 10:2; 撒母耳記上 30:24"> 難道我們要聽任你們行這一切大惡，娶外邦女子，以致對我們的神不忠嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米記 2:19; 尼希米記 3:1; 尼希米記 12:22"> 大祭司以利亞實的兒子耶赫亞達有一個兒子，是賀倫人叁巴拉的女婿，我把他從我身邊趕走了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="尼希米記 6:14; 民數記 25:12–13; 瑪拉基書 2:4–8"> 我的神哪，求你記住他們，因他們玷汙了祭司的職份，玷汙了有關祭司職份和利未人的約。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="尼希米記 10:30; 尼希米記 12:1–26; 歷代志上 23:1–26"> 這樣，我潔淨他們脫離了外邦人的一切，又為祭司和利未人確立了職責，各盡其職；</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 13:14; 尼希米記 13:22; 詩篇 106:4"> 也安排了定期奉獻木柴的事，以及初熟之物的事。<br />我的神哪，求你記念我，恩待我！</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:10; 希伯來書 11:36; 詩篇 35:15–16"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在馬索拉文本為3:33至4:17。">a</a></sup>那時叁巴拉聽說我們在建造城牆，就發怒，非常惱火，並且嘲笑猶太人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:9–10; 哥林多前書 1:27; 以西結書 37:3–13"> 他在他的兄弟們和撒瑪利亞軍兵面前議論，說：「這些弱小的猶太人在做什麼呢？難道他們要憑自己修復城牆嗎？難道他們要獻祭嗎？他們要在一天之內完工嗎？他們要從灰土堆中使那些被燒毀的石頭復原嗎？」</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 2:19; 列王紀上 20:10; 尼希米記 2:10"> 亞捫人托比亞在他旁邊也說：「是啊，他們所建造的石牆，就算一隻狐狸上去，也能踩塌！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 79:12; 詩篇 123:3–4; 箴言 3:34"> 我們的神哪，求你垂聽，因為我們被藐視！求你使他們的辱罵回到自己頭上，使他們成為掠物被擄到外地。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 109:14; 耶利米書 18:23; 詩篇 69:27–28"> 不要遮蓋他們的罪孽，不要從你面前抹掉他們的罪，因為他們在建造的人面前挑釁。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比書 2:13; 尼希米記 6:15; 希伯來書 13:21"> 這樣，我們建造城牆，整個城牆都連起來了，並且達到一半的高度，因為民眾都用心做工。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米記 2:10; 尼希米記 4:1; 使徒行傳 5:33"> 那時叁巴拉和托比亞，以及阿拉伯人、亞捫人和阿實突人聽說耶路撒冷城牆的修復工作還在進行，破口開始被堵上了，他們就非常惱火。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 83:3–11; 以賽亞書 8:9–10; 耶利米書 20:10"> 他們所有人一同密謀，要來攻打耶路撒冷，製造混亂。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 5:8; 使徒行傳 4:24–30; 詩篇 50:15"> 於是我們向我們的神禱告，並因他們的緣故派守衛站崗，日夜防備他們。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 11:1–2; 哈該書 1:2; 歷代志下 2:18"> 但猶大人說：「搬運工已經筋疲力竭，灰土卻還有許多，我們不能繼續建造城牆了！」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 5:2; 使徒行傳 23:12; 詩篇 56:6"> 我們的敵人說：「我們要趁著他們還不知道，還沒察覺，就進入他們中間殺了他們，使這工程終止。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:7; 創世記 31:41; 民數記 14:22"> 那時，住在那些人附近的猶太人也十次來告訴我們，他們在策劃各種陰謀對付我們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他們在策劃各種陰謀對付我們——或譯作「無論我們轉向哪裡，他們都會攻擊我們」。">b</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:17–18; 以弗所書 6:11–20; 雅歌 3:7–8"> 於是我讓民眾在城牆後面那些低窪的空地站崗，讓他們按著家族，帶著刀劍、長矛和弓箭站著。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 10:12; 民數記 14:9; 以賽亞書 41:10–14"> 我檢閱後，起來對貴族、官長們以及其餘的民眾說：「不要怕他們。你們當記住我們大而可畏的主，要為你們的兄弟、兒女、妻子和你們的家業爭戰！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 17:14; 羅馬書 12:11; 約伯記 5:12–13"> 那時，我們的仇敵聽說我們知道了這事，神也破壞了他們的計謀。於是我們都回到城牆那裡，各自回到自己的工作上。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 4:23; 詩篇 101:6; 尼希米記 5:15–16"> 從那天起，我的下屬有一半做工，一半裝備著長矛、盾牌、弓箭和鎧甲；首領們跟在猶大全家後面。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 6:7; 提摩太後書 4:7; 提摩太後書 2:3"> 那些建造城牆的人和背負重物的搬運工，都一手做工，一手握著兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 10:9; 歷代志下 13:12–17"> 建造的人各自腰間佩著刀劍建造，吹角的人在我旁邊。</span>
<span className="v" id="v19" data-v="19"> 我對貴族、官長們以及其餘的民眾說：「這工程浩大寬廣，我們在城牆上彼此分散得很遠。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 14:14; 申命記 1:30; 申命記 20:4"> 你們無論在什麼地方聽見號角聲，都要聚集到我們這裡。我們的神必為我們爭戰。」</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 6:9; 歌羅西書 1:29; 哥林多前書 15:58"> 這樣我們繼續做工，一半的人握著長矛，從天亮的時候直到星辰出現。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 11:1–2"> 那時，我還對民眾說：「你們各人和你們的下屬要在耶路撒冷城中過夜，這樣可以夜間守城，白天做工。」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 9:48; 尼希米記 7:2; 哥林多前書 15:10"> 於是我和我的兄弟們、我的下屬，以及跟隨我的守衛們，沒有一個人脫下衣服，各人喝水時也拿著<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="拿著——輔助詞語。">c</a></sup>兵器。</span>
</div>
</div>

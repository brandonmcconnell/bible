<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 7:6; 尼希米記 3:26; 歷代志下 34:15"> 那時，全體民眾如同一人聚集到水門對面的廣場上。他們請經文士以斯拉將耶和華頒布給以色列的摩西律法書帶來。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:24; 瑪拉基書 2:7; 民數記 29:1"> 七月一日，祭司以斯拉將律法書帶到會眾——男人、女人以及所有能聽明白的人面前。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:22; 啟示錄 2:29; 希伯來書 2:1–3"> 他在水門前的廣場那裡，從天亮到中午，在男人、女人以及那些能明白的人面前，宣讀這律法書，全體民眾都側耳傾聽。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 10:29; 尼希米記 12:13; 尼希米記 10:20"> 經文士以斯拉站在為這事製作的木臺上，他旁邊站著的，右邊是瑪塔提雅、示瑪、亞奈雅、烏利亞、希勒加和瑪西雅，左邊是皮達雅、米沙利、瑪基雅、哈書姆、哈示巴達納、撒迦利亞和米書蘭。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 3:20; 列王紀上 8:14; 路加福音 4:16–17"> 以斯拉在全體民眾眼前打開書卷，當時他在全體民眾的上方。他一打開書卷，全體民眾都站了起來。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 2:8; 耶利米哀歌 3:41; 出埃及記 4:31"> 以斯拉頌讚耶和華偉大的神，全體民眾高舉雙手回應：「阿們，阿們！」然後俯身，臉伏於地向耶和華下拜。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米記 9:4; 利未記 10:11; 尼希米記 3:23"> 耶書亞、巴尼、示利比、雅憫、阿庫布、沙比泰、霍迪亞、瑪西雅、基利達、亞撒利雅、約撒巴、哈南、佩拉雅等利未人，向民眾教導律法，民眾都站在自己的位置上。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:45; 使徒行傳 28:23; 路加福音 24:32"> 這些人宣讀神的律法書，講解闡釋，使民眾明白所誦讀的。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 7:65; 尼希米記 7:70; 申命記 12:12"> 省長尼希米和祭司經文士以斯拉，以及那些教導民眾律法的利未人，對全體民眾說：「今天是你們的神耶和華的聖日，你們不要悲慟，不要哭泣。」這是因為全體民眾聽見律法上的話語時，都哭了。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 28:7–8; 箴言 17:22; 哥林多後書 12:8–9"> 以斯拉對他們說：「你們去吃美食、喝美酒吧，也分一些給那些無法為自己預備的人，因為今天是我們主的聖日。你們不要憂傷，因為耶和華所賜的喜樂是你們的保障。」</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 13:30"> 利未人也讓全體民眾平靜下來，說：「大家安靜！今天是聖日，你們不要憂傷。」</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 119:174; 詩篇 119:111; 詩篇 119:130"> 於是全體民眾都去吃喝，也送食物給人，並且舉行了盛大的慶祝，因為他們明白了那些教導給他們的內容。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 2:1–6; 箴言 8:33–34; 箴言 12:1"> 第二天，全體民眾的父系首領們、祭司和利未人都聚集到經文士以斯拉那裡，為要查考律法上的話。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:34; 申命記 16:13–15; 利未記 23:40–43"> 他們發現律法上記著：耶和華藉著摩西吩咐以色列子民，要在七月的節期住在棚子裡，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 23:40; 申命記 16:16; 利未記 23:4"> 並要在他們各城和耶路撒冷通告、傳令說：「你們要上山去，帶回來橄欖樹的枝子、野橄欖樹的枝子、香桃木的枝子、棕櫚樹的枝子以及各種茂密樹的枝子，搭建棚子，正如律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="律法——輔助詞語。">a</a></sup>上所記的。」</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 12:39; 列王紀下 14:13; 尼希米記 12:37"> 於是民眾出去，帶回來枝子，在自己家屋頂上、院子裡，在神殿的庭院裡，在水門的廣場上，在以法蓮門的廣場上，各人為自己搭了棚子。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 8:13; 以斯拉記 3:4; 歷代志下 7:8–10"> 從流亡之地回歸的全體會眾都搭了棚子，住在棚子裡。自從嫩的兒子約書亞的日子直到這天，以色列子孫都沒有這樣做過，那時有極大的歡慶。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 29:35; 利未記 23:36; 申命記 31:10–13"> 從第一天到最後一天，以斯拉每天宣讀神的律法書。他們守節期七天，然後照著規定在第八天舉行了嚴肅集會。</span>
</div>

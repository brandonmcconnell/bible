<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 12:39; 耶利米書 31:38; 約翰福音 5:2"> 那時，大祭司以利亞實起來，與他的兄弟眾祭司建造羊門。他們把它分別為聖，安裝門扇；從百樓到哈楠業樓，也都分別為聖了。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 7:36; 以斯拉記 2:34; 尼希米記 10:12"> 在他旁邊的一段，由耶利哥人建造。在耶利哥人旁邊的一段，由伊姆利的兒子扎克爾建造。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 33:14; 尼希米記 12:39; 西番雅書 1:10"> 哈西納的子孫建造魚門；他們為它架上木梁，安裝門扇、門鎖和門閂。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 8:33; 尼希米記 3:21; 尼希米記 10:7"> 在他們旁邊的一段，由哈克茲的孫子、烏利亞的兒子米利莫修建。在他們旁邊的一段，由米示薩別的孫子、比利迦的兒子米書蘭修建。在他旁邊的一段，由巴納的兒子撒督修建。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 3:27; 撒母耳記下 14:2; 耶利米書 27:2"> 在他們旁邊的一段，由提克亞人修建，不過他們的貴族沒有承擔他們主的工作。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米記 12:39"> 帕西亞的兒子耶赫亞達和貝索德雅的兒子米書蘭修建古門；他們為它架上木梁，安裝門扇、門鎖和門閂。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:2; 約書亞記 9:3–27; 尼希米記 3:19"> 在他們旁邊的一段，由基遍人米拉提和米倫人雅敦修建，他們是大河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼發拉底河。">a</a></sup>對岸的省長所管轄的基遍和米斯巴的人。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 12:38; 尼希米記 3:31–32; 創世記 50:2"> 在他們旁邊的一段，由赫爾哈雅的兒子銀匠烏基業修建。在他旁邊的一段，由調制香膏的匠人哈納尼雅修建。他們修復耶路撒冷，直到寬牆。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米記 3:12; 尼希米記 3:17"> 在他們旁邊的一段，由戶珥的兒子，就是耶路撒冷半個行政區的長官勒法雅修建。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 3:28–30; 尼希米記 10:4; 尼希米記 3:23"> 在他們旁邊的一段，由哈路瑪的兒子耶達雅在自己家對面修建。在他旁邊的一段，由哈沙尼的兒子哈突施修建。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 12:38; 以斯拉記 2:6; 尼希米記 10:14"> 哈琳的兒子瑪基雅和帕哈摩押的兒子哈述修建另一段，包括爐樓。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 3:9; 使徒行傳 21:8–9; 出埃及記 35:25"> 在他們旁邊的一段，由哈羅赫施的兒子，就是耶路撒冷另半個行政區的長官沙勒姆和他的女兒們修建。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米記 2:13; 約書亞記 15:34; 歷代志下 26:9"> 哈嫩和撒挪亞的居民修建谷門；他們建造它，安裝門扇、門鎖和門閂，又修建一千肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一千肘——相當於457公尺。1肘=45.7公分。">b</a></sup>城牆，直到糞場門。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 6:1; 尼希米記 2:13; 尼希米記 3:12–13"> 利甲的兒子，就是伯哈基琳行政區的長官瑪基雅修建糞場門；他建造它，安裝門扇、門鎖和門閂。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 9:7; 以賽亞書 8:6; 尼希米記 12:37"> 科爾霍澤的兒子，就是米斯巴行政區的長官沙崙修建泉門。他建造泉門，給它封頂，安裝門扇、門鎖和門閂，又建造王室園子旁邊西羅亞池那裡的城牆，直到從大衛城伸下來的臺階。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:29; 尼希米記 3:9; 列王紀下 20:20"> 在他之後的一段，由押布的兒子，就是伯促爾半個行政區的長官尼希米修建，直到大衛的墳墓對面，又到蓄水池，又到勇士之家。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 15:44; 尼希米記 3:16; 撒母耳記上 23:1–13"> 在他之後的一段，由利未人巴尼的兒子利戶姆修建。在他旁邊的一段，是由基伊拉半個行政區的長官哈沙比雅為自己的行政區修建。</span>
<span className="v" id="v18" data-v="18"> 在他之後的一段，由他們的兄弟希納達的兒子賓努伊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="賓努伊——輔助詞語。">c</a></sup>，就是基伊拉另半個行政區的長官巴瓦伊修建。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 26:9; 尼希米記 10:9; 尼希米記 12:8"> 在他旁邊的另一段，由耶書亞的兒子，就是米斯巴的首領以謝爾，從城牆凸角的兵器庫上坡對面修建。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米記 3:1; 傳道書 9:10; 羅馬書 12:11"> 在他之後的另一段，由撒該的兒子巴錄克熱心修建，從城牆凸角直到大祭司以利亞實的家門口。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 7:63; 以斯拉記 2:61"> 在他之後的另一段，由哈克茲的孫子、烏利亞的兒子米利莫修建，從以利亞實的家門口直到以利亞實家的盡頭。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:28; 尼希米記 6:2"> 在他之後的一段，由那些來自周邊地區的祭司修建。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米記 10:2; 尼希米記 8:4; 尼希米記 3:29–30"> 在他們之後的一段，由便雅憫和哈述在自己的家對面修建。在他們之後的一段，由亞納尼亞的孫子、瑪西雅的兒子亞撒利雅在自己的家旁邊修建。</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米記 3:19; 尼希米記 3:27; 尼希米記 10:9"> 在他之後的另一段，由希納達的兒子賓努伊修建，從亞撒利雅的家直到城牆的凸角，又到城角。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 32:2; 耶利米書 37:21; 尼希米記 12:39"> 烏扎伊的兒子帕拉爾是從城牆凸角的對面，以及護衛兵院子旁邊、王宮上層凸出來的塔樓那裡修建。在他之後的一段，由帕羅示的兒子皮達雅，</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米記 8:1; 尼希米記 11:21; 尼希米記 12:37"> 以及住在俄斐勒的聖殿僕役修建，直到東邊的水門對面和凸出來的塔樓那裡。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 3:5"> 在他們之後的另一段，由提克亞人修建，從凸出來的大塔樓對面直到俄斐勒的城牆。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="歷代志下 23:15; 耶利米書 31:40; 列王紀下 11:16"> 從馬門往上，由祭司們各自在自己的家對面修建。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 19:2; 以斯拉記 2:37; 尼希米記 7:40"> 在他們之後的一段，由伊梅爾的兒子撒督在自己的家對面修建。在他之後的一段，由謝喀尼亞的兒子示瑪雅修建，他是東門的守衛。</span>
<span className="v" id="v30" data-v="30"> 在他之後的另一段，由示勒米雅的兒子哈納尼雅和薩勒弗的第六個兒子哈嫩修建。在他們之後的一段，由比利迦的兒子米書蘭在自己的房間對面修建。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 3:8; 尼希米記 3:32"> 在他之後的一段，由銀匠瑪基雅修建，直到檢閱門對面聖殿僕役和客商的住房那裡，又到角樓。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 3:1; 約翰福音 5:2; 尼希米記 12:39"> 在角樓與羊門之間的一段，由銀匠們和客商修建。</span>
</div>
</div>

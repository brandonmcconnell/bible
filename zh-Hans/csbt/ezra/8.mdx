<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 7:7; 以斯拉記 2:62; 歷代志上 9:1"> 亞達薛西王在位時，與我一同從巴比倫上來的人，他們各父系的首領和家譜記錄如下：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志上 3:22; 歷代志上 3:1; 歷代志上 6:3–15"> 非尼哈的子孫，有革順；<br />以塔瑪爾的子孫，有但以理；<br />大衛的子孫，有哈突施，</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 2:3; 尼希米記 10:14; 尼希米記 7:8"> 屬於謝喀尼亞的後裔；<br />帕羅示的子孫，有撒迦利亞，以及與他一起記錄在家譜中的男子一百五十人；</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 2:6; 尼希米記 10:14; 尼希米記 7:11"> 帕哈摩押的子孫，有西拉希雅的兒子以利約奈，以及與他一起的男子兩百人；</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 薩圖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="薩圖——依據七十士譯本；馬索拉文本此處缺失名字。">a</a></sup>的子孫，有雅哈希的兒子謝喀尼亞，以及與他一起的男子三百人；</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 2:15; 尼希米記 10:16; 尼希米記 7:20"> 阿丁的子孫，有約拿單的兒子伊別德，以及與他一起的男子五十人；</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 2:31; 尼希米記 7:34; 以斯拉記 2:7"> 以攔的子孫，有亞塔利雅的兒子耶賽亞，以及與他一起的男子七十人；</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:4; 以斯拉記 2:4; 尼希米記 7:9"> 示法提雅的子孫，有米迦勒的兒子希巴迪亞，以及與他一起的男子八十人；</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米記 7:11; 以斯拉記 2:6"> 約押的子孫，有耶希業的兒子俄巴底亞，以及與他一起的男子兩百一十八人；</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 巴尼<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巴尼——依據七十士譯本；馬索拉文本此處缺失名字。">b</a></sup>的子孫，有約細斐的兒子示羅米，以及與他一起的男子一百六十人；</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 10:28; 尼希米記 7:16; 以斯拉記 2:11"> 比巴伊的子孫，有比巴伊的兒子撒迦利亞，以及與他一起的男子二十八人；</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 2:12; 尼希米記 7:17"> 阿茲伽德的子孫，有哈卡坦的兒子約哈南，以及與他一起的男子一百一十人；</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 2:13; 尼希米記 7:18"> 亞多尼卡姆的子孫是隨後來的，他們的名字是以利菲烈、耶烏利、示瑪雅，與他們一起的男子有六十人；</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米記 10:12; 以斯拉記 2:14; 尼希米記 7:19"> 比格瓦伊的子孫，有烏塔伊和扎克爾，以及與他們一起的男子七十人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 8:21; 以斯拉記 8:31; 以斯拉記 7:7"> 我把他們聚集到流向亞哈瓦的那條河邊，我們在那裡紮營三天。我在民眾和祭司中仔細查找，卻在那裡沒有找到一個利未子孫。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉記 8:18; 以斯拉記 10:39"> 於是我派遣以利以謝、亞利伊勒、示瑪雅、以利拿單、雅立、以利拿單、拿單、撒迦利亞和米書蘭這些首領，以及教師約雅立和以利拿單。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 2:43; 出埃及記 4:15; 民數記 8:22–26"> 我吩咐他們去見卡西非亞地區的首領易多，並交代他們要對易多和他在卡西非亞地區作聖殿僕役的兄弟們說什麼話，好為我們神的殿帶回來一些事奉的人。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 3:15; 以斯拉記 7:28; 尼希米記 2:8"> 因著我們的神施恩的手幫助我們，他們就從以色列之子利未的孫子瑪赫利的後裔中，給我們帶回來一個明達人示利比，以及他的兒子們和兄弟們十八人；</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 6:1; 歷代志上 6:16; 尼希米記 10:11"> 還有哈沙比雅，並與他一起的米拉利子孫耶賽亞，以及他的兄弟們和他們的兒子二十人；</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 2:43; 以斯拉記 7:7; 歷代志上 9:2"> 還有一些聖殿僕役，是大衛和首領們從前所委派服事利未人的聖殿僕役的子孫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的子孫——輔助詞語。">c</a></sup>，共有兩百二十人。他們全都被列入了名單。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 20:3; 約珥書 1:14; 撒母耳記上 7:6"> 那時我在亞哈瓦河邊宣告禁食，要在我們的神面前謙卑下來，為我們和我們的家屬以及我們所擁有的一切，向神祈求平安的行程。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 3:12; 詩篇 33:18–19; 歷代志下 16:9"> 我羞於求王派出軍隊和馬兵幫助我們對付路上的敵人，因為我們已經告訴王說：「我們神施恩的手必幫助所有尋求他的人，他的大能和怒氣必攻擊所有離棄他的人。」</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 29:12–13; 馬太福音 7:7–8; 以斯拉記 8:31"> 我們為此禁食，向我們的神祈求，他就應允了我們的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 8:18–19"> 我從祭司首領中分別出來十二個人，就是示利比、哈沙比雅，以及他們兄弟中與他們同工的十個人。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 8:33; 以斯拉記 7:14–16; 以斯拉記 1:8"> 我把那些金銀和器皿，就是王和內閣大臣們、首領們以及所有在巴比倫的以色列人獻給我們神殿的供物，都稱了交給他們。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 1:9–11"> 我稱出來交到他們手中的，有：銀子六百五十他連得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="六百五十他連得——相當於22.2公噸。1他連得=34.2公斤。">d</a></sup>，銀器一百他連得<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一百他連得——相當於3.4公噸；下同。">e</a></sup>，金子一百他連得；</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 金碟二十個，值一千達利克<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一千達利克——相當於8.4公斤金子。1達利克金幣=8.4公克。">f</a></sup>；拋光的上等銅器兩個，珍貴如金。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 22:2–3; 利未記 21:6–8; 歷代志上 23:28"> 那時，我對他們說：「你們是歸於耶和華為聖的，這些器皿也是神聖的，這些金銀是甘心奉獻物，歸於耶和華你們祖先的神。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉記 8:33–34; 馬可福音 13:34–35; 歷代志上 26:20–26"> 你們當警醒看守，直到你們在耶路撒冷耶和華殿的庫房，在祭司和利未人的首領們以及以色列各父系首領面前，把它們都過了秤。」</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉記 8:22; 歷代志上 29:2–3; 以賽亞書 60:13"> 於是祭司和利未人接收了這些稱量過的金銀和器皿，要帶到耶路撒冷我們神的殿。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉記 8:21–22; 以斯拉記 7:9; 以斯拉記 8:15"> 一月十二日，我們從亞哈瓦河邊起程，往耶路撒冷去。我們神的手幫助了我們，保守我們避開敵人和路上埋伏之人的手。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 2:11; 以斯拉記 7:8–9"> 我們來到耶路撒冷，在那裡歇息了三天。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米記 3:4; 尼希米記 3:21; 以斯拉記 8:30"> 第四天，在我們神的殿中，我們把金銀和器皿過了秤，然後交到祭司烏利亞的兒子米利莫手中，與他同工的有非尼哈的兒子以利亞撒，還有利未人耶書亞的兒子約撒巴和賓努伊的兒子挪亞迪。</span>
<span className="v" id="v34" data-v="34"> 這一切都核對了數目和重量，重量全都在當時記下來了。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以斯拉記 6:17; 歷代志下 29:31–32; 詩篇 66:10–15"> 從流亡之地回歸的那些擄民，向以色列的神獻上了燔祭：為全體以色列人獻上公牛十二頭，公綿羊九十六隻，公羊羔七十七隻，贖罪祭公山羊十二隻；這都是獻給耶和華的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以斯拉記 7:21–24; 以斯拉記 4:7–23; 以斯拉記 6:13"> 他們也把王的法令交給王的行政官們和大河<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大河——指幼發拉底河。">g</a></sup>對岸的省長們，這些人就資助以色列民和神的殿。</span>
</div>

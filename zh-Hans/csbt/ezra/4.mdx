<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 22:9–10; 以斯拉記 1:11; 以斯拉記 10:16"> 猶大和便雅憫的敵人聽說那些回歸的擄民在為以色列的神耶和華重建聖殿，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 19:37; 列王紀下 17:24; 加拉太書 2:4"> 就來見所羅巴伯和各父系的首領，對他們說：「讓我們與你們一同建造吧！我們也像你們一樣尋求你們的神，從亞述王以撒哈頓把我們遷到這裡的日子以來，我們一直都向你們的神獻祭。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="尼希米記 2:20; 馬太福音 10:16; 歷代志下 36:22–3"> 但所羅巴伯和耶書亞以及以色列其餘的父系首領對他們說：「我們為我們的神建造殿宇，與你們無關；我們是照著波斯的王——居魯士王所吩咐的，要自己為以色列的神耶和華建造。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 3:3; 尼希米記 6:9; 耶利米書 38:4"> 於是，當地的人就使猶大民眾的手發軟，阻撓他們建造，</span>
<span className="v" id="v5" data-v="5" data-xref="那鴻書 1:11; 以斯拉記 5:5–18; 詩篇 2:1–2"> 還收買官員來反對他們，破壞他們的工程計劃。在波斯王居魯士所有的日子裡，一直到波斯王大流士在位時，都是這樣。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 1:1; 但以理書 9:1; 使徒行傳 24:5–9"> 亞哈隨魯王在位初期，那些人寫了一封控告信，指控猶大和耶路撒冷的居民。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 18:26; 但以理書 2:4; 以賽亞書 36:11"> 亞達薛西年間，比施蘭、米特利達、塔別以及他們其餘的同僚，上書波斯王亞達薛西，公文的文書是用亞蘭語寫下、用亞蘭語轉述的。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:9; 撒母耳記下 8:17; 撒母耳記下 20:25"> 行政長官利戶姆和書記希姆沙伊也給亞達薛西王寫了一封指控耶路撒冷的奏章：</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 5:6; 以斯拉記 6:6; 列王紀下 17:24"> 「謹有行政長官利戶姆、書記希姆沙伊和他們其餘的同僚，司法官、行政官員、各級官員，波斯人、烏魯克人、巴比倫人、蘇薩人——就是以攔人，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 4:17; 以斯拉記 4:11; 以斯拉記 7:12"> 以及其餘的民族，就是被偉大尊貴的亞斯納巴遷移，安置在撒瑪利亞城和幼發拉底河對岸其餘地區的民族，現在</span>
<span className="v" id="v11" data-v="11"> 有呈送給王的奏章副本如下：<br />致亞達薛西王，<br />我們是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我們是——輔助詞語。">a</a></sup>你的臣民，是幼發拉底河對岸地區的人。現在</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 5:9; 歷代志下 36:13; 以斯拉記 5:3"> 願王知道，從王那裡上到我們這裡的猶太人，已經到了耶路撒冷，正在重建這座邪惡、反叛的城，就要建好城牆，打好根基了。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 7:24; 羅馬書 13:6–7; 尼希米記 5:4"> 如今願王知道，如果這城被重建，城牆被建好，他們就不會交納稅捐、貢物和路稅了，王的財政收入就會受損。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 19:12–15; 以西結書 33:31; 約翰福音 12:5–6"> 如今我們既然吃宮廷的鹽，就不應該看著王蒙受虧損<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="蒙受虧損——原文直譯「蒙羞」。">b</a></sup>，因此我們上奏稟告，</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 4:12; 以斯帖記 3:5–8; 列王紀下 24:20–1"> 請王調查先王的記事檔案，從記事檔案中查找，就會明白這城是反叛之城，曾使君王和各省受損。從久遠的日子以來，這城就常常發生叛亂，因此才被摧毀。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 4:20; 列王紀上 4:24; 撒母耳記下 8:3"> 我們稟告王：如果這城被重建，城牆被建好，那麼王在幼發拉底河對岸地區必將一無所有。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:7; 以斯拉記 5:7; 以斯拉記 4:9–11"> 王就發諭旨給行政長官利戶姆、書記希姆沙伊和他們其餘的同僚，就是住在撒瑪利亞和幼發拉底河對岸其餘地區的人：<br />「願你們平安！<br />現在</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 8:8"> 你們呈送來的公函，已經在我面前清楚地誦讀了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 18:7; 箴言 25:2; 申命記 13:14"> 我已下令調查，查出這城從久遠的日子以來就常常背叛王，發生造反和叛亂的事。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 15:18; 列王紀上 4:21; 歷代志上 18:3"> 從前有強勢的君王管理耶路撒冷，有掌權者治理整個幼發拉底河對岸地區，那時稅捐、貢物和路稅都交給了他們。</span>
<span className="v" id="v21" data-v="21"> 現在你們要命令這些人停工；我若不下令，這城就不可重建。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 7:3–4; 以斯帖記 3:8–9; 以斯拉記 4:13"> 你們當謹慎，做這件事不可疏忽。何必讓損害增加，使王受虧損呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="羅馬書 3:15; 彌迦書 2:1; 以斯拉記 4:17"> 亞達薛西王的公函副本在利戶姆、書記希姆沙伊和他們的同僚面前誦讀後，他們就急忙前往耶路撒冷，到猶太人那裡去，以強權和武力使他們停工。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哈該書 1:15; 尼希米記 6:9; 以斯拉記 5:5"> 這樣，耶路撒冷的神殿工程就停工了，一直停工到波斯王大流士執政的第二年。</span>
</div>
</div>

</div>

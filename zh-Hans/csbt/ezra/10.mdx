<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:20; 詩篇 119:136; 羅馬書 9:2"> 以斯拉禱告、認罪，俯伏在神的殿前面哭泣的時候，以色列的廣大會眾——男人、女人和孩子，都聚集到他那裡，人們也痛哭流涕。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 13:27; 以斯拉記 9:2; 耶利米書 3:12–13"> 以攔的子孫耶希業的兒子謝喀尼亞就對以斯拉說：「我們對我們的神不忠，從當地百姓中娶了外邦女子。雖然這樣，以色列還有希望。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:2–3; 以斯拉記 9:4; 約書亞記 23:12–13"> 現在讓我們與我們的神立約吧，按著我主與那些因我們神的誡命而戰兢的人的意見，送走那些女人和她們所生的；這事要照著律法處理。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:10; 傳道書 9:10; 希伯來書 12:12–13"> 起來，這件事要靠你了；我們與你同心，你要堅強行事！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米記 13:25; 尼希米記 5:12; 箴言 9:9"> 於是以斯拉起來，讓眾祭司首領、利未人和全體以色列人都起誓要照著這話語去做。他們就起了誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 9:18; 尼希米記 3:1; 尼希米記 12:22"> 隨後，以斯拉從神的殿前面起身，來到以利亞實的兒子約哈南的房間。他待在那裡，不吃飯也不喝水，為那些擄民的不忠而極其悲慟。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 1:1; 歷代志下 30:5"> 他們在猶大和耶路撒冷通告所有回歸的擄民，要他們聚集到耶路撒冷，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 7:26; 約翰福音 9:22; 士師記 21:5"> 任何人不照著首領和長老們所商議的在三天之內來到，他的一切財物都要成為奉獻物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="成為奉獻物——或譯作「被沒收充公」。">a</a></sup>，他自己也要從回歸的擄民會眾當中被革除。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 12:17–18; 耶利米書 10:13; 以斯拉記 7:8–9"> 於是，猶大和便雅憫的所有男人三天內都聚集到耶路撒冷。那是在九月的二十日，全體民眾坐在神殿的廣場上，他們因這事，又因下雨，都戰戰兢兢。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 9:6; 民數記 32:14; 馬太福音 23:32"> 祭司以斯拉起身，對他們說：「你們不忠，娶了外邦女子，以致增添了以色列的罪責。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 12:2; 以斯拉記 10:3; 以賽亞書 1:16–18"> 現在，你們要向你們祖先的神耶和華認罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="認罪——原文直譯「獻上感謝」。">b</a></sup>，遵行他的旨意，與當地百姓和外邦女子分別開來。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米記 13:23; 詩篇 78:57; 以斯拉記 10:3–4"> 全體會眾大聲回應說：「我們必照著你的話去做。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 10:18–44; 馬太福音 7:13–14"> 不過民眾很多，這時候又下雨，我們不能站在外面；而且這不是一天、兩天的事，因為在這事上我們有許多人犯罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有許多人犯罪——或譯作「犯了大罪」。">c</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 29:10; 歷代志下 30:8; 民數記 25:4"> 請讓我們的首領們代表全體會眾留下來，以後讓我們各城所有娶了外邦女子的人，在指定的時候與各城的長老和審判官們一同前來。這樣，我們的神因這事而發的烈怒就會轉消。」</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 11:16; 尼希米記 10:20; 尼希米記 12:33"> 只有亞撒暉的兒子約拿單和提克瓦的兒子雅哈謝反對這事，米書蘭和利未人沙比泰也支持他們。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約伯記 29:16; 申命記 13:14; 約翰福音 7:51"> 於是，回歸的擄民就這樣做。祭司以斯拉把各父系首領中的一些人，按著他們的父家分別出來，並且全都列入了名單。他們在十月一日坐下來調查這事，</span>
<span className="v" id="v17" data-v="17"> 直到一月一日，調查完了所有娶外邦女子的男人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 5:2; 以斯拉記 3:2; 撒迦利亞書 3:1"> 祭司的子孫中，查出娶了外邦女子的是：<br />約薩達的兒子耶書亞和他兄弟們的子孫中，有瑪西雅、以利以謝、雅立、基大利；</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 6:6; 列王紀下 10:15; 歷代志下 30:8"> 他們舉手承諾要送走他們的妻子，並且認罪，為自己的罪獻上了一隻公綿羊。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 2:37; 歷代志上 24:14; 尼希米記 7:40"> 伊梅爾的子孫中，有哈納尼、希巴迪亞。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志上 24:8; 以斯拉記 2:39; 尼希米記 7:42"> 哈琳的子孫中，有瑪西雅、以利亞、示瑪雅、耶希業、烏西雅。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歷代志上 9:12; 尼希米記 7:41; 以斯拉記 2:38"> 帕示戶珥的子孫中，有以利約奈、瑪西雅、以實瑪利、拿旦業、約撒巴、以利亞薩。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米記 10:10; 尼希米記 11:16; 以斯拉記 8:33"> 利未人中，有約撒巴、示每、基拉雅——就是基利達，還有佩塔希雅、猶大、以利以謝。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 歌手中，有以利亞實。<br />門衛中，有沙勒姆、特勒姆、烏利。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 2:3; 尼希米記 7:8"> 還有一些以色列人：<br />帕羅示的子孫中，有拉姆亞、耶基雅、瑪基雅、米雅憫、以利亞撒、瑪基雅、比納雅。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 10:2; 以斯拉記 2:31; 尼希米記 7:12"> 以攔的子孫中，有瑪塔尼亞、撒迦利亞、耶希業、阿伯迪、耶利莫、以利亞。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="尼希米記 7:13; 以斯拉記 2:8"> 薩圖的子孫中，有以利約奈、以利亞實、瑪塔尼亞、耶利莫、撒巴德、阿茲扎。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以斯拉記 8:11; 以斯拉記 2:11; 尼希米記 7:16"> 比巴伊的子孫中，有約哈南、哈納尼雅、扎巴伊、阿特萊。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="尼希米記 7:15; 尼希米記 10:4; 以斯拉記 2:10"> 巴尼的子孫中，有米書蘭、瑪盧克、亞達雅、雅實布、謝阿勒、耶利莫。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以斯拉記 8:4; 尼希米記 7:11; 以斯拉記 2:6"> 帕哈摩押的子孫中，有阿德納、基拉、比納雅、瑪西雅、瑪塔尼亞、比撒列、賓努伊、瑪拿西。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 3:11; 尼希米記 7:35; 以斯拉記 2:32"> 哈琳的子孫中，有以利以謝、伊示亞、瑪基雅、示瑪雅、西緬、</span>
<span className="v" id="v32" data-v="32"> 便雅憫、瑪盧克、示瑪利雅。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以斯拉記 2:19; 尼希米記 7:22"> 哈書姆的子孫中，有瑪特奈、瑪特塔、撒巴德、以利菲烈、耶利邁、瑪拿西、示每。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 巴尼的子孫中，有瑪阿代、阿姆蘭、烏伊勒、</span>
<span className="v" id="v35" data-v="35"> 比納雅、比迪雅、克錄希、</span>
<span className="v" id="v36" data-v="36"> 瓦尼亞、米利莫、以利亞實、</span>
<span className="v" id="v37" data-v="37"> 瑪塔尼亞、瑪特奈、雅阿蘇、</span>
<span className="v" id="v38" data-v="38"> 巴尼、賓努伊、示每、</span>
<span className="v" id="v39" data-v="39"> 示勒米雅、拿單、亞達雅、</span>
<span className="v" id="v40" data-v="40"> 瑪赫拿德拜、沙沙伊、沙拉伊、</span>
<span className="v" id="v41" data-v="41"> 阿扎列、示勒米雅、示瑪利雅、</span>
<span className="v" id="v42" data-v="42"> 沙勒姆、亞瑪利雅、約瑟。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="以斯拉記 2:29; 尼希米記 7:33"> 尼波的子孫中，有耶伊列、瑪塔提雅、撒巴德、錫彼納、伊度、約珥、比納雅。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; 以斯拉記 10:3; 箴言 2:16"> 這些人全都娶了外邦女子，其中有些人的妻子還生了兒女<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="其中有些人的妻子還生了兒女——或譯作「現在他們把妻子連同孩子都送走了」。">d</a></sup>。</span>
</div>

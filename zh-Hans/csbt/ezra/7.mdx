<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:1; 歷代志上 6:4–14; 以斯拉記 7:21"> 這些事以後，波斯王亞達薛西在位時，以斯拉回來了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="回來了——輔助詞語。">a</a></sup>——他是西萊雅的兒子，西萊雅是亞撒利雅的兒子，亞撒利雅是希勒加的兒子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 2:35; 撒母耳記下 8:17"> 希勒加是沙勒姆的兒子，沙勒姆是撒督的兒子，撒督是亞希突的兒子，</span>
<span className="v" id="v3" data-v="3"> 亞希突是亞瑪利雅的兒子，亞瑪利雅是亞撒利雅的兒子，亞撒利雅是米拉約的兒子，</span>
<span className="v" id="v4" data-v="4"> 米拉約是西拉希雅的兒子，西拉希雅是烏基的兒子，烏基是布其的兒子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 6:25; 歷代志下 26:20; 歷代志上 6:4"> 布其是亞比書的兒子，亞比書是非尼哈的兒子，非尼哈是以利亞撒的兒子，以利亞撒是大祭司亞倫的兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 8:22; 以斯拉記 7:28; 以斯拉記 8:31"> 這以斯拉從巴比倫上來，他是經文士，精通以色列的神耶和華所賜下的摩西律法。王准許了他所求的一切，因為他的神耶和華的手幫助他。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 8:1–20; 歷代志上 6:31–48; 歷代志上 9:17–27"> 這樣，在亞達薛西王第七年，一些以色列人、祭司、利未人、歌手、門衛和聖殿僕役，上耶路撒冷去。</span>
<span className="v" id="v8" data-v="8"> 亞達薛西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亞達薛西——輔助詞語。">b</a></sup>王第七年的五月，以斯拉來到了耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 7:6; 尼希米記 2:8; 尼希米記 2:18"> 他在一月一日從巴比倫起程上行，五月一日就來到耶路撒冷，是因他的神施恩的手幫助他。</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 2:7; 提摩太後書 4:2; 馬太福音 7:24"> 因為以斯拉立定了心志，要研讀並遵行耶和華的律法，並在以色列人中教導這些律例和法規。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 5:6; 以斯拉記 7:6; 馬太福音 23:2"> 亞達薛西王將公文的副本交給了以斯拉，他是祭司，是經文士，精通耶和華的誡命和賜給以色列的律例。公文副本如下：</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理書 2:37; 以西結書 26:7; 以斯拉記 4:17"> 「王中之王亞達薛西致祭司以斯拉，那精通<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="精通——輔助詞語。">c</a></sup>天上之神法令的經文士……<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="省略號——原文語義不明；或譯作「願你平安」。">d</a></sup><br />現在</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 6:1; 詩篇 148:6; 歷代志下 30:5"> 我下令：在我國中的以色列民以及他們的祭司和利未人，凡是甘願奉獻自己去耶路撒冷的，都可以與你一起去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 1:14; 以斯拉記 7:25–26; 以斯拉記 7:28"> 既然你從王和七位內閣大臣面前受了差派，照著你的神交託給你的法令去調查猶大和耶路撒冷的情況，</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 135:21; 歷代志下 6:2; 以斯拉記 6:12"> 並且帶去王和內閣大臣們甘願奉獻給住在耶路撒冷的以色列之神的金銀，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 29:6; 以斯拉記 1:4; 歷代志上 29:9"> 還有你在巴比倫全省得到的一切金銀，以及民眾和祭司們甘願奉獻給耶路撒冷他們神殿宇的奉獻物，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 12:5–11; 民數記 15:4–13; 以斯拉記 6:9–10"> 那麼，這些銀子要專用於購買公牛、公綿羊、公羊羔，以及同獻的素祭和酒祭，你要在耶路撒冷你們神殿的祭壇上把它們獻上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 22:7; 以弗所書 5:17; 列王紀下 12:15"> 其餘的金銀，你和你的兄弟們看怎樣好，就怎樣用，要照著你們神的旨意去做。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 3:17; 以斯拉記 8:33–34; 歷代志下 32:19"> 至於那些交給你，在你神的殿中事奉用的器皿，你要完全交付在耶路撒冷的神面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 6:4; 以斯拉記 6:8–18"> 你神的殿由你負責的其餘需用，你可以從王的府庫裡支取。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 4:16; 以斯拉記 7:6; 以斯拉記 7:10–13"> 我亞達薛西王向幼發拉底河對岸地區所有的司庫官下令：那精通<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="精通——輔助詞語。">e</a></sup>天上之神法令的經文士，祭司以斯拉，他向你們要求的一切，你們都要認真照辦；</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未記 2:13; 以西結書 45:14"> 銀子上限一百他連得<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一百他連得——相當於3.4公噸。1他連得=34.2公斤。">f</a></sup>，小麥上限一百柯珥<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一百柯珥——相當於22,000公升。1柯珥=220公升。">g</a></sup>，酒上限一百罷特<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一百罷特——相當於2,200公升；下同。1罷特=22公升。">h</a></sup>，油上限一百罷特，鹽不用記數。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:4; 以斯拉記 7:18; 以斯拉記 6:10–12"> 凡是天上之神所命令的，都要為天上之神的殿盡心執行。何必讓震怒臨到王和王子們的國土呢？</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 7:7; 以斯拉記 4:13; 以斯拉記 2:36–55"> 你們還要知道：對於所有的祭司、利未人、歌手、門衛、聖殿僕役，以及在神的這殿宇事奉的人，你們都無權向他們徵收稅捐、貢物和路稅。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 7:10; 申命記 16:18; 雅各書 1:5"> 至於你以斯拉，你要照著你的神賜予你的智慧，指派那些明白你神的法令的人作司法官和審判官，讓他們治理幼發拉底河對岸地區的所有百姓；你們也要教導那些不明白法令的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 6:11; 申命記 13:1–18; 利未記 20:1–27"> 任何人不遵行你神的法令和王的法令，他就要受到嚴厲的審判：或處死，或放逐，或沒收財產，或囚禁。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 6:22; 啟示錄 17:17; 以賽亞書 60:13"> 我們祖先的神耶和華是當受頌讚的！他把這樣的意念放在王的心中，為要使耶路撒冷耶和華的聖殿得榮耀。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 4:17–18; 以斯拉記 5:5; 創世記 32:28"> 他還在王和王的內閣大臣面前，以及王的所有高官面前向我施慈愛。這樣，因著我神耶和華的手幫助我，我就堅強，從以色列人中招聚首領們，與我一同上去。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦後書 3:1; 哥林多前書 15:2; 哥林多前書 15:58"> 弟兄們，你們自己知道，我們進到你們那裡並不是空無果效的；</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 16:22–24; 使徒行傳 4:13; 使徒行傳 17:2–9"> 相反，正如你們知道，雖然我們以前在腓立比受了苦、受了凌辱，但是靠著我們的神，我們還是放膽直言，在大爭戰中把神的福音傳給了你們。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 2:17; 哥林多後書 4:2; 帖撒羅尼迦前書 4:7"> 我們的勸勉不是出於迷惑<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="迷惑——或譯作「錯覺」。">a</a></sup>，不是出於汙穢，也不是用詭詐；</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:10; 羅馬書 8:27; 加拉太書 2:7"> 相反，我們怎樣被神考驗而受了福音的委託，我們就照樣傳講；不是要討人的喜悅，而是要討神的喜悅——神是考驗我們內心的。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 1:9; 哥林多後書 12:17; 使徒行傳 20:33"> 實際上，我們從來沒有用過諂媚的話，這是你們知道的；也沒有懷著貪婪的居心，這是神可以見證的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這是神可以見證的——原文直譯「神就是見證者」。">b</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 1:10; 帖撒羅尼迦前書 2:9; 約翰福音 5:41"> 無論向你們或向其他人，我們也都沒有尋求從人來的榮耀。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 66:13; 帖撒羅尼迦前書 2:11; 提摩太後書 2:24–25"> 我們身為基督的使徒，雖然可以加給你們重擔，但是我們在你們當中成了溫柔的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="溫柔的——有古抄本作「小孩子」。">c</a></sup>，就像哺乳的母親顧惜自己的兒女那樣。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰一書 3:16; 哥林多後書 12:15; 腓立比書 2:17"> 我們這樣眷愛你們，不僅樂意把神的福音分享給你們，連自己的生命<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="生命——原文直譯「靈魂」。">d</a></sup>也樂意分享給你們，因為你們成了我們所愛的人。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:7–9; 哥林多後書 11:9; 使徒行傳 18:3"> 弟兄們，你們記得我們的辛苦和勞碌：我們把神的福音傳給你們的時候，我們日夜做工，免得成為你們任何人的負擔。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 5:3; 帖撒羅尼迦前書 1:5; 哥林多後書 1:12"> 你們和神可以見證：我們對你們這些信的人是多麼聖潔、公義、無可指責的。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 4:14–15; 希伯來書 13:22; 提摩太前書 5:21"> 正如你們知道我們怎樣待你們每一個人，就像父親待自己的兒女那樣；</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:1; 約翰一書 2:6; 約翰一書 1:6–7"> 我們鼓勵你們，安慰你們，忠告你們，為要你們行事為人配得上那召喚你們進入他國度和榮耀的神。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="希伯來書 4:12; 羅馬書 10:17; 彼得前書 1:23"> 我們之所以也不住地感謝神，是因為你們接受了從我們所聽的神的話語，沒有把它看做人的話語，而是把它看做神的話語接受了；這確實是神的話語，而且它也正在你們這些信的人裡面做工。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 3:4; 希伯來書 10:33–34; 希伯來書 5:7–8"> 弟兄們，你們效法了猶太地區在基督耶穌裡屬神的各教會，因為你們也受了自己同胞的苦害，就像他們受了猶太人的苦害那樣。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:12; 路加福音 11:48–53; 使徒行傳 7:52"> 這些猶太人不但殺了主耶穌和<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「他們自己的」。">e</a></sup>先知們，也驅逐了我們，並且不討神的喜悅，又與所有的人作對，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:13; 使徒行傳 14:19; 馬可福音 16:16"> 阻止我們向外邦人傳道使外邦人得救。這樣，他們常常積滿自己的罪孽，而神的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神的——輔助詞語。">f</a></sup>震怒在最後臨到了他們身上！</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歌羅西書 2:5; 哥林多前書 5:3; 帖撒羅尼迦前書 3:6"> 弟兄們，我們被迫暫時與你們分離——身體分離，心卻沒有；我們非常渴望並且更加努力要見你們的面，</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 15:22; 羅馬書 1:13; 啟示錄 2:10"> 所以我們想要到你們那裡去。我保羅確實一再地要去，只是撒旦攔阻了我們。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 4:1; 帖撒羅尼迦前書 3:13; 腓立比書 2:16"> 我們主耶穌<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶穌——有古抄本作「耶穌基督」。">g</a></sup>來臨的時候，在主<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="主——原文直譯「他」。">h</a></sup>面前，到底誰是我們的盼望、喜樂和所誇耀的冠冕呢？難道不也是你們嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 1:14; 哥林多前書 11:7; 箴言 17:6"> 的確，你們就是我們的榮耀和喜樂。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="啟示錄 16:15; 彼得後書 3:10; 馬太福音 24:42–44"> 因為你們自己明確地知道，主的日子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="日子——指「基督再來的日子」。">a</a></sup>來臨，就像夜裡的賊來臨那樣。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 21:34–35; 馬太福音 24:37–39; 路加福音 17:26–30"> 當人們正說「和平」、「安全」的時候，毀滅那時就突然臨到他們，就像孕婦的臨產陣痛那樣，他們絕不能逃脫。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 2:8; 彼得後書 3:10; 申命記 19:6"> 不過弟兄們，你們不是在黑暗裡，以致那日子像賊一樣抓住你們。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 5:8; 使徒行傳 26:18; 約翰福音 12:36"> 因為你們都是光明的兒女，白晝的兒女。我們不屬於黑夜，也不屬於黑暗。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 1:13; 馬太福音 24:42; 路加福音 22:46"> 由此可見，我們不要像其他人那樣睡著了，而要警醒、謹慎。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 13:13; 哥林多前書 15:34; 彼得後書 2:13"> 因為睡覺的人是在夜裡睡，醉酒的人是在夜裡醉。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:12–13; 以弗所書 6:11; 彼得前書 1:13"> 但我們既然屬於白晝，就讓我們謹慎，以信與愛做為護胸甲穿上，以救恩的盼望做為頭盔戴上。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 1:10; 彼得前書 2:10; 提摩太後書 2:10"> 因為神不是預定我們到震怒裡面，而是預定我們藉著我們的主耶穌基督獲得救恩。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 14:8–9; 彼得前書 3:18; 羅馬書 8:34"> 基督替我們死，為要使我們無論是醒著還是睡著，都與他一同活著。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 4:29; 希伯來書 10:25; 羅馬書 15:2"> 因此，你們要彼此鼓勵，互相造就，就像你們現在所做的那樣。</span>
</div>
<div className="bp poetry">

<span className="v" id="v13" data-v="13" data-xref="馬可福音 9:50; 希伯來書 12:14; 加拉太書 6:6"> 因著他們的工作，要在愛中格外地看重他們。你們要彼此和睦。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太後書 4:2; 羅馬書 14:1; 使徒行傳 20:35"> 弟兄們，我們勸你們：要勸誡懶散的人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="懶散的人——或譯作「不守規矩的人」。">c</a></sup>，安慰膽怯的人，扶助軟弱的人，對所有的人都要恆久忍耐。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 3:9; 加拉太書 6:10; 利未記 19:18"> 你們要注意，誰都不要以惡報惡；相反，無論是彼此之間，還是對待眾人，總要追求美善。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:12; 腓立比書 4:4; 馬太福音 5:12"> <span className="pl pl-1">要常常歡喜，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:12; 歌羅西書 4:2; 以弗所書 6:18"> <span className="pl pl-1">不住地禱告，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 5:20; 腓立比書 4:6; 歌羅西書 3:17"> <span className="pl pl-1">凡事感謝；</span><br /><span className="pl pl-1">因為這是神在基督耶穌裡對你們的旨意。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 4:30; 使徒行傳 7:51; 提摩太後書 1:6"> <span className="pl pl-1">不要消滅聖靈</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="不要消滅聖靈——或譯作「不要使聖靈止息」。">d</a></sup><br /><span className="pl pl-1">的感動</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="的感動——輔助詞語。">e</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 14:3–6; 哥林多前書 14:1; 民數記 11:25–29"> <span className="pl pl-1">不要輕視做先知傳道</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="做先知傳道——原文直譯「說預言」。">f</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 4:1; 羅馬書 12:2; 以弗所書 5:10"> <span className="pl pl-1">卻要凡事分辨，</span><br /><span className="pl pl-1">要持守美善，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 6:3; 腓立比書 4:8; 哥林多前書 10:31–33"> <span className="pl pl-1">連一切惡的樣式都要遠避。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="猶大書 1:24; 希伯來書 4:12; 哥林多前書 1:8–9"> 願賜平安的神親自使你們完全分別為聖。願你們的靈、魂、體，在我們的主耶穌基督來臨的時候，全然得蒙保守、無可指責。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦後書 3:3; 民數記 23:19; 哥林多前書 1:9"> 召喚你們的那一位是信實的，他將成就這事。</span>

<span className="v" id="v26" data-v="26" data-xref="羅馬書 16:16; 哥林多前書 16:20"> 你們要用聖潔的親吻禮問候所有的弟兄。</span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 4:16; 使徒行傳 19:13; 提摩太前書 1:3"> 我藉著主吩咐你們，要把這封信讀給所有<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「聖潔」。">g</a></sup>的弟兄聽。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 16:20; 帖撒羅尼迦後書 3:18; 羅馬書 16:23"> 願我們主耶穌基督的恩典與你們同在！<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「阿們。」">h</a></sup></span>

<span className="v" id="v2" data-v="2" data-xref="使徒行傳 14:22–23; 以弗所書 6:21–22; 腓立比書 2:19–25"> 並派了我們的弟兄——在基督的福音工作上的神的同工<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的同工——有古抄本作「神的僕人、我們的同工」。">a</a></sup>提摩太，好在信仰上堅固你們、鼓勵你們，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 14:22; 羅馬書 5:3; 使徒行傳 9:16"> 免得有人在這些患難中動搖。因為你們自己知道，我們要受患難是註定的。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:14; 哥林多後書 8:1–2; 帖撒羅尼迦前書 2:2"> 事實上，我們還在你們那裡的時候，早就不斷地告訴你們，我們將要受患難，這果然應驗了，就像你們所知道的那樣。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 1:13–14; 馬太福音 4:3; 哥林多後書 2:11"> 為此，我既然不能再等了，就派提摩太<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="提摩太——輔助詞語。">b</a></sup>去，要知道你們的信仰怎樣，恐怕那試探者誘惑了你們，我們所勞苦的落了空。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 11:2; 以賽亞書 52:7; 箴言 25:25"> 但是，現在提摩太從你們那裡來到我們這裡，帶來了你們信仰和愛心的好消息，並且說你們總是對我們懷著美好的記憶，切切地想見到我們，就像我們也渴望見到你們那樣。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 1:4; 約翰二書 1:4; 帖撒羅尼迦前書 3:8–9"> 所以弟兄們，在我們的一切困苦和患難中，由於你們的緣故，藉著你們的信心<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信心——指「對耶穌基督的信心」。">c</a></sup>，我們就受到安慰，</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 1:23; 哥林多前書 16:13; 啟示錄 3:11"> 因為，你們如果在主裡站立得穩，我們如今就真的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="真的——輔助詞語。">d</a></sup>活了。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 71:14–15; 詩篇 96:12–13; 哥林多後書 9:15"> 我們因著你們，在我們的神面前就喜樂；為這一切的喜樂，我們到底能用什麼樣的感謝為你們回報神呢？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 13:9; 帖撒羅尼迦前書 3:11; 腓立比書 1:25"> 我們日夜迫切祈求，要見你們的面，並且要補全你們在信仰上的缺欠。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 3:5–6; 馬太福音 6:32; 帖撒羅尼迦後書 2:16"> 願神我們的父和我們的主耶穌<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="耶穌——有古抄本作「耶穌基督」。">e</a></sup>，親自引導我們的道路到你們那裡去。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比書 1:9; 約翰一書 4:7–16; 馬太福音 22:39"> 願主使你們彼此之間的愛，以及對眾人的愛都能增加、充實滿溢，就像我們對你們的愛那樣；</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:22; 帖撒羅尼迦前書 5:23; 以弗所書 5:27"> 但願他這樣堅固你們的心，使你們在我們主耶穌<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="耶穌——有古抄本作「耶穌基督」。">f</a></sup>與他所有的聖徒一起來臨的時候，在神我們的父面前，在聖潔中是無可指責的！阿們。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「阿們。」">g</a></sup></span>
</div>

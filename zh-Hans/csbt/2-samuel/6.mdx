<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 13:1–4; 列王紀上 8:1; 歷代志上 13:6–14"> 大衛再次招聚以色列中所有的精兵，共三萬人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:4; 撒母耳記上 7:1; 詩篇 80:1"> 大衛與所有隨同他的人起身前往猶大的巴阿拉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="巴阿拉——就是基列-耶琳。參《歷代志上》13:6；《約書亞記》15:9。">a</a></sup>，要把神的約櫃從那裡抬上來；這約櫃是以坐在基路伯之上萬軍之耶和華的名而命名的。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 6:7; 民數記 7:4–9; 民數記 4:5–12"> 他們把神的約櫃安放在一輛新車上，從丘陵上亞比拿達的家運出來。亞比拿達的兩個兒子烏撒和亞希約引領這輛新車，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 13:7; 撒母耳記上 7:1–2"> 把神的約櫃從丘陵上亞比拿達的家運出來；那時亞希約走在約櫃前面。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 13:8; 詩篇 150:3–5; 阿摩司書 5:23"> 大衛和以色列全家伴著各種松木樂器，以及豎琴、里拉琴、鈴鼓、響板、銅鈸，在耶和華面前歡慶。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志上 13:9; 民數記 4:15; 民數記 4:19–20"> 當他們來到拿墾禾場時，牛絆了一下，烏撒就伸手扶住神的約櫃。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 6:19; 歷代志上 15:13; 歷代志上 13:10"> 於是耶和華的怒氣向烏撒發作，神因這過失而擊殺他，他就當場死在神的約櫃面前。</span>
<span className="v" id="v8" data-v="8" data-xref="約拿書 4:1; 歷代志上 13:11–12; 約拿書 4:9"> 大衛很惱火，因為耶和華向烏撒怒氣爆發。因此那地方被稱為佩勒斯-烏撒，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 119:120; 歷代志上 13:11–12; 民數記 17:12–13"> 那一天，大衛懼怕耶和華，說：「耶和華的約櫃怎能到我這裡來呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 26:4–8; 撒母耳記下 15:19; 歷代志上 15:18"> 大衛不願意把耶和華的約櫃遷移到大衛城自己那裡，於是把它轉運到迦特人俄別·以東的家。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:5; 創世記 30:27; 箴言 3:9–10"> 耶和華的約櫃停留在迦特人俄別·以東的家三個月，耶和華祝福了俄別·以東和他全家。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 15:25–3; 列王紀上 8:1; 馬太福音 10:42"> 有人告訴大衛王說：「因神約櫃的緣故，耶和華祝福了俄別·以東的家和一切屬於他的。」大衛就去，歡歡喜喜把神的約櫃從俄別·以東家裡抬上來，放到大衛城。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 8:5; 歷代志上 15:15; 民數記 4:15"> 當抬耶和華約櫃的人前進六步，大衛就祭獻一頭公牛和一隻肥畜。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 2:18; 出埃及記 15:20; 詩篇 150:4"> 大衛束著細麻布的以弗得，在耶和華面前極力跳舞。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 68:24–27; 歷代志上 15:28; 歷代志上 15:25"> 這樣，在歡呼和號角聲中，大衛和以色列全家把耶和華的約櫃抬上來了。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 2:14; 歷代志上 15:29; 詩篇 69:7"> 當耶和華的約櫃進入大衛城時，掃羅的女兒米甲透過窗戶俯看，看見大衛王在耶和華面前踴躍跳舞，心裡就藐視他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 15:1; 歷代志下 1:4; 列王紀上 8:5"> 他們把耶和華的約櫃抬來，安放在預備好的地方，在大衛為它支搭的帳篷內，然後大衛在耶和華面前獻上燔祭和平安祭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 8:55; 歷代志上 16:2; 創世記 14:19"> 大衛獻完了燔祭和平安祭，就奉萬軍之耶和華的名祝福民眾，</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 8:10; 歷代志下 35:7–8; 歷代志上 16:3"> 又分給以色列所有民眾，所有的人無論男女，每人一個餅、一個棗餅、一個葡萄餅。然後全體民眾各回各家去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 6:16; 撒母耳記下 6:14; 士師記 9:4"> 大衛回去要祝福自己的家人時，掃羅的女兒米甲出來迎接大衛，她說：「今天以色列王多麼光彩啊！竟然在臣僕們的婢女眼前露體，如同一個下賤人赤身露體。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:22; 詩篇 89:19–20; 撒母耳記上 13:14"> 大衛對米甲說：「我這是在耶和華面前做的，是他揀選了我，勝過揀選你父親和他全家，任命我作耶和華子民以色列的領袖，所以我要在耶和華面前歡慶。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 4:14; 希伯來書 12:2; 以賽亞書 51:7"> 我還要比這更顯為輕賤，自視卑微；至於你提到的那些婢女，她們卻會尊重我。」</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 1:25; 以賽亞書 22:14; 以賽亞書 4:1"> 掃羅的女兒米甲，直到死的日子都沒有孩子。</span>
</div>
</div>

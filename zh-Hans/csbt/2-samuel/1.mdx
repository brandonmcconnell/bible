<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 27:6; 撒母耳記上 31:6; 撒母耳記上 30:17–26"> 掃羅死了，大衛也已經擊殺亞瑪力人回來，在洗革拉住了兩天。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:12; 撒母耳記下 4:10; 約書亞記 7:6"> 到了第三天，看哪，有一個人從掃羅的營地前來，他的衣服撕裂，頭蒙灰塵。他一來到大衛面前，就俯伏在地下拜。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 1:15–19; 列王紀下 5:25"> 大衛問他：「你從哪裡來？」<br />他回答大衛：「我從以色列的營地逃了出來。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 4:16; 撒母耳記上 31:1–6; 歷代志上 10:1–6"> 大衛又問：「情況怎麼樣？請告訴我！」<br />他回答：「軍兵從戰場上逃跑，軍兵當中有很多人倒下陣亡，掃羅和他的兒子約拿單也死了。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 25:2; 箴言 14:15"> 大衛就問向他報信的年輕人：「你怎麼知道掃羅和他兒子約拿單死了呢？」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 28:4; 撒母耳記下 1:21; 歷代志上 10:4–6"> 那報信的年輕人回答：「我正巧來到基利波山上，看哪，掃羅靠在他的長矛上，戰車和騎兵正向他逼近。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 22:12; 撒母耳記下 9:6; 士師記 9:54"> 他回頭看見我，就呼喚我。我說：『我在這裡！』</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:17; 撒母耳記上 30:13; 撒母耳記上 30:1"> 他問我：『你是誰？』我回答他：『我是亞瑪力人。』</span>
<span className="v" id="v9" data-v="9"> 他就對我說：『請到我身邊來，把我殺了，死亡的痛苦抓住我，但我性命還在。』</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:2; 士師記 9:54; 列王紀下 11:12"> 我就到他身邊，把他殺了，因為我知道他倒下後必不能活了。這樣我取下他頭上的冠冕和胳膊上的臂環，帶到我主這裡來。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 13:31; 創世記 37:29; 撒母耳記下 3:31"> 大衛就抓著自己的衣服，把衣服撕裂，所有與他在一起的人也都這樣。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:17; 詩篇 35:13–14; 馬太福音 5:44"> 他們為掃羅和他兒子約拿單、為耶和華的子民和以色列家哀慟、哭泣、禁食，直到傍晚，因為他們倒在刀下。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 1:8"> 大衛問那報信的年輕人：「你是哪裡的人？」<br />他回答：「我是一個寄居者的兒子，是亞瑪力人。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 26:9; 撒母耳記上 31:4; 彼得後書 2:10"> 大衛對他說：「你伸手殺害耶和華的受膏者，怎麼沒有畏懼呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 2:34; 士師記 8:20; 撒母耳記下 4:10–12"> 於是大衛叫來一個僕人，說：「你過去把他殺了！」那僕人擊殺他，他就死了。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:25; 路加福音 19:22; 利未記 20:9"> 大衛對他說：「你的血債歸在你自己頭上！因為你親口指證自己說『我殺了耶和華的受膏者。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="歷代志下 35:25; 撒母耳記下 1:19; 創世記 50:11"> 大衛為掃羅和他兒子約拿單作了以下這首哀歌，</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 10:13; 創世記 49:8; 申命記 4:10"> 並吩咐要教猶大子孫這首《弓之歌》，這首歌被記在《雅煞爾書》<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="《雅煞爾書》——或譯作「《正直人之書》」；是古以色列的詩歌集，已失傳。">a</a></sup>上：</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 1:27; 撒母耳記下 1:25; 申命記 4:7–8"> <span className="pl pl-1">以色列啊，你的尊榮者在你的高處被殺</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你的尊榮者在你的高處被殺——或譯作「羚羊在你的高處被殺」。">b</a></sup><br /><span className="pl pl-1">！</span><br /><span className="pl pl-1">勇士竟然倒下！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彌迦書 1:10; 撒母耳記上 18:6; 士師記 11:34"> <span className="pl pl-1">不要在迦特報信，</span><br /><span className="pl pl-1">不要在阿實基倫的街上傳揚，</span><br /><span className="pl pl-1">免得非利士女子歡喜，</span><br /><span className="pl pl-1">免得未受割禮之人的女子們歡躍。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 31:1; 以賽亞書 21:5; 撒母耳記上 10:1"> <span className="pl pl-1">基利波的眾山哪，</span><br /><span className="pl pl-1">願你們那裡沒有露水、沒有雨水，</span><br /><span className="pl pl-1">田地也沒有出產作供物，</span><br /><span className="pl pl-1">因為勇士的盾牌在那裡被玷汙，</span><br /><span className="pl pl-1">掃羅的盾牌不再抹油。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 18:4; 以賽亞書 34:6–7; 撒母耳記上 14:6–14"> <span className="pl pl-1">約拿單的弓不縮回，</span><br /><span className="pl pl-1">掃羅的刀也不空回，</span><br /><span className="pl pl-1">除非沾了被殺之人的血，</span><br /><span className="pl pl-1">沾了勇士的脂油。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 4:13; 士師記 14:18; 耶利米哀歌 4:19"> <span className="pl pl-1">掃羅和約拿單，</span><br /><span className="pl pl-1">生時相親相愛，</span><br /><span className="pl pl-1">死時也不分離。</span><br /><span className="pl pl-1">他們比鷹更快，</span><br /><span className="pl pl-1">比獅子更強！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 3:3–5; 耶利米書 2:32; 士師記 5:30"> <span className="pl pl-1">以色列女子啊，要為掃羅哀哭，</span><br /><span className="pl pl-1">是他使你們穿上朱紅的美衣，</span><br /><span className="pl pl-1">使你們的衣袍佩上黃金的妝飾。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 1:19; 撒母耳記下 1:27; 士師記 5:18"> <span className="pl pl-1">勇士竟然在戰場上仆倒！</span><br /><span className="pl pl-1">約拿單在你的高處被殺！</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 20:17; 撒母耳記上 23:16; 撒母耳記上 20:41"> <span className="pl pl-1">我兄約拿單哪，我為你悲痛！</span><br /><span className="pl pl-1">你曾使我喜悅，</span><br /><span className="pl pl-1">你對我的愛非常奇妙，超過女人的愛。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 1:25; 撒母耳記下 1:19; 以西結書 39:9–10"> <span className="pl pl-1">勇士竟然仆倒！</span><br /><span className="pl pl-1">作戰的兵器竟然滅沒！</span></span>

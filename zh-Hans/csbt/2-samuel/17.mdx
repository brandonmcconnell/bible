<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳記下" data-chapter="17" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 59:7–8; 詩篇 109:2–4; 詩篇 3:3–5"> 亞希多弗對押沙龍說：「請讓我挑選一萬兩千人，今夜就動身追趕大衛。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 16:14; 列王紀上 22:31; 撒迦利亞書 13:7"> 我要趁他困倦手發軟的時候追上他，讓他恐慌，這樣隨同他的人都會逃跑。我只擊殺王，</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 5:3; 以賽亞書 48:22; 以賽亞書 57:21"> 讓所有人都歸順你，就像他們曾都歸順你所尋索的那人一樣；所有人必平安無事。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 18:20–21; 羅馬書 1:32; 歷代志下 30:4"> 這建議在押沙龍和以色列所有長老眼中都看為好。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 15:32–37; 撒母耳記下 16:16–19"> 押沙龍說：「去把亞基人戶篩也召來，我們也聽聽他怎麼說。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 於是戶篩來見押沙龍，押沙龍對他說：「亞希多弗提了這樣的建議，我們可以照他的話行事嗎？如果不可，你就提議吧！」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> 戶篩對押沙龍說：「亞希多弗這次提的建議不好。」</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 13:8; 撒母耳記上 16:18; 希伯來書 11:32–34"> 戶篩說：「你知道，你父親和他的部下都是勇士，他們現在心裡狂怒如野外失去幼仔的母熊；況且你父親是個有經驗的戰士，不會與軍兵在一起過夜。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 24:3; 撒母耳記上 14:14–15; 士師記 20:32–33"> 看哪，他現在或躲藏在一個坑中，或躲藏在某個地方。一旦他開始襲擊我們的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他開始襲擊我們的人——或譯作「軍兵中開始有人倒斃」。">a</a></sup>，聽見的就會說：『跟從押沙龍的軍兵遭到了殺戮！』</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 2:9–11; 出埃及記 15:15; 創世記 49:9"> 縱然有英勇的人，他的心如獅子心，也會徹底消融，因為全以色列都知道你父親是個勇士，與他在一起的也都是英勇的人。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 士師記 20:1; 詩篇 9:16"> 因此我建議，把以色列全軍從但到比爾-謝巴都招聚到你這裡，他們多如海邊的沙；你親自率領出戰，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 23:23; 俄巴底亞書 1:3; 列王紀上 20:10"> 不管他在哪裡被發現，我們就過去，臨到他如同露水落在地上。這樣，他和所有隨同的人，一個也不會存留。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:2; 彌迦書 1:6"> 如果他撤到城裡，以色列全軍就拿繩子圍繞那城，把城拖到溪谷裡去，使原處連一粒石子也找不到。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 15:34; 哥林多前書 1:19–20; 箴言 19:21"> 押沙龍和以色列眾人都說：「亞基人戶篩的建議比亞希多弗的建議好。」耶和華定意要破壞亞希多弗的好建議，好降災禍給押沙龍。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 15:35–36"> 隨後戶篩對祭司撒督和亞比亞特說，亞希多弗為押沙龍和以色列的長老們是如此如此建議的，而他是如此如此建議的。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 15:28; 哥林多前書 15:54; 哥林多後書 5:4"> 他又說：「現在，你們要迅速派人去告訴大衛：今夜不要在曠野的渡口<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="渡口——或譯作「荒原」。">b</a></sup>過夜，一定要過河，免得王和所有隨同他的人都被吞滅。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 15:36; 約書亞記 18:16; 撒母耳記下 15:27"> 那時約拿單和亞希瑪斯在恩羅格爾等候，有一個婢女去傳話給他們，他們再去報信給大衛王，因為不能讓人看見他們進城。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 3:16; 撒母耳記下 16:5; 撒母耳記下 19:16"> 不過，有一個年輕人看見了他們，報告了押沙龍。因此他們二人迅速離去，來到巴戶琳一戶人家。那人院子裡有一口井，他們就下到井裡。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 1:19; 約書亞記 2:4–24"> 那家的婦人拿了一塊簾布鋪在井口上，然後在上面攤了一些麥子，這事就沒有被發現。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 1:19; 約書亞記 2:22–23; 撒母耳記上 19:12–17"> 押沙龍的僕人們來到那家，問那婦人：「亞希瑪斯和約拿單在哪裡？」<br />婦人回答：「他們已經過了河。」於是那些僕人去尋找，卻沒有找到，就回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 17:15–16"> 那些僕人走了之後，二人從井裡上來，去向大衛王報信，對大衛說：「你要迅速起身過河，因為亞希多弗已經如此建議對付你們。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 10:16; 約翰福音 18:9; 箴言 27:12"> 於是大衛和所有跟隨他的人起身過約旦河，早晨天亮之前沒有剩下一個還沒有過約旦河的。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 27:5; 列王紀下 20:1; 撒母耳記下 15:12"> 亞希多弗見自己的建議沒有被採納，就給驢子備上鞍，起身回本鄉本家去。他安排好家裡的事，然後上吊死了。他被葬在他父親的墳墓裡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 32:2; 撒母耳記下 2:8; 約書亞記 13:26"> 大衛來到瑪哈念，押沙龍和跟隨他的以色列眾人也過了約旦河。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 2:13; 撒母耳記下 19:13; 撒母耳記下 20:9–12"> 押沙龍立亞瑪撒代替約押統管軍隊，亞瑪撒是一個名叫耶特拉的以實瑪利人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以實瑪利人——或譯作「以色列人」。">c</a></sup>的兒子，耶特拉娶了婭比蓋，婭比蓋是納哈什的女兒、洗魯雅的姐妹，洗魯雅是約押的母親。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 17:1; 申命記 3:15; 民數記 32:1–42"> 以色列人和押沙龍在基列地紮營。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:7; 撒母耳記下 10:1–2; 撒母耳記下 9:4"> 大衛來到瑪哈念的時候，拉巴的亞捫人納哈什的兒子朔比，還有羅迪巴人亞米利的兒子瑪吉，羅格琳的基列人巴爾茲萊，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 25:18; 俄巴底亞書 1:3; 撒母耳記下 16:1–2"> 帶來了寢具、缽、瓦器，還帶來小麥、大麥、麵粉、烤麥子、豆子、紅豆、炒豆<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="炒豆——或譯作「烤麥」。">d</a></sup>、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 16:2; 以賽亞書 21:14; 撒母耳記下 16:14"> 蜂蜜、乳酪、羊肉<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="肉——輔助詞語。">e</a></sup>和牛奶酪，供大衛和跟隨他的人吃，因為他們說：「人們在曠野裡一定又飢渴，又疲乏。」</span>
</div>
</div>

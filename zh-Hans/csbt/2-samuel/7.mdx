<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王紀上 5:4"> 當王住進自己的宮殿，耶和華使他得享安息，脫離四圍一切仇敵的時候，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 16:1; 撒母耳記下 5:11; 哈該書 1:4"> 王對先知拿單說：「你看，如今我住在香柏木的宮殿裡，神的約櫃卻在帳幕裡。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:7; 列王紀上 8:17–18; 列王紀下 4:27"> 拿單對王說：「你心裡所想的一切，只管去做，因為耶和華與你同在。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志上 17:3; 民數記 12:6; 阿摩司書 3:7"> 當天夜裡，耶和華的話語臨到拿單，說：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 23:3–32; 列王紀上 5:3–4; 列王紀上 8:16–19"> 「你去告訴我的僕人大衛：『耶和華如此說：你要為我建造殿宇讓我居住嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:16; 約書亞記 18:1; 出埃及記 40:18–19"> 要知道，自從我帶以色列子民出埃及的那天起直到今日，我從來沒有住過殿宇，我一直以帳幕為住所，到處遷移。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 17:6; 撒母耳記下 5:2; 利未記 26:11–12"> 在我與全體以色列子民走過的哪一個地方，我何曾對哪一個以色列士師<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="士師——原文直譯「支派」；參《歷代志上》17:6。">a</a></sup>，就是我吩咐要牧養我子民以色列的士師，說過這話：你們怎麼不為我建造一座香柏木的殿宇呢？』</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 78:70–71; 撒母耳記下 6:21; 撒母耳記下 12:7"> 「現在，你要對我的僕人大衛這樣說：『萬軍之耶和華如此說：是我把你從牧場上、從羊群後帶出來，作我子民以色列的領袖。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 5:10; 歷代志上 17:8; 撒母耳記上 18:14"> 我在你所去的任何地方一直與你同在，並且從你面前剪除了你的一切仇敵。我將為你成就大名，如同世上那些偉人的名。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 9:15; 歷代志上 17:9; 耶利米書 24:6"> 我必為我的子民以色列選定一個地方，栽植他們，使他們安居在那裡，不再受攪擾，也不再像先前那樣被不義之人苦待——</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 7:27; 撒母耳記下 7:1; 歷代志上 17:10"> 從我吩咐士師治理我子民以色列的日子以來，他們一直被苦待。我要使你得享安息，脫離一切仇敵。<br />「『耶和華向你宣告：耶和華將為你建立家室。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 8:20; 使徒行傳 2:30; 使徒行傳 13:36"> 當你壽數滿足，與你列祖長眠時，我必興起你親生的後裔接續你，也必堅立他的王權。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王紀上 8:19; 撒母耳記下 7:16"> 他將為我的名建造殿宇，我必堅立他的王位，直到永遠。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 1:5; 啟示錄 3:19; 歷代志上 17:13"> 我要作他的父親，他要作我的兒子。當他行事扭曲，我要用人的杖、用世人的鞭來懲戒他；</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:23; 撒母耳記上 15:28; 詩篇 89:28"> 我的慈愛卻不會離開他，像離開在你面前所廢除的掃羅那樣。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 詩篇 89:36–37; 撒母耳記下 7:13"> 你的家和你的國必在我<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我——依據七十士譯本；馬索拉文本作「你」。">b</a></sup>面前永遠堅固，你的王位必永遠堅立。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 17:15; 使徒行傳 20:27; 哥林多前書 15:3"> 拿單就把這一切話語，把這整個異象，如實地告訴了大衛。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 8:4; 歷代志上 17:16; 撒母耳記上 18:18"> 於是大衛王進去，坐在耶和華面前，說：「主耶和華啊，我是誰，我的家算什麼，你竟帶領我到這地步！</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 55:8–9; 歷代志上 17:17; 詩篇 36:7"> 主耶和華啊，這在你眼中還看為小事，你竟又提說僕人家的未來！主耶和華啊，這難道是人的常例嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 21:17; 撒母耳記上 16:7; 詩篇 139:1"> 大衛還能對你說什麼呢？主耶和華啊，你知道你的僕人。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 115:1; 詩篇 138:2; 以弗所書 1:9"> 你因著自己的應許，照著自己的心意行了這一切大事，為要顯明給你的僕人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 86:10; 出埃及記 15:11; 詩篇 86:8"> 「主耶和華啊，你是如此偉大！照著我們耳中所聽見的一切，沒有像你的，除你以外沒有別的神。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:26; 申命記 10:21; 申命記 15:15"> 世上有哪一國像你的子民以色列呢？神為自己贖回一個民族，為自己立名，在你從埃及、列國和他們神明那裡救贖的子民面前，為你的地行了大而可畏的事。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 26:18; 彼得前書 2:10; 創世記 17:7"> 你為自己堅立了你的子民以色列，使他們永遠作你的子民；耶和華啊，你也作了他們的神。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 119:49; 以西結書 36:37; 創世記 32:12"> 「現在，耶和華神哪，你所應許的有關你僕人和他家的話，求你永遠確立。求你照著你所應許的行事，</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 17:23–24; 詩篇 72:18–19; 馬太福音 6:9"> 這樣，你的名就永遠被尊為大，人必說：『萬軍之耶和華就是掌管以色列的神。』你僕人大衛的家也將在你面前被堅立，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 17:25–26; 詩篇 10:17; 路得記 4:4"> 因為你——萬軍之耶和華以色列的神，是你親自啟示你的僕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="啟示你的僕人——原文直譯「開啟你僕人的耳朵」。">c</a></sup>，說：『我要為你建立家室。』所以你的僕人有了勇氣來向你獻上這禱告。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 17:17; 出埃及記 34:6; 民數記 23:19"> 是的，主耶和華啊，你是神，你的話語就是真理，是你向你的僕人應許了這福份。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 6:24–26; 歷代志上 17:27; 詩篇 115:12–15"> 現在，願你祝福你僕人的家，使它在你面前永遠長存，因為主耶和華啊，你已經發話了。願你僕人的家因你的祝福而永遠蒙福。」</span>
</div>
</div>

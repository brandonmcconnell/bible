<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 18:1–17; 撒母耳記下 7:9; 撒母耳記下 21:15–22"> 此後，大衛擊敗非利士人，制伏了他們；大衛從非利士人手中奪取了他們京城的控制權<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="控制權——原文直譯「嚼環」。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 24:17; 撒母耳記上 10:27; 撒母耳記下 8:6"> 他又擊敗摩押人，讓他們趴在地上用繩子量，每兩繩內的都處死，第三繩內的就存留；這樣摩押就臣服於大衛，向他進貢。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 14:47; 撒母耳記下 10:16; 撒母耳記下 10:19"> 當利合的兒子瑣巴王哈大底謝去奪回他在幼發拉底河流域的掌控權時，大衛擊敗了他。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 11:6; 約書亞記 11:9; 歷代志上 18:4"> 大衛從他那裡俘虜了一千七百馬兵、兩萬步兵，大衛從拉戰車的馬中保留了一百匹，把其餘所有拉戰車的馬都砍斷了蹄筋。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 11:23–25; 以賽亞書 7:8; 約伯記 9:13"> 大馬士革的亞蘭人來幫助瑣巴王哈大底謝時，大衛擊殺了亞蘭人兩萬兩千。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 8:14; 撒母耳記下 7:9; 詩篇 18:34–46"> 大衛在大馬士革的亞蘭地設立駐軍，這樣亞蘭就臣服於大衛，向他進貢。大衛無論往哪裡去，耶和華都使他得勝。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 9:15–16; 列王紀上 14:26–27; 列王紀上 10:16–17"> 大衛奪取哈大底謝臣僕們所拿的金盾牌，把它們帶回耶路撒冷。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 18:8; 歷代志上 22:16; 以西結書 47:16"> 大衛王也從哈大底謝的城——比塔城和比羅塔城中，奪走極多的銅。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 8:65; 歷代志下 8:4; 歷代志上 18:9"> 哈馬王陀伊聽說大衛擊敗了哈大底謝的全軍，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 13:10; 歷代志上 18:10; 詩篇 129:8"> 就派遣他兒子約蘭去見大衛王，向他問安，為他祝福，因為大衛攻打哈大底謝並擊敗了他；原來哈大底謝一直是陀伊的敵手。約蘭手中帶著銀器、金器和銅器，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 7:51; 歷代志上 29:2; 歷代志上 22:14–16"> 大衛王把這些分別為聖歸於耶和華，就像他把征服各國得來的金銀分別為聖那樣——</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 10:14; 撒母耳記下 8:2; 歷代志上 18:11"> 這些金銀是從以東人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以東人——依據七十士譯本以及有些古抄本；參《歷代志上》18:11；傳統譯法作「亞蘭」。">b</a></sup>、摩押人、亞捫人、非利士人、亞瑪力人，以及利合的兒子瑣巴王哈大底謝那裡得來的戰利品。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀下 14:7; 撒母耳記下 7:9; 歷代志上 18:12"> 大衛在鹽谷擊殺一萬八千以東人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以東人——依據七十士譯本以及有些古抄本；參《歷代志上》18:12；傳統譯法作「亞蘭」。">c</a></sup>回來，名聲大振。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 27:29; 創世記 25:23; 撒母耳記下 8:6"> 大衛在以東設立了駐軍；他在全以東設立駐軍，全以東就臣服於大衛。大衛無論往哪裡去，耶和華都使他得勝。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="阿摩司書 5:15; 詩篇 89:14; 詩篇 72:2"> 大衛作王統治全以色列，大衛為所有百姓實行公正和公義。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 4:3; 歷代志上 11:6; 撒母耳記下 19:13"> <span className="pl pl-1">洗魯雅的兒子約押統管軍隊，</span><br /><span className="pl pl-1">亞希律的兒子約沙法作史官，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:8; 歷代志上 18:16; 歷代志上 24:3–4"> <span className="pl pl-1">亞希突的兒子撒督</span><br /><span className="pl pl-1">和亞比亞特的兒子亞希米勒作祭司，</span><br /><span className="pl pl-1">西萊雅作書記，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 30:14; 撒母耳記下 20:7; 撒母耳記下 20:23"> <span className="pl pl-1">耶赫亞達的兒子比納雅</span><br /><span className="pl pl-1">統管基利提人和比利提人，</span><br /><span className="pl pl-1">大衛的兒子們作內官</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="內官——或譯作「祭司」。">d</a></sup><br /><span className="pl pl-1">。</span></span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳記下" data-chapter="13" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 3:9; 撒母耳記下 3:2–3; 撒母耳記下 13:15"> 此後發生了一件事：大衛的兒子押沙龍有一個美麗的妹妹，名叫塔瑪爾，大衛的兒子暗嫩愛上了她。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 7:10; 列王紀上 21:4; 雅歌 5:8"> 暗嫩因妹妹塔瑪爾的緣故憂悶成疾，因為她是個處女，在暗嫩看來很難對她做什麼。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 16:9; 哥林多前書 3:19; 雅各書 3:15"> 暗嫩有一個朋友，名叫約拿達，是大衛的哥哥示米亞的兒子。約拿達是一個非常精明的人。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:17; 利未記 18:9; 以斯帖記 5:13–14"> 他對暗嫩說：「王子啊，你為什麼天天都這樣憔悴呢？你不能告訴我嗎？」<br />暗嫩對他說：「我愛上了我弟弟押沙龍的妹妹塔瑪爾。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬可福音 6:24–25; 箴言 19:27; 使徒行傳 23:15"> 約拿達對他說：「你躺在床上裝病。你父親來看你，你就對他說：『請讓我的妹妹塔瑪爾來，給我東西吃。讓她在我眼前預備吃的，讓我可以看見，並且從她的手中吃。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 18:6; 馬太福音 13:33"> 於是暗嫩躺著裝病。王來看他，暗嫩就對王說：「請讓我妹妹塔瑪爾來，在我眼前做兩個餅，我好從她手中吃。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大衛就派人到宮裡對塔瑪爾說：「請你去你哥哥暗嫩的家，給他做點吃的。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 於是塔瑪爾去了她哥哥暗嫩的家，暗嫩正躺著。她取了麵團揉好，在暗嫩眼前做餅，把餅做熟了。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:1; 約翰福音 3:20; 士師記 3:19"> 塔瑪爾拿起鍋，在他面前倒出餅，他卻不肯吃。暗嫩說：「所有人離開我出去！」所有的人就離開他出去了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩對塔瑪爾說：「把吃的帶到臥室來，我好從你手中吃。」塔瑪爾就拿了做好的餅，帶到她哥哥暗嫩的臥室，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:11–12"> 上前來給他吃。他卻抓住塔瑪爾，對她說：「我的妹妹，來與我同睡吧！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士師記 19:23; 利未記 20:17; 士師記 20:6"> 塔瑪爾對他說：「不，哥哥，不要玷辱我！在以色列絕不可做這樣的事，你不要做這醜惡的事。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 19:24; 創世記 20:12; 創世記 19:8"> 不然，我到哪裡除去我的羞辱呢？而你也會在以色列中成為一個愚昧人！現在你去向王提說，他絕不會阻止我歸你的。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 12:11; 以斯帖記 7:8; 士師記 20:5"> 但暗嫩不肯聽她的話，因比她力大，就玷辱了她，與她同睡。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西結書 23:17"> 事後，暗嫩非常恨惡她，甚至對她的恨惡超過先前對她的愛。暗嫩對她說：「你起來走吧！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 塔瑪爾說：「不要這樣！你趕我走這樣的惡，比你剛才對我所做的更嚴重。」但暗嫩不肯聽，</span>
<span className="v" id="v17" data-v="17"> 叫來侍候他的僕人，說：「把這女人從我這裡趕出去，然後把門鎖住！」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:30; 創世記 37:3; 詩篇 45:13–14"> 當時塔瑪爾身上穿著彩色的袍子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="彩色的袍子——依據七十士譯本；或譯作「長袖的袍子」。">a</a></sup>，因為未嫁的公主都穿這樣的外袍。侍候暗嫩的僕人把她趕到外面去，隨後鎖住了門。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:6; 耶利米書 2:37; 撒母耳記下 1:11"> 塔瑪爾把灰燼撒在頭上，撕裂身上彩色的袍子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="彩色的袍子——依據七十士譯本；或譯作「長袖的袍子」。">b</a></sup>，然後手抱著頭離開，一邊走一邊哀號。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:19; 創世記 46:15; 創世記 34:2"> 她的哥哥押沙龍問她：「你哥哥暗嫩親近你了嗎？妹妹，現在你要保持沉默，他是你的哥哥，你不要把這事放在心上。」於是塔瑪爾淒涼地住在她哥哥押沙龍家裡。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 34:7; 撒母耳記下 3:28–29; 撒母耳記上 2:29"> 大衛王聽說了這一切事，非常惱火；<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="七十士譯本以及有些古譯本附「但由於暗嫩是他長子，又喜愛他，就不願責備兒子」。">c</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="利未記 19:17–18; 創世記 31:24; 創世記 24:50"> 而押沙龍無論壞話好話都沒有對暗嫩說。因為暗嫩玷辱了他妹妹塔瑪爾，所以押沙龍恨他。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 38:12–13; 撒母耳記上 25:4; 歷代志下 26:10"> 過了整整兩年，在以法蓮附近的巴力哈索，有人為押沙龍剪羊毛，押沙龍就邀請了所有的王子。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 11:8–15; 耶利米書 41:6–7; 詩篇 55:21"> 押沙龍來見王，說：「看哪，現在有人為僕人剪羊毛，請王和王的臣僕們與僕人同去。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士師記 19:7–10; 撒母耳記下 14:22"> 王對押沙龍說：「不，我兒，我們不必所有人都去，以免成為你的負擔。」押沙龍再三地求王，但王不肯去，只是祝福了他。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 20:9; 撒母耳記下 3:27; 撒母耳記下 11:13–15"> 押沙龍就說：「王不去的話，請讓我哥哥暗嫩與我們一起去。」<br />王問他：「為什麼要他與你同去呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 押沙龍再三地求王，王就讓暗嫩和所有的王子與他一起去了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士師記 19:6; 士師記 19:22; 士師記 19:9"> 押沙龍吩咐他的僕人們說：「你們要注意！當暗嫩喝酒暢快的時候，我對你們說：『擊殺暗嫩！』你們就把他殺了。不要害怕！這不是我吩咐你們的嗎？你們要堅強，作英勇的人！」</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 18:9; 列王紀上 1:33; 列王紀下 1:9–12"> 押沙龍的僕人們就照他所吩咐的向暗嫩行了。王子們都起來，各人騎上騾子逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 他們還在路上，消息就傳到大衛那裡，說：「押沙龍擊殺了所有的王子，沒有剩下一個。」</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 1:11; 撒母耳記下 12:16; 約伯記 1:20"> 王就起來，撕裂衣服，伏在地上，侍立的臣僕們也都撕裂衣服。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:9; 撒母耳記下 13:3; 創世記 27:41"> 大衛的哥哥示米亞的兒子約拿達就說：「我主不要以為他們把所有的年輕人——王子們都殺了，其實只有暗嫩一人死了。因為自從他玷辱了押沙龍的妹妹塔瑪爾那天起，押沙龍就決意要殺他了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 19:19"> 現在，我主我王不要把這事放在心上，以為王子們都死了，其實只有暗嫩一人死了。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 4:8–14; 箴言 28:17; 阿摩司書 5:19"> 押沙龍逃走了。守望的年輕人舉目觀看，看哪，有許多人從西邊山旁的路上過來。</span>
<span className="v" id="v35" data-v="35"> 約拿達就對王說：「看哪，王子們回來了，正如你僕人所說的那樣。」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 18:33; 撒母耳記下 12:21; 撒母耳記下 13:15"> 他剛說完，看哪，王子們就到了。他們放聲大哭，王和他的所有臣僕也都號啕大哭。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 3:3; 撒母耳記下 14:32; 撒母耳記下 13:34"> 押沙龍逃走了，去了亞米忽的兒子基述王塔爾邁那裡。大衛天天為他的兒子悲慟。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 15:8; 撒母耳記下 14:23; 撒母耳記下 14:32"> 押沙龍逃到基述，在那裡三年。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:67; 創世記 38:12; 創世記 37:35"> 這時，大衛王在暗嫩死的事上已經受了安慰，渴望去見押沙龍。</span>
</div>
</div>

</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 16:12–13; 撒母耳記下 7:8–9; 詩篇 89:20"> 以下是大衛臨終的話，是耶西的兒子大衛的宣告；是被高舉之人、雅各之神的受膏者、以色列所喜愛的詩人的宣告：</span>
<span className="v" id="v2" data-v="2" data-xref="彼得後書 1:21; 馬太福音 22:43; 馬可福音 12:36"> <span className="pl pl-1">耶和華的靈藉著我說話，</span><br /><span className="pl pl-1">他的言語在我的舌頭上。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 22:32; 申命記 32:4; 出埃及記 18:21"> <span className="pl pl-1">以色列的神發話，</span><br /><span className="pl pl-1">以色列的磐石對我說：</span><br /><span className="pl pl-1">「那以公義統治人民，</span><br /><span className="pl pl-1">存敬畏神的心施行統治的，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="士師記 5:31; 詩篇 72:6; 何西阿書 6:5"> <span className="pl pl-1">他就像日出的晨光、</span><br /><span className="pl pl-1">無雲的清晨，</span><br /><span className="pl pl-1">又像雨後的晴光，</span><br /><span className="pl pl-1">使嫩草破土而出。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 55:3; 撒母耳記下 7:14–16; 以賽亞書 9:6–7"> <span className="pl pl-1">我的家在神面前，不正是這樣嗎？</span><br /><span className="pl pl-1">他與我立下永遠的約，既全備又穩妥。</span><br /><span className="pl pl-1">我的一切拯救和一切願望，他不都成全</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="成全——原文直譯「生發」。">a</a></sup><br /><span className="pl pl-1">嗎？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 2:6; 以賽亞書 33:12; 申命記 13:13"> <span className="pl pl-1">但卑劣的人全都像荊棘那樣被丟棄，</span><br /><span className="pl pl-1">不能用手去拿；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 6:8; 帖撒羅尼迦後書 2:8; 以賽亞書 27:4"> <span className="pl pl-1">誰觸碰它，就必須配備鐵器和槍桿；</span><br /><span className="pl pl-1">它必在原地被火燒盡。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志上 27:2; 歷代志上 11:11–47; 歷代志上 27:32"> 以下是大衛的勇士們的名字：<br />塔克莫尼人約設巴設，是眾軍官<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="眾軍官——或譯作「三勇士」。">b</a></sup>之首；他曾揮動長矛對敵，一次擊殺了八百人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="他曾揮動長矛對敵，一次擊殺了八百人——依據七十士譯本；或譯作「他又稱為伊斯尼人亞底諾，因為曾一次擊殺了八百人」。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志上 27:4; 歷代志上 11:12–14; 撒母耳記上 17:26"> 其次是阿赫阿人朵多的兒子以利亞撒。他是跟隨大衛向非利士人罵陣的三勇士之一。當時非利士人聚集在那裡要打仗，以色列人撤退，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 19:5; 撒母耳記上 11:13; 士師記 15:14"> 他卻堅守，擊殺非利士人，直到手臂疲憊，手粘住刀。那日耶和華施行了大拯救。軍兵轉回跟著他，只是來剝去死者的衣物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 11:13–14; 歷代志上 11:27; 撒母耳記下 23:33"> 再其次是哈拉人亞基的兒子沙瑪。有一次，非利士人聚集成隊<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="成隊——或譯作「在利希」。">d</a></sup>，那裡有一塊長滿了扁豆的田地。以色列軍兵從非利士人面前逃跑，</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳記下 23:10; 詩篇 3:8"> 沙瑪卻在那塊田中站立，守護那塊田，擊殺非利士人。這樣耶和華施行了大拯救。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:1; 撒母耳記下 5:18; 約書亞記 12:15"> 收割的時候，三十個首領中的那三個人下去，到亞杜蘭山洞去見大衛。有一隊非利士人在利乏音谷紮營。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 22:4–5; 撒母耳記上 13:4; 撒母耳記上 10:5"> 那時大衛在要塞中，而非利士人的駐軍在伯利恆。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 4:14; 詩篇 42:1–2; 以賽亞書 41:17"> 大衛心中渴望，說：「誰能把伯利恆城門旁水窖裡的水帶來給我喝啊！」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:14; 哥林多後書 5:14; 腓立比書 2:17"> 那三勇士就突破非利士人的防營，從伯利恆城門旁的水窖裡打水，提上來帶回大衛那裡。但大衛不肯喝，而是把水澆奠在耶和華面前，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 17:10; 馬可福音 14:24; 哥林多前書 15:30"> 說：「耶和華啊，我絕不可做這事！這水不是那些冒生命危險之人的血嗎？」所以他不肯喝。這些是三勇士的事蹟。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 10:10; 撒母耳記下 10:14; 歷代志上 11:20–21"> 洗魯雅的兒子約押的弟弟亞比篩，是三十<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三十—— 依據古敘利亞文譯本；馬索拉文本作「三」。">e</a></sup>勇士之首；他曾揮動長矛殺了三百人，所以和那三勇士一樣有名。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:8; 馬太福音 13:23; 哥林多前書 15:41"> 他在三十<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三十—— 依據古敘利亞文譯本；馬索拉文本作「三」。">f</a></sup>勇士中最受尊崇，所以成為他們的首領，只是不及那三勇士。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 8:18; 約書亞記 15:21; 撒母耳記下 20:23"> 耶赫亞達的兒子比納雅，是來自卡布策勒的勇士，也有許多事蹟。他曾擊殺了摩押的兩個英雄，也曾在下雪的日子，下到坑裡殺了一隻獅子。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 17:51; 歷代志上 11:23; 歌羅西書 2:15"> 他還擊殺了一個埃及人，是個身材健壯的人；這埃及人手中有長矛，比納雅卻拿著棍子下去攻擊他，從他手中搶奪了長矛，用那長矛把他殺了。</span>
<span className="v" id="v22" data-v="22"> 這些是耶赫亞達的兒子比納雅的事蹟，他和那三勇士一樣有名。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 20:23; 歷代志上 27:6; 撒母耳記上 22:14"> 他在三十勇士中受尊崇，但不及那三勇士。大衛立他作侍衛長。</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 2:18; 歷代志上 27:7; 歷代志上 11:26"> 三十勇士有：<br /><span className="pl pl-1">約押的弟弟亞撒暉，</span><br /><span className="pl pl-1">伯利恆人朵多的兒子伊勒哈南，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="士師記 7:1; 歷代志上 11:27–28"> <span className="pl pl-1">哈律人沙瑪，</span><br /><span className="pl pl-1">哈律人以利加，</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:2; 歷代志上 11:27–28; 歷代志上 27:9–10"> <span className="pl pl-1">帕勒提人希利斯，</span><br /><span className="pl pl-1">提克亞人益吉的兒子伊拉，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 21:18; 歷代志上 11:19; 歷代志上 11:28"> <span className="pl pl-1">亞拿突人亞比以謝，</span><br /><span className="pl pl-1">戶沙人米本奈，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 27:13; 列王紀下 25:23; 歷代志上 11:30"> <span className="pl pl-1">阿赫阿人撒門，</span><br /><span className="pl pl-1">尼托法人瑪哈萊，</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 11:30–31; 約書亞記 18:28; 歷代志上 27:15"> <span className="pl pl-1">尼托法人巴納的兒子希勒，</span><br /><span className="pl pl-1">基比亞的便雅憫人利拜的兒子伊太，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="士師記 12:15; 歷代志上 27:14; 士師記 12:13"> <span className="pl pl-1">比拉頓人比納雅，</span><br /><span className="pl pl-1">迦實溪谷的人希太，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:16; 歷代志上 11:32–33"> <span className="pl pl-1">亞拉巴人亞比阿爾本，</span><br /><span className="pl pl-1">巴魯米人阿茲瑪維，</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 11:34"> <span className="pl pl-1">沙本人以利雅哈巴，</span><br /><span className="pl pl-1">雅善的兒子們，</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 11:27; 撒母耳記下 23:11; 歷代志上 11:35"> <span className="pl pl-1">哈拉人沙瑪的兒子</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="的兒子——輔助詞語；參《歷代志上》11:34。">g</a></sup><br /><span className="pl pl-1">約拿單，</span><br /><span className="pl pl-1">哈拉人沙拉的兒子亞希暗，</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 11:3; 撒母耳記下 15:12; 撒母耳記下 10:6"> <span className="pl pl-1">瑪迦人亞哈拜的兒子以利菲烈，</span><br /><span className="pl pl-1">基羅人亞希多弗的兒子伊連，</span><br /></span>

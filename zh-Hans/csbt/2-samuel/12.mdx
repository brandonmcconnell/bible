<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 20:35–41; 詩篇 51:1–19; 撒母耳記下 11:10–17"> 耶和華派遣拿單去見大衛。拿單來到大衛那裡，對他說：「在一座城中有兩個人，一個富有，一個貧窮。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 15:16; 約伯記 1:3; 撒母耳記下 5:13–16"> 那富人有極多的牛羊，</span>
<span className="v" id="v3" data-v="3" data-xref="彌迦書 7:5; 撒母耳記下 11:3; 箴言 5:18–19"> 而那窮人除了一隻買來養活的小母羊以外，一無所有。小母羊在他身邊與他的孩子們一起長大，吃他所吃的、喝他所喝的、睡在他的懷中，小母羊就像是他的女兒。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 1:14; 撒母耳記下 11:3–4; 創世記 18:2–7"> 有一個旅客來到那富人那裡，他捨不得從自己的牛羊中取出一隻來招待到他那裡的旅客，卻取了那窮人的小母羊來招待到他那裡的人。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 38:24; 羅馬書 2:1; 撒母耳記上 26:16"> 大衛就因那人非常惱火，他對拿單說：「我指著耶和華的永生起誓：做這事的人，實在該死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:1; 路加福音 19:8; 箴言 6:31"> 他必須為小母羊賠償四倍，因為他做了這事，毫無憐恤之心。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 14:14; 撒母耳記上 16:13; 撒母耳記下 22:1"> 拿單對大衛說：「你就是那人！以色列的神耶和華如此說：『我膏立你為以色列的王，解救你脫離掃羅的手。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 84:11; 羅馬書 8:32; 撒母耳記下 9:7"> 我把你主人的家交給你，把你主人的妃嬪交在你懷中，又把以色列和猶大家交給了你。如果這些還不夠，我會增添給你更多；</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:19; 詩篇 139:1–2; 撒母耳記上 15:23"> 但你為什麼藐視耶和華的話，做他眼中看為惡的事呢？你用刀劍擊殺了赫提人烏利亞，又娶他的妻子作你的妻子，你藉著亞捫人的刀劍殺了他！</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 18:14–15; 馬太福音 26:52; 羅馬書 2:4"> 現在，刀劍必永不離開你的家，因為你藐視了我，娶了赫提人烏利亞的妻子作你的妻子。』</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 16:21–22; 申命記 28:30; 撒母耳記下 15:10"> 「耶和華如此說：『看哪，我必從你家裡興起禍患攻擊你。我將在你眼前把你的妃嬪奪去，交給在你身邊的人，他會在日光之下、在你眼前與你的妃嬪同睡。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 16:22; 撒母耳記下 11:4–15; 傳道書 12:14"> 你雖然在暗中行事，我卻要在全體以色列人面前，在日光之下施行這報應。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:4; 撒母耳記下 24:10; 箴言 28:13"> 大衛對拿單說：「我對耶和華犯了罪！」<br />拿單對大衛說：「耶和華已經除去你的罪，你不會死。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:24; 以賽亞書 52:5; 詩篇 89:31–33"> 但因你這行為大大藐視了耶和華<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大大藐視了耶和華——或譯作「使耶和華的仇敵大得褻瀆的機會」。">a</a></sup>，你所生的兒子必定死。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:38; 詩篇 104:29; 歷代志下 13:20"> 之後拿單回自己的家去了。 大衛與芭示巴的兒子夭折<br />耶和華打擊烏利亞的妻子給大衛所生的孩子，孩子就得了重病。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 13:31; 使徒行傳 9:9; 詩篇 69:10"> 大衛為孩子向神祈求，並且禁食，進了房躺在地上過夜。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:35; 撒母耳記上 28:23"> 他家中的老臣來站在他旁邊，要扶他從地上起來，他卻不肯，也不與他們一起吃飯。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 20:15"> 到了第七天，孩子死了。大衛的臣僕們害怕告訴他孩子死了，因為他們說：「看哪，孩子活著的時候，我們對他說話，他都不聽勸，我們怎能告訴他孩子已經死了呢？他可能會做出不好的事。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 大衛看見臣僕們低聲耳語，就知道孩子已經死了。大衛問臣僕們：「孩子死了嗎？」<br />他們回答：「死了。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:20; 路得記 3:3; 耶利米哀歌 3:39–41"> 大衛就從地上起來，洗澡，抹油，更換衣服，進耶和華的殿去敬拜，然後回到宮中，讓人給他擺上飯，他就吃了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 2:15"> 臣僕們就問他：「你所做的這些是什麼意思呢？孩子活著的時候，你禁食、哭泣；孩子死了，你卻起來吃飯。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 38:1–3; 以賽亞書 38:5; 約拿書 3:9–10"> 他說：「孩子還活著的時候，我禁食、哭泣，是因為我想：『誰知道呢，或許耶和華會恩待我，讓孩子得以存活。』</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:35; 約伯記 30:23; 路加福音 23:43"> 現在，孩子死了，我為什麼還要禁食呢？我能使他回來嗎？我必到他那裡去，他卻不能回到我這裡來。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 1:6; 歷代志上 28:5–6; 歷代志上 22:9–10"> 大衛安慰他的妻子芭示巴，進到她那裡，與她同睡。她就生了一個兒子，大衛給他起名為所羅門。耶和華愛他，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 7:4; 尼希米記 13:26; 列王紀上 1:11"> 就派遣先知拿單，為耶和華的緣故給他起名為耶迪底亞。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 20:1–3; 申命記 3:11; 撒母耳記下 11:25"> 約押攻打亞捫人的拉巴，攻取了水城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="水城——原文直譯「王城」。">b</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 21:20; 撒母耳記下 11:1; 申命記 3:11"> 約押派遣使者去見大衛，說：「我攻打拉巴，已經攻取了水城。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 7:18"> 現在你要聚集其餘的軍隊，紮營攻擊這城，攻取它，免得我攻取了這城，它就會以我的名字命名。」</span>
<span className="v" id="v29" data-v="29"> 於是大衛聚集全軍去攻打拉巴，並攻取了它。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 20:2"> 大衛奪取了亞捫王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="亞捫王——原文直譯「他們的王」；七十士譯本和有些古抄本作「米勒公」，就是亞捫人的神。">c</a></sup>頭上的王冠，其金子的重量是一他連得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一他連得——相當於34.2公斤。">d</a></sup>，其上有寶石；這王冠就戴在大衛的頭上。大衛從那城帶走了極多的戰利品，</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 20:3; 詩篇 21:8–9; 阿摩司書 1:3"> 並且把城裡的居民帶出來，讓他們用鋸子、鐵鎬、鐵斧做工，或者在磚窯裡勞動；他對待亞捫人的各城都是這樣。然後大衛和全軍回耶路撒冷去了。</span>
</div>
</div>

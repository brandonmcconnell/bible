<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 30:31; 撒母耳記上 23:4; 創世記 32:2"> 此後，大衛求問耶和華說：「我可以上猶大的一座城去嗎？」<br />耶和華對他說：「可以上去。」<br />大衛又問：「我應該上哪裡去呢？」<br />耶和華說：「希伯崙。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 25:42–43; 撒母耳記上 30:5; 路加福音 22:28–29"> 於是大衛和他的兩個妻子——耶斯列人婭希暖和迦密人納巴爾的遺孀婭比蓋，就上希伯崙去了。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 30:1; 歷代志上 12:1–7; 撒母耳記上 27:2–3"> 大衛把跟隨他的部下和各人的家屬，也帶了上去。他們就在希伯崙的城鎮住下。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 5:5; 撒母耳記上 31:11–13; 撒母耳記下 5:3"> 猶大人前來，在那裡膏立大衛作猶大家的王。<br />有人告訴大衛說：「是基列-雅比人埋葬了掃羅。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 23:21; 詩篇 115:15; 路得記 2:20"> 大衛就派遣使者去見基列-雅比人，對他們說：「願你們蒙耶和華的祝福！因為你們以恩慈對待你們的主掃羅，把他埋葬了。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及記 34:6; 馬太福音 5:44"> 你們既然做了這事，如今願耶和華以慈愛和信實對待你們！我也會為此善待你們。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 6:10; 撒母耳記下 10:12; 創世記 15:1"> 現在，你們的主掃羅死了，猶大家已經膏立我作他們的王，所以你們要堅強，作英勇的人。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 14:50; 創世記 32:2; 撒母耳記下 3:7–8"> 尼珥的兒子押尼珥——掃羅的元帥，帶著掃羅的兒子伊施波設過河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="河——輔助詞語。">a</a></sup>到瑪哈念，</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 19:18; 約書亞記 13:8–11; 民數記 1:40"> 然後立他為王治理基列、亞書利、耶斯列、以法蓮、便雅憫——整個以色列。</span>
<span className="v" id="v10" data-v="10"> 掃羅的兒子伊施波設作以色列王的時候四十歲，統治了兩年。猶大家卻跟隨大衛；</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 2:11; 撒母耳記下 5:4–5; 歷代志上 3:4"> 大衛在希伯崙作猶大家的王共七年零六個月。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:25; 約書亞記 10:2; 約書亞記 9:3"> 有一次，尼珥的兒子押尼珥與掃羅的兒子伊施波設的臣僕們，從瑪哈念出來去基遍；</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 8:16; 歷代志上 2:16; 撒母耳記下 20:23"> 洗魯雅的兒子約押與大衛的臣僕們也出來，在基遍的水池旁邊與對方相遇。雙方都坐下，一方在水池這邊，一方在水池那邊。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥對約押說：「讓年輕人起來，在我們面前較量一下吧！」<br />約押說：「那就讓他們起來吧。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 年輕人就起來，按著數目過去：屬於掃羅之子伊施波設的便雅憫人有十二個，大衛的臣僕也有十二個。</span>
<span className="v" id="v16" data-v="16"> 他們各人抓住對方的頭，把刀刺進對方的肋旁，一同倒斃了。因此那地方被稱為希利甲-哈素林，就在基遍。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:1"> 那天的戰事極其激烈，押尼珥和以色列人敗在大衛的臣僕們面前。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 12:8; 哈巴谷書 3:19; 雅歌 8:14"> 當時洗魯雅的三個兒子約押、亞比篩和亞撒暉都在那裡。亞撒暉腿腳敏捷，如同野羚羊。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 2:21; 約書亞記 1:7; 箴言 4:27"> 亞撒暉追趕押尼珥，不偏左右，緊跟在押尼珥後面。</span>
<span className="v" id="v20" data-v="20"> 押尼珥回頭說：「亞撒暉，是你嗎？」<br />他說：「是我。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 14:19"> 押尼珥對他說：「你或轉向左或轉向右，捉住一個年輕人，奪走他的裝備吧！」但亞撒暉不肯停止追趕他。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 3:27; 箴言 29:1; 列王紀下 14:10–12"> 押尼珥再次對亞撒暉說：「你轉開不要追我了！我何必把你擊殺在地呢？那樣我怎麼有臉見你的哥哥約押呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 3:27; 撒母耳記下 4:6; 撒母耳記下 5:6"> 亞撒暉不肯轉開，押尼珥就用矛尾刺入他的腹部，甚至矛從他背後穿出，亞撒暉就仆倒在那裡，當場死了；所有來到亞撒暉倒斃之處的人都站住了，</span>
<span className="v" id="v24" data-v="24"> 但約押和亞比篩卻繼續追趕押尼珥。日落的時候，他們來到亞瑪山，在基亞對面、基遍曠野的路旁。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 便雅憫人集結在押尼珥身後，成為一隊，站在一座山頂上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 46:14; 耶利米書 46:10; 使徒行傳 7:26"> 押尼珥向約押呼喊，說：「難道刀劍要永久吞噬下去嗎？你不知道結局將是苦果嗎？你要到什麼時候才吩咐大家轉回不追趕自己的兄弟呢？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳記下 2:14; 箴言 15:1"> 約押說：「我指著永生的神起誓：要不是你這樣說，大家必定不停止追趕自己的兄弟，直到清晨！」</span>
<span className="v" id="v28" data-v="28"> 於是約押吹響號角，所有軍兵就停下，不再追趕以色列人，不再繼續打仗了。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 2:8; 雅歌 2:17"> 押尼珥和他的部下經過亞拉巴，走了一整夜，然後過了約旦河，又走了一上午<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="走了一上午——傳統譯法作「穿過畢倫」。">b</a></sup>，回到瑪哈念。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 約押追擊押尼珥回來，聚集所有軍兵，大衛的臣僕中少了十九個人，還少了亞撒暉；</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:1; 列王紀上 20:11"> 但大衛的臣僕們擊殺押尼珥的部下便雅憫人，殺死了三百六十個人。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 2:13–16; 撒母耳記上 17:58; 歷代志下 21:1"> 他們抬走亞撒暉，葬在伯利恆他父親的墳墓裡。約押和他的部下走了一整夜，天亮的時候到了希伯崙。</span>
</div>
</div>

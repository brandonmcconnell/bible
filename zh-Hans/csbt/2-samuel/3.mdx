<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:30; 箴言 4:18–19; 約伯記 8:7"> 掃羅家和大衛家之間的爭戰持續了很久，大衛家日漸強盛，掃羅家日漸衰弱。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="歷代志上 3:1–4; 創世記 49:3–4; 撒母耳記下 13:1–29"> 大衛在希伯崙生了幾個兒子：<br /><span className="pl pl-1">長子暗嫩，</span><br /><span className="pl pl-1">是耶斯列人婭希暖所生；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 27:8; 歷代志上 3:1; 申命記 3:14"> <span className="pl pl-1">次子基利押，</span><br /><span className="pl pl-1">是迦密人納巴爾的遺孀婭比蓋所生；</span><br /><span className="pl pl-1">三子押沙龍，</span><br /><span className="pl pl-1">是基述王塔爾邁的女兒瑪迦的兒子；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13–25; 列王紀上 1:5–18"> <span className="pl pl-1">四子亞多尼雅，</span><br /><span className="pl pl-1">是哈及的兒子；</span><br /><span className="pl pl-1">五子示法提雅，</span><br /><span className="pl pl-1">是亞比塔的兒子；</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">六子以特念，</span><br /><span className="pl pl-1">是大衛的妻子以格拉所生。</span><br />這些兒子都是大衛在希伯崙所生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 2:8–9; 歷代志下 25:8; 以賽亞書 8:9–10"> 在掃羅家與大衛家爭戰期間，押尼珥在掃羅家強盛起來。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:8–11; 列王紀上 2:21–22; 撒母耳記下 12:8"> 掃羅有一個妃嬪，名叫利斯巴，是阿亞的女兒。伊施波設對押尼珥說：「你為什麼與我父親的妃嬪同房呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 9:8; 撒母耳記下 16:9; 馬可福音 6:18–19"> 押尼珥因伊施波設的話非常惱火，他說：「我是猶大的狗頭嗎？我如今以恩慈對待你父親掃羅的家和他的兄弟、夥伴，沒有把你交在大衛手中，你現在竟指控我和這女人犯罪！</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:28; 列王紀上 19:2; 路得記 1:17"> 我如果不照著耶和華向大衛所起的誓為大衛去行——從掃羅家挪去王權，確立大衛的寶座，使他統治以色列和猶大，從但直到比爾-謝巴——就願神處置押尼珥，重重地處置他！」</span>
<span className="v" id="v11" data-v="11"> 伊施波設一句話也不敢再回應押尼珥，因為他懼怕押尼珥。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 12:38–40; 撒母耳記下 3:21; 路加福音 16:5–8"> 押尼珥派遣使者代表他去見大衛，說：「這地屬於誰呢？」又說：「你與我立約吧，看哪，我的手必輔助你，使全體以色列人都歸向你。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 43:3; 撒母耳記上 19:11–17; 創世記 44:23"> 大衛說：「好，我與你立約。只是我請求你一件事：你來見我的時候，要先把掃羅的女兒米甲帶來，否則不得見我的面。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 18:27; 撒母耳記上 18:25; 撒母耳記下 2:10"> 隨後大衛派遣使者去見掃羅的兒子伊施波設，說：「請把我的妻子米甲還給我，她是我用一百個非利士人的包皮聘娶的。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:44"> 伊施波設就派人去，把米甲從她丈夫——拉伊的兒子帕爾提業那裡帶回來。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 16:5; 撒母耳記下 19:16; 列王紀上 2:8"> 她丈夫與她一起去，跟在她後面邊走邊哭，直到巴戶琳。押尼珥對帕爾提業說：「走吧，回去吧！」他就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 押尼珥與以色列的長老們商議，說：「你們從前就一直想要大衛作你們的王，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 15:28; 詩篇 89:19–23; 撒母耳記上 9:16"> 現在行動吧！因為耶和華論到大衛曾說：『我要藉著我僕人大衛的手，拯救我的子民以色列脫離非利士人的手和一切仇敵的手。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志上 12:29; 撒母耳記上 10:20–21; 詩篇 68:27"> 押尼珥把這話也說給便雅憫人聽，然後他去希伯崙，把以色列人和便雅憫全家眼中看為好的都說給大衛聽。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 26:30; 以斯帖記 1:3"> 押尼珥帶著二十個人，來到希伯崙見大衛，大衛就為押尼珥和隨同他的人擺設宴席。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 3:12; 列王紀上 11:37; 撒母耳記下 3:10"> 押尼珥對大衛說：「讓我動身，去把全體以色列人都招聚到我主我王這裡，讓他們與你立約，這樣你就可以照著自己的心願統治一切。」於是大衛送押尼珥走，他就平安地離開了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 看哪，大衛的臣僕和約押出擊回來了，帶著許多戰利品。那時押尼珥不在希伯崙大衛那裡，因為大衛已經把他送走，他也平安地離開了。</span>
<span className="v" id="v23" data-v="23"> 約押和隨同的全軍到達後，有人告訴約押說，尼珥的兒子押尼珥曾來過王這裡，王已經把他送走，他也平安地離開了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 3:8; 撒母耳記下 19:5–7; 約翰福音 18:35"> 約押來見王，說：「你做了什麼呢？看哪，押尼珥來見你，你為什麼把他送走呢？他竟然離開了！</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 28:6; 以賽亞書 37:28; 民數記 27:17"> 你知道尼珥的兒子押尼珥，他來是要引誘你，要了解你的出入，了解你的一切行動。」</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 約押從大衛那裡出來，派人去追趕押尼珥；他們從西拉的水井那裡請他回來，大衛卻不知道。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:5; 撒母耳記下 20:9–10; 列王紀上 2:32"> 押尼珥回到希伯崙，約押把他拉到城門裡要與他私下說話。約押在那裡刺穿他的腹部，他就死了，因為他流了約押弟弟亞撒暉的血。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民數記 35:33; 出埃及記 21:12; 創世記 9:6"> 事後大衛聽說了，就說：「對於尼珥的兒子押尼珥被殺流血的事，我和我的王國在耶和華面前永遠是清白的。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 1:16; 詩篇 109:8–19; 利未記 13:44–46"> 願這罪歸到約押的頭上以及他父親的全家，願約押家不斷有患漏症的、患痲瘋的、拄拐杖的、倒在刀下的和缺乏食物的！」</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行傳 28:4; 撒母耳記下 2:19–23"> 約押和他弟弟亞比篩殺押尼珥，是因他在基遍戰場上殺了他們的弟弟亞撒暉。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 37:34; 撒母耳記下 1:11; 撒母耳記下 1:2"> 大衛對約押和跟隨他的全體民眾說：「你們當撕裂衣服、束上麻布，在押尼珥面前哀哭。」然後大衛王跟在棺材後面。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 約伯記 31:28; 撒母耳記上 30:4"> 他們把押尼珥葬在希伯崙，王在押尼珥的墳墓旁放聲大哭，全體民眾也都哭了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 1:17; 歷代志下 35:25; 路加福音 12:19–20"> 王為押尼珥作哀歌，說：<br /><span className="pl pl-1">「押尼珥死去，怎麼像愚頑人死去！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="士師記 16:21; 撒母耳記下 1:12; 約伯記 24:14"> <span className="pl pl-1">你的手沒有被捆住，</span><br /><span className="pl pl-1">你的腳沒有被銅鐐枷住，</span><br /><span className="pl pl-1">你卻仆倒，像人仆倒在不義之子面前！」</span><br />全體民眾就又為他哀哭。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 12:17; 撒母耳記下 1:12; 路得記 1:17"> 人們在白天的時候都來勸大衛吃點東西，但大衛起誓說：「如果我在日落之前吃了餅或其他任何東西，就願神處置我，重重地處置我！」</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 7:37; 詩篇 62:9; 馬可福音 15:11–13"> 人們都認同了，這在他們眼中看為好，正如王所做的每一件事在他們眼中都看為好。</span>
<span className="v" id="v37" data-v="37"> 那天，全體民眾和全以色列都知道，殺尼珥的兒子押尼珥不是出於王意。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約伯記 32:9; 撒母耳記下 2:8; 撒母耳記下 3:12"> 王又對他的臣僕說：「難道你們不知道，今天在以色列中有一位領袖、一位偉人倒下了嗎？</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 2:33–34; 詩篇 101:8; 詩篇 28:4"> 我雖然被膏立為王，今天卻軟弱；這些人——洗魯雅的兒子們強硬得令我作難。願耶和華照著惡人所行的惡，報應惡人！」</span>
</div>
</div>

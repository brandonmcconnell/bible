<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈該書 1:1; 哈該書 2:20; 哈該書 2:10"> 七月二十一日，耶和華的話語臨到先知哈該，說：</span>
<span className="v" id="v2" data-v="2" data-xref="哈該書 1:1; 尼希米記 8:9; 以斯拉記 2:63"> 「現在你要吩咐撒拉鐵的兒子猶大省長所羅巴伯，約薩達的兒子大祭司約書亞，以及餘剩之民，說：</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 3:12; 哈該書 2:9; 以西結書 7:20"> 你們中間，哪個餘剩者見過這殿宇先前的榮耀呢？你們現在怎麼看這殿宇呢？在你們眼中，難道它不是如同無有嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:20; 約書亞記 1:9; 撒迦利亞書 8:9"> 現在，所羅巴伯啊，你要堅強！這是耶和華的宣告。約薩達的兒子大祭司約書亞啊，你要堅強！這地所有的子民哪，你們要堅強！這是耶和華的宣告。你們行動吧，因為我與你們同在。這是萬軍之耶和華的宣告。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 34:10; 出埃及記 29:45–46; 以賽亞書 41:13"> 這是照著你們出埃及時我與你們所立的約，我的靈住在你們中間，你們不要害怕。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯來書 12:26–28; 以賽亞書 10:25; 馬可福音 13:24–26"> 「是的，萬軍之耶和華如此說：再過不久，我必震動諸天和大地、海洋和陸地。</span>
<span className="v" id="v7" data-v="7" data-xref="瑪拉基書 3:1; 列王紀上 8:11; 約翰福音 7:37–39"> 我必震動萬國，萬國的財寶都必運來，我要使這殿宇充滿榮耀。這是萬軍之耶和華說的。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 50:10–12; 詩篇 24:1; 以賽亞書 60:17"> 銀子是我的，金子也是我的。這是萬軍之耶和華的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 85:8–9; 哥林多後書 3:9–10; 歌羅西書 1:19–21"> 萬軍之耶和華說：這殿宇後來的榮耀，必大過先前的榮耀；並且在這地方，我必賜下平安。這是萬軍之耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哈該書 2:20; 哈該書 1:1; 哈該書 1:15–1"> 大流士第二年的九月二十四日，耶和華的話語臨到先知哈該，說：</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 10:10–11; 瑪拉基書 2:7; 申命記 33:10"> 「萬軍之耶和華如此說：你去向祭司們詢問律法，說：</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 6:27; 馬太福音 23:19; 利未記 7:6"> 如果有人用衣襟兜了神聖的肉，又用那衣襟碰了餅、湯、酒、油等任何食物，這些食物就會分別為聖嗎？」<br />祭司們回答說：「不會。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 5:2–3; 民數記 19:11–22; 利未記 22:4–6"> 哈該又問：「如果有人碰了屍體而成為不潔淨的，又碰了這些東西裡的任何一樣，這東西會不潔淨嗎？」<br />祭司們回答說：「會不潔淨。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; 提多書 1:15; 以賽亞書 1:11–15"> 哈該就說：「這子民、這民族在我面前也是如此。這是耶和華的宣告。他們手所做的一切也是如此，他們在我面前獻上的，都是不潔淨的。</span>
<span className="v" id="v15" data-v="15" data-xref="哈該書 1:5; 以斯拉記 3:10; 以斯拉記 4:24"> 現在你們要反思，今天之前，就是耶和華的聖殿還沒有一塊石頭壘在另一塊石頭上的時候，</span>
<span className="v" id="v16" data-v="16" data-xref="哈該書 1:6; 瑪拉基書 2:2; 箴言 3:9–10"> 有人來到二十斗的穀堆，那裡卻只有十斗；有人來到榨酒池，想舀五十桶，那裡卻只有二十桶。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:22; 哈該書 1:11; 哈該書 1:9"> 我用枯焦、霉爛、冰雹打擊你們和你們手所做的一切，但你們還是不歸向我。這是耶和華的宣告。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 8:9; 哈該書 2:15; 以斯拉記 5:1–2"> 現在你們要反思，今天之前，就是九月二十四日奠定耶和華聖殿根基的日子之前——你們要反思——</span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 3:10; 哈巴谷書 3:17–18; 箴言 3:9–10"> 倉裡還有種子嗎？葡萄樹、無花果樹、石榴樹和橄欖樹，也都沒有結果子。但從今天開始，我要祝福你們。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶和華的話語在當月二十四日，第二次臨到哈該，說：</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 4:6–10; 哈該書 2:6–7; 哈該書 1:1"> 「你要告訴猶大省長所羅巴伯說：我將震動諸天和大地，</span>
<span className="v" id="v22" data-v="22" data-xref="彌迦書 5:10; 士師記 7:22; 西番雅書 3:8"> 傾覆各國的王權，除滅列邦的勢力；我要傾覆戰車和乘駕者，戰馬和騎士都將倒在各人兄弟的刀劍之下。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 43:10; 以賽亞書 42:1; 雅歌 8:6"> 這是萬軍之耶和華的宣告：在那日，我必揀選你；我的僕人，撒拉鐵的兒子所羅巴伯啊，這是耶和華的宣告：我必以你為印戒，因為我揀選了你。這是萬軍之耶和華的宣告。」</span>
</div>

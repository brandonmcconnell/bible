<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JDG" data-book-slug="judges" data-book-name="士師記" data-chapter="1" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:18; 民數記 27:21; 士師記 20:28"> 約書亞死了以後，以色列子民求問耶和華說：「我們當中，誰先上去攻打迦南人，與他們爭戰呢？」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="啟示錄 5:5; 希伯來書 7:14; 民數記 2:3"> 耶和華說：「猶大先上去。看哪，我已經把那地交在他手中了。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 10:11; 約書亞記 19:1; 士師記 1:17"> 猶大對他的兄弟西緬說：「請與我一同上去，到我抽籤所得之地，與迦南人爭戰。以後我也與你一同到你抽籤所得之地去。」西緬就與他一同去了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 11:8; 出埃及記 23:28–29; 約書亞記 11:6–8"> 猶大上去，耶和華把迦南人和比利洗人交在他們手中，他們在貝澤克擊殺了一萬人。</span>
<span className="v" id="v5" data-v="5"> 他們在貝澤克遇見阿多尼·貝澤克，與他爭戰，擊敗了迦南人和比利洗人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 阿多尼·貝澤克逃跑，他們追趕他，抓住了他，砍掉了他手腳的拇指。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 15:33; 啟示錄 13:10; 路加福音 6:37–38"> 阿多尼·貝澤克說：「從前有七十個王，被我砍掉了手腳的拇指，在我桌子底下撿吃的。現在神照著我所做的，如此回報我了。」他們把他帶到耶路撒冷，他就死在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 15:63; 士師記 1:21"> 猶大子孫攻打耶路撒冷，攻取了它，用刀擊殺城裡的人，又放火燒了那城。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 15:13–20; 約書亞記 11:21; 約書亞記 10:36"> 之後，猶大子孫下去，與住在山地、南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音譯作「內蓋夫」；本章下同。">a</a></sup>和丘陵地帶的迦南人爭戰。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 13:22; 約書亞記 14:15; 耶利米書 9:23"> 猶大又去攻打住在希伯崙的迦南人，擊殺了示篩、亞希幔和塔爾邁；希伯崙從前名叫基列-阿爾巴。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 15:15; 約書亞記 10:38–39"> 他們又從那裡去攻打底璧的居民，底璧從前名叫基列西弗。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:16–17; 撒母耳記上 17:25; 撒母耳記上 18:23"> 迦勒說：「誰攻打基列西弗，攻取那城，我就把女兒婭撒嫁給他為妻。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 3:9"> 迦勒的弟弟基納斯的兒子俄陀聶攻取了那城，迦勒就把女兒婭撒嫁給他為妻。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:18–19"> 婭撒出嫁的時候，鼓動丈夫從她父親那裡求一塊田。她下了驢，迦勒問她：「你有什麼事呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:18; 哥林多後書 9:5; 彼得前書 3:9"> 她就對父親說：「求你給我一個祝福：你既然把南地給了我，請你把水泉也給我。」於是迦勒把上泉和下泉都給了她。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 10:29–32; 士師記 4:11; 撒母耳記上 15:6"> 摩西的內兄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="內兄——或譯作「岳父」或「姻親」；參《士師記》4:11《民數記》10:29。">b</a></sup>是基尼人，他的子孫與猶大子孫一起離開棕櫚城，上到阿拉德南地的猶大曠野，去與那裡的人住在一起。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 21:3; 士師記 1:3; 約書亞記 19:4"> 猶大與他們的兄弟西緬同去，擊殺住在洗法的迦南人，滅絕了那城。他們就給那城起名為霍爾瑪。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 11:22; 士師記 3:3; 約書亞記 15:45–47"> 猶大也攻取了加沙和它的四境，阿實基倫和它的四境，以革倫和它的四境。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 41:10; 士師記 1:2; 詩篇 60:12"> 耶和華與猶大同在，猶大就占領了山地，然而猶大不能趕出平原的居民，因為他們有鐵戰車。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 1:10; 約書亞記 15:13–14; 民數記 14:24"> 以色列人照著摩西的吩咐，把希伯崙給了迦勒，迦勒從那裡趕出了三支亞衲子孫。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 15:63; 士師記 19:10–12; 士師記 1:8"> 便雅憫人沒有把住在耶路撒冷的耶布斯人趕出去，所以耶布斯人與便雅憫人一起住在耶路撒冷，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士師記 1:19; 列王紀下 18:7; 民數記 1:32"> 約瑟家也上去攻打伯特利，耶和華與他們同在。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 28:19; 創世記 35:6; 創世記 48:3"> 約瑟家探察伯特利，這城從前名叫路斯；</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 2:12–14; 撒母耳記上 30:15"> 探子看見一個人從城裡出來，就對他說：「請指給我們進城的路，我們必以恩慈對待你。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:22–25"> 那人指給他們進城的路，他們就用刀擊殺城裡的人，但放走了那人和他的全家。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 7:6; 歷代志下 1:17"> 那人前往赫提人之地，建造了一座城，又給那城起名為路斯，至今還是這名。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約書亞記 17:11–13; 耶利米書 48:10; 詩篇 106:34–35"> 瑪拿西沒有趕出伯珊和附屬村鎮的居民，特納克和附屬村鎮的居民，多珥和附屬村鎮的居民，以伯蓮和附屬村鎮的居民，米吉多和附屬村鎮的居民；迦南人堅持住在這地。</span>
<span className="v" id="v28" data-v="28"> 以色列強盛的時候，就使迦南人服苦役，沒有完全趕出他們。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 16:10; 列王紀上 9:16"> 以法蓮沒有把住在基色的迦南人趕出去，於是迦南人住在基色，在以法蓮人當中。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:15"> 西布倫沒有把基倫的居民和拿哈拉的居民趕出去，於是迦南人住在西布倫人當中，成了服苦役的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 19:24–30"> 亞設沒有趕出阿科的居民和西頓的居民，以及阿赫拉、阿克濟、赫勒巴、阿費克和利合的居民。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:34–35"> 於是亞設人住在那地的居民迦南人當中，因為他們沒有趕出迦南人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 19:32–38; 士師記 1:30; 詩篇 18:24"> 拿弗他利沒有把伯示麥的居民和伯亞納的居民趕出去，所以拿弗他利人住在那地的居民迦南人當中，但伯示麥和伯亞納的居民成了為他們服苦役的人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 19:47; 士師記 18:1"> 亞摩利人把但子孫壓制在山地，不讓他們下到平原來。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 19:42; 士師記 12:12; 約書亞記 10:12"> 亞摩利人堅持住在希列斯山、阿雅崙和沙勒賓，當約瑟家的勢力強盛的時候，他們就成了服苦役的人。</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 34:4; 約書亞記 15:2–3"> 亞摩利人的邊界從阿克拉賓斜坡起，從西拉往上延伸。</span>
</div>
</div>

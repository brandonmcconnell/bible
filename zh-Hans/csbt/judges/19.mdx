<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 18:1; 士師記 17:8; 瑪拉基書 2:15"> 在以色列沒有王的那些日子，有一個利未人寄居在以法蓮山地深處，他從猶大的伯利恆娶了一個女子為妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 16:28; 申命記 22:21; 利未記 21:9"> 他的妾厭惡他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="厭惡他——七十士譯本作「對他惱怒」；馬索拉文本作「背叛他行淫」。">a</a></sup>，離開他回到猶大伯利恆她的父家，留在那裡四個月。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 34:3; 創世記 50:21; 利未記 19:17"> 她丈夫帶著一個僕人和兩頭驢起程去找她，為要對她說寬心的話，讓她回來。那女子把丈夫帶進父家，父親看見他，就高興地迎接他。</span>
<span className="v" id="v4" data-v="4"> 他的岳父，就是那女子的父親挽留他，他就在岳父那裡住了三天。他們又吃又喝，在那裡留宿。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士師記 19:8; 創世記 18:5; 詩篇 104:15"> 到了第四天，他們清早起來，那人起身要離去，女子的父親對女婿說：「你吃點餅補充一下精力，然後再走吧。」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:9; 士師記 16:25; 路得記 3:7"> 於是他們兩人又坐下來，一同吃喝。女子的父親對那人說：「請你再過一夜吧，讓你心裡暢快！」</span>
<span className="v" id="v7" data-v="7"> 那人起身要走，但他岳父再三勸說，他就又在那裡過了一夜。</span>
<span className="v" id="v8" data-v="8"> 第五天他清早起來要走，女子的父親又說：「你補充一下精力，等到下午再走吧。」於是他們兩人又一起吃飯。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各書 4:13–14"> 然後那人帶著他的妾和僕人起身要走，他的岳父——女子的父親又對他說：「你看，天快要黑了，再過一夜吧。看哪，天晚了，就在這裡過夜吧，讓你心裡暢快，明天清早起來再上路回家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="家——或譯作「自己的帳篷」。">b</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 15:63; 約書亞記 15:8; 士師記 1:8"> 可是那人不願再過一夜了，就給兩頭驢備好鞍，帶著他的妾起身離去。他來到耶布斯對面，耶布斯就是耶路撒冷。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 5:6; 士師記 1:21; 士師記 19:10"> 他們臨近耶布斯的時候，天已經很晚了，僕人就對主人說：「讓我們去，前往這耶布斯人的城，在那裡過夜吧。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 主人對他說：「我們不要進外邦人的城，那不是以色列人的地方；我們要前往基比亞。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 10:26; 何西阿書 5:8; 以賽亞書 10:29"> 主人又對僕人說：「走吧，我們趕到基比亞或拉瑪，在其中一個地方過夜。」</span>
<span className="v" id="v14" data-v="14"> 他們就繼續往前走，臨近便雅憫的基比亞時，已經日落了。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 19:18; 馬太福音 25:35; 馬太福音 25:43"> 於是他們前往那裡去，要在基比亞過夜。他們來到城中的廣場坐下，卻沒有人接待他們到家裡過夜。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 19:1; 詩篇 104:23; 創世記 3:19"> 看哪，有一個老人傍晚從田間勞作回來，他是以法蓮山地的人，寄居在基比亞；那裡是便雅憫人的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:17; 創世記 16:8"> 老人舉目看見城中廣場上那個客旅，就問他說：「你從哪裡來，要往哪裡去呢？」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 18:31; 約翰福音 15:6; 撒母耳記上 1:7"> 那人回答：「我們是過路的，從猶大的伯利恆到以法蓮山地的深處去，我原是那裡的人。我去了猶大的伯利恆，現在要回我的家鄉<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="現在要回我的家鄉——依據七十士譯本；馬索拉文本作「現在要去耶和華的家」，指的是「伯特利」。">c</a></sup>，可是這裡沒有人接待我到家裡去。</span>
<span className="v" id="v19" data-v="19"> 其實我們有乾草和飼料餵我們的驢，你僕人我和你的這女僕，以及隨行的年輕人也有餅和酒；我們什麼都不缺。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 6:23; 雅各書 2:15–16; 希伯來書 13:2"> 老人說：「願你平安！你有什麼需要，只管讓我來承擔，可不要在廣場上過夜。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:24; 創世記 18:4; 路加福音 7:44"> 於是老人把他們帶回家，給驢拌了飼料，他們也洗了腳，然後吃喝。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 19:4–5; 哥林多前書 6:9; 士師記 20:5"> 他們正心裡暢快的時候，看哪，城裡的卑劣之徒圍住了房屋，擁擠著撞門<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="擁擠著撞門——或譯作「不斷拍門」。">d</a></sup>，對那老家主說：「把來到你家的人帶出來，我們要與他交合。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 34:7; 撒母耳記下 13:12; 士師記 20:6"> 家主出來見他們，對他們說：「不要這樣，我的兄弟們，請不要作惡。既然這人已經進了我的家，就請你們不要做這醜惡的事。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 19:8; 申命記 21:14; 創世記 34:2"> 看哪，我有個女兒還是處女，還有這人的妾，我把她們帶出來吧，你們可以玷辱她們，隨意對待她們<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="隨意對待她們——原文直譯「對她們做你們眼中看為好的」。">e</a></sup>，只是不可對這人做如此醜惡的事。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="何西阿書 10:9; 何西阿書 9:9; 何西阿書 7:4–7"> 可是那些人不願聽他的。那人就拉住自己的妾，推到外面給了他們。他們與她交合，整夜凌辱她，直到早晨天亮的時候，才放她走。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 19:3; 創世記 18:12; 彼得前書 3:6"> 天快亮的時候，那女人回來，倒在她丈夫留宿的老人家門口，直到天亮。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 她丈夫清早起來，打開房門出去，要繼續趕路，卻發現那女人——他的妾倒在房門口，雙手搭在門檻上。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 20:5; 列王紀上 18:29"> 丈夫對她說：「起來，我們走吧！」可是沒有回應。於是那人把她馱在驢背上，動身回本地去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 20:6–7; 撒母耳記上 11:7; 羅馬書 10:2"> 回到家裡，他拿來刀，扶住他的妾，把她的屍體切成十二塊，送到以色列全境。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 20:7; 箴言 13:10; 何西阿書 9:9"> 所有看見的人都說：「以色列子孫從埃及地上來的那天起，直到今天，從來沒有發生過、也沒有見到過這樣的事。大家要考慮、商議，對此表態。」</span>
</div>
</div>

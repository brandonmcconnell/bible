<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:31; 詩篇 83:2–4; 撒母耳記下 15:6"> 耶路巴力的兒子亞比米勒到示劍去見他的舅舅們，與他們和他外祖父的全家商議，說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:14; 士師記 8:30; 希伯來書 2:14"> 「請問問所有的示劍人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="示劍人——原文直譯「示劍的主人」；本章下同。">a</a></sup>：『你們覺得哪一樣好：讓耶路巴力的兒子七十人都管轄你們，還是讓一個人管轄你們？』你們要記得，我是你們的骨肉之親。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 29:15; 詩篇 10:3; 箴言 1:11–14"> 他的舅舅們把他這些話都說給所有的示劍人聽，他們的心就傾向亞比米勒，因為他們想：「亞比米勒是我們的兄弟。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 8:33; 使徒行傳 17:5; 歷代志下 13:7"> 他們從巴力比利土的廟宇拿出七十錠銀子給了亞比米勒，亞比米勒用這些銀子雇用了一些無賴和流氓，他們就跟隨他。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 11:1–2; 歷代志下 21:4; 士師記 6:24"> 然後他來到俄弗拉，到他的父家，在一塊磐石上把自己的兄弟，就是耶路巴力的七十個兒子都殺了，只剩下耶路巴力最小的兒子約坦，因為他躲藏了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:9; 列王紀上 12:20; 列王紀下 12:20"> 所有的示劍人和所有的伯米羅人聚集起來，到示劍的橡樹神柱旁，立亞比米勒為王。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="申命記 11:29; 約翰福音 4:20; 申命記 27:12"> 有人告訴了約坦，他就去站在基利心山頂上，放聲呼喊，對他們說：<br /><span className="pl pl-1">「示劍的主人哪，你們聽我說，</span><br /><span className="pl pl-1">願神也垂聽你們！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="士師記 8:22–23; 但以理書 4:10–18; 列王紀下 14:9"> <span className="pl pl-1">有一天，樹木們執意要去膏立一個王統治他們。</span><br /><span className="pl pl-1">他們對橄欖樹說：『你作王統治我們吧。』</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="利未記 2:1; 出埃及記 29:7; 使徒行傳 4:27"> <span className="pl pl-1">但橄欖樹回答他們：</span><br /><span className="pl pl-1">『難道我要停止出產那讓神和人得尊榮的油，</span><br /><span className="pl pl-1">而去飄摇在眾樹之上嗎？』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10"> <span className="pl pl-1">樹木們又對無花果樹說：</span><br /><span className="pl pl-1">『你來作王統治我們吧。』</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> <span className="pl pl-1">但無花果樹回答他們：</span><br /><span className="pl pl-1">『難道我要停止出產甜美的果實，</span><br /><span className="pl pl-1">而去飄摇在眾樹之上嗎？』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">樹木們又對葡萄樹說：</span><br /><span className="pl pl-1">『你來作王統治我們吧。』</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 104:15; 傳道書 10:19; 民數記 15:5"> <span className="pl pl-1">但葡萄樹回答他們：</span><br /><span className="pl pl-1">『難道我要停止出產讓神和人喜樂的新酒，</span><br /><span className="pl pl-1">而去飄摇在眾樹之上嗎？』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 14:9"> <span className="pl pl-1">於是所有的樹木對荊棘說：</span><br /><span className="pl pl-1">『你來作王統治我們吧。』</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:2; 士師記 9:20; 何西阿書 14:7"> <span className="pl pl-1">荊棘回答樹木們：</span><br /><span className="pl pl-1">『你們如果真誠地膏立我作王統治你們，</span><br /><span className="pl pl-1">就來投靠在我的影子下吧！</span><br /><span className="pl pl-1">否則，就願火從荊棘裡出來，</span><br /><span className="pl pl-1">吞噬黎巴嫩的香柏樹。』</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 8:35"> 「現在，如果你們立亞比米勒為王是真誠無偽地行事，如果你們是善待耶路巴力和他的家，如果你們是照著他應得的對待他——</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:4; 羅馬書 5:8; 啟示錄 12:11"> 要知道，從前我父親為你們爭戰，捨命不顧，解救你們脫離了米甸人的手，</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:5–6; 士師記 8:30–31; 士師記 9:14"> 今天你們卻起來攻擊我父親的家，在一塊磐石上殺死了他的七十個兒子，而立他婢女之子亞比米勒為示劍人的王，因『他是你們的兄弟』——</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 8:6; 雅各書 4:16; 腓立比書 3:3"> 今天如果你們是真誠無偽地對待耶路巴力和他的家，你們就因亞比米勒而歡喜吧，也願他因你們而歡喜。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:15; 士師記 9:56–57; 歷代志下 20:22–23"> 否則，就願火從亞比米勒發出，吞噬示劍人和伯米羅人；也願火從示劍人和伯米羅人發出，吞噬亞比米勒！」</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 21:16; 撒母耳記下 20:14; 約書亞記 19:8"> 隨後約坦就逃跑，逃到了比爾，住在那裡，躲避他的兄弟亞比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 亞比米勒統管治理以色列三年。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 33:1; 以賽亞書 19:14; 以賽亞書 19:2"> 那時，神使攪擾之靈來到亞比米勒和示劍人之間，示劍人就背棄了亞比米勒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 2:32; 詩篇 7:16; 以斯帖記 9:25"> 這是為要耶路巴力七十個兒子被害的報應臨到，使他們的血債歸在那殺害他們的人——他們的兄弟亞比米勒身上，也歸到那些幫助亞比米勒去殺害自己兄弟的示劍人身上。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 8:12–13; 箴言 1:11–12; 約書亞記 8:4"> 示劍人在山頂對亞比米勒設下埋伏，並且搶奪所有從他們那條路經過的人。有人把這事告訴了亞比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 13:8; 創世記 19:7"> 那時伊別德的兒子迦勒和他的兄弟們前來，路過示劍，示劍人都信任他。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 9:4; 士師記 9:46; 詩篇 109:17"> 他們出去到田間，摘取葡萄園的葡萄踹酒，舉行慶典；然後進入他們神明的廟宇吃喝，並且詛咒亞比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 34:2; 創世記 34:6; 撒母耳記上 25:10"> 伊別德的兒子迦勒說：「亞比米勒是誰，我們示劍人竟然要服事他？亞比米勒不是耶路巴力的兒子嗎？他的幫手不是西布勒嗎？你們當服事示劍之父哈莫爾的後人！我們為什麼要服事亞比米勒呢？</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 15:4; 撒母耳記下 2:14–17; 以賽亞書 36:8–9"> 但願這民歸在我手下，我就除掉亞比米勒，我要對亞比米勒說：『增派你的軍隊出來吧！』」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 城主西布勒聽到伊別德的兒子迦勒的話，就發怒，</span>
<span className="v" id="v31" data-v="31"> 暗中派遣使者到亞比米勒那裡，說：「看哪，伊別德的兒子迦勒和他的兄弟們來到了示劍，他們在煽動那城的人反對你。</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 3:15; 詩篇 36:4; 箴言 1:11–16"> 現在，你和跟隨你的軍兵要在夜間動身，埋伏在田野，</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 10:7; 傳道書 9:10; 利未記 25:26"> 到清晨太陽升起的時候，你就早早起來衝向那城。看哪，當迦勒和跟隨他的人出來攻擊你時，你就全力<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="全力——原文直譯「照著手上所有的」。">b</a></sup>對付他吧。」</span>
<span className="v" id="v34" data-v="34"> 於是亞比米勒和所有跟隨他的軍兵夜間動身，分成四隊，對示劍設下埋伏。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 當伊別德的兒子迦勒出來站在城門口的時候，亞比米勒和跟隨他的人就從埋伏的地方起來。</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 8:24; 以西結書 7:7"> 迦勒看見那些人，就對西布勒說：「看哪，有人正從山頂下來！」西布勒卻對他說：「你把山的影子看成人了。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命記 18:14"> 迦勒又再次發話說：「看哪，有人正從山腰<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="山腰——或譯作「中心地帶」。">c</a></sup>下來，還有一隊人正從『算命者橡樹』的方向前來。」</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 9:28–29; 列王紀下 14:8–14; 撒母耳記下 2:26–27"> 西布勒就對他說：「你曾經說過：『亞比米勒是誰，我們竟然要服事他。』現在你所誇口的在哪裡呢？這不是你所藐視的人嗎？現在請你出去，與他們爭戰吧！」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 於是迦勒率領示劍人出去，與亞比米勒爭戰。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 20:18–21; 列王紀上 20:30"> 結果亞比米勒追擊迦勒，迦勒從他面前逃跑，有許多人受傷仆倒，一直到城門口。</span>
<span className="v" id="v41" data-v="41" data-xref="士師記 9:28; 士師記 9:30"> 之後，亞比米勒住在亞魯瑪，西布勒趕走迦勒和他的兄弟們，不讓他們住在示劍。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 第二天，示劍人出去到田野，有人報告了亞比米勒。</span>
<span className="v" id="v43" data-v="43"> 他就帶領軍兵，分成三隊，埋伏在田野。他觀看，看見有人從城裡出來，他就起來擊殺他們。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太書 5:15; 士師記 9:15; 士師記 9:20"> 亞比米勒和跟隨他的一隊人衝上去，守在城門口，另有兩隊人衝向所有在田野中的人，擊殺他們。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 3:25; 申命記 29:23; 雅各書 2:13"> 亞比米勒一整天攻打那城，攻取了它，殺了城裡的人。他還拆毀那城，並且撒上鹽。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士師記 8:33; 士師記 9:4; 列王紀上 8:26"> 示劍樓所有的人都聽說了，就進入伊勒比利特廟宇的地下室。</span>
<span className="v" id="v47" data-v="47"> 有人報告亞比米勒說，示劍樓所有的人都聚集在一處，</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 68:14; 箴言 1:11–12; 士師記 7:17–18"> 於是亞比米勒和跟隨他的所有軍兵上到撒門山。亞比米勒手拿斧頭，砍下一根樹枝，舉起來扛在肩上，然後吩咐跟隨他的軍兵：「你們看我怎麼做，也趕快照樣做！」</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太書 5:15; 雅各書 3:16; 士師記 9:20"> 於是所有軍兵也各自砍下一根樹枝，跟隨亞比米勒，把樹枝堆在地下室上面，然後放火燒毀地下室。這樣，示劍樓的人也都死了，男人和女人約有一千人。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50"> 接著亞比米勒前往提貝斯，對著提貝斯紮營，攻取了它。</span>
<span className="v" id="v51" data-v="51"> 城中有一座堅固的塔樓，那城所有的人，無論男女都逃到那裡，把自己關在裡面，上到塔樓的屋頂。</span>
<span className="v" id="v52" data-v="52" data-xref="士師記 9:48–49; 列王紀下 14:10; 列王紀下 15:16"> 亞比米勒來到塔樓那裡，攻打它。他接近塔樓門口，要放火燒毀它。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 11:21; 約伯記 31:3; 耶利米書 49:20"> 這時有一個女人把一塊磨石扔到亞比米勒頭上，砸破了他的頭顱。</span>
<span className="v" id="v54" data-v="54" data-xref="撒母耳記上 31:4–5"> 他趕快呼喚替他拿兵器的年輕人，對他說：「拔出你的刀來，把我殺了！免得人們論到我說：『一個女人殺了他。』」於是那年輕人把他刺死了。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳記下 18:16; 撒母耳記下 20:21–22; 列王紀上 22:35–36"> 以色列人看到亞比米勒死了，就各回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="詩篇 94:23; 士師記 9:24; 箴言 5:22"> 這樣，神報應了亞比米勒的惡行，就是他對父親作惡，殺了自己的七十個兄弟。</span>
<span className="v" id="v57" data-v="57" data-xref="士師記 9:20; 約書亞記 6:26; 列王紀上 16:34"> 神也使示劍人的一切惡行報應到他們自己頭上，耶路巴力的兒子約坦的詛咒臨到了他們身上。</span>
</div>
</div>

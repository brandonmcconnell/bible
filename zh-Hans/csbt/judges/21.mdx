<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:1; 馬可福音 6:23; 使徒行傳 23:12"> 以色列人曾在米斯巴起誓說：「我們當中誰也不可把女兒嫁給便雅憫人為妻。」</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 20:26; 士師記 20:18; 撒母耳記上 30:4"> 所以民眾來到伯特利，坐在神面前直到傍晚。他們放聲大哭，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 74:1; 約書亞記 7:7–9; 以賽亞書 63:17"> 說：「以色列的神耶和華啊！為什麼在以色列發生這樣的事呢？今天以色列竟然少了一個支派。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 24:25; 列王紀上 8:64; 詩篇 78:34–35"> 第二天，民眾清早起來，在那裡築了一座祭壇，獻上燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 5:23; 士師記 21:18; 士師記 21:1"> 那時，以色列人問：「以色列各支派中，誰沒有到耶和華面前來參加集會？」原來他們針對沒有上米斯巴到耶和華面前來的人，曾嚴厲起誓說：「那人必須被處死。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 21:15; 士師記 20:23; 路加福音 19:41–42"> 以色列人為他們的兄弟便雅憫難過，說：「如今以色列中有一個支派被砍掉了！</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:1; 士師記 21:18; 撒母耳記上 14:28–29"> 我們怎樣才能使他們剩下的人有妻子呢？我們已經指著耶和華起了誓，不把我們的女兒嫁給便雅憫人為妻。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 31:11–13; 撒母耳記上 11:1–3; 撒母耳記下 2:5–6"> 他們就問：「以色列支派中誰沒有上米斯巴，到耶和華面前來呢？」結果發現基列-雅比沒有一個人到營地來參加集會。</span>
<span className="v" id="v9" data-v="9"> 他們數點民眾，發現基列-雅比的居民沒有一個人在場。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 5:23; 士師記 21:5; 撒母耳記上 11:7"> 於是會眾從勇士中派出一萬兩千人，吩咐他們說：「你們去，用刀擊殺基列-雅比的居民，包括女人和孩童。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 31:17–18; 申命記 2:34"> 你們要這樣做：把所有的男人，以及所有與男人同房過的女人，都滅絕淨盡。」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:1; 耶利米書 7:12; 詩篇 78:60"> 他們在基列-雅比的居民中，找到四百個年輕處女，都是沒有與男人同房過的。他們就把這些處女帶到迦南地的示羅營地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 20:47; 申命記 20:10; 以弗所書 2:17"> 全體會眾派人去，到臨門岩石那裡與便雅憫人商談，向他們提議和好，</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 21:12; 哥林多前書 7:2; 士師記 20:47"> 便雅憫人就在那時回來了。以色列人把存活的基列-雅比女子給了便雅憫人為妻，卻發現不夠分給他們所有人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 21:6; 歷代志上 15:13; 以賽亞書 58:12"> 人們為便雅憫人難過，因為耶和華使以色列眾支派有了破口。</span>
<span className="v" id="v16" data-v="16"> 會眾的長老們說：「便雅憫的女子都滅絕了，我們怎樣才能使剩下的人有妻子呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 26:55; 民數記 36:7"> 他們又說：「便雅憫的倖存者必須有繼承產業的，免得以色列中一個支派被抹掉。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 21:1; 士師記 11:35"> 可是我們又不能把自己的女兒嫁給他們為妻。」因為以色列人已經起誓說，把女兒嫁給便雅憫人的必受詛咒。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 16:10; 申命記 16:1; 申命記 16:13"> 他們就說：「看哪，示羅每年都有耶和華的節期。」示羅在伯特利以北，伯特利至示劍的大道東邊，利波拿的南邊。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 於是他們吩咐便雅憫人說：「你們去埋伏在葡萄園裡，</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:34; 出埃及記 15:20; 傳道書 3:4"> 你們看著，一見示羅的女子出來繞著圈跳舞，你們就從葡萄園出來，各自搶走一個示羅女子為妻，帶回便雅憫地去。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 21:1; 士師記 21:18; 士師記 21:14"> 當他們的父親或兄弟來與我們爭論的時候，我們會對他們說：『請看在我們的情面上恩待他們吧，因為我們在戰爭中沒有使他們每個人都娶到妻子。何況不是你們自己把女兒嫁給了他們，不然你們現在就要承擔罪責了。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:48"> 便雅憫人就照著去做了。他們按著自己的人數，把他們搶奪的跳舞女子娶來為妻，然後回自己的繼業去，重建城鎮，住在其中。</span>
<span className="v" id="v24" data-v="24"> 那時，以色列人也離開那裡，各歸自己的支派和家族，各回自己的繼業去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 12:8; 士師記 17:6; 箴言 3:5"> 在那些日子，以色列沒有王，各人做自己眼中看為正的事。</span>
</div>
</div>

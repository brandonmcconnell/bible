<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 20:2; 創世記 17:7–8; 利未記 26:42"> 耶和華的使者從吉甲上到波金，說：「我把你們從埃及帶上來，領你們進入我起誓要給你們先祖的土地。那時我說：『我永不廢除我與你們所立的約，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:2–4; 耶利米書 2:36; 以斯拉記 9:1–3"> 至於你們，不可與這地的居民立約，你們要拆毀他們的祭壇。』你們卻沒有聽從我的話。你們做的這是什麼事呢？</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 23:13; 民數記 33:55; 申命記 7:16"> 因此我說：我不再從你們面前驅逐這些居民，他們必成為你們肋旁的刺<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="刺——輔助詞語。">a</a></sup>，他們的神明必成為你們的陷阱。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 31:9; 箴言 17:10; 撒迦利亞書 12:10"> 耶和華的使者對全體以色列子民說這些話的時候，民眾都放聲大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 7:9; 創世記 35:8; 約書亞記 7:26"> 於是他們給那地方起名為波金，並在那裡向耶和華獻祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 24:28–31; 約書亞記 22:6"> 約書亞遣散了民眾，以色列子民就各到自己的繼業之地，擁有那地。</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:12; 約書亞記 24:31; 歷代志下 24:2"> 約書亞在世的日子以及他死後，那些見過耶和華為以色列所行一切大事的長老們還在世的日子，民眾都服事耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 24:29–30"> 耶和華的僕人嫩的兒子約書亞死了，享年一百一十歲。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 19:50; 約書亞記 24:30"> 人們把他葬在他繼業的境內，在迦實山的北方，以法蓮山地的亭拿-希列斯。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 2:12; 提多書 1:16; 出埃及記 5:2"> 那世代的人也都歸到他們列祖那裡去了，在他們之後另外的世代興起，不知道耶和華，也不知道耶和華為以色列所行的事。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 4:1; 士師記 6:1; 士師記 3:7"> 以色列子民做耶和華眼中看為惡的事，服事眾巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:5; 申命記 13:5; 申命記 6:14–15"> 他們離棄了把他們從埃及地領出來的耶和華他們祖先的神，而跟從別的神，就是他們四圍各民族的神明，向它們下拜，惹怒了耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:6; 詩篇 106:36; 士師記 3:7"> 他們離棄耶和華，服事巴力和亞斯她錄。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 17:20; 詩篇 106:40–42; 申命記 32:30"> 於是耶和華對以色列發怒，把他們交在搶掠者手中，使他們被搶掠；又把他們交於<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="交於——原文直譯「賣到」。">b</a></sup>四圍的仇敵手中，使他們在仇敵面前再也站立不住。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; 約書亞記 23:15–16; 利未記 26:14–46"> 他們每次出戰，耶和華的手都以禍患攻擊他們，正如耶和華所說的，如耶和華對他們所起的誓。他們就陷入了極大的危難。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 13:20; 詩篇 106:43–45; 撒母耳記上 12:11"> 於是耶和華興起士師，拯救他們脫離搶掠者的手。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 1:6; 申命記 9:12; 士師記 2:7"> 但他們連士師也不聽從，繼續行淫追隨別的神，向它們下拜，很快偏離了祖先所行的道路，不像他們祖先那樣聽從耶和華的誡命。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 32:36; 約書亞記 1:5; 出埃及記 2:24"> 當耶和華為他們興起士師的時候，耶和華與士師同在；士師在世的日子，耶和華都拯救他們脫離仇敵的手。他們因壓迫和苦害他們之人而發出哀聲，耶和華就施憐憫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="施憐憫——或譯作「感到後悔」。">c</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 8:33; 士師記 4:1; 馬太福音 23:32"> 可是當士師死了之後，他們就反轉，比他們的祖先更敗壞，去跟從別的神，服事那些神明，向它們下拜。他們總不離棄他們的惡行和頑梗行為。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 2:14; 約書亞記 23:16; 出埃及記 32:10–11"> 於是耶和華對以色列人發怒，說：「既然這民違背我為他們祖先立定的約，不聽從我的話，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 23:13; 士師記 2:3; 士師記 3:3"> 那麼我也不再從他們面前，趕出約書亞死時還剩下的各族中任何一人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 8:2; 申命記 8:16; 申命記 13:3"> 我要藉著這些民族試驗以色列，看他們是否會像他們的祖先那樣，謹守遵行耶和華的道。」</span>
<span className="v" id="v23" data-v="23"> 這樣，耶和華留下了這些民族，沒有很快趕出他們，沒有把他們交在約書亞手中。</span>
</div>
</div>

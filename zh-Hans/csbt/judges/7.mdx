<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:32; 傳道書 9:10; 創世記 12:6"> 耶路巴力——就是基甸——與跟隨他的全體軍兵清早起來，在哈羅德泉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哈羅德泉——或譯作「恩哈羅德」。">a</a></sup>旁紮營。米甸營地在他們北邊，在摩利山下的平原上。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:17; 哥林多前書 1:27–29; 哥林多後書 4:7"> 耶和華對基甸說：「跟隨你的人太多了，我不能把米甸人交在他們手中，免得以色列人向我自誇說：『是我們自己的手拯救了我們。』</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:8; 啟示錄 17:14; 啟示錄 21:8"> 現在，你要向軍兵宣告說：『誰懼怕、戰兢，他就可以回去，盡快離開基列山。』」於是有兩萬兩千人回去，一萬人留了下來。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 33:16; 撒母耳記上 16:7; 撒母耳記上 14:6"> 耶和華對基甸說：「人還是太多了。你帶他們下到水邊，我要在那裡為你試驗他們。我對你說『這人可以與你同去』，他就可以與你同去；但我對你說『這人不可與你同去』，他就不可以去。」</span>
<span className="v" id="v5" data-v="5"> 基甸就把軍兵帶到水邊。耶和華對基甸說：「凡是用舌頭舔水，像狗舔水那樣的，你要把他們安置在一處；凡是雙膝跪下喝的，也要如此。」</span>
<span className="v" id="v6" data-v="6"> 這樣，用手捧到嘴邊舔水的數目有三百人，其餘的人都是雙膝跪下喝水。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 14:6; 以賽亞書 41:14–16; 士師記 7:18–22"> 耶和華對基甸說：「我要用這三百個舔水的人拯救你們，把米甸人交在你手中。其他所有的軍兵，就讓他們各回自己的地方去吧。」</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 6:20; 民數記 10:9; 約書亞記 6:4"> 於是，這三百人手中接過了軍兵的食物和號角，基甸打發其他以色列人各回自己的帳篷，只留下這三百人。米甸營地在他們下面的平原中。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 46:2–3; 士師記 3:28; 使徒行傳 18:9–10"> 當天夜裡，耶和華對基甸說：「起來，下去攻打那營地，因為我已經把它交在你手中了。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:10–14; 士師記 4:8–9"> 如果你害怕下去，你就與你的僕人普拉先下到那營地去，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 6:10; 士師記 7:13–15; 以賽亞書 35:3–4"> 聽聽他們說什麼，隨後你就會堅強，可以下去攻打那營地。」於是基甸和他的僕人普拉下到那營地駐軍的前哨。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士師記 8:10; 士師記 6:5; 約書亞記 11:4"> 米甸人、亞瑪力人和所有的東方人散布在平原上，多如蝗蟲；他們的駱駝多如海邊的沙，無法數算。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 1:27; 以賽亞書 41:14–15; 士師記 4:9"> 基甸到了，正好有一個人在給同伴講述他的夢。他說：「看哪，我做了一個夢，夢見一個大麥餅滾進米甸營地，到了帳篷這裡，撞倒帳篷，帳篷就翻轉朝上倒塌了。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 7:6–7; 約書亞記 2:9; 約書亞記 2:24"> 他的同伴回答說：「這不是別的，而是以色列人約阿施之子基甸的刀！神已經把米甸和全營交在他手中了。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 10:4–6; 創世記 40:8; 歷代志下 20:18–19"> 基甸聽見了這夢的講述和解釋，就俯伏下拜，然後回到以色列營地，說：「起來，耶和華已經把米甸全營交在你們手中了！」</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 4:7"> 基甸把三百人分成三隊，把號角和空罐子交在他們每個人手中，罐子裡放進了火把。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 11:1; 馬太福音 16:24; 希伯來書 13:7"> 基甸對他們說：「你們看著我，照樣去做。看哪，我到那營地邊上的時候，我怎樣做，你們也怎樣做。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 20:15–17; 撒母耳記上 17:47"> 當我和所有跟隨我的人吹響號角，你們也要在全營四圍吹響號角，並且呼喊：『為耶和華！為基甸！』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="詩篇 2:9; 出埃及記 14:24; 馬太福音 25:6"> 剛到半夜的更次，守衛才換了崗的時候，基甸和跟隨他的一百人來到那營地邊上，吹響號角，打碎手中的罐子。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 27:13; 哥林多後書 4:7; 哥林多前書 15:52"> 於是三隊的人都吹響號角，打破罐子，左手握住火把，右手拿著號角吹，並且呼喊：「為耶和華、為基甸舉刀！」</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 20:17; 箴言 28:1; 列王紀下 7:6–7"> 他們在那營地四圍各守其位。全營地的人都亂跑，一邊喊叫，一邊逃跑。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 4:12; 約書亞記 6:20; 約書亞記 6:4"> 當三百人吹響號角時，耶和華使全營地的人彼此刀劍相向。那些軍兵往西利拉方向逃跑，逃到伯哈示塔，直到靠近塔巴的亞貝勒-米何拉邊緣。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 6:35; 撒母耳記上 14:21–22"> 以色列人就從拿弗他利、亞設和瑪拿西全地聚集起來，追擊米甸人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="士師記 3:27–28; 腓立比書 1:27; 羅馬書 15:30"> 基甸派遣使者走遍全以法蓮山地，說：「你們下來迎戰米甸人，在他們之前占據約旦河的各渡口，直到伯巴拉。」於是，以法蓮人都被召集起來，占據約旦河的各渡口，直到伯巴拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="占據約旦河的各渡口，直到伯巴拉——或譯作「守住直到伯巴拉的各渡口，守住約旦河」。">b</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 10:26; 士師記 8:3–4; 詩篇 83:11–12"> 他們捉住米甸的兩個首領俄立和西伊伯，在俄立磐石那裡殺了俄立，在西伊伯榨酒池那裡殺了西伊伯。然後他們追趕米甸人，並把俄立和西伊伯的頭顱送到約旦河對岸基甸那裡。</span>
</div>
</div>

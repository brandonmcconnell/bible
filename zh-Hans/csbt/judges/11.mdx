<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:32; 士師記 6:12; 列王紀下 5:1"> 基列人耶弗塔是個英勇的戰士，是一個妓女的兒子，基列與這妓女生了耶弗塔。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:10; 箴言 2:16; 申命記 23:2"> 基列的妻子也給基列生了兒子，這些兒子們長大了，就趕走耶弗塔，說：「你不可在我們父親的家繼承產業，因為你是外女的兒子。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 9:4; 撒母耳記上 22:2; 撒母耳記下 10:8"> 於是，耶弗塔從他的兄弟們面前逃走，住在陀伯地。有一些無賴聚集到耶弗塔那裡，與他一同出入。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 10:9"> 過了一些日子，亞捫人與以色列爭戰。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:22–23; 使徒行傳 7:35–39; 哥林多前書 1:27–29"> 當亞捫人與以色列爭戰的時候，基列的長老們去請耶弗塔從陀伯地回來。</span>
<span className="v" id="v6" data-v="6"> 他們對耶弗塔說：「你來作我們的統帥吧，我們好與亞捫人爭戰。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 3:9; 創世記 45:4–5; 以賽亞書 60:14"> 耶弗塔回答基列的長老們：「你們不是恨我嗎？你們把我從我父家趕走了，為什麼現在危難臨到你們，就來找我呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士師記 10:18; 列王紀上 13:6; 出埃及記 10:17"> 基列的長老們對耶弗塔說：「我們現在回來找你，就是要你與我們同去，與亞捫人爭戰，你可以作我們基列所有居民的領袖。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 32:20–29"> 耶弗塔對基列的長老們說：「如果你們請我回去攻打亞捫人，而耶和華把他們交給我，那我就作你們的領袖。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 42:5; 創世記 31:50; 耶利米書 29:23"> 基列的長老們回答耶弗塔：「有耶和華在我們之間作證：我們一定照著你的話這樣做。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 10:17; 撒母耳記上 10:17; 士師記 20:1"> 於是耶弗塔與基列的長老們同去，民眾就立耶弗塔為他們的領袖和統帥。耶弗塔在米斯巴將他那些話全都在耶和華面前述說了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:26; 馬太福音 18:15–16; 箴言 25:8–9"> 耶弗塔派遣使者去見亞捫人的王，說：「我與你有什麼相干，你竟然來我這裡，侵犯我的國土呢？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 32:22; 民數記 21:24–26; 申命記 2:37"> 亞捫人的王回答耶弗塔的使者們：「因為以色列從埃及上來的時候，奪取了我的土地，從亞嫩河直到雅博河、約旦河。所以現在，你要和平歸還這些土地。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:11; 羅馬書 12:18; 希伯來書 12:14"> 耶弗塔再次派遣使者去見亞捫人的王，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 2:19; 申命記 2:9; 民數記 21:27–30"> 對他說：「耶弗塔如此說：以色列並沒有奪取摩押地或亞捫人之地。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 14:25; 申命記 1:40; 民數記 20:1"> 因為以色列從埃及上來的時候，走過曠野到紅海，然後來到加低斯，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 20:14–21; 申命記 2:4–9; 民數記 20:1"> 以色列派遣使者去見以東王，說：『請讓我們從你境內經過。』但以東王不聽。他們又派人去見摩押王，摩押王也不答應。於是以色列就留在加低斯。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 2:1–8; 民數記 22:36; 民數記 21:4–13"> 「後來他們經過曠野，繞過以東地和摩押地，來到摩押地的東邊，在亞嫩河對岸紮營。他們並沒有進入摩押境內，因為亞嫩河是摩押的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民數記 21:21–35; 申命記 2:26–36; 申命記 3:1–17"> 「以色列又派遣使者去見亞摩利王，就是希實本王西宏，以色列對他說：『請讓我們從你境內經過，到我們的地方去。』</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 13:15–32; 民數記 21:23–25; 詩篇 136:17–21"> 但西宏不信任以色列，不讓他們從他境內經過。西宏還招聚他的全軍，在雅哈茲紮營，與以色列作戰。</span>
<span className="v" id="v21" data-v="21"> 以色列的神耶和華把西宏和他的全軍交在以色列手中，以色列擊敗他們，占有了那地居民亞摩利人的全地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 2:36"> 這樣，他們占有了亞摩利人的全境，從亞嫩河直到雅博河，從曠野直到約旦河。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 「現在，以色列的神耶和華已經把亞摩利人從他子民以色列面前趕出去了，你竟然要占有這地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="竟然要占有這地——或譯作「卻要趕出以色列」。">a</a></sup>嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 21:29; 詩篇 78:55; 彌迦書 4:5"> 你不是占有了你的神基抹讓你占有的土地嗎？我們也占有我們的神耶和華讓我們占有的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="讓我們占有的——或譯作「從我們面前趕出之人的」。">b</a></sup>一切。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 6:5; 約書亞記 24:9–10; 申命記 23:3–4"> 現在，難道你比西撥的兒子摩押王巴勒還強嗎？難道他與以色列爭論過，或者與他們爭戰過嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 2:36; 約書亞記 12:5; 士師記 10:8"> 以色列住在希實本和附屬的村鎮，亞羅珥和附屬的村鎮，以及亞嫩河沿岸所有的城鎮，已經三百年了，那時候你們為什麼不收回呢？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 24:15; 創世記 16:5; 撒母耳記上 24:12"> 我並沒有得罪你，你卻侵犯我，要與我爭戰。願審判者耶和華今天在以色列人和亞捫人之間施行審判！」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 14:11; 箴言 16:18"> 但亞捫人的王不聽耶弗塔向他傳達的話。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 11:25; 士師記 3:10; 士師記 13:25"> 於是耶和華的靈臨到耶弗塔身上，他就穿過基列和瑪拿西，又穿過基列的米斯巴，然後從基列的米斯巴過去，到亞捫人那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 28:20; 撒母耳記上 1:11; 傳道書 5:1–2"> 耶弗塔向耶和華許了一個願，說：「如果你確實把亞捫人交在我手中，</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 66:13–14; 利未記 27:28–29; 撒母耳記上 1:28"> 當我從亞捫人那裡平安回來時，誰先從我家門出來迎接我，誰就歸給耶和華，我必把他獻上作為燔祭。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="士師記 1:4; 士師記 2:18; 士師記 3:10"> 於是耶弗塔過去，到亞捫人那裡與他們交戰，耶和華就把亞捫人交在他手中。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 27:17; 申命記 2:36"> 他擊殺他們，從亞羅珥到米尼特隘口二十座城，直到亞貝勒-基拉明，那是一場極大的殺戮。這樣，亞捫人在以色列子民面前被制伏了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米書 31:4; 出埃及記 15:20; 士師記 10:17"> 耶弗塔回到米斯巴自己的家，看哪，他的女兒拿著鈴鼓跳舞出來迎接他；耶弗塔只有這個獨生女，沒有別的兒女。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 14:7–9; 創世記 37:29–30; 創世記 42:36–38"> 耶弗塔看見女兒，就撕裂衣服，說：「唉，我的女兒啊！你讓我愁苦至極，你給我帶來了困擾。我已經向耶和華開了口，不能收回啊！」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 18:19; 腓立比書 2:30; 羅馬書 16:4"> 他女兒對他說：「父親啊，你已經向耶和華開了口，耶和華已經在你仇敵亞捫人身上為你報仇，你就照著你說出的話對待我吧。」</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 1:25; 撒母耳記上 1:6"> 她又對父親說：「願你准許我這件事：請寬限我兩個月，讓我與我的女伴們到山裡去，為我終身不嫁而哀哭。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 耶弗塔說：「你去吧」，就讓她離開兩個月。她與她的女伴們到山裡，為她終身不嫁而哀哭。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 66:3; 士師記 11:31; 利未記 27:28–29"> 過了兩個月，她回到父親那裡，父親照著所許的願對待她，她就終身沒有親近男人。於是在以色列有一個習俗：</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 9:25; 士師記 5:11"> 以色列的女子每年都會去紀念基列人耶弗塔的女兒，每年有四天。</span>
</div>
</div>

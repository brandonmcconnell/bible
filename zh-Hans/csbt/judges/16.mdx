<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:47; 以斯拉記 9:1–2; 創世記 38:16–18"> 後來叄孫去加沙，在那裡見到一個妓女，就與她同寢。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:10–12; 撒母耳記上 23:26; 使徒行傳 9:24"> 加沙人聽說叄孫到這裡來了，就把他圍住，整夜在城門口埋伏著。他們整夜靜默不動，心想：「等到早晨天一亮，我們就殺了他。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 2:24; 詩篇 107:16; 以賽亞書 63:1–5"> 叄孫睡到半夜，在半夜起來，抓住城門口的門扇和兩個門框，把它們與門閂一同拔出來，扛在肩膀上，抬到了希伯崙對面的山頂上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:6; 箴言 22:14; 尼希米記 13:26"> 此後，叄孫在索列溪谷愛上了一個女人，名叫達莉拉。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 13:3; 士師記 14:15; 提摩太前書 6:9–10"> 非利士的首領們上去見達莉拉，對她說：「你要引誘叄孫，探查他的力量為何這麼大，我們怎樣才能勝過他，把他捆住制伏他。我們每人會給你一千一百錠銀子。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 7:21; 箴言 6:26; 箴言 22:14"> 於是達莉拉對叄孫說：「請你告訴我，你的力量為何這麼大，怎樣才能把你捆住制伏你。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 21:2–3; 羅馬書 3:8; 撒母耳記上 27:10"> 叄孫告訴她：「如果用七條還沒有乾的新皮條捆住我，我就會軟弱無力，像普通人一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="傳道書 7:26"> 於是非利士的首領們給達莉拉送來七條還沒有乾的新皮條，她就用這些皮條捆住叄孫。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 58:9"> 她預先讓埋伏的人在內室等著，然後對叄孫說：「叄孫，非利士人捉你來了！」叄孫掙斷皮條，像麻線一碰到火就斷了那樣。他力量的根源還是沒有人知道。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 16:13; 路加福音 22:48; 士師記 16:7"> 達莉拉對叄孫說：「看，你愚弄我，對我說謊！現在請告訴我，怎樣才能捆住你？」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 13:5; 以弗所書 4:25; 箴言 13:3"> 叄孫告訴她：「如果用從來沒有使用過的新繩子牢牢捆住我，我就會軟弱無力，像普通人一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 達莉拉就拿新繩子捆住叄孫，對他說：「叄孫，非利士人捉你來了！」埋伏的人預先在內室等著。叄孫掙斷膀臂上的繩子，如同掙斷一條絲帶。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 達莉拉就對叄孫說：「你直到如今都在愚弄我，對我說謊！請告訴我，怎樣才能捆住你？」<br />叄孫告訴她：「如果你把我頭上的七條辮子與織布機的緯線編在一起，用橛子牢牢釘住，我就會軟弱無力，像普通人一樣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="用橛子牢牢釘住，我就會軟弱無力，像普通人一樣——依據七十士譯本；馬索拉文本無此句。">a</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:43; 以斯拉記 9:13–14"> 於是，達莉拉趁叄孫睡覺的時候，把叄孫頭上的七條辮子與織布機的緯線編在一起<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="趁叁孫睡覺的時候，把叁孫頭上的七條辮子與織布機的緯線編在一起——依據七十士譯本；馬索拉文本無此句。">b</a></sup>，用橛子釘牢，然後對他說：「叄孫，非利士人捉你來了！」叄孫就從沉睡中醒來，把橛子、織布機、緯線都拔了出來。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 14:16; 約翰一書 2:15–16; 約翰福音 14:21–24"> 達莉拉對叄孫說：「你怎能說你愛我呢？你的心根本不在我身上！這三次你都愚弄我，沒有告訴我你的力量為何這麼大。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 7:21–23; 路加福音 18:5; 馬可福音 14:24"> 這樣，達莉拉天天用話催逼他，糾纏他，以致他心中煩得要死。</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 7:5; 士師記 13:5; 箴言 12:23"> 叄孫就把心裡的一切都告訴了達莉拉。他對達莉拉說：「我頭上從來沒有用過剃刀，因為我在母腹中就已經歸於神作拿細耳人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="拿細耳人——意思是「分別出來的人」。">c</a></sup>。一旦我的頭髮被剃掉，我的力量就會離開我，我就會軟弱無力，像普通人一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 26:15; 士師記 16:5; 提摩太前書 6:10"> 達莉拉見叄孫把心裡的一切都告訴了她，就派人去叫來非利士的首領們，說：「你們再一次過來吧！他已經把心裡的一切都告訴我了。」非利士的首領們就上她那裡去，手裡拿著銀子。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 7:26–27; 箴言 7:21–23; 傳道書 7:26"> 達莉拉使叄孫在她的膝蓋上沉睡，然後叫人來，剃掉他頭上的七條辮子。這樣達莉拉就制伏叄孫，叄孫的力量離開了。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 14:42–43; 撒母耳記上 16:14; 約書亞記 7:12"> 達莉拉說：「叄孫，非利士人捉你來了！」叄孫從沉睡中醒過來，心想：「我要像前幾次那樣，一抖脫身。」他卻不知道耶和華已經離開了他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 2:19; 箴言 14:14; 以賽亞書 47:2"> 非利士人抓住了叄孫，剜出他的雙眼，把他帶到加沙，用銅鏈捆住他，讓他在監獄裡推磨。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:13–14; 詩篇 106:44–45; 利未記 26:44"> 然而，他的頭髮被剃掉以後，又開始長出來了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 5:2–5; 箴言 24:17; 詩篇 35:15–16"> 非利士的首領們聚集在一起，要向他們的神大袞獻大祭並歡慶，他們說：<br /><span className="pl pl-1">「我們的神把我們的仇敵叄孫</span><br /><span className="pl pl-1">交在我們手中了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="但以理書 5:4; 但以理書 5:23; 士師記 15:16"> 民眾看見叄孫，就讚美他們的神明，說：<br /><span className="pl pl-1">「我們的神把我們的仇敵交在我們手中了，</span><br /><span className="pl pl-1">這人曾使我們的土地荒廢，</span><br /><span className="pl pl-1">殺害了我們許多人！」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 13:28; 士師記 19:6; 士師記 9:27"> 那時，他們心裡高興，就說：「把叄孫叫來，在我們面前戲耍！」於是他們把叄孫從監獄裡叫出來，叄孫就在他們面前耍把戲。他們讓叄孫站在柱子中間。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 叄孫對拉著他手的少年人說：「放開我的手吧，讓我摸摸支撐廟宇的柱子，我好在柱子上靠一靠。」</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 22:8; 撒母耳記下 11:2; 約書亞記 2:8"> 那時廟宇裡擠滿了男人女人，非利士的首領全都在那裡，屋頂上約有三千男人和女人在觀看叄孫戲耍。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 15:15; 耶利米哀歌 3:31–32; 詩篇 143:12"> 叄孫呼求耶和華說：「主耶和華啊，求你記念我！神哪，就這一次，求你賜我力量，讓我一次就向非利士人報了我雙眼的仇。」</span>
<span className="v" id="v29" data-v="29"> 叄孫就按住中央兩根支撐廟宇的柱子，右手一根，左手一根，抵住它們。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 2:8; 馬太福音 16:25; 馬太福音 24:38–39"> 叄孫說：「讓我與非利士人一起死吧！」然後用力一推，廟宇就倒在裡面的首領和所有民眾身上。這樣，叄孫死時所殺的人，比生前所殺的還多。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 15:20; 士師記 13:25; 士師記 13:2"> 叄孫的兄弟們和他父親的全家一起下去，把他帶回來，葬在佐拉和以實陶之間他父親瑪挪亞的墳墓裡。叄孫作以色列的士師有二十年。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 19:41; 士師記 12:1–6; 約伯記 5:2"> 那時，以法蓮人對基甸說：「你去攻打米甸人，竟然不召喚我們！你怎麼這樣對待我們呢？」他們與基甸激烈地爭論。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 13:4–7; 腓立比書 2:2–3; 雅各書 3:13–18"> 基甸就對他們說：「我現在所做的，怎麼能與你們相比呢？以法蓮遺落的葡萄，不是比亞比以謝採收的葡萄更好嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士師記 7:24–25; 約翰福音 4:37"> 神已經把米甸首領俄立和西伊伯交在你們手中了，我能做什麼與你們相比呢？」基甸說了這話，以法蓮人的怒氣就平息了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太書 6:9; 哥林多後書 4:16; 撒母耳記上 14:28–29"> 基甸來到約旦河，他和跟隨他的三百人過了河，雖然疲乏，仍繼續追趕。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:17; 詩篇 60:6; 撒母耳記上 25:18"> 基甸對疏割人說：「請拿幾塊餅給這些跟隨我的人吃吧，因為他們疲乏了，我正在追趕米甸王西巴和撒慕拿。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 20:11; 腓立比書 2:21; 箴言 18:23"> 疏割的首領們回答：「西巴和撒慕拿已經在你手中了嗎？居然要我們送餅給你的隊伍！」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士師記 7:15"> 基甸就宣告：「那好！耶和華把西巴和撒慕拿交在我手中的時候，我必用曠野的荊棘和蒺藜抽打你們的身體。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:30–31; 列王紀上 12:25"> 然後，基甸從那裡上到毗努伊勒，對那裡的人說同樣的話，但毗努伊勒人回應他像疏割人的回應一樣。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 8:17; 列王紀上 22:27–28"> 基甸也向毗努伊勒人宣告說：「我平安回來的時候，必拆毀這座塔樓。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 7:12; 士師記 20:25; 士師記 20:2"> 那時西巴和撒慕拿在卡克爾，跟隨他們的軍兵約有一萬五千人，是東方人剩下的全部軍兵，他們已經有十二萬拿刀劍的人倒下了。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 32:35; 民數記 32:42; 士師記 18:27"> 基甸從挪巴和約比哈東面，沿著住帳篷之人的道路上去，在敵營毫無戒備的時候，攻打那營地。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:11; 阿摩司書 2:14; 約伯記 12:16–21"> 西巴和撒慕拿就逃跑。基甸追趕他們，捉住了米甸的兩個王西巴和撒慕拿，使全軍潰亂。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 約阿施的兒子基甸沿著希列斯山坡從戰場回來，</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:24–25; 撒母耳記上 30:11–15"> 捉住疏割的一個年輕人，訊問他。年輕人給他寫下了疏割的首領和長老的名字，共七十七人。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:6–7"> 於是，基甸來到疏割人那裡，說：「你們曾經羞辱我說：『西巴和撒慕拿已經在你手中了嗎？居然要我們送餅給你那些疲乏的人。』看哪，這就是西巴和撒慕拿！」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 8:7; 以斯拉記 2:6; 箴言 10:13"> 於是他捉住那城的長老們，並拿來曠野的荊棘和蒺藜，用它們教訓了疏割人。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 8:9; 列王紀上 12:25"> 他又拆毀了毗努伊勒的塔樓，殺了城裡的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 4:6; 猶大書 1:16; 詩篇 89:12"> 基甸問西巴和撒慕拿：「你們在他泊山所殺的，是怎樣的人？」他們回答：「都像你，個個都像王子的模樣。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 基甸說：「他們是我的兄弟，我母親的兒子。我指著耶和華的永生起誓：要是你們讓他們存活，我就不殺你們了。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 149:9; 撒母耳記上 15:33; 約書亞記 10:24"> 於是基甸對長子耶特爾說：「起來，把他們殺了！」但那年輕人沒有拔出刀來，因為他害怕，他還年輕。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="詩篇 83:11; 士師記 8:26; 以賽亞書 3:18"> 西巴和撒慕拿說：「你自己起來殺我們吧，大丈夫才有力量<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大丈夫才有力量——或譯作「人怎樣，力量也怎樣」。">a</a></sup>。」基甸就起來，殺了西巴和撒慕拿，並奪去他們駱駝脖子上的月牙圈。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 6:15; 士師記 9:8–15; 撒母耳記上 12:12"> 那時，以色列人對基甸說：「你既然救我們脫離米甸人的手，你和你的子子孫孫也管轄我們吧。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 33:22; 撒母耳記上 12:12; 撒母耳記上 10:19"> 但基甸對他們說：「我不管轄你們，我的兒子也不管轄你們；耶和華會管轄你們。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:13; 創世記 37:25; 創世記 37:28"> 基甸又對他們說：「我有一件事求你們，請你們各人把奪來的耳環給我一個。」原來敵軍是以實瑪利人，都戴金耳環。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他們說：「我們樂意給你。」於是他們鋪開外衣，各人把奪來的耳環扔在上面。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 18:16; 約翰福音 19:2; 啟示錄 18:12"> 基甸要來的金耳環，其金子的重量是一千七百謝克爾<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一千七百謝克爾——相當於19.4公斤。1謝克爾=11.4公克。">b</a></sup>；此外，還有米甸王身上的月牙圈、耳墜和紫色衣服，以及駱駝脖子上的項圈。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:5; 士師記 18:14; 詩篇 106:39"> 基甸用這些製作了一個以弗得，放在本城俄弗拉。全以色列都在那裡行淫追隨這以弗得，這成了基甸和他家的陷阱。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31; 士師記 3:11; 士師記 3:30"> 這樣，米甸人在以色列人面前被制伏，再也不能抬頭。在基甸的年日，國中太平四十年。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 6:32; 士師記 7:1; 撒母耳記上 12:11"> 約阿施的兒子耶路巴力回去，住在自己家裡。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="士師記 9:5; 士師記 9:2; 列王紀上 11:3"> 基甸有七十個兒子，都是他親生的，因為他有許多妻子。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 9:18; 創世記 22:24; 創世記 16:15"> 他在示劍的妾也為他生了一個兒子，基甸給這兒子取名為亞比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 25:8; 士師記 6:24; 約伯記 5:26"> 約阿施的兒子基甸盡享天年而死，葬在亞比以謝族的俄弗拉，在他父親約阿施的墳墓裡。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 9:46; 士師記 2:19; 士師記 9:4"> 基甸死後，以色列子民又轉去行淫追隨巴力，奉巴力比利土為他們的神。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 78:42; 詩篇 106:21; 詩篇 78:11"> 以色列子民不記念耶和華他們的神，就是解救他們脫離四圍一切仇敵之手的那一位；</span>
<span className="v" id="v35" data-v="35" data-xref="傳道書 9:14–15; 士師記 9:5; 士師記 9:16–19"> 也不照著耶路巴力——基甸向以色列所施的一切恩惠，以恩慈對待他的家。</span>
</div>
</div>

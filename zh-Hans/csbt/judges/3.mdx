<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 2:21–22; 申命記 7:22; 箴言 17:3"> 以下是耶和華留下的那些民族，為要藉著他們試驗所有未曾經歷過迦南任何戰事的以色列人，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 3:5; 創世記 3:7; 哥林多前書 9:26–27"> 特意讓以色列的子孫後代，特意讓以前沒有經歷過的人去經歷戰事，教導他們作戰。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 13:3; 約書亞記 13:5; 士師記 10:7"> 所留下的有：非利士的五個首領；所有的迦南人；西頓人；從巴力黑門山直到哈馬隘口住在黎巴嫩山地的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:1; 士師記 2:22; 出埃及記 15:25"> 這是為要藉著他們試驗以色列人，要知道他們是否會聽從耶和華藉著摩西所指示他們祖先的誡命。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:34–38; 創世記 10:15–18; 出埃及記 3:8"> 然而，以色列子民住在迦南人、赫提人、亞摩利人、比利洗人、希未人和耶布斯人中間，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:3–4; 出埃及記 34:16; 列王紀上 11:1–5"> 娶他們的女兒為妻，又把自己的女兒嫁給他們的兒子，並且服事他們的神明。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 34:13; 列王紀下 23:6; 列王紀上 18:19"> 以色列子民做耶和華眼中看為惡的事，忘記了耶和華他們的神，而服事巴力和亞舍拉。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 2:14; 哈巴谷書 3:7; 士師記 4:9"> 於是耶和華對以色列發怒，把他們交於<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="交於——原文直譯「賣到」。">a</a></sup>美索不達米亞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="美索不達米亞——原文直譯「兩河之間的亞蘭」。">b</a></sup>王古珊·利薩田手中。以色列子民服事了古珊·利薩田八年。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 3:15; 士師記 1:13; 詩篇 22:5"> 以色列子民向耶和華哀求，耶和華就為以色列子民興起一位拯救者來救他們，就是迦勒的弟弟、基納斯的兒子俄陀聶。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 13:25; 撒母耳記上 11:6; 士師記 14:19"> 耶和華的靈臨到俄陀聶身上，他就作了以色列的士師。他出去作戰，耶和華把亞蘭王古珊·利薩田交在他手中，他的手就制伏了古珊·利薩田。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 5:31; 士師記 8:28; 約書亞記 11:23"> 於是國中太平了四十年，後來基納斯的兒子俄陀聶死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 12:9; 士師記 2:19; 士師記 2:14"> 以色列子民又做耶和華眼中看為惡的事。於是耶和華使摩押王伊磯倫強盛，壓制以色列，因為他們做了耶和華眼中看為惡的事。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 1:16; 申命記 34:3; 士師記 5:14"> 伊磯倫把亞捫人和亞瑪力人招聚到他那裡，來攻打以色列，占據了棕櫚城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:47–48; 申命記 28:40; 利未記 26:23–25"> 以色列子民服事了摩押王伊磯倫十八年。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 3:9; 詩篇 78:34; 以賽亞書 36:16"> 以色列子民向耶和華哀求，耶和華就為他們興起一位拯救者，便雅憫人基拉的兒子以胡德，他是一個慣用左手的人。那時，以色列子民委託他呈送貢物給摩押王伊磯倫。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 啟示錄 2:12; 詩篇 149:6"> 以胡德為自己打造了一把一肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘——相當於45.7公分。">c</a></sup>長的雙刃刀，綁在右大腿上衣袍裡面。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:20; 約伯記 15:27; 耶利米書 50:11"> 他把貢物獻給摩押王伊磯倫，伊磯倫是一個很肥胖的人。</span>
<span className="v" id="v18" data-v="18"> 以胡德獻完貢物以後，把抬貢物的人打發走了，</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 4:20; 士師記 3:20; 使徒行傳 23:18–19"> 他自己卻從吉甲附近的雕像群那裡返回，說：「王啊，我有機密的事要向你稟報。」王說：「先不要開口<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="先不要開口——原文直譯「安靜」。">d</a></sup>！」他旁邊侍立的人都退了出去，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 10:7; 阿摩司書 3:15; 詩篇 29:1"> 以胡德來到王那裡，王正獨自坐在涼爽的閣樓裡。以胡德說：「我有神的話要向你稟報。」王就從寶座上起身。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 13:3; 約伯記 20:25; 撒母耳記上 15:33"> 以胡德伸出左手，從右腿上拔出刀來，刺進王的肚子，</span>
<span className="v" id="v22" data-v="22"> 連刀柄也隨著刀鋒刺了進去；肥肉裹住了刀鋒，因此以胡德沒有把刀從王的肚子裡拔出；王的糞便都流了出來。</span>
<span className="v" id="v23" data-v="23"> 以胡德出來到走廊上，他把閣樓的門從裡面關上，鎖住了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 24:3"> 以胡德出去之後，王的臣僕們來了，他們觀看，發現閣樓的門鎖住了，就想：「王一定是在涼爽的裡間解手。」</span>
<span className="v" id="v25" data-v="25"> 他們一直等候，直到覺得尷尬，但王還是沒有打開閣樓的門。他們就拿鑰匙開門，看哪，主人已經倒在地上死了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 在他們耽延的時候，以胡德已經逃離了。他經過雕像群那裡，逃往西伊拉。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:34; 撒母耳記上 13:3; 士師記 5:14"> 到了那裡，他就在以法蓮山地吹響號角。以色列人與他一同下山，他在他們前面。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 12:5; 士師記 7:9; 士師記 7:15"> 以胡德對他們說：「你們緊跟著我，耶和華已經把你們的仇敵摩押人交在你們手中了！」他們隨著他下去，占據通往摩押的約旦河渡口，不允許一人過去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:15; 士師記 3:17; 詩篇 17:10"> 那時，他們擊殺了大約一萬摩押人，都是強壯的勇士，沒有一人逃脫。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 3:11; 士師記 5:31"> 那一天，摩押被制伏在以色列手下，於是國中太平了八十年。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 5:6; 哥林多前書 1:17; 撒母耳記上 17:50"> 以胡德之後，有亞拿的兒子沙姆伽爾興起，他用趕牛棒擊殺了六百個非利士人，他也拯救了以色列。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 11:11; 撒母耳記上 3:20; 撒母耳記上 10:17"> 於是全體以色列人出動，從但直到比爾-謝巴，還有基列地，會眾如同一人聚集到米斯巴，到耶和華面前。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:10; 士師記 20:17; 士師記 20:15"> 以色列眾支派全體民眾的首領，都站在神子民的集會裡，拿刀劍的步兵共有四十萬。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> 以色列人上到米斯巴，便雅憫人也聽說了。<br />以色列人說：「請說，這件惡事是怎麼發生的？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 19:15–28"> 那利未人，就是被殺的婦人的丈夫，回答說：「我和我的妾來到便雅憫的基比亞過夜。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 士師記 19:25–26; 創世記 19:4–8"> 基比亞的居民起來攻擊我，夜間包圍我的住處，想要殺我，隨後把我的妾玷辱致死了。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:29; 約書亞記 7:15; 士師記 19:23"> 於是我扶住我的妾，把屍體切成塊，送到以色列得為繼業的全境，因為基比亞人在以色列做了淫穢醜惡的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:30; 哥林多前書 5:6; 哥林多前書 5:10–12"> 現在，你們全體以色列人哪，請你們表態，給出建議吧！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="傳道書 9:10; 士師記 20:1; 箴言 21:3"> 那時，全體民眾起來如同一人，說：「我們每個人都不回自己的帳篷，不回自己的家。</span>
<span className="v" id="v9" data-v="9" data-xref="約拿書 1:7; 尼希米記 11:1; 約書亞記 14:2"> 我們現在要這樣行事來對付基比亞：按著所抽的籤，上去攻打他們；</span>
<span className="v" id="v10" data-v="10"> 在以色列各支派中，每一百人選十人，每一千人選一百人，每一萬人選一千人，為軍兵運送食物，等軍兵來到便雅憫的基比亞，就照著他們在以色列所做的一切醜惡之事處置他們。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 於是以色列眾人團結如同一人，聚集起來要攻擊那城。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 13:14; 申命記 20:10; 羅馬書 12:18"> 以色列眾支派打發人到便雅憫支派各地，說：「你們中間為什麼有這樣的惡事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:12; 申命記 13:13; 士師記 19:22"> 現在，你們要把基比亞的那些卑劣之徒交出來，讓我們把他們處死，從以色列清除邪惡。」但便雅憫人不願聽從他們兄弟以色列人的話。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 20:20; 約伯記 15:25–26; 民數記 21:23"> 便雅憫人從各城聚集到基比亞，要出去與以色列人作戰。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:41; 士師記 20:25; 民數記 1:37"> 那一天，各城被調集來的便雅憫人，有兩萬六千拿刀劍的，此外被調集的還有基比亞居民七百精兵。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:15; 歷代志上 12:2; 撒母耳記上 17:49–50"> 這全軍當中，七百精兵都是慣用左手的，全都能用投石索甩石，毫髮不差。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 1:46; 歷代志下 17:14–18; 民數記 26:51"> 便雅憫人之外的以色列人，調集了四十萬拿刀劍的，都是戰士。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 20:23; 士師記 20:26–27; 民數記 27:21"> 以色列人起來，上伯特利去求問神，說：「我們當中，誰先上去與便雅憫人作戰呢？」<br />耶和華說：「猶大先上去。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:16; 約書亞記 3:1; 約書亞記 6:12"> 以色列人清早起來，對著基比亞紮營。</span>
<span className="v" id="v20" data-v="20"> 以色列人出去，要與便雅憫人作戰。以色列人在基比亞對面擺陣迎戰，</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 20:25; 詩篇 73:18–19; 歷代志下 28:10"> 便雅憫人就從基比亞出來，當天把兩萬兩千以色列人擊殺在地。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 64:5; 士師記 20:17; 撒母耳記上 30:6"> 以色列軍兵堅定心志，在第一天擺陣的地方再次擺開戰陣。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:26–27; 詩篇 78:34–36; 約書亞記 7:6"> 以色列人上前來，在耶和華面前哀哭，直到傍晚，他們求問耶和華說：「我們可以再過去與我們的兄弟便雅憫人作戰嗎？」<br />耶和華說：「上去攻擊他們吧。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 第二天，以色列人又上前去攻打便雅憫人。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 20:21; 創世記 18:25; 羅馬書 2:5"> 便雅憫人也在第二天從基比亞出來迎戰，又把以色列人一萬八千人擊殺在地，都是拿刀劍的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="士師記 20:23; 約珥書 2:12–18; 士師記 20:18"> 於是，全體以色列人，全體軍兵，都上到伯特利，坐在耶和華面前哀哭。那一天他們禁食直到傍晚，又在耶和華面前獻上燔祭和平安祭，</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 18:1; 士師記 20:18; 撒母耳記上 4:3–4"> 然後以色列人求問耶和華。那些日子裡，神的約櫃是在伯特利，</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 7:9; 約書亞記 24:33; 申命記 18:5"> 亞倫的孫子、以利亞撒的兒子非尼哈當時侍立在約櫃前。以色列人求問說：「我們應該再去攻打我們的兄弟便雅憫人呢，還是不要去呢？」<br />耶和華說：「上去吧，明天我必把他們交在你們手中。」</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 8:4; 撒母耳記下 5:23; 士師記 20:34"> 以色列人就在基比亞四圍設下埋伏。</span>
<span className="v" id="v30" data-v="30"> 第三天，以色列人又上去攻打便雅憫人，像前幾次那樣在基比亞對面擺陣。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 19:13–14; 約書亞記 7:5; 以賽亞書 10:29"> 便雅憫人出來迎戰，被引誘出城。他們在兩條大道上，一條通往伯特利、一條通往基比亞，開始像前兩次那樣擊殺以色列人，在田野殺了大約三十個人。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 8:15–16"> 便雅憫人想：「他們必像先前那樣敗在我們面前。」其實以色列人想的是：「我們要逃跑，引誘他們出城到大道上。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 8:18–22"> 這樣，以色列所有軍兵從自己的位置起來，在巴力塔瑪擺陣；以色列的伏兵也從基比亞西面，從自己的位置衝上來。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 8:14; 以賽亞書 47:11; 約伯記 21:13"> 全以色列中的一萬精兵，從正面進攻基比亞，戰鬥很激烈。便雅憫人並不知道，禍患已經臨近他們了。</span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 20:5; 士師記 20:15; 士師記 20:44–46"> 耶和華在以色列面前打敗了便雅憫人；那一天，以色列人消滅了兩萬五千一百便雅憫人，都是拿刀劍的。</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 8:15–29"> 便雅憫人這才知道自己被打敗了。<br />以色列人在便雅憫人面前退出陣地，是因為他們信賴那些在基比亞對面設下的伏兵。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 8:19; 約書亞記 6:5; 出埃及記 19:13"> 這時伏兵急速衝進基比亞，伏兵擴散開，用刀擊殺全城。</span>
<span className="v" id="v38" data-v="38" data-xref="約書亞記 8:20; 創世記 17:21; 列王紀下 4:16"> 以色列人事先與伏兵有約定：伏兵在城內升起烽火濃煙，</span>
<span className="v" id="v39" data-v="39" data-xref="士師記 20:32"> 以色列人就返回戰場。便雅憫人一開始擊殺了大約三十個以色列人，就說：「他們將要像先前的戰鬥那樣，徹底敗在我們面前了。」</span>
<span className="v" id="v40" data-v="40" data-xref="約書亞記 8:20; 啟示錄 19:3; 創世記 19:28"> 然而，烽火的煙柱從城內開始上騰，便雅憫人回頭一看，全城煙氣衝天，</span>
<span className="v" id="v41" data-v="41" data-xref="彼得後書 2:12; 路加福音 21:26; 啟示錄 6:15–17"> 以色列人又返回來了，便雅憫人就惶恐，因為看出禍患臨近他們了。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 8:15; 何西阿書 9:9; 耶利米哀歌 1:3"> 他們在以色列人面前轉身逃往曠野，卻被緊緊追擊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="卻被緊緊追擊——原文直譯「戰鬥卻緊隨他們」。">a</a></sup>，從各城出來的人也夾攻消滅他們。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 8:20–22"> 以色列人包圍便雅憫人，追趕他們，從挪哈<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="追趕他們，從挪哈——或譯作「不停歇地追趕他們」。">b</a></sup>直到東邊的基比亞對面，踐踏他們。</span>
<span className="v" id="v44" data-v="44"> 便雅憫人中倒下的有一萬八千人，全都是勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 15:32; 士師記 21:13; 撒迦利亞書 14:10"> 其餘的人轉身逃往曠野，到臨門岩石去。以色列人在大道上除掉了他們五千人，並追擊他們直到基頓，又擊殺了兩千人。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士師記 20:35; 士師記 20:15"> 那一天，便雅憫人中總共倒下了兩萬五千個拿刀劍的人，全都是勇士。</span>
<span className="v" id="v47" data-v="47" data-xref="以賽亞書 1:9; 詩篇 103:9–10; 哈巴谷書 3:2"> 有六百人轉身逃往曠野，到臨門岩石去，在臨門岩石那裡停留了四個月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 13:15–17; 歷代志下 25:13; 歷代志下 28:6–9"> 以色列人回到便雅憫人那裡，用刀擊殺他們，擊殺全城包括牲畜以及所遇到的一切，又放火燒毀他們的所有城鎮。</span>
</div>
</div>

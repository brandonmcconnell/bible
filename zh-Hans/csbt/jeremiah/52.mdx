<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 24:18; 約書亞記 10:29; 歷代志下 36:11"> 西底加作王的時候二十一歲，在耶路撒冷統治了十一年。他的母親名叫哈慕她勒，是立拿人耶利米的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 14:22; 列王紀下 24:19–20; 以西結書 17:16–20"> 西底加效法約雅敬所做的一切，做耶和華眼中看為惡的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 3:4–5; 歷代志下 36:13; 以賽亞書 3:1"> 因此耶和華發怒，這些事就臨到耶路撒冷和猶大，直到耶和華把他們從自己面前趕走了。後來，西底加背叛了巴比倫王。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:1; 撒迦利亞書 8:19; 以西結書 24:1–2"> 西底加在位第九年的十月十日，巴比倫王尼布甲尼撒率領全軍來攻打耶路撒冷。他們在城外紮營，在城的四圍造臺築壘。</span>
<span className="v" id="v5" data-v="5"> 城被圍困，直到西底加王十一年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米書 39:2; 以賽亞書 3:1; 列王紀下 25:3"> 到了四月九日，城中饑荒嚴重，當地百姓沒有糧食了。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 39:4–7; 耶利米書 51:32; 列王紀下 25:4"> 城就被攻破，所有的戰士從王室園子旁邊兩道城牆之間的門趁夜逃出城；那時迦勒底人正圍攻這城。他們沿著亞拉巴方向的路逃走，</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 34:21; 耶利米書 32:4; 耶利米書 38:23"> 迦勒底軍隊追趕西底加王，在耶利哥平原追上了他，王的全軍從他身邊四散。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 39:5; 民數記 13:21; 列王紀下 25:6"> 迦勒底人捉住王，把他帶到哈馬地的利比拉，到巴比倫王那裡，王就對他宣告裁決。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 22:30; 列王紀下 25:7; 創世記 21:16"> 巴比倫王在西底加眼前把他的兒子們殺了，在利比拉把猶大的眾首領也都殺了，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 12:13; 耶利米書 34:3–5"> 並且弄瞎西底加的雙眼，用銅鏈捆住他。巴比倫王把他帶到巴比倫去，關在監牢裡，直到他死的日子。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:8; 耶利米書 39:9; 耶利米書 52:29"> 巴比倫王尼布甲尼撒王十九年的五月十日，在巴比倫王面前侍立的護衛長尼布撒拉旦進入耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 79:1; 彌迦書 3:12; 歷代志下 36:19"> 他燒毀了耶和華的殿和王宮，以及耶路撒冷所有的房屋；所有高大的建築，他都放火燒毀了。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 1:3; 列王紀下 25:10"> 護衛長率領的迦勒底全軍還拆毀了耶路撒冷四圍所有的城牆。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 15:1–2; 撒迦利亞書 14:2"> 護衛長尼布撒拉旦把民中一些窮人，還有城中殘留的其餘民眾和那些之前向巴比倫王投降的人，以及其餘的工匠，都擄走了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 25:12; 耶利米書 39:9–10; 耶利米書 40:5–7"> 但護衛長尼布撒拉旦留下當地一些窮人，作葡萄園丁和耕田的農夫。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 27:19–22; 耶利米書 52:21–23; 歷代志下 4:12–15"> 迦勒底人打碎了耶和華殿的銅柱，以及耶和華殿中的銅盆底座和銅海，把這些銅全都運到巴比倫去。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 27:3; 民數記 4:14; 列王紀上 7:45"> 他們帶走了鍋、鏟子、蠟剪、碗、勺子，以及事奉用的所有銅器。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:49–50; 歷代志下 4:6–22; 利未記 26:12"> 還有缽、盤子、碗、鍋、燈臺、勺子、祭酒杯，凡是純金的、純銀的，護衛長都帶走了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀上 7:47; 列王紀下 25:16; 歷代志下 4:18"> 所羅門王為耶和華殿製作的兩根柱子，一個銅海和底座下面的十二頭銅牛，這一切器物所用銅的重量無法確定。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:17; 列王紀上 7:15–21; 歷代志下 3:15–17"> 兩根柱子，一根柱子高十八肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十八肘——相當於8.2公尺。1肘=45.7公分。">a</a></sup>，周長十二肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十二肘——相當於5.5公尺。">b</a></sup>，厚四指，是空心的，</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:25; 列王紀下 25:17; 歷代志下 3:15"> 頂上有銅柱頭，一個柱頭高五肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五肘——相當於2.3公尺。">c</a></sup>，柱頭上環繞著網格和石榴，都是銅的。另一根柱子也一樣，也有石榴。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 7:20"> 柱子周邊的石榴有九十六個，網格周圍全部的石榴有一百個。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀下 25:18; 耶利米書 29:25; 耶利米書 35:4"> 護衛長捉住了祭司長西萊雅、副祭司長西番雅和三個門衛，</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 25:19; 以斯帖記 1:14; 馬太福音 18:10"> 他在城裡還捉住一個監督軍兵的內臣，七個留在城裡的王室近臣，一個招募當地百姓的將軍秘書，以及六十個留在城裡的當地百姓。</span>
<span className="v" id="v26" data-v="26"> 護衛長尼布撒拉旦捉住他們，把他們帶到利比拉，到巴比倫王那裡。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 33:28; 以賽亞書 32:13–14; 以賽亞書 6:11–12"> 巴比倫王擊殺他們，在哈馬地的利比拉把他們處死了。這樣猶大人就從自己的國土被擄走了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀下 24:12–16; 列王紀下 24:2–3; 但以理書 1:1–3"> 以下是尼布甲尼撒所擄走的民眾：他在位第七年，擄走猶大人三千零二十三人；</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 52:12; 創世記 12:5; 列王紀下 25:11"> 尼布甲尼撒十八年，從耶路撒冷擄走八百三十二人；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 52:15; 耶利米書 6:9"> 尼布甲尼撒二十三年，護衛長尼布撒拉旦擄走猶大人七百四十五人；總共有四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀下 25:27–30; 詩篇 3:3; 創世記 40:13"> 在猶大王約雅斤被擄後三十七年的十二月二十五日，也就是巴比倫王伊莫米羅達作王的那一年，巴比倫王恩赦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="恩赦——原文直譯「抬起～的頭」。">d</a></sup>猶大王約雅斤，把他從牢房釋放出來，</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; 但以理書 5:18–19; 但以理書 2:37"> 對他說和善的話，使他的地位高過那些與他同在巴比倫的王。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 9:7; 列王紀上 2:7; 創世記 41:14"> 約雅斤換下囚服，以後終生常在王面前吃飯。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 9:10; 路加福音 11:3; 馬太福音 6:11"> 至於他的飲食，從巴比倫王那裡有份例賜給他，每天一份，終生都是如此，直到他去世的日子。</span>
</div>
</div>

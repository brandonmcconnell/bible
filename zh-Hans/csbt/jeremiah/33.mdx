<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 38:28; 耶利米書 37:21; 耶利米書 32:2–3"> 耶利米還被拘禁在護衛兵院子裡的時候，耶和華的話語第二次臨到他，說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:3; 出埃及記 15:3; 以賽亞書 37:26"> 「耶和華是創造者，是塑造堅立一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一切——七十士譯本作「大地」。">a</a></sup>的那一位，耶和華是他的名。耶和華如此說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:12; 以賽亞書 65:24; 以弗所書 3:20"> 你呼求我，我就回應你，並且把你所不知道的那些大而深奧的事告訴你。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:24; 哈巴谷書 1:10; 以西結書 4:2"> 論到這城中的房屋和猶大王宮，就是為了抵擋攻城的土壘和刀劍而被拆毀的那些房屋，以色列的神耶和華如此說：</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 8:17; 耶利米書 21:10; 耶利米書 21:4–7"> 他們去與迦勒底人爭戰，實際是用我在怒氣和怒火中所殺之人的屍體充滿這些房屋。我已經因他們的一切惡行，向這城隱藏了我的臉。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 10:10; 以賽亞書 30:26; 提多書 3:5–6"> 然而，我必使這城康復、痊癒，我必醫治他們，向他們顯明豐盛的平安和信實。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:26; 耶利米書 30:3; 阿摩司書 9:14–15"> 我必使猶大的擄民和以色列的擄民回歸<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="使猶大的擄民和以色列的擄民回歸——或譯作「復興猶大和以色列的家業」。">b</a></sup>，重建他們，如起初一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亞書 13:1; 彌迦書 7:18–19; 詩篇 51:2"> 我必除淨他們對我所犯的一切罪孽，赦免他們得罪我、悖逆我所犯的一切罪孽。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:2–3; 以賽亞書 60:5; 西番雅書 3:17–20"> 這城必在地上萬國面前，就是那些聽見我賜給這城一切福份的國家面前，使我獲得喜樂的名，得讚美和榮耀；那些國家必因我賜給這城的一切福份和平安而懼怕、顫抖。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:43; 耶利米書 32:36; 以西結書 37:11"> 「耶和華如此說：在你們說『荒廢，沒有人，也沒有牲畜』的這地方，在荒涼無人、無居民無牲畜的猶大各城和耶路撒冷的街道上，必再次聽見</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 16:34; 詩篇 106:1; 詩篇 107:22"> 歡喜快樂的聲音、新郎新娘的聲音，以及那些帶著感謝祭到耶和華殿之人的聲音，他們說：<br /><span className="pl pl-1">『你們當稱謝萬軍之耶和華，</span><br /><span className="pl pl-1">耶和華是美善的，</span><br /><span className="pl pl-1">他的慈愛永遠長存！』</span><br />是的，我必使這地的擄民回歸，如起初一樣。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 65:10; 以西結書 34:12–15; 耶利米書 36:29"> 「萬軍之耶和華如此說：在這無人無牲畜的荒廢之地，在它的各城鎮，必再次有牧人們的牧場，使羊群躺臥。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:32; 路加福音 15:4; 耶利米書 17:26"> 在山地的各城、丘陵的各城、南地<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地——音譯作「內蓋夫」。">c</a></sup>的各城、便雅憫地、耶路撒冷的四圍和猶大的各城，必再次有羊群從數點的人手下經過。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哈該書 2:6–9; 耶利米書 23:5; 歷代志上 17:13–14"> 「看哪，這是耶和華的宣告：日子將到，我必成就我向以色列家和猶大家所承諾的美好應許。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 11:1–5; 耶利米書 23:5–6; 以賽亞書 4:2"> 在那些日子，在那時候，我要使一個公義的苗裔為大衛長出，他必在地上施行公正和公義。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:6; 哥林多前書 1:30; 以賽亞書 45:17"> 在那些日子，猶大必得拯救，耶路撒冷必安然居住；它將被稱為『耶和華我們的公義』。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 2:4; 詩篇 89:29–37; 路加福音 1:32–33"> 因為耶和華如此說：大衛家必不斷絕有人坐在以色列家的寶座上；</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 56:7; 啟示錄 1:6; 申命記 18:1"> 利未祭司們也不斷絕有人在我面前獻燔祭，燒獻素祭，終日獻祭。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和華的話語臨到耶利米，說：</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 8:22; 詩篇 89:37; 以賽亞書 54:9–10"> 「耶和華如此說：除非你們能廢除我所立白天黑夜的約，使白天和黑夜不按時來臨，</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 89:34; 歷代志下 7:18; 撒母耳記下 23:5"> 否則，我與我僕人大衛所立的約絕不會被廢除，他必有子孫在他的寶座上作王，並且我與事奉我的利未祭司們所立的約也絕不會被廢除。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 15:5; 創世記 22:17; 希伯來書 11:12"> 諸天的萬象怎樣無法數清，海沙怎樣無法測量，我也必怎樣使我僕人大衛的後裔和事奉我的利未人增多。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華的話語臨到耶利米，說：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米記 4:2–4; 詩篇 83:4; 詩篇 44:13–14"> 「你沒有注意到這子民說什麼嗎？他們說：『耶和華所揀選的兩個家族，他已經厭棄了。』他們這樣藐視我的子民，不再把他們看為一個國家。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 74:16–17; 耶利米書 31:35–36; 詩篇 104:19"> 耶和華如此說：除非我沒有立白天黑夜的約，沒有立諸天大地的定律，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 31:37; 以賽亞書 14:1; 何西阿書 2:23"> 否則，我絕不會棄絕雅各的後裔和我僕人大衛的後裔，必從大衛的後裔中揀選人管轄亞伯拉罕、以撒和雅各的後裔。我必使他們的擄民回歸，我必憐憫他們。」</span>
</div>

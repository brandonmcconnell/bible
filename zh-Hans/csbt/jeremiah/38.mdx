<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 7:9; 以斯拉記 2:3; 使徒行傳 4:6–10"> 瑪坦的兒子示法提雅，帕示戶珥的兒子基大利，示勒米雅的兒子猶甲，瑪基雅的兒子帕示戶珥，都聽見了耶利米對全體民眾所說的話：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 39:18; 耶利米書 34:17; 耶利米書 45:5"> 「耶和華如此說：留在這城中的，必死於刀劍、饑荒和瘟疫。但出去向迦勒底人投降的，必得存活；他必保住自己的性命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他必保住自己的性命——原文直譯「使自己的性命作為戰利品歸於他」。">a</a></sup>，得以存活！</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:10; 耶利米書 32:3–5"> 耶和華如此說：這城一定會被交在巴比倫王的軍隊手中，他必攻取這城。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 26:11; 使徒行傳 16:20; 尼希米記 6:9"> 首領們就對王說：「請把這人處死！因為他對這城中剩下的戰士和全體民眾說這樣的話，使他們的手發軟。這人並不是在為這子民求平安，而是在求禍患。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:12–16; 撒母耳記下 3:39; 撒母耳記下 19:22"> 西底加王說：「看哪，他在你們手中，王不能阻止你們做什麼。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 37:21; 耶利米書 38:22; 耶利米書 37:16"> 於是他們抓住耶利米，把他關進護衛兵院子中王子瑪基雅的水窖。他們用繩子把耶利米放下去，水窖裡沒有水，只有淤泥，耶利米就陷在淤泥中。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 21:19; 阿摩司書 5:10; 耶利米書 29:2"> 王宮裡的太監庫實人伊伯米勒，聽說他們把耶利米關進了水窖。那時王坐在便雅憫門口，</span>
<span className="v" id="v8" data-v="8"> 伊伯米勒從王宮裡出來，告訴王說：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 37:21–6; 以斯帖記 7:4–6; 箴言 31:8–9"> 「我主我王啊，這些人對先知耶利米所做的都是惡事，他們把他扔進水窖，他必在那裡餓死，因為這城中再沒有糧食了。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 21:1; 以斯帖記 8:7; 以斯帖記 5:2"> 王就吩咐庫實人伊伯米勒說：「你從這裡帶三十個手下，在先知耶利米未死之前，把他從水窖裡拉上來。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 於是伊伯米勒帶了這些手下，進入王宮，到庫房下面，從那裡拿出破布和舊衣服，用繩子縋到水窖中給耶利米。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 12:10; 以弗所書 4:32; 羅馬書 12:15"> 庫實人伊伯米勒對耶利米說：「請把這些破舊的布和衣服墊在你的腋窩下，墊在繩子下面。」耶利米就照做了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 37:21; 使徒行傳 28:16; 使徒行傳 23:35"> 他們用繩子拉耶利米，把他從水窖裡拉上來。這樣，耶利米就拘留在護衛兵的院子裡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 37:17; 列王紀上 22:16; 耶利米書 21:1–2"> 西底加王派人把先知耶利米帶到耶和華殿中第三入口處去見他，王對耶利米說：「我要問你一件事，你不要向我隱瞞什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:67–68"> 耶利米對西底加說：「我如果告訴你，你不是必定把我處死嗎？我即使向你提建議，你也不會聽從我。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 37:17; 耶利米書 38:1–6; 以賽亞書 57:16"> 於是西底加王暗中向耶利米起誓說：「我指著賜予我們這生命的耶和華的永生起誓：我絕不會把你處死，也絕不會把你交在那些尋索你性命的人手中。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 27:12; 耶利米書 27:17; 耶利米書 38:2"> 耶利米就對西底加說：「以色列的神萬軍之神耶和華如此說：只要你出去投降巴比倫王的首領們，你的性命就得以存活，這城也不會被火燒毀，你和你的家人必得存活；</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:3; 耶利米書 24:8–10; 列王紀下 25:4–10"> 但如果你不出去投降巴比倫王的首領們，這城就要被交在迦勒底人手中，他們將放火燒毀它，你也絕不能從他們手中逃脫。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 12:42; 耶利米書 38:22; 約翰福音 19:12–13"> 西底加王對耶利米說：「我怕那些向迦勒底人投降的猶大人，恐怕迦勒底人把我交在他們手中，他們就會凌辱我。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="但以理書 4:27; 以賽亞書 55:3; 耶利米書 26:13"> 耶利米說：「他們不會把你交出去。求你聽從我對你所說的耶和華的話，這樣你就平安無事，你的性命必得存活。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 2:7; 以西結書 2:4–5; 耶利米書 26:15"> 但如果你拒絕出去投降，以下就是耶和華顯明給我的話語：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 43:6; 耶利米哀歌 1:2; 耶利米哀歌 5:11"> 看哪，猶大王宮裡剩下的女人都要被帶到巴比倫王的首領們那裡。她們會說：<br /><span className="pl pl-1">『你的密友成功誤導了你！</span><br /><span className="pl pl-1">你的雙腳陷入泥沼中，</span><br /><span className="pl pl-1">他們卻向後退縮。』</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 41:10; 耶利米書 39:6; 耶利米書 38:18"> 「你所有的妻子，還有你的兒女，都必被帶到迦勒底人那裡；你也不能從他們手中逃脫，必被巴比倫王的手抓住，這城也必被火燒毀。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 西底加對耶利米說：「不要讓人知道這些話，否則你會死。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 38:27; 耶利米書 38:4–6"> 如果首領們聽說我與你談論過，就來到你這裡說『請告訴我們，你對王說了什麼，王又對你說了什麼，不要向我們隱瞞，免得我們處死你』，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 37:20; 耶利米書 37:15; 以斯帖記 4:8"> 你就要對他們說：『我在王面前呈上我的懇求，求他不要把我送回約拿單的房屋中，使我死在那裡。』」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 10:15–16; 列王紀下 6:19; 使徒行傳 23:6"> 隨後，眾首領來到耶利米那裡問他，他就照著王所吩咐的這一切話告訴他們。他們就對他閉口不言了，因為那次談話沒有被人聽見。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 37:21; 耶利米書 39:14; 詩篇 23:4"> 這樣，耶利米就拘留在護衛兵的院子裡，直到耶路撒冷被攻取的日子。</span>
</div>
</div>

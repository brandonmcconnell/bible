<span className="v" id="v1" data-v="1" data-xref="以西結書 8:11–12; 以賽亞書 30:14; 耶利米哀歌 4:2"> 耶和華如此說：「你去買個陶匠的瓦罐，然後帶上子民中的長老和祭司中的長老，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 15:8; 列王紀下 23:10; 耶利米書 7:31–32"> 出去到哈珥西城門口的欣嫩子谷，在那裡宣告我對你說的話語。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 3:11; 耶利米書 17:20; 以賽亞書 28:19"> 你要說：『猶大君王和耶路撒冷的居民哪，你們要聽耶和華的話語！以色列的神萬軍之耶和華如此說：看哪，我就要使禍患臨到這地方，所有聽見這事的人，都會耳朵震響。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 2:34; 申命記 28:20; 列王紀下 21:16"> 因為他們離棄了我，使這地方成為異邦之地，在這裡向別的神燒香，那是他們和他們的祖先以及猶大君王都不認識的神明；他們又使這地方滿了無辜人的血。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:35; 申命記 12:31; 利未記 18:21"> 他們還建造了巴力的高壇，為要在火中焚燒自己的兒女，作燔祭獻給巴力；這不是我所吩咐的，不是我所提說的，我也從來沒有這樣想過。』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 15:8; 以賽亞書 30:33; 耶利米書 19:2"> 「所以看哪，這是耶和華的宣告：日子將到，這地方必不再被稱為陀斐特或欣嫩子谷，而要被稱為『殺戮谷』。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 26:17; 耶利米書 16:4; 詩篇 33:10–11"> 我要在這地方使猶大和耶路撒冷的謀略落空，使他們在仇敵面前倒在刀下，倒在尋索他們性命的人手下。我要把他們的屍體交給天空的飛鳥和地上的走獸作食物。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 18:16; 耶利米書 49:13; 列王紀上 9:8"> 我要使這城令人驚駭、被嗤笑；所有經過這城的人，都會因她所受的一切擊打而驚恐，並嗤笑她。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 9:20; 利未記 26:29; 耶利米哀歌 4:10"> 他們在圍困和壓迫中，在仇敵和尋索他們性命的人壓迫他們的時候，我要使他們吃自己兒女的肉，也彼此吃對方的肉。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 51:63–64; 耶利米書 48:12; 耶利米書 19:1"> 「你要在那些與你一起去的人眼前，打碎那個瓦罐，</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:9; 以賽亞書 30:14; 耶利米哀歌 4:2"> 對他們說，萬軍之耶和華如此說：我必照樣打碎這子民和這城，就像人打碎陶匠的瓦器，不能再修復。人們必在陀斐特埋葬他們，因為沒有別的地方可以埋葬。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 10:13; 耶利米書 11:5"> 我必如此對待這地方和其中的居民，使這城像陀斐特一樣。這是耶和華的宣告。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 32:29; 列王紀下 23:12; 西番雅書 1:5"> 耶路撒冷的房屋和猶大列王的宮殿，必成為陀斐特地那樣的不潔之處，因為在這些房屋的屋頂上，人們曾向諸天的萬象燒香，向別的神澆奠酒祭。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 26:2; 歷代志下 20:5; 耶利米書 19:2–3"> 耶利米從陀斐特，就是耶和華派遣他去說預言的地方回來，站在耶和華殿的院宇裡，對全體民眾說：</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 7:26; 耶利米書 17:23; 尼希米記 9:29"> 「以色列的神萬軍之耶和華如此說：看哪，我必使我對這城宣告的一切禍患臨到這城和屬它的所有城鎮！因為他們硬著頸項，不聽從我的話。」</span>
</div>

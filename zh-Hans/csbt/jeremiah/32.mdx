<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 39:1–2; 列王紀下 25:1–2; 耶利米書 25:1"> 猶大王西底加十年，就是尼布甲尼撒十八年，有話語從耶和華臨到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 37:21; 尼希米記 3:25; 耶利米書 33:1"> 那時巴比倫王的軍隊正圍困耶路撒冷，先知耶利米被囚禁在猶大王宮中護衛兵的院子裡。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 34:2–3; 耶利米書 21:4–7; 耶利米書 26:8–9"> 猶大王西底加囚禁他時，問他：「你為什麼這樣預言呢？你說：『耶和華如此說：看哪，我要把這城交在巴比倫王手中，他必攻取這城。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:4–7; 列王紀下 25:4–7; 耶利米書 37:17"> 猶大王西底加必不能從迦勒底人手中逃脫，一定會被交在巴比倫王手中；他們必面對面說話，眼對眼相看。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 39:7; 以西結書 17:9–10; 以西結書 17:15"> 巴比倫王必把西底加帶到巴比倫，西底加必留在那裡，直到我眷顧他的時候。即使你們與迦勒底人爭戰，也不會成功。這是耶和華的宣告。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶利米說：<br />耶和華的話語臨到我，說：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 1:1; 耶利米書 11:21; 利未記 25:25"> 「看哪，你叔叔沙勒姆的兒子哈拿米列必來見你，說：『請你買下我在亞納圖的那塊田地，因為你有買它的贖回權。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米書 32:7; 耶利米書 32:2; 耶利米書 33:1"> 之後，正如耶和華所說的，我叔叔的兒子哈拿米列來到護衛兵的院子見我，對我說：「請你買下我在便雅憫地亞納圖的那塊田地，因為你有繼承權和贖回權。你買下來吧！」我就知道這是耶和華的話語。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 11:12–13; 以斯帖記 3:9; 列王紀上 20:39"> 於是我向我叔叔的兒子哈拿米列買下亞納圖的那塊田地，稱了十七謝克爾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十七謝克爾——相當於193.8公克。1謝克爾=11.4公克。">a</a></sup>銀子給他。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:44; 耶利米書 32:12; 耶利米書 32:25"> 我在契約上籤了字，然後封印，又請人做見證，並用天平稱了銀子。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前書 11:16; 使徒行傳 26:3"> 然後我拿起含有細則和條款的購買契約，一份是封印的，一份是未封的，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 32:16; 耶利米書 51:59; 耶利米書 36:4–5"> 當著我叔叔的兒子哈拿米列的面，當著那些在購買契約上簽字的見證人的面，當著所有坐在護衛兵院子裡的猶大人的面，把購買契約交給了瑪西雅的孫子、尼利亞的兒子巴錄克。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 我當著他們的面，吩咐巴錄克說：</span>
<span className="v" id="v14" data-v="14"> 「以色列的神萬軍之耶和華如此說：你要把封印的和未封的這兩份購買契約，拿去放在瓦器裡，好使它們存留許多日子。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 3:10; 阿摩司書 9:14–15; 耶利米書 30:18"> 因為以色列的神萬軍之耶和華如此說：在這地，人們必再次購買房屋、田地和葡萄園。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 12:1; 創世記 32:9–12; 腓立比書 4:6–7"> 我把購買契約交給尼利亞的兒子巴錄克之後，向耶和華禱告說：</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米書 32:27; 創世記 18:14"> 「唉，主耶和華啊！看哪，是你以偉大的能力和伸出的膀臂造了諸天和大地，在你沒有任何難成的事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 10:16; 申命記 5:9–10; 出埃及記 34:7"> 你施行慈愛，直到千代，又把父親的罪孽報應在他們的後代子孫懷中。偉大全能的神哪，萬軍之耶和華是你<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你——原文直譯「他」。">b</a></sup>的名！</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 17:10; 馬太福音 16:27; 詩篇 62:12"> 你謀事有大略，行事有大能；你睜眼看世人一切的道路，要照著各人的道路，照著他行為所結的果實回報各人。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 9:10; 撒母耳記下 7:23; 出埃及記 10:2"> 你曾在埃及地施行神蹟和奇事，在以色列和世人中間也是如此，直到今日；你為自己成就了名聲，就像今日這樣。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 6:6; 申命記 26:8; 詩篇 105:43"> 你曾用神蹟、奇事、大能的手、伸出的膀臂和極其可畏的事，把你的子民以色列從埃及地領出來，</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 3:8; 出埃及記 13:5; 耶利米書 11:5"> 又把這地賜給他們，就是你曾向他們的祖先起誓要賜給他們的流奶與蜜之地。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:7; 詩篇 78:54–55; 但以理書 9:10–14"> 他們進去占有了這地，卻不聽從你的話，也不遵行你的律法；你吩咐他們做的任何事，他們都不做，所以你使這一切禍患臨到他們。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 32:36; 申命記 4:26; 約書亞記 23:15–16"> 看哪，攻城的土壘已經迫近這城，要攻破它了！因刀劍、饑荒和瘟疫，這城被交在攻打它的迦勒底人手中。你所說的都成就了，看哪，你也都看見了！</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 32:24; 詩篇 97:2; 詩篇 77:19"> 主耶和華啊，你卻對我說『你要用銀子為自己買下那塊田地，並且請人做見證』，其實這城已經被交在迦勒底人手中了。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華的話語臨到耶利米，說：</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:26; 耶利米書 32:17; 以賽亞書 64:8"> 「看哪，我是耶和華，是一切有血肉者的神。難道在我有什麼難成的事嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 32:3; 耶利米書 32:24; 耶利米書 19:7–12"> 耶和華如此說：看哪，我要把這城交在迦勒底人手中和巴比倫王尼布甲尼撒手中，他必攻取這城。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 21:10; 耶利米書 19:13; 耶利米書 52:13"> 攻打這城的迦勒底人必進來，放火燒毀這城和其中的房屋，因為在那些房屋頂上，人們曾向巴力燒香，向別的神澆奠酒祭，以致惹我惱怒。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 7:22–26; 申命記 9:7–12; 耶利米書 25:7"> 實際上，以色列子民和猶大子民從年幼時就專做我眼中看為惡的事，以色列子民專以他們手所造的惹怒我。這是耶和華的宣告。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:27; 耶利米書 27:10; 列王紀下 21:4–7"> 這城自從建造的那天起，直到今日，常惹動我的怒氣和怒火，以致我要把這城從我面前除掉。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理書 9:8; 耶利米書 2:26; 以賽亞書 1:4–6"> 以色列子民和猶大子民，就是他們和他們的君王、首領、祭司、先知，以及猶大人和耶路撒冷居民，以他們所做的一切惡事惹怒我。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 7:13; 耶利米書 2:27; 以西結書 8:16"> 他們轉身背對著我，不面向我；我不斷地教導他們，他們卻不聽從，不接受管教。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 7:30; 以西結書 8:5–16; 列王紀下 21:4–7"> 他們把自己的可憎偶像放在這被稱為我名下的殿宇裡，玷汙了它。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 7:31; 歷代志下 33:6; 利未記 18:21"> 他們建造欣嫩子谷中的巴力高壇，為要把自己的兒女經火獻給摩洛。這不是我所吩咐他們的，我也從來沒有這樣想過；他們行這可憎之事，以致猶大陷入罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米書 32:24; 耶利米書 32:3; 耶利米書 32:28"> 「現在，論到這城，就是你們說『因著刀劍、饑荒和瘟疫，被交在巴比倫王手中』的這城，以色列的神耶和華如此說：</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 23:3; 耶利米書 23:6; 以西結書 34:12–14"> 看哪，我必從各地，就是我在怒氣、怒火和大震怒中驅趕他們所到的地方，把他們招聚起來，使他們回到這地方，安然居住。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 24:7; 以西結書 11:19–20; 希伯來書 8:10"> 他們要作我的子民，我要作他們的神。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 11:19–20; 使徒行傳 4:32; 約翰福音 17:21"> 我要使他們同心、同路，好讓他們終日敬畏我，使他們和他們的後代子孫得享福份。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米書 31:31–33; 以西結書 36:26; 耶利米書 24:7"> 我要與他們立一個永遠的約：我絕不轉離他們，而要向他們施恩；我要使他們心中敬畏我，不再離開我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 24:6; 西番雅書 3:17; 以賽亞書 62:5"> 我必樂意向他們施恩，全心、全靈、信實地把他們栽種在這地上。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="耶利米書 31:28; 約書亞記 23:14–15; 耶利米書 33:10–11"> 「是的，耶和華如此說：我怎樣使這一切大禍患臨到這子民，也必怎樣使我應許他們的一切福份臨到他們。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 37:11–14; 耶利米書 32:15; 耶利米書 32:36"> 在你們說『荒涼，沒有人，也沒有牲畜，已被交在迦勒底人手中』的這地上，必有人購買田地。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米書 17:26; 耶利米書 33:26; 耶利米書 33:11"> 在便雅憫地、耶路撒冷的四圍、猶大的各城、山地的各城、丘陵的各城和南地<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地——音譯作「內蓋夫」。">c</a></sup>的各城，人們必用銀子購買田地，在契約上簽字、封印，又請見證人做見證，因為我必使他們的擄民回歸。這是耶和華的宣告。」</span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="民數記 10:33; 詩篇 95:11; 馬太福音 11:28"> 耶和華如此說：<br /><span className="pl pl-1">刀下倖存的子民，</span><br /><span className="pl pl-1">在曠野蒙了恩；</span><br /><span className="pl pl-1">以色列去尋找安寧的時候，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 103:17; 以賽亞書 54:8–9; 何西阿書 11:4"> <span className="pl pl-1">耶和華從遠方向他</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——原文直譯「我」。">a</a></sup><br /><span className="pl pl-1">顯現，說：</span><br /><span className="pl pl-1">「我以永遠的愛愛你，</span><br /><span className="pl pl-1">因此我對你長懷慈愛</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="對你長懷慈愛——或譯作「以信實之愛吸引你」。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 33:7; 耶利米書 31:13; 阿摩司書 5:2"> <span className="pl pl-1">少女以色列啊，</span><br /><span className="pl pl-1">我要再次建立你，</span><br /><span className="pl pl-1">你必被建立。</span><br /><span className="pl pl-1">你將再次佩帶鈴鼓，</span><br /><span className="pl pl-1">出去與歡笑的人一起跳舞。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 9:14; 利未記 19:23–25; 申命記 28:30"> <span className="pl pl-1">你將再次在撒瑪利亞的群山上</span><br /><span className="pl pl-1">栽種葡萄園，</span><br /><span className="pl pl-1">栽種的人栽種了，</span><br /><span className="pl pl-1">就能享用收成。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:4–5; 彌迦書 4:1–3; 耶利米書 50:19"> <span className="pl pl-1">必有一天，</span><br /><span className="pl pl-1">守望的人在以法蓮山地呼喚：</span><br /><span className="pl pl-1">『起來，讓我們上錫安，</span><br /><span className="pl pl-1">到我們的神耶和華那裡去！』」</span></span>

<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 14:7; 詩篇 28:9; 以賽亞書 37:31"> 是的，耶和華如此說：<br /><span className="pl pl-1">你們要為雅各喜樂歡唱，</span><br /><span className="pl pl-1">為列國之首歡呼；</span><br /><span className="pl pl-1">要傳揚、讚美，說：</span><br /><span className="pl pl-1">「耶和華啊，</span><br /><span className="pl pl-1">求你拯救你的子民，</span><br /><span className="pl pl-1">拯救以色列餘剩之民！」</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 34:16; 以賽亞書 42:16; 耶利米書 23:8"> <span className="pl pl-1">看哪，我必從北方之地帶回他們，</span><br /><span className="pl pl-1">從地極招聚他們！</span><br /><span className="pl pl-1">他們中間有瞎眼的、瘸腿的、</span><br /><span className="pl pl-1">孕婦、臨產的婦人，</span><br /><span className="pl pl-1">都在一起，</span><br /><span className="pl pl-1">成為一支極大的隊伍回到這裡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 5:4; 耶利米書 3:4; 出埃及記 4:22"> <span className="pl pl-1">他們將哭泣著前來，</span><br /><span className="pl pl-1">我必照著他們的懇求帶領他們。</span><br /><span className="pl pl-1">我要使他們走在溪水旁，</span><br /><span className="pl pl-1">走平穩的道路，</span><br /><span className="pl pl-1">他們在其上不會絆倒。</span><br /><span className="pl pl-1">因為我是以色列的父親，</span><br /><span className="pl pl-1">以法蓮是我的長子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:11; 以西結書 34:12; 申命記 30:4"> <span className="pl pl-1">列國啊，你們要聽耶和華的話語，</span><br /><span className="pl pl-1">要在遠方的眾海島宣告說：</span><br /><span className="pl pl-1">「那一位驅散以色列的，</span><br /><span className="pl pl-1">必招聚他，守護他，</span><br /><span className="pl pl-1">如同牧人守護自己的羊群。」</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 48:20; 提多書 2:14; 以賽亞書 44:23"> <span className="pl pl-1">因為耶和華贖回了雅各，</span><br /><span className="pl pl-1">從那些比雅各強大的人手中救贖了他。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 35:10; 以賽亞書 58:11; 約珥書 3:18"> <span className="pl pl-1">他們必來到錫安的高處歡唱，</span><br /><span className="pl pl-1">容光煥發，</span><br /><span className="pl pl-1">因為耶和華賜下了美物，</span><br /><span className="pl pl-1">就是五穀、新酒、新油、羊羔和牛犢。</span><br /><span className="pl pl-1">他們的心靈必像得灌溉的園子，</span><br /><span className="pl pl-1">絕不再乾涸。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 30:11; 以賽亞書 61:3; 以賽亞書 51:11"> <span className="pl pl-1">那時少女必歡喜跳舞，</span><br /><span className="pl pl-1">年輕人和老年人也一同歡喜。</span><br /><span className="pl pl-1">我要把他們的哀慟變為歡樂，</span><br /><span className="pl pl-1">我要安慰他們，</span><br /><span className="pl pl-1">使他們歡喜，不再悲哀。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:25; 彼得前書 2:9; 耶利米書 33:9"> <span className="pl pl-1">我要用美食讓祭司的心滿足，</span><br /><span className="pl pl-1">我的子民必因我的美物而飽足。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="馬太福音 2:16–18; 耶利米書 40:1; 詩篇 77:2"> 耶和華如此說：<br /><span className="pl pl-1">在拉瑪聽見了聲音，</span><br /><span className="pl pl-1">是哀號和沉痛哭泣的聲音，</span><br /><span className="pl pl-1">是拉結為她的兒女哀哭，</span><br /><span className="pl pl-1">不肯為兒女接受安慰，</span><br /><span className="pl pl-1">因為他們不在了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="路得記 2:12; 耶利米書 30:3; 希伯來書 6:10"> 耶和華如此說：<br /><span className="pl pl-1">停住聲音不要哭了，</span><br /><span className="pl pl-1">讓你的眼睛止住淚水；</span><br /><span className="pl pl-1">因為你所做的必有賞報，</span><br /><span className="pl pl-1">他們必從仇敵之地回歸。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:21; 耶利米書 29:11–16; 耶利米哀歌 3:18"> <span className="pl pl-1">你的前途必有希望，</span><br /><span className="pl pl-1">你的兒女必回到自己境內。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:9; 詩篇 80:3; 約伯記 5:17"> <span className="pl pl-1">我確實聽見以法蓮在悲嘆：</span><br /><span className="pl pl-1">「你管教了我，</span><br /><span className="pl pl-1">我像沒有被馴服的牛犢受管教。</span><br /><span className="pl pl-1">求你使我回轉，好讓我回轉，</span><br /><span className="pl pl-1">因為你是耶和華我的神。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:31; 耶利米書 3:25; 以西結書 21:12"> <span className="pl pl-1">我回轉之後就後悔，</span><br /><span className="pl pl-1">我受教之後就拍大腿；</span><br /><span className="pl pl-1">我抱愧羞慚，</span><br /><span className="pl pl-1">因為我承受了年幼時的羞辱。」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 55:7; 彌迦書 7:18–19; 以賽亞書 63:15"> <span className="pl pl-1">以法蓮是我親愛的兒子嗎？</span><br /><span className="pl pl-1">是我喜歡的孩子嗎？</span><br /><span className="pl pl-1">當然！我雖常常責備他，</span><br /><span className="pl pl-1">還是深深記念他。</span><br /><span className="pl pl-1">因此我的心腸為他翻騰，</span><br /><span className="pl pl-1">我必定憐憫他。」</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 50:5; 以賽亞書 62:10; 詩篇 84:5"> <span className="pl pl-1">你要為自己設立標記，豎立路標；</span><br /><span className="pl pl-1">你要留心大道，就是你走過的道路。</span><br /><span className="pl pl-1">少女以色列啊，回轉吧，</span><br /><span className="pl pl-1">回到你的這些城鎮吧！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 49:4; 耶利米書 7:24; 馬太福音 1:21"> <span className="pl pl-1">背道的女兒啊，</span><br /><span className="pl pl-1">你反复無常要到什麼時候呢？</span><br /><span className="pl pl-1">耶和華在地上創造了一件新事：</span><br /><span className="pl pl-1">女人圍護男人。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 8:3; 以賽亞書 1:26; 耶利米書 50:7"> 以色列的神萬軍之耶和華如此說：我使他們的擄民回歸時，他們必在猶大地和其中的各城再次說這樣的話：「公義的居所，聖山哪，願耶和華祝福你！」</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 8:4–8; 以西結書 36:10; 撒迦利亞書 2:4"> 猶大和猶大各城的人，農夫和那些帶著群羊遊牧的人，都必一同住在那地。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 5:6; 馬太福音 11:28; 約翰福音 4:14"> 我必使疲乏的心靈得潤澤，使所有乾涸的心靈得滿足。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="詩篇 127:2; 撒迦利亞書 4:1–2"> 我醒來觀看，我睡得好香甜！</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="何西阿書 2:23; 撒迦利亞書 10:9; 以西結書 36:9"> 看哪，這是耶和華的宣告：日子將到，我要使人類的種子和牲畜的種子在以色列家和猶大家繁衍！</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 24:6; 耶利米書 1:10; 耶利米書 18:7–9"> 我曾怎樣看管他們，為要拔出、拆毀、傾覆、消滅、降禍，我也必怎樣看管他們，為要建立和栽種。這是耶和華的宣告。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 5:7; 以西結書 18:2–3; 耶利米書 31:30"> 在那些日子，人們必不再說：<br /><span className="pl pl-1">「父親吃酸葡萄，</span><br /><span className="pl pl-1">兒子的牙齒酸倒了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西結書 18:20; 以賽亞書 3:11; 申命記 24:16"> 各人卻要因自己的罪孽而死；凡吃酸葡萄的，這人的牙齒必酸倒。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="希伯來書 10:16–17; 以西結書 37:26; 耶利米書 31:31–34"> 看哪，這是耶和華的宣告：日子將到，我要與以色列家和猶大家立一個新的約，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 24:6–8; 申命記 5:3; 出埃及記 19:5"> 不像從前的約。我拉著他們祖先的手，領他們出埃及地的日子裡，與他們立了約，他們卻違背我的約，儘管我是他們的主人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主人——或譯作「丈夫」。">c</a></sup>。這是耶和華的宣告。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 3:3; 希伯來書 10:16; 希伯來書 8:10"> 在那些日子之後，我要與以色列家所立的約是這樣的：我要把我的律法放在他們裡面，寫在他們心上；我要作他們的神，他們要作我的子民。這是耶和華的宣告。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 43:25; 希伯來書 8:12; 約翰一書 2:27"> 他們各人不再教導自己的鄰舍和兄弟，說：「你要認識耶和華。」因為無論尊卑，都必認識我。我要赦免他們的罪孽，不再記念他們的罪惡。這是耶和華的宣告。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="耶利米書 10:16; 以賽亞書 51:15; 詩篇 136:7–9"> 耶和華使太陽作白天的光，使月亮和星辰按定律作夜間的光；他攪動海洋，使海中的波濤咆哮；萬軍之耶和華是他的名。耶和華如此說：</span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 54:9–10; 耶利米書 33:20–26; 詩篇 89:36–37"> <span className="pl pl-1">除非這些定律能從我面前挪移，</span><br /><span className="pl pl-1">否則，以色列的後裔</span><br /><span className="pl pl-1">永不會在我面前斷絕，</span><br /><span className="pl pl-1">他們必再成為一個國家。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="耶利米書 33:24–26; 以賽亞書 40:12; 耶利米書 33:22"> 耶和華如此說：<br /><span className="pl pl-1">除非人能測量在上的諸天，</span><br /><span className="pl pl-1">探查在下的大地根基，</span><br /><span className="pl pl-1">否則，我絕不會因那些以色列後裔</span><br /><span className="pl pl-1">所做的一切而棄絕他們。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒迦利亞書 14:10; 列王紀下 14:13; 耶利米書 30:18"> 看哪，這是耶和華的宣告：日子將到，這城必重建歸於耶和華，從恩典樓直到角門。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亞書 2:1–2; 以西結書 40:8"> 測量的準繩還要往外伸展，直到迦立丘陵，然後繞到歌亞；</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 15:23; 約珥書 3:17; 列王紀下 11:16"> 拋屍體和倒灰燼的整個山谷，以及從汲淪溪谷到東邊馬門角落的所有田地，都必歸耶和華為聖。這城永不再被拔出，不再被傾覆。</span>

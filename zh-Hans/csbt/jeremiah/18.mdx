<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 有話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 1:1; 使徒行傳 9:6; 耶利米書 19:1–2"> 「起來，下到陶匠的家裡去。我要在那裡使你聽到我的話語。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 15:14; 約拿書 1:3; 使徒行傳 26:19"> 我就下到陶匠的家裡去，看哪，他正在輪盤上做工。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:20–23; 耶利米書 18:6; 以賽亞書 45:9"> 陶匠用陶泥做的器皿，在他手中做壞了，他就把這泥再做成別的器皿，照著陶匠眼中看為好的去做。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 那時耶和華的話語臨到我，說：</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 64:8; 羅馬書 9:20–21; 耶利米書 18:4"> 「以色列家啊，難道我不能像這陶匠一樣對待你們嗎？以色列家啊，看哪，陶泥在陶匠手中怎樣，你們在我手中也怎樣。這是耶和華的宣告。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 1:10; 耶利米書 12:14–17; 耶利米書 45:4"> 我何時宣告要拔出、拆毀、消滅一邦或一國，</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 18:21; 耶利米書 26:13; 約拿書 3:9–10"> 如果我所宣告的那邦國轉離了他們的惡行，我就改變心意，不把我所計劃的災禍降給他們。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 31:28; 阿摩司書 9:11–15; 耶利米書 1:10"> 我何時宣告要建立、栽種一邦或一國，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 33:18; 撒母耳記上 2:30; 以西結書 18:24"> 如果他們做我眼中看為惡的事，不聽從我的話，我就改變心意，不把我所說的福份賜給他們。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 17:13; 以賽亞書 55:6–7; 耶利米書 35:15"> 現在，你要告訴猶大人和耶路撒冷的居民說，耶和華如此說：看哪，我正在籌備災禍攻擊你們，謀劃計策對付你們！你們各人要轉離自己邪惡的道路，改正自己的所作所為。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:25; 耶利米書 7:24; 申命記 29:19"> 他們卻說：『算了吧！我們一定要照著自己的意圖而行，各人隨從自己頑固敗壞的心行事。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 5:30; 何西阿書 6:10; 耶利米書 23:14"> 「因此，耶和華如此說：<br /><span className="pl pl-1">你們在列國中問問吧，</span><br /><span className="pl pl-1">有誰聽過這樣的事呢？</span><br /><span className="pl pl-1">少女以色列做了一件極其可怕的事。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 6:68"> <span className="pl pl-1">黎巴嫩的雪會從高原的磐石上消失嗎？</span><br /><span className="pl pl-1">那從遠處流下來的清涼之水會斷絕嗎？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 6:16; 耶利米書 2:32; 何西阿書 11:2"> <span className="pl pl-1">然而我的子民卻忘記了我，</span><br /><span className="pl pl-1">向虛妄的偶像燒香！</span><br /><span className="pl pl-1">他們在自己的道路上，</span><br /><span className="pl pl-1">在那古時的路途上絆跌，</span><br /><span className="pl pl-1">去走崎嶇小路，而非平坦的大道，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 22:7; 耶利米書 25:9; 耶利米書 19:8"> <span className="pl pl-1">以致他們的國土令人驚駭，</span><br /><span className="pl pl-1">永遠被嗤笑，</span><br /><span className="pl pl-1">所有經過這地的人都驚恐、搖頭。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 13:24; 耶利米書 2:27; 約伯記 27:21"> <span className="pl pl-1">我要像一陣東風，</span><br /><span className="pl pl-1">使他們在仇敵面前四散；</span><br /><span className="pl pl-1">他們遭難的日子裡，</span><br /><span className="pl pl-1">我只讓他們看見我的背，</span><br /><span className="pl pl-1">不讓他們看見我的面。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 52:2; 耶利米書 11:19; 瑪拉基書 2:7"> 他們說：「來吧，讓我們謀劃計策對付耶利米！反正律法不會從祭司消亡，謀略不會從智慧人消亡，話語也不會從先知消亡。來吧，讓我們用舌頭攻擊他，不要理睬他的任何話語！」</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 6:9; 耶利米書 20:12; 詩篇 55:16–17"> <span className="pl pl-1">耶和華啊，求你傾聽我的話，</span><br /><span className="pl pl-1">求你聽聽與我爭鬥之人的聲音！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 35:7; 詩篇 57:6; 詩篇 106:23"> <span className="pl pl-1">人怎能以惡報善呢？</span><br /><span className="pl pl-1">他們竟然挖坑害我的性命。</span><br /><span className="pl pl-1">求你記念我曾站在你面前為他們說好話，</span><br /><span className="pl pl-1">為要使你的怒火轉離他們。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 109:9–20; 耶利米哀歌 5:3; 阿摩司書 4:10"> <span className="pl pl-1">因此，求你把他們的兒女交給饑荒，</span><br /><span className="pl pl-1">把他們交在刀劍之下！</span><br /><span className="pl pl-1">願他們的妻子喪失兒女，並且成為寡婦，</span><br /><span className="pl pl-1">願他們的男人被殺死，</span><br /><span className="pl pl-1">他們的青年人在戰場上被刀劍擊殺！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 6:26; 詩篇 140:5; 西番雅書 1:10–11"> <span className="pl pl-1">你使襲擊者突然來攻擊他們的時候，</span><br /><span className="pl pl-1">願哀聲從他們的房屋裡傳出！</span><br /><span className="pl pl-1">他們竟然挖了坑，要捉住我；</span><br /><span className="pl pl-1">暗設網羅，要絆我的腳。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 35:4; 詩篇 69:22–28; 尼希米記 4:4–5"> <span className="pl pl-1">可是你，耶和華啊，</span><br /><span className="pl pl-1">你知道他們要殺我的一切謀劃！</span><br /><span className="pl pl-1">求你不要赦免</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="赦免——原文直譯「贖」。">a</a></sup><br /><span className="pl pl-1">他們的罪，</span><br /><span className="pl pl-1">不要從你面前抹掉他們的罪惡；</span><br /><span className="pl pl-1">求你使他們在你面前絆倒，</span><br /><span className="pl pl-1">求你在發怒的時候處治他們！</span></span>
</div>

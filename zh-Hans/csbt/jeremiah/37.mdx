<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 22:24; 列王紀下 24:17; 列王紀下 24:12"> 約西亞的兒子西底加接替約雅敬的兒子哥尼雅作王，是巴比倫王尼布甲尼撒使他在猶大地作王的。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 24:19–20; 箴言 29:12; 歷代志下 36:12–16"> 他和他的臣僕，以及那地的民眾，都不聽從耶和華藉著先知耶利米所說的話語。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:1–2; 耶利米書 29:25; 耶利米書 42:20"> 西底加王派遣示勒米雅的兒子猶甲和瑪西雅的兒子祭司西番雅到先知耶利米那裡，說：「請為我們向耶和華我們的神禱告。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 37:15; 耶利米書 32:2–3"> 那時耶利米在民眾當中出入，他們還沒有把他關進牢房；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 17:15; 耶利米書 37:11; 耶利米書 34:21"> 法老的軍隊已經從埃及出來，那些圍困耶路撒冷的迦勒底人聽見他們的風聲，就從耶路撒冷撤離了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶和華的話語臨到先知耶利米，說：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米哀歌 4:17; 列王紀下 22:18; 以西結書 17:17"> 「以色列的神耶和華如此說：你們要對派你們來求問我的猶大王如此說：『看哪，出來幫助你們的法老的軍隊必回埃及本土去。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 39:2–8; 耶利米書 38:23; 耶利米書 34:21–22"> 迦勒底人必回來攻打這城，攻取它，放火燒毀它。』</span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亞書 1:3; 耶利米書 29:8; 加拉太書 6:3"> 耶和華如此說：你們不要欺哄自己說『迦勒底人一定會離開我們』，因為他們不會離開。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 50:45; 以賽亞書 30:17; 約珥書 2:11"> 即使你們擊敗了與你們爭戰的迦勒底全軍，使他們只剩下受重傷的人在各自的帳篷中，他們也必起來，放火燒毀這城。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 37:5"> 迦勒底人的軍隊因法老的軍隊而從耶路撒冷撤離的時候，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 1:1; 尼希米記 6:11; 列王紀上 19:3"> 耶利米從耶路撒冷出來，往便雅憫地去，要在那裡從民眾當中分得產業。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 14:10; 耶利米書 38:7; 路加福音 23:2"> 他到了便雅憫門，那裡有個守門官，名叫伊利雅，是哈納尼雅之子示勒米雅的兒子，他抓住先知耶利米，說：「你是要投降迦勒底人！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 52:1–2; 耶利米書 40:4–6; 詩篇 27:12"> 耶利米說：「你錯了，我不是要投降迦勒底人！」但伊利雅不聽他，抓住耶利米，把他帶到首領們那裡。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 38:26; 耶利米書 20:1–3; 耶利米書 26:16"> 首領們就對耶利米發怒，打了他，把他關進囚室，就是書記約拿單的房屋，因為他們把這房屋做成了牢房。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 38:6; 耶利米書 38:10–13; 耶利米哀歌 3:53"> 這樣，耶利米進了地牢，就是囚房，在那裡拘留了許多日子。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 21:7; 耶利米書 24:8; 列王紀上 14:1–4"> 西底加王派人把他帶出來，王在自己的宮殿裡暗中問他說：「有話語從耶和華臨到你嗎？」<br />耶利米說：「有！」又說：「你必被交在巴比倫王手中。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 25:8; 約翰福音 10:32; 但以理書 6:22"> 耶利米又對西底加王說：「我對你，對你的臣僕，對這子民，犯了什麼罪，以致你把我關在牢房裡呢？</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 2:28; 耶利米書 28:10–17; 耶利米書 6:14"> 那些曾向你們預言說『巴比倫王不會來攻擊你們和這地』的先知，如今在哪裡呢？</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 36:7; 耶利米書 38:6–9; 使徒行傳 28:18–19"> 我主我王啊，現在請聽！請讓我的懇求達到你面前，不要把我送回書記約拿單的房屋，以免我死在那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 38:13; 耶利米書 38:28; 耶利米書 38:9"> 於是西底加王下令，他們就把耶利米安置在護衛兵院子裡，每天從烤餅街拿一塊餅給他，直到這城裡所有的餅都吃光了。這樣，耶利米就拘留在護衛兵的院子裡。</span>
</div>
</div>

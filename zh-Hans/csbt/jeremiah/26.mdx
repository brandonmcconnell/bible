<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 36:4–5; 耶利米書 27:1; 列王紀下 23:34–36"> 約西亞的兒子猶大王約雅敬開始執政的時候，有這話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:2; 使徒行傳 20:27; 馬太福音 28:20"> 「耶和華如此說：你要站在耶和華殿的院宇裡，把我指示你說的一切話，都告訴猶大各城的人，就是到耶和華的殿來敬拜的人，一個字也不可減去。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 36:3; 以賽亞書 1:16–19; 耶利米書 18:7–10"> 或許他們肯聽從，各人轉離邪惡的道路，我就改變心意，不把我因他們的惡行而計劃的災禍降給他們。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:6; 耶利米書 44:10; 以賽亞書 1:20"> 你要對他們說，耶和華如此說：如果你們不聽從我，不遵行我在你們面前設立的律法，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 11:7; 列王紀下 9:7; 耶利米書 7:13"> 不聽從我僕人眾先知的話語——我派遣他們到你們那裡去，不斷地派遣，你們卻不聽從——</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 24:9; 列王紀下 22:19; 耶利米書 25:18"> 我就使這殿宇像示羅那樣，使這城被地上萬國咒罵。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 5:31; 彌迦書 3:11; 使徒行傳 5:17"> 耶利米在耶和華殿中說的這些話，祭司和先知們以及全體民眾都聽見了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:13–14; 使徒行傳 7:52; 耶利米書 18:18"> 耶利米說完了耶和華吩咐他對全體民眾說的一切話，祭司和先知們以及全體民眾就抓住他，說：「你必須死！</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:17–19; 使徒行傳 19:24–32; 彌迦書 2:6"> 你為什麼奉耶和華的名預言說這殿宇必像示羅那樣，這城必荒廢，無人居住？」全體民眾都在耶和華殿中聚集到耶利米那裡。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:10; 耶利米書 38:4–6; 耶利米書 37:14–16"> 猶大的首領們聽見這些事，就從王宮上耶和華的殿去，在耶和華殿的新門入口坐下。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 38:4; 馬太福音 26:66; 申命記 18:20"> 祭司和先知們對首領們和全體民眾說：「這人該受死刑！因為他說預言攻擊這城，正如你們親耳聽見的。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:29; 耶利米書 26:15; 使徒行傳 4:19"> 於是耶利米對眾首領和全體民眾說：「是耶和華派遣了我，針對這聖殿和這城，預言你們所聽見的一切話。</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 3:9; 約拿書 4:2; 以賽亞書 1:19"> 現在，你們要改正你們的所作所為，聽從你們的神耶和華的話，好讓耶和華改變心意，不把他所宣告的災禍降給你們。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 9:25; 撒母耳記下 15:26; 耶利米書 38:5"> 至於我，看哪，我在你們手中，你們看怎樣好、怎樣合適，就怎樣對待我吧！</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 35:33; 箴言 6:17; 馬太福音 26:25"> 不過你們要確實知道：你們如果把我處死，就是把無辜人的血債歸在你們身上，歸到這城和其中的居民身上，因為耶和華確實派遣了我到你們這裡，把這一切話語傳到你們的耳中。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 5:34–39; 使徒行傳 23:29; 使徒行傳 25:25"> 首領們和全體民眾就對祭司和先知們說：「這人不該受死刑！因為他是奉我們神耶和華的名對我們說話。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:34; 彌迦書 1:1"> 那地的長老中有一些人起來，對聚集的全體民眾說：</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 1:1; 尼希米記 4:2; 撒迦利亞書 8:3"> 「猶大王希西加年間，摩利沙人彌迦說預言，向猶大全體民眾宣告說：『萬軍之耶和華如此說：<br /><span className="pl pl-1">錫安必像田地被耕犁，</span><br /><span className="pl pl-1">耶路撒冷將變為荒堆，</span><br /><span className="pl pl-1">聖殿山將變為荒林高地。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 32:14; 撒母耳記下 24:16; 以賽亞書 37:15–20"> 「那時，猶大王希西加和全體猶大人把他處死了嗎？希西加難道不是敬畏耶和華，懇求耶和華的情面嗎？耶和華就改變心意，沒有把他所宣告的災禍降給他們。現在我們卻要使大禍臨到我們！」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 7:2; 約書亞記 9:17; 約書亞記 15:60"> 另有一個人也奉耶和華的名說預言，這人是基列-耶琳人示瑪雅的兒子烏利亞，他針對這城和這地說預言，與耶利米所說的話語全都一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 10:23; 馬太福音 14:5; 耶利米書 36:26"> 約雅敬王和他的勇士們、首領們全都聽見了烏利亞的話語，王就想要把他處死。烏利亞聽說後就害怕，逃往埃及去了。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 36:12; 列王紀下 22:12; 列王紀下 22:14"> 約雅敬王派人前往埃及，他派亞革波的兒子以利拿單帶著一些人一同到埃及去。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 2:30; 啟示錄 11:7; 以西結書 19:6"> 他們把烏利亞從埃及帶出來，帶到約雅敬王那裡。王用刀殺了他，把他的屍體扔在平民的墳地裡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 40:5–7; 耶利米書 39:14; 耶利米書 1:18–19"> 然而沙番的兒子亞希甘保護了耶利米，使他不被交在民眾的手中處死。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 13:11; 希伯來書 1:1; 耶利米書 27:2"> 耶和華對我如此說：「你去為自己買一條細麻腰帶，束在腰上；這腰帶不可過水。」</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 2:8; 約翰福音 15:14; 箴言 3:5"> 我就照著耶和華的話語，買了一條腰帶，束在腰上。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 13:8"> 耶和華的話語第二次臨到我，說：</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 4:10; 詩篇 137:1; 耶利米書 51:63–64"> 「你帶上那買來束在腰上的腰帶，起來往幼發拉底河去，把它藏在那裡的岩石縫中。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 40:16; 出埃及記 39:42–43; 提摩太後書 2:3"> 我就去，照著耶和華吩咐我的，把它藏在幼發拉底河那裡。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 過了許多日子，耶和華對我說：「你起來往幼發拉底河去，把我吩咐你藏在那裡的腰帶從那裡取出來。」</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:12; 以賽亞書 64:6; 耶利米書 13:10"> 我就往幼發拉底河去，在那裡掏挖，把腰帶從所藏的地方取出來。看哪，腰帶已經毀掉，沒有任何用處了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 26:19; 耶利米書 13:15–17; 西番雅書 3:11"> 「耶和華如此說：我必照樣摧毀猶大的驕傲，摧毀耶路撒冷極大的驕傲。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 16:12; 耶利米書 9:14; 歷代志下 36:15–16"> 這敗壞的子民，不肯聽從我的話，照著自己頑固的心行事，又跟從別的神，服事它們，向它們下拜，這子民必像這腰帶一樣，沒有任何用處。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 19:5–6; 耶利米書 33:9; 詩篇 81:11"> 因為正如腰帶緊貼人的腰，我也曾使以色列全家和猶大全家照樣緊貼著我，為要使他們作我的子民，使我得名聲，得讚美，得榮耀，他們卻不聽從我的話<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我的話——輔助詞語。">a</a></sup>。這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 24:19"> 「你要對他們說這話：『以色列的神耶和華如此說：每個罈子都要裝滿酒。』他們會對你說：『難道我們不知道每個罈子都要裝滿酒嗎？』</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 63:6; 詩篇 75:8; 詩篇 60:3"> 你就對他們說：『耶和華如此說：看哪，我必使這地所有的居民，就是坐大衛寶座的君王，還有祭司和先知，以及所有耶路撒冷的居民，都酩酊大醉。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 詩篇 2:9; 耶利米書 19:9–11"> 我要使他們彼此碰撞，連父子也彼此碰撞。我必不憐恤、不顧惜、不憐憫，必把他們毀掉。』這是耶和華的宣告。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 28:14–22; 啟示錄 2:29; 使徒行傳 4:19–20"> <span className="pl pl-1">你們要聽，要傾聽，不要自高，</span><br /><span className="pl pl-1">因為耶和華已經發話。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 59:9; 以賽亞書 8:22; 以賽亞書 5:30"> <span className="pl pl-1">在耶和華帶來黑暗之前，</span><br /><span className="pl pl-1">你們的腳絆跌在昏暗的群山上之前，</span><br /><span className="pl pl-1">你們要歸榮耀給耶和華你們的神，</span><br /><span className="pl pl-1">免得你們等候光明，</span><br /><span className="pl pl-1">他卻使光明成為死蔭，變為幽暗。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 2:2; 耶利米書 9:1; 耶利米書 14:17"> <span className="pl pl-1">如果你們不聽從這話，</span><br /><span className="pl pl-1">我的心就因你們的驕傲而暗中哭泣；</span><br /><span className="pl pl-1">我的眼睛必痛哭流淚，</span><br /><span className="pl pl-1">因為耶和華的羊群被擄走了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 22:26; 列王紀下 24:12; 列王紀下 24:15"> <span className="pl pl-1">「你要對君王和太后說：</span><br /><span className="pl pl-1">『你們降卑坐下吧！</span><br /><span className="pl pl-1">你們的華冠已經從頭上掉下來了。』</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 52:27; 耶利米書 39:9; 申命記 28:52"> <span className="pl pl-1">南地</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音譯作「內蓋夫」。">b</a></sup><br /><span className="pl pl-1">的各城已被封閉，</span><br /><span className="pl pl-1">沒有人打開；</span><br /><span className="pl pl-1">猶大人全都被擄走，</span><br /><span className="pl pl-1">全然被擄去了。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 6:22; 耶利米書 1:14; 哈巴谷書 1:6"> <span className="pl pl-1">舉目觀看那些從北方來的人吧！</span><br /><span className="pl pl-1">從前交託給你的群羊，</span><br /><span className="pl pl-1">你榮美的羊群，</span><br /><span className="pl pl-1">如今在哪裡呢？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 13:8; 耶利米書 4:31; 耶利米書 5:31"> <span className="pl pl-1">「你所結交的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="所結交的——或譯作「曾教導的」。">c</a></sup><br /><span className="pl pl-1">那些同伴，</span><br /><span className="pl pl-1">耶和華將指派他們為首領管轄你，</span><br /><span className="pl pl-1">那時你會說什麼呢？</span><br /><span className="pl pl-1">難道絞痛不會抓住你，</span><br /><span className="pl pl-1">像臨產的婦人那樣嗎？</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="那鴻書 3:5; 耶利米書 16:10–11; 耶利米書 5:19"> <span className="pl pl-1">你如果心裡說：</span><br /><span className="pl pl-1">『這些事為什麼發生在我身上呢？』</span><br /><span className="pl pl-1">那是因為你的罪孽極大，</span><br /><span className="pl pl-1">所以你的衣裙被揭開，</span><br /><span className="pl pl-1">你的腳跟受了傷。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 2:22; 耶利米書 9:5; 馬太福音 19:24–28"> <span className="pl pl-1">庫實人能改變他的膚色嗎？</span><br /><span className="pl pl-1">豹子能改變牠的斑點嗎？</span><br /><span className="pl pl-1">如果能改變，</span><br /><span className="pl pl-1">你們這些慣於行惡的也就能行善了！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 1:4; 利未記 26:33; 以西結書 5:12"> <span className="pl pl-1">因此我要使你們四散，</span><br /><span className="pl pl-1">好像麥稭被曠野的風吹散。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 20:29; 耶利米書 2:32; 詩篇 9:17"> <span className="pl pl-1">這是你的命運，</span><br /><span className="pl pl-1">是我量給你的份，</span><br /><span className="pl pl-1">因為你忘記了我，</span><br /><span className="pl pl-1">依靠虛假的偶像。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米哀歌 1:8; 何西阿書 2:10; 以西結書 23:29"> <span className="pl pl-1">所以我要把你的衣裙掀到你臉上，</span><br /><span className="pl pl-1">以致你的羞辱被人看見。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="何西阿書 8:5; 以西結書 6:13; 以西結書 24:13"> <span className="pl pl-1">你在岡陵上和田野中的通姦、嘶叫，</span><br /><span className="pl pl-1">以及你醜惡的淫行，</span><br /><span className="pl pl-1">這些可憎之事我都看見了。</span><br /><span className="pl pl-1">耶路撒冷啊，你有禍了！</span><br /><span className="pl pl-1">你不潔淨要到什麼時候呢？」</span></span>
</div>

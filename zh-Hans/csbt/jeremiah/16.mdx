<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 1:2; 耶利米書 2:1; 耶利米書 1:4"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 7:26–27; 路加福音 23:29; 創世記 19:14"> 「你在這地方不可娶妻，不可有兒女。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 16:9; 耶利米書 16:5; 耶利米書 6:21"> 因為論到在這地方出生的兒女，以及在這地生養他們的父母，耶和華如此說：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 25:33; 詩篇 83:10; 耶利米書 9:22"> 他們必因致命的疾病而死，無人哀哭，不被埋葬，成為地面上的糞土。他們也必被刀劍和饑荒滅絕，屍體給天空的飛鳥和地上的走獸作食物。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 24:16–23; 以賽亞書 27:11; 耶利米書 15:1–4"> 耶和華如此說：「你不要進入居喪之家，不要去哀哭，也不要為他們悲哀，因為我已從這子民身上收回我的平安，收回慈愛和憐憫。這是耶和華的宣告。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:1; 耶利米書 41:5; 耶利米書 47:5"> 尊貴的和卑微的都必死在這地，不被埋葬，無人哀哭，沒有人為他們割傷自己、剃光頭髮；</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 9:4; 以西結書 24:17; 申命記 26:14"> 也沒有人為哀悼者掰餅，因死者而安慰他們，沒有人因他們喪父或喪母給他們一杯安慰酒喝。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 15:17; 傳道書 7:2–4; 以賽亞書 22:12–14"> 你也不要進入宴樂之家，與他們同坐吃喝。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 25:10; 耶利米書 7:34; 以西結書 26:13"> 是的，以色列的神萬軍之耶和華如此說：「看哪，我必在你們眼前，在你們的年日裡，使這地方不再有歡喜快樂的聲音、新郎新娘的聲音。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 5:19; 列王紀上 9:8–9; 申命記 29:24–25"> 「當你把這一切話語告訴這子民時，他們會對你說：『耶和華為什麼對我們宣告這一切大禍患呢？我們有什麼過犯，對我們的神耶和華犯了什麼罪呢？』</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:35–41; 申命記 29:25–26; 耶利米書 22:9"> 你就對他們說：這是因為你們的祖先離棄了我，跟從別的神，服事它們，向它們下拜；他們離棄了我，不遵守我的律法。這是耶和華的宣告。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 13:10; 耶利米書 7:26; 傳道書 9:3"> 你們也行惡，甚至超過你們的祖先，看哪，你們各人隨從自己頑固敗壞的心行事，不聽從我！</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:36; 申命記 4:26–28; 耶利米書 15:14"> 因此，我要把你們從這地拋出去，扔到你們和你們祖先都不認識的地方，你們將在那裡晝夜服事別的神，因為我必不向你們施恩。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 23:7–8; 申命記 15:15; 出埃及記 20:2"> 「所以看哪，這是耶和華的宣告：日子將到，那時人們必不再說『我指著那從埃及地把以色列子孫帶上來的耶和華的永生起誓』，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 3:18; 耶利米書 24:6; 耶利米書 32:37"> 而會說『我指著那從北方之地，從所有放逐之地把以色列子孫帶上來的耶和華的永生起誓』。我必使他們回歸自己的土地，就是我所賜給他們祖先的土地。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="哈巴谷書 1:14–15; 阿摩司書 4:2; 彌迦書 7:2"> 「看哪，我要派人召來許多漁夫，捕撈他們；此後我還要派人召來許多獵人，從各山各嶺，從岩石縫獵取他們。這是耶和華的宣告。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 15:3; 耶利米書 23:24; 箴言 5:21"> 因為我的眼目察看他們一切的道路，他們不能從我面前隱藏，他們的罪孽也不能從我眼前藏匿。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 35:33–34; 以賽亞書 40:2; 啟示錄 18:6"> 我必須先雙倍報應他們的罪孽和罪惡，因為他們玷汙了我的土地，以毫無生氣的可憎偶像<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="毫無生氣的可憎偶像——或譯作「可憎的屍體」。">a</a></sup>和可厭之物充滿我的產業之地。」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 25:4; 耶利米書 17:17; 那鴻書 1:7"> <span className="pl pl-1">耶和華我的力量、我的堡壘、</span><br /><span className="pl pl-1">我在患難之日的避難所啊，</span><br /><span className="pl pl-1">列國必從地極來到你這裡，說：</span><br /><span className="pl pl-1">「我們祖先所繼承的盡都虛假，</span><br /><span className="pl pl-1">是虛空無益的！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 37:19; 詩篇 115:4–8; 加拉太書 4:8"> <span className="pl pl-1">人能為自己造神嗎？</span><br /><span className="pl pl-1">其實那不是神。」</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 9:16; 詩篇 83:18; 耶利米書 33:2"> <span className="pl pl-1">「所以看哪，</span><br /><span className="pl pl-1">我必使他們知道，就是這一次，</span><br /><span className="pl pl-1">使他們知道我的手、我的大能。</span><br /><span className="pl pl-1">他們必知道：我的名是耶和華。」</span></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 29:25; 耶利米書 37:3; 耶利米書 52:24"> 有話語從耶和華臨到耶利米。那時西底加王派遣瑪基雅的兒子帕示戶珥和瑪西雅的兒子祭司西番雅到耶利米那裡，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 37:3; 耶利米書 42:4–6; 耶利米書 37:7"> 「請你替我們求問耶和華，因為巴比倫王尼布甲尼撒在攻打我們。或許耶和華會照著他的一切奇妙作為對待我們，使巴比倫王從我們面前撤離。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 耶利米對他們說：「你們要對西底加說，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:5; 耶利米書 37:8–10; 以賽亞書 5:5"> 以色列的神耶和華如此說：看哪，你們手中的武器，就是你們用來與巴比倫王和城牆外圍困你們的迦勒底人爭戰的武器，我必把它們掉轉過來，收聚在這城中。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 63:10; 出埃及記 6:6; 以賽亞書 5:25"> 我要在怒氣、怒火和大震怒中，用伸出的手和大能的膀臂，親自攻擊你們。</span>
<span className="v" id="v6" data-v="6" data-xref="西番雅書 1:3; 以西結書 14:13; 耶利米書 12:3–4"> 我要擊殺這城的居民，連人帶牲畜，他們都必死於大瘟疫。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 37:17; 列王紀下 25:5–7; 哈巴谷書 1:6–10"> 此後，我要把猶大王西底加和他的臣民，就是這城裡從瘟疫、刀劍和饑荒中殘留下來的人，都交在巴比倫王尼布甲尼撒手中，交在他們仇敵和尋索他們性命的人手中。尼布甲尼撒必用刀劍擊殺他們，不會顧惜，不會憐恤，不會憐憫他們。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 30:19; 申命記 30:15; 申命記 11:26"> 「你要對這子民說，耶和華如此說：看哪，我把生命的路和死亡的路擺在你們面前：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 38:2; 耶利米書 45:5; 耶利米書 39:18"> 留在這城中的，必死於刀劍、饑荒和瘟疫；但出去向圍困你們的迦勒底人投降的，必得存活，他必保住自己的性命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他必保住自己的性命——原文直譯「使自己的性命作為戰利品歸於他」。">a</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 44:11; 阿摩司書 9:4; 耶利米書 44:27"> 因為我已經決意向這城降禍而不降福，這城必被交在巴比倫王手中，他必放火燒掉這城。這是耶和華的宣告。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 17:20; 彌迦書 3:1; 耶利米書 13:18"> 「你要對猶大王室說：你們要聽耶和華的話語！</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 1:17; 箴言 31:8–9; 耶利米書 4:4"> 大衛家啊，耶和華如此說：<br /><span className="pl pl-1">你們要在每清晨秉公審斷，</span><br /><span className="pl pl-1">從欺壓者手中解救被搶奪的人，</span><br /><span className="pl pl-1">免得我的憤怒因你們的惡行而發作，</span><br /><span className="pl pl-1">如火燃起，無人撲滅。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 13:8; 耶利米哀歌 4:12; 俄巴底亞書 1:3–4"> <span className="pl pl-1">坐落在山谷之間和平原磐石上的城啊，</span><br /><span className="pl pl-1">看哪，我與你敵對！</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /><span className="pl pl-1">你們說：『誰能進攻我們，</span><br /><span className="pl pl-1">誰能闖入我們的住處呢？』</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 3:10–11; 耶利米書 32:19; 箴言 1:31"> <span className="pl pl-1">我必照著你們行為所結的果實懲罰你們，</span><br /><span className="pl pl-1">我要在耶路撒冷的林中點火，</span><br /><span className="pl pl-1">吞噬它四圍的一切。</span><br /><span className="pl pl-1">這是耶和華的宣告。」</span></span>
</div>

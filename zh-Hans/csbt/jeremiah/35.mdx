<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 23:35; 耶利米書 1:3; 耶利米書 25:1"> 約西亞的兒子猶大王約雅敬年間，有話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 2:55; 歷代志上 9:26; 列王紀上 6:5–6"> 「你要去見利甲家族的人，與他們說話，並把他們帶到耶和華殿的一個房間裡，讓他們喝酒。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 於是我帶來哈巴茲尼雅的孫子、耶利米雅的兒子雅撒尼亞，還有他的兄弟們和他所有的兒子，以及利甲整個家族，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 33:1; 列王紀下 12:9; 歷代志下 8:14"> 把他們帶進耶和華的殿，帶到伊基大利之子神人哈南兒子們的房間，就在首領們的房間旁邊，在沙勒姆的兒子門衛瑪西雅的房間上面。</span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 9:7; 阿摩司書 2:12; 哥林多後書 2:9"> 然後我在利甲家族的子孫面前擺上盛滿酒的酒壺和杯子，對他們說：「請喝酒吧。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 1:15; 歷代志上 2:55; 列王紀下 10:15"> 他們卻說：「我們不喝酒，因為我們先祖利甲的兒子約拿達曾吩咐我們說：『你們和你們的子孫永遠不可喝酒。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 35:10; 創世記 25:27; 尼希米記 8:14–16"> 你們也不可建造房屋，不可播種，不可栽種或擁有葡萄園；你們一生的日子都要住在帳篷中，好使你們在寄居的土地上長久存活。』</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:20; 箴言 4:10; 箴言 1:8–9"> 我們在先祖利甲的兒子約拿達所吩咐的一切事上，都聽從他的話，我們和我們的妻子、兒女一生的日子都不喝酒，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 6:6; 耶利米書 35:7; 詩篇 37:16"> 不建造房屋居住，我們也沒有葡萄園、田地和種子。</span>
<span className="v" id="v10" data-v="10"> 我們只住帳篷，聽從並遵行我們先祖約拿達所吩咐的一切。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:14; 耶利米書 4:5–7; 但以理書 1:1–2"> 巴比倫王尼布甲尼撒上來攻打這地的時候，我們說：『來吧！讓我們去耶路撒冷，躲避迦勒底人的軍隊和亞蘭人的軍隊。』這樣，我們才住進耶路撒冷。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 於是耶和華的話語臨到耶利米，說：</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 32:33; 耶利米書 5:3; 耶利米書 6:8–10"> 「以色列的神萬軍之耶和華如此說：你去對猶大人和耶路撒冷的居民說：你們怎麼不接受管教，不聽從我的話呢？這是耶和華的宣告。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 25:3–4; 耶利米書 7:24–26; 箴言 1:20–33"> 利甲的兒子約拿達吩咐他子孫不可喝酒的話語，他們都遵行了。他們直到今日也不喝酒，因為他們聽從先祖的誡命；而我不斷地對你們說話，你們卻不聽從我。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 18:11; 以西結書 18:30–32; 耶利米書 25:5–6"> 我派遣我的僕人眾先知到你們那裡去，不斷地派遣，說：『現在你們各人要轉離自己邪惡的道路，改正自己的行為，不要跟從別的神去服事它們；這樣你們就必住在我賜給你們和你們祖先的土地上。』你們卻不側耳聽，不聽從我。</span>
<span className="v" id="v16" data-v="16" data-xref="瑪拉基書 1:6; 耶利米書 35:14; 路加福音 15:11–13"> 利甲之子約拿達的子孫遵行了先祖吩咐他們的誡命，但這子民卻不聽從我。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 66:4; 以賽亞書 65:12; 羅馬書 10:21"> 因此以色列的神萬軍之神耶和華如此說：看哪，我必使我對他們宣告的一切禍患臨到猶大和所有耶路撒冷的居民。因為我對他們宣告，他們不聽從；我呼喚他們，他們不回應。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16; 出埃及記 20:12; 以弗所書 6:1–3"> 耶利米對利甲家族的人說：「以色列的神萬軍之耶和華如此說：因為你們聽從你們先祖約拿達的誡命，遵守他的一切誡命，照著他所吩咐你們的一切去做，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 15:19; 路加福音 21:36; 耶利米書 33:17–18"> 所以，以色列的神萬軍之耶和華如此說：利甲的兒子約拿達必永不斷絕有人侍立在我面前。」</span>
</div>
</div>

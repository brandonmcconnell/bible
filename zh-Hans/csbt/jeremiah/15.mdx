<span className="v" id="v4" data-v="4" data-xref="耶利米書 24:9; 列王紀下 23:26–27; 列王紀下 24:3–4"> 因希西加的兒子猶大王瑪拿西在耶路撒冷所做的事，我要使他們令地上的萬國戰兢。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 51:19; 那鴻書 3:7; 耶利米書 21:7"> <span className="pl pl-1">「耶路撒冷啊，</span><br /><span className="pl pl-1">誰會憐恤你呢？</span><br /><span className="pl pl-1">誰會為你悲哀呢？</span><br /><span className="pl pl-1">誰會轉身向你問安呢？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:24; 西番雅書 1:4; 以賽亞書 1:4"> <span className="pl pl-1">你撇棄了我，向後退縮，</span><br /><span className="pl pl-1">所以我要伸手攻擊你，毀掉你，</span><br /><span className="pl pl-1">我已經厭倦向你施憐憫了。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 3:12; 耶利米書 51:2; 以賽亞書 41:16"> <span className="pl pl-1">我要在這地的各城門口</span><br /><span className="pl pl-1">用揚穀叉揚散他們；</span><br /><span className="pl pl-1">我要使他們喪掉兒女；</span><br /><span className="pl pl-1">我要消滅我的子民，</span><br /><span className="pl pl-1">因為他們不轉離自己的道路。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 3:25–1; 耶利米書 6:4–5; 路加福音 21:35"> <span className="pl pl-1">我要使他們的寡婦比海沙更多；</span><br /><span className="pl pl-1">我要使毀滅者</span><br /><span className="pl pl-1">在正午來打擊青年人的母親，</span><br /><span className="pl pl-1">使痛苦和惶恐突然臨到她。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 2:5; 以賽亞書 47:9; 耶利米哀歌 1:1"> <span className="pl pl-1">生過七個孩子的婦人衰敗氣絕了，</span><br /><span className="pl pl-1">還在白天的時候，</span><br /><span className="pl pl-1">她的太陽就已經落下，</span><br /><span className="pl pl-1">她必蒙羞、慚愧。</span><br /><span className="pl pl-1">我要在他們的仇敵面前，</span><br /><span className="pl pl-1">把他們的餘剩之民交給刀劍。</span><br /><span className="pl pl-1">這是耶和華的宣告。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="路加福音 6:22; 出埃及記 22:25; 箴言 26:2"> <span className="pl pl-1">我的母親哪，我有禍了！</span><br /><span className="pl pl-1">因為你生了我這個</span><br /><span className="pl pl-1">與全地爭辯、紛爭的人。</span><br /><span className="pl pl-1">我沒有借貸給人，</span><br /><span className="pl pl-1">人也沒有借貸給我，</span><br /><span className="pl pl-1">但人人都詛咒我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 16:7; 耶利米書 29:11–14; 詩篇 106:46"> 耶和華說：<br /><span className="pl pl-1">「我必定釋放你，恩待你。</span><br /><span className="pl pl-1">當災禍和患難臨到時，</span><br /><span className="pl pl-1">我必定使仇敵向你哀求。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 40:9; 耶利米書 21:4–5; 以賽亞書 45:9"> <span className="pl pl-1">難道人能折斷鐵——北方的鐵，</span><br /><span className="pl pl-1">或者打破銅嗎？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 17:3; 詩篇 44:12; 以賽亞書 52:3"> <span className="pl pl-1">因你們在全境的一切罪，</span><br /><span className="pl pl-1">我要把你們的財富和寶物</span><br /><span className="pl pl-1">無償地交出去為掠物。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 16:13; 申命記 32:22; 耶利米書 17:4"> <span className="pl pl-1">我還要使你們在不認識的地方</span><br /><span className="pl pl-1">服事你們的仇敵，</span><br /><span className="pl pl-1">因為烈火在我的怒氣中點燃，</span><br /><span className="pl pl-1">向你們燃起。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 12:3; 詩篇 69:7–9; 路加福音 21:17"> <span className="pl pl-1">耶和華啊，你是知道的！</span><br /><span className="pl pl-1">求你記念我，眷顧我，</span><br /><span className="pl pl-1">為我報復那些追逼我的人。</span><br /><span className="pl pl-1">求你不要容忍他們把我取走，</span><br /><span className="pl pl-1">要知道我為你而承受辱罵！</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 10:9–10; 以西結書 3:1–3; 詩篇 119:101–103"> <span className="pl pl-1">萬軍之神耶和華啊，</span><br /><span className="pl pl-1">我得到你的話語就吃了；</span><br /><span className="pl pl-1">你的話語成了我心中的歡喜和快樂，</span><br /><span className="pl pl-1">因為我是被稱為你名下的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 1:1; 耶利米哀歌 3:28; 詩篇 26:4–5"> <span className="pl pl-1">我沒有坐在歡笑者的聚會中，</span><br /><span className="pl pl-1">也沒有歡躍；</span><br /><span className="pl pl-1">我因你的手獨自坐著，</span><br /><span className="pl pl-1">因為你使我充滿了憤怒。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 30:15; 約伯記 34:6; 彌迦書 1:9"> <span className="pl pl-1">我的痛苦為什麼長久不停，</span><br /><span className="pl pl-1">我的創傷為什麼無法救治，</span><br /><span className="pl pl-1">不得痊癒？</span><br /><span className="pl pl-1">你對我實在像不可靠的溪流，</span><br /><span className="pl pl-1">不可信任的水流！</span></span>

<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 3:7; 路加福音 21:15; 利未記 10:10"> 因此，耶和華如此說：<br /><span className="pl pl-1">「如果你回心轉意，</span><br /><span className="pl pl-1">我就讓你回來，站在我面前；</span><br /><span className="pl pl-1">如果你離棄卑賤選擇尊貴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="離棄卑賤選擇尊貴——或譯作「分辨尊貴的和卑賤的」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你就可以作我的口。</span><br /><span className="pl pl-1">他們要轉向你，</span><br /><span className="pl pl-1">而不是你要轉向他們。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 1:18–19; 使徒行傳 18:9–10; 以西結書 3:9"> <span className="pl pl-1">我要使你對這子民成為堅固的銅牆；</span><br /><span className="pl pl-1">他們會攻擊你，卻不能勝過你，</span><br /><span className="pl pl-1">因為我與你同在，必拯救你，解救你。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 1:10; 以賽亞書 49:24–25; 耶利米書 50:34"> <span className="pl pl-1">我必解救你脫離惡人的手，</span><br /><span className="pl pl-1">救贖你脫離強橫者的手掌。」</span></span>

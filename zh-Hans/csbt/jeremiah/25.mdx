<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 36:1; 列王紀下 24:1–2; 但以理書 1:1"> 約西亞的兒子猶大王約雅敬四年，就是巴比倫王尼布甲尼撒元年，有話語臨到耶利米，論到猶大全體民眾。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 18:11; 耶利米書 19:14–15; 馬可福音 7:14–15"> 先知耶利米就把這話傳達給猶大全體民眾和耶路撒冷的所有居民，他說：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 11:7; 耶利米書 26:5; 耶利米書 1:2"> 從亞門的兒子猶大王約西亞十三年直到今日，這二十三年來，耶和華的話語常臨到我，我不斷地向你們傳達，你們卻不聽從。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 25:3; 耶利米書 26:5; 耶利米書 13:10–11"> 耶和華也派遣他的僕人眾先知到你們這裡來，不斷地派遣，你們卻不聽從，不側耳聽。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 7:7; 創世記 17:8; 以賽亞書 55:6–7"> 先知對你們說：「你們各人要轉離自己邪惡的道路，離開自己的惡行，好使你們安居在耶和華永永遠遠賜給你們和你們祖先的土地上。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:19; 耶利米書 7:6; 耶利米書 35:15"> 你們不可跟從別的神，服事它們，向它們下拜，不可用自己手所造的惹怒我，以免我向你們降下災禍。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 21:15; 箴言 8:36; 申命記 32:21"> 「然而你們不聽從我，竟然以自己手所造的惹怒我，自招災禍。這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 「因此萬軍之耶和華如此說：因為你們不聽從我的話，</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 13:3; 耶利米書 18:16; 耶利米書 1:15"> 看哪，我要派人去把北方的各族帶來，也派人到我的僕人巴比倫王尼布甲尼撒那裡去，把他們帶來攻擊這地，攻擊這地的居民以及四圍的所有國家。我要把這地和各國<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="這地和各國——原文直譯「它們」。">a</a></sup>滅絕淨盡，使它們令人驚駭、被嗤笑，成為永遠的廢墟。這是耶和華的宣告。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 7:34; 啟示錄 18:22–23; 以西結書 26:13"> 我要使歡樂和喜樂的聲音、新郎和新娘的聲音、推石磨的聲音和燈光，都從他們中間消失。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 9:2; 撒迦利亞書 1:12; 歷代志下 36:21–22"> 這全地都必成為廢墟，令人驚駭，這些國家必服事巴比倫王七十年。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 9:2; 以賽亞書 13:19; 耶利米書 29:10"> 七十年滿了以後，我要因巴比倫王和他的國家的罪孽懲罰他們，懲罰迦勒底人之地，使那地永遠荒涼。這是耶和華的宣告。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 1:10; 耶利米書 1:5; 但以理書 5:31"> 我要使我針對那地所說的一切話語，就是所有記在這書卷上、耶利米針對所有國家所預言的，都應驗在那地上。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 51:6; 耶利米書 27:7; 耶利米書 50:9"> 是的，甚至有許多國家和大君王奴役迦勒底人；我要照著他們的作為和他們手所做的，報應他們。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 75:8; 以賽亞書 51:17; 啟示錄 14:10"> 因此以色列的神耶和華對我如此說：「你要從我手中接過這杯烈怒的酒，給我所派遣你去的列國喝。</span>
<span className="v" id="v16" data-v="16" data-xref="那鴻書 3:11; 耶利米書 51:7; 耶利米書 51:39"> 他們喝了，就會踉蹌、發狂，因為我要派遣刀劍到他們中間。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 1:10; 耶利米書 25:28; 以西結書 43:3"> 我就從耶和華手中接過這杯酒，給耶和華派遣我去的以下各國喝：</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 24:9; 詩篇 60:3; 耶利米書 44:22"> 給耶路撒冷和猶大的城鎮，還有耶路撒冷的君王們和首領們，要使這些城鎮成為廢墟，令人驚駭、被嗤笑、被咒罵，就像今日這樣；</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 46:13–26; 那鴻書 3:8–10; 耶利米書 46:2"> 給埃及王法老和他的臣僕們、首領們，以及他所有的子民；</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:1; 以西結書 30:5; 以賽亞書 20:1"> 給所有混雜的族群，烏斯地所有的王，非利士人之地所有的王，阿實基倫人，加沙人，以革倫人，阿實突的餘剩之民；</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 48:1–22; 詩篇 137:7; 耶利米書 9:26"> 給以東，摩押，亞捫人，</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 47:4; 阿摩司書 1:9–10; 以西結書 28:22–23"> 提爾所有的王，西頓所有的王，海對岸沿海的列王，</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 9:26; 耶利米書 49:32; 耶利米書 49:8"> 底但，提瑪，布斯，所有剃掉額角的人，</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="歷代志下 9:14; 耶利米書 25:20; 以西結書 30:5"> 阿拉伯所有的王，所有居住在曠野的混雜族群的王，</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:11; 創世記 10:22; 以賽亞書 13:17"> 心利所有的王，以攔所有的王，米底亞所有的王；</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米書 51:41; 耶利米書 25:9; 耶利米書 50:1–46"> 給北方遠近各處所有的王，一個接一個；也給地上的萬國；他們喝了以後，示沙克王也要喝。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 25:16; 哈巴谷書 2:16; 以西結書 21:4–5"> 「你要對他們說：『以色列的神萬軍之耶和華如此說：你們喝！喝醉吧，吐出來吧，仆倒吧，必不再起來！因為我要派遣刀劍到你們中間。』</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 34:33; 耶利米書 51:29; 以賽亞書 14:24–27"> 如果他們不肯從你手中接過這杯來喝，你就對他們說：『萬軍之耶和華如此說：你們一定要喝！</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 38:21; 箴言 11:31; 彼得前書 4:17"> 看哪，我就要開始降災禍給這被稱為我名下的城了。你們能免於罪罰嗎？你們絕不能免於罪罰，因為我就要召喚刀劍對付地上所有的居民了。』這是萬軍之耶和華的宣告。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="阿摩司書 1:2; 約珥書 3:16; 以賽亞書 42:13"> 「你要向他們預言這一切話語，對他們說：<br /><span className="pl pl-1">耶和華從至高處吼叫，</span><br /><span className="pl pl-1">從他神聖的居所發聲，</span><br /><span className="pl pl-1">向自己的牧場大聲吼叫；</span><br /><span className="pl pl-1">他對地上所有的居民發出呼喊，</span><br /><span className="pl pl-1">像踹酒的人那樣呼喊。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="何西阿書 4:1; 約珥書 3:2; 以賽亞書 66:16"> <span className="pl pl-1">喧嚷達到了地極，</span><br /><span className="pl pl-1">因為耶和華與列國有爭訟。</span><br /><span className="pl pl-1">他必審判一切有血肉的；</span><br /><span className="pl pl-1">至於惡人，他必把他們交給刀劍。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="耶利米書 23:19; 以賽亞書 34:2; 歷代志下 15:6"> 萬軍之耶和華如此說：<br /><span className="pl pl-1">看哪，災禍就要發出，</span><br /><span className="pl pl-1">從這國來到那國！</span><br /><span className="pl pl-1">大風暴就要從地極颳起！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 66:16; 耶利米書 8:2; 詩篇 79:3"> 「到那日，從地這邊到地那邊都有被耶和華所殺的人，無人哀哭，不被收殮，不被埋葬，必成為地面上的糞土。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 6:26; 耶利米書 50:27; 詩篇 2:9"> <span className="pl pl-1">牧人們哪，哀號呼叫吧！</span><br /><span className="pl pl-1">羊群的帶領者啊，在灰中打滾吧！</span><br /><span className="pl pl-1">因為你們被宰殺、被分散的日子到了，</span><br /><span className="pl pl-1">你們必像寶器那樣跌碎。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 11:20; 阿摩司書 2:14; 耶利米書 52:8–11"> <span className="pl pl-1">牧人們無處逃難，</span><br /><span className="pl pl-1">羊群的帶領者無處逃脫。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 4:8; 耶利米書 25:34"> <span className="pl pl-1">聽啊，牧人們哀呼，</span><br /><span className="pl pl-1">羊群的帶領者哀號！</span><br /><span className="pl pl-1">耶和華正在毀滅他們的牧場。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 27:10–11; 以賽亞書 32:14"> <span className="pl pl-1">因耶和華猛烈的怒氣，</span><br /><span className="pl pl-1">平安的牧場靜寂無聲。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 4:7; 耶利米書 5:6; 何西阿書 13:7–8"> <span className="pl pl-1">耶和華離開了這地，</span><br /><span className="pl pl-1">像少壯獅子離開牠的洞穴。</span><br /><span className="pl pl-1">因欺壓者的烈怒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="烈怒——有古抄本作「刀劍」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">也因耶和華猛烈的怒氣，</span><br /><span className="pl pl-1">他們的土地必成為荒場。」</span></span>
</div>

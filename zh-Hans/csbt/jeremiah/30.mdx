<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 26:15; 耶利米書 1:1–2"> 有話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 36:32; 以賽亞書 30:8; 哈巴谷書 2:2–3"> 「以色列的神耶和華如此說：你要把我對你說的一切話語都記在書卷上。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:14; 耶利米書 16:15; 耶利米書 30:18"> 看哪，這是耶和華的宣告：日子將到，我要使我流亡的子民以色列和猶大回歸。耶和華說：我要使他們回歸我賜給他們祖先的土地，他們必擁有這地。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4"> 以下是耶和華論到以色列和猶大所說的話語，</span>
<span className="v" id="v5" data-v="5" data-xref="西番雅書 1:10–11; 阿摩司書 8:10; 以賽亞書 5:30"> 耶和華如此說：<br /><span className="pl pl-1">你們</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——依據七十士譯本；馬索拉文本作「我們」。">a</a></sup><br /><span className="pl pl-1">聽見戰兢的聲音，</span><br /><span className="pl pl-1">令人恐懼，沒有平安。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鴻書 2:10; 約珥書 2:6; 耶利米書 4:31"> <span className="pl pl-1">請你們問問、看看，</span><br /><span className="pl pl-1">男人會生孩子嗎？</span><br /><span className="pl pl-1">我怎麼看見他們人人雙手扶腰，</span><br /><span className="pl pl-1">像臨產的婦人那樣，</span><br /><span className="pl pl-1">個個臉色變得蒼白呢？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 12:1; 撒迦利亞書 14:1–2; 瑪拉基書 4:1"> <span className="pl pl-1">禍哉！那日子極大，無日可比；</span><br /><span className="pl pl-1">這是雅各遭患難的時候，</span><br /><span className="pl pl-1">但他必得救脫離患難。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="那鴻書 1:13; 以西結書 34:27; 以賽亞書 9:4"> 萬軍之耶和華宣告：到那日，我必從他們的頸項上打斷仇敵的軛，拉斷他們身上的繩索；外邦人必不再奴役他們。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 3:5; 以賽亞書 55:3–5; 路加福音 1:69"> 他們必服事他們的神耶和華，服事我為他們興起的大衛王。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 46:27–28; 以賽亞書 43:5; 耶利米書 29:14"> <span className="pl pl-1">耶和華宣告：</span><br /><span className="pl pl-1">我的僕人雅各啊，你不要害怕！</span><br /><span className="pl pl-1">以色列啊，你不要喪膽！</span><br /><span className="pl pl-1">看哪，我必從遠方拯救你，</span><br /><span className="pl pl-1">從流亡之地拯救你的後裔。</span><br /><span className="pl pl-1">雅各必回歸，</span><br /><span className="pl pl-1">得享平靜安逸，無人驚嚇；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 10:24; 耶利米書 1:19; 以賽亞書 8:10"> <span className="pl pl-1">因為我與你同在，必拯救你。</span><br /><span className="pl pl-1">儘管我要滅絕我所驅散你到的列國，</span><br /><span className="pl pl-1">我卻不會對你施行滅絕。</span><br /><span className="pl pl-1">然而我要以公正管教你，</span><br /><span className="pl pl-1">絕不會讓你免於罪罰。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 15:18; 耶利米書 30:15; 耶利米書 14:17"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">你的創傷無法救治，</span><br /><span className="pl pl-1">你的傷勢嚴重。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 46:11; 耶利米書 8:22; 耶利米書 30:17"> <span className="pl pl-1">沒有人為你的爭訟伸冤，</span><br /><span className="pl pl-1">你的創傷無藥可救，不得痊癒。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 5:6; 約伯記 30:21; 耶利米哀歌 1:2"> <span className="pl pl-1">你所親愛的都忘記了你，不顧念你；</span><br /><span className="pl pl-1">我以仇敵的擊打，</span><br /><span className="pl pl-1">以殘忍者的管教來擊打你，</span><br /><span className="pl pl-1">因為你的罪孽極大，</span><br /><span className="pl pl-1">你的罪惡眾多。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 30:14; 耶利米書 30:12; 耶利米書 6:6–7"> <span className="pl pl-1">你為什麼因你的創傷哀求呢？</span><br /><span className="pl pl-1">你的痛苦無法救治。</span><br /><span className="pl pl-1">因為你的罪孽極大，</span><br /><span className="pl pl-1">你的罪惡眾多，</span><br /><span className="pl pl-1">我才這樣對待了你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 10:25; 以賽亞書 33:1; 出埃及記 23:22"> <span className="pl pl-1">雖然如此，</span><br /><span className="pl pl-1">所有吞吃你的都將被吞吃，</span><br /><span className="pl pl-1">你所有的敵人都將被擄去；</span><br /><span className="pl pl-1">搶掠你的必成為擄物，</span><br /><span className="pl pl-1">凡掠奪你的，我必使他成為掠物。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:20; 耶利米書 33:6; 彼得前書 2:24"> <span className="pl pl-1">我必使你康復，使你的傷痊癒，</span><br /><span className="pl pl-1">因為他們稱你為被流放者，說：</span><br /><span className="pl pl-1">「這就是錫安，沒有人顧念她！」</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="哈該書 2:7–9; 詩篇 102:13; 耶利米書 30:3"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">看哪，我必使流亡的雅各家回歸</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="使流亡的雅各家回歸——或譯作「復興雅各的家業」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">也必憐憫他的居所。</span><br /><span className="pl pl-1">城鎮必在廢堆上重建，</span><br /><span className="pl pl-1">城堡必在原處屹立；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 33:22; 以賽亞書 51:11; 以賽亞書 60:22"> <span className="pl pl-1">必有感謝和歡笑的聲音從其中發出。</span><br /><span className="pl pl-1">我要使他們增多，不致減少；</span><br /><span className="pl pl-1">使他們得尊榮，不致卑微。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 32:39; 耶利米書 2:3; 耶利米書 50:33–34"> <span className="pl pl-1">他們的兒女必像從前那樣，</span><br /><span className="pl pl-1">他們的會眾必在我面前堅立；</span><br /><span className="pl pl-1">我必懲罰一切壓迫他們的人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:5; 以西結書 34:23–24; 使徒行傳 5:31"> <span className="pl pl-1">他們的首領是他們自己的人，</span><br /><span className="pl pl-1">他們的管轄者出自他們中間；</span><br /><span className="pl pl-1">我要使他靠近，讓他接近我，</span><br /><span className="pl pl-1">否則誰敢冒生命危險</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="冒生命危險——原文直譯「抵押自己的心」。">c</a></sup><br /><span className="pl pl-1">接近我呢？</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 21:3; 以西結書 36:28; 耶利米書 31:33"> <span className="pl pl-1">你們要作我的子民，</span><br /><span className="pl pl-1">我要作你們的神。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:19–20; 撒迦利亞書 9:14; 耶利米書 25:32"> <span className="pl pl-1">看哪，耶和華的狂風！</span><br /><span className="pl pl-1">他的怒火發出，是掃蕩的狂風，</span><br /><span className="pl pl-1">必在惡人的頭上旋轉！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 23:20; 何西阿書 3:5; 彌迦書 4:1"> <span className="pl pl-1">耶和華猛烈的怒氣不會轉消，</span><br /><span className="pl pl-1">直到他實行、成就心中的計劃。</span><br /><span className="pl pl-1">在末後的日子，</span><br /><span className="pl pl-1">你們必明白這事。</span></span>

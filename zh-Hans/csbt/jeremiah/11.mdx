<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 有話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 11:6; 出埃及記 19:5; 歷代志下 29:10"> 「你要聽這約的話語，並把它們告訴猶大人和耶路撒冷的居民。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 27:26; 申命記 28:15–68; 申命記 29:19–20"> 你要對他們說，以色列的神耶和華如此說：不聽從這約上話語的人，是受詛咒的！</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:12; 耶利米書 7:22–23; 申命記 4:20"> 這約是我與你們祖先立定的，在我從埃及地、從那鐵的熔爐中領出他們的日子，我說：『你們要聽從我的話，遵行我所吩咐你們的一切。這樣，你們就作我的子民，我也作你們的神。』</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:12–13; 詩篇 105:9–11; 耶利米書 28:6"> 這是為要確立我向你們祖先所起的誓，把流奶與蜜之地賜給他們，就像今日這樣。」<br />我就回應說：「耶和華啊，阿們！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:22; 羅馬書 2:13; 耶利米書 7:2"> 耶和華對我說：「你要在猶大的各城中和耶路撒冷的街道上宣告這一切話語，說：你們要聽從這約的話語，遵行它們。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 36:15; 以弗所書 4:17; 撒母耳記上 8:9"> 自從我把你們的祖先從埃及地帶上來的日子，直到今日，我都嚴厲地告誡他們，不斷地警誡說：要聽從我的話！</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 7:24; 耶利米書 7:26; 耶利米書 35:15"> 他們卻不聽從，不側耳聽，各人隨從自己頑固敗壞的心行事。因此我使這約上一切詛咒的話語都應驗在他們身上，這約是我吩咐他們要遵行的，他們卻沒有遵行。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿書 6:9; 馬太福音 26:3–4; 彌迦書 3:11"> 耶和華對我說：「在猶大人和耶路撒冷的居民中有叛逆的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 31:16; 以西結書 16:59; 詩篇 78:8–10"> 他們重複他們祖先的罪孽，不肯聽從我的話，也去跟從服事別的神。以色列家和猶大家違背了我與他們祖先所立的約。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:18; 箴言 1:28; 以賽亞書 1:15"> 因此耶和華如此說：「看哪，我必使禍患臨到他們，他們絕不能逃脫；即使他們向我哀求，我也不會垂聽他們。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:28; 申命記 32:37; 歷代志下 28:22"> 那時猶大的各城和耶路撒冷的居民必去哀求他們燒香所供奉的神明，但在禍患臨到他們的時候，那些神明絕不能拯救他們。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:28; 列王紀下 23:13; 以賽亞書 2:8"> 猶大啊，你的神明與你城鎮的數目一樣多；你為可恥的偶像立的祭壇，就是向眾巴力燒香的祭壇，與耶路撒冷街道的數目一樣多！</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 7:16; 耶利米書 11:11; 約翰一書 5:16"> 「至於你，不要為這子民祈禱，也不要為他們揚聲呼求或禱告；他們遭禍患向我呼求的時候，我必不垂聽。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多書 1:15; 耶利米書 3:1–2"> <span className="pl pl-1">我所愛的人行了許多詭計，</span><br /><span className="pl pl-1">還有什麼資格在我的殿宇中呢？</span><br /><span className="pl pl-1">難道神聖的肉能使你脫離禍患，</span><br /><span className="pl pl-1">使你歡躍嗎？</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:17–24; 以賽亞書 27:11; 詩篇 52:8"> <span className="pl pl-1">耶和華曾給你起名為</span><br /><span className="pl pl-1">『佳美、多結果實的青翠橄欖樹』，</span><br /><span className="pl pl-1">但他必在極大的轟隆聲中點火焚燒這樹，</span><br /><span className="pl pl-1">樹枝都將被燒毀。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 5:2; 耶利米書 2:21; 耶利米書 12:2"> 「那栽種你的萬軍之耶和華已經對你宣告禍患，因為以色列家和猶大家作惡，他們向巴力燒香，惹我惱怒。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 23:11–12; 列王紀下 6:9–10; 以西結書 8:6–18"> <span className="pl pl-1">耶和華指示我，我就知道；</span><br /><span className="pl pl-1">那時你把他們的行為向我顯明了。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 53:7–8; 耶利米書 20:10; 詩篇 83:4"> <span className="pl pl-1">我就像溫順的羊羔被牽去宰殺，</span><br /><span className="pl pl-1">並不知道他們謀劃計策害我；</span><br /><span className="pl pl-1">他們說：</span><br /><span className="pl pl-1">「讓我們把樹連果子都毀掉吧，</span><br /><span className="pl pl-1">把他從活人之地剪除，</span><br /><span className="pl pl-1">使他的名不再被記念！」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 20:12; 耶利米書 17:10; 撒母耳記上 16:7"> <span className="pl pl-1">萬軍之耶和華啊，</span><br /><span className="pl pl-1">你是按公義施行審判、</span><br /><span className="pl pl-1">察驗肺腑心腸的，</span><br /><span className="pl pl-1">求你讓我看見你在他們身上報仇！</span><br /><span className="pl pl-1">我已經向你陳明了我的案件。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 20:10; 阿摩司書 2:12; 路加福音 13:33–34"> 因此耶和華如此論到那些亞納圖人：「他們尋索你的性命說：『你不要奉耶和華的名說預言，以免死在我們手中』，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 18:21; 歷代志下 36:17; 耶利米書 9:21"> 所以萬軍之耶和華如此說：看哪，我必懲罰他們！他們的青年人必死在刀下，他們的兒女必死在饑荒中。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:12; 彌迦書 7:4; 何西阿書 9:7"> 他們不會有餘剩之民，因為我要在他們受懲罰之年，使禍患臨到亞納圖人。」</span>
</div>

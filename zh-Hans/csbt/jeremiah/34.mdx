<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 1:15; 但以理書 2:37–38; 列王紀下 25:1–9"> 巴比倫王尼布甲尼撒和他的全軍，以及他所統治的地上各國各族，攻打耶路撒冷和所有附屬的城鎮，那時有話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 21:10; 耶利米書 34:22; 耶利米書 37:8–10"> 「以色列的神耶和華如此說：你去告訴猶大王西底加說，耶和華如此說：看哪，我要把這城交在巴比倫王手中，他必放火燒毀這城。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 32:4; 耶利米書 21:7; 列王紀下 25:4–7"> 你絕不會從他手中逃脫，一定會被抓住，交在他手中。你必與巴比倫王眼對眼相看，面對面說話；你必到巴比倫去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 「然而，猶大王西底加啊，你要聽耶和華的話語！論到你，耶和華如此說：你必不會死在刀下，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 22:18; 歷代志下 16:14; 列王紀下 22:20"> 而會平安死去。人們怎樣為你的祖先，就是為你之前的君王們焚燒香料，也必怎樣為你焚燒香料，並且為你哀哭說：『哀哉，我主啊！』是的，我說了這話。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 15:16–24; 撒母耳記上 3:18; 列王紀上 21:19"> 於是先知耶利米在耶路撒冷把這一切話語都告訴了猶大王西底加。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 10:3; 耶利米書 4:5; 列王紀下 18:13–14"> 那時巴比倫王的軍隊正攻打耶路撒冷和猶大剩下的城鎮，就是拉吉和亞西加，因為在猶大的城鎮中，只剩下這兩座堡壘城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 25:10; 列王紀下 23:2–3; 列王紀下 11:17"> 有話語從耶和華臨到耶利米。此前西底加王與耶路撒冷的全體民眾立約，向僕婢宣告自由：</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 15:12; 利未記 25:39–46; 出埃及記 3:18"> 各人要釋放自己的希伯來男僕和婢女，誰也不可奴役他的兄弟猶大人。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 26:16; 耶利米書 26:10; 耶利米書 38:4"> 所有立約的首領和全體民眾都聽從，各人釋放了自己的男僕和婢女，不再奴役他們。他們都聽從，把僕婢釋放了，</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 2:20–22; 箴言 26:11; 馬太福音 12:43–45"> 後來卻反悔，把釋放的那些男僕和婢女帶回來，強迫他們再作僕婢。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 於是耶和華的話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 6:8; 約書亞記 24:17; 申命記 5:27"> 「以色列的神耶和華如此說：我把你們祖先從埃及地、從為奴之家領出來的日子裡，曾與他們立約說：</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 15:12; 列王紀上 9:22; 列王紀下 17:13–14"> 『每七年的最後一年，你們各人要釋放那被賣給你、服事了你六年的希伯來兄弟，要釋放他，讓他離開你得自由。』你們的祖先卻不聽從我，不側耳聽。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 34:8; 列王紀下 23:3; 尼希米記 10:29"> 如今你們回轉了，做我眼中看為正的事，各人向自己的鄰人宣告自由，並且在這被稱為我名下的殿宇裡，在我面前立了約；</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 19:12; 出埃及記 20:7; 耶利米書 34:11"> 你們卻又反悔，褻瀆了我的名，各人把那些得釋放隨心自由離去的男僕和婢女帶回來，強迫他們再作你們的僕婢。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 7:2; 申命記 28:25; 加拉太書 6:7"> 「因此耶和華如此說：既然你們不聽從我，各人不向自己的兄弟和鄰舍宣告自由；看哪，我必向你們宣告自由，讓你們遭遇刀劍、瘟疫和饑荒，使你們令地上的萬國戰兢。這是耶和華的宣告。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 15:10; 創世記 15:17–18; 何西阿書 6:7"> 那些違背我的約，不遵行在我面前所立的誓約的人，我必使他們遭報，如同他們所劈成兩半，並從兩半之間經過的牛犢。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 34:10; 西番雅書 3:3–4; 但以理書 9:6"> 猶大的首領、耶路撒冷的首領、內臣和祭司，以及這地的全體民眾，就是那些從牛犢兩半之間經過的人，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 7:33; 耶利米書 16:4; 耶利米書 19:7"> 我要把他們交在他們仇敵手中和尋索他們性命的人手中，他們的屍體必給天空的飛鳥和地上的走獸作食物。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 52:24–27; 耶利米書 39:6; 耶利米書 52:10"> 我也要把猶大王西底加和他的首領們交在他們仇敵手中和尋索他們性命的人手中，以及那些從你們面前撤離的巴比倫王軍隊手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 9:11; 耶利米書 39:8; 耶利米書 39:1–2"> 看哪，我要下令，使巴比倫王的軍隊回到這城，攻打它，攻取它，放火燒毀。我要使猶大的各城變得荒涼，無人居住。這是耶和華的宣告。」</span>
</div>

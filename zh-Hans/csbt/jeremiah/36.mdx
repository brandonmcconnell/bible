<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 25:1; 歷代志下 36:5; 耶利米書 45:1"> 約西亞的兒子猶大王約雅敬四年，有這話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 30:2; 耶利米書 25:3; 耶利米書 1:10"> 「你拿一個書卷，記下來我對你所說有關以色列和猶大以及列國的一切話語，就是從約西亞年間我對你說話的日子直到今日，我對你說過的一切話語。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 18:8; 使徒行傳 3:19; 耶利米書 26:3"> 或許猶大家聽到我計劃要降給他們的一切災禍，各人就會轉離自己邪惡的道路，我就赦免他們的罪孽和罪惡。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:12; 耶利米書 36:32; 以西結書 2:9"> 於是耶利米召來尼利亞的兒子巴錄克，巴錄克就照耶利米的口述，把耶和華對耶利米說的一切話語都記在書卷上。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:2; 耶利米書 33:1; 哥林多後書 11:23"> 然後耶利米吩咐巴錄克說：「我被拘禁，不能進入耶和華的殿。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 36:8–9; 耶利米書 26:2; 耶利米書 22:2"> 所以你要去，在禁食的日子，在耶和華殿中，把你照我的口述記在書卷上耶和華的話語，宣讀給民眾聽，也宣讀給所有從本城來的猶大人聽。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 36:3; 耶利米書 21:5; 歷代志下 33:12–13"> 或許他們的懇求會達到耶和華面前，各人會轉離自己邪惡的道路，因為耶和華向這子民宣告的怒氣和怒火是極大的。」</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 1:17; 哥林多前書 16:10; 路加福音 4:16–30"> 尼利亞的兒子巴錄克就照著先知耶利米吩咐他的一切去做，在耶和華殿中宣讀那書卷上耶和華的話語。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志下 20:3; 約拿書 3:5; 以斯帖記 4:16"> 約西亞的兒子猶大王約雅敬五年九月，所有在耶路撒冷的民眾和所有從猶大各城來到耶路撒冷的民眾，都在耶和華面前宣告禁食。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:11; 耶利米書 26:10; 耶利米書 52:25"> 巴錄克就在耶和華殿中，就是耶和華殿的新門入口處，在上院裡書記沙番的兒子基瑪利雅的房間，把那書卷上耶利米的話語宣讀給全體民眾聽。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 36:10; 歷代志下 34:20; 列王紀下 25:22"> 沙番之子基瑪利雅的兒子米該亞，聽見那書卷上耶和華的一切話語，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 26:22; 列王紀下 22:12; 耶利米書 36:25"> 就下到王宮，進入書記室。看哪，眾首領都坐在那裡，其中有書記以利沙瑪，示瑪雅的兒子德拉雅，亞革波的兒子以利拿單，沙番的兒子基瑪利雅，哈納尼雅的兒子西底加，以及其餘的首領。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 22:10; 歷代志下 34:24; 歷代志下 34:16–18"> 米該亞把一切話語，就是他在巴錄克宣讀書卷給民眾聽的時候所聽見的，都告訴了他們。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 36:2; 耶利米書 41:18; 耶利米書 41:1–2"> 於是眾首領派遣猶底，就是尼坦亞的兒子、示勒米雅的孫子、庫希的曾孫，去見巴錄克說：「請你手裡拿上宣讀給民眾聽的書卷，到這裡來。」尼利亞的兒子巴錄克就手裡拿上那書卷，到他們那裡去。</span>
<span className="v" id="v15" data-v="15"> 他們對他說：「請你坐下，宣讀給我們聽吧。」巴錄克就宣讀給他們聽。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 13:18; 耶利米書 36:24; 阿摩司書 7:10–11"> 他們聽見這一切話語就懼怕，彼此相望。他們對巴錄克說：「我們必須把這一切話報告給王。」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 9:15; 約翰福音 9:10–11; 約翰福音 9:26–27"> 他們又問巴錄克說：「請告訴我們，你是怎麼記下這一切話語的？是照耶利米的口述嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 36:4; 耶利米書 36:2; 箴言 26:4–5"> 巴錄克對他們說：「他向我口述了這一切話語，我用墨水記在這書卷上。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀上 17:3; 列王紀上 18:10; 耶利米書 26:20–24"> 首領們就對巴錄克說：「你和耶利米去躲藏起來吧，不要讓人知道你們在哪裡。」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 36:12; 耶利米書 36:21"> 然後他們進到院子去見王，而把書卷存放在書記以利沙瑪的房間裡；他們把一切話語都報告給王聽。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 22:10; 歷代志下 34:18; 以西結書 2:4–5"> 王派遣猶底去取那書卷，猶底就從書記以利沙瑪的房間裡把書卷取來，宣讀給王和侍立於王旁邊的所有首領聽。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司書 3:15; 耶利米書 22:14–16; 耶利米書 36:9"> 那時正是九月，王坐在過冬的房屋裡，在他面前有燃燒著的火盆。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:8; 箴言 21:30; 列王紀上 22:27"> 每當猶底宣讀了三、四段，王就用書記的小刀把書卷割下，扔到火盆中的火裡，直到整個書卷都在火盆中的火裡燒盡了。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 36:16; 詩篇 36:1; 約拿書 3:6"> 王和所有聽見這一切話語的臣僕都不懼怕，也不撕裂衣服；</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:22; 耶利米書 36:12; 使徒行傳 5:34–39"> 甚至以利拿單、德拉雅和基瑪利雅哀求王不要燒掉那書卷，王也不聽他們。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 17:3; 列王紀上 19:1–3; 列王紀上 19:14"> 王又吩咐王子耶拉米列，以及亞斯列的兒子西萊雅和亞伯疊的兒子示勒米雅，去捉拿書記巴錄克和先知耶利米，但耶和華隱藏了他們。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 36:4"> 王燒掉那書卷，燒掉巴錄克照耶利米口述所記下的話語之後，耶和華的話語臨到耶利米，說：</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亞書 1:5–6; 約伯記 23:13; 耶利米書 44:28"> 「你再另外拿一個書卷，把猶大王約雅敬燒掉的前一書卷上先前的話語全都記在上面。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 30:10; 耶利米書 26:9; 申命記 29:19"> 你要論到猶大王約雅敬說，耶和華如此說：你燒掉這書卷，說：『你為什麼在它上面記著說，巴比倫王一定會來，毀滅這地，使人和牲畜從其上斷絕呢？』</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 22:30; 列王紀下 24:12–15; 創世記 31:40"> 因此論到猶大王約雅敬，耶和華如此說：他必不會有後裔坐在大衛的寶座上，他的屍體必被拋棄，經受白天的炎熱、夜間的寒霜。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; 耶利米書 19:15; 耶利米書 35:17"> 我要因他和他後裔並他臣僕們的罪孽懲罰他們，我要使我所宣告的一切禍患臨到他們，臨到耶路撒冷的居民和猶大人；我對他們宣告了，他們卻不聽！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米書 36:4; 耶利米書 36:18; 出埃及記 4:15–16"> 於是耶利米另外拿了一個書卷，交給尼利亞的兒子書記巴錄克，巴錄克就照耶利米的口述，把猶大王約雅敬在火中所燒掉書卷上的一切話語都記在上面，這次還增添了許多類似的話語。</span>
</div>
</div>

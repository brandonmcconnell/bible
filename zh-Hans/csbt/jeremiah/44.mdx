<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 46:14; 以賽亞書 11:11; 出埃及記 14:2"> 論到所有住在埃及地，就是住在密奪、塔帕尼斯、挪弗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="挪弗——希臘語音譯為「孟菲斯」。">a</a></sup>和巴特羅地的猶大人，有話語臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 6:11; 耶利米書 9:11; 耶利米書 34:22"> 「以色列的神萬軍之耶和華如此說：你們看見了我降在耶路撒冷和猶大各城鎮的一切災禍。看哪，今日它們成為廢墟，無人住在其中！</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:26; 申命記 13:6; 申命記 32:17"> 這是因為他們作惡惹怒我，他們去燒香，服事別的神，就是他們和你們以及你們祖先都不認識的神明。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 26:5; 耶利米書 7:25; 耶利米書 7:13"> 我派遣我的僕人眾先知到你們那裡去，不斷地派遣，說：『切不可行我所恨惡的這可憎之事！』</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 11:10; 耶利米書 19:13; 歷代志下 36:16"> 他們卻不聽從，不側耳聽，不轉離他們的惡行，仍向別的神燒香。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:20; 耶利米書 21:5; 以賽亞書 51:17"> 因此我的怒火和怒氣傾瀉而出，在猶大各城中和耶路撒冷的街道上燃燒，以致它們成為廢墟和荒場，就像今日這樣。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷書 2:10; 耶利米書 51:22; 以西結書 33:11"> 「現在，以色列的神萬軍之神耶和華如此說：你們為什麼做極大的惡事自害己命，使你們男人、女人、幼童和嬰兒從猶大被剪除，使你們一個餘剩之民也不留下呢？</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 42:18; 耶利米書 25:6–7; 耶利米書 44:3"> 為什麼用你們手所造的惹怒我，在你們去寄居的埃及地向別的神燒香，以致你們被剪除，在地上萬國中被咒罵、被羞辱？</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:17–18; 約書亞記 22:17–20; 耶利米書 44:15–19"> 你們祖先的惡行，猶大列王的惡行和他們妻子的惡行，你們的惡行和你們妻子的惡行，就是在猶大地和耶路撒冷街道上所做的，你們都忘記了嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:14; 彼得前書 5:6; 啟示錄 15:4"> 直到今日，你們還沒有痛悔，沒有畏懼，沒有遵行我在你們和你們祖先面前設立的律法和律例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 21:10; 利未記 26:17; 利未記 20:5–6"> 「因此以色列的神萬軍之耶和華如此說：看哪，我決意要向你們降災禍，剪除全體猶大人。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 42:15–18; 耶利米書 42:22; 以賽亞書 65:15"> 我要除掉那些執意去埃及地寄居的猶大餘剩之民，他們必全都滅盡。他們必仆倒在埃及地，因刀劍和饑荒而滅盡，無論尊卑，都死於刀劍和饑荒；他們將被辱罵、令人驚駭、被咒罵、被羞辱。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 11:22; 耶利米書 43:11; 耶利米書 44:27–28"> 我要用刀劍、饑荒和瘟疫懲罰那些住在埃及地的人，就像我懲罰耶路撒冷那樣。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 9:27; 耶利米書 22:26–27; 耶利米書 42:17"> 那些去寄居在埃及地的猶大餘剩之民，沒有一個逃脫者或倖存者，沒有人能回到他們心裡盼望回去居住的猶大地；除了一些逃脫者之外，沒有人能回去。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 11:21; 耶利米書 5:1–5; 創世記 19:4"> 那些知道妻子向別的神燒香的男人，以及所有站在那裡的女人，這一大群人，包括住在埃及地巴特羅的全體民眾，他們回應耶利米，說：</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 21:14–15; 路加福音 19:27; 耶利米書 16:15–17"> 「你奉耶和華之名對我們所說的話，我們不會聽從。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 7:18; 尼希米記 9:34; 耶利米書 44:21"> 我們一定照著我們口中所出的一切話去做，向天后燒香，向她澆奠酒祭，就像我們和我們的祖先、君王、首領，在猶大各城中和耶路撒冷街道上所做的那樣。那時我們得以飽食，得享福樂，不見災禍；</span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 3:13–15; 民數記 11:5–6; 約伯記 21:14–15"> 但自從我們停止向天后燒香，停止向她澆奠酒祭以來，我們卻樣樣缺少，又因刀劍和饑荒而滅盡。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 7:18; 耶利米書 44:15; 列王紀上 21:25"> 女人們也說：「我們向天后燒香，向她澆奠酒祭，照著天后的形像做祭餅供奉她，向她澆奠酒祭，難道沒有經過我們的丈夫同意嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶利米就告訴全體民眾，對男人和女人，以及所有用這話回應他的民眾，說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 44:17; 耶利米書 44:9; 耶利米書 11:13"> 「你們和你們的祖先、君王、首領，以及那地的民眾，在猶大各城中和耶路撒冷街道上所燒的香，耶和華不是都記得，在他心裡想起來了嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 25:18; 以賽亞書 7:13; 瑪拉基書 2:17"> 耶和華不能再忍受你們的惡行、你們所行的那些可憎之事，因此你們的土地成為廢墟，令人驚駭、被咒罵，無人居住，就像今日這樣。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 9:9; 但以理書 9:11–12; 尼希米記 13:18"> 因為你們燒香，對耶和華犯罪，不聽從耶和華的話語，也不遵行他的律法、律例和法度，所以這禍患臨到了你們，就像今日這樣。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 43:7; 耶利米書 44:15–16; 耶利米書 42:15"> 耶利米又對全體民眾和所有的女人說：「所有在埃及地的猶大人哪，你們要聽耶和華的話語！</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 14:9; 使徒行傳 23:12–15; 以賽亞書 28:15"> 以色列的神萬軍之耶和華如此說：你們和你們的妻子親口說過、親手做成了，你們說：『我們一定要還我們所許的願，向天后燒香，向她澆奠酒祭。』你們儘管守你們的願，儘管還你們的願吧！</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="詩篇 50:16; 以西結書 20:39; 希伯來書 6:13"> 「因此，所有住在埃及地的猶大人哪，你們要聽耶和華的話語！耶和華說：看哪，我指著我偉大的名起誓：在埃及全地，我的名絕不再被任何一個猶大人的口宣告說『我指著永生的主耶和華起誓』！</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 31:28; 列王紀下 21:14; 耶利米書 1:10"> 看哪，我看管著他們，為要降禍而不降福，所有在埃及地的猶大人都必死於刀劍和饑荒，直到他們滅絕。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 44:14; 以賽亞書 27:12–13; 以賽亞書 10:19"> 只有少數的人逃脫刀劍，從埃及地返回猶大地。這樣，所有去埃及地寄居的猶大餘剩之民，就知道誰的話語會成就，是我的，還是他們的！</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 19:21; 馬太福音 24:15–16; 耶利米書 44:30"> 以下是給你們的徵兆，這是耶和華的宣告；我必在這地方懲罰你們，好使你們知道我向你們降災禍的話語必定成就。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 25:4–7; 耶利米書 43:9–13; 耶利米書 34:21"> 耶和華如此說：看哪，我要把埃及王法老合弗拉交在他仇敵和尋索他性命的人手中，就像我把猶大王西底加交在他仇敵和尋索他性命的巴比倫王尼布甲尼撒手中那樣！」</span>
</div>
</div>

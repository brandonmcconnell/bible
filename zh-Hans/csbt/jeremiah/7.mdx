<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JER" data-book-slug="jeremiah" data-book-name="耶利米書" data-chapter="7" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 有話語從耶和華臨到耶利米，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 26:2; 啟示錄 3:22; 阿摩司書 7:16"> 「你要站在耶和華殿的門口，在那裡宣告這話，說：所有進入這些門來敬拜耶和華的猶大人哪，你們都要聽耶和華的話語！」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 18:11; 耶利米書 26:13; 以賽亞書 1:16–19"> 以色列的神萬軍之耶和華如此說：「你們要改正自己的所作所為，我就讓你們居住在這地方。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 3:11; 馬太福音 3:9–10; 西番雅書 3:11"> 你們不要依靠虛妄的話語，說：『這些是耶和華的聖殿，是耶和華的聖殿，是耶和華的聖殿。』</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:12–13; 以賽亞書 1:19; 耶利米書 7:3"> 如果你們徹底改正你們的所作所為，如果你們彼此真正實行公正，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:21–24; 撒迦利亞書 7:9–12; 耶利米書 13:10"> 不欺壓寄居者、孤兒和寡婦，不在這地方流無辜人的血，也不跟從別的神而自招災禍，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; 耶利米書 25:5; 耶利米書 3:18"> 那麼，我就讓你們安居在這地方，就是我永永遠遠賜給你們祖先的這地。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:15; 以西結書 13:6–16; 耶利米書 23:14–16"> 看哪，你們卻依靠虛妄無益的話語！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:6; 出埃及記 20:3; 雅各書 4:1–4"> 「你們偷竊、殺人、通姦、起假誓，向巴力燒香，跟從你們所不認識的別的神，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:34; 以西結書 23:37; 以西結書 23:39"> 然後來到這被稱為我名下的殿宇，站在我面前，說『我們得保全了』！難道可以任憑你們行這一切可憎之事嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以賽亞書 56:7; 馬太福音 21:13"> 難道這被稱為我名下的殿宇，在你們眼中成了賊窩嗎？看哪，我都看見了！這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:1; 耶利米書 26:6; 撒母耳記上 4:10–11"> 「現在，你們要前往我在示羅的居所，就是我先前使我的名安居的地方，看看我因子民以色列的罪惡而對那地做了什麼。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 65:12; 歷代志下 36:15–16; 耶利米書 7:25"> 現在，這是耶和華的宣告：因為你們做了這一切事，因為我不斷地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不斷地——或譯作「一大早就」。">a</a></sup>對你們說話，你們卻不聽從，我呼喚你們，你們卻不回應，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:60; 列王紀下 25:9; 耶利米書 7:4"> 因此我怎樣對待示羅，也要怎樣對待你們所依靠的這被稱為我名下的殿宇，以及我所賜給你們和你們祖先的這地方。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 15:1; 列王紀下 17:23; 耶利米書 52:3"> 我要把你們從我面前趕走，正如我曾趕走你們的眾兄弟——所有以法蓮的後裔。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 11:14; 耶利米書 14:11–12; 耶利米書 15:1"> 「至於你，不要為這子民祈禱，不要為他們揚聲呼求或禱告，也不要為他們向我代求，因為我不會垂聽你。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 8:6–18; 以西結書 14:23; 耶利米書 6:27"> 他們在猶大各城中和耶路撒冷的街道上做了什麼，你沒有看見嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 19:13; 耶利米書 44:17–19; 哥林多前書 10:22"> 他們孩子撿木柴、父親點火、女人揉麵團為天后做祭餅，並且向別的神澆奠酒祭，以致惹我惱怒。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 20:11; 耶利米書 2:19; 但以理書 9:7–8"> 他們只是惹怒我嗎？難道他們不是給自己惹禍，以致滿臉恥辱嗎？這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米書 42:18; 耶利米哀歌 2:3–5; 以賽亞書 42:25"> 「因此主耶和華如此說：看哪，我的怒氣和怒火必傾瀉在這地方，傾瀉在人和牲畜身上，以及田野的樹木和這地的果實上；怒火燃燒，不會熄滅！」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿書 8:13; 耶利米書 6:20; 阿摩司書 5:21–23"> 以色列的神萬軍之耶和華如此說：「把你們的燔祭歸入你們別的祭物，吃那肉吧！</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 6:6; 撒母耳記上 15:22; 詩篇 51:16–17"> 因為我把你們祖先從埃及地領出來的日子，並沒有對他們說過，也沒有吩咐過他們有關燔祭和別的祭物的事。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 15:26; 申命記 5:33; 出埃及記 19:5–6"> 我只是吩咐他們這一件事，說：『你們要聽從我的話，我就作你們的神，你們也作我的子民；你們要走在我所吩咐你們的一切道路上，好讓你們蒙福。』</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 耶利米書 8:5; 耶利米書 7:26"> 他們卻不聽從，不側耳聽，反而隨從自己的計謀，隨從自己頑固敗壞的心而行，背對著我，不面向我。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 36:15; 耶利米書 25:4; 尼希米記 9:26"> 自從你們祖先出埃及地那日直到今日，我派遣我的僕人眾先知到你們那裡去，每日不斷地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不斷地——或譯作「一大早就」。">b</a></sup>派遣。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 16:12; 歷代志下 30:8; 耶利米書 7:24"> 你們<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你們——原文直譯「他們」；本節下同。">c</a></sup>卻不聽從我，不側耳聽，反而硬著自己的頸項，作惡超過你們的祖先。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 26:2; 耶利米書 1:7; 以賽亞書 65:12"> 「你要把這一切話語都告訴他們，但他們不會聽從你；你要呼喚他們，但他們不會回應你。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 59:14–15; 箴言 1:7; 以賽亞書 1:4–5"> 你要對他們說：『這就是那民族，不聽從他們的神耶和華的話，不接受管教！誠信已經消亡，從他們口中斷絕了。』</span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 1:20; 彌迦書 1:16; 耶利米書 6:30"> 你要剪去自己的頭髮扔掉，在光禿的高地上舉哀，因為耶和華厭棄、撇棄了這惹怒他的世代。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 32:34; 以西結書 7:20; 但以理書 9:27"> 耶和華宣告：「猶大子民做了我眼中看為惡的事，把他們的可憎偶像放在這被稱為我名下的殿宇裡，玷汙了它。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:10; 耶利米書 32:35; 利未記 18:21"> 他們還建造了欣嫩子谷中的陀斐特高壇，為要在火中焚燒自己的兒女；這不是我所吩咐的，我也從來沒有這樣想過。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米書 19:11; 耶利米書 19:6; 列王紀下 23:10"> 「所以看哪，這是耶和華的宣告：日子將到，這地方不再被稱為陀斐特或欣嫩子谷，而要被稱為『殺戮谷』。他們將在陀斐特埋葬屍體，直到無處可葬。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 12:9; 申命記 28:26; 啟示錄 19:17–18"> 這子民的屍體將給天空的飛鳥和地上的走獸作食物，無人嚇走牠們。</span>
<span className="v" id="v34" data-v="34" data-xref="啟示錄 18:23; 何西阿書 2:11; 以西結書 26:13"> 我要使猶大各城中和耶路撒冷的街道上，不再有歡喜快樂的聲音、新郎新娘的聲音，因為這地將成為廢墟。」</span>
</div>
</div>

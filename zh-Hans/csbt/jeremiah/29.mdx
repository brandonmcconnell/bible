<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 9:20; 使徒行傳 15:23; 希伯來書 13:22"> 以下是一封信中的話語，先知耶利米把書信從耶路撒冷送給了擄民中倖存的長老們，祭司和先知們以及全體民眾，就是尼布甲尼撒從耶路撒冷擄到巴比倫的人。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 22:24–28; 耶利米書 27:20; 歷代志下 36:9–10"> 這封信是在耶哥尼雅王、太后和內臣、猶大和耶路撒冷的首領們，以及木匠和鐵匠離開耶路撒冷之後，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 8:11; 歷代志下 34:20; 耶利米書 39:14"> 藉著沙番的兒子以利亞薩和希勒加的兒子基瑪利的手送去的；這二人被猶大王西底加派遣去巴比倫，到巴比倫王尼布甲尼撒那裡。信中說：</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 24:5; 以賽亞書 10:5–6; 以賽亞書 45:7"> 以色列的神萬軍之耶和華對所有的擄民，就是耶和華使他們從耶路撒冷被擄到巴比倫的人，如此說：</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 29:28; 耶利米書 29:10; 以西結書 28:26"> 「你們要建造房屋住下來，栽種果園，吃園中的果實。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3–4; 創世記 24:51; 創世記 28:1–4"> 你們要娶妻，生養兒女；並為你們的兒子娶妻，使你們的女兒出嫁，讓他們也生養兒女。你們要在那裡增多，不要減少。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 2:1–2; 以斯拉記 6:10; 彼得前書 2:13–17"> 你們要為那城，就是我把你們流放到的那城求平安，為它向耶和華祈求；因為它有平安，你們也就有平安。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:6; 耶利米書 5:31; 帖撒羅尼迦後書 2:9–11"> 以色列的神萬軍之耶和華如此說：<br />「不要讓你們中間的先知和你們的占卜者欺哄你們，也不要聽從你們做夢者所得的夢。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 27:15; 耶利米書 29:31; 耶利米書 29:23"> 因為他們奉我名向你們說的神言是謊言，我並沒有派遣他們。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 9:2; 撒迦利亞書 7:5; 耶利米書 24:6–7"> 事實上，耶和華如此說：<br />「巴比倫的七十年期限滿了以後，我必眷顧你們，為你們成就我美好的應許，把你們帶回這地方。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 55:8–12; 詩篇 33:11; 彌迦書 4:12"> 我知道我為你們安排的計劃，是平安的計劃，不是降禍的計劃，好使你們有前途和希望。這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 7:7–8; 耶利米書 33:3; 詩篇 50:15"> 「那時你們呼求我，來向我禱告，我必垂聽你們。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:29–31; 詩篇 119:2; 馬太福音 7:7"> 你們尋找我，如果全心尋求我，就必找到；</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 36:1–38; 耶利米書 30:3; 歷代志上 28:9"> 我必使你們找到我。這是耶和華的宣告。我也必使你們的擄民回歸，把你們從我驅趕你們到的各國各地招聚起來，帶回到我使你們被擄離開的地方。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 29:8–9; 耶利米書 28:1–17; 以西結書 1:3"> 因為你們說「耶和華已經在巴比倫為我們興起了眾先知」，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 38:2–3; 耶利米書 38:17–23; 以西結書 17:12–21"> 所以論到坐大衛寶座的王，以及住在這城的全體民眾，就是沒有與你們一起被擄去的同胞們，</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 24:8–10; 耶利米書 29:18; 耶利米書 24:1–3"> 萬軍之耶和華如此說：<br />「看哪，我必使刀劍、饑荒和瘟疫臨到他們，使他們像腐爛的無花果，壞得不能吃。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 29:8; 耶利米書 15:4; 耶利米書 42:18"> 我必用刀劍、饑荒和瘟疫追趕他們，使他們令地上的萬國戰兢，在我驅趕他們到的所有國家中受詛咒、令人驚駭、被嗤笑、被羞辱，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 6:19; 耶利米書 26:5; 耶利米書 7:24–26"> 因為他們不聽從我的話。這是耶和華的宣告。我派遣我的僕人眾先知到他們那裡去，不斷地派遣，他們卻不聽從。這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米書 24:5; 彌迦書 4:10; 以西結書 3:15"> 「因此你們所有的擄民，就是我從耶路撒冷流放到巴比倫的人，都要聽耶和華的話語。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:14–15; 耶利米哀歌 2:14; 耶利米書 29:8–9"> 論到奉我名向你們說假預言的科賴雅的兒子亞哈和瑪西雅的兒子西底加，以色列的神萬軍之耶和華如此說：看哪，我必把這二人交在巴比倫王尼布甲尼撒手中，他將在你們眼前擊殺他們。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 65:15; 但以理書 3:6; 但以理書 3:21"> 所有在巴比倫的猶大擄民，都會以他們詛咒人，說：『願耶和華使你像巴比倫王用火焚燒的西底加和亞哈那樣！』</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:14; 希伯來書 4:13; 瑪拉基書 3:5"> 因為他們在以色列做了醜惡的事，與鄰人的妻子通姦，又藉我的名說我沒有吩咐過他們的假話。我是知情者，也是見證人。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 29:31–32"> 「你要告訴尼希蘭人示瑪雅說，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 37:3; 耶利米書 29:29; 耶利米書 52:24"> 以色列的神萬軍之耶和華如此說：你竟然用自己的名義送信給在耶路撒冷的全體民眾，以及瑪西雅的兒子祭司西番雅和所有的祭司，說：</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米書 20:1–2; 列王紀下 9:11; 約翰福音 10:20"> 『耶和華已經立你西番雅為祭司，代替祭司耶赫亞達，作耶和華殿的監督，處治所有發狂說神言的人，給他們戴上枷鎖和鐵枷。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 25:16; 耶利米書 43:2–3; 耶利米書 29:26"> 現在，你為什麼不斥責向你們說神言的亞拿突人耶利米呢？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 29:5; 耶利米書 29:1; 耶利米書 29:10"> 因為他送信給我們在巴比倫的人，說：流亡必長久；你們要建造房屋住下來，栽種果園，吃園中的果實。』</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米書 29:25"> 「祭司西番雅把這封信宣讀給先知耶利米聽，</span>
<span className="v" id="v30" data-v="30"> 所以耶和華的話語臨到耶利米，說：</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 29:9; 耶利米書 29:23–24; 耶利米書 14:14–15"> 你要送信給所有的擄民說，論到尼希蘭人示瑪雅，耶和華如此說：『示瑪雅向你們說神言，我並沒有派遣他，他竟使你們依靠虛謊。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 28:16; 列王紀下 7:19–20; 耶利米書 17:6"> 因此耶和華如此說：看哪，我必懲罰尼希蘭人示瑪雅和他的後裔！他必不會有後裔住在這子民中間，也不會看到我要為子民做的美事，因為他對耶和華說了叛逆的話。這是耶和華的宣告。』」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 41:11; 耶利米書 40:13; 耶利米書 6:13"> 那時，所有的將領，加利亞的兒子約哈南和何沙雅的兒子耶撒尼亞，以及全體民眾，無論尊卑都前來，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 36:7; 利未記 26:22; 使徒行傳 8:24"> 對先知耶利米說：「請接受我們的懇求<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="接受我們的懇求——原文直譯「讓我們的懇求達到你面前」。">a</a></sup>，為我們，為這所有的餘剩之民向你的神耶和華禱告；因為就像你親眼看到的，我們眾多的人只剩下了少數。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 86:11; 箴言 3:6; 詩篇 25:4–5"> 願你的神耶和華指示我們當走的路和當做的事！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 12:23; 撒母耳記上 3:17–18; 出埃及記 8:29"> 先知耶利米對他們說：「我已經聽見了。看哪，我必照著你們的話向你們的神耶和華禱告。耶和華回答你們的一切話語，我都會告訴你們，不會保留一句不告訴你們的。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 31:50; 士師記 11:10; 瑪拉基書 3:5"> 他們就對耶利米說：「如果我們不照著耶和華你神派遣你告訴我們的一切話去做，就願耶和華作真實誠信的見證，指控我們！</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:23; 申命記 5:29; 羅馬書 8:7"> 我們派你去求問耶和華我們的神，他的話語無論是好是壞，我們都會聽從，好使我們因聽從我們神耶和華的話語而蒙福。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:14; 以賽亞書 28:16; 哈巴谷書 2:3"> 過了十天，耶和華的話語臨到耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 42:1; 耶利米書 41:11–16; 耶利米書 43:2–5"> 他就把加利亞的兒子約哈南和那些跟隨他的將領，以及全體民眾，無論尊卑都召來。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 19:4; 耶利米書 42:2; 列王紀下 19:6"> 他對他們說：「你們派我去在以色列的神耶和華面前呈上你們的懇求，現在他如此說：</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:28; 以西結書 36:36; 耶利米書 24:6"> 如果你們仍然住在這地，我就建立你們而不拆毀，栽種你們而不拔出，因為我對降給你們的災禍感到後悔。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:31; 耶利米書 1:19; 耶利米書 1:8"> 不要怕你們所懼怕的巴比倫王，不要怕他，因為我與你們同在，必拯救你們，解救你們脫離他的手。這是耶和華的宣告。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 1:11; 詩篇 106:45–46; 箴言 16:7"> 我要向你們施憐憫，使他憐憫你們，讓你們回歸自己的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 44:16; 出埃及記 5:2; 耶利米書 42:10"> 但如果你們不聽從你們的神耶和華的話語，而說『我們不住在這地！</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 41:17; 耶利米書 4:19; 以賽亞書 31:1"> 不，我們還是要去埃及地，住在那裡，在那裡不會看到戰爭，不會聽到號角聲，也不會因缺乏糧食而挨餓』，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 17:16; 耶利米書 44:12–14; 耶利米書 42:17"> 那麼，猶大的餘剩之民哪，現在你們要聽耶和華的話語！以色列的神萬軍之耶和華如此說：如果你們執意要去埃及，去寄居在那裡，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 44:27; 以西結書 11:8; 阿摩司書 9:1–4"> 你們所懼怕的刀劍就會在埃及地追上你們，你們所擔憂的饑荒也會在埃及緊跟著你們，你們必死在那裡。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 42:22; 耶利米書 44:28; 耶利米書 44:13–14"> 所有執意要去埃及寄居的人，都必死於刀劍、饑荒和瘟疫，絕不會有倖存者或逃脫者躲避我降給他們的災禍。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 7:20; 耶利米書 18:16; 耶利米書 29:18"> 「以色列的神萬軍之耶和華如此說：我的怒氣和怒火怎樣傾瀉在耶路撒冷的居民身上，當你們去埃及的時候，我的怒火也怎樣傾瀉在你們身上。你們將被辱罵、令人驚駭、被咒罵、被羞辱，再也看不到這地方。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 17:16; 以賽亞書 30:1–7; 尼希米記 9:26"> 猶大的餘剩之民哪，耶和華已經對你們說：『不要去埃及！』你們要確實知道：我今天已經警誡你們了！</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:3–4; 以西結書 33:31; 馬太福音 22:15–18"> 你們實在是自欺，因為你們派我去求問你們的神耶和華，說『請為我們向我們的神耶和華禱告，把我們神耶和華所說的全都告訴我們，我們必遵行』，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 2:7; 撒迦利亞書 7:11–12; 使徒行傳 20:26–27"> 我今天告訴了你們，你們卻不聽從你們的神耶和華的話語，不聽從他所派我來告訴你們的一切。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 42:17; 以西結書 6:11; 何西阿書 9:6"> 現在你們要確實知道：你們在想要去寄居的地方，必死於刀劍、饑荒和瘟疫。」</span>
</div>
</div>

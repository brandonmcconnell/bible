<span className="v" id="v3" data-v="3" data-xref="利未記 26:19; 耶利米書 14:4; 申命記 28:23"> <span className="pl pl-1">因此甘霖止住，春雨不降，</span><br /><span className="pl pl-1">你卻還是一副妓女面孔</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="面孔——原文直譯「額」。">a</a></sup><br /><span className="pl pl-1">，不顧羞恥。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 2:2; 耶利米書 3:19; 詩篇 71:17"> <span className="pl pl-1">你不是剛剛呼喚我：</span><br /><span className="pl pl-1">「父啊，你是我年輕時的同伴！</span><br /></span>

<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 17:7–17; 以西結書 16:31; 耶利米書 7:24"> 約西亞王年間，耶和華對我說：「你看見背道的以色列所做的嗎？她到各高山上，各青翠樹下，在那裡行淫。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 16:46; 何西阿書 6:1–4; 何西阿書 14:1"> 我以為她做了這一切事之後，就會回轉歸向我，她卻沒有回轉；她奸詐的妹妹猶大也看見了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 24:1; 何西阿書 4:15–17; 以賽亞書 50:1"> 因背道的以色列那些通姦之事，我休棄她，給了她一份休書；我看見她背信的妹妹猶大卻不害怕，也去行淫。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 2:27; 以賽亞書 57:6; 耶利米書 3:2"> 以色列輕忽自己的淫行，與石頭、木頭通姦，因而玷汙了這地。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 7:14; 耶利米書 12:2; 歷代志下 34:33–18"> 即使如此，她奸詐的妹妹猶大還不全心回轉歸向我，而是假意回轉。這是耶和華的宣告。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西結書 23:11; 以西結書 16:51–52; 何西阿書 11:7"> 耶和華對我說：「背道的以色列比背信的猶大倒顯為義了！</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 86:15; 以西結書 33:11; 申命記 4:29–31"> 你去，向北方宣告這些話語說：<br /><span className="pl pl-1">背道的以色列啊，回轉吧！</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /><span className="pl pl-1">我不會怒視你們，</span><br /><span className="pl pl-1">因為我是信實的；</span><br /><span className="pl pl-1">我不會永遠懷怒。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:25; 耶利米書 3:6; 申命記 12:2"> <span className="pl pl-1">只要你承認自己的罪孽，</span><br /><span className="pl pl-1">就是悖逆了耶和華你的神，</span><br /><span className="pl pl-1">在各青翠樹下追求外邦神明，</span><br /><span className="pl pl-1">沒有聽從我的話。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="何西阿書 2:19–20; 耶利米書 2:19; 耶利米書 31:32"> 「背道的兒女啊，回轉吧！這是耶和華的宣告。因為我是你們的主人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="主人——或譯作「丈夫」。">b</a></sup>，我要從一城取一人、從一家取兩人，把你們帶到錫安。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 23:4; 使徒行傳 20:28; 以弗所書 4:11–12"> 我要把合我心意的牧者賜給你們，他們要用知識和智慧牧養你們。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 65:17; 阿摩司書 9:14–15; 以西結書 37:26"> 在那些日子，當你們在這地上增多、繁衍的時候，人必不再說起『耶和華的約櫃』，不會想起，不會記念，不覺缺少，也不再製造。這是耶和華的宣告。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 43:7; 彌迦書 4:1–5; 耶利米書 17:12"> 那時，人必稱耶路撒冷為『耶和華的寶座』，萬國必為耶和華的名聚集到耶路撒冷；他們必不再隨從自己頑固敗壞的心行事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:8; 何西阿書 1:11; 阿摩司書 9:15"> 在那些日子，猶大家要與以色列家同行，從北方之地一同來到我賜給你們祖先為繼業之地。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 3:4; 耶利米書 31:9; 以賽亞書 63:16"> <span className="pl pl-1">「我說：『我多想把你列在兒女當中，</span><br /><span className="pl pl-1">把美好之地，就是萬國中</span><br /><span className="pl pl-1">最榮美的繼業賜給你！』</span><br /><span className="pl pl-1">我以為你會稱呼我『父親』，</span><br /><span className="pl pl-1">不會轉離不跟從我。</span><br /></span>

</div>

<span className="v" id="v22" data-v="22" data-xref="何西阿書 14:1; 何西阿書 14:4; 撒迦利亞書 13:9"> <span className="pl pl-1">『背道的兒女啊，回轉吧！</span><br /><span className="pl pl-1">我必醫除你們的背道。』</span><br /><span className="pl pl-1">『看哪，我們要來到你這裡，</span><br /><span className="pl pl-1">因為你是耶和華我們的神。</span><br /></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 6:60; 耶利米書 11:21; 歷代志下 36:21"> 這是希勒加的兒子耶利米的話語，希勒加是便雅憫地亞納圖城的一位祭司。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 13:20; 約拿書 1:1; 耶利米書 1:11"> 在亞門的兒子猶大王約西亞年間，就是約西亞在位第十三年，耶和華的話語臨到耶利米；</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 39:2; 歷代志下 36:5–8; 列王紀下 23:34"> 從約西亞的兒子猶大王約雅敬年間，直到約西亞的兒子猶大王西底加末年，就是第十一年五月耶路撒冷被擄掠的時候，耶和華的話語也臨到了耶利米。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以西結書 3:16; 以西結書 1:3; 耶利米書 1:2"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 139:16; 以賽亞書 49:1; 加拉太書 1:15–16"> <span className="pl pl-1">「我使你在母腹中成形之前，就認識了你；</span><br /><span className="pl pl-1">你還沒有出胎胞，我就把你分別為聖了。</span><br /><span className="pl pl-1">我已經立你作列國的先知。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 6:12; 出埃及記 4:10–16; 列王紀上 3:7–9"> 我就說：「唉，主耶和華啊！看哪，我不知道怎麼說話，因為我是個少年人。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="馬可福音 16:15–16; 以西結書 3:27; 民數記 22:20"> 耶和華對我說：<br /><span className="pl pl-1">「你不要說『我是個少年人』，</span><br /><span className="pl pl-1">因為無論我派遣你去哪裡，你都要去，</span><br /><span className="pl pl-1">無論我吩咐你說什麼，你都要說。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 1:5; 約書亞記 1:9; 以賽亞書 51:7"> <span className="pl pl-1">你不要怕他們，</span><br /><span className="pl pl-1">因為我與你同在，必拯救你。</span><br /><span className="pl pl-1">這是耶和華的宣告。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:15; 出埃及記 4:11–12; 路加福音 12:12"> 然後耶和華伸手碰了我的口，耶和華對我說：<br /><span className="pl pl-1">「看哪，我已經把我的話語放在你的口中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:28; 哥林多後書 10:4–5; 以賽亞書 44:26–28"> <span className="pl pl-1">看，我今天立你在列邦列國之上，</span><br /><span className="pl pl-1">為要拔出、拆毀、消滅、傾覆，</span><br /><span className="pl pl-1">為要建立和栽種。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="阿摩司書 7:8; 阿摩司書 8:2; 撒迦利亞書 5:2"> 耶和華的話語臨到我，說：「耶利米，你看見了什麼？」<br />我說：「我看見一根杏樹枝。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 12:28; 以西結書 12:25; 以西結書 12:22–23"> 耶和華對我說：「你看得沒錯，因為我守護<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="守護——與希伯來語的「杏樹枝」諧音。">a</a></sup>著我的話語，要使它成就。」</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 11:3; 以西結書 11:7; 撒迦利亞書 4:2"> 耶和華的話語第二次臨到我，說：「你看見了什麼？」<br />我說：「我看見一個沸騰的鍋，正在從北面傾倒。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 41:25; 耶利米書 4:6; 耶利米書 10:22"> 耶和華對我說：「必有禍患從北方衝來，臨到這地所有的居民。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 43:10; 耶利米書 25:9; 耶利米書 9:11"> 看哪，我要召喚北方列國萬族。這是耶和華的宣告。他們來到後，必在耶路撒冷各城門口安放各自的寶座，攻打耶路撒冷四圍所有的城牆和猶大所有的城鎮。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 7:9; 耶利米書 19:4; 使徒行傳 7:41"> 我要對這地的居民宣告我的判決，懲罰他們的一切惡行，因為他們離棄我，向別的神燒香，向自己手所造的下拜。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 1:7–8; 列王紀上 18:46; 彼得前書 1:13"> 「所以你要束腰，起來把我吩咐你的一切都告訴他們。不要因他們的緣故而驚惶，免得我使你在他們面前驚惶。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 50:7; 以西結書 3:8–9; 耶利米書 15:20"> 看哪，我今天使你成為堡壘城、鐵柱和銅牆，抵擋全地，就是猶大的君王、首領、祭司，以及這地的民眾。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 1:9; 耶利米書 1:8; 耶利米書 20:11"> 他們會攻擊你，卻不能成功，因為我與你同在，必拯救你。這是耶和華的宣告。」</span>
</div>
</div>

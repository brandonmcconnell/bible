<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 34:2; 路加福音 3:19–20; 撒母耳記下 24:11–12"> 耶和華如此說：「你下到猶大王宮去，在那裡宣告這話，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 1:32; 以賽亞書 9:7; 耶利米書 22:4"> 說：坐大衛寶座的猶大王啊，你和你的臣僕，以及進入這些城門的民眾，都要聽耶和華的話語！</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:12; 彌迦書 6:8; 耶利米書 22:17"> 耶和華如此說：你們要施行公正和公義，從欺壓者手中解救被搶奪的人；不可欺負寄居者和孤兒寡婦，不可傷害他們，也不可在這地方流無辜人的血。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 17:25"> 如果你們確實遵行這話，坐大衛寶座的君王們就會乘車騎馬，與臣民一起進入這宮殿的各門。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 6:8; 希伯來書 6:13; 創世記 22:16"> 但如果你們不聽從這些話語，我指著自己起誓：這宮殿就必成為廢墟！這是耶和華的宣告。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="詩篇 107:34; 以賽亞書 6:11; 以賽亞書 27:10"> 論到猶大王宮，耶和華如此說：<br /><span className="pl pl-1">「雖然你對於我就像基列，</span><br /><span className="pl pl-1">像黎巴嫩的山頂，</span><br /><span className="pl pl-1">但我必使你變為曠野，</span><br /><span className="pl pl-1">成為無人居住的城。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 37:24; 以賽亞書 10:33–34; 耶利米書 4:6–7"> <span className="pl pl-1">我要預備毀滅者，</span><br /><span className="pl pl-1">各拿武器攻擊你；</span><br /><span className="pl pl-1">他們必砍掉你最好的香柏樹，</span><br /><span className="pl pl-1">扔進火中。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 9:8–9; 歷代志下 7:20–22; 申命記 29:23–26"> 「將有許多國家的人經過這城，彼此問：『耶和華為什麼如此對待這大城呢？』</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 22:17; 歷代志下 34:25; 耶利米書 50:7"> 必有人回答：『是因為他們離棄了他們的神耶和華的約，向別的神下拜，服事它們。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="傳道書 4:2; 耶利米書 22:11; 以賽亞書 57:1"> <span className="pl pl-1">「你們不要為死者哀哭，</span><br /><span className="pl pl-1">也不要為他悲哀，</span><br /><span className="pl pl-1">而要為離去的人大大哀哭，</span><br /><span className="pl pl-1">因為他不得再回來，</span><br /><span className="pl pl-1">不得見到本族之地。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 3:15; 歷代志下 36:1–4; 列王紀下 23:34"> 因為論到約西亞的兒子猶大王沙勒姆，就是接替他父親約西亞作王，又從這地方出去的那位，耶和華如此說：他不得再回到這裡！</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 23:34; 耶利米書 22:18"> 他必死在流亡的地方，不得再見到這地。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:4; 彌迦書 3:10; 利未記 19:13"> <span className="pl pl-1">「那不按公義建造宮殿，</span><br /><span className="pl pl-1">不按公正建造樓閣的人有禍了！</span><br /><span className="pl pl-1">他讓同胞無償地勞動，</span><br /><span className="pl pl-1">不支付工資，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 7:2; 以賽亞書 5:8–9; 哈該書 1:4"> <span className="pl pl-1">還說：『我要為自己建造宏偉的宮殿，</span><br /><span className="pl pl-1">寬敞的樓閣。』</span><br /><span className="pl pl-1">他為房屋開窗戶，</span><br /><span className="pl pl-1">用香柏木作鑲板，</span><br /><span className="pl pl-1">塗上赤紅色。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:25; 以賽亞書 3:10; 傳道書 10:17"> <span className="pl pl-1">難道你作王是要以香柏木炫耀嗎？</span><br /><span className="pl pl-1">你的父親不是也吃也喝，</span><br /><span className="pl pl-1">並且施行公正和公義嗎？</span><br /><span className="pl pl-1">所以他事事順利。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 9:24; 以賽亞書 1:17; 約翰一書 2:3–4"> <span className="pl pl-1">他為困苦人和貧窮人的爭訟伸冤，</span><br /><span className="pl pl-1">所以他事事順利。</span><br /><span className="pl pl-1">認識我，不就在於此嗎？</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得後書 2:14; 列王紀下 24:4; 耶利米書 22:3"> <span className="pl pl-1">然而你眼中和心中只顧財利，</span><br /><span className="pl pl-1">流無辜人的血，</span><br /><span className="pl pl-1">施行欺壓和暴力。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:30; 耶利米書 16:6; 耶利米書 16:4"> 因此論到約西亞的兒子猶大王約雅敬，耶和華如此說：<br /><span className="pl pl-1">人們必不為他哀哭，</span><br /><span className="pl pl-1">說『哀哉，我的兄弟！』</span><br /><span className="pl pl-1">或說『哀哉，我的姐妹！』</span><br /><span className="pl pl-1">也不會為他哀哭，</span><br /><span className="pl pl-1">說『哀哉，我的主！』</span><br /><span className="pl pl-1">或說『哀哉，陛下！』</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 36:30; 列王紀上 21:23–24; 歷代志下 36:6"> <span className="pl pl-1">他必像驢子那樣被埋葬，</span><br /><span className="pl pl-1">被拖走丟棄在耶路撒冷的城門外。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="民數記 27:12; 以西結書 23:22; 耶利米哀歌 1:2"> <span className="pl pl-1">你上黎巴嫩去呼號吧！</span><br /><span className="pl pl-1">在巴珊揚聲吧！</span><br /><span className="pl pl-1">從亞巴琳呼號吧！</span><br /><span className="pl pl-1">因為你所親愛的都被摧毀了。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 32:30; 耶利米書 3:25; 耶利米書 7:22–28"> <span className="pl pl-1">你安穩的時候，我對你說話，</span><br /><span className="pl pl-1">你卻說：『我不聽。』</span><br /><span className="pl pl-1">你從年幼時就是這樣行事，</span><br /><span className="pl pl-1">不聽從我的話。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 5:30–31; 耶利米書 12:10; 耶利米書 23:1–2"> <span className="pl pl-1">風必捲走你所有的牧人，</span><br /><span className="pl pl-1">你所親愛的也必被擄去；</span><br /><span className="pl pl-1">是的，因你的一切惡事，</span><br /><span className="pl pl-1">那時你必抱愧羞慚。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 6:24; 耶利米書 4:30–31; 耶利米書 22:6"> <span className="pl pl-1">你這住在黎巴嫩，</span><br /><span className="pl pl-1">在香柏樹上搭窩的人哪，</span><br /><span className="pl pl-1">當絞痛臨到你，</span><br /><span className="pl pl-1">劇痛像婦人臨產那樣來到，</span><br /><span className="pl pl-1">你會怎樣地哀鳴啊！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 37:1; 雅歌 8:6; 歷代志上 3:16"> 耶和華宣告：「我指著我的永生起誓：儘管你，約雅敬的兒子猶大王哥尼雅，是我右手上的印戒，我也一定要把你從手上扯下來。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 34:20–21; 耶利米書 21:7; 列王紀下 24:15–16"> 我要把你交在尋索你性命的人和你所懼怕的人手中，就是巴比倫王尼布甲尼撒和迦勒底人手中。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 24:15; 耶利米書 15:2–4; 以賽亞書 22:17"> 我要把你和生你的母親拋到別國，你們沒有出生在那裡，卻必死在那裡。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 44:14; 列王紀下 25:27–30; 詩篇 86:4"> 你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——原文直譯「他們」。">a</a></sup>心中盼望回歸這地，卻不得回歸。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 31:12; 何西阿書 8:8; 耶利米書 48:38"> <span className="pl pl-1">「哥尼雅這個人，</span><br /><span className="pl pl-1">是被輕視、被打碎的陶器嗎？</span><br /><span className="pl pl-1">他是沒人想要的器皿嗎？</span><br /><span className="pl pl-1">為什麼他和他的後裔被拋出去，</span><br /><span className="pl pl-1">扔到他們不認識的地方呢？</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:1; 彌迦書 1:2; 耶利米書 6:19"> <span className="pl pl-1">大地啊，大地啊，大地啊，</span><br /><span className="pl pl-1">你要聽耶和華的話語！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 36:30; 詩篇 94:20; 馬太福音 1:11–16"> 耶和華如此說：<br /><span className="pl pl-1">你們要把這人登記為</span><br /><span className="pl pl-1">無子女、一生不成功的人，</span><br /><span className="pl pl-1">因為在他的後裔中，</span><br /><span className="pl pl-1">沒有一個人會成功坐上大衛的寶座，</span><br /><span className="pl pl-1">再次管轄猶大。」</span></span>
</div>
</div>

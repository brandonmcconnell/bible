<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 10:21; 撒迦利亞書 11:15–17; 以西結書 34:2–10"> 耶和華宣告：「那些毀滅、驅散我牧場羊群的牧人有禍了！」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 32:34; 耶利米書 21:12; 彌迦書 7:4"> 因此，論到那些牧養他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——原文直譯「我」。">a</a></sup>子民的牧人，以色列的神耶和華如此說：「你們驅散我的羊群，趕散他們，沒有眷顧他們。看哪，我必因你們的惡行懲罰你們！這是耶和華的宣告。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 9:14–15; 耶利米書 32:37; 以賽亞書 43:5–6"> 然後我要親自把我羊群中餘剩的，從我驅趕他們所到的各地招聚起來，使他們回到自己的牧場；他們必繁衍增多。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 3:14–15; 彼得前書 1:5; 以西結書 34:23–31"> 我必興起一些牧人看顧他們，牧養他們，他們將不再害怕，不再驚惶，一個也不會丟失。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 1:32–33; 以賽亞書 4:2; 以賽亞書 9:7"> 「看哪，這是耶和華的宣告：日子將到，我要為大衛興起一個公義的苗裔；他必作王掌權，行事有智慧，在地上施行公正和公義。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 1:30; 耶利米書 33:16; 腓立比書 3:9"> 在他的日子裡，猶大必得拯救，以色列必安然居住；他的名必稱為『耶和華我們的公義』。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 16:14–15; 耶利米書 23:3; 以賽亞書 43:18–19"> 所以看哪，這是耶和華的宣告：日子將到，人們必不再說『我指著那從埃及地把以色列子孫帶上來的耶和華的永生起誓』，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 43:5–6; 阿摩司書 9:14–15; 以西結書 34:13"> 而會說『我指著那從北方之地，從放逐的各地把以色列家的後裔帶上來、領回來的耶和華的永生起誓』。他們必住在自己的土地上。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="哈巴谷書 3:16; 耶利米哀歌 3:15; 詩篇 60:3"> <span className="pl pl-1">論到那些先知，</span><br /><span className="pl pl-1">我的心在我裡面破碎，</span><br /><span className="pl pl-1">我全身的骨頭都發顫。</span><br /><span className="pl pl-1">因耶和華和他神聖的話語，</span><br /><span className="pl pl-1">我就像一個醉酒的人，</span><br /><span className="pl pl-1">一個被酒所勝的人。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 4:2–3; 詩篇 107:34; 耶利米書 9:2"> <span className="pl pl-1">因為這地滿了通姦的人；</span><br /><span className="pl pl-1">這地因受詛咒就荒蕪，</span><br /><span className="pl pl-1">曠野的牧場都枯乾了。</span><br /><span className="pl pl-1">他們的路徑邪惡，</span><br /><span className="pl pl-1">他們的力量不義。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="西番雅書 3:4; 耶利米書 6:13; 馬太福音 21:12–13"> <span className="pl pl-1">「是的，無論先知還是祭司，</span><br /><span className="pl pl-1">都被玷汙了；</span><br /><span className="pl pl-1">甚至在我的殿宇中，</span><br /><span className="pl pl-1">我也發現了他們的惡行。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 13:16; 耶利米書 11:23; 詩篇 35:6"> <span className="pl pl-1">因此他們的道路必像滑地，</span><br /><span className="pl pl-1">他們必被趕進幽暗，在其中仆倒；</span><br /><span className="pl pl-1">因為我要在他們受懲罰之年，</span><br /><span className="pl pl-1">使禍患臨到他們。</span><br /><span className="pl pl-1">這是耶和華的宣告。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:8; 以賽亞書 9:16; 列王紀上 18:18–21"> <span className="pl pl-1">「在撒瑪利亞的先知中，</span><br /><span className="pl pl-1">我看見了可厭的事：</span><br /><span className="pl pl-1">他們藉著巴力說預言，</span><br /><span className="pl pl-1">使我的子民以色列迷失。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 1:9–10; 耶利米書 29:23; 以西結書 22:25"> <span className="pl pl-1">在耶路撒冷的先知中，</span><br /><span className="pl pl-1">我也看見了可怕的事：</span><br /><span className="pl pl-1">他們通姦，行事虛假，</span><br /><span className="pl pl-1">堅固惡人的手，</span><br /><span className="pl pl-1">以致沒有人轉離惡行。</span><br /><span className="pl pl-1">在我面前，他們都像所多瑪，</span><br /><span className="pl pl-1">耶路撒冷的居民就像格摩拉。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 8:14; 耶利米書 9:15; 耶利米哀歌 3:5"> 「因此論到那些先知，萬軍之耶和華如此說：<br /><span className="pl pl-1">看哪，我要把苦艾給他們吃，</span><br /><span className="pl pl-1">把毒水給他們喝，</span><br /><span className="pl pl-1">因為玷汙的事從耶路撒冷的先知</span><br /><span className="pl pl-1">擴散到了全地。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 14:14; 以西結書 13:6; 加拉太書 1:8–9"> 萬軍之耶和華如此說：「你們不要聽從那些先知的話語，他們向你們說預言，使你們成為虛妄；他們說的異象是出於自己的心，不是出於耶和華的口。</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 3:11; 耶利米書 13:10; 阿摩司書 9:10"> 他們對藐視我的人反覆說：『耶和華說：你們必得平安。』又對所有照著自己頑固的心行事的人說：『禍患不會臨到你們。』</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:22; 以賽亞書 40:13–14; 阿摩司書 3:7"> <span className="pl pl-1">然而，他們中有誰曾站在耶和華的會中，</span><br /><span className="pl pl-1">得以看見，得以聽見他的話語呢？</span><br /><span className="pl pl-1">有誰留心聽他的話語而聽從呢？</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 30:23; 耶利米書 25:32; 阿摩司書 1:14"> <span className="pl pl-1">看哪，耶和華的狂風在怒火中發出，</span><br /><span className="pl pl-1">是旋轉的狂風，</span><br /><span className="pl pl-1">必旋轉到惡人的頭上！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 30:24; 以賽亞書 55:11; 撒迦利亞書 1:6"> <span className="pl pl-1">耶和華的怒氣不會轉消，</span><br /><span className="pl pl-1">直到他實行、成就他心中的計劃。</span><br /><span className="pl pl-1">在末後的日子，</span><br /><span className="pl pl-1">你們必完全明白這事。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:14; 耶利米書 27:15; 耶利米書 23:32"> <span className="pl pl-1">我沒有派遣這些先知，</span><br /><span className="pl pl-1">他們卻奔跑；</span><br /><span className="pl pl-1">我沒有對他們說話，</span><br /><span className="pl pl-1">他們卻說預言。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:18; 撒迦利亞書 1:4; 耶利米書 25:5"> <span className="pl pl-1">他們如果曾站在我的會中，</span><br /><span className="pl pl-1">就應當使我的子民聽我的話語，</span><br /><span className="pl pl-1">使他們轉離邪惡的道路，</span><br /><span className="pl pl-1">離開自己的惡行。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 139:1–10; 列王紀上 20:23; 列王紀上 20:28"> 「難道我只是近處的神而非遠處的神嗎？這是耶和華的宣告。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:3; 詩篇 139:7; 詩篇 90:8"> 難道人能隱藏在隱祕處，使我看不見他嗎？這是耶和華的宣告。我豈不是充滿諸天和大地嗎？這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米書 23:32; 耶利米書 23:28; 耶利米書 29:8"> 「我聽見了藉我名說假預言的那些先知所說的，他們說：『我做了夢！我做了夢！』</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 4:1–2; 耶利米書 14:14; 帖撒羅尼迦後書 2:9–11"> 那些說假預言、心裡詭詐的先知，他們這樣存心要到什麼時候呢？</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 8:33–34; 士師記 3:7; 使徒行傳 13:8"> 他們藉著彼此講述自己的夢，圖謀使我的子民忘記我的名，就像他們的祖先因巴力而忘記我的名一樣。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多後書 2:17; 提摩太前書 1:12; 哥林多前書 3:12–13"> 得了夢的先知，就讓他講述那夢吧！得了我話語的先知，他要誠實地講說我的話語！乾草怎麼能與穀物相比呢？這是耶和華的宣告。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 4:12; 耶利米書 5:14; 路加福音 24:32"> 我的話語難道不是像烈火，像打碎岩石的大錘嗎？這是耶和華的宣告。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 18:20; 以西結書 13:8; 耶利米書 14:14–15"> 所以看哪，我敵對那些先知！他們互相偷竊對方的話，卻當作我的話。這是耶和華的宣告。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 23:17; 歷代志下 18:10–12; 歷代志下 18:5"> 看哪，這是耶和華的宣告：我敵對那些先知！他們搬弄舌頭謊稱『宣告』。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 13:7–18; 西番雅書 3:4; 耶利米哀歌 2:14"> 看哪，我敵對那些先知！他們藉著虛假之夢說預言。這是耶和華的宣告。他們講述這些夢，以他們的虛假和浮誇使我的子民迷失。我並沒有派遣他們，也沒有吩咐他們，他們對這子民毫無益處。這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="瑪拉基書 1:1; 耶利米書 12:7; 哈巴谷書 1:1"> 「無論是這子民還是先知、祭司，如果問你說：『耶和華的默示<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="默示——原文也作「負擔」；本章下同。">b</a></sup>是什麼呢？』你就對他們說：『什麼默示？我要撇棄你們。』這是耶和華的宣告。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 13:3; 耶利米哀歌 2:14"> 無論是先知、祭司還是子民，如果說『耶和華的默示』，我必懲罰那人和他的家。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 31:34; 耶利米書 42:4; 耶利米書 33:3"> 你們各人對自己的鄰舍、對自己的兄弟，要如此說：『耶和華回應了什麼？耶和華說了什麼？』</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 10:10; 彼得後書 3:16; 以賽亞書 3:8"> 你們不要再提起『耶和華的默示』，因為各人所說的話必成為自己的默示；你們已經歪曲了我們的神萬軍之耶和華、永生神的話語。</span>
<span className="v" id="v37" data-v="37"> 你們要對先知如此說：『耶和華回應了你什麼？耶和華說了什麼？』</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志下 11:13–14"> 如果你們說『耶和華的默示』，耶和華就如此說：因為我派人到你們那裡去，告訴你們不可說『耶和華的默示』，你們卻還說『耶和華的默示』這樣的話，</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米書 23:33; 以西結書 8:18; 箴言 13:13"> 所以看哪，我必完全忘記你們，把你們以及我所賜給你們和你們祖先的這城，都從我面前撇棄；</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米書 20:11; 以西結書 5:14–15; 耶利米書 42:18"> 也必加給你們永遠的羞辱和永遠的羞恥，不會被忘記。」</span>
</div>

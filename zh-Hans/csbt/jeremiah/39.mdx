<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 24:1–2; 耶利米書 52:4–7; 列王紀下 25:1–12"> 耶路撒冷被攻取的時候是這樣的：猶大王西底加九年十月，巴比倫王尼布甲尼撒和他的全軍來到耶路撒冷，圍困這城；</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 52:6–7; 彌迦書 2:12–13; 列王紀下 25:3–4"> 西底加十一年四月九日，城被攻破。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:4; 耶利米書 38:17; 耶利米書 39:13"> 巴比倫王所有的首領，就是尼甲沙利薛，叁甲尼波，內侍長撒西金，大總管尼甲沙利薛，以及巴比倫王其餘的眾首領，都進了城，坐鎮在中門。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="阿摩司書 2:14; 歷代志下 32:5; 列王紀下 25:4–7"> 那時，猶大王西底加和所有的戰士看見他們，就從王室園子兩道城牆之間的門趁夜逃出城，沿著亞拉巴方向的路逃去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:33; 約書亞記 5:10; 耶利米書 52:26–27"> 迦勒底軍隊追趕他們，在耶利哥平原追上了西底加，捉住他，把他帶到哈馬地的利比拉，到巴比倫王尼布甲尼撒那裡。尼布甲尼撒就對他宣告裁決。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米書 52:10; 耶利米書 34:19–21; 耶利米書 24:8–10"> 巴比倫王在利比拉，在西底加眼前把他的兒子們殺了。巴比倫王還殺了猶大所有的貴族，</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 12:13; 列王紀下 25:7; 耶利米書 52:11"> 並且弄瞎西底加的雙眼，用銅鏈捆住他，要把他帶到巴比倫去。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 1:3; 耶利米書 38:18; 耶利米書 21:10"> 迦勒底人放火燒毀了王宮和民眾的房屋，也拆毀了耶路撒冷的城牆。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 40:1; 創世記 37:36; 耶利米書 10:18"> 護衛長尼布撒拉旦把城中殘留的其餘民眾和那些之前向他投降的人，以及其餘的餘剩之民，都擄到了巴比倫。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 25:12; 耶利米書 40:7; 耶利米書 52:16"> 至於民中那些一無所有的窮人，護衛長尼布撒拉旦把他們留在猶大地，當時也給了他們一些葡萄園和田地。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 24:23; 耶利米書 15:21; 約伯記 5:19"> 巴比倫王尼布甲尼撒為耶利米吩咐護衛長尼布撒拉旦，說：</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; 耶利米書 40:4; 箴言 21:1"> 「你把他帶走，看顧他，不可做任何傷害他的事。他對你怎樣說，你就怎樣做。」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 39:3; 耶利米書 39:9"> 於是護衛長尼布撒拉旦、內侍長尼布沙斯班、大總管尼甲沙利薛，以及巴比倫王所有的高官，就派人去，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 38:28; 列王紀下 22:12; 耶利米書 26:24"> 把耶利米從護衛兵院子裡帶出來，交給沙番之子亞希甘的兒子基大利，讓他把耶利米帶回家。這樣，耶利米就住在民眾當中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 2:9; 耶利米書 32:1–2; 耶利米書 36:1–5"> 耶利米還被拘禁在護衛兵院子裡的時候，耶和華的話語臨到他說：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 9:12; 撒迦利亞書 1:6; 約書亞記 23:14–15"> 「你去告訴庫實人伊伯米勒說，以色列的神萬軍之耶和華如此說：看哪，我必使我的話語臨到這城，降禍而不降福！到那日，這一切必在你面前發生。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 41:1–2; 詩篇 91:14–15; 詩篇 50:15"> 到那日，我卻要解救你，你不會被交在你所懼怕的那些人手中。這是耶和華的宣告。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:2; 詩篇 34:22; 耶利米書 21:9"> 我必定拯救你，你不會倒在刀下。你必保住自己的性命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你必保住自己的性命——原文直譯「你的性命必作為戰利品歸於你」。">a</a></sup>，因為你依靠我。這是耶和華的宣告。」</span>
</div>

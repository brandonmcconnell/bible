<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以弗所書 6:8–20; 雅各書 2:13; 申命記 24:14–15"> <span className="pl pl-1">你們做主人的，要公正、公平地對待奴僕，因為你們知道，你們也有一位主人在天上。</span></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 5:17–18; 腓立比書 4:6; 以弗所書 6:18"> 你們要恆切禱告，禱告中要保持警醒，懷著感謝的心。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 6:19–20; 使徒行傳 14:27; 帖撒羅尼迦後書 3:1–2"> 同時也要為我們禱告：願神給我們開福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直譯「話語」或「道」。">a</a></sup>的門，使我們能傳講基督的奧祕——我也是為此被捆鎖的，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 4:1–4; 以弗所書 6:20; 歌羅西書 4:6"> 願我能照著所當說的，把這奧祕顯明出來。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 5:15–17; 帖撒羅尼迦前書 4:12; 雅各書 3:13"> 你們要把握機會<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="要把握機會——原文直譯「要贖回時機」。">b</a></sup>，對外面的人靠智慧行事。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 4:29; 彼得前書 3:15; 傳道書 10:12"> 你們的話語總要帶著恩惠，像用鹽調和過的，好使你們知道該怎樣回答每一個人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所書 6:21–23; 使徒行傳 20:4; 提摩太後書 4:12"> 有關我的一切事，特其庫斯會讓你們明白。他是蒙愛的弟兄、忠心的僕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="僕人——或譯作「執事」。">c</a></sup>，是在主裡同做奴僕<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="奴僕——或譯作「僕人」。">d</a></sup>的。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:22; 歌羅西書 2:2; 腓立比書 2:28"> 我正是為此派他到你們那裡去，好讓你們知道有關我們的事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="好讓你們知道有關我們的事——有古抄本作「好讓他知道有關你們的事」。">e</a></sup>，並且讓他安慰你們的心。</span>
<span className="v" id="v9" data-v="9" data-xref="腓利門書 1:10–19; 歌羅西書 4:7"> 與他一起去的奧尼斯莫，是一位忠心、蒙愛的弟兄，是你們那裡的人。他們會把這裡的一切情況都讓你們明白。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓利門書 1:24; 提摩太後書 4:11; 使徒行傳 19:29"> 與我一起坐牢的亞里達古問候你們。巴拿巴的表弟馬可也問候你們。關於馬可，你們已經領受了指示：如果他到你們那裡去，你們要接受他。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 11:2; 哥林多後書 6:1; 使徒行傳 10:45"> 稱為猶斯托的耶數也問候你們。在割禮派的人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="割禮派的人——或譯作「受割禮的人」。">f</a></sup>中，只有這幾個人是為了神的國與我同工的；他們也成了我的安慰。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:30; 歌羅西書 1:9; 歌羅西書 1:7"> 以帕弗拉問候你們；他來自你們那裡，是基督耶穌的奴僕；他在禱告中，總是為你們竭力祈求<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="竭力祈求——原文直譯「爭戰」。">g</a></sup>：願你們成熟、站立得住，在神的一切旨意中確信不疑<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="確信不疑——有古抄本作「得以完全」。">h</a></sup>；</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 2:1; 羅馬書 10:2; 啟示錄 1:11"> 其實我可以為他見證：他為了你們和那些在勞迪西亞和希拉波利斯的人，多受勞苦<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="多受勞苦——有古抄本作「多有熱心」。">i</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="腓利門書 1:24; 提摩太後書 4:10–11"> 蒙愛的醫生路加和迪馬斯問候你們。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:5; 腓利門書 1:2; 哥林多前書 16:9"> 請問候在勞迪西亞的弟兄們，還有寧法以及在她<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="她——有古抄本作「他」。">j</a></sup>家裡的教會。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 5:27; 帖撒羅尼迦後書 3:14"> 這封書信在你們那裡宣讀了以後，也一定要在勞迪西亞的教會中宣讀；你們也要宣讀從勞迪西亞轉來的書信。</span>
<span className="v" id="v17" data-v="17" data-xref="腓利門書 1:2; 使徒行傳 1:17; 以西結書 44:23–24"> 請你們告訴阿其波斯：「在主裡所領受的服事工作，要留心把它完成。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯來書 13:3; 提摩太後書 4:22; 提摩太前書 6:21"> 我保羅親筆問候：請你們記住我所受的捆鎖。願恩典與你們同在！<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附「阿們。」">k</a></sup></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 8:6; 馬太福音 6:33; 哥林多後書 4:18"> 所以，你們如果已經與基督一同復活了，就應當尋求上面的事；在那裡，基督坐在神的右邊。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 2:15–17; 歷代志上 22:19; 歌羅西書 3:1"> 你們要思想上面的事，不要思想地上的事，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 2:20; 羅馬書 6:2; 歌羅西書 2:20"> 因為你們已經死了，你們的生命與基督一同藏在神裡面。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 11:25; 約翰一書 3:2; 加拉太書 2:20"> 基督是你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——有古抄本作「我們」。">a</a></sup>的生命，當他顯現的時候，你們那時也就和他一同在榮耀裡顯現。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:13; 加拉太書 5:19–21; 加拉太書 5:24"> 所以，當把你們屬世的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="屬世的——原文直譯「地上的」。">b</a></sup>各個部分看為死了的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="看為死了的——或譯作「處死」。">c</a></sup>，就如淫亂、汙穢、邪情、惡慾和貪心，貪心就是拜偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 5:6; 羅馬書 1:18; 彼得前書 1:14"> 為了這些事，神的震怒就臨到那些不信從的兒女身上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的震怒就臨到那些不信從的兒女身上——有古抄本作「神的震怒就要來臨」。">d</a></sup>；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 2:2; 彼得前書 4:3–4; 羅馬書 6:19–20"> 當你們從前生活在這些事中的時候，也在其中生活<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="生活——原文直譯「行走」。">e</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 4:29; 以弗所書 4:22; 雅各書 1:20–21"> 但如今，你們也要脫去一切暴怒、憤恨、惡毒、毀謗，以及從你們口中所出的汙穢的話；</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:22; 以弗所書 4:25; 利未記 19:11"> 不要彼此說謊，因你們已經脫去了舊人和舊人的所作所為，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 4:23–24; 羅馬書 12:2; 以弗所書 2:10"> 並且穿上了新人。這新人照著創造他那一位的形像不斷地被更新，以致真正認識他。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:28–29; 哥林多前書 12:13; 羅馬書 10:12"> 在這裡沒有希臘人和猶太人，受割禮的和不受割禮的，外族人、塞西亞人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="塞西亞人——原文直譯「野蠻人」。">f</a></sup>、奴隸、自由人；而基督就是一切，也在一切之中。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:32; 以弗所書 4:2; 約翰一書 4:19"> 因此，你們身為蒙神揀選、聖潔和蒙愛的人，就應當穿上憐憫的心腸<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="心腸——或譯作「情感」。">g</a></sup>，以及仁慈、謙卑、溫柔、耐心。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:32; 馬可福音 11:25; 雅各書 2:13"> 如果一個人對另一個人懷有不滿，總要彼此容忍，互相饒恕。正如主<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="主——有古抄本作「基督」。">h</a></sup>饒恕了你們，你們也當如此。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 4:8; 以弗所書 5:2; 哥林多前書 13:1–13"> 在這一切之上，還要穿上愛——愛就是成熟境界的聯結。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 4:6–7; 約翰福音 14:27; 以賽亞書 26:3"> 又要讓基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——有古抄本作「神」。">i</a></sup>的和平在你們心裡做主；你們也為此蒙召歸於一體。你們要有感謝的心。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:11; 以弗所書 5:19; 約翰福音 15:7"> 你們要讓基督的話語豐豐富富地住在你們裡面，要用一切的智慧彼此教導、勸誡，懷著感恩的心，以詩篇、聖詩、屬靈的詩歌來歌頌神<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神——有古抄本作「主」。">j</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 10:31; 歌羅西書 3:23; 箴言 3:6"> 你們無論做什麼，或在言語上或在行為上，都要奉主耶穌的名，藉著他感謝父神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="以弗所書 5:22–9; 提多書 2:4–5; 哥林多前書 11:3"> <span className="pl pl-1">你們做妻子的，要服從丈夫，這在主裡是合宜的；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 3:7; 創世記 2:23–24; 歌羅西書 3:21"> <span className="pl pl-1">你們做丈夫的，要愛妻子，不可對她們懷有苦毒；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:12; 以弗所書 6:1–3; 箴言 6:20"> <span className="pl pl-1">你們做兒女的，要凡事順從父母，因為這在主裡是蒙喜悅的；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所書 6:4; 詩篇 103:13"> <span className="pl pl-1">你們做父親的，不要惹自己兒女生氣，免得他們灰心喪志；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 6:5–7; 提摩太前書 6:1–2; 加拉太書 1:10"> <span className="pl pl-1">你們做奴僕的，凡事都要順從自己在世上的</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="世上的——原文直譯「肉體的」。">k</a></sup><br /><span className="pl pl-1">主人，不要只在人眼前服事，像是討人的歡心，而要以忠實的心敬畏主</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="主——有古抄本作「神」。">l</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 3:17; 以弗所書 6:6–7; 羅馬書 14:8"> <span className="pl pl-1">你們無論做什麼，都要從心裡去做，像是為主做的，不是為人做的；</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 6:8; 加拉太書 1:10; 使徒行傳 20:32"> <br /><span className="pl pl-1">因為你們知道，你們將要從主那裡得到繼業為報償；你們當服事主基督</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="你們當服事主基督——或譯作「你們當為主基督做奴僕」。">m</a></sup><br /><span className="pl pl-1">。</span></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 10:34; 羅馬書 2:11; 哥林多後書 5:10"> <br /><span className="pl pl-1">要知道，那行不義的，將要照著他所行的不義來領受回報；主是不偏待人的。</span></span>
</div>

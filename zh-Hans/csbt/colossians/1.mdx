<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 1:1; 哥林多前書 1:1; 腓利門書 1:1"> 照著神的旨意做基督耶穌使徒的保羅，以及弟兄提摩太，</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得後書 1:2; 以弗所書 1:1; 羅馬書 1:7"> 致歌羅西的聖徒們，就是在基督裡忠心的弟兄：<br />願恩典與平安從神我們的父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="父——有古抄本作「父和主耶穌基督」。">a</a></sup>臨到你們！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 1:2; 歌羅西書 1:9; 提摩太後書 1:3"> 我們為你們禱告的時候，總是感謝神我們主耶穌基督的父，</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 1:15; 帖撒羅尼迦後書 1:3; 帖撒羅尼迦前書 1:3"> 因為我們聽說了你們在基督耶穌裡的信仰，以及對所有聖徒所懷的愛——</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:3–4; 以弗所書 1:13; 提摩太後書 4:8"> 這信心和愛是藉著那為你們存留在天上的盼望，這盼望是你們在傳到你們那裡的福音真理之話語中所聽過的，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:16; 腓立比書 1:11; 歌羅西書 1:23"> 正如它在全世界，不斷地結果子和擴展<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="擴展——原文直譯「生長」。">b</a></sup><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不斷地結果子和擴展——有古抄本作「不斷地結果子」。">c</a></sup>；自從你們在真理中聽見並了解神恩典的那一天起，在你們中間也像這一樣，</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 4:12; 腓利門書 1:23; 歌羅西書 4:7"> 正如你們從蒙愛的人，就是與我們同做奴僕的以帕弗拉那裡所學到的；他為你們<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你們——有古抄本作「我們」。">d</a></sup>做了基督忠心的僕人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="僕人——或譯作「執事」。">e</a></sup>，</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 15:30; 提摩太後書 1:7; 加拉太書 5:22"> 也把你們在聖靈裡的愛告訴了我們。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各書 3:17; 腓立比書 1:9–11; 雅各書 1:5"> 為此，我們自從聽到這事的那一天起，就不斷地為你們禱告和祈求：願你們藉著一切屬靈的智慧和悟性，能被神旨意的真正知識所充滿；</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 4:1; 希伯來書 13:21; 彼得後書 1:2–3"> 好讓你們行事為人配得上主，凡事蒙他喜悅，在一切美善的工作中結出果子，在神的真正知識上不斷長進。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:16; 腓立比書 4:13; 以弗所書 4:2"> 願你們按照他榮耀的權能，藉著一切能力得以剛強，好讓你們凡事忍耐寬容，懷著喜樂的心</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 20:32; 以弗所書 1:11; 以弗所書 1:18"> 感謝父——他使你們<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你們——有古抄本作「我們」。">f</a></sup>能夠分享聖徒們在光明中的繼業；</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 5:8; 使徒行傳 26:18; 彼得前書 2:9"> 他救我們脫離了黑暗的權勢，把我們遷入他愛子的國度；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 1:7; 羅馬書 3:24–25; 彼得前書 1:19–20"> 在他裡面，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「藉著他的血，」。">g</a></sup>我們得蒙救贖，罪得赦免。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 1:3; 約翰福音 14:9; 約翰福音 1:1"> <span className="pl pl-1">愛子是那不可見之神的形像，</span><br /><span className="pl pl-1">是一切被造之物的長子</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="長子——原文直譯「首生者」。">h</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:36; 約翰福音 1:3; 哥林多前書 8:6"> <span className="pl pl-1">因為萬有都是藉著他造的：</span><br /><span className="pl pl-1">天上和地上的，看得見和看不見的，</span><br /><span className="pl pl-1">無論王位或主權，統治的或掌權的，</span><br /><span className="pl pl-1">一切都是藉著他造的，也是為他而造的，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 1:3; 哥林多前書 8:6; 使徒行傳 17:28"> <span className="pl pl-1">他在萬有之先，萬有也藉著他而存在，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 1:22–23; 啟示錄 1:5; 以弗所書 4:15–16"> <span className="pl pl-1">他是身體的頭，就是教會的頭，</span><br /><span className="pl pl-1">他是元始，是從死人中首先復活的</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="首先復活的——原文直譯「首生的」或「長子」。">i</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">為要使他能在萬有中居首位，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 2:9; 約翰福音 1:16; 以弗所書 1:23"> <span className="pl pl-1">因為父</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="父——原文直譯「他」。">j</a></sup><br /><span className="pl pl-1">樂意使一切的豐盛完美都住在他裡面，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 5:18–21; 以弗所書 1:10; 約翰一書 4:9–10"> <span className="pl pl-1">又藉著他在十字架上所流的血成就了和平，</span><br /><span className="pl pl-1">就是藉著他使萬有——無論地上的或天上的——</span><br /><span className="pl pl-1">都與他自己和好了。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所書 2:12; 提多書 3:3–7; 以弗所書 2:1–3"> 從前，你們在邪惡的行為中與神<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="與神——輔助詞語。">k</a></sup>隔絕，在意念中與他為敵；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 5:27; 猶大書 1:24; 以弗所書 1:4"> 但如今，神在基督的血肉之軀上，藉著死使你們與他自己和好了，並且使你們站在他面前，是聖潔、毫無瑕疵、無可指責的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 3:14; 希伯來書 3:6; 馬太福音 24:13–14"> 可是你們要持守信仰，立定根基，堅定不移，不要從你們所聽到的福音盼望上被挪去。這福音是傳給天下萬人<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="萬人——原文直譯「一切被造之物」。">l</a></sup>的，我保羅也成了這福音的僕人<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="僕人——或譯作「執事」。">m</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="羅馬書 5:3; 提摩太後書 1:8; 哥林多後書 1:5–8"> 如今我為你們受苦難，感到歡喜；並且我為基督的身體，就是教會，要在我的肉體上補滿基督患難的缺欠。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所書 3:2; 歌羅西書 1:23; 加拉太書 2:7–8"> 神為了你們的緣故賜給了我任務<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="任務——或譯作「管家的任務」。">n</a></sup>，我按照這任務成為教會的僕人<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="僕人——或譯作「執事」。">o</a></sup>，為要使神的話語<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="神的話語——或譯作「神的道」。">p</a></sup>完全傳開<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="傳開——輔助詞語。">q</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 羅馬書 16:25–26; 以弗所書 3:3–10"> 這話語就是歷世歷代被隱藏的奧祕，但如今已經顯明給他的聖徒們。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:20; 羅馬書 8:10; 以弗所書 3:16–17"> 神願意在外邦人中，讓他們明白什麼是這奧祕的榮耀的豐盛；那就是：基督在你們裡面，他是榮耀的盼望！</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 5:27; 耶利米書 3:15; 以弗所書 4:11–13"> 我們傳揚基督，用一切的智慧勸誡所有人，教導所有人，好讓我們使所有的人在基督<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="基督——有古抄本作「基督耶穌」。">r</a></sup>裡成熟<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="成熟——或譯作「完全」。">s</a></sup>，能夠獻給神<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="神——輔助詞語。">t</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 15:10; 以弗所書 1:19; 哥林多前書 9:25–27"> 我也為此勞苦，藉著他在我裡面的大能作為而爭戰。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:6; 彼得後書 1:12–15; 彼得前書 1:22"> 各位蒙愛的人哪，這已經是我寫給你們的第二封信。在這兩封信中，我都用提醒的話來激發你們純潔的意念，</span>
<span className="v" id="v2" data-v="2" data-xref="猶大書 1:17; 彼得後書 2:21; 路加福音 1:70"> 要使你們想起聖先知們曾經說過的話，以及你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——有古抄本作「我們」。">a</a></sup>的使徒們所傳<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="所傳——輔助詞語。">b</a></sup>的主、救主的命令。</span>
<span className="v" id="v3" data-v="3" data-xref="猶大書 1:18; 提摩太前書 4:1–2; 彼得後書 2:10"> 你們首先要知道這一點：在末後的日子裡，將有好譏誚的人出來譏誚<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「譏誚」。">c</a></sup>，他們順著自己的欲望生活，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 17:15; 瑪拉基書 2:17; 耶利米書 5:12–13"> 並且說：「他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——指「基督」。">d</a></sup>來臨的應許在哪裡呢？其實自從祖先睡了以來，一切<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一切——或譯作「萬物」。">e</a></sup>都繼續存留，與創世之初一樣。」</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:3; 創世記 1:9; 詩篇 24:2"> 他們故意忽略這一點：就是從太古的時候，藉著神的話語有了諸天，也有了從水而出、藉水而成的大地；</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 24:38–39; 彼得後書 2:5; 路加福音 17:27"> 藉著神的話語和水<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神的話語和水——原文直譯「這些」。">f</a></sup>，當時的世界被水淹沒就毀滅了；</span>
<span className="v" id="v7" data-v="7" data-xref="彼得後書 3:10; 以賽亞書 51:6; 彼得後書 3:12"> 但現在的天和地，藉著他的話語得以存留，一直留到不敬神的人受審判和滅亡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="滅亡——或譯作「沉淪」。">g</a></sup>的日子，被火焚燒<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="焚燒——輔助詞語。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 90:4; 羅馬書 11:25; 哥林多前書 12:1"> 可是，各位蒙愛的人哪，你們不可忽略這一點：在主看來，一日如千年，千年如一日。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 2:4; 羅馬書 2:4; 哈巴谷書 2:3"> 主沒有像有些人認為的那樣，拖延所應許的；相反，他對你們恆久忍耐，不願任何人滅亡，而願所有人都來悔改。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:1; 馬太福音 24:35; 彼得後書 3:7"> 不過，主的日子要來臨，就像<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「在夜裡」。">i</a></sup>賊來臨那樣。在那日，諸天要轟然一聲地消逝，天體<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="天體——或譯作「元素」。">j</a></sup>將被火焚燒而廢除，地和地上的作為也都將被暴露出來<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="被暴露出來——有古抄本作「被燒掉」。">k</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前書 1:15; 腓立比書 1:27; 彼得前書 2:12"> 既然這一切都要如此被廢除，那麼，你們應該做什麼樣的人呢？應該行為聖潔、敬畏神，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得後書 3:10; 以賽亞書 34:4; 彌迦書 1:4"> 等候並催促<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="催促——或譯作「渴望」。">l</a></sup>神的日子來臨。因為在那日，諸天將被焚燒而廢除，天體<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="天體——或譯作「元素」。">m</a></sup>要被火焚燒而熔化。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 65:17; 啟示錄 21:1; 以賽亞書 66:22"> 但照著他的應許，我們等候著一個新天新地，有公義居住在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 5:23; 帖撒羅尼迦前書 3:13; 腓立比書 1:10"> 所以，各位蒙愛的人哪，你們既然等候這些事，就當努力地使自己被神<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="神——輔助詞語。">n</a></sup>看做是與他和好、毫無玷汙、毫無瑕疵的；</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 2:4; 彼得後書 3:9; 提摩太前書 1:16"> 並且你們要把我們主的耐心看做救恩，就像我們親愛的弟兄保羅，照著所賜他的智慧寫給你們的那樣。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:6; 希伯來書 5:11; 雅各書 1:8"> 他在所有的信中也都說到這些事。那些沒有知識、不堅定的人曲解了他信中一些難懂的地方，正如他們也曲解其他經文，就導致了他們自己的滅亡<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="滅亡——或譯作「沉淪」。">o</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 3:14; 歌羅西書 2:8; 哥林多後書 11:13–15"> 因此，各位蒙愛的人哪，你們既然預先知道了這些，就應該警惕，免得被那些惡人<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="惡人——或譯作「不法之徒」。">p</a></sup>的迷惑<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="迷惑——或譯作「錯覺」。">q</a></sup>引入歧途，從自己堅固的地步墜落。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:10; 以弗所書 4:15; 彼得前書 2:2"> 你們要在我們的主、救主耶穌基督的恩典和知識中不斷長進。願榮耀歸於他，從現在直到永遠之日！阿們。<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="有古抄本沒有「阿們。」">r</a></sup></span>
</div>
</div>

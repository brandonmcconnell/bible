<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 58:1; 以西結書 24:6; 以西結書 24:9"> 「人子啊，你要譴責嗎？要譴責這殺人流血的城嗎？你要讓她知道她的一切可憎之事。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 22:27; 羅馬書 2:5; 彼得後書 2:3"> 你要說，主耶和華如此說：這城中有殺人流血的事，以致她的時候來到；她還製造偶像玷汙自己！</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:16; 詩篇 44:13–14; 以西結書 22:2"> 你因殺人流血而有了罪責，你以製造的偶像玷汙了自己。你使你的日子臨近，使你的年數來到。因此，我要使你被列國羞辱，被全地諷刺。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 22:2; 耶利米書 15:2–3"> 你這聲名狼藉、騷亂眾多的城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="城——輔助詞語。">a</a></sup>啊，無論離你近的、離你遠的，都將嘲諷你！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 22:27; 以賽亞書 1:23; 撒迦利亞書 3:3"> 「看哪，在你那裡，以色列的領袖各人依仗權勢，去殺人流血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:16; 出埃及記 22:21–22; 利未記 20:9"> 在你那裡有人藐視父母，在你中間有人欺壓寄居者，在你那裡有人欺負孤兒寡婦。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 23:38–39; 以西結書 22:26; 以西結書 20:13"> 你輕視我的聖物，褻瀆我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 4:14; 利未記 19:16; 何西阿書 4:10"> 在你那裡有人搬弄是非，為要殺人流血。在你那裡有人到山上吃祭物，在你中間有人行醜惡的事。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 18:19; 利未記 18:7–8; 以西結書 18:6"> 在你那裡有人裸露父親的下體，在你那裡有人玷辱經期中不潔淨的女人。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 18:15; 撒母耳記下 13:14; 利未記 20:17"> 有人與鄰人的妻子做可憎的事；有人玷汙自己的兒媳，做了醜惡的事；在你那裡有人玷辱自己的姐妹——自己父親的女兒。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:25; 以西結書 23:35; 詩篇 106:21"> 在你那裡有人接受賄賂殺人流血。你收取利息和厚利，欺壓剝削你的鄰人。你忘記了我！這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 21:17; 以賽亞書 33:15; 阿摩司書 2:6–8"> 「所以看哪，因你獲取的不義之財，因你中間的血債，我要擊掌奮起。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 21:7; 以西結書 17:24; 以西結書 24:14"> 到了我對付你的日子，你的心能承受得住嗎？你的手還能穩固嗎？我耶和華發了話，就必成就。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 1:8; 以西結書 22:22; 申命記 4:27"> 我要把你驅散到列國，揚散在各地，從你中間除盡你的汙穢。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 6:7; 詩篇 83:18; 以西結書 7:24"> 你必在列邦眼前被褻瀆，那時你就知道：我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:119; 以賽亞書 1:22; 耶利米書 6:28–30"> 「人子啊，以色列家對我已經成了渣滓。他們全都是熔爐中的銅、錫、鐵和鉛，是銀子的渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:30; 以西結書 24:3–6; 彌迦書 4:12"> 因此主耶和華如此說：因為你們全都成了渣滓，所以看哪，我必把你們聚攏在耶路撒冷當中。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:11–12; 以賽亞書 54:16; 以西結書 24:13"> 人怎樣把銀、銅、鐵、鉛和錫聚攏在熔爐中，向它吹火，好使它們熔化，我也照樣在怒氣和怒火中把你們聚攏起來，放在城中熔化。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 64:7; 那鴻書 1:6; 詩篇 50:3"> 我必聚攏你們，把我盛怒的火吹向你們，使你們在其中熔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:8; 以西結書 20:33; 何西阿書 5:10"> 銀子怎樣在熔爐中熔化，你們也必怎樣在城中熔化。那時你們就知道：是我耶和華向你們傾瀉我的怒火。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 36:14–16; 耶利米書 2:30; 歷代志下 28:22"> 「人子啊，你要對這城說：在憤怒的日子裡，你是未得潔淨、無雨降下之地。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 6:9; 耶利米書 2:34; 以西結書 13:19"> 她的眾先知同謀結伙<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="眾先知同謀結夥——七十士譯本作「領袖們」。">b</a></sup>，在她中間好像吼叫的獅子撕咬獵物，他們吞吃人，奪取財富和寶物，使寡婦在她中間增多。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 10:10; 以西結書 44:23; 以西結書 22:8"> 她的祭司們踐踏我的律法，褻瀆我的聖物，不分別聖與俗，也不教導人分辨潔淨的與不潔淨的，並且閉眼不顧我的安息日，以致我在他們中間被褻瀆。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以西結書 22:13; 以賽亞書 1:23; 以西結書 22:6"> 「她當中的首領們像撕咬獵物的豺狼，殺人流血，傷害人命，為要謀取不義之財。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 13:6–7; 以西結書 13:10–16; 耶利米書 23:25–32"> 她的眾先知用白灰為人粉飾掩蓋，他們見虛假的異象，為人行虛謊的占卜，說『主耶和華如此說』，其實耶和華並沒有發話。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 22:7; 出埃及記 23:9; 出埃及記 22:21"> 這地的民眾施行欺壓，強取豪奪，欺負困苦人和貧窮人，非法侵奪寄居者。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 59:16; 耶利米書 5:1; 詩篇 106:23"> 我在他們中間尋找人修補圍牆，在我面前為這地站在破口處，使我不毀滅這地；可是，我連一個也沒找到。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 16:43; 以西結書 7:8–9; 以西結書 9:10"> 所以我要向他們傾瀉我的憤怒，用我盛怒的火滅絕他們，把他們的惡行報應在他們頭上。這是主耶和華的宣告。」</span>
</div>
</div>

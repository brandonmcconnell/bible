<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 49:1–6; 阿摩司書 1:13–15; 以西結書 6:2"> 「人子啊，你要面向亞捫人，針對他們發預言。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 36:2; 詩篇 70:2–3; 箴言 17:5"> 要對亞捫人說：你們當聽主耶和華的話語！主耶和華如此說：我的聖所被褻瀆，以色列地變得荒涼，猶大家被擄去時，你竟然說『啊哈』，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:33; 士師記 6:33; 列王紀上 4:30"> 所以看哪，我必把你交給東方人為產業。他們將在你那裡設立營寨，建造居所；他們將吃你的果實，喝你牛羊的奶。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 21:20; 撒母耳記下 12:26; 以賽亞書 17:2"> 我要使拉巴成為駱駝的牧場，使亞捫人之地成為羊群躺臥之處。那時你們就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="西番雅書 2:8; 俄巴底亞書 1:12; 西番雅書 2:10"> 「是的，主耶和華如此說：因為你擊掌頓足，對以色列地幸災樂禍，滿心恨惡，</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅書 1:4; 以西結書 25:16; 以西結書 6:14"> 所以看哪，我必伸手攻擊你，把你交給萬國為掠物。我要從萬民中剪除你，從列國中消滅你；我必除滅你。那時你就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 15:1–9; 耶利米書 25:21; 耶利米書 48:1–47"> 「主耶和華如此說：因為摩押和西珥說『看哪，猶大家與列國沒有什麼不同』，</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 48:23; 約書亞記 13:17; 約書亞記 13:19–20"> 所以看哪，我必從摩押邊界的各城，就是從那地所誇耀的伯耶西莫、巴力梅翁和基列亭，破開摩押的側翼。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 21:32; 詩篇 83:3–6; 以西結書 25:4"> 我要把它連同亞捫人交給東方人為產業，使亞捫人在列國中不再被記念。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 35:15; 以西結書 30:19; 詩篇 149:7"> 我要對摩押施行審判，那時他們就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 49:7–22; 以西結書 25:8; 詩篇 137:7"> 「主耶和華如此說：因為以東向猶大家施行報復，他們報復猶大家而有了極大的罪責，</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 29:8; 瑪拉基書 1:3–4; 耶利米書 25:23"> 所以主耶和華如此說：我必伸手攻擊以東，從其中剪除人和牲畜，我要使它成為廢墟。他們將倒在刀下，從提幔直到底但。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 11:14; 創世記 27:29; 希伯來書 10:30–31"> 我要藉著我子民以色列的手報復以東，他們必照著我的怒氣和怒火處治以東。那時以東人就知道，這是我的報復。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西結書 25:6; 以賽亞書 14:29–31; 以西結書 25:12"> 「主耶和華如此說：因為非利士人報復猶大家，滿心恨惡施行報復，帶著世代的仇恨要毀滅他們，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 30:14; 西番雅書 2:4–15; 以西結書 25:13"> 所以主耶和華如此說：看哪，我必伸手攻擊非利士人，我要剪除基利提人，消滅沿海一帶餘剩的居民。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 25:11; 以西結書 25:14; 以西結書 5:15"> 我要發烈怒責罰他們，向他們施行極大的報復。當我報復他們時，他們就知道：我是耶和華。」</span>
</div>

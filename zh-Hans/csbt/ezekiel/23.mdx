<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 16:44–46; 耶利米書 3:7–10"> 「人子啊，有兩個女子，是一母所生。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 17:7; 以西結書 16:22; 約書亞記 24:14"> 她們在埃及行淫，在年幼時行淫。在那裡，人們揉搓她們的乳房，撫弄她們貞潔的雙乳。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 16:8; 詩篇 76:2; 耶利米書 2:2–3"> 她們的名字，年長的是阿荷拉，妹妹是阿荷利巴。她們歸屬我，並且生了兒女。她們的名字，阿荷拉就是撒瑪利亞，阿荷利巴就是耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="何西阿書 5:13; 列王紀下 17:3; 列王紀下 16:7"> 「阿荷拉屬於我卻行淫，愛戀她的情人，就是那些鄰邦的亞述人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="鄰邦的亞述人——或譯作「亞述軍人」。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 23:23"> 他們身穿藍色衣服，是省長和官長，是騎馬的馬兵，全都是英俊的青年人。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 5:3; 何西阿書 6:10; 以西結書 22:3–4"> 她與那些人放縱行淫，他們都是最優秀的亞述人；她追隨所愛戀的那些人和他們的一切偶像，玷汙了自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 23:19; 以西結書 23:3; 出埃及記 32:4"> 她從不離棄她在埃及就有的淫亂，那些人在她年幼時就與她同寢，他們撫弄她貞潔的雙乳，向她傾瀉淫欲。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 11:5; 列王紀下 15:29; 列王紀下 17:23"> 因此我把她交在她情人們手中，就是她所愛戀的亞述人手中。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 23:29; 何西阿書 2:10; 耶利米書 22:8–9"> 他們裸露她的下體，擄走她的兒女，用刀劍殺戮她，以致她在女人中成為笑柄。這樣，他們對她施行了審判。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:8–11; 以西結書 16:47–51; 以西結書 23:4"> 「妹妹阿荷利巴看見了這一切，卻比她姐姐更沉陷情慾，她的淫亂超過姐姐的淫行。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:7–15; 以西結書 23:23; 歷代志下 28:16–23"> 她愛戀亞述人，那些省長和官長，披掛整齊的軍人，騎馬的馬兵，他們全都是英俊的青年人。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 12:1–2; 列王紀下 17:18–19; 以西結書 23:31"> 我看見她玷汙了自己，她們兩姐妹同行一路。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 8:10; 耶利米書 22:14; 耶利米書 50:2"> 她還增加淫亂：她看見牆上雕刻的人，就是用赤紅色顏料塗畫的迦勒底人的像，</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:18; 撒母耳記上 18:4; 以賽亞書 22:21"> 腰間束帶，頭裹下垂的頭巾，全都是軍官的樣子，是巴比倫人的形象，迦勒底是他們的出生地；</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 16:29; 馬太福音 5:28; 約伯記 31:1"> 她一看見，就愛戀他們，派使者到迦勒底去見他們。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 23:28; 以西結書 23:22; 創世記 10:10"> 於是巴比倫人來到她那裡，上了歡愛的床，以他們的淫行玷汙她。她讓他們玷汙了自己，隨後心裡就厭棄他們。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 78:59; 詩篇 106:40; 耶利米書 12:8"> 她暴露自己的淫行，裸露自己的下體，因此我的心厭棄她，如同我的心厭棄她姐姐。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 23:3; 以西結書 20:7; 以西結書 16:51"> 她增多自己的淫行，懷念她年幼時在埃及地行淫的時光；</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 17:15; 以西結書 16:26; 耶利米書 5:8"> 她甘願作他們的情婦；他們的下體如驢，精壯如馬。</span>
<span className="v" id="v21" data-v="21"> 你如此眷戀你年幼時的醜惡之事，那時埃及人撫弄你的雙乳，你年幼時的乳房。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 16:37; 啟示錄 17:16; 耶利米書 6:22–23"> 「因此阿荷利巴啊，主耶和華如此說：看哪，我必挑動你心裡厭棄的情人們攻擊你。我要使他們前來，從四圍攻擊你。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 50:21; 列王紀下 24:2; 列王紀下 20:14–17"> 他們是巴比倫人和所有的迦勒底人，比割人、書亞人、哥亞人，以及所有與他們在一起的亞述人；他們全都是英俊的青年人，是省長和官長、軍官和名人，全都騎著駿馬。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 24:14; 以西結書 26:10; 以西結書 23:45"> 他們將帶著兵器、戰車、攻城車，帶著各民族的軍隊來攻擊你；他們裝備大小盾牌和頭盔，從四圍攻擊你。我要把裁決權賜給他們，他們必以自己的裁決來審判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 23:47; 以西結書 8:1–18; 以西結書 15:6–7"> 我要使我的妒火臨到你，他們必在憤怒中處治你。他們將割掉你的鼻子和耳朵，你殘留的人將倒在刀下；他們將擄走你的兒女，你殘留的人將被烈火吞噬；</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 16:39; 耶利米書 13:22; 以西結書 23:29"> 他們將剝去你的衣服，擄走你榮美的器物。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 16:41; 以西結書 23:3; 以西結書 23:19"> 這樣，我使你的醜惡和你在埃及地就開始的淫行終止，你就不再仰望他們，不再思念埃及了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西結書 23:22; 以西結書 23:17; 耶利米書 34:20"> 「是的，主耶和華如此說：看哪，我必把你交在你所厭惡、你心裡厭棄的人手中。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 16:39; 以西結書 23:25–26; 以西結書 23:45–47"> 他們將以仇恨對待你，擄走你的一切辛苦所得，留下你赤身露體，以致你淫亂的下體、你的醜惡和淫行暴露出來。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 6:9; 詩篇 106:35–38; 耶利米書 2:18–20"> 你遭遇這些，是因你隨從列邦行淫，你以他們的偶像玷汙自己。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 21:13; 耶利米書 7:14–15; 以西結書 16:47–51"> 你走了你姐姐的道路，所以我要把她的杯放在你手中。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 51:17; 詩篇 60:3; 以西結書 22:4–5"> 「主耶和華如此說：<br /><span className="pl pl-1">你必喝你姐姐的杯，它又深又廣，</span><br /><span className="pl pl-1">這杯盛滿了譏諷和嘲笑，</span><br /><span className="pl pl-1">容量極大。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 51:17; 耶利米書 25:27; 耶利米書 25:15–16"> <span className="pl pl-1">你將酩酊大醉，充滿悲哀，</span><br /><span className="pl pl-1">這是驚駭、荒涼之杯，</span><br /><span className="pl pl-1">是你姐姐撒瑪利亞的杯。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 75:8; 以賽亞書 51:17; 啟示錄 18:7"> <span className="pl pl-1">你將喝這杯，一滴不剩，</span><br /><span className="pl pl-1">甚至啃舔杯子的碎片，</span><br /><span className="pl pl-1">撕扯自己的乳房。</span><br /><span className="pl pl-1">是的，我已經發了話。</span><br /><span className="pl pl-1">這是主耶和華的宣告。</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:9; 以賽亞書 17:10; 耶利米書 32:33"> 「因此主耶和華如此說：因為你忘記了我，把我撇棄在背後，所以你也必承擔你醜惡之事和你淫行的後果。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西結書 22:2; 以賽亞書 58:1; 以西結書 16:2"> 耶和華又對我說：「人子啊，你要譴責阿荷拉和阿荷利巴嗎？你要向她們指出她們的可憎之事：</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 16:36; 耶利米書 32:35; 耶利米書 7:31"> 她們通姦，並且手中有血債。她們與她們的偶像通姦，還把為我所生的兒女經火獻給偶像為食物。</span>
<span className="v" id="v38" data-v="38" data-xref="以西結書 20:13; 列王紀下 21:7; 以西結書 7:20"> 她們甚至對我做了這樣的事：在同一天玷汙我的聖所，褻瀆我的安息日；</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀下 21:4; 以西結書 44:7; 耶利米書 23:11"> 她們宰殺兒女給她們的偶像，又在同一天進入我的聖所，褻瀆了它。看哪，她們就是這樣在我的殿宇中行事！</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王紀下 9:30; 耶利米書 4:30; 以西結書 16:13–16"> 「她們還派使者去請人從遠方來，使者被派去，看哪，他們就來了。為這些人，你洗澡，塗眼影，佩戴妝飾，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖記 1:6; 耶利米書 44:17; 以賽亞書 65:11"> 坐在華美的床榻上，有桌子擺在床榻前，你把我的香料和膏油放在其上。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 16:11–12; 啟示錄 12:3; 出埃及記 32:18–19"> 那裡傳出安樂喧囂的聲音，有雜亂的人群，從曠野請來的酒徒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="酒徒——或譯作「示巴人」。">b</a></sup>。那些人把鐲子戴在她們手上，把華冠戴在她們頭上。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 23:3; 耶利米書 13:23; 以斯拉記 9:7"> 那時我論到這因通姦而衰殘的婦人說：『她都這樣了，他們還與她犯姦淫！』</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 23:9–13; 以西結書 23:3"> 他們與她同寢，如同與妓女同寢。他們就是這樣與醜惡的女人阿荷拉和阿荷利巴同寢！</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿書 6:5; 利未記 20:10; 以西結書 23:36–39"> 但那些行公義的人，必以淫婦之罪和殺人流血之罪來審判她們；因為她們就是淫婦，並且手中有血債。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以西結書 16:40; 耶利米書 15:4; 耶利米書 24:9"> 是的，主耶和華如此說：「召集隊伍上去攻擊她們吧，使她們成為掠物，令人戰兢。</span>
<span className="v" id="v47" data-v="47" data-xref="以西結書 16:40–41; 耶利米書 39:8; 以西結書 24:21"> 這隊伍將用石頭砸死她們，用刀劍砍殺她們，殺掉她們的兒女，放火燒掉她們的房屋。</span>
<span className="v" id="v48" data-v="48" data-xref="以西結書 6:6; 以西結書 23:27; 以西結書 16:41"> 這樣，我就使醜惡之事從這地上終止，所有的女人都會受到警誡，不會效法你們的淫行。</span>
<span className="v" id="v49" data-v="49" data-xref="以西結書 9:10; 以西結書 7:4; 以西結書 6:7"> 他們將把你們醜惡的事報應在你們身上，你們必承擔你們拜偶像的罪責。那時你們就知道：我是主耶和華。」</span>
</div>

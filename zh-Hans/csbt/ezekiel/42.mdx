<span className="v" id="v1" data-v="1" data-xref="以西結書 40:20; 以西結書 40:17; 以西結書 42:13"> 他把我帶到朝北方向的外院，帶我到空地對面、北邊的建築物對面的一排房間那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 41:13"> 這排房間進深一百肘，寬五十肘，北面有入口。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 41:15–16; 以西結書 41:10; 雅歌 7:5"> 它們對著內院的二十肘空地，也對著外院的鋪石地，三層都是走廊與走廊相對。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 46:19; 路加福音 13:24; 馬太福音 7:14"> 在這些房間前面，朝著內院有一條過道，寬十肘，長一百<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百——依據七十士譯本；馬索拉文本作「一」。">a</a></sup>肘；房間的門口都朝北。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 41:7"> 上層的房間，因為走廊占用了一些地方，就比下層和中層的建築窄小。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 41:6; 列王紀上 6:8"> 它們有三層，並且沒有像外院那樣的柱子，因此從地面往上，上層比下層和中層縮進一些。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 42:12; 以西結書 42:10"> 外面有圍牆，面向這些房間，沿著外院與這些房間平行，長五十肘。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 41:13–14"> 這樣，那些挨著外院的房間進深五十肘，看哪，靠近聖殿的房間有一百肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 46:19; 以西結書 44:5"> 在這些房間下方，東側有個入口，通過它從外院進來。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 42:1; 以西結書 42:13; 以西結書 41:12–15"> 沿著南邊<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南邊——依據七十士譯本；馬索拉文本作「東邊」。">b</a></sup>內院圍牆的橫面，在空地對面、南邊的建築物對面也有一排房間，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 42:4"> 在它們前面有通道，與朝北那些房間的樣式一樣，有同樣的進深和寬；它們所有的出口規格一樣，入口也一樣。</span>
<span className="v" id="v12" data-v="12"> 它們與朝南那些房間的入口一樣，入口在通道的起點；通道朝東，在圍牆的正前面，通過它進入這些房間。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 10:17; 利未記 7:6; 以西結書 40:46"> 那人對我說：「南邊、北邊面向空地的房間，都是聖屋。近前來事奉耶和華的祭司們要在那裡吃至聖物，在那裡放置至聖物，就是素祭、贖罪祭和贖愆祭，因為那地方是分別為聖的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 44:19; 利未記 8:7; 出埃及記 29:4–9"> 祭司們進來事奉後，要把事奉時穿的衣服留在那裡，然後才可以從聖所出去到外院，因為這些衣服是聖物。他們要穿上別的衣服，才可以來到民眾所在的地方。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以西結書 43:1; 以西結書 41:15; 以西結書 40:6–16"> 他測量完了內殿，就帶我往面朝東的門出去，測量聖殿的四圍。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 40:3; 啟示錄 11:1–2; 撒迦利亞書 2:1"> <span className="pl pl-1">他用量竿在東面測量，</span><br /><span className="pl pl-1">按著量竿，是五百竿；</span><br /></span>
<span className="v" id="v17" data-v="17"> <span className="pl pl-1">轉到北面測量，</span><br /><span className="pl pl-1">按著量竿，是五百竿；</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">轉到南面測量，</span><br /><span className="pl pl-1">按著量竿，是五百竿；</span><br /></span>
<span className="v" id="v19" data-v="19"> <span className="pl pl-1">轉到西面測量，</span><br /><span className="pl pl-1">按著量竿，是五百竿。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 45:2; 以西結書 22:26; 以西結書 40:5"> 他這樣沿著四個方向都測量了，四周有圍牆，長五百竿，寬五百竿，為要把聖與俗分別開來。</span>
</div>

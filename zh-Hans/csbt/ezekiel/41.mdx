<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 40:2–3; 以西結書 40:17; 以西結書 41:23"> 他把我帶到了正殿。他測量牆柱，這邊寬六肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六肘——相當於3.2公尺；下同。">a</a></sup>，那邊寬六肘，是牆柱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="牆柱——依據七十士譯本；馬索拉文本作「會幕」。">b</a></sup>的厚度。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 6:17; 歷代志下 3:3; 列王紀上 6:2"> 門口寬十肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十肘——相當於5.3公尺。">c</a></sup>；門口的兩側，這邊五肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五肘——相當於2.7公尺；下同。">d</a></sup>，那邊五肘。他測量正殿，進深四十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="四十肘——相當於21.2公尺。">e</a></sup>，寬二十肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二十肘——相當於10.6公尺；下同。">f</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 40:16"> 他來到內殿，測量門口的牆柱，是兩肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="兩肘——相當於1公尺。">g</a></sup>。門口六肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="六肘——相當於3.2公尺。">h</a></sup>，門口兩側寬七肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="七肘——相當於3.7公尺。">i</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 6:20; 希伯來書 9:3–8; 出埃及記 26:33–34"> 他測量內殿，進深二十肘，寬二十肘，面對著正殿。他對我說：「這是至聖所。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:5–6; 以西結書 42:3–14; 以西結書 41:6–9"> 他又測量聖殿的牆，厚六肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="六肘——相當於3.2公尺。">j</a></sup>；圍繞殿宇四圍的厢房，寬四肘<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="四肘——相當於2.1公尺。">k</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:10; 列王紀上 6:5–6; 以西結書 40:17"> 那些厢房，厢房疊加厢房，有三層，每層三十間；厢房四圍以殿宇的牆坎為支撐，而不是直接以殿宇的牆為支撐。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 6:8; 希伯來書 6:1; 馬太福音 13:32"> 厢房層層加寬，螺旋上升，因為殿宇四圍的層架結構環繞上升。因此屋內越向上越寬，這樣從下層經過中層，抵達上層。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 40:5; 啟示錄 21:16"> 我看見有一個高臺圍繞著殿宇，是厢房的根基，足足高一竿，就是六肘<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="六肘——相當於3.2公尺。">l</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 41:11; 以西結書 42:4; 以西結書 42:1"> 厢房的外牆厚五肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="五肘——相當於2.7公尺；下同。">m</a></sup>；殿宇厢房的旁邊有空隙地，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 40:17"> 就是厢房與庫房之間，寬二十肘<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="二十肘——相當於10.6公尺。">n</a></sup>，圍繞著殿宇的周圍。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 41:9; 以西結書 42:4"> 厢房門口面向那空隙地，一個門口朝北，一個門口向南，有一條五肘寬的走道圍繞著厢房。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 42:1; 以西結書 42:13; 以西結書 41:13–15"> 在西邊，空地前面的建築物寬七十肘<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="七十肘——相當於37.1公尺。">o</a></sup>，長九十肘<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="九十肘——相當於47.7公尺。">p</a></sup>；建築物四圍的牆厚五肘。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 40:47"> 這樣，他測量了聖殿，進深一百肘<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="一百肘——相當於53公尺；下同。">q</a></sup>；空地和那建築物以及它的牆，進深也是一百肘；</span>
<span className="v" id="v14" data-v="14"> 聖殿前面、東面的空地，寬一百肘。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 42:3; 以西結書 42:1; 以西結書 41:12"> 他測量面向後邊空地的建築物，以及這邊和那邊的走廊，進深一百肘。 內部的木頭構造<br />裡面的正殿、院子的門廊、</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 6:4; 以西結書 40:25; 以西結書 40:16"> 門檻、狹窄的窗格和周圍三面對著門檻的走道，四圍都鑲嵌著木板。從地面到窗格——窗格有遮罩——</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 42:15"> 直到門口上方，從聖殿的內部到外部，內外四圍所有的牆上，都照著規格，</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:36; 以西結書 40:16; 以西結書 40:22"> 雕刻著基路伯和棕櫚樹。基路伯與基路伯之間，都間隔著一棵棕櫚樹；每個基路伯有兩張臉，</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 10:14; 以西結書 1:10"> 這邊是人的臉，對著棕櫚樹，那邊是獅子的臉，對著棕櫚樹。整個殿宇四圍都是這樣的雕刻，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 41:18"> 從地面到門口上方，都雕刻著基路伯和棕櫚樹，正殿的牆壁也是如此。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 41:1; 列王紀上 6:33; 以西結書 40:14"> 正殿有方形的門框立柱。至聖所前面有一個物件，形狀像<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="此節或譯作：正殿有方形的門框立柱；內殿前面，樣式與正殿相似。">r</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="瑪拉基書 1:12; 以西結書 23:41; 瑪拉基書 1:7"> 木頭的祭壇，高三肘<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="三肘——相當於1.6公尺。">s</a></sup>，長兩肘<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="兩肘——相當於1公尺。">t</a></sup>，它的凸角、底座和四壁都是木頭的。那人對我說：「這是耶和華面前的桌子。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 6:31–35; 歷代志下 4:22; 以西結書 41:1"> 正殿和內殿都有雙扇門，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:34; 以西結書 40:48"> 各門有兩個門扇，每扇又有兩個折疊的門頁。這一邊門扇有兩個門頁，另一邊門扇也有兩個門頁。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 41:18"> 正殿的門上雕刻著基路伯和棕櫚樹，與雕刻在牆上的一樣。在門廊前面，有向外伸展的木頭廊簷。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 41:16; 以西結書 40:16; 以西結書 41:5"> 門廊兩側的這邊和那邊，都有狹窄的窗格和棕櫚樹的雕飾。殿宇的厢房也有廊簷。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 33:30; 以西結書 33:17; 以西結書 3:11"> 「人子啊，你要告訴你的同胞，對他們說：如果我使刀劍臨到一個地方，那地的民眾從他們中間選取了一個人立為守望者，</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 8:1; 尼希米記 4:20; 尼希米記 4:18"> 這人看見刀劍即將臨到那地，就吹角警誡民眾，</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:13; 使徒行傳 18:6; 耶利米書 6:17"> 凡是聽見號角聲卻不受警誡的，刀劍來除掉了他，他的血債將歸到自己頭上。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 9:19–21; 希伯來書 11:7; 約翰福音 8:39"> 他聽見號角聲，卻不受警誡，他的血債就歸到自己身上；他如果受警誡，就可保全自己的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 3:18–20; 以西結書 33:8–9; 創世記 42:22"> 但那守望者如果看見刀劍即將臨到，卻不吹角，以致民眾未曾被警誡，刀劍就來除掉他們中間某人的性命，這人因自己的罪孽而被除掉了，我卻要從守望者手中追討他的血債。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 3:17–21; 耶利米書 26:2; 以西結書 2:7–8"> 「所以你，人子啊，我已經立你為以色列家的守望者，你從我口中聽到了話語，就要使他們受我的警誡。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 20:26–27; 以西結書 33:6; 以西結書 33:14"> 當我對惡人說『惡人哪，你必定死』，你卻沒有發話警誡惡人離開他的道路，那惡人就會因自己的罪孽而死，我卻要從你手中追討他的血債。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 3:19; 使徒行傳 20:26; 箴言 15:10"> 但如果你警誡了惡人，要他轉離他的道路，他卻不轉離自己的道路，他必因自己的罪孽而死，你卻保全了你的性命。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 49:14; 以西結書 37:11; 以西結書 24:23"> 「人子啊，你要對以色列家說：『你們曾這樣討論說：我們既然有過犯和罪惡，正在因這些而衰亡，我們怎能存活呢？』</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 2:4; 以西結書 18:23; 彼得後書 3:9"> 你要對他們說，這是主耶和華的宣告：我指著我的永生起誓，我所樂意的絕不是惡人死亡，而是惡人轉離他的道路而存活。以色列家啊，回轉吧，轉離你們邪惡的道路！你們何必死亡呢？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 7:14; 以西結書 33:18–19; 羅馬書 3:25"> 「人子啊，你要對你的同胞說：義人的義，在他有過犯的日子裡不能解救他；惡人的惡，在他轉離惡事的日子裡不會使他倒下。義人在他犯罪的日子裡，不能因他先前的義而存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 18:24; 希伯來書 10:38; 以西結書 18:4"> 當我對義人說『你必定存活』，他卻仗著自己的義而行不義，他先前所有的義都不再被提起，他必因所行的不義而死。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 18:27; 耶利米書 18:7–8; 何西阿書 14:1"> 「另外，當我對惡人說『你必定死』，他就轉離自己的罪，實行公正和公義，</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 20:11; 路加福音 19:8; 出埃及記 22:1–4"> 這惡人歸還抵押，償還搶來的東西，按照生命的律例行事，不再行不義，他必定存活，不會死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 43:25; 以西結書 18:22; 彌迦書 7:18–19"> 他所犯的一切罪，都不會被提起；他實行公正和公義，必定存活。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 25:24–26; 以西結書 18:25; 以西結書 18:29"> 「你的同胞說主做事不公平，其實是他們做事不公平。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 33:12–13; 彼得後書 2:20–22; 希伯來書 10:38"> 義人如果轉離自己的義而行不義，他必因這些不義而死；</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 18:27–28; 以西結書 33:14"> 惡人如果轉離自己的惡，實行公正和公義，他必因此而存活。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 16:27; 以西結書 18:25; 以西結書 33:17"> 你們卻說主做事不公平！以色列家啊，我必照著你們各人的行為審判你們。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 1:2; 耶利米書 39:1–8; 列王紀下 25:4"> 在我們被擄後第十二年的十月五日，有個從耶路撒冷逃脫的人來到我這裡，說：「城已經被攻陷了。」</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 1:3; 以西結書 3:26–27; 以西結書 24:26–27"> 那逃脫的人來到的前一天傍晚，耶和華的手已經臨到我了；直到清晨那人來到我這裡，耶和華才開了我的口。我的口開了，我不再啞然無聲。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 33:27; 以賽亞書 51:2; 使徒行傳 7:5"> 「人子啊，以色列地這些廢墟上的居民討論說：『亞伯拉罕一個人的時候，擁有了這地；現在我們有許多人，這地必定賜給我們為產業了。』</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 12:16; 耶利米書 7:9–10; 創世記 9:4"> 因此你要對他們說，主耶和華如此說：你們吃帶血的肉，仰望你們的偶像，殺人流血，你們還能擁有這地嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:40; 彌迦書 2:1–2; 西番雅書 3:3"> 你們依仗自己的刀劍做可憎的事，各人玷汙鄰人的妻子，你們還能擁有這地嗎？</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 13:6; 耶利米書 42:22; 以西結書 39:4"> 「你要對他們說，主耶和華如此說：我指著我的永生起誓，在廢墟中的，必倒在刀下；在田野上的，我要交給野獸吃；在要塞和洞穴裡的，必死於瘟疫。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 7:24; 耶利米書 44:2; 耶利米書 44:6"> 我要使這地荒廢、淒涼，它所誇耀的勢力必消亡，以色列的群山必荒涼，無人經過。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 6:7; 以西結書 36:17–18; 以西結書 22:2–15"> 我因他們所做的一切可憎之事，使這地荒廢、淒涼，那時他們就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 22:16–17; 耶利米書 23:35; 以賽亞書 29:13"> 「至於你，人子啊，你的同胞，就是那些在城牆邊、在家門口談論你的人，他們這人與那人彼此談論說：『來吧，我們聽聽來自耶和華的信息是什麼。』</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 13:22; 詩篇 78:36–37; 雅各書 1:22–24"> 他們來到你這裡，像是民眾到來；坐在你面前，像是我的子民。然而他們聽到你的話語，卻不遵行。他們雖然用嘴巴說出愛情，心裡卻追隨私利。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 6:20; 馬可福音 4:16–17; 約翰福音 5:35"> 看哪，他們看你像是一首情歌，聲音優美，彈得巧妙，但他們聽到你的話語，卻不遵行。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 28:9; 撒母耳記上 3:19–20; 以西結書 2:5"> 看哪，你所說的必應驗！當它應驗時，他們就知道：曾有一位先知在他們中間。」</span>
</div>

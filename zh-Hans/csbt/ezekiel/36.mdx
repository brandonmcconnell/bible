<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 37:4; 以西結書 34:14; 以西結書 37:22"> 「人子啊，你還要向以色列的群山發預言，說：以色列的群山哪，你們要聽耶和華的話語！</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:13; 以西結書 25:3; 以西結書 35:10"> 主耶和華如此說：<br />「因為仇敵論到你們說『啊哈！古老的高地成為我們的產業了』，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米書 18:16"> 所以你要發預言說，主耶和華如此說：正是因四圍的仇敵使你們荒涼，踐踏你們，使你們成為其餘列國的產業，成為人們的笑談和辱罵，</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 34:28; 申命記 11:11; 以西結書 36:6"> 因此以色列的群山哪，你們要聽主耶和華的話語！論到大山、小山，溪谷、山谷，荒涼的廢墟和被遺棄的城鎮，就是被四圍其餘列國所掠奪、所嘲笑的，主耶和華如此說：</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彌迦書 7:8; 以西結書 36:3; 詩篇 137:7"> 「因此主耶和華如此說：我確實在妒火中發了話，責備其餘的列國，以及整個以東！他們滿心幸災樂禍，心存恨惡，把我的土地歸自己為產業，使那裡的牧野成為掠物。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 123:3–4; 以西結書 34:29; 詩篇 74:23"> 因此你要向以色列地發預言，對大山、小山、溪谷、山谷說，主耶和華如此說：看哪，我在妒火和憤怒中發話！因為你們承受了列國的羞辱，</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 20:5; 阿摩司書 1:1–15; 以西結書 20:15"> 所以主耶和華如此說：我舉手起誓，你們四圍的列國也必承受羞辱！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 27:6; 希伯來書 10:37; 以西結書 34:26–29"> 「但你們，以色列的群山哪，你們卻將發出枝條，為我的子民以色列結出果實，因為他們快要回來了。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:11; 何西阿書 2:21–23; 以西結書 36:34"> 看哪，我必幫助你們，眷顧你們，你們將被耕耘、被播種。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 36:33; 耶利米書 33:12; 以西結書 36:37"> 我要使以色列全家的人口在你們上面增多，使城鎮有人居住，廢墟得以重建。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 33:12; 耶利米書 23:5–8; 耶利米書 31:27"> 我要使人和牲畜在你們上面增多，他們必增多、繁衍。我要使你們像先前那樣有人居住，並且比起初更蒙福。那時你們就知道：我是耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 15:7; 以西結書 36:13; 耶利米書 32:44"> 我要引領人，就是我的子民以色列，在你上面行走；他們將擁有你，你必成為他們的繼業，你也絕不再使他們喪掉兒女。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 13:32"> 「主耶和華如此說：因為他們對你說『你是吞噬人的，你使你的國民喪掉兒女』，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 37:25–28; 阿摩司書 9:15; 以賽亞書 60:21"> 因此你必不再吞噬人，不再使你的國民喪掉兒女。這是主耶和華的宣告。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 34:29; 詩篇 89:50; 以西結書 36:6"> 我不再使你聽到列國的羞辱；你不會再承受外邦人的辱罵，也不會再使你的國民喪亡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="喪亡——或譯作「倒下」。">a</a></sup>。這是主耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 2:7; 民數記 35:33–34; 彌迦書 2:10"> 「人子啊，以色列家居住在自己的土地上時，以他們的所作所為玷汙了那地，他們的行為在我眼前好像經期的不潔。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 34:21; 以西結書 7:8; 耶利米哀歌 2:4"> 所以，因他們在那地上殺人流血，以偶像玷汙那地，我就把怒火傾瀉在他們身上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 39:24; 申命記 28:64; 以西結書 5:12"> 我把他們驅散到列國，揚散在各地；我照著他們的所作所為審判了他們。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 2:24; 以賽亞書 52:5; 耶利米書 33:24"> 他們到了所去的列國，就使我的聖名受到褻瀆，因為人們論到他們說：『這些人是耶和華的子民，卻從他的土地被趕出去了！』</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 48:9; 詩篇 74:18; 以西結書 20:9"> 但我顧惜我的聖名，就是以色列家在所去的列國褻瀆的名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 106:8; 以西結書 36:32; 詩篇 115:1–2"> 「因此你要對以色列家說，主耶和華如此說：以色列家啊，我將要做的事不是為了你們，而是為了我的聖名，就是你們在所去的列國褻瀆的名。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 20:41; 以賽亞書 5:16; 以西結書 39:7"> 我被褻瀆的大名，就是在列國中被你們所褻瀆的名，我必使它顯為聖。當我藉著你們在他們眼前顯為聖時，列國就知道：我是耶和華。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西結書 37:21; 以西結書 34:13; 阿摩司書 9:14–15"> 「我要從列國領你們出來，從各地招聚你們，把你們帶回你們的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 10:22; 約翰福音 3:5; 耶利米書 33:8"> 我要把潔淨之水灑在你們身上，你們必得潔淨。我要使你們脫離一切不潔，脫離你們的一切偶像，得以潔淨。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 11:19–20; 詩篇 51:10; 哥林多後書 5:17"> 我要賜給你們一顆新的心，把一個新的靈放在你們裡面。我要從你們肉體中除掉石心，賜給你們肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多書 3:3–6; 希伯來書 13:21; 哥林多前書 3:16"> 我要把我的靈放在你們裡面，使你們遵從我的律例，謹守遵行我的法規。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 31:33; 耶利米書 32:38; 以西結書 37:27"> 你們必住在我所賜給你們祖先的土地上，你們將要作我的子民，我將要作你們的神。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 1:7–9; 馬太福音 1:21; 何西阿書 2:21–23"> 我要把你們從你們的一切不潔中拯救出來，並且傳令五穀，使它們增多，使饑荒不再臨到你們。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 34:27; 約珥書 2:26; 申命記 29:23–28"> 我要使樹木多結果實，田野增多出產，好讓你們在列國中不再因饑荒而遭受羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西結書 6:9; 以西結書 20:43; 尼希米記 9:26–35"> 「那時你們就會想起你們的惡行和不好的行為，並因你們的罪孽和可憎之事而厭惡自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 9:5; 以西結書 36:22; 提摩太後書 1:9"> 你們要知道，我這樣行事不是為了你們。這是主耶和華的宣告。以色列家啊，你們要因自己的行為而抱愧羞慚！</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 58:12; 以西結書 36:10; 耶利米書 33:10"> 「主耶和華如此說：在我使你們得潔淨，脫離一切罪孽的日子裡，我要使城鎮有人居住，廢墟得以重建。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 6:14; 耶利米書 25:9–11; 歷代志下 36:21"> 這荒蕪之地將被耕耘，不再是所有過路人眼中的荒場。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 51:3; 約珥書 2:3; 耶利米書 33:9"> 他們會說：『這荒蕪之地現在就像伊甸園，這些荒廢、荒涼、被拆毀的城現在堅固了，有人居住了！』</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 24:35; 民數記 23:19; 以西結書 17:24"> 那時你們四圍殘留的列邦就知道：是我耶和華重建了這些被拆毀的城，種植了這荒蕪之地。我耶和華發了話，就必成就。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰一書 5:14; 希伯來書 10:21–22; 以西結書 14:3"> 「主耶和華如此說：我必再次接受以色列家求問，給他們成就這事：我要使他們人口增多，如同羊群。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 8:63; 使徒行傳 2:5–11; 約翰福音 10:16"> 荒廢的城鎮必充滿了人群，就像耶路撒冷在各約期充滿了被獻為聖的羊群。那時他們就知道：我是耶和華。」</span>
</div>
</div>

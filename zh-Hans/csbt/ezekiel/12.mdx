<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 4:12; 耶利米書 5:21; 詩篇 78:40"> 「人子啊，你是住在悖逆之家當中，他們有眼可看卻不看，有耳可聽卻不聽；他們實在是悖逆之家！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 36:3; 提摩太後書 2:25; 耶利米書 26:3"> 「所以你，人子啊，你要準備好被擄時的行李，白天使自己在他們眼前被擄走。你要在他們眼前，從自己的地方被擄到別的地方。或許他們會思索，儘管他們是悖逆之家。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:4; 以西結書 12:12; 列王紀下 25:4"> 你要在白天，在他們眼前帶出你的行李，好像帶出被擄時的行李；也要在傍晚，在他們眼前出去，好像被擄走的人。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 25:4; 耶利米書 39:2–4"> 你要在他們眼前挖牆，從牆洞把行李帶出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 4:3; 以賽亞書 8:18; 以西結書 24:24"> 你要在天黑的時候，在他們眼前把行李扛在肩膀上帶出去。你要蒙住臉，使你看不見這地。我已經立你作以色列家的預表。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:18; 以西結書 37:10; 以西結書 37:7"> 我就照著所受的指示去做，白天帶出我的行李，像在被擄時的行李；到了傍晚用手挖牆，天黑的時候將行李扛在肩上，在他們眼前帶出去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 第二天早晨，耶和華的話語臨到我，說：</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 24:19; 以西結書 17:12; 以西結書 20:49"> 「人子啊，以色列家，就是那悖逆之家，他們不是問你在做什麼嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 9:25; 以賽亞書 13:1; 耶利米書 24:8"> 你要對他們說，主耶和華如此說：這默示關乎耶路撒冷的君王，以及在耶路撒冷的以色列全家。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 52:15; 耶利米書 15:2; 耶利米書 52:28–30"> 你要說：『我是你們的預表。我怎樣行事，事情也將怎樣在你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你們——原文直譯「他們」；本節下同。">a</a></sup>身上發生。你們將成為俘虜，被擄去。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:4; 耶利米書 39:4; 以西結書 12:6"> 他們中間的君王必在天黑的時候，肩上扛著行李出去。他們將挖牆，好使他從牆洞出去。他將蒙住自己的臉，使他的眼睛看不見這地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 39:7; 何西阿書 7:12; 以西結書 17:20"> 我要向他張開我的網，他必被我的網羅捉住。我要把他帶到迦勒底人之地巴比倫，他卻不會看見那地，並將死在那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 5:2; 列王紀下 25:4–5; 以西結書 17:21"> 我要把他四圍所有幫助他的，以及他所有的軍隊，都驅散到四方，我還要拔刀追趕他們。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 6:7; 以西結書 12:16; 以西結書 12:20"> 當我把他們驅散到列國、揚散在各地的時候，他們就知道：我是耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 22:8–9; 以西結書 14:22–23; 以西結書 6:8–10"> 但我會使他們中間少數的人從刀劍、饑荒和瘟疫中存留下來，好讓他們在所到的列國中述說自己一切可憎之事。那時他們就知道：我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 詩篇 80:5; 約伯記 3:24"> 「人子啊，你要在戰兢中吃飯，在顫栗和憂慮中喝水。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 7:14; 以西結書 6:6–7; 以西結書 6:14"> 你要對這地的民眾說，論到以色列地耶路撒冷的居民，主耶和華如此說：他們必在憂慮中吃飯，在惶恐中喝水；因為以色列地所充滿的，將因其中所有居民的惡行而被摧毀。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:7; 以賽亞書 7:23–24; 耶利米書 25:9"> 有居民的各城將荒廢，這地將變得荒涼。那時你們就知道：我是耶和華。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 18:2–3; 以西結書 11:3; 以西結書 12:27"> 「人子啊，你們在以色列地怎麼有這樣的俗語，說：<br /><span className="pl pl-1">『日子漫長，異象都消亡』？</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約珥書 2:1; 以西結書 7:5–7; 西番雅書 1:14"> 「因此你要告訴他們，主耶和華如此說：我必使這俗語終止，以色列將不再有人引用它。你卻要對他們說：日子臨近了，一切異象就要應驗了。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 14:13–16; 以西結書 13:23; 撒迦利亞書 13:2–4"> 是的，在以色列家中，必不再有任何虛假的異象和諂媚的占卜。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷書 1:5; 以西結書 12:28; 以賽亞書 55:11"> 我耶和華說出我要說的話，它必成就，不再耽延；悖逆之家啊，它必在你們的年日裡成就！我發了話，必定成就。這是主耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 10:14; 以西結書 12:22; 彼得後書 3:4"> 「人子啊，看哪，以色列家說：『他所見的異象是指著許多年日以後<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以後——輔助詞語。">b</a></sup>，他所說的預言是指著遙遠的時候。』</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 12:23–25; 馬可福音 13:32–37; 帖撒羅尼迦前書 5:2–3"> 因此你要對他們說，主耶和華如此說：我的一切話語都不再耽延，我所說的話必成就。這是主耶和華的宣告。」</span>
</div>
</div>

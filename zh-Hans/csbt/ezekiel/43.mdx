<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 44:1; 以西結書 42:15; 以西結書 46:1"> 他又帶我到一座門，就是朝東的門那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 18:1; 以西結書 11:23; 以賽亞書 6:3"> 看哪，以色列神的榮耀從東而來，他的聲音如同大水的聲音，全地因他的榮耀而發光。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 9:5; 以西結書 9:1; 耶利米書 1:10"> 我所看見的這異象，景象如同從前他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——依據有些古抄本；馬索拉文本作「我」。">a</a></sup>來毀滅這城時我所看見的異象，又如同我在迦巴魯河邊所看見的異象；我就臉伏於地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 10:18–19; 以西結書 44:2; 以西結書 43:2"> 耶和華的榮耀從面朝東的門進入聖殿。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:2–4; 列王紀上 8:10–11; 以西結書 8:3"> 隨後，靈把我舉起，帶到內院，看哪，耶和華的榮耀充滿了聖殿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 40:3; 以賽亞書 66:6; 啟示錄 16:1"> 那人站在我旁邊，我聽見殿宇中有聲音對我說話。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 43:9; 詩篇 47:8; 利未記 26:30"> 那聲音對我說：「人子啊，這是我寶座設立之處，腳凳所在之地。我要居住在這裡，在以色列子民中間，直到永遠。以色列家和他們的君王，再不會以淫行和他們君王的死屍<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="死屍——或譯作「高壇上的石碑」。">b</a></sup>來玷汙我的聖名。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 5:11; 以西結書 8:3–16; 歷代志下 33:7"> 他們曾把自己的門檻與我的門檻放在一起，把自己的門柱立在我的門柱旁邊，他們和我之間只隔一道牆，他們以所做的可憎之事玷汙了我的聖名，所以我在怒氣中消滅他們。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 43:7; 以西結書 37:26–28; 以西結書 18:30–31"> 現在，但願他們從我面前徹底清除他們的淫行和他們君王的屍體，我就居住在他們中間，直到永遠。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 40:4; 以西結書 16:61; 以西結書 16:63"> 「人子啊，你要把這聖殿指示給以色列家，使他們因自己的罪孽而愧疚，讓他們思量聖殿的完美<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="思量聖殿的完美——或譯作「測量聖殿的尺寸」。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 36:27; 以西結書 11:20; 馬太福音 28:20"> 如果他們因自己所做的一切而愧疚，你就把這聖殿的形製，包括構造、出入口等所有的形製，把它所有的規範、所有的形製，以及所有相關的法規，都指示給他們，並在他們眼前記下來，使他們遵照所有的形製和規範去做。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 40:2; 啟示錄 21:27; 詩篇 93:5"> 這聖殿的法規是這樣的：它要在山頂上，四圍地界內全都是至聖的。看哪，這就是聖殿的法規。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 40:5; 出埃及記 27:1–8; 以西結書 41:8"> 「以下是祭壇的尺寸，以肘為標準，這肘是通用的肘加一掌<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="通用的肘加一掌——相當於53公分。1肘=45.7公分；1掌=7.4公分。">d</a></sup>：溝槽深一肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一肘——相當於53公分；下同。">e</a></sup>，寬一肘，四圍起邊高一拃<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一拃——約20公分；表示張開大拇指和中指或小指兩端的距離。">f</a></sup>。祭壇的壇身如下：</span>
<span className="v" id="v14" data-v="14"> 從地面的溝槽到底層的磴臺高兩肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="兩肘——相當於106公分。">g</a></sup>，寬一肘。從小磴臺到大磴臺高四肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="四肘——相當於2.1公尺；下同。">h</a></sup>，寬一肘。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 27:2; 詩篇 118:27; 利未記 9:9"> 祭壇的爐臺高四肘，從爐臺向上有四個犄角。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 27:1; 歷代志下 4:1; 出埃及記 38:1–2"> 爐臺長十二肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="十二肘——相當於6.4公尺；下同。">i</a></sup>，寬十二肘，是四方形的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 20:26; 以西結書 40:6; 出埃及記 25:25"> 磴臺長十四肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="十四肘——相當於7.4公尺；下同。">j</a></sup>，寬十四肘，是四方形的。四圍的起邊有半肘，四圍的溝槽深一肘。臺階朝東。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 40:29; 希伯來書 10:4–12; 以西結書 2:1"> 那聲音又對我說：「人子啊，主耶和華如此說：以下是祭壇造好那天，在其上獻燔祭、灑血的律例。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 40:46; 以西結書 44:15; 民數記 16:40"> 你要把一頭公牛作為贖罪祭交給利未祭司，就是那些近前來事奉我的撒督後裔。這是主耶和華的宣告。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 16:19; 利未記 8:15; 出埃及記 29:12"> 你要取一些公牛的血，抹在祭壇的四個犄角、磴臺的四角和四圍的邊上。這樣，你就潔淨了它，為它行了贖罪禮。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 29:14; 利未記 4:12; 利未記 8:17"> 你要取來那贖罪祭公牛，在聖所外面為聖殿指定的地方燒掉。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 43:25–26; 以西結書 43:20; 彼得前書 1:19"> 「第二天，你要獻上一隻無瑕疵的公山羊作贖罪祭。他們要潔淨祭壇，就像用公牛潔淨祭壇一樣。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:1"> 當你潔淨完了祭壇，要獻上一頭無瑕疵的公牛和羊群中一隻無瑕疵的公綿羊，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 2:13; 馬可福音 9:49–50; 民數記 18:19"> 獻在耶和華面前。祭司們要在其上撒鹽，把牠們獻給耶和華為燔祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:33; 出埃及記 29:35–37; 利未記 8:35"> 一連七天，每天都要這樣準備一隻公山羊為贖罪祭，也要準備一頭公牛和羊群中一隻公綿羊，都是無瑕疵的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 29:24; 利未記 8:34; 出埃及記 32:29"> 一連七天，他們要為祭壇行贖罪禮，潔淨它，使它能承接聖職。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 9:1; 以西結書 20:40–41; 彼得前書 2:5"> 這些日子結束後，從第八天起，祭司們就可以在這祭壇上獻你們的燔祭和平安祭，我必悅納你們。這是主耶和華的宣告。」</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="以西結書 20:1; 以西結書 1:2; 耶利米書 39:2"> 第十一年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第十一年——指約雅斤王被擄之後的第十一年；參《以西結書》1:2。">a</a></sup>正月<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="正月——原文直譯「那個月」；有古抄本作「十一月」。">b</a></sup>一日，耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 23:1–18; 以西結書 36:2; 約珥書 3:4"> 「人子啊，因為提爾對耶路撒冷說『啊哈！這列邦之門已經被摧毀，被我取代了！它荒廢了，我將富足』，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 51:42; 以賽亞書 5:30; 彌迦書 4:11"> 因此主耶和華如此說：提爾啊，看哪，我敵對你！我要使許多國家上來攻打你，就如海洋使波濤湧上來。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 23:11; 阿摩司書 1:10; 以西結書 26:9"> 他們將摧毀提爾的城牆，拆掉它的塔樓。我要刮淨它的塵土，使它成為光禿禿的岩石。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 29:19; 以西結書 27:32; 以西結書 25:7"> 它必在海中成為一個曬網的地方；是的，我已經發了話。這是主耶和華的宣告。它必成為列國的掠物，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 16:46; 以西結書 26:8; 耶利米書 49:2"> 它陸地上的居民必遭刀劍殺戮。那時他們就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 7:12; 但以理書 2:37; 以西結書 23:24"> 「是的，主耶和華如此說：看哪，我要使王中之王巴比倫王尼布甲尼撒從北方來到提爾，帶著馬匹、戰車、馬兵，那是許多民族的軍隊。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 21:22; 耶利米書 52:4; 耶利米書 32:24"> 他將用刀劍殺戮你陸地上的居民，建造高臺、築起土壘攻擊你，舉起盾牌攻擊你，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 26:15"> 架起攻城錘撞擊你的城牆，用武器摧毀你的塔樓。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 26:15; 以西結書 27:28; 耶利米書 47:3"> 他的馬匹成群結隊，揚起塵土遮蔽你。他將進入你的城門，如同進入已攻破的城；那時你的城牆必因馬兵、攻城車和戰車的聲音而震動。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:28; 以賽亞書 26:5; 哈巴谷書 1:8"> 他的馬蹄將踩踏你所有的街道，他的刀劍將殺戮你的居民，你那些穩固的神柱必倒在地上。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 23:8; 歷代志下 32:27; 撒迦利亞書 9:3–4"> 他們將擄掠你的財富，掠奪你的貨物，摧毀你的城牆，拆毀你華美的房屋，把你的石頭、木頭和灰泥拋在水中。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 7:34; 以賽亞書 23:16; 以賽亞書 14:11"> 我要使你歌唱的喧囂止息，你豎琴的聲音不再被聽見。</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 1:4; 約伯記 12:14; 民數記 23:19"> 我要使你成為光禿禿的岩石，你必成為一個曬網的地方。你必不得重建，因為我耶和華已經發了話。這是主耶和華的宣告。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以西結書 27:35; 耶利米書 49:21; 以西結書 26:18"> 「主耶和華對提爾如此說：當你中間遭遇殺戮，受傷的人呻吟時，眾海島難道不會因你傾覆的聲音而震動嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 32:10; 約拿書 3:6; 約伯記 8:22"> 那時所有沿海的君王都將從寶座上下來，脫去外袍，脫下彩衣。他們將以恐慌為衣，坐在地上，時刻戰兢，因你而驚恐。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 14:12; 以西結書 19:1; 撒母耳記下 1:25–27"> 他們將為你吟唱哀歌，對你說：<br /><span className="pl pl-1">『這坐落在海邊，受稱讚的城啊，</span><br /><span className="pl pl-1">你怎麼滅亡了呢？</span><br /><span className="pl pl-1">你曾是海上的強者，</span><br /><span className="pl pl-1">你和你的居民</span><br /><span className="pl pl-1">使其他所有的居民都驚恐。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 26:15; 以賽亞書 23:5–7; 以西結書 27:35"> <span className="pl pl-1">如今眾海島在你傾覆的日子戰兢，</span><br /><span className="pl pl-1">海洋中的眾海島</span><br /><span className="pl pl-1">因你消逝而惶恐。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 8:7–8; 以西結書 26:3; 但以理書 11:40"> 「是的，主耶和華如此說：當我使你的城荒廢，如同無人居住的城鎮，當我使深淵的水漫過你，大水淹沒你時，</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 27:13; 路加福音 10:15; 撒迦利亞書 2:8"> 我要使你與下陰坑的人一起下去，到古時的人那裡。我要使你與下陰坑的人一起居住在地府，就是那從古時就有的廢墟，以致你那裡無人居住，你在活人之地再無榮耀<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你在活人之地再無榮耀——或譯作「我卻要在活人之地賜下榮耀」。">c</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 27:36; 以西結書 28:19; 啟示錄 18:21"> 我使恐怖的事臨到你，你就不復存在了；人尋找你，卻永不再尋見你。這是主耶和華的宣告。」</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 3:14; 以西結書 11:24; 以西結書 11:13"> 靈又把我舉起，帶到耶和華殿朝東的東門。看哪，在門口有二十五個人，我看見其中有阿佐爾的兒子雅撒尼亞、比納雅的兒子皮拉提，他們是民眾的首領。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 30:1; 耶利米書 5:5; 詩篇 2:1–2"> 耶和華對我說：「人子啊，這些就是謀劃奸惡的人，他們在這城中策劃惡謀，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 12:27; 以西結書 12:22; 以西結書 11:7–11"> 說：『建造房屋的時候不是臨近了嗎<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不是臨近了嗎——或譯作「還沒有臨近」。">a</a></sup>？這城是鍋，我們是肉。』</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 20:46–47; 以西結書 21:2; 以西結書 3:2–15"> 因此你要針對他們發預言，人子啊，你要說預言！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 17:10; 耶利米書 16:17; 啟示錄 2:23"> 耶和華的靈降臨在我身上，他對我說：「你要宣告，耶和華如此說：以色列家啊，這就是你們所想的；你們心裡起的意念，我都知道。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 7:23; 以西結書 22:27; 以西結書 22:12"> 你們使這城中被殺的人增多，使街道上遍滿了被殺的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:3–13; 彌迦書 3:2–3; 列王紀下 25:18–22"> 「因此主耶和華如此說：你們所殺害堆放在城中的人，他們才是肉，這城是鍋，而你們卻要從其中被拋出去。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以賽亞書 24:17–18; 約伯記 3:25"> 你們害怕刀劍，我就使刀劍臨到你們。這是主耶和華的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 5:8; 詩篇 106:41; 申命記 28:36"> 我要把你們從其中拋出去，交在外族人手裡；我要對你們施行審判。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 14:25; 耶利米書 52:9–10; 列王紀下 25:19–21"> 你們必倒在刀下，我要在以色列的邊境審判你們。那時你們就知道：我是耶和華。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 11:3; 以西結書 11:7–10"> 這城不會是你們的鍋，你們也不會是其中的肉；我要在以色列的邊境審判你們。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:10; 以西結書 8:16; 以西結書 8:14"> 那時你們就知道：我是耶和華。因為你們不遵從我的律例，不遵行我的法規，反而效法你們四圍列國的習俗。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 11:1; 以西結書 9:8; 使徒行傳 5:5"> 我正說預言的時候，比納雅的兒子皮拉提死了。我就臉伏於地，大聲哀叫說：「唉，主耶和華啊！你要滅絕以色列的餘剩之民嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 33:24; 以賽亞書 65:5; 約翰福音 16:2"> 「人子啊，論到你的兄弟，你的親族兄弟，以及以色列全家所有的人，那些耶路撒冷的居民曾對他們說：『你們遠離耶和華吧！這地已經賜給我們為產業了。』</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 8:14; 申命記 30:3–4; 詩篇 90:1"> 「因此你要說，主耶和華如此說：雖然我把他們遠遠趕到了列國中，雖然我把他們驅散到各地，但我會在他們所到之地作聖所，略微庇護他們。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:25; 耶利米書 3:18; 以西結書 34:13"> 「因此你要說，主耶和華如此說：我必從萬民中招聚你們，把你們從被驅散到的各地聚攏起來，並將以色列地賜給你們。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西結書 37:23; 以西結書 5:11; 以西結書 42:7–8"> 「他們回到那裡時，將從其中除掉一切可憎之物、一切可憎之事。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:26–27; 耶利米書 31:33; 詩篇 51:10"> 我要賜給他們合一的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="合一的——或譯作「專一的」。">b</a></sup>心，把新的靈放在他們裡面；我要從他們肉體中除掉石心，賜給他們肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:11; 詩篇 105:45; 耶利米書 30:22"> 好使他們順從我的律例，謹守遵行我的法規。他們將要作我的子民，我將要作他們的神。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 9:10; 傳道書 11:9; 耶利米書 1:16"> 至於那些心中隨從可憎之物、可憎之事的人，我要把他們的惡行報應在他們頭上。這是主耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:19; 以西結書 1:19–20"> 然後，基路伯揚起了翅膀，輪子都在牠們旁邊，以色列神的榮耀在牠們上方。</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 14:4; 以西結書 8:4; 以西結書 10:4"> 耶和華的榮耀就從城中上升，停留在城東邊的山上。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 3:12; 以西結書 8:3; 以西結書 11:1"> 這時，靈把我舉起，在異象中藉著神的靈把我帶到迦勒底，帶到擄民那裡，我所看見的異象就上升離開了我。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 3:4; 以西結書 3:27; 以西結書 3:17"> 於是，我把耶和華所顯明給我的一切事都告訴了擄民。</span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 13:6; 以西結書 21:12; 約珥書 1:11"> 「人子啊，你要發預言說，主耶和華如此說：<br /><span className="pl pl-1">哀號吧！為那日子悲哀吧！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="俄巴底亞書 1:15; 約珥書 2:1–2; 約珥書 1:15"> <span className="pl pl-1">日子臨近了，</span><br /><span className="pl pl-1">耶和華的日子臨近了；</span><br /><span className="pl pl-1">那是密雲的日子，</span><br /><span className="pl pl-1">也是列國受審判</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="受審判——輔助詞語；同30:9。">a</a></sup><br /><span className="pl pl-1">的時候。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 29:19; 以西結書 29:8; 以賽亞書 16:7"> <span className="pl pl-1">刀劍必臨到埃及，</span><br /><span className="pl pl-1">埃及被殺的人倒下時，</span><br /><span className="pl pl-1">庫實</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="庫實——指埃塞俄比亞。">b</a></sup><br /><span className="pl pl-1">將劇痛。</span><br /><span className="pl pl-1">埃及的財富</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="財富——或譯作「民眾」；下同。">c</a></sup><br /><span className="pl pl-1">將被擄走，</span><br /><span className="pl pl-1">它的根基將被拆毀。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 25:20; 以西結書 27:10; 耶利米書 25:24"> <span className="pl pl-1">庫實人、普特</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="普特——指利比亞。">d</a></sup><br /><span className="pl pl-1">人、呂底亞人、</span><br /><span className="pl pl-1">所有混雜的族群、</span><br /><span className="pl pl-1">古布人以及結盟之地的人，</span><br /><span className="pl pl-1">都將與埃及人一起倒在刀下。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 29:10; 以賽亞書 20:3–6; 以賽亞書 31:3"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">埃及的扶助者們必倒下，</span><br /><span className="pl pl-1">它所誇耀的勢力必敗落；</span><br /><span className="pl pl-1">在埃及境內，從密奪到賽伊尼，</span><br /><span className="pl pl-1">人們必倒在刀下。</span><br /><span className="pl pl-1">這是主耶和華的宣告。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 29:12; 耶利米書 25:18–26; 以西結書 32:18–32"> <span className="pl pl-1">它將成為最荒蕪的土地，</span><br /><span className="pl pl-1">它的城也將成為最荒涼的城鎮。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 29:6; 以西結書 29:16; 阿摩司書 1:7"> <span className="pl pl-1">我必點火焚燒埃及，</span><br /><span className="pl pl-1">所有幫助它的都將被摧毀，</span><br /><span className="pl pl-1">那時他們就知道：我是耶和華。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 18:1–2; 以賽亞書 23:5; 以西結書 32:9–10"> 「在那日，使者們將乘船從我面前出去，使安逸的庫實人戰兢。在埃及受審判的日子裡，劇痛必臨到他們。看哪，這事臨近了！</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 29:19; 以西結書 32:11–16; 以西結書 29:4–5"> <span className="pl pl-1">主耶和華如此說：</span><br /><span className="pl pl-1">我要藉著巴比倫王尼布甲尼撒的手，</span><br /><span className="pl pl-1">除掉埃及的大軍。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 28:7; 以西結書 32:12; 以西結書 39:11–20"> <span className="pl pl-1">他和與他一起的軍兵，</span><br /><span className="pl pl-1">就是列國強橫的人，</span><br /><span className="pl pl-1">必被領來毀滅這地。</span><br /><span className="pl pl-1">他們將拔刀攻擊埃及，</span><br /><span className="pl pl-1">使被殺的人遍滿這地。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 29:3; 那鴻書 1:4; 啟示錄 16:12"> <span className="pl pl-1">我要使江河成為乾地，</span><br /><span className="pl pl-1">並把埃及地交在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="交在——原文直譯「賣到」。">e</a></sup><br /><span className="pl pl-1">惡人手中。</span><br /><span className="pl pl-1">我要藉著外族人的手，</span><br /><span className="pl pl-1">使大地和其上所充滿的都荒蕪。</span><br /><span className="pl pl-1">我耶和華已經發了話。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 10:11; 耶利米書 46:14; 耶利米書 2:16"> <span className="pl pl-1">主耶和華如此說：</span><br /><span className="pl pl-1">我要消滅偶像，</span><br /><span className="pl pl-1">使虛無的偶像從挪弗</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="挪弗——希臘語音譯為「孟斐斯」；下同。">f</a></sup><br /><span className="pl pl-1">絕跡，</span><br /><span className="pl pl-1">埃及地也不再有君王興起；</span><br /><span className="pl pl-1">我要使懼怕臨到埃及地。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 29:14; 耶利米書 46:25; 詩篇 78:43"> <span className="pl pl-1">我要使巴特羅荒涼，</span><br /><span className="pl pl-1">點火焚燒瑣安，</span><br /><span className="pl pl-1">我要對挪城</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="挪城——希臘語音譯為「底比斯」；下同。">g</a></sup><br /><span className="pl pl-1">施行審判。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 16:1; 那鴻書 1:6; 詩篇 11:6"> <span className="pl pl-1">我要向埃及的堡壘訓城傾瀉怒火，</span><br /><span className="pl pl-1">我要剪除挪城的大軍。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 30:8–9; 以西結書 28:18"> <span className="pl pl-1">我要點火焚燒埃及，</span><br /><span className="pl pl-1">訓城必痛苦掙扎，</span><br /><span className="pl pl-1">挪城必被攻破，</span><br /><span className="pl pl-1">挪弗終日遭遇敵人。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 41:45"> <span className="pl pl-1">安城和皮貝塞特的青年人</span><br /><span className="pl pl-1">將倒在刀下，</span><br /><span className="pl pl-1">城裡的人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="城裡的人——或譯作「女人」。">h</a></sup><br /><span className="pl pl-1">將被擄去。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 30:3; 以西結書 29:15; 以賽亞書 10:27"> <span className="pl pl-1">我在塔帕尼斯打斷埃及的軛時，</span><br /><span className="pl pl-1">那裡白天將變為黑暗；</span><br /><span className="pl pl-1">它所誇耀的勢力必在那裡消亡，</span><br /><span className="pl pl-1">密雲將籠罩它，</span><br /><span className="pl pl-1">它的居民將被擄去。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 30:14; 啟示錄 17:1; 以西結書 5:8"> <span className="pl pl-1">我必這樣對埃及施行審判，</span><br /><span className="pl pl-1">那時他們就知道：我是耶和華。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 29:17; 以西結書 26:1; 以西結書 29:1"> 第十一年<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="第十一年——指約雅斤王被擄之後的第十一年；參《以西結書》1:2。">i</a></sup>一月七日，耶和華的話語臨到我，說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 30:13; 耶利米書 46:11; 詩篇 37:17"> 「人子啊，我已打斷埃及王法老的一隻膀臂。看哪，這膀臂沒有包紮敷藥，沒有用繃帶纏裹使它穩固，能握住刀劍。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 37:17; 耶利米書 37:7; 列王紀下 24:7"> 因此主耶和華如此說：看哪，我與埃及王法老敵對，我要把他那有力的和已被打斷的膀臂都折斷，使刀劍從他手中掉落。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 30:26; 以西結書 30:17–18; 以西結書 29:12–13"> 我要把埃及人驅散到列國，揚散在各地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 30:25; 西番雅書 2:12; 以賽亞書 45:5"> 我要扶持巴比倫王的膀臂，把我的刀劍交在他手中；我卻要打斷法老的膀臂，使他像受傷將死的人發哀聲那樣，在巴比倫王面前唉哼。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 29:21; 以西結書 32:15; 以西結書 29:16"> 我扶持巴比倫王的膀臂，法老的膀臂卻要垂落。當我把我的刀劍交在巴比倫王手中，他伸出刀劍攻擊埃及地時，他們就知道：我是耶和華。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 11:42; 以西結書 29:12; 以西結書 30:23"> 我必把埃及人驅散到列國，揚散在各地。那時他們就知道：我是耶和華。」</span>

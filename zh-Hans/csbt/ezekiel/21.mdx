<span className="v" id="v5" data-v="5" data-xref="以西結書 21:30; 那鴻書 1:9; 撒母耳記上 3:12"> 那時，一切有血肉的就知道：我耶和華已經拔刀出鞘，這刀必不再入鞘。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 22:4; 以西結書 6:11; 耶利米書 19:10"> 「人子啊，你要哀鳴，在他們眼前肝腸寸斷地痛苦哀鳴。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 7:17; 以西結書 7:26; 以賽亞書 13:7"> 當他們問你為什麼哀鳴時，你要說：是因為即將來臨的消息。所有的心都將消融，所有的手都將發軟，所有的靈都將昏沉，所有的膝蓋都將癱軟如水。看哪，它即將來臨，必然發生！這是主耶和華的宣告。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 34:5–6; 以西結書 21:28; 以西結書 21:3"> 「人子啊，你要發預言說，主如此說：<br /><span className="pl pl-1">刀劍！刀劍已經磨利，</span><br /><span className="pl pl-1">並且磨亮；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 110:5–6; 以西結書 20:47; 以西結書 21:25–27"> <span className="pl pl-1">它磨利是要行殺戮，</span><br /><span className="pl pl-1">磨亮是要像閃電！</span><br /><span className="pl pl-1">這刀劍藐視我兒的權杖和一切木杖</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這刀劍藐視我兒的權杖和一切木杖——或譯作「我兒啊，一個木杖藐視所有的樹木」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">我們還能歡喜嗎？</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 21:19; 耶利米書 25:33; 耶利米書 51:20–23"> <span className="pl pl-1">它已經交給人磨亮了，</span><br /><span className="pl pl-1">可以握在手掌中。</span><br /><span className="pl pl-1">這刀劍已經磨利，</span><br /><span className="pl pl-1">已經磨亮，</span><br /><span className="pl pl-1">可以交在殺戮者手中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以西結書 21:6; 約珥書 1:13; 以西結書 21:14"> <span className="pl pl-1">人子啊，你呼叫、哀號吧！</span><br /><span className="pl pl-1">這刀劍必臨到我的子民，</span><br /><span className="pl pl-1">臨到以色列所有的領袖，</span><br /><span className="pl pl-1">他們將與我的子民一起</span><br /><span className="pl pl-1">被拋在刀劍之下。</span><br /><span className="pl pl-1">所以你拍腿嘆息吧！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 21:10; 哥林多後書 8:2; 以西結書 21:25"> <span className="pl pl-1">這的確是個試煉：</span><br /><span className="pl pl-1">如果連它藐視的權杖都不復存在，</span><br /><span className="pl pl-1">情況會怎樣呢？</span><br /><span className="pl pl-1">這是主耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 24:1; 民數記 24:10; 利未記 26:24"> <span className="pl pl-1">人子啊，你要發預言，</span><br /><span className="pl pl-1">要擊掌奮起</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="擊掌奮起——原文直譯「拍打雙手」；下同。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">讓刀反覆揮動三次！</span><br /><span className="pl pl-1">這是屠殺的刀劍，</span><br /><span className="pl pl-1">大屠殺的刀劍必圍住他們，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 21:10; 耶利米書 17:27; 以西結書 21:22"> <span className="pl pl-1">好讓他們心融膽喪，</span><br /><span className="pl pl-1">許多人仆倒。</span><br /><span className="pl pl-1">在他們各城門旁邊，</span><br /><span className="pl pl-1">我都指派了殺戮的刀劍。</span><br /><span className="pl pl-1">哀哉！</span><br /><span className="pl pl-1">這刀劍造得像閃電，</span><br /><span className="pl pl-1">鋒快要屠殺。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 21:20; 以西結書 21:4; 以西結書 14:17"> <span className="pl pl-1">刀劍哪，</span><br /><span className="pl pl-1">向右衝殺！向左揮去！</span><br /><span className="pl pl-1">你必所向披靡！</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 5:13; 以西結書 21:14; 撒迦利亞書 6:8"> <span className="pl pl-1">我也要擊掌奮起，</span><br /><span className="pl pl-1">使我的怒火平息。</span><br /><span className="pl pl-1">我耶和華已經發了話。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 4:1–3; 耶利米書 1:10; 以西結書 5:1–17"> 「人子啊，你要設定兩條道路，好讓巴比倫王的刀劍前來。這兩條路要從同一個地方分出來；你還要設置一個路標，設置在通往城市的路口。</span>
<span className="v" id="v20" data-v="20" data-xref="阿摩司書 1:14; 耶利米書 49:2; 以西結書 25:5"> 你要設定道路，好讓刀劍前往亞捫人的拉巴，或者前往猶大的堅固城耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 18:20; 箴言 16:33; 士師記 17:5"> 因為巴比倫王站在岔路口，在兩條路的起點占卜。他將搖晃箭矢，求問家族神像，察看祭物的肝臟。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 4:2; 以西結書 26:9; 耶利米書 51:14"> 他右手中所得的占卜是『耶路撒冷』，要讓他架設攻城錘，開口喊殺，揚聲吶喊，架設攻城錘攻打各城門，築起土壘，建造高臺。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 5:15; 以西結書 21:24; 以西結書 29:16"> 在那些曾向巴比倫王起誓臣服的人眼中，這好像是虛假的占卜，但巴比倫王必使他們的罪孽被記起，以致他們被捉住。</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="何西阿書 4:2; 彌迦書 3:10–12; 耶利米書 3:2"> 「因此主耶和華如此說：因為你們的過犯被揭露，使自己的罪孽被記起，以致你們在一切行為上的罪惡被顯明出來——你們既然使自己被記起，就必被人下手捉住。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 35:5; 以西結書 21:29; 以西結書 17:19"> <span className="pl pl-1">至於你這敗壞的惡人，</span><br /><span className="pl pl-1">以色列的領袖啊，</span><br /><span className="pl pl-1">你的日子來到了，</span><br /><span className="pl pl-1">那是最終受懲罰的時候！</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 17:24; 詩篇 75:7; 耶利米書 13:18"> <span className="pl pl-1">主耶和華如此說：</span><br /><span className="pl pl-1">除掉頂冠！取下王冠！</span><br /><span className="pl pl-1">這不是從前了。</span><br /><span className="pl pl-1">卑微人要升高，</span><br /><span className="pl pl-1">高位者要降卑！</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 5:2; 耶利米書 23:5–6; 撒迦利亞書 9:9"> <span className="pl pl-1">覆滅！覆滅！覆滅！</span><br /><span className="pl pl-1">我要命定這事。</span><br /><span className="pl pl-1">這國將不復存在，</span><br /><span className="pl pl-1">直到配得審判權的那一位來到，</span><br /><span className="pl pl-1">我要把國度賜給他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="以西結書 21:20; 以西結書 21:9–10; 西番雅書 2:8–10"> 「人子啊，你要發預言說『論到亞捫人和他們的辱罵，主耶和華如此說』。你要說：<br /><span className="pl pl-1">刀劍！有一把刀劍，</span><br /><span className="pl pl-1">拔出要殺戮，</span><br /><span className="pl pl-1">磨亮要吞滅，為要快如閃電——</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 21:25; 以西結書 22:28; 詩篇 37:13"> <span className="pl pl-1">雖然他們為你見虛假的異象，</span><br /><span className="pl pl-1">為你行虛謊的占卜，</span><br /><span className="pl pl-1">但你必砍在那些敗壞的惡人脖子上。</span><br /><span className="pl pl-1">他們的日子來到了，</span><br /><span className="pl pl-1">那是最終受懲罰的時候！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="以西結書 16:38; 創世記 15:14; 耶利米書 47:6–7"> <span className="pl pl-1">你回到鞘中吧！</span><br /><span className="pl pl-1">我必在你受造之處，</span><br /><span className="pl pl-1">在你起源之地審判你。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="那鴻書 1:6; 耶利米書 6:22–23; 以西結書 14:19"> <span className="pl pl-1">我要向你傾瀉我的憤怒，</span><br /><span className="pl pl-1">把我盛怒的火吹向你，</span><br /><span className="pl pl-1">把你交在善於殺戮的野蠻人手中。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 25:10; 瑪拉基書 4:1; 以西結書 20:47–48"> <span className="pl pl-1">你將成為火中的燃料，</span><br /><span className="pl pl-1">你的血將傾灑在國土中。</span><br /><span className="pl pl-1">你必不再被記念，</span><br /><span className="pl pl-1">因為我耶和華已經發了話。」</span></span>

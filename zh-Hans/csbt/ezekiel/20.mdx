<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 30:20; 以西結書 24:1"> 第七年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第七年——指約雅斤王被擄之後的第七年；參《以西結書》1:2。">a</a></sup>五月十日，以色列的長老中有些人來求問耶和華，他們坐在我面前。</span>
<span className="v" id="v2" data-v="2"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 馬太福音 15:8–9; 詩篇 50:15–21"> 「人子啊，你要告訴以色列的長老，對他們說，主耶和華如此說：你們來是要求問我嗎？我指著我的永生起誓：我絕不讓你們求問。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西結書 22:2; 以西結書 23:36; 以西結書 14:20"> 「你要譴責他們嗎？人子啊，你要譴責他們嗎？你要讓他們知道他們祖先的可憎之事！</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:6; 以西結書 20:15; 出埃及記 3:8"> 你要對他們說，主耶和華如此說：我在揀選以色列的日子，曾向雅各家的後裔舉手起誓；那時我在埃及地向他們顯現，向他們舉手起誓說：『我是耶和華你們的神。』</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 3:8; 耶利米書 32:22; 以西結書 20:15"> 在那日，我向他們舉手起誓要把他們從埃及地領出來，進入我為他們探察的流奶與蜜之地，它是全地中最美的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 18:3; 以西結書 20:8; 利未記 11:44"> 我對他們說：『你們各人要扔掉自己愛慕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="愛慕——原文直譯「眼中」；下同。">b</a></sup>的可憎之物，不要以埃及的偶像玷汙自己。我是耶和華你們的神。』</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 20:7; 以賽亞書 63:10; 以西結書 20:21"> 「但是他們悖逆我，不肯聽從我，不扔掉他們各人愛慕的可憎之物，不離棄埃及的偶像。我就說，我要向他們傾瀉我的怒火，在埃及地對他們發盡我的怒氣。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 39:7; 以西結書 20:22; 出埃及記 32:12"> 然而我為我的名行事，免得我的名在他們所住的列邦眼前被褻瀆，因我曾在列邦眼前向他們顯現，為要把他們從埃及地領出來。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 15:22; 出埃及記 13:17–18; 出埃及記 14:17–22"> 「這樣，我把他們從埃及地領出來，帶到曠野。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 10:5; 利未記 18:5; 申命記 4:8"> 我把我的律例賜給他們，把我的法規告訴他們——人若遵行這些，就必因此而活。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 20:20; 以西結書 37:28; 利未記 21:23"> 我還把我的安息日賜給他們，作為我和他們之間的記號，使他們知道：我是把他們分別為聖的耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 20:21; 以西結書 20:8; 以賽亞書 56:6"> 「但是以色列家在曠野中悖逆我，不順從我的律例，厭棄我的法規——人若遵行這些，就必因此而活——他們極大地褻瀆了我的安息日。我就說，我要向他們傾瀉怒火，在曠野滅絕他們。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 20:9; 以西結書 36:22–23; 以西結書 20:22"> 然而我為我的名克制<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="克制——輔助詞語。">c</a></sup>行事，免得我的名在列邦眼前被褻瀆，因我曾在列邦眼前把他們領出來。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 95:11; 詩篇 106:26; 希伯來書 3:18"> 不過我在曠野中向他們舉手起誓，不再領他們進入我所賜給他們的流奶與蜜之地，它是全地中最美的。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 15:39; 以西結書 20:8; 以西結書 14:3–4"> 這是因為他們厭棄我的法規，不順從我的律例，褻瀆我的安息日，他們的心執意追隨自己的偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 11:13; 耶利米書 4:27; 耶利米書 5:18"> 然而我還是眼中顧惜他們，沒有毀滅他們，沒有在曠野滅絕他們。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 1:2–4; 詩篇 78:6–8; 彼得前書 1:18"> 「我在曠野中對他們的兒女說：『不要隨從你們祖先的定例，不要遵守他們的規條，也不要以他們的偶像玷汙自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:27; 申命記 5:32–8; 以西結書 37:24"> 我是耶和華你們的神，你們要順從我的律例，謹守遵行我的法規。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 58:13; 耶利米書 17:22; 出埃及記 31:13–17"> 你們要把我的安息日尊為聖，好讓這安息日在我和你們之間作記號，使你們知道：我是耶和華你們的神。』</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 20:13; 民數記 21:5; 以西結書 20:8"> 「但是這些兒女悖逆我，不順從我的律例，不謹守遵行我的法規——人若遵行這些，就必因此而活——他們褻瀆了我的安息日。我就說，我要向他們傾瀉怒火，在曠野對他們發盡我的怒氣。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:14; 以西結書 20:9; 耶利米書 14:21"> 然而我為我的名克制<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="克制——原文直譯「收回我的手」。">d</a></sup>行事，免得我的名在列邦眼前被褻瀆，因我曾在列邦眼前把以色列人領出來。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 26:33; 申命記 28:64–68; 申命記 32:26–27"> 不過我在曠野中向他們舉手起誓，要把他們驅散到列國，揚散在各地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 20:16; 以西結書 6:9; 阿摩司書 2:4"> 這是因為他們不遵行我的法規，厭棄我的律例，褻瀆我的安息日，他們的眼目追隨他們祖先的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:12; 以賽亞書 66:4; 以西結書 20:39"> 因此我也任憑他們有無益的定例，有不能使人存活的規條。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 6:7; 利未記 18:21; 以西結書 20:31"> 因著他們使各人的頭生子經火，我就任憑他們因這些供物而不潔，為要摧毀他們，使他們知道我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="羅馬書 2:24; 以西結書 2:7; 以西結書 3:11"> 「因此，人子啊，你要向以色列家說話，要對他們說，主耶和華如此說：你們的祖先一再對我行事不忠，這樣褻瀆我！</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 6:13; 尼希米記 9:22–26; 耶利米書 3:6"> 我把他們帶進了我舉手起誓要賜給他們的那地，而他們看見各高丘、各種茂盛的樹，就在那裡獻祭，在那裡奉上惹怒我的祭品，獻上馨香之氣，又澆奠酒祭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 16:24–25; 以西結書 16:31"> 我就對他們說：『你們去的高壇叫什麼呢？』於是那高壇的名字被稱為『巴麻』，直到今天。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 16:12; 耶利米書 7:26; 士師記 2:19"> 「因此你要對以色列家說，主耶和華如此說：你們要繼續照著你們祖先所行的玷汙自己，繼續追隨他們的可憎之物行淫嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 20:26; 詩篇 106:37–39; 耶利米書 7:31"> 你們獻上供物，使你們的兒女經火；你們以各樣的偶像玷汙自己，直到今天。以色列家啊，我能讓你們求問我嗎？這是主耶和華的宣告：我指著我的永生起誓，我絕不讓你們求問我！</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西結書 11:5; 耶利米書 44:17; 詩篇 139:2"> 「你們說『我們要像列邦，像地上的各族那樣，去事奉木頭和石頭』，你們靈裡所起的這意念，絕不會實現。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 21:5; 以西結書 8:18; 耶利米書 44:6"> 這是主耶和華的宣告：我指著我的永生起誓，我必用大能的手和伸出的膀臂，以及傾瀉的怒火統治你們。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 20:38; 阿摩司書 9:9–10; 以西結書 34:16"> 我要把你們從萬民中帶出來，用大能的手和伸出的膀臂，以及傾瀉的憤怒，把你們從被驅散到的各地招聚起來，</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿書 2:14; 耶利米書 2:35; 以西結書 17:20"> 帶到萬民的曠野，在那裡面對面審判你們。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前書 10:5–10; 民數記 11:1–35; 以西結書 20:13"> 我怎樣在埃及地的曠野審判你們的祖先，也必怎樣審判你們。這是主耶和華的宣告。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 33:13; 利未記 27:32; 馬太福音 25:32–33"> 我要使你們從杖下經過，使你們受到誓約的管束。</span>
<span className="v" id="v38" data-v="38" data-xref="以西結書 13:9; 阿摩司書 9:9–10; 詩篇 95:11"> 我要從你們中間除盡那些背叛我、悖逆我的人；我要把他們從寄居之地帶出來，他們卻不得進入以色列地。那時你們就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="何西阿書 4:17; 以賽亞書 1:13–15; 以西結書 43:7"> 「你們以色列家啊，主耶和華如此說：你們各人去服事自己的偶像吧！但以後你們必定聽從我<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你們各人去服事自己的偶像吧！但以後你們必定聽從我——或譯作「既然你們不願聽從我，你們各人去服事自己的偶像吧」。">e</a></sup>，不會再以你們的供物和偶像褻瀆我的聖名。</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 56:7; 瑪拉基書 3:4; 以賽亞書 60:7"> 這是主耶和華的宣告：以色列全家必在我的聖山，就是以色列的高山上，在那地服事我。我要在那裡悅納你們，在那裡收取你們的供物和最好的供獻，連同你們的一切聖物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 28:25; 以西結書 11:17; 以西結書 38:23"> 當我把你們從萬民中領出來，從被驅散到的各地招聚起來時，我要悅納你們如馨香之氣，我要藉著你們在列邦眼前顯為聖。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 34:13; 以西結書 38:23; 以西結書 36:23–24"> 當我把你們帶進以色列地，就是我曾舉手起誓賜給你們祖先的那地時，你們就知道：我是耶和華。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 6:9; 何西阿書 5:15; 耶利米書 31:18"> 你們在那裡回想你們玷汙自己的一切所作所為，就會因所做的一切惡事而厭惡自己。</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 24:24; 詩篇 115:1; 以西結書 20:9"> 以色列家啊，當我為我名的緣故行事，不照著你們的惡行和敗壞行為對待你們，那時你們就知道：我是耶和華。這是主耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45"> <sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="此節至20:49在馬索拉文本為21:1至21:5。">f</a></sup>耶和華的話語又臨到我，說：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司書 7:16; 以西結書 21:2; 耶利米書 13:19"> 「人子啊，你要面向南方，向南方傳道，針對南地<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="南地——音譯作「內蓋夫」；下同。">g</a></sup>田野的樹林發預言。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米書 21:14; 以賽亞書 24:1–6; 以西結書 17:24"> 你要對南地的樹林說：請聽耶和華的話語！主耶和華如此說：看哪，我必在你中間點火，吞噬你中間一切青綠的樹和一切枯乾的樹。熾烈的火焰無法撲滅，從南到北整個地面<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="整個地面——或譯作「人們的臉」。">h</a></sup>都將被燒焦。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 40:2–3; 耶利米書 7:20; 申命記 29:24–28"> 一切有血肉的都將看到：是我耶和華點著了火，這火無法撲滅。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="約翰福音 16:25; 使徒行傳 17:18; 以西結書 17:2"> 於是我說：「唉，主耶和華啊！他們都議論我說：『他不就是設個比喻嗎？』」</span>
</div>

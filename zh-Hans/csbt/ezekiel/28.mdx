<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 28:9; 帖撒羅尼迦後書 2:4; 以賽亞書 14:13–14"> 「人子啊，你要對提爾的君王說，主耶和華如此說：<br /><span className="pl pl-1">你心裡高傲，說『我是神，</span><br /><span className="pl pl-1">我在海洋中心坐在神的座位上』；</span><br /><span className="pl pl-1">其實你不過是人，不是神，</span><br /><span className="pl pl-1">卻把自己的心智比作神的心智。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 1:20; 但以理書 2:22; 但以理書 2:27–28"> <span className="pl pl-1">看哪，</span><br /><span className="pl pl-1">你自以為</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自以為——輔助詞語。">a</a></sup><br /><span className="pl pl-1">比但以理還有智慧，</span><br /><span className="pl pl-1">任何隱祕事都瞞不住你；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:17–18; 箴言 23:4–5; 箴言 18:11"> <span className="pl pl-1">你靠著自己的智慧和聰慧</span><br /><span className="pl pl-1">獲取財富，</span><br /><span className="pl pl-1">獲取金銀收在你的寶庫裡；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 62:10; 詩篇 52:7; 以西結書 28:2"> <span className="pl pl-1">你靠著自己眾多的智慧，</span><br /><span className="pl pl-1">靠著你的貿易增多了財富，</span><br /><span className="pl pl-1">就因自己的財富而心裡高傲。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西結書 28:2; 出埃及記 9:17; 雅各書 1:11"> 「因此主耶和華如此說：<br /><span className="pl pl-1">因為你把自己的心智比作神的心智，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 31:12; 以西結書 32:12; 以西結書 30:11"> <span className="pl pl-1">所以看哪，</span><br /><span className="pl pl-1">我必帶來外族人攻擊你，</span><br /><span className="pl pl-1">他們是列國強橫的人。</span><br /><span className="pl pl-1">他們將拔刀</span><br /><span className="pl pl-1">攻擊你靠著智慧而得的榮美，</span><br /><span className="pl pl-1">折損你的光彩。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 27:26–27; 以西結書 27:34; 箴言 1:12"> <span className="pl pl-1">他們將使你下入陰坑，</span><br /><span className="pl pl-1">你必像被屠殺之人那樣，</span><br /><span className="pl pl-1">死在海洋中心。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:2; 以賽亞書 31:3; 詩篇 82:7"> <span className="pl pl-1">在殺你的人面前，</span><br /><span className="pl pl-1">你還能說『我是神』嗎？</span><br /><span className="pl pl-1">在那些刺透你的人手中，</span><br /><span className="pl pl-1">你不過是人，不是神！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 31:18; 以西結書 32:19; 腓立比書 3:3"> <span className="pl pl-1">你必像未受割禮之人死亡那樣，</span><br /><span className="pl pl-1">死在外族人手中。</span><br /><span className="pl pl-1">是的，我已經發了話。</span><br /><span className="pl pl-1">這是主耶和華的宣告。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 19:1; 以西結書 26:17; 哥林多後書 1:22"> 「人子啊，你要為提爾王吟唱哀歌，對他說，主耶和華如此說：<br /><span className="pl pl-1">你曾是完美的典範</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="典範——原文直譯「印章」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">充滿智慧，全然美麗。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:15; 創世記 2:8; 以西結書 27:16"> <span className="pl pl-1">你在神的伊甸園中，</span><br /><span className="pl pl-1">以各樣的寶石為妝飾，</span><br /><span className="pl pl-1">有紅寶石、黃玉和鑽石，</span><br /><span className="pl pl-1">黃水晶、紅瑪瑙和碧玉，</span><br /><span className="pl pl-1">藍寶石、綠松石和綠寶石；</span><br /><span className="pl pl-1">你身上的衣襟和花邊，</span><br /><span className="pl pl-1">是金線的工藝</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="衣襟和花邊，是金線的工藝——或譯作「鈴鐺和短笛，是金子製成的」。">c</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">這些都在你受造的日子裡預備好了。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 14:12–15; 出埃及記 30:26; 以西結書 28:13"> <span className="pl pl-1">你曾是受膏的基路伯，</span><br /><span className="pl pl-1">是守護者，</span><br /><span className="pl pl-1">我設立了你。</span><br /><span className="pl pl-1">你在神的聖山上，</span><br /><span className="pl pl-1">在發出火焰的寶石之間往來。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:4; 以西結書 28:17–18; 羅馬書 7:9"> <span className="pl pl-1">你從受造的日子起就行為純全，</span><br /><span className="pl pl-1">直到在你裡面發現了不義。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 6:9–10; 哈巴谷書 2:8; 哈巴谷書 2:17"> <span className="pl pl-1">因你的貿易眾多，</span><br /><span className="pl pl-1">你裡面就充滿了惡行。</span><br /><span className="pl pl-1">你犯了罪，</span><br /><span className="pl pl-1">所以我折辱你，從神的山驅除你；</span><br /><span className="pl pl-1">守護者基路伯啊，</span><br /><span className="pl pl-1">我把你從發出烈火的寶石之間除滅。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:5; 以西結書 31:10; 雅各書 4:6"> <span className="pl pl-1">你因你的美麗而心裡高傲，</span><br /><span className="pl pl-1">因你的光彩而泯滅了智慧。</span><br /><span className="pl pl-1">我把你拋在地上，</span><br /><span className="pl pl-1">展示在君王們面前。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 4:3; 啟示錄 18:8; 阿摩司書 1:9–10"> <span className="pl pl-1">由於你的罪孽眾多，</span><br /><span className="pl pl-1">因你的貿易不義，</span><br /><span className="pl pl-1">你褻瀆了你的聖所。</span><br /><span className="pl pl-1">所以我使火從你中間發出，吞噬你；</span><br /><span className="pl pl-1">我使你在所有觀看你的人眼前，</span><br /><span className="pl pl-1">成為地上的灰燼。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 26:21; 啟示錄 18:21; 啟示錄 18:15–19"> <span className="pl pl-1">各民族中凡是認識你的，</span><br /><span className="pl pl-1">都因你而驚恐。</span><br /><span className="pl pl-1">你遭遇了恐怖的事，</span><br /><span className="pl pl-1">將不復存在，直到永遠。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 6:2; 創世記 10:15; 耶利米書 25:22"> 「人子啊，你要面向西頓，針對它發預言。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 39:13; 出埃及記 14:17; 以西結書 20:41"> 你要說，主耶和華如此說：<br /><span className="pl pl-1">西頓啊，看哪，我敵對你！</span><br /><span className="pl pl-1">我要在你中間得榮耀。</span><br /><span className="pl pl-1">我要在它中間施行審判，</span><br /><span className="pl pl-1">藉著它顯為聖，</span><br /><span className="pl pl-1">那時他們就知道：我是耶和華。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 38:22; 以西結書 26:6; 以西結書 25:11"> <span className="pl pl-1">我要使瘟疫降到它中間，</span><br /><span className="pl pl-1">使殺戮遍布它的街道；</span><br /><span className="pl pl-1">刀劍從四圍攻擊它，</span><br /><span className="pl pl-1">以致被殺的人倒在它中間。</span><br /><span className="pl pl-1">那時他們就知道：我是耶和華。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 33:55; 約書亞記 23:13; 哥林多後書 12:7"> 「四圍所有侮慢以色列家的人，再不會作傷害他們的刺草和扎傷他們的荊棘。那時他們就知道：我是主耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米書 32:37; 以西結書 20:41; 以西結書 36:28"> 「主耶和華如此說：當我把以色列家從他們被驅散到的萬民中招聚起來時，我就藉著他們在列國眼前顯為聖。他們必居住在自己的土地上，那是我賜給我僕人雅各的。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 28:24; 以西結書 28:22; 耶利米書 32:15"> 他們將在這地安然居住，建造房屋，栽種葡萄園。當我向四圍所有侮慢他們的人施行審判時，他們必安然居住。那時他們就知道：我是耶和華他們的神。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 43:1; 以西結書 40:17; 以西結書 42:14"> 那人又把我帶回到聖所外面朝東的門，門是關著的。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 43:2–4; 出埃及記 24:10; 以賽亞書 6:1–5"> 耶和華對我說：「這門必須關著，不可打開。誰也不可從它進入，因為以色列的神耶和華已經從它進入，所以它必須關著。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 46:2; 以西結書 34:24; 以西結書 37:25"> 至於君王，唯獨君王可以坐在裡面，在耶和華面前吃飯。他要從這門廊的通道進入，也要從它的通道出來。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:28; 啟示錄 1:17; 以西結書 3:23"> 他又帶我經由北門來到殿宇前。我觀看，看哪，耶和華的榮耀充滿了耶和華的殿，我就臉伏於地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 40:4; 以西結書 43:10–11; 申命記 12:32"> 耶和華對我說：「人子啊，我要把耶和華殿所有的律例和律法都告訴你，你要留意，要用眼看、用耳聽，並要留意殿宇入口和聖所各出口的規定<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的規定——輔助詞語。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 3:9; 以西結書 45:9; 彼得前書 4:3"> 「你要對悖逆的以色列家說，主耶和華如此說：以色列家啊，你們行一切可憎之事已經夠多了！</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 22:25; 耶利米書 9:26; 以西結書 44:9"> 你們獻上我的食物——脂油和血時，竟然把那些心未受割禮、身體也未受割禮的外邦人帶進我的聖所，以致褻瀆我的殿宇；你們以你們的一切可憎之事，違背了我的約。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 44:14; 民數記 18:3–5; 以西結書 40:45–46"> 你們沒有為我的聖物謹守職責，卻安排外人在我的聖所代替你們值守！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約珥書 3:17; 以西結書 44:7; 撒迦利亞書 14:21"> 「主耶和華如此說：所有心未受割禮、身體也未受割禮的外邦人，包括所有在以色列子民中間的外邦人，都不可進入我的聖所。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 22:26; 以西結書 48:11; 列王紀下 23:8–9"> 至於那些利未人，他們在以色列迷失的時候也遠離了我，他們竟迷失離開我，追隨自己的偶像，所以他們必承擔自己的罪孽。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 16:9; 歷代志下 29:34; 歷代志下 30:17"> 然而他們將在我的聖所作僕役，看守聖殿各門，在聖殿裡作僕役。他們要為民眾宰殺燔祭牲和其他祭物，要侍立在他們面前，侍候他們。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:10–16; 詩篇 106:26; 以西結書 14:3–4"> 因為他們曾在民眾的偶像面前侍候民眾，成了絆腳石，導致以色列家犯罪，因此我針對他們舉手起誓：他們必承擔自己的罪孽。這是主耶和華的宣告。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 18:3; 列王紀下 23:9; 以西結書 16:61"> 他們不可近前來作我的祭司，也不可接近我的任何聖物和至聖物；他們要承受自己的羞辱，承擔他們所做可憎之事的後果。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 23:28–32; 民數記 18:4"> 不過我要讓他們謹守聖殿的職責，負責聖殿的所有勞役，以及其中要做的一切事務。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 10:8; 以西結書 48:11; 以西結書 44:7"> 「但撒督的子孫，就是那些利未祭司，當以色列子民迷失離開我時，他們在我的聖所謹守職責，所以他們必近前來事奉我，侍立在我面前，把脂油和血獻給我。這是主耶和華的宣告。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 41:22; 瑪拉基書 1:12; 民數記 18:7–8"> 唯獨他們可以進入我的聖所，他們可以接近我的聖桌事奉我，為我謹守職責。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 19:8; 出埃及記 28:43; 出埃及記 39:27–29"> 他們進入內院門的時候，要穿上細麻衣服；他們在內院裡或聖殿內事奉的時候，不可穿戴羊毛衣料。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 39:28; 哥林多前書 11:4–10; 以賽亞書 3:20"> 他們要頭戴細麻頭巾，身穿細麻褲子，不可穿戴使身體出汗的衣物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 46:20; 利未記 6:27; 利未記 6:10–11"> 他們出去到外院<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="到外院——馬索拉文本重複此短語。">b</a></sup>民眾那裡的時候，要脫下他們的事奉衣服，放在那些聖屋中，然後穿上別的衣服，以免民眾因他們的衣服而成為祭獻的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="祭獻的——輔助詞語。">c</a></sup>聖物。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 11:14; 民數記 6:5; 利未記 21:5–24"> 「他們不可剃光頭，也不可留長髮，只可修剪頭髮。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 10:9; 提多書 1:7–8; 提摩太前書 5:23"> 任何祭司要進入內院時，都不可喝酒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 21:7; 利未記 21:13–14; 提摩太前書 3:2"> 他們不可娶寡婦或被休的女人為妻，只可娶以色列後裔中的處女或祭司遺留的寡婦。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 22:26; 利未記 10:10–11; 提摩太後書 2:24–25"> 他們要指教我的子民區分聖與俗，辨別潔淨的與不潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="歷代志上 23:4; 以西結書 22:26; 歷代志下 19:8–10"> 「對於爭訟，祭司必須受理案件，按照我的公正來審斷。他們在我的各約期要謹守我的律法和律例，要把我的安息日尊為聖。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 5:16; 利未記 22:4; 馬太福音 8:21–22"> 他不可到死人那裡，以致玷汙自己；除非那死人是他父母、兒女、兄弟和未嫁人的姐妹，他才可使自己受玷汙。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 9:13–14; 民數記 19:11–14; 民數記 6:10–21"> 等他潔淨之後，再給他數算七天，</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 6:9–11; 以西結書 44:17; 利未記 4:3–35"> 然後到他進入內院聖所事奉的日子，他要獻上自己的贖罪祭。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 13:33; 民數記 18:20; 申命記 18:1–2"> 「有關祭司的繼業，我就是他們的繼業。你們不可在以色列給他們地業，我就是他們的地業。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 18:14; 利未記 27:21; 利未記 27:28"> 他們可以吃素祭、贖罪祭和贖愆祭，以色列中所有的永獻之物都歸屬他們。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 10:35–37; 歷代志下 31:10; 申命記 18:4"> 各樣初熟之物中上好的，以及你們各樣供物中上好的供物，全都歸屬祭司。你們也要把初熟五穀的麵團帶給祭司，好使祝福臨到你們的家。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 22:8; 出埃及記 22:31; 申命記 14:21"> 凡是自然死去的或被咬死的飛禽走獸，祭司都不可吃。</span>
</div>
</div>

</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="以西結書 31:4; 以西結書 17:15; 列王紀下 24:20"> <span className="pl pl-1">然而另有一隻大鷹，</span><br /><span className="pl pl-1">翅膀大，羽毛多，</span><br /><span className="pl pl-1">看哪，這葡萄樹從所栽種的苗圃，</span><br /><span className="pl pl-1">把根向這鷹彎過去，把枝子伸向牠，</span><br /><span className="pl pl-1">好得牠的澆灌。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 17:5–6"> <span className="pl pl-1">其實這葡萄樹已經栽種</span><br /><span className="pl pl-1">在好田地裡、豐富的水源旁，</span><br /><span className="pl pl-1">可以生出枝條，結出果實，</span><br /><span className="pl pl-1">成為佳美的葡萄樹。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以西結書 17:10; 耶利米書 32:5; 以賽亞書 30:1–7"> 你要說，主耶和華如此說：<br /><span className="pl pl-1">它怎能發旺？</span><br /><span className="pl pl-1">先前的鷹難道不是要拽出它的根，</span><br /><span className="pl pl-1">掃落它的果實，</span><br /><span className="pl pl-1">以致它枯乾嗎？</span><br /><span className="pl pl-1">它所有長出的嫩葉都必枯乾。</span><br /><span className="pl pl-1">不用強大的膀臂或許多人，</span><br /><span className="pl pl-1">就能把它連根拔出。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 13:15; 約翰福音 15:6; 馬太福音 21:19"> <span className="pl pl-1">看哪，它被栽種，</span><br /><span className="pl pl-1">就能發旺嗎？</span><br /><span className="pl pl-1">東風吹襲時，</span><br /><span className="pl pl-1">它不是要完全枯乾嗎？</span><br /><span className="pl pl-1">它必在所生長的苗圃裡枯乾。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 24:19; 以西結書 17:3; 以西結書 1:2"> 「現在你要對那悖逆之家說：你們不知道這些是什麼意思嗎？你要說：看哪，巴比倫王曾來到耶路撒冷，擄走君王和首領們，把他們帶到了巴比倫他那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 36:13; 列王紀下 24:15–17; 以西結書 17:5"> 巴比倫王挑選了一位王室後裔，與他立約，使他起了誓；並且擄走當地的權貴，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 29:14; 申命記 28:43; 撒母耳記上 2:30"> 使這國衰微，不能再興起，只有遵守他的約才得以存留。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 52:3; 耶利米書 38:18; 以西結書 17:7"> 但這人卻背叛了巴比倫王，派遣使者到埃及去，要埃及給他馬匹和許多軍兵。難道他能成功嗎？他做這些事，難道能逃脫嗎？他違背誓約，能逃脫嗎？</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西結書 12:13; 耶利米書 52:11; 以西結書 17:18–19"> 「這是主耶和華的宣告：我指著我的永生起誓，他必定死在巴比倫，就是立他作王的那位王的地方，因他輕看王的誓言，違背王與他所立的約。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 37:7; 以西結書 4:2; 以西結書 29:6–7"> 當敵人築起土壘，建造高臺，為要剪除許多人時，法老不會率領大軍和眾多的隊伍到戰場上救助他。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 29:24; 歷代志下 30:8; 耶利米哀歌 5:6"> 他輕看誓言，違背誓約，看哪，他已經舉手臣服，卻做出這些事，他絕不能逃脫。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 5:11; 耶利米書 5:9; 耶利米書 5:2"> 「因此主耶和華如此說：我指著我的永生起誓，他既輕看我的誓言，違背我的約，我必把這罪報應在他的頭上。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 12:13; 以西結書 32:3; 耶利米書 2:35"> 我要向他張開我的網，他必被我的網羅捉住。我要把他帶到巴比倫，在那裡審判他，因他對我行事不忠。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:5; 列王紀下 25:11; 以西結書 12:14"> 他所有軍隊中潰逃的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="潰逃的——或譯作「精兵」。">b</a></sup>都將倒在刀下，殘留的也將被驅散到四方。那時你們就知道：是我耶和華發了話。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 53:2; 撒迦利亞書 6:12–13; 以賽亞書 11:1–5"> 「主耶和華如此說：<br /><span className="pl pl-1">然後，我要親自從高大的香柏樹梢</span><br /><span className="pl pl-1">取下嫩枝，安置它；</span><br /><span className="pl pl-1">我要從這樹的嫩枝頭上摘下嫩芽，</span><br /><span className="pl pl-1">栽種在高聳險峻的山嶺上。</span><br /></span>

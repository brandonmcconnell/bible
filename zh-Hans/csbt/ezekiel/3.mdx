<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 10:9–10; 以西結書 3:17–21; 以西結書 2:8–9"> 他對我說：「人子啊，吃下你所看到的，吃下這書卷，然後你要去，向以色列家宣講。」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 25:17; 使徒行傳 26:19"> 我張開口，他就使我吃下這書卷，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 15:16; 啟示錄 10:9–10; 詩篇 119:103"> 並對我說：「人子啊，把我給你的這書卷吃到肚子裡，充滿你的肚腹。」我吃了，這書卷在我口中甘甜如蜜。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:5–6; 使徒行傳 1:8; 以西結書 2:3"> 他對我說：「人子啊，去吧，你到以色列家去，把我的話告訴他們。</span>
<span className="v" id="v5" data-v="5" data-xref="約拿書 1:2; 以賽亞書 33:19; 約拿書 3:2–4"> 你被派遣，並不是到口齒含混、語言難懂的民族中，而是到以色列家去。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 11:20–24; 羅馬書 9:30–33; 約拿書 3:5–10"> 你不是到口齒含混、語言難懂的眾多民族中去，他們的話你聽不懂——其實我如果派你到他們那裡，他們倒會聽從你！</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 以西結書 2:4; 撒母耳記上 8:7"> 但以色列家卻不願聽從你，因為他們向來不願聽從我，以色列全家實在是額堅心硬的。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 1:18; 使徒行傳 7:51–56; 彌迦書 3:8"> 看哪，我要使你的臉像他們的臉一樣剛硬，使你的額頭像他們的額頭一樣堅硬。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 2:6; 耶利米書 1:8; 以賽亞書 50:7"> 我要使你的額頭如金剛石，比燧石還堅硬。你不要怕他們，也不要因他們的臉色而喪膽，他們實在是悖逆之家！」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:11; 約伯記 22:22; 以西結書 3:1–3"> 他又對我說：「人子啊，我對你說的一切話，你都要記在心裡、聽到耳中。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 2:7; 以西結書 3:27; 以西結書 33:30"> 你去吧，到被擄的同胞那裡去！無論他們聽還是不聽，你都要向他們宣講，對他們說：『主耶和華如此說。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:3; 使徒行傳 8:39; 以西結書 11:1"> 然後靈把我舉起，我聽見身後有巨大的轟鳴聲，耶和華的榮耀從他所在之處升起<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和華的榮耀從他所在之處升起——或譯作「耶和華從他居所顯出的榮耀是當受頌讚的」。">a</a></sup>；</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 1:24; 以西結書 10:16–17; 以西結書 10:5"> 那些活物翅膀彼此相接的聲音、旁邊輪子的聲音，都是巨大的轟鳴聲。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 37:1; 耶利米書 20:7–9; 列王紀下 3:15"> 靈舉起我，把我帶走。我離去時，靈裡激憤，痛苦不已，耶和華的手在我身上大有能力。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 137:1; 約伯記 2:13; 創世記 50:10"> 我到了特拉維夫，就是住在迦巴魯河邊的擄民那裡，在他們所住的地方坐下來。我在他們中間茫然地坐了七天。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 42:7"> 七天過後，耶和華的話語臨到我，說：</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 52:8; 希伯來書 13:17; 歷代志下 19:10"> 「人子啊，我指派你作以色列家的守望者，你聽了我口中的話，就要為我警誡他們。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西結書 33:6; 雅各書 5:19–20; 以西結書 3:20"> 「當我對惡人說『你必定死』，如果你不警誡他，不發話警誡惡人離開他邪惡的道路，好使他得以存活，這惡人就必死在自己的罪孽中，我卻要從你手中追討他的血債。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 33:9; 以西結書 14:20; 提摩太前書 4:16"> 但如果你警誡了惡人，而他不轉離自己的惡事和邪惡道路，他就必死在自己的罪孽中，你卻保全了自己的性命。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 18:24; 以西結書 18:26; 以西結書 33:12–13"> 「當義人離開他的義而行不義，我把絆腳石放在他面前，他將要死，如果你不警誡他，他必死在自己的罪中，他所行的義不會被記念，我卻要從你手中追討他的血債。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前書 4:16; 箴言 9:9; 提多書 2:15"> 但如果你警誡了義人，好使義人不犯罪，他也不再犯罪，他必因接受了警誡而存活，你也保全了自己的性命。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:6; 以西結書 37:1; 以西結書 8:4"> 然後，耶和華的手在那裡臨到我身上，他對我說：「起來，往平原去，我要在那裡與你說話。」</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 1:28; 使徒行傳 7:55; 啟示錄 1:17"> 於是我起來，往平原去。看哪，耶和華的榮耀停留在那裡，正如我在迦巴魯河邊看見的榮耀，我就臉伏於地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 2:2; 但以理書 10:19; 但以理書 10:8–10"> 那時，靈進入我裡面，使我站了起來，耶和華吩咐我說：「你去，把自己關在家裡。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 4:8; 使徒行傳 9:16; 馬可福音 3:21"> 人子啊，看哪，他們還將用繩子綁住你，捆住你，使你不能出去到他們中間。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 24:27; 彌迦書 3:6–7; 阿摩司書 8:11–12"> 我要使你的舌頭緊貼上顎，使你啞然無聲，不能作責備他們的人；他們實在是悖逆之家！</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 12:2–3; 以西結書 24:27; 以西結書 3:11"> 但我對你說話的時候，我會開你的口，你要對他們說：『主耶和華如此說。』願意聽的，就讓他聽；拒絕的，就讓他拒絕；他們實在是悖逆之家！</span>
</div>
</div>

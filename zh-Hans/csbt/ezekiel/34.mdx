<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 23:1; 耶利米書 3:15; 以賽亞書 40:11"> 「人子啊，你要針對以色列的牧人說神言。你要說神言告訴他們，主耶和華對牧人們如此說：有禍了，那些只牧養自己的以色列牧人！牧人難道不是要牧養羊群嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 11:16; 耶利米書 2:30; 以西結書 33:25–26"> 你們吃脂油，穿羊毛，宰殺肥壯的羊，卻不牧養羊群。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 18:12–13; 馬太福音 9:36; 以西結書 34:16"> 衰弱的，你們不扶助；患病的，你們不醫治；受傷的，你們不包紮；走散的，你們不領回；失喪的，你們不尋找；你們只是粗暴、嚴酷地轄制他們。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 9:36; 歷代志下 18:16; 耶利米書 23:2"> 羊群因為沒有牧人就四散，成了田野各樣走獸的食物。他們四散了！</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 142:4; 彼得前書 2:25; 約翰福音 10:16"> 我的羊群迷失在各山嶺、各高丘，我的羊群四散在整個地面上，無人尋找，無人顧念。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 22:2–3; 彌迦書 3:8–9; 詩篇 82:1–7"> 「因此牧人們哪，你們要聽耶和華的話語，</span>
<span className="v" id="v8" data-v="8" data-xref="彼得後書 2:13; 使徒行傳 20:33; 以西結書 34:5–6"> 這是主耶和華的宣告：我指著我的永生起誓，我的羊群竟然成了掠物！我的羊群因沒有牧人而成為田野各樣走獸的食物，我的牧人們卻不尋找我的羊群，那些牧人只牧養自己，而不牧養我的羊群。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「因此牧人們哪，你們要聽耶和華的話語，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 34:2; 撒迦利亞書 10:3; 以西結書 13:8"> 主耶和華如此說：看哪，我與那些牧人敵對！我必從他們手中要回我的羊群，不讓他們牧養羊群，那些牧人也不能再牧養自己。我要把我的羊群從他們口中解救出來，不再作他們的食物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:16; 路加福音 19:10; 耶利米書 23:3"> 「是的，主耶和華如此說：看哪，我要親自尋找我的羊群，顧念<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="顧念——或譯作「找回」；下節同。">a</a></sup>他們。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 40:11; 約翰福音 10:11–12; 路加福音 19:10"> 牧人在他身邊的羊群四散的日子裡，怎樣顧念他的羊，我也照樣顧念我的羊群。我要從各個地方，就是他們在密雲和幽暗的日子裡被驅散到的地方，解救他們。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:25–26; 以西結書 11:17; 以賽亞書 11:11–16"> 我要從萬民中領他們出來，從各地招聚他們，把他們帶回自己的土地。我要在以色列的群山上、溪谷中，在那地一切居住的地方牧養他們。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 10:9; 耶利米書 31:25; 詩篇 31:8–10"> 我要在佳美的草場上牧養他們，他們吃草的牧場在以色列的高山上。他們必躺臥在佳美的牧場，在以色列群山上享用肥美的草場。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 3:15; 詩篇 23:1–2; 約翰福音 21:15"> 我要親自牧養我的羊群，使他們安然躺臥。這是主耶和華的宣告。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西結書 34:4; 以西結書 34:11"> 失喪的，我要尋找；走散的，我要領回；受傷的，我要包紮；患病的，我要扶助；肥的壯的，我卻要除滅。我要以公正牧養他們。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:20–22; 馬太福音 25:32–33; 撒迦利亞書 10:3"> 「至於你們，我的羊群哪，主耶和華如此說：看哪，我必在羊與羊之間、公綿羊與公山羊之間施行審判。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 23:13; 路加福音 11:52; 民數記 16:13"> 你們享用佳美的草場，還不夠嗎？你們又用蹄子踐踏剩下的草場。你們喝了清澈的水，又用蹄子蹚渾剩下的水。</span>
<span className="v" id="v19" data-v="19"> 我的羊只能吃你們蹄子所踐踏的，喝你們蹄子所蹚渾的！</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 25:31–46; 以西結書 34:10; 詩篇 22:12–16"> 「因此主耶和華對他們如此說：看哪，我必親自在肥羊和瘦羊之間施行審判。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 11:5; 申命記 33:17; 路加福音 13:14–16"> 因為你們用胯和肩膀推擠、用犄角衝撞所有衰弱的，直到把他們驅散到外面，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:2–3; 詩篇 72:12–14; 以西結書 34:10"> 所以我要拯救我的羊，使他們不再成為掠物；我要在羊與羊之間施行審判。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 37:24–25; 耶利米書 30:9; 以賽亞書 40:11"> 我要興起一個牧人照管我的羊，牧養他們，他是我的僕人大衛。他將親自牧養他們，作他們的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 31:33; 以西結書 36:28; 耶利米書 23:5–6"> 我耶和華要作他們的神，我的僕人大衛將在他們中間作君王。我耶和華已經發了話。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:6–9; 以西結書 37:26; 利未記 26:6"> 「我要與他們立平安的約，使惡獸從這地斷絕；他們在曠野中也能安然居住，在森林中也能安睡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:12; 以賽亞書 44:3; 利未記 26:4"> 我要使他們以及我山崗的四圍祝福滿滿，我必按時降下雨水，是祝福的甘霖。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 30:8; 利未記 26:4; 利未記 26:13"> 田野的樹木必結出果實，這地必有出產，他們必安居在自己的土地上。我必打斷他們身上的軛套，從奴役他們的人手中解救他們，那時他們就知道：我是耶和華。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 46:27; 耶利米書 30:10; 以西結書 39:26"> 他們不再成為列國的掠物，地上的野獸不再吞噬他們；他們必安然居住，無人驚嚇。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 36:29; 以賽亞書 4:2; 以西結書 34:26–27"> 我要為他們建立一個著名的栽種之地，他們在這地不會再被饑荒除滅，不再受列國羞辱。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 37:27; 以西結書 34:24; 詩篇 46:11"> 那時他們就知道：我是耶和華他們的神，與他們同在，他們以色列家是我的子民。這是主耶和華的宣告。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 100:3; 約翰福音 10:16; 詩篇 78:52"> 你們是我的羊，我牧場的羊群；你們是子民<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="子民——原文直譯「人」。">b</a></sup>，我是你們的神。這是主耶和華的宣告。」</span>
</div>
</div>

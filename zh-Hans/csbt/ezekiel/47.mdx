<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 22:1; 撒迦利亞書 14:8; 約珥書 3:18"> 他把我帶回到聖殿門口。看哪，有水從聖殿的門檻下面流出來，往東而去，因為聖殿面朝東。這水從聖殿的右側下面，從祭壇南邊流下來。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 44:4; 以西結書 44:2"> 他又帶我從北門出來，從外面繞行到朝東的外門。看哪，有水從右側湧出。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 40:3; 使徒行傳 10:45–46; 使徒行傳 11:16–18"> 那人手中拿著準繩，往東出去測量了一千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一千肘——相當於530公尺；下同。">a</a></sup>，然後讓我從水中趟過去，水到腳踝。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 1:6; 羅馬書 15:19; 使徒行傳 19:10–20"> 他又測量了一千肘，然後讓我從水中趟過去，水到膝蓋。他又測量了一千肘，然後讓我趟過去，水到腰部。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 11:9; 哈巴谷書 2:14; 馬太福音 13:31–32"> 他又測量了一千肘，水成了我不能趟過去的河，因為水漲起來，成了可游泳的深水，不能趟過去的河。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 44:5; 以西結書 40:4; 撒迦利亞書 4:2"> 他對我說：「人子啊，你都看見了嗎？」然後他帶我回到河岸邊。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 47:12; 啟示錄 22:2; 列王紀下 2:13"> 我返回的時候，看見這邊和那邊河岸上有極多的樹木。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 3:16; 申命記 3:17; 列王紀下 2:19–22"> 他對我說：「這些水往東部地帶流去，下到亞拉巴，流入死海。這水進入停滯的海，海水就會變成淡水<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="變成淡水——或譯作「被治好」；下同。">b</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 7:37–38; 約翰福音 6:63; 約翰福音 4:14"> 這些河水所到的任何地方，一切繁衍的活物都會存活，並且有極多的魚；因為這些水流到哪裡，哪裡就變成淡水，河水所到之處的一切活物都會存活。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:19; 詩篇 104:25; 民數記 34:6"> 從恩蓋迪到恩以革蓮，都有漁夫站在岸邊，到處都是曬網的地方；那裡的魚各從其類，像大海的魚那樣極其眾多。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 29:23; 啟示錄 22:11; 耶利米書 17:6"> 但死海的沼澤和水窪沒有變成淡水，它們被留下為產鹽地。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 22:2; 詩篇 1:3; 耶利米書 17:8"> 在兩邊的河岸上將長出各樣的果樹。它們葉子不凋零，果實也不斷絕；每月都有新結的果實，因為它們的水是從聖所流出來的。它們的果實可作食物，葉子用於醫治。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 48:4–6; 耶利米書 3:18; 民數記 34:2–12"> 主耶和華如此說：「你們要按著以下邊界，把這地分給以色列十二支派為繼業，約瑟要得雙份。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 20:5–6; 創世記 12:7; 以西結書 48:29"> 你們要彼此均分這地為繼業，這是我所舉手起誓賜給你們祖先的；你們要抽籤分得這地為繼業。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 34:8; 以西結書 48:1"> 「那地的邊界如下：<br />北部疆界是從大海經由希特倫，到澤達德隘口，</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 48:1; 民數記 13:21; 撒母耳記下 8:8"> 又到哈馬，比羅塔，大馬士革邊界和哈馬邊界之間的西伯蓮，以及浩蘭邊界旁邊的哈撒-哈提干。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 48:1; 民數記 34:9"> 這樣，邊界是從大海到大馬士革的邊界哈薩耶楠，北部到達哈馬的邊界。這是北部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 13:10; 創世記 31:23; 創世記 31:47"> 東部疆界是在浩蘭和大馬士革之間，基列和以色列地之間，沿著約旦河，從北界下來測量到東邊的海。這是東部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 48:28; 申命記 32:51; 民數記 34:5"> 南部疆界，是從塔瑪爾到米利巴-加低斯水，沿著埃及河到大海。這是南部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 34:6; 以西結書 48:1"> 西部疆界是大海，從南界上去到哈馬隘口對面。這是西部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 「你們要按著以色列的支派分配這地。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:11; 以弗所書 3:6; 使徒行傳 11:18"> 你們要把它抽籤分給自己為繼業，也要分給那些寄居在你們中間、在你們中間生養兒女的外人。他們對於你們，就像以色列子孫中的本族人，要與你們一同在以色列各支派中抽籤分得繼業。</span>
<span className="v" id="v23" data-v="23"> 外人在哪個支派寄居，你們就要在那裡分給他們繼業。這是主耶和華的宣告。</span>
</div>

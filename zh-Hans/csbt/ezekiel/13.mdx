<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 13:17; 耶利米書 37:19; 以西結書 22:28"> 「人子啊，你要針對那些說預言的以色列先知發預言，對隨從自己心意的眾先知說：你們要聽耶和華的話語！</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 2:14; 耶利米書 23:28–32; 何西阿書 9:7"> 主耶和華如此說：那些愚頑的先知有禍了！他們是隨從自己的靈，什麼也沒有看見。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 19:20; 彌迦書 2:11; 帖撒羅尼迦後書 2:9–10"> 以色列啊，你的眾先知就像廢墟中的狐狸！</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 22:30; 詩篇 106:23; 以賽亞書 58:12"> 他們沒有上去堵破口，也沒有為以色列家修補圍牆，好使以色列家在耶和華的日子裡，在戰場上站立得住。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 29:8; 以西結書 22:28; 耶利米書 28:15"> 他們所見的是虛假的異象，是虛謊的占卜。他們說『這是耶和華的宣告』，其實耶和華並沒有派遣他們；他們還期待那些話語成就！</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 13:6; 馬太福音 24:23–24; 以西結書 13:2–3"> 難道你們不是見了虛假的異象，說了虛謊的占卜嗎？你們說『這是耶和華的宣告』，其實我並沒有宣告。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 5:8; 以西結書 21:3; 以西結書 28:22"> 「因此主耶和華如此說：因為你們說虛假的事，見虛謊的異象，所以看哪，我敵對你們！這是主耶和華的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 87:6; 詩篇 69:28; 以西結書 20:38"> 我要出手攻擊那些見虛假異象、行虛謊占卜的先知，他們必不被列入我子民的會中，不被記在以色列家的名冊上，不得進入以色列地。那時你們就知道：我是主耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 22:28; 以西結書 13:16; 耶利米書 6:14"> 「這實在是因為他們誤導我的子民說『平安！』，其實並沒有平安。看哪，有人建造脆弱的牆，他們卻用白灰粉飾它！</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 38:22; 以賽亞書 28:2; 那鴻書 1:7–8"> 你要對那些用白灰粉飾的人說：牆必倒塌。必有雨水氾濫；冰雹啊，你們也要降下；必有暴風吹襲！</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 3:13; 耶利米哀歌 2:14–15; 士師記 9:38"> 看哪，這牆就倒塌了。人們豈不是要責問你們：『你們粉飾的灰泥在哪裡呢？』</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 30:30; 啟示錄 16:21; 詩篇 148:8"> 「因此主耶和華如此說：我要在怒火中使暴風吹襲；必有雨水在我的怒氣中氾濫，有冰雹在我的憤怒中施行毀滅。</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 1:6; 耶利米書 14:15; 耶利米書 6:15"> 我要拆毀你們用白灰粉飾的牆，把它夷為平地，以致它根基裸露。它必倒塌，你們也將在牆下滅亡。那時你們就知道：我是耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:13; 詩篇 62:3; 尼希米記 4:3"> 我要向那牆和那些用白灰粉飾牆的人發盡我的怒火，然後對你們說：『牆沒有了！粉飾它的人也不在了！』</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 13:10; 耶利米書 6:14; 耶利米書 8:11"> 那些人就是向耶路撒冷說預言的以色列先知，他們見異象說耶路撒冷有平安，其實並沒有平安。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 13:2; 列王紀下 22:14; 士師記 4:4"> 「人子啊，你要面向你子民中那些隨從自己心意說預言的女人，針對她們發預言。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得後書 2:14; 以西結書 13:20; 提摩太後書 4:3"> 你要說，主耶和華如此說：你們有禍了！你們照著各人的手腕縫製符咒帶子，照著各樣身高之人的頭製作蓋頭巾，為要獵取靈魂。你們獵取我子民的靈魂，難道還能保全自己的靈魂嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 3:5; 箴言 28:21; 耶利米書 23:17"> 你們為了幾把大麥、幾小塊餅，在我的子民中褻瀆我；你們對愛聽謊言的民眾說謊，使不該死的人被處死，使不該活的人存活。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 13:18; 提摩太後書 3:8–9; 以西結書 13:8–9"> 「因此主耶和華如此說：看哪，我要對付你們的符咒帶子，就是你們像獵取飛鳥那樣獵取靈魂的帶子。我必從你們膀臂上撕下它們，釋放那些靈魂，就是你們像獵取飛鳥那樣獵取的靈魂。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 91:3"> 我必撕碎你們的蓋頭巾，把我的子民從你們手中解救出來，不再作你們手中的獵物。那時你們就知道：我是耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:14; 耶利米書 14:13–17; 彼得後書 2:18–19"> 因為你們以虛謊使義人心裡傷痛，其實我並沒有使他心裡傷痛；你們又穩固惡人的手，使他不轉離邪惡的道路得以存活，</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 13:21; 以西結書 12:24; 彌迦書 3:6"> 因此你們絕不再見虛假的異象，不再行占卜；我也要把我的子民從你們手中解救出來。那時你們就知道：我是耶和華。」</span>
</div>

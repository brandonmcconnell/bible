<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 19:1; 耶利米書 9:10; 以西結書 28:12"> 「人子啊，你要為提爾吟唱哀歌，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 27:4; 以賽亞書 23:11; 以賽亞書 23:2–3"> 要對那居住在入海口、與許多海島上的民眾通商的提爾說，主耶和華如此說：<br /><span className="pl pl-1">提爾啊，你曾說：</span><br /><span className="pl pl-1">『我全然美麗！』</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 26:5"> <span className="pl pl-1">你的邊界在海洋中心，</span><br /><span className="pl pl-1">那些建造你的使你全然美麗。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:9; 以賽亞書 14:8; 雅歌 4:8"> <span className="pl pl-1">他們用示尼珥的松樹</span><br /><span className="pl pl-1">為你造所有的木板，</span><br /><span className="pl pl-1">取來黎巴嫩的香柏樹為你製作桅杆，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:4; 以賽亞書 2:13; 撒迦利亞書 11:2"> <span className="pl pl-1">用巴珊的橡樹製作你的船槳，</span><br /><span className="pl pl-1">用基提</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基提——就是塞浦路斯。">a</a></sup><br /><span className="pl pl-1">眾海島的絲柏木鑲嵌象牙</span><br /><span className="pl pl-1">製作你的甲板。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 10:9; 出埃及記 25:4; 創世記 10:4"> <span className="pl pl-1">你的船帆用埃及的白細麻刺繡製作，</span><br /><span className="pl pl-1">成為你的旗幟；</span><br /><span className="pl pl-1">你的船篷</span><br /><span className="pl pl-1">用以利沙眾海島</span><br /><span className="pl pl-1">藍色和紫色的布做成。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 10:18; 列王紀上 9:27; 以西結書 27:11"> <span className="pl pl-1">西頓和亞發的居民是你的槳手；</span><br /><span className="pl pl-1">提爾啊，你那裡有智慧人，</span><br /><span className="pl pl-1">他們是你的舵手；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 5:18; 約書亞記 13:5; 詩篇 83:7"> <span className="pl pl-1">你那裡有迦巴勒的老師傅和巧匠，</span><br /><span className="pl pl-1">為你修補破損處。</span><br /><span className="pl pl-1">你那裡有海上</span><br /><span className="pl pl-1">各處的船隻和他們的水手，</span><br /><span className="pl pl-1">販賣你的商品。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 38:5; 以西結書 30:5; 以賽亞書 66:19"> <span className="pl pl-1">波斯、呂底亞、普特</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="普特——指利比亞。">b</a></sup><br /><span className="pl pl-1">人</span><br /><span className="pl pl-1">在你軍隊中作戰士，</span><br /><span className="pl pl-1">他們在你中間掛起盾牌和頭盔，</span><br /><span className="pl pl-1">彰顯你的威榮；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 27:3–4"> <span className="pl pl-1">亞發人和赫勒克人</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="赫勒克人——或譯作「你的軍兵」。">c</a></sup><br /><span className="pl pl-1">在你四圍的城牆上，</span><br /><span className="pl pl-1">加瑪德人</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="加瑪德人——或譯作「勇士」。">d</a></sup><br /><span className="pl pl-1">在你的塔樓上，</span><br /><span className="pl pl-1">他們都把盾牌掛在你四圍的城牆上；</span><br /><span className="pl pl-1">他們使你全然美麗。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="創世記 10:4; 以賽亞書 23:10; 以西結書 38:13"> 「塔爾施因你各樣的財物眾多，就與你做買賣，用銀、鐵、錫、鉛交換你的貨物。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:2; 以賽亞書 66:19; 以西結書 39:1"> 雅完人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="雅完人——指希臘人；下同。">e</a></sup>、圖巴人、米設人都與你交易，用人口和銅器交換你的商品。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:3; 以西結書 38:6; 歷代志上 1:6"> 伯陀伽瑪的人用馬匹、戰馬和騾子交換你的貨物。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 10:7; 啟示錄 18:12; 列王紀上 10:22"> 底但人與你交易，眾多海島是你掌控的碼頭<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="碼頭——或譯作「市場」。">f</a></sup>，他們以象牙和烏木償付你的貨款。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 以西結書 28:13; 撒母耳記下 10:6"> 以東人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以東人——依據有些古抄本；傳統譯法作「亞蘭人」。">g</a></sup>因你的產品眾多，就與你做買賣，用綠松石、紫色布、刺繡、細麻布、珊瑚和紅寶石交換你的貨物。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 11:33; 列王紀上 5:9; 耶利米書 8:22"> 猶大和以色列地的人與你交易，用米尼特的小麥，以及餅、蜂蜜、油和乳香交換你的商品。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 7:8; 創世記 15:2; 以西結書 47:16–18"> 大馬士革因你的產品眾多，因你各樣的財物眾多，就用赫爾幫的酒和扎哈爾的羊毛與你做買賣。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 30:23–24; 詩篇 45:8; 雅歌 4:13–14"> 威但人和來自烏薩的雅完人交換你的貨物，你的商品中有精鐵、桂皮和菖蒲。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 25:3; 以西結書 27:15"> 底但人用馬鞍墊子與你交易。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 60:7; 創世記 25:13; 列王紀上 10:15"> 阿拉伯人和基達所有的領袖是你手下的商人，用羊羔、公綿羊和公山羊與你做買賣。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:7; 以賽亞書 60:6; 詩篇 72:10"> 示巴和拉瑪的客商都與你交易，用各種上等的香料、各種寶石以及金子交換你的貨物。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 19:12; 以賽亞書 37:12; 阿摩司書 1:5"> 哈蘭人、肯尼人、伊甸人、示巴的客商、亞述人、基抹人與你交易，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 2:8"> 他們在你的市場上，用精美的衣服、刺繡的藍色袍子，以及繩索緊緊綑紮的華麗地毯，與你交易。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 2:16; 詩篇 48:7; 以賽亞書 23:14"> 塔爾施的船隻運載你的商品。<br /><span className="pl pl-1">你富足了，在海洋中心極其繁華。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 48:7; 以西結書 26:19; 使徒行傳 27:14"> <span className="pl pl-1">你的槳手把你帶到大水上，</span><br /><span className="pl pl-1">東風在大海深處摧毀你。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; 以西結書 27:24; 以西結書 27:12"> <span className="pl pl-1">在你傾覆的日子裡，</span><br /><span className="pl pl-1">你的財物、貨物、商品，</span><br /><span className="pl pl-1">你的水手、舵手、維修工，</span><br /><span className="pl pl-1">販賣你商品的人，</span><br /><span className="pl pl-1">以及你船上的所有戰士，</span><br /><span className="pl pl-1">都將隨著你的全軍沉入大海深處。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="以西結書 26:10; 出埃及記 15:14; 以西結書 31:16"> <span className="pl pl-1">因你舵手的哀叫聲，四野震動。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 26:16; 以西結書 32:10; 啟示錄 18:17–24"> <span className="pl pl-1">所有的搖槳者、水手，</span><br /><span className="pl pl-1">海上所有的舵手，</span><br /><span className="pl pl-1">都將從船上下來，</span><br /><span className="pl pl-1">站在陸地上。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 6:26; 撒母耳記下 1:2; 耶利米哀歌 2:10"> <span className="pl pl-1">他們將為你放聲痛哭，</span><br /><span className="pl pl-1">把塵土撒在頭上，</span><br /><span className="pl pl-1">在灰燼中打滾。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 7:18; 以賽亞書 22:12; 以賽亞書 15:2"> <span className="pl pl-1">他們將為你剃光頭髮，</span><br /><span className="pl pl-1">束上麻布，</span><br /><span className="pl pl-1">為你痛心哭泣，痛苦哀號。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="以西結書 26:17; 啟示錄 18:18; 以西結書 27:2"> <span className="pl pl-1">他們將在哀號中向你吟唱哀歌，</span><br /><span className="pl pl-1">為你哀唱說：</span><br /><span className="pl pl-1">『有誰像提爾，</span><br /><span className="pl pl-1">在海中死寂無聲呢？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="啟示錄 18:19; 以西結書 27:3; 以西結書 28:16"> <span className="pl pl-1">你的貨物從海上運出時，</span><br /><span className="pl pl-1">你曾使許多國民豐足，</span><br /><span className="pl pl-1">你以眾多的財物和商品</span><br /><span className="pl pl-1">使地上的君王富有。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 27:26–27; 撒迦利亞書 9:3–4; 以西結書 26:19–21"> <span className="pl pl-1">但你在水深處被海洋摧毀的時候，</span><br /><span className="pl pl-1">你的商品和你中間所有的隊伍，</span><br /><span className="pl pl-1">都沉下去了！</span><br /></span>

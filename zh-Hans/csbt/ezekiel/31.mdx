<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 30:20; 耶利米書 52:5–6; 以西結書 1:2"> 第十一年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第十一年——指約雅斤王被擄之後的第十一年；參《以西結書》1:2。">a</a></sup>三月一日，耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 29:19; 以西結書 30:10; 以西結書 31:18"> 「人子啊，你要對埃及王法老和他的大軍說：<br /><span className="pl pl-1">論到你的高大，誰能與你相比呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 10:33–34; 但以理書 4:10; 但以理書 4:20–23"> <span className="pl pl-1">看哪，亞述是黎巴嫩的香柏樹，</span><br /><span className="pl pl-1">枝條美麗，濃蔭如林，</span><br /><span className="pl pl-1">樹身高大，樹梢上達雲間。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 17:15; 箴言 14:28; 以西結書 17:5"> <span className="pl pl-1">水源滋潤它，</span><br /><span className="pl pl-1">深淵的水使它長高；</span><br /><span className="pl pl-1">它的栽種之地有河流環繞，</span><br /><span className="pl pl-1">分出的溝渠流向田野所有的樹木。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 4:11; 以西結書 17:5; 詩篇 1:3"> <span className="pl pl-1">因此，它的樹身</span><br /><span className="pl pl-1">高過田野所有的樹木；</span><br /><span className="pl pl-1">因它發旺時有豐富的水源，</span><br /><span className="pl pl-1">它就枝杈眾多，枝條修長。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:23; 馬太福音 13:32; 但以理書 4:12"> <span className="pl pl-1">天空的飛鳥都在它枝子上搭窩，</span><br /><span className="pl pl-1">田野的走獸都在它枝條下產仔，</span><br /><span className="pl pl-1">所有的大國都在它蔭影下居住。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">這樣，它因樹身高大，</span><br /><span className="pl pl-1">因枝子修長而美麗，</span><br /><span className="pl pl-1">因為它的根在豐富的水源旁。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 28:13; 創世記 13:10; 以賽亞書 51:3"> <span className="pl pl-1">神園子裡的香柏樹比不上它，</span><br /><span className="pl pl-1">松樹不能與它的枝子相比，</span><br /><span className="pl pl-1">楓樹沒有像它那樣的枝條，</span><br /><span className="pl pl-1">神園子裡一切樹木都不如它美麗。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:13; 但以理書 2:37–38; 創世記 13:10"> <span className="pl pl-1">我使它因枝子繁多而美麗，</span><br /><span className="pl pl-1">神伊甸園裡所有的樹都羨慕它。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 28:17; 但以理書 5:20; 歷代志下 32:25"> 「因此主耶和華如此說：因為它樹身高大，樹梢伸到雲間，它就因自己的高度而心裡高傲。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 32:11–12; 那鴻書 3:18; 但以理書 5:18–19"> 所以我要把它交在列國一位領袖手中，這領袖必處治它。我已經照著它的惡行，驅逐了它。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 28:7; 以西結書 35:8; 以西結書 30:11"> 列國強橫的外族人砍伐它，把它丟棄在山上。它的枝子掉落在各山谷中，枝條折斷落在地上各溪谷中，地上的萬民都從它的蔭影下離去，拋棄它。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 32:4; 以西結書 29:5; 以賽亞書 18:6"> 天空的飛鳥都棲息在它倒下的樹幹上，田野的走獸都躺臥在它的枝子旁。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 63:9–10; 尼希米記 13:18; 彼得後書 2:6"> 這樣，水邊一切樹木都不再因它們的樹身而高傲，不再把樹梢伸到雲間，所有得水滋潤的大樹都不再高高挺立。因為它們全都被交於死亡，交到地府，與下陰坑的世人在一起。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 3:4; 那鴻書 2:8–10; 啟示錄 18:9–11"> 「主耶和華如此說：在它下陰間的日子裡，我使人悲慟；我因它的緣故遮蔽深淵，攔住深淵的河流，止住豐富的水源。我使黎巴嫩因它而哀痛，田野的樹木都因它而枯萎。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 14:15; 以賽亞書 14:8; 以西結書 26:15"> 當我使它下陰間，與下陰坑的人在一起的時候，我使列國因它倒下的聲音而震動；伊甸所有的樹木，就是黎巴嫩最佳最美的、所有得水滋潤的樹木，都在地府受了安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:17; 以西結書 31:6; 以西結書 31:3"> 它們也與它一起下陰間，到了那些被刀劍所殺的人那裡；它們曾是它的膀臂，在列國中居住在它的蔭影下。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西結書 32:19; 以西結書 32:21; 以西結書 28:10"> 「論到你的榮美和高大，伊甸的樹木中，誰能與你相比呢？然而你卻將與伊甸的樹木一起下到地府，與被刀劍所殺的人一起躺臥在未受割禮的人中間。法老和他的全軍都必如此。這是主耶和華的宣告。」</span>
</div>

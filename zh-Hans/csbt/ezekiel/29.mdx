<span className="v" id="v1" data-v="1" data-xref="以西結書 29:17; 以西結書 26:1; 以西結書 20:1"> 第十年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第十年——指約雅斤王被擄之後的第十年；參《以西結書》1:2。">a</a></sup>十月十二日，耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 6:2; 耶利米書 44:30; 耶利米書 46:2–16"> 「人子啊，你要面向埃及王法老，針對他和全埃及發預言。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 32:2; 以賽亞書 27:1; 耶利米書 44:30"> 你要宣告說，主耶和華如此說：<br /><span className="pl pl-1">埃及王法老啊，</span><br /><span className="pl pl-1">看哪，我敵對你！</span><br /><span className="pl pl-1">你這躺臥在自己江河中的巨獸，</span><br /><span className="pl pl-1">你說：</span><br /><span className="pl pl-1">『這尼羅河是我的，是我自己修築的。』</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:28; 以西結書 38:4; 阿摩司書 4:2"> <span className="pl pl-1">所以我要用鉤子鉤住你的下巴，</span><br /><span className="pl pl-1">使你江河裡的魚緊貼在你鱗甲上，</span><br /><span className="pl pl-1">然後把你連同你江河裡</span><br /><span className="pl pl-1">所有緊貼在你鱗甲上的魚，</span><br /><span className="pl pl-1">都從你的江河中拖上來。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 34:20; 以西結書 32:4–6; 耶利米書 8:2"> <span className="pl pl-1">我要把你和你江河裡所有的魚，</span><br /><span className="pl pl-1">都拋在曠野中。</span><br /><span className="pl pl-1">你將倒斃在田野上，</span><br /><span className="pl pl-1">不被收殮，不被收聚；</span><br /><span className="pl pl-1">我把你交給了地上的野獸和</span><br /><span className="pl pl-1">天空的飛鳥作食物。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 18:21; 以賽亞書 36:6; 出埃及記 9:14"> <span className="pl pl-1">這樣，</span><br /><span className="pl pl-1">埃及所有的居民就知道我是耶和華，</span><br /><span className="pl pl-1">因為你對於以色列家是一根蘆葦杖：</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 36:6; 以西結書 17:15–17; 耶利米書 17:5–6"> <span className="pl pl-1">他們用手握住你，</span><br /><span className="pl pl-1">你就破裂，劃傷他們所有人的肩；</span><br /><span className="pl pl-1">他們倚靠你，</span><br /><span className="pl pl-1">你就折斷，閃了他們所有人的腰。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 14:17; 以西結書 30:10; 以西結書 29:19–20"> 「因此主耶和華如此說：看哪，我必使刀劍臨到你，從你中間剪除人和牲畜，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 29:3; 箴言 16:18; 以西結書 29:10–12"> 埃及地必成為荒場和廢墟。那時他們就知道：我是耶和華。因為你曾說『尼羅河是我的，是我修築的』，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 30:12; 以西結書 30:6–9; 出埃及記 14:2"> 所以看哪，我與你敵對，與你的江河敵對！我要使埃及地成為荒場和荒蕪的廢墟，從密奪到賽伊尼，直到庫實的邊界。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 32:13; 耶利米書 43:11–12; 以西結書 30:10–13"> 人的腳不會經過，獸的蹄不會踏入，那裡將四十年之久無人居住。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 46:19; 以西結書 30:7; 以西結書 30:23"> 我要使埃及地成為最荒蕪的土地，它的城也將成為最荒涼的城鎮，有四十年之久。我要把埃及人驅散到列國，揚散在各地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 46:26; 以賽亞書 19:22"> 「是的，主耶和華如此說：四十年後，我要把埃及人從他們被驅散到的萬民中招聚起來。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 30:14; 以賽亞書 11:11; 耶利米書 44:1"> 我要使埃及的擄民回歸<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="使埃及的擄民回歸——或譯作「復興埃及的家業」。">b</a></sup>，回到他們的起源之地巴特羅地，在那裡成為一個卑微的國家。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 10:11; 以西結書 30:13; 以西結書 17:14"> 它將成為各國中最卑微的，不再高抬自己在列國之上。我要使他們弱小，不能再轄制列國。</span>
<span className="v" id="v16" data-v="16" data-xref="何西阿書 8:13; 以賽亞書 20:5; 以西結書 29:6–7"> 埃及將不再成為以色列家的依賴，反而使以色列家想起他們投靠埃及而犯的罪。那時他們就知道：我是主耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 29:1; 以西結書 1:2; 以西結書 24:1"> 第二十七年<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="第二十七年——指約雅斤王被擄之後的第二十七年。">c</a></sup>一月一日，耶和華的話語臨到我，說：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 27:6; 耶利米書 25:9; 以西結書 26:7–12"> 「人子啊，巴比倫王尼布甲尼撒使他的軍兵極其辛勞地攻打提爾，所有人的頭都光禿了，所有人的肩膀都磨破了。王和他的軍兵辛勞攻打提爾，卻沒有從提爾得到酬報。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 30:24–25; 耶利米書 43:10–13; 以西結書 32:11"> 因此主耶和華如此說：看哪，我要把埃及地賜給巴比倫王尼布甲尼撒，他必運走那地的財富，擄奪戰利品，掠取財物。這就成為他軍兵的酬報。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 25:9; 以賽亞書 10:6–7; 以賽亞書 45:1–3"> 我把埃及地賜給他，作為他勞苦的酬報，因為他們是為我做工。這是主耶和華的宣告。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 2:10; 路加福音 21:15; 詩篇 132:17"> 在那日，我要使以色列家有一個犄角長出來，也要指派你在他們中間作代言人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="代言人——原文直譯「敞開的口」。">d</a></sup>。那時他們就知道：我是耶和華。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 3:16; 以西結書 11:24; 使徒行傳 7:56"> 第三十年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第三十年——或譯作「我三十歲那一年」。">a</a></sup>四月五日，我在迦巴魯河邊的擄民當中，那時諸天打開了，我看見神的異象。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 24:12–15; 以西結書 8:1; 以西結書 20:1"> 這是在約雅斤王被擄後第五年的四月五日，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 3:14; 以西結書 3:22; 列王紀下 3:15"> 在迦勒底人之地迦巴魯河邊，耶和華的話語特別臨到布西的兒子祭司以西結，耶和華的手在那裡臨到了他身上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:27; 以西結書 8:2; 耶利米書 23:19"> 我觀看，看哪，暴風從北方吹來，有一朵巨大的雲，火光熠熠，四圍環繞著光輝，中央的烈火內如同閃耀的琥珀。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 4:6–8; 以西結書 1:26; 啟示錄 6:6"> 火的中央有四個活物的形象，牠們的外觀是這樣：都有人的樣貌，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 10:14; 啟示錄 4:7–8; 以西結書 1:15"> 但每一個活物都有四張臉，都有四個翅膀。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 1:15; 但以理書 10:6; 詩篇 104:4"> 牠們的腿是直的，腳掌像牛犢的蹄子；牠們閃亮如拋光閃耀的銅。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 10:21; 以西結書 10:11; 以賽亞書 6:6"> 在牠們四面的翅膀底下，都有人的手。至於這四個活物的臉和翅膀：</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 10:22; 以西結書 10:11; 以西結書 1:11–12"> 牠們的翅膀彼此相接，行走時並不轉身，各都直往前行。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 10:14; 啟示錄 4:7; 哥林多前書 9:9–10"> 牠們臉的樣貌，都有一張人的臉，四個活物的右邊都有一張獅子的臉，左邊都有一張公牛的臉，也都有一張老鷹的臉，</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 6:2; 以西結書 1:23; 以西結書 10:19"> 這是牠們的臉。牠們的翅膀，各有兩個向上張開，彼此相接，另外兩個遮蔽自己的身體。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 1:9; 以西結書 10:22; 希伯來書 1:14"> 牠們各都直往前行，靈往哪裡去，牠們就往哪裡去，行走時並不轉身。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 4:5; 詩篇 104:4; 馬太福音 28:3"> 這四個活物的形象和外觀，像燃燒的火炭，又像火把。烈火在活物之間穿行，火光明亮，有閃電從烈火中發出。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 24:27; 撒迦利亞書 4:10; 馬可福音 13:27"> 活物往返飛奔，快如閃電。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 7:9; 以西結書 10:9; 以西結書 1:19–21"> 我觀看這些活物，看哪，這些有四張臉的活物旁邊，各有一個輪子在地上。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 10:6; 以西結書 10:9–11; 出埃及記 39:13"> 至於輪子的形狀和構造，它們如同閃耀的黃水晶，四個輪子是同一個樣式，形狀和構造像是輪中套輪。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 1:9; 以西結書 1:12; 以賽亞書 55:11"> 輪子移動時，四個方向都可前行，移動時並不轉向。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 10:12; 啟示錄 4:6; 啟示錄 4:8"> 輪圈高大可畏，四個輪圈周身布滿了眼睛。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 10:16; 以西結書 10:19; 詩篇 103:20"> 活物前行時，輪子也在牠們旁邊前行；活物離地上升時，輪子也上升。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:12; 以西結書 10:17; 哥林多前書 14:32"> 靈往哪裡去，活物就往靈要去的地方前行；輪子在活物旁邊一起上升，因為活物的靈在輪子裡。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 10:17; 以西結書 1:19–20; 羅馬書 8:2"> 活物行走時，輪子也行走；活物站住時，輪子也站住；活物離地上升時，輪子也在牠們旁邊上升，因為活物的靈在輪子裡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:1; 以西結書 1:26; 啟示錄 4:6"> 在活物的頭頂上方有穹蒼的景象，如同閃耀可畏的冰晶，高高地在牠們頭頂上方展開著。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 4:18; 以西結書 1:11–12; 詩篇 89:7"> 在穹蒼之下，活物的翅膀伸直，彼此相接；牠們各用兩個翅膀遮蔽<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="各用兩個翅膀遮蔽——此句在馬索拉文本裡有重複。">b</a></sup>自己的身體。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 43:2; 但以理書 10:6; 啟示錄 1:15"> 牠們行走時，我聽見牠們翅膀的聲音，如同大水的聲音，如同全能者的聲音；有轟隆的聲音，如同軍隊的聲音。牠們站住時，就垂下牠們的翅膀。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 1:22"> 當牠們站住垂下翅膀時<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="當牠們站住垂下翅膀時——此句在馬索拉文本裡處於節尾，重複了前一節末尾。">c</a></sup>，有聲音從牠們頭頂上方的穹蒼之上傳來。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 10:1; 出埃及記 24:10; 啟示錄 1:13"> 活物的頭頂上方的穹蒼之上，有寶座的形象，好像藍寶石的外觀。在寶座的形象之上，還有一個形象，好像人的樣貌，高高坐在上面。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 1:4; 以西結書 8:2; 希伯來書 12:29"> 我看見從他腰部往上，好像閃耀的琥珀，四圍彷彿環繞著烈火的景象。我又看見從他腰部往下，彷彿烈火的景象，四圍環繞著光輝。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 10:1; 啟示錄 4:3; 創世記 17:3"> 下雨的日子裡雲中彩虹是什麼景象，他四圍的光輝也是什麼景象，這是耶和華榮耀形象的樣子。我一看見，就臉伏於地，然後聽見了說話的聲音。</span>
</div>
</div>

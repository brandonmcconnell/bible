<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 66:23; 以西結書 44:1–2; 出埃及記 20:9"> 「主耶和華如此說：內院朝東的門，六天工作日都要關著，但在安息日要打開，在新月節那天也要打開。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 44:3; 以西結書 46:8; 歷代志上 29:10–12"> 那時君王要由這門廊的通道從外面進來，站在門柱旁邊。祭司們要獻上他的燔祭和平安祭，然後他就在門檻那裡下拜，隨後出去。這門傍晚之前不可關上。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 約翰福音 10:9; 希伯來書 10:19–22"> 安息日和新月節，這地的民眾要在這門口，在耶和華面前下拜。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西結書 45:17; 民數記 28:9–10"> 「君王在安息日要向耶和華獻上的燔祭，是六隻無瑕疵的公羊羔和一隻無瑕疵的公綿羊。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 45:24; 以西結書 46:7; 申命記 16:17"> 至於素祭，是每隻公綿羊配上一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一伊法——相當於22公升；下同。">a</a></sup>細麵；為公羊羔配上的素祭，可量力而獻；每一伊法細麵要配上一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一欣——相當於3.7公升；下同。">b</a></sup>油。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 46:1"> 在新月節那天，君王要獻上一頭無瑕疵的公牛，還有六隻公羊羔和一隻公綿羊，都是無瑕疵的。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 46:5"> 他還要獻上素祭，每頭公牛配上一伊法細麵，每隻公綿羊配上一伊法細麵；為公羊羔配上的素祭，是量力而獻；每一伊法細麵要配上一欣油。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 46:2; 以西結書 44:1–3; 歌羅西書 1:18"> 君王進入的時候，要從這門廊的通道進入，也從這通道出來。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 16:16; 出埃及記 23:14–17; 彼得後書 2:20–21"> 「這地的民眾在各約期來到耶和華面前時，那些從北門進來下拜的要從南門出去，從南門進來的要從北門出去；不可從原來進入的門返回，而是要從對面的門出去。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 42:4; 歷代志上 29:20; 歷代志上 29:22"> 他們進來時，君王也與他們一同進來；他們出去時，他也出去。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 46:5; 以西結書 46:7; 民數記 15:1–41"> 各節期、各約期中的素祭，是每頭公牛配上一伊法細麵，每隻公綿羊配上一伊法細麵；為公羊羔配上的素祭，可量力而獻；每一伊法細麵要配上一欣油。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 46:1–2; 以西結書 45:17; 以西結書 44:3"> 「當君王向耶和華獻上甘心祭，就是甘心奉獻的燔祭或平安祭時，要為君王打開朝東的門。他要像在安息日獻祭那樣，獻上他的燔祭和平安祭，然後出去。他出去之後，門要關上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 50:4; 約翰福音 1:29; 出埃及記 12:5"> 「君王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="君王——原文直譯「你」。">c</a></sup>每天要向耶和華獻上一隻無瑕疵的一歲公羊羔為燔祭，在每天早晨獻上牠。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 28:5"> 也要在每天早晨獻上同獻的素祭，就是六分之一伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="六分之一伊法——相當於3.6公升。1伊法=22公升。">d</a></sup>細麵，並用三分之一欣<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三分之一欣——相當於1.2公升。1欣=3.7公升。">e</a></sup>油來調和細麵。這是歸於耶和華的素祭，要作為永遠的律例，一直持守。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 10:1–10; 民數記 28:6; 出埃及記 29:42"> 每天早晨都要這樣獻上公羊羔、素祭和油，這是常獻的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 21:3; 加拉太書 4:7; 創世記 25:5–6"> 「主耶和華如此說：如果君王把地業<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="把地業——輔助詞語。">f</a></sup>賞賜給了他任何一個兒子，那就是他兒子的繼業，歸屬他的兒子，是他們所繼承的地業。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 25:10; 路加福音 19:25–26; 加拉太書 4:30–31"> 如果他把繼業之地賞賜給了他任何一個臣僕，這地就歸屬那臣僕直到自由年，然後要歸還給君王。他的繼業只能是他兒子們的，要歸屬他們。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 45:8; 列王紀上 21:19; 以西結書 22:27"> 君王不可奪取民眾的繼業之地，使他們被迫離開自己的地業。他要從自己的地業中分給他兒子們繼業，免得我的子民離散，各人離開自己的地業。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 42:9; 以西結書 44:4–5; 以西結書 40:44–46"> 那人又帶我從東門旁邊的入口來到北面祭司們的聖屋那裡。看哪，在聖屋西邊的盡頭有一個場地。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 35:13; 以西結書 44:29; 以西結書 44:19"> 他對我說：「這是祭司們煮贖愆祭、贖罪祭以及烤素祭的地方，以免祭物被帶到外院去，使民眾成為祭獻的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="祭獻的——輔助詞語。">g</a></sup>聖物。」</span>
<span className="v" id="v21" data-v="21"> 他又帶我出來到外院，讓我經過外院的四個角落。看哪，這個角落有一個小院子，那個角落也有一個小院子；</span>
<span className="v" id="v22" data-v="22"> 外院的四個角落都有小院子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="小院子——依據七十士譯本；或譯作「圍起來的院子」。">h</a></sup>，每個長四十肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="四十肘——相當於21.2公尺。">i</a></sup>，寬三十肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="三十肘——相當於15.9公尺。">j</a></sup>，四個角落的院子尺寸都一樣。</span>
<span className="v" id="v23" data-v="23"> 這四個院子裡面的四圍都有一排廊房，四圍的廊房下面建造了一些爐灶。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:20; 約翰福音 21:15–17; 彼得前書 5:2"> 他對我說：「這些是廚房，聖殿僕役要在那裡烤煮民眾的祭物。」</span>
</div>
</div>

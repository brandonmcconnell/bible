<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 31:29–30; 耶利米哀歌 5:7; 以西結書 37:11"> 「你們在以色列地怎麼有這樣的俗語，說：<br /><span className="pl pl-1">『父親吃酸葡萄，兒子的牙齒酸倒了』？</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西結書 18:19–20; 以西結書 33:11–20; 以西結書 18:30"> 「這是主耶和華的宣告：我指著我的永生起誓，你們在以色列絕不會再引用這俗語。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:20; 羅馬書 6:23; 民數記 16:22"> 看哪，所有人的性命都是我的，父親的性命與兒子的性命一樣屬於我；只有犯罪的人才會喪命。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 33:14; 約翰一書 3:7; 箴言 21:3"> 「如果有人是公義的，實行公正和公義，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 18:15; 申命記 4:19; 以西結書 6:13"> 不到山上吃祭物，不仰望以色列家的偶像；不玷汙鄰人的妻子，不親近經期中的女人；</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 18:16; 出埃及記 22:26; 以西結書 18:12"> 不欺壓人，反而歸還欠債人的抵押物；不搶劫，反而給飢餓的人食物吃，給赤身的人衣服穿；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 22:25; 撒迦利亞書 8:16; 申命記 23:19–20"> 借貸不收利息，不取厚利；不出手做不義的事，在人與人之間施行誠實的裁決；</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:11; 哈巴谷書 2:4; 阿摩司書 5:4"> 遵行我的律例，謹守我的法規，誠實行事——這人是公義的，他必定存活。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 21:12; 約翰一書 3:12; 約翰福音 18:40"> 「但如果這人生養的兒子是個惡徒，是殺人流血的，做了這些事的任何一件——</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 22:14; 馬太福音 7:21–27; 列王紀上 13:8"> 儘管他自己沒有做這些事，但他兒子竟然到山上吃祭物，或玷汙鄰人的妻子，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:17; 以西結書 8:6; 列王紀下 21:11"> 欺壓困苦人和貧窮人，強取豪奪，不歸還抵押物，仰望偶像，做可憎的事，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 22:25; 利未記 20:9; 以西結書 3:18"> 借貸收利息，取厚利——這兒子能存活嗎？他絕不能存活！他做了這些可憎的事，必須被處死，他的血債歸在他自己身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 34:21; 箴言 23:24; 耶利米書 8:6"> 「如果這人生養了一個兒子，兒子看見父親所行的那些罪惡，看見了就不這樣做，</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 18:6–7; 以西結書 18:11–13"> 不到山上吃祭物，不仰望以色列家的偶像，不玷汙鄰人的妻子，</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 18:7; 以賽亞書 58:7–10; 約伯記 22:7"> 不欺壓人，不拿人的抵押物，不強取豪奪，反而給飢餓的人食物吃，給赤身的人衣服穿，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 18:8–9; 馬太福音 18:27–35; 以西結書 18:13"> 不出手害困苦人，不收取利息或厚利，遵行我的法規，遵從我的律例，他就不會因父親的罪孽而死，他必定存活。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西結書 3:18; 以西結書 18:26; 以西結書 18:24"> 「至於這位父親，因為他欺壓人，搶奪弟兄，在同胞中做不善的事，看哪，他必因自己的罪孽而死。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:5; 撒迦利亞書 1:3–6; 申命記 5:9"> 你們會問：『兒子為什麼不承擔父親的罪責呢？』這兒子行公正和公義，謹守遵行我的一切律例，他當然要存活。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:16; 列王紀下 14:6; 以西結書 18:4"> 那犯罪之人，他才會喪命。兒子不承擔父親的罪責，父親也不承擔兒子的罪責。義人的義歸屬自己，惡人的惡也歸屬自己。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 18:27–28; 提多書 2:11–14; 以西結書 33:19"> 「惡人如果轉離所行的一切罪惡，謹守我的一切律例，實行公正和公義，他必定存活，不致死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="彌迦書 7:19; 以西結書 33:16; 以賽亞書 43:25"> 他所犯的一切過犯，都不會被記起，他必因所行的公義而存活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:11; 提摩太前書 2:4; 彼得後書 3:9"> 這是主耶和華的宣告：難道我真的樂意惡人死亡嗎？難道我不是樂意他轉離自己的道路而存活嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 33:18; 箴言 21:16; 約翰二書 1:8"> 但如果義人轉離自己的義而行不義，照著惡人所做的那些可憎之事而行，他能存活嗎？他所行的一切義都不會被提起，他必因自己行事不忠，因自己所犯的罪而死。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 33:17; 瑪拉基書 3:13–15; 瑪拉基書 2:17"> 「你們竟然說：『主做事不公平！』以色列家啊，你們聽著：是我做事不公平嗎？難道不是你們做事不公平嗎？</span>
<span className="v" id="v26" data-v="26"> 義人如果轉離他的義而行不義，就會因此而死，他必因所行的不義而死。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 18:21; 以賽亞書 1:18; 以賽亞書 55:7"> 惡人如果轉離他所行的惡，實行公正和公義，他就會使自己的性命得以存活；</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:29; 路加福音 15:17–18; 雅各書 2:10–12"> 他思索後，就轉離他所行的一切過犯，他必定存活，不致死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 18:25; 箴言 19:3; 以西結書 18:2"> 以色列家竟然說：『主做事不公平！』以色列家啊，是我做事不公平嗎？難道不是你們做事不公平嗎？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西結書 18:21; 馬太福音 16:27; 馬太福音 3:2"> 「因此以色列家啊，我必照著各人的行為審判你們。這是主耶和華的宣告。你們要回轉，轉離你們的一切過犯，免得罪孽成為你們的絆腳石。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 51:10; 以西結書 36:26; 以西結書 11:19"> 你們要拋棄你們的一切悖逆行為，為自己獲得一個新的心、新的靈。以色列家啊，你們何必死亡呢？</span>
<span className="v" id="v32" data-v="32" data-xref="彼得後書 3:9; 以西結書 18:23; 以西結書 33:11"> 我絕不樂意有人死亡，這是主耶和華的宣告。你們要回轉，要存活！」</span>
</div>
</div>

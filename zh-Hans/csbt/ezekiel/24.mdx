<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 20:1; 以西結書 29:17"> 第九年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第九年——指約雅斤王被擄之後的第九年；參《以西結書》1:2。">a</a></sup>十月十日，耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 39:1; 耶利米書 52:4; 列王紀下 25:1"> 「人子啊，你要記下今天這日子的名稱，就是在這個日子，巴比倫王圍攻耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 11:3; 以西結書 17:2; 以西結書 20:49"> 你要向這悖逆之家設比喻，對他們說，主耶和華如此說：<br /><span className="pl pl-1">要放上一口鍋，</span><br /><span className="pl pl-1">放好後，往裡面倒進水。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 3:2–3; 以西結書 22:18–22; 馬太福音 7:2"> <span className="pl pl-1">要把肉塊，所有肥美的肉，</span><br /><span className="pl pl-1">大腿和肩部，都放進去；</span><br /><span className="pl pl-1">要裝滿上好的骨頭；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 52:24–27; 耶利米書 52:10; 耶利米書 39:6"> <span className="pl pl-1">要取羊群中最好的。</span><br /><span className="pl pl-1">然後把木柴堆在鍋底下，</span><br /><span className="pl pl-1">燒開鍋，</span><br /><span className="pl pl-1">把肉連骨頭都在裡面煮透。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西結書 22:2; 那鴻書 3:1; 俄巴底亞書 1:11"> 是的，主耶和華如此說：<br /><span className="pl pl-1">有禍了，這殺人流血的城，</span><br /><span className="pl pl-1">裡面生鏽的鍋！</span><br /><span className="pl pl-1">它的鏽還沒有從其中除掉。</span><br /><span className="pl pl-1">要把肉一塊一塊都取出來，</span><br /><span className="pl pl-1">不必抽籤挑選。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="利未記 17:13; 申命記 12:16; 約伯記 16:18"> <span className="pl pl-1">殺人流的血還在城中，</span><br /><span className="pl pl-1">留在光禿禿的岩石上，</span><br /><span className="pl pl-1">而不是倒在地上，</span><br /><span className="pl pl-1">用塵土掩蓋起來。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命記 32:21–22; 啟示錄 18:5–10; 以西結書 22:30–31"> <span className="pl pl-1">其實，我任憑血</span><br /><span className="pl pl-1">留在光禿禿的岩石上不被掩蓋，</span><br /><span className="pl pl-1">是為了激起我的怒火，施行報復。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以西結書 24:6; 哈巴谷書 2:12; 以賽亞書 31:9"> 因此主耶和華如此說：<br /><span className="pl pl-1">有禍了，這殺人流血的城！</span><br /><span className="pl pl-1">我還要加大柴堆。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米書 17:3; 耶利米哀歌 1:10"> <span className="pl pl-1">你要增添木柴，點燃火，</span><br /><span className="pl pl-1">把肉煮爛，</span><br /><span className="pl pl-1">調入香料，</span><br /><span className="pl pl-1">把骨頭烤焦。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 21:10; 瑪拉基書 4:1; 以賽亞書 1:25"> <span className="pl pl-1">然後把倒空的鍋放在炭火上，</span><br /><span className="pl pl-1">好把它燒熱，</span><br /><span className="pl pl-1">把它的銅燒紅，</span><br /><span className="pl pl-1">使它的汙穢在其中熔化，</span><br /><span className="pl pl-1">除盡它的鏽。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 9:5; 耶利米書 2:13; 耶利米書 5:3"> <span className="pl pl-1">雖勞碌疲倦，</span><br /><span className="pl pl-1">它厚厚的鏽也無法從其中除掉，</span><br /><span className="pl pl-1">它的鏽必須用火炙烤</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="它的鏽必須用火炙烤——或譯作「即使用火炙烤它的鏽」。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 22:24; 以西結書 5:13; 西番雅書 3:2"> <span className="pl pl-1">你實在汙穢醜惡！</span><br /><span className="pl pl-1">因為我潔淨你，</span><br /><span className="pl pl-1">你卻不肯脫離汙穢得潔淨，</span><br /><span className="pl pl-1">所以在我對你的怒火平息之前，</span><br /><span className="pl pl-1">你再也不會得潔淨！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 16:27; 以西結書 18:30; 以賽亞書 3:11"> <span className="pl pl-1">我耶和華已經發了話；</span><br /><span className="pl pl-1">這事必臨到，我必成就。</span><br /><span className="pl pl-1">我絕不放手，不顧惜，不後悔。</span><br /><span className="pl pl-1">我要照著你的所作所為審判你。</span><br /><span className="pl pl-1">這是主耶和華的宣告。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 22:10; 耶利米書 13:17; 雅歌 7:10"> 「人子啊，看哪，我即將擊打你眼中的寶貝，把她從你身邊取走，但你不可哀悼，不可哭泣，不可流淚。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 9:4; 撒母耳記下 15:30; 利未記 10:6"> 只可靜默嘆息，不可辦喪事；要戴好頭巾，腳上穿鞋；不可蒙著嘴，不可吃弔喪之人的食物。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 7:29–30"> 於是，清晨我向民眾說了這事，傍晚我的妻子就死了。第二天早晨，我照著所受的指示去做，</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 12:9; 以西結書 37:18; 瑪拉基書 3:7–8"> 民眾問我：「你做的這些事與我們有什麼關係，你不告訴我們嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 我回答他們：「耶和華的話語臨到我，說：</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 23:47; 以西結書 23:25; 詩篇 27:4"> 你要告訴以色列家，主耶和華如此說：『看哪，我即將褻瀆我的聖所，就是你們所誇耀的勢力，你們眼中的寶貝、心裡所珍愛的；你們所留下的兒女必倒在刀下。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:64; 耶利米書 16:4–7; 以西結書 24:16–17"> 那時你們必照著以西結<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以西結——原文作「我」。">c</a></sup>所做的去做：不蒙著嘴，不吃弔喪之人的食物，</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:10; 以西結書 4:17; 利未記 26:39"> 戴好頭巾，腳上穿鞋；不哀悼，不哭泣，反而在自己的罪孽中衰弱，彼此哀嘆。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 4:3; 以賽亞書 20:3; 路加福音 11:29–30"> 以西結是你們的預表，當這事臨到的時候，你們必照著他所做的一切去做。那時你們就知道：我是主耶和華。』</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 24:21; 詩篇 48:2; 耶利米書 11:22"> 「人子啊，那日我必除掉他們的保障，就是他們所誇耀、所喜悅的，除掉他們眼中的寶貝、心裡所看重的兒女。</span>
<span className="v" id="v26" data-v="26" data-xref="約伯記 1:15–19; 以西結書 33:21–22; 撒母耳記上 4:12–18"> 那日，逃脫的人難道不會來到你這裡，使你聽見消息嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 33:22; 以西結書 29:21; 路加福音 21:15"> 那日，你要向逃脫的人開口，你要說話，不再默然無聲。這樣，你成為他們的預表，他們就知道：我是耶和華。」</span>
</div>

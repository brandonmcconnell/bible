<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 22:2; 以西結書 20:4; 以賽亞書 58:1"> 「人子啊，你要讓耶路撒冷知道她的可憎之事。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 16:45; 以賽亞書 51:1–2; 申命記 20:17"> 你要說，主耶和華對耶路撒冷如此說：你的起源、你的出生是在迦南人之地，你父親是亞摩利人，你母親是赫提人。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 2:3; 創世記 15:13; 出埃及記 5:16–21"> 論到你的出生，在你生下來的日子裡，沒有人為你剪斷臍帶，沒有人用水清洗你，更沒有人用鹽為你擦身，沒有人包裹你。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:10; 創世記 21:10; 出埃及記 1:22"> 誰的眼目都不顧惜你，為你做一件這樣的事來憐恤你。你在生下來的日子裡就遭厭棄，被扔在田野上。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所書 2:4–5; 約翰福音 5:25; 提多書 3:3–7"> 「我從你旁邊經過，看見你在血中掙扎，就對血中的你說：『活下去！』我對血中的你說『活下去』，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 1:10; 出埃及記 1:7; 以賽亞書 62:3"> 我使你發旺如田野的幼苗。你漸漸長大，到了打扮妝飾的年齡，乳房成形，頭髮秀長，不過你還是赤身露體。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得記 3:9; 耶利米書 2:2–3; 羅馬書 5:8"> 「我從你旁邊經過，看見你正處在愛情的萌發期。我把衣襟鋪在你身上，遮蔽你的下體，又向你起誓，與你立約，你就歸屬了我。這是主耶和華的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 23:5; 路得記 3:3; 約翰一書 2:27"> 我用水洗你，沖洗你身上的血，為你抹油。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 16:18; 以西結書 16:13; 以賽亞書 61:10"> 我給你穿上彩衣，穿上皮涼鞋，用白細麻布為你裹頭，給你披上絲綢。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 24:22; 以賽亞書 3:19; 創世記 41:42"> 我給你佩戴妝飾，把鐲子戴在你手腕上，項鏈戴在你脖子上，</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 3:21; 以賽亞書 28:5; 耶利米書 13:18"> 環子戴在你鼻子上，耳環戴在你耳朵上，華冠戴在你頭上。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:13–14; 詩篇 50:2; 列王紀上 4:21"> 這樣，你佩戴金銀，穿的是白細麻布、絲綢和彩衣，吃的是細麵粉、蜂蜜和油。你極其美麗，達到王后的尊榮。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 10:24; 耶利米哀歌 2:15; 哥林多前書 4:7"> 你的名聲傳遍列國，因為你非常美麗；因著我加給你的榮光，你實在完美。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 57:8; 耶利米書 2:20; 以西結書 16:25"> 「然而你依靠自己的美麗，仗著你的名聲行淫。你傾瀉淫欲，獻身給每個過路的人。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:7; 以西結書 7:20; 歷代志下 28:24"> 你拿自己的衣服搭建色彩斑斕的高壇，在其上行淫——這些事不該出現，不該發生！</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 23:14–21; 耶利米書 3:9; 以西結書 16:11"> 你還拿我賜給你的金銀榮美器物，製作男性的雕像，與它們行淫。</span>
<span className="v" id="v18" data-v="18"> 又拿你的彩衣給它們披上，把我的膏油和香料獻在它們面前。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 16:13; 何西阿書 2:8–13; 創世記 8:21"> 我所賜給你的糧食，給你吃的細麵粉、油和蜂蜜，你卻獻給了它們作馨香之氣——竟然有這樣的事！這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 23:37; 以西結書 20:31; 耶利米書 7:31"> 「你還把你為我所生的兒女帶來，祭獻給它們吃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="吃——或譯作「作食物」。">a</a></sup>。你自己淫亂還不夠嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 17:17; 利未記 18:21; 申命記 18:10"> 你竟然把我的兒女宰殺了，把他們經火獻給偶像！</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 2:2; 何西阿書 11:1; 以西結書 16:43"> 你行這一切淫亂和可憎之事，並不回想你年幼時怎樣赤身露體，在血中掙扎。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="啟示錄 12:12; 以西結書 2:10; 以西結書 24:6"> 「你有禍了！有禍了！這是主耶和華的宣告：在這一切惡事之外，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:58; 以西結書 16:39; 以西結書 16:31"> 你還建造圓頂花樓，在各廣場上造高臺。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 16:31; 耶利米書 3:2; 創世記 38:21"> 你在各路口建造你的高臺，使你的美麗變為可憎；你向所有過路的人張開雙腿，增多你的淫行。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 23:19–21; 以西結書 20:7–8; 以西結書 8:10"> 你還與情慾旺盛的鄰居埃及人行淫，增多你的淫行惹怒我。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 9:12; 以西結書 16:57; 以西結書 16:37"> 「所以，看哪，我伸手攻擊你，縮減你的糧食供應<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="糧食供應——或譯作「地界」。">b</a></sup>，又把你交給厭惡你的非利士女子任意對待，連她們也對你的淫穢行為感到羞恥。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 16:7; 何西阿書 10:6; 列王紀下 16:10–18"> 然而你因為不滿足，又與亞述人行淫。你與他們行淫，還是不滿足，</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 21:9; 士師記 2:12–19; 以西結書 13:14–23"> 又增多你的淫行，直到貿易之地迦勒底。即使這樣，你還不滿足。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 3:3; 以賽亞書 1:3; 以賽亞書 3:9"> 「這是主耶和華的宣告：你的欲念何等狂熱！你做這一切事，就像厚顏無恥的妓女。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 16:33–34; 以賽亞書 52:3; 以西結書 16:39"> 你在各路口建造圓頂花樓，在各廣場上搭建高臺時，不屑於收賣淫的酬金，並不像是一個妓女。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 2:28; 以西結書 23:37; 耶利米書 2:25"> 你這淫婦啊，你接納外人，替代自己的丈夫！</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 57:9; 何西阿書 8:9–10; 以西結書 16:41"> 所有的妓女都是別人送禮物給她，你卻是送禮物給你所有的情人，拉攏他們從四圍到你這裡，與你行淫。</span>
<span className="v" id="v34" data-v="34"> 你的淫行與那些女人相反，不是人追求你行淫。你給人酬金，而不是人給你酬金，你就是這樣與人相反！</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 4:18; 列王紀上 22:19; 約翰福音 4:10"> 「因此，你這妓女啊，你要聽耶和華的話語！</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 23:10; 以西結書 24:13; 西番雅書 3:1"> 主耶和華如此說：因為你放縱情慾，在淫亂中向你的情人們以及你一切可憎的偶像裸露下體，又因你流兒女的血，把兒女獻給它們，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿書 2:10; 耶利米書 13:22; 何西阿書 2:3"> 所以看哪，我必招聚你喜愛的那些情人，以及你愛慕的那些人，連同你恨惡的那些人。我要從四圍招聚他們攻擊你，把你的下體裸露給他們，使他們看見你整個下體。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 20:10; 創世記 9:6; 西番雅書 1:17"> 我要像審判淫婦和殺人流血的婦人那樣審判你，在憤怒和妒火中向你追討血債。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 23:26; 何西阿書 2:3; 以西結書 16:24–25"> 我要把你交在他們手中，他們將拆掉你的圓頂花樓，拆毀你的高臺，剝去你的衣服，奪走你榮美的器物，留下你赤身露體。</span>
<span className="v" id="v40" data-v="40" data-xref="以西結書 23:47; 哈巴谷書 1:6–10; 約翰福音 8:5–7"> 他們將聚衆上來攻打你，用石頭砸死你，用刀斬殺你，</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 23:48; 耶利米書 52:13; 耶利米書 39:8"> 放火燒掉你的房屋，在眾多女人眼前對你施行審判。我必使你停止賣淫，你再也不能送酬金給人了。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 5:13; 以西結書 21:17; 以賽亞書 40:1–2"> 這樣我就平息了我對你的憤怒，我的妒火也會離開你，我就平靜，不再惱怒。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 16:22; 以西結書 11:21; 詩篇 78:42"> 既然你不記念你年幼的日子，在這一切事上惹怒我，所以看哪，我也把你的惡行報應在你頭上。這是主耶和華的宣告。這樣，你就不會再做醜惡的事，以及你的一切可憎之事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="以西結書 18:2–3; 詩篇 106:35–38; 撒母耳記上 24:13"> 「看哪，凡引用俗語的，都將對你引用俗語說：<br /><span className="pl pl-1">『母親怎樣，女兒也怎樣。』</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="撒迦利亞書 11:8; 以賽亞書 1:4; 以西結書 23:37–39"> 「你真是你母親的女兒，她厭惡自己的丈夫和兒女。你也真是你姐妹的姐妹，她們厭惡自己的丈夫和兒女。你母親是赫提人，父親是亞摩利人。</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 23:4; 以西結書 16:48–49; 以西結書 16:53–56"> 你姐姐是撒瑪利亞，她和她的女兒們是你北面的居民；你妹妹所多瑪和她的女兒們，是你南面的居民。</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀下 21:9; 以西結書 16:51; 以西結書 5:6–7"> 你不只是隨從她們的行為，照著她們的可憎之事去做，甚至在短短片刻，你在一切行為上比她們更敗壞！</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="馬太福音 10:15; 路加福音 10:12; 使徒行傳 7:52"> 「這是主耶和華的宣告：我指著我的永生起誓，你妹妹所多瑪和她的女兒們從來沒有像你和你的女兒們這樣行事！</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 138:6; 以西結書 28:2; 創世記 13:10"> 看哪，這是你妹妹所多瑪的罪孽：她和她的女兒們心高氣傲，她們糧食豐足、安穩平靜，卻不扶助困苦人和貧窮人。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 19:24; 創世記 18:20; 創世記 19:5"> 她們自高，在我面前做可憎的事，所以我照著所看見的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="照著所看見的——或譯作「看見時」。">c</a></sup>，除掉了她們。</span>
<span className="v" id="v51" data-v="51" data-xref="耶利米書 3:8–11; 路加福音 12:47–48; 羅馬書 3:9–20"> 至於撒瑪利亞，她犯的罪不及你一半，你使你的可憎之事比她們更多；你做一切可憎的事，使你姐姐反倒顯為義了。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 7:1–5; 以西結書 36:15; 以西結書 16:56"> 你是為你的姐妹辯護，所以你要承受自己的羞辱。因你的罪惡比她們可憎，她們與你相比倒顯為義了；你既然使你的姐妹顯為義，你就要蒙羞，承受自己的羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="以西結書 29:14; 耶利米書 12:16; 以西結書 39:25"> 「我要使她們的擄民回歸<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使她們的擄民回歸——或譯作「復興她們的家業」。">d</a></sup>，就是被擄的所多瑪和她的女兒們、被擄的撒瑪利亞和她的女兒們，以及你那些在她們中間的擄民，</span>
<span className="v" id="v54" data-v="54" data-xref="以西結書 14:22–23; 耶利米書 2:26; 以西結書 36:31–32"> 好讓你承受自己的羞辱；你的行為安慰了她們，所以你要為你所行的一切受辱。</span>
<span className="v" id="v55" data-v="55" data-xref="以西結書 36:11; 瑪拉基書 3:4; 以西結書 16:53"> 那時，你妹妹所多瑪和她的女兒們必恢復到先前的地位，撒瑪利亞和她的女兒們必恢復到先前的地位，你和你的女兒們也必恢復到先前的地位。</span>
<span className="v" id="v56" data-v="56" data-xref="以賽亞書 65:5; 路加福音 15:28–30; 西番雅書 3:11"> 在你心高氣傲的日子裡，你妹妹所多瑪不是你口中的笑柄嗎？</span>
<span className="v" id="v57" data-v="57" data-xref="列王紀下 16:5–7; 以西結書 16:36–37; 歷代志下 28:5–6"> 那時你的惡行還沒有顯露。如今亞蘭女子和她們四圍所有的人，以及你四圍侮慢你的非利士女子，都羞辱你。</span>
<span className="v" id="v58" data-v="58" data-xref="以西結書 23:49; 耶利米哀歌 5:7; 創世記 4:13"> 你的淫穢和你的可憎之事，你都親自承擔了。這是耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="以賽亞書 24:5; 以西結書 17:19; 申命記 29:25"> 「是的，主耶和華如此說：因你輕看誓言，違背誓約，我必照著你所做的對待你。</span>
<span className="v" id="v60" data-v="60" data-xref="何西阿書 2:19–20; 希伯來書 12:24; 以西結書 16:8"> 不過我要記起我在你年幼時與你所立的約，並且還要與你確立永遠的約。</span>
<span className="v" id="v61" data-v="61" data-xref="希伯來書 8:13; 加拉太書 4:26–31; 以賽亞書 66:7–12"> 這樣，當你接納你的姐姐和妹妹時，你就會回想自己的行為而愧疚；我要把她們賜給你作女兒，但不是按著與你所立的約。</span>
<span className="v" id="v62" data-v="62" data-xref="耶利米書 24:7; 以西結書 6:7; 以西結書 39:22"> 我自己要確立我與你的約，那時你就知道：我是耶和華。</span>
<span className="v" id="v63" data-v="63" data-xref="詩篇 39:9; 羅馬書 3:19; 以西結書 36:31–32"> 這樣，當我為你贖清你所犯的一切罪惡時，你就會回想而羞愧，因自己的羞辱而閉口不言。這是主耶和華的宣告。」</span>

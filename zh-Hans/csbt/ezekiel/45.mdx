<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 48:29; 撒迦利亞書 14:20–21; 民數記 34:13"> 「你們為繼業抽籤分地時，要向耶和華獻上一份供地，作為那地中的聖地；要長兩萬五千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="兩萬五千肘——相當於13公里；下同。">a</a></sup>，寬一萬肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一萬肘——相當於5.3公里；下同。">b</a></sup>；它四圍地界內都是神聖的。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 42:16–20; 以西結書 27:28"> 其中一部分用於建聖所，長五百肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五百肘——相當於265公尺；下同。">c</a></sup>，寬五百肘，是四方形的，四周要有五十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十肘——相當於26.5公尺。">d</a></sup>的外圍空地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 48:10"> 你要按這個尺寸測量，長兩萬五千肘，寬一萬肘，其中有聖所，是至聖的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 43:19; 民數記 16:5; 以西結書 40:45"> 它是這地中的聖地，歸屬那些在聖所事奉的祭司，就是近前來事奉耶和華的人；這要作他們的房屋用地和聖所的聖地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 48:13; 尼希米記 10:38–39; 以西結書 48:20"> 還要獻上一份，長兩萬五千肘，寬一萬肘，歸屬那些在聖殿事奉的利未人，作為他們的居住區<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="居住區——依據七十士譯本；馬索拉經文為「二十個房間的地業」。">e</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 48:15–18; 以西結書 48:30–35"> 「你們還要給這城一份地業，寬五千肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="五千肘——相當於2.6公里。">f</a></sup>，長兩萬五千肘，靠近聖供地，歸屬以色列全家。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 48:21; 以西結書 34:24; 以西結書 46:16–18"> 至於歸屬君王的地業，是在聖供地和這城地業的兩邊，面向聖供地和這城的地業，從西邊往西延伸，從東邊往東延伸；它從西邊界到東邊界的跨度，與每支派的地界平行。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 11:3–5; 以西結書 46:18; 以西結書 22:27"> 這是以色列中歸屬君王為地業的土地；我所立的君王們絕不再欺壓我的子民，而是會把土地按支派分給以色列家。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 8:16; 耶利米書 22:3; 以西結書 44:6"> 「主耶和華如此說：以色列的君王們哪，你們夠了吧！你們要除去惡行和迫害，施行公正和公義，終止對我子民的剝奪。這是主耶和華的宣告。</span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 6:10–11; 阿摩司書 8:4–6; 箴言 16:11"> 你們要用公正的天平、公正的量斗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="量斗——原文直譯「伊法」；一伊法相等於22公升，計量穀物的量器。">g</a></sup>、公正的量筒<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="量筒——原文直譯「罷特」；一罷特相當於22公升，計量液體的量器。">h</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:10"> 伊法要與罷特標準一樣：一罷特量筒可容十分之一賀梅珥，一伊法量斗也可容十分之一賀梅珥，度量單位都以賀梅珥<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="賀梅珥——相當於220公升；本章下同。">i</a></sup>為準。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 30:13; 民數記 3:47; 利未記 27:25"> 一謝克爾是二十季拉<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="二十季拉——相當於11.4公克。1季拉=0.57公克。">j</a></sup>；二十謝克爾、二十五謝克爾又十五謝克爾，是你們的一彌納<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一彌納——相當於684公克；對比《列王紀上》10:17。1彌納=60謝克爾。">k</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 「以下是你們要獻上的供物：小麥，每一賀梅珥要獻上六分之一伊法<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="六分之一伊法——相當於3.6公升。1伊法=22公升。">l</a></sup>；大麥，每一賀梅珥要獻上六分之一伊法。</span>
<span className="v" id="v14" data-v="14"> 油的份額，按油的罷特，每一柯珥<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="一柯珥——相當於220公升。">m</a></sup>油要獻上十分之一罷特<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="十分之一罷特——相當於2.2公升。1罷特=22公升。">n</a></sup>；一柯珥相當於十罷特或一賀梅珥，因為一賀梅珥也相當於十罷特。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 1:4; 利未記 6:30; 歌羅西書 1:21"> 至於羔羊，要從以色列水源充足之地的羊群中，每兩百隻取一隻，作為素祭、燔祭和平安祭，為以色列人贖罪。這是主耶和華的宣告。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 30:14–15; 以賽亞書 16:1"> 這地全體民眾要把這樣的供物交給以色列的君王；</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 46:4–12; 歷代志下 31:3; 以賽亞書 66:23"> 君王負責的，是在各節期、新月節和安息日，在以色列家的一切約期，獻上燔祭、素祭和酒祭。他要獻上贖罪祭、素祭、燔祭和平安祭，替以色列家贖罪。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 16:16; 出埃及記 12:2; 以西結書 43:22"> 「主耶和華如此說：一月一日，你要取一頭無瑕疵的公牛，潔淨聖所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 43:20; 以西結書 43:14; 利未記 16:18–20"> 祭司要取來一些贖罪祭的血，抹在聖殿的門柱上、祭壇磴臺的四角上，以及內院的門柱上。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 19:12; 利未記 4:27–35; 以西結書 45:15"> 這月七日，你也要為過失犯罪的人或因無知而犯罪的人照樣做。這樣，就為聖殿行了贖罪禮。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 23:5–8; 哥林多前書 5:7–8; 民數記 9:2–14"> 「一月十四日，你們要守逾越節；節期七天，都要吃無酵餅。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:14; 哥林多後書 5:21; 馬太福音 20:28"> 到那日，君王要為自己和這地所有的民眾獻上一頭贖罪祭公牛。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 42:8; 利未記 23:8; 民數記 23:1–2"> 這七天節期，在七天的每一天，他都要向耶和華獻上燔祭，就是無瑕疵的七頭公牛和七隻公綿羊，每一天還要獻上一隻贖罪祭公山羊。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:5–7; 民數記 28:12–15"> 他還要獻上素祭，每頭公牛配上一伊法細麵，每隻公綿羊配上一伊法細麵，每一伊法細麵配上一欣<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="一欣——相當於3.7公升。">o</a></sup>油。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:33–43; 民數記 29:12–38; 歷代志下 5:3"> 到七月十五日，節期中他一連七天都要這樣獻上贖罪祭、燔祭、素祭和油。</span>
</div>
</div>

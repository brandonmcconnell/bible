<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 38:2–3; 以西結書 35:3; 那鴻書 3:5"> 「人子啊，你要針對歌革發預言說，主耶和華如此說：米設和圖巴的為首領袖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米設和圖巴的為首領袖——或譯作「米設、圖巴和羅施的領袖」。">a</a></sup>歌革啊，看哪，我與你敵對！</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 40:14; 以西結書 38:15; 以賽亞書 37:29"> 我要把你調轉過來，牽引你，把你從極遠的北方帶上來，帶到以色列的群山上。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 76:3; 何西阿書 1:5; 耶利米書 21:4–5"> 我要擊落你左手的弓，打落你右手的箭。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 39:17–20; 以西結書 33:27; 以西結書 38:21"> 你和你的全軍，以及跟著你的各民族，都將倒在以色列的群山上。我要把你交給猛禽、各類飛鳥和田野的走獸，作為食物。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 22:19; 以西結書 32:4; 耶利米書 8:2"> 你必倒在田野上，是的，我已經發了話。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 30:16; 阿摩司書 1:4; 以西結書 30:8"> 「我要降火在瑪格，以及那些安居眾海島的人身上。那時他們就知道：我是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 38:16; 以西結書 38:23; 出埃及記 20:7"> 我要在我子民以色列中間彰顯我的聖名，不讓我的聖名再被褻瀆。那時列國就知道：我是耶和華，是以色列中的至聖者。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 38:17; 啟示錄 16:17; 以西結書 7:2–10"> 看哪，這事臨近了，必定成就。這就是我所說的日子。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:9; 以賽亞書 66:24; 瑪拉基書 1:5"> 「以色列各城的居民將出去，點火焚燒兵器，就是大小盾牌，以及弓箭、棍棒和長矛，用它們燒火七年之久。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 33:1; 以賽亞書 14:2; 彌迦書 5:8"> 他們不必從田野撿木柴，也不必從樹林中伐木，因為他們將用兵器來燒火。他們將擄掠那些擄掠他們的，掠奪那些掠奪他們的。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西結書 47:18; 民數記 34:11; 以西結書 38:2"> 「到那日，我要在以色列給歌革預備一塊墓地，就是鹽海東邊路人經過的山谷，它會擋住過路的人。人們將在那裡埋葬歌革和他的全軍，稱那地為『哈門-歌革谷』。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:23; 以西結書 39:14; 以西結書 39:16"> 以色列家將用七個月埋葬他們，好潔淨那地；</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:22; 西番雅書 3:19–20; 耶利米書 33:9"> 那地所有的民眾都要來埋葬他們。在我得榮耀的日子，這事必使以色列人得名聲。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 39:12; 民數記 19:11–19"> 「他們將分派人時常巡行那地，埋葬地面上殘留的入侵者的屍體，好潔淨那地。過了七個月，他們還要探查。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:44"> 巡行的人經過那地，看見人的骸骨，就會在旁邊立一個標記，等埋葬的人把它埋葬在『哈門-歌革谷』，</span>
<span className="v" id="v16" data-v="16"> 所以那裡的城也名叫哈莫納。這樣他們就潔淨了那地。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="西番雅書 1:7; 啟示錄 19:17–18; 以賽亞書 34:6"> 「人子啊，主耶和華如此說：你要對一切飛鳥和田野的一切走獸說：『你們聚集而來吧！我在以色列群山上為你們祭獻了盛大的祭筵，你們從四圍聚來赴我的祭筵，吃肉喝血吧！</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 22:12; 耶利米書 51:40; 啟示錄 19:17–18"> 你們將吃勇士們的肉，喝那地領袖們的血，他們都是公綿羊、羊羔、公山羊、公牛，是巴珊的肥畜。</span>
<span className="v" id="v19" data-v="19"> 你們將從我為你們祭獻的祭筵上飽餐脂油，醉飲鮮血。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 19:18; 哈該書 2:22; 詩篇 76:5–6"> 你們將在我的筵席上飽餐馬匹、戰車兵、勇士和所有的戰士。這是主耶和華的宣告。』</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 38:16; 以西結書 38:23; 以賽亞書 37:20"> 「我必在列國中彰顯榮耀，萬國都將看見我所施行的審判和我刑罰<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="刑罰——原文直譯「施加於」。">b</a></sup>他們的手。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 24:7; 以西結書 28:26; 以西結書 39:28"> 從那天起，以色列家就知道：我是耶和華他們的神。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 22:8–9; 以賽亞書 1:15; 以賽亞書 59:2"> 列國也會知道，以色列家被擄走是因他們的罪孽。他們對我不忠，因此我向他們隱藏我的臉，把他們交在敵人手中，使他們全都倒在刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 36:19; 耶利米書 2:17; 耶利米書 4:18"> 我照著他們的汙穢和過犯處治他們，向他們隱藏了我的臉。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 34:13; 以賽亞書 27:12–13; 何西阿書 1:11"> 「因此主耶和華如此說：現在我要使雅各的擄民回歸<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使雅各的擄民回歸——或譯作「復興雅各的家業」。">c</a></sup>，我要憐憫以色列全家，為我的聖名發熱心。</span>
<span className="v" id="v26" data-v="26" data-xref="彌迦書 4:4; 列王紀上 4:25; 以西結書 16:63"> 他們必在自己的土地上安然居住，無人驚嚇；那時，他們已承受了自己的羞辱，承擔了所有對我不忠的罪責。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 38:16; 以西結書 38:23; 以西結書 36:23–24"> 當我把他們從各民族中帶回來，從他們仇敵之地招聚回來時，我就藉著他們在許多國家眼前顯為聖了。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 39:22; 阿摩司書 9:9; 以賽亞書 27:12"> 那時他們就知道：我是耶和華他們的神；因為我使他們被擄到了外邦，又把他們招聚到他們的土地上，一個也不留在外邦。</span>
<span className="v" id="v29" data-v="29" data-xref="約珥書 2:28; 約翰一書 3:24; 以賽亞書 32:15"> 那時，我不再向他們隱藏我的臉，因我已經把我的靈傾注在以色列家身上。這是主耶和華的宣告。」</span>
</div>

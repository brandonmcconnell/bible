<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 20:1; 列王紀下 6:32"> 以色列的長老中有些人來到我這裡，坐在我面前。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司書 3:7; 列王紀上 14:4"> 那時耶和華的話語臨到我，說：</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 14:7; 以西結書 7:19; 以西結書 20:3"> 「人子啊，這些人把偶像供奉在心中，把導致犯罪的絆腳石放在自己面前，難道我會接受他們求問嗎？</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 66:4; 以西結書 14:7; 以賽亞書 3:11"> 「因此你要向他們宣告，對他們說，主耶和華如此說：在以色列家中，任何人把偶像供奉在心中，把導致犯罪的絆腳石放在自己面前，又來見先知，我耶和華都必照著他拜偶像的程度<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拜偶像的程度——原文直譯「偶像的眾多」。">a</a></sup>，回應這前來的人，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 1:4; 撒迦利亞書 11:8; 羅馬書 1:28"> 好使我奪回以色列家的心——他們全都因著自己的偶像背離了我！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 18:30; 以賽亞書 30:22; 以西結書 36:31–32"> 「因此你要告訴以色列家，主耶和華如此說：回轉吧！轉離你們的偶像，轉臉離開你們的一切可憎之物！</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:48; 以賽亞書 58:1–2; 利未記 24:22"> 無論以色列家中，還是寄居在以色列的外人中，任何人遠離我，把偶像供奉在心中，把導致犯罪的絆腳石放在自己面前，又來見先知求問我，我耶和華都必親自回應他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 15:7; 耶利米書 44:11; 以西結書 5:15"> 我要向那人翻臉，使他成為鑒戒和笑柄；我要把他從我的子民中間剪除。那時你們就知道：我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:25; 耶利米書 4:10; 詩篇 81:11–12"> 「至於先知，如果被引誘而說神言，那是我耶和華使這先知受了引誘。我要伸手攻擊他，把他從我子民以色列中除滅。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 23:49; 以西結書 14:4; 耶利米書 8:11–12"> 他們必承擔自己的罪責；求問之人的罪責怎樣，先知的罪責也怎樣。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 37:23; 以西結書 44:10; 啟示錄 21:7"> 這樣，以色列家就不再迷失離開我，不再以他們的一切過犯玷汙自己了。他們將要作我的子民，我將要作他們的神。這是主耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和華的話語臨到我，說：</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 26:26; 以西結書 4:16; 以賽亞書 24:20"> 「人子啊，當一個地方行事不忠，對我犯罪時，如果我伸手攻擊那地，斷絕它的糧食供應，降下饑荒，從那裡剪除人和牲畜，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 14:20; 耶利米書 15:1; 以西結書 28:3"> 即使有挪亞、但以理和約伯這三人在那裡，他們也只能因著自己的義救自己的性命。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西結書 5:17; 利未記 26:22; 耶利米書 15:3"> 「如果我使惡獸遍行那地，使那地喪失居民，以致它因野獸而無人經過，變得荒涼，</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:29; 雅各書 5:16; 以西結書 33:11"> 即使有這三人在那裡，我指著我的永生起誓：他們也絕不能救自己的兒女，唯獨他們能得救，那地必變得荒涼。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未記 26:25; 以西結書 21:3–4; 西番雅書 1:3"> 「如果我使刀劍臨到那地，說：『讓刀劍遍行那地，我要從其中剪除人和牲畜』，</span>
<span className="v" id="v18" data-v="18"> 即使有這三人在那裡，我指著我的永生起誓：他們也絕不能救自己的兒女，唯獨他們能得救。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 38:22; 以西結書 5:12; 耶利米書 14:12"> 「如果我使瘟疫降到那地，把我的怒火傾瀉在其上施行殺戮<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="施行殺戮——原文直譯「帶著血」。">b</a></sup>，要從那裡剪除人和牲畜，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:14; 約翰一書 2:29; 以賽亞書 3:10"> 即使有挪亞、但以理和約伯在那裡，我指著我的永生起誓：他們也絕不能救自己的兒女，他們只能因著自己的義救自己的性命。這是主耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 33:27; 以西結書 5:17; 以西結書 14:13"> 「是的，主耶和華如此說：更何況，那時我會把這四樣嚴厲的審判，就是刀劍、饑荒、惡獸和瘟疫，都降到耶路撒冷，要從其中剪除人和牲畜！</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 12:16; 以西結書 20:43; 希伯來書 12:6–11"> 然而，看哪，其中必有逃脫者存留，並且帶出兒女。看哪，他們來到你們這裡，你們看見他們的所作所為，就會因我向耶路撒冷降禍，因我向這城所降的一切而受到安慰。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 22:8–9; 啟示錄 15:4; 申命記 8:2"> 當你們看見他們的所作所為時，你們就因他們而受到安慰。那時你們就知道：我在耶路撒冷所做的一切都不是無故做的。這是主耶和華的宣告。」</span>
</div>
</div>

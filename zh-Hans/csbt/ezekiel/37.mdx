<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 3:22; 以西結書 1:3; 使徒行傳 8:39"> 耶和華的手臨到我身上，耶和華藉著他的靈把我帶出去，安置在平原中間，這平原遍滿骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 141:7; 以西結書 37:11; 申命記 11:30"> 他使我在骸骨之間四處巡行，看哪，它們在平原上極其眾多，看上去極其枯乾。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:25–26; 約翰福音 5:21; 申命記 32:39"> 他問我：「人子啊，這些骸骨能活過來嗎？」<br />我說：「主耶和華啊，你知道。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 5:25; 約翰福音 5:28–29; 馬太福音 21:21"> 他對我說：「你要向這些骸骨發預言，對他們說：枯乾的骸骨啊，你們要聽耶和華的話語！</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 37:14; 詩篇 104:29–30; 創世記 2:7"> 主耶和華對這些骸骨如此說：看哪，我將要使氣息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="氣息——或譯作「靈」；本章下同。">a</a></sup>進入你們裡面，你們必活過來。</span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:27; 以賽亞書 49:23; 約珥書 3:17"> 我要給你們加上筋，附上肉，覆蓋上皮膚，然後使氣息進入你們裡面，你們就會活過來。那時你們就知道：我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 2:2; 列王紀上 19:11–13; 耶利米書 13:5–7"> 於是我照著所受的吩咐說預言。當我說預言的時候，有聲音，看哪，是地震！骨頭就合攏，骨頭連接骨頭。</span>
<span className="v" id="v8" data-v="8"> 我觀看，看哪，骸骨上面有筋，也附上了肉，又有皮膚覆蓋在上面，只是他們裡面還沒有氣息。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:8; 雅歌 4:16; 詩篇 104:30"> 他對我說：「你向氣息發預言吧，人子啊，你要向氣息發預言說，主耶和華如此說：氣息啊，從四方而來，吹進這些死人裡面，使他們活過來！」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 11:11; 詩篇 104:30; 啟示錄 20:4–5"> 於是我照著他所吩咐我的說預言。氣息就進入他們裡面，他們活了過來，雙腳站立，成為極其龐大的軍隊。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:1; 詩篇 77:7–9; 以西結書 39:25"> 他對我說：「人子啊，這些骸骨就是以色列全家。看哪，他們常說：『我們的骨頭枯乾了，我們的希望破滅了，我們被剪除了！』</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 26:19; 何西阿書 13:14; 帖撒羅尼迦前書 4:16"> 因此你要發預言，對他們說，主耶和華如此說：我的子民哪，看，我必打開你們的墳墓，把你們從墳墓裡帶上來，把你們帶回以色列地。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 37:6; 以西結書 16:62; 詩篇 126:2–3"> 我的子民哪，當我打開你們的墳墓，把你們從墳墓裡帶上來時，你們就知道：我是耶和華。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 36:27; 約珥書 2:28–29; 以西結書 36:36"> 我要使我的氣息進入你們裡面，使你們活過來；我要使你們在你們土地上安居。那時你們就知道：我耶和華發了話，就必成就。這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:9; 歷代志下 10:19; 歷代志下 10:17"> 「人子啊，你要取一根木杖，在它上面寫下『猶大和他的同伴以色列人』；再取一根木杖，在它上面寫下『約瑟——以法蓮的杖——和他的同伴以色列全家』。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 1:11; 耶利米書 50:4; 以賽亞書 11:13"> 你要使它們彼此合攏，成為一根杖，在你手中合而為一。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 24:19; 以西結書 12:9; 以西結書 17:12"> 當你的同胞問你說：『能不能告訴我們，你這是什麼意思？』</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 10:6; 以西結書 37:16–17; 以弗所書 2:13–14"> 你要對他們說，主耶和華如此說：看哪，我要拿起約瑟的杖，就是以法蓮和他同伴以色列眾支派手中的杖，與猶大的杖放在一起，使它們成為一根杖，在我手中合而為一。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 12:3; 民數記 17:6–9; 何西阿書 12:10"> 「那時，你要在他們眼前，把你寫上字的兩根木杖拿在手中，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 36:24; 耶利米書 29:14; 耶利米書 23:8"> 對他們說，主耶和華如此說：看哪，我必把以色列子孫從他們所到的列國中帶出來，把他們從四方招聚起來，帶回他們的土地。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 37:24; 以西結書 34:23–24; 耶利米書 3:18"> 我要使他們在那地，在以色列的群山上成為一國，有一位王作他們全體的王；他們再不會是兩個國家，再不會分成兩個王國。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 21:3–4; 以西結書 36:28–29; 約翰一書 1:9"> 他們再也不會以偶像和可憎之物，以及他們的一切過犯而玷汙自己；我必把他們從所犯的一切背道之罪中<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="所犯的一切背道之罪中——依據七十士譯本；馬索拉文本為「犯罪的一切居住之處」。">b</a></sup>拯救出來，潔淨他們。他們將要作我的子民，我將要作他們的神。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 34:23–24; 何西阿書 3:5; 以西結書 37:25"> 我的僕人大衛是他們的王，他們全都歸屬一個牧人。他們將遵從我的法規，謹守遵行我的律例。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="阿摩司書 9:15; 以西結書 37:24; 以西結書 28:25"> 「他們必居住在我賜給我僕人雅各的土地上，就是你們祖先所居住的那地。他們和他們的孩子、子子孫孫，都將居住在其上，直到永遠。我的僕人大衛是他們的君王，直到永遠。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 55:3; 耶利米書 30:19; 以西結書 34:25"> 我要與他們立平安的約，是我與他們永遠的約。我要使他們安居，人數增多；我要把我的聖所永遠設立在他們中間。</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 21:3; 約翰福音 1:14; 以西結書 37:23"> 我的居所要在他們中間，我將要作他們的神，他們將要作我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 17:17–19; 以西結書 20:12; 出埃及記 31:13"> 當我的聖所永遠在他們中間時，列國就知道：我是把以色列分別為聖的耶和華。」</span>
</div>
</div>

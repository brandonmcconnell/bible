<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JOS" data-book-slug="joshua" data-book-name="約書亞記" data-chapter="2" data-verses="24">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:31; 雅各書 2:25; 馬太福音 1:5"> 那時嫩的兒子約書亞從什亭暗中派出兩個人作探子，說：「你們去，察看那地和耶利哥。」他們就去了。他們來到一個名叫拉合的妓女家，就在那裡住下。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 43:13; 但以理書 4:35; 箴言 21:30"> 有人告訴耶利哥王說：「看哪，今夜有人從以色列人那邊來到這裡了，要窺探這地。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 10:3; 創世記 42:9–12; 使徒行傳 12:6"> 耶利哥王就派人到拉合那裡，說：「把那些來到你這裡，進了你家的人交出來！因為他們是來窺探全地的。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 6:19; 撒母耳記下 17:19–20; 撒母耳記下 16:18–19"> 但那婦人已經把兩人帶去藏了起來。她回答：「那些人確實來過我這裡，但我不知道他們來自哪裡。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 50:20; 以西結書 47:12; 啟示錄 21:25"> 天黑關城門的時候，那些人出去了，我也不知道他們去了哪裡。你們趕快追他們吧，一定能追上。」</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 11:23; 雅各書 2:25; 歌羅西書 3:3"> 其實她把他們帶上了屋頂，藏在屋頂上擺放的亞麻稈中。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 3:28; 約書亞記 2:5; 士師記 12:5"> 追趕他們的人朝著約旦河的方向，往渡口追去。追趕的人一出城，城門就關上了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 他們睡下之前，那婦人上了屋頂到他們那裡，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 23:27; 申命記 2:25; 約書亞記 2:11"> 對這二人說：「我知道耶和華已經把這地賜給你們了，並且對你們的恐懼籠罩了我們，這地所有的居民都因你們的緣故而心融膽喪。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:21–35; 出埃及記 15:14–16; 出埃及記 14:21–31"> 因為我們聽說了你們出埃及時，耶和華怎樣在你們面前使紅海的水乾涸，以及你們怎樣處置約旦河對岸那兩個亞摩利王西宏和歐革，把他們滅絕淨盡。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 4:39; 約書亞記 5:1; 約書亞記 7:5"> 我們聽了，心就消融。因你們的緣故，人人再也提不起勇氣，因為耶和華你們的神，他是天上地上的神。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 2:18; 約書亞記 9:18–20; 提摩太後書 1:16–18"> 所以，現在請你們指著耶和華向我起誓：既然我以恩慈對待了你們，你們也要以恩慈對待我的父家；也請給我一個信實的憑據，</span>
<span className="v" id="v13" data-v="13"> 使我的父母、兄弟、姐妹，以及所有屬於他們的人得以存活，救我們的性命免於死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 5:7; 士師記 1:24–25; 創世記 24:49"> 二人回答婦人：「你們如果不泄漏我們這事，我們就以生死來擔保你們。當耶和華把這地賜給我們的時候，我們必以恩慈和真誠對待你。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:25; 哥林多後書 11:33; 約書亞記 6:20"> 於是婦人用繩子把他們從窗口縋下去，因為她的房屋就在城牆上，她住在城牆上。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 2:25; 撒母耳記上 23:14; 詩篇 11:1"> 她對他們說：「你們往山上去，免得追趕的人遇見你們。你們在那裡躲藏三天，等追趕的人回來，然後再上路。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 30:2; 撒母耳記下 21:7; 創世記 24:3–8"> 二人對她說：「你要這樣做，否則，你讓我們起的這誓就與我們無干了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你要這樣做，否則，你讓我們起的這誓就與我們無干了——原文直譯「對於你讓我們起的這誓，我們必清白」。">a</a></sup>：</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 6:23; 約書亞記 2:21; 約書亞記 2:12–13"> 看哪，我們來到這地的時候，你要把這根朱紅的線繩繫在你縋我們下去的窗戶上，並且把你的父母、兄弟以及你的整個父家都聚集到你這房屋裡。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 27:31; 列王紀上 2:36–42; 出埃及記 12:13"> 任何人走出你的家門到外面去，他的血債都要歸在自己頭上，與我們無干；但任何人與你一起在房屋裡，如果有人對他下手，他的血債就歸在我們頭上。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 此外，你如果泄漏我們這事，你讓我們起的誓也就與我們無干了。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 2:5; 約書亞記 2:18; 馬太福音 7:24"> 婦人說：「就照你們的話做吧。」於是她送走他們。他們走後，她把朱紅的線繩繫在窗戶上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 19:10–12; 撒母耳記下 17:20; 詩篇 32:6–7"> 他們離開，來到山上，在那裡停留了三天，直到追趕的人回去。追趕的人一路尋找，都沒有找到。</span>
<span className="v" id="v23" data-v="23"> 二人返回，下了山，過河來到嫩的兒子約書亞那裡，向他講述了他們遇見的一切事。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 23:31; 約書亞記 1:8; 約書亞記 2:9–11"> 他們對約書亞說：「耶和華確實把那全地交在我們手中了，並且那地的居民都因我們的緣故而心融膽喪。」</span>
</div>
</div>

</div>

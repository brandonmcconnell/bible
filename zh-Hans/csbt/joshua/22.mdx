<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 32:18–33; 申命記 29:7–8"> 那時，約書亞召來魯本人、迦得人和瑪拿西半支派的人，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:12–18; 申命記 3:16–20; 民數記 32:20–29"> 對他們說：「你們遵守了耶和華的僕人摩西所吩咐你們的一切，也聽從了我所吩咐你們的一切話。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比書 1:23–27"> 這許多日子以來直到今天，你們沒有離棄你們的兄弟，而是持守了你們的神耶和華規定的職責。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 13:8; 民數記 32:18; 申命記 3:20"> 現在，你們的神耶和華已經照著他所應許的，使你們的兄弟得享安息。所以，你們返回自己的帳篷去吧，回到耶和華的僕人摩西在約旦河對岸給你們的產業之地。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 22:37; 出埃及記 20:6; 羅馬書 8:28"> 只是要特別謹慎，遵行耶和華的僕人摩西所吩咐你們的誡命和律法，愛耶和華你們的神，走在他的一切道路上，遵守他的誡命，緊緊跟隨他，全心、全靈服事他。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:13; 路加福音 24:50; 創世記 47:7"> 然後約書亞祝福他們，讓他們回去，他們就回自己的帳篷去了。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 17:1–12; 民數記 32:33; 約書亞記 13:29–31"> 摩西已經在巴珊給了瑪拿西半支派產業；另外的半支派，約書亞在約旦河西岸使他們與他們的兄弟一同得了產業。約書亞讓他們回自己的帳篷時，祝福了他們，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 31:27; 申命記 8:9–14; 箴言 3:16"> 並吩咐他們說：「你們帶著大量財物，極多的牲畜，金、銀、銅、鐵，極多的衣裳，回自己的帳篷去吧，也要與你們的兄弟分享從仇敵奪來的戰利品。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 32:29; 民數記 32:26; 民數記 32:1"> 魯本子孫、迦得子孫和瑪拿西半支派的人就回去，離開迦南地的示羅，離開以色列子孫，回到基列地，就是他們照耶和華藉著摩西所指示而分得的產業之地。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:26–27; 創世記 31:46–52; 約書亞記 4:5–9"> 他們來到迦南地的約旦河地帶，魯本子孫、迦得子孫和瑪拿西半支派的人就在約旦河旁邊築了一座祭壇，那祭壇很壯觀。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 13:12–14; 利未記 17:8–9; 約書亞記 2:7"> 以色列子民聽到消息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="消息——輔助詞語。">a</a></sup>說：「看哪，魯本子孫、迦得子孫和瑪拿西半支派的人，在迦南地對岸的約旦河地帶，在以色列子民的對面築了一座祭壇。」</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–11; 申命記 13:15; 加拉太書 4:17–18"> 以色列子民聽到了，全體以色列會眾就聚集在示羅，要上去與他們爭戰。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 25:7; 詩篇 106:30–31; 出埃及記 6:25"> 以色列子民派遣以利亞撒的兒子祭司非尼哈，到基列地去見魯本子孫、迦得子孫和瑪拿西半支派的人；</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:4; 出埃及記 18:25"> 還有十個領袖與他同去，以色列每支派中一個父家領袖，每一個都是以色列千軍的父家首領。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 21:3; 撒母耳記上 15:23; 申命記 30:17"> 他們來到基列地魯本子孫、迦得子孫和瑪拿西半支派那裡，與他們講論說：</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 12:13–14"> 「耶和華的全體會眾如此說：這是何等不忠的事啊！你們如今轉離不跟從耶和華，不忠於以色列的神，你們如今為自己築祭壇，背叛了耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 25:1–18; 詩篇 106:28–29; 申命記 4:3–4"> 我們在毗珥的罪孽還不夠嗎？當時瘟疫臨到了耶和華的會眾，而我們至今還沒有洗淨這罪孽。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 16:22; 約書亞記 22:16; 約書亞記 7:11"> 你們今天竟然轉離不跟從耶和華！今天如果你們背叛耶和華，明天他就會對全體以色列會眾發怒。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 18:1; 歷代志下 11:16–17; 使徒行傳 10:14–15"> 如果你們的產業之地真是不潔淨的，你們可以過來，到耶和華的產業之地——耶和華的帳幕所安置的地方，在我們中間得產業；但絕不要背叛耶和華，不要背叛我們，在我們的神耶和華的祭壇以外為自己築祭壇！</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 7:1; 約書亞記 7:5; 約書亞記 7:18"> 謝拉的曾孫亞干難道不是違犯了當滅之物的禁令<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的禁令——輔助詞語。">b</a></sup>，以致震怒臨到了全體以色列會眾嗎？因他罪孽而死的，不只他一個人哪！」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:19; 箴言 16:1; 彼得前書 3:15"> 魯本子孫、迦得子孫和瑪拿西半支派的人，回答以色列千軍的首領們說：</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 8:39; 詩篇 44:21; 申命記 10:17"> 「大能者神耶和華！大能者神耶和華！他是知道的，願以色列也知道。我們如果是叛逆，如果是對耶和華不忠，今天就不要饒過我們<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="饒過我們——或譯作「讓我們得拯救」。">c</a></sup>！</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:16; 申命記 18:19; 以西結書 3:18"> 我們築祭壇如果是要轉離不跟從耶和華，如果是要在壇上獻燔祭、素祭，或是獻上平安祭，就願耶和華親自追討！</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 4:6; 申命記 6:20; 創世記 30:33"> 我們做這事實在是有原因的，是出於憂慮，心想日後你們的子孫會對我們的子孫說：『你們與以色列的神耶和華有什麼相干呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 12:16; 以斯拉記 4:2–3; 撒母耳記上 26:19"> 耶和華在我們與你們魯本子孫、迦得子孫之間劃定了約旦河為界限，你們與耶和華無份。』這樣，你們的子孫就使我們的子孫不再敬畏耶和華了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 「所以我們說：『讓我們行動，為自己築一座祭壇吧。』這不是為獻燔祭，也不是為獻祭物，</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 24:27; 創世記 31:48; 申命記 12:17–18"> 而是要它在我們和你們之間，以及在我們的後代之間作見證，好讓我們到耶和華面前用我們的燔祭、祭物和平安祭來服事他，以免日後你們的子孫對我們的子孫說：『你們與耶和華無份。』</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 25:40; 以西結書 43:10–11; 希伯來書 8:5"> 我們想，日後如果他們對我們或我們的後代這樣說，我們就可以回答：『你們看我們祖先所築的耶和華祭壇的樣式，它不是為獻燔祭，不是為獻祭物，而是要在我們和你們之間作見證。』</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 24:16; 申命記 12:13–14; 約書亞記 22:23"> 我們如今絕不是要背叛耶和華，轉去不跟從耶和華，在我們神耶和華的帳幕前的祭壇以外，築祭壇獻燔祭、素祭和其他祭物。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約書亞記 22:33; 以斯帖記 1:21; 箴言 15:1"> 祭司非尼哈和會眾的領袖們，就是與他同去的以色列千軍的首領，聽見魯本子孫、迦得子孫和瑪拿西子孫所說的話，這在他們眼中看為好。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 15:2; 利未記 26:11–12; 以賽亞書 12:6"> 以利亞撒的兒子祭司非尼哈就對魯本子孫、迦得子孫和瑪拿西子孫說：「今天我們知道：耶和華就在我們當中，因為你們沒有對耶和華行這不忠的事。現在你們救了以色列子民脫離耶和華的手。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約書亞記 22:12–14; 箴言 25:13"> 於是，以利亞撒的兒子祭司非尼哈和領袖們離開了魯本子孫和迦得子孫，從基列地回到迦南地以色列子民那裡，把這話帶給他們。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 29:20; 路加福音 2:28; 但以理書 2:19"> 這事在以色列子民眼中看為好，以色列子民就頌讚神，不再說要上去攻打他們，毀滅魯本子孫、迦得子孫的居住地了。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 22:27; 馬太福音 4:10; 以賽亞書 43:10"> 於是魯本子孫和迦得子孫給那壇起名，說「這壇在我們之間見證：耶和華是神」。</span>
</div>
</div>

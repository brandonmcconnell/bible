<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 23:2; 撒母耳記上 10:19; 創世記 33:18–19"> 約書亞把以色列眾支派都招聚到示劍，召來了以色列的長老、首領、審判官和官長，他們就站在神面前。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:15; 以西結書 16:3; 創世記 31:30"> 約書亞對全體民眾說：<br />「以色列的神耶和華如此說：<br /><span className="pl pl-1">古時你們的祖先，包括亞伯拉罕和拿鶴的父親塔拉，住在大河</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼發拉底河；本章下同。">a</a></sup><br /><span className="pl pl-1">對岸，服事別的神。</span></span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1–4; 創世記 21:2–3; 使徒行傳 7:2–3"> <span className="pl pl-1">那時我把你們的祖先亞伯拉罕從大河對岸帶過來，帶領他走遍迦南全地，又使他後裔增多。我把以撒賜給他，</span></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 36:8; 申命記 2:5; 創世記 25:24–26"> <span className="pl pl-1">又把雅各和以掃賜給以撒；我把西珥山賜給以掃為產業，而雅各和他的子孫下埃及去了。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:10; 出埃及記 7:1–12; 詩篇 105:26–36"> <span className="pl pl-1">我又派遣了摩西和亞倫，藉著我在埃及人當中所行的打擊埃及，然後把你們領出來。</span></span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 7:36; 希伯來書 11:29; 以賽亞書 63:12–13"> <br /><span className="pl pl-1">我領你們祖先出埃及，來到了海邊。埃及人帶著戰車和馬兵，追趕你們祖先到紅海。</span></span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:34; 出埃及記 14:10; 出埃及記 14:20"> <br /><span className="pl pl-1">你們祖先呼求耶和華，他就使黑暗隔在你們和埃及人之間，使海水衝來淹沒他們。你們親眼看見了我在埃及所做的，並在曠野中住了許多日子。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民數記 21:21–35; 詩篇 135:10–11; 尼希米記 9:22"> <span className="pl pl-1">我把你們領到住在約旦河對岸的亞摩利人之地。他們與你們爭戰，我把他們交在你們手中，你們就擁有了那些土地，我也把他們從你們面前除滅了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="士師記 11:25; 彌迦書 6:5; 民數記 22:2"> <br /><span className="pl pl-1">後來西撥的兒子摩押王巴勒起來與以色列爭戰，派人把比珥的兒子巴蘭召來詛咒你們。</span></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 23:5; 民數記 24:5–10; 以賽亞書 54:17"> <br /><span className="pl pl-1">我不願垂聽巴蘭，反而使他再三祝福你們，這樣我解救你們脫離了巴勒的手。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 4:10–12; 約書亞記 3:14–17; 詩篇 114:5"> <span className="pl pl-1">你們過了約旦河，來到耶利哥。耶利哥人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人——原文直譯「主人」。">b</a></sup><br /><span className="pl pl-1">，以及亞摩利人、比利洗人、迦南人、赫提人、革迦撒人、希未人、耶布斯人，都曾與你們爭戰，我把他們交在你們手中。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:20; 出埃及記 23:28; 詩篇 44:3–6"> <br /><span className="pl pl-1">我派出黃蜂在你們前面，從你們面前驅逐了亞摩利人的兩個王，不是用你的刀，也不是用你的弓。</span></span>
<span className="v" id="v13" data-v="13" data-xref="申命記 6:10–12; 申命記 8:7; 約書亞記 21:45"> <br /><span className="pl pl-1">我把不是你們辛勞所得的土地賜給了你們；不是你們建造的城，你們住在其中，不是你們栽種的葡萄園和橄欖園，你們得以享用。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 12:24; 申命記 10:12; 創世記 35:2"> 「所以，你們要敬畏耶和華，真誠無偽地服事他，除掉你們祖先在大河對岸和埃及所服事的神明，而服事耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:21; 約翰福音 6:67–68; 路得記 1:15–16"> 但如果你們不願意服事耶和華<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不願意服事耶和華——原文直譯「眼中看服事耶和華不好」。">c</a></sup>，你們今天就選擇要服事誰吧：或是你們祖先在大河對岸所服事的神明，或是你們所住之地亞摩利人的神明。至於我和我的家，我們必服事耶和華！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 10:38–39; 撒母耳記上 12:23; 羅馬書 6:2"> 民眾回應說：「我們絕不離棄耶和華去服事別的神！</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 19:4; 以賽亞書 63:7–14; 以賽亞書 46:4"> 因為是我們的神耶和華親自把我們和我們的祖先從埃及地為奴之家帶了上來，他在我們眼前行了那些大神蹟，並且在我們所走的整個路途中、所經過的一切民族中保護了我們。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 4:2; 出埃及記 10:2; 詩篇 116:16"> 耶和華還從我們面前驅逐了各民族，包括住在這地的亞摩利人。所以我們也必服事耶和華，因為他是我們的神。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 5:16; 出埃及記 23:21; 詩篇 99:9"> 約書亞對民眾說：「你們不能服事耶和華！因為他是聖潔的神，他是忌邪的神，他不會饒恕你們的過犯和罪惡。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 10:26–27; 以西結書 18:24; 歷代志上 28:9"> 如果你們離棄耶和華，服事外邦的神明，那麼，他在降福給你們之後，必轉而降禍給你們，把你們滅絕。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 20:19; 以賽亞書 44:5; 申命記 5:27–28"> 民眾回答約書亞：「不，我們一定要服事耶和華！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 119:173; 詩篇 119:11; 約伯記 15:6"> 約書亞對民眾說：「你們就是自己的見證人：你們自己選擇了服事耶和華！」<br />他們說：「我們是見證人！」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:16–18; 約書亞記 24:14; 希伯來書 12:28–29"> 約書亞說：「那麼現在，你們要除掉你們當中的外邦神明，一心歸向耶和華以色列的神。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 24:7; 出埃及記 24:3; 申命記 5:27–29"> 民眾回答約書亞：「我們必服事耶和華我們的神，聽從他的話。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="尼希米記 9:38; 歷代志下 23:16; 出埃及記 15:25"> 約書亞就在那一天為民眾立約，在示劍為他們立定律例和法規。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 9:6; 創世記 35:4; 約書亞記 4:20–24"> 約書亞把這些話寫在神的律法書上，又取來一塊大石頭，立在耶和華聖所旁的橡樹下。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 約書亞記 22:34; 約書亞記 22:27–28"> 約書亞對全體民眾說：「看哪，這塊石頭給我們作見證，因為它聽見了耶和華對我們所說的一切話。它給你們作見證，免得你們否認你們的神。」</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 2:6"> 然後約書亞遣散民眾，讓各人回自己的繼業之地去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 2:8; 提摩太後書 4:7–8; 申命記 34:5"> 這些事以後，耶和華的僕人嫩的兒子約書亞死了，享年一百一十歲。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:50; 士師記 2:9; 撒母耳記下 23:30"> 人們把他葬在他繼業的境內，在迦實山的北邊，以法蓮山地的亭拿-西拉。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 2:7; 申命記 31:13; 申命記 11:2"> 約書亞在世的日子以及他死後，那些知道耶和華為以色列所行一切事的長老們還在世的日子，以色列人都服事耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 50:25; 創世記 33:19; 出埃及記 13:19"> 以色列子孫從埃及帶上來的約瑟的骸骨，葬在了示劍，葬在雅各用一百個銀錢從示劍之父哈莫爾的兒子們買下的那塊地裡，這地成為了約瑟子孫的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 22:13; 出埃及記 6:25; 以賽亞書 57:1–2"> 亞倫的兒子以利亞撒也死了，人們把他葬在他兒子非尼哈在以法蓮山地分得的小山上。</span>
</div>
</div>

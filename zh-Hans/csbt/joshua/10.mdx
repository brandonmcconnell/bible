<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 6:21; 希伯來書 7:1; 約書亞記 8:2"> 耶路撒冷王亞多尼·希德聽說約書亞攻取了艾城並把它滅絕淨盡，怎樣處置耶利哥城和它的王，也怎樣處置了艾城和它的王；也聽說基遍的居民與以色列人講和了，歸附於他們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="歸附於他們——原文直譯「在他們當中」。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:25; 約書亞記 2:24; 出埃及記 15:14–16"> 耶路撒冷的人就極其害怕，因為基遍是個大城，像一座王城，比艾城更大，城裡的人都是勇士。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:9; 彌迦書 1:13; 約書亞記 10:1"> 耶路撒冷王亞多尼·希德派人去見希伯崙王霍含、雅爾慕王皮蘭、拉吉王雅非亞和伊磯倫王底璧，說：</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 9:15; 約書亞記 10:1; 以賽亞書 8:9–10"> 「你們上我這裡來幫助我吧，我們一起攻打基遍，因為他們與約書亞和以色列人講和了。」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 8:9–10; 創世記 15:16; 約書亞記 10:6"> 於是亞摩利人的五個王——耶路撒冷王、希伯崙王、雅爾慕王、拉吉王、伊磯倫王聚集起來，帶著他們所有的軍兵上去，對著基遍紮營，攻打它。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 9:6; 約書亞記 5:10; 申命記 1:15"> 基遍人就派人到吉甲營地去見約書亞，說：「不要袖手不顧你的奴僕，請趕快上我們這裡來，拯救我們，幫助我們，因為住在山地的亞摩利諸王都聚集來攻擊我們了。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 8:1; 以賽亞書 8:12; 以賽亞書 8:14"> 於是約書亞和跟隨他的全體軍兵，以及所有的英勇戰士，都從吉甲上去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 8:31; 申命記 3:2; 詩篇 27:1–2"> 耶和華對約書亞說：「不要怕他們，因為我已經把他們交在你手中了，他們當中沒有一個人能在你面前站立得住。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="傳道書 9:10; 提摩太後書 2:3; 箴言 24:11–12"> 約書亞連夜從吉甲上去，突然進攻他們。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:14; 約書亞記 16:3; 約書亞記 16:5"> 耶和華使他們在以色列人面前潰亂，以色列人在基遍大大擊殺他們，沿著伯賀崙山坡的路追趕、擊殺他們，直到亞西加和瑪克達。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 28:2; 士師記 5:20; 詩篇 18:12–14"> 他們從以色列人面前逃跑，正在伯賀崙的下坡那裡時，耶和華從天上降下大冰雹在他們身上，直到亞西加，他們就被砸死了。那時死於冰雹的，比以色列人用刀殺死的還多。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="哈巴谷書 3:11; 以賽亞書 38:8; 以賽亞書 60:20"> 當時，就在耶和華把亞摩利人交給以色列子民的那一天，約書亞求告耶和華，他在以色列人眼前說：<br /><span className="pl pl-1">「太陽啊，停留在基遍；</span><br /><span className="pl pl-1">月亮啊，停留在阿雅崙谷！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 3:11; 以賽亞書 38:8; 約書亞記 10:14"> 太陽就停住，月亮就站住，直到這民報復了他們的仇敵。這不都記在《雅煞爾書》<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="《雅煞爾書》——或譯作「《正直人之書》」；是古以色列的詩歌集，已失傳。">b</a></sup>上嗎？<br /><span className="pl pl-1">太陽在天空中站住，不急於下落，</span><br /><span className="pl pl-1">大約整整一天。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 1:30; 出埃及記 14:14; 約書亞記 10:42"> 這以前或者以後，耶和華都沒有像這一天那樣垂聽人的禱告；這是耶和華在為以色列爭戰。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:43; 約書亞記 10:6"> 然後，約書亞和跟隨他的以色列全軍返回吉甲的營地。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 24:8; 阿摩司書 9:2; 詩篇 139:7–10"> 那五個王逃跑，躲藏在瑪克達的洞穴裡。</span>
<span className="v" id="v17" data-v="17"> 有人向約書亞報告說：「那五個王找到了，躲藏在瑪克達的洞穴裡。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:66; 約伯記 21:30; 阿摩司書 9:1"> 約書亞說：「把幾塊大石頭滾到洞口，派人在洞口看守他們！</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:37–41; 耶利米書 8:14; 以賽亞書 9:14–15"> 你們不要停留，要追擊你們的仇敵，從後面擊殺他們，不讓他們逃回城裡，因為你們的神耶和華已經把他們交在你們手中了。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 8:24; 撒母耳記下 20:6; 約書亞記 10:10"> 於是，約書亞和以色列人大大擊殺他們，直到把他們滅盡了，只剩下一些倖存者逃進堡壘城。這事結束之後，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 11:7; 以賽亞書 54:17; 以賽亞書 57:4"> 全體軍兵平安回到瑪克達營地約書亞那裡，再沒有人敢對任何以色列人饒舌了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 15:32"> 約書亞說：「打開洞口，把那五個王從洞穴裡給我帶出來！」</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 10:1; 約書亞記 10:5; 約書亞記 10:3"> 人們就這樣做，把那五個王——耶路撒冷王、希伯崙王、雅爾慕王、拉吉王、伊磯倫王，從洞穴裡帶出來，帶到約書亞面前。</span>
<span className="v" id="v24" data-v="24" data-xref="瑪拉基書 4:3; 羅馬書 16:20; 啟示錄 2:26–27"> 當他們把那些王帶到約書亞那裡，約書亞就召來以色列的全體軍兵，對同行的軍隊統帥們說：「你們上前來，把腳踏在這些王的脖子上。」他們就上前來，把腳踏在那些王的脖子上。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 1:10; 約書亞記 1:9; 以弗所書 6:10"> 約書亞對他們說：「不要害怕，不要喪膽。你們要堅強、勇敢，因為耶和華必這樣處置你們所攻打的一切仇敵。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約書亞記 8:29; 撒母耳記下 21:9; 馬太福音 27:25"> 隨後，約書亞處死了那五個王，把他們掛在五棵樹上。他們被掛在樹上，直到傍晚。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 8:29; 申命記 21:22–23; 約書亞記 7:26"> 到了日落的時候，約書亞下令，人們就把他們從樹上取下來，扔進他們曾經躲藏的洞穴裡，並把幾塊大石頭堆在洞口，那石堆至今還在。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 6:21; 申命記 7:16; 申命記 20:16–17"> 那天約書亞攻取瑪克達，用刀擊殺了那城和它的王，把城裡的人都滅絕淨盡，沒有留下一人存活。他處置瑪克達王，像處置耶利哥王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 21:13; 約書亞記 15:42; 耶利米書 52:1"> 約書亞和跟隨他的以色列全軍，又從瑪克達前往立拿，攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和華把那城和它的王都交在以色列手中，約書亞把城裡的人都用刀擊殺了，沒有留下一人存活。他處置立拿王，像處置耶利哥王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 10:3; 約書亞記 12:11; 約書亞記 10:5"> 約書亞和跟隨他的以色列全軍，又從立拿前往拉吉，對著城紮營，攻打它。</span>
<span className="v" id="v32" data-v="32"> 耶和華把拉吉交在以色列手中，約書亞在第二天就攻取了它，把城裡的人都用刀擊殺了，就像他對立拿所做的一切。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 16:10; 士師記 1:29; 約書亞記 16:3"> 那時基色王何蘭上來幫助拉吉，約書亞擊敗了他和他的軍隊，沒有給他留下一人存活。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 10:3; 約書亞記 12:12; 約書亞記 15:39"> 約書亞和跟隨他的以色列全軍，又從拉吉前往伊磯倫，對著城紮營，攻打它。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 26:44; 約書亞記 10:37; 約伯記 19:10"> 他們當天就攻取了它，用刀擊殺那城。那一天約書亞把城裡的人滅絕淨盡，就像他對拉吉所做的一切。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 1:10; 約書亞記 15:13; 約書亞記 14:13–14"> 約書亞和跟隨他的以色列全軍，又從伊磯倫上到希伯崙，攻打它。</span>
<span className="v" id="v37" data-v="37"> 他們攻取那城，把它的王和所有附屬的城鎮以及其中的人都用刀擊殺了，沒有留下一人存活，就像他對伊磯倫所做的一切。他滅絕了那城和其中所有的人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約書亞記 15:15; 約書亞記 12:13; 約書亞記 15:49"> 約書亞和跟隨他的以色列全軍，又轉向底璧，攻打它。</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亞書 1:18; 約書亞記 11:8; 申命記 3:3"> 他攻取那城，用刀擊殺它的王，擊殺它所有附屬的城鎮，把其中的人都滅絕淨盡，沒有留下一人存活。他怎樣處置希伯崙、處置立拿和它的王，也怎樣處置底璧和它的王。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 7:2–16; 出埃及記 23:31–33; 約書亞記 8:27"> 這樣，約書亞擊敗了那全地，就是山地、南地、丘陵<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地、丘陵——音譯作「內蓋夫、示非拉」。">c</a></sup>、山坡地帶，以及他們所有的王，沒有留下一人存活，他照著以色列的神耶和華所指示的，把一切有氣息的都滅絕淨盡。</span>
<span className="v" id="v41" data-v="41" data-xref="約書亞記 11:16; 約書亞記 15:51; 申命記 9:23"> 約書亞擊敗他們，從加低斯-巴尼亞直到加沙，從歌珊全地直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 10:14; 詩篇 46:7; 詩篇 80:3"> 約書亞一次就征服了這些王以及他們的領土，因為是以色列的神耶和華在為以色列爭戰。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 10:15; 約書亞記 4:19; 撒母耳記上 11:14"> 然後，約書亞和跟隨他的以色列全軍返回吉甲營地。</span>
</div>
</div>

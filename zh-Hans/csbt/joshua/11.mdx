<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 11:10; 詩篇 2:1–4; 士師記 4:2"> 哈佐王耶賓聽說了這些事，<br /><span className="pl pl-1">就派人去見瑪頓王約巴、</span><br /><span className="pl pl-1">希姆崙王、阿克沙弗王，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 12:3; 士師記 1:27; 約書亞記 17:11"> <span className="pl pl-1">還有北方山地的眾王，</span><br /><span className="pl pl-1">革尼勒南邊的亞拉巴、</span><br /><span className="pl pl-1">示非拉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亞拉巴、示非拉——或譯作「流域荒灘、丘陵地帶」。">a</a></sup><br /><span className="pl pl-1">、西邊多珥高地的眾王，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:3; 約書亞記 18:26; 創世記 31:49"> <span className="pl pl-1">以及東邊和西邊的迦南人，</span><br /><span className="pl pl-1">山地的亞摩利人、赫提人、比利洗人、耶布斯人，</span><br /><span className="pl pl-1">黑門山腳下米斯巴地的希未人。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 7:12; 撒母耳記上 13:5; 創世記 32:12"> 於是，他們和他們的全軍一起出來，有許多軍兵，多如海邊的沙，還有極多的戰車馬匹。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:10–12; 啟示錄 16:14; 以賽亞書 8:9"> 這些王都會合起來，到米倫水邊一同紮營，與以色列作戰。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 10:8; 撒母耳記下 8:4; 士師記 20:28"> 耶和華對約書亞說：「不要怕他們，因為明天這個時候，我必使他們全都死在以色列面前。你要砍斷他們馬的蹄筋，用火燒毀他們的戰車。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 10:9; 帖撒羅尼迦前書 5:2–3"> 於是約書亞和跟隨他的全體軍兵突然來到米倫水邊，襲擊他們。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:6; 約書亞記 19:28; 撒迦利亞書 9:2"> 耶和華把他們交在以色列人手中，以色列人就擊殺他們，追擊他們直到西頓大城、米斯利弗-瑪音以及東邊的米斯巴平原。以色列人擊殺他們，沒有留下一人存活。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 11:6; 以西結書 39:9–10"> 約書亞照著耶和華吩咐他的處置他們，砍斷他們馬的蹄筋，用火燒毀了他們的戰車。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 11:1; 士師記 4:2"> 那時，約書亞又轉去攻取哈佐，用刀擊殺了哈佐王，因為之前哈佐是這些王國的首領。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 10:40; 申命記 20:16"> 他們把城裡的人都擊殺了，滅絕於刀刃之下，沒有留下任何有氣息的，然後放火燒毀了哈佐。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 20:16–17; 申命記 7:2; 民數記 33:50–53"> 約書亞征服了這些王以及他們所有的城鎮，用刀擊殺他們，照著耶和華的僕人摩西所吩咐的把他們滅絕淨盡。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 30:18"> 只是所有坐落在高崗上的城，除了哈佐以外，以色列人都沒有燒毀，約書亞只燒毀了哈佐。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:14; 民數記 31:9; 約書亞記 8:27"> 這些城所有的財物和牲畜，以色列人都掠奪歸於自己，只把所有的人都用刀擊殺了，直到除滅他們，沒有留下任何有氣息的。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 1:7; 出埃及記 34:11–13; 使徒行傳 20:20"> 耶和華怎樣指示他的僕人摩西，摩西就怎樣指示約書亞，約書亞也就怎樣做。耶和華所指示摩西的一切話，約書亞都沒有偏離。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約書亞記 10:41; 約書亞記 11:21; 約書亞記 12:8"> 這樣，約書亞奪取了那全地——就是山地、整個南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音譯作「內蓋夫」。">b</a></sup>、歌珊全地、示非拉、亞拉巴<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="示非拉、亞拉巴——或譯作「丘陵地帶、流域荒灘」。">c</a></sup>——以色列的山地和丘陵，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 7:24; 約書亞記 11:3; 約書亞記 13:5"> 從往西珥上去的哈拉山，直到黑門山腳下黎巴嫩平原的巴力迦得。他征服那裡所有的王，擊敗他們，把他們處死了。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 14:7–10; 約書亞記 11:23"> 約書亞與這些王作戰，有許多日子。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 9:3–27"> 除了基遍的居民希未人以外，沒有一城與以色列人講和，都是以色列人作戰奪取的。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:18; 申命記 20:16–17; 出埃及記 4:21"> 因為這是出於耶和華，要使他們的心剛硬，來迎戰以色列，為要使他們滅絕淨盡，使他們不蒙憐憫而被除滅，正如耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 9:2; 民數記 13:22–23; 約書亞記 15:13–14"> 那時約書亞前來剪除了亞衲人，他們分佈<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他們分布——輔助詞語。">d</a></sup>在山地、希伯崙、底璧、阿納布，以及整個猶大山地、整個以色列山地。約書亞把他們和他們的城鎮滅絕淨盡。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 17:4; 歷代志上 18:1; 約書亞記 15:46"> 以色列人境內沒有留下一個亞衲人，只在加沙、迦特和阿實突存留了一些。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約書亞記 21:44–45; 民數記 26:52–55; 約書亞記 14:1–15"> 約書亞照著耶和華所指示摩西的一切，奪取了全地，然後按照以色列的支派劃分，把地分給他們為繼業。於是國中太平，沒有戰爭。</span>
</div>
</div>

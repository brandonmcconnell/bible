<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:9; 申命記 1:38; 申命記 31:23"> 耶和華的僕人摩西死了以後，耶和華指示摩西的助手<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="助手——或譯作「侍從」。">a</a></sup>嫩的兒子約書亞，說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 3:28; 申命記 31:7; 民數記 27:16–21"> 「我的僕人摩西死了，現在你要起來，與這全體民眾過約旦河，到我所要賜給他們——以色列子民的那地去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 11:24; 約書亞記 14:9; 提多書 1:2"> 你們腳掌踏上的每一個地方，我都已經照著應許摩西的，賜給你們了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 23:31; 創世記 15:18–21; 申命記 3:25"> 從曠野和黎巴嫩直到幼發拉底大河，赫提人的全地，直到日落方向的大海，都將成為你們的領土。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:31; 申命記 31:6–8; 馬太福音 28:20"> 你一生的日子，必沒有人能在你面前站立得住。我怎樣與摩西同在，也將怎樣與你同在；我必不撇下你，也不離棄你。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理書 10:19; 以弗所書 6:10; 約書亞記 1:9"> 「你要堅強、勇敢！你必定使這子民繼承那地，就是我向他們先祖起誓要賜給他們的那地。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 22:13; 申命記 5:32; 約書亞記 1:8"> 你一定要堅強，極其勇敢，謹守遵行我僕人摩西所吩咐你的一切律法，不偏離左右，好使你無論往哪裡去都行事通達。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 119:15; 詩篇 19:14; 歌羅西書 3:16"> 不要讓這律法書離開你的口，而要晝思夜想，好使你謹守遵行其中所記的一切。這樣你的道路才會順利，你才會通達。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 28:15; 耶利米書 1:7–8; 約書亞記 1:6–7"> 我不是吩咐你了嗎？要堅強、勇敢！不要恐懼，不要喪膽，因為你無論往哪裡去，你的神耶和華都必與你同在。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 於是約書亞吩咐民眾的官長，說：</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:1; 何西阿書 6:2; 列王紀下 20:5"> 「你們要走遍營中，吩咐民眾說：『當預備好食物，因為三天之內，你們就要過約旦河，去占有你們的神耶和華將賜給你們的那地，去擁有它。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 32:20–22"> 約書亞對魯本人、迦得人和瑪拿西半支派的人說：</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 32:20–28; 申命記 3:18–20; 約書亞記 22:1–4"> 「你們要記得耶和華的僕人摩西所吩咐你們的話，他說：『你們的神耶和華必使你們得享安息，他必賜給你們這地。』</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:8; 出埃及記 13:18; 啟示錄 17:4"> 你們的妻子、孩子以及牲畜可以留在約旦河對岸摩西給你們的土地上，但你們所有英勇的戰士要整裝列隊，在你們的弟兄前面過去，幫助他們，</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 2:4; 民數記 32:17–22; 哥林多前書 12:26"> 直到耶和華使你們的兄弟像你們一樣得享安息，並且擁有了你們的神耶和華將要賜給他們的那地。那時你們才可以回到你們的產業之地，擁有耶和華的僕人摩西在約旦河東岸給你們的那地。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="提多書 3:1; 申命記 5:27; 彼得前書 2:13–15"> 他們回答約書亞說：「你吩咐我們的一切，我們都會遵行；你派遣我們去的任何地方，我們都會去。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 1:5; 列王紀上 1:37; 約書亞記 1:9"> 我們從前怎樣在一切事上聽從摩西的，現在也會照樣聽從你。唯願你的神耶和華與你同在，就像他與摩西同在那樣。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 6:10; 約書亞記 1:9; 以斯拉記 10:4"> 任何人違背你的命令，不聽從你所吩咐的一切話，都必被處死。你只要堅強、勇敢！」</span>
</div>
</div>

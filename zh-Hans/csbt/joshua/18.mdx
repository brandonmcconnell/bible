<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 19:51; 撒母耳記上 1:3; 約書亞記 21:2"> 全體以色列會眾聚集在示羅，把會幕安置在那裡，那地已經被他們征服了。</span>
<span className="v" id="v2" data-v="2"> 以色列子民中剩下七個支派，還沒有分得繼業。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 18:9; 箴言 13:4; 箴言 10:4"> 約書亞對以色列子民說：「你們要拖延到什麼時候，才去占有你們祖先的神耶和華所賜給你們的土地呢？</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 18:6; 約書亞記 4:2; 約書亞記 18:3"> 你們按著支派帶來三個人，我要派遣他們。他們要起身走遍那地，按著各支派繼業的份做記錄，然後回到我這裡。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 16:1–10; 約書亞記 19:1–9; 約書亞記 15:1–12"> 他們要把地分成七份；猶大留在南方自己的境內，約瑟家留在北方自己的境內。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:2; 約書亞記 18:10; 使徒行傳 13:19"> 你們把那七份地做好記錄，把記錄拿到我這裡來，我要在這裡，在我們的神耶和華面前為你們抽籤。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 13:33; 約書亞記 13:8–31; 民數記 18:20"> 利未人在你們中間沒有繼業的份，因為耶和華的祭司職份就是他們的繼業。至於迦得、魯本和瑪拿西半支派，他們已經在約旦河東岸得了繼業，是耶和華的僕人摩西分給他們的。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 18:10; 羅馬書 14:19; 撒母耳記上 14:41"> 於是，那些人起身前往。約書亞吩咐前往記錄那地的人說：「你們要去，走遍那地，把它記錄好，然後回到我這裡來。我要在示羅，在耶和華面前為你們抽籤。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 13:19"> 那些人就去，走遍全地，按著城鎮把它分為七份，記錄在冊子上，然後回到示羅營地約書亞那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 1:12; 使徒行傳 13:19; 約書亞記 18:6"> 約書亞就在示羅，在耶和華面前為他們抽籤。約書亞在那裡，照著他們的支派劃分，把土地分給了以色列子民。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 16:1–10; 約書亞記 15:1–8; 申命記 10:1–22"> 便雅憫支派按著他們的家族抽籤，他們的籤抽出來，地界是在猶大子孫和約瑟子孫之間。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 16:1; 約書亞記 7:2; 約書亞記 2:1"> 他們北面的邊界是從約旦河開始，上到耶利哥北邊的山坡，又往西上去，穿過山地，終點在伯亞文曠野。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 28:19; 約書亞記 16:2–3; 約書亞記 10:11"> 邊界又從那裡經過路斯，往南到路斯山坡，路斯就是伯特利；然後邊界下到亞塔羅-亞達珥，靠近下伯賀崙南邊的山。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:9; 歷代志上 13:5–6; 撒母耳記上 7:1–2"> 邊界又轉向，從南邊伯賀崙對面的山繞到西邊又往南，終點是猶大子孫的城基列-巴力，就是基列-耶琳。這是西面的疆界。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 15:9"> 南面從基列-耶琳的邊緣為起點，邊界往西延伸，到尼弗多亞水泉。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:10; 約書亞記 15:7–8; 以賽亞書 30:33"> 邊界又下到欣嫩子谷對面、利乏音谷北邊那座山的邊緣，再下到欣嫩子谷，沿著耶布斯的南坡下到恩羅格爾；</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 15:6"> 再轉向北，延伸到恩示麥，又延伸到阿杜米姆山坡對面的格利錄，又下到魯本之子波罕的磐石那裡；</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 15:6; 約書亞記 15:61"> 又向北經過亞拉巴對面的山坡，下到亞拉巴流域。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:3; 約書亞記 15:2; 民數記 34:3"> 邊界又經過伯霍格拉的北坡，邊界的終點是約旦河南端鹽海北邊的灣汊。這是南面的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 約旦河被劃定為東面的疆界。<br />這就是便雅憫子孫按著他們的家族，按著他們四圍的邊界所得的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 18:12; 約書亞記 6:1; 約書亞記 18:19"> 便雅憫支派按著他們的家族所得的城鎮有：<br />耶利哥，伯霍格拉，伊麥基悉，</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 15:6; 列王紀上 12:29–32; 約書亞記 18:18"> 伯亞拉巴，策瑪蓮，伯特利，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 13:17"> 阿維姆，帕拉，俄弗拉，</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 2:26; 約書亞記 21:17; 以賽亞書 10:29"> 克法阿莫尼，俄弗尼，迦巴，共十二座城，還有附屬的村莊；</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 9:17; 列王紀上 3:4–5; 約書亞記 10:2"> 基遍，拉瑪，比錄，</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 10:17; 以斯拉記 2:25; 約書亞記 9:17"> 米斯巴，克非拉，莫扎，</span>
<span className="v" id="v27" data-v="27"> 利肯，伊利培勒，塔爾阿拉，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 21:14; 約書亞記 15:8; 士師記 20:4–5"> 洗拉，以利弗，耶布斯——就是耶路撒冷，基比亞，基列，共十四座城，還有附屬的村莊。<br />這就是便雅憫子孫按著他們的家族所得的繼業。</span>
</div>
</div>

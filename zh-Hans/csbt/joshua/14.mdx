<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 34:17–29"> 以下是以色列子民在迦南地分得的繼業，是祭司以利亞撒和嫩的兒子約書亞，以及以色列子孫各支派父系的首領分給他們的，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 33:54; 民數記 34:13; 民數記 26:55–56"> 是按照耶和華藉著摩西所指示的，以抽籤的方式把繼業分給了九個半支派。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 13:14; 約書亞記 13:8; 約書亞記 13:32–33"> 那時摩西已經在約旦河對岸，把繼業分給了兩個半支派，不過沒有在他們中間給利未人分繼業；</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 48:5; 歷代志上 5:1–2; 民數記 35:2–8"> 約瑟子孫是兩個支派，瑪拿西和以法蓮。利未人沒有在那地分得繼業，只得了城鎮居住，還有附屬的牧野，好安置他們的牲畜財產。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 21:2; 民數記 35:1–2"> 耶和華怎樣指示摩西，以色列子民就怎樣做，分配了土地。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民數記 14:30; 民數記 13:6; 民數記 14:24"> 那時，猶大子孫前來吉甲見約書亞，基尼洗人耶弗尼的兒子迦勒對約書亞說：「你知道，在加低斯-巴尼亞，耶和華對神人摩西論到你和我的那些話。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:6; 民數記 13:26–33; 民數記 14:6–10"> 耶和華的僕人摩西派遣我從加低斯-巴尼亞去窺探這地時，我四十歲；我給他帶回了發自內心的報告。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 14:24; 申命記 1:36; 民數記 13:31"> 雖然與我一同上去的兄弟們使民眾的心融化，我卻全心跟從耶和華我的神。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 1:3; 申命記 1:36; 民數記 14:22–24"> 所以，摩西那天起誓說：『你腳所踏之地必定歸於你和你的子孫為繼業，直到永遠，因為你全心跟從耶和華我的神。』</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民數記 14:33–34; 民數記 14:30; 約書亞記 11:18"> 「現在看哪，自從耶和華對摩西說了這話以來，耶和華照著他所應許的使我存活了這四十五年，這期間以色列一直走在曠野。你看，我現在八十五歲了。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 34:7; 詩篇 103:5; 申命記 31:2"> 我今天還是強壯，像摩西派遣我去的那天一樣。當時我的力量怎樣，如今我的力量還是怎樣，能出入，能作戰。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:33; 腓立比書 4:13; 民數記 13:33"> 所以，請你把耶和華那天所應許的這些山地分給我。你那天確實也聽到了，那裡有亞衲人，有高大堅固的城；但如果耶和華與我同在，我必趕出他們，正如耶和華所應許的。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 1:20; 約書亞記 22:6; 歷代志上 6:55–56"> 約書亞就祝福他，把希伯崙給了耶弗尼的兒子迦勒為繼業。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 14:8–9; 哥林多前書 15:58"> 因此希伯崙成為基尼洗人耶弗尼的兒子迦勒的繼業，直到今日，因為他全心跟從耶和華以色列的神。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 11:23; 創世記 23:2; 約書亞記 15:13"> 希伯崙從前名叫基列-阿爾巴，阿爾巴原是亞衲人中的偉人。<br />於是國中太平，沒有戰爭。</span>
</div>
</div>

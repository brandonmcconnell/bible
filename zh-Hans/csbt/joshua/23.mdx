<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 13:1; 約書亞記 21:44; 約書亞記 11:23"> 耶和華使以色列脫離四圍一切仇敵得享安息，後來又過了許多日子，約書亞老了，上了年紀。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:1; 申命記 31:28; 歷代志上 28:1"> 約書亞召來全體以色列人——他們的長老、首領、審判官和官長，對他們說：「我已經老了，上了年紀。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 14:14; 約書亞記 10:42; 約書亞記 10:14"> 你們的神耶和華為你們的緣故向這些國家所行的一切，你們都看見了；是耶和華你們的神，親自為你們爭戰。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 13:6–7; 約書亞記 18:10; 約書亞記 13:2"> 你們看，我已經把剩下的這些國家，還有我所剪除的各國，從約旦河到日落方向的大海，都抽籤分給了你們，作為你們各支派的繼業。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 11:23; 約書亞記 13:6; 出埃及記 33:2"> 你們的神耶和華會親自把他們從你們面前驅逐出去，從你們面前趕出去，你們必占有他們的土地，正如你們的神耶和華向你們所應許的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 5:32; 申命記 28:14; 箴言 4:26–27"> 「你們要格外堅強，謹守遵行摩西律法書上所記的一切，不偏離左右，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 23:13; 詩篇 16:4; 申命記 7:2–3"> 不與這些留在你們中間的民族往來。他們神的名，你們不可提起，不可指著起誓；你們不可服事那些神明，不可向它們下拜。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 10:20; 約書亞記 22:5; 申命記 13:4"> 只要緊緊跟隨耶和華你們的神，正如你們至今所行的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約書亞記 1:5; 申命記 11:23; 約書亞記 23:5"> 「耶和華已經從你們面前趕出強大的民族，至今沒有一個人在你們面前站立得住。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:30; 利未記 26:8; 申命記 3:22"> 你們一人能追趕千人，因為是你們的神耶和華照著他向你們所應許的，親自為你們爭戰。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 22:5; 申命記 6:5–12; 箴言 4:23"> 所以你們要極力保守自己的靈魂，愛耶和華你們的神。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:3; 以西結書 18:24; 西番雅書 1:6"> 如果你們決然轉離，與留在你們中間的這些民族的遺民聯結，與他們通婚，彼此往來，</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 7:16; 民數記 33:55; 出埃及記 23:33"> 你們要確實知道：你們的神耶和華必不再從你們面前趕出這些民族，他們將成為你們的網羅、陷阱，成為你們肋旁的鞭子、眼中的荊棘，直到你們在你們神耶和華所賜的這美地上滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王紀上 2:2; 利未記 26:3–13"> 「看哪，如今我就要走世人都必走的路了。你們要全心全意認識到：你們的神耶和華向你們所說的一切美好應許，沒有一句落空，全都應驗在你們身上了，他的話語沒有一句落空。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; 利未記 26:14–46; 士師記 3:8"> 你們的神耶和華對你們所說的一切美好應許，怎樣應驗在你們身上，耶和華也會怎樣使一切禍患的事都應驗在你們身上，直到把你們從你們神耶和華所賜的這美地上除滅。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:25–26; 列王紀下 24:20"> 如果你們違背你們的神耶和華為你們立定的約，去服事別的神，向它們下拜，耶和華的怒氣必向你們發作，你們就會從他所賜給你們的美地上迅速滅亡。」</span>
</div>

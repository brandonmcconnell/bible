<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 34:6; 出埃及記 3:17; 出埃及記 23:23"> 約旦河對岸所有的王，就是在山地、丘陵地帶、黎巴嫩對面大海沿岸整個地區的王——赫提人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人的王，他們聽見了這事，</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 16:14; 約珥書 3:9–13; 詩篇 2:1–2"> 就聚集在一起，一口同聲要與約書亞和以色列人爭戰。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約書亞記 10:2; 約書亞記 9:17; 撒母耳記下 21:1–2"> 基遍的居民聽說了約書亞對耶利哥和艾城所做的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 馬太福音 10:16; 馬可福音 2:22"> 就用詭計採取行動。他們去預備了乾糧，在驢背上馱著破舊的麻袋和裂開又縫補過的破舊酒囊，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命記 33:25; 申命記 29:5"> 腳上穿著補過的舊鞋，身上穿著破舊的衣服，所有預備的乾糧都是乾硬發霉的。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 5:10; 列王紀下 20:14; 約書亞記 9:9"> 他們前往吉甲營地，到了約書亞那裡，對他和以色列人說：「我們從遙遠之地而來，現在求你們與我們立約。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 11:19; 士師記 2:2; 出埃及記 34:12"> 以色列人對這些希未人說：「或許你們就住在我們附近，那我們怎能與你們立約呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 20:11; 列王紀下 10:5; 約書亞記 9:11"> 他們對約書亞說：「我們是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="是——或譯作「願作」。">a</a></sup>你的奴僕。」<br />約書亞問他們：「你們是什麼人，從哪裡來？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 20:15; 約書亞記 9:24; 以賽亞書 55:5"> 他們回答約書亞：「你的奴僕為了你的神耶和華的名，從遙遠之地而來。我們聽說了他的名聲和他在埃及所做的一切，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:24–35; 申命記 1:4; 約書亞記 12:4"> 以及他向約旦河對岸的兩個亞摩利王——希實本王西宏和亞斯他錄的巴珊王歐革——所做的一切。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 9:8; 以斯帖記 8:17; 約書亞記 1:11"> 所以我們的長老和本地所有的居民對我們說：『你們手中拿著路上用的食物，去迎見他們吧。要對他們說：我們是<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="是——或譯作「願作」。">b</a></sup>你們的奴僕，現在求你們與我們立約！』</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 9:4–5"> 我們出發來你們這裡的那天，從家裡預備的這乾糧還是熱的，現在你看，它們都乾硬發霉了。</span>
<span className="v" id="v13" data-v="13"> 這些酒囊裝滿酒的時候還是新的，看哪，現在它們都裂開了。還有我們的這些衣服和鞋子，由於路途太遙遠，現在都破舊了。」</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民數記 27:21; 歷代志上 10:13–14"> 人們接過來他們的一些乾糧查看<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="查看——輔助詞語。">c</a></sup>，卻沒有請示耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 21:2; 申命記 20:10–11; 約書亞記 11:19"> 約書亞與他們講和，並與他們立約，讓他們存活；會眾的領袖們也向他們起了誓。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 以色列人與他們立約之後，過了三天才聽說他們是近鄰，住在附近。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 2:25; 約書亞記 18:25–28; 約書亞記 18:14"> 於是以色列人就出發，第三天來到他們的城鎮，他們的城鎮是基遍、克非拉、比錄、基列-耶琳。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 15:4; 撒母耳記下 21:7; 傳道書 5:6"> 以色列人沒有攻擊他們，因為會眾的領袖們已經指著以色列的神耶和華向他們起了誓。全體會眾就向領袖們發怨言。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="傳道書 8:2; 約書亞記 9:20; 傳道書 9:2"> 眾領袖對全體會眾說：「我們已經指著以色列的神耶和華向他們起了誓，如今不能碰他們了。</span>
<span className="v" id="v20" data-v="20" data-xref="瑪拉基書 3:5; 箴言 20:25; 提摩太前書 1:10"> 我們要這樣處置他們：讓他們存活，以免因我們向他們所起的誓，就有震怒臨到我們。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 29:11; 約書亞記 9:27; 約書亞記 9:23"> 領袖們吩咐會眾要讓他們存活，於是他們成了給全體會眾砍柴打水的人，正如領袖們向他們承諾的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約書亞記 9:6; 約書亞記 9:16; 創世記 3:13–14"> 約書亞把基遍人召來，責問他們說：「你們怎麼欺騙我們說『我們離你們很遠』？其實你們就住在我們附近。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 9:21; 創世記 9:25–26; 約書亞記 9:27"> 如今你們是受詛咒的！你們必不會停止作奴僕，要為我神的殿作砍柴打水的人。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 20:15–17; 申命記 7:1–2; 出埃及記 23:31–33"> 他們回答約書亞說：「因為有人確切告訴過你的奴僕：你的神耶和華曾指示他的僕人摩西，要把全地賜給你們，並且要把這地所有的居民從你們面前除滅。所以，因你們的緣故，我們極其害怕失去性命，就做了這事。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 16:6; 士師記 10:15; 耶利米書 26:14"> 現在看哪，我們在你手中，你看怎樣好、怎樣合適，就怎樣處置我們吧！」</span>
<span className="v" id="v26" data-v="26"> 於是約書亞這樣處置了他們，他解救他們脫離以色列人的手，以色列人就沒有殺他們。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5"> 那一天，約書亞使他們在耶和華所選擇的地方，為會眾和耶和華的祭壇作砍柴打水的人，直到今日。</span>
</div>
</div>

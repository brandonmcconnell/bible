<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 22:20; 傳道書 9:18; 歷代志上 2:6–7"> 然而，以色列子民違犯了當滅之物的禁令<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的禁令——輔助詞語。">a</a></sup>，猶大支派謝拉的曾孫、扎布迪的孫子、迦米的兒子亞干，取走了一些當滅之物。於是，耶和華的怒氣向以色列子民發作。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約書亞記 18:12; 何西阿書 4:15; 撒母耳記上 14:23"> 當時約書亞從耶利哥派人去艾城，在伯特利東邊，靠近伯亞文。他吩咐他們說：「你們上去窺探那地。」那些人就上去窺探艾城。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯來書 6:11–12; 路加福音 13:24; 彼得後書 1:5"> 他們回到約書亞那裡，對他說：「不用所有人都上去，大約兩三千人上去就能攻取艾城。不用勞煩所有人去那裡，因為他們人很少。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:25; 利未記 26:17; 申命記 32:30"> 於是軍中約有三千人上那裡去，結果他們在艾城的人面前逃跑了。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 2:11; 約書亞記 2:9; 利未記 26:36"> 艾城的人擊殺了他們大約三十六人，又從城門前追趕他們，直到示巴琳，在下坡那裡擊殺他們。軍兵的心都消融如水。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 37:29; 創世記 37:34; 啟示錄 18:19"> 約書亞就撕裂衣服，他和以色列的長老們在耶和華約櫃前臉伏於地，直到傍晚，並且把塵土撒在自己頭上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 12:5; 列王紀下 3:10; 馬太福音 17:20"> 約書亞說：「唉，主耶和華啊！你為什麼非要讓這民眾過約旦河，把我們交在亞摩利人手中，消滅我們呢？還不如讓我們留在約旦河對岸。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:5–6; 以斯拉記 9:10; 哈巴谷書 2:1"> 哦，主啊，我還能說什麼呢？以色列已經在仇敵面前轉身而逃！</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 32:12; 詩篇 83:4; 以西結書 36:22–23"> 迦南人和這地所有的居民聽見這事，必圍攻我們，從這地上剪除我們的名。那時你為你的大名還能做什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:22; 出埃及記 14:15; 撒母耳記上 16:1"> 耶和華對約書亞說：「你起來吧！為什麼這樣臉伏於地呢？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:1–2; 希伯來書 4:13; 約書亞記 6:17–19"> 以色列犯了罪！他們竟然違背我為他們立定的約，取走了當滅之物；他們竟然偷竊、哄騙，把它們放進自己的物品中。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 5:4–5; 以賽亞書 59:2; 約書亞記 6:18"> 所以，以色列子民在他們的仇敵面前站立不住；他們從仇敵面前轉身而逃，是因為他們自己成了當滅之物。如果你們不把當滅之物從你們中間滅盡，我就不再與你們同在了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 約書亞記 3:5; 馬太福音 7:5"> 「你起來，把這民眾分別為聖，吩咐他們為了明天潔淨自己。因為以色列的神耶和華如此說：『以色列啊，你們中間有當滅之物！除非把當滅之物從你們中間除掉，你們絕不能在仇敵面前站立得住。』</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 約拿書 1:7; 約書亞記 7:17–18"> 明天早晨，你們要按著支派上前來，然後耶和華抽取的支派，要按著家族上前來；耶和華抽中的家族，要按著家庭上前來；耶和華抽中的家庭，要按著男丁上前來。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 34:7; 撒母耳記上 14:38–39; 士師記 20:6"> 最後，那個取了當滅之物而被抽出來的人，他和屬於他的一切都要被火燒掉，因為他違背了耶和華的約，也因為他在以色列做了愚頑的事。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:60; 約書亞記 3:1; 創世記 22:3"> 於是約書亞清早起來，讓以色列人按著支派上前來，猶大支派就被抽中了。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 26:20; 歷代志上 2:4–7; 創世記 38:30"> 他讓猶大家上前來，然後抽中了謝拉的家族；又讓謝拉家族的男丁一個個上前來，然後扎布迪被抽中了；</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 32:23; 使徒行傳 5:1–10; 撒母耳記上 14:42"> 又讓扎布迪家的男丁一個個上前來，結果猶大支派謝拉的曾孫、扎布迪的孫子、迦米的兒子亞干被抽出來了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 6:5; 耶利米書 13:16; 約翰福音 9:24"> 約書亞就對亞干說：「我兒啊，你要把榮耀歸給耶和華以色列的神，向他認罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="認罪——原文直譯「獻上感謝」。">b</a></sup>。請告訴我你做了什麼，不要向我隱瞞。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 38:18; 約伯記 33:27; 創世記 42:21"> 亞干回答約書亞，說：「我確實對以色列的神耶和華犯了罪！我是這樣做的：</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:15; 詩篇 119:37; 約翰一書 2:15–16"> 我看見戰利品中，有一件漂亮的示拿外衣、兩百謝克爾<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="兩百謝克爾——相當於2,280公克。1謝克爾=11.4公克。">c</a></sup>銀子、一條重五十謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十謝克爾——相當於570公克。">d</a></sup>的金子，我就貪愛它們，把它們拿走了。看哪，它們都藏在我帳篷內的地裡，銀子在外衣底下。」</span>
<span className="v" id="v22" data-v="22"> 約書亞就派遣使者，他們跑到帳篷那裡，看哪，東西果然藏在亞干的帳篷中，銀子在外衣底下。</span>
<span className="v" id="v23" data-v="23"> 他們把這些東西從帳篷裡拿出來，帶到約書亞和全體以色列子民那裡，攤放在耶和華面前。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前書 6:9–10; 約書亞記 7:26"> 約書亞就和全體以色列人一起帶著謝拉的曾孫亞干，還有那銀子、外衣、金條，以及他的兒女、牛、驢、羊，他的帳篷和屬於他的一切，上到亞割谷。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:18; 歷代志上 2:7; 利未記 24:14"> 約書亞說：「你為什麼給我們帶來禍患呢？今天耶和華也要給你帶來禍患。」於是全體以色列人用石頭把他砸死了，然後用火焚燒這一切，又把石頭扔在其上。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 65:10; 何西阿書 2:15; 申命記 13:17"> 人們在他上面堆了一大堆石頭，那石堆至今還在。於是耶和華收回了他猛烈的怒氣。因此那地方名叫亞割谷，直到今日。</span>
</div>
</div>

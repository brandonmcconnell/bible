<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:1; 約書亞記 19:51; 約書亞記 17:4"> 那時，利未人各父系的首領前來見祭司以利亞撒和嫩的兒子約書亞，以及以色列子孫各支派父系的首領，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 18:1; 民數記 35:2–8; 馬太福音 10:10"> 在迦南地的示羅對他們說：「耶和華曾藉著摩西指示，要給我們城鎮居住，也為我們的牲畜提供周圍的牧野。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 49:7; 申命記 33:8–10; 歷代志上 6:54–81"> 以色列子民就照耶和華的吩咐，從自己的繼業中分給利未人以下城鎮和附屬的牧野：</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志上 6:54–60; 約書亞記 24:33; 約書亞記 21:8–19"> 第一支籤為哥轄的各家族抽出來。這些利未人，祭司亞倫的子孫從猶大支派、西緬支派、便雅憫支派的產業中，抽籤得了十三座城；</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 21:20–26; 出埃及記 6:16–25; 歷代志上 6:66–70"> 哥轄其餘的子孫，從以法蓮支派各家族、但支派、瑪拿西半支派的產業中，抽籤得了十座城。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 21:27–33; 歷代志上 6:71–76; 出埃及記 6:16–17"> 革順的子孫，從以薩迦支派各家族、亞設支派、拿弗他利支派，以及在巴珊的瑪拿西半支派的產業中，抽籤得了十三座城。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:34–40; 歷代志上 6:77–81; 出埃及記 6:19"> 米拉利的子孫，按著他們的家族，從魯本支派、迦得支派、西布倫支派的產業中，得了十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 21:3; 約書亞記 18:6; 民數記 33:54"> 這樣，以色列子民照耶和華藉著摩西所指示的，把這些城和附屬的牧野抽籤分給了利未人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志上 6:65; 約書亞記 21:13–18"> 他們從猶大支派、西緬支派中，把以下點到名字的城分出來，</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 21:4; 民數記 3:27; 出埃及記 6:20–26"> 給利未人中哥轄各家族的亞倫子孫，因為第一支籤給了他們。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 6:55; 路加福音 1:39; 撒母耳記下 5:1–5"> 以色列人給了他們猶大山地的基列-阿爾巴和四圍的牧野；阿爾巴是亞衲人的祖先，基列-阿爾巴就是希伯崙。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 14:13–15; 歷代志上 6:55–57"> 至於這城的田野和附屬的村莊，以色列人已經給了耶弗尼的兒子迦勒為產業。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 15:42; 約書亞記 10:29; 約書亞記 15:54"> 祭司亞倫的子孫分得了殺人者的逃城希伯崙和附屬的牧野，還有立拿和附屬的牧野，</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:48; 約書亞記 15:50; 撒母耳記上 30:27–28"> 雅提珥和附屬的牧野，以實提莫和附屬的牧野，</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 15:49; 約書亞記 15:51; 約書亞記 12:13"> 霍崙和附屬的牧野，底璧和附屬的牧野，</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 15:10; 歷代志上 6:59; 約書亞記 15:55"> 阿音和附屬的牧野，猶特和附屬的牧野，伯示麥和附屬的牧野；共九座城，都是出自這兩個支派。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約書亞記 18:24–25; 約書亞記 9:3; 歷代志上 6:60"> 從便雅憫支派中，他們得了基遍和附屬的牧野，迦巴和附屬的牧野，</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 10:30; 歷代志上 6:60; 耶利米書 1:1"> 亞納圖和附屬的牧野，阿勒蒙和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 作祭司的亞倫子孫總共得了十三座城，還有附屬的牧野。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 6:66; 約書亞記 21:5"> 利未人哥轄子孫的其他家族，就是哥轄其餘的子孫抽籤：<br />從以法蓮支派中，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 20:7; 士師記 9:1; 列王紀上 12:1"> 分得了殺人者的逃城以法蓮山地的示劍和附屬的牧野，還有基色和附屬的牧野，</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 6:68; 約書亞記 16:3; 約書亞記 18:13–14"> 基伯先和附屬的牧野，伯賀崙和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約書亞記 19:44–45"> 從但支派中，他們得了伊利特克和附屬的牧野，基比頓和附屬的牧野，</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 19:42; 約書亞記 10:12; 歷代志上 6:69"> 阿雅崙和附屬的牧野，迦特臨門和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 17:11; 士師記 5:19"> 從瑪拿西半支派中，他們得了特納克和附屬的牧野，迦特臨門和附屬的牧野，共兩座城。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 哥轄其餘子孫的各家族，總共得了十座城，還有附屬的牧野。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 6:71; 申命記 1:4; 約書亞記 20:8"> 利未人各家族中革順的子孫，<br />從瑪拿西半支派中，得了殺人者的逃城巴珊的戈蘭和附屬的牧野，還有比施提拉和附屬的牧野，共兩座城。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 19:12; 歷代志上 6:72–73"> 從以薩迦支派中，得了其雄和附屬的牧野，達比拉和附屬的牧野，</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 10:23; 約書亞記 12:11; 約書亞記 10:3"> 雅爾慕和附屬的牧野，恩干寧和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="歷代志上 6:74–75; 約書亞記 19:25–28"> 從亞設支派中，得了米沙勒和附屬的牧野，阿布頓和附屬的牧野，</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 18:21; 歷代志上 6:75; 士師記 1:31"> 赫爾卡特和附屬的牧野，利合和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歷代志上 6:76; 約書亞記 20:7; 約書亞記 19:37"> 從拿弗他利支派中，得了殺人者的逃城加利利的基低斯和附屬的牧野，還有哈末多珥和附屬的牧野，加珥坦和附屬的牧野，共三座城。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 革順人按著他們的家族，總共得了十三座城，還有附屬的牧野。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歷代志上 6:77; 約書亞記 19:11; 約書亞記 21:7"> 其餘的利未人，就是米拉利子孫的各家族，<br />從西布倫支派中，得了約念和附屬的牧野，加珥他和附屬的牧野，</span>
<span className="v" id="v35" data-v="35"> 丁拿和附屬的牧野，拿哈拉和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約書亞記 20:8; 申命記 4:43; 民數記 21:23"> 從魯本支派中，得了比冊爾和附屬的牧野，雅哈茲和附屬的牧野，</span>
<span className="v" id="v37" data-v="37"> 基底莫和附屬的牧野，米法押和附屬的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 32:2; 列王紀上 22:3; 歷代志上 6:80"> 從迦得支派中，得了殺人者的逃城基列的拉末和附屬的牧野，還有瑪哈念和附屬的牧野，</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 16:8–9; 民數記 32:35; 民數記 32:1"> 希實本和附屬的牧野，雅謝和附屬的牧野，總共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 以上是利未人其餘的家族，就是米拉利子孫的各家族所有城鎮，他們抽籤得了十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 35:1–8; 申命記 33:10; 創世記 49:7"> 利未人在以色列子孫的產業中，總共得了四十八座城，還有附屬的牧野。</span>
<span className="v" id="v42" data-v="42"> 這些城四圍都有附屬的牧野，這些城全都如此。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 13:15; 詩篇 106:42–45; 出埃及記 23:27–31"> 這樣，耶和華把他起誓要賜給以色列先祖的全地，都賜給了以色列人，他們占領那地，住在其中。</span>
<span className="v" id="v44" data-v="44" data-xref="約書亞記 11:23; 希伯來書 4:9; 申命記 31:3–5"> 耶和華照著向他們先祖所起誓的一切，使他們四圍安定下來。他們一切仇敵，沒有一個能在他們面前站立得住，耶和華把他們的仇敵全都交在了他們手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 8:56; 約書亞記 23:14–15; 民數記 23:19"> 耶和華對以色列家所說的一切美好應許，沒有一句落空，全都應驗了。</span>
</div>
</div>

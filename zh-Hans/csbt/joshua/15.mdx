<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JOS" data-book-slug="joshua" data-book-name="約書亞記" data-chapter="15" data-verses="63">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:55–56; 約書亞記 14:2; 民數記 33:36–37"> 猶大支派按著家族抽籤所得之地，是在最南邊，到以東的邊界，往南到尋的曠野。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="創世記 14:3; 以西結書 47:8; 以賽亞書 11:15"> 南面的邊界是從鹽海下端南邊的灣汊開始，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 34:4; 士師記 1:36; 民數記 20:1"> 往南穿過阿克拉賓斜坡，沿著尋的曠野，從加低斯-巴尼亞南邊上去，經過希斯倫，上到阿達爾，繞到卡爾卡，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 34:5; 約書亞記 13:3; 出埃及記 23:31"> 又經過阿茲蒙，沿著埃及河下去，邊界的終點是大海。這就是他們南面的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 34:12; 約書亞記 18:15–19; 民數記 34:10"> 東面的邊界是鹽海，直到約旦河的南端。<br />北面的邊界從約旦河南端的灣汊開始，</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 18:17; 約書亞記 18:19–21"> 上到伯霍格拉，經過伯亞拉巴的北邊，然後上到魯本之子波罕的磐石那裡。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 1:9; 撒母耳記下 17:17; 約書亞記 7:26"> 邊界又從亞割谷上到底璧，往北轉到阿杜米姆山坡對面、溪谷南邊的吉甲；然後邊界經過恩示麥水泉，終點是恩羅格爾。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 18:16; 約書亞記 15:63; 約書亞記 18:28"> 邊界又從欣嫩子谷上到耶布斯的南坡——耶布斯就是耶路撒冷，然後上到西邊欣嫩子谷對面、利乏音谷北端的山頂。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 13:6; 約書亞記 18:15; 士師記 18:12"> 邊界又從山頂轉向尼弗多亞水泉，穿過以弗崙山的城鎮，然後轉到巴阿拉，就是基列-耶琳。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 14:1; 士師記 14:5; 創世記 38:12–13"> 邊界又從巴阿拉往西繞到西珥山，經過耶琳山的北坡——也就是克撒崙；然後下到伯示麥，經過亭拿。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 15:45; 列王紀下 1:2–3; 撒母耳記上 5:10"> 邊界又延伸到以革倫的北坡，然後轉向希克崙，經過巴阿拉山，延伸到雅比聶；邊界的終點是大海。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="民數記 34:6–7; 約書亞記 15:47; 以西結書 47:20"> 西面的邊界是大海和海岸線。<br /><span className="pl pl-1">以上是猶大子孫各家族四圍的邊界。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 13:30; 申命記 1:34–36; 民數記 14:23–24"> 約書亞照著耶和華的吩咐，把猶大子孫當中的一份地——基列-阿爾巴——分給了耶弗尼的兒子迦勒；基列-阿爾巴就是希伯崙，阿爾巴是亞衲人的祖先。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:20; 士師記 1:10; 民數記 13:22–23"> 迦勒從那裡趕出三支亞衲子孫——示篩、亞希幔、塔爾邁，都是亞衲人的後裔。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:38; 約書亞記 10:3; 士師記 1:11–13"> 他又從那裡上去攻打底璧的居民，底璧從前名叫基列西弗。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 1:12–13; 士師記 1:6"> 迦勒說：「誰攻打基列西弗，攻取那城，我就把女兒婭撒嫁給他為妻。」</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 3:9; 士師記 1:13; 約書亞記 14:6"> 迦勒的弟弟基納斯的兒子俄陀聶攻取了那城，迦勒就把女兒婭撒嫁給他為妻。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 24:64; 撒母耳記上 25:23"> 婭撒出嫁的時候，鼓動丈夫從她父親那裡求一塊田。她下了驢，迦勒問她：「你有什麼事呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 1:14–15; 撒母耳記上 25:27; 申命記 33:7"> 她就說：「求你給我一個祝福：你既然把南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音譯作「內蓋夫」。">a</a></sup>給了我，請你把水泉也給我。」於是迦勒把上泉和下泉都給了她。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:8–12; 申命記 33:7"> 以下是猶大支派按著他們的家族所得的繼業：</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 35:21; 尼希米記 11:25"> 猶大支派最南邊靠近以東邊界的城鎮，有卡布策勒，伊德，雅古爾，</span>
<span className="v" id="v22" data-v="22"> 基拿，底摩拿，亞大達，</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 12:22; 民數記 33:37; 申命記 1:19"> 基低斯，哈佐，伊特楠，</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 23:14; 撒母耳記上 23:24; 撒母耳記上 23:19"> 西弗，特勒姆，比亞錄，</span>
<span className="v" id="v25" data-v="25"> 哈佐-哈達特，加略-希斯倫——就是哈佐，</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 4:28"> 亞曼，示瑪，漠拉達，</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 11:26"> 哈薩伽達，赫示蒙，伯帕列，</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 26:33; 歷代志上 4:28; 創世記 21:31–33"> 哈薩書爾，比爾-謝巴，比斯猶提亞，</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 15:9–11; 約書亞記 19:3; 歷代志上 4:29"> 巴阿拉，伊音，埃曾，</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:4; 民數記 14:45; 申命記 1:44"> 伊利多拉，克希爾，霍爾瑪，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 27:6; 撒母耳記上 30:1; 歷代志上 12:1"> 洗革拉，瑪德曼納，參參納，</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 34:11; 尼希米記 11:29"> 利巴奧，希津，阿音，臨門，總共二十九座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 13:25; 士師記 16:31; 民數記 13:23"> 在丘陵地帶，有以實陶，佐拉，亞實拿，</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 12:17; 約書亞記 15:53"> 撒挪亞，恩干寧，塔普阿，恩納因，</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 17:1; 撒母耳記上 22:1; 約書亞記 10:3"> 雅爾慕，亞杜蘭，梭哥，亞西加，</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 17:52"> 沙拉音，阿迪塔音，格德拉（格德羅塔音），共十四座城，還有附屬的村莊。</span>
<span className="v" id="v37" data-v="37"> 策楠，哈達沙，米格達-迦得，</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 14:7; 士師記 20:1; 撒母耳記上 10:17"> 迪勒安，米斯巴，約克帖，</span>
<span className="v" id="v39" data-v="39" data-xref="約書亞記 10:3; 列王紀下 22:1; 約書亞記 10:31–32"> 拉吉，波斯加，伊磯倫，</span>
<span className="v" id="v40" data-v="40"> 卡本，拉瑪斯，其特利示，</span>
<span className="v" id="v41" data-v="41" data-xref="約書亞記 10:21; 約書亞記 12:16; 約書亞記 10:10"> 格德羅，伯大衮，拿瑪，瑪克達，共十六座城，還有附屬的村莊。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 10:29; 列王紀下 8:22; 約書亞記 19:7"> 立拿，伊特爾，阿珊，</span>
<span className="v" id="v43" data-v="43"> 耶弗塔，亞實拿，尼茨布，</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 38:5; 彌迦書 1:14–15; 撒母耳記上 23:1–14"> 基伊拉，阿克濟，瑪利沙，共九座城，還有附屬的村莊。</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 13:3; 阿摩司書 1:8; 撒母耳記上 6:17"> 以革倫和附屬的村鎮、村莊；</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 26:6; 阿摩司書 1:8; 撒母耳記上 5:1"> 從以革倫直到大海，所有靠近阿實突邊界的城鎮，以及附屬的村莊；</span>
<span className="v" id="v47" data-v="47" data-xref="約書亞記 15:4; 出埃及記 23:31; 阿摩司書 1:6–7"> 阿實突和附屬的村鎮、村莊；加沙和附屬的村鎮、村莊；直到埃及河、大海和海岸線。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約書亞記 21:14"> 在山地，有沙米爾，雅提珥，梭哥，</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 15:15; 士師記 1:11"> 達納，基列薩拿——就是底璧，</span>
<span className="v" id="v50" data-v="50"> 阿納布，以實提莫，阿尼姆，</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 11:16; 約書亞記 10:41; 撒母耳記下 15:12"> 歌珊，霍崙，基羅，共十一座城，還有附屬的村莊。</span>
<span className="v" id="v52" data-v="52" data-xref="以賽亞書 21:11"> 阿拉布，魯瑪，伊珊，</span>
<span className="v" id="v53" data-v="53"> 雅努姆，伯塔普阿，阿非卡，</span>
<span className="v" id="v54" data-v="54" data-xref="約書亞記 15:13; 創世記 23:2; 約書亞記 14:15"> 胡姆塔，基列-阿爾巴——就是希伯崙，齊奧爾，共九座城，還有附屬的村莊。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳記上 25:2; 約書亞記 15:24; 撒母耳記上 23:25"> 瑪雲，迦密，西弗，猶特，</span>
<span className="v" id="v56" data-v="56"> 耶斯列，約克甸，撒挪亞，</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 15:10; 創世記 38:12; 耶利米書 14:1"> 基尼，基比亞，亭拿，共十座城，還有附屬的村莊。</span>
<span className="v" id="v58" data-v="58" data-xref="歷代志上 4:39"> 哈爾胡勒，伯促爾，格多，</span>
<span className="v" id="v59" data-v="59"> 瑪拉特，伯阿諾特，伊勒特孔，共六座城，還有附屬的村莊。</span>
<span className="v" id="v60" data-v="60" data-xref="約書亞記 18:14; 撒母耳記上 7:1"> 基列-巴力——就是基列-耶琳，拉巴，共兩座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="約書亞記 15:6; 約書亞記 18:18"> 在曠野，有伯亞拉巴，米丁，西喀喀，</span>
<span className="v" id="v62" data-v="62" data-xref="撒母耳記上 23:29; 歷代志下 20:2"> 尼布珊，鹽城，恩蓋迪，共六座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="士師記 1:21; 士師記 1:8; 撒母耳記下 5:6–9"> 至於住在耶路撒冷的耶布斯人，猶大子孫不能把他們趕出去，耶布斯人就與猶大子孫一起住在耶路撒冷，直到今日。</span>
</div>

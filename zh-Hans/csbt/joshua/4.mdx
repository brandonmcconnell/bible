<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 27:2; 約書亞記 3:17"> 所有的民完全過了約旦河之後，耶和華就對約書亞說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 3:12; 民數記 1:4–15; 列王紀上 18:31"> 「你要從民中選出十二個人，每支派一人，</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 4:19–20; 約書亞記 3:13; 約書亞記 4:8"> 吩咐他們說：『你們要從約旦河中，祭司們的腳所站的位置，從那裡取十二塊石頭，隨著你們帶過去，安置在你們今夜的宿營地。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約書亞記 4:2; 馬可福音 3:14–19"> 於是，約書亞召來他從以色列子民中指定的十二個人，每支派一人。</span>
<span className="v" id="v5" data-v="5"> 約書亞對他們說：「你們過去，到約旦河中你們神耶和華的約櫃面前，按著以色列子民的支派數目，各人取一塊石頭扛在肩上，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 13:14; 約書亞記 4:21; 詩篇 44:1"> 好讓這些石頭在你們中間作為標記。日後如果你們的子孫問你們說：『這些石頭對你們是什麼意思呢？』</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:14; 民數記 16:40; 出埃及記 28:12"> 你們就告訴他們：約旦河的水曾經在耶和華的約櫃面前被截斷；當約櫃過約旦河時，約旦河的水被截斷了。這些石頭要給以色列子孫作記念，直到永遠。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 4:2–5; 約書亞記 1:16–18; 約書亞記 4:20"> 以色列子民就照著約書亞的吩咐做了。他們照著耶和華對約書亞所說的，按著以色列子民支派的數目，從約旦河中取了十二塊石頭，隨著他們帶過去，到宿營地把它們安置在那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 7:12; 士師記 1:26; 歷代志下 5:9"> 約書亞又在約旦河中，在抬約櫃的祭司雙腳所站的位置，豎立了十二塊石頭，它們至今還在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 3:13; 詩篇 119:60; 箴言 27:1"> 抬約櫃的祭司們一直站在約旦河中，直到耶和華指示約書亞告訴子民的一切事都完成了，正如摩西所吩咐約書亞的一切；民眾很快過去了。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 3:8; 約書亞記 4:18; 約書亞記 3:17"> 全體民眾完全過去之後，耶和華的約櫃和祭司們也在民眾面前過去了。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 32:20–32; 約書亞記 1:14"> 魯本子孫、迦得子孫和瑪拿西半支派，也都照著摩西對他們所說的，整裝列隊在以色列子民前面過去。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 6:11; 耶利米書 39:5; 耶利米書 52:8"> 有大約四萬武裝隊伍準備出戰，在耶和華面前過去，前往耶利哥平原。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約書亞記 3:7; 歷代志下 30:12; 列王紀上 3:28"> 那一天，耶和華在全體以色列人眼前高抬約書亞，他們在他一生的日子都敬畏他，像敬畏摩西一樣。</span>
<span className="v" id="v15" data-v="15"> 耶和華對約書亞說：</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:19; 出埃及記 25:16–22; 約書亞記 3:3–6"> 「你吩咐抬見證櫃的祭司們從約旦河裡上來吧。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 8:16–18; 使徒行傳 16:35–39; 使徒行傳 16:23"> 於是約書亞吩咐祭司們說：「你們從約旦河裡上來。」</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 3:15; 歷代志上 12:15; 約書亞記 3:13"> 抬耶和華約櫃的祭司們從約旦河裡上來，祭司們的腳掌一踏上乾地，約旦河的水就流回原處，像先前那樣漫過整個河岸。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約書亞記 5:9; 彌迦書 6:5; 出埃及記 12:2–3"> 一月十日，民眾從約旦河上來，在耶利哥東邊的吉甲紮營。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 4:3; 約書亞記 4:8"> 約書亞把人們從約旦河中取來的那十二塊石頭豎立在吉甲，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 4:6; 詩篇 145:4–7; 詩篇 105:2–5"> 然後對以色列子民說：「日後你們的子孫問他們的父親說：『這些石頭是什麼意思呢？』</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 3:17; 以賽亞書 51:10; 以賽亞書 44:27"> 你們要教導子孫說：『以色列曾經走乾地過了這約旦河。』</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 14:21; 以賽亞書 43:16; 以賽亞書 63:12–14"> 因為你們的神耶和華在你們面前使約旦河的水乾涸，直到你們過去，就像你們的神耶和華曾經所做的，他在我們面前使紅海乾涸，直到我們都過去。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 106:8; 詩篇 89:13; 列王紀上 8:42–43"> 這樣，地上的萬民就知道耶和華的手大有能力，你們也會終生敬畏耶和華你們的神。」</span>
</div>
</div>

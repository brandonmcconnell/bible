<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JOS" data-book-slug="joshua" data-book-name="約書亞記" data-chapter="8" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 1:9; 申命記 7:18; 申命記 1:21"> 耶和華對約書亞說：「不要害怕，不要喪膽。你要帶領全體軍兵，起來上艾城去。你看，我已經把艾城的王和他的子民、他的城、他的領土都交在你手中了。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 20:14; 約書亞記 6:21; 歷代志下 20:22"> 你怎樣處置耶利哥和它的王，也要怎樣處置艾城和它的王；唯有城裡的財物和牲畜，你們可以掠奪歸於自己。你要在城的後面設下伏兵。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 24:39; 馬太福音 25:6; 帖撒羅尼迦前書 5:2"> 於是約書亞和全體軍兵起來，要上艾城去。約書亞挑選了三萬英勇的戰士，夜間派出他們。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 20:29; 約書亞記 8:16; 士師記 20:36"> 約書亞吩咐他們說：「看，你們要埋伏在城的後面，不要離城太遠；你們全都要做好準備。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 7:5; 馬太福音 10:16; 士師記 20:31–33"> 我與跟隨我的所有軍兵將上前攻城，當他們像先前那樣出來迎戰我們時，我們就從他們面前逃走。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 20:32; 出埃及記 15:9; 傳道書 8:11"> 他們必出來追趕我們，直到我們引誘他們遠離那城，因為他們會想：『這些人像先前那樣在我們面前逃跑了！』我們在他們面前逃跑時，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王紀下 5:1; 約書亞記 8:1"> 你們要從埋伏的地方起來，占領那城，你們的神耶和華必把它交在你們手中。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 13:28; 約書亞記 1:16; 約書亞記 1:9"> 你們攻取那城之後，要放火燒城。你們要照著耶和華的話行事，看，我已經吩咐你們了。」</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 7:2; 創世記 12:8; 以斯拉記 2:28"> 約書亞派出他們，他們就到埋伏的地方去，潛伏在艾城的西邊，伯特利和艾城之間。那天晚上，約書亞在軍兵中間過夜。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 6:12; 詩篇 119:60; 創世記 22:3"> 第二天清晨，約書亞早早起來，數點了軍兵，他和以色列的長老們就率領軍兵上艾城去。</span>
<span className="v" id="v11" data-v="11"> 所有跟隨他的軍兵都上去，向前逼近，來到城的對面，在艾城北邊紮營。他們與艾城之間，隔著一個山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 8:2–3"> 約書亞選出大約五千人，安排他們埋伏在艾城的西邊，伯特利和艾城之間。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 8:12; 約書亞記 8:8"> 這樣，他們安置好了軍兵，整個軍隊在城北，側翼在城西。那天夜裡，約書亞進了山谷。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 24:39; 士師記 20:34–36; 申命記 1:1"> 艾城的王看見了這情況，城裡的人就清早急忙起來，出去迎戰以色列人。他和他的全軍到了面向亞拉巴荒原的約戰之處，並不知道城後有埋伏。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 18:12; 約書亞記 16:1; 士師記 20:36"> 約書亞和全體以色列人在他們面前假裝敗退，往曠野的方向逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 20:31; 士師記 20:36–39; 約書亞記 8:5–6"> 城裡的所有軍兵都被召去追趕，他們追趕約書亞，就被引誘遠離了那城。</span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 5:13; 約書亞記 8:3; 以賽亞書 19:11–13"> 艾城和伯特利城中，沒有一個人留下不去追趕以色列的。他們撇下城任其敞開，去追趕以色列。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約書亞記 8:26; 約伯記 15:25; 撒母耳記上 17:41"> 那時耶和華對約書亞說：「伸出你手中的標槍指向艾城！我要把城交在你手中了。」約書亞就伸出他手中的標槍指向那城。</span>
<span className="v" id="v19" data-v="19"> 他一伸出手，伏兵就從原處迅速起來衝上去，進城攻取了它，並立刻放火燒城。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 76:5; 約伯記 11:20; 創世記 19:28"> 艾城的人回頭一看，看哪，城中濃煙向天上騰，他們無論往哪個方向都無法逃脫，因為那些逃往曠野的軍兵，現在轉身攻擊追來的人。</span>
<span className="v" id="v21" data-v="21"> 約書亞和以色列全軍看見伏兵已經攻取那城，城中濃煙上騰，他們就返回擊殺艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:2; 約書亞記 10:28; 約書亞記 6:21"> 伏兵也從城裡出來夾擊，這樣艾城的人就在以色列人中間腹背受敵。他們被擊殺，沒有留下一人存活或逃脫。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 15:8; 約書亞記 10:17; 啟示錄 19:20"> 以色列人活捉了艾城的王，把他帶到約書亞那裡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約書亞記 11:10–14; 約書亞記 10:30–41; 民數記 21:24"> 以色列人在田野和曠野殺盡了所有出來追擊他們的艾城居民，這些人全都倒在刀刃之下，直到滅盡了。然後以色列全軍回到艾城，用刀擊殺城裡的人。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 20:16–18"> 那一天倒斃的，無論男女，共有一萬兩千人，是艾城所有的人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 17:11–12; 約書亞記 8:18"> 約書亞一直沒有收回他伸出標槍的那只手，直到滅絕艾城所有的居民。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 8:2; 民數記 31:26; 詩篇 50:10"> 唯有城裡的牲畜和財物，以色列人掠奪歸於自己，正如耶和華所吩咐約書亞的話。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 13:16; 耶利米書 49:2; 列王紀下 19:25"> 約書亞燒毀了艾城，使它成為永遠的廢堆，荒涼直到今日。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 7:26; 撒母耳記下 18:17; 申命記 21:22–23"> 他把艾城的王掛在樹上，直到傍晚時分。日落的時候，約書亞下令，人們就把他的屍體從樹上取下來，扔在城門口那裡，上面堆了一大堆石頭，那石堆至今還在。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:4–6; 出埃及記 20:24; 創世記 12:7–8"> 那時，約書亞在以巴錄山上，為以色列的神耶和華築了一座祭壇。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 27:5–7; 出埃及記 20:24–25; 約書亞記 8:34–35"> 這祭壇是照著耶和華的僕人摩西所吩咐以色列子民的，照著摩西律法書上所記的，用完整的石頭築成，其上沒有動過鐵器。他們在這壇上向耶和華獻了燔祭，又獻上平安祭。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 27:2–3; 申命記 27:8"> 約書亞在那裡，當著以色列子民的面，把摩西寫下的律法，刻了一份副本在石頭上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 11:29; 申命記 31:12; 申命記 31:9"> 全體以色列人，無論是外人還是本族人，都與他們的長老、官長、審判官一起站在約櫃兩旁，在抬耶和華約櫃的利未祭司面前，一半對著基利心山，一半對著以巴錄山，照著耶和華的僕人摩西先前所吩咐的，祝福以色列子民。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 8:2–3; 尼希米記 13:1; 申命記 31:10–12"> 然後，他又照著律法書上所記的一切，宣讀了律法上有關祝福和詛咒的一切話語。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 31:12; 尼希米記 8:2; 耶利米書 26:2"> 約書亞在以色列全體會眾面前，包括女人、孩童以及他們當中往來的寄居者，把摩西所吩咐的一切話語都宣讀了，沒有漏下一句<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="都宣讀了，沒有漏下一句——原文直譯「沒有一句不向他們宣讀的」。">a</a></sup>。</span>
</div>

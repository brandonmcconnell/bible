<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="JOS" data-book-slug="joshua" data-book-name="約書亞記" data-chapter="13" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:10; 申命記 31:3; 約書亞記 24:29"> 約書亞老了，上了年紀，耶和華對他說：「你老了，上了年紀，但還剩下很多土地要去占領。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 13:11; 撒母耳記上 27:8; 約珥書 3:4"> 剩下的土地如下：<br />非利士人的全境和基述人的全境，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 2:23; 士師記 3:3; 耶利米書 2:18"> 從埃及東邊的西赫河，直到北邊的以革倫邊界——這也算是迦南人之地——五個非利士首領管轄的加沙、阿實突、阿實基倫、迦特、以革倫；還有亞瓦人之地，</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 19:30; 撒母耳記上 4:1; 士師記 1:34–36"> 南邊的迦南人全地，從西頓人的亞拉，直到阿費克，又到亞摩利人的邊界；</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 5:18; 約書亞記 12:7; 詩篇 83:7"> 還有迦巴勒人之地，東邊的整個黎巴嫩，就是從黑門山腳下的巴力迦得，直到哈馬隘口。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 11:8; 約書亞記 23:13; 士師記 2:21–23"> 「從黎巴嫩直到米斯利弗-瑪音山地的所有居民，所有的西頓人，我必把他們從以色列子民面前趕出去，你只管照著我所指示的，把這地抽籤分給以色列人為繼業。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 26:53–56; 民數記 33:54; 以西結書 48:23–29"> 現在，你要把這地分給九個支派和瑪拿西半支派為繼業。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 12:6; 申命記 3:12–17; 約書亞記 22:4"> 魯本和迦得與瑪拿西半支派一起，已經照著耶和華的僕人摩西所分給他們的，得了摩西在約旦河東岸分給他們的繼業：</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約書亞記 13:16; 民數記 21:30; 約書亞記 12:2"> 從亞嫩溪谷邊的亞羅珥和溪谷之城，以及整個米底巴平原，直到迪本；</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:24–26"> 還有在希實本統治的亞摩利王西宏所有的城鎮，直到亞捫人的邊界；</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 2:23; 約書亞記 12:2–5; 申命記 4:47–48"> 又有基列地，基述人和瑪迦人的地界，以及整個黑門山和巴珊全地，直到撒迦；</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 12:4; 約書亞記 14:3–4; 民數記 21:23–35"> 還有在亞斯他錄和伊德賴統治的巴珊王歐革的整個王國，歐革是利乏音人遺民中殘留下來的。<br />摩西擊敗他們，趕出了他們。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 23:12–13; 約書亞記 13:11; 民數記 33:55"> 以色列子民卻沒有把基述人和瑪迦人趕出去，所以基述人和瑪迦人住在以色列人當中，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 18:20–24; 約書亞記 14:3–4; 申命記 18:1–2"> 只有利未支派，摩西沒有分給他們繼業；因為照著耶和華向他們所應許的，獻與以色列的神耶和華的火祭就是他們的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 摩西按著魯本子孫的家族，把繼業分給了他們支派。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 13:9; 約書亞記 12:2; 以賽亞書 16:7–9"> 他們的地界包括：<br />亞嫩溪谷邊的亞羅珥和溪谷之城，還有靠近米底巴的整個平原；</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 22:41; 民數記 32:38; 民數記 21:19"> 希實本和平原上所有屬它的城鎮，迪本，巴莫巴力，伯巴力米恩；</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:23; 約書亞記 21:36–37; 歷代志上 6:78–79"> 雅哈茲，基底莫，米法押，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 32:37–38"> 基列亭，西比瑪，谷中山上的澤列沙哈爾，</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 12:3; 申命記 4:46; 以西結書 25:9"> 伯毗珥，毗斯迦山坡，伯耶西莫，</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 31:8; 申命記 3:10; 申命記 2:30–36"> 以及平原上的所有城鎮，在希實本統治的亞摩利王西宏的整個王國。摩西擊敗了西宏，以及米甸的領袖埃維、利肯、蘇珥、戶珥和利巴，他們是住在那地的西宏的眾首領。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 31:8; 猶大書 1:11; 彼得後書 2:15"> 以色列人擊殺了這些人，也把比珥之子占卜者巴蘭用刀殺了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 魯本子孫的邊界是約旦河沿岸。這是魯本子孫按著他們的家族，所得為繼業的城鎮和附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 32:34–36"> 摩西按著迦得子孫的家族，把繼業分給了他們支派。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 12:26; 撒母耳記下 11:1; 民數記 32:35"> 他們的地界包括：<br />雅謝，基列的所有城鎮，亞捫人之地的一半，直到拉巴前面的亞羅珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 17:27; 撒母耳記下 2:8; 士師記 10:17"> 從希實本直到拉瑪-米斯巴和比多寧，又從瑪哈念直到羅迪巴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="羅迪巴——或音譯「迪比」。">a</a></sup>的邊界；</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 32:36; 民數記 34:11; 創世記 33:17"> 還有谷中的伯亞蘭，伯寧拉，疏割，撒芬，就是希實本王西宏國中其餘的土地；以約旦河為界，直到革尼勒湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="革尼勒湖——指加利利海；又稱「革尼撒勒湖、太巴列湖」。">b</a></sup>的南端，約旦河的東岸。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 這是迦得子孫按著他們的家族，所得為繼業的城鎮和附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 摩西也把繼業分給瑪拿西半支派，按著他們的家族，分給了瑪拿西子孫的半支派。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 13:26; 申命記 3:13–15; 民數記 32:39–41"> 他們的地界包括：<br />瑪哈念以及整個巴珊，巴珊王歐革的整個王國，巴珊所有的睚珥村鎮，共六十座城；</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 12:4; 民數記 32:39–40"> 還有半個基列，巴珊的歐革王國的城亞斯他錄和伊德賴。這些按著他們的家族，分給了瑪拿西的兒子瑪吉的子孫，就是瑪吉的一半子孫。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 以上是摩西在耶利哥東邊約旦河對面的摩押平原所分配的繼業。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 18:7; 約書亞記 13:14; 申命記 18:1–2"> 摩西沒有分繼業給利未支派，因為照著耶和華向他們所應許的，以色列的神耶和華就是他們的繼業。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 19:9; 創世記 49:5–7; 約書亞記 18:6–11"> 第二支籤為西緬，就是西緬支派，按著他們的家族抽出來，他們的繼業是在猶大子孫的繼業中間。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 4:28–30; 尼希米記 11:26–30; 創世記 21:31"> 他們所得的繼業是：<br />比爾-謝巴——也叫謝巴，漠拉達，</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 15:28–29"> 哈薩書爾，巴拉，埃曾，</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 15:30; 士師記 1:17"> 伊利多拉，貝圖勒，霍爾瑪，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 30:1; 歷代志上 4:31; 約書亞記 15:31"> 洗革拉，伯瑪克波，哈薩蘇撒，</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 15:32"> 伯利巴奧，沙錄恆，共十三座城，還有附屬的村莊；</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:42; 約書亞記 15:32; 民數記 33:19–20"> 阿音，臨門，伊特爾，阿珊，共四座城，還有附屬的村莊；</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 4:33; 撒母耳記上 30:27"> 又有這些城四圍所有的村莊，直到巴阿拉-比爾，就是南地的拉瑪。<br />這是西緬支派按著他們的家族所得的繼業。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 8:14–15; 出埃及記 16:18"> 西緬子孫的繼業來自猶大子孫的份，因為猶大子孫的份對於他們太多了，所以西緬子孫就在猶大的繼業中分得繼業。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 18:11; 約書亞記 18:6; 創世記 49:13"> 第三支籤為西布倫子孫，按著他們的家族抽出來。<br />他們繼業的地界是到撒立，</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 12:22; 歷代志上 6:68; 列王紀上 4:12"> 然後他們的邊界往西上去，到瑪拉拉，抵達大巴設，又抵達約念對面的溪谷；</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 4:6; 歷代志上 6:72; 約書亞記 19:22"> 又從撒立往東轉到吉斯羅-他泊的邊界，又延伸到達比拉，上到雅非亞；</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 14:25"> 又從那裡往東邊日出的方向，經過迦特希弗、伊特卡津，延伸到臨門，轉到尼亞；</span>
<span className="v" id="v14" data-v="14"> 邊界又在北方繞過尼亞，到哈拿頓，終點是伊弗塔伊勒谷；</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 11:1; 路得記 1:19; 撒母耳記下 23:15"> 又有卡塔特，拿哈拉，希姆崙，伊達拉，伯利恆；共十二座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 這些城和附屬的村莊，就是西布倫子孫按著他們的家族所得的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 第四支籤是給以薩迦，按著他們的家族為以薩迦子孫抽出來。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 28:4; 列王紀下 4:8; 何西阿書 1:4–5"> 他們的地界是到耶斯列，包括了基蘇律，書念，</span>
<span className="v" id="v19" data-v="19"> 哈弗連，示按，亞拿哈拉，</span>
<span className="v" id="v20" data-v="20"> 拉比特，其雄，埃貝茲，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 21:29"> 雷梅特，恩干寧，恩哈達，伯帕澤茲；</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 4:6; 歷代志上 6:77; 約書亞記 19:38"> 邊界又抵達他泊，沙哈洗瑪，伯示麥，他們邊界的終點是約旦河；共十六座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 這些城和附屬的村莊，就是以薩迦支派按著他們的家族所得的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 2:26–38"> 第五支籤為亞設支派，按著他們的家族抽出來。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 12:20; 約書亞記 11:1; 撒母耳記下 2:16"> 他們的地界是：赫爾卡特，哈利，比田，阿克沙弗，</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王紀上 18:42; 以賽亞書 33:9"> 阿拉米勒，阿瑪德，米沙勒，向西抵達迦密和希赫爾-利布納；</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:13; 撒母耳記上 5:2"> 又往東轉到伯大衮，抵達西布倫，向北到伊弗塔伊勒谷，伯伊莫克和尼伊勒，延伸到北面的卡布勒；</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:31; 約書亞記 11:8; 以賽亞書 23:12"> 又到伊伯崙，利合，哈門，加拿，直到西頓大城；</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:31; 撒母耳記下 5:11; 彌迦書 1:14"> 邊界又轉回拉瑪和堡壘城提爾，然後轉回何薩，終點是大海，靠近阿克濟地區；</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 21:31; 列王紀上 20:30; 撒母耳記上 4:1"> 又有烏瑪，阿費克，利合；共二十二座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 33:24–25; 創世記 49:20"> 這些城和附屬的村莊，就是亞設支派按著他們的家族所得的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 第六支籤是給拿弗他利子孫，按著他們的家族為拿弗他利子孫抽出來。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 4:11"> 他們的地界是從希利弗，從撒拿音的橡樹，到亞大米-尼吉和雅比聶，直到拉庫姆，終點是約旦河；</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 33:23; 約書亞記 19:12; 約書亞記 19:22"> 邊界又向西轉到亞斯納-他泊，從那裡延伸到戶割；南邊抵達西布倫，西邊抵達亞設，東邊抵達約旦河邊的猶大。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 11:2; 列王紀上 8:65; 創世記 10:18"> 堡壘城有：策迪姆，策珥，哈末，拉卡特，革尼勒，</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 11:1; 約書亞記 11:20; 約書亞記 12:19"> 亞達瑪，拉瑪，哈佐，</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 20:7; 約書亞記 12:22"> 基低斯，伊德賴，恩哈佐，</span>
<span className="v" id="v38" data-v="38"> 伊利溫，米格達-伊勒，霍勒姆，伯亞納，伯示麥。他們共有十九座城，還有附屬的村莊。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 這些城和附屬的村莊，就是拿弗他利支派按著他們的家族所得的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 第七支籤為但支派，按著他們的家族抽出來。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志上 2:53; 約書亞記 15:33; 士師記 13:25"> 他們繼業的地界是：佐拉，以實陶，伊珥示麥，</span>
<span className="v" id="v42" data-v="42" data-xref="士師記 1:35; 約書亞記 10:12; 約書亞記 21:24"> 沙勒賓，阿雅崙，伊特拉，</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 38:12; 撒母耳記上 5:10; 士師記 14:1–2"> 埃隆，亭拿，以革倫，</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 15:27; 列王紀上 16:15; 列王紀上 9:18"> 伊利特克，基比頓，巴阿拉特，</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 21:24"> 耶胡德，比尼別拉克，迦特臨門，</span>
<span className="v" id="v46" data-v="46" data-xref="約拿書 1:3; 使徒行傳 9:36; 歷代志下 2:16"> 米耶爾昆，拉昆，包括約帕對面的地界。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="士師記 1:34–35; 士師記 18:1–29"> 後來但子孫擴張了地界，但子孫上去攻打利謝姆，攻取了那城。他們用刀擊殺其中的人，占領那城，住在其中，照著他們祖先但的名字稱利謝姆為「但」。</span>
<span className="v" id="v48" data-v="48"> 這些城和附屬的村莊，就是但支派按著他們的家族所得的繼業。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以西結書 45:7–8"> 他們按著地界分完了那地為繼業，以色列子民就在他們中間也分給嫩的兒子約書亞一份繼業。</span>
<span className="v" id="v50" data-v="50" data-xref="約書亞記 24:30; 士師記 2:9; 歷代志上 7:24"> 照著耶和華的吩咐，他們給了他所要求的城，就是在以法蓮山地的亭拿-西拉。他重建那城，住在其中。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="約書亞記 18:10; 約書亞記 14:1; 約書亞記 18:1"> 以上就是祭司以利亞撒和嫩的兒子約書亞，以及以色列子孫各支派父系的首領，在示羅會幕的入口，在耶和華面前，以抽籤的方式分配的繼業。這樣，他們分完了土地。</span>
</div>
</div>

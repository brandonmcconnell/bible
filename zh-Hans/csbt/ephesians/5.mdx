<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 4:11; 彼得前書 1:15–16; 以弗所書 4:32"> 所以，做為蒙愛的兒女，你們要效法神；</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 13:34; 加拉太書 2:20; 歌羅西書 3:14"> 要在愛中行事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行事——原文直譯「行走」。">a</a></sup>，就像基督也愛了我們，為我們捨棄了自己，做供物和祭物獻給神，成為馨香的氣味。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 3:5; 以弗所書 5:5; 加拉太書 5:19–21"> 至於淫亂和一切汙穢，或是貪心，在你們中間連提都不可提，這樣才與聖徒相宜。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:8; 以弗所書 4:29; 帖撒羅尼迦前書 5:18"> 汙穢的言行、愚妄的話語、下流的笑話，這些都不合宜；反而倒要說感謝的話。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:21; 哥林多前書 6:9–10; 以弗所書 5:3"> 實際上你們應當清楚知道這一點：所有淫亂的、汙穢的，或貪心的——就是拜偶像的——在基督和神的國度裡都得不到繼業。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="羅馬書 1:18; 歌羅西書 2:8; 馬太福音 24:4"> 不要讓任何人用虛空的話把你們欺騙了；正是為了這些，神的震怒就臨到那些不信從的兒女<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不信從的兒女——或譯作「悖逆的人」。">b</a></sup>身上。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 18:4; 以弗所書 5:11; 提摩太前書 5:22"> 所以，不要與他們同夥。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 8:12; 約翰一書 1:7; 使徒行傳 26:18"> 你們從前原是黑暗，但如今在主裡就是光；你們要像屬於光的兒女行走，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 3:9–10; 加拉太書 5:22–23; 約翰三書 1:11"> 原來屬於光的果子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="屬於光的果子——有古抄本作「聖靈的果子」。參《加拉太書》5:22。">c</a></sup>，就是一切良善、公義、真理；</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:1–2; 希伯來書 12:28; 詩篇 19:14"> 要分辨什麼是主所喜悅的事。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 13:12; 提摩太前書 5:20; 帖撒羅尼迦後書 3:6"> 你們不要參與那些屬黑暗結不出果子的事，反而要把那些事揭露出來，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:3; 耶利米書 23:24; 傳道書 12:14"> 因為他們暗中所做的，連說出來也是可恥的。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 3:20–21; 哥林多前書 4:5; 何西阿書 2:10"> 然而，一切被光所揭露的事，都要成為明顯的，</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 60:1; 羅馬書 13:11–12; 以賽亞書 26:19"> 因為使一切成為明顯的，就是光。所以有話說：<br /><span className="pl pl-1">「醒過來！睡著的人哪，從死人中起來吧！</span><br /><span className="pl pl-1">基督就要光照你了！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 4:5; 雅各書 3:13; 腓立比書 1:27"> 所以，你們要仔細察看怎樣行事為人，不要像沒有智慧的人，而要像有智慧的人；</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 4:5; 阿摩司書 5:13; 約翰福音 12:35"> 要把握機會<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="要把握機會——原文直譯「要贖回時機」。">d</a></sup>，因為這時代是邪惡的。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:2; 帖撒羅尼迦前書 5:18; 歌羅西書 1:9"> 為此，不要做愚妄的人，而要領悟主的旨意是什麼。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 羅馬書 13:13"> 不要醉酒，醉酒帶來<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="帶來——原文直譯「就是」。">e</a></sup>放蕩，而要被聖靈充滿：</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:16; 哥林多前書 14:26; 詩篇 95:2"> <span className="pl pl-1">用詩篇、聖詩、屬靈的詩歌彼此對說，</span><br /><span className="pl pl-1">從你們的心裡，歌頌讚美主；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 3:17; 帖撒羅尼迦前書 5:18; 希伯來書 13:15"> <span className="pl pl-1">奉我們主耶穌基督的名，</span><br /><span className="pl pl-1">為一切常常感謝父神；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:3; 以弗所書 5:24; 以弗所書 5:22"> <span className="pl pl-1">懷著敬畏基督</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="基督——有古抄本作「神」。">f</a></sup><br /><span className="pl pl-1">的心，彼此服從。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:18–1; 彼得前書 3:1–6; 提多書 2:5"> 你們做妻子的，要服從<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本沒有「服從」。">g</a></sup>自己的丈夫，如同服從主，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 11:3–10; 歌羅西書 1:18; 以弗所書 1:22–23"> 因為丈夫是妻子的頭，正如基督是教會的頭；他也是這身體的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 5:33; 歌羅西書 3:20; 提多書 2:7"> 而且教會怎樣服從基督，妻子也照樣要在一切事上服從<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「自己的」。">h</a></sup>丈夫。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 3:7; 歌羅西書 3:19; 以弗所書 5:28"> 你們做丈夫的，要愛自己的妻子，就像基督也愛了教會，為她捨棄了自己。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 10:22; 約翰福音 15:3; 以西結書 36:25"> 基督這麼做<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督這麼做——輔助詞語。">i</a></sup>，是要藉著話語，用水<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="用水——或譯作「在水裡」。">j</a></sup>的洗滌而潔淨教會，使她分別為聖，</span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 1:22; 希伯來書 9:14; 彼得前書 1:19"> 為要給自己預備一個榮耀的教會，沒有汙漬、皺紋或任何這類的事，卻要她成為聖潔、毫無瑕疵。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 5:25; 馬太福音 19:5; 創世記 2:21–24"> 照樣，丈夫也應該愛自己的妻子，就像愛自己的身體一樣；那愛自己妻子的，就是愛自己。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 34:14–15; 以弗所書 5:31; 傳道書 4:5"> 從來沒有人恨惡自己的身體，總是保養、顧惜它，就像基督<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="基督——有古抄本作「主」。">k</a></sup>對待教會那樣，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 6:15; 哥林多前書 12:12–27; 羅馬書 12:5"> 因為我們是基督身體的各個部分<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="部分——或譯作「肢體」。">l</a></sup><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附「是屬他的肉，屬他的骨」。">m</a></sup>。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 2:24; 馬太福音 19:5; 馬可福音 10:7–8"> <span className="pl pl-1">「為這緣故，人將離開父母，</span><br /><span className="pl pl-1">與妻子結合，</span><br /><span className="pl pl-1">兩個人就成為一體。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="啟示錄 21:2; 哥林多後書 11:2; 以賽亞書 54:5"> 這是極大的奧祕，但我是指著基督和教會說的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 3:2–7; 以斯帖記 1:20; 以弗所書 5:25"> 不過，你們每一個人也要愛自己的妻子，就像愛自己一樣；而妻子要敬重<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="敬重——或譯作「敬畏」。">n</a></sup>丈夫。</span>
</div>
</div>

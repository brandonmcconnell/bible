<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:20–25; 箴言 23:22; 箴言 6:20"> 你們做兒女的，要在主裡順從自己的父母，因為這是理所當然的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 20:12; 申命記 27:16; 馬太福音 15:4–6"> 「要孝敬父母，使你得福，在地上長壽。」這是第一條<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="-3 第一條——或譯作「最重要的」。">a</a></sup>帶著應許的誡命。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:21; 箴言 22:6; 箴言 29:15"> 你們做父親的，不要惹自己兒女生氣，而要照著主的訓練和警戒養育他們。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得前書 2:18–21; 提多書 2:9–10; 歌羅西書 3:17–24"> 你們做奴僕的，要懷著敬畏和戰兢，以忠實的心順從自己在世上的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="世上的——原文直譯「肉體的」。">b</a></sup>主人，就像聽從基督一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:22–23; 帖撒羅尼迦前書 2:4; 加拉太書 1:10"> 不要只在人眼前服事，像是討人的歡心，而要像基督的奴僕，從心裡遵行神的旨意。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 3:23; 以弗所書 6:5–6; 哥林多前書 10:31"> 要甘心樂意地服事，如同服事主，不是服事人，</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:24; 路加福音 14:14; 箴言 11:18"> 因為你們知道：每個人，無論是奴隸或是自由人，如果做了什麼美善的事，就將從主那裡領受這事的回報。</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 3:25–1; 使徒行傳 10:34; 羅馬書 2:11"> 你們做主人的，對奴僕也要這樣做，不要威嚇他們，因為你們知道，他們和你們同樣有一位主人在天上，而且他是不偏待人的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="腓立比書 4:13; 以賽亞書 40:31; 約書亞記 1:9"> 最後，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「我的弟兄們，」。">c</a></sup>你們要在主裡藉著他力量的權能得以剛強。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 10:4; 羅馬書 13:12; 以弗所書 6:13"> 你們要配上神的全副武裝，使你們得以站立，對付魔鬼的騙局，</span>
<span className="v" id="v12" data-v="12" data-xref="歌羅西書 1:13; 哥林多後書 4:4; 以弗所書 2:2"> 因為我們不是與血肉之體搏鬥，而是與那些統治的、掌權的、管轄這黑暗世界的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="管轄這黑暗世界的——原文直譯「屬這黑暗的世界掌管者」。">d</a></sup>，以及天上邪惡的屬靈勢力搏鬥。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 10:4; 路加福音 21:36; 以弗所書 6:11–17"> 為此，要拿起神的全副武裝，好使你們在邪惡的日子能夠抵擋，並且在完成一切以後，還站立得住。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 59:17; 帖撒羅尼迦前書 5:8; 以賽亞書 11:5"> 所以，你們要站立得住：<br /><span className="pl pl-1">用真理束上腰，穿上公義的護胸甲；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 52:7; 羅馬書 10:15; 哥林多後書 5:18–21"> <span className="pl pl-1">把所預備好的和平</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="和平——或譯作「平安」。">e</a></sup><br /><span className="pl pl-1">福音，穿在腳上；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 5:8–9; 約翰一書 5:4–5; 箴言 18:10"> <span className="pl pl-1">在任何情況下，要拿起信仰的盾牌；</span><br /><span className="pl pl-1">你們藉著它就能消滅那惡者一切燃燒的飛箭；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:12; 以賽亞書 59:17; 啟示錄 19:15"> <span className="pl pl-1">並且要接受救恩的頭盔和聖靈的寶劍——就是神的話語。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:17; 歌羅西書 4:2; 腓立比書 4:6"> 你們要以各樣的禱告和祈求，藉著聖靈時刻祈禱；而且為此警醒，以極大的忍耐，為所有聖徒祈求，</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 4:3; 使徒行傳 4:29; 帖撒羅尼迦後書 3:1"> 也為我祈求，好使我在開口的時候被賜予話語，能坦然無懼地讓人明白福音的奧祕——</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 5:20; 歌羅西書 4:4; 提摩太後書 2:9"> 為此，我成了帶鎖鏈的特使。請為我祈求<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="請為我祈求——輔助詞語。">f</a></sup>，使我能照著應該說的，放膽傳道。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:4; 提摩太後書 4:12; 提多書 3:12"> 在主裡蒙愛的弟兄、忠心的僕人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="僕人——或譯作「執事」。">g</a></sup>特其庫斯，會讓你們明白一切，好讓你們也知道有關我的事和我現在所做的事。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 2:25; 歌羅西書 4:7–8; 帖撒羅尼迦後書 2:17"> 我正是為此派他到你們那裡去，好讓你們知道有關我們的事，並且讓他安慰你們的心。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:16; 加拉太書 5:6; 彼得前書 5:14"> 願平安以及隨著信仰的愛，從父神和主耶穌基督臨到弟兄們！</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 22:37; 哥林多後書 8:12; 馬太福音 6:13"> 願恩典與所有愛我們主耶穌基督的人同在——直到永遠<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="直到永遠——原文直譯「在不朽中」。">h</a></sup>！<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「阿們。」">i</a></sup></span>
</div>
</div>

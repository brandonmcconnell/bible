<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:24; 提摩太後書 1:8; 腓立比書 1:13–16"> 因此，我保羅為你們外邦人做了基督耶穌的囚犯。</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 1:25–27; 提摩太前書 1:11; 提摩太後書 1:11"> 你們一定聽說過，為了你們的緣故，神那恩典的任務已經賜給我了；</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 1:12; 羅馬書 16:25; 以弗所書 1:9–11"> 也就是說，藉著啟示，那奧祕已經顯明給我，就像我先前簡略寫過的那樣。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 4:3; 哥林多前書 4:1; 哥林多後書 11:6"> 你們讀了，就能明白我在基督奧祕上的悟性。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:10–12; 彼得後書 3:2; 提多書 1:1–3"> 這奧祕在別的各世代並不顯明給人類<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="人類——原文直譯「人的子孫」。">a</a></sup>，不像如今藉著聖靈啟示給了他的聖使徒和先知們。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:26–29; 約翰一書 1:3; 約翰一書 2:25"> 這奧祕就是：外邦人在基督耶穌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督耶穌——有古抄本作「基督」。">b</a></sup>裡，藉著福音，成為共同的繼承人，同屬一體、同蒙應許。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 1:19; 以弗所書 3:20; 以弗所書 3:2"> 我成了這福音的僕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="僕人——或譯作「執事」。">c</a></sup>，是照著神恩典的賞賜；這賞賜是照著他大能的作為賜給我的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 1:27; 哥林多前書 15:9; 以弗所書 2:7"> 我在所有聖徒中，比最小的還小，但被賜予了這恩典，是為了把基督那無法測度的豐盛傳給外邦人；</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:26; 馬太福音 13:35; 提摩太後書 1:9"> 並且使所有的人都明白這奧祕的計劃<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="計劃——或譯作「任務」或「管家任務」；有古抄本作「契合」。">d</a></sup>到底是什麼，這奧祕自古以來被隱藏在<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「藉著耶穌基督」。">e</a></sup>創造萬有的神裡面，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 1:12; 以弗所書 6:12; 哥林多前書 2:7"> 為要使天上的統治者和掌權者，如今藉著教會能明白神各種各樣的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 1:9; 以弗所書 1:11; 以弗所書 1:4"> 這都是照著他在我們主基督耶穌裡所成就的永恆心意。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 2:18; 羅馬書 5:2; 希伯來書 4:14–16"> 在基督裡，藉著信基督，我們能坦然無懼、確信無疑地來到神面前<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神面前——輔助詞語。">f</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:24; 帖撒羅尼迦後書 3:13; 哥林多後書 1:6"> 所以，我請求你們<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="你們——輔助詞語。">g</a></sup>，不要因我為你們所受的患難而喪膽<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="喪膽——或譯作「膽怯」。">h</a></sup>；這患難是你們的榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 95:6; 以弗所書 1:16–19; 腓立比書 2:10"> 因此，我屈膝在<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附「我們主耶穌基督的」。">i</a></sup>父面前——</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 1:10; 啟示錄 5:8–14; 以弗所書 1:21"> 天上地上的萬族都是從他得名的，</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:11; 腓立比書 4:13; 以賽亞書 40:29–31"> 願他按照他那榮耀的豐盛，藉著他的靈，以大能使你們內在的人堅強起來；</span>
<span className="v" id="v17" data-v="17" data-xref="歌羅西書 2:7; 約翰一書 4:16; 約翰福音 14:23"> 使基督藉著你們的信仰，住在你們心裡；使你們在愛中扎根，根基穩固，</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 103:11–12; 約伯記 11:7–9; 以弗所書 1:18–23"> 好讓你們有能力與所有聖徒一起了解基督的愛<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="基督的愛——輔助詞語。">j</a></sup>是多麼長、闊、高、深——</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 1:23; 歌羅西書 2:9–10; 歌羅西書 1:10"> 明白那超越了人所能<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="人所能——輔助詞語。">k</a></sup>理解的基督之愛，好讓你們得以滿足，達到神一切的豐盛完美。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 9:8; 羅馬書 4:21; 耶利米書 32:27"> 神能照著在我們裡面做工的大能，成就那遠超過我們所求所想的一切事——</span>
<span className="v" id="v21" data-v="21" data-xref="猶大書 1:25; 羅馬書 11:36; 彼得後書 3:18"> 願榮耀在教會裡、在基督耶穌裡歸於神，直到世世代代，永永遠遠！阿們。</span>
</div>
</div>

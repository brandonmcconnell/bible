<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 2:13; 以弗所書 2:5–6; 歌羅西書 3:1–4"> 你們因著自己的過犯和罪孽，原是死的；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:12; 約翰一書 5:19; 以弗所書 2:3"> 在其中，你們從前行事為人，是順著這世界的潮流，順著那空中勢力的掌權者，就是現今在那些不信從的兒女裡面做工的靈。</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 3:3; 以弗所書 4:22; 加拉太書 5:16–24"> 我們從前也都生活在他們中間，生活在自己肉體的欲望裡，行肉體和意念所願的事。我們正如其他人，生來也是震怒之下的兒女。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 1:3; 以弗所書 1:7; 詩篇 86:15"> 不過神有豐富的憐憫，因著他愛我們的大愛，</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 3:24; 以弗所書 2:8; 羅馬書 5:10"> 甚至當我們還死在過犯中的時候，就使我們與基督一同活過來——你們得救是藉著恩典！</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:1–3; 以弗所書 1:3; 羅馬書 6:4–5"> 神又使我們在基督耶穌裡，與基督一同復活、一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 1:16–17; 提多書 3:4; 以弗所書 2:4"> 為了在將來的各世代中，在基督耶穌裡，藉著對我們的仁慈，可以顯出他那無限恩典的豐盛。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:22–26; 以弗所書 2:5; 羅馬書 4:16"> 你們得救確實是藉著恩典、藉著信，這不是出於你們自己，而是神的恩賜；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 1:9; 羅馬書 11:6; 提多書 3:3–5"> 也不是本於行為，免得有人自誇。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:13; 歌羅西書 1:10; 希伯來書 13:21"> 實際上，我們是神的創作，是為了美善的工作在基督耶穌裡被造成的；神早已預備好了美善工作，要我們在其中行事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行事——原文直譯「行走」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌羅西書 2:11; 歌羅西書 2:13; 歌羅西書 3:11"> 所以你們當記住：從前，你們照著肉體說是外邦人，被那些所謂「受割禮的」稱為「沒受割禮的」；割禮是人手在肉體上所行的。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 4:8; 歌羅西書 1:21; 耶利米書 31:31–34"> 那時候，你們與基督無關；被排除在以色列國民之外；在那些所應許的諸約上是外人；在這世界上沒有盼望、沒有神。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 2:39; 歌羅西書 1:20–22; 歌羅西書 1:13–14"> 但如今，在基督耶穌裡，你們這些從前在遠處的人，藉著基督的血，已經被帶到近處了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:28; 歌羅西書 3:11; 歌羅西書 3:15"> 因為他自己是我們的和平，他使兩者合而為一，廢除了那隔在中間仇恨的牆；以自己的身體，</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 2:14; 加拉太書 3:10; 歌羅西書 1:21–22"> 廢除了諭令中誡命的律法，為了把兩者在他自己裡面造成一個新人，締造和平。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:20–22; 羅馬書 5:10; 哥林多後書 5:18–21"> 他在十字架上既然消除了仇恨，就藉著十字架使兩者得以在一個身體裡，與神和好；</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 57:19–21; 使徒行傳 10:36; 羅馬書 5:1"> 並且來傳和平<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="和平——或譯作「平安」。">b</a></sup>的福音給你們在遠處的人，也給那些在近處的人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 12:13; 以弗所書 3:12; 羅馬書 5:2"> 因為藉著基督，我們兩者能夠在同一位聖靈裡，來到父面前。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 3:20; 約翰一書 3:1; 加拉太書 6:10"> 由此可見，你們不再是外人，或寄居的；你們是聖徒的同國之民，是神家裡的人，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:4–5; 以賽亞書 28:16; 彼得前書 2:7–8"> 並且被建造在使徒和先知的根基上，有基督耶穌自己為房角石。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 3:16–17; 哥林多前書 3:9; 哥林多後書 6:16"> 在基督耶穌裡，全部建築互相連接，漸漸成為在主裡的聖殿；</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:4–5; 哥林多前書 3:16; 約翰一書 4:16"> 在他裡面，你們也一同被建造，藉著聖靈成為神居住的地方。</span>
</div>

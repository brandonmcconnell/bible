<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:10; 腓立比書 1:27; 帖撒羅尼迦前書 2:12"> 所以，我這個在主裡的囚犯勸你們：行事為人要配得上你們所蒙的召喚，</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 3:12–13; 哥林多前書 13:7; 哥林多前書 13:4–5"> 要以完全的謙卑和溫柔，以耐心，在愛中彼此容忍；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:10; 歌羅西書 3:13–15; 哥林多前書 12:12–13"> 以和平的聯結，努力保持屬聖靈的合一：</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:18; 羅馬書 12:4–5; 哥林多前書 12:4–13"> 一個身體、一位聖靈，就像你們蒙召時也被召入一個盼望，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 8:6; 哥林多前書 12:13; 彼得前書 3:21"> 一位主、一個信仰、一個洗禮、</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 11:36; 瑪拉基書 2:10; 哥林多前書 8:6"> 一位神——就是萬有之父，他超越萬有<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="萬有——或譯作「萬人」。">a</a></sup>，貫通萬有，在萬有之中。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:10; 羅馬書 12:3; 哥林多前書 12:7–11"> 然而，我們每一個人都按照基督恩賜的尺度被賜予了恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:18; 歌羅西書 2:15; 撒母耳記上 30:26"> 所以經上說：<br /><span className="pl pl-1">他升上高天的時候，擄掠了俘虜，</span><br /><span className="pl pl-1">把各樣的恩惠賜給了人。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:13; 馬太福音 12:40; 箴言 30:4"> 那麼「他升上」這話是什麼意思呢？難道不也是說<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「首先」。">b</a></sup>他曾降到地的低層<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="地的低層——或譯作「地上更低微的地方」。">c</a></sup>嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 7:26; 希伯來書 4:14; 以弗所書 1:20–23"> 降下來的那一位，也就是為要充滿<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="充滿——或譯作「成就」或「完成」。">d</a></sup>萬有而升到諸天之上的那一位。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:15; 哥林多前書 12:28–29; 以弗所書 2:20"> 他賜下一些人做使徒，一些人做先知傳道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="做先知傳道——原文直譯「做先知」。">e</a></sup>，一些人做傳福音者，一些人做牧人或教師，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:11–14; 以弗所書 4:16; 哥林多前書 12:27"> 為了要裝備聖徒去做服事的工作，以建立基督的身體；</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:28; 約翰福音 17:21; 以弗所書 4:5"> 直到我們大家達到在信仰上以及對神兒子真正認識上的合一，達到成熟人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="成熟人——或譯作「完全人」。">f</a></sup>的地步，達到基督那豐盛完美的身量。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:9; 羅馬書 16:17–18; 哥林多前書 14:20"> 這樣，我們就不再是小孩子，在人的狡詐和詭計中陷入那迷惑人的騙局，被各種教義之風搖動，飄來飄去。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 3:18; 以弗所書 4:25; 撒迦利亞書 8:16"> 我們卻要在愛中說真話，在一切事上向著他長進；他就是頭，是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 2:19; 約翰福音 15:5; 歌羅西書 2:2"> 本於他，全身藉著每一個關節的支持，照著每一個部分<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="部分——或譯作「肢體」。">g</a></sup>適當的功用，互相連接，結合在一起，使身體漸漸成長，以致在愛中建立自己。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:21; 彼得前書 4:3–4; 帖撒羅尼迦前書 4:1–2"> 所以，我這樣說，並且在主裡忠告：你們行事不要再像<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「其餘」。">h</a></sup>外邦人那樣，在自己虛妄的理性中行事<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="行事——原文直譯「行走」。">i</a></sup>；</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:15; 以弗所書 2:12; 羅馬書 1:21–23"> 他們的意念變為黑暗，因著那在自己裡面的愚昧無知和心裡的剛硬，就與神的生命隔絕了；</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:5; 羅馬書 1:24–26; 提摩太前書 4:2"> 他們麻木不仁，任憑自己好色，以致貪婪地行出各樣汙穢的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提多書 2:11–14; 約翰福音 6:45; 馬太福音 11:29"> 但你們學了基督，就不是這樣——</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 5:20; 以弗所書 1:13; 希伯來書 3:7–8"> 如果你們真的聽從了他，又照著在耶穌裡的真理，在他裡面受了教導，</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 6:6; 希伯來書 12:1; 雅各書 1:21"> 為了你們脫去在過去行為上的舊人。這舊人順著迷惑人的私慾受敗壞，</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 12:2; 羅馬書 8:6; 詩篇 51:10"> 而你們在自己的心靈裡得以更新，</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:10–14; 哥林多後書 5:17; 以弗所書 2:10"> 並且穿上新人；這新人是照著神的形像<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="的形像——輔助詞語。">j</a></sup>，在真理的公義和聖潔中被造成的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌羅西書 3:9; 撒迦利亞書 8:16; 箴言 12:22"> 所以，你們既然脫去虛假，每個人就要與自己鄰人說真話，因為我們都是身體的一部分，彼此相屬。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 1:19; 詩篇 4:4; 詩篇 37:8"> 你們發怒卻不可繼續犯罪，不可生氣到日落，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 4:7; 彼得前書 5:8; 以弗所書 6:16"> 也不可給魔鬼留地步。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前書 6:18; 帖撒羅尼迦前書 4:11–12; 加拉太書 6:10"> 偷竊的，不可再偷，反而要勞苦做工，親手做有益處的事<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有益處的事——或譯作「美善的事」。">k</a></sup>，好使自己能有所得，分給有需要的人。</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 4:6; 帖撒羅尼迦前書 5:11; 傳道書 10:12"> 任何壞話都不可出口，而是按著需要說造就人的好話，使聽的人得到益處。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 5:19; 以賽亞書 63:10; 以弗所書 1:13–14"> 不要讓神的聖靈憂傷；你們蒙了他的印記，直到得贖的日子<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="日子——指「基督再來的日子」。">l</a></sup>。</span>
<span className="v" id="v31" data-v="31" data-xref="歌羅西書 3:8; 傳道書 7:9; 提多書 3:2–3"> 你們要除掉一切苦毒、暴怒、憤怒、喧嚷、毀謗，以及一切的惡毒；</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 3:12–13; 馬太福音 6:14–15; 馬可福音 11:25"> 要以仁慈彼此相待，心存憐憫，互相饒恕，就像神在基督裡饒恕了你們<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="你們——有古抄本作「我們」。">m</a></sup>那樣。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:12; 哥林多後書 12:7; 約翰一書 5:20"> 誇耀雖然沒有益處，但是必須的；我要說到主的異象和啟示：</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 22:17; 以西結書 8:1–3; 帖撒羅尼迦前書 4:17"> 我知道一個在基督裡的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一個在基督裡的人——指「保羅自己」。">a</a></sup>，他十四年前被提到第三層天上。他是否在身體裡，我不知道；是否在身體外，我也不知道；只有神知道。</span>
<span className="v" id="v3" data-v="3"> 不過我知道這樣一個人——他是否在身體裡，還是在身體外，我都不知道，只有神知道——</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 23:43; 啟示錄 2:7; 以西結書 31:9"> 他被提到樂園裡去，聽見了無法描述的話語，是人不可以說出來的。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 11:30; 哥林多前書 2:3; 哥林多後書 12:9–10"> 為這樣一個人，我要誇耀，但為我自己，除了有關那些軟弱的事以外，我不誇耀。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 11:16; 哥林多後書 11:31; 哥林多後書 12:11"> 其實就算我願意誇耀，也不算是愚妄的人，因為我會講真理。可是我要克制，免得有人把我看高了，過於他在我身上所看到的，或是從我所聽到的。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 33:55; 士師記 2:3; 歷代志下 32:25–26"> 並且為了不讓我因這些極大的啟示而高抬自己，有一根刺加在我的肉體上，就是撒旦的使者來擊打我，免得我高抬自己。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 5:7; 馬太福音 26:39–44; 撒母耳記上 15:11"> 為了這事，我三次求主使這根刺<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這根刺——或譯作「它」。">b</a></sup>離開我。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 4:13; 哥林多後書 12:10; 以賽亞書 40:29–31"> 但他對我說：<span className="woj">「我的恩典是夠你用的，因為我的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「我的」。">c</a></sup><span className="woj">大能在軟弱中得以完全。」</span>因此，我反而極其樂意地誇耀我的那些軟弱，好讓基督的能力遮蓋在我身上。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 12:9; 以弗所書 6:10; 羅馬書 5:3"> 所以，為了基督的緣故，我在那些軟弱中、凌辱中、艱難中、在逼迫和困苦中，都感到喜悅；因為我什麼時候軟弱，什麼時候就剛強了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 11:5; 哥林多後書 11:1; 哥林多前書 15:8–10"> 我<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「這樣誇耀」。">d</a></sup>成了愚妄的人，是你們逼我的。其實我應該受到你們的推薦，因為即使我一無所是，我也沒有一點趕不上那些「超級使徒」。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:18–19; 哥林多後書 11:4; 哥林多後書 4:2"> 我在你們中間以極大的忍耐，用神蹟、奇事和大能，確實顯出了使徒的標記。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 9:12; 哥林多前書 9:6; 哥林多後書 11:7–9"> 除了我自己沒有成為你們的負擔以外，你們所受的對待，到底有什麼不如其他教會呢？請你們饒恕我這點不公平吧！</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 創世記 24:35–36; 哥林多前書 10:33"> 看哪，這是我第三次預備好到你們那裡去，而且我不會成為你們的負擔，因為我想要的不是你們的東西，而是你們自己。本來，不應該是兒女為父母積蓄財富，而是父母為兒女積蓄財富。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:8; 哥林多後書 1:6; 腓立比書 2:17"> 所以為了你們的靈魂，我會極其樂意地付出，甚至完全付出。難道我愛你們越多，就越少得到你們的愛嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 2:5; 哥林多後書 10:2–3; 哥林多後書 12:13"> 不過就算如此，我也沒有成為你們的負擔——難道我是狡猾的人，用詭計牢籠了你們嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 9:5; 哥林多前書 4:17; 列王紀下 5:20–27"> 難道我曾經藉著派到你們那裡去的人，對不起你們嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:6; 羅馬書 4:12; 使徒行傳 20:33–35"> 我鼓勵提多去，又打發那位弟兄與他一起去。難道提多對不起你們嗎？我們行事，難道不是同一個心靈嗎？難道不是同一個步調嗎？</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="羅馬書 9:1; 哥林多前書 14:26; 哥林多後書 10:8"> 你們一直以為我們是在向你們申辯嗎？我們是在基督裡，在神面前說話。各位蒙愛的人哪，這一切都是為了造就你們。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 5:19–21; 彼得前書 2:1; 羅馬書 1:29"> 其實我擔心，恐怕我來到的時候會發現你們不像我所希望的那樣，而你們發現我也不像你們所希望的那樣；又恐怕有紛爭、嫉妒、暴怒、爭競<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="爭競——或譯作「結黨」。">e</a></sup>、誹謗、讒言、自大和混亂；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 13:2; 彼得前書 4:2–3; 歌羅西書 3:5"> 恐怕我來的時候，我的神會使我在你們面前再一次蒙羞<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="蒙羞——原文直譯「降卑」。">f</a></sup>，而且因為許多人從前犯了罪，又不肯為他們所行的汙穢、淫亂和好色的事而悔改，我就會悲傷。</span>
</div>

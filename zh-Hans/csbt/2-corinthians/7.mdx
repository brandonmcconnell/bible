<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 4:7; 彼得前書 2:11; 箴言 8:13"> 所以各位蒙愛的人哪，我們既然擁有這些應許，就讓我們潔淨自己，除去肉體和靈魂的一切汙穢，懷著敬畏神的心來達成聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 20:33; 哥林多後書 6:12–13; 哥林多後書 11:9"> 請你們接受我們。我們沒有虧負過誰，沒有敗壞過誰，也沒有對不起誰。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 6:11–12; 帖撒羅尼迦前書 2:8; 哥林多後書 11:11"> 我這樣說，不是為定你們的罪，因為我先前說過：你們常在我們心中，我們甚至可以與你們同生共死。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 1:4; 哥林多後書 3:12; 雅各書 1:2"> 我對你們大有確信，為你們大大誇耀；我充滿了安慰，在我們一切的患難中，喜樂格外增多。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 2:13; 申命記 32:25; 使徒行傳 20:1"> 實際上，我們以前到馬其頓省的時候，不但身體得不到安寧，也處處受患難，外有爭戰，內有懼怕。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 1:3–4; 帖撒羅尼迦後書 2:16–17; 哥林多後書 7:13"> 然而那安慰卑微<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="卑微——或譯作「謙卑」。">a</a></sup>之人的神，藉著提多的到來安慰了我們；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 5:2; 猶大書 1:3; 哥林多後書 8:16"> 不僅藉著他的到來，也藉著他從你們所受的安慰，安慰了我們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="安慰了我們——輔助詞語。">b</a></sup>，因他向我們報告了你們的渴望、你們的傷痛、你們對我的熱心，以致使我更加歡喜。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 3:19; 耶利米書 20:7–9; 馬太福音 26:21–22"> 即使我在那封信中使你們憂傷，我也不後悔了；因為就算我後悔過——我知道那封信使你們憂傷，雖然只是暫時的——</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:7; 耶利米書 31:18–20; 哥林多後書 7:10–11"> 現在我還是感到歡喜。這並不是因為你們憂傷，而是因為你們憂傷以至於悔改。實際上，你們按神的意思<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的意思——輔助詞語。">c</a></sup>憂傷，使你們在任何事上都不會因我們而受到損失；</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 3:19; 使徒行傳 11:18; 提摩太後書 2:25–26"> 因為按神的意思<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="的意思——輔助詞語。">d</a></sup>憂傷，就生出悔改通向救恩，是不懊悔的；可是屬世界的憂傷，卻帶來死亡。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 14:18; 提摩太前書 5:21–22; 提摩太後書 2:15"> 看哪，原來正是這件事——你們按神的意思<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="的意思——輔助詞語。">e</a></sup>憂傷——在你們裡面帶來了何等的殷勤、分辯、義憤、敬畏、渴望、熱心和懲罰。你們在各方面都證明了自己在那件事上是純潔的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:9; 提摩太前書 3:5; 哥林多後書 2:17"> 因此我雖然給你們寫了信，但不是為了那虧負人的，也不是為了那受虧負的，而是為了在神面前把你們對我們的殷勤，向你們顯明出來。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 7:6; 哥林多前書 12:26; 哥林多前書 16:13"> 為此，我們受到了安慰。<br />在這安慰之外，我們又因著提多的喜樂更是格外喜樂，因為他的心靈被你們大家所安撫。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 7:4; 帖撒羅尼迦後書 1:4; 哥林多後書 1:18–20"> 原來，即使我向提多誇耀過你們什麼，我也不至於蒙羞；其實就像我們對你們所講的一切都是真實的，照樣我們向提多所誇耀你們的也是真實的；</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 2:12; 哥林多後書 2:9; 約翰一書 3:17"> 而且當提多想起你們大家的順從，想起你們怎樣懷著敬畏和戰兢的心接受他，他對你們的情感就越發增多了。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 2:3; 腓利門書 1:8; 腓利門書 1:21"> 我如今歡喜的是，在一切事上我都因你們滿懷勇氣。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:1; 腓立比書 1:1; 以弗所書 1:1"> 照著神的旨意做基督耶穌使徒的保羅，以及弟兄提摩太，<br />致那在哥林多屬神的教會，以及在全亞該亞省所有的聖徒：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:7; 以弗所書 6:23; 腓立比書 1:2"> 願恩典與平安從神我們的父和主耶穌基督臨到你們！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以弗所書 1:3; 彼得前書 1:3; 羅馬書 15:5–6"> 願頌讚歸於神——我們主耶穌基督的父！他是各樣憐憫的父、一切安慰的神。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:11; 以賽亞書 51:12; 帖撒羅尼迦後書 2:16–17"> 在我們一切的患難中，他安慰我們，使我們自己能用從神所受的安慰去安慰那些在各樣患難中的人，</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 1:24; 腓立比書 3:10; 哥林多後書 4:10–11"> 因為基督的苦難怎樣充充滿滿臨到我們，藉著基督，我們的安慰也照樣充充滿滿。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太後書 2:10; 哥林多後書 1:4; 哥林多後書 4:15–18"> 我們如果受患難，是為了你們的安慰和救恩；我們如果受安慰，也是為了你們的安慰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「救恩」。">a</a></sup>；這安慰有功效，使你們能忍耐與我們所受的同樣苦難。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:17–18; 帖撒羅尼迦後書 1:4–7; 雅各書 1:12"> 而且我們對你們的盼望是確定的，因為知道你們怎樣在苦難中與我們有份，也怎樣在安慰中與我們有份。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 4:7–12; 哥林多前書 15:32; 哥林多前書 4:8"> 弟兄們，我們不願意你們不明白我們在亞細亞省所遭受的患難：我們所受的壓力遠遠過於我們的承受能力，甚至連活下去的希望也沒有了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 3:5; 希伯來書 11:19; 哥林多後書 4:7"> 然而我們在自己裡面已經承受了死亡的判決，好讓我們不依靠自己，而依靠那使死人復活的神。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 4:10; 詩篇 34:19; 彼得後書 2:9"> 他救我們脫離了如此致命的危險<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="如此致命的危險——有古抄本作「如此可怕的死亡」。">b</a></sup>，並且將來要救我們——我們盼望他將來還要救我們。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比書 1:19; 哥林多後書 4:15; 使徒行傳 12:5"> 你們也能通過祈禱一同幫助我們，好讓許多人因著那臨到我們的恩惠<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="恩惠——或譯作「恩賜」。">c</a></sup>為我們獻上感謝；這恩惠是通過許多人臨到我們的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:17; 哥林多前書 2:13; 雅各書 3:13–18"> 我們所誇耀的是這一點：我們的良心見證了我們在世上行事為人帶著屬神的忠實<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="忠實——有古抄本作「聖潔」。">d</a></sup>和真誠，不是靠屬肉體的智慧，而是靠神的恩典；對你們更是如此。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 4:2; 腓利門書 1:6; 哥林多後書 13:6"> 其實我們寫給你們的，無非是你們能讀、能了解的，而且我希望你們能徹底地了解，</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 2:16; 哥林多前書 1:8; 帖撒羅尼迦前書 2:19–20"> 就像你們對我們已經有一些了解那樣，因為在我們<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「我們」。">e</a></sup>主耶穌的日子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="日子——指「基督再來的日子」。">f</a></sup>，我們是你們的誇耀，正如你們是我們的誇耀。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 4:19; 羅馬書 1:11; 羅馬書 15:29"> 藉著這樣的確信，我早就打算先到你們那裡去，使你們能得到兩次的恩典<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="得到兩次的恩典——有古抄本作「再得喜樂」。">g</a></sup>：</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:5–7; 使徒行傳 21:5; 使徒行傳 19:21–22"> 就是經過你們那裡往馬其頓省去，再從馬其頓省回到你們那裡，然後由你們送我上路去猶太。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:37; 雅各書 5:12; 哥林多後書 10:2–3"> 那麼，我這樣打算，難道就是輕率行事嗎？難道我所計劃的，是順著肉體的計劃，以致在我忽是忽非嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:9; 啟示錄 3:7; 約翰福音 7:28"> 神是信實的，我們向你們傳的話語，並沒有「是」而又「非」。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 13:8; 啟示錄 1:17; 約翰二書 1:9"> 要知道，藉著我們，就是我、西拉斯和提摩太，在你們中間所傳揚的神兒子耶穌基督，並沒有「是」而又「非」；相反，在他只有「是」，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰一書 2:24–25; 加拉太書 3:22; 啟示錄 7:12"> 因為神的一切應許，在基督<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="基督——原文直譯「他」。">h</a></sup>裡都成為「是」。所以，說「阿們」也是藉著基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——原文直譯「他」。">i</a></sup>，使榮耀藉著我們歸於神。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 2:27; 彼得前書 5:10; 約翰一書 2:20"> 原來將我們與你們在基督裡一起確立，並且膏立了我們大家的那一位，就是神。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 4:30; 哥林多後書 5:5; 以弗所書 1:13–14"> 他又在我們身上蓋了印，並且賜聖靈在我們心裡做為預付憑據<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="預付憑據——或譯作「定金」。">j</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 1:20; 哥林多前書 4:21; 羅馬書 1:9"> 我求告神為我的靈魂見證：我沒有再往哥林多去，是因為顧惜你們。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 5:3; 哥林多前書 15:1; 腓立比書 1:25–26"> 我們並不是要轄制你們的信仰，而是要做你們的同工，使你們喜樂；因為你們已經因信站立得住了。</span>
</div>
</div>

</div>

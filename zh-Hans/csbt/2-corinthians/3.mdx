<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 12:11; 哥林多後書 10:12; 哥林多後書 5:12"> 我們又開始推薦自己嗎？難道我們像有些人那樣，需要給你們推薦信，或向你們要推薦信嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 9:1–2; 帖撒羅尼迦前書 1:8; 羅馬書 1:8"> 你們就是我們的推薦信，寫在我們的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我們的——有古抄本作「你們的」。">a</a></sup>心裡，被人人所知道、所誦讀；</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 11:19; 耶利米書 31:33; 希伯來書 8:10"> 因為很明顯，你們是基督的書信，由我們所經手；不是用墨寫的，而是用永生神的靈寫的；不是刻在石版上，而是刻在人的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人的——原文直譯「肉體的」。">b</a></sup>心版上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比書 1:6; 以弗所書 3:12; 哥林多後書 2:14"> 我們藉著基督，對神有這樣的確信，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:9; 腓立比書 4:13; 哥林多前書 15:10"> 並不是說，我們憑自己配得上把什麼算做出於自己；而是說，我們之所以配得上是出於神。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 6:63; 羅馬書 7:6; 耶利米書 31:31"> 他也使我們能夠做新約的僕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="僕人——或譯作「執事」。">c</a></sup>——不屬於律法條文，而屬於聖靈；因為律法條文帶來死亡，而聖靈卻賜予生命。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 3:9–11; 羅馬書 10:4; 出埃及記 31:18"> 如果，那以條文刻在石版上、屬死亡的服事工作尚且帶有榮光——以致以色列子民因為摩西臉上那漸漸消失的榮光，不能注視他的臉——</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 3:16; 以弗所書 2:18; 加拉太書 3:14"> 何況那屬聖靈的服事工作，難道不更帶有榮光嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 3:21–22; 希伯來書 12:18–21; 哥林多後書 5:21"> 因為那帶來<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="帶來——輔助詞語。">d</a></sup>定罪的服事工作尚且有榮光，何況那帶來<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="帶來——輔助詞語。">e</a></sup>稱義的服事工作，難道不更充滿了榮光嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 1:17; 哈該書 2:7–9; 使徒行傳 26:13"> 事實上，在這種情況下，那先前有榮光的，因這無限的榮光，就成了沒有榮光的。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:20–21; 希伯來書 8:13; 希伯來書 7:21–25"> 這樣，那漸漸消失的尚且帶有榮光，何況這長存的，難道不更帶有榮光嗎？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 7:4; 使徒行傳 4:13; 腓立比書 1:20"> 因此，我們既然懷有這樣的盼望，就大有膽量地行事。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:33–35; 希伯來書 10:1–9; 以弗所書 2:14–15"> 我們不像摩西那樣，他把帕子蒙在臉上，使以色列子民不能注視那漸漸消失的榮光的結局。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 4:3–4; 使徒行傳 26:18; 羅馬書 11:25"> 可是，他們的心思剛硬；事實上，直到今天誦讀舊約的時候，同樣的帕子仍然存在，沒有被揭去，因為那帕子只有<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="只有——輔助詞語。">f</a></sup>在基督裡才被除去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 13:27–29"> 的確，直到今天，摩西書無論什麼時候被誦讀，那帕子仍然蓋在他們的心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 34:34; 以賽亞書 29:18; 以賽亞書 25:7"> 可是一個人什麼時候歸向主，那帕子就被除掉了。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:2; 加拉太書 5:13; 約翰福音 8:32"> 主就是聖靈，主的靈在哪裡，哪裡就有自由；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 4:6; 以弗所書 4:22–24; 羅馬書 12:2"> 而且臉上的帕子既然被揭去了，我們大家就像鏡子返照出<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="就像鏡子返照出——或譯作「就像從鏡子裡看見」。">g</a></sup>主的榮光，正在被改變成與主同樣的形像，從榮耀歸入榮耀，這正是出於主——聖靈。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 1:23; 哥林多後書 12:20–21; 哥林多後書 13:10"> 所以，我自己這樣決定：不再帶著憂傷到你們那裡去。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 7:8; 哥林多後書 1:14; 哥林多前書 12:26"> 因為如果我使你們憂傷，那麼，除了我使他憂傷的那個人，誰能使我歡喜呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 5:10; 哥林多後書 8:22; 腓利門書 1:21"> 我寫了那封信<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那封信——原文直譯「這件事」。">a</a></sup>，免得我來的時候，那些本應該使我喜樂的人使我憂傷，因為我深信你們大家以我的喜樂為你們大家的喜樂。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 7:12; 箴言 27:5–6; 利未記 19:17–18"> 我在極大的患難和內心的痛苦中，流了許多淚水寫給你們，並不是要使你們憂傷，而是要你們知道我對你們懷有更多的愛。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 5:12–13; 加拉太書 4:12; 箴言 17:25"> 如果有人使人憂傷，他不是使我憂傷，而是在某種程度上使你們大家憂傷——我這樣說，免得說得太嚴重。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 5:4–5; 提摩太前書 5:20; 哥林多後書 7:11"> 這樣的人，受了大多數人的那懲罰已經夠了。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:32; 加拉太書 6:1–2; 歌羅西書 3:13"> 所以，你們反而更要饒恕他、安慰他，免得他被過度的憂傷吞沒了。</span>
<span className="v" id="v8" data-v="8" data-xref="猶大書 1:22–23; 加拉太書 6:1–2; 加拉太書 6:10"> 因此，我懇求你們向他證實你們的愛。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 10:6; 腓利門書 1:21; 腓立比書 2:22"> 其實我也為此寫了信<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="信——輔助詞語。">b</a></sup>，就是要知道你們經過考驗的品德：你們是否在一切事上都順從。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 20:23; 馬太福音 18:18; 哥林多後書 5:20"> 你們在任何事上饒恕了誰，我也饒恕誰；實際上，我如果饒恕了什麼，我所饒恕的，就是在基督面前為了你們的緣故而饒恕的，</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前書 5:8; 以弗所書 6:11–12; 哥林多後書 11:3"> 免得被撒旦占了上風，因為我們不是不明白它的意圖。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 16:8; 使徒行傳 14:27; 歌羅西書 4:3"> 我為了基督的福音來到特羅阿斯的時候，雖然主為我開了門，</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 7:5–6; 哥林多後書 12:18; 提多書 1:4"> 我還是靈裡不安，因為我沒有見到我的弟兄提多。因此我向那裡的人告別，往馬其頓省去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以弗所書 5:2; 羅馬書 8:37; 哥林多後書 2:15–16"> 但是感謝神！他總是率領我們在基督裡誇勝，並且藉著我們，在各地傳揚因認識基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——原文直譯「他」。">c</a></sup>而有的香氣。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 5:2; 哥林多前書 1:18; 以西結書 20:41"> 因為在神面前，無論在得救的人中間，還是在滅亡的人中間，我們都是基督的馨香：</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 3:5–6; 約翰福音 9:39; 彼得前書 2:7–8"> 對滅亡的人，我們是死亡的香氣以至於死亡；對得救的人，我們是生命的香氣以至於生命。對這些事，到底誰配得上呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 4:2; 哥林多後書 1:12; 彼得後書 2:1–3"> 實際上，我們不像許多人那樣，用神的話語<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的話語——或譯作「神的道」。">d</a></sup>來做生意；相反，我們是出於真誠、出於神，在神面前、在基督裡講話。</span>
</div>
</div>

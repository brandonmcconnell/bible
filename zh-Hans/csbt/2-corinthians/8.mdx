<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 16:9; 哥林多後書 9:2; 哥林多後書 9:4"> 弟兄們，我們要你們明白神在馬其頓省各教會中所賜的恩典：</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 2:5; 箴言 11:25; 哥林多後書 6:10"> 在患難的極大考驗中，他們的喜樂之滿和貧窮之深都流露出來，歸入他們慷慨之心的財富。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:29; 出埃及記 35:5; 出埃及記 35:21–22"> 因為我可以見證他們是按著自己的能力，甚至超過了自己的能力，甘心樂意，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 24:17; 加拉太書 6:10; 哥林多後書 9:1"> 用許多乞求的話，懇請我們在對聖徒的服事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="服事——或譯作「供應」。">a</a></sup>上給與他們恩准和分享的機會<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的機會——輔助詞語。">b</a></sup>；</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 12:1; 羅馬書 14:7–9; 歷代志下 30:12"> 他們不但照我們所盼望的，而且照著神的旨意，首先把自己獻給了主，又獻給了我們。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 12:18; 哥林多後書 8:19; 哥林多後書 8:4"> 我們於是勸提多，他怎樣開始了這恩惠之事，就當照樣在你們那裡把它完成；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 9:8; 彼得後書 1:5–8; 帖撒羅尼迦後書 1:3"> 而且你們怎樣在信仰、言語、知識、殷勤和你們對我們的愛心<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你們對我們的愛心——有些古抄本作「我們對你們的愛心」。">c</a></sup>上都豐足有餘，你們也當怎樣在這恩惠之事上豐足有餘。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 7:6; 約翰一書 3:17–19; 雅各書 2:14–16"> 我說這話不是出於命令，而是要藉著別人的殷勤來考驗你們愛的真誠，</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 8:32; 腓立比書 2:6–8; 馬太福音 20:28"> 因為你們知道我們主耶穌基督的恩典：他雖然富足<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="雖然富足——指「他成肉身之前的時候」。">d</a></sup>，卻為你們成了貧窮<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他……成了貧窮——指「他成肉身之後的時候」。">e</a></sup>，好使你們藉著他的貧窮可以成為富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:18–19; 希伯來書 13:16; 哥林多後書 9:2"> 我在這件事上提供意見，因為這對你們是有益處的。從去年開始，你們不僅做了這件事，而且願意去做，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 9:2"> 所以現在你們就當完成這事，好使你們怎樣有願做的樂意之心，就怎樣以你們所擁有的完成它；</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 12:42–44; 哥林多後書 9:7; 路加福音 21:1–4"> 因為人如果有樂意之心，就會照著他所擁有的蒙悅納，並不是照著他所沒有的蒙悅納。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 4:34; 羅馬書 15:26–27"> 其實我這樣說<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="我這樣說——輔助詞語。">f</a></sup>不是為了讓別人輕鬆、你們為難，而是為了公平——</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 9:12; 使徒行傳 4:34"> 在現今的時刻，你們的富餘可以補他們的缺乏，好使將來<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="將來——輔助詞語。">g</a></sup>他們的富餘也可以補你們的缺乏，這樣就公平了。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 16:18; 路加福音 22:35"> 正如經上所記：<br /><span className="pl pl-1">「多收的沒有增多，</span><br /><span className="pl pl-1">少收的也沒有缺少。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:17; 耶利米書 32:40; 哥林多後書 2:13–14"> 感謝神，他為了你們，把同樣的殷勤放在提多的心裡。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 8:6; 希伯來書 13:22; 哥林多後書 8:10"> 提多一方面接受了我們的鼓勵，另一方面自己更是殷勤，自願到你們那裡去。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 12:18; 哥林多後書 8:19; 哥林多前書 7:17"> 我們也打發了一位弟兄與他一起去。這位弟兄在福音工作上受到各教會的稱讚；</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 16:3–4; 哥林多後書 4:15; 哥林多後書 9:8"> 不僅如此，他也被各教會選出，與我們一起帶著惠贈<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="惠贈——或譯作「恩惠之事」。">h</a></sup>同行。我們這服事為的是主自己的榮耀，也為了表明<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="表明——輔助詞語。">i</a></sup>我們的樂意之心。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒羅尼迦前書 5:22; 羅馬書 14:16; 以弗所書 5:15"> 我們這樣謹慎，免得有人在我們所經手的這豐厚之事<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="豐厚之事——或譯作「豐厚的惠贈」。">j</a></sup>上挑剔我們，</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 12:17; 彼得前書 2:12; 腓立比書 4:8"> 因為我們顧念的，不僅是主看為美善，也要人看為美善。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 2:20–22"> 我們還打發了另一位弟兄和他們一起去。我們在很多事上多次驗證過這位弟兄是殷勤的，而現在他因為深深地信任你們，就更加殷勤了。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 2:25; 腓利門書 1:17; 哥林多後書 8:6"> 論到提多，他是我的同伴，也是為著你們<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="為著你們——或譯作「在你們中間」。">k</a></sup>的同工。至於那兩位弟兄<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="那兩位弟兄——原文直譯「我們的弟兄們」。">l</a></sup>，他們是各教會的使者，是基督的榮耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 7:14; 哥林多後書 7:4; 哥林多後書 9:2–4"> 所以，你們要在各教會面前，向他們顯出你們愛心的憑證，以及我們所誇耀你們的憑據。</span>
</div>

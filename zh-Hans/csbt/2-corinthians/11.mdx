<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:4; 哥林多前書 1:21; 哥林多後書 11:19"> 我真希望你們能容忍我這一點點的愚妄！的確，你們是容忍我的。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 2:19–20; 以弗所書 5:26–27; 以賽亞書 54:5"> 我以神的熱心熱愛你們，因為我已經把你們許配給一位丈夫，做為貞潔的童女獻給基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:8; 加拉太書 1:6; 以弗所書 4:14"> 可是我擔心，恐怕你們的思想受到敗壞，離開對基督的忠實和貞潔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「貞潔」。">a</a></sup>，就像蛇用牠的詭計欺騙了夏娃那樣。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:6–8; 哥林多前書 3:11; 提摩太前書 2:5"> 實際上，如果有人真的來傳另一個耶穌，不是我們所傳過的；或者你們領受另外一個靈，不是你們所領受過的；或者接受另外一個福音，不是你們所接受過的——你們竟然容忍他！</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:11–12; 哥林多前書 15:10; 加拉太書 2:6–9"> 實際上，我認為自己沒有一點趕不上那些「超級使徒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="超級使徒——指「那些認為保羅不是真使徒的教會領袖」。">b</a></sup>」。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 3:4; 哥林多前書 1:17; 哥林多後書 4:2"> 即使我在言語上沒有技巧，但在知識上並不是這樣。其實我們在各個方面、在所有的事上都已經向你們顯明了這一點。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 12:13; 帖撒羅尼迦前書 2:9; 哥林多後書 10:1"> 我降卑自己，好使你們被高舉，因為我把神的福音無償地傳給你們，難道我這樣就犯了罪嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:18; 哥林多後書 11:9; 腓立比書 4:14–16"> 我「掠奪了」別的教會，拿了他們的工價來服事你們。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:8–9; 帖撒羅尼迦前書 2:9; 帖撒羅尼迦前書 2:6"> 我在你們那裡有缺乏的時候，也沒有成為任何人的負擔，因為從馬其頓省來的弟兄們補足了我的缺乏。在一切事上我都留意，不讓自己成為你們的負擔，將來也會留意。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 9:1; 羅馬書 1:9; 使徒行傳 18:12"> 我指著<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我指著——輔助詞語。">c</a></sup>在我裡面基督的真理說，在亞該亞地區，誰也不能阻止我如此誇耀。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 12:15; 哥林多後書 6:11–12; 哥林多後書 7:3"> 為什麼呢？難道因為我不愛你們嗎？神是知道的！</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:12; 哥林多前書 5:6; 哥林多後書 5:12"> 我現在所做的，將來還要做，為要斷絕那些人的機會——他們想找一個機會，好讓別人以為他們所誇耀的與我們一樣，</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 1:7; 啟示錄 2:2; 約翰一書 4:1"> 因為這樣的人是假使徒，是詭詐的工人，他們裝做基督的使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 1:8; 哥林多後書 2:11; 哥林多後書 11:3"> 這並不足為奇，原來撒旦自己也裝做光明的天使；</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 3:19; 啟示錄 9:11; 以賽亞書 9:14–15"> 所以，即使他的僕人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="僕人——或譯作「執事」。">d</a></sup>把自己裝做義的僕人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="僕人——或譯作「執事」。">e</a></sup>，也不足為怪；他們的結局必然照著他們的行為。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 11:1; 哥林多後書 12:6; 哥林多後書 12:11"> 我再說：誰都不要以為我是愚妄的人！否則，至少該接受我這個像是愚妄的人，好讓我也可以稍微自誇。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 7:12; 腓立比書 3:3–6; 哥林多後書 9:4"> 我現在所說的，不是按照主說的，而是像一個愚妄人那樣自信誇耀。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 4:10; 哥林多後書 11:21–23; 哥林多後書 10:12–18"> 既然有許多人按人的標準<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="按人的標準——原文直譯「按肉體」。">f</a></sup>自誇，我也要自誇了，</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 4:10; 哥林多前書 10:15; 哥林多前書 8:1"> 因為你們做為聰明人，樂意容忍愚妄的人！</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 2:4; 加拉太書 4:3; 加拉太書 5:1"> 實際上，就算有人奴役你們，或侵吞你們，或榨取你們，或壓制你們，或打你們的臉，你們也能容忍。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 10:10; 哥林多後書 11:17; 哥林多後書 10:1–2"> 說來慚愧，我們倒好像是軟弱的。<br />但如果有人在什麼事上大膽——我說句愚妄的話——我也大膽！</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 3:5; 羅馬書 11:1; 羅馬書 9:4"> <span className="pl pl-1">他們是希伯來人嗎？我也是。</span><br /><span className="pl pl-1">他們是以色列人嗎？我也是。</span><br /><span className="pl pl-1">他們是亞伯拉罕的後裔嗎？我也是。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:4–5; 哥林多後書 1:9–10; 哥林多後書 6:9"> <span className="pl pl-1">他們是基督的僕人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="僕人——或譯作「執事」。">g</a></sup><br /><span className="pl pl-1">嗎？</span><br /><span className="pl pl-1">我狂妄地說：我更是！</span><br /><span className="pl pl-1">我受了更多的勞苦，更多的監禁，</span><br /><span className="pl pl-1">更多的鞭打，經常面臨死亡，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="馬可福音 13:9; 申命記 25:2–3; 馬太福音 10:17"> <span className="pl pl-1">我在猶太人的手中，遭受了五次「四十減一」的鞭打</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="的鞭打——輔助詞語。">h</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 14:19; 使徒行傳 16:37; 希伯來書 11:37"> <span className="pl pl-1">被棍子打過三次，</span><br /><span className="pl pl-1">被石頭砸過一次，</span><br /><span className="pl pl-1">遭遇海難</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="遭遇海難——原文直譯「船隻破壞」。">i</a></sup><br /><span className="pl pl-1">三次，</span><br /><span className="pl pl-1">在深海裡度過了一晝一夜；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 14:5; 使徒行傳 17:5; 使徒行傳 13:50"> <span className="pl pl-1">我經常行遠路，</span><br /><span className="pl pl-1">遭遇江河的危險、強盜的危險、</span><br /><span className="pl pl-1">來自同胞的危險、來自外邦人的危險、</span><br /><span className="pl pl-1">在城裡的危險、在曠野中的危險、</span><br /><span className="pl pl-1">在海上的危險、在假弟兄中的危險；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="腓立比書 4:12; 哥林多後書 6:5; 帖撒羅尼迦前書 2:9"> <span className="pl pl-1">我辛苦勞碌，經常失眠，</span><br /><span className="pl pl-1">又飢又渴，經常缺食，</span><br /><span className="pl pl-1">遭受寒冷，衣不蔽體。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 7:17; 羅馬書 15:16; 使徒行傳 20:18–35"> 除了這些外在的事，還有對各教會的掛慮，天天壓在我身上。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 8:13; 哥林多前書 9:22; 加拉太書 4:8–20"> 有誰軟弱，我不軟弱呢？有誰被絆倒<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="被絆倒——或譯作「被誘犯罪」。">j</a></sup>，我不心如火燒呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多後書 12:5–11; 箴言 25:27; 哥林多前書 2:3"> 如果必須誇耀，我就誇耀自己的那些軟弱。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 9:5; 以弗所書 1:3; 約翰福音 10:30"> 主耶穌的神與父——永遠當受頌讚的那一位，知道我不是在說謊。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 9:24–25; 哥林多後書 11:26"> 在大馬士革，阿瑞塔斯王的總督看守了大馬士革城，要抓<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="要抓——有古抄本作「想要抓」。">k</a></sup>我，</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 9:25; 撒母耳記上 19:12; 約書亞記 2:18"> 可是我被人用筐子從城牆的窗口縋下來，逃脫了他的手。</span>
</div>

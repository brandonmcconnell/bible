</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="詩篇 73:22; 哥林多前書 3:18; 以賽亞書 6:5"> <span className="pl pl-1">我實在比別人更愚拙，</span><br /><span className="pl pl-1">也沒有世人的悟性；</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:42; 列王紀下 2:9; 詩篇 27:4"> <span className="pl pl-1">我向你求兩件事，</span><br /><span className="pl pl-1">在我死之前，請不要不賜給我：</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前書 6:6–8; 詩篇 62:9–10; 詩篇 119:37"> <span className="pl pl-1">求你使虛妄和虛謊的事遠離我；</span><br /><span className="pl pl-1">求你使我不貧窮也不富裕，</span><br /><span className="pl pl-1">只要把我日用</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="日用——原文直譯「份額」。">c</a></sup><br /><span className="pl pl-1">的食糧分給我，</span><br /></span>

<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 14:4; 傳道書 7:21; 申命記 23:15"> <span className="pl pl-1">你不要對主人說僕人的壞話，</span><br /><span className="pl pl-1">免得他詛咒你，你就要承擔罪責。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 20:20; 箴言 30:17; 出埃及記 21:17"> <span className="pl pl-1">這世代詛咒自己的父親，</span><br /><span className="pl pl-1">也不祝福自己的母親。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 18:11; 箴言 16:2; 提摩太後書 3:5"> <span className="pl pl-1">這世代自以為</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="自以為——原文直譯「在自己眼中」。">d</a></sup><br /><span className="pl pl-1">純潔，</span><br /><span className="pl pl-1">但他的汙穢卻沒有被洗淨。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 6:17; 以賽亞書 2:11; 詩篇 101:5"> <span className="pl pl-1">這世代的眼目多麼高傲！</span><br /><span className="pl pl-1">連他的眼皮也高高抬起。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 57:4; 詩篇 3:7; 詩篇 14:4"> <span className="pl pl-1">這世代的牙齒如劍，尖牙如刀，</span><br /><span className="pl pl-1">要吞滅地上的困苦人和世人中的貧窮人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="箴言 30:21; 箴言 30:29; 箴言 6:16"> <span className="pl pl-1">螞蟥有兩個女兒，</span><br /><span className="pl pl-1">總說「給我！給我！」</span><br /><span className="pl pl-1">有三樣東西不知足，</span><br /><span className="pl pl-1">絕不說「夠了」的共有四樣，就是：</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:20; 哈巴谷書 2:5; 創世記 30:1"> <span className="pl pl-1">陰間、</span><br /><span className="pl pl-1">不育的胎胞、</span><br /><span className="pl pl-1">水源不足的土地、</span><br /><span className="pl pl-1">不說「夠了」的火。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="箴言 23:22; 申命記 21:18–21; 箴言 30:11"> <span className="pl pl-1">嘲笑父親，藐視而不順從母親的，</span><br /><span className="pl pl-1">他的眼睛將被溪谷的烏鴉啄出來，</span><br /><span className="pl pl-1">被鷹雛吃掉。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="約伯記 42:3; 詩篇 139:6"> <span className="pl pl-1">有三樣事，對我過於奇妙；</span><br /><span className="pl pl-1">連同我不明白的共有四樣，就是：</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 40:31; 約伯記 39:27; 出埃及記 22:16"> <span className="pl pl-1">天空中鷹的道、</span><br /><span className="pl pl-1">磐石上蛇的道、</span><br /><span className="pl pl-1">海洋中船的道，</span><br /><span className="pl pl-1">以及男女之道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 5:6; 箴言 7:13–23; 民數記 5:11–30"> <span className="pl pl-1">淫婦的行徑是這樣的：</span><br /><span className="pl pl-1">她吃完，把嘴一擦，就說：</span><br /><span className="pl pl-1">「我沒有做壞事。」</span></span>

<span className="v" id="v23" data-v="23" data-xref="箴言 21:19; 箴言 27:15; 箴言 29:21"> <span className="pl pl-1">令人厭惡的女子有了丈夫、</span><br /><span className="pl pl-1">婢女趕出她的主母。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="約伯記 12:7"> <span className="pl pl-1">地上有四樣東西微小，</span><br /><span className="pl pl-1">但牠們很有智慧：</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:6–8"> <span className="pl pl-1">螞蟻，牠們不是強悍的種類，</span><br /><span className="pl pl-1">但在夏天預備糧食；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 104:18; 利未記 11:5"> <span className="pl pl-1">巖貍，牠們不是強壯的種類，</span><br /><span className="pl pl-1">但在岩石中安置自己的家；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="約珥書 2:25; 約珥書 1:6–7; 約珥書 2:7–11"> <span className="pl pl-1">蝗蟲，牠們沒有王，</span><br /><span className="pl pl-1">但全部列隊而出；</span><br /></span>

</div>
<div className="bp poetry">

<span className="v" id="v30" data-v="30" data-xref="民數記 23:24; 士師記 14:18"> <span className="pl pl-1">動物中勇猛的獅子，</span><br /><span className="pl pl-1">牠面對一切都不退縮；</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 3:15–18; 箴言 20:2; 箴言 16:14"> <span className="pl pl-1">紮著腹帶的戰馬</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="戰馬——或譯作「公雞」或「獵狗」。">e</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">還有公山羊；</span><br /><span className="pl pl-1">以及帶著軍隊的王。</span></span>

<div className="bp poetry">

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; 約翰福音 14:21–24; 申命記 6:6–9"> <span className="pl pl-1">我兒啊，不要忘記我的訓誨，</span><br /><span className="pl pl-1">你的心要謹守我的誡命，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:1–3; 箴言 4:10; 詩篇 91:16"> <span className="pl pl-1">因為它們會將長久的日子、</span><br /><span className="pl pl-1">生命的歲月與平安加給你。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多後書 3:3; 希伯來書 10:16"> <span className="pl pl-1">不要讓慈愛和信實離開你，</span><br /><span className="pl pl-1">要把它們繫在你的頸項上，</span><br /><span className="pl pl-1">刻在你的心版上；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 2:52; 撒母耳記上 2:26; 羅馬書 14:18"> <span className="pl pl-1">這樣，你就在神和人的眼前蒙恩，</span><br /><span className="pl pl-1">得著美好的見識。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:5; 耶利米書 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要全心依靠耶和華，</span><br /><span className="pl pl-1">不要依賴自己的悟性；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 詩篇 32:8; 腓立比書 4:6"> <span className="pl pl-1">在你一切的道路上，都要認定他，</span><br /><span className="pl pl-1">他就會修直你的路。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 28:28; 羅馬書 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以為</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自以為——原文直譯「在你眼中」。">a</a></sup><br /><span className="pl pl-1">有智慧，</span><br /><span className="pl pl-1">要敬畏耶和華，遠離惡事；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 詩篇 147:3; 箴言 16:24"> <span className="pl pl-1">這樣健康就臨到你的身上</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="身上——原文直譯「肚臍」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你的骨頭就得到滋養。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 26:2–15; 哥林多前書 16:2; 出埃及記 23:19"> <span className="pl pl-1">你當以你的財物，以一切初熟的收成，</span><br /><span className="pl pl-1">榮耀耶和華；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命記 28:8; 箴言 22:9"> <span className="pl pl-1">這樣，你的倉庫必充滿，豐豐足足，</span><br /><span className="pl pl-1">你的榨酒池也必溢出新酒。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 5:17; 啟示錄 3:19; 希伯來書 12:5–12"> <span className="pl pl-1">我兒啊，不可厭棄耶和華的管教，</span><br /><span className="pl pl-1">也不可厭惡他的責備！</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 8:5; 啟示錄 3:19; 箴言 29:17"> <span className="pl pl-1">因為耶和華責備他所愛的，</span><br /><span className="pl pl-1">正如父親責備他所喜悅的兒子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 傳道書 9:15–18"> <span className="pl pl-1">那找到智慧、獲得聰慧的人，</span><br /><span className="pl pl-1">是蒙福的！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 約伯記 28:13–19"> <span className="pl pl-1">因為智慧的盈利好過銀子，</span><br /><span className="pl pl-1">她的收益勝過金子；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 約伯記 28:18; 詩篇 73:25–26"> <span className="pl pl-1">她比紅寶石更寶貴，</span><br /><span className="pl pl-1">你喜悅的一切都無法與她相比；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多後書 6:10; 箴言 22:4"> <span className="pl pl-1">她的右手有長壽，</span><br /><span className="pl pl-1">左手有財富和尊榮；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以賽亞書 26:3; 腓立比書 4:8–9"> <span className="pl pl-1">她的道路是恩慈的道路，</span><br /><span className="pl pl-1">她的路徑全是平安；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 啟示錄 2:7; 箴言 15:4"> <span className="pl pl-1">對於持守她的，她就是生命樹；</span><br /><span className="pl pl-1">持定她的人被稱為有福。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:24; 耶利米書 10:12; 約翰福音 1:3"> <span className="pl pl-1">耶和華藉著智慧奠定大地的根基，</span><br /><span className="pl pl-1">藉著聰慧確立諸天；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 7:11; 詩篇 65:9–12; 約伯記 36:27–28"> <span className="pl pl-1">藉著他的知識，深淵就裂開，</span><br /><span className="pl pl-1">雲朵也滴下甘露。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 1:8; 申命記 6:6–9; 申命記 32:46–47"> <span className="pl pl-1">我兒啊，你要謹守真知和謀略，</span><br /><span className="pl pl-1">不要讓它們離開你的眼目！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以賽亞書 38:16"> <span className="pl pl-1">對於你的靈魂，它們就是生命；</span><br /><span className="pl pl-1">它們也是你頸項上的美飾</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="美飾——原文直譯「恩惠」。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 詩篇 121:3"> <span className="pl pl-1">這樣你就會安然行路，</span><br /><span className="pl pl-1">你的腳也不會跌跌撞撞；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 3:5; 詩篇 4:8; 箴言 6:22"> <span className="pl pl-1">你躺下時，也不會懼怕；</span><br /><span className="pl pl-1">你躺下，就睡得甜美。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 41:10–14; 詩篇 112:7; 彼得前書 3:14"> <span className="pl pl-1">突來的恐怖，你不必害怕；</span><br /><span className="pl pl-1">惡人遭毀滅時，你也不必擔心。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 91:3; 撒母耳記上 2:9; 箴言 14:26"> <span className="pl pl-1">因為耶和華是你的依靠</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="是你的依靠——或譯作「要在你身旁」。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他保守你的腳不陷入網羅。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太書 6:10; 雅各書 2:15–16; 羅馬書 13:7"> <span className="pl pl-1">當你的手有能力做好事時，</span><br /><span className="pl pl-1">不要有所保留，不給應得的人；</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="利未記 19:13; 申命記 24:12–15; 哥林多後書 8:11"> <span className="pl pl-1">當你那裡有鄰人所求的</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="所求的——輔助詞語。">e</a></sup><br /><span className="pl pl-1">，不可對他說：</span><br /><span className="pl pl-1">「走吧，明天再來，我才給你。」</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 詩篇 55:20"> <span className="pl pl-1">你鄰人在你附近安居時，</span><br /><span className="pl pl-1">不要向他策劃惡事；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="提摩太後書 2:24; 箴言 29:22; 羅馬書 12:18–21"> <span className="pl pl-1">如果人沒有惡待你，</span><br /><span className="pl pl-1">不要無故與他相爭。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 詩篇 37:1; 加拉太書 5:21"> <span className="pl pl-1">不要嫉妒殘暴的人，</span><br /><span className="pl pl-1">也不要選擇他的任何道路；</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 25:14; 約翰福音 15:15; 箴言 11:20"> <span className="pl pl-1">因為耶和華憎惡邪僻的人，</span><br /><span className="pl pl-1">而與正直的人親密無間。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 37:22; 利未記 26:14–46; 約伯記 8:6–7"> <span className="pl pl-1">耶和華的詛咒在惡人的家，</span><br /><span className="pl pl-1">而他祝福義人的居所；</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="雅各書 4:6; 彼得前書 5:5; 詩篇 138:6"> <span className="pl pl-1">他譏諷那些譏諷者，</span><br /><span className="pl pl-1">把恩惠賜給卑微人。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 132:18; 以賽亞書 65:13–15; 詩篇 73:24"> <span className="pl pl-1">智慧人將繼承榮耀，</span><br /><span className="pl pl-1">愚昧人卻蒙受羞辱</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="蒙受羞辱——原文直譯「高舉羞辱」。">f</a></sup><br /><span className="pl pl-1">。</span></span>

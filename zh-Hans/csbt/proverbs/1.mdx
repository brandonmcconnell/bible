<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; 哥林多前書 10:15"> <span className="pl pl-1">讓智慧人聽了，就增添學問，</span><br /><span className="pl pl-1">讓有悟性的人得到指引，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:2; 馬可福音 4:11; 詩篇 49:4"> <span className="pl pl-1">使他們領悟箴言和比喻，</span><br /><span className="pl pl-1">領悟智慧人的話語和謎題</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="謎題——或譯作「謎語」或「隱語」。">a</a></sup><br /><span className="pl pl-1">。</span></span>

<div className="bp poetry">

<span className="v" id="v9" data-v="9" data-xref="但以理書 5:29; 箴言 4:9; 創世記 41:42"> <span className="pl pl-1">因為這些是你頭上恩惠的花冠，</span><br /><span className="pl pl-1">是你頸項上的一串明珠。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 5:11; 箴言 16:29; 詩篇 1:1"> <span className="pl pl-1">我兒啊，如果罪人引誘你，</span><br /><span className="pl pl-1">你不要順從！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">如果他們說：</span><br /><span className="pl pl-1">「你與我們一起去吧，</span><br /><span className="pl pl-1">讓我們埋伏，殺人流血，</span><br /><span className="pl pl-1">任意設伏攻擊無辜的人，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 124:3; 詩篇 28:1; 羅馬書 3:13"> <span className="pl pl-1">讓我們活活地囫圇吞掉他們，</span><br /><span className="pl pl-1">就像陰間吞掉那些下陰坑的人；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 6:9–10; 路加福音 12:15; 約伯記 24:2–3"> <span className="pl pl-1">我們將找到各樣寶貴的財物，</span><br /><span className="pl pl-1">用掠物裝滿我們的房屋；</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">把你的那份</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="份——原文直譯「籤」。">c</a></sup><br /><span className="pl pl-1">投入我們當中吧，</span><br /><span className="pl pl-1">我們大家共用一個錢袋！」</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="約伯記 35:11; 箴言 7:23; 耶利米書 8:7"> <span className="pl pl-1">要知道，在任何飛鳥眼前布設網羅都是無用的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 9:16; 以斯帖記 7:10; 箴言 5:22–23"> <span className="pl pl-1">他們埋伏，是在流自己的血；</span><br /><span className="pl pl-1">他們設伏，是在害自己的性命。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; 彼得後書 2:3; 雅各書 5:1–4"> <span className="pl pl-1">一切貪圖私利者所行的路</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="路——七十士譯本作「結局」。">d</a></sup><br /><span className="pl pl-1">就是這樣，</span><br /><span className="pl pl-1">不義之財將奪去其擁有者的性命。</span></span>

<span className="v" id="v23" data-v="23" data-xref="使徒行傳 3:19; 以西結書 33:11; 以西結書 18:27–30"> <span className="pl pl-1">你們要因我的責備而回轉；</span><br /><span className="pl pl-1">看哪，我要把我的靈傾注在你們身上，</span><br /><span className="pl pl-1">使你們明白我的話語！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 65:12; 羅馬書 10:21; 耶利米書 7:13"> <span className="pl pl-1">既然我呼喚了，你們拒絕，</span><br /><span className="pl pl-1">我伸出了手，沒有人留心，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:11; 路加福音 7:30; 箴言 1:30"> <span className="pl pl-1">你們忽視了我一切的勸告，</span><br /><span className="pl pl-1">也沒有接受我的責備；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:4; 箴言 10:24; 詩篇 37:13"> <span className="pl pl-1">那麼，你們遭難時，我就譏笑；</span><br /><span className="pl pl-1">恐怖臨到你們時，我就嘲笑——</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; 路加福音 21:34–35; 詩篇 58:9"> <span className="pl pl-1">那時，恐怖像風暴那樣臨到，</span><br /><span className="pl pl-1">災難像旋風那樣來臨，</span><br /><span className="pl pl-1">患難和困苦臨到你們身上。</span><br /></span>

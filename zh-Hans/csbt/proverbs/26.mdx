<span className="v" id="v3" data-v="3" data-xref="箴言 10:13; 詩篇 32:9; 哥林多前書 4:21"> <span className="pl pl-1">鞭子用來打馬，嚼環用來套驢，</span><br /><span className="pl pl-1">而杖用來打愚昧人的背。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 26:5; 彼得前書 3:9; 猶大書 1:9"> <span className="pl pl-1">不要照著愚昧人的愚妄回應他，</span><br /><span className="pl pl-1">免得你也像他一樣。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 12:16; 馬太福音 16:1–4; 箴言 28:11"> <span className="pl pl-1">要照著愚昧人的愚妄回應他，</span><br /><span className="pl pl-1">免得他自以為</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自以為——原文直譯「在自己眼中」。">a</a></sup><br /><span className="pl pl-1">有智慧。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 10:26; 箴言 25:13; 箴言 13:17"> <span className="pl pl-1">藉著愚昧人的手傳送信息的，</span><br /><span className="pl pl-1">就是自砍雙腳、自討苦吃</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="自討苦吃——原文直譯「喝下殘暴」。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:9; 詩篇 64:8; 箴言 17:7"> <span className="pl pl-1">箴言在愚昧人的口中，</span><br /><span className="pl pl-1">就像瘸子的腿懸空無用。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:1; 箴言 30:22; 箴言 19:10"> <span className="pl pl-1">把尊榮給愚昧人，</span><br /><span className="pl pl-1">如同把石頭綁死在彈弓</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="彈弓——或譯作「投石器」。">c</a></sup><br /><span className="pl pl-1">上</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="把石頭綁死在彈弓上——或譯作「把寶石放在石堆中」。">d</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 23:35"> <span className="pl pl-1">箴言在愚昧人的口中，</span><br /><span className="pl pl-1">就如蒺藜落在醉漢的手裡。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 2:6; 箴言 11:31"> <span className="pl pl-1">雇用愚昧人和過路人的，</span><br /><span className="pl pl-1">就如任意射人的弓箭手。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 2:22; 馬太福音 12:45; 出埃及記 8:15"> <span className="pl pl-1">愚昧人重複自己的愚妄，</span><br /><span className="pl pl-1">如同狗轉回來吃自己所吐的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:20; 哥林多前書 3:18–19; 箴言 26:5"> <span className="pl pl-1">你見過自以為</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="自以為——原文直譯「在自己眼中」。">e</a></sup><br /><span className="pl pl-1">有智慧的人嗎？</span><br /><span className="pl pl-1">愚昧人比他更有希望。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 22:13; 箴言 19:15; 箴言 15:19"> <span className="pl pl-1">懶惰人說：「道路上有猛獅，</span><br /><span className="pl pl-1">街市中有獅子。」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 6:12; 箴言 12:27; 箴言 12:24"> <span className="pl pl-1">懶惰人在自己床上，</span><br /><span className="pl pl-1">就如門在軸上扭轉。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:24"> <span className="pl pl-1">懶惰的人手放在盤子裡，</span><br /><span className="pl pl-1">連把食物拿回自己口裡也嫌麻煩。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 26:12; 彼得前書 3:15; 箴言 12:15"> <span className="pl pl-1">懶惰人自以為</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="自以為——原文直譯「在自己眼中」。">f</a></sup><br /><span className="pl pl-1">比七個善於應對的人更有智慧。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:3; 提摩太後書 2:23–24; 路加福音 12:14"> <span className="pl pl-1">過路人捲入與自己無關的爭辯，</span><br /><span className="pl pl-1">就如人去揪住狗的耳朵。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 25:18; 以賽亞書 50:11; 箴言 7:23"> <span className="pl pl-1">人欺騙了鄰舍，</span><br /><span className="pl pl-1">卻說「我不就是開個玩笑嗎？」</span><br /><span className="pl pl-1">他就像瘋狂的人，</span><br /><span className="pl pl-1">拋出火把、箭矢和死亡</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="-19 拋出火把、箭矢和死亡——或譯作「拋出致死的火把和利箭」。">g</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 22:10; 雅各書 3:6; 箴言 16:28"> <span className="pl pl-1">沒有木柴，火就熄滅；</span><br /><span className="pl pl-1">沒有傳謠者，紛爭就平息。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 15:18; 箴言 29:22; 撒母耳記下 20:1"> <span className="pl pl-1">好爭執的人煽動爭端，</span><br /><span className="pl pl-1">就如餘火加炭，火上加柴。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 18:8; 箴言 20:19; 以西結書 22:9"> <span className="pl pl-1">傳謠者的話語，如同可口的食物，</span><br /><span className="pl pl-1">下到人的臟腑。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:47–48; 路加福音 11:39; 箴言 10:18"> <span className="pl pl-1">火熱的嘴配奸惡的心，</span><br /><span className="pl pl-1">就像銀渣包在瓦器上。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:20; 箴言 10:18; 詩篇 41:6"> <span className="pl pl-1">懷恨人的，用言語</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="言語——原文直譯「嘴唇」。">h</a></sup><br /><span className="pl pl-1">掩飾自己，</span><br /><span className="pl pl-1">心裡卻存著詭詐。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:16–19; 耶利米書 12:6; 詩篇 28:3"> <span className="pl pl-1">他說的再好聽，也不要相信他，</span><br /><span className="pl pl-1">因為他的心裡有七樣可憎之事。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 55:21–23; 撒母耳記上 18:17; 撒母耳記上 18:21"> <span className="pl pl-1">他的怨恨雖用欺瞞掩蓋，</span><br /><span className="pl pl-1">但他的邪惡必在會眾裡被揭露。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 28:10; 詩篇 9:15; 詩篇 7:15–16"> <span className="pl pl-1">挖陷坑的，自己必掉在其中；</span><br /><span className="pl pl-1">滾石頭的，石頭必反滾在自己身上。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 8:44–49; 路加福音 20:20–21; 約翰福音 10:32–33"> <span className="pl pl-1">撒謊的舌，恨它壓傷的人；</span><br /><span className="pl pl-1">圓滑的口，造成敗壞的事。</span></span>

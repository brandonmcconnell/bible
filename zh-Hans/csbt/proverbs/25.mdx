<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 列王紀上 4:32; 彌迦書 1:1"> 以下也是所羅門的箴言，是猶大王希西加的人所抄錄的：</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="申命記 29:29; 羅馬書 11:33–34; 約伯記 11:7–8"> <span className="pl pl-1">隱藏事情，是神的榮耀；</span><br /><span className="pl pl-1">探查事情，是君王的榮耀。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 55:9; 詩篇 103:11; 列王紀上 4:29"> <span className="pl pl-1">如天之高，如地之深，</span><br /><span className="pl pl-1">君王之心也無法測度。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 2:20–21; 以西結書 22:18; 箴言 17:3"> <span className="pl pl-1">除掉銀子中的渣滓，</span><br /><span className="pl pl-1">煉銀者就造出器皿；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:12; 箴言 20:8; 詩篇 101:7–8"> <span className="pl pl-1">除掉王面前的惡人，</span><br /><span className="pl pl-1">王的寶座就藉著公義而堅立。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="箴言 27:2; 箴言 25:27; 箴言 16:19"> <span className="pl pl-1">你不要在王面前妄自尊大，</span><br /><span className="pl pl-1">也不要站在大人物的位上；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:7–11; 路加福音 18:14; 彼得前書 5:5"> <span className="pl pl-1">因為讓人對你說「上到這裡來吧」，</span><br /><span className="pl pl-1">好過在你所見的權貴面前被降卑。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="馬太福音 5:25; 箴言 17:14; 箴言 18:6"> <span className="pl pl-1">不可急於出去與人爭訟；</span><br /><span className="pl pl-1">否則你的鄰人羞辱你時，</span><br /><span className="pl pl-1">你最後要怎麼做呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 18:5–17; 箴言 11:13; 箴言 20:19"> <span className="pl pl-1">有了爭訟，可以與鄰人爭辯，</span><br /><span className="pl pl-1">但不要暴露他人的祕密，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:39"> <span className="pl pl-1">免得聽見的人辱罵你，</span><br /><span className="pl pl-1">你的惡名就不會離開你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 15:23; 以賽亞書 50:4; 傳道書 12:10"> <span className="pl pl-1">話說得合宜，</span><br /><span className="pl pl-1">就如金蘋果鑲在銀器上。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 141:5; 箴言 15:31–32; 箴言 15:5"> <span className="pl pl-1">在聽從者的耳中，</span><br /><span className="pl pl-1">智慧的責備就如金環和黃金首飾。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 13:17; 箴言 25:25; 腓立比書 2:25–30"> <span className="pl pl-1">忠實的信使對於派遣他的人，</span><br /><span className="pl pl-1">如同收割日子裡冰雪的清涼，</span><br /><span className="pl pl-1">使主人的心舒暢</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使主人的心舒暢——或譯作「使主人的靈魂甦醒」。">a</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="箴言 20:6; 路加福音 14:11; 彼得後書 2:15–19"> <span className="pl pl-1">為沒送的禮物誇耀，</span><br /><span className="pl pl-1">就如有雲有風卻無雨。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 15:1; 傳道書 10:4; 箴言 16:14"> <span className="pl pl-1">藉著恆久忍耐，能說服統領；</span><br /><span className="pl pl-1">溫和的舌頭，能折斷骨頭。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 25:27; 以弗所書 5:18; 箴言 24:13–14"> <span className="pl pl-1">你找到蜂蜜，吃夠就好</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就好——輔助詞語。">b</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">免得你過飽，把它吐出來。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 19:2–3; 士師記 19:18–21; 羅馬書 15:24"> <span className="pl pl-1">你的腳要少進鄰人的家，</span><br /><span className="pl pl-1">免得他厭煩你、恨惡你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 57:4; 箴言 12:18; 雅各書 3:6"> <span className="pl pl-1">作假見證指證自己鄰人的，</span><br /><span className="pl pl-1">就像大錘、刀劍和利箭。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 36:6; 以西結書 29:6–7; 約伯記 6:14–20"> <span className="pl pl-1">在患難的日子裡依賴背信者，</span><br /><span className="pl pl-1">就如依賴壞的牙齒、顫抖的腳。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:15; 傳道書 3:4; 以賽亞書 58:7"> <span className="pl pl-1">對著悲傷的心靈唱歌，</span><br /><span className="pl pl-1">就像冷天脫衣服，</span><br /><span className="pl pl-1">又像鹼上倒醋。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="羅馬書 12:20–21; 馬太福音 5:44; 出埃及記 23:4–5"> <span className="pl pl-1">如果你的仇敵餓了，你當給他食物吃；</span><br /><span className="pl pl-1">如果他渴了，你當給他水喝；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 16:12; 馬太福音 10:13; 哥林多前書 15:18"> <span className="pl pl-1">你這樣做</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="這樣做——輔助詞語。">c</a></sup><br /><span className="pl pl-1">，就如把火炭堆在他的頭上，</span><br /><span className="pl pl-1">耶和華也必回報你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="約伯記 37:22; 詩篇 15:3; 羅馬書 1:30"> <span className="pl pl-1">北風帶來大雨，</span><br /><span className="pl pl-1">暗中毀謗的口舌帶來怒容。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 21:19; 箴言 21:9; 箴言 27:15–16"> <span className="pl pl-1">寧可住在屋頂的一角，</span><br /><span className="pl pl-1">也好過與爭吵的妻子</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="妻子——或譯作「女人」。">d</a></sup><br /><span className="pl pl-1">同住一屋。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:30; 羅馬書 10:15; 詩篇 63:1"> <span className="pl pl-1">來自遙遠之地的好消息，</span><br /><span className="pl pl-1">就如涼水滋潤</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="滋潤——輔助詞語。">e</a></sup><br /><span className="pl pl-1">疲乏的心靈。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 34:18–19; 撒母耳記上 22:14–18; 帖撒羅尼迦前書 2:15"> <span className="pl pl-1">義人在惡人面前動搖，</span><br /><span className="pl pl-1">就如被踐踏的泉源，受汙染的水泉。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 5:44; 箴言 27:2; 腓立比書 2:3"> <span className="pl pl-1">吃蜂蜜過多不好；</span><br /><span className="pl pl-1">刻意追求自己的榮耀，也不榮耀。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 16:32; 箴言 22:24; 歷代志下 32:5"> <span className="pl pl-1">人不控制自己的心靈，</span><br /><span className="pl pl-1">就如毀壞的城沒有城牆。</span></span>
</div>
</div>

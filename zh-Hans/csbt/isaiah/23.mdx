<span className="v" id="v5" data-v="5" data-xref="約書亞記 2:9–11; 出埃及記 15:14–16; 啟示錄 18:17–19"> <span className="pl pl-1">當消息傳到埃及，</span><br /><span className="pl pl-1">埃及人就因提爾的消息而痛苦。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 23:12; 以賽亞書 21:15; 以賽亞書 23:10"> <span className="pl pl-1">沿海的居民哪，哀號吧！</span><br /><span className="pl pl-1">過到塔爾施去！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:2; 以賽亞書 32:13; 約書亞記 19:29"> <span className="pl pl-1">難道這就是你們歡騰的城嗎？</span><br /><span className="pl pl-1">這城起源於遠古，</span><br /><span className="pl pl-1">她的腳帶她到遠方居住。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 1:6; 以賽亞書 10:5; 列王紀下 17:24"> <span className="pl pl-1">看哪！迦勒底人之地——</span><br /><span className="pl pl-1">這地上的國民已經不在了。</span><br /><span className="pl pl-1">亞述人把這地指定給曠野的走獸；</span><br /><span className="pl pl-1">他們立起攻城塔，</span><br /><span className="pl pl-1">把城堡徹底摧毀，</span><br /><span className="pl pl-1">使這地成為廢墟。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 23:1; 以賽亞書 23:6; 以西結書 27:25–30"> <span className="pl pl-1">塔爾施的船隻啊，哀號吧！</span><br /><span className="pl pl-1">因為你們的堡壘被摧毀了。</span></span>

<span className="v" id="v16" data-v="16" data-xref="耶利米書 30:14; 箴言 7:10–12"> <span className="pl pl-1">「被遺忘的妓女啊，</span><br /><span className="pl pl-1">拿起豎琴，走遍全城吧！</span><br /><span className="pl pl-1">要彈得妙、唱得多，</span><br /><span className="pl pl-1">好使人再記起你！」</span></span>

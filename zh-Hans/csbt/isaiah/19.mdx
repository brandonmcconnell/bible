<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:12; 啟示錄 1:7; 約書亞記 2:11"> 有關埃及的默示：<br /><span className="pl pl-1">看哪，耶和華乘駕飛快的雲，</span><br /><span className="pl pl-1">即將臨到埃及！</span><br /><span className="pl pl-1">埃及的偶像將在他面前顫抖，</span><br /><span className="pl pl-1">埃及人都心融膽喪</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="埃及人都心融膽喪——原文直譯「埃及人的心都在自己裡面消融」。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="士師記 7:22; 撒母耳記上 14:20; 馬太福音 10:36"> <span className="pl pl-1">「我要激起埃及人敵對埃及人，</span><br /><span className="pl pl-1">各人攻擊自己的兄弟，</span><br /><span className="pl pl-1">各人攻擊自己的鄰舍，</span><br /><span className="pl pl-1">城攻擊城，國攻擊國。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 8:19; 但以理書 2:2; 歷代志上 10:13"> <span className="pl pl-1">埃及人必失魂落魄</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="埃及人必失魂落魄——原文直譯「埃及人的靈必在自己裡面被清空」。">b</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">我要使他們的計劃混亂。</span><br /><span className="pl pl-1">他們必求問偶像、陰魂、招魂的和通靈的；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 20:4; 耶利米書 46:26; 以西結書 29:19"> <span className="pl pl-1">我要把埃及交在嚴酷的主人手中，</span><br /><span className="pl pl-1">凶猛的君王必管轄他們。」</span><br /><span className="pl pl-1">這是主萬軍之耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 51:36; 以西結書 30:12; 撒迦利亞書 14:18"> <span className="pl pl-1">海裡的水必枯乾，</span><br /><span className="pl pl-1">大河必乾涸枯竭，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:25; 出埃及記 7:18; 列王紀下 19:24"> <span className="pl pl-1">河道必發臭，</span><br /><span className="pl pl-1">埃及的河流必消減而乾涸；</span><br /><span className="pl pl-1">蘆葦和蘆荻必衰殘，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 32:20; 約珥書 1:17–18; 以賽亞書 23:3"> <span className="pl pl-1">尼羅河邊、尼羅河口的蒲草</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="蒲草——或譯作「不毛之地」。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">以及沿著尼羅河所種的田都必枯竭，</span><br /><span className="pl pl-1">被風吹去，不復存在。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 47:10; 哈巴谷書 1:15; 民數記 11:5"> <span className="pl pl-1">漁夫必哀哭，</span><br /><span className="pl pl-1">尼羅河上所有垂釣的必悲慟，</span><br /><span className="pl pl-1">水面上撒網的也必沮喪。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 27:7; 箴言 7:16; 列王紀上 10:28"> <span className="pl pl-1">績麻的和織白布的都必蒙羞，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:10; 出埃及記 7:19; 出埃及記 8:5"> <span className="pl pl-1">埃及的棟梁</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="棟梁——或譯作「紡織的人」。">d</a></sup><br /><span className="pl pl-1">必被壓碎，</span><br /><span className="pl pl-1">所有的雇工都必心裡悲痛。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="民數記 13:22; 使徒行傳 7:22; 列王紀上 4:30"> <span className="pl pl-1">瑣安的首領們極其愚妄，</span><br /><span className="pl pl-1">法老最智慧的謀士們所出的謀略都是愚拙！</span><br /><span className="pl pl-1">你們怎麼能對法老說</span><br /><span className="pl pl-1">「我是智慧人的子孫，</span><br /><span className="pl pl-1">是古代君王的後裔」？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 1:20; 以賽亞書 14:24; 士師記 9:38"> <span className="pl pl-1">你的智慧人在哪裡呢？</span><br /><span className="pl pl-1">讓他們告訴你吧，</span><br /><span className="pl pl-1">讓他們去明白萬軍之耶和華對埃及所策劃的！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 30:13; 耶利米書 2:16; 耶利米書 46:14"> <span className="pl pl-1">瑣安的首領們愚昧，</span><br /><span className="pl pl-1">挪弗</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="挪弗——希臘語音譯為「孟菲斯」。">e</a></sup><br /><span className="pl pl-1">的首領們被欺哄；</span><br /><span className="pl pl-1">埃及眾支派中當房角石的，使埃及人迷失。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦後書 2:11; 列王紀上 22:20–23; 以西結書 14:7–9"> <span className="pl pl-1">耶和華在埃及中摻入了歪謬的靈，</span><br /><span className="pl pl-1">首領們就使埃及在一切所做的事上都迷失，</span><br /><span className="pl pl-1">好像醉酒的人嘔吐時搖晃迷糊。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 9:14–15; 帖撒羅尼迦前書 4:11–12; 箴言 14:23"> <span className="pl pl-1">無論是頭是尾，是棕枝是蘆葦，</span><br /><span className="pl pl-1">都不能為埃及成就什麼。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 51:30; 那鴻書 3:13; 以賽亞書 11:15"> 到那日，埃及人必像婦女一樣，必因萬軍之耶和華揮手攻擊他們而戰兢懼怕。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 14:24; 但以理書 4:35; 以西結書 29:6–7"> 猶大地必使埃及恐懼——猶大地一被提起，任何人都會懼怕，因為這是萬軍之耶和華向埃及所策劃的謀略。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="西番雅書 3:9; 撒迦利亞書 2:11; 以賽亞書 19:21"> 到那日，在埃及地必有五座城說迦南通用語<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="通用語——原文直譯「嘴唇」；或譯作「語言」。">f</a></sup>，並向萬軍之耶和華起誓，其中一座稱為「太陽城<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="太陽城——或譯作「滅亡城」。">g</a></sup>」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 28:18; 約書亞記 22:10; 約書亞記 22:26"> 到那日，在埃及地當中必有一座為耶和華而立的祭壇；在埃及的邊界附近必有一根為耶和華而立的石柱。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:15; 提多書 2:13; 以賽亞書 45:21–22"> 這都在埃及地作萬軍之耶和華的標記和見證。埃及人因受人壓迫向耶和華呼求時，他就派遣一位拯救者、維護者來解救他們。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 11:9; 瑪拉基書 1:11; 約翰福音 17:3"> 這樣，耶和華就把自己向埃及顯明。到那日，埃及人必認識耶和華，他們必用祭物和供物來敬拜他，向耶和華許願、還願。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; 希伯來書 12:11; 何西阿書 14:1"> 耶和華必擊打埃及，擊打後又醫治。這樣，埃及人就回轉歸向耶和華；而耶和華必應允他們的祈求，醫治他們。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 11:16; 以弗所書 2:18–22; 以賽亞書 35:8–10"> 到那日，必有一條大道從埃及通往亞述；亞述人到埃及來，埃及人也到亞述去；埃及人與亞述人一同敬拜耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 65:8; 創世記 12:2; 加拉太書 3:14"> 到那日，以色列將與埃及、亞述一同，三者都成為地上的祝福；</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 29:23; 何西阿書 2:23; 羅馬書 9:24–25"> 萬軍之耶和華祝福他們，說：「埃及我的百姓，亞述我手的作為，以色列我的繼業，都是蒙福的！」</span>
</div>

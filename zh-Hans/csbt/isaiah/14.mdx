</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 30:10; 以賽亞書 32:18; 以斯拉記 9:8–9"> 在耶和華使你脫離痛苦、煩擾，脫離被迫所服的沉重勞役，得享安息的日子裡，</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 49:26; 哈巴谷書 1:2–10; 耶利米書 51:34–35"> 你必對巴比倫王唱這首諷刺歌：<br /><span className="pl pl-1">「壓迫人的怎麼止息了呢？</span><br /><span className="pl pl-1">凶暴怎麼止息了呢？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 125:3; 以賽亞書 9:4; 耶利米書 48:15–17"> <span className="pl pl-1">耶和華打斷了惡人的杖和管轄者的權杖——</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 7:19–21; 雅各書 2:13; 啟示錄 17:16–17"> <span className="pl pl-1">它們曾在盛怒中以不停的猛擊來擊打萬民；</span><br /><span className="pl pl-1">在怒氣中以無情的逼迫來轄制列國。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 126:1–3; 詩篇 98:7–9; 詩篇 96:11–13"> <span className="pl pl-1">現在全地都安息、平靜了，</span><br /><span className="pl pl-1">人人都放聲歡呼；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 31:16; 以賽亞書 55:12–13; 撒迦利亞書 11:2"> <span className="pl pl-1">連松樹和黎巴嫩的香柏樹也因你倒下而歡喜，說：</span><br /><span className="pl pl-1">『自從你倒下後，</span><br /><span className="pl pl-1">再沒有伐木之人上來砍伐我們了！』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以西結書 32:21–32; 耶利米書 50:8; 箴言 15:24"> <span className="pl pl-1">「地下的陰間騷動起來迎接你的到來，</span><br /><span className="pl pl-1">並為你喚醒陰魂，就是所有生前</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="生前——輔助詞語。">a</a></sup><br /><span className="pl pl-1">在地上作過領袖的陰魂；</span><br /><span className="pl pl-1">又使所有生前</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="生前——輔助詞語。">b</a></sup><br /><span className="pl pl-1">作過列國君王的都從自己寶座上起來。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 49:6–14; 傳道書 2:16; 詩篇 82:6–7"> <span className="pl pl-1">他們都必回應你，說：</span><br /><span className="pl pl-1">『你竟然像我們一樣變得軟弱無能，</span><br /><span className="pl pl-1">與我們相似了！』</span><br /></span>

<div className="bp poetry">

<span className="v" id="v13" data-v="13" data-xref="但以理書 8:10–12; 以西結書 28:2; 以西結書 28:12–16"> <span className="pl pl-1">你心裡曾說：</span><br /><span className="pl pl-1">『我要升到天上，</span><br /><span className="pl pl-1">我要高舉我的寶座在神的眾星之上，</span><br /><span className="pl pl-1">我要坐在北方極處的聚會山上，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 47:8; 創世記 3:5; 帖撒羅尼迦後書 2:4"> <span className="pl pl-1">我要升到雲端之上，</span><br /><span className="pl pl-1">我要使自己與至高者相比。』</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 11:23; 以西結書 32:23; 使徒行傳 12:22–23"> <span className="pl pl-1">然而你必墜入陰間，</span><br /><span className="pl pl-1">下到陰坑的極處！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 50:23; 詩篇 58:10–11; 耶利米書 51:20–23"> <span className="pl pl-1">「那些看見你的都必注視你，</span><br /><span className="pl pl-1">他們要審視你，說：</span><br /><span className="pl pl-1">『那使大地顫抖，使列國震動的，</span><br /><span className="pl pl-1">難道就是這人嗎？</span><br /></span>

<span className="v" id="v18" data-v="18" data-xref="歷代志下 24:25; 以賽亞書 22:16; 以西結書 32:18–32"> <span className="pl pl-1">所有生前</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="生前——輔助詞語。">d</a></sup><br /><span className="pl pl-1">作過列國君王的，</span><br /><span className="pl pl-1">都在各自的墓穴裡長眠於尊榮中，</span><br /></span>

<span className="v" id="v20" data-v="20" data-xref="詩篇 21:10; 約伯記 18:19; 詩篇 37:28"> <span className="pl pl-1">你必不能與其他君王同葬，</span><br /><span className="pl pl-1">因為你毀壞了你的國，</span><br /><span className="pl pl-1">殺戮了你的民。</span><br /><span className="pl pl-1">願作惡者的後裔永不被提起！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 23:35; 出埃及記 20:5; 哈巴谷書 2:8–12"> <span className="pl pl-1">你們要為他的子孫預備好屠宰場，</span><br /><span className="pl pl-1">這是因他們祖先的罪孽；</span><br /><span className="pl pl-1">他們絕不會再興起、占有土地、使城鎮遍滿地面。」</span></span>
</div>

<span className="v" id="v23" data-v="23" data-xref="西番雅書 2:14; 以賽亞書 13:21–22; 列王紀上 14:10"> 「我必使巴比倫被豪豬占據，成為沼澤地；我必用毀滅的掃帚將它掃淨！」萬軍之耶和華如此宣告。</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="箴言 19:21; 約伯記 23:13; 以賽亞書 46:10–11"> 萬軍之耶和華起誓說：<br /><span className="pl pl-1">「我怎樣想，也必怎樣成；</span><br /><span className="pl pl-1">我怎樣策劃，也必怎樣成立。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 9:4; 那鴻書 1:13; 以賽亞書 37:36–38"> <span className="pl pl-1">我要在我的地上摧毀亞述，</span><br /><span className="pl pl-1">在我的群山上把它踐踏；</span><br /><span className="pl pl-1">它所加的軛必離開以色列人，</span><br /><span className="pl pl-1">它所加的重擔必離開他們的肩膀。」</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 23:9; 西番雅書 3:6–8; 出埃及記 15:12"> <span className="pl pl-1">這就是對全地所策劃的謀略，</span><br /><span className="pl pl-1">這就是向萬國所伸出的手。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="列王紀下 16:20; 以賽亞書 13:1; 歷代志下 28:27"> 亞哈斯王駕崩的那年，有這樣的默示：</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 30:6; 以賽亞書 11:8; 歷代志下 26:6"> <span className="pl pl-1">非利士全地啊，</span><br /><span className="pl pl-1">不要因那責打你的杖折斷了而歡喜！</span><br /><span className="pl pl-1">因為從蛇的根必生出毒蛇，</span><br /><span className="pl pl-1">所生的</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="所生的——原文直譯「它的果實」。">e</a></sup><br /><span className="pl pl-1">是會飛的火蛇。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 7:21–22; 西番雅書 2:4–7; 以賽亞書 5:17"> <span className="pl pl-1">最貧弱的人</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="最貧弱的人——原文直譯「貧弱者的長子」。">f</a></sup><br /><span className="pl pl-1">也必有所食，</span><br /><span className="pl pl-1">貧窮的人也必安然躺臥；</span><br /><span className="pl pl-1">但我卻要用饑荒殺死你的根，</span><br /><span className="pl pl-1">你的餘剩之民也要被饑荒所殺。</span><br /></span>

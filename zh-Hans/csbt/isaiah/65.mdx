<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 10:20; 羅馬書 9:24–26; 彼得前書 2:10"> 耶和華說：<br /><span className="pl pl-1">「那些沒有求問我的，我讓他們尋求我；</span><br /><span className="pl pl-1">沒有尋找我的，我讓他們尋見我；</span><br /><span className="pl pl-1">沒有被稱為我名下的國，我對他們說：</span><br /><span className="pl pl-1">『我在這裡！我在這裡！』</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 10:21; 箴言 1:24; 耶利米書 4:14"> <span className="pl pl-1">我終日向悖逆的子民伸出我的手。</span><br /><span className="pl pl-1">他們隨著自己的意念行不善之道；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:29; 申命記 32:21; 以賽亞書 66:17"> <span className="pl pl-1">這子民當著我的面不斷地惹怒我，</span><br /><span className="pl pl-1">他們在園林裡獻祭，在磚頭上燒香；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 66:17; 利未記 11:7; 以賽亞書 66:3"> <span className="pl pl-1">他們坐在墳墓之間，在隱祕處過夜；</span><br /><span className="pl pl-1">他們吃豬肉，器皿中有不潔之肉做的湯；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:9–12; 路加福音 7:39; 箴言 16:5"> <span className="pl pl-1">他們說：『你就站在那裡，</span><br /><span className="pl pl-1">不要接近我，因為我比你聖潔。』</span><br /><span className="pl pl-1">這些就是我鼻孔中的煙，</span><br /><span className="pl pl-1">是終日燃燒的火。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 50:3; 耶利米書 16:18; 詩篇 79:12"> <span className="pl pl-1">看哪！這都被記在我面前：</span><br /><span className="pl pl-1">我不再靜默，一定報應；</span><br /><span className="pl pl-1">我必把他們的罪孽、他們祖先的罪孽一同報應在他們懷中。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 20:27–28; 以賽亞書 57:7; 出埃及記 20:5"> <span className="pl pl-1">因為他們在山上燒香，在岡陵上辱罵我，</span><br /><span className="pl pl-1">所以我必稱量他們先前的行為，報應在他們懷中。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 9:27–29; 阿摩司書 9:8–9; 羅馬書 11:24–26"> 耶和華如此說：<br /><span className="pl pl-1">「當新酒在累累葡萄中被發現時，</span><br /><span className="pl pl-1">人怎樣說：『不要毀滅它，</span><br /><span className="pl pl-1">因為有祝福在其中』，</span><br /><span className="pl pl-1">我也要怎樣做——</span><br /><span className="pl pl-1">為我僕人們的緣故，</span><br /><span className="pl pl-1">不把一切都毀滅。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 9:11–15; 以賽亞書 27:6; 羅馬書 11:5–7"> <span className="pl pl-1">我必使後裔從雅各而出，</span><br /><span className="pl pl-1">使我眾山的繼承人從猶大而來；</span><br /><span className="pl pl-1">我的選民必擁有那地，</span><br /><span className="pl pl-1">我的僕人們必居住在那裡。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 35:2; 以賽亞書 33:9; 何西阿書 2:15"> <span className="pl pl-1">為那些尋求我的子民，</span><br /><span className="pl pl-1">沙崙將成為羊群的牧場，</span><br /><span className="pl pl-1">亞割谷將成為牛群的躺臥之處。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 2:2; 以賽亞書 1:28; 申命記 32:17"> <span className="pl pl-1">至於你們這些離棄耶和華、</span><br /><span className="pl pl-1">忘記我的聖山、</span><br /><span className="pl pl-1">為『幸運之神』擺設筵席、</span><br /><span className="pl pl-1">為『命運之神』倒滿混合酒的人，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 7:13; 歷代志下 36:15–16; 撒迦利亞書 7:11–13"> <span className="pl pl-1">我命定你們歸於刀劍，</span><br /><span className="pl pl-1">你們所有的人都將在屠殺中倒下。</span><br /><span className="pl pl-1">因為我呼喚，你們不回應；</span><br /><span className="pl pl-1">我說話，你們不聽從；</span><br /><span className="pl pl-1">你們做我眼中看為惡的事，</span><br /><span className="pl pl-1">選擇我所不喜悅的事。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 3:18; 以賽亞書 66:14; 以賽亞書 61:7"> 因此，主耶和華如此說：<br /><span className="pl pl-1">「看哪，我的僕人們必有吃的，</span><br /><span className="pl pl-1">你們卻會挨餓！</span><br /><span className="pl pl-1">看哪，我的僕人們必有喝的，</span><br /><span className="pl pl-1">你們卻會口渴！</span><br /><span className="pl pl-1">看哪，我的僕人們必歡喜，</span><br /><span className="pl pl-1">你們卻會蒙羞！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 8:12; 詩篇 66:4; 馬太福音 22:13"> <span className="pl pl-1">看哪，我的僕人們因心中高興而歡呼，</span><br /><span className="pl pl-1">你們卻因心中傷痛而呼號、</span><br /><span className="pl pl-1">因靈裡破碎而哀號！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 62:2; 羅馬書 9:26; 使徒行傳 11:26"> <span className="pl pl-1">你們必留下自己的名字，</span><br /><span className="pl pl-1">作我選民的詛咒詞。</span><br /><span className="pl pl-1">主耶和華必殺死你們；</span><br /><span className="pl pl-1">至於我</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——原文直譯「他」。">a</a></sup><br /><span className="pl pl-1">的僕人們，我</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我——原文直譯「他」。">b</a></sup><br /><span className="pl pl-1">必用另外的名字稱呼他們。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 19:18; 耶利米書 4:2; 詩篇 31:5"> <span className="pl pl-1">在地上為自己祝福的，</span><br /><span className="pl pl-1">必藉著真實的神為自己祝福；</span><br /><span className="pl pl-1">在地上起誓的，</span><br /><span className="pl pl-1">必指著真實的神起誓；</span><br /><span className="pl pl-1">因為先前的患難已被忘記，</span><br /><span className="pl pl-1">從我眼前被隱藏了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="彼得後書 3:13; 啟示錄 21:1–5; 以賽亞書 66:22"> <span className="pl pl-1">「看哪！我要創造一個新天新地，</span><br /><span className="pl pl-1">先前的事不再被記念，也不再被想起</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="想起——原文直譯「上到心上」。">c</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 98:1–9; 啟示錄 19:1–6; 以賽亞書 66:10–14"> <span className="pl pl-1">你們要因我所創造的而歡喜快樂，直到永遠。</span><br /><span className="pl pl-1">看哪！我要創造耶路撒冷作為歡樂之源</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="之源——輔助詞語。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">創造她的民作為喜樂之泉</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="之泉——輔助詞語。">e</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 21:4; 啟示錄 7:17; 以賽亞書 25:8"> <span className="pl pl-1">我要因耶路撒冷而快樂，</span><br /><span className="pl pl-1">因我的子民而歡喜，</span><br /><span className="pl pl-1">城中再也聽不見哭泣的聲音和哀叫的聲音；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 5:26; 傳道書 8:12–13; 申命記 4:40"> <span className="pl pl-1">那裡不再有數日夭折</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="數日夭折——或譯作「只活幾天」。">f</a></sup><br /><span className="pl pl-1">的嬰孩，</span><br /><span className="pl pl-1">也不再有壽數不滿的老年人；</span><br /><span className="pl pl-1">因為百歲死的只算為年少，</span><br /><span className="pl pl-1">不到百歲死的就算為受詛咒。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="阿摩司書 9:14; 以賽亞書 62:8–9; 以賽亞書 32:18"> <span className="pl pl-1">他們必建造房屋住下來，</span><br /><span className="pl pl-1">栽種葡萄園，吃園中的果實。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 92:12–14; 詩篇 91:16; 詩篇 21:4"> <span className="pl pl-1">他們不會建造了房屋而別人來居住，</span><br /><span className="pl pl-1">不會栽種了葡萄園而別人來享用；</span><br /><span className="pl pl-1">因為我子民的壽命必像樹木的壽命，</span><br /><span className="pl pl-1">我的選民必長久享受他們雙手做工的成果</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="的成果——輔助詞語。">g</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 61:9; 耶利米書 32:38–39; 申命記 28:3–12"> <span className="pl pl-1">他們不會徒然辛勞，</span><br /><span className="pl pl-1">也不會生下註定</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="註定——輔助詞語。">h</a></sup><br /><span className="pl pl-1">遭禍患的孩子；</span><br /><span className="pl pl-1">因為他們是蒙耶和華祝福的後裔，</span><br /><span className="pl pl-1">他們的子孫也是如此。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 10:12; 約翰一書 5:14–15; 以賽亞書 58:9"> <span className="pl pl-1">那時，他們還沒有呼求，我就回應；</span><br /><span className="pl pl-1">他們還在說話，我就垂聽。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:6–9; 彌迦書 4:3; 使徒行傳 9:19–21"> <span className="pl pl-1">狼與羊羔一同吃草，</span><br /><span className="pl pl-1">獅子像牛一樣吃乾草，</span><br /><span className="pl pl-1">蛇以塵土為食物；</span><br /><span className="pl pl-1">在我整個聖山上，</span><br /><span className="pl pl-1">牠們都不會帶來傷害或毀滅。」</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>

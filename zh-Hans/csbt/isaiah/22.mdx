<span className="v" id="v1" data-v="1" data-xref="耶利米書 21:13; 詩篇 125:2; 約珥書 3:12"> 有關「異象谷」的默示：<br /><span className="pl pl-1">究竟發生了什麼事，</span><br /><span className="pl pl-1">以致你們全都上到屋頂了？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 32:13; 以賽亞書 23:7; 耶利米哀歌 2:20"> <span className="pl pl-1">你這充滿叫嚷的喧鬧之城、歡騰之邑啊！</span><br /><span className="pl pl-1">你當中被殺的人，</span><br /><span className="pl pl-1">卻不是被刀所殺，</span><br /><span className="pl pl-1">也不是死於戰場。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 25:4–7; 以賽亞書 3:1–8; 耶利米書 39:4–7"> <span className="pl pl-1">你所有的統領一同逃亡，</span><br /><span className="pl pl-1">弓未拉開就被抓住；</span><br /><span className="pl pl-1">你們所有被發現的人，</span><br /><span className="pl pl-1">雖然逃到遠方也一同被抓住。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 9:1; 馬太福音 2:18; 詩篇 77:2"> <span className="pl pl-1">因此我說：</span><br /><span className="pl pl-1">「請你轉眼別看我，讓我痛哭吧！</span><br /><span className="pl pl-1">不要因我子民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="子民——原文直譯「女兒子民」。">a</a></sup><br /><span className="pl pl-1">的毀滅而強行安慰我！」</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 7:4; 以賽亞書 37:3; 路加福音 23:30"> <span className="pl pl-1">因為主萬軍之耶和華定了一個日子，</span><br /><span className="pl pl-1">在「異象谷」必有騷亂、踐踏和驚惶——</span><br /><span className="pl pl-1">城牆被攻破，呼救聲達到山上。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 16:9; 以賽亞書 21:2; 阿摩司書 1:5"> <span className="pl pl-1">以攔背上箭袋，</span><br /><span className="pl pl-1">帶著戰車馬兵；</span><br /><span className="pl pl-1">吉珥亮出盾牌。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 8:7–8; 以賽亞書 10:28–32; 耶利米書 39:1–3"> <span className="pl pl-1">你最好的山谷中遍滿戰車，</span><br /><span className="pl pl-1">馬兵也在城門前排陣就位。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:2; 列王紀上 10:17; 以賽亞書 36:1–3"> <span className="pl pl-1">耶和華挪去了猶大的屏障。</span><br />到那日，你們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你們——原文直譯「你」。">b</a></sup>指望林宮裡的兵器；</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 20:20; 尼希米記 3:16; 歷代志下 32:1–6"> 你們看見大衛城的破口很多，就積聚下池的水；</span>
<span className="v" id="v10" data-v="10"> 你們數點耶路撒冷的房屋，把房屋拆掉，用來加固城牆；</span>
<span className="v" id="v11" data-v="11" data-xref="彌迦書 7:7; 耶利米書 33:2–3; 以賽亞書 31:1"> 你們又在兩道城牆之間造蓄水池，用來盛舊池的水；但你們卻沒有指望行這事的、沒有顧念在遠古計劃這事的那一位。</span>
<span className="v" id="v12" data-v="12" data-xref="約珥書 2:17; 彌迦書 1:16; 約珥書 1:13"> <span className="pl pl-1">到那日，</span><br /><span className="pl pl-1">主萬軍之耶和華呼籲你們哭泣哀號、</span><br /><span className="pl pl-1">剃光頭髮、束上麻布。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 56:12; 哥林多前書 15:32; 路加福音 17:26–29"> <span className="pl pl-1">看哪！你們卻歡喜快樂，</span><br /><span className="pl pl-1">殺牛宰羊，吃肉喝酒，說：</span><br /><span className="pl pl-1">「讓我們吃喝吧！</span><br /><span className="pl pl-1">因為明天我們就要死了。」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 24:13; 撒母耳記上 3:14; 以賽亞書 5:9"> <span className="pl pl-1">萬軍之耶和華親自啟示我</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="啟示我——原文直譯「在我耳中啟示」。">c</a></sup><br /><span className="pl pl-1">：</span><br /><span className="pl pl-1">「這罪孽，你們到死也絕不會贖清！」</span><br /><span className="pl pl-1">這是主萬軍之耶和華說的。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 36:3; 列王紀下 18:18; 列王紀下 19:2"> 主萬軍之耶和華如此說：「去吧，到管理宮殿的舍伯納總管那裡，對他說：</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:60; 歷代志下 16:14; 撒母耳記下 18:18"> 你在這裡有什麼權利，你在這裡有什麼人，你竟然在這裡為自己開鑿墳墓？你這在高處為自己開鑿墳墓、在岩石中為自己雕鑿居所的人哪！</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 14:3; 約伯記 9:24; 以斯帖記 7:8"> 看哪，耶和華必把你猛力拋出！你這強人哪，耶和華必把你緊緊抓住，</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 17:13; 阿摩司書 7:17"> 把你捲了又捲，捲成球狀，拋向寬廣之地！你必死在那裡，你華美的戰車也必毀在那裡，你這主人家的羞辱啊！</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 17:24; 詩篇 75:6–7; 約伯記 40:11–12"> 我必從你的職位革除你，把你從你的位置上拉下來。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 36:3; 列王紀下 18:18; 以賽亞書 37:2"> 「到那日，我必召來我的僕人，就是希勒加的兒子以利亞敬；</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:8; 以賽亞書 9:6–7; 創世記 41:42–43"> 我要把你的袍子給他穿上，把你的腰帶給他繫緊，把你的權柄交在他的手中；他必作耶路撒冷的居民和猶大家的父。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 16:18–19; 啟示錄 3:7; 約伯記 12:14"> 我必把大衛家的鑰匙放在他的肩上——他開了就沒有人能關，關了就沒有人能開。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:8; 約伯記 36:7; 撒迦利亞書 10:4"> 我要把他像橛子一樣釘在牢固的地方。對他的父家，他必成為榮耀的寶座。</span>

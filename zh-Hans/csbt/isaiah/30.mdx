<span className="v" id="v2" data-v="2" data-xref="以賽亞書 36:6; 民數記 27:21; 申命記 28:68"> <span className="pl pl-1">他們沒有請示我，就起身下埃及去，</span><br /><span className="pl pl-1">在法老的保護下避難，</span><br /><span className="pl pl-1">投靠在埃及的蔭庇下。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 20:5; 羅馬書 10:11; 耶利米書 17:5–6"> <span className="pl pl-1">因此，法老的保護必成為他們</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他們——原文直譯「你們」。">a</a></sup><br /><span className="pl pl-1">的恥辱；</span><br /><span className="pl pl-1">投靠在埃及的蔭庇下，也必成為他們的羞愧。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 19:11; 以賽亞書 57:9; 耶利米書 43:7"> <span className="pl pl-1">雖然他們的首領們已經在瑣安，</span><br /><span className="pl pl-1">他們的使者們已經到達哈內斯，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 2:36; 以賽亞書 30:7; 以賽亞書 30:16"> <span className="pl pl-1">但他們卻因那無益之民而蒙羞——</span><br /><span className="pl pl-1">那民不能給他們帶來幫助和益處，</span><br /><span className="pl pl-1">只能帶來恥辱和羞辱。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="申命記 8:15; 以賽亞書 46:1–2; 耶利米書 11:4"> 與南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音譯作「內蓋夫」。">b</a></sup>動物有關的默示：<br /><span className="pl pl-1">他們把財富馱在驢子背上，</span><br /><span className="pl pl-1">把寶物馱在駱駝峰上，</span><br /><span className="pl pl-1">經過患難困苦之地，</span><br /><span className="pl pl-1">就是公獅、母獅、蝮蛇和會飛的火蛇出沒之地，</span><br /><span className="pl pl-1">要到一個無益於他們的民那裡。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 2:22; 以賽亞書 7:4; 詩篇 118:8–9"> <span className="pl pl-1">埃及的幫助是虛空的、徒然的，</span><br /><span className="pl pl-1">因此我稱它為</span><br /><span className="pl pl-1">「靜止不動的拉哈伯</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="拉哈伯——指一種水怪。">c</a></sup><br /><span className="pl pl-1">」。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="申命記 31:22; 哈巴谷書 2:2; 以賽亞書 8:1"> <span className="pl pl-1">現在你去！</span><br /><span className="pl pl-1">在他們面前把這話刻在版上，</span><br /><span className="pl pl-1">記在書卷上，</span><br /><span className="pl pl-1">作為將來日子的證據，直到永遠。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 30:1; 使徒行傳 7:51; 撒迦利亞書 1:4–6"> <span className="pl pl-1">因為他們是悖逆的子民，欺詐的兒女，</span><br /><span className="pl pl-1">是不肯聽從耶和華訓誨的兒女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 13:7–10; 羅馬書 16:18; 阿摩司書 2:12"> <span className="pl pl-1">他們對先見說：「不要看異象</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="異象——輔助詞語。">d</a></sup><br /><span className="pl pl-1">了！」</span><br /><span className="pl pl-1">對先知說：「不要向我們預言真確的事，</span><br /><span className="pl pl-1">要向我們說柔滑的話，預言虛幻的事！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:7; 羅馬書 1:30; 約翰福音 15:23–24"> <span className="pl pl-1">你們要離開這道，轉離這路，</span><br /><span className="pl pl-1">不要在我們面前再提以色列的聖者了！」</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 31:1–3; 以賽亞書 5:24; 帖撒羅尼迦前書 4:8"> <span className="pl pl-1">因此，以色列的聖者如此說：</span><br /><span className="pl pl-1">「因為你們厭棄了這話，</span><br /><span className="pl pl-1">依靠欺壓和邪僻，以它們為依賴；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 29:5; 以西結書 13:10–15; 列王紀上 20:30"> <span className="pl pl-1">所以這罪孽對你們就像高牆上的破口，</span><br /><span className="pl pl-1">牆體凸出，快要倒塌——</span><br /><span className="pl pl-1">頃刻之間，崩毀就突然臨到；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 2:9; 耶利米書 19:10–11; 彼得後書 2:4–5"> <span className="pl pl-1">那崩毀好像陶匠的瓦器被搗毀，</span><br /><span className="pl pl-1">被無情地打碎，</span><br /><span className="pl pl-1">以致在碎瓦塊中找不到一片</span><br /><span className="pl pl-1">可以用來從爐裡取火或從池中舀水。」</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:3–4; 以賽亞書 32:17; 耶利米書 3:22–23"> <span className="pl pl-1">以色列的聖者主耶和華如此說：</span><br /><span className="pl pl-1">「你們得救在於悔改和安息，</span><br /><span className="pl pl-1">你們得力在於平靜和信靠。」</span><br /><span className="pl pl-1">你們卻不肯接受，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 31:1; 以賽亞書 31:3; 申命記 28:25"> <span className="pl pl-1">還說：「不，我們要騎馬逃跑！」</span><br /><span className="pl pl-1">因此你們真的會逃跑；</span><br /><span className="pl pl-1">你們又說：「我們要騎飛快的馬！」</span><br /><span className="pl pl-1">因此追趕你們的人也會飛快。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:25; 約書亞記 23:10; 申命記 32:30"> <span className="pl pl-1">一個人的威脅，會使千人逃跑；</span><br /><span className="pl pl-1">五個人的威脅，會使你們逃跑得所剩無幾，</span><br /><span className="pl pl-1">如山頂上的旗杆，</span><br /><span className="pl pl-1">又如岡陵上的旗幟。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:25–26; 彼得後書 3:9; 箴言 16:20"> <span className="pl pl-1">雖然如此，耶和華卻等候著要恩待你們；</span><br /><span className="pl pl-1">因此，他會起來憐憫你們，</span><br /><span className="pl pl-1">因為耶和華是公正的神；</span><br /><span className="pl pl-1">所有等候他的，都是蒙福的！</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 60:20; 詩篇 50:15; 以賽亞書 65:24"> 錫安的民——住在耶路撒冷的人哪，你必不再哭泣！他必定恩待你，他聽了你哀求的聲音，就必回應你。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:27; 詩篇 80:5; 阿摩司書 8:11–12"> 主雖然給你吃艱難餅，喝困苦水，但主<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="主——輔助詞語。">e</a></sup>你的導師卻不再隱藏，你必親眼看見你的導師。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 32:8; 箴言 3:5–6; 以賽亞書 58:11"> 你或向左或向右，都必聽見後面有聲音說：「這是正路，要走在其上！」</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 17:3–4; 以賽亞書 31:7; 撒迦利亞書 13:2"> 你要羞辱<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="羞辱——原文直譯「玷汙」。">f</a></sup>你那些包銀的雕像和鍍金的鑄像，要拋棄它們如同拋棄汙穢之物，要對它們說：「給我出去！」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 8:11–12; 以賽亞書 32:20; 詩篇 65:9–13"> 主必賜下雨水給你播在地裡的種子，並要使地裡出肥美豐盛的糧食。到那日，你的牲畜將在寬闊的草場上吃草；</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 45:6; 申命記 25:4; 撒母耳記上 8:12"> 耕地的牛和驢將吃調過味的飼料，是用鏟和叉揚淨的。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 43:19–20; 以賽亞書 35:6–7; 以賽亞書 2:14–15"> 在大行殺戮的日子，在城樓倒塌的時候，一切崇山峻嶺都將有溪水湧流。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 60:19–20; 申命記 32:39; 啟示錄 22:5"> 在耶和華包紮他子民傷口的日子，在醫治他所擊打之創傷的時候，月光必像日光，日光必加增七倍，像七日的光一樣。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦後書 2:8; 那鴻書 1:5–6; 詩篇 18:7–9"> <span className="pl pl-1">看哪，有威名的耶和華</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有威名的耶和華——原文直譯「耶和華的名」。">g</a></sup><br /><span className="pl pl-1">從遠方而來！</span><br /><span className="pl pl-1">他的怒氣燃燒，濃煙上騰；</span><br /><span className="pl pl-1">他的嘴唇充滿憤怒，</span><br /><span className="pl pl-1">他的舌頭像吞噬的烈火；</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 37:29; 以賽亞書 11:4; 帖撒羅尼迦後書 2:8"> <span className="pl pl-1">他的氣息如漫溢的河水，直漲到頸項；</span><br /><span className="pl pl-1">他要用毀滅的篩把列國篩淨，</span><br /><span className="pl pl-1">又在眾民的臉頰套上使他們迷失的轡頭。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 42:4; 詩篇 95:1–2; 出埃及記 15:1–21"> <span className="pl pl-1">你們卻會歌唱，</span><br /><span className="pl pl-1">像守聖節的夜晚那樣；</span><br /><span className="pl pl-1">並會心裡喜樂，</span><br /><span className="pl pl-1">像人伴著笛聲行走，</span><br /><span className="pl pl-1">上耶和華的山，</span><br /><span className="pl pl-1">到以色列的磐石那裡。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 18:13–14; 約書亞記 10:11; 以賽亞書 29:6"> <span className="pl pl-1">耶和華必使人聽見他威嚴的聲音，</span><br /><span className="pl pl-1">又以猛烈的怒氣、吞噬的火焰、</span><br /><span className="pl pl-1">暴雨、狂風和石頭般的冰雹，</span><br /><span className="pl pl-1">使人看見他掄下來的膀臂。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 11:4; 以賽亞書 9:4; 彌迦書 5:5–6"> <span className="pl pl-1">亞述人必因耶和華的聲音而喪膽，</span><br /><span className="pl pl-1">耶和華必用杖責打他們；</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 11:15; 以賽亞書 19:16; 以賽亞書 2:19"> <span className="pl pl-1">耶和華施刑的杖</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施刑的杖——或譯作「命定的杖」。">h</a></sup><br /><span className="pl pl-1">每打他們一下，</span><br /><span className="pl pl-1">人都會搖鈴鼓、彈豎琴；</span><br /><span className="pl pl-1">打仗的時候，耶和華將揮臂與他們爭戰。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 23:10; 創世記 19:24; 耶利米書 19:6"> <span className="pl pl-1">原來，那焚燒場</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="那焚燒場——音譯作「陀斐特」。">i</a></sup><br /><span className="pl pl-1">早已安排好了，</span><br /><span className="pl pl-1">是為君王所預備的；</span><br /><span className="pl pl-1">它又深又寬，其中充滿了火和許多木柴；</span><br /><span className="pl pl-1">耶和華的氣息如同一股硫磺火使它燃燒起來。</span></span>

<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:48–50; 使徒行傳 17:24; 馬太福音 5:34–35"> 耶和華如此說：<br /><span className="pl pl-1">「天是我的寶座，</span><br /><span className="pl pl-1">地是我的腳凳。</span><br /><span className="pl pl-1">你們要為我建造的殿宇在哪裡呢？</span><br /><span className="pl pl-1">我安歇的地方在哪裡呢？」</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 57:15; 詩篇 34:18; 詩篇 51:17"> <span className="pl pl-1">耶和華宣告：</span><br /><span className="pl pl-1">「這一切是我手所造的，</span><br /><span className="pl pl-1">這一切就因此存在了。</span><br /><span className="pl pl-1">我要看顧這樣的人，</span><br /><span className="pl pl-1">就是謙卑、靈裡痛悔、</span><br /><span className="pl pl-1">因我的話語而戰兢的人。</span><br /></span>

<div className="bp poetry">

</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="約珥書 3:7–16; 阿摩司書 1:2; 以賽亞書 34:8"> <span className="pl pl-1">有喧嚷的聲音出自城內，</span><br /><span className="pl pl-1">有聲音出於殿中；</span><br /><span className="pl pl-1">那是耶和華正向他仇敵施行報應的聲音！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 12:1–5; 以賽亞書 54:1; 加拉太書 4:26"> <span className="pl pl-1">錫安沒有產痛就生產，</span><br /><span className="pl pl-1">陣痛還沒有臨到，她就生下一個男孩。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 64:4; 以賽亞書 49:20–22; 羅馬書 15:18–21"> <span className="pl pl-1">有誰聽過這樣的事？</span><br /><span className="pl pl-1">有誰見過這些事？</span><br /><span className="pl pl-1">國土能在一日之內就誕生嗎？</span><br /><span className="pl pl-1">國家能在一時之間就生出嗎？</span><br /><span className="pl pl-1">然而，錫安剛要有產痛，</span><br /><span className="pl pl-1">就生下了她的兒女！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 37:3; 創世記 18:14"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「我既然使她臨盆，</span><br /><span className="pl pl-1">難道不使她生產嗎？」</span><br /><span className="pl pl-1">你的神說：</span><br /><span className="pl pl-1">「我既然使她臨產，</span><br /><span className="pl pl-1">難道會閉塞她嗎？」</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 26:8; 申命記 32:43; 詩篇 137:6"> <span className="pl pl-1">所有愛耶路撒冷的人哪，</span><br /><span className="pl pl-1">你們要與她一同歡喜，</span><br /><span className="pl pl-1">要因她而快樂！</span><br /><span className="pl pl-1">所有為耶路撒冷悲慟的人哪，</span><br /><span className="pl pl-1">你們要與她一同歡欣喜樂，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 60:16; 約珥書 3:18; 以賽亞書 60:5"> <span className="pl pl-1">好使你們從她安慰的懷中吃奶而飽足，</span><br /><span className="pl pl-1">使你們從她飽滿的乳房吸乳而歡暢！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 48:18; 以賽亞書 60:16; 以賽亞書 45:14"> 因為耶和華如此說：<br /><span className="pl pl-1">「看哪！我必向她廣賜平安，如同江河；</span><br /><span className="pl pl-1">廣賜列國的榮耀，如同漫溢的河水。</span><br /><span className="pl pl-1">你們必吃奶，被抱在胯上，搖弄在膝上。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 1:4; 以賽亞書 51:3; 以賽亞書 40:1"> <span className="pl pl-1">母親怎樣安慰兒子，</span><br /><span className="pl pl-1">我也怎樣安慰你們；</span><br /><span className="pl pl-1">你們必在耶路撒冷受安慰。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 10:7; 以斯拉記 8:31; 以斯拉記 7:9"> <span className="pl pl-1">那時，你們看見了就心裡歡喜，</span><br /><span className="pl pl-1">你們的骨頭必像嫩草一樣興盛；</span><br /><span className="pl pl-1">耶和華的手必向他的僕人們顯明，</span><br /><span className="pl pl-1">他必對他的仇敵惱怒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:33; 帖撒羅尼迦後書 1:6–9; 彼得後書 3:10–12"> <span className="pl pl-1">看哪！耶和華必在烈火中臨到，</span><br /><span className="pl pl-1">他的戰車好像旋風，</span><br /><span className="pl pl-1">為要在怒火中施行他憤怒的報應，</span><br /><span className="pl pl-1">在火焰中發出他的斥責；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 38:21–22; 以賽亞書 30:30; 以西結書 39:2–10"> <span className="pl pl-1">因為耶和華必以烈火和他的刀劍審判一切有血肉的；</span><br /><span className="pl pl-1">那時被耶和華所殺的人會很多。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 65:3–4; 申命記 14:3–8; 以賽亞書 1:28–29"> 耶和華宣告：「那些自我分別為聖、自我潔淨去園林追隨他們中的一個<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他們中的一個——或譯作「園林中心的一個」。">a</a></sup>，去吃豬肉、可憎之物和老鼠的，都必一同被清除。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 86:9; 啟示錄 11:15; 哥林多後書 4:4–6"> 耶和華說：「我知道他們的作為和他們的意念。聚集各國和各語言群體的時候將到<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="聚集各國和各語言群體的時候將到——或譯作「我要來聚集各國和各語言群體」。">b</a></sup>！萬民<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="萬民——原文直譯「他們」。">c</a></sup>都必來看我的榮耀。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 52:15; 羅馬書 15:21; 以賽亞書 55:5"> 我要在萬民<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="萬民——原文直譯「他們」。">d</a></sup>中間設立一個標記，並派遣他們中的倖存者到列國，就是到塔爾施、普勒、拉弓的呂底亞、圖巴和雅完，以及那些未曾聽過我名聲、未曾見過我榮耀的遙遠海島；他們必在列國中宣揚我的榮耀。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 60:3–14; 以賽亞書 65:11; 以賽亞書 11:9"> 他們必從萬國，用馬匹、戰車、篷車、騾子、駱駝，把你們所有的兄弟都帶到我的聖山耶路撒冷，作為供物獻給耶和華，就像以色列子孫用潔淨的器皿把供物帶到耶和華的殿那樣。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:9; 出埃及記 19:6; 啟示錄 1:6"> 我也要從他們中挑選人作祭司，作利未人。」這是耶和華說的。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 65:17; 彼得後書 3:13; 啟示錄 21:1"> <span className="pl pl-1">耶和華宣告：</span><br /><span className="pl pl-1">「我所造的新天新地怎樣在我面前長存，</span><br /><span className="pl pl-1">你們的後裔和你們的名字也怎樣長存。」</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 46:1; 詩篇 86:9; 歌羅西書 2:16–17"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「那時，每逢新月節，每逢安息日，</span><br /><span className="pl pl-1">一切有血肉的都必來到我面前下拜。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="啟示錄 14:10–11; 以賽亞書 14:11; 帖撒羅尼迦前書 2:15–16"> 「他們會出去看那些悖逆我之人的屍體。要知道，吃那些人的蟲是不死的，燒那些人的火是不滅的；那些人必被一切有血肉的所憎惡。」</span>

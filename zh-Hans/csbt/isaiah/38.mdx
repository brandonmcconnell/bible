<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 38:1–8; 歷代志下 32:24; 列王紀下 20:1–11"> 在那些日子，希西加患病快要死了。亞摩斯的兒子先知以賽亞來到他那裡，對他說：「耶和華如此說：『你要安排好你的家事，因為你將要死，不能存活了。』」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:6; 詩篇 91:15; 列王紀上 8:30"> 希西加就轉臉對著牆，向耶和華禱告，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 5:7; 詩篇 18:20–27; 希伯來書 6:10"> 說：「哦，耶和華啊，求你記念我在你面前怎樣以誠實和完全的心行事，又做你眼中看為善的事！」然後，希西加就痛哭起來。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 那時，耶和華的話語臨到以賽亞，說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:5–6; 約翰一書 5:14–15; 啟示錄 7:17"> 「你去告訴希西加：『你先祖大衛的神耶和華如此說：我聽到了你的禱告，看見了你的眼淚。看哪！我必在你的壽數上增添十五年。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:35; 以賽亞書 31:4–5; 以賽亞書 12:6"> 我必解救你和這城脫離亞述王的手；我必保護這城。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:37–39; 以賽亞書 37:30; 以賽亞書 7:11–14"> 以下是我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——輔助詞語；本節下同。">a</a></sup>耶和華給你的徵兆來證明我耶和華必成就所說的這事：</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 20:9–11; 約書亞記 10:12–14; 馬太福音 16:1"> 看哪！我要使亞哈斯的日晷上前進的日影向後退十個刻度。』」於是日晷上前進的日影，果然向後退了十個刻度。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:1; 出埃及記 15:1–21; 約伯記 5:18"> 猶大王希西加患病痊癒後，寫了一首詩：</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:24; 哥林多後書 1:9; 詩篇 107:18"> <span className="pl pl-1">「我曾說：我如日中天就要進入陰間之門；</span><br /><span className="pl pl-1">我餘剩的歲月竟被剝奪！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:13; 詩篇 116:8–9; 詩篇 31:22"> <span className="pl pl-1">我曾說：我必不得見耶和華，</span><br /><span className="pl pl-1">必不得見在活人之地的耶和華！</span><br /><span className="pl pl-1">我再也不會見到世上居民中的任何人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 73:14; 哥林多後書 5:1; 希伯來書 1:12"> <span className="pl pl-1">我的住處好像牧人的帳篷，被拔出、挪走；</span><br /><span className="pl pl-1">我捲起我的性命，像織布的捲布那樣；</span><br /><span className="pl pl-1">他把我從織布機上剪斷，</span><br /><span className="pl pl-1">一日之間，他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他——原文直譯「你」。">b</a></sup><br /><span className="pl pl-1">使我喪命。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:8; 但以理書 6:24; 詩篇 50:22"> <span className="pl pl-1">我不斷呼救</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我不斷呼救——或譯作「我使自己平穩」。">c</a></sup><br /><span className="pl pl-1">，直到早晨；</span><br /><span className="pl pl-1">他像獅子折斷我所有的骨頭，</span><br /><span className="pl pl-1">一日之間，他</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——原文直譯「你」。">d</a></sup><br /><span className="pl pl-1">使我喪命。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 59:11; 詩篇 69:3; 詩篇 123:1–4"> <span className="pl pl-1">我像燕子呢喃，像白鶴啼叫，</span><br /><span className="pl pl-1">又像鴿子哀鳴。</span><br /><span className="pl pl-1">我的眼睛因仰望高處而衰弱；</span><br /><span className="pl pl-1">主啊！我受欺壓，</span><br /><span className="pl pl-1">求你作我的保障。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 21:27; 約伯記 7:11; 約伯記 10:1"> <span className="pl pl-1">我還能說什麼呢？</span><br /><span className="pl pl-1">他對我說過的，他已親自做了。</span><br /><span className="pl pl-1">我因心靈愁苦，</span><br /><span className="pl pl-1">要謹慎地</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="謹慎地——或譯作「慢慢地」。">e</a></sup><br /><span className="pl pl-1">度過我所有的年日。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 12:10–11; 哥林多前書 11:32; 詩篇 119:25"> <span className="pl pl-1">主啊！人存活靠著這些；</span><br /><span className="pl pl-1">我靈魂的生命也在所有這些之中。</span><br /><span className="pl pl-1">求你使我復原，使我存活。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 43:25; 彌迦書 7:18–19; 約拿書 2:6"> <span className="pl pl-1">看哪！我受盡苦痛，是對我有益的；</span><br /><span className="pl pl-1">是你在愛中保全我的靈魂脫離滅亡之坑，</span><br /><span className="pl pl-1">是你把我的一切罪都拋在你的背後。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 9:10; 詩篇 30:9; 詩篇 6:5"> <span className="pl pl-1">陰間不會稱頌你，死亡不會讚美你，</span><br /><span className="pl pl-1">下陰坑的人也不會盼望你的信實；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 詩篇 119:175; 詩篇 78:3–6"> <span className="pl pl-1">唯獨活人——活著的人才會稱頌你，像我今日這樣；</span><br /><span className="pl pl-1">作父親的才會使兒女認識你的信實。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 116:2; 詩篇 150:4; 詩篇 145:2"> <span className="pl pl-1">耶和華必拯救我；</span><br /><span className="pl pl-1">我們一生一世都要在耶和華的殿中，</span><br /><span className="pl pl-1">彈奏絲弦的樂器。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀下 20:7–8; 馬可福音 7:33; 約翰福音 9:6"> ——而此前，以賽亞曾說：「拿一塊無花果餅來，敷在瘡上，王就必痊癒！」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 118:18–19; 列王紀下 20:8; 約翰福音 5:14"> 希西加卻問：「有什麼徵兆來證明我會上耶和華的殿呢？」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:37; 列王紀下 16:1; 以賽亞書 1:1"> 烏西雅的孫子、約坦的兒子猶大王亞哈斯年間，亞蘭王利汛會同利瑪利的兒子以色列王比加上來攻打耶路撒冷，卻不能攻下。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 8:12; 以賽亞書 7:13; 以賽亞書 9:9"> 有人向大衛家報告說：「亞蘭已經與以法蓮結盟了。」王的心和他子民的心就搖動，好像林中的樹隨風搖動。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:17; 以賽亞書 36:2; 羅馬書 9:27"> 耶和華對以賽亞說：「現在你和你的兒子施亞·雅實布出去，在上池的溝渠盡頭，通往漂布場的大道上迎見亞哈斯，</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 35:4; 耶利米哀歌 3:26; 申命記 20:3"> 對他說：『你要謹慎，保持鎮靜，不要因亞蘭王利汛和利瑪利的兒子發烈怒而害怕，也不要因這兩個冒煙的火把殘頭而心裡膽怯。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 83:3–4; 撒迦利亞書 1:15; 詩篇 2:2"> 儘管亞蘭王和以法蓮王利瑪利的兒子策劃惡事要害你，說：</span>
<span className="v" id="v6" data-v="6"> 「讓我們上去攻擊猶大，恐嚇它，攻破它歸我們，並在其中立塔比勒的兒子為王」，</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 8:10; 耶利米哀歌 3:37; 以賽亞書 46:10–11"> 但主耶和華如此說：<br /><span className="pl pl-1">這事必立不住，也不會得逞，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 17:1–3; 創世記 14:15; 撒母耳記下 8:6"> <span className="pl pl-1">因為亞蘭之首不過是大馬士革，</span><br /><span className="pl pl-1">大馬士革之首不過是利汛；</span><br /><span className="pl pl-1">至於以法蓮，六十五年之內必被擊碎，</span><br /><span className="pl pl-1">不再成為一個民族；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 11:6; 羅馬書 11:20; 歷代志下 20:20"> <span className="pl pl-1">以法蓮之首不過是撒瑪利亞，</span><br /><span className="pl pl-1">撒瑪利亞之首不過是利瑪利的兒子。</span><br /><span className="pl pl-1">你們如果不相信，</span><br /><span className="pl pl-1">就一定不能堅立。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 8:5; 以賽亞書 1:5; 以賽亞書 10:20"> 耶和華又吩咐亞哈斯說：</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 37:30; 以賽亞書 38:7–8; 以賽亞書 38:22"> 「你為自己向你的神耶和華求一個徵兆吧——或往深求，深如陰間，或往高求，高如上天。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 33:31; 歷代志下 28:22; 瑪拉基書 3:15"> 但亞哈斯說：「我不求，我不試探耶和華。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 43:24; 以賽亞書 63:10; 以西結書 34:18"> 於是以賽亞說：「大衛家啊，你們要聽！難道你們使人厭倦還不夠，又要使我的神厭倦嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 1:23; 以賽亞書 9:6; 路加福音 1:31"> 因此主要親自給你們一個徵兆：看哪！必有童貞女懷孕，她要生一個兒子，並稱他的名為以馬內利。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 7:22; 阿摩司書 5:15; 馬太福音 3:4"> 到他懂得棄惡擇善的時候，他必吃乳酪與蜂蜜。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 8:4; 申命記 1:39; 以賽亞書 9:11"> 因為在這孩子知道棄惡擇善之前，你所憂心的那兩個王的土地必被遺棄。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 8:7–8; 以賽亞書 10:5–6; 歷代志下 28:19–21"> 耶和華必使亞述王攻擊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="攻擊——輔助詞語。">a</a></sup>的日子臨到你、你的子民和你的父家；這是自從以法蓮脫離猶大以來未曾有過的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 5:26; 約書亞記 24:12; 申命記 1:44"> <span className="pl pl-1">「到那日，</span><br /><span className="pl pl-1">耶和華必發出哨聲，</span><br /><span className="pl pl-1">召來埃及江河源頭的蒼蠅和亞述地的刺蜂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 2:19; 耶利米書 16:16; 以賽亞書 2:21"> <span className="pl pl-1">牠們全都會飛來，</span><br /><span className="pl pl-1">停落在深谷中、岩石縫裡、</span><br /><span className="pl pl-1">所有的荊棘叢中、所有的草場上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:7; 以西結書 29:18; 以賽亞書 10:15"> <span className="pl pl-1">「到那日，</span><br /><span className="pl pl-1">主必雇用幼發拉底河對岸的剃刀——亞述王，</span><br /><span className="pl pl-1">剃光你們的頭髮和腳毛，</span><br /><span className="pl pl-1">也刮掉你們的鬍鬚。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 5:17; 耶利米書 39:10; 以賽亞書 37:30"> <span className="pl pl-1">「到那日，</span><br /><span className="pl pl-1">一個人只能養活一頭小母牛和兩隻母羊。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 7:15; 馬太福音 3:4; 撒母耳記下 17:29"> <span className="pl pl-1">因為產的奶很多，他就以乳酪為食；</span><br /><span className="pl pl-1">這地上所有剩下的人都將以乳酪和蜂蜜為食。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 5:6; 雅歌 8:11–12; 馬太福音 21:33"> <span className="pl pl-1">「到那日，</span><br /><span className="pl pl-1">所有種過一千棵葡萄樹、</span><br /><span className="pl pl-1">值一千錠銀子的地方，</span><br /><span className="pl pl-1">都必成為荊棘和蒺藜之地。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 27:3"> <span className="pl pl-1">人到那裡去，就必帶弓和箭，</span><br /><span className="pl pl-1">因為遍地都是荊棘和蒺藜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 7:21–22; 以賽亞書 13:20–22; 以賽亞書 5:17"> <span className="pl pl-1">所有被鋤頭翻耕過的山地，</span><br /><span className="pl pl-1">你都不會上去，</span><br /><span className="pl pl-1">因為你懼怕荊棘和蒺藜；</span><br /><span className="pl pl-1">那裡必成為放牛之地、羊群踐踏之處。」</span></span>
</div>
</div>

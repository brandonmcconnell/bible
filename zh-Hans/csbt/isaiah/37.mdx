<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 19:1–37; 以斯拉記 9:5; 以賽亞書 36:22–38"> 希西加王聽了就撕裂衣服，披上麻布，進入耶和華的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:1; 列王紀下 18:18; 以賽亞書 36:3"> 他派遣宮廷總管以利亞敬、書記舍伯納和祭司中年長的，個個披上麻布，到亞摩斯的兒子先知以賽亞那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 66:9; 何西阿書 13:13; 以賽亞書 26:17–18"> 他們對他說：「希西加如此說：『今天是一個患難、責罰、恥辱的日子；因為嬰孩已經臨盆，我們卻沒有力氣生下來。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 1:9; 以賽亞書 36:20; 以賽亞書 10:22"> 將軍的主人亞述王派他來辱罵永生的神，或許你的神耶和華聽見了他的話，就會斥責所聽見的那些話。因此，求你為倖存的餘剩之民獻上禱告。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 當希西加王的臣僕來到以賽亞那裡時，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 7:4; 以賽亞書 35:4; 馬可福音 5:36"> 以賽亞對他們說：「你們要這樣告訴你們的主人：『耶和華如此說：你不要因為聽見亞述王的僕人們褻瀆我的話而害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 31:8–9; 歷代志下 32:21; 以賽亞書 33:10–12"> 看哪！我要把一個靈放入亞述王裡面，讓他一聽見傳來的風聲就返回本土；我必使他在那裡倒在刀下。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 10:29; 民數記 33:20–21; 列王紀下 19:8–9"> 將軍聽到亞述王已拔營離開拉吉，就撤退了，與正在攻打立拿的亞述王會合。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 18:1; 以賽亞書 20:5; 以賽亞書 37:7"> 亞述王聽到了有關庫實王特哈加出來要與自己爭戰的消息。他一聽到，就派遣使者們到希西加那裡，並吩咐使者們：</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 36:15; 列王紀下 18:5; 馬太福音 27:43"> 「你們要對猶大王希西加這樣說：『不要讓你所依靠的神欺哄你，說：耶路撒冷必不落入亞述王的手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 36:18–20; 列王紀下 18:33–35; 以賽亞書 14:17"> 看哪！你必定聽說過亞述列王向各國所行的，就是把它們滅絕淨盡；難道只有你能得解救嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:31; 列王紀下 17:6; 列王紀下 18:11"> 我祖先所毀滅的，有歌散、哈蘭和利色，還有在提拉撒的伊甸子孫，那些國的神明解救他們了嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 19:13; 列王紀下 17:24; 以賽亞書 36:19"> 哈馬的王、阿爾帕的王，拉伊爾、西法瓦音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拉伊爾、西法瓦音——傳統譯法作「西法瓦音城」。">a</a></sup>、希拿、伊瓦的眾王，如今都在哪裡呢？』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 19:14; 詩篇 123:1–4; 約珥書 2:17–20"> 希西加從使者們手裡接過書信，讀完了，就上耶和華的殿，在耶和華面前展開書信。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 7:8–9; 但以理書 9:3–4; 雅各書 5:13"> 希西加向耶和華禱告，說：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:22; 詩篇 99:1; 詩篇 86:10"> 「坐在基路伯之上的萬軍之耶和華，以色列的神哪！你——唯獨你是地上萬國的神，是你造了諸天和大地。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 6:40; 詩篇 17:6; 以賽亞書 37:4"> 耶和華啊，求你側耳聽！耶和華啊，求你睜眼看！聽聽西納基立派人來辱罵永生神的一切話！</span>
<span className="v" id="v18" data-v="18" data-xref="那鴻書 2:11–12; 列王紀下 15:29; 列王紀下 17:6"> 耶和華啊，亞述列王確實使各國和它們的國土荒廢，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 44:9–10; 耶利米書 10:11; 何西阿書 8:6"> 又把它們的神像扔進火中；那些神像之所以被滅絕，是因為它們不是神，只不過是人手所造的，是用木頭、石頭造的！</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:10; 列王紀上 18:36–37; 詩篇 83:17–18"> 耶和華我們的神哪，現在求你拯救我們脫離亞述王的手，使地上萬國都知道，你——唯獨你是耶和華<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你是耶和華——死海古卷作「耶和華是神」；參《列王紀下》19:19。">b</a></sup>！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 58:9; 以賽亞書 38:3–6; 使徒行傳 4:31"> 亞摩斯的兒子以賽亞就派人到希西加那裡，說：「以色列的神耶和華如此說：『你為亞述王西納基立的事向我禱告，因此，</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 16:4; 耶利米哀歌 2:13; 以賽亞書 1:8"> 以下是耶和華針對西納基立說的話：<br /><span className="pl pl-1">少女錫安藐視你、嘲笑你，</span><br /><span className="pl pl-1">女子耶路撒冷在你背後搖頭。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 39:7; 但以理書 5:20–23; 以賽亞書 17:7"> <span className="pl pl-1">你辱罵誰、褻瀆誰呢？</span><br /><span className="pl pl-1">你揚起聲音、高舉眼目是針對誰呢？</span><br /><span className="pl pl-1">是針對以色列的聖者！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 14:8; 以賽亞書 10:18; 出埃及記 15:9"> <span className="pl pl-1">你藉著你的臣僕辱罵主</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主——有古抄本作「耶和華」；馬索拉文本作「我主」；參《列王紀下》19:23。">c</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">你又說：我帶著眾多的戰車，</span><br /><span className="pl pl-1">上到群山的高峰和黎巴嫩的極深之處；</span><br /><span className="pl pl-1">我砍伐黎巴嫩最高的香柏樹和最好的松樹，</span><br /><span className="pl pl-1">來到它的極高之處和最茂密的森林；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:10; 以賽亞書 36:12; 列王紀下 19:23–24"> <span className="pl pl-1">我挖井喝了水</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="我挖井喝了水——死海古卷作「我挖井喝了外族人的水」。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">我的腳掌踏乾了埃及一切的河流。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 4:27–28; 使徒行傳 2:23; 彼得前書 2:8"> <span className="pl pl-1">我從遠古以來所立的，</span><br /><span className="pl pl-1">在太初的日子所定的，</span><br /><span className="pl pl-1">難道你沒有聽過嗎？</span><br /><span className="pl pl-1">現在我使它應驗了，</span><br /><span className="pl pl-1">就是讓你把堅固的城變為荒廢的石堆——</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 129:6; 詩篇 37:2; 彼得前書 1:24"> <span className="pl pl-1">那時城中的居民軟弱無力，驚惶羞愧，</span><br /><span className="pl pl-1">像田間蔬草、青綠嫩草，</span><br /><span className="pl pl-1">像被東風吹焦的屋頂上的草</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="像被東風吹焦的屋頂上的草——依據死海古卷；馬索拉文本作「像屋頂上的草、沒有長成的田園」。">e</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 2:13; 詩篇 139:1–11; 耶利米書 23:23–24"> <span className="pl pl-1">你或坐或出或入</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你或坐或出或入——死海古卷作「你起你坐，你出你入」。">f</a></sup><br /><span className="pl pl-1">，我都知道；</span><br /><span className="pl pl-1">我也知道你對我發怒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 38:4; 以賽亞書 30:28; 以賽亞書 37:34"> <span className="pl pl-1">因為你對我發怒，</span><br /><span className="pl pl-1">你的驕奢安逸上達我的耳中，</span><br /><span className="pl pl-1">所以我要把鉤子放進你的鼻孔，</span><br /><span className="pl pl-1">把嚼環放入你的嘴裡，</span><br /><span className="pl pl-1">我必使你從原路返回。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王紀下 19:29; 利未記 25:4–5; 列王紀上 13:3–5"> 「『希西加啊，以下是給你的徵兆：今年你們會吃自生的，第二年你們會吃自長的，而第三年你們將播種、收割，栽種葡萄園，吃園中的果實。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 27:6; 列王紀下 19:30–31; 詩篇 80:9"> 猶大家殘留的倖存者將再次往下扎根，向上結果；</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 9:7; 列王紀下 19:31; 以賽亞書 59:17"> 必有餘剩之民從耶路撒冷而出，必有倖存者從錫安山而來。萬軍之耶和華的熱心必成就這事。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 17:12; 以賽亞書 10:32–34; 以賽亞書 17:14"> 「因此，耶和華論到亞述王如此說：<br /><span className="pl pl-1">『他必不進入這城，</span><br /><span className="pl pl-1">也不在這裡射箭；</span><br /><span className="pl pl-1">他必不拿著盾牌兵臨城下，</span><br /><span className="pl pl-1">也不築起土壘攻城；</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 37:29; 箴言 21:30"> <span className="pl pl-1">他必從原路返回，</span><br /><span className="pl pl-1">也不進入這城。</span><br /><span className="pl pl-1">這是耶和華的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="列王紀下 20:6; 以賽亞書 38:6; 以賽亞書 31:5"> <span className="pl pl-1">我必為自己的緣故和我僕人大衛的緣故，</span><br /><span className="pl pl-1">保護拯救這城。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 10:12; 列王紀下 19:35; 以賽亞書 10:33–34"> 於是耶和華的使者出去，在亞述的營中擊殺了十八萬五千人；清早人們起來，看哪，所見的都是死屍！</span>
<span className="v" id="v37" data-v="37" data-xref="約拿書 1:2; 約拿書 3:3; 創世記 10:11–12"> 亞述王西納基立就拔營回去，住在尼尼微。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 8:4; 耶利米書 51:27; 以斯拉記 4:2"> 有一天，西納基立在自己的神尼斯洛的廟裡下拜，他的兒子亞得米勒和沙利色用刀殺了他，然後逃到亞拉臘地。他的兒子以撒哈頓接替他作王。</span>
</div>

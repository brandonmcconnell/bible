</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿書 1:3–9; 士師記 4:4; 以賽亞書 7:13–14"> 後來我與女先知<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="女先知——就是以賽亞的妻子。">c</a></sup>親近，她就懷孕，生了一個兒子。耶和華對我說：「你要給他起名為瑪黑珥·薩拉勒·哈施·罷斯，</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:11; 列王紀下 16:9; 申命記 1:39"> 因為在這孩子知道叫爸爸媽媽之前，大馬士革的財富和撒瑪利亞的掠物都要被搬到亞述王面前。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 7:10"> 耶和華又告訴我說：</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 9:7; 尼希米記 3:15; 以賽亞書 7:6"> <span className="pl pl-1">「因為這子民厭棄西羅亞緩慢的流水，</span><br /><span className="pl pl-1">卻喜悅利汛和利瑪利的兒子；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 17:12–13; 創世記 6:17; 以賽亞書 7:17"> <span className="pl pl-1">因此，看哪，主必使幼發拉底河強盛的大水，</span><br /><span className="pl pl-1">就是亞述王和他所有的威勢，</span><br /><span className="pl pl-1">上漲淹沒他們，</span><br /><span className="pl pl-1">又上漲淹沒一切水道，</span><br /><span className="pl pl-1">漫過所有的河岸；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 7:14; 以賽亞書 30:28; 馬太福音 1:23"> <span className="pl pl-1">然後湧入猶大，</span><br /><span className="pl pl-1">漫溢氾濫，高達頸項！</span><br /><span className="pl pl-1">他展開的翅膀，遍滿你廣闊的土地，</span><br /><span className="pl pl-1">以馬內利啊！</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他展開的翅膀，遍滿你廣闊的土地，以馬內利啊！——或譯作「但神與我們同在，他展開的翅膀，遍滿你廣闊的土地。」">d</a></sup><br /><span className="pl pl-1">」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 14:5–6; 箴言 11:21; 詩篇 37:14–15"> <span className="pl pl-1">萬民哪，你們必被打破</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你們必被打破——或譯作「你們聯合吧」。">e</a></sup><br /><span className="pl pl-1">，必被擊碎！</span><br /><span className="pl pl-1">遠方的眾人哪，當傾聽！</span><br /><span className="pl pl-1">你們束腰吧，必定被擊碎；</span><br /><span className="pl pl-1">你們束腰吧，必定被擊碎！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:37; 羅馬書 8:31; 約伯記 5:12"> <span className="pl pl-1">你們謀劃吧，必定遭挫敗；</span><br /><span className="pl pl-1">你們下令吧，必定不成立！</span><br /><span className="pl pl-1">因為神與我們同在。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西結書 3:14; 箴言 1:15; 耶利米書 15:19"> 耶和華把大能的手放在我身上對我說話<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="耶和華把大能的手放在我身上對我說話——原文直譯「耶和華以大能的手對我說話」。">f</a></sup>，警誡我不要走這子民所走的路；他如此說：</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:14–15; 路加福音 21:9; 詩篇 53:5"> <span className="pl pl-1">「凡這子民所稱為陰謀的，</span><br /><span className="pl pl-1">你們不要稱為陰謀；</span><br /><span className="pl pl-1">他們所怕的，</span><br /><span className="pl pl-1">你們不要害怕，也不要畏懼。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:5; 以賽亞書 26:3–4; 啟示錄 15:4"> <span className="pl pl-1">萬軍之耶和華是你們要尊為聖的，</span><br /><span className="pl pl-1">他才是你們要怕的，也是你們要畏懼的。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 2:8; 羅馬書 9:32–33; 以賽亞書 28:16"> <span className="pl pl-1">他必作聖所，</span><br /><span className="pl pl-1">而向以色列兩家卻作絆腳石和絆倒人的磐石，</span><br /><span className="pl pl-1">向耶路撒冷的居民作網羅和陷阱。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 21:44; 路加福音 20:17–18; 以賽亞書 28:13"> <span className="pl pl-1">許多人將在石頭上絆跌、</span><br /><span className="pl pl-1">仆倒、破碎，</span><br /><span className="pl pl-1">陷入圈套被纏住。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="但以理書 12:4; 希伯來書 3:5; 馬可福音 4:10–11"> <span className="pl pl-1">你要收起</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="收起——原文直譯「綁起」。">g</a></sup><br /><span className="pl pl-1">誡命，</span><br /><span className="pl pl-1">在我的門徒中封住訓誨。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:36–39; 哈巴谷書 2:3; 耶利米哀歌 3:25–26"> <span className="pl pl-1">我要等候向雅各家掩面的耶和華，</span><br /><span className="pl pl-1">我要仰望他！</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯來書 2:13–14; 路加福音 2:34; 撒迦利亞書 8:3"> 看哪！我與耶和華所賜給我的孩子們成了以色列中的徵兆和預表——這出於住錫安山的萬軍之耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 10:13; 利未記 20:6; 歷代志下 33:6"> 儘管有人對你們說：「求問那些喃喃自語、念念有詞的招魂者和通靈者吧」，但百姓難道不應當求問自己的神嗎？難道應當為活人求問死人嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="彼得後書 1:19; 提摩太後書 3:15–17; 以賽亞書 30:8–11"> 當求問神的<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神的——輔助詞語。">h</a></sup>訓誨和誡命！如果他們不按照這準則說話，他們就沒有曙光。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 9:20; 箴言 19:3; 耶利米哀歌 4:4–5"> 他們必經過這地，遭困苦，受飢餓。他們飢餓的時候就發怒，仰面朝天，詛咒自己的君王和自己的神；</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 5:30; 馬太福音 22:13; 耶利米書 13:16"> 他們向大地觀看，看哪，盡是患難、黑暗、幽暗痛苦！他們必被趕入漆黑之中！</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 7:8; 哥林多前書 7:26–27; 哥林多前書 7:37–38"> 關於你們所寫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「給我」。">a</a></sup>的事，你們說<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你們說——輔助詞語。">b</a></sup>「男人不碰女人是好事<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="男人不碰女人是好事——或譯作「男人不結婚就好」。">c</a></sup>」；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 5:28; 以弗所書 5:33; 哥林多前書 7:9"> 不過為了避免<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="避免——輔助詞語。">d</a></sup>淫亂的事，每個男人都應當有自己的妻子，每個女人也應當有自己的丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 3:7; 出埃及記 21:10"> 丈夫對妻子應當盡自己的本分，妻子對丈夫也應當如此。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 3:3; 馬太福音 19:9; 馬可福音 10:11–12"> 妻子對自己的身體沒有主權，這主權在丈夫；同樣，丈夫對自己的身體也沒有主權，這主權在妻子。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 19:15; 約珥書 2:16; 撒迦利亞書 12:12–14"> 夫妻同房<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="同房——輔助詞語。">e</a></sup>不可拒絕對方，除非為了有一段時間專心<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「禁食、」。">f</a></sup>禱告；然後仍要在一起，免得撒旦趁著你們不能自制而試探你們。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 8:8; 哥林多前書 7:25; 哥林多前書 7:12"> 不過我說這話是出於容忍，而不是出於命令。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 19:11–12; 羅馬書 12:6; 哥林多前書 9:5"> 我希望所有的人也都像我一樣，但是每個人自己都有從神而來的恩賜：有人是這樣，有人是那樣。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 7:32; 哥林多前書 7:34–35; 哥林多前書 7:26–27"> 我對沒有結婚的人和寡婦說，如果他們能像我一樣保持現狀，對他們來說是好事。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 7:2; 提摩太前書 5:14; 提摩太前書 5:11"> 但如果他們不能自制，就應該結婚，因為結婚總比心如火燒更好。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 5:32; 路加福音 16:18; 馬太福音 19:3–9"> 至於對那些已經結婚的人，我吩咐——其實不是我，而是主吩咐：妻子不可離開丈夫；</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:1; 哥林多前書 7:10; 以賽亞書 50:1"> 但如果還是離開了，就應當守身不嫁，或者與丈夫和好。丈夫也不可離棄妻子。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 11:17; 哥林多前書 7:6; 哥林多前書 7:25"> 對其餘的人，我說——不是主說：如果某個弟兄有不信的妻子，而妻子情願與他一起生活，他就不可離棄妻子；</span>
<span className="v" id="v13" data-v="13"> 同樣，如果妻子有不信的丈夫，而丈夫情願與她一起生活，她也不可離棄丈夫<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="丈夫——有古抄本作「他」。">g</a></sup>，</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 2:15–16; 提摩太前書 4:5; 提多書 1:15"> 因為那不信的丈夫因著妻子就得以聖潔了；而那不信的妻子也因著丈夫得以聖潔了；否則，你們的兒女就是不潔淨的；但如今他們是聖潔的。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 14:19; 哥林多後書 13:11; 雅各書 3:17–18"> 可是如果那不信的一方要離開，就讓他離開吧。在這樣的事上，那弟兄或姐妹就不受束縛了。不過神召喚了我們<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="我們——有古抄本作「你們」。">h</a></sup>，是要我們和睦。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:1–2; 哥林多前書 9:22; 羅馬書 11:14"> 做妻子的啊，你到底怎麼知道將來是否救你的丈夫呢？做丈夫的啊，你怎麼知道將來是否救你的妻子呢？</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 4:17; 羅馬書 12:3–8; 哥林多前書 7:24"> 只是當照著主<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主——有古抄本作「神」。">i</a></sup>所分給每個人的，以及神<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神——有古抄本作「主」。">j</a></sup>所召喚每個人的去行事。我在各教會中也是這樣吩咐的。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 15:5; 使徒行傳 15:28; 使徒行傳 15:24"> 如果一個人蒙召的時候已經受了割禮<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一個……已經受了割禮——指「猶太人」。">k</a></sup>，就不應該取消割禮的記號；如果一個人蒙召的時候沒有受割禮<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="一個……沒有受割禮——指「外邦人」。">l</a></sup>，就不應該受割禮。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 6:15; 加拉太書 5:6; 約翰一書 2:3–4"> 受割禮不重要，不受割禮也不重要，重要的是遵守神的命令。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 7:17; 帖撒羅尼迦前書 4:11; 帖撒羅尼迦後書 3:12"> 每個人在蒙了召喚的時候怎樣，他就應當保持怎樣。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:18–24; 歌羅西書 3:11; 路加福音 10:40–41"> 你蒙召的時候是做奴僕的嗎？你不要介意。但如果你真的能成為自由人，還是要把握機會。<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="但如果你真的能成為自由人，還是要把握機會。——或譯作「但是即使你有機會成為自由人，也要寧願充分發揮你作為奴僕的作用。」">m</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:16; 腓利門書 1:16; 歌羅西書 3:22–24"> 要知道，做奴僕時在主裡蒙召的，就是主的自由人；同樣，做自由人時蒙召的，就是基督的奴僕。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 6:20; 彼得前書 1:18–19; 提多書 2:14"> 你們是被重價贖回來的，不要成為人的奴僕。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 7:20; 歌羅西書 3:23–24; 哥林多前書 7:17"> 弟兄們，你們每個人蒙召的時候怎樣，在神面前就應當保持怎樣。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 7:6; 哥林多前書 4:2; 哥林多前書 7:40"> 關於童貞的女子，我沒有從主而來的命令，但是我既然蒙主的憐憫成為忠心的人，我就提供意見。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前書 7:1; 哥林多前書 7:8; 彼得前書 4:17"> 實際上，由於現今的艱難，我認為一個人保持現狀是合宜的，這才是好的。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 7:20; 哥林多前書 7:12–14"> 你已經有妻子約束著，就不要尋求擺脫；你沒有妻子束縛著<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="沒有妻子束縛著——原文直譯「被妻子釋放」。">n</a></sup>，就不要尋求妻子。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 13:4; 哥林多前書 7:32–36; 哥林多前書 7:26"> 不過你如果還是要結婚，並不是犯罪；童貞女子如果結婚，也不是犯罪。不過這樣的人在今生<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="今生——原文直譯「肉體上」。">o</a></sup>將要受患難，而我顧惜你們。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰一書 2:17; 哥林多前書 7:31; 羅馬書 13:11–12"> 弟兄們，我要說這一點：時候不多了<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="不多了——原文直譯「減少了」。">p</a></sup>！從此有妻子的，要像沒有妻子的；</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哭泣的，要像沒有哭泣的；快樂的，要像沒有快樂的；買了東西的，要像沒有什麼的；</span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 2:17; 彼得前書 4:7; 雅各書 4:14"> 利用世界的，要像沒有充分利用世界的；因為這世界的形態正在消逝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 6:25–34; 提摩太前書 5:5; 腓立比書 4:6"> 我希望你們一無掛慮。沒有結婚的男人所掛慮的是主的事，是要怎樣討主的喜悅；</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 3:7; 歌羅西書 3:19; 以弗所書 5:25–33"> 而結了婚的男人所掛慮的是世界的事，是要怎樣討妻子的喜悅，</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前書 6:20; 路加福音 2:36–37"> 這樣他就分心了。未婚女子和童貞女子掛慮主的事，以致身體和心靈都得以聖潔；而結了婚的婦女掛慮世界的事，是要怎樣討丈夫的喜悅。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前書 7:33–34; 哥林多前書 7:36; 路加福音 8:14"> 我說這話是為了你們自己的益處，不是要給你們套上牢籠，而是要你們行事合宜，毫無分心地殷勤服事主。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哥林多前書 7:37; 哥林多前書 7:9; 撒母耳記上 2:33"> 但如果有人認為他對待自己的童貞女兒不合宜，而且女兒也過了花期，事情又該如此行，就當按著自己所願的去做——他並不是犯罪，應當讓兩個人結婚。</span>
<span className="v" id="v37" data-v="37"> 但如果一個人自己心裡堅定不移，也不出於勉強，又對自己的意願有主權，並且自己心裡已經決定留下自己的童貞女兒，那麼他就做得好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 13:4; 哥林多前書 7:1–2; 哥林多前書 7:8"> 所以，那讓自己的童貞女兒結婚的，做得好；那沒有讓她結婚的，做得更好。<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="-38 或譯作「如果有人認為他對待自己的未婚妻不合宜，而且她也過了花期，事情又該如此行，就當按著自己所願的去做——他並不是犯罪，他們應當結婚。但如果一個人自己心裡堅定不移，也不出於勉強，又能控制自己的意志，並且心裡已經決定留下自己的未婚妻，那麼他就做得好。所以，那與自己的未婚妻結婚的，做得好；那不結婚的，做得更好。」或「如果有人認為自己守童身不合宜，而且他的意願超過了極限，事情又該如此行，就當按著自己所願的去做——他並不是犯罪，他們應當結婚。但如果一個人自己心裡堅定不移，也不出於勉強，又能控制自己的意志，並且心裡已經決定保持自己的童身，那麼他就做得好。所以，那結婚的，做得好；那不結婚的，做得更好。」">q</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="羅馬書 7:2–3; 哥林多後書 6:14–16; 哥林多前書 7:10"> 丈夫活著的時候，妻子是受約束的<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="妻子是受約束的——有古抄本作「妻子是被律法約束的」。">r</a></sup>；丈夫如果死了<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="死了——原文直譯「睡了」。">s</a></sup>，妻子就可以自由地嫁給她所願意的人，只是要嫁給主裡的人。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前書 7:35; 彼得後書 3:15–16; 哥林多前書 7:8"> 但是照我的意見，如果她能保持現狀，就更蒙福了。我想我也有神的靈。</span>
</div>

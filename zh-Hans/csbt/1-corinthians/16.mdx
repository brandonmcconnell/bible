<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 12:13; 哥林多後書 8:1–9; 哥林多後書 9:12–15"> 關於為聖徒收集的事，我從前怎樣吩咐加拉太的各教會，你們也當照樣做：</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 3:9–10; 申命記 15:11–14; 申命記 8:18"> 每週的頭一天，你們每個人如果充裕，就應當從中拿出一些積蓄起來，免得我來的時候才開始收集。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:6; 哥林多前書 11:34; 哥林多前書 4:19–21"> 等我來了，我會派你們所認可的那些人，帶著書信，把你們的惠贈送到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 8:4; 哥林多後書 8:19; 羅馬書 15:25"> 但如果我也該去，他們就要與我一同去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 19:21; 哥林多前書 4:19; 哥林多後書 1:15–17"> 我經過馬其頓省以後，就會到你們那裡去——因為我要經過馬其頓省——</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 15:3; 羅馬書 15:24; 使徒行傳 20:38"> 我也許會在你們那裡停留一些時候，甚至過冬。這樣，無論我往哪裡去，你們都可以送我上路。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 18:21; 哥林多前書 4:19; 雅各書 4:15"> 實際上，我現在並不願意在趕路的時候見你們；主如果准許，我希望在你們那裡住一段時間。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:1; 出埃及記 23:16; 使徒行傳 18:19"> 只是我會留在以弗所，一直到五旬節。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 2:12; 使徒行傳 14:27; 歌羅西書 4:3"> 原來，為了有功效的工作<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="工作——輔助詞語。">a</a></sup>，一個大門向我敞開了，不過反對的人也很多。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 15:58; 帖撒羅尼迦前書 3:2; 羅馬書 16:21"> 如果提摩太來了，你們要關心，好讓他在你們那裡無所懼怕，因為他和我一樣在做主的工作。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 4:12; 使徒行傳 15:33; 提多書 2:15"> 所以任何人都不要藐視他。你們要送他平平安安地上路，好讓他到我這裡來，因為我在等候他與弟兄們一起來<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我在等候他與弟兄們一起來——或譯作「我與弟兄們一起等候他來」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 1:12; 哥林多前書 3:5; 提多書 3:4"> 至於阿波羅弟兄，我曾多次勸他要與弟兄們一起到你們那裡去，只是他目前實在不願意去；但有機會的時候，他會去的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 1:9; 以弗所書 6:13–18; 以弗所書 6:10"> 你們要警醒，在信仰上當站立得穩，要做大丈夫，要堅強；</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 13:34–35; 彼得前書 4:8; 提摩太前書 1:5"> 你們所做的一切，都要在愛中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 1:16; 羅馬書 16:5; 羅馬書 16:2"> 弟兄們，你們知道司提法納一家人是亞該亞初熟的果子，而且他們獻上了自己去服事聖徒們。我勸你們，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 13:17; 帖撒羅尼迦前書 5:12; 約翰三書 1:8"> 要服從這樣的人，以及所有和他們一同工作、一同勞苦的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 11:9; 腓立比書 2:30; 腓利門書 1:13"> 我為司提法納、福特納托和阿卡伊庫的到來感到歡喜，因為他們彌補了你們的空缺<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="空缺——或譯作「不足」。">c</a></sup>；</span>
<span className="v" id="v18" data-v="18" data-xref="腓利門書 1:7; 哥林多後書 7:13; 帖撒羅尼迦前書 5:12"> 他們使我和你們的心靈得到安寧，因此你們要認可這樣的人。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 18:2; 腓利門書 1:2; 羅馬書 16:3–5"> 亞細亞省的各教會問候你們。阿奎拉和普茜拉，以及他們家裡的教會，在主裡熱誠地問候你們。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 16:16; 帖撒羅尼迦前書 5:26; 彼得前書 5:14"> 所有的弟兄都問候你們。你們要用聖潔的親吻禮彼此問候。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歌羅西書 4:18; 加拉太書 6:11; 帖撒羅尼迦後書 3:17"> 我保羅親筆問候。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 6:24; 約翰福音 14:21; 哥林多後書 5:14–15"> 如果有人不愛主<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="主——有古抄本作「主耶穌基督」。">d</a></sup>，他就該受詛咒。願主快來！</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 16:20; 羅馬書 16:23"> 願主耶穌<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="耶穌——有古抄本作「耶穌基督」。">e</a></sup>的恩典與你們同在！</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 14:16; 啟示錄 3:19; 哥林多後書 12:15"> 願我的愛在基督耶穌裡與你們大家同在！<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「阿們。」">f</a></sup></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:17; 提摩太前書 2:7; 哥林多前書 9:19"> 我不是自由的嗎？我不是使徒嗎？我不是看到我們的主耶穌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶穌——有古抄本作「耶穌基督」。">a</a></sup>嗎？你們不是我在主裡的工作嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 12:12; 約翰福音 6:27; 哥林多後書 3:1–3"> 即使我對別人不是使徒，但至少對你們還是使徒，因為你們是我在主裡做使徒的印證。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 12:16–19; 哥林多後書 13:3; 哥林多後書 13:10"> 對那些評斷我的人，我的辯護是這樣的：</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:6; 帖撒羅尼迦後書 3:8–9; 路加福音 10:7"> 難道我們沒有權利吃喝嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:42; 希伯來書 13:4; 馬太福音 8:14"> 難道我們沒有權利像其他的使徒，像主的弟弟們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="弟弟們——原文直譯「兄弟們」。">b</a></sup>，像磯法那樣，也帶著信主的妻子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信主的妻子——原文直譯「姐妹妻子」。">c</a></sup>一同往來嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:7–9; 使徒行傳 13:1–2; 使徒行傳 4:36"> 難道只有我和巴拿巴沒有不做工的權利嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命記 20:6; 提摩太後書 2:3–4"> 曾經有誰當兵自備糧餉呢？有誰栽種葡萄園不吃園中的果子呢？有誰牧養羊群不喝羊群的奶呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:20; 帖撒羅尼迦前書 4:8; 羅馬書 3:31"> 我說這些話，難道是按人的意思嗎？律法不也是說這些話嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:4; 提摩太前書 5:18; 詩篇 104:27"> 事實上，摩西的律法上記著：「牛踹穀的時候，不可籠住牠的嘴。」難道神顧念的是牛嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太後書 2:6; 羅馬書 15:4; 羅馬書 4:23–24"> 還是特別為我們說的呢？這樣寫下來，當然是為我們的緣故！因為耕田的應該懷著希望去耕田，打場的應該懷著一同分享糧食<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="糧食——輔助詞語。">d</a></sup>的希望去打場。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 15:27; 加拉太書 6:6; 哥林多後書 11:15"> 既然我們為你們播下了屬靈的種子，那麼，如果我們從你們收取物質上的東西<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="物質上的東西——原文直譯「屬肉體的事」。">e</a></sup>，這算過份嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:15; 哥林多前書 9:18; 哥林多後書 11:12"> 如果別人能從你們那裡分享這權利，我們不是更能分享嗎？<br />然而，我們並沒有用過這權利，反而凡事包容，免得給基督的福音帶來阻礙。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 18:8–20; 民數記 5:9–10; 利未記 6:26"> 難道你們不知道，在聖殿供職的人，都吃聖殿中的食物；侍候祭壇的人，都一同享用祭壇上的供物嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:10; 提摩太前書 5:17–18; 哥林多前書 9:4"> 照樣，主也吩咐那些傳福音的人，靠福音生活。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:9; 帖撒羅尼迦後書 3:8; 哥林多前書 9:12"> 但是，這些權利我一個也沒有用過。我寫這些並不是要人這樣對待我，因為我寧願死，也不願意任何人使我所誇耀的落了空。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 1:14; 耶利米書 20:9; 歌羅西書 4:17"> 原來，就算我傳福音，也沒有可誇耀的，因為傳福音的需要催逼著我；我如果不傳福音，我就有禍了；</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 2:7; 哥林多前書 3:8; 歷代志上 28:9"> 如果我自願做這事，就有報償；如果我不自願，這任務<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="任務——或譯作「管家的任務」。">f</a></sup>也已經委託給我了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 11:7–9; 哥林多前書 8:9; 帖撒羅尼迦前書 2:6"> 那麼，我的報償到底是什麼呢？就是：我傳福音的時候，能免費地提供福音<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="福音——有古抄本作「基督的福音」。">g</a></sup>，好使我不會充分利用在福音工作上屬自己的權利。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太書 5:13; 馬太福音 18:15; 雅各書 5:19–20"> 我誠然是自由的，不屬於任何人，但我使自己成為所有人的奴僕，為了贏得更多的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 16:3; 加拉太書 5:18; 使徒行傳 21:20–26"> 對猶太人，我就成為一個像猶太人那樣的人，為了贏得猶太人；對律法之下的人，雖然我自己不在律法之下，<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「雖然我自己不在律法之下，」。">h</a></sup>我卻成為一個像是在律法之下的人，為了贏得在律法之下的人；</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 2:12; 羅馬書 2:14; 加拉太書 3:2"> 對沒有律法的人，我就成為一個像是沒有律法的人那樣，為了贏得沒有律法的人——對神，我不是沒有律法的，而是在基督的律法之下。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 10:33; 羅馬書 15:1; 哥林多前書 9:19"> 對軟弱的人，我就成為軟弱的人，為了贏得軟弱的人。對什麼樣的人，我就成為什麼樣的人，一定要拯救一些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太後書 2:10; 馬可福音 8:35; 哥林多前書 9:25–27"> 並且我做這一切，都是為了福音的緣故，好使我能成為在福音上一同有份的人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="腓立比書 3:14; 希伯來書 12:1; 提摩太後書 4:7–8"> 難道你們不知道，賽場上奔跑的人雖然都在跑，但是得獎的只有一個嗎？你們也應當這樣奔跑，好使你們得著獎賞。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 2:5; 啟示錄 2:10; 提摩太後書 4:7–8"> 每一個參加比賽的人，都要在一切事上自制；不過他們這樣做是為了得到會朽壞的冠冕，而我們是為了得到不會朽壞的冠冕。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得後書 1:10; 腓立比書 1:21; 提摩太後書 2:5"> 因此，我奔跑不像沒有目標的；我鬥拳不像打空氣的；</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 8:13; 哥林多前書 9:25; 歌羅西書 3:5"> 然而我不斷克制<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="克制——原文直譯「痛打」。">i</a></sup>自己的身體，使它服從我，免得我傳道給別人，自己反而經不起考驗了。</span>
</div>

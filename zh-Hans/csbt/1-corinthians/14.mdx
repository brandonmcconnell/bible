<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 14:39; 提摩太前書 4:14; 哥林多前書 12:1"> 你們要追求愛，也要渴慕屬靈的事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="屬靈的事——或譯作「屬靈的恩賜」。">a</a></sup>，但更要渴慕做先知傳道<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="做先知傳道——原文直譯「說預言」。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:17; 使徒行傳 19:6; 使徒行傳 10:46"> 原來那說殊言<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="殊言——原文直譯「舌頭」；傳統譯法作「方言」。">c</a></sup>的，不是對人說，而是對神說，因為沒有人聽得懂；他是在靈裡講說各樣的奧祕。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 14:12; 提摩太前書 4:13; 猶大書 1:20"> 可是那做先知傳道的是對人說，為要造就、鼓勵和安慰人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 14:22; 哥林多前書 14:26; 馬可福音 16:17"> 那說殊言的是造就自己，但那做先知傳道的是造就教會。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:28–30; 哥林多前書 12:10; 馬可福音 16:17"> 我雖然希望你們都說殊言，但更希望你們都做先知傳道。因為，除非說殊言的能把殊言翻譯出來使教會得到造就，否則那做先知傳道的就比說殊言的更大了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所書 1:17; 羅馬書 6:17; 提摩太後書 3:16"> 所以弟兄們，就算我現在到你們那裡去，用殊言說話，但如果不用啟示、知識、預言<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="預言——或譯作「先知傳道」。">d</a></sup>、或教導來對你們說話，那麼我對你們有什麼益處呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 14:8; 路加福音 7:32; 哥林多前書 13:1"> 甚至是那些沒有生命卻能發出聲音的東西，例如笛子或豎琴，如果發出的音調沒有分別，怎麼能使人知道所吹所彈的是什麼呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 10:9; 以西結書 33:3–6; 耶利米書 4:19"> 實際上，如果號角發出的聲音真的不清楚，誰會準備好出戰呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 9:26"> 照樣，如果你們用舌頭說出不可理解的話，那麼所說的怎麼能使人明白呢？這樣，你們就是向空氣說話了。</span>
<span className="v" id="v10" data-v="10"> 世界上也許有好多種語言，但沒有一種是沒有意思的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:2; 羅馬書 1:14; 歌羅西書 3:11"> 所以，如果我不明白那語言的意思，那麼，對於說話的人，我就是個外族人；對於我，那說話的人也是個外族人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 14:26; 哥林多前書 14:3–4; 哥林多前書 14:1"> 你們也是這樣：既然你們對屬靈的事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="屬靈的事——或譯作「屬靈的恩賜」。">e</a></sup>是熱心人，就應當追求造就教會的事，好讓你們能豐足有餘。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 11:24; 哥林多前書 12:30; 約翰福音 14:13–14"> 所以，說殊言的人應當禱告，好讓自己能翻譯出來。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 14:2; 哥林多前書 14:15–16; 哥林多前書 14:19"> 如果我用殊言禱告，是我的靈在禱告，但我的理性卻是結不出果子的。</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 3:16; 約翰福音 4:23–24; 以弗所書 6:18"> 那麼該怎麼辦呢？我要用靈禱告，也要用理性禱告；我要用靈歌頌，也要用理性歌頌。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 16:36; 詩篇 106:48; 啟示錄 5:14"> 否則，如果你用靈祝謝，在場的那些不明白的人，既然不知道你在說什麼，怎麼能在你感謝的時候說「阿們」呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 14:4; 哥林多前書 14:6"> 因為你感謝的固然是好，但別人卻沒有得造就。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:4–6; 哥林多前書 4:7"> 我感謝神，我說殊言比你們所有人都多；</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 14:21–22; 哥林多前書 14:4"> 但是在教會裡，為了要教導別人，我寧願用我的理性說五句話，也不願用殊言說萬句話。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:2; 哥林多前書 13:11; 羅馬書 16:19"> 弟兄們，你們在思想上不要做小孩子，但是在惡事上要做嬰孩，在思想上要做成熟的人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="成熟的人——或譯作「完全的人」。">f</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 28:11–12; 耶利米書 5:15; 申命記 28:49"> 律法書上記著：「主說：<br /><span className="pl pl-1">『我要藉著說別種語言的人，</span><br /><span className="pl pl-1">藉著別人的嘴唇對這子民說話。</span><br /><span className="pl pl-1">即使這樣，他們也不會聽我的。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 2:6–12; 馬可福音 16:17; 哥林多前書 14:1"> 這樣，說殊言不是給信的人做為標記，而是給不信的人；但做先知傳道<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="做先知傳道——原文直譯「說預言」。">g</a></sup>不是給不信的人做為標記，而是給信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 2:13; 使徒行傳 26:24; 哥林多前書 11:18"> 所以，如果全教會聚集在一起，大家都說殊言，有不明白殊言的，或不信的人進來，他們難道不會說你們都瘋了嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 2:37; 哥林多前書 2:15; 希伯來書 4:12–13"> 但如果大家都做先知傳道，有一個不信的或不明白的人進來，他就會因這一切而知罪、受到責問，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 45:14; 撒迦利亞書 8:23; 詩篇 72:11"> 他心中隱祕的事就會顯露出來。這樣，他就會把臉伏在地上敬拜神，承認說：「神真的是在你們中間！」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所書 5:19; 羅馬書 14:19; 哥林多前書 12:7–10"> 弟兄們，那麼該怎麼辦呢？你們聚集的時候，各人或有詩歌，或有教導，或有啟示，或有殊言，或有翻譯出來的話語——一切都要為了造就人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 14:26"> 如果有人說殊言，就應該只有兩個人，或最多三個人，而且要輪流說，也要有一個人翻譯。</span>
<span className="v" id="v28" data-v="28"> 如果沒有翻譯的人，他就應當在教會裡保持沉默，只對自己和神說話。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 12:10; 帖撒羅尼迦前書 5:19–21; 約翰一書 4:1–3"> 做先知傳道的<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="做先知傳道的——原文直譯「先知」。">h</a></sup>也應該兩個人或三個人講，其他的人應當分辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 5:19–20; 約伯記 33:31–33; 約伯記 32:11"> 如果在坐的人中另有人得了啟示，那先講的就應當保持沉默。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦前書 5:14; 哥林多前書 14:3; 帖撒羅尼迦前書 5:11"> 因為你們都可以一個一個地做先知傳道，好讓大家都能學，都得到鼓勵。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 4:19–20; 約翰一書 4:1; 撒母耳記上 10:10–13"> 先知的靈是服從先知的，</span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 3:17–18; 哥林多前書 14:40; 帖撒羅尼迦後書 3:16"> 因為神不是混亂的神，而是和平的神。<br />正如在聖徒的各教會那樣，</span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前書 2:11–12; 創世記 3:16; 民數記 30:3–13"> 婦女在教會應當保持沉默，因為她們沒有獲准講話；就像律法上所說的那樣，她們要服從。</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所書 5:12; 彼得前書 3:7; 以弗所書 5:25–27"> 如果她們想請教什麼，就應該在家裡問自己的丈夫，因為婦女在教會裡講話是可恥的。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 18:1–17; 撒迦利亞書 14:8; 使徒行傳 17:15"> 難道神的話語<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的話語——或譯作「神的道」。">i</a></sup>是從你們出來的嗎？難道只是臨到你們嗎？</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰一書 4:6; 哥林多後書 10:7; 彼得後書 3:2"> 如果有人自以為是做先知傳道的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="做先知傳道的——原文直譯「先知」。">j</a></sup>，或是屬靈的，就應該承認：我寫給你們的是主的命令；</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太後書 4:3–4; 何西阿書 4:17; 啟示錄 22:11–12"> 但如果有人不承認，他也不會被承認。<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="但如果有人不承認，他也不會被承認。——有古抄本作「但如果有人無知，就讓他無知吧！」">k</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 12:31; 哥林多前書 14:1; 帖撒羅尼迦前書 5:20"> 所以，我的弟兄們，你們要渴慕做先知傳道，也不要禁止說殊言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌羅西書 2:5; 提多書 1:5; 哥林多前書 14:26–33"> 然而，一切事都要行得端正，並且要按著秩序行。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CO" data-book-slug="1-corinthians" data-book-name="哥林多前書" data-chapter="10" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 14:29; 尼希米記 9:11–12; 詩篇 78:13–14"> 弟兄們，我不願意你們不明白：我們的祖先曾經都在那雲彩之下，都從那海中經過，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 3:2–3; 哥林多前書 1:13–16; 出埃及記 14:31"> 並且都在那雲裡和海裡受洗歸於摩西。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:3; 尼希米記 9:15; 出埃及記 16:35"> 他們都吃了同樣的屬靈食物，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 17:6; 約翰福音 7:37; 以賽亞書 48:21"> 也都喝了同樣的屬靈之水。原來他們所喝的是出於那隨著他們的屬靈磐石；那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 3:17; 猶大書 1:5; 民數記 14:37"> 但是神不喜悅他們中的大多數人，所以他們倒斃在曠野。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="猶大書 1:7; 哥林多前書 10:11; 希伯來書 4:11"> 這些事的發生，是為了我們的鑒戒，好使我們不像他們成為貪戀惡事的人。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 32:6–8; 詩篇 106:19–20; 哥林多前書 6:9"> 你們也不可像他們中的有些人那樣，成為拜偶像的，正如經上所記：「民眾坐下吃喝，起來玩樂。」</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 25:1–9; 哥林多前書 6:18; 詩篇 106:29"> 我們也不可行淫亂，像他們中的有些人行淫亂，結果一天就倒斃了兩萬三千人。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 21:5–6; 詩篇 78:18; 希伯來書 3:8–11"> 我們也不可試探基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基督——有古抄本作「主」。">a</a></sup>，像他們中的有些人試探了，結果就被蛇所滅。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:2; 民數記 16:41; 民數記 14:37"> 你們也不可抱怨，像他們中的有些人抱怨了，結果就被那毀滅者所滅。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 15:4; 羅馬書 13:11; 哥林多前書 9:10"> 這些事發生在他們身上，做為鑒戒；並且被記載下來，是為了警戒我們這些面臨萬世結局的人。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:20; 彼得後書 3:17; 箴言 16:18"> 所以，那自以為站得住的，應該當心，免得跌倒。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得後書 2:9; 提摩太後書 4:18; 帖撒羅尼迦後書 3:3"> 你們所遭受的試探<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="試探——或譯作「試煉」。">b</a></sup>，無非是人所遭受的。神是信實的，他不會讓你們受試探過於你們所能受的；而且在你們受試探的時候，他會給你們開一條出路，使你們能忍受得住。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:8; 約翰一書 5:21; 彼得前書 2:11"> 所以，我親愛的各位，你們要逃避拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:1; 帖撒羅尼迦前書 5:21; 哥林多前書 11:13"> 我就像對聰明人在說話；我所說的，你們應當自己判斷。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:26–28; 哥林多前書 11:23–29; 使徒行傳 2:42"> 我們所祝謝的福杯，難道不是在基督之血裡的一種契合嗎？我們所掰的餅，難道不是在基督身體裡的一種契合嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:5; 歌羅西書 3:15; 哥林多前書 12:27"> 這是因為餅只有一個，而我們這許多人是一個身體——就是說，我們全都共享這一個餅。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比書 3:3–5; 加拉太書 6:16; 利未記 7:6"> 你們看世上的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="世上的——原文直譯「肉體上的」。">c</a></sup>以色列人吧，難道那些吃祭物的人不是與祭壇有份的人嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 8:4; 哥林多前書 3:7; 哥林多前書 13:2"> 那麼，我怎麼說呢？難道說祭過偶像的食物算得了什麼嗎？或說，偶像算得了什麼嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 9:20; 詩篇 106:37–39; 申命記 32:16–17"> 不，我是說，外邦人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="外邦人——有古抄本作「他們」。">d</a></sup>所獻的祭是獻給鬼魔的，不是獻給神的；而我不願意你們成為與鬼魔有份的人。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:24; 列王紀上 18:21; 哥林多後書 6:15–17"> 你們不能既喝主的杯，又喝鬼魔的杯；不能既吃主的筵席，又吃鬼魔的筵席。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:21; 申命記 32:16; 希伯來書 10:31"> 難道我們要激起主的嫉恨嗎？難道我們比他更強嗎？</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 6:12; 哥林多前書 8:9; 以弗所書 4:29"> 「什麼事都可以做」，但不都有益處；「什麼事都可以做」，但不都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 15:1–2; 哥林多前書 10:33; 腓立比書 2:4–5"> 誰都不應當求自己的益處，而應當求別人的益處。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太前書 4:4; 哥林多前書 8:7; 提多書 1:15"> 肉市上所賣的一切，你們都可以吃；不要為了良心的緣故而問什麼，</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 24:1; 出埃及記 19:5; 詩篇 50:12"> 因為「大地和其中的一切都屬於主。」</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 10:25; 路加福音 10:7–8; 哥林多前書 5:9–11"> 如果有不信的人請你們吃飯<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="吃飯——輔助詞語。">e</a></sup>，而你們也願意去，那麼，凡是擺在你們面前的都可以吃，不要為了良心的緣故而問什麼。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 8:10–13; 哥林多前書 8:7; 哥林多前書 10:26"> 但如果有人對你們說：「這是祭過偶像的食物」，那麼，為了那指明這事的人和良心的緣故，你們就不要吃<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「因為大地和其中的一切都屬於主。」">f</a></sup>——</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 9:19; 羅馬書 14:15–21; 哥林多前書 8:9–13"> 我說的良心不是你自己的，而是那個人的，因為我的自由何必被別人的良心評斷呢？</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 14:6; 提摩太前書 4:3–4"> 如果我懷著感恩的心領受，難道有什麼能使我為所感謝的東西而受到毀謗嗎？</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歌羅西書 3:17; 歌羅西書 3:23; 彼得前書 4:11"> 因此，你們無論或吃、或喝、或做什麼，一切都要為神的榮耀而做。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 20:28; 哥林多前書 10:33; 羅馬書 14:13"> 無論對猶太人、對外邦人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="外邦人——原文直譯「希臘人」；指「希臘文化區的非猶太人」。">g</a></sup>，或對神的教會，你們都不可成為絆跌物；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 10:24; 加拉太書 1:10; 哥林多前書 9:19–23"> 要像我那樣，也在一切事上使所有的人喜悅——不求自己的益處，而求多人的益處，好讓他們都能得救。</span>
</div>
</div>

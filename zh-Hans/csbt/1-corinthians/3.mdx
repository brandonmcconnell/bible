<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 5:13; 哥林多前書 2:14–15; 以弗所書 4:13–14"> 弟兄們，以往我對你們說話，不能把你們當做屬靈的，只能當做屬肉體的，當做在基督裡的小孩子。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 5:11–14; 約翰福音 16:12; 彼得前書 2:2"> 我餵給你們吃的是奶，不是飯，原來你們那時還不能吃飯——其實現在也還是不能，</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 3:16; 加拉太書 5:15; 提多書 3:3"> 因為你們仍然是屬肉體的。既然你們中間有嫉妒、紛爭和分裂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「分裂」。">a</a></sup>，難道你們不就是屬肉體的，按人的意思來行事的嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 1:12; 哥林多前書 3:3; 哥林多前書 4:6"> 當有人說：「我是屬保羅的」，另有人說：「我是屬阿波羅的」時候，難道你們不就是屬肉體的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="屬肉體的——有古抄本作「人」。">b</a></sup>嗎？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 6:4; 哥林多後書 6:1; 彼得前書 4:10"> 其實阿波羅算什麼？保羅算什麼？都是僕人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="僕人——或譯作「執事」。">c</a></sup>；藉著他們，你們信了，是照著主所賜給每個人的。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 3:9–10; 箴言 11:25; 哥林多後書 10:14–15"> 我栽種了，阿波羅澆灌了，然而使之生長的還是神。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:5; 加拉太書 6:3; 詩篇 115:1"> 所以，除了使之生長的神，那栽種的和那澆灌的都算不得什麼。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 2:6; 馬太福音 16:27; 約翰二書 1:8"> 栽種的和澆灌的都一樣，只是將來每個人要照著自己的勞苦得自己的報償。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:5; 以弗所書 2:20–22; 哥林多後書 6:1"> 實際上，我們是神的同工；你們是神的田地，是神的建築物。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 3:11; 以弗所書 2:20; 羅馬書 15:20"> 我照著神賜給我的恩典，像一個有智慧的建築師，立好了根基，然後別人在上面建造；只是每個人應該當心怎樣在上面建造，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:20; 以賽亞書 28:16; 提摩太後書 2:19"> 因為除了那已經立好的根基以外，沒有人能立別的；那根基就是耶穌基督。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 4:3; 提摩太後書 3:7; 提摩太後書 2:20"> 如果有人用金、銀、寶石，木、草、禾秸在那根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 1:7; 哥林多前書 3:14–15; 啟示錄 20:12"> 每個人的工程將來要顯露，因為那日子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="日子——指「基督再來的日子」。">d</a></sup>要把它顯明；原來它要被火顯現出來，這火要考驗每個人的工程是怎樣的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 3:8; 馬太福音 25:21–23; 哥林多前書 4:5"> 如果有人在那根基<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="那根基——輔助詞語。">e</a></sup>上面所建造的工程能存留得住，這個人就將得到報償；</span>
<span className="v" id="v15" data-v="15" data-xref="約翰二書 1:8; 哥林多前書 3:12–13; 猶大書 1:23"> 如果有人的工程被燒掉，他就將受到損失，而他自己卻將得救，但是會像從火裡經過的那樣。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 6:19; 以西結書 36:27; 哥林多後書 6:16"> 你們難道不知道自己就是神的聖所，而且神的靈住在你們裡面嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 6:18–20; 以西結書 43:12; 民數記 19:20"> 如果有人毀壞<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="毀壞——或譯作「敗壞」。">f</a></sup>神的聖所，神就要毀壞<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="毀壞——或譯作「敗壞」。">g</a></sup>這個人，因為神的聖所是聖潔的，這聖所就是你們。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以賽亞書 5:21; 加拉太書 6:3"> 誰都不可自欺！如果你們中間有人自以為在這個世代中是有智慧的，他就應該變為愚拙，好成為有智慧的，</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 5:13; 詩篇 141:10; 哥林多前書 1:19–20"> 因為在神看來，這世界的智慧就是愚拙；原來經上記著：「神使智慧人落入自己的詭計中」；</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 94:11; 歌羅西書 2:8; 羅馬書 1:21"> 又說：「主知道智慧人的思想是虛妄的。」</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:32; 羅馬書 8:28; 耶利米書 9:23–24"> 所以誰都不要以人誇耀；要知道，一切都屬於你們：</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 4:11–12; 腓立比書 1:21; 哥林多前書 9:19–22"> 無論是保羅、是阿波羅、是磯法、是世界、是生、是死、是現在的事、是將來的事，全都屬於你們；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 3:29; 哥林多前書 11:3; 約翰福音 17:9–10"> 而你們屬於基督，基督屬於神。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 1:1; 以弗所書 1:1; 哥林多後書 1:1"> 照著神的旨意蒙召做基督耶穌使徒的保羅，以及弟兄索提尼，</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:7; 哥林多前書 6:9–11; 哥林多前書 1:30"> 致那在哥林多屬神的教會，就是在基督耶穌裡被分別為聖、蒙召成為聖徒的人，以及所有在各地求告我們主耶穌基督之名的人。基督是他們的主，也是我們的主。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="羅馬書 1:7; 哥林多後書 1:2; 彼得前書 1:2"> 願恩典與平安從神我們的父和主耶穌基督臨到你們！</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:8; 約翰福音 14:26; 提摩太前書 1:14"> 我常常為你們感謝我的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「我的」。">a</a></sup>神，因你們在基督耶穌裡被賜予了神的恩典，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 9:11; 哥林多後書 8:7; 歌羅西書 2:3"> 使你們在基督裡凡事都得以富足——在一切話語上、一切知識上——</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:2; 提摩太後書 1:8; 提摩太前書 2:6"> 正如有關基督的見證在你們中間得以確立，</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 3:20; 彼得後書 3:12; 希伯來書 9:28"> 以致你們在任何恩賜上都不缺乏，熱切等待著我們主耶穌基督的顯現。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:23–24; 帖撒羅尼迦前書 3:13; 歌羅西書 1:22"> 他也將使你們堅定到底，使你們在我們主耶穌基督的日子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="日子——指「基督再來的日子」。">b</a></sup>無可指責。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:3; 希伯來書 10:23; 申命記 7:9"> 神是信實的；你們已經被他召喚，進到與他的兒子——我們主耶穌基督的契合裡。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:1–4; 以弗所書 4:1–7; 哥林多前書 12:25"> 弟兄們，我藉著我們主耶穌基督的名，懇求你們大家言語一致；你們中間不要分裂，而要在同一個心思、同一個目的上得以完備。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:6; 提摩太前書 6:4; 提摩太後書 2:23–25"> 我的弟兄們，事實上，克洛伊家的一些人告訴了我有關你們的事，說你們中間有紛爭。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 3:21–23; 約翰福音 1:42; 馬太福音 23:9–10"> 這就是說：你們各自聲稱「我是屬保羅的」，或「我是屬阿波羅的」，或「我是屬磯法的」，或「我是屬基督的」。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:5; 哥林多後書 11:4; 使徒行傳 2:38"> 難道基督是被分割的嗎？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="難道基督是被分割的嗎？——或譯作「基督竟然被分割了！」">c</a></sup>難道保羅為你們被釘十字架了嗎？或者你們受洗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="受洗——或譯作「受浸」。">d</a></sup>是歸入保羅的名<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="歸入保羅的名——或譯作「奉保羅的名」。">e</a></sup>嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 18:8; 羅馬書 16:23; 哥林多前書 1:4"> 我感謝神<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「神」。">f</a></sup>，除了克里斯普和蓋尤斯以外，我沒有給你們任何人施過洗，</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 11:2; 約翰福音 3:28–29; 約翰福音 7:18"> 免得有人說，你們是奉我的名受洗。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:15; 哥林多前書 16:17; 使徒行傳 16:33"> 我雖然也給司提法納的一家人施過洗，此外我卻不記得是否給其他人施過洗。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 2:1; 哥林多前書 2:13; 彼得後書 1:16"> 要知道，基督差派我，不是為了施洗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="施洗——或譯作「施浸」。">g</a></sup>，而是為了傳福音——並不用智慧的話語，免得基督的十字架落了空。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 2:14; 羅馬書 1:16; 帖撒羅尼迦後書 2:10"> 原來，十字架的福音<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十字架的福音——原文直譯「十字架的話語」或「十字架的道」。">h</a></sup>對那些正在滅亡的人來說，是愚拙的；但是對我們這些正在被拯救的人來說，卻是神的大能。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 29:14; 耶利米書 8:9; 哥林多前書 3:19"> 因為經上記著：<br /><span className="pl pl-1">「我將要毀滅智慧人的智慧，</span><br /><span className="pl pl-1">廢棄聰明人的聰明。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:22; 約伯記 12:17; 哥林多前書 3:19"> 智慧人在哪裡？經文士在哪裡？這世代的雄辯家在哪裡？神難道不使這世界的智慧成了愚拙嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 10:21; 羅馬書 1:20–22; 馬太福音 11:25"> 實際上，在神的智慧中，世界既然憑智慧不認識神，神就樂意藉著傳道的愚拙，拯救那些相信的人。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 16:1–4; 馬太福音 12:38–39; 馬可福音 8:11"> 雖然猶太人求神蹟，希臘人尋智慧，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 2:14; 哥林多前書 2:2; 彼得前書 2:8"> 但我們卻傳揚被釘十字架的基督——對猶太人來說是絆腳石，對外邦人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="外邦人——有古抄本作「希臘人」。">i</a></sup>來說是愚拙的；</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 1:30; 歌羅西書 2:3; 哥林多前書 1:18"> 不過對那些蒙召的人，無論是猶太人、或是希臘人，基督總是神的大能、神的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 11:33–36; 哥林多前書 1:18; 撒迦利亞書 4:6–7"> 因為神的愚拙比人更智慧，神的軟弱比人更強壯。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各書 2:5; 哥林多前書 3:18–20; 雅各書 1:9–11"> 弟兄們，想一想你們所蒙的召喚：按人的標準<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="按人的標準——原文直譯「按肉體」。">j</a></sup>，你們當中<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你們當中——輔助詞語。">k</a></sup>有智慧的不多，有權勢的不多，出身高貴的也不多。</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 2:5; 馬太福音 11:25; 哥林多前書 1:20"> 然而神卻揀選了世上愚拙的，為了使那些有智慧的羞愧；神又揀選了世上軟弱的，為了使那些強壯的羞愧；</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 34:24; 羅馬書 4:17; 以賽亞書 2:11"> 神也揀選了世上出身低微的、被人藐視的，就是那些不是什麼的，為了要廢除那些是個什麼的，</span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 3:27; 耶利米書 9:23; 以弗所書 2:9"> 好使所有的人<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="人——原文直譯「肉體」。">l</a></sup>在神面前都不能自誇，</span>
<span className="v" id="v30" data-v="30" data-xref="以弗所書 1:7; 腓立比書 3:9; 羅馬書 8:1"> 但本於神，你們卻是在基督耶穌裡的。基督耶穌為我們成了從神而來的智慧、公義、聖潔和救贖，</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 9:23–24; 哥林多後書 10:17; 腓立比書 3:3"> 為要像經上所記的：「誇耀的當在主裡誇耀。」</span>
</div>
</div>

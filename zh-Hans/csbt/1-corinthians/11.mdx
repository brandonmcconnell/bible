<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CO" data-book-slug="1-corinthians" data-book-name="哥林多前書" data-chapter="11" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比書 3:17; 帖撒羅尼迦前書 1:6; 哥林多前書 4:16"> 你們要效法我，就像我效法基督一樣。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦後書 2:15; 哥林多前書 4:17; 箴言 31:28–31"> 我稱讚你們，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「弟兄們，」。">a</a></sup>因為你們在一切事上都記念我，並且照著我所傳給你們的來持守傳統。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:16; 歌羅西書 1:18; 歌羅西書 3:18"> 但是我願你們知道：基督是每一個男人的頭，男人是女人的頭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="男人是女人的頭——或譯作「丈夫是妻子的頭」。">b</a></sup>，而神是基督的頭。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 15:30; 哥林多前書 12:28; 哥林多前書 12:10"> 凡是男人在禱告或做先知傳道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知傳道——原文直譯「說預言」。">c</a></sup>的時候，如果蒙著頭，就是羞辱自己的頭；</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 21:12; 路加福音 2:36; 使徒行傳 2:17"> 凡是女人在禱告或做先知傳道的時候，如果不蒙著頭，就是羞辱自己的頭，因為這與頭髮被剃掉了是同樣一件事。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 22:5; 民數記 5:18"> 要知道，女人如果不遮蓋自己<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="自己——輔助詞語。">d</a></sup>，她就應該連頭髮也剪掉；但既然女人剪掉頭髮或剃掉頭髮是可恥的，她就應該遮蓋自己<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="自己——輔助詞語。">e</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 11:3; 創世記 5:1; 詩篇 8:6"> 男人本來不應該遮蓋著頭，因為他是神的形像和榮耀，而女人是男人的榮耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前書 2:13; 創世記 2:21–23"> 原來男人不是由女人而出，女人卻是由男人而出；</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 2:18; 創世記 2:23–24; 創世記 2:20"> 並且男人不是為女人而造，女人卻是為男人而造。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:64–65; 希伯來書 1:14; 馬太福音 18:10"> 因此，為了天使的緣故，應該有權柄<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="權柄——傳統譯法作「權柄的記號」。">f</a></sup>在女人的頭之上。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:28; 哥林多前書 7:10–14; 哥林多前書 12:12–22"> 不過在主裡，沒有女人就沒有男人，沒有男人也就沒有女人。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:36; 哥林多前書 8:6; 希伯來書 1:2–3"> 因為就像女人出於男人，照樣，男人也來自女人，而一切都是出於神。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 約翰福音 7:24; 哥林多前書 10:15"> 你們自己判斷吧：女人不蒙著頭向神禱告是合宜的嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 14:26; 哥林多前書 14:35"> 人的本性不也教導你們：男人如果留長髮就是他的羞恥，</span>
<span className="v" id="v15" data-v="15"> 而女人如果留長髮就是她的榮耀嗎？因為頭髮是賜給女人當做蓋頭的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 7:17; 提摩太前書 6:3–4; 帖撒羅尼迦前書 2:14"> 但如果有人想爭辯，我們卻沒有這樣的慣例；神的各教會也沒有。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:25; 哥林多前書 14:23; 哥林多前書 11:22"> 現在我吩咐以下的事，並不是在稱讚你們，因為你們聚集所導致的不是更好，而是更糟。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 3:3; 哥林多前書 1:10–12; 哥林多前書 5:1"> 首先，我聽說你們做為一個教會聚集的時候，在你們中間有分裂，我也部分地相信這話。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 2:19; 提多書 3:10; 使徒行傳 20:30"> 實際上，你們當中必定也會有結派的事，好讓那些經過考驗的人在你們中間能顯露出來。</span>
<span className="v" id="v20" data-v="20"> 這樣說來，你們聚集在一起，所吃的並不是主的晚餐，</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:13; 猶大書 1:12; 哥林多前書 11:23–25"> 因為你們吃的時候，每個人都爭先吃自己的晚餐，甚至有人餓著，有人醉了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 20:28; 箴言 17:5; 雅各書 2:5–6"> 難道你們沒有家，可以在那裡吃喝嗎？還是你們輕視神的教會，羞辱那些沒有什麼的人呢？我要對你們怎麼說呢？要稱讚你們嗎？在這事上，我不稱讚你們。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 馬太福音 26:26–28; 哥林多前書 11:23–25"> 我當時傳授給你們的是我從主所領受的：主耶穌在被出賣的那一夜，拿起餅來，</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:53–58; 哥林多前書 11:27–28; 哥林多前書 10:3–4"> 祝謝了，就掰開，說：<span className="woj">「</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「你們領受吃吧，」。">g</a></sup><span className="woj">這是我的身體，為了你們的緣故</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「掰開的」。">h</a></sup><span className="woj">；你們應當如此行，為的是記念我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯來書 9:15–20; 希伯來書 13:20"> 晚餐後，他也照樣拿起杯來，說：<span className="woj">「這杯是用我的血所立的新約。你們每逢喝的時候，應當如此行，為的是記念我。」</span></span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 9:28; 啟示錄 1:7; 約翰福音 14:3"> 你們每逢吃這餅、喝這杯，就是傳揚主的死，直到主來。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 6:51; 哥林多前書 10:21; 希伯來書 10:29"> 因此無論誰，不合宜地吃主的餅、喝主的杯，就是干犯主的身體、主的血。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 6:4; 哥林多後書 13:5; 耶利米哀歌 3:40"> 這樣，一個人應當省察自己，然後才吃這餅、喝這杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 11:27; 哥林多前書 11:30; 哥林多前書 11:32–34"> 因為那吃喝的人，如果不分辨主的<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有「主的」。">i</a></sup>身體，就是吃喝對自己的懲罰了。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 3:19; 民數記 20:12; 阿摩司書 3:2"> 為此，你們中間有很多人是軟弱的、患病的，甚至有許多人睡著了。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 1:9; 詩篇 32:3–5; 啟示錄 2:5"> 但如果我們省察自己，就不會受懲罰；</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 12:5–11; 詩篇 118:18; 箴言 3:11–12"> 即使我們受懲罰，也是在受主的管教，免得我們和這世界一同被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 所以我的弟兄們，你們聚集吃的時候，應當彼此等候。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 11:21–22; 哥林多前書 7:17; 哥林多前書 4:19"> 如果有人餓了，就應當在家裡吃，免得你們聚集，反導致懲罰。至於其他的事，當我來的時候才吩咐。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:10; 提多書 1:7; 提摩太前書 3:9"> 這樣，人應該把我們看做是基督的僕人、神奧祕之事的管家。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 在這裡，進一步要求管家們的是，各人都要被看做是忠心的。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 7:24; 哥林多前書 2:15; 撒母耳記上 16:7"> 至於我被你們評斷，或被人審判，對我都是極小的事。其實連我自己也不評斷自己。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 143:2; 約翰一書 3:20–21; 詩篇 130:3"> 我誠然問心無愧，但也並不因此被稱為義，原來評斷我的是主。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 5:7; 哥林多後書 5:10; 哥林多前書 3:13"> 所以時候沒有到，在主來臨之前，不要評斷任何事；主將照亮黑暗中隱祕的事，顯明人心裡的計劃。那時候，稱讚將從神那裡臨到各人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 12:6; 哥林多後書 11:4; 哥林多後書 12:19"> 弟兄們，我把這些事應用到我和阿波羅身上，是為了你們的緣故，好讓你們從我們學到「不要超越經上所記的」，免得你們自我膨脹，抬高這個人，貶低那個人。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 3:27; 彼得前書 4:10; 雅各書 1:17"> 使你與別人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="與別人——輔助詞語。">a</a></sup>不同的到底是誰呢？你有什麼不是領受的呢？如果真是領受的，你為什麼還自誇，好像不是領受的呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; 箴言 13:7; 哥林多前書 5:6"> 你們已經飽足了，已經富有了，沒有我們，自己就做王了！我真希望你們真做王，好讓我們也與你們一同做王！</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:33; 羅馬書 8:36; 哥林多後書 4:8–12"> 其實我在想，神把我們做使徒的列在最後，好像被定死罪的人；原來我們成了給宇宙<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="宇宙——或譯作「世界」。">b</a></sup>、天使、世人的一臺戲。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 2:3; 使徒行傳 26:24; 哥林多前書 3:18"> 我們為基督的緣故是愚拙的，你們在基督裡倒是聰明的；我們軟弱，你們倒強壯；你們有榮耀，我們倒不受尊重。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:35; 哥林多後書 11:23–27; 腓立比書 4:12"> 直到現在這時刻，我們還是又飢又渴，衣不蔽體，被人毆打，居無定所，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:9; 馬太福音 5:11; 彼得前書 4:12–14"> 並且親手勞苦做工。被人辱罵，我們就祝福；被人逼迫，我們就容忍；</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:45; 使徒行傳 22:22"> 受到毀謗，我們就勸導。我們被當做世界的垃圾、萬人的渣滓，直到如今。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:11; 哥林多前書 4:15; 約翰三書 1:4"> 我寫這些，不是要你們感到羞愧，而是把你們當做我親愛的兒女來勸誡。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:19; 哥林多前書 3:10; 哥林多前書 9:14"> 其實就算你們在基督裡有上萬的導師<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="導師——或譯作「監護人」。">c</a></sup>，卻沒有很多的父親，因為是我在基督耶穌裡藉著福音生了你們。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 11:1; 帖撒羅尼迦後書 3:9; 腓立比書 3:17"> 所以我勸你們：當效法我。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前書 1:2; 哥林多前書 16:10; 哥林多前書 7:17"> 為了這緣故，我派提摩太到你們那裡去。他是我在主裡又親愛又忠心的兒子，他會使你們想起我在基督耶穌裡的行事為人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="行事為人——原文直譯「道路」。">d</a></sup>，正如我在各處、各教會中所教導的。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 4:6–8; 哥林多前書 5:2; 哥林多前書 4:21"> 有些人以為我不會到你們那裡去，他們就自我膨脹。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 13:1–4; 使徒行傳 18:21; 使徒行傳 19:21"> 但如果主願意，我不久就會到你們那裡去；那時候，我所要知道的不是那些自我膨脹之人的話語，而是他們的權能，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 2:4; 帖撒羅尼迦前書 1:5; 哥林多後書 10:4–5"> 因為神的國不在於話語，而在於權能。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 13:2; 哥林多後書 13:10; 帖撒羅尼迦前書 2:7"> 你們要什麼呢？要我帶著權杖，還是要我帶著愛和溫柔的心靈到你們那裡去呢？</span>
</div>
</div>

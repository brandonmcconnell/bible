<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:6–12; 彼得前書 5:12; 哥林多前書 15:3–11"> 弟兄們，我要你們明白我先前所傳給你們的福音；你們也領受了這福音，並且在這福音上站立得住。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 3:6; 希伯來書 2:1; 希伯來書 3:14"> 如果你們不是毫無理由地相信，而是持守我所傳給你們的話語，你們也就會藉著它得救。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 2:24; 加拉太書 1:4; 以賽亞書 53:1–12"> 因為我所傳給你們的，其中最重要的，也是我所領受的，就是<br /><span className="pl pl-1">基督照著經上所記的，為我們的罪孽死了，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 6:2; 馬太福音 12:40; 詩篇 16:10–11"> <span className="pl pl-1">而且被埋葬了，</span><br /><span className="pl pl-1">又照著經上所記的，在第三天復活了，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 16:14; 哥林多前書 1:12; 約翰福音 1:42"> <span className="pl pl-1">並且向磯法顯現，然後向十二使徒</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使徒——輔助詞語。">a</a></sup><br /><span className="pl pl-1">顯現，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 28:10; 馬可福音 16:7; 使徒行傳 13:36"> <span className="pl pl-1">後來一次性地向五百多個弟兄顯現，</span><br /><span className="pl pl-1">其中大多數人至今還在，雖然也有些已經睡了；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行傳 1:2–12; 路加福音 24:33"> <span className="pl pl-1">後來他向雅各顯現，再向所有的使徒顯現，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 9:1; 使徒行傳 26:16; 使徒行傳 22:18"> <span className="pl pl-1">最後也顯現給我——這個像是早產嬰兒一樣的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以弗所書 3:7–8; 提摩太前書 1:13–15; 使徒行傳 8:3"> 原來我是使徒中最小的，不配被稱為使徒，因為我曾經逼迫神的教會。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 4:13; 哥林多後書 3:5; 腓立比書 2:13"> 但藉著神的恩典，我成了現在的我，並且神賜給我的恩典沒有落空。不但如此，我比任何使徒更加勞苦做工；其實不是我，而是與我同在的神的恩典。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 15:3–4; 哥林多前書 2:2"> 因此無論是我，或是他們，我們都如此傳，你們也就如此信了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 26:8; 使徒行傳 17:32; 提摩太後書 2:18"> 既然宣講基督已經從死人中復活了，你們中間怎麼還有些人說沒有死人復活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 11:25–26; 羅馬書 8:11; 帖撒羅尼迦前書 4:14"> 如果沒有死人復活的事，基督也就沒有復活了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 15:17; 帖撒羅尼迦前書 4:14; 加拉太書 2:2"> 如果基督沒有復活，我們傳道就是虛空，你們相信也是虛空。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:24; 約伯記 13:7–10; 使徒行傳 2:32"> 這樣，我們就被看做是神的假見證人，因為我們見證了有關神的事，說神使基督復活了，如果死人真不會復活，神就沒有使基督復活；</span>
<span className="v" id="v16" data-v="16"> 就是說，如果死人不會復活，基督也就沒有復活了。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 4:25; 彼得前書 1:3; 哥林多前書 15:14"> 如果基督沒有復活，你們的信仰就是虛妄的，你們也仍然在自己的罪孽中；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 4:13–14; 啟示錄 14:13; 帖撒羅尼迦前書 4:16"> 因此在基督裡那些睡了的人也就滅亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 1:21; 啟示錄 14:13; 提摩太後書 1:12"> 如果我們在基督裡的盼望只在於今生<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="如果我們在基督裡的盼望只在於今生——或譯作「如果我們今生所擁有的一切就是我們在基督裡的盼望」。">b</a></sup>，我們就比所有的人更可憐。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 15:23; 使徒行傳 26:23; 啟示錄 1:5"> 但如今，基督已經從死人中復活，成為睡了之人初熟的果子，</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 11:25; 羅馬書 5:12–17; 哥林多前書 15:22"> 因為死亡既然是由一個人而來，死人的復活也是由一個人而來。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 5:12–21; 哥林多前書 15:45–49; 約翰福音 5:21–29"> 原來，就像在亞當裡所有的人都死了，照樣，在基督裡所有的人也都將得以復活，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 26:19; 加拉太書 3:29; 哥林多前書 15:52"> 不過每個人要按著自己的次序：初熟的果子是基督；然後他來臨的時候，是那些屬於基督的人；</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:27; 但以理書 7:14; 馬太福音 28:18"> 再後才是結局。那時候，基督要把國度交給父神；同時，基督要廢除一切統治的、掌權的、有勢力的，</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 10:12–13; 詩篇 110:1; 馬太福音 22:44"> 因為基督必須做王，直到神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神——原文直譯「他」。">c</a></sup>把所有的敵人都放在他的腳下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:10; 哥林多前書 15:55; 啟示錄 21:4"> 最後被廢除的仇敵就是死亡，</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 8:6; 希伯來書 2:8; 馬太福音 28:18"> 因為「神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——原文直譯「他」。">d</a></sup>使萬有都服從在基督<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="基督——原文直譯「他」。">e</a></sup>的腳下。」當經上<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="經上——原文直譯「它」。">f</a></sup>說「萬有」都已經服從了他的時候，明顯地，使萬有服從基督<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="基督——原文直譯「他」。">g</a></sup>的那一位是不包括在內的。</span>
<span className="v" id="v28" data-v="28" data-xref="歌羅西書 3:11; 哥林多前書 3:23; 以弗所書 1:23"> 當萬有都服從他的時候，子自己也要服從那位使萬有都服從他的，這樣神就是萬有中的萬有。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="羅馬書 6:3–4; 哥林多前書 15:16; 馬太福音 20:22"> 如果不是這樣，那些替死人受洗的，將怎麼辦呢？如果死人根本不會復活，人們為什麼還替死人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="死人——有古抄本作「他們」。">h</a></sup>受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多後書 6:9; 加拉太書 5:11; 哥林多後書 4:7–12"> 我們又為什麼要時時刻刻面臨危險呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:10–11; 羅馬書 8:36; 哥林多前書 4:9–13"> 弟兄們，藉著我在我們的主基督耶穌裡所擁有的，就是我對你們的誇耀，我肯定地說：我天天都在死！</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 22:13; 以賽亞書 56:12; 路加福音 12:19"> 我在以弗所與野獸搏鬥，如果按人的意思來說，對我有什麼好處呢？如果死人不會復活，就「讓我們吃吃喝喝吧，因為明天我們就要死了。」</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 馬太福音 24:4; 哥林多前書 5:6"> 你們不要被迷惑了！「結交惡友，敗壞善德。」</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 6:5; 羅馬書 13:11; 希伯來書 5:11–12"> 你們應當醒悟過來，不繼續犯罪；實際上，有些人不認識神。我說這話，是為了使你們羞愧。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="以西結書 37:3; 哥林多前書 15:38–53; 羅馬書 9:19"> 但是有人會說：「死人怎樣復活呢？他們以什麼樣的身體出現呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 12:24; 路加福音 11:40; 以弗所書 5:15"> 你這愚妄的人哪！你所種的如果不死，就得不到生命；</span>
<span className="v" id="v37" data-v="37"> 你所種的也不是那將要長成的形體；你所種的不過是一粒赤裸的種子，也許是麥子，或是其他什麼。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前書 3:7; 以賽亞書 61:11; 馬可福音 4:26–29"> 但神照著自己的意願，給那種子一個形體，並且使每一粒種子各有自己的形體。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 1:20–26"> 並不是所有的身體都是同樣的：人是一個樣子，牲畜的身體是另一個樣子，鳥的身體又是一個樣子，魚又是另一個樣子。</span>
<span className="v" id="v40" data-v="40"> 還有天上的形體，也有地上的形體；但天上形體的光輝是一個樣子，地上形體的光輝是另一個樣子。</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 24:23; 詩篇 148:3–5; 申命記 4:19"> 太陽的光輝是一個樣子，月亮的光輝是另一個樣子，星辰的光輝又是一個樣子；這星與那星的光輝當然有區別。</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 13:43; 但以理書 12:3; 羅馬書 8:21"> 死人的復活也是這樣：<br /><span className="pl pl-1">在衰朽</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="衰朽——或譯作「敗壞」。">i</a></sup><br /><span className="pl pl-1">中被種下，在不朽中復活；</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前書 6:14; 歌羅西書 3:4; 腓立比書 3:20–21"> <span className="pl pl-1">在卑賤中被種下，在榮耀中復活；</span><br /><span className="pl pl-1">在軟弱中被種下，在強壯中復活；</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前書 15:50; 路加福音 24:31; 約翰福音 20:19"> <span className="pl pl-1">被種下的是屬血氣的身體，復活的是屬靈的身體。</span><br />既然有屬血氣的身體，也就有屬靈的身體。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 5:21; 創世記 2:7; 羅馬書 8:2"> 經上也這樣記著：「第一個人亞當成了有生命的人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有生命的人——原文直譯「活的靈」。">j</a></sup>，最後的亞當<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="最後的亞當——指「耶穌基督」。">k</a></sup>成了賜生命的靈。」</span>
<span className="v" id="v46" data-v="46" data-xref="歌羅西書 3:9–10; 羅馬書 6:6; 以弗所書 4:22–24"> 不過在先的不是屬靈的，而是屬血氣的；在後的才是屬靈的。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:31; 創世記 2:7; 創世記 3:19"> <span className="pl pl-1">第一個人是出於地，是屬塵土的</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="屬塵土的——或譯作「塵土造成的」。">l</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">第二個人</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附「是主，」。">m</a></sup><br /><span className="pl pl-1">是出於天。</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="創世記 5:3; 羅馬書 5:12–21; 約翰福音 3:6"> <span className="pl pl-1">屬塵土的</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="屬塵土的——或譯作「塵土造成的」。">n</a></sup><br /><span className="pl pl-1">那個人怎樣，那些屬塵土的也就怎樣；</span><br /><span className="pl pl-1">屬天的那一位怎樣，那些屬天的也就怎樣。</span><br /></span>
<span className="v" id="v49" data-v="49" data-xref="羅馬書 8:29; 哥林多後書 3:18; 創世記 5:3"> <span className="pl pl-1">就像我們帶有了屬塵土的</span><sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="屬塵土的——或譯作「塵土造成的」。">o</a></sup><br /><span className="pl pl-1">那個人的形像，</span><br /><span className="pl pl-1">我們也將帶有屬天的那一位的形像。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v50" data-v="50" data-xref="約翰福音 3:3–6; 馬太福音 16:17; 以弗所書 4:17"> 弟兄們，我要說這一點：血肉之體不能繼承神的國，衰朽<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="衰朽——或譯作「敗壞」。">p</a></sup>的也不能繼承不朽的。</span>
<span className="v" id="v51" data-v="51" data-xref="帖撒羅尼迦前書 4:14–17; 腓立比書 3:21; 哥林多前書 15:20"> 看哪，我告訴你們一個奧祕：<br /><span className="pl pl-1">我們並不是都要睡了，而是都要被改變，</span><br /></span>
<span className="v" id="v52" data-v="52" data-xref="帖撒羅尼迦前書 4:16–17; 馬太福音 24:31; 約翰福音 5:28"> <span className="pl pl-1">就在一刹那，眨眼之間，在那最後的號角聲中。</span><br /><span className="pl pl-1">的確，號角要吹響，死人要復活成為不朽壞的，我們也要被改變；</span><br /></span>
<span className="v" id="v53" data-v="53" data-xref="哥林多後書 5:2–4; 約翰一書 3:2; 羅馬書 2:7"> <span className="pl pl-1">因為這會朽壞的，必須穿上不朽壞的；</span><br /><span className="pl pl-1">這會死的，必須穿上不死的。</span><br /></span>
<span className="v" id="v54" data-v="54" data-xref="以賽亞書 25:8; 啟示錄 20:14; 希伯來書 2:14–15"> <span className="pl pl-1">一旦這會朽壞的穿上那不朽壞的，</span><br /><span className="pl pl-1">這會死的穿上那不死的，</span><br /><span className="pl pl-1">經上所記的話就會應驗了：</span><br /><span className="pl pl-1">「死亡被勝利吞滅了！」</span><br /></span>
<span className="v" id="v55" data-v="55" data-xref="何西阿書 13:14; 詩篇 89:48; 使徒行傳 2:27"> <span className="pl pl-1">「死亡啊！你的勝利</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="勝利——有古抄本作「毒刺」。">q</a></sup><br /><span className="pl pl-1">在哪裡？</span><br /><span className="pl pl-1">死亡啊！你的毒刺在哪裡？</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="死亡啊！你的毒刺在哪裡？——有古抄本作「墳墓啊！你的勝利在哪裡？」">r</a></sup><br /><span className="pl pl-1">」</span><br /></span>
<span className="v" id="v56" data-v="56" data-xref="羅馬書 4:15; 加拉太書 3:10–13; 羅馬書 7:5–13"> <span className="pl pl-1">死亡的毒刺就是罪，而罪的權勢就是律法。</span><br /></span>
<span className="v" id="v57" data-v="57" data-xref="哥林多後書 2:14; 羅馬書 8:37; 約翰一書 5:4–5"> <span className="pl pl-1">但感謝神，他藉著我們的主耶穌基督，</span><br /><span className="pl pl-1">賜給我們勝利！</span></span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="加拉太書 6:9; 歷代志下 15:7; 希伯來書 6:10"> 因此，我親愛的弟兄們，你們要堅定，不可動搖，常常在主的工作中豐足有餘，因為你們知道，你們的勞苦在主裡不是虛空。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 12:4; 撒迦利亞書 7:1; 撒迦利亞書 1:7"> 大流士二年的八月，耶和華的話語臨到易多的孫子、比利迦的兒子先知撒迦利亞，說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 44:6; 耶利米哀歌 5:7; 以西結書 22:31"> 「耶和華曾對你們的祖先大大發怒，</span>
<span className="v" id="v3" data-v="3" data-xref="瑪拉基書 3:7; 耶利米書 3:22; 耶利米書 4:1"> 因此你要對我的子民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我的子民——原文直譯「他們」。">a</a></sup>說：『萬軍之耶和華如此說：你們當轉向我！』這是萬軍之耶和華的宣告。『我就轉向你們！』這是萬軍之耶和華說的。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 78:8; 詩篇 106:6–7; 耶利米書 35:15"> 耶和華宣告：『你們不要像你們的祖先！先前的眾先知呼喚他們，說：「萬軍之耶和華如此說：現在你們要轉離自己邪惡的所作所為！」他們卻不聽從，也不留心聽我的話。</span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 12:5; 約伯記 14:10–12; 傳道書 12:7"> 你們的祖先，他們在哪裡呢？那些先知，他們會永遠活著嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 2:17; 申命記 28:15; 以西結書 12:25–28"> 然而我吩咐我僕人眾先知的話語和律例，不都追上了你們的祖先嗎？於是他們回轉，說：萬軍之耶和華照著我們的所作所為決意怎樣對待我們，他就怎樣對待了我們。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 1:1"> 大流士二年的十一月（細罷特月）二十四日，耶和華的話語臨到易多的孫子、比利迦的兒子先知撒迦利亞。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 6:4; 以賽亞書 55:13; 撒迦利亞書 13:7"> 我在夜間觀看，看哪，有一個人騎著紅色的馬，站在深谷裡的桃金娘樹中間！在他後面還有紅色、栗色、白色的馬。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 4:4–5; 撒迦利亞書 5:5; 撒迦利亞書 2:3"> 我就問：「主啊，這些是什麼呢？」<br />那與我說話的天使回答我：「我會向你指明這些是什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 1:11; 撒迦利亞書 6:5–8; 希伯來書 1:14"> 那站在桃金娘樹中間的人回應說：「這些是耶和華派遣去遍地巡行的。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 1:10; 撒迦利亞書 1:15; 詩篇 103:20–21"> 他們回應站在桃金娘樹中間耶和華的使者，說：「我們遍地巡行，看哪，全地都安定、平靜！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒迦利亞書 7:5; 耶利米書 29:10; 詩篇 102:13"> 於是耶和華的使者就回應說：「萬軍之耶和華啊，這七十年來你惱怒耶路撒冷和猶大各城，你不憐憫它們要到什麼時候呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 29:10; 以賽亞書 40:1–2; 耶利米書 30:10–22"> 耶和華就用和善安慰的話回答了那與我說話的天使。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約珥書 2:18; 以賽亞書 40:1; 撒迦利亞書 1:17"> 那與我說話的天使對我說：「你要宣告說：『萬軍之耶和華如此說：我為耶路撒冷，為錫安嫉妒，是極大的妒愛。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 25:12–17; 耶利米書 51:24; 以賽亞書 54:8"> 我對安逸的列國極其震怒，因為我從前對我的子民<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="對我的子民——輔助詞語。">b</a></sup>只是稍微發怒，列國卻對他們<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="對他們——輔助詞語。">c</a></sup>變本加厲。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 8:3; 以斯拉記 6:14–15; 撒迦利亞書 2:10–11"> 因此耶和華如此說：我在憐憫中回到了耶路撒冷，我的殿必在城中重建，準繩必拉在耶路撒冷之上。』這是萬軍之耶和華的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 51:3; 撒迦利亞書 2:12; 西番雅書 3:15–17"> 「你要再次宣告說：『萬軍之耶和華如此說：我的各城必再次福份滿溢，耶和華必再次安慰錫安，再次揀選耶路撒冷。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約書亞記 5:13; 列王紀下 24:1–20; 撒迦利亞書 5:9"> 我舉目觀看，看哪，有四隻犄角！</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 1:21; 撒迦利亞書 8:14; 撒迦利亞書 2:2"> 我就問那與我說話的天使：「這些是什麼呢？」<br />他回答我：「這些是打散猶大、以色列和耶路撒冷的犄角。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒迦利亞書 10:3–5; 撒迦利亞書 12:2–6; 撒迦利亞書 9:12–16"> 接著耶和華讓我看見四個工匠。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 75:10; 撒迦利亞書 1:19; 詩篇 75:4–5"> 我就問：「這些人來做什麼呢？」<br />他回答說：「那些打散猶大的犄角，使人不能抬起頭；而這些工匠來，要使那些犄角戰兢，打掉那些犄角之國——那些國曾舉起他們的犄角攻擊猶大地，為要打散它。」</span>
</div>
</div>

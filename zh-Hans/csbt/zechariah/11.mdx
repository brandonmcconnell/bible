<span className="v" id="v2" data-v="2" data-xref="以賽亞書 2:12–17; 以西結書 31:17; 以賽亞書 10:33–34"> <span className="pl pl-1">松樹啊，哀號吧！</span><br /><span className="pl pl-1">因為香柏樹倒地，茁壯的樹都被摧毀了。</span><br /><span className="pl pl-1">巴珊的橡樹啊，哀號吧！</span><br /><span className="pl pl-1">因為茂密的森林倒下了。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 50:44; 耶利米書 25:34–36; 撒迦利亞書 11:8"> <span className="pl pl-1">有牧人們哀號的聲音，</span><br /><span className="pl pl-1">因為他們的榮美被摧毀了；</span><br /><span className="pl pl-1">有少壯獅子怒吼的聲音，</span><br /><span className="pl pl-1">因為約旦河的叢林被摧毀了。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 11:7; 馬太福音 23:37; 羅馬書 15:8"> 耶和華我的神如此說：「你要牧養這將被殺戮的羊群！</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 50:7; 何西阿書 12:8; 提摩太前書 6:5–10"> 那些買他們的，殺戮他們卻不承受罪責；那些賣他們的，說：『耶和華是當受頌讚的！因為我變得富有了。』他們的牧人不憐恤他們。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 13:14; 馬太福音 22:7; 以賽亞書 9:19–21"> 因此耶和華宣告：「我必不再憐恤這地的居民。看哪，我必把各人交在他的鄰人和他的君王手中！他們將摧毀這地，我必不解救這地的居民脫離他們的手。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 11:14; 撒迦利亞書 11:4; 以賽亞書 11:4"> 於是，我就牧養這將被殺戮的羊群，就是困苦的羊群<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我就牧養這將被殺戮的羊群，就是困苦的羊群——七十士譯本作「我就為買賣群羊的人牧養這將被殺戮的羊群」。">a</a></sup>。我拿了兩根杖，一根稱為「恩慈」，另一根稱為「聯合」。這樣，我就牧養了羊群。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 49:7; 馬太福音 23:34–36; 約翰福音 15:18"> 一個月之內，我除滅了三個牧人。我的心對他們不耐煩，他們的心也憎嫌我。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 43:11; 馬太福音 13:10–11; 馬太福音 21:19"> 我說：「我不牧養你們了。那將要死的，就讓他死吧；那將被除滅的，就讓他被除滅吧；那將要留下的，就讓他們彼此吞吃對方的肉吧！」</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 11:7; 詩篇 89:39; 希伯來書 8:8–13"> 然後我拿起那稱為「恩慈」的杖，把它砍斷了，為要廢除我與萬民所立的約。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅書 3:12; 路加福音 2:38; 申命記 31:21"> 這約當天就被廢除了。這樣，那仰望我的困苦羊群，就知道這是耶和華的話語。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:15; 出埃及記 21:32; 路加福音 22:3–6"> 我對他們說：「如果你們眼中看為好，就給我酬報；不然，就算了！」他們就稱了三十錠銀子作我的酬報。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 27:3–10; 使徒行傳 1:18–19; 以賽亞書 53:2–3"> 耶和華對我說：「你要把那銀子扔給陶匠。」那銀子就是他們給我估定的高價。我就拿了那三十錠銀子，在耶和華的殿中扔給了陶匠。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 9:21; 以賽亞書 11:13; 使徒行傳 23:7–10"> 我又砍斷那稱為「聯合」的第二根杖，為要廢除猶大和以色列之間的兄弟之情。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 6:10–12; 路加福音 11:40; 耶利米書 2:26–27"> 耶和華又對我說：「你再拿愚蠢牧人的器具。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 34:2–6; 耶利米書 23:2; 馬太福音 23:2–4"> 看哪，我必使一個牧人在這地興起！那將被除滅的，他不眷顧；那分散的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="分散的——原文直譯「年少的」。">b</a></sup>，他不尋找；那受傷的，他不醫治；那精疲力竭的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="精疲力竭的——或譯作「健壯的」。">c</a></sup>，他不扶養；他卻要吞吃肥羊的肉，撕裂牠們的蹄子。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 23:1; 以西結書 13:3; 哥林多前書 8:4"> <span className="pl pl-1">「有禍了，那離棄羊群的無用牧人！</span><br /><span className="pl pl-1">刀劍必落在他的膀臂和右眼上；</span><br /><span className="pl pl-1">他的膀臂將徹底枯萎，</span><br /><span className="pl pl-1">他的右眼將完全失明。」</span></span>

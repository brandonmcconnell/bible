<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 13:9; 以賽亞書 2:12; 以賽亞書 13:6"> 看哪，耶和華的日子將到，你的被掠之物必在你面前被瓜分！</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:20–24; 以賽亞書 13:16; 羅馬書 9:27–29"> 我要招聚萬國與耶路撒冷作戰，這城將被攻取，房屋被搶掠，女人被奸汙；城中的人必有一半被擄去，但剩餘的民不會從城中被剪除。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 12:9; 西番雅書 3:19; 撒迦利亞書 2:8–9"> 那時，耶和華要出去，與那些國家爭戰，像他從前在戰鬥之日爭戰那樣。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 1:3–4; 以西結書 11:23; 使徒行傳 1:11–12"> 到那日，他的腳必站在橄欖山上——這山面向耶路撒冷，位於耶路撒冷的東邊；橄欖山必從東向西裂為兩半，形成極大的山谷，山的一半向北挪移，另一半向南挪移。</span>
<span className="v" id="v5" data-v="5" data-xref="猶大書 1:14–15; 阿摩司書 1:1; 馬太福音 25:31"> 你們會經由我的山谷逃跑，因為山谷延伸到亞薩；你們會逃跑，像人們逃避猶大王烏西雅年間的大地震那樣。耶和華我的神必來臨，所有的聖者也與他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——馬索拉文本作「你」。">a</a></sup>一起來臨。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:10–11; 詩篇 112:4; 約翰福音 12:46"> 到那日，不會有光，光體都必凍結。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 22:5; 帖撒羅尼迦前書 5:2; 但以理書 12:4"> 那將是耶和華所知道的獨特之日；那日不再有白天黑夜，傍晚時分仍然有光。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 22:1–2; 約翰福音 7:38; 約翰福音 4:14"> 到那日，必有活水從耶路撒冷流出，一半流向東邊的海，另一半流向西邊的海，夏天和冬天都會如此。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:5–6; 啟示錄 11:15; 但以理書 7:27"> 耶和華必作全地的王；到那日，耶和華就是唯一的，他的名也是唯一的。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 12:6; 約書亞記 15:32; 列王紀上 15:22"> 從迦巴直到耶路撒冷南方臨門的全地都將變為荒原，但耶路撒冷必聳立、存留在原處——從便雅憫門到第一門之處，又到角門，再從哈楠業樓到王的榨酒池那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 22:3; 耶利米書 23:5–6; 阿摩司書 9:15"> 城中必有人居住，不再有命定的滅絕，耶路撒冷的居民必安然居住。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 39:17–20; 以賽亞書 66:15–16; 彌迦書 4:11–13"> 以下是耶和華要降下的災殃，用來擊打所有與耶路撒冷作戰的民族：他們雙腳還站立著，他們的肉體就會腐爛；他們的眼睛必在眼窩裡腐爛，他們的舌頭必在口中腐爛。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 12:4; 啟示錄 17:12–17; 士師記 7:22"> 到那日，必有大騷亂從耶和華臨到他們，他們彼此抓住對方的手，彼此舉手攻擊對方。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 23:18; 撒迦利亞書 12:2; 歷代志下 20:25–27"> 猶大也必在耶路撒冷爭戰；四圍列邦的財富將被收聚，有極多的金銀和衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 14:12"> 必有一個災殃像以上的那樣，臨到馬匹、騾子、駱駝、驢子和他們營中的一切牲畜。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 14:17–19; 以賽亞書 66:23; 以賽亞書 66:18–21"> 前來攻擊耶路撒冷的萬國中所有存留下來的人，都必年復一年上來敬拜大君王萬軍之耶和華，並且守住棚節。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司書 4:7–8; 以賽亞書 60:12; 耶利米書 14:4"> 地上的萬族中，凡不上耶路撒冷敬拜大君王萬軍之耶和華的，就不會有雨水降在他們的地上。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 14:15; 申命記 11:10–11; 撒迦利亞書 14:12"> 如果埃及民族不上來參與，就不會有雨水降在他們的地上。這就是耶和華要降下的災殃，用來打擊那些不上來守住棚節的國家；</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 3:19"> 這是埃及要承擔的罪責，是所有不上來守住棚節的國家要承擔的罪責。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 3:16–17; 出埃及記 39:30; 利未記 8:9"> 到那日，馬的鈴鐺上必有「歸耶和華為聖」的字樣；耶和華殿中的鍋必像祭壇前的碗那樣。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 44:9; 羅馬書 14:6–7; 哥林多前書 10:31"> 耶路撒冷和猶大所有的鍋都必歸萬軍之耶和華為聖，所有獻祭的都會來取這些鍋，在其中煮肉。到那日，萬軍之耶和華的殿中，必不再有迦南人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="迦南人——或譯作「商人」。">b</a></sup>。</span>
</div>

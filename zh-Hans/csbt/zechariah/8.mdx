<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 萬軍之耶和華的話語又臨到我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 2:18; 撒迦利亞書 1:14–16; 以賽亞書 42:13–14"> 「萬軍之耶和華如此說：『我為錫安大大嫉憤，以極大的憤怒為她嫉憤。』</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 1:16; 撒迦利亞書 2:10–11; 約翰福音 1:14"> 耶和華如此說：『我要回到錫安，住在耶路撒冷中；耶路撒冷必被稱為「真理之城」，萬軍之耶和華的山必被稱為「聖山」。』</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 65:20–22; 約伯記 5:26; 耶利米哀歌 5:11–15"> 萬軍之耶和華如此說：『年老的男人和女人必再次坐在耶路撒冷的廣場上，他們因年紀老邁，個個手拿拐杖；</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 31:13; 馬太福音 11:16–17; 耶利米書 30:19–20"> 城中的廣場上必滿是男孩和女孩，他們在廣場上玩耍。』</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 32:27; 羅馬書 4:20–21; 民數記 11:22–23"> 萬軍之耶和華如此說：『在那些日子，這事在這餘剩之民眼中看為奇妙，難道在我眼中也看為奇妙嗎？』這是萬軍之耶和華的宣告。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 31:8; 羅馬書 11:25–27; 瑪拉基書 1:11"> 萬軍之耶和華如此說：『看哪，我必從日出之地和日落之地拯救我的子民！</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 36:28; 以西結書 11:20; 耶利米書 31:33"> 我要把他們帶回來，住在耶路撒冷中。他們必作我的子民，我必藉著真理和公義作他們的神。』</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 35:4; 歷代志上 22:13; 以斯拉記 5:1–2"> 「萬軍之耶和華如此說：『在奠定萬軍之耶和華殿的根基、要建造聖殿的日子，你們這些當時聽見眾先知親口說這些話的人，願你們的手堅強！</span>
<span className="v" id="v10" data-v="10" data-xref="哈該書 1:6–11; 哈該書 2:16–18; 阿摩司書 3:6"> 因為在那些日子之前，人沒有酬報，牲畜也沒有酬報；因敵人的緣故，人出入都沒有平安；我使所有的人彼此敵對。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 12:1; 哈該書 2:19; 撒迦利亞書 8:8–9"> 但如今，我對待這餘剩之民必不像先前的日子那樣。』萬軍之耶和華宣告：</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 26:4–5; 申命記 33:13; 創世記 27:28"> 『和平的種子必被撒下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="和平的種子必被撒下——原文直譯「必有和平的種子」。">a</a></sup>，葡萄樹必結果實，地必出收成，天必賜甘露；我要使這餘剩之民繼承這一切。</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅書 3:20; 撒迦利亞書 8:9; 詩篇 72:17"> 猶大家和以色列家啊，你們曾經在列國中成了受詛咒的，現在我必拯救你們，使你們成為蒙祝福的！你們不要害怕，願你們的手堅強！』</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:28; 以西結書 24:14; 耶利米書 4:28"> 萬軍之耶和華如此說：『你們的祖先惹怒我的時候，我怎樣決意向你們降下災禍並不改變心意；</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 8:13; 彌迦書 7:18–20; 路加福音 12:32"> 照樣，在這些日子，我必再次決意要善待耶路撒冷和猶大家。』萬軍之耶和華說：『你們不要害怕！</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所書 4:25; 撒迦利亞書 7:9; 詩篇 15:2"> 你們當行這些事：各人要與鄰人說真話，要在你們的城門口施行真理與和平的審判。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; 彌迦書 2:1–3; 耶利米書 44:4"> 各人不要在心裡向鄰人謀劃惡事，不要喜愛起假誓，因為這一切都是我所恨惡的。』這是耶和華的宣告。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 萬軍之耶和華的話語臨到我，說：</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 8:16; 耶利米書 39:2; 撒迦利亞書 7:5"> 「萬軍之耶和華如此說：『四月的禁食、五月的禁食、七月的禁食和十月的禁食，都將成為猶大家的歡樂、喜樂、快樂的節期；你們要喜愛真理與和平。』</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 2:2–3; 彌迦書 4:1–2; 撒迦利亞書 2:11"> 萬軍之耶和華如此說：『必有眾民，就是許多城市的居民再次前來，</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 7:2; 何西阿書 6:3; 詩篇 146:1–2"> 一個城市的居民將到另一個城市去說：「我們快去懇求耶和華的恩寵，尋求萬軍之耶和華吧！我也去！」</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亞書 8:21; 以賽亞書 60:3–22; 啟示錄 21:24"> 必有許多的民和強盛的國家前來，在耶路撒冷尋求萬軍之耶和華，懇求耶和華的恩寵。』</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 55:5; 哥林多前書 14:25; 以賽亞書 60:3"> 萬軍之耶和華如此說：『在那些日子，列國的語言群體中，必有十個人抓住一個猶太人的衣襟，說：讓我們與你們同去，因為我們聽說神與你們同在。』」</span>
</div>

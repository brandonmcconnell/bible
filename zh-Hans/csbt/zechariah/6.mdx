<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亞書 1:18–19; 撒迦利亞書 6:5; 但以理書 8:22"> 我又舉目觀看，看哪，有四輛戰車從兩座山之間出來！那兩座山是銅山。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 1:8; 啟示錄 6:2–6; 撒迦利亞書 6:6"> 第一輛戰車套著紅色的馬，第二輛戰車套著黑色的馬，</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 6:2; 啟示錄 6:8; 撒迦利亞書 1:8"> 第三輛戰車套著白色的馬，第四輛戰車套著有斑點的馬；那些馬都很強壯。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 1:9; 撒迦利亞書 5:10; 撒迦利亞書 1:19–21"> 我就問那與我說話的天使說：「主啊，這些是什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="希伯來書 1:14; 希伯來書 1:7; 詩篇 104:3–4"> 天使回答我，說：「這些是天上四方的風，站立在全地之主面前，現在從那裡出來了。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 51:48; 耶利米書 4:6; 耶利米書 6:1"> 黑色馬的戰車出來往北方之地，白色馬的戰車在其後出來<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在其後出來——或譯作「出來往西方去」。">a</a></sup>，斑點馬的戰車出來往南方之地。」</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 16:9; 撒迦利亞書 1:10; 約伯記 1:6–7"> 那些強壯的馬出來，急切地要去遍地巡行。天使說：「你們去，遍地巡行吧！」牠們就遍地巡行。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 5:13; 撒迦利亞書 1:15; 以賽亞書 18:3–4"> 然後他呼叫我，告訴我說：「看，那出來往北方之地的，在北方之地使我的怒氣平息了。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 8:1; 撒迦利亞書 7:1; 撒迦利亞書 1:1"> 耶和華的話語又臨到我，說：</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 7:14–16; 以斯拉記 8:26–30; 以賽亞書 66:20"> 「你要從擄民赫爾達伊、托比亞和耶達亞那裡收取奉獻——他們已經從巴比倫回來了；你要當天到西番雅的兒子約西亞的家裡去。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 3:1; 詩篇 21:3; 雅歌 3:11"> 你要收取金銀製作冠冕，戴在約薩達的兒子大祭司約書亞頭上，</span>
<span className="v" id="v12" data-v="12" data-xref="撒迦利亞書 3:8; 以賽亞書 4:2; 耶利米書 33:15"> 對他說：『萬軍之耶和華如此說：看哪，那名字稱為「苗裔」的人，必從自己的地方長出，並要建造耶和華的聖殿；</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:4; 以賽亞書 49:5–6; 希伯來書 3:1"> 是他要建造耶和華的聖殿，並要束上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="束上——原文直譯「承擔」。">b</a></sup>尊榮，坐在寶座上掌權，也在寶座上作祭司；兩職之間必有和平的謀略。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:13; 出埃及記 12:14; 馬可福音 14:9"> 這冠冕必留在耶和華的聖殿中，作為對希連<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="希連——黑玳的別名。">c</a></sup>、托比亞、耶達亞和西番雅的兒子賢<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="賢——約西亞的別名。">d</a></sup>的記念。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 60:10; 撒迦利亞書 3:7; 以賽亞書 58:10–14"> 遠方的人也要來建造耶和華的聖殿。』」這樣你們就知道：萬軍之耶和華派遣了我到你們這裡。你們如果留心聽你們的神耶和華的吩咐，這事就必成就。</span>
</div>

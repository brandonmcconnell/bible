<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 1:1; 以斯拉記 6:14–15; 撒迦利亞書 1:1"> 大流士王四年的九月（基斯流月）四日，耶和華的話語臨到撒迦利亞。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 8:21; 耶利米書 26:19; 撒母耳記上 13:12"> 那時，伯特利人派遣了沙利色、利堅·米勒和隨同他們的人，去懇求耶和華的恩寵，</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 8:19; 雅各書 4:8–10; 瑪拉基書 2:7"> 問萬軍之耶和華殿中的祭司們和先知們說：「我們還要像這許多年來所做的那樣，在五月哭泣、禁食嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 10:16"> 於是萬軍之耶和華的話語臨到我，說：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 1:12; 以賽亞書 58:4–6; 哥林多前書 10:31"> 「你要對這地所有的民眾和祭司說：『這七十年來，你們在五月和七月禁食、哀哭，是真的為我禁食嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 11:20–21; 哥林多前書 11:26–29; 何西阿書 8:13"> 當你們吃喝的時候，難道不是為自己吃，為自己喝嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:16–20; 耶利米書 17:26; 耶利米書 7:5"> 這些話語難道不是耶和華藉著先前的眾先知所宣告的嗎？那時，耶路撒冷和四圍的各城都有人居住，並且很安穩，南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音譯作「內蓋夫」。">a</a></sup>和丘陵地帶也有人居住。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華的話語又臨到撒迦利亞，說：</span>
<span className="v" id="v9" data-v="9" data-xref="彌迦書 6:8; 詩篇 82:2–4; 箴言 21:3"> 「萬軍之耶和華如此說：『你們要施行真理的審判，各人要以恩慈和憐憫對待自己的兄弟。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 5:28; 以賽亞書 1:23; 雅各書 5:4"> 不要欺壓寡婦、孤兒、寄居者和困苦人，各人不要在心裡向自己的兄弟謀劃惡事。』</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 9:29; 耶利米書 8:5; 何西阿書 4:16"> 然而，他們不肯留心聽，竟扭轉頑梗的肩頭，充耳不聞；</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 11:19; 尼希米記 9:29–30; 歷代志下 36:16"> 他們使自己的心硬如金剛石，不聽從律法，不聽從萬軍之耶和華藉著他的靈和先前的眾先知所發出的話語。因此，有極大的震怒從萬軍之耶和華而來。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 1:24–28; 耶利米書 14:12; 以賽亞書 1:15"> 萬軍之耶和華說：『既然我呼喚他們，他們不聽，那麼他們呼喚我，我也不聽。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:33; 申命記 28:64; 耶利米書 23:19"> 我用旋風把他們吹散到他們不認識的萬國去；他們身後的地變得荒涼，無人往來經過，他們使那美好之地成了荒場。』」</span>
</div>

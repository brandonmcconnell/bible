<span className="v" id="v1" data-v="1" data-xref="以賽亞書 42:5; 耶利米書 51:15; 以賽亞書 57:16"> 耶和華的話語，就是默示，是關於以色列的：<br />展開諸天、奠定大地的根基、造人裡面之靈的耶和華宣告：</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 14:14; 詩篇 75:8; 以賽亞書 51:22–23"> 「看哪，我必使耶路撒冷成為一隻酒杯，讓四圍所有的民族都醉得搖搖晃晃！耶路撒冷被圍困的時候，猶大也將被圍困。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 21:44; 撒迦利亞書 14:2–4; 但以理書 2:34–35"> 到那日，我必使耶路撒冷成為萬民的一塊沉重石頭，凡背負它的都必受重傷；地上萬國都將聚集起來攻擊它。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:28; 撒迦利亞書 12:3; 撒迦利亞書 12:6"> 耶和華宣告：「到那日，我必打擊所有的馬匹，使牠們恐慌，打擊騎馬的人，使他們瘋狂；我必睜眼看顧猶大家，打擊萬民所有的馬匹，使牠們瞎眼。</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 10:12; 約珥書 3:16; 詩篇 18:32"> 猶大的族長們心裡就說：『耶路撒冷的居民藉著萬軍之耶和華他們的神，成為我們的力量！』</span>
<span className="v" id="v6" data-v="6" data-xref="俄巴底亞書 1:18; 彌迦書 5:5–8; 撒迦利亞書 2:4"> 到那日，我必使猶大的族長們像木柴中的火盆，又像禾捆中燃燒的火把；他們將向左向右吞噬四圍所有的民族，但耶路撒冷的居民仍在耶路撒冷自己的地方居住。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 30:18; 羅馬書 3:27; 路加福音 1:51–53"> 耶和華必首先拯救猶大的帳篷，為要使大衛家的榮耀和耶路撒冷居民的榮耀不超過猶大。</span>
<span className="v" id="v8" data-v="8" data-xref="彌迦書 5:2–4; 撒迦利亞書 9:8; 約珥書 3:16–17"> 到那日，耶和華必保護耶路撒冷的居民；他們中間軟弱的人在那日將如大衛，而大衛家將像神——像在他們前面耶和華的使者那樣。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 54:17; 撒迦利亞書 14:2–3; 哈該書 2:22"> 到那日，我必設法除滅前來攻擊耶路撒冷的萬國。</span>

<span className="v" id="v11" data-v="11" data-xref="歷代志下 35:24; 列王紀下 23:29"> 到那日，耶路撒冷必有極大的哀號，如米吉多平原上哈達-臨門的哀號。</span>
<span className="v" id="v12" data-v="12" data-xref="撒迦利亞書 7:3; 路加福音 3:31; 撒母耳記下 5:14"> 這地必哀哭，各家族都獨在一處：大衛家族獨在一處，他們的女人獨在一處；拿單家族獨在一處，他們的女人獨在一處；</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 23:7; 撒母耳記下 16:5; 歷代志上 23:10"> 利未家族獨在一處，他們的女人獨在一處；示每家族獨在一處，他們的女人獨在一處；</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 9:12"> 其餘的所有家族，各個都獨在一處，他們的女人獨在一處。」</span>

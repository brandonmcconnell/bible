<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 24:8; 利未記 14:56; 利未記 14:3"> 「如果有人皮肉上出現了丘疹、疥癬或斑點，在他皮肉上出現了痲瘋病的症狀，就要帶他到祭司亞倫或他子孫中的一個祭司那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 3:19–20; 使徒行傳 20:28; 瑪拉基書 2:7"> 祭司要查看他皮肉上的疾患，如果疾患的毛髮已經變白，疾患症狀已經深入皮肉，這就是痲瘋病。祭司查看他後，要判定他為不潔淨。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 12:15; 哥林多前書 4:5; 提摩太前書 5:24"> 如果他皮肉上的斑點是白色的，症狀還沒有深入皮膚，毛髮也沒有變白，祭司就要把患者隔離七天。</span>
<span className="v" id="v5" data-v="5"> 到第七天祭司要查看他，如果據祭司看來疾患止住了，疾患沒有在皮膚上擴散，祭司就要把他再隔離七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 11:25; 利未記 14:8; 申命記 32:5"> 到第七天祭司要再查看他，如果疾患消退了，疾患沒有在皮膚上擴散，祭司就要判定他為潔淨，這就是皮疹。他洗衣服，就潔淨了。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 38:3; 利未記 13:35–36; 提摩太後書 2:16–17"> 但在祭司查看他而判定潔淨之後，如果皮疹在皮膚上又擴散了，他就要再次給祭司查看。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 15:7–8; 腓立比書 3:18–19; 使徒行傳 8:21"> 祭司要查看，如果皮疹在皮膚上確實擴散了，祭司就要判定他為不潔淨，這是痲瘋病。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「如果有人染上了痲瘋病，就要帶他到祭司那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 5:27; 歷代志下 26:19–20; 利未記 13:14–15"> 祭司查看，如果皮膚上有白色的丘疹，那裡的毛髮已經變白，丘疹上出現潰爛的肉，</span>
<span className="v" id="v11" data-v="11"> 這就是他皮肉上的慢性痲瘋病。祭司要判定他為不潔淨，不必隔離觀察，他明顯是不潔淨的。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 1:8–10; 約伯記 42:6; 羅馬書 7:14"> 如果痲瘋在皮膚上蔓延開來，祭司看這些症狀，痲瘋病已經從頭到腳覆蓋了患者全身的皮膚，</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 9:41; 以賽亞書 64:6"> 祭司查看，發現痲瘋病確實覆蓋了他全身，就要判定患者為潔淨；他全身變白，這是潔淨的。</span>
<span className="v" id="v14" data-v="14"> 然而，一旦他身上出現潰爛的肉，他就不潔淨。</span>
<span className="v" id="v15" data-v="15"> 祭司看到那潰爛的肉，就要判定他為不潔淨。這潰爛的肉是不潔淨的，這是痲瘋病。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 1:14–16; 羅馬書 7:14–24; 腓立比書 3:6–8"> 但如果潰爛的肉復原變白了，他就要去見祭司，</span>
<span className="v" id="v17" data-v="17"> 祭司查看他，如果疾患變白了，祭司就要判定患者為潔淨，他是潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 9:9; 以賽亞書 38:21; 詩篇 38:3–7"> 「如果有人身上的皮膚生瘡，已經痊癒了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 13:24"> 在生瘡的地方又起了白色的丘疹或紅白色的斑點，他就要給祭司查看。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 5:14; 利未記 13:3; 彼得後書 2:20"> 祭司要查看，如果那症狀侵入皮膚，那裡的毛髮也變白了，祭司就要判定他為不潔淨，這是瘡中發散的痲瘋病。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 5:5"> 但如果祭司查看疾患，發現上面沒有白毛，症狀也沒有侵入皮膚，反而消退了，祭司就要把他隔離七天。</span>
<span className="v" id="v22" data-v="22"> 然後，如果症狀在皮膚上又擴散了，祭司就要判定他為不潔淨，這是痲瘋病。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:1; 約伯記 34:31–32; 馬太福音 26:75"> 如果斑點留在原處沒有擴散，這就是瘡的疤痕，祭司要判定他為潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 3:24"> 「或者，如果有人身上的皮膚被火燙傷，燙傷的淤肉成為紅白色或白色的斑點，</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 13:18–20; 利未記 13:4"> 祭司就要查看，如果斑點上的毛髮已經變白，症狀已經深入皮膚，這就是燙傷中發散的痲瘋病，祭司要判定他為不潔淨，這是痲瘋病。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 13:23; 利未記 13:4–5"> 但如果祭司查看，發現斑點上沒有白毛，斑點沒有侵入皮膚，反而消退了，祭司就要把他隔離七天。</span>
<span className="v" id="v27" data-v="27"> 到第七天，祭司要查看他，如果斑點在皮膚上又擴散了，祭司就要判定他為不潔淨，這是痲瘋病。</span>
<span className="v" id="v28" data-v="28"> 但如果斑點留在原處，沒有在皮膚上擴散，反而消退了，這就是燙傷的丘疹，祭司要判定他為潔淨，這只是燙傷的疤痕。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 9:15; 馬太福音 13:14–15; 哥林多後書 4:3–4"> 「無論男女，如果他們頭上或下巴上有疾患，</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 13:34–37; 利未記 14:54"> 祭司就要查看這疾患，如果症狀深入皮膚，其上還有細弱的黃毛，祭司就要判定這人為不潔淨，這是癲癇，是頭或下巴上的痲瘋病。</span>
<span className="v" id="v31" data-v="31"> 但如果祭司查看癲癇的疾患，發現症狀沒有深入皮膚，不過其上沒有黑毛，祭司就要把這癲癇患者隔離七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 13:30; 馬太福音 23:5; 路加福音 18:9–12"> 到第七天，祭司要查看疾患，如果癲癇沒有擴散，其上也沒有黃毛，癲癇的症狀沒有深入皮膚，</span>
<span className="v" id="v33" data-v="33"> 這人就要剃掉鬚髮，但不要刮癲癇處，祭司要把這癲癇患者再隔離七天。</span>
<span className="v" id="v34" data-v="34" data-xref="猶大書 1:22; 約翰一書 4:1; 啟示錄 2:2"> 到第七天祭司要再查看癲癇，如果癲癇沒有在皮膚上擴散，症狀沒有深入皮膚，祭司就要判定這人為潔淨。他洗衣服，就潔淨了。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 13:27; 提摩太後書 2:16–17; 利未記 13:7"> 但如果判定他為潔淨以後，癲癇在皮膚上又擴散了，</span>
<span className="v" id="v36" data-v="36"> 祭司就要再查看他：如果癲癇已經在皮膚上擴散，祭司就不用搜尋黃毛了，這人是不潔淨的；</span>
<span className="v" id="v37" data-v="37"> 如果祭司看見癲癇止住了，其上也長出了黑毛，癲癇就是痊癒了，這人是潔淨的，祭司要判定他為潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 「無論男女，如果他們皮肉上出現了很多白色的斑點，</span>
<span className="v" id="v39" data-v="39" data-xref="羅馬書 7:22–25; 雅各書 3:2; 傳道書 7:20"> 祭司就要查看，如果他們皮肉上的斑點是淡白色的，這就是皮膚上發散的白斑病，這人是潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="加拉太書 4:13; 羅馬書 8:10; 雅歌 5:11"> 「如果有人的頭頂脫髮，這是頭頂禿，他是潔淨的。</span>
<span className="v" id="v41" data-v="41"> 如果他的頭是從前額脫髮，這是前額禿，他是潔淨的。</span>
<span className="v" id="v42" data-v="42"> 但如果在禿頂上，或禿前額上出現了紅白色的疾患，這就是他禿頂或禿前額上發散的痲瘋病。</span>
<span className="v" id="v43" data-v="43"> 祭司要查看他，如果他禿頂或禿前額上的丘疹是紅白色的，像皮肉的痲瘋病症狀一樣，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得後書 2:1–2; 馬太福音 6:23; 以賽亞書 1:5"> 這人就是患了痲瘋病，他是不潔淨的，祭司必須判定他為不潔淨，他頭上有了這疾患。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="彌迦書 3:7; 利未記 10:6; 以西結書 24:17"> 「身上患了痲瘋病的人，要撕裂衣服，披散頭髮，蒙著嘴，喊叫：『不潔淨！不潔淨！』</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀下 7:3; 列王紀下 15:5; 歷代志下 26:21"> 這疾患在他身上的日子，他都不潔淨。他不潔淨，就要獨自居住，住在營地外。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="猶大書 1:23; 羅馬書 13:12; 以西結書 16:16"> 「如果衣物上出現了痲瘋菌斑，無論是在羊毛衣物上或是在細麻衣物上，</span>
<span className="v" id="v48" data-v="48" data-xref="利未記 13:51; 啟示錄 3:4; 申命記 8:11"> 細麻或羊毛的經紗緯紗上，皮革或任何皮革製品上，</span>
<span className="v" id="v49" data-v="49"> 如果在布料或皮革上、經紗緯紗上、任何皮革製品上，出現綠色或紅色的菌斑，這就是痲瘋菌斑，要給祭司查看。</span>
<span className="v" id="v50" data-v="50" data-xref="以西結書 44:23"> 祭司要查看這菌斑，把有菌斑的物件隔離七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未記 14:44"> 到第七天祭司要查看，如果菌斑在布料上、經紗緯紗上，或在任何用途的皮革上擴散了，這菌斑就是惡性痲瘋，物件是不潔淨的。</span>
<span className="v" id="v52" data-v="52" data-xref="利未記 11:35; 利未記 11:33; 利未記 14:44–45"> 他要燒掉那染上病菌的衣物，無論那是經紗緯紗，還是羊毛或細麻，或任何皮革製品；因為這是惡性痲瘋，必須用火燒掉。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53"> 「但如果祭司查看，發現菌斑沒有在衣物上，經紗緯紗上，或任何皮革製品上擴散，</span>
<span className="v" id="v54" data-v="54"> 祭司就要吩咐把那有菌斑的物件洗淨，然後把它再隔離七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西結書 24:13; 希伯來書 6:4–8; 彼得後書 2:20–22"> 那有菌斑的物件洗淨之後，祭司要查看，如果菌斑的外觀沒有變化，雖然菌斑沒有擴散，但那物件還是不潔淨，要用火燒掉；這菌斑無論在物件裡面還是外面，都是侵蝕性的。</span>
<span className="v" id="v56" data-v="56"> 如果祭司查看，發現洗滌後菌斑消退了，就要把那一處從布料或皮革上、經紗緯紗上撕下來。</span>
<span className="v" id="v57" data-v="57" data-xref="馬太福音 22:7; 啟示錄 21:8; 馬太福音 3:12"> 之後，如果菌斑又出現在衣物上、經紗緯紗上，或任何皮革製品上，這是在擴散，你要把那染上病菌的物件用火燒掉。</span>
<span className="v" id="v58" data-v="58" data-xref="列王紀下 5:14; 啟示錄 1:5; 詩篇 51:2"> 那洗過的衣物、經紗緯紗，或是任何皮革製品，如果菌斑消失了，還要再洗一次，物件就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> 「以上是痲瘋菌斑的條例，無論它出現在羊毛或細麻的衣物上，經紗緯紗上，還是在任何皮革製品上，用於判定那物件潔淨或不潔淨。」</span>
</div>
</div>

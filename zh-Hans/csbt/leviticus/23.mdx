<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:4; 利未記 23:37; 民數記 29:39"> 「你要吩咐以色列子民，對他們說：以下是我所定的節期，是你們要宣告神聖聚會的耶和華的節期。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 19:3; 出埃及記 23:12; 出埃及記 35:2–3"> 「六天可以做工，但第七天是完全安息的安息日，要有神聖的聚會，任何工作你們都不可做。在你們居住的任何地方，這都是向耶和華守的安息日。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未記 23:2; 出埃及記 23:14; 利未記 23:37"> 「以下是耶和華所定的節期，你們要在這些所定的節期宣告神聖的聚會。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:10; 申命記 16:1–8; 民數記 28:16–17"> 在一月十四日黃昏的時候，是耶和華的逾越節。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 34:18; 申命記 16:8; 出埃及記 12:15–16"> 這月的十五日，是耶和華的除酵節，你們要吃無酵餅七天。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 28:18–25; 利未記 23:8; 利未記 23:21"> 第一天要有神聖的聚會，任何日常工作都不可做。</span>
<span className="v" id="v8" data-v="8"> 你們要連續七天獻火祭給耶和華，第七天要有神聖的聚會，任何日常工作都不可做。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華指示摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 34:26; 出埃及記 23:19; 申命記 16:9"> 「你要吩咐以色列子民，對他們說：當你們進入我所賜給你們的那地，收割莊稼時，要把一捆初熟的莊稼帶到祭司那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 29:24; 利未記 10:14; 利未記 9:21"> 祭司要把那禾捆在耶和華面前搖一搖，使你們蒙悅納，就是在安息日的次日，把它搖一搖。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:10–12; 彼得前書 1:19; 利未記 1:10"> 在搖獻禾捆那天，你們要獻上一隻無瑕疵的一歲公羊羔，作為燔祭獻給耶和華；</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 2:14–16; 約珥書 1:9; 民數記 28:10"> 同獻的素祭是十分之二伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之二伊法——相當於4.4公升。1伊法=22公升；本章下同。">a</a></sup>細麵粉，用油調和，作為馨香的火祭獻給耶和華；還有酒祭，是四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相當於0.9公升。1欣=3.7公升。">b</a></sup>的酒。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 34:26; 創世記 4:4–5; 利未記 3:17"> 在那一天你們把神的祭物帶來之前，無論是餅，還是烤麥子，或是新穗子，你們都不可吃。這是在你們居住的任何地方，你們世世代代永遠的律例。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 23:10–11; 利未記 25:8; 申命記 16:9–10"> 「從安息日的次日，就是你們把禾捆帶來作搖獻祭物那天起，你們要數算整整七個安息日，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:1; 民數記 28:26"> 直到第七個安息日的次日，這樣數算五十天，再把新的素祭帶來獻給耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 23:10; 出埃及記 34:26; 出埃及記 34:22"> 你們要從居住的地方帶來兩個餅作搖獻祭，是用十分之二伊法細麵粉、帶著酵烘烤的，作初熟之物獻給耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 28:27–31; 利未記 23:12–13; 瑪拉基書 1:13–14"> 連同這餅，你們要獻上七隻無瑕疵的一歲公羊羔，一頭公牛，兩隻公綿羊；這些要作為燔祭，連同素祭、酒祭獻給耶和華，作馨香的火祭獻給耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 28:30; 利未記 4:23–28; 利未記 7:11–18"> 然後，你們要獻上一隻公山羊為贖罪祭，兩隻一歲的公綿羊為平安祭。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 18:4; 以弗所書 2:14; 民數記 18:8–12"> 祭司要把這些祭物連同初熟之物的餅，與這兩隻綿羊羔一起，作為搖獻祭物在耶和華面前搖一搖。這些是獻給耶和華的聖物，歸於祭司。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 23:2; 利未記 23:4; 民數記 18:23"> 你們要在同一天宣告聚會；這是你們的神聖聚會，任何日常工作都不可做。這是在你們居住的任何地方，你們世世代代永遠的律例。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 24:19–21; 利未記 19:9–10; 以賽亞書 58:10"> 當你們收割地裡的莊稼時，不可連田地的邊角都收割乾淨，也不要撿拾所遺落的莊稼，總要留給困苦人和寄居者。我是耶和華你們的神。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華指示摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:52; 帖撒羅尼迦前書 4:16; 利未記 25:9"> 「你要吩咐以色列子民：七月的第一日，是你們完全安息的日子，要長鳴號角作記念，要有神聖的聚會。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:21"> 任何日常工作都不可做；要把火祭獻給耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華指示摩西說：</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 16:29–31; 出埃及記 30:10; 利未記 16:24"> 「至於七月的第十日，是贖罪日，你們要有神聖的聚會，刻苦己心，把火祭獻給耶和華。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亞書 3:9; 利未記 16:34; 希伯來書 10:10"> 這一天，任何工作都不可做，因為這是贖罪日，要在你們的神耶和華面前為你們贖罪。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:14; 民數記 5:2; 利未記 23:27"> 凡是這一天沒有刻苦己心的人，都必從民中被剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 20:3; 西番雅書 2:5; 耶利米書 15:7"> 凡是在這一天做任何工作的人，我必把這人從民中除滅。</span>
<span className="v" id="v31" data-v="31"> 任何工作你們都不可做。這是在你們居住的任何地方，你們世世代代永遠的律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 16:31; 馬太福音 11:28–30; 詩篇 69:10–11"> 這是你們完全安息的安息日，你們要刻苦己心。從這月九日傍晚到次日傍晚，你們要守安息日。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和華指示摩西說：</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 7:2; 尼希米記 8:14; 以斯拉記 3:4"> 「你要吩咐以色列子民：到七月的十五日，要向耶和華守七天的住棚節。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 23:24–25; 利未記 23:7–8"> 第一天要有神聖的聚會，任何日常工作都不可做。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 8:18; 約翰福音 7:37; 歷代志下 7:8–11"> 要連續七天把火祭獻給耶和華，第八天要有神聖的聚會，並且把火祭獻給耶和華；這是嚴肅集會，任何日常工作都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="利未記 23:2; 利未記 23:4; 傳道書 3:1"> 「以上是耶和華所定的節期，你們要宣告神聖的聚會，要把火祭，就是燔祭和素祭等祭物，連同酒祭，照著每天的份額獻給耶和華。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 29:39; 利未記 19:3; 以斯拉記 2:68–69"> 這些節期，是在耶和華的安息日以外的節期；這些祭物，是在你們獻給耶和華的供物、各種還願祭、各種甘心祭以外的祭物。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 23:16; 申命記 16:13; 利未記 23:34"> 「每當七月十五日，你們收聚了田地的出產，就要守耶和華的節期七天。第一天是完全安息的日子，第八天也是完全安息的日子。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 4:4; 啟示錄 7:9; 申命記 16:14–15"> 第一天，你們要拿來華美的樹枝——棕櫚葉子、茂密樹的枝條和溪谷中的柳枝，這樣在你們的神耶和華面前歡樂七天。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 29:12; 尼希米記 8:18"> 你們每年都要向耶和華守這節期七天；這是你們世世代代永遠的律例，必須在七月份守這節。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米記 8:14–17; 創世記 33:17; 民數記 24:5"> 你們要在棚子裡住七天，以色列所有的本族人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="本族人——原文直譯「本地人」。">c</a></sup>都要住在棚子裡，</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 31:10–13; 詩篇 78:5–6; 出埃及記 13:14"> 好讓你們世世代代知道：我把以色列子民從埃及地領出來的時候，曾使他們住在棚子裡。我是耶和華你們的神。」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="利未記 23:1–2; 馬太福音 18:20; 利未記 21:24"> 於是，摩西向以色列子民宣告了耶和華所定的節期。</span>
</div>

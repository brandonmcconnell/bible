<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 19:4; 申命記 27:15; 民數記 33:52"> 「你們不可為自己製造虛無的偶像，不可為自己豎立雕像或神柱，也不可在你們的地上安放石雕，向它下拜；我是耶和華你們的神。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 19:30"> 你們要謹守我的安息日，要敬畏我的聖所。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:19; 申命記 11:13–15; 申命記 28:1–14"> 「如果你們遵從我的律例，謹守遵行我的誡命，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 8:12; 詩篇 67:6; 利未記 25:21"> 我必按時給你們賜下雨水，使土地供應出產，田野的樹木結出果實。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 9:13; 約珥書 2:26; 約珥書 2:19"> 你們打穀會持續到採收葡萄時，採收葡萄會持續到撒種時。你們必有糧吃得飽足，在自己的地上安然居住。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 35:9; 西番雅書 3:13; 詩篇 147:14"> 我要賜平安在這地上，你們躺臥無人驚嚇。我要使惡獸從那地斷絕，刀劍必不會經過你們境內。</span>
<span className="v" id="v7" data-v="7"> 你們將追趕仇敵，他們必在你們面前倒在刀下。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 23:10; 申命記 28:7; 申命記 32:30"> 你們將五人追趕百人，百人追趕萬人，仇敵必在你們面前倒斃在刀劍之下。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 17:6–7; 尼希米記 9:23; 以西結書 16:62"> 「我必眷顧你們，使你們生養增多；我必確立我與你們的約。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 25:22; 列王紀下 19:29; 路加福音 12:17"> 你們還吃著儲藏的陳糧，就要為新的而把陳的清除。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 25:8; 啟示錄 21:3; 出埃及記 29:45"> 我要把我的帳幕安設在你們中間，我的心不會厭惡你們。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 6:16; 耶利米書 30:22; 耶利米書 7:23"> 我要行走在你們中間；我要作你們的神，你們要作我的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 34:27; 利未記 25:38; 詩篇 116:16"> 我是耶和華你們的神：是我把你們從埃及地領了出來，使你們不再作他們的奴隸；是我打碎了你們的軛套，使你們能昂首而行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 28:15–68; 利未記 26:18; 耶利米書 17:27"> 「但如果你們不聽從我，不遵行這一切誡命，</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 17:15; 申命記 31:16; 撒迦利亞書 7:11–13"> 如果你們厭棄我的律例，如果你們心中厭惡我的法規，不遵行我的一切誡命，而違背我的約，</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 31:8; 耶利米書 5:17; 彌迦書 6:15"> 我就要如此對付你們：我要指派惶恐臨到你們，必有癆病和熱病使你們眼睛衰竭、生命耗盡。你們將徒然播種，因為你們的仇敵要吃掉它。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 17:10; 箴言 28:1; 詩篇 53:5"> 我要對你們翻臉，你們將敗在仇敵面前，恨你們的人要轄制你們；雖無人追趕，你們也將逃跑。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 26:21; 利未記 26:28; 利未記 26:24"> 「如果這樣你們還不聽從我，我就要因你們的罪，加重七倍管教你們。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:23; 列王紀上 17:1; 但以理書 4:37"> 我將摧毀你們所誇耀的勢力，使你們的天空如鐵，土地如銅。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 127:1; 申命記 11:17; 以賽亞書 49:4"> 你們必徒然耗盡力氣，你們的土地不供應出產，地上的樹木也不結果實。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 26:18; 利未記 26:27"> 「你們如果繼續敵對我，不願意聽從我，我必照著你們的罪，加重七倍打擊你們。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 14:15; 申命記 32:24; 士師記 5:6"> 我要派出田野的走獸到你們中間，牠會使你們喪掉兒女，滅絕你們的牲畜，使你們人數減少，道路荒涼。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 5:3; 耶利米書 2:30; 阿摩司書 4:6–12"> 「如果經過這些事，你們還不接受我的管教，繼續敵對我，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 18:26; 撒母耳記下 22:27; 約伯記 9:4"> 我也必繼續敵對你們；我甚至要因你們的罪而七倍打擊你們。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 14:12; 以西結書 5:17; 耶利米書 29:17–18"> 我要使刀劍臨到你們，因你們背約而施行報復。當你們聚攏到城裡，我就降瘟疫在你們中間，你們也必被交在仇敵手中。</span>
<span className="v" id="v26" data-v="26" data-xref="彌迦書 6:14; 以賽亞書 3:1; 詩篇 105:16"> 當我斷絕你們的糧食供應時，十個女人將用一個火爐為你們烤餅，然後按定量稱了餅返回給你們，你們吃了卻吃不飽。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未記 26:24; 利未記 26:21"> 「如果經過這些事，你們還不聽從我，繼續敵對我，</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 59:18; 耶利米書 21:5; 以賽亞書 66:15"> 我也在怒火中繼續敵對你們，甚至因你們的罪而七倍管教你們。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 5:10; 耶利米哀歌 4:10; 馬太福音 24:19"> 你們將要吃自己兒子的肉，也要吃自己女兒的肉。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 23:20; 以賽亞書 27:9; 以西結書 6:13"> 我要拆毀你們的高壇，砍倒你們的香壇，把你們的屍體扔在你們偶像的殘骸上；我的心必厭惡你們。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 2:3; 耶利米哀歌 1:10; 希伯來書 10:26"> 我要使你們的城鎮變成廢墟，使你們的眾聖所變得荒涼；我也不會再聞你們的馨香之氣。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 9:11; 耶利米書 19:8; 耶利米書 18:16"> 我要使那地荒涼，甚至那些來居住在你們地上的仇敵，也會因此而震驚。</span>
<span className="v" id="v33" data-v="33" data-xref="撒迦利亞書 7:14; 以西結書 20:23; 申命記 28:64–66"> 我要把你們分散在列國中，還要拔出刀劍追趕你們。你們的土地將成為荒場，你們的城將變為廢墟。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歷代志下 36:21; 利未記 26:43; 利未記 25:2–4"> 「這樣，當你們在仇敵之地，而這地荒涼的整個期間，這地就可以補修它的安息。那時，這地將得享安息，補修它的安息年。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 24:5–6; 羅馬書 8:22"> 這地必在它所有荒涼的日子得享安息，是你們在這裡居住時，這地在你們的安息年中從來沒有享受過的安息。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西結書 21:7; 以賽亞書 30:17; 利未記 26:17"> 「至於你們當中殘留的人，我要使他們在仇敵之地心中恐慌，甚至風吹樹葉的聲音也會追趕他們。他們逃跑如逃避刀劍，雖無人追趕，也會仆倒。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 7:12–13; 士師記 2:14; 耶利米書 37:10"> 雖無人追趕，他們卻要像面對刀劍那樣彼此絆倒；你們在仇敵面前必站立不住。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 28:48; 以賽亞書 27:13; 耶利米書 42:17–18"> 你們將在列國中滅亡，仇敵之地會吞滅你們。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 4:17; 以西結書 24:23; 以西結書 33:10"> 你們當中殘留的人，將在仇敵之地因自己的罪孽而衰亡，也因自己祖先的罪孽隨同他們衰亡。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; 尼希米記 9:2–5; 約翰一書 1:8–10"> 「不過，當他們承認自己的罪孽和他們祖先的罪孽——他們對我不忠，繼續敵對我，</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 44:7; 歷代志下 32:26; 歷代志下 12:6–7"> 我也繼續敵對他們，把他們帶到仇敵之地——如果那時他們未受割禮的心謙卑下來，並且償清了自己的罪債，</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 106:45; 出埃及記 6:5; 以西結書 16:60"> 我必記念我與雅各的約，也記念我與以撒的約、我與亞伯拉罕的約，並且顧念這地。</span>
<span className="v" id="v43" data-v="43" data-xref="羅馬書 8:7; 利未記 26:15; 約翰福音 7:7"> 這地因他們而被遺棄，卻在荒涼無人的時候補修了安息。他們要償清自己的罪債，因為他們厭棄我的法規，他們的心厭惡我的律例。</span>
<span className="v" id="v44" data-v="44" data-xref="羅馬書 11:2; 尼希米記 9:31; 申命記 4:29–31"> 即使是這樣，當他們在仇敵之地時，我也沒有厭棄他們，沒有厭惡他們，使他們滅絕，沒有廢除我與他們所立的約，因為我是耶和華他們的神。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 25:38; 以西結書 20:22; 以西結書 20:9"> 我必為他們的緣故記念先前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="先前——或譯作「先祖」。">a</a></sup>的約，我在列國眼前把他們從埃及地領了出來，為要作他們的神。我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未記 27:34; 申命記 12:1; 申命記 6:1"> 以上是耶和華在西奈山，在他和以色列子民之間，藉著摩西所立定的律例、法規和訓誨。</span>
</div>

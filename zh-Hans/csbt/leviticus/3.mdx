<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 6:14; 利未記 1:3; 羅馬書 5:1–2"> 「當一個人的祭物是平安祭，如果所獻的是取自牛群，無論公的母的，都要把無瑕疵的獻在耶和華面前。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 29:10; 利未記 1:4–5; 使徒行傳 2:36–38"> 他要按手在祭牲的頭上，在會幕的入口把牠宰殺了。那些作祭司的亞倫子孫要把血灑在祭壇的四壁。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:13; 利未記 4:8–9; 出埃及記 29:22"> 他要從平安祭的祭牲中獻上火祭給耶和華：要把覆蓋內臟的脂肪，內臟上的全部脂肪，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 3:10; 利未記 8:25; 出埃及記 29:22"> 兩個腎臟和腎臟上靠近腰部的脂肪，以及腎臟上方的肝葉，都取下來。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 6:12; 出埃及記 29:13; 彼得前書 2:5"> 亞倫的子孫要把這些，連同火中木柴上的燔祭，在祭壇上燒獻為煙，作馨香的火祭獻給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多書 2:11–12; 加拉太書 3:28; 利未記 1:2"> 「如果他獻給耶和華的平安祭是取自羊群的祭物，無論公的母的，都要獻上無瑕疵的。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:62; 以弗所書 5:12; 利未記 17:8–9"> 如果他獻上綿羊為祭物，就要帶到耶和華面前獻上，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 1:5; 以弗所書 3:12; 利未記 3:13"> 按手在這祭牲的頭上，在會幕前面把牠宰殺了；亞倫的子孫要把血灑在祭壇的四壁。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 29:22; 利未記 9:19; 利未記 8:25"> 他要從平安祭的祭牲中獻上火祭給耶和華，就是祭牲的脂肪：要把靠近脊骨的整個肥尾巴取下，還要把覆蓋內臟的脂肪，內臟上的全部脂肪，</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 3:4"> 兩個腎臟和腎臟上靠近腰部的脂肪，以及腎臟上方的肝葉，都取下來。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 21:17; 利未記 21:6; 利未記 3:16"> 祭司要把這些在祭壇上燒獻為煙，作火祭的食物獻給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未記 9:15; 以賽亞書 53:2; 哥林多後書 5:21"> 「如果他以山羊為祭物，就要帶到耶和華面前獻上，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 3:8; 羅馬書 5:15–21; 哥林多後書 5:21"> 按手在牠頭上，在會幕前面把牠宰殺了；亞倫的子孫要把血灑在祭壇的四壁。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:38; 馬太福音 22:37; 利未記 3:9–11"> 他要從祭牲中獻上火祭給耶和華：要把覆蓋內臟的脂肪，內臟上的全部脂肪，</span>
<span className="v" id="v15" data-v="15"> 兩個腎臟和腎臟上靠近腰部的脂肪，以及腎臟上方的肝葉，都取下來。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:23–25; 馬太福音 22:37; 以賽亞書 53:10"> 祭司要把這些在祭壇上燒獻為馨香之氣，作火祭的食物。<br />「所有的脂油都歸於耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:4; 馬太福音 26:28; 申命記 15:23"> 任何脂油和血都不可吃，這是在你們居住的任何地方，你們世世代代永遠的律例。」</span>

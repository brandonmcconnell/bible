<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="LEV" data-book-slug="leviticus" data-book-name="利未記" data-chapter="19" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 11:44–45; 利未記 20:7; 彼得前書 1:15–16"> 「你要吩咐全體以色列會眾，對他們說：你們要成為聖潔的，因為我耶和華你們的神是聖潔的。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:12; 出埃及記 20:8; 希伯來書 12:9"> 「你們每個人都要敬畏父母。你們要謹守我的安息日。我是耶和華你們的神。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:1; 出埃及記 20:23; 詩篇 115:4–7"> 你們不可轉向虛無的偶像，不可為自己鑄造神像。我是耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未記 22:19; 利未記 22:29; 利未記 7:16"> 「你們獻平安祭給耶和華時，要獻得使你們可蒙悅納。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 7:11–17"> 你們的祭物要在獻上的當天或第二天吃；到了第三天還剩下的，要用火燒掉。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 7:18–21; 利未記 22:25; 耶利米書 16:18"> 到第三天如果還是被人吃了，這祭物就成了不潔之物，不蒙悅納。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 22:15; 利未記 5:1"> 吃了的人要承擔自己的罪責，因為他褻瀆了耶和華的聖物；這人要從民中被剪除。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未記 23:22; 申命記 24:19–22; 路得記 2:2"> 「你們收割地裡的莊稼時，不可連田地的邊角都收割乾淨，也不要撿拾所遺落的莊稼。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 17:6; 利未記 25:6; 以賽亞書 24:13"> 不可把葡萄園摘光，也不可撿拾葡萄園中掉落的葡萄，總要留給困苦人和寄居者。我是耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 101:7; 以弗所書 4:25; 歌羅西書 3:9"> 「不可偷竊，不可欺騙，不可彼此說謊。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:7; 申命記 5:11; 利未記 18:21"> 不可指著我的名起假誓，褻瀆你神的名。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:4; 瑪拉基書 3:5; 申命記 24:14–15"> 「不可欺壓你的鄰人，也不可搶奪他。雇工的工錢不可在你那裡留到早晨。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 27:18; 利未記 19:32; 利未記 25:17"> 不可咒罵耳聾的人，不可在瞎眼的人前面放絆腳石。你要敬畏你的神，我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 1:17; 箴言 24:23; 申命記 27:19"> 「不可在裁決上行不義；不可顧及貧弱者的情面，也不可看重大人物的情面，必須按公義審判你的同胞。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:1; 出埃及記 23:7; 箴言 20:19"> 不可在民中往來搬弄是非，也不可危害你鄰人的性命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="危害你鄰人的性命——原文直譯「站在你鄰人的血上面」。">a</a></sup>。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰一書 2:9; 約翰一書 2:11; 路加福音 17:3"> 「不可心裡恨惡你的弟兄；你可以坦誠地責備你的同胞，以免因他承擔罪過。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 13:9; 馬太福音 22:39–40; 馬可福音 12:31–34"> 不可報復，不可對你的同胞懷恨；你要愛鄰如己。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 6:14–17; 申命記 22:9–11; 馬太福音 9:16–17"> 「你們要遵守我的律例，不可使牲畜混類交配，不可在你的田地裡混類播種，不可穿上混類織成的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 22:23–24; 出埃及記 21:20–21"> 「如果一個男人與一個女人同寢交合，這女人是婢女，已經許配了人，但還沒有正式贖身，或者還沒有得自由，那麼對這事要處罰，但不可把他們處死，因為這女人還沒有得自由。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 6:6–7; 利未記 5:1–6; 利未記 5:15"> 那男人要把贖愆祭，就是一隻贖愆祭公綿羊，帶到會幕入口獻給耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:26; 利未記 4:20"> 祭司用這贖愆祭公綿羊，在耶和華面前為他贖罪，他所犯的罪就得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="利未記 22:27; 使徒行傳 7:51; 耶利米書 9:25–26"> 「當你們進入迦南地，栽種各樣果樹，要把樹上的果實看作不潔淨的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不潔淨的——或譯作「未受割禮」；本節下同。">b</a></sup>。三年期間，你們要把那些果實看作不潔淨的，不可以吃。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 3:9; 申命記 18:4; 民數記 18:12–13"> 第四年，那些果實全是聖潔的，要用於頌讚耶和華。</span>
<span className="v" id="v25" data-v="25" data-xref="哈該書 1:9–11; 瑪拉基書 3:8–10; 利未記 26:3–4"> 到了第五年，你們可以吃那些果實。這樣，果樹就會為你們增添收成。我是耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 18:10–14; 列王紀下 17:17; 歷代志下 33:6"> 「不可吃帶血的食物。不可用法術，不可算命。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 21:5; 申命記 14:1; 以西結書 44:20"> 不可把頭的邊角剃掉，也不可把鬍鬚的邊角剪掉；</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 14:1; 利未記 21:5; 列王紀上 18:28"> 不可為死人割傷你們的身體，也不可紋身。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 23:17–18; 利未記 21:7; 何西阿書 4:12–14"> 「不可讓你的女兒賣淫，受玷汙，以免這地遍行淫亂，地上充滿淫穢。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 26:2; 利未記 19:3; 傳道書 5:1"> 你們要謹守我的安息日，要敬畏我的聖所。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 8:19; 利未記 20:27; 利未記 20:6–7"> 「不可轉向招魂的，不可尋求通靈的，以免被他們玷汙。我是耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="提摩太前書 5:1; 耶利米哀歌 5:12; 箴言 16:31"> 「在白髮人面前，你要起身，要尊重老年人。你要敬畏你的神，我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及記 23:9; 出埃及記 22:21; 瑪拉基書 3:5"> 「如果有外人在你們的地方與你同住，你不可欺負他。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 10:19; 利未記 19:18; 出埃及記 12:48–49"> 你們要像對待本族人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="本族人——原文直譯「本地人」。">c</a></sup>那樣，對待寄居在你們那裡的外人，你要愛他如己，因為你們在埃及地也作過寄居者。我是耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 25:15; 申命記 25:13; 箴言 16:11"> 「不可在量度上，在尺寸、重量、容量上行不義，</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 11:1; 出埃及記 20:2; 申命記 25:13–15"> 你們要用公正的天平、公正的砝碼、公正的量斗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="量斗——原文直譯「伊法」；相當於22公升，計量穀物的量器。">d</a></sup>和公正的量筒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="量筒——原文直譯「欣」；相當於3.7公升，計量液體的量器。">e</a></sup>。我是耶和華你們的神，把你們從埃及地領出來的那一位。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 8:1; 利未記 18:4–5; 申命記 5:1"> 你們要謹守遵行我的一切律例和法規。我是耶和華。」</span>
</div>
</div>

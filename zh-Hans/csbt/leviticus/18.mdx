<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:7; 利未記 11:44; 以西結書 20:5"> 「你要吩咐以色列子民，對他們說：我是耶和華你們的神。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 20:23; 出埃及記 23:24; 彼得前書 4:2–4"> 你們不可效法你們曾居住的埃及地的行為，也不可效法我將帶你們去的迦南地的行為；你們不可隨從他們的習俗。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 18:2; 利未記 18:26; 以西結書 20:19"> 你們要實行我的法規，謹守遵行我的律例。我是耶和華你們的神。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 10:5; 以西結書 20:11; 加拉太書 3:12"> 你們要遵守我的律例和法規；人若遵行這些，就必因此而活。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 20:17–21; 利未記 18:7–19; 利未記 20:11–12"> 「任何人都不可親近自己的任何血親，裸露她的下體。我是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 20:11; 以西結書 22:10; 利未記 18:8–16"> 你不可裸露你母親的下體，那是你父親的下體，她是你的母親，你不可裸露她的下體。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 20:11; 哥林多前書 5:1; 申命記 27:20"> 也不可裸露你父親妻妾的下體，那是你父親的下體。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 20:17; 申命記 27:22; 以西結書 22:11"> 不可裸露你姐妹的下體，無論她是你父親的女兒還是你母親的女兒，是家裡出生的還是外面出生的。</span>
<span className="v" id="v10" data-v="10"> 不可裸露你孫女或外孫女的下體，因為那是裸露你自己的下體。</span>
<span className="v" id="v11" data-v="11"> 不可裸露你父親妻妾的女兒的下體，她是你父親所生的，是你的姐妹。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 20:19; 出埃及記 6:20"> 不可裸露你姑母的下體，她是你父親的血親。</span>
<span className="v" id="v13" data-v="13"> 不可裸露你姨母的下體，因為她是你母親的血親。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:20"> 不可親近你父親兄弟的妻子，裸露她的下體<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不可親近你父親兄弟的妻子，裸露她的下體——原文直譯「不可裸露你父親兄弟的下體，不可親近他的妻子」。">a</a></sup>，她是你的伯母叔母。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 20:12; 創世記 38:26; 以西結書 22:11"> 不可裸露你兒媳的下體，她是你兒子的妻子，你不可裸露她的下體。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 25:5; 利未記 20:21; 馬太福音 22:24"> 不可裸露你兄弟妻子的下體，那是裸露你兄弟的下體。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 20:14; 阿摩司書 2:7; 申命記 27:23"> 不可既裸露一個婦女的下體，又裸露她女兒的下體，也不可娶她的孫女或外孫女，裸露她們的下體；她們是骨肉之親，你這樣做是醜惡的。</span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 2:15; 創世記 30:15; 創世記 29:28"> 不可在妻子還活著的時候，又娶她的姐妹裸露她的下體，以致她們成為對頭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 20:18; 利未記 15:24; 以西結書 22:10"> 「不可親近在經期不潔的婦女，裸露她的下體。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:14; 哥林多前書 6:9; 希伯來書 13:4"> 不可與你鄰人的妻子行淫，以致玷汙自己。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 12:31; 利未記 20:2–5; 申命記 18:10"> 「不可把你的兒女經火<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="火——輔助詞語。">b</a></sup>獻給摩洛，不可褻瀆你神的名。我是耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 20:13; 羅馬書 1:26–27; 哥林多前書 6:9"> 不可與男人同寢，就像與女人同寢那樣；這是可憎的行為。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 22:19; 利未記 20:15–16; 利未記 20:12"> 不可與任何動物交合，以致玷汙自己；女人也不可親近<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="親近——原文直譯「站在……前面」。">c</a></sup>動物與牠交合；這是違反天性的事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 18:12; 利未記 18:30; 利未記 20:22–23"> 「你們不可在這一切事上玷汙自己。因為我將要在你們面前驅逐的那些民族，就是在這一切事上玷汙了自己，</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 18:28; 利未記 20:22–23; 耶利米書 2:7"> 連那地也被玷汙了，所以我追究那地上的罪孽，那地就把其中的居民吐出來。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 18:5; 利未記 17:10; 利未記 18:30"> 你們務必謹守我的律例和法規，無論本族人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="本族人——原文直譯「本地人」。">d</a></sup>還是寄居在你們中間的外人，都不可做其中任何一件可憎之事。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 36:14; 利未記 18:24; 申命記 23:18"> 因為在你們之前那地的人，做了這一切可憎之事，地就被玷汙了。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 3:16; 利未記 20:22; 利未記 18:25"> 所以，不可讓這地因你們玷汙了它而把你們吐出來，就像吐出你們之前的民族那樣。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 20:6; 出埃及記 12:15; 利未記 17:10"> 要知道，任何人做了其中任何一件可憎之事，都必從民中被剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 20:23; 申命記 18:9–12; 利未記 22:9"> 你們要謹守我的吩咐，不再效法你們之前那些人所行的可憎習俗；你們不可因他們的習俗而玷汙自己。我是耶和華你們的神。」</span>
</div>
</div>

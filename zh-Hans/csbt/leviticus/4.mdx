<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 19:12; 希伯來書 9:7; 利未記 4:27"> 「你要吩咐以色列子民：當一個人無意中犯了罪，做了耶和華誡命中不可做的任何一件事：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯來書 7:27–28; 利未記 4:14; 利未記 9:2"> 「如果是受膏的祭司犯罪，連累百姓有了罪，他就要為自己所犯的罪，把一頭無瑕疵的公牛獻給耶和華作贖罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 1:3–4; 但以理書 9:26; 以賽亞書 53:6"> 他要把公牛牽到會幕入口耶和華面前，按手在公牛的頭上，在耶和華面前把公牛宰殺了。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 16:14; 民數記 19:4; 利未記 4:16–17"> 受膏的祭司要取一些公牛的血，帶進會幕；</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 16:14; 利未記 14:18; 利未記 26:28"> 祭司要把手指蘸到血裡，在耶和華面前把一些血對著聖所的幔子彈灑七次；</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 8:15; 利未記 9:9; 利未記 16:18"> 祭司也要在會幕中耶和華面前的香壇犄角上塗一些血，然後把公牛其餘的血全都倒在會幕入口的燔祭壇基座那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 3:3–5; 利未記 4:26; 利未記 4:31"> 他要取出這贖罪祭公牛的全部脂肪：覆蓋內臟的脂肪，內臟上的全部脂肪，</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 3:4"> 兩個腎臟和腎臟上靠近腰部的脂肪，以及腎臟上方的肝葉，都要取下來，</span>
<span className="v" id="v10" data-v="10"> 就像從平安祭所獻的公牛取出那樣。祭司要在燔祭壇上把這些燒獻為煙。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 19:5; 出埃及記 29:14; 利未記 9:8–11"> 至於公牛的皮和所有的肉，連同頭、腿、內臟和糞便，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 13:11; 出埃及記 29:14; 利未記 16:27"> 就是公牛其餘的一切，都要帶到營地外潔淨之地倒灰燼的地方，然後在木柴上用火焚燒，在倒灰燼的地方燒掉。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 5:17; 利未記 5:2–5; 何西阿書 5:15"> 「如果全體以色列會眾無意中有過失，會眾卻對此沒有察覺，做了耶和華誡命中不可做的任何一件事，因而有了罪責，</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 4:23; 利未記 4:3; 利未記 4:28"> 一旦他們知道自己在誡命上所犯的罪，就要獻上一頭公牛作贖罪祭。他們要把牛牽到會幕前面，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 1:4; 利未記 16:21; 利未記 8:14"> 會眾的長老要在耶和華面前按手在公牛的頭上，在耶和華面前把公牛宰殺了。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:5–12; 希伯來書 9:12–14"> 受膏的祭司要把一些公牛的血帶進會幕；</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:6–7"> 祭司要用手指蘸一些血，在耶和華面前對著幔子彈灑七次；</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:7"> 也要在會幕中耶和華面前的祭壇犄角上塗一些血，然後把其餘的血全都倒在會幕入口的燔祭壇基座那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 5:6; 利未記 4:26; 民數記 15:25"> 他要取出這公牛的全部脂肪，在祭壇上燒獻為煙。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 15:25; 希伯來書 10:10–12; 利未記 12:8"> 他處理這公牛，要像處理贖罪祭所獻的公牛那樣，同樣處理。這樣，祭司為他們贖罪，他們就得到赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 16:15; 馬太福音 20:28; 哥林多後書 5:21"> 公牛其餘的一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="其餘的一切——輔助詞語。">a</a></sup>要帶到營地外，像焚燒前一頭公牛那樣燒掉；這是會眾的贖罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 4:2; 利未記 4:13; 民數記 31:13"> 「如果一個領袖犯罪，無意中做了他的神耶和華誡命中不可做的任何一件事，因而有了罪責，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 4:14; 羅馬書 8:3; 民數記 7:22"> 一旦他知道自己在誡命上所犯的罪，他就要牽來一隻無瑕疵的公山羊為祭物。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 3:13; 利未記 7:2; 利未記 4:3–35"> 他要按手在公山羊的頭上，在宰殺燔祭牲的地方，在耶和華面前把牠宰殺了；這是贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:7; 利未記 4:18; 利未記 4:30"> 祭司要用手指取一些贖罪祭的血，抹在燔祭壇的犄角上，然後把其餘的血倒在燔祭壇基座那裡。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 4:20; 利未記 4:31; 利未記 4:35"> 他要像燒獻平安祭的脂肪那樣，在祭壇上把全部的脂肪燒獻為煙。這樣，祭司為他的罪贖罪，他就得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未記 4:2; 民數記 15:27; 利未記 4:13"> 「如果這地的百姓有一個人無意中犯了罪，做了耶和華誡命中不可做的任何一件事，因而有了罪責，</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 4:23; 利未記 4:3; 利未記 4:32"> 一旦他知道自己所犯的罪，就要為他所犯的罪牽來一隻無瑕疵的母山羊為祭物。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 4:4; 利未記 4:24; 利未記 1:4"> 他要按手在贖罪祭牲的頭上，在燔祭的地方宰殺這贖罪祭。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 4:7; 利未記 4:25; 利未記 4:34"> 祭司要用手指取一些血，抹在燔祭壇的犄角上，然後把其餘的血全都倒在祭壇的基座那裡。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 4:26; 利未記 4:35; 利未記 1:9"> 他要取出全部的脂肪，就像從平安祭的祭牲上取下脂肪那樣。祭司要把這些在祭壇上燒獻為煙，作馨香之氣獻給耶和華。這樣，祭司為他贖罪，他就得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未記 4:28; 彼得前書 3:18; 彼得前書 2:22"> 「他如果是帶來一隻綿羊羔作為贖罪祭，就要帶來一隻無瑕疵的母羊。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 4:29–31; 利未記 4:4"> 他要按手在贖罪祭牲的頭上，在宰殺燔祭牲的地方把牠宰殺作贖罪祭。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 4:30; 利未記 4:25; 利未記 4:7"> 祭司要用手指取一些贖罪祭的血，抹在燔祭壇的犄角上，然後把其餘的血全都倒在祭壇的基座那裡。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 4:26; 利未記 4:20; 利未記 14:18"> 他要取出綿羊的全部脂肪，就像從平安祭的祭牲上取下脂肪那樣；祭司要把這些與耶和華的火祭一起在祭壇上燒獻為煙。這樣，祭司為他所犯的罪贖罪，他就得到赦免。</span>
</div>

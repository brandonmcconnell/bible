<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="LEV" data-book-slug="leviticus" data-book-name="利未記" data-chapter="8" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 28:2–4; 出埃及記 39:41; 希伯來書 7:27"> 「你要把亞倫和他的兒子們帶來，也帶來聖衣、膏油、贖罪祭的公牛、兩隻公綿羊和一籃子無酵餅，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 30:13; 使徒行傳 2:1; 尼希米記 8:1"> 然後招聚全體會眾到會幕入口。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 39:26; 出埃及記 39:7; 出埃及記 39:5"> 摩西就照著耶和華指示他的去做。於是會眾聚集到會幕入口，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 29:4–37"> 摩西對會眾說：「耶和華指示要做以下的事。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 6:11; 以弗所書 5:26; 出埃及記 29:4"> 摩西讓亞倫和他的兒子們上前來，用水洗淨他們。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 28:4; 以賽亞書 61:10; 加拉太書 3:27"> 然後給亞倫穿上袍子，束上腰帶，穿上外袍，套上以弗得，再用精巧的織帶束好以弗得，繫在他身上。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 2:63; 帖撒羅尼迦前書 5:8; 以賽亞書 59:17"> 再給他戴上胸牌，把烏陵和土明放在胸牌裡；</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 2:9–11; 撒迦利亞書 6:11–14; 出埃及記 28:36–38"> 最後把頂冠戴在亞倫頭上，在頂冠前面安上金牌，就是聖冠。這都是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:9–11; 利未記 8:2; 出埃及記 30:23–29"> 摩西拿著膏油，膏抹了帳幕和它裡面的一切，使它們分別為聖；</span>
<span className="v" id="v11" data-v="11" data-xref="提多書 3:6; 出埃及記 30:29; 出埃及記 16:19"> 又把一些膏油向祭壇彈灑七次，並膏抹了祭壇和祭壇的一切器具，以及洗濯盆和盆座，使它們分別為聖。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 30:30; 詩篇 133:2; 出埃及記 29:7"> 然後在亞倫頭上澆了一些膏油，膏抹他，使他分別為聖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 29:8–9; 啟示錄 5:10; 啟示錄 1:6"> 接著，摩西讓亞倫的兒子們上前來，給他們穿上袍子，束上腰帶，戴上頭巾，都是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 43:19; 詩篇 66:15; 彼得前書 3:18"> 摩西把贖罪祭的公牛牽來，亞倫和他的兒子們按手在贖罪祭公牛的頭上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 4:7; 希伯來書 9:18–23; 以西結書 43:19–27"> 宰殺後，摩西取了一些血，用手指抹在祭壇四圍的犄角上，潔淨祭壇，把其餘的血倒在祭壇的基座那裡，使祭壇分別為聖，為祭壇行贖罪禮。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 29:13; 利未記 3:3–5; 利未記 4:8–9"> 然後取出內臟上的全部脂肪、肝葉、兩個腎臟和腎臟的脂肪，摩西把這些在祭壇上燒獻為煙。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:11–12; 出埃及記 29:14; 利未記 6:30"> 公牛其餘的一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="其餘的一切——輔助詞語。">a</a></sup>——牠的皮、肉和糞便，都在營地外用火燒掉了。這都是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 8:2; 利未記 1:4–13; 出埃及記 29:15–18"> 接著，摩西把燔祭的公綿羊牽來，亞倫和他的兒子們按手在公綿羊的頭上。</span>
<span className="v" id="v19" data-v="19"> 宰殺後，摩西把血灑在祭壇四壁。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 1:8"> 公綿羊切成了塊，摩西就把頭、肉塊和板油燒獻為煙。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 5:2; 出埃及記 29:18; 利未記 1:17"> 用水洗淨內臟和腿之後，摩西把整隻公綿羊在祭壇上燒獻為煙。這是馨香的燔祭，是獻給耶和華的火祭，都是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 8:2; 利未記 8:29; 出埃及記 29:19–31"> 接著，摩西牽來第二隻公綿羊，就是聖職禮所用的公綿羊，亞倫和他的兒子們按手在公綿羊的頭上。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:20; 利未記 14:14; 羅馬書 12:1"> 宰殺後，摩西取了一些血，抹在亞倫的右耳垂上，以及右手拇指和右腳拇趾上。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:18–22"> 又讓亞倫的兒子們上前來，摩西把一些血抹在他們的右耳垂上，以及右手拇指和右腳拇趾上，然後摩西把血灑在祭壇四壁。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 3:9; 利未記 3:3–5; 以賽亞書 53:10"> 接著取下了脂肪、肥尾巴、內臟上的全部脂肪、肝葉、兩個腎臟和腎臟的脂肪，以及右腿，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 29:23; 提摩太前書 2:5; 使徒行傳 5:12"> 又從耶和華面前的無酵餅籃子中取出一個無酵餅、一個油餅、一個薄餅，放在脂肪和右腿上。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 30:21; 希伯來書 9:14; 出埃及記 29:24–37"> 摩西把這一切放在亞倫手上以及他兒子們的手上，作為搖獻祭物在耶和華面前搖一搖。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 29:25; 詩篇 22:13–14; 希伯來書 10:14–22"> 然後，摩西從他們手上把這些接過來，連同燔祭在祭壇上燒獻為煙；這些是馨香的聖職祭，是獻給耶和華的火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 10:31; 彼得前書 4:11; 利未記 7:30–34"> 摩西又拿起胸肉，作為搖獻祭物在耶和華面前搖一搖；這是聖職禮所用的公綿羊中給摩西的份，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 29:21; 民數記 3:3; 出埃及記 30:30"> 摩西取了一些膏油和祭壇上的血，彈灑在亞倫的身上和衣服上，以及他兒子們的身上和衣服上，使亞倫和他的衣服，以及他兒子們和他們的衣服分別為聖。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 29:31–32; 加拉太書 2:20; 撒母耳記上 2:13–17"> 摩西對亞倫和他的兒子們說：「你們要在會幕的入口煮祭肉，在那裡吃這肉和聖職祭籃子裡的餅，正如我所受的吩咐<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我所受的吩咐——依據有些古抄本；馬索拉文本作「我所吩咐的說」。">b</a></sup>：亞倫和他的兒子們要吃這些。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 29:34; 出埃及記 12:10; 希伯來書 3:13–14"> 剩下的肉和餅，都要用火燒掉。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 29:35; 民數記 19:12; 以西結書 43:25–27"> 七天之內，你們不可走出會幕入口，直到你們聖職禮日期滿了的那天為止，因為你們承接聖職需要七天。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 7:27; 希伯來書 7:16; 希伯來書 10:11–12"> 今天所做的，是耶和華吩咐要做的，為你們贖罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 3:7; 申命記 11:1; 列王紀上 2:3"> 七天之內，你們要日夜留在會幕入口，謹守耶和華的要求，以免你們死亡；我是如此受的吩咐。」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 12:32; 申命記 4:2; 出埃及記 40:16"> 於是亞倫和他的兒子們，遵行了耶和華藉著摩西所指示的一切事。</span>
</div>
</div>

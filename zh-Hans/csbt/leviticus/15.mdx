<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 3:7; 利未記 13:1; 利未記 11:1"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 5:2; 撒母耳記下 3:29; 利未記 22:4"> 「你們要吩咐以色列子民，對他們說：凡是身患漏症的人，他就因這漏症不潔淨了。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 23:20; 以西結書 16:26; 利未記 12:3"> 他因漏症而不潔淨的情況如下：無論身體流出泄漏物，還是身體封閉了泄漏物，這些都使他不潔淨。</span>
<span className="v" id="v4" data-v="4" data-xref="提多書 1:15; 以弗所書 5:11; 哥林多前書 15:33"> 漏症患者所躺臥的任何床鋪，都不潔淨；所坐上的任何物件，也都不潔淨。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 11:25; 利未記 16:26; 利未記 17:15"> 觸碰他床鋪的人，要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 4:8; 以賽亞書 1:16"> 坐上那漏症患者所坐物件的人，要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v7" data-v="7"> 觸碰漏症患者身體的人，要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v8" data-v="8" data-xref="猶大書 1:4; 彼得後書 2:1–3; 以賽亞書 1:16"> 如果漏症患者吐唾沫在一個潔淨的人身上，這人就要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:34"> 漏症患者騎上的任何鞍子，都會不潔淨。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 4:8; 詩篇 26:6; 利未記 15:8"> 凡是觸碰他身下任何東西的人，都會不潔淨直到傍晚；拿起這些東西的人，要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v11" data-v="11"> 漏症患者沒有用水洗手而觸碰了任何人，這人就要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 6:28; 利未記 11:32–33; 哥林多後書 5:1"> 漏症患者所觸碰的瓦器要打碎，木器都要用水沖洗。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 14:8; 利未記 8:33; 利未記 15:28"> 「當漏症患者的漏症得潔淨了，他還要為自己得潔淨數算七天，然後洗衣服，用活水洗身，這樣他就潔淨了。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 12:8; 利未記 12:6; 希伯來書 10:10"> 第八天他要帶上兩隻斑鳩或兩隻雛鴿，來到會幕入口耶和華面前，把牠們交給祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 14:30–31; 利未記 4:26; 馬太福音 3:17"> 祭司要獻上牠們，一隻作贖罪祭，一隻作燔祭。這樣，祭司就為這人的漏症，在耶和華面前為他贖了罪。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 23:10–11; 利未記 22:4; 利未記 15:5"> 「如果一個男人遺精，他要用水洗全身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v17" data-v="17"> 任何衣物或皮革沾上了精液，都要用水清洗，並且會不潔淨直到傍晚。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 15:5; 帖撒羅尼迦前書 4:3–5; 哥林多前書 6:12"> 如果男人與女人同寢交合，他們要用水洗身，並且會不潔淨直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 12:2; 馬太福音 15:19; 馬可福音 5:25"> 「如果一個女人流液，下體流出的是血，她就有七天的汙穢期。凡是觸碰她的，都會不潔淨直到傍晚。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 15:4–9; 箴言 2:16–19; 箴言 6:35"> 她在經期所躺的任何物件都會不潔淨，所坐的任何物件也都會不潔淨。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 7:14; 哥林多後書 7:1; 以賽亞書 22:14"> 凡是觸碰她床鋪的人，都要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v22" data-v="22"> 凡是觸碰她所坐任何物件的人，都要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
<span className="v" id="v23" data-v="23"> 即使是那床鋪上或她所坐物件上的東西，如果有人觸碰了，也會不潔淨直到傍晚。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 20:18; 彼得前書 2:11; 利未記 18:19"> 如果有男人竟然與那女人同寢，以致女人的汙穢沾上了他，他就會不潔淨七天，他所躺的床鋪也都會不潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬可福音 5:25; 馬太福音 9:20; 路加福音 8:43"> 「如果一個女人在非經期流血多日，或者過了經期還在流血，她在流出汙穢的整個期間就像在經期一樣，都是不潔淨的。</span>
<span className="v" id="v26" data-v="26"> 她在這漏症的整個期間，所躺的任何床鋪，都像經期的床鋪那樣，是不潔淨的；她所坐的任何物件，也都像她經期時那樣，是不潔淨的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 15:21; 希伯來書 10:22; 利未記 17:15–16"> 凡是觸碰這些東西的人，都會不潔淨，要洗衣服，用水洗身，並且會不潔淨直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="利未記 15:13–15; 加拉太書 3:13; 以弗所書 1:6–7"> 「當她的漏症得潔淨了，她還要為自己數算七天，之後她就潔淨了。</span>
<span className="v" id="v29" data-v="29"> 第八天她要帶上兩隻斑鳩或兩隻雛鴿，帶到會幕入口給祭司。</span>
<span className="v" id="v30" data-v="30"> 祭司要獻上一隻作贖罪祭，一隻作燔祭。這樣，祭司就為她漏症的不潔，在耶和華面前為她贖了罪。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民數記 19:20; 民數記 19:13; 以西結書 5:11"> 「你們要使以色列子民遠離這些不潔，以免我在他們中間的帳幕被他們的不潔所玷汙，以致他們死亡。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 11:46; 利未記 13:59; 民數記 6:13"> 以上條例適用於漏症患者，遺精而不潔淨的男人，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 15:19; 利未記 20:18; 利未記 15:24–25"> 經期的女人，其他情況流液的男人或女人，以及與不潔期間的女人同寢的男人。」</span>
</div>
</div>

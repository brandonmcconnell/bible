<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 18:21; 申命記 15:19; 利未記 22:32"> 「你要吩咐亞倫和他的兒子們，謹慎對待以色列子民所分別為聖歸於我的聖物，以免褻瀆我的聖名。我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 7:20–21; 民數記 19:13; 詩篇 16:11"> 你要對他們說：你們世世代代所有的後裔中，凡是身上不潔淨的人，如果接近了以色列子民所分別為聖歸於耶和華的聖物，這人就要從我的面前被剪除。我是耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 11:39; 利未記 15:2–3; 利未記 15:13–16"> 亞倫後裔中，凡是患痲瘋病或有漏症的人，在得潔淨之前，不可吃聖物。如果有人觸碰任何因屍體而不潔淨的東西，或有人遺精，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 11:43–44; 利未記 15:7; 利未記 15:19"> 或有人觸碰任何使他不潔淨的群居爬物，觸碰使他不潔淨的人——不管那人有怎樣的不潔——</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 15:5; 希伯來書 10:22; 哈該書 2:13"> 如果有人觸碰了這些，他就不潔淨直到傍晚，除非他用水洗身，否則不可吃聖物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 21:22; 申命記 18:3–4; 哥林多前書 9:13–14"> 日落時，他就潔淨了，之後他可以吃聖物，因為這是他的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 17:15; 出埃及記 22:31; 以西結書 44:31"> 他不可吃自然死去的或被咬死的動物，使自己受玷汙。我是耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 28:43; 民數記 18:22; 民數記 18:32"> 他們要謹守我的吩咐，以免他們因褻瀆了聖物，就承擔罪過而死。我是把他們分別為聖的耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 12:4; 撒母耳記上 21:6; 出埃及記 29:33"> 「祭司家以外的任何人都不可吃聖物，祭司家裡的客居者和雇工，也不可吃聖物。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:13; 出埃及記 12:44; 民數記 18:11–13"> 但如果是祭司用銀子買來的人，這人可以吃聖物；在祭司家裡出生的人，也可以吃祭司的食物。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 40:13; 利未記 21:3"> 祭司的女兒如果嫁給祭司家以外的男人，她就不可吃供上的聖物。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 10:14; 創世記 38:11; 民數記 18:11–19"> 但祭司的女兒如果成了寡婦或被休了，而且沒有後裔，又像她年幼時那樣回到她的父家，就可以吃她父親的食物；祭司家以外的任何人，都不可吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 27:15; 利未記 27:13; 利未記 5:15–19"> 如果有人無意中吃了聖物，就要把聖物加上五分之一，交還給祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 18:32; 利未記 19:8; 以西結書 22:26"> 不可褻瀆以色列子民獻給耶和華的聖物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 22:9; 彼得前書 2:24; 以賽亞書 53:11–12"> 使人們因吃了聖物而承擔罪責。要知道，我是把他們分別為聖的耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華指示摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 1:2; 申命記 12:6; 民數記 15:3"> 「你要吩咐亞倫和他的兒子們，以及所有的以色列子民，對他們說：凡是以色列家中或以色列中寄居的人，如果要獻上他的祭物，無論是還願祭或是獻給耶和華為燔祭的甘心祭，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 1:10; 利未記 1:3; 以弗所書 5:27"> 都必須是無瑕疵的公牛、公綿羊或公山羊，使你們可蒙悅納。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 17:1; 瑪拉基書 1:8; 申命記 15:21"> 任何身上有殘疾的祭牲，你們都不可獻上，因為牠不能代表你們蒙悅納。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 15:8; 民數記 15:3; 利未記 3:6"> 「如果有人從牛群或羊群中帶來平安祭物獻給耶和華，無論是還特殊的願或是作甘心祭，都必須是無瑕疵的，才蒙悅納，牠身上不可有任何殘疾。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 22:20; 瑪拉基書 1:8; 利未記 1:9"> 瞎眼的、骨折的、傷殘的、有瘤子的、生癬的、長疥的，這些都不可獻給耶和華，不可作為火祭在祭壇上獻給耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 21:18"> 肢體過長或過短的牛羊，可以作甘心祭獻上，但作還願祭，就不會蒙悅納。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 22:20; 申命記 23:1; 利未記 21:20"> 睾丸被挫傷、壓碎、破裂或騸割的，都不可獻給耶和華。在你們的地上，不可這樣做，</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 21:8; 以斯拉記 6:8–10; 民數記 15:14–16"> 也不可接受外邦人手中任何這樣的牲畜，作你們神的食物獻上；因為這些身上有損傷、有殘疾的，不能代表你們蒙悅納。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華指示摩西說：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 22:30; 利未記 19:23–24; 利未記 22:25"> 「剛出生的公牛、綿羊或山羊，當跟著牠母親七天，從第八天開始可以蒙悅納為祭牲，獻給耶和華作火祭。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 22:6–7; 申命記 14:21; 出埃及記 34:26"> 不可在同一天，把牛或羊與牠的幼仔一起宰殺了。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 116:17; 詩篇 107:22; 阿摩司書 4:5"> 當你們獻上感謝祭給耶和華時，要獻得使你們可蒙悅納；</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 7:15–18; 出埃及記 16:19–20; 利未記 19:7"> 要當天吃掉祭物，一點也不可留到次日早晨。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 4:40; 利未記 19:37; 民數記 15:40"> 「你們要謹守遵行我的誡命。我是耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 18:21; 路加福音 11:2; 馬太福音 6:9"> 你們不可褻瀆我的聖名，我在以色列子民中要被尊為聖。我是把你們分別為聖的耶和華，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 11:45; 出埃及記 6:7; 利未記 25:38"> 是我把你們從埃及地領出來，為要作你們的神。我是耶和華。」</span>
</div>

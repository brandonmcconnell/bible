<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="LEV" data-book-slug="leviticus" data-book-name="利未記" data-chapter="16" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 10:1–2"> 亞倫的兩個兒子上前到耶和華面前時死了；他們死後，耶和華對摩西說話。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 30:10; 列王紀上 8:10–12; 希伯來書 10:19–20"> 耶和華對摩西說：「你要吩咐你哥哥亞倫，他不可隨時隨意進入幔子內的聖所，到見證櫃上的施恩座前，以免他死亡，因為我要在施恩座上的雲中顯現。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 4:3; 希伯來書 9:24–25; 希伯來書 9:7"> 「亞倫要這樣進入聖所：他要帶一頭公牛作贖罪祭，一隻公綿羊作燔祭；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 28:39–43; 以西結書 44:17–18; 出埃及記 30:20"> 要穿上細麻聖袍，貼身穿上細麻褲子，束上細麻腰帶，戴上細麻頂冠。這些是聖衣，他要用水洗身，然後穿上它們。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:21; 利未記 8:2; 以斯拉記 6:17"> 他還要從以色列會眾那裡帶來兩隻公山羊作贖罪祭，一隻公綿羊作燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 9:7; 希伯來書 9:7; 希伯來書 7:27"> 「亞倫要獻上他的贖罪祭公牛，為自己和家人贖罪。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 12:1; 利未記 4:4; 馬太福音 16:21"> 然後牽來那兩隻公山羊，讓牠們站在會幕入口耶和華面前。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:23–26; 約拿書 1:7; 箴言 16:33"> 亞倫要為那兩隻公山羊抽籤，一支籤是要歸耶和華，一支籤是要作除罪羊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="除罪羊——或譯作「離去的羊」；原文音譯為「阿撒瀉勒」。本章下同。">a</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:27–28; 使徒行傳 2:23"> 亞倫要把那隻抽中籤歸耶和華的公山羊獻為贖罪祭；</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 2:2; 利未記 16:21–22; 希伯來書 9:23–24"> 至於那隻抽中籤作除罪羊的公山羊，要讓牠活著站在耶和華面前，用於贖罪，要釋放牠到曠野作除罪羊。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 16:6; 希伯來書 7:27; 希伯來書 9:7"> 「亞倫要獻上他的贖罪祭公牛，為自己和家人贖罪，把那頭為自己作贖罪祭的公牛宰殺了，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 10:1; 出埃及記 30:34–38; 啟示錄 8:3–4"> 然後拿來香爐，盛滿耶和華面前祭壇上的火炭，並且帶著一滿捧細碎的芬芳香，拿進幔子內。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 25:21; 出埃及記 30:1; 出埃及記 30:7–8"> 他要在耶和華面前把香放在火上，使香的煙雲遮掩見證櫃上的施恩座，以免他死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:25; 利未記 4:5–6; 希伯來書 9:13"> 他要取一些公牛的血，用手指彈灑在施恩座朝東那面，再用手指把一些血向施恩座前面彈灑七次。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 9:7; 希伯來書 2:17; 希伯來書 9:3"> 「接著，他要把百姓的那隻贖罪祭公山羊宰殺了，把血帶進幔子內，要像處理公牛的血那樣處理羊的血，把血彈灑在施恩座上和施恩座前面。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 9:22–23; 利未記 16:18; 以西結書 45:18–19"> 他要這樣為聖所行贖罪禮，除去以色列子民一切罪惡所帶來的汙穢和過犯。他也要為會幕照樣做，因為會幕安置在他們那裡，在他們的汙穢當中。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 53:6; 路加福音 1:10; 出埃及記 34:3"> 當亞倫進入聖所行贖罪禮時，任何人都不可留在會幕中，直到他出來。他為自己和家人、為以色列全體會眾行了贖罪禮，</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:7; 希伯來書 5:7–8; 利未記 16:16"> 之後要出來，到耶和華面前的祭壇那裡，為祭壇行贖罪禮。他要取一些公牛的血和公山羊的血，抹在祭壇四圍的犄角上，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 13:1; 以西結書 43:18–22"> 並且用手指把一些血向祭壇彈灑七次。這樣，他就潔淨了祭壇，使祭壇分別為聖，除去了以色列子民帶來的汙穢。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未記 16:16; 以西結書 45:20; 歌羅西書 1:20"> 「亞倫為聖所、會幕和祭壇完成了贖罪禮之後，就要把那隻活的公山羊帶上來。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 53:6; 哥林多後書 5:21; 以斯拉記 10:1"> 亞倫要雙手按在那隻活的公山羊頭上，在牠身上承認以色列子民的一切罪孽和過犯，無論什麼罪惡，都歸到那隻公山羊頭上，然後藉著指定的人把牠釋放到曠野去。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 9:28; 以賽亞書 53:11–12; 約翰福音 1:29"> 這樣，那隻公山羊背負以色列人的一切罪孽到荒蕪之地，那人就要在曠野裡把公山羊釋放了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西結書 44:19; 以西結書 42:14; 利未記 16:4"> 「然後亞倫要回到會幕，把他進聖所時穿上的那些細麻聖衣脫下，留在那裡。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 16:3–5; 希伯來書 10:19–22; 出埃及記 28:4–14"> 他要在神聖的地方用水洗身，穿上他的衣服，然後出來，把自己的燔祭和百姓的燔祭獻上，為自己和百姓贖罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 29:13; 利未記 4:8–10; 利未記 16:6"> 他要把贖罪祭的脂肪在祭壇上燒獻為煙。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 16:10; 希伯來書 7:19; 民數記 19:21"> 那釋放除罪羊的人，要洗衣服，用水洗身，之後才可以進入營地。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 4:21; 利未記 6:30; 利未記 4:11–12"> 至於贖罪祭公牛和贖罪祭公山羊，牠們的血已經帶進了聖所贖罪，牠們要被搬運到營地外，皮、肉和糞便都要用火燒掉。</span>
<span className="v" id="v28" data-v="28"> 焚燒這些東西的人也要洗衣服，用水洗身，之後才可以進入營地。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 58:3; 民數記 29:7; 出埃及記 20:10"> 「以下是你們永遠的律例：每年的七月十日，你們要刻苦己心，無論是本族人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="本族人——原文直譯「本地人」。">b</a></sup>還是寄居在你們中間的外人，任何工作都不可做。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 33:8; 詩篇 51:2; 以弗所書 5:26"> 因為在這一天，要為你們行贖罪禮，使你們潔淨；你們必須在耶和華面前得潔淨，脫離你們一切的罪惡。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 23:32; 以賽亞書 58:5; 利未記 25:4"> 這是你們完全安息的安息日，你們要刻苦己心；這是永遠的律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 16:4; 出埃及記 29:29–30; 利未記 4:5"> 那被膏立接續他父親承接聖職的祭司，要行贖罪禮，他要穿上細麻聖衣，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 16:16; 利未記 16:24; 利未記 16:6"> 為至聖所行贖罪禮，為會幕和祭壇行贖罪禮，也為祭司和全體會眾行贖罪禮。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 9:7; 希伯來書 9:25; 出埃及記 30:10"> 這要作為你們永遠的律例，每年一次為以色列子民贖他們一切的罪。」<br />耶和華所指示摩西的，他都遵行了。</span>
</div>
</div>

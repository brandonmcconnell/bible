<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 馬可福音 1:40–44"> 「以下是痲瘋病人潔淨之日的條例：他要被帶到祭司那裡；</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要來到營地外，然後祭司查看他，如果痲瘋病人身上的痲瘋病已經痊癒了，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 19:6; 利未記 14:6; 希伯來書 9:19"> 祭司就要吩咐為那求潔淨的人取來兩隻潔淨的活鳥，以及香柏木、朱紅色線和牛膝草。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 14:50; 希伯來書 2:14; 哥林多後書 5:1"> 祭司要吩咐人在瓦器裡的活水上方，宰殺一隻鳥。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:5; 撒迦利亞書 13:1; 腓立比書 2:9–11"> 然後，祭司要拿來另一隻活鳥，以及香柏木、朱紅色線和牛膝草，把這些物品與活鳥一起，蘸在那活水上方被宰殺的鳥血中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 以西結書 36:25; 以賽亞書 52:15"> 祭司要向那脫離痲瘋病求潔淨的人彈灑血七次，判定他為潔淨，最後在田野上釋放那隻活鳥。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 11:25; 民數記 8:7; 彼得前書 3:21"> 那求潔淨的人要洗衣服，剃掉身上所有的毛髮，用水洗身，這樣他就潔淨了。之後，他可以進入營地，但必須住在自己的帳篷外七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 6:9; 利未記 14:8; 民數記 8:7"> 到了第七天，他要再剃掉身上所有的毛，把他的頭髮、鬍鬚、眉毛以及全身的毛都剃掉。然後洗衣服，用水洗身，他就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 2:1; 馬太福音 8:4; 路加福音 5:14"> 「第八天，他要帶來兩隻無瑕疵的公羊羔，一隻無瑕疵的一歲母羊羔，以及十分之三伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之三伊法——相當於6.6公升。1伊法=22公升。">a</a></sup>調了油的素祭細麵粉，還有一羅格<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一羅格——相當於0.3公升；本章下同。">b</a></sup>油。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 5:26–27; 出埃及記 29:1–4; 民數記 8:21"> 舉行潔淨禮的祭司，要讓那求潔淨的人帶著這些祭物，站在會幕入口耶和華面前。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 29:24; 利未記 6:6–7; 利未記 8:27–29"> 然後祭司要取一隻公羊羔，獻為贖愆祭，連同那一羅格油，作為搖獻祭物在耶和華面前搖一搖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 29:11; 利未記 1:11; 利未記 4:24"> 他要在宰殺贖罪祭牲和燔祭牲的聖所那裡，宰殺那隻公羊羔；這贖愆祭牲就像贖罪祭一樣，要歸於祭司，這是至聖的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 29:20; 利未記 8:23–24; 哥林多後書 7:1"> 祭司要取一些贖愆祭牲的血，抹在那求潔淨的人右耳垂上，以及他右手拇指和右腳拇趾上。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 45:7; 約翰福音 3:34; 約翰一書 2:20"> 祭司要從那一羅格油中取一些，倒在他左手掌裡，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:17; 哥林多前書 10:31; 利未記 4:6"> 然後把右手指蘸在左手掌裡的油中，用手指把一些油在耶和華面前彈灑七次。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 1:2; 以西結書 36:27; 利未記 14:14"> 祭司要把手掌裡剩下的一些油，抹在那求潔淨的人右耳垂上，以及他右手拇指和右腳拇趾上，就是在抹贖愆祭牲之血的地方；</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:26; 哥林多後書 1:21–22; 以弗所書 1:17–18"> 祭司手掌裡剩下的油，要抹在那求潔淨之人的頭上。然後，祭司要在耶和華面前為那人贖罪。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 14:12; 利未記 5:1; 利未記 12:6–8"> 祭司要獻上贖罪祭，為那脫離汙穢求潔淨的人贖罪。隨後，他要宰殺燔祭牲，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 14:10; 以弗所書 5:2; 利未記 14:8"> 祭司要把燔祭和素祭獻在祭壇上。這樣，祭司為那人贖罪，那人就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 5:7; 利未記 12:8; 箴言 17:5"> 「如果那人貧困，負擔不起這些，他可以取來一隻公羊羔作贖愆祭，作為搖獻祭物為他贖罪；並取來十分之一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之一伊法——相當於2.2公升。1伊法=22公升。">c</a></sup>調了油的細麵粉作素祭，還有一羅格油，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 7:16; 以賽亞書 59:11; 耶利米書 48:28"> 以及他負擔得起的兩隻斑鳩或兩隻雛鴿，一隻作贖罪祭，一隻作燔祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 14:10–11"> 第八天，他要為了得潔淨把這些帶到會幕入口耶和華面前，帶到祭司那裡。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 14:12; 利未記 14:10"> 祭司要取來那隻贖愆祭羊羔和那一羅格油，作為搖獻祭物在耶和華面前搖一搖。</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 5:1; 詩篇 40:6; 利未記 14:14–20"> 宰殺贖愆祭羊羔後，祭司要取一些贖愆祭的血，抹在那求潔淨的人右耳垂上，以及他右手拇指和右腳拇趾上。</span>
<span className="v" id="v26" data-v="26"> 祭司要倒一些油在他左手掌裡，</span>
<span className="v" id="v27" data-v="27"> 然後用右手指，把左手掌裡的一些油在耶和華面前彈灑七次。</span>
<span className="v" id="v28" data-v="28"> 接著，祭司要把手掌裡的一些油，抹在那求潔淨的人右耳垂上，以及他右手拇指和右腳拇趾上，就在抹贖愆祭牲之血的地方。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 14:18; 約翰一書 2:1–2; 出埃及記 30:15–16"> 祭司手掌裡剩下的油，要抹在那求潔淨之人的頭上，在耶和華面前為他贖罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 14:22; 羅馬書 8:3; 利未記 12:8"> 然後他要獻上一隻負擔得起的斑鳩或雛鴿，</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 14:18; 利未記 5:7"> 獻上他負擔得起的一隻作贖罪祭，一隻作燔祭，都與素祭一起獻上。這樣，祭司就在耶和華面前為那求潔淨的人贖罪了。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 14:10; 利未記 14:21; 馬太福音 11:5"> 這是關於那染上痲瘋病的人負擔不起潔淨禮的條例。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和華指示摩西和亞倫說：</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 32:49; 創世記 17:8; 民數記 32:22"> 「你們進入我所賜給你們為產業的迦南地後，如果我使你們產業之地的房屋中有了痲瘋菌斑，</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 91:10; 申命記 7:26; 撒迦利亞書 5:4"> 那房屋的主人要來告訴祭司，說：『我房屋裡好像有痲瘋菌斑出現。』</span>
<span className="v" id="v36" data-v="36" data-xref="啟示錄 18:4; 希伯來書 12:15; 提摩太後書 2:17–18"> 祭司要在過去查看那菌斑之前，吩咐把房屋搬空，免得房屋裡的東西全都成為不潔淨的。然後祭司要過去查看那房屋。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 13:42; 利未記 13:3; 利未記 13:19–20"> 祭司查看後，如果發現房屋牆上的菌斑是綠色或紅色的霉斑，症狀深入牆內，</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 13:50"> 祭司就要從房屋裡出來，到門口，封閉房屋七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未記 13:36; 利未記 13:27; 利未記 13:22"> 到第七天祭司要回來查看，如果菌斑在房屋的牆上擴散了，</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 2:20; 提多書 3:10; 哥林多前書 5:5–6"> 祭司就要吩咐把那些有菌斑的磚石拆掉，扔到城外不潔淨的地方；</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 65:4; 啟示錄 22:15; 馬太福音 24:51"> 再把房屋裡四面都刮乾淨，把刮掉的灰泥倒在城外不潔淨的地方；</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太後書 2:2; 提摩太前書 5:21–22; 歷代志下 17:7–9"> 然後用別的磚石取代原來的磚石，用別的灰泥粉刷房屋。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米書 6:28–30; 猶大書 1:12; 彼得後書 2:20"> 「如果拆掉那些磚石、刮了房屋又粉刷以後，菌斑在房屋裡再次發散，</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 13:51–52; 撒迦利亞書 5:4"> 祭司就要進去查看，如果菌斑在房屋裡確實擴散了，這就是房屋裡的惡性痲瘋，它是不潔淨的。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 10:27; 馬太福音 24:2; 列王紀上 9:6–9"> 這房屋就要被拆毀，磚石、木頭和房屋的灰泥都要搬運到城外不潔淨的地方。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 19:21–22; 利未記 22:6; 利未記 11:28"> 房屋被封閉的整個期間，進入這房屋的人，會不潔淨直到傍晚；</span>
<span className="v" id="v47" data-v="47" data-xref="利未記 14:8–9; 利未記 11:25"> 在這房屋躺臥的人，要洗自己的衣服；在這房屋吃喝的人，也要洗自己的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前書 6:11; 約伯記 5:18; 馬可福音 5:29"> 「但如果祭司進去查看，發現房屋粉刷以後，菌斑並沒有在房屋裡擴散，祭司就要判定這房屋為潔淨，因為這痲瘋已經治好了。</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 14:4"> 為了使這房屋得潔淨，祭司要取來兩隻鳥，以及香柏木、朱紅色線和牛膝草；</span>
<span className="v" id="v50" data-v="50"> 在瓦器裡的活水上方宰殺一隻鳥，</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 51:7"> 然後取來香柏木、牛膝草、朱紅色線以及另一隻活鳥，蘸在那被宰殺的鳥的血和活水中，向房屋彈灑這血水七次。</span>
<span className="v" id="v52" data-v="52"> 祭司用鳥血、活水、活鳥、香柏木、牛膝草和朱紅色線潔淨了房屋，</span>
<span className="v" id="v53" data-v="53" data-xref="利未記 14:20; 利未記 14:7"> 然後要把那隻活鳥釋放到城外的田野上。這樣，他為房屋贖罪，房屋就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未記 15:32; 利未記 14:32; 利未記 6:9"> 「以上條例，適用於各種痲瘋病、癲癇，</span>
<span className="v" id="v55" data-v="55" data-xref="利未記 13:47–59"> 衣物上或房屋上的痲瘋，</span>
<span className="v" id="v56" data-v="56" data-xref="利未記 13:2"> 丘疹、疥癬、斑點，</span>
<span className="v" id="v57" data-v="57" data-xref="利未記 10:10; 以西結書 44:23; 耶利米書 15:19"> 用於指示什麼時候不潔淨、什麼時候潔淨。這是關於痲瘋的條例。」</span>
</div>

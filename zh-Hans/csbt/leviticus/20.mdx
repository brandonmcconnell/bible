<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 21:21; 利未記 18:21; 利未記 20:27"> 「你要吩咐以色列子民：凡是把兒女獻給摩洛的人，無論他是以色列人還是寄居在以色列的外人，必須被處死，這地的民眾要用石頭砸死他。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 18:21; 以西結書 5:11; 以西結書 23:38–39"> 我必對那人翻臉，把他從民中剪除，因為他把他的兒女獻給摩洛，以致玷汙了我的聖所，褻瀆了我的聖名。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 17:2–5; 使徒行傳 17:30; 列王紀上 20:42"> 當那人把他的兒女獻給摩洛時，如果這地的民眾對那人閉眼不管，不把他處死，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:39; 何西阿書 2:13; 何西阿書 2:5"> 我就會親自對那人和他的家族翻臉，把他和所有跟著他行淫追隨摩洛的人，從民中剪除。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 19:31; 以賽亞書 8:19; 利未記 20:27"> 「如果有人轉向招魂的和通靈的，去行淫追隨他們，我必對那人翻臉，把他從民中剪除。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 11:44; 利未記 19:2; 彼得前書 1:15–16"> 你們要使自己分別為聖，要聖潔，因為我是耶和華你們的神。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 31:13; 雅各書 1:22; 帖撒羅尼迦前書 5:23"> 你們要謹守遵行我的律例。我是把你們分別為聖的耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 21:17; 馬可福音 7:10; 申命記 27:16"> 「凡是詛咒父母的人，必須被處死；他詛咒了自己的父母，他的血債歸在自己身上。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:4–5; 申命記 22:22–24; 申命記 5:18"> 凡是與別人的妻子通姦的，與鄰人的妻子通姦的，這姦夫和淫婦都必須被處死。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 27:20; 申命記 27:23; 阿摩司書 2:7"> 凡是與父親的妻妾同寢的人，他是裸露父親的下體，這二人必須被處死，他們的血債歸在自己身上。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:15; 利未記 18:23; 創世記 38:18"> 凡是與自己兒媳同寢的，這二人必須被處死；他們做了亂倫的事，他們的血債歸在自己身上。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 6:9; 利未記 18:22; 猶大書 1:7"> 如果有男人與男人同寢，像與女人同寢那樣，這二人是做了可憎之事，必須被處死，他們的血債歸在自己身上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 18:17; 申命記 27:23; 約書亞記 7:15"> 如果有人娶了妻子，又娶她的母親，這是醜惡的，必須把這三人用火燒死，這樣你們中間就不會有醜惡的事。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 18:23; 申命記 27:21; 出埃及記 22:19"> 如果有男人與動物交合，他必須被處死，也要把那動物殺掉。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 21:32; 出埃及記 19:13; 希伯來書 12:20"> 如果有女人親近任何動物與牠交合，必須把那女人和那動物殺掉，他們必須被處死，他們的血債歸在自己身上。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 18:9; 申命記 27:22; 以西結書 22:11"> 如果有人娶了自己的姐妹——無論是他父親的女兒還是他母親的女兒——他看了姐妹的下體，姐妹也看了他的下體，這是可恥的事，他們必在族人面前被剪除。他裸露了自己姐妹的下體，必須承擔自己的罪責。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 15:24; 利未記 18:19; 以西結書 18:6"> 如果有人與經期<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="經期——或譯作「血漏」。">a</a></sup>的女人同寢，裸露她的下體，那是裸露她的血源，女人也裸露了自己的血源，他們二人必須從民中被剪除。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 18:6; 利未記 18:12–30; 出埃及記 6:20"> 不可裸露你姨母或姑母的下體；這是裸露自己血親的下體，他們必須承擔自己的罪責。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 18:14; 約伯記 18:19; 路加福音 23:29"> 如果有人與自己的叔母伯母同寢，這是裸露他叔伯的下體，他們必須承擔自己的罪過，他們必沒有子女而死。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 18:16; 馬太福音 14:3–4"> 如果有人娶他兄弟的妻子，這是汙穢的事，是裸露他兄弟的下體，他們二人必沒有子女。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 18:25–28; 以西結書 36:27; 利未記 18:4–5"> 「你們要謹守遵行我的一切律例和法規，以免我所領你們去居住的那地把你們吐出來。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:5; 利未記 18:24; 利未記 18:30"> 我將從你們面前驅逐的那些民族，你們不可隨從他們的習俗；正是因為他們做了這一切，所以我厭惡他們，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 14:2; 出埃及記 6:8; 申命記 7:6"> 而對你們說：『你們要占有他們的土地；我要把這流奶與蜜之地賜給你們，讓你們繼承。』我是耶和華你們的神，把你們從萬民中分別出來的那一位。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 14:3–21; 利未記 11:1–47; 使徒行傳 10:11–15"> 你們要分別潔淨和不潔淨的走獸，分別不潔淨和潔淨的飛禽；不可因我給你們分別為不潔淨的走獸、飛禽和地上的一切爬蟲，使自己成為可憎的。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:15–16; 利未記 20:7; 利未記 20:24"> 你們要歸於我為聖，因為我耶和華是聖潔的，我已經把你們從萬民中分別出來，使你們歸於我。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 19:31; 利未記 20:6; 撒母耳記上 28:7–9"> 無論是男人還是女人，如果有誰作招魂的或通靈的，就必須被處死；要用石頭砸死他們，他們的血債歸在自己身上。」</span>
</div>

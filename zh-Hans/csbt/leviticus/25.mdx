<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="LEV" data-book-slug="leviticus" data-book-name="利未記" data-chapter="25" data-verses="55">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 1:1; 加拉太書 4:24–25; 出埃及記 19:1"> 耶和華在西奈山指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 36:21; 利未記 26:34–35; 出埃及記 23:10"> 「你要吩咐以色列子民，對他們說：當你們進入了我所賜給你們的那地，地要休耕，向耶和華守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 23:10"> 你們可以六年耕種田地，六年修剪葡萄園，收取地裡的出產。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 36:21; 利未記 25:20–23; 出埃及記 23:10–11"> 但在第七年，土地要有完全安息的安息年，是向耶和華守的安息年。不可耕種田地，也不可修剪葡萄園；</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:29; 以賽亞書 37:30"> 自長的莊稼，不可收割；未修剪的葡萄樹，也不可採收。土地要完全安息一年。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 2:44; 出埃及記 23:11; 使徒行傳 4:34–35"> 不過，土地在安息年中出產的，可以作你們的食物，給你們和你們的僕婢、雇工，以及居住在你們那裡的客居者吃；</span>
<span className="v" id="v7" data-v="7"> 這一切出產，也要給你們的牲畜和地上的走獸吃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="吃——或譯作「作食物」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 23:15; 創世記 2:2"> 「你要數算七個安息年，就是七個七年，這樣就有了七個安息年的年數，一共四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 23:24; 利未記 23:27; 帖撒羅尼迦前書 1:8"> 然後在七月十日，你要長鳴號角，要在這贖罪日使號角聲響遍全地。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 34:8; 以賽亞書 63:4; 彼得前書 2:16"> 你們要把第五十年分別為聖，在全地向所有的居民宣告自由。這是你們的禧年，你們各人要回歸自己的地業，回歸自己的家族。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 27:17; 利未記 25:4–5"> 這第五十年是你們的禧年，你們不可耕種，也不可收割自長的莊稼，不可採收未修剪的葡萄樹。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 25:6–7"> 因為這是禧年，你們要把它當作神聖的。你們要吃田地自長的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 25:10; 利未記 27:17–24; 民數記 36:4"> 「在這禧年，你們各人要回歸自己的地業。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 19:13; 利未記 25:17; 撒母耳記上 12:3–4"> 如果你們賣什麼東西給鄰人，或是從鄰人手中買東西，不可彼此虧負。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 27:18–23; 腓立比書 4:5"> 你要按禧年之後的年數向鄰人購買，他也要按收成的年數賣給你。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 25:27; 利未記 25:51"> 年數多就提高價格，年數少就降低價格，因為他賣給你的是收成的數量。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 19:14; 利未記 19:32; 利未記 25:43"> 你們不可彼此虧負，要敬畏你們的神；我是耶和華你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:6; 申命記 12:10; 箴言 1:33"> 「你們要遵行我的律例，謹守遵行我的法規，這樣你們就可以在那地安然居住。</span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:26; 詩篇 85:12; 利未記 26:5"> 那地必供應出產，使你們吃得飽足，在那裡安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 25:4; 路加福音 12:29; 民數記 11:4"> 如果你們說：『看哪，第七年不耕種，也不收獲出產，我們吃什麼呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:8; 箴言 10:22; 哥林多後書 9:10"> 要知道，我必在第六年賜下我的祝福給你們，使土地產出三年的收成。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 19:29; 利未記 26:10; 以賽亞書 37:30"> 這樣，第八年你們耕種時，還在吃陳年的出產；直到第九年，那年的出產收進來時，你們還在吃陳年的。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前書 2:11; 詩篇 39:12; 以西結書 48:14"> 「土地不可永久賣斷，因為地是我的，你們在我面前是佃戶、是寄居的。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 1:7; 利未記 25:51–53; 利未記 25:27"> 你們所得的任何土地，都要允許人有土地的贖回權。</span>
<span className="v" id="v25" data-v="25" data-xref="路得記 2:20; 耶利米書 32:7–8; 路得記 3:12"> 如果你的弟兄貧窮，以致賣了他的一些地產，他那有贖回權的近親就要來，贖回這弟兄所賣的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 5:7"> 如果沒有誰可為這人贖回地產，但他自己後來手頭寬裕了，有了足夠的錢來贖回，</span>
<span className="v" id="v27" data-v="27"> 他就要計算賣地的年數，把差額償還給那與他交易的人，這樣他就可以回歸自己的地業。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 35:9–10; 利未記 25:10; 彼得前書 1:4–5"> 但如果他手頭沒有足夠的錢贖回，他所賣的就要留在買主手中，直到禧年。不過到了禧年，那地就要退還，使原主回歸自己的地業。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 「如果有人賣了城牆內的住宅，他的贖回權在出售後的一整年有效，這期間他有贖回權。</span>
<span className="v" id="v30" data-v="30"> 如果滿了一整年沒有贖回，城牆內這棟房屋就要世世代代永久歸屬那買主，即使到了禧年也不必退還。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 49:7–8"> 但村莊的房屋，四圍無城牆，所以算為在郊外的地產，這些房屋有贖回權，到了禧年要退還。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約書亞記 21:1–45; 民數記 35:1–8"> 「至於利未人的城鎮，就是他們得為業的城，其中的房屋，利未人有永久贖回權。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 18:20–24; 申命記 18:1–2"> 如果有利未人無力贖回，他們得為業的城中所出售的房屋，到了禧年必須退還，因為利未人城裡的房屋是他們在以色列子民中的產業。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 25:23; 使徒行傳 4:36–37; 民數記 35:2–5"> 此外，他們城郊的牧野不可出售，因為那是他們永久的產業。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 15:7–8; 使徒行傳 11:29; 利未記 25:25"> 「如果你的弟兄貧窮，在你那裡無法維持生計<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="無法維持生計——原文直譯「手動搖」。">b</a></sup>，你要扶持他，像扶持外人或寄居者那樣，讓他與你一同生活。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 22:25; 申命記 23:19–20; 以西結書 18:8"> 不可向他收取利息或厚利，你要敬畏你的神，讓你的弟兄能與你一同生活。</span>
<span className="v" id="v37" data-v="37"> 你借錢給他，不可收取利息；借糧給他，不可貪圖利益。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 11:45; 民數記 15:41; 出埃及記 20:2"> 我是耶和華你們的神，是我把你們從埃及地領了出來，把迦南地賜給你們，為要作你們的神。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 21:2; 列王紀上 9:22; 列王紀下 4:1"> 「如果你身邊的弟兄貧窮，把自己賣給了你，你不可奴役他，使他做奴隸的工作。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 21:2–3"> 他在你那裡，要像雇工、像客居者一樣。他要在你那裡服事到禧年，</span>
<span className="v" id="v41" data-v="41" data-xref="利未記 25:28; 出埃及記 21:3; 約翰福音 8:32"> 然後他和他的兒女要從你那裡離去，回歸自己的家族，回歸自己祖先的地業。</span>
<span className="v" id="v42" data-v="42" data-xref="利未記 25:55; 羅馬書 6:22; 哥林多前書 7:21–23"> 要知道，他們是我的僕人，是我從埃及地領出來的，不可被賣為奴僕。</span>
<span className="v" id="v43" data-v="43" data-xref="歌羅西書 4:1; 利未記 25:46; 出埃及記 1:13–14"> 不可嚴酷地轄制他，你要敬畏你的神。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 12:44; 詩篇 2:8–9; 以賽亞書 14:1–2"> 那些成為你僕婢的，只能是周圍那些民族的人，你要從他們中間買僕婢；</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 56:3–6"> 也或者是住在你們中間的客居者的子孫，你們可以從他們中間買——他們的族人在你們中間，是在你們土地上出生的人。他們可以成為你們的產業。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 14:2; 利未記 25:43"> 你們可以把他們遺留給後代子孫作為產業繼承，可以永久奴役他們。但在你們的弟兄以色列子民中間，不可嚴酷地轄制彼此。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="雅各書 2:5; 利未記 25:26; 撒母耳記上 2:7–8"> 「如果你身邊的外人或寄居者手頭寬裕，而他那裡你的一個弟兄卻貧窮，把自己賣給了那外人、寄居者或外人的家族成員，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米記 5:5; 希伯來書 2:11–13; 利未記 25:35"> 那麼他被賣之後，還是有贖身的權利。他任何一個兄弟都可以贖回他，</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 25:26"> 他的叔伯或堂兄弟可以贖回他，他家族中的血親也可以贖回他；或者他手頭寬裕了，也可以贖回自己。</span>
<span className="v" id="v50" data-v="50" data-xref="以賽亞書 16:14; 以賽亞書 21:16; 利未記 25:53"> 贖回者要與買主核算，從賣出的那年開始到禧年為止，贖價要依據這年數，照著他在買主那裡作雇工的年日核算。</span>
<span className="v" id="v51" data-v="51"> 如果剩餘的年數多，他就要按年數從買價中償還他的贖價；</span>
<span className="v" id="v52" data-v="52"> 如果到禧年只剩下幾年，就要與買主按年數核算，償還他的贖價。</span>
<span className="v" id="v53" data-v="53" data-xref="利未記 25:46; 利未記 25:43"> 他在買主那裡要像長年雇用的工人，你不可眼看著他被買主嚴酷地轄制。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 21:2–3; 利未記 25:40–41; 以賽亞書 49:9"> 如果他不能以這些方式被贖回，他與他的兒女一起要在禧年自由離去。</span>
<span className="v" id="v55" data-v="55" data-xref="利未記 25:42; 以賽亞書 43:3; 出埃及記 13:3"> 要知道，以色列子民是我的僕人；他們是我從埃及地領出來的僕人。我是耶和華你們的神。</span>
</div>
</div>

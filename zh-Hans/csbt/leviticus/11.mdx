<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西和亞倫，對他們說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 15:11; 利未記 11:11; 希伯來書 9:10"> 「你們要吩咐以色列子民，地上一切動物中，可以吃的活物是這些：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多後書 6:17; 申命記 6:6–7"> 凡是分蹄、裂趾並且反芻的動物，都可以吃。</span>
<span className="v" id="v4" data-v="4"> 然而反芻的或分蹄的動物當中，這些不可以吃：<br /><span className="pl pl-1">駱駝，雖然反芻，卻不分蹄，</span><br /><span className="pl pl-1">所以牠對於你們是不潔淨的；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:18; 箴言 30:26; 馬太福音 7:26"> <span className="pl pl-1">巖貍，雖然反芻，卻不分蹄，</span><br /><span className="pl pl-1">所以牠對於你們是不潔淨的；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:7"> <span className="pl pl-1">兔子，雖然反芻，卻不分蹄，</span><br /><span className="pl pl-1">所以牠對於你們是不潔淨的；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 66:17; 以賽亞書 65:4; 以賽亞書 66:3"> <span className="pl pl-1">豬，雖然分蹄、裂趾，卻不反芻，</span><br /><span className="pl pl-1">所以牠對於你們是不潔淨的。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 52:11; 歌羅西書 2:16; 希伯來書 9:10"> 不可吃牠們的肉，也不可觸碰牠們的屍體；這些對於你們都是不潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 5:6; 雅各書 2:18; 使徒行傳 20:21"> 「水中的一切，可以吃的是這些：無論海裡、河裡，水中凡是有鰭有鱗的，都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未記 7:18; 詩篇 139:21–22"> 而無論海裡、河裡，一切水生的群居爬物、一切水裡的活物中，凡是無鰭無鱗的，對於你們都是可憎之物。</span>
<span className="v" id="v11" data-v="11"> 這些對於你們是可憎的，你們不可吃牠們的肉，並且要憎惡牠們的屍體。</span>
<span className="v" id="v12" data-v="12"> 凡是水中無鰭無鱗的，對於你們都是可憎之物。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="約伯記 39:27–30; 耶利米書 4:22; 提多書 3:3"> 「鳥類中，要憎惡的是這些，你們都不可吃，牠們是可憎之物：<br /><span className="pl pl-1">老鷹、禿鷲、紅頭鵰、</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">鷂鷹、小隼與其類，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王紀上 17:6; 箴言 30:17"> <span className="pl pl-1">各種烏鴉與其類，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 34:11–15; 以弗所書 5:7–11; 以弗所書 2:2–3"> <span className="pl pl-1">鴕鳥、夜鷹、海鷗、蒼鷹與其類，</span><br /></span>
<span className="v" id="v17" data-v="17"> <span className="pl pl-1">小鴞、鸕鶿、貓頭鷹、</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">白鴞、鵜鶘、鶚、</span></span>
<span className="v" id="v19" data-v="19"> <br /><span className="pl pl-1">白鸛、鷺鷥與其類，</span><br /><span className="pl pl-1">戴勝和蝙蝠。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 4:10; 腓立比書 3:18–19; 利未記 11:23"> 「凡是用四足行走、有翅膀的昆蟲，對於你們都是可憎之物。</span>
<span className="v" id="v21" data-v="21"> 然而，各類用四足行走、有翅膀的昆蟲中，腳上有曲腿、在地上跳的那種，你們可以吃。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 3:4; 馬可福音 1:6; 出埃及記 10:4–5"> 可以吃的是這些：<br /><span className="pl pl-1">蝗蟲與其類，蝻子與其類，</span><br /><span className="pl pl-1">蟋蟀與其類，蚱蜢與其類。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 但其他各類有四足、有翅膀的昆蟲，對於你們都是可憎之物。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:33; 以弗所書 2:1–3; 哥林多後書 6:17"> 「以上這些會使你們不潔淨，凡是觸碰牠們屍體的人，就不潔淨直到傍晚；</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 15:5; 利未記 14:8; 民數記 31:24"> 凡是搬運牠們屍體的人，都要洗自己的衣服，並且會不潔淨直到傍晚。</span>
<span className="v" id="v26" data-v="26"> 凡是分蹄卻不裂趾、不反芻的動物，對於你們都是不潔淨的，任何觸碰這些動物的人，都會不潔淨。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 11:23; 利未記 11:20"> 各類四足行走的活物中，凡是趾行的，對於你們都是不潔淨的，任何觸碰牠們屍體的人，都會不潔淨直到傍晚；</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 11:24–25"> 搬運牠們屍體的人，要洗自己的衣服，並且會不潔淨直到傍晚。這些動物對於你們都是不潔淨的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="利未記 11:41–42; 提摩太後書 3:2–5; 詩篇 10:3"> 「地上的群居爬物中，對於你們不潔淨的是這些：<br /><span className="pl pl-1">鼴鼠，老鼠，蜥蜴與其類，</span><br /></span>
<span className="v" id="v30" data-v="30"> <span className="pl pl-1">壁虎，石龍子，守宮，沙蜥，蝘蜓。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 11:24–25; 利未記 11:8"> 這些群居爬物對於你們都是不潔淨的。凡是觸碰牠們死屍的人，都會不潔淨直到傍晚。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 15:12; 提多書 3:5; 提多書 2:14"> 這些群居爬物的死屍掉在任何東西上，那東西就會不潔淨，無論是木器，或是衣服、皮革、麻袋——任何用途的物件，都要放進水裡，它會不潔淨直到傍晚，之後就潔淨了。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 6:28; 利未記 15:12; 利未記 14:45"> 這些死屍掉進任何瓦器，瓦器裡的東西全都會不潔淨，你們要打碎那瓦器。</span>
<span className="v" id="v34" data-v="34" data-xref="提多書 1:15; 箴言 21:4; 箴言 21:27"> 瓦器裡的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瓦器裡的——輔助詞語。">a</a></sup>水沾上任何可以吃的食物，這食物就會不潔淨；沾上任何器皿裡任何可以喝的飲物，這飲物也會不潔淨。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 15:12; 利未記 6:28; 利未記 11:33"> 這些屍體掉在任何物件上面，這物件就會不潔淨，無論是火爐還是竈臺，都要拆毀；這些都不潔淨，對於你們是不潔淨的；</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亞書 13:1; 約翰福音 4:14"> 然而泉源或蓄水的水窖，仍是潔淨的；但如果有人觸碰那裡面的屍體，他就會不潔淨。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 15:37; 彼得前書 1:23; 約翰一書 5:18"> 這些屍體掉在任何要播種的種子上的時候，那種子仍然是潔淨的；</span>
<span className="v" id="v38" data-v="38"> 但如果種子上澆了水，而屍體掉在種子上面，那種子對於你們就是不潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="利未記 11:40; 利未記 11:24; 利未記 15:7"> 「如果一隻給你們食用的動物死了，觸碰牠屍體的人，會不潔淨直到傍晚。</span>
<span className="v" id="v40" data-v="40" data-xref="利未記 22:8; 以西結書 44:31; 申命記 14:21"> 吃了這動物屍體的，要洗衣服，並且會不潔淨直到傍晚。搬運這動物屍體的，也要洗衣服，並且會不潔淨直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="利未記 11:29; 利未記 11:20; 利未記 11:23"> 「凡是地上的群居爬物，都是可憎的，都不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多書 1:12; 以賽亞書 65:25; 哥林多後書 11:3"> 地上的各類群居爬物中，凡是肚腹爬行的、四足行走的，甚至多足的，你們都不可吃，因為牠們是可憎之物。</span>
<span className="v" id="v43" data-v="43" data-xref="利未記 20:25; 利未記 11:41–42"> 你們不可因任何群居爬物使自己成為可憎的，不可使自己受玷汙，或被牠們玷汙。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 20:2; 彼得前書 1:15–16; 利未記 19:2"> 要知道，我是耶和華你們的神，你們要使自己分別為聖，成為聖潔的，因為我是聖潔的。你們不可因任何地上活動的群居爬物玷汙自己。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 11:44; 出埃及記 20:2; 出埃及記 6:7"> 我是耶和華，是我把你們從埃及地帶了上來，為要作你們的神。所以你們要成為聖潔的，因為我是聖潔的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未記 14:54; 利未記 15:32; 以西結書 43:12"> 「以上是關於動物、鳥類、水中游動的一切活物和地上爬動的一切活物的條例，</span>
<span className="v" id="v47" data-v="47" data-xref="利未記 10:10; 以西結書 44:23; 羅馬書 14:13–23"> 為要分別潔淨與不潔淨，分別可吃的活物與不可吃的活物。」</span>
</div>
</div>

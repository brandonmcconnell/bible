<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 6:14–18; 利未記 9:17; 以賽亞書 66:20"> 「當一個人獻上素祭為祭物給耶和華時，他要用細麵粉作為祭物，其上要澆油，並加上乳香。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 5:12; 利未記 6:15; 使徒行傳 10:4"> 他要把這素祭帶到那些作祭司的亞倫子孫那裡，祭司要從其中捧出滿滿一把細麵粉和油，連同所有的乳香。然後祭司要把這記念的部分在祭壇上燒獻為煙，作馨香的火祭獻給耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 10:12–13; 民數記 18:9; 利未記 21:22"> 素祭中所剩的，歸於亞倫和他的子孫，這是耶和華火祭中的至聖物。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:2; 哥林多前書 5:7–8; 詩篇 22:14"> 「當你獻上爐中烘烤的素祭為祭物，要用細麵粉做成調了油的無酵餅，或抹上油的無酵薄餅。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 6:21; 利未記 7:9"> 如果你以烤盤上的素祭為祭物，就要用細麵粉做成調了油的無酵餅，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:1–19; 詩篇 22:1–21; 馬可福音 14:1–15"> 把它分成小塊，澆上油；這是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 2:1–2; 利未記 7:9"> 如果你以煎盤上的素祭為祭物，就要用細麵粉調油做成。</span>
<span className="v" id="v8" data-v="8"> 你把這樣做出的素祭帶來獻給耶和華，交給祭司，祭司就要把它拿到祭壇前。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 2:2; 腓立比書 4:18; 利未記 6:15"> 祭司要從素祭中取出記念的部分，在祭壇上燒獻為煙，作馨香的火祭獻給耶和華。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 2:3"> 素祭中所剩的，歸於亞倫和他的子孫，這是耶和華火祭中的至聖物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太書 5:9; 路加福音 12:1; 出埃及記 23:18"> 「你們獻給耶和華的任何素祭，都不可帶著酵做成；因為任何酵、任何蜂蜜，你們都不可作為火祭燒獻給耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 23:19; 創世記 23:10–11; 出埃及記 22:29"> 它們可以作為初熟之物的祭物獻給耶和華，但不可獻在祭壇上為馨香之氣。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 43:24; 馬太福音 5:13; 歌羅西書 4:6"> 所有素祭的祭物，你都要用鹽調和。你素祭裡不可缺少你的神立約的鹽，你所有的祭物都要帶著鹽獻上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 23:10; 瑪拉基書 1:11; 民數記 28:2"> 「如果你獻上初熟之物的素祭給耶和華，就要獻上用火烘烤的新穗子——脫殼的新穀物，作為你初熟之物的素祭。</span>
<span className="v" id="v15" data-v="15"> 你要給它加上油，放上乳香；這是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 5:7; 羅馬書 8:26–27; 以賽亞書 61:1"> 祭司要把素祭中作為記念的部分，就是其中一些脫殼的穀物和一些油，連同所有的乳香都燒獻為煙，獻給耶和華作火祭。</span>
</div>

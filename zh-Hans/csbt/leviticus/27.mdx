<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 6:2; 撒母耳記上 1:28; 士師記 11:30–31"> 「你要吩咐以色列子民，對他們說：當一個人向耶和華還特殊的願，涉及到為人估價，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 30:13; 利未記 27:25; 民數記 18:16"> 你的估價應該是這樣：按聖所的謝克爾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="謝克爾——重量單位；後來成為貨幣單位。1謝克爾=11.4公克。本章下同。">a</a></sup>標準，男子從二十歲到六十歲，估價為五十謝克爾銀子；</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 27:9–10; 撒迦利亞書 11:12–13; 馬太福音 26:15"> 如果是女人，估價為三十謝克爾。</span>
<span className="v" id="v5" data-v="5"> 如果是從五歲到二十歲，估價為男人二十謝克爾，女人十謝克爾。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 3:40–43; 民數記 18:14–16"> 如果是從一個月到五歲，要給男人估價五謝克爾銀子，給女人估價三謝克爾銀子。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 90:10"> 如果是六十歲以上，男人的估價是十五謝克爾，而女人是十謝克爾。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 14:7; 利未記 14:21–22; 路加福音 21:1–4"> 如果他窮得付不起這估價，就要讓他站在祭司面前，由祭司估價；祭司要按許願者能負擔的，為他估價。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「所許的如果是可獻給耶和華為祭物的牲畜，他獻給耶和華的一切，都要成為神聖的。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 27:15–33; 雅各書 1:8"> 他不可更改，也不可替換，無論是以壞換好，或是以好換壞。如果他還是以牲畜替換了牲畜，那麼，原來的和所替換的都要成為神聖的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 23:18; 瑪拉基書 1:14"> 「所許的如果是任何不潔淨的牲畜，是不可獻給耶和華為祭物的，他就要讓那牲畜站在祭司面前，</span>
<span className="v" id="v12" data-v="12"> 由祭司來區分好壞，給出估價；祭司怎樣估價，就怎樣為準。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:19; 利未記 27:15; 利未記 22:14"> 如果他一定要贖回那牲畜，就要在這估價上加五分之一。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 18:14; 利未記 25:29–31; 利未記 27:21"> 「如果有人把自己的房屋分別為聖，歸於耶和華，要由祭司來區分好壞，給出估價；祭司怎樣估價，就怎樣定準。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 27:13"> 那把房屋分別為聖的人，如果要贖回自己的房屋，就要在你所估的價銀上加五分之一，這樣房屋就歸屬於他。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西結書 45:11–14; 何西阿書 3:2; 使徒行傳 4:34–37"> 「如果有人把自己一部分田產分別為聖，歸於耶和華，要按那地的撒種量來估價，一賀梅珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一賀梅珥——相當於220公升。">b</a></sup>大麥種子為五十謝克爾<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五十謝克爾——相當於570公克。">c</a></sup>銀子。</span>
<span className="v" id="v17" data-v="17"> 如果他是在禧年把田地分別為聖，就要照估價來定準；</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 25:15–16; 利未記 25:51–52; 利未記 25:27"> 但如果他是在禧年之後把田地分別為聖，祭司就要照著下一個禧年之前所剩的年數，給他核算價銀，然後從估價中減去。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 27:13"> 那把地分別為聖的人，如果一定要贖回田地，就要在你所估的價銀上加五分之一，這樣田地就定準歸他。</span>
<span className="v" id="v20" data-v="20"> 但如果他不贖回田地，或者把田地賣給了別人，田地就再不能贖回了。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 44:29; 民數記 18:14; 利未記 25:31"> 到了禧年該退還的時候，那塊田地要歸耶和華為聖，就像永獻的田地那樣，歸於祭司為產業。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 25:10; 利未記 25:25"> 「如果有人把他所購買、原不屬於自己田產的田地，分別為聖歸於耶和華，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 27:18; 利未記 27:12"> 祭司就要為他核算到禧年為止的估價數目，他要當天交付那估價，歸耶和華為聖。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 25:28; 利未記 27:20"> 到了禧年，這田地要歸還賣主，就是產業之地的原主。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:13; 民數記 18:16; 民數記 3:47"> 你所有的估價，都要按聖所的謝克爾標準，二十季拉<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="二十季拉——相當於11.4公克。1季拉=0.57公克。">d</a></sup>為一謝克爾。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 13:2; 出埃及記 13:12–13; 民數記 18:17"> 「然而那頭生的，就是屬於耶和華的頭胎牲畜，任何人不可把牠分別為聖；無論是牛還是羊，那原是屬於耶和華的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 27:11"> 如果那是不潔淨的牲畜，就要按估價贖回，並且在估價上加五分之一；如果不贖回，就要按估價賣了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 6:17–19; 利未記 27:21; 出埃及記 22:20"> 「一切永獻之物，就是人從他所擁有的一切中永遠奉獻給耶和華的——無論是人、是牲畜，還是田產——都不可賣掉，也不可贖回。一切永獻之物，都是歸於耶和華的至聖物。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 15:18–23; 民數記 21:2–3"> 一切被永獻為當滅之物的人，都不可贖回，他必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 23:23; 尼希米記 13:12; 創世記 28:22"> 「土地的一切出產，無論是地上的穀物，還是樹上的果實，十分之一都屬於耶和華，要歸耶和華為聖。</span>
<span className="v" id="v31" data-v="31"> 如果有人決定要贖回他十一奉獻的一部分，他就要在原價上加五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 33:13; 以西結書 20:37; 彌迦書 7:14"> 一切牛群、羊群的十分之一，就是從杖下經過的每第十隻，都要歸耶和華為聖。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 27:10"> 不可查究好壞，不可替換。如果他還是替換了，那麼，原來的和替換的都要成為神聖的，並且不可被贖回。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="利未記 26:46; 民數記 1:1; 希伯來書 12:18–25"> 以上是耶和華在西奈山藉著摩西向以色列子民頒布的誡命。</span>
</div>
</div>

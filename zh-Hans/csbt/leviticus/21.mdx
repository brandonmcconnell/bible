<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 44:25; 利未記 21:11; 利未記 10:6–7"> 耶和華對摩西說：「你要吩咐作祭司的亞倫子孫，對他們說：不可為民中的死人使自己受玷汙，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 4:13; 利未記 18:6"> 除非那死人是他的骨肉至親，父母、兒女、兄弟；</span>
<span className="v" id="v3" data-v="3"> 如果他的至親姐妹是未嫁人的處女，也可以為這姐妹使自己受玷汙。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 24:16–17"> 他不可作為家主，為姻親使自己受玷汙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他不可作為家主，為姻親使自己受玷汙——或譯作「他在民中為首，不可使自己受玷汙」。">a</a></sup>，被褻瀆。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 14:1; 以西結書 44:20; 利未記 19:27–28"> 「祭司不可剃光頭髮，不可剪掉鬍鬚的邊角，也不可割劃身體。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 3:11; 利未記 18:21; 彼得前書 2:9"> 他們要成為聖潔的歸於神，不可褻瀆神的名；因為是他們要獻上耶和華的火祭——神的食物，所以他們必須聖潔。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 21:13–14; 以西結書 44:22; 利未記 21:8"> 祭司不可娶妓女或被玷汙的女人，也不可娶那被丈夫休了的女人，因為祭司是歸神為聖的。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 20:7–8; 利未記 19:2; 利未記 11:44–45"> 你要使祭司分別為聖，因為是他要獻上你神的食物；他對於你們應當是聖潔的，因為我耶和華，把你們分別為聖的那一位，是聖潔的。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 38:24; 利未記 19:29; 以西結書 9:6"> 祭司的女兒，如果去賣淫玷汙自己，就是在褻瀆自己的父親，必須用火燒死。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 10:6–7; 利未記 16:32; 馬太福音 26:65"> 「弟兄當中作大祭司的，頭上被澆了膏油、已經承接聖職穿上聖衣，他不可披散頭髮，也不可撕裂衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 19:14; 利未記 21:1–2; 民數記 6:7"> 他不可接近任何死人的屍體，即使是為了父母，他也不可使自己受玷汙。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 10:7; 出埃及記 29:6–7; 利未記 8:9–12"> 他也不可為死者<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="為死者——輔助詞語。">b</a></sup>離開聖所，以免褻瀆神的聖所，因為神的受膏聖冠<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受膏聖冠——或譯作「離俗膏油」；參《出埃及記》29:6-7。">c</a></sup>在他頭上。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 21:7; 哥林多後書 11:2; 啟示錄 14:4"> 「他要娶處女為妻；</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 21:7; 以西結書 44:22"> 寡婦或被休的婦女，或是被玷汙的妓女，這些他都不可娶，只可以娶本族<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="本族——或譯作「本民」；本章下同。">d</a></sup>的處女為妻，</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 11:16; 哥林多前書 7:14; 尼希米記 13:23–29"> 以免在本族中褻瀆了自己的後裔。我是把他分別為聖的耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華指示摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 65:4; 民數記 16:5; 利未記 10:3"> 「你要吩咐亞倫：你世世代代的後裔中，凡是身上有殘疾的，都不可近前來獻上他的神的食物。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 3:2–3; 利未記 22:19–25; 提多書 1:7"> 因為凡是身上有殘疾的人，都不可近前來獻祭，無論那人是瞎眼的還是瘸腿的，或是面目受損的、畸形的，</span>
<span className="v" id="v19" data-v="19"> 或是折手斷腳的人、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 23:1; 以賽亞書 56:3"> 駝背的、侏儒症的、眼睛有毛病的、生癬的、長疥的，睾丸受損的。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 21:6; 利未記 21:8; 利未記 21:17"> 祭司亞倫的後裔中，凡是身上有殘疾的人，都不可近前來獻上耶和華的火祭；他身上有殘疾，不可近前來獻上神的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 2:3; 民數記 18:19; 利未記 24:8–9"> 神的食物，無論是至聖的還是聖潔的，他都可以吃，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 21:12; 以西結書 44:9–14; 出埃及記 30:6–8"> 但他不可進到幔子那裡，也不可接近祭壇，因為他有殘疾，以免他褻瀆了我的聖所。我是把他們分別為聖的耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太前書 1:18; 瑪拉基書 2:1–7; 提摩太後書 2:2"> 於是，摩西把這一切告訴了亞倫和他的兒子們，以及所有的以色列子民。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在馬索拉文本為5:20至6:23。">a</a></sup>耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 3:9; 使徒行傳 5:4; 利未記 5:15"> 「如果有人犯罪，不忠於耶和華，在所交託的寄存物、抵押物上欺騙鄰人，或者搶奪鄰人，欺壓鄰人，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 23:4; 利未記 19:12; 出埃及記 22:9–11"> 或者撿到了失物卻否認並且起假誓——在人們常做的任何一件事上犯了罪；</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:18; 阿摩司書 3:10; 利未記 5:3–4"> 當他犯罪而有了罪責時，他要歸還所搶奪的，或欺壓得來的，或交託他的寄存物，或撿到的失物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 5:16; 路加福音 19:8; 民數記 5:7–8"> 或起假誓所得到的任何東西。他要全數償還，並且加上五分之一，在承擔罪責的那天都交給物主。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 5:15; 利未記 5:18; 以賽亞書 53:10–11"> 他還要把贖愆祭帶給耶和華，就是羊群中一隻無瑕疵的公綿羊，或等價的銀子，作為贖愆祭交給祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 4:26; 約翰一書 1:9; 約翰一書 2:1–2"> 祭司要在耶和華面前為他贖罪，他所做的任何一件事使他有了罪責，都必得赦免。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華指示摩西說：</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 6:12–13; 民數記 28:3; 出埃及記 29:38–42"> 「你要吩咐亞倫和他的子孫說，這是燔祭的條例：燔祭要一整夜留在祭壇的爐床上直到早晨；祭壇的火要一直燃燒。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 28:39–43; 利未記 16:4; 利未記 1:13"> 祭司要穿上細麻衣袍，貼身穿上細麻褲子，要把祭壇上燒完燔祭的灰燼除掉，放在祭壇旁邊。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 4:12; 以西結書 44:19; 希伯來書 13:11–13"> 然後脫下這些衣服，穿上別的衣服，把灰燼帶到營地外潔淨的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 9:24; 出埃及記 29:38–42; 尼希米記 13:31"> 祭壇上的火要一直燃燒，不可熄滅。祭司要每天早晨在其上添加木柴燃燒，然後擺上燔祭，在其上把平安祭的脂肪燒獻為煙。</span>
<span className="v" id="v13" data-v="13"> 火在祭壇上要一直燃燒，不可熄滅。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 15:4; 利未記 2:1–2; 約翰福音 6:32"> 「這是素祭的條例：亞倫的子孫要在祭壇前在耶和華面前獻上素祭。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 2:2; 利未記 2:9"> 祭司要從素祭中，就是從素祭的細麵粉和油中捧出一把，連同素祭上的所有乳香，作為素祭的記念部分在祭壇上燒獻為煙，作馨香之氣獻給耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 44:29; 利未記 2:3; 利未記 10:12–13"> 亞倫和他子孫要吃剩下的素祭，要做成無酵餅在神聖的地方吃，就是在會幕的院子裡吃。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 2:3; 利未記 2:11; 民數記 18:9–10"> 不可帶著酵烘烤；這是我從我的火祭中賜給他們的份，是像贖罪祭和贖愆祭一樣的至聖物。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 6:29; 民數記 18:10; 哈該書 2:12–14"> 亞倫子孫中所有的男丁都可以吃，這是耶和華的火祭中，給你們世世代代永遠的份例；凡是觸碰這些火祭的，都會成為聖潔的。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和華指示摩西說：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 29:2; 出埃及記 16:36; 利未記 2:1–16"> 「亞倫和他的子孫，在被膏立的那天要獻給耶和華以下祭物：十分之一伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十分之一伊法——相當於2.2公升。1伊法=22公升。">b</a></sup>的細麵粉，作常獻的素祭，早晨獻一半，傍晚獻一半；</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 2:5; 利未記 7:9; 歷代志上 9:31"> 要在烤盤上用油揉拌製作，拿來烤好做成碎餅的素祭獻上，作馨香之氣獻給耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:22–25; 以賽亞書 53:10; 利未記 8:21"> 亞倫子孫中接續他作受膏祭司的，要獻上這素祭，這是永遠的定例，要把它完全燒獻給耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 2:10; 利未記 6:16–17"> 祭司的這一切素祭都是全燒祭，不可以吃。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 耶和華指示摩西說：</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:24; 利未記 1:11; 利未記 1:3"> 「你要吩咐亞倫和他的子孫說，贖罪祭的條例是這樣：要在宰殺燔祭牲的地方，在耶和華面前宰殺贖罪祭牲；這是至聖的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 10:17–18; 以西結書 44:28–29; 何西阿書 4:8"> 獻上贖罪祭的祭司要吃這祭物，要在會幕的院子，就是在神聖的地方吃。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 29:37; 哈該書 2:12; 哥林多後書 7:1"> 凡是觸碰這祭物之肉的，都會成為聖潔的。如果有祭物的血濺在衣服上，就要在神聖的地方洗掉那濺上的血。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 11:33; 利未記 15:12; 希伯來書 9:9–10"> 煮這祭物的瓦器要打碎；如果是用銅器煮的，之後要擦凈銅器，用水沖洗。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 6:25; 利未記 6:17–18; 民數記 18:10"> 祭司家中所有的男丁都可以吃，這是至聖物。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 10:18; 利未記 16:27–28; 希伯來書 13:11"> 任何贖罪祭牲，如果牠的血被帶進會幕，用來在聖所裡贖罪，這贖罪祭牲就不可以吃，要用火把牠燒掉。</span>
</div>
</div>

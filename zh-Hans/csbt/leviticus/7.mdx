<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 6:17; 利未記 5:14–7; 利未記 6:25"> 「贖愆祭的條例是這樣：這祭是至聖的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 1:5; 利未記 6:25; 利未記 1:11"> 要在宰殺燔祭牲的地方宰殺贖愆祭牲，祭司要把祭牲的血灑在祭壇四壁。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:13; 利未記 3:15–16; 詩篇 51:6"> 祭牲的全部脂肪都要獻上：肥尾巴，覆蓋內臟的脂肪，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 3:4"> 兩個腎臟和腎臟上靠近腰部的脂肪，以及腎臟上方的肝葉，都要取下來。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 1:13; 加拉太書 5:24; 彼得前書 4:1–2"> 祭司要在祭壇上把這些燒獻為煙，作為火祭獻給耶和華；這是贖愆祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 6:29; 民數記 18:9–10; 利未記 2:3"> 祭司家中所有的男丁都可以吃，這祭物必須在神聖的地方吃，這是至聖的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未記 6:25–26; 利未記 14:13; 哥林多前書 9:13"> 「贖罪祭像贖愆祭，有同一個條例：祭物要歸於那用牠行贖罪禮的祭司。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 4:11; 出埃及記 29:14; 羅馬書 13:14"> 祭司為人獻上燔祭的時候，所獻上的燔祭牲的皮要歸於那祭司，這是屬於他的。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 18:9; 以西結書 44:29; 利未記 2:10"> 所有在爐中烘烤的素祭，所有在煎盤裡、在烤盤上製作的素祭，都要歸於那獻祭的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 8:14; 出埃及記 16:18"> 所有調了油的或者乾的素祭，都要歸於亞倫的所有子孫，彼此均分。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 22:18–21; 以西結書 45:15; 利未記 3:1–17"> 「獻給耶和華的平安祭的條例是這樣：</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 2:4; 民數記 6:15; 彼得前書 2:5"> 如果是為感謝而獻，就要與感謝的祭物一起獻上調了油的無酵餅，還有抹上油的無酵薄餅，以及細麵粉調了油揉拌做成的餅。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 4:5; 利未記 23:17; 馬太福音 13:33"> 要把祭物與有酵餅，連同為感謝所獻的平安祭一起獻上。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 18:19; 出埃及記 29:27–28; 民數記 18:24–32"> 要從各樣祭物的餅中各取一份，作為供物獻給耶和華，這份要歸於那灑平安祭之血的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 22:29–30"> 為感謝所獻的平安祭肉，要在獻祭的當天吃掉，一點也不可留到次日早晨。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 19:5–8; 申命記 12:6; 詩篇 116:14"> 「如果所獻的祭物是作還願祭或甘心祭，要在獻上祭物的當天吃；剩下的部分可以第二天吃。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:10; 何西阿書 6:2; 哥林多前書 15:4"> 但此後剩下的祭肉，到了第三天就要用火燒掉。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 19:7–8; 利未記 11:41; 民數記 18:27"> 到第三天如果平安祭的肉還是被人吃了，那獻祭的人就不蒙悅納，所獻的也無效；這祭肉成了不潔之物，吃了的人要承擔自己的罪責。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多書 1:15; 使徒行傳 10:15–16"> 「祭肉接觸了任何不潔之物，都不可吃，要用火燒掉。除此以外的祭肉，凡是潔淨的人都可以吃；</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 15:2–33; 創世記 17:14; 利未記 22:3–7"> 如果有人不潔淨，卻吃了屬於耶和華的平安祭的肉，這人就要從民中被剪除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 12:1–59; 利未記 11:20; 以西結書 4:14"> 如果有人觸碰了任何不潔之物——無論是人的汙穢還是不潔淨的動物，或是任何不潔淨的可憎之物——然後吃了獻給耶和華的平安祭的肉，這人也要從民中被剪除。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華指示摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 3:16–17; 利未記 17:6; 撒母耳記上 2:15–17"> 「你要吩咐以色列子民：公牛、綿羊或山羊的任何脂肪，你們都不可吃。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 22:31; 利未記 17:15; 利未記 22:8"> 自然死去動物的脂肪，或者被咬死動物的脂肪，可作其他的用途，但你們絕不可吃。</span>
<span className="v" id="v25" data-v="25"> 任何人吃了獻給耶和華為火祭的祭牲的脂肪，這吃了的人就要從民中被剪除。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 9:4; 利未記 3:17; 使徒行傳 15:20"> 在你們居住的任何地方，你們任何血都不可吃，無論是鳥類的血，還是動物的血。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 10:29; 利未記 7:20–21; 利未記 7:25"> 無論什麼人，吃了任何血，這人就要從民中被剪除。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和華指示摩西說：</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 1:20; 約翰一書 1:7; 利未記 3:1–17"> 「你要吩咐以色列子民：那向耶和華獻上平安祭的人，要從他的平安祭物中取來祭物獻給耶和華。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 6:20; 利未記 3:9; 利未記 3:14"> 他要親手帶來耶和華的火祭；要把脂肪與胸肉一起帶來，把胸肉作為搖獻祭物在耶和華面前搖一搖。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 3:5; 利未記 3:11; 利未記 3:16"> 祭司要在祭壇上把脂肪燒獻為煙，胸肉歸屬亞倫和他的子孫。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 6:20; 利未記 7:34; 利未記 9:21"> 要把你們平安祭物的右腿作為供物歸給祭司；</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 26:1–46; 利未記 6:1–30; 利未記 7:3"> 亞倫子孫中獻上平安祭的血和脂肪的祭司，要得這右腿作為他的份。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 18:18–19; 利未記 10:14–15; 出埃及記 29:9"> 因為我已經從以色列子孫的平安祭物中，取了搖獻祭的胸肉和供物的大腿，賜給祭司亞倫和他的子孫，作為他們從以色列子孫所得永遠的份例。」</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:20; 約翰一書 2:27; 民數記 18:7–19"> 這是耶和華的火祭中亞倫受膏的份，以及他子孫受膏的份；在摩西把他們獻給耶和華作祭司的那天，</span>
<span className="v" id="v36" data-v="36" data-xref="利未記 8:12; 利未記 8:30; 出埃及記 40:13–15"> 就是摩西膏立他們的那天，耶和華指示要從以色列子孫的祭物中賜給他們，作他們世世代代永遠的份例。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及記 29:1; 利未記 1:1–6; 利未記 6:9–18"> 以上是燔祭、素祭、贖罪祭、贖愆祭、聖職祭和平安祭的條例，</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 1:1–2"> 是耶和華在西奈山指示摩西的，那天耶和華在西奈曠野指示以色列子民，要向耶和華獻上他們的祭物。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及記" data-chapter="39" data-verses="43">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 31:10; 出埃及記 35:23; 出埃及記 35:19"> 他們用藍色、紫色、朱紅色線，做了聖所事奉用的編織的衣服，又為亞倫做了聖衣，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及記 28:6–12; 利未記 8:7; 出埃及記 25:7"> 比撒列用金色、藍色、紫色、朱紅色線和捻成的細麻線做了以弗得。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 36:8; 出埃及記 26:1"> 他們把金子錘成薄片，剪成細線，以精巧的工藝織入了藍色、紫色、朱紅色線和細麻之中；</span>
<span className="v" id="v4" data-v="4"> 又為以弗得做了兩條相連的肩帶，與它的兩端相連。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:13; 馬太福音 28:20; 以賽亞書 11:5"> 以弗得上的精巧織帶，與以弗得的做法一樣，都從同樣的材料——金色、藍色、紫色、朱紅色線和捻成的細麻線織出，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 28:9; 以西結書 28:13; 約伯記 28:16"> 他們把兩塊紅瑪瑙石鑲嵌在金槽中，像雕刻印章那樣，雕刻了以色列兒子們的名字。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 4:7; 出埃及記 28:12; 出埃及記 28:29"> 他把這兩塊寶石安在以弗得的肩帶上，作為以色列兒子們的記念石，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 28:4; 利未記 8:8–9; 以賽亞書 59:17"> 他以精巧的工藝做了一個胸牌，與以弗得的做法一樣，用金色、藍色、紫色、朱紅色線和捻成的細麻線來做。</span>
<span className="v" id="v9" data-v="9"> 胸牌是方形的；他們把胸牌做成了雙層，長一拃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一拃——約20公分；下同。">a</a></sup>，寬一拃，疊為雙層。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 28:21; 出埃及記 28:16–17; 啟示錄 21:19–21"> 他們在胸牌上鑲嵌了四行寶石：第一行是紅寶石、黃玉、綠寶石，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 28:18; 以西結書 28:13"> 第二行是綠松石、藍寶石、金剛石，</span>
<span className="v" id="v12" data-v="12"> 第三行是紅鋯石、白瑪瑙、紫晶，</span>
<span className="v" id="v13" data-v="13"> 第四行是黃水晶、紅瑪瑙、碧玉。這些都鑲嵌在各自的金槽中。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:12"> 這些寶石都按著以色列兒子們的名字，十二塊都按著他們的名字，像雕刻印章那樣，按著各自的名字，代表十二個支派。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 10:28; 約翰福音 17:12; 彼得前書 1:5"> 他們在胸牌上用編繩子的工藝做了純金的鏈子；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:12"> 他們做了兩個金槽和兩個金環，把兩個環接在胸牌上邊<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="上邊——輔助詞語。">b</a></sup>的兩端；</span>
<span className="v" id="v17" data-v="17"> 他們把兩條金鏈子接在胸牌上邊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="上邊——輔助詞語。">c</a></sup>兩端的兩個環中，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 28:14; 雅歌 1:10"> 把兩條鏈子的另兩端接在兩個槽上，把它們連在以弗得前面的肩帶上。</span>
<span className="v" id="v19" data-v="19"> 他們再做了兩個金環，安在胸牌下邊<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="下邊——輔助詞語。">d</a></sup>的兩端，在以弗得內側的邊上；</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 26:3"> 又做了兩個金環，把它們接在以弗得前面的兩條肩帶下面，靠近接縫處，在以弗得的精巧織帶上方。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 16:24; 哥林多前書 1:25; 哥林多前書 1:27"> 他們用藍色的細繩把胸牌的環與以弗得的環連接，使胸牌貼在以弗得的精巧織帶上，使胸牌不致從以弗得上鬆脫，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:31–35"> 他用紡織的工藝做了以弗得的外袍，整件都是藍色的。</span>
<span className="v" id="v23" data-v="23"> 外袍的中間之處，有一個領口，像戰袍的領口那樣，領口有圍邊，免得撕裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 28:33; 加拉太書 5:22"> 他們在外袍的下擺上，用捻成的藍色、紫色、朱紅色線做了石榴，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 28:33–34; 雅歌 4:13; 詩篇 89:15"> 又用純金做了鈴鐺，把鈴鐺加在石榴之間，在外袍下擺圍邊上的石榴之間，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 28:34; 雅歌 4:13; 雅歌 6:7"> 一個鈴鐺一個石榴，一個鈴鐺一個石榴，在外袍下擺的圍邊上，是用於事奉，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以西結書 44:18; 彼得前書 1:13; 以賽亞書 61:10"> 他們用紡織的工藝，為亞倫和他的兒子們做了細麻袍子，</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 28:4; 以西結書 44:18; 出埃及記 28:39"> 細麻頂冠和細麻頭飾巾，用捻成的細麻線做了細麻褲子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 28:39"> 又用藍色、紫色、朱紅色線和捻成的細麻線，以刺繡的工藝做了腰帶，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="啟示錄 5:10; 希伯來書 7:26; 希伯來書 1:3"> 他們用純金做了一面聖冠牌子，像雕刻印章那樣，在金牌上刻了字「歸耶和華為聖」；</span>
<span className="v" id="v31" data-v="31"> 又用一條藍色的細繩把金牌繫在頂冠上面，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及記 39:42–43; 馬太福音 28:20; 出埃及記 25:40"> 這樣，會幕的一切工作都完成了。以色列子孫遵行耶和華所指示摩西的一切，都照著做了。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 35:11–19; 出埃及記 31:7–11; 出埃及記 36:1–38"> 他們把帳幕帶到摩西那裡，就是帳篷和帳篷的一切器具：鉤子、木板、橫閂、柱子、底座、</span>
<span className="v" id="v34" data-v="34"> 染紅公綿羊皮的遮蓋、海獅皮的頂罩、簾幕的幔子、</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 9:5; 出埃及記 25:17; 希伯來書 9:8"> 見證櫃和櫃的杠、施恩座、</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:30; 列王紀上 7:48"> 桌子和桌子的一切器具、陳設餅、</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比書 2:15; 出埃及記 27:21; 馬太福音 5:14–16"> 純金的燈臺、排列的燈、燈臺的一切器具、點燈的油、</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 30:7; 出埃及記 37:29; 出埃及記 30:3"> 金壇、膏油、芬芳香、帳篷的門簾、</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 8:64; 出埃及記 38:30"> 銅祭壇、祭壇用的銅格網、祭壇的杠、祭壇的一切器具、洗濯盆和盆座、</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 27:9–16"> 院子的帷幔、帷幔的柱子、底座、院子的門簾、繩子、橛子、會幕的帳幕服事所用的一切器具、</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 28:2; 出埃及記 31:10; 出埃及記 39:1"> 聖所事奉用的編織的衣服——祭司亞倫的聖衣和他兒子們作祭司事奉時的衣服。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及記 35:10; 出埃及記 23:21–22; 提摩太後書 2:15"> 這樣，以色列子孫照著耶和華所指示摩西的一切，完成了一切工作。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 6:23–27; 利未記 9:22–23; 撒母耳記下 6:18"> 摩西查看一切工作，看哪，他們遵行耶和華所指示的，都照著做了。於是，摩西祝福了他們。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 26:30; 出埃及記 13:4; 民數記 7:1"> 「一月一日，你要把會幕的帳幕立起來，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:12; 民數記 4:5; 啟示錄 11:19"> 把見證櫃安放在那裡，用幔子遮掩這櫃；</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:8; 出埃及記 40:22–25; 出埃及記 37:10–24"> 把桌子搬進去，擺好桌子上應擺的東西；又把燈臺搬進去，點上燈。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 10:19–22; 希伯來書 9:24; 約翰一書 2:1–2"> 你要把金香壇放在見證櫃前面，掛上帳幕的門簾；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 40:29; 約翰一書 4:9–10; 希伯來書 13:10"> 把燔祭的祭壇放在會幕的帳幕入口的前面；</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 13:1; 約翰一書 1:7; 詩篇 26:6"> 又把洗濯盆放在會幕和祭壇之間，盆中盛水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 40:33; 以弗所書 4:11–12; 馬太福音 16:18"> 你要在四圍設院子，掛上院子的門簾。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未記 8:10; 民數記 7:1; 馬太福音 3:16"> 「你要把膏油拿來，膏抹帳幕和帳幕裡的一切，使帳幕和帳幕的一切器具分別為聖，帳幕就成為神聖的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 29:36–37; 路加福音 1:35; 以賽亞書 61:1"> 你要膏抹燔祭的祭壇和祭壇的一切器具，使祭壇分別為聖，祭壇就成為至聖的。</span>
<span className="v" id="v11" data-v="11"> 你要膏抹洗濯盆和盆座，使盆分別為聖。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未記 8:1–13; 利未記 9:1–24; 出埃及記 29:1–35"> 「你要把亞倫和他的兒子們帶到會幕的入口，用水洗他們；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 28:41; 約翰一書 2:20; 約翰一書 2:27"> 給亞倫穿上聖衣，膏抹他，使他分別為聖，作祭司事奉我；</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 61:10; 羅馬書 8:30; 哥林多前書 1:30"> 又把他的兒子們帶來，給他們穿上袍子，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 25:13; 希伯來書 5:1–14; 希伯來書 8:1–10"> 膏抹他們，像膏抹他們的父親那樣，使他們作祭司事奉我。他們受膏抹，就使他們世世代代擁有永遠的祭司職份。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 4:1; 出埃及記 40:17–32; 申命記 12:32"> 摩西遵行耶和華所指示他的一切，都照著做了。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 7:1; 出埃及記 40:1–2; 民數記 9:1"> 第二年一月一日，帳幕立了起來。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 37:27–28; 彼得前書 1:5; 利未記 26:11"> 摩西把帳幕立了起來，安好帳幕的底座，豎起木板，穿上橫閂，立起柱子，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 26:1–14; 出埃及記 36:8–19"> 把罩篷鋪在帳幕上，又把罩篷的頂罩安放其上，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:34; 申命記 10:5; 希伯來書 10:19–21"> 摩西把見證版拿來，安放在櫃裡，把杠穿在櫃的兩邊，把施恩座安放在櫃上面；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 26:33; 出埃及記 40:3; 出埃及記 35:12"> 又把櫃抬進帳幕，掛上簾幕的幔子來遮掩見證櫃，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 26:35; 約翰福音 6:53–57; 以弗所書 3:8"> 摩西把桌子安置在會幕中，在帳幕的北邊，幔子的外面；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 25:30; 出埃及記 40:4; 希伯來書 9:2"> 在桌子上擺好陳設餅，擺在耶和華面前，是照著耶和華指示摩西的。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 26:35; 啟示錄 2:5; 約翰福音 1:1"> 他把燈臺放在會幕中，在桌子對面，在帳幕的南邊；</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 40:4; 出埃及記 25:37; 啟示錄 4:5"> 又把燈點在耶和華面前，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 40:5; 希伯來書 7:25; 約翰福音 11:42"> 他把金壇安放在會幕中，幔子的前面；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 30:7"> 在壇上燒獻芬芳香，是照著耶和華指示摩西的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 40:5; 希伯來書 10:19–20; 以弗所書 2:18"> 他掛上帳幕的門簾。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 40:6; 希伯來書 13:5–6; 希伯來書 13:10"> 他把燔祭的祭壇安放在會幕的帳幕入口，把燔祭和素祭獻在祭壇上，都是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 40:7; 出埃及記 38:8; 以西結書 36:25"> 他把洗濯盆安放在會幕和祭壇之間，盆中盛水，用來洗濯；</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 30:19–20; 詩篇 26:6; 約翰福音 13:10"> 摩西、亞倫和他的兒子們在盆中洗手洗腳。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 73:19; 出埃及記 30:19–20; 出埃及記 40:19"> 當他們進入會幕，或接近祭壇的時候，他們就洗濯，是照著耶和華指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及記 40:8; 出埃及記 27:9–16; 約翰福音 17:4"> 他在帳幕和祭壇的四圍設了院子，掛上院子的門簾。這樣，摩西就完成了工作。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="啟示錄 15:8; 民數記 9:15–23; 歷代志下 7:2"> 那時，雲彩遮蓋會幕，耶和華的榮耀充滿了帳幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 8:11; 利未記 16:2; 歷代志下 7:2"> 摩西不能進入會幕，因為雲彩停留在會幕上，耶和華的榮耀充滿了帳幕。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="尼希米記 9:19; 民數記 9:17; 出埃及記 13:21–22"> 在以色列子孫的整個行程中，每當雲彩從帳幕上收上去，他們就起行；</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 9:19–22; 詩篇 31:15"> 如果雲彩不收上去，他們就不起行，直到雲彩收上去那天。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 78:14; 民數記 9:15; 出埃及記 13:21"> 在他們的整個行程中，白天有耶和華的雲彩在帳幕上，夜間有火在雲彩中，就在以色列全家的眼前。</span>
</div>
</div>

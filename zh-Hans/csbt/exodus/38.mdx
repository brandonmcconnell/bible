<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 27:1–8; 以西結書 43:13–17; 出埃及記 40:6"> 他用金合歡木造了一座燔祭壇，長五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="五肘——相當於2.3公尺。1肘=45.7公分。">a</a></sup>，寬五肘，是方形的，高三肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三肘——相當於1.4公尺。">b</a></sup>；</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 27:2; 約伯記 6:12"> 在祭壇的四角上做了犄角，犄角從祭壇而出；又把祭壇包上了銅。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 27:3; 撒母耳記上 2:13"> 他做了祭壇的一切器具：桶、鏟子、碗、肉叉和火盆；祭壇的一切器具，他都用銅做。</span>
<span className="v" id="v4" data-v="4"> 他為祭壇做了一個銅格網，安放在祭壇的邊框之下，使網達到祭壇的半腰。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 27:4"> 他在銅格網的四角鑄了四個環，用來穿杠。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:3; 出埃及記 25:6"> 他用金合歡木做了杠，把它們包上銅，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 9:15; 哥林多前書 2:2; 哥林多前書 1:24"> 把杠穿進祭壇兩邊的環中，用來抬祭壇。他用木板把祭壇做成了空心的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 2:22; 路加福音 2:37; 出埃及記 40:7"> 他用會幕入口服事的女人的銅<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="銅——輔助詞語。">c</a></sup>鏡做了一個銅盆和銅盆座。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 27:9–19; 詩篇 89:7; 列王紀上 6:36"> 他做了院子。南邊用捻成的細麻線編織了院子的帷幔，共一百肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一百肘——相當於45.7公尺。1肘=45.7公分。">d</a></sup>。</span>
<span className="v" id="v10" data-v="10"> 帷幔的柱子二十根，柱子的銅底座二十個，柱子上的鉤子和箍環都是銀的。</span>
<span className="v" id="v11" data-v="11"> 北邊也是一百肘，帷幔的柱子二十根，柱子的銅底座二十個，柱子上的鉤子和箍環都是銀的。</span>
<span className="v" id="v12" data-v="12"> 西邊的帷幔是五十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="五十肘——相當於22.9公尺；下同。1肘=45.7公分。">e</a></sup>，帷幔的柱子十根，柱子的底座十個，柱子上的鉤子和箍環都是銀的。</span>
<span className="v" id="v13" data-v="13"> 東邊，就是日出的方向，也是五十肘：</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:14"> 門的一邊，帷幔十五肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="十五肘——相當於6.9公尺；下同。">f</a></sup>，帷幔的柱子三根，柱子的底座三個；</span>
<span className="v" id="v15" data-v="15"> 門的另一邊也一樣，院子門口兩邊的帷幔各十五肘，帷幔的柱子三根，柱子的底座三個。</span>
<span className="v" id="v16" data-v="16"> 院子四圍所有的帷幔都是用捻成的細麻線編織的。</span>
<span className="v" id="v17" data-v="17"> 柱子的底座都是銅的，柱子上的鉤子和箍環都是銀的，包柱頂的也都是銀的；院子的所有柱子都有銀箍環箍著。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 3:14"> 院子的門簾是用藍色、紫色、朱紅色線和捻成的細麻線，以刺繡的工藝編織；長二十肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="二十肘——相當於9.1公尺。1肘=45.7公分。">g</a></sup>，寬五肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="五肘——相當於2.3公尺。">h</a></sup>之高，與院子的帷幔一樣高。</span>
<span className="v" id="v19" data-v="19"> 帷幔的柱子四根，柱子的銅底座四個，柱子上的鉤子都是銀的，包柱頂的和箍環也都是銀的。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 3:9; 出埃及記 27:19; 以弗所書 2:21–22"> 帳幕和院子四圍所有的橛子都是銅的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 7:44; 民數記 9:15; 歷代志下 24:6"> 以下是有關帳幕，就是見證帳幕的清單，是照著摩西的吩咐清點的；這是祭司亞倫的兒子以塔瑪爾經手的利未人的服事。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 35:30–3; 出埃及記 31:1–5; 詩篇 119:6"> 耶和華所指示摩西的一切，猶大支派中戶珥的孫子、烏利的兒子比撒列都做了。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 35:34; 出埃及記 31:6"> 與他一起的，有但支派中亞希撒抹的兒子亞何利亞伯，能雕刻，能設計，又能用藍色、紫色、朱紅色線和細麻刺繡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 18:16; 民數記 3:47; 利未記 27:25"> 用於做聖所工程一切工作的所有金子，就是搖獻的金子，按聖所的謝克爾<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="謝克爾——重量單位；後來成為貨幣單位。1謝克爾=11.4公克。本章下同。">i</a></sup>標準，是二十九他連得<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="二十九他連得——相當於991.8公斤。1他連得=34.2公斤。">j</a></sup>七百三十謝克爾<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="七百三十謝克爾——相當於8.3公斤。">k</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:12"> 會眾中被數點的人所付的銀子，按聖所的謝克爾標準，是一百他連得<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="一百他連得——相當於3.4公噸；下同。1他連得=34.2公斤。">l</a></sup>一千七百七十五謝克爾<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="一千七百七十五謝克爾——相當於20.2公斤；下同。">m</a></sup>：</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:46; 出埃及記 30:13; 出埃及記 12:37"> 所有通過數點歸入被數之眾的人，每人一比加<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="一比加——相當於5.7公克。1比加=0.5謝克爾=10季拉。">n</a></sup>，按聖所的謝克爾標準，是半謝克爾<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="半謝克爾——相當於5.7公克。">o</a></sup>；二十歲以上的，共六十萬三千五百五十人。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 26:19; 出埃及記 26:25; 出埃及記 26:21"> 一百他連得銀子用來鑄聖所的底座和幔子的底座：一百個底座一百他連得，一個底座一他連得；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 27:17"> 一千七百七十五謝克爾銀子用來做柱子上的鉤子，包上柱頂，並做柱子的箍環。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 搖獻的銅是七十他連得<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="七十他連得——相當於2.4公噸。1他連得=34.2公斤。">p</a></sup>兩千四百謝克爾<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="兩千四百謝克爾——相當於27.4公斤。1謝克爾=11.4公克。">q</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 26:37; 出埃及記 27:17; 出埃及記 27:10"> 這些銅用來做會幕入口的底座、銅祭壇、祭壇用的銅格網、祭壇的一切器具、</span>
<span className="v" id="v31" data-v="31"> 院子四圍的底座、院子門口的底座、帳幕所有的橛子和院子四圍所有的橛子。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 16:1; 出埃及記 12:6; 利未記 23:16–18"> 以色列子孫從埃及地出來後的第三個月的初一<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的初一——輔助詞語。">a</a></sup>，就在那一天，他們來到西奈曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 3:1; 出埃及記 17:1; 出埃及記 3:12"> 他們從利菲迪姆起行，來到了西奈曠野，在曠野中紮營；以色列人就在那裡的山前紮了營。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 3:4; 使徒行傳 7:38; 出埃及記 20:21"> 摩西上到神那裡，耶和華從那山上向他呼喚說：「你要如此對雅各家說，如此告訴以色列子孫：</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:11–12; 以賽亞書 63:9; 以賽亞書 40:31"> 『你們看見了我對埃及所做的事，以及我怎樣把你們背在如鷹的羽翼上，帶你們來到我這裡。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:2; 申命記 7:6; 申命記 26:18"> 現在，如果你們留心聽我的聲音，遵守我的約，你們就會在萬民中作我珍貴的產業，因為全地都是屬於我的。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 5:10; 彼得前書 2:9; 彼得前書 2:5"> 你們要歸我作祭司的國度和聖潔的國民。』這些話你要對以色列子孫說。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 4:29–30; 出埃及記 3:16; 哥林多前書 15:1"> 摩西就去召來百姓的長老們，把耶和華指示他的這一切話都陳明在他們面前。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 24:7; 出埃及記 24:3; 約書亞記 24:24"> 全體民眾一同回應說：「耶和華所說的一切，我們都會遵行。」摩西就把百姓的話帶回給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 4:36; 出埃及記 19:16; 出埃及記 24:15–16"> 耶和華對摩西說：「看哪，我要在厚密的雲彩中臨到你那裡，好讓子民聽見我與你說話，他們就會永遠相信你。」摩西把百姓的話告訴了耶和華。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:22; 創世記 35:2; 利未記 11:44–45"> 耶和華對摩西說：「你到子民那裡去，今天和明天要把他們分別為聖，讓他們洗自己的衣服，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 19:16; 出埃及記 34:5; 申命記 33:2"> 為第三天預備好，因為第三天耶和華要在全體民眾眼前降臨在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 12:20–21; 約書亞記 3:4; 出埃及記 19:21"> 你要在子民周圍定下界限，說：『你們要謹慎，不可上這山，也不可碰山的邊界。凡碰這山的，必須被處死；</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 4:16; 希伯來書 12:20; 出埃及記 19:16"> 你們不可用手碰那人，必須用石頭砸死，或用箭射死；無論是牲畜還是人，都不得存活。』號角長鳴的時候，子民才可以上山。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 19:10"> 摩西下了山到百姓那裡，把百姓分別為聖；他們都洗了自己的衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 7:5; 撒母耳記上 21:4–5; 出埃及記 19:11"> 摩西對百姓說：「你們要為第三天預備好，不要與女人親近。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 12:18–19; 詩篇 18:11–14; 希伯來書 12:21"> 到了第三天早晨的時候，山上有雷聲、閃電和濃厚的雲彩，又有極其大的號角聲，營中的全體民眾都戰兢。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 4:10; 申命記 5:5"> 摩西把百姓從營地領出來迎接神，他們都站在山下。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:5; 出埃及記 3:2; 詩篇 144:5"> 那時整座西奈山都冒煙，因為耶和華在火中降臨到山上；山的濃煙上騰，像窯爐的煙那樣，整座山都大大震動。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 81:7; 出埃及記 19:16; 尼希米記 9:13"> 號角聲越來越大，摩西說話，神就在雷聲中回應他。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米記 9:13; 出埃及記 34:2; 出埃及記 19:11"> 耶和華降臨在西奈山，臨到山頂上。耶和華呼喚摩西上山頂，摩西就上去了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 6:19; 出埃及記 3:5; 希伯來書 12:28–29"> 耶和華對摩西說：「你下去警誡子民，免得他們闖過界限到耶和華這裡來看，以致他們中間有許多人滅亡<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="滅亡——原文直譯「倒下」。">b</a></sup>；</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 24:5; 使徒行傳 5:10; 歷代志上 13:9–11"> 又告誡那些接近耶和華的祭司們把自己分別為聖，免得耶和華的怒氣<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的怒氣——輔助詞語。">c</a></sup>向他們發作。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 19:12; 約書亞記 3:4–5"> 摩西對耶和華說：「百姓不能上西奈山，因為你已經警誡了我們，說：『要為這座山定下界限，把它分別為聖。』」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 4:16; 希伯來書 12:18–25; 希伯來書 12:29"> 耶和華對他說：「你下去，與亞倫一起上來；但祭司們和子民不可闖過界限上到耶和華這裡，免得耶和華的怒氣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="的怒氣——輔助詞語。">d</a></sup>向他們發作。」</span>
<span className="v" id="v25" data-v="25"> 於是，摩西下到百姓那裡去告訴他們。</span>
</div>
</div>

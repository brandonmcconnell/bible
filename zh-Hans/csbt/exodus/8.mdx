<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 3:18; 出埃及記 3:12; 出埃及記 5:1"> 耶和華對摩西說：「你到法老那裡去，對他說：『耶和華如此說：讓我的子民走，好使他們服事我。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 78:45; 出埃及記 9:2; 出埃及記 7:14"> 如果你拒絕讓他們走，看哪，我就用青蛙打擊你的全境！</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 105:30; 出埃及記 12:34"> 尼羅河裡將充滿青蛙，青蛙會上來，進入你的宮殿、你的臥室，上你的床榻，進入你臣僕的房屋，上到你的子民身上，進入你的火爐、你的揉麵盆。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 19:11; 但以理書 4:37; 使徒行傳 12:22–23"> 青蛙也會上到你身上，上到你的子民和你所有的臣僕身上。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 7:19"> 耶和華對摩西說：「你要對亞倫說：『拿你的杖，伸出你的手在河流、運河、池塘之上，使青蛙上到埃及地。』」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 105:30; 詩篇 78:45; 啟示錄 16:13"> 亞倫伸出他的手在埃及的眾水之上，青蛙就上來，遮蓋了埃及地。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 7:11; 出埃及記 7:22; 申命記 13:1–3"> 術士們也用他們的邪術照樣做，使青蛙上到埃及地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 10:17; 出埃及記 9:28; 出埃及記 8:25–28"> 於是法老召來摩西和亞倫，說：「請你們向耶和華祈求，使這些青蛙離開我和我的子民，我就讓以色列人走，好使他們向耶和華獻祭。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 18:25; 以賽亞書 10:15; 士師記 7:2"> 摩西對法老說：「請指示我什麼時候為你、你的臣僕和你的子民祈求，使這些青蛙從你那裡、從你的宮殿中被除去，只留在尼羅河裡。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 46:9; 詩篇 86:8; 歷代志上 17:20"> 法老回答：「明天。」<br />摩西說：「就照著你的話吧，好讓你知道我們的神耶和華無與倫比！</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 8:3; 出埃及記 8:9"> 這些青蛙將離開你、你的宮殿、你的臣僕和你的子民，只留在尼羅河裡。」</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 5:16–18; 出埃及記 8:30; 出埃及記 10:18"> 摩西和亞倫從法老那裡出來，摩西為加給法老的蛙災<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="蛙災——原文直譯「青蛙的事」。">a</a></sup>，向耶和華呼求。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 34:10–12"> 耶和華就照著摩西所求的做了。於是在房屋、院子和田野中的青蛙都死了。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 8:24; 出埃及記 7:21; 約珥書 2:20"> 人們把青蛙一堆一堆積聚起來，那地就發臭了。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:10; 傳道書 8:11; 希伯來書 3:8"> 然而，法老看見災禍有所緩解，就硬著心，不聽從摩西和亞倫，正如耶和華所說的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 8:5; 出埃及記 8:17"> 耶和華對摩西說：「你要對亞倫說：『伸出你的杖，擊打地上的塵土，使塵土在埃及全地變成蠓蚋。』」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 105:31; 以賽亞書 23:9; 使徒行傳 12:23"> 他們就這樣做了。亞倫伸出手中的杖擊打了地上的塵土，人和牲畜的身上就都有了蠓蚋；在埃及全地，地上所有的塵土都變成了蠓蚋。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:11; 出埃及記 9:11; 但以理書 5:8"> 術士們也用他們的邪術照樣做，要變出蠓蚋來，卻是不能。這樣，人和牲畜的身上都有了蠓蚋。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:20; 詩篇 8:3; 出埃及記 7:5"> 術士們就對法老說：「這是神的手指所做的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="所做的——輔助詞語。">b</a></sup>。」然而，法老的心剛硬，不聽從摩西和亞倫，正如耶和華所說的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 7:15; 出埃及記 9:13; 出埃及記 8:1"> 耶和華對摩西說：「你要清早起來，站到法老面前。看哪，他會出來到水邊！你要對他說：『耶和華如此說：讓我的子民走，好使他們服事我。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:45; 以賽亞書 7:18; 詩篇 105:31"> 如果你不讓我的子民走，看哪，我就打發成群的蒼蠅落在你、你的臣僕和你的子民身上，進入你的宮殿！埃及人的房屋和他們的所在之地都將充滿成群的蒼蠅。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 9:4; 瑪拉基書 3:18; 出埃及記 10:23"> 到那日，我會把我子民所住的歌珊地分別出來，使那裡沒有成群的蒼蠅，好讓你知道在這地上，我是耶和華。</span>
<span className="v" id="v23" data-v="23"> 我要把我的子民和你的子民區分開來。明天必有這神蹟。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 105:31; 詩篇 78:45; 出埃及記 8:21"> 耶和華就這樣做了。無數成群的蒼蠅進入了法老的宮殿和他臣僕的房屋；在埃及全地，因成群的蒼蠅，地都毀壞了。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 8:8; 出埃及記 9:27; 出埃及記 10:16"> 法老召來摩西和亞倫，說：「你們去，在這地向你們的神獻祭吧！」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 43:32; 創世記 46:34; 申命記 7:25–26"> 摩西說：「這樣做不妥，因為我們獻給我們神耶和華的祭是埃及人所憎惡的。看哪，如果我們把埃及人所憎惡的在他們眼前獻為祭，難道他們不會用石頭砸死我們嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:18; 出埃及記 3:12; 出埃及記 34:11"> 我們必須在曠野中走三天的路程，照著我們的神耶和華對我們所說的向他獻祭。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及記 8:8; 出埃及記 9:28; 列王紀上 13:6"> 法老說：「我會讓你們走，好使你們在曠野向你們的神耶和華獻祭，只是不可走得太遠。請你們為我祈求！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及記 8:15; 耶利米書 42:20–21; 出埃及記 8:8"> 摩西說：「看哪，我從你這裡出去會向耶和華祈求，使成群的蒼蠅明天離開法老、他的臣僕和他的子民！只是法老不可再愚弄我們，不讓以色列百姓走，去向耶和華獻祭。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 8:12; 出埃及記 9:33; 雅各書 5:16"> 摩西從法老那裡出來，向耶和華祈求。</span>
<span className="v" id="v31" data-v="31"> 耶和華就照著摩西所求的做了。於是成群的蒼蠅離開了法老、他的臣僕和他的子民，連一隻也沒有留下。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 8:15; 出埃及記 4:21; 羅馬書 2:5"> 然而，這一次法老又硬著心，不讓以色列百姓走。</span>
</div>
</div>

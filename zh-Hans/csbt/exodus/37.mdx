<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 25:10–20; 出埃及記 26:33; 民數記 10:33–36"> 比撒列用金合歡木做了一個櫃，長二肘半<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二肘半——相當於114.3公分。1肘=45.7公分。">a</a></sup>，寬一肘半<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一肘半——相當於68.6公分；下同。">b</a></sup>，高一肘半。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 30:3"> 他把櫃的裡裡外外都包上了純金，並在它的四圍鑲上了金邊；</span>
<span className="v" id="v3" data-v="3"> 又為它鑄了四個金環，安裝在它的四個腳上，兩個環在一邊，兩個環在另一邊。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 9:15; 彼得前書 1:7; 民數記 4:14–15"> 他用金合歡木做了兩根杠，把它們包上了金，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 4:15; 撒母耳記下 6:3–7; 民數記 1:50"> 把杠穿進櫃兩邊的環中，用來抬櫃。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯來書 9:5; 提多書 2:14; 羅馬書 3:25"> 他用純金做了施恩座<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="施恩座——或譯作「贖罪蓋」；下同。">c</a></sup>，長二肘半<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="二肘半——相當於114.3公分。1肘=45.7公分。">d</a></sup>，寬一肘半<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一肘半——相當於68.6公分。">e</a></sup>；</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 10:2; 詩篇 104:4; 詩篇 80:1"> 又在施恩座的兩端，用金子造了兩個基路伯，錘擛成形——</span>
<span className="v" id="v8" data-v="8"> 一端造一個基路伯，另一端也造一個基路伯，從施恩座的兩端造出基路伯。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 1:51; 希伯來書 1:14; 創世記 28:12"> 兩個基路伯向上展開翅膀，用它們的翅膀遮掩施恩座，它們的臉彼此相向；基路伯的臉朝向施恩座。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 1:14; 以西結書 40:39–42; 瑪拉基書 1:12"> 他用金合歡木做了一張桌子，長二肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二肘——相當於91.4公分。">f</a></sup>，寬一肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一肘——相當於45.7公分。">g</a></sup>，高一肘半<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一肘半——相當於68.6公分。">h</a></sup>。</span>
<span className="v" id="v11" data-v="11"> 他把桌子包上了純金，並在它的四圍鑲上了金邊；</span>
<span className="v" id="v12" data-v="12"> 在它的四圍做了一掌寬<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一掌寬——相當於7.4公分。">i</a></sup>的邊框，並在它的邊框四圍鑲上了金邊；</span>
<span className="v" id="v13" data-v="13"> 又為它鑄了四個金環，安裝在它的四角，就是它的四個腿上。</span>
<span className="v" id="v14" data-v="14"> 環靠近邊框，用來穿杠抬桌子。</span>
<span className="v" id="v15" data-v="15"> 他用金合歡木做了兩根杠，把它們包上了金，用來抬桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:29; 列王紀上 7:50; 列王紀下 12:13"> 他做了桌子上澆奠用的器具：盤、碟、壺和杯；這些都是純金的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 25:31–39; 希伯來書 9:2; 歷代志下 13:11"> 他用純金做了一個燈臺，燈臺是錘擛成形的——它的底座、枝幹、花杯、花萼和花瓣都與燈臺一體錘出。</span>
<span className="v" id="v18" data-v="18"> 從燈臺的兩邊伸出六根枝幹，三根枝幹在一邊，三根枝幹在另一邊。</span>
<span className="v" id="v19" data-v="19"> 在一邊的每根枝幹上有三個杏花形狀的花杯，每個都有花萼和花瓣；在另一邊的每根枝幹上也有三個杏花形狀的花杯，每個都有花萼和花瓣；從燈臺伸出的六根枝幹都是這樣。</span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 12:5; 耶利米書 1:11; 出埃及記 25:33"> 燈臺的主幹<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="的主幹——輔助詞語。">j</a></sup>上有四個杏花形狀的花杯，每個都有花萼和花瓣；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 25:35"> 從燈臺伸出的第一對兩根枝幹下面有一個花萼，第二對兩根枝幹下面有一個花萼，第三對兩根枝幹下面也有一個花萼；從燈臺伸出的六根枝幹都是這樣。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:5; 出埃及記 25:31; 詩篇 51:17"> 它們的花萼和枝幹與燈臺一體錘出，整個燈臺都用同一塊純金錘成。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 1:12; 出埃及記 25:37; 啟示錄 1:20–1"> 他做了燈臺的七盞燈，以及燈臺的燈剪和燈盤，都是純金的；</span>
<span className="v" id="v24" data-v="24"> 用一他連得<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一他連得——相當於34.2公斤。">k</a></sup>純金做了燈臺和燈臺的一切器具。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:1–5; 希伯來書 7:25; 啟示錄 8:3–4"> 他用金合歡木造了一座香壇，長一肘<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="一肘——相當於45.7公分；下同。">l</a></sup>，寬一肘，是方形的，高二肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="二肘——相當於91.4公分。">m</a></sup>；犄角從壇而出。</span>
<span className="v" id="v26" data-v="26"> 他把壇包上純金，壇的頂部、壇的四邊和壇的犄角都包上了，並在壇的四圍鑲上了金邊；</span>
<span className="v" id="v27" data-v="27"> 又在金邊之下、在壇的相對兩邊為壇做了兩個金環，用來穿杠抬壇。</span>
<span className="v" id="v28" data-v="28"> 他用金合歡木做了兩根杠，把它們包上了金。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 141:2; 希伯來書 7:25; 約翰一書 2:20"> 他用調配師的做法製作了聖膏油和純淨的芬芳香。</span>
</div>
</div>

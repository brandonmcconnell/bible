<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 4:3; 瑪拉基書 1:13–14; 出埃及記 12:5"> 「你要為他們做以下的事，使他們分別為聖，作祭司事奉我：取一頭公牛、兩隻無瑕疵的公綿羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 6:15; 利未記 2:15; 利未記 7:12"> 以及無酵餅、調了油的無酵餅和抹上油的無酵薄餅；你要用麥子的細麵粉做這些餅。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 6:17; 利未記 8:26; 利未記 8:2"> 你要把這些餅放在一個籃子裡，用籃子帶來，也把公牛和兩隻公綿羊都帶來。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 40:12; 希伯來書 10:22; 出埃及記 26:36"> 你要把亞倫和他的兒子們帶到會幕的入口，用水洗他們；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 28:2–8; 利未記 8:7–8"> 拿來衣裝，給亞倫穿上袍子、以弗得的外袍、以弗得和胸牌，給他束上以弗得的精巧織帶；</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 8:9; 出埃及記 28:36–39"> 並且把頂冠戴在他的頭上，把聖冠安在頂冠上；</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 35:25; 利未記 21:10; 約翰福音 3:34"> 又拿來膏油，澆在他的頭上，膏抹他。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 8:13; 出埃及記 28:40"> 然後你要把他的兒子們帶來，給他們穿上袍子，</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 18:7; 利未記 8:22–28; 申命記 18:5"> 給亞倫和他的兒子們束上腰帶，戴上頭巾。這樣，他們就按著永遠的律例擁有祭司的職份。你要這樣使亞倫和他的兒子們承接聖職。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 1:4; 利未記 8:14; 出埃及記 29:15"> 「你要把公牛帶到會幕前，亞倫和他的兒子們要按手在這公牛的頭上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 9:8; 利未記 9:12; 出埃及記 29:4"> 你要在耶和華面前，在會幕的入口，宰殺這公牛，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 27:2; 利未記 9:9; 利未記 8:15"> 取一些公牛的血，用手指抹在祭壇犄角上，把其餘的血全都倒在祭壇的基座那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 3:3–4; 撒母耳記上 2:16; 利未記 9:10"> 你要取出所有覆蓋內臟的脂肪、肝葉、兩個腎臟和其上的脂肪，在祭壇上燒獻為煙。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 4:11–12; 利未記 4:21; 出埃及記 30:10"> 至於公牛的肉、皮、糞便，都要在營地外面用火燒掉。這是贖罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 29:19; 出埃及記 29:3; 利未記 8:18–21"> 「你要取一隻公綿羊，亞倫和他的兒子們要按手在這公綿羊的頭上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 29:11–12"> 你要宰殺這公綿羊，取一些血，灑在祭壇四壁。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 4:14; 利未記 1:13; 利未記 1:9"> 你要把公綿羊切成碎塊，洗淨內臟和腿，把它們與碎塊和頭放在一起，</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 8:21; 腓立比書 4:18; 創世記 22:7"> 把整隻公綿羊在祭壇上燒獻為煙。這是獻給耶和華的燔祭，是獻給耶和華的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 29:3; 利未記 8:22–29"> 「你要取另一隻公綿羊，亞倫和他的兒子們要按手在這公綿羊的頭上。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 50:5; 希伯來書 10:22; 利未記 14:16"> 你要宰殺這公綿羊，取一些血，抹在亞倫的右耳垂和他兒子們的右耳垂上，以及他們右手的拇指和右腳的拇趾上，把其餘的血灑在祭壇四壁。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 9:22; 出埃及記 29:7; 出埃及記 29:1"> 你要取一些祭壇上的血，也取一些膏油，彈灑在亞倫和他的衣服上，以及他的兒子們和他們的衣服上。這樣，亞倫和他的衣服，他的兒子們和他們的衣服，就都分別為聖了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:13; 利未記 9:21; 利未記 9:19"> 「你要從這公綿羊取出脂肪、肥尾巴、覆蓋內臟的脂肪、肝葉、兩個腎臟和其上的脂肪，以及右大腿，因為這是聖職禮所用的公綿羊；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:2–3; 利未記 8:26"> 又要從耶和華面前的無酵餅籃子裡取一塊餅、一塊油餅和一塊薄餅；</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 7:30; 利未記 8:27; 利未記 9:21"> 你要把這一切都放在亞倫的手中和他兒子們的手中，作為搖獻祭物在耶和華面前搖一搖。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:28; 出埃及記 29:41; 利未記 3:16"> 然後，你要從他們的手中把這些取過來，連同燔祭在祭壇上燒獻為煙，作為耶和華面前的馨香之氣。這是獻給耶和華的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未記 8:29; 利未記 7:31; 利未記 7:34"> 「你要取亞倫聖職禮所用的公綿羊的胸肉，作為搖獻祭物在耶和華面前搖一搖；這是你的份。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 10:15; 民數記 18:11; 申命記 18:3"> 搖獻的胸肉和供物的大腿，就是亞倫和他的兒子們聖職禮所用的公綿羊身上取下被搖過被奉上的部分，你要分別為聖。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 15:19–20; 利未記 7:11–38; 利未記 10:14–15"> 這是亞倫和他的子孫從以色列子孫所得永遠的份例，因為這是供物；這是從以色列子孫所得、從他們的平安祭物中取出的供物，獻給耶和華的供物。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 18:8; 出埃及記 28:3–4; 出埃及記 30:30"> 「亞倫的聖衣要傳給他的後代子孫，他們要穿著受膏抹，承接聖職。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 20:28; 利未記 13:5; 使徒行傳 20:6–7"> 亞倫的子孫中接替他作祭司的，進入會幕在聖所中事奉，都要穿聖衣七天。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 8:31; 撒母耳記上 2:13; 以西結書 46:20–24"> 「你要取聖職禮所用的公綿羊，在神聖的地方煮牠的肉。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 12:4; 出埃及記 29:23; 出埃及記 29:2–3"> 亞倫和他的兒子們要在會幕的入口吃公綿羊的肉和籃子裡的餅。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 18:4; 利未記 10:13–18; 詩篇 22:26"> 他們承接聖職、分別為聖時用來贖罪的那些祭物，只有他們可以吃，他們以外的人不可以吃，因為那些是神聖之物。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 12:10; 利未記 8:32; 出埃及記 29:22"> 聖職禮所用的肉或餅，如果有剩下的留到早晨，就要用火燒掉，不可以吃，因為那是神聖之物。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及記 29:30; 利未記 14:8–11; 利未記 8:4–36"> 「你要照著我吩咐你的一切，向亞倫和他的兒子們這樣做，用七天使他們承接聖職。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 10:11; 希伯來書 9:22–23; 出埃及記 30:28–29"> 你要每天獻一頭公牛作為贖罪祭用來贖罪；你要為祭壇行贖罪禮，使它潔淨；要膏抹它，使它分別為聖。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 40:10; 馬太福音 23:19; 出埃及記 30:28–29"> 你要為祭壇行贖罪禮七天，使它分別為聖。這樣，祭壇就成為至聖的，所有碰祭壇的也都分別為聖了。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志下 2:4; 歷代志上 16:40; 民數記 28:3–8"> 「以下是你要在祭壇上所獻的：每天兩隻一歲的羊羔，持續不斷；</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 46:13–15; 列王紀下 16:15; 詩篇 5:3"> 早晨獻上一隻羊羔，黃昏的時候獻上另一隻羊羔。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 2:17; 以西結書 46:14; 約珥書 2:14"> 與第一隻羊羔一同獻上的，要有十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相當於2.2公升。1伊法=22公升。">a</a></sup>細麵粉與四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相當於0.9公升；下同。1欣=3.7公升。">b</a></sup>壓榨的油調和的素祭<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="素祭——輔助詞語。">c</a></sup>，以及四分之一欣酒的酒祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 46:13–15; 列王紀上 18:29; 詩篇 141:2"> 第二隻羊羔要在黃昏的時候獻上，要一同獻上早晨那樣的素祭和酒祭。這是獻給耶和華的馨香火祭。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及記 25:22"> 這要作為你們世世代代常獻的燔祭，在會幕的入口，在耶和華面前——在那裡我要與你們相會，在那裡向你說話。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 8:11; 歷代志下 7:1–3; 瑪拉基書 3:1"> 在那裡我要與以色列子孫相會，那裡就必因我的榮耀分別為聖。</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 21:15; 利未記 22:9; 利未記 22:16"> 我要使會幕和祭壇分別為聖，也要使亞倫和他的兒子們分別為聖，作祭司事奉我。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 26:12; 哥林多後書 6:16; 出埃及記 25:8"> 我要住在以色列子孫中間，作他們的神。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 20:2; 耶利米書 31:33; 以西結書 20:5"> 這樣他們就知道：我是耶和華他們的神，是我把他們從埃及地領出來，為要居住在他們中間。我是耶和華他們的神。</span>
</div>

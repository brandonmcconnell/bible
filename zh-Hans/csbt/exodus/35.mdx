<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 34:32; 出埃及記 31:1–11; 羅馬書 2:13"> 摩西招聚全體以色列會眾，對他們說：「以下是耶和華指示你們要做的事：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:3; 路加福音 13:14–15; 出埃及記 20:9–10"> 六天可以做工，但第七天對你們是完全安息的安息日，是歸耶和華為聖的；任何人在這日做工，就要被處死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 16:23; 民數記 15:32–36; 出埃及記 12:16"> 在安息日，你們居住的任何地方都不可生火。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:1–2"> 摩西對全體以色列會眾說：「耶和華所指示的話是這樣的，他說：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 9:7; 詩篇 110:3; 出埃及記 25:2–7"> 你們要從你們中間拿供物獻給耶和華；凡甘心樂意的，就把獻給耶和華的供物帶來：金、銀、銅，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 26:7–14; 出埃及記 26:31; 出埃及記 28:15"> 藍色線、紫色線、朱紅色線、細麻、山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染紅的公綿羊皮、海獅皮，金合歡木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 27:20; 出埃及記 25:1–40; 出埃及記 30:23"> 點燈的油、製作膏油和芬芳香的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 39:6–14; 出埃及記 28:9; 出埃及記 25:5"> 以及以弗得和胸牌上用的紅瑪瑙石和鑲嵌的寶石。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 31:1–6; 出埃及記 36:1–4"> 「你們中間一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直譯「心裡有智慧」；本章下同。">a</a></sup>的，都要來做耶和華所吩咐的一切：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:1–37; 出埃及記 36:8–34; 出埃及記 31:7–9"> 帳幕——帳幕的罩篷、頂罩、鉤子、木板、橫閂、柱子、底座、</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 25:10–22; 出埃及記 26:31–33; 出埃及記 37:1–9"> 櫃和櫃的杠、施恩座、簾幕的幔子、</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 25:23–30; 利未記 24:5–6; 出埃及記 37:10–16"> 桌子和桌子的杠、桌子的一切器具、陳設餅、</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 25:31–39; 馬太福音 5:14–15; 出埃及記 37:17–24"> 點燈的燈臺和燈臺的器具、燈和點燈的油、</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 30:1–10; 出埃及記 30:22–38; 出埃及記 37:25–28"> 香壇和香壇的杠、膏油和芬芳香、帳幕入口的門簾、</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 27:1–8; 出埃及記 30:18–21; 出埃及記 38:1–8"> 燔祭的祭壇、祭壇用的銅格網、祭壇的杠、祭壇的一切器具、洗濯盆和盆座、</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 7:2; 出埃及記 38:9–20; 出埃及記 27:9–19"> 院子的帷幔、帷幔的柱子、底座、院子的門簾、</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 27:19"> 帳幕的橛子、院子的橛子、帳幕和院子的繩子、</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 31:10; 民數記 4:5–15; 出埃及記 28:1–43"> 聖所事奉用的編織的衣服——祭司亞倫的聖衣和他兒子們作祭司事奉時的衣服。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 全體以色列會眾就從摩西面前出去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 25:2; 出埃及記 35:26; 歷代志上 29:14"> 凡是心裡受激勵、甘心奉獻的人都來了，把獻給耶和華的供物帶來，用於做會幕的工作、各樣的服事和聖衣。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 7:70–72; 馬太福音 2:11; 以斯拉記 2:68–69"> 凡甘心樂意的男男女女都來了，把胸針、耳環、戒指、項鏈和一切的金器都帶來；他們每個人都把這些搖一搖，作為搖獻的金祭物，獻給耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 29:8; 出埃及記 25:2–7; 出埃及記 35:6–10"> 凡有藍色線、紫色線、朱紅色線、細麻、山羊毛、染紅的公綿羊皮、海獅皮的人，都把它們帶來了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 8:12"> 凡奉上銀或銅為供物的，都把獻給耶和華的供物帶來了。凡有金合歡木用於工程上各樣工作的，都把它們帶來了。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡有才能的女人都親手紡線，把所紡的藍色線、紫色線、朱紅色線和細麻都帶來了。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:21; 出埃及記 36:8; 出埃及記 35:29"> 凡心裡受激勵、有智慧的女人，都紡山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 2:68; 歷代志上 29:6; 出埃及記 35:9"> 首領們把以弗得和胸牌上用的紅瑪瑙石和鑲嵌的寶石、</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 30:23–38; 出埃及記 35:8"> 點燈的油、製作膏油和芬芳香的香料，都帶來了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 9:7; 出埃及記 35:21–22; 出埃及記 35:4"> 凡是甘心奉獻的以色列子孫，無論男女，都把甘心奉獻物帶來給耶和華，為要做耶和華藉著摩西所指示的一切工作。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 31:1–6; 雅各書 1:17; 哥林多前書 12:11"> 摩西對以色列子孫說：「你們看，耶和華已經提名召喚了猶大支派中戶珥的孫子、烏利的兒子比撒列！</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 1:17; 以賽亞書 11:2–5; 以賽亞書 61:1–3"> 耶和華用神的靈充滿了他，使他有智慧、聰慧、知識、各樣的技藝，</span>
<span className="v" id="v32" data-v="32"> 能構思藝術設計，能做金、銀、銅的工藝，</span>
<span className="v" id="v33" data-v="33"> 能做鑲嵌寶石的石雕工藝，又能做木雕工藝，為要做各樣的精巧工藝。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 31:6; 歷代志下 2:14; 以斯拉記 7:27"> 耶和華又把指教的能力放在他和但支派中亞希撒抹的兒子亞何利亞伯的心裡；</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 35:31; 列王紀上 7:14; 以賽亞書 28:26"> 並用智慧充滿他們的心，使他們擅長做各樣的工藝——雕刻，設計，用藍色、紫色、朱紅色線和細麻刺繡，以及紡織——使他們成為做各樣工藝的人和構思藝術設計的人。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 36:8–19; 出埃及記 26:36; 出埃及記 26:31"> 「你要用十幅幔帳造帳幕，幔帳要用捻成的細麻線和藍色、紫色、朱紅色線編織，以精巧的工藝繡上基路伯。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 7:2; 民數記 4:25; 歷代志上 17:1"> 每幅幔帳長二十八肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二十八肘——相當於12.8公尺。1肘=45.7公分。">a</a></sup>，每幅幔帳寬四肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四肘——相當於1.8公尺。">b</a></sup>，所有幔帳的尺寸都要一樣。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 36:10; 歌羅西書 2:2; 以弗所書 2:21–22"> 五幅幔帳要彼此相連，另五幅幔帳也要彼此相連。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 36:11–12; 出埃及記 36:17; 出埃及記 26:10–11"> 在一組幔帳的最後一幅邊上，要用藍色線做扣環；在另一組幔帳的最後一幅邊上，也要照樣做。</span>
<span className="v" id="v5" data-v="5"> 在一組幔帳的邊上，要做五十個扣環；在另一組幔帳的邊上，也要做五十個扣環，扣環彼此相對。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 36:13; 出埃及記 26:11; 出埃及記 26:33"> 你要做五十個金鉤，用這些鉤子把兩組幔帳彼此相連為一大幅<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="為一大幅——輔助詞語。">c</a></sup>，好使帳幕成為一個整體。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 26:14; 詩篇 45:13; 出埃及記 26:9"> 「你要用山羊毛做幔帳，作為帳幕上的罩篷，要做十一幅幔帳。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 26:13; 出埃及記 26:2"> 每幅幔帳長三十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三十肘——相當於13.7公尺。1肘=45.7公分。">d</a></sup>，每幅幔帳寬四肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="四肘——相當於1.8公尺。">e</a></sup>，十一幅幔帳的尺寸都要一樣。</span>
<span className="v" id="v9" data-v="9"> 你要把五幅幔帳連成一組，把另外的六幅幔帳也連成一組，並把第六幅幔帳在罩篷的前部疊上去。</span>
<span className="v" id="v10" data-v="10"> 在一組幔帳的最後一幅邊上，要做五十個扣環；在另一組幔帳的邊上，也要做五十個扣環。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:3; 出埃及記 26:6"> 你要做五十個銅鉤，把這些鉤子鉤入扣環，把罩篷連起來，好使它成為一個整體。</span>
<span className="v" id="v12" data-v="12"> 罩篷幔帳遮蓋帳幕<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="遮蓋帳幕——輔助詞語。">f</a></sup>多出的部分，就是多出的半幅幔帳，要垂在帳幕的後面。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 26:2; 出埃及記 26:8"> 罩篷幔帳遮蓋那大幅幔帳<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="遮蓋那大幅幔帳——輔助詞語。">g</a></sup>多出的長度，要一肘在一邊，一肘在另一邊，垂在帳幕的兩邊——在一邊和另一邊，好遮蓋帳幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 36:19; 出埃及記 25:5; 出埃及記 35:23"> 你要用染紅的公綿羊皮為罩篷做一個遮蓋，其上再用海獅皮做一個頂罩。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 36:20–33; 民數記 4:31–32; 出埃及記 40:17–18"> 「你要用金合歡木為帳幕做豎板。</span>
<span className="v" id="v16" data-v="16"> 每塊木板長十肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十肘——相當於4.6公尺。1肘=45.7公分。">h</a></sup>，每塊木板寬一肘半<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一肘半——相當於0.7公尺。">i</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 36:22; 出埃及記 26:19; 出埃及記 36:24"> 每塊木板要有兩個榫頭，彼此並列<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="彼此並列——或譯作「使木板彼此連接」。">j</a></sup>；帳幕所有的木板都要這樣做。</span>
<span className="v" id="v18" data-v="18"> 你要為帳幕做木板，為南邊，就是朝南的那邊，做二十塊木板；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 38:27; 出埃及記 38:30–31; 出埃及記 26:37"> 在這二十塊木板底下，做四十個銀底座；一塊木板底下有兩個底座連接它的兩個榫頭，下一塊木板底下也有兩個底座連接它的兩個榫頭。</span>
<span className="v" id="v20" data-v="20"> 你要為帳幕的另一邊，就是北邊，做二十塊木板，</span>
<span className="v" id="v21" data-v="21"> 以及四十個銀底座；一塊木板底下有兩個底座，下一塊木板底下也有兩個底座。</span>
<span className="v" id="v22" data-v="22"> 你也要為帳幕的後部，就是西面，做六塊木板；</span>
<span className="v" id="v23" data-v="23"> 並在帳幕後部的兩個邊角做兩塊木板，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 36:29–30; 詩篇 133:1–3; 哥林多前書 1:10"> 兩個邊角要雙層，雙層木板從下端到頂端完全對齊，頂端用一個環扣住；兩塊木板都要這樣，形成兩個凸角。</span>
<span className="v" id="v25" data-v="25"> 這樣共有八塊木板和十六個銀底座；一塊木板底下有兩個底座，下一塊木板底下也有兩個底座。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="羅馬書 15:1; 民數記 4:31; 加拉太書 6:1–2"> 「你要用金合歡木做橫閂，為帳幕一邊的木板做五根，</span>
<span className="v" id="v27" data-v="27"> 為帳幕另一邊的木板做五根橫閂，又為帳幕後邊，就是西面的木板，也做五根橫閂。</span>
<span className="v" id="v28" data-v="28"> 在木板中部，中間那根橫閂，從一端穿到另一端。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 25:11–12"> 你要把木板包上金，又用金子做其上的環，用來穿橫閂；橫閂也要包上金。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 25:40; 希伯來書 8:5; 出埃及記 25:9"> 你要照著在山上向你指明的規制，把帳幕立起來。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 27:51; 歷代志下 3:14; 出埃及記 36:35"> 「你要用藍色、紫色、朱紅色線和捻成的細麻線編織幔子，以精巧的工藝繡上基路伯。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 26:37; 出埃及記 36:38; 以斯帖記 1:6"> 你要把幔子垂掛在四根包金的金合歡木柱子上；柱子上有金鉤，柱子在四個銀底座上。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 9:2–3; 利未記 16:2; 出埃及記 40:21"> 你要把幔子垂掛在鉤子之下，把見證櫃抬進幔子內；這幔子就為你們隔開了聖所和至聖所。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 40:20; 出埃及記 25:21; 希伯來書 9:5"> 你要把施恩座安放在至聖所裡的見證櫃上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 40:24; 出埃及記 40:22; 希伯來書 9:2"> 你要把桌子放在幔子外，把燈臺放在桌子對面，在帳幕的南邊；桌子要安置在帳幕的北邊。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及記 36:37; 民數記 9:15; 出埃及記 26:31"> 「你要用藍色、紫色、朱紅色線和捻成的細麻線，以刺繡的工藝，為帳篷的入口編織簾幕。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 36:38"> 你要用金合歡木為簾幕做五根柱子，把柱子包上金，柱子上有金鉤；又要為柱子鑄五個銅底座。</span>
</div>
</div>

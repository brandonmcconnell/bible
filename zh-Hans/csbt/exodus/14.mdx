<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及記" data-chapter="14" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:1; 出埃及記 13:1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 33:7–8; 耶利米書 44:1; 出埃及記 13:17–18"> 「你要吩咐以色列子孫轉回去，在比哈希錄前面，密奪和海之間紮營，就是在巴力洗分前面，面對著它，靠著海邊紮營。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 4:28; 撒母耳記上 23:23; 詩篇 71:11"> 這樣，法老就會說以色列子孫在這地迷了路，曠野把他們困住了。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:22–23; 出埃及記 7:5; 羅馬書 9:17"> 那時我要使法老的心剛硬，他會追趕他們，但我必藉著法老和他的全軍得榮耀，埃及人就知道我是耶和華。」於是以色列子孫就這樣做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 105:25; 出埃及記 12:33; 路加福音 11:24–26"> 有人向埃及王報告以色列百姓逃走了；法老和他的臣僕就對以色列百姓改變了心意，說：「我們做的這是什麼呢？居然讓以色列人走，不再服事我們。」</span>
<span className="v" id="v6" data-v="6"> 於是法老備好他的戰車，帶著他的軍隊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="軍隊——原文直譯「子民」。">a</a></sup>一起去，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 15:4; 士師記 4:3; 詩篇 68:17"> 又帶著六百輛精選的戰車和埃及其餘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="其餘——輔助詞語。">b</a></sup>所有的戰車，每輛戰車上都有軍官。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:17; 民數記 33:3; 申命記 26:8"> 耶和華使埃及王法老的心剛硬，他就追趕以色列子孫；那時以色列子孫正昂然無懼地<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="昂然無懼地——原文直譯「高舉著手」。">c</a></sup>出去。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 15:9; 約書亞記 24:6; 出埃及記 14:2"> 埃及人追趕他們，法老所有的馬匹、戰車、馬兵和軍隊，追上了在海邊紮營的以色列子孫；那地方靠著比哈希錄，在巴力洗分前面。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:7; 詩篇 34:17; 尼希米記 9:9"> 法老逼近的時候，以色列子孫舉目，看哪，埃及人追過來了！以色列子孫就極其害怕，向耶和華呼求。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:7–8; 民數記 14:1–4; 出埃及記 15:23–24"> 他們對摩西說：「難道埃及沒有墳墓，你就把我們帶來死在曠野嗎？你把我們從埃及領出來，你對我們做的這是什麼呢？</span>
<span className="v" id="v12" data-v="12" data-xref="約拿書 4:3; 出埃及記 6:9; 約拿書 4:8"> 我們在埃及的時候，難道沒有對你說過『不要管我們，讓我們服事埃及人』這話嗎？因為服事埃及人總比死在曠野好。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 20:17; 歷代志下 20:15; 出埃及記 14:30"> 摩西對以色列百姓說：「不要害怕，要站穩！看耶和華今天要為你們施行的拯救，因為你們今天所看見的埃及人，你們永遠不會再看見了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 3:22; 申命記 20:4; 歷代志下 20:17"> 耶和華必為你們爭戰，你們要沉默！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 7:10; 以斯拉記 10:4–5; 尼希米記 9:9"> 耶和華對摩西說：「你為什麼向我呼求呢？你要吩咐以色列子孫前行。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 7:19; 出埃及記 4:20; 出埃及記 4:2"> 你要舉起你的杖，向海伸出你的手，把海分開，讓以色列子孫從海中的乾地上過去。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:8; 出埃及記 14:4; 以西結書 34:11"> 而我，看哪，我要使埃及人的心剛硬，他們就會隨著下去。這樣，我必藉著法老、他的全軍、他的戰車和馬兵得榮耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:5; 出埃及記 14:4; 出埃及記 7:17"> 我藉著法老、他的戰車和馬兵得榮耀的時候，埃及人就知道我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 63:9; 出埃及記 32:34; 出埃及記 23:20–21"> 於是，在以色列營地前面行走的神的使者就移動，轉到他們後面；雲柱也從他們前面移動，立在他們後面。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:14; 哥林多後書 2:15–16; 箴言 4:18–19"> 雲柱來到埃及營地和以色列營地之間，一邊是雲彩和黑暗，一邊是火<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="火——輔助詞語。">d</a></sup>照亮夜間。這樣，雙方整夜沒有彼此靠近。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 63:12; 出埃及記 15:8; 詩篇 66:6"> 摩西向海伸出他的手，耶和華就用猛烈的東風颳了整整一夜，使海水退去，把海變成乾地；於是水被分開了，</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:29; 詩篇 66:6; 出埃及記 15:19"> 以色列子孫就從海中的乾地上過去，水在他們的右邊和左邊形成了牆。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 15:19; 出埃及記 14:17; 出埃及記 15:9"> 埃及人追趕過來，法老所有的馬匹、戰車和馬兵都隨著他們下到海中。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 13:21; 詩篇 77:16–19; 出埃及記 14:25"> 到了晨更的時候，耶和華從雲火柱中俯看埃及的軍隊，使埃及的軍隊潰亂，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 14:14; 申命記 3:22; 約伯記 20:24"> 又使他們的車輪脫落，難以駕駛。埃及人就說：「我們從以色列人面前逃跑吧！因為耶和華為他們爭戰，攻擊埃及了。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 14:16; 出埃及記 8:5; 雅各書 2:13"> 耶和華對摩西說：「向海伸出你的手，使水回落淹沒埃及人、他們的戰車和馬兵。」</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 4:18; 詩篇 78:53; 希伯來書 11:29"> 摩西就向海伸出他的手，清晨來臨的時候，海恢復了原狀；埃及人正迎著水逃跑，耶和華就把埃及人抖落在海中。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:53; 詩篇 106:9–11; 哈巴谷書 3:13"> 水一回落，就淹沒了戰車、馬兵，以及隨著以色列子孫下到海中的法老全軍；他們中間連一個也沒有留下。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 14:22; 詩篇 77:19–20; 以賽亞書 43:2"> 以色列子孫卻從海中的乾地上走過，水在他們的右邊和左邊形成了牆。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 106:8; 詩篇 106:10; 詩篇 92:9–11"> 那一天，耶和華拯救以色列人脫離了埃及人的手；以色列人看見埃及人橫尸海邊。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 2:11; 約翰福音 11:45; 約翰福音 2:23–25"> 以色列人看見了耶和華向埃及施展大能的手段，百姓就敬畏耶和華，並相信耶和華和他的僕人摩西。</span>
</div>
</div>

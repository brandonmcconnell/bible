<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 32:19; 出埃及記 31:18; 詩篇 119:89"> 耶和華對摩西說：「你要鑿出兩塊石版，像先前的那樣；我要把你先前摔碎的石版上的話，寫在這兩塊石版上。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:20; 申命記 9:25; 出埃及記 19:11"> 早晨之前，你要預備好；到了早晨，你要上西奈山，在山頂那裡站在我面前。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 19:12–13; 出埃及記 19:21; 提摩太前書 2:5"> 任何人都不可與你一同上來，整座山都不可有人，羊群和牛群也不可在這座山前面吃草。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 摩西就鑿出了兩塊石版，像先前的那樣；他清早起來，照著耶和華所指示他的，上到西奈山，手中拿著兩塊石版。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 33:19; 民數記 11:25; 路加福音 9:34–35"> 耶和華在雲彩中降臨，與摩西一同站在那裡，並宣告耶和華的名。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 86:15; 約珥書 2:13; 詩篇 103:8–13"> 耶和華在摩西面前經過，宣告說：<br />「耶和華，耶和華，是有憐憫、有恩惠的神；他不輕易發怒，有豐盛的慈愛和信實，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 20:5–6; 詩篇 103:3; 申命記 5:9–10"> 為千代存留慈愛，赦免罪孽、過犯和罪惡，但絕不會讓有罪的免於罪責，而會追究罪責，從父親到兒子、孫子，直到第三代、第四代。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:31; 歷代志下 20:18; 創世記 17:3"> 摩西急忙俯身於地下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 33:12; 申命記 32:9; 詩篇 94:14"> 他說：「主啊，如果我在你眼前蒙恩，求主在我們中間同我們一起去！雖然這是硬著頸項的百姓，但求你赦免我們的罪孽和罪惡，以我們為你的繼業。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 10:21; 詩篇 77:14; 以賽亞書 64:3"> 耶和華說：「看哪，我要立約！我要在你眾百姓面前行奇妙的事，是在全地、萬國中沒有行<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行——原文直譯「創造」。">a</a></sup>過的；你所在的萬民中，萬民必看見耶和華的作為，因為我向你行的是可畏的事。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 33:2; 出埃及記 3:17; 出埃及記 3:8"> 我今天吩咐你的，你要遵守。看哪，我必從你們面前驅逐亞摩利人、迦南人、赫提人、比利洗人、希未人、耶布斯人！</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 23:32–33; 約書亞記 23:12–13; 申命記 7:2"> 你要謹慎，不可與你所去之地的居民立約，免得他們成為你們當中的陷阱。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:4; 出埃及記 23:24; 申命記 7:25–26"> 你們要拆毀他們的祭壇，打碎他們的神柱，砍掉他們的亞舍拉柱。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 4:24; 申命記 32:21; 哥林多前書 10:22"> 你不可向別的神明下拜，因為耶和華他的名字是『嫉憤者』，他是嫉憤的神。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 2:17; 詩篇 106:28; 民數記 25:2"> 「你不可與那地的居民立約，因為他們行淫追隨他們的神明、向他們的神明獻祭的時候，有人邀請你，你就會吃他的祭物；</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 7:3–4; 列王紀上 11:2–4; 以斯拉記 9:2"> 你為你的兒子娶來他的女兒，他的女兒行淫追隨她們的神明，就會使你的兒子也行淫追隨她們的神明。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未記 19:4; 出埃及記 32:8; 以賽亞書 46:6–7"> 「不可為自己鑄造神像。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 13:4; 利未記 23:6; 出埃及記 13:6–7"> 「你要守無酵節，照著我吩咐你的，在亞筆月所定的日期吃無酵餅七天，因為你是在亞筆月從埃及出來的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 13:2; 出埃及記 22:29; 出埃及記 13:12"> 「所有的頭胎都屬於我；你的牲畜中所有頭生的，無論是牛是羊，凡是公的都屬於我。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 13:13; 出埃及記 23:15; 申命記 16:16"> 頭生的驢子，你要用羔羊贖回；如果不贖回，就要打斷牠的脖子。你兒子們中所有頭生的，你都要贖回；誰也不可空手朝見我。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:12; 申命記 21:4; 路加福音 13:14"> 「六天你要勞碌，但第七天要安息；在耕種或收割的時候，也要安息。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 23:16; 申命記 16:10–15; 約翰福音 7:2"> 「在收割初熟小麥的時候，你要守七七節；在過年的時候，你要守收藏節。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 23:14; 申命記 16:16; 出埃及記 23:17"> 一年三次，你所有的男子都要朝見主耶和華以色列的神。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:55; 出埃及記 33:2; 箴言 16:7"> 我必從你面前趕出列國，擴寬你的邊界；你一年三次上去朝見耶和華你神的時候，沒有人會貪圖你的土地。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 23:18; 出埃及記 12:10; 哥林多前書 5:7–8"> 「不可把我祭物的血與有酵之物一起獻祭，也不可使逾越節的祭物過夜留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 23:19; 申命記 14:21; 申命記 26:2"> 「要把你土地裡上好的初熟之物帶到你神耶和華的殿中。<br />「不可用母山羊的奶煮牠的小山羊。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及記 24:4; 申命記 31:9; 申命記 4:13"> 耶和華對摩西說：「你要把這些話語記下來，因為我是照著這些話語與你和以色列一起立約的。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及記 34:1; 出埃及記 24:18; 申命記 9:18"> 摩西在那裡與耶和華一起四十晝夜，沒有吃飯沒有喝水。耶和華把這約的話語，就是十誡，寫在兩塊版上。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 17:2; 路加福音 9:29; 出埃及記 32:15"> 摩西從西奈山下來——下山的時候，摩西手中拿著兩塊見證版——摩西不知道自己的臉皮因他與耶和華說話而發光。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:3; 路加福音 5:8; 民數記 12:8"> 亞倫和所有的以色列子孫看見摩西，看哪，他的臉皮發光！他們就害怕接近他。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:15; 出埃及記 24:1–3; 創世記 45:3"> 摩西呼叫他們，亞倫和所有的會眾領袖都回到他那裡，摩西就與他們說話。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 22:14; 出埃及記 24:3; 馬太福音 28:20"> 之後，所有的以色列子孫近前來，摩西就把耶和華在西奈山上與他所說的一切都吩咐他們。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 4:4–6; 哥林多後書 3:13–18; 羅馬書 10:4"> 摩西與他們說完了話，就用帕子蒙上臉。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多後書 3:16; 希伯來書 10:19–22; 希伯來書 4:16"> 每當摩西來到耶和華面前與他說話的時候，摩西就把帕子取下，直到他出來；他出來後，就把耶和華所指示的告訴以色列子孫。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 34:29–30; 約翰福音 5:35; 但以理書 12:3"> 以色列子孫看見摩西的臉，見摩西的臉皮發光，摩西就再次用帕子蒙上臉，直到他進去與耶和華說話。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 18:7; 希伯來書 5:1–5; 民數記 17:2–9"> 「你要從以色列子孫中，把你哥哥亞倫和他的兒子們帶到你這裡，使亞倫、亞倫的兒子納達布、亞比戶、以利亞撒和以塔瑪爾作祭司事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 8:30; 出埃及記 31:10; 啟示錄 19:8"> 你要為你哥哥亞倫做聖衣，以顯出榮耀、華美。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 1:17; 哥林多前書 12:7–11; 以賽亞書 11:2"> 你要吩咐一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直譯「心裡有智慧」。">a</a></sup>的人，就是我用智慧的靈所充滿的人，他們要為亞倫做聖衣，使他分別為聖，作祭司事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 6:14; 啟示錄 9:17; 以賽亞書 59:17"> 以下是他們要做的衣裝：胸牌、以弗得、外袍、編織的袍子、頂冠、腰帶。他們要為你哥哥亞倫和他的兒子們做聖衣，使他們作祭司事奉我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:3–4; 出埃及記 39:2–3"> 他們要拿金色、藍色、紫色、朱紅色線和細麻來做。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 39:2–7; 出埃及記 26:1"> 「他們要用金色、藍色、紫色、朱紅色線和捻成的細麻線，以精巧的工藝做以弗得；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 39:4"> 以弗得要有兩條肩帶與它的兩端相連，使之相連在一起。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 28:27–28; 利未記 8:7; 出埃及記 29:5"> 以弗得上的精巧織帶，要與以弗得的做法一樣，都從同樣的材料——金色、藍色、紫色、朱紅色線和捻成的細麻線織出。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:13; 歷代志下 2:7; 以賽亞書 49:16"> 「你要拿兩塊紅瑪瑙石，在它們上面雕刻以色列兒子們的名字：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 1:1–4; 創世記 43:33"> 六個名字在一塊寶石上，六個名字在另一塊寶石上，都按著他們的家系；</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 2:19; 啟示錄 7:2; 耶利米書 22:24"> 要用寶石匠雕刻印章的工藝，在這兩塊寶石上雕刻以色列兒子們的名字，再把寶石鑲嵌在金槽中。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 28:29; 約書亞記 4:7; 出埃及記 39:6–7"> 你要把這兩塊寶石安在以弗得的肩帶上，為以色列子孫作記念石。亞倫要在耶和華面前把他們的名字背負在他的雙肩上，作為記念。</span>
<span className="v" id="v13" data-v="13"> 你要做兩個金槽，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 39:15; 出埃及記 39:17–18; 列王紀上 7:17"> 又要用編繩子的工藝做兩條純金的鏈子，把繩子一樣的鏈子接在槽上。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 28:30; 出埃及記 26:1; 出埃及記 28:4"> 「你要以精巧的工藝做一個決斷胸牌，要與以弗得的做法一樣，用金色、藍色、紫色、朱紅色線和捻成的細麻線來做。</span>
<span className="v" id="v16" data-v="16"> 胸牌是方形的，疊為雙層，長一拃<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一拃——約20公分；下同。">b</a></sup>，寬一拃。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:13; 出埃及記 39:10–21; 箴言 8:11"> 你要在胸牌上鑲嵌四行寶石：<br /><span className="pl pl-1">第一行是紅寶石、黃玉、綠寶石，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 27:16; 約伯記 28:6; 雅歌 5:14"> <span className="pl pl-1">第二行是綠松石、藍寶石、金剛石，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 54:12; 出埃及記 39:12"> <span className="pl pl-1">第三行是紅鋯石、白瑪瑙、紫晶，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:16; 啟示錄 4:3; 但以理書 10:6"> <span className="pl pl-1">第四行是黃水晶、紅瑪瑙、碧玉。</span><br />這些都要鑲嵌在各自的金槽中。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:12; 啟示錄 7:4–8; 列王紀上 18:31"> 這些寶石都要按著以色列兒子們的名字，十二塊都按著他們的名字，像雕刻印章那樣，按著各自的名字，代表十二個支派。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 「你要在胸牌上用編繩子的工藝做純金的鏈子；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 25:11–15"> 你要在胸牌上做兩個金環，把兩個環接在胸牌上邊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="上邊——輔助詞語。">c</a></sup>的兩端；</span>
<span className="v" id="v24" data-v="24"> 你要把兩條金鏈子接在胸牌上邊<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="上邊——輔助詞語。">d</a></sup>兩端的兩個環中，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 39:15; 出埃及記 39:4; 出埃及記 28:14"> 把兩條鏈子的另兩端接在兩個槽上，連在以弗得前面的肩帶上。</span>
<span className="v" id="v26" data-v="26"> 你要再做兩個金環，把它們安在胸牌下邊<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="下邊——輔助詞語。">e</a></sup>的兩端，在以弗得內側的邊上；</span>
<span className="v" id="v27" data-v="27"> 又做兩個金環，把它們接在以弗得前面的兩條肩帶下面，靠近接縫處，在以弗得的精巧織帶上方。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 15:38; 出埃及記 28:31; 出埃及記 39:30–31"> 你要用藍色的細繩把胸牌的環與以弗得的環連接，使胸牌貼在以弗得的精巧織帶上，使胸牌不致從以弗得上鬆脫。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及記 28:12; 出埃及記 28:30; 耶利米書 30:21"> 「亞倫進入聖所的時候，要把決斷胸牌上以色列兒子們的名字掛在他的胸前，在耶和華面前常作記念。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 7:65; 以斯拉記 2:63; 民數記 27:21"> 你要把烏陵和土明放在決斷胸牌裡；於是亞倫進到耶和華面前的時候，烏陵和土明就會在他的胸前。這樣，亞倫在耶和華面前就常在心中背負著決斷以色列子孫的責任。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 8:7; 出埃及記 28:4; 出埃及記 39:22–26"> 「你要做以弗得的外袍，整件都是藍色的。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 4:16; 約翰福音 19:23–24; 出埃及記 39:28"> 外袍頭部的中間之處，要有一個領口，領口要有圍邊，用紡織的工藝做成，像戰袍的領口那樣，免得撕裂。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 39:24–26; 撒迦利亞書 14:20; 列王紀上 7:18"> 外袍下擺的圍邊上，要用藍色、紫色、朱紅色線做石榴，石榴之間要有金鈴鐺，</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; 約翰福音 15:4–8; 歌羅西書 1:10"> 一個金鈴鐺一個石榴，一個金鈴鐺一個石榴，在外袍下擺的圍邊上。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 9:12; 利未記 16:2"> 亞倫事奉的時候要把外袍穿上；他進入聖所到耶和華面前以及出來的時候，外袍上的鈴聲就會被聽見，他就不致死亡。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒迦利亞書 14:20; 利未記 8:9; 出埃及記 39:30"> 「你要用純金做一面牌子，像雕刻印章那樣，在牌子上面雕刻『歸耶和華為聖』。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及記 29:6; 出埃及記 28:4; 撒迦利亞書 3:5"> 「你要用一條藍色的細繩把金牌繫在頂冠上，就在頂冠的前面。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前書 2:24; 民數記 18:1; 利未記 10:17"> 牌子要在亞倫的額頭上，亞倫要承擔有關神聖之物的罪責——神聖之物是以色列子孫分別為聖的所有神聖的禮物；牌子要常在亞倫的額頭上，好使他們在耶和華面前蒙悅納。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="詩篇 45:14"> 「你要用細麻編織袍子，用細麻布做頂冠，以刺繡的工藝做腰帶。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 39:41; 出埃及記 28:4; 出埃及記 28:2"> 你要為亞倫的兒子們做袍子，為他們做腰帶，為他們做頭巾，以顯出榮耀、華美。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 29:7; 利未記 8:1–36; 出埃及記 40:15"> 你要把這些給你的哥哥亞倫和他的兒子們穿上，又膏抹他們，使他們承接聖職、分別為聖，作祭司事奉我。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 44:18; 利未記 6:10; 利未記 16:4"> 你要用細麻布為他們做褲子，遮蔽下體，從腰間直到大腿。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及記 27:21; 出埃及記 20:26; 利未記 5:17"> 亞倫和他的兒子們進入會幕，或接近祭壇，在聖所事奉的時候，要把褲子穿上，使他們不致承擔罪責而死。這要成為亞倫和他的後裔永遠的律例。</span>
</div>

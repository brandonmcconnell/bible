<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 2:1–2; 創世記 46:8–26; 創世記 35:23–26"> 以色列的兒子們——各帶家屬與雅各一同來到埃及——他們的名字如下：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:22"> <span className="pl pl-1">魯本、西緬、利未、猶大、</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 28:20; 創世記 35:23"> <span className="pl pl-1">以薩迦、西布倫、便雅憫、</span><br /></span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">但、拿弗他利、迦得、亞設。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 10:22; 創世記 46:26–27; 士師記 8:30"> 雅各所有的直系子孫，共有七十人。那時約瑟已經在埃及了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 50:26; 創世記 50:24; 使徒行傳 7:14–16"> 後來約瑟和他所有的兄弟，以及那一代所有的人都死了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:3; 創世記 1:28; 申命記 26:5"> 以色列子孫生養、繁衍、增多，極其強盛，充滿了那地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 7:18; 傳道書 2:18–19; 傳道書 9:15"> 再後來有一位不知道約瑟的新王興起，統治埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 105:24–25; 傳道書 4:4; 雅各書 3:14–16"> 他對自己的子民說：「看哪！以色列民比我們更多、更強大。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 7:19; 詩篇 83:3–4; 箴言 1:11"> 來吧！讓我們精明地對付他們，免得他們增多，一旦戰爭發生，他們就會與我們的仇敵聯合，攻打我們，然後離開這地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="離開這地——原文直譯「從這地上去」。">a</a></sup>。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 15:13; 創世記 47:11; 出埃及記 3:7"> 於是埃及人指派督工來管理以色列子孫，用苦役來苦待他們。他們為法老建造了兩座積貨城：比東和拉美西斯。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 105:24; 出埃及記 1:9; 羅馬書 8:28"> 然而，埃及人越是苦待他們，他們越是增多，越是擴散。埃及人就因以色列子孫的緣故而憂心。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:20"> 於是埃及人更嚴酷地奴役以色列子孫。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 7:19; 民數記 20:15; 出埃及記 2:23"> 埃及人用沉重的勞役——和泥、做磚，以及田野中的各樣勞役——嚴酷地奴役他們的一切勞役，使他們的生活很苦。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 當時埃及王吩咐兩個希伯來接生婆，一個名叫施弗拉，另一個名叫普阿；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 1:22; 馬太福音 21:38; 啟示錄 12:4"> 他說：「你們為希伯來婦女接生，看她們臨盆<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="臨盆——原文直譯「在產床上」。">b</a></sup>的時候，如果所生的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="所生的——輔助詞語。">c</a></sup>是個男嬰<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="男嬰——原文直譯「兒子」。">d</a></sup>，就把他殺死；如果是個女嬰<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="女嬰——原文直譯「女兒」。">e</a></sup>，就讓她存活。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:29; 出埃及記 1:21; 馬太福音 10:28"> 然而，接生婆敬畏神，沒有照著埃及王吩咐她們的去做，卻讓男孩也存活。</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 8:4; 撒母耳記下 13:28"> 埃及王就把接生婆叫來，問她們：「你們為什麼做這樣的事，讓男孩也存活呢？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約書亞記 2:4–24; 撒母耳記下 17:19–20; 撒母耳記上 21:2"> 接生婆回答法老：「因為希伯來婦女不像埃及婦女，希伯來婦女很健壯，接生婆還沒有到她們那裡之前，她們就已經生產了。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 3:10; 傳道書 8:12; 箴言 11:18"> 神善待接生婆，以色列百姓就增多，而且極其強盛。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 11:38; 撒母耳記上 2:35; 詩篇 37:3"> 接生婆因為敬畏神，神就為她們建立了家庭。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 7:19; 箴言 1:16; 出埃及記 1:16"> 法老吩咐他所有的子民說：「希伯來人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="希伯來人——輔助詞語。">f</a></sup>所生的每一個男嬰<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="男嬰——原文直譯「兒子」。">g</a></sup>，你們都要把他扔進尼羅河裡；而每一個女嬰<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="女嬰——原文直譯「女兒」。">h</a></sup>，你們可以讓她存活。」</span>
</div>
</div>

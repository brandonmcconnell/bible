<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 33:10–12; 出埃及記 15:27; 出埃及記 17:1"> 全體以色列會眾從伊利姆起行，在他們從埃及地出來後的第二個月的十五日，來到伊利姆和西奈之間汛的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 10:10; 出埃及記 15:24; 詩篇 106:25"> 全體以色列會眾在曠野向摩西和亞倫發怨言。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 11:4–5; 民數記 20:3–5; 出埃及記 17:3"> 以色列子孫對他們說：「我們寧願在埃及地死在耶和華的手中！那時我們坐在肉鍋旁邊，吃糧吃到飽；你們卻把我們領到這曠野，要餓死這全體會眾！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:3; 詩篇 78:24–25; 申命記 8:2"> 耶和華對摩西說：「看哪，我要從天上降下糧食給你們！子民要出去，每天撿拾每天的份額，我好試驗他們會不會遵行我的法規。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 16:22–23; 出埃及記 35:2–3; 利未記 25:21–22"> 到了第六天，他們要把所收進來的預備好，那將是他們天天撿拾的雙倍。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 6:7; 民數記 16:28; 出埃及記 16:12–13"> 摩西和亞倫對所有的以色列子孫說：「晚上，你們就會知道是耶和華把你們從埃及地領出來的；</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 40:5; 民數記 16:11; 約翰福音 11:40"> 早晨，你們就會看到耶和華的榮耀，因為耶和華聽見了你們對他的怨言。我們算什麼，你們為何向我們發怨言呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:2; 撒母耳記上 8:7; 帖撒羅尼迦前書 4:8"> 摩西又說：「到了晚上，耶和華會給你們肉吃；到了早晨，他會給你們糧食吃到飽，因為耶和華聽見了你們向他所發的怨言。我們算什麼呢？你們的怨言其實不是向我們發的，而是向耶和華發的。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 16:16; 出埃及記 16:2; 出埃及記 16:8"> 摩西對亞倫說：「你要對全體以色列會眾說：『你們要近前來到耶和華的面前，因為他已經聽見了你們的怨言。』」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 16:7; 民數記 16:19; 民數記 16:42"> 亞倫對全體以色列會眾說話的時候，他們轉向曠野，看哪，耶和華的榮耀在雲彩中顯現！</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華指示摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="約珥書 3:17; 以西結書 39:22; 出埃及記 6:7"> 「我已經聽見以色列子孫的怨言，你要告訴他們說：『黃昏的時候，你們會有肉吃；到了早晨，你們會有糧食得飽足。這樣你們就知道：我是耶和華你們的神。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 11:9; 詩篇 105:40; 詩篇 78:27–28"> 到了晚上，有鵪鶉飛上來，遮蓋了營地；到了早晨，營地的四圍有一層露水。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 11:7–9; 詩篇 105:40; 詩篇 78:24"> 那一層露水蒸發之後，看哪，曠野的地面上有薄片狀的東西，薄得像地上的霜！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 16:4; 約翰福音 6:58; 出埃及記 16:31"> 以色列子孫看到就彼此說：「這是什麼呢？」因為他們不知道那是什麼。<br />摩西對他們說：「這就是耶和華賜給你們吃的糧食。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 16:36; 出埃及記 16:18; 出埃及記 16:32–33"> 耶和華所指示的話是這樣的：『你們要按各人的食量撿拾，也要按你們各人帳篷中的人數撿收，一人一俄梅珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一俄梅珥——相當於2.2公升，計量穀物的量器；本章下同。">a</a></sup>。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 以色列子孫就這樣做了。有人撿拾得多，有人撿拾得少；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:14–15"> 但他們用俄梅珥量的時候，多撿拾的沒有剩餘，少撿拾的也沒有缺少；各人都按自己的食量撿拾。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 12:10; 出埃及記 23:18; 馬太福音 6:34"> 摩西對他們說：「誰都不可留下一點糧食到早晨。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 10:14; 民數記 16:15; 以弗所書 4:26"> 有些人卻沒有聽從摩西，把一些糧食留到早晨，那些糧食就生蟲發臭了。於是摩西對他們發怒。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 傳道書 12:1; 哥林多後書 6:2"> 每天早晨，他們按各人的食量撿拾；太陽一熱，糧食就融化了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 16:5; 利未記 25:22; 出埃及記 16:16"> 到了第六天，他們撿拾雙倍的糧食，一人兩俄梅珥。所有的會眾領袖都來告訴摩西這事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這事——輔助詞語。">b</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 23:3; 出埃及記 31:15; 出埃及記 20:8–11"> 摩西就對他們說：「耶和華這樣說：『明天是完全安息的日子，是耶和華的聖安息日。今天<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="今天——輔助詞語。">c</a></sup>你們要烤的就烤，要煮的就煮，所有剩餘的要留在一邊<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="留在一邊——原文直譯「為自己存放」。">d</a></sup>保存到早晨。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 16:20; 出埃及記 16:33"> 他們就照著摩西吩咐的，把剩餘的留到早晨，那些糧食既沒有發臭，裡面也沒有生蛆。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 16:23; 出埃及記 16:29; 尼希米記 9:14"> 摩西說：「今天就吃這個吧，因為今天是耶和華的安息日，今天你們在田野中必找不到糧食。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:13; 出埃及記 20:9–11; 以西結書 46:1"> 六天你們可以撿拾糧食，但第七天是安息日，那一天不會有糧食。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 到了第七天，百姓中有些人出去撿拾，但找不到糧食。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:10; 詩篇 106:13; 民數記 14:11"> 耶和華對摩西說：「你們拒絕遵守我的誡命和訓誨，要到什麼時候呢？</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 31:13; 以賽亞書 58:13–14; 以西結書 20:12"> 你們看，耶和華賜給了你們安息日，因此第六天他就賜給你們兩天的糧食；第七天你們各人都要留在原處，任何人都不可離開自己的地方。」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 5:12–14; 利未記 23:3; 希伯來書 4:9"> 於是百姓就在第七天安息了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民數記 11:6–9; 出埃及記 16:15"> 以色列家給這糧食起名為「嗎哪」，它像芫荽的種子，是白色的，它的味道像加蜂蜜的薄餅。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 105:5; 路加福音 22:19; 詩篇 111:4–5"> 摩西說：「耶和華所指示的話是這樣的：『你們要把一俄梅珥滿滿的嗎哪保存下來給你們的世世代代，好讓他們看到我把你們從埃及地領出來的時候，給你們在曠野中吃的糧食。』」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="希伯來書 9:4"> 摩西對亞倫說：「拿一個罐子，裝入滿滿一俄梅珥的嗎哪，放在耶和華面前，保存下來給你們的世世代代。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 27:21; 出埃及記 25:21; 出埃及記 25:16"> 亞倫就照著耶和華所指示摩西的，把嗎哪放在見證版前面，保存下來。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="尼希米記 9:20–21; 約書亞記 5:12; 申命記 8:2–3"> 以色列子孫吃這嗎哪四十年，直到他們來到有人居住的地方；他們吃這嗎哪，直到他們來到迦南地的邊界。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 16:16; 出埃及記 16:32–33"> （一俄梅珥<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一俄梅珥——相當於2.2公升。">e</a></sup>是一伊法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一伊法——相當於22公升。">f</a></sup>的十分之一。）</span>
</div>
</div>

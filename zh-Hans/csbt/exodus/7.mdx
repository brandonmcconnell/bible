<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 4:15–16; 詩篇 82:6; 約翰福音 10:35–36"> 耶和華對摩西說：「你看，我使你在法老面前像神一樣，而你哥哥亞倫是你的先知。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 4:15; 出埃及記 6:29; 申命記 4:2"> 我所吩咐你的一切，你都要說；然後你哥哥亞倫要對法老說，讓以色列子孫走，離開法老的地。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 4:21; 出埃及記 11:9; 詩篇 105:27–36"> 然而，我要使法老硬著心，也要在埃及地使我的神蹟和奇事增多。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 11:9; 出埃及記 6:6; 出埃及記 12:51"> 法老不會聽從你們；我要向埃及下手，用極大的審判把我的大軍——我的子民以色列子孫，從埃及地領出來。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 14:18; 出埃及記 7:17; 出埃及記 8:22"> 當我伸出手攻擊埃及，把以色列子孫從埃及人中間領出來的時候，埃及人就知道我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 7:2; 創世記 6:22; 出埃及記 7:10"> 摩西和亞倫就這樣做了；耶和華所指示他們的，他們都照著做了。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 34:7; 使徒行傳 7:30; 申命記 31:2"> 他們對法老說話的時候，摩西八十歲，亞倫八十三歲。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 4:2; 約翰福音 2:18; 以賽亞書 7:11"> 「當法老吩咐你們說『你們行一件奇事吧』，你就對亞倫說：『拿你的杖，扔在法老面前，杖就會變成一條大蛇。』」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:3; 路加福音 10:19; 阿摩司書 9:3"> 摩西和亞倫就到法老那裡去，照著耶和華所指示的做了。亞倫把他的杖扔在法老和他的臣僕面前，杖就變成了一條大蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 7:22; 提摩太後書 3:8; 出埃及記 8:18"> 於是法老召來智慧人和行巫術的。這些埃及的術士們也用他們的邪術照樣做。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 4:4; 出埃及記 9:11; 出埃及記 8:18–19"> 他們各人扔下自己的杖，他們的杖也都變成了大蛇；但亞倫的杖吞掉了他們的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 4:21; 出埃及記 8:15; 撒迦利亞書 7:11–12"> 然而，法老的心剛硬，不聽從摩西和亞倫，正如耶和華所說的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 10:20; 出埃及記 8:15; 出埃及記 10:1"> 耶和華對摩西說：「法老心裡頑固，拒絕讓我的子民走。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 8:20; 出埃及記 2:5; 出埃及記 7:10"> 明天早晨你要到法老那裡去。看哪，他會出來到水邊，你就站在尼羅河岸迎候他。你手中要拿著那根曾變成蛇的杖。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 3:18; 出埃及記 9:1; 出埃及記 9:13"> 你要對他說：『希伯來人的神耶和華派遣我到你這裡說：讓我的子民走，好使他們在曠野中服事我。看哪，直到現在你都不聽！</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 4:9; 出埃及記 5:2; 出埃及記 7:5"> 耶和華如此說：看哪，我要用我手中的杖擊打尼羅河裡的水，水就會變成血，這樣你就知道我是耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:24; 出埃及記 7:21; 民數記 11:20"> 尼羅河裡的魚都會死，尼羅河也會發臭，埃及人就不能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不能——原文直譯「厭惡」。">a</a></sup>喝尼羅河裡的水了。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 14:21; 出埃及記 10:12; 出埃及記 8:5–6"> 耶和華對摩西說：「你要對亞倫說：『拿你的杖，伸出你的手在埃及眾水之上，就是在他們的河流、運河、池塘以及所有的蓄水池之上，水就會變成血；在埃及全地都會有血，甚至在木器、石器裡。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 78:44; 詩篇 105:29; 出埃及記 7:17–18"> 摩西和亞倫就照著耶和華所指示的做了。亞倫在法老眼前和他的臣僕眼前舉起杖，擊打尼羅河裡的水，尼羅河裡的水就全都變成了血。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 7:18; 啟示錄 8:9"> 尼羅河裡的魚都死了，尼羅河也發臭了，埃及人就不能喝尼羅河裡的水。在埃及全地都是血。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 7:11; 提摩太後書 3:8; 耶利米書 27:18"> 埃及的術士們也用他們的邪術照樣做。於是法老的心就剛硬，不聽從摩西和亞倫，正如耶和華所說的。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 36:24; 以西結書 40:4; 瑪拉基書 2:2"> 法老轉身回到他的宮殿裡，竟沒有把這事放在心上。</span>
<span className="v" id="v24" data-v="24"> 所有的埃及人在尼羅河周圍挖地找水喝，因為他們不能喝尼羅河裡的水。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 10:23; 出埃及記 8:9–10; 撒母耳記下 24:13"> 耶和華打擊尼羅河之後，滿了七天。</span>
</div>
</div>

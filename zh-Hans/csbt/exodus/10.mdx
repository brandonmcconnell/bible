<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 4:21; 出埃及記 7:13–14; 出埃及記 3:20"> 耶和華對摩西說：「你到法老那裡去，因為我已經使他和他的臣僕硬著心，為要在他們當中施行我的這些神蹟，</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 1:3; 申命記 4:9; 申命記 6:20–22"> 也為要你向你的兒孫講述我嚴厲對付埃及的事和我在他們中間施行的神蹟，好讓你們知道我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 5:6; 列王紀上 21:29; 雅各書 4:10"> 摩西和亞倫就來到法老那裡，對他說：「希伯來人的神耶和華如此說：『你拒絕在我面前謙卑，要到什麼時候呢？讓我的子民走，好使他們服事我。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 9:3; 約珥書 2:25; 出埃及記 11:4–5"> 如果你拒絕讓我的子民走，看哪，我明天就使蝗蟲進入你的境內！</span>
<span className="v" id="v5" data-v="5" data-xref="約珥書 1:4; 出埃及記 9:32; 約珥書 2:25"> 牠們將遮蓋地面，以致人看不見地。牠們將吞噬冰雹後留給你們的那些餘剩物，也將吞噬田野中給你們長出的所有樹木。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 8:21; 出埃及記 8:3; 出埃及記 11:6"> 牠們又將充滿你的宮殿、你所有臣僕的房屋和所有埃及人的房屋。這是自從你祖先和你祖先的祖先住在這地之日直到今日未曾見過的。』」然後摩西就轉身從法老那裡出去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 18:21; 出埃及記 23:33; 約書亞記 23:13"> 法老的臣僕對法老說：「這人作我們的陷阱，要到什麼時候呢？讓這些人走，好使他們服事耶和華他們的神。難道你不知道埃及已經毀了嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 10:24; 出埃及記 12:31; 出埃及記 8:8"> 於是，摩西和亞倫被帶回到法老那裡。法老對他們說：「你們去，服事耶和華你們的神！不過，要去的是哪些人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哪些人——原文直譯「誰與誰」。">a</a></sup>呢？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:1; 哥林多前書 5:7–8; 申命記 31:12–13"> 摩西說：「我們要與我們的少年人、老年人一起去，與我們的兒子們、女兒們、羊群、牛群一起去，因為我們要守耶和華的節期。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 13:21; 歷代志下 32:15; 出埃及記 12:30–31"> 法老對他們說：「如果我真讓你們與你們的孩童一起走，那麼我也會願耶和華與你們同在！看，邪惡就在你們的臉上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="邪惡就在你們的臉上——或譯作「災禍就在你們面前」。">b</a></sup>！</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 10:28; 詩篇 119:69; 出埃及記 5:4"> 不行，只有你們中的男人可以去服事耶和華！這是你們所要求的。」於是法老把他們從自己面前趕出去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 7:19; 出埃及記 10:4–5"> 耶和華對摩西說：「向埃及地伸出你的手，使蝗蟲上到埃及地，吞噬地上冰雹後留下的所有蔬草。」</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 1:4; 詩篇 78:26; 詩篇 148:8"> 摩西向埃及地伸出他的杖，耶和華就引導東風在地上颳了整整一日一夜。到了早晨，東風把蝗蟲颳來了。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:46; 約珥書 1:2–4; 詩篇 105:34–35"> 蝗蟲上到埃及全地，停留在埃及全境，極其眾多；這樣多的蝗蟲，以前未曾有過，以後也不會再有。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 10:5; 詩篇 78:46; 約珥書 1:6–7"> 蝗蟲遮蓋了整個地面，以致地都黑暗了。牠們吞噬了地上冰雹後留下的所有蔬草和樹上的所有果實。在埃及全地，無論是樹木，還是田間的蔬草，都沒有留下一點青綠。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 9:27; 撒母耳記下 19:20; 撒母耳記上 15:30"> 於是法老急忙召來摩西和亞倫，說：「我對你們的神耶和華犯了罪，也對你們犯了罪。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 8:8; 出埃及記 9:28; 列王紀上 13:6"> 現在，請你饒恕我的罪，就只這一次；也請你們向你們的神耶和華祈求，只要使這死亡離開我。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 6:28; 出埃及記 8:28–30; 出埃及記 8:9"> 摩西從法老那裡出來，向耶和華祈求。</span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:20; 出埃及記 13:18; 出埃及記 15:4"> 耶和華就把東風轉為極其強大的西風，把蝗蟲颳起，吹入紅海；在埃及全境連一隻蝗蟲也沒有留下。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 4:21; 出埃及記 11:10; 申命記 2:30"> 然而，耶和華使法老的心剛硬，他就不讓以色列子孫走。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="啟示錄 16:10–11; 猶大書 1:6; 路加福音 23:44"> 耶和華又對摩西說：「向天伸出你的手，使黑暗——甚至可以摸得到的黑暗臨到埃及地。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 105:28; 啟示錄 16:10; 出埃及記 20:21"> 摩西向天伸出他的手，濃厚的黑暗就臨到埃及全地，有三天之久；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 8:22; 以賽亞書 42:16; 彼得前書 2:9"> 這三天中，人們彼此看不見，誰也不能起來離開原處。然而，所有以色列子孫居住的地方都有光。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 10:8–10; 出埃及記 8:28; 創世記 34:23"> 於是法老召來摩西，說：「你們去，服事耶和華！只是你們的羊群和牛群要留下，你們的孩童可以與你們一起去。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="利未記 9:22; 利未記 16:9; 出埃及記 29:1–46"> 摩西就說：「你必須把祭物和燔祭也交在我們的手中，好使我們獻給耶和華我們的神。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 23:18; 使徒行傳 2:44–45; 箴言 3:9"> 我們的牲畜也要與我們一起去，連一蹄也不留下，因為我們要從中取出一些來服事耶和華我們的神，而在我們到達那裡之前，我們並不知道要用什麼來服事耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及記 10:20; 出埃及記 4:21; 出埃及記 14:8"> 然而，耶和華使法老的心剛硬，他就不肯讓他們走。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 25:16; 歷代志下 16:10; 阿摩司書 7:13"> 法老對摩西說：「你離開我去吧！你要小心，不要再見我的面，因為你見我面的那一天，你必會死！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="希伯來書 11:27; 出埃及記 12:30–31; 出埃及記 11:4–8"> 摩西說：「你說得對，我絕不會再見你的面了！」</span>
</div>
</div>

</div>

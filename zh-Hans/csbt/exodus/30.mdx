<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 8:3; 出埃及記 37:25–28; 出埃及記 40:5"> 「你要造一座焚香的壇，用金合歡木來造，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 27:2"> 長一肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘——相當於45.7公分；下同。">a</a></sup>，寬一肘，是方形的，高二肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二肘——相當於91.4公分。">b</a></sup>；犄角從壇而出。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 25:11; 出埃及記 25:24"> 你要把壇包上純金，壇的頂部、壇的四邊和壇的犄角都要包上，並在壇的四圍鑲上金邊；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:27; 出埃及記 26:29; 出埃及記 27:7"> 又要在金邊之下、在壇的相對兩邊為壇做兩個金環，用來穿杠抬壇。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:13; 出埃及記 25:27"> 你要用金合歡木做兩根杠，把它們包上金。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 25:21–22; 出埃及記 30:36; 利未記 16:13"> 「你要把壇放在靠近見證櫃的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="靠近見證櫃的——原文直譯「見證櫃前面的」。">c</a></sup>幔子前，對著見證櫃上的施恩座——我與你相會的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:28; 歷代志上 23:13; 出埃及記 27:20–21"> 亞倫要在壇上燒獻芬芳香：每天早晨他照管燈的時候，都要燒獻這香；</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 9:24; 帖撒羅尼迦前書 5:17; 希伯來書 7:25"> 黃昏亞倫點燈的時候，也要燒獻這香；這要作為你們世世代代在耶和華面前常獻的香。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 10:1"> 你們不可在壇上獻異樣的香、燔祭、素祭，也不可在壇上澆奠酒祭。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 16:18; 希伯來書 9:22–23; 利未記 16:29–30"> 「亞倫要一年一次在壇的犄角上贖罪，一年一次用贖罪祭牲的血在壇上贖罪；你們世世代代都要這樣做。這壇是歸耶和華為至聖的。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華指示摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 31:50; 歷代志上 27:24; 出埃及記 38:25–26"> 「當你統計以色列子孫的人口數點他們的時候，各人要在你數點他們的時候向耶和華付上他們性命的贖價；這樣災殃就不會在數點他們的時候臨到他們。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:25; 民數記 3:47; 以西結書 45:12"> 所有通過數點歸入被數之眾的人，都要付上這贖價：按聖所的謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="謝克爾——重量單位；後來成為貨幣單位。1謝克爾=11.4公克。本章下同。">d</a></sup>標準付上半謝克爾<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="半謝克爾——相當於5.7公克；下同。1謝克爾=11.4公克。">e</a></sup>——一謝克爾是二十季拉<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二十季拉——相當於11.4公克。1季拉=0.57公克。">f</a></sup>——這半謝克爾是獻給耶和華的供物。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:20; 民數記 1:18; 民數記 1:3"> 所有通過數點歸入被數之眾的人，二十歲以上的，都要把供物獻給耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 31:50; 利未記 17:11; 出埃及記 30:12"> 富人不可多付，窮人不可少付，都要付半謝克爾，獻給耶和華作供物，為你們的性命贖罪。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 10:32–33; 民數記 16:40; 出埃及記 38:25–31"> 你要從以色列子孫收取這贖罪銀，用在會幕的服事上，使它為以色列子孫在耶和華面前作記念，為你們的性命贖罪。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華指示摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 40:7; 出埃及記 38:8; 列王紀上 7:23"> 「你要做一個用於洗濯的銅盆和銅盆座，放在會幕和祭壇之間，盆中盛水。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 52:11; 出埃及記 40:31–32; 詩篇 26:6"> 亞倫和他的兒子們要在盆中洗手洗腳。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 10:1–3; 希伯來書 12:28–29; 歷代志上 13:10"> 當他們進入會幕，或接近祭壇事奉、燒獻火祭給耶和華的時候，他們要用水洗濯，免得死亡；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 28:43; 出埃及記 27:21"> 他們要洗手洗腳，免得死亡。這要成為亞倫和他的後裔世世代代永遠的定例。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華指示摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 27:19; 雅歌 4:14; 以西結書 27:22"> 「你要取上等的香料：沒藥液五百謝克爾<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="五百謝克爾——相當於5.7公斤；下同。1謝克爾=11.4公克。">g</a></sup>、香肉桂是沒藥的一半——兩百五十謝克爾<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="兩百五十謝克爾——相當於2.85公斤；下同。1謝克爾=11.4公克。">h</a></sup>、香菖蒲兩百五十謝克爾、</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 45:8; 出埃及記 29:40; 民數記 3:47"> 桂皮五百謝克爾，都要按聖所的謝克爾標準；又要取橄欖油一欣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一欣——相當於3.7公升。">i</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 37:29; 歷代志上 9:30; 出埃及記 40:9"> 你要用這些來製作聖膏油，就是用調配師的做法調配的香膏。這要成為聖膏油。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民數記 7:1; 約翰一書 2:20; 以賽亞書 61:1"> 「你要用它膏抹會幕和見證櫃、</span>
<span className="v" id="v27" data-v="27"> 桌子和桌子的一切器具、燈臺和燈臺的器具、香壇、</span>
<span className="v" id="v28" data-v="28"> 燔祭的祭壇和祭壇的一切器具、洗濯盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 23:19; 出埃及記 29:37; 利未記 6:18"> 你要把它們分別為聖，它們就成為至聖的；所有碰它們的也都分別為聖了。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 8:12; 出埃及記 28:3; 利未記 8:30"> 你要膏抹亞倫和他的兒子們，使他們分別為聖，作祭司事奉我。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 37:29; 利未記 21:10; 詩篇 89:20"> 「你要吩咐以色列子孫說：『你們世世代代要把這膏油歸我作聖膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 30:25; 出埃及記 30:37–38; 利未記 21:10"> 不可澆在一般人的身上，也不可照著它的配方去製作膏油；這膏油是神聖的，你們要把它當作神聖的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 30:38; 創世記 17:14; 出埃及記 12:15"> 任何人照著這膏油去調配，或把膏油抹在祭司以外的人身上，就要從民中被剪除。』」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出埃及記 37:29; 出埃及記 25:6; 出埃及記 30:23"> 耶和華對摩西說：「你要取芬芳的香料：蘇合香、螺香、白松香；這些芬芳的香料和純淨的乳香，分量要相等。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 2:13; 出埃及記 30:25; 約翰福音 12:3"> 你要用這些做香，就是用調配師的做法調配，是加鹽的、純淨的、神聖的。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:22; 出埃及記 30:6; 出埃及記 16:34"> 你要把一些香搗成粉末，放一些在會幕中的見證櫃前——我與你相會的地方；你們要以這香為至聖。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 2:3; 出埃及記 29:37; 出埃及記 30:32–33"> 你所做的這香，不可照著它的配方為自己做；你要把這香當作神聖的，歸給耶和華。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 30:33"> 任何人照著這香去做，為要聞它的香味，就要從民中被剪除。」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華指示摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 9:7; 尼希米記 11:2; 以斯拉記 2:68"> 「你要吩咐以色列子孫拿供物給我；凡是甘心奉獻的人，你們就從他們收取給我的供物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:9; 約伯記 28:2"> 以下是你們要從他們收取的供物：金、銀、銅，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 19:8; 創世記 41:42; 以西結書 16:10"> 藍色線、紫色線、朱紅色線、細麻、山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 26:37–1; 出埃及記 26:14–15; 出埃及記 36:20"> 染紅的公綿羊皮、海獅皮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="海獅皮——原文語義不確定，基本意思是一種精細的皮革；本卷下同。">a</a></sup>，金合歡木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 27:20; 出埃及記 25:37; 出埃及記 40:24–25"> 點燈的油、製作膏油和芬芳香的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 28:4; 出埃及記 28:6–30"> 以及以弗得和胸牌上用的紅瑪瑙石和鑲嵌的寶石。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 6:16; 列王紀上 6:13; 啟示錄 21:3"> 「他們要為我造一個聖所，好使我住在他們中間。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:40; 希伯來書 8:5; 使徒行傳 7:44"> 我將向你指明的一切，就是帳幕的樣式和其中一切器具的樣式，你們要照著去做。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯來書 9:4; 出埃及記 37:1–3; 申命記 10:1–3"> 「他們要用金合歡木做一個櫃，長二肘半<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二肘半——相當於114.3公分；下同。1肘=45.7公分。">b</a></sup>，寬一肘半<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘半——相當於68.6公分；下同。">c</a></sup>，高一肘半。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 25:24; 出埃及記 30:3; 歷代志下 3:4"> 你要把它包上純金，裡裡外外都包上，並在它的四圍鑲上金邊；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 27:7; 出埃及記 25:26; 出埃及記 25:15"> 又要為它鑄四個金環，安裝在它的四個腳上，兩個環在一邊，兩個環在另一邊。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 15:15; 民數記 4:11; 出埃及記 27:6"> 你要用金合歡木做兩根杠，把它們包上金，</span>
<span className="v" id="v14" data-v="14"> 把杠穿進櫃兩邊的環中，用它們來抬櫃。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 8:8; 歷代志下 5:9"> 杠要留在櫃的環中，不可抽出來。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 31:26; 列王紀上 8:9; 希伯來書 9:4"> 你要把我將賜給你的見證版安放在櫃裡。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 9:5; 出埃及記 37:6; 希伯來書 4:16"> 你要用純金做施恩座<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="施恩座——或譯作「贖罪蓋」；下同。">d</a></sup>，長二肘半，寬一肘半；</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 10:20; 希伯來書 9:5; 列王紀上 8:6–7"> 又要在施恩座的兩端，用金子造兩個基路伯，錘擛成形——</span>
<span className="v" id="v19" data-v="19"> 一端造一個基路伯，另一端也造一個基路伯，從施恩座的兩端造出基路伯。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 28:18; 列王紀上 8:7; 希伯來書 9:5"> 兩個基路伯要向上展開翅膀，用它們的翅膀遮掩施恩座；基路伯的臉要彼此相向，它們的臉要朝著施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 26:34; 羅馬書 10:4; 出埃及記 25:16–17"> 你要把施恩座安放在櫃上面，把我將賜給你的見證版安放在櫃裡。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:42–43; 民數記 7:89; 以賽亞書 37:16"> 我要在那裡與你相會，並從施恩座上，從見證櫃上面的兩個基路伯之間，把我要吩咐你傳給以色列子孫的一切事告訴你。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯來書 9:2; 出埃及記 37:10–16; 列王紀上 7:48"> 「你要用金合歡木做一張桌子，長二肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="二肘——相當於91.4公分。1肘=45.7公分。">e</a></sup>，寬一肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一肘——相當於45.7公分。">f</a></sup>，高一肘半<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一肘半——相當於68.6公分。">g</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 25:11; 列王紀上 6:20–22"> 你要把它包上純金，並在它的四圍鑲上金邊；</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 37:2; 出埃及記 30:3"> 要在它的四圍做一掌寬<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一掌寬——相當於7.4公分。">h</a></sup>的邊框，並在它的邊框四圍鑲上金邊；</span>
<span className="v" id="v26" data-v="26"> 又要為它做四個金環，安裝在它的四角，就是它的四個腿上。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 25:14; 出埃及記 25:28"> 環要靠近邊框，用來穿杠抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 25:14; 使徒行傳 9:15; 民數記 10:17"> 你要用金合歡木做兩根杠，把它們包上金，用它們來抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 4:7; 出埃及記 37:16; 啟示錄 3:20"> 你要做桌子上澆奠用的盤、碟、壺和杯；這些都要用純金來做。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 24:5–9; 馬太福音 12:4; 出埃及記 39:36"> 你要在桌子上擺放陳設餅，使陳設餅常在我面前。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 7:49; 撒迦利亞書 4:2; 出埃及記 37:17–24"> 「你要用純金做一個燈臺，燈臺要錘擛成形——它的底座、枝幹、花杯、花萼和花瓣都要與燈臺一體錘出。</span>
<span className="v" id="v32" data-v="32"> 從燈臺的兩邊要伸出六根枝幹，三根枝幹在一邊，三根枝幹在另一邊。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 17:4–8; 耶利米書 1:11–12; 撒迦利亞書 4:3"> 在一邊的每根枝幹上有三個杏花形狀的花杯，每個都有花萼和花瓣；在另一邊的每根枝幹上也有三個杏花形狀的花杯，每個都有花萼和花瓣；從燈臺伸出的六根枝幹都要這樣。</span>
<span className="v" id="v34" data-v="34"> 燈臺的主幹<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="的主幹——輔助詞語。">i</a></sup>上有四個杏花形狀的花杯，每個都有花萼和花瓣；</span>
<span className="v" id="v35" data-v="35"> 從燈臺伸出的第一對兩根枝幹下面有一個花萼，第二對兩根枝幹下面有一個花萼，第三對兩根枝幹下面也有一個花萼；從燈臺伸出的六根枝幹都要這樣。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:18; 列王紀上 10:16–17; 歷代志下 9:15"> 它們的花萼和枝幹要與燈臺一體錘出，整個燈臺都要用同一塊純金錘成。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民數記 8:2; 啟示錄 1:20–1; 利未記 24:2–4"> 「你要做燈臺的七盞燈，把它們安裝在燈臺上，使燈照亮燈臺前方。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 12:13; 耶利米書 52:18; 列王紀下 25:14"> 燈臺的燈剪和燈盤都要用純金做；</span>
<span className="v" id="v39" data-v="39"> 要用一他連得<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="一他連得——相當於34.2公斤。">j</a></sup>純金做燈臺和所有這些器具。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯來書 8:5; 出埃及記 26:30; 使徒行傳 7:44"> 你當留意，要照著在山上向你指明的樣式去做！</span>
</div>
</div>

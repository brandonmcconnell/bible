<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:14; 申命記 6:20; 出埃及記 24:3–4"> 「以下是你要在百姓面前立的法規：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命記 15:12–15; 出埃及記 12:44; 申命記 15:18"> 「如果你買了一個希伯來奴僕，他要服事你六年，第七年他可以作為自由人無償離去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:12–14"> 如果他單身來，就可以單身離去；如果他是有婦之夫，他的妻子也可以與他一同離去。</span>
<span className="v" id="v4" data-v="4"> 如果他的主人給了他妻子，妻子又為他生了兒子或女兒，妻子和孩子就要歸主人，而他要單身離去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:14–15; 申命記 15:16–17; 以賽亞書 26:13"> 「如果那奴僕明確地說『我愛我的主人、我的妻子兒女，我不願意自由離去』，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:17; 利未記 25:40; 申命記 19:17–18"> 他的主人就要把他帶到神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神——或譯作「審判官」。">a</a></sup>面前，然後帶他到門前或門框那裡；他的主人要用錐子為他穿耳洞，他就要永遠服事主人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米記 5:5; 出埃及記 21:2–3"> 「如果有人把自己的女兒賣為女僕，女僕不可像男僕那樣離去。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:8; 申命記 20:7; 瑪拉基書 2:11–15"> 如果她的主人選定她歸自己，後來卻不喜歡她，就要讓她贖身；主人既然對她失信，就沒有權力把她賣給外邦人。</span>
<span className="v" id="v9" data-v="9"> 如果主人選定她歸自己的兒子，就要照著待女兒的慣例對待她。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:1–6"> 如果主人為自己另娶一個女人，不可減少原先那女人的食物、衣服和房事。</span>
<span className="v" id="v11" data-v="11"> 如果主人不為她做這三件事，她就可以無償離去，不用付贖金<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="贖金——原文直譯「銀子」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 9:6; 馬太福音 26:52; 利未記 24:17"> 「打人致死的，必須被處死；</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 20:2–9; 撒母耳記上 24:18; 申命記 4:41–43"> 但如果不是預謀殺人，而是神使那人落在他的手中，我就會給你指定一個地方，讓他可以逃到那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 2:28–34; 希伯來書 10:26; 民數記 15:30–31"> 如果有人蓄意針對他的鄰人，用詭計殺死他，你即使從我的祭壇那裡，也要把他抓去處死。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 21:18–21; 箴言 30:17; 提摩太前書 1:9"> 「打父母的，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 24:7; 提摩太前書 1:10; 出埃及記 22:4"> 「拐帶人口的，無論是把人賣了，或是把人留在手中，都必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 馬可福音 7:10–11; 申命記 27:16"> 「詛咒父母的，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 21:20; 申命記 25:11; 撒母耳記下 14:6"> 「如果人彼此相爭，一個用石頭或拳頭打另一個，被打的沒有死，而是躺在床上，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 3:29; 撒迦利亞書 8:4"> 後來他如果能起來用拐杖出外行走，那打他的就免於罪罰，但要賠償他誤工的損失，並負責他徹底痊癒。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命記 19:21; 民數記 35:19"> 「如果有人用棍打他的男僕或女僕，以致奴僕當場<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="當場——輔助詞語。">c</a></sup>死在他的手下，他就必定受報應；</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 25:44–46"> 但如果奴僕還挺了一兩天，那人就不會受報應，因為奴僕是他的財產<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="財產——原文直譯「銀子」。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 22:18–19; 出埃及記 21:30; 申命記 16:18"> 「如果人彼此打架，傷到孕婦，以致她早產，但沒有其他損傷，那傷她的就必須照著那婦人的丈夫所要求的受懲罰，按審判官所判的來賠償；</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 19:21; 民數記 35:31; 利未記 24:19"> 但如果有其他損傷，就要以命償命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 19:21; 馬太福音 5:38–40; 馬太福音 7:2"> 以眼還眼，以牙還牙，以手還手，以腳還腳，</span>
<span className="v" id="v25" data-v="25"> 以灼還灼，以傷還傷，以打還打。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 21:20; 約伯記 31:13–15; 詩篇 72:12–14"> 「如果有人打他男僕的眼睛或女僕的眼睛，以致毀了一只眼睛，就要因眼睛的緣故讓奴僕走，作自由人。</span>
<span className="v" id="v27" data-v="27"> 如果有人打掉他男僕的牙齒或女僕的牙齒，就要因牙齒的緣故讓奴僕走，作自由人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及記 21:32; 利未記 20:15–16; 創世記 9:5–6"> 「如果有牛頂男人或女人，以致人死了，那牛就必須用石頭砸死，牠的肉也不可以吃，不過牛的主人可以算為無罪；</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 21:1–9"> 但如果那牛向來頂人，牠的主人也被告誡過，卻沒有把牛看好，以致牛把男人或女人頂死了，那牛就要用石頭砸死，牠的主人也要被處死。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 21:22; 出埃及記 30:12; 民數記 35:31–33"> 如果他被要求了贖價，他就要照著所要求的來付上他性命的贖價。</span>
<span className="v" id="v31" data-v="31"> 牛無論頂了男孩<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="男孩——原文直譯「兒子」。">e</a></sup>或頂了女孩<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="女孩——原文直譯「女兒」。">f</a></sup>，都要照著這條規定處置牠的主人。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 26:15; 撒迦利亞書 11:12–13; 馬太福音 27:3–9"> 如果牛頂了男僕或女僕，牠的主人就要給奴僕的主人三十謝克爾<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="三十謝克爾——相當於342公克。1謝克爾=11.4公克。">g</a></sup>銀子，而那牛要用石頭砸死。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米書 18:20; 傳道書 10:8"> 「如果有人敞開坑口，或是挖了坑卻沒有遮蓋坑口，以致有牛或驢掉進裡面，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 22:6; 出埃及記 21:29–30; 出埃及記 22:14"> 那坑的主人就要賠償，付銀子給牲畜的主人，而死牲畜就歸自己。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 「如果有人的牛傷了他鄰人的牛，以致鄰人的牛死了，就要把活牛賣了，平分銀子，也要平分死牛；</span>
<span className="v" id="v36" data-v="36"> 但如果早已知道那牛向來頂人，牠的主人卻沒有把牛看好，牠的主人就必須以牛賠牛，而死牛就歸自己。</span>
</div>
</div>

</div>

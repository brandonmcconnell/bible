<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 28:3; 出埃及記 35:30–35; 出埃及記 31:1–6"> 比撒列和亞何利亞伯，以及一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直譯「心裡有智慧」；本章下同。">a</a></sup>的人，就是蒙耶和華賜智慧和聰慧在他們裡面、知道怎樣做聖所一切建造工作的人，都要照著耶和華所吩咐的一切去做。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 4:17; 希伯來書 5:4; 出埃及記 31:6"> 摩西就召比撒列和亞何利亞伯，一切有才能的人，就是蒙耶和華賜智慧在他們心裡的人，以及所有心裡受激勵的人，近前來做這工作。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:29; 出埃及記 35:27; 出埃及記 35:5–21"> 他們在摩西面前接受了以色列子孫為聖所的建造工作而帶來的一切供物。每天早晨，以色列子孫不斷地把甘心奉獻物帶來給摩西。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 3:10; 路加福音 12:42; 馬太福音 24:45"> 那些做聖所一切工作的巧匠<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巧匠——原文直譯「智慧人」。">b</a></sup>，各人放下自己在做的工作，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 31:6–10; 哥林多後書 8:2–3; 歷代志下 24:14"> 來告訴摩西說：「百姓帶來的太多，已經超過了耶和華指示要做的建造工作所需要的。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 於是摩西吩咐在營中傳令說：「無論男女都不必再為聖所奉獻任何供物。」這樣，百姓才被阻止，不再帶來供物；</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:10"> 因為材料已經足夠做一切的工作，而且有餘。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 6:23; 出埃及記 26:1–37; 以西結書 1:5–28"> 這些工作的人中，一切有才能的，用十幅幔帳造了帳幕；比撒列用捻成的細麻線和藍色、紫色、朱紅色線編織幔帳，以精巧的工藝繡上了基路伯。</span>
<span className="v" id="v9" data-v="9"> 每幅幔帳長二十八肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="二十八肘——相當於12.8公尺。1肘=45.7公分。">c</a></sup>，每幅幔帳寬四肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="四肘——相當於1.8公尺。">d</a></sup>，所有幔帳的尺寸都一樣。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 12:27; 出埃及記 26:3; 詩篇 122:3"> 五幅幔帳彼此相連，另五幅幔帳也彼此相連。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:4"> 在一組幔帳的最後一幅邊上，用藍色線做扣環；另一組幔帳的最後一幅邊上，也照樣做。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 26:5; 出埃及記 26:10"> 在一組幔帳的邊上，做五十個扣環；在另一組幔帳的邊上，也做五十個扣環，扣環彼此相對。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:4–5; 以弗所書 2:20–22; 哥林多前書 12:20"> 他做了五十個金鉤，用這些鉤子把兩組幔帳彼此相連，好使帳幕成為一個整體。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 26:7–13"> 他用山羊毛做幔帳，作為帳幕上的罩篷，做了十一幅幔帳。</span>
<span className="v" id="v15" data-v="15"> 每幅幔帳長三十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三十肘——相當於13.7公尺。1肘=45.7公分。">e</a></sup>，每幅幔帳寬四肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="四肘——相當於1.8公尺。">f</a></sup>，十一幅幔帳的尺寸都一樣。</span>
<span className="v" id="v16" data-v="16"> 他把五幅幔帳連成一組，把另外的六幅幔帳也連成一組。</span>
<span className="v" id="v17" data-v="17"> 在一組幔帳的最後一幅邊上，做五十個扣環；在另一組幔帳的邊上，也做五十個扣環。</span>
<span className="v" id="v18" data-v="18"> 他做了五十個銅鉤，把罩篷連起來，好使它成為一個整體。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 26:14"> 他用染紅的公綿羊皮為罩篷做一個頂罩，其上再用海獅皮做了一個頂罩。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 25:5; 民數記 25:1; 出埃及記 40:18–19"> 他用金合歡木為帳幕做了豎板。</span>
<span className="v" id="v21" data-v="21"> 每塊木板長十肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="十肘——相當於4.6公尺。1肘=45.7公分。">g</a></sup>，每塊木板寬一肘半<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一肘半——相當於0.7公尺。">h</a></sup>。</span>
<span className="v" id="v22" data-v="22"> 每塊木板有兩個榫頭，彼此並列<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="彼此並列——或譯作「使木板彼此連接」。">i</a></sup>；帳幕所有的木板都這樣做。</span>
<span className="v" id="v23" data-v="23"> 他為帳幕做了木板，為南邊做了二十塊木板；</span>
<span className="v" id="v24" data-v="24"> 在這二十塊木板底下，做了四十個銀底座；一塊木板底下有兩個底座連接它的兩個榫頭，下一塊木板底下也有兩個底座連接它的兩個榫頭。</span>
<span className="v" id="v25" data-v="25"> 他為帳幕的另一邊，就是北邊，做了二十塊木板，</span>
<span className="v" id="v26" data-v="26"> 以及四十個銀底座；一塊木板底下有兩個底座，下一塊木板底下也有兩個底座。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 26:22; 出埃及記 26:27"> 他也為帳幕的後部，就是西面，做了六塊木板；</span>
<span className="v" id="v28" data-v="28"> 並在帳幕後部的兩個邊角做兩塊木板，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:32; 以弗所書 3:18–19; 哥林多前書 1:10"> 兩個邊角是雙層，雙層木板從下端到頂端完全對齊，頂端用一個環扣住；兩塊木板都是這樣，形成兩個凸角。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 26:25"> 這樣共有八塊木板和十六個銀底座；每塊木板底下都有兩個底座。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 26:26–29; 出埃及記 25:28; 出埃及記 30:5"> 他用金合歡木做橫閂，為帳幕一邊的木板做了五根，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 26:26"> 為帳幕另一邊的木板做了五根橫閂，又為帳幕後邊，就是西面的木板，也做了五根橫閂。</span>
<span className="v" id="v33" data-v="33"> 他使中間那根橫閂，在木板中部，從一端穿到另一端。</span>
<span className="v" id="v34" data-v="34"> 他把木板包上了金，又用金子做了其上的環，用來穿橫閂；也把橫閂包上了金。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 27:51; 希伯來書 10:20; 出埃及記 40:21"> 他用藍色、紫色、朱紅色線和捻成的細麻線編織幔子，以精巧的工藝繡上了基路伯。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 1:18"> 他用金合歡木為幔子做了四根柱子，把它們包上了金；柱子上有金鉤；他又為柱子鑄了四個銀底座。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及記 26:36–37; 出埃及記 40:28"> 他用藍色、紫色、朱紅色線和捻成的細麻線，以刺繡的工藝，為帳篷的入口編織了簾幕。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 27:10"> 他為簾幕做了五根柱子和柱子上的鉤子，把柱頂和柱子上的箍環包上了金；柱子有五個銅底座。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:33; 出埃及記 12:31; 出埃及記 3:19–20"> 耶和華對摩西說：「現在你必看到我要對法老做的事；他必因我大能的手讓子民走，他必因我大能的手從自己的地驅逐他們。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米書 9:24; 瑪拉基書 3:6; 使徒行傳 17:24–25"> 神指示摩西說：「我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 83:18; 詩篇 68:4; 創世記 17:1"> 我曾經以『全能的神』向亞伯拉罕、以撒、雅各顯現；至於我的名字『耶和華』，我未曾讓他們知道。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:4; 創世記 15:18; 創世記 17:7–8"> 我又與他們確立了我的約，要賜給他們迦南地，就是他們曾寄居在其中的寄居之地。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 2:24; 詩篇 106:44–45; 以賽亞書 63:9"> 現在，我聽見了以色列子孫因埃及人奴役他們而發出的哀聲，我就記念我的約。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 26:8; 歷代志上 17:21; 出埃及記 7:4"> 「因此你當對以色列子孫說：『我是耶和華。我要把你們從埃及的苦役中領出來，我要解救你們脫離埃及的奴役，我要用伸出的膀臂和極大的審判來贖回你們；</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:6; 申命記 29:13; 申命記 4:20"> 我要揀選你們作我的子民，我也要作你們的神。這樣你們就知道：我是耶和華你們的神，是把你們從埃及的苦役中領出來的那一位。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 26:3; 創世記 15:18; 以西結書 20:42"> 我要領你們進入我舉手起誓要賜給亞伯拉罕、以撒、雅各的那地，我要把那地賜給你們作產業。我是耶和華。』」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:21; 約伯記 21:4; 出埃及記 14:12"> 摩西就把這話告訴了以色列子孫，但他們因靈裡的沮喪和沉重的勞役，沒有聽從摩西。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 於是耶和華指示摩西說：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 6:29; 出埃及記 5:23; 出埃及記 3:10"> 「你去，對埃及王法老說，讓以色列子孫走，離開法老的地。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 4:10; 耶利米書 1:6; 出埃及記 6:30"> 摩西在耶和華面前說：「看哪，以色列子孫尚且不聽從我，法老又怎麼會聽從我呢？因為我是個口脣笨拙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="口唇笨拙——原文直譯「嘴唇沒有受割禮」。">a</a></sup>的人。」</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 27:23; 提摩太前書 6:13; 詩篇 91:11"> 耶和華對摩西和亞倫說話，吩咐了他們有關以色列子孫和埃及王法老的事，要他們把以色列子孫從埃及地領出來。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="創世記 46:9; 歷代志上 5:3; 民數記 26:5–7"> 以下是他們父家的首領：<br /><span className="pl pl-1">以色列長子魯本的兒子是哈諾、法路、希斯倫和迦米。</span><br /><span className="pl pl-1">這是魯本的家族。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 4:24; 創世記 46:10; 民數記 26:12–13"> <span className="pl pl-1">西緬的兒子是耶姆利、雅憫、阿轄、雅斤、瑣哈爾，以及掃羅——迦南女子的兒子。</span><br /><span className="pl pl-1">這是西緬的家族。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="民數記 3:17; 創世記 46:11; 歷代志上 6:1"> <span className="pl pl-1">利未的兒子，按著他們的家系，名字如下：革順、哥轄、米拉利；</span><br /><span className="pl pl-1">利未一生的年歲是一百三十七歲。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:17; 民數記 3:18; 歷代志上 23:7"> <span className="pl pl-1">革順的兒子，按著他們的家族，名字如下</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="名字如下——輔助詞語。">b</a></sup><br /><span className="pl pl-1">：立尼、示每。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 6:18; 歷代志上 6:2; 民數記 3:19"> <span className="pl pl-1">哥轄的兒子是阿姆蘭、以斯哈、希伯倫和烏基業；</span><br /><span className="pl pl-1">哥轄一生的年歲是一百三十三歲。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="民數記 3:20; 歷代志上 23:21; 歷代志上 6:19"> <span className="pl pl-1">米拉利的兒子是瑪赫利和穆希。</span><br /><span className="pl pl-1">這是利未的家族，都按著他們的家系。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="民數記 26:59; 出埃及記 2:1–2; 出埃及記 6:18"> <span className="pl pl-1">阿姆蘭娶了他父親的妹妹約基別為妻，</span><br /><span className="pl pl-1">約基別為他生了亞倫和摩西；</span><br /><span className="pl pl-1">阿姆蘭一生的年歲是一百三十七歲。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:1; 歷代志上 6:37–38; 民數記 16:32"> <span className="pl pl-1">以斯哈的兒子是可拉、尼斐和澤克利。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="利未記 10:4; 民數記 3:30; 尼希米記 3:20"> <span className="pl pl-1">烏基業的兒子是米沙利、以利撒番和西提利。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路得記 4:19–20; 民數記 2:3; 民數記 1:7"> <span className="pl pl-1">亞倫娶了亞米拿達的女兒、拿順的妹妹以利沙巴為妻，</span><br /><span className="pl pl-1">以利沙巴為他生了納達布、亞比戶、以利亞撒和以塔瑪爾。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 6:22–23; 民數記 16:1; 撒母耳記上 1:1"> <span className="pl pl-1">可拉的兒子是亞惜、以利加拿和亞比亞撒。</span><br /><span className="pl pl-1">這是可拉的家族。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 24:33; 民數記 25:7–13; 約書亞記 22:31–32"> <span className="pl pl-1">亞倫的兒子以利亞撒娶了普提業的一個女兒為妻，</span><br /><span className="pl pl-1">他的妻子為他生了非尼哈。</span><br /><span className="pl pl-1">以上是利未人父系的首領，都按著他們的家族。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 12:51; 出埃及記 12:17; 出埃及記 7:4"> 正是這亞倫和摩西，耶和華曾對他們說：「你們要把以色列子孫從埃及地一隊一隊領出來！」</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 6:26; 出埃及記 7:10; 詩篇 77:20"> 而對埃及王法老說話，要把以色列子孫從埃及領出來的，也正是這摩西和亞倫。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 當耶和華在埃及地對摩西說話的日子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 6:11; 出埃及記 7:2; 出埃及記 6:2"> 耶和華指示摩西說：「我是耶和華。我對你所說的一切，你都要告訴埃及王法老。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 6:12; 出埃及記 4:10; 哥林多前書 9:16–17"> 摩西卻在耶和華面前說：「看哪，我是個口脣笨拙<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="口唇笨拙——原文直譯「嘴唇沒有受割禮」。">c</a></sup>的人，法老怎麼會聽從我呢？」</span>
</div>
</div>

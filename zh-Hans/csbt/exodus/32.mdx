<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:40; 申命記 9:9; 出埃及記 24:18"> 百姓見摩西遲遲不下山，就聚集到亞倫那裡，對他說：「起來！為我們造一個行走在我們前面的神明，因為那摩西，就是把我們從埃及地帶上來的那個人，我們不知道他發生了什麼事。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士師記 8:24–27; 出埃及記 12:35–36; 以西結書 16:17"> 亞倫對他們說：「把你們妻子兒女耳朵上的金環摘下，拿來給我！」</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 46:6; 以賽亞書 40:19–20; 耶利米書 10:9"> 全體民眾就把他們耳朵上的金環摘下，拿來給亞倫。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 9:18; 申命記 9:16; 列王紀上 12:28"> 亞倫從他們的手中接過來，用雕刻工具做模子，造了一個牛犢鑄像。<br />他們就說：「以色列啊，這是你的神，是把你從埃及地帶上來的那一位！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 10:20; 利未記 23:2; 利未記 23:37"> 亞倫看見，就在牛犢前面築了一座祭壇；亞倫宣告說：「明天是耶和華的節期。」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:7; 民數記 25:2; 使徒行傳 7:41–42"> 第二天，他們早早起來獻上了燔祭，也帶來了平安祭，然後百姓坐下吃喝，起來玩樂。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 32:11; 何西阿書 9:9; 士師記 2:19"> 耶和華對摩西說：「你趕快下去！因為你從埃及地帶上來的百姓已經敗壞了。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 12:28; 出埃及記 20:23; 出埃及記 20:3–4"> 他們很快就偏離了我指示他們的道路，為自己造了一個牛犢鑄像，向它下拜，向它獻祭，說：『以色列啊，這是你的神，是把你從埃及地帶上來的那一位！』」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:51; 申命記 9:13; 以賽亞書 48:4"> 耶和華又對摩西說：「我看見這子民，看哪，他們是硬著頸項的子民！</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 9:14; 民數記 14:12; 申命記 9:19"> 現在，你由著我，我的怒氣要向他們發作，我要滅絕他們，然後我要使你成為一個強大的民族。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 9:18–20; 申命記 9:26–29; 詩篇 106:23"> 摩西就懇求他的神耶和華的情面，說：「耶和華啊，你的怒氣為什麼要向你的子民發作呢？他們是你以偉大的能力，用大能的手，從埃及地領出來的。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 14:13–16; 申命記 9:28; 約書亞記 7:9"> 為什麼要讓埃及人說『他出於惡意領他們出來，為要在山中殺死他們，從地面上滅絕他們』？求你轉消你猛烈的怒氣，改變心意，不向你的子民降災禍。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 6:13; 創世記 12:7; 創世記 22:16"> 求你記念你的僕人亞伯拉罕、以撒和以色列；你曾經指著自己向他們起誓，對他們說：『我必使你們的後裔增多，如同天上的星辰，我必把我說過的這全地都賜給你們的後裔；他們必繼承這地，直到永遠。』」</span>
<span className="v" id="v14" data-v="14" data-xref="約拿書 3:10; 詩篇 106:45; 耶利米書 26:13"> 於是，耶和華改變心意，不把他所說的災禍降在他的子民身上。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 9:15; 出埃及記 40:20; 申命記 5:22"> 摩西轉身從山上下來，手中拿著兩塊見證版；這版兩面都寫著字，正面背面都寫著字。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 31:18; 希伯來書 8:10; 申命記 10:1"> 這版是神的工作，文字是神的文字，刻在版上。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 24:13; 出埃及記 17:9; 約書亞記 6:20"> 約書亞聽見百姓喊叫的聲音，就對摩西說：「營中有戰爭的聲音。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 15:1–18; 但以理書 5:4; 但以理書 5:23"> 摩西說：<br /><span className="pl pl-1">「這不是戰勝呼叫的聲音，</span><br /><span className="pl pl-1">也不是戰敗呼叫的聲音，</span><br /><span className="pl pl-1">我聽見的是歌唱的聲音。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 9:16–17; 耶利米書 31:32; 耶利米哀歌 5:15"> 摩西靠近營地，看見牛犢，又看見人在跳舞，摩西就怒氣發作，他把兩塊版從手中扔出，摔碎在山下；</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 9:21; 列王紀下 23:6; 列王紀下 23:15"> 又把他們造的牛犢拿過來，用火焚燒，磨成粉末，撒在水面上，讓以色列子孫喝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 20:9; 約書亞記 7:19–26; 列王紀上 21:22"> 摩西對亞倫說：「這百姓對你做了什麼，以致你把這大罪帶給了他們？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 9:24; 出埃及記 15:24; 出埃及記 16:20"> 亞倫說：「求我主不要怒氣發作；你是知道這百姓的，他們傾向罪惡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="傾向罪惡——原文直譯「在罪惡中」。">a</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 32:1–4; 出埃及記 32:8"> 他們對我說：『為我們造一個行走在我們前面的神明，因為那摩西，就是把我們從埃及地帶上來的那個人，我們不知道他發生了什麼事。』</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 32:4; 路加福音 10:29; 羅馬書 3:10"> 我對他們說『誰有金子就摘下來』，他們就給了我；我把金子扔進火中，這牛犢就出來了！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 47:3; 彌迦書 1:11; 啟示錄 16:15"> 摩西看見百姓放縱——因為亞倫放縱他們，使他們在敵人中成為笑柄——</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 9:32; 馬太福音 12:30; 撒母耳記下 20:11"> 摩西就站在營門口，說：「誰屬於耶和華，到我這裡來！」於是所有的利未子孫都聚集到他那裡。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 25:5; 路加福音 14:26; 申命記 33:8–9"> 摩西對他們說：「以色列的神耶和華如此說：『你們各人要把刀佩在大腿上，在營中往來，從一個門到另一個門，各人要殺死自己的兄弟、朋友和親屬。』」</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:9; 瑪拉基書 2:4–6; 哥林多前書 10:8"> 利未的子孫就照著摩西的話去做了。那一天，百姓中倒下的約有三千人。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 25:11–13; 馬太福音 10:37; 撒迦利亞書 13:3"> 摩西說：「今天你們已經奉獻自己<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="已經奉獻自己——或譯作「要承接聖職」。">b</a></sup>歸於耶和華，因為你們各人與自己的兒子和兄弟對立，今天給自己帶來了祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 12:20; 民數記 25:13; 列王紀下 17:21"> 第二天，摩西對百姓說：「你們犯了大罪，現在我要上到耶和華那裡去，或許我可以為你們贖罪。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 20:23; 但以理書 9:11; 但以理書 9:8"> 摩西回到耶和華那裡，說：「哦，這百姓犯了大罪，為自己造了金神像！</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 69:28; 羅馬書 9:3; 啟示錄 21:27"> 現在，求你饒恕他們的罪；不然，請你把我從你所記的冊子上抹掉吧！」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 29:20; 以西結書 18:4; 啟示錄 20:12"> 耶和華對摩西說：「誰對我犯罪，我就把誰從我的冊子上抹掉。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 23:20; 申命記 32:35; 馬太福音 23:35"> 現在你去，引導子民到我所告訴你的地方！看哪，我的使者必行走在你的前面！不過，在我懲罰的日子，我必懲罰他們的罪。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 7:41; 出埃及記 32:25; 撒母耳記下 12:9–10"> 耶和華打擊百姓，是因為他們向亞倫造的牛犢所做的事。</span>
</div>
</div>

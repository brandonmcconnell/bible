<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 38:1–7; 出埃及記 20:24–26; 出埃及記 40:10"> 「你要用金合歡木造一座祭壇，長五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="五肘——相當於2.3公尺；下同。1肘=45.7公分。">a</a></sup>，寬五肘，祭壇是方形的，高三肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三肘——相當於1.4公尺。">b</a></sup>；</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:27; 出埃及記 29:12; 利未記 4:7"> 要在祭壇的四角上做犄角，犄角從祭壇而出；又要把祭壇包上銅。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 7:45; 民數記 4:14; 歷代志上 28:17"> 你要做一些桶，用來收去祭壇的灰，並要做一些鏟子、碗、肉叉和火盆；祭壇的一切器具，都要用銅做。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 35:16; 出埃及記 25:12; 出埃及記 38:4–5"> 你要為祭壇做一個銅格網，在網的四角上做四個銅環，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 38:4"> 把網安放在祭壇的邊框之下，使網達到祭壇的半腰。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 35:13–15; 民數記 4:44; 出埃及記 30:4"> 你要用金合歡木為祭壇做兩根杠，把它們包上銅，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 25:28; 出埃及記 30:4; 民數記 4:13–14"> 把杠穿進環中，抬祭壇時，杠就在祭壇的兩邊。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 25:40; 出埃及記 25:9; 希伯來書 8:5"> 你要用木板把祭壇做成空心的，要照著在山上向你所指明的去做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 38:9–20; 以西結書 40:32; 以西結書 42:3"> 「你要做帳幕的院子。南邊要用捻成的細麻線編織院子的帷幔，邊長一百肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一百肘——相當於45.7公尺；下同。1肘=45.7公分。">c</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 26:19–21; 耶利米書 52:21; 出埃及記 36:38"> 帷幔的柱子二十根，柱子的銅底座二十個，柱子上的鉤子和箍環都是銀的。</span>
<span className="v" id="v11" data-v="11"> 北邊的長度也一樣，帷幔長一百肘，帷幔的柱子二十根，柱子的銅底座二十個，柱子上的鉤子和箍環都是銀的。</span>
<span className="v" id="v12" data-v="12"> 院子的西邊，帷幔寬五十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十肘——相當於22.9公尺；下同。1肘=45.7公分。">d</a></sup>，帷幔的柱子十根，柱子的底座十個。</span>
<span className="v" id="v13" data-v="13"> 院子的東邊，就是日出的方向，寬五十肘：</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:9; 出埃及記 26:36"> 門的一邊，帷幔寬十五肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="十五肘——相當於6.9公尺；下同。1肘=45.7公分。">e</a></sup>，帷幔的柱子三根，柱子的底座三個；</span>
<span className="v" id="v15" data-v="15"> 門的另一邊，帷幔也寬十五肘，帷幔的柱子三根，柱子的底座三個；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 26:36; 士師記 5:30; 出埃及記 28:39"> 院子的門簾寬二十肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二十肘——相當於9.1公尺。1肘=45.7公分。">f</a></sup>，用藍色、紫色、朱紅色線和捻成的細麻線，以刺繡的工藝編織，帷幔的柱子四根，柱子的底座四個。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 「院子四圍所有的柱子都要有銀箍環箍著，柱子上的鉤子都是銀的，柱子的底座都是銅的。</span>
<span className="v" id="v18" data-v="18"> 院子長一百肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一百肘——相當於45.7公尺。1肘=45.7公分。">g</a></sup>，兩邊各寬五十肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="五十肘——相當於22.9公尺。">h</a></sup>；帷幔高五肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="五肘——相當於2.3公尺。">i</a></sup>，用捻成的細麻線編織，柱子的底座都是銅的。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 35:18; 以賽亞書 22:23–25; 民數記 4:32"> 帳幕中各樣服事所用的一切器具，並帳幕所有的橛子，以及院子所有的橛子，都是銅的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未記 24:1–4; 撒迦利亞書 4:11–14; 詩篇 23:5"> 「你要吩咐以色列子孫，把壓榨的純橄欖油拿來給你，用來點燈，使燈持續點燃著。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 19:21; 民數記 18:23; 撒母耳記上 3:3"> 亞倫和他的兒子們要在會幕中，在見證櫃前的幔子外，從傍晚到早晨，在耶和華面前照管燈。這是以色列子孫世世代代永遠的律例。</span>
</div>

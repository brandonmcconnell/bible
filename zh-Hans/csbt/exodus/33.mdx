<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:7; 出埃及記 32:13; 出埃及記 32:7"> 耶和華對摩西說：「去，你和你從埃及地帶上來的百姓要從這裡上去，進入我起誓要給亞伯拉罕、以撒、雅各的那地——我曾對他們說：『我必把這地賜給你的後裔』。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 32:34; 約書亞記 24:11; 出埃及記 23:27–31"> 我必派遣使者在你前面，我必驅逐迦南人、亞摩利人、赫提人、比利洗人、希未人、耶布斯人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 32:9–10; 出埃及記 3:8; 使徒行傳 7:51"> 你們要上到那流奶與蜜之地。我不在你們中間同你們一起上去，因為你們是硬著頸項的子民，免得我在路上滅絕你們。」</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 14:39; 民數記 14:1; 以西結書 26:16"> 百姓聽見這個壞消息就悲慟，沒有人佩戴裝飾。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 16:21; 民數記 16:45–46; 出埃及記 33:3–4"> 耶和華對摩西說：「你要對以色列子孫說：『你們是硬著頸項的子民，如果我在你們中間同你們一起上去，哪怕只是一瞬間也會滅絕你們。現在，你們要從你們身上取下裝飾，我好知道要怎麼處置你們。』」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 33:4; 出埃及記 32:3; 耶利米書 2:19"> 於是，從何烈山起，以色列子孫就摘掉了他們的裝飾。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 55:6–7; 出埃及記 29:42–43; 箴言 15:29"> 摩西一向拿帳篷支搭在營地外面，離營地有一段距離；摩西稱呼它為「會幕」。所有尋求耶和華的，就到營地外面的會幕去。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 16:27"> 每當摩西出去到那帳篷的時候，全體民眾就都起來，各人站在自己帳篷的入口，望著摩西，直到他進入那帳篷。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 99:7; 出埃及記 31:18; 出埃及記 13:21–22"> 每當摩西進入那帳篷的時候，雲柱就降下來，停留在那帳篷的入口，耶和華就與摩西說話。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 8:22; 列王紀上 8:14; 出埃及記 4:31"> 全體民眾看見雲柱停留在帳篷入口的時候，就都起來，各人在自己帳篷的入口下拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 12:8; 申命記 34:10; 出埃及記 24:13"> 耶和華與摩西面對面說話，就像人與朋友說話。摩西回到營地的時候，他的助手<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="助手——或譯作「侍從」。">a</a></sup>，年輕人嫩的兒子約書亞卻不離開那帳篷。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 33:17; 耶利米書 1:5; 約翰福音 10:14–15"> 摩西對耶和華說：「看，你對我說『把這百姓帶上來』，卻沒有讓我知道你要派遣誰與我同去。你曾說：『我按你的名認識你，你也在我眼前蒙了恩。』</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:33; 詩篇 25:4; 詩篇 27:11"> 現在，如果我在你眼前蒙恩，求你使我明白你的道路，使我認識你，好讓我在你眼前蒙恩。看，這民是你的子民！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約書亞記 21:44; 馬太福音 11:28; 約書亞記 1:5"> 耶和華說：「我必親自與你同去，我必使你得安息。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:9; 詩篇 4:6; 出埃及記 33:3"> 摩西對耶和華說：「如果你不親自與我們同去，就不要把我們從這裡帶上去。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:7; 民數記 14:14; 列王紀上 8:53"> 人怎麼能知道我和你的子民在你眼前蒙恩呢？難道不是因為你與我們同去，才使我和你的子民從地面上的萬民中分別出來嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 65:24; 約翰一書 5:14–15; 出埃及記 33:12"> 耶和華對摩西說：「你所求的這事我必做，因為你在我眼前蒙恩，並且我按你的名認識你。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="啟示錄 21:23; 出埃及記 33:20; 提多書 2:13"> 摩西說：「求你向我顯出你的榮耀。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="羅馬書 9:15–18; 以弗所書 1:6–8; 耶利米書 31:14"> 耶和華說：「我要使我一切的美善在你面前經過，我要在你面前宣告耶和華的名。我要恩待誰就恩待誰，我要憐憫誰就憐憫誰。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 32:30; 約翰福音 1:18; 提摩太前書 6:16"> 他又說：「你不能看見我的臉，因為沒有人看見我還能存活。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 5:31; 撒迦利亞書 3:7; 約書亞記 20:4"> 耶和華說：「看哪，我這裡有個地方，你要站在磐石上！</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 91:1; 以賽亞書 2:21; 詩篇 91:4"> 我的榮耀經過的時候，我要把你放在磐石縫中，用我的手掌遮蔽你，直到我過去。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 33:20; 約翰福音 1:18; 提摩太前書 6:16"> 然後我會移開我的手掌，你就會看見我的背，卻不會看見我的臉。」</span>
</div>
</div>

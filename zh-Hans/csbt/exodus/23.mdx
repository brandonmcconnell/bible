</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; 路加福音 23:23–24"> 「不可隨眾行惡；不可在爭訟的事上隨眾偏行，作證屈枉公義<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公義——輔助詞語。">a</a></sup>，</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 3:17; 利未記 19:15; 詩篇 82:2–3"> 也不可在爭訟的事上偏袒貧弱者。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 22:1–4; 帖撒羅尼迦前書 5:15; 馬太福音 5:44"> 「如果你遇見仇敵的牛或驢迷失，就必須把牠帶回來給你的仇敵。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 22:4"> 「如果你看見恨你之人的驢被壓臥在重擔之下，就不可置之不理留給驢的主人，必須與他一起挪開重擔。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 3:5; 耶利米書 5:28; 利未記 19:15"> 「不可在貧窮人的爭訟上屈枉公正。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:25; 出埃及記 34:7; 出埃及記 23:1"> 要遠離虛假的控告，不可殺死無辜人和義人，因為我不會稱惡人為義。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 16:19; 箴言 17:23; 以賽亞書 5:23"> 不可收取賄賂，因為賄賂會使明眼人眼瞎，又會歪曲義人的話。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 27:19; 出埃及記 22:21; 申命記 24:14–18"> 不可壓迫寄居者，因為你們在埃及地作過寄居者，寄居者的心你們是知道的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 25:3–4"> 「六年你要耕種田地，收聚田地的出產，</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 26:34–35; 利未記 25:2–7; 利未記 25:11–12"> 但第七年要讓田地歇息休耕，好使你百姓中的貧窮人有吃的；他們所剩下的，田野的走獸可以吃。你也要照樣對待你的葡萄園和橄欖園。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:14; 出埃及記 34:21; 出埃及記 35:3"> 「六天你要做工，但第七天要安息，好使你的牛和驢安歇，也使你女僕的兒子和寄居者恢復精力。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 23:7; 撒迦利亞書 13:2; 提摩太前書 4:16"> 「我對你們所說的一切，你們都要謹守。別的神明的名號，你們不可提起，也不可讓人從你的口中聽到。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 16:16; 出埃及記 34:22–24; 利未記 23:34"> 「一年三次，你要向我守節期。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:7; 出埃及記 34:20; 民數記 28:16–25"> 要守無酵節，照著我吩咐你的，在亞筆月所定的日期吃無酵餅七天，因為你是在這個月從埃及出來的；誰也不可空手朝見我。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 34:22; 出埃及記 22:29; 利未記 23:9–21"> 要守收割節，就是收割你在田地播種、勞碌所得的初熟之物的節期。要守收藏節，就是在年底、你從田地收聚你勞碌所得之物的時候。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:16; 出埃及記 34:23; 出埃及記 23:14"> 一年三次，你所有的男子都要朝見主耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:25; 利未記 2:11; 申命記 16:4"> 「不可把我祭物的血與有酵之物一起獻祭，也不可使我節期祭牲<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="祭牲——輔助詞語。">b</a></sup>的脂肪過夜留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 34:26; 申命記 14:21; 申命記 26:10"> 「要把你土地裡上好的初熟之物帶到你神耶和華的殿中。<br />「不可用母山羊的奶煮牠的小山羊。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 33:14; 詩篇 91:11; 出埃及記 32:34"> 「看哪，我必派遣使者在你前面，為要在路上保守你，領你到我預備好的地方！</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:56; 詩篇 78:40; 希伯來書 12:25"> 你們在他面前要謹慎，聽他的聲音，不要違背他；否則，他不會饒恕你們的悖逆，因為他是奉我名的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="他是奉我名的——原文直譯「我的名在他裡面」。">c</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 12:3; 申命記 30:7; 撒迦利亞書 2:8"> 如果你留心聽他的聲音，遵行我所說的一切，我就作你仇敵的仇敵，作你敵人的敵人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 23:20; 以賽亞書 5:13; 創世記 15:19–21"> 我的使者必走在你前面，領你到亞摩利人、赫提人、比利洗人、迦南人、希未人、耶布斯人那裡；我必除滅他們。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:5; 申命記 12:30–31; 民數記 33:52"> 你不可向他們的神明下拜，不可服事它們，也不可照著那些人所做的去做，而要把那些神明徹底除掉，把神柱完全打碎。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:15; 出埃及記 15:26; 約書亞記 22:5"> 你們要服事耶和華你們的神，他就必祝福你的糧食和你的水。我必從你們當中除去疾病；</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 7:14; 約伯記 5:26; 申命記 28:4"> 在你的地上不會有流產的或不能生育的；我必使你滿了壽數。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 2:25; 創世記 35:5; 申命記 11:25"> 「我會在你前面發出威嚇，使你所到之處的所有民眾混亂，使你一切仇敵轉身而逃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 7:20; 約書亞記 24:11–12"> 我會在你前面派出黃蜂，使牠們從你面前驅逐希未人、迦南人、赫提人。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 7:22; 約書亞記 17:12–13; 士師記 3:1–4"> 我不會在一年之內就從你面前驅逐他們，免得那地變得荒涼，田野的走獸增多危害你。</span>
<span className="v" id="v30" data-v="30"> 我會一點一點地從你面前驅逐他們，直到你繁衍增多，繼承那地。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 15:18; 申命記 11:24; 約書亞記 21:44"> 我會定下你的邊界，從紅海直到非利士人之海，又從曠野直到大河<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="大河——指幼發拉底河。">d</a></sup>。我會把那地的居民交在你的手中，你要把他們從你面前驅逐出去。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 7:2; 出埃及記 34:12; 出埃及記 34:15"> 你不可與他們和他們的神明立約；</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 106:36; 申命記 7:16; 出埃及記 34:12"> 不可讓他們住在你的地上，免得他們使你犯罪敵對我。如果你服事他們的神明，這必定成為你的陷阱。」</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="申命記 5:22; 申命記 5:4; 申命記 4:36"> 神吩咐了以下這一切話，說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 5:6; 何西阿書 13:4; 利未記 26:13"> <span className="pl pl-1">「我是耶和華你的神，是把你從埃及地、從為奴之家領出來的那一位。</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 5:7; 馬太福音 4:10; 詩篇 81:9"> <span className="pl pl-1">除我以外，你不可有別的神。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="申命記 5:8; 利未記 26:1; 申命記 4:15–19"> <span className="pl pl-1">不可為自己造偶像</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="偶像——或譯作「雕像」。">a</a></sup><br /><span className="pl pl-1">，不可造上天、下地和地底下水中之物的任何形象。</span></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 5:9; 民數記 14:18; 申命記 4:24"> <br /><span className="pl pl-1">不可向它們下拜，也不可服事它們，因為我耶和華你的神是嫉憤的神。恨我的人，我必懲罰他們的罪孽，從父到子，直到三代、四代；</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:9; 約翰福音 14:21; 約翰一書 5:3"> <br /><span className="pl pl-1">愛我並遵守我誡命的人，我必向他們施慈愛，直到千代。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="申命記 5:11; 利未記 19:12; 雅各書 5:12"> <span className="pl pl-1">不可妄稱你神耶和華的名，因為妄稱耶和華名的人，耶和華必不讓他免於罪罰。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="利未記 26:2; 利未記 19:3; 出埃及記 31:13–16"> <span className="pl pl-1">要記念安息日，把它分別為聖。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 13:14; 出埃及記 34:21; 出埃及記 23:12"> <br /><span className="pl pl-1">六天你要勞碌，做你一切工作；</span></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 5:14–15; 出埃及記 34:21; 民數記 15:32–36"> <br /><span className="pl pl-1">但第七日是你神耶和華的安息日，你和你的兒女、僕婢，你的牲畜，以及你城裡的寄居者，都不可做任何工作。</span></span>
<span className="v" id="v11" data-v="11" data-xref="創世記 1:1–2; 創世記 2:2–3; 出埃及記 31:17"> <br /><span className="pl pl-1">因為六日中耶和華造了諸天、大地、海和其中的萬有，在第七日他就安息了，所以耶和華祝福安息日，把它分別為聖。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 6:1–3; 歌羅西書 3:20; 申命記 5:16"> <span className="pl pl-1">要孝敬父母，使你的日子在你神耶和華所賜給你的地上長久。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 13:9; 申命記 5:17; 創世記 9:5–6"> <span className="pl pl-1">不可殺人。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:4; 申命記 5:18; 羅馬書 7:2–3"> <span className="pl pl-1">不可通姦。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 13:9; 以弗所書 4:28; 利未記 19:11"> <span className="pl pl-1">不可偷竊。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 19:5; 馬太福音 19:18; 詩篇 15:3"> <span className="pl pl-1">不可作假見證指證你的鄰人。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:9; 路加福音 12:15; 希伯來書 13:5"> <span className="pl pl-1">不可貪愛你鄰人的房屋，不可貪愛你鄰人的妻子、僕婢、牛驢，以及任何屬於你鄰人的東西。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 19:16–18; 耶利米書 23:23; 詩篇 139:7–8"> 全體民眾都聽見<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="聽見——輔助詞語。">b</a></sup>雷聲和號角聲，看見閃電和山上冒煙；百姓看見了就顫抖，遠遠地站著。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; 使徒行傳 7:38; 加拉太書 3:19"> 他們對摩西說：「你向我們說話吧，我們會聽；不要讓神向我們說話，免得我們死。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 13:3; 箴言 3:7; 撒母耳記上 12:20"> 摩西對百姓說：「不要害怕，因為神來臨是要試驗你們，好使你們常存對他的敬畏，不致犯罪。」</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 8:12; 詩篇 97:2; 詩篇 18:9"> 百姓就遠遠地站著，摩西卻接近神所在的幽暗之中。</span>
</div>
<div className="bp">

<span className="v" id="v23" data-v="23" data-xref="以西結書 20:39; 西番雅書 1:5; 列王紀下 17:33"> 你們不可造別的神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="別的神——輔助詞語。">c</a></sup>與我並列——不可為自己造金銀神像。</span>
</div>

<span className="v" id="v25" data-v="25" data-xref="約書亞記 8:31; 申命記 27:5–6"> 如果你為我造一座石祭壇，不可用鑿過的石頭來築，因為你在石頭上一動鑿刀，就玷汙了石頭。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:16; 傳道書 5:1; 利未記 10:3"> 你不可用臺階登上我的祭壇，免得在其上顯露你的下體。』</span>

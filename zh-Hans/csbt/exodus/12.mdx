<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華在埃及地對摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 13:4; 申命記 16:1; 出埃及記 34:18"> 「本月要作為你們的正月，作為你們一年的第一個月。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 1:2; 哥林多前書 5:7; 約翰福音 1:29"> 你們要吩咐全體以色列會眾說：本月十日，他們各人要按著父家為自己取羔羊，一家一隻羔羊。</span>
<span className="v" id="v4" data-v="4"> 如果一家的人太少，吃不了一隻羔羊，那麼就要與最靠近的鄰居按人數共取一隻；你們要按各人的食量估算羔羊的量。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:18–19; 希伯來書 9:13–14; 瑪拉基書 1:14"> 羔羊必須是無瑕疵的一歲公羊，可以從綿羊或山羊裡取。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 23:5; 歷代志下 30:15–18; 民數記 28:16"> 你們要把羔羊保留到本月十四日；當天黃昏的時候，以色列全體會眾要宰殺羔羊。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:28; 出埃及記 12:22–23; 希伯來書 9:22"> 他們要取一些血，塗在他們吃羔羊的房屋的兩邊門框上和門楣上。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 34:25; 申命記 16:7; 出埃及記 13:3"> 那天夜裡，他們要吃用火烤的羔羊肉，與無酵餅和苦菜一起吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 12:8; 申命記 16:7; 耶利米哀歌 1:13"> 你們不可吃任何生的或用水煮的羔羊肉，只可吃用火烤的，連頭帶腿，與內臟一起烤；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 23:18; 出埃及記 34:25; 出埃及記 29:34"> 你們一點也不可留到早晨，任何留到早晨的，都要用火燒掉。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 12:27; 以弗所書 6:15; 哥林多前書 5:7"> 你們要這樣吃羔羊的肉：腰間束帶，腳上穿鞋，手中拿杖，並要快快地吃。這是耶和華的逾越節。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 33:4; 出埃及記 12:23; 詩篇 82:6"> 「那天夜裡，我要遍行埃及地，擊殺埃及地所有頭生的，無論是人還是牲畜；我還要對埃及的一切神明施行審判。我是耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 11:28; 出埃及記 12:23; 約翰一書 1:7"> 這血在你們所住的房屋上，要作為你們的標記。我看見這血，就會越過你們；我打擊埃及地的時候，毀滅的災殃就不會臨到你們。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 23:21; 出埃及記 12:24; 出埃及記 13:9–10"> 「這一天要成為你們的記念，你們要守這日為耶和華的節期；你們世世代代要守這節期，作為永遠的律例。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:14; 申命記 16:3; 出埃及記 23:15"> 你們要吃無酵餅七天；第一天就要把酵從你們的家裡除掉，因為從第一天到第七天，凡吃了有酵之物的，那人就要從以色列中被剪除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 23:7–8; 民數記 28:18; 出埃及記 16:23"> 第一天你們要有神聖的聚會，第七天你們也要有神聖的聚會；在這兩天，任何工作都不可做，只能預備各人吃的東西，這是你們唯一可做的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 7:5; 出埃及記 13:3; 出埃及記 12:41"> 「你們要守無酵節，因為就在這一天，我把你們的大軍從埃及地領出來，所以你們世世代代要守這一日，作為永遠的律例。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 23:5–8; 出埃及記 12:15; 出埃及記 12:1–2"> 從一月十四日傍晚到二十一日傍晚，你們要吃無酵餅。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 12:15; 出埃及記 23:15; 申命記 16:3"> 在這七天，你們的家裡不可有酵，因為凡吃了有酵之物的，無論是外人還是本族人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本族人——原文直譯「本地人」；本章下同。">a</a></sup>，那人就要從以色列的會眾當中被剪除。</span>
<span className="v" id="v20" data-v="20"> 一切有酵之物，你們都不可吃；在你們居住的任何地方，你們都要吃無酵餅。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:3; 路加福音 22:7–13; 歷代志下 35:5–6"> 於是摩西召來以色列所有的長老，對他們說：「你們要按著你們的家族，為自己挑選並取來一隻羔羊，宰殺這逾越節的羔羊。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:28; 民數記 19:18; 詩篇 51:7"> 你們要拿一把牛膝草，蘸在盆中的血裡，把盆中的血塗在門楣上和兩邊的門框上。你們誰都不可出自己的家門，直到早晨，</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 7:3; 啟示錄 9:4; 希伯來書 11:28"> 因為耶和華要遍行這地，擊殺埃及人；耶和華看見門楣上和兩邊門框上的血，就會越過那門，不允許那毀滅者進入你們的房屋擊殺你們。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 12:14; 創世記 17:8–10"> 「你們要遵守這吩咐，作為你和你子孫的定例，直到永遠。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 3:17; 出埃及記 3:8; 申命記 12:8–9"> 日後，你們進入耶和華應許賜給你們的那地，也要守這服事之禮。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 13:14–15; 申命記 32:7; 詩篇 145:4"> 日後，你們的子孫問你們『這服事之禮對你們是什麼意思呢？』</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 4:31; 出埃及記 12:11; 哥林多前書 5:7"> 你們就要說『這是獻給耶和華的逾越節之祭；他在擊殺埃及人的時候，越過了在埃及的以色列子孫的房屋，解救了我們的家。』」於是，以色列百姓俯身下拜。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 11:28"> 以色列子孫就這樣去做；耶和華所指示摩西和亞倫的，以色列子孫都照著去做了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 78:51; 出埃及記 4:23; 詩篇 105:36"> 到了半夜，耶和華擊殺了埃及地所有頭生的——從坐寶座的法老的長子到牢房裡的俘虜的長子，以及所有頭生的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 11:6; 阿摩司書 5:17; 箴言 21:13"> 法老夜間起來，他所有的臣僕和所有的埃及人也都起來了；在埃及有極大的哀聲，因為沒有一家不死人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 6:1; 出埃及記 10:9; 出埃及記 3:19–20"> 於是法老夜間召來摩西和亞倫，說：「起來，你們和以色列子孫都從我的子民中間出去！照著你們所說的，去服事耶和華；</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 10:26; 創世記 27:34; 創世記 27:38"> 也照著你們所說的，帶著你們的羊群和牛群走！不過，你們也要為我祝福！」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="詩篇 105:38; 出埃及記 11:1; 創世記 20:3"> 埃及人催促以色列百姓，要他們趕快走，離開那地，因為埃及人說：「我們全都要死了。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 8:3"> 於是以色列百姓拿起未放入酵的麵團和揉麵盆，用他們的衣服包住，扛在肩膀上。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及記 3:21–22; 出埃及記 11:2–3; 創世記 15:14"> 以色列子孫照著摩西的話去做，向埃及人索要銀器、金器和衣服。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 15:14; 使徒行傳 7:10; 出埃及記 3:21–22"> 耶和華使以色列百姓在埃及人眼前蒙恩，埃及人就給了他們索要的；這樣他們就剝奪了埃及人。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民數記 1:46; 出埃及記 38:26; 民數記 33:3"> 以色列子孫從拉美西斯起程往疏割去，除了孩童，步行的男人約有六十萬；</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 11:4; 撒迦利亞書 8:23"> 與他們一起上去的，還有眾多混雜的族群，以及羊群、牛群等極多的牲畜。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 11:1; 出埃及記 6:1; 出埃及記 12:31–33"> 他們把從埃及帶出來的未放入酵的麵團烤成無酵餅，因為他們被驅逐離開埃及，不能耽延，也沒有為自己預備食物。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 15:13; 使徒行傳 7:6; 使徒行傳 13:17"> 以色列子孫在埃及居住的時間是四百三十年。</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷書 2:3; 約翰福音 7:8; 使徒行傳 1:7"> 到了四百三十年結束的時候，就在這一天，耶和華的全軍都從埃及地出來了。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 16:1–6; 出埃及記 12:14; 出埃及記 13:10"> 這一夜是為耶和華所謹守的，因為他把他們從埃及地領出來；這一夜是所有的以色列子孫世世代代都要為耶和華謹守的夜。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出埃及記 12:48; 民數記 9:14; 出埃及記 12:11"> 耶和華對摩西和亞倫說：「逾越節的律例是這樣的：所有外邦人都不可吃逾越節的羔羊；</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 17:12–13; 創世記 17:23"> 至於各人用銀子買來的每一個奴僕，在你給他行過割禮之後，他就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 22:10; 以弗所書 2:12"> 客居者和雇工都不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 9:12; 約翰福音 19:36; 約翰福音 19:33"> 你們要在同一間屋子裡吃，羔羊的肉一點也不可帶到屋子外面，羔羊的骨頭一根也不可折斷。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及記 12:6; 民數記 9:13; 出埃及記 12:3"> 全體以色列會眾都要守這節期。</span>
<span className="v" id="v48" data-v="48" data-xref="民數記 9:14; 歌羅西書 3:11; 加拉太書 3:28"> 如果有外人寄居在你們中間，也願意向耶和華守逾越節，那麼他們中的每一個男子都要在受割禮之後，才可以近前來守節期；他也就像本族人那樣了；但所有未受割禮的人都不可吃逾越節的羔羊。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 15:15–16; 民數記 15:29; 利未記 24:22"> 本族人與寄居在你們中間的外人，都是同一個條例。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬太福音 7:24–25; 出埃及記 6:26; 出埃及記 7:4"> 所有的以色列子孫就這樣做了；耶和華所指示摩西和亞倫的，以色列子孫都照著做了。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及記 12:41; 出埃及記 6:26"> 就在這一天，耶和華把以色列子孫從埃及地一隊一隊領出來了。</span>
</div>

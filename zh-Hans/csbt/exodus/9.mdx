<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 8:1; 出埃及記 10:3; 出埃及記 8:20"> 耶和華對摩西說：「你到法老那裡去，對他說：『耶和華希伯來人的神如此說：讓我的子民走，好使他們服事我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 8:2; 出埃及記 4:23; 利未記 26:27–28"> 如果你拒絕讓他們走，還要強行留住他們，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:4; 使徒行傳 13:11; 撒母耳記上 6:9"> 看哪，耶和華的手就使極其嚴重的瘟疫臨到你田野中的牲畜，就是馬匹、驢子、駱駝、牛群和羊群！</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 8:22; 出埃及記 10:23; 瑪拉基書 3:18"> 但是耶和華會把以色列的牲畜和埃及的牲畜分別開來，所有屬於以色列子孫的，一隻也不會死。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 8:23; 出埃及記 10:4; 耶利米書 28:16–17"> 耶和華定下了時間，說：「明天，耶和華必在這地做這事。」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:48; 出埃及記 9:25; 詩篇 78:50"> 第二天，耶和華就做了這事。埃及的牲畜全都死了，而屬於以色列子孫的牲畜一隻也沒有死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 7:14; 出埃及記 8:32; 以賽亞書 48:4"> 法老派人去，看哪，屬於以色列的牲畜連一隻也沒有死！然而，法老又硬著心，不讓以色列百姓走。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 8:16"> 耶和華對摩西和亞倫說：「你們要雙手滿滿捧著爐灰，摩西在法老眼前向天空揚撒這爐灰。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 16:2; 申命記 28:27; 約伯記 2:7"> 這爐灰將在埃及全地變成微塵，使埃及全地的人和牲畜的身上都生出流膿的瘡。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 28:27"> 於是他們就拿了爐灰，站在法老面前。摩西把爐灰向天揚撒，人和牲畜的身上就生出了流膿的瘡。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 7:11–12; 出埃及記 8:18–19; 啟示錄 16:2"> 術士們因這瘡的緣故在摩西面前站立不住，因為術士們和所有埃及人的身上都生出了瘡。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 4:21; 出埃及記 7:13–14; 詩篇 81:11–12"> 然而，耶和華使法老的心剛硬，他就不聽從摩西和亞倫，正如耶和華對摩西所說的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及記 8:20; 出埃及記 7:15; 出埃及記 9:1"> 耶和華對摩西說：「你要清早起來，站到法老面前，對他說，『希伯來人的神耶和華如此說：讓我的子民走，好使他們服事我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 8:10; 利未記 26:28; 歷代志上 17:20"> 要知道，這一次我要使我所有的災殃降到你<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你——原文直譯「你的心」。">a</a></sup>、你的臣僕和你的子民身上，為要你知道在全地上沒有能與我相比的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 3:20; 出埃及記 9:3; 出埃及記 9:16"> 如果我現在伸手用瘟疫打擊你和你的子民，你早已從地上除滅了。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:17; 箴言 16:4; 詩篇 83:17–18"> 實際上，我使你存留是為要向你顯明我的大能，好讓我的名在全地上被講述。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 37:29; 以賽亞書 10:15; 以賽亞書 37:23–24"> 你還在對我的子民自高，不讓他們走。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 20:6; 詩篇 83:15; 出埃及記 9:22–25"> 看哪，明天大約這個時候，我必降下極其猛烈的冰雹，是自從埃及建國之日直到現在未曾有過的！</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 3:2"> 現在，你要派人去，把你的牲畜和田野中所有屬於你的都帶去避難。任何在田野中沒有被聚集到房屋裡的人和牲畜，冰雹必降在他們身上，他們就必死。』」</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯來書 11:7"> 法老的臣僕中，那些懼怕耶和華這話的，就讓自己的僕人們和牲畜逃避進房屋；</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 40:4; 約伯記 34:14; 歷代志上 22:19"> 而那些不把耶和華這話放在心上的，就把自己的僕人們和牲畜留在田野中。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="啟示錄 16:21; 出埃及記 7:19; 出埃及記 8:5"> 耶和華對摩西說：「向天伸出你的手，使冰雹落在埃及全地，落在人和牲畜身上，落在埃及地田間所有的蔬草上。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:13; 約書亞記 10:11; 以賽亞書 30:30"> 摩西向天伸出他的杖，耶和華就發出雷聲和冰雹，有火閃到地上。耶和華在埃及地降下冰雹。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 9:23; 馬太福音 24:21; 出埃及記 10:6"> 那時有冰雹，又有火在冰雹中不斷地閃爍，極其猛烈！這是埃及全地自從開國以來未曾有過的。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 78:47; 詩篇 105:32–33"> 在埃及全地，冰雹打擊了田野中所有的人和牲畜；冰雹又打擊了田間所有的蔬草，摧毀了田野中所有的樹木。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 11:7; 出埃及記 9:4; 出埃及記 10:23"> 只有以色列子孫所住的歌珊地，沒有冰雹。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 詩篇 129:4; 出埃及記 10:16"> 於是法老派人召來摩西和亞倫，對他們說：「這一次我犯了罪，耶和華是公義的，而我和我的子民是邪惡的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 8:8; 出埃及記 10:17; 出埃及記 8:28"> 請你們向耶和華祈求，因為我們已經受夠了神的雷聲和冰雹。我讓你們走，你們不用再留下來了。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 10:26; 列王紀上 8:38; 以賽亞書 1:15"> 摩西對他說：「我一出城，就會向耶和華伸開我的雙手，雷聲就會停止，也不會再有冰雹，好讓你知道這地是屬於耶和華的。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 26:10; 箴言 16:6; 以賽亞書 63:17"> 至於你和你的臣僕，我知道你們在神耶和華的面前還是沒有敬畏之心。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路得記 1:22; 路得記 2:23; 哈巴谷書 3:17"> 那時，因為大麥已經吐穗，亞麻也開了花，亞麻和大麥就被擊打了。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 10:22"> 小麥和黑麥卻沒有被擊打，因為它們是晚熟的。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及記 9:29; 出埃及記 8:12; 雅各書 5:17–18"> 摩西從法老那裡出了城，向耶和華伸開他的雙手，雷聲和冰雹就停止了，雨水也不再傾瀉在地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 7:14; 歷代志下 36:13; 出埃及記 4:21"> 法老看見雨水、冰雹和雷聲都停止了，就再次犯罪，他和他的臣僕都硬著心。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 4:21"> 法老的心剛硬，不讓以色列子孫走，正如耶和華藉著摩西所說的。</span>
</div>
</div>

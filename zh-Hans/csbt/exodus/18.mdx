<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 2:16; 詩篇 77:14–15; 出埃及記 3:1"> 摩西的岳父米甸祭司耶特羅，聽見了神為摩西和神的子民以色列所做的一切，就是耶和華怎樣把以色列人從埃及領出來的事。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及記 2:21; 出埃及記 4:25–26"> 摩西的岳父耶特羅帶來了摩西的妻子西坡拉——她先前被送回家；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 2:22; 使徒行傳 7:29; 詩篇 39:12"> 耶特羅也帶來了西坡拉的兩個兒子，一個名叫革順，因為摩西說「我在外邦之地作了寄居者」；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 13:6; 提摩太後書 4:17; 哥林多後書 1:8–10"> 一個名叫以利以謝，因為摩西說「我父親的神是我的幫助者，他解救我脫離了法老的刀劍」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:1; 出埃及記 3:12; 出埃及記 24:16–17"> 摩西的岳父耶特羅與摩西的兩個兒子和摩西的妻子一同來到曠野摩西那裡，就是他在神的山紮營的地方。</span>
<span className="v" id="v6" data-v="6"> 耶特羅傳話給摩西說<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="傳話給摩西說——原文直譯「對摩西說」。">a</a></sup>：「我，你的岳父耶特羅，與你的妻子和她的兩個兒子就要來到你這裡了。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 29:13; 創世記 14:17; 撒母耳記下 11:7"> 摩西就出來迎接他的岳父，向他下拜，親吻他，彼此問安，然後一起進入了帳篷。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 145:4–12; 尼希米記 9:9–15; 詩篇 107:2"> 摩西向他的岳父講述了耶和華為以色列的緣故對法老和埃及所做的一切事，以及以色列人在路上所遭遇的一切艱難，並耶和華怎樣解救了他們。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 12:26; 羅馬書 12:15; 以賽亞書 66:10"> 耶特羅因耶和華為以色列所做的一切美事，就是解救他們脫離埃及人之手的事，而歡樂喜悅。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 14:20; 撒母耳記下 18:28; 路加福音 1:68"> 耶特羅說：「耶和華是當受頌讚的！他解救你們脫離埃及人的手和法老的手，把這百姓從埃及人的手下解救出來。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 95:3; 出埃及記 15:11; 歷代志下 2:5"> 現在，通過埃及人狂傲對待這百姓的後果，我知道耶和華偉大，超越一切神明。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; 申命記 12:7; 出埃及記 24:11"> 摩西的岳父耶特羅帶來了燔祭和祭物獻給神；亞倫和以色列所有的長老都來了，與摩西的岳父在神面前吃飯。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 16:5; 約伯記 29:7; 士師記 5:10"> 第二天，摩西坐著為百姓施行審斷，百姓從早到晚站在摩西周圍。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父看見摩西為百姓所做的一切，就說：「你為百姓做的這是什麼事呢？為什麼你獨自坐著，而全體民眾從早到晚站在你周圍呢？」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 15:34; 民數記 27:5; 民數記 9:8"> 摩西對他的岳父說：「這是因為百姓到我這裡來求問神。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 24:14; 哥林多前書 6:1; 撒母耳記下 15:3"> 他們之間發生了什麼事，就會到我這裡來，我就在雙方之間施行審斷，使他們明白神的律例和訓誨。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 摩西的岳父對他說：「你這樣做不好。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 11:14–17; 使徒行傳 6:1–4; 哥林多後書 12:15"> 你和這些與你在一起的百姓都一定會疲憊不堪，因為這事對你太沉重，你獨自一人做不了。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 27:5; 申命記 5:5; 出埃及記 20:19"> 現在你當聽從我的話，我給你提個建議，願神與你同在！你要在神的面前代表百姓，把他們的事帶到神那裡；</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:1; 詩篇 143:8; 申命記 1:18"> 你要用律例和訓誨警誡他們，使他們明白他們當走的路和當做的事；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 6:3; 申命記 1:13–17; 歷代志下 19:5–10"> 你要從全體民眾當中選出有才能的、敬畏神的、誠實的、恨惡私利的人，立他們作千夫長、百夫長、五十夫長、十夫長來管理百姓，</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 11:17; 民數記 27:2; 民數記 15:33"> 讓他們隨時為百姓施行審斷——所有的大事都帶到你這裡來，而所有的小事都由他們自己審斷。這樣，你就可以輕省些，他們也可以與你一起分擔。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 8:6–7; 出埃及記 18:18; 撒母耳記上 8:22"> 如果你這樣做，神也這樣吩咐你，你就能站立得住，全體民眾也能平安地回到自己的地方。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 10:2; 出埃及記 18:19; 出埃及記 18:2–5"> 摩西聽從了他岳父的話，照著他所說的一切做了。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:15; 出埃及記 18:21; 使徒行傳 6:5"> 摩西從全體以色列人中挑選了有才能的人，立他們作百姓的首領，作千夫長、百夫長、五十夫長、十夫長。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 18:22; 出埃及記 18:14–15; 申命記 17:8"> 他們隨時為百姓施行審斷——難斷的事就帶到摩西那裡，而所有的小事都由他們自己審斷。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民數記 10:29–30; 士師記 19:9; 創世記 31:55"> 後來，摩西送走了他的岳父，他的岳父就回本地去了。</span>
</div>
</div>

</div>

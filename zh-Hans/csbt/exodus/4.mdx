<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及記" data-chapter="4" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 3:18; 出埃及記 2:14; 耶利米書 1:6"> 摩西回應說：「看哪！他們不會相信我，也不會聽從我的話，因為他們會說：『耶和華沒有向你顯現。』」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及記 4:17; 出埃及記 4:20; 以賽亞書 11:4"> 耶和華問摩西：「你手中的是什麼呢？」<br />他回答：「是一根杖。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:10–15; 阿摩司書 5:19; 出埃及記 4:17"> 耶和華說：「把杖扔在地上！」摩西把它扔在地上，它就變成了一條蛇；摩西急忙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="急忙——輔助詞語。">a</a></sup>逃避那條蛇。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 28:3–6; 創世記 22:1–2; 詩篇 91:13"> 耶和華接著對摩西說：「伸出你的手來，抓住蛇的尾巴！」摩西伸出手，拿住牠，牠就在摩西的手掌中變回了杖。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 19:9; 創世記 48:3; 出埃及記 3:15"> 耶和華說：<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶和華說：——輔助詞語。">b</a></sup>「這是為了使他們相信：耶和華他們先祖的神——亞伯拉罕的神、以撒的神、雅各的神，向你顯現了。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 5:27; 民數記 12:10"> 耶和華又對摩西說：「現在，把你的手放進懷裡！」他就把手放進懷裡。當他拿出手來，看哪，他的手長了痲瘋，像雪那樣白！</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 申命記 32:39; 馬太福音 8:3"> 耶和華接著說：「把你的手放回懷裡！」他就把手放回懷裡。當他從懷裡拿出手來，看哪，他的手復原了，像他身上別處<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="別處——輔助詞語。">c</a></sup>的皮肉那樣！</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:10; 申命記 32:39; 出埃及記 4:30–31"> 耶和華說：<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="耶和華說：——輔助詞語。">d</a></sup>「如果他們不相信你，也不聽從第一個神蹟所表明的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神蹟所表明的——原文直譯「神蹟的聲音」。">e</a></sup>，那麼他們必相信後一個神蹟所表明的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神蹟所表明的——原文直譯「神蹟的聲音」。">f</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 7:19–25; 出埃及記 1:22; 馬太福音 7:2"> 如果他們連這兩個神蹟都不相信，也不聽從你的話語，你就從尼羅河取一些水，倒在乾地上，你從尼羅河取來的水必在乾地上變成血。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 1:6; 出埃及記 6:12; 使徒行傳 7:22"> 摩西對耶和華說：「哦，主啊，我不是個能說會道的人——以前不是<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以前不是——原文直譯「昨天不是，前天也不是」。">g</a></sup>，從你對僕人說話以後也不是——我是個笨口拙舌的人！」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="阿摩司書 3:6; 詩篇 146:8; 以西結書 3:26–27"> 耶和華對他說：「是誰造人的口呢？又是誰使人口啞、耳聾、目明、眼瞎呢？難道不是我耶和華嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 1:9; 路加福音 12:11–12; 馬太福音 10:19–20"> 現在你去，我必親自與你的口同在，並指示你當說的話！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約拿書 1:3; 出埃及記 4:1; 馬太福音 13:41"> 摩西說：「哦，主啊，你要派遣誰經手，就派遣誰吧！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬可福音 14:13–15; 出埃及記 4:27; 歷代志上 21:7"> 於是耶和華的怒氣向摩西發作，他說：「不是有你的哥哥利未人亞倫嗎？我知道他能言善道。看哪，他正出來迎接你！他一看見你，心裡就會歡喜。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 51:16; 申命記 18:18; 路加福音 21:15"> 你要向他說話，把當說的話放在他的口中；我必親自與你的口同在，也必與他的口同在，並指示你們當做的事；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 7:1–2; 詩篇 82:6; 約翰福音 10:34–35"> 他要替你向子民說話，他對你就像是你的口，而你對他就像是神一樣。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 4:2; 哥林多前書 1:27; 出埃及記 7:9–20"> 你要把這根杖拿在你手中，用它來施行神蹟。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 3:1; 撒母耳記上 1:17; 提摩太前書 6:1"> 於是摩西就離開，回到他的岳父耶特羅那裡，對他說：「請讓我走，讓我回到我在埃及的同胞那裡，看看他們是否還活著。」<br />耶特羅對摩西說：「你平平安安地去吧！」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 2:20; 出埃及記 2:23; 出埃及記 2:15"> 耶和華在米甸對摩西說：「回埃及去！因為那些尋索你性命的人都死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 17:9; 民數記 20:8–9; 出埃及記 18:3–4"> 摩西就帶著他的妻子和兒子們，騎上驢，回埃及地去。摩西手中拿著神的杖。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="羅馬書 9:18; 以賽亞書 63:17; 出埃及記 14:8"> 耶和華對摩西說：「你回到埃及的時候，要留意我交在你手中的一切奇事，把它們施行在法老面前；但是我要使他的心剛硬，他就不會讓我的子民走。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 11:1; 羅馬書 9:4; 耶利米書 31:9"> 那時，你要對法老說：『耶和華如此說：以色列是我的兒子、我的長子。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 11:5; 出埃及記 12:29; 詩篇 135:8"> 我對你說過：讓我的兒子走，好使他服事我；你卻拒絕讓他走。看哪，我必殺你的兒子、你的長子！』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 17:14; 民數記 22:22–23; 何西阿書 13:8"> 在路上一處住宿的地方，耶和華遇見摩西，想要殺死他。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 5:2–3; 創世記 17:14; 撒母耳記下 16:7"> 西坡拉就拿一把石刀，割下她兒子的包皮，碰了摩西的腳，說：「你實在是我的血郎。」</span>
<span className="v" id="v26" data-v="26"> 這樣，耶和華就放了他。當時西坡拉說「血郎」，是因割禮的緣故。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:1; 出埃及記 4:14–16; 列王紀上 19:8"> 耶和華對亞倫說：「你到曠野去迎接摩西。」他就去了，在神的山遇見摩西，並親吻他。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 4:8–9; 出埃及記 4:15–16; 馬太福音 21:29"> 摩西把耶和華派遣他時所說的一切話以及吩咐他的一切神蹟都告訴了亞倫。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 3:16; 出埃及記 24:11; 出埃及記 24:1"> 摩西和亞倫就去招聚以色列子孫所有的長老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 4:16"> 亞倫複述了耶和華對摩西所說的一切話，又在以色列百姓眼前施行了那些神蹟。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:18; 出埃及記 2:25; 詩篇 106:12–13"> 於是百姓就相信了。他們聽見耶和華眷顧了以色列子孫、垂顧了他們的苦難，就俯身下拜。</span>
</div>
</div>

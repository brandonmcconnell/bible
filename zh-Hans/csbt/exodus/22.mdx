<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 19:8; 撒母耳記下 12:6; 箴言 6:31"> 「如果有人偷了牛或羊，並且把牠宰了或賣了，就要以五牛賠一牛，以四羊賠一羊。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 24:43; 馬太福音 6:19–20; 民數記 35:27"> 如果竊賊潛入時被發現，被打致死，那打他的就沒有殺人流血的罪；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 21:2; 以賽亞書 50:1; 馬太福音 18:25"> 但如果那時太陽已經升起了，那打他的就有殺人流血的罪。竊賊必須賠償；如果他一無所有，就要被賣，來賠償所偷的；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 22:7; 出埃及記 22:1; 出埃及記 22:9"> 如果所偷的，無論是牛，是驢，或是羊，確實被發現在他的手中還活著，他就要雙倍賠償。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:3; 出埃及記 22:12; 約伯記 20:18"> 「如果有人在田地裡或葡萄園中放牧，任憑自己的家畜到別人的田地吃食，他就必須用自己田地裡最好的，或自己葡萄園中最好的來賠償。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:9; 出埃及記 21:33–34; 撒母耳記下 14:30–31"> 「如果有火燃起，蔓延到荊棘，以致吞噬了堆積的禾捆、未收割的莊稼，或是田地，那點火的必須賠償。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 22:4; 箴言 6:30–31; 耶利米書 2:26"> 「如果有人把銀子或物品托給他的鄰人看管，東西卻從那人的家裡被偷走，當竊賊被抓到了，竊賊就要雙倍賠償；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 22:28; 申命記 16:18; 出埃及記 21:6"> 如果找不到竊賊，那家的主人就要被帶到神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神——或譯作「審判官」；下節同。">a</a></sup>面前，看他是否伸手拿了他鄰人的財產。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:1; 出埃及記 22:4; 民數記 5:6–7"> 任何占有行為<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="占有行為——原文直譯「過犯」。">b</a></sup>的案件，無論有關牛、驢、羊、衣裳，或任何失物，如果有一方說『這是我的』，他們兩個人的案件就要帶到神面前，神定為有罪的那人，要給他的鄰人雙倍賠償。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 12:48; 提摩太後書 1:12; 路加福音 16:11"> 「如果有人把驢、牛、羊，或任何牲畜托給他的鄰人看管，牲畜或死，或受傷，或丟失<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="丟失——原文直譯「被搶走」。">c</a></sup>，而沒有人看見，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:16; 利未記 5:1; 列王紀上 2:42–43"> 他們兩個人就要在耶和華面前起誓，表明那看管的沒有伸手拿他鄰人的財產。如果牲畜的主人接受了，就不用賠償；</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:39; 出埃及記 22:7"> 但如果牲畜確實從看管的那裡被偷走了，看管的就要給牲畜的主人賠償；</span>
<span className="v" id="v13" data-v="13" data-xref="那鴻書 2:12; 彌迦書 5:8; 以西結書 4:14"> 而如果牲畜確實是被野獸咬死了，他就要把被咬死的牲畜帶來作證，他就不用賠償了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 23:19–20; 出埃及記 21:34; 申命記 15:2"> 「如果有人向他的鄰人借牲畜，牲畜或受傷或死，牠的主人沒有在場，那借的人就必須賠償；</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 8:10"> 但如果牠的主人在場，那借的人就不用賠償。如果牲畜是租來的，賠償已經包含在租金內了<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="賠償已經包含在租金內了——原文直譯「牲畜就是為租金而來的」。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 22:28–29; 創世記 34:2–4"> 「如果有人引誘還沒有訂婚的處女，與她同睡，那人就必須交付聘禮，娶她為妻。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:12; 撒母耳記上 18:25; 申命記 22:29"> 如果她的父親堅決不肯把女兒嫁給他，他就要照著處女的聘禮交付<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="交付——原文直譯「稱出」。">e</a></sup>銀子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 20:27; 申命記 18:10–11; 撒母耳記上 28:3"> 「不可讓行巫術的女人存活。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 18:23; 申命記 27:21; 利未記 20:15–16"> 「凡與動物交合的，都必須處死。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 17:2–5; 民數記 25:7–8; 申命記 18:20"> 「不僅僅向耶和華獻祭，還向別的神明獻祭的，要被滅絕淨盡。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:9; 申命記 10:19; 利未記 19:33"> 「不可欺負寄居者，也不可壓迫他，因為你們在埃及地也作過寄居者。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 24:17; 以賽亞書 1:17; 以賽亞書 1:23"> 「不可苦待任何寡婦或孤兒。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:6; 詩篇 10:17–18; 路加福音 18:7"> 如果你確實苦待了他們，一旦他們向我迫切地呼求，我就必定垂聽他們的呼聲，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 109:9; 耶利米書 15:8; 詩篇 76:7"> 怒氣發作，用刀殺你們；這樣，你們的妻子就會成為寡婦，你們的兒子會成為孤兒。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; 利未記 25:35–37; 申命記 23:19–20"> 「如果你借錢給我的子民，給你們中間的困苦人，不可像債主那樣對待他，不可向他收取利息。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 20:16; 阿摩司書 2:8; 申命記 24:6"> 「如果你確實拿了你鄰人的衣裳作抵押，就要在日落之前把衣裳還給他；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 34:6; 歷代志下 30:9; 詩篇 136:10–11"> 因為那是他唯一的遮蓋，是他遮身的衣服；否則他蓋什麼睡覺呢？如果他向我呼求，我就會垂聽，因為我是有恩惠的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 23:5; 傳道書 10:20; 出埃及記 22:8–9"> 「不可咒罵神，也不可咒罵你百姓中的領袖。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及記 23:16; 出埃及記 13:2; 雅各書 1:18"> 「你從豐收的五穀和滿溢的榨池中拿來奉獻的，不可遲延獻上。你兒子們中頭生的，要獻給我；</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 22:27; 申命記 15:19; 出埃及記 13:12"> 你也要照樣對待你的牛和羊：讓牠與牠的母親在一起七天，第八天要把牠獻給我。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西結書 4:14; 利未記 19:2; 申命記 14:21"> 「你們要歸我作聖潔的人，因此你們不可吃田野中被咬死動物的肉，要把牠扔給狗。</span>
</div>

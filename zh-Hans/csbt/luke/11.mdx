<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:6–15; 傳道書 5:2; 詩篇 72:18–19"> 耶穌就對他們說：<span className="woj">「你們禱告的時候，要說：</span><br /><span className="pl pl-1 woj">『父</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="父——有古抄本作「我們在天上的父」。">a</a></sup><br /><span className="pl pl-1 woj">啊，</span><br /><span className="pl pl-1 woj">願你的名被尊為聖，</span><br /><span className="pl pl-1 woj">願你的國度來臨</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「願你的旨意行在地上，如同行在天上」。">b</a></sup><br /><span className="pl pl-1 woj">。</span><br /></span>

</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:1–8"> 耶穌又對他們說：<span className="woj">「假如你們當中誰有一個朋友，就半夜到朋友那裡去，對他說：『朋友，請借給我三個餅，</span></span>
<span className="v" id="v6" data-v="6"> <span className="woj">因為有一個朋友旅途中來到我這裡，我沒有什麼可以招待他。』</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 13:25; 加拉太書 6:17; 路加福音 7:6"> <span className="woj">那個人從裡面回答說：『請不要煩擾我。門已經關上了，我與孩子們也已經上了床，不能起來拿給你。』</span></span>

</div>
<div className="bp">

</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 12:22–24; 馬太福音 9:32–34; 馬可福音 7:32–37"> 有一次，耶穌正在驅趕一個使人成為啞巴的鬼魔。鬼魔一出去，啞巴就說出話來，眾人都感到驚奇。</span>

</div>
<div className="bp">

</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 12:43–45; 彼得前書 5:8; 約伯記 2:2"> <span className="woj">「有個汙靈從一個人身上出來以後，走遍無水之地，尋找安歇的地方，卻找不到，就說：『我要回到我離開的那屋裡去。』</span></span>

</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:42; 路加福音 1:48; 路加福音 23:29"> 耶穌正說這些話的時候，人群中有一個婦人高聲對他說：「那懷你胎又哺育你的是蒙福的！」</span>
</div>

<span className="v" id="v28" data-v="28" data-xref="路加福音 6:47–48; 路加福音 8:21; 詩篇 112:1"> 耶穌說：<span className="woj">「那聽了神的話語</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神的話語——或譯作「神的道」。">j</a></sup><span className="woj">又遵守的人，才真是蒙福的！」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:16; 馬可福音 8:11–12; 哥林多前書 1:22"> 那時，人群越聚越多，耶穌就開始說：<span className="woj">「這世代是個邪惡的世代</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="是個邪惡的世代——有古抄本作「是邪惡的」。">k</a></sup><span className="woj">，它在尋求神蹟；可是除了約拿</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="約拿——有古抄本作「先知約拿」。">l</a></sup><span className="woj">的神蹟以外，不會有神蹟賜給它了。</span></span>

</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:16–17; 馬可福音 4:21–22; 馬太福音 5:15–16"> <span className="woj">「沒有人點上油燈，放在隱藏的地方</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="隱藏的地方——或譯作「地窖」。">q</a></sup><span className="woj">或斗</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="斗——指「一種度量穀物的量器」；容量約為9升。">r</a></sup><span className="woj">底下</span><sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="有古抄本沒有「或斗底下」。">s</a></sup><span className="woj">，而是放在燈臺上，好讓進來的人能看見光。</span></span>

<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 7:36; 哥林多前書 9:19–23; 路加福音 14:1"> 耶穌說話的時候，有一個法利賽人請耶穌到他家裡吃飯，於是耶穌進去坐席。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 1:16–20; 馬太福音 4:18–22; 馬可福音 3:9"> 有一次，當人群擁擠著耶穌，聽神的話語<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的話語——或譯作「神的道」。">a</a></sup>的時候，他正站在革尼撒勒湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="革尼撒勒湖——就是「加利利湖」。">b</a></sup>邊。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 1:19; 馬太福音 4:21"> 他看見湖邊停著兩條船，漁夫們下了船，正在洗網。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:18; 馬太福音 13:1–2; 約翰福音 1:41–42"> 有一條船是西門的，耶穌上去，請他把船划出去，稍微離岸。耶穌就坐下來，從船上教導眾人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 21:6; 馬太福音 17:27"> 講完了以後，他對西門說：<span className="woj">「把船划到水深的地方，下網捕魚吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 2:5; 約翰福音 15:14; 路加福音 6:46–48"> 西門回答說：「老師，我們勞碌了一整夜，什麼也沒有捕到。不過按照你的話，我就下網吧。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 15:58; 約翰福音 21:6–11; 傳道書 11:6"> 他們這樣做了，網住了一大群魚，漁網幾乎要撐破。</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 6:2; 腓立比書 4:3; 使徒行傳 11:25"> 他們就招呼另一條船上的夥伴來幫忙；他們過來，裝滿了兩條船，甚至兩條船都幾乎要沉下去了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 6:5; 約伯記 42:5–6; 啟示錄 1:17"> 西門彼得看見，就俯伏在耶穌腳<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="腳——原文直譯「膝」。">c</a></sup>前，說：「主啊，離開我吧，因為我是個罪人！」</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; 詩篇 8:8; 馬可福音 9:6"> 那時，他和所有與他一起的人，都對這一網捕到的魚驚訝不已。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:19; 馬太福音 13:47; 以西結書 47:9–10"> 西門的夥伴，就是西庇太的兒子雅各和約翰，也同樣驚訝。<br />耶穌對西門說：<span className="woj">「不要怕！從今以後，你將得人了</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你將得人了——原文直譯「你將是一個捕人的人」。">d</a></sup><span className="woj">。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 4:20; 路加福音 5:28; 馬太福音 19:27"> 他們把兩條船靠了岸，捨棄一切跟從了耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 50:15; 路加福音 17:16; 馬太福音 8:2–4"> 有一次，耶穌在一個城裡，忽然有個渾身長滿痲瘋的人，看見耶穌就把臉伏在地上，央求他說：「主啊，如果你願意，你就能潔淨我。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 9:29–30; 約翰福音 4:50–53; 何西阿書 14:4"> 耶穌伸出手來摸他，說：<span className="woj">「我願意，你潔淨了吧！」</span>痲瘋病立刻離開了他。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 14:2–32; 路加福音 17:14; 馬可福音 1:44"> 耶穌吩咐他不要告訴任何人，說：<span className="woj">「只要去把自己給祭司看，並且為了你的潔淨，照著摩西所吩咐的去獻上祭物，好對他們做見證。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="馬太福音 15:30–31; 路加福音 12:1; 馬可福音 1:45–2"> 耶穌的消息反而越發傳開了。有一大群人聚集而來，聽他傳道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他傳道——輔助詞語。">e</a></sup>，也要他們的病得痊癒。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 馬可福音 1:35–36; 馬太福音 14:23"> 耶穌卻常常退到曠野去禱告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 馬太福音 11:5"> 就在那些日子裡，有一天耶穌在教導人的時候，也有些法利賽人和律法教師坐在那裡，他們是從加利利和猶太地區的各村莊，以及耶路撒冷來的。主的大能與耶穌同在，使他能醫病。</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 2:3–12; 馬太福音 9:2–8; 約翰福音 5:5–6"> 這時候，有幾個人用床榻抬來一個癱瘓的人，想把他帶進去放在耶穌面前。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 2:4; 馬太福音 10:27; 馬太福音 24:17"> 但由於人多，他們沒有辦法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="沒有辦法——原文直譯「找不到辦法」。">f</a></sup>把他帶進去，就爬上屋頂，從屋瓦中間把他和床榻一起縋到眾人當中，正在耶穌面前。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 14:9; 馬太福音 9:2; 馬可福音 2:5"> 耶穌看見他們的信心，就對癱瘓的人說：<span className="woj">「朋友</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="朋友——原文直譯「人哪」。">g</a></sup><span className="woj">，你的罪孽已經被赦免了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 43:25; 馬可福音 2:6–7; 路加福音 7:49"> 那些經文士和法利賽人就開始想：「這個人是誰？竟說褻瀆的話。除了神一位之外，誰能赦免罪呢？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; 以賽亞書 66:18; 詩篇 139:2"> 耶穌知道他們的意念，就對他們說：<span className="woj">「你們心裡為什麼這樣想呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 2:9; 馬太福音 9:5"> <span className="woj">或說『你的罪孽已經被赦免了』，或說『你起來走路』，哪一樣更容易呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 1:13; 以賽亞書 53:11; 路加福音 8:54"> <span className="woj">不過為要使你們知道人子在地上有赦免罪的權柄——」</span>耶穌就對癱瘓的人說：<span className="woj">「我吩咐你：起來，拿起你的床榻，回家去吧！」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 9:24; 路加福音 5:13; 詩篇 107:20–22"> 那個人立刻在大家面前站了起來，拿起他所躺的床榻回家去，一路上榮耀神。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 9:8; 馬太福音 12:23; 路加福音 7:16"> 於是大家都驚訝不已，就不住地榮耀神，並且滿懷敬畏之心說：「我們今天看到奇妙的事了！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬可福音 2:13–22; 馬太福音 9:9–17; 約翰福音 1:43"> 這些事以後，耶穌出去，看到一個名叫利未<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="利未——就是「馬太」。">h</a></sup>的稅吏，在稅關坐著。耶穌對他說：<span className="woj">「你跟從我！」</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 馬太福音 19:22–27; 列王紀上 19:19–21"> 利未就撇下一切，站起來跟從了耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬可福音 2:15; 路加福音 15:1; 哥林多前書 10:27"> 利未在自己家裡為耶穌預備盛大的宴席，有一大群稅吏和其他人與他們一同坐席。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 21:28–32; 路加福音 5:17; 馬可福音 7:3"> 法利賽人和他們的經文士就向耶穌的門徒們抱怨，說：「你們為什麼與那些稅吏和罪人一起吃喝呢？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 2:17; 馬太福音 9:12–13; 耶利米書 8:22"> 耶穌對他們說：<span className="woj">「健康的人不需要醫生，有病的人才需要。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前書 1:15–16"> <span className="woj">我來不是要召喚義人，而是要召喚罪人來悔改。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 9:14–17; 馬可福音 2:18–22; 約翰福音 3:25"> 他們對耶穌說：「約翰的門徒們經常禁食、祈禱，法利賽人的門徒們也是如此，而你的門徒們卻又吃又喝。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="約翰的門徒們……又吃又喝。——有古抄本作「為什麼約翰的門徒們……又吃又喝呢？」">i</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 3:29; 哥林多後書 11:2; 以賽亞書 54:5"> 耶穌對他們說：<span className="woj">「新郎與賓客</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="賓客——或譯作「伴郎」；原文直譯「新房之子」。">j</a></sup><span className="woj">在一起的時候，難道你們能叫賓客禁食嗎？</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行傳 14:23; 使徒行傳 3:21"> <span className="woj">可是日子將要來到：當新郎從他們中間被帶走的時候，他們那時——在那些日子裡就要禁食了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬太福音 9:16–17; 馬可福音 2:21–22; 哥林多後書 6:16"> 耶穌又對他們講了一個比喻：<span className="woj">「沒有人從新衣服上撕下一塊布來縫在舊衣服上，否則，他不但撕破了新衣服，而且來自新衣服的那塊布與舊衣服不相稱。</span></span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 9:13; 詩篇 119:83; 約書亞記 9:4"> <span className="woj">也沒有人把新酒裝在舊皮袋裡，否則新酒會脹破舊皮袋，酒會流出來，皮袋也會糟蹋了。</span></span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 8:8–13; 哥林多後書 5:17; 以西結書 36:26"> <span className="woj">因此，新酒必須裝在新皮袋裡。</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附「這樣兩者都保全了。」">k</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="希伯來書 11:39; 馬可福音 7:7–13; 耶利米書 6:16"> <span className="woj">沒有人喝了陳酒以後想喝新酒，因為他總說：『還是陳酒好</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="好——有古抄本作「更好」。">l</a></sup><span className="woj">。』」</span></span>
</div>
</div>

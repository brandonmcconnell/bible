<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:2; 路加福音 20:20; 詩篇 62:4"> 有一個安息日，耶穌到一個法利賽人的首領家裡去吃飯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="飯——原文直譯「餅」。">a</a></sup>，他們密切注意著耶穌。</span>
<span className="v" id="v2" data-v="2"> 當時，有一個患水腫病的人在他面前。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:10; 馬可福音 3:4; 路加福音 13:14–16"> 於是耶穌問律法師們和法利賽人，說：<span className="woj">「在安息日使人痊癒，可以不可以？」</span></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 22:46; 馬太福音 21:25–27"> 他們都安靜下來。耶穌就扶著那人，使他痊癒，讓他走了。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及記 23:4–5; 馬太福音 12:11–12"> 然後耶穌對他們說：<span className="woj">「你們當中誰有兒子</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="兒子——有古抄本作「驢」。">b</a></sup><span className="woj">或牛在安息日這一天掉到井裡，而不立刻把他拉上來呢？」</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行傳 6:10"> 他們對這些話不能答辯。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:3; 路加福音 11:43; 馬太福音 23:6"> 耶穌留意到被邀請的人怎樣在那裡挑選上座，就對他們講了一個比喻說：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> <span className="woj">「你被人邀請赴婚宴的時候，不要坐在上座，恐怕有比你更尊貴的人也被邀請，</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> <span className="woj">那邀請你們</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你們——原文直譯「你和他」。">c</a></sup><span className="woj">的會來對你說：『請讓座給這一位！』那時候，你就要羞慚地去坐末位了。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳記上 15:17"> <span className="woj">「你被邀請的時候，要去坐在末位上，好讓邀請你的人一旦來，就會對你說：『朋友，請來上座。』那時候，你就在所有一同坐席的人面前有光彩了。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 馬太福音 23:12; 箴言 29:23"> <span className="woj">因為每一個自我高舉的都會被降卑；而自我降卑的都會被高舉。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 5:46; 雅各書 2:1–6; 路加福音 6:32–36"> 耶穌又對邀請他的人說：<span className="woj">「你預備午餐或晚餐的時候，不要叫你的朋友、兄弟、親戚或富有的鄰居，免得他們也回請你，你就得了你的回報了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以賽亞書 58:10; 箴言 14:31"> <span className="woj">相反，你預備宴席的時候，要邀請那些貧窮的、殘疾的、瘸腿的、瞎眼的，</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行傳 24:15; 約翰福音 5:29"> <span className="woj">這樣你就蒙福了，因為他們沒有可回報你的，而在義人復活的時候，你將得到回報。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:9; 路加福音 22:30; 路加福音 13:29"> 一同坐席的有一個人聽了這些話，就說：「將來能在神的國裡吃飯<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="飯——原文直譯「餅」。">d</a></sup>的人是蒙福的！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 22:2–14; 啟示錄 22:17; 以賽亞書 55:1–7"> 耶穌對他說：<span className="woj">「有一個人預備盛大的宴席，邀請了許多人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:27–29; 馬太福音 10:1–4; 馬太福音 22:3–4"> <span className="woj">到了宴席的時刻，他派奴僕去對那些被邀請的人說：『請來吧，一切都已經預備好了！』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> <span className="woj">「可是他們都開始一致地推辭。第一個說：『我買了一塊地，必須去看看，請你容我推辭吧。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> <span className="woj">「另一個說：『我買了五對牛，正要去試試牠們，請你容我推辭吧。』</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 24:5; 哥林多前書 7:33; 路加福音 14:26–28"> <span className="woj">「另有人說：『我剛娶了妻子，所以不能去。』</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 馬太福音 11:5; 路加福音 14:24"> <span className="woj">「奴僕回來把這些事報告給主人。那家的主人就發怒，吩咐奴僕說：『趕快出去，到城裡的大街</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="大街——或譯作「廣場」。">e</a></sup><span className="woj">小巷，把那些貧窮的、殘疾的、瞎眼的、瘸腿的，都帶到這裡來。』</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 14:2; 以弗所書 3:8; 提摩太前書 2:5–6"> <span className="woj">「奴僕說：『主人，你所吩咐的已經做了，可是還有位子。』</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 22:9–10; 歌羅西書 1:28; 使徒行傳 13:47–48"> <span className="woj">「主人就對奴僕說：『出去，到大街和小巷</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="小巷——原文直譯「籬笆邊」。">f</a></sup><span className="woj">上去，強求人進來，好坐滿我的房子。</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 21:43; 使徒行傳 13:46; 約翰福音 8:24"> <span className="woj">我告訴你們：原本被邀請的那些人，沒有一個能嘗到我的宴席。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 6:24–27; 路加福音 12:1"> 有一大群人與耶穌同行。他轉過身來對他們說：</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:37; 約翰福音 12:25; 腓立比書 3:8"> <span className="woj">「如果有人到我這裡來，而不恨自己的父親、母親、妻子、兒女、兄弟、姐妹，甚至自己的生命，他就不能做我的門徒。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 10:38; 路加福音 9:23–25; 馬可福音 8:34–37"> <span className="woj">凡是不背著自己的十字架來跟從我的，也不能做我的門徒。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 馬太福音 10:22; 約書亞記 24:19–24"> <span className="woj">「你們當中到底有誰想蓋一座樓，不先坐下來計算費用，看自己是否能夠完成呢？</span></span>
<span className="v" id="v29" data-v="29"> <span className="woj">免得立好了地基，卻不能完工，看見的人都開始嘲笑他，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 6:11; 約翰二書 1:8; 哥林多前書 3:11–14"> <span className="woj">說：『這個人開始蓋了，卻不能完工！』</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王紀下 18:20–22"> <span className="woj">「或者，有哪一個君王要出去和別的君王交戰，不先坐下來考慮是否能夠用一萬兵去迎戰那用兩萬兵來攻打他的呢？</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 12:20; 雅各書 4:6–10; 路加福音 12:58"> <span className="woj">否則，就會趁著他還遠的時候，差派特使去求問和平的事宜。</span></span>
<span className="v" id="v33" data-v="33" data-xref="腓立比書 3:7–8; 約翰一書 2:15–16; 路加福音 5:28"> <span className="woj">同樣，你們當中任何人，如果不向自己所擁有的一切告別，就不能做我的門徒。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:13; 歌羅西書 4:6; 馬可福音 9:49–50"> <span className="woj">「因此鹽是好的，但如果連鹽也失去了味道，還能用什麼來調味呢？</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 11:15; 路加福音 9:44; 啟示錄 2:11"> <span className="woj">把它用在田地裡或在糞肥裡都不合適，只好把它丟在外面。凡是有耳可聽的，就應當聽！」</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:23–27; 路加福音 19:47–48; 使徒行傳 6:12"> 就在那些日子裡，有一天耶穌在聖殿裡教導民眾、傳福音的時候，祭司長們、經文士們和長老們一起上前來，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 2:14; 馬可福音 11:28–33; 約翰福音 2:18"> 對他說：「請告訴我們：你憑什麼權柄做這些事？是誰給你這權柄的？」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 15:2–3; 路加福音 22:68; 歌羅西書 4:6"> 耶穌回答他們，說：<span className="woj">「我也要問你們一個問題，你們告訴我：</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 馬太福音 11:7–19; 馬太福音 17:11–12"> <span className="woj">約翰的洗禮是來自天上，還是來自人間呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:34; 約翰福音 1:15–18; 約翰福音 1:30"> 他們就彼此商量，說：「如果我們說『是來自天上』，他就會問『你們為什麼不相信他呢？』</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:26; 馬太福音 11:9; 約翰福音 10:41"> 但如果說『是來自人間』，那麼民眾都會用石頭砸我們，因為他們深信約翰是先知。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 29:14; 彼得後書 3:3; 以賽亞書 41:28"> 於是他們回答：「不知道是從哪裡來的。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 馬太福音 21:27; 馬可福音 11:33"> 耶穌就對他們說：<span className="woj">「我也不告訴你們我憑什麼權柄做這些事。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 21:33–46; 馬可福音 12:1–12; 以賽亞書 5:1–7"> 接著，耶穌開始對民眾講這個比喻：<span className="woj">「有一個人栽種了一個葡萄園，把它租給一些農夫，然後就出外旅行，去了許久。</span></span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:15–16; 尼希米記 9:26; 馬太福音 21:34–36"> <span className="woj">到了收獲的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="收穫的——輔助詞語。">a</a></sup><span className="woj">季節，他就派了一個奴僕到那些農夫那裡去，好讓他們從葡萄園的果子中把當納的</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="當納的——輔助詞語。">b</a></sup><span className="woj">交給他。但那些農夫打了他，叫他空手回去。</span></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 10:1; 希伯來書 11:36–37; 帖撒羅尼迦前書 2:2"> <span className="woj">園主又派另一個奴僕去，可是他們把那個人也打了，並且侮辱他，叫他空手回去。</span></span>
<span className="v" id="v12" data-v="12"> <span className="woj">於是，他又派了第三個人去，他們又把這個人打傷，趕了出去。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 3:17; 約翰福音 3:16–17; 耶利米書 36:7"> <span className="woj">「葡萄園的主人就說：『我該做什麼呢？我要派遣我的愛子，或許他們</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「看見」。">c</a></sup><span className="woj">會尊重他。』</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="羅馬書 8:17; 希伯來書 1:2; 使徒行傳 2:23"> <span className="woj">「可是那些農夫看見他，就彼此討論說：『這是繼承人。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「來，」。">d</a></sup><span className="woj">我們把他殺了，那繼業就成為我們的了。』</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:12; 馬可福音 12:6–9; 馬太福音 21:37–40"> <span className="woj">於是他們把他扔出葡萄園外，殺了。</span><br /><span className="woj">「那麼，葡萄園的主人會怎麼對待他們呢？</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行傳 13:46; 馬太福音 21:41"> <span className="woj">他會來除滅這些農夫，把葡萄園交給別人。」</span><br />大家聽了就說：「絕不可有這樣的事！」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 118:22; 以賽亞書 28:16; 使徒行傳 4:11"> 耶穌注視著他們，說：<span className="woj">「那麼，經上記的『工匠所棄絕的石頭，它已經成了房角的頭塊石頭』這話是什麼意思呢？</span></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 8:14–15; 撒迦利亞書 12:3; 但以理書 2:44–45"> <span className="woj">所有跌落在那石頭上的，就將被破碎；那石頭落在誰的身上，就會把誰砸得稀爛。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 馬太福音 21:45–46"> 經文士和祭司長們知道這個比喻是針對他們而說的，當時就想下手捉拿耶穌，可是又怕民眾。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 馬太福音 22:15–22; 馬太福音 27:2"> 於是，他們密切注意，派了一些奸細裝做好人，要抓耶穌的話柄，好把他交在總督的管理和權柄之下。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦前書 2:4–5; 馬太福音 26:49–50; 馬太福音 22:16"> 那些奸細問耶穌，說：「老師，我們知道你所說所教導的都是對的，你也不顧人的情面，而是按真理教導神的道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="道——或譯作「路」。">e</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 9:37; 馬可福音 12:14–17; 使徒行傳 5:37"> 請問：我們向凱撒納稅，可以不可以呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 22:18; 哥林多前書 3:19; 路加福音 5:22"> 耶穌看出他們的詭詐，就對他們說：<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「你們為什麼試探我呢？」">f</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 18:28; 使徒行傳 11:28; 使徒行傳 26:32"> <span className="woj">「拿一個銀幣</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="銀幣——原文為「得拿利」。1得拿利=約1日工資的羅馬銀幣。">g</a></sup><span className="woj">給我看。這上面是誰的像和名號？」</span><br />他們說：「是凱撒的。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="羅馬書 13:6–7; 馬可福音 12:17; 彼得前書 2:13–17"> 耶穌對他們說：<span className="woj">「因此，凱撒的歸給凱撒；神的歸給神。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多書 1:10"> 他們在民眾面前抓不到耶穌的話柄，又對他的答覆感到驚奇，就啞口無言了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 4:1–2; 哥林多前書 15:12; 馬可福音 12:18–27"> 撒都該人來到耶穌那裡，他們一向說沒有復活的事。他們問耶穌，</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 25:5–10; 創世記 38:8; 創世記 38:11"> 說：「老師，摩西為我們寫道：如果一個人的兄弟死了，留下妻子而沒有孩子，他就應該娶這婦人，為他兄弟留後裔。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 20:20; 耶利米書 22:30"> 曾經有兄弟七人，第一個娶了妻子，沒有孩子就死了。</span>
<span className="v" id="v30" data-v="30"> 第二個、<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="第二個、——有古抄本作「第二個娶她為妻，也沒有孩子就死了；」。">h</a></sup></span>
<span className="v" id="v31" data-v="31"> 第三個也娶了她；七個人都是這樣，沒有留下兒女就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="傳道書 1:4; 傳道書 9:5; 希伯來書 9:27"> 後來這婦人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 22:24–28; 馬可福音 12:19–23"> 既然這七個人都娶過她為妻，那麼，在復活的時候，這婦人是誰的妻子呢？」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯來書 13:4"> 耶穌對他們說：<span className="woj">「這世代的兒女又娶又嫁；</span></span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 1:5; 約翰福音 5:29; 但以理書 12:2–3"> <span className="woj">但那些算是配得上承受那世代，又配得上從死人中復活的人，既不娶也不嫁。</span></span>
<span className="v" id="v36" data-v="36" data-xref="啟示錄 21:4; 腓立比書 3:21; 馬太福音 22:30"> <span className="woj">事實上，他們再也不會死，因為就與天使一樣；他們既然是復活的兒女，就是神的兒女了。</span></span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 3:2–6; 馬可福音 12:26–27; 使徒行傳 7:30–32"> <span className="woj">至於死人復活的事，摩西在『荊棘篇』上也指明了，正如稱主是『亞伯拉罕的神、以撒的神、雅各的神。』</span></span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:25–26; 歌羅西書 3:3–4; 羅馬書 6:10–11"> <span className="woj">所以神不是死人的神，而是活人的神；在神，人都是活著的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 23:9; 馬可福音 12:28–34; 馬太福音 22:34–40"> 有一些經文士應聲說：「老師，你說得好。」</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 22:46; 馬可福音 12:34; 箴言 26:5"> 從此他們再也不敢質問他什麼了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="馬可福音 12:35–37; 馬太福音 1:1; 馬太福音 22:41–45"> 耶穌對他們說：<span className="woj">「人怎麼說基督是大衛的後裔呢？</span></span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 110:1; 使徒行傳 2:34–35; 希伯來書 1:13"> <span className="woj">大衛自己在詩篇裡說：</span><br /><span className="pl pl-1 woj">『主對我主說：</span><br /><span className="pl pl-1 woj">你坐在我的右邊，</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 19:27; 詩篇 110:1; 啟示錄 19:14–21"> <span className="pl pl-1 woj">等我把你的敵人放在你的腳下做腳凳。』</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="啟示錄 22:16; 路加福音 1:31–35; 馬太福音 1:23"> <span className="woj">大衛既然稱基督為『主』，基督又怎麼會是大衛的後裔呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 15:10; 馬可福音 12:38–39; 馬可福音 8:34"> 全體民眾正在聽的時候，耶穌對他的門徒說：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 馬可福音 12:38–39; 路加福音 14:7"> <span className="woj">「你們要提防經文士。他們喜歡穿著長袍走來走去，喜愛街市上的致敬問候，又喜愛會堂裡的首位、宴席中的上座。</span></span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 12:40; 雅各書 3:1; 提多書 1:16"> <span className="woj">他們侵吞寡婦的家產，又假意做很長的禱告。這些人將受到更重的懲罰</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="懲罰——或譯作「審判」。">i</a></sup><span className="woj">。」</span></span>
</div>

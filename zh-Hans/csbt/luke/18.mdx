<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 4:2; 羅馬書 12:12; 帖撒羅尼迦前書 5:17"> 耶穌對他們講了一個比喻，說他們必須常常禱告，不要喪膽。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 詩篇 8:1–4; 路加福音 18:4"> 他說：<span className="woj">「某城裡有一個審判官，他既不敬畏神，也不尊重人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:17; 耶利米書 5:28; 申命記 27:19"> <span className="woj">那城裡有一個寡婦，經常到他那裡去，說：『請為我向我的對頭討個公道。』</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯來書 4:12–13; 路加福音 16:3; 路加福音 12:17"> <span className="woj">「法官一直不肯，但是後來心裡說：『即使我不敬畏神，也不尊重人，</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:8; 路加福音 18:39; 士師記 16:16"> <span className="woj">還是因為這寡婦不斷地煩擾我，我就為她討個公道，免得她一直來，到最後使我疲憊不堪！』」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 7:13"> 主接著說：<span className="woj">「你們當聽這個不公義的審判官所說的！</span></span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 10:35–37; 彼得後書 3:9; 路加福音 11:13"> <span className="woj">難道神絕不會給那些他所揀選、日夜向他呼求的人主持公道嗎？難道神會耽誤幫助</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="幫助——輔助詞語。">a</a></sup><span className="woj">他們嗎？</span></span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:23–26; 彼得後書 3:8–9; 馬太福音 24:9–13"> <span className="woj">我告訴你們：他會很快地給他們主持公道。不過人子回來的時候，難道在地上能找到這樣的信仰嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 16:15; 箴言 30:12; 以賽亞書 65:5"> 耶穌還對某些自以為義而藐視其他人的，講了這個比喻：</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 21:31–32; 列王紀上 8:30; 列王紀下 20:5"> <span className="woj">「有兩個人上聖殿去禱告。一個是法利賽人，另一個是稅吏。</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 6:5; 以賽亞書 65:5; 啟示錄 3:17"> <span className="woj">那法利賽人站著，向自己禱告這些話</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那法利賽人站著，向自己禱告這些話——或譯作「那法利賽人獨自站著，這樣禱告說」。">b</a></sup><span className="woj">：『神哪，我感謝你，因為我不像其他人那樣：勒索、不義、通姦，也不像這個稅吏。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 11:42; 馬太福音 23:23–24; 馬太福音 9:14"> <span className="woj">我一週禁食兩次，並奉獻我所有收入的十分之一。』</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 9:6; 約翰一書 1:8–10; 提摩太前書 1:15"> <span className="woj">「那稅吏卻遠遠地站著，甚至不敢舉目望天，可是捶著胸說：『神哪，你寬恕我這個罪人吧！』</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 14:11; 路加福音 16:15; 雅各書 4:10"> <span className="woj">我告訴你們：下去回家時已經被稱為義的是這個稅吏，而不是那個法利賽人。因為每一個自我高舉的都會被降卑；而自我降卑的都會被高舉。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="馬可福音 10:13–16; 馬太福音 19:13–15; 撒母耳記上 1:24"> 有些人把嬰孩也帶到耶穌那裡，好讓耶穌摸他們一下。門徒們看見了卻責備那些人。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 18:3–4; 哥林多前書 14:20; 哥林多前書 7:14"> 但耶穌把他們叫過來，說：<span className="woj">「讓小孩子到我這裡來，不要阻止他們，因為神的國正屬於這樣的人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 18:3; 馬可福音 10:15; 詩篇 131:1–2"> <span className="woj">我確實地告訴你們：無論誰不像小孩子一樣接受神的國，就絕不能進去。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 10:17–31; 使徒行傳 16:30; 馬太福音 19:16–30"> 有一個首領問耶穌，說：「良善的老師，我該做什麼才會繼承永恆的生命呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="約伯記 15:14–16; 雅各書 1:17; 希伯來書 7:26"> 耶穌對他說：<span className="woj">「你為什麼稱我是良善的呢？除了神一位之外，沒有一個是良善的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:12–17; 申命記 5:16–21; 羅馬書 13:9"> <span className="woj">你是知道這些誡命的：</span><br /><span className="pl pl-1 woj">『不可通姦、</span><br /><span className="pl pl-1 woj">不可殺人、</span><br /><span className="pl pl-1 woj">不可偷竊、</span><br /><span className="pl pl-1 woj">不可做偽證、</span><br /><span className="pl pl-1 woj">要孝敬父母。』</span><br /><span className="pl pl-1 woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="腓立比書 3:6; 羅馬書 10:2–3; 馬可福音 10:20–21"> 那個人說：「這一切我從年少就遵守了。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 12:33; 提摩太前書 6:18–19; 馬太福音 19:21"> 耶穌聽了就對他說：<span className="woj">「你還缺少一件：把你所擁有的一切都賣掉，分給窮人，這樣你將有財寶在天上；然後你來跟從我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:31; 約翰一書 2:15; 約伯記 31:24–25"> 那個人聽了這些話就變得很憂愁，因為他極其富有。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; 雅各書 2:5–7; 馬可福音 10:23–27"> 耶穌看見他變得很憂愁<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「變得很憂愁」。">c</a></sup>，就說：<span className="woj">「有錢財的人進入神的國，是多麼困難！</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 23:24"> <span className="woj">駱駝穿過針眼，比富有的人進入神的國更容易呢！」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 13:23"> 聽見的人就說：「那麼，誰能得救呢？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 32:17; 馬太福音 19:26; 路加福音 1:37"> 耶穌說：<span className="woj">「在人不可能的事，在神都是可能的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬可福音 10:28; 腓立比書 3:7; 馬太福音 19:27"> 彼得說：「看，我們捨棄自己所擁有的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="自己所擁有的——有古抄本作「一切」。">d</a></sup>，跟從了你！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬可福音 10:29–31; 馬太福音 10:37–39; 路加福音 14:26–28"> 耶穌對他們說：<span className="woj">「我確實地告訴你們：沒有誰為神國的緣故捨棄房屋，或妻子，或兄弟，或父母，或兒女，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 13:5–6; 約伯記 42:10; 啟示錄 2:17"> <span className="woj">而不會在今世得到許多倍，在來世得到永恆生命的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 20:17–19; 以賽亞書 53:1–12; 詩篇 22:1–31"> 耶穌把十二使徒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="使徒——輔助詞語。">e</a></sup>帶到一邊，對他們說：<span className="woj">「看，我們現在上耶路撒冷去，那藉著先知們所寫的一切有關人子的事，都要成就。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 23:11; 以賽亞書 50:6; 以賽亞書 53:3"> <span className="woj">要知道，他將被交給外邦人，被戲弄、受凌辱、被人吐唾沫；</span></span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 15:3–4; 路加福音 24:7; 馬太福音 27:63"> <span className="woj">他們要鞭打他，並殺害他；然後在第三天，他要復活。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 9:45; 馬可福音 9:32; 路加福音 24:25"> 但門徒們一點也不領悟這些話。這話對他們是隱藏的，他們不知道他在說什麼。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:29–34; 馬可福音 10:46–52; 路加福音 16:20–21"> 耶穌快到耶利哥的時候，有一個瞎眼的坐在路邊乞討。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 21:10–11; 路加福音 15:26"> 他聽見人群經過那裡，就問到底是什麼事。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 2:23; 約翰福音 19:19; 約翰福音 12:35–36"> 有人告訴他：「拿撒勒人耶穌經過這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬太福音 9:27; 路加福音 18:39; 馬太福音 15:22"> 他就呼喊說：「耶穌啊，大衛的後裔<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="大衛的後裔——或譯作「大衛之子」。">f</a></sup>，可憐我吧！」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 32:26–28; 詩篇 141:1; 路加福音 18:15"> 走在前頭的人就責備他，要他安靜。可是，他卻更加大聲呼叫：「大衛的後裔<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大衛的後裔——或譯作「大衛之子」。">g</a></sup>，可憐我吧！」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 20:31–34; 馬可福音 10:48–52"> 耶穌就停住，吩咐把他帶到他面前來；那人走近了，耶穌就問他：</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 3:5–15; 馬太福音 20:21–22; 腓立比書 4:6"> <span className="woj">「你要我為你做什麼呢？」</span><br />他說：「主啊，我要重見光明！」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬太福音 8:3; 路加福音 8:48; 路加福音 17:19"> 耶穌對他說：<span className="woj">「你重見光明吧！你的信救了你。」</span></span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 146:8; 帖撒羅尼迦後書 1:10–12; 以賽亞書 43:21"> 他立刻重見光明，於是跟隨耶穌，一路上榮耀神。民眾都看到了，就讚美神。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 8:5–13; 路加福音 7:1–10; 馬太福音 7:28–29"> 當耶穌向民眾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="向民眾——原文直譯「向民眾耳中」。">a</a></sup>說完了這一切話<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="這一切話——原文直譯「他所有的話」。">b</a></sup>，就進了迦百農。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:2–3; 創世記 24:27; 約翰福音 4:46–47"> 有個百夫長所重視的奴僕病得快要死了。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 8:5; 約翰福音 4:47; 路加福音 9:38"> 百夫長聽說了耶穌的事，就託幾個猶太人的長老到耶穌那裡，求耶穌來救他的奴僕。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:4; 馬太福音 10:11; 路加福音 7:6–7"> 他們來到耶穌那裡，殷切地求他說：「這人配得你的幫助，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 2:11–12; 歷代志上 29:3–9; 列王紀上 5:1"> 因為他愛我們的同胞，還為我們建了會堂。」</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 5:24; 創世記 32:10; 雅各書 4:6"> 於是耶穌與他們一起去了。當耶穌離他家不遠的時候，百夫長又託了幾個朋友來對耶穌說：「主啊，不用麻煩了，我實在不配請你進我家，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 107:20; 詩篇 33:9; 路加福音 4:36"> 我自己也覺得不配到你那裡去。只要你說一句話，我的僕人就會痊癒的。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:22; 使徒行傳 23:17; 使徒行傳 22:25–26"> 事實上，我也被放在人的權下，也有士兵在我之下。我對這個說『去』，他就去；對那個說『來』，他就來；對我的奴僕說『做這事』，他就去做。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 15:28; 羅馬書 3:1–3; 馬太福音 8:10"> 耶穌聽了這些話，十分感慨，轉過身來對跟隨他的那群人說：<span className="woj">「我告訴你們：在以色列我沒有見過這麼大的信心</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信心——指「對耶穌的信心」。">c</a></sup><span className="woj">。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:50–53; 馬太福音 8:13; 馬太福音 15:28"> 那些受託的人回到家裡時，發現那<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「患病的」。">d</a></sup>奴僕已經痊癒了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 10:38"> 第二天，耶穌往一個叫做拿因的城去，他的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「許多」。">e</a></sup>門徒們和一大群人也與他同行。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王紀上 17:9"> 當他接近城門口的時候，看哪，有一個死人被抬出來了。這人是獨生兒子，他的母親又是寡婦。一大群城裡的人陪著她。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:13; 以賽亞書 63:9; 詩篇 86:15"> 主看見那寡婦，就對她動了憐憫之心，向她說：<span className="woj">「不要哭了！」</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 5:25; 約翰福音 11:43–44; 使徒行傳 9:40–41"> 於是耶穌上前去，按著棺架，抬棺架的人就停住了。耶穌說：<span className="woj">「年輕人，我吩咐你起來！」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; 列王紀下 4:32–37; 列王紀上 17:23–24"> 那死人就坐了起來，開始說話。耶穌把他交給他的母親。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 每個人敬畏不已，就不住地榮耀神，說：「我們中間興起了一位偉大的先知！」又說：「神臨到<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="臨到——或譯作「照顧」。">f</a></sup>他的子民了！」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 4:24; 馬可福音 6:14; 馬太福音 9:26"> 於是有關耶穌的這消息傳遍了整個猶太和周圍所有的地區。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:26; 馬太福音 11:2–19"> 約翰的門徒們把這一切事都告訴了約翰。他就叫來他的兩個門徒，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 9:6–7; 約翰福音 4:25; 創世記 22:18"> 派他們到主<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="主——有古抄本作「耶穌」。">g</a></sup>那裡去問：「將要來的那一位就是你嗎？還是我們應該等候另一位呢？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 那兩個人來到耶穌那裡，說：「施洗者<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗者——或譯作「施浸者」。">h</a></sup>約翰派我們來問你：『將要來的那一位就是你嗎？還是我們應該等候另一位呢？』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 3:10; 詩篇 90:7–9; 希伯來書 12:6"> 就在那<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="那——有古抄本作「同一個」。">i</a></sup>時候，耶穌治癒了許多有疾病的、有苦痛的、被邪靈附著的人，又施恩給許多瞎眼的使他們能看見。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 35:5–6; 以賽亞書 61:1–3; 路加福音 4:18"> 於是耶穌<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶穌——有古抄本作「他」。">j</a></sup>回答那兩個人，說：<span className="woj">「你們去把所看見、所聽見的告訴約翰，就是：瞎眼的得以看見，瘸腿的行走，痲瘋病人被潔淨，耳聾的聽見，死人得以復活，窮人得以聽到福音。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 11:6; 彼得前書 2:7–8; 羅馬書 9:32–33"> <span className="woj">凡不因我被絆倒</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="被絆倒——或譯作「放棄信仰」。">k</a></sup><span className="woj">的人，就蒙福了。」</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 4:14; 約翰福音 1:23; 路加福音 1:80"> 約翰的使者離開了，耶穌就開始對眾人談起約翰，說：<span className="woj">「你們曾經到曠野去，是要觀看什麼呢？一根被風吹動的蘆葦嗎？</span></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 59:17; 以斯帖記 8:15; 以斯帖記 1:3"> <span className="woj">你們出去，究竟是要看什麼呢？一個身穿細軟衣服的人嗎？看哪，那些穿華麗衣服、生活放蕩的人在王宮裡。</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 約翰福音 5:35; 路加福音 20:6"> <span className="woj">你們出去，究竟是要看什麼呢？一位先知嗎？是的，我告訴你們：他比先知還大。</span></span>
<span className="v" id="v27" data-v="27" data-xref="瑪拉基書 3:1; 路加福音 1:76; 馬可福音 1:2"> <span className="woj">他就是經上記載的那個人：</span><br /><span className="pl pl-1 woj">『看哪，我要差派我的使者在你前頭，</span><br /><span className="pl pl-1 woj">他要在你之前預備你的道</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="道——或譯作「路」。">l</a></sup><br /><span className="pl pl-1 woj">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 13:16–17; 馬太福音 11:11; 歌羅西書 1:25–27"> <span className="woj">「我告訴你們：在女人所生的人中，沒有一個</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附「先知」。">m</a></sup><span className="woj">比約翰</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="約翰——有古抄本作「施洗者約翰」。">n</a></sup><span className="woj">更大的；然而在神的國裡，再小的也比約翰更大。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行傳 18:25"> 所有已經受過約翰洗禮的民眾和稅吏，聽了這話，都承認神是義的；</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多後書 6:1; 馬太福音 22:35"> 而沒有受過他洗禮的法利賽人和律法師們，就棄絕了神對他們的計劃。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 11:16–19; 耶利米哀歌 2:13; 馬可福音 4:30"> 主又說：<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本沒有「主又說：」。">o</a></sup><span className="woj">「我要把這世代的人比做什麼呢？他們好比什麼呢？</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 11:16–19; 耶利米書 5:3–5; 箴言 17:16"> <span className="woj">他們就好比：孩子們坐在街市上，彼此呼叫，說：</span><br /><span className="pl pl-1 woj">『我們為你們吹笛，</span><br /><span className="pl pl-1 woj">你們卻不跳舞；</span><br /><span className="pl pl-1 woj">我們唱哀歌，</span><br /><span className="pl pl-1 woj">你們也不哭泣。』</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 馬可福音 1:6; 約翰福音 8:52"> <span className="woj">「因為施洗者</span><sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="施洗者——或譯作「施浸者」。">p</a></sup><span className="woj">約翰來了，不吃餅，也不喝酒，你們就說：『他有鬼魔附身！』</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 約翰福音 12:2"> <span className="woj">人子來了，也吃也喝，你們就說：『看，這個貪食好酒的人！稅吏和罪人的朋友！』</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 馬太福音 11:19; 何西阿書 14:9"> <span className="woj">然而，智慧是憑著智慧的眾兒女被證明為義的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 14:3–9; 馬太福音 26:5–6; 路加福音 14:1"> 有一個法利賽人請耶穌與他一起吃飯，耶穌就進到那法利賽人的家裡坐席。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 14:3–9; 馬太福音 26:6–13; 馬太福音 21:31"> 當時，城裡有一個女人，是個罪人，她知道耶穌在那法利賽人家裡坐席，就拿著一個盛了香液的玉瓶來。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 126:5–6; 詩篇 51:17; 創世記 18:4"> 她站在耶穌後面，在他的腳邊哭泣，開始用淚水沾濕耶穌的腳，再用自己的頭髮擦乾，又親吻他的腳，用香液膏抹。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 馬可福音 7:21"> 那邀請耶穌的法利賽人看見了，心裡說：「這個人如果是先知，就會知道摸他的是誰，是個什麼樣的女人，因為她是個罪人。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 16:19; 路加福音 5:31; 以西結書 33:31"> 耶穌對他說：<span className="woj">「西門，我有話要對你說。」</span><br />西門說：「老師，請說。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 羅馬書 5:20; 馬太福音 18:28"> <span className="woj">「有一個債主有兩個欠債人。一個欠五百個銀幣</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="五百個銀幣——原文為「500得拿利」。1得拿利=約1日工資的羅馬銀幣。">q</a></sup><span className="woj">，另一個欠五十個銀幣。</span></span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 9:18–19; 歌羅西書 3:13; 羅馬書 3:24"> <span className="woj">他們無力償還，債主就免了他們兩個人的債。那麼，你說</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="有古抄本沒有「你說」。">r</a></sup><span className="woj">他們哪一個會更愛那債主呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="詩篇 116:16–18; 提摩太前書 1:13–16; 路加福音 7:47"> 西門回答說：「我想是債主免債更多的那一個。」<br />耶穌說：<span className="woj">「你判斷得對。」</span></span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前書 5:10; 士師記 19:21; 創世記 18:4"> 於是，他轉向那女人，對西門說：<span className="woj">「你看見這個女人嗎？我進了你的家，你沒有給我水洗腳，但她卻用淚水沾濕我的腳，又用她的頭髮擦乾。</span></span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳記下 15:5; 撒母耳記下 19:39; 羅馬書 16:16"> <span className="woj">你沒有向我行親吻禮，而她從我進來的時候起，就不停地親我的腳。</span></span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 23:5; 傳道書 9:8; 馬太福音 6:17"> <span className="woj">你沒有用油來膏抹我的頭，她卻用香液膏抹我的腳。</span></span>
<span className="v" id="v47" data-v="47" data-xref="約翰一書 4:19; 約翰一書 3:18; 以賽亞書 1:18"> <span className="woj">故此，我告訴你：她的罪孽被赦免得多，所以</span><sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="所以——或譯作「因為」。">s</a></sup><span className="woj">她愛得多；而那被赦免少的，就愛得少。」</span></span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 9:2; 馬可福音 2:5; 路加福音 5:20"> 接著，耶穌對那女人說：<span className="woj">「你的罪孽已經被赦免了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 馬太福音 9:3; 馬可福音 2:7"> 那些與他一同坐席的人就心裡想：「這個人是誰，竟然赦免罪？」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 但耶穌對那女人說：<span className="woj">「你的信救了你，平平安安地去吧。」</span></span>
</div>

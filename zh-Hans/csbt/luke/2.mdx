<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 馬太福音 24:14; 使徒行傳 25:21"> 就在那些日子裡，凱撒奧古斯都頒布諭令，要普天下的人都登記戶口<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="戶口——輔助詞語。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 馬太福音 4:24; 使徒行傳 26:30"> 這是頭一次戶口登記，在居里尼烏斯任敘利亞總督的時候進行的。</span>
<span className="v" id="v3" data-v="3"> 於是眾人都各回自己的城鎮去登記。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彌迦書 5:2; 約翰福音 7:42; 撒母耳記上 16:1"> 約瑟也從加利利的拿撒勒城上猶太去，到了那叫做伯利恆的大衛之城，因為他是大衛一家一族的人。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22–27; 馬太福音 1:18–19"> 他和已經許配給他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「做妻子」。">b</a></sup>、懷有身孕的瑪麗亞一起去登記。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 33:11; 啟示錄 12:1–5; 彌迦書 5:2"> 他們在伯利恆的時候，瑪麗亞的產期到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 4:4; 哥林多後書 8:9; 以賽亞書 53:2–3"> 就生了她的頭胎兒子。她用布把他包起來放在馬槽裡，因為客店裡沒有地方給他們。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 31:39–40; 詩篇 78:70–71; 撒母耳記上 17:34–35"> 當時在同一個地區，有些牧人露宿在野地裡，夜間守更看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:1; 哥林多後書 3:18; 列王紀上 8:11"> 這時候，主的一位天使站在他們旁邊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="站在他們旁邊——或譯作「向他們顯現」。">c</a></sup>，主的榮光四面照射他們，他們就大為驚恐。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:9; 以賽亞書 61:1; 以賽亞書 52:7"> 那位天使對他們說：「不要怕！因為看哪，我傳給你們一個大喜的信息，是要給萬民的。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 9:6; 馬太福音 1:21; 使徒行傳 2:36"> 今天，在大衛的城裡，為你們誕生了一位救主，他就是主基督。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 7:14; 以賽亞書 53:1–2; 以賽亞書 7:11"> 你們會看見一個嬰孩，用布包著，躺在馬槽裡；這就是給你們的標記。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:20–21; 啟示錄 5:11; 詩篇 148:2"> 忽然有一大隊天軍出現，與那位天使一起讚美神，說：</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 5:1; 路加福音 19:38; 歌羅西書 1:20"> <span className="pl pl-1">「在至高之處，榮耀歸於神！</span><br /><span className="pl pl-1">在地上，平安</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="平安——或譯作「和平」。">d</a></sup><br /><span className="pl pl-1">臨到他所喜悅的人！」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="彼得前書 3:22; 馬太福音 2:1–2; 馬太福音 2:9–11"> 天使們離開他們往天上去了，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「而那些人——」。">e</a></sup>牧人就彼此說：「來，我們到伯利恆去，看看這件已成就的事，就是主讓我們明白的事！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 於是他們急忙趕去，找到了瑪麗亞、約瑟和那躺在馬槽裡的嬰孩。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 66:16; 路加福音 8:39; 詩篇 71:17–18"> 他們看見以後，就把天使告訴他們有關這孩子的話傳開了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 所有聽見的人，對那些牧人告訴他們的事，都感到驚奇。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 瑪麗亞卻把這一切事存在心裡，反覆思想。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:48; 以賽亞書 29:19; 使徒行傳 11:18"> 那些牧人因為所見所聞的一切正如天使向他們所說的，就榮耀、讚美神，於是回去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 創世記 17:12; 加拉太書 4:4–5"> 滿了八天，為孩子行割禮的時候，他們就給他起名叫耶穌。這名字是他在母<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="母——輔助詞語。">f</a></sup>腹成胎以前天使所起的。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 12:1–8"> 按照摩西的律法，潔淨的日子滿了以後，約瑟和瑪麗亞領著孩子上耶路撒冷去，要把他獻給主。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 13:2; 出埃及記 22:29; 民數記 3:13"> 正如主的律法上所記載的：「所有頭胎的男孩都將被稱為聖歸給主；」</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 12:6–8; 利未記 12:2; 哥林多後書 8:9"> 並按照主的律法上所說的，獻上了「一對斑鳩或兩隻雛鴿」為祭物。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 25:9; 路加福音 2:38; 路加福音 1:6"> 看哪，在耶路撒冷有一個名叫西緬的人。這個人又公義又虔誠，一直期待著以色列得蒙安慰；聖靈也在他身上。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:51; 希伯來書 11:5; 路加福音 9:27"> 他得了聖靈的啟示：自己在經歷死亡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="經歷死亡——原文直譯「見到死亡」。">g</a></sup>以前會看見主的基督。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 他受了聖靈的感動，來到聖殿。這時候，耶穌的父母抱著孩子進來，要按照律法的規矩為他辦事。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 西緬把孩子抱在懷裡，頌讚神說：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 14:13; 創世記 15:15; 腓立比書 1:23"> <span className="pl pl-1">「主啊，</span><br /><span className="pl pl-1">現在可以照你的話，</span><br /><span className="pl pl-1">讓你的奴僕平平安安地離去，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因為我的眼睛已經看見你的救恩，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 62:1–2; 以賽亞書 42:1–4; 詩篇 98:2–3"> <span className="pl pl-1">就是你為萬民</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="為萬民——原文直譯「在萬民面前」。">h</a></sup><br /><span className="pl pl-1">所預備的：</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 60:1–3; 以賽亞書 49:6; 使徒行傳 26:23"> <span className="pl pl-1">他是啟示外邦人的光，</span><br /><span className="pl pl-1">是你子民以色列的榮耀。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以賽亞書 8:18; 路加福音 2:48"> 他的父母<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="他的父母——有古抄本作「約瑟和孩子的母親」。">i</a></sup>對這些關於孩子的話，感到驚奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 1:23; 彼得前書 2:7–8; 以賽亞書 8:14–15"> 西緬祝福他們，並對孩子的母親瑪麗亞說：「看哪，這孩子註定要使以色列中許多人跌倒、許多人興起，並要成為一個遭受反對的標記<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="遭受反對的標記——或譯作「被攻擊的對象」。">j</a></sup>，</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 8:2; 哥林多前書 11:19; 馬太福音 12:24–35"> 這樣，許多人的心思意念將被顯露出來；你自己的靈魂也要被劍刺透。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及記 15:20; 創世記 30:13; 使徒行傳 21:9"> 有一個女先知安娜，是亞設支派法努埃的女兒。她已經上了年紀，是出嫁以後與丈夫生活了七年的，</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太前書 5:5; 詩篇 23:6; 使徒行傳 14:23"> 後來守寡了，現在已經<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="現在已經——有古抄本作「約」。">k</a></sup>八十四歲。她從不離開聖殿，禁食祈禱，日夜事奉神。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多後書 9:15; 馬可福音 15:43"> 就在這時候，她也上前來讚頌神<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="神——有古抄本作「主」。">l</a></sup>，向所有期待著耶路撒冷得救贖的人<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="期待著耶路撒冷得救贖的人——有古抄本作「在耶路撒冷期待救贖的人們」。">m</a></sup>講說這孩子的事。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太書 4:4–5; 申命記 12:32"> 約瑟和瑪麗亞按照主的律法辦完了一切事以後，就返回加利利，到自己的城拿撒勒去了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以賽亞書 11:1–5"> 那孩子漸漸長大，堅強<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="堅強——有古抄本作「靈裡堅強」。">n</a></sup>而充滿智慧，並且有神的恩典在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及記 12:14; 民數記 28:16; 申命記 12:18"> 每年逾越節，耶穌的父母都上耶路撒冷去。</span>
<span className="v" id="v42" data-v="42"> 當耶穌十二歲的時候，他們按照節日的規矩上去<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="上去——有古抄本作「上耶路撒冷去」。">o</a></sup>。</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志下 30:21–23; 出埃及記 12:15; 歷代志下 25:17"> 守完了節期，他們回去的時候，孩童耶穌仍然留在耶路撒冷，他的父母<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="他的父母——有古抄本作「約瑟和孩子的母親」。">p</a></sup>卻不知道，</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 122:1–4; 以賽亞書 2:3; 詩篇 42:4"> 以為他在同行的人群中。他們走了一天的路，才開始在親戚和熟人中找他。</span>
<span className="v" id="v45" data-v="45"> 他們找不到他，就回到耶路撒冷去找。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以賽亞書 49:1–2; 以賽亞書 50:4"> 到了第三天，他們發現耶穌在聖殿裡，坐在教師們當中，一邊聽，一邊問。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 7:28; 路加福音 4:32; 詩篇 119:99"> 所有聽他講說的人，都對他的悟性和對答十分驚訝。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 馬太福音 12:46; 路加福音 3:23"> 他的父母看見他，感到吃驚，他的母親就對他說：「孩子啊，為什麼對我們這樣做呢？你看，你父親和我一直在焦急地找你呢！」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="約翰福音 6:38; 約翰福音 8:29; 瑪拉基書 3:1"> 耶穌對他們說：<span className="woj">「你們為什麼找我呢？難道不知道我必須在我父的家裡</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="在我父的家裡——或譯作「從事於我父的事」。">q</a></sup><span className="woj">嗎？」</span></span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 馬可福音 9:32"> 可是他們沒有領悟他對他們說的話。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理書 7:28; 創世記 37:11"> 於是耶穌與他們一起下去，回到拿撒勒，一直服從他們。他的母親把這一切事都珍藏在心裡。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳記上 2:26"> 耶穌的智慧和身量，以及神和人對他的喜愛<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="神和人對他的喜愛——或譯作「在神和人面前的喜愛」。">r</a></sup>，都不斷增長。</span>
</div>
</div>

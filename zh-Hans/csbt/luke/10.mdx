<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 6:7–13; 路加福音 9:52; 民數記 11:24–26"> 這些事以後，主另外指定了七十<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十——有古抄本作「七十二」。">a</a></sup>個人，差派他們兩個兩個地在他前頭，到他要去的各城各地去。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:36–38; 約翰福音 4:35–38; 哥林多前書 3:6–9"> 耶穌對他們說：<span className="woj">「收割的工作</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="收割的工作——或譯作「莊稼」。">b</a></sup><span className="woj">多，而工人少。所以你們要祈求收割</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="收割——或譯作「莊稼」。">c</a></sup><span className="woj">的主催促工人參與他的收割工作</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="參與他的收割工作——或譯作「收他的莊稼」。">d</a></sup><span className="woj">。</span></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 10:16; 使徒行傳 20:29; 以西結書 2:3–6"> <span className="woj">你們去吧！看哪，我差派你們出去，就像把羊羔送進狼群中。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:35; 列王紀下 4:29; 路加福音 10:4–12"> <span className="woj">你們不要帶錢包，不要帶行囊，不要帶鞋子，在路上也不要問候任何人。</span></span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 25:6; 馬太福音 10:12–13; 以賽亞書 57:19"> <span className="woj">你們無論進哪一家，首先要說『願這一家平安。』</span></span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:16; 哥林多後書 2:15–16; 以弗所書 5:6"> <span className="woj">如果那裡有平安之子，你們的平安就會臨到他；否則，那平安就歸回你們。</span></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 5:17–18; 馬太福音 10:10–11; 加拉太書 6:6"> <span className="woj">你們當住在那一家，吃喝他們所供給的，因為工人配得自己的酬報。不要從這家搬到那家。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:27; 馬太福音 10:40; 路加福音 10:10"> <span className="woj">無論進哪一個城，如果人們接受你們，給你們擺上什麼，你們就吃什麼。</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 3:2; 約翰福音 3:5; 路加福音 10:11"> <span className="woj">你們要使那城裡的病人痊癒，並且要對他們說『神的國臨近你們了。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 18:6; 馬太福音 10:14; 使徒行傳 13:51"> <span className="woj">無論進哪一個城，如果人們不接受你們，你們就到大街</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="大街——或譯作「廣場」。">e</a></sup><span className="woj">上去，說</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:9; 使徒行傳 13:51; 使徒行傳 13:26"> <span className="woj">『連那沾在我們腳上</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本沒有「腳上」。">f</a></sup><span className="woj">的你們城裡的塵土，我們也要當著你們擦掉，不過你們應當知道：神的國近了</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="近了——有古抄本作「臨近你們了」。">g</a></sup><span className="woj">。』</span></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 10:15; 馬太福音 11:24; 耶利米哀歌 4:6"> <span className="woj">我告訴你們：在那日，所多瑪所受的，將要比那城還容易受呢！</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 23:1–18; 約珥書 3:4–8; 以西結書 26:1–26"> <span className="woj">「哥拉汛哪，你有禍了！伯賽達呀，你有禍了！因為在你們當中行過的神蹟，如果行在提爾和西頓，那裡的人早就會披麻蒙灰，坐在地上悔改了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 15:22–25; 羅馬書 2:1; 路加福音 12:47–48"> <span className="woj">不過在審判的時候，提爾和西頓所受的，將要比你們還容易受呢！</span></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 14:13–15; 馬太福音 4:13; 路加福音 13:28"> <span className="woj">而你——迦百農啊，你將被高舉到天上嗎？不，你將下到陰間。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 13:20; 馬太福音 10:40; 帖撒羅尼迦前書 4:8"> <span className="woj">「聽從你們的，就是聽從我；拒絕你們的，就是拒絕我；拒絕我的，就是拒絕差派我來的那一位。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:20; 馬可福音 16:17; 路加福音 9:1"> 那七十<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="七十——有古抄本作「七十二」。">h</a></sup>個人懷著喜樂的心回來，說：「主啊，奉你的名，連鬼魔也服從了我們。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="啟示錄 12:7–9; 以賽亞書 14:12; 啟示錄 9:1"> 耶穌對他們說：<span className="woj">「我看見撒旦像閃電一樣從天上墜落。</span></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:13; 馬可福音 16:18; 羅馬書 16:20"> <span className="woj">看，我已經給了你們權柄去踐踏蛇和蠍子，又勝過仇敵一切的勢力，絕不會有什麼能傷害你們了。</span></span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 20:15; 啟示錄 20:12; 希伯來書 12:23"> <span className="woj">但不要因為邪靈服從了你們就歡喜，要因為你們的名字已經被記錄在天上而歡喜。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 4:3; 馬太福音 13:11–16; 馬太福音 11:25–27"> 那時候，耶穌<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="耶穌——有古抄本作「他」。">i</a></sup>受了聖靈的感動就快樂，說：<span className="woj">「父啊，天地的主，我讚美</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="讚美——或譯作「感謝」。">j</a></sup><span className="woj">你，因為你把這些事向有智慧的和有學問的人隱藏起來，而向小孩子們顯明出來。是的，父啊！因為這正是你的美意。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:27; 約翰福音 1:18; 約翰福音 6:44–46"> <span className="woj">「我父把一切都交給了我。除了父，沒有人知道子是誰；除了子和子所願意啟示的人，也沒有人知道父是誰。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:16–17"> 耶穌轉過身來，悄悄地對門徒們說：<span className="woj">「看見你們所看見的，那眼睛是蒙福的！</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 8:56; 希伯來書 11:13; 彼得前書 1:10–12"> <span className="woj">我告訴你們：曾經有許多先知和君王想要看你們所看見的，卻沒有看到；想要聽你們所聽見的，卻沒有聽到。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 22:34–39; 路加福音 18:18; 馬太福音 19:16–19"> 這時候，忽然有一個律法師站起來試探耶穌，說：「老師，我該做什麼才會繼承永恆的生命呢？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="羅馬書 10:5; 以賽亞書 8:20; 加拉太書 3:21–22"> 耶穌對他說：<span className="woj">「律法上是怎麼寫的？你是怎麼讀的呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬可福音 12:30–31; 馬太福音 22:37–40; 申命記 6:5"> 他回答說：<br />「你要以全心、全靈、全力、全意愛主——你的神，並且要愛鄰如己。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西結書 20:11; 利未記 18:5; 馬太福音 19:17"> 耶穌說：<span className="woj">「你回答得對。你這樣去做，就將活著。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 16:15; 羅馬書 4:2; 利未記 19:34"> 那個人卻要顯示自己為義，就對耶穌說：「那麼，誰是我的鄰人呢？」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 88:4; 路加福音 18:31; 耶利米哀歌 2:12"> 耶穌回答說：<span className="woj">「有一個人從耶路撒冷下到耶利哥去，途中</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="途中——輔助詞語。">k</a></sup><span className="woj">遇到強盜。他們剝去他的衣服，把他打得半死，丟下他走了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 3:16–18; 詩篇 69:20; 耶利米書 5:31"> <span className="woj">恰好有一個祭司從那條路下來，看見他，就從另一邊走了過去。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行傳 18:17; 詩篇 109:25"> <span className="woj">有一個利未人也正好來到那地方，看見他，也同樣地從另一邊走了過去。</span></span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 8:50; 耶利米書 38:7–13; 路加福音 7:13"> <span className="woj">可是，有一個撒瑪利亞人行路來到他那裡，看見他，就動了憐憫之心，</span></span>
<span className="v" id="v34" data-v="34" data-xref="羅馬書 12:20; 詩篇 147:3; 帖撒羅尼迦前書 5:15"> <span className="woj">上前來，在他的傷處倒上油和酒，包紮好，然後把他扶上自己的牲口，帶到旅店裡照顧他。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; 路加福音 14:13; 羅馬書 16:23"> <span className="woj">第二天</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附「離開的時候」。">l</a></sup><span className="woj">，他拿出兩個銀幣</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="兩個銀幣——原文為「2得拿利」。1得拿利=約1日工資的羅馬銀幣。">m</a></sup><span className="woj">交給店家，說『請你照顧他，一切額外的費用，我回來的時候將還給你。』</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="路加福音 7:42; 馬太福音 21:28–31; 馬太福音 17:25"> <span className="woj">「你認為，這三個人中，哪一個是落在強盜手中那人的鄰人呢？」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰一書 3:16–18; 彌迦書 6:8; 彼得前書 2:21"> 律法師說：「是那個憐憫他的人。」<br />耶穌對他說：<span className="woj">「你去如此做吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:19–20; 約翰福音 11:1–5; 約翰福音 12:1–3"> 他們繼續前行，耶穌進了一個村子，有一個名叫瑪妲的女人接待他<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="接待他——有古抄本作「接他到自己家裡」。">n</a></sup>。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; 路加福音 8:35; 約翰福音 12:3"> 瑪妲有個妹妹<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="妹妹——原文直譯「姐妹」。">o</a></sup>，稱為瑪麗亞，坐在主<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="主——有古抄本作「耶穌」。">p</a></sup>的腳前聽他的話語。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 6:27; 路加福音 12:29; 馬太福音 14:15"> 瑪妲為了很多伺候的事就心裡煩亂，上前來說：「主啊，我妹妹丟下我一個人伺候，你不管嗎？請叫她來幫我的忙吧。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="腓立比書 4:6; 路加福音 21:34; 馬太福音 6:25–34"> 主<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="主——有古抄本作「耶穌」。">q</a></sup>回答她，說：<span className="woj">「瑪妲，瑪妲，你為很多事憂慮、煩惱，</span></span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 27:4; 詩篇 16:5–6; 約翰福音 10:27–28"> <span className="woj">但是有一件事是需要的，而瑪麗亞選擇了那美好的一份，是不能從她那裡被拿去的。」</span></span>
</div>

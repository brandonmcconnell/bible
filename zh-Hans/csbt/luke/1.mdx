<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 1:1–3; 彼得後書 1:16–19; 約翰福音 20:31"> 提阿費羅大人哪，既然有許多人著手編錄關於在我們中間所成就的事，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 15:27; 使徒行傳 26:16; 希伯來書 2:3"> 就是照著從起初以來的目擊者和做福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直譯「話語」或「道」。">a</a></sup>僕人的那些人所傳給我們的，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 1:1; 使徒行傳 26:25; 使徒行傳 11:4"> 我也已經從頭仔細地追蹤了這一切，我就認為應該按著次序寫給您，</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 20:31; 使徒行傳 18:25; 哥林多前書 14:19"> 好讓您了解到您所領受的話語都是確實的。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 24:10; 馬太福音 2:1; 尼希米記 12:4"> 在猶太王希律的那些日子裡，有一個祭司名叫撒迦利亞，屬於亞比雅班組。他的妻子也是亞倫的子孫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="子孫——原文直譯「女兒」。">b</a></sup>，名叫伊莉莎白。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 7:1; 創世記 17:1; 腓立比書 2:15"> 他們兩個人在神面前都是義人，遵行主的一切誡命和公義規定，無可指責。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:11; 創世記 18:11; 撒母耳記上 1:2"> 可是他們沒有孩子，因為伊莉莎白不能生育，兩個人又都上了年紀。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:14; 歷代志上 24:19; 歷代志下 31:2"> 有一次，當撒迦利亞的班組輪值的時候，撒迦利亞在神面前履行祭司的職務，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 29:11; 出埃及記 30:7–8; 歷代志上 23:13"> 照著祭司職務的規矩，抽中了籤就進入主的聖所燒香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 16:17; 啟示錄 8:3; 希伯來書 4:14"> 燒香的時候，全體民眾都在外面禱告。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:26–27; 使徒行傳 10:3–4; 士師記 13:3"> 有主的一位天使站在香壇的右邊向他顯現。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:22; 士師記 6:22; 路加福音 2:9–10"> 撒迦利亞看見後，就驚慌不安，恐懼就臨到了他。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 2:21; 使徒行傳 10:31; 創世記 25:21"> 天使對他說：<br /><span className="pl pl-1">「撒迦利亞，不要怕，</span><br /><span className="pl pl-1">因為你的祈禱已蒙垂聽。</span><br /><span className="pl pl-1">你的妻子伊莉莎白要為你生一個兒子，</span><br /><span className="pl pl-1">你要給他起名叫約翰。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 創世記 21:6"> <span className="pl pl-1">他將使你歡喜、快樂，</span><br /><span className="pl pl-1">許多人也會因他的誕生而歡欣，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:5; 民數記 6:2–4; 路加福音 7:33"> <span className="pl pl-1">因為他將要在主面前為大。</span><br /><span className="pl pl-1">淡酒和烈酒他絕不能喝，</span><br /><span className="pl pl-1">還在母腹中的時候，</span><br /><span className="pl pl-1">他就會被聖靈充滿。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 40:3–5; 馬太福音 21:32; 瑪拉基書 3:1"> <span className="pl pl-1">他將使許多以色列子民</span><br /><span className="pl pl-1">歸向主——他們的神。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 4:5–6; 馬太福音 11:14; 路加福音 1:76"> <span className="pl pl-1">他將藉著以利亞的靈和能力，</span><br /><span className="pl pl-1">在主的面前先行，</span><br /><span className="pl pl-1">使父親的心</span><br /><span className="pl pl-1">轉向兒女，</span><br /><span className="pl pl-1">使悖逆的人</span><br /><span className="pl pl-1">轉向義人的智慧，</span><br /><span className="pl pl-1">好為主準備一群預備好了的子民。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 38:22; 創世記 17:17; 路加福音 1:7"> 撒迦利亞對天使說：「我憑著什麼能知道這事呢？我是個老人，我的妻子也上了年紀。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 馬太福音 18:10; 但以理書 9:21–23"> 天使回答他，說：「我是站在神面前的加百列，奉差派來對你說話，向你傳達這些好消息。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 3:26; 以西結書 24:27; 路加福音 1:22"> 看哪，你要成為啞巴，不能說話，一直到這些事成就的日子，因為你不相信我的話！到了時候，我的話就會應驗。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 6:23–27"> 民眾等候著撒迦利亞，對他在聖所裡的遲延不出感到驚奇。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 約翰福音 13:24; 使徒行傳 21:40"> 當他出來不能和他們說話的時候，他們才了解他在聖所裡看到了異象。撒迦利亞一直向他們打手勢，卻始終不能說話。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 9:25; 列王紀下 11:5–7"> 他服事的日子滿了以後，就回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 這些日子以後，他的妻子伊莉莎白懷了孕，隱居了五個月。她說：</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 30:22–23; 以賽亞書 54:1–4; 創世記 21:1–2"> 「為了除去我在人間的恥辱，主在這些眷顧的日子裡，這樣看待了我。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 2:23; 路加福音 1:19; 約翰福音 7:41"> 在第六個月，天使加百列從神那裡奉差派，去加利利一個叫拿撒勒的城，</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 1:18; 以賽亞書 7:14; 馬太福音 1:16"> 到一個童貞女那裡。這童貞女名叫瑪麗亞，已經許配給大衛家族一個名叫約瑟的人。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 6:12; 但以理書 10:19; 路加福音 1:30"> 天使<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="天使——有古抄本作「他」。">c</a></sup>來到她面前，說：「蒙大恩的女子，願你歡喜，主與你同在！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「你在婦女中是蒙祝福的！」">d</a></sup>」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 10:17; 路加福音 1:12; 使徒行傳 10:4"> 瑪麗亞因這話就驚慌不安，思索這問候到底是什麼意思。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 羅馬書 8:31; 路加福音 12:32"> 天使對她說：<br /><span className="pl pl-1">「瑪麗亞，不要怕，</span><br /><span className="pl pl-1">因為你在神面前蒙恩了。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 7:14; 馬太福音 1:21; 馬太福音 1:25"> <span className="pl pl-1">看哪，你將要懷孕生一個兒子，</span><br /><span className="pl pl-1">你要給他起名叫耶穌。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 9:6–7; 以賽亞書 16:5; 撒母耳記下 7:11–13"> <span className="pl pl-1">他將要為大，</span><br /><span className="pl pl-1">被稱為至高者的兒子；</span><br /><span className="pl pl-1">主、神要把他先祖大衛的王位賜給他。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 2:44; 希伯來書 1:8; 但以理書 7:13–14"> <span className="pl pl-1">他要做王統管雅各家，直到永遠，</span><br /><span className="pl pl-1">他的國度沒有窮盡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="士師記 13:8–12; 使徒行傳 9:6"> 瑪麗亞對天使說：「我既然沒有出嫁<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="沒有出嫁——原文直譯「沒有親近男人」。">e</a></sup>，怎麼會有這事呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 1:18; 約翰福音 1:49; 馬太福音 1:20"> 天使回答她，說：<br /><span className="pl pl-1">「聖靈將要臨到你，</span><br /><span className="pl pl-1">至高者的大能要蔭庇你，</span><br /><span className="pl pl-1">因此，那要誕生的聖者</span><br /><span className="pl pl-1">將被稱為神的兒子。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 你看，你的親戚伊莉莎白雖然年老，也懷了男胎；那被稱為不能生育的，現在已有六個月的身孕<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的身孕——輔助詞語。">f</a></sup>了。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 19:26; 耶利米書 32:27; 馬可福音 10:27"> 因為在神沒有什麼事是不可能的。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="羅馬書 4:20–21; 詩篇 119:38; 詩篇 116:16"> 瑪麗亞說：「看哪，我是主的婢女，願這事照著你的話成就在我身上。」於是天使離開了她。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:65; 約書亞記 15:48–59; 約書亞記 10:40"> 就在那些日子裡，瑪麗亞起身到山區去，趕往猶大的一個城，</span>
<span className="v" id="v40" data-v="40"> 進了撒迦利亞的家，問候伊莉莎白。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 1:67; 使徒行傳 4:8; 路加福音 1:44"> 伊莉莎白一聽到瑪麗亞的問候，胎兒就在她的腹中跳動，伊莉莎白也被聖靈充滿，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 1:28; 士師記 5:24; 創世記 22:18"> 大聲呼喊說：<br /><span className="pl pl-1">「你在婦女中是蒙祝福的，</span><br /><span className="pl pl-1">你腹中的胎兒</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="胎兒——原文直譯「果實」。">g</a></sup><br /><span className="pl pl-1">也是蒙祝福的！</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="約翰福音 20:28; 約翰福音 13:13; 路加福音 2:11"> 我主的母親竟然到我這裡來，這事怎麼會臨到我呢？</span>
<span className="v" id="v44" data-v="44"> 看哪，原來你問候的聲音一傳入我的耳朵，胎兒就在我的腹中歡喜跳躍。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 20:29; 約翰福音 11:40; 路加福音 11:27–28"> 這相信的女子是蒙福的，因為主對她說的話都會實現。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v46" data-v="46" data-xref="撒母耳記上 2:1–10; 詩篇 34:2–3; 詩篇 35:9"> 瑪麗亞說：<br /><span className="pl pl-1">「我的心尊主為大，</span><br /></span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 35:9; 提摩太前書 2:3; 哈巴谷書 3:18"> <span className="pl pl-1">我的靈以神我的救主為樂，</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 138:6; 瑪拉基書 3:12; 哥林多前書 1:26–28"> <span className="pl pl-1">因為他看顧他婢女的卑微。</span><br /><span className="pl pl-1">看哪，從今以後，</span><br /><span className="pl pl-1">世世代代都要稱我有福，</span><br /></span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 126:2–3; 詩篇 111:9; 以弗所書 3:20"> <span className="pl pl-1">因為那全能者</span><br /><span className="pl pl-1">為我行了大事；</span><br /><span className="pl pl-1">他的名是神聖的。</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 103:17–18; 出埃及記 20:6; 創世記 17:7"> <span className="pl pl-1">他的憐憫，</span><br /><span className="pl pl-1">世世代代臨到敬畏他的人。</span><br /></span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 98:1; 以賽亞書 52:10; 撒母耳記上 2:3–4"> <span className="pl pl-1">他用膀臂施展大能，</span><br /><span className="pl pl-1">驅散那些心思意念驕傲的人。</span><br /></span>
<span className="v" id="v52" data-v="52" data-xref="以西結書 17:24; 雅各書 4:10; 詩篇 107:40–41"> <span className="pl pl-1">他把權能者從高位上拉下，</span><br /><span className="pl pl-1">又把卑微的人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="卑微的人——或譯作「謙卑的人」。">h</a></sup><br /><span className="pl pl-1">高舉。</span><br /></span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:8–9; 路加福音 6:21; 詩篇 34:10"> <span className="pl pl-1">他用美物滿足飢餓的人，</span><br /><span className="pl pl-1">讓富有的人空手而去。</span><br /></span>
<span className="v" id="v54" data-v="54" data-xref="詩篇 98:3; 彌迦書 7:20; 以賽亞書 44:21"> <span className="pl pl-1">他扶助他的僕人以色列，</span><br /><span className="pl pl-1">不忘憐憫，</span><br /></span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 105:6–10; 創世記 17:19; 詩篇 132:11–17"> <span className="pl pl-1">正如他對我們祖先，</span><br /><span className="pl pl-1">對亞伯拉罕和他的後裔所說的，直到永遠。」</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> 瑪麗亞與伊莉莎白一起住了大約三個月，就回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="路加福音 1:13; 創世記 21:2–3; 路加福音 2:6–7"> 伊莉莎白產期到了，生了一個兒子。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:25; 路加福音 1:14; 羅馬書 12:15"> 她的鄰居和親戚聽說主向她大施憐憫，就與她一同歡樂。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="創世記 17:12; 利未記 12:3; 腓立比書 3:5"> 到了第八天，他們來給孩子行割禮，要按照他父親的名字叫他撒迦利亞。</span>
<span className="v" id="v60" data-v="60" data-xref="路加福音 1:13; 撒母耳記下 12:25; 路加福音 1:63"> 可是孩子的母親應聲說：「不！他要被稱為約翰。」</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61"> 他們對她說：「你的親族中沒有叫這名字的。」</span>
<span className="v" id="v62" data-v="62" data-xref="路加福音 1:22"> 於是他們向孩子的父親打手勢，到底他願意叫他什麼名字。</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 1:60; 以賽亞書 30:8; 路加福音 1:13"> 撒迦利亞要了一塊寫字板，寫上：「他的名字是約翰。」大家都感到驚奇。</span>
<span className="v" id="v64" data-v="64" data-xref="路加福音 1:20; 出埃及記 4:15–16; 以西結書 33:22"> 撒迦利亞的口立刻開了，舌頭也鬆了，就說出話來，頌讚神。</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 1:39; 使徒行傳 5:11; 路加福音 7:16"> 於是住在他們周圍的人都感到懼怕，整個猶太山區的人也都在談論這一切事。</span>
<span className="v" id="v66" data-v="66" data-xref="使徒行傳 11:21; 路加福音 2:19; 路加福音 2:51"> 所有聽見的人都把這一切存在心裡，說：「這孩子將來究竟會怎麼樣呢？」因為顯然有主的手與他同在。</span>
</div>

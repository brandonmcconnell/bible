<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:10; 馬太福音 25:14–30; 雅各書 4:3"> 耶穌又對門徒們說：<span className="woj">「某財主有個管家，這個管家被人控告揮霍主人的財產。</span></span>

<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 5:31; 以賽亞書 10:3; 箴言 18:9"> <span className="woj">「那管家心裡說：『主人要把我管家的任務拿去了，我能做什麼呢？挖地沒有力氣，乞討又感到羞恥。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:9; 耶利米書 4:22; 雅各書 3:15"> <span className="woj">我知道我該做什麼了，好使我被免除管家的任務以後，人們會接我到他們家裡去。』</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:41–42; 馬太福音 18:24"> <span className="woj">「於是他把自己主人的每一個欠債人都叫了來。他問第一個：『你欠我主人多少？』</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多書 2:10; 路加福音 16:12; 路加福音 16:9"> <span className="woj">「他說：『一百桶</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百桶——原文為「100巴脫斯」；或譯作「一百簍」。1巴脫斯=22公升。">a</a></sup><span className="woj">油。』</span><br /><span className="woj">「管家就對他說：『拿你的欠條，趕快坐下來寫成五十。』</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="雅歌 8:11–12; 路加福音 20:9; 路加福音 20:12"> <span className="woj">「他問另一個說：『你呢，你欠多少？』</span><br /><span className="woj">「他說：『一百擔</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一百擔——原文為「100柯羅斯」；或譯作「一百石」。1柯羅斯=350公升。">b</a></sup><span className="woj">麥子。』</span><br /><span className="woj">「管家說：『拿你的欠條，寫成八十。』</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:5; 以弗所書 5:8; 箴言 6:6–8"> <span className="woj">「於是主人因這個不義的管家做事精明，就稱讚他。這樣看來，今世的兒女在自己的世代裡</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="在自己的世代裡——或譯作「在對付自己人方面」。">c</a></sup><span className="woj">，比光明的兒女還要聰明。</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 19:21; 提摩太前書 6:17–19; 但以理書 4:27"> <span className="woj">我告訴你們：要藉著那不義的財富</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="財富——或譯作「瑪門」。">d</a></sup><span className="woj">為自己結交朋友，這樣當財富</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="財富——或譯作「瑪門」。">e</a></sup><span className="woj">無用的時候，你們會被接到永恆的居所</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="居所——原文直譯「帳幕」。">f</a></sup><span className="woj">裡。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:11–12; 馬太福音 25:21; 路加福音 19:17"> <span className="woj">在最小的事上忠心的人，在很多事上也忠心；在最小的事上不義的人，在很多事上也不義。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 12:33; 雅各書 2:5; 箴言 8:18–19"> <span className="woj">因此，你們如果在不義的財富</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="財富——或譯作「瑪門」。">g</a></sup><span className="woj">上不忠心，誰會把真正的財富</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="財富——或譯作「瑪門」。">h</a></sup><span className="woj">委託給你們呢？</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 19:13–26; 馬太福音 25:14–29; 約伯記 1:21"> <span className="woj">你們如果在別人的東西上不忠心，誰會把屬於你們的交給你們呢？</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 2:15–16; 馬太福音 6:24; 雅各書 4:4"> <span className="woj">一個僕人不能服事兩個主人。他不是厭惡這個、喜愛那個，就是忠於這個、輕視那個。你們不能既服事神，又服事財富</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="財富——或譯作「瑪門」。">i</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:35; 路加福音 20:47; 耶利米書 6:13"> 愛錢財的法利賽人聽到這一切話，就譏笑耶穌。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:7; 箴言 21:2; 哥林多前書 4:5"> 耶穌對他們說：<span className="woj">「你們就是那些在人面前顯示自己為義的，但是神知道你們的心。人看為高貴的，在神面前卻是可憎惡的。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 11:9–14; 馬太福音 21:32; 使徒行傳 3:24–25"> <span className="woj">「律法和先知</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="先知——或譯作「先知書」。">j</a></sup><span className="woj">到約翰為止，從此神國的福音被傳揚，人人都在努力爭取進入它。</span></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:18; 路加福音 21:33; 彼得前書 1:25"> <span className="woj">天地的消逝，也比律法的一筆一畫</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一筆一畫——或譯作「字母中的一點」。">k</a></sup><span className="woj">落空更容易呢！</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 19:9; 馬可福音 10:11–12; 馬太福音 5:31–32"> <span className="woj">「凡是休妻另娶的，就是犯通姦罪；凡是娶了被丈夫休的女人的，也是犯通姦罪。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 16:49; 阿摩司書 6:4–6; 路加福音 18:24–25"> <span className="woj">「有一個財主，身穿紫色袍子和細麻衣，天天奢華宴樂。</span></span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:2; 撒母耳記上 2:8; 雅各書 2:5"> <span className="woj">又有一個窮人，名叫拉撒路，滿身膿瘡，被放在財主的門口，</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 15:27; 馬可福音 7:28; 約翰福音 6:12"> <span className="woj">渴望得到財主桌子上掉下來的碎渣</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有「碎渣」。">l</a></sup><span className="woj">充飢，甚至有狗來舔他的瘡。</span></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:24; 詩篇 49:16–19; 雅各書 1:11"> <span className="woj">後來那窮人死了，被天使們帶到亞伯拉罕的懷裡。接著，那財主也死了，並且被埋葬了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 2:4; 路加福音 16:28; 馬太福音 18:9"> <span className="woj">財主在陰間的痛苦中，舉目遠遠地望見亞伯拉罕，又望見拉撒路在他懷裡，</span></span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 4:10; 啟示錄 22:1; 啟示錄 7:16–17"> <span className="woj">就呼喚說：『我父</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="父——或譯作「祖」。">m</a></sup><span className="woj">亞伯拉罕，可憐我吧！請打發拉撒路用指頭蘸點水，涼一下我的舌頭吧，因為我在這火焰裡，極其痛苦！』</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:24; 約翰一書 2:15; 詩篇 17:14"> <span className="woj">「可是亞伯拉罕說：『孩子啊，你當想起，你一生怎樣享了你的福，而拉撒路怎樣受了苦；但如今他在這裡受到安慰，你卻在痛苦中。</span></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 3:36; 詩篇 49:14; 詩篇 50:22"> <span className="woj">這一切之外，在我們和你們之間，隔著巨大的深淵，所以人想要從這邊過到你們那邊是不可能的，從那邊過到我們這邊也是不可能的。』</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> <span className="woj">「財主就說：『我父啊，那麼求你打發拉撒路到我父親家去，</span></span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 2:40; 詩篇 49:12–13; 帖撒羅尼迦前書 4:6"> <span className="woj">因為我有五個兄弟，讓他去鄭重地勸誡他們</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="勸誡他們——或譯作「向他們做見證」。">n</a></sup><span className="woj">，免得他們也來到這痛苦的地方。』</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 15:21; 路加福音 24:27; 路加福音 16:16"> <span className="woj">「但是亞伯拉罕說：『你的兄弟們有摩西和先知們，讓你的兄弟們聽從他們吧。』</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="啟示錄 16:9–11; 路加福音 16:24; 路加福音 13:5"> <span className="woj">「財主卻說：『不，我父</span><sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="父——或譯作「祖」。">o</a></sup><span className="woj">亞伯拉罕哪！其實如果有人從死人中復活</span><sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="復活——輔助詞語。">p</a></sup><span className="woj">，到他們那裡去，他們就會悔改。』</span></span>
</div>

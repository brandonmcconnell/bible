<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 20:1–2; 馬可福音 16:1–8; 馬太福音 28:1–8"> 在一週的頭一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一週的頭一天——指「星期日」。">a</a></sup>，一大清早，婦女們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="婦女們——原文直譯「她們」。">b</a></sup>帶著預備好的香料來到墓穴那裡，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「還有一些人和她們在一起。」">c</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:3–4; 馬太福音 27:60–66; 馬可福音 15:46–47"> 發現那石頭已經從墓穴被滾開了。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 約翰福音 20:6–7; 馬太福音 16:5"> 她們就進去，卻找不到主耶穌的遺體。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 16:5; 約翰福音 20:11–12; 使徒行傳 1:10"> 她們正為這件事心裡困惑的時候，忽然有兩個人，身穿閃閃發光的衣服，站在她們旁邊。</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 16:5–6; 馬太福音 28:3–5; 啟示錄 1:18"> 婦女們嚇得把臉伏在地上。<br />那兩個人對她們說：「你們為什麼在死人中尋找活人呢？</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 17:22–23; 路加福音 9:22; 馬可福音 8:31"> 他不在這裡，已經復活<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="復活——原文直譯「被復活」；指「神使耶穌復活」。">d</a></sup>了！你們當想起他還在加利利的時候怎樣告訴你們，</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 16:21"> 說<span className="woj">『人子必須被交在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="被交在——或譯作「被出賣到」。">e</a></sup><span className="woj">罪人手中，被釘十字架，然後在第三天復活。』」</span></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 12:16; 約翰福音 14:26; 約翰福音 2:19–22"> 她們就想起耶穌的話來。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 馬可福音 16:7–8; 馬太福音 28:7–8"> 於是從墓穴回去，把這一切都告訴了那十一個使徒和所有其他的人。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 27:56; 約翰福音 20:11–18; 路加福音 8:2–3"> 告訴使徒們這些事的，是茉大拉的瑪麗亞、約亞娜、雅各的母親<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="母親——輔助詞語。">f</a></sup>瑪麗亞，還有其餘和她們在一起的婦女。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 9:16; 馬可福音 16:11; 創世記 19:14"> 可是這些話在使徒們看來似乎是胡說，他們就不相信婦女們。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 20:3–10"> 但彼得卻起來，跑到了墓穴。他彎腰去看，只看見那細麻布條<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「放在那裡」。">g</a></sup>。於是他就回去了，對所發生的事感到驚奇。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 馬可福音 16:12–13"> 正好在同一天，門徒中有兩個人往一個村子去；這村子名叫以馬忤斯，離耶路撒冷約有十一公里<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十一公里——原文為「60視距」。1視距=185公尺。">h</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命記 6:7; 瑪拉基書 3:6"> 他們彼此談論著所發生的這一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:20; 約翰福音 14:18–19; 路加福音 24:36"> 在他們交談討論的時候，耶穌親自走近他們，與他們同行，</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 20:14; 約翰福音 21:4; 路加福音 24:31"> 但是他們的眼睛被遮蔽了，認不出他來。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:20–22; 約翰福音 16:6; 以西結書 9:4–6"> 耶穌問他們：<span className="woj">「你們一路上彼此談論的這些，到底是什麼事呢？」</span>他們就停住<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有「停住」。">i</a></sup>，面帶愁容。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 19:25"> 其中一個名叫克利奧帕的回答耶穌，說：「你在耶路撒冷作客，難道只有你還不知道這幾天在那裡所發生的事嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 21:11; 使徒行傳 7:22; 約翰福音 4:19"> 耶穌問他們：<span className="woj">「什麼事呢？」</span><br />他們對他說：「就是有關拿撒勒人耶穌的事。這個人是一位先知，在神和全體民眾面前說話行事都有能力。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:13–15; 使徒行傳 4:8–10; 路加福音 23:13"> 我們的祭司長們和首領們竟把他交出去，判了死罪，釘上十字架。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前書 1:18–19; 路加福音 2:38"> 不過我們一直希望他就是要救贖以色列的那一位。不但如此，從這些事發生到今天<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「今天」。">j</a></sup>，已經是第三天了。</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 16:9–10; 馬太福音 28:7–8; 約翰福音 20:1–2"> 還有，我們中間有些婦女也使我們驚訝：她們清早到了墓穴，</span>
<span className="v" id="v23" data-v="23"> 卻找不到他的遺體，回來還說她們看到了天使的異象，而天使說耶穌還活著。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 約翰福音 20:1–10"> 後來，與我們在一起的一些人，到墓穴那裡去，發現一切就像婦女們所說的那樣。只是他們沒有看見耶穌。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬可福音 7:18; 馬可福音 9:19; 希伯來書 5:11–12"> 耶穌對他們說：<span className="woj">「唉，你們這些無知的人哪！對於信靠先知們所說的一切話，你們的心太遲鈍了！</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:11; 以賽亞書 53:1–12; 撒迦利亞書 13:7"> <span className="woj">基督不是必須這樣受難，然後才進入他的榮耀嗎？」</span></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 7:14; 路加福音 24:44; 申命記 18:15"> 於是耶穌從摩西和所有的先知開始，向他們解釋了經上一切關於自己的話。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬可福音 6:48; 創世記 19:2; 創世記 32:26"> 他們快到要去的村子了，耶穌好像還要往前走。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 4:8; 路加福音 14:23; 創世記 19:3"> 他們就極力挽留他，說：「時候晚了，太陽已經平西了，請與我們一起住下吧！」耶穌就進去，與他們一起住下。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 14:19; 路加福音 24:35; 馬太福音 15:36"> 當耶穌與他們一同坐席的時候，他拿起餅來，祝福了，然後掰開遞給他們。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 約翰福音 8:59; 路加福音 4:30"> 那時他們的眼睛就開了，這才認出他來，而耶穌從他們眼前消失了。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米書 23:29; 希伯來書 4:12"> 他們彼此說：「在路上他對我們說話，為我們講解經文的時候，我們心裡不是在燃燒嗎？」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 16:13; 約翰福音 20:19–26; 使徒行傳 1:14"> 他們就立刻起身，回耶路撒冷去，見到那十一個使徒和與他們聚集在一起的人，</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 15:5; 馬可福音 16:7; 路加福音 22:54–62"> 大家都在說：「主真的復活了，並且已經向西門顯現了！」</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 16:12–13; 使徒行傳 2:42; 路加福音 24:30–31"> 兩個人就把在路上所發生的，以及耶穌掰餅的時候怎樣被他們認出來的事，都述說了一遍。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="帖撒羅尼迦後書 3:16; 以賽亞書 57:18; 馬可福音 16:14"> 在他們說這些話的時候，耶穌<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="耶穌——有古抄本作「他」。">k</a></sup>親自站在他們當中，對他們說：<span className="woj">「願你們平安！」</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本沒有「對他們說：『願你們平安！』」">l</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 28:13; 馬太福音 14:26–27; 約伯記 4:14–16"> 他們就驚慌，感到害怕，以為看到了幽靈。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 4:14; 希伯來書 4:13; 但以理書 4:19"> 耶穌對他們說：<span className="woj">「你們為什麼驚慌不安？為什麼心裡起疑惑呢？</span></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 20:27; 約翰一書 1:1; 傳道書 12:7"> <span className="woj">你們看我的手、我的腳，確實是我。摸我看看！幽靈沒有骨，也沒有肉，你們看，我是有的。」</span></span>
<span className="v" id="v40" data-v="40"> 說了這話，他就把手和腳給他們看。<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本沒有此節。">m</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 21:5; 詩篇 126:1–2; 創世記 45:26–28"> 他們又驚又喜，還不敢相信的時候，耶穌對他們說：<span className="woj">「你們這裡有什麼吃的嗎？」</span></span>
<span className="v" id="v42" data-v="42"> 他們遞給他一片烤魚<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="烤魚——有古抄本作「烤魚和蜂蜜」。">n</a></sup>，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 10:41"> 他拿過來，當著他們的面吃了。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒迦利亞書 12:10; 路加福音 24:26–27; 撒迦利亞書 9:9"> 耶穌對他們說：<span className="woj">「這就是我還與你們在一起的時候，對你們說過的話：摩西的律法、先知書和詩篇上所記的有關我的一切事，都必須應驗。」</span></span>
<span className="v" id="v45" data-v="45" data-xref="使徒行傳 16:14; 約翰一書 5:20; 詩篇 119:18"> 於是耶穌開啟他們的理性，使他們能領悟經上的話，</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 53:2–12; 以賽亞書 50:6; 路加福音 24:44"> 又對他們說：<span className="woj">「經上這樣記著：基督必須</span><sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本沒有「必須」。">o</a></sup><span className="woj">受難，然後在第三天從死人中復活，</span></span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 5:31; 以賽亞書 49:6; 使徒行傳 2:38"> <span className="woj">並且人要奉他的名宣講為罪得赦免的悔改</span><sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="為罪得赦免的悔改——有古抄本作「悔改和罪得赦免的道」。">p</a></sup><span className="woj">，從耶路撒冷開始，直到萬國。</span></span>
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 1:8; 使徒行傳 2:32; 使徒行傳 13:31"> <span className="woj">你們就是這些事的見證人。</span></span>
<span className="v" id="v49" data-v="49" data-xref="使徒行傳 1:8; 使徒行傳 1:4; 約珥書 2:28–32"> <span className="woj">看哪！我要將我父所應許的差派到你們那裡</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="到你們那裡——原文直譯「在你們身上」。">q</a></sup><span className="woj">。不過你們要留在城</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="城——有古抄本作「耶路撒冷城」。">r</a></sup><span className="woj">裡，直到領受</span><sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="領受——原文直譯「穿上」。">s</a></sup><span className="woj">了從上面</span><sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="上面——原文直譯「高處」。">t</a></sup><span className="woj">來的能力。」</span></span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行傳 1:12; 馬太福音 21:17; 馬可福音 11:1"> 耶穌領他們出去，到了伯大尼附近，就舉起雙手祝福他們。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行傳 1:9; 馬可福音 16:19; 列王紀下 2:11"> 他在祝福的時候離開他們，被接到天上去了<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="有古抄本沒有「被接到天上去了」。">u</a></sup>。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 28:9; 約翰福音 16:22; 詩篇 30:11"> 他們就敬拜他<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="有古抄本沒有「敬拜他」。">v</a></sup>，懷著極大的喜樂回耶路撒冷去，</span>
<span className="v" id="v53" data-v="53" data-xref="馬可福音 16:20; 使徒行傳 2:46–47; 使徒行傳 5:41–42"> 常常在聖殿裡頌讚<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="頌讚——有古抄本作「讚美和稱頌」。">w</a></sup>神。<sup className="fn"><a href="#fn-x" id="fnref-x" data-fn="有古抄本附「阿們。」">x</a></sup></span>

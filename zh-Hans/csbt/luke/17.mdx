<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:7; 羅馬書 14:13; 哥林多前書 11:19"> 耶穌對他的門徒們說：<span className="woj">「那些使人絆腳的事必然出現</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="必然出現——原文直譯「不可能不發生」。">a</a></sup><span className="woj">，不過使它出現的人有禍了。</span></span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 9:42; 馬太福音 18:14; 馬太福音 18:3–6"> <span className="woj">對他來說，就算脖子上拴著大磨石</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大磨石——原文直譯「磨坊的磨石」；有古抄本作「驢拉的磨石」。">b</a></sup><span className="woj">，被丟到海裡，也比他使這些卑微人中的一個絆倒更好。</span></span>
<span className="v" id="v3" data-v="3" data-xref="利未記 19:17; 馬太福音 18:21; 馬太福音 18:15–17"> <span className="woj">你們要謹慎！如果你的弟兄</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附「對你」。">c</a></sup><span className="woj">犯了罪，就告誡他；如果他悔改，就饒恕他。</span></span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:12–13; 馬太福音 18:21–22; 羅馬書 12:20"> <span className="woj">如果他一天七次對你犯了罪，又</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「一天」。">d</a></sup><span className="woj">七次回轉過來，對你說：『我悔改！』你要饒恕他。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬可福音 9:24; 希伯來書 12:2; 腓立比書 4:13"> 使徒們對主說：「請你加添我們的信心<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="信心——指「對耶穌基督的信心」。">e</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬太福音 17:20; 馬太福音 21:21; 馬可福音 9:23"> 主說：<span className="woj">「如果你們有像一粒芥菜種子那樣的信仰，即使是對這棵桑樹說『願你被連根拔起，栽到海裡去！』它也會聽從你們。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 12:11; 路加福音 13:15; 路加福音 14:5"> <span className="woj">「你們當中誰有奴僕耕田或放羊，從田裡回來的時候，會對奴僕說『立刻過來，坐下吃飯』呢？</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 創世記 43:16; 撒母耳記下 12:20"> <span className="woj">他難道不會對奴僕說『你預備我所要吃的晚餐，束上腰帶伺候我，等我吃喝完了，你才要吃喝』嗎？</span></span>
<span className="v" id="v9" data-v="9"> <span className="woj">奴僕做了所吩咐的事，難道主人要向奴僕懷有感恩的心嗎？</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附「我認為不會。」">f</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 9:16–17; 約伯記 22:2–3; 彼得前書 5:5–6"> <span className="woj">你們也是這樣，當你們做完了所吩咐你們的一切事以後，應該說『我們是無用的奴僕，只是做了自己該做的。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 約翰福音 4:3–4"> 耶穌往耶路撒冷去的時候，經過撒瑪利亞和加利利的中間地帶。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 13:45–46; 路加福音 5:12; 列王紀下 7:3"> 他進了一個村子，有十個痲瘋病人見到他，遠遠地站著，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 15:22; 馬太福音 20:30–31; 馬太福音 9:27"> 大聲說：「耶穌啊，老師啊，可憐我們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未記 13:1–46; 列王紀下 5:14"> 耶穌看見了，就對他們說：<span className="woj">「你們去，讓祭司檢查你們吧！」</span>結果在他們去的時候，就被潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 30:11–12; 詩篇 103:1–4; 詩篇 118:18–19"> 其中有一個人看見自己得了痊癒，就回來大聲地榮耀神，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 8:5–25; 馬太福音 10:5; 啟示錄 19:10"> 並且把臉伏在耶穌腳前，感謝他。這人是個撒瑪利亞人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:21; 詩篇 106:13; 創世記 3:9"> 耶穌回答說：<span className="woj">「被潔淨的不是有十個人嗎？另外九個在哪裡呢？</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 50:23; 馬太福音 15:24–28; 詩篇 106:13"> <span className="woj">除了這個外邦人，難道沒有人回來把榮耀歸給神嗎？」</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 馬可福音 10:52"> 然後耶穌對他說：<span className="woj">「起來，走吧！你的信救了你。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 18:36; 路加福音 19:11; 但以理書 2:44"> 有一次，法利賽人問耶穌：「神的國什麼時候到來呢？」耶穌回答說：<span className="woj">「神國的到來，不是眼所能見的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 12:28; 羅馬書 14:17; 馬可福音 13:21"> <span className="woj">沒有人能說『看，在這裡！』或『在那裡！』因為看哪，神的國就在你們中間</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在你們中間——或譯作「在你們心裡」。">g</a></sup><span className="woj">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 5:35; 馬太福音 9:15; 約翰福音 8:21–24"> 耶穌又對門徒們說：<span className="woj">「日子將要來到，那時候你們會渴望看見人子日子中的一天，可是看不到。</span></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 馬太福音 24:23–26; 路加福音 17:21"> <span className="woj">他們會告訴你們『看，在那裡！』或『看，在這裡！』你們不要出去，也不要追隨他們；</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 24:27; 馬太福音 24:30; 瑪拉基書 4:1–2"> <span className="woj">因為就像閃電一閃，從天這邊照耀到天那邊，人子在他的日子</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「在他的日子」。">h</a></sup><span className="woj">也將要這樣。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 16:21; 路加福音 9:22; 馬可福音 8:31"> <span className="woj">不過他必須先受很多苦害，又被這世代所棄絕。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 24:37–39; 路加福音 17:24; 創世記 7:7–23"> <span className="woj">「在挪亞的那些日子裡發生的怎樣，在人子的那些日子裡也將要怎樣：</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒羅尼迦前書 5:1–3; 路加福音 16:19–23"> <span className="woj">人們繼續吃、喝、嫁、娶，直到挪亞進方舟的那一天，洪水到來，把一切都毀滅了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 16:49–50; 創世記 18:20–21; 雅各書 5:1–5"> <span className="woj">同樣，就像在羅得的那些日子裡發生的那樣：人們繼續吃喝、買賣、耕種、建造，</span></span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 2:6; 西番雅書 2:9; 猶大書 1:7"> <span className="woj">到了羅得離開所多瑪的那一天，烈火和硫磺就從天而降，把一切都毀滅了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 1:7; 帖撒羅尼迦後書 1:7; 啟示錄 1:7"> <span className="woj">人子顯現的那一天，也將是同樣的。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 21:21; 馬可福音 13:14–16; 耶利米書 45:5"> <span className="woj">在那一天，在屋頂上的人，如果東西在屋子裡，不要下來拿；同樣，在田裡的人，也不要轉回到背後的事上。</span></span>
<span className="v" id="v32" data-v="32" data-xref="創世記 19:26; 希伯來書 10:38–39; 彼得後書 2:18–22"> <span className="woj">你們當記得羅得的妻子！</span></span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 8:35–37; 馬太福音 10:39; 約翰福音 12:25"> <span className="woj">凡想要保全</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="保全——原文直譯「買來」；有古抄本作「救」。">i</a></sup><span className="woj">自己生命的，將失去生命；凡失去自己生命的，將保存生命。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 24:40–41; 彼得後書 2:9; 瑪拉基書 3:16–18"> <span className="woj">我告訴你們：在那一夜，兩個人在一張床上，一個會被接去，另一個會被留下；</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:41; 出埃及記 11:5; 士師記 16:21"> <span className="woj">兩個女人在一起推磨，一個會被接去，另一個會被留下。」</span></span>
<span className="v" id="v36" data-v="36"> <span className="woj">兩個人在田裡，一個會被接去，另一個會被留下。</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有此節。">j</a></sup><span className="woj">」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬太福音 24:28; 約伯記 39:29–30; 啟示錄 19:17–18"> 門徒們問耶穌，說：「主啊，在哪裡呢？」<br />耶穌對他們說：<span className="woj">「屍體在哪裡，禿鷹也就聚集在哪裡。」</span></span>
</div>

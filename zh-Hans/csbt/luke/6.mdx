<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; 馬可福音 2:23–28; 馬太福音 12:1–8"> 有一次在安息日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="安息日——有古抄本作「第二重要安息日」。">a</a></sup>，耶穌從麥田經過，他的門徒們摘下麥穗，用手搓著吃。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:2; 約翰福音 5:16; 約翰福音 5:9–11"> 有一些法利賽人說：「你們為什麼做安息日不可以做<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本沒有「做」。">b</a></sup>的事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 21:3–6; 馬可福音 2:25–26; 馬太福音 12:3–5"> 耶穌回答他們，說：<span className="woj">「大衛和那些與他在一起的人飢餓時所做的事，你們難道這個也沒有讀過嗎？</span></span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:5–9"> <span className="woj">他怎樣進了神的殿</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="殿——原文直譯「家」。">c</a></sup><span className="woj">，拿了陳設餅吃，還分給與他在一起的人呢？這餅除了祭司一個人之外，誰都不可以吃。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 2:27; 啟示錄 1:10; 馬可福音 9:7"> 於是耶穌對他們說：<span className="woj">「人子是安息日的主。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 3:1–6; 馬太福音 12:9–14; 路加福音 4:31"> 在另一個安息日的時候，耶穌進了會堂教導人。那裡有一個人，右手枯萎了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; 詩篇 38:12; 路加福音 13:14"> 經文士們和法利賽人就密切注意耶穌會不會在安息日使人痊癒，為要找把柄<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="把柄——輔助詞語。">d</a></sup>控告他。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 42:4; 馬太福音 9:4; 路加福音 5:22"> 耶穌知道他們的意念，就對那手枯萎的人說：<span className="woj">「起來，站到中間來！」</span>那人就起來，站著。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 3:4; 馬太福音 12:12–13; 路加福音 14:3"> 耶穌對他們說：<span className="woj">「我問你們</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「一件事」。">e</a></sup><span className="woj">，在安息日是否可以行善或作惡，救命或害命？」</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:6–7; 馬可福音 3:5; 約翰福音 5:8"> 他環視周圍所有的人，然後對那個人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="那個人——有古抄本作「他」。">f</a></sup>說：<span className="woj">「伸出你的手！」</span>那個人一伸，他的手就復原了<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「和另一隻一樣健全」。">g</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:1–2; 使徒行傳 5:33; 傳道書 9:3"> 他們就滿腔怒火<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="滿腔怒火——原文直譯「（內心）充滿無知」或「被無知所充滿」。">h</a></sup>，彼此商量到底怎麼對付耶穌。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="希伯來書 5:7; 馬可福音 6:46; 馬可福音 1:35"> 就在那些日子裡，耶穌有一次出去到山上禱告；他整夜向神禱告。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 3:13–19; 馬太福音 9:36–4; 啟示錄 21:14"> 一到天亮，他就招呼他的門徒，從他們中間揀選了十二個人，稱他們為使徒：</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 1:13; 馬太福音 4:21; 馬太福音 4:18"> <span className="pl pl-1">西門——耶穌又稱他為彼得，</span><br /><span className="pl pl-1">他的弟弟</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="弟弟——原文直譯「兄弟」。">i</a></sup><br /><span className="pl pl-1">安得烈，</span><br /><span className="pl pl-1">又有雅各、約翰、</span><br /><span className="pl pl-1">腓力、巴多羅邁、</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 9:9; 馬可福音 3:18; 使徒行傳 1:13"> <span className="pl pl-1">馬太、多馬，</span><br /><span className="pl pl-1">亞勒腓的兒子</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="兒子——輔助詞語。">j</a></sup><br /><span className="pl pl-1">雅各，</span><br /><span className="pl pl-1">稱為激進派</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="激進派——或譯作「奮銳黨」。">k</a></sup><br /><span className="pl pl-1">的西門，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:22; 約翰福音 6:70–71; 馬可福音 3:18"> <span className="pl pl-1">雅各的兒子</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="兒子——輔助詞語。">l</a></sup><br /><span className="pl pl-1">猶大，</span><br /><span className="pl pl-1">還有那成為出賣者的加略人猶大。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:21; 馬太福音 4:23–25; 詩篇 107:17–20"> 耶穌與他們一起下了山，站在一塊平地上。那裡有他的一大<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本沒有「大」。">m</a></sup>群門徒，還有來自整個猶太地區、耶路撒冷以及沿海的提爾和西頓的一大群人。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 17:15; 馬太福音 15:22; 使徒行傳 5:16"> 他們來是要聽他講說，要他們的病得痊癒。那些被汙靈折磨的，都得了痊癒。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 14:36; 馬可福音 3:10; 使徒行傳 5:15–16"> 眾人都想要摸到他，因為有能力從他身上發出，使所有的人得痊癒。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="雅各書 2:5; 路加福音 6:20–24; 哥林多後書 8:9"> 耶穌舉目看著他的門徒們，說：<br /><span className="pl pl-1 woj">「貧乏的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為神的國是你們的。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 6:35; 馬太福音 5:6; 雅各書 1:12"> <span className="pl pl-1 woj">如今飢餓的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為你們將得飽足。</span><br /><span className="pl pl-1 woj">如今哭泣的人是蒙福的，</span><br /><span className="pl pl-1 woj">因為你們將要歡笑。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 5:10–12; 馬太福音 10:22; 彼得前書 4:12–16"> <span className="pl pl-1 woj">當人們因人子的緣故憎恨你們，</span><br /><span className="pl pl-1 woj">排斥你們，責罵你們，</span><br /><span className="pl pl-1 woj">把你們當做惡人革除你們的名，</span><br /><span className="pl pl-1 woj">你們就是蒙福的。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 5:41; 啟示錄 21:7; 啟示錄 3:12"> <span className="woj">「在那一天，你們當歡喜，當歡然跳躍，因為看哪，你們在天上的報償是大的。要知道，那些人的祖先也是同樣對待先知們的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 6:2; 雅各書 5:1–6; 詩篇 49:6–7"> <span className="pl pl-1 woj">「不過富有的人，你們有禍了，</span><br /><span className="pl pl-1 woj">因為你們已經得到了你們的安慰。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 65:13; 雅各書 4:9; 箴言 14:13"> <span className="pl pl-1 woj">如今</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本沒有「如今」。">n</a></sup><br /><span className="pl pl-1 woj">飽足的人，你們有禍了，</span><br /><span className="pl pl-1 woj">因為你們將要飢餓。</span><br /><span className="pl pl-1 woj">如今歡笑的人，你們有禍了，</span><br /><span className="pl pl-1 woj">因為你們將要悲傷、哭泣。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:19; 雅各書 4:4; 馬太福音 7:15"> <span className="pl pl-1 woj">當所有的人都說你們好的時候，</span><br /><span className="pl pl-1 woj">你們有禍了，</span><br /><span className="pl pl-1 woj">因為他們的祖先也是同樣對待假先知們的。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦前書 5:15; 路加福音 6:35; 羅馬書 12:17–21"> <span className="woj">「然而我告訴你們這些正在聽的人：要愛你們的敵人</span><sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="敵人——或譯作「反對者」。">o</a></sup><span className="woj">，善待那些恨你們的人；</span></span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 3:9; 哥林多前書 4:12; 羅馬書 12:14"> <span className="woj">要祝福那些詛咒你們的人，為那些詆毀你們的人禱告。</span></span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 10:34; 馬太福音 5:39–42; 哥林多後書 11:20"> <span className="woj">有人打你這邊的臉，把另一邊也讓他打；有人拿走你的外衣，連裡衣</span><sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="裡衣——或譯作「襯袍」。">p</a></sup><span className="woj">也不要阻止他拿；</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 15:7–10; 哥林多後書 9:6–14; 馬太福音 6:12"> <span className="woj">任何人求你，都要給他；有人拿走你的東西，不要討回來。</span></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 7:12; 加拉太書 5:14; 馬太福音 22:39"> <span className="woj">你們希望別人怎樣對待你們，你們也應當怎樣對待別人。</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 5:46–47; 彼得前書 2:19–20"> <span className="woj">如果你們只愛那些愛你們的人，難道有什麼可稱讚的嗎？其實連罪人也愛那些愛他們的人。</span></span>
<span className="v" id="v33" data-v="33"> <span className="woj">如果你們只善待那些善待你們的人，難道有什麼可稱讚的嗎？連罪人也這樣做。</span></span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> <span className="woj">如果你們借東西，只借給那些有指望能從他們收取</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="收取——有古抄本作「收回」。">q</a></sup><span className="woj">的人，那有什麼可稱讚的呢？就是罪人也借給罪人，為要如數收回。</span></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 5:44–45; 約翰福音 13:35; 箴言 19:17"> <span className="woj">不過你們要愛你們的敵人</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="敵人——或譯作「反對者」。">r</a></sup><span className="woj">，要善待人；借出去，不指望任何償還</span><sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="不指望任何償還——有古抄本作「總不絕望」。">s</a></sup><span className="woj">。這樣，你們的報償就大了，而且你們將成為至高者的兒女，因為他以仁慈待那些忘恩負義和邪惡的人。</span></span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 5:1–2; 馬太福音 5:48; 彼得前書 1:15–16"> <span className="woj">你們要仁慈，正如你們的父是仁慈的。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以弗所書 4:32; 雅各書 5:9; 馬太福音 7:1–5"> <span className="woj">「不要評斷人，你們就絕不被評斷；不要定人的罪，你們就絕不被定罪；要饒恕人，你們就會被饒恕。</span></span>
<span className="v" id="v38" data-v="38" data-xref="哥林多後書 9:6–8; 申命記 15:10; 馬可福音 4:24"> <span className="woj">你們要給與，就會被賜予，而且用十足的量器，連搖帶按、滿滿當當地倒在你們懷裡，因為，你們用什麼量器</span><sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="量器——或譯作「尺度」或「標準」。">t</a></sup><span className="woj">來衡量，也會同樣地被衡量。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="馬太福音 15:14; 提摩太後書 3:13; 提摩太前書 6:3–5"> 耶穌又對他們講了一個比喻：<span className="woj">「難道瞎子能給瞎子領路嗎？兩個人不都會掉進坑裡嗎？</span></span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 13:16; 馬太福音 10:24–25; 約翰福音 15:20"> <span className="woj">學生不高於他的老師，但所有學成的人，將會像他的老師一樣。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 8:7; 雅各書 1:24; 羅馬書 2:1"> <span className="woj">「你為什麼看見你弟兄眼裡的木屑，卻不想自己眼裡的梁木呢？</span></span>
<span className="v" id="v42" data-v="42" data-xref="羅馬書 2:21–29; 帖撒羅尼迦前書 2:10–12; 詩篇 51:9–13"> <span className="woj">你看不見自己眼裡的梁木，怎麼能對你弟兄說『弟兄啊，讓我除掉你眼裡的木屑』呢？你這偽善的人！先除掉你自己眼裡的梁木，然後你才能看得清楚，好除掉你弟兄眼裡的木屑。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米書 2:21; 馬太福音 12:33; 馬太福音 7:16–20"> <span className="woj">「好樹不結壞果子，壞</span><sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="壞——或譯作「腐敗的」或「有病的」。">u</a></sup><span className="woj">樹也不結好果子。</span></span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 12:33; 雅各書 3:12; 加拉太書 5:19–23"> <span className="woj">這樣，每一棵樹都是憑著它的果子被認出來。人不從蒺藜中收無花果，也不從荊棘上摘葡萄。</span></span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; 馬太福音 12:34–37; 以弗所書 4:29"> <span className="woj">好人從他心裡所存的善，發出善來；壞人從他心裡所存的</span><sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="有古抄本沒有「他心裡所存的」。">v</a></sup><span className="woj">惡，發出惡來；因為人心裡所充滿的，口裡就說出來。</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="加拉太書 6:7; 瑪拉基書 1:6; 馬太福音 7:21–23"> <span className="woj">「你們為什麼稱呼我『主啊，主啊！』卻不遵行我所說的話呢？</span></span>
<span className="v" id="v47" data-v="47" data-xref="雅各書 1:22–25; 馬太福音 7:24–27; 路加福音 11:28"> <span className="woj">我要指示你們，凡是到我這裡來聽了我的話而實行的人是什麼樣的人：</span></span>

</div>

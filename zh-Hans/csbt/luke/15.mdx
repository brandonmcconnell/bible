<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 1:15; 馬太福音 9:10–13; 路加福音 5:29–32"> 當時，稅吏和罪人都接近耶穌，聽他講說。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 法利賽人和經文士抱怨，說：「這個人歡迎罪人，又與他們一起吃飯。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 於是耶穌對他們講了這個比喻：</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 34:16; 以西結書 34:11–12; 馬太福音 18:12–14"> <span className="woj">「你們當中的哪一個人擁有一百隻羊，而丟失其中的一隻，就不會把九十九隻留在曠野，去找那一隻丟失的，直到找到了牠呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 12:2; 路加福音 19:9; 以賽亞書 46:3–4"> <span className="woj">一旦找到了，他就快快樂樂地扛在自己的肩上，</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前書 2:25"> <span className="woj">回到家裡請朋友和鄰居來，對他們說：『你們與我一同歡樂吧，因為我找到了那隻丟失的羊。』</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> <span className="woj">我告訴你們：同樣，一個罪人的悔改，比九十九個不需要悔改的義人，會讓天上更有喜樂。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西結書 34:12; 約翰福音 10:16"> <span className="woj">「或者，如果一個婦人有十個銀幣</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十個銀幣——原文為「10錐克瑪」。1錐克瑪=約1日工資的希臘銀幣。">a</a></sup><span className="woj">，丟失了一個，難道她不點上油燈，打掃屋子，仔細尋找，直到找到了它嗎？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> <span className="woj">一旦找到了，她就會請朋友和鄰居來，說：『你們與我一同歡樂吧，因為我找到了那個丟失的銀幣</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="銀幣——原文為「錐克瑪」。1錐克瑪=約1日工資的希臘銀幣。">b</a></sup><span className="woj">。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多後書 7:10; 以西結書 33:11"> <span className="woj">同樣，我告訴你們：一個罪人的悔改，會讓神的天使們面前有喜樂。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 21:23–31"> 耶穌又說：<span className="woj">「某人有兩個兒子。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:16–17; 馬可福音 12:44; 路加福音 15:30"> <span className="woj">小兒子對父親說：『父親，請把我應得的那份家產給我。』父親就把財產分給兩個兒子。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米書 2:5; 箴言 21:17"> <span className="woj">沒過幾天，那小兒子就收拾了一切，往一個遙遠的地方去旅行了。他在那裡過著放蕩的生活，揮霍他的錢財。</span></span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 33:11; 阿摩司書 8:9–12; 何西阿書 2:9–14"> <span className="woj">當他花盡了自己的一切，那地方又發生了嚴重的饑荒，他就開始窮困起來。</span></span>
<span className="v" id="v15" data-v="15" data-xref="提多書 3:3; 提摩太後書 2:25–26; 以賽亞書 1:5"> <span className="woj">於是他去投靠當地的一個居民，那人打發他到自己的田裡去放豬。</span></span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 6:19–21; 耶利米哀歌 4:5; 何西阿書 12:1"> <span className="woj">他就是渴望拿豬吃的豆莢來充飢</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="充飢——有古抄本作「填自己的肚子」。">c</a></sup><span className="woj">，也沒有人給他。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 18:28; 以弗所書 2:4–5; 路加福音 15:18–19"> <span className="woj">可是他醒悟過來的時候，就說：『我父親那麼多的雇工都食物充足，我卻要在這裡餓死</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="餓死——或譯作「因饑荒喪命」。">d</a></sup><span className="woj">嗎？</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 約翰一書 1:8–10; 路加福音 15:21"> <span className="woj">我要起來，到我父親那裡去，對他說：『父親，我對天犯了罪，也在你面前犯了罪。</span></span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 42:6; 路加福音 5:8; 詩篇 84:10"> <span className="woj">我再也不配稱為你的兒子，請把我當做你的一個雇工吧。』</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 103:10–13; 詩篇 86:5; 詩篇 86:15"> <span className="woj">於是他起來往自己的父親那裡去。他離得還遠的時候，他父親就看到他，動了憐憫之心，跑上去摟住他的脖子親吻他。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 51:4; 路加福音 15:18–19; 耶利米書 3:13"> <span className="woj">兒子說：『父親，我對天犯了罪，也在你面前犯了罪。我再也不配稱為你的兒子。』</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 41:42; 以斯帖記 8:2; 啟示錄 6:11"> <span className="woj">「父親卻對奴僕們說：『趕快</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「趕快」。">e</a></sup><span className="woj">把那最好的袍子拿來給他穿上，把戒指戴在他手上，把鞋子穿在他腳上，</span></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 25:6; 馬太福音 22:2–14; 詩篇 63:5"> <span className="woj">把那隻養肥的牛犢牽來宰殺了，讓我們吃喝、慶祝吧！</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 2:5; 以西結書 34:16; 路加福音 19:10"> <span className="woj">因為我這個兒子是死而復生、失而復得的。』於是他們開始慶祝。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 150:4; 耶利米書 31:4; 路加福音 15:11–12"> <span className="woj">「那時，大兒子正在田裡。當他往回走，快到家的時候，聽見音樂和跳舞的聲音，</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">就叫來一個僕人，問這些到底是什麼事。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 9:17; 腓利門書 1:16; 使徒行傳 22:13"> <span className="woj">僕人對他說：『你弟弟</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="弟弟——原文直譯「兄弟」。">f</a></sup><span className="woj">回來了。你父親因他平安無恙地回來，就宰殺了那隻養肥的牛犢。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約拿書 4:9; 撒母耳記上 18:8; 約拿書 4:1–4"> <span className="woj">「大兒子發怒，不肯進去，他父親就出來勸</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="勸——或譯作「安慰」。">g</a></sup><span className="woj">他。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亞書 7:3; 以賽亞書 65:5"> <span className="woj">他回答父親，說：『你看，我服事你這麼多年，從來沒有違背過你的命令，可是你從來沒有給過我一隻小山羊，好讓我與朋友們一同慶祝。</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> <span className="woj">而你這個兒子，這個與妓女們一起吞盡了你財產的，他一來了，你就為他宰殺了養肥的牛犢！』</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 7:27–28; 羅馬書 9:4; 羅馬書 11:1"> <span className="woj">「父親對他說：『孩子啊，你一直與我在一起，我的一切都是你的。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以弗所書 2:1–10; 路加福音 15:24; 以賽亞書 35:10"> <span className="woj">現在，我們應該慶祝、歡喜，因為你這個弟弟是死而復生、失而復得的。』」</span></span>
</div>
</div>

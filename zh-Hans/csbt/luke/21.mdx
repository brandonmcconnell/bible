<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 12:41–44; 約翰福音 8:20; 馬太福音 27:6"> 耶穌抬頭觀看，見富有的人把他們的奉獻投入奉獻箱裡，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 12:42"> 又見一個窮寡婦投進兩個小錢<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="兩個小錢——原文為「2雷普頓」。1雷普頓=約1/128日工資的希臘小銅幣。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:12; 使徒行傳 10:34; 哥林多後書 8:2–3"> 於是他說：<span className="woj">「我確實地告訴你們：這窮寡婦所投的，比所有的人更多。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 2:44–45; 路加福音 15:12; 使徒行傳 4:34"> <span className="woj">因為那些人都是從自己的富餘中拿出來，當做奉獻</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="奉獻——有古抄本作「給神的奉獻」。">b</a></sup><span className="woj">來投入；而這寡婦是從自己的缺乏中，把她擁有的養生費用全都投進去了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 2:20; 馬太福音 24:1–51; 馬可福音 13:1–37"> 有些人談論到聖殿，說它是用精美的石頭和供奉的禮物裝飾的。耶穌就說：</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 24:2; 馬可福音 13:2; 耶利米哀歌 5:18"> <span className="woj">「你們現在所看見的這些，當那些日子來到的時候，將不會有一塊石頭留在另一塊石頭上而不被拆下。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 1:6–7; 馬可福音 13:14; 馬可福音 13:3–4"> 他們就問耶穌，說：「老師，那麼，這些事什麼時候會發生呢？這些事將要發生的時候，會有什麼預兆呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰一書 4:1; 馬可福音 13:5–6; 以弗所書 5:6"> 耶穌說：<span className="woj">「你們要當心，免得被迷惑，因為許多人會以我的名而來，聲稱『我就是那一位</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我就是那一位——原文直譯「我就是」或「我永在」。">c</a></sup><span className="woj">』，又說『時候快到了。』你們不要跟從他們。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 馬太福音 24:6–8; 馬可福音 13:7–8"> <span className="woj">當你們聽見有戰爭和混亂的時候，不可驚慌，因為這些事必須先發生，不過結局不會立刻就到。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:19–20; 馬可福音 13:8; 歷代志下 15:5–6"> 耶穌接著對他們說：<span className="woj">「一個民族要起來反對另一個民族，一個國家要起來反對另一個國家；</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 24:29–30; 路加福音 21:25–27"> <span className="woj">到處都會有大地震、饑荒和瘟疫；會有恐怖的景象和天上來的大徵兆。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:12–14; 使徒行傳 5:40; 使徒行傳 22:30"> <span className="woj">不過在所有這些事以前，他們將對你們下手，逼迫你們，把你們送交會堂，送進監獄；為我名的緣故，你們將被帶到君王和總督面前。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 1:12; 腓立比書 1:28; 帖撒羅尼迦後書 1:5"> <span className="woj">但這卻要成為你們做見證的機會。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 馬可福音 13:11; 馬太福音 10:19–20"> <span className="woj">所以你們應當心裡鎮定，不用預先思慮怎樣申辯。</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:9; 以弗所書 6:19; 路加福音 12:12"> <span className="woj">因為我將賜給你們口才和智慧，是所有反對你們的人都不能抵擋、不能駁倒的。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 啟示錄 6:9; 彌迦書 7:5–6"> <span className="woj">你們甚至將被父母、兄弟、親戚和朋友出賣，他們還會害死你們當中的一些人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:19; 路加福音 6:22; 約翰福音 15:21"> <span className="woj">為了我的名，你們將被所有的人憎恨，</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 10:30; 撒母耳記上 14:45; 路加福音 12:7"> <span className="woj">可是你們連一根頭髮也絕不會失去。</span></span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 10:36; 馬太福音 10:22; 雅各書 1:3"> <span className="woj">你們當在你們的忍耐中獲得自己的生命</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="生命——或譯作「靈魂」。">d</a></sup><span className="woj">。</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你們當在忍耐中獲得自己的生命。——或譯作「你們當靠忍耐獲得自己的生命。」">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理書 9:27; 馬可福音 13:14"> <span className="woj">「當你們看見耶路撒冷被軍隊包圍的時候，你們那時就應當知道它的毀滅近了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 6:1; 創世記 19:17; 路加福音 17:31–33"> <span className="woj">那時，在猶太的人應當逃到山裡；在城</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="城——原文直譯「她」，指「耶路撒冷」。">f</a></sup><span className="woj">裡的人應當出來；在鄉下的人不要進城；</span></span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 9:7; 以賽亞書 65:12–16; 以賽亞書 63:4"> <span className="woj">因為這是報應的日子，為要應驗經上所記載的一切。</span></span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 13:17; 馬太福音 24:19; 路加福音 23:29"> <span className="woj">在那些日子裡，孕婦和哺乳的女人有禍了！因為將有大苦難臨到這地</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="這地——或譯作「地上」或「大地」。">g</a></sup><span className="woj">，也有震怒臨到這民</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="這民——或譯作「人們」或「子民」或「這個民族」。">h</a></sup><span className="woj">。</span></span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:25; 啟示錄 11:2; 以賽亞書 63:18"> <span className="woj">他們將倒在刀口下，被擄到各國去。耶路撒冷將要被外邦人踐踏，直到外邦人的日期滿了。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 13:10; 約珥書 2:30–31; 啟示錄 6:12–14"> <span className="woj">「在太陽、月亮和星辰中將有徵兆出現</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="出現——輔助詞語。">i</a></sup><span className="woj">；在地上，因海洋的咆哮和翻騰，列國的人就驚慌失措，陷入困惑混亂之中；</span></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 24:29; 申命記 28:65–67; 彼得後書 3:10–12"> <span className="woj">人們預料到將要臨到世界的事，就嚇得魂不附體；因為諸天的各勢力都將被震動。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 24:30; 啟示錄 1:7; 馬可福音 13:26"> <span className="woj">那時候，人們將要看見人子帶著極大的權能和榮耀，在雲彩中來臨。</span></span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 8:23; 以賽亞書 60:1–2; 以弗所書 4:30"> <span className="woj">這些事一開始發生，你們就當挺起身、抬起頭，因為你們的救贖近了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 24:32–35; 馬可福音 13:28–30"> 耶穌又給他們講了一個比喻：<span className="woj">「你們看無花果樹和其他</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="其他——輔助詞語。">j</a></sup><span className="woj">所有的樹，</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:57"> <span className="woj">當它們長出葉子</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="葉子——輔助詞語。">k</a></sup><span className="woj">的時候，你們一看就知道夏天已經快到了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 5:9; 希伯來書 10:37; 彼得前書 4:7"> <span className="woj">照樣，當你們看見這些事發生的時候，你們應當知道：神的國快到了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 13:30; 馬太福音 24:34; 馬太福音 23:36"> <span className="woj">我確實地告訴你們：在這一切事發生之前，這世代絕不會過去。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 40:8; 馬可福音 13:31; 馬太福音 24:35"> <span className="woj">天和地將要消逝，但是我的話絕不會消逝。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> <span className="woj">「你們要謹慎自守，免得你們的心因宴樂</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="宴樂——或譯作「放蕩」。">l</a></sup><span className="woj">、醉酒和今生的憂慮變得遲鈍，那日子就會像網羅一樣突然臨到你們，</span></span>
<span className="v" id="v35" data-v="35" data-xref="啟示錄 16:15; 詩篇 11:6; 耶利米書 48:43–44"> <span className="woj">因為那日子將要臨到所有住在全地面上的人。</span></span>
<span className="v" id="v36" data-v="36" data-xref="約翰一書 2:28; 馬太福音 25:13; 彼得前書 5:8"> <span className="woj">你們要時刻警醒、禱告，使你們能夠</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="能夠——有古抄本作「被算為配得上」。">m</a></sup><span className="woj">逃避這一切將要發生的事，好站立在人子面前。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 馬可福音 11:19; 馬太福音 21:17"> 耶穌白天在聖殿裡教導人，夜間出去到那叫做「橄欖園」的山裡過夜。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 8:1–2"> 全體民眾清早起來上聖殿，到耶穌那裡聽他講說。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="路加福音 18:24–27; 歷代志下 17:5–6"> 看哪，有一個名叫撒該的人，是個稅吏長，很富有。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:8; 路加福音 9:7–9; 約翰福音 12:21"> 他很想看看耶穌是什麼樣的人，可是因為他身材矮小，從人群中無法看到耶穌。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 9:10; 路加福音 5:19; 列王紀上 10:27"> 於是他跑到前頭，爬上一棵桑樹，要看耶穌，因為耶穌就要從那裡經過。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 3:20; 約翰福音 14:23; 希伯來書 13:2"> 耶穌來到那地方時，抬頭一看，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「看見他」。">a</a></sup>對他說：<span className="woj">「撒該，快下來！因為我今天必須住在你家裡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:29; 使徒行傳 16:34; 使徒行傳 16:15"> 撒該就急忙下來，快快樂樂地接待耶穌。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:2; 路加福音 7:39; 路加福音 7:34"> 大家看見，就抱怨說：「他竟然到一個罪人家裡去借宿。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 12:6; 民數記 5:7; 路加福音 18:22–23"> 撒該站著對主說：「主啊，請看，我要把我財產的一半分給窮人。我如果勒索過誰的東西，就償還四倍。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:7; 路加福音 13:16; 羅馬書 4:16"> 耶穌對他說：<span className="woj">「今天救恩臨到了這一家，因為他也是亞伯拉罕的子孫。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 34:16; 馬太福音 1:21; 提摩太前書 1:13–16"> <span className="woj">要知道，人子來，是為了尋找並拯救迷失的人。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 17:20; 使徒行傳 1:6; 帖撒羅尼迦後書 2:1–3"> 大家正聽這些話的時候，耶穌再講了一個比喻，因為他已經離耶路撒冷不遠，而且他們以為神的國快要顯現了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:14–30; 路加福音 19:12–27; 路加福音 20:9"> 他說：<span className="woj">「有一個出身高貴的人，要往遙遠的地方去接受王位</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="王位——原文直譯「王國」。">b</a></sup><span className="woj">，然後再回來。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 25:14–15; 約翰福音 12:26; 哥林多前書 12:7–11"> <span className="woj">他叫來自己的十個奴僕，給他們一千銀幣</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一千銀幣——原文為「10彌那」。1彌那=約100日工資；希臘幣製，原為重量單位；相當於舊約50舍客勒。">c</a></sup><span className="woj">，對他們說：『你們去做生意，直到我回來。』</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 8:7; 使徒行傳 7:51–52; 使徒行傳 3:14–15"> <span className="woj">「他本國的人卻憎恨他，就差派特使在他背後去，說：『我們不要這個人做王統治我們。』</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 4:1–5; 羅馬書 14:10–12; 詩篇 2:4–6"> <span className="woj">「當他接受了王位</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="王位——原文直譯「王國」。">d</a></sup><span className="woj">回來的時候，就吩咐把這些曾領了銀子的奴僕叫來，要知道他們做生意賺了多少。</span></span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 2:18–26; 提摩太後書 4:7–8; 哥林多前書 15:10"> <span className="woj">第一個前來說：『主啊，你的那一百銀幣</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一百銀幣——原文為「1彌那」。1彌那=約100日工資；希臘幣製，原為重量單位；相當於舊約50舍客勒。">e</a></sup><span className="woj">，已經賺了一千</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一千——原文為「10彌那」。1彌那=約100日工資；希臘幣製，原為重量單位；相當於舊約50舍客勒。">f</a></sup><span className="woj">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 16:10; 馬太福音 25:21; 啟示錄 2:26–29"> <span className="woj">「主人對他說：『做得好，好奴僕！因為你在最小的事上忠心，你就有權掌管十個城。』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 4:20; 馬太福音 13:23; 哥林多後書 8:12"> <span className="woj">「第二個上前來說：『主啊，你的那一百銀幣</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一百銀幣——原文為「1彌那」。1彌那=約100日工資；希臘幣製，原為重量單位；相當於舊約50舍客勒。">g</a></sup><span className="woj">，已經賺了五百</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="五百——原文為「5彌那」。1彌那=約100日工資；希臘幣製，原為重量單位；相當於舊約50舍客勒。">h</a></sup><span className="woj">。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 15:58; 哥林多前書 15:41–42; 哥林多前書 3:8"> <span className="woj">「主人也對這個人說：『你掌管五個城吧！』</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 25:24; 箴言 26:13–16; 雅各書 4:17"> <span className="woj">「另一個上前來說：『主啊，請看，你的那一百銀幣，我一直保存在手巾裡。</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:24–25; 羅馬書 8:7; 約翰一書 4:18"> <span className="woj">我怕你，因為你是個嚴厲的人，不是你存放的，你提取；不是你播種的，你收獲。』</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 1:16; 馬太福音 12:37; 約伯記 15:5–6"> <span className="woj">「主人對他說：『你這惡奴！我要憑你的口定你的罪。你既然知道我是個嚴厲的人，不是我存放的，我提取；不是我播種的，我收獲，</span></span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 22:25–27; 羅馬書 2:4–5; 申命記 23:19–20"> <span className="woj">那麼你為什麼沒有把我的銀子交給錢莊呢？這樣我回來的時候，可以連本帶利收回來。』</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 16:2; 路加福音 12:20"> <span className="woj">於是他對站在旁邊的人說：『把那一百銀幣從他那裡拿走，給那個有一千的。』</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 16:2; 撒母耳記下 7:19; 以賽亞書 55:8–9"> <span className="woj">「他們說：『主啊，他已經有一千銀幣了！』</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約翰二書 1:8; 路加福音 8:18; 馬太福音 21:43"> <span className="woj">「我告訴你們：凡是有的，還要賜給他；那沒有的，連他有的也將從他那裡被拿走。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:14; 詩篇 21:8–9; 馬太福音 22:7"> <span className="woj">不過我的這些敵人，就是不要我做王統治他們的人，把他們帶到這裡來，在我面前殺掉！」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:51; 希伯來書 12:2; 彼得前書 4:1"> 說完這些話，耶穌就繼續往前走，上耶路撒冷去。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 1:12; 馬太福音 21:17; 馬太福音 21:1–11"> 快到伯法其和伯大尼，那叫做「橄欖園」的山，耶穌派了兩個門徒，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 22:8–13; 路加福音 19:32; 撒母耳記上 10:2–9"> 說：<span className="woj">「你們到對面的村子裡去。你們一進村，就會發現一頭驢駒拴在那裡，是從來沒有人騎過的。你們把牠解開牽過來。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 24:1; 詩篇 50:10–12; 馬可福音 11:3–6"> <span className="woj">如果有人問你們為什麼解開牠，你們就這樣說『主需要牠</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主需要牠——或譯作「牠的主人有需要」。">i</a></sup><span className="woj">。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 22:13"> 被差派的人去了，發現事情正如耶穌所告訴他們的。</span>
<span className="v" id="v33" data-v="33"> 在他們解開驢駒的時候，驢的主人們問他們：「你們為什麼解開這驢駒呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 9:9; 約翰福音 10:35; 哥林多後書 8:9"> 他們就說：「主需要牠。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 11:7–8; 馬太福音 21:7; 約翰福音 12:14"> 他們牽著驢駒到耶穌那裡，把自己的外衣搭在驢駒上，扶著耶穌騎上去。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 9:13; 馬太福音 21:8"> 耶穌前行的時候，人們把自己的外衣鋪在路上。</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 12:12–13; 以斯拉記 3:10–13; 馬太福音 21:1"> 耶穌已經快到橄欖山的下坡附近的時候，全體門徒為了他們所看見的一切神蹟，開始歡樂起來，大聲讚美神，</span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亞書 9:9; 路加福音 13:35; 詩篇 118:22–26"> 說：<br /><span className="pl pl-1">「奉主名而來的那位君王，</span><br /><span className="pl pl-1">是蒙祝福的！</span><br /><span className="pl pl-1">在天上有和平，</span><br /><span className="pl pl-1">在至高之處有榮耀！」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 4:1–2; 馬太福音 23:13; 使徒行傳 4:16–18"> 人群中有一些法利賽人對耶穌說：「老師，責備你的門徒吧！」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="哈巴谷書 2:11; 以賽亞書 55:12; 馬太福音 3:9"> 耶穌回答說：<span className="woj">「我告訴你們：這些人如果不做聲，石頭都會呼喊起來！」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 13:34–35; 約翰福音 11:35; 詩篇 119:136"> 耶穌快到耶路撒冷<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶路撒冷——輔助詞語。">j</a></sup>的時候，看見那城，就為她哭泣，</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 32:29; 希伯來書 10:26–29; 以賽亞書 48:18"> 說：<span className="woj">「巴不得你在這日子裡明白關乎你和平的事，但如今這事在你眼前被隱藏了。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 21:20–24; 以賽亞書 29:1–4; 以西結書 4:2"> <span className="woj">因為日子將臨到你，你的敵人要築起壁壘包圍你，四面困住你。</span></span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 21:6; 路加福音 13:34–35; 約翰福音 3:18–21"> <span className="woj">而且，他們要將你和你裡面的兒女猛摔在地，不容你裡面有一塊石頭留在另一塊石頭上，因為你沒有認出神</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="神——輔助詞語。">k</a></sup><span className="woj">臨到</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="臨到——或譯作「探望」。">l</a></sup><span className="woj">你的時候。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 21:12–13; 馬可福音 11:15–17; 約翰福音 2:13–17"> 耶穌進了聖殿，開始把那些<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附「在裡面」。">m</a></sup>做買賣的人<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="做買賣的人——有古抄本作「賣東西的人」。">n</a></sup>趕出去，</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 56:7; 耶利米書 7:11; 詩篇 93:5"> 對他們說：<span className="woj">「經上記著：『我的殿將成為禱告的殿』，而你們卻使它成為賊窩了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="馬可福音 11:18; 馬太福音 26:55; 馬可福音 11:27–33"> 耶穌天天在聖殿裡教導人。祭司長們、經文士們和民間的首領們想要殺害他，</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:6–23; 馬太福音 26:2–5; 約翰福音 11:55–57"> 除酵節——又叫逾越節——快到了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 11:47–53; 馬太福音 12:14; 路加福音 20:19"> 祭司長們和經文士們在圖謀怎樣能殺掉耶穌，因為他們怕民眾。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約翰福音 13:2; 馬可福音 14:10–11; 約翰福音 13:26–27"> 那時，撒旦進入了那稱為加略人的猶大裡面。猶大算是十二使徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使徒——輔助詞語。">a</a></sup>中的一個。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:1; 使徒行傳 5:24; 路加福音 22:52"> 他去跟祭司長們和守衛長們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="守衛長們——原文直譯「指揮官們」或「司令官們」或「將軍們」。">b</a></sup>商量怎樣把耶穌交給他們。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 26:15–16; 使徒行傳 1:18; 馬太福音 27:3–5"> 他們就歡喜，並且說好要給他銀錢。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 14:2; 馬太福音 26:5"> 猶大同意了，就開始找機會，要趁眾人不在的時候，把耶穌交給他們。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:18; 馬可福音 14:12–16; 哥林多前書 5:7"> 除酵節的第一日到了，在這一天必須宰殺逾越節的羔羊。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 14:13–16; 使徒行傳 4:19; 使徒行傳 4:13"> 耶穌差派彼得和約翰，說：<span className="woj">「你們去為我們預備逾越節的晚餐，好讓我們能吃上。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 他們問耶穌：「你要我們在哪裡預備呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 16:4; 馬太福音 26:18–19; 使徒行傳 8:26–29"> 耶穌對他們說：<span className="woj">「看哪！你們進了城，會有一個人提著一罐水迎面而來，你們就跟著他，到他所進的那一家去，</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:28; 啟示錄 3:20; 路加福音 19:34"> <span className="woj">對那家的主人說：『老師問你：我與我的門徒們一起吃逾越節晚餐的客房在哪裡呢？』</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 16:14–15; 使徒行傳 1:13; 約翰福音 2:25"> <span className="woj">他會給你們看樓上一間布置好的大房間，你們就在那裡預備吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:33; 路加福音 19:32; 約翰福音 2:5"> 他們去了，看到的正如耶穌對他們所說的。他們就預備了逾越節的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:20; 馬可福音 14:17; 申命記 16:6–7"> 時候一到，耶穌就坐席，十二<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本沒有「十二」。">c</a></sup>使徒也和他同坐。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:50; 約翰福音 4:34; 約翰福音 17:1"> 耶穌對他們說：<span className="woj">「我一直非常渴望在我受難之前，與你們一起吃這逾越節的晚餐。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 14:15; 啟示錄 19:9; 路加福音 22:30"> <span className="woj">我告訴你們：我絕不</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「再」。">d</a></sup><span className="woj">吃這晚餐，直等到逾越節在神的國裡得以成就。」</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:19; 詩篇 116:13; 申命記 8:10"> 耶穌拿起杯來，祝謝了，說：<span className="woj">「你們拿這個，大家分著喝。</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 26:29; 路加福音 22:16; 馬可福音 14:25"> <span className="woj">我告訴你們：從今以後</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「從今以後」。">e</a></sup><span className="woj">我絕不喝這葡萄汁</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="葡萄汁——或譯作「葡萄酒」；原文直譯「葡萄樹的產品」。">f</a></sup><span className="woj">，直到神的國來臨。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 11:23–29; 哥林多前書 10:16; 馬可福音 14:22–24"> 他又拿起餅來，祝謝了，掰開遞給他們，說：<span className="woj">「這是我的身體，為你們獻上的；你們應當如此行，為的是記念我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 26:28; 哥林多前書 11:25; 撒迦利亞書 9:11"> 晚餐後，他也照樣拿起杯來，說：<span className="woj">「這杯是用我的血所立的新約，為你們所流的。</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="-20 有古抄本沒有「為你們獻上的……為你們所流的。」">g</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 41:9; 約翰福音 13:26; 約翰福音 13:21–22"> <span className="woj">不過看哪，那賣我之人的手，與我的手一同在這桌子上，</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 2:23; 詩篇 109:6–15; 詩篇 55:12–15"> <span className="woj">因為人子確實要按照所決定的離去。不過出賣人子的那個人有禍了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:22–25; 馬可福音 14:19; 馬太福音 26:22"> 於是他們開始彼此議論，他們當中究竟是誰會做這事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 9:46; 馬可福音 9:34; 馬可福音 10:37–41"> 門徒之間也起了爭論：他們當中誰算是更大的。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 20:25–28; 馬可福音 10:41–45"> 耶穌對他們說：<span className="woj">「外邦人有君王轄制他們，他們的掌權者被稱為恩主。</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 5:5; 路加福音 9:48; 馬太福音 18:3–5"> <span className="woj">但你們卻不是這樣；相反，你們當中誰更大，誰就該變得像年幼的那樣；領頭的，該像服事人的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 20:28; 路加福音 12:37; 約翰福音 13:5–16"> <span className="woj">坐席的或服事的，到底哪一個更大呢？難道不是坐席的嗎？然而我在你們中間，是像服事人的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:18; 希伯來書 4:15; 使徒行傳 1:25"> <span className="woj">不過我在試煉當中，始終與我在一起的就是你們；</span></span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 25:34; 提摩太後書 2:12; 雅各書 2:5"> <span className="woj">並且我把國度賜給你們，就像我父賜給了我那樣，</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 19:28; 馬太福音 8:11; 啟示錄 2:26–27"> <span className="woj">使你們在我的國度裡，在我的筵席上吃喝；並且坐在寶座上審判以色列的十二個支派。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前書 5:8; 撒迦利亞書 3:1; 約伯記 1:6–12"> <span className="woj">主又說</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本沒有「主又說」。">h</a></sup><span className="woj">：「西門，西門，你看，撒旦想要得著你們，要篩你們像篩麥子一樣。</span></span>
<span className="v" id="v32" data-v="32" data-xref="彼得前書 5:8–10; 約翰福音 21:15–17; 約翰福音 17:9–11"> <span className="woj">但是，我已經為你祈求，使你不失去信仰。所以當你回轉過來的時候，要堅固你的弟兄們。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬可福音 14:31; 馬太福音 26:33–35; 馬可福音 14:29"> 可是彼得對耶穌說：「主啊，我預備好要與你一起去監獄、一起去死！」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 13:38; 馬太福音 26:34; 馬可福音 14:30"> 耶穌卻說：<span className="woj">「彼得，我告訴你：今天雞叫以前，你會三次否定認識我。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 10:9–10; 路加福音 10:4; 詩篇 23:1"> 接著耶穌問他們：<span className="woj">「我從前差派你們出去的時候，你們不帶錢包、行囊、鞋子，你們缺少過什麼沒有？」</span><br />他們說：「沒有。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬太福音 10:22–25; 帖撒羅尼迦前書 3:4; 帖撒羅尼迦前書 2:14–15"> 耶穌卻對他們說：<span className="woj">「但現在，有錢包的應當帶著；同樣，有行囊的也應當帶著；沒有刀的，應當賣掉自己的外衣去買一把。</span></span>
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 53:12; 路加福音 23:32; 哥林多後書 5:21"> <span className="woj">我告訴你們：經上記著：『他被列在不法之徒當中』，這話必須在我身上成就，因為那有關我的事就要有個結局了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:49; 馬太福音 26:52–54; 約翰福音 18:36"> 他們說：「主啊，你看，這裡有兩把刀。」<br />耶穌說：<span className="woj">「實在夠了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 21:37; 約翰福音 18:1–2; 馬太福音 21:1"> 耶穌出來，照他的習慣往橄欖山去，門徒們也跟著他。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 6:13; 馬太福音 26:36–46; 路加福音 22:46"> 到了那地方，耶穌對他們說：<span className="woj">「你們要禱告，免得陷入試探。」</span></span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 26:39; 馬可福音 14:35; 路加福音 18:11"> 然後他抽出身，離他們約有扔一塊石頭的距離，跪下禱告，</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:27–28; 馬太福音 26:39; 馬太福音 26:42"> 說：<span className="woj">「父啊，如果你願意，請把這杯從我這裡拿走吧！但不要成就我的意思，而要成就你的意思。」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 4:11; 馬太福音 26:53; 詩篇 91:11–12"> 有一位天使從天上向他顯現，加添他的力量。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米哀歌 1:12; 希伯來書 5:7; 詩篇 22:12–21"> 耶穌在極大的痛苦中，禱告更加懇切；他的汗珠變得像大血滴，落在地上。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本沒有43,44節。">i</a></sup></span>
<span className="v" id="v45" data-v="45" data-xref="馬可福音 14:40–41; 馬太福音 26:43; 馬太福音 26:40"> 禱告完了，他起身到門徒那裡，看見他們因為憂傷都睡著了，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 22:40; 約拿書 1:6; 路加福音 21:34–36"> 就對他們說：<span className="woj">「你們為什麼睡覺呢？起來禱告，免得陷入試探。」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="馬可福音 14:41–50; 約翰福音 18:2–11; 路加福音 22:3–6"> 耶穌還在說話的時候，忽然來了一群人。十二使徒中的一個，就是那稱為猶大的，走在他們前頭。他靠近耶穌，要親吻他。</span>
<span className="v" id="v48" data-v="48" data-xref="馬可福音 14:44–46; 撒母耳記下 20:9–10; 箴言 27:6"> 耶穌對他說：<span className="woj">「猶大，你用親吻禮來出賣人子嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 22:38"> 耶穌周圍的人看到要發生的事，就說：「主啊，我們要用刀砍嗎？」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 18:10–11; 馬可福音 14:47; 羅馬書 12:19"> 其中一個人向大祭司的奴僕砍去，削掉了他的右耳。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="羅馬書 12:21; 哥林多後書 10:1; 彼得前書 2:21–23"> 耶穌應聲說：<span className="woj">「住手，到此為止！」</span>然後摸一下那個人的耳朵，使他痊癒了。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 22:4; 馬可福音 14:48–49; 約翰福音 17:12"> 耶穌對前來對付他的祭司長們、聖殿守衛長們和長老們說：<span className="woj">「你們帶著刀劍和棍棒出來，就像對付強盜那樣嗎？</span></span>
<span className="v" id="v53" data-v="53" data-xref="約翰福音 12:27; 以弗所書 6:12; 使徒行傳 26:18"> <span className="woj">我天天在聖殿裡與你們在一起的時候，你們不向我下手。不過現在是你們的時候了，是黑暗掌權的時候了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="馬可福音 14:53–54; 馬太福音 26:57–58; 約翰福音 18:12–17"> 他們抓住耶穌，把他帶走，押到大祭司的家裡。彼得遠遠地跟著。</span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 26:4–5; 哥林多後書 6:15–17; 馬可福音 14:66–72"> 他們在院子當中生了火，一起坐著。彼得也坐在他們中間。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 18:17; 馬可福音 14:6; 馬可福音 14:17"> 有一個女僕看見彼得坐在火光中，就注視著他，說：「這個人也與他是一夥的。」</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="約翰一書 1:9; 約翰福音 18:25; 馬太福音 26:70"> 彼得卻否認說：「你這個女人哪，我不認識他！」</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="約翰福音 18:25; 馬太福音 26:71–72; 馬可福音 14:69–70"> 過了一會兒，另一個人看見他，就說：「你也是與他們一夥的！」<br />彼得說：「你這個人哪，我不是！」</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="約翰福音 18:26–27; 馬可福音 14:69–70; 馬太福音 26:73–74"> 大約過了一個小時，又有一個人肯定地說：「這個人真的也是與他一夥的，因為他也是加利利人。」</span>
</div>
<div className="bp">

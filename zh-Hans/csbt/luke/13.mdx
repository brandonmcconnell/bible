<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:17–18; 耶利米哀歌 2:20; 以西結書 9:5–7"> 正在那時候，有些人前來告訴耶穌有關加利利人的事，就是彼拉多把加利利人的血與他們的祭物混在一起的事。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 9:2; 使徒行傳 28:4; 約伯記 22:5–16"> 耶穌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶穌——有古抄本作「他」。">a</a></sup>回答他們，說：<span className="woj">「你們以為這些加利利人如此受害，是因為他們比其他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="其他——輔助詞語。">b</a></sup><span className="woj">所有加利利人更有罪嗎？</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 3:19; 馬太福音 3:2; 使徒行傳 2:38–40"> <span className="woj">不是的。我告訴你們：你們如果不悔改，都會同樣地滅亡。</span></span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 3:15; 約伯記 1:19; 約翰福音 9:11"> <span className="woj">或者，西羅亞樓倒塌壓死的那十八個人，你們以為他們比所有住在耶路撒冷的人更有罪嗎？</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 18:30; 路加福音 13:3; 以賽亞書 28:10–13"> <span className="woj">不是的。我告訴你們：你們如果不悔改，都會同樣滅亡。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:16; 以賽亞書 5:1–4; 加拉太書 5:22"> 於是耶穌講了這個比喻：<span className="woj">「一個人有一棵無花果樹栽在自己的葡萄園裡。當他過來，在那樹上找果子時，卻找不到，</span></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:19; 路加福音 3:9; 約翰福音 15:6"> <span className="woj">就對園丁說：『你看，一連三年，我在這無花果樹上找果子，都找不到。把它砍了吧！何必讓它白占土地？』</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="彼得後書 3:9; 約珥書 2:17; 羅馬書 10:1"> <span className="woj">「但是園丁回答，對他說：『主人，今年再留著它吧。等我在它周圍挖掘，施些糞肥，</span></span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 15:2; 帖撒羅尼迦前書 2:15; 希伯來書 6:8"> <span className="woj">或許它來年真會結出果子，否則，你就砍了它。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 在安息日，耶穌在一個會堂裡教導人，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 看哪，有一個婦人，被邪靈附身病了十八年，一直彎著腰，完全直不起身來。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:20; 馬太福音 8:16; 路加福音 6:8–10"> 耶穌看見她，就招呼她，對她說：<span className="woj">「婦人，你已經從你的疾病中被釋放了！」</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 107:20–22; 馬可福音 16:18; 馬可福音 5:23"> 然後耶穌按手在她身上，她的腰立刻直了，她就不住地榮耀神。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 20:9; 馬太福音 12:2; 約翰福音 9:14–16"> 因為耶穌在安息日使人痊癒，會堂主管就很生氣，對那群人說：「應該做工的日子有六天，所以你們在那些日子來得痊癒吧！但不要在安息日這一天。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 約翰福音 7:21–24; 使徒行傳 13:9–10"> 主回答他，說：<span className="woj">「你們這些偽善的人！難道你們每個人在安息日，不也是把自己的牛或驢從槽邊解開，牽去飲水嗎？</span></span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 2:27; 提摩太後書 2:26; 路加福音 19:9"> <span className="woj">何況這婦人，做為亞伯拉罕的子孫</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="子孫——原文直譯「女兒」。">c</a></sup><span className="woj">，被撒旦所捆綁竟然有十八年，難道不應該在安息日這一天從捆鎖中被釋放嗎？」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得前書 3:16; 詩篇 132:18; 以賽亞書 45:24"> 耶穌說了這些話，所有反對他的人都感到蒙羞，可是眾人都因他所行的一切榮耀的事而感到歡喜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 4:30–34; 路加福音 17:21; 馬太福音 13:31–32"> 於是耶穌說：<span className="woj">「神的國好比什麼呢？我要把它比做什麼呢？</span></span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 4:12; 但以理書 4:21; 但以理書 2:44–45"> <span className="woj">它好比一粒芥菜種子，有人拿去種在自己的園子裡，種子長大，成了一棵樹</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="樹——有古抄本作「大樹」。">d</a></sup><span className="woj">，天空的飛鳥也在它的枝子上搭窩。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶穌又說：<span className="woj">「我要把神的國比做什麼呢？</span></span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 13:33; 哥林多前書 5:6; 帖撒羅尼迦前書 5:23–24"> <span className="woj">它好比酵母，一個婦人拿去拌在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="拌在——原文直譯「藏在」。">e</a></sup><span className="woj">三斗</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三斗——原文為「3撒頓」；容量約為22公升。1撒頓=7.3公升。">f</a></sup><span className="woj">麵裡，直到整團麵都發了酵。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 馬太福音 9:35; 馬可福音 10:32–34"> 耶穌走遍許多城鎮、鄉村教導人，並繼續往耶路撒冷前行。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 7:14; 馬太福音 22:14; 約翰福音 21:21–22"> 有一個人問他：「主啊，得救的人很少嗎？」<br />耶穌對他們說：</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 7:13–14; 彼得後書 1:10; 哥林多前書 9:24–27"> <span className="woj">「你們要為進窄門而爭戰，因為我告訴你們：將有許多人想要進去，卻是不能。</span></span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 25:10–12; 路加福音 13:27; 馬太福音 7:21–23"> <span className="woj">等到那家的主人起來關了門，你們才開始站在外面敲門，說：『主啊，請給我們開門！』主人就會回答你們，說：『我不知道你們是從哪裡來的。』</span></span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 58:2; 提多書 1:16; 提摩太後書 3:5"> <span className="woj">那時你們就開始說：『我們曾經在你面前吃過、喝過，你也曾經在我們的大街</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大街——或譯作「廣場」。">g</a></sup><span className="woj">上教導過！』</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 6:8; 馬太福音 25:41; 馬太福音 7:22–23"> <span className="woj">他要對你們說：『我不知道你們是從哪裡來的。離開我，你們所有不義的工人！』</span></span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 8:11–12; 馬太福音 22:13; 馬太福音 25:30"> <span className="woj">當你們看見亞伯拉罕、以撒、雅各和所有的先知在神的國裡，而你們卻被丟在外面的時候，在那裡將有哀哭和切齒。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 43:6; 以賽亞書 66:18–20; 以賽亞書 49:6"> <span className="woj">人們將從東、西、南、北而來，在神的國裡坐席。</span></span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 19:30; 馬可福音 10:31; 馬太福音 20:16"> <span className="woj">看哪，有些在後的，將要在前；有些在前的，將要在後。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 6:9–11; 詩篇 11:1–2; 馬太福音 14:1"> 就在這時候<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="這時候——原文直譯「同一時候」。">h</a></sup><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="時候——有古抄本作「天」。">i</a></sup>，有一些法利賽人前來對耶穌說：「你離開吧，從這裡走開！因為希律想要殺你。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="希伯來書 2:10; 希伯來書 5:9; 約翰福音 17:4–5"> 耶穌對他們說：<span className="woj">「你們去告訴那狐狸：看哪！今天明天我驅趕鬼魔、治癒疾病，然後在第三天，我的事就得以完成了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 馬太福音 21:11; 使徒行傳 13:27"> <span className="woj">不過今天、明天、後天，我必須往前走，因為先知不能在耶路撒冷之外被殺！</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 23:37–39; 申命記 32:11–12; 使徒行傳 7:52"> <span className="woj">「耶路撒冷啊，耶路撒冷！這城殺害先知們，又用石頭砸死被差到她這裡的人！我多次想聚集你的兒女，像母雞把自己的小雞聚集在翅膀下，可是你們不願意！</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:26; 馬可福音 11:9–10; 馬太福音 21:9"> <span className="woj">看哪，你們的家</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="家——或譯作「殿」；指「聖殿」。參《耶利米書》12:7；22:5。">j</a></sup><span className="woj">要被廢棄</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附「成為荒場」。">k</a></sup><span className="woj">。我</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附「確實地」。">l</a></sup><span className="woj">告訴你們：你們絕不會再見到我了，直到那日子來臨，就是你們說『奉主名而來的那一位是蒙祝福的』那時候。」</span></span>
</div>
</div>

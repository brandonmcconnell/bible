<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:23; 羅馬書 10:15; 馬太福音 9:35"> 不久以後，耶穌走遍各個城鎮鄉村，講道、傳神國的福音。與他在一起的有十二使徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使徒——輔助詞語。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:9; 馬太福音 27:55–56; 馬可福音 15:40–41"> 還有一些從邪靈和疾病中被解脫出來<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="被解脫出來——輔助詞語。">b</a></sup>、得了痊癒的婦女，其中有那稱為茉大拉的瑪麗亞，從她身上曾經有七個鬼魔被趕出來，</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 4:46–53; 哥林多後書 8:9; 使徒行傳 9:36–39"> 又有希律的管家苦撒的妻子約亞娜，以及蘇珊娜和許多別的婦女，她們都用自己所擁有的來服事耶穌和門徒們<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶穌和門徒們——原文直譯「他們」；有古抄本作「他」。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬可福音 4:1–9; 馬太福音 13:2–9"> 那時，有一大群人聚集，又有人從各城鎮來到耶穌那裡，耶穌就用比喻說：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 2:1; 雅各書 1:23–24; 馬可福音 4:15"> <span className="woj">「有一個撒種的出去撒種。他撒的時候，有的種子落在路邊，被人踐踏，天空的飛鳥也把它吃掉了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 3:7–8; 路加福音 8:13; 馬可福音 4:5–6"> <span className="woj">有的落在岩石上，一長出來就枯萎了，因為得不到水份。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 4:3; 路加福音 8:14; 路加福音 21:34"> <span className="woj">有的落進荊棘叢裡，荊棘與它一起生長，把它擠住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 11:15; 啟示錄 2:11; 啟示錄 2:7"> <span className="woj">但另有落進好土壤裡的，長起來，結出百倍的果實。」</span>耶穌講完這些話，就大聲說：<span className="woj">「凡是有耳可聽的，就應當聽！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="馬可福音 4:10; 馬太福音 13:10; 馬太福音 13:18"> 耶穌的門徒們問他這比喻到底是什麼意思。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 6:9; 馬可福音 4:11; 馬太福音 11:25"> 他說：<span className="woj">「神國的奧祕已經賜下來讓你們知道，但是對其他的人就用比喻。這是為要使</span><br /><span className="pl pl-1 woj">『他們看，卻看不見；</span><br /><span className="pl pl-1 woj">聽，卻不領悟。』</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 13:19; 馬可福音 4:14–20; 雅各書 1:21"> <span className="woj">「原來，這個比喻是這樣的。那種子就是神的話語</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的話語——或譯作「神的道」。">d</a></sup><span className="woj">。</span></span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦後書 2:9–14; 啟示錄 12:9; 雅各書 1:23–24"> <span className="woj">那『路邊之地』，是這樣的人：他們聽了這話語，然後魔鬼就來，從他們心裡把話語奪走，免得他們信而得救。</span></span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 6:4; 約翰福音 5:35; 箴言 12:12"> <span className="woj">那『岩石』，是這樣的人：他們一旦聽了，就懷著喜樂的心接受了這話語；可是這些人沒有根，他們暫時相信，而在試煉的時候，就離開信仰</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="離開信仰——或譯作「背棄」。">e</a></sup><span className="woj">了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="約翰一書 2:15–17; 提摩太前書 6:9–10; 提摩太前書 6:17"> <span className="woj">種子落在其中的那『荊棘叢』，是這樣的人：他們聽了，卻走自己的路</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="自己的路——輔助詞語。">f</a></sup><span className="woj">，被今生的憂慮、財富和享樂擠住了，結不出成熟的果實。</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 10:36; 加拉太書 5:22–26; 歌羅西書 1:10"> <span className="woj">那『好土壤』，是這樣的人：他們聽了這話語，以誠實美善的心持守它，並且在忍耐中結出果實。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 馬太福音 5:15–16; 馬可福音 4:21–22"> <span className="woj">「沒有人點上油燈，用器皿蓋住或放在床底下，而是放在燈臺上，好讓進來的人能看見光。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 馬太福音 10:26; 馬可福音 4:22"> <span className="woj">隱祕的事沒有不顯露的，隱藏的事絕沒有不被知道、不顯露出來的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:12; 路加福音 19:26; 馬可福音 4:23–25"> <span className="woj">所以，你們要留心怎樣去聽；因為凡是有的，還要賜給他；凡是沒有的，連他自以為有的也將從他那裡被拿走。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 12:46–50; 馬可福音 3:31–35; 馬可福音 3:21"> 耶穌的母親和弟弟們<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="弟弟們——原文直譯「兄弟們」。">g</a></sup>來到他那裡，可是由於人多，不能靠近他。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 1:14; 馬可福音 6:3; 馬太福音 13:55–56"> 有人告訴他：「你母親和弟弟們站在外面，想要見你。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各書 1:22; 約翰福音 13:17"> 耶穌回答他們，說：<span className="woj">「我的母親、我的弟兄，是那些聽神的話語</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神的話語——或譯作「神的道」。">h</a></sup><span className="woj">而遵行的人。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 8:23–27; 馬可福音 4:35–41; 馬可福音 6:45"> 就在那些日子裡，有一天耶穌和他的門徒們上了船，耶穌對他們說：<span className="woj">「我們渡到湖對岸去吧。」</span>他們就出發了。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 93:3–4; 詩篇 124:2–4; 詩篇 148:8"> 船行的時候，耶穌睡著了。這時候，暴風降臨到湖上，他們不斷地被水浸灌，情況危險。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:25–29; 路加福音 4:39; 詩篇 104:6–9"> 門徒們上前來叫醒耶穌，說：「老師，老師，我們沒命了！」耶穌就起來，斥責風和浪，風浪就止息，湖面就變得平靜。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 8:26; 箴言 30:4; 馬可福音 4:40–41"> 耶穌對他們說：<span className="woj">「你們的信仰在哪裡？」</span><br />他們又懼怕，又驚奇，彼此說：「這個人究竟是誰？他竟然命令風和水，連風和水也聽從他！」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬可福音 5:1–20; 馬太福音 8:28–34"> 他們行船到了格拉森<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="格拉森——有古抄本作「格達拉」。">i</a></sup>人的地方，就是加利利的對岸。</span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 5:2–5; 撒母耳記上 19:24; 民數記 19:16"> 耶穌剛上岸，那城裡一個有鬼魔附身的人就迎面而來。這個人已經很長時間不穿衣服，不住在家裡，而住在墓地裡。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 8:29; 彼得後書 2:4; 馬可福音 5:6–8"> 他一看見耶穌，就喊叫起來，俯伏在耶穌面前，大聲說：「至高神的兒子耶穌，我與你有什麼關係？求求你不要折磨我！」</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 5:3–5; 路加福音 9:39; 提摩太後書 2:25–26"> 這是因為耶穌吩咐汙靈從那個人身上出來。原來汙靈曾多次抓住那個人，雖然他被鐵鏈和腳鐐捆鎖，被看守著，可是他掙斷鎖鏈，被鬼魔驅逐到曠野去。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 26:53; 路加福音 8:2; 馬太福音 8:29"> 耶穌問他：<span className="woj">「你叫什麼名字？」</span><br />他回答說：「軍團。」因為有許多鬼魔進到他裡面。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 25:41; 腓立比書 2:10–11; 約伯記 2:5"> 那些鬼魔央求耶穌不要命令它們進無底坑去。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 65:4; 以賽亞書 66:3; 啟示錄 20:7"> 當時，那裡有一大群豬正在山上吃食。那些鬼魔就央求耶穌准許它們進入那些豬裡，耶穌准許了它們。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 5:8; 約翰福音 8:44; 路加福音 8:22–23"> 鬼魔就從那個人身上出來，進入豬裡面。於是那群豬從山崖衝到湖裡淹死了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 5:14; 馬太福音 8:33; 馬太福音 28:11"> 那些放豬的人看見所發生的事，就逃跑了，去<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本沒有「去」。">j</a></sup>把這事傳到城裡城外。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行傳 22:3; 約翰一書 3:8"> 人們就出來，要看所發生的事，他們來到耶穌那裡，看見鬼魔所離開的那人，穿著衣服，神志清醒地坐在耶穌腳前，他們就懼怕起來。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 4:24"> 那些看見的人，就告訴大家被鬼魔附身的人怎樣得到救治。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 16:39; 路加福音 8:28; 路加福音 10:10–11"> 格拉森<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="格拉森——有古抄本作「格達拉」。">k</a></sup>一帶的全體民眾請求耶穌離開他們，因為他們十分懼怕。耶穌就上船回去了。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 9:13–16; 馬可福音 5:18–20; 詩篇 145:3–12"> 鬼魔所離開的那人央求耶穌，要和他在一起，但耶穌<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="耶穌——有古抄本作「他」。">l</a></sup>讓他走，說：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前書 5:8; 申命記 10:21"> <span className="woj">「你回家去吧，述說神為你做了什麼。」</span>於是他就離開了，在全城裡傳揚耶穌為他做了什麼樣的事<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="什麼樣的事——或譯作「多麼大的事」。">m</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 9:1; 馬可福音 5:21; 馬可福音 6:20"> 耶穌回來的時候，一群人來歡迎他，原來大家一直在等候他。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 5:22–43; 路加福音 13:14; 使徒行傳 18:8"> 這時候，來了一個名叫睚魯的人，他是一個會堂主管。他俯伏在耶穌腳前，懇求耶穌到他家裡去，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; 約伯記 1:18–19"> 因為他有一個約十二歲的獨生女兒，快要死了。<br />耶穌去的時候，人群擁擠著他。</span>
<span className="v" id="v43" data-v="43" data-xref="馬可福音 5:25–26; 馬太福音 9:20–22; 利未記 15:25–33"> 有一個婦人，患了十二年的血漏病，在醫生那裡花盡了她所有的養生費用，<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本沒有「在醫生那裡花盡了她所有的養生費用，」。">n</a></sup>卻沒有一個人能使她痊癒。</span>
<span className="v" id="v44" data-v="44" data-xref="馬可福音 5:27–28; 申命記 22:12; 使徒行傳 19:12"> 她從耶穌後面過來，摸了一下耶穌的衣服穗子，立刻，她的血漏就止住了。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶穌說：<span className="woj">「誰摸了我？」</span><br />大家都否認。彼得<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本附「和與他在一起的人」。">o</a></sup>就說：「老師，人群正圍著擁擠你呢！<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本附「你還問『誰摸了我』嗎？」">p</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前書 2:9"> 但是耶穌說：<span className="woj">「有人摸了我，因為我知道有能力從我身上出去了。」</span></span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 5:33; 路加福音 17:15–16; 哥林多前書 2:3"> 那婦人知道瞞不過了，就戰戰兢兢地上前俯伏在耶穌面前，在全體民眾面前說出她是因什麼理由摸了耶穌，以及怎樣立刻得了痊癒。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 馬太福音 9:22; 希伯來書 4:2"> 耶穌對她說：<span className="woj">「女兒，</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="有古抄本附「鼓起勇氣吧！」">q</a></sup><span className="woj">你的信救了你，平平安安地去吧。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="馬可福音 5:35–43; 以賽亞書 7:12; 路加福音 7:6"> 耶穌還在說話的時候，有人從會堂主管的家<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="家——輔助詞語。">r</a></sup>來，對睚魯<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="對睚魯——輔助詞語；有古抄本作「對他」。">s</a></sup>說：「你的女兒已經死了，不要再麻煩老師了。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="約翰福音 11:40; 約翰福音 11:25; 馬可福音 5:36"> 耶穌聽了，就對睚魯說：<span className="woj">「不要怕，只要信！她就會得救治。」</span></span>
<span className="v" id="v51" data-v="51" data-xref="馬可福音 14:33; 馬太福音 6:5–6; 列王紀上 17:19–23"> 耶穌來到他的家，除了彼得、約翰、雅各和孩子的父母以外，不准任何人與他一起進去。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 約翰福音 11:4; 撒迦利亞書 12:10"> 大家都在為那女孩捶胸哀哭。耶穌說：<span className="woj">「不要哭！她不是死了，而是睡了。」</span></span>
</div>

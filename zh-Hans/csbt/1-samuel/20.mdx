<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 2:9; 哥林多後書 1:12; 約翰一書 3:21"> 大衛逃離拉瑪的納約特，來見約拿單，說：「我做了什麼？我的罪孽是什麼？我在你父親面前犯了什麼罪，以致他要尋索我的性命呢？」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:15; 約翰福音 17:8; 約翰福音 15:15"> 約拿單回答他：「絕對沒有，你不會死的。看哪，我父親做事，無論大小沒有不告訴我的，我父親怎麼會向我隱瞞這事呢？沒有這樣的事！」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 25:26; 申命記 6:13; 列王紀下 2:6"> 大衛又起誓說：「你父親深知我在你眼前蒙恩，就想：『不要讓約拿單知道這事，免得他憂傷。』然而我指著耶和華的永生和你的生命起誓：我離死只有一步！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 約拿單就對大衛說：「你怎麼說，我就為你怎麼做。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 10:10; 撒母耳記上 19:2; 民數記 28:11"> 大衛對約拿單說：「看哪，明天是新月節，我應該與王一同坐席吃飯。但請讓我離開，躲藏在田野裡，直到後天傍晚。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:58; 撒母耳記上 9:12; 申命記 12:5"> 如果你父親問起我，你就說：『大衛懇求我讓他趕回他本鄉伯利恆去，因為全家族要在那裡舉行年祭。』</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 25:17; 以斯帖記 7:7; 申命記 1:23"> 如果你父親說：『好！』你的僕人就平安；如果他大為惱火，你就要知道：他已經決意要加害我了。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 14:32; 撒母耳記上 18:3; 撒母耳記上 23:18"> 那時求你以恩慈對待你的僕人，因為你曾與你僕人一同在耶和華面前立約。如果在我身上有罪孽，你就親自殺我吧！何必把我交給你父親呢？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 20:42; 撒母耳記上 19:2; 撒母耳記上 20:38"> 約拿單說：「你絕不會有事的！況且如果我確實知道我父親已經決意要加害你，我會不告訴你嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 25:14; 撒母耳記上 25:17; 創世記 42:30"> 大衛問約拿單：「要是你父親嚴厲地回應你，誰來告訴我呢？」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 約拿單對大衛說：「走，我們出去到田野裡！」他們兩個人就出去到了田野。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 22:22; 約伯記 31:4; 箴言 25:2–3"> 約拿單對大衛說：「願以色列的神耶和華作證：明後天大約這個時候，我會探探我父親是否對大衛有善意，然後我一定派人到你這裡告訴你。</span>
<span className="v" id="v13" data-v="13" data-xref="路得記 1:17; 歷代志上 22:11; 約書亞記 1:5"> 如果我父親有意要加害你，而我不告訴你，不送你平安地離開，就願耶和華處置約拿單，重重地處置！願耶和華與你同在，像他曾與我父親同在那樣。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 9:3; 以弗所書 5:1–2"> 在我活著的時候，願你以耶和華的慈愛對待我，免我死亡；</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 21:7; 撒母耳記上 24:21; 撒母耳記下 9:1–7"> 在耶和華把大衛的每個仇敵從這地面上剪除的時候，願你也不要對我家斷絕慈愛，直到永遠。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 25:22; 撒母耳記上 18:3; 撒母耳記下 21:8"> 於是約拿單與大衛家立約：「願耶和華從大衛仇敵的手中追討背約之罪！」</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 撒母耳記上 18:1; 撒母耳記上 18:3"> 約拿單因著對大衛的愛，就讓大衛再次起誓，因為他愛大衛如同愛自己的性命。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 20:25; 撒母耳記上 20:5"> 約拿單對他說：「明天是新月節，人們會問起你，因為你的座位空著。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 19:2; 撒母耳記上 20:5"> 第三天，你要趕快下去，到你在出事的日子曾經隱藏的那地方，在伊澤爾磐石旁邊等著。</span>
<span className="v" id="v20" data-v="20"> 我會向磐石旁邊射三支箭，就像射向靶子那樣。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 5:2; 阿摩司書 8:14; 耶利米書 12:16"> 看哪，我會派一個少年，去找回那些箭。如果我對那少年明確地說：『看，箭在你後面，把它們撿回來』，那麼你就回來，因為我指著耶和華的永生起誓：你必平安無事。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 20:37"> 如果我對少年說：『看，箭在你前面』，那麼你就要走，因為是耶和華讓你離去。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:14–15; 撒母耳記上 20:42; 創世記 31:50"> 我和你所說的這些話，看哪，有耶和華在你我之間作證<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="作證——輔助詞語。">a</a></sup>，直到永遠。」</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; 以賽亞書 1:11–15; 箴言 21:3"> 於是大衛躲藏在田野裡。 掃羅怒責約拿單<br />到了新月節，王入席要吃飯。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 20:18; 士師記 16:20"> 王像往常那樣坐在他的座位上，座位靠牆；約拿單在對面<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在對面——馬索拉文本作「起立」。">b</a></sup>，押尼珥坐在掃羅旁邊，而大衛的位子空著。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 15:5; 利未記 11:24; 利未記 11:27"> 掃羅那天沒有說什麼，因為他想：「有意外的事發生，大衛不潔淨了，他一定是不潔淨了。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="彼得前書 2:4; 撒母耳記上 19:15; 撒母耳記上 18:11"> 第二天，就是新月節第二天，大衛的位子還是空著。掃羅就問兒子約拿單：「為什麼耶西的兒子昨天、今天都沒有來赴宴呢？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 20:6"> 約拿單回答掃羅：「大衛懇求我准許他回伯利恆。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 17:28"> 他說：『請讓我走，因為我們家族要在那城裡舉行祭祀，我哥哥親自吩咐我回去。現在，如果我在你眼前蒙恩，就請讓我缺席，讓我去見我的哥哥們。』因此他沒有來赴王的筵席。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; 雅各書 1:19–20; 箴言 25:28"> 掃羅就對約拿單發怒，對他說：「你這忤逆的娼婦之子！難道我不知道嗎？你在袒護耶西的兒子，以致自己蒙羞，也使你母親露體蒙羞！</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 19:6; 撒母耳記上 20:8; 撒母耳記上 19:11–15"> 只要耶西的兒子活在這地上一天，你和你的王位就不能穩固。現在，你派人去把他帶到我這裡來，他必須死！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 27:23; 撒母耳記上 19:5; 路加福音 23:22"> 約拿單回應他父親掃羅說：「他為什麼該死？他做了什麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 20:7; 撒母耳記上 18:11; 撒母耳記上 19:10"> 掃羅把長矛朝著約拿單擲出去，要擊殺他。約拿單就知道，他父親是決意要殺大衛。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所書 4:26; 馬可福音 3:5; 傳道書 7:20"> 約拿單在烈怒中起來離開筵席，他在新月節第二天沒有吃飯，因為他為父親羞辱大衛而憂傷。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 20:5; 撒母耳記上 20:19"> 到了清晨，約拿單按著與大衛的約定，出去到田野裡，有一個小少年跟著他。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 20:20–22"> 他對那少年說：「往前跑，去把我將射的箭找回來！」少年就跑去，約拿單把箭射到他前頭。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 20:22"> 那少年跑到約拿單所射的箭落地之處，約拿單就在少年的後面呼喊說：「箭不是在你前頭嗎？」</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 55:6–9; 箴言 6:4–5; 馬可福音 13:14–16"> 約拿單又在少年後面呼喊：「趕快去，不要停留！」少年撿起了那些箭，回到他主人那裡。</span>
<span className="v" id="v39" data-v="39"> 那少年什麼也不知道，只有約拿單和大衛知道這意思。</span>
<span className="v" id="v40" data-v="40"> 約拿單把自己的兵器交給那少年，對他說：「去吧，拿回城裡！」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="創世記 29:11; 撒母耳記上 18:3; 撒母耳記下 9:6"> 少年走後，大衛從磐石旁邊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="磐石旁邊——依據七十士譯本；馬索拉文本作「南邊」。">c</a></sup>出來，臉伏於地，下拜三次。然後他們彼此親吻，一起哭泣，大衛哭得尤其厲害。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 1:17; 撒母耳記上 23:18; 撒母耳記上 20:22–23"> 約拿單對大衛說：「平平安安地去吧！我們兩人已經指著耶和華的名起誓說：『願耶和華在你我之間、我的後裔與你的後裔之間作證，直到永遠。』」於是大衛起身離去，約拿單也回城去了。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="此句在馬索拉文本為21:1。">d</a></sup></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:44; 彌迦書 6:15; 尼希米記 3:17–18"> 有人告訴大衛說：「看哪，非利士人在攻打基伊拉，搶掠打穀場。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 23:4; 撒母耳記下 5:19; 撒母耳記下 5:23"> 大衛就求問耶和華說：「我可以去攻打這些非利士人嗎？」<br />耶和華回答大衛：「去吧，你可以攻打非利士人，拯救基伊拉。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 12:5; 詩篇 11:1; 撒母耳記上 23:15"> 大衛的部下卻對他說：「看哪，我們在猶大這裡尚且懼怕，更何況去基伊拉攻打非利士的軍隊呢！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 7:7; 約書亞記 8:7; 列王紀下 3:18"> 於是大衛再次求問耶和華。耶和華回答他，說：「起身，下到基伊拉去，因為我必把非利士人交在你手中。」</span>
<span className="v" id="v5" data-v="5"> 大衛和他的部下就往基伊拉去，與非利士人爭戰，擄走他們的牲畜，大大擊殺他們。這樣，大衛拯救了基伊拉的居民。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 22:20; 撒母耳記上 14:3; 撒母耳記上 14:18"> 亞希米勒的兒子亞比亞特逃到基伊拉大衛那裡時，手中拿著以弗得下去。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 24:4–6; 約伯記 20:5; 撒母耳記上 26:8–9"> 有人告訴掃羅：「大衛到了基伊拉。」掃羅就說：「神把他交在我手中了，因為他進入一座有門有閂的城，把自己關在裡面了。」</span>
<span className="v" id="v8" data-v="8"> 於是掃羅召集全軍出戰，要下到基伊拉去圍困大衛和他的部下。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 30:7; 撒母耳記上 23:6; 民數記 27:21"> 大衛知道掃羅圖謀害他，就對祭司亞比亞特說：「把以弗得拿過來！」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 3:15–16; 撒母耳記上 23:8; 創世記 18:24"> 大衛求問說：「以色列的神耶和華啊，你的僕人確實聽說了掃羅想要來基伊拉，因我的緣故毀掉這城。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 33:3; 詩篇 50:15; 馬太福音 7:7–8"> 基伊拉的居民會把我交在掃羅的手中嗎？掃羅會像你僕人所聽說的那樣下來嗎？以色列的神耶和華啊，請你指示僕人。」<br />耶和華回答：「他會下來。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 23:20; 詩篇 31:8; 詩篇 62:1"> 大衛接著問：「基伊拉的居民會把我和我的人交在掃羅手中嗎？」<br />耶和華回答：「會交出去。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:2; 撒母耳記上 25:13; 撒母耳記上 30:9–10"> 於是，大衛和他的部下約六百人就起身離開基伊拉，到處遷移。有人告訴掃羅，大衛已經逃離基伊拉，掃羅就不下去了。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 54:3–4; 詩篇 32:7; 約書亞記 15:24"> 大衛住在曠野的各個要塞裡，或住在西弗曠野的山地。掃羅天天尋索大衛，神卻不把大衛交在他手中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 大衛知道掃羅已經出來尋索他的性命，那時大衛在西弗曠野的何列什。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 35:3–4; 希伯來書 12:12–13; 約伯記 4:3–4"> 掃羅的兒子約拿單起身去何列什見大衛，勉勵他靠著神堅強，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 20:31; 撒母耳記上 24:20; 使徒行傳 28:16"> 對他說：「不要怕，因為我父親掃羅的手害不了你。你必作以色列的王，我將在你之下位居第二，連我父親掃羅也知道會這樣。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 21:7; 撒母耳記上 20:42; 撒母耳記上 18:3"> 於是他們二人在耶和華面前立約，然後大衛仍住在何列什，而約拿單回自己的家去了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 26:1; 撒母耳記上 26:3; 詩篇 54:1–7"> 西弗人上到基比亞見掃羅，說：「大衛難道不是躲藏在我們這裡，在曠野南邊哈基拉山上的何列什要塞嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:12; 箴言 29:26; 箴言 11:23"> 王啊，你願意什麼時候下來就請下來；至於我們，我們必把他交在王的手中。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 22:8; 以賽亞書 66:5; 彌迦書 3:11"> 掃羅說：「願你們蒙耶和華祝福！因為你們顧惜我。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 5:13"> 請你們去再次確認，察看他的落腳之處，有誰在那裡看到他，因為有人對我說，他非常狡猾。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 3:15–16; 馬可福音 14:1; 民數記 10:36"> 你們要查清他躲藏的所有地方，確定後回來見我，我就與你們一同去。如果他在那地方，我就把他從猶大的千家萬戶中搜出來。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 25:2; 約書亞記 15:55"> 於是西弗人動身，在掃羅之先回西弗去了。<br />那時大衛和他的部下在瑪雲曠野，荒漠南邊的亞拉巴。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 15:8; 撒母耳記上 23:28"> 掃羅和他的部下去尋索大衛，有人告訴大衛，他就下到岩石帶，留在瑪雲曠野。掃羅聽說了，就去瑪雲曠野追趕大衛。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="詩篇 17:9; 哥林多後書 1:8; 詩篇 140:1–9"> 掃羅在山這邊走，大衛和他的部下在山那邊走。大衛慌忙躲避掃羅，掃羅和他的部下要圍困大衛和他的部下，抓住他們。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 19:9; 詩篇 116:3; 申命記 32:36"> 這時有一個使者來告訴掃羅：「請趕快回去，因為非利士人入境搶掠了。」</span>
<span className="v" id="v28" data-v="28"> 於是掃羅返回不追趕大衛，而迎戰非利士人去了。因此那地方被稱為隔斷巖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="隔斷巖——音譯作「西拉-哈瑪希羅結」。">a</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 20:2; 約書亞記 15:62; 以西結書 47:10"> 大衛從那裡上去，住在恩蓋迪的要塞裡。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此節在馬索拉文本為24:1。">b</a></sup></span>
</div>
</div>

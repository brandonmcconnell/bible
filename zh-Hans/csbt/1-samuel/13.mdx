<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:5; 彌迦書 6:6"> 掃羅作王的時候三十<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="三十——依據七十士譯本；馬索拉文本此處缺失年數。">a</a></sup>歲，統治了以色列四十二<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四十二——較多譯本依據《使徒行傳》13:21，補缺此處的年數。馬索拉文本作「兩」。">b</a></sup>年。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 10:26; 撒母耳記上 13:5; 撒母耳記上 14:31"> 掃羅從以色列中為自己挑選了三千人：兩千人跟隨掃羅在米克瑪和伯特利山，一千人跟隨約拿單在便雅憫的基比亞。其餘的人，掃羅就打發他們各回自己的帳篷。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 10:5; 士師記 3:27; 士師記 6:34"> 約拿單攻擊迦巴的非利士駐軍，非利士人聽說了這事。掃羅就在全地吹響號角，說：「要讓希伯來人聽見！」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 34:30; 出埃及記 5:21; 撒迦利亞書 11:8"> 全體以色列人聽說掃羅攻擊了非利士的駐軍，而且以色列人被非利士人厭惡，民眾就聚集到吉甲跟隨掃羅。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 14:23; 約書亞記 11:4; 約書亞記 18:12"> 非利士人聚集起來，要與以色列爭戰，他們有戰車三千<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三千——依據古敘利亞文譯本和其他古希臘譯本；馬索拉文本作「三萬」。">c</a></sup>輛、馬兵六千，人多如海邊的沙。他們上來，在伯亞文東邊的米克瑪紮營。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 6:2; 希伯來書 11:38; 士師記 10:9"> 以色列人看見形勢危急，處境窘迫，軍兵就躲藏在洞穴裡、叢林中、岩石間、地窖裡和坑裡。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 20:8; 利未記 26:17; 民數記 32:1–5"> 有些希伯來人過約旦河到了迦得和基列地；掃羅仍然在吉甲，所有軍兵都戰戰兢兢地跟隨他。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 10:8"> 他按著撒母耳所定的日期等候了七天，但撒母耳還沒有來到吉甲，軍兵也開始離開他散去。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 3:4; 箴言 21:27; 箴言 15:8"> 於是掃羅說：「把燔祭和平安祭帶到我這裡！」他就獻上燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:13; 路得記 2:4; 詩篇 129:8"> 他剛獻完了燔祭，看哪，撒母耳來了。掃羅出去迎接他，要向他問安。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:23; 撒母耳記上 13:5; 撒母耳記上 13:16"> 撒母耳說：「你做了什麼事呢？」<br />掃羅說：「因為我看見軍兵離開我散去，你也沒有按著所定的日子來到，而非利士人聚集在米克瑪，</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 66:3; 阿摩司書 8:5; 哥林多後書 9:7"> 我就想：『現在非利士人就要下到吉甲攻擊我，而我還沒有向耶和華求恩。』於是我迫不得已獻上了燔祭。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 15:22; 歷代志下 16:9; 撒母耳記上 15:28"> 撒母耳對掃羅說：「你做了愚蠢的事！你沒有遵守你的神耶和華所吩咐你的誡命。不然，耶和華就會堅立你在以色列的王權到永遠了；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 13:22; 撒母耳記上 15:28; 詩篇 89:19–37"> 但如今，你的王權不會長久了，耶和華已經為自己找到一個合乎他心意的人，耶和華任命這人作他子民的領袖，因為你不遵守耶和華吩咐你的。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 14:2; 撒母耳記上 13:2; 撒母耳記上 13:6–7"> 撒母耳起身，從吉甲上便雅憫的基比亞去了。掃羅數點留在他那裡的軍兵，約有六百人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 13:3"> 掃羅和他兒子約拿單，以及留在他們那裡的軍兵，駐守在便雅憫的迦巴，而非利士人在米克瑪紮營。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 18:23; 撒母耳記上 14:15; 約書亞記 19:3"> 有突擊隊從非利士人的營地出來，分三隊，一隊轉向俄弗拉的方向前往書亞地，</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 11:34; 約書亞記 18:13–14; 約書亞記 16:3"> 一隊轉向伯賀崙的方向，一隊轉向邊界的方向，那裡能俯看通往曠野的洗波音山谷。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 24:14; 士師記 5:8; 耶利米書 24:1"> 當時在以色列全地找不到一個鐵匠，因為非利士人說：「恐怕希伯來人製造刀劍或長矛。」</span>
<span className="v" id="v20" data-v="20"> 所以，以色列人都下到非利士人那裡去，磨利他們的鋤頭、犁頭、斧頭和鏟子。</span>
<span className="v" id="v21" data-v="21"> 磨鋤頭、犁頭的價錢是三分之二謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三分之二謝克爾——原文作「皮姆」。1皮姆=7.6公克；1謝克爾=11.4公克。">d</a></sup>，磨草叉、斧頭或磨尖刺棒的價錢是三分之一謝克爾<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三分之一謝克爾——相當於3.8公克。">e</a></sup>。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="此節或譯作：磨鋤頭、犁頭、三齒叉、斧頭或磨尖刺棒的價錢是三分之二謝克爾。">f</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:8; 撒迦利亞書 4:6; 撒母耳記上 17:50"> 所以到了爭戰的日子，隨同掃羅和約拿單的所有軍兵手中都沒有刀劍或長矛，只有掃羅和他兒子約拿單有刀槍。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 10:28; 撒母耳記上 14:1; 撒母耳記上 14:4–5"> 那時，非利士的守軍出來，前往米克瑪關口。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 17:1; 撒母耳記上 29:1–3; 撒母耳記上 7:7"> 那時候，非利士人聚集他們的軍兵，合成一支軍隊，要與以色列人爭戰。亞吉對大衛說：「你要確切知道：你和你的部下要隨我出征。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="羅馬書 12:9; 撒母耳記下 16:16–19; 撒母耳記上 27:10"> 大衛對亞吉說：「很好，你會知道僕人能做什麼。」<br />亞吉就對大衛說：「這樣，我必立你終身作我的護衛長。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 19:31; 撒母耳記上 25:1; 利未記 20:27"> 那時撒母耳已經死了，全以色列為他哀哭，把他葬在他本鄉拉瑪。掃羅曾經把招魂的和通靈的從國中驅除了。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 31:1; 約書亞記 19:18; 列王紀下 4:8"> 非利士人聚集，來到書念紮營；掃羅也聚集以色列全軍，在基利波紮營。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 57:20–21; 但以理書 5:6; 以賽亞書 21:3–4"> 掃羅看見非利士的軍營就懼怕，心中大大戰兢。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 12:6; 撒母耳記上 14:37; 耶利米哀歌 2:9"> 掃羅求問耶和華，耶和華卻沒有藉著夢，或烏陵，或先知回應他。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 16:16; 約書亞記 17:11; 歷代志上 10:13"> 掃羅就對他的臣僕們說：「你們為我尋找一個招魂的女巫吧，我好去她那裡求問。」<br />臣僕們對他說：「看哪，在恩多爾有一個招魂的女巫。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:19; 歷代志上 10:13; 列王紀上 22:30"> 於是掃羅喬裝，穿上別的衣服，然後帶著兩個人與他一同前往。他們夜間去見那女人，掃羅說：「請你用招魂術，把我告訴你的人為我招上來。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 28:3; 列王紀下 5:7; 撒母耳記下 18:13"> 那女人對他說：「看哪，你知道掃羅所做的事，他把招魂的和通靈的從國中剪除了。你為什麼對我設下圈套，要害死我呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 14:11; 撒母耳記上 19:6; 申命記 18:10–12"> 掃羅指著耶和華向她起誓說：「我指著耶和華的永生起誓：你必不因這事受到懲罰。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 那女人就問：「我要為你招誰上來呢？」<br />掃羅回答：「為我招撒母耳上來。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 28:3; 列王紀上 14:5"> 那女人看見撒母耳，就大聲哀叫。她對掃羅說：「你為什麼欺騙我呢？你就是掃羅！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:6–7; 約翰福音 10:34–35; 出埃及記 22:28"> 王對她說：「不要害怕。你究竟看見了什麼？」<br />那女人對掃羅說：「我看見有神明從地裡上來。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 15:27; 列王紀下 2:8; 撒母耳記上 24:8"> 掃羅問她：「他是什麼模樣呢？」<br />她回答：「上來的是個老人，披著外袍。」掃羅認為<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="認為——原文直譯「知道」。">a</a></sup>那是撒母耳，就臉伏於地下拜。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:23–26; 撒母耳記上 28:6; 撒母耳記上 18:12"> 撒母耳問掃羅：「你為什麼攪擾我，招我上來呢？」<br />掃羅回答：「我面臨極大的危難：非利士人與我爭戰，神也離開了我，不再藉著先知或夢回應我。所以我召喚你來、指示我該怎麼做。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 6:27; 耶利米哀歌 2:5; 詩篇 68:1–3"> 撒母耳說：「既然耶和華已經離開你，與你為敵，你為什麼還問我呢？</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 15:27–29; 撒母耳記上 16:13; 撒母耳記上 13:13–14"> 耶和華成就了他藉著我所說的話：耶和華從你的手中撕去了王國，賜給了與你鄰近的人——大衛。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 15:9; 列王紀上 20:42; 詩篇 50:21–22"> 因為你沒有聽從耶和華的吩咐，沒有對亞瑪力人施行他烈怒的懲罰<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="施行他烈怒的懲罰——原文直譯「施行他猛烈的怒氣」。">b</a></sup>，因此今天耶和華向你行了這事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 5:5; 耶利米書 28:16–17; 列王紀上 22:20"> 耶和華必將以色列與你一同交在非利士人手中，明天你和你的兒子們就會與我在一起了；耶和華也必將以色列軍兵交在非利士人手中。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 28:5; 約伯記 26:2; 約伯記 15:20–24"> 掃羅立刻整個身體仆倒在地，他因撒母耳的話極其害怕，並且渾身無力，因為他整日整夜都沒有吃東西。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 12:3; 約伯記 13:14; 撒母耳記上 19:5"> 那女人來到掃羅跟前，見他極其惶恐，就對他說：「看哪，你的婢女聽從了你的話；我冒著生命危險，聽從了你對我所說的話。</span>
<span className="v" id="v22" data-v="22"> 現在請你也聽從婢女的話，讓我在你面前擺上一點餅。你吃了，身上有了力氣，才能趕路。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 21:4; 路加福音 24:29; 路加福音 14:23"> 掃羅不肯，他說：「我不吃。」他的臣僕們和那女人再三地勸他，他才聽從了他們的話，從地上起來，坐到床榻上。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:23; 創世記 18:7–8"> 那女人家裡有一頭養肥的牛犢，她趕快把牠宰殺了，又取來麵粉，揉好了，烤成無酵餅，</span>
<span className="v" id="v25" data-v="25"> 帶到掃羅和他的臣僕們面前。他們吃了，就在當天夜裡起身走了。</span>
</div>
</div>

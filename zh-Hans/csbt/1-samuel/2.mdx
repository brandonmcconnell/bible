<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 詩篇 13:5; 以賽亞書 12:2–3"> 那時哈娜禱告說：<br /><span className="pl pl-1">「我的心因耶和華而歡樂，</span><br /><span className="pl pl-1">我的角因耶和華而高舉；</span><br /><span className="pl pl-1">我的口向眾仇敵張大，</span><br /><span className="pl pl-1">因我以你的救恩歡喜。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 22:32; 以賽亞書 44:6; 詩篇 86:8"> <span className="pl pl-1">沒有像耶和華那樣的聖者，</span><br /><span className="pl pl-1">除你以外實在沒有；</span><br /><span className="pl pl-1">沒有磐石像我們的神。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王紀上 8:39; 箴言 24:12"> <span className="pl pl-1">你們不要再說高傲自大的話，</span><br /><span className="pl pl-1">不要讓傲慢的話從你們口中出來，</span><br /><span className="pl pl-1">因為耶和華是全知的神，</span><br /><span className="pl pl-1">人的行為都被他衡量。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 76:3; 詩篇 37:15; 詩篇 46:9"> <span className="pl pl-1">勇士的弓被折斷，</span><br /><span className="pl pl-1">軟弱的卻以力量束腰；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 15:9; 路加福音 1:53; 詩篇 113:9"> <span className="pl pl-1">飽足的為食物受雇，</span><br /><span className="pl pl-1">飢餓的卻不再挨餓；</span><br /><span className="pl pl-1">不能懷孕的生了七個，</span><br /><span className="pl pl-1">兒子眾多的反倒衰敗。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 32:39; 以賽亞書 26:19; 啟示錄 1:18"> <span className="pl pl-1">耶和華使人死，也使人活；</span><br /><span className="pl pl-1">使人下陰間，也使人從那裡上來。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 75:7; 約伯記 5:11; 申命記 8:17–18"> <span className="pl pl-1">耶和華使人貧窮，也使人富有；</span><br /><span className="pl pl-1">使人降卑，也使人升高。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 113:7–8; 但以理書 2:48; 雅各書 2:5"> <span className="pl pl-1">他從塵土中興起貧弱者，</span><br /><span className="pl pl-1">從糞堆中提拔貧窮人，</span><br /><span className="pl pl-1">要使他們與高貴人同坐，</span><br /><span className="pl pl-1">使他們繼承榮耀的寶座；</span><br /><span className="pl pl-1">因為大地的支柱都屬於耶和華，</span><br /><span className="pl pl-1">他把世界安置在其上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 121:3; 詩篇 91:11–12; 詩篇 33:16–17"> <span className="pl pl-1">他必保守他忠信者的腳步，</span><br /><span className="pl pl-1">惡人卻在黑暗中滅亡；</span><br /><span className="pl pl-1">人得勝不是靠著力量。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 2:9; 詩篇 89:24; 詩篇 18:13–14"> <span className="pl pl-1">耶和華必擊碎那些與他抗爭的，</span><br /><span className="pl pl-1">他將從天上打雷攻擊他們。</span><br /><span className="pl pl-1">耶和華必審判地極；</span><br /><span className="pl pl-1">他將賜力量給他所立的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所立的——輔助詞語。">a</a></sup><br /><span className="pl pl-1">王，</span><br /><span className="pl pl-1">使他受膏者的角高舉。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 3:1; 撒母耳記上 2:18; 撒母耳記上 1:28"> 以利加拿一行<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一行——輔助詞語。">b</a></sup>回拉瑪自己的家去了，而那孩子留在祭司以利面前事奉耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 1:28–30; 耶利米書 2:8; 士師記 2:10"> 以利的兩個兒子是卑劣之徒，不尊重<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不尊重——原文直譯「不認識」。">c</a></sup>耶和華，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 7:29–34"> 也不尊重祭司對民眾的規矩。每當有人獻祭，正在煮肉的時候，祭司的僕人就會來，手拿三齒的叉子，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 29:27–28; 以賽亞書 56:11; 撒母耳記上 2:29"> 插入盆或筐子，或大鍋小鍋，叉子插上來的，祭司全都拿去歸自己。他們就是這樣對待所有來到示羅的以色列人。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 3:16; 利未記 3:3–5; 羅馬書 16:18"> 甚至在燒獻脂肪以前，祭司的僕人也會來，對獻祭的人說：「把祭肉交給祭司去烤，他不接受你煮過的肉，他只要生肉。」</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:23–25; 利未記 3:16; 彼得前書 5:2–3"> 如果獻祭的人說「必須先燒獻了脂肪，然後你可以隨意拿」，祭司的僕人就會說「不，你現在就給我，不然我就搶了」。</span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 2:7–9; 創世記 13:13; 瑪拉基書 2:13"> 這兩個年輕祭司的罪在耶和華面前極大，因為他們藐視耶和華的供物。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 3:1; 出埃及記 28:4; 撒母耳記上 2:11"> 當時，撒母耳還是個孩子，穿戴著細麻布的以弗得，在耶和華面前事奉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 1:3; 撒母耳記上 1:21; 出埃及記 23:14"> 他母親每年都會為他做一件小外袍，與丈夫一起上來獻年祭的時候就帶給他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 1:27–28; 路加福音 2:34; 路得記 4:11"> 以利就會祝福以利加拿和他妻子，說：「願耶和華藉著這婦人再賜給你後裔，代替她求來獻給耶和華的這孩子。」然後，他們就回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳記上 3:19; 創世記 21:1"> 耶和華眷顧哈娜，她就懷孕，又生了三個兒子、兩個女兒。那孩子撒母耳在耶和華面前漸漸長大。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 38:8; 撒母耳記上 2:13–17; 耶利米書 7:9–10"> 這時以利已經很老了，他聽說兒子們對以色列眾人所做的一切，還聽說他們與會幕門口服事的婦女們同睡，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 8:12; 腓立比書 3:19; 使徒行傳 9:4"> 就對他們說：「你們為什麼做這樣的事呢？我從這民眾都聽說了你們的惡行。</span>
<span className="v" id="v24" data-v="24" data-xref="瑪拉基書 2:8; 提摩太前書 3:7; 使徒行傳 6:3"> 我兒啊，不要這樣，我所聽見耶和華子民傳來的風聲實在不好。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 3:14; 約書亞記 11:20; 希伯來書 10:26"> 人如果對人犯罪，有神可以為他調解；人如果對耶和華犯罪，有誰能為他調解呢？」但他們不聽從父親的話，因為耶和華定意要他們死。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行傳 2:47"> 那孩子撒母耳的身量，以及耶和華和人對他的喜愛，都不斷增長。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 33:1; 出埃及記 4:27; 出埃及記 4:14–16"> 有一位神人來見以利，對他說：「耶和華如此說：當你的父家在埃及法老手下<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="法老手下——原文直譯「屬於法老的家」。">d</a></sup>的時候，我不是明確向他們顯現了自己嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 28:1; 利未記 8:7–8; 民數記 18:19"> 我不是從以色列所有支派中揀選了他們作我的祭司嗎？我讓他們上我的祭壇燒香，在我面前佩戴以弗得，把以色列子民的各種火祭都賜給了你的父家。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 10:37; 申命記 32:15; 撒母耳記上 2:13–17"> 你們為什麼踐踏我為我的居所指示的祭物和供物呢？你竟尊重你的兒子超過尊重我，又用我子民以色列上好的供物來養肥你們自己。</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:26; 耶利米書 18:9–10; 箴言 3:9–10"> 「因此以色列的神耶和華宣告：<br /><span className="pl pl-1">我確實說過，</span><br /><span className="pl pl-1">你和你的父家</span><br /><span className="pl pl-1">要永遠行在我面前。</span><br /><span className="pl pl-1">但現在，耶和華宣告：絕不會這樣了！</span><br /><span className="pl pl-1">因為尊重我的，我必尊重他；</span><br /><span className="pl pl-1">輕視我的，他必被藐視。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 22:17–20; 列王紀上 2:26–27; 詩篇 37:17"> 「看哪，日子將到，我必砍下你的膀臂和你父家的膀臂，使你家中沒有一個老年人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亞書 8:4; 撒母耳記上 4:11; 詩篇 78:59–64"> 當以色列在各方面蒙福的時候，你卻要看到我居所的危難；你家中永遠不再有老年人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 2:26–27; 列王紀上 1:7; 撒母耳記上 22:21–23"> 你家中沒被我從祭壇前剪除的人，必使你的眼睛衰竭、心裡憂傷；而所有你家中增添的人，都死於壯年。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 4:11; 列王紀上 13:3; 撒母耳記上 4:17"> 那將要臨到你兩個兒子何弗尼和非尼哈的事，就是給你的徵兆：他們二人將在同一天死去。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 7:27; 撒母耳記下 7:11; 列王紀上 11:38"> 「我將為自己興起一位忠實的祭司，他會照著我的心、我的靈行事；我將為他建立一個持久的家室，他必終生行在我受膏者的面前。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 2:27; 瑪拉基書 1:13; 以西結書 44:10–12"> 你家中所有存留的人都將為一錠銀子、一塊餅，來向他下拜，說：『求你給我安排一個祭司的職份，好讓我有塊餅吃。』」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:27; 彌迦書 7:5; 撒母耳記下 1:25–26"> 有一天，掃羅的兒子約拿單對替他拿兵器的年輕人說：「走，我們過到對面非利士的守軍那裡吧！」他卻沒有把這事告訴他的父親。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 13:15–16; 以賽亞書 10:28–29"> 那時掃羅在基比亞的邊界，坐在米磯崙的石榴樹下，隨同他的軍兵約有六百人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 22:20; 撒母耳記上 2:28; 撒母耳記上 4:21"> 其中有佩戴著以弗得的亞希雅。他是亞希突的兒子，亞希突是以迦博的哥哥，是非尼哈的兒子，非尼哈是從前在示羅作耶和華祭司的以利的兒子。當時人們不知道約拿單離開了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 13:23"> 約拿單想要穿過關口到非利士的守軍那裡，關口這邊有一座石峰，那邊也有一座石峰：一座叫播薛，另一座叫西尼；</span>
<span className="v" id="v5" data-v="5"> 一峰在北，與米克瑪相對，一峰在南，與迦巴相對。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 19:26; 羅馬書 8:31; 撒迦利亞書 4:6"> 約拿單對替他拿兵器的年輕人說：「走，我們過到未受割禮之人的守軍那裡吧！或許耶和華會為我們行動，因為無論人多人少，什麼也不能阻礙耶和華施行拯救。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 7:3; 撒迦利亞書 8:23; 撒母耳記上 10:7"> 替他拿兵器的對他說：「你心裡想的一切，你儘管去做吧！只管前行，看哪，我與你同心。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士師記 7:9–14"> 約拿單就說：「看，我們過到他們那裡，讓他們看見我們。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 6:36–40; 創世記 24:13–14"> 如果他們對我們說：『站住，等我們過到你們那裡！』我們就留在原地，不上他們那裡去。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:14; 撒母耳記上 10:7; 士師記 7:11"> 如果他們說：『上我們這裡來！』我們就上去，因為耶和華已經把他們交在我們手中了，這是給我們的徵兆。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:6; 撒母耳記上 14:22; 士師記 6:2"> 於是他們兩人就讓非利士的守軍看見他們。非利士人說：「看，希伯來人從他們躲藏的洞裡出來了！」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 17:43–44; 撒母耳記下 5:24; 士師記 7:15"> 守軍中有人向約拿單和替他拿兵器的喊道：「上我們這裡來，讓我們教訓教訓你們！」<br />約拿單就對拿兵器的說：「跟我上去，因為耶和華已經把他們交在以色列手中了。」</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 8:31; 約書亞記 23:10; 利未記 26:7–8"> 約拿單手腳並用爬了上去，替他拿兵器的跟在後面。非利士人在約拿單面前仆倒，拿兵器的跟在後面殺死他們。</span>
<span className="v" id="v14" data-v="14"> 約拿單和替他拿兵器的發起第一次攻擊，在大約二十公畝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二十公畝——原文作「半茨梅德」；1茨梅德=4,047平方公尺，是一對耕牛一日的犁地面積。">a</a></sup>地的範圍內，擊殺了約有二十人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 13:17; 創世記 35:5; 撒母耳記下 5:24"> 於是，營地和郊外的所有軍兵，一片恐慌，守軍和突擊隊都戰兢，大地也顫抖，這是從神而來的恐慌。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 20:22–25; 以賽亞書 19:2; 士師記 7:22"> 在便雅憫的基比亞，掃羅的守望兵觀看，看哪，敵軍潰散，四處奔逃。</span>
<span className="v" id="v17" data-v="17"> 掃羅就對那些隨同他的軍兵說：「你們現在數點一下，看看誰從我們這裡離開了。」他們數點，就發現約拿單和替他拿兵器的不在。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 30:7–8; 撒母耳記上 5:2; 士師記 20:23"> 掃羅對亞希雅說：「把神的約櫃帶來！」當時神的約櫃與以色列子民在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 14:24; 民數記 27:21; 約書亞記 9:14"> 掃羅正對祭司說話的時候，非利士營地中的喧囂越來越大，掃羅就對祭司說：「停手吧！」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 7:22; 歷代志下 20:23; 撒母耳記上 14:16"> 掃羅和隨同他的全體軍兵都集合，來到戰場，看哪，非利士人彼此刀劍相向，有極大的騷亂。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 29:4; 士師記 7:23"> 那些以前歸順非利士人、與他們一起上到周圍敵營的希伯來人，現在回來與那些隨同掃羅和約拿單的以色列人在一起了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 13:6; 撒母耳記上 31:7"> 躲藏在以法蓮山地的所有以色列人，聽說非利士人逃跑了，也都到戰場上追擊敵人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 14:30; 撒母耳記上 13:5; 詩篇 44:6–8"> 那一天，耶和華拯救了以色列人。 掃羅輕率的誓言<br />戰爭延伸到伯亞文。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 6:26; 羅馬書 10:2; 士師記 1:28"> 那天以色列人的處境窘迫，因為掃羅讓軍兵起過誓說：「在我報復了仇敵以先、在傍晚之前吃東西的人是受詛咒的！」所以軍兵中沒有一個人吃東西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="吃東西——原文直譯「嘗食物」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 3:8; 民數記 13:27; 申命記 9:28"> 那整個地方，進入森林，地面上都有蜂蜜。</span>
<span className="v" id="v26" data-v="26" data-xref="傳道書 9:2"> 當軍兵進入森林，看哪，有蜂蜜流淌，但沒有人用手取蜜放入嘴裡，因為他們害怕所起的誓。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 14:29; 撒母耳記上 14:43; 撒母耳記上 30:12"> 而約拿單沒有聽見他父親讓軍兵起誓，所以他伸出手裡的杖，把杖尖蘸在有蜜的蜂巢裡，然後用手取蜜放入嘴裡，眼睛就明亮了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 14:43; 撒母耳記上 14:24"> 軍兵中有人告訴他說：「你父親讓大家鄭重起誓說：『今天吃東西的人，是受詛咒的！』所以軍兵就疲乏了。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:18; 約書亞記 7:25"> 約拿單說：「我父親給國家帶來了困擾。你們看，我嘗了一點這蜂蜜，眼睛就明亮了。</span>
<span className="v" id="v30" data-v="30" data-xref="傳道書 9:18"> 如果今天軍兵能隨意吃從仇敵奪來的東西，那該多好！現在被擊殺的非利士人不就更多了嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 10:12; 約書亞記 19:42"> 那天他們擊殺非利士人，從米克瑪直到阿雅崙，軍兵非常疲乏。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 15:19; 利未記 3:17; 利未記 17:10–14"> 軍兵衝向戰利品，取來羊、牛和牛犢，在地上宰殺，然後軍兵們帶著血就吃了。</span>
<span className="v" id="v33" data-v="33" data-xref="羅馬書 2:1; 馬太福音 7:5"> 有人報告掃羅說：「看哪，人們在吃帶血的肉，對耶和華犯罪了。」<br />掃羅說：「你們背信了！現在把一塊大石頭滾到我這裡來！」</span>
<span className="v" id="v34" data-v="34"> 他又說：「你們分散開來，到軍兵中去吩咐他們：各人要把自己的牛羊牽到我這裡來，在這裡宰殺了吃；不可對耶和華犯罪去吃帶血的肉。」於是那夜，所有軍兵都把各自手裡的牛牽來，在那裡宰殺了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 7:17; 撒母耳記上 7:12; 提摩太後書 3:5"> 之後掃羅為耶和華築了一座祭壇，這是他為耶和華築的第一座祭壇。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 48:1–2; 詩篇 73:28; 瑪拉基書 2:7"> 掃羅說：「我們要趁夜下去追趕非利士人，掠奪他們直到天亮，不讓他們一人存留。」<br />軍兵說：「你看怎樣好就怎樣做吧！」<br />但祭司說：「讓我們在這裡求問<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="求問——原文直譯「親近」。">c</a></sup>神。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 28:6; 撒母耳記上 30:7–8; 撒母耳記上 23:9–12"> 掃羅就求問神：「我可以下去追趕非利士人嗎？你會把他們交在以色列人手中嗎？」那一天，神沒有回應他。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="士師記 20:2; 約書亞記 7:14–26; 民數記 24:17"> 掃羅說：「所有軍兵的首領，你們都上這裡來，要察看今天這罪是怎麼發生的！</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 14:44; 撒母耳記下 12:5; 撒母耳記上 14:24"> 我指著拯救以色列的耶和華的永生起誓：即使罪在我的兒子約拿單，他也必須死！」全體軍兵中沒有人回應他。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 15:15; 撒母耳記上 14:7; 撒母耳記上 14:36"> 他對全體以色列人說：「你們站在這一邊，我和我兒子約拿單在那一邊。」<br />軍兵對掃羅說：「你看怎樣好就怎樣做吧！」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 1:24; 約書亞記 7:16–18; 撒母耳記上 10:20–21"> 掃羅對以色列的神耶和華說：「求你指明正確的抽籤結果！」於是約拿單和掃羅被抽中，軍兵都脫罪了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 掃羅說：「在我和我兒子約拿單之間抽籤吧。」結果約拿單被抽中了。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 7:19; 撒母耳記上 14:27; 約拿書 1:7–10"> 掃羅對約拿單說：「告訴我，你做了什麼？」<br />約拿單就告訴他說：「我只是用手杖尖蘸了一點蜂蜜吃，我這樣就必須死嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒母耳記上 14:39; 路得記 1:17; 撒母耳記上 25:22"> 掃羅說：「約拿單，你必須死，否則願神處置我，重重地處置我！」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 21:18; 使徒行傳 27:34; 撒母耳記下 14:11"> 軍兵對掃羅說：「約拿單為以色列成就了這樣大的拯救，怎麼可以死呢？絕對不可！我們指著耶和華的永生起誓：連他的一根頭髮也不可落在地上！因為他今天是與神一同行事。」這樣，人們救了約拿單，他就免於一死；</span>
<span className="v" id="v46" data-v="46"> 掃羅回去，不再追趕非利士人，非利士人也回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳記下 10:6; 撒母耳記上 14:52; 撒母耳記下 8:3"> 掃羅得了以色列的王位，攻打四圍一切仇敵，攻打摩押人、亞捫人、以東人、瑣巴的眾王和非利士人，凡他所到之處盡都征服。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及記 17:14; 撒母耳記上 15:3–7; 申命記 25:19"> 他作戰英勇，擊敗了亞瑪力人，解救以色列人脫離搶掠他們之人的手。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="歷代志上 8:33; 撒母耳記上 31:2; 撒母耳記下 6:20–23"> 掃羅的兒子是約拿單、伊施韋和麥基舒亞。他有兩個女兒，大的名叫米拉，小的名叫米甲。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳記下 2:8; 撒母耳記上 17:55; 撒母耳記下 3:27"> 掃羅的妻子名叫婭希暖，是亞希瑪斯的女兒。他的元帥名叫押尼珥，是掃羅的叔叔尼珥的兒子；</span>
<span className="v" id="v51" data-v="51" data-xref="撒母耳記上 9:1; 撒母耳記上 9:21"> 掃羅的父親基士和押尼珥的父親尼珥都是亞比耶的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="撒母耳記上 8:11; 撒母耳記上 8:1"> 掃羅一生的日子常與非利士人發生激烈的戰爭。掃羅遇見任何有能力的人或英勇的人，都會招聚到他那裡。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 10:24; 撒母耳記上 11:14–15; 撒母耳記上 10:1"> 撒母耳對全體以色列人說：「看哪，我已經聽從了你們的話，聽從了你們對我說的一切，立了一個王統治你們。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 8:5; 撒母耳記上 8:1; 撒母耳記上 8:20"> 看哪，現在有這王帶領你們了。至於我，我已經年老髮白；而我的兒子們在這裡與你們在一起。我從年輕時到今天一直帶領你們。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 20:33; 民數記 16:15; 彼得前書 5:2"> 看哪，你們可以在耶和華和他的受膏者面前指證我：我奪取過誰的牛，奪取過誰的驢子？我欺壓過誰，壓迫過誰？又從誰的手中收取過賄賂，以致我的眼睛被蒙住了？如果是這樣，我必歸還給你們。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理書 6:4; 詩篇 37:5–6; 約翰三書 1:12"> 他們說：「你沒有欺壓過我們，沒有壓迫過我們，也沒有從任何人手中收取過什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:4; 使徒行傳 24:20; 使徒行傳 23:9"> 撒母耳對他們說：「今天，耶和華在你們中間作見證，他的受膏者也作見證：你們在我的手中沒有找到什麼。」<br />他們說：「願他作見證！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="彌迦書 6:4; 出埃及記 6:26; 詩篇 99:6"> 撒母耳接著對民眾說：「是耶和華指定了摩西和亞倫，把你們的祖先從埃及地帶了上來。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:18; 彌迦書 6:1–5; 使徒行傳 17:3"> 所以，現在你們要站好，我要在耶和華面前與你們講論耶和華向你們和你們祖先所行的一切公義。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:14–16; 出埃及記 2:23–24; 詩篇 78:54–55"> 「雅各來到了埃及，後來你們的祖先向耶和華哀求，耶和華就派遣摩西和亞倫，把你們的祖先從埃及領出來，安置在這個地方。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:1; 士師記 10:7; 士師記 3:12"> 然而他們卻忘掉了耶和華他們的神，因此神把他們交於<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="交於——原文直譯「賣到」。">a</a></sup>哈佐的元帥西西拉的手中，交於非利士人和摩押王的手中，這些人就攻打他們。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 10:10; 士師記 2:13; 士師記 3:7"> 他們向耶和華哀求，說：『我們犯了罪，我們離棄了耶和華，服事眾巴力和亞斯她錄。現在求你解救我們脫離仇敵的手，我們要服事你。』</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 6:32; 士師記 4:6; 士師記 8:35"> 於是耶和華派遣了耶路巴力、比丹<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="比丹——七十士譯本和古敘利亞文譯本作「巴拉克」。">b</a></sup>、耶弗塔、撒母耳。耶和華解救你們脫離四圍仇敵的手，你們就安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 8:23; 撒母耳記上 8:5–7; 創世記 17:7"> 可是當你們看到亞捫人的王納哈什來攻擊你們，就對我說：『不，我們必須要一個王統治我們。』其實你們的神耶和華就是你們的王。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="何西阿書 13:11; 撒母耳記上 10:24; 撒母耳記上 8:5"> 「現在你們所選擇、所要求的王在這裡，看哪，耶和華已經立了一個王統治你們。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 24:14; 申命記 28:1–14; 詩篇 81:12–15"> 如果你們敬畏耶和華、服事他、聽從他的話、不違背耶和華的命令，那麼統治你們的王必與你們跟隨耶和華你們的神。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 24:20; 以賽亞書 1:20; 以賽亞書 3:11"> 但如果你們不聽從耶和華的吩咐，違背耶和華的命令，耶和華的手就會對付你們，像對付你們的祖先一樣。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 14:13; 出埃及記 14:31; 撒母耳記上 12:7"> 「現在你們要站好，觀看耶和華將在你們眼前行的大事。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 8:7; 箴言 26:1; 撒母耳記上 7:9–10"> 今日不是收割小麥的時候嗎？我向耶和華呼求，他就會降下雷雨。這樣你們就會知道並看見你們為自己要求一個王，在耶和華眼中是行了極大的惡事！」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:31; 以斯拉記 10:9; 詩篇 106:12–13"> 於是撒母耳向耶和華呼求，耶和華就在那日降下雷雨，全體民眾都非常懼怕耶和華和撒母耳。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 9:28; 約翰一書 5:16; 撒母耳記上 12:23"> 全體民眾對撒母耳說：「求你為僕人們向你的神耶和華禱告，免得我們死亡。因為在我們的一切罪惡上，我們又增添了一件惡事，為自己要求一個王。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 11:16; 約書亞記 23:6; 彼得前書 3:16"> 撒母耳對民眾說：「不要害怕。你們雖然做了這一切惡事，但不要偏離耶和華不跟隨他，而要全心服事耶和華；</span>
<span className="v" id="v21" data-v="21" data-xref="哈巴谷書 2:18; 耶利米書 10:15; 耶利米書 16:19"> 不要偏離耶和華去追隨那些虛無之神——它們不能使人得益處、也不能解救人，只是虛無之物。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:7–8; 申命記 14:2; 詩篇 106:8"> 要知道，耶和華為他大名的緣故，必不會撇棄他的子民，因為耶和華願意你們作他的子民。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:9; 羅馬書 1:9; 提摩太後書 1:3"> 「至於我，我絕不會停止為你們禱告而得罪耶和華，我必指教你們那美善、正直的道路。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 10:21; 箴言 1:7; 以賽亞書 5:12"> 只是你們要敬畏耶和華，誠實地全心服事他——你們看，他為你們做了何等大的事！</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 24:20; 何西阿書 10:3; 撒母耳記上 31:1–5"> 如果你們繼續作惡，無論是你們還是你們的王，都必被除滅。」</span>
</div>
</div>

</div>

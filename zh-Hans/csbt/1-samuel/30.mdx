<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 15:7; 撒母耳記上 29:11; 撒母耳記上 27:8–10"> 第三天，大衛和他的部下回到洗革拉的時候，亞瑪力人已經侵襲了南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音譯作「內蓋夫」；本章下同。">a</a></sup>和洗革拉。亞瑪力人攻入洗革拉，放火燒毀了它，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 27:11; 約伯記 38:11; 詩篇 76:10"> 又把城裡的女人和其餘所有人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="和其餘所有人——依據七十士譯本。">b</a></sup>，無論老少，都擄走了；他們沒有殺任何人，而是帶著人上路走了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="詩篇 34:19; 彼得前書 1:6–7; 啟示錄 3:9"> 大衛和他的部下回到那城，看哪，城已經被火燒毀，他們的妻子、兒女都被擄走了。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 11:4; 民數記 14:1; 士師記 21:2"> 大衛和隨同他的人就放聲大哭，直哭到沒有力氣。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 25:42–43; 撒母耳記下 2:2; 撒母耳記上 1:2"> 大衛的兩個妻子，耶斯列人婭希暖和迦密人納巴爾的遺孀婭比蓋，也被擄走了。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 56:3–4; 詩篇 56:11; 詩篇 62:5"> 那時大衛處境十分危急，因為人們都說要用石頭砸死他，所有人都為自己的兒女心中苦痛；但大衛靠著他的神耶和華堅強。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 2:26; 撒母耳記上 22:20–21; 撒母耳記上 23:2–9"> 大衛對亞希米勒的兒子祭司亞比亞特說：「請把以弗得帶到我這裡來。」亞比亞特就把以弗得帶到大衛那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:18; 箴言 3:5–6; 撒母耳記上 23:2"> 大衛求問耶和華說：「我該去追趕這些匪徒嗎？我能追上他們嗎？」<br />耶和華回答他：「去追趕，你必定追上，必定把一切救回來。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 27:2"> 於是大衛和隨同他的六百人出發了。他們來到比梭溪谷，那些跟不上的就留了下來。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 30:9; 撒母耳記上 30:21; 撒母耳記上 14:31"> 大衛和四百人繼續追趕，那兩百個人疲乏不能過比梭溪谷，就留在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 12:20–21; 申命記 23:7; 馬太福音 25:35"> 他們在曠野中發現了一個埃及人，就把他帶到大衛那裡，給他東西吃，給他水喝。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 15:19; 撒母耳記上 14:27; 撒母耳記上 30:13"> 他們給了他一塊無花果餅、兩個葡萄餅，他吃了，就恢復了精神。他已經三天三夜沒有吃東西，沒有喝水了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各書 2:13; 箴言 12:10; 約伯記 31:13–15"> 大衛問他：「你屬於誰？你從哪裡來？」<br />他回答：「我是個埃及少年，是亞瑪力人的奴僕。因為我三天前病了，我主人撇棄了我。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 1:38; 撒母耳記下 8:18; 列王紀上 1:44"> 我們侵襲了基利提的南地和屬於猶大的地方，以及迦勒的南地，並且放火燒毀了洗革拉。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 2:12; 約書亞記 9:19–20; 以西結書 17:16"> 大衛問他：「你願意帶我下到匪徒那裡嗎？」<br />他回答：「如果你指著神向我起誓，絕不殺我，也絕不把我交在我主人手中，我就帶你下到匪徒那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:10–13; 撒母耳記下 13:28; 士師記 16:23–30"> 於是他帶大衛下去。看哪，他們分散在那整片地上，吃喝慶祝，因他們從非利士人之地和猶大地擄掠了大量的各樣戰利品。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 11:11; 詩篇 18:42; 撒母耳記上 15:3"> 大衛擊殺他們，從黃昏直到第二天傍晚；他們當中除了四百個騎駱駝的年輕人逃跑了以外，再沒有一個人逃脫。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 14:16"> 大衛奪回了亞瑪力人所擄掠的一切，也救回了他的兩個妻子。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:9–10; 撒母耳記上 30:8; 約伯記 1:10"> 無論老少，兒子或女兒，無論掠物或被帶走的一切，都沒有缺失，大衛全都奪回來了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 30:26; 民數記 31:9–12; 歷代志下 20:25"> 大衛也擄掠了亞瑪力人所有的羊群和牛群；人們把這些驅趕在原有的牲畜前面，說：「這些是大衛的戰利品。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:1; 撒母耳記上 30:10; 士師記 8:15"> 大衛來到那兩百個因疲乏不能跟隨而留在比梭溪谷的人那裡，他們出來迎接大衛和隨同他的人。大衛走近他們，向他們問安。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:12; 申命記 13:13; 列王紀上 21:10"> 與大衛一起去的人中，所有的惡人和卑劣之徒都議論說：「既然他們沒有與我們一起去，就不要把我們奪取的戰利品分給他們。只讓他們把各自的妻子、兒女帶走。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 8:18; 詩篇 44:2–7; 使徒行傳 7:2"> 但大衛說：「我的兄弟們，你們不可這樣處理耶和華所賜給我們的，他保守了我們，把那些來攻擊我們的匪徒交在我們手中。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 22:8; 民數記 31:27; 詩篇 68:12"> 關於這事，誰會聽你們的呢？出戰的人怎樣得份，留下看守輜重的人也怎樣得份，要同等分配。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 16:13"> 從那天以後，大衛就把這定為以色列的律例和法規，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 25:27; 創世記 33:11; 以賽亞書 32:8"> 大衛回到洗革拉，把一部分戰利品送給他的朋友——猶大的長老們，說：「看哪，這是給你們的禮物，是從耶和華的仇敵奪來的戰利品。」</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 15:48; 約書亞記 19:8; 士師記 1:22–23"> 他把禮物送給了那些在伯特利、南地拉莫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地拉莫——音譯作「拉莫-內蓋夫」。">c</a></sup>、雅提珥、</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 13:16; 約書亞記 15:50; 約書亞記 21:14"> 亞羅珥、希弗莫、以實提莫、</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:16; 撒母耳記上 27:10; 撒母耳記上 15:6"> 拉哈勒、耶拉米列人各城、基尼人各城、</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 1:17; 約書亞記 19:4; 約書亞記 15:42"> 霍爾瑪、博拉珊、阿嗒克、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 2:1; 撒母耳記下 15:10; 撒母耳記下 4:1"> 希伯崙，以及大衛和部下所到之處的長老們。</span>
</div>
</div>

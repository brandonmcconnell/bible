<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:18–19; 提摩太前書 5:21; 尼希米記 7:2"> 撒母耳年老的時候，立他的兒子們作以色列的士師。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 6:38; 創世記 22:19; 歷代志上 6:28"> 他的長子名叫約珥，次子名叫亞比雅，他們在比爾-謝巴作士師。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:19; 詩篇 15:5; 提摩太前書 6:10"> 他的兒子們沒有走他的道路，反而貪圖私利，收取賄賂，屈枉公正。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 7:17; 撒母耳記下 5:3; 出埃及記 3:16"> 於是以色列的長老都聚集到拉瑪見撒母耳，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 17:14–15; 何西阿書 13:10–11; 撒母耳記上 8:6–8"> 對他說：「看哪，你老了，你的兒子們又不走你的道路，所以請你為我們立一個王來治理我們，像其他國家那樣。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 15:11; 雅各書 1:5; 撒母耳記上 12:17"> 他們說「請為我們立一個王來治理我們」，這話讓撒母耳很愁煩，他就向耶和華禱告。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 撒母耳記上 10:19; 出埃及記 16:8"> 耶和華對撒母耳說：「你就聽從民眾對你說的一切話。其實他們不是厭棄你，而是厭棄我作他們的王。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:34–40; 出埃及記 32:1; 士師記 13:1"> 自從我帶他們出埃及的那天起直到今日，他們離棄我，服事別的神——他們怎樣對我做這一切，現在也怎樣對你做。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 10:25; 撒母耳記上 8:11–18; 以西結書 46:18"> 所以你要聽從民眾的話，但一定要嚴厲地警誡他們，告訴他們那將要統治他們的王，會用什麼方法統治他們。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 於是撒母耳把耶和華的一切話，都轉述給那些要求他立王的民眾。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 14:52; 申命記 17:14–20; 撒母耳記上 10:25"> 他說：「那將要統治你們的王，會用以下的方法統治你們：他將奪走你們的兒子，分配他們作戰車兵和馬兵，奔跑在他的戰車前；</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 22:7; 列王紀上 4:7; 歷代志上 27:1–22"> 又立他們作千夫長、五十夫長，耕耘他的土地、收割他的莊稼，為他製造兵器和戰車上的器械。</span>
<span className="v" id="v13" data-v="13"> 他將奪走你們的女兒作調香師、厨師和烘焙師。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 46:18; 列王紀上 21:7; 列王紀上 21:19"> 他將奪走你們上好的田地、葡萄園和橄欖園，給他的臣僕們。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 1:3; 以賽亞書 39:7; 創世記 37:36"> 他將收取你們穀物和葡萄園收成的十分之一，給他的內臣和臣僕們。</span>
<span className="v" id="v16" data-v="16"> 他將帶走你們的男僕和婢女、你們優秀的青年人以及你們的驢子，為他做工。</span>
<span className="v" id="v17" data-v="17"> 他將收取你們羊群的十分之一，連你們自己也將作他的奴僕。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 3:4; 以賽亞書 1:15; 箴言 1:25–28"> 到那日，你們必因自己所選擇的王而哀叫，但那時耶和華不會回應你們。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 44:16; 耶利米書 7:13; 以賽亞書 66:4"> 然而，民眾不肯聽從撒母耳的話，他們說：「不，必須有一個王來統治我們！</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 8:5; 詩篇 106:35; 申命記 7:6"> 我們也要像其他國家那樣，有自己的王治理我們，率領我們出征，為我們作戰。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 11:11"> 撒母耳聽了民眾的一切話，就把這些話轉述給耶和華聽。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 8:7; 何西阿書 13:11"> 耶和華對撒母耳說：「你就聽從民眾的話，給他們立一個王。」<br />於是撒母耳對以色列人說：「你們各回自己的城去吧。」</span>
</div>
</div>

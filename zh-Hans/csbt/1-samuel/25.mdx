<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 28:3; 民數記 20:29; 申命記 34:8"> 撒母耳死了，全以色列聚集哀悼他，把他葬在拉瑪他的家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——或譯作「墓穴」。">a</a></sup>。之後大衛動身，下到帕蘭曠野去。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="創世記 38:13; 撒母耳記上 23:24; 約書亞記 15:55"> 在瑪雲有一個人，他的產業在迦密。那人非常富有，有綿羊三千隻，山羊一千隻，那時他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以賽亞書 32:5–7"> 那人名叫納巴爾，他的妻子名叫婭比蓋。這女人既有美好的見識，又身材秀美；而她的男人既頑梗，又行事凶惡。他是迦勒族的人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 38:13; 撒母耳記下 13:23"> 大衛在曠野聽說納巴爾正在剪羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 43:23; 撒母耳記上 17:22"> 就派遣十個僕人，對那些僕人說：「你們上迦密去見納巴爾，提我的名向他問安。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 歷代志上 12:18; 詩篇 122:7"> 你們要如此說：『願你長壽！願你平安！願你的家平安！願屬於你的一切都平安！</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 25:21; 撒母耳記上 25:15–16; 撒母耳記上 22:2"> 我聽說現在有人在為你剪羊毛。你的牧人與我們在一起時，我們沒有欺負過他們；他們在迦密的所有日子，也沒有丟失過什麼東西。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 9:19; 尼希米記 8:10–12; 路加福音 14:12–14"> 你問一問你的僕人，他們就會告訴你。願我派去的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我派去的——輔助詞語。">b</a></sup>這些僕人在你眼前蒙恩，因為我們是在喜慶的日子來的。請你隨手拿點什麼，賜給你的僕人們和你兒子大衛。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 2:15; 歷代志下 14:7; 創世記 8:4"> 大衛的僕人們到了，就提大衛的名對納巴爾說了這一切話，然後在那裡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="在那裡——輔助詞語。">c</a></sup>等候。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 9:28; 以賽亞書 32:7; 撒母耳記上 22:7–8"> 納巴爾回應大衛的僕人們說：「大衛是誰？耶西的兒子是誰？如今從主人那裡逃走的僕人很多。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 8:6; 加拉太書 6:10; 哥林多後書 6:9"> 我能拿我的餅、我的水，以及我為那些剪羊毛之人宰殺的肉，給我不知道來自哪裡的人嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 36:21–22; 撒母耳記下 24:13; 希伯來書 13:17"> 於是大衛的僕人們轉身上路回去了。他們來到大衛那裡，把這一切話都告訴了他。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 23:13; 箴言 25:8; 撒母耳記上 24:5–6"> 大衛對他的部下說：「各人佩上刀劍！」每個人就佩上刀劍，大衛也佩上刀劍。約有四百人跟著大衛上去，兩百人留下看守輜重。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 13:10; 馬可福音 15:29"> 納巴爾的僕人中有一個年輕人告訴納巴爾的妻子婭比蓋說：「看哪，大衛從曠野派遣使者來向我們的主人問安，主人卻辱罵了他們。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:7; 撒母耳記上 25:21; 腓立比書 2:15"> 其實那些人對我們非常好，我們在田野與他們往來的所有日子，沒有受過他們欺負，也沒有丟失過什麼東西。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 1:10; 出埃及記 14:22; 撒迦利亞書 2:5"> 我們在他們附近牧羊的所有日子，無論黑夜白天，他們都是我們四圍的屏障。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 20:7; 申命記 13:13; 撒母耳記上 20:9"> 現在請你想好，看看該做什麼，因為禍患一定會臨到我們主人和他的全家。他是個惡劣的人，無法與他說話。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 16:1; 馬太福音 5:25; 箴言 6:4–5"> 婭比蓋趕快取來兩百個餅、兩皮袋酒、五隻預備好的羊、五斗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五斗——原文作「五細亞」；相當於36公升。1細亞=7.3公升。">d</a></sup>烤麥子、一百個葡萄餅、兩百個無花果餅，都放在驢背上，</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 32:20; 創世記 32:16; 箴言 31:11–12"> 然後對僕人們說：「你們在我前面先走，看哪，我跟在你們後面。」但她沒有告訴丈夫納巴爾。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 4:24"> 婭比蓋騎著驢，正從山坡下來，看哪，大衛和他的部下也正迎著婭比蓋下來，她就迎上他們。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所書 4:31; 羅馬書 12:21"> 此前大衛曾說：「我在曠野守護這人的一切，使他沒有丟失過任何東西，實在是枉然的！他竟對我以惡報善。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 14:10; 撒母耳記上 20:13; 撒母耳記上 3:17"> 如果我留下屬於這人的任何一個男丁<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="男丁——原文直譯「對著牆撒尿的」。">e</a></sup>到早晨，就願神處置大衛<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="大衛——依據七十士譯本；馬索拉文本作「大衛的仇敵」。">f</a></sup>，重重地處置！」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:41; 士師記 1:14; 約書亞記 15:18"> 婭比蓋看見大衛，就趕快從驢子上下來，在大衛面前臉伏於地下拜。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖記 8:3; 撒母耳記上 25:28; 撒母耳記下 14:9"> 婭比蓋俯伏在大衛腳前，說：「我主啊，願這罪責歸於我！請容許你的女僕向你說話，求你聽女僕的話：</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 25:17; 瑪拉基書 2:2; 撒母耳記下 13:33"> 請我主不要把這惡劣人納巴爾放在心上，因為他的名字怎樣，他的為人也怎樣；他的名字是納巴爾，愚頑也伴隨著他；我——你的女僕並沒有看見我主所派來的僕人們。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 18:32; 羅馬書 12:19–20; 創世記 20:6"> 現在，我主啊，我指著耶和華的永生和你的生命起誓：耶和華阻止了你流人的血，阻止了你親手報仇。願你的仇敵和那些謀害我主的人都像納巴爾一樣！</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 33:11; 撒母耳記上 30:26; 列王紀下 5:15"> 現在，請把婢女給我主帶來的這些禮物賜給跟隨我主的僕人們。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 18:17; 撒母耳記下 7:11; 撒母耳記上 24:11"> 求你饒恕女僕的過犯！耶和華必定為我主建立一個持久的家室，因為我主是為耶和華爭戰；在你一生的日子裡，在你身上必找不到任何過犯。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰福音 17:21; 馬太福音 10:29–30; 瑪拉基書 3:17"> 「即使有人起來追趕你，尋索你的性命，我主的性命卻必裹藏在你的神耶和華生命的囊中。至於你仇敵的性命，耶和華必甩出去，像從投石索的兜囊中甩出去那樣。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 13:14; 詩篇 89:20; 撒母耳記上 23:17"> 當耶和華成就他向我主所應許的一切福份，任命你作以色列領袖的時候，</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 40:14; 羅馬書 12:19; 路加福音 23:42"> 我主就不會因無故殺人流血、親手報仇而心裡內疚、良心受責備。耶和華賜福我主的時候，求你記念你的女僕。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及記 18:10; 詩篇 72:18"> 大衛對婭比蓋說：「以色列的神耶和華是當受頌讚的！因他今天派遣了你來迎接我。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 25:26; 箴言 28:23; 箴言 9:9"> 你的見識是當受稱讚的，你也當受稱讚，因為你今天阻止了我流人的血，阻止了我親手報仇。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 11:11; 撒母耳記上 25:26; 約書亞記 10:6"> 我指著那阻止我加害你的以色列之神耶和華的永生起誓：要不是你趕來迎接我，到早晨天亮時，屬於納巴爾的男丁<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="男丁——原文直譯「對著牆撒尿的」。">g</a></sup>一個也不會存留！」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 19:21; 撒母耳記上 20:42; 列王紀下 5:19"> 大衛從婭比蓋手中接受了她帶來的東西，對她說：「平平安安地回家去吧！看，我已經聽了你的話，顧及了你的情面。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 25:19; 撒母耳記下 13:23; 撒母耳記下 13:28"> 婭比蓋回到納巴爾那裡，看哪，他在家裡擺設宴席，像王的宴席一樣。納巴爾心情好，醉得很厲害，所以婭比蓋無論大事小事都沒有告訴他，直到早晨天亮。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命記 28:28; 撒母耳記上 25:34; 撒母耳記上 25:22"> 到了早晨，納巴爾酒醒後，他的妻子把這些事告訴他，他就失去了意識<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="他就失去了意識——原文直譯「他的心就在他裡面死了」。">h</a></sup>，身體變得硬如石頭。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記上 26:10; 列王紀下 15:5; 撒母耳記上 6:9"> 大約過了十天，耶和華打擊納巴爾，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 25:26; 撒母耳記上 25:34; 箴言 22:23"> 大衛聽說納巴爾死了，就說：「耶和華是當受頌讚的！他為我伸了冤，除去了納巴爾<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="納巴爾——原文直譯「納巴爾的手」。">i</a></sup>加給我的羞辱，也攔阻了僕人行惡；耶和華使納巴爾的惡歸到他自己頭上。」<br />大衛派人去對婭比蓋說，要娶她為妻。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 24:51; 創世記 24:37–38"> 大衛的僕人們來到迦密見婭比蓋，告訴她說：「大衛派遣我們到你這裡來，要迎娶你作他的妻子。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="提摩太前書 5:10; 約翰福音 13:3–5; 路得記 2:10"> 婭比蓋就起來，臉伏於地下拜，說：「看哪，你的女僕願意作婢女，為我主的僕人洗腳。」</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 24:61–67; 詩篇 45:10–11"> 婭比蓋急忙動身，騎上驢子，帶著五個侍候她的使女，跟著大衛的使者們去，作了大衛的妻子。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="撒母耳記上 30:5; 約書亞記 15:56; 撒母耳記上 27:3"> 大衛先前娶了耶斯列人婭希暖，她與婭比蓋都作了大衛的妻子；</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記下 3:14; 撒母耳記上 18:27; 撒母耳記上 18:20"> 那時，掃羅已經把他的女兒米甲，就是大衛的妻子，嫁給了迦琳人拉伊的兒子帕爾提。</span>
</div>
</div>

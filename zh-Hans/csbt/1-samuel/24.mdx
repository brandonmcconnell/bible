<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 23:28–29; 以西結書 22:9; 撒母耳記上 23:19"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在馬索拉文本為24:2至24:23。">a</a></sup>掃羅追擊非利士人回來的時候，有人告訴他說：「看哪，大衛在恩蓋迪曠野。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 26:2; 詩篇 104:18; 詩篇 37:32"> 掃羅就帶著全以色列中的三千精兵，前往野山羊磐石東邊去尋索大衛和他的部下。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:24; 詩篇 57:1–11; 詩篇 142:1–7"> 來到路旁的羊圈時，那裡有一個洞穴，掃羅進去解手，那時大衛和他的部下正在<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="正在——或譯作「坐在」。">b</a></sup>洞穴的深處。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 26:8–11; 撒母耳記上 24:10; 撒母耳記上 26:23"> 大衛的部下對他說：「耶和華曾對你說：『看哪，我要將你的仇敵交在你手中，你可以按你看為好的對待他。』看，今天就是了！」於是大衛起來，悄悄割下掃羅外袍的衣擺。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 24:10; 列王紀下 22:19; 約翰一書 3:20–21"> 隨後大衛因割下掃羅的衣擺而心中自責，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 1:14; 約伯記 31:29–30; 撒母耳記上 26:9–11"> 就對部下說：「耶和華絕不允許我對耶和華的受膏者我主做這樣的事，我絕不對他下手，因為他是耶和華的受膏者。」</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 5:44; 詩篇 7:4; 羅馬書 12:17–21"> 大衛用這些話阻止了部下，不允許他們起來攻擊掃羅。<br />掃羅起身離開洞穴，繼續趕路。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 25:23–24; 羅馬書 13:7; 出埃及記 20:12"> 隨後大衛也起來，從洞穴出去，在掃羅後面呼叫說：「我主我王啊！」掃羅回身觀看，大衛就臉伏於地下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 7:21–22; 箴言 29:12; 箴言 16:28"> 大衛對掃羅說：「你為什麼聽信人的話，說：『看哪，大衛要謀害你』？</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 105:15; 撒母耳記上 24:4; 撒母耳記上 26:8–9"> 看哪，今天你親眼看到了，在洞穴裡，耶和華把你交在了我手中。有人說要殺你，我卻顧惜你，說：『我絕不對我主下手，因為他是耶和華的受膏者。』</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 26:20; 撒母耳記上 23:14; 撒母耳記上 23:23"> 我父啊，請看！看看你外袍的衣擺就在我手中！我割下了你外袍的衣擺，卻沒有殺你。你要知道，也要看見我的手中沒有惡行或悖逆。儘管你在獵取我的性命，我卻沒有得罪你。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 43:1; 士師記 11:27; 詩篇 35:1"> 「願耶和華在你我之間做判斷，願耶和華在你身上為我施行報應，但我的手絕不敵對你。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 7:20; 馬太福音 7:16–18; 馬太福音 12:33–34"> 正如古時的箴言所說：『惡事出於惡人』，我的手絕不敵對你。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 26:20; 撒母耳記上 17:43; 撒母耳記下 9:8"> 以色列王出來追趕誰呢？你在追逐誰呢？是在追一條死狗、一隻跳蚤啊！</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 43:1; 詩篇 35:1; 詩篇 119:154"> 願耶和華作審斷者，在你我之間做判斷。願他察看，為我辯護，救我脫離你的手。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:17; 創世記 33:4; 路加福音 21:15"> 當大衛對掃羅說完了這些話，掃羅就說：「我兒大衛，這是你的聲音嗎？」然後掃羅放聲大哭。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:44; 撒母耳記上 26:21; 創世記 38:26"> 他對大衛說：「你比我公義，因為你以善待我，我卻以惡待你。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 26:23; 詩篇 31:8; 撒母耳記上 23:12"> 今天顯明你是以善待我：耶和華把我交在了你手中，你卻沒有殺我。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:20; 撒母耳記上 23:21; 箴言 25:21–22"> 人遇見仇敵的時候，會放他安然離去嗎？願耶和華因你今天對我所做的，以善回報你。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:17; 馬太福音 2:3–6; 撒母耳記下 3:17–18"> 「看哪，現在我知道你必定作王，以色列王國將在你手中堅立。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:23; 撒母耳記下 21:6–8; 撒母耳記上 20:14–17"> 現在你要指著耶和華向我起誓，絕不剪除我的後裔，絕不從我父家除滅我的名。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 23:29; 約翰福音 2:24; 馬太福音 10:16–17"> 於是大衛向掃羅起誓，掃羅就回自己的家去，大衛和他的部下也回要塞去了。</span>
</div>

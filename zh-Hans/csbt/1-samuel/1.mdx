<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1SA" data-book-slug="1-samuel" data-book-name="撒母耳記上" data-chapter="1" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 6:34; 歷代志上 6:25–27; 撒母耳記上 1:19"> 以法蓮山地的拉瑪-瑣非有一個人名叫以利加拿，他是耶羅罕的兒子、以利戶的孫子、托戶的曾孫、蘇弗的玄孫，是以法蓮人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:1–2; 士師記 13:2; 創世記 29:23–29"> 以利加拿有兩個妻子，一個叫哈娜，另一個叫皮尼娜；皮尼娜有孩子，哈娜沒有孩子。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 2:41; 約書亞記 18:1; 申命記 12:5–7"> 以利加拿每年都從他本鄉上示羅去，向萬軍之耶和華敬拜、獻祭；在那裡，有以利的兩個兒子何弗尼和非尼哈作耶和華的祭司。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 12:17–18; 申命記 16:11; 申命記 12:5–7"> 每到獻祭那天，以利加拿就會把各人應得的份，分給他的妻子皮尼娜和皮尼娜所有的兒女，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:2; 創世記 29:30–31; 創世記 45:22"> 卻給哈娜雙倍的份，因為他愛哈娜。不過，耶和華使哈娜不能懷胎<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使哈娜不能懷胎——原文直譯「關閉她的子宮」。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 6:14; 約伯記 24:21; 利未記 18:18"> 由於耶和華使她不能懷胎<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="使她不能懷胎——原文直譯「關閉她的子宮」。">b</a></sup>，她的對頭皮尼娜就極力地挑釁她，為要惹她惱怒；</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:19"> 年年都是如此，每當她上耶和華的殿時，皮尼娜總是惹她惱怒，她就哭泣，不吃飯。</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 4:15; 約伯記 6:14; 以賽亞書 54:6"> 她的丈夫以利加拿就對她說：「哈娜，你為什麼哭泣，為什麼不吃飯，為什麼心裡愁煩呢？對你來說，有我難道不比有十個兒子更好嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 3:3; 詩篇 27:4; 詩篇 5:7"> 有一次，在示羅吃喝之後，哈娜就起來。那時祭司以利正坐在耶和華聖殿門柱旁的座位上。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 7:11; 路加福音 22:44; 約伯記 10:1"> 哈娜心靈愁苦，向耶和華禱告，流淚痛哭。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 13:5; 民數記 6:5; 創世記 29:32"> 她許願說：「萬軍之耶和華啊，如果你確實看到了你女僕的苦情，又記念我、不忘記你的女僕、賜給你女僕一個兒子，那麼我必把他終生獻給耶和華，絕不在他的頭上用剃刀。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:17; 雅各書 5:16; 路加福音 18:1"> 當時哈娜在耶和華面前不停地禱告，以利一直注意著她的嘴。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 8:26; 使徒行傳 2:13; 創世記 24:42–45"> 原來哈娜心裡說話，只有嘴唇在動，卻聽不到聲音，因此以利以為她喝醉了。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 4:25; 約伯記 8:2; 箴言 6:9"> 以利就對她說：「你要醉到什麼時候呢？不要再喝酒了！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 62:8; 耶利米哀歌 2:19; 詩篇 42:4"> 哈娜回答說：「我主啊，不是這樣的，我是個心靈苦痛的婦人。淡酒烈酒我都沒有喝，我是在耶和華面前傾吐心意。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 2:12; 約伯記 6:2–3; 馬太福音 12:34–35"> 請不要把你的女僕看為卑劣的女子，我因為有極大的苦情和煩惱，所以一直傾訴到現在。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬可福音 5:34; 士師記 18:6; 詩篇 20:3–5"> 以利回應說：「平平安安地去吧！願以色列的神把你向他所求的賜給你。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路得記 2:13; 羅馬書 15:13; 傳道書 9:7"> 哈娜說：「願你的婢女在你眼前蒙恩。」然後她就離開了；她吃了飯，臉上不再有愁容<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="臉上不再有愁容——依據七十士譯本；原文直譯「她的臉不再是她原來的」。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 21:1; 創世記 30:22; 撒母耳記上 1:11"> 第二天清晨，他們早早起來，在耶和華面前敬拜，然後回拉瑪他們的家去了。以利加拿與他的妻子哈娜同寢，耶和華記念哈娜，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:51–52; 馬太福音 1:21; 出埃及記 2:10"> 哈娜就懷孕；時候到了，生了一個兒子。哈娜給兒子起名為撒母耳，因為她說：「我向耶和華求得了他。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 1:3; 申命記 12:11; 約書亞記 24:15"> 以利加拿和他的全家又要上示羅去，向耶和華獻年祭，並且還願。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 1:28; 撒母耳記上 1:11; 路加福音 2:22"> 但哈娜這一次沒有上去，因為她對丈夫說：「等孩子斷了奶，我再帶他上去，那時讓他朝見耶和華，然後永遠住在那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 7:25; 路加福音 11:27; 創世記 21:7–8"> 她丈夫以利加拿對她說：「你看怎樣好就怎樣做吧，你可以留下來，直到你給他斷奶。唯願耶和華成就他的話。」於是哈娜留下來，乳養她的兒子，直到給孩子斷了奶。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 15:9–10; 約書亞記 18:1; 撒母耳記上 4:3–4"> 她給孩子斷奶之後，就帶他一同上去，還帶著一頭三歲的公牛<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一頭三歲的公牛——依據七十士譯本；馬索拉文本作「三頭公牛」。">d</a></sup>、一斗<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一斗——原文作「一伊法」。1伊法=22公升。">e</a></sup>麵粉和一皮袋酒。哈娜把兒子帶到了示羅耶和華的殿那裡，那時孩子還幼小。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 18:15–16; 路加福音 2:22"> 他們宰殺了公牛，然後把孩子帶到以利那裡。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀下 4:30; 列王紀下 2:4; 列王紀下 2:6"> 哈娜說：「哦，我主啊！我指著我主的生命起誓：我就是從前在這裡站在你旁邊，向耶和華禱告的那婦人。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰一書 5:15; 詩篇 118:5; 馬太福音 7:7"> 我為了得這孩子而禱告，現在耶和華已經把我向他所求的賜給我了。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 24:26; 創世記 24:52; 提摩太後書 3:15"> 因此，我把這孩子獻給耶和華；他終生都歸於耶和華。」於是他<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他——有古抄本作「他們」。">f</a></sup>就在那裡敬拜耶和華。</span>
</div>
</div>

</div>

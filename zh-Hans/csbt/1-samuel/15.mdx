<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1SA" data-book-slug="1-samuel" data-book-name="撒母耳記上" data-chapter="15" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 9:16; 撒母耳記上 12:14; 詩篇 2:10–11"> 撒母耳對掃羅說：「耶和華派遣我來膏立你為王，統治他的子民以色列，所以，你現在要聽從耶和華的命令。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:17–19; 出埃及記 17:8–16; 民數記 24:20"> 萬軍之耶和華如此說：『我要清算亞瑪力人對以色列人所做的事，就是當以色列人從埃及上來時，亞瑪力人在路上攻擊他們。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:16–18; 民數記 24:20; 民數記 31:17"> 現在你要去攻打亞瑪力人，把他們所有的一切都滅絕淨盡，不可憐恤他們；無論是男女、幼童、嬰兒，還是牛羊、駱駝、驢子，都要殺滅。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約書亞記 15:24; 撒母耳記上 11:8; 撒母耳記上 13:15"> 於是掃羅召集軍隊，在提拉因數點他們，有步兵二十萬，還有猶大人一萬。</span>
<span className="v" id="v5" data-v="5"> 掃羅來到亞瑪力人的城，埋伏在溪谷中。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 1:16; 民數記 10:29–32; 出埃及記 18:19"> 掃羅對基尼人說：「你們走，離開亞瑪力人下去吧，免得我把你們與他們一同除滅了。當全體以色列人從埃及上來時，你們曾經向他們施慈愛。」於是基尼人從亞瑪力人中間離開了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 16:7; 創世記 25:18; 撒母耳記上 14:48"> 掃羅擊殺亞瑪力人，從哈腓拉直到埃及東邊的書珥，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:1; 以斯帖記 3:1; 民數記 24:7"> 活捉了亞瑪力王亞甲，把所有的民眾都滅絕於刀刃之下。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:15; 撒母耳記上 15:19; 撒母耳記上 15:3"> 但掃羅和軍兵顧惜亞甲和上好的牛羊、肥牛犢、羊羔以及一切美好的東西，不願意把這些滅絕淨盡；至於一切輕賤的、沒有價值的東西，他們都滅絕了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 那時耶和華的話語臨到撒母耳，說：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:13; 創世記 6:6; 撒母耳記下 24:16"> 「我後悔立掃羅為王了，因為他轉離不跟從我，也不執行我的命令。」撒母耳為此很苦惱，整夜向耶和華哀求。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:55; 撒母耳記下 18:18; 撒母耳記上 25:2"> 撒母耳清早起來去見掃羅，有人告訴撒母耳說：「掃羅去了迦密，看哪，他為自己豎立了一座紀念碑，然後轉身下到吉甲去了。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 17:2; 路得記 3:10; 箴言 31:31"> 撒母耳到了掃羅那裡，掃羅對他說：「願你蒙耶和華祝福！我已經執行了耶和華的命令。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 3:13–15; 耶利米書 2:18–19; 耶利米書 2:34–37"> 撒母耳說：「那麼我耳中這羊叫的聲音、我所聽見的牛叫聲，是怎麼回事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:21; 撒母耳記上 15:9; 出埃及記 32:22–23"> 掃羅說：「這些是軍兵從亞瑪力人那裡帶回來的，因為他們顧惜上好的牛羊，為要獻祭給耶和華你的神。至於其餘的，我們都已經滅絕了。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 9:27; 列王紀上 22:16; 撒母耳記上 12:7"> 撒母耳對掃羅說：「住口吧！讓我把耶和華夜間對我說的話告訴你。」<br />掃羅對他說：「請說。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 10:22; 撒母耳記上 9:21; 撒母耳記上 15:1–3"> 撒母耳說：「雖然你看自己微小，但你難道不是以色列眾支派的首領嗎？耶和華膏立你為以色列的王。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 創世記 13:13; 創世記 15:16"> 耶和華派給你使命，說：『你去，把那些罪人——亞瑪力人滅絕淨盡。你要與他們爭戰，直到滅絕他們。』</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 14:32; 歷代志下 33:6; 歷代志下 36:12"> 你為什麼沒有聽從耶和華的話，而衝向戰利品，做耶和華眼中看為惡的事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 15:13; 馬太福音 19:20; 羅馬書 10:3"> 掃羅對撒母耳說：「我就是聽從了耶和華的話，完成了耶和華所派給我的使命。我把亞瑪力王亞甲抓來了，也滅絕了亞瑪力人。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:15; 出埃及記 32:22–23; 創世記 3:13"> 軍兵還從戰利品中取了一些牛羊，是當滅之物中那些上好的，要在吉甲獻祭給耶和華你的神。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="何西阿書 6:6; 詩篇 51:16–17; 箴言 21:3"> 撒母耳說：<br /><span className="pl pl-1">「耶和華喜悅燔祭和祭物，</span><br /><span className="pl pl-1">難道與喜悅人聽從耶和華的話等同嗎？</span><br /><span className="pl pl-1">看哪，聽從勝過獻祭，</span><br /><span className="pl pl-1">聽命勝過公綿羊的脂油；</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 28:16; 撒母耳記上 13:14; 利未記 20:6"> <span className="pl pl-1">要知道，悖逆如同占卜的罪，</span><br /><span className="pl pl-1">頑梗就像拜偶像的惡。</span><br /><span className="pl pl-1">你既然厭棄耶和華的話，</span><br /><span className="pl pl-1">耶和華也厭棄你作王。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 12:13; 以賽亞書 51:12–13; 民數記 22:34"> 掃羅對撒母耳說：「我犯罪了！我確實違背了耶和華的吩咐和你的話語。因為我懼怕軍兵，就聽了他們的話。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 10:17"> 現在，請你饒恕我的罪，與我一同回去，讓我敬拜耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="何西阿書 4:6; 撒母耳記上 13:14; 撒母耳記上 16:1"> 撒母耳對掃羅說：「我不與你一同回去，因為你厭棄了耶和華的話，耶和華也厭棄你作以色列的王。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 11:30–31"> 撒母耳轉身要走，掃羅抓住他外袍的衣擺，外袍被撕裂了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 28:17–18; 使徒行傳 13:22; 但以理書 4:32"> 撒母耳就對他說：「耶和華今天從你身上撕去了以色列的王國，賜給了你的鄰人，他比你好。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 24:14; 民數記 23:19; 提多書 1:2"> 以色列的永恆者不說謊，也不改變心意；因為他不像人那樣會改變心意。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 5:44; 約翰福音 12:43; 以賽亞書 29:13"> 掃羅說：「我犯罪了！現在請你在我子民的長老們面前和以色列人面前尊重我，與我一同回去，讓我敬拜耶和華你的神。」</span>
<span className="v" id="v31" data-v="31"> 於是撒母耳跟掃羅回去，掃羅就敬拜耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="啟示錄 18:7; 帖撒羅尼迦前書 5:3; 耶利米書 48:44"> 撒母耳說：「把亞瑪力王亞甲帶到我這裡來！」<br />亞甲歡歡喜喜地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="歡歡喜喜地——或譯作「被捆綁著」。">a</a></sup>來到他那裡，心裡想：「死亡的苦痛必定過去了！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="士師記 1:7; 創世記 9:6; 馬太福音 7:2"> 撒母耳說：<br /><span className="pl pl-1">「你的刀劍怎樣使女人喪子，</span><br /><span className="pl pl-1">你的母親也必怎樣在女人中喪子。」</span><br />於是撒母耳在吉甲，在耶和華面前把亞甲砍碎。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 11:4; 撒母耳記上 7:17"> 然後撒母耳回拉瑪，掃羅也回自己的家，上掃羅的基比亞去了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 15:11; 撒母耳記上 19:24; 撒母耳記上 16:1"> 撒母耳直到死的日子，再也沒有見掃羅，但撒母耳為掃羅悲慟。耶和華後悔立掃羅為以色列的王。</span>
</div>
</div>

</div>

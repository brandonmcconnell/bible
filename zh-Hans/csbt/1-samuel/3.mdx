<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 8:11–12; 詩篇 74:9; 撒母耳記上 3:21"> 那孩子撒母耳在以利面前事奉耶和華。在那些日子，耶和華的話語稀少，異象也不常見。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:15; 詩篇 90:10; 創世記 27:1"> 有一天，以利在自己的地方睡覺。他的眼睛早已昏花，不能看見。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:4; 利未記 24:2–4; 出埃及記 27:20–21"> 神的燈還沒熄滅，撒母耳睡在耶和華的聖殿中，那裡有神的約櫃。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 6:8; 哥林多前書 12:6–11; 出埃及記 3:4"> 耶和華呼喚撒母耳，撒母耳就回應：「我在這裡！」</span>
<span className="v" id="v5" data-v="5"> 然後他跑到以利那裡，說：「我在這裡，你呼喚我了嗎？」<br />以利說：「我沒有呼喚你，回去睡吧。」他就去睡了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬太福音 9:2; 撒母耳記上 4:16; 撒母耳記下 18:22"> 耶和華再次呼喚撒母耳，撒母耳就起來，到以利那裡，說：「我在這裡，你呼喚了我嗎？」<br />以利說：「我沒有呼喚你，我兒，回去睡吧。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:2; 耶利米書 9:24"> 那時撒母耳還不認識耶和華，耶和華的話語也沒有向他啟示。</span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 33:14–15; 哥林多前書 13:11–12"> 耶和華第三次又呼喚撒母耳，撒母耳就起來，到以利那裡，說：「我在這裡，你呼喚我了嗎？」<br />以利這才明白，是耶和華在呼喚這孩子。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 20:19; 以賽亞書 6:8; 詩篇 85:8"> 於是以利對撒母耳說：「去睡吧，如果他再呼喚你，你就說：『耶和華啊，請說，僕人在聽。』」撒母耳就回自己的地方去睡了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 3:8; 撒母耳記上 3:4–6"> 耶和華又來站在那裡，像前幾次那樣呼喚：「撒母耳，撒母耳！」<br />撒母耳就說：「請說，僕人在聽。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哈巴谷書 1:5; 耶利米書 19:3; 列王紀下 21:12"> 耶和華對撒母耳說：「看哪，我就要在以色列做一件事，所有聽見這事的人都會雙耳震響。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:27–36; 撒迦利亞書 1:6; 約書亞記 23:15"> 到那日，我針對以利家所說的一切話，我必全部<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="全部——原文直譯「從頭到尾」。">a</a></sup>實行在以利身上。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; 馬太福音 10:37; 撒母耳記上 2:12"> 我曾告訴過他，我必為他知道的罪孽永遠懲罰他的家；這罪就是他的兒子們褻瀆神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="褻瀆神——依據七十士譯本；馬索拉文本作「自招詛咒」。">b</a></sup>，而他卻沒有制止他們。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 22:14; 撒母耳記上 2:25; 耶利米書 15:1"> 因此我向以利家起了誓：『以利家的罪孽是永遠不能用祭物或供物來贖清的。』」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:6–8; 瑪拉基書 1:10; 撒母耳記上 1:9"> 撒母耳睡到清晨，打開耶和華殿的門。撒母耳怕告訴以利那異象，</span>
<span className="v" id="v16" data-v="16"> 以利呼喚撒母耳，說：「撒母耳，我兒！」<br />他回答：「我在這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:35; 路得記 1:17; 詩篇 141:5"> 以利說：「耶和華對你說了什麼事呢？不要向我隱瞞。如果你向我隱瞞其中任何他對你說的話，就願神處置你，重重地處置你！」</span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 2:10; 以賽亞書 39:8; 士師記 10:15"> 於是撒母耳把一切話都告訴了他，沒有向他隱瞞。以利說：「他是耶和華，願他做自己眼中看為好的事吧。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 39:2; 撒母耳記上 9:6; 列王紀上 8:56"> 撒母耳漸漸長大，耶和華與他同在，沒有讓他的任何一句話落空。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 20:1; 撒母耳記下 3:10; 提摩太前書 1:12"> 全以色列，從但直到比爾-謝巴，都知道撒母耳被確立為耶和華的先知。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 3:1; 創世記 12:7; 撒母耳記上 3:4"> 耶和華繼續在示羅顯現——耶和華就是在那裡藉著他的話語向撒母耳啟示了自己。</span>
</div>
</div>

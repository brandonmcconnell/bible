<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 20:17; 箴言 18:24; 撒母耳記上 18:3"> 大衛和掃羅說完了話以後，約拿單的心就與大衛的心相契合，約拿單愛他如同愛自己的性命。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 17:15; 撒母耳記上 16:21–23"> 從那天起，掃羅留下大衛，不讓他回他父親的家。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 20:8–17; 撒母耳記上 20:42; 撒母耳記下 21:7"> 約拿單與大衛結為盟友，因為他愛大衛如同愛自己的性命。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 41:42; 路加福音 15:22; 以斯帖記 6:8–9"> 約拿單脫下身上的外袍給了大衛，又把他的戰袍，甚至刀、弓、腰帶，都給了大衛。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 18:30; 撒母耳記上 18:14–15; 歌羅西書 4:5"> 大衛出征，在掃羅派遣他去做的所有事上都通達。掃羅就立他作戰士們的統領，這在全體軍兵和掃羅的臣僕們眼中都看為好。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 15:20; 士師記 11:34; 詩篇 68:25"> 在大衛擊殺了那非利士人之後，大家返回的時候，婦女們從以色列的各城鎮出來唱歌跳舞，伴著鈴鼓、歡呼、三弦琴來迎接掃羅王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 21:11; 撒母耳記上 29:5; 出埃及記 15:21"> 婦女們歡慶歌唱，說：<br /><span className="pl pl-1">「掃羅擊殺千千，</span><br /><span className="pl pl-1">大衛擊殺萬萬！」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 15:28; 箴言 13:10; 雅各書 4:5"> 掃羅非常惱火，這話使他很不高興，就說：「他們歸給大衛萬萬，而歸給我千千，只剩王位還沒給他了！」</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 7:22; 創世記 31:2; 馬太福音 20:15"> 從那天起，掃羅一直猜忌大衛。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 19:9; 帖撒羅尼迦後書 2:11; 列王紀上 18:29"> 第二天，從神那裡來的攪擾之靈大大臨到掃羅，他在宮殿中說神言<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="說神言——或譯作「胡言亂語」。">a</a></sup>。大衛一如往日手彈豎琴，掃羅手裡拿著長矛，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 20:33; 以賽亞書 54:17; 路加福音 4:30"> 掃羅擲出長矛，心裡說：「我要把大衛刺穿，釘在牆上。」但大衛兩次都從他面前躲開了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 18:15; 撒母耳記上 18:29; 撒母耳記上 16:13–14"> 掃羅懼怕大衛，因為耶和華與大衛同在，卻離開了掃羅。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 5:2; 詩篇 121:8; 撒母耳記上 18:16–17"> 所以掃羅把大衛從身邊調離，立他為千夫長，他就領軍出入。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 39:23; 馬太福音 28:20; 撒母耳記上 16:18"> 大衛在他一切的道路上都通達，因為耶和華與他同在。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:17; 歌羅西書 4:5; 雅各書 1:5"> 掃羅見他行事極其通達，就懼怕他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 18:5; 民數記 27:17; 列王紀上 3:7"> 但以色列和猶大都愛大衛，因為是他帶領他們出入。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 17:25; 撒母耳記上 25:28; 撒母耳記上 18:25"> 掃羅對大衛說：「看哪，我把我的大女兒米拉給你為妻，只要你作我的勇士，為耶和華作戰。」因為掃羅想：「我的手不對付他，讓非利士人的手對付他吧！」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 7:18; 撒母耳記上 9:21; 撒母耳記上 18:23"> 大衛對掃羅說：「我是誰？我的出身、我父親的家族在以色列算什麼，我竟然作王的女婿！」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 7:22; 撒母耳記下 21:8; 士師記 14:20"> 到了掃羅的女兒米拉該嫁給大衛的時候，她卻被許配給米何拉人亞得列為妻。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 18:28"> 掃羅的女兒米甲愛大衛；有人把這事告訴了掃羅，這事在他眼中看為好。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 18:17; 出埃及記 10:7; 耶利米書 9:8"> 他想：「我要把米甲嫁給大衛，使她成為大衛的陷阱，好讓非利士人的手對付他。」於是掃羅對大衛說：「今天你有第二次機會作我的女婿。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 36:1–3; 詩篇 55:21; 撒母耳記下 13:28–29"> 掃羅吩咐他的臣僕：「你們要私下對大衛說：『看哪，王喜歡你，他所有的臣僕們也愛你，如今你就作王的女婿吧。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:141; 箴言 14:20; 傳道書 9:15–16"> 掃羅的臣僕們就把這些話說給大衛聽。大衛說：「難道作王的女婿在你們眼中算為小事嗎？我不過是個貧窮、卑微的人。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 掃羅的臣僕們向掃羅報告說，大衛說了這些話。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 34:12; 撒母耳記上 18:17; 撒母耳記上 14:24"> 掃羅就說：「你們對大衛這樣說：『王想要的不是聘金，他只要一百個非利士人的包皮，為要報復王的仇敵。』」這是掃羅的謀算，要讓大衛在非利士人手中倒下。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 18:21"> 掃羅的臣僕們把這些事告訴了大衛；作王的女婿這事在大衛眼中看為好。日期未滿，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 3:14; 士師記 14:19; 撒母耳記上 18:13"> 大衛就動身，帶著他的部下去擊殺了兩百個非利士人。大衛把他們的包皮帶來，滿數交給王，為要作王的女婿。於是掃羅把他的女兒米甲給大衛為妻。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 24:20; 撒母耳記上 26:25; 創世記 37:8–11"> 掃羅看見並知道耶和華與大衛同在，而且自己的女兒米甲也愛大衛，</span>
<span className="v" id="v29" data-v="29" data-xref="傳道書 4:4; 約翰福音 11:53; 雅各書 2:19"> 掃羅就更加懼怕大衛，終生與大衛為敵。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 18:5; 撒母耳記下 11:1; 彼得前書 2:4"> 非利士人的首領們經常出兵，每逢他們出戰的時候，大衛比掃羅所有的臣僕更有智慧，因此他的名極受尊重。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 23:19; 詩篇 54:1–7; 約書亞記 15:24"> 西弗人來到基比亞見掃羅，說：「大衛不是躲藏在曠野對面的哈基拉山中嗎？」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 24:2; 撒母耳記上 13:2; 詩篇 140:4–9"> 掃羅就動身，帶著以色列中的三千精兵下到西弗曠野，要在西弗曠野尋索大衛。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 23:19; 撒母耳記上 26:1"> 掃羅在荒漠對面的哈基拉山，在路邊紮了營。那時大衛住在曠野，他發現掃羅追他來到了曠野。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:16; 約書亞記 2:1"> 大衛派出探子，得知掃羅確實來了。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 17:55; 撒母耳記上 17:20; 撒母耳記上 14:50–51"> 於是大衛動身，來到掃羅紮營的地方。大衛看見了掃羅和尼珥的兒子元帥押尼珥睡臥的地方，掃羅睡在行營中間，軍兵在他的四圍紮營。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 7:10–11; 撒母耳記下 2:18; 創世記 15:20"> 大衛就問赫提人亞希米勒以及洗魯雅的兒子、約押的弟弟亞比篩，說：「誰與我一起下到營地中掃羅那裡？」<br />亞比篩回答：「我與你一同下去。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦前書 5:2–3"> 夜間大衛和亞比篩來到軍兵那裡，看哪，掃羅正躺在行營中沉睡，他的長矛插在枕頭旁的地上，押尼珥和軍兵睡在他四圍。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 24:4; 撒母耳記上 26:23; 申命記 32:30"> 亞比篩對大衛說：「今天神把你的仇敵交在你手中了。現在，請讓我用長矛把他一槍刺透在地，不用第二槍。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 1:14; 詩篇 105:15; 撒母耳記下 1:16"> 大衛對亞比篩說：「不要殺害他！有誰對耶和華的受膏者下手而能免於罪罰呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 47:29; 申命記 31:14; 詩篇 37:13"> 大衛又說：「我指著耶和華的永生起誓：一定是耶和華來打擊他——或是到了所定的日子而死，或是出戰陣亡；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 24:6; 撒母耳記上 24:12; 撒母耳記下 1:14"> 耶和華絕不允許我對耶和華的受膏者下手。現在，你把他頭旁的長矛和水瓶拿過來，然後我們就走！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; 創世記 15:12; 以賽亞書 29:10"> 大衛拿了掃羅枕頭旁的長矛和水瓶，他們就走了。沒有人看見，沒有人知道，也沒有人醒來，人們全都在沉睡，因為是耶和華使他們陷入沉睡。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 24:8; 士師記 9:7"> 大衛過到對面，站在遠處的山頂上，他們之間有很大的距離。</span>
<span className="v" id="v14" data-v="14"> 大衛向軍兵和尼珥的兒子押尼珥呼叫，說：「押尼珥，你不回應嗎？」<br />押尼珥回應說：「你是誰，竟敢對著王呼叫？」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 大衛對押尼珥說：「你不是個大丈夫嗎？在以色列中，有誰能與你相比呢？民中有人來要殺害王你的主，你為什麼沒有保護王你的主呢？</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 79:11; 撒母耳記下 12:5; 撒母耳記上 26:9"> 你這事做得不好。我指著耶和華的永生起誓：你們是該死的，因為你們沒有保護耶和華的受膏者你們的主。現在你看看王的長矛和他枕頭旁的水瓶在哪裡呢？」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 24:16; 撒母耳記上 24:8"> 掃羅認出大衛的聲音，就問：「我兒大衛，這是你的聲音嗎？」<br />大衛回答：「我主我王啊，是我的聲音。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 24:9; 撒母耳記上 24:11–14; 約翰福音 10:32"> 又說：「我主為什麼追趕你的僕人呢？我到底做了什麼，我手中有什麼惡行呢？</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 14:16; 撒母耳記下 16:11; 撒母耳記下 20:19"> 現在，求我主我王聽你僕人的話：如果是耶和華促動你攻擊我，願耶和華悅納供物；如果是出於人，就願他們在耶和華面前受詛咒！因為今日他們驅逐我，不讓我在耶和華的繼業上有份，說：『去服事別的神吧！』</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 24:14; 馬太福音 26:55; 撒母耳記上 25:29"> 現在，求你不要讓我的血流在遠離耶和華面前的地方。以色列王出來，不過是尋索一隻跳蚤，就像人在山中追趕鷓鴣那樣。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:24; 撒母耳記上 24:17; 出埃及記 9:27"> 掃羅說：「我有罪了！我兒大衛啊，回來吧！我不會再傷害你了，因為今天我的性命在你眼中看為寶貴。看哪，我很愚蠢，並且錯得極其嚴重。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 大衛回應說：「看哪，這是王的長矛，請讓一個僕人過來拿回去吧。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 62:12; 撒母耳記上 24:6–7; 詩篇 18:20–26"> 願耶和華按著各人的公義和信實回報他！因為耶和華今天把你交在了我手中，我卻不願意對耶和華的受膏者下手。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 5:7; 哥林多後書 1:9–10; 詩篇 54:7"> 看哪，今天我怎樣重視你的性命，願耶和華也怎樣重視我的性命，願他解救我脫離一切患難！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 24:9–10; 箴言 26:25; 撒母耳記上 24:19"> 掃羅對大衛說：「我兒大衛，你是蒙祝福的！你必成就大事，也必得勝。」於是大衛上路離開，掃羅也回自己的地方去了。</span>
</div>
</div>

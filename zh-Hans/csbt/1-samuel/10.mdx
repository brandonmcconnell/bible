<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 16:13; 詩篇 78:71; 撒母耳記上 9:16"> 撒母耳拿了一瓶膏油，澆在掃羅頭上，然後親吻他，說：「耶和華不是已經膏立你為領袖掌管他的繼業嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:3–5; 創世記 35:19–20; 約書亞記 18:28"> 今天你離開我以後，將在便雅憫境內的謝撒，拉結的墳墓附近遇見兩個人。他們會對你說：『你去尋找的那幾頭母驢已經找到了。看哪，你父親已經不操心驢的事，反而為你們擔憂，說：「我兒子的情況，我該怎麼辦呢？」』</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:22"> 「你從那裡經過再往前走，來到他泊的橡樹，在那裡會遇見三個上伯特利拜見神的人，一個帶著三隻小山羊，一個帶著三塊餅，一個帶著一皮袋酒。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 18:15"> 他們會向你問安，然後給你兩塊餅，你要從他們手中接過來。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 3:15; 撒母耳記上 13:3; 撒母耳記上 19:20"> 「此後你要去神的山，那裡有非利士的駐軍。你到那城的時候，會遇見一隊先知正從高壇下來，他們都在說神言；在他們前面有彈里拉琴的、擊鼓的、吹笛的、彈豎琴的。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 10:10; 撒母耳記上 19:23–24; 民數記 11:25"> 耶和華的靈會大大臨到你，你就會與他們一同說神言，轉變為另一個人。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:12; 約書亞記 1:5; 以賽亞書 7:14"> 這些徵兆臨到你的時候，你手所當做的，只管去做，因為神與你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 11:14–15; 撒母耳記上 13:4; 撒母耳記上 13:8–15"> 你要在我之前下到吉甲，看哪，我也將下到你那裡去獻上燔祭，獻上平安祭。你要等候七天，直到我來到你那裡，指示你當做的事。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 38:7–8; 撒母耳記上 10:2–6; 士師記 7:11"> 掃羅轉身離開撒母耳的時候，神就把他的心轉變為另一顆心，這一切徵兆都在那日發生了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 10:5–6; 撒母耳記上 19:20–24"> 他來到那座山，看哪，有一隊先知迎見他。神的靈大大臨到他，他就在他們中間說神言。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 19:24; 約翰福音 7:15; 馬太福音 13:54–55"> 所有以前認識掃羅的人，他們都看見掃羅與眾先知一同說神言，就彼此說：「基士的兒子發生了什麼事呢？難道掃羅也列在先知中嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 54:13; 約翰福音 6:45; 雅各書 1:17"> 那裡的一個人回應說：「這些人的師父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="師父——原文直譯「父親」。">a</a></sup>是誰呢？」<br />因此這成了一句俗語：「難道掃羅也列在先知中嗎？」</span>
<span className="v" id="v13" data-v="13"> 掃羅說神言結束後，就前往高壇。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 14:50; 列王紀下 5:25; 撒母耳記上 9:3–10"> 後來掃羅的叔叔問掃羅和他的僕人：「你們到哪裡去了呢？」<br />他回答：「尋找驢子去了，我們沒有找到，就去見撒母耳。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 掃羅的叔叔說：「請告訴我，撒母耳對你們說了什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士師記 14:6; 撒母耳記上 9:20"> 掃羅回答他叔叔：「他清楚地告訴我們，驢已經找到了。」至於撒母耳所說有關王位的事，掃羅沒有告訴他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 20:1; 撒母耳記上 7:5–6"> 撒母耳招聚民眾到米斯巴，到耶和華那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:8–9; 尼希米記 9:27–28; 士師記 2:1"> 他對以色列子民說：「以色列的神耶和華如此說：我把以色列從埃及帶上來，解救你們脫離埃及的手，脫離壓迫你們的各國的手。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 12:12; 撒母耳記上 8:19; 約書亞記 24:1"> 今天你們卻厭棄你們的神，就是使你們脫離一切災禍和患難的拯救者；你們對他說：『求你立一個王統治我們。』現在，你們要按著自己的支派和宗族，站在耶和華面前。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約書亞記 7:16–18; 使徒行傳 1:24–26; 撒母耳記上 14:41"> 撒母耳讓以色列所有的支派都上前來，便雅憫支派被抽中；</span>
<span className="v" id="v21" data-v="21"> 然後讓便雅憫支派按著家族上前來，瑪特利家族被抽中；最後基士的兒子掃羅被抽中。民眾就尋找他，卻找不到。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 27:21; 士師記 20:18; 撒母耳記上 23:2–4"> 於是他們再次求問耶和華：「那人來了這裡沒有？」<br />耶和華說：「看哪，他躲藏在行李堆中。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 9:2; 撒母耳記上 16:7; 撒母耳記上 17:4"> 他們就跑去，把掃羅從那裡帶出來。他站在民眾當中，比眾人高出一頭。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:25; 列王紀上 1:39; 撒母耳記下 21:6"> 撒母耳對全體民眾說：「你們看到耶和華所揀選的人了嗎？在全民中，實在沒有人能與他相比。」<br />民眾都呼喊說：「願王萬歲！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 8:11–18; 申命記 17:14–20; 羅馬書 13:1–7"> 於是撒母耳把王國的法規向民眾宣告了，又寫在書卷上，放在耶和華面前。然後撒母耳遣散全體民眾，讓各人回自己的家去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 11:4; 約書亞記 18:28; 撒母耳記上 15:34"> 掃羅也回基比亞自己的家去了，那些心裡被神感動的勇士們，也與掃羅一同去了。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 13:13; 歷代志下 17:5; 列王紀上 10:25"> 然而有些卑劣之徒說：「這人怎麼能拯救我們呢？」他們就輕視他，也沒有給他帶禮物，掃羅卻保持沉默。</span>
</div>
</div>

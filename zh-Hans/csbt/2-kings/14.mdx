<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2KI" data-book-slug="2-kings" data-book-name="列王紀下" data-chapter="14" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 13:10; 歷代志下 25:1–4; 列王紀下 14:15"> 約哈斯的兒子以色列王約阿施在位第二年，猶大王約阿施的兒子亞瑪謝作王。</span>
<span className="v" id="v2" data-v="2"> 他作王的時候二十五歲，在耶路撒冷統治了二十九年。他的母親名叫耶赫阿丹，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 25:2–3; 撒迦利亞書 1:4–6; 列王紀上 11:4"> 他做耶和華眼中看為正的事，只是不如他的先祖大衛；他效法他父親約阿施所做的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 12:3; 列王紀下 16:4; 列王紀下 15:35"> 只是那些高壇還沒有除掉，百姓仍舊在高壇獻祭燒香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志下 25:3–4; 列王紀下 12:20–21; 民數記 35:33"> 當他手中的王權穩固後，他就把殺他父王的臣僕都殺掉了。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 24:16; 以西結書 18:20; 以西結書 18:4"> 但他沒有處死那些凶手的兒子，是照著摩西律法書上所記的，耶和華所指示的：「不可因著兒子處死父親，也不可因著父親處死兒子；各人只可因自己的罪過被處死。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 8:13; 歷代志上 18:12; 約書亞記 15:38"> 他在鹽谷擊殺了一萬以東人，又出戰攻取了西拉，給它起名為約克帖，直到今日。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 25:17–24; 撒母耳記下 2:14–17; 列王紀下 14:11"> 此後亞瑪謝派遣使者去見耶戶的孫子、約哈斯的兒子以色列王約阿施，說：「來，讓我們戰場相見吧！」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 9:8–15; 列王紀上 4:33; 歷代志下 33:11"> 以色列王約阿施就派人去見猶大王亞瑪謝，說：「黎巴嫩的蒺藜派人到黎巴嫩的香柏樹那裡，說：『把你的女兒嫁給我兒子為妻吧！』然而，有一隻黎巴嫩的野獸經過，把那蒺藜踐踏了。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 26:16; 申命記 8:14; 歷代志下 32:25"> 你確實擊敗了以東，你的心就高傲了。你自高自大吧，但請留在家裡！何必招惹禍患，使自己和猶大一同敗亡呢？」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 19:38; 歷代志下 25:16; 約書亞記 15:10"> 亞瑪謝卻不聽。於是以色列王約阿施上來，與猶大王亞瑪謝在猶大的伯示麥對陣。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 18:17; 撒母耳記上 4:10; 列王紀上 22:36"> 猶大敗在以色列面前，各人逃回自己的帳篷。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 8:16; 尼希米記 12:39; 撒迦利亞書 14:10"> 以色列王約阿施在伯示麥捉住了亞哈謝的孫子、約阿施的兒子猶大王亞瑪謝，然後來到耶路撒冷，拆毀了耶路撒冷的城牆，從以法蓮門直到角門，有四百肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="四百肘——相當於183公尺。1肘=45.7公分。">a</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:26; 列王紀上 7:51; 列王紀上 15:18"> 約阿施奪取耶和華殿中和王宮庫房裡所有的金銀、所有的器具，並帶走人質，然後回撒瑪利亞去了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:12–13; 列王紀上 14:19–20; 列王紀下 10:34–35"> 約阿施其餘的事蹟，他的作為，他的武力，以及他與猶大王亞瑪謝的爭戰，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 13:9; 列王紀下 13:13; 列王紀上 1:21"> 約阿施與他的列祖長眠，葬在撒瑪利亞，與以色列諸王在一起；他的兒子耶羅波安接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志下 25:25–28; 列王紀下 13:10; 列王紀下 14:23"> 約哈斯的兒子以色列王約阿施死後，約阿施的兒子猶大王亞瑪謝又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀下 13:8"> 亞瑪謝其餘的事蹟，不是都記在《猶大諸王年代志》上嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 10:31; 列王紀下 15:25; 列王紀下 12:20–21"> 有人在耶路撒冷密謀反叛他，他就逃到拉吉，但他們派人追到拉吉，在那裡殺了他。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 9:28; 列王紀下 12:21; 歷代志下 33:20"> 人們用馬把他馱回來，葬在耶路撒冷的大衛城，與他的列祖在一起。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀下 21:24; 馬太福音 1:8–9; 列王紀下 15:13"> 猶大全體民眾選立亞撒利雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亞撒利雅——又稱「烏西雅」；見《歷代志下》26:1。">b</a></sup>，接替他父親亞瑪謝作王，那時他十六歲。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 16:6; 列王紀上 9:26; 申命記 2:8"> 亞瑪謝王與列祖長眠之後，亞撒利雅重建埃拉特，使它回歸猶大。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿書 1:1; 阿摩司書 7:9–11; 阿摩司書 1:1"> 約阿施的兒子猶大王亞瑪謝在位第十五年，以色列王約阿施的兒子耶羅波安在撒瑪利亞作王，統治了四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 13:6; 列王紀下 13:11; 創世記 38:7"> 他做耶和華眼中看為惡的事，不離開尼八之子耶羅波安使以色列所犯的一切罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 3:17; 馬太福音 12:39–40; 約書亞記 19:13"> 他收復以色列的邊界，從哈馬隘口直到亞拉巴海，正如以色列的神耶和華藉著他的僕人——迦特希弗人亞米太的兒子先知約拿所宣告的話。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:36; 出埃及記 3:7; 列王紀下 13:4"> 因為耶和華看見了以色列的苦難，無論是為奴的還是自由的，都極其悲慘，也沒有人幫助以色列。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 13:23; 列王紀下 13:5; 羅馬書 11:2–12"> 其實耶和華並沒有說要把以色列的名號從天下抹掉，所以他藉著約阿施的兒子耶羅波安的手拯救了他們。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 11:24; 歷代志上 18:5–6; 撒母耳記下 8:6"> 耶羅波安其餘的事蹟和他所做的一切，以及他的武力和爭戰，他怎樣把猶大時期擁有的大馬士革和哈馬收回歸於以色列，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 15:8"> 耶羅波安與他的列祖以色列諸王長眠，他的兒子撒迦利亞接替他作王。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2KI" data-book-slug="2-kings" data-book-name="列王紀下" data-chapter="3" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 1:17; 列王紀上 22:51; 列王紀下 8:16"> 猶大王約沙法在位第十八年，亞哈的兒子約蘭在撒瑪利亞作以色列的王，統治了十二年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 10:18; 列王紀下 10:26–28; 列王紀上 21:25"> 他做耶和華眼中看為惡的事，只是沒有像他父母那樣。他除掉了他父親所造的巴力神柱，</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀下 15:18"> 不過他執着於尼八之子耶羅波安使以色列所犯的罪惡，總不離開。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 8:2; 創世記 26:13–14; 約伯記 1:3"> 摩押王米沙從事畜牧業，照例向以色列王交納十萬隻羊羔，以及十萬隻公綿羊的毛，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 1:1; 列王紀下 8:20; 歷代志下 21:8–10"> 但亞哈死後，摩押王就反叛了以色列王。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 24:1–25; 撒母耳記上 11:8; 撒母耳記上 15:4"> 那時約蘭王從撒瑪利亞出來，調集以色列全軍。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 22:4; 歷代志下 22:10–12; 歷代志下 18:3"> 他出發時，派人去見猶大王約沙法，說：「摩押王反叛了我，你願與我一起去攻打摩押嗎？」<br />約沙法說：「我願意去，你我不分彼此，我的子民如同你的子民，我的馬匹如同你的馬匹。」</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 1:2–3; 民數記 21:4"> 他又說：「我們從哪一條路上去呢？」<br />約蘭回答：「以東曠野那條路。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 22:47; 民數記 20:2; 出埃及記 17:1"> 於是，以色列王、猶大王和以東王一起出發。他們繞行七天的路程，軍兵和跟隨的牲畜都沒有水喝了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:34–36; 以賽亞書 51:20; 以賽亞書 8:21"> 以色列王說：「唉！耶和華召來我們這三個王，是要把我們交在摩押人手中啊。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 22:7; 列王紀上 19:21; 列王紀下 3:3"> 約沙法說：「這裡有没有耶和華的先知？我們可以藉著他求問耶和華。」<br />以色列王的一個臣僕回覆說：「這裡有沙法的兒子以利沙，他從前服事以利亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="服事以利亞——原文直譯「給以利亞手上倒水」。">a</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 5:15; 列王紀下 2:21; 以賽亞書 60:14"> 約沙法說：「他必有耶和華的話語。」以色列王、約沙法和以東王就下去見以利沙。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:6; 列王紀上 18:19; 列王紀上 22:10–11"> 以利沙對以色列王說：「我與你有什麼相干呢？去找你父親的先知、你母親的先知吧！」<br />以色列王回答：「不要這樣，是耶和華召來我們這三個王，要把我們交在摩押人手中！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 5:16; 列王紀上 17:1; 歷代志下 19:3–4"> 以利沙說：「我指著我所事奉的萬軍之耶和華的永生起誓：要不是看在猶大王約沙法的情面上，我絕不理你，也不睬你。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:23; 以弗所書 5:18–19; 以西結書 1:3"> 現在，給我找來一個彈琴的人。」<br />當彈琴的人彈奏時，耶和華的手<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="手——或譯作「大能」。">b</a></sup>落在以利沙身上。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 2:16–18; 列王紀下 4:3"> 他就說：「耶和華如此說：『讓這溪谷遍地都是水池。』</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:35; 以賽亞書 41:17–18; 以賽亞書 48:21"> 因為耶和華如此說：『你們不會見風，也不會見雨，但這溪谷卻必充滿了水，你們和你們的牲畜都會有水喝。』</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 32:27; 路加福音 1:37; 耶利米書 32:17"> 這在耶和華眼中算為小事，他還要把摩押交在你們手中。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 13:17; 申命記 20:19–20; 士師記 6:16"> 你們必攻破所有的堡壘城和所有繁榮的城鎮，砍倒一切美好的樹木，堵上所有水泉，用石頭毀壞所有良田。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 29:39–40; 但以理書 9:21; 列王紀上 18:36"> 到了早晨，大約獻祭的時間，看哪，有水從以東方向流過來，遍地都滿了水。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所書 6:14; 列王紀上 20:11"> 全摩押都聽說了有幾個王上來攻打他們，於是所有佩帶兵器<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="兵器——原文直譯「腰帶」。">c</a></sup>的成年人都被召集起來，守在邊界上。</span>
<span className="v" id="v22" data-v="22"> 他們清早起來的時候，日光照射在水面上，摩押人從對面看到水紅如血。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 5:30; 出埃及記 15:9; 以賽亞書 10:14"> 他們就說：「那是血！一定是那些王彼此攻擊、自相殘殺。摩押人哪，去搶戰利品了！」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:3–4; 約書亞記 8:20–22; 士師記 20:40–46"> 摩押人來到以色列的營地，以色列人起來擊殺他們，摩押人就從以色列人面前逃跑。以色列人又殺入他們境內，擊殺摩押人。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 16:7; 耶利米書 48:36; 耶利米書 48:31"> 以色列人拆毀他們的城鎮，各人扔石頭填滿所有良田，堵上所有水泉，砍倒一切美好的樹木，只剩下吉珥-哈列設的石牆，後來擲石兵包圍並攻破了它。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀下 3:9; 阿摩司書 2:1"> 摩押王見戰事激烈，對他不利，就帶領七百個刀手，要突圍進攻以東王，卻沒成功。</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 6:7; 申命記 12:31; 士師記 11:31"> 他就把要接替他作王的長子帶來，在城牆上獻為燔祭。這時有極大的震怒臨到以色列，他們就從那裡撤退，回自己的地方去了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 34:29–33; 歷代志下 30:2; 申命記 31:28"> 王派人去，招聚了猶大和耶路撒冷所有的長老到他那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 22:8; 申命記 31:10–13; 啟示錄 20:12"> 然後，王與猶大眾人、全耶路撒冷的居民、祭司、先知、全體民眾，無論尊卑，都一起上耶和華的殿去。王就把耶和華殿中發現的約書上一切話語，宣讀給他們聽。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 11:14; 列王紀下 11:17; 申命記 13:4"> 王站在柱子旁邊，在耶和華面前立約，要全心、全靈跟從耶和華，遵守他的誡命、法度和律例，履行這書卷上所記的聖約之言。全體民眾也都歸入這約。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:3; 列王紀下 21:7; 歷代志下 33:3"> 王吩咐大祭司希勒加、副祭司們以及門衛，把那些為巴力、亞舍拉和天上的萬象所造的一切器具從耶和華聖殿中搬出去，在耶路撒冷外面汲淪溪谷的田野焚燒了，然後把灰燼運到伯特利。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 44:17–19; 列王紀下 21:3–4; 何西阿書 10:5"> 他還驅除猶大列王所指派的那些服事偶像的祭司，就是在猶大各城的高壇和耶路撒冷四周燒香的祭司，並且驅除那些向巴力、太陽、月亮、星辰和天上萬象燒香的人。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 34:4; 列王紀下 23:15; 列王紀上 14:23"> 他把亞舍拉柱從耶和華的殿搬出去，帶到耶路撒冷外面的汲淪溪谷，在汲淪溪谷焚燒了，磨碎成灰，然後把灰撒在平民的墳墓上。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 15:12; 以西結書 16:16; 列王紀上 14:24"> 他拆毀了耶和華殿中男廟妓的房屋，那裡也是婦女們為亞舍拉編織帳幔的地方。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 15:22; 約書亞記 21:17; 列王紀上 19:3"> 他從猶大各城把那些祭司全召來，將祭司們燒香的高壇都玷汙了，從迦巴直到比爾-謝巴。他也拆毀了城門口的高壇，就在城主約書亞的城門入口處、城門的左邊。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 44:10–14; 撒母耳記上 2:36; 瑪拉基書 2:8–9"> 然而，那些高壇的祭司沒有上耶路撒冷耶和華的祭壇，只是與兄弟們一起吃了無酵餅。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:33; 耶利米書 19:6; 利未記 18:21"> 他還把欣嫩子谷的陀斐特玷汙了，以免有人使兒女經火獻給摩洛。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:16; 申命記 4:19; 歷代志下 14:5"> 他從耶和華殿的入口、前院中內臣拿單米勒的房間旁邊，除掉了猶大列王獻給太陽的馬匹，用火焚燒了太陽戰車。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 21:5; 西番雅書 1:5; 耶利米書 19:13"> 猶大列王在亞哈斯樓閣屋頂上所築的祭壇，以及瑪拿西在耶和華的殿兩個院子內所築的祭壇，約西亞王都拆毀搗碎了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="搗碎了——或譯作「從那裡除去了」。">a</a></sup>，把碎屑扔進汲淪溪谷。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 11:7; 列王紀上 11:5; 民數記 21:29"> 王還把耶路撒冷東邊邪僻山南面的高壇玷汙了，這些都是從前以色列王所羅門為西頓人的可憎偶像亞斯她錄、摩押人的可憎偶像基抹、亞捫人的可憎偶像米勒公所建造的。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 7:5; 出埃及記 23:24; 列王紀下 23:16"> 他打碎神柱，砍倒亞舍拉柱，使那些地方布滿了人的骸骨。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:6; 列王紀上 14:16; 列王紀上 21:22"> 此外還有伯特利的祭壇，以及尼八之子耶羅波安所建造使以色列犯罪的高壇，王也把這祭壇和高壇拆毀了。他燒毀高壇，把殘餘磨碎成灰，並燒毀亞舍拉柱。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 13:1–2; 列王紀上 13:32; 約翰福音 10:35"> 約西亞回頭，看見山上的那些墳墓，就派人從墳墓裡取出骸骨，在祭壇上焚燒，玷汙了祭壇，正如從前神人預言這些事情時所宣告的耶和華的話語。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 13:1; 列王紀上 13:30–31"> 王問：「我看見的這石碑是誰的？」<br />那城的人告訴王：「這是以前那位從猶大來的神人的墳墓，他曾宣告了你現在向伯特利的祭壇所做的這些事。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:31; 列王紀上 13:1–22"> 王說：「讓他安息吧！不要讓人驚動他的骸骨。」於是他們保全了他的骸骨，以及從撒瑪利亞來的那位先知的骸骨。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 34:6–7; 列王紀下 17:9; 以西結書 8:17–18"> 從前以色列諸王在撒瑪利亞各城建造高壇廟宇，以致惹怒耶和華，約西亞也把它們全都除掉了。他照著在伯特利的一切處理方式，處理它們。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 11:18; 歷代志下 34:5; 出埃及記 22:20"> 他把那裡所有的高壇祭司都斬殺<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="斬殺——或譯作「祭獻」。">b</a></sup>在祭壇上，並在祭壇上焚燒人的骸骨。之後，他回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 16:1–8; 民數記 9:2–5; 歷代志下 35:1–19"> 王吩咐全體民眾說：「你們要照著這約書上所記的，向你們的神耶和華守逾越節。」</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 30:1–3; 歷代志下 30:13–20; 歷代志下 35:3–19"> 從士師治理以色列的日子，到以色列和猶大列王的整個時期，實在沒有守過像這樣的逾越節；</span>
<span className="v" id="v23" data-v="23"> 只有約西亞王第十八年，在耶路撒冷向耶和華守了這樣的逾越節。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未記 19:31; 列王紀下 21:6; 創世記 31:19"> 此外，在猶大地和耶路撒冷所見的招魂者、通靈者、家族神像、偶像，以及一切可憎之物，約西亞也都清除了，為要履行祭司希勒加在耶和華殿中發現的書卷上所記律法的話語。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 18:5; 耶利米書 29:13; 申命記 6:5"> 在他以前從來沒有一個王像他那樣照著摩西的全部律法，全心、全靈、全力回轉歸向耶和華，在他之後也沒有興起一個像他那樣的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:11–13; 列王紀下 24:4; 耶利米書 3:7–10"> 然而，因著瑪拿西惹怒耶和華的種種挑釁行為，耶和華還是沒有收回他向猶大所發的極其猛烈的怒氣。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 18:11; 列王紀下 21:13; 列王紀下 21:4"> 耶和華說：「我要像驅逐以色列那樣，也把猶大從我面前驅逐了。我要棄絕我所選擇的這城耶路撒冷，以及我曾說『我的名必常在那裡』的這殿宇。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀下 20:20"> 約西亞其餘的事蹟和他所做的一切，不是都記在《猶大諸王年代志》上嗎？</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 46:2; 歷代志下 35:20–24; 士師記 5:19"> 約西亞年間，埃及王法老尼科上來攻打幼發拉底河那裡的亞述王，約西亞王去迎戰他。法老在米吉多見到約西亞時，把他殺了。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 9:28; 歷代志下 36:1–4; 列王紀下 21:24"> 他的臣僕用車把他的屍體從米吉多運走，帶回耶路撒冷，葬在他的墳墓裡。那地的民眾選擇約西亞的兒子約哈斯，膏抹了他，立他為王接替他父親。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歷代志上 3:15; 列王紀下 24:18; 耶利米書 22:11"> 約哈斯作王的時候二十三歲，在耶路撒冷統治了三個月。他的母親名叫哈慕她勒，是立拿人耶利米的女兒。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀下 21:2–7; 列王紀下 21:21–22"> 他效法他的祖先所做的一切，做耶和華眼中看為惡的事。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 8:65; 列王紀下 25:6; 耶利米書 39:5–6"> 法老尼科把他囚禁在哈馬地的利比拉，不讓他在耶路撒冷作王，並且罰了猶大國一百他連得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一百他連得——相當於3.4公噸。">c</a></sup>銀子、一他連得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一他連得——相當於34.2公斤。">d</a></sup>金子。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以西結書 19:3–4; 列王紀下 24:17; 歷代志上 3:15"> 法老尼科立約西亞的兒子以利亞敬為王接替他父親約西亞，把他的名字改為約雅敬。然後尼科帶走約哈斯，把他帶到埃及去了，後來他死在那裡。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 23:33; 列王紀下 15:19–20"> 約雅敬向法老上交金銀，但他為了按照法老的要求上交銀子，就向本國攤派。他照著自己給各人的估價，向國民索取金銀，為要上交給法老尼科。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="歷代志下 36:5; 耶利米書 26:1; 歷代志上 3:15"> 約雅敬作王的時候二十五歲，在耶路撒冷統治了十一年。他的母親名叫澤布達，是魯瑪人皮達雅的女兒。</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志下 33:22–23; 以西結書 19:5–9; 耶利米書 36:31"> 約雅敬效法他祖先所做的一切，做耶和華眼中看為惡的事。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:1; 以賽亞書 7:1; 列王紀下 15:38"> 利瑪利的兒子比加在位第十七年，猶大王約坦的兒子亞哈斯作王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 28:1–4; 列王紀下 15:34; 列王紀上 11:4–8"> 亞哈斯作王的時候二十歲，在耶路撒冷統治了十六年。他沒有像他先祖大衛那樣，做他的神耶和華眼中看為正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 12:31; 利未記 18:21; 列王紀下 21:2"> 而是走以色列王的道路，甚至效法耶和華在以色列子民面前趕出的那些民族的可憎行為，使自己的兒子經火，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:2; 列王紀上 14:23; 耶利米書 17:2"> 又在高壇上、丘陵上、各青翠樹下獻祭燒香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 15:37; 以賽亞書 9:6–7; 以賽亞書 8:9–10"> 於是，亞蘭王利汛會同利瑪利的兒子以色列王比加上來攻打耶路撒冷。他們圍困亞哈斯，卻不能戰勝。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 14:22; 申命記 2:8; 列王紀上 9:26"> 那時，亞蘭王利汛把埃拉特收歸亞蘭，將猶大人從埃拉特趕走。以東人就來到埃拉特，住在那裡，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 15:29; 耶利米哀歌 4:17; 何西阿書 14:3"> 亞哈斯派遣使者去見亞述王提革拉·毗列色，說：「我是你的僕人、你的兒子。求你上來，救我脫離那起來攻擊我的亞蘭王和以色列王。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 12:17–18; 歷代志下 28:20–21; 歷代志下 16:2"> 亞哈斯把耶和華殿中和王宮庫房裡的金銀都拿去，送給亞述王作禮物。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 9:7; 以賽亞書 22:6; 阿摩司書 1:3–5"> 亞述王答應了亞哈斯，亞述王就上去攻打大馬士革，攻取了那城。他把城裡的人擄到吉珥，把利汛殺了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:2; 以西結書 23:16–17; 以賽亞書 8:2"> 亞哈斯王去大馬士革會見亞述王提革拉·毗列色。亞哈斯王看到了大馬士革的祭壇，就把祭壇的圖樣以及詳細構造的設計圖，送到祭司烏利亞那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 4:6; 歷代志下 26:17–18; 何西阿書 5:11"> 祭司烏利亞完全照著亞哈斯王從大馬士革送來的圖樣，築了一座祭壇。這樣，祭司烏利亞在亞哈斯王從大馬士革回來之前，就完工了。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 26:16–19; 歷代志下 28:25; 列王紀上 13:1"> 王從大馬士革回來，看見了那祭壇，王就上前來，在祭壇上獻祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 1:1–3"> 他燒獻燔祭和素祭，澆奠了酒祭，把平安祭的血灑在祭壇上。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 4:1; 出埃及記 40:6; 出埃及記 40:29"> 至於耶和華面前的銅祭壇，他把它從耶和華殿和新祭壇之間，從殿宇前面搬走了，放在新祭壇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="新祭壇——原文直譯「那祭壇」。">a</a></sup>的北邊。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 29:39–41; 列王紀上 8:64; 歷代志下 29:21–24"> 亞哈斯王吩咐祭司烏利亞說：「你要在我的大祭壇上燒獻清晨的燔祭、傍晚的素祭，王的燔祭和素祭，所有國民的燔祭、素祭和酒祭；一切燔祭的血和祭物的血都要灑在它上面。至於銅祭壇，那是給我求問用的。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 4:19; 使徒行傳 5:29; 猶大書 1:11"> 祭司烏利亞就照著亞哈斯王所吩咐的一切做了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志下 4:14–15; 耶利米書 52:20; 歷代志下 28:24"> 亞哈斯王拆掉銅盆底座的鑲板，把盆從底座上取下來；又把銅海從底下的銅牛上拿下來，放在鋪石地上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 11:5; 列王紀上 10:5; 以西結書 46:2"> 他還為了亞述王的緣故，把耶和華殿中為安息日建造的廊子，以及王從外面進殿的入口，都從耶和華的殿拆除了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 15:36; 歷代志下 28:26; 列王紀下 20:20–21"> 亞哈斯所做的其餘事蹟，不是都記在《猶大諸王年代志》上嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 1:9; 以賽亞書 1:1; 歷代志上 3:13"> 亞哈斯與他的列祖長眠，葬在大衛城，與他的列祖在一起；他的兒子希西加接替他作王。</span>
</div>
</div>

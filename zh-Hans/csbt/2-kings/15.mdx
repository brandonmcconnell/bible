<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 26:3–4; 列王紀下 14:21; 歷代志下 26:1"> 以色列王耶羅波安在位第二十七年，猶大王亞瑪謝的兒子亞撒利雅作王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 26:3–4"> 他作王的時候十六歲，在耶路撒冷統治了五十二年。他的母親名叫耶克利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 14:3–4; 列王紀下 12:2–3; 歷代志下 26:4"> 他效法他父親亞瑪謝所做的一切，做耶和華眼中看為正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 15:35; 列王紀下 14:4; 列王紀下 12:3"> 只是那些高壇還沒有除掉，百姓仍舊在高壇獻祭燒香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未記 13:46; 民數記 12:14; 列王紀下 7:3"> 耶和華打擊王，他就患了痲瘋，直到死的日子；他住在隔離的房子裡。王的兒子約坦接管王室，治理國民。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 26:5–15; 列王紀下 14:18"> 亞撒利雅其餘的事蹟和他所做的一切，不是都記在《猶大諸王年代志》上嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 26:23; 以賽亞書 6:1"> 亞撒利雅與他的列祖長眠，人們把他葬在大衛城，與他的列祖在一起；他的兒子約坦接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 14:16–17; 列王紀下 14:29–1; 列王紀下 14:21"> 猶大王亞撒利雅在位第三十八年，耶羅波安的兒子撒迦利亞在撒瑪利亞作以色列的王，統治了六個月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 14:24; 列王紀下 13:2; 列王紀下 13:11"> 他效法他列祖的行為，做耶和華眼中看為惡的事，不離開尼八之子耶羅波安使以色列所犯的罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:28; 列王紀下 15:14; 列王紀下 9:24"> 雅比的兒子沙勒姆密謀反叛撒迦利亞，當眾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="當眾——或譯作「在以伯蓮」。">a</a></sup>攻擊他，把他殺了，接替他作王。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 14:28"> 撒迦利亞其餘的事蹟，看哪，都記在《以色列諸王年代志》上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 10:30; 馬可福音 13:31; 列王紀下 13:13"> 耶和華曾對耶戶說「你子孫四代都必坐以色列的王位」，這話就如此成就了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀下 15:1; 馬太福音 1:8–9; 列王紀下 15:8"> 猶大王亞撒利雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亞撒利雅——原文是別名「烏西雅」；見《歷代志下》26:1。">b</a></sup>在位第三十九年，雅比的兒子沙勒姆作王，在撒瑪利亞統治了一個月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:17; 列王紀上 16:17; 列王紀上 16:15"> 迦底的兒子米納恆從提爾撒上來，來到撒瑪利亞。他在撒瑪利亞攻擊雅比的兒子沙勒姆，把他殺了，接替他作王。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 14:19; 列王紀上 14:29; 列王紀下 15:11"> 沙勒姆其餘的事蹟，包括他謀反的事，看哪，都記在《以色列諸王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 8:12; 列王紀上 4:24; 何西阿書 13:16"> 那時米納恆從提爾撒出發，攻打提弗薩和城中所有的人，以及提弗薩的四境，因為他們沒有打開城門，他就屠殺他們，剖開所有的孕婦。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 猶大王亞撒利雅在位第三十九年，迦底的兒子米納恆在撒瑪利亞作以色列的王，統治了十年。</span>
<span className="v" id="v18" data-v="18"> 他做耶和華眼中看為惡的事，一生的日子不離開尼八之子耶羅波安使以色列所犯的罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 14:5; 歷代志上 5:25–26; 列王紀下 18:16"> 亞述王普勒侵入這地，米納恆就給了普勒一千他連得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一千他連得——相當於34.2公噸。1他連得=34.2公斤。">c</a></sup>銀子，為要普勒幫助他鞏固手中的王權。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 18:14–17; 列王紀下 23:35; 列王紀下 17:3–4"> 米納恆向以色列所有富豪徵收銀子，每人五十謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十謝克爾——相當於570公克。1謝克爾=11.4公克。">d</a></sup>銀子，交納給亞述王。於是亞述王回去，不在這地停留了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 米納恆其餘的事蹟和他所做的一切，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v22" data-v="22"> 米納恆與他的列祖長眠，他的兒子佩卡希亞接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 15:25; 列王紀上 22:51; 約伯記 20:5"> 猶大王亞撒利雅在位第五十年，米納恆的兒子佩卡希亞在撒瑪利亞作以色列的王，統治了兩年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:9; 列王紀下 15:18"> 他做耶和華眼中看為惡的事，不離開尼八之子耶羅波安使以色列所犯的罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歷代志下 28:6; 列王紀下 9:14; 列王紀上 16:9"> 他的軍官利瑪利的兒子比加密謀反叛他，與亞珥歌伯、亞利耶，以及跟隨比加的五十個基列人一起，在撒瑪利亞王宮的城堡裡攻擊他，把他殺了，接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 佩卡希亞其餘的事蹟和他所做的一切，看哪，都記在《以色列諸王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 7:4; 以賽亞書 7:1; 列王紀下 15:23"> 猶大王亞撒利雅在位第五十二年，利瑪利的兒子比加在撒瑪利亞作以色列的王，統治了二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 15:18; 列王紀下 13:6; 列王紀下 15:9"> 他做耶和華眼中看為惡的事，不離開尼八之子耶羅波安使以色列所犯的罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志上 5:26; 列王紀下 17:6; 列王紀下 16:7"> 以色列王比加年間，亞述王提革拉·毗列色前來奪取了伊永、亞貝勒-伯瑪迦、雅挪哈、基低斯、哈佐、基列、加利利，就是拿弗他利全地，並把那裡的人擄到亞述去了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:1; 歷代志下 28:4–6; 列王紀下 16:1"> 烏西雅的兒子約坦在位第二十年，以拉的兒子何西阿密謀反叛利瑪利的兒子比加，攻擊他，把他殺了，接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 比加其餘的事蹟和他所做的一切，看哪，都記在《以色列諸王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歷代志上 3:12; 列王紀下 15:7; 歷代志下 27:1–9"> 利瑪利的兒子以色列王比加在位第二年，猶大王烏西雅的兒子約坦作王。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 27:1"> 他作王的時候二十五歲，在耶路撒冷統治了十六年。他的母親名叫耶路莎，是撒督的女兒。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 26:4–5; 列王紀下 15:3–4; 歷代志下 27:2"> 約坦效法他父親烏西雅所做的一切，做耶和華眼中看為正的事。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 12:3; 歷代志下 23:20; 歷代志下 27:3–9"> 只是那些高壇還沒有除掉，百姓仍舊在高壇獻祭燒香。<br />約坦修築了耶和華殿的上門。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志下 27:4–9; 列王紀下 15:6–7"> 約坦其餘的事蹟和他所做的，不是都記在《猶大諸王年代志》上嗎？</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 16:5; 以賽亞書 7:1; 路加福音 21:28"> 在那些日子，耶和華開始派遣亞蘭王利汛和利瑪利的兒子比加來進攻猶大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀下 16:1"> 約坦與他的列祖長眠，葬在先祖大衛的城，與他的列祖在一起；他的兒子亞哈斯接替他作王。</span>
</div>

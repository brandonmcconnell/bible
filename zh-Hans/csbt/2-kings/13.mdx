<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 11:21; 列王紀下 8:26; 列王紀下 11:4"> 亞哈謝的兒子猶大王約阿施在位第二十三年，耶戶的兒子約哈斯在撒瑪利亞作以色列的王，統治了十七年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 12:26–33; 列王紀上 14:16; 列王紀下 10:29"> 他做耶和華眼中看為惡的事，隨從尼八之子耶羅波安使以色列所犯的罪惡，總不離開那罪。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:17; 列王紀下 13:24–25; 士師記 2:14"> 於是耶和華的怒氣向以色列發作，長期把他們交在亞蘭王哈薛和哈薛的兒子本哈達手中。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 14:26; 出埃及記 3:7; 詩篇 78:34"> 約哈斯懇求耶和華的恩寵，耶和華垂聽了他，因為耶和華看見以色列所受的壓迫，亞蘭王實在是壓迫他們。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 9:27; 列王紀下 14:25; 列王紀下 14:27"> 耶和華賜予以色列一位拯救者，他們就脫離了亞蘭人的手。於是以色列子民像從前那樣，安居在自己的帳篷裡。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 16:33; 列王紀下 13:2; 申命記 7:5"> 然而他們不離開耶羅波安家使以色列所犯的罪惡，繼續行在其中，而且亞舍拉柱依然豎立在撒瑪利亞。</span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司書 1:3; 列王紀下 10:32; 列王紀上 20:15"> 約哈斯除了五十個馬兵、十輛戰車和一萬步兵以外，再沒有其餘的軍兵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="約哈斯……再沒有其餘的軍兵——或譯作「耶和華沒有給約哈斯留下軍兵」。">a</a></sup>，因為亞蘭王消滅他們，踐踏他們如同禾場上的塵土。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 11:4; 列王紀上 14:29; 列王紀上 14:31"> 約哈斯其餘的事蹟和他所做的一切，以及他的武力，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 10:35; 列王紀下 13:13; 列王紀下 14:8"> 約哈斯與他的列祖長眠，人們把他葬在撒瑪利亞；他的兒子約阿施接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 猶大王約阿施在位第三十七年，約哈斯的兒子約阿施在撒瑪利亞作以色列的王，統治了十六年。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 13:2; 列王紀下 10:29; 列王紀下 3:3"> 他做耶和華眼中看為惡的事，不離開尼八之子耶羅波安使以色列所犯的一切罪惡，繼續行在其中。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 13:14–25; 列王紀下 14:8–16; 歷代志下 25:17–24"> 約阿施其餘的事蹟和他所做的一切，以及他與猶大王亞瑪謝爭戰時的武力，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 1:21; 列王紀下 14:28–29; 列王紀上 2:10"> 約阿施與他的列祖長眠，耶羅波安坐上他的王位。約阿施被葬在撒瑪利亞，與以色列諸王在一起。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 2:12; 腓立比書 2:26; 創世記 48:1"> 以利沙患病將死，以色列王約阿施下去看他，在他面前哭泣，說：「我父啊，我父啊！以色列的戰車馬兵啊！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 以利沙對王說：「把弓箭拿來！」他就拿來了弓箭。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 4:34; 創世記 49:24; 詩篇 144:1"> 以利沙對以色列王說：「手握在弓把上！」王就用手握住，然後以利沙把自己的手按在王的手上，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:26; 列王紀下 5:10–14; 哥林多前書 1:18"> 說：「打開朝東的窗戶。」他就打開了。以利沙說：「射箭！」王就射箭。以利沙說：「這是耶和華的勝利之箭，是戰勝亞蘭人的箭！你將在阿費克徹底擊敗亞蘭人。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀下 4:6; 出埃及記 17:11; 以賽亞書 20:2–4"> 以利沙又說：「拿起箭來！」他就拿起來。以利沙對以色列王說：「往地上擊打！」他打了三下，就停了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 13:25; 民數記 16:15; 列王紀下 4:40"> 神人對他發怒，說：「你應該擊打五次、六次，這樣你就徹底擊敗了亞蘭人。而現在，你只能擊敗亞蘭人三次。」</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 24:2; 列王紀下 3:7; 列王紀下 6:23"> 以利沙死了，人們把他安葬了。<br />那時每年的年初，摩押的劫掠隊都會入侵那地。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 37:1–10; 使徒行傳 19:12; 約翰福音 5:28–29"> 有一天，人們正在埋葬死人，突然看見一支劫掠隊，就把那死人扔到以利沙的墳墓裡跑了。那死人一碰到以利沙的骸骨，就復活了，雙腳站了起來。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王紀下 8:12; 列王紀下 13:3–7; 詩篇 106:40–42"> 約哈斯一生的日子，亞蘭王哈薛一直壓迫以色列。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 105:8; 列王紀下 14:27; 彌迦書 7:18–20"> 但耶和華因他與亞伯拉罕、以撒、雅各所立的約，就恩待以色列人，憐憫他們，垂顧他們。他不願意毀滅他們，沒有把他們從他面前趕走，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 125:3; 路加福音 18:7"> 亞蘭王哈薛死了，他的兒子本哈達接替他作王。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 13:18–19; 列王紀下 10:32; 列王紀下 14:25"> 約哈斯的兒子約阿施從哈薛的兒子本哈達手中奪回了一些城鎮，都是以前哈薛打仗從他父親約哈斯手中奪取的。約阿施擊敗他三次，收復了以色列的一些城鎮。</span>
</div>
</div>

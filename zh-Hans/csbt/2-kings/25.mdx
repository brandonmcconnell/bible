<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 52:4–11; 歷代志上 6:15; 耶利米書 34:1–6"> 西底加在位第九年的十月十日，巴比倫王尼布甲尼撒率領全軍來攻打耶路撒冷。他們在城外紮營，在城的四圍造臺築壘。</span>
<span className="v" id="v2" data-v="2"> 城被圍困，直到西底加王十一年。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 52:6; 以西結書 5:12; 耶利米書 38:2"> 到了四月九日，城中饑荒嚴重，當地百姓沒有糧食了。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 33:21; 列王紀下 25:5; 耶利米書 39:2–7"> 城就被攻破，所有的戰士從王室園子旁邊兩道城牆之間的門趁夜逃走；那時迦勒底人正圍攻這城。王沿著亞拉巴方向的路逃走，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 30:16; 耶利米書 39:5; 阿摩司書 2:14–16"> 迦勒底軍隊追趕王，在耶利哥平原追上了他，王的全軍從他身邊四散。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 23:33; 耶利米書 34:21–22; 耶利米書 21:7"> 迦勒底人捉住王，把他帶到利比拉，到巴比倫王那裡，對他宣告裁決。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 32:4–5; 士師記 16:21; 耶利米書 39:6–7"> 然後，他們在西底加眼前把他的兒子們殺了，並且弄瞎西底加的雙眼，用銅鏈捆住他，把他帶到巴比倫去了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米書 52:12–16; 耶利米書 40:1–4; 耶利米哀歌 4:12"> 巴比倫王尼布甲尼撒十九年的五月七日，巴比倫王的臣僕護衛長尼布撒拉旦進入耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 2:5; 詩篇 74:3–7; 列王紀上 9:8"> 他燒毀了耶和華的殿和王宮，以及耶路撒冷所有的房屋；所有高大的建築，他都放火燒毀了。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 1:3; 耶利米書 39:8; 耶利米書 52:14–23"> 護衛長率領的迦勒底全軍還拆毀了耶路撒冷四圍的城牆。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 5:2; 耶利米書 15:1–2; 耶利米書 39:9"> 護衛長尼布撒拉旦把城中殘留的其餘民眾和那些之前向巴比倫王投降的人，以及其餘的群體<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="群體——或譯作「工匠」；參《耶利米書》52:15。">a</a></sup>，都擄走了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 40:7; 列王紀下 24:14; 以西結書 33:24"> 但護衛長留下當地一些窮人，作葡萄園丁和耕田的農夫。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 36:18; 耶利米哀歌 1:10; 列王紀下 20:17"> 迦勒底人打碎了耶和華殿的銅柱，以及耶和華殿中的銅盆底座和銅海，把這些銅都運到巴比倫去。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:3; 列王紀上 7:47–50; 出埃及記 38:3"> 他們帶走了鍋、鏟子、蠟剪、勺子，以及事奉用的所有銅器。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:2–3; 民數記 7:13–14; 列王紀上 7:48–51"> 還有香爐和碗，凡是純金的、純銀的，護衛長也都帶走了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:47"> 所羅門為耶和華殿製作的兩根柱子，一個銅海以及所有的銅盆底座，這一切器物所用銅的重量無法確定。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:15–22; 耶利米書 52:21–23"> 一根柱子高十八肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十八肘——相當於8.2公尺。1肘=45.7公分。">b</a></sup>，頂上的柱頭是銅的，柱頭高三肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三肘——相當於1.4公尺。">c</a></sup>，柱頭上環繞著網格和石榴，都是銅的。另一根柱子也一樣，上面有網格。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 29:25; 以斯拉記 7:1; 耶利米書 21:1"> 護衛長捉住了祭司長西萊雅、副祭司長西番雅和三個門衛，</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 1:14"> 他在城裡還捉住一個監督軍兵的內臣，五個留在城裡的王室近臣，一個招募當地百姓的將軍秘書，以及六十個留在城裡的當地百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 4:16; 耶利米書 52:26–27; 列王紀下 23:33"> 護衛長尼布撒拉旦捉住他們，把他們帶到利比拉，到巴比倫王那裡。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:64; 列王紀下 23:27; 申命記 4:26"> 巴比倫王擊殺他們，在哈馬地的利比拉把他們處死了。這樣猶大人就從自己的國土被擄走了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 39:14; 列王紀下 22:12; 耶利米書 41:2"> 至於那些被留在猶大地的百姓，就是巴比倫王尼布甲尼撒所留下的人，尼布甲尼撒指派沙番的孫子、亞希甘的兒子基大利管理他們。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 40:7–9; 耶利米書 40:11–12; 約書亞記 18:26"> 眾將領和他們的部下聽說巴比倫王指派了基大利，就到米斯巴去見基大利；這些人有尼坦亞的兒子以實瑪利、加利亞的兒子約哈南、尼托法人坦胡米特的兒子西萊雅、瑪迦人的子孫雅撒尼亞，還有他們的部下。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 40:9–10; 耶利米書 43:6; 撒母耳記下 19:23"> 基大利向這些人和他們的部下起誓，對他們說：「不要懼怕迦勒底人的臣僕，只管住在這地，服事巴比倫王，這樣你們必安好無事。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒迦利亞書 7:5; 撒迦利亞書 8:19; 耶利米書 40:15"> 到了七月，王室後裔以利沙瑪的孫子、尼坦亞的兒子以實瑪利帶著十個人前來擊殺基大利，於是他和那些與他一起在米斯巴的猶大人和迦勒底人都死了。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 43:4–7; 耶利米書 41:16–18; 耶利米書 42:14–22"> 於是全體民眾，無論尊卑，連同將領們起身往埃及去，因為他們懼怕迦勒底人。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 52:31–34; 創世記 40:20; 創世記 40:13"> 在猶大王約雅斤被擄後三十七年的十二月二十七日，也就是巴比倫王伊莫米羅達作王的那一年，巴比倫王恩赦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="恩赦——原文直譯「抬起～的頭」。">d</a></sup>猶大王約雅斤，把他從牢房釋放了，</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:37; 耶利米書 27:6–11; 但以理書 5:18–19"> 對他說和善的話，使他的地位高過那些與他同在巴比倫的王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 9:7; 以賽亞書 61:3; 創世記 41:42"> 約雅斤換下囚服，以後終生常在王面前吃飯。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 11:3; 馬太福音 6:11; 尼希米記 11:23"> 至於他的飲食，從巴比倫王那裡有份例賜給他，每天一份，終生都是如此。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:30; 列王紀上 13:32; 列王紀上 21:8–14"> 那時，亞哈的七十個兒子在撒瑪利亞。耶戶寫信送到撒瑪利亞，給耶斯列的首領、長老們以及亞哈子女的監護人，說：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:6"> 「如今，這封書信到達你們那裡時，既然你們有主人的兒子與你們在一起，又有車馬、堡壘城和兵器，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 2:8–9; 列王紀上 12:20–21; 撒母耳記下 2:12–17"> 就請你們選出主人的兒子中最優秀最合適的，立他坐他父親的王位，然後你們為主人的家爭戰吧！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 9:24; 列王紀下 9:27; 以賽亞書 27:4"> 他們卻極其害怕，說：「看哪，兩個王在這人面前都站立不住，我們怎麼能站立得住呢？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 20:32; 列王紀上 20:4; 約書亞記 9:11"> 於是宮廷總管、城裡的官長、長老們和亞哈兒女的監護人就派人去見耶戶，說：「我們是你的僕人，你吩咐我們什麼，我們都會去做，我們不立誰為王。你看怎樣好就怎樣做吧！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:20–23; 申命記 5:9; 民數記 25:4"> 耶戶就給他們寫了第二封信，說：<br />「你們如果歸屬我、聽從我的吩咐，就要把你們主人所有兒子的頭顱帶來，明天這時候到耶斯列來見我。」<br />當時，眾王子七十人與城中那些撫養他們的大臣在一起。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:21; 列王紀下 11:1; 列王紀下 10:9"> 當書信到達他們那裡時，他們就抓住那些王子，把七十個人都殺了。然後把他們的頭顱放進筐子裡，送到耶斯列耶戶那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 21:23; 撒母耳記下 11:18–21; 馬可福音 6:28"> 有一個使者來向耶戶報告說：「他們把那些王子的頭顱帶來了。」耶戶說：「把這些頭顱分成兩堆放在城門口，直到明天早晨。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:14–24; 以賽亞書 5:3; 何西阿書 1:4"> 到了早晨，耶戶出去站著，對全體民眾說：「你們是清白的，看哪，是我密謀反叛我的主人，把他殺了；但這些人都是誰殺的呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:29; 列王紀上 21:19; 列王紀下 9:7–10"> 現在你們當知道：耶和華的話語——耶和華指著亞哈家所說的，一句也不落空；耶和華已經成就了藉著他僕人以利亞所宣告的話。」</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 18:19; 列王紀上 18:19; 列王紀上 22:6"> 這樣，耶戶擊殺了亞哈家在耶斯列所有剩下的人、他所有的大臣、親密的朋友和他的祭司，沒有留下一人存活。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶戶起身往撒瑪利亞去。路過牧羊人的伯艾吉時，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 8:29; 列王紀下 8:24; 歷代志下 21:17"> 耶戶遇見了猶大王亞哈謝的族兄弟們。他問：「你們是誰？」<br />他們回答：「我們是亞哈謝的族兄弟，下來要向王的家人和太后的家人問安。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 22:10; 列王紀下 10:6; 列王紀下 10:10–11"> 耶戶吩咐：「活捉他們！」他的部下就活捉了他們，在伯艾吉的水窖旁邊把他們殺了，共四十二人，一個也沒有留下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 35:14–19; 以斯拉記 10:19; 以西結書 17:18"> 耶戶從那裡前行，遇見了利甲的兒子約拿達前來迎接他。耶戶向他問安，說：「你的心是否真誠，就像我的心對你的心那樣？」<br />約拿達回答：「是。」<br />耶戶說：「既然是，就請遞出你的手。」<br />約拿達遞出手，耶戶就把他拉上戰車。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 19:10; 馬太福音 6:5; 列王紀下 10:31"> 耶戶說：「跟我一起去，看看我對耶和華的熱心！」於是耶戶讓約拿達乘上了自己的戰車。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 9:8; 歷代志下 22:8; 瑪拉基書 4:1"> 耶戶來到撒瑪利亞，擊殺了其餘在撒瑪利亞所有屬亞哈的人，直到滅盡了，正如耶和華向以利亞所宣告的話。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 16:31–32; 列王紀下 3:2; 羅馬書 3:8"> 耶戶招聚全體民眾，對他們說：「亞哈服事巴力還不夠熱心，耶戶要更加熱心服事。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:6; 列王紀上 18:19; 哥林多後書 11:3"> 現在，你們要把巴力的所有先知、所有服事巴力的人和巴力的所有祭司都召集到我這裡來，一個都不能缺，因為我要給巴力舉行一個盛大的祭祀；任何缺席者都不得存活。」原來耶戶是在用詭計，為要消滅服事巴力的人。</span>
<span className="v" id="v20" data-v="20" data-xref="約珥書 1:14; 出埃及記 32:5; 列王紀上 18:19–20"> 耶戶又說：「要為巴力舉行一個嚴肅聖會！」於是他們發出通告。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 16:32; 列王紀下 11:18; 約珥書 3:2"> 耶戶派人走遍全以色列，所有服事巴力的人都來了，沒有一個留下不來的。人們進入巴力的廟宇，巴力的廟宇從這頭到那頭都擠滿了人。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:2; 馬太福音 22:11–12"> 耶戶對掌管禮服的人說：「把衣袍給所有服事巴力的人拿出來。」他就把服裝給他們拿出來。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:30; 馬太福音 25:32–33; 馬太福音 13:41"> 耶戶與利甲的兒子約拿達進入巴力的廟宇，耶戶對服事巴力的人說：「搜尋看看，你們這裡不許有耶和華的僕人與你們在一起，只能有那些服事巴力的人在場。」</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:30–42"> 這樣，他們進去獻上祭物和燔祭。<br />耶戶在外面提前安排了八十人，說：「我交在你們手中的人，誰讓其中逃脫一個，誰就要以命抵命。」</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 16:6–7; 以西結書 22:21–22; 列王紀上 18:40"> 獻完了燔祭，耶戶就吩咐護衛兵和軍官們：「進去擊殺他們，不要讓任何人逃出來！」護衛兵和軍官們就用刀把他們殺了扔出去，然後進到巴力廟宇的內殿，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:23; 列王紀下 3:2; 列王紀下 19:18"> 把巴力廟宇裡的神柱都搬出去燒毀了。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 3:29; 以斯拉記 6:11; 但以理書 2:5"> 他們拆毀巴力的神柱，又拆毀巴力的廟宇，用作廁所，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 這樣，耶戶從以色列中除滅了巴力。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:28–30; 列王紀上 14:16; 列王紀上 13:33–34"> 只是耶戶沒有離棄尼八之子耶羅波安使以色列所犯的罪惡，就是敬拜伯特利和但的金牛犢。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 10:35; 列王紀下 13:1; 列王紀下 13:10"> 耶和華對耶戶說：「因為你做我眼中看為正的事，做得很好，照著我心裡的一切處置了亞哈家，所以你子孫四代都必坐以色列的王位。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀下 10:29; 箴言 4:23; 希伯來書 2:1"> 然而，耶戶沒有全心謹守遵行以色列的神耶和華的律法，沒有離開耶羅波安使以色列所犯的罪惡。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀下 8:12; 列王紀上 19:17; 列王紀下 13:22"> 在那些日子，耶和華開始切割以色列。哈薛在以色列境內各處擊敗他們，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司書 1:3–4; 申命記 2:36; 約書亞記 13:9–12"> 遍及約旦河東的基列地——迦得人、魯本人和瑪拿西人之地——從靠近亞嫩溪谷的亞羅珥，直到基列和巴珊。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀上 14:19"> 耶戶其餘的事蹟和他所做的一切，以及他的所有武力，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀上 1:21"> 耶戶與他的列祖長眠，人們把他葬在撒瑪利亞；他的兒子約哈斯接替他作王。</span>
<span className="v" id="v36" data-v="36"> 耶戶在撒瑪利亞統治以色列的日子共二十八年。</span>
</div>
</div>

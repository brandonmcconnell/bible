<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2KI" data-book-slug="2-kings" data-book-name="列王紀下" data-chapter="18" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 28:27–1; 馬太福音 1:9–10; 歷代志上 3:13"> 以拉的兒子以色列王何西阿在位第三年，猶大王亞哈斯的兒子希西加作王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 29:1–2"> 他作王的時候二十五歲，在耶路撒冷統治了二十九年。他的母親名叫婭比，是撒迦利亞的女兒。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 20:3; 列王紀上 11:4; 歷代志下 31:20–21"> 他效法他的先祖大衛所做的一切，做耶和華眼中看為正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 31:1; 民數記 21:8–9; 列王紀下 18:22"> 他除掉高壇，打碎神柱，砍倒亞舍拉柱，還打碎了摩西製作的銅蛇，以色列子民直到那時候一直向這銅蛇燒香，稱它為「內胡什坦」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:25; 列王紀下 19:10; 馬太福音 27:43"> 他依靠耶和華以色列的神，在他之後、在他之前所有的猶大王中沒有一個能與他相比的。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 23:8; 申命記 10:20; 約翰福音 14:15"> 他緊緊跟隨耶和華，沒有偏離不跟隨他，而是遵守耶和華所指示摩西的誡命。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:31; 創世記 39:2–3; 列王紀下 16:7"> 耶和華與他同在，他無論往哪裡去都通達。他背叛了亞述王，不再臣服於他。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 14:29; 列王紀下 17:9; 歷代志下 28:18"> 希西加擊敗非利士人，直到加沙，攻取了它境內的守望樓以及堡壘城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿書 10:14; 列王紀下 17:3–23; 列王紀下 18:1"> 到了希西加王第四年，就是以拉的兒子以色列王何西阿第七年，亞述王撒縵以色上來攻打撒瑪利亞，圍困它。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 6:7; 阿摩司書 9:1–4; 彌迦書 1:6–9"> 過了三年，它被攻取。希西加在位第六年，就是以色列王何西阿九年，撒瑪利亞被攻取了。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 5:26; 列王紀下 17:6; 以賽亞書 37:12"> 亞述王把以色列人擄到亞述，安置在哈臘，歌散河流域的哈博，以及米底亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米底亞——原文作「瑪代」。">a</a></sup>的城鎮。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:17; 彼得前書 2:8; 彌迦書 3:4"> 這是因他們沒有聽從他們的神耶和華的話，違背他的約；他們對耶和華的僕人摩西所吩咐的一切，既不聽從，也不遵行。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 36:1–22; 歷代志下 32:1–23; 以賽亞書 7:17–25"> 希西加王十四年，亞述王西納基立上來攻打猶大所有堅固的城，攻取了它們。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 18:7; 路加福音 14:32; 列王紀上 20:4"> 猶大王希西加派人到拉吉去見亞述王，說：「我錯了，求你從我這裡撤離吧！你對我的處置，我都接受。」於是亞述王向猶大王希西加索要三百他連得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三百他連得——相當於10.3公噸。1他連得=34.2公斤。">b</a></sup>銀子、三十他連得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十他連得——相當於1公噸。">c</a></sup>金子。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 16:8; 列王紀上 15:18–19; 列王紀下 12:18"> 希西加就把耶和華殿中和王宮庫房裡所有的銀子都交出來。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 29:3; 列王紀上 6:31–35"> 那時，希西加把耶和華聖殿的門上和柱子上的金子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="金子——輔助詞語。">d</a></sup>拆下來，交給了亞述王，都是猶大王希西加原來貼在其上的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 20:1; 列王紀下 20:20; 以賽亞書 7:3"> 但亞述王還是派遣元帥、參謀長、將軍<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="元帥、參謀長、將軍——音譯作「塔珥坦、拉伯撒利、拉伯沙基」；都是亞述高級官員的頭銜。">e</a></sup>率領大軍，從拉吉往耶路撒冷，到希西加王那裡去。他們就上來，到了耶路撒冷。他們上來後，前來站在上池的溝渠旁，通往漂布場的大道上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 19:2; 以賽亞書 36:3; 撒母耳記下 8:16–17"> 他們呼叫王，於是希勒加的兒子宮廷總管以利亞敬，書記舍伯納，以及亞薩的兒子史官約亞，都出來到他們那裡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 36:4; 列王紀下 19:10; 以賽亞書 10:8–14"> 將軍對他們說：<br />「請你們告訴希西加，亞述大王如此說：你所依靠的算什麼依靠？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你說你有作戰的謀略和實力，但那只是嘴上的空談！你現在依靠誰，竟敢背叛我！</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 30:7; 以西結書 29:6–7; 以賽亞書 30:2–3"> 現在看哪，你依靠的埃及是壓裂的蘆葦杖；如果有人倚靠它，它就會扎入那人的手掌，把手掌刺透。埃及王法老對所有依靠他的人都是這樣。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 31:1; 列王紀下 18:4–5; 馬太福音 27:43"> 你們也許會對我說『我們依靠耶和華我們的神』，但希西加除掉了這神的高壇和祭壇，還對猶大和耶路撒冷的人說『你們當在耶路撒冷這祭壇前敬拜！』難道耶和華不就是這神嗎？</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:42; 列王紀上 20:10; 尼希米記 4:2–5"> 現在你可以與我主亞述王下一個賭注：你那邊如果能給出相應的騎士，我就給你兩千匹馬；</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 10:8; 申命記 17:16; 以賽亞書 36:6"> 如果不能，你怎能擊退我主的臣僕中至小的一個軍官呢？你竟敢依靠埃及的戰車和馬兵！</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 19:6; 以賽亞書 10:5–6; 列王紀下 19:22–37"> 現在，我上來攻打這地方，要把它毀滅，難道不是出於耶和華嗎？是耶和華對我說『你要上去攻打這地，把它毀滅！』」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 4:7; 但以理書 2:4; 以賽亞書 36:11–12"> 希勒加的兒子以利亞敬、舍伯納、約亞對將軍說：「求你用亞蘭語對僕人們說話，因為我們聽得懂；不要用猶大話對我們說話，免得達到城牆上眾人的耳中。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="詩篇 73:8; 耶利米哀歌 4:5; 以西結書 4:15"> 將軍卻對他們說：「難道我的主人派我來，只對你和你的主人說這些話嗎？不也對那些坐在城牆上，將與你們一同吃自己糞、喝自己尿的人說話嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 36:13–18; 以賽亞書 10:8–13; 以西結書 29:3"> 然後，將軍站著用猶大話大聲呼喊，宣告說：<br />「你們要聽亞述大王的話！</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 32:15; 帖撒羅尼迦後書 2:8; 歷代志下 32:11"> 王如此說：『不要讓希西加欺哄你們，因為他不能解救你們脫離王的手；</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 125:1–2; 路加福音 23:35; 列王紀下 19:32–34"> 也不要讓希西加說服你們依靠耶和華，因為他會說：耶和華必定解救我們，這城必不落入亞述王手中。』</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 4:25; 列王紀上 4:20; 撒迦利亞書 3:10"> 「你們不要聽希西加的話，因為亞述王如此說：『你們要與我和好，出來向我投降，各人就可以吃自己葡萄樹和無花果樹的果實，喝自己水窖裡的水；</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 8:7–9; 出埃及記 3:8; 申命記 11:12"> 以後我會來，把你們帶到一個地方，與你們本土一樣，是一個有五穀和新酒的地方，一個有糧食和葡萄園的地方，有橄欖油和蜂蜜的地方，好使你們存活，不至於死。不要聽希西加，因為他誤導你們，說：耶和華必解救我們。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 10:10–11; 列王紀下 19:12–13; 歷代志下 32:19"> 列國的神明中，有哪一個曾真正解救自己的國土脫離亞述王的手呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 10:9; 列王紀下 17:23–33; 耶利米書 49:23"> 哈馬和阿爾帕的神在哪裡呢？西法瓦音、希拿和伊瓦的神在哪裡呢？難道他們曾解救撒瑪利亞脫離我的手嗎？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理書 3:15; 以賽亞書 10:15; 出埃及記 5:2"> 這些國所有的神明中，有哪一個曾解救自己的國土脫離我的手呢？難道耶和華會解救耶路撒冷脫離我的手嗎？』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="阿摩司書 5:13; 箴言 9:7; 馬太福音 7:6"> 眾人都默不作聲，一句也不回應，因為希西加王有令說：「不許回應他。」</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 22:11; 創世記 37:29; 列王紀下 5:7"> 希勒加的兒子宮廷總管以利亞敬，書記舍伯納，以及亞薩的兒子史官約亞，都撕裂衣服來到希西加那裡，把將軍的話告訴了他。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2KI" data-book-slug="2-kings" data-book-name="列王紀下" data-chapter="17" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:30"> 猶大王亞哈斯在位第十二年，以拉的兒子何西阿在撒瑪利亞作以色列的王，統治了九年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 3:2; 列王紀下 13:11; 歷代志下 30:5–11"> 他做耶和華眼中看為惡的事，只不過沒有像他之前的那些以色列王。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿書 10:14; 列王紀下 15:19; 列王紀下 19:36–37"> 亞述王撒縵以色上來攻打何西阿，何西阿就臣服於他，向他進貢。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 18:21; 列王紀下 24:20; 以西結書 17:13–19"> 後來亞述王發現了何西阿的陰謀，就是他派遣使者去見埃及王梭，不再每年向亞述王進貢。於是亞述王把他關押起來，囚禁在牢房裡。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 13:16; 列王紀下 25:1–3; 列王紀下 18:9"> 亞述王還入侵以色列全地，上來攻打撒瑪利亞，圍困這城三年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志上 5:26; 何西阿書 13:16; 申命記 28:64"> 何西阿在位第九年，亞述王攻取了撒瑪利亞。他把以色列人擄到亞述，安置在哈臘，歌散河流域的哈博，以及米底亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米底亞——原文作「瑪代」。">a</a></sup>的城鎮。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 23:16; 詩篇 106:35–41; 尼希米記 9:26"> 這是因為以色列子民犯罪，得罪了耶和華他們的神——就是從埃及地和埃及王法老手下把他們帶上來的那一位，而去敬畏別的神，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 18:3; 列王紀下 16:3; 申命記 18:9"> 隨從耶和華在以色列子民面前趕出的那些民族的習俗，以及以色列諸王所推行的習俗。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:8; 約伯記 31:27; 申命記 13:6"> 以色列子民暗中對他們的神耶和華做了不義的事，在他們所有的城鎮，從守望樓到堡壘城，為自己建造了高壇。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 14:23; 彌迦書 5:14; 出埃及記 34:13"> 他們在各高丘上、各青翠樹下，為自己豎立神柱和亞舍拉柱。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 28:25; 列王紀下 21:6; 耶利米書 44:17"> 他們像耶和華在他們面前驅逐的那些國民一樣，在所有的高壇燒香，並且做惡事來惹怒耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:4; 出埃及記 20:3–5; 申命記 4:23–25"> 他們服事偶像，儘管耶和華吩咐過他們不可做這樣的事。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 35:15; 撒母耳記上 9:9; 耶利米書 18:11"> 所以，耶和華藉著眾先知、眾先見警誡以色列和猶大，說：「你們要轉離自己邪惡的道路，謹守我的誡命、律例，遵行我的一切律法，這律法是我所吩咐你們祖先，又藉著我的僕人眾先知傳給你們的。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 31:27; 使徒行傳 7:51; 詩篇 106:24"> 他們卻不聽從，反而像他們的祖先一樣硬著頸項，不信靠耶和華他們的神。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 12:30–31; 申命記 32:21; 羅馬書 1:21–23"> 他們厭棄耶和華的定例和他與他們祖先所立的約，厭棄他對他們的警誡。他們隨從虛無的神明，以致自己也變得虛妄；又隨從周圍的那些民族，就是耶和華所吩咐他們不可效法的外邦人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:23; 列王紀上 16:31; 列王紀上 14:15"> 他們離棄了他們的神耶和華的一切誡命，為自己造了兩個牛犢的鑄像，製作了亞舍拉柱，向天上的萬象下拜，服事巴力。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:6; 列王紀下 16:3; 申命記 18:10–12"> 他們使自己的兒女經火，並且占卜、行法術，出賣自己去做耶和華眼中看為惡的事，惹怒他。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 12:20; 列王紀上 11:13; 何西阿書 11:12"> 於是耶和華對以色列大大發怒，把他們從自己面前驅逐，唯有猶大支派被留下。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 16:3; 列王紀上 14:22–23; 以西結書 16:51–52"> 然而，連猶大也不遵守他們神耶和華的誡命，而是隨從以色列所推行的習俗。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 耶利米書 6:30; 列王紀下 13:3"> 於是耶和華厭棄了以色列的所有後裔，苦待他們，把他們交在搶掠者的手中，最終把他們從自己面前趕走了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 11:11; 列王紀上 11:31; 列王紀上 14:16"> 耶和華把以色列從大衛家撕去之後，人們立了尼八之子耶羅波安為王。耶羅波安卻引誘以色列不跟從耶和華，使他們犯了大罪。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 3:3; 列王紀下 13:6; 列王紀下 13:11"> 以色列子民隨從耶羅波安所行的一切罪惡，總不離開，</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 17:6; 列王紀下 17:13; 列王紀下 17:20"> 直到耶和華把以色列從自己面前驅逐，正如藉著他的僕人眾先知所宣告的。這樣以色列人就從自己的國土被擄到亞述，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀下 18:34; 列王紀下 17:30–31; 馬太福音 10:5"> 亞述王從巴比倫、古它、阿瓦、哈馬和西法瓦音遷移人過來，安置在撒瑪利亞的城鎮，取代以色列子民。這些人就占有了撒瑪利亞，住在它的城鎮。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 17:32; 列王紀下 17:34; 列王紀下 17:41"> 這些人開始在那裡居住時，不敬畏耶和華，耶和華就派遣獅子到他們中間，咬死他們中間的一些人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 17:27; 撒母耳記上 8:9; 阿摩司書 8:14"> 有人稟告亞述王，說：「你所遷徙並安置在撒瑪利亞城鎮的那些國民，不知道當地之神的規矩，神就派遣獅子到他們中間。看哪，獅子把他們咬死了，因為他們不知道當地之神的規矩。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士師記 17:13; 列王紀上 12:31; 列王紀上 13:2"> 亞述王就吩咐說：「派去一個從那地擄來的祭司，讓他去住在那裡，指教他們當地之神的規矩。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 12:29–32; 以賽亞書 29:13; 馬太福音 15:14"> 於是有一個從撒瑪利亞被擄去的祭司回來住在伯特利，指教他們如何敬畏耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:31; 彌迦書 4:5; 列王紀上 13:32"> 可是各國各族的人仍然製造自己的神像，放在撒瑪利亞人建造的高壇廟宇裡；各國各族的人在所住的城鎮都這樣做。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:24"> 巴比倫人製造疏割比訥，古它人製造匿甲，哈馬人製造亞示瑪，</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:24; 列王紀下 17:17; 列王紀下 19:37"> 亞瓦人製造尼布哈茲和塔珥塔克，西法瓦音人把兒女用火焚燒給西法瓦音的神亞得米勒和亞拿米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 12:31; 列王紀下 17:29; 列王紀上 13:33"> 他們既畏懼耶和華，又從他們各類的人中為自己設立高壇的祭司，在高壇廟宇裡為他們服事。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 17:41; 路加福音 16:13; 馬太福音 6:24"> 他們又畏懼耶和華，又照著被遷徙之前本國的習俗來敬拜他們的神明。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 創世記 35:10; 列王紀下 17:27–28"> 這些人至今還是照著先前的習俗去行。他們不敬畏耶和華，也不遵行律例和法規，就是耶和華所吩咐雅各子孫的律法和誡命——這雅各，耶和華給他取名為以色列。</span>
<span className="v" id="v35" data-v="35" data-xref="士師記 6:10; 約書亞記 23:16; 約書亞記 23:7"> 耶和華曾與他們立約，吩咐他們說：「你們不可敬畏別的神，不可向它們下拜，不可服事它們，不可向它們獻祭。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 6:6; 申命記 6:13; 利未記 19:32"> 只有耶和華，就是以偉大的能力和伸出的膀臂把你們從埃及地帶上來的那一位，你們要敬畏他，向他下拜，向他獻祭。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 19:37; 申命記 5:31–2; 申命記 4:44–45"> 他為你們寫下的律例、法規、律法、誡命，你們要終身謹守遵行，不可敬畏別的神。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 4:23; 申命記 6:12; 申命記 8:14–18"> 你們不可忘記我與你們所立的約，不可敬畏別的神。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:74–75; 撒母耳記上 12:24; 馬太福音 10:28"> 你們只要敬畏耶和華你們的神，他就會解救你們脫離一切仇敵的手。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 4:28; 列王紀下 17:8; 耶利米書 13:23"> 然而，這些人沒有聽從，還是照著他們先前的習俗去行。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 6:24; 西番雅書 1:5; 列王紀上 18:21"> 這些民族既畏懼耶和華，又敬拜他們的偶像。這些人的孩子、他們的子子孫孫也都這樣，他們祖先怎樣做，他們也怎樣做，直到今日。</span>
</div>
</div>

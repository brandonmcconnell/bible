<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2KI" data-book-slug="2-kings" data-book-name="列王紀下" data-chapter="4" data-verses="44">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:25; 列王紀下 2:3; 尼希米記 5:2–5"> 有一個婦人，是先知團契中一個門徒的妻子，她向以利沙訴苦說：「你的僕人我丈夫死了，你知道你這僕人是敬畏耶和華的，現在有債主前來，要帶走我兩個孩子給他作奴僕。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王紀上 17:12; 雅各書 2:5; 列王紀下 6:26–27"> 以利沙對她說：「我能為你做什麼呢？請告訴我，你家裡還有什麼？」<br />她說：「婢女家裡除了一瓶油，什麼也沒有了。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="約翰福音 2:7; 詩篇 81:10; 約翰福音 16:24"> 以利沙說：「你到外面去向所有的鄰居借罐子，要空罐子，不要少借。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 8:5–9; 馬太福音 6:6; 以弗所書 3:20"> 然後你和兒子們回來，關上門<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="關上門——原文直譯「把身後的門關上」；5節和33節相同。">a</a></sup>，把油倒進所有的罐子裡，倒滿的就放一邊。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 5:11; 希伯來書 11:7–8; 列王紀上 17:15–16"> 那婦人就離開以利沙去了。<br />之後，她和兒子們關上門，兒子們不斷地遞給她罐子，她一個個倒滿。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 14:20; 列王紀下 13:19; 路加福音 6:19"> 罐子都倒滿了，她對兒子說：「再遞過來一個罐子！」兒子說：「沒有罐子了。」這時油就停了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦後書 3:7–12; 列王紀上 12:22; 羅馬書 12:17"> 婦人來告訴神人，神人就說：「去把油賣了還債吧。剩餘的，你和兒子們可以靠著生活。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 19:18; 創世記 19:3; 列王紀下 4:11–12"> 有一天，以利沙路過書念，那裡有一個貴婦人留他吃飯。此後，以利沙每次經過時，都會轉到她家去吃飯。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 17:24; 箴言 31:10–11; 列王紀下 4:7"> 那婦人對丈夫說：「你看，那位常從我們這裡經過的人，我認出他是個聖潔的神人。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:13; 馬太福音 10:41–42; 馬太福音 25:40"> 我們在樓上做個小隔間吧，給他放一張床，還有桌、椅、燈臺。他來我們這裡的時候，可以過來住在那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 這一天，以利沙過來了，就到樓上去躺下。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 8:4–5; 列王紀下 3:11; 列王紀下 4:29–31"> 他吩咐僕人基哈西說：「你去叫來這位書念婦人。」基哈西把她叫來，她就站在以利沙門前<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="門前——原文直譯「面前」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 1:16–18; 腓立比書 4:18–19; 希伯來書 6:10"> 以利沙吩咐僕人：「你問她：看哪，你為我們費了這一切心思，我能為你做些什麼呢？你有什麼事要我替你向王或將領提說嗎？」<br />她回答：「我在族人當中安居無憂。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:7; 創世記 15:2–3; 撒母耳記上 1:8"> 以利沙問：「那還有什麼能為她做的嗎？」<br />基哈西說：「對了，她沒有孩子，而她丈夫已經老了。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 於是以利沙說：「叫她過來。」基哈西把她叫過來，她就站在門口。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 18:10; 路加福音 1:13; 列王紀下 4:28"> 以利沙說：「在所定的日期，大約明年這時候，你必懷抱一個兒子。」<br />她說：「不，我主，神人哪，不要哄騙你的婢女。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:9; 路加福音 1:36; 創世記 21:1"> 那婦人果然懷孕了，到了第二年，在所定的日期生下一個兒子，正如以利沙告訴她的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路得記 2:4"> 那孩子長大了，有一天他出去，到收割的人那裡找他父親。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 14:1–2; 耶利米書 4:19"> 他忽然對父親說：「我的頭！我的頭！」<br />他父親吩咐僕人：「把他抱到他母親那裡去。」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:12; 約翰福音 11:3; 約翰福音 11:14"> 僕人抱著孩子，把他帶到他母親那裡去。孩子坐在母親的膝上，到了中午就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 4:32; 列王紀下 4:10; 列王紀下 4:7"> 婦人就上樓，把他放在神人的床上，然後關上門出去了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:38; 列王紀下 4:26; 約翰福音 11:3"> 她呼喚她的丈夫，說：「請給我派來一個僕人和一頭驢，我要趕快去神人那裡，很快就回來。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民數記 10:10; 民數記 28:11; 歷代志上 23:31"> 丈夫問：「你為什麼要今天去他那裡呢？今天既不是新月節，也不是安息日。」<br />她回答：「請放心。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 4:20; 列王紀上 13:13; 撒母耳記上 25:19–20"> 她給驢子備好鞍，對僕人說：「牽著走吧！不要為我放慢速度，除非我吩咐你。」</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 2:25; 以賽亞書 35:2; 列王紀上 18:19"> 於是她出發，來到迦密山，到了神人那裡。<br />當神人從對面看見她，就對僕人基哈西說：「看，是那位書念婦人。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:36; 列王紀下 4:23; 撒母耳記上 17:18"> 你現在趕快去迎接她，問她：『你平安嗎？你丈夫平安嗎？孩子平安嗎？』」<br />那婦人回答：「平安！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 7:3; 創世記 18:17; 阿摩司書 3:7"> 婦人來到山上神人那裡，就抱住他的腳。基哈西過去要推開她，神人說：「由她吧，她心中實在苦痛。耶和華向我隱藏了這事，沒有告訴我。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 30:1; 列王紀下 4:16"> 婦人說：「我向我主求過孩子嗎？我難道不是說過『不要哄騙我』嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀下 2:14; 列王紀上 18:46; 出埃及記 14:16"> 以利沙就對基哈西說：「你束上腰，手裡拿著我的杖前去。如果遇到什麼人，不要向他問安；如果有人向你問安，你也不要回應。你要把我的杖放在孩子臉上。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路得記 1:16–18; 列王紀下 2:2; 出埃及記 33:12–16"> 但孩子的母親說：「我指著耶和華的永生和你的生命起誓：我絕不離開你。」以利沙就起身，跟著她去了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 11:11; 馬可福音 5:39; 馬可福音 9:19–29"> 基哈西在他們前面先到，把杖放在孩子臉上，但孩子沒有動靜，沒有反應。基哈西回去迎見以利沙，就告訴他說：「孩子沒有醒來。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 8:52–53; 約翰福音 11:17; 列王紀上 17:17"> 以利沙來到婦人家裡，看見孩子死了，躺在以利沙床上。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 6:6; 列王紀下 4:4; 使徒行傳 9:40"> 他進去後關上門，只有自己和孩子二人在裡面，他就向耶和華禱告。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 17:21; 使徒行傳 20:10"> 然後他過去伏在孩子身上，口對著口，眼對著眼，手對著手；他伏在孩子身上，孩子的身體就暖和起來。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 8:5; 列王紀下 13:21; 列王紀上 17:22"> 他起身在房屋裡來回走了一次，然後過去再伏在孩子身上。孩子打了七次噴嚏，就睜開眼睛了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="希伯來書 11:35; 列王紀上 17:23; 路加福音 7:15"> 以利沙呼喚基哈西說：「你把那位書念婦人叫來。」基哈西去叫她，她就來了。以利沙說：「把你兒子抱走吧！」</span>
<span className="v" id="v37" data-v="37" data-xref="希伯來書 11:35; 列王紀下 2:15; 列王紀上 17:24"> 她就進來，在以利沙腳前俯伏於地下拜，然後抱起她的兒子出去了。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王紀下 8:1; 列王紀下 2:3; 列王紀下 2:1"> 以利沙回到吉甲，那地正有饑荒。先知團契的門徒坐在他面前，他吩咐他的僕人說：「放上大鍋，給先知門徒們煮一些湯。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="耶利米書 2:21; 以賽亞書 5:4; 馬太福音 15:13"> 有一個人出去，到田間采摘野菜。他發現了一株野瓜藤，從藤上採下滿滿一兜野瓜，帶回來切碎了放進湯鍋裡，不過沒有人知道那是什麼瓜。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬可福音 16:18; 出埃及記 15:23; 出埃及記 10:17"> 他們把湯舀出來給大家吃，正在吃的時候，有人呼叫：「神人哪，鍋裡有毒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="毒——原文直譯「死」。">c</a></sup>！」這樣大家就不能再吃了。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王紀下 2:21; 出埃及記 15:25; 哥林多前書 1:25"> 以利沙說：「拿點麵粉來。」他把麵粉撒在鍋裡，然後說：「舀給大家吃吧。」鍋裡就沒有毒了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 9:7; 約翰福音 6:9; 馬太福音 14:16–21"> 有一個人從巴力沙利沙來，給神人帶來了初熟大麥做的餅二十張和一袋新穗子。神人說：「把這些分給大家吃吧。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:13; 馬太福音 14:20; 約翰福音 6:9"> 他的侍從問：「我怎麼能把這些分給一百個人呢？」<br />但以利沙回答：「你只管分給大家吃，因為耶和華如此說：都吃了還有剩餘！」</span>
<span className="v" id="v44" data-v="44"> 於是僕人擺在大家面前，他們都吃了，並且還有剩餘，正如耶和華所說的。</span>
</div>
</div>

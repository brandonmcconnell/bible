<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2KI" data-book-slug="2-kings" data-book-name="列王紀下" data-chapter="9" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 10:1; 列王紀下 4:29; 列王紀上 1:39"> 先知以利沙叫來先知團契的一個門徒，對他說：「你束上腰，手中拿著這瓶膏油，到拉末-基列去。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 9:5; 列王紀上 19:16–17; 列王紀下 9:11"> 到了那裡，你要找寧示的孫子、約沙法的兒子耶戶。你去請他從他兄弟們當中起來，把他帶到內室。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:16; 出埃及記 29:7; 撒母耳記上 16:2"> 然後拿這瓶膏油澆在他頭上，說：『耶和華如此說：我膏立你為以色列的王。』然後開門就跑，不要耽延。」</span>
<span className="v" id="v4" data-v="4"> 於是那年輕的先知就往拉末-基列去了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士師記 3:19"> 他到了那裡，看哪，將領們都坐著。他說：「我有話帶給你，長官。」<br />耶戶問：「是給我們當中哪一位呢？」<br />他回答：「給你，長官。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 22:7; 列王紀上 19:16; 列王紀下 9:3"> 耶戶就起來，進了屋子。那年輕人把膏油澆在耶戶頭上，對他說：「以色列的神耶和華如此說：<br />『我已經膏立你為王治理耶和華的子民以色列。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:15; 列王紀上 18:4; 申命記 32:43"> 你要擊殺你主人亞哈的全家，好讓我向耶洗別施行報復，因她下手流了我僕人眾先知的血，耶和華眾僕人的血。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 25:22; 申命記 32:36; 列王紀下 14:26"> <span className="pl pl-1">亞哈全家都必滅亡；</span><br /><span className="pl pl-1">以色列中凡屬亞哈的男丁</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="男丁——原文直譯「對著牆撒尿的」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">無論是為奴的還是自由的，</span><br /><span className="pl pl-1">我都必剪除。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 15:29; 列王紀上 21:22; 列王紀上 14:10–11"> <span className="pl pl-1">我要使亞哈家</span><br /><span className="pl pl-1">像尼八之子耶羅波安的家，</span><br /><span className="pl pl-1">又像亞希雅的兒子巴沙的家那樣。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:23; 列王紀下 9:35–36; 列王紀下 9:3"> <span className="pl pl-1">至於耶洗別，</span><br /><span className="pl pl-1">狗必在耶斯列的地界內吃掉她，</span><br /><span className="pl pl-1">無人埋葬。』」</span><br />然後，他開門就跑了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 29:26; 使徒行傳 26:24; 何西阿書 9:7"> 耶戶出來，回到他主人的臣僕們那裡。他們問他：「一切平安嗎？這瘋子為什麼來見你呢？」<br />他回答：「你們都了解這個人和他的胡話。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他們說：「你糊弄人，請告訴我們吧！」<br />他就說：「那人說這說那，還告訴我：『耶和華如此說：我膏立你為以色列的王。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 11:7–8; 列王紀上 1:39; 列王紀上 1:34"> 他們就急忙各自脫下外衣鋪在耶戶腳前的臺階上，隨後吹響號角，說：「耶戶作王了！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 8:28; 列王紀上 22:3; 列王紀上 16:16"> 這樣，寧示的孫子、約沙法的兒子耶戶密謀反叛了約蘭。當時約蘭和全體以色列人正駐守在拉末-基列，抵抗亞蘭王哈薛。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 8:29; 撒母耳記上 27:9–11; 歷代志下 22:6"> 後來約蘭王回來，在耶斯列療傷，他與亞蘭王哈薛交戰時被亞蘭人打傷了。耶戶說：「如果你們有心讓我作王<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="讓我作王——輔助詞語。">b</a></sup>，就不要讓任何人逃脫出城，去耶斯列報信。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 22:6–7; 列王紀下 8:28–29"> 隨後耶戶乘上戰車往耶斯列去，因為約蘭正在那裡臥床養傷。那時猶大王亞哈謝已經下去看望他。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 16:4; 以西結書 33:2–9; 列王紀下 7:14"> 守望的人站在耶斯列的塔樓上，看見耶戶一群人來了，就說：「我看見有一群人！」<br />約蘭說：「叫來一個騎兵，派去迎見他們，詢問是否平安。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀下 9:19; 列王紀下 9:22; 耶利米書 16:5"> 騎兵就去迎見耶戶，說：「王如此說：平安嗎？」<br />耶戶說：「是否平安，與你有什麼相干？跟到我後面去！」<br />守望的人報告說：「派去的人到了他們那裡，但沒有回來。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 王又派第二個騎兵去。他來到他們那裡，說：「王如此說：平安嗎？」<br />耶戶說：「是否平安，與你有什麼相干？跟到我後面去！」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 18:27; 列王紀上 19:17; 傳道書 9:10"> 守望的人報告說：「派去的人到了他們那裡，但沒有回來。那駕車的像是寧示的孫子耶戶的駕車風格，駕得很瘋狂。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 21:1–7; 歷代志下 22:7; 彌迦書 1:13"> 於是約蘭吩咐：「備車！」有人就備好他的戰車。以色列王約蘭和猶大王亞哈謝各乘自己的戰車出發，出去迎見耶戶，在耶斯列人拿伯的那塊田地遇見了他。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 21:13; 那鴻書 3:4; 列王紀上 16:30–33"> 約蘭看見耶戶，就說：「耶戶，平安嗎？」<br />耶戶回答說：「你母親耶洗別的淫行和法術如此氾濫，怎麼會有平安呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀下 11:14; 歷代志下 23:13"> 約蘭急忙調頭逃走，對亞哈謝說：「亞哈謝啊，他謀反了！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 22:34; 箴言 21:30; 帖撒羅尼迦前書 5:3"> 耶戶拉滿弓，射中了約蘭兩臂正中間，一箭穿心，他就癱倒在戰車裡。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 21:19; 列王紀上 21:24–29; 以賽亞書 13:1"> 耶戶對他的軍官畢甲說：「把他抬走扔到耶斯列人拿伯的那塊田地裡。你當記得，你我一同駕車跟隨他父親亞哈時，耶和華曾向亞哈發出了這默示：</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 21:19; 申命記 5:9; 歷代志下 25:4"> <span className="pl pl-1">『昨夜我確實看見了拿伯的血和他兒子們的血</span><br /><span className="pl pl-2">——這是耶和華的宣告；</span><br /><span className="pl pl-1">我必在那塊田地上報應你</span><br /><span className="pl pl-2">——這是耶和華的宣告。』</span><br />現在你就照著耶和華的話，把他抬走扔到那塊田地裡吧。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士師記 1:27; 約書亞記 17:11; 列王紀下 8:29"> 猶大王亞哈謝看見這一切，就往伯哈干的方向逃走。耶戶追趕他說：「把他也殺了！」於是在靠近以伯蓮的古珥山坡上，有人把他射傷在戰車上。他逃到米吉多，死在那裡。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 35:24; 列王紀下 23:30; 列王紀下 12:21"> 他的臣僕們用車把他運送到耶路撒冷，葬在大衛城他的墳墓裡，與他的列祖在一起。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 21:18–19; 歷代志下 22:1–2; 列王紀下 8:24–25"> 亞哈的兒子約蘭在位第十一年，亞哈謝作猶大的王。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 4:30; 以西結書 23:40; 以西結書 24:17"> 耶戶來到耶斯列，耶洗別聽說了，就畫眉梳頭，從窗戶俯看。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 16:9–20"> 耶戶進了城門，耶洗別說：「你這弒主的澤姆利啊，平安嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以斯帖記 2:15; 出埃及記 32:26; 歷代志下 11:12"> 耶戶抬頭對著窗戶，說：「有誰聽我的？有誰？」兩三個太監向他俯看。</span>
<span className="v" id="v33" data-v="33" data-xref="彌迦書 7:10; 耶利米哀歌 1:15; 以賽亞書 25:10"> 耶戶說：「把她扔下來！」他們就把她扔下去，她的血噴濺到牆上和馬身上，耶戶從她上面軋過去。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:31; 列王紀上 21:25; 以賽亞書 65:15"> 耶戶進去，又吃又喝，然後說：「去看看這受詛咒的女人，把她埋葬了，她畢竟是王的女兒。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 12:23; 以賽亞書 14:18–20; 約伯記 31:3"> 他們就去埋葬她，卻發現除了頭骨和手腳以外，什麼都沒有了。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 21:23; 利未記 8:36; 列王紀下 14:25"> 他們回去報告耶戶，耶戶說：「這應驗了耶和華藉著他的僕人提斯比人以利亞所宣告的話：『狗必在耶斯列地界內吃掉耶洗別的肉。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 8:2; 詩篇 83:10; 耶利米書 16:4"> 耶洗別的屍體必在耶斯列地界內如同地上的糞土，以致沒有人能說：這就是耶洗別。』」</span>
</div>
</div>

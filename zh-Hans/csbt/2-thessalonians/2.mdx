<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 4:14–17; 馬可福音 13:27; 馬太福音 24:31"> 弟兄們，論到我們主耶穌基督的來臨，以及我們聚集歸於他的事，我們請求你們：</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 4:1–2; 馬可福音 13:7; 馬太福音 24:4–6"> 無論是藉著靈，還是藉著話語，或藉著一封好像是來自我們的書信，說主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主——有古抄本作「基督」。">a</a></sup>的日子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="日子——指「基督再來的日子」。">b</a></sup>已經來到了，你們都不要輕易被搖動而失去理性，也不要驚慌；</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 24:4–6; 約翰一書 2:18; 以弗所書 5:6"> 不要讓任何人用任何方法把你們欺騙了；因為那日子來臨以前<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那日子來臨以前——輔助詞語。">c</a></sup>，必定先有離道反教之事來到，並且那不法之人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="不法之人——有古抄本作「罪孽之人」。">d</a></sup>，就是那滅亡<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="滅亡——或譯作「沉淪」。">e</a></sup>之子也會被顯露出來。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 28:2; 但以理書 7:25; 啟示錄 13:6–7"> 他反對一切被稱為神的，或受人敬拜的，他又高抬自己在這一切之上，甚至坐在神的聖所裡宣稱自己是神。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得後書 1:15; 加拉太書 5:21; 馬太福音 16:9"> 我還在你們那裡的時候，一直告訴你們這些事，你們不記得嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 2:3; 帖撒羅尼迦後書 2:8"> 你們也知道，現在什麼攔阻了他，好使他在所定的時候<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="所定的時候——原文直譯「自己的時候」。">f</a></sup>被顯露出來。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰一書 4:3; 啟示錄 17:7; 提摩太後書 2:17–18"> 其實這不法的奧祕已經在做工，只是要等到那現在攔阻他的不在其中，</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦後書 2:3; 啟示錄 19:20–21; 以賽亞書 11:4"> 然後這不法之人要被顯露出來。主耶穌要以自己口中的氣殺掉<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="殺掉——有古抄本作「毀滅」。">g</a></sup>他，藉著自己來臨的顯現除去他。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 24:24; 啟示錄 19:20; 以弗所書 2:2"> 這不法之人的到來，是出於撒旦的作為，對那些正在滅亡的人，使用一切能力、虛假的神蹟和奇事，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 1:18; 箴言 1:7; 哥林多後書 4:2–3"> 並且使用一切不義的詭計，因為他們不接受那能使他們得救的真理之愛。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 1:28; 約翰福音 12:39–43; 提摩太前書 4:1"> 為此，神就把一種迷惑人的力量送進他們裡面，使他們相信虛假之事，</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 1:32; 羅馬書 8:7–8; 馬可福音 16:16"> 好使所有不相信真理而喜悅不義的人，都被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 1:9; 以弗所書 1:4–5; 帖撒羅尼迦前書 1:4"> 蒙主所愛的弟兄們，我們應該為你們常常感謝神，因為神為了救恩的緣故，就藉著在聖靈裡的分別為聖，以及真理的信仰，揀選了你們做為初熟的果子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="揀選了你們做為初熟的果子——有古抄本作「從起初揀選了你們」。">h</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:12; 彼得前書 5:10; 帖撒羅尼迦前書 1:5"> 為此，神也藉著我們的福音召喚了你們，使你們獲得我們主耶穌基督的榮耀。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 11:2; 帖撒羅尼迦後書 3:6; 帖撒羅尼迦後書 2:2"> 弟兄們，由此可見，你們當站立得穩；你們所領受的傳統，無論是藉著我們的話語，還是藉著我們的書信，你們都要持守。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="羅馬書 5:2–5; 約翰福音 3:16; 彼得前書 1:3–8"> 願我們的主耶穌基督自己和神我們的父，就是愛我們又在恩典中把永恆的安慰和美好的盼望賜給我們的那一位，</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 3:3; 帖撒羅尼迦前書 3:13; 帖撒羅尼迦前書 3:2"> 安慰你們的心，並且在一切美善的工作和言語上堅固你們。</span>
</div>
</div>

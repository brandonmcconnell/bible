<span className="v" id="v2" data-v="2" data-xref="哥林多後書 4:3–4; 羅馬書 15:31; 申命記 32:20"> 願神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神——輔助詞語。">c</a></sup>救我們脫離那些無理和邪惡的人，因為不是每個人都有這信仰。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 4:18; 帖撒羅尼迦前書 5:24; 哥林多前書 10:13"> 不過主是信實的，他會堅固你們、保守你們脫離那惡者。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 1:6; 腓利門書 1:21; 帖撒羅尼迦前書 4:10"> 至於你們，我們在主裡深信，你們正在遵行，並且也將繼續遵行我們所吩咐的。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 119:36; 歷代志上 29:18; 申命記 30:6"> 願主引導你們的心歸於神的慈愛，又歸於基督的忍耐。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:10–11; 帖撒羅尼迦後書 3:7; 羅馬書 16:17"> 弟兄們，我們奉我們主耶穌基督的名吩咐你們，要避開所有過著懶散生活，以及不照著你們從我們領受的傳統而生活的弟兄。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦後書 3:6; 帖撒羅尼迦後書 3:9; 哥林多前書 4:16"> 其實你們自己知道應該怎樣效法我們，因為我們在你們那裡的時候並沒有懶散，</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:11; 帖撒羅尼迦前書 2:9; 以弗所書 4:28"> 也沒有白吃過誰的飯<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="飯——原文直譯「餅」。">d</a></sup>。相反，我們辛苦勞碌、日夜做工，免得成為你們任何人的負擔。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:7; 帖撒羅尼迦前書 2:6; 哥林多前書 9:4–14"> 這並不是因為我們沒有這權利，而是要親自給你們做榜樣，好讓你們效法我們。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 3:19; 箴言 13:4; 箴言 20:4"> 事實上，我們還在你們那裡的時候，一直吩咐你們這一點：如果有人不肯做工，就不應當吃飯。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:13; 帖撒羅尼迦後書 3:6; 帖撒羅尼迦前書 4:11"> 因為我們聽說你們中間有些人生活懶散，什麼工都不做，卻好管閒事。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:28; 帖撒羅尼迦前書 4:11; 帖撒羅尼迦後書 3:8"> 我們在主耶穌基督裡吩咐並勸勉這樣的人：要安靜做工，吃自己的飯<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="飯——原文直譯「餅」。">e</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:9–10; 希伯來書 12:3; 哥林多後書 4:1"> 不過弟兄們，你們行美善的事不要喪膽。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提多書 3:10; 帖撒羅尼迦後書 3:6; 哥林多前書 5:11"> 如果有人不順從我們這信上的話語，你們就要記住這個人，不可與他交往，好讓他感到羞愧；</span>
<span className="v" id="v15" data-v="15" data-xref="提多書 3:10; 帖撒羅尼迦前書 5:14; 哥林多前書 5:5"> 可是不要把他看為敵人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="敵人——或譯作「反對者」。">f</a></sup>，而要勸誡他，如同弟兄那樣。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 29:11; 約翰福音 16:33; 馬太福音 1:23"> 願賜平安的主，常常以各種方法親自賜給你們平安！願主與你們大家同在！</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 16:21; 帖撒羅尼迦後書 1:5; 歌羅西書 4:18"> 我保羅親筆問候，這是我每一封信中的標記，我都是這樣寫的。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 16:20; 羅馬書 16:23"> 願我們主耶穌基督的恩典與你們大家同在！<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附「阿們。」">g</a></sup></span>

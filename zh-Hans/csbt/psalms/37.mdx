<span className="v" id="v2" data-v="2" data-xref="詩篇 92:7; 詩篇 90:5–6; 雅各書 1:10–11"> <span className="pl pl-1">因為他們就像青草快被割掉，</span><br /><span className="pl pl-1">也像青綠的嫩草即將衰殘。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 17:7–8; 馬太福音 6:31–33; 詩篇 62:8"> <span className="pl pl-1">你要依靠耶和華，要行善事，</span><br /><span className="pl pl-1">在地上安居，並要以信實為糧；</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前書 5:7; 腓立比書 4:6–7"> <span className="pl pl-1">當把你的道路交託耶和華，</span><br /><span className="pl pl-1">當依靠他，他必成全；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 54:17; 約伯記 11:17; 以賽亞書 58:8"> <span className="pl pl-1">他將使你的公義如光發出，</span><br /><span className="pl pl-1">使你的公正明</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="明——輔助詞語。">b</a></sup><br /><span className="pl pl-1">如正午。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="雅各書 5:7–11; 詩篇 27:14; 詩篇 62:5"> <span className="pl pl-1">你要在耶和華面前靜默，耐心等候他；</span><br /><span className="pl pl-1">不要因那道路通達、施行詭計的人而心懷不平。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各書 1:19–20"> <span className="pl pl-1">當抑制怒氣，離棄怒火；</span><br /><span className="pl pl-1">不要心懷不平，那只會導致惡事。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:21; 詩篇 25:13; 詩篇 37:29"> <span className="pl pl-1">因為作惡的必被剪除，</span><br /><span className="pl pl-1">唯有等候耶和華的必繼承那地。</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:5; 加拉太書 5:22–23; 以賽亞書 26:3"> <span className="pl pl-1">但謙卑的人必繼承那地，</span><br /><span className="pl pl-1">以豐盛的平安為樂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 2:1; 詩篇 35:16; 詩篇 31:13"> <span className="pl pl-1">惡人決意要對付義人，</span><br /><span className="pl pl-1">向他咬牙切齒。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:4; 箴言 1:26; 撒母耳記上 26:10"> <span className="pl pl-1">但主必譏笑惡人，</span><br /><span className="pl pl-1">因為見他受罰的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受罰的——輔助詞語。">c</a></sup><br /><span className="pl pl-1">日子將來到。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 詩篇 11:2; 約翰一書 3:12"> <span className="pl pl-1">惡人已經拔出刀劍，拉開了弓，</span><br /><span className="pl pl-1">要使困苦人和貧窮人倒下，</span><br /><span className="pl pl-1">要殺戮行為正直的人。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14–15; 詩篇 35:8; 耶利米書 51:56"> <span className="pl pl-1">但惡人的刀劍將刺入自己的心，</span><br /><span className="pl pl-1">他們的弓也將被打斷。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前書 6:6"> <span className="pl pl-1">一個義人擁有的雖少，</span><br /><span className="pl pl-1">卻好過許多惡人的富有。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 41:10; 詩篇 63:8; 詩篇 145:14"> <span className="pl pl-1">因為惡人的膀臂必被打斷，</span><br /><span className="pl pl-1">耶和華卻扶助義人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 1:6; 羅馬書 6:23; 詩篇 103:17"> <span className="pl pl-1">耶和華知道純全人的日子，</span><br /><span className="pl pl-1">他們的繼業長存，直到永遠。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 33:19; 箴言 10:3; 約伯記 5:20–22"> <span className="pl pl-1">他們在災禍中不致蒙羞，</span><br /><span className="pl pl-1">在饑荒的日子裡也會飽足。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 68:2; 詩篇 102:3; 路加福音 13:3"> <span className="pl pl-1">然而惡人必將滅亡，</span><br /><span className="pl pl-1">耶和華的仇敵如同草場</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="草場——或譯作「羊羔」。">d</a></sup><br /><span className="pl pl-1">的華美必將消逝——</span><br /><span className="pl pl-1">如煙消逝。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:16; 詩篇 112:5; 箴言 22:7"> <span className="pl pl-1">惡人只借不還；</span><br /><span className="pl pl-1">義人卻恩待人、給予人。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前書 16:22; 加拉太書 3:13"> <span className="pl pl-1">要知道，蒙耶和華祝福的，必繼承那地；</span><br /><span className="pl pl-1">被耶和華詛咒的，必被剪除。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 詩篇 145:14; 詩篇 94:18"> <span className="pl pl-1">他即使仆倒，也不被拋棄，</span><br /><span className="pl pl-1">因為耶和華扶助他的手。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 13:5; 詩篇 37:28; 詩篇 112:2"> <span className="pl pl-1">我曾經年少，現在老了，</span><br /><span className="pl pl-1">卻未曾見過義人被離棄，</span><br /><span className="pl pl-1">也未曾見過他的後裔討飯。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 112:5; 馬太福音 5:7; 詩篇 37:21"> <span className="pl pl-1">他終日恩待人、借予人，</span><br /><span className="pl pl-1">連他的後裔也成為人的祝福</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="成為人的祝福——或譯作「必蒙福」或「成為他的祝福」。">e</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:14; 箴言 16:6; 約翰一書 2:16–17"> <span className="pl pl-1">你當遠離惡事，當行善事，</span><br /><span className="pl pl-1">就必安居直到永遠；</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 11:7; 箴言 2:22; 詩篇 21:10"> <span className="pl pl-1">因為耶和華喜愛公正，</span><br /><span className="pl pl-1">不離棄他的忠信者，</span><br /><span className="pl pl-1">他們必蒙保守，直到永遠；</span><br /><span className="pl pl-1">而惡人的後裔必被剪除。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:21; 詩篇 37:9; 彼得後書 3:13"> <span className="pl pl-1">義人將繼承那地，</span><br /><span className="pl pl-1">在其上永遠安居。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 4:6; 箴言 25:11–13; 以弗所書 4:29"> <span className="pl pl-1">義人的口，述說智慧；</span><br /><span className="pl pl-1">他的舌頭，講說公正。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 40:8; 申命記 6:6; 以賽亞書 51:7"> <span className="pl pl-1">神的律法在他心裡，</span><br /><span className="pl pl-1">他的步履不會搖擺。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 詩篇 10:8–10; 詩篇 37:12"> <span className="pl pl-1">惡人窺伺義人，</span><br /><span className="pl pl-1">尋機置他於死地；</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 109:31; 彼得後書 2:9; 羅馬書 8:1"> <span className="pl pl-1">但耶和華必不將他離棄在惡人的手中；</span><br /><span className="pl pl-1">在審判的時候，也不定他有罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="詩篇 27:14; 詩篇 37:9; 箴言 20:22"> <span className="pl pl-1">你當等候耶和華，謹守他的道路；</span><br /><span className="pl pl-1">他就高舉你，使你繼承那地；</span><br /><span className="pl pl-1">惡人被剪除的時候，你必看到。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 5:3; 以西結書 31:18; 以賽亞書 14:14–19"> <span className="pl pl-1">我曾看到惡人的強橫，</span><br /><span className="pl pl-1">像本地青翠的樹那樣蔓延；</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 37:10; 使徒行傳 12:22–23; 以賽亞書 10:16–19"> <span className="pl pl-1">但他很快就消逝了</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他很快就消逝了——或譯作「我再經過時」。">f</a></sup><br /><span className="pl pl-1">，看哪，他不復存在！</span><br /><span className="pl pl-1">雖然我尋找他，卻找不到。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 32:17; 以賽亞書 57:1–2; 提摩太後書 4:6–8"> <span className="pl pl-1">你當留意純全的人，觀看正直的人，</span><br /><span className="pl pl-1">因為這些和平的人必有前途</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="前途——或譯作「後代」。">g</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="箴言 14:32; 詩篇 52:5; 詩篇 1:4–6"> <span className="pl pl-1">但悖逆者都要被除滅，</span><br /><span className="pl pl-1">惡人的前途必遭斷絕。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="詩篇 9:9; 詩篇 91:15; 以賽亞書 12:2"> <span className="pl pl-1">義人的拯救來自耶和華，</span><br /><span className="pl pl-1">他是他們在患難時的保障。</span><br /></span>

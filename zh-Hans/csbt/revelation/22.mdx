<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 7:17; 約翰福音 4:14; 詩篇 36:8–9"> 接著，天使<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="天使——原文直譯「他」。">a</a></sup>給我看一條生命水的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「清淨的」。">b</a></sup>河，明亮如水晶，從神和羔羊的寶座流出來，</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 22:1; 彼得前書 2:24; 啟示錄 2:7"> 從城的大街中間穿過。河的兩邊有生命樹，結十二種果子；每個月都結果子，樹上的葉子是為了醫治萬民。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 25:21; 啟示錄 21:3–4; 約翰福音 12:26"> 將來不再有任何詛咒。神和羔羊的寶座將要在城中，他的奴僕們將事奉他，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 5:8; 啟示錄 14:1; 啟示錄 3:12"> 他們將要看到他的面容，而他的名字將要寫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="將要寫——輔助詞語。">c</a></sup>在他們的額上。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 60:19–20; 但以理書 7:18; 啟示錄 20:4"> 將來不再有黑夜<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="不再有黑夜——有古抄本作「那裡不會有黑夜」。">d</a></sup>，他們不需要燈光<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="燈光——有古抄本作「燈」。">e</a></sup>或日光，因為主、神將照亮他們。他們將做王，直到永永遠遠。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:1; 啟示錄 21:5; 啟示錄 19:9"> 隨後，天使<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="天使——原文直譯「他」。">f</a></sup>對我說：「這些話是信實的、真實的。主——眾先知之靈<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="先知之靈——有古抄本作「聖先知」。">g</a></sup>的神，差派了他的天使，要把這些必須快發生的事指示給他的奴僕們。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 1:3; 啟示錄 3:11; 啟示錄 22:20"> <span className="woj">「看哪，我快要來了！那遵守這書上預言之話的人，他是蒙福的！」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 19:10; 啟示錄 1:1; 啟示錄 19:19"> 我約翰，是聽見又看見這些事的人。我聽見又看見了以後，就俯伏在那位指示我這些事的天使腳前，要敬拜他。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:10; 歌羅西書 2:18–19; 啟示錄 14:7"> 可是他對我說：「你要注意，不可這樣！我和你，以及你的弟兄先知們，還有那些遵守這書上話語的人，都是同做奴僕的。你應當敬拜神！」</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 8:26; 啟示錄 1:3; 彼得前書 4:7"> 他又對我說：「不可封住這書上的預言之話，因為時候快到了。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:10; 箴言 4:18; 以西結書 3:27"> 行不義的，讓他繼續行不義；骯髒的，讓他繼續骯髒；公義的，讓他繼續行公義<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="行公義——有古抄本作「被稱為義」。">h</a></sup>；聖潔的，讓他繼續被分別為聖。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 16:27; 以賽亞書 62:11; 以賽亞書 40:10"> <span className="woj">「看哪，我快要來了！我帶著報償，要按照各人的行為回報每個人。</span></span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 1:8; 啟示錄 21:6; 以賽亞書 44:6"> <span className="woj">我是『阿爾法』，也是『歐米伽』；是首先的，也是末後的；是開始，也是終結。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:27; 約翰一書 5:3; 啟示錄 22:7"> <span className="woj">「凡是洗淨自己袍子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="洗淨自己袍子——有古抄本作「遵行他命令」。">i</a></sup><span className="woj">，好使自己有權利到生命樹那裡，並且得以從城門進到城內的人——他們是蒙福的！</span></span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 21:8; 加拉太書 5:19–21; 腓立比書 3:2"> <span className="woj">那些犬類、行邪術的、淫亂的、殺人的、拜偶像的，以及所有愛虛假、行虛假的人，都在外面。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 5:5; 彼得後書 1:19; 以賽亞書 11:1"> <span className="woj">「我耶穌，派遣了我的使者</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="使者——或譯作「天使」。">j</a></sup><span className="woj">，為各教會向你們見證了這些事。我就是大衛的根，也是他的後裔，那明亮的晨星。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:14; 啟示錄 21:6; 以賽亞書 55:1–3"> 聖靈和新娘都說：「來吧！」那聽見的人也當說：「來吧！」乾渴的人也當來；願意的人，當無償地接受生命之水。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:2; 箴言 30:6"> 我向一切聽見這書上預言之話的人做見證<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="做見證——或譯作「做警告」。">k</a></sup>：如果有人在這些話上加添什麼，神將要把這書上所寫的災害加在他身上；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:2; 路加福音 11:52; 啟示錄 22:2"> 如果有人從這書上的預言之話中刪去什麼<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="如果有人從這書上的預言之話中刪去什麼——或譯作「如果有人刪減這預言書中的話」。">l</a></sup>，神將要從這書上所寫的生命樹<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="生命樹——有古抄本作「生命冊」。">m</a></sup>和聖城中刪去他的份。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="啟示錄 22:7; 希伯來書 9:28; 啟示錄 22:12"> 見證這些事的那一位說：<span className="woj">「是的，我快要來了！」</span><br />阿們！主耶穌啊，願你來！</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦後書 3:18; 羅馬書 16:20; 哥林多後書 13:14"> 願主耶穌<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="主耶穌——有古抄本作「我們的主耶穌基督」。">n</a></sup>的恩典與所有的聖徒<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="所有的聖徒——有古抄本作「所有的人」或「你們大家」。">o</a></sup>同在！阿們。<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本沒有「阿們。」">p</a></sup></span>
</div>
</div>

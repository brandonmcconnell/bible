<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 65:17–19; 彼得後書 3:13; 以賽亞書 66:22"> 接著，我看見一個新天新地，因為先前的天和先前的地都已經過去了，海也不再存在了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:10; 啟示錄 3:12; 啟示錄 21:10"> 我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——有古抄本作「我約翰」。">a</a></sup>也看見聖城新耶路撒冷，從神那裡、從天上降下來，已經被預備好了，就像為自己的丈夫裝飾整齊的新娘那樣。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西結書 37:27; 哥林多後書 6:16; 約翰福音 14:23"> 我又聽見有大聲音從寶座上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="從寶座上——有古抄本作「從天上」。">b</a></sup>傳來，說：<br /><span className="pl pl-1">「看哪，神的居所</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="居所——原文直譯「帳幕」。">c</a></sup><br /><span className="pl pl-1">在人間，</span><br /><span className="pl pl-1">神將要與人一同居住</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="居住——原文直譯「展開帳幕」。">d</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">他們將要做他的子民，</span><br /><span className="pl pl-1">神將要親自與他們同在，做他們的神</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「做他們的神」。">e</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 25:8; 啟示錄 7:17; 哥林多前書 15:26"> <span className="pl pl-1">神</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神——有古抄本作「他」。">f</a></sup><br /><span className="pl pl-1">要從他們的眼中抹去一切淚水。</span><br /><span className="pl pl-1">將來不再有死亡，</span><br /><span className="pl pl-1">也不再有悲傷、哭泣或痛苦，</span><br /><span className="pl pl-1">因為先前的事已經過去了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:17; 以賽亞書 42:9; 以賽亞書 43:19"> 坐在寶座上的那一位說：「看哪，我正在更新一切！」他又說：「你當寫下，因為這些話是信實的、真實的。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 7:37–38; 約翰福音 4:10; 啟示錄 7:17"> 他又對我說：「成了！我就是『阿爾法』，也是『歐米伽』；是開始，也是終結。我將要從生命水的泉源把水無償地賜給乾渴的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 6:18; 希伯來書 8:10; 啟示錄 2:11"> 那得勝的，將要繼承這些；我將要做他的神，他將要做我的兒子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 6:9–10; 啟示錄 2:11; 以弗所書 5:5–6"> 但那些膽怯的、不信的、可憎的、殺人的、淫亂的、行邪術的、拜偶像的，和所有說謊的人，他們的份就在燃燒著烈火和硫磺的湖裡。這是第二次的死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 21:2; 啟示錄 19:7; 啟示錄 16:1–17"> 拿著七個盛滿最後七災害之碗的七位天使中，有一位過來對我講話，說：「來，我要給你看看新娘，就是羔羊的妻子。」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:2; 以西結書 11:24; 以西結書 40:1–49"> 於是我在靈裡被天使帶到一座高大的山上。他給我看那從神那裡、從天上降下來的聖城耶路撒冷；</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 4:6; 啟示錄 22:5; 啟示錄 22:1"> 這城有神的榮耀，她的光輝彷彿極貴重的寶石，如同碧玉，清澈如水晶。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 48:31–34; 啟示錄 7:4–8; 啟示錄 21:17–21"> 她有又高又大的城牆，有十二個城門，城門前有十二位天使，又有名字刻在上頭，是以色列子民十二支派的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 48:31–34"> 東面三個門，北面三個門，南面三個門，西面三個門。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 11:10; 以弗所書 2:20; 以賽亞書 54:11"> 城牆有十二座基石，上面有羔羊十二使徒的十二個名字。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 2:1; 啟示錄 11:1–2; 以西結書 41:1–5"> 那位對我說話的天使<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="天使——輔助詞語。">g</a></sup>，拿著一根金蘆葦的量尺，要測量那城，就是<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="就是——或譯作「以及」。">h</a></sup>她的城門和城牆。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 48:35; 以西結書 48:8–20"> 那城布置為四方形，長度和寬度一樣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="長度和寬度一樣——有古抄本作「長度這麼長，寬度也一樣長」。">i</a></sup>。天使用蘆葦測量那城，有兩千兩百公里<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="兩千兩百公里——原文直譯「十二千視距」，包含了數字12。1視距=185公尺。">j</a></sup>；她的長、寬、高都是相等的。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 7:4; 申命記 3:11; 啟示錄 13:18"> 天使又測量了她的城牆，按人的尺度有一百四十四肘<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一百四十四肘——相當於66公尺。1肘=46公分。144是12個12，隱含了數字12。">k</a></sup>；這也是天使的尺度。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 21:11; 啟示錄 21:21; 啟示錄 21:19"> 她的城牆是用碧玉建造的；城是純金的，彷彿純淨的玻璃。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 54:11–12; 出埃及記 28:17–21; 約伯記 28:16–19"> 城牆的基石是用各種寶石裝飾的：<br /><span className="pl pl-1">第一座基石是碧玉，</span><br /><span className="pl pl-1">第二座是藍寶石，</span><br /><span className="pl pl-1">第三座是綠瑪瑙，</span><br /><span className="pl pl-1">第四座是綠寶石，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 4:3"> <span className="pl pl-1">第五座是紅瑪瑙，</span><br /><span className="pl pl-1">第六座是紅寶石，</span><br /><span className="pl pl-1">第七座是黃璧璽，</span><br /><span className="pl pl-1">第八座是水蒼玉，</span><br /><span className="pl pl-1">第九座是黃玉，</span><br /><span className="pl pl-1">第十座是翡翠，</span><br /><span className="pl pl-1">第十一座是紫瑪瑙，</span><br /><span className="pl pl-1">第十二座是紫水晶。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:18; 啟示錄 17:4; 啟示錄 22:2"> 十二個城門是十二顆珍珠；每一個門各自是由一顆珍珠造成的。城裡的大街<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="大街——或譯作「廣場」。">l</a></sup>是純金的，好像透明的玻璃。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:23; 列王紀上 8:27; 歷代志下 2:6"> 在城中我沒有看見聖所，因為主、神、全能者和羔羊就是城的聖所。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 60:19–20; 啟示錄 22:5; 啟示錄 21:11"> 這城不需要太陽和月亮來照耀，因為神的榮耀照亮她，而羔羊就是她的燈。</span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 21:26; 啟示錄 22:2; 撒迦利亞書 8:22–23"> 列國<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="列國——有古抄本作「蒙得救的列國」。">m</a></sup>都將藉著城的光行走<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="將藉著城的光行走——有古抄本作「將在城的光裡行走」。">n</a></sup>；地上的眾君王都要把他們的榮耀<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="眾君王都要把他們的榮耀——有古抄本作「眾君王都要把列國的榮耀和尊貴」。">o</a></sup>帶進城內。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 60:11; 撒迦利亞書 14:7; 啟示錄 22:5"> 她的各城門整天絕不關上，原來那裡沒有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 21:24"> 人們將要把列國的榮耀和尊貴帶進城內。</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 22:14–15; 以賽亞書 52:1; 啟示錄 20:15"> 凡是不潔淨的，行可憎和虛假之事的人，絕不能進到城內；唯有名字<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="名字——輔助詞語。">p</a></sup>被記在羔羊生命冊上的才能進去。</span>
</div>
</div>

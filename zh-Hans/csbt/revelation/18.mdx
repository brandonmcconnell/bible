<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 43:2; 路加福音 17:24; 帖撒羅尼迦後書 2:8"> 這些事以後，我看見另一位天使從天上降下來，他擁有大權；大地被他的榮光照亮了。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 14:8; 耶利米書 51:8; 耶利米書 51:37"> 他用強有力的聲音呼喊說：<br /><span className="pl pl-1">「倒塌了！大巴比倫倒塌了！</span><br /><span className="pl pl-1">她成了鬼魔居住的地方、</span><br /><span className="pl pl-1">一切汙靈的巢穴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="巢穴——或譯作「牢籠」。">a</a></sup><br /><span className="pl pl-1">、</span><br /><span className="pl pl-1">一切汙穢鳥類的巢穴、</span><br /><span className="pl pl-1">一切汙穢可憎野獸的巢穴</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一切汙穢鳥類的巢穴、一切汙穢可憎野獸的巢穴——有古抄本作「一切汙穢可憎之鳥類的巢穴」。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 14:8; 啟示錄 17:2; 啟示錄 18:9"> <span className="pl pl-1">原來萬國都喝了她淫亂憤怒</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="憤怒——或譯作「激情」。">c</a></sup><br /><span className="pl pl-1">的酒，</span><br /><span className="pl pl-1">地上的眾君王曾與她行淫亂，</span><br /><span className="pl pl-1">地上的商人也由於她極度的驕奢淫逸而發了財。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 52:11; 哥林多後書 6:17; 耶利米書 51:6"> 接著，我聽見另一個聲音從天上傳來，說：<br /><span className="pl pl-1">「我的子民哪，你們要從她那裡出來，</span><br /><span className="pl pl-1">免得在她的罪孽上有份，</span><br /><span className="pl pl-1">也免得遭受她所受的災害，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="創世記 18:20–21; 以斯拉記 9:6; 啟示錄 16:19"> <span className="pl pl-1">因為她的罪孽滔天，</span><br /><span className="pl pl-1">神也記得她的罪行。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:29; 詩篇 137:8; 耶利米書 51:24"> <span className="pl pl-1">她怎樣待人，你們也要怎樣待她，</span><br /><span className="pl pl-1">並照著她的行為加倍地報應她；</span><br /><span className="pl pl-1">你們要在她混合酒的杯子裡，</span><br /><span className="pl pl-1">加倍地混合給她喝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 47:7–9; 西番雅書 2:15; 耶利米哀歌 1:1"> <span className="pl pl-1">她怎樣炫耀自己、驕奢淫逸，</span><br /><span className="pl pl-1">你們也要照樣給她折磨和悲傷，</span><br /><span className="pl pl-1">因為她心裡說：『我坐著女王的位子</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="的位子——輔助詞語。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">我不是寡婦，絕不會經歷悲傷。』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 50:34; 耶利米書 50:31; 啟示錄 17:16"> <span className="pl pl-1">為此，在一天之內</span><br /><span className="pl pl-1">她所受的災害，就是死亡、悲傷和饑荒，</span><br /><span className="pl pl-1">就要來到。</span><br /><span className="pl pl-1">她將要在烈火中被燒掉，</span><br /><span className="pl pl-1">因為主、神——審判她的那一位是強有力的。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:3; 啟示錄 18:3; 啟示錄 17:2"> 地上的眾君王，就是那些與她行淫亂、一同驕奢淫逸的，當看見焚燒她時的煙，就會為她捶胸哀哭。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 18:19; 啟示錄 18:8; 啟示錄 18:15–17"> 他們因懼怕她所受的折磨，就遠遠地站著，說：<br /><span className="pl pl-1">「有禍了！有禍了！宏大的城，</span><br /><span className="pl pl-1">強大的巴比倫城啊！</span><br /><span className="pl pl-1">因為一時之間，</span><br /><span className="pl pl-1">你的審判就來到了！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 18:3; 啟示錄 18:23; 以西結書 27:27–36"> 地上的商人也為她哭泣、悲傷，因為再也沒有人買他們的貨物了；</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 17:4; 以西結書 27:5–25; 箴言 8:10–11"> 那些貨物就是：金、銀、寶石、珍珠，細麻布、紫色布、絲綢、深紅色布，各種香木，各種象牙製品，各種極貴重的木、銅、鐵和大理石的製品，</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 27:13; 阿摩司書 2:6; 彼得後書 2:3"> 肉桂、香料<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本沒有「香料」。">e</a></sup>、香、香液、乳香；酒、油、麵粉、麥子；牲畜、羊、馬、馬車；人的肉體和靈魂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="靈魂——或譯作「生命」。">f</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 10:6; 詩篇 106:14; 路加福音 16:25"> <span className="pl pl-1">「你心所貪戀的果子離開了你；</span><br /><span className="pl pl-1">一切珍饈美味、華麗物品，都從你那裡消逝</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="消逝——有古抄本作「離開」。">g</a></sup><br /><span className="pl pl-1">了，</span><br /><span className="pl pl-1">人絕不能再看到它們了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 18:3; 使徒行傳 19:24–27; 以西結書 27:31"> 販賣<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="販賣——輔助詞語。">h</a></sup>這些東西的商人，就是那些由於她而發了財的人，因懼怕她所受的折磨，就會遠遠地站著，哭泣、悲傷，</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:4; 路加福音 16:19–31; 啟示錄 18:10–11"> 說：<br /><span className="pl pl-1">「有禍了！有禍了！宏大的城，</span><br /><span className="pl pl-1">那曾身穿細麻、紫色、深紅色衣服，</span><br /><span className="pl pl-1">以金子、寶石、珍珠為裝飾的城啊！</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 27:27–36; 啟示錄 17:16; 以賽亞書 23:14"> <span className="pl pl-1">這麼多的財富，竟然在一時之間就化為烏有了！」</span><br />所有的船長、所有到處航行的人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="航行的人——有古抄本作「在船上的人們」。">i</a></sup>、水手們、所有靠海為業的人，都遠遠地站著。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 13:4; 以西結書 27:30–32; 啟示錄 18:9–10"> 他們看著焚燒她時的煙，呼喊說：「哪一個城能與這大城相比呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 18:10; 約書亞記 7:6; 以西結書 27:30"> 他們把塵土撒在自己頭上，哭泣、悲傷，呼喊說：<br /><span className="pl pl-1">「有禍了！有禍了！宏大的城，所有靠著她在海上有船隻的人</span><br /><span className="pl pl-1">都因她的財富發了財。</span><br /><span className="pl pl-1">她竟然在一時之間就化為烏有了！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 6:10; 啟示錄 19:1–3; 路加福音 18:7–8"> <span className="pl pl-1">上天哪、聖徒們、使徒們、先知們哪，你們應當因她歡喜！</span><br /><span className="pl pl-1">因為神已經向她施行審判，為你們懲罰她！」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 51:63–64; 以西結書 26:21; 啟示錄 5:2"> 隨後，一位強有力的天使拿起一塊像大磨石那樣的石頭，把它丟進海裡，說：<br /><span className="pl pl-1">「大巴比倫城也將這樣被猛烈地扔下去，</span><br /><span className="pl pl-1">絕不會再找到了！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 26:13; 耶利米書 25:10; 耶利米書 7:34"> <span className="pl pl-1">彈琴的、奏樂的、吹笛的、吹號之人的聲音，</span><br /><span className="pl pl-1">在你中間絕不會再聽到了！</span><br /><span className="pl pl-1">各種手藝的工匠，</span><br /><span className="pl pl-1">在你中間絕不會再找到了！</span><br /><span className="pl pl-1">磨石的聲音，</span><br /><span className="pl pl-1">在你中間絕不會再聽到了！</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 18:3; 以賽亞書 23:8; 那鴻書 3:4"> <span className="pl pl-1">燈的亮光，</span><br /><span className="pl pl-1">在你中間絕不會再照耀了！</span><br /><span className="pl pl-1">新郎和新娘的聲音，</span><br /><span className="pl pl-1">在你中間絕不會再聽到了！</span><br /><span className="pl pl-1">因為你的商人一向是地上的大人物，</span><br /><span className="pl pl-1">又因為萬國都被你的邪術</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="邪術——或譯作「巫術」或「毒品」。">j</a></sup><br /><span className="pl pl-1">所迷惑，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 17:6; 啟示錄 16:6; 耶利米書 51:49"> <span className="pl pl-1">而且先知們、聖徒們以及地上一切被殺之人的血，</span><br /><span className="pl pl-1">在你</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你——原文直譯「她」；指「巴比倫」。">k</a></sup><br /><span className="pl pl-1">那裡都被發現了。」</span></span>
</div>

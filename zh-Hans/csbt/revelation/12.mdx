<span className="v" id="v1" data-v="1" data-xref="路加福音 21:25; 以弗所書 5:32; 路加福音 21:11"> 接著，天上出現了一個大徵兆：有一個婦人身披太陽，腳踏月亮，頭上戴著十二顆星的冠冕。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 16:21; 加拉太書 4:19; 啟示錄 12:4"> 她懷了孕；後來在臨產的陣痛和分娩的折磨中喊叫起來。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:12; 啟示錄 12:9; 但以理書 7:24"> 隨後，天上出現了另一個徵兆：看哪，一條火紅色的巨龍，有七個頭和十隻角，七個頭上戴著七個王冠。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 8:9–12; 啟示錄 12:9; 約翰福音 8:44"> 牠的尾巴拖著天上星辰的三分之一，把它們摔在地上。這龍站在那快要生產的婦人面前，為要在她生產之後，吞吃她的孩子。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 19:15; 啟示錄 2:26–27; 啟示錄 12:2"> 那婦人生了一個男孩子，就是那位將要用鐵杖治理<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="治理——原文直譯「牧養」。">a</a></sup>萬國的。可是這孩子被提到神和他的寶座那裡。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 13:5; 啟示錄 11:2–3; 啟示錄 12:14"> 那婦人就逃到曠野去，在那裡有神已經為她所預備好的地方，好讓她在那裡被供養一千二百六十天。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="猶大書 1:9; 但以理書 12:1; 以弗所書 6:12"> 接著，天上發生了戰爭：米迦勒和他的天使們與龍交戰，龍和牠的使者們也應戰，</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 37:10; 啟示錄 12:11; 猶大書 1:6"> 可是龍不能得勝，天上再也沒有<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="沒有——原文直譯「找不到」。">b</a></sup>牠們的地方了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 10:18; 約翰福音 12:31; 啟示錄 20:10"> 於是那巨龍被摔了下來。牠就是那古蛇，被稱為魔鬼和撒旦，那迷惑普天下的。牠被摔在地上，牠的使者們也與牠一起被摔了下來。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="路加福音 22:31; 撒迦利亞書 3:1–2; 啟示錄 11:15"> 隨後，我聽見天上有一個大聲音說：<br /><span className="pl pl-1">「我們神的救恩、大能、國度，</span><br /><span className="pl pl-1">和他基督的權柄，現在都來到了！</span><br /><span className="pl pl-1">因為我們弟兄的控告者，</span><br /><span className="pl pl-1">就是那日夜在我們神面前控告他們的，</span><br /><span className="pl pl-1">已經被摔下去了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 10:3–5; 約翰福音 16:33; 約翰一書 5:5"> <span className="pl pl-1">他們藉著羔羊的血，藉著自己所見證的話語而勝過了牠，</span><br /><span className="pl pl-1">他們至死也沒有愛惜自己的生命。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 49:13; 啟示錄 8:13; 詩篇 96:11–13"> <span className="pl pl-1">為此，諸天和居住在其中的，你們應當慶祝！</span><br /><span className="pl pl-1">但是大地和海洋</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大地和海洋——有古抄本作「住在大地和海洋的人」。">c</a></sup><br /><span className="pl pl-1">卻有禍了，</span><br /><span className="pl pl-1">因為魔鬼知道自己的時候不多，</span><br /><span className="pl pl-1">就懷著烈怒下到你們那裡去了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 3:15; 啟示錄 12:3–5; 約翰福音 16:33"> 那龍一見自己被摔在地上，就追逼那生了男孩的婦人。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 19:4; 以賽亞書 40:31; 啟示錄 12:6"> 但那婦人被賜予了大鷹的兩個翅膀，使她可以飛到曠野，到她自己的地方；在那裡她被供養一期，二期，又半期<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一期，二期，又半期——或譯作「一年，兩年，又半年」；等於「3年半」或「42個月」或「1,260天」；參本書11:2,3；13:5；《但以理書》7:25；12:7。">d</a></sup>，遠離那蛇的面。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 8:7; 以賽亞書 59:19; 詩篇 18:4"> 蛇就在那婦人後面，從口裡吐出水來，像江河一樣，要把她沖走。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 17:6; 出埃及記 12:35–36; 列王紀下 8:9"> 可是大地幫助了那婦人；大地張開口，吞下了從龍口裡吐出的河水。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 14:12; 創世記 3:15; 啟示錄 11:7"> 於是龍就向那婦人發怒，又去與她其餘的後裔作戰，這後裔就是那些遵守神的命令、持守有關耶穌<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="耶穌——有古抄本作「耶穌基督」。">e</a></sup>見證的人。</span>
<span className="v" id="v18" data-v="18"> 然後，龍<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="龍——原文直譯「牠」或「他」。">f</a></sup>站在海邊的沙灘上。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有譯本把18節附在17節或本書13:1的開頭。">g</a></sup></span>
</div>

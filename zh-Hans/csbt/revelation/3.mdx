<span className="v" id="v2" data-v="2" data-xref="彼得前書 5:8; 提摩太後書 4:1–4; 啟示錄 16:15"> <span className="woj">你當警醒，堅固那些剩餘的、快要死去的人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人——或譯作「事」。">b</a></sup><span className="woj">。實際上，我看出你的行為在我的神面前是不完全的；</span></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 2:5; 彼得後書 3:10; 帖撒羅尼迦前書 5:2"> <span className="woj">所以你應當記住你所領受、所聽見的是什麼；你應當持守，應當悔改。如果你不警醒，我就要來臨，就像賊來臨那樣；而你絕不會知道我什麼時候臨到你。</span></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:5; 啟示錄 7:9; 傳道書 9:8"> <span className="woj">然而在薩迪斯，你還有幾名是沒有玷汙自己衣服的，他們將要身穿白衣與我同行，因為他們是配得上的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 10:32; 路加福音 12:8; 啟示錄 21:27"> <span className="woj">那得勝的，將要同樣穿上白衣，我絕不從生命冊上抹去他的名字；而且我將要在我父面前、在我父的眾天使面前，承認他的名字。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:7"> <span className="woj">「凡是有耳的，就應當聽聖靈向各教會所說的話！</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:22; 馬太福音 16:19; 啟示錄 1:18"> <span className="woj">「你要給那在費拉德菲亞教會的使者</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使者——或譯作「天使」。">c</a></sup><span className="woj">寫信說：</span><br /><span className="woj">「那位神聖的、真實的，拿著大衛的鑰匙、開了就沒有人能關、關了就沒有人能開的，這樣說：</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 16:9; 歌羅西書 4:3; 啟示錄 3:7"> <span className="woj">我知道你的行為。看哪，我在你面前賜下了一個敞開的門，是沒有人能關上的；這是因為你能力小，但你遵守了我的話語，沒有否認我的名。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:14; 啟示錄 2:9; 以賽亞書 49:23"> <span className="woj">看哪，我要使那些屬於撒旦會堂的，就是那些自稱是猶太人，其實不是猶太人，而是說謊的人——看哪，我要使他們來，在你腳前下拜；他們就會知道我已經愛了你，</span></span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 2:9; 啟示錄 14:12; 撒迦利亞書 13:9"> <span className="woj">因為你遵守了我忍耐的教導</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="教導——原文直譯「話語」或「道」。">d</a></sup><span className="woj">，我還要保守你脫離那試煉的時刻，就是那將要臨到普天下，考驗住在地上之人的時刻。</span></span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 1:12; 啟示錄 22:12; 啟示錄 2:10"> <sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「看哪，」。">e</a></sup><span className="woj">我快要來了！你應當持守你所擁有的，免得有人拿走你的冠冕。</span></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 22:4; 啟示錄 21:2; 啟示錄 14:1"> <span className="woj">那得勝的，我將要讓他在我神的聖所中做柱石，他絕不再出去。我要把我神的名，我神之城的名——就是從我的神那裡、從天上降下來的新耶路撒冷的名，和我的新名，都寫在他身上。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 2:7"> <span className="woj">「凡是有耳的，就應當聽聖靈向各教會所說的話！</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:15; 啟示錄 1:5; 哥林多後書 1:20"> <span className="woj">「你要給那在勞迪西亞教會的使者</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="使者——或譯作「天使」。">f</a></sup><span className="woj">寫信說：</span><br /><span className="woj">「那位阿們，就是那信實的、真實的見證者，神創造之物的本源，這樣說：</span></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 12:11; 馬太福音 6:24; 列王紀上 18:21"> <span className="woj">我知道你的行為，你既不冷也不熱；我真希望你或冷或熱。</span></span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 2:5; 撒迦利亞書 11:8–9; 耶利米書 14:19"> <span className="woj">正因為你是溫的，既不熱也不冷，我就要把你從我口中吐出去，</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; 何西阿書 12:8; 羅馬書 7:24"> <span className="woj">因為你說『我是富有的；我發了財，什麼都不缺』，卻不知道你是可悲的、可憐的、貧窮的、瞎眼的、赤身的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 16:15; 彼得前書 1:7; 以賽亞書 55:1"> <span className="woj">我建議你向我買被火煉過的金子，使你富足；又買白衣穿上，使你赤身的羞恥不露出來；又買眼藥抹你的眼睛，使你能看見。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前書 11:32; 希伯來書 12:5–11"> <span className="woj">凡是我所愛的，我都責備、管教。所以你應當熱心，應當悔改。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:36–37; 啟示錄 19:9; 約翰福音 14:21–23"> <span className="woj">看哪，我站在門口敲門。如果有人聽見我的聲音就開門，我就會進到他那裡，而且我與他、他與我，將要一同吃宴席。</span></span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:12; 馬太福音 19:28; 啟示錄 2:26–27"> <span className="woj">那得勝的，我將要准許他與我一起坐在我的寶座上；就像我已經得勝，與我父一起坐在他的寶座上那樣。</span></span>
</div>

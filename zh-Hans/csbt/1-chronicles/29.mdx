<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CH" data-book-slug="1-chronicles" data-book-name="歷代志上" data-chapter="29" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 22:5; 列王紀上 3:7; 歷代志下 13:7"> 大衛王對全體會眾說：「神特別揀選了我兒子所羅門，他還年少幼嫩，而這工程極大，因為這宮殿不是為人，而是為耶和華神建造的。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 22:3–5; 哥林多後書 8:3; 以賽亞書 54:11–12"> 我已經盡力為我神的殿預備了金器所需的金子、銀器所需的銀子、銅器所需的銅、鐵器所需的鐵、木器所需的木材，還有紅瑪瑙石、鑲嵌用的孔雀石，以及彩石、各樣的寶石和大量的大理石。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 21:24; 詩篇 27:4; 詩篇 26:8"> 此外，因我喜愛我神的殿，我除了為聖殿所預備的一切之外，也把我自己的金銀珍寶獻給了我神的殿，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:28; 歷代志上 22:14; 約伯記 28:16"> 有三千他連得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="三千他連得——相當於100公噸。1他連得=34.2公斤。">a</a></sup>俄斐黃金、七千他連得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="七千他連得——相當於240公噸。">b</a></sup>純銀，要用來裝飾殿宇的牆，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 7:2–3; 出埃及記 35:5–9; 以斯拉記 7:15–16"> 並要用金子做金器，銀子做銀器，藉著工匠的手做成各樣的工藝品。今天誰甘願奉獻，全心歸於耶和華呢？」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 9:7; 歷代志上 27:25–1; 以賽亞書 60:3–10"> 於是各家族的首領、以色列各支派的首領、千夫長、百夫長和管理王事務的官員，都甘願奉獻。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 7:70–71; 以斯拉記 2:69"> 他們為神殿的服事捐獻了金子五千他連得零一萬達利克<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五千他連得零一萬達利克——相當於171公噸又84公斤。1他連得=34.2公斤；1達利克金幣=8.4公克。">c</a></sup>，銀子一萬他連得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一萬他連得——相當於342公噸。">d</a></sup>，銅一萬八千他連得<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一萬八千他連得——相當於616公噸。">e</a></sup>，鐵十萬他連得<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="十萬他連得——相當於3,420公噸。">f</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 23:8; 歷代志上 26:21–22"> 那些有寶石的也捐獻寶石到耶和華殿的庫房裡，由革順人耶希業經手管理。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 9:7–8; 哥林多後書 8:3; 列王紀上 8:61"> 民眾因這些人甘願奉獻而歡喜，因為他們是全心甘願奉獻給耶和華的；大衛王也極其歡喜快樂。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以弗所書 1:3; 彼得前書 1:3; 羅馬書 1:7"> 於是大衛在全體會眾面前頌讚耶和華，大衛說：「我們先祖以色列的神耶和華啊，你是當受頌讚的，從永遠到永遠<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="永遠到永遠——或譯作「亙古到永遠」。">g</a></sup>！</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 1:3; 但以理書 4:34–35; 提摩太前書 1:17"> 耶和華啊，尊大、權柄、榮耀、威嚴、尊榮都是你的，天上地上的萬有都是你的。耶和華啊，國度也是你的，你顯為尊崇，為萬有之首。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 3:16; 歷代志下 20:6; 申命記 8:18"> 財富和榮耀都從你而來，是你掌管一切。你手中有能力和權柄；你的手使人偉大、強盛。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:1; 哥林多後書 9:15; 哥林多後書 8:16"> 我們的神哪，現在我們稱謝你，讚美你榮耀之名。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:17; 哥林多後書 3:5; 羅馬書 11:36"> 「我究竟算什麼呢？我的子民算什麼呢？我們竟然能這樣甘願奉獻！其實一切都從你而來，我們只是把從你手中得來的獻給你。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 144:4; 利未記 25:23; 詩篇 102:11"> 我們是依靠你的外人，是寄居的，像我們所有的祖先那樣。我們在世的日子如同虛影，沒有盼望。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 29:14; 詩篇 24:1; 歷代志下 31:10"> 耶和華我們的神哪，我們預備了這麼多，要為你的聖名建造殿宇，這些都是從你手中得來的，一切都是屬於你的。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 17:10; 箴言 11:20; 歷代志上 28:9"> 我的神哪，我知道你察驗人心，喜悅公平；我懷著正直的心，甘願奉獻了這一切，現在我也歡喜地看見你在這裡的子民都甘願奉獻給你。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 32:39; 耶利米書 10:23; 希伯來書 13:21"> 我們先祖亞伯拉罕、以撒、以色列的神耶和華啊，求你永遠保守你子民心中這樣的意念動機，使他們立定心志歸向你。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 72:1; 歷代志上 28:9; 雅各書 1:17"> 求你賜我兒子所羅門一顆完全的心，好使他遵守你的誡命、法度和律例，去做成這一切，用我所預備的建造這殿宇。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 95:6; 出埃及記 4:31; 詩篇 135:19–21"> 然後大衛對全體會眾說：「現在要頌讚耶和華你們的神！」全體會眾就頌讚耶和華他們祖先的神，俯身向耶和華、向王下拜。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 7:4–9; 民數記 15:7; 以斯拉記 6:17"> 第二天他們向耶和華獻祭，向耶和華所獻的燔祭有公牛一千頭、公綿羊一千隻、綿羊羔一千隻，還有同獻的酒祭，以及為全體以色列人獻上的大量祭物。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 2:35; 歷代志上 23:1; 出埃及記 24:11"> 那一天，他們極其歡喜地在耶和華面前吃喝。 所羅門繼位<br />他們再次確立大衛的兒子所羅門作王，為耶和華膏立他作君王，又膏立撒督作祭司。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 2:12; 歷代志上 28:5; 羅馬書 13:1"> 於是所羅門坐在耶和華設立<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="設立——輔助詞語。">h</a></sup>的寶座上，接替他父親大衛作王。他就亨通，全體以色列人都聽從他。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 2:3–9; 以西結書 17:18; 創世記 24:2"> 所有的首領和勇士，以及大衛王所有的兒子，都舉手臣服所羅門王。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 1:12; 歷代志下 1:1; 傳道書 2:9"> 耶和華在全體以色列人面前高抬所羅門，賜給他王權的尊榮，是在他之前任何一個以色列王都比不上的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 18:14; 詩篇 78:71–72"> 耶西的兒子大衛作全以色列的王，</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:11; 撒母耳記下 5:4–5; 歷代志上 3:4"> 他統治以色列的日子有四十年：在希伯崙統治七年，在耶路撒冷統治三十三年。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:15; 使徒行傳 13:36; 歷代志上 23:1"> 大衛富貴榮華，盡享天年，壽數滿足而死，他的兒子所羅門接替他作王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 9:9; 撒母耳記下 12:1–7; 歷代志上 21:9–11"> 大衛王從始至終的事蹟，看哪，都記在《先見撒母耳紀事》《先知拿單紀事》和《先見迦得紀事》上。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 4:25; 但以理書 4:23; 但以理書 2:21"> 他的王權、他的武力，以及他和以色列並這地列國所經歷的時事，也都記在這些書上。</span>
</div>
</div>

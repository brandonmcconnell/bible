<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CH" data-book-slug="1-chronicles" data-book-name="歷代志上" data-chapter="15" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 16:1; 歷代志上 17:1–5; 詩篇 132:5"> 大衛在大衛城為自己建造宮殿，又為神的約櫃預備地方，為它支搭了一座帳篷。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 10:8; 申命記 31:9; 民數記 18:1–8"> 那時大衛說：「除了利未人以外，沒有人可以抬神的約櫃，因為耶和華揀選了他們抬耶和華的約櫃，並且永遠事奉他。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:1; 歷代志上 13:5; 歷代志上 15:1"> 大衛招聚全體以色列人到耶路撒冷，要把耶和華的約櫃抬上來放到大衛所預備的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 6:16–22; 歷代志上 12:26–28; 歷代志上 6:16–30"> 大衛又招聚亞倫的子孫和利未人：</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 6:22–24"> 哥轄的子孫中，有首領烏列和他的族兄弟一百二十人；</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 6:29–30"> 米拉利的子孫中，有首領亞撒雅和他的族兄弟兩百二十人；</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 15:11; 歷代志上 23:8"> 革順的子孫中，有首領約珥和他的族兄弟一百三十人；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 6:22"> 以利撒番的子孫中，有首領示瑪雅和他的族兄弟兩百人；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 6:18; 歷代志上 23:19; 歷代志上 26:30–31"> 希伯倫的子孫中，有首領以利業和他的族兄弟八十人；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 6:18; 歷代志上 6:18; 歷代志上 23:12"> 烏基業的子孫中，有首領亞米拿達和他的族兄弟一百一十二人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 12:28; 列王紀上 2:35; 撒母耳記上 22:20–23"> 大衛召來撒督和亞比亞特兩位祭司，以及利未人烏列、亞撒雅、約珥、示瑪雅、以利業和亞米拿達，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:6; 出埃及記 19:14–15; 歷代志上 15:14"> 對他們說：「你們是利未人各父系的首領，你們和你們的族兄弟要使自己分別為聖，好把以色列的神耶和華的約櫃抬上來放到我所預備的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 6:3; 哥林多前書 14:40; 約翰一書 1:8–10"> 因為上一次你們不在場，我們也沒有按照規定求問神，所以耶和華我們的神就對我們發怒。」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 29:15; 約珥書 2:16–17; 歷代志下 29:34"> 於是祭司和利未人使自己分別為聖，為要把以色列的神耶和華的約櫃抬上來。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 4:15; 民數記 7:9; 歷代志下 5:9"> 利未子孫照著耶和華的話，按摩西所吩咐的，用杠子把神的約櫃扛在肩上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志上 13:8; 歷代志下 5:13; 歷代志上 16:42"> 大衛吩咐利未人的首領指派他們的族兄弟作歌手，用里拉琴、豎琴、銅鈸等各種樂器伴奏，高唱喜樂的歌。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:39; 歷代志上 6:44; 歷代志上 6:33"> 利未人就指派了約珥的兒子希幔和他的族兄弟比利迦的兒子亞薩，以及他們的族兄弟米拉利子孫中古沙雅的兒子伊坦；</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 26:4; 歷代志上 26:8; 歷代志上 13:14"> 其次是與他們一起的族兄弟：撒迦利亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亞——依據七十士譯本以及有些古抄本；馬索拉文本作「兒子撒迦利亞」。">a</a></sup>、雅阿基業、示米拉莫、耶希業、烏尼、以利押、比納雅、瑪西雅、瑪塔提雅、以利斐利戶、彌克尼雅，以及門衛俄別·以東和耶伊列。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 25:6; 歷代志上 16:5; 歷代志上 13:8"> 歌手希幔、亞薩和伊坦要敲響銅鈸；</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:1–11"> 撒迦利亞、雅基業、示米拉莫、耶希業、烏尼、以利押、瑪西雅和比納雅彈里拉琴，用「少女」曲調<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="用「少女」曲調——或譯作「調用阿拉莫特」。">b</a></sup>；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 10:5; 歷代志上 25:6–7; 詩篇 81:1–2"> 瑪塔提雅、以利斐利戶、彌克尼雅、俄別·以東、耶伊列和阿撒細雅彈豎琴，用「第八」曲調<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="用「第八」曲調——或譯作「調用謝米尼特」。">c</a></sup>領奏。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 15:27; 歷代志上 15:16; 歷代志上 25:7–8"> 克納尼雅是利未人歌唱的領隊，教導人歌唱，因為他精通於此。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 84:10; 列王紀下 22:4; 歷代志上 9:21–23"> 比利迦和以利加拿是看守約櫃的門衛。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 16:6; 民數記 10:8; 歷代志上 15:28"> 祭司示巴尼、約沙法、拿旦業、亞瑪賽、撒迦利亞、比納雅和以利以謝，在神的約櫃前吹號。俄別·以東和耶希亞也是看守約櫃的門衛。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 6:12–23; 彌迦書 5:2; 腓立比書 3:3"> 於是大衛、以色列的長老們和千夫長們一起前去，歡歡喜喜地把耶和華的約櫃從俄別·以東家裡抬上來。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 23:29; 歷代志上 29:14; 詩篇 66:13–15"> 神幫助那些抬耶和華約櫃的利未人，他們就祭獻了七頭公牛和七隻公綿羊。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 2:18; 撒母耳記下 6:14"> 大衛和所有抬約櫃的利未人，並歌手和歌手的首領克納尼雅，都穿著細麻布的外袍，大衛還穿著細麻布的以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 13:8; 歷代志上 15:16; 歷代志下 5:12–13"> 全體以色列人在歡呼和號角聲中，奏響號筒、銅鈸、里拉琴和豎琴，把耶和華的約櫃抬上來。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 6:20–23; 撒母耳記下 6:16; 申命記 31:26"> 當耶和華的約櫃進入大衛城時，掃羅的女兒米甲透過窗戶俯看，看見大衛王跳躍歡慶，心裡就藐視他。</span>
</div>
</div>

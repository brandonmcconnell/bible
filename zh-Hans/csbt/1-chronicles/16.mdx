<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 15:1; 以斯拉記 6:16–18; 歷代志下 5:6–7"> 他們把神的約櫃抬來，安放在大衛為它支搭的帳篷內，然後在神面前獻上燔祭和平安祭。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 47:10; 創世記 14:19; 利未記 1:3"> 大衛獻完了燔祭和平安祭，就奉耶和華的名祝福民眾，</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 8:10; 以西結書 45:17; 歷代志下 35:7–8"> 又分給以色列所有的人，無論男女，每人一個餅、一個棗餅、一個葡萄餅。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志上 23:27–32; 詩篇 72:18; 詩篇 103:2"> 大衛指定一些利未人在耶和華的約櫃前事奉，來記念、稱謝、讚美耶和華以色列的神。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 6:39; 歷代志下 29:25; 歷代志上 15:16–24"> 為首的是亞薩，其次是撒迦利亞、耶伊列、示米拉莫、耶希業、瑪塔提雅、以利押、比納雅、俄別·以東和耶伊列，他們彈奏里拉琴和豎琴等樂器，而亞薩奏響銅鈸。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 13:12; 歷代志下 29:26–28; 歷代志下 5:12–13"> 比納雅和雅哈希兩位祭司常在神的約櫃前吹號。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 22:1; 詩篇 18:1; 撒母耳記下 23:1–2"> 那一天，大衛首次指定亞薩和他的族兄弟負責稱謝耶和華：</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 105:1–15; 以賽亞書 12:4; 列王紀下 19:19"> <span className="pl pl-1">你們當稱謝耶和華，呼求他的名，</span><br /><span className="pl pl-1">在萬民中傳揚他的作為；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 3:16; 詩篇 96:1–3; 詩篇 98:1–4"> <span className="pl pl-1">當向他歌唱，歌頌他，</span><br /><span className="pl pl-1">談論他一切的奇妙作為；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:7–8; 耶利米書 29:13; 詩篇 34:2"> <span className="pl pl-1">當以他的聖名誇耀，</span><br /><span className="pl pl-1">願尋求耶和華的人心裡歡喜！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:8–9; 西番雅書 2:2–3; 詩篇 68:35"> <span className="pl pl-1">你們當尋求耶和華和他的力量，</span><br /><span className="pl pl-1">一直尋求他的容面。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 111:4; 詩篇 119:20; 詩篇 103:2"> <span className="pl pl-1">他的僕人以色列的後裔啊，</span><br /><span className="pl pl-1">他所揀選的雅各的子孫哪，</span><br /><span className="pl pl-1">你們當記念他所行的奇妙作為，</span><br /><span className="pl pl-1">記念他的奇事和他口中的法規！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="詩篇 48:10–11; 以賽亞書 26:9; 出埃及記 15:2"> <span className="pl pl-1">他是耶和華我們的神，</span><br /><span className="pl pl-1">他的公正充滿全地。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 105:8; 瑪拉基書 4:4; 申命記 7:9"> <span className="pl pl-1">他記念自己的約，直到永遠；</span><br /><span className="pl pl-1">記念他所吩咐的話，直到千代——</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:3; 創世記 17:2; 創世記 35:11"> <span className="pl pl-1">就是他與亞伯拉罕所立的約，</span><br /><span className="pl pl-1">向以撒所起的誓；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 17:7–8; 創世記 35:11–12; 約書亞記 24:11–13"> <span className="pl pl-1">又把這約給雅各立為律例，</span><br /><span className="pl pl-1">給以色列立為永遠的約；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 13:15; 彌迦書 2:5; 創世記 17:8"> <span className="pl pl-1">他說：「我要把迦南地賜給你，</span><br /><span className="pl pl-1">作為你們分得的繼業。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="創世記 34:30; 申命記 7:7; 使徒行傳 7:5"> <span className="pl pl-1">那時他們</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他們——原文作「你們」；參《詩篇》105:12。">a</a></sup><br /><span className="pl pl-1">人數稀少，實在很少，</span><br /><span className="pl pl-1">在那地是寄居的；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 46:6; 創世記 20:1; 創世記 46:3"> <span className="pl pl-1">他們從這國流浪到那國，</span><br /><span className="pl pl-1">從這邦流浪到那邦。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 12:17; 創世記 20:3; 出埃及記 7:15–18"> <span className="pl pl-1">他不容任何人欺壓他們，</span><br /><span className="pl pl-1">還為他們的緣故責備君王：</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="創世記 20:7; 詩篇 105:15; 創世記 49:8–10"> <span className="pl pl-1">「你們不可碰我的受膏者，</span><br /><span className="pl pl-1">不可惡待我的先知。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="詩篇 96:1–13; 詩篇 71:15; 以賽亞書 51:6–8"> <span className="pl pl-1">全地啊，你們當向耶和華歌唱，</span><br /><span className="pl pl-1">日復一日地傳揚他的救恩！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 12:2–6; 但以理書 4:1–3; 詩篇 22:27"> <span className="pl pl-1">當在列國中講述他的榮耀，</span><br /><span className="pl pl-1">在萬民中講述他的奇妙作為；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 89:7; 詩篇 76:7; 詩篇 66:3–5"> <span className="pl pl-1">因耶和華偉大，當受極大的讚美；</span><br /><span className="pl pl-1">他超越一切神明，當受敬畏；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 102:25; 利未記 19:4; 以賽亞書 42:5"> <span className="pl pl-1">萬民的一切神明都是虛無的偶像，</span><br /><span className="pl pl-1">而耶和華造了諸天。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:11; 詩篇 96:6; 詩篇 28:7–8"> <span className="pl pl-1">尊榮和威嚴在他的面前，</span><br /><span className="pl pl-1">力量和喜樂在他的居所。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 15:10; 腓立比書 4:13; 詩篇 100:1–2"> <span className="pl pl-1">萬民萬族啊，你們當把榮耀和力量</span><br /><span className="pl pl-1">歸給耶和華，歸給耶和華！</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 100:4; 詩篇 96:9; 以賽亞書 6:3"> <span className="pl pl-1">當把耶和華之名的榮耀歸給他，</span><br /><span className="pl pl-1">帶著供物，來到他的面前。</span><br /><span className="pl pl-1">當向聖潔威嚴的耶和華下拜；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 33:9; 詩篇 148:5–6; 希伯來書 1:3"> <span className="pl pl-1">全地啊，你們當在他面前震撼！</span><br /><span className="pl pl-1">是的，世界被確立，不致動搖！</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 96:10; 啟示錄 19:6; 詩篇 97:1"> <span className="pl pl-1">願諸天歡喜，願大地快樂，</span><br /><span className="pl pl-1">願人們在列國中說：「耶和華作王了！」</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 148:9–10; 以賽亞書 44:23; 詩篇 98:7–8"> <span className="pl pl-1">願海洋和其中所充滿的澎湃如雷，</span><br /><span className="pl pl-1">願田野和其中的一切都歡慶。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 98:9; 詩篇 96:12–13; 啟示錄 11:17–18"> <span className="pl pl-1">那時森林中的樹木將在耶和華面前歡呼，</span><br /><span className="pl pl-1">因為他來要審判大地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="詩篇 106:1; 歷代志下 7:3; 詩篇 107:1"> <span className="pl pl-1">你們當稱謝耶和華，</span><br /><span className="pl pl-1">他是美善的，他的慈愛永遠長存！</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 106:47–48; 彼得前書 2:9; 詩篇 14:7"> <span className="pl pl-1">你們要說：</span><br /><span className="pl pl-1">「拯救我們的神哪，求你拯救我們！</span><br /><span className="pl pl-1">求你從列國中招聚我們、解救我們，</span><br /><span className="pl pl-1">好讓我們稱頌你的聖名，</span><br /><span className="pl pl-1">以讚美你為福樂！」</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 8:15; 詩篇 72:18–19; 列王紀上 8:56"> <span className="pl pl-1">以色列的神耶和華是當受頌讚的，</span><br /><span className="pl pl-1">從永遠到永遠</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="永遠到永遠——或譯作「亙古到永遠」。">b</a></sup><br /><span className="pl pl-1">。</span><br />全體民眾都說「阿們」，並且讚美耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="歷代志下 8:14; 以斯拉記 3:4; 歷代志上 16:4–6"> 大衛安排亞薩和他的族兄弟在耶和華的約櫃前，要按著每天的任務，常在約櫃前事奉；</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 26:10; 歷代志上 13:14; 歷代志上 25:3"> 還有俄別·以東和他的族兄弟六十八人，耶杜頓的兒子俄別·以東以及何薩作門衛。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 3:4; 歷代志上 15:11; 歷代志下 1:3–4"> 大衛又安排祭司撒督和他的兄弟眾祭司在基遍的高壇，在耶和華的帳幕前事奉，</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 28:3–8; 出埃及記 29:38–42; 歷代志下 31:3"> 要照著律法所記的一切，就是耶和華所吩咐以色列的，清晨和傍晚在燔祭的祭壇上向耶和華獻上常獻的燔祭。</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志下 5:13; 歷代志上 25:1–6; 歷代志下 20:21"> 還有希幔、耶杜頓和其餘被選出、被指名的人，與他們一起稱謝耶和華：「他的慈愛永遠長存！」</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 150:3–6; 歷代志上 25:6–7; 歷代志下 29:25–28"> 希幔、耶杜頓與他們一同用號筒、銅鈸等各種樂器發聲歌頌神。耶杜頓的子孫守門。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 6:19–20; 創世記 18:19; 詩篇 101:2"> 於是全體民眾各回各家，大衛也回去為自己的家人祝福。</span>
</div>

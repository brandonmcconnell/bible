<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CH" data-book-slug="1-chronicles" data-book-name="歷代志上" data-chapter="21" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 24:1–25; 撒迦利亞書 3:1; 約伯記 2:4–6"> 撒旦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒旦——指那控告者。">a</a></sup>起來攻擊以色列，誘導大衛去數點以色列人。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 27:23–24; 撒母耳記下 3:10; 撒母耳記下 24:15"> 大衛對約押和軍兵的將領們說：「你們去，數點以色列人，從比爾-謝巴直到但，然後回來告訴我，我好知道他們的數目。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; 以賽亞書 26:15; 歷代志上 19:13"> 約押說：「願耶和華使他的軍兵<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="軍兵——或譯作「子民」。">b</a></sup>增添到現有的一百倍。我主我王啊！他們不全都是我主的臣僕嗎？我主何必想做這事呢？為什麼要使以色列陷入罪裡呢？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:29; 出埃及記 1:17; 但以理書 3:18"> 但王的命令強過約押，約押就出去，走遍全以色列，之後回到了耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 24:9; 歷代志上 27:23"> 約押把軍兵的統計數目呈報大衛：全以色列中拿刀劍的人有一百一十萬，猶大中拿刀劍的人有四十七萬。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 27:24; 民數記 1:47–49; 撒母耳記下 20:9–10"> 但是利未人和便雅憫人，他沒有數點在內，因為約押厭惡王這個命令。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 15:5; 約書亞記 7:5; 撒母耳記下 21:14"> 這事在神的眼中看為惡，於是他打擊了以色列。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 12:13; 約翰一書 1:9; 創世記 34:7"> 大衛對神說：「我做這事，犯了大罪！現在，求你除去你僕人的罪孽，因我做了極其愚蠢的事！」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 9:9; 撒母耳記下 24:11; 歷代志上 29:29"> 耶和華吩咐大衛的先見迦得，說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 13:21–22; 啟示錄 3:19; 箴言 1:29–31"> 「你去告訴大衛說：『耶和華如此說：我給你三樣災，你從其中挑選一個，我就降在你身上。』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> 迦得就來見大衛，對他說：「耶和華如此說：『任你選擇：</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 28:27; 使徒行傳 12:23; 以西結書 14:19–21"> 三年饑荒，或者三個月在敵人面前被驅逐，被仇敵的刀劍追逼，或者三天被耶和華的刀劍攻擊，國中發生瘟疫，耶和華的使者在以色列的全境施行毀滅。』現在，你看看我應該怎麼回話給派遣我來的那一位。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 130:7; 以賽亞書 55:7; 腓立比書 1:23"> 大衛對迦得說：「這使我非常為難！還是讓我落在耶和華手中吧，因為他有極其豐盛的憐憫；請不要讓我落在人的手中。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 12:30; 歷代志上 27:24; 列王紀下 19:35"> 於是耶和華在以色列降下瘟疫，以色列中倒斃了七萬人。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:6; 出埃及記 32:14; 耶利米書 26:18"> 神派遣天使去毀滅耶路撒冷，天使正要毀滅時，耶和華見了就後悔降這禍患，他對施行毀滅的天使說：「夠了，住手吧！」那時耶和華的使者站在耶布斯人歐珥楠的打穀場那裡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 14:5; 列王紀上 21:27; 列王紀下 6:17"> 大衛舉目，看見耶和華的使者站在天地之間，手裡拿著拔出的刀，伸在耶路撒冷之上。大衛和長老們都披上麻布，臉伏於地。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 16:63; 撒母耳記下 24:17; 約翰福音 10:11–12"> 大衛對神說：「吩咐數點人口的不是我嗎？是我犯了罪，是我行了大惡！這群羊，他們做了什麼呢？耶和華我的神哪，願你的手對付我和我的父家，不要讓瘟疫臨到你的子民。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 3:1; 撒母耳記下 24:18; 歷代志上 21:11"> 耶和華的使者吩咐迦得去告訴大衛，叫大衛上去，在耶布斯人歐珥楠的打穀場上為耶和華立一座祭壇。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 9:6; 約翰福音 2:5; 列王紀下 5:10–14"> 大衛就照著迦得奉耶和華的名所說的話上去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 6:11"> 那時歐珥楠正在踹小麥，歐珥楠轉過身來，看見了天使，就與他的四個兒子一同躲藏起來。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 25:23; 撒母耳記下 24:18–20"> 大衛來到歐珥楠那裡，歐珥楠看見大衛，就從打穀場出來，臉伏於地向大衛下拜。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 24:21; 列王紀上 21:2; 民數記 25:8"> 大衛對歐珥楠說：「請把打穀場這塊地賣給我，我好在這裡為耶和華築一座祭壇；請按足價賣給我，使瘟疫在百姓中間止住。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 24:22–23; 撒母耳記上 6:14; 創世記 23:4–6"> 歐珥楠對大衛說：「只管拿去用，我主我王看怎樣好就怎樣做吧！看，我還送上牛作燔祭，打穀器具作木柴，小麥作素祭；這一切我都送給王。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 16:16–17; 創世記 14:23; 創世記 23:13"> 大衛王對歐珥楠說：「不，我一定要按足價購買，我不能拿你的東西給耶和華，也不能獻上無償的燔祭。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 24:24–25"> 大衛就為那塊地付了歐珥楠重六百謝克爾<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="六百謝克爾——相當於6.8公斤。1謝克爾=11.4公克。">c</a></sup>的金子。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 9:24; 士師記 6:21; 箴言 15:8"> 大衛在那裡為耶和華築了一座祭壇，獻上燔祭和平安祭。他向耶和華呼求，耶和華就從天上降火在燔祭的祭壇上，應允了他。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 18:11; 詩篇 103:20; 歷代志上 21:15–16"> 耶和華吩咐天使，天使就把劍收回鞘中。</span>
<span className="v" id="v28" data-v="28"> 那時候，大衛見耶和華在耶布斯人歐珥楠的打穀場上回應了他，就在那裡獻祭——</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 16:39; 歷代志下 1:3; 歷代志下 1:13"> 摩西在曠野所造的耶和華的帳幕，以及燔祭的祭壇，那時候都在基遍的高壇——</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 1:17; 希伯來書 12:28–29; 啟示錄 15:4"> 可是大衛不能夠來到神面前求問，因為耶和華使者的刀使他驚慌失措。</span>
</div>
</div>

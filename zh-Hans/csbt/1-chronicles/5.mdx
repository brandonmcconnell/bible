<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 35:22; 創世記 29:32; 創世記 48:15–22"> 以下是以色列的長子魯本的子孫。魯本雖然是長子，但他玷汙了父親的床榻，他的長子名份就被轉給以色列之子約瑟的兩個兒子，所以在家譜記錄中沒有長子名份。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 2:6; 彌迦書 5:2; 希伯來書 7:14"> 猶大雖然在他兄弟們中強盛，領袖也是從他而出，但長子名份是屬於約瑟的。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 46:9; 出埃及記 6:14; 民數記 26:5–9"> 以色列長子魯本的兒子是<br />哈諾、法路、希斯倫和迦米。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 約珥的子孫是：他的兒子示瑪雅，<br />示瑪雅的兒子歌革，歌革的兒子示每，</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 示每的兒子米迦，米迦的兒子利阿亞，<br />利阿亞的兒子巴力，</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 5:26; 列王紀下 15:29; 歷代志下 28:20"> 巴力的兒子備拉。<br />備拉被亞述王提革拉·毗列色擄走了，他是魯本支派的領袖。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 5:17"> 備拉的族兄弟，按著自己的家族，照著他們的家系記錄，有首領耶伊列、撒迦利亞、</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 5:4; 民數記 32:34; 民數記 32:38"> 比拉；比拉是亞撒的兒子，亞撒是示瑪的兒子，示瑪是約珥的兒子。約珥住在亞羅珥，直到尼波和巴力梅翁一帶；</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 22:8–9"> 他又到東邊居住，一直到幼發拉底河這邊曠野的入口，因為他們在基列地的牲畜增多了。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 21:9; 歷代志上 5:18–21; 詩篇 83:6"> 掃羅年間，他們與哈格利人作戰，哈格利人敗在他們手下，他們就住在基列東邊全域哈格利人的帳篷中。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 13:11; 約書亞記 13:24–28; 申命記 3:10–17"> 迦得的子孫在他們對面，住在巴珊地，直到撒迦。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他們有首領約珥，副首領沙番，還有雅奈和住在巴珊的沙法。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 按著他們的父家，他們的族兄弟是米迦勒、米書蘭、示巴、約賴、雅干、細亞和希伯，共七人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 這些都是亞比亥的子孫；亞比亥是戶利的兒子，<br />戶利是耶羅亞的兒子，耶羅亞是基列的兒子，<br />基列是米迦勒的兒子，米迦勒是耶示篩的兒子，<br />耶示篩是耶哈多的兒子，耶哈多是布斯的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 古尼的孫子、押比疊的兒子亞希，是他們父家的首領。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 27:29; 雅歌 2:1; 以賽亞書 35:2"> 他們住在基列、巴珊和附屬的村鎮，以及整個沙崙牧野，直到它的盡頭。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:16; 列王紀下 14:28; 列王紀下 15:32"> 他們全都在猶大王約坦年間和以色列王耶羅波安年間，被記錄在家譜中。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 1:3; 約書亞記 4:12–13"> 魯本、迦得和瑪拿西半支派的勇士，那些拿盾牌刀劍、拉弓射箭、受過作戰訓練的，有四萬四千七百六十人，都能列隊出戰。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 25:15; 歷代志上 1:31; 歷代志上 5:10"> 他們與哈格利人、伊突人、拿非施人和挪達人作戰。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 22:4–5; 詩篇 9:10; 歷代志下 18:31"> 他們得到幫助，哈格利人和所有與哈格利人同盟的人都被交在他們手中，因為他們在戰爭中向神哀求，神就因為他們信靠他而應允了他們的祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 18:13; 民數記 31:35"> 他們擄掠了夏甲人的牲畜，有駱駝五萬頭、羊二十五萬隻、驢子兩千隻；還擄掠了人口十萬。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 32:8; 羅馬書 8:31; 約書亞記 23:10"> 有許多夏甲人被殺倒下，因為這場戰爭是出於神。他們就取代夏甲人住下，直到被擄時期。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 3:8–9; 雅歌 4:8; 詩篇 133:3"> 瑪拿西半支派的子孫住在那地，從巴珊直到巴力黑門、示尼珥和黑門山；他們人數眾多。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 4:38"> 以下是他們父家的首領：以弗、伊示、以利業、亞斯列、耶利米、赫達維亞、耶赫迪業，都是英勇的戰士、有名望的人，是他們父家的首領。</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 17:5; 詩篇 106:34–39; 出埃及記 34:15"> 但他們對祖先的神不忠，行淫追隨當地之民的神明，這民是神從他們面前所除滅的。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 15:19; 列王紀下 17:6; 列王紀下 15:29"> 所以，以色列的神觸動了亞述王普勒——亞述王提革拉·毗列色的心，他就把魯本支派、迦得支派和瑪拿西半支派的人擄走，帶到了哈臘、哈博、哈拉，以及歌散河邊，直到今日。</span>
</div>

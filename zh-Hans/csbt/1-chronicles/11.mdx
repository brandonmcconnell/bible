<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 5:1–16; 歷代志上 12:23–40; 士師記 9:2"> 全體以色列人聚集到希伯崙來見大衛，說：「看哪，我們是你的骨肉之親。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 5:2; 約翰福音 10:4; 詩篇 78:71"> 從前掃羅作王的時候，帶領以色列出入的就是你，你的神耶和華也曾對你說：『你要牧養我的子民以色列，你要作我的子民以色列的領袖。』」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 16:12–13; 撒母耳記上 16:1; 撒母耳記下 5:3"> 以色列的長老們都來到希伯崙見王，大衛在希伯崙，在耶和華面前與他們立約，他們就膏立大衛作以色列的王，正如耶和華藉著撒母耳所傳的話。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 1:21; 創世記 15:21; 約書亞記 15:8"> 大衛和以色列全軍來到耶路撒冷——就是耶布斯，那地的居民都是耶布斯人。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 5:2; 列王紀上 8:1; 詩篇 87:2"> 耶布斯的居民對大衛說：「你進不到這裡來！」然而大衛攻取了錫安的堡壘，就是後來的大衛城。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 8:16; 撒母耳記下 20:23; 撒母耳記下 3:27"> 大衛說：「誰先擊殺耶布斯人，他就作元帥，作首領。」洗魯雅的兒子約押先攻上去，就作了元帥。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 11:5; 撒母耳記下 5:7; 詩篇 2:6"> 大衛住在這堡壘裡，因此人們稱它為「大衛城」。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 9:6; 列王紀上 11:27; 列王紀下 12:20"> 大衛把城的周圍建造起來，從梯壘直到四圍城牆；約押修復城其餘的部分。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 3:1; 以賽亞書 41:10; 歷代志上 9:20"> 大衛越來越強大，因為萬軍之耶和華與他同在。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 11:3; 撒母耳記上 16:1; 歷代志上 12:38"> 這些是大衛勇士們的首領，就是與全以色列一同極力擁護他王權的人，他們照著耶和華所應許以色列的，立他為王。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 23:8; 歷代志上 27:2; 歷代志上 12:18"> 以下是大衛的勇士們的名單：<br />哈克莫尼人雅朔班，是眾軍官<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="眾軍官——或譯作「三十勇士」。">a</a></sup>之首，他曾揮動長矛，一次擊殺了三百人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 27:4; 撒母耳記下 23:17–19; 撒母耳記下 23:23"> 其次是阿赫阿人朵多的兒子以利亞撒，他是三勇士之一。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 23:11–12; 撒母耳記上 17:1"> 從前他與大衛在巴斯達憫，非利士人聚集在那裡要打仗，那裡有一塊長滿了大麥的田地。以色列軍兵從非利士人面前逃跑，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 144:10; 列王紀下 5:1; 撒母耳記上 14:23"> 他們卻在那塊田中站立，守護那塊田，擊殺非利士人。這樣耶和華施行了大拯救。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 14:9; 撒母耳記下 5:18; 以賽亞書 17:5"> 有一次，三十個首領中的那三個人下去，到亞杜蘭山洞的磐石那裡去見大衛。非利士人的軍隊在利乏音谷紮營。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 10:5; 撒母耳記上 13:4; 撒母耳記上 13:23"> 那時大衛在要塞中，而非利士人的駐軍在伯利恆。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:14; 以賽亞書 12:3; 撒母耳記下 23:15–16"> 大衛心中渴望，說：「誰能把伯利恆城門旁水窖裡的水帶來給我喝啊！」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:13; 撒母耳記上 19:5; 使徒行傳 20:24"> 那三個人就突破非利士人的防營，從伯利恆城門旁的水窖裡打水，提上來，帶回大衛那裡。但大衛不肯喝，而是把水澆奠在耶和華面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 23:17; 詩篇 72:14; 士師記 9:17"> 說：「我絕不可在我的神面前做這事！我怎麼能喝那些冒生命危險之人的血呢？這水是他們冒著生命危險取回來的。」所以大衛不肯喝。這些是三勇士的事蹟。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 26:6; 歷代志上 2:16; 撒母耳記下 20:6"> 約押的弟弟亞比篩，是三十<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三十—— 依據古敘利亞文譯本；馬索拉文本作「三」。">b</a></sup>勇士之首；他曾揮動長矛殺了三百人，所以和那三勇士一樣有名。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 15:41; 馬太福音 13:8"> 他在三十<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十—— 依據古敘利亞文譯本；馬索拉文本作「三」。">c</a></sup>勇士中倍受尊崇，所以成為他們的首領，只是不及那三勇士。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 23:20–23; 撒母耳記下 8:18; 約書亞記 15:21"> 耶赫亞達的兒子比納雅，是來自卡布策勒的勇士，有許多事蹟。他曾擊殺了摩押的兩個英雄，也曾在下雪的日子，下到坑裡殺了一隻獅子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:7; 撒母耳記上 17:4; 申命記 3:11"> 他還擊殺了一個身高五肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五肘——相當於2.3公尺。1肘=45.7公分。">d</a></sup>的埃及人；這埃及人手中有長矛，比納雅卻拿著棍子下去攻擊他，從他手中搶奪了長矛，用那長矛把他殺了。</span>
<span className="v" id="v24" data-v="24"> 這些是耶赫亞達的兒子比納雅的事蹟，他和三勇士一樣有名。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 20:23"> 看哪，他在三十勇士中受尊崇，但是不及那三勇士。大衛立他作侍衛長。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 27:7; 撒母耳記下 21:19; 撒母耳記下 2:18–23"> 軍隊中的勇士有：<br />約押的弟弟亞撒暉，<br />伯利恆人朵多的兒子伊勒哈南，</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 23:25–26"> 哈律人沙瑪，<br />佩羅尼人希利斯，</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="歷代志上 27:12; 歷代志上 27:9; 撒母耳記下 23:27"> 提克亞人益吉的兒子伊拉，<br />亞拿突人亞比以謝，</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 23:27–28; 歷代志上 27:11"> 戶沙人西比凱，<br />阿赫阿人伊萊，</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="歷代志上 27:13; 歷代志上 27:15; 撒母耳記下 23:29"> 尼托法人瑪哈萊，<br />尼托法人巴納的兒子希勒，</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 23:29"> 基比亞的便雅憫人利拜的兒子伊太，<br />比拉頓人比納雅，</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳記下 23:30–31"> 迦實溪谷的人戶萊，<br />亞拉巴人亞比耶，</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 巴魯米人阿茲瑪維，<br />沙本人以利雅哈巴，</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 23:32–33"> 基孫人哈善的兒子們，<br />哈拉人沙基的兒子約拿單，</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 23:33–34"> 哈拉人沙卡爾的兒子亞希暗，<br />吾珥的兒子以利法勒，</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 米基拉人希弗，<br />佩羅尼人亞希雅，</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 23:35"> 迦密人希斯羅，<br />伊斯拜的兒子拿萊，</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 23:36"> 拿單的兄弟約珥，<br />哈格利的兒子彌伯哈，</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 亞捫人洗勒，<br />替洗魯雅之子約押拿兵器的比錄人拿哈萊，</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 20:26"> 以帖人伊拉，<br />以帖人迦立，</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志上 2:36; 撒母耳記下 23:39; 撒母耳記下 11:6–27"> 赫提人烏利亞，<br />阿赫萊的兒子撒巴德，</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 魯本人示撒的兒子阿迪納——他是魯本支派的一個首領，有三十人跟隨他，</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 瑪迦的兒子哈南，<br />彌特尼人約沙法，</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 亞施塔拉人烏西亞，<br />亞羅珥人赫坦的兒子沙瑪和耶伊列，</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45"> 提洗人示姆利的兒子耶迪阿業和他的兄弟約哈，</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> 瑪哈維人以利業，<br />伊利納姆的兒子耶利拜和約沙維亞，<br />摩押人伊特瑪，</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47"> 還有以利業、俄備得和米瑣巴人雅西業。</span>
</div>

<div className="bp">
<span className="v" id="v2" data-v="2"> 但、約瑟、便雅憫、<br />拿弗他利、迦得和亞設。</span>

<span className="v" id="v3" data-v="3" data-xref="創世記 38:2–10; 創世記 46:12; 民數記 26:19"> 猶大的兒子是珥、俄南和示拉，這三人是迦南女子芭書婭給他生的。猶大的長子珥做耶和華眼中看為惡的事，耶和華就把他擊殺了。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:3; 創世記 38:13–30; 尼希米記 11:4"> 猶大的兒媳塔瑪爾給他生了法勒斯和謝拉。猶大總共有五個兒子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 46:12; 路得記 4:18; 民數記 26:21"> 法勒斯的兒子是希斯倫和哈姆勒。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 4:31; 約書亞記 7:17–18; 約書亞記 7:1"> 謝拉的兒子是澤姆利、伊坦、希幔、卡珥克勒、達拉，總共五人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 6:18; 申命記 7:26; 約書亞記 7:25"> 迦米的兒子是亞干，他違犯了當滅之物的禁令<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的禁令——輔助詞語。">a</a></sup>，給以色列帶來了禍患。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 伊坦的兒子是亞撒利雅。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志上 2:42; 馬太福音 1:3; 路得記 4:19"> 希斯倫所生的兒子是耶拉米列、蘭和基路拜。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 1:4; 民數記 1:7; 民數記 2:3"> 蘭生亞米拿達，<br />亞米拿達生猶大子孫的領袖拿順，</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路得記 4:21; 馬太福音 1:4–5; 路加福音 3:32"> 拿順生撒門<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="撒門——或音譯作「薩瑪」；下同。">b</a></sup>，<br />撒門生波阿斯，</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:12; 歷代志上 10:14; 以賽亞書 11:10"> 波阿斯生俄備得，<br />俄備得生耶西。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 17:13; 撒母耳記上 17:28; 歷代志上 20:7"> 耶西生了長子以利押，<br />次子亞比拿達，三子示米亞，</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 四子拿旦業，五子拉代，</span>

<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:10–11; 撒母耳記上 17:12–14"> 六子阿鮮，七子大衛。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:6; 撒母耳記下 3:39; 撒母耳記下 2:18–23"> 他們的姐妹是洗魯雅和婭比蓋。<br />洗魯雅的兒子是亞比篩、約押、亞撒暉，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 17:25; 列王紀上 2:32; 撒母耳記下 20:4–12"> 婭比蓋生亞瑪撒，<br />亞瑪撒的父親是以實瑪利人耶特爾。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 希斯倫的兒子迦勒與妻子阿蘇巴和耶略生了兒子，這些兒子是耶設、朔罷、押墩。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 2:50; 歷代志上 2:24; 歷代志上 4:4"> 阿蘇巴死後，迦勒又娶以法她，生了戶珥。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 31:2; 出埃及記 36:1–2; 出埃及記 37:1"> 戶珥生烏利，烏利生比撒列。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 27:1; 申命記 3:15; 民數記 26:29"> 後來希斯倫六十歲時，娶了基列之父瑪吉的女兒，與她同房，她就為希斯倫生了西割。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 13:30; 申命記 3:14; 民數記 32:41"> 西割生睚珥，睚珥在基列地擁有二十三座城；</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 13:30; 申命記 3:14; 民數記 32:41–42"> 後來基述人和亞蘭人從他們手中奪取了這些睚珥鎮，以及基納和附屬的村鎮，共六十座城。這些都是基列之父瑪吉的子孫。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 4:5; 歷代志上 2:9; 撒母耳記上 30:14"> 希斯倫死了以後，迦勒與父親希斯倫的妻子以法她同房，她為迦勒生了提克亞之祖亞施戶。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="此節依據七十士譯本；馬索拉文本作「希斯倫在迦勒-以法他死了以後，希斯倫的妻子婭比雅為他生了提克亞之祖亞施戶。」">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 希斯倫長子耶拉米列的兒子是：長子蘭，以及布拿、阿連、阿鮮和亞希雅。</span>
<span className="v" id="v26" data-v="26"> 耶拉米列又有另外一個妻子，名叫婭塔拉，她是阿南的母親。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 耶拉米列長子蘭的兒子是瑪斯、雅憫和以結。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 阿南的兒子是沙買和雅達，<br />沙買的兒子是納達布和亞比述。</span>
<span className="v" id="v29" data-v="29"> 亞比述的妻子名叫亞比亥，她為亞比述生了阿赫班和莫利德。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 納達布的兒子是塞列德和阿帕因，塞列德沒有兒子就死了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歷代志上 2:34–35"> 阿帕因的兒子是伊示，<br />伊示的兒子是示珊，<br />示珊的兒子是阿赫萊。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 沙買兄弟雅達的兒子是耶特爾和約拿單，耶特爾沒有兒子就死了。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 約拿單的兒子是比勒和撒薩。這些都是耶拉米列的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 示珊沒有兒子，只有女兒。示珊有一個埃及奴僕，名叫耶哈。</span>
<span className="v" id="v35" data-v="35"> 示珊把女兒給奴僕耶哈為妻，生下亞泰歸他。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="歷代志上 11:41"> 亞泰生拿單，<br />拿單生撒巴德，</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 撒巴德生以弗拉，<br />以弗拉生俄備得，</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 俄備得生耶戶，<br />耶戶生亞撒利雅，</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 亞撒利雅生希利斯，<br />希利斯生以利亞薩，</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 以利亞薩生西斯買，<br />西斯買生沙勒姆，</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41"> 沙勒姆生耶加米雅，<br />耶加米雅生以利沙瑪。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="歷代志上 2:23–24; 希伯來書 12:23; 羅馬書 8:29"> 耶拉米列兄弟迦勒的兒子有：<br />長子米沙，他是西弗的父親；<br />次子瑪利沙<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="次子瑪利沙——馬索拉文本作「瑪利沙的眾子」。">d</a></sup>，是希伯倫的父親。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 希伯倫的兒子是可拉、塔普阿、利肯和示瑪。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 示瑪生了約克安之父拉罕。<br />利肯生了沙買。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約書亞記 15:58"> 沙買的兒子是瑪雲，瑪雲是伯促爾的父親。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="歷代志上 2:18–19; 歷代志上 2:48"> 迦勒的妾以法生了哈蘭、莫扎和伽澤茲，<br />哈蘭生伽澤茲。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47"> 雅代的兒子是利健、約坦、基珊、毗力、以法和沙亞弗。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="創世記 25:5–6; 歷代志上 2:46"> 迦勒的妾瑪迦生了示別、特哈拿，</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 15:31; 歷代志上 2:42; 以賽亞書 10:31"> 又生麥瑪拿之父沙亞弗，抹比拿之父和基比亞之父示法。迦勒的女兒是婭撒。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="撒母耳記上 7:1; 約書亞記 15:60; 歷代志上 2:53"> 這些都是迦勒的子孫。<br />以法她的長子是戶珥，戶珥的兒子是：<br />基列-耶琳之祖朔巴、</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="歷代志上 4:4; 約翰福音 7:42; 馬太福音 2:6"> 伯利恆之祖撒門、<br />伯迦德之祖哈勒。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="歷代志上 4:2"> 基列-耶琳之祖朔巴的子孫是哈羅耶，一半的瑪拿哈人，</span>

</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="尼希米記 7:26; 以斯拉記 2:22; 尼希米記 12:28"> 撒門的子孫是伯利恆人、尼托法人、阿塔羅-伯約押人、一半的瑪拿哈人、佐拉人；</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀下 10:15; 士師記 1:16; 耶利米書 35:19"> 還有住在雅比斯的文士家族：特拉人、示米押人和蘇甲人。他們都是基尼人，是利甲家的族長哈末的後人。</span>

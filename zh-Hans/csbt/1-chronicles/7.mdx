<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CH" data-book-slug="1-chronicles" data-book-name="歷代志上" data-chapter="7" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:13; 民數記 26:23–24"> 以薩迦的兒子是陀拉、普瓦、雅實布和希姆崙，共四人。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 24:1–9; 歷代志上 27:23–24; 歷代志上 27:1"> 陀拉的兒子是烏基、勒法雅、耶勒、雅買、易伯散和撒母耳，都是他們父家的首領，是陀拉族譜系中英勇的戰士，大衛年間他們的數目有兩萬兩千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 烏基的兒子是伊斯拉希雅，伊斯拉希雅的兒子是米迦勒、俄巴底亞、約珥和伊示亞，共五人，都是首領。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 12:32"> 按著他們父家的譜系，跟隨他們的作戰軍兵有三萬六千人，因為他們的妻兒眾多。</span>
<span className="v" id="v5" data-v="5"> 他們的族兄弟，以薩迦所有家族中英勇的戰士，按著他們的家譜記錄，共有八萬七千人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 46:21; 歷代志上 8:1–40; 歷代志上 7:10–11"> 便雅憫的兒子是比拉、比結和耶迪阿業，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 17:17–18; 歷代志上 21:1–5"> 比拉的兒子是伊茲本、烏基、烏基業、耶利莫和以利，共五人，都是他們父家的首領，是英勇的戰士。他們記錄家譜的，有兩萬兩千零三十四人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 比結的兒子是細米拉、約阿施、以利以謝、以利約奈、歐姆利、耶利莫、亞比雅、亞納圖和阿勒米特，這都是比結的兒子。</span>
<span className="v" id="v9" data-v="9"> 他們按著各父家首領的譜系記錄了家譜，都是英勇的戰士，共兩萬零兩百人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 3:15–30"> 耶迪阿業的兒子是比勒罕，比勒罕的兒子是耶烏施、便雅憫、以胡德、克拿阿納、細坦、塔爾施和亞希沙哈。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 17:13–19"> 這些都是耶迪阿業的兒子，是各父系的首領、英勇的戰士；他們能上陣出戰的，共一萬七千兩百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 26:38–39; 創世記 46:21; 歷代志上 7:15"> 此外還有以珥的兒子書皮姆和戶皮姆，阿赫爾的兒子戶西姆。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 26:48–49; 創世記 30:3–8; 創世記 35:22"> 拿弗他利的兒子是雅赫茲列、古尼、耶則爾、沙勒姆。他們都是碧拉的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 32:30–42; 士師記 5:14; 申命記 3:13–15"> 瑪拿西的兒子是亞斯列，是他的亞蘭妾所生的，她還生了基列的父親瑪吉。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:33; 民數記 36:1–12; 民數記 27:1–11"> 瑪吉娶了一個妻子，是戶皮姆和書皮姆的妹妹，名叫瑪迦。瑪吉有另一繫的子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瑪吉……的子孫——輔助詞語；參《約書亞記》17:3。">a</a></sup>名叫西羅非哈，西羅非哈只有女兒。</span>
<span className="v" id="v16" data-v="16"> 瑪吉的妻子瑪迦生了一個兒子，她給他起名為佩雷示；佩雷示的兄弟名叫謝雷示，謝雷示的兒子是烏蘭和利肯，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 12:11"> 烏蘭的兒子是比丹。<br />這些是基列的子孫，基列是瑪吉的兒子，瑪吉是瑪拿西的兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:24; 士師記 6:11; 士師記 8:2"> 基列的妹妹哈莫莉克生了伊施赫德、亞比以謝、瑪拉。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 謝米達的兒子是阿西揚、示劍、利克希、阿尼安。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 26:35–36"> 以法蓮的兒子是書提拉，<br />書提拉的兒子是貝列德，<br />貝列德的兒子是塔哈特，<br />塔哈特的兒子是伊拉達，<br />伊拉達的兒子是塔哈特，</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 塔哈特的兒子是撒巴德，<br />撒巴德的兒子是書提拉。<br />以法蓮的兒子還有以謝爾和以利亞德，被當地的迦特人殺了，因為他們下去奪取迦特人的牲畜。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 2:11; 創世記 37:34"> 他們的父親以法蓮悲慟了許多日子，他的族兄弟都來安慰他。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 23:5"> 後來以法蓮與妻子同房，她就懷孕，生了一個兒子，以法蓮給兒子起名為比利亞，因為他家裡遭了禍患。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 16:3; 約書亞記 16:5; 歷代志下 8:5"> 他的女兒是謝伊拉，謝伊拉建造了下伯賀崙和上伯賀崙，以及烏曾-謝伊拉。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 比利亞的兒子是利法和利謝，<br />利謝的兒子是特拉，<br />特拉的兒子是塔罕，</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 塔罕的兒子是拉丹，<br />拉丹的兒子是亞米忽，<br />亞米忽的兒子是以利沙瑪，</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民數記 13:8; 民數記 13:16; 出埃及記 17:9–14"> 以利沙瑪的兒子是嫩，<br />嫩的兒子是約書亞。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 28:19; 約書亞記 16:2–3; 歷代志上 6:66–67"> 他們的產業和居住的地方是伯特利和附屬的村鎮，東邊的拿蘭，西邊的基色和附屬的村鎮，以及示劍和附屬的村鎮，直到艾雅和附屬的村鎮；</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:22–29; 撒迦利亞書 12:11; 列王紀下 9:27"> 還有靠近瑪拿西子孫邊界的伯珊和附屬的村鎮，特納克和附屬的村鎮，米吉多和附屬的村鎮，多珥和附屬的村鎮。以色列的兒子約瑟的子孫就住在這些地方。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 46:17; 民數記 26:44–46"> 亞設的兒子是伊姆納、伊施瓦、伊施韋和比利亞，還有他們的妹妹西拉。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 比利亞的兒子是希伯和瑪結，瑪結是比爾仔特的父親。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 希伯生了雅弗列、朔梅爾、赫坦和他們的妹妹淑雅。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 雅弗列的兒子是琶薩、賓哈勒和阿示瓦，這些是雅弗列的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 朔梅爾的兒子是亞希、羅迦、戶巴<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="戶巴——傳統音譯作「耶戶巴」。">b</a></sup>和亞蘭。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 他的兄弟希連的兒子是佐法、伊姆納、示列斯和亞瑪爾。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 佐法的兒子是蘇阿赫、哈尼弗、書阿勒、比利、伊姆拉、</span>
<span className="v" id="v37" data-v="37"> 比冊爾、赫德、沙瑪、希勒沙、益蘭、比爾拉。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 耶特爾的兒子是耶弗尼、皮斯巴和阿拉。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 烏拉的兒子是阿拉赫、哈尼業和利茨業。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歷代志上 21:1–5; 撒母耳記下 24:1–9"> 這些人都是亞設的子孫，是他們父家的首領，是精選的勇士，在領袖中為首。他們的家譜記錄裡，能上陣出戰的，數目有兩萬六千人。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="創世記 46:21; 歷代志上 7:6–12; 民數記 26:38"> 便雅憫生了長子比拉，<br />次子阿實別，三子亞哈拉，</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2"> 四子挪哈，五子勒法。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 46:21; 民數記 26:40"> 比拉的兒子是阿達爾、基拉、亞比忽、</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 亞比書、奈曼、亞何亞、</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 7:12; 民數記 26:39; 士師記 3:15"> 基拉、謝弗番和戶蘭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志上 2:54; 士師記 3:20–30; 歷代志上 7:10"> 以下是埃胡德的子孫，他們這些人是迦巴居民各父系的首領，曾被遷徙到瑪拿哈；</span>
<span className="v" id="v7" data-v="7"> 有奈曼、亞希雅、基拉——是他使他們遷徙的——基拉生了烏撒和亞希忽。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得記 1:1; 創世記 25:6"> 沙哈萊姆休了他的兩個妻子戶茜姆和巴阿拉以後，又在摩押地生養孩子，</span>
<span className="v" id="v9" data-v="9"> 他的妻子赫德示生了約巴、洗比雅、米沙、瑪勒幹、</span>
<span className="v" id="v10" data-v="10"> 耶烏茲、撒其亞和米爾瑪；這些都是他的兒子，是各父系的首領。</span>
<span className="v" id="v11" data-v="11"> 他與戶茜姆生了阿比突和以利帕力。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 2:33; 尼希米記 7:37; 尼希米記 6:2"> 以利帕力的子孫是希伯、米珊和謝梅德，謝梅德建造了阿挪和羅德以及附屬的村鎮。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志上 2:52; 約書亞記 19:42; 歷代志上 4:4"> 還有比利亞和示瑪，他們是阿雅崙的居民各父系的首領，他們曾經趕走了迦特的居民；</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 又有亞希約、沙煞、耶利莫、</span>
<span className="v" id="v15" data-v="15"> 希巴迪亞、阿拉德、埃德、</span>
<span className="v" id="v16" data-v="16"> 米迦勒、伊施巴和約哈，都是比利亞的兒子；</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 又有希巴迪亞、米書蘭、希西基、希伯、</span>
<span className="v" id="v18" data-v="18"> 伊施米萊、伊斯利亞和約巴。他們都是以利帕力的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 還有雅其姆、澤克利、扎布迪、</span>
<span className="v" id="v20" data-v="20"> 以利乃、洗勒太、以利業、</span>
<span className="v" id="v21" data-v="21"> 亞達雅、比拉雅和申拉，都是示每的兒子；</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 伊施班、希伯、以利業、</span>
<span className="v" id="v23" data-v="23"> 阿布頓、澤克利、哈南、</span>
<span className="v" id="v24" data-v="24"> 哈納尼雅、以攔、安陀提雅、</span>
<span className="v" id="v25" data-v="25"> 伊弗底雅和毗努伊勒，都是沙煞的兒子；</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 珊示萊、示哈利、亞塔利雅、</span>
<span className="v" id="v27" data-v="27"> 雅利西、以利亞和澤克利，都是耶羅罕的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士師記 1:21; 約書亞記 15:63; 尼希米記 11:1"> 這些人都是各父系的首領，在他們的譜系中為首。他們住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志上 9:35–38"> 基遍之祖耶伊列<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶伊列——輔助詞語；參《歷代志上》9:35。">a</a></sup>住在基遍，他的妻子名叫瑪迦。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 9:36–37"> 他的長子是阿布頓，然後是蘇珥、基士、巴力、納達布、</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 9:37"> 格多、亞希約、撒迦、</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 9:38"> 米克羅；米克羅生了示米亞。他們也與族兄弟一同住在耶路撒冷，在他們眾兄弟對面。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 9:1; 撒母耳記下 2:8; 撒母耳記上 31:2"> 尼珥生基士，基士生掃羅，掃羅生了約拿單、麥基舒亞、亞比拿達和伊施巴力。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 4:4; 撒母耳記下 9:12; 撒母耳記下 9:10"> 約拿單的兒子是米力巴力，米力巴力生了米迦。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歷代志上 9:41"> 米迦的兒子是皮敦、米勒、塔利亞和亞哈斯。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="歷代志上 9:42"> 亞哈斯生耶赫阿達，<br />耶赫阿達生阿勒米特、阿茲瑪維和澤姆利，<br />澤姆利生莫扎，</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 9:43"> 莫扎生比尼亞，<br />比尼亞的兒子是勒法，勒法的兒子是以利亞薩，以利亞薩的兒子是亞悉。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 亞悉有六個兒子，以下是他們的名字：亞斯利甘、波基路、以實瑪利、示亞利雅、俄巴底亞和哈南，這些都是亞悉的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 亞悉的兄弟以設的兒子是：長子烏蘭，次子耶烏施，三子以利菲烈。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="詩篇 128:3–6; 歷代志下 14:8; 歷代志上 12:2"> 烏蘭的子孫都是英勇的戰士，是弓箭手。他們兒孫眾多，共一百五十人。<br />以上都是便雅憫子孫。</span>
</div>

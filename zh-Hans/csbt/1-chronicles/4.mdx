<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1CH" data-book-slug="1-chronicles" data-book-name="歷代志上" data-chapter="4" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:12; 創世記 38:29; 民數記 26:20–21"> 猶大的子孫是法勒斯、希斯倫、迦米、戶珥和朔巴。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 歷代志上 2:52–54; 約書亞記 15:33"> 朔巴的兒子利阿亞生雅哈，<br />雅哈生亞戶買和拉哈；<br />這些是佐拉人的各家族。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士師記 15:11; 歷代志下 11:6"> 以坦人之祖如下：耶斯列、伊施瑪、伊得巴，他們的妹妹名字是哈慈勒珀妮；</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志上 4:18; 歷代志上 2:50; 歷代志上 4:39"> 毗努伊勒是格多的父親；<br />以謝爾是戶沙的父親；<br />這些都是伯利恆之祖戶珥的子孫。戶珥是以法她的長子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 2:24"> 提克亞人之祖亞施戶有兩個妻子：赫拉和拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉生了亞戶撒、希弗、提米尼、阿哈示塔利，這些都是拿拉的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 赫拉的兒子是洗列、瑣哈爾和伊提南。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 克茲生了阿諾布、措比巴，以及哈崙之子阿哈黑爾的各家族。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 4:21; 歷代志上 7:23; 創世記 35:18"> 雅比斯比他的兄弟們更有尊榮。他母親給他起名為雅比斯，說：「我在痛苦中生的。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:7–11; 詩篇 116:1–4; 箴言 10:22"> 雅比斯呼求以色列的神說：「但願你大大祝福我，擴大我的邊界！願你的手與我同在，願你使我脫離禍患，不受傷害！」神成全了他的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 書哈的兄弟基律生了伊施屯之父米希爾。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 伊施屯生了伯拉法、帕西亞，以及納哈什城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="納哈什城——或譯作「珥-納哈什」。">a</a></sup>之祖提欣納；這些就是利迦人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 15:17; 士師記 1:13; 士師記 3:9–11"> 基納斯的兒子是俄陀聶和西萊雅。<br />俄陀聶的兒子是哈塔、</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 11:35; 列王紀下 24:14"> 梅諾泰，梅諾泰生了俄弗拉。<br />西萊雅生了哈拉欣谷<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哈拉欣谷——或譯作「格哈拉欣人」、「匠人谷」。">b</a></sup>之祖約押，他們都是工匠。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 13:6; 民數記 14:6–10; 約書亞記 15:13–20"> 耶弗尼之子迦勒的子孫是以路、以拉和拿安，以拉的兒子是基納斯。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶哈利勒的兒子是西弗、西法、提利和亞撒列。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 4:19; 歷代志上 6:57; 約書亞記 15:50"> 以斯拉的兒子是耶特爾、米列、以弗和雅倫。米列所娶法老的女兒比提婭生了米利暗、沙買和以實提莫之祖益巴，這些是比提婭的兒子；米列的猶大妻子生了格多之祖雅列，梭哥之祖希伯和撒挪亞之祖耶庫蒂爾。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 15:44; 撒母耳記上 23:1–13"> 霍迪亞的妻子是娜娢的姐妹，她的兒子是迦米人基伊拉之祖，以及瑪迦人以實提莫之祖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 示門的兒子是暗嫩、林拿、本哈南和提倫。<br />伊示的子孫是澤赫特和便澤赫特。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 38:5; 歷代志上 2:3; 民數記 26:20"> 猶大的兒子示拉的子孫是：利迦之祖珥，瑪利沙之祖拉阿達，在伯亞實比織造細麻布的各家族。</span>
<span className="v" id="v22" data-v="22"> 還有約敬，克則巴人，在摩押作了主人的約阿施和薩拉，以及雅叔比利恆，這些是古代的記錄。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 81:6; 歷代志上 4:14"> 他們都是陶匠，是尼塔因和格德拉的居民，他們住在那裡為王工作。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 46:10; 出埃及記 6:15; 民數記 26:12–14"> 西緬的子孫是尼姆利、雅憫、雅立、謝拉和掃羅；</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 掃羅的兒子沙勒姆，沙勒姆的兒子米比衫，米比衫的兒子米施瑪。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 米施瑪的子孫是米施瑪的兒子哈姆列，哈姆列的兒子扎克爾，扎克爾的兒子示每。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民數記 26:14; 民數記 26:22; 民數記 2:13"> 示每有十六個兒子，六個女兒，但他兄弟們的兒女不多，他們整個家族也不如猶大的子孫那樣眾多。</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 19:2–3; 約書亞記 15:28–29; 約書亞記 19:9"> 他們住在比爾-謝巴、漠拉達、哈薩書爾、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:3–4"> 碧拉、埃曾、托拉德、</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 11:28; 約書亞記 19:4–5; 撒母耳記上 30:1"> 彼土利、霍爾瑪、洗革拉、</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 19:5–6"> 伯瑪克波、哈薩蘇撒、伯比利和沙拉音。直到大衛作王，這些都是他們的城，</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 19:7"> 包括附屬的村莊；還有以坦、阿音、臨門、托肯和阿珊五座城，</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 19:8"> 以及這些城周圍所有的村莊，直到巴力<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="巴力——或譯作「巴阿拉」；參《約書亞記》19:8。">c</a></sup>；這些是他們居住的地方。他們也為自己記錄家譜：</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 有米所巴、雅米勒、亞瑪謝的兒子約沙、</span>
<span className="v" id="v35" data-v="35"> 約珥、耶戶；耶戶是約示比的兒子，約示比是西萊雅的兒子，西萊雅是阿希業的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 還有以利約奈、雅格巴、約朔海、亞撒雅、亞迪業、耶西瑪利、比納雅、</span>
<span className="v" id="v37" data-v="37"> 細撒；細撒是示非的兒子，示非是亞龍的兒子，亞龍是耶達雅的兒子，耶達雅是示姆利的兒子，示姆利是示瑪雅的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志上 5:24; 創世記 6:4"> 這些按名字記下來的，都是他們各家族的領袖；他們的父家繁衍眾多。</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志上 4:4; 歷代志上 4:18; 約書亞記 15:58"> 他們往格多的路口去，直到山谷東邊，為自己的羊群尋找草場。</span>
<span className="v" id="v40" data-v="40" data-xref="士師記 18:7–10; 詩篇 105:23; 詩篇 78:51"> 他們找到了肥沃美好的草場，那地也邊界寬廣，平靜安穩，從前住在那裡的是含族的人。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 14:28–32; 列王紀下 18:8–12; 歷代志上 4:34–38"> 這些按名字記下來的人，在猶大王希西加年間前來，攻擊含族人的帳篷和在那裡遇見的米烏尼人，把他們滅絕淨盡，直到今日；又取代他們住在那裡，因為有草場可以牧放他們的羊群。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 36:8–9; 申命記 1:2"> 這些西緬子孫當中，有五百人往西珥山去，他們的首領是伊示的眾子皮拉提、尼利雅、勒法雅和烏基業。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記上 30:17; 撒母耳記上 15:7–8; 撒母耳記下 8:12"> 他們擊殺了亞瑪力人中逃脫的餘剩者，就住在那裡，直到今日。</span>
</div>
</div>

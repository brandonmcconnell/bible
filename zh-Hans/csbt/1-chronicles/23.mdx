<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 29:28; 歷代志上 28:5; 列王紀上 1:33–39"> 大衛年邁，壽數滿足時，立他兒子所羅門為以色列的王。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:1; 歷代志下 34:29–30; 歷代志上 13:1"> 大衛招聚以色列的所有首領，以及祭司和利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 23:24; 民數記 4:2–49"> 三十歲以上的利未人都被數點，按著他們的人頭，數目是男丁三萬八千。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 19:8; 申命記 16:18; 歷代志上 26:29–31"> 其中監管耶和華殿工作的有兩萬四千人，作官長和審判官的有六千人，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:25–26; 歷代志下 8:14; 詩篇 87:7"> 門衛有四千人，那些用大衛所預備的頌讚樂器來讚美耶和華的，有四千人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 8:14; 歷代志上 6:1; 歷代志上 6:16"> 大衛又按著利未的兒子革順、哥轄和米拉利的宗族，給他們分配班組。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 26:21; 出埃及記 6:17; 歷代志上 6:17–20"> 革順人有拉丹和示每。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志上 6:33–34; 歷代志上 15:20–21; 歷代志上 15:7"> 拉丹的兒子，長子是耶希業，其次是澤坦和約珥，共三人。</span>
<span className="v" id="v9" data-v="9"> 這些人是拉丹各父系的首領。<br />示每的兒子是示羅米、哈薛和哈蘭，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 示每的子孫是雅哈、細撒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="細撒——依據七十士譯本；馬索拉文本作「細拿」；參照下一節。">a</a></sup>、耶烏施和比利亞，這四人都是示每的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 雅哈是長子，細撒是次子；耶烏施和比利亞子孫不多，歸為一個父家，同屬一個職份。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 6:18; 民數記 3:27; 民數記 26:58"> 哥轄的兒子是阿姆蘭、以斯哈、希伯倫和烏基業，共四人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 21:5; 出埃及記 6:20; 撒母耳記上 2:28"> 阿姆蘭的兒子是亞倫和摩西。<br />亞倫和他的子孫永遠被分別出來，為要被分別為至聖的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="為要被分別為至聖的——或譯作「為要把至聖之物分別為聖」。">b</a></sup>，在耶和華面前燒香、事奉，奉耶和華的名祝福，直到永遠。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:1; 詩篇 90:1; 歷代志上 26:23–25"> 至於神人摩西，他的子孫被算在利未支派中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 18:3–4; 出埃及記 2:22; 出埃及記 4:20"> 摩西的兒子是革順和以利以謝。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志上 26:24; 歷代志上 25:20; 歷代志上 24:20"> 革順的兒子，有長子謝布業。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:25"> 以利以謝的兒子，有頭生的利哈比雅；以利以謝沒有別的兒子，但利哈比雅的兒子卻很多。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志上 26:26; 歷代志上 24:22"> 以斯哈的兒子，有長子示羅米。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 24:23; 歷代志上 15:9; 歷代志上 23:12"> 希伯倫的兒子，有長子耶利雅，<br />次子亞瑪利雅，三子雅哈希，<br />四子耶咖緬。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 烏基業的兒子，有長子米迦，<br />次子伊示亞。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 6:19; 歷代志上 6:20; 歷代志上 24:26–30"> 米拉利的兒子有瑪赫利和穆希，<br />瑪赫利的兒子有以利亞撒和基士。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歷代志上 24:28; 民數記 36:6–8"> 以利亞撒死了，他沒有兒子，只有女兒，<br />她們的族兄弟——就是基士的眾子——娶了她們。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歷代志上 24:30"> 穆希的兒子有瑪赫利、伊德和耶利莫，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 10:17; 民數記 10:21; 歷代志上 23:3"> 以上按著他們的父家，都是利未的子孫，是各父系的首領，按名單，按著他們的人頭數點，都在二十歲以上，為耶和華的殿服事做工。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 132:13–14; 歷代志上 22:18; 撒母耳記下 7:11"> 因為大衛說：「以色列的神耶和華已經使他的子民得享安息，他將永遠居住在耶路撒冷，</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 4:5; 民數記 7:9; 民數記 4:15"> 利未人也不必再抬帳幕和其中一切用於服事的器具了。」</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 23:24; 詩篇 72:20; 撒母耳記下 23:1"> 根據大衛臨終的吩咐，他們都是二十歲以上被數點的利未子孫。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 35:3–6; 歷代志下 31:11; 歷代志下 35:11–14"> 他們的職任是協助亞倫子孫做耶和華殿的服事工作，管理庭院和公房，負責潔淨一切聖物，從事神殿的各樣服事工作；</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 19:35–36; 出埃及記 25:30; 利未記 6:20–23"> 負責陳設餅、素祭的細麵粉、無酵薄餅，烤製、揉拌，也負責所有的容量和尺寸；</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 92:1–3; 以斯拉記 3:10–11; 歷代志上 9:33"> 每天早晨侍立，稱謝讚美耶和華，傍晚也是如此；</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 1:13–14; 民數記 28:1–29; 民數記 10:10"> 也負責向耶和華獻上一切燔祭，在安息日、新月節和各節期，按照數目，照著規定，把燔祭常獻在耶和華面前。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 1:53; 民數記 3:38; 民數記 3:6–9"> 他們要謹守會幕的職責、聖所的職責，以及協助他們的族兄弟亞倫子孫的職責，在耶和華的殿服事。</span>
</div>
</div>

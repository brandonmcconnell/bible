<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 12:9–10; 以弗所書 6:10; 提摩太後書 1:7"> 所以我的兒子啊，你要藉著在基督耶穌裡的恩典得以剛強。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太後書 1:13–14; 提摩太前書 4:6; 提摩太前書 6:12"> 你要把那些在許多見證人面前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在許多見證人面前——或譯作「藉著許多見證人」。">a</a></sup>從我所聽見的，交託給那些忠心可靠、又有能力教導別人的人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯來書 12:2–3; 雅各書 1:12; 提摩太後書 4:5"> 做為基督耶穌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督耶穌——有古抄本作「耶穌基督」。">b</a></sup>的好士兵，你要與我<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="與我——輔助詞語。">c</a></sup>同受苦難。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:4; 路加福音 8:14; 彼得後書 2:20"> 凡是當兵的，沒有一個會讓日常事務糾纏自己，這是為要使那招兵的人喜悅。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 9:24–27; 啟示錄 3:11; 提摩太後書 4:7–8"> 同樣，如果有人要參加競賽，除非按著規矩去競賽，否則就不能得冠冕。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 10:36; 哥林多前書 9:7–11; 哥林多前書 3:6–9"> 勞苦做工的農夫，應該先享受果實。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:5; 約翰一書 5:20; 路加福音 24:45"> 你要思考我所說的話，主會在一切事上賜給你悟性。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:24; 羅馬書 2:16; 哥林多前書 15:11–20"> 你當記住那從死人中復活的耶穌基督，照著我的福音，他出自大衛的後裔。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 1:7; 使徒行傳 28:31; 提摩太後書 1:8"> 我為這福音受苦，甚至像罪犯一樣被捆綁；然而神的話語<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的話語——或譯作「神的道」。">d</a></sup>是不受捆綁的。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 5:10; 歌羅西書 1:24; 提摩太後書 2:3"> 所以，我為了那些蒙揀選的人忍受一切，好讓他們也能得到那在基督耶穌裡的救恩和永恆的榮耀。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 6:8; 歌羅西書 3:3–4; 羅馬書 6:5"> 以下的話是信實的：<br /><span className="pl pl-1">我們如果與基督一同死了，就將與他一同活著；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 8:17; 馬太福音 10:33; 啟示錄 20:4"> <span className="pl pl-1">我們如果忍耐，就將與他一同做王；</span><br /><span className="pl pl-1">我們如果不認他，他也將不認我們。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民數記 23:19; 羅馬書 3:3; 帖撒羅尼迦後書 3:3"> <span className="pl pl-1">我們如果不信實，他仍然是信實的，</span><br /><span className="pl pl-1">因為他不能否定自己。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="提多書 3:9–11; 提摩太後書 2:23; 提摩太後書 4:1"> 你要提醒他們這些事，在神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神——有古抄本作「主」。">e</a></sup>面前鄭重地勸誡他們：不可在言詞上爭執，那是毫無益處的，只會敗壞聽見的人。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:4; 彼得後書 1:10; 提摩太前書 4:6"> 你要努力地向神顯明自己是經過考驗的，是無愧的工人，能正確分解真理的話語。</span>
<span className="v" id="v16" data-v="16" data-xref="提多書 3:9; 提摩太前書 6:20; 提摩太後書 2:14"> 至於那些不敬神的空談，你們要避免，因為說這些話的人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="說這些話的人——或譯作「這些空談」。">f</a></sup>將導致更多不敬神的事；</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前書 1:20; 那鴻書 3:15; 雅各書 5:3"> 他們的話像毒瘤那樣將會擴散。這些人中間有希米奈奧和菲利特斯，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 15:12; 提摩太前書 1:19; 希伯來書 3:10"> 他們偏離了那有關真理的事，稱復活為已經過去的事，結果推翻了一些人的信仰。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 10:14; 哥林多前書 8:3; 那鴻書 1:7"> 不過神堅固的根基始終確立，上面有這樣的印記：<br /><span className="pl pl-1">「主認識那些屬於自己的人」 還有</span><br /><span className="pl pl-1">「所有稱呼主</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="主——有古抄本作「基督」。">g</a></sup><br /><span className="pl pl-1">名的人都要離開不義」。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:21–23; 彼得前書 2:5; 提摩太前書 3:15"> 在大戶人家，不僅有金器、銀器，也有木器、瓦器；雖然有的為了貴重的用處<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="用處——輔助詞語。">h</a></sup>，但有的卻為了卑賤的用處<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="用處——輔助詞語。">i</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 3:17; 以弗所書 2:10; 哥林多後書 7:1"> 所以，如果有人潔淨自己脫離卑賤的事，他就會成為貴重的器皿，被分別為聖，對主人有用，而且是為著一切美善的工作所預備好的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:11; 彼得前書 3:11; 哥林多前書 6:18"> 所以你要逃避年輕人的欲望；要與那些以潔淨的心求告主的人一同追求公義、信仰、愛心、和平；</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太後書 2:14; 提多書 3:9; 提摩太前書 4:7"> 要拒絕愚拙無知的辯論，因為你知道這些只會引起爭鬥，</span>
<span className="v" id="v24" data-v="24" data-xref="提多書 3:2; 雅各書 1:19–20; 提摩太前書 3:2–3"> 而主的奴僕不應該爭鬥；相反，要溫和地對待所有的人，善於教導，忍受惡待，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 11:18; 加拉太書 6:1; 提摩太前書 2:4"> 溫柔地管教那些反對的人；或許神會賜給這些人悔改的心，到真理的知識當中。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 3:7; 以賽亞書 49:25–26; 詩篇 124:7"> 這樣，那些被魔鬼擄去、隨從魔鬼意思的人，就能醒悟過來，脫離魔鬼的網羅。</span>
</div>
</div>

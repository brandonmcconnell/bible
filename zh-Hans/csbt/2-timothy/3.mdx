<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 3:3; 提摩太後書 4:3; 提摩太前書 4:1–3"> 你應當知道這一點：在末後的日子裡，將有艱難的時候來到；</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 2:21; 羅馬書 1:29–31; 猶大書 1:16"> 因為人們將會愛自己、愛錢財，又自誇、又驕傲，褻瀆神、悖逆父母、忘恩負義、毫不聖潔、</span>
<span className="v" id="v3" data-v="3" data-xref="猶大書 1:18; 羅馬書 1:31; 馬太福音 10:21"> 沒有親情、不肯和解、惡意控告、不能自制、殘忍凶暴、不愛良善、</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 3:18–19; 提摩太前書 3:6; 猶大書 1:4"> 背叛出賣、任意妄為、自以為是，愛享樂過於愛神，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 29:13; 提多書 1:16; 馬太福音 23:27–28"> 有敬神的外表，卻否定敬神的實質<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="實質——原文直譯「能力」。">a</a></sup>；這樣的人你要避開。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="猶大書 1:4; 彼得後書 3:17; 提多書 3:3"> 他們當中有些人溜進別人家裡，虜獲無知的婦女。這些婦女被罪孽壓制，被各種欲望牽引，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太後書 4:3–4; 以弗所書 4:14; 提摩太前書 2:4"> 雖然一直學習，卻始終不能達到到真理的知識當中。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:8–11; 啟示錄 2:20; 提摩太前書 6:5"> 揚尼和揚布列怎樣抵擋摩西，這些人也照樣抵擋真理；他們理性敗壞，在信仰上經不起考驗。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 3:8; 出埃及記 7:12; 耶利米書 28:15–17"> 然而，他們不能再進一步了，因為他們的無知會在眾人面前顯露出來，就像那兩個人一樣。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:11; 提多書 2:7; 彼得後書 1:5–7"> 至於你，你跟從了我的教導、品行、心意、信仰、寬容、愛心、忍耐，</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 34:19; 使徒行傳 14:5–6; 哥林多後書 11:23–28"> 以及我在安提阿、以哥念、路司得所遭受的逼迫和苦難——我忍受了何等的逼迫啊！可是主救我脫離了這一切。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:14; 彼得前書 4:12–16; 彼得前書 2:20–21"> 其實，所有想要在基督耶穌裡過敬神生活的，也都會受到逼迫；</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 4:1; 彼得後書 2:20; 提多書 3:3"> 而惡人和迷惑人的會越來越壞，他們迷惑人，自己也被迷惑。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:13; 提摩太後書 2:2; 提摩太後書 1:13"> 至於你，你當持守所學到、所確信的，因為你知道是從哪些人學的；</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:98–99; 路加福音 24:45; 箴言 22:6"> 並且你從年幼就知道了聖經，這聖經能使你有智慧，藉著在基督耶穌裡的信仰，以至於救恩。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 15:4; 希伯來書 4:12; 彼得後書 1:19–21"> 聖經都是神所默示的，對於教導、責備、規正、在義中的訓練都是有益處的，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 2:21; 以弗所書 2:10; 哥林多後書 9:8"> 要使屬神的人完備，為一切美善的工作，裝備齊全。</span>
</div>

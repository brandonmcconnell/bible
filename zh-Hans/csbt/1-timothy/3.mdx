<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多書 1:7; 使徒行傳 20:28; 彼得前書 5:2"> 「如果有人嚮往監督的職份，他就是在渴望一份美好的工作。」這話是信實的。</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 1:6–9; 提摩太後書 2:24; 羅馬書 12:13"> 所以做監督的必須無可指責，只做一個婦人的丈夫，節制、自律、端莊，樂意款待客旅，善於教導，</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 1:7; 以弗所書 5:18; 提多書 3:2"> 不酗酒、不好鬥；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「不貪圖不正當的利益，」。">a</a></sup>反要謙和，不爭吵、不貪財<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不貪財——原文直譯「不愛金錢」。">b</a></sup>，</span>
<span className="v" id="v4" data-v="4" data-xref="提多書 1:6; 創世記 18:19; 提摩太前書 3:12"> 好好帶領<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="帶領——或譯作「管理」。">c</a></sup>自己的家，在一切的事上莊重，使兒女順服。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 3:13; 以弗所書 5:24; 使徒行傳 20:28"> 但如果有人不知道怎麼帶領<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="帶領——或譯作「管理」。">d</a></sup>自己的家，他怎麼能照顧神的教會呢？</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 6:4; 希伯來書 5:12–13; 彼得前書 2:2"> 做監督的不可以是新信徒，免得他自以為是，就落在魔鬼所受的懲罰裡；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 8:21; 提摩太後書 2:26; 歌羅西書 4:5"> 同時，做監督的在外人中也必須有好名聲<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="名聲——原文直譯「見證」。">e</a></sup>，免得受人責罵，落在魔鬼的網羅裡。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="腓立比書 1:1; 提摩太前書 5:23; 使徒行傳 6:3–6"> 做執事<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="執事——或譯作「僕人」。">f</a></sup>的也一樣，必須莊重，不一口兩舌，不酗酒，不貪圖不正當的利益，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 1:19; 約翰二書 1:9–10; 提摩太前書 1:5"> 以清白的良心持守信仰的奧祕；</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 5:22; 提摩太前書 3:13; 提多書 1:6–7"> 並且這些人也當先受考驗，如果是無可指責的，才可以做執事。</span>
<span className="v" id="v11" data-v="11" data-xref="提多書 2:3; 提多書 3:2; 提摩太前書 3:2"> 照樣，他們的妻子<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="他們的妻子——原文直譯「婦女」或「妻子」。">g</a></sup>也必須莊重，不惡意控告人，有節制，在一切事上都忠心。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 3:2; 提摩太前書 3:4–5; 腓立比書 1:1"> 做執事的只可做一個婦人的丈夫，好好帶領<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="帶領——或譯作「管理」。">h</a></sup>兒女和自己的家。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 25:21; 希伯來書 6:10; 使徒行傳 21:35"> 因為那好好服事的，就讓自己達到<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="達到——原文直譯「買來」。">i</a></sup>美好的境地，並且在基督耶穌裡的信仰上大有膽量。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 11:34; 腓利門書 1:22; 哥林多後書 1:15–17"> 我把這些事寫給你，希望很快到你那裡去。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 2:5; 以弗所書 2:21–22; 帖撒羅尼迦前書 1:9"> 就算我耽延了，你也可以知道在神的家裡應該怎樣行事。這家是永生神的教會，是真理的柱石和根基。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 1:14; 希伯來書 1:3; 馬可福音 16:19"> 正如大家所承認的，敬神的奧祕是極大的：<br /><span className="pl pl-1">神</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神——有古抄本作「那一位」。">j</a></sup><br /><span className="pl pl-1">以肉身顯現，</span><br /><span className="pl pl-1">被聖靈證實，</span><br /><span className="pl pl-1">被天使觀看，</span><br /><span className="pl pl-1">被傳於萬邦，</span><br /><span className="pl pl-1">被世人信仰，</span><br /><span className="pl pl-1">被接在榮耀裡。</span></span>
</div>
</div>

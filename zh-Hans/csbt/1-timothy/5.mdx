<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 19:32; 彼得前書 5:5–6; 提多書 2:2"> 不要嚴厲責備年長的人，而要勸他像勸父親那樣；對年輕的人要像對兄弟那樣；</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 4:12; 馬太福音 12:50; 腓立比書 4:8"> 對年長的婦女要像對母親那樣，對年輕的婦女要像對姐妹那樣，要懷著完全純潔的心。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 27:19; 使徒行傳 6:1; 申命記 10:18"> 要尊重那些真正的寡婦。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 6:1–3; 約翰福音 19:26–27; 馬太福音 15:4–6"> 不過一個寡婦如果有兒女或孫兒女，就應當讓他們先學會孝敬自己的家人，報答親恩，因為這在神面前是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「美好的、」。">a</a></sup>蒙悅納的。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 5:3; 路加福音 2:37; 哥林多前書 7:32"> 那真正的寡婦，無依無靠，已經把盼望寄託於神，日夜不住地祈求禱告；</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 5:5; 啟示錄 18:7; 路加福音 15:24"> 而那享樂度日的寡婦，雖然活著，卻是死的。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 4:11; 提多書 2:15; 提摩太後書 4:1"> 你當吩咐這些事，好使她們無可指責。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 6:10; 哥林多後書 12:14; 路加福音 11:11–13"> 如果有人不顧念自己的親屬，尤其是家裡的人，他就否定了信仰，比不信的人更壞。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 3:2; 提摩太前書 5:11; 路加福音 2:36–37"> 應當算入寡婦之列的，不可小於六十歲；只做過一個男人的妻子；</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:18; 提多書 3:8; 使徒行傳 9:36"> 並且必須有美好行為的名聲，就如養育孩子、接待客旅、洗聖徒的腳、幫助受患難的人、追隨一切美善的工作。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:14; 何西阿書 13:6; 雅各書 5:5"> 至於年輕的寡婦，你要拒絕她們入列<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="她們入列——輔助詞語。">b</a></sup>；要知道，當她們情慾衝動而違背基督的時候，就想要結婚；</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 1:6; 雅各書 3:1; 哥林多前書 11:34"> 她們被定罪，是因為她們棄絕了最初的誓言<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="誓言——原文直譯「信仰」。">c</a></sup>，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 帖撒羅尼迦後書 3:6–11; 使徒行傳 20:30"> 同時她們又學會了懶惰，四處串門；不僅懶惰，還好說閒話，好管閒事，說不該說的話。</span>
<span className="v" id="v14" data-v="14" data-xref="提多書 2:5; 提摩太前書 6:1; 提多書 2:8"> 所以，我希望年輕的寡婦結婚，生養兒女，料理家務，不給反對的人辱罵的機會。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:2; 猶大書 1:4–5; 彼得後書 2:20–22"> 實際上，已經有一些人轉去隨從撒旦了。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 5:3–5; 提摩太前書 5:8"> 如果一個<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「男信徒或」。">d</a></sup>女信徒，在親屬中<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在親屬中——輔助詞語。">e</a></sup>有寡婦，她就應該幫助她們，不要讓教會承受壓力，好使教會能夠幫助那些真正的寡婦。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 13:17; 帖撒羅尼迦前書 5:12–13; 加拉太書 6:6"> 那些好好帶領<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="帶領——或譯作「管理」。">f</a></sup>了信徒<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="信徒——輔助詞語。">g</a></sup>的長老，尤其是在傳道和教導上勞苦做工的，應該被看為配得加倍的尊重。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 25:4; 哥林多前書 9:14; 哥林多前書 9:7–10"> 原來經上說：<br /><span className="pl pl-1">「牛踹穀的時候，不可籠住牠的嘴。」</span><br /><span className="pl pl-1">又說：</span><br /><span className="pl pl-1 woj">「工人配得自己的酬報。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 18:16; 申命記 19:15; 哥林多後書 13:1"> 除非有兩三個見證人，否則你不可受理對長老的控告。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 4:2; 提多書 1:13; 提摩太前書 1:20"> 對那些繼續犯罪的，你要當眾責備他們，好使其他的人也有所懼怕。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:4; 提摩太後書 4:1; 提摩太前書 6:13"> 我在神、基督耶穌<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="基督耶穌——有古抄本作「主耶穌基督」。">h</a></sup>，和蒙揀選的天使面前鄭重地勸誡你：遵守這些話要毫無成見，做任何事都不要偏心。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 5:11; 提摩太前書 3:10; 提摩太前書 3:6"> 不要輕易給人按手，也不要在別人的罪孽上有份，要保守自己純潔。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 104:15; 箴言 31:4–7; 提摩太前書 4:4"> 由於你胃的問題和常患的那些疾病，你今後不要只喝水，要用一點酒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="酒——就是「葡萄酒」。">i</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:10; 使徒行傳 8:18; 加拉太書 5:19–21"> 有些人的罪孽是明顯的，要先面對審判；而有些人的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="而有些人的——原文直譯「而對有些人，」。">j</a></sup>罪卻是隨後跟著的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; 路加福音 11:33; 詩篇 37:5–6"> 照樣，美好行為也是明顯的，即使是那些不明顯的，也不能一直隱藏下去。</span>
</div>

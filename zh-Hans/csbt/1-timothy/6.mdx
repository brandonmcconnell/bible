<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="提多書 2:5; 彼得前書 2:17–20; 提多書 2:8–10"> 凡是負軛做奴僕的，應該看自己的主人配受十分尊重，免得神的名和神的教導受到褻瀆。</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 4:1; 提摩太前書 4:11; 創世記 16:4–5"> 如果奴僕的主人是信徒，不可因為主人是弟兄就輕看他們；反而倒要服事他們，因為從這樣的美事而得益處的，是信徒、是蒙愛的人。 錯誤的教導與人的貪心<br />你要教導、勸勉這些事。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 1:3; 羅馬書 16:17; 提摩太前書 1:10"> 如果有人傳講別的教義，不符合我們主耶穌基督的健全話語以及那合乎敬神的教導，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 2:23; 提摩太後書 3:4; 提摩太前書 3:6"> 那麼他就成了自以為是的人，什麼都不知道，只對辯論和言詞上的爭執有病態的嗜好，由此引發嫉妒、紛爭、毀謗、惡意的猜疑；</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太後書 3:5; 提多書 1:11; 彼得後書 2:3"> 他在那些理性敗壞、喪失真理、以為敬神是得利之道的人中，引發無休止的爭吵。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附「你要避開這種人。」">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 13:5; 提摩太前書 6:8; 箴言 16:8"> 其實敬神加上知足，才是極大的得利之道。</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 1:21; 詩篇 49:17; 路加福音 12:20–21"> <span className="pl pl-1">實際上，我們沒有帶什麼到世上來，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附「明顯地，」。">b</a></sup><br /><span className="pl pl-1">也不能帶什麼去。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 13:5–6; 馬太福音 6:11; 馬太福音 6:25–33"> <span className="pl pl-1">不過有了吃的、穿的，我們將以此為滿足。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰一書 2:15–17; 箴言 15:27; 提摩太前書 3:7"> 至於那些想發財的人就會陷入試探、網羅以及很多無知有害的欲望裡；這些欲望使人沉溺在敗壞和滅亡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="滅亡——或譯作「沉淪」。">c</a></sup>中。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 1:19; 提摩太前書 6:9; 詩篇 32:10"> 要知道，貪愛金錢是萬惡之根；有些人戀慕金錢，就被迷惑而離開了信仰，用很多苦痛把自己刺透了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 2:22; 提摩太後書 3:17; 提摩太前書 4:12"> <span className="pl pl-1">至於你，哦，屬神的人哪，你要逃避這些事！</span><br /><span className="pl pl-1">你要追求公義、敬神、信仰、</span><br /><span className="pl pl-1">愛心、忍耐、溫柔，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:10; 提摩太前書 1:18; 哥林多前書 9:25–26"> <span className="pl pl-1">要為信仰打那美好的仗，</span><br /><span className="pl pl-1">要抓住永恆的生命。</span><br /><span className="pl pl-1">你正是為此蒙召的，</span><br /><span className="pl pl-1">並且在許多見證人面前</span><br /><span className="pl pl-1">做了美好的告白。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 18:36–37; 馬太福音 27:11; 提摩太前書 5:21"> 我在那賜生命給萬物的神面前，並在那曾經向本丟彼拉多見證了美好告白的基督耶穌面前吩咐你：</span>
<span className="v" id="v14" data-v="14" data-xref="彼得後書 3:14; 彼得前書 1:7; 帖撒羅尼迦前書 5:23"> 要毫無玷汙、無可指責地遵守這命令，直到我們主耶穌基督的顯現。</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:16; 啟示錄 17:14; 提摩太前書 1:17"> 在所定的時候<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="所定的時候——原文直譯「自己的時候」。">d</a></sup>，他將要顯明出來他就是<br /><span className="pl pl-1">那當受稱頌的、獨一的全能者，</span><br /><span className="pl pl-1">萬王之王、萬主之主，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 1:17; 約翰福音 1:18; 約翰一書 1:5"> <span className="pl pl-1">就是那獨一不朽的、</span><br /><span className="pl pl-1">住在人所不能靠近的光裡，</span><br /><span className="pl pl-1">沒有人見過、也沒有人能看見的那一位。</span><br /><span className="pl pl-1">願尊貴和永恆的權能都歸於他！</span><br /><span className="pl pl-1">阿們。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 11:28; 使徒行傳 14:17; 箴言 27:24"> 對那些今世富有的人，你當吩咐他們不可高傲自大，也不可把盼望寄託在靠不住的財富上，而要寄託在神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神——有古抄本作「永生的神」。">e</a></sup>身上，神把萬物豐豐富富地賜給我們享受。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 13:16; 約翰一書 3:17; 詩篇 37:3"> 你要吩咐他們常行美善，在美好行為上富足，慷慨施捨，樂意分享；</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 6:19–21; 提摩太前書 6:12; 提摩太後書 2:19"> 為著那將要來臨的，給自己積存美好的基礎，使他們抓住那真正的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="真正的——有古抄本作「永恆的」。">f</a></sup>生命。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 2:8; 提摩太後書 2:16; 提摩太後書 1:12–14"> 哦，提摩太呀！你要保守那所受的託付，避開那些不敬神的空談和假冒知識之名的反對論。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:18; 提摩太前書 1:6; 提摩太後書 4:22"> 有些人自稱有這些「知識」，就在信仰上偏離了。<br />願恩典與你們<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="你們——有古抄本作「你」。">g</a></sup>同在！<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附「阿們。」">h</a></sup></span>
</div>
</div>

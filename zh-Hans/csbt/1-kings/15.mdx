<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1KI" data-book-slug="1-kings" data-book-name="列王紀上" data-chapter="15" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:31; 歷代志下 13:1–22"> 尼八之子耶羅波安王在位第十八年，亞比雅姆作猶大的王，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 13:2; 歷代志下 11:20–22; 列王紀上 15:13"> 在耶路撒冷統治了三年。他的母親名叫瑪迦，是押沙龍的外孫女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="押沙龍的外孫女——或譯作「押沙龍之女」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:4; 詩篇 119:80; 列王紀上 3:14"> 亞比雅姆隨從他父親先前所行的一切罪惡，他的心沒有像他先祖大衛的心那樣完全忠於耶和華他的神。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:36; 歷代志下 21:7; 以賽亞書 37:35"> 然而他的神耶和華為大衛的緣故，給大衛在耶路撒冷留下一盞燈，興起他的後裔接續他，堅立耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 14:8; 撒母耳記下 11:15–17; 列王紀上 15:3"> 這是因為大衛除了赫提人烏利亞那件事以外，一生的日子都做耶和華眼中看為正的事，沒有偏離耶和華所吩咐的一切。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 14:30"> 羅波安一生中和耶羅波安之間一直有爭戰。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 13:2–22; 列王紀上 14:29"> 亞比雅姆其餘的事蹟和他所做的一切，不是都記在《猶大諸王年代志》上嗎？亞比雅姆和耶羅波安之間常有戰爭。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 14:1; 列王紀上 14:31; 馬太福音 1:7–8"> 亞比雅姆與他的列祖長眠，人們把他葬在大衛城；他的兒子亞撒接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 以色列王耶羅波安在位第二十年，亞撒作猶大的王，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:2; 列王紀上 15:13; 歷代志下 13:2"> 在耶路撒冷統治了四十一年。他的祖母名叫瑪迦，是押沙龍的外孫女<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="押沙龍的外孫女——或譯作「押沙龍之女」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志下 14:2; 歷代志下 15:17; 列王紀上 15:3"> 亞撒像他的先祖大衛那樣，做耶和華眼中看為正的事。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:46; 列王紀上 14:23–24; 歷代志下 14:2–5"> 他從國中除去那些男廟妓，又除掉他祖先造的所有偶像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 32:20; 申命記 7:5; 撒迦利亞書 13:3"> 他還廢除了他祖母瑪迦的太后之位，因為她製作了淫穢的亞舍拉柱。亞撒把那淫穢的神柱砍掉，並在汲淪溪谷焚燒了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 22:43; 列王紀上 8:61; 列王紀上 15:3"> 雖然那些高壇還沒有除掉，但亞撒一生的日子完全對耶和華忠心。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:51; 歷代志下 14:13; 歷代志下 15:18"> 亞撒把他父親和他自己分別為聖的金銀和器皿，都帶到了耶和華的殿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:32; 列王紀上 14:30; 歷代志下 16:1–6"> 亞撒和以色列王巴沙之間一直有爭戰。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 12:27; 歷代志下 16:1–6; 約書亞記 18:25"> 以色列王巴沙上來攻擊猶大，修築了拉瑪，不讓人與猶大王亞撒往來。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:26; 列王紀下 12:18; 列王紀上 11:23–24"> 於是亞撒把耶和華殿的庫房和王宮的庫房剩下的所有金銀都取出來，交在臣僕手中，然後亞撒王派遣他們去見住在大馬士革的亞蘭王——希旬的孫子、塔伯利門的兒子本哈達，說：</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 1:31; 歷代志下 16:7; 羅馬書 3:8"> 「你我之間立約吧，就像我父親與你父親之間那樣。看哪，我把金銀送給你為禮物，請你廢除你與以色列王巴沙所立的約，好讓他從我這裡撤離。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 士師記 18:29; 約書亞記 11:2"> 本哈達聽取了亞撒王，就派遣他的將領們去攻擊以色列的城鎮，攻占了伊永、但、亞貝勒-伯瑪迦，革尼勒全域以及拿弗他利全地。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:17; 列王紀上 16:15–18; 歷代志下 16:5"> 巴沙聽說了，就停止修築拉瑪，滯留在提爾撒。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 21:17; 約書亞記 18:24; 約書亞記 18:26"> 於是亞撒王通告全體猶大人，無人能免，將巴沙用於修築拉瑪的石頭和木材運走。亞撒王用這些來修築便雅憫的迦巴和米斯巴。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歷代志下 16:11–14; 列王紀上 14:29–31; 列王紀上 15:7–8"> 亞撒其餘的一切事蹟，他的所有武力、所成就的一切，以及他所建造的城鎮，不是都記在《猶大諸王年代志》上嗎？只是他年老的時候，雙腳患了病。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 1:8; 列王紀上 22:41–43; 歷代志下 17:1–9"> 亞撒與他的列祖長眠，葬在先祖大衛的城，與他的列祖在一起；他的兒子約沙法接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 14:20; 列王紀上 14:12"> 猶大王亞撒在位第二年，耶羅波安的兒子納達布作了以色列的王，統治以色列兩年。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀上 15:30"> 納達布做耶和華眼中看為惡的事，走他父親的道路，效法他父親使以色列所犯的罪。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約書亞記 19:44; 約書亞記 21:23; 列王紀上 14:14"> 以薩迦家族亞希雅的兒子巴沙密謀反叛納達布。巴沙在非利士人的基比頓擊殺了他，那時納達布和全體以色列人正在圍攻基比頓。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:35"> 猶大王亞撒在位第三年，巴沙殺了納達布，接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 14:9–16; 列王紀下 19:25; 列王紀下 10:10–11"> 巴沙一作王，就把耶羅波安的全家都擊殺了。他沒有留下耶羅波安家任何有氣息的，全都除滅了，正如耶和華藉著他僕人示羅人亞希雅所宣告的話。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 15:26; 列王紀上 14:22; 列王紀上 14:9–16"> 這是因耶羅波安所犯的罪，以及他使以色列所犯的罪，惹怒了耶和華以色列的神。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 14:19; 列王紀上 16:20; 列王紀上 16:14"> 納達布其餘的事蹟和他所做的一切，不是都記在《以色列諸王年代志》上嗎？</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 15:16"> 亞撒和以色列王巴沙之間一直有爭戰。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王紀上 16:8"> 猶大王亞撒在位第三年，亞希雅的兒子巴沙在提爾撒作全以色列的王，統治了二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 15:26; 列王紀上 14:16; 列王紀上 12:28–29"> 他做耶和華眼中看為惡的事，走耶羅波安的道路，效法耶羅波安使以色列所犯的罪。</span>
</div>
</div>

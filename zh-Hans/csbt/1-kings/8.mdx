<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 5:2–10; 歷代志上 15:25; 撒母耳記下 6:12–17"> 那時，所羅門把以色列的長老、各支派的首領、以色列子孫各父系的首領，都招聚到耶路撒冷所羅門王那裡，要把耶和華的約櫃從大衛城錫安抬上來。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:34; 歷代志下 7:8–10; 撒迦利亞書 14:16–19"> 於是以色列眾人在以塔寧月，就是在七月的節期時，都聚集到所羅門王那裡。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; 約書亞記 3:6; 民數記 4:15"> 以色列所有的長老來到後，祭司們就抬起約櫃，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:4; 歷代志下 1:3; 出埃及記 40:2–33"> 把耶和華的約櫃和會幕以及其中一切神聖的器具都抬上來；祭司和利未人把它們抬上來了。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 6:13; 歷代志上 16:1; 列王紀上 8:62–63"> 所羅門王與會合到他那裡的全體以色列會眾，在約櫃前一起祭獻牛羊，多得無法數清、不可勝數。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:19; 撒母耳記下 6:17; 列王紀上 6:27"> 然後祭司們把耶和華的約櫃抬進來，放在預備好的地方，在內殿至聖所兩個基路伯的翅膀底下。</span>
<span className="v" id="v7" data-v="7"> 基路伯在約櫃的位置之上展開翅膀，這樣基路伯從上方遮掩約櫃和約櫃的杠子。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 25:13–15; 出埃及記 37:4–5; 約書亞記 4:9"> 杠子很長，從內殿前面看得見聖所伸出的杠子兩端，不過從外面就看不見；杠子至今還在那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:21; 希伯來書 9:4; 出埃及記 40:20"> 約櫃裡只有那兩塊石版，沒有別的；那是以色列子孫出埃及地之後，耶和華與他們立約時，摩西在何烈山放進去的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:34–35; 歷代志下 7:1–2"> 祭司們從聖所出來的時候，雲霧充滿了耶和華的殿，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 43:4–5; 以西結書 44:4; 哥林多後書 3:18"> 以致祭司們因那雲霧的緣故不能事奉供職，因為耶和華的榮耀充滿了耶和華的殿。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="詩篇 97:2; 歷代志下 6:1–11; 利未記 16:2"> 那時所羅門說：<br /><span className="pl pl-1">「耶和華曾說要居於幽暗之中，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 7:13; 詩篇 132:13–14; 希伯來書 9:24"> <span className="pl pl-1">我竟然為你建造了一座宏偉的殿宇，</span><br /><span className="pl pl-1">作為你永遠的居所。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 6:18; 列王紀上 8:55–56; 歷代志下 30:18–20"> 然後王轉過身來，祝福了以色列全體會眾；以色列全體會眾都站著。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:68; 歷代志上 29:20; 歷代志上 29:10"> 王說：<br /><span className="pl pl-1">「以色列的神耶和華是當受頌讚的！</span><br /><span className="pl pl-1">他親口應許我父親大衛的，</span><br /><span className="pl pl-1">也親手成就了；</span><br /><span className="pl pl-1">他曾說：</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 16:1; 列王紀上 8:29; 撒母耳記下 7:4–8"> <span className="pl pl-1">『自從我把我的子民以色列從埃及領出來那天起，</span><br /><span className="pl pl-1">我沒有在以色列任何支派中揀選過一座城，</span><br /><span className="pl pl-1">建造殿宇使我的名常在那裡；</span><br /><span className="pl pl-1">然而我揀選了大衛，治理我的子民以色列。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 7:2–3; 歷代志上 22:7; 歷代志上 28:2"> <span className="pl pl-1">「我父親大衛一直有心</span><br /><span className="pl pl-1">為以色列的神耶和華的名建造殿宇，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 6:7–9; 哥林多後書 8:12"> <span className="pl pl-1">但耶和華對我父親大衛說：</span><br /><span className="pl pl-1">『雖然你有心為我的名建造殿宇，</span><br /><span className="pl pl-1">你的心意也確實很好，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 7:5; 歷代志上 22:8–10; 歷代志上 28:6"> <span className="pl pl-1">只是你不可建造這殿宇，</span><br /><span className="pl pl-1">而是你親生的兒子——</span><br /><span className="pl pl-1">他將為我的名建造殿宇。』</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以斯拉記 9:5; 列王紀上 8:54; 出埃及記 9:33"> 然後，所羅門在以色列全體會眾面前，站在耶和華的祭壇前，向天伸開雙手，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 7:22; 申命記 7:9; 但以理書 9:4"> 說：<br /><span className="pl pl-1">「以色列的神耶和華啊，</span><br /><span className="pl pl-1">天上地上沒有神明能與你相比！</span><br /><span className="pl pl-1">你向那些全心行走在你面前的僕人</span><br /><span className="pl pl-1">守約施慈愛。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 7:16; 列王紀上 8:15; 撒母耳記下 7:12"> <span className="pl pl-1">你向你的僕人我父親大衛信守對他的應許，</span><br /><span className="pl pl-1">你親口應許的，</span><br /><span className="pl pl-1">也親手成就了，</span><br /><span className="pl pl-1">就像今日這樣。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="歷代志下 2:6; 以賽亞書 66:1; 耶利米書 23:24"> <span className="pl pl-1">「其實，神真的會住在地上嗎？</span><br /><span className="pl pl-1">看哪，天和天上的天尚且無法容納你，</span><br /><span className="pl pl-1">更何況我所建造的這殿宇呢！</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 88:1–2; 詩篇 5:1; 路加福音 18:1"> <span className="pl pl-1">耶和華我的神哪，願你垂顧你僕人的禱告和懇求，</span><br /><span className="pl pl-1">垂聽你僕人的呼聲和今天在你面前獻上的禱告；</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 22:8–11; 歷代志下 6:22–23; 利未記 5:1"> <span className="pl pl-1">「如果有人因對鄰人犯罪的事</span><br /><span className="pl pl-1">而被要求起誓，</span><br /><span className="pl pl-1">當他來到這殿宇在你祭壇前起誓的時候，</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="利未記 26:17; 申命記 28:25; 約拿書 3:10"> <span className="pl pl-1">「如果你的子民以色列因對你犯罪而敗在了仇敵面前，</span><br /><span className="pl pl-1">當他們回轉歸向你，承認</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="承認——或譯作「稱頌」。">a</a></sup><br /><span className="pl pl-1">你的名，</span><br /><span className="pl pl-1">在這殿宇中向你禱告懇求的時候，</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="利未記 26:19; 申命記 11:17; 列王紀上 8:33"> <span className="pl pl-1">「如果你的子民對你犯罪，以致天閉塞不下雨，</span><br /><span className="pl pl-1">當他們向著這地方禱告，</span><br /><span className="pl pl-1">承認</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="承認——或譯作「稱頌」。">b</a></sup><br /><span className="pl pl-1">你的名，</span><br /><span className="pl pl-1">並因你的懲罰而轉離他們罪的時候，</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="申命記 28:21–22; 利未記 26:16; 歷代志下 20:9"> <span className="pl pl-1">「如果這地有饑荒、瘟疫，有枯焦、霉爛、蝗蟲和螞蚱，</span><br /><span className="pl pl-1">或有仇敵在境內圍攻他們的城門，</span><br /><span className="pl pl-1">或有任何禍患、疾病來臨，</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 73:21–22; 列王紀上 8:22; 腓立比書 4:6"> <span className="pl pl-1">當你的子民以色列，無論個人或眾人，</span><br /><span className="pl pl-1">因深感內心的憂傷</span><br /><span className="pl pl-1">而向著這殿宇伸開雙手的時候，</span><br /><span className="pl pl-1">無論禱告什麼、懇求什麼，</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="歷代志上 28:9; 耶利米書 17:10; 使徒行傳 1:24"> <span className="pl pl-1">願你從天上的居所垂聽而赦免，採取行動。</span><br /><span className="pl pl-1">你知道人的心，</span><br /><span className="pl pl-1">唯獨你知道所有世人的心，</span><br /><span className="pl pl-1">願你照著各人所行的一切回報他，</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="列王紀上 10:1–2; 使徒行傳 8:27–40; 出埃及記 18:8–12"> <span className="pl pl-1">「至於那些不屬於你子民以色列的外邦人，</span><br /><span className="pl pl-1">當他們因你名的緣故從遙遠之地而來，</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="歷代志下 6:34; 詩篇 78:67–69; 列王紀上 8:16"> <span className="pl pl-1">「如果你的子民出去與仇敵爭戰，</span><br /><span className="pl pl-1">無論你派遣他們往哪個方向去，</span><br /><span className="pl pl-1">當他們朝著你所揀選的城和我為你名建造的這殿宇</span><br /><span className="pl pl-1">向耶和華禱告時，</span><br /></span>

<div className="bp poetry">

<span className="v" id="v50" data-v="50" data-xref="詩篇 106:46; 歷代志下 30:9; 使徒行傳 7:10"> <span className="pl pl-1">赦免對你犯罪的子民，</span><br /><span className="pl pl-1">赦免他們對你的一切悖逆行為，</span><br /><span className="pl pl-1">向他們施憐憫，</span><br /><span className="pl pl-1">使他們在擄走他們的人面前蒙憐憫。</span><br /></span>
<span className="v" id="v51" data-v="51" data-xref="尼希米記 1:10; 耶利米書 11:4; 申命記 4:20"> <span className="pl pl-1">因為他們是你的子民、你的繼業，</span><br /><span className="pl pl-1">是你從埃及——那煉鐵的熔爐中領出來的。</span><br /></span>
<span className="v" id="v52" data-v="52" data-xref="詩篇 145:18; 列王紀上 8:29; 詩篇 86:5"> <span className="pl pl-1">願你眼睛睜開，</span><br /><span className="pl pl-1">顧念你僕人的懇求以及你子民以色列的懇求，</span><br /><span className="pl pl-1">垂聽他們向你的一切呼求。</span><br /></span>

<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="歷代志下 7:1; 歷代志下 6:12–13; 路加福音 22:45"> 所羅門在耶和華的祭壇前雙膝跪下，向天伸開雙手，在耶和華面前做完這一切禱告和懇求，就起來了。</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀上 8:14; 撒母耳記下 6:18; 民數記 6:23–26"> 他站著，大聲祝福以色列全體會眾，說：</span>
<span className="v" id="v56" data-v="56" data-xref="約書亞記 23:14–15; 約書亞記 21:44–45; 路加福音 21:33"> 「耶和華是當受頌讚的！他照著他所應許的一切，賜予他的子民以色列安息；凡藉著他僕人摩西所應許的一切福份，一句也沒有落空。</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 1:5; 申命記 31:6; 申命記 31:8"> 願我們的神耶和華與我們同在，就像他與我們的祖先同在那樣。願他不離棄我們，也不撇棄我們，</span>
<span className="v" id="v58" data-v="58" data-xref="詩篇 119:36; 以西結書 36:26–27; 耶利米書 31:33"> 好使我們的心歸向他，遵行他一切的道，謹守他吩咐我們祖先的誡命、律例和法規。</span>
<span className="v" id="v59" data-v="59" data-xref="詩篇 141:2; 約翰福音 17:9; 約翰福音 17:20–24"> 願我在耶和華面前所懇求的這些話，晝夜上達耶和華我們的神，使他照著每天的事務聽取他僕人的申訴，聽取他子民以色列的申訴，</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 4:35; 耶利米書 10:10–12; 列王紀上 18:39"> 好讓地上的萬民都知道：唯獨耶和華是神，沒有另一位。</span>
<span className="v" id="v61" data-v="61" data-xref="列王紀上 11:4; 列王紀下 20:3; 哥林多後書 7:1"> 所以你們的心要完全忠於耶和華我們的神，遵行他的律例，謹守他的誡命，就像今日這樣。」</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="撒母耳記下 6:17–19; 以斯拉記 6:16–17; 歷代志下 7:4–10"> 王和全體以色列人一起在耶和華面前獻祭。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉記 6:16–17; 歷代志下 15:11; 尼希米記 12:27"> 所羅門獻上祭物，就是向耶和華獻上的平安祭，有兩萬兩千頭牛、十二萬隻羊。這樣，王和所有的以色列子民為耶和華的殿舉行了奉獻禮。</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="歷代志下 4:1; 歷代志下 7:7"> 那天，王又把耶和華殿前的院子中心分別為聖，在那裡獻上燔祭和素祭以及平安祭的脂油，因為耶和華面前的銅祭壇太小，容不下所有的燔祭和素祭，以及平安祭的脂油。</span>

<div className="bp">
<span className="v" id="v65" data-v="65" data-xref="民數記 34:5; 民數記 34:8; 列王紀上 8:2"> 那時，所羅門和全體以色列人，就是從哈馬隘口直到埃及河來的極多的會眾，一起在我們的神耶和華面前守了七天的節期，加上七天，共十四天。</span>

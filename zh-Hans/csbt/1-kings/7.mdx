<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:10; 歷代志下 8:1; 傳道書 2:4–5"> 此後，所羅門建造自己的王宮，用十三年完成了他全部的殿宇。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 10:17; 歷代志下 9:16; 列王紀上 10:21"> 他建造黎巴嫩林宮，長一百肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百肘——相當於45.7公尺。1肘=45.7公分。">a</a></sup>，寬五十肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="五十肘——相當於22.8公尺；下同。">b</a></sup>，高三十肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十肘——相當於13.7公尺；下同。">c</a></sup>。有四排香柏木立柱，柱子上有香柏木橫梁。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 6:5"> 還有四十五根立柱——每排十五根——支撐著檁條，上面鋪上香柏木板。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 40:22; 以西結書 40:16; 列王紀上 6:4"> 有三排格子窗，面面相對，有三層。</span>
<span className="v" id="v5" data-v="5"> 所有的門和門框都是方形的，還有窗戶，三層面面相對。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:12; 以西結書 41:25–26"> 他建造了一個圓柱大廳，長五十肘，寬三十肘，前面有一個門廊，門廊前有柱子和廊簷。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 詩篇 122:5; 以賽亞書 9:7"> 他建造有寶座的大廳，就是「審判大廳」，要在那裡施行審判；大廳從地面到頂部都鋪上香柏木板。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:11; 列王紀上 3:1; 列王紀上 9:24"> 大廳後面的另一個院子是他自己住的宮殿，構造像這大廳一樣。所羅門迎娶法老的女兒並為她建造的宮殿，也像這大廳一樣。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 7:10–11; 列王紀上 5:17"> 從根基到牆頂、從外圍到大院，這一切所用的都是貴重的石材，是按尺寸鑿成的料石，用鋸內外平整切割。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:19–20; 哥林多前書 3:10–11; 以賽亞書 54:11"> 根基是貴重的石材、巨大的塊石，有長十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="十肘——相當於4.6公尺。1肘=45.7公分。">d</a></sup>的塊石，有長八肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="八肘——相當於3.7公尺。">e</a></sup>的塊石；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:20–22; 彼得前書 2:5"> 其上也有按尺寸鑿成的貴重石材以及香柏木材。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 6:36; 列王紀上 7:6; 約翰福音 10:23"> 大院四圍有三層鑿好的料石，以及一層香柏木梁。耶和華殿的內院和殿宇門廊也是一樣。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 4:11; 歷代志下 2:13–14; 列王紀上 7:40"> 所羅門王派人從提爾把戶蘭請來。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 2:14; 歷代志下 4:16; 出埃及記 31:2–6"> 他是拿弗他利支派中一個寡婦的兒子，父親是提爾人，是個銅匠。他滿有才能、聰慧和知識，會製作各樣銅器。他來到所羅門王那裡，做他一切的工作。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 52:21; 歷代志下 3:15–17; 列王紀上 7:21"> 戶蘭鑄造了兩根銅柱，一根柱子高十八肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="十八肘——相當於8.2公尺。1肘=45.7公分。">f</a></sup>，周長<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="周長——原文直譯「繩子繞一圈」。">g</a></sup>十二肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十二肘——相當於5.5公尺。">h</a></sup>，另一根柱子也一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 38:19; 歷代志下 4:12–13; 出埃及記 38:17"> 他做了兩個柱頭，裝在柱子的頂上，是用銅鑄成的；一個柱頭高五肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="五肘——相當於2.3公尺；下同。">i</a></sup>，另一個柱頭也高五肘。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 28:14; 出埃及記 28:24–25; 出埃及記 28:22"> 柱子頂上的柱頭有網格狀、鏈條交織的纓絡，第一個柱頭上有七條，第二個柱頭上也有七條。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 28:14; 出埃及記 39:15–18; 出埃及記 28:22"> 他做的柱子，每一個網格上環繞著兩行石榴，用來裝飾柱子頂上的柱頭，另一個柱頭也這樣做。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:22; 列王紀上 6:32–35; 列王紀上 6:18"> 門廊裡柱子頂上的柱頭有百合花雕飾，高四肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="四肘——相當於1.8公尺。">j</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 3:16; 歷代志下 4:13; 耶利米書 52:22–23"> 兩根柱子的柱頭上，挨著網格的鼓肚邊上，還有兩百個石榴分行環繞著兩個柱頭。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 3:17; 列王紀上 6:3; 列王紀上 7:12"> 他把兩根柱子豎立在正殿的門廊前：右邊豎立一根，起名為雅斤；左邊豎立一根，起名為波阿斯。</span>
<span className="v" id="v22" data-v="22"> 在柱子頂上，有百合花雕飾。這樣，柱子的工作就完成了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歷代志下 4:2; 列王紀下 25:13; 耶利米書 52:17"> 他鑄造了一個銅海，直徑<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="直徑——原文直譯「從口沿到口沿」。">k</a></sup>十肘<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="十肘——相當於4.6公尺。1肘=45.7公分。">l</a></sup>，是圓形的，高五肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="五肘——相當於2.3公尺。">m</a></sup>，周長<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="周長——原文直譯「繩子繞一圈」。">n</a></sup>三十肘<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="三十肘——相當於13.7公尺。">o</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:18; 歷代志下 4:3; 出埃及記 37:17–22"> 銅海口沿的下方有匏瓜的圖形，圍繞在銅海周圍，每肘十個，環繞在銅海周圍；匏瓜圖形有兩行，是與銅海一體鑄造的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 52:20; 歷代志下 4:4–5; 馬太福音 28:19"> 銅海安裝在十二頭銅牛上面，三頭朝北，三頭朝西，三頭朝南，三頭朝東。銅海在牛背上，牛尾全都向內。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 4:5; 列王紀上 7:38; 列王紀上 6:18"> 銅海厚一掌<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="一掌——相當於7.4公分。">p</a></sup>，口沿如杯沿的工藝，像綻開的百合花，它的容量為兩千罷特<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="兩千罷特——相當於44,000公升。1罷特=22公升。">q</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志下 4:14; 列王紀下 25:13; 耶利米書 52:17"> 他做了十個銅底座，每個底座長四肘<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="四肘——相當於1.8公尺；下同。1肘=45.7公分。">r</a></sup>，寬四肘，高三肘<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="三肘——相當於1.4公尺。">s</a></sup>。</span>
<span className="v" id="v28" data-v="28"> 底座的構造是這樣：它們都有鑲板，鑲板在支架中間。</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿書 5:14; 以西結書 10:14; 出埃及記 37:7"> 支架之間的鑲板上有獅子、牛和基路伯的浮雕，各支架上面有盆座；獅子和牛的下面有花環浮雕。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 10:10–13; 以西結書 3:13; 以西結書 1:15–21"> 每個底座有四個銅輪子和銅軸。盆下面的四角有支架，各支架的邊上都有鑄造的花環。</span>
<span className="v" id="v31" data-v="31"> 盆座的口是在頂部的內面，高一肘<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="一肘——相當於45.7公分。">t</a></sup>；口是圓形的。盆座的構造直徑一肘半<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="一肘半——相當於68.6公分；下同。">u</a></sup>，口上也有雕刻，鑲板是方形的，不是圓的。</span>
<span className="v" id="v32" data-v="32"> 四個輪子在鑲板下方，輪子的軸連接在底座下，每個輪子直徑一肘半。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 1:18; 以西結書 1:16"> 輪子的工藝如同戰車輪子的工藝，輪軸、輪圈、輪輻、輪轂都是鑄造的。</span>
<span className="v" id="v34" data-v="34"> 每一個底座有四個支架，在四個角上；支架與底座是一體的。</span>
<span className="v" id="v35" data-v="35"> 底座頂部有半肘<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="半肘——相當於22.8公分。">v</a></sup>高的圓形支架，底座上面的支架和鑲板與盆座是一體的。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:29; 列王紀上 6:29; 以西結書 41:18–20"> 支架和鑲板的表面上雕刻著基路伯、獅子和棕櫚樹，四圍各個空白的地方有花環浮雕。</span>
<span className="v" id="v37" data-v="37"> 他這樣做了十個底座，鑄模全都一樣，尺寸一樣，形狀一樣。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="出埃及記 40:11–12; 撒迦利亞書 13:1; 約翰一書 1:7"> 他做了十個銅盆，每個盆可容納四十罷特<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="四十罷特——相當於880公升。1罷特=22公升。">w</a></sup>，每個盆直徑四肘<sup className="fn"><a href="#fn-x" id="fnref-x" data-fn="四肘——相當於1.8公尺。1肘=45.7公分。">x</a></sup>。盆放在十個底座上，每個底座上一個。</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志下 4:10; 歷代志下 4:6"> 五個底座放在殿宇的右側，五個底座放在殿宇的左側；銅海放在殿宇的右側，在東南角。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志下 4:11–16; 出埃及記 24:6; 出埃及記 39:32–43"> 戶蘭還做了盆、鏟子和碗。 所有銅器<br />這樣，戶蘭完成了他為所羅門王在耶和華殿中做的各樣工程，</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 7:15–22; 歷代志下 4:12"> 包括：兩根柱子，兩根柱子頂上盆狀的柱頭，以及兩個用來裝飾柱子頂上盆狀柱頭的網格，</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 7:20"> 還有兩個網格上的四百個石榴，每個網格上有兩行石榴，用來裝飾各柱子上面盆狀的柱頭。</span>
<span className="v" id="v43" data-v="43"> 還有十個底座和底座上的十個盆，</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 7:23; 列王紀上 7:25"> 一個銅海和銅海底下的十二頭牛，</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及記 27:3; 出埃及記 38:3; 歷代志下 4:16"> 鍋、鏟子、碗。戶蘭為所羅門王給耶和華殿製作的這一切器皿，都是用磨亮的銅製作的。</span>
<span className="v" id="v46" data-v="46" data-xref="約書亞記 3:16; 歷代志下 4:17; 創世記 33:17"> 王在約旦平原、疏割和撒拉坦之間的土模場鑄造了這些。</span>
<span className="v" id="v47" data-v="47" data-xref="歷代志上 22:14; 歷代志上 22:3; 歷代志下 4:18"> 所羅門沒有稱量這一切器物，因為數量極多，銅的重量無法計算。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="出埃及記 37:10–16; 歷代志下 4:8; 出埃及記 39:36"> 所羅門製作了耶和華殿中的一切器物：金祭壇和擺放陳設餅的金桌；</span>
<span className="v" id="v49" data-v="49" data-xref="歷代志下 4:7; 歷代志下 4:20; 撒迦利亞書 4:11–14"> 內殿前面的純金燈臺，右邊五個，左邊五個；金製的花朵、燈盞、燈剪；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 25:29; 歷代志下 4:21–22; 出埃及記 27:3"> 純金的缽、蠟剪、碗、勺子、香爐；內殿至聖所的門和殿宇正殿的門，鉸鏈<sup className="fn"><a href="#fn-y" id="fnref-y" data-fn="鉸鏈——或譯作「表層」。">y</a></sup>都是金的。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="歷代志下 5:1; 撒母耳記下 8:7–11; 歷代志上 28:11–18"> 所羅門王為耶和華殿所做的一切工作都完成了，所羅門就把他父親大衛分別為聖獻出的金銀和器皿都拿來，放在耶和華殿的庫房裡。</span>
</div>
</div>

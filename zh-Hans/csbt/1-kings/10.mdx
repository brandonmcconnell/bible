<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1KI" data-book-slug="1-kings" data-book-name="列王紀上" data-chapter="10" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:42; 路加福音 11:31; 歷代志下 9:1–12"> 示巴女王聽說了所羅門因耶和華的名而得的名聲，就來要用一些難題試驗所羅門。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 25:23; 詩篇 4:4; 約伯記 4:2"> 她帶著大隊隨從，並有駱駝馱著香料、極多的金子以及寶石，來到耶路撒冷。她來到所羅門那裡，與所羅門談論自己心中的一切問題。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 馬太福音 13:11; 列王紀上 10:1"> 所羅門解答了她的一切問題，沒有一個問題對於王是深奧無解的。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 12:42; 列王紀上 3:28; 歷代志下 9:3–4"> 示巴女王看到所羅門的一切智慧，還有他建造的宮殿，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 26:16; 列王紀上 4:22–23; 列王紀下 16:18"> 他筵席上的食物，他臣僕們的座次，他侍從的服務和服裝，他的司酒官，以及他在耶和華殿中所獻的燔祭，示巴女王心裡就深深震撼了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="心裡就深深震撼了——原文直譯「喘不過氣來」或「裡面不再有氣息了」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 9:5–6"> 她對王說：「有關你的事蹟和你的智慧，我在本國聽說的那些消息都是真實的！</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 2:9; 約翰福音 20:25–29; 約翰一書 3:2"> 我本來不相信那些話，直到我來之後親眼看到了，看哪，他們連一半都沒有告訴我，你的智慧和福份遠超我所聽到的傳聞。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的臣民多麼有福啊！這些常侍立在你面前、聆聽你智慧的臣僕，是多麼有福啊！</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 72:2; 列王紀上 5:7; 撒母耳記下 8:15"> 耶和華你的神是當受頌讚的！他喜悅你，使你坐以色列的王位。因耶和華永遠愛以色列，所以他立你為王，來實行公正和公義。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 10:2; 馬太福音 2:11; 列王紀上 9:14"> 示巴女王送給所羅門王一百二十他連得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一百二十他連得——相當於4.1公噸。1他連得=34.2公斤。">b</a></sup>金子、極多的香料以及寶石，示巴女王送給所羅門王的香料如此之多，再也沒有這樣運來過。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 9:27–28; 歷代志下 8:18; 詩篇 45:9"> 希蘭的船隊從俄斐運來黃金，此外還從俄斐運來了極多的檀香木和寶石。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 25:1–31; 詩篇 150:3–5; 啟示錄 14:2–3"> 王用這些檀香木為耶和華的殿和王宮做了護欄，為歌手製作豎琴和里拉琴；這樣的檀香木至今沒有運來過，也沒有人看見過。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 37:4; 馬太福音 15:28; 詩篇 20:4"> 除了王慷慨回贈示巴女王的東西，所羅門王還贈送她所想所求的一切。隨後，女王和她的臣僕返回本國去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 9:13–28; 列王紀上 9:28"> 每年帶到所羅門那裡的金子，重六百六十六他連得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="六百六十六他連得——相當於22.8公噸。1他連得=34.2公斤。">c</a></sup>；</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 72:10; 歷代志上 9:24; 以賽亞書 21:13"> 此外還有來自商販和客商，以及阿拉伯諸王和地方省長們的進獻。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:26–28; 歷代志下 12:9–10; 歷代志下 9:15–16"> 所羅門王製作了兩百個錘揲的金盾牌，每個盾牌用六百謝克爾<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="六百謝克爾——相當於6.8公斤。1謝克爾=11.4公克。">d</a></sup>金子；</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:2; 列王紀上 14:26"> 又製作了三百個錘揲的小金盾牌，每個盾牌用三彌納<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三彌納——相當於1.7公斤。1彌納=570公克。">e</a></sup>金子。王就把這些都放在黎巴嫩林宮裡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 45:8; 列王紀上 10:22; 啟示錄 20:11"> 王製作了一個很大的象牙寶座，鍍上純金。</span>
<span className="v" id="v19" data-v="19"> 寶座有六級臺階，寶座的後背有一個圓頂，座位的左邊右邊都有扶手，有兩隻獅子站在扶手兩邊。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 24:9; 創世記 49:9; 民數記 23:24"> 在六級臺階上，共有十二隻獅子分站左右。在列國中，沒有製作過這樣的寶座。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 10:17; 列王紀上 7:2; 歷代志下 9:20–22"> 所羅門王的一切飲酒器皿都是金的，黎巴嫩林宮的一切器皿都是純金的，沒有銀的，銀子在所羅門年間算不了什麼。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 22:48; 創世記 10:4; 歷代志下 20:36–37"> 因為王有一支塔爾施船隊與希蘭的船隊一同出海，這塔爾施船隊每三年回來一次，裝載著金銀、象牙、猿猴和孔雀。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 3:12–13; 歌羅西書 2:2–3; 列王紀上 4:29–34"> 所羅門王在財富和智慧上超過地上所有的君王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 3:12; 雅各書 1:5; 列王紀上 3:28"> 世上的眾王<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="世上的眾王——原文直譯「全地」；參《歷代志下》9:23。">f</a></sup>都想要見所羅門的面，聆聽神賜予他心中的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 42:11; 詩篇 72:10; 詩篇 72:15"> 他們各自帶來貢物，有銀器、金器、衣裳、兵器、香料、馬匹和騾子，年年都是如此。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 9:25; 列王紀上 4:26; 申命記 17:16"> 所羅門屯集戰車和馬兵，有一千四百輛戰車、一萬兩千馬兵，都安置在屯車城，以及王所在的耶路撒冷。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 1:15–17; 申命記 17:17; 歷代志下 9:27"> 王使銀子在耶路撒冷多如石頭，使香柏木像丘陵的西克莫無花果樹那樣多。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 17:16; 歷代志下 9:28; 以賽亞書 31:1–3"> 所羅門的馬匹是埃及和庫威出口的，由王的商人按照市價從庫威買來。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 1:4; 列王紀下 7:6–7; 瑪拉基書 1:1"> 他們從埃及進口的戰車每輛六百謝克爾<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="六百謝克爾——相當於6.8公斤。1謝克爾=11.4公克。">g</a></sup>銀子，馬每匹一百五十謝克爾<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一百五十謝克爾——相當於1.7公斤。">h</a></sup>；這些也經由他們出口到赫提人諸王以及亞蘭眾王那裡。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="傳道書 1:12; 歷代志下 9:30; 列王紀上 12:19–20"> 所羅門王作了全以色列的王，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 18:21; 哥林多前書 12:28; 撒母耳記下 8:15–18"> 他的群臣如下：<br /><span className="pl pl-1">撒督的兒子亞撒利雅作祭司，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:16; 以賽亞書 62:6; 歷代志上 18:15"> <span className="pl pl-1">示沙的兩個兒子以利赫列和亞希雅作書記，</span><br /><span className="pl pl-1">亞希律的兒子約沙法作史官，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:35; 列王紀上 2:26–27"> <span className="pl pl-1">耶赫亞達的兒子比納雅統管軍隊，</span><br /><span className="pl pl-1">撒督和亞比亞特作祭司，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 27:33; 撒母耳記下 15:37; 撒母耳記下 16:16"> <span className="pl pl-1">拿單的兒子亞撒利雅統管總督們，</span><br /><span className="pl pl-1">拿單的兒子撒布德作內官，是王的朋友</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="作內官，是王的朋友——或譯作「作王的祭司兼顧問」。">a</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:15; 撒母耳記下 20:24; 列王紀上 12:18"> <span className="pl pl-1">阿希沙作宮廷總管，</span><br /><span className="pl pl-1">阿布達的兒子亞多尼蘭掌管服苦役的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 27:1–15"> 所羅門在全以色列設立十二個總督，他們要供應王和王室，一年中每人負責供應一個月。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 24:33; 士師記 19:1; 士師記 17:1"> 他們的名字如下：<br /><span className="pl pl-1">本戶珥，管理以法蓮山地；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 21:16; 撒母耳記上 6:20; 撒母耳記上 6:12"> <span className="pl pl-1">本迪克，管理瑪迦斯、沙勒賓、伯示麥、埃隆-伯哈南；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 15:35; 約書亞記 12:17; 約書亞記 17:2"> <span className="pl pl-1">本希悉，管理亞魯泊，梭哥和希弗全地也歸他管理；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 11:2; 約書亞記 12:23; 約書亞記 17:11"> <span className="pl pl-1">本亞比拿達，管理全多珥高地，他娶了所羅門的女兒塔法特為妻；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 17:11; 士師記 5:19; 約書亞記 3:16"> <span className="pl pl-1">亞希律的兒子巴拿，管理特納克、米吉多，以及撒拉坦附近、耶斯列下邊的伯珊全地，從伯珊到亞貝勒-米何拉，一直到約克緬對面；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="申命記 3:4; 民數記 32:41; 列王紀上 22:3"> <span className="pl pl-1">本基別，管理拉末-基列，以及在基列的瑪拿西子孫的那些睚珥鎮，另外巴珊的亞珥歌伯地區也歸他管理，共六十座大城，都有城牆和銅門閂；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 13:26; 撒母耳記下 17:24; 撒母耳記下 2:8"> <span className="pl pl-1">易多的兒子亞希納達，管理瑪哈念；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 19:32–39; 撒母耳記下 15:27; 撒母耳記上 18:18"> <span className="pl pl-1">亞希瑪斯，管理拿弗他利，他也娶了所羅門的女兒，娶了巴絲瑪為妻；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 19:24–31; 撒母耳記下 15:32"> <span className="pl pl-1">戶篩的兒子巴拿，管理亞設和比亞錄；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 19:17–23"> <span className="pl pl-1">帕路阿的兒子約沙法，管理以薩迦；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:8; 約書亞記 18:20–28; 撒迦利亞書 12:13"> <span className="pl pl-1">以拉的兒子示每，管理便雅憫；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:26–17; 約書亞記 13:9–12; 民數記 21:21–35"> <span className="pl pl-1">烏利的兒子基別，管理基列地，就是從前屬亞摩利王西宏和巴珊王歐革的領土，</span><br />他是這地區唯一的總督。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 22:17; 列王紀上 3:8; 創世記 32:12"> 猶大人和以色列人多如海邊的沙，他們有吃有喝，歡喜快樂。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:18; 約書亞記 1:4; 詩篇 68:29"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此節至5:18在馬索拉文本為5:1至5:32。">b</a></sup>所羅門統管列國，從大河<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大河——指幼發拉底河；本章下同。">c</a></sup>到非利士人之地，直到埃及的邊界。所羅門在世的日子，這些王國都向他進貢，臣服於他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 所羅門每日所用的食物，有細麵粉三十柯珥<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三十柯珥——相當於6,600公升。1柯珥=220公升。">d</a></sup>，粗麵粉六十柯珥<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="六十柯珥——相當於13,200公升。">e</a></sup>，</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 5:17–18"> 圈養的肥牛十隻，放牧的牛二十隻，羊一百隻，此外有鹿、羚羊、麃子和各類肉禽。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 22:9; 詩篇 72:11; 詩篇 72:3"> 所羅門統轄大河西邊的全域，從提弗薩到加沙，統治大河西邊的所有君王，他周圍四境都有平安。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 4:4; 撒迦利亞書 3:10; 士師記 20:1"> 所羅門在世的日子，猶大和以色列——從但直到比爾-謝巴，各人在自己的葡萄樹下、無花果樹下，安然居住。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 1:14; 歷代志下 9:25; 撒母耳記下 8:4"> 所羅門有四千個<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="四千個——依據七十士譯本；參《歷代志下》9:25；馬索拉文本作「四萬個」。">f</a></sup>馬廄存放戰車馬匹，還有一萬兩千馬兵。</span>
<span className="v" id="v27" data-v="27"> 那些總督各按自己的月份，供應所羅門王和所有與王同席的人，保證一無所缺。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖記 8:10; 以斯帖記 8:14; 彌迦書 1:13"> 他們各照自己的任務，把戰馬和驛馬所需用的大麥和乾草，送到指定的地方。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 3:12; 雅各書 3:17; 列王紀上 4:20"> 神賜予所羅門智慧、極大的聰慧和廣闊的心思，多如海邊的沙。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 5:11–12; 創世記 25:6; 但以理書 1:20"> 所羅門的智慧超過所有東方人的智慧和埃及人的一切智慧。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 2:6; 歷代志上 15:19; 列王紀上 3:12"> 他比任何人都有智慧，超過以斯拉人伊坦、瑪赫勒的兒子希幔、卡珥克勒、達爾達；他的名聲傳遍了四圍列邦。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 馬太福音 13:35; 箴言 1:1–31"> 他寫作<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="寫作——原文直譯「述說」。">g</a></sup>了三千句箴言，他的詩歌有一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 19:23; 詩篇 51:7; 詩篇 92:12"> 他講論草木植物，從黎巴嫩的香柏樹到牆上長的牛膝草；又講論飛禽走獸、爬蟲水族。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 9:23; 列王紀上 10:1; 歷代志下 9:1"> 萬民中，那些聽說所羅門智慧的各國君王中，都有人來聆聽所羅門的智慧。</span>
</div>

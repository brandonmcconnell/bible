<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 17:17; 箴言 6:24; 尼希米記 13:23–27"> 所羅門王除了法老的女兒之外，還貪愛許多外邦女子，有摩押人、亞捫人、以東人、西頓人和赫提人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 34:16; 申命記 7:3–4; 約書亞記 23:12–13"> 論到這些國民，耶和華曾吩咐過以色列子孫：「你們不可與他們通婚，他們也不可與你們通婚；因為他們必定使你們的心偏離，去隨從他們的神明。」但所羅門卻深深迷戀她們。</span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 7:28; 撒母耳記下 5:13–16; 歷代志下 11:21"> 他有七百個妃，都出身貴族，又有三百個嬪，他的妃嬪使他的心偏離。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:4; 列王紀上 8:61; 列王紀上 11:6"> 所羅門年老的時候，他的妃嬪使他的心偏離，去隨從別的神，他的心沒有像他父親大衛的心那樣完全忠於耶和華他的神。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 2:13; 列王紀上 11:7; 列王紀下 23:13"> 所羅門去隨從西頓人的女神亞斯她錄，也隨從亞捫人的可憎偶像米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:24; 約書亞記 14:8; 約書亞記 14:14"> 所羅門做耶和華眼中看為惡的事，不像他父親大衛那樣全心跟從耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民數記 21:29; 士師記 11:24; 使徒行傳 7:43"> 那時，所羅門為摩押的可憎偶像基抹和亞捫人的可憎偶像摩洛，在耶路撒冷東邊的山上建造高壇；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:11–12; 列王紀上 11:1; 以西結書 16:22–29"> 他為所有的妃嬪，就是那些向自己的神明燒香獻祭的外邦女子，都這樣做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:2; 列王紀上 3:5; 申命記 7:4"> 耶和華對所羅門發怒，因為他的心偏離了曾經兩次向他顯現的耶和華以色列的神；</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:12–13; 歷代志下 7:17–22; 列王紀上 9:4–7"> 耶和華曾為這事吩咐他不可跟從別的神，他卻不遵守耶和華所吩咐的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 12:15–16; 列王紀上 11:31; 列王紀下 17:21"> 於是耶和華對所羅門說：「你既然如此行事，不遵守我的約以及我所吩咐你的律例，我必定從你撕去王國，將它賜給你的臣僕。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 20:19; 撒母耳記上 9:4–5; 列王紀下 22:19–20"> 然而我為你父親大衛的緣故，不會在你在世的日子做這事，我將從你的兒子手中撕去王國。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:20; 申命記 12:11; 列王紀上 11:32"> 不過我不會撕去整個王國，為我僕人大衛的緣故，為我所揀選的耶路撒冷的緣故，我會留下一個支派給你的兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志上 5:26; 詩篇 89:30–34; 以賽亞書 13:17"> 此後耶和華興起一個敵對所羅門的人，就是以東人哈達，他是以東王室的後裔。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 8:14; 歷代志上 18:12–13; 申命記 20:13"> 先前大衛在以東的時候，元帥約押上去埋葬那些陣亡的人，還把以東的所有男丁都擊殺了。</span>
<span className="v" id="v16" data-v="16"> 約押和以色列全軍留在那裡六個月，直到他剪除了以東所有的男丁。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 2:13–14; 出埃及記 2:1–10; 列王紀下 11:2"> 哈達卻逃走了，他和他父親的臣僕——幾個以東人一起逃往埃及，那時哈達還是個小孩子。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 10:12; 申命記 33:2; 申命記 1:1"> 他們從米甸起行，來到帕蘭，又從帕蘭帶了幾個人一同來到埃及，到了埃及王法老那裡。法老賜給他房屋，吩咐供應他糧食，並賜給他土地。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 39:4; 耶利米書 43:7–9; 創世記 39:21"> 哈達在法老眼前蒙大恩，法老把他妻子的妹妹，就是王后塔佩妮斯的妹妹，賜給他為妻。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:7; 撒母耳記上 1:24"> 塔佩妮斯的妹妹給哈達生了兒子格努巴特，塔佩妮斯在法老的宮殿裡撫養他到斷奶，格努巴特就在法老的宮殿裡，與法老的兒子們在一起。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 出埃及記 4:19; 馬太福音 2:20"> 當哈達在埃及聽說大衛與他的列祖長眠，元帥約押也已經死了，他就對法老說：「請讓我走吧，我要回我本土去。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 18:22–23; 路加福音 22:35; 馬可福音 14:31"> 法老對他說：「你在我這裡到底有什麼缺乏，以致你突然想回本土去呢？」<br />他回答：「沒有什麼缺乏，只求你讓我走。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 11:14; 撒母耳記下 8:3; 撒母耳記下 10:15–18"> 神還興起另外一個敵對所羅門的人，就是以利雅大的兒子利遜。他先前從他的主人瑣巴王哈大底謝那裡逃走。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 10:8; 撒母耳記下 10:18; 列王紀上 20:34"> 當時大衛擊殺瑣巴人，利遜就招聚了一夥人，並自立為隊伍的首領。他們來到大馬士革，在那裡住下來，統治大馬士革。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 15:2; 詩篇 106:40; 列王紀上 5:4"> 在所羅門一生的日子，除了哈達為禍患之外，利遜也與以色列敵對，他厭惡以色列，並且統治了亞蘭。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 13:6; 列王紀上 12:2; 列王紀上 11:28"> 還有所羅門的一個臣僕，尼八之子耶羅波安，他是澤利達的以法蓮人，母親是個寡婦，名叫洗魯阿；這耶羅波安也起來反叛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="起來反叛——原文直譯「舉手反對」。">a</a></sup>王。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:24; 列王紀上 9:15; 箴言 30:32"> 他起來反叛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="起來反叛——原文直譯「舉手反對」。">b</a></sup>所羅門王的經過如下：先前所羅門修築梯壘，修補他父親大衛之城的破口。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳記下 19:20; 士師記 1:22–23"> 耶羅波安這人很有能力，所羅門見這年輕人工作勤奮，就指派他管理約瑟家的一切勞役。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:15; 列王紀上 14:2; 歷代志下 9:29"> 那時，耶羅波安從耶路撒冷出來，示羅人先知亞希雅在路上遇見了他。亞希雅穿著一件新外袍，當時只有他們二人在田野。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 15:27–28; 撒母耳記上 24:4–5"> 亞希雅抓住自己身上的新外袍，把它撕成十二片。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 11:11–12"> 他對耶羅波安說：<br />「拿去十片吧！因為以色列的神耶和華如此說：『看哪，我必把王國從所羅門手中撕去，將十個支派賜給你。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 11:13; 列王紀上 12:20–21; 列王紀上 14:21"> 但為我僕人大衛的緣故，為我從以色列眾支派所揀選的耶路撒冷城的緣故，會有一個支派留給所羅門。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 11:9; 列王紀上 11:5–7; 列王紀上 9:5–7"> 因為他離棄了我，去膜拜西頓人的女神亞斯她錄、摩押的神基抹和亞捫人的神米勒公，沒有像他父親大衛那樣遵行我的道，做我眼中看為正的事，遵守我的律例和法規。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:12–13; 列王紀上 11:31; 約伯記 11:6"> 「『然而，我不會從他手中奪去整個王國，我要讓他一生的日子都作君王；這是為了我所揀選的僕人大衛的緣故，因大衛遵守了我的誡命和律例。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 12:20; 列王紀上 11:12; 出埃及記 20:5–6"> 我要從他兒子手中奪去王權，把十個支派賜給你，</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 8:19; 列王紀上 11:13; 列王紀上 15:4"> 只留下一個支派給他的兒子，好讓我僕人大衛在我面前、在我所揀選安置我名的城——耶路撒冷，永遠有一盞燈。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 14:26; 列王紀上 11:26; 撒母耳記下 3:21"> 我選擇你，讓你照著自己的心願統治一切，作王掌管以色列。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 7:11; 約書亞記 1:5; 申命記 31:8"> 「『如果你聽從我所吩咐你的一切，遵行我的道，像我僕人大衛所行的那樣，做我眼中看為正的事，謹守我的律例和誡命，我就與你同在，為你建立一個持久的家室，像我為大衛建立的家室一樣；並且我要把以色列賜給你。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以賽亞書 11:1–10"> 我要因所羅門的罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="因所羅門的罪——原文直譯「因此」。">c</a></sup>而苦待大衛的後裔，但不會永遠這樣。』」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歷代志下 12:2–9; 以賽亞書 14:24–27; 耶利米哀歌 3:37"> 所羅門想要殺耶羅波安，耶羅波安就動身逃往埃及，到了埃及王示撒那裡。他留在埃及，直到所羅門去世。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志下 9:29–31"> 所羅門其餘的事蹟和他所做的一切，以及他的智慧，不是都記在《所羅門紀事》上嗎？</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 2:11"> 所羅門在耶路撒冷統治全以色列的日子有四十年。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀下 21:18; 列王紀上 2:10; 馬太福音 1:7"> 所羅門與他的列祖長眠，葬在他父親大衛的城；他的兒子羅波安接替他作王。</span>
</div>
</div>

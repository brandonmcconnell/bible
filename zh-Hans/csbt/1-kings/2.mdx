<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 47:29; 申命記 31:14; 提摩太前書 1:18"> 大衛死的日子臨近了，他囑咐他的兒子所羅門說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:6–7; 約書亞記 23:14; 以弗所書 6:10"> 「我就要走世人都必走的路了；你要堅強，要作大丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:9; 申命記 17:18–20; 箴言 3:1–4"> 你要遵守你的神耶和華的吩咐，照著摩西律法上所記的，遵行他的道，謹守他的律例、誡命、規定和法度，好使你無論做什麼，無論轉向哪裡，都會通達。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 20:3; 撒母耳記下 7:25; 列王紀上 8:25"> 這樣，耶和華必成就他所論到我的話說：你的子孫如果謹守自己的道路，全心、全靈誠實地行走在我面前，你的子孫中就不會斷絕人坐以色列的王位。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 3:27; 撒母耳記下 20:10; 撒母耳記下 18:5"> 「此外，你也知道洗魯雅的兒子約押對我所做的事，就是他對以色列的兩個元帥——尼珥的兒子押尼珥和耶特爾的兒子亞瑪撒所做的：他在和平時期殺人流血，像在戰爭時期一樣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他在和平時期殺人流血，像在戰爭時期一樣——原文直譯「他殺了他們，在和平時期流了戰爭的血」。">a</a></sup>，使戰爭的血染透了他的腰帶和腳上的鞋。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 2:9; 以賽亞書 57:21; 詩篇 37:37"> 所以你要憑智慧行事，不要讓他白頭安然地下陰間。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 17:27–29; 撒母耳記下 9:7; 撒母耳記下 19:31–40"> 「你要向基列人巴爾茲萊的兒子們施慈愛，把他們列在你筵席上吃飯的人當中，因為我逃避你哥哥押沙龍的時候，他們也如此接待了我。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 16:5–8; 列王紀上 2:36–46; 撒母耳記下 19:16–23"> 「看哪，你這裡還有巴戶琳的便雅憫人基拉的兒子示每：他在我去瑪哈念那天，用嚴厲的惡言咒罵我。但後來他下到約旦河來迎接我的時候，我指著耶和華向他起誓說：『我絕不動刀殺你。』</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:6; 創世記 42:38; 創世記 44:31"> 現在你不要讓他免於罪罰，你是有智慧的人，一定知道怎樣對待他，要讓他白頭見血下陰間。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:29; 使徒行傳 13:36; 列王紀上 1:21"> 此後大衛與他列祖長眠，葬在大衛城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 5:4–5; 歷代志上 29:26–27"> 大衛統治以色列的日子有四十年：在希伯崙統治七年，在耶路撒冷統治三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 1:1; 歷代志上 29:23–25; 詩篇 132:12"> 所羅門坐上了他父親大衛的寶座，他的王權極其穩固。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 16:4–5; 列王紀上 1:5–10; 路加福音 10:5–6"> 哈及的兒子亞多尼雅去見所羅門的母親芭示巴，芭示巴問：「你是帶著平安來的嗎？」<br />他回答：「平安。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 14:12; 路加福音 7:40"> 他接著說：「我有事要對你說。」<br />芭示巴說：「請說。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 22:9–10; 歷代志上 28:5–7; 列王紀上 1:25"> 他說：「你知道這王國本來是歸屬我的，全以色列也期望我作王，但王國卻轉歸了我弟弟，因為這是出於耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 詩篇 132:10"> 現在我請求你一件事，請你不要回絕我。」<br />芭示巴對他說：「你說吧。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 12:8; 列王紀上 1:2–4; 撒母耳記下 3:7"> 亞多尼雅就說：「求你向所羅門王提說，讓他把書念女子婭比莎賜給我為妻；他一定不會回絕你的。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 芭示巴說：「好，我可以為你向王提說。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="詩篇 45:9; 列王紀上 15:13; 利未記 19:32"> 於是芭示巴去見所羅門王，為亞多尼雅向王提說。王起身迎接她，向她下拜，然後坐回寶座上，又給母后擺設一個座位，她就在王的右邊坐下。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:7–11; 馬太福音 11:24; 約翰福音 2:3–4"> 芭示巴說：「我要向你提出一個小小的請求，請你不要回絕我。」<br />王對她說：「請說吧，母親，我不會回絕你。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 1:3; 撒母耳記下 16:21–22"> 芭示巴說：「請你把書念女子婭比莎賜給你的哥哥亞多尼雅為妻。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歷代志上 3:2; 歷代志上 3:5; 馬太福音 20:22"> 所羅門王回答他母親說：「你為什麼替亞多尼雅求書念女子婭比莎呢？既然他是比我年長的哥哥，你也為他——以及祭司亞比亞特和洗魯雅的兒子約押——求這王國吧。」</span>
<span className="v" id="v23" data-v="23" data-xref="路得記 1:17; 詩篇 140:9; 詩篇 64:8"> 於是所羅門王指著耶和華起誓說：「亞多尼雅提出這請求，如果他不賠上自己的性命，就願神處置我，重重地處置我！</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 22:10; 歷代志上 17:10; 歷代志上 17:17"> 耶和華堅立了我，使我坐上我父親大衛的寶座，照著他所應許的為我建立家室，現在我指著耶和華的永生起誓：亞多尼雅今天必被處死！」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 8:18; 列王紀上 2:46; 士師記 8:20–21"> 然後，所羅門王派耶赫亞達的兒子比納雅去擊殺亞多尼雅，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約書亞記 21:18; 撒母耳記上 22:20–23; 耶利米書 1:1"> 王對祭司亞比亞特說：「回亞納圖你自己的田地去吧。你本來是該死的人，但我今天不殺你，因為你從前在我父親大衛面前抬主耶和華的約櫃，並且與我父親同受他的一切苦難。」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 2:27–36; 撒母耳記上 3:12–14; 耶利米書 7:12–14"> 這樣，所羅門驅逐了亞比亞特，不讓他作耶和華的祭司，應驗了耶和華在示羅所說有關以利家的話。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 1:50; 列王紀上 1:7; 撒母耳記下 18:2"> 這消息傳到了約押那裡；約押雖然沒有附從押沙龍，卻附從了亞多尼雅。約押就逃到耶和華的帳幕那裡，抓住祭壇的犄角。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 2:25; 出埃及記 21:14; 列王紀上 2:46"> 有人稟告所羅門王：「約押逃到耶和華的帳幕那裡了，看哪，就在祭壇旁邊。」所羅門就派耶赫亞達的兒子比納雅，說：「去把他殺了！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 比納雅進入耶和華的帳幕，對約押說：「王如此吩咐：你出來！」<br />約押回應：「不，我要死在這裡。」<br />比納雅就去回稟王說：「約押如此說，如此回答我。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 21:8–9; 民數記 35:33; 出埃及記 21:14"> 王對比納雅說：「你就照著他的話去做吧，把他殺掉，埋葬了，這樣就從我和我父家除去了約押無故殺人流血的罪。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 9:24; 士師記 9:57; 詩篇 7:16"> 耶和華必使約押的血債歸到他自己頭上，因為他在我父親大衛不知道的情況下，殺害兩個比他公義良善的人，用刀殺了尼珥之子以色列的元帥押尼珥和耶特爾之子猶大的元帥亞瑪撒。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:25; 列王紀上 2:32; 路加福音 2:14"> 這血債必永遠歸到約押頭上，以及他後裔的頭上；至於大衛和他的後裔，他的家和王位，願耶和華賜予平安，直到永遠。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 3:1; 約書亞記 15:61; 列王紀上 2:25"> 於是耶赫亞達的兒子比納雅上去擊殺約押，把他處死了，葬在曠野他的家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="家——或譯作「墓穴」。">b</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 2:27; 歷代志上 24:3; 歷代志上 29:22"> 此後，王立耶赫亞達的兒子比納雅替代約押統管軍隊，王又立祭司撒督替代亞比亞特。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 16:5–9; 列王紀上 2:8–9; 箴言 20:26"> 王派人召來示每，對他說：「你要在耶路撒冷為自己建造房屋，住在這裡，不可離開去任何地方。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 1:16; 撒母耳記下 15:23; 約書亞記 2:19"> 當你離開，越過汲淪溪谷那天，你要確切知道：你必定死，你的血債將歸到你自己頭上。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王紀上 20:4; 列王紀下 20:19"> 示每回答王：「這話甚好，我主我王怎麼說，你僕人就怎麼做。」於是示每在耶路撒冷住了許多日子。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 21:10; 撒母耳記上 27:2–3"> 過了三年，示每的兩個奴僕逃到了瑪迦的兒子迦特王亞吉那裡。有人告訴示每說：「看哪，你的奴僕在迦特。」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前書 6:10"> 示每就動身，給驢子備好鞍，往迦特到亞吉那裡去尋找他的奴僕。示每去把他們從迦特帶回來了。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41"> 有人稟告所羅門：示每離開耶路撒冷去了迦特，又回來了。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 15:4; 列王紀上 2:36–38; 路加福音 15:22"> 王就派人把示每召來，對他說：「我不是讓你指著耶和華起誓，並且警誡過你嗎？我說：『當你離開去任何地方那天，你要確切知道：你必定死。』你也回答我：『這話甚好，我會聽從。』</span>
<span className="v" id="v43" data-v="43" data-xref="羅馬書 13:5; 歷代志下 30:12; 傳道書 8:2"> 現在，你為什麼不遵守你向耶和華所起的誓，以及我吩咐你的命令呢？」</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記下 16:5–13; 詩篇 7:16; 以西結書 17:19"> 王又對示每說：「你知道你對我父親大衛所做的一切惡事，你心裡很清楚。現在耶和華把你的罪惡報應在你頭上了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王紀上 2:24; 以賽亞書 9:6–7"> 所羅門王卻必蒙福，大衛的寶座也必在耶和華面前堅立，直到永遠。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="歷代志下 1:1; 列王紀上 2:12; 列王紀上 2:45"> 於是王吩咐耶赫亞達的兒子比納雅，他出去擊殺示每，示每就死了。這樣，王國在所羅門手中得以穩固。</span>
</div>
</div>

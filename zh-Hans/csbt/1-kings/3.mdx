<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:24; 列王紀上 11:1; 列王紀上 6:1–15"> 所羅門與埃及王法老結親，娶了法老的女兒，把她先接到大衛城，直到所羅門建完自己的宮殿以及耶和華的殿和耶路撒冷四圍的城牆。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 22:43; 歷代志下 33:17; 申命記 12:2–5"> 那時百姓仍舊在高壇獻祭，因為還沒有為耶和華的名建造好殿宇。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 8:3; 詩篇 31:23; 申命記 30:16"> 所羅門愛耶和華，遵行他父親大衛的律例，不過他也在高壇獻祭、燒香。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志上 16:39; 歷代志下 1:3; 歷代志下 7:5"> 有一天，所羅門王到基遍去，在那裡獻祭，因為那是個重要的高壇。所羅門在那祭壇上獻了一千隻燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 9:2; 雅各書 1:5–6; 民數記 12:6"> 在基遍，耶和華藉著夜間的夢向所羅門顯現，神說：「你要我賜給你什麼，儘管求吧。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:4; 列王紀上 1:48; 哥林多後書 9:11"> 所羅門說：「你以極大的慈愛對待你僕人我父親大衛，因他以真理、公義和一顆正直的心行走在你面前；你還持守這極大的慈愛對待他，賜給他一個兒子坐在他的寶座上，就像今日這樣。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 29:1; 民數記 27:17; 耶利米書 1:6"> 「耶和華我的神哪，如今你立你的僕人為王接替我父親大衛，但我是個小孩子，不知怎樣出入。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:5; 創世記 13:16; 歷代志上 21:2"> 你的僕人在你所揀選的子民當中，而這眾多的子民多得不可勝數、無法數清，</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 1:5; 箴言 16:16; 希伯來書 5:14"> 所以求你賜給僕人一顆明辨的心，使我能治理你的子民，辨別是非。否則，誰能治理你這眾多的子民呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 所羅門祈求這事，在主的眼中看為好。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:26; 雅各書 4:2–3; 箴言 16:31"> 神就對他說：「既然你求這事，而不為自己求長壽，不為自己求富貴，也不求你仇敵的性命，卻為自己求悟性，為要明辨申訴，</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 5:14–15; 傳道書 1:16; 馬太福音 12:42"> 看哪，我必成全你的請求。現在我要賜給你一顆智慧明辨的心，在你之前未曾有像你這樣的人，在你之後也不會興起像你這樣的人。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 3:20; 馬太福音 6:33; 箴言 3:16"> 此外，你沒有求的富貴和榮華，我也賜給你，在你一生的日子，君王中沒有一個人能與你相比。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 詩篇 91:16; 列王紀上 15:5"> 而且如果你像你父親大衛所行的那樣遵行我的道，謹守我的律例和誡命，我就使你長壽。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 41:7; 列王紀上 8:65; 以斯帖記 1:3"> 所羅門醒來後，看哪，是一個夢。他就回到耶路撒冷，站在主的約櫃前，獻上燔祭，又獻平安祭，也為他所有的臣僕擺設宴席。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 18:16; 士師記 11:1; 民數記 27:2"> 有一天，兩個妓女來見王，站在他面前。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:7; 創世記 43:20"> 其中一個婦人說：「哦，我主啊，我和那婦人同住一間房屋，我生孩子的時候，她也在屋子裡。</span>
<span className="v" id="v18" data-v="18"> 我生了孩子的第三天，那婦人也生了孩子，當時我們在一起。屋子裡沒有別人，只有我們兩個在屋子裡。</span>
<span className="v" id="v19" data-v="19"> 夜間，那婦人的兒子死了，因為她壓在孩子身上了。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 3:20; 馬太福音 13:25; 詩篇 139:11"> 她就半夜起來，趁著婢女我沉睡的時候，把我的兒子從我身邊抱走，放在她懷中，而把她死了的兒子放在我懷中。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:7; 撒母耳記上 1:23; 耶利米哀歌 4:3–4"> 我清早起來給我兒子吃奶，看哪，他已經死了。但清早我仔細察看時，發現那不是我生的兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王紀上 3:23–24"> 另一個婦人卻說：「不！活的是我兒子，死的才是你兒子。」<br />這個婦人就說：「不！死的是你兒子，活的是我兒子。」兩人在王面前彼此爭辯。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 王說：「這個說『活的是我兒子，死的是你兒子』，那個說『不！死的才是你兒子，活的是我兒子』」，</span>
<span className="v" id="v24" data-v="24"> 王就吩咐：「給我拿一把刀來！」於是有人把刀拿到王面前。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王說：「把活孩子劈成兩半，一半給這婦人，一半給那婦人。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 49:15; 耶利米書 31:20; 約翰一書 3:17"> 那活孩子的母親因為憐子之心湧上來，就對王說：「哦，我主啊，把活孩子給她吧，千萬不要殺他！」<br />另一個婦人卻說：「這孩子也不歸我，也不歸你，劈了吧！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 於是王宣判說：「把活孩子交給這婦人，千萬不要殺他，這婦人就是他的母親。」</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:47; 列王紀上 3:9–12; 歌羅西書 2:3"> 全以色列都聽說了王所做的判決，就敬畏王，因為他們看到王裡面有神的智慧，能實行公正。</span>
</div>
</div>

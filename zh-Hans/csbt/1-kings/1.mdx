<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 23:1–2; 歷代志上 29:27–28; 歷代志上 23:1"> 大衛王老了，上了年紀，人們給他蓋上厚毯子，他還是不能暖和。</span>
<span className="v" id="v2" data-v="2" data-xref="傳道書 4:11; 創世記 16:5; 彌迦書 7:5"> 臣僕們對他說：「請讓人為我主我王尋找一個年輕處女，她可以在王面前侍候，照顧王，睡在王的懷中，使我主我王暖和。」</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 19:18; 以斯帖記 2:4; 以斯帖記 2:2"> 於是他們在以色列全境尋找美麗年輕的女子，找到了書念女子婭比莎，把她帶到王那裡。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:25"> 這女子極其美麗，她照顧王，侍候他，但王卻沒有與她行房。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 15:1; 撒母耳記下 3:4; 申命記 17:15–16"> 那時，哈及的兒子亞多尼雅高抬自己說：「我要作王。」他就為自己配備戰車和馬兵，還有五十人在他前面奔跑開道。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 3:3–4; 撒母耳記上 3:13; 希伯來書 12:5–6"> 他的父親從來沒有責問他說：「你為什麼這樣做？」他的身材也非常健美，他是在押沙龍之後出生的。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 20:25; 列王紀上 2:22; 撒母耳記上 22:20–23"> 亞多尼雅與洗魯雅的兒子約押、祭司亞比亞特一同商議，他們就輔助亞多尼雅。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 4:18; 撒母耳記下 23:8–39; 撒母耳記下 20:25"> 但祭司撒督、耶赫亞達的兒子比納雅、先知拿單、示每、列伊和大衛的勇士們，沒有附從亞多尼雅。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 17:17; 撒母耳記下 13:23–27; 撒母耳記下 15:11–12"> 於是，亞多尼雅在恩羅格爾附近，瑣希列的磐石那裡，祭獻牛羊和肥畜。他邀請了他所有的兄弟——王子們，以及所有作王臣僕的猶大人，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 12:24; 列王紀上 1:19; 撒母耳記下 12:1–15"> 但沒有邀請先知拿單、比納雅、勇士們和他的兄弟所羅門。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 3:4; 撒母耳記下 7:12–17; 撒母耳記下 12:24–25"> 拿單對所羅門的母親芭示巴說：「你沒有聽說嗎，哈及的兒子亞多尼雅作王了，而我們的主大衛還不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行傳 27:31; 創世記 19:17"> 現在，請讓我給你提個建議，保全你的性命和你兒子所羅門的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 1:30; 列王紀上 1:17; 詩篇 132:11–12"> 你到大衛王那裡去，對他說：『我主我王啊，你不是曾經向你的女僕起誓說「你兒子所羅門將接續我作王，他將坐在我的寶座上」嗎？現在為什麼亞多尼雅卻作了王呢？』</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 13:1; 列王紀上 1:17–27"> 看哪，你還在那裡與王說話的時候，我會隨後進去，證實你的話。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 1:1"> 於是芭示巴來到內室見王。王已經很老了，書念女子婭比莎正在侍候王。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 25:23; 撒母耳記上 24:8; 撒母耳記上 20:41"> 芭示巴向王俯身下拜，王問：「你有什麼事呢？」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 1:13; 列王紀上 1:30; 彼得前書 3:6"> 她回答王：「我主啊，你曾指著你的神耶和華向女僕起誓說：『你兒子所羅門將接續我作王，他將坐在我的寶座上。』</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:24; 列王紀上 1:11; 使徒行傳 3:17"> 現在看哪，亞多尼雅卻作了王，而我主我王現在還不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 1:25; 列王紀上 1:7–10"> 他祭獻了大量的牛羊和肥畜，還邀請了眾王子、祭司亞比亞特和元帥約押，卻沒有邀請你的僕人所羅門。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 29:1; 詩篇 123:2; 歷代志上 22:8–10"> 現在，我主我王啊，全以色列都矚目在你身上，盼著你告訴他們，誰才會接續你坐在我主我王的寶座上。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 申命記 31:16; 創世記 15:15"> 否則，當我主我王與列祖長眠之後，我和我兒子所羅門就要成為罪人了！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約伯記 1:16–18; 創世記 24:15; 但以理書 9:20"> 看哪，芭示巴還在與王說話的時候，先知拿單進來了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 1:16; 彼得前書 2:17; 羅馬書 13:7"> 有人稟告王說：「看哪，先知拿單來了。」拿單就來到王面前，臉伏於地向王下拜。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:17–18; 列王紀上 1:5; 列王紀上 1:13–14"> 拿單說：「我主我王啊，你是否說過『亞多尼雅將接續我作王，他將坐在我的寶座上』？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 10:24; 列王紀上 1:19; 列王紀上 1:9"> 要知道，亞多尼雅今天下去祭獻了大量的牛羊和肥畜，還邀請了眾王子、將領們和祭司亞比亞特。看哪，他們在亞多尼雅面前吃喝，說：『亞多尼雅王萬歲！』</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 1:8; 列王紀上 1:10; 撒母耳記下 7:2"> 他卻沒有邀請你僕人我，並祭司撒督、耶赫亞達的兒子比納雅以及你的僕人所羅門。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 15:15; 列王紀上 1:24; 列王紀下 4:27"> 這件事是否出於我主我王呢？王並沒有告訴僕人，誰將接續我主我王坐在你的寶座上啊。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 大衛王就回應說：「叫芭示巴到我這裡來。」於是芭示巴進來，站在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 4:9; 詩篇 136:24; 撒母耳記上 14:45"> 王起誓說：「我指著那救贖我性命脫離一切患難的耶和華的永生起誓：</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:13; 列王紀上 1:17"> 我從前怎樣指著以色列的神耶和華向你起誓說：『你的兒子所羅門將接續我作王，他將接替我坐在我的寶座上』，我今天必如此實行。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="但以理書 2:4; 但以理書 5:10; 但以理書 3:9"> 於是芭示巴臉伏於地，向王下拜，說：「願我主大衛王萬歲！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀上 1:8; 列王紀上 1:38; 列王紀上 1:26"> 大衛王又說：「把祭司撒督、先知拿單和耶赫亞達的兒子比納雅召來見我。」他們就來到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 32:30; 列王紀上 1:38; 歷代志下 33:14"> 王吩咐他們：「帶上你們主人的眾僕人，讓我兒子所羅門騎上我的騾子，送他下到基訓去。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 1:25; 撒母耳記下 15:10; 撒母耳記上 10:1"> 在那裡讓祭司撒督和先知拿單膏立他為以色列的王。你們要吹響號角，說：『所羅門王萬歲！』</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 1:17; 詩篇 72:1–2; 列王紀上 1:13"> 然後你們跟隨他上來，讓他坐在我的寶座上。他要接替我作王，我已經指定他作以色列和猶大的領袖。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米書 28:6; 哥林多前書 14:16; 詩篇 72:19"> 耶赫亞達的兒子比納雅回應王說：「阿們！願我主我王的神耶和華也如此說。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 20:13; 列王紀上 1:47; 約書亞記 1:17"> 耶和華怎樣與我主我王同在，願他也照樣與所羅門同在，使他的王位比我主大衛王的王位更尊大。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 8:18; 列王紀上 1:8; 列王紀上 1:33"> 於是祭司撒督、先知拿單和耶赫亞達的兒子比納雅，以及基利提人和比利提人都下去，讓所羅門騎上大衛王的騾子，送他到基訓去。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 89:20; 列王紀上 1:34; 歷代志上 29:22"> 祭司撒督取出帳幕裡盛膏油的犄角，膏抹了所羅門。他們就吹響號角，全體民眾都說：「所羅門王萬歲！」</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 11:14; 撒迦利亞書 9:9; 列王紀下 11:20"> 全體民眾都跟隨他上來，民眾吹著橫笛，極其歡喜快樂，似乎大地都因他們的聲音震裂。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約伯記 15:21–22; 路加福音 17:26–29; 使徒行傳 21:31"> 亞多尼雅和所有與他在一起的客人剛結束吃喝，聽到了這聲音。約押聽到號角聲，就說：「城中為什麼有喧鬧的聲音呢？」</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記下 15:36; 撒母耳記下 17:17; 撒母耳記下 18:27"> 他還在說話，看哪，祭司亞比亞特的兒子約拿單來了。亞多尼雅說：「進來吧！你是個忠義的人，一定是來報好消息的。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 約拿單回答亞多尼雅說：「不好了！我們的主大衛王已經立所羅門為王了。</span>
<span className="v" id="v44" data-v="44"> 王派遣祭司撒督、先知拿單和耶赫亞達的兒子比納雅，以及基利提人和比利提人，與所羅門同去，他們讓他騎上了王的騾子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 1:40; 但以理書 5:26–28; 撒母耳記上 4:5"> 祭司撒督和先知拿單在基訓膏立他為王，人們歡喜地從那裡上來，全城都轟動了。這就是你們所聽見的聲音。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="歷代志上 29:23; 詩篇 132:11; 列王紀上 1:13"> 「不但所羅門坐上了王位，</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 47:31; 列王紀上 1:37; 以斯拉記 6:10"> 而且王的臣僕們也去為我們的主大衛王祝福說：『願你的神使所羅門的名比你的名更美，使他的王位比你的王位更尊大。』王就在床上敬拜，</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 3:6; 詩篇 132:11–12; 詩篇 145:2"> 然後這樣說：『以色列的神耶和華是當受頌讚的！因為他今天設立一人坐上我的寶座，讓我親眼看到了。』」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以賽亞書 21:4–5; 箴言 28:1; 但以理書 5:4–6"> 於是亞多尼雅的所有客人都戰戰兢兢起身，各自上路散去了。</span>
<span className="v" id="v50" data-v="50" data-xref="列王紀上 2:28; 出埃及記 21:14; 出埃及記 27:2"> 亞多尼雅懼怕所羅門，就動身，前去抓住祭壇的犄角。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> 有人稟告所羅門說：「看哪，亞多尼雅懼怕所羅門王。你看，他抓住了祭壇的犄角說：『請所羅門王今天向我起誓，絕不用刀處死他的僕人。』」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="撒母耳記上 14:45; 撒母耳記下 14:11; 箴言 13:6"> 所羅門說：「如果他是個忠義的人，他連一根頭髮也不會掉在地上；但如果在他身上發現了惡行，他就必死。」</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 1:16; 撒母耳記下 14:24; 撒母耳記下 1:2"> 於是所羅門王派人去把亞多尼雅從祭壇上帶下來。他前來向所羅門王下拜，所羅門對他說：「你回家去吧。」</span>
</div>
</div>

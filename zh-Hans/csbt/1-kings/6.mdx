<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1KI" data-book-slug="1-kings" data-book-name="列王紀上" data-chapter="6" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 3:1–2; 使徒行傳 7:47; 歷代志上 29:19"> 以色列子孫出埃及地之後的第四百八十年，所羅門作以色列王的第四年西弗月，就是二月，他開始建造耶和華的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 40:1–41; 以西結書 41:1–15; 啟示錄 21:16–17"> 所羅門王為耶和華建造的殿宇，長六十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六十肘——相當於27.4公尺。1肘=45.7公分。">a</a></sup>，寬二十肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十肘——相當於9.1公尺。">b</a></sup>，高三十肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十肘——相當於13.7公尺。">c</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 28:11; 歷代志下 3:3–4; 以西結書 41:15"> 殿宇正殿前面的門廊：寬度的尺寸與殿宇一樣是二十肘，殿宇前面的進深是十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="十肘——相當於4.6公尺。">d</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 40:16; 以西結書 41:26; 以西結書 41:16"> 他為殿宇做了嵌入式的格子窗。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:16; 列王紀上 6:19–21; 列王紀上 6:31"> 靠著殿宇四圍的牆壁，也就是圍繞正殿和內殿的殿宇牆壁，他建造層架結構，四圍建造了厢房。</span>
<span className="v" id="v6" data-v="6"> 層架結構的下層寬五肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="五肘——相當於2.3公尺。1肘=45.7公分。">e</a></sup>，中層寬六肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="六肘——相當於2.7公尺。">f</a></sup>，第三層寬七肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="七肘——相當於3.2公尺。">g</a></sup>；他在殿宇四圍的外牆上做了牆坎，免得梁木插入殿宇的牆壁。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:5–6; 彼得前書 2:5; 出埃及記 20:25"> 建造殿宇是用採石場鑿好的料石來建造，所以建造時，殿宇裡聽不到鐵錘、斧頭或任何鐵器的聲音。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 41:6–7"> 厢房的入口在殿宇右側，可以從螺旋梯上到中層，再從中層到第三層。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:14; 列王紀上 6:38"> 所羅門建完殿宇，用香柏木的椽子和望板給殿宇封頂。</span>
<span className="v" id="v10" data-v="10"> 他靠著整個殿宇的側面建造了層架結構，每層<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="每層——輔助詞語。">h</a></sup>高五肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="五肘——相當於2.3公尺。">i</a></sup>，並且用香柏木的梁與殿宇連接。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華的話語臨到所羅門，說：</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 22:10; 歌羅西書 1:23; 列王紀上 3:14"> 「論到你建造的這殿宇，如果你遵從我的律例，遵行我的法規，謹守遵行我的一切誡命，我就向你成就我應許你父親大衛的話。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 31:6; 出埃及記 25:8; 利未記 26:11"> 我必住在以色列人中間，絕不離棄我的子民以色列。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 6:9; 列王紀上 6:38; 使徒行傳 7:47–48"> 所羅門建造這殿宇，完工了。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:7"> 他用香柏木板建造殿宇的牆壁內面；從殿宇地面到頂部的檁那裡，內面都貼上木板，殿宇的地面也貼上松木板。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 3:8; 列王紀上 8:6; 希伯來書 9:3"> 他又把殿宇的後面部分二十肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="二十肘——相當於9.1公尺；下同。1肘=45.7公分。">j</a></sup>，從地面到檁那裡用香柏木板隔起來，在殿宇中建造了一間內殿，作為至聖所。</span>
<span className="v" id="v17" data-v="17"> 這內殿前面是正殿，有四十肘<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="四十肘——相當於18.3公尺。">k</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:24"> 殿宇內面的香柏木上雕刻著匏瓜和綻放的花朵，殿宇內全用香柏木，一塊石頭也見不著。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:6–10; 詩篇 28:2; 列王紀上 6:5"> 內殿設立在殿宇的最裡面，是為了安放耶和華的約櫃。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 6:2–3; 列王紀上 6:22; 列王紀上 7:48"> 內殿長二十肘，寬二十肘，高二十肘，都貼上了純金，香柏木造的祭壇也貼上純金。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 3:7–9; 歷代志下 3:14–16; 列王紀上 6:5"> 所羅門給殿宇內面都貼上了純金，內殿前懸掛金鏈，內殿也貼上金子。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 30:1; 出埃及記 30:3; 歷代志下 3:7–14"> 殿宇內全都貼上金子，直到整個殿宇都貼完；還有內殿前的壇，也整個包上了金子。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 37:7–9; 創世記 3:24; 彼得前書 1:12"> 內殿中，他用橄欖木製作了兩個基路伯，每個<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="每個——輔助詞語。">l</a></sup>高十肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="十肘——相當於4.6公尺；下同。1肘=45.7公分。">m</a></sup>。</span>
<span className="v" id="v24" data-v="24"> 基路伯的一隻翅膀是五肘<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="五肘——相當於2.3公尺；下同。">n</a></sup>，另一隻翅膀也是五肘，從這翅尖到那翅尖總長十肘。</span>
<span className="v" id="v25" data-v="25"> 第二個基路伯的翅展也是十肘，兩個基路伯的尺寸一樣，形狀也一樣。</span>
<span className="v" id="v26" data-v="26"> 第一個基路伯高十肘，第二個基路伯也一樣。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 37:9; 出埃及記 25:20; 歷代志下 5:8"> 所羅門把基路伯安放在內殿裡面，基路伯的雙翅展開，第一個基路伯的一隻翅膀碰到一邊的牆，第二個基路伯的一隻翅膀碰到另一邊的牆，它們的另一隻翅膀在內殿的中央彼此相接——翅尖連翅尖。</span>
<span className="v" id="v28" data-v="28"> 他給基路伯也包上了金子。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 6:32; 詩篇 92:12–15; 歷代志下 4:2–5"> 內殿和正殿四面的牆上都雕刻著基路伯、棕櫚樹和綻放的花朵。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 21:18–21; 以賽亞書 60:17; 以賽亞書 54:11–12"> 內殿和正殿的地面，也都貼上了金子。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="希伯來書 10:19–20; 以弗所書 3:18; 約翰福音 14:6"> 內殿的入口，用橄欖木製作了門扇、門楣和五稜的門框立柱。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 6:18; 列王紀上 6:29"> 橄欖木的兩扇門上，雕刻了基路伯、棕櫚樹和綻放的花朵，然後貼上金子，基路伯和棕櫚樹也敷上一層金子。</span>
<span className="v" id="v33" data-v="33"> 同樣，正殿的入口用橄欖木製作了四稜的門框立柱。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 41:23–25; 列王紀上 5:8"> 兩扇門是松木的，這一扇門是兩葉折疊式的，另一扇門也是兩葉折疊式的，</span>
<span className="v" id="v35" data-v="35"> 都雕刻了基路伯、棕櫚樹和綻放的花朵，然後給這些雕刻均匀地鍍上金子。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:12; 歷代志下 7:7; 出埃及記 27:9–19"> 他又用三層鑿好的料石，以及一層香柏木梁，建造了內院。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王紀上 6:1; 歷代志下 3:2"> 所羅門在位第四年的西弗月，他奠定了耶和華殿的根基。</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉記 6:14–15; 列王紀上 7:1; 撒迦利亞書 4:9"> 到了第十一年的布勒月，就是八月，他照著所有的細節，按著全部的規劃，完成了殿宇。他建造殿宇用了七年。</span>
</div>
</div>

</div>

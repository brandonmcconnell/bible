<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 20:5; 列王紀上 13:33–34; 撒母耳記上 31:2"> 那時，耶羅波安的兒子亞比雅病了。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 28:8; 列王紀上 11:29–38; 撒母耳記下 14:2"> 耶羅波安對他的妻子說：「你起身喬裝改扮，不要讓人認出你是耶羅波安的妻子，然後往示羅去。看哪，先知亞希雅在那裡，就是他從前對我說我將作這子民的王。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 9:7–8; 列王紀上 13:7; 列王紀下 4:42"> 你手裡帶十個餅、一些點心和一罐蜂蜜去見他，他會告訴你這孩子將會怎樣。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:29; 撒母耳記上 3:2; 撒母耳記上 4:15"> 耶羅波安的妻子就這樣做，她動身往示羅去，來到亞希雅的家。亞希雅因為年紀老邁，眼睛昏花不能看見。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 6:8–12; 箴言 21:30; 列王紀下 4:27"> 耶和華對亞希雅說：「看哪，耶羅波安的妻子要來問你有關她兒子的事，因為她兒子病了。你要如此如此回答她。她進來的時候，會掩飾自己。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="但以理書 5:17–28; 使徒行傳 5:9–10; 路加福音 20:20–23"> 王后來到門口，亞希雅聽見她的腳步聲，就說：「耶羅波安的妻子啊，進來吧。你何必這樣掩飾自己呢？我受派遣給你一個嚴酷的消息。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 16:2; 撒母耳記下 12:7–8; 撒母耳記上 15:16"> 你去告訴耶羅波安：『以色列的神耶和華如此說：我從子民中提拔了你，立你作我子民以色列的領袖，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 15:5; 列王紀上 11:33–38; 歷代志下 28:1"> 我把王國從大衛家撕去，賜給了你，可是你卻沒有像我僕人大衛那樣遵守我的誡命、全心跟從我，做我眼中看為正的事。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 23:35; 尼希米記 9:26; 詩篇 50:17"> 你反而行惡超過所有在你之前的人，去為自己製造別的神和鑄像惹怒我，把我拋在背後。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:36; 列王紀上 21:21; 列王紀下 14:26"> 所以看哪，我必使禍患臨到耶羅波安的家，<br /><span className="pl pl-1">凡是屬於耶羅波安的男丁</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="男丁——原文直譯「對著牆撒尿的」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">無論是為奴的還是自由的，我都要從以色列剪除。</span><br /><span className="pl pl-1">我要除盡耶羅波安家的後代，</span><br /><span className="pl pl-1">如同除盡糞土。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 16:4; 耶利米書 15:3; 列王紀上 21:23–24"> <span className="pl pl-1">屬於耶羅波安的人，</span><br /><span className="pl pl-1">死在城裡的將被狗吃掉，</span><br /><span className="pl pl-1">死在田野的將被天空的飛鳥吃掉。</span><br /><span className="pl pl-1">這是耶和華說的。』</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀上 14:3; 列王紀上 14:16–17; 列王紀下 1:6"> 「你起身回家去吧。你的腳踏進城的時候，你孩子必定死。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 19:3; 歷代志下 12:12; 約伯記 19:28"> 全以色列會為他哀哭，把他安葬。要知道，凡是屬於耶羅波安的人，唯獨他一人得以入墳墓，因為在耶羅波安家中，只有這孩子身上還能找到以色列的神耶和華看為美善的事。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 15:27–29; 以西結書 7:2–7; 以西結書 12:22–28"> 耶和華要為自己興起一個王來治理以色列，他必在當天剪除耶羅波安的家。什麼時候？現在就是了！</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 23:15–16; 詩篇 52:5; 列王紀下 15:29"> 耶和華要打擊以色列，使以色列如同水中搖蕩的蘆葦。他要把以色列人從耶和華賜給他們祖先的美地上拔出來，把他們驅散到大河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大河——指幼發拉底河。">b</a></sup>那邊去，因為他們製作亞舍拉柱惹怒了耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:34; 列王紀上 16:2; 列王紀上 13:34"> 因著耶羅波安所犯的罪，以及他使以色列所犯的罪，耶和華必撇棄以色列。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 15:33; 列王紀上 16:15; 列王紀上 16:23"> 於是耶羅波安的妻子起身離開，回到提爾撒；她一跨進家門檻，孩子就死了。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:13"> 人們安葬了他，全以色列為他哀哭，正如耶和華藉著他的僕人亞希雅先知所宣告的話。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 13:2–20; 歷代志上 27:24; 列王紀上 16:20"> 耶羅波安其餘的事蹟，他的爭戰、他的統治，看哪，都記在《以色列諸王年代志》上。</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 14:12; 詩篇 3:5; 列王紀上 11:43"> 耶羅波安統治的日子有二十二年，他與他的列祖長眠，他的兒子納達布接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 12:13; 列王紀上 11:36; 列王紀上 14:31"> 所羅門的兒子羅波安在猶大作王。他作王的時候四十一歲，在耶路撒冷統治了十七年，這城是耶和華從以色列眾支派所揀選要安置他名的地方。羅波安的母親名叫拿瑪，是亞捫人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歷代志下 12:1; 哥林多前書 10:22; 詩篇 78:58"> 猶大人做耶和華眼中看為惡的事，他們犯罪惹耶和華嫉憤，比他們祖先所做的一切還嚴重。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:2; 以賽亞書 57:5; 列王紀下 17:9–10"> 他們在各高丘上、各青翠樹下，為自己建立高壇、神柱和亞舍拉柱；</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 23:17; 哥林多前書 6:9; 列王紀上 15:12"> 國中甚至有男廟妓。他們效法耶和華在以色列子民面前趕出的那些民族的一切可憎行為。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:40; 歷代志下 12:2–4; 歷代志下 12:9"> 到了羅波安王第五年，埃及王示撒上來攻打耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 15:18; 歷代志下 9:15–16; 列王紀上 7:51"> 他奪走耶和華殿的寶物和王宮的寶物，全都奪走了，所羅門做的那些金盾牌也都奪走了。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 8:11; 撒母耳記上 22:17; 列王紀上 18:46"> 羅波安王就做了銅盾牌代替它們，交託在那些看守王宮大門的衛隊長手上。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 12:11"> 每當王進入耶和華的殿時，守衛們就拿出這些盾牌，之後再放回守衛室。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 22:45; 列王紀上 15:23; 列王紀上 14:19"> 羅波安其餘的事蹟和他所做的一切，不是都記在《猶大諸王年代志》上嗎？</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 12:24; 列王紀上 12:21; 列王紀上 15:6–7"> 羅波安和耶羅波安之間一直有爭戰。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 12:16; 馬太福音 1:7; 列王紀上 15:3"> 羅波安與他的列祖長眠，葬在大衛城，與他的列祖在一起。他的母親名叫拿瑪，是亞捫人。他的兒子亞比雅姆接替他作王。</span>
</div>
</div>

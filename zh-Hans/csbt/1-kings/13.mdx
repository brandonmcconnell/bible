<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1KI" data-book-slug="1-kings" data-book-name="列王紀上" data-chapter="13" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:32–33; 列王紀下 23:17; 帖撒羅尼迦前書 4:15"> 看哪，有一個神人奉耶和華的命令從猶大來到伯特利，那時耶羅波安正站在祭壇旁燒香。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 36:1; 列王紀下 23:15–18; 列王紀下 22:1–2"> 神人奉耶和華的命令對著祭壇呼喚，說：「祭壇哪，祭壇哪，耶和華如此說：看哪，大衛家將生一個兒子，名叫約西亞，他必把那些向你燒香的高壇祭司祭獻在你上面，也必有人的骸骨焚燒在你上面。」</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:22; 出埃及記 4:3–5; 士師記 6:17"> 當天，神人又給了一個預兆，說：「這是耶和華所宣告的預兆：看哪，這祭壇必破裂，祭壇上的灰燼必傾灑出來。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="啟示錄 11:5; 歷代志下 18:25–27; 路加福音 6:10"> 耶羅波安王一聽見神人對伯特利的祭壇所呼喊的話，就從祭壇上伸出手下令：「捉住他！」王伸出的手卻枯乾了，不能收回去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:3; 耶利米書 28:16–17; 申命記 18:22"> 祭壇破裂了，祭壇上的灰燼也傾灑出來，正如神人奉耶和華的命令所給的預兆。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 9:28; 使徒行傳 8:24; 出埃及記 10:17"> 於是王回應神人說：「請懇求你神耶和華的恩寵，為我禱告，使我的手可以收回。」神人懇求耶和華的恩寵，王的手就收回，像原先一樣了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:15; 撒母耳記上 9:7–8; 士師記 13:15"> 王對神人說：「請跟我一起回宮，你可以恢復精力，我也要送你一件禮物。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民數記 24:13; 民數記 22:18; 馬可福音 6:23"> 但神人對王說：「就算你把你宮殿的一半賜給我，我也不跟你一起回去，不在這地方吃飯喝水。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 13:17; 申命記 13:13–18; 羅馬書 16:17"> 因為有耶和華的話語如此吩咐我說：『你不可吃飯，不可喝水，也不可從你原路返回。』」</span>
<span className="v" id="v10" data-v="10"> 於是神人從另外一條路走了，沒有從他來伯特利的原路返回。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:18; 列王紀上 13:20–21; 民數記 24:2"> 有一個老先知住在伯特利，他的兒子們回來，把神人當天在伯特利所做的一切事都講述給他。神人對王所說的那些話，他們也給父親講述了。</span>
<span className="v" id="v12" data-v="12"> 父親問他們：「他從哪一條路回去的？」兒子們都看到了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="都看到了——有古抄本作「就指明了」。">a</a></sup>那位從猶大來的神人回去的路。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:4; 撒母耳記下 19:26; 士師記 5:10"> 父親就對兒子們說：「給驢子備好鞍。」他們為父親備好驢、上好鞍，他騎上去</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 4:12–13; 哥林多後書 11:27; 哥林多前書 4:11–12"> 追趕神人，發現他正坐在一棵橡樹底下，就問他：「你是從猶大來的神人嗎？」<br />他回答：「我是。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 老先知對神人說：「請跟我一起回家吃個飯吧。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 13:8–9; 馬太福音 16:23; 民數記 22:19"> 神人說：「我不能跟你一起回去，與你前往，也不能在這地方與你一起吃飯喝水。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:35; 帖撒羅尼迦前書 4:15; 列王紀上 13:1"> 因為有耶和華的話語吩咐我：『你不可在那裡吃飯，不可在那裡喝水，也不可從你原路回去。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 4:1; 馬太福音 7:15; 民數記 22:35"> 老先知對他說：「我與你一樣，也是先知。有一位天使奉耶和華的命令對我說：『你把他帶回家來，請他吃飯喝水。』」老先知是在哄騙他。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 13:1; 創世記 3:6; 使徒行傳 4:19"> 於是神人跟著老先知一起回去，在他家裡吃飯喝水。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:22; 民數記 24:4; 民數記 24:16–24"> 他們正坐席的時候，耶和華的話語臨到了那帶神人回來的先知。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 13:17; 撒母耳記上 13:13–14; 撒母耳記上 4:18"> 他就對那從猶大來的神人宣告說：「耶和華如此說：因為你違背了耶和華的話，不遵守你的神耶和華所吩咐你的命令，</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 14:18–20; 列王紀上 14:13; 耶利米書 22:18–19"> 反而回來，在耶和華吩咐你不可吃飯、不可喝水的地方吃飯喝水，因此你的屍體必不得葬入你祖先的墳墓。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 吃喝之後，老先知為那個請回來的先知備好驢、上好鞍，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:36; 列王紀下 2:24; 箴言 26:13"> 他就走了。在路上有一隻獅子遇見他，把他咬死了，屍體拋在路上，驢子站在屍體旁邊，獅子也站在屍體旁邊。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 13:11"> 看哪，人們路過，看見屍體拋在路上，獅子站在屍體旁邊，就去老先知所住的城裡報告這件事。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 9:6; 箴言 11:31; 詩篇 119:120"> 那將神人從路上請回來的老先知聽到了，就說：「這是那違背耶和華命令的神人。耶和華把他交給獅子，獅子撕裂他，把他咬死了，正如耶和華對他所宣告的話。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 於是他吩咐兒子們，說：「給驢子備好鞍。」他們就為父親備好驢，上好鞍。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 17:6; 詩篇 148:7–8; 但以理書 6:22–24"> 老先知前去，看見神人的屍體拋在路上，驢子和獅子站在屍體旁邊，獅子卻沒有吃那屍體，也沒有傷害那頭驢子。</span>
<span className="v" id="v29" data-v="29"> 老先知就抬起神人的屍體，馱在驢子上帶回去。老先知回到城裡，為他哀哭，把他安葬了。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 22:18; 使徒行傳 8:2; 列王紀上 14:13"> 他把神人的屍體安放在自己的墳墓裡，人們為他哀悼說：「唉，我的兄弟啊！」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:17–18; 民數記 23:10; 路加福音 16:22–23"> 老先知把他安葬之後，吩咐兒子們說：「當我死了，你們要把我葬在神人被安葬的墳墓裡，要把我的骸骨放在他的骸骨旁邊。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 16:24; 列王紀上 13:2; 列王紀上 12:31"> 他奉耶和華的命令，針對伯特利的祭壇和撒瑪利亞各城的一切高壇廟宇所宣告的話，必定成就。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歷代志下 11:15; 歷代志下 13:9; 民數記 17:12–13"> 這事以後，耶羅波安不但不轉離他邪惡的道路，反而繼續設立各類的人為高壇的祭司。凡是願意的，他就讓那人承接神職，成為高壇的祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 14:10; 列王紀上 15:29–30; 列王紀上 12:30"> 這事成了耶羅波安家的罪孽，以致他的家從地面上被剪除滅盡。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 7:11–6; 列王紀上 9:19; 列王紀上 7:51"> 所羅門建完了耶和華的殿和王宮，以及所羅門想要建造的一切，之後</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 3:5; 歷代志下 7:12; 列王紀上 11:9"> 耶和華第二次向所羅門顯現，就像從前在基遍向他顯現那樣。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 10:17; 約翰一書 5:14; 列王紀下 20:5"> 耶和華對他說：<br />「我已經垂聽你在我面前所做的禱告和懇求，把你建造的這殿宇分別為聖了，好使我的名永遠安置在那裡，我的眼、我的心也必終日在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 15:5; 列王紀上 3:14; 列王紀上 11:6"> 至於你，如果你像你父親大衛所行的那樣，以正直、純全的心行走在我面前，遵行我所吩咐你的一切，謹守我的律例和法規，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 2:4; 列王紀上 6:12; 撒母耳記下 7:16"> 我就堅立你的王位，使你永遠統治以色列，正如我向你父親大衛所應許說的：『你的子孫中，就不會斷絕人坐以色列的王位。』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 7:14–16; 歷代志上 28:9; 歷代志下 15:2"> 但如果你們和你們的子孫執意轉離不跟從我，不遵守我在你們面前賜下的誡命和律例，去服事別的神，向它們下拜，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:14; 耶利米書 24:9; 申命記 4:26"> 我就把以色列人從我所賜給他們的這地面上剪除，並且把我為我名所分別為聖的這殿宇從我面前丟棄，以色列將在萬民中成為笑柄，被人諷刺。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:24–26; 耶利米書 22:8–9; 歷代志下 7:21"> 這曾經至高的殿宇，將使每一個經過它的人都震驚並嗤笑。他們說：『耶和華為什麼這樣對待這地和這殿宇呢？』</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 2:19; 耶利米書 5:19; 申命記 29:25–28"> 人們會回答：『因為以色列人離棄了耶和華他們的神，就是把他們祖先從埃及地領出來的那一位，去依附別的神，向它們下拜，服事它們，所以耶和華使這一切禍患臨到了他們。』」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:37–1; 歷代志下 8:1–18; 列王紀上 9:1"> 所羅門用二十年時間建造了耶和華的殿和王宮這兩座殿宇之後，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 8:2; 歷代志下 2:16; 歷代志下 2:8–10"> 由於提爾王希蘭照著所羅門想要的一切，提供了香柏木、松木和金子，所羅門王就把加利利地區的二十座城邑送給了希蘭。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:34; 士師記 14:3"> 希蘭從提爾出來察看所羅門送給他的城邑，但在他眼裡，那些城不好。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 19:27; 阿摩司書 1:9; 列王紀上 5:1–2"> 他說：「我的兄弟啊，你送給我的是什麼城呢？」於是他給這些城邑起名為「卡布勒之地」，直到今日。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 9:11; 列王紀上 10:10; 列王紀上 9:28"> 希蘭給所羅門王送去了一百二十他連得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百二十他連得——相當於4.1公噸。1他連得=34.2公斤。">a</a></sup>金子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 17:11; 列王紀上 9:24; 撒母耳記下 5:9"> 以下是服苦役之人的記載。所羅門王徵調他們去建造耶和華的殿、他自己的宮殿、梯壘、耶路撒冷的城牆、哈佐、米吉多、基色；</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 3:1; 列王紀上 9:24; 列王紀上 7:8"> 先前埃及王法老上來攻取了基色，又放火燒毀這城，殺了住在城內的迦南人，把城邑作為陪嫁賜給他的女兒——所羅門的妻子。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 16:3; 約書亞記 21:22; 歷代志下 8:4–18"> 所羅門建造了基色、下伯賀崙、</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 19:44; 歷代志下 8:4"> 巴阿拉特、猶大地曠野中的塔德莫，</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 9:1; 傳道書 6:9; 出埃及記 1:11"> 還建造所有屬於所羅門的積貨城，屯車城，馬兵城，以及所羅門想要在耶路撒冷、黎巴嫩和他統治的全地內建造的一切。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 23:23; 創世記 15:19–21; 申命記 7:1–3"> 亞摩利人、赫提人、比利洗人、希未人、耶布斯人中所有存留下來的民眾，不屬於以色列人，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 17:12; 士師記 1:21; 約書亞記 15:63"> 他們是那些外邦人在這地存留下來的後代子孫，以色列人沒有滅絕他們；所羅門徵調這些人服苦役，直到今日。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 25:39; 列王紀上 4:1–27; 撒母耳記上 8:11–12"> 至於以色列人，所羅門沒有使他們作奴僕，他們是他的戰士、臣僕、將領、軍官、戰車長和馬兵長。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 5:16; 歷代志下 8:10; 歷代志下 2:18"> 這些人有五百五十人作所羅門工程的監工，監管做工的人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 7:8; 撒母耳記下 5:9; 歷代志下 32:5"> 在法老的女兒從大衛城遷到所羅門為她建造的宮殿之後，所羅門才修築了梯壘。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歷代志下 8:12–13; 歷代志下 8:16; 出埃及記 23:14–17"> 所羅門每年三次在他為耶和華所築的祭壇上獻燔祭和平安祭，又在耶和華面前的壇上燒香。這樣，他完成了聖殿的工作。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 22:48; 民數記 33:35; 申命記 2:8"> 所羅門王又在以旬迦別，就是在以東地紅海沿岸的埃拉特附近建造船隊。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 10:11; 列王紀上 5:6; 列王紀上 5:9"> 希蘭派他的臣僕和熟悉航海的船員，與所羅門的臣僕一起組成船隊。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 8:18; 歷代志上 29:4; 列王紀上 10:11"> 他們出航到俄斐，從那裡運回來四百二十他連得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四百二十他連得——相當於14.4公噸。1他連得=34.2公斤。">b</a></sup>黃金，帶到所羅門王那裡。</span>
</div>
</div>

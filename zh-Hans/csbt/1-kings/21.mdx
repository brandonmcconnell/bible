<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="1KI" data-book-slug="1-kings" data-book-name="列王紀上" data-chapter="21" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:33; 歷代志下 28:22; 約書亞記 19:18"> 這些事以後，又發生了一件事。耶斯列人拿伯有一個葡萄園，位於耶斯列，靠近撒瑪利亞王亞哈的宮殿。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 8:14; 雅各書 1:14–15; 提摩太前書 6:9"> 亞哈告訴拿伯說：「請把你的葡萄園給我，作我的菜園，因為它靠近我的宮殿。我可以給你一個更好的葡萄園作交換，或者如果你眼中看為好，我也可以按葡萄園的售價付給你銀子。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民數記 36:7; 利未記 25:23; 以西結書 46:18"> 拿伯對亞哈說：「耶和華絕不允許我把祖先的繼業讓給你。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 20:43; 雅各書 1:14; 約拿書 4:9"> 亞哈因為耶斯列人拿伯回覆他說「我不能把祖先的繼業讓給你」，就悶悶不樂地回到王宮，躺在床上，轉過臉去，也不吃飯。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 16:31; 創世記 3:6; 列王紀上 19:2"> 王后耶洗別來見他，問他說：「你為什麼心裡這樣憂悶，甚至不吃飯呢？」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 5:9–14; 雅各書 4:2–7; 提摩太前書 6:9–10"> 亞哈回答：「因為我與耶斯列人拿伯商量，對他說：『把你的葡萄園按銀價賣給我吧，或者如果你願意，我可以給你另一個葡萄園作交換』；他卻說：『我不能把我的葡萄園讓給你。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 8:14; 彌迦書 7:3; 撒母耳記下 13:4"> 王后耶洗別對他說：「你不是現在執掌著以色列的王權嗎？起來吃飯，開心點吧。我來為你拿到耶斯列人拿伯的葡萄園。」</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 6:5; 列王紀下 10:11; 以斯拉記 4:7–8"> 於是王后用亞哈的名義寫信，蓋上王的印章，然後送達那些與拿伯同城居住的長老和貴族。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 58:4; 馬太福音 23:13; 路加福音 20:47"> 她在書信裡寫著說：<br />「你們要宣告禁食，讓拿伯坐在民眾的首席上；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 22:28; 使徒行傳 6:11; 利未記 24:15–16"> 安排兩個卑劣之徒坐在他對面，作見證控告他說：『你詛咒了神和王』。然後你們把他拉出去，用石頭砸死。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 4:19; 利未記 19:15; 列王紀下 10:6–7"> 於是城裡的人——那些與拿伯同城居住的長老和貴族，就照著耶洗別吩咐他們的去做，照著送來的書信中所寫的，</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 58:4; 列王紀上 21:8–10"> 宣告禁食，讓拿伯坐在民眾的首席上。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 9:26; 申命記 22:24; 傳道書 10:20"> 接著來了兩個人，是卑劣之徒，坐在拿伯對面。兩個卑劣之徒當著民眾的面作見證控告拿伯說：「拿伯詛咒了神和王。」人們就把拿伯拉出城外，用石頭把他砸死了。</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 8:14; 撒母耳記下 11:14–24; 傳道書 5:8"> 隨後，他們派人去告訴耶洗別：「拿伯已經被石頭砸死了。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王紀上 21:7"> 當耶洗別聽說拿伯被石頭砸死了，她就對亞哈說：「起來去獲得耶斯列人拿伯不肯出價賣給你的葡萄園吧，因為拿伯不在了，已經死了。」</span>
<span className="v" id="v16" data-v="16" data-xref="俄巴底亞書 1:12–14; 羅馬書 1:32; 撒母耳記下 11:25–27"> 亞哈一聽說拿伯死了，就起來下到耶斯列人拿伯的葡萄園，去占有這園子。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:12; 以賽亞書 26:21; 列王紀下 5:26"> 於是，耶和華的話語臨到提斯比人以利亞，說：</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:32; 歷代志下 22:9"> 「你起來，下去迎見以色列王亞哈，他在撒瑪利亞，看哪，就在拿伯的葡萄園裡，他下去要占有那地方。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:38; 撒母耳記下 12:9; 哈巴谷書 2:9"> 你要對亞哈說：『耶和華如此說：你既殺人又占有搶奪嗎？』要對他說：『耶和華如此說：狗在什麼地方舔拿伯的血，也必在那地方舔你的血；是的，就是你！』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 17:17; 羅馬書 7:14; 列王紀上 21:25"> 亞哈對以利亞說：「我的仇敵啊，你竟然找到了我！」<br />以利亞回答：「找到了！因為你賣掉了自己，去做耶和華眼中看為惡的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:10; 撒母耳記上 25:34; 列王紀下 10:1–7"> 耶和華說<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和華說——輔助詞語。">a</a></sup>：<br /><span className="pl pl-1">『看哪，我必使禍患臨到你，除滅你的後代。</span><br /><span className="pl pl-1">以色列中凡屬亞哈的男丁</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="男丁——原文直譯「對著牆撒尿的」。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">無論是為奴的還是自由的，</span><br /><span className="pl pl-1">我都必剪除。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 16:3; 列王紀上 14:16; 列王紀上 16:11"> <span className="pl pl-1">我要使你的家像尼八之子耶羅波安的家，</span><br /><span className="pl pl-1">又像亞希雅的兒子巴沙的家那樣，</span><br /><span className="pl pl-1">因為你惹怒我，並且使以色列犯罪。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="列王紀下 9:10; 列王紀下 9:30–37; 列王紀上 21:25"> 耶和華還論到耶洗別說：<br /><span className="pl pl-1">『狗必在耶斯列地界內</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="地界內——依據一些古抄本；參《列王紀下》9:10,36；馬索拉文本作「城垣邊」。">c</a></sup><br /><span className="pl pl-1">吃掉耶洗別。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 16:4; 列王紀上 14:11; 耶利米書 15:3"> <span className="pl pl-1">屬於亞哈的人，</span><br /><span className="pl pl-1">死在城裡的將被狗吃掉，</span><br /><span className="pl pl-1">死在田野的將被天空的飛鳥吃掉。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王紀上 21:20; 列王紀上 16:30–33"> 實在是沒有像亞哈這樣的，賣掉自己，受他妻子耶洗別的慫恿，去做耶和華眼中看為惡的事。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:11; 創世記 15:16; 利未記 18:25–30"> 他效法從前在以色列子民面前被耶和華趕出的亞摩利人所做的一切，做極為可憎的事，去追隨偶像。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王紀下 6:30; 創世記 37:34; 撒母耳記下 3:31"> 亞哈聽了這些話，就撕裂衣服，貼身穿著麻衣，禁食，睡臥在麻布上，行走時也很消沉。</span>
<span className="v" id="v28" data-v="28"> 於是，耶和華的話語臨到提斯比人以利亞，說：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 3:9; 彌迦書 7:18; 詩篇 86:15"> 「你看見了嗎，亞哈在我面前謙卑下來了。既然他在我面前謙卑下來，我必不在他的日子裡使這禍患臨到他；不過他兒子在世的日子，我要使這禍患臨到他的家。」</span>
</div>
</div>

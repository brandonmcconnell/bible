<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各書 5:17; 申命記 28:12"> 許多日子過去，到了第三年，耶和華的話語臨到以利亞，說：「去讓亞哈見到你，我將要在這地上賜下雨水。」</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 6:25; 箴言 28:1; 利未記 26:26"> 以利亞就去，要與亞哈見面。<br />那時撒瑪利亞的饑荒很嚴重。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 7:2; 列王紀上 16:9; 馬太福音 10:28"> 亞哈召來宮廷總管俄巴底亞，俄巴底亞非常敬畏耶和華，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 18:13; 馬太福音 10:40–42; 啟示錄 17:4–6"> 當耶洗別除滅耶和華的眾先知時，俄巴底亞曾收留一百個先知，把他們藏起來，每五十人一個山洞，供應他們餅和水。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 14:5–6; 約珥書 1:18; 約珥書 2:22"> 亞哈吩咐俄巴底亞：「你去走遍這地所有的水泉、所有的溪流，或許我們能找到一些青草，使馬和騾子得以存活，不至於使牲畜斷絕。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 14:3"> 於是他們劃分地區巡行，亞哈獨自往一個方向去，俄巴底亞獨自往另一個方向去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 1:6–8; 創世記 44:20; 以賽亞書 60:14"> 俄巴底亞正在路上，看哪，以利亞向他迎面過來了。俄巴底亞認出以利亞，就臉伏於地，說：「你是我主以利亞嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:7; 列王紀上 18:3; 彼得前書 2:17–18"> 以利亞回答：「是我。去告訴你的主人，以利亞在這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:21; 列王紀上 18:12; 列王紀上 17:18"> 俄巴底亞說：「我犯了什麼罪，你竟要把僕人交在亞哈手中處死？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 17:1; 列王紀上 1:29; 列王紀上 18:15"> 我指著你的神耶和華的永生起誓：沒有一邦一國我主不派人去尋找你的。如果他們說你不在，他就要求那邦那國起誓說真找不到你。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 18:8; 列王紀上 18:14"> 「現在你竟然說：『去告訴你的主人，以利亞在這裡。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 2:16; 使徒行傳 8:39; 以西結書 8:3"> 我一旦離開你，耶和華的靈就會把你帶到我所不知道的地方去，這樣如果我去告訴亞哈，他卻找不到你，就必殺我。其實你僕人從年幼時就敬畏耶和華！</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 18:4; 馬太福音 25:35; 詩篇 18:21–24"> 難道沒有人把我所做的事告訴我主嗎？耶洗別殺戮耶和華眾先知的時候，我把耶和華的一百個先知藏了起來，每五十人一個山洞，供應他們餅和水。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:28"> 現在你竟然說：『去告訴你的主人，以利亞在這裡。』他一定會殺我的。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 17:1; 列王紀上 18:10; 路加福音 2:13–14"> 以利亞說：「我指著我所事奉的萬軍之耶和華的永生起誓：今天我必讓亞哈見到我。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 於是俄巴底亞去與亞哈會合，把這件事稟告王。亞哈就去迎見以利亞。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 7:25; 列王紀上 21:20; 使徒行傳 16:20"> 亞哈一看見以利亞，就對他說：「是你嗎？你這給以色列帶來禍患的人！」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 15:2; 列王紀上 9:9; 耶利米書 2:19"> 以利亞說：「給以色列帶來禍患的人不是我，而是你和你父家，因為你們離棄耶和華的誡命，去追隨巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 19:26; 列王紀上 16:33; 彼得後書 2:1"> 現在，你派人去招聚全體以色列人，以及那四百五十個巴力的先知，還有與耶洗別同席吃飯的四百個亞舍拉先知，都到迦密山見我。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:9"> 亞哈就派人到以色列眾人那裡，把那些先知都招聚到迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:24; 約書亞記 24:15; 哥林多前書 10:21–22"> 以利亞走近全體民眾，說：「你們心懷二意搖擺不定<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="心懷二意搖擺不定——原文直譯「兩條拐杖上瘸著走」。">a</a></sup>，要到什麼時候呢？如果耶和華是神，就當跟從耶和華；如果巴力是神，就當跟從巴力。」民眾一句話也不回答。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王紀上 19:10; 列王紀上 19:14; 提摩太後書 4:3–4"> 以利亞對民眾說：「耶和華的先知唯獨剩下我一個，巴力的先知卻有四百五十人。</span>
<span className="v" id="v23" data-v="23"> 請給我們提供兩頭公牛，讓巴力的先知自己挑選一頭，切成塊，放在木柴上，但不要點火；我會把另一頭公牛也預備好，放在木柴上，不點火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 18:38; 歷代志上 21:26; 歷代志下 7:1"> 然後你們呼求你們神的名，我也呼求耶和華的名；那用烈火回應的神，他才是神。」<br />全體民眾回答：「這提議很好。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 以利亞對巴力的眾先知說：「你們既然人多，請你們先來吧，為自己挑選一頭公牛，預備好，然後呼求你們神的名，但不要點火。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米書 10:5; 哥林多前書 8:4; 馬太福音 6:7"> 他們就把提供給他們的公牛取來獻上，從清晨到正午呼求巴力的名，說：「巴力啊，求你回應我們！」可是沒有動靜，沒有回應。他們在修築的祭壇周圍搖擺蹦跳。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="詩篇 78:65–66; 以賽亞書 41:23; 傳道書 11:9"> 到了中午，以利亞嘲弄他們說：「他既然是神，你們大聲呼求吧！他一定是在默想，或者他正忙著，或者他在旅行，或者他在沉睡，需要叫醒。」</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 19:28; 申命記 14:1; 馬可福音 5:5"> 於是他們大聲呼求，照著他們的習俗用刀用矛刺傷自己，以致滿身流血。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:26; 撒母耳記上 18:10; 出埃及記 29:39"> 過了中午，他們繼續說神言，直到下午獻祭的時間；但還是沒有動靜，沒有回應，沒有反應。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="歷代志下 33:16; 列王紀上 19:14; 列王紀上 19:10"> 於是，以利亞對全體民眾說：「到我這裡來吧。」全體民眾近前來，他就修復那被拆毀的耶和華的祭壇。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:34; 創世記 35:10; 創世記 32:28"> 以利亞按照雅各子孫的支派數目取了十二塊石頭——耶和華的話語曾臨到雅各說「你的名字要叫以色列」——</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 3:17; 出埃及記 20:24–25; 士師記 21:4"> 以利亞用這些石頭以耶和華的名築了一座祭壇，又在祭壇四圍挖了一條可容下二斗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二斗——原文作「二細亞」；相當於14公升。1細亞=7.3公升。">b</a></sup>穀物的溝渠。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 22:9; 士師記 6:20; 利未記 1:6–8"> 他擺好木柴，把公牛切成塊，放在木柴上，然後吩咐說：「裝滿四桶水，倒在燔祭和木柴上。」</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多後書 8:21; 哥林多後書 4:2"> 他又說：「再倒一次。」他們就再倒了一次。他又說：「倒第三次。」他們就倒了第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 18:32; 列王紀上 18:38"> 水向祭壇的四圍流下來，連溝渠裡也滿了水。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="列王紀上 18:29; 列王紀下 19:19; 出埃及記 3:6"> 到了下午獻祭的時間，先知以利亞上前來禱告：「亞伯拉罕、以撒、以色列的神耶和華啊，求你今天顯明：你是以色列的神，我是你的僕人，並且是遵照你的話語做了這一切事。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理書 9:17–19; 路加福音 1:16–17; 以西結書 36:25–27"> 應允我，耶和華啊，應允我！讓這子民知道：你耶和華才是神，你使他們的心回轉。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志上 21:26; 利未記 9:24; 歷代志下 7:1"> 於是耶和華的火降下來，把燔祭、木柴、石頭、塵土都吞噬了，連溝渠裡的水也吞沒了。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:24; 歷代志下 7:3; 列王紀上 18:21"> 全體民眾看見了，就臉伏於地，說：「耶和華是神！耶和華是神！」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 18:20; 士師記 4:7; 申命記 13:5"> 以利亞吩咐他們：「把巴力的先知都抓起來，不讓一個逃脫！」人們就抓住那些先知。以利亞把他們帶到基順河邊，在那裡都殺了。</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 18:1; 傳道書 9:7; 列王紀上 17:1"> 以利亞對亞哈說：「你上去吃喝吧，已經有了大雨的嘈雜聲。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理書 9:7; 約書亞記 7:6"> 亞哈就上去吃喝，以利亞卻上到迦密山頂，屈身在地，臉伏在雙膝間。</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷書 2:3; 路加福音 18:7; 路加福音 18:1"> 他對僕人說：「你上去朝著大海觀看。」<br />僕人上去觀看了，然後說：「什麼也沒有。」<br />以利亞說：「再去。」這樣有七次。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 約伯記 8:7; 撒迦利亞書 4:10"> 到了第七次，僕人說：「看哪，有一片像手掌那麼小的烏雲從海面升起來。」<br />以利亞說：「你上去告訴亞哈：備好車下去吧，免得被大雨困住。」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王紀上 18:39–40; 約書亞記 17:16; 列王紀上 21:1"> 剎那間，天空風雲變色，下起了大雨。亞哈乘車前往耶斯列去；</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 3:14; 以西結書 1:3; 列王紀下 9:1"> 耶和華的手<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="手——或譯作「大能」。">c</a></sup>落在以利亞身上，他就束上腰，跑在亞哈的前面，直到耶斯列的城門口。</span>
</div>
</div>

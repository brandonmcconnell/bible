<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 25:7; 路得記 3:12; 申命記 16:18"> 波阿斯來到城門口，在那裡坐下。看哪！波阿斯所說的那個有贖回權的近親正經過那裡；波阿斯就說：「某某人哪，請過來，坐在這裡吧！」那個人就過來坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 31:23; 列王紀上 21:8; 使徒行傳 6:12"> 波阿斯又從城裡的長老中請來十個人，說：「請你們坐在這裡。」他們就都坐下。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:10; 詩篇 112:5"> 然後他對那個有贖回權的近親說：「從摩押地回來的娜娥米，要把我們兄弟以利米勒的那塊田賣了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 25:25–29; 耶利米書 32:7–12; 羅馬書 12:17"> 我想我應該讓你知道這事，並建議你當著在座各位的面，當著我族人的長老們的面，買下那塊田。如果你要贖取就贖取吧！但如果你不贖取，請告訴我，我好知道；因為除你以外沒有人可以先贖取，而我是在你之後的。」那人說：「我要贖取！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 38:8; 申命記 25:5–6; 馬太福音 22:24"> 接著波阿斯說：「你從娜娥米的手中買下這塊田的那天，你也要得到那死者的妻子摩押女子路得，好使那死者在繼業上立名。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 25:25; 路得記 3:13"> 那個有贖回權的近親就說：「那我就不能贖取那塊田了，免得毀掉了我自己的繼業。你贖取那塊田吧！你可以擁有我的贖回權，因為我不能贖取了。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 25:7–10"> 從前在以色列中，確立任何有關贖回權或有關替換權的事，就要這樣做：一方要脫下鞋子交給另一方。這是以色列中作見證的方式。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 那個有贖回權的近親對波阿斯說：「你買下那塊田吧！」於是他就脫下了鞋子。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 32:10–12; 創世記 23:16–18"> 接著波阿斯對長老們和全體民眾說：「今天你們都是見證人：所有屬於以利米勒的、所有屬於基連和瑪倫的，我都從娜娥米的手中買下了；</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 25:6; 以弗所書 5:25; 創世記 29:27"> 此外我也得到瑪倫的妻子摩押女子路得作我的妻子，好使那死者在繼業上立名，以免那死者的名從他的兄弟中、從本地的城門口斷絕。今天你們都是見證人。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 29:32–24; 彌迦書 5:2; 馬太福音 2:6"> 在城門口的全體民眾和長老們都說：「我們都是見證人！願耶和華使進到你家的這女子像建立以色列家的拉結和莉亞兩人那樣！願你在以法他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以法他——就是伯利恆。">a</a></sup>做大能的事，在伯利恆得名聲！</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 38:29; 撒母耳記上 2:20; 歷代志上 2:4"> 願耶和華從這年輕女子賜你後裔，使你的家像塔瑪爾給猶大所生的法勒斯的家那樣！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 33:5; 創世記 29:31; 路得記 3:11"> 於是波阿斯娶了路得，路得就成為他的妻子；波阿斯與她同房，耶和華使她懷胎，她就生了一個兒子。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 1:5–20; 路加福音 1:58; 創世記 12:2"> 婦女們對娜娥米說：「耶和華是當受頌讚的！因為他今天沒有使你缺失有贖回權的近親。願這孩子在以色列得名聲！</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 55:22; 以賽亞書 46:4; 創世記 45:11"> 他必使你的靈魂甦醒，在你年老時供養你，因為他是愛你的兒媳所生的；對你來說，有她比有七個兒子更好。」</span>
<span className="v" id="v16" data-v="16"> 娜娥米把那孩子接過來，抱在懷中，撫養他。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:58–63"> 鄰居的婦女們給孩子起名，說：「有一個兒子為娜娥米而生！」她們就給他起名為俄備得。俄備得是耶西的父親，耶西是大衛的父親。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 1:3–6; 歷代志上 2:4–8; 路加福音 3:33"> 以下是法勒斯的譜系：<br /><span className="pl pl-1">法勒斯生希斯倫，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:33; 歷代志上 2:9–10; 馬太福音 1:4"> <span className="pl pl-1">希斯倫生蘭，</span><br /><span className="pl pl-1">蘭生亞米拿達，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:7; 路加福音 3:32; 馬太福音 1:4"> <span className="pl pl-1">亞米拿達生拿順，</span><br /><span className="pl pl-1">拿順生撒門，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:32; 馬太福音 1:5; 歷代志上 2:11–12"> <span className="pl pl-1">撒門生波阿斯，</span><br /><span className="pl pl-1">波阿斯生俄備得，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 2:15; 以賽亞書 11:1; 馬太福音 1:6"> <span className="pl pl-1">俄備得生耶西，</span><br /><span className="pl pl-1">耶西生大衛。</span></span>
</div>

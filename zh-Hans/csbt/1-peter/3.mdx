<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:18; 以弗所書 5:33; 以弗所書 5:22–24"> 同樣，你們做妻子的，要服從自己的丈夫。這樣，即使有不肯信從這話語的丈夫，他們也會被感化<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="被感化——原文直譯「被贏得」。">a</a></sup>過來，不是因著妻子的話語，而是因著妻子的品行，</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 2:12; 彼得前書 1:15; 腓立比書 1:27"> 因為看見了你們懷有敬畏之心的貞潔品行。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 2:9–10; 羅馬書 12:2; 以賽亞書 3:18–24"> 你們的美麗之處不應該是外在的，如編頭髮、戴金飾、穿華服，</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:12; 撒母耳記上 16:7; 羅馬書 2:29"> 而應該是心裡面內在的人，帶著不朽壞的品性<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="品性——輔助詞語。">b</a></sup>，出於謙和、安靜的靈；這在神面前是極其貴重的。</span>
<span className="v" id="v5" data-v="5" data-xref="提多書 2:3–4; 提摩太前書 5:5; 路加福音 2:37"> 實際上，從前盼望神的那些聖潔婦女，也是這樣裝飾自己，服從自己丈夫的；</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:12; 羅馬書 9:7–9; 以賽亞書 57:11"> 就像撒拉順從亞伯拉罕，稱他為主那樣；當你們行善而不怕任何驚擾的時候，就成為撒拉的兒女了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 3:19; 創世記 2:23–24; 馬太福音 19:3–9"> 同樣，你們做丈夫的，要按情理與妻子同住，將女性當做比較軟弱的器皿而尊重她們，也當做是生命之恩的共同繼承人。這樣，你們的禱告就不會受攔阻。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 12:10; 以弗所書 4:31–2; 彼得前書 1:22"> 總而言之，你們大家都要心思一致，互相同情，相愛如弟兄，心存憐憫，滿有謙卑<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="滿有謙卑——有古抄本作「待人友善」。">c</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; 羅馬書 12:17; 羅馬書 12:14"> 不要以惡報惡，以辱罵還辱罵，反要祝福，因為<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附「你們知道」。">d</a></sup>你們是為此蒙召的，好使你們繼承祝福。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:12–16; 雅各書 1:26; 彼得前書 2:1"> <span className="pl pl-1">要知道，「那願意愛惜生命、</span><br /><span className="pl pl-1">願意見到好日子的人，</span><br /><span className="pl pl-1">要停止舌頭出惡言，</span><br /><span className="pl pl-1">不讓嘴唇說詭詐的話；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:9; 詩篇 34:14; 希伯來書 12:14"> <span className="pl pl-1">要遠離邪惡，要行美善，</span><br /><span className="pl pl-1">要尋求和睦，要竭力追求；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 34:15–16; 約翰福音 9:31; 箴言 15:29"> <span className="pl pl-1">因為主的眼睛看顧義人，</span><br /><span className="pl pl-1">主的耳朵垂聽他們的祈禱；</span><br /><span className="pl pl-1">但主的臉卻敵對作惡的人。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; 羅馬書 8:28; 帖撒羅尼迦前書 5:15"> 如果你們是為美善而熱心<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="為美善而熱心——有古抄本作「效法美善」。">e</a></sup>的人，誰會傷害你們呢？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:28; 彼得前書 2:19–20; 馬太福音 5:10–12"> 然而，即使你們為義受苦，也是蒙福的。不要怕他們所懼怕的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他們所懼怕的——或譯作「他們的恐嚇」。">f</a></sup>，也不要驚慌不安，</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 4:6; 提摩太後書 2:25–26; 路加福音 21:14–15"> 只要你們心裡尊主基督<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="基督——有古抄本作「——神」。">g</a></sup>為聖，無論誰要你們對你們裡面的盼望做個交代，你們都要隨時預備好答覆他；</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 2:12; 希伯來書 13:18; 彼得前書 2:15"> 不過要以溫柔、敬畏的心答覆，並且持守無愧的良心，以致誰詆毀你們在基督裡的良好品行，誰就要在你們受到誹謗的事上蒙羞。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 3:14; 彼得前書 4:19; 馬太福音 26:39"> 要知道，即使神的旨意要你們因行善而受苦，也比因作惡而受苦更好，</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 9:28; 希伯來書 9:26; 哥林多後書 5:21"> <span className="pl pl-1">因為基督也曾一次為了贖罪而受苦</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="為了贖罪而受苦——有古抄本作「為了贖我們的罪而死」或「為我們的罪孽死了」或「為你們的罪孽死了」。">h</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">就是義的代替不義的，</span><br /><span className="pl pl-1">為要把你們</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="你們——有古抄本作「我們」。">i</a></sup><br /><span className="pl pl-1">帶到神的面前。</span><br /><span className="pl pl-1">照著肉身說，基督固然被處死了；</span><br /><span className="pl pl-1">但照著靈說，他卻得以復活了。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前書 4:6; 以賽亞書 61:1; 以賽亞書 42:7"> 藉著靈，他也曾去傳道給那些被監禁的靈魂，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 11:7; 彼得後書 2:5; 創世記 6:3"> 就是從前在挪亞建造方舟的那些日子裡，在神耐心等待的時候那些不肯信從的靈魂。當時進入方舟，藉著水獲救的人很少，只有八個人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="人——原文直譯「靈魂」。">j</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 16:16; 以西結書 36:25–26; 使徒行傳 2:38"> 這水所象徵的洗禮，如今也藉著耶穌基督的復活拯救你們<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你們——有古抄本作「我們」。">k</a></sup>，不是清除肉體的汙穢，而是向神懇求<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="懇求——或譯作「宣誓」。">l</a></sup>無愧的良心。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 9:24; 希伯來書 12:2; 希伯來書 10:12"> 耶穌基督已經升天，就在神的右邊，天使們、掌權的、有勢力的，都服從了他。</span>
</div>
</div>

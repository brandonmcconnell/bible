<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各書 1:1; 使徒行傳 2:5–11; 希伯來書 11:13"> 耶穌基督的使徒彼得，<br />致那些蒙揀選，分散在本都、加拉太、卡帕多細亞、亞細亞、比提尼亞寄居的人，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦後書 2:13; 以弗所書 1:4–5; 希伯來書 12:24"> 就是按照父神的預知，藉著聖靈分別為聖，以致順從耶穌基督，又蒙他寶血所灑的人：<br />願恩典與平安多多地加給你們！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 1:23; 約翰一書 5:4; 羅馬書 15:13"> 願頌讚歸於神——我們主耶穌基督的父！他照著自己極大的憐憫，藉著耶穌基督從死人中的復活，使我們重生，得著永生的盼望，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 21:27; 希伯來書 9:15; 彼得前書 5:4"> 得著不會朽壞、不會玷汙、不會衰殘、保存<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保存——原文直譯「為你們保存」。">a</a></sup>在天上的繼業；</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 1:6; 以弗所書 2:8; 帖撒羅尼迦後書 2:13–14"> 你們藉著信，在神的大能中蒙保守，以至於那預備好要在末世顯現的救恩。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:2; 彼得前書 5:10; 羅馬書 12:12"> 為此，你們歡欣跳躍，但如今必須在種種試煉中暫時憂傷，</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 23:10; 以賽亞書 48:10; 彼得前書 4:12"> 好讓你們的信仰經過考驗，就比那被火煉過仍然會朽壞的金子更加寶貴，能在耶穌基督顯現的時候，被看為是可以得著稱讚、榮耀和尊貴的。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 20:29; 哥林多後書 5:7; 羅馬書 15:13"> 你們雖然沒有見過他，卻愛他；雖然如今看不到他，卻信他，並且懷著無法描述、充滿榮耀的喜樂而歡欣跳躍，</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 6:22; 雅各書 1:21; 希伯來書 11:13"> 因為你們正在領受你們信仰的結果，就是靈魂的救恩。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 關於這救恩，那些預言你們要得著這恩典的先知，曾經尋求過，詳細查考過。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 52:13–14; 彼得後書 1:21; 路加福音 24:25–27"> 他們查考了自己裡面基督之靈，當他預言有關基督的苦難和此後的榮耀時，究竟指明的是什麼時候、或什麼樣的情況。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 15:26; 哥林多前書 2:10; 以弗所書 3:10"> 他們蒙了啟示，知道所服事的這一切，不是為自己，而是為你們。如今，這些事藉著從天上派來的聖靈，通過那些向你們傳福音的人，傳講給了你們；對於這些事，天使們也渴望能詳細察看。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前書 5:8; 路加福音 12:35; 彼得前書 4:7"> 因此，你們要約束自己的意念<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="約束自己的意念——原文直譯「束上自己意念的腰帶」。">b</a></sup>，要謹慎，要把盼望完全寄託在耶穌基督顯現時帶給你們的恩典上。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 12:2; 提多書 3:3–5; 彼得前書 4:2–3"> 做為順從的兒女，不可效法你們原先愚昧無知時的那些欲望；</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:48; 哥林多後書 7:1; 希伯來書 12:14"> 相反，正如召喚你們的那一位是聖潔的，你們在一切行為上也當成為聖潔的，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 11:44; 利未記 19:2; 利未記 20:7"> 因為經上記著：「你們當成為聖潔的，因為我是聖潔的。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 10:34–35; 歷代志下 19:7; 馬太福音 6:9"> 你們既然稱不偏待人、只按每個人的行為施行審判的那一位為父，就應當懷著敬畏的心，過你們寄居的日子，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 6:20; 提多書 2:14; 詩篇 49:7–8"> 因為你們知道，你們被救贖，脫離祖先所傳下來的虛妄行為，不是憑著會朽壞的東西，如銀子或金子，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 1:7; 彼得前書 2:22–24; 約翰福音 1:29"> 而是憑著那像羔羊一樣毫無瑕疵、毫無玷汙的基督寶血。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 1:4; 提摩太後書 1:9–10; 希伯來書 9:26"> 基督在創世以前就已經被神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神——輔助詞語。">c</a></sup>預先知道，又在這末後的時代為你們的緣故顯明出來。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 2:24; 希伯來書 2:9; 約翰福音 12:44"> 藉著基督<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="基督——原文直譯「他」。">d</a></sup>，你們信靠那使他從死人中復活、又賜他榮耀的神，以致你們的信仰和盼望也都在於神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="提摩太前書 1:5; 希伯來書 13:1; 羅馬書 12:9–10"> 你們既然藉著順從真理，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附「藉著聖靈」。">e</a></sup>使自己的靈魂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="靈魂——或譯作「生命」。">f</a></sup>純潔，以致有了不虛假的弟兄之愛，就應當以潔淨的心<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以潔淨的心——有古抄本作「從心裡」。">g</a></sup>，彼此熱切地相愛。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前書 1:3; 希伯來書 4:12; 約翰福音 1:13"> 你們得以重生，不是出於會朽壞的種子，而是出於不朽壞的種子，是藉著神永活長存的話語，</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 40:6–8; 詩篇 103:15; 雅各書 4:14"> 因為，<br /><span className="pl pl-1">「所有的人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="人——原文直譯「肉體」。">h</a></sup><br /><span className="pl pl-1">都像草一樣，</span><br /><span className="pl pl-1">他們的一切榮耀就像草上的花；</span><br /><span className="pl pl-1">草會枯乾，花會凋謝，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 40:8; 馬太福音 5:18; 詩篇 119:89"> <span className="pl pl-1">但主的話卻永遠長存。」</span><br />所傳給你們的福音就是這話。</span>
</div>
</div>

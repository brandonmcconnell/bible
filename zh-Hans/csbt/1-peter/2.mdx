<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以弗所書 4:31; 雅各書 1:21; 雅各書 4:11"> 所以，你們要脫去一切惡毒、一切詭詐、偽善、嫉妒，以及一切的誹謗，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 5:12–13; 以弗所書 4:15; 彼得後書 3:18"> 要像剛出生的嬰孩一樣，愛慕那純淨的話語之奶，好使你們藉著它成長，以至於救恩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本沒有「以至於救恩」。">a</a></sup>，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 34:8; 希伯來書 6:5–6; 詩篇 63:5"> 因為你們嘗過主仁慈的滋味。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 118:22–23; 使徒行傳 4:11–12; 彼得前書 2:7"> 你們來到那活石面前——他雖然被人棄絕，卻是神所揀選、所珍貴的——</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:20–22; 彼得前書 2:9; 哥林多前書 3:9"> 你們也就像活石，被建造成一座屬靈的殿宇<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="殿宇——原文直譯「家」。">b</a></sup>，進入聖潔的祭司體系，好藉著耶穌基督獻上蒙神悅納的屬靈祭物，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 28:16; 羅馬書 9:32–33; 彼得前書 2:4"> 因為經上記著：<br /><span className="pl pl-1">「看哪，我在錫安放一塊</span><br /><span className="pl pl-1">蒙揀選的、珍貴的房角石，</span><br /><span className="pl pl-1">信靠他的人絕不至於蒙羞。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 118:22–23; 馬可福音 12:10–11; 使徒行傳 4:11–12"> 這樣，對你們信的人來說，他是尊貴的；但是對那些不信的人來說，卻是<br /><span className="pl pl-1">「工匠所棄絕的石頭，</span><br /><span className="pl pl-1">它已經成了房角的頭塊石頭。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:14; 哥林多前書 1:23; 羅馬書 9:32–33"> 並且是<br /><span className="pl pl-1">「一塊絆腳的石頭，</span><br /><span className="pl pl-1">使人絆倒的磐石。」</span><br />他們絆倒是因為不肯信從這話語，而這也是被預定的。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 19:5–6; 申命記 7:6; 啟示錄 1:6"> <span className="pl pl-1">但你們屬於蒙揀選的族類、君王的祭司體系、</span><br /><span className="pl pl-1">聖潔的國度 ，是屬神的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="屬神的——原文直譯「所獲得的」或「財產的」。">c</a></sup><br /><span className="pl pl-1">子民 ；</span><br /><span className="pl pl-1">為要使你們宣揚曾召喚你們的那一位的美德——</span><br /><span className="pl pl-1">他召喚你們出黑暗，入他奇妙的光明。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 2:23; 希伯來書 4:16; 何西阿書 1:9–10"> <span className="pl pl-1">你們從前不是子民，</span><br /><span className="pl pl-1">但如今卻是神的子民；</span><br /><span className="pl pl-1">從前沒有蒙憐憫，</span><br /><span className="pl pl-1">但如今卻蒙了憐憫。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰一書 2:15–17; 加拉太書 5:24; 彼得前書 4:2"> 各位蒙愛的人哪，我勸你們：做為過客和寄居的，要遠避那與你們靈魂爭戰的肉體欲望。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:16; 馬太福音 5:16; 提多書 2:7–8"> 你們在外邦人中，要有良好的品行；這樣，當他們誹謗你們是作惡之人的時候，因看到你們美好的行為，就在神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——輔助詞語。">d</a></sup>臨到<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="臨到——或譯作「探望」。">e</a></sup>的日子榮耀神。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提多書 3:1; 羅馬書 13:1–7; 提摩太前書 2:1–2"> 為了主的緣故，你們要服從人的一切制度；無論是在上的君王，</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 13:3–4"> 或是他所委派來懲惡賞善的那些官員<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="官員——或譯作「總督」。">f</a></sup>；</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 3:17; 提多書 2:8; 馬太福音 7:26"> 因為神的旨意就是要你們藉著行善，堵住那些愚妄人無知的口。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 5:13; 羅馬書 6:22; 羅馬書 6:18"> 做為自由人，你們不可拿自由當做惡事的藉口，卻要做神的奴僕。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 24:21; 羅馬書 12:10; 羅馬書 13:7"> 你們應當尊重所有的人，愛弟兄姐妹，敬畏神，尊重君王。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="提多書 2:9–10; 以弗所書 6:5–7; 歌羅西書 3:22–25"> 你們做家僕的，應當以完全敬畏的心服從主人；不僅要服從善良溫和的，就是乖僻的，也要服從。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 5:10–12; 彼得前書 3:14–17; 彼得前書 2:20"> 因為人如果為了在神面前良心的緣故，在不公正的苦害中忍受憂患，這是可稱讚的；</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:19; 彼得前書 3:17; 馬太福音 5:10–12"> 就是說，如果你們因犯罪受責打而忍耐，有什麼可稱讚的呢？但如果你們因行善受苦害而忍耐，這在神看來是可稱讚的。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 2:6; 馬太福音 16:24; 約翰福音 13:15"> <span className="pl pl-1">原來你們是為此蒙召的，</span><br /><span className="pl pl-1">因為基督也為你們受了苦害，</span><br /><span className="pl pl-1">給你們留下了榜樣，</span><br /><span className="pl pl-1">好讓你們追隨他的腳蹤。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 53:9; 哥林多後書 5:21; 希伯來書 4:15"> <span className="pl pl-1">他沒有犯過罪，</span><br /><span className="pl pl-1">在他口中也找不出詭詐；</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 53:7; 彼得前書 4:19; 希伯來書 12:3"> <span className="pl pl-1">他被辱罵的時候，不還口；</span><br /><span className="pl pl-1">受苦害的時候，不說威嚇的話，</span><br /><span className="pl pl-1">而是把自己交託給以公義施行審判的那一位。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 53:4–6; 馬太福音 8:17; 羅馬書 6:11"> <span className="pl pl-1">他在木頭上，以自己的身體親自擔當了我們的罪孽，</span><br /><span className="pl pl-1">好使我們既然向罪而死，</span><br /><span className="pl pl-1">就能向義而活；</span><br /><span className="pl pl-1">因他受的鞭傷，你們得了痊癒。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 53:6; 以西結書 34:6; 路加福音 15:4–6"> <span className="pl pl-1">要知道，你們從前像是迷失的羊，</span><br /><span className="pl pl-1">但現在卻回到了</span><br /><span className="pl pl-1">你們靈魂</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="靈魂——或譯作「生命」。">g</a></sup><br /><span className="pl pl-1">的牧人和監督的身旁。</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:21–24; 詩篇 33:10; 詩篇 33:16"> 羅波安回到耶路撒冷，招聚了猶大家和便雅憫家十八萬善戰的精兵，要與以色列人爭戰，恢復羅波安的王國。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 12:15; 歷代志下 12:5–7; 歷代志下 8:14"> 但耶和華的話語臨到神人示瑪雅，說：</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 17:34; 創世記 49:28; 啟示錄 7:4–8"> 「你要告訴所羅門的兒子猶大王羅波安，以及猶大和便雅憫的全體以色列人，說：</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 50:20; 列王紀上 11:29–38; 歷代志下 10:15–16"> 『耶和華如此說：你們不可上去，不可與你們的兄弟爭戰。各回自己的家去吧，因為這事出於我。』」<br />於是他們聽從耶和華的話，轉回不去攻打耶羅波安了。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 8:2–6; 歷代志下 14:6–7; 以賽亞書 22:8–11"> 羅波安住在耶路撒冷，他在猶大修築城鎮來設防。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 3:5; 阿摩司書 1:1; 歷代志上 4:32"> 他修築了伯利恆、以坦、提克亞、</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:35; 撒母耳記上 22:1; 約書亞記 15:58"> 伯促爾、梭哥、亞杜蘭、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 54:1; 約書亞記 15:24; 撒母耳記上 23:19"> 迦特、瑪利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 15:39; 約書亞記 15:35; 約書亞記 10:5"> 亞多萊音、拉吉、亞西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 13:22; 約書亞記 15:33; 約書亞記 14:14"> 佐拉、阿雅崙、希伯崙，這些都是在猶大和便雅憫的防御城。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 17:19; 以賽亞書 22:10–11; 歷代志下 11:23"> 他鞏固了這些防御城，在其中設立將領，儲備食物、油和酒，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 13:22; 歷代志下 26:14–15; 歷代志下 32:5"> 並在每座城中配備盾牌和長矛，使城極其堅固。這樣，猶大和便雅憫就一直屬於他。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 全以色列的祭司和利未人從他們四境前來支持羅波安<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="支持羅波安——原文直譯「站在羅波安一邊」。">a</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 13:9; 民數記 35:2–5; 列王紀上 12:28–33"> 利未人撇下了他們的牧野和地產，來到猶大和耶路撒冷，因為耶羅波安和他的兒子們拋棄了利未人，不讓他們作耶和華的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 12:28; 列王紀上 12:31; 列王紀上 13:33"> 耶羅波安為高壇、山羊神和他鑄造的牛犢設立了自己的祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:9; 使徒行傳 11:23; 詩篇 84:5–7"> 以色列各支派中，那些決心要尋求以色列神耶和華的人，也跟隨祭司和利未人來到耶路撒冷，要向他們祖先的神耶和華獻祭。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 12:1; 歷代志下 1:1–12; 歷代志下 7:17–19"> 這樣他們鞏固了猶大王國，使所羅門的兒子羅波安強盛三年，因為這三年期間他們走大衛和所羅門的道路。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:6; 歷代志上 27:18; 撒母耳記上 17:13"> 羅波安娶了大衛之子耶利莫的女兒瑪哈拉為妻，瑪哈拉的母親<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="瑪哈拉的母親——輔助詞語。">b</a></sup>是耶西之子以利押的女兒亞比亥。</span>
<span className="v" id="v19" data-v="19"> 瑪哈拉給羅波安生了幾個兒子：耶烏施、示瑪利雅、扎罕。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 13:2; 歷代志下 11:21; 歷代志下 12:16"> 在她之後，羅波安又娶了押沙龍的外孫女<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="押沙龍的外孫女——或譯作「押沙龍之女」。">c</a></sup>瑪迦，瑪迦為他生了亞比雅、亞泰、細撒和示羅米。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 8:30; 申命記 17:17; 列王紀上 11:3"> 羅波安喜愛押沙龍的外孫女<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="押沙龍的外孫女——或譯作「押沙龍之女」。">d</a></sup>瑪迦超過他其他的妃嬪；他娶了十八個妃、六十個嬪，生了二十八個兒子、六十個女兒。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 21:15–17; 歷代志上 29:1; 歷代志上 5:1–2"> 羅波安立瑪迦的兒子亞比雅為太子，讓他在兄弟中作領袖，因為要立他為王。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 21:3; 創世記 25:6; 路加福音 16:8"> 羅波安行事有智慧，把他的兒子都分散到猶大和便雅憫全地各防御城，並為他們提供大量的糧食，聘娶眾多的妻子。</span>
</div>
</div>

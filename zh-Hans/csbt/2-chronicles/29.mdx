<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歷代志下" data-chapter="29" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:1–3; 歷代志上 3:13; 歷代志下 26:5"> 希西加二十五歲作王，在耶路撒冷統治了二十九年。他的母親名叫婭比雅，是撒迦利亞的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 34:2; 歷代志下 28:1"> 他效法他先祖大衛所做的一切，做耶和華眼中看為正的事。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 28:24; 歷代志下 29:7; 馬太福音 6:33"> 他作王的第一年一月，他打開了耶和華殿的門，並且修繕它們。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 19:2; 尼希米記 3:29; 歷代志下 32:6"> 然後他召來祭司和利未人，把他們聚集在東邊的廣場上，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 35:6; 哥林多前書 3:16–17; 歷代志下 34:3–8"> 對他們說：「利未人哪，請聽我說！現在你們要使自己分別為聖，然後把你們祖先的神耶和華的殿也分別為聖，把汙穢之物從聖所中除去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 8:16; 耶利米書 2:27; 但以理書 9:16"> 我們的祖先對神不忠，做我們的神耶和華眼中看為惡的事。他們離棄他，轉臉不顧耶和華的居所，背對著它。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 28:24; 利未記 24:2–8; 歷代志下 29:3"> 他們還關上門廊的門，熄滅燈盞，不在聖所向以色列的神燒香、獻燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 25:9; 耶利米書 25:18; 耶利米書 29:18"> 所以耶和華的震怒臨到猶大和耶路撒冷，使它們的遭遇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="遭遇——輔助詞語。">a</a></sup>令人戰兢、令人驚駭、被嗤笑，正如你們親眼所見的那樣。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 28:17; 歷代志下 28:5–8; 耶利米哀歌 5:7"> 看哪，我們的祖先倒在刀下，我們的兒女和妻子也因此被擄去。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 50:5; 歷代志下 23:16; 以斯拉記 10:3"> 現在我心中有意要與以色列的神耶和華立約，好使他從我們身上收回他猛烈的怒氣。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:8; 加拉太書 6:7–8; 民數記 8:6–14"> 我的子民哪，現在你們不要懈怠，因為耶和華揀選了你們站在他面前事奉他，給他作侍從、作燒香的人。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="民數記 3:19–20; 歷代志上 15:5–7; 民數記 4:2–20"> 於是利未人就起來：<br /><span className="pl pl-1">哥轄的子孫中有亞瑪賽的兒子瑪哈、</span><br /><span className="pl pl-1">亞撒利雅的兒子約珥，</span><br /><span className="pl pl-1">米拉利的子孫中有阿伯迪的兒子基士、</span><br /><span className="pl pl-1">耶哈利勒的兒子亞撒利雅，</span><br /><span className="pl pl-1">革順人中有津瑪的兒子約亞、</span><br /><span className="pl pl-1">約亞的兒子伊甸，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 6:39; 歷代志上 15:8; 歷代志上 15:17"> <span className="pl pl-1">以利撒番的子孫中有示姆利和耶伊列，</span><br /><span className="pl pl-1">亞薩的子孫中有撒迦利亞和瑪塔尼亞，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 6:33; 歷代志上 25:1; 歷代志上 25:6"> <span className="pl pl-1">希幔的子孫中有耶希業和示每，</span><br /><span className="pl pl-1">耶杜頓的子孫中有示瑪雅和烏基業；</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志下 30:12; 歷代志上 23:28; 歷代志下 29:5"> 他們聚集他們的兄弟，都使自己分別為聖了，然後照著王的命令，按照耶和華的吩咐，進去潔淨耶和華的殿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:16; 馬太福音 21:12–13; 馬太福音 23:27"> 祭司們進去潔淨耶和華的殿，把耶和華聖殿中發現的一切不潔之物都搬到耶和華殿的院子裡，然後利未人接過去，帶到城外的汲淪溪谷那裡。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:2–8; 歷代志下 3:4; 列王紀上 6:3"> 他們一月一日開始分別為聖的工作，在當月的八日進展到耶和華的門廊前，又用了八天時間使耶和華的殿分別為聖，這樣在一月十六日完工了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 4:1; 歷代志下 4:7–8; 歷代志下 13:11"> 然後，他們進王宮<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="王宮——輔助詞語。">b</a></sup>去見希西加王，說：「我們已經把整個耶和華的殿，燔祭壇和附屬的一切器具，陳設餅的桌子和附屬的一切器具，都潔淨了。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 28:24"> 亞哈斯王在位時對神不忠而拋棄的一切器具，我們也預備好了，把它們分別為聖了；看哪，這些都在耶和華的祭壇前面。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約書亞記 6:12; 耶利米書 25:4; 出埃及記 24:4"> 於是希西加王清早起來，招聚城裡的眾首領，然後上耶和華的殿去。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 4:3–14; 約伯記 42:8; 以西結書 45:23"> 他們牽來七頭公牛、七隻公綿羊、七隻綿羊羔、七隻公山羊，要為國家、為聖所、為猶大作贖罪祭；王吩咐作祭司的亞倫子孫把這些獻在耶和華的祭壇上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:18; 利未記 8:19; 利未記 8:24"> 他們就宰殺公牛，祭司把血接過來，灑在祭壇上；又宰殺公綿羊，把血灑在祭壇上；又宰殺綿羊羔，把血灑在祭壇上。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 4:15; 利未記 4:24; 利未記 1:4"> 然後把作贖罪祭的公山羊牽到王和會眾面前，他們按手在公山羊身上，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 14:20; 以西結書 45:15; 哥林多後書 5:18–21"> 祭司宰殺了公山羊，把血灑在祭壇上作贖罪祭，為全以色列贖罪，因為王吩咐要為全以色列獻上這燔祭和贖罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歷代志下 8:14; 歷代志上 23:5; 撒母耳記下 24:11"> 王又按照先王大衛與他的先見迦得和先知拿單的規定，安排利未人在耶和華殿中奏響銅鈸、里拉琴和豎琴，因為這是耶和華藉著他的眾先知所規定的。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 23:5; 歷代志上 15:24; 阿摩司書 6:5"> 這樣，利未人拿著大衛的樂器、祭司拿著號筒侍立。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志下 23:18; 詩篇 137:3–4; 歷代志下 20:21"> 希西加吩咐把燔祭獻在祭壇上。燔祭開始獻上時，讚美耶和華的歌聲和號筒聲也伴隨著以色列王大衛的樂器開始響起。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 5:8–14; 詩篇 89:15; 詩篇 68:24–26"> 全體會眾都敬拜，歌唱的歌唱，吹號的吹號，這一切持續到獻完了燔祭。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 20:18; 歷代志上 29:20; 腓立比書 2:10–11"> 獻完燔祭，王和所有與他一同在場的人都俯伏敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 4:4; 詩篇 95:1–2; 歷代志上 16:7–36"> 然後，希西加王和眾首領吩咐利未人用大衛和先見亞薩的歌詞來讚美耶和華。於是他們歡歡喜喜地讚美耶和華，俯身下拜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歷代志下 13:9; 出埃及記 35:22; 利未記 7:12"> 希西加說：「現在你們已經奉獻自己歸於耶和華。請上前來，把感謝的祭物帶到耶和華殿中。」於是會眾把感謝的祭物帶來，所有甘心樂意的人都帶來了燔祭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉記 6:17; 列王紀上 3:4; 歷代志上 29:21"> 會眾帶來的燔祭數目是公牛七十頭，公綿羊一百隻，綿羊羔兩百隻，這一切都作為燔祭歸於耶和華；</span>
<span className="v" id="v33" data-v="33"> 還有分別為聖之物，公牛六百頭，綿羊三千隻。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 35:11; 歷代志下 30:3; 詩篇 94:15"> 只是祭司太少，不能給所有的燔祭牲剝皮，所以他們的兄弟利未人幫助他們，直到完成了這工作，並且其他祭司都使自己分別為聖了，因為利未人比祭司們更誠心使自己分別為聖。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 15:5–10; 出埃及記 29:13; 歷代志上 16:37–42"> 這大量的燔祭之外，還有平安祭的脂油，以及與燔祭同獻的酒祭。<br />這樣，耶和華殿中的服事就重新確立了。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 2:41; 帖撒羅尼迦前書 3:8–9; 歷代志上 29:9"> 希西加和全體民眾都因神為子民確立這事而歡喜，因為這事突然間就實現了。</span>
</div>

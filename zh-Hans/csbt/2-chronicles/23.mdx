<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歷代志下" data-chapter="23" data-verses="21">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 15:12; 列王紀下 11:4–20; 尼希米記 9:38"> 到了第七年，耶赫亞達堅定心志，請來幾位百夫長與自己結盟，有耶羅罕的兒子亞撒利雅、約哈南的兒子以實瑪利、俄備得的兒子亞撒利雅、亞達雅的兒子瑪西雅和澤克利的兒子以利沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 11:13–17; 歷代志下 21:2; 歷代志上 15:12"> 然後他們走遍猶大，招聚猶大各城的利未人，以及以色列各父系的首領。他們都來到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 21:7; 撒母耳記下 7:12; 歷代志下 6:16"> 全體會眾就在神的殿中與王立約。耶赫亞達對他們說：「看哪，這是王子，照著耶和華關於大衛子孫的應許，他必須作王！</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 23:3–6; 歷代志上 26:13–16; 路加福音 1:8–9"> 你們要這樣做：你們安息日當班的祭司和利未人，三分之一要在入口處做門衛，</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 46:2–3; 使徒行傳 3:2; 列王紀下 11:5–6"> 三分之一在王宮，三分之一在根基門；其他所有人都要在耶和華殿的院子裡。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 23:28–32; 列王紀下 11:6–7"> 誰都不可進入耶和華的殿，只有祭司和事奉的利未人可以進去，因為他們是聖潔的；所有的人必須遵守耶和華的吩咐。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 3:38; 民數記 3:10; 列王紀下 11:8–9"> 利未人要各自手拿兵器圍繞著王，其他人進入殿宇必被處死。王出入的時候，你們必須緊隨著王。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 11:9; 歷代志上 24:1–26"> 於是利未人和全體猶大人照著祭司耶赫亞達所吩咐的一切去做，各自帶領部下，無論是安息日當班的還是安息日休班的，因為祭司耶赫亞達沒有解散班組。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 21:9; 撒母耳記下 8:7"> 祭司耶赫亞達把神殿中大衛王的那些長矛和大小盾牌交給眾百夫長，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:6; 歷代志下 6:12; 列王紀下 11:11"> 然後讓所有軍兵各自手拿兵器，從殿宇右側到殿宇左側，對著祭壇和殿宇，侍立在王子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王子——原文直譯「王」。">a</a></sup>的四圍。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 10:24; 出埃及記 25:16; 列王紀下 11:12"> 他們把王子領出來，給他戴上冠冕，把律法書交給他，立他為王。耶赫亞達和他的兒子們膏抹了他，然後眾人說：「願王萬歲！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 11:13–16; 列王紀下 9:32–37"> 婭塔利雅聽見民眾來回奔走<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="民眾來回奔走——或譯作「民眾、護衛兵」。">b</a></sup>讚美王的聲音，就來到耶和華殿中民眾那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:2; 歷代志下 34:31; 列王紀下 9:23"> 她觀看，看哪，王站在入口處的柱子旁邊，將領們和吹號手在王身邊，這地所有的民眾在歡樂、吹號，歌手們在各種樂器的伴奏下帶領讚美。婭塔利雅就撕裂衣服，說：「謀反了！謀反了！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 9:7; 列王紀下 11:8; 列王紀下 11:15"> 祭司耶赫亞達吩咐率領軍隊的眾百夫長出來，對他們說：「把她從隊列之間趕出去，把跟隨她的人都用刀殺了！」因為祭司說不可在耶和華殿中處死她。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 3:28; 耶利米書 31:40; 歷代志下 22:10"> 他們就下手抓住她，當她到了王宮馬門入口處的時候，在那裡把她處死了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 29:10; 尼希米記 9:38; 列王紀下 11:17"> 此後，耶赫亞達使全體民眾和王與他一起立約，要作耶和華的子民。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 18:40; 列王紀下 10:25–28; 列王紀下 18:4"> 於是全體民眾來到巴力的廟宇，把它拆毀，打碎其中的祭壇和偶像，並且在祭壇前殺了巴力的祭司瑪坦。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 5:5; 民數記 28:1–31; 歷代志下 29:25"> 耶赫亞達把耶和華殿的監管職份交在利未祭司手中，他們是大衛在耶和華殿中所分派的人，照著摩西律法所記的，伴著大衛所指定的詩歌，歡歡喜喜向耶和華獻上燔祭。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 26:1–32; 歷代志上 9:22–24"> 他也在耶和華殿的各門安排了門衛，不潔淨的人無論任何理由，都不准進入。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 11:19; 列王紀下 15:35; 列王紀下 11:9–10"> 然後他帶領百夫長、貴族、民眾的官長以及這地所有的民眾，請王從耶和華的殿下來，穿過上門進入王宮，使王坐上王位。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 11:20; 啟示錄 18:20; 啟示錄 19:1–4"> 於是這地所有的民眾都歡喜，城中也平靜，因為他們把婭塔利雅用刀殺了。</span>
</div>
</div>

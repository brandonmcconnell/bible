<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 83:5–8; 以賽亞書 16:6; 歷代志下 32:1"> 後來摩押人、亞捫人，還有一些米烏尼人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一些米烏尼人——依據七十士譯本；馬索拉文本作「來自亞捫人的」；參《歷代志下》26:7。">a</a></sup>，一同來攻擊約沙法，與他爭戰。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:7; 撒母耳記上 23:29; 約書亞記 15:62"> 有人來向約沙法報告說：「有一支大軍從海對面的以東<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以東——依據古拉丁文譯本以及其他古抄本；馬索拉文本作「亞蘭」。">b</a></sup>來攻擊你，看哪，他們已經在哈洗遜-塔瑪爾。」哈洗遜-塔瑪爾就是恩蓋迪。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 9:3; 歷代志下 19:3; 撒母耳記上 7:6"> 約沙法就害怕，於是定意尋求耶和華，向全猶大宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 50:15; 詩篇 60:10–12; 詩篇 69:35"> 猶大人聚集起來求助於耶和華，甚至從猶大的各城前來向耶和華求助。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:15–19; 歷代志下 6:12–13; 歷代志下 34:31"> 那時，約沙法站在猶大和耶路撒冷的會眾當中，在耶和華殿的新院子前面，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 4:39; 歷代志上 29:11–12; 但以理書 4:17"> 說：<br />「我們祖先的神耶和華啊，你不是那一位在天上的神嗎？你不是管轄列國列邦的主宰嗎？你手中有能力和權柄，沒有誰能在你面前站立得住。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 41:8; 雅各書 2:23; 詩篇 44:2"> 我們的神哪，你不是已經從你子民以色列面前趕出這地的居民，把這地永遠賜給了你朋友亞伯拉罕的後裔嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 6:10; 歷代志下 2:4"> 他們住在其中，並在這裡為你的名建造了聖所，說：</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 6:28–30; 歷代志下 6:20; 列王紀上 8:33"> 『如果有禍患臨到我們，無論是審判的刀劍，還是瘟疫、饑荒，那時我們站在這殿宇中，在你的面前——因為你的名在這殿宇中——我們在患難中向你哀求，你必垂聽，施行拯救。』</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 2:19; 申命記 2:4–5; 申命記 2:9"> 「現在，你看亞捫、摩押和西珥山的居民——以色列人從埃及地上來的時候，你不允許以色列人侵犯他們，以色列人就從他們旁邊繞過去，沒有除滅他們——</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 83:3–12; 士師記 11:23–24; 耶利米書 18:20"> 你看他們竟然這樣回報我們，要來把我們從你給我們繼承的產業之地趕走。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 121:1–2; 詩篇 25:15; 詩篇 141:8"> 我們的神哪，難道你不審判他們嗎？我們實在無力面對來攻擊我們的這支大軍，我們不知道該做什麼，我們的眼睛只仰望你。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 10:1; 使徒行傳 21:5; 申命記 29:10"> 全體猶大人，連同他們的家屬——妻子、兒女，都站在耶和華面前。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 15:1; 歷代志下 24:20; 使徒行傳 10:31"> 那時，耶和華的靈在會眾當中臨到了雅哈希身上；雅哈希是撒迦利亞的兒子、比納雅的孫子、耶伊列的曾孫、瑪塔尼亞的玄孫，屬於利未人亞薩的後裔。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 32:7–8; 申命記 31:6; 出埃及記 14:13–14"> 雅哈希就說：「全體猶大人、耶路撒冷的居民和約沙法王啊，你們留心聽！耶和華對你們如此說：『你們不要害怕，不要因這大軍而喪膽，因為戰爭的勝敗不在於你們，而在於神。</span>
<span className="v" id="v16" data-v="16"> 明天你們就下去迎戰他們，看哪，他們正從洗斯的斜坡上來，你們會在耶魯伊勒曠野對面的溪谷口遇見他們。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:13–14; 歷代志下 15:2; 以賽亞書 41:10"> 這場仗不用你們打，你們只管站住，站好觀看耶和華為你們施行拯救。』猶大和耶路撒冷的人哪，你們不要害怕，不要喪膽，明天就出去到他們面前，耶和華必與你們同在！」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 4:31; 歷代志下 7:3; 創世記 24:26"> 約沙法臉伏於地，全體猶大人和耶路撒冷的居民都俯伏在耶和華面前，向耶和華下拜。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 15:16–22; 歷代志上 16:42; 歷代志上 16:5"> 哥轄子孫中、可拉子孫中的利未人都起來，以高亢的聲音讚美耶和華以色列的神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 8:31; 約翰福音 14:1; 約翰福音 11:40"> 第二天清晨，他們早早起來，出去到提克亞曠野去。他們出去的時候，約沙法站著說：「猶大和耶路撒冷的居民哪，請聽我說！要相信耶和華你們的神，你們必堅立；要相信他的先知，你們必得勝！」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:1; 詩篇 106:1; 歷代志下 5:13"> 約沙法與民眾商議後，就安排人向耶和華歌唱，讚美聖潔威嚴的那一位<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="讚美聖潔威嚴的那一位——或譯作「穿著聖潔的裝束獻上讚美」。">c</a></sup>，走在武裝士兵的前面說：<br /><span className="pl pl-1">「你們要稱謝耶和華，</span><br /><span className="pl pl-1">他的慈愛永遠長存！」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 14:20; 以賽亞書 19:2; 以西結書 38:21"> 當他們開始歡呼讚美的時候，耶和華設下伏兵攻擊那些入侵猶大的亞捫、摩押和西珥山的居民，他們就被打敗了。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 7:22; 撒母耳記上 14:20; 以西結書 35:2–3"> 亞捫人和摩押人起來攻擊西珥山的居民，要把他們滅絕淨盡；他們滅絕了西珥的居民之後，又極力<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="極力——原文直譯「幫助」。">d</a></sup>自相殘殺。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 37:36; 詩篇 110:6; 歷代志上 5:22"> 猶大人來到曠野的守望臺，向敵軍觀望，看哪，他們屍橫遍地，沒有一個倖存者。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 30:19–20; 列王紀下 7:9–16; 民數記 31:15"> 約沙法和他的子民就來掠取財物，那裡有大量的裝備、衣服<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="衣服——依據一些古抄本；馬索拉文本作「屍首」。">e</a></sup>、珍貴物品。他們收拾起來，直到裝不下為止。由於財物很多，他們連續掠取了三天。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 17:15; 創世記 32:20; 歷代志下 5:9"> 第四天，他們聚集到比拉卡平原，他們就在那裡頌讚耶和華。因此他們給那地方起名為比拉卡平原，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="尼希米記 12:43; 希伯來書 6:20; 詩篇 30:1"> 猶大和耶路撒冷的人都回去了，約沙法率領他們歡歡喜喜地回耶路撒冷去，他們因耶和華使他們勝過仇敵而歡喜。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 14:2–3; 詩篇 57:8; 詩篇 92:3"> 他們伴著里拉琴、豎琴、號筒回到耶路撒冷，進入耶和華的殿。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志下 17:10; 列王紀下 7:6; 出埃及記 23:27"> 當那地的列國聽說耶和華戰敗以色列的仇敵時，他們就懼怕神。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 15:15; 歷代志下 14:6–7; 撒母耳記下 7:1"> 這樣，約沙法國中太平，他的神使他四圍安定下來。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 22:41–44"> 約沙法作了猶大的王，他作王的時候三十五歲，在耶路撒冷統治了二十五年。他的母親名叫阿蘇巴，是示利希的女兒。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 14:2–5; 列王紀上 15:11; 歷代志下 14:11–13"> 他走他父親亞撒的道路，沒有偏離；他做耶和華眼中看為正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 17:6; 歷代志下 19:3; 歷代志下 12:14"> 只是高壇還沒有除掉，百姓仍舊沒有立定心志歸向他們祖先的神。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:1; 歷代志下 19:2; 列王紀上 16:7"> 約沙法其餘的事蹟，從始至終，看哪，都記在《以色列諸王紀》上哈納尼的兒子耶戶的紀事中。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:48–49; 列王紀下 1:2–16"> 後來猶大王約沙法與那做盡壞事的以色列王亞哈謝結盟。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 10:22; 歷代志下 9:21; 列王紀上 9:26"> 他們二人聯合建造出海的塔爾施船隊，在以旬迦別造船。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 歷代志下 19:2; 歷代志下 9:21"> 那時瑪利沙人德達瓦的兒子以利以謝向約沙法預言說：「因為你與亞哈謝結盟，耶和華必拆毀你所建造的。」後來那些船果然被毀壞，不能開往塔爾施去了。</span>
</div>
</div>

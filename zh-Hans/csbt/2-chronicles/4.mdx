<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:64; 以西結書 43:13–17; 列王紀上 9:25"> 他做了一個銅祭壇，長二十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二十肘——相當於9.1公尺；下同。1肘=45.7公分。">a</a></sup>，寬二十肘，高十肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十肘——相當於4.6公尺；下同。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 3:5; 撒迦利亞書 13:1; 出埃及記 30:18–21"> 又鑄造了一個銅海，是圓形的，直徑<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="直徑——原文直譯「從口沿到口沿」。">c</a></sup>有十肘，高五肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五肘——相當於2.3公尺。">d</a></sup>，周長<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="周長——原文直譯「繩子繞一圈」。">e</a></sup>三十肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三十肘——相當於13.7公尺。">f</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 1:10; 以西結書 10:14; 哥林多前書 9:9–10"> 口沿下方有牛的圖形，圍繞在整個銅海周圍，每肘十個環繞在銅海周圍；牛的圖形有兩行，是與銅海一體鑄造的。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 28:19–20; 啟示錄 21:14; 馬可福音 16:15"> 銅海安裝在十二頭銅牛<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="銅牛——原文直譯「牛」。">g</a></sup>上面，三頭朝北，三頭朝西，三頭朝南，三頭朝東。銅海在牛背上，牛尾全都向內。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:26"> 銅海厚一掌<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一掌——相當於7.4公分。">h</a></sup>，口沿如杯沿的工藝，像百合花，容量為三千罷特<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="三千罷特——相當於66,000公升。1罷特=22公升。">i</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:38; 出埃及記 30:18–21; 列王紀上 7:40"> 他做了十個用於洗濯的盆，五個放在右側，五個放在左側，用來清洗獻燔祭之物；至於銅海，是給祭司洗濯用的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 25:31–40; 列王紀上 7:49; 約翰福音 8:12"> 他照著所定的規格做了十個金燈臺，放在聖殿中，五個在右邊，五個在左邊；</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:48; 瑪拉基書 1:12; 出埃及記 25:23–30"> 又做了十張桌子，放在聖殿中，五張在右邊，五張在左邊；還做了一百個金碗。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:36; 列王紀下 21:5; 列王紀上 7:12"> 他建造祭司院、大院和院門，門都貼上了銅。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 7:39"> 他把銅海放在殿宇的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="殿宇的——輔助詞語。">j</a></sup>右側，在東南角。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 7:40–51; 列王紀上 7:14"> 他還做了鍋、鏟子和碗。 所有銅器<br />這樣，戶蘭完成了他為所羅門王在神殿所做的工作，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 7:41; 歷代志下 3:15–17"> 包括：兩根柱子，兩個柱子頂上盆狀的柱頭，以及兩個用來裝飾柱子頂上盆狀柱頭的網格，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 7:20; 列王紀上 7:42; 耶利米書 52:23"> 還有兩個網格上的四百個石榴——每網格上兩行石榴，用來裝飾各柱子上面盆狀的柱頭。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 7:27–43"> 他還做了底座和底座上的盆，</span>
<span className="v" id="v15" data-v="15"> 一個銅海和銅海底下的十二頭牛，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 2:13; 列王紀上 7:13–14; 歷代志下 4:11"> 鍋、鏟子、叉子，以及一切相關的器物，都是戶蘭阿比<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="戶蘭阿比——或譯作「戶蘭匠師」。">k</a></sup>用磨亮的銅為所羅門王，給耶和華的殿製作的。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:46"> 王在約旦平原、疏割和撒拉坦之間的土模場鑄造了這些。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:47; 耶利米書 52:20; 歷代志上 22:14"> 所羅門製作這一切器物，數量極多，所以銅的重量無法計算。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="啟示錄 9:13; 但以理書 5:2–3; 出埃及記 25:23–30"> 所羅門製作了神殿中的一切器物：金祭壇和擺放陳設餅的桌；</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 4:7; 出埃及記 25:31–37; 列王紀上 6:5"> 純金的燈臺和其上按照規定在內殿前點燃的燈盞，</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 6:29; 出埃及記 37:20; 列王紀上 6:35"> 燈臺上的花朵、燈盞、金燈剪，都是純金的；</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 12:13; 列王紀下 25:14; 耶利米書 52:18"> 還有純金的蠟剪、碗、勺子、香爐；殿宇的門，就是最裡面至聖所的門和殿宇正殿的門，它們都是金的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 1:1; 耶利米書 1:2; 歷代志下 33:25"> 約西亞作王的時候八歲，在耶路撒冷統治了三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 29:2; 約書亞記 1:7; 列王紀下 22:2"> 他做耶和華眼中看為正的事，走他先祖大衛的道路，不偏離左右。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 33:22; 歷代志下 15:2; 箴言 8:17"> 他在位第八年，他還年少，就開始尋求他先祖大衛的神。到了第十二年，他開始潔淨猶大和耶路撒冷，除掉高壇、亞舍拉柱、雕像和鑄像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 32:20; 利未記 26:30; 列王紀下 23:4–6"> 人們在王面前拆毀巴力的祭壇，也砍倒了那些祭壇上高高的香壇，把亞舍拉柱、雕像和鑄像打碎並磨碎，撒在向這些偶像獻祭之人的墳墓上，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:2; 耶利米書 3:10; 民數記 35:33"> 還把那些祭司的骸骨燒在他們的祭壇上。這樣，他潔淨了猶大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 13:20–21; 以賽亞書 7:25; 歷代志下 30:1"> 他也在瑪拿西、以法蓮、西緬直到拿弗他利的各城，以及它們四圍的荒廢之處，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:1; 申命記 9:21; 歷代志下 34:1"> 在以色列全地拆毀祭壇，打碎、磨碎亞舍拉柱和雕像，砍倒所有的香壇，然後回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:16; 歷代志上 18:15; 耶利米書 29:25"> 約西亞在位第十八年，他潔淨了那地和殿宇以後，派遣亞薩利雅的兒子沙番、城主瑪西雅，以及約哈斯的兒子史官約亞，去修繕他的神耶和華的殿。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志下 30:18; 歷代志下 30:10; 歷代志下 35:8"> 於是他們來到大祭司希勒加那裡，把那些奉獻到神殿的銀子交給他，這銀子是守門的利未人從瑪拿西和以法蓮手中，從以色列所有的餘剩之民，從全猶大和便雅憫，從耶路撒冷的居民所接收的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 12:11–12; 以斯拉記 3:7; 列王紀下 22:5–6"> 他們把銀子交託在那些監管耶和華殿中工作的人手中，這些人再把銀子支付給那些做這工作、在耶和華殿中施工的人，去修復、修繕殿宇。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 33:4–7; 歷代志下 33:22"> 他們把銀子交給木匠和建築工，去購買鑿好的料石和做連接件的木材，又為猶大列王任由其毀壞的殿宇架上木梁。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 12:15; 歷代志上 23:5; 列王紀下 22:7"> 這些人在工作上行事誠信。利未人米拉利的子孫雅哈和俄巴底亞，以及哥轄的子孫撒迦利亞和米書蘭被委任來作監管，還有那些利未人，全都是精通樂器的；</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:10; 歷代志下 2:18; 耶利米書 8:8"> 他們也管理搬運工，監管做各樣工作的所有工人。利未人中也有作書記、官長和門衛的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 8:36; 詩篇 1:2; 利未記 10:11"> 當他們把奉獻到耶和華殿的銀子拿出來時，祭司希勒加發現了藉著摩西所傳的耶和華的律法書。</span>
<span className="v" id="v15" data-v="15"> 於是希勒加告訴書記沙番說：「我在耶和華殿中發現了律法書！」希勒加就把書卷交給沙番。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 22:9–10; 耶利米書 36:20–21"> 沙番把書卷拿到王那裡，回稟王說：「所有交託在你臣僕們手中的事，他們都在辦理。</span>
<span className="v" id="v17" data-v="17"> 他們把耶和華殿中的銀子倒出來，交在監管的人和工作的人手中了。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:46; 耶利米書 36:20–21; 申命記 17:19"> 書記沙番接著告訴王說：「祭司希勒加交給我一個書卷。」沙番就在王面前朗讀它。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:6; 申命記 28:3–68; 列王紀下 22:19"> 王聽了律法書上的話語，就撕裂衣服。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 22:12; 耶利米書 26:24; 耶利米書 40:9"> 王吩咐希勒加、沙番的兒子亞希甘、米迦的兒子阿布頓、書記沙番，以及王的僕人亞撒雅，說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 21:2; 以西結書 14:1–11; 歷代志下 28:6"> 「關於所發現這書卷上的話語，你們去，為我、為以色列和猶大的餘剩者求問耶和華。因為我們的祖先沒有謹守耶和華的話語，沒有去遵行這書卷上所記的一切，所以耶和華向我們傾瀉極大的怒火。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及記 15:20; 列王紀下 22:14"> 於是希勒加和王所派的那些人去見女先知胡勒達，她住在耶路撒冷第二區，是掌管禮服的沙勒姆的妻子；沙勒姆是哈斯拉的孫子、提克瓦的兒子。他們請教胡勒達，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 37:7–10; 耶利米書 21:3–7; 列王紀下 22:15–20"> 她就對他們說：<br />「以色列的神耶和華如此說：你們告訴那派你們來見我的人，</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 36:14–20; 約書亞記 23:16; 申命記 28:15–68"> 『耶和華如此說：看哪，我要使禍患，就是在猶大王面前讀的那書卷上所寫的一切詛咒，臨到這地方和這裡的居民身上；</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 7:20; 馬可福音 9:43–48; 那鴻書 1:6"> 因為他們離棄我，向別的神燒香，以他們手所造的一切惹怒了我。我的怒火要傾瀉在這地方，絕不熄滅。』</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 34:23; 歷代志下 34:21"> 不過，你們要對那派你們來求問耶和華的猶大王如此說：『關於你所聽見的那些話語，以色列的神耶和華如此說：</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 32:26; 以西結書 9:4; 詩篇 34:18"> 你既然聽了針對這地方和它居民的那些話語，就心裡柔軟，在神面前謙卑下來；你在我面前謙卑下來，撕裂衣服、在我面前哀哭，因此我已經垂聽了你。這是耶和華的宣告。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 39:8; 詩篇 37:37; 列王紀上 21:29"> 看哪，我必使你歸到你列祖那裡，你將平平安安歸到你的墳墓裡，你不會親眼看到我要降在這地方和其上居民的一切災禍。』」<br />他們就回去稟告王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀下 23:1–3; 歷代志下 30:2; 馬可福音 14:8"> 王派人去，招聚了猶大和耶路撒冷所有的長老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 24:7; 列王紀下 23:2; 歷代志下 34:15"> 然後，王與猶大眾人、耶路撒冷的居民、祭司、利未人、全體民眾，無論尊卑，都上耶和華的殿去。王就把耶和華殿中發現的約書上一切話語，宣讀給他們聽。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 23:16; 列王紀下 23:3; 列王紀下 11:14"> 王站在自己的位置，在耶和華面前立約，要全心、全靈跟從耶和華，謹守他的誡命、法度和律例，遵行這書卷上所記的聖約之言。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歷代志下 30:12; 耶利米書 3:10; 歷代志下 14:4"> 他也讓所有在耶路撒冷和便雅憫的人都歸入這約。於是耶路撒冷的居民就遵行神的約，他們祖先之神的約。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歷代志下 34:3–7; 約書亞記 24:31; 列王紀下 23:4–20"> 約西亞在以色列人的全境除掉了一切可憎之物，使所有在以色列的人都服事耶和華他們的神。約西亞在世的日子，他們都跟隨耶和華他們祖先的神，沒有偏離。</span>
</div>
</div>

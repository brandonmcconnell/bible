<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:4; 歷代志下 32:12; 創世記 19:15"> 這一切事結束後，在那裡的以色列人全都出去到猶大的各城，打碎神柱，砍倒亞舍拉柱，並在全猶大、便雅憫、以法蓮和瑪拿西，拆毀高壇和祭壇，直到全部拆毀了。然後所有的以色列人就各回自己的產業，回本城去了。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志上 24:1; 歷代志上 16:4–6; 歷代志下 29:24–26"> 希西加安排了祭司和利未人的班組，使祭司和利未人照著各自的班組、各自的服事去獻上燔祭和平安祭，在耶和華營中的各門那裡事奉、稱謝、讚美。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 45:17; 歷代志下 35:7; 歌羅西書 2:16–17"> 他還從自己的財物中劃定王的份做燔祭，就是耶和華律法上所記的清晨和傍晚的燔祭，安息日、新月節和各節期的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="瑪拉基書 2:7; 民數記 18:8–21; 尼希米記 13:10–13"> 他又吩咐耶路撒冷的居民要把祭司和利未人的份交上來，好讓他們能專心於耶和華的律法。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 13:12; 歷代志下 24:10–11; 尼希米記 10:35–39"> 這諭令一發出，以色列人就大量送來初熟的五穀、新酒、新油、蜂蜜和田地各樣的收成，也大量送來各物的十分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 27:30; 歷代志下 11:16–17; 申命記 14:28"> 至於住在猶大各城的以色列人和猶大人，他們也帶來牛群羊群的十分之一，以及分別為聖歸於耶和華他們神的聖物的十分之一，把它們積聚成堆。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 23:16–24"> 他們從三月開始收聚堆積，到七月結束。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 1:3; 創世記 14:19–20; 腓立比書 4:10"> 希西加和首領們前來，看見這些堆積物品，就頌讚耶和華，祝福耶和華的子民以色列。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 希西加向祭司和利未人詢問這些堆積的物品，</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 3:10; 歷代志上 6:8; 哥林多後書 9:8–11"> 撒督家族的祭司長亞撒利雅告訴他說：「自從人們開始把供物帶到耶和華的殿以來，我們就吃得飽足，還有大量剩餘的；耶和華實在祝福他的子民，這眾多之物都是剩餘的。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米記 10:38–39; 尼希米記 13:5; 尼希米記 13:12–13"> 於是希西加吩咐人在耶和華殿中預備一些庫房，他們就預備了。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:9; 列王紀下 12:15; 歷代志上 26:20–26"> 然後他們忠誠地把供物和十一奉獻以及聖物帶進去。利未人克南雅是他們的主管，他的兄弟示每是副手；</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 24:5; 歷代志下 31:10–11; 歷代志上 9:11"> 耶希業、阿撒細雅、拿哈、亞撒暉、耶利莫、約撒巴、以利業、伊斯瑪基雅、瑪哈、比納雅，按照希西加王和神殿總管亞撒利雅的指派，在克南雅和他的兄弟示每手下作監督。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 23:38; 歷代志上 26:12; 利未記 27:28"> 東門的門衛——利未人伊姆納的兒子可列管理獻給神的甘心祭，分發獻給耶和華的供物和那些至聖物。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 21:9–19; 歷代志上 9:22; 歷代志下 29:12"> 在他手下有伊甸、珉雅憫、耶書亞、示瑪雅、亞瑪利雅和謝喀尼亞，他們在各祭司城忠誠地按照班組分發物品給他們的兄弟，無論尊卑。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 3:4; 利未記 21:22–23; 歷代志上 23:3"> 此外也分發給記錄在家譜中三歲以上的男丁，就是所有要為日常事務進入耶和華的殿，照他們的職責和班組做服事的人；</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 23:24; 歷代志上 23:27; 民數記 3:15"> 還有按著他們父家記錄在家譜中的祭司，按照他們的職責和班組服事的二十歲以上的利未人；</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 15:16; 以賽亞書 5:16; 歷代志下 31:15"> 以及記錄在家譜中全體會眾的所有家屬——妻子、兒女，因為他們忠誠地使自己分別為聖了。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 31:12–15; 利未記 25:34; 民數記 35:2–5"> 至於亞倫子孫中那些住在他們城郊牧野的祭司，在各城都有被指名的人，負責把食物分發給這些祭司家中所有的男丁，以及所有記錄在家譜中的利未人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 20:3; 列王紀下 22:2; 使徒行傳 24:16"> 希西加在全猶大都這樣行。他在他的神耶和華面前做美善、正直、信實的事。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:33; 耶利米書 29:13; 約書亞記 1:7–8"> 無論在神殿的服事上，還是在律法或誡命上，凡他著手做的事，他都尋求他的神，全心去做，並且亨通。</span>
</div>
</div>

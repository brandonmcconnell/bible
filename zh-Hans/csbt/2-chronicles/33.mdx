<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 21:1–18; 歷代志上 3:13; 以賽亞書 3:12"> 瑪拿西作王的時候十二歲，在耶路撒冷統治了五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 28:3; 申命記 18:9; 列王紀下 17:11"> 他做耶和華眼中看為惡的事，效法耶和華在以色列子民面前趕出的那些民族，行可憎之事。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:21; 申命記 17:3; 歷代志下 31:1"> 他重建了他父親希西加拆毀的高壇，為巴力設立祭壇，製作亞舍拉柱，並向天上的萬象下拜，服事它們。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 7:16; 列王紀上 8:29; 申命記 12:11"> 他在耶和華殿中築了別的祭壇，關於這殿，耶和華曾指著它說「我的名要永遠在耶路撒冷」。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 4:9; 耶利米書 32:34–35; 以西結書 8:7–18"> 他又在耶和華殿的兩個院子裡為天上的萬象築了祭壇，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 18:21; 利未記 20:6; 歷代志下 28:3"> 在欣嫩子谷使自己的兒女經火，並且算命、行法術、行巫術、招魂、通靈。他做了許多在耶和華眼中看為惡的事，惹他惱怒。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 33:4; 歷代志下 7:16; 列王紀上 11:13"> 瑪拿西甚至把自己雕刻的偶像安置在神的殿中，關於這殿，神曾指著它對大衛和他兒子所羅門說：「我要在這殿中，在我從以色列眾支派所揀選的耶路撒冷，永遠安置我的名。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 7:10; 申命記 5:31–1; 利未記 8:36"> 只要以色列人謹守遵行我藉著摩西所吩咐他們的一切律法、律例和法規，我就不再使他們的腳離開我指定給你們列祖的這地。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 24:3–4; 箴言 29:12; 歷代志下 33:2"> 瑪拿西使猶大人和耶路撒冷的居民迷失，以致他們作惡超過那些在以色列子民面前被耶和華除滅的民族。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:15–16; 耶利米書 44:4–5; 撒迦利亞書 1:4"> 耶和華對瑪拿西和他的子民說話，他們卻不聽。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 28:36; 歷代志下 36:6; 尼希米記 9:32"> 所以耶和華使亞述王的將領們來攻擊他們，用鉤子捉住瑪拿西，用銅鏈捆住他，把他帶到巴比倫去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 10:3; 詩篇 50:15; 歷代志下 32:26"> 他在危難的時候，懇求他的神耶和華的恩寵，在他祖先的神面前極其謙卑。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 5:20; 但以理書 4:25; 馬太福音 7:7–8"> 他向耶和華禱告，耶和華就應允他的祈求，垂聽他的懇求，使他回歸耶路撒冷，恢復王權。瑪拿西這才知道：唯獨耶和華是神。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 27:3; 列王紀上 1:33; 尼希米記 3:3"> 此後他在大衛城外，從溪谷中的基訓西邊直到魚門入口，建造了一道城牆，環繞俄斐勒，並且建得很高。他又在猶大所有堅固的城中指派將領。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志下 33:3–7; 何西阿書 14:1–3; 列王紀下 21:7"> 他還從耶和華殿中除掉了外邦的神明和偶像，也把他在耶和華殿的山上、在耶路撒冷修築的祭壇全都拋到了城外。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 14:4; 列王紀上 18:30; 歷代志下 33:9"> 然後他重新修築耶和華的祭壇，在其上獻平安祭和感謝祭，吩咐猶大人要服事耶和華以色列的神。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 32:12; 列王紀上 22:43; 列王紀下 15:4"> 不過百姓仍舊在高壇獻祭，雖然只是獻給耶和華他們的神。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:19; 歷代志下 33:12–13; 阿摩司書 7:12"> 瑪拿西其餘的事蹟，還有他向他的神獻上的禱告，以及那些先見奉以色列的神耶和華的名向他宣告的話，看哪，這些都記在《以色列諸王紀事》上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 9:11; 約翰一書 1:9; 但以理書 5:22"> 他的禱告，神怎樣應允他的祈求，他謙卑下來之前的一切罪惡和不忠行為，以及他在哪些地方建造高壇、豎立亞舍拉柱和雕像，看哪，都記在《何賽紀事》上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 1:10; 歷代志下 32:33; 列王紀下 21:18–25"> 瑪拿西與他的列祖長眠，人們把他葬在他的宮殿院內；他的兒子亞門接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 4:13–15; 路加福音 12:19–20; 歷代志下 33:1"> 亞門作王的時候二十二歲，在耶路撒冷統治了兩年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 21:20; 以西結書 20:18; 列王紀下 21:1–11"> 他效法他父親瑪拿西的行為，做耶和華眼中看為惡的事。亞門向他父親瑪拿西雕刻的一切偶像獻祭，服事它們。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 33:12; 歷代志下 33:19; 耶利米書 7:26"> 但他沒有像他父親瑪拿西那樣，在耶和華面前謙卑下來，反而這亞門不斷增加罪過。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:22; 歷代志下 25:27–28; 歷代志下 24:25–26"> 他的臣僕密謀反叛他，在他的宮殿裡把他殺了。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 35:31; 歷代志下 34:1; 歷代志下 36:1"> 那地的民眾又把所有密謀反叛亞門王的人都殺了，然後立他的兒子約西亞接替他作王。</span>
</div>
</div>

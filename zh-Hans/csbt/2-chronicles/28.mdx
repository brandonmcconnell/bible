<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歷代志下" data-chapter="28" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 3:13; 以賽亞書 1:1; 列王紀下 16:1–20"> 亞哈斯作王的時候二十歲，在耶路撒冷統治了十六年。他沒有像他先祖大衛那樣，做耶和華眼中看為正的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 34:17; 士師記 2:11; 歷代志下 22:3–4"> 而是走以色列王的道路，甚至為巴力鑄造偶像。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 33:2; 歷代志下 33:6; 利未記 18:21"> 他效法耶和華在以色列子民面前趕出的那些民族的可憎行為，在欣嫩子谷燒香，用火焚燒自己的兒女；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 16:4; 申命記 12:2–3; 利未記 26:30"> 又在高壇上、丘陵上、各青翠樹下獻祭燒香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 7:1; 歷代志下 24:24; 列王紀下 16:5–6"> 所以耶和華他的神把他交在亞蘭王手中；亞蘭王擊敗了他，從他那裡擄走了很多人，帶到大馬士革。<br />亞哈斯又被交在以色列王手中，以色列王向他大行殺戮。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 15:27; 約書亞記 24:20; 耶利米書 15:6"> 利瑪利的兒子比加在猶大一天之內殺了十二萬人，全都是勇士，因為他們離棄了耶和華他們祖先的神。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 43:15; 創世記 41:43; 以斯帖記 10:3"> 以法蓮的勇士澤克利殺了王子瑪西雅、宮廷總管亞斯利甘和宰相以利加拿。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 11:4; 申命記 28:25; 申命記 28:41"> 以色列人擄走了他們的兄弟二十萬人，包括這些人的妻子、兒女，還從他們那裡掠奪了許多財物，把戰利品帶到撒瑪利亞。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 47:6; 以斯拉記 9:6; 啟示錄 18:5"> 那裡有耶和華的一位先知，名叫俄德，他出來迎見回撒瑪利亞的軍隊，對他們說：「看哪，你們祖先的神耶和華對猶大惱怒，把他們交在你們手中，你們竟然怒火滔天殺戮他們。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 25:39–46; 馬太福音 7:2–4; 耶利米書 25:29"> 現在你們又想要強迫猶大和耶路撒冷的人作你們的僕婢。你們自己不也在你們的神耶和華面前有罪過嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 2:13; 以斯拉記 10:14; 馬太福音 5:7"> 現在請聽我說！你們要把從你們兄弟中擄來的俘虜送回去，因為耶和華猛烈的怒氣臨到你們了！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 28:1; 耶利米書 26:6"> 於是以法蓮人的一些首領，就是約哈南的兒子亞撒利雅、米實列莫的兒子比利迦、沙勒姆的兒子耶希西加和哈德萊的兒子亞瑪撒，起來攔阻那些從戰場回來的人，</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 32:14; 馬太福音 23:32; 約書亞記 22:17–18"> 對他們說：「你們不可把俘虜帶到這裡來。我們已經在耶和華面前有罪過了，你們還想要增添我們的罪惡和罪過！我們的罪過實在重大，有猛烈的怒氣臨到以色列了！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 於是，武裝士兵們把俘虜和財物留在眾首領和全體會眾面前。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 25:21–22; 申命記 34:3; 士師記 1:16"> 以上被指名的那幾個人就起來，把俘虜領來，從戰利品中拿出衣服給他們所有赤身的人穿上，給他們穿衣穿鞋，給他們吃喝，給他們抹油，又用驢子馱著他們中所有虛弱的人，把他們帶到棕櫚城耶利哥他們的兄弟身邊。然後，他們回撒瑪利亞去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 16:5–7; 以賽亞書 7:17; 以賽亞書 7:1–9"> 那時，亞哈斯王派人去見亞述王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王——依據七十士譯本；馬索拉文本作「眾王」。">a</a></sup>，向他求助。</span>
<span className="v" id="v17" data-v="17" data-xref="俄巴底亞書 1:10; 俄巴底亞書 1:13–14; 利未記 26:18"> 因為以東人再次來攻打猶大，擄走民眾。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 16:57; 以西結書 16:27; 撒母耳記上 6:9"> 非利士人也搶掠了猶大丘陵和南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音譯作「內蓋夫」。">b</a></sup>的城鎮，攻取了伯示麥、阿雅崙、格德羅，還有梭哥和附屬的村鎮，亭拿和附屬的村鎮，瑾瑣和附屬的村鎮，然後住在那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 21:2; 約伯記 40:12; 申命記 28:43"> 耶和華由於猶大王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="猶大王——馬索拉文本作「以色列王」。">c</a></sup>亞哈斯的緣故，就降卑猶大，因為亞哈斯使猶大放縱行惡，對耶和華極其不忠。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 歷代志上 5:26; 以賽亞書 30:16"> 亞述王提革拉·毗列色來到他那裡，卻苦害他，沒有幫助他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 16:8–9; 列王紀下 18:15–16; 歷代志下 12:9"> 雖然亞哈斯搜刮了耶和華的殿、王宮以及首領們的家，敬獻給亞述王，但這沒有為他帶來幫助。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 1:5; 以西結書 21:13; 耶利米書 5:3"> 這亞哈斯王在危難的時候，卻更加對耶和華不忠。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 25:14; 耶利米書 44:20–28; 哈巴谷書 1:11"> 他向那些擊敗他的大馬士革人的神明獻祭，說：「既然亞蘭王的神在幫助亞蘭人，我也向它們獻祭，它們就會幫助我。」然而它們卻使他和全以色列敗亡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="歷代志下 29:7; 列王紀下 16:17–18; 歷代志下 30:14"> 亞哈斯聚攏神殿中的器皿，把它們都拆毀了，並且關閉耶和華殿的門，然後在耶路撒冷的各個角落為自己建造祭壇。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 28:3"> 他在猶大各城都建造高壇，向別的神燒香，惹怒了耶和華他祖先的神。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀下 16:19–20; 歷代志下 20:34; 歷代志下 27:7–9"> 亞哈斯其餘的事蹟、從始至終一切的行為，看哪，都記在《猶大和以色列諸王紀》上。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 21:20; 歷代志下 24:25; 箴言 10:7"> 亞哈斯與他的列祖長眠，葬在耶路撒冷城中，但沒有送進以色列君王們的陵墓；他的兒子希西加接替他作王。</span>
</div>
</div>

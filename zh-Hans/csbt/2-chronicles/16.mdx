<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 15:9; 歷代志下 15:5; 列王紀上 12:27"> 亞撒在位第三十六年，以色列王巴沙上來攻擊猶大，修築了拉瑪，不讓人與猶大王亞撒往來。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 12:18; 歷代志下 28:21; 列王紀下 18:15"> 於是亞撒從耶和華殿的庫房和王宮裡取出金銀，送給住在大馬士革的亞蘭王本哈達，說：</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 15:4; 歷代志下 18:3; 哥林多後書 6:16"> 「你我之間立約吧，就像我父親與你父親之間那樣。看哪，我把金銀送給你，請你廢除你與以色列王巴沙所立的約，好讓他從我這裡撤離。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 20:1; 歷代志下 17:12; 列王紀上 15:20"> 本哈達聽取了亞撒王，就派遣他的將領們到以色列的城鎮，攻占了伊永、但、亞貝勒-瑪音，以及拿弗他利所有的積貨城。</span>
<span className="v" id="v5" data-v="5"> 巴沙聽說了，就停止修築拉瑪，終止了他的工程。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 21:17; 約書亞記 15:38; 以賽亞書 10:29"> 於是亞撒王帶領全體猶大人，運走巴沙用於修築拉瑪的石頭和木材，用來修築迦巴和米斯巴。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 19:2; 列王紀上 16:1; 詩篇 146:3–6"> 那時，先見哈納尼來見猶大王亞撒，對他說：「由於你依靠亞蘭王，沒有依靠耶和華你的神，因此亞蘭王的軍隊逃脫了你的手。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 12:3; 歷代志下 13:16; 歷代志下 16:7"> 難道當初庫實人和利比亞人不是有強大的軍隊，極多的戰車和馬兵嗎？但你依靠耶和華，他就把他們交在了你手中。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 3:12; 箴言 15:3; 耶利米書 16:17"> 要知道，耶和華的眼目遍察全地，要彰顯大能幫助那些全心歸向他的人。你在這事上做得很愚蠢！從今以後，必有爭戰伴隨你。」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 18:26; 使徒行傳 16:23–24; 撒母耳記下 12:13"> 亞撒就對先見動怒，把他投入牢房，因亞撒為這話對他很憤怒。同時亞撒也逼迫了一些人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志下 12:15; 歷代志下 9:29; 歷代志下 35:27"> 亞撒從始至終的事蹟，看哪，都記在《猶大和以色列諸王紀》上。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 17:5; 歷代志下 28:22; 歷代志上 10:14"> 亞撒在位第三十九年，他的雙腳患了病，病情越來越嚴重。但他即使在病中也沒有尋求耶和華，只求問醫生。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 15:24"> 亞撒與他的列祖長眠，死於他在位第四十一年。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 50:2; 歷代志下 21:19; 耶利米書 34:5"> 人們把他葬在大衛城中他為自己開鑿的墓穴裡，安放在裝滿了用香膏工藝調制的各種香料的棺架上，並且為哀悼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哀悼——輔助詞語。">a</a></sup>他燃起了極大的篝火。</span>
</div>
</div>

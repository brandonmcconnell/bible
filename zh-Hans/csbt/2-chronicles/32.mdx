<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歷代志下" data-chapter="32" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:13–37; 列王紀下 17:6; 歷代志下 20:1–2"> 在希西加這些虔誠的行為之後，亞述王西納基立來入侵猶大，對著那些堅固的城紮營，想要攻破占據它們。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王紀下 12:17"> 希西加見西納基立前來，定意要攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就與他的首領、勇士們商議，要把城外那些水泉堵上，他們都幫助他。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 32:30; 列王紀下 18:9; 列王紀上 19:21"> 許多民眾聚集起來，堵上了所有的泉源和從那地穿過的溪流，他們說：「何必讓亞述王來找到豐富的水源呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 25:23; 列王紀上 9:24; 列王紀下 25:4"> 希西加堅定心志，重建所有被拆毀的城牆，加高城樓，又在城外另建一道牆，加固大衛城中的梯壘，並製造大量的兵器和盾牌。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 40:2; 歷代志下 30:22; 尼希米記 8:16"> 他又設立軍官指揮民眾，把他們聚集到他所在的城門口廣場上。他鼓勵他們說：</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 6:16; 羅馬書 8:31; 以弗所書 6:10"> 「你們要堅強、勇敢！不要害怕，不要因亞述王和與他一起的整個大軍而喪膽，因為與我們一起的比與他們一起的更強大。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 17:5; 歷代志下 20:17; 以賽亞書 41:10"> 與他一起的是血肉的膀臂，與我們一起的是耶和華我們的神，他必幫助我們，為我們作戰。」民眾因猶大王希西加的話而受到鼓舞。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:17; 約書亞記 10:31; 以賽亞書 36:2"> 此後，亞述王西納基立帶著他的全軍攻打拉吉的時候，派遣他的臣僕們去耶路撒冷，對猶大王希西加和耶路撒冷的所有猶大人說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:19; 以賽亞書 36:4"> 「亞述王西納基立如此說：你們困守耶路撒冷，到底是依靠什麼呢？</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 27:43; 詩篇 11:1–3; 以賽亞書 36:18"> 希西加說『我們的神耶和華會解救我們脫離亞述王的手』，這不是在誤導你們嗎？他是要你們因飢餓和乾渴而死。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 31:1; 申命記 12:13–14; 申命記 12:26–27"> 不就是他希西加除掉了耶和華的高壇和祭壇嗎？他還吩咐猶大和耶路撒冷的人，說『你們只可在一個祭壇前敬拜，在上面燒香』。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:33–35; 以賽亞書 44:8–10; 但以理書 4:30"> 「難道你們不知道，我和我的列祖對地上各民做了什麼？難道地上列國的神真能解救他們的國土脫離我的手嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 10:11–12; 出埃及記 15:9–11; 以賽亞書 42:8"> 我祖先滅絕的那些國家所有的神，哪一位能解救自己的子民脫離我的手呢？難道你們的神能解救你們脫離我的手嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 5:2; 但以理書 3:15; 以賽亞書 36:18"> 現在，不要讓希西加欺哄你們了，不要讓他這樣誤導你們。你們不要相信他，因為列國列邦所有的神都不能解救自己的子民脫離我的手和我列祖的手，何況你們的神，更不能解救你們脫離我的手！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 73:9; 約翰福音 15:21; 約伯記 15:25–26"> 西納基立的臣僕們還說了一些話攻擊耶和華神和他的僕人希西加。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 37:14; 列王紀下 19:12; 以賽亞書 37:28–29"> 西納基立也寫信辱罵耶和華以色列的神，攻擊他說：<br />「正如地上列國的神不能解救自己的子民脫離我的手，同樣，希西加的神也不能解救他的子民脫離我的手。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 17:10; 列王紀下 18:26–28; 撒母耳記上 17:26"> 他們用猶大話向城牆上的耶路撒冷民眾大聲呼喊，要恐嚇他們，使他們惶恐，好攻取那城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 19:18; 以賽亞書 2:8; 耶利米書 32:30"> 他們談論耶路撒冷的神，像是談論人手所造的地上萬民的神明。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 91:14–15; 以賽亞書 37:14–20; 歷代志下 14:11"> 希西加王和亞摩斯的兒子先知以賽亞為此禱告，向天呼求。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 37:36–38; 詩篇 76:5; 詩篇 18:50"> 耶和華就派遣一位天使，除滅了亞述王營地中所有的勇士、首領和將領。於是亞述王滿臉恥辱地撤回了本土。當他進入自己神明的廟宇時，他的幾個親生兒子在那裡用刀把他殺了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 31:4–5; 詩篇 18:48–50; 帖撒羅尼迦後書 3:5"> 這樣，耶和華拯救希西加和耶路撒冷的居民脫離了亞述王西納基立的手和所有敵人的手，使他們四圍安定<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使他們四圍安定——依據七十士譯本；馬索拉文本作「四圍帶領他們」。">a</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 17:5; 馬太福音 2:11; 歷代志下 1:1"> 有許多人把供物帶到耶路撒冷獻給耶和華，也把珍寶獻給猶大王希西加。從此以後，希西加在列國眼中顯為尊崇。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 38:1–8; 列王紀下 20:1–11; 以賽亞書 38:21–22"> 在那些日子，希西加患病快要死了，他向耶和華禱告，耶和華應允了他，並賜給他一個預兆。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 24:18; 歷代志下 26:16; 歷代志下 32:31"> 希西加卻沒有照著所蒙的恩惠回應耶和華，因為他心裡高傲。於是耶和華的震怒臨到他，也臨到猶大和耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 26:18–19; 歷代志下 34:27–28; 歷代志下 33:12"> 希西加知道<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="知道——輔助詞語。">b</a></sup>自己心裡的高傲，他與耶路撒冷的居民就謙卑下來，所以耶和華的震怒沒有在希西加年間臨到他們身上。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 27:25–31; 歷代志下 1:12; 箴言 10:22"> 希西加擁有極大的財富和榮耀，他為自己的金銀、寶石、香料、盾牌和各樣貴重物品建造庫房；</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 7:8; 歷代志下 26:10; 列王紀上 4:26"> 為收穫的五穀、新酒、新油建造倉房；也為各類牲畜修建廄棚，為羊群修建羊圈。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 29:12; 箴言 10:22; 撒母耳記上 2:7"> 他為自己建造了城鎮，他還獲得大量的羊群和牛群，因為神賜給他極多的財物。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:33; 以賽亞書 22:9–11; 詩篇 1:1–3"> 這希西加截住基訓上游的水源，把水往下引到大衛城的西邊。希西加所做的一切事都順利。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 8:2; 箴言 17:3; 創世記 22:1"> 只是當巴比倫眾首領派遣使者來查問這地發生的奇事時，神離開他，為要試驗他，好知道他心裡的一切。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 36:1–22; 列王紀下 18:1–20; 歷代志下 31:20–21"> 希西加其餘的事蹟和他對神的忠誠，看哪，都記在亞摩斯的兒子先知以賽亞的《異象書》上，以及《猶大和以色列諸王紀》上。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王紀上 1:21; 歷代志下 16:14"> 希西加與他的列祖長眠，人們把他葬在大衛子孫陵墓的山坡上。他死的時候，全體猶大人和耶路撒冷的居民都向他致敬。他的兒子瑪拿西接替他作王。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 12:16; 列王紀上 15:1–8"> 耶羅波安王在位第十八年，亞比雅作猶大的王，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 11:20; 列王紀上 15:6–7; 士師記 19:16"> 在耶路撒冷統治了三年。他的母親名叫米該婭，是基比亞人烏列的女兒。<br />亞比雅和耶羅波安之間常有爭戰。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 26:12–13; 歷代志上 21:5; 撒母耳記上 17:1–3"> 亞比雅統率一支軍隊出戰，有四十萬精兵，都是善戰的勇士；耶羅波安也擺陣迎戰，有八十萬精兵，都是英勇的戰士。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 18:22; 歷代志下 15:2; 創世記 10:18"> 亞比雅站在以法蓮山地的策瑪蓮山上，說：「耶羅波安和全體以色列人哪，請聽我說！</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 18:19; 利未記 2:13; 馬可福音 9:49–50"> 難道你們不知道嗎？以色列的神耶和華藉著鹽約，把以色列的王權永遠賜給了大衛和他的子孫。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 11:26; 列王紀上 12:20; 歷代志下 10:19"> 尼八之子耶羅波安原是大衛的兒子所羅門的臣僕，竟然起來背叛他的主人。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 9:4; 歷代志下 12:13; 使徒行傳 17:5"> 一些無賴和卑劣之徒聚集起來跟隨他，對抗所羅門的兒子羅波安，那時羅波安年少心軟，不能抗衡他們。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 12:28; 歷代志下 11:15; 路加福音 19:14"> 「現在你們又說要對抗大衛子孫所掌管的耶和華的王國！你們人多勢眾，並有耶羅波安為你們鑄造當作神的那些金牛犢與你們在一起。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 11:14–15; 耶利米書 2:11; 出埃及記 29:35"> 你們不是驅逐了耶和華的祭司，驅逐了亞倫子孫和利未人，像外邦人那樣為自己立了祭司嗎？任何人帶著一頭公牛和七隻公綿羊來奉獻自己，他就可以作那些虛無之神的祭司。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 19:5–6; 歷代志下 11:16–17; 撒迦利亞書 13:9"> 「至於我們，耶和華是我們的神，我們沒有離棄他。事奉耶和華的祭司是亞倫的子孫，利未人也在盡職；</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 2:4; 利未記 24:2–9; 出埃及記 29:38"> 每天早晨和傍晚都向耶和華燒獻燔祭和芬芳香；在潔淨的桌子上有陳設餅；每日傍晚點燃金燈臺的燈盞。我們一直遵守我們神耶和華的吩咐，你們卻離棄了他。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:39; 羅馬書 8:31; 民數記 10:8–9"> 看哪，神與我們同在，率領我們，他的祭司要對你們吹響進攻的號筒。以色列子孫哪，不要與耶和華你們祖先的神爭戰，因為你們不會得勝。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 8:4; 約書亞記 8:9; 箴言 21:30"> 那時，耶羅波安派了伏兵繞到他們後面，這樣猶大前有以色列軍，後有伏兵。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 14:11; 出埃及記 14:10; 約書亞記 8:20"> 猶大人轉身一看，自己腹背受敵，他們就呼求耶和華，祭司們也吹響號筒。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 14:12; 約書亞記 11:8; 詩篇 118:4–7"> 於是猶大人呼喊。當猶大人呼喊的時候，神就在亞比雅和猶大人面前打敗耶羅波安和全體以色列人。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 16:8; 士師記 11:21; 約書亞記 10:12"> 以色列人在猶大人面前逃跑，神把他們交在猶大人手中。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 28:6; 歷代志下 13:3; 歷代志下 13:12"> 亞比雅和他的軍兵擊敗了以色列人，是一場極大的殺戮，以色列有五十萬精兵被殺倒下。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 5:20; 歷代志下 14:11; 那鴻書 1:7"> 那時，以色列人就被制伏了。猶大人獲勝是因為依靠耶和華他們祖先的神。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 15:8; 約書亞記 15:9; 約書亞記 10:39"> 亞比雅追擊耶羅波安，攻取了他的幾座城，就是伯特利和附屬的村鎮，耶沙納和附屬的村鎮，以弗崙和附屬的村鎮。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 25:38; 列王紀上 14:20; 使徒行傳 12:23"> 亞比雅年間，耶羅波安不能再維持他的勢力。後來耶和華打擊他，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 9:5; 撒母耳記下 5:12–13; 士師記 10:4"> 亞比雅卻強盛起來；他娶了十四個妃嬪，生了二十二個兒子，十六個女兒。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 9:29; 歷代志下 12:15; 歷代志下 24:27"> 亞比雅其餘的事蹟和他的言行，都記在《先知易多評傳》上。</span>
</div>
</div>

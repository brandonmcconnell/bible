<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歷代志下" data-chapter="35" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:6; 民數記 9:3; 列王紀下 23:21–23"> 那時約西亞在耶路撒冷向耶和華守逾越節，人們在一月十四日宰殺了逾越節的羔羊。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 31:2; 歷代志上 22:19; 歷代志下 29:5–11"> 他指派祭司各自的職責，鼓勵他們為耶和華的殿服事，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 23:26; 瑪拉基書 2:7; 申命記 33:10"> 然後吩咐那些歸耶和華為聖、教導全體以色列人的利未人，說：「你們要把聖約櫃放在大衛之子以色列王所羅門建造的殿宇中，它不再是你們肩上的擔子了。如今，你們要服事耶和華你們的神，以及他的子民以色列。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志下 8:14; 歷代志上 23:1–26; 尼希米記 11:10–20"> 「你們要按著你們的父家，照著你們的班組，按照以色列王大衛的文書和他兒子所羅門的文告，預備好自己。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 135:2; 以斯拉記 6:18"> 你們要按著你們平民兄弟的父家劃分，照著利未人的每個父家分支，侍立在聖所。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 29:5; 希伯來書 9:13–14; 歷代志下 29:15"> 你們要宰殺逾越節的羔羊，並要使自己分別為聖，為你們的兄弟預備好自己，照著耶和華藉著摩西所指示的行事。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:63; 歷代志下 30:24; 以賽亞書 32:8"> 於是，約西亞為平民捐出羊群中的綿羊羔和山羊羔，全都作為所有在場之人的逾越節祭牲，數目有三萬隻，還有公牛三千頭；這些都出自王的財物。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 29:31–33; 耶利米書 29:25–26; 歷代志上 24:4–5"> 他的首領們也甘心為民眾、祭司和利未人捐出祭物；神殿的總管們希勒加、撒迦利亞和耶希業，給了祭司們兩千六百隻逾越節羔羊，三百頭公牛。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:21–28; 耶利米書 3:10; 以賽亞書 1:10–15"> 利未人的首領，就是克南雅和他的兄弟示瑪雅、拿旦業，以及哈沙比雅、耶伊列和約撒巴，為利未人捐出五千隻逾越節羔羊，五百頭公牛。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 30:16; 以斯拉記 6:18; 歷代志下 35:4–5"> 服事工作預備好之後，照著王的命令，祭司們在自己的位置上侍立，利未人也按照自己的班組侍立。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 29:34; 希伯來書 9:21–22; 歷代志下 29:22–24"> 利未人把逾越節的羔羊宰殺了，祭司從他們手中接過血來灑在祭壇上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在祭壇上——輔助詞語。">a</a></sup>。利未人剝去燔祭的皮，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 3:9–11; 利未記 3:3; 利未記 3:5"> 然後把燔祭拿去，按著父家的支系交給平民，讓他們照著摩西的書中所記的獻給耶和華；對公牛也是同樣處理。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 12:8–9; 撒母耳記上 2:13–15; 申命記 16:7"> 他們照著規定用火烤逾越節的羔羊，用鍋、釜或罐子煮其他聖物，然後迅速分給所有的平民。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 6:2–4"> 之後他們為自己和祭司們預備這一切，因為作祭司的亞倫子孫忙於獻燔祭和脂油一直到晚上。於是利未人為自己和作祭司的亞倫子孫都預備好了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 25:1–7; 歷代志上 26:12–19; 歷代志上 9:17–19"> 作歌手的亞薩子孫照著大衛、亞薩、希幔和王的先見耶杜頓的命令，在自己的崗位上侍立，門衛也在各門口侍立。他們不必離開自己的服事崗位，因為他們的兄弟利未人也為他們預備了一切。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 一切服事耶和華的工作都在那天預備好了，為要照著約西亞王的命令守逾越節，在耶和華的祭壇上獻燔祭。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:15–20; 歷代志下 30:21–23; 出埃及記 23:15"> 那時，在場的以色列人都守了逾越節，並守了七天除酵節。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 30:5; 列王紀下 23:21–23; 歷代志下 30:26–27"> 從先知撒母耳的日子以來，在以色列沒有守過這樣的逾越節；任何以色列王，都沒有守過像約西亞、祭司、利未人、全體猶大人和在場的以色列人以及耶路撒冷居民所守的逾越節。</span>
<span className="v" id="v19" data-v="19"> 這逾越節是約西亞在位第十八年守的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 10:9; 列王紀下 23:29–30; 耶利米書 46:2–12"> 在約西亞整頓殿宇的這一切事之後，埃及王尼科上來攻打靠近幼發拉底河的卡赫美士，約西亞出去迎戰他。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 25:19; 列王紀下 18:25; 以賽亞書 36:10"> 尼科派遣使者去見約西亞說：「猶大王啊，我與你有什麼相干呢？我今天不是攻擊你，而是攻擊那與我爭戰之家，並且神吩咐我急速行動。所以你不要對抗與我同在的神，免得他毀滅你。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士師記 5:19; 歷代志下 18:29; 列王紀上 22:30"> 約西亞卻不肯轉身離開，反而喬裝去與他作戰。他不聽從神所吩咐尼科的話，來到米吉多平原去爭戰。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:34; 列王紀下 9:24; 創世記 49:23"> 弓箭手射中約西亞王，王就對他的臣僕說：「你們把我抬走吧，我受了重傷。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 12:11; 列王紀下 23:30; 詩篇 36:6"> 他的臣僕把他從戰車上抬走，放在他的副戰車上，送回耶路撒冷。約西亞死了，被葬在他列祖的墳墓裡，全猶大和耶路撒冷為他悲慟。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米哀歌 4:20; 耶利米書 22:10; 約伯記 3:8"> 耶利米為約西亞作了哀歌，所有男女歌手在他們的哀歌裡也都提到約西亞，直到今日；人們使這些成為以色列的習俗。看哪，這都記在《哀歌書》上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 31:20; 歷代志下 32:32"> 約西亞其餘的事蹟，他對耶和華律法內容的忠誠，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 26:22; 歷代志下 25:26; 列王紀下 10:34"> 以及他從始至終的事蹟，看哪，都記在《以色列和猶大諸王紀》上。</span>
</div>
</div>

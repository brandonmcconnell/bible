<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 15:24; 以弗所書 6:10; 馬太福音 1:8"> 亞撒的兒子約沙法接替他作王。約沙法穩固勢力，對抗以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 15:8; 歷代志下 11:5; 歷代志下 11:11–12"> 他在猶大所有堅固的城中派駐軍隊，也在猶大地和他父親亞撒所攻取的以法蓮各城中派遣駐軍。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀下 22:2; 以賽亞書 41:10; 提摩太後書 4:22"> 耶和華與約沙法同在，因為他走他先祖大衛先前的道路。他不尋求巴力，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 12:28; 路加福音 1:6; 帖撒羅尼迦前書 2:12"> 只尋求他父親的神，按照神的誡命行事，不效法以色列人的行為。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 18:1; 馬太福音 6:33; 詩篇 127:1"> 所以耶和華堅立他手中的王權，全猶大都向約沙法進貢，他就擁有極大的財富和榮耀。</span>
<span className="v" id="v6" data-v="6" data-xref="何西阿書 14:9; 歷代志下 15:17; 歷代志下 20:33"> 他心中尊崇耶和華的道，而且還從猶大除掉了高壇和亞舍拉柱。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 35:3; 尼希米記 8:7–8; 傳道書 12:9–10"> 約沙法在位第三年，他派遣大臣本亥伊勒、俄巴底亞、撒迦利亞、拿旦業、米該亞，到猶大各城去教導人。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 7:1–6; 歷代志下 19:8; 瑪拉基書 2:7"> 與他們同去的有利未人示瑪雅、尼坦亞、希巴迪亞、亞撒暉、示米拉莫、約拿單、亞多尼雅、托比亞和駝巴多尼雅，都是利未人；與他們同去的還有祭司以利沙瑪和約蘭。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 5:46; 羅馬書 3:2; 使徒行傳 8:40"> 他們在猶大教導人，隨身帶著耶和華的律法書。他們巡行猶大各城，教導民眾。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 14:14; 出埃及記 15:14–16; 箴言 16:7"> 猶大四圍之地的列國都懼怕耶和華，不與約沙法爭戰。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 26:8; 歷代志下 9:14; 撒母耳記下 8:2"> 一些非利士人給約沙法送來禮物和貢銀，阿拉伯人也給他送來牲畜——公綿羊七千七百隻、公山羊七千七百隻。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 8:2–6; 歷代志下 14:6–7; 歷代志下 32:5"> 約沙法漸漸變得非常強盛。他在猶大各地建造營寨和積貨城，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 27:25–31; 歷代志下 26:10–15"> 在猶大各城還有許多工程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有許多工程——或譯作「儲備大量物資」。">a</a></sup>。在耶路撒冷駐有英勇的戰士，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 11:1; 創世記 15:5; 民數記 1:18"> 按著他們的父家登記如下，屬猶大支派的千夫長有：<br /><span className="pl pl-1">將領阿德納，帶領英勇的戰士三十萬；</span><br /></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">其次是將領約哈南，帶領二十八萬人；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="士師記 5:9; 士師記 5:2; 歷代志上 29:9"> <span className="pl pl-1">其次是澤克利的兒子亞瑪斯雅，帶領英勇的戰士二十萬，他是甘願奉獻給耶和華的人。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 14:8; 撒母耳記下 1:21–22"> <span className="pl pl-1">出自便雅憫支派的有：</span><br /><span className="pl pl-1">英勇的戰士以利雅大，帶領持弓執盾的人二十萬；</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">其次是約撒巴，帶領武裝隊伍十八萬。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 17:2; 歷代志下 11:12; 歷代志下 11:23"> 這些都是事奉王的，不包括王派駐在全猶大各堡壘城的軍兵。</span>
</div>

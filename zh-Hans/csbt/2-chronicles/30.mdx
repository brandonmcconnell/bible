<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbt" data-translation-id="cmn_csbt" data-translation-label="CSBT" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歷代志下" data-chapter="30" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 5:7–8; 歷代志下 11:13; 何西阿書 5:4"> 那時希西加派人到全以色列和全猶大，又寫信給以法蓮人和瑪拿西人，要他們到耶路撒冷耶和華的殿來，向以色列的神耶和華守逾越節。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 9:10–11; 歷代志上 13:1–3; 歷代志下 30:13"> 王和首領們以及在耶路撒冷的全體會眾商議了，要在二月守逾越節；</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 29:34; 出埃及記 12:6; 出埃及記 12:18"> 他們不能在正月守節，因為分別為聖的祭司還不夠，而且民眾還沒有聚集到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 13:4"> 這事在王眼中和全體會眾眼中都看為合宜，</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 20:1; 利未記 23:2; 以斯帖記 8:8–10"> 他們就作出決議，傳令全以色列，從比爾-謝巴直到但，要到耶路撒冷向以色列的神耶和華守逾越節，因為他們已經很久沒有照著律法所記的守節了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米書 51:31; 以斯帖記 8:14; 列王紀下 15:19"> 信使們帶著王和首領們簽發的書信，走遍全以色列和全猶大，照著王的諭令宣告：「以色列子孫哪，你們要回轉歸向亞伯拉罕、以撒、以色列的神耶和華，好使他也轉向你們這些在亞述王手下殘留的倖存者。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 29:8; 以西結書 20:13–18; 撒迦利亞書 1:3–4"> 你們不要像你們的祖先和你們的兄弟那樣，他們對他們祖先的神耶和華不忠，以致耶和華使他們令人驚駭，正如你們所看見的那樣。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 32:9; 歷代志下 29:10; 申命記 10:16"> 現在你們不要像你們的祖先那樣硬著頸項，而要舉手歸順耶和華，進入他的聖所——那永遠分別為聖的居所，要服事耶和華你們的神，好使他從你們身上收回他猛烈的怒氣。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 55:7; 彌迦書 7:18; 詩篇 86:5"> 如果你們回轉歸向耶和華，你們的兄弟和你們的兒女就會在擄走他們的人面前蒙憐憫，回歸這地；因為你們的神耶和華有恩惠、有憐憫，只要你們回轉歸向他，他必不會轉臉不顧你們。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:16; 歷代志下 30:6; 尼希米記 2:19"> 信使們從這城到那城走遍了以法蓮和瑪拿西之地，直到西布倫；那裡的人卻譏笑他們，嘲笑他們。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 30:18; 歷代志下 30:21; 歷代志下 30:25"> 但在亞設和瑪拿西，在西布倫，有一些人謙卑下來，前往耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 32:39; 耶利米書 24:7; 腓立比書 2:13"> 神的手也在猶大人身上，賜給他們合一的心，去遵行王和首領們按照耶和華的吩咐頒發的諭令。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 30:2; 詩篇 84:7"> 到了二月，有許多民眾聚集到耶路撒冷守除酵節，成了盛大的集會。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 28:24; 撒母耳記下 15:23; 歷代志下 15:16"> 他們起來，除掉耶路撒冷的那些祭壇，也除掉了所有燒香的祭壇，扔進汲淪溪谷。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 29:34; 歷代志下 5:11; 出埃及記 19:22"> 二月十四日，他們宰殺了逾越節的羔羊。祭司和利未人感到愧疚，所以使自己分別為聖，然後把燔祭帶到耶和華殿中。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 33:1; 歷代志下 35:15; 列王紀下 11:14"> 他們照著神人摩西的律法，按照他們的規定，在自己的位置上侍立，祭司從利未人接過血來灑在祭壇上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在祭壇上——輔助詞語。">a</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 29:34; 歷代志下 35:3–6; 出埃及記 12:6"> 因為會眾有許多人還沒有使自己分別為聖，所以利未人負責為所有不潔淨的人宰殺逾越節的羔羊，好使他們在耶和華面前分別為聖。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 11:28; 雅各書 5:15–16; 但以理書 9:19"> 其實，大部分民眾——有許多來自以法蓮、瑪拿西、以薩迦和西布倫——他們還沒潔淨自己，就已經不按律法所記的吃了逾越節的羔羊，因此希西加為他們禱告說：「至善的耶和華啊，願你饒恕他們！</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 19:3; 箴言 23:26; 約伯記 11:13"> 他們都立定心志尋求神——耶和華他們祖先的神，儘管他們沒有照聖所的潔淨禮行事。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 15:26; 雅各書 5:15–16; 詩篇 103:3"> 耶和華垂聽了希西加，就醫治<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="醫治——或譯作「赦免」。">b</a></sup>民眾。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:15; 出埃及記 13:6; 申命記 12:12"> 在耶路撒冷的以色列人極其歡喜地守了七天除酵節，利未人和祭司們每天都用嘹亮的樂器在耶和華面前讚美耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 32:6; 尼希米記 9:3; 以賽亞書 40:1–2"> 希西加對所有在耶和華的事上明達幹練的利未人說寬心的話。這樣，他們獻上平安祭並稱謝耶和華他們祖先的神，吃這節期的筵席共七天。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 8:65; 歷代志下 7:9"> 全體會眾商議，要另外守節七天，於是他們歡歡喜喜地又守了七天。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 29:34; 歷代志下 35:7–8; 以弗所書 4:8"> 因此猶大王希西加為會眾捐出了一千頭公牛、七千隻羊，首領們為會眾捐出了一千頭公牛、一萬隻羊，有許多祭司使自己分別為聖。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 30:11; 歷代志下 30:18; 歷代志上 16:10–11"> 於是，猶大全體會眾、祭司、利未人、從以色列各地來的全體會眾、從以色列各地來的寄居者和居住在猶大的人，都歡喜快樂。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 7:8–10"> 在耶路撒冷有極大的喜樂，因為自從大衛的兒子以色列王所羅門那時候以來，耶路撒冷從來沒有這樣做過。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 26:15; 詩篇 68:5; 民數記 6:23–26"> 那時利未祭司們起來，祝福民眾，他們的聲音蒙神垂聽，他們的禱告達到天上那神聖的居所。</span>
</div>
</div>

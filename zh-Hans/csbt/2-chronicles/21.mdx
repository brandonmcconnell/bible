<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 22:50; 列王紀下 8:16–17; 歷代志下 12:16"> 約沙法與他的列祖長眠，葬在大衛城，與他的列祖在一起；他的兒子約蘭接替他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 12:6; 歷代志下 23:2; 歷代志下 24:5"> 約蘭有幾個兄弟，就是約沙法的兒子亞撒利雅、耶希業、撒迦利亞、亞撒利雅、米迦勒和示法提雅，這些都是以色列王約沙法的兒子。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:23; 申命記 21:15–17; 歷代志下 11:5"> 他們的父親給了他們許多禮物，有金銀、珍寶，以及猶大的幾座防御城；但把王權交給了約蘭，因為他是長子。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:5; 歷代志下 21:17; 創世記 4:8"> 約蘭執掌他父親的國權，勢力穩固之後，用刀殺了他所有的兄弟，還殺了以色列的一些首領。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 8:17–22"> 約蘭作王的時候三十二歲，在耶路撒冷統治了八年。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 18:1; 列王紀上 12:28–30; 列王紀下 8:18"> 他走以色列王的道路，像亞哈家所做的那樣，因為亞哈的女兒作了他的妻子；他做耶和華眼中看為惡的事。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 11:36; 詩篇 132:17–18; 撒母耳記下 7:12–17"> 但耶和華因著他與大衛所立的約，就不願毀掉大衛家，而要照著他的應許永遠賜給大衛和大衛的子孫一盞燈。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 21:10; 歷代志下 20:22–23; 創世記 27:40"> 約蘭年間，以東反叛脫離猶大的掌控，自己立了一個王。</span>
<span className="v" id="v9" data-v="9"> 約蘭就帶著他的將領以及所有的戰車過去。他夜間起來，攻擊那些包圍他的以東人和眾戰車長。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 15:2; 耶利米書 2:13; 歷代志下 13:10"> 最終，以東反叛脫離了猶大的權下，直到今日。立拿也在那時反叛脫離約蘭的掌控，因為約蘭離棄了耶和華他祖先的神。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 20:5; 列王紀上 11:7; 利未記 17:7"> 他還在猶大各山上建造高壇，使耶路撒冷的居民行淫，把猶大人引入歧途。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 14:2–5; 歷代志下 17:3–4; 列王紀下 2:1"> 於是先知以利亞寫信給約蘭，說：<br />「你先祖大衛的神耶和華如此說：『因為你不走你父親約沙法的道路，也不走猶大王亞撒的道路，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 21:4; 歷代志下 21:11; 列王紀上 16:30–33"> 卻走了以色列王的道路，像亞哈家行淫那樣，使猶大人和耶路撒冷的居民行淫，並且殺了你父家那些比你好的兄弟，</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 26:21; 出埃及記 20:5; 何西阿書 5:11"> 看哪，耶和華將用極大的災禍打擊你的子民和你的兒子們、妃嬪們，以及你擁有的一切。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 21:18–19; 使徒行傳 1:18; 申命記 28:67"> 至於你，你會有嚴重的病患，是腸道的疾病，你的腸道必因日復一日的病患而脫垂。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 17:11; 歷代志下 33:11; 列王紀上 11:14"> 耶和華激發非利士人以及庫實人附近的阿拉伯人的怒氣，與約蘭作對。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 22:1; 歷代志下 22:6; 歷代志下 25:23"> 他們就上來攻打猶大，攻破了它，擄走王宮裡的一切財物，以及王的兒子們、妃嬪們；除了他最小的兒子約哈斯以外，沒有給他留下一個兒子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 21:15; 使徒行傳 12:23; 列王紀下 9:29"> 這一切事之後，耶和華打擊約蘭，使他的腸道患了不治之症。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 16:14; 耶利米書 34:5"> 一天天過去，兩年之後，他的腸道因這疾病而脫垂，他就病重而死。他的子民沒有為他燃起篝火哀悼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哀悼——輔助詞語。">a</a></sup>，像為他祖先燃起篝火那樣。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米書 22:18; 歷代志下 28:27; 耶利米書 22:28"> 他作王的時候三十二歲，在耶路撒冷統治了八年。他去世無人悼念，人們把他葬在大衛城，但不在君王們的陵墓裡。</span>
</div>
</div>

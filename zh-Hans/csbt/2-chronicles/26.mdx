<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 22:1; 馬太福音 1:8–9; 歷代志下 33:25"> 猶大全體民眾選立烏西雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="烏西雅——又稱「亞撒利雅」；見《列王紀下》14:21。">a</a></sup>，接替他父親亞瑪謝作王，那時他十六歲。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 16:6; 歷代志下 25:28; 歷代志下 25:23"> 亞瑪謝王與列祖長眠之後，烏西雅重建埃拉特，使它回歸猶大。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀下 15:2–3; 阿摩司書 1:1; 何西阿書 1:1"> 烏西雅作王的時候十六歲，在耶路撒冷統治了五十二年。他的母親名叫耶克利雅，是耶路撒冷人。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 25:2"> 他效法他父親亞瑪謝所做的一切，做耶和華眼中看為正的事。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 15:2; 歷代志下 24:2; 歷代志上 22:13"> 教導人敬畏神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="教導人敬畏神——或譯作「領悟神的啟示」。">b</a></sup>的撒迦利亞在世的時候，烏西雅一直尋求神。在他尋求耶和華的年日裡，神使他亨通。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 14:29; 撒母耳記上 5:6; 撒母耳記上 5:1"> 他出去攻打非利士人，拆毀了迦特的城牆、雅比尼的城牆、阿實突的城牆，然後在阿實突附近、在非利士境內建造了幾座城。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 21:16; 歷代志上 5:20; 歷代志下 14:11"> 神幫助他對抗非利士人和住在姑珥巴力的阿拉伯人，以及米烏尼人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:2; 歷代志下 17:11; 創世記 19:38"> 亞捫人向烏西雅進貢；他的名聲一直傳到埃及，因為他變得極其強盛。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 3:13; 歷代志下 25:23; 列王紀下 14:13"> 烏西雅在耶路撒冷的角門、谷門和城牆凸角上面都建造塔樓，並加固它們。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 26:18–21; 以賽亞書 29:17; 列王紀下 3:4"> 他在曠野建造守望樓，並開鑿了許多水窖，因為他在丘陵和平原上有許多牲畜。他在山區和果園裡還有許多農夫和葡萄園丁，他是個喜愛土地的人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 5:2"> 烏西雅有一支善戰的軍隊，按照書記耶伊列和官長瑪西雅經手登記的人數，在王的一位將軍哈納尼雅指揮下編隊出戰。</span>
<span className="v" id="v12" data-v="12"> 各父系的首領——英勇的戰士——總數為兩千六百人，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 25:5; 歷代志下 14:8; 歷代志下 11:1"> 他們手下有善戰的軍兵三十七萬七千五百人，是一支強大力量，幫助王抗擊敵軍。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 20:16; 撒母耳記上 17:49"> 烏西雅給全軍預備了盾牌、長矛、頭盔、鎧甲、弓箭和投石器。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 31:4; 馬太福音 4:24; 歷代志下 2:7"> 他還在耶路撒冷製造了由設計師發明的裝置，安放在塔樓和城角上面，用來發射箭矢和大石頭。他的名聲傳到遠方，因為他奇妙地得到幫助，強盛了起來。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 32:25; 歷代志下 25:19; 箴言 16:18"> 烏西雅勢力強盛時，就心裡高傲，以致敗壞。他對他的神耶和華不忠，進入耶和華的聖殿，要在香壇上燒香。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:10; 歷代志上 26:6; 歷代志上 12:28"> 祭司亞撒利雅帶著耶和華的祭司八十人跟著他進去，都是英勇的人。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 30:7–8; 民數記 18:7; 耶利米書 13:18"> 他們攔阻烏西雅王，對他說：「烏西雅啊，給耶和華燒香不是你該做的，而是亞倫的子孫祭司們該做的，他們被分別為聖來燒香。請你離開聖所吧！因為你對神不忠，不會從耶和華神那裡得到尊榮。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民數記 12:10; 歷代志下 25:16; 列王紀下 5:25–27"> 烏西雅卻發怒，那時他手裡拿著香爐正要燒香。他正對祭司們發怒時，就在耶和華殿中香壇旁邊，在祭司們面前，他的額頭上出現了痲瘋。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 28:22; 以斯帖記 6:12; 利未記 14:34"> 祭司長亞撒利雅和所有的祭司朝他看去，看哪，他額頭上長了痲瘋。他們就急切催他離開，他自己也急著要出去，因為耶和華打擊了他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 13:46; 民數記 12:15; 列王紀下 7:3"> 烏西雅王患了痲瘋，直到死的日子。他因患了痲瘋就住在隔離的房子裡，與耶和華的殿隔絕。他的兒子約坦接管王室，治理國民。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 1:1; 以賽亞書 6:1; 歷代志下 9:29"> 烏西雅其餘的事蹟，從始至終，都由亞摩斯的兒子先知以賽亞記下來了。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 28:27; 歷代志下 21:20; 歷代志下 26:18"> 烏西雅與他的列祖長眠，人們把他葬在王陵的田間、與他的列祖在一起，因為他們說：「他是個患痲瘋的人。」他的兒子約坦接替他作王。</span>
</div>
</div>
